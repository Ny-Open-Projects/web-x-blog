# 选题卡模板（创作者用）

> 用来判断「这个点值不值得写 / 值不值得出成题」。
> 一条选题一张卡，攒够 5 条再排产。

```markdown
## {选题标题}

- **来源**：{哪门课 / 哪次面试 / 自己踩的坑}
- **类型**：知识点补缺 / 体系梳理 / 实战复盘 / 认知纠偏
- **受众**：{初阶 / 中阶 / 高阶}
- **核心主张**：{一句话，写这个要想清楚什么}
- **材料**：
  - [ ] source 里已有素材
  - [ ] 需要补外部资料（记 URL）
- **预估产出**：{N 张卡 / 1 篇长文}
- **状态**：待排产 / 进行中 / 已产出 / 已发布
- **备注**：{反常识点、易错点、能当钩子的句子}
```

## 排产原则

- **同一个考点不重复出**：先查 `work/target/` 和 `work/blog/` 现有索引。
- **认知纠偏类优先级最高** —— 这些才是创作者的价值差。
