## 0. 一句话定位

**面向个人投资者的「量化投研内容 + 短线择时决策看板 + 策略实验」一体化站点**：把课程知识、行情数据、量化策略、可解释的买卖决策打通，让用户「学得会、看得懂、敢下手、知风险」。

差异化：不同于同花顺/东方财富（重交易、轻教学）、聚宽/JQData（重专业回测、门槛高），本站**以「可解释的短线决策 + 系统化量化课程」为切口**，降低个人量化门槛。

## 1. 背景与机会

- **需求侧**：个人投资者规模庞大，但「凭感觉交易」普遍亏损；量化被视为专业机构能力，个人缺乏**低门槛、可解释、带教学内容**的量化工具。
- **内容侧**：已有体系化课程素材（指标/分类/系统构成/取数/JQData + wyy0008 量化投资课），可快速转化为结构化内容资产。
- **方法论侧**：短线择时决策链路（当日量价、换手、多空量能、午后动能、MACD/RSI/均线、支撑压力）已跑通，可产品化为「决策看板」。
- **基建侧**：已有内容生产管线（source→target→blog）与 Node 微服务经验，可复用降本。

## 4. 功能模块详述（六大模块）

### M1 投研内容库（内容端，获客与留存）
- **课程体系**：把五份 docx + wyy0008 转成结构化课程/博客卡片（复用既有 source→target→blog 管线，格式红线照旧）。
- **每日复盘**：大盘环境、涨跌分布、热点板块、资金流向的图文日报。
- **术语/指标词典**：K线、均线、MACD、RSI、布林、PE/PB、北向资金、多因子等，配可运行代码片段。
- **形式**：文章 + 卡片 + mermaid 图解 + 可运行 Python/JS 示例 + 视频课索引。

### M2 行情与数据可视化（数据端 + 可视化端）
- **大盘环境**：主要指数（上证/深成/沪深300/创业板/科创50）实时/日线、涨跌家数、成交额、量比。
- **个股详情**：日/周/月 K 线、分钟线、成交量、换手率、资金流（北向/主力/散户）、技术指标叠加。
- **自选与分组**：自选股、行业/概念板块、涨跌榜、异动监测。
- **技术栈**：K线图表库（ECharts / Lightweight-Charts）+ 指标计算（TA-Lib / 自研）。

### M3 策略实验室（决策端，专业壁垒）
- **策略模板库**（呼应课程流派）：双均线、均值回归、动量、二八轮动、海归、多因子选股、机器学习占位。
- **可视化搭策略**：低代码选择「指标+阈值+仓位规则」，生成信号。
- **回测引擎**：历史数据回测，输出收益率、最大回撤、夏普、胜率、盈亏比、资金曲线；支持参数寻优。
- **代码态**：进阶用户可直接写 Python 策略（受限沙箱执行），复用课程代码。

### M4 决策看板（决策端 + 可视化端，专家强项/爆点）
每个标的/组合输出**可解释的短线决策**，固定包含：
- **今日数据**：涨跌幅、成交量/量比、换手率、波动、多空量能、内外盘。
- **午后方向**：上攻 / 冲高回落 / 探底回升 / 震荡（盘中动量）。
- **多时间维度**：下一交易日 / 下周 / 下月，各带方向、幅度、置信度、依据、支撑/压力。
- **情景概率**：多/空/震荡概率分布。
- **操作指引**：条件式「若…则买入/加仓…，若…则止损/止盈…，否则观望」，含价位、仓位、止损止盈。
- **大盘环境**：当日大盘多空评级，作为个股决策前置过滤。
- 交付形态：**深色 HTML 决策看板**（专家既有产物形态）。

### M5 模拟盘与风控（执行端，不碰真实下单）
- **模拟交易**：虚拟资金下单、成交、持仓、收益统计，验证决策看板有效性。
- **风控模块**：单票仓位上限、止损线、组合回撤阈值、VaR 提示。
- **决策回放**：把历史「决策看板」与后续实际走势对照，统计命中率（用真实数据说话，不吹准确率）。

### M6 社区与策略市集（留存与网络效应）
- 策略分享、复盘帖子、组合跟盘（模拟）、达人榜（按模拟盘夏普/回撤排名）。
-  UGC 护栏：禁晒真实收益承诺、禁代操盘、强风险提示。

## 6. 技术架构与选型

**选型对比（前端/全栈）**：

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| A. Next.js 全栈（App Router） | SSR/SSG、React 生态、一套代码前后端、Vercel 友好 | 重计算(回测)需拆服务 | **推荐**：主站用 Next.js |
| B. 纯静态 hexo + 客户端取数 | 复用既有博客基建、上线快 | 无账号/无回测/无持久化 | 仅适合 M1 内容站，不够 |
| C. Vue + 独立后端 | 生态成熟 | 团队若偏 React/Node 则分裂 | 备选 |

**推荐架构**：
- **前端**：Next.js 15 + React 19 + TypeScript + Tailwind + shadcn/ui；图表 ECharts / Lightweight-Charts；决策看板可复用专家深色 HTML 模板。
- **后端**：Node.js（可复用 nofault 微服务框架）+ 量化计算用 **Python 微服务（FastAPI）**（指标/回测/因子，生态最强）。
- **数据层**：PostgreSQL（用户/策略/持仓）+ TimescaleDB（行情时序）+ Redis（缓存/热点）。
- **数据源**：JQData(JoinQuant) / Tushare / akshare（免费额度）+ 可选 Wind/彭博（付费秒级）。落库做本地缓存，前端不直连数据商。
- **任务**：定时抓数 + 指标计算 + 决策看板生成（cron / 消息队列）。
- **部署**：Docker + Nginx；可对标既有 web-x-blog 的 Docker 部署经验（端口/镜像 tag 管理）。
- **合规前置**：用户协议、风险揭示书、免责声明；不接入真实券商户，仅模拟盘。

## 7. 数据来源与指标体系

**数据分级**：
| 类型 | 来源 | 用途 | 成本 |
|---|---|---|---|
| 日/分钟行情、财务、指数 | JQData / Tushare / akshare | 看板、回测 | 免费额度起步 |

**指标体系（呼应课程，分层）**：
- **择时（短线，看板核心）**：MACD、RSI、均线(MA/EMA)、布林带、KDJ、量比、换手、多空量能、午后动量、支撑/压力位。
- **选股（因子）**：市值、PE/PB、ROE/盈利、成长、波动率、最大回撤、行业景气（申万/中证分类）。
- **组合/风控**：VaR、最大回撤、夏普、盈亏比、胜率、仓位集中度。
- **策略流派库**：均值回归、动量、二八轮动、海归、多因子、机器学习（占位）。

## 9. 合规、风险与披露（红线，贯穿全程）

1. **不承诺收益、不保证准确率**；所有历史/回测数据标注「不代表未来」。
2. **不自动下单、不接真实资金**；仅模拟盘 + 信息展示，明确「非投资建议」。
3. **风险揭示**：每篇决策/策略/文章尾部固定风险披露 + 数据来源 + 时效。
4. **决策可解释**：每个信号给出依据（哪些指标、什么阈值），杜绝黑箱。
5. **数据合规**：仅用授权数据源，遵守数据商条款；不转售原始行情。
6. **社区 UGC 审核**：禁代客理财、禁收益承诺、禁荐股引流。
