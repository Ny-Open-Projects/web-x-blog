# 407 GOPROXY：模块代理的配置与取值

> 分类：Go 工程化 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**GOPROXY**/**direct**/**off**/**go env -w**/**国内代理**

> 原文锚点：第 49~59 段「代理是什么 / 默认值 / direct / off / 国内镜像」

## 一句话总述
`GOPROXY` 指定 Go 拉取依赖包的代理地址，默认值是官方的 `https://proxy.golang.org,direct`；国内常用七牛云或阿里云镜像加速，末尾加 `direct` 表示代理拉不到时回源到版本控制系统；设为 `off` 则禁止从任何源下载模块。

## 面试官视角
这是「你有没有在国内真机配过环境」的试金石。能说出默认地址、为什么国内要换、以及 `direct` 与 `off` 的语义差别，基本过关；能补一句「私有包不能走公网代理」就能自然过渡到下一个问题。

## 主问答
**Q（面试官原话）：** GOPROXY 是干什么的？你怎么配的？

1. **本质是代理**：Go 拉取包时会按 `GOPROXY` 设置的值，从指定地址下载依赖模块，而不是直接连源码站。
2. **默认值**：默认是官方代理地址，因在境外，国内拉取通常较慢，所以一般换用国内镜像。
3. **多地址与回源**：多个地址用逗号分隔；末尾写 `direct` 表示代理取不到时，直接按模块地址从源码仓库拉取，最大限度保证能取到包。
4. **取值为 off**：表示不允许从任何源下载依赖模块，常用于强制离线或只允许本地缓存/vendor 的场景。
5. **持久化方式**：除环境变量外，可用 `go env -w` 写入配置文件，避免每次开终端都要重新导出。

## 版本与兼容性
| 取值 | 含义 |
|------|------|
| 默认 | 官方代理 + direct 回源 |
| 国内镜像 | 七牛云 / 阿里云 + direct |
| off | 禁止从任何源下载 |
| 空 direct | 全部直连源码仓库 |

## 关键代码
```go
// Go 侧视角：构建前打印并校验代理配置，避免 CI 机器配置漂移
package main

import (
	"fmt"
	"os/exec"
	"strings"
)

func main() {
	out, _ := exec.Command("go", "env", "GOPROXY").Output()
	proxy := strings.TrimSpace(string(out))
	fmt.Println("GOPROXY =", proxy)
	if !strings.Contains(proxy, "direct") {
		fmt.Println("警告：未配 direct，代理缺失时无法回源")
	}
}
```

## 总结与追问预判
核心：**代理 + direct 回源 + off 断网**。追问常拐向「私有包怎么办」「go env -w 写到哪」，备好「私有域名配不走代理」与「写入 go env 配置文件」两句话。

## ⚠️ 原文纠错
1. 事实核校： [经验] 原文称代理「从 Go 1.11 开始支持、跟随模块机制诞生」——模块机制确于 1.11 引入，但代理协议与默认取值在 1.13 起才稳定，且 Go 1.16 起模块模式成为默认，表述时应区分「引入」与「稳定」。
2. 事实核校： [经验] 原文描述 off 为「不允许从任何源来下载依赖包」，准确；需补充的是此时仍可使用模块缓存与 vendor 目录，并非完全无法构建。
3. 崩坏词归一：源码将 GOPROXY / Go modules / 七牛云 等音译为多组崩坏词，本卡统一为规范术语。
