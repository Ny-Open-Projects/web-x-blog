# 178 二叉树基础：定义、满二叉树、完全二叉树与存储

> 分类：算法/树 | 难度：L2 | 题型：概念题 | 频率：高 | 关键词：**二叉树**/**满二叉树**/**完全二叉树**/**链式存储**/**顺序存储**
> 原文锚点：第 1~28 段「树定义(根唯一/递归/叶子) + 二叉树(最多两子) + 满二叉树(2^k-1) + 完全二叉树(第k层集中最左) + 链式/顺序存储」

## 一句话总述
二叉树是每个节点**最多两个子节点**的递归层次结构。两个关键特殊形态：**满二叉树**（只有度0/度2节点、度0全在同一层，深度 k 节点数 = 2^k−1）与**完全二叉树**（除第 k 层外各层达最大、且第 k 层节点连续集中在最左）。存储分**链式**（节点含左右指针）与**顺序**（数组连续、下标访问）两种。

## 面试官视角
- 考察意图：能否说清满/完全二叉树的区别，以及两种存储方式的取舍。
- 分档：P5 知二叉树最多两子；P6 能背满/完全定义与 2^k−1；P7 知完全二叉树与堆/数组映射关系。
- 红旗答案：把完全二叉树说成满二叉树；忽略完全二叉树「第 k 层集中最左」这一关键。
- 惊艳点：点出「满二叉树是完全二叉树的特例、完全二叉树契合数组下标映射（堆的基础）」 [经验]。

## 主问答
**Q（面试官原话）：** 什么是满二叉树和完全二叉树？
**A：**
1. **二叉树定义**：每个节点最多两个子节点；树是递归结构（节点+后代仍是一棵树），根唯一无父、叶子无后代 [经验]。
2. **满二叉树**：只有度0（叶子）和度2节点、且度0全在同一层；深度 k 时节点数 = 2^k−1 [经验]。
3. **完全二叉树**：除最后一层外各层节点数达最大，且最后一层节点**连续集中在最左**；满二叉树是其特例 [经验]。

## 总结与追问预判
满/完全二叉树是堆、优先队列、线段树的基础。完全二叉树「集中最左」使其可被数组紧凑表示，是二叉堆 O(1) 父子下标映射的前提。

// 二叉树节点（链式存储）：值 + 左右指针
type TreeNode struct {
    Val   int
    Left  *TreeNode // 左子节点指针
    Right *TreeNode // 右子节点指针
}
// 顺序存储：用数组按层序存放，下标 i 的节点
//   左子 = 2*i+1，右子 = 2*i+2（完全二叉树紧凑、无空洞）
// 满二叉树深度 k 节点数 = 1<<k - 1（即 2^k - 1）
