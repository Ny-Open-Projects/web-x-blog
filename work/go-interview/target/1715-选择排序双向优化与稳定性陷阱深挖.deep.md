# 1715 选择排序双向优化与稳定性陷阱 深挖

> 覆盖源 17-15 全文：双向选择优化（每轮同时找 min+max、轮数减半）、下标漂移坑、不稳定性的完整反例推演、以及「比较次数与输入无关」这一性质带来的选型边界。主卡已给原理、实测与双向实现，本附录做「双向优化的下标陷阱」「为什么不稳定」「与冒泡/插入/快排的选型矩阵」「什么时候 O(n²) 反而合理」四层深挖。

## 思路与架构

```text
双向选择排序（每轮处理未排序区 [l, r]）
├─ 一轮同时求 minIdx / maxIdx（一次扫描, 比较各一次）
├─ 交换顺序是唯一的坑
│   ├─ 先换 a[l]<->a[minIdx]
│   ├─ 若 maxIdx == l → max 已被换到 minIdx, 必须 maxIdx = minIdx
│   └─ 再换 a[r]<->a[maxIdx]
├─ 终止条件: l >= r 或 minIdx == maxIdx(剩余全相等)
└─ 收益与代价
    ├─ 外层轮数: n-1 -> ⌈n/2⌉
    ├─ 总比较: 仍约 n^2/4 量级, 量级不变
    └─ 每轮多一次比较 + 两处边界判断, 常数变大
```

## 方案取舍
- **为什么比较次数固定反而是短板**：n(n-1)/2 次比较「雷打不动」意味着选择排序**无法利用输入的有序性**——冒泡有序时一趟扫描 O(n) 就能提前结束，插入有序时也是 O(n)，而选择排序对「已有序 / 逆序 / 随机」三种输入的比较次数完全相同。对「基本有序」的真实数据（如按时间增量写入后再补插少量记录的数组），选择排序是最差选择之一 [经验]。
- **为什么不稳定是结构性的**：交换发生在「未排序区第一个位置」与「极值位置」之间，两者通常**不相邻**，中间的相等元素会被跳过。反例完整推演：`[5a, 5b, 2]` → 第一轮最小值 2 与 5a 交换 → `[2, 5b, 5a]`，5a 与 5b 的相对次序被破坏。要稳定就得改成「整体平移插入」（那就变成插入排序了），失去「每轮只交换一次」的卖点——**稳定性与最少交换在原地交换模型下不可兼得** [经验]。
- **双向优化的性价比判断**：轮数减半听起来诱人，但总比较次数只从 n²/2 降到约 n²/4，**仍是 O(n²) 量级**；且每轮多维护一个 max 下标、多两处边界分支，常数开销上升。它的真正价值是面试中展示「知道优化方向 + 知道下标漂移陷阱」，工程上不如直接换算法 [经验]。
- **与邻居算法的选型矩阵**：要稳定且基本有序 → 插入排序；要交换次数最少且内存写敏感（如 EEPROM/Flash 写寿命敏感场景）→ 选择排序有独特价值；要平均最快 → 快排/堆排；要稳定 O(n log n) → 归并。快排的本质差异见 1717：它靠分区让每轮的**信息利用率**远高于「只确定一个极值」 [边界]。
- **O(n²) 反而合理的场景**：n 很小（如 n ≤ 16 的插入排序阈值，多数标准库快排/内省排序在小区间就退化到插入排序）；或**写代价 >> 读代价**的存储介质上，选择排序「交换最少」的特性是真实优势——这是它至今仍出现在嵌入式面试里的原因 [经验]。

## 答题技巧
- 手写前先问一句「需要稳定吗 / 数据规模多大」，把选型意识亮出来，比闷头写代码加分 [经验]。
- 被问「和冒泡区别」时用**两个数字**说话：交换 ≤ n-1 次 vs 平均 O(n²) 次；比较固定 n(n-1)/2 vs 有序时 O(n) [实测]。
- 被问「基本有序会不会快」时先答「不会」，再对比插入排序「会」，一正一反显出比较次数固定这一定性 [经验]。
- 写双向优化时**主动说坑**：「先换 min 会把 max 的下标换走，要先换 max 或交换后修正」，这是本算法最容易写错的点，主动讲出来直接到 P7 档 [经验]。
- 主动边界到 `1717-quicksort-overview`（分治如何突破 O(n²)）、`1718-*` 排序家族卡（若后续覆盖堆排/归并再引用），构成排序专题链 [边界]。

## 细节与核心 API

```go
// 鸡尾酒排序（双向冒泡）：每轮先从左向右把最大冒右，再从右向左把最小冒左
func cocktail(a []int) {
    lo, hi := 0, len(a)-1
    for lo < hi {
        for i := lo; i < hi; i++ { if a[i] > a[i+1] { a[i], a[i+1] = a[i+1], a[i] } }
        hi--
        for i := hi; i > lo; i-- { if a[i] < a[i-1] { a[i], a[i-1] = a[i-1], a[i] } }
        lo++
    }
}
// 优化点：双向各把一头就位，对“小值偏右”的数据比单向冒泡少一轮
// 稳定性：冒泡类稳定（仅相邻等序不交换）；若改写为“跨位交换最小值”就退化为选择排序、变不稳定
// 代价：仍是 O(n^2)，仅常数改善；数据量大应直接上 O(n log n)
```
