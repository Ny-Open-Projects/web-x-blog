# 510 如何使一个结构体不能被比较？

> 分类：Go 语言 / 类型系统 | 难度：L3 | 题型：技巧题 | 频率：中 | 关键词：**不可比较**/**零尺寸字段**/**非导出**/**[0]func()**/**匿名结构体**
> 原文锚点：第 1~35 段「结构体想要不能被比较,给它一个不可比较类型的字段...优雅做法:放一个非导出的零尺寸不可比较字段(函数不可比较,零元素数组零尺寸,即 [0]func())...验证 Sizeof 不增...结构体相等三前提:字段都是可比较类型+可隐式转换+按声明顺序逐字段相等...命名类型之间即使字段完全一致也不可比较,匿名结构体之间才可以」

## 一句话总述
想让结构体**不能被比较**，给它加一个**不可比较类型**的字段即可；更优雅的做法是加一个**非导出的零尺寸不可比较字段**——用 `[0]func()`（函数是不可比较类型，零元素数组是零尺寸的），结果是结构体既无法用 `==` 比较（自然也就不能作 map 的 key），**又不占任何额外内存**。另外要留意结构体相等的三前提：字段都是可比较类型、两个类型之间**可隐式转换**（命名类型之间即使字段完全一致也不行，只有**匿名结构体**才可）、按声明顺序逐字段比较且全部相等。

## 面试官视角
- 考察意图：表面考"怎么禁用比较"，实则考对**可比较性规则、类型同一性、零尺寸值**三者的综合理解。
- 分档：P5 知"加个不可比较字段"；P6 能给出 `[0]func()` 并说明零尺寸不占内存；P7 能讲清相等三前提与命名/匿名结构体的差异。
- 红旗答案：只说"加个 slice/map 字段"（能禁用比较但会占内存且语义变重）；不知道命名类型与匿名结构体在比较上的差别。
- 惊艳点：点出「用 `[0]func()` 同时做到不可比较 + 零开销 + 非导出（外部无法构造）」「命名类型之间不可隐式转换，即使字段完全一致也不可比较」 [经验]。

## 主问答
**Q（面试官原话）：** 怎么让一个结构体不能被比较？
**A：**
1. **基本做法**：结构体只要含有**不可比较类型**的字段，整个结构体就不可比较——所以给结构体加一个不可比较字段即可 [经验]。
2. **优雅做法**：加一个**非导出的、零尺寸的、不可比较字段**——`_ [0]func()`。理由是**函数是不可比较类型**、**零个元素的数组是零尺寸的**，且非导出让外部无法构造该字段 [经验]。
3. **零开销验证**：实测 `unsafe.Sizeof`，含该字段的结构体与不加该字段时**尺寸完全相同**（如都 16 字节），证明该字段不占内存 [经验]。
4. **为什么要这么做**：不可比较类型**不能作为 map 的 key**；当我们希望避免某结构体被误用作 map key 时，就主动把它变成不可比较类型 [经验]。
5. **相等三前提（易踩坑）**：两结构体相等需同时满足——① 字段类型**都是可比较类型**；② 两个类型之间**可隐式转换**（**命名类型**即使字段数量/名称/顺序完全一致也不可隐式转换、不可比较；只有**匿名结构体**之间才可）；③ 按**声明顺序**逐字段比较且全部相等，字段顺序不同则不相等 [经验]。

## 总结与追问预判
标准答案是 `_ [0]func()`：不可比较 + 零尺寸 + 非导出三合一。面试常追问「为什么不用 slice 字段」→ 答「会占 24 字节且改变结构体语义，零尺寸方案更干净」；再追问「两个字段完全一样的结构体能比较吗」→ 答「命名类型不能（不可隐式转换），匿名结构体才可以」。

## ⚠️ 原文纠错
1. 事实核校： [经验] 含不可比较字段则结构体不可比较、`[0]func()` 为零尺寸且函数不可比较、命名类型之间不可隐式转换、匿名结构体可比较、字段顺序影响相等性——均正确，符合 Go 类型系统规则。
2. 崩坏词归一：源码将若干术语音译为崩坏词（如将结构体、数组、函数、字段等音译为非规范串），本卡统一为规范术语，无黑名单词。

```go
// 使结构体不可比较的优雅做法：加一个非导出的零尺寸不可比较字段
type Person struct {
    Name string
    _    [0]func() // 函数不可比较；[0]T 是零尺寸不占内存；非导出，外部无法构造
}

// 验证：零尺寸字段不占内存
fmt.Println(unsafe.Sizeof(Person{})) // 16，与只含 Name 的结构体相同

// 命名类型之间不能隐式转换，即使字段完全一致也不可比较
// var _ = p1 == p4 // 编译错误：mismatched types（两个不同的命名类型）

// 匿名结构体之间可隐式转换、可比较（字段顺序也须一致）
p5 := struct{ Name string }{Name: "a"}
p6 := struct{ Name string }{Name: "a"}
fmt.Println(p5 == p6) // true
```
