# 816 GMP 的设计权衡与优缺点

> 分类：并发模型 | 难度：L3 | 题型：工程题 | 频率：中 | 关键词：**work-stealing** / **handoff** / **复杂度** / **协程泄露**
> 原文锚点：第 84~166 段「work-stealing…handoff…GMP 优缺点总结」

## 一句话总述
GMP 用本地队列 + 工作窃取 + handoff 实现负载均衡与多核并行，换来高效并发；代价是模型复杂、用户/内核态协作有额外开销、并引入协程泄露等风险。

- P5 能列优点 / P6 能讲 work-stealing 与 handoff 如何配合 / P7 能讲缺点与踩坑（泄露/调试）
- 红旗：只说优点；把"额外开销"夸大到否定模型
- 惊艳点：work-stealing 偷一半 + handoff 在阻塞时转移 P，二者共同避免 P/m 过载或闲置 `[源码]`

## 主问答
**Q：** GMP 到底好在哪、又付出了什么代价？
**A：**
1. **优点·均衡**：本地队列 + 工作窃取 + handoff，让 g 在 P/m 间灵活迁移，避免局部过载 `[源码]`。
2. **优点·并行**：P 数默认等于逻辑 CPU，天然吃满多核 `[经验]`。
3. **缺点**：模型复杂、用户/内核态协作有信号/扫描/分配开销，且带来协程泄露、调试困难等风险 `[经验]`。
**加分层：** 额外开销相比"线程在内核态频繁切换"已小很多，属工程最优折中。
