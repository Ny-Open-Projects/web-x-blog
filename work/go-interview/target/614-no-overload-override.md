# 614 Go 不支持重载，支持有限的重写

> 分类：语言基础 / 面向对象 | 难度：L2 | 题型：概念辨析题 | 频率：高 | 关键词：**重载**/**重写**/**不支持重载**/**结构体嵌入**/**接口多态**

> 原文锚点：第 2~18 段「重载的定义与结论 → 重写的实现」

## 一句话总述
**重载（overload）**是同名方法参数列表不同、编译器按实参自动选择——**Go 不支持**，这是刻意的简单性取舍；**重写（override）**是子类型对父类型同名同参方法给出不同实现——Go 以两种方式支持：结构体嵌入后外层方法**遮蔽**内层同名方法，以及接口层「不同实现体对同一方法签名各给实现」的真多态。

## 面试官视角
这道题的陷阱在「重载 vs 重写」一字之差，考官用它在三分钟内分出三档人：只会背「Go 不支持重载」是一档；能说清**为什么砍掉重载**（同名多义伤害可读性、类型推断复杂化）是二档；能指出**嵌入遮蔽不是多态**、真多态必须经接口的是三档。第三档直接进追问深水区。

## 主问答
**Q（面试官原话）：** Go 支持重载吗？如何实现重写？

1. **重载是什么**：同一个类里定义多个同名方法，参数列表（类型/个数/顺序）不同，调用时编译器按实参自动选择。典型例子：一个 `Add` 方法分别收两个、三个、多个参数。
2. **Go 的回答：不支持**。在 Go 里把两个同名方法写进同一个结构体，**编译直接报错**（method redeclared）。设计哲学是保持足够简单——同名多义让「看到方法名猜行为」变难，也让没有重载决策的类型系统更轻；面向对象上做了大量阉割换来轻量级实现。
3. **重写是什么**：子类型重新定义与父类型同名同参数的方法，实现不同——目的是子类型按自己的需要改变行为，换来多态与可扩展性。
4. **Go 怎么做到重写——两层**：① **嵌入遮蔽**：把内层结构体嵌入外层，外层定义同名方法后，外层调用走自己的版本（内层方法被「遮住」，仍可显式 `Cat.Animal.Eat()` 触达）；② **接口多态**：不同类型实现同一接口方法，经接口变量调用时走各自实现——这才是**运行期分派**的真重写。细节见深卡与 `615-embedding-inheritance.md`。
5. **没有重载，怎么办**：可变参数 `func Add(nums ...int)` 一个方法吃掉任意个数；类型不同则用泛型 `func Max[T cmp.Ordered](a, b T) T` 或显式命名不同方法。**「一个名字一种行为」逼你把差异写进名字或类型参数里**。

## 版本与兼容性
| 主题 | 说明 |
|------|------|
| 重载 | 1.0 至今不支持，官方 FAQ 明确立场：简化类型系统 |
| 嵌入遮蔽 | 外层方法遮蔽内层同名方法，编译期静态分派，无 virtual 语义 |
| 接口分派 | 运行期经 itab 分派，是 Go 唯一的「真重写」通道 |
| 泛型 | 1.18+ 类型参数可替代「参数类型不同」的重载场景 |

## 关键代码
```go
// 重载：编译报错 method redeclared
// type Calc struct{}
// func (c Calc) Add(a, b int) int              { return a + b }
// func (c Calc) Add(a, b, d int) int           { return a + b + d }  // ✗ 不编译

// 可变参数：一条路吃掉任意个数
func Add(nums ...int) int {
	sum := 0
	for _, n := range nums {
		sum += n
	}
	return sum
}

// 嵌入遮蔽 + 接口多态：两种「重写」
type Animal struct{}

func (Animal) Eat() string { return "动物进食" }

type Cat struct{ Animal }

func (Cat) Eat() string { return "猫吃鱼" } // 遮蔽 Animal.Eat

type Eater interface{ Eat() string }

func main() {
	var e Eater = Cat{}
	_ = e.Eat() // 接口分派走 Cat.Eat——运行期多态
}
```

## 总结与追问预判
核心：**重载=同名不同参（Go 拒绝）、重写=同名同参不同实现（Go 用嵌入遮蔽 + 接口分派两层支持）；替代重载靠可变参数与泛型**。追问必拐向「遮蔽算不算多态」——答案是静态遮蔽、非运行期分派，接口才是多态通道（见 `614-overload-alternatives.deep.md`），嵌入语义细节见 `615-embedding-inheritance.md`、方法提升冲突见 `615-method-promotion-conflict.md`。

## ⚠️ 原文纠错
1. 事实核校： [经验] 原文说「cat 类继承了 animal 类」「结构体内嵌表示 cat 子类实现了 animal 类」——**表述失准**：嵌入是组合不是继承，无 is-a 关系；外层同名方法是遮蔽，未经接口时并不产生多态。真重写须「定义接口 + 各类型各自实现 + 经接口变量调用」。
2. 术语归一：源文将「重载」多次音转为「承载/编载」、eat 转为 it，本卡统一为规范术语；类/继承等说法已按 Go 组合语义改写。
