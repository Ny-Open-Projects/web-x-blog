# 411 Go 格式化动词：布尔与整型

> 分类：Go 标准库 | 难度：中 | 题型：语法细节 | 频率：高 | 关键词：**fmt、%t、%T、%d、%b、%c、%x、rune**

> 原文锚点：第 1~32 段「布尔与整型的格式化输出动词」

## 一句话总述
Go 的 `fmt` 用动词控制输出形态：布尔 `%t` 输出值、`%T` 输出类型；整型 `%d` 十进制、`%5d`/`%05d` 控宽（补空格/补零）、`%b` 二进制、`%o` 八进制、`%c` 按码点出字符、`%q` 带单引号、`%x`/`%X` 十六进制、`%U` Unicode；`rune` 本质是 `int32` 别名。

## 面试官视角
fmt 动词是「不难但考点细」的题，考的是你有没有真写过格式化输出。能讲清 `%5d` 与 `%05d` 差异、`%c` 是码点而非字节、rune=int32，就能拉开与背答案者的差距。

## 主问答
**Q（面试官原话）：** Go 里整型和布尔常用哪些格式化动词？%5d 和 %05d 区别？

1. **布尔**：`%t` 输出 `true/false` 值；`%T` 输出变量类型；用 `%s` 套布尔会得到格式错误占位符（如 `%!s(bool=true)`），并非正常字符串。
2. **整型十进制与控宽**：`%d` 普通十进制；`%5d` 宽度 5、不足左补空格；`%05d` 宽度 5、不足左补零（如 `12` → `00012`）。
3. **进制与字符**：`%b` 二进制、`%o` 八进制、`%x`/`%X` 十六进制（小/大写）、`%c` 按 Unicode 码点转字符、`%q` 带单引号（必要时转义）、`%U` 输出 `U+XXXX`。
4. **rune 本质**：`rune` 是 `int32` 的别名，打印其字符用 `%c` 即可转成对应字母。

## 版本与兼容性
| 动词 | 输出 |
|------|------|
| %d | 十进制 |
| %b/%o | 二进制/八进制 |
| %c/%q | 字符/带引号字符 |
| %x/%X/%U | 十六进制/Unicode |

## 关键代码
```go
fmt.Printf("%05d\n", 12)   // 00012
fmt.Printf("%c\n", 65)    // A（rune 码点）
fmt.Printf("%T\n", true)  // bool
```

## 总结与追问预判
核心：**动词决定形态，%5d 补空格、%05d 补零，%c 是码点**。追问常拐向字符串/浮点动词（见 411）或 `%v` 三兄弟（见 411）。
