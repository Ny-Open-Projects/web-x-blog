# 1715 选择排序：每轮选极值、交换次数最少的 O(n²) 排序

> 分类：排序算法 | 难度：L2 | 题型：手写算法题 | 频率：中 | 关键词：**选择排序**/**每轮一次交换**/**比较次数固定**/**不稳定**/**双向选择**
> 原文锚点：第 1~32 段「选择排序不像冒泡排序一样相邻的去交换元素，而是通过选择最小的元素，每轮迭代只需要交换一次…外层遍历的次数就是 n 减一…每一轮我们除了找到最小的下标之外，我们还去找最大的下标，这样循环次数就可以减半」

## 一句话总述
选择排序每轮从**未排序区**选出最小（或最大）元素，与未排序区**第一个元素交换**、并入已排序区——比较次数固定为 n(n-1)/2 与初始序列无关，但**交换次数全程最多 n-1 次**，是交换类排序里交换开销最小的一种；可用「每轮同时找 min+max」的双向优化把外层轮数减半。

## 面试官视角
- 考察意图：手写门槛低，真正分档在**复杂度细节**——「交换次数比冒泡少在哪」「数组基本有序它会不会变快」「稳不稳定、为什么」。
- 分档：P5 能写出两层 for 正确排序；P6 说清交换 O(n) vs 比较固定 O(n²)；P7 能给出不稳定的反例并主动做双向选择优化、说清其代价与坑。
- 红旗答案：说「和冒泡差不多」却答不出交换次数差异；说「数组基本有序时选择排序会变快」——错，它的比较次数与初始序列无关。
- 惊艳点：主动指出**不稳定**并举反例 `5a 5b 2`：第一轮 2 与 5a 远距离交换后，5a 跑到 5b 之后 [经验]。

## 主问答
**Q（面试官原话）：** 手写一个选择排序，并说说它和冒泡排序的区别。
**A：**
1. **工作原理**：外层 i 从 0 走到 n-2，每轮在 `[i, n)` 区间**记录最小值下标**（先记下标不急着换），内层扫完后若 `min != i` 才交换一次——每轮固定把一个极值归位，n-1 轮后整体有序 [源码]。
2. **与冒泡的核心差异在交换次数**：时间同是 O(n²)，但选择排序**每轮至多交换 1 次、全程 ≤ n-1 次**；冒泡平均/最坏交换 O(n²) 次。实测 n=1000 随机序列：选择排序 swap=**993**，冒泡 swap=**250539**，相差 **253 倍** [实测]。
3. **代价是比较次数固定**：无论输入是否有序，比较都是固定 n(n-1)/2 次（实测 n=1000 时 cmp=**499500**）——「基本有序的数组」对选择排序**毫无加速**，这点和冒泡（有序可提前结束）、插入（有序 O(n)）本质不同 [实测]。
4. **不稳定**：交换发生在**不相邻**的两个位置，会跨过中间元素改变相等元素的相对次序。多关键字二次排序等需要稳定性的场景不能用裸选择排序 [经验]。
5. **双向优化**：每轮同时找 min 与 max，分别与未排序区**首尾**交换，外层轮数从 n-1 减半到 ⌈n/2⌉；**两个坑**：① min 交换会移动 max 所在位置，若 `max == l` 需把 max 修正为 min；② 剩余元素全相等（min==max）时可直接结束 [经验]。

| 写寿命敏感存储场景 | 选择排序「交换最少」成为真实优势 | 别把 O(n²) 一票否决，按介质特性选型 |

## 关键代码
```go
// 选择排序 + 双向优化（每轮同时找 min 与 max，外层轮数减半）
func selectionSort(a []int) {
	for l, r := 0, len(a)-1; l < r; l, r = l+1, r-1 {
		min, max := l, l
		for j := l + 1; j <= r; j++ {
			if a[j] < a[min] {
				min = j
			}
			if a[j] > a[max] {
				max = j
			}
		}
		if min == max { // 剩余全部相等，提前结束
			return
		}
		a[l], a[min] = a[min], a[l]
		if max == l { // max 恰好指向被换走的位置，修正下标
			max = min
		}
		a[r], a[max] = a[max], a[r]
	}
}
// [实测] n=1000 随机序列：比较 499500 次（固定 n(n-1)/2），交换 993 次；同数据冒泡比较 498759 次、交换 250539 次
```

## 总结与追问预判
一句话记忆：**「每轮挑一个极值归位：比较固定 O(n²)，交换最少 O(n)，不稳定」**。同为交换类排序，快排用「基准分区 + 分治」把平均复杂度降到 O(n log n)，选型上 O(n²) 算法只适合教学与小数据，见 `1717-quicksort-overview` [边界]。常追问「生产为什么不用它」——答：不稳定 + 比较次数与输入无关、没有提前终止能力，被快排/堆排取代；再追问「双向优化的坑」——按主问答第 5 条答「先换 max 或交换后修正下标」。

## ⚠️ 原文纠错
1. 术语归一：[经验] 源为语音转写，「变径」「便利」均应为「遍历」，其余术语音译崩坏词统一为规范术语。
2. 口径矛盾：源扑克例子说「最大的牌放最左边」，与后文正式定义（最小放已排序区末尾）方向相反，实为降序/升序两种等价写法，本卡统一按升序表述。
3. 补充：源称优化后「复杂度减半」不准确——双向只把外层轮数减半，总比较次数仍是 n²/4 量级，复杂度量级不变。
