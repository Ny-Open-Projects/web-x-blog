# 1714 冒泡 vs 选择：实测对账与选型深挖

> 覆盖源 17-14 的对比延伸：同一随机序列下冒泡与选择的比较/交换/轮次实测对账、逆序数视角、鸡尾酒与梳排序的改进方向、教学排序在真实工程的位置。主卡已给冒泡主线，本附录做横向对账深挖。

## 思路与架构

```text
n=1000 随机序列 (seed=42) 实测账本
├─ 冒泡 (带剪枝)
│   ├─ cmp = 498015  (上界 499500, early exit 少跑 54 轮)
│   ├─ swap = 248090 ( = 逆序数, 期望 n(n-1)/4 )
│   └─ rounds = 945 / 999 上限
├─ 选择 (wave146 同法实测)
│   ├─ cmp = 499500  (固定 n(n-1)/2, 与输入无关)
│   ├─ swap = 993    (最多 n-1, 实测 993)
│   └─ 结论: 比较接近, 交换差 250 倍
└─ 选型判据
    ├─ 写代价高 (Flash/EEPROM) -> 选择
    ├─ 要求稳定 / 数据近乎有序 -> 冒泡(剪枝) 或插入
    └─ 生产 -> sort.Slice (pdqsort), 教学排序不入产线
```

## 方案取舍
- **交换次数的量级差是两算法的本质分野**：冒泡每发现一对逆序就地交换，交换数=逆序数（随机期望 n(n-1)/4≈24.8 万）；选择每轮只记下标、轮末一次交换，交换数≤n-1。代价结构相反：冒泡「多写少想」，选择「多想少写」。**写昂贵读便宜**的介质（早期 Flash 有写入寿命）选选择；**写便宜但要稳定**的场景选冒泡 [实测]。
- **逆序数是统一的量尺**：冒泡的交换次数、相邻交换排序的移动代价，都精确等于逆序数对——这解释了「近乎有序的输入冒泡飞快」（逆序数趋近 0，剪枝后 O(n)）。同一把尺子还能解释插入排序的移动次数也=逆序数，三者构成「逆序数敏感族」；而选择的比较数恒定，对输入分布完全钝感 [经验]。
- **改进谱系一句话**：鸡尾酒排序（双向冒泡）救「大龟」元素——末尾的小值每轮只前移 1 位是冒泡的死角；梳排序把比较间距从 1 放大到逐步收缩，先远距粗排再近距精修；两者都在逆序数上做文章，但复杂度仍是 O(n²)/O(n²) 边缘，始终进不了生产 [经验]。
- **教学排序与生产的分界**：冒泡/选择的价值是**把「有序性」这个概念拆成可手推的原子动作**，以及面试中检验复杂度分析的基本功；生产用 `sort.Slice`/`slices.Sort`（pdqsort：快排 + 堆排 + 插入的混合，退化有保底）。答题时主动划这条线，展示「懂算法史也懂工程」[经验]。

## 答题技巧
- 报实测对账而非背符号：「同为 n=1000 随机序列，比较 49.8 万 vs 49.95 万几乎打平，交换 24.8 万 vs 993 差 250 倍」——数字一出口，选型结论自动成立 [实测]。
- 用「逆序数=交换数」一把钥匙开两把锁：解释随机序列的交换期望、近乎有序时剪枝生效、与插入排序同族——三个追问一次覆盖 [经验]。
- 被问「生产用哪个」→ 直说 pdqsort（`sort.Slice` 底层），把教学题收束到工程观 [经验]。
- 主动边界到 `1715-selection-sort`（选择排序主线与双向选择）、`1717-quicksort-overview`（生产级分治排序）、`1717-partition`（partition 细节），构成「排序算法谱系」专题 [边界]。
