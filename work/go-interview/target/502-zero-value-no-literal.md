> 原文锚点：第 28~31 段「切片和映射的零值都是利偶…所以切片和映射的零值是不能用组合自变量形式表示…指针通道接口类型的值没有字变量表示形式」

## 一句话总述
组合字面量的关键边界在于**零值**：切片和映射的零值是 `nil`，而组合字面量（如 `[]T{}`、`map[K]V{}`）产生的是**非 nil 的空容器**，二者语义不同；而**指针、通道、接口**三类根本**没有字面量形式**，必须靠 `new`/`make`/赋具体实现来构造。

## 面试官视角
这道题的"坑"就在零值与组合字面量的关系——很多候选人以为 `[]int{}` 是 nil，或以为 `map` 能写出 nil 字面量。能讲清这点即过关。

## 主问答
**Q（面试官原话）：** 为什么说切片和映射的零值不能用组合字面量表示？指针、通道、接口呢？

**A：**

1. **切片/映射零值是 nil，组合字面量给非 nil 空**：`var s []int` 得到 `nil` 切片（`len0、cap0、ptr=nil`），而 `s := []int{}` 得到**非 nil** 的空切片（底层数组存在）。同理 `var m map[K]V` 是 nil 映射（写入 panic），`m := map[K]V{}` 是非 nil 空映射（可写）。所以"零值(nil)"无法用组合字面量表出——组合字面量必然构造出一个具体容器。
2. **指针没有字面量**：不能用字面量写出某个地址的值，只能 `new(T)`（返回 `*T` 指向零值）或取变量地址 `&x`。
3. **通道没有字面量**：必须 `make(chan T, n)` 创建；`var c chan T` 只是 nil 通道（收发永久阻塞）。
4. **接口没有字面量**：接口是"方法集契约"，不能字面量构造，只能把具体类型值赋给接口变量（`var i I = impl{}`）。

## 版本与兼容性
- 该语义自 Go 1.0 稳定：`nil` 是预声明标识符，切片/映射/指针/通道/接口/函数的零值均为 `nil`。
- `new(T)` 与 `make` 自 Go 1.0 起行为一致；`make` 仅用于 slice/map/channel，不能用于指针/接口。

## 关键代码
```go
var s []int            // nil 切片
s2 := []int{}          // 非 nil 空切片
fmt.Println(s == nil, s2 == nil) // true false

var m map[string]int   // nil 映射
_ = m["k"]             // 读 OK，返回 0
// m["k"] = 1          // panic: assignment to entry in nil map
m2 := map[string]int{} // 非 nil 空映射，可写

var p *int = new(int)  // *int 指向 0
var c chan int         // nil 通道
var i interface{}      // nil 接口
```

## 总结与追问预判
- 口诀：**"组、数、切、映"里，切/映的零值是 nil 且字面量给非空；指/通/接连字面量都没有**。
- 预判追问：那结构体/数组的零值能用组合字面量吗？答：**能**——`Person{}`、`[3]int{}` 就是它们的零值（字段全零），只有切片/映射的 nil 零值无法用组合字面量表。
