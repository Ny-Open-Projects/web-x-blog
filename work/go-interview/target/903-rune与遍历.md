# 903 rune 与遍历：range 的索引是字节下标，不是字符下标

> 分类：Go 基础 / string | 难度：L3 | 题型：代码题 | 频率：高 | 关键词：**rune、码点、for range、字节下标、字符数**

> 原文锚点：第 37~49 段「Go 语言提供了一个 rune 类型，它用来表示一个 Unicode 码点，所以我们可以先将字符串转成 rune 切片，然后再计算这个切片的个数就可以得到这个字符串的 Unicode 码点的个数…如果我们需要按照字符去迭代一个字符串，同样也需要先把它转成 rune…我们直接这样迭代，得到的索引第一个是零，它的值是二零零一三，然后直接跳到了第三个索引，它的值是二五九九一…这两个值就是『中』和『文』这两个字的 Unicode 码点值…转成 rune 之后索引就变成了零和一」

## 一句话总述
`rune` 是 **Unicode 码点**的类型；直接 `range` 字符串时**索引是字节下标**（中文会跳格），而转成 `[]rune` 后遍历**索引才是字符下标**，两种方式取到的值都是码点值。

## 面试官视角
P6 会用 `len()` 当字符数；P7 要能说清 `range` 字符串的**双返回值语义**（i 是字节偏移、v 是 rune），并解释为什么中文字符串的索引会「跳到 3」，以及转 `[]rune` 与 `range` 两种取字符数方式的取舍。

## 主问答
**Q（面试官原话）：** 怎么按字符遍历一个中文字符串？为什么索引会跳？

1. **rune 的含义**：Go 提供 **rune 类型**，用来表示**一个 Unicode 码点** `[源码]`。
2. **取字符数的方法**：先把字符串**转成 rune 切片**，再计算切片个数，即得 **Unicode 码点个数（字符数）** `[源码]`。
3. **按字符迭代**：若要按字符迭代，同样**需要先转成 rune** `[源码]`。
4. **直接 range 的现象**：直接迭代时，第一个索引是 **0**、值为 **20013**，下一个索引**直接跳到 3**、值为 **25991** `[源码]`。
5. **跳格的原因**：索引是**字节下标**，一个中文占 3 字节，所以下一个字符从下标 3 开始 `[经验]`。
6. **值是什么**：这两个值正是「中」「文」两个字的 **Unicode 码点值** `[源码]`。
7. **转 rune 后的效果**：转成 rune 再遍历，**索引变成 0、1**（字符下标），**值仍是码点值** `[源码]`。
8. **显示原字符**：通过 `string(r)` 转换（或直接打印）即可显示原本字符 `[源码]`。

## 关键代码
```go
package main

import "fmt"

func main() {
	s := "中文"

	// 方式一：直接 range —— i 是字节下标（会跳格），v 是码点值
	for i, v := range s {
		fmt.Printf("byteIdx=%d codePoint=%d char=%c\n", i, v, v)
	}
	// byteIdx=0 codePoint=20013 char=中
	// byteIdx=3 codePoint=25991 char=文

	// 方式二：转 []rune —— 索引变字符下标，值仍是码点
	for i, v := range []rune(s) {
		fmt.Printf("runeIdx=%d codePoint=%d char=%c\n", i, v, v)
	}
	// runeIdx=0 codePoint=20013 char=中
	// runeIdx=1 codePoint=25991 char=文

	// 字符数
	fmt.Println(len([]rune(s))) // 2
}
```

## 总结与追问预判
**「range 的 i 是字节偏移」是本卡题眼**，中文字符串索引跳到 3 就是这个原因。若面试官追问「两种方式怎么选」——**只读遍历用 `range`（零分配），需要随机访问第 N 个字符才转 `[]rune`**。底层字节布局见同批 903-string-data-pointer。

## ⚠️ 原文纠错
1. 事实核校：rune 表示 Unicode 码点、转 []rune 取字符数、range 索引为字节下标且中文跳到 3、值为码点值（20013/25991）、转 rune 后索引为 0、1、string() 可还原字符——均与 Go 规范一致 `[经验]`。
2. 补充：「中」的码点为 U+4E2D（十进制 20013）、「文」为 U+6587（十进制 25991），与原文示例吻合；另外**直接 `range` 不分配内存**，转 `[]rune` 会分配切片，性能敏感场景应优先 `range` `[经验]`。
3. 崩坏词归一：源码将 rune、码点、索引、迭代等术语音译为多组崩坏词，本卡统一为规范术语 `[经验]`。
