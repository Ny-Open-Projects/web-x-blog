# 1025 Singleflight 的 Forget：重置合并项

> 分类：Go 并发 | 难度：中 | 题型：用法 | 频率：中 | 关键词：**Forget、重置、map 删除、重新执行、Group**

> 原文锚点：第 60~61 段「Forget 提供覆盖方法、删除 map 的 key、后续同 key 重新执行 fn」

## 一句话总述
Forget(key) 会立即从 Group 的 map 中删除该 key 对应的 call 项。效果：之后再来相同 key 的调用，map 中已无记录，会重新执行一次 fn，而不是复用上一次的结果。它用于「不希望结果被长期复用、允许同 key 再次回源」的场景。

## 面试官视角
Forget 是易被忽略的细节题。考官想确认你知道它的副作用：它不是「取消进行中的请求」，而是「删除已完成的合并记录，让下一波同 key 重新执行」。常与「缓存主动失效」搭配使用。

## 主问答
**Q（面试官原话）：** singleflight 的 Forget 是做什么的？

1. **行为**：`g.Forget(key)` 从内部 map 删除 `key` 对应的 call 记录。
2. **直接效果**：删除后，后续相同 key 的 Do 调用在 map 中查不到，于是再次执行 fn（重新回源）。
3. **不影响进行中请求**：若此刻正有同 key 请求在执行，Forget 不会中断它，只影响「之后的」调用。
4. **适用场景**：结果有时效、希望周期性重新回源（如缓存 TTL 很短），或主动失效后强制刷新。
