# 1709 判断两棵二叉树相等：递归三分支

> 分类：算法 / 二叉树 | 难度：L1~L2 | 题型：实现题 | 频率：中 | 关键词：**两树相等**/**结构+值**/**递归**/**双空判定**/**对称比较**

> 原文锚点：第 1~16 段「结构相同+对应位置值相同…双空 return true…一空一非空 false…值相等再递归左右…三例演示」

## 一句话总述
两棵二叉树相等 = **结构相同** 且 **对应位置节点值相同**，二者缺一不可。递归三分支：双空 → true；一空一非空 → false（结构异）；都非空 → 比当前值相等后，**同时递归左子树对左子树、右子树对右子树**。与「镜像/翻转」题的区别正在于左右不交叉、同位对同位。

## 面试官视角
- 意图：递归基本功题——看空树边界处理与「同位比较」意识，是 100/101（对称树/相同树）类题的入口。
- 分档：P5 写对递归三分支；P6 讲清两条件为何缺一不可并给出三组反例；P7 能对比迭代法（双栈/BFS 逐层配对）与复杂度。
- 红旗答案：只比叶子值不看结构；一空一非空时写成 true 或漏判。
- 惊艳点：一句话区分三兄弟——**相同树=同位对同位，对称树=同位对镜像位，子树判断=把相同树当子程序** [经验]。

## 主问答
**Q（面试官原话）：** 如何判断两棵二叉树是否相等？

**A：** 两条件：① 结构相同；② 对应位置上的值相同 [实测]：

1. **三分支递归**：`a==nil && b==nil` → true（都空，走到尽头对齐）；`a==nil || b==nil` → false（一空一非空，结构不同）；否则 `a.Val==b.Val && isSame(a.Left,b.Left) && isSame(a.Right,b.Right)`。
2. **源文三例**：两棵 `4-(2,6)` 全同 → true；一棵少右节点（结构异）→ false；结构同但 6 改 3（值异）→ false。
3. **复杂度**：时间 O(min(m,n))——结构不一致时提前短路；递归深度=树高 O(h)，退化链表 worst O(n) 栈深。
4. **对比记忆**：对称树把右参数换成 `b.Left/b.Right` 交叉即可；「t 是否含子树 s」= 沿 t 每个节点跑一次 isSame(t, s)。

## 关键代码
```go
package main

import "fmt"

type Node struct {
	Val         int
	Left, Right *Node
}

func isSame(a, b *Node) bool {
	if a == nil && b == nil {
		return true // 都空
	}
	if a == nil || b == nil {
		return false // 一空一非空：结构异
	}
	return a.Val == b.Val &&
		isSame(a.Left, b.Left) && // 同位对同位
		isSame(a.Right, b.Right)
}

func n(v int, l, r *Node) *Node { return &Node{Val: v, Left: l, Right: r} }

func main() {
	t1 := n(4, n(2, nil, nil), n(6, nil, nil))
	t2 := n(4, n(2, nil, nil), n(6, nil, nil))
	t3 := n(4, n(2, nil, nil), nil)            // 结构异
	t4 := n(4, n(2, nil, nil), n(3, nil, nil)) // 值异
	fmt.Println(isSame(t1, t2), isSame(t1, t3), isSame(t1, t4))
}
```

[实测] 输出：`true false false`——与源文三例（全同/少节点/改值）逐一对应。

## 总结与追问预判
核心：**三分支模板是肌肉记忆；答题必带「结构+值两条件」与三组反例**。追问接树族：二叉树基础与遍历见 178 / `178-tree-traversal`、Go 实现见 178、树形递归的另一道（子树最大和）见 1710 与「子树≠路径」辨析 `1710-subtree-vs-path.deep`；对称树/子树判断是本题的标准变式，答题时主动点破改法即可拿分。

## ⚠️ 原文纠错
1. 术语核校： [经验] 原文将 nil 音转为「new/为 o」、true 音转为「处/returntrue」、工程目录名音转为「betrayequo」，本卡统一为规范术语，不列举原词。
2. 事实核校： [经验] 原文「如果这两棵二叉树都是空树 return true」正确——双空对齐是递归 base case，漏写会空指针；「一个为空另一个非空 return false」即结构不同判定，两分支顺序不可颠倒。
