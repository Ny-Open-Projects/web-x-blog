# 178 二叉树遍历：深度优先（前/中/后序）与广度优先

> 分类：算法/树 | 难度：L3 | 题型：方案题 | 频率：高 | 关键词：**深度优先**/**前序**/**中序**/**后序**/**广度优先层序**/**中间节点顺序**
> 原文锚点：第 29~42 段「深度优先三序(前中后=中间节点顺序) + 广度优先(上到下左到右层序) + 前中后序输出示例」

## 一句话总述
二叉树遍历两类：**深度优先**——前序（中→左→右）、中序（左→中→右）、后序（左→右→中），「前中后」指**中间节点的访问顺序**；**广度优先（层序）**——从上到下、从左到右逐层访问。前/中/后序是面试手写高频。

## 面试官视角
- 考察意图：能否默写三种 DFS 递归写法，并说清「前中后」到底指谁的顺序。
- 分档：P5 知有前中后序；P6 能写三种递归；P7 知中序对 BST 出升序、层序用队列迭代。
- 红旗答案：把「前中后」当成整棵树遍历先后而非中间节点位置；中序写成「中左右」。
- 惊艳点：点出「前中后唯一区别是中间节点何时访问、中序遍历 BST 恰为升序」 [经验]。

## 主问答
**Q（面试官原话）：** 二叉树有哪几种遍历？怎么写？
**A：**
1. **深度优先三序**：前序（中→左→右）、中序（左→中→右）、后序（左→右→中）——「前中后」指**中间节点**访问顺序 [经验]。
2. **广度优先（层序）**：从上到下、从左到右逐层访问，通常用队列迭代实现 [经验]。
3. **记忆口诀 + BST 性质**：中间节点位置决定序名；中序遍历二叉搜索树恰好得到升序序列 [经验]。

## ⚠️ 原文纠错
1. 事实核校： [经验] 前中后指中间节点顺序、层序上到下左到右、中序 BST 升序——均正确。
2. 崩坏词归一：源码将若干术语音译为崩坏词，本卡统一为规范术语（深度优先、前序、中序、后序、广度优先、层序等）。

```go
// 三种深度优先遍历（递归），仅中间节点访问时机不同
func preorder(n *TreeNode, out *[]int) { // 中→左→右
    if n == nil { return }
    *out = append(*out, n.Val); preorder(n.Left, out); preorder(n.Right, out)
}
func inorder(n *TreeNode, out *[]int) { // 左→中→右（BST 恰为升序）
    if n == nil { return }
    inorder(n.Left, out); *out = append(*out, n.Val); inorder(n.Right, out)
}
func postorder(n *TreeNode, out *[]int) { // 左→右→中
    if n == nil { return }
    postorder(n.Left, out); postorder(n.Right, out); *out = append(*out, n.Val)
}
// 广度优先（层序）：队列迭代，逐层入队出队
func levelorder(root *TreeNode) []int {
    if root == nil { return nil }
    q, out := []*TreeNode{root}, []int{}
    for len(q) > 0 {
        n := q[0]; q = q[1:]
        out = append(out, n.Val)
        if n.Left != nil { q = append(q, n.Left) }
        if n.Right != nil { q = append(q, n.Right) }
    }
    return out
}
```
