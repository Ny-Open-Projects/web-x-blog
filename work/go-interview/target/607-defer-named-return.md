# 607 命名返回值被 defer 改写

> 分类：错误处理 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**命名返回值** / **闭包捕获** / **传参估值**
> 原文锚点：第 2~13 段「defer 闭包 r=r+x，return s+s 最终返回六」

## 一句话总述
命名返回值变量在函数栈帧里存在；defer 闭包改写它，会覆盖 return 表达式的结果，最终返回被改后的值。

## 面试官视角
- 意图：是否分清"return 表达式求值"与"defer 改写命名返回值"两步。
- 分档：P5 知能改 / P6 说清两步顺序 / P7 知传值参数不会回写。
- 红旗：以为 defer 改的是临时副本；以为参数也被改。
- 惊艳点：return s+s 得 4，defer r=r+x 得 6，传 r 作参数反得 2 `[源码]` 语言规范。

## 主问答
**Q（面试官原话）：** 下面这段 defer 改了返回值，最后返回几？
**A：**
1. **结论**：return 表达式先写命名返回值，defer 闭包随后改写，最终返回改写后的值。
2. **机制**：return s+s 把 r 置 4 入寄存器，defer 执行 r=r+x 变 6；若把 r 当值参数传入，参数在 defer 声明时定格为 0，defer 算 0+x 把 r 覆盖成 2。
3. **边界**：只有命名返回值（或闭包捕获的变量）能被改；值参数在 defer 推栈时已拷贝，不会回写。
**加分层：** 想让 defer 生效就用命名返回值或闭包捕获，别用值参数绕弯。

## 关键代码
```go
// 示意，未验证：值参数在 defer 声明时定格，不会回写
func f(s int) (r int) {
    defer func(x int) { r = x + s }(r) // r 此时为 0，结果 r=0+2=2
    return s + s                       // 先写 r=4，再被 defer 覆盖成 2
}
```

## 总结与追问预判
- 命名返回值可被 defer 改写；值参数在 defer 时定格不回写。
