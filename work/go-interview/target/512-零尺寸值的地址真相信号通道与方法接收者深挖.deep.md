# 512 零尺寸值的地址真相、信号通道与方法接收者 深挖

> 覆盖源 5-12 全文：零尺寸值的地址相等性实测（规范不保证）、接口装箱后的比较语义、`chan struct{}` 信号模式、空结构体作方法接收者、与对齐特例/空 select 的边界。主卡已给 Set 两种实现与实测，本附录做零尺寸语义四层深挖。

## 思路与架构

```text
零尺寸值 (struct{} / [0]T) 的四个舞台
├─ 1. map 的 value: Set 惯用法 (主卡)
├─ 2. chan 的元素: 纯信号通知 (close 广播/一次唤醒)
├─ 3. 方法接收者: stateless 对象零成本挂方法
└─ 4. 占位字段: 阻止/影响内存布局 (配合 _ 占位)
地址真相 (go1.26.5 实测):
├─ 规范: 零尺寸变量地址 may or may not 相同, 不保证
├─ 实测: 栈变量不同 / new(empty) 不同 / [0]byte 不同
├─ 接口装箱后 i==j: true (值比较, 与地址无关)
└─ 结论: 永不写依赖地址相等性的代码
```

## 方案取舍
- **地址相等性实测澄清（本卡核心增量）**：坊间流传「所有空结构体共享 zerobase 同一地址」，实测 go1.26.5 的结果更 nuanced——**栈上两个局部变量 `&a == &b` 为 false；`new(empty)` 两次分配地址不同；`[0]byte` 数组也不同**；真正恒真的是**接口装箱后的值比较**（`var i, j interface{} = empty{}, empty{}; i == j` 为 true，因为接口比较比的是动态类型+值，零尺寸值无内容可比）。规范原文只说 zero-size variable **may or may not** 有相同地址——**它是个「允许优化」不是「保证」**，编译器版本一换结论就可能翻转。工程铁律：**比较空结构体用 `==`（值语义），绝不比较地址** [实测]。
- **`chan struct{}` 是信号通道的惯用形态**：需要一个「事件发生」的载体时，`chan struct{}` 比 `chan bool`/`chan int` 更准确——信号只有「发生/没发生」，无载荷。典型三板斧：① **一次性完成信号**（`done := make(chan struct{})`，`close(done)` 广播给所有等待者，接收方 `<-done` 解除阻塞）；② **优雅退出**（协程监听 done，配合 select）；③ **容量为 1 的 semaphore**（`make(chan struct{}, N)` 拿放令牌限流，见 606 [边界]）。close 广播之所以优雅：向已关闭通道接收立即返回零值，**一个 close 唤醒全部等待者**，无需逐个通知 [经验]。
- **空结构体作方法接收者**：无状态的工具对象用 `type Empty struct{}` 挂方法，实例零内存——但 Go 更地道的做法是**直接函数或空具名类型**；空接收者的真实价值在「实现接口的类型必须是有类型的东西」时（如 `var _ Interface = Empty{}` 编译期断言）与**占位语义**。与 `type Empty int` 等价，选 struct{} 表达「确实无状态」 [经验]。
- **对齐特例是零尺寸的边界坑**：零尺寸值作结构体字段一般不占空间，但**作末位字段时会触发对齐**——否则取其地址会得到结构体之外的悬空地址（被长期持有可致内存泄漏）。这提醒我们「零尺寸绝对零成本」的口吻要收敛：**绝大多数场景零成本，取地址场景有例外**，详见 910 [边界]。
- **Set 封装的泛型时代选型**：`type Set[T comparable] map[T]struct{}` 解决了 interface{} 版的两痛（类型不安全、装箱开销）；再往上还有三方权衡——**map Set**（通用）、**bit 位图**（小整数域，内存省一个数量级）、**第三方 generics set 库**（带并集/交集运算）。选型依据是元素域与运算需求，不只是内存 [经验]。

## 答题技巧
- 报实测数字：sizeof=0、value 0 vs 1 字节、地址相等性「规范不保证 + 实测多路径不同」——三个数字三重可信 [实测]。
- 「类型即文档」这句话要讲：struct{} 宣告值域为空，编译器兜底——比省内存更本质 [经验]。
- 被问「chan struct{} 怎么用」→ close 广播 + semaphore 两个模式，配 done channel 惯例 [经验]。
- 被问「地址一定相等吗」→ 直接答「规范不保证，我实测过栈变量/new 都不同，接口装箱比较才是恒真」——纠正流传误区，P7 惊艳点 [实测]。
- 主动边界到 `910-empty-struct-alignment`（末位对齐特例）、`1238-range-empty-lock`（range 信号通道）、`918-nil-vs-empty-map`（map 零值语义）、`510-struct-not-comparable`（不可比较类型的另一极端），构成结构体语义专题 [边界]。

## 细节与核心 API

```go
type Z struct{}
z1, z2 := Z{}, Z{}
// 所有零尺寸变量的地址都指向同一块 runtime.zerobase（地址相同但不可写）
fmt.Printf("%p %p\n", &z1, &z2) // 相同
// 信号通道：chan 用作“事件通知”而非传值
done := make(chan struct{})
go func() { /* 干活 */ close(done) }()
<-done // 只收信号，struct{} 零内存
// 方法接收者：小值用值接收者（T）避免逃逸；需修改或大对象用指针（*T）
func (z Z) Read()  {}  // 值接收者，拷贝零尺寸无成本
func (m *MyBig) Mutate() {}
```
