# 1717 快速排序的工程优化与非递归实现

> 分类：排序算法 | 难度：高 | 题型：优化/工程 | 频率：中 | 关键词：**随机基准、三数取中、小数组插排、三向切分、尾递归、显式栈**

> 原文锚点：第 90~105 段「切分优化、三种改进与栈模拟非递归」

## 一句话总述
快排性能高度依赖切分均匀度，工程上用「随机基准 / 三数取中」避免退化到 O(n²)，用「小数组切插入排序 / 三向切分（重复多）/ 尾递归」降常数与栈深；还可用显式栈把递归改写成非递归，Go 标准库 sort 即综合了这些优化。

## 面试官视角
这是 P7 加分题。能说出「为什么随机化能期望 O(n log n)」「三向切分解决什么」「非递归的意义」的人，说明真正写过生产级排序，而非只会背模板。

## 主问答
**Q（面试官原话）：** 快排有哪些优化？怎么避免最差 O(n²)？非递归怎么写？

1. **避免退化**：每次随机选基准（先 shuffle 或随机取一个），让「每次取极值」的概率趋零，期望回到 O(n log n)；或用三数取中（首/中/尾取中位数）作基准，代价是额外比较。
2. **小数组切插入排序**：递归到很小规模时切换插入排序，减少递归开销与函数调用。
3. **三向切分**：数组重复值多时分成「< / = / >」三段，等于基准的一段不再递归，避免重复元素拖慢。
4. **尾递归**：把一侧递归改成循环，把栈空间从 O(n) 压到 O(log n)，防大数据栈溢出。
5. **非递归**：用显式栈替代调用栈，把 (low,high) 压栈、循环弹栈处理，栈空间变为 O(n) 但可控、不依赖系统栈深度。

## 关键代码
```go
// 随机基准：交换首元素与随机位置后再 partition
import "math/rand"
func quickSortOpt(a []int, low, high int) {
    if low >= high { return }
    k := low + rand.Intn(high-low+1)
    a[low], a[k] = a[k], a[low]
    p := partition(a, low, high)
    quickSortOpt(a, low, p-1)
    quickSortOpt(a, p+1, high)
}
```
