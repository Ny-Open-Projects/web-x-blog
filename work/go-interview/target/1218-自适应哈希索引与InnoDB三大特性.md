# 1218 自适应哈希索引与 InnoDB 三大特性

> 分类：MySQL 索引 | 难度：中 | 题型：原理 | 频率：中 | 关键词：**自适应哈希索引、AHI、Buffer Pool、双写缓冲、InnoDB 特性**

> 原文锚点：第 74~93 段「哈希索引特点、自适应哈希、InnoDB 三大特性、开关与分区」

## 一句话总述
除 B+ 树外，MySQL 也支持哈希索引，但 MyISAM/InnoDB 默认不用、仅 Memory/NDB 支持。InnoDB 有「自适应哈希索引（AHI）」：当引擎统计发现某等值查询符合哈希特征，就自动为该列建哈希索引加速，只存内存、仅宜等值、可按开关控制与分区。InnoDB 三大特性为 AHI、Buffer Pool、双写缓冲。

## 面试官视角
这是 B+ 树题的「拓展收尾」。考官若往深问，看你能不能补：哈希索引不支持范围/排序、不支持部分列匹配；AHI 是 InnoDB 自动建的、只在内存、适合等值；并能报出三大特性（AHI / Buffer Pool / 双写缓冲）。提到「AHI 默认开、8 个分区、最多 512」是细节加分。

## 主问答
**Q（面试官原话）：** InnoDB 的自适应哈希索引是什么？三大特性有哪些？

1. **哈希索引局限**：基于哈希表，只适合等值（= / IN），不支持范围、排序、部分列匹配；冲突多时要遍历链表。
2. **AHI 机制**：InnoDB 发现某列等值查询频繁且符合哈希特征，自动建哈希索引；底层是哈希表，只存在于内存（Buffer Pool），无需人工干预。
3. **AHI 适用与开关**：只适合等值查询，范围查用不上；由 `innodb_adaptive_hash_index` 控制，默认开；默认 8 分区，最多 512 分区。
4. **三大特性**：自适应哈希索引、Buffer Pool（缓冲池）、双写缓冲（doublewrite buffer）。

## 总结与追问预判
核心：**哈希仅等值；AHI 是 InnoDB 自动在内存建的等值加速索引；三大特性 = AHI + Buffer Pool + 双写缓冲**。追问可回「为什么主索引仍是 B+ 树」（见 1218）。
