# 1713 字符串反转的两种实现：临时变量与异或

> 分类：数据结构 / 算法 | 难度：L2 | 题型：实现题 | 频率：中 | 关键词：**字符串反转**/**双指针**/**临时变量交换**/**异或交换**/**UTF-8 坑**

> 原文锚点：第 2~12 段「转字符数组 + 双指针 → 临时变量法 → 异或法」

## 一句话总述
字符串反转的标准骨架：**转字符数组 → 双指针从两端向中间交换 → 相遇即止**，一次遍历 O(n)。交换实现两法：**临时变量法**（直白，Go 的 `a, b = b, a` 即此类）与**异或法**（`a^=b; b^=a; a^=b` 三步无临时变量，利用 a^a=0、a^0=a 与结合律）。[实测] 两法对 `helloworld` 均得 `dlrowolleh`。

## 面试官视角
反转字符串人人会写，考官用三处细节定档：① 双指针循环条件（`i < j` 还是 `i <= j`）；② 异或法的**推导**能否讲清（不是背三行）；③ **主动报坑**——`[]byte` 转换会**撕碎 UTF-8**，中文必须走 `[]rune`。前两处考基本功，第三处直接检验你是不是只做过英文题。

## 主问答
**Q（面试官原话）：** 至少使用 2 种方式实现字符串的反转？

1. **共同骨架**：字符串转字符数组；`i=0`、`j=末位`，循环交换 `s[i]` 与 `s[j]`，同时 i 增 j 减，**i 与 j 相遇即完成**——一次遍历 O(n)，原地完成 O(1) 额外空间。
2. **法一：临时变量交换**：`tmp := r[i]; r[i] = r[j]; r[j] = tmp`。Go 里 `r[i], r[j] = r[j], r[i]` 原生多赋值一行搞定，语义就是临时变量。[实测] `helloworld` → `dlrowolleh`。
3. **法二：异或交换**：`a^=b; b^=a; a^=b` 三步完成。推导链：令 c=a^b——第一步后 a=c；第二步 `b=c^b=a^(b^b)=a^0=a`；第三步 `a=c^a=b^(a^a)=b`。依赖三条性质：**a^a=0、a^0=a、异或满足交换结合律**。
4. **[实测] 对照**：两法对 `helloworld` 均输出 `dlrowolleh`；异或法的字节级实现对中文 `"你好"` 输出 **"\xbd\xa5堽\xe4"**——UTF-8 多字节序列被反转撕碎，产生乱码；**rune 级临时变量法输出 `好你` 正确**。
5. **选型结论**：工程上一律临时变量法（可读性、rune 友好）；异或法的价值在「不借助第三变量」的思维训练与 C 时代的省寄存器遗产——Go 编译器下无性能优势，面试讲清推导即可，别带入生产。

## 关键代码
```go
// 法一: 临时变量交换 (rune 级, UTF-8 安全) —— 工程首选
func reverseTemp(s string) string {
	r := []rune(s)
	for i, j := 0, len(r)-1; i < j; i, j = i+1, j-1 {
		r[i], r[j] = r[j], r[i]
	}
	return string(r)
}

// 法二: 异或交换 (byte 级, 仅 ASCII)
func reverseXor(s string) string {
	b := []byte(s)
	for i, j := 0, len(b)-1; i < j; i, j = i+1, j-1 {
		b[i] ^= b[j]
		b[j] ^= b[i]
		b[i] ^= b[j]
	}
	return string(b)
}
```

[实测] 两法对 `helloworld` 输出 `dlrowolleh`；异或法对 `你好` 输出乱码，rune 法输出 `好你`。

## 总结与追问预判
核心：**双指针骨架 + 临时变量/异或两法；中文必须 []rune，[]byte 异或会撕碎 UTF-8**。追问常拐向「其他反转方式」——栈法与递归法见 `175-reverse-stack-queue.md`/`175-reverse-stack-recursive.md`/`175-reverse-stack.deep.md`，rune 与字节遍历的本质见 `903-rune-iteration.md`/`903-len-is-bytes.md`，异或法的同址雷与选型深挖见 `1713-reverse-utf8-xor-traps.deep.md`。

## ⚠️ 原文纠错
1. 事实核校： [经验] 原文推导中「a 一或 b」=a XOR b 的音转、开头「自符数组」=字符数组，已归一；推导本身正确，但源文例句写「比如这里 a 一或 b 呢，它和 b 一或 a 的值是相等的」——交换律成立没错，后文实际用的是**结合律**（c^b^b 分组），两律角色要分清。
2. 事实核校： [实测] 原文示例 `helloword` 为英文可正常反转，但**未提示 UTF-8 多字符坑**——按原文写法处理中文会输出乱码（[实测] "\xbd\xa5堽\xe4"），面试主动补此坑是关键加分项。
