# 1003 并发面试题项目案例与多方案 深挖

> 覆盖源 10-3 全文：五大考点 + 答题四技巧（费曼/自己的话/真实案例/多方案优劣）+ 程序员六级别。主卡已给方法论总览，本附录做"项目案例四要素 SOP"与"多方案优劣对比框架"。

## 思路与架构

```text
并发答题素材准备
├─ 项目案例四要素: 背景 → 发现 → 定位 → 解决 (务必可复述)
├─ 级别匹配: 初级/中级用经典案(原子性坑) / 高级用真实案例
└─ 多方案框架: 原语A vs 原语B vs 规避 — 各说优劣
```

## 方案取舍
- **案例真实优先**：务必是自己参与并解决过的，能清晰描述排查链路；编造案例一追问就露馅 [经验]。
- **级别对齐**：初级/中级可用课程经典并发问题（如原子性误用）；高级必须用自己的真实项目，体现系统设计/优化能力 [经验]。
- **多方案取舍**：同一并发问题常可用 mutex/channel/atomic/singleflight 多种原语，甚至靠设计规避；给出方案并讲清"为何这个最合适"比只给一种更分 [经验]。

## 答题技巧
- 被问"遇到过什么并发问题"先抛案例四要素（背景/发现/定位/解决），再补"若重来会用 X 方案更优" [经验]。
- 主动边界到 `101-concurrency-must-learn`(为何学并发)、`925`/`1011`/`913`/`609`(具体原语)，构成"方法+技术"全栈 [边界]。
