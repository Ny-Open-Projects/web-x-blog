# 811 CPU 存储金字塔：寄存器与三级缓存

> 分类：内存与 GC | 难度：L2 | 题型：八股题 | 频率：中 | 关键词：**寄存器** / **L1-L3 缓存** / **速度与容量权衡**
> 原文锚点：第 6~28 段「寄存器非常快速…CPU 缓存通常分三级…速度递增容量递减」

## 一句话总述
存储层级从寄存器→L1→L2→L3→内存→磁盘，速度递减、容量递增；缓存用空间换时间，弥补 CPU 与内存的速度差。

## 面试官视角
- 意图：是否理解硬件层级如何影响程序性能，而非只会写业务代码。
- P5 知有三级缓存 / P6 说清层级速度与容量反比 + 缓存命中意义 / P7 知 false sharing、缓存行对齐。
- 红旗：以为缓存越大越好无代价；把寄存器当普通内存乱用。
- 惊艳点：L1 与寄存器速度接近，L1 一般几十 KB —— 验证 `lscpu` L1d/L1i 行缓存 `[经验]`。

## 主问答
**Q（面试官原话）：** 讲讲 CPU 缓存层级，为什么需要它？
**A：**
1. **结论**：层级速度递减、容量递增；缓存用高速 SRAM 暂存热数据，减少访问内存的延迟 `[源码]`。
2. **机制**：L1 在核内最快最小（几十 KB），L2/L3 逐级变大变慢；L3 多核共享，未命中再读主存。
3. **边界**：缓存非免费——容量、功耗、一致性都需成本；纯流式数据缓存收益有限。
**加分层：** 多核下 false sharing 会拖垮并发，需按缓存行（通常 64B）对齐。
