# 709 注册定时任务的两种方式

> 分类：工程实践 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**AddFunc** / **AddJob** / **Job 接口**
> 原文锚点：第 9~34 段「注册两种方式：AddFunc 与 AddJob」「Start/Entries/Remove/Stop 生命周期」

## 一句话总述
`cron.New()` 建调度器后，用 `AddFunc(spec, func())` 或 `AddJob(spec, Job)` 注册；`Job` 需实现 `Run()`；`Start()` 启动、`Entries()`/`Entry(id)` 查状态、`Remove(id)`/`Stop()` 管理；二者都返回 `(EntryID, error)`。

## 面试官视角
- 意图：是否用过库、分清 Func 与 Job 两种注册、理解生命周期 API。
- P5 会调 AddFunc / P6 说清 Job 接口与 Run / P7 知 NewChain(Recover) 与常驻主协程。
- 红旗：以为 AddJob 第二参是 func；忘了 Start 任务不跑。
- 惊艳点：AddJob 的 Job 是接口（仅需 `Run()`），可挂 recover/日志链 —— 验证 `cron.Job` 接口 `[源码]`。

## 主问答
**Q（面试官原话）：** 用 robfig/cron 怎么注册一个定时任务？
**A：**
1. **结论**：`AddFunc(spec string, cmd func())` 直接传闭包；`AddJob(spec string, cmd Job)` 传实现了 `Run()` 的 Job 结构体，二者都返回 `(EntryID, error)` `[源码]`。
2. **机制**：`cron.New(opts...)` 建调度器（可传 `WithSeconds()`/`WithLocation()`）；注册后必须 `Start()`，调度在独立 goroutine 跑。
3. **边界**：未 `Start()` 任务不执行；想查下次/上次执行用 `Entries()` 或 `Entry(id)`；`Remove(id)` 删计划、`Stop()` 终止。
**加分层：** 主协程必须常驻（如 `select{}` 或 `signal.Notify`），否则进程退出任务停。
