# 411 Go 格式化动词：字符串、浮点与字节数组

> 分类：Go 标准库 | 难度：中 | 题型：语法细节 | 频率：高 | 关键词：**UTF-8 下标、%f、%e、%g、五舍、byte 数组**

> 原文锚点：第 33~91 段「字符串/中文/浮点/字节数组的格式化输出」

## 一句话总述
Go 字符串按 UTF-8 字节存储，中文占 3 字节故 `s[0]`、`s[3]` 才分别是两个汉字；浮点 `%f` 默认 6 位小数四舍五入、`%.2f` 控精度、`%e`/`%E` 科学计数、`%g`/`%G` 自动选最短；浮点保留小数时遇结尾恰为 5 可能「五舍」而非五入；`byte` 即 `uint8`，字节数组可用 `%s`/`%x` 等直接输出。

## 面试官视角
字符串下标和浮点精度是高频挖坑点。考官想听你讲清「为什么中文下标跳 3」以及「0.125 为何舍成 0.12」。这两点能答上就是细节控。

## 主问答
**Q（面试官原话）：** 字符串下标怎么算？浮点 %f 和 %g 有什么区别？

1. **字符串按字节**：Go 字符串是 UTF-8 字节序列，`s[0]` 取首字节；中文占 3 字节，故第一个汉字下标 0、第二个下标 3（0/1/2 属首字，3/4/5 属次字）。
2. **浮点小数**：`%f` 十进制、默认保留 6 位小数（第 7 位四舍五入）；`%.2f` 保留 2 位；`%e`/`%E` 科学计数法（小/大写 E）；`%g`/`%G` 自动选 `%f` 或 `%e` 中更简洁者。
3. **精度细节（坑）**：浮点保留小数时，小数部分结尾恰好为 5 往往「五舍」而非「五入」（如 `0.125`→`0.12`），这是浮点表示与舍入实现的真实行为，不能想当然当四舍五入。
4. **字节数组**：`byte` 即 `uint8`，二者等价；`[]byte`/`[]rune` 可用 `%c` 逐字符、`%s` 直接出串、`%x`/`%X` 十六进制。

| 动词 | 输出 |
|------|------|
| %s/%q | 字符串/带双引号 |
| %f/%e/%g | 浮点十进制/科学/自动 |

## 关键代码
```go
s := "中a"
fmt.Println(s[0], s[3])  // 中(3字节)→0，a→3
fmt.Printf("%.2f\n", 0.125) // 0.12（五舍）
```

## 总结与追问预判
核心：**字符串按字节、中文跳 3；浮点默认 6 位、结尾 5 易五舍；%g 自动最短**。追问常接 `%v` 三兄弟（见 411-v-verbs）或 FMT 三函数（见 411-pointer-fmt-funcs）。
