# 708 Gin 模板语法要点

> 分类：网络与 IO | 难度：L2 | 题型：工程题 | 频率：中 | 关键词：**define/template** / **点号上下文** / **range 遍历**
> 原文锚点：第 72~110 段

## 一句话总述
Gin 用 Go 原生 `html/template`：`{{define "名"}}…{{end}}` 定义、`{{template "名"}}` 引用、`{{.}}` 是当前上下文、变量必须带点号。

## 面试官视角
- 意图：是否写过 Gin 模板、知不知道点号(.)是变量引用的关键。
- P5 会写 define/range / P6 说清点号与上下文 / P7 知子模板传变量要显式 `.`。
- 红旗：说变量不用点号也能引用；以为 template 后跟的是路径。
- 惊艳点：去掉点号模板直接报错——变量必须 `.` 或键路径引用 —— 验证 `html/template` 解析规则。

## 主问答
**Q（面试官原话）：** Gin 模板里怎么定义、引用模板，怎么遍历 map 和 slice？
**A：**
1. **结论**：`define` 定义具名模板，`template` 引用（引号里是名字非路径）。
2. **机制**：`{{.}}` 是当前上下文；`range` 遍历 map/slice，都要用点号引用。
3. **边界**：变量须经 `.` 或键路径引用，去掉点号解析直接报错。
**加分层：** 取数靠 `c.HTML(200,"t.html", gin.H{"title":..,"dataM":map})`。
