# 412 打印字面百分号与 % 转义陷阱

> 分类：数据结构/格式化 | 难度：L1 | 题型：八股题 | 频率：低 | 关键词：**%% 转义** / **% 是动词** / **格式串陷阱**
> 原文锚点：第 61~68 段「输出一个保留两位小数的百分数…百分号是特殊符号，需要用两个百分号转义」

## 一句话总述
`%` 在格式串里是「动词起始符」，要输出字面 `%` 必须写成 `%%`；漏写会导致后续动词错位、缺参报 `%!(MISSING)`。

## 面试官视角
- **意图**：是否知道格式串的 `%` 需转义，以及排错时能定位 `MISSING`。
- **P5** 知 `%%` 输出一个 `%` / **P6** 能解释 `%(MISSING)` 是未转义 `%` 被当动词 / **P7** 知 `%w` 用于 error 包装等动词语义。
- **红旗**：用字符串拼接绕开格式化；以为 `%%` 是「转义百分号 + 多打一个」。
- **惊艳点**：`fmt.Printf("%.2f%%", 99.99)` 得 `99.99%`——验证：实测 go1.26.5 `[实测]`。

## 主问答
**Q（面试官原话）：** 我想打印「99.99%」怎么写？
**A：**
1. **结论**：格式串里每个字面 `%` 都要写成 `%%`，即 `fmt.Printf("%.2f%%", 99.99)`。
2. **机制**：fmt 解析到 `%` 后期待动词（`f`/`v`/`d`…），单个 `%` 后无合法动词就被当成缺参动词报错 `[源码]`。
3. **边界**：仅在格式串中需转义；用 `strings.Builder` 拼接等非 fmt 路径不受影响。
**加分层：** 错把未转义的 `%` 当「数值四舍五入成 100」是误判——`%.2f` 的 99.99 仍是 99.99，多出的是格式错位而非浮点误差。

## 关键代码
```go
// 示意，未验证：字面百分号必须转义
fmt.Printf("%.2f%%\n", 99.99) // 99.99%
fmt.Printf("%.2f%\n", 99.99)  // 99.99%!(MISSING) 误把末尾%当动词
```

## 总结与追问预判
- 格式串里 `%` 是动词起始符，字面 `%` 写 `%%`。
- 预判：三大动词总览 → 见 412-fmt-verbs；标准输入方式 → 见 412-fmt-stdin。

## ⚠️ 原文纠错
原文第 61~68 段把「99.99 输出了 100%」归因于「浮点数精度四舍五入」。实测（go1.26.5）`%.2f` 对 99.99 仍输出 99.99；异常结果来自未转义的 `%` 被当作动词导致格式串错位、报 `%!(MISSING)`，并非浮点误差。正确结论：打印字面 `%` 须用 `%%`，`%.2f` 不会把 99.99 舍入成 100。
