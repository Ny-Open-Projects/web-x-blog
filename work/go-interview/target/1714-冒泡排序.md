# 1714 冒泡排序：逐轮过程与提前退出

> 分类：数据结构 / 算法 | 难度：L2 | 题型：实现题 | 频率：高 | 关键词：**冒泡排序**/**相邻交换**/**轮次收敛**/**提前退出**/**稳定排序**

> 原文锚点：第 3~14 段「53821 序列逐轮推演 → 双层循环与 swapped 剪枝」

## 一句话总述
冒泡排序每轮**从左到右比较相邻两元素，逆序则交换**，一轮下来最大值像气泡一样「冒」到未排序区末尾；外层跑 n-1 轮即可有序，若某轮**一次交换都没发生**说明已完全有序，可立即退出。它是**稳定**的原地排序，平均/最坏 O(n²)，最好 O(n)（已序 + 剪枝）。

## 面试官视角
冒泡是「会用」门槛最低、但「讲透」最见功力的排序题。考官三个抓手：① 能否**逐轮手推**序列（5 3 8 2 1 四轮各变成什么）；② 是否知道**提前退出的条件与收益**（已序输入 O(n)）；③ 能否与选择排序对比出「**比较次数接近但交换次数天差地别**」——最后一点直接检验你是否真算过账而不是背复杂度。

## 主问答
**Q（面试官原话）：** 用 Go 实现冒泡排序？

1. **核心动作**：比较相邻 `a[j]` 与 `a[j+1]`，前者大就交换。每完成一轮，未排序区的最大值落到末尾。
2. **双层循环骨架**：外层 `i` 从 0 到 n-2 控制轮数（n-1 轮上限）；内层 `j` 只需扫到 `n-2-i`——末尾 i 个元素已被前几轮「冒」到位，无需再比。
3. **提前退出剪枝**：外层每轮设 `swapped` 标记，整轮无交换即全序，`break`。[实测] 教材序列 5 3 8 2 1 逐轮为 3 5 2 1 8 → 3 2 1 5 8 → 2 1 3 5 8 → 1 2 3 5 8，4 轮（n-1）收敛；而**已序输入只跑 1 轮、4 次比较、0 次交换**即退出。
4. **复杂度账本**：比较最多 n(n-1)/2；交换次数等于序列**逆序数**——[实测] n=1000 随机序列 cmp=498015、swap=248090，与理论期望 n(n-1)/4=249750 吻合（early exit 少跑了 54 轮，cmp 从上界 499500 降到 498015）。
5. **稳定性**：相等元素不交换（比较用 `>` 不用 `>=`），相对次序保持——冒泡是稳定排序，这是它与选择排序（不稳定）的关键差异之一。

## 关键代码
```go
// BubbleSort 相邻逆序交换；swapped 剪枝：整轮无交换即有序，提前退出
func BubbleSort(a []int) {
	n := len(a)
	for i := 0; i < n-1; i++ {
		swapped := false
		for j := 0; j < n-1-i; j++ { // 末尾 i 个已就位
			if a[j] > a[j+1] { // 用 > 不用 >=，保证稳定
				a[j], a[j+1] = a[j+1], a[j]
				swapped = true
			}
		}
		if !swapped {
			break
		}
	}
}
```

## 总结与追问预判
核心：**相邻逆序交换、每轮冒出最大值、swapped 剪枝；比较≈n(n-1)/2 上界、交换=逆序数；稳定**。追问常拐向「和选择排序比」——[实测] 同为 n=1000 随机：比较接近（498015 vs 499500）但交换差 250 倍（248090 vs 993），交换贵的环境选选择排序；手推过程与更多对账见 1714.md`，选择排序主线见 1715.md`，快排见 1717.md`。
