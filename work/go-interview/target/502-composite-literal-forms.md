# 502 四类聚合类型的组合字面量写法

> 分类：Go 语法/字面量 | 难度：L2 | 题型：八股题 | 频率：中 | 关键词：**组合字面量**/**结构体**/**数组**/**切片**/**映射**

> 原文锚点：第 14~27 段「组合自变量表示结构体数组切片映射的值…结构体两种带字段名和不带…数组可省略下标也可设下标…长度可用三点省略…切片直接声明四元素…映射给键值对」

## 一句话总述
组合字面量 `Type{...}` 对四类聚合类型写法各异：**结构体**可带字段名或按位置省略字段名、**数组**可省略下标或用 `...` 让编译器数长度、**切片**直接列元素得非 nil 空、**映射**用 `key: value` 对，掌握这些写法能写出更简洁的初始化代码。

## 面试官视角
写法是基本功，但面试官常借此延伸到"结构体零值 vs 组合字面量""数组长度推导""切片/映射非 nil 空"等易错点。

## 主问答
**Q（面试官原话）：** 结构体、数组、切片、映射的组合字面量分别怎么写？有什么省略写法？

**A：**

1. **结构体**：两种写法——带字段名 `Person{Name: "a", Age: 1}`（推荐，字段顺序随意、可缺省取零值）与按位置 `Person{"a", 1}`（必须按字段声明顺序、不可缺省）。
2. **数组**：可显式下标 `([4]int{1: 2, 3: 4})`，也可省略下标按顺序 `([3]int{1,2,3})`；长度用 `...` 推导 `([...]int{1,2,3})` 让编译器数元素个数（类型是具体长度数组，非切片）。
3. **切片**：`[]int{1, 2, 3}` 得到一个**非 nil、len=3** 的切片；`[]int{}` 是**非 nil、len=0** 的空切片（区别于 nil 切片）。
4. **映射**：`map[string]int{"k": 1}` 得到非 nil 空映射；`map[string]int{}` 是非 nil 空映射（区别于 nil 映射，后者不能写入）。

## 版本与兼容性
- `[...]T{...}` 长度推导自 Go 1.0 支持；结构体按位置字面量自 Go 1.0 支持。
- 映射字面量自 Go 1.0 支持；现代版本对字面量元素数无实质限制。

## 关键代码
```go
type Person struct{ Name string; Age int }

// 结构体：带字段名（推荐） vs 按位置
p1 := Person{Name: "a", Age: 1}
p2 := Person{"a", 1} // 顺序必须与字段声明一致

// 数组：显式下标 / 顺序 / 长度推导
a1 := [4]int{1: 2, 3: 4}
a2 := [3]int{1, 2, 3}
a3 := [...]int{1, 2, 3} // 类型 [3]int，不是切片

// 切片：非 nil
s1 := []int{1, 2, 3}
s2 := []int{} // 非 nil、len0

// 映射：非 nil
m1 := map[string]int{"k": 1}
m2 := map[string]int{} // 非 nil 空映射，可写入
```

## 总结与追问预判
- 口诀：**结构带名最稳、数组三点推导长度、切片映射字面量必非空**。
- 预判追问：`var m map[K]V` 与 `m := map[K]V{}` 区别？答：前者 nil 不可写（panic），后者非 nil 空可写；读都返回零值不 panic。
