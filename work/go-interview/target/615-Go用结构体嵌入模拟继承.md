# 615 Go 用结构体嵌入模拟"继承"

> 分类：Go 语言 / 面向对象 | 难度：L2 | 题型：概念题 | 频率：高 | 关键词：**结构体嵌入** / **方法提升** / **组合优于继承** / **字段提升**
> 原文锚点：第 4~11 段「go语言没有传统继承…通过结构体的内嵌实现类似继承…字段方法成为外层一部分」

## 一句话总述
Go 没有 extends 之类的关键字，也不支持传统 is-a 继承；它用**结构体嵌入（embedding）**把内层结构体的字段与方法"提升"为外层结构体的一部分，从而复用与扩展——这是 Go 式"组合优于继承"。

## 面试官视角
- 意图：是否清楚 Go 根本不支持继承，以及"嵌入 ≠ 继承"的语义差异。
- P5 知嵌入复用字段/方法；P6 说清方法提升与重写机制；P7 知嵌入是组合语义、非 is-a、可多层嵌套。
- 红旗：说"Go 支持继承"；以为嵌入就是 Java 的 extends。
- 惊艳点：嵌入是编译期字段/方法"提升"（promotion），外层可重写同名成员，本质是组合而非子类化 `[经验]`。

## 主问答
**Q（面试官原话）：** Go 没有继承，怎么实现类似继承的效果？
**A：**
1. **无继承关键字**：Go 不提供 extends/继承语法，复用靠结构体嵌入 `[源码]`。
2. **字段与方法提升**：把内层结构体类型嵌入外层，其字段与方法自动"提升"为外层可见成员（如 Teacher 嵌入 People/Person 后拥有其 Run/Eat）。
3. **可多层嵌入**：一个结构体可同时嵌入多个结构体，组合出更丰富的类型（Teacher 嵌 People+Person）。
4. **是组合非继承**：嵌入不产生 is-a 关系，外层可重写同名方法覆盖内层——复用靠组合而非层次。

## 关键代码
```go
// 示意，未验证：结构体嵌入——Teacher 嵌入 People/Person，方法被提升
package main
import "fmt"
type People struct{}
func (People) Run() { fmt.Println("people run") }
type Person struct{}
func (Person) Eat() { fmt.Println("person eat") }
type Teacher struct {
    People // 嵌入：字段与方法提升为 Teacher 的一部分
    Person
}
func main() {
    t := Teacher{}
    t.Run() // 提升自 People
    t.Eat() // 提升自 Person
}
```
