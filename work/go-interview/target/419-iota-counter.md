# 419 Go iota 常量计数器

> 分类：Go 数值类型 | 难度：L2 | 题型：概念题 | 频率：高 | 关键词：**iota**/**const 块**/**自增**/**位移枚举**
> 原文锚点：第 75~106 段「iota 计数器规则与位移声明」

## 一句话总述
`iota` 是 `const` 块里的**行计数器**：每个 `const` 出现时重置为 0，块内每新增一行常量自增 1；前面有显式常量也会占用行号，影响后续 iota 值。

## 面试官视角
- 考察意图：iota 的"按行自增"语义，以及"前面常量占位"的坑。
- 分档：P5 知 iota 从 0 自增；P6 知 const 重置；P7 知前导常量占行导致 iota 不从 0 起。
- 红旗答案：以为 iota 只在用它的那行从 0 开始，忽略前面行的占位。
- 惊艳点：点出"iota 是按行号，不是按使用次数"，并用 `1<<(10*iota)` 声明 KB/MB/GB。

## 主问答
**Q（面试官原话）：** 下面的 c2 到底是从 0 还是 1 开始？
**A：**
1. **重置规则**：`const` 关键字出现时 iota 重置为 0；块内每多一行常量声明 +1。
2. **前导占位**：若 `c1` 是显式值（如字符串）占第 0 行，则 `c2`(用 iota) 在第 1 行 → `c2=1`，`c3=2`；**不是从 0 起**。
3. **新块独立**：另一个 `const` 块里 `c4` 重新从 0 起（`c4=0`, `c5=1`），与上一个块无关。
4. **实战用法**：`KB = 1 << (10 * iota)` 一行声明 KB/MB/GB/TB/PB；或配合加法做枚举（`_ = iota` 跳过）。

## 关键代码
```go
const (
    KB = 1 << (10 * iota) // 1<<10
    MB                    // 1<<20
    GB                    // 1<<30
)
```

## 总结与追问预判
iota 是 const 块行计数器：const 重置 0、每行 +1；前面显式常量占行会让后续 iota 不从 0 起。常用 `1<<(10*iota)` 声明存储单位，用 `_ = iota` 跳值。
