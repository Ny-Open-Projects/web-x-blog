# 615 Go 面向对象深挖

> 分类：Go 语言 / 面向对象 | 难度：L3 | 题型：深挖 | 频率：中 | 关键词：**组合优于继承** / **嵌入规则** / **隐式接口** / **空指针陷阱**
> 原文锚点：第 4~46 段「结构体嵌模拟继承…同名方法重写…指针vs值…接口两种实现/隐式/空指针」

## 思路与架构
Go 的"面向对象"由三件套构成，且不走传统类继承：
- **结构体 + 嵌入**：用组合复用字段/方法（嵌入即字段/方法提升，组合优于继承）。
- **接口**：方法集契约，隐式实现（struct 自动满足，无需声明）。
- **组合 > 继承**：官方明确推荐小接口 + 组合，避免深层次 is-a 耦合。

## 方案取舍
```text
嵌入 vs 显式字段组合：
────────────────────────────────────────────
嵌入(匿名)                    显式字段(具名)
✅ 字段/方法自动提升，写法短   ✅ 命名清晰、无歧义
✅ 语义像"继承"(易读)         ✅ 无同名冲突歧义
❌ 同名方法须重写、易歧义     ❌ 调用需多写一层字段名
❌ 值嵌入复制副本(内存↑)      ✅ 指针/值可控
→ 小复用、少冲突用嵌入；复杂结构用显式组合

内嵌接口 vs 全实现接口：
────────────────────────────────────────────
内嵌接口：可只实现部分方法，灵活但留 nil 方法指针(调用panic)
全实现：  必须实现全部方法，健壮无隐患(推荐)
```

## 答题技巧
```text
面试话术（先破"Go 有没有继承"）：
1. 直说：Go 不支持传统继承(无 extends)，用组合/嵌入+接口模拟
2. 嵌入：字段方法提升、可多层、外层可重写同名(优先级外层>内层)
3. 指针vs值：指针共享、值复制副本(大结构体用指针)
4. 接口：隐式实现(方法集匹配即可)，两种实现路径
5. 收尾坑：内嵌接口部分实现→调用未实现方法 nil pointer panic，故优先全实现
```

> 边界：接口比较运行时细节见 509；error 接口自定义见 513；接口逃逸性能见 1119；本卡只深挖"嵌入模拟继承 + 接口实现"不重述比较/逃逸。

## 细节与核心 API

```go
// Go 无 class/extends/继承；用“组合 + 接口”实现复用与多态
type Animal interface { Speak() string }
type Base struct{ Name string }
func (b Base) Describe() string { return b.Name }
type Dog struct { Base }                 // 嵌入（组合）
func (d Dog) Speak() string { return "woof" }
var a Animal = Dog{Base{"Rex"}}          // 多态：Dog 实现 Animal
a.Speak()
// 方法提升：Dog 直接拥有 Base.Describe（字段与方法都提升）
// 重写：Dog 定义同名方法即“覆盖”提升方法
// 接口满足是隐式的，调用方依赖小接口，实现方自由演化
```
