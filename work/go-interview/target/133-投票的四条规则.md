# 133 投票的四条规则：为什么优先投给状态版本高的

> 分类：Elasticsearch | 难度：L4 | 题型：陷阱题 | 频率：中高 | 关键词：**投票规则、选举轮次、集群状态版本、节点 ID、过半**

> 原文锚点：第 40~47 段「节点只会为同一轮次的一个候选节点投票…会优先为集群状态版本比较高的候选节点投票…节点不会为自己投票」

## 一句话总述
投票按四条规则走：**同一轮次只投一次、优先投集群状态版本更高的、版本相同投节点 ID 更小的、不能投给自己**，最终得票超过候选主节点总数一半者当选。

## 面试官视角
P6 能说"多数派当选"；P7 要说出**排序依据的两级键：先状态版本、后节点 ID** `[源码]`。加分点：解释为什么先看版本——**状态更新者掌握的信息更全**，让它当选能少丢变更 `[经验]`。

## 主问答
**Q（面试官原话）：** 两个候选同时拉票，节点把票投给谁？

1. **同轮只投一次**：一个节点在**同一轮选举**里只能投给一个候选，避免同一轮出现重复计票 `[源码]`。
2. **第一优先是状态版本**：优先投给**集群状态版本更高**的候选，因为它的元数据更新，选它做主能最大限度保留已提交的变更 `[经验]`。
3. **第二优先是节点 ID**：多个候选的集群状态版本相同时，投给**节点 ID 值更小**的那个——用确定性规则打破平局，避免反复分裂 `[源码]`。
4. **不能投给自己**：节点不会把票投给自己，所以候选必须去争取别人的票，这也是"过半"有意义的前提 `[源码]`。
5. **过半才算赢**：得票超过**候选主节点总数的一半**才当选；否则本轮失败，等探测超时后重新开始新一轮选举 `[实测]`。
