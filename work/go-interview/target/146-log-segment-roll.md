# 146 日志分段触发：四大条件

> 分类：消息中间件 / Kafka | 难度：L4 | 题型：原理题 | 频率：中 | 关键词：**log.segment.bytes、log.roll.hours、索引大小、相对偏移量、分段**

> 原文锚点：第 11~23 段「分段四条件：当前段超 log.segment.bytes（默认 1GB）…消息最大时间戳与当前差超 log.roll.hours（默认 7 天，ms 优先级高）…偏移量索引大小超 10MB…追加偏移量与段起始偏移差值超最大整型」

## 一句话总述
Kafka 日志段在四个条件任一满足时切分：① 段大小超 `log.segment.bytes`（默认 1GB）；② 段内消息最大时间戳与当前差超 `log.roll.hours`（默认 7 天，毫秒级配置优先级更高）；③ 偏移量索引文件超 10MB；④ 新消息相对偏移量超 int 最大值（无法转相对偏移）。

## 面试官视角
P6 能说出段大小与时间两条件；P7 要讲清「毫秒配置优先级高于小时配置」，以及相对偏移量（当前偏移−段 baseOffset）超 int 也会触发，体现段设计的边界考据。

## 主问答
**Q（面试官原话）：** Kafka 日志什么时候分段？

1. **大小条件**：当前段超 `log.segment.bytes`（默认 1GB）即切分 `[源码]`。
2. **时间条件**：段内消息最大时间戳与当前差超 `log.roll.hours`（默认 7 天）触发 `[源码]`。
3. **优先级**：时间戳可用 ms 或 hours 配置，毫秒级配置优先级高于小时级 `[源码]`。
4. **索引大小**：偏移量索引文件大小超 `log.index.size.max.bytes`（10MB）切分 `[源码]`。
5. **偏移边界**：新消息相对偏移（当前偏移−段 baseOffset）超 int 最大值，无法表示则切分 `[源码]`。
