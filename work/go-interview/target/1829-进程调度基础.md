# 1829 进程调度基础：定义与抢占原则

> 分类：OS 进程调度 | 难度：L3 | 题型：概念题 | 频率：高 | 关键词：**进程调度**/**抢占式**/**非抢占式**/**时间片**/**优先权**/**短作业优先**
> 原文锚点：第 1~20 段「进程调度算法有哪些 + 抢占原则」

## 一句话总述
进程调度是 CPU 从**就绪队列**中选一个进程分配 CPU 的动作，发生在进程状态切换时；按「是否允许运行中进程被中断」分为**非抢占式**（完成/阻塞才让出）与**抢占式**（可强制让出）。三大抢占原则：**时间片**、**优先权**、**短作业优先**。

## 面试官视角
- 考察意图：是否理解调度的触发时机、抢占/非抢占的本质区别，以及三种抢占原则各自解决的问题与副作用。
- 分档：P5 知调度=选进程给 CPU；P6 知抢占 vs 非抢占；P7 知三原则（时间片/优先权/短作业）及饥饿、动态优先级等细节。
- 红旗答案：把调度说成「分配内存」；或不知道抢占式会打断运行进程。
- 惊艳点：点出「调度只影响等待时间，不影响进程真正用 CPU 的时间和 IO 时间」。

## 主问答
**Q（面试官原话）：** 什么是进程调度？抢占式和非抢占式有什么区别？有哪些抢占原则？
**A：**
1. **调度定义与时机**：调度是 CPU 在就绪态进程里挑一个分配 CPU 的动作；通常在状态切换时发生（运行→等待、就绪→终止属非抢占；运行/等待→就绪属抢占）。
2. **非抢占 vs 抢占**：非抢占发生在进程完成或阻塞时，一旦运行就占满 CPU 直到退出/阻塞；抢占允许运行中的进程被中断让出 CPU，抢占依据有三原则。
3. **三抢占原则**：① 时间片——每进程分固定时间量子，用完交还 CPU，保证公平避免独占；② 优先权——按优先级排执行序，高优先级先得 CPU，但低优先级可能饥饿；③ 短作业优先——按估计运行时间排，短者先跑，降低平均等待但长作业可能饥饿。
4. **调度的作用边界**：调度影响的是**等待时间**（在就绪队列等的总时长），不影响进程真正占用 CPU 的时间和 IO 时间。

```go
// 时间片轮转的极简模型：每进程分配固定时间片，用完轮到下一个
func rrDemo(procs []string, quantum int, remaining []int) {
	for {
		done := true
		for i := range procs {
			if remaining[i] <= 0 {
				continue
			}
			done = false
			run(procs[i], min(quantum, remaining[i])) // 运行 <= 时间片
			remaining[i] -= quantum
		}
		if done {
			break
		}
	}
}
func min(a, b int) int { if a < b { return a }; return b }
```
