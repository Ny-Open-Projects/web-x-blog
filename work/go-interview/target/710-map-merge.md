# 710 mergo 合并两个 map

> 分类：数据结构 | 难度：L2 | 题型：工程题 | 频率：低 | 关键词：**map 并集** / **类型不符保留目标** / **零值才覆盖**
> 原文锚点：第 105~127 段

## 一句话总述
`mergo.Merge` 合并 map 是"并集"：同 key 仅目标零值被覆盖，类型不符以目标为准，缺失 key 补入。

## 面试官视角
- 意图：分清 struct/map 合并异同与边界。
- P5 会调用 / P6 说清三规则并举例 / P7 知类型不符为何以目标为准。
- 红旗：以为同 key 总覆盖；以为类型不同会强转。
- 惊艳点：类型不同的同 key 保留目标、不报错 —— 验证 mergo 反射前做兼容判断。

## 主问答
**Q（面试官原话）：** 用 mergo 合并两个 map，结果怎么算？
**A：**
1. **结论**：同 key 时目标为零值才被覆盖，非零点保留；缺失 key 补入。
2. **机制**：按 key 名反射赋值；合并结果≈两 map **并集**。
3. **边界**：同 key **类型不同**以目标为准，不转换也不报错。
**加分层：** 同 struct 合并，想全覆盖用 `WithOverride`。

## 关键代码
```go
// 示意，未验证：map 合并为并集，零值才覆盖
package main

import (
	"fmt"
	"log"

	"dario.cat/mergo"
)

func main() {
	m1 := map[string]interface{}{"name": "a", "sex": "m"}   // 目标
	m2 := map[string]interface{}{"name": "", "email": "@x"} // 源：name 零值，email 缺失
	if err := mergo.Merge(&m1, m2); err != nil {
		log.Fatal(err)
	}
	fmt.Printf("%+v\n", m1) // name 被覆盖为空、email 补入、sex 保留
}
```

## 总结与追问预判
- map 合并是并集：零值才覆盖、类型不符保留目标、缺失 key 补入。
- 预判：struct 合并异同 → 见 710-struct-merge；改默认 → 见 710-merge-options。
