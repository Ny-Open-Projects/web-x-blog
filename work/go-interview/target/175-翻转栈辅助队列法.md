# 175 翻转栈：辅助队列法

> 分类：算法/栈 | 难度：L3 | 题型：方案题 | 频率：中 | 关键词：**辅助队列**/**出栈入队**/**FIFO颠倒**/**O(n)空间**/**直观**
> 原文锚点：第 1~5 段「申请额外队列、元素依次出栈入队、再按出队顺序入栈实现翻转、缺点额外空间」

## 一句话总述
辅助队列法最直观：准备一个**额外队列**，把栈中元素**依次出栈、入队**（此时队里是正序），再把队列元素**依次出队、入栈**——借助队列 FIFO 把顺序颠倒，栈即被翻转。代价是需 O(n) 额外空间。

## 面试官视角
- 考察意图：能否用「第三种结构」打破栈的 LIFO 限制完成全局逆序。
- 分档：P5 知用队列；P6 能写「出栈入队→出队入栈」两步；P7 能量化空间 O(n)、对比递归法。
- 红旗答案：出栈后直接再入栈（顺序不变）；忽略额外空间代价。
- 惊艳点：点出「队列 FIFO 把『后进先出』的弹出序变回正序、再入栈即逆序」这一关键 [经验]。

## 主问答
**Q（面试官原话）：** 用辅助队列怎么翻转栈？
**A：**
1. **出栈入队**：把栈元素依次 pop 进队列，队列里保持原顺序（1,2,3,4,5） [经验]。
2. **出队入栈**：再把队列元素依次出队、push 回栈，FIFO 使入栈序变逆序（5,4,3,2,1） [经验]。
3. **代价**：借助了额外队列，空间复杂度 O(n)，是此法主要缺点 [经验]。

## 总结与追问预判
队列法是「空间换理解简单」的解。追求低空间时改用递归法（借调用栈），但递归深度受语言栈深限制，超长栈需迭代/显式栈替代。

## ⚠️ 原文纠错
1. 事实核校： [经验] 出栈入队→出队入栈、FIFO 颠倒、额外 O(n) 空间——均正确。
2. 崩坏词归一：源码将若干术语音译为崩坏词，本卡统一为规范术语（栈、队列、出栈、入栈、FIFO、递归等）。

```go
// 辅助队列法翻转栈（slice 尾为栈顶）
func reverseStackQueue(s []int) []int {
    q := []int{}              // 额外队列
    for len(s) > 0 {          // 依次出栈入队
        q = append(q, s[len(s)-1])
        s = s[:len(s)-1]
    }
    for len(q) > 0 {          // 依次出队入栈 → 顺序颠倒
        s = append(s, q[0])
        q = q[1:]
    }
    return s // 5,4,3,2,1（5 在栈顶）
}
// 代价：额外队列 O(n) 空间
```
