# 802 runtime 准备度检验清单（模拟考）

> 分类：Go runtime/面试方法 | 难度：L2 | 题型：方法论 | 频率：低 | 关键词：**模拟考**/**思维导图**/**主动回忆**/**大声复述**

> 原文锚点：第 12~19 段「检验准备度=模拟考…思维导图折叠答案只显问题…大声作答模拟面试…主动回忆检索成永久记忆…面试前一天再过一遍」

## 一句话总述
检验 runtime 准备是否到位，靠**模拟考**而非自我感觉：把高频题做成**思维导图、答案折叠只显问题**，能**大声流畅复述**才算准备好；答不出时**主动回忆**（比直接看答案更能形成永久记忆），实在不会才展开答案；**面试前一天整体过一遍**直到全部能答。

## 面试官视角
这是备考闭环的方法题。面试官看你是否掌握"主动检索>被动阅读"的学习科学——会检验、会复盘，比"看完课"强得多。

## 主问答
**Q（面试官原话）：** 怎么检验自己 runtime 准备好了没？

**A：**

1. **模拟考检验**：找朋友模拟面试，或把问题整理成思维导图、**答案折叠只显示问题**，自测能否流利说出——这是检验备考效果最有效的方法。
2. **大声作答**：复述时**发出声音、模拟面试表达**，而非心里默念；能流畅讲出才说明真掌握。
3. **主动回忆优先**：答不出时先**努力回忆**（主动从大脑检索是变永久记忆的最有效法），实在想不起再展开答案；完全没思路说明该回看课程加深理解。
4. **面试前一日复盘**：考前一天把问题整体再过一遍，直到能流利答完全部为止。
