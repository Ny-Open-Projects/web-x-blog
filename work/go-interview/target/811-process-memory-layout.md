# 811 程序内存布局：代码段到内核空间

> 分类：内存与 GC | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**代码段** / **堆与栈** / **内核空间**
> 原文锚点：第 86~108 段「示意图理解内存布局…代码段/数据区/BSS/堆/栈/内核区」

## 一句话总述
进程虚拟地址从低到高依次：代码段、已初始化数据、BSS、堆（向上长）、未分配区、栈（向下长）、内核空间；Go 变量分配在堆还是栈由逃逸分析决定。

## 面试官视角
- 意图：是否分得清各段用途，尤其堆与栈的增长方向与生命周期。
- P5 知堆栈区别 / P6 说清增长方向与逃逸分析 / P7 知栈溢出、mmap 大块。
- 红旗：以为 Go 一定在堆上分配；混淆 BSS 与 data。
- 惊艳点：栈向下、堆向上，相向生长，相遇即 OOM —— 验证 `runtime.Stack` 观栈 `[经验]`。

## 主问答
**Q（面试官原话）：** 程序内存分哪几段？堆和栈有什么区别？
**A：**
1. **结论**：低址代码/data/BSS，中堆向上、栈向下，顶内核空间；堆手动或 GC 管、栈随调用自动伸缩 `[源码]`。
2. **机制**：代码段只读可共享；BSS 存未初始化全局变量；栈由 OS 压栈出栈高效，堆需分配器管理。
3. **边界**：段布局是虚拟地址约定，并非物理排布；Go 对象在堆/栈由逃逸分析决定，非写代码时定。
**加分层：** 栈溢出是栈增长撞上堆/未映射区，不是代码段位置导致。

## ⚠️ 原文纠错
原文第 90 段称「代码段放在堆空间最下面，是为了避免堆栈溢出」。该表述因果关系不成立：代码段位于低地址是布局惯例，而栈溢出发生在栈向下增长撞上堆/未映射区，与代码段位置无关。正确说法应为代码段固定于最低地址、堆与栈从中间相向生长，二者相遇才会导致越界/OOM。其余各段（data/BSS/堆/栈/内核）的划分与用途描述正确。机翻解码：勾浪→Go、占→栈。
