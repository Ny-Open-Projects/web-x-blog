# 1118 堆与栈的区别与 Go 协程栈

> 分类：内存与 GC | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**栈静态分配** / **堆动态分配** / **协程栈**
> 原文锚点：第 7~27 段「栈是静态分配、堆是动态分配、协程有自己栈空间」

## 一句话总述
栈由编译器自动分配释放、高效但空间小且静态；堆运行时动态分配、供长生命周期大对象、需 GC。Go 每个 goroutine 有独立连续栈，初始约 2KB 并按需伸缩，上限 64 位 1GB。

## 面试官视角
- 意图：是否理解栈堆分工及 Go 协程栈特性。
- P5 说清分配/释放差异 / P6 知协程栈连续且自适应 / P7 知上限与 SetMaxStack。
- 红旗：以为堆一定比栈慢；以为栈能存大对象。
- 惊艳点：Go 1.4 改连续栈后初始栈 2KB，1.19 起按需增长收缩，上限 1GB(64 位) —— 验证 `[源码]`。

## 主问答
**Q（面试官原话）：** Go 里堆和栈有什么区别？
**A：**
1. **结论**：栈编译期确定、函数返回自动回收、高效但小；堆运行时分配、需 GC、适合大/长生命周期对象。
2. **机制**：栈空间静态、goroutine 私有，访问快；堆全局可达、供协程间共享地址，分配释放慢且有碎片。
3. **边界**：栈上限受限（Go 默认 64 位 1GB、32 位 250MB，可用 runtime/debug.SetMaxStack 改），大对象与逃逸对象只能放堆。
**加分层：** 把小且生命周期明确的对象留在栈，可省 GC 压力，这正是逃逸分析的意义。
