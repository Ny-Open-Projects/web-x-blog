# 174 最小栈的重复值陷阱与空间优化深挖

> 覆盖源 17-4 的工程延伸：重复最小值 panic 的逐层实测、`<=` 与「每层压 min」两种修法的空间对比、差值栈的 O(1) 空间思路、辅助栈范式的迁移场景。主卡已给双栈主线，本附录做边界与优化深挖。

## 思路与架构

```text
重复最小值 2,3,2 的两种命运 (go1.26.5 实测)
├─ 严格小于版 (<)
│   ├─ push2: min栈=[2]   push3: [2]   push2: 2<2 假 -> 不压, 仍[2]
│   ├─ pop(弹2): 值==min顶 -> 同步弹 -> min栈=[]
│   └─ GetMin() -> panic: index out of range [-1]
├─ 小于等于版 (<=)  [实测修复]
│   ├─ push2:[2] push3:[2] push2:[2 2]  (重复值各占一层)
│   └─ pop -> min栈=[2], GetMin=2 正确
└─ 每层都压版 (Push 时 min栈压 min(v, 旧min))
    ├─ min栈高度恒等于数据栈 (空间换健壮性)
    └─ 弹栈无脑同步, 无条件分支
```

## 方案取舍
- **重复值是双栈方案的默认考题**：源文「严格小于」+「相等就弹」的组合，在 2,3,2 序列上 [实测] **直接 panic**（最小栈弹空后 GetMin 越界）。修法一：压栈条件改 `<=`——重复最小值在最小栈里各占一层，弹出次数天然配平；修法二：每层压 `min(v, 当前min)`——最小栈与数据栈**永远等高**，弹栈无条件分支、不可能错位。两修法 [实测] 均正确（`<` 版 Go 源码级复现 panic、`<=` 版输出 2）[实测]。
- **两种修法的空间账**：`<=` 版最小栈高度 = 最小值的不同「历史段」数，最好 O(1)（递增序列只压一次）、最坏 O(n)；每层都压版高度恒为 n——**用确定性空间换掉条件分支**。面试答「`<=` 为主、说明每层压法的取舍」即可覆盖；真要抠空间是下一个问题 [经验]。
- **差值栈：O(1) 辅助空间的进阶答案**：栈里存「当前值 − 截至上一层的最小值」的差，min 变量维护当前最小；push 时差为负说明新值更小、更新 min；pop 时用差值反推前一个 min。代价是**可读性骤降、负差值可能溢出**——工程上不推荐，面试上是「知道存在但选双栈」的成熟表态 [经验]。
- **辅助栈范式的迁移**：「主栈 + 旁路记账」不止于 GetMin——`container/heap` 之外的「带 max 的栈」「栈实现队列时的 in/out 双栈」（见 175.md`）、甚至 GMP 调度器的本地队列 + 全局队列，都是「一份数据两份视图」的同构。设计题的收尾答一句迁移，展示范式而非模板 [经验]。

## 答题技巧
- 主线答双栈两条同步规则，**主动报出重复最小值的坑并给 `<=` 修法**——把面试官埋的雷自己拆掉，是本题最大加分点 [实测]。
- 用 panic 现场说话：「2,3,2 弹一个 2 后 GetMin 报 index out of range [-1]」——一句话证明测过代码，不是背题 [实测]。
- 被问「空间还能省吗」→ 简述差值栈思路后明确表态：可读性差、易溢出，工程选双栈——「知道但不选」比硬吹更专业 [经验]。
- 被问「还有哪里用到这个范式」→ 报 max 栈/双栈队列/调度器双队列三个同构点 [经验]。
- 主动边界到 `174-min-stack`（双栈主线）、`173-array-stack`/`173-linkedlist-stack`（栈底座实现）、`173-stack-select`（实现选型）、`175-reverse-stack-queue`（栈队列互模拟），构成「栈专题全家桶」[边界]。

## 细节与核心 API

```go
// 方案1：辅助栈存“当前最小值”
type MinStack struct {
    st   []int
    mins []int
}
func (m *MinStack) Push(v int) {
    m.st = append(m.st, v)
    cur := v
    if len(m.mins) > 0 && m.mins[len(m.mins)-1] < v { cur = m.mins[len(m.mins)-1] }
    m.mins = append(m.mins, cur)
}
func (m *MinStack) Pop() { m.st = m.st[:len(m.st)-1]; m.mins = m.mins[:len(m.mins)-1] }
func (m *MinStack) Min() int { return m.mins[len(m.mins)-1] }
// 重复值陷阱：不能只用一个变量记 min（弹出该值后 min 丢失），必须用辅助栈同步压/弹
// 空间优化：存“差值编码”（push 时压 v-curMin，pop 时按符号还原），省一半空间但易溢出需 int64
// 选型：辅助栈最直观稳妥；差值法省内存但边界（溢出/还原）要写对
```
