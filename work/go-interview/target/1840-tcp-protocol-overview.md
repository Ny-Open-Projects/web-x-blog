# 1840 TCP 是什么：面向连接、可靠、基于字节流的传输层协议

> 分类：计算机网络 / TCP | 难度：L3 | 题型：记忆题 | 频率：高 | 关键词：**TCP、传输控制协议、面向连接、可靠、字节流、协议栈**

> 原文锚点：第 1~17 段「TCP 的全称是传输控制协议，它是一种面向连接的、可靠的，并且是基于字节流的传输层协议…所谓协议就是指在特定背景下，参与者之间达成了一种行为规范或者是共同的约定…在 TCP/IP 协议栈中，TCP 负责可靠的传输，IP 负责寻址和路由」

## 一句话总述
TCP（传输控制协议）是**面向连接的、可靠的、基于字节流的传输层协议**；所谓协议就是参与者之间约定的行为规范，在 TCP/IP 协议栈中 **TCP 负责可靠传输、IP 负责寻址与路由**。

## 面试官视角
P6 能背「面向连接、可靠、字节流」三个词；P7 要能解释**「什么是协议」的多个维度**（规范约定 / 交互过程 / 规则算法 / 分层结构 / 标准化），并说出 TCP 与 IP 的职责边界。

## 主问答
**Q（面试官原话）：** 说一下你对 TCP 的理解。

1. **全称与定位**：TCP 全称**传输控制协议**，是**传输层协议**，为应用程序提供可靠高效的数据传输服务，是互联网通信的基础 `[源码]`。
2. **三个关键定语**：**面向连接**、**可靠**、**基于字节流** `[源码]`。
3. **协议即约定**：协议是特定背景下参与者之间达成的**行为规范或共同约定**；计算机网络中指传输和处理数据的一系列规则 `[源码]`。
4. **理解维度一 · 规范约定**：规定**数据格式、传输方式、处理过程**，以确保通信的有效性与可靠性 `[源码]`。
5. **理解维度二 · 交互过程**：描述参与者之间的交互，规定**通信的起始与结束时机、参与者角色和行为**；可分为**请求应答型、发布订阅型**等模式 `[源码]`。
6. **理解维度三 · 规则与算法**：包括**数据包格式、传输协议、错误检测与纠正机制**等技术细节 `[源码]`。
7. **理解维度四 · 分层结构**：协议按功能与层次划分，每层负责特定功能；**TCP/IP 协议栈中 TCP 负责可靠传输，IP 负责寻址和路由** `[源码]`。
8. **理解维度五 · 标准化**：由标准化机构制定和管理，确保**一致性与互操作性**，使不同厂商的系统能相互通信 `[源码]`。

## 关键代码
```go
package main

import (
	"fmt"
	"net"
)

func main() {
	// Go 中面向连接的 TCP：先 Dial 建立连接，再读写字节流
	conn, err := net.Dial("tcp", "127.0.0.1:8080")
	if err != nil {
		panic(err)
	}
	defer conn.Close()

	// 基于字节流：写入的是字节，没有消息边界概念
	if _, err := conn.Write([]byte("hello")); err != nil {
		panic(err)
	}

	buf := make([]byte, 128)
	n, err := conn.Read(buf) // 读取的是字节，不保证一次读满一条消息
	if err != nil {
		panic(err)
	}
	fmt.Println("recv:", string(buf[:n]))
}
```
