# 516 for range 闭坑深挖

> 分类：Go 陷阱 / for range | 难度：L3 | 题型：深挖 | 频率：高 | 关键词：**副本语义** / **取地址陷阱** / **大元素复制** / **nil 解引用** / **闭坑**
> 原文锚点：第 1~46 段「value副本+同址复用(取地址陷阱全3)/v++不改原值/大元素用s[i]避复制/指针数组nil解引用panic用_忽略」

## 思路与架构
for range 的坑都源于同一个根因：**循环变量 v 是元素的副本，且每次迭代复用同一个变量**（语法糖=底层 for + 复用 value）。由此裂出三条线——① 取地址陷阱（同址复用→全得最后值）② 改 v 不动原（副本正确性）③ 大元素复制开销（性能）④ 指针元素 nil 解引用（防御遍历）。回答时以"副本 + 复用"一根线串起全部坑。

## 方案取舍
```text
for range 四大坑矩阵：
──────────────────────────────────────────────────────────────
坑               根因              后果              破解
取地址陷阱       v副本+同址复用     map值全为最后     先拷贝再取址
改v不动原        v是副本两份       循环内改写无效    直接改原用s[i]
大元素复制       每次复制元素值部   性能降数量级       单变量+s[i]/普通for
指针nil解引用    遍历中即解引用     panic             _忽略值+下标+判空

设计法则：
- 根因统一：v 是副本且复用同变量
- 要存地址：先 vv:=v 再 &vv
- 要大元素性能：for i := range + s[i]
- 指针元素：永远先判空；遍历用 _ 忽略值
```

## 答题技巧
```text
面试话术（先根因后四类，再对比）：
1. 根因：v 是副本且每次迭代复用同一变量（语法糖=底层 for）
2. 取地址：&v 全同址 → 先拷贝 vv 再取址
3. 正确性：改 v 不动原 → 要改原用 s[i]
4. 性能：大元素复制 → 单变量+下标避复制(基准验证)
5. 防御：指针元素 nil → _ 忽略值+下标+判空；与闭包捕获同款
```
