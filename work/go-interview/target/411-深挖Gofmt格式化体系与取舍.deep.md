# 411 深挖：Go fmt 格式化体系与取舍

> 分类：Go 标准库 | 难度：高 | 题型：深挖 | 频率：高 | 关键词：**动词语义、UTF-8、浮点精度、%v 递进、FMT 函数**
> 原文锚点：第 1~108 段「Go 格式化输出全链路」

## 思路与架构
把「一次 fmt 输出」串成一条链：
1. **选函数**：Print（朴素）/ Printf（格式化）/ Println（换行+空格）——按是否需要动词与换行决定。
2. **选动词**：按类型选——通用 %v 系、数值 %d/%f、字符串 %s、指针 %p。
3. **细节语义**：整型控宽(%5d/%05d)、进制(%b/%o/%x)、字符(%c=码点)；字符串 UTF-8 字节下标。
4. **精度与舍入**：浮点 %f 默认 6 位、%.2f 控精度，注意结尾 5 常「五舍」。
5. **结构体输出**：%v(值) → %+v(值+字段名) → %#v(值+字段名+类型名) 信息量递进。

## 方案取舍
- **%v vs %+v vs %#v**：调试想快速看值用 %v；想对应字段用 %+v；要可复现字面量或看类型用 %#v。生产日志多用 %+v 平衡可读与体积。
- **%f vs %g**：固定小数位用 %f；数值跨度大、想紧凑用 %g（自动选十进制或科学计数）。
- **Print vs Printf**：纯拼接用 Print/Println 省去动词；需对齐/进制/宽度必用 Printf。
- **中文处理**：下标按字节，遍历字符用 `for range`（按 rune）而非索引，避免截断 3 字节汉字。

## 答题技巧
- 答「%v 三兄弟」用**一句话递进**：值 → 值+字段名 → 值+字段名+类型名，这是 P6/P7 必拿分。
- 必点 **UTF-8 字节下标**与**浮点五舍**两个坑——多数人会栽，你点出即脱颖而出。
- 被追问浮点精度：直接举 `0.125`→`0.12` 的反例，并说明这是二进制浮点 + 舍入实现的真实行为。
- 收尾补一句「%T 看类型而非值」，展示对反射式输出的理解。

## 细节与核心 API

```bash
gofmt -l .                 # 列出未格式化的文件（CI 门禁常用）
gofmt -w .                 # 就地格式化
goimports -w .             # gofmt + 自动管理 import（增删、分组）
go vet ./...               # 静态检查（printf 格式、不可达代码、锁拷贝等）
# 取舍：gofmt 强制统一风格，消灭“格式争论”，但风格不可配置（故意）
#  CI 集成：make fmt / pre-commit 钩子；MR 前 gofmt -l 必须为空
# 编辑器：保存时自动 gofmt；imports 用 goimports 或 gopls
# 进阶：golangci-lint 聚合多 linter（errcheck/staticcheck/ineffassign）
# 注意：gofmt 改的是排版，不改语义；它让 diff 聚焦逻辑改动而非空格
```
