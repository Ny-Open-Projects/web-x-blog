# 421 结构体可内嵌类型的资格规则

> 分类：Go 语法/结构体嵌入 | 难度：L3 | 题型：八股题 | 频率：中 | 关键词：**内嵌字段**/**匿名**/**接口**/**指针**/**类型名T**

> 原文锚点：第 1~18 段「哪些类型可以被内嵌…类型内嵌=字段只有类型无字段名(匿名字段)，字段名即类型名…可内嵌：基本类型/map/接口/结构体及其指针/匿名结构体指针/具名类型；不可内嵌：具名指针类型/接口类型的指针/无名的非指针类型(切片·映射)」

## 一句话总述
结构体**内嵌字段（匿名字段）**的资格有一条硬规则：嵌入类型必须是一个**类型名 T**，或指向**非接口**类型名 T 的指针 `*T`；且 **T 本身不能是指针类型、不能是接口类型（若取指针则更不行）**。由此：具名类型（基类型/结构体/接口/map/基本类型）及其**匿名**指针可嵌；具名指针类型、接口类型的指针、未命名类型（切片/映射/数组/函数/通道等）**不可嵌**。

## 面试官视角
这是结构体嵌入里最易翻车的细节题。面试官想看你能否说清"哪些类型能嵌、哪些不能"的判定依据（类型名 vs 指针 vs 接口 vs 未命名），而不是只背"struct 可以嵌 struct"。

## 主问答
**Q（面试官原话）：** Go 里哪些类型可以被结构体内嵌？

**A：**

1. **可嵌入——具名类型**：基本类型（`int`）、结构体、接口（如 `iperson`）、map，以及它们的**匿名指针**（`*int`、`*person` 匿名形式）——只要类型是"有名字的 T"，即可作内嵌字段；匿名字段的字段名就是它的类型名。
2. **不可嵌入——指针相关**：**具名指针类型**（如 `type intPtr *int` 再嵌 `intPtr`）不行，因为 T 本身是指针类型违反规则；**接口类型的指针**（如 `*iperson`）也不行——接口可取 T 本身，但不能取 `*T`（指针指向接口）。
3. **不可嵌入——未命名类型**：切片 `[]T`、映射 `map[K]V`、数组、函数、通道等**未命名（anonymous）复合类型**不能直接内嵌；只有先用 `type` 给它们起名变成具名类型，才能嵌入。

## 版本与兼容性
- 结构体嵌入自 Go 1.0 起稳定，资格规则与 spec 一致，无版本翻转。
- 注意：内嵌类型名与外层字段名**不可重名**（如 `m` 与 `*m` 只能留一个），否则编译冲突。

## 关键代码
```go
type iperson interface{ Say() }
type person struct{ name string }

// 可嵌入：具名类型及其匿名指针
type A struct {
    int      // 基本类型匿名嵌入，字段名即 "int"
    person   // 结构体嵌入
    *person  // 匿名指针嵌入（*T，T 非指针非接口）✓
    iperson  // 接口类型嵌入（T 本身，非 *T）✓
    m        map[string]int
}
// 不可嵌入示例（编译报错）：
// type intPtr *int
// type B struct { intPtr }   // ✗ 具名指针类型（T 是指针）
// type C struct { *iperson } // ✗ 接口类型的指针
// type D struct { []int }     // ✗ 未命名复合类型
```

## 总结与追问预判
- 口诀：**可嵌看"类型名 T"——具名就行；不可嵌看"指针/接口指针/未命名"**。
- 预判追问："嵌入后外层能调内层方法吗？"→ 那是方法提升（见 615），本卡只讲类型资格，不重述继承机制。
