# 411 Go fmt 格式化动词全景与易错点

> 分类：Go 标准库 | 难度：中 | 题型：综合 | 频率：高 | 关键词：**动词分类、易错点、UTF-8、精度、类型**

> 原文锚点：第 1~108 段「Go 格式化输出全貌」

## 一句话总述
Go `fmt` 动词按类型可归为：通用(%v 系)、布尔(%t/%T)、整型(%d/%b/%o/%c/%q/%x/%X/%U)、字符串(%s/%q)、浮点(%f/%e/%g)、指针(%p)。高频易错点是：字符串按 UTF-8 字节下标、浮点默认 6 位且结尾 5「五舍」、`%T` 看类型而非值。

## 面试官视角
这是动词体系的收口题。考官期待你一张表把动词归类，并指出 2~3 个真正会坑人的细节（中文下标、五舍、%T）。能举出反例的人，说明真写过而非背表。

## 主问答
**Q（面试官原话）：** 把 Go 的格式化动词梳理一遍，并说说易错点。

1. **动词分类**：通用 `%v/%+v/%#v`；布尔 `%t`(值)/`%T`(类型)；整型 `%d`(十)/`%b`(二)/`%o`(八)/`%c`(字符)/`%q`(引号)/`%x`/`%X`(十六)/`%U`(Unicode)；字符串 `%s`/`%q`；浮点 `%f`/`%e`/`%g`；指针 `%p`。
2. **易错点一（字符串）**：下标按字节、中文占 3 字节，故 `s[0]` 与 `s[3]` 才是两个汉字，别当字符数组索引。
3. **易错点二（浮点）**：`%f` 默认 6 位小数、第 7 位四舍五入；但恰好结尾为 5 时往往「五舍」（如 `0.125`→`0.12`），不可想当然当四舍五入。
4. **易错点三（类型）**：`%T` 输出的是**类型名**不是值；`rune`=int32、`byte`=uint8，打印字符用 `%c` 按码点转。

## 关键代码
```go
fmt.Printf("%T %v\n", 3.14, 3.14) // float64 3.14
fmt.Printf("%#v\n", struct{ A int }{1}) // struct { A int }{A:1}
```
