# 413 new 的实战定位与局限

> 分类：Go 基础 / 内置函数 | 难度：L3 | 题型：认知题 | 频率：中 | 关键词：**new 对 slice/map 无意义** / **字面量更常用** / **new 对数组=*[N]T** / **零值**
> 原文锚点：第 43~52 段「用 new 创建映射和切片没有任何价值；实际多用字面量；new 对数组得到已清零的 *[N]T；数组声明即零值」

## 一句话总述
`new(T)` 返回 `*T` 且内存清零，但**对 slice/map/chan 用 new 几乎没有价值**——得到的指针指向 nil，还得手动 `make` 才可用；实际工程中多用**字面量/复合字面量**创建值或指针。唯一值得提的特例是对**数组** `new([N]T)` 得到已清零的 `*[N]T`（与 `&[N]T{}` 等价）。

## 面试官视角
- 考察意图：是否理解 new 的"清零但不初始化引用"导致它在引用类型上鸡肋
- P5 知 new 返回指针且清零；P6 能讲"对 slice/map 用 new 无意义、要再 make"；P7 能讲"实际多用字面量、new 仅在需显式 *T 时有用"
- 红旗：在代码里 `p := new([]int)` 然后直接 append；说"new 和字面量完全等价"
- 惊艳点：点出"new 的零值是'每个元素零值'（数组），但'引用零值是 nil'（slice/map/chan）——这是 new 在两类类型上表现不同的根因" [源码]

## 主问答
**Q（面试官原话）：** 实际项目里 new 用得多吗，有什么讲究？
**A：**
1. **引用类型上 new 鸡肋**：`new([]int)` / `new(map[K]V)` 得到的是指向 **nil** 的指针，不初始化引用，必须再 `make` 才可用——所以对 slice/map 用 new **没有价值**，直接用 `make` 更省事 [经验]。
2. **实际多用字面量**：创建值用 `s := []int{}`，创建指针用 `p := &[]int{}` 或 `p := new([]int)`，三者语义相近；工程里**字面量/复合字面量**最常用、最直观 [经验]。
3. **new 的靠谱场景是数组**：`new([N]T)` 返回 `*[N]T` 且**每个元素已清零**（数组的零值就是各元素零值），与 `&[N]T{}` 等价；这是 new 少有的"开箱即用"场景 [边界]。

## 关键代码
```go
// 引用类型：new 鸡肋
p := new([]int)      // *[]int，指向 nil，需再 make
// 更优：直接字面量
s := []int{}         // 值类型，非 nil
// 数组：new 开箱即用
a := new([3]int)     // *[3]int，元素已清零 [0 0 0]，等价于 &[3]int{}
```
