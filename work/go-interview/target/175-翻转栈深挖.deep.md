# 175 翻转栈 深挖

> 覆盖源 17-5 全文：翻转栈语义、辅助队列法、递归法（两递归函数）。主卡已拆成总览、队列法、递归法三张，本附录做递归展开可视化与取舍。

## 思路与架构

```mermaid

```

## 方案取舍
- **队列法 vs 递归法**：队列法直观、空间 O(n)、不易错；递归法省显式空间但两层递归难读、深栈易溢出。
- **递归深度**：递归深度 = 栈长，超长栈须改迭代显式栈，否则栈溢出。
- **本质**：两者都是「借第三种结构（队列/调用栈）打破 LIFO 限制完成全局逆序」。

## 答题技巧
- 被问「翻转栈」先给队列法（稳），再补递归法（秀深度），并点空间/可读性取舍 [经验]。
- 主动边界到 `173`(栈基本操作 push/pop)，构成栈算法全栈 [边界]。

## 细节与核心 API

```go
// 用递归不借助额外结构“原地”翻转栈（面试经典）
func reverseStack(s *[]int) {
    if len(*s) == 0 { return }
    top := (*s)[len(*s)-1]
    *s = (*s)[:len(*s)-1]
    reverseStack(s)
    insertBottom(s, top)
}
// 把 x 插到栈底（再递归弹到空再压回）
func insertBottom(s *[]int, x int) {
    if len(*s) == 0 { *s = append(*s, x); return }
    top := (*s)[len(*s)-1]
    *s = (*s)[:len(*s)-1]
    insertBottom(s, x)
    *s = append(*s, top)
}
// 思路：pop 到底，从最深开始把元素 insertBottom，利用调用栈保存顺序
// 复杂度 O(n^2)（每次 insertBottom 要弹出再压回）；仅考察递归理解，非性能最优
```
