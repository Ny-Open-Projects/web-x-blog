# 1818 RAID 0 条带化 vs RAID 1 镜像

> 分类：存储/硬件 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**条带化**/**镜像**/**利用率 50%**/**无冗余**/**读性能**

> 原文锚点：第 4~17 段「RAID 0 条带化与 RAID 1 镜像」

## 一句话总述
RAID 0 把数据切成块平均铺到多盘上，读写可并行、吞吐翻倍，但**没有任何数据保护**，一块盘坏则整阵列失效；RAID 1 给每个数据块在多盘上各留一份副本，读性能高、坏一块仍可服务，代价是利用率只有 50%。

## 面试官视角
考官要的是**数字与代价**：最少几块盘、可用容量多少、坏几块能撑、读和写各自怎么变。能把「RAID 1 提升读不提升写」说清楚，就能和只会背「镜像安全」的人区分开。

## 主问答
**Q（面试官原话）：** RAID 0 和 RAID 1 有什么区别？分别适合什么场景？

1. **RAID 0 是条带化**：文件被切成多段按规则写入各盘，同一文件可同时从多盘读写，因而吞吐显著提升。
2. **RAID 0 无冗余**：不提供数据保护，任一磁盘故障则整个阵列不可用，盘数越多阵列整体越脆弱。
3. **RAID 1 是镜像**：每个数据块至少在两块盘上各有一份副本，一块坏掉另一块仍有完整数据，可继续提供服务。
4. **RAID 1 读写不对称**：读请求可由两块盘分担，读性能更高；写入要把同一份数据写两遍，写性能并不提升。
5. **容量账**：RAID 0 可用容量为 N×单盘；RAID 1 为单盘容量，利用率 50%——这是换可靠性的直接成本。

## 追问链

| L1 | RAID 0 有冗余吗？ | 误以为有保护 |

## 版本与兼容性
| 级别 | 最少盘 | 可用容量 | 容错 |
|------|--------|----------|------|
| RAID 0 | 2 | N×单盘 | 0 块 |
| RAID 1 | 2 | 1×单盘 | N-1 块 |

## 关键代码
```go
// Go 侧视角：模拟条带化分布，理解"一个文件散落在多盘"
package main

import "fmt"

func stripe(block int, disks int) int {
	return block % disks // 第 block 块落在第几块盘
}

func main() {
	for b := 0; b < 6; b++ {
		fmt.Printf("数据块 %d -> 磁盘 %d\n", b, stripe(b, 2))
	}
}
```

## 总结与追问预判
核心：**RAID 0 换吞吐、无保护；RAID 1 换可靠、利用率 50%**。追问常拐向「为什么数据库很少用 RAID 0」「两块盘怎么做既快又安全」，后者自然引到 RAID 10。

## ⚠️ 原文纠错
1. 事实核校： [经验] 原文称 RAID 0「可靠性为 N 分之一」——严谨说法是 N 盘中任一损坏即整阵列不可用，阵列存活概率随 N 增加而下降，「1/N」只是粗略的相对描述。
2. 事实核校： [经验] 原文称 RAID 1「提供了很高的数据冗余和读写性能」——读性能确实因两盘分担而提升，写性能并不提升（每份数据都要写两遍），应分开表述。
3. 崩坏词归一：源码将 RAID / 条带化 等音译为多组崩坏词，本卡统一为规范术语。
