# 175 翻转栈：递归法（低空间）

> 分类：算法/栈 | 难度：L3 | 题型：方案题 | 频率：中 | 关键词：**递归翻转**/**栈底移到栈顶**/**两递归函数**/**终止条件空栈**/**调用栈省空间**
> 原文锚点：第 6~17 段「递归定义(栈底→栈顶+子栈递归)+终止条件(空)、主调pop子栈递归再push回、移栈底函数pop递归push回」

## 一句话总述
递归法靠**调用栈**省显式空间：核心是两个递归函数——① `moveBottomToTop`：弹出栈顶、栈不空则递归、结束再把弹出元素 push 回（把原栈底移到栈顶）；② 主调函数：pop 当前栈顶、对不含栈顶的子栈递归调用 ①、再把弹出的栈顶 push 回。对空栈终止。递归返回时顺序被逐层颠倒，完成翻转。

## 面试官视角
- 考察意图：能否讲清「把栈底移到栈顶」的递归定义与终止条件，理解两层递归如何协作。
- 分档：P5 知用递归；P6 能说清两递归函数分工；P7 能走查 12345 的递归展开、知深度受栈深限制。
- 红旗答案：只写一层递归（无法全局颠倒）；终止条件写错导致死递归。
- 惊艳点：点出「递归返回顺序与执行顺序相反、逐层 push 回即完成逆序」，以及「隐式调用栈替代显式队列省空间」 [经验]。

## 主问答
**Q（面试官原话）：** 递归怎么翻转栈？
**A：**
1. **递归定义+终止**：定义=把当前栈底元素移到栈顶、其余顺次下移、对子栈递归；终止=栈为空 [经验]。
2. **移栈底函数**：pop 栈顶，栈不空则递归自身，递归结束把弹出元素 push 回——最终把原栈底移到栈顶 [经验]。
3. **主调函数**：pop 当前栈顶，递归调移栈底处理子栈，再把弹出的栈顶 push 回；返回时逐层颠倒顺序 [经验]。

## 关键代码

```go
// 递归法翻转栈（slice 尾为栈顶），借调用栈省显式空间
func reverseStackRec(s []int) []int {
    if len(s) == 0 {
        return s // 终止条件：空栈
    }
    top := s[len(s)-1]
    s = s[:len(s)-1]       // pop 当前栈顶
    s = reverseStackRec(s) // 对子栈递归
    s = moveBottomToTop(s) // 把原栈底移到栈顶
    s = append(s, top)     // 把弹出的栈顶 push 回
    return s
}
// moveBottomToTop：把栈底元素移到栈顶（空则直接 push 回）
func moveBottomToTop(s []int) []int {
    if len(s) == 0 {
        return s
    }
    top := s[len(s)-1]
    s = s[:len(s)-1]
    if len(s) > 0 {
        s = moveBottomToTop(s) // 递归到栈底
    }
    s = append(s, top) // 逐层 push 回，栈底升到栈顶
    return s
}
// 输入 [1,2,3,4,5] → 输出 [5,4,3,2,1]
```

## 总结与追问预判
递归法是「空间换理解成本」的反面——省显式空间但难读。生产超长栈应改迭代显式栈，避免递归过深栈溢出。
