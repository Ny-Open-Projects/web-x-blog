# 1840 TCP 六个控制标志位：URG、ACK、PSH、RST、SYN、FIN

> 分类：计算机网络 / TCP | 难度：L4 | 题型：记忆题 | 频率：高 | 关键词：**URG、ACK、PSH、RST、SYN、FIN、紧急指针、强制断连**

> 原文锚点：第 49~72 段「后面这六个都是标志位，每个标志位都占一个比特…URG 表示紧急指针有效…ACK 当这个位的值为 1 的时候表示确认应答的字段是有效的，TCP 规定除了最初建立连接时的 SYN 包之外，这个位都必须设置为 1…PSH 表示接收方应该立即将数据推送给应用程序…RST 表示 TCP 连接中出现了异常，必须强制断开连接…SYN 表示同步序列号，用于建立连接…FIN 表示今后不再有数据发送，并且希望断开连接」

## 一句话总述
TCP 有 **URG、ACK、PSH、RST、SYN、FIN** 六个控制标志位（各占 1 比特），分别表示**紧急数据有效、确认号有效、立即推送、强制复位、建立连接、请求断连**。

## 面试官视角
P6 认识 SYN/ACK/FIN；P7 要能**六个全说全**，并讲清**两个高频细节**：**除首次 SYN 包外 ACK 必须置 1**，以及 **RST 的三种触发场景**（不存在的连接收到数据、等待确认时发现包有误、已关闭连接上收到数据）。

## 主问答
**Q（面试官原话）：** TCP 首部有哪些标志位？各自什么作用？

1. **URG（紧急指针有效）**：置 1 时表示**紧急指针字段的值有效**，指示报文段中**需要优先处理的紧急数据的位置** `[源码]`。
2. **URG 的边界**：紧急数据的**处理方式由应用程序定义**，TCP 本身**不提供对紧急数据的特殊处理机制**，只是通知接收方存在紧急数据 `[源码]`。
3. **典型场景**：如 telnet 中用户按下 Ctrl+C 终止会话时，通过发送紧急数据中断连接 `[源码]`。
4. **ACK（确认号有效）**：置 1 表示**确认应答字段有效**；**TCP 规定除最初建立连接的 SYN 包之外，该位都必须置 1** `[源码]`。
5. **PSH（立即推送）**：置 1 表示接收方应**立即将数据推送给应用程序**，而不是在缓冲区继续等待更多数据；常用于**交互性强、实时性要求高**的场景（如 telnet、SSH） `[源码]`。
6. **RST（强制复位）**：置 1 表示连接**出现异常，必须强制断开**；收到 RST 的一方**立即终止连接并释放相关资源**，必要时通知应用程序 `[源码]`。
7. **RST 的典型场景**：**不存在的连接收到数据**、**发送方等待确认时发现数据包有误**、**在已关闭的连接上收到数据** `[源码]`。
8. **SYN（建立连接）**：置 1 表示**希望建立连接**，并在序列号字段中**设定序列号初始值** `[源码]`。
9. **FIN（请求断连）**：置 1 表示**今后不再有数据发送，希望断开连接**；通信结束时双方**互相交换 FIN 段** `[源码]`。

## 关键代码
```go
package main

import "fmt"

// TCP 控制标志位（首部第 14 字节）
const (
	FIN = 0x01
	SYN = 0x02
	RST = 0x04
	PSH = 0x08
	ACK = 0x10
	URG = 0x20
)

func describeFlags(b byte) string {
	out := ""
	for _, f := range []struct {
		mask byte
		name string
	}{{FIN, "FIN"}, {SYN, "SYN"}, {RST, "RST"}, {PSH, "PSH"}, {ACK, "ACK"}, {URG, "URG"}} {
		if b&f.mask != 0 {
			out += f.name + " "
		}
	}
	return out
}

func main() {
	fmt.Println(describeFlags(SYN))       // SYN：发起连接
	fmt.Println(describeFlags(SYN | ACK)) // SYN+ACK：应答连接
	fmt.Println(describeFlags(FIN | ACK)) // FIN+ACK：请求断连
	fmt.Println(describeFlags(RST | ACK)) // RST：强制复位
}
```

## 总结与追问预判
**「除首次 SYN 包外 ACK 必须为 1」是最爱考的细节**。面试官常追问「什么时候会收到 RST」——答案是连接不存在、包有误或连接已关闭这三种异常。报文头整体结构见同批 1840-tcp-header。

## ⚠️ 原文纠错
1. 事实核校：六标志各 1 比特及其语义、URG 由应用定义处理方式、ACK 除首次 SYN 外必须置 1、PSH 立即推送、RST 三种场景、SYN 设初始序号、FIN 交换断连——均与 RFC 793 一致 `[经验]`。
2. 补充：现代 TCP 首部实际还有 **NS、CWR、ECE** 三个标志位（共 9 位），原文讲的 6 个是经典必备集合；答题时说「经典六位，现代扩展至九位」更严谨 `[经验]`。
3. 崩坏词归一：源码将各标志位名、紧急指针、复位、推送等术语音译为多组崩坏词，本卡统一为规范术语 `[经验]`。
