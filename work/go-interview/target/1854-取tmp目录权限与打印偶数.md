# 1854 取 /tmp 目录权限与打印偶数的多种写法

> 分类：Linux / 文本处理 | 难度：L3 | 题型：实操题 | 频率：中 | 关键词：**stat 三法**/**管道切片**/**BSD vs GNU**/**sticky 位**/**shell 无块作用域**
> 原文锚点：第 1~25 段「取 tmp 目录权限的多种方法（stat / ls 切片 / grep 正则）……打印偶数的六种写法（sed / awk / for / while）」
> 版本口径：macOS 14.5（系统 bash 3.2.57 + BSD 工具）实测；GNU/Linux 的差异逐条标注。管道检索的实战见 186-超大日志怎么查；重定向见 1813；启动脚本加载顺序见 1812。

## 一句话总述
权限题考的是「**先定位行、再拆字段、再清洗**」的文本流水线——`stat` 只负责产出文本，真正的活是 `head`/`tail`/`tr`/`cut`/`awk`/`grep -oE` 逐层切片（三法：格式化法 / 文本切片法 / 正则法）；偶数题考的是「**同一逻辑换三类控制流实现**」——六种写法归三类：**按行号过滤**（`sed`/`awk`）、**命令替换枚举**（`for i in $(seq)`）、**算术循环**（C 风格 `for`、`while`）。最值钱的是三个实测平台坑：macOS 的 `/tmp` 是指向 `/private/tmp` 的符号链接；`stat -f '%Lp'` **丢 sticky 位**（真身 1777 给你 777）；`sed '1~2d'` 是 GNU 扩展、BSD 直接报错。

## 面试官视角
- 考察意图：两道题看着无关，练的是同一技能——「把一段文本切成想要的字段」（权限题）和「同一逻辑换不同控制流实现」（奇偶题）；顺便探测你有没有跨平台踩坑经验。
- 分档：P5 能写出一种取权限、一种打印偶数的写法；P6 能给全三法/六法并说清分类；P7 能报出 sticky 位丢失、`first~step` 平台坑这类**实测细节**。
- 红旗答案：把 `stat -f '%Lp'` 的 777 当成 `/tmp` 真实权限；用 `sed '1~2d'` 而不知道它在 BSD 上跑不了。
- 惊艳点：能讲清「为什么 777 和 1777 都对——取决于你算不算特殊位」，以及 shell **没有块作用域**、C 风格 `for` 跑完 `i=11` 会污染后面的 `while` [实测]。

## 主问答
**Q（面试官原话）：** 用命令行取出 /tmp 的权限数字，有几种方法？再打印 1~10 里的偶数。
**A：**
1. **法一·格式化法**：`stat` 直接拿八进制——GNU 用 `-c '%a'`，BSD/macOS 用 `-f '%Lp'`，**参数名完全不兼容**；macOS 上 `%Lp` 只给低 9 位，**丢 sticky 位**，要真值用 `%p`（含文件类型位，输出 `41777`）再取末 4 位 [实测]。
2. **法二·文本切片法**：`ls -ld` 取 `drwxrwxrwt` 符号串，去掉首位文件类型后 9 位分 3 组、按 `r=4/w=2/x=1` 累加得 `777`，**末位 `t`（sticky）再在最高位补 1** 得 `1777`——不用 stat、跨平台 [源码]。
3. **法三·正则法**：`grep -oE '[0-7]{3,4}$'` 从 stat 完整输出里抠数字——**用 `$` 锚定行尾**，避免误伤行中间的数字（比如 `Uid: (0/root)` 里的 0）；源文用 `grep -oE '[0-9]{4}'` 无锚点，思路对但欠稳 [源码]。
4. **偶数六法归三类**：①按行号过滤——`sed -n 'n;p'`（可移植；`sed '1~2d'` 是 GNU 扩展）、`awk 'NR%2==0'`；②命令替换枚举——`for i in $(seq 1 10)`（外部命令，跨 shell）、`for i in {1..10}`（bash 花括号展开，`{2..10..2}` 步长形式是 **bash 4.0+**，macOS 自带 3.2 不展开）；③算术循环——C 风格 `for ((i=1;i<=10;i++))`、`while`（**必须显式重置 `i`**，否则上一轮留下的 `i=11` 让循环一次都不进）[实测]。

## 版本与兼容性

## 关键代码
```bash
#!/usr/bin/env bash
# perm-parity.sh —— 两道综合题的可复现实现
# 题 A：用三种方式取出 /tmp 的权限数字；题 B：用六种方式打印 1~10 中的偶数
set -u

OS="$(uname -s)"
# macOS 的 /tmp 是符号链接，真身在 /private/tmp；Linux 上 /tmp 本身就是目录
if [ "$OS" = "Darwin" ]; then TMPDIR_REAL=/private/tmp; else TMPDIR_REAL=/tmp; fi

echo "===== A. 取 $TMPDIR_REAL 的权限数字（三法）====="

# 法一：stat 格式化输出（GNU 用 -c，BSD 用 -f，参数名完全不同）
if stat --version >/dev/null 2>&1; then          # 只有 GNU stat 认 --version
  echo "  法一(stat -c): $(stat -c '%a' "$TMPDIR_REAL")"
else
  echo "  法一(stat -f): $(stat -f '%Lp' "$TMPDIR_REAL")   # ⚠ macOS 丢 sticky 位：/private/tmp 真实是 1777"
fi

# 法二：文本切片 —— 从 ls -l 的符号权限串逐位换算成数字（跨平台）
perm="$(ls -ld "$TMPDIR_REAL" | awk '{print $1}')"       # drwxrwxrwt
perm9="$(printf '%s' "$perm" | cut -c2-10)"              # rwxrwxrwt（去掉首位的文件类型）
# 三组 rwx 各自求和：r=4、w=2、x=1（t/T/s/S 在对应位上等价于 x 的 1）
oct="$(printf '%s' "$perm9" | awk '{d[0]=d[1]=d[2]=0;
  for(i=1;i<=9;i++){c=substr($0,i,1); v=(c=="r"?4:c=="w"?2:(c~/[xstST]/)?1:0);
                    g=int((i-1)/3); d[g]+=v} printf "%d%d%d", d[0],d[1],d[2]}')"
special=""                                               # 特殊位前缀：sticky=1 / setgid=2 / setuid=4
case "$(printf '%s' "$perm9" | cut -c9)" in t|T) special=1;; esac
echo "  法二(ls 切片): ${special}${oct}"

# 法三：从 stat 的完整输出里用「扩展正则」抽数字（锚定行尾）
if stat --version >/dev/null 2>&1; then
  raw="$(stat -c '%A %a' "$TMPDIR_REAL")"
else
  raw="$(stat -f '%Sp %p' "$TMPDIR_REAL")"
fi
echo "  法三(正则抽数字): $(printf '%s' "$raw" | grep -oE '[0-7]{3,4}$')"

echo "===== B. 打印 1~10 的偶数（六法）====="
echo "  法一(sed):     $(seq 1 10 | sed -n 'n;p' | tr '\n' ' ')"      # 可移植；1~2d 是 GNU 扩展
echo "  法二(awk):     $(seq 1 10 | awk 'NR%2==0' | tr '\n' ' ')"
out=''; for i in $(seq 1 10); do [ $((i%2)) -eq 0 ] && out="$out$i "; done
echo "  法三(for+seq): $out"
out=''; for i in {1..10}; do [ $((i%2)) -eq 0 ] && out="$out$i "; done
echo "  法四(brace):   $out"
out=''; for ((i=1;i<=10;i++)); do ((i%2==0)) && out="$out$i "; done
echo "  法五(C-for):   $out"     # 循环结束后 i=11，会污染后面的同名变量！
i=1; out=''; while [ "$i" -le 10 ]; do [ $((i%2)) -eq 0 ] && out="$out$i "; i=$((i+1)); done
echo "  法六(while):   $out"     # 必须显式重置 i，否则上一轮的 i=11 让循环一次都不进
```

实测输出（macOS 14.5 / bash 3.2.57）[实测]：

```text
===== A. 取 /private/tmp 的权限数字（三法）=====
  法一(stat -f): 777   # ⚠ macOS 丢 sticky 位：/private/tmp 真实是 1777
  法二(ls 切片): 1777
  法三(正则抽数字): 1777
===== B. 打印 1~10 的偶数（六法）=====
  法一(sed):     2 4 6 8 10
  法二(awk):     2 4 6 8 10
  法三(for+seq): 2 4 6 8 10
  法四(brace):   2 4 6 8 10
  法五(C-for):   2 4 6 8 10
  法六(while):   2 4 6 8 10
```

旁证（确证平台差异）[实测]：`stat -c '%a' /tmp` → `stat: illegal option -- c`（BSD 没有 -c）；`seq 1 10 | sed '1~2d'` → `sed: 1: "1~2d": invalid command code ~`；`ls -ld /tmp` → `lrwxr-xr-x ... /tmp -> private/tmp`；`stat -f 'Lp=%Lp p=%p' /private/tmp` → `Lp=777 p=41777`。

## 总结与追问预判
一句话记忆：**「权限题是文本流水线，偶数题是三类控制流；平台坑比写法值钱」**。追问预判：生产里怎么选——只做行过滤用 `sed`/`awk`（流式省内存）；枚举离散值用 `for in $(seq)`；带步长序列优先 `seq 1 2 10` 别用 `{1..10..2}`；**遍历命令输出优先 `while read` 而不是 `for`**（`for i in $(ls)` 按 IFS 切词，含空格文件名会散架）。「`ls -l` 和 `stat` 为什么结果不一样」——信息源与口径不同：`ls -ld` 对链接显示链接本身（加 `-L` 跟随），`stat -f '%Lp'` 丢特殊位；拿到权限值先问「谁的、含不含特殊位」。重定向的坑见 1813，inode 与链接见 1814 [边界]。

## ⚠️ 原文纠错
1. 用 `stat` 直接取权限并假设输出形如 `Access: (1777/drwxrwxrwt)`——那是 **GNU coreutils 的格式**；BSD/macOS 的 `stat` 没有 `-c` 选项、默认输出完全不同，源文命令在 macOS 上直接报错 [实测]。
2. `sed '1~2d'` 做「每隔两行删一行」——思路对，但 `first~step` 是 **GNU sed 扩展**，BSD 报错；可移植写法 `sed -n 'n;p'` [实测]。
3. 命令名大面积音译：`graph/grap`→grep、`state`→stat、`side/set`→sed、`seconds`→seq、`多乐/哆啦`→`$`、`CD 参数`→`-c/-d` 参数，全系语音转写音译错误。
4. 「grep 用 `+` 匹配多个数字需要 egrep」——**对**：BRE 里 `+` 是普通字符，要 `-E`（或 `\+`）才表示「一个或多个」[实测]。
5. 花括号「只能生成一到十」——不完整：`{1..10}` bash 3.2 可用，但**带步长的 `{2..10..2}` 是 bash 4.0+ 特性**，macOS 3.2.57 不展开 [实测]。
