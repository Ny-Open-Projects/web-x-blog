# 1215 COMPACT 行格式：四段结构

> 分类：MySQL 存储 | 难度：中高 | 题型：原理 | 频率：中高 | 关键词：**变长字段长度列表、NULL 值列表、记录头、逆序存储、真实数据**

> 原文锚点：第 14~34 段、第 70~73 段「COMPACT 四部分、逆序存放、NULL 位补齐字节、隐藏列」

## 一句话总述
COMPACT 行由四部分组成：**变长字段长度列表 → NULL 值列表 → 记录头信息（固定 5 字节）→ 真实列数据**。前两者均按「列的逆序」存放（便于从记录头向左读回时恢复列序），且都可缺省：无非变长列则无长度列表、列全 NOT NULL 则无 NULL 列表。真实数据后还有三个隐藏列：DB_TRX_ID(6B)、DB_ROLL_PTR(7B)，无主键时再加 DB_ROW_ID(6B)。

## 面试官视角
COMPACT 是行格式题的核心。考官期待你讲清「逆序存储」的巧思：变长长度列表与 NULL 列表逆序，使得从记录头向左读取时恰好按列顺序还原。能补「NULL 值不占真实数据空间、只占 NULL 列表一个 bit」是细节分。

## 主问答
**Q（面试官原话）：** COMPACT 行格式由哪几部分组成？

1. **变长字段长度列表**：记录各变长字段（如 VARCHAR/TEXT/BLOB）真实占用字节数，**按列逆序存放**，只记非 NULL 列；长度 <255 用 1 字节、>255 用 2 字节。
2. **NULL 值列表**：可为 NULL 的列各占 1 个二进制位，**同样逆序**；位为 1 表示该列值为 NULL；位数不足整字节时**高位补 0**。列全 NOT NULL 则该列表不存在。
3. **记录头信息**：固定 **5 字节 = 40 位**，承载删除标记、记录类型、下条记录偏移等（详见 1215-record-header）。
4. **真实数据 + 隐藏列**：用户列数据（NULL 值不占此处空间），外加 DB_TRX_ID(6B)、DB_ROLL_PTR(7B)，无主键时追加 DB_ROW_ID(6B)。

## 版本与兼容性
| 部分 | 是否可缺省 |
|------|------------|
| 变长长度列表 | 无非变长列则无 |
| NULL 列表 | 全 NOT NULL 则无 |
| 记录头 | 固定 5 字节 |

```text
COMPACT 行布局：
[变长字段长度列表(逆序)] [NULL值列表(逆序)] [记录头 5B] [真实列数据 + 隐藏列]
```

## 总结与追问预判
核心：**四段式、前两段逆序存放（为向左读还原列序）、NULL 仅占 1 bit、记录头固定 5 字节**。追问常接「记录头 40 位分别是什么」（见 1215-record-header）。
