# 1828 进程间通信选型深挖

> 分类：内存与 OS | 难度：L3 | 题型：深挖 | 频率：中 | 关键词：**选型矩阵** / **速度梯度** / **跨机能力** / **同步成本**
> 原文锚点：第 1~50 段「九大IPC方式…共享内存最快/套接字跨网…信号vs信号量…按场景选型」

## 思路与架构
IPC 选型本质是三维权衡：**速度**（是否零拷贝）、**作用域**（亲缘/本机/跨网）、**复杂度**（是否自带同步、是否要格式化）。
- 最快且本机：共享内存（零拷贝，但要自管锁）。
- 最简单流式：管道（匿名亲缘/命名跨进程）。
- 结构化投递：消息队列（按类型，有长度与拷贝开销）。
- 跨网络：套接字 / RPC（能力最强，延迟最高）。
- 通知与同步：信号（事件）、信号量（互斥）。

## 方案取舍
```text
IPC 选型矩阵（按需取列）
──────────────────────────────────────────────────────────
方式            速度        作用域        自带同步    典型场景
匿名管道        中         亲缘进程      否          父子数据流(shell |)
命名管道        中         本机任意      否          持久通道
消息队列        中(拷贝)   本机          是(内核)    按类型投递
共享内存        最快(零拷) 本机          否(自管)    大块高频共享
信号            异步通知    本机          否          异常/事件
信号量          同步原语    本机          是          临界区/生产者消费者
套接字          较慢(网)   本机/跨网     否          网络服务
内存映射文件    快          本机          否          文件内容共享
RPC             较慢(网)   跨网          否          远程函数调用
```

## 答题技巧
```text
面试话术（先总后分，再点坑）：
1. 前提：用户空间独立→IPC 走内核（共享内存除外，直映射）
2. 速度梯度：共享内存 > 管道/队列 > 套接字/RPC
3. 信号 vs 信号量：通知(异步单向) vs 同步(计数P/V)，别混
4. 共享内存坑：最快但要信号量配锁，否则竞态
5. 跨网需求：直接上套接字/RPC；本机高频大块用共享内存
```

## 细节与核心 API

```bash
# 管道（匿名）：父子进程，单向  pipe(2)
# 命名管道 FIFO：无亲缘关系也可  mkfifo /tmp/p && cat /tmp/p
# 消息队列：ipcmk -Q；ipcs -q 查看（内核持久，注意清理）
# 共享内存：最快（零拷贝，需自己加锁/信号量）  ipcmk -M
# 信号：异步通知，信息量最小（kill -SIGUSR1 <PID>）
# socket：最通用，跨机/跨进程，Unix domain socket 本机最快
ipcs -a                  # 查看 System V 共享内存/信号量/消息队列
# 选型：高频大数据 -> 共享内存+信号量；请求/响应 -> socket/Unix domain；简单事件 -> 信号/管道
# Go：os/exec 用 pipe；net 包用 UnixConn；sync 原语跨 goroutine 而非跨进程
```
