# 416 字符串字面量全景（深挖）

> 分类：Go/基础语法 | 难度：L4 | 题型：体系化深挖 | 频率：中 | 关键词：**字面量语法** / **转义** / **byte/rune** / **答题技巧**

## 思路与架构
字符串字面量题的答题架构是"**两种引号 → 转义形式 → 单字符表示 → 编码**"四层：
- **引号层**：双引号(解释型,解析转义) vs 反引号(原生型,原样)。
- **转义层**：\ooo(八) / \xXX(十六) / \uXXXX / \UXXXXXXXX，同码值等价；边界八进制引号非法。
- **字符层**：Go 无 char，单引号字符是 byte(uint8)/rune(int32) 码值；中文用 rune。
- **编码层**：string 底层 byte 序列，中文须按 rune 遍历（见 420 间接值部）。

## 方案取舍
| 写法 | 类型 | 转义 | 典型用途 |
|---|---|---|---|
| `"..."` | string | 解析 | 普通字符串、含控制字符 |
| `` `...` `` | string | 不解析 | 正则/SQL/多行模板 |
| `'x'` | byte/rune | — | 单字符码值 |
| `byte` | uint8 | — | ASCII 字符 |
| `rune` | int32 | — | Unicode 字符(含中文) |

**取舍**：要写含大量 `\` 或换行的文本（正则、SQL）→ 反引号省转义；普通字符串 → 双引号。

## 答题技巧
1. **先抛区别**：双引号解析转义、反引号原样，一句话锁定题型。
2. **补类型**：强调两者都是 string，反引号可跨行——显出规范熟悉度。
3. **转义细节**：主动讲 \ooo/\x/\u/\U 和"八进制引号非法"边界，区分 P6/P7。
4. **接 byte/rune**：单引号字符是码值、中文用 rune，连接到 string 编码。
5. **实战举例**：反引号写正则/SQL 不用层层转义，显工程经验。

## 细节与核心 API

Go string 是只读字节序列，底层结构 `reflect.StringHeader{Data uintptr; Len int}`。字符串不可寻址取元素地址：

```go
s := "hello"
// &s[0]            // 编译错误：cannot take address of s[0]
p := unsafe.StringData(s) // 1.20+ 可取底层指针，但禁止写入
```

相同字面量是否合并由编译器/链接器决定，**不能依赖**“两个相同字面量共享同一地址”。字符串拼接产生新分配；频繁拼接用 `strings.Builder`。
