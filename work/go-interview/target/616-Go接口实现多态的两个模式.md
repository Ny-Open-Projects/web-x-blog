# 616 Go 接口实现多态的两个模式

> 分类：Go 语言基础 / 接口与多态 | 难度：L1~L2 | 题型：机制题 | 频率：高 | 关键词：**多态**/**接口切片遍历**/**多态参数**/**开闭原则**

> 原文锚点：第 1~21 段「多态=同一行为不同形态…duck 接口+两种实现…切片遍历调用同一方法…多态提高扩展性」

## 一句话总述
Go 的多态只有一条正道：**接口**。同一个方法调用，落在不同具体类型上产生不同行为。落地就两个模式：① **接口切片**——`[]Duck` 统一持有不同实现，for 循环遍历、同一调用点得到不同行为；② **多态参数**——函数收接口类型，任何新实现都能直接传入，**调用方零改动**。这就是扩展性的来源：加类型不改旧代码。

## 面试官视角
- 意图：是否能把「多态」从 OO 八股落到 Go 的具体写法——接口隐式实现 + 统一调用点。
- 分档：P5 背定义；P6 能写接口切片遍历并说清分派原理；P7 能讲扩展性本质（新增实现不改调用方=开闭原则）并对比继承式多态。
- 红旗答案：说「Go 要 implements 声明才能多态」；把多态等同于重载。
- 惊艳点：指出 Go 没有继承和重载，接口是**唯一**多态载体；用一个 append 演示「新增类型零改动调用方」 [经验]。

## 主问答
**Q（面试官原话）：** Go 语言中如何实现多态？

**A：** 多态 = 同一消息、不同响应：方法调用根据对象的具体类型产生不同行为。Go 无继承、无重载（见 614），接口是唯一载体——任何类型实现了接口全部方法，就能赋给该接口变量（隐式实现机制见 613，本卡只讲使用模式）。

1. **模式一·接口切片**：定义 `Duck` 接口，`YellowDuck`/`NormalDuck` 各自实现 `Quack`；放入 `[]Duck` 遍历调用——同一行 `d.Quack()`，黄鸭子叫 "ga-ga"，普通鸭子叫 "quack-quack" [实测]。
2. **模式二·多态参数**：`func quack(d Duck)` 收接口类型，两个不同结构体都能传进去——编译器只看「有没有 Quack」，不看「你是谁」 [实测]。
3. **扩展性验证**：追加第三种实现 `robotDuck` 到同一切片，**调用方一行不改**，新行为自动生效 [实测]——新增开放、修改关闭，多态的价值就在这。

## 关键代码
```go
package main

import "fmt"

type Duck interface{ Quack() string }

type YellowDuck struct{ Name string }
type NormalDuck struct{ Name string }

func (d YellowDuck) Quack() string { return d.Name + ": ga-ga" }
func (d NormalDuck) Quack() string { return d.Name + ": quack-quack" }

type robotDuck struct{} // 扩展：第三种实现

func (robotDuck) Quack() string { return "robot: beep" }

// 多态参数：收接口，不关心具体类型
func quack(d Duck) { fmt.Println(d.Quack()) }

func main() {
	flock := []Duck{YellowDuck{"A"}, NormalDuck{"B"}} // 接口切片
	for _, d := range flock {
		quack(d) // 同一调用点，不同行为
	}
	flock = append(flock, robotDuck{}) // 新增实现，调用方零改动
	for _, d := range flock {
		quack(d)
	}
}
```

[实测] 输出：`A: ga-ga` / `B: quack-quack` / `A: ga-ga` / `B: quack-quack` / `robot: beep` 五行齐全。

## 总结与追问预判
核心：**多态答法三步——定义（同一消息不同响应）→ 写法（接口切片 + 接口参数）→ 价值（加类型不改调用方）**。追问必往机制走：鸭子类型语义见 613，隐式实现两条路径与 nil 陷阱见 615，为什么不能靠重载见 614；策略模式是同一思想在业务代码里的应用，见 163。
