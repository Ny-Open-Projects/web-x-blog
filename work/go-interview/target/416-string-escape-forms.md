# 416 字符串字面量的转义表示形式

> 分类：Go/基础语法 | 难度：L3 | 题型：细节题 | 频率：中 | 关键词：**\ooo 八进制** / **\x 十六进制** / **\u \U unicode** / **字面量边界**
> 原文锚点：第 46~67 段「字面量四表示：\ooo(八进制)/\xXX(十六进制)/\uXXXX(小写unicode)/\UXXXXXXXX(宽unicode)；双引号内单引号合法、八进制双引号转义非法、十六进制/unicode 双引号合法」

## 一句话总述
双引号字符串里可用**转义序列**表示任意字符：八进制 `\ooo`、十六进制 `\xXX`、小写 unicode `\uXXXX`、宽 unicode `\UXXXXXXXX`（均对应字符的码值）。边界细节：**双引号内可直接含单引号**，但**八进制形式的双引号转义（如 `\42`）非法**，十六进制/unicode 形式的双引号则合法——这是易踩的编译陷阱。

## 面试官视角
- 意图：考察字符串字面量的**精确细节**，是"双引号 vs 反引号"题的延伸深挖。
- P6 能说出四种转义形式（八/十六进制/unicode）；P7 能讲清"为什么八进制双引号转义非法、十六进制合法"这一反直觉边界（八进制 `\42` 被解析为字符本身而非转义引号）。
- 红旗：以为所有进制的引号转义都一样（实际八进制形式的引号转义非法）；混淆 `\x`(1字节) 与 `\u`(2字节)/\U`(4字节) 码值宽度。
- 惊艳点：用"abc 的 ASCII 八进制是 141/142/143"举例，说明同一字符可用多种进制表示且结果相同。

## 主问答
**Q（面试官原话）：** 双引号字符串里怎么用转义表示字符？有哪些边界？
**A：**
1. **结论**：四种转义形式——`\ooo`（八进制，1~3 位）、`\xXX`（十六进制，2 位）、`\uXXXX`（小写 unicode，4 位）、`\UXXXXXXXX`（宽 unicode，8 位）。它们都按码值还原字符，结果等价。
2. **机制（边界陷阱）**：
   - 双引号内**可直接包含单引号**（`'`），合法。
   - 双引号内若写**八进制形式的双引号转义**（如 `\42`，42 是双引号的八进制码值），**非法**——Go 只把八进制序列当字符码值，不视为"转义引号"。
   - 但写**十六进制/小写u/大写U 形式的双引号**（如 `\x22`、`\u0022`）则**合法**。
   - 本质：转义符后跟八进制只表示"该码值字符"，不代表"引号转义"；要输出引号须用十六进制/unicode 或 `\"` `[经验]`。
3. **边界（码值宽度）**：`\x` 对应 1 字节、`\u` 对应 2 字节(BMP)、`\U` 对应 4 字节(全 Unicode)；`\ooo` 最高到 `\377`。

## 关键代码
```go
package main

import "fmt"

func main() {
    // 同一字符"a"(ASCII 97=八进制141=十六进制61)多种表示等价
    a1 := "\141"        // 八进制
    a2 := "\x61"        // 十六进制
    a3 := "a"
    fmt.Println(a1 == a2, a2 == a3) // true true

    // 合法：双引号内直接含单引号
    s := "it's go"
    // 合法：十六进制形式的双引号
    q := "\x22quote\x22" // 输出 "quote"
    // 非法（编译报错）：八进制形式的双引号转义
    // bad := "\42"     // 八进制 42 被当字符码值，不是转义引号
    _ = s
    _ = q
}
```

## 总结与追问预判
- 四转义：\ooo/\xXX/\uXXXX/\UXXXXXXXX；边界：八进制引号转义非法、十六/unicode 合法；\x/\u/\U 码值宽度 1/2/4 字节。
- 预判：双引号 vs 反引号 → 见 416-string-literal-quotes；单引号 byte/rune → 见 416-byte-rune-char；间接值部 → 见 420-single-block-types。
