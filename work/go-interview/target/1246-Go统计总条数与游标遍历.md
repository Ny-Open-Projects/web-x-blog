# 1246 Go 统计总条数与游标遍历：Scan 必须传地址

> 分类：数据库 / Go 工程 | 难度：L3 | 题型：代码题 | 频率：中 | 关键词：**COUNT(*)、Scan、取地址、结构体映射、游标遍历**

> 原文锚点：第 32~43、68~82 段「这个结构体里面有三个字段，ID 是 int64 类型，name 是 string 类型，age 也是 int64 类型…我们使用 SELECT COUNT(*)…需要把 sumTotal 的地址传进来，因为它获取到总条数之后需要把总条数赋值给 sumTotal，所以需要修改 sumTotal 的值，因此需要传地址…返回值是 error，如果 error 不为 nil 就说明它出错了…打印出这个表的总数，它是一千零一万九千九百九十八」

## 一句话总述
Go 统计千万级表总条数时，用 `SELECT COUNT(*)` 配合 `Scan(&变量)`——**必须传地址**，否则无法把结果写回变量；再结合 id 游标分页即可顺序遍历全表。

## 面试官视角
P6 能写查询；P7 要讲清**「为什么传 &sumTotal 而不是 sumTotal」**——因为要修改变量值必须传指针，这是 Go 值传递的直接推论；还要能说出大表 `COUNT(*)` 本身的代价与替代方案。

## 主问答
**Q（面试官原话）：** 用 Go 查这张表的总数，怎么写？为什么传的是地址？

1. **先定义结构体**：字段与表列一一对应，示例为 **ID int64、Name string、Age int64** `[源码]`。
2. **获取客户端**：通过客户端名取得已实例化的数据库对象，再执行查询 `[源码]`。
3. **统计语句**：执行 `SELECT COUNT(*) FROM 表名` 得到总条数 `[源码]`。
4. **必须传地址**：因为查询后**要把总条数赋值给变量**，需要修改变量的值，所以**必须传入变量的地址** `[源码]`。
5. **返回值是 error**：调用后返回 error，**不为 nil 即说明出错**，应打印错误信息 `[源码]`。
6. **实测结果**：示例表总数读出为 **10019998**（超过一千万，因为另外增加了数据），与终端直接 `SELECT COUNT(*)` 的结果一致 `[源码]`。
7. **遍历全表**：先取总数，再用 **id 游标法**逐页顺序取数，避免深度分页 `[经验]`。
8. **注意事项**：大表上 `COUNT(*)` 本身有成本，频繁统计应考虑缓存或近似值 `[经验]`。

## 关键代码
```go
package main

import (
	"database/sql"
	"fmt"
	"log"
)

// User 与表 userbig 的列一一对应
type User struct {
	ID   int64
	Name string
	Age  int64
}

func countTotal(db *sql.DB, table string) (int64, error) {
	var sumTotal int64
	// 必须传 &sumTotal：Scan 需要写回变量，值传递无法修改外部变量
	err := db.QueryRow("SELECT COUNT(*) FROM " + table).Scan(&sumTotal)
	if err != nil {
		return 0, err
	}
	return sumTotal, nil
}

// 游标法遍历全表：每页以 lastID 作为下一页起点，避免深度分页
func scanByCursor(db *sql.DB, pageSize int64) error {
	var lastID int64
	for {
		rows, err := db.Query(
			"SELECT id, name, age FROM userbig WHERE id > ? ORDER BY id LIMIT ?",
			lastID, pageSize)
		if err != nil {
			return err
		}
		n := 0
		for rows.Next() {
			var u User
			if err := rows.Scan(&u.ID, &u.Name, &u.Age); err != nil {
				rows.Close()
				return err
			}
			lastID = u.ID
			n++
		}
		rows.Close()
		if n == 0 {
			return nil // 取完
		}
	}
}

func main() {
	// db 为已初始化的 *sql.DB
	// total, err := countTotal(db, "userbig")

	_ = fmt.Sprint
	_ = log.Println
}
```

## 总结与追问预判
**`Scan(&x)` 传地址是 Go 值传递的必然要求**，也是面试高频送分题。追问方向通常是「千万级表遍历怎么做」——答案就是**先 COUNT 拿总量，再用 id 游标逐页取**，避免 `LIMIT offset` 深度分页（原理见 1246）。
