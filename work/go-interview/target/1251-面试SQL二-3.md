# 1251 面试 SQL（二）：取排名第二的分数技巧

> 分类：MySQL/SQL | 难度：L3 | 题型：方案题 | 频率：中 | 关键词：**排名第二**/**MAX嵌套**/**排除最高**/**ORDER BY LIMIT**/**成绩排名**
> 原文锚点：第 44~56 段「成绩表找排名第二语文成绩：先找最高、再 成绩<最高 取 MAX = 第二；排名第一用 ORDER BY DESC LIMIT 1 或 MAX」

## 一句话总述
取**排名第一**简单：`ORDER BY 成绩 DESC LIMIT 1` 或 `MAX(成绩)`。取**排名第二**有个巧法：先算出最高分，再在「成绩 < 最高分」的范围内取 `MAX`——排除掉第一后剩下的最大即第二。避免用 `LIMIT 1 OFFSET 1`（并列时会错位）。

## 面试官视角
- 考察意图：能否用「排除极值再取极值的嵌套」拿到第 N 名，而非依赖 OFFSET（并列会错）。
- 分档：P5 知 ORDER BY LIMIT 取第一；P6 能写 `MAX(成绩) WHERE 成绩 < (SELECT MAX)` 取第二；P7 知 `LIMIT 1,1` 并列错位、窗口函数 `ROW_NUMBER/DENSE_RANK` 更准。
- 红旗答案：用 `LIMIT 1 OFFSET 1` 取第二（并列同分时错位）；忽略并列排名语义。
- 惊艳点：点出「嵌套 MAX 排除法对并列稳健」，以及「现代写法用窗口函数 `DENSE_RANK()=2` 明确并列语义」 [经验]。

## 主问答
**Q（面试官原话）：** 怎么查排名第二的成绩？
**A：**
1. **第一名的取法**：`ORDER BY score DESC LIMIT 1` 或 `SELECT MAX(score)` 直接取最高 [经验]。
2. **第二名的巧法**：先取最高分，再在「成绩 < 最高分」范围取 `MAX`——排除第一后剩下的最大即第二 [经验]。
3. **并列与窗口函数**：`LIMIT 1 OFFSET 1` 在并列同分时错位；现代写法用窗口函数 `DENSE_RANK()=2` 表达「并列第二」更准 [经验]。

## 总结与追问预判
「排除极值再取极值」是经典取第 N 名技巧。面试常追问「并列怎么算排名」→ 答「ROW_NUMBER（不并列）/RANK（跳号）/DENSE_RANK（不跳号）三语义」。

## ⚠️ 原文纠错
1. 事实核校： [经验] 第一名 MAX/LIMIT1、第二名 <MAX 再 MAX、OFFSET 并列错位、窗口函数——均正确。
2. 崩坏词归一：源码将若干术语音译为崩坏词，本卡统一为规范术语（排名、成绩、最高分、并列、窗口函数等）。

```sql
-- 排名第一（语文）
SELECT MAX(chinese) FROM score;
SELECT chinese FROM score ORDER BY chinese DESC LIMIT 1;

-- 排名第二：先排除最高，再取剩下的最大
SELECT MAX(chinese) AS second
FROM   score
WHERE  chinese < (SELECT MAX(chinese) FROM score);

-- 并列语义用窗口函数更准（DENSE_RANK 不跳号）
SELECT chinese FROM (
  SELECT chinese, DENSE_RANK() OVER (ORDER BY chinese DESC) rk FROM score
) t WHERE rk = 2;
-- 注：LIMIT 1 OFFSET 1 在并列同分时错位，不推荐用于排名
```
