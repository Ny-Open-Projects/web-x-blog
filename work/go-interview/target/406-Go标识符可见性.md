# 406 Go 标识符可见性：大小写决定导出

> 分类：Go 基础 | 难度：中 | 题型：原理 | 频率：高 | 关键词：**可见性、导出、大写开头、包内包外、结构体字段**

> 原文锚点：第 5~30 段「函数变量结构体大小写可见性、结构体字段方法同样受限、包内全可见」

## 一句话总述
Go 用「首字母大小写」控制可见性：**小写开头**的函数、变量、常量、结构体、结构体字段与方法**只能在本包内访问**；**大写开头**的才能被其他包访问。结构体本身导出、但字段或方法小写时，那些字段/方法在包外同样不可访问。而在包内部，无论大小写都能访问。

## 面试官视角
可见性是「如何使用内部包」的铺垫。考官看你能不能讲清两层：① 顶层标识符（函数/变量/常量/结构体）大小写决定能否跨包；② **结构体字段与方法也遵循同一规则**——这是最常被忽略的一点。能举「导出结构体但小写字段在包外赋值报错」的例子最稳。

## 主问答
**Q（面试官原话）：** Go 里怎么控制一个变量或函数能不能被其他包访问？

1. **顶层标识符**：小写开头的函数/变量/常量/结构体只能在本包内访问；大写开头的可被其他包导入访问。
2. **结构体字段与方法**：即使结构体名大写（已导出），其**小写字段或小写方法仍只能在包内访问**——包外给小写字段赋值会报「未导出」错误。
3. **连带影响**：小写结构体在包外既不能实例化，也无法调用其方法（连入口都没有）。
4. **包内无限制**：在同一个包内，大写与小写的常量、变量、结构体、字段、方法都可以访问。

|------|----------|----------|
| 包外 | 可访问 | 不可访问 |
| 包内 | 可访问 | 可访问 |

## 关键代码
```go
package pkg1

type TestStruct1 struct {
    Field1 string // 导出，包外可用
    field2 string // 未导出，仅包内可用
}
```

## 总结与追问预判
核心：**大小写即导出开关，字段与方法同样受限，包内一切可见**。追问必接「如何限制整个包被外部导入」（见 406）。
