# 1828 共享内存、信号与信号量

> 分类：内存与 OS | 难度：L3 | 题型：机制题 | 频率：中 | 关键词：**共享内存** / **信号异步** / **信号量P-V** / **互斥同步** / **最快IPC**
> 原文锚点：第 21~42 段「共享内存最快需自管同步…信号异步软中断…信号量P-V操作同步互斥」

## 一句话总述
共享内存允许多进程映射同一块物理内存，是**最快的 IPC**（零拷贝），但需自管同步互斥；信号是异步软中断（通知事件、单向、不可回复）；信号量是同步互斥机制（P/V 操作改计数器，可二元可计数，常配共享内存用）。

## 面试官视角
- 意图：是否分得清"信号"（事件通知）与"信号量"（同步原语），以及共享内存为何快却要配锁。
- P5 知共享内存最快、信号是通知；P6 说清信号量 P/V 与共享内存配锁；P7 知信号异步、信号量用于临界区/生产者消费者。
- 红旗：把信号当成信号量；以为共享内存自带同步。
- 惊艳点：信号是"软中断"、处理单向（收方不能回信号）；信号量是"计数器"、P 操作≤0 即阻塞——二者目的完全不同 `[经验]`。

## 主问答
**Q（面试官原话）：** 共享内存为什么最快？信号和信号量有什么区别？
**A：**
1. **共享内存最快**：多进程直映射同一物理内存，数据无需在进程间复制（免用户态↔内核态拷贝），但必须自管同步/互斥（否则竞态）`[源码]`。
2. **信号=异步通知**：内核中断目标进程正常流程转去执行信号处理函数，单向（收方不能回复），常用于异常/简单事件。
3. **信号量=同步互斥**：维护计数器，P 操作减一（≤0 则阻塞加锁）、V 操作加一（解锁），可二元或计数，用于临界区互斥、生产者消费者。
4. **配合**：信号量常与共享内存搭配，弥补共享内存"无自带同步"的短板。

## 关键代码
```go
// 示意，未验证：Go 用 signal.Notify 注册信号处理（信号=异步通知的落地）
package main
import ("fmt"; "os"; "os/signal"; "syscall")
func main() {
    ch := make(chan os.Signal, 1)
    signal.Notify(ch, syscall.SIGINT) // 捕获 Ctrl+C 信号
    fmt.Println("等待信号...")
    s := <-ch
    fmt.Println("收到信号:", s) // 异步中断后转入此处处理
}
```

## 总结与追问预判
- 共享内存最快需配锁；信号=异步通知、信号量=同步互斥（P/V）；二者不可混。
