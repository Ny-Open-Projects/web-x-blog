# 1254 缓存三大异常全景：穿透 / 雪崩 / 击穿（深卡）

> 分类：Redis · 缓存异常 | 难度：L3 | 题型：综合题 | 频率：高 | 关键词：**穿透**/**雪崩**/**击穿**/**三兄弟对比**/**防回源风暴**
> 原文锚点：第 1~36 段「缓存穿透(查不存在)/雪崩(大量同时失效或集群宕机)/击穿(单热点失效瞬间) 的成因与解法」

## 思路与架构
缓存异常"三兄弟"常被混为一谈，本质区别在**触发条件**与**作用的 key 范围**：

| 异常 | 触发条件 | 作用范围 | 根因 | 解法主线 |
| --- | --- | --- | --- | --- |
| **穿透** | 查**根本不存在**的数据 | 单个非法 key | 缓存/DB 皆无，每次直击 DB | 让"不存在"也别打 DB（空值缓存/布隆/校验） |
| **雪崩** | **大量 key 同时失效**或集群宕机 | 批量 key | 集体失效瞬间冲垮 DB | 错峰（TTL 抖动）+ 兜底（多级）+ 保护 DB（熔断降级） |
| **击穿** | **单个热点 key 失效瞬间** | 单热点 key | 并发回源风暴 | 只回源一次（锁/singleflight）或不阻塞读（逻辑过期） |

记忆口诀：**穿透=没这数据，雪崩=全没了，击穿=红的没了**。

## 方案取舍
| 解法 | 适用异常 | 收益 | 代价/注意 |
| --- | --- | --- | --- |
| 空值缓存(短TTL) | 穿透 | 简单直接 | TTL 要短防脏；占内存 |
| 布隆过滤器 | 穿透 | 内存省、拦截彻底 | 有误判率；需预置 key |
| TTL 随机抖动 | 雪崩 | 错峰失效 | 仍可能偶发重叠 |
| 多级缓存 | 雪崩/击穿 | 本地兜底削峰 | 一致性更复杂 |
| 熔断降级 | 雪崩 | 保 DB 核心 | 部分请求拿不到数据 |
| 互斥锁/singleflight | 击穿 | 只回源一次 | 锁有等待；singleflight 更优 |
| 逻辑过期 | 击穿 | 读不阻塞 | 短期可能返回旧值 |

**取舍总纲**：穿透治"不存在"、雪崩治"集体失效"、击穿治"单点并发回源"——三者解法不通用，先判类型再下药 `[经验]`。

## 答题技巧
- 被问"缓存穿透/雪崩/击穿区别"：先抛对比表的三列（触发条件/范围/根因），再各给一招主打解法，最后补"雪崩也含集群宕机、需高可用"。
- 被问具体某一异常：用对应专项卡的主问答（穿透 `1254-cache-penetration`、雪崩 `1254-cache-avalanche`、击穿 `1254-cache-stampede`）。
- 边界声明：本卡是三兄弟的**对比总纲与选型表**，不重述各异常的内部论证；缓存一致性（Cache-Aside/双删）归 `1261-*`、秒杀链路缓存设计归 `193-*`、秒杀高可用（限流防雪崩）归 `196-seckill-ha.deep`。本卡仅做整合与边界声明。

## 细节与核心 API

**击穿（单热点失效瞬间并发回源风暴）→ singleflight 只回源一次：**

```go
var g singleflight.Group
val, _, _ := g.Do(key, func() (any, error) {
    if v, ok := cache.Get(key); ok { // 其他并发直接拿同一结果，不重复打 DB
        return v, nil
    }
    v := db.Load(key)
    cache.Set(key, v, ttl)
    return v, nil
})
```

**穿透（查不存在的数据）→ 布隆过滤器拦截 + 空值短 TTL 兜底：**

```go
if !bloom.MayContain(id) { // 不存在直接挡在缓存/DB 之前
    return nil, ErrNotFound
}
if v, ok := cache.Get(key); ok {
    return v, nil
}
v := db.Load(key)
if v == nil { // 查 DB 也无 → 写短 TTL 空值，防重复打 DB
    cache.Set(key, "", time.Minute)
}
```

**雪崩（大量 key 同时失效）→ TTL 加随机抖动错峰：**

```go
ttl := baseTTL + time.Duration(rand.Int63n(int64(jitter))) // 错峰失效，避免集体过期冲垮 DB
```
