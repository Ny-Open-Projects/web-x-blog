## 一句话总述
应对 Go runtime 类面试题，**最有效的一招是提前准备**：这类题考点固定，"三分靠实力、七分靠准备"——除非实力碾压，否则充分准备才是过关杀手锏；而"有效准备"的判据是**经得起检验**（能流畅答出、而非看完课就以为会了）。

## 面试官视角
这是一道"面试方法论"题。面试官不在考你 runtime 细节，而在看你是否具备**体系化备考**的意识——能否把庞杂的 runtime 知识组织成可复述的体系。

## 主问答
**Q（面试官原话）：** Go runtime 这类问题怎么准备？

**A：**

1. **提前准备是核心**：runtime 面试题考察内容相对固定（调度/内存/GC/反射等），提前把高频题答案背熟，机会青睐有准备的人——"三分实力、七分准备"。
2. **有效准备的标准**：不是"看完课"，而是**经得起检验**；无效准备=自以为懂，有效准备=能当众流畅讲出。
3. **为什么重要**：技术面试纯拼技术储备，充分准备能在同等实力下显著提升通过率，是性价比最高的杠杆。
