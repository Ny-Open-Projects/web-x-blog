# 1012 自旋锁深挖

> 分类：Go / 并发 / 锁 | 难度：L3 | 题型：深挖 | 频率：中 | 关键词：**忙等** / **CAS** / **CPU 代价** / **基准测试** / **选型**
> 原文锚点：第 1~48 段「自旋锁实现(atomic CAS忙等)；与互斥对比(忙等vs睡眠)；选型(短→自旋/读多→读写/都多→互斥)；Mutex快路径CAS；读写锁写锁不等价互斥；基准测试」

## 思路与架构
自旋锁 = "用户态无锁思路 + 原子 CAS 轮询"，与互斥锁（内核态/调度器睡眠）是两条路线；选型本质是"用 CPU 空转换低延迟"还是"让出 CPU 等唤醒"。

## 方案取舍
```text
锁选型矩阵：
──────────────────────────────────────────────────────────
场景                  选什么          理由
极短临界区           自旋锁          免线程切换，忙等更优
不确定持有时间       互斥锁/读写锁    稳，不空耗 CPU
读操作明显多         读写锁          读锁不互斥读，并发高
读和写都频繁         互斥锁          读写锁写锁更重、读被写阻塞概率高
高竞争/长持有        互斥锁          自旋会空转浪费 CPU

实现代价：
自旋锁   → atomic CAS 忙等，无系统调用，调度器无感
互斥锁   → 先 CAS 快路径，失败走 sema 睡眠（sync.Mutex）
读写锁   → 底层含互斥锁，写锁更重，不等价互斥锁
```

## 答题技巧
```text
面试话术（先实现，再对比，后选型）：
1. 实现：int32 状态 0/1，Lock 用 for+CAS 自旋，Unlock 用 store 置0
2. 对比：自旋忙等(占CPU) vs 互斥睡眠(让CPU)；短临界区自旋优
3. 选型：短→自旋 / 读多→读写 / 读写都多或不确定→互斥
4. 底层：Mutex 先 CAS 快路径；读写锁写锁底层含互斥故更重、不等价互斥
5. 基准：互斥写操作明显优于读写锁写锁（实现复杂度差异）
6. 收尾：自旋锁与 runtime M 自旋找 G 同源不同层，都是短促忙等换低延迟
```

## 细节与核心 API

**自旋锁最小实现**（int32 状态 + atomic CAS 忙等，无系统调用，调度器无感）：

```go
type SpinLock int32

func (l *SpinLock) Lock() {
    for !atomic.CompareAndSwapInt32((*int32)(l), 0, 1) {
        // 忙等：占 CPU 自旋，不做系统调用、不睡眠
    }
}
func (l *SpinLock) Unlock() {
    atomic.StoreInt32((*int32)(l), 0)
}

// Go 1.19+ 用 atomic.Bool 更直观：字段不可直接访问，从源头消灭混用
type SpinLock2 struct{ flag atomic.Bool }
func (l *SpinLock2) Lock()   { for !l.flag.CompareAndSwap(false, true) {} }
func (l *SpinLock2) Unlock() { l.flag.Store(false) }
```

**基准测试骨架**（用 `RunParallel` 压并发，临界区必须极短才有意义）：

```go
func BenchmarkSpin(b *testing.B) {
    var l SpinLock2
    b.RunParallel(func(pb *testing.PB) {
        for pb.Next() {
            l.Lock()
            // 极短临界区（如一次计数器自增）
            l.Unlock()
        }
    })
}
// 对照：sync.Mutex 写操作明显优于读写锁写锁（读写锁写锁底层含互斥，更重）
```

**选型 API 对照**：

```text
场景                  调什么                        关键 API
极短临界区           自旋锁                        SpinLock.Lock/Unlock
不确定持有时间       互斥锁/读写锁                  sync.Mutex / sync.RWMutex
读明显多            读写锁                        RWMutex.RLock/RUnlock
高竞争/长持有        互斥锁                        sync.Mutex（避免空转）
```
