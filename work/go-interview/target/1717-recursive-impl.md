# 1717 快速排序的递归实现与参数设计

> 分类：排序算法 | 难度：中 | 题型：代码实现 | 频率：高 | 关键词：**递归、三参数、low/high、终止条件、入口**

> 原文锚点：第 11~17 段「递归函数三参数与递归终止」

## 一句话总述
快排递归实现封装一个带三参数的内部函数：待排序数组、扫描起始下标 low、结束下标 high；当 low < high 时先 partition 拿基准最终下标，再对左右区间递归；否则直接返回（递归终止）。

## 面试官视角
这题考「递归边界」与「区间划分」的正确性。一半人会漏写 low < high 的终止判断，或把递归区间写错（含了 pivot 导致死循环）。能正确写出三参数与左右区间的人是合格线。

## 主问答
**Q（面试官原话）：** 快排的递归函数怎么设计？终止条件是什么？

1. **三参数签名**：`quickSort(a []int, low, high int)`——数组 + 当前处理区间 [low, high]，调用方入口传 `quickSort(a, 0, len(a)-1)`。
2. **终止条件**：`if low < high` 才进入分区与递归；一旦 `low >= high`（区间长度 ≤1）直接返回，这是递归 base case，缺它必栈溢出。
3. **分区后双递归**：先 `p := partition(a, low, high)` 得到基准最终位置，再 `quickSort(a, low, p-1)` 与 `quickSort(a, p+1, high)`——左右区间都**不含 pivot**，否则无限递归。

## 版本与兼容性
| 版本 | 行为 |
|------|------|
| 递归版 | 简洁易读；递归栈空间 O(log n)~O(n) |
| 非递归版 | 显式栈模拟，栈空间变 O(n) 但可控（见 1717-optimization） |
| Go sort | 标准库内部已做小数组/三数取中等优化 |

## 关键代码
```go
func quickSort(a []int, low, high int) {
    if low < high {
        p := partition(a, low, high)
        quickSort(a, low, p-1)
        quickSort(a, p+1, high)
    }
}
```

## 总结与追问预判
核心：**三参数 + low<high 终止 + 递归区间排除 pivot**。追问常要求现场写 partition（见 1717-partition），或问「为什么 pivot 不能进递归区间」。回答强调 base case 防栈溢出。
