# 409 init 函数的作用与使用边界

> 分类：Go 基础 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**init**/**包初始化**/**无参无返回值**/**可重复定义**/**中间件初始化**

> 原文锚点：第 1~9 段「init 的作用与常见用途」

## 一句话总述
`init` 函数用于在**程序执行前**完成包的初始化，例如初始化包内变量；工程中常用来初始化 HTTP Server、数据库、缓存等中间件。它没有参数与返回值、不能被显式调用，由运行时自动触发，且在同一个文件里可以重复定义多个。

## 面试官视角
这题被归类为「基础但高频」。考官要的不是一句「初始化用的」，而是三条硬规则：**无参无返回值**、**不能显式调用**、**同文件可重复定义**。能再补一句工程风险（init 里做 I/O 难处理错误），就是加分项。

## 主问答
**Q（面试官原话）：** init 函数是干什么的？什么时候执行？

1. **用途**：用于程序执行前做包的初始化，例如初始化包内部的变量。
2. **常见场景**：项目工程中常用来做 HTTP Server、数据库、缓存等中间件的初始化。
3. **签名固定**：没有参数也没有返回值，不能像普通函数那样被调用，只能由运行时自动执行。
4. **可重复定义**：与自定义普通函数不能重名不同，`init` 在**同一个文件里可以定义多个**，按定义顺序依次执行。
5. **执行时机**：所有 init 函数都在 `main` 函数之前执行完毕，因此适合放启动前置逻辑。

## 版本与兼容性
| 特性 | 普通函数 | init |
|------|----------|------|
| 可否重名 | 不可 | 可（同文件多个） |
| 参数/返回值 | 自定义 | 无 |
| 调用方 | 显式调用 | 运行时自动 |
| 执行时机 | 调用时 | main 之前 |

## 关键代码
```go
package main

import "fmt"

var version = detect() // 包级变量先于 init 初始化

func detect() string { return "v1" }

func init() { fmt.Println("init 1:", version) } // 同一文件可多个，按顺序执行
func init() { fmt.Println("init 2:", version) }

func main() { fmt.Println("main") }
```

## 总结与追问预判
核心：**init 做包初始化、无参无返回值、不能调用、可重复定义、先于 main**。追问常拐向「执行顺序」「能不能在里面连数据库」，备好顺序规则与「不推荐放外部 I/O」两句。

## ⚠️ 原文纠错
1. 事实核校： [经验] 原文只说「用于程序执行前做包的初始化」——本卡补全三条硬规则：**无参数无返回值**、**不能被显式调用**、**同一文件内可重复定义多个**（普通函数不可重名）。
2. 事实核校： [经验] 原文提到用 init 做数据库、缓存等中间件初始化——需提示工程风险：init 无法返回 error，外部依赖失败只能 panic；且会拖慢启动、在测试中也被强制触发，更推荐显式初始化函数并显式传依赖。
3. 崩坏词归一：源码将 init / 包 / main.go 等音译为多组崩坏词，本卡统一为规范术语。
