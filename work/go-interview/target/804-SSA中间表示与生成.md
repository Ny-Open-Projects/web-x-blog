# 804 SSA 中间表示与生成

> 分类：工程化与编译 | 难度：L3 | 题型：原理题 | 频率：中 | 关键词：**SSA** / **GOSSAFUNCTION** / **静态单赋值**
> 原文锚点：第 42~48 段、第 112~118 段「SSA 是静态单赋值…GOSSAFUNCTION 导出 ssa.html」

## 一句话总述
SSA(Static Single Assignment) 是每个变量只被赋值一次的底层中间表示，便于做机器无关优化；`GOSSAFUNCTION=main go build` 可导出 `ssa.html` 可视化每步。

## 主问答
**Q（面试官原话）：** 什么是 SSA？编译为什么要在 SSA 上做优化？
**A：**
1. **结论**：SSA 是"每个变量仅被赋值一次"的中间表示，让数据流分析更简单，中端优化(DCE、循环不变量外提等)在此完成 `[源码]`。
2. **机制**：`ssa` 包把 `ir` 降级成 SSA 并做架构无关优化，再经各 arch 后端(`amd64`/`arm64`) lowering 成 genssa→机器码写入 `obj` `[源码]`。
3. **边界**：SSA 优化与 CPU 架构无关；真正对 x86_64/arm 的取值靠近、寄存器分配在后端 lowering 阶段才做。
**加分层：** `GOSSAFUNCTION=main go build` 导出 ssa.html，是排查"为什么没内联/没消除"的利器。
