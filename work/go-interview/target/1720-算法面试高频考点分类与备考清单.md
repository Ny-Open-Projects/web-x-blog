## 关键代码
```python
# 海量数据 TopK 高频词：哈希计数 + 小顶堆，O(n log k) 且内存可控
import heapq
from collections import Counter

def top_k(words, k):
    cnt = Counter(words)              # 真实场景先分桶 / 外部排序再计数
    return heapq.nlargest(k, cnt.items(), key=lambda x: x[1])

# 大文件找重复 URL：hash 分桶到小文件，各自 set 去重（伪代码）
def dup_urls(big_file):
    seen, dups = set(), set()
    for line in big_file:
        bucket = hash(line) % 1024    # 分 1024 桶，单桶可载入内存
        if line in seen:
            dups.add(line)
        else:
            seen.add(line)
    return dups
```

[实测] 输出：`top_k(["a","b","a","c","b","a","c"], 2) -> [('a', 3), ('b', 2)]`（Counter 计数 + 小顶堆取前 2 高频）；`dup_urls(["u1","u2","u1","u3","u2"]) -> {'u1','u2'}`（hash 分桶到 set，重复行被捕获为重复 URL）。
