# 181 后端岗 Linux 面试备考路线（五大知识域）

> 分类：Linux 基础 | 难度：L2 | 题型：备考 | 频率：高 | 关键词：**grep/awk/find/top**/**Shell**/**系统管理**/**内核参数**

> 原文锚点：第 74~89 段「后端为何要会 Linux / 面试需掌握的知识点」

## 一句话总述
后端代码最终都跑在 Linux 上，排查线上问题、搭建开发环境绕不开它；备考按**五大域**推进：基本概念与工作原理、常用命令与工具、Shell 编程、系统管理与性能调优、内核编译与模块，其中命令与排查场景是高频。

## 面试官视角
非运维岗这部分占比确实不如语言与并发，但它极少以八股形式出现，而是藏在场景题里：CPU 飙高、磁盘满、连接数打满、句柄耗尽。答不出基础命令会被直接判定为「没法独立干活」。

## 主问答
**Q（面试官原话）：** Linux 知识点那么多，你怎么准备面试？

1. **第一域 概念与原理**：内核、文件系统、进程与线程、用户与用户组；再往里是进程调度、内存管理、文件系统、设备驱动的工作方式。
2. **第二域 命令与工具**：文件操作、权限、进程管理、系统监控、网络管理五类，高频考点是 grep、awk、find、top 的组合使用。
3. **第三域 Shell 编程**：变量、循环、条件判断、字符串处理、文件操作，能写出自动化脚本即可，不考复杂语法。
4. **第四域 管理与调优**：用户组、软件包、服务、网络、磁盘、日志的管理；调优手段包括内核参数、文件系统与调度策略。
5. **第五域 内核与模块**：了解内核架构与模块机制，知道某些扩展功能需要重新编译内核才能支持。

## 关键代码
```go
// Go 侧视角：把排查命令固化成巡检工具，面试时能讲出"我做过"比背命令有力
package main

import (
	"fmt"
	"os/exec"
)

func main() {
	for _, c := range [][]string{
		{"df", "-h"},        // 磁盘空间
		{"df", "-i"},        // inode 是否耗尽
		{"ss", "-s"},        // 连接数概览
		{"top", "-bn1"},     // CPU/内存快照
	} {
		out, err := exec.Command(c[0], c[1:]...).CombinedOutput()
		fmt.Printf("$ %v -> err=%v\n%s\n", c, err, out)
	}
}
```

## 总结与追问预判
核心：**五大域 + 排查场景化**。追问常拐向「CPU 飙高怎么查」「磁盘满了怎么定位」，备好 top → pidstat → perf 与 df -h → df -i → du 两条链路。
