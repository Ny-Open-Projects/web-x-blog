## 方案取舍
- **链式 vs 顺序**：链式灵活、易动态增删但指针开销；顺序（数组）紧凑、适合完全二叉树/堆的 O(1) 父子映射，但非完全树有空洞浪费。
- **三序记忆**：前中后唯一区别是中间节点访问时机；中序遍历 BST 恰为升序，是重要性质。
- **插入平衡**：简单递归 insert 不自动平衡，退化需 AVL/红黑树。

## 细节与核心 API

```go
type TreeNode struct { Val int; Left, Right *TreeNode }
// 前序（根左右）
func preorder(n *TreeNode, out *[]int) {
    if n == nil { return }
    *out = append(*out, n.Val); preorder(n.Left, out); preorder(n.Right, out)
}
// 中序（左根右）——BST 中序即有序
func inorder(n *TreeNode, out *[]int) {
    if n == nil { return }
    inorder(n.Left, out); *out = append(*out, n.Val); inorder(n.Right, out)
}
// 层序（BFS，队列）
func levelOrder(root *TreeNode) [][]int {
    if root == nil { return nil }
    var res [][]int; q := []*TreeNode{root}
    for len(q) > 0 {
        var lv []int; nq := q[:0:0]
        for _, n := range q { lv = append(lv, n.Val); if n.Left != nil { nq = append(nq, n.Left) }; if n.Right != nil { nq = append(nq, n.Right) } }
        res = append(res, lv); q = nq
    }
    return res
}
// 递归易写但深树可能栈溢出（Go 协程栈会复制扩容，足够深才触发）；超深用显式栈迭代
```
