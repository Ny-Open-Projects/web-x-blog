# 新博客生成规范（blog）

## 总体要求（用户需求 4-7）
1. 基于原 blog 内容 + 11 种语言代码生成，**用上所有语言**
2. **主语言 TypeScript 详细教学**，其他 10 语言作附录（完整可运行代码）
3. 系统阐述**关键思想 + 关键 API**（主语言的 API 表格）
4. **保留每题每种语言的所有解法**：正文详解每种思路；附录给代表实现 + 仓库内全部解法文件清单
5. **由浅入深、新手易懂**：先直觉再代码，逐行拆解
6. **动态算法图**：每篇 1 个动画 SVG（内嵌 inline + 存 animation.svg）
7. **编号 = 课程顺序**（_meta/curriculum.json 的 order），标题 `NNN · 题名（阶段 · 位置）`

## 目录与文件
`blog/{NNN}_{题名}/index.md` + `animation.svg`

## index.md 结构模板（参照 blog/001_二叉树的最大深度/index.md）
```
# NNN · 题名（专题 · 定位）
> 难度 ⭐｜LeetCode XXX｜学习阶段：第N阶段 · 专题
## 1. 题目描述（+图示示例）
## 2. 先建立直觉（讲故事，不谈代码）
## 3. 动态算法图（inline SVG）
## 4. 解法一（最直观）：思路 + TS 代码逐行拆解表 + 关键 API 速查表
## 5. 解法二（更优/更优雅）：同上
## 6. 解法对比表（复杂度/代码量/扩展性/面试叙事）
## 7. 关键思想总结（可迁移，3-4 条）
## 8. 附录：11 种语言完整实现（Python/Go/Java/Rust/Lua/C/C++/R/Zig/Dart 每语言代表解 + 全部解法文件名清单）
## 9. 面试惊艳点（复杂度主动报、扩展迁移、追问防守、一句话记忆）
尾注：原 CSDN blog 链接 + 上下篇导航
```

## 动画 SVG 生成
- 用 `_tools/svg_anim.py`（现有 bubble_sort/dfs_tree 生成器，可扩展新算法动画）
- 或手写 inline SVG：`<svg>` 内嵌 `<style>` CSS keyframes，暗色背景 #0F172A，节点蓝 #4A90D9，高亮黄 #FACC15，成功绿 #34D399
- 动画必须"自动循环播放"，体现算法核心步骤（比较/交换/访问/入队等）

## 内容来源优先级
1. 算法逻辑：`dsa/ts/{topic}/{problem}/`（已验证 PASS，内嵌用例）
2. 背景知识/叙事：`blog/{blog_id}/index.md`（原 CSDN 文章）
3. 各语言代码：`dsa/{lang}/{topic}/{problem}/`（新 7 语言生成后）
4. 编号与难度：`_meta/curriculum.json`

## 质量红线
- 附录代码必须与仓库文件一致（可运行输出 PASS）
- 复杂度必须标注（时间/空间）
- 每篇都有"面试惊艳点"
- 中文行文，新手友好，不用未解释的术语
