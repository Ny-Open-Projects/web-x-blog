# LeetCode 344. 反转字符串 (ts)

> 来源：[Wang's Blog](https://blog.csdn.net/tyro_java/article/details/145116781)
> 语言：**ts**（博客原文）

## 题目描述

- - 
- 编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 s 的形式给出
- - 
- 不要给另外的数组分配额外的空间，你必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题

## 示例

```
输入：s = ["h","e","l","l","o"]
输出：["o","l","l","e","h"]

输入：s = ["h","e","l","l","o"]
输出：["o","l","l","e","h"]

输入：s = ["H","a","n","n","a","h"]
输出：["h","a","n","n","a","H"]

输入：s = ["H","a","n","n","a","h"]
输出：["h","a","n","n","a","H"]
```

## 提示

- 1 <= s.length <= 
 1
 0
 5
 10^5
 105
- s[i] 都是 ASCII 码表中的可打印字符
