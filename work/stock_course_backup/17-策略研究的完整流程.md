# 第 17 章 策略研究的完整流程

> 本章目标：第 12 章教你"跑一个回测"，这一章教你"做一次完整的研究"。
> 差别是：回测是一个动作，研究是一条流水线——有假设、有登记、有验证、有放弃标准。
> 这是把"凭感觉试"变成"工程化研究"的那一步。

---

## 17.1 为什么需要流程

先看两种研究方式的差别：

| | 无流程（多数人） | 有流程（少数人） |
|---|---|---|
| 起点 | "我觉得 XX 可能有效" | 登记在册的、可证伪的假设 |
| 过程 | 反复调参直到结果好看 | 参数固定，只在样本外检验 |
| 产物 | 一个回测截图 | 假设登记表 + 实验记录 + 结论 |
| 结局 | 实盘亏损后不知道哪错了 | 知道策略为什么失败，或为什么成功 |

**无流程研究的最大危害**：你无法区分"策略失效"和"我研究做错了"。这两者的解法完全不同——前者该放弃策略，后者该修正流程。

---

## 17.2 七步流水线

```
① 假设登记 → ② 逻辑审查 → ③ 数据与时点 → ④ 构建与回测
→ ⑤ 样本外与稳健性 → ⑥ 纸面交易 → ⑦ 小资金实盘
```

每一步都有明确的"通过/不通过"标准。**任何一步不通过，回到上一步或放弃。**

### 第①步：假设登记

把想法写成一句**可证伪**的话：

```
错误写法："MACD 金叉应该能赚钱"（什么叫能赚？赚多少？多长时间？）

正确写法：
"在沪深300 成分股上，当 20 日均线上穿 60 日均线时买入、
下穿时卖出，在 2015–2024 年、计入万 3 佣金和最低 5 元后，
年化收益超过同期买入持有。"
```

**登记表字段**（每个假设都要有）：

```
编号：H-001
日期：2026-11-09
假设（可证伪版本）：____________
验证标准（什么叫成立）：____________
放弃标准（什么叫失败）：____________
经济学逻辑（收益从哪来）：____________
状态：待验证 / 验证通过 / 验证失败 / 放弃
```

**为什么要登记**：它是你对抗"事后修改记忆"的工具（第 9 章的后见之明偏差）。**白纸黑字写在验证之前，才作数。**

### 第②步：逻辑审查

问三个问题（与第 16.3 节的因子审问相同）：

```
① 谁在把钱输给我？（对手方是谁，他为什么愿意输）
② 这个逻辑依赖什么环境？（利率、制度、参与者结构）
③ 如果所有人都用这个策略，它还成立吗？
```

**第③问是关键**：如果答案是"不成立"，说明它的收益来自对手方的错误——错误会消失。

**在这一步放弃的想法，成本为零。这是流水线最省钱的一步。**

### 第③步：数据与时点

三个必查项（第 12 章讲过，这里是操作化清单）：

```
□ 复权方式对吗？（前复权/后复权会影响收益率计算）
□ 成分股是 point-in-time 吗？（用今天的名单回测历史 = 幸存者偏差）
□ 财报数据有公告滞后吗？（Q1 利润可能 4 月底才公布）
□ 退市股、ST 股在样本里吗？
□ 成交假设合理吗？（用 T 日收盘价做决策，必须 T+1 开盘价成交）
```

### 第④步：构建与回测

回测规则（一个假设只测一次，不许边跑边改）：

```
□ 固定所有参数（写死在配置文件里）
□ 计入：佣金 + 最低 5 元 + 印花税 + 滑点 0.1%
□ 报告：年化、最大回撤、夏普、交易次数、胜率
□ 产出实验记录（模板见 17.4）
```

### 第⑤步：样本外与稳健性

**这是多数人跳过、也是最有价值的一步。**

| 检验 | 做法 | 通过标准 |
|---|---|---|
| **样本外** | 参数只在 2015–2021 调，2022–2026 只跑一次 | 样本外收益 ≥ 样本内的 50% |
| **参数敏感性** | 参数 ±20% 各测一次 | 相邻参数结果平滑，无悬崖 |
| **分年度** | 逐年看收益 | 没有靠单一年份撑起全部收益 |
| **子样本** | 只含大盘股 / 只含震荡市 | 逻辑在子样本中方向一致 |

**样本外失败的典型样子**：样本内年化 25%，样本外 -8%。**这不是运气差，这是过拟合的确诊书。** 放弃该参数组合，回第①步重新登记假设。

### 第⑥步：纸面交易（模拟盘实盘化）

用模拟盘跑 1–3 个月，但这次和第 4 章的模拟盘不同——**目标是验证"执行"，不是验证"策略"**：

```
□ 信号出现时，你真的下得了单吗？（逆向信号最难执行）
□ 滑点比回测假设大多少？
□ 隔夜风险实际发生了几次？
```

### 第⑦步：小资金实盘

用第 8 章的仓位框架，把策略资金限制在总资金的 20% 以内，跑至少 3 个月。**实盘收益 ≥ 回测收益的 50% 才算通过。**

## 17.3 研究日志与实验记录

每个假设的验证过程，记成一份实验记录：

```
## 实验 E-001（对应假设 H-001）

日期：2026-11-09
研究问题：双均线策略在沪深300 上是否跑赢买入持有？
数据：沪深300 ETF 日线，2015-01 至 2026-10，前复权
方法：20/60 双均线，T+1 开盘价成交
成本假设：万 3 佣金 + 最低 5 元 + 滑点 0.1%

结果：
  策略年化：____%    买入持有年化：____%
  最大回撤：____%    交易次数：____
  样本外（2022–2026）年化：____%

稳健性：
  参数 15/60：____%   25/60：____%   20/50：____%   20/70：____%
  是否存在参数平原：____%

结论：假设 H-001 成立 / 不成立
未解决问题：____________
下一步：____________
```

**为什么要记录"未解决问题"**：三个月后你会忘记当时的疑虑。写下来的疑虑才会被处理。

## 17.4 什么时候放弃一个策略

多数人不会放弃策略——他们会在亏损时"再给它一次机会"。**你需要预先写死放弃标准：**

| 信号 | 行动 |
|---|---|
| 样本外收益 < 样本内的 50% | 放弃该参数组合 |
| 连续 6 个月跑输基准超过 10% | 停止实盘，重新验证 |
| 逻辑基础消失（如依赖的制度改变） | **立即放弃**，不管当前盈亏 |
| 研究过程中发现逻辑本身站不住 | 放弃（最省钱的位置） |

**放弃不是失败。** 一个假设从登记到放弃可能只花 3 小时——这 3 小时保护了你实盘里的 3 个月。

> **研究的产出不只是"有效的策略"，还包括"已被排除的想法"。后者同样值钱。**

## 17.5 程序员版：把研究当工程项目

你已经有工程习惯，直接迁移过来：

| 工程实践 | 研究对应物 |
|---|---|
| Git 版本控制 | 数据版本、参数版本、结论版本 |
| 单元测试 | 数据质量断言（无重复日期、无负价格、复权连续性） |
| CI 流水线 | 每次改参数自动重跑全部回测 |
| Code Review | 研究结论给朋友/社区看一遍，找逻辑漏洞 |
| 可复现构建 | 任何人拿你的配置文件能跑出一模一样的结果 |
| Bug 追踪 | 假设登记表 + 实验记录 |

**一个最低配置**：

```
策略仓库/
├── data/            # 数据快照（带日期戳）
├── strategies/      # 策略代码（参数写死在配置里）
├── experiments/     # 实验记录（E-001.md, E-002.md...）
├── hypotheses.md    # 假设登记表
└── README.md        # 环境与复现说明
```

**用 Git 管理 `hypotheses.md`**——每次修改假设都有 commit 记录，这就是你的"研究信用"。

---

## 17.6 一个必须警惕的病：研究上瘾

有流程之后，可能出现新的问题：**你开始享受研究本身，忘记研究是为了交易。**

| 症状 | 判断 |
|---|---|
| 回测了几十个策略，一个都没实盘 | 研究替代了行动 |
| 持续优化参数，只为看资金曲线变漂亮 | 优化本身成了奖励 |
| 数据下载了 100GB，策略写了 3 个 | 收集代替了验证 |

**解药**：给自己定配额——**每完成 3 个假设的验证，必须至少有 1 个进入纸面交易阶段**，否则停止新研究。

---

## 17.7 回测结果有多可信：统计检验入门

这是流水线的最后一道质检。前面六步保证了"过程干净"，这一步回答一个更尖锐的问题：

> **就算过程干净，我看到的这个收益，有没有可能只是运气？**

答案：**很可能。** 原因有两个，都有明确的应对方法。

### 问题一：时间太短，夏普比率本身不可靠

夏普比率（SR = 年化收益 ÷ 年化波动）是回测报告的核心指标，但它自带"测量误差"。对日频数据的近似公式：

```
夏普比率的标准误 SE ≈ √( (1 + SR²/2) ÷ T )     T = 回测年数
检验标准：SR ÷ SE > 2（约 95% 置信）才算与运气区分开
```

把常用情形算成一张表（这个表值得背下来）：

| 回测年数 T | 夏普 0.5 | 夏普 1.0 | 夏普 2.0 |
|---|---|---|---|
| 3 年 | t=0.82 ❌ | t=1.41 ❌ | t=2.00 ⚠️ 卡在线上 |
| 5 年 | t=1.05 ❌ | t=1.83 ❌ | t=2.58 ✅ |
| **10 年** | t=1.49 ❌ | **t=2.58 ✅** | t=3.65 ✅ |

**这张表在说什么**：

- 3 年回测、夏普 2.0——t 刚好等于 2.00，**卡在线上**。参数稍微动一动就会掉到线下。你在短视频里看到的"三年十倍"策略，大多属于这一类：统计上与运气无法可靠区分。
- **10 年回测、夏普 1.0 才刚刚达到"与运气区分开"的标准。** 而夏普 1.0 的策略，长期看已经是优秀水平。
- 夏普 0.5 的策略，**10 年回测 t 只有 1.49，依然不显著**——它的收益与噪音无法区分，实盘大概率归零。

**结论**：看到一个策略，先问两件事——**回测多少年？夏普多少？** 然后查这张表。两个都不过线的，不需要看任何其他细节。

### 问题二：你试了很多次，"最好的那次"必然虚高

这是更隐蔽的坑。假设你试了 100 组参数，每组的结果都是随机的（没有真实 alpha）：

```
100 次随机结果里，最好那组的夏普也会"看起来很高"
→ 这是纯数学：极值一定偏离均值，试得越多偏得越远
→ 你挑选的过程，制造了不存在的 alpha
```

这就是第 16.5 节"因子动物园"的成因：几百个发表因子绝大多数失效，**因为它们是从海量尝试里挑出来的最大值**。

学术界的应对工具叫 **Deflated Sharpe Ratio**（紧缩夏普）：把"你试了多少次"作为惩罚项，从报告的夏普里扣掉。公式复杂，但**思想可以直接实操化**：

| 你实际尝试的次数 N | 对"最优结果"的诚实折扣 |
|---|---|
| 1–5 次 | 样本外收益打 8 折 |
| 5–20 次 | 打 6–7 折 |
| **20–50 次** | **打 5 折** |
| 50–200 次 | 打 3 折，且样本外必须重新验证 |
| > 200 次 | **视为噪音，全部作废**，重新提假设 |

**你试了多少次，必须诚实记录。** 第 17.2 节的假设登记表天然就是这个账本——**H-001 到 H-0xx 的编号数量，就是你的 N**。这就是登记表除了对抗记忆偏差之外的第二个作用。

### 三条可执行的质检规则

```
规则一：显著性门槛
  SR ÷ SE > 2（用上面的表查），不达标 → 不进实盘，无论曲线多漂亮

规则二：试验次数折扣
  统计 H 编号总数 N，按上表对"最优结果"打折后再评估

规则三：把试错预算写进假设登记表
  每个假设登记时就写"本假设最多允许 ___ 次参数尝试"（建议 ≤ 10）
  超出预算还没通过 → 该假设判负，禁止继续调参
```

**规则三是治"调参上瘾"的硬约束**：它把第 12 章的过拟合警告，变成了一个可计数的红线。

### 与流水线的关系

```
第④步 回测    → 产出 SR 和 T
第⑤步 样本外  → 验证稳健性（17.2 的 50% 规则）
第⑦步 本节质检 → SR 显著性 + 试验次数折扣
三关全过 → 才有资格进入纸面交易
```

**顺序不能反**：先做本节的两分钟查表，再做昂贵的样本外验证。**多数策略在查表这一步就该被扔掉。**

---

## 本章要记住的 4 件事

1. **假设必须先登记（可证伪版本 + 放弃标准），再做验证。** 事前白纸黑字是对抗后见之明偏差的唯一工具，登记表同时是"试验次数 N"的账本。
2. **样本外检验是流水线的核心**：样本外收益 < 样本内的 50% = 过拟合确诊，直接放弃该参数组合。
3. **回测的收益要用统计检验过滤**：SR÷SE>2 才算与运气区分；试验次数 N 越大，对"最优结果"折扣越狠。
4. **放弃是被低估的产出。** 排除一个坏想法的 3 小时，保护的是实盘里的 3 个月。

## 动手做

### 练习 17-1：登记你的第一个假设（20 分钟）

把你曾经想过（或听别人说过）的一个策略，改写成可证伪版本，填进假设登记表：

```
编号：H-001
假设（可证伪版本）：____________
验证标准：____________
放弃标准：____________
经济学逻辑：____________
```

**检验**：你的验证标准里有没有"赚""有效""不错"这种模糊词？有就重写。

### 练习 17-2：为已有策略做一次样本外体检（1 小时）

拿你第 12 章跑过的双均线策略：

```
样本内（2020–2022）调参：选出表现最好的参数组
样本外（2023–2026）验证：只跑一次
样本外年化 ÷ 样本内年化 = ______%
```

**如果低于 50%**，恭喜你亲眼确认了一次过拟合——这次经验值 3 个月实盘学费。

### 练习 17-3：搭你的研究仓库（30 分钟）

按 17.5 的目录结构建一个文件夹，把 `hypotheses.md`（含 H-001）和第一个实验记录放进去，`git init` 并提交。

**目的**：让"登记假设"变成一个有仪式感的动作——有 commit 记录的动作才算数。

### 练习 17-4：给你的旧回测做一次"运气体检"（15 分钟）

找任何一个你（或别人）展示过的回测结果：

```
回测年数 T：______ 年
年化收益：______%    年化波动：______%
夏普 SR = 收益 ÷ 波动 = ______

SE ≈ √((1 + SR²/2) ÷ T) = ______
t = SR ÷ SE = ______
判定：t > 2 ？  显著 / **与运气无法区分**
```

再用 17.7 的折扣表：

```
这个策略的开发者大概试过多少组参数？N ≈ ______
诚实折扣后的年化收益 = ______%
还值得进实盘吗？______
```

**多数人做完这个练习的结论是：自己曾经心动的策略，一半过不了第一张表。** 这正是这张表的价值。
