# 第 16 章 因子投资入门

> 本章目标：理解"因子"这个量化投资的核心概念——它回答的是"长期来看，什么类型的股票赚钱"。
> 读完你会知道四个主要因子的逻辑、A 股的真实有效性，以及普通人正确的参与方式（买 Smart Beta ETF，而不是自己挖因子）。

---

## 16.1 因子是什么

**因子（factor）= 一组股票的共同特征，这类特征在长期被证明能带来超额收益或解释收益差异。**

学术脉络一句话讲完：

```
1960s  CAPM：股票收益 = 市场收益 × β
1992   Fama-French 三因子：+ 规模（小盘超额）+ 价值（低估值超额）
2015   Fama-French 五因子：+ 盈利（质量）+ 投资（保守扩张）
后来    动量、低波动……学术界登记了几百个因子（多数后来被证明是噪音）
```

**关键理解**：因子不是"炒股技巧"，它是**用数据验证过的、跨越多个市场和几十年的规律**——以及对这些规律"为什么会存在"的解释。

## 16.2 四个主要因子：逻辑与 A 股真相

### 因子一：价值（Value）

```
定义：买入 PE、PB 低的股票，卖出贵的
逻辑来源：
  ① 风险补偿——便宜的公司往往经营有麻烦，超额收益是对承担麻烦的补偿
  ② 行为偏差——人们过度追捧热门股、过度冷落落难股
```

**A 股有效性**：长期有效，但波动剧烈。A 股的价值风格会连续跑输成长风格两三年（如 2019–2020），然后大幅回归。**持有价值因子的人必须能忍受"显得很蠢"的年份。**

### 因子二：动量（Momentum）

```
定义：买入过去 3–12 个月表现最好的，卖出最差的
逻辑来源：信息扩散有速度，趋势会自我强化一段时间
```

**A 股有效性：弱，甚至反转。** 这是 A 股与美股最大的因子差异之一。

原因：A 股散户占比高、换手快，涨多了立刻被获利盘砸（中期反转明显）。**美股验证过几十年的动量因子，在 A 股经常失效。**

**给你的结论：不要照搬美股的动量策略到 A 股。** 这也是为什么第 11 章说"均线追涨"在 A 股更不可靠。

### 因子三：质量（Quality）

```
定义：买入高 ROE、低负债、盈利稳定的公司
逻辑来源：赚钱能力强的公司，长期复利更高；
         投资者对" boring 但赚钱"的公司系统性定价不足
```

**A 股有效性：较好，且回撤小。** 质量因子在 A 股熊市里防守属性突出（高质量公司在下跌中跌得少）。

**与你已有知识的连接**：第 10 章讲的 ROE、经营现金流，就是质量因子的原料。

### 因子四：低波动（Low Volatility）

```
定义：买入波动最小的股票
逻辑来源：行为偏差——投资者偏爱"彩票型"高波动股票，
         把它们炒贵，导致低波动股票反而被低估
```

**A 股有效性：长期有效，且是散户友好的因子**——低波动组合回撤小，能拿得住。

### 小市值：A 股的特别案例

必须单独讲，因为它是 A 股历史上最强的因子，也是最惨烈的教训。

```
2007–2016：A 股小市值因子收益惊人（壳价值：小公司可以借壳上市）
2017 前后：IPO 常态化 + 退市趋严 → 壳价值崩塌 → 小市值策略大幅回撤
```

**教训**：**因子的收益来源如果依赖制度套利（而非风险补偿或行为偏差），制度一变，因子就死。** 任何回测里表现最好的因子，都要先问"它的收益从哪来"。

---

## 16.3 因子的收益从哪来：两种解释

判断一个因子是否值得长期持有，就问这个问题：

| 来源 | 含义 | 持久性 |
|---|---|---|
| **风险补偿** | 你多赚的钱，是对承担某种风险的报酬（如价值股经营风险高） | **持久**——只要风险在，补偿就在 |
| **行为偏差** | 你赚的是其他投资者系统性犯错的钱（追热门、捧彩票股） | 较持久——但会随参与者结构变化 |

**危险的是第三种**：制度套利（如壳价值）。它不属于上面两种，制度变了就没有了。

**检验清单**：

```
□ 这个因子的超额收益，在多个市场/多个年代都出现过吗？
□ 它有不舒服的时候吗？（没有任何不适期的因子，大概率是数据挖掘）
□ 我能说清"谁在把钱输给我"吗？
   ——说不清，就说明你不知道收益从哪来
```

## 16.4 普通人的正确参与方式：Smart Beta ETF

**Smart Beta = 把因子规则做成指数的 ETF。** 它自动帮你执行因子，不用你选股。

### 常见的国内 Smart Beta ETF 类型

| 类型 | 规则 | 属性 |
|---|---|---|
| **红利 ETF** | 选分红高、稳定的股票 | 价值 + 质量的混合体，防守型 |
| **低波 ETF** | 选波动率最低的股票 | 防守型，熊市抗跌 |
| **基本面 ETF** | 按营收/利润/分红规模选股 | 价值系 |
| **质量/价值 ETF** | 按 ROE、估值筛选 | 进攻+防守混合 |
| **红利低波 ETF** | 高分红 + 低波动双重筛选 | **最防守的组合** |

### 怎么挑（沿用第 6 章五查，加一条）

```
□ 1. 规模 ≥ 2 亿
□ 2. 日成交额 ≥ 5000 万
□ 3. 跟踪误差 ≤ 1%
□ 4. 综合费率合理
□ 5. 溢价率 ≤ 0.5%
□ 6.（Smart Beta 新增）编制方案我看得懂吗？
```

**第 6 条最重要**：打开这只 ETF 的指数编制方案（中证指数官网可查），看它到底怎么选股。**如果你不能用一句话说清它的选股规则，不要买**——你会在它失效时不知道该不该继续拿。

### 因子 ETF 的正确用法

```
错误用法：哪个因子最近涨得好就买哪个（追因子 = 追涨的另一种形式）
正确用法：选定 1–2 个逻辑你能理解的因子，长期持有，
          在第 15 章的配置框架里给它分配固定比例
```

## 16.5 为什么不建议你自己挖因子

对程序员这个诱惑特别大：数据现成（akshare/tushare），工具现成（第 12 章），挖一个"年化 40%"的因子看起来只需要一个周末。

**四个现实**：

1. **学术界登记了几百个因子，绝大多数在发表后失效**——这被称为"因子动物园"。发表后失效的原因包括过拟合、数据窥探、市场拥挤。
2. **你能想到的简单因子，早被人挖过并交易过**。你挖出来的"新发现"，大概率是过拟合。
3. **A 股数据质量问题**：停牌、ST、退市、复权处理，任何一个处理不对，回测就是假的（第 12 章的幸存者偏差）。
4. **因子衰减**：即使真实的因子，被广泛使用后超额收益会下降（拥挤交易）。

**正确的路径**：

```
入门期：买因子 ETF（红利、低波）
进阶期：用第 17 章的完整研究流程，验证 1–2 个公开因子在你数据上的表现
精通期：才有资格谈"自己构造因子"
```

## 16.6 因子与你的 90 天计划的关系

诚实地说：**因子投资不是你现阶段该做的事。**

- 你的 1000 元应该继续按第 13 章的计划走（宽基 ETF + 流程学习）
- 因子 ETF 是你**第二个 10 万**阶段的工具
- 但**现在就要建立防坑意识**：以后任何人给你讲"这个因子年化 50%"，你都知道该问三个问题——

```
① 收益从哪来？（风险补偿 / 行为偏差 / 制度套利？）
② 它历史上最惨的连续跑输期有多长？
③ 这个数字是样本内还是样本外？
```

---

## 本章要记住的 3 件事

1. **因子 = 被数据长期验证的股票共同特征。** 价值、质量、低波在 A 股长期有效；**动量在 A 股很弱**，别照搬美股结论。
2. **因子收益只有两种持久来源：风险补偿和行为偏差。** 说不清"谁在输钱给你"的因子，不要碰。制度套利型因子（如历史上的壳价值）会随制度变化死亡。
3. **普通人参与因子的正确方式是 Smart Beta ETF，前提是看懂编制方案。** 自己挖因子是精通期之后的事。

## 动手做

### 练习 16-1：读一份指数编制方案（30 分钟）

1. 打开中证指数官网（csindex.com.cn），搜"中证红利"或"红利低波"
2. 找到它的编制方案 PDF
3. 用一句话写下它的选股规则
4. 再找一只"XX 主题/概念"指数的方案对比——你会发现后者往往没有清晰规则

**检验标准**：你能给朋友解释清楚"这只 ETF 里都是什么股票"吗？

### 练习 16-2：验证"A 股动量弱"（30 分钟，有代码者可扩展）

不用代码的方法：找任意 5 个"过去 3 个月涨幅最大的板块/ETF"，分别记录它们**之后 3 个月**的表现。

```
标的 | 前 3 月涨幅 | 后 3 月涨幅
1    |            |
2    |            |
...
```

**统计**：有几个继续涨？如果一半以上回落，你就亲眼看到了"A 股反转效应"。

### 练习 16-3：做一次"因子审问"（15 分钟）

找一个你听过的"神奇策略"（公众号、短视频都行），用这三个问题审它：

```
① 收益从哪来？
② 最惨的连续跑输期有多长？（他答得上来吗？）
③ 数字是样本内还是样本外？（他分得清吗？）
```

**记录他能不能回答。** 这会是你识别"因子营销"的肌肉。
