# 附录 A 术语表

> 收录 A 股入门最常遇到的 60 多个术语，按拼音首字母分组。
> 遇到看不懂的词，先来这里查——不要在搜素引擎里随便点开一条"解读"，那多半是引流。

---

## A

| 术语 | 解释 |
|---|---|
| **ATR（平均真实波幅）** | 衡量标的价格波动幅度的指标，取过去 N 天真实波幅的平均值。用于设定止损距离（第 11 章）。 |

## B

| 术语 | 解释 |
|---|---|
| **被动投资** | 不主动选股，直接买指数。与之相对的是"主动投资"。 |
| **贝塔（β）** | 衡量标的相对市场整体的波动敏感度。β=1.2 意味着市场涨 1% 它涨 1.2%。 |
| **补仓** | 在已有持仓下跌后继续买入，用以摊低成本。**注意：补仓会放大风险，不是"摊平"就安全**。 |
| **逼空** | 大量空头被迫平仓，导致价格加速上涨。 |
| **板块** | 按行业、概念或地域划分的股票集合。如"半导体板块""券商板块"。 |

## C

| 术语 | 解释 |
|---|---|
| **除权** | 因送股、转增导致股本增加，股价按比例下调。总市值不变。 |
| **除息** | 因现金分红，股价按分红金额下调。总资产不变。 |
| **场外基金** | 在基金公司或第三方平台申购的基金，按当日净值确认，10 元起投，无最低 5 元佣金。 |
| **场内基金** | 在证券交易所买卖的基金（含 ETF、LOF），像股票一样实时成交。 |
| **成交额** | 一段时间内成交的总金额。**比成交量更能反映真实活跃度**。 |
| **成交量** | 成交的股数或份数，单位通常为"手"（1 手 = 100 股）。 |
| **持仓成本** | 买入的平均价格（含手续费）。**注意：它是历史，不是决策依据**（第 9 章）。 |
| **抄底** | 在价格大幅下跌后买入，假设已见底。新手最常失败的操作之一。 |

## D

| 术语 | 解释 |
|---|---|
| **跌停** | 价格跌至当日允许的最大跌幅（主板 -10%、创业板/科创板 -20%、ST -5%）。 |
| **动态市盈率** | 用预测的全年净利润计算的 PE，含猜测成分，可靠性低。 |
| **大宗交易** | 大额股份通过专用通道成交，不影响盘中价格。 |
| **对冲** | 同时持有多空两个方向，以降低整体风险。 |
| **多杀多** | 持仓者互相踩踏抛售，导致价格加速下跌。 |

## E

| 术语 | 解释 |
|---|---|
| **ETF** | 交易型开放式指数基金。跟踪指数、盘中实时交易、免印花税。 |
| **ETF 联接基金** | 场外申购的、投资于对应 ETF 的基金。适合小额定投。 |

## F

| 术语 | 解释 |
|---|---|
| **分红** | 公司把利润的一部分以现金或股票形式分给股东。**不是白送钱**。 |
| **复权** | 把历史价格按除权除息调整，使走势连续可比。分前复权、后复权。 |
| **风险溢价** | 股票盈利收益率减去无风险利率（10 年国债）。衡量股票相对债券的吸引力。 |
| **估值分位** | 当前 PE/PB 在过去 N 年中的百分位排名。50% 表示中位。 |
| **封单** | 涨停价上排队的买单总量（或跌停价上的卖单）。封单越大，涨停越牢。 |

## G

| 术语 | 解释 |
|---|---|
| **股票** | 公司所有权的凭证。持有即成为股东。 |
| **股本** | 公司发行的股份总数。总股本 × 股价 = 总市值。 |
| **股息率** | 每股分红 ÷ 股价。衡量现金回报水平。 |
| **过户费** | 中国结算收取的股份过户费用，费率 0.001%，双向。 |
| **杠杆** | 借钱放大投资规模。**A 股唯一合法杠杆是融资融券（50 万门槛）**。 |
| **国家队** | 指汇金、证金等国有资金，通常在极端行情入场维稳。 |

## H

| 术语 | 解释 |
|---|---|
| **换手率** | 成交股数 ÷ 流通股本 × 100%。衡量交易活跃度。 |
| **沪深300** | 沪深两市规模最大、流动性最好的 300 只股票构成的指数，代码 000300。 |
| **回撤** | 从历史最高点下跌的幅度。最大回撤是风控核心指标（第 8 章）。 |

## J

| 术语 | 解释 |
|---|---|
| **集合竞价** | 开盘（9:15–9:25）和收盘（14:57–15:00）时段，所有委托统一撮合出一个价格。 |
| **净资产** | 总资产减总负债，即所有者权益。 |
| **净佣** | 佣金报价不含交易所规费，实际成本更高。开户时要确认是"全佣"还是"净佣"。 |
| **建仓** | 首次买入某个标的，建立仓位。 |
| **减仓** | 卖出一部分持仓，降低仓位比例。 |
| **解禁** | 限售股到期可以上市流通。**解禁通常带来抛压**。 |

## K

| 术语 | 解释 |
|---|---|
| **K 线** | 记录一段时间内开盘、收盘、最高、最低四个价格的图形。**只描述历史**。 |
| **可转债** | 可转换为股票的债券。T+0 交易、免印花税，但波动大、规则复杂。 |
| **开盘价** | 集合竞价撮合出的当日第一个成交价。 |

## L

| 术语 | 解释 |
|---|---|
| **量比** | 当日每分钟成交量 ÷ 过去 5 日每分钟成交量。判断是否放量。 |
| **流动性** | 能快速买卖而不明显影响价格的能力。看日成交额。 |
| **利润表** | 反映一段时期收入、成本、利润的报表。 |
| **两市** | 指上海证券交易所和深圳证券交易所。 |
| **逻辑止损** | 买入理由消失时卖出（如基本面恶化），不依赖价格。 |

## M

| 术语 | 解释 |
|---|---|
| **MACD** | 一种趋势指标，用两条均线的差离值判断动能。**滞后指标，不能预测**。 |
| **市值** | 股价 × 总股本。**判断公司大小看市值，不看股价**。 |
| **面值退市** | 连续 20 个交易日收盘价低于 1 元，将被强制退市。 |
| **满仓** | 全部资金都买了股票，没有现金。**新手应避免**。 |

## N

| 术语 | 解释 |
|---|---|
| **内盘** | 以买方报价成交的量（卖方主动）。 |
| **年化收益率** | 把不同期限的收益率折算成一年的比率。 |
| **牛市** | 市场整体持续上涨的阶段。 |

## P

| 术语 | 解释 |
|---|---|
| **PE（市盈率）** | 市值 ÷ 净利润，或股价 ÷ 每股收益。其倒数是盈利收益率。 |
| **PB（市净率）** | 市值 ÷ 净资产。适合银行、周期股。 |
| **盘口** | 买一到买五、卖一到卖五的挂单情况。**挂单可撤，可能造假**。 |
| **破净** | 股价低于每股净资产，即 PB < 1。 |

## Q

| 术语 | 解释 |
|---|---|
| **清仓** | 卖出全部持仓。 |
| **权益乘数** | 总资产 ÷ 净资产。衡量杠杆水平，ROE 杜邦分解的一项。 |
| **全佣** | 佣金报价已包含规费和过户费，成本透明。**开户优先选全佣**。 |
| **强制平仓** | 杠杆交易中，亏损达到阈值时被系统强制卖出。 |

## R

| 术语 | 解释 |
|---|---|
| **ROE（净资产收益率）** | 净利润 ÷ 净资产。**长期最重要的单一财务指标**。 |
| **融资融券** | 借钱买股（融资）或借股卖出（融券）。门槛 50 万资产 + 半年经验。 |
| **日 K 线** | 每根 K 线代表一个交易日的走势。 |

## S

| 术语 | 解释 |
|---|---|
| **市盈率** | 同 PE。 |
| **市净率** | 同 PB。 |
| **印花税** | 国家税收，卖出单边 0.05%。**ETF 免征**。 |
| **手** | 交易单位，1 手 = 100 股（份）。买入必须为 100 的整数倍。 |
| **散户** | 个人投资者。与之相对的是机构投资者。 |
| **三张报表** | 资产负债表、利润表、现金流量表。 |
| **时间止损** | 持有超过预定时间仍未达预期就卖出，释放资金。 |

## T

| 术语 | 解释 |
|---|---|
| **T+1** | 当日买入的股票，次日才能卖出。资金 T+1 可用于买入，T+2 可提现。 |
| **停牌** | 因重大事项暂停交易。**期间无法卖出，是隐性风险**。 |
| **退市** | 股票被终止上市。转入老三板后流动性极差。 |
| **套牢** | 买入后价格下跌，卖出即亏损，只能被动持有。 |
| **条件单** | 预设条件（如价格跌到 X）自动触发委托的订单。**止损必备工具**。 |

## W

| 术语 | 解释 |
|---|---|
| **委比** | (委买 − 委卖) ÷ (委买 + 委卖) × 100%。**最容易被操纵的指标**。 |
| **委差** | 委买手数减委卖手数。 |
| **外盘** | 以卖方报价成交的量（买方主动）。 |

## X

| 术语 | 解释 |
|---|---|
| **限价委托** | 指定价格买卖，不达价格不成交。**新手一律用这个**。 |
| **现手** | 最近一笔成交的量。 |
| **熊市** | 市场整体持续下跌的阶段。 |
| **现金流量表** | 反映一段时期真实现金进出的报表。**唯一不撒谎的表**。 |

## Y

| 术语 | 解释 |
|---|---|
| **溢价率** | (交易价格 − 净值) ÷ 净值。**> 0.5% 不要买**（第 6 章）。 |
| **佣金** | 券商收取的交易服务费。双向收取，**单笔不足 5 元按 5 元**。 |
| **阳线** | 收盘价高于开盘价的 K 线，中国用**红色**。 |
| **阴线** | 收盘价低于开盘价的 K 线，中国用**绿色**。 |
| **应收账款** | 已确认收入但尚未收到的款项。**增速远超营收 = 利润质量差**。 |

## Z

| 术语 | 解释 |
|---|---|
| **涨停** | 价格涨至当日允许的最大涨幅。**可能买不进**。 |
| **止损** | 亏损达到预设幅度时卖出，锁定最大损失。 |
| **最大回撤** | 从历史最高点到之后最低点的最大跌幅。**决定你能否拿得住**。 |
| **资产负债表** | 反映某一时点资产、负债、所有者权益的报表。 |
| **主升浪** | 一段上涨行情中涨幅最大、最流畅的阶段。**事后才能确认**。 |
| **做 T** | 用已有底仓做日内价差（先卖后买或先买后卖）。A 股 T+1 下只能"先卖后买"。 |

## 三个最常见的概念混淆

| 容易混淆 | 区别 |
|---|---|
| **股价 vs 市值** | 股价低不代表便宜。8 元和 300 元的股票，要看市值和 PE 比较。 |
| **成交量 vs 成交额** | 100 万手对 3 元股是 3 亿，对 300 元股是 300 亿。**横向比较只能用成交额**。 |
| **分红 vs 收益** | 分红当天你的总资产不变（股价同步下调），且持股不满 1 个月要交 20% 税。 |
