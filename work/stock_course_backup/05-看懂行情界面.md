# 第 5 章 看懂行情界面

> 本章目标：让你打开任何行情软件，都知道每个数字在说什么，并且知道**哪些数字值得看、哪些纯属噪音**。
> 这一章的重点不是"教你预测"，恰恰相反——是让你看清这些指标的真实边界。

---

## 5.1 行情界面的七个区域

打开任意一只股票的详情页，信息可以分成七块：

```
┌──────────────────────────────────────────────────┐
│ ① 顶部：代码、名称、最新价、涨跌幅                │
├──────────────────────────────────────────────────┤
│ ② 左侧：五档盘口（买一到买五 / 卖一到卖五）        │
│    右侧：关键指标（今开、最高、最低、成交量、额）  │
├──────────────────────────────────────────────────┤
│ ③ 分时图（当日走势）或 K 线图（多日走势）          │
├──────────────────────────────────────────────────┤
│ ④ 成交量柱状图（在图的下方）                      │
├──────────────────────────────────────────────────┤
│ ⑤ 成交明细（逐笔成交记录）                        │
├──────────────────────────────────────────────────┤
│ ⑥ 资金流向、龙虎榜、公告                          │
├──────────────────────────────────────────────────┤
│ ⑦ 财务数据、行业对比、研报                        │
└──────────────────────────────────────────────────┘
```

**新手 90% 的时间应该只花在 ①③ 和两个数字上：成交额、溢价率。** 其余区域先放着，第 7、10 章再回来看。

---

## 5.2 五档盘口：市场此刻的供需

### 长什么样

以沪深300ETF（510300）2026-11-09 收盘时的盘口为例：

```
卖五   4.135    2133 手
卖四   4.134     309 手
卖三   4.133    3983 手
卖二   4.132    3616 手
卖一   4.131   15830 手     ← 最便宜的卖单
─────────────────────────────
买一   4.130   30540 手     ← 最贵的买单
买二   4.129   10550 手
买三   4.128    9383 手
买四   4.127    4512 手
买五   4.126    7907 手
```

### 读这十一行，只需要记住三件事

**① 卖单从下往上是涨的，买单从上往下是跌的。**

"卖一"永远是最低的卖价（4.131），"买一"永远是最高的买价（4.130）。两者之间差 0.001 元，这个差叫**买卖价差（spread）**，是第 3 章讲的隐性成本。

**② 买一和卖一的挂单量，代表此刻的"墙"。**

买一挂了 30540 手（305 万股），说明有大量资金愿意在 4.130 接货；卖一挂了 15830 手，说明有大量筹码想在 4.131 出。

**注意**：这些挂单可以随时撤掉。**盘口上的"大单"可能是假的**——有人挂 3 万手在买一，制造"有支撑"的错觉，等你买进去之后他撤单跑路。这叫"**虚假挂单**"，在 A 股非常常见。

**③ 盘口只反映"此刻"，不反映"未来"。**

这是本章最重要的一句话。盘口告诉你的是"现在这个瞬间，谁愿意在什么价格买卖多少"，仅此而已。

## 5.3 委比与委差

```
委买手数 = 买一到买五的挂单总量
委卖手数 = 卖一到卖五的挂单总量

委差 = 委买手数 − 委卖手数
委比 = 委差 ÷ (委买手数 + 委卖手数) × 100%
```

上例中：
```
委买 = 30540 + 10550 + 9383 + 4512 + 7907 = 62,892 手
委卖 = 15830 + 3616 + 3983 + 309 + 2133 = 25,871 手
委差 = 62,892 − 25,871 = 37,021 手
委比 = 37,021 ÷ 88,763 × 100% = +41.7%
```

委比 +41.7% 意味着买盘挂单明显多于卖盘。

**但要打个大折扣看这个数字**：因为挂单可以撤，委比是**最容易被操纵的指标**。开盘前的委比尤其不可信——9:15–9:20 期间大量挂单是为了影响虚拟开盘价，9:20 一到就全消失了。

**结论：委比当作"当前情绪的温度计"可以，当作"未来走势的预测"绝对不行。**

## 5.4 内盘与外盘：谁更主动

每一笔成交，都有一方是"主动"的：

| 概念 | 定义 | 含义 |
|---|---|---|
| **外盘** | 以**卖方报价**成交（买方主动吃掉卖单） | 买方着急，看涨情绪 |
| **内盘** | 以**买方报价**成交（卖方主动砸向买单） | 卖方着急，看跌情绪 |

例：你要买 200 份，市场上最便宜的卖价是 4.131。你直接按 4.131 下单成交——这笔算**外盘**。

行情软件里通常显示为「外盘 613.4 万 / 内盘 451.5 万」。

**传统解读**：外盘 > 内盘 → 买盘强 → 看涨。

**真实情况**：这个解读在今天的市场已经基本失效。原因：

1. 量化机构可以用算法把大单拆成小单，主动/被动可以随意控制
2. 主力资金完全可以"用外盘拉高、用内盘出货"，做成相反的信号
3. 内外盘是**全天累计**数据，看到的时候已经是滞后的

**给你的建议：知道它是什么就行，不要拿它做决策。**

## 5.5 成交量、成交额、量比、换手率

这四个数字里，**只有前两个是真实的、不可操纵的**。

### 成交量与成交额

| 指标 | 含义 | 单位 |
|---|---|---|
| **成交量** | 成交了多少股（份） | 手（1 手 = 100 股）或万股 |
| **成交额** | 成交了多少钱 | 元 / 万元 / 亿元 |

```
成交额 ≈ 成交量 × 均价
```

**为什么成交额比成交量重要**：

同样是"成交 100 万手"，对一只 3 元的股票是 3 亿元，对一只 300 元的股票是 300 亿元。**只有成交额能横向比较不同标的的活跃程度。**

### 量比

```
量比 = 当日每分钟平均成交量 ÷ 过去 5 个交易日每分钟平均成交量
```

| 量比 | 含义 |
|---|---|
| < 0.5 | 明显缩量，市场冷清 |
| 0.8 – 1.5 | 正常 |
| 1.5 – 2.5 | 温和放量 |
| > 2.5 | 明显放量，通常伴随消息或异动 |

**量比的有效用途**：判断"今天这个波动是不是有真实资金参与"。价格涨了但量比只有 0.6，说明是缩量上涨，参与度低。

### 换手率

```
换手率 = 成交股数 ÷ 流通股本 × 100%
```

| 换手率 | 含义 |
|---|---|
| < 1% | 极不活跃（大盘股常见） |
| 1% – 3% | 正常 |
| 3% – 10% | 活跃 |
| > 10% | 高度活跃，情绪化 |
| > 20% | 极端，通常有炒作 |

510300 在 2026-11-09 的换手率是 **2.28%**——对一只规模近 2000 亿的宽基 ETF 来说，这个活跃度非常健康。

**换手率的关键用途**：判断你要买的标的**流动性够不够**。换手率长期低于 0.5% 的品种，你想卖的时候可能找不到对手方。

## 5.6 分时图：一天的价格轨迹

分时图有三个元素：

| 元素 | 颜色 | 含义 |
|---|---|---|
| **白线**（或蓝线） | 白/蓝 | 当前成交价 |
| **黄线** | 黄 | **当日成交均价**（累计成交额 ÷ 累计成交量） |
| **成交量柱** | 红/绿 | 每分钟的成交量 |

### 一个非常有用的读法

```
白线在黄线之上 → 今天买入的人，平均是赚钱的
白线在黄线之下 → 今天买入的人，平均是亏钱的
白线在黄线上方越远 → 追高买入的人越多，抛压越大
```

这条判断的实战价值在于：**当白线远离黄线时，说明当天的涨幅是由少数高价成交拉起来的，不稳固。**

### 分时图上不该做的事

- **不要看"支撑位""压力位"**：一天之内的价格轨迹是随机的，画线没有意义
- **不要根据分时形态猜收盘价**：这是胜率接近 50% 的赌博，还要付手续费

## 5.7 K 线：一根蜡烛在说什么

K 线（蜡烛图）是本间宗久在 18 世纪日本米市发明的，现在全球通用。

### 一根 K 线记录四个价格

```
        ┌───┐  ← 最高价（上影线顶端）
        │   │
    ┌───┴───┴───┐
    │           │  ← 实体：开盘价到收盘价
    └───┬───┬───┘
        │   │
        └───┘  ← 最低价（下影线底端）
```

| 部分 | 含义 |
|---|---|
| **实体上沿** | 收盘价（阳线）或开盘价（阴线） |
| **实体下沿** | 开盘价（阳线）或收盘价（阴线） |
| **上影线顶端** | 该周期内的最高价 |
| **下影线底端** | 该周期内的最低价 |

### 阴线与阳线

| 类型 | 条件 | A 股颜色 |
|---|---|---|
| **阳线** | 收盘价 > 开盘价（涨） | **红色** |
| **阴线** | 收盘价 < 开盘价（跌） | **绿色** |
| 十字星 | 收盘 ≈ 开盘 | 视微幅涨跌定颜色 |

**注意**：中国市场的颜色和欧美相反。中国是**红涨绿跌**，欧美是绿涨红跌。看境外网站的图时别搞错。

### 实体长短的意义

| 形态 | 含义 |
|---|---|
| 长实体（大阳/大阴） | 多空一方压倒性胜利 |
| 短实体 / 十字星 | 多空胶着，方向不明 |
| 长上影线 | 冲高被打回，上方抛压重 |
| 长下影线 | 下探被承接，下方有支撑 |

### 关于 K 线最重要的一句话

**K 线只描述已经发生的事，不预告将要发生的事。**

一根大阳线告诉你"今天涨了很多"，不告诉你"明天还会涨"。把 K 线形态当作预测工具，是第 11 章要专门批判的内容。

## 5.8 涨停板上的"封单"

涨停的时候，盘口会变成这样：

```
卖一   ——     无卖单
─────────────────────
买一   11.00   88万手     ← 涨停价上排队买入的量
买二   10.99   1.2万手
```

这 88 万手就是**封单**。

| 封单情况 | 含义 |
|---|---|
| 封单量大（几十万手以上） | 想买的人远多于想卖的人，涨停难以打开 |
| 封单量小（几万手） | 涨停不牢，随时可能打开 |
| 封单突然大幅减少 | 有人在撤单，可能是主力出货 |

**"炸板"**：涨停被打开，股价从涨停价跌下来。这是短线最危险的信号之一。

**对 1000 元本金的你**：涨停板的股票基本买不进（你的单排在 88 万手后面）。**所以不要在涨停板上追**——不是"不该追"，是"追不到，只能追那些封单薄、马上要炸的，而那种最危险"。

## 5.9 新手该看哪几个数

信息过载是新手最大的敌人。行情界面有 60 多个字段，你的注意力只有一份。

**只看这五个：**

| 数字 | 为什么看 | 阈值参考 |
|---|---|---|
| **最新价 / 涨跌幅** | 现在什么状态 | — |
| **成交额** | 流动性够不够 | 日成交额 < 5000 万的 ETF 不碰 |
| **换手率** | 活跃度 | 长期 < 0.5% 的不碰 |
| **溢价率**（ETF 专用） | 有没有多付钱 | > 0.5% 不买 |
| **买卖价差** | 隐性成本 | ETF 超过 2 个价位不碰 |

**其余 55 个字段，在你完成 100 笔交易之前，都不需要看。**

---

## 本章要记住的 3 件事

1. **盘口、委比、内外盘都可能被操纵，只有成交额和换手率是硬数据。** 前者是情绪，后者是事实。
2. **白线（价格）在黄线（均价）之上 = 今天买入的人平均在赚。** 这是分时图上唯一有实战价值的判断。
3. **K 线只记录历史，不预测未来。** 看懂它是为了不被别人的话术忽悠，不是为了靠它下注。

## 动手做

### 练习 5-1：手算委比（10 分钟）

打开任意一只股票的盘口，抄下五档买卖挂单量，按 5.3 的公式算委比，和软件显示的对比。

**误差应该在 1% 以内。** 如果不是，检查你是不是把"手"和"股"搞混了（软件可能显示的是股数而不是手数，1 手 = 100 股）。

### 练习 5-2：观察一个交易日的分时图（一整天，每小时看一次）

选一只你关注的 ETF，在 9:30、10:30、13:30、14:50 各看一次分时图，记录：

```
时间    白线 vs 黄线    成交量（相对前一时段放大还是缩小）
9:30    ______          ______
10:30   ______          ______
13:30   ______          ______
14:50   ______          ______
```

**目的**：建立"价格与均价的关系"的直觉。收盘时回头看，白线最终落在黄线的哪一侧？

### 练习 5-3：找一根 K 线拆解它（10 分钟）

选任意一天的一根日 K 线，从行情软件里找到那天的：开盘价、收盘价、最高价、最低价。

然后在纸上画出这根 K 线（实体 + 上下影线），标出四个价格。

**验证**：你画的实体颜色和软件的阳线/阴线颜色一致吗？
