# 第 13 章 90 天实操计划

> 本章目标：把前面 12 章变成一张可以照着执行的日程表。
> 每一周都有明确的动作和可验证的检查标准——不是"要好好学习"，是"做完这三件事"。

---

## 13.1 计划总览

```
第 1–2 周   认知期      只读不买，把规则和费用搞清楚
第 3–4 周   模拟期      模拟盘 20 笔，建立记录习惯
第 5–8 周   方法期      学估值与仓位，用回测验证一个想法
第 9–12 周  实盘期      1000 元真实走一遍全流程
```

**总原则：前 8 周一分钱不投。**

这不是保守，这是效率。你在模拟盘上犯的错是免费的，在实盘上犯的错要付钱。

## 第三至四周：模拟盘 20 笔

**这两周的核心任务只有一件：做 20 笔模拟交易，每笔都写记录。**

> 具体的操作方法、五条规则、要统计的五个指标，见 **4.3 节「模拟盘：先用假钱练三周」**。
> 这里只讲日程安排。**如果还没读 4.3，先回去读，否则这两周会白练。**

### 为什么要 20 笔

少于 10 笔，你还在"熟悉操作"阶段，记录的是手忙脚乱。
20 笔能让你看到模式：**你是不是总在涨了之后买？是不是亏了就装死？**

### 怎么做（关键）

**不要随便买卖。** 每一笔都要有理由，哪怕是错的理由。

```
第 N 笔
日期：
标的：
方向：买 / 卖
价格：
数量：
理由：（一句话，必须写）
当时的估值分位：（如果知道）
事后（3 天后回看）：
  涨了还是跌了：
  我的理由成立吗：
  如果重来我会怎么做：
```

### 20 笔的构成建议

| 类型 | 笔数 | 目的 |
|---|---|---|
| 买宽基 ETF | 8 笔 | 熟悉主流标的 |
| 买一只个股 | 4 笔 | 体会个股波动 |
| 追一次涨 | 2 笔 | **故意做错，看后果** |
| 抄一次底 | 2 笔 | 体会"接飞刀" |
| 止损一次 | 2 笔 | 练习执行 |
| 什么都不做（记录不交易） | 2 次 | 体会"空仓也是一种决策" |

**"故意做错"是刻意的。** 你需要在小代价下体验追涨和抄底的后果，否则实盘时你会用真钱去学。

### 第三至四周检查标准

```
□ 完成 20 笔记录？
□ 我的胜率是多少？（自己数）
□ 我有几笔是"因为怕错过"买入的？
□ 我有几笔计划止损但没执行？
□ 我的平均持有天数是多少？
```

**这四个数字比任何收益率都重要。** 它们是关于你的数据。

## 第九至十二周：1000 元实盘

**这是唯一花钱的阶段。四个星期，只做两个动作。**

### 第 9 周：入金 + 第一笔真实买入

```
动作 1：银证转账 1000 元
动作 2：买入 1 手 510300（413 元左右）
```

**注意：只买 1 手，不是 2 手。**

理由见第 8 章：1 手 + 587 元现金，单笔最大亏损控制在 4% 左右。2 手的风险是 8.3%，太高。

**买完之后做什么**：什么都不做。等。

### 第 10 周：观察与记录

| 天 | 动作 |
|---|---|
| 每天 | 收盘后看一眼价格，记下来，**不要改单** |
| 周三 | 查一次估值分位，看有没有变化 |
| 周五 | 记录：本周我的情绪波动如何？想卖出的冲动有几次？ |

**这一周的目的是体会"持有"的感觉**，而不是操作。

### 第 11 周：卖出（或继续持有）

**两个分支，取决于你的记录：**

**分支 A：按计划卖出**
如果到了你预设的卖出条件（价格、时间或估值），执行卖出。

**分支 B：继续持有**
如果条件未到，什么都不做。**这也是一个正确的决策。**

**关键动作：无论如何，卖出后立刻核对交割单。**

```
□ 买入佣金是不是 5.00 元？
□ 卖出佣金是不是 5.00 元？
□ 印花税是不是 0（ETF 免征）？
□ 往返总成本是不是 10 元左右？
```

## 13.3 三个月之后：三条路

### 路线 A：继续学习型（推荐）

```
做法：每月定投 300–500 元买入宽基 ETF，只买不卖
目的：把投资变成储蓄习惯
预期：长期年化 5%–9%，波动会让你不舒服但不致命
```

**这条路的前提**：这笔钱未来 5 年不用。

### 路线 B：研究型（适合有兴趣的人）

```
做法：保留 1000 元实盘，同时用模拟盘或回测研究策略
目的：把投资当成一个可以深入学习的领域
预期：3 年内不指望赚钱，5 年后可能有一套自己的方法
```

**这条路适合程序员**，因为你有验证工具。

### 路线 C：暂停（完全合理）

```
做法：清仓，把钱取出来，承认这件事暂时不适合自己
目的：止损，包括金钱和时间
```

**这条路不需要羞耻感。** 90 天里发现自己不适合做某件事，是极高性价比的收获——比亏三年才发现好得多。

## 13.4 三个必须守住的纪律

无论走哪条路，这三条不能破：

```
① 投入的钱，亏光不影响生活
   → 不含房租、不含应急金、不含要还的债

② 不加杠杆
   → 不开两融（50 万门槛，你也开不了）
   → 不碰场外配资（这是违法的）

③ 不向别人推荐，也不听别人推荐
   → 你的判断只对你自己负责
```

**第 ③ 条的理由**：一旦你开始"带人"或"跟人"，你会为了面子而坚持错误判断。这是最贵的心理成本。

## 本章要记住的 3 件事

1. **前 8 周不投一分钱。** 模拟盘犯的错免费，实盘犯的错要付钱。
2. **20 笔模拟交易的记录比收益率重要。** 它给你的是关于自己的数据，不是关于市场的数据。
3. **第 7 条和第 10 条（纪律）比前 6 条（知识）重要。** 知识可以补，纪律只能练。
