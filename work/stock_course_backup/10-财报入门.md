# 第 10 章 财报入门

> 本章是选读章。**你现在的资金量和策略（买宽基 ETF）其实用不上财报。**
> 但你需要它，理由只有一个：**让你在别人给你推荐个股时，有能力说"不"。**

---

## 10.1 为什么选读章还要写

如果你只买宽基 ETF，你确实不需要读财报——指数会自动帮你筛选。

但现实是：**你一定会遇到有人向你推荐个股。**

- 同事说"这只票要重组了"
- 群里说"这家公司拿到了大订单"
- 短视频说"这个赛道是未来"

这时候你有两个选择：

| 选择 | 结果 |
|---|---|
| 不懂财报，凭感觉 | 买了，然后靠运气 |
| 会看三个数字，五分钟验证 | 发现"它的利润是赊出来的"，不买 |

**财报知识的最大价值不是"找到好公司"，是"快速排除坏公司"。**

排除比选择容易得多，也有效得多。

## 10.2 三张表：用一间小店解释

假设你开了一家奶茶店。一年下来，你要搞清楚三件事：

### 第一张：资产负债表（家底照片）

**回答的问题：此时此刻，我有什么、欠什么？**

```
资产（我有的）
  现金 5 万
  设备 10 万
  存货 2 万
  ────────────
  总资产 17 万

负债（我欠的）
  银行贷款 7 万
  欠供应商 3 万
  ────────────
  总负债 10 万

所有者权益（真正属于我的）
  17 万 − 10 万 = 7 万
```

**恒等式**：

```
资产 = 负债 + 所有者权益
```

这个等式永远成立，是财报的地基。

**关键特征：这是一个"时点"数据。** 就像拍照片——"2026 年 12 月 31 日那一刻，我的家底是这样"。

### 第二张：利润表（收支记录）

**回答的问题：这一段时间，我赚了多少？**

```
营业收入        50 万
营业成本        20 万
──────────────
毛利            30 万
销售费用         5 万
管理费用         4 万
房租             6 万
──────────────
营业利润        15 万
利息支出         1 万
──────────────
利润总额        14 万
所得税           3.5 万
──────────────
净利润          10.5 万
```

**关键特征：这是一个"期间"数据。** 就像录像——"这一年，我赚了 10.5 万"。

**注意**：净利润 10.5 万，不代表你手里多了 10.5 万现金。因为你可能赊账卖了货（记了收入但没收到钱），也可能买了一台设备（花了钱但记在资产上）。

### 第三张：现金流量表（银行流水）

**回答的问题：这一段时间，真金白银进出多少？**

```
经营活动现金流
  收到的货款      45 万（有 5 万是赊的，没收到）
  支付的货款     −20 万
  支付的工资     −10 万
  支付的税        −3.5 万
  ──────────────
  经营现金流      11.5 万

投资活动现金流
  买设备         −5 万
  ──────────────
  投资现金流      −5 万

筹资活动现金流
  银行贷款       +7 万
  还利息         −1 万
  ──────────────
  筹资现金流     +6 万

──────────────
现金净增加      12.5 万
```

**关键特征：这是唯一一张"不说谎"的表。**

因为利润可以被会计处理影响（折旧年限、收入确认时点），但**银行流水是硬事实**——钱到账了就是到账了。

### 三张表的关系

```
利润表的"净利润"  ──→  通过营运资本变动、折旧摊销  ──→  现金流量表的"经营现金流"
                                                       ↓
                                              期末现金  ──→  资产负债表的"货币资金"
```

**一句话总结**：

> **利润表说"我赚了"，现金流量表说"我真的收到了"，资产负债表说"我现在有多少"。**

三张表互相验证。**如果一家公司连续多年"净利润很高但经营现金流很差"，那它的利润质量有问题。**

## 10.3 三个必看指标

年报有几百页，你只需要看三个数字。

### 指标一：ROE（净资产收益率）

```
ROE = 净利润 ÷ 净资产 × 100%
```

**含义**：股东每投入 100 元，公司一年能赚回多少。

| ROE | 判断 |
|---|---|
| < 8% | 平庸，不如买国债（假设国债 2%，但风险低得多） |
| 8% – 15% | 正常 |
| **15% – 25%** | **优秀**（巴菲特的标准是长期 >15%） |
| > 25% | 极优秀，但要查是不是高杠杆撑起来的 |
| > 40% | 警惕，通常不可持续 |

**为什么 ROE 是最重要的单一指标**：

因为长期来看，**你的股票收益率会向公司的 ROE 收敛**。一家能持续创造 20% ROE 的公司，股价长期也会给你接近 20% 的年化回报（如果买入估值不变）。

### ROE 的杜邦分解（进阶但很有用）

```
ROE = 净利率 × 总资产周转率 × 权益乘数
       （赚得多）  （转得快）    （借得多）
```

三种不同的高 ROE：

| 类型 | 特征 | 风险 |
|---|---|---|
| **高净利率型** | 品牌溢价、技术壁垒（如高端白酒） | 低，最优质 |
| **高周转型** | 薄利多销、渠道效率（如商超） | 中，怕竞争 |
| **高杠杆型** | 借很多钱放大收益（如银行、地产） | **高**，利率或政策变化就崩 |

**同样是 ROE 25%，这三种公司的风险完全不同。** 看到高 ROE，一定要看它是怎么来的。

### 指标二：毛利率

```
毛利率 = (营业收入 − 营业成本) ÷ 营业收入 × 100%
```

**含义**：产品本身的赚钱能力（还没扣管理费用、销售费用）。

| 毛利率 | 含义 |
|---|---|
| < 15% | 竞争激烈，无定价权（如传统制造、商贸） |
| 15% – 30% | 一般 |
| 30% – 50% | 有品牌或技术优势 |
| > 50% | 强定价权（如软件、高端消费） |

**毛利率的关键不是高低，是"趋势"。**

```
毛利率连续三年下滑 5 个百分点
→ 说明竞争加剧、或者产品在降价换销量
→ 这是比净利润下滑更早的预警信号
```

### 指标三：经营现金流 ÷ 净利润

```
这个比值 = 经营现金流净额 ÷ 净利润
```

| 比值 | 含义 |
|---|---|
| **> 1** | **健康**，利润是真金白银 |
| 0.7 – 1 | 尚可 |
| 0.3 – 0.7 | 警惕，利润有水分 |
| < 0.3 或为负 | **危险**，赚的是纸面利润 |

**为什么这个比值最重要**：

会计上有很多方法可以做出"漂亮的净利润"：
- 把货赊给经销商（确认收入，但钱没收到）
- 延长设备折旧年限（降低当期成本）
- 资本化研发支出（不计入当期费用）

但这些方法**都做不出经营现金流**。现金流是银行账户里的钱。

> **净利润是观点，现金流是事实。**

## 10.4 五分钟读一份年报

年报几百页，95% 你不需要看。按这个顺序，五分钟能得出初步结论。

### 第一步：看三个增长率（1 分钟）

在"主要会计数据"那一节找：

```
营业收入同比增速：____%
净利润同比增速：  ____%
经营现金流同比：  ____%
```

**判断**：
- 营收增、利润增、现金流增 → 健康
- 营收增、利润增、**现金流降** → 利润可能是赊的，继续查
- 营收降、利润增 → 靠削减成本，不可持续
- 营收增、利润降 → 增收不增利，竞争加剧

### 第二步：看毛利率趋势（1 分钟）

对比近三年毛利率：

```
2024：____%   2025：____%   2026：____%
```

**连续下滑 > 3 个百分点 → 警惕。**

### 第三步：看应收账款（1 分钟）

```
应收账款增速：____%
营业收入增速：____%
```

**应收账款增速明显高于营收增速 → 说明收入是靠赊账做出来的。**

这是最常见的"财务美化"手法，也是最好识别的。

### 第四步：看负债（1 分钟）

```
资产负债率：____%
有息负债（短期借款+长期借款+应付债券）：____ 亿元
货币资金：____ 亿元
```

**判断**：
- 有息负债远大于货币资金 → 偿债压力大
- 资产负债率 > 70%（非金融企业）→ 警惕
- 货币资金很多但还在大量借款 → 反常，可能有资金占用问题

### 第五步：看两个"人"的信号（1 分钟）

| 项目 | 在哪看 | 什么信号危险 |
|---|---|---|
| **大股东质押比例** | 公告、行情软件 F10 | 质押 > 50% → 大股东缺钱，可能爆仓 |
| **高管/大股东减持** | 公告 | 连续减持 → 内部人不看好 |

**最后这一条最容易被忽视，但信号最强。**

如果公司董事长在持续减持，而他同时在对媒体说"公司前景非常好"——**相信他的行动，不要相信他的话。**

### 五分钟检查清单

```
□ 营收、利润、经营现金流三个增速都是正的？
□ 毛利率近三年没有连续下滑？
□ 应收账款增速 ≤ 营收增速？
□ 有息负债可控，货币资金充足？
□ 大股东质押 < 50%，无连续减持？

5 项全过 → 可以进一步研究
有 1–2 项不过 → 需要查明原因
有 3 项以上不过 → 直接排除，不用看了
```

**注意最后一行**：财报的用法是"排除"，不是"选中"。**排除掉 90% 的公司，比找到 1 家好公司容易得多，而且更有效。**

## 10.5 三个最常见的财报陷阱

### 陷阱一：应收账款暴增

```
营收增长 30%，应收账款增长 80%
```

**可能的情况**：公司把货压给经销商，确认了收入，但钱没收回来。经销商卖不掉就会退货，到时候收入要冲回。

**这是"虚增收入"最常见的路径。**

### 陷阱二：存货暴增

```
营收增长 10%，存货增长 60%
```

**可能的情况**：产品卖不动了，堆在仓库里。存货需要计提跌价准备，未来利润会受影响。

**存货周转天数**是一个好指标：

```
存货周转天数 = 存货 ÷ 营业成本 × 365
```

天数持续上升 → 卖得越来越慢。

### 陷阱三：商誉

```
商誉 = 收购价格 − 被收购公司的净资产
```

公司花 10 亿收购一家净资产 2 亿的公司，多付的 8 亿记作"商誉"。

**商誉不是资产，是"溢价"。** 如果被收购的公司业绩不达预期，这 8 亿就要"计提减值"——直接从当期利润里扣掉，可能一次亏掉几年的利润。

**检查方法**：

```
商誉 ÷ 净资产 > 30% → 有减值风险
```

A 股 2018 年有大量公司因为商誉减值一次性巨亏，股价腰斩。这个教训值得记住。

## 10.6 一个诚实的结论

读完这一章，你应该得到一个判断：

> **对 1000 元本金的你，财报知识的最大用途是"防守"，不是"进攻"。**

- **进攻**（靠财报选股赚钱）需要：行业理解、产业链知识、财务建模、持续跟踪。这是全职工作的量。
- **防守**（靠财报排除坏公司）只需要：上面那五个检查项。半小时能学会。

**学防守，别学进攻。** 进攻的钱让基金经理去赚（他们也不一定赚得到），你只需要保护好自己的 1000 元。

---

## 本章要记住的 3 件事

1. **净利润是观点，现金流是事实。** 经营现金流 ÷ 净利润 < 0.3 的公司，利润大概率有水分。
2. **ROE 最重要，但要看它是怎么来的。** 高杠杆撑起来的 25% 和高净利率带来的 25%，风险完全不同。
3. **财报的用法是排除，不是选中。** 排除掉 90% 比找到 1 家容易得多，也更有效。

## 动手做

### 练习 10-1：五分钟体检一家公司（30 分钟）

选一家你听说过的 A 股公司，在行情软件的"F10 → 财务分析"里找到这五项，填表：

```
公司名称：___________
营收增速：____%   净利润增速：____%   经营现金流增速：____%
毛利率（近三年）：____% → ____% → ____%
应收账款增速：____%   资产负债率：____%
有息负债：____ 亿   货币资金：____ 亿
大股东质押比例：____%

五项检查：过了 ___ 项
结论：___________
```

**如果你发现任何一项不过，试着找出原因。** 这一步比看十篇文章有用。

### 练习 10-2：找一个"利润好但现金流差"的案例（30 分钟）

在行情软件里按"经营现金流/净利润"排序，找一家这个比值连续两年低于 0.3 的公司。

然后看它的应收账款变化。

**你会看到"应收账款暴增"和"现金流差"同时出现**——这就是教科书上的案例，在真实数据里。

### 练习 10-3：验证"行动比话术可信"（长期练习）

找一家近期有高管增持或减持公告的公司，看公告前后媒体的报道口径。

**对比**：公告说的是什么，实际行动是什么，媒体报道的是什么。

这个练习会让你对"消息"产生免疫力。
