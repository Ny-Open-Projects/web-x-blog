## 这本书是什么

这不是一本"教你抓涨停"的书。

这是一本**让你用最少的钱、最短的时间，把股市这件事彻底搞明白一次**的操作手册。读完它，你不会有能力预测涨跌——没有人有——但你会具备三样东西：

1. **不踩坑的能力**：知道 T+1、涨跌停、除权除息、印花税这些规则怎么影响你的钱
2. **不亏光的能力**：知道一笔交易最多该亏多少，以及为什么这是唯一重要的决定
3. **判断贵贱的能力**：知道怎么用估值分位判断现在是"该买"还是"该等"

| 想从入门走到精通（程序员） | **就是为你写的**：第六篇（15–20 章）+ 附录 D 路线图 |

## 三个前提假设

全书建立在三个明确假设上，如果你的情况不同，部分内容需要调整：

- **本金 1000 元**。所有手续费算例、仓位算例都按这个数字。资金量不同，成本占比会变（第 3 章有临界点表）。
- **只做 A 股和场内 ETF**。不涉及期货、期权、外汇、加密货币。
- **目标是学习和试水，不是赚钱**。1000 元一年赚 10% 是 100 元——这不是收入，这是学费的找零。

## 怎么用这本书

**不要通读。** 这本书是操作手册，不是小说。按这个顺序用：

```
第 1 周  →  第 1、2、3 章（规则与费用，必须一次读完）
第 2 周  →  第 4 章（开户 + 4.3 模拟盘教程），然后开始模拟盘
第 3-4 周 → 第 5、6、7 章（行情、ETF、估值），边学边在模拟盘验证
第 5-6 周 → 第 8、9 章（仓位、心理），这两章要反复读
第 7-8 周 → 第 10 章（财报），选读，看不懂先跳过
第 9-12 周 → 第 13 章（90 天计划），开始 1000 元实盘
随时      → 第 11、12、14 章（技术分析、量化、骗局），当参考书查
第 13 周+ → 第 15、19 章（配置与资产扩展），第二个 10 万阶段用
1 年后    → 第 16、17、18 章（因子、研究、风控），进阶
长期      → 第 20 章 + 附录 D（系统化与路线图）
```

每章结尾都有 **「本章要记住的 3 件事」** 和 **「动手做」**。动手做那一节不要跳过——这本书的价值一半在实操里。
