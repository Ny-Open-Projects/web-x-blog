# 量化交易分类

量化交易可从三个维度划分：**交易什么产品**、**靠什么盈利**、**用什么信号**。

## 一、按交易产品分类

| 策略 | 交易标的 | 核心逻辑 |
|---|---|---|
| 股票策略 | 股票 | 围绕股票价格与价值展开 |
| CTA（管理期货） | 期货 | 基于多空机制，关注资金头寸；**只要有波动就有机会，波动越大越有利**，与涨跌方向无关 |
| 期权策略 | 期权 | 关注期货相关的期权定价与组合 |
| FOF（母基金） | 股票/债券/期货/基金 | 一篮子组合，波动风险相对可控、收益更高 |

## 二、按盈利模式分类

- **单边多空**：要么做多、要么做空。如追涨杀跌，或其反向的追跌杀涨。
- **套利**：追求稳定的、接近无风险的收益。典型如两个相关性标的 a、b，一个涨另一个跌，按比例同时持有，赚取价差回归。
- **对冲**：由传统套利演化而来，如**阿尔法策略**（追求超越沪深300 等基准的超额收益）、**事件驱动策略**。

## 三、按策略信号（数学模型）分类

这是最核心的一层——不同流派本质是不同数学模型的体现：

1. **多因子策略**：择时与选股最基本的评价要素。例如「市值 > 1000 亿、行业 Top、PE < 20、近一年最大回撤 < 30%」各算一个因子，多因子组合筛选。选哪些因子、权重如何，考验个人能力。
2. **均值回归策略**：价格像身高遗传——终会向均值回归。持续上涨后未来可能跌，深跌之后可能涨。适用于长线、中线乃至日线/小时级短线。
3. **动量效应策略**：1993 年由两位美国学者提出，借物理学惯性——涨的标的倾向于继续涨，跌的倾向于继续跌；但超出平衡态后趋势会反转。
4. **二八轮动策略**：约 20% 的龙头/特殊股带领后面 80% 的股票，分波段变化。
5. **海归策略**：经典的入市/离市规则模型（趋势跟随类）。
6. **机器学习策略**：用 ML 从数据中学习非线性规律（进阶方向）。

> 小结：先选**产品**（股票/期货/期权/FOF），再定**盈利模式**（单边/套利/对冲），最后落到**信号流派**（多因子/均值回归/动量等）——三者共同定义一套完整策略。
