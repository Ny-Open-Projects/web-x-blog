# 量化系统的构成

## 一、用电脑类比

一台电脑由**输入设备（键盘鼠标）、主机（主板/CPU/内存）、输出设备（显示器）**组成。映射到量化交易系统：

| 电脑部件 | 量化系统组件 | 职责 |
|---|---|---|
| 显示器（输出） | **可视化** | 把接口数据用图表直观展示 |
| 键盘鼠标（输入） | **行情** | 投资品类（股票/债券/基金）当前价格与成交信息 |
| 主机（处理） | **策略 + 柜台** | 决策端 + 执行端 |

## 二、四大组件

1. **行情组件（数据端）**：指数（上证50、沪深300 等一篮子组合）与个股（如茅台）的每日价格、成交、资金流（北向资金等）、基本信息。
2. **个股与交易策略组件（决策端）**：在个股页结合技术指标（布林线、均线、RSI）与财务数据，决定买/卖——这就是「做决策」的过程。
3. **执行交易 / 柜台（执行端）**：券商称「柜台」，负责委托下单、成交、持仓与资金结算。**这是最核心、最不能出错的一环。**
4. **可视化（辅助端）**：把行情、资金、成交明细用图表展示，帮助直观判断。

> 一句话：量化系统 = **数据端 + 决策端 + 执行端**（外加可视化辅助），和其他软件系统一样，是「输入 → 处理 → 输出」的流程。

## 三、代码层三模块

用 Python 实现时，分为三大模块，对应上面三端：

```text
data      行情数据：指数 + 个股（价格/成交/资金流/基本信息）
strategy  交易策略：择时（布林/均线/RSI）+ 选股（市值/盈利/PE/PB 等因子）
trade     交易执行：委托下单、成交记录、持仓与收益/资金核算
chart     辅助模块：行情与成交的可视化
```

- **择时**：选择买卖时点，常用技术指标（布林线、移动平均、RSI）。
- **选股**：既可用技术类指标（市值），也可用基本面因子（盈利能力、净利润、PE/PB 估值）。
- **trade**：知道何时买卖后，调用接口委托；成交后记录持仓，用于计算收益与资金。

> 本站「数据看板」对应 **可视化 + 决策端**（指标计算与信号综合），「模拟盘」对应 **执行端**（不接真实资金），课程则对应把这三端从头到尾跑通。
