# 第9课 · 选币策略

> 数字货币上千个，股票几千只——**选币（选股）**解决“交易什么”，与“何时交易”的择时互补。一个完整策略往往先选出一批标的，再在其上做择时。

## 9.1 为什么需要选币

- **标的太多**：不可能全盯，需先缩小范围。
- **流动性**：成交额低的品种滑点大、难成交，甚至归零风险高。
- **波动与趋势**：不同品种风险收益特征差异巨大。

## 9.2 选币数据整理

先把多品种的行情整理成一张宽表，便于横向比较：

```python
import pandas as pd, glob

frames = []
for f in glob.glob("data/daily/*.csv"):
    d = pd.read_csv(f)
    d["symbol"] = f.split("/")[-1].replace(".csv", "")
    frames.append(d)
df = pd.concat(frames, ignore_index=True)

# 每个品种近 30 日的汇总指标
g = df.groupby("symbol").agg(
    avg_vol=("volume", "mean"),       # 平均成交量（流动性）
    vol=("close", "std"),             # 波动率
    ret=("close", lambda s: s.iloc[-1] / s.iloc[0] - 1),  # 区间涨幅（趋势）
).dropna()
```

## 9.3 多维护筛选

按目标设定阈值，筛出候选池：

```python
# 例：要“有流动性、有波动、有趋势”的品种
cand = g[(g.avg_vol > g.avg_vol.median())      # 流动性高于中位数
         & (g.vol > g.vol.quantile(0.6))        # 波动率前 40%
         & (g.ret > 0)]                          # 区间上涨
print(cand.sort_values("ret", ascending=False).head(10))
```

- **偏趋势**：提高 `ret` 权重，选强势品种做多。
- **偏稳健**：提高 `avg_vol`、降低 `vol`，选流动性好、波动小的。
- 筛选因子与权重，同样要**回测验证**，而非拍脑袋。

> 小结：选币 = 数据整理 + 多维护筛选 + 回测验证。选出候选池后，就能在其上运行第 7 课的择时策略了。下一课讲套利——赚取价差回归的、相对稳健的策略。
