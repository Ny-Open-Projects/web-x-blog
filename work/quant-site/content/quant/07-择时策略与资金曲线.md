# 第7课 · 择时策略与资金曲线

> 从这里进入策略核心。**择时**就是对着价格走势决定何时买、何时卖——适用于任何能画出价格曲线的品种（数字货币、股票、期货，甚至房价）。

## 7.1 产生交易信号（双均线示例）

最经典的择时之一：短期均线上穿长期均线（**金叉**）做多，下穿（**死叉**）平仓。

```python
import pandas as pd

df = pd.read_csv("data/eth_15min.csv")
df["ma_short"] = df["close"].rolling(10).mean()
df["ma_long"]  = df["close"].rolling(30).mean()

# 信号：金叉=1(做多)，死叉=0(空仓)
df["signal"] = 0
df.loc[df["ma_short"] > df["ma_long"], "signal"] = 1
df.loc[df["ma_short"] < df["ma_long"], "signal"] = 0
```

## 7.2 从信号到持仓：慢一根 K 线

信号按**收盘价**产生，而真实成交只能发生在**下一根 K 线的开盘**——所以实际持仓 `position` 要比 `signal` **慢一根**：

```python
df["position"] = df["signal"].shift(1)   # 延后一根，避免“未来函数”
df["position"].fillna(0, inplace=True)
```

> 这一步是回测不自欺的关键：杜绝用“当根收盘才知道的信号”去“当根开盘前成交”。

## 7.3 计算资金曲线

开仓：投入 `初始资金 × 杠杆`，按开盘价买入；收益来自开仓到收盘的涨跌幅：

```python
init_cash, leverage = 100, 3
df["change"] = df["close"].pct_change()

# 简化：持仓部分的资产随涨跌幅变动
df["equity"] = init_cash * (1 + leverage * df["position"] * df["change"]).cumprod()
df[["candlebegintime", "equity"]].plot(x="candlebegintime", y="equity")
```

## 7.4 爆仓判断

杠杆放大收益也放大风险。判断回测过程中是否爆仓：**只要某一天资金低于最小保证金，就判定爆仓**（程序应报警/停止）。

```python
min_margin = init_cash * 0.45        # 例：初始100、3倍杠杆 → 最小保证金45
if (df["equity"] < min_margin).any():
    print("历史存在爆仓，需降低杠杆或优化风控")
```

## 7.5 寻找最优参数 + 封装

把「导入→转周期→算信号→算资金曲线」封装成函数，即可批量遍历参数（如均线周期组合）寻优：

```python
def backtest(short, long_, leverage):
    df = load_and_resample("15T")
    df["signal"] = (df["close"].rolling(short).mean() > df["close"].rolling(long_).mean()).astype(int)
    df["position"] = df["signal"].shift(1).fillna(0)
    df["equity"] = (1 + leverage * df["position"] * df["close"].pct_change()).cumprod()
```
