# 第1课 · 量化投资介绍

> 本课为「数字货币 Python 量化投资实战」开篇，含 6 个课时：量化定义 → 市场特点 → 实操复盘 → 定投策略（Excel/Python 回测）。

## 1.1 什么是量化投资

**量化交易，就是用数学模型、而不是人脑，去决定交易的品种、方向、时机与数量。**

- 它把「买什么、看多还是看空、什么时候买卖、买多少」这些决策，交给规则与程序。
- 好处是**客观、可回测、可复现**：同一个策略在同一段历史上，结果唯一，不会因情绪反复。
- 本课程路线：从 Python 基础 → 数据处理(Pandas) → 交易所接口 → 择时/选币/套利策略 → 自动交易，最终跑通一个完整闭环。

## 1.2 数字货币市场特点

以比特币为例，理解这个标的所处的市场：

- **年轻**：2009 年 1 月诞生，历史已超过 A 股创业板。
- **牛熊周期**：十年经历约三轮牛熊，与比特币**四年减半**特性相关；每轮熊市从高点回撤往往超过 90%。
- **7×24 交易**：无涨跌停（区别于 A 股 ±10%）、全天候连续交易，波动远大于传统市场。
- **高风险高波动**：既可能短期暴涨，也可能深度回撤——**务必用小额、可承受亏损的资金，并严格止损**。

## 1.3 2018 量化实操复盘：为什么是「更弱的牌局」

讲师入场的一句话：*与其提高牌技，我更愿意花时间寻找对手更弱的牌局。* 新兴的币圈正是这样一个市场：

1. **系统性暴涨机会**：新市场、市值小，易出现爆发性上涨（成熟市场罕见）。
2. **套利机会**：市场不成熟、定价偏差多，存在「捡钱」式套利空间（后续课程详解）。
3. **参与者更弱**：对手平均水平更低，方法论优势更容易变现。

> 提醒：这是 2018 年的复盘视角；如今币圈机构化程度已大幅提高，「对手弱」的红利在下降，但**用规则与数据替代情绪**的核心不变。

## 1.4 ~ 1.6 定投策略：用数据回测「定投到底赚不赚」

**定投（DCA, Dollar-Cost Averaging）**：每隔固定时间投入固定金额，无论价格高低。它规避「择时」难题，靠时间摊平成本。

关键认知：
- **牛市定投，收益会低于一次性买入持有**（因为后期高位也买，拉高成本）；定投的价值在于**平滑波动、降低择时风险**，而非收益最大化。
- 定投的**时间段、频率、金额**会显著影响结果——这些都能用回测量化。

### 用 Python 回测定投（可运行）

```python
import pandas as pd

# 假设已有日线收盘价序列（此处用示例数据；实战从交易所接口获取）
prices = pd.Series(
    [100, 90, 80, 120, 150, 130, 160, 200, 180, 220],
    index=pd.date_range("2024-01-01", periods=10, freq="D"),
    name="close",
)

def dca_backtest(prices: pd.Series, per_day: float = 100.0):
    coins = 0.0          # 累计买入份额
    cost = 0.0           # 累计投入成本
    for p in prices:
        coins += per_day / p
        cost += per_day
    final_value = coins * prices.iloc[-1]
    return {
        "总投入": round(cost, 2),
        "期末市值": round(final_value, 2),
        "收益率": round((final_value - cost) / cost * 100, 2),
        "平均成本": round(cost / coins, 4),
        "持有份额": round(coins, 4),
    }

print(dca_backtest(prices, per_day=100))
# 期末市值 > 总投入即为正收益；平均成本体现「摊平」效果
```

回测要回答的问题：不同起止时间、不同频率（日投/周投）、不同金额下，收益率与最大回撤如何变化——这就是「用数据决定怎么定投更有效」。

> 小结：第 1 课建立了两块基石——**量化 = 用模型替代人脑决策**，以及**任何策略先用历史数据回测、再谈实盘**。下一课进入 Python 与 Pandas 基础，为策略编码做准备。
