# 第2课 · 比特币与区块链基础

> 做量化，要先懂你交易的品种。数字货币繁多，但都借鉴了比特币的原理——读懂比特币，就懂了数字货币圈的大半。

## 2.1 什么是区块链

货币最重要的用处是**交易**，每一笔交易都要被记录。区块链本质上是一个**分布式账本**：把一段时间内发生的多笔交易打包成一个「区块」，每个区块通过哈希值链接到前一个区块，形成一条「链」。

- **不可篡改**：每个区块包含前一区块的哈希，改动任一历史区块会导致后续全部哈希对不上。
- **公开可验证**：账本由全网节点共同维护，任何人可下载、可核对。

## 2.2 如何完成一笔交易

交易记账需要「账号 + 密码」，在区块链里对应**公钥与私钥**：

- **私钥**：一串 256 位二进制数字（0/1）。无需向谁申请，甚至可抛 256 次硬币生成；一般用钱包软件生成。
- **公钥/地址**：由私钥推导，相当于「账号」，可公开，用于接收资产。
- **签名**：用私钥对交易签名，全网可用公钥验证「确实是你发的、且未被篡改」。

> 核心认知：**谁掌握私钥，谁掌握资产**。私钥丢失=资产丢失，私钥泄露=资产可被转走。

## 2.3 去中心化记账

没有中心机构，如何记账？比特币的答案是**去中心化**：人人都可记账，人人都可保留完整账本。

- 下载开源客户端 → 自动加入比特币 **P2P 网络**（类似 BT/迅雷的成熟技术）。
- 任一节点收到交易，转发给相邻节点，瞬间传遍全球。
- 通过**工作量证明（PoW，即挖矿）**竞争记账权，胜出者把新区块广播全网，获得比特币奖励。

## 2.4 攻击比特币：攻防模拟

| 攻击 | 为何失败 |
|---|---|
| 篡改某笔交易 | 哈希保证单笔难改；且账本存在每个节点，改不了一台就改不了全网 |
| 拒绝服务（不收录某地址交易） | 单个矿工本时段可不收录，但下个时段其他矿工会收录，无法长期屏蔽 |
| 双花（同一笔钱花两次） | 需控制超过全网 50% 算力重写历史，成本极高 |

## 2.5 比特币的历史与未来

- 2007.05 中本聪开始写代码 → 2008.08 注册 bitcoin.org → 2008.10 发布白皮书 → 2009.01.03 创世区块诞生。
- **四年减半**：每约 4 年产出速率减半，是理解其周期与叙事的重要变量。
- 十年三轮牛熊，每轮熊市高点回撤常超 90%——**高波动是这个标的的底色**，量化务必严控仓位与止损。

> 小结：第 2 课建立对标的的认知——区块链是不可篡改的分布式账本，私钥即资产，去中心化靠 PoW 维护，高波动需敬畏。下一课进入 Python 编程基础。
