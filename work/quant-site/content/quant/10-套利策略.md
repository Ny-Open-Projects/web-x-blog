# 第10课 · 套利策略

> 套利追求**赚取价差回归**的、相对稳健的收益。本课以数字货币合约（期货）为载体，讲跨期套利及其风险。

## 10.1 合约基础

交易所的**合约就是期货**：

- 合约价格相对独立，由自身五档盘口决定，但**围绕现货价格上下波动**（极端情况会大幅偏离）。
- **贴水**：合约价 < 现货价；**升水**：合约价 > 现货价。
- 合约可加杠杆、可做多/做空，收益被杠杆放大——**风险同样放大**。

## 10.2 跨期套利

**跨期套利**：同时建仓**当周合约**与**季度合约**，赚两个合约之间**价差**的回归，而非赌方向。

- 当价差处于统计上的高位/低位时，做空价差 / 做多价差，等价差回归获利。
- 价差朝预期方向变动约 **1%**，在杠杆作用下收益可达约 **10%**——具体取决于杠杆与投入（第 11.3 节有完整推导）。
- **网格策略**：把建仓/加仓价位按网格分批布置，平滑入场成本、降低一次性判断错误的冲击。

## 10.3 收益计算（概念）

```
单个合约收益率(美金本位) ≈ (平仓价 - 开仓价) / 开仓价 × 杠杆方向
跨期套利总收益 = 当周合约腿 + 季度合约腿 两腿收益之和
```
> 精确收益要把保证金、杠杆、手续费一起算——先把“价差变动 1% 如何变成约 10% 收益”的推导搞清楚，再上实盘。

## 10.4 风控启示：一次真实爆仓

助教曾实盘跨期套利，因**价差短期逆向波动 + 杠杆过高**而爆仓。教训：

- 套利不是无风险，**价差可以短期继续扩大」**，极端行情下会打爆保证金。
- **绝不重仓、绝不高杠杆**；给价差逆向留足缓冲（网格 + 分批 + 止损）。
- 上实盘前，用历史数据把“最坏情况下价差能走多远、自己会不会爆”算清楚。

> 小结：套利用价差回归赚钱，跨期套利 + 网格能平滑风险，但杠杆是双刃剑——风控永远排在收益前面。至此策略篇（择时/选币/套利）已闭环。
