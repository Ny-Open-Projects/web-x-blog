# 用户画像与增长分析

## 一、用户画像

**用户画像**，就是用一组标签描述一类用户，也就是各类描述用户数据的变量集合：

- **基本属性**：年龄、性别、地域、职业。
- **兴趣偏好 / 消费行为**：爱社交还是运动、消费力强弱。

把多种标签组合，就能实现**用户分群**，做差异化运营（如「25-40 岁女性」是婴幼儿用品主力人群）。

## 二、埋点与数据标签体系

要知道用户做了什么，先要**采集行为数据**：这就是**埋点**：在产品关键节点埋代码，记录点击、浏览、下单等事件。埋点数据汇成**数据标签系统**，是画像与转化的原料。

```text
事件(谁-何时-在何页面-做了什么) → 日志 → 清洗 → 标签/指标
```

## 三、流量与转化漏斗

流量=访问量，是核心资产；转化=流量变成交易。用**漏斗**看每一环的流失：

```text
曝光 → 点击 → 加购 → 下单 → 支付
```
定位流失最大的环节，针对性优化（如「下单→支付」流失高，可能是支付流程问题）。

## 四、消费行为分析

研究消费者特征与行为如何影响企业：
- **消费者画像**：谁在买（人群特征）。
- **行为路径**：从认识到复购的旅程。
- **影响因素**：价格、评价、促销对决策的影响。

## 迁移到量化

- **画像/分群** → 给标的打标签（行业/市值/波动/趋势）分组研究。
- **漏斗/转化** → 策略信号的「触发→确认→执行」各环节效率。
- **行为路径** → 资金流向的「建仓→加仓→获利→撤离」轨迹。

> 画像是为了分群，埋点是为了采集，漏斗是为了定位瓶颈。
