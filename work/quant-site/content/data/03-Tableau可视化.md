# 数据可视化 Tableau

## 为什么可视化

可视化在分析流程的**探索**与**展示**两环都关键：
- 探索：把数据画成图，比看数字更快发现规律、异常。
- 展示：用合适的图表作为讲解依据，让结论有说服力。

## 常用工具

| 工具 | 定位 |
|---|---|
| Excel 图表 | 最基础的可视化 |
| **Tableau** | 专业 BI，拖拽式做交互图表与仪表盘 |
| Python（matplotlib / ECharts） | 编程式、可定制的可视化 |

## Tableau 要点

- **连接数据**：接 Excel / 数据库 / CSV。
- **维度与度量**：维度=分类（如日期、行业），度量=数值（如成交量、收益率）；拖拽即可生成图表。
- **图表选择**：趋势用折线，对比用柱状，占比用饼/堆叠，分布用直方图/散点，地理用地图。
- **仪表盘**：把多张图组合成交互式看板，加筛选器联动。
- **保存与发布**：发布成网页/图片，嵌入报告。

> 量化里，K 线图、资金曲线、回测净值、指标分布都是可视化，本站「数据看板」就是一张交互式仪表盘。
