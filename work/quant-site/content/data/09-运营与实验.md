# 数据驱动运营与实验

## 一、销售额预测（GMV）

**GMV**（成交总额）是销售/运营的核心 KPI。预测它的方法：

- **时间序列**：用历史 GMV 的趋势 + 周期（如节假日）外推。
- **回归/相关分析**：把 GMV 与流量、转化率、客单价等驱动因子关联，量化各因子贡献。

```python
# 简化：GMV ≈ 流量 × 转化率 × 客单价
gmv = traffic * cvr * aov
# 预测就是预测右侧三个驱动因子，再相乘
```

> 预测「组合未来收益」同样拆解为 胜率、盈亏比、交易频率 等驱动因子。

## 二、用户留存与生命周期价值

- **留存**：新用户次日/7日/30 日回访比例，衡量产品粘性。
- **生命周期价值（LTV）**：一个用户全周期贡献的价值；LTV > 获客成本（CAC）才健康。

## 三、A/B 实验

两个方案谁更好？用 **A/B 测试**让数据说话：

```text
① 提出假设（如"按钮变红提升点击"）
② 分流：用户随机分 A/B 组，其他条件一致
③ 运行足够样本量
④ 用统计检验判断差异是否显著（非偶然）
```

> 策略和参数的对比，本质就是一次 A/B 测试：同一段历史、同一风控下对比两组参数，用收益率、夏普、最大回撤判断差异是否真实。

## 四、数据报告与表达

- **结构**：背景 → 目标 → 方法 → 发现（图表）→ 结论 → 建议。
- **一图胜千言**：每个核心发现配一张最合适的图。
- **面试**：能讲清「你做过的一个完整分析」，目标、取数、方法、结论、价值。

> 预测用模型、实验用 A/B、表达靠报告，至此数据分析从工具到思维到应用形成闭环。你已具备用数据解决问题、并把它讲清楚的全套能力。
