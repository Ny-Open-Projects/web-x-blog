# 高级可视化

`matplotlib` 是 Python 绘图的地基。上一节把数据算成了结构，这一节把它变成能说服人的图。重点不是会画多少种图，而是**每种图回答什么问题**，以及怎么调得清楚、专业。

## 一、画布与视觉元素

一切从 Figure（画布）和 Axes（坐标系）开始。显式建画布，比 `plt.plot` 默认那一套更好控制。

```python
import matplotlib
matplotlib.use("Agg")          # 无界面环境也能出图
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(10, 4), dpi=120)
ax.plot([1, 2, 3, 4], [3, 1, 4, 2], color="#f04a4a", linewidth=1.8)
ax.set_title("示例折线", fontsize=14)
ax.set_xlabel("时间"); ax.set_ylabel("价格")
ax.grid(True, alpha=0.3)
fig.tight_layout()
fig.savefig("line.png")
```

常用视觉旋钮：`figsize` 控制比例、`dpi` 控制清晰度、`color` 用十六进制更可控、`grid(alpha=0.3)` 加淡网格、`tight_layout` 防止标签被裁。中文显示要指定字体，否则是方框，后面案例给出做法。本地出图前设 `plt.rcParams['font.sans-serif']=['PingFang SC']`（mac）或对应中文字体，并设 `plt.rcParams['axes.unicode_minus']=False`，中文标签即可正常显示。

## 二、图表选型：先想清楚回答什么问题

| 图 | 回答的问题 | 典型场景 |
| --- | --- | --- |
| 直方图 | 一组数怎么分布 | 收益率分布、PE 分布 |
| 折线 | 随时间的趋势 | 净值曲线、价格走势 |
| 柱状 | 类别之间对比 | 各行业平均收益 |
| 散点 | 两个变量的关系 | 成交量与涨跌 |
| 饼图 | 构成占比 | 仓位行业分布 |
| 热力图 | 多变量相关强弱 | 因子相关性矩阵 |
| 箱线图 | 分布与异常值 | 各行业收益离散度 |

选错图比不画图更糟。趋势用柱、对比用饼，读者一眼就困惑。

## 三、直方图与折线：分布与趋势

```python
import numpy as np, pandas as pd
import matplotlib.pyplot as plt
matplotlib.use("Agg")

np.random.seed(3)
ret = np.random.normal(0.001, 0.02, 250)

fig, axes = plt.subplots(1, 2, figsize=(12, 4))
axes[0].hist(ret, bins=30, color="#1fb786", alpha=0.8)
axes[0].set_title("日收益率分布")
axes[1].plot(np.cumprod(1 + ret), color="#f04a4a")
axes[1].set_title("净值曲线")
fig.tight_layout(); fig.savefig("dist_trend.png")
```

左图看分布形态（是否近似正态、有无厚尾），右图看累计净值走势。

## 四、散点图：看两个变量的关系

```python
vol = np.abs(ret) * 100
chg = ret * 100
plt.figure(figsize=(7, 5))
plt.scatter(vol, chg, alpha=0.5, color="#3b82f6")
plt.xlabel("当日波动率(%)"); plt.ylabel("当日涨跌(%)")
plt.title("波动与涨跌的关系")
plt.savefig("scatter.png")
```

如果两点呈正相关，说明波动大的日子涨跌幅也大；散成一团则说明两者无关。

## 五、热力图：相关性矩阵

多因子分析里，先看清因子之间是否高度相关（共线），比直接上模型更重要。用 `imshow` 画相关性矩阵，无需额外依赖。

```python
import numpy as np
import matplotlib.pyplot as plt
matplotlib.use("Agg")

np.random.seed(5)
# 三列模拟因子收益
a = np.random.normal(0, 1, 200)
b = 0.7 * a + np.random.normal(0, 0.7, 200)   # 与 a 高度相关
c = np.random.normal(0, 1, 200)               # 独立
M = np.corrcoef(np.vstack([a, b, c]))
labels = ["因子A", "因子B", "因子C"]

fig, ax = plt.subplots(figsize=(5, 4))
im = ax.imshow(M, cmap="RdYlGn", vmin=-1, vmax=1)
ax.set_xticks(range(3)); ax.set_yticks(range(3))
ax.set_xticklabels(labels); ax.set_yticklabels(labels)
for i in range(3):
    for j in range(3):
        ax.text(j, i, f"{M[i, j]:.2f}", ha="center", va="center")
fig.colorbar(im)
fig.savefig("heatmap.png")
```

颜色越红相关越强。A 与 B 接近 0.7，提示两者信息重叠，建模时保留一个即可。

## 六、箱线图：分布对比与异常值

比较不同行业收益的离散程度，箱线图比均值更有信息量：它显示中位数、四分位和异常点。

```python
import numpy as np
import matplotlib.pyplot as plt
matplotlib.use("Agg")

np.random.seed(9)
bank = np.random.normal(0.0004, 0.008, 250)
semi = np.random.normal(0.0012, 0.020, 250)
fig, ax = plt.subplots(figsize=(6, 4))
ax.boxplot([bank, semi], patch_artist=True)
ax.set_xticklabels(["银行", "半导体"])
ax.set_ylabel("日收益率")
ax.set_title("两行业收益分布对比")
fig.savefig("box.png")
```

半导体箱子更高、须更长，直观说明它波动大、机会与风险都更极端。

## 七、词云：文本高频词

文本字段（新闻、研报、标签）想一眼看重点，用词云。标准库 `wordcloud` 需要单独安装，下面给出可运行替代：用条形图展示词频，零依赖；并附上 `wordcloud` 的写法供有环境时用。

```python
import matplotlib.pyplot as plt
matplotlib.use("Agg")

tags = {"新能源": 42, "半导体": 38, "医药": 21, "银行": 15, "消费": 12}
items = sorted(tags.items(), key=lambda x: x[1], reverse=True)
words, cnt = zip(*items)
plt.figure(figsize=(8, 4))
plt.barh(words[::-1], cnt[::-1], color="#3b82f6")
plt.title("研报标签词频（零依赖替代词云）")
plt.savefig("tags.png")
```

若已安装 `wordcloud`，可直接：`from wordcloud import WordCloud; WordCloud(font_path="...").generate_from_frequencies(tags).to_file("cloud.png")`。注意中文字体路径要显式传入，否则乱码。

## 八、实战：一份股票数据分析报告

把上面的图串起来，就是一份迷你分析报告：净值、分布、相关性、行业对比四张图同屏。

```python
import numpy as np, pandas as pd
import matplotlib.pyplot as plt
matplotlib.use("Agg")

np.random.seed(11)
dates = pd.date_range("2025-01-02", periods=250, freq="B")
close = 10 * np.cumprod(1 + np.random.normal(0.001, 0.015, 250))
ret = pd.Series(close).pct_change().dropna()

fig, ax = plt.subplots(2, 2, figsize=(12, 8))
ax[0, 0].plot(close, color="#f04a4a"); ax[0, 0].set_title("价格走势")
ax[0, 1].hist(ret, bins=30, color="#1fb786"); ax[0, 1].set_title("日收益分布")
ax[1, 0].scatter(range(len(ret)), ret, s=8, alpha=0.4); ax[1, 0].set_title("收益散点")
ax[1, 1].boxplot(ret.values); ax[1, 1].set_title("收益箱线")
fig.suptitle("示例标的分析报告")
fig.tight_layout(); fig.savefig("report.png")
print("年化收益约", f"{(close[-1]/close[0]-1)*100:.1f}%")
```

四张图分别对应趋势、分布、关系、离散度，覆盖了单标的分析骨架。把 `close` 换成真实行情，就是一份可交付的报告。

## 九、迁移到量化

- **净值曲线 + 回撤**：任何策略先画净值，再画水下曲线（回撤），可读性远高于一张收益表。
- **相关性热力图**：多因子选股前必看，剔除共线因子。
- **箱线图**：对比策略在不同市场环境下的收益分布，而不只是看平均。
- **图表即证据**：量化结论要让别人一眼看懂，图表选型正确，说服力就先赢一半。
