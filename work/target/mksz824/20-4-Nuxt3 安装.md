# 20-4-Nuxt3 安装

讲完 Nuxt 3 的特点和优势，第一步就是安装。整个过程可以参考官方文档的 installation 小节，当然其中还有一些意想不到的问题，我会和大家一起过一遍安装流程。

先说前提，我总结为两条。第一是 Node.js 的版本：要在 18 以上，需要一个比较新的版本。第二是编辑器要求：使用 Visual Studio Code（我们也一直在用它），并且要装 Volar 这个 Vue 插件。用 Vue 的大多数人应该已经装了，这里不多说。

满足前提后开始安装，核心命令是 `npx nuxi@latest init` 加上项目名。我这里已经装过，就不带着装了。它会弹出一些提示，比如选择哪个 package manager、是否初始化一个 git repository，选择安装即可，很简单。

安装过程中会有一个小问题要特别注意：使用命令安装有可能失败。因为它要从 raw.githubusercontent.com 下载内容，由于众所周知的原因无法访问，会下载失败。这里给大家两条解决方案，喜欢哪条用哪条。

第一条是把网址用 IP 解析，因为 IP 还是可以访问的。将映射关系添加到 hosts 文件中：Windows 和 Mac 的 hosts 路径不同，添加的内容就是把网址映射到对应的 IP。IP 可能会变化，可以用查询网站查这个网址当前对应的 IP，选一个放进去即可。

如果觉得麻烦或者还是不行，可以直接用简单粗暴的方法：clone 原项目。其实 nuxi 工具本质上就是提供了一个友好的界面，最终完成的是 clone 功能。使用 `git clone -b v3` 加上分支地址和你起的项目名即可，项目就是 Nuxt 的模板，切换到 v3 分支，里面的内容就是最终创建出来的内容。

安装完毕后启动。运行 `npm run dev -- -o`，后面的参数表示把启动的网址直接在浏览器打开，省得再输入一次。它直接弹到 localhost:3000 并打开。第一次启动要等待一会儿，因为需要前端和后端两部分都启动。看到欢迎界面就说明启动成功了。

再来看看项目里的文件，其实就是刚才 GitHub repo 里的内容，非常简单：只有几个文件，是个很轻量但功能强大的框架。app.vue 是入口文件，里面有一个内置的全局组件 NuxtWelcome，就是展示欢迎内容的。public 放公共文件，这里只放了 favicon。server 可以放一系列后端相关的代码：Nuxt 3 是全栈框架，不仅能写前端还能写后端，后端代码都放在 server 中。还有配置文件 nuxt.config.ts，关于 Nuxt 的方方面面的配置都写在这里。其他文件大家都熟悉了：tsconfig.json、package.json、package-lock.json。README 里有具体如何启动的帮助，自己看一下就好。

项目里还内置了一个很强大的 DevTools。页面上会浮动一个小图标，它是否启用由配置文件中的 devtools: true 控制，启动开发环境时会弹出这个工具。点击 Get Started 进入后，首页会展示一系列信息：版本、已有的全局组件、import 等等。这些功能是什么、怎么用，之后慢慢描述，现在先不展开。
