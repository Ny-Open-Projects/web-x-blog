# 21-2-Tailwind 规则演示

上节课配置好了 Tailwind CSS，加了两个类名但没讲命名规则。这节课把玩一下这个工具，弄清类名是怎样组织的。我们来到它的文档，左侧把类名分成很多类：layout、flexbox、spacing、sizing 等等。不会逐个讲，只挑几个让大家熟悉通用的命名规则。

特别提醒：文档支持搜索，任何想了解的 CSS 属性都可以直接搜，会列出最相近的类名。比如搜 color，decoration color、border color、background color 等相关内容都会出现。

## 字体大小与字重

先看字体大小。`text-base` 是最基础的文本大小，实际添加的是 `font-size: 1rem` 和 `line-height: 1.5rem`，文档里还标注了换算后的 16px、24px。再往上有 `text-lg`、`text-xl`、`2xl`、`3xl` 等一系列档位，每个都有具体解释，比如 3xl 对应 font-size 1.875rem。把 `text-2xl` 加到 h1 上，保存后字体明显变大了。

字体的加粗程度对应 font weight，同样用类名表示。加一个 `bold`，保存后文字就加粗了。

## 颜色的通用规则

颜色是一套通用方案。Tailwind 提供了独特的色板，每种色系固定 11 个色号，用数字表示：50、100、200 直到 950。数字越大颜色越深，越小越浅，从浅到深排列。

任何和颜色相关的属性都能与这些色号组合。比如背景色，搜 background color 可以看到 `bg` 是前缀，后面跟色系和色号，比如 `bg-slate-50`。我们来加一个 300 号的红色，写 `bg-red-300`，编辑器里能实时预览颜色，这是插件很方便的地方。保存后背景颜色就变了。

文字颜色规则完全一样，只是前缀换成 `text-`，比如 `text-blue-700`，保存后文字颜色随之改变。课下可以自行探索其他颜色属性，命名规则是通用的。

## 方位缩写

有些值可以从四个方位分别添加，Tailwind 用特殊字符表示。以内边距 padding 为例：`px` 是横向的值，`py` 是纵向的值，还有 `pt`、`pb` 等单边取值，规则很多不一一列举。取值范围很丰富，从 0.5、1 一直到 96，基本涵盖所有需求。

加一个 `px-5`，文档里能看到它实际添加的是 `padding-left` 和 `padding-right` 各 1.25rem，也就是 20px。保存后内边距就出现了。margin 的规则和 padding 完全一样，比如 `my-6` 加纵向外间距，保存后两块外间距立即可见。

## 状态修饰符与响应式

Tailwind 的一大创新是状态修饰符。最基础的是 hover：在属性前加 `hover` 单词再加冒号即可。它几乎支持所有 CSS 修饰符，能想到的都有对应前缀。

实验一下：希望鼠标放上去时文字变绿，写 `hover:text-green-700`。保存后鼠标悬停，文字确实变成了绿色。

另一个典型场景是响应式设计。文档里有一系列 breakpoint：sm、md、lg、xl、2xl，代表不同宽度。在特定断点生效，就把 breakpoint 前缀加在属性前面。

Tailwind 秉承 mobile first 思想，所以要先写手机端的样式。比如手机端希望字符很大，设成 `text-6xl`，然后在大于等于 lg（1024px）时用新样式覆盖，改成 `text-lg`：

```html
<h1 class="text-6xl lg:text-lg">
```

桌面端看到的是 lg 的正常大小，切换到手机尺寸时，6xl 的超大字符就生效了。
