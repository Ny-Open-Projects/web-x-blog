# 10-26-mongoDB 安装第一部分：下载运行

这节课简单讲解 MongoDB 在本地的安装和运行。这是非常基础的内容，我不会详细讲解，同时会以文档的形式供大家参考。毕竟在安装软件这种步骤性的内容中，文档肯定是更好用的。虽然安装看起来很简单，但其中有一些非常有意思的点，可以供我们以后更深入地了解 MongoDB，也可以更深入地了解一些 Linux 命令。

首先来到下载地址，大家特别注意要到官方的下载地址。点进来以后是一个对应的网页，里面有几种版本，我们特别注意是 community 版本，不是 enterprise server，因为社区版本是完全开源并且免费使用的版本。在这里可以选择对应的版本：version 选最新的；然后选择不同的 platform，Windows 用户选 Windows 下载，我这里是 macOS，所以选择 Mac。它会下载一个对应的压缩包。

在 Mac 上下载安装其实有几种方式。第一种是手动下载对应的安装包，然后手动配置安装，这个手段不仅适用于 Mac，也适用于 Linux。第二种是采用 Homebrew 安装，Homebrew 是 Mac 上非常出名、大家都会使用的包管理器。我在这里采用手动安装的过程，因为我认为手动安装的过程中能学到非常多有意思的点，而且更加灵活，对整个启动的参数和过程也会更加了解。手动安装学会后，再用 Homebrew 安装、甚至 Windows 安装，你会发现原理其实都是一样的。

官网中都有特定的文档对这个过程进行详细的讲解。我强烈建议大家在安装任何软件的时候都去看对应的官方文档。虽然是英文、可能比较难懂，但也可以试着去查。我认为官方文档第一写得非常详细，第二对新版本有比较快的更新，会告诉你其中的一些坑。这里分别对应几种安装手段：Windows 安装可以参考这个文档；macOS 使用 Homebrew 安装参考这个文档；macOS 手动安装可以看这个文档。我就是看了对应的文档再进行抽取的。

第一步是下载。使用手动方式，先进入 /usr/local 路径，这是一个常用的 Linux 下存放用户软件的位置。进入以后进行下载。大家特别注意，这个目录有固定权限，只有 root 才能写入，所以要使用 sudo 进行下载。使用 `curl -O`，链接可以在下载页点 Copy Link 获得，粘贴进去回车就可以下载。这个压缩包有六十多兆，要稍微等一会儿。我这里已经下载完毕了，下载完毕它就是一个压缩包。

下一步是解压缩，同样要注意也要 sudo，要有权限。使用 `zvxf` 解压，输入密码。解压以后进去看看里面有什么：文件夹名是 mongodb-macos-x86_64-5.0.3 这类形式。ls 一下，发现里面有几个文本文件，都是协议，不用管；最重要的目录称之为 bin 目录。bin 里面有几个可执行的文件：第一个是 install_compass，第二个是 mongo，第三个是 mongod，最后是 mongos。这是一系列 MongoDB 提供给我们的可执行的二进制文件，其中最重要的就是 mongod，它是运行启动一个 MongoDB server 的最主要二进制文件，之后我们主要跟它打交道。

现在可以直接运行这个二进制命令启动了。但首先还需要准备一个文件夹存放 MongoDB 数据库的文件。文档中有一段很有意思：默认的文件夹是 /data/db，注意 /data 是一个根目录。但这里特别提示了一个 important notice：在 macOS 10.15 以上，苹果会限制默认文件夹（/data/db）的访问。所以最好的办法是，假如你是新版本 macOS，最好使用另外的文件夹地址。理论上来说可以创建任意路径的文件夹，但要特别注意权限问题，保证新建的文件夹是有权限的。假如你直接在 /usr/local 里创建，会发现 permission denied，当前用户在里面是没有权限的。

所以我们选择另外的文件夹：/usr/local/var。var 代表 variable，是安装软件的一系列变量或资源的存放位置，里面有一系列的软件存放地址，也是官方文档推荐的位置。把文件夹新建在这里：mkdir -p mongodb，可以看到在这个目录当中我们有权限，可以直接创建。

准备就绪后就可以直接运行了。回到刚才解压缩的文件夹，进入到 bin 下面，运行 mongod，加一个参数 --dbpath，把新建的文件夹路径输入进去，注意不要输错，回车就可以完成启动。terminal 上会弹出一系列信息告诉你启动成功：没有任何错误信息就说明启动成功了。用 Control C 关闭一下，进入刚才的数据库文件夹看一下有什么新东西：在 /usr/local/var/mongodb 里 ls，会发现自动创建了一系列文件，它们就是 MongoDB 的数据库文件。

现在启动成功了，但还有一个问题：每次运行这个二进制文件，我们都需要进入那个特定的文件夹，也就是下载并解压缩的这个文件夹，它的路径很长而且麻烦。能否将 MongoDB 变成一个全局命令呢？像 node、npm 那样直接敲命令就能运行，这样会方便很多。带着这个疑问，下节课我们看看怎样完成这个任务。
