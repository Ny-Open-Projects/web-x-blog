# 16-3-3-拖拽改变大小 编码第二部分： 实现四个角拖拽大小

上节课成功完成了右下角的缩放功能，现在把逻辑衍生到其他三个角，让它们都可以完成缩放。

## 参数类型与 calculateSize 函数

startResize 这个方法希望可以重用，所以要添加一个新的参数，告知是完成哪个方向的 resize。先确定参数类型，创建一个字符串字面量类型：`ResizeDirection`，包含四个方向：`top-left`、`top-right`、`bottom-left`、`bottom-right`，只有这四个。

仿照之前的 `calculateMovePosition`，创建一个随鼠标移动的处理函数，根据不同的场景计算值并返回，但逻辑要更复杂一些，叫 `calculateSize`。它有哪些参数呢？

- 第一个是 `direction`，向哪个方向移动，类型是刚才确定的 ResizeDirection；
- 第二个是 MouseEvent `e`；
- 还有一个很重要的数据：元素开始拖动时的一系列坐标值，图上的 top、right、left、bottom 都需要。特别注意：**这个值不能在这个函数里获取**，因为函数是在 move 时调用的，那时值会一直变化；要获得的是原始值，所以要在 startResize 时获取，然后作为参数传入。它是一个对象，类型里有四项：left、right、top、bottom，都是 number 类型。总类型称为 `OriginalPositions`，作为第三个参数传入，叫 `positions`；
- 还有一个数据是 container 的 offsetLeft 和 offsetTop，这个可以在函数里面获取，因为它是不变的。

先把数据都取出来：从 e 里拿到需要的 clientX 和 clientY 坐标值；从 positions 里拿到 left、right、top、bottom；container 用 `document.getElementById` 直接拿，和上面一样。

## 计算六组值

拿到这些值以后就可以开始计算了。特别注意：几种情形之间值会重复使用，对照图能搞得很清楚：

- **情形一（右下）**：只有高度和宽度在改变。往右延伸的宽度称为 `rightWidth`，等于 clientX - left；向下延伸的高度称为 `bottomHeight`，等于 clientY - top。
- **情形二（右上）**：宽度一样是向右延伸（rightWidth）；高度是向上的，称为 `topHeight`，等于 bottom - clientY。另外 top 值也改变了，称为 `topOffset`，等于 clientY - container.offsetTop。
- **情形三（左下）**：向下增加的高度（bottomHeight）和前面一致；宽度因为向左延伸，等于 right - clientX，和 rightWidth 做区分，叫 `leftWidth`。另外 left 值也在改变，这是一个新的值，加到最下面：`leftOffset`，等于 clientX - container.offsetLeft。
- **情形四（左上）**：只是它们的排列组合而已，四个值都要返回，但所需的值之前都完成计算了。

可以对照图复核这些值。有图的话先分析再写就简单很多，凭空计算很容易出错。

## switch 返回

有了所有的值就可以进行返回了。使用 switch 对四种情况进行处理，switch 的对象是 direction。第一个 case 写最复杂的 top-left，它四个值都返回。四种不同情形分别返回各自的一系列值，还是要对照图，以免出错。

calculateSize 是一个非常重要的函数，也是整个过程的灵魂所在。写这个逻辑时，一定要先把图画出来，然后对照图上的指示进行计算，这样就不容易出错。

## 改造 startResize

写完 calculateSize 后改造 startResize：给它添加一个参数知道往哪个方向动，也叫 `direction`，类型 ResizeDirection。之前的 MouseEvent 参数在这里根本没使用，可以去掉。

在 startResize 里首先获取最开始的值。这里修改一下 currentElement，把它直接类型断言成 HTMLElement，因为开始移动的时候 DOM 节点肯定存在。然后从 currentElement 上用 getBoundingClientRect 方法把四个值都拿出来：left、right、top、bottom。原来的简单计算逻辑删掉，改用 calculateSize 计算：

```ts
const size = calculateSize(direction, e, { left, right, top, bottom })
```

可以看到 size 是一个联合类型，并且有可能是 undefined，因为默认的 case 什么都没有返回，所以使用时要判断一下。

然后改它的 style，先把 style 从 currentElement 中提出来。首先判断 size 存在；先写两个肯定存在的：`style.width = size.width + 'px'`，还有 height，也是肯定存在的，`style.height = size.height + 'px'`。另外两个值因为 left 和 top 不是每次都返回（有些情形才返回），所以要加判断：先判断 `size.left` 存在（TS 会智能地判断出类型是可选的），然后 `style.left = size.left + 'px'`；最后判断 `size.top`，`style.top = size.top + 'px'`。

## 绑定四个方向

将 startResize 绑定到一系列 resizer 上去，带着不同的参数（不同的 direction）绑定：`@mousedown.stop="startResize('top-left')"` 等等，可以看到 top-left、top-right、bottom-left、bottom-right 一一对应。

试一下成果：最简单的情况（右下）没问题；然后是右上，也没问题；再试左下，没问题；最后是最复杂的左上，四个值都要改，也没有问题。任务完成。
