# 11-9-更新文档第二部分：更新数组内容

这节课继续介绍更新文档的方式。上节课都是对象级别的更新，这次说一个更深入的数据结构：数组。为了配合讲解，我把数据更新了一下：给记录添加了 hobbies 属性，对应一个数组，里面有一项 music。我们一直在操作 LeBron 这条记录，就用它来演示。

对数组的操作不只是像上节课那样用 $set 直接换成新数组，很多时候需要修改数组中的内容：添加新的一项、删除一项、替换其中的项等。这里介绍几个新的数组操作符。update operators 里先学比较简单的 pop、pull 和 push；除了这些，还有一系列配套的操作符叫 update operator modifiers，会学 $each 和 $position，知道 modifier 是配合主操作符使用的就行。看到这里大家应该会发现，MongoDB 的很多操作都是围绕操作符展开的，记住常用操作符是必须完成的任务，课下要多复习几遍。

第一个是插入操作，用 $push。它向数组中增加特定元素，也可以创建新数组：如果 document 中存在相应的数组字段（比如我们的 hobbies 已经存在），它就向数组尾部插入一个元素；如果不存在，它会在 document 中创建这个数组字段并初始化。

回到代码，先把之前的注释掉，复制一份。因为数据里加了 hobbies，为了自动联想，我们给泛型里也加上 hobbies 的类型。用 $push 操作符：如果对 name 操作会报错，因为 name 是 string 类型不能这么操作；改成 hobbies 就成功了。添加一个 golf。运行 ts-node index.ts，再查数据，hobbies 多出一项 golf，插在最下方。注意 $push 每次只能向数组尾部插入一个元素，要一次添加多个，就搭配刚才说的 modifier $each：不直接写 golf，用 object 包裹，$push 里用 $each 加数组结构，再加 golf 和 reading。运行后，尾部添加了 golf 和 reading 两项。

$push 只能把元素插到尾部，想插到指定位置就搭配另一个 modifier $position。$position 必须和 $each 搭配使用，数组下标从零开始。想向第一项插入一个新值 first：$each 里放 first，$position 设为 0。运行后它插到了第一项，position 生效。

说完新增说删除，道理一样，借助特定操作符。最简单的叫 $pop，和 JavaScript 的 pop 一个意思。把数组看成一个队列：下标 0 是队列头部（数组的第一个元素），下标最大的是数组最后一个元素。$pop 删除元素时指定 1 或 -1：1 表示删除数组最后一个元素，-1 表示删除第一个元素。写 {hobbies: 1}，当前最后一个是 reading，运行后查看数据，reading 被删除了。-1 大家可以自己试，一个意思。$pop 只能在头和尾修改，另一个 $pull 和 push 很对应，可以删除特定的元素：它接受一个值，删哪个元素就把它的值写进去。我们删除高尔夫，数据库里高尔夫本来有两项，刷新后都删掉了，没问题。

增删都有了，怎么更新呢？最常用的做法是根据下标更新。比如更新第一项，把 first 更新掉，这里用 dot notation，在数组特定位置更新，很好理解。更新一项用的还是 $set，但 key 要用引号括起来再加点：'hobbies.0'，点后面写任何下标。当前第一项是 first，把它改成高尔夫。保存运行后刷新界面，第一项从 first 改成了高尔夫，更新成功。

还有一种常用情况：不知道要更新的数组元素的下标，只知道值是多少，怎么办？这就涉及更高级的内容，查找数组中的内容。这节课先到这里，下节课深入数组，了解怎样在数组元素中进行查找并更新。
