# 14-14-docker images 镜像操作

大家都知道，使用虚拟机软件安装操作系统时，需要下载对应的镜像并进行安装。比如要在 VirtualBox 中安装 Fedora 这个 Linux 发行版，我们会到官网下载一个对应的文件，可以看到这些镜像文件都是以 .iso 结尾的。在 Docker 当中，任何容器（Container）也是从镜像开始的。

镜像也称之为 image。Docker 为我们提供了各种官方的或者第三方的镜像，可以来到 hub.docker.com 进行浏览和下载。这里有各种各样已经封装了各种工具的镜像，有的下载量非常大，比如有一个有一亿（one billion 以上）的下载量，还有我们熟悉的 Ubuntu、Python 等等。

现在学习镜像的下载。我们要下载的是非常熟悉的 node，可以来这里搜索。点击回车以后会发现这里有一系列的镜像，我们需要这个：大家可以看到有一个绿色的标签，叫 Official Image，说明它是官方的镜像，下载量也非常大。下载镜像需要在命令行中输入对应的命令。

我已经做了一个总结，命令是 `docker pull 镜像名:tag`。首先确保 Docker Engine 已经开始运行了（就是上节课下载的软件）。我们输入 `docker --version`，发现命令行工具起作用了，它的版本号正常显示。

现在使用 docker pull 下载对应的镜像。冒号前面是 image name，这里下载的是 node；后面是版本号（tag），假如不加任何版本，它会下载最新的。版本号在哪里呢？可以看到有非常多的 tags。我们这里直接下载 16：`docker pull node:16`。点击回车，它就会下载对应的镜像。

如果直接使用 Docker 官方的源，你会发现速度比较慢。这里和 npm 下载是一个原理，可以选择镜像代理，国内有很多 Docker 的代理源可以加速。我们来设置一下，先把下载关掉。设置的位置：点开 Dock 栏对应的图标，Mac 和 Windows 在这里完全一样。点开以后找到第三个 Preference（设置），点开会弹出一个界面，里面有一个 Docker Engine 选项。点进来以后发现它有一系列 JSON 设置，这些 JSON 是配置 Docker 引擎的。我们把对应的配置拷贝过来，也是一个 JSON 选项：registry-mirrors。这里面我们选择中科大以及七牛的镜像源，这里可以添加多个，我们添加两个就好。复制上去，没有弹出任何 JSON 错误，说明设置没问题。点击 Apply & Restart，它会重启整个 Docker 软件，稍微等待一下，重启就完毕了。

回到命令行，先看一下镜像的设置是否成功：输入 `docker info`，它会弹出一系列信息，最下面有对应的字符，说明设置成功了。

现在再来一次 docker pull，看 node:16 是不是会快很多。可以看到很快就弹出了下载界面，它会分成多个文件下载。刚才是一点一点，现在速度就快很多。等待下载完毕，一会儿以后发现下载完了，下载的过程都显示 pull complete。

可以使用一个命令查看本机下载了哪些 image：`docker images`。点击回车会弹出列表。这些是我之前下载的，而新下载的 node，可以看到 tag 是 16，它有 905MB，还是稍微有些大的，所以下载需要一段时间。这里有一个 image ID，这个 ID 是独一无二的标识符，说明本机下载了这些 images。

当然还要学习 image 的删除，使用另外一个命令：`docker rmi`。注意要输入的是 image ID，而不是 repository 的名称。把 ID 输进去，点击回车，它会弹出一系列信息。最后用 docker images 确认一下，原来是四个，现在只有三个了，说明删除成功。

最后一个命令我这里就不演示了，也就是上传：可以把我们自己生成的镜像上传到刚才看的 hub 中去，使用 `docker push`。执行这个命令之前，需要在 Docker Hub 进行注册（Sign up），然后再进行操作。

这就是关于 Docker images 的基础知识。有了对应的镜像之后，我们就可以启动对应的容器让它进行工作了。下节课看容器怎样进行启动和管理。
