# 8-15-Vue3 中组件通信的四种方法

上节课讲了 Vue3 中的三种实例，这节课讲组件之间的实例怎样互相获取，以及数据传递的几种方法。应用是由组件树组成的，父子之间相互获取数据是非常常见的需求。注意，这里说的实例都是上节课讲的组件实例（component instance）。

## 场景一：父组件访问子组件

第一个场景是父组件访问子组件的实例，大家都已经很熟悉了。Vue2 时代经常使用 this.$refs 来获取，Composition API 中的做法是：创建一个 ref，称之为 uploader，将它 return；并在子组件标签上添加 ref 属性，名称和返回的名称完全一样，就可以获取到子组件实例，然后调用它上面的一系列属性和方法。我们的代码中就是这么做的，App.vue 想获得 uploader 的实例，在上面调用 uploadFiles 手动完成一个上传。

## 场景二：子组件访问父组件

第二个场景反过来，子组件访问父组件的实例。组件实例上有一个特殊的属性 $parent（$ 开头表示内置或全局的），可以拿到父组件的实例。

来看例子。在 uploader 组件中，首先获取自身的实例，需要上节课讲的 getCurrentInstance。注意要在 onUnmounted（unmounted）中添加，因为在 setup 中它是不存在的。拿到 instance 后：`instance.proxy`（internal component instance 要通过 proxy 拿到组件实例本身），再点 $parent。打印出来，点开 proxy，可以看到 callUpload、handleFileChange、test 等正是 App.vue 上 setup 返回的一系列属性和方法，父组件实例就拿到了。

特别注意：直接调用父组件上面的方法和属性是一种很不好的做法，我们应该保持单向数据流，子组件发送特定的事件去触发父组件的改变。

还有一点注意事项：$parent 可以继续往上嵌套调用，比如 $parent.$parent，一直可以到 root component。实际上我们已经到根组件了，再往上调用它是 null，说明已经到了最高点。从图上看：child 可以通过 $parent 拿到父组件实例，grandchild 也可以先访问第一级再向上拿到最上面的 parent。

## 场景三：provide / inject

第三个场景很常见：某个父组件的数据想被它所有的子组件访问，不仅是第一级的儿子，还包括孙子、重孙子等等。如果用 props 一级一级传递，或者用 $parent 反向访问，都可能跨越好多级，非常繁琐。这时可以使用 dependency injection 特性，也叫 provide / inject。看到这个特性会想到 Vuex，没错，Vuex 的钩子也是采用这个特性完成的。

用一个简单的例子演示，采用 Vue3 Composition API 的写法。在 App.vue 中使用 provide 导入并调用：第一个参数是要提供的变量名称，这里叫 testKey；第二个参数是内容 hello from app。在 uploader 中使用 inject（同样从 vue 导入），在 setup 中调用：`const parentMessage = inject('testKey')`，注意名称要一样。打印 parentMessage，输出 hello from app，流程成功。

特别注意，不仅仅是普通 JS 类型（string），响应式对象也可以被 provide，这样父子双方的数据可以完全同步。

## 场景四：事件监听器

最后一个场景使用事件监听器完成父子组件的通信。有些特殊情况必须用它。举个例子：父组件中有 slot，父组件这么写 `<div><slot></slot></div>`，使用时是 parent-child 关系，但 slot 上没法添加 ref，添加了 ref 也拿不到子组件实例。这时如果还想使用子组件上的属性和方法，就必须使用事件监听器。

Vue2 中大家应该用过 $on、$off 等事件监听器，但 Vue3 中它们已经被废除，需要使用第三方库。官方推荐 mitt，现在有 5000 多个 star，最大的特点是小，gzip 之后只有 200 多个字节。如果大家用过 Node.js 的简单 EventEmitter 就知道了，它的 API 和那个完全一样，只有几个方法：on（listen to an event）、emit（fire an event）、off，还有 all（clear，清除所有 event），就这么简单。其实用什么事件监听器都可以，甚至自己实现一个也完全没有问题。

演示一下。安装后在某个文件（和 main 同级）中导入 mitt，创建实例并导出：`export const emitter = mitt()`。

首先在父组件 App.vue 上进行监听：导入 emitter，在 setup 中 `emitter.on('message', handler)`，第一个参数是事件名称 message，第二个是回调，即拿到消息后做什么。注意第一个参数是可选的，我们需要传。回调里简单把信息打印出来。

然后在子组件上发射，也就是 uploader.vue 中：同样导入 emitter（名称还是 emitter），在 setup 中直接发射：`emitter.emit('message', 'hello from uploader')`。运行后 hello from uploader 被打印出来，说明事件成功从 uploader 发送到了 App 组件。

从图上看流程：parent 导入 emitter 并创建 on 事件监听，任何想发送事件的地方调用 emitter.emit，事件名相同，第二个参数是要发送的内容。这个内容发送给 parent，parent 就可以获得，可以是属性也可以是方法，子组件的任何内容都可以。

## 小结

这节课总结了组件之间相互访问的几种方式。前两种（template refs 和 $parent）比较常见、好理解，但 $parent 最好少用。第四种比较灵活，可以将特定的属性或方法跨级传递。第一、第二种访问的是整个实例，第三、第四种传递的不是实例，而是实例上特定的属性和方法。大家可以回顾图示把这几种方法再过一遍。这节课就到这里，谢谢大家。
