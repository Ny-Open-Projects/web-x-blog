# 21-16-简介和安装 NuxtUI

上一章完成了用户登录和状态持久化，这一章继续开发功能。管理系统里最常见的操作是通过表格管理数据，我们选用用户列表这个典型场景来完成对应功能，因此要开始选择组件库了。

整个项目的开发采用完全循序渐进的方式：先了解足够的底层知识，再往上拔高获取更多知识。这里选的组件库和之前的 Tailwind 还有千丝万缕的联系，它也可以用 Tailwind 来定制化，它就是 Nuxt 官方的组件库 Nuxt UI，网址是 ui.nuxt.com。

## Nuxt UI 与 Headless UI

它的介绍很有意思，注意这一句：它提供一系列的 Vue 组件以及组合式函数，构建在 Tailwind CSS 和 Headless UI 这两个库的基础上。Tailwind CSS 我们已经非常熟悉了，Headless UI 是何方神圣？

看它的官网描述：unstyled，没有任何样式，只实现一系列功能；fully accessible UI components，完全实现了可访问性功能的组件库。它设计出来就是为了和 Tailwind CSS 组合的，也可以方便地和任何样式库结合，自然是 Tailwind CSS 的绝佳拍档。这种方式也是现在组件库非常流行的解决方案。

看它的源码也能印证：点开任何一个组件，比如 Menu 或 Dropdown，点 Code 可以看到里面只有一系列组件，留了各种各样的 class 供大家高度定制，添加 class 即可，这就是刚才说的宗旨。

## Nuxt UI 的特性

回到 Nuxt UI，简单浏览一下它的组件。components 非常多，主页往下移动就能看到这些由 Nuxt UI 生成的组件，样式很精美，而且特别注意它是高度可自定义的，有一个特别强大的 theme 系统。

简单看一下：它可以通过多个维度修改组件，做成任何想要的样式。最基础的是主题颜色，很简单，和 Tailwind CSS Color 高度结合，可以深度自定义。往下还有更多可自定义性：任何 component 都可以自定义，通过 `ui` 配置定义和组件相关的一系列 class name。比如 container 这样的组件，就是通过一系列类名定义的。

点开 container 看一个类：这里面的 `ui` 就是它的一系列基础配置，正是刚才看到的那些类名。通过这个整体配置文件就可以修改任何组件的样式，所以它是非常强大的可自定义组件库。

## 安装

安装非常简单：`npm install @nuxt/ui`（我这里已装完，大家课下自行安装）。使用时只要把 `@nuxt/ui` 添加到 nuxt.config 的 modules 里就可以了。

特别提醒：安装时它会自动安装 `@nuxtjs/tailwindcss`，而我们之前使用过它，所以这里直接替换，用刚选的 module 即可，安装就完成了。

这里会出一行红线，有一个很长的错误。想解决很简单：把 node_modules 删掉重装一遍。原因是现在里面有两个版本的对应 module：Nuxt UI 会安装 Tailwind CSS，而我们原来就装了，出现两个版本；删除重装后只留一个，问题就解决了。

## 试用

之后就可以非常方便地使用它的全局组件了。拿 button 做例子：复制一个 `UButton` 添加到 login 页面中，保存后到界面看是否生效。可以看到 button 已经出现了，说明 Nuxt UI 安装成功。
