# 3-4-项目难点分析

上节课分析了整个项目的需求，基本了解了项目流程。整个应用分为多个页面，有一定经验的同学一眼就能看出编辑器页面是整个项目的难点。项目就从编辑器起步，而且编辑器相对独立，一定程度上开始开发不需要后端支持。

整个开发流程对标大厂：先是需求分析、编写需求文档，之后一般是编写技术解决方案。很多同学开发时很少写技术方案，看完需求就埋头编码，对简单项目来说没什么问题，但对我们这个项目，技术方案非常重要。对个人，它可以梳理思路，预先解决项目中可能存在的难题；对团队，技术方案写完后要有一轮评审，前端、后端、架构师、产品经理等多个角色一起 review，判断方案设计是否合理，不合理就打回重写，以此尽量减少问题。

技术方案要写什么？其实就是你计划如何完成需求中的功能，写清楚怎么做这件事。它没有固定格式，力求用文档清晰明了地解决需求中的功能，这也是考察工程师能力的重要组成部分。这节课的任务，就是从庞杂的需求中找到项目难点，这些难点就是完成技术方案的整个脉络。

架构师只是个头衔，任何程序员对一个系统或应用进行设计开发时，就在扮演架构师的职责，只不过项目有难易之分。下面我们就来分析编辑器页面里可能存在的一系列难点，这也是技术方案要解答的问题。

## 抓住本质：一系列元素

抓住事物的本质，发现核心问题。这个项目最重要的就是产出和展示海报，这两个功能分别来自两个项目：产出海报来自编辑器，可以在上面针对海报元素进行一系列交互和修改；展示海报来自 H5 端，点击预览设置就能看到。这两个项目形成一个小闭环。

它们要展示的内容非常相似。中国有句古话，大道至简。编辑器和 H5 页面本质上就是一系列元素构成，上面有文本、图片、形状等，唯一的区别是编辑器里的元素可以交互，而 H5 页面的元素不可以交互。

这些元素自然而然应该根据类型抽象出组件：文字可以定义为 OpsFlow text 组件，传入一系列属性后渲染生成不同的文本；还有 OpsFlow image，传入属性后渲染生成图片，等等。业务组件需求文档里定义了它们应有的所有属性：既有一组所有基本组件都有的通用属性，也有每个组件特有的属性。这些属性和组件本身是一一对应的关系，有的和样式（CSS）高度相似，有的又像是行为，比如事件、点击等。

## 五个核心问题

**问题一：怎样实现组件？** 也就是如何让这些组件渲染出对应的元素。

**问题二：跨项目使用。** 这些组件要在两个项目中使用，不仅编辑器要用，H5 页面也要用，怎样在不同项目中做到统一使用这一系列组件？

**问题三：组件的可扩展性。** 现在虽然只有三种组件，但最初的设计就要考虑良好的扩展性。项目里预留了一个尚未实现的高级组件，可作为扩展需求，到时候大家一起完成。

**问题四：编辑器的整体状态。** 说完组件个体的问题，把它融合到编辑器中讨论。编辑器做的功能就是对组件进行三种操作：增加（点击添加一个）、删除、属性修改，也就是增删改。我们是 SPA 应用，怎样设计编辑器的整体状态，是下一个难题。

**问题五：元素属性的修改。** 这是整个编辑器的核心问题。点击某个元素会弹出一系列表单组件，这里又分两步。

第一步，怎样把这些属性渲染成不同的表单？以 OpsFlow text 为例，它有 text 属性（显示什么文字）、font size（字号大小）、font family（字体）。text 需要一个 text input，font size 希望有一个可拖动的 slider，font family 希望有一个 drop down 下拉菜单供选择字体。属性可能非常多，也不仅仅是表单元素，比如设置图片就需要上传组件。

第二步，实时反馈。在表单里输入文字、拖动大小或改变下拉选项时，这些修改要实时反射到组件中去：修改文字，画布上立刻变化。这是另外一个难点。

到这里，编辑器的核心功能其实已经完成了，剩下的都是对属性的补充，比如编辑器的增强交互，可能有拖动、快捷键、右键菜单等。这些功能都在核心问题之外，那么很自然的问题是：能否将这些功能解耦，不和编辑器混为一谈，而是像独立的插件一样运作？

## 小结

通过难点分析得出了这一系列问题，它们就是技术文档的脉络。回答了这些问题，整个编辑器的大体流程就跑通了。总览型的技术设计文档站在一定高度指引项目的大体流程；至于非常具体的解决方案，比如改变大小要怎样实现，可以到时候针对对应功能再写一个具体的设计文档来分析，不影响整体流程的进行。

对这种复杂项目，不能一开始就埋头苦干，项目前期必须经过这样的思考过程，试图寻找问题的答案，争取满足项目的可扩展性，否则就会出现干到一半发现原方案有问题、被迫返工的情况。当然，想一开始就设计出完美运作的系统也是天方夜谭，但我们要尽量做到完美。

强烈建议大家在语雀的技术方案目录下新建一个文档，把这些核心问题总结进去，自己试着寻找解决方案。下节课我会和大家一起分析我的方案，对比看看我们的思路之间有怎样的异同。
