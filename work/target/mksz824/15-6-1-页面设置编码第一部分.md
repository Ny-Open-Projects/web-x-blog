# 15-6-1-页面设置编码第一部分

完成了右侧的两个设置面板之后，现在来到最后一个设置面板：页面设置。

## 需求分析

点击页面设置时会弹出一系列属性：背景颜色、背景图片、背景重复、背景大小、高度等。这些属性都是和页面背景相关的 CSS 属性，所以对它们的处理可以使用现成的 PropsTable 组件，只要将对应的 props 传入就能形成对应的效果。

首先要确定数据从哪里来。我们的数据中枢神经来自 Vuex 的 editor 模块。目前 editor 中没有这些属性的容身之处，现有的是 components（供中间编辑器渲染的数组）和 currentElement（当前编辑的是哪个元素）。当时我特意加过一个注释：保存项目时还可能有一些项目信息没有写出，等做到时再补充。现在就是这个时候了。

和 components 一样，整个页面的样式肯定是需要持久化的：项目完成时，每个保存的项目中必然会有 components 和页面总体的信息，取得这些信息后才能渲染出对应的界面。所以这里应该有一个配置字段，保存与项目总体相关的一系列内容。

## 定义 PageData

建立对应的 interface。已有 ComponentData，这个就叫 PageData：

```ts
export interface PageData {
  props: { [key: string]: any }
  title: string
}
```

第一项是整体页面的样式，用 props 表示。它是一个 key-value 的 object，所以用 indexable type，返回 any。第二项暂时加一个测试的 title（项目名称），让它不那么单调。

有了 interface 之后，把它添加到整个的 editor state 中去，字段名称叫 `page`，类型是 PageData。添加完毕后往里面填数据：把刚才说的那些样式添加一个默认值，和组件默认值的做法类似，变量称为 `pageDefaultProps`。然后添加 page：props 传 `pageDefaultProps`，title 传 `test title`。这样 editor 中就把状态属性添加上去了。

## 展示到编辑器与右侧面板

现在把它展示到页面中。在 EditorView 中取得这个数据：对应 Page 放在 computed 中，返回 `store.state.editor.page`。首先给中间编辑器添加对应的 props，多添加一个节点并把样式加上（已写好）：创建一个 div，class 叫 `body-container`。注意要在预览列表上设置 `overflow-y: auto`，因为里面内容的高度有可能超过容器，这样会出现内部滚动的效果。

页面上已经生效了：初始高度（560px）大于外侧容器的高度，所以出现了滚动条。下一步在右侧显示它：在 EditorView 添加一个新的 tab，已有图层设置，再加一个页面设置，key 设置成 `page`。内部自然使用 PropsTable，把 `page.props` 传给它：PropsTable 接受一个 props 属性，把 page 的 props 传过去即可。

保存后看右侧面板：点击页面设置，内容出现了。当然并没有显示完全，我们设置了五个默认数据，这里只显示了两种。原因大家都知道：没有添加属性和表单的对应关系。

其中有一个很有意思的属性，叫 background-image。设置图片属性时感觉之前接触过类似的属性，但它和 src 有一定的区别：这个属性一开始可能是空的，上传完毕后可能需要重新上传，并且要截图。
