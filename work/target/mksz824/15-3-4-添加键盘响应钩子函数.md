# 15-3-4-添加键盘响应钩子函数

上节课完成了 InlineEdit 测试用例的开发，学会了怎样用程序触发特定的事件。这节课来完成 Enter 和 Esc 的编码。

这里我把测试用例稍微修改了一下：因为想支持自定义模板的情形，我在 InlineEdit 中添加了具名 slot，所以测试里没有用默认模板，而是用了自定义的 h2 标签。对应的修改其实就是把测试里的 span 全部改成 h2，就这么简单。

## 抽象 useKeyPress

现在面对的问题是：怎样监听特定的按键，然后根据不同的按键做对应的处理。自然要创建一个通用的按键处理，抽象一个 hooks 函数来完成，命名为 `useKeyPress`。

它的签名是 `const useKeyPress = (key: string, cb: Function) => ...`：第一个参数是要绑定的 key，string 类型；第二个是当这个 key 被触发时调用的回调 cb，是函数类型，这里直接返回值类型给 any 就可以了。

逻辑上要添加 keypress 监听，就要在 document 上添加事件。把两个生命周期钩子函数从 vue 中导入：在 `onMounted` 里绑定事件，绑定之后肯定要清除，所以在 `onUnmounted` 里把它移除。

事件处理函数命名为 `trigger`，定义为一个 function，它会拿到事件对象，类型是 `KeyboardEvent`，上节课说过这个对象，甚至用它的构造函数创建过一个实例。

内部逻辑很简单：判断什么时候调用 cb，传入的 key 和当前按下的 key（即 `event.key` 上的值）相同时就调用：

```ts
const trigger = (e: KeyboardEvent) => {
  if (e.key === key) cb()
}
```

然后在 `onMounted` 里执行 `document.addEventListener('keydown', trigger)`，事件用 keydown 或 keypress 都可以，看个人爱好；`onUnmounted` 里对应地 `document.removeEventListener('keydown', trigger)` 清除。最后 `export default useKeyPress`。

## 在 InlineEdit 中使用

把它导入到 InlineEdit 中，然后在 setup 里使用。先处理 Enter 键：

```ts
useKeyPress('Enter', () => {
  if (isEditing.value) {
    isEditing.value = false
    context.emit('change', innerValue.value)
  }
})
```

注意 Enter 的写法是首字母大写。回调里先判断 `isEditing.value` 为 true 才做进一步处理：按了 Enter 且正在编辑中，首先把 `isEditing.value` 置为 false，然后通过 `context.emit('change', innerValue.value)` 把 v-model 绑定的值发送出去。

这样 Enter 的处理就完成了。运行测试，"press enter should render to default layout with new value" 已经通过，功能没问题。

## Esc 的处理与一个 bug

接下来照猫画虎写 Esc，调用 `useKeyPress('escape', ...)`，注意键值是 `escape`，不要写成 ESC。回调同样先判断在编辑状态，然后恢复原始值：把 `innerValue.value` 改回 `props.value`。

运行测试却出现了错误：45 行 expected 是 `test new`，received 却是 `test`。前面都能通过，只有最后一个断言失败。原因是：最初在编辑之前值已经是 `test new`（我们把内部值改成了 test new），然后设置成 `test 123`，点击 Esc 时它应该恢复到 `test new`，但实际恢复到了最初的 props value，也就是第一次传入的 `test`。

我们希望每次恢复到**开始编辑时**的数据，而不是最初的状态。解决方法：在切换进入编辑状态时，保存一个开始编辑时候的值，留给后面恢复用。添加一个 let 变量 `cachedOldValue`，初始为空字符串；然后添加一个 watch 监听 `isEditing` 的切换，拿到新值后判断：如果正在编辑，就执行 `cachedOldValue = innerValue.value`，把开始编辑那一刻的值缓存下来。之后按 Esc 时恢复到这个缓存值即可：

```ts
useKeyPress('escape', () => {
  if (isEditing.value) {
    isEditing.value = false
    innerValue.value = cachedOldValue
  }
})
```

再次运行测试，用例完美通过，键盘响应功能完成。

## 小结

这也是一般键盘响应功能的常规做法，本质就是往 `document.addEventListener` 上添加一系列回调。项目后期我们还会遇到更复杂的键盘响应，比如组合键（Ctrl+C、Ctrl+V）、多作用域（不同作用域有不同组合键）等，那时候可能会进化到使用第三方库。我的习惯是先用实际代码演示一个自己写的简单版本，再引入第三方解决方案，这样能让大家了解这些库的基本原理，它们的核心就是这里的按键响应机制。
