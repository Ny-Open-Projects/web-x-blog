# 15-6-3-使用正则获取文件名称

这节课需要在字符串上做一些处理：从一个 `url("xxx.png")` 这样的字符串中取出图片地址。这时候要使用正则。正则这个东西大家感同身受，难以记忆和理解，每次用可能都会忘记，需要再查用法。我也是这样。这里教给大家一个使用正则的简单方法。

## 用 RegExr 可视化分析

首先需要一个好用的工具，我一般使用 RegExr 在线工具，强烈推荐。它的可视化非常强大。它分为几个部分，中间是要匹配的字符串，我已经把目标字符串放进去了。我们希望最后获得的字符串是 `123.png`，它有什么规律呢？

它应该是圆括号和引号中间的那一系列字符串，这就是它的特征。按照这个特征来写正则：

- 先匹配左边的圆括号。直接写 `(` 会报错，因为圆括号在正则中是保留符号（等会儿我们会用到这个特性），需要转义，加一个斜杠：`\(`。匹配到第一个括号，下方有解释：matches `(` character，是一个 escaped character（已被转义的字符）。
- 接下来是一个引号，引号不是保留字符，可以直接写。但有一个特殊情况：单引号也是合理的 URL 包裹值，所以要表达"单引号或者双引号"，使用方括号表示"或"的关系：`['"]`，这样两种引号都能匹配到。

到这里已经拿到了左括号和一个引号，接下来匹配文件名称，没有特殊要求，直接匹配字符串：添加一个点 `.`，它的含义是除 line breaks（换行）以外的任何字符；要匹配多个，添加加号 `+`，代表匹配一个或多个对应字符。

此时发现它直接匹配到了最后面，因为引号、括号以及空格都属于点的范畴，所以要把后面的引号和括号也添加上：先添加引号，再匹配右边的括号（括号要先转义），再进行匹配。现在就没问题了，已经可以匹配到全部想要的字符串。

## capture groups：分组取值

现在匹配到的是整个字符串，但我们要拿到里面的具体值。可以使用正则的一个特性，叫 capture groups（分组）：它允许你在当前的匹配中获取部分结果，作为返回数组中的新的一项。这个特性就是用括号完成的。

我们希望引号中的那部分作为一个新的一项，就用括号把它包裹起来。RegExr 会提示你正在创建一个 capture group 作为单独的一项。点击 details 验证：match 到了两项，第一项是整个匹配的字符串（括号加引号加 `123.png`），第二项就是分组拿到的东西，`123.png`，我们最终想要的值。

每一个括号都可以生成数组中的新值。比如想要匹配"123"、"点"、"png"三项，就创建三个括号：第一项 `([1-9]+)`，第二项 `(\\.)`，第三项把 `png` 写死。现在可以看到它根据这三个括号创建了三项。这就是分组的意思，很好用的功能。

## 应用到项目中

成功拿到想要的字符串，任务的核心就完成了，现在把正则用到项目中。先还原回一个分组的正则。来到 propsMap，创建一个 `initialTransform`，原始值是一个 string。首先判断这个 string 存在且不为空，如果为空或者不是 string，直接返回空的 string。

在外面创建正则表达式变量 `reg`，把工具里写好的表达式复制过来。然后用 `reg.exec` 方法运行，要处理的字符串就是 `v`：

```ts
const matches = reg.exec(v)
```

处理完成后，matches 是一个类数组或者 null，所以要先判断：matches 存在，并且我们希望它不止一项，因为有分组匹配，必须满足这个条件才能拿到正确的值，即 `matches.length > 1`。满足条件时直接返回数组的第一项（就是我们想要的图片地址）；其他情况返回空字符串。

看界面上的效果：能打印出这个数组，第一项是整个匹配的范围，第二项就是最终要拿到的图片地址。组件中也能完全显示出图片了，说明传入没问题。

这样我们就完成了正则的任务，学习了一个正则的分析过程。同时推荐了一款很好用的工具，希望大家把它保存在收藏夹里，下次遇到正则操作时想起用它，它的提示非常全面，交互也做得很好。
