# 20-28-总结

按照常规来到本章知识的总结。这一章我们接触到了使用 Nuxt 3 写后端的方式，也就是 Nitro 框架的用法。和 Nest.js 相比，我感受到了它简洁好用的一面。项目中用哪个可以按个人爱好选择，希望大家能感受到两者在设计思想上的异同。

首先了解 Nuxt 3 后端的架构。这张经典的三层结构图中，越往下越底层：最上面是 Nuxt，然后是 Nitro，Nitro 下面用了 H3。所有和服务器端相关的代码都存放在 server 文件夹中。和前端类似，后端也是基于文件系统的路由：server 下有个 api 文件夹，hello.ts 就会生成 /api/hello 这样的路由。同时，不同的 HTTP verb（method）也用文件定义，可以使用 .post、.patch、.delete 这样的后缀生成对应的 method。

接着学习了 H3 一些和请求参数相关的全局帮助函数：defineEventHandler 定义一个路由，getRouterParam 获取参数，getQuery 取得 query，readBody 获得 body 发送过来的数据等等。它们很好掌握，写一个例子就能理解各自的用法。

然后是后端的 middleware。要知道它和前端中间件的区别：它只在 server 端路由中运行。Nitro 的中间件设计非常简单，只有一条规则：middleware 文件夹中的内容都会自动执行。它的设计思想很灵活，没有强约定，middleware 也有一系列平替方案：可以用一个单独的函数，也可以利用 utils 可以自动导入的特性创建一个高阶函数，比如我们做的 defineAuthResponseHandler 假权限验证，就可以在不同的文件中使用。

了解完 middleware，讲了 Nitro 提供的一个很特殊的内容：Server Storage。它内置了一套完全可扩展的存储层，可以实现一套简易的 Key Value 存储系统，默认使用内存储存数据，还可以扩展使用各种熟悉的数据库或文件系统。它基于 Unstorage（UnJS 系列高质量模块之一），写法非常值得参考，大家可以看它的源代码学习模块的写法。基本用法是 useStorage 后调用 setItem、getItem；默认使用内存。它还可以接入其他工具，比如配置 Redis 支持：在 nuxt.config.ts 中添加配置后，useStorage('redis') 就代表使用了这种 storage，可以进行持久化存储了。

讲完 Server Storage，又了解了配置文件。在 nuxt.config.ts 中可以创建 runtimeConfig，代码中用 useRuntimeConfig 取值。这里的配置可以和环境变量配合使用，隐藏私密的值。比如 apiKey，可以在 .env 中按命名规则覆盖它，使用环境变量文件中创建的私密信息。命名规则再说一遍：以 NUXT 开头加下划线，多单词时以大写字母分割、转换成下划线相连。

同样还有 app.config.ts 文件，在文件中定义，代码中用 useAppConfig 取值。两者的简单区别：runtimeConfig 支持环境变量，appConfig 不支持。顾名思义，runtimeConfig 更适合运行时才能提供的敏感、私密数据；appConfig 更适合应用的整体配置，比如主题颜色、语言等不敏感的数据。

之后讲了 plugins。plugins 中的文件会自动注册，并在 Nitro 启动初始化时运行。插件中可以拿到整个应用的一系列生命周期，在里面做各种操作。示例代码使用 defineNitroPlugin 注册，唯一参数是 nitroApp，即后端运行后的实例；通过 hooks 的 hook 方法可以拿到一系列事件，做对应的处理。

从后端的 plugins 引申到 Nuxt 3 前端的 plugin 概念（上一章没讲，放到这里和后端放在一起更好理解）。它的作用：可以获取整个 lifecycle hooks 并处理；可以获取 vueApp 实例做处理（这是最常使用的，可以往上面放插件、全局组件、指令等）；还可以扩展 nuxtApp 本身，提供全局可用的属性和实例方法，比如通过 provide 放入一个对象，在别处就能全局使用。

最后讲 modules。它是让 Nuxt 3 变强大的利器：允许开发者使用预制的独立模块来扩展和定制 Nuxt 应用，也是将功能组织和封装的一种方式，让开发更模块化、更可维护。modules 不是 server 端的概念，而是整个 Nuxt 应用的概念，可以扩展到方方面面。之后我们安装使用了 nuxt-mongoose 来连接 MongoDB 数据库并做了一系列操作。modules 我们没有自己写，想写的话可以参考官方文档。

这就是本章的所有内容。希望大家课下随着总结再回顾一遍 Nuxt 3 的基础知识，到这里就告一段落了。下节课我们进入项目的正式开发。
