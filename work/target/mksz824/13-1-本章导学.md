# 13-1-本章导学

欢迎来到第十六周的学习，这是项目开发的第二周。上一周我们已经对实体的增删改查非常熟悉，这些内容没必要再大费笔墨，大家触类旁通即可。这一周要学习一些和实体操作无关的内容，它们可以极大丰富应用的功能，也是一个典型后端项目常用的能力，对应三个标题：文件上传与处理、SSR 实现 H5 端展示、角色的权限控制。

课程仍然坚持两个宗旨。第一是由浅入深：从基本做法一直讲到源码解读，让大家真正理解这些内容在底层如何运作。第二是全面：比如文件上传，一般课程讲完一个普通的 file 类型上传就草草收尾，而我们从单文件模式到 stream 模式，再到 stream 底层的 busboy，再到多文件上传，把这块知识一网打尽。

本周的主要内容按顺序展开。一开始讲文件上传。app 提供了两种上传模式，第一种是最简单、最好理解的 file 模式，先用它完成上传，同时因为上传到本地需要展示，要学习用 static 完成静态文件展示。之后是本地图片处理这个常见需求，比如缩放、旋转、裁剪，会介绍一个好用的库 Sharp，它可以方便地完成图片的各种操作。

接下来学 Stream。为什么学？因为之后要做流式上传，Stream 是重要的前置知识，也是 Node.js 的基本功。我们会对比 file 和 stream 两种模式的优缺点，讲 stream 的基本概念和编码，然后用 Stream 完成上传，再讲一些 stream 的高级知识。这两块学会后，就可以使用阿里云 OSS 上传了。相比把文件保存到本地，云服务大有裨益，所以会讲 OSS 的优势。为了完成多文件上传，还会深入 stream 底层的 busboy 库，讲它的用法和实现。

文件上传讲完后是新内容：SSR，即服务器端页面渲染。会讲它的概念和特点，以及 egg view 实现 SSR 的基本做法，然后使用前后端共用的业务组件库渲染对应的 H5 页面，并做一些处理让页面更好看。最后还需要用 Webpack 处理静态文件、模板等一系列功能。

最后是本课程的一个亮点：基于 RBAC 的权限管理（RBAC 四个字母的缩写后面会解释）。这里会用到 Casl 这个库，一个很流行的 Node.js 角色管理库。我们会讲它的概念、Node.js 各个角色管理库的对比、它的基本用法，然后使用 Casl 结合之前用过的 Decorator 装饰器完成项目中的角色权限管理。这块内容是可以放进面试里大书特书的亮点。

总结一下本周内容的特点：由浅入深、覆盖面广、实用性强，学完可以直接用到工作中。同时会继续通过分析源码来彻底弄懂知识，这次分析的是 egg 的一个插件 egg-multipart，这种源码分析会让你更清楚底层的运作方式。

导学就到这里。这一周是三大块的内容，闲话少说，开始吧。
