# 16-5-6-进阶：撤销重做支持一次处理多个数据

上节课通过测试引出了几个要修复的问题，这节课来实现第一个：拖动改变位置、改变大小这类操作只保存一次历史记录。

## 追根溯源

这些操作都发生在 `updatePosition` 里：它用 `forEach` 循环一个 key-value 对象，循环里多次调用 `updateComponent`，每次调用都写一条记录，问题就出在这里。

思路是：改为只调用一次 `updateComponent`，传入的 key 和 value 不再是单个字符串，而是复杂的数据结构，多次赋值在 `updateComponent` 内部完成。这样历史记录里保存的就是一个复杂结构，回滚时也能一次完成。

## 改造数据结构

现在传入的数据是 `key: 'top', value: '50px'` 和 `key: 'left', value: '30px'` 这样的形式，改成：

- `keys`：`['top', 'left']`
- `values`：`['50px', '30px']`

两个数组按 index 一一对应，`id` 不变。

editor.vue 里 `updateData` 经过 `pickBy` 把 id 去掉后已经能拿到这个对象，接下来提取两个数组：

```ts
const keysArray = Object.keys(updatedData)
const valuesArray = Object.values(updatedData).map(v => v + 'px')
```

原来在单独位置做的 `px` 转换，挪到 values 的 `map` 里直接完成。然后删掉 `forEach`，只调用一次 `updateComponent`，key 传 `keysArray`，value 传 `valuesArray`。

## 给 updateComponent 补类型

`updateComponent` 的参数一直没有具体类型，默认推断全是 `any`，内部写了大量类型断言，这不好。现在逻辑复杂了，更丰富的类型也能保证代码质量，所以给它定义参数类型。类型写在 `HistoryProps` 附近，创建 `UpdateComponentData`：

```ts
export interface UpdateComponentData {
  key: keyof AllComponentProps | (keyof AllComponentProps)[]
  value: string | string[]
  id: string
  isRoot?: boolean
}
```

`key` 是联合类型：可能是单个 key，也可能是数组；`value` 同理是 string 或 string 数组；`id` 是 string；`isRoot` 是可选的布尔值。类型文件是跟逻辑写在一起还是单独成文件，两种都可以，没有硬性规定，我个人偏好类型和实现写在一起。

## 方法体两种分支

方法体加上类型后按两种情况处理。第一种用 `Array.isArray` 判断：

```ts
if (Array.isArray(key) && Array.isArray(value)) {
  key.forEach((keyName, index) => {
    updatedComponent.props[keyName] = value[index]
  })
}
```

注意要同时判断 key 和 value 都是数组，循环赋值才不会出错。由于都是联合类型，`Array.isArray` 充当了 type guard，能精确收窄类型，forEach 里 `keyName` 和按 index 取的 `value[index]` 都能正确体现类型。

第二种情况不能简单写 `else`，同样要用 type guard 精确控制类型，这个分支成立的条件是 key 和 value 都是 string：

```ts
else if (typeof key === 'string' && typeof value === 'string') {
  updatedComponent.props[key] = value
}
```

其他类型组合（一个数组一个 string）不处理，报错就报错。写完后没有类型错误了，这正是 type guard 发挥实力的地方。

## 历史记录的配套修改

还有两处要改。第一处是 `isRoot` 分支下的赋值：isRoot 修改的根属性不可能是数组，所以把这里的 key 断言成 string 处理类型错误。第二处是 `oldValue` 的获取：key 是数组时要拿到一组旧值：

```ts
const oldValue = Array.isArray(key)
  ? key.map(k => updatedComponent.props[k])
  : updatedComponent.props[key as keyof AllComponentProps]
```

是数组就用 map 取每个 key 的旧值，不是数组直接取当前值。

最后把 `pushHistory` 挪到修改值之前：值已经改掉了再去取，拿到的会是新值。

## 验证

到界面上测试：拖动元素，只出现一条 `modify: left, top`；修改大小，一条 `modify: width, height`（含 top、left 时也在同一条里）。多维数据保存成功。
