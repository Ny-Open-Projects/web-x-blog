# 8-1-本章导学

上一周我们系统学习了测试的知识，但处理的都是一些简单组件，还处于"英雄无用武之地"的阶段。从另一个方面说，编辑器目前还缺失一块很重要的功能：文件上传。虽然 Ant Design Vue 已经提供了现成的上传组件，但学习用 Vue3 和 React 这类框架开发复杂组件，我认为是非常重要的能力，这一点必须掌握。这一周就让两者双剑合璧：用一个真实场景模拟真实的开发流程，看看测试和开发是怎样配合的。我们会使用前面学过的 TDD 方式，一步步开发一个通用上传组件，从中感受 TDD 是怎样帮助我们重构代码的。

第二点是开发完毕以后，我们会分析 Element Plus 的 uploader 源代码，看看作为一个很成熟的框架，它有怎样的代码结构，有哪些值得我们学习的地方。同时我也要提醒大家不要教条主义：不要因为它是有名的框架，就认为它的实现一定是最好的。项目中最重要的，是选择适合自己需求的实现方式。之后我们还会把写好的上传组件添加到编辑器中，看看怎样用它创建图片类型的组件。

除了这些主要内容，这一章还会刻意培养大家对知识点发散和总结的能力。我在开发过程中遇到不太了解的知识点时，经常会像意识流写作一样，思绪跟着知识点进行一系列衍生和发散，我认为这是一种非常好的思维模型。这一章会由此带出一大堆发散出来的知识和实用方法，比如：Vue3 中实例的类型有几种？Vue3 中组件通信的方法有哪些？本地图片预览的方式有哪些？上一周我们遇到过 HTMLInputElement 类型，这里则会学习 HTMLElement 家族的一系列关系。最后我们还会学习 Jest 怎样借助 jsdom 模拟浏览器环境，把测试跑起来。

有了主要内容，关键词就很容易得到：TDD 开发方式、上传组件的完整开发流程，以及代码重构，我们会特意讲 TDD 怎样推动重构，有了它的保障，重构会更安全、更方便。接下来是 Element Plus Uploader 的源码分析，最后是通过发散和总结推动出来的系列知识点。

学习方法上有两点。第一是真实场景：这一周我会作为和大家一样的程序员，写一系列计划，拆分成不同的任务，然后使用 TDD 的方式感受它的开发节奏。第二就是发散学习：追根溯源的过程其实非常有趣。另外，上传文件最好有一个可以测试的接口，届时可以参阅我们的线上电子书，我会提供可测试的接口给大家使用。

这些就是这一周非常丰富的内容，让我们开始学习吧。
