# 20-1-Nuxt3导学

欢迎来到课程的 2024 年最新更新内容。这一部分带来的是基于 Vue 3 的 Nuxt 3。现在全栈框架越来越火，掌握一个全栈框架成了必备选项：React 生态对应的是 Next.js，而 Vue 生态就是 Nuxt。

Nuxt 3 是 Nuxt 的全新版本，作为 Vue 3 最出名的全栈框架，我使用下来确实非常方便：前后端可以写在一起，还能享受大量内置且优化过的模块；加上 SSR 的加持，让原来 SPA 项目受影响的 SEO 问题得到了根本性解决。所以我把它列为 Vue 技术栈中必须掌握的框架。

再说说我们要做什么项目。这里要完成的是 OpsFlowAdmin 管理系统。我们之前已经分别实现了 OpsFlow 海报编辑器这个前端项目，以及基于 Axios 的 OpsFlow Server 这个后端项目，现在就选择大型项目中必不可少的管理系统作为补全的一环，同时完成整个 Nuxt 的学习流程。当然，Nuxt 可以胜任各种类型的网站应用，选用管理系统只是抛砖引玉，希望大家掌握方法论之后，能把它衍生到自己的各种项目中去。

教学方式会有一些变化。前面前端和后端项目中，我们已经建立了完备的知识体系，所以 Nuxt 3 的学习不会再事无巨细。比如鉴权，之前在后端课程里已经详尽介绍了各种加密方式和不同鉴权方案的实现，最终采用的是 JWT。Nuxt 3 的后端实现中同样要用到 JWT，虽然 API 稍有不同，但原理完全一致，所以只会一笔带过，具体知识点请参阅之前的内容。

功能方面也不会每个都详细讲解。管理系统的重要功能之一是针对表格的操作，我们只学一种数据类型的管理：学完用户管理后，其他数据类型比如海报（poster）就让大家自行实现，因为它们和用户管理非常类似。重要的是掌握整体解决方案，之后在任何管理系统中都能套用。

编码风格同样会体现这一点：重复度极高的代码不会一行行手打，那是浪费我们共同的时间。学到这里，相信你已经能理解这种授人以渔的风格：一开始事无巨细，越往后越发散大家的想象力，我只讲重点、抛砖引玉。

这就是本章的导学内容，接下来让我们进入 Nuxt 3 的世界。
