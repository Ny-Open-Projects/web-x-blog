# 9-9-创建入口文件

现在我们来为组件库创建入口文件。之前的例子描述了整个插件的运行机制，作为业务组件库，当然也要像其他组件库一样做成一个插件。现在组件库有两种需求。

第一种是可以将所有组件一次性全部导入，并且作为插件使用。示例代码是这样：先 import 我们的组件库，然后 `app.use()` 整个组件库，之后应用下面的所有组件中就可以使用全局组件了。要完成这个任务，首先需要建立一个入口文件，可以称之为 index.ts，然后把需要放到全局的所有组件导入，做成一个数组。接着创建一个 install 函数，在函数中循环这个数组，调用 `app.component()` 方法一个一个把它们注册上去。最后把这个 install 函数进行默认导出，因为插件有两种形式：一个 object 带 install 属性，或者直接是一个 function，我们用的是第二种方式。

另一个重要特性是将组件单独导入使用，因为有些情形不需要全局使用所有组件，只需要一个或者几个组件。比如代码中直接从组件库导出 LText，然后 `app.use(LText)` 这样使用，或者 `app.component(LText.name, LText)`，这两种写法都可以。

要完成这个任务怎么办？为了不影响之前组件的实现，也就是 LText.vue 里面的内容，我们新建一个文件夹，把 LText.vue 放进去，再创建一个单独的 index.ts。Vue 组件其实就是一个 object，所以可以导入原来的组件，在这个对象上面添加一个 install 方法，将它插件化，这样就可以支持两种写法。最后因为要从这里导出，所以在全局入口文件也就是刚才创建的 index.ts 中将它导出即可。

有了这个指导思想，现在动手。先完成单个组件的导出。我在这里建了一个 l-text 文件夹，把原来的 LText 移进来，创建 index.ts 作为单个组件的入口文件。首先还是需要类型，也就是 App 这个类型，然后把 LText 导过来，路径是 `./LText`（同级目录）。接着在 LText 上面添加 install 属性，将其插件化，之后就可以被 App 的 use 调用。它本来就是一个 object，在上面添加 install 方法，第一个参数是 app，方法内部调用 `app.component(LText.name, LText)`。这样就完成了单个组件的插件化，最后不要忘记把整个 LText 导出。

然后是全局入口文件。我新建了一个全局的 index.ts，放在 src 根目录下面，代表整个项目的入口。第一步同样把类型导进来，然后将所有组件导入。这里只有 LText 一个组件，课下大家可以把其他组件都补充完。之后把所有组件放到一个数组 components 中。接着创建 install 函数，第一个参数是 app，也就是应用实例。函数内部循环所有组件并调用 app 的 component 方法：`components.forEach(component => { app.component(component.name, component) })`，每个 component 都是个 object，有 name 和真正的实现，这样任务就完成了。

最后是导出。首先要把每个单独的组件都导出，比如 LText，并且把 install 也导出。另外别忘了默认导出：使用方 `import ... from` 组件库时拿到的就是一个默认导出，这里只需要将 install 这个 function 用 `export default` 导出，作为插件的入口。

这样业务组件库就改造完毕了，现在支持两种插件的调用方式。我这里只写了一个组件，请大家把 LImage 和 LShape 等组件一一补充完整，留作课下练习。
