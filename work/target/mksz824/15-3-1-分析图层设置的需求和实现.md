# 15-3-1-分析图层设置的需求和实现

这节课进入右侧面板的第二部分开发。设计图中的右侧面板有三块内容：已经完成的属性设置，以及还未开发的图层设置和页面设置。本章先开发图层设置的相关功能，先看编辑需求文档中的具体需求，我用原型图来表示，看起来更清楚。

## 需求梳理

图层设置是一个单独的 tab，所以要在面板上新增一个 tab。每个图层对应编辑器上的每一个 component，也就是元素，有多少个 component 就有多少个图层。

图层上有一系列功能：

- **锁定**：每个图层的第一项是一把锁。单击后，再想编辑编辑器上的这个元素时就没法编辑，会显示一个提示；再点击一下取消锁定，恢复可编辑模式。
- **显示/隐藏**：锁之后是一个眼睛图标，即可见性。点击一下就隐藏，元素在编辑器中消失；再点击恢复。
- **点击选中**：图层本身也可以单击，效果就是选中，单击后编辑器上自动选中对应的元素。
- **名称编辑**：图层文字可以编辑。单击文字时界面切换成一个 input，把当前文字填进去，进入编辑模式后可以输入新的图层名称。这里有键盘快捷键：按 Enter 确认新名称，按 ESC 退出。还有一种模式：在 input 中输入时，点击外面任何区域，也会作为确认退出编辑模式。
- **拖动排序**：每个图层有一个拖动手柄，可以拖动它调换图层顺序。这是一个很常见的交互需求。

这几个功能的难度是由易到难的。

## 实现思路

先说最简单的：图层锁定、显示隐藏和点击选中。图层和编辑器中的元素是一一对应的，看一下 `editor.ts`，`components` 其实就对应图层，其中的 `ComponentData` 已经有一系列属性。所以对这些不同状态，只需添加特定的标识符来表示：比如锁定添加 `isLocked` 表示是否锁定，再加一个 `isHidden` 表示是否隐藏。点击不同的按钮时切换这些值，再根据值在页面中做判断，显示相应的提示或样式。至于点击选中，实现已经有了，就是 `currentElement`，点击选中后直接把它设置成被点击的元素即可。

第二个功能是图层名称编辑，交互会多一些。首先要有图层名称，可以继续在 `ComponentData` 上添加一个 `layerName` 属性。点击图层名称区域时，在 input 和普通标签之间切换。在不同状态下要对按钮和键盘事件做响应，需要响应 ESC 和 Enter 键，也就是可能要绑定一系列键盘事件，这里很可能要抽象出一个通用的 hooks 函数，可以叫 `useKeyPress`，处理键盘相关的事件。另外点击外面时状态要切回原状，这也可能抽象出一个通用 hooks 函数，叫 `useClickOutside`，判断是否点击到了当前区域之外。

最后一个需求是拖动改变顺序。这是常见需求，也是这里难度最高的一个，因为它涉及比较复杂的交互。不过它的最终目的其实很简单：改变 store 中 `components` 数组的顺序。`components` 就是一个数组，拖动完成后只要改变数组中不同项的位置，就实现了最终效果。但这个交互有不少细节，这里不做细节分析，等编码这一功能时再详细展开。

这节课我们分析了图层设置面板的一系列需求，并根据需求整理出了实现思路。有了这些指导思想，接下来的编码就可以下笔如有神了。
