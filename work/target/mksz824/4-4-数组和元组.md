# 4-4-数组和元组

这节课进入原始数据类型之外的世界，先接触前端工程师最熟悉的数据结构：数组（Array）。

## 数组类型

数组有多种定义方式，先看最简单的一种。声明一个数字类型的数组，只需在 number 后面加方括号：

```typescript
let arrayOfNumbers: number[] = [1, 2, 3];
```

数组项只能是约定好的类型，混入字符串就会报错 `string is not assignable to number`。反过来看 TypeScript 的好处：声明之后，变量自动获得了数组上所有方法的提示；而且方法的参数也会按定义时约定的类型做限制，`push(3)` 没问题，`push('123')` 就会出现红线。

## 类数组

补充一个 JavaScript 基础概念：类数组（Array-like Object）。它很像数组但不是数组。典型例子是函数体内的 arguments 对象，它有 length 属性，可以按索引取值，但没有数组的方法，比如 forEach 就不存在。

而且不能把数组直接赋给它。新建一个 any 类型的数组，让它等于 arguments 会直接报错，因为两者的类型定义并不相同。这些类型 TypeScript 都预先定义好了，把鼠标浮到 arguments 上就能看到它是 IArguments 类型。类似的还有 HTMLCollection、NodeList 等 DOM 相关的类数组，都写好了对应类型，用到的时候再展开讲。

## 元组（Tuple）

接下来是前端开发里没见过的领域：元组。名字唬人，其实它和数组非常类似。数组把同一类型的数据聚合到一起，比如上面的例子全是 number；如果想在不同位置放不同类型的数据怎么办？用 any 会丧失具体的类型信息，而元组可以合并不同类型的对象，它起源于函数式编程，用过 Python 的同学应该有印象。

元组的表示和数组类似，只是把每个位置的类型写在方括号里：

```typescript
let user: [string, number] = ['viking', 20];
```

定义之后约束很强：第一项必须是 string，第二项必须是 number；写错位置报错，多加一项也会报错说类型不适配。

不过元组本质上还是一个数组，所以可以用数组方法突破长度限制，比如 `user.push()` 再添加一项是允许的。但注意，通过 push 添加的值仍然只能是已声明的两种类型之一：push 一个 string 没问题，push 一个布尔值就会报错。这里出现的"或"的关系叫联合类型，后面章节会专门学习，这里先做个引子。

## 小结

这节课接触了第一种 object type 的复杂类型数组，还引出了它的特殊变体元组，理解起来都不难。
