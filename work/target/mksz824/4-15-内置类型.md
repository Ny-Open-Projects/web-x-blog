# 4-15-内置类型

上节课简介了声明文件：想在 TS 项目中使用第三方库时，需要安装或者自己写一系列声明文件。上节课也说到了，除了第三方库，JavaScript 还有许多原生对象，称之为 built-in objects。其实前面课程中我们已经不知不觉使用了许多内置对象。

内置对象是指根据标准在全局作用域（global）上存在的对象。这里的标准是指 ECMAScript 和其他环境（比如 DOM）的标准。这些内置对象在安装 tsc 的时候会当作附加的礼物送给你，在每个 TS 项目中会被自动加载进去。

## Global Objects

先来感受一下 global objects，举几个例子。

写一个数组：`const arr: number[] = [1, 2, 3]`，没有问题。可以点击进去看 array 在哪儿定义：Mac 按住 Command、Windows 按住 Control 点击，会发现它在不同的文件中都有定义，都是内部类型的一部分，根据不同的版本或功能合并在一起。一个 interface 或类多次定义会合并在一起。这些文件都以 lib 开头、以 .d.ts 结尾，告诉我们它们是内置的对象类型。

再创建一个 Date：`const d = new Date()`，d 就变成了内置的 Date 类型。可以右键 go to type definition 去定义的地方，逻辑和刚才一样。有了 Date 类型，就可以在上面调用一系列方法，非常全，比如 getTime 没问题。

再创建一个正则表达式 /abc/，reg 是 RegExp 类型，可以在上面调用它的方法，比如 test 传入字符串 'abc'，没问题。

还可以使用其他内置对象，比如 Math.pow(x, y)，两个参数都是 number。Math 与其他全局对象不同的是，它不是一个构造函数，所有属性与方法都是静态的。

## DOM 和 BOM

除了 ECMAScript 的标准语法，JavaScript 和浏览器打交道也非常多，需要连接这两个世界的桥梁，这就是 DOM 和 BOM 的一些标准对象。

创建变量 body 等于 document.body，document 也是一个内置对象，body 就变成了 HTMLElement 类型，上面有一系列方法和属性，非常全。

document 上还有 querySelectorAll 方法，找 li 标签：`const allLis = document.querySelectorAll('li')`。allLis 变成了 NodeList 类型，可以调用 NodeList 上的方法，比如 forEach、item、keys 等，非常全。

添加事件也是很重要的一部分。document 上有 addEventListener 方法，第一个参数是事件类型（click），第二个是回调函数。注意这个回调函数：因为类型推断，里面的 e（事件对象）自动获得了类型，是 MouseEvent，因为点击是鼠标事件。现在就可以方便地使用 e 上的属性和方法，比如 preventDefault。

## 标准库与版本

看看 TypeScript 内部的标准库，就是刚才看到的 .d.ts 文件，非常多，而且很多和版本相关：从 ES2015 一直到 ES2016、2017、2018、2019、2020 到 Next。也就是说在 TS 中可以随意使用最新版本的 JavaScript 语法，非常方便。

## Utility Types

除了这些内置类型，TypeScript 还提供了一些功能性、帮助性的类型，在 JavaScript 世界里是看不到的，我们称之为 Utility Types，提供简洁明快而且非常方便的功能。以后的课程中会慢慢接触到。这里简介两个。

**Partial**：把传入的类型都变成可选。定义一个 interface 叫 IPerson，有 name、age 两个属性。建立一个变量 viking，是 IPerson 类型，就必须有这两个属性，给 name、age 赋值才能通过。新建一个 type：

```ts
interface IPerson {
  name: string
  age: number
}
type PartialPerson = Partial<IPerson>
```

Partial 是内置的，直接就有提示。把 IPerson 当做泛型传进去，返回的 PartialPerson 中 name、age 都变成了可选的。所以声明一个 PartialPerson 类型的变量，什么都不传也没有报错，传了也没问题。

**Omit**：返回的类型可以忽略传入类型的某个属性。创建一个 type：

```ts
type PersonWithoutName = Omit<IPerson, 'name'>
```

它接受两个泛型：第一个还是要传入的类型 IPerson，第二个是要忽略的属性。希望把 name 忽略掉，PersonWithoutName 就只剩下 age 了，声明变量时只需要 age: 20。

看一下它的定义，点一下 omit 会跳到 lib.es5.d.ts。虽然它们不是 ES5 的一部分，但算是附赠的小礼物，在 TS 编码环境中可以直接使用。

## 小结

这节课带大家了解了 TypeScript 一系列的内置类型。有了这些类型，可以搞清楚 TypeScript 的一部分来龙去脉。它定义的这些丰富的类型，可以在很大程度上帮助我们编码的过程。
