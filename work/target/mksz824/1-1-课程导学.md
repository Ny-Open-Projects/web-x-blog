# 1-1-课程导学

这门课程是从前端架构师体系大课中剥离出来的独立课程。架构师课程中的项目内容几乎完全独立，几个项目形成业务闭环，并且有比较完美的成品。不少同学在咨询时问能不能单独选学这部分内容，于是我们就把最后的这一块单独拿出来，做成了这门课：低代码可视化海报编辑器的全栈开发。

从标题不难看出，我们要完成的是一个高难度项目。设计这门课时，我们就是朝前端架构师方向去研究的，摒弃了那些不痛不痒、没有难度、拿不出手的 CRUD 项目。在互联网就业形势越来越严峻的今天，掌握多项有竞争力的技能非常重要，而一个有完整流程闭环、有深度和广度的真实项目，正好能匹配这个需求。

课程采用最新技术栈，实现了三个独立项目并形成闭环。这是我个人编程至今难度最大、知识面最广、技术最新、耗时最长、业务完全闭环的超大型项目，而且是在线运营的真实项目，几乎把所有技术干货都融汇进来了。在编码和录制的过程中，我自己也成长了很多。跟着完成之后，它完全可以成为你工作中的一个亮点级项目、求职的利器。比起简历上那些没有亮点的简单应用，一个充满亮点和难点的真实在线项目，面试官点开链接的第一时间就会被吸引。

## 项目演示

可以直接看成果，对应的网址是 OpsFlow。进入首页后能看到一系列热门海报，这些都是可以用编辑器完成的作品。

首先需要登录，我们使用真实的手机号。输入手机号后点击获取验证码，用的是阿里云的短信服务，会发送真实短信。登录成功后就可以创建设计了，可以直接使用模板。选一张海报点击"使用模板"，就进入了海报编辑器页面，这是整个项目的核心难点。

编辑器里由一系列元素组成，每个元素都配有各自的表单来编辑属性。比如可以通过下拉菜单修改字体，把字体改成宋体，画布上的元素立刻发生变化。所有属性都可以修改。交互操作也很丰富：拖动非常丝滑，还支持缩放，以及撤销、重做等功能。

编辑完毕后进入发布流程。点击发布，系统会单独生成一个 URL，可以分享给别人。复制 URL 打开对应页面，这个页面是完全手机端友好的，最终生成对应的 HTML 结构供使用。

## 整体架构

为了支撑这个庞大的系统，后端共有四个项目在同时运作，恰好设计成四块完全不同的技术方向，涵盖前端、后端、运维的各类知识，目标是把学员往前端架构师甚至全栈架构师方向培养。

看整体架构图，上面有很多密密麻麻的连线，一共要实现四个大项目，学习四套不同的知识：

- **前端项目**：就是刚才演示的低代码海报编辑器，技术栈是 Vue 3 + TS + Ant Design Vue，要实现各种复杂的数据流和交互，属于高难度的明星项目。
- **后端项目**：前端所有 API 调用都由它提供，另外还有一块用于手机端的展示，就是刚才那个 URL 打开的页面，技术栈是 Angular + TypeScript。
- **OpsFlow 组件库**：这是设计中很特殊的一点，组件库供前后端共同使用，技术栈是 Vue 3 + TS + Rollup 打包。它既可以给前端渲染，也可以给后端的 C 端手机端展示做渲染。后端部分从基础全流程到深入浅出再到进阶和云服务，一网打尽，还讲了运维知识：用 CI/CD 触发一系列动作，比如 GitHub Actions 构建 Docker、Docker Compose，最后部署到阿里云 ECS，完全是企业级的 CI/CD 流程。
- **管理系统**：用来管理系统的各项功能，并且采用了 2024 年最新录制的技术栈，用 Nuxt 3 和 TypeScript 打造。

## 课程亮点

第一个亮点是真实运行的商业项目，实现完整闭环。四个项目从前端、后端到管理系统，再到组件库，是完整的闭环。

第二个亮点是纯手写打造。四个项目工程有两万多行代码，核心业务内容齐全且复杂度高：高难度的海报编辑器、通用组件库的开发测试打包发布、前端项目的性能优化、后端超全的知识点和云服务使用，最后是部署打通，Docker 和 GitHub Actions 实现 CI/CD。

第三个亮点是高复杂度、有深度、有广度。海报编辑器作为一个复杂的 Vue 项目，有几个必须解决的问题：数据表单的对应关系怎样设计？数据的相互依赖和实时更新怎样实现？交互复杂性如何实现，包括拖拽移动、缩放排序、撤销重做？画布和属性表单两者的数据怎样联动？画布上有大量表单对应各种属性，如果把这些表单一一写出，明显不现实也非常复杂，怎么设计是个难点。最后是如何实现可扩展的、前后端通用的组件库，这正是这个项目的巧思所在。

## 知识体系

一门课掌握全新、全面的全栈知识体系。由于课程设计从前端架构师角度出发，涉猎内容非常广：

- 前端基础架构：Vue 3、Nuxt 3、TypeScript、ESLint、Vite 和 Vue CLI。
- 组件库与样式方案：Ant Design Vue、Nuxt UI、Tailwind CSS。
- Vue 3 生态及第三方工具：内容非常多。
- 组件库打包发布：Rollup 及其一系列插件、NPM 的发布和配置、Travis 等。
- 服务器端：知识点非常丰富，还有 RBAC 权限管理、权限控制等高难度内容。
- 管理系统：Nuxt 3 的丰富知识点，以及性能优化的高阶内容。
- 部署与持续集成：课程一大亮点，Docker、Docker Compose、GitHub Actions、Release It，还有一系列云服务支撑，包括阿里云的几款和 Git 的 OSS。

## 课程收获与储备

学完这门课，你会有三个收获：掌握 Vue 3 最新的技术栈和知识体系；掌握复杂项目的设计和研发过程，包括页面 UI 组件的拆分设计、数据的拆分模块、合理的数据结构设计、数据流的组织分析，以及扩展性和灵活性的考量；掌握后端开发的最新技术和全流程，不仅技术栈新、难度高，云服务用得也非常多。

需要的技术储备只有两条：掌握前端开发的基础知识，掌握 Vue 2 的基础知识。

希望借助这门课，大家能在技术广度和深度上全方位提升自己。
