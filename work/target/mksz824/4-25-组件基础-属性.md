# 4-25-组件基础-属性

这节课讲 Vue3 组件的基础知识。组件是现代前端框架最重要的概念，不论 React、Vue 还是其他框架都有它。我们可以把大型应用按逻辑分割成多个更好维护的组件，组件之间一般是相互嵌套的。

前面我们已经多次和组件打交道，所有代码都是在 App.vue 中完成的。这节课重点了解组件的属性（Props），完成一个小任务：创建一个叫 MyProfile 的组件，显示姓名和年龄，它们就是这个组件的属性。

## 单文件组件结构

在 components 文件夹下新建组件。`.vue` 是 Vue 独创的文件格式，一个文件分三块：template 是组件的 HTML 结构，上面可以写各种 Vue 指令；script 是代码逻辑，注意可以设置 `lang="ts"`，让内容被解析成 TypeScript，很多同学就是因为漏了这个属性而在里面用 TS 报错，要特别注意；style 是组件样式。本节课先学 template 和 script 两部分。

## 定义属性

script 中最终导出的是一个 object，这里用 defineComponent 包裹，为了获得更好的 TS 类型提示。首先添加 name，它是组件的名称，最好和文件名一致。如果写成 Profile 会报错，这是 ESLint 的 Vue 规则：组件名必须是多单词（Multi word），单单词不够，改成 MyProfile 后错误消失。

接着用 props 字段定义组件属性。要显示姓名和年龄，就声明 name 和 age：

```typescript
import { computed, defineComponent, PropType } from 'vue';

export default defineComponent({
  name: 'MyProfile',
  props: {
    name: {
      type: String,
      required: true,
    },
    age: {
      type: Number,
      required: true,
    },
  },
  setup(props) {
    const doubleAge = computed(() => props.age * 2);
    return { doubleAge };
  },
});
```

特别要注意：这里的类型要用大写的 String 和 Number，也就是构造函数。所有和 Vue 属性相关的类型声明都需要用大写的 constructor。required 为 true 表示属性必传。

setup 的第一个参数就是 props，在 TS 的加持下它会获得对应类型：props 里写的是 String，name 就被映射成 string 类型，age 对应 number，一一相对。这里加了一个 computed 的 doubleAge 返回年龄的两倍，就是为了演示 props 会根据定义自动推断类型，用起来很方便。

## 注册并使用组件

在 App.vue 中展示 MyProfile。第一步用 import 把组件引入，第二步用 components 字段注册，不注册是无法编译使用的。注册后如果没使用，ESLint 会报"registered but not used"。在 template 最下面使用：

```html
<MyProfile name="Viking" :age="30" />
```

推荐驼峰式的写法，和原生标签区分开，一眼就能看出是 Vue 组件；写连字符形式也可以。

此时会报类型检查错误：两个 required 属性一个都没传。先传 name="Viking"，这是静态属性，传入的等于字符串，name 正好接收字符串，没问题。但 age 直接写 30 会报错 `string is not assignable to type number`，静态属性把值当字符串传。要传数字必须用冒号的动态写法，`:age="30"` 是 v-bind 的简写，动态属性里可以传变量或 JavaScript 表达式，所以 30 是数字而不是字符串，展示正确：name Viking，age 30，doubleAge 60。

## 默认值

属性还可以加 default，传入默认值后就不必必传了。把 age 的 required 换成 `default: 30`，App.vue 里不传 age，刷新后同样显示 30 和 60；传 40 则覆盖默认值，显示 40 和 80。

## 标注复杂类型

最后讲一个 TS 相关的进阶内容。现在不想传 name 和 age 了，只想传一个 object 类型的 user，上面有 name 和 age。如果把类型设置成 Object 构造函数，props.user 只会得到 Record<string, any>，所有属性都是 any，和 TS 的理念相悖。Vue 提供了专门标注 props 类型的函数 PropType：

```typescript
interface User {
  name: string;
  age: number;
}

props: {
  user: {
    type: Object as PropType<User>,
    required: true,
  },
}
```

PropType 接受一个泛型，把想要的类型传进去。这样 props.user 就有了正确提示：name 是 string，age 是 number。模板和传入处相应改成 user 属性，可以直接传之前创建的 user 变量，刷新后显示正常，复杂类型标注成功。

## 小结

这节课讲了组件属性的定义方式：props 字段下声明属性名和类型，required 设为必选，default 设默认值；还讲了用 PropType 加泛型来标注复杂属性类型，标注后 setup 中的 props 就会变成对应的类型。
