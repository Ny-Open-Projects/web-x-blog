# 13-11-配置阿里云 oss

这节课学习使用阿里云 OSS 完成对应的上传。第一步是在阿里云中创建一个 bucket。bucket 是水桶的意思，可以理解为一个大的文件夹分类，下面还可以创建非常多的子文件夹。bucket 不是阿里云 OSS 特有的概念，所有对象存储服务都有这个概念，是共性的。

## 创建 bucket

点击创建 bucket，填写名称，这里叫 OpsFlow-backend。地域选择离你近的地方，我选上海，选择地域时 endpoint 会随之变化，其他选项保持默认。有一项要特别修改：读写权限。因为图片上传后要可供各种人访问，所以设置成公共读。确认后 bucket 就创建完毕了。

## aliy-oss SDK 与 egg-oss 插件

创建完 bucket，接下来了解怎样在服务器端完成上传。需要使用阿里云基于 Node.js 的 SDK，包名是 aliy-oss，同时支持浏览器和 Node.js。用法上，先实例化（create a bucket instance），传入一系列 options，之后就可以在实例上调用各种方法。方法非常多，我们要用 object operation 里的几个，最重要的是 put，put 就是上传，把一个 file 上传到对应的位置。

在 egg 应用中可以直接使用 egg-oss 插件。从 SDK 的用法看，最重要的是 OSS 实例，有了实例就能调用各种方法。插件怎么提供这个实例？文档写明：You can acquire OSS instance on app or ctx，也就是通过 `ctx.oss` 拿到实例。

为了验证这个想法，看一下源码。可以想象它应该在程序启动时初始化对应对象，然后在 ctx 上做 extend 扩展。看 app.js：它直接使用了 lib 下面的 oss，把相关代码写到 lib 中，这是常用写法。点开 lib/oss.js：从 aliy-oss 拿到构造函数，然后使用常见的 `app.addSingleton('oss', ...)` 向 app 上添加这个变量，根据配置的不同创建不同实例（cluster、client、sts），什么都不加的话就是普通的 new OSS 实例。程序启动时还有一个扩展步骤：extend 目录里只有一项 context.js，源码里就是一个 get oss 的读取，直接返回 app 上的 oss。通过这种方式完成了扩展。

## 补类型定义

现在安装和配置 egg-oss 插件。遗憾的是它没有 TS 定义文件，用起来会非常不便：看 aliy-oss 的文档就知道，初始化的 options 和方法都非常多，手写类型非常痛苦且容易出错，所以必须添加类型。

第一步安装 egg-oss 插件；同时还要安装 @types/ali-oss，因为插件内部基于 aliy-oss，装上它的定义文件，然后在 ctx 和 app 上做扩展。两个包都装好后启动应用。

之前已经在 typings 的 index.d.ts 里做过扩展，现在要在 context 和 config 上扩展。先导入类型：`import * as OSS from 'ali-oss'`，它默认导出一个类，就是我们使用的实例类型。在 Context 上添加 `oss: OSS`；App 上可以自己照着写一下。还有一个重要的配置项 oss 的选项，参考例子：写成 `{ client: {...} }` 这种类型。client 的参数可以从 aliy-oss 的 options 里导入类型，进去看会发现和 SDK 文档的配置参数完全一致。于是定义成 `oss?: { client?: Options }`。

安装的插件或包没有类型时，希望大家都能用这个文件进行自定义，它是一个非常方便的扩展文件。有了类型后，`ctx.oss.` 会自动联想出各种方法，写代码时能知道参数名和类型，避免不该有的错误。

## 启用插件并配置

第一步在 plugin 里启用：包名 oss，enable 为 true，package 为 egg-oss。然后在 config 中添加 config.oss，里面是 client，参数包括：accessKeyId（使用阿里云的服务都需要这几个参数，之前发短信的 aliy cloud 配置里也有，直接复制过来，从环境变量提取，并补一个空字符串默认值防止 undefined）、accessKeySecret（同样从环境变量提取）、bucket（上传到哪个桶，就是刚创建的 OpsFlow-backend）、endpoint（选择不同地域 endpoint 不同，有对应的对照表，上海地域是 oss-cn-shanghai，选其他地域请自行查询后填上）。

参数都添加完毕，这节课的准备工作就完成了。从 bucket 创建、ali-oss 实例上的方法、egg-oss 的原理，到最后的配置，希望大家对这个过程都清楚了。下节课使用它完成上传任务并返回对应的 URL。
