# 19-4-1-vue.config.js简介

上一章我们简介了 webpack loader 和 plugin 的原理。之前我们也了解了 Vue 在构建过程中底层使用的是 webpack，还拿到了它非常复杂的配置文件。对于一些大型项目，我们希望在构建过程中做一些个性化的定制，这时就必须使用 vue-cli 提供的途径来完成定制化。这个可选的配置文件就称之为 vue.config.js。

## vue.config.js 的基本规则

文档中说明：vue.config.js 是一个可选的配置文件，如果项目的 package.json 同级的根目录中存在这个文件，它就会被 @vue/cli-service 自动加载。所以必须有这种格式，并且放到根目录去，然后在里面写一系列配置，其中大多数都是和 Webpack 配置相关的内容。作为 vue.config.js 的第一节，先简介两个我们项目中会用到的简单选项，再进阶到拦截 Webpack 配置、自定义 Webpack 的阶段。所有配置字段都可以在文档中找到。

再强调一点：vue.config.js 文件中所有的环境变量都可以访问。之前说的用 .env 创建的一系列变量，在客户端中只能使用特定类型的（NODE_ENV、BASE_URL、VUE_APP_ 开头的变量），而在这个脚本中它是编译的第一阶段，所以不管里面定义了任何变量，都可以直接使用。

## 第一个需求：publicPath

第一个字段是 publicPath，它是部署应用包时的基本 URL，对应的是 Webpack 配置中的 publicPath 属性。我们的需求是：生产环境使用一个单独的 CDN 域名，其他环境使用默认域名的根路径。

它有一系列可选值。第一个是默认值 `/`，会把应用部署在域名的根路径上，静态资源直接部署到根路径。第二个可以设置为子路径，如果应用部署在一个子路径（二级文件夹）下面，就设置成对应的路径。第三个就是我们的需求：设置为一个 CDN 路径。我们的应用最后静态资源要全部上传到 CDN，这是脚手架自动完成的，所以这里需要设置 CDN 域名，对应的是 `oss.mulego.com/editor`。最后还可以设置为相对路径（'' 或 './'），所有资源都会被链接为相对路径。

来看代码。首先要拿到环境变量，判断当前是什么环境。创建一个 isStaging，取 process.env 的 VUE_APP_STAGE 变量，转换成布尔值；再拿是不是 production：process.env.NODE_ENV 等于 production 时说明要到 production 环境。然后使用 module.exports 把配置导出：

```js
module.exports = {
  // 生产环境使用 CDN 地址，其他环境使用绝对路径
  publicPath: isProduction && !isStaging
    ? 'https://oss.mulego.com/editor'
    : '/',
};
```

注意这里要 isProduction 并且不是 staging，因为 staging 其实也是一个要打出 production 代码的环境，但它应该用绝对路径；其他环境都用绝对路径 `/`。

做两个打包来验证。第一个直接 npm run build，应该进入 CDN 的逻辑。打包完成后 `cat dist/index.html`，可以看到每个静态资源前面都加上了 OSS 地址，说明最终是 production 环境。接下来测试 staging 环境，命令是 npm run build:staging，打包完成后同样看一下：这时它直接生成了绝对路径，之前的 OSS 地址消失了。第一个任务完成。

## 第二个需求：定制主题色

第二个需求是项目中的一个真实需求：项目后期想改主题颜色，也就是想拥有定制 CSS 的能力。我们使用的主要样式库是 Ant Design Vue，所以想修改这个框架的主色调。

Ant Design Vue 的文档里提到了样式变量：它使用 Less 作为开发语言，Less 中定义了一系列全局组件的样式变量，可以在这个文件中找到所有变量。它的定制方式是：在 Webpack 中定制主题，其实就是对 less-loader 的 options 属性进行相应的配置，添加一个 modifyVars，就能修改变量的值，比如 primaryColor（主色调）可以修改成任何想要的色调。

那么怎样在 Vue CLI 中修改 loader 的选项？有一个特殊的选项叫 css.loaderOptions，就是向 CSS 相关的 loader 传递选项。我们需要的是 less-loader，所以在里面添加 less 的配置，把 modifyVars 传进去：

```js
css: {
  loaderOptions: {
    less: {
      lessOptions: {
        modifyVars: {
          'primary-color': '#1D39C4',
        },
        javascriptEnabled: true,
      },
    },
  },
},
```

modifyVars 把 primary-color 改成另外一种深蓝色；javascriptEnabled 这个选项文档里写了默认要添加。

既然这里配置了 less，那么 main.ts 中就不能直接加载编译后的 CSS 了，要使用 less 文件。Ant Design Vue 的 dist 中不仅有编译后的 CSS，还提供 LESS 的源文件，直接使用 LESS 就可以了。

## 版本兼容的大坑

使用的时候还需要安装 less-loader 和 less 本身，Vue CLI 并没有默认安装 less 的处理。这里特别注意有一个大坑：less-loader 要使用 7 系列的版本（我这里用了 7.1.0），less 要使用 3 系列的版本。因为最新版本 less-loader 是 8、less 是 4，它们不兼容旧版的语法，而 antd 的 less 源文件用的是比较旧的语法，直接使用新版本会报错。所以一定要选用这两个旧版本。

安装完成后运行 npm run serve，启动完毕后看应用：主色调已经变了，原来是浅蓝色，现在变成了深蓝色，功能生效。

这节课了解了 vue.config.js 这个文件的来龙去脉，并用它完成了项目中的两个具体需求。下节课会更深入了解这个文件的其他内容。
