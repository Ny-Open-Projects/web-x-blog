# 14-13-Docker 简介以及安装

经过传统部署的煎熬以后，我们希望有一个工具可以帮我们完成一键的智能部署：假如要部署在多台不同的机器上，可以不用再担心不同系统、不同版本的差异，以及运行之前需要安装不同软件的痛苦。同时这些软件还有可能出现不兼容的问题，修复这些 bug 会是非常费时费力的步骤。为了解决这个问题，我们要使用当前最火的虚拟化工具：Docker。大家可以直接访问 Docker 的主页，里面有一系列信息可以看一下。

提到虚拟化工具，大家第一个想到的应该是传统的虚拟机。我相信大家都使用过 VMware 或者 VirtualBox 这一类型的软件，安装过虚拟机上的操作系统，比如在 Mac 上安装 Windows 进行测试，或者在 Windows 上安装 Linux 进行测试。Docker 和这类虚拟机类似，但在它们之上做了大幅的改进，采用了一个全新的架构。

看这张图，左边是 Docker 的架构，右边是传统虚拟机的架构。传统虚拟机首先要虚拟一系列硬件，我们都知道要给它分配多少内存、多少硬盘、虚拟的显卡等等，然后需要在上面安装一个完整的操作系统。黄色的 Guest OS 就是一个完整的操作系统。这样做当然要占用一部分系统资源，运行时也会受到操作系统的限制，有可能速度比较慢，或者有一系列限制。

而 Docker 推陈出新，推出了一个新的概念，叫 Container。图里每一个都是 Container：Container A、Container B 和 Container C。每个容器不需要安装完整的操作系统，可以看到里面并没有 Guest OS 这一部分。里面的进程（比如 App A、App B）可以直接运行在 Docker 创建的宿主内核中，也就是 host operating system。Docker 创建了一部分新的内容。这么运行不需要虚拟任何硬件，也就是说不需要给它分配多少内存、多少 CPU 或者多少硬盘，所以它更加轻便和快速。

通过这张图可以总结出 Docker 的几个优点。第一个特点是更快速的启动速度：摆脱了操作系统，直接运行在宿主内核中，所以它比传统虚拟机快得多。第二是更少的资源占用、更高效的资源利用：不需要安装操作系统和虚拟硬件，Docker 每个容器占用的资源由宿主内核自动分配，大量减少了系统的开销。所以同一台机器也许可以运行几个虚拟机，但可以运行几十个甚至上百个容器。

第三个特点是一致的运行环境。Docker Container 可以轻松部署到任何环境、机器或操作系统，内核提供了一致的运行环境，确保运行环境完全一致。这样就可以杜绝不同环境差异带来的问题，解决了我们之前所说的：假如应用要在多个地方部署，Docker 可以轻松完成这个任务。

最后一个特点是微服务架构。Docker 天生适配微服务架构，这也是现在微服务这么流行的原因。它将原来大型的应用分割成一系列小的服务，每个服务都可以运行在一个单独的 container 中。每个容器都可以轻松地被启用、停止、删除或者重启，每个容器都不会对系统整体产生致命的影响。

讲了这些优点，相信大家已经跃跃欲试了。现在来下载 Docker，下载地址在这里。安装非常简单，它提供了完全图形化的界面和工具。来到这里以后，它会自动根据你的操作系统弹出选项：我们是 Mac，所以选 Mac with Intel chip（Intel 的内核）。这里还有 Windows 和 Linux，根据你的操作系统自己去安装就好了。

安装完毕以后会生成一个具体的软件，运行一下：就是这个蓝色的图标，点击运行以后会弹出一个对应的界面。等它运行完毕以后，界面会发生变化。这个时候 Docker 软件已经启动成功了，可以看到它显示绿色状态，并且提示 No containers running，因为我们还没有启动任何容器。

下载和运行就成功了。这节课我们简单介绍了 Docker 是什么以及它的优势，最后还下载启动了 Docker 的客户端。大家特别注意：客户端和容器不是一个概念，只有先启动客户端以后，才可以使用对应的容器。下节课学习它的基本概念。
