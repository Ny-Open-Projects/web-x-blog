# 8-3-上传文件的原理

在开始编码上传组件之前，我们先来谈谈文件上传的流程。很多同学经常在业务中使用写好的上传组件，但对其中的一些基本原理可能还有欠缺，这节课就来查漏补缺，把上传文件的流程彻底搞明白。

## 传统表单提交

文件上传有两种方式，先从最基本的 form 提交谈起。既然要上传文件，当然要选择文件，可以用现成的 `input type="file"`，它会渲染出一个选择文件的按钮，点击后即可选择文件。

文件选择完成后，有两种方式完成上传：一种是传统的 form submission 表单提交；另一种是使用 JavaScript 发送异步请求，也就是我们要着重实现的方法（它本质上也是模拟表单提交）。

传统的 form 提交流程是：点击提交（`type="submit"`），请求带着 `method="post"` 发送到 action 指定的支持上传的 URL，server 端接到请求后做对应处理并返回结果。这是经典的 client 到 server 的形式。演示中我在首页加了一个一模一样的表单，file 有 `name="file"`，还多加了一个 text 字段。选择文件、点击 Submit 后，模拟的后端完成上传并返回一个阿里云 OSS 地址。

## multipart/form-data

要特别注意表单和普通表单的区别：发送的文件属于二进制格式，所以 `enctype` 必须设置成 `multipart/form-data`。只要表单里有二进制文件，就必须使用这个格式。为什么这么说？我用抓包工具演示一下它的工作方式。这里推荐 Mac 下的 Proxyman，可以免费下载，比 Chrome 的调试信息看得更清楚，新版 Chrome 中使用 form data 发送文件时，详细信息是看不见的。Windows 平台可以使用大家都熟悉的 Fiddler 2。我加了一个 filter 只监控 7001 端口的请求。

发送请求时选择文件、填几个值、点击 Submit，Proxyman 监控到了 API upload 这个请求。查看它的 headers 和 body，可以看到发送的信息是分段的：先是发送的图片 component-props.png，后面跟一大段二进制信息（显示为乱码没关系），然后又一段是我们添加的字符串 text 等于一二三四。form data 就是通过特殊字符分段的方式来完成文件上传的。

那表单默认的 enctype 是什么呢？是 `application/x-www-form-urlencoded`，这是表单默认的编码格式，含义是表单数据被 encode 到 body 或 URL 中发送。把表单的 enctype 删掉、使用默认格式再发一次，后端会返回失败，因为它提示 Content-Type 必须是 multipart。从请求的 body 可以看到，它只是把 `file=component-props.png&text=一二三四` 用 URL encoded 的形式结合在一起，真正的二进制文件并没有被转换，只留下了一个文件名，这当然是不行的。

结论：如果要发送大量的二进制数据，必须使用表单的 multipart/form-data 类型。

## JavaScript 异步上传

有了这一点知识，我们就可以用 JavaScript 完成异步上传的 post 请求了。提交 form 本质也是发送 HTTP 请求，用 JavaScript 发送体验更好，过程万变不离其宗，仍是模拟表单发送 HTTP 请求。

首先在 `input type="file"` 上，希望文件一变就发送请求，自然想到 onChange 事件。在 setup 中写一个 handleFileChange，它接收一个 event 类型的参数。要拿到 file 对象，先取 `event.target`，做一个类型断言，把它断言成 HTMLInputElement；然后取它下面的 files 属性。files 是一个特殊类型 FileList，它是一个 array-like object，不是真正的数组。

接着判断 files 存在后取第一项（这里只测试上传单个文件）：`const uploadedFile = files[0]`。因为它是 array-like object，可以用索引访问。

拿到文件后就可以发送数据了，我们用 FormData 对象模拟表单数据，这是专门为 XHR 设计的数据类型，可以很方便地用 JavaScript 创建表单对象。创建 `const formData = new FormData()` 后，用 append 方法添加键值对：第一个参数是名称，用 uploadedFile.name；第二个参数是值，直接传 uploadedFile 文件本身。

发送请求用 axios 的 post：第一个参数是后端 URL；第二个参数是要发送的数据，即 formData；第三个是一系列选项，特别要记得加上 content-type 这个 header，值与 enctype 一致，表单的 enctype 转换到 post 之后，就是 content-type 这个字段。

打印 response.data 验证一下：把 handleFileChange 绑定到 change 事件，选择文件后触发了 onChange，请求真正发送成功并有返回值，同时页面没有跳转。这就完成了使用 Ajax 发送文件的方法。

这节课我们学习了传统表单上传文件的原理，并演化到使用 JavaScript 上传文件的过程，这就是上传组件的基本原理。懂了这个流程，其他都不在话下，下节课开始正式编码。
