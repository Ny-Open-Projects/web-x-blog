# 4-27-组合式函数

在本章最早介绍 Vue3 时说过，使用组合式 API（setup 中的这些逻辑）可以解决两个问题：一是把相关的 feature 结合在一起，不必分散在很多地方；二是可以非常容易地重用，比 Vue2 的 mixin 有更高的灵活度。这节课展示怎样用组合式 API 做逻辑化和模块化的重用，这是组合式 API 最大的应用，会用几节课详细说明。

## 场景：追踪鼠标位置

产品经理扔来一个需求：追踪鼠标的位置，点击鼠标时捕捉当前坐标，可能拿来做用户分析或数据展示。不管用途，先完成任务。

在 App.vue 中需要两个坐标，各用一个响应式对象记录：

```typescript
import { defineComponent, onMounted, onUnmounted, ref } from 'vue';

export default defineComponent({
  setup() {
    const x = ref(0);
    const y = ref(0);

    const updateMouse = (e: MouseEvent) => {
      x.value = e.pageX;
      y.value = e.pageY;
    };

    onMounted(() => {
      document.addEventListener('click', updateMouse);
    });

    onUnmounted(() => {
      document.removeEventListener('click', updateMouse);
    });

    return { x, y };
  },
});
```

在 onMounted 里给 document 添加 click 事件，回调的参数是事件对象，类型标注为 MouseEvent，这是 TS 内置的 DOM 相关事件类型，上面有鼠标点击相关的属性。pageX 是鼠标相对于文档的位置，pageY 同理，分别更新到 x 和 y。

特别注意：既然在 mounted 时添加了事件，就要在 unmounted（组件卸载时调用的生命周期钩子）里把事件移除，有始有终才是完美做法。

模板里用两个 h1 展示 x 和 y，点击页面后坐标正常更新，功能完成。

## 提取成组合式函数

第二个任务是重用：假如 MyProfile 组件也需要拿到鼠标位置怎么办？这就是 Vue3 最重要的部分：组合式函数（Composition Functions），完成逻辑提取。我喜欢把它叫 hooks，沿用了 React 对这个词的用法。

在 src 下新建 hooks 文件夹，再建一个 useMousePosition.ts。用 use 开头是组合式函数的命名习惯。把刚才的所有逻辑放进一个函数，最后返回需要的值：

```typescript
import { onMounted, onUnmounted, ref } from 'vue';

export function useMousePosition() {
  const x = ref(0);
  const y = ref(0);

  const updateMouse = (e: MouseEvent) => {
    x.value = e.pageX;
    y.value = e.pageY;
  };

  onMounted(() => {
    document.addEventListener('click', updateMouse);
  });

  onUnmounted(() => {
    document.removeEventListener('click', updateMouse);
  });

  return { x, y };
}
```

这种利用 Vue 组合式 API 封装和复用有状态逻辑的函数，就称为组合式函数。

## 使用

在 App.vue 里删掉原来的逻辑，导入并直接调用：

```typescript
import { useMousePosition } from './hooks/useMousePosition';

const { x, y } = useMousePosition();
```

它没有任何参数，返回两个坐标值，类型推断完全正确。重构后点击页面，坐标依然完美更新。

## 对比 mixin 的优点

通过这种重构方式，可以清楚发现它比 mixin 好在哪里：

1. 数据来源清晰：x 和 y 来自 useMousePosition，一眼就知道它们是追踪鼠标位置的值。
2. 可以给返回值设置任何别名，避免命名冲突的风险。
3. 这段逻辑可以脱离组件存在：它本来就与组件实现无关，不需要组件、不需要模板，就像一个正常函数一样存在，非常明晰。

## vueuse

最后推荐一个库：vueuse（vueuse.org），Vue 官方推荐的一系列组合式函数库，有两百多个 function，作者是一批 Vue 核心团队成员，代码质量很高。日常工作中可以直接使用这些函数，也建议阅读它的源码，分析写法的优势，用到自己的项目里。

通过这种方式，我们非常优雅地完成了一次逻辑重用。
