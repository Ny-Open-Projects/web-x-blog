# 4-16-Vue3 学习导学

这一章我们学习 Vue 3 的基础知识。所有代码都会使用 TS 编写，正好可以应用上一章学到的 TS 知识，看看两者是怎样完美结合的。

这节课的目的简单介绍一下本章的学习计划，看看有什么新内容。已经有很好 Vue 3 基础的同学可以选择跳过，不过我还是建议所有人再看一下，因为里面添加了很多新的知识点和技巧，特别注意最后还有非常新的关于 3.3 的更新简介，应该还是有一些新东西的。

## 学习计划

第一步，学习使用脚手架创建项目，也就是使用 Vite 来创建。创建完后分析它的文件结构，并安装一些对应的插件。然后配置开发环境，使用 ESLint 工具。ESLint 对整个代码规范来说是举足轻重的工具，非常重要。

接下来是学习各类基础知识（对应的环境是 Vue 3.2）。一开始是响应式，介绍 ref、reactive、computed 和 watch 四个最常用的 API；然后是生命周期；再进入组件的世界，讲组件最重要的两部分，属性和事件；之后是 Vue 3 一个非常重要的特性，Hooks 函数；再讲 setup 语法糖，之后的代码都会使用 setup 语法糖的规范；最后讲依赖注入，也就是 provide 和 inject。

介绍完各类基础知识后，最后介绍最新版本 Vue 3.3 升级的内容。Vue 3.3 非常新，是 2023 年 5 月 11 号推出的版本。由于 3.3 不是一个特别大的版本，升级内容不多，一大部分都是和 TS 相关的更好的类型支持。没有 breaking change，所以 3.2 和 3.3 是兼容的。

代码录制过程中 3.3 还没推出，所以前期代码的编写都使用 3.2 版本。所有代码编写完毕后，我们会一起把它升级到 3.3 版本，看看能有什么新的体验。

这就是本章的导学。接下来按照计划，一步步进行 Vue 3 基础知识的学习。
