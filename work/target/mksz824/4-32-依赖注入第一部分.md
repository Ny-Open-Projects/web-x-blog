# 4-32-依赖注入第一部分

这节课讲一个非常实用的 Vue3 新特性，也是组合式 API 的一部分：Provide 和 Inject，中文叫依赖注入。先看问题是怎么发生的。

## Prop Drilling 的问题

典型 Vue 应用中，数据通过 props 由上而下传递，从父组件传给子组件。但对某些全局性的属性来说，这种传递非常繁琐。比如当前语言（中文还是英文）、当前主题（深色还是浅色），这些属性在应用的各层组件中都可能用到。

假设有一棵组件树，根节点有一个 language 属性，而一个深层子组件需要它，就只能一层层传：先传给 footer，再由 footer 以 props 方式传给 deep child；如果 deep child 下面还有嵌套，还要继续传。这种层层传递的方式称为 prop drilling，非常令人苦恼。

## Provide / Inject

provide 和 inject 就是为解决这个问题推出的：它提供了一种在组件间共享值的方式，不必在组件树每个层级显式传递 props，设计目的就是共享对组件树而言全局的数据，比如主题、语言、当前用户信息等。

从图上看：父组件（比如根组件）可以作为依赖提供者（provider），用 provide 方法提供想给子组件的信息；它树下的任何子组件，无论多深，都可以通过 inject 方法快速拿到 provide 提供的数据。一层层传递就省掉了。

## 基本用法

在 App.vue 中提供一个全局的语言信息。先从 vue 导入 provide，在 setup 任何位置都能调用。它有两个参数：key 和 value：

```typescript
import { provide } from 'vue';

provide('language', 'ch');
```

接下来在子组件中取值。为了让层级更深，把 HelloWorld 嵌套到 MyProfile 中形成三层结构。只要是 App 的子组件，无论多深都可以注入，HelloWorld 里用 inject 拿值：

```typescript
import { inject } from 'vue';

const language = inject('language');
```

inject 提供相同的 key，返回的就是 provide 对应 key 的值。放进模板后，页面上 HelloWorld 成功显示了 ch，任务完成。

## 提供响应式对象

再进一步：provide 的值也可以是响应式对象，子组件能完美响应变化、更新视图。在 App.vue 中创建响应式对象 language，以及更新它的函数：

```typescript
const language = ref('en');
const changeLanguage = (type: string) => {
  language.value = type;
};

provide('language', language);
```

界面上加两个按钮，分别切换中文和英文，点击时调用 changeLanguage 更新值。测试：点击中文切换成 ch，再点英文切换回 en，响应式注入完全可行。

## Symbol 作为注入名

刚才用的是字符串 "language" 作为注入名称。但如果在构建一个大型应用，可能包含非常多的依赖提供，字符串 key 很容易重名，重名会造成覆盖问题。我们需要独一无二的注入名称。

这正好契合 JavaScript 的一个基础数据类型：Symbol。文档写得很清楚：每个从 Symbol() 返回的值都是唯一的，并且能作为对象属性的标识符，这是它仅有的目的。

最佳实践是新建一个单独的文件保存这些 symbol。在与 App.vue 同层新建 keys.ts：

```typescript
export const languageKey = Symbol();
```

现在 languageKey 是一个独一无二的 symbol。provide 和 inject 两处都把字符串替换成这个 key：

```typescript
import { languageKey } from './keys';

provide(languageKey, language);
```

刷新验证：默认 en，点击中文变 ch，点英文变回来，改造成功。
