# 4-12-类型别名，字面量 和 交叉类型

前几次课分多次讲解了泛型的用法，希望大家多看几次好好消化，泛型确实很费脑细胞。这节课查漏补缺，讲几个比较简单的零碎小概念：类型别名、字面量和交叉类型。

## 类型别名（Type Alias）

类型别名，听名称就好理解：给类型起一个别名。之前说过，有些类型写出来是一大长串，每次都写非常累。比如一个函数类型：

```ts
const sum = (a: number, b: number): number => a + b
const result = sum(1, 2)
```

写这个函数类型要写很长一串，在其他地方写又要写一长串，非常不方便。这时可以创建一个类型别名，使用 type 关键字，创建一个名称叫 PlusType，把类型赋给它：

```ts
type PlusType = (a: number, b: number) => number
```

假如有一个 sumTwo 变量，可以直接把它赋值为 PlusType，然后 result2 = sumTwo(2, 3)，没有问题。注意这里只是演示，只声明了类型没有添加实现，直接在 JS 中运行是会报错的。

类型别名支持各种写法。要在多处使用的类型，都不妨用它来抽象管理。再举一个例子：一个类型可以是字符串也可以是数字，可以创建一个联合类型：

```ts
type StringOrNumber = string | number
```

result3 是 StringOrNumber 类型，它可以等于字符串，也可以等于数字，都没问题。但不能等于布尔值，这时会报错。

## 字面量（Literals）

提到类型别名和联合类型，这里添加一个新的小概念：字面量 literals。它是一个特殊的类型，只能是一个原始数据类型（primitive values）。

举个例子，有一个字符串 const str: 'name'，它的类型可以用定死的字符串 name 来定义，所以它只能等于 name，等于 'name2' 的时候就会报错。number 也一样，如果希望 number 只能等于 1，赋其他值都会报错。

大家可能会问，这东西有啥用？在 TS 中我们经常遇到一系列常量值，字符串字面量就是处理这种情形的简单方法。定义一个 type Direction，它有四个方向，都是字符串：

```ts
type Direction = 'up' | 'down' | 'left' | 'right'
```

新建一个变量 toWhere，类型是 Direction，就可以让它等于这四个值中的一个，输入时还有自动提示，非常方便。其他的值是不被允许的。

这个特性在以后的学习中会用到非常多，请大家记住，它应该也是非常好理解的。

## 交叉类型（Intersection Type）

刚才说的"或"的概念，在 TypeScript 中称为联合类型，指可以是这几种类型中的任意一种。和它相对应的还有交叉类型（Intersection Type），使用的符号是 &（and 符号），可以把几种类型合并起来。

举一个小例子，创建一个 interface 叫 IName，对象里只有一个属性 name，是 string 类型。然后创建一个 type Person，希望它等于 IName & 再加一个 age 属性：

```ts
interface IName {
  name: string
}
type Person = IName & { age: number }
```

这时 Person 就变成了有 name 和 age 两个属性的类型。声明一个 Person 类型的变量，name 有提示且是 string，age 可以赋值 123。

可以发现它和 interface 的 extends 非常类似，都是为了实现对象形状的组合和扩展。它们之间有一点区别，这里不展开讲，只说说什么时候用 interface、什么时候用 type。

type 作为类型别名是一种非常灵活宽泛的概念，它本身不是一种特殊的类型，只是别的类型的别名，有点像快捷方式。当要使用交叉或组合类型时，可以考虑使用 type。interface 是 duck typing 的实现方式，是一种独特的类型。当要实现 extends，或者用类去 implements 的时候，可以考虑使用 interface。其他情况下就看你的心情了，想用哪种都没有问题。

## 复习

这节课有几个新概念：类型别名（type alias），一个快捷方式，给写起来很烦的类型创造一个简单的写法；字符串字面量，提供非常方便的一系列常量的写法；交叉类型，使用 type 扩展对象的一种方式。
