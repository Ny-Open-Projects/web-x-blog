# Go 企业级抽奖项目: 奖品管理实现（中）

## 纲要

- 列表动作 `Get()`：通过 `GiftService.GetAll()` 取全量奖品，并完成「发奖计划」字段的可读化转换。
- 发奖计划 `PrizeData` 在库中是以 Unix 时间戳存储的 JSON 数组，需在程序侧反序列化并格式化为「时间:数量」字符串，再交模板渲染。
- 编辑动作 `GetEdit()`：依 `id` 取单条记录，`models.LtGift` 转换为 `viewmodels.ViewGift`。
- 引入视图模型 `ViewGift`：与数据库模型字段一致，但 `TimeBegin/TimeEnd` 改为字符串，并带 `xorm`/`json`/`form` 三类 Struct Tag。
- 转换原则：格式转换一律放在 Go 代码里完成，而非塞进模板。

## 视图模型 ViewGift

数据库模型 `LtGift` 面向表结构（字段类型由 XORM 映射），视图模型 `ViewGift` 面向表单与展示（时间用字符串）。两者通过 Struct Tag 建立多重映射关系：

```go
package viewmodels

import "time"

// ViewGift 后台奖品编辑页使用的视图模型
type ViewGift struct {
    Id        int    `xorm:"id" json:"id" form:"id"`
    Title     string `xorm:"title" json:"title" form:"title"`
    PrizeNum  int    `xorm:"prize_num" json:"prize_num" form:"prize_num"`
    PrizeCode string `xorm:"prize_code" json:"prize_code" form:"prize_code"`
    PrizeTime int    `xorm:"prize_time" json:"prize_time" form:"prize_time"`
    // 时间字段在库中是 int 时间戳，在表单/页面上是字符串
    TimeBegin string `xorm:"time_begin" json:"time_begin" form:"time_begin"`
    TimeEnd   string `xorm:"time_end" json:"time_end" form:"time_end"`
    PrizeData string `xorm:"prize_data" json:"prize_data" form:"prize_data"`
    SysStatus int    `xorm:"sys_status" json:"sys_status" form:"sys_status"`
}

// 时间格式化模板，统一后台时间展示样式
const timeLayout = "2006-01-02 15:04:05"

func formatUnix(sec int64) string {
    if sec <= 0 {
        return ""
    }
    return time.Unix(sec, 0).Format(timeLayout)
}
```

> 三种 Tag 的作用：`xorm` 让 XORM 识别列名与类型；`json` 控制序列化字段名（用 `-` 可忽略）；`form` 让 Iris 的 `ReadForm` 能把表单字段自动填充进结构体。

## 列表动作 Get

取全量数据后，对每条记录的 `PrizeData` 做「时间戳 → 可读字符串」转换。

```go
package controllers

import (
    "encoding/json"
    "strconv"
    "time"

    "github.com/kataras/iris/v12"
    "github.com/kataras/iris/v12/mvc"

    "lottery/models"
    "lottery/viewmodels"
)

// planItem 表示一条发奖计划：[Unix时间戳, 发放数量]
type planItem [2]int64

// Get 奖品列表页，附带发奖计划的可读化转换
func (c *AdminGiftController) Get() mvc.Result {
    dataList := c.GiftService.GetAll()

    for i := range dataList {
        dataList[i].PrizeData = formatPrizeData(dataList[i].PrizeData)
    }

    return mvc.View{
        Name: "admin/gift.html",
        Data: iris.Map{
            "Title":    "奖品管理",
            "Channel":  "gift",
            "GiftList": dataList,
            "GiftTotal": len(dataList),
        },
        Layout: "shared/layout.html",
    }
}

// formatPrizeData 把库中的时间戳数组转成「时间:数量」字符串数组的 JSON
func formatPrizeData(raw string) string {
    if raw == "" || len(raw) < 1 {
        return "[]"
    }
    var items []planItem
    if err := json.Unmarshal([]byte(raw), &items); err != nil {
        return "[]"
    }
    out := make([]string, 0, len(items))
    for _, it := range items {
        t := time.Unix(it[0], 0).Format(viewmodels.TimeLayout)
        out = append(out, t+": "+strconv.FormatInt(it[1], 10))
    }
    b, err := json.Marshal(out)
    if err != nil {
        return "[]"
    }
    return string(b)
}
```

## 编辑动作 GetEdit

通过 `URLParamIntDefault` 安全地读取 `id`（带默认值 0），有 `id` 则查库并转换为视图模型，无 `id` 则使用零值（新增场景）。

```go
// GetEdit 新增/编辑页
func (c *AdminGiftController) GetEdit() mvc.Result {
    id := c.Ctx.URLParamIntDefault("id", 0)

    giftInfo := viewmodels.ViewGift{}
    if id > 0 {
        gift := c.GiftService.Get(id)
        giftInfo = toViewGift(gift)
    }

    return mvc.View{
        Name: "admin/giftedit.html",
        Data: iris.Map{
            "Title":    "奖品编辑",
            "Channel":  "gift",
            "GiftInfo": giftInfo,
        },
        Layout: "shared/layout.html",
    }
}

// toViewGift 数据库模型 → 视图模型（时间戳转字符串）
func toViewGift(g models.LtGift) viewmodels.ViewGift {
    return viewmodels.ViewGift{
        Id:        g.Id,
        Title:     g.Title,
        PrizeNum:  g.PrizeNum,
        PrizeCode: g.PrizeCode,
        PrizeTime: g.PrizeTime,
        TimeBegin: viewmodels.FormatUnix(int64(g.TimeBegin)),
        TimeEnd:   viewmodels.FormatUnix(int64(g.TimeEnd)),
        PrizeData: g.PrizeData,
        SysStatus: g.SysStatus,
    }
}
```

## API 速览

| 方法 | 说明 |
| --- | --- |
| `URLParamIntDefault(key, def)` | 从 URL 读取 int 参数，失败或缺失时返回默认值，比直接解析更安全 |
| `GiftService.GetAll()` | 返回 `[]models.LtGift` 全量奖品 |
| `GiftService.Get(id)` | 按主键返回单条奖品 |
| `json.Unmarshal([]byte, &v)` | 将 JSON 字符串反序列化为 Go 切片/结构 |

## Demo 示例

运行说明：将本讲的 `ViewGift`、`Get()`、`GetEdit()` 与上讲骨架合并；为 `GiftService` 实现 `GetAll/Get`（从 XORM 查询 `lt_gift`）。启动后访问 `/admin/gift` 可见列表，弹窗中发奖计划已变为可读时间；访问 `/admin/gift/edit?id=1` 可见时间字段以字符串回填到表单。

代码说明：核心难点是「库存格式（int 时间戳）」与「展示格式（字符串）」的双向差异。`PrizeData` 在库中是 `[unixts,num]` 数组，列表展示前反序列化为可读串；编辑页通过 `ViewGift` 把 `TimeBegin/TimeEnd` 转为字符串供表单回填。

技术点总结：

- 数据格式转换统一放在 Go 代码，模板只负责展示，降低耦合与维护成本。
- 视图模型与数据库模型分离：`form` Tag 让 `ReadForm` 自动绑定，减少手写类型转换。
- 带默认值的参数读取是后台接口防错的常用手段。
