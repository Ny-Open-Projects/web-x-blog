# Go 企业级抽奖项目: 优惠券管理实现（上）

## 纲要

- 优惠券管理只有列表页（无编辑页），功能为导入、删除、恢复，核心差异在「批量导入」。
- 列表需分页：优惠券量级可达数万，每页取较大值（100 条）以平衡效率。
- `Get()` 取数逻辑：传入 `giftId` 则按奖品过滤，否则取全量；分页用 `offset=(page-1)*size`。
- 总数 `Total` 优化：当本页返回数不足一页时，可直接由页码算出，免一次 `count` 查询；否则再查库。
- 上一页/下一页：由当前页码推导，下一页=page+1，上一页=page-1（page>1 时）。

## 列表动作 Get

```go
package controllers

import (
    "github.com/kataras/iris/v12"
    "github.com/kataras/iris/v12/mvc"

    "lottery/services"
    "lottery/models"
)

// AdminCodeController 优惠券管理后台
type AdminCodeController struct {
    mvc.Controller
    CodeService services.CodeService
}

// Get 优惠券列表（带分页与礼品过滤）
func (c *AdminCodeController) Get() mvc.Result {
    giftId := c.Ctx.URLParamIntDefault("gift_id", 0)
    page := c.Ctx.URLParamIntDefault("page", 1)
    if page < 1 {
        page = 1
    }
    pageSize := 100

    var (
        dataList []models.LtCode
        total    int64
    )

    if giftId > 0 {
        dataList = c.CodeService.GetByGift(giftId, page, pageSize)
    } else {
        dataList = c.CodeService.GetAll(page, pageSize)
    }

    // 总数优化：本页不满一页则可直接推算，避免一次额外 count
    if len(dataList) < pageSize {
        if page == 1 {
            total = int64(len(dataList))
        } else {
            total = int64((page-1)*pageSize + len(dataList))
        }
    } else {
        if giftId > 0 {
            total = c.CodeService.CountByGift(giftId)
        } else {
            total = c.CodeService.CountAll()
        }
    }

    prevPage := 0
    if page > 1 {
        prevPage = page - 1
    }
    nextPage := page + 1

    return mvc.View{
        Name: "admin/code.html",
        Data: iris.Map{
            "Title":    "优惠券管理",
            "Channel":  "code",
            "GiftId":   giftId,
            "CodeList": dataList,
            "Total":    total,
            "Page":     page,
            "PrevPage": prevPage,
            "NextPage": nextPage,
        },
        Layout: "shared/layout.html",
    }
}
```

## 分页在 XORM 中的落地

分页本质是在 DAO 层拼 `Limit` 与 `Offset`：

```go
// dao/code_dao.go 节选
func (d *CodeDao) GetAll(page, size int) []models.LtCode {
    var list []models.LtCode
    offset := (page - 1) * size
    d.engine.OrderBy("id ASC").Limit(size, offset).Find(&list)
    return list
}

func (d *CodeDao) CountAll() int64 {
    var c int64
    d.engine.Table(&models.LtCode{}).Count(&c)
    return c
}
```

> `Limit(size, offset)` 中第一个参数为每页条数，第二个为偏移量，与「页码 → offset」换算一致。

## API 速览

| 方法 | 说明 |
| --- | --- |
| `URLParamIntDefault(key, def)` | 读取分页/过滤参数，缺失时回退默认值 |
| `CodeService.GetByGift(gid, page, size)` | 按奖品过滤并分页 |
| `CodeService.GetAll(page, size)` | 全量分页 |
| `CodeService.CountByGift/CountAll()` | 返回 `int64` 精确总数 |

代码说明：分页的关键是把「页码」换算成「offset」，并在总数计算上做「不满一页即推算」的优化，减少无效 `count` 查询。

技术点总结：

- 后台大数据量列表必须分页，且 pageSize 可按场景取较大值。
- 总数估算优先用「当前页是否满页」判断，避免每次都查库。
- 按业务维度（giftId）过滤时，DAO 需配套 `Where` + 专属 `count` 方法。
