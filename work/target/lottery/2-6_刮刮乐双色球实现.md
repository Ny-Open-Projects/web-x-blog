# Go 企业级抽奖项目: 刮刮乐与双色球实现

## 纲要

- 即开即得型：随机生成 0-9 尾号，按区间映射一/二/三等奖，其余为未中奖
- 双色球：随机生成 6 个红球的 1-33 与 1 个蓝球的 1-16
- 两类玩法的核心都是"随机数匹配"，与名单抽取型抽奖本质不同
- 无共享变量，不存在并发安全问题

## 即开即得型（刮刮乐）逻辑

刮刮乐的核心是一段"尾号→奖项"的映射规则。程序随机生成一个 0-9 的尾号 `code`，再按区间判断：

- `code == 1`：一等奖
- `code ∈ [2,3]`：二等奖
- `code ∈ [4,6]`：三等奖
- 其它：未中奖（返回规则说明与当前 `code`）

虽然现实中刮开的是多位号码，但决定中奖与否的只有最后一位，因此程序只需生成最后一位数字即可，匹配规则完全由尾号区间决定。

## 双色球逻辑

双色球的"开奖机器"才是程序真正要做的事（用户自选号码无需程序干预）。开奖号码由 6 个红球（1-33）加 1 个蓝球（1-16）组成：

- 红球循环 6 次：`r.Intn(33)+1`，得到 1-33 的整数；
- 蓝球：`r.Intn(16)+1`，得到 1-16 的整数。

用固定长度的数组 `[7]int` 即可，因为位数是固定的 7 位。

## Demo 示例

运行说明：

```bash
cd code/lottery/_demo/ticket
go run main.go
# 即开即得：  curl http://localhost:8080/
# 双色球开奖：curl http://localhost:8080/prize
```

代码说明（取自 `ticket/main.go`，按讲稿逻辑整理）：

```go
package main

import (
	"fmt"
	"math/rand"
	"time"

	"github.com/kataras/iris"
	"github.com/kataras/iris/mvc"
)

func newApp() *iris.Application {
	app := iris.New()
	mvc.New(app.Party("/")).Handle(&lotteryController{})
	return app
}

func main() {
	app := newApp()
	app.Run(iris.Addr(":8080"))
}

type lotteryController struct {
	Ctx iris.Context
}

// 即开即得 GET http://localhost:8080/
func (c *lotteryController) Get() string {
	c.Ctx.Header("Content-Type", "text/html")
	seed := time.Now().UnixNano()
	code := rand.New(rand.NewSource(seed)).Intn(10) // 仅取最后一位尾号
	var prize string
	switch {
	case code == 1:
		prize = "一等奖"
	case code >= 2 && code <= 3:
		prize = "二等奖"
	case code >= 4 && code <= 6:
		prize = "三等奖"
	default:
		return fmt.Sprintf("尾号为1获得一等奖<br/>"+
			"尾号为2或者3获得二等奖<br/>"+
			"尾号为4/5/6获得三等奖<br/>"+
			"code=%d<br/>很遗憾，没有获奖", code)
	}
	return fmt.Sprintf("尾号为1获得一等奖<br/>"+
		"尾号2或者3获得二等奖<br/>"+
		"尾号4/5/6获得三等奖<br/>"+
		"code=%d<br/>恭喜你获得:%s", code, prize)
}

// 定时开奖 GET http://localhost:8080/prize
func (c *lotteryController) GetPrize() string {
	c.Ctx.Header("Content-Type", "text/html")
	seed := time.Now().UnixNano()
	r := rand.New(rand.NewSource(seed))
	var prize [7]int
	for i := 0; i < 6; i++ {
		prize[i] = r.Intn(33) + 1 // 红球 1-33
	}
	prize[6] = r.Intn(16) + 1 // 蓝球 1-16
	return fmt.Sprintf("今日开奖号码是： %v", prize)
}
```

技术点总结：

- 刮刮乐看似规则繁琐，本质只是"末位尾号 + 区间匹配"，中奖概率由区间宽度决定。
- 双色球本质是"在指定范围内逐个随机出号"，与玩法复杂度无关。
- 两者都没有共享变量，所以**不存在并发安全问题**——可以无限次并发刮奖/开奖而不会产生脏数据。
