# Go 企业级抽奖项目: 微博红包之发红包实现

## 纲要

- 红包集合 `packageList` 用 `map[int][]int` 保存：键为随机正整数红包 ID，值为该红包内各小红包金额的切片（单位：分）。
- 首页接口汇总返回所有红包的"数量"与"总金额"，便于调试与查看。
- 发红包接口（GET `set`）接收参数：发红包用户 `uid`、金额 `money`（元，浮点）、个数 `num`。
- 金额统一转换为整数"分"存储（`money * 100`），并对参数合法性做校验（金额、个数下限）。
- 金额分配采用随机算法：设定随机上限系数 `rmax=0.55`，最后一个红包拿走全部余额，其余按"预留 + 随机"拆分，保证最小单位为 1 分。
- 生成唯一红包 ID 后写入 `packageList`，返回红包地址供抢红包使用。

## 全局红包集合与首页接口

所有红包集中保存在全局 `map` 中。首页接口遍历该 `map`，对每个红包的切片再求和，最终汇总出"红包个数"和"总金额"两个数据返回。

```go
package main

import "fmt"

// packageList 全局红包集合：key=红包ID，value=该红包内各小红包金额（分）
var packageList = make(map[int][]int)

// HomeResult 首页汇总返回
type HomeResult struct {
	Count int // 红包个数
	Money int // 总金额（分）
}

// Home 首页：汇总所有红包的数量与总金额
func Home() HomeResult {
	result := HomeResult{}
	for _, amounts := range packageList {
		result.Count++
		for _, m := range amounts {
			result.Money += m
		}
	}
	return result
}

func main() {
	fmt.Printf("当前红包：%+v\n", Home())
}
```

## 发红包接口与参数校验

发红包接口的参数很少，用 GET 即可。关键参数是 `uid`、`money`（浮点，单位元）、`num`（个数）。开发工作中很大一部分工作量都在参数解析与异常校验上。

- 浮点金额转为整数"分"：`moneyCent = int(money * 100)`。
- 校验：金额、个数不能为负或过小（例如发 5 个红包，总不能只有 5 分钱）；`uid` 格式异常时返回提示。

```go
import (
	"fmt"
	"math/rand"
	"time"
)

// SetPacket 发红包：返回红包 ID；参数非法时返回错误
func SetPacket(uid int, money float64, num int) (int, error) {
	if uid <= 0 {
		return 0, fmt.Errorf("用户参数异常")
	}
	moneyCent := int(money * 100) // 元转分，精确到分
	if moneyCent < num {
		return 0, fmt.Errorf("金额不足以平分给 %d 个红包", num)
	}
	if num <= 0 {
		return 0, fmt.Errorf("红包个数不合法")
	}
	amounts, err := allocMoney(moneyCent, num)
	if err != nil {
		return 0, err
	}
	id := genID()
	packageList[id] = amounts
	return id, nil
}
```

## 金额随机分配算法

分配采用"随机上限 + 预留"的思路，而不是简单平均：

- 定义随机上限系数 `rmax = 0.55`，即单个红包最多拿走剩余金额的 55%，避免极端不均衡。
- 循环分配：若只剩最后一个红包，则直接拿走全部剩余金额；否则在"为后面红包预留若干分"之后，对剩余部分乘以随机数得出本次金额，再转回整数并保底为 1 分。
- 当剩余金额过小（如 5 人分 5 分），直接每人 1 分，不再随机。

```go
const rmax = 0.55

// allocMoney 把 total 分随机分配给 num 个红包，返回金额切片
func allocMoney(total, num int) ([]int, error) {
	if total < num {
		return nil, fmt.Errorf("余额不足")
	}
	r := rand.New(rand.NewSource(time.Now().UnixNano()))
	amounts := make([]int, 0, num)
	leftNum := num
	leftMoney := total
	for leftNum > 0 {
		if leftNum == 1 { // 最后一个红包拿走全部余额
			amounts = append(amounts, leftMoney)
			break
		}
		// 余额过小直接平分（最小单位 1 分）
		if leftMoney <= leftNum {
			amounts = append(amounts, 1)
			leftMoney -= 1
			leftNum--
			continue
		}
		// 预留后面红包每人 1 分，剩余部分按 rmax 随机
		reserved := leftNum - 1
		randMoney := int(float64(leftMoney-reserved) * rmax * r.Float64())
		if randMoney < 1 {
			randMoney = 1
		}
		amounts = append(amounts, randMoney)
		leftMoney -= randMoney
		leftNum--
	}
	return amounts, nil
}

// genID 生成随机正整数红包 ID（简化示例）
func genID() int {
	return rand.Intn(1<<31-1) + 1
}
```

## 接口联调说明

发红包完成后返回红包地址，例如 `localhost:8080/set?uid=1&money=100&num=100`，表示用户 1 发了 100 元、100 个红包。返回中携带红包 ID，抢红包时凭该 ID 领取。出于隐蔽性考虑，接口不回显发放者、金额、个数等明细。

## API 速览

- `Home() HomeResult`：汇总所有红包数量与总金额。
- `SetPacket(uid int, money float64, num int) (int, error)`：发红包，金额按"分"存储，返回红包 ID。
- `allocMoney(total, num int) ([]int, error)`：随机分配金额，最后一个红包拿全部余额，其余按 `rmax` 上限随机，最小 1 分。
- 发红包接口（GET `set`）：参数 `uid`、`money`、`num`。

## Demo 示例

运行说明：将首页与发红包相关函数合并为 `main` 包，`go run` 后调用 `SetPacket(1, 100, 100)` 即可生成红包并写入 `packageList`，再用 `Home()` 查看汇总。

代码说明：金额统一以"分"的整数存储避免浮点误差；`allocMoney` 演示了"预留保底 + 随机上限"的分配策略，保证每个红包至少 1 分且最后一个红包兜底。

技术点总结：发红包的本质是"参数校验 + 金额随机拆分 + 写入全局集合"，其中金额转整数分、随机分配算法、最小单位保底是最容易出错的地方，需重点测试。
