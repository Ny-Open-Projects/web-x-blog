# Go 企业级抽奖项目: 中奖记录管理

## 纲要

- 中奖记录只有列表页，数据来自抽奖接口生成，后台不提供新增，仅做查询、删除、恢复、标记作弊。
- 列表支持按 `giftId`（奖品）与 `uid`（用户）两类维度过滤，配套 `searchByGift` / `searchByUser`。
- 分页与总数优化同优惠券：本页不满一页则推算总数，否则按过滤维度查 `countByXxx`。
- 状态语义：`0` 正常、`1` 已删除、`2` 作弊；标记作弊即 `Update(status=2)`，恢复即 `status=0`。
- DAO 过滤用 XORM 的 `Where` 拼条件，`Find` + `Limit` 实现分页，`Count` 实现统计。

## 列表动作 Get

```go
package controllers

import (
    "github.com/kataras/iris/v12"
    "github.com/kataras/iris/v12/mvc"

    "lottery/services"
    "lottery/models"
)

// AdminResultController 中奖记录管理后台
type AdminResultController struct {
    mvc.Controller
    ResultService services.ResultService
}

// Get 中奖记录列表（按奖品/用户过滤 + 分页）
func (c *AdminResultController) Get() mvc.Result {
    giftId := c.Ctx.URLParamIntDefault("gift_id", 0)
    uid := c.Ctx.URLParamInt64Default("uid", 0)
    page := c.Ctx.URLParamIntDefault("page", 1)
    if page < 1 {
        page = 1
    }
    pageSize := 100

    var (
        dataList []models.LtResult
        total    int64
    )

    switch {
    case giftId > 0:
        dataList = c.ResultService.SearchByGift(giftId, page, pageSize)
    case uid > 0:
        dataList = c.ResultService.SearchByUser(int(uid), page, pageSize)
    default:
        dataList = c.ResultService.GetAll(page, pageSize)
    }

    // 总数优化：本页不满一页则推算
    if len(dataList) < pageSize {
        if page == 1 {
            total = int64(len(dataList))
        } else {
            total = int64((page-1)*pageSize + len(dataList))
        }
    } else {
        switch {
        case giftId > 0:
            total = c.ResultService.CountByGift(giftId)
        case uid > 0:
            total = c.ResultService.CountByUser(int(uid))
        default:
            total = c.ResultService.CountAll()
        }
    }

    return mvc.View{
        Name: "admin/result.html",
        Data: iris.Map{
            "Title":     "中奖记录管理",
            "Channel":   "result",
            "ResultList": dataList,
            "Total":     total,
            "Page":      page,
            "GiftId":    giftId,
            "Uid":       uid,
        },
        Layout: "shared/layout.html",
    }
}
```

## DAO 过滤与统计

```go
// dao/result_dao.go 节选
func (d *ResultDao) SearchByGift(giftId, page, size int) []models.LtResult {
    var list []models.LtResult
    offset := (page - 1) * size
    d.engine.Where("gift_id = ?", giftId).
        OrderBy("id DESC").Limit(size, offset).Find(&list)
    return list
}

func (d *ResultDao) SearchByUser(uid, page, size int) []models.LtResult {
    var list []models.LtResult
    offset := (page - 1) * size
    d.engine.Where("uid = ?", uid).
        OrderBy("id DESC").Limit(size, offset).Find(&list)
    return list
}

func (d *ResultDao) CountByGift(giftId int) int64 {
    var c int64
    d.engine.Where("gift_id = ?", giftId).Count(&models.LtResult{})
    return c
}
```

## 删除、恢复与标记为作弊

```go
// GetDelete 删除（状态置 1）
func (c *AdminResultController) GetDelete() mvc.Result {
    id, _ := c.Ctx.URLParamInt("id")
    if id > 0 {
        c.ResultService.Update(&models.LtResult{Id: id, SysStatus: 1}, "sys_status")
    }
    return mvc.Response{Path: "/admin/result"}
}

// GetReset 恢复（状态置 0）
func (c *AdminResultController) GetReset() mvc.Result {
    id, _ := c.Ctx.URLParamInt("id")
    if id > 0 {
        c.ResultService.Update(&models.LtResult{Id: id, SysStatus: 0}, "sys_status")
    }
    return mvc.Response{Path: "/admin/result"}
}

// GetCheat 标记为作弊（状态置 2）
func (c *AdminResultController) GetCheat() mvc.Result {
    id, _ := c.Ctx.URLParamInt("id")
    if id > 0 {
        c.ResultService.Update(&models.LtResult{Id: id, SysStatus: 2}, "sys_status")
    }
    return mvc.Response{Path: "/admin/result"}
}
```

## API 速览

| 方法 | 说明 |
| --- | --- |
| `ResultService.SearchByGift(gid, page, size)` | 按奖品过滤并分页 |
| `ResultService.SearchByUser(uid, page, size)` | 按用户过滤并分页 |
| `engine.Where("col = ?", v)` | XORM 条件构造，支持多维度过滤 |
| `ResultService.CountByXxx(...)` | 返回 `int64` 精确计数 |

## Demo 示例

运行说明：将本讲 `AdminResultController` 与 `result_dao.go` 合并，路由挂到 `admin.Party("/result")`。访问 `/admin/result?gift_id=4` 查看某奖品全部中奖记录；`/admin/result?uid=1001` 查看某用户记录；对记录执行删除/恢复/作弊操作验证状态变化。

代码说明：中奖记录复用「列表 + 分页 + 过滤」骨架，差异点是新增 `uid`/`giftId` 双过滤维度与 `status=2` 作弊语义。DAO 用 `Where` + `Limit` 实现过滤分页。

技术点总结：

- 多维度过滤在 DAO 层表现为不同 `Where` 条件，Service 层按需暴露 `SearchByXxx`。
- 状态机思维：同一张表用 `sys_status` 区分正常/删除/作弊，避免物理删除。
- 总数优化策略在多个后台模块间高度复用，是通用最佳实践。
