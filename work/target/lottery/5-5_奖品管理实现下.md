# Go 企业级抽奖项目: 奖品管理实现（下）

## 纲要

- 保存动作 `PostSave()`：用 `ReadForm` 把表单绑定到 `ViewGift`，再转回 `models.LtGift`（字符串时间 → 时间戳）。
- 新增与更新分支：`Id>0` 走 `Update`（指定 `Cols`），否则走 `Insert` 并补 `SysCreated`、`SysIp`、`LeftNum` 初始值。
- 剩余数量联动：奖品总数 `PrizeNum` 变化时，按差值同步调整 `LeftNum`，并保证不为负。
- 删除/恢复是一对反向动作：仅把 `SysStatus` 置 1 或置 0，均用 `Cols("sys_status")` 定点更新。
- 预留两处 TODO：奖品数量变化需同步缓存；发放周期变化需重建发奖计划（后续 Redis 优化章节完善）。

## 保存动作 PostSave

```go
package controllers

import (
    "time"

    "github.com/kataras/iris/v12/mvc"

    "lottery/models"
    "lottery/viewmodels"
)

// PostSave 新增或更新奖品
func (c *AdminGiftController) PostSave() mvc.Result {
    giftInfo := viewmodels.ViewGift{}
    if err := c.Ctx.ReadForm(&giftInfo); err != nil {
        c.Ctx.Application().Logger().Errorf("ReadForm error: %v", err)
        return mvc.Response{Text: "表单转换异常：" + err.Error()}
    }

    // 视图模型 → 数据库模型（字符串时间转回时间戳）
    gift := toModelGift(giftInfo)
    if err := parseTimeFields(&gift, giftInfo); err != nil {
        return mvc.Response{Text: "开始/结束时间格式不正确：" + err.Error()}
    }

    if gift.Id > 0 {
        // 更新：取出旧数据，校正剩余数量后再写回
        old := c.GiftService.Get(gift.Id)
        if old != nil && old.PrizeNum != gift.PrizeNum {
            gift.LeftNum = old.LeftNum - (old.PrizeNum - gift.PrizeNum)
            if gift.LeftNum < 0 || gift.PrizeNum <= 0 {
                gift.LeftNum = 0
            }
        }
        gift.SysUpdated = int(time.Now().Unix())
        c.GiftService.Update(gift,
            "title", "prize_num", "prize_code", "prize_time",
            "time_begin", "time_end", "prize_data", "left_num", "sys_updated")
    } else {
        // 新增：初始化创建信息与剩余数量
        now := int(time.Now().Unix())
        gift.SysCreated = now
        gift.SysUpdated = now
        gift.SysIp = clientIP(c.Ctx)
        gift.LeftNum = gift.PrizeNum
        c.GiftService.Create(&gift)
    }

    // TODO: 奖品数量变化后需同步更新 Redis 缓存（见第7章）
    // TODO: 发放周期变化后需重建 prize_data 发奖计划（见第8章）
    return mvc.Response{Path: "/admin/gift"}
}

// toModelGift 视图模型转数据库模型
func toModelGift(v viewmodels.ViewGift) models.LtGift {
    return models.LtGift{
        Id:        v.Id,
        Title:     v.Title,
        PrizeNum:  v.PrizeNum,
        PrizeCode: v.PrizeCode,
        PrizeTime: v.PrizeTime,
        PrizeData: v.PrizeData,
        SysStatus: v.SysStatus,
    }
}

// parseTimeFields 把字符串时间回填为 int 时间戳
func parseTimeFields(g *models.LtGift, v viewmodels.ViewGift) error {
    tb, err := time.Parse(viewmodels.TimeLayout, v.TimeBegin)
    if err != nil {
        return err
    }
    te, err := time.Parse(viewmodels.TimeLayout, v.TimeEnd)
    if err != nil {
        return err
    }
    g.TimeBegin = int(tb.Unix())
    g.TimeEnd = int(te.Unix())
    return nil
}

// clientIP 取客户端 IP
func clientIP(c *AdminGiftController) string {
    return c.Ctx.Request().RemoteAddr
}
```

## 删除与恢复

两者仅更新 `SysStatus` 字段，删除置 1、恢复置 0，使用 `Cols` 保证只动状态列。

```go
// GetDelete 删除（状态置 1）
func (c *AdminGiftController) GetDelete() mvc.Result {
    id, err := c.Ctx.URLParamInt("id")
    if err != nil || id <= 0 {
        return mvc.Response{Path: "/admin/gift"}
    }
    c.GiftService.Delete(id) // 内部等价于 Update(status=1)
    return mvc.Response{Path: "/admin/gift"}
}

// GetReset 恢复（状态置 0）
func (c *AdminGiftController) GetReset() mvc.Result {
    id, err := c.Ctx.URLParamInt("id")
    if err != nil || id <= 0 {
        return mvc.Response{Path: "/admin/gift"}
    }
    c.GiftService.Update(&models.LtGift{Id: id, SysStatus: 0}, "sys_status")
    return mvc.Response{Path: "/admin/gift"}
}
```

## API 速览

| 方法 | 说明 |
| --- | --- |
| `Ctx.ReadForm(&struct)` | 按 `form` Tag 把表单字段自动填充进结构体，省去逐项解析 |
| `GiftService.Update(m, cols...)` | 按指定列更新，避免整行覆盖 |
| `GiftService.Create(&m)` | 插入新记录 |
| `time.Parse(layout, s)` | 把格式化字符串解析回 `time.Time`，再取 `.Unix()` 得时间戳 |

## Demo 示例

运行说明：将本讲 `PostSave/GetDelete/GetReset` 合并进 `AdminGiftController`，并为 `GiftService` 提供 `Get/Update/Create/Delete`。启动后进入 `/admin/gift/edit`，修改标题与数量并保存，可见列表与剩余数量同步变化；对记录执行删除/恢复，状态列随之翻转。

代码说明：保存的核心是「表单 → 视图模型 → 数据库模型」的二次转换；剩余数量联动保证库存一致性——总数减少 N，剩余也减少 N，且下限为 0。删除/恢复通过定点更新 `sys_status` 实现软删除。

技术点总结：

- `ReadForm` + `form` Tag 让表单绑定几乎零成本，但双向时间格式仍需手动转换。
- 更新时务必用 `Cols` 限定列，防止未赋值字段被清零。
- 业务上的「数量变化」「周期变化」需要联动处理，且为后续缓存/计划优化预留扩展点。
