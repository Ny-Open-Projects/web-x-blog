# Go 企业级抽奖项目: 项目配置和通用方法

## 纲要

- 项目级配置：`conf/project.go` 统一定义时间格式、中国时区、签名密钥、Cookie 密钥，以及抽奖次数上限、奖品类型常量与按小时分布的奖品权重。
- 通用方法：`comm` 包沉淀与时间、随机、加解密、转义、类型转换相关的高频工具函数，业务层直接复用，避免重复造轮子。
- 安全相关：对称加密（`encrypt`/`decrypt`）、签名（`CreateSign`）、Cookie 防篡改密钥均集中配置。
- 类型安全：提供从 `interface{}`、各类 `map` 中安全取值的封装，屏蔽类型断言的繁琐与风险。

## 项目配置 project.go

时间格式与密钥是贯穿全项目的基础配置。Go 的时间格式采用“参考时间”写法而非传统的 `%Y-%m-%d`，这是 Go 的一大特色：

```go
package conf

import "time"

const UserPrizeMax = 3000            // 用户每天最多抽奖次数
const IpPrizeMax = 30000             // 同一个 IP 每天最多抽奖次数
const IpLimitMax = 300000            // 黑名单判定用的 IP 上限

const SysTimeform = "2006-01-02 15:04:05"     // 长格式：年月日 时分秒
const SysTimeformShort = "2006-01-02"         // 短格式：仅年月日

// 是否需要启动全局计划任务服务
var RunningCrontabService = false

// 中国时区
var SysTimeLocation, _ = time.LoadLocation("Asia/Chongqing")

// ObjSalesign 签名密钥
var SignSecret = []byte("0123456789abcdef")

// cookie 中的加密验证密钥
var CookieSecret = "hellolottery"
```

此外，`project.go` 还定义了奖品类型常量（`GtypeVirtual` / `GtypeCodeSame` / `GtypeCodeDiff` / `GtypeGiftSmall` / `GtypeGiftLarge`）以及一份按小时分布的奖品权重数组 `PrizeDataRandomDayTime`，用于后续在不同时间段控制中奖概率。

## 通用方法 functions.go

`comm` 包把项目中反复出现、但又琐碎的工具逻辑做了统一封装：

```go
// 当前时间的时间戳（按中国时区）
func NowUnix() int {
	return int(time.Now().In(conf.SysTimeLocation).Unix())
}

// 将 unix 时间戳格式化为 长/短 字符串
func FormatFromUnixTime(t int64) string {
	if t > 0 {
		return time.Unix(t, 0).Format(conf.SysTimeform)
	}
	return time.Now().Format(conf.SysTimeform)
}
func FormatFromUnixTimeShort(t int64) string {
	if t > 0 {
		return time.Unix(t, 0).Format(conf.SysTimeformShort)
	}
	return time.Now().Format(conf.SysTimeformShort)
}

// 得到一个 [0, max) 的随机数
func Random(max int) int {
	r := rand.New(rand.NewSource(time.Now().UnixNano()))
	if max < 1 {
		return r.Int()
	}
	return r.Intn(max)
}
```

### 签名与加解密

签名用于校验数据完整性（例如登录 Cookie 防篡改），加解密用于敏感字段的对称加密：

```go
// 对字符串进行签名（前缀拼接密钥后做 MD5）
func CreateSign(str string) string {
	str = string(conf.SignSecret) + str
	sign := fmt.Sprintf("%x", md5.Sum([]byte(str)))
	return sign
}

// 对字符串进行 AES 加密
func encrypt(key, text []byte) ([]byte, error) {
	block, err := aes.NewCipher(key)
	if err != nil {
		return nil, err
	}
	b := base64.StdEncoding.EncodeToString(text)
	ciphertext := make([]byte, aes.BlockSize+len(b))
	iv := ciphertext[:aes.BlockSize]
	cfb := cipher.NewCFBEncrypter(block, iv)
	cfb.XORKeyStream(ciphertext[aes.BlockSize:], []byte(b))
	return ciphertext, nil
}

// 对字符串进行 AES 解密
func decrypt(key, text []byte) ([]byte, error) {
	block, _ := aes.NewCipher(key)
	if len(text) < aes.BlockSize {
		return nil, errors.New("ciphertext too short")
	}
	iv := text[:aes.BlockSize]
	text = text[aes.BlockSize:]
	cfb := cipher.NewCFBDecrypter(block, iv)
	cfb.XORKeyStream(text, text)
	return base64.StdEncoding.DecodeString(string(text))
}
```

```go
// 将 IPv4 字符串转为 int64，节省数据库存储空间
func Ip4toInt(ip string) int64 {
	bits := strings.Split(ip, ".")
	if len(bits) == 4 {
		b0, _ := strconv.Atoi(bits[0])
		b1, _ := strconv.Atoi(bits[1])
		b2, _ := strconv.Atoi(bits[2])
		b3, _ := strconv.Atoi(bits[3])
		var sum int64
		sum += int64(b0) << 24
		sum += int64(b1) << 16
		sum += int64(b2) << 8
		sum += int64(b3)
		return sum
	}
	return 0
}

// 得到当前时间到下一天零点的延时（用于定时任务）
func NextDayDuration() time.Duration {
	year, month, day := time.Now().Add(time.Hour * 24).Date()
	next := time.Date(year, month, day, 0, 0, 0, 0, conf.SysTimeLocation)
	return next.Sub(time.Now())
}
```

### 安全的类型转换

很多场景（如读取数据库 `map[string]interface{}` 结果）拿到的都是 `interface{}`，直接断言既繁琐又易 panic。项目把转换封装成 `GetInt64`、`GetString` 以及在 `map` 上取值的 `GetInt64FromMap`、`GetStringFromMap` 等：

```go
// 从 interface{} 安全获取 int64
func GetInt64(i interface{}, d int64) int64 {
	if i == nil {
		return d
	}
	switch v := i.(type) {
	case string:
		num, err := strconv.Atoi(v)
		if err != nil {
			return d
		}
		return int64(num)
	case int:
		return int64(v)
	case int64:
		return v
	case float64:
		return int64(v)
	// ... uint / []byte 等其他类型
	default:
		return d
	}
}

// 从 map[string]interface{} 安全获取某个 key 的 int64
func GetInt64FromMap(dm map[string]interface{}, key string, dft int64) int64 {
	data, ok := dm[key]
	if !ok {
		return dft
	}
	return GetInt64(data, dft)
}
```

这样业务代码一行即可拿到带默认值的强类型结果，且转换失败时安全返回默认值。

## Demo 示例

运行说明：示例演示时间格式与签名的使用，无需外部依赖。

```go
package main

import (
	"fmt"
	"imooc.com/lottery/comm"
	"imooc.com/lottery/conf"
)

func main() {
	// 时间格式
	now := comm.NowUnix()
	fmt.Println(comm.FormatFromUnixTime(int64(now)))
	fmt.Println(comm.FormatFromUnixTimeShort(int64(now)))

	// 签名：规则为 密钥 + 原文 后做 MD5
	sign := comm.CreateSign("uid=1&username=admin")
	fmt.Println("sign =", sign)
	fmt.Println("secret =", string(conf.SignSecret))
}
```

代码说明：展示 `comm` 中时间格式化与 `CreateSign` 签名的调用方式，签名不可逆向，是后续 Cookie 防篡改的基础。

技术点总结：把高频、易错、跨模块通用的逻辑下沉到 `conf` 与 `comm`，既保证术语与行为一致，又让控制器、服务层专注业务；对称加密、签名、密钥全部集中配置，便于安全策略统一演进。
