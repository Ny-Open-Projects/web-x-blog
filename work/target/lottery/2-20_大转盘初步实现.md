# Go 企业级抽奖项目: 抽奖大转盘初步实现

## 纲要

- 大转盘把奖品信息拆成两块：`giftList`（奖品名称列表）与 `rateList`（对应中奖概率），并据此生成中奖区间。
- 辅助接口一（首页）：以文本/HTML 返回奖品列表，便于查看。`giftList`
- 辅助接口二（调试）：返回概率列表 `rateList` 及区间，便于核对。
- 核心抽奖接口：生成一万以内的随机抽奖码，遍历奖品列表匹配中奖区间；区间采用"起始含、结束不含"的闭开区间判定。
- 发奖逻辑简化：奖品总数 `total=0` 表示无限量直接成功；`left>0` 有剩余则减一成功；否则未中奖。
- 初步实现尚未做并发安全改造，库存扣减存在线程安全隐患，留待下一篇用锁或原子操作处理。

## 奖品建模与区间生成

大转盘省略了"奖品类型"字段，只关心名称、概率与数量。初始化阶段就把概率区间算好。

```go
package main

import (
	"fmt"
	"math/rand"
	"time"
)

// Gift 奖品（简化：无类型字段，只关心名称、概率、数量）
type Gift struct {
	Name  string
	Rate  int // 中奖概率（权重）
	Total int // 总数，0 表示无限量
	Left  int // 剩余数量
	Min   int // 中奖区间下界（含）
	Max   int // 中奖区间上界（不含）
}

// giftList 奖品名称列表
var giftList = []string{"一等奖", "二等奖", "三等奖"}

// rateList 对应中奖概率（权重）
var rateList = []int{1, 5, 10}

// BuildGifts 依据名称与概率生成奖品及中奖区间
func BuildGifts(names []string, rates []int) []Gift {
	gifts := make([]Gift, 0, len(names))
	min := 0
	for i, name := range names {
		max := min + rates[i]
		gifts = append(gifts, Gift{
			Name: name,
			Rate: rates[i],
			Min:  min,
			Max:  max,
		})
		min = max
	}
	return gifts
}
```

## 抽奖接口

抽奖的本质与前面活动一致：生成一个随机抽奖码，再按区间匹配命中哪个奖品。

```go
// Draw 大转盘抽奖：返回中奖奖品，nil 表示未中奖
func Draw(gifts []Gift) *Gift {
	code := rand.New(rand.NewSource(time.Now().UnixNano())).Intn(10000)
	for i := range gifts {
		g := &gifts[i]
		// 闭开区间：[Min, Max)
		if code >= g.Min && code < g.Max {
			return award(g)
		}
	}
	return nil
}

// award 发奖：无限量直接成功；有限量且有剩余则扣减
func award(g *Gift) *Gift {
	if g.Total == 0 { // 无限量
		return g
	}
	if g.Left > 0 { // 有限量且有剩余
		g.Left--
		return g
	}
	return nil // 已抢光，未中奖
}
```

发奖分支：奖品总数 `total=0` → 无限量，直接成功；剩余 `left>0` → 扣减一后成功；其余情况视为未中奖。相比于微信摇一摇"按奖品类型分别发奖"，这里因省略类型字段而更简洁。

示例请求：

- 调试接口 `host:8080/rate` 查看 `rateList` 与中奖区间；
- 抽奖接口 `host:8080/lucky` 触发抽奖。

## 运行验证

启动后首页可见三个奖品；调试接口返回各自概率与区间。初始概率设置较低时，抽奖多半返回"很遗憾，再来一次"。这与预期一致——低概率下中奖难度高，后续会把概率调高并做压测。

## API 速览

- `BuildGifts(names []string, rates []int) []Gift`：生成奖品及中奖区间。
- `Draw(gifts []Gift) *Gift`：生成万内随机码并匹配区间，返回中奖奖品或 nil。
- `award(g *Gift) *Gift`：无限量/有剩余则发奖，抢光返回 nil。
- 首页接口（GET `/`）、调试接口（GET `/rate`）、抽奖接口（GET `/lucky`）。
