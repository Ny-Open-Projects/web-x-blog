# Go 企业级抽奖项目: 微信摇一摇服务端实现（上）

## 纲要

- 定义奖品类型枚举 `GiftType` 与奖品结构体 `Gift`（含库存、概率、中奖区间）
- 初始化 `giftList`，并整理累计中奖区间 `RateMin`/`RateMax` 提升抽奖效率
- 基于 Iris 暴露首页统计与 `/lucky` 抽奖接口
- 抽奖逻辑：为每次请求生成随机码，与各奖品区间比较命中

## 数据模型设计

摇一摇的奖品种类繁多，需要先抽象出统一的模型。用 `iota` 定义奖品类型枚举，再用一个 `Gift` 结构体描述单个奖品：

- 基础字段：`Id` 唯一标识、`Name` 名称、`Pic` 图片、`Link` 链接、`Type` 类型。
- 数据字段：`Data` 存固定值（如虚拟币数量、固定券编码）；`DataList` 存动态集合（如 50 张券的编码切片）。
- 库存字段：`Total` 总数（0 表示不限量）、`Left` 剩余数量、`Useful` 是否启用。
- 概率字段：`Rate` 中奖概率（以"万分之 N"表示），以及由它推导出的累计区间 `RateMin`/`RateMax`。

## 初始化与区间整理

`initGift` 预先构建奖品列表（真实项目应由后台维护，这里先硬编码演示）。随后遍历 `giftList`，按 `Rate` 累加出每个奖品的 `[RateMin, RateMax)` 区间。这样在抽奖时只需一次随机码落在区间内即可命中，无需每次重新计算，显著提升效率。

代码说明：

```go
package main

import (
	"fmt"
	"math/rand"
	"sync"
	"time"

	"github.com/kataras/iris"
	"github.com/kataras/iris/mvc"
)

// 奖品类型枚举
const (
	giftTypeCoin      = iota // 虚拟币
	giftTypeCouponFix        // 固定虚拟券（同一编码）
	giftTypeCouponDiff       // 动态虚拟券（每个用户不同编码）
	giftTypeRealSmall        // 实物小奖
	giftTypeRealLarge        // 实物大奖
)

// Gift 奖品对象
type Gift struct {
	Id       int       // 奖品唯一标识
	Name     string    // 奖品名称
	Pic      string    // 图片
	Link     string    // 链接
	Type     int       // 奖品类型
	Data     string    // 固定数据（如券编码、币数量）
	DataList []string  // 动态数据集合（如多张券编码）
	Total    int       // 总数，0 表示不限量
	Left     int       // 剩余数量
	Useful   bool      // 是否启用
	Rate     int       // 中奖概率（万分之 N）
	RateMin  int       // 中奖区间起始
	RateMax  int       // 中奖区间结束
}

var (
	giftList []Gift
	mu       sync.Mutex
)

func newApp() *iris.Application {
	app := iris.New()
	mvc.New(app.Party("/")).Handle(&lotteryController{})
	return app
}

func main() {
	app := newApp()
	initGift()
	app.Run(iris.Addr(":8080"))
}

// 初始化奖品并整理累计中奖区间
func initGift() {
	giftList = make([]Gift, 0)
	giftList = append(giftList, Gift{Id: 1, Name: "手机大奖", Type: giftTypeRealLarge, Total: 2, Left: 2, Useful: true, Rate: 1})
	giftList = append(giftList, Gift{Id: 2, Name: "实物小奖", Type: giftTypeRealSmall, Total: 5, Left: 5, Useful: true, Rate: 10})
	giftList = append(giftList, Gift{Id: 3, Name: "满200减50券", Type: giftTypeCouponFix, Data: "CODE-FIX-001", Total: 50, Left: 50, Useful: true, Rate: 5000})
	giftList = append(giftList, Gift{Id: 4, Name: "直降50券", Type: giftTypeCouponDiff, DataList: []string{"C01", "C02", "C03", "C04", "C05"}, Total: 5, Left: 5, Useful: true, Rate: 2000})
	giftList = append(giftList, Gift{Id: 5, Name: "金币", Type: giftTypeCoin, Data: "10", Total: 0, Left: 0, Useful: true, Rate: 10000})

	rateStart := 0
	for i := range giftList {
		g := &giftList[i]
		if !g.Useful {
			continue
		}
		g.RateMin = rateStart
		rateStart += g.Rate
		g.RateMax = rateStart
	}
}

type lotteryController struct {
	Ctx iris.Context
}

// GET / 返回有效奖品与限量库存统计
func (c *lotteryController) Get() string {
	countUseful := 0
	totalLeft := 0
	for _, g := range giftList {
		if g.Useful && (g.Total == 0 || g.Left > 0) {
			countUseful++
			totalLeft += g.Left
		}
	}
	return fmt.Sprintf("当前有效奖品种类: %d，限量奖品总数量: %d\n", countUseful, totalLeft)
}
```

技术点总结：

- 用 `iota` 枚举奖品类型，便于 `switch` 分发不同发奖逻辑。
- `[RateMin, RateMax)` 累计区间把"多奖品概率匹配"从 O(N) 比较降为一次落点判断。
- 概率以"万分之 N"为单位，`RateMax` 的最大值即为概率空间总量（本例 10000 即 100%）。
- 真实项目中 `giftList` 应来自管理后台，这里为演示先硬编码。
