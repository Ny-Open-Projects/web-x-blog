# Go 企业级抽奖项目: 数据模型的生成

## 纲要

- 使用 XORM 自带的 `xorm` 命令行工具，依据已建立的数据表批量生成 Go 数据模型
- 数据库连接串格式：`user:password@tcp(host:port)/dbname?charset=utf8`
- 生成命令：`xorm reverse mysql "<连接串>" template/go xorm`
- 生成的模型文件按表一一对应，拷贝进项目的 `models` 目录即可
- 需要先启动本地 MySQL，并进入 XORM 工具源码目录（模板文件随工具提供）

## 为什么用代码生成

数据库表已经在设计阶段建好，如果手写每张表对应的结构体，既繁琐又容易与表结构不一致。XORM 自带一个 `xorm` 命令行工具，可以根据数据表定义反向生成 Go 数据模型代码，让 `models` 与数据库保持严格一致。

## 数据库连接串格式

`xorm reverse` 需要一段符合 XORM 约定的 MySQL 连接串，其格式为：

```text
root:password@tcp(127.0.0.1:3306)/lottery?charset=utf8
```

- 第一段 `root:password` 是用户名与密码；
- `@tcp(...)` 指定协议为 TCP，括号内是数据库实例的 IP 与端口；
- 斜杠后是数据库名称 `lottery`；
- 末尾 `?charset=utf8` 是连接参数，表示字符集使用 UTF-8。

## 生成步骤

执行生成前，先进入 XORM 命令行工具的源码目录（工具依赖自带的 Go 模板文件）。随后执行：

```bash
# 1. 启动本地 MySQL
mysql.server start

# 2. 进入 xorm 命令行工具目录（GOPATH 下的 github.com/xormplus/xorm 等）
# 3. 执行反向生成，输出到当前目录的 models 子目录
xorm reverse mysql "root:password@tcp(127.0.0.1:3306)/lottery?charset=utf8" template/go xorm
```

参数含义：

- `reverse`：根据数据表定义反向生成代码文件；
- `mysql`：数据源类型；
- 双引号内是上面构造好的数据库连接串；
- `template/go xorm`：使用 Go 语言的 XORM 模板生成文件（XORM 也支持生成其他语言模板）。

执行完成后，会在当前目录的 `models` 下生成若干个文件——每个数据表对应一个文件。本项目中已经设计了六张表，因此会生成六个模型文件。

## 收尾

把生成出来的模型文件拷贝到项目的 `models` 目录即可直接使用。整个生成过程非常快，后续只要数据表结构有调整，重新执行一次生成命令并覆盖即可。
