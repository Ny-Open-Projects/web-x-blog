# Go 企业级抽奖项目: 年会抽奖基本功能实现

## 纲要

- 用 Iris + MVC 搭建 Web 应用，暴露根路径首页、`/import`、`/lucky` 三个接口
- `/import`（POST）以逗号分隔导入用户名单，追加到全局切片 `userList`
- `/lucky`（GET）基于时间戳生成随机索引，从名单中抽走一名用户
- 通过 curl 验证导入与抽奖效果，单用户场景下功能完整

## 项目与控制器搭建

年会抽奖程序基于 Iris 框架实现。核心是一个 MVC 模式的 `lotteryController`，其内部持有 Iris 自动注入的上下文 `Ctx`，以及一个全局的用户列表切片 `userList`。`newApp` 负责创建 Iris 应用并把控制器挂载到根路径。

## 三个接口的实现

- **首页 `GET /`**：返回当前参与抽奖的用户总数，便于直观掌握剩余概率。
- **导入 `POST /import`**：从表单参数 `users` 读取以逗号分隔的姓名，逐个 `TrimSpace` 后过滤空串，再 `append` 进 `userList`，并返回导入前后的人数差值。
- **抽奖 `GET /lucky`**：当人数大于 1 时，用当前时间戳作随机种子生成 `[0, count)` 区间内的随机索引，取出该用户并从切片中移除（`append(userList[0:index], userList[index+1:]...)`）；仅剩 1 人时直接取走；无用户时提示先导入。

## Demo 示例

下面是基于讲稿逻辑整理出的可运行实现（取自课程 `code/lottery/_demo/annualMeeting` 示例）。

运行说明：

```bash
go run main.go
# 另开终端测试
curl http://localhost:8080/
curl --data "users=yifan,yifan2" http://localhost:8080/import
curl http://localhost:8080/lucky
```

代码说明：

```go
package main

import (
	"fmt"
	"math/rand"
	"strings"
	"time"

	"github.com/kataras/iris"
	"github.com/kataras/iris/mvc"
)

// userList 是全局的用户列表（切片），属于被并发读写的共享变量
var userList []string

func newApp() *iris.Application {
	app := iris.New()
	mvc.New(app.Party("/")).Handle(&lotteryController{})
	return app
}

func main() {
	app := newApp()
	userList = make([]string, 0)
	// http://localhost:8080
	app.Run(iris.Addr(":8080"))
}

// 抽奖的控制器
type lotteryController struct {
	Ctx iris.Context
}

// GET http://localhost:8080/
func (c *lotteryController) Get() string {
	count := len(userList)
	return fmt.Sprintf("当前总共参与抽奖的用户数: %d\n", count)
}

// POST http://localhost:8080/import
func (c *lotteryController) PostImport() string {
	strUsers := c.Ctx.FormValue("users")
	users := strings.Split(strUsers, ",")
	count1 := len(userList)
	for _, u := range users {
		u = strings.TrimSpace(u)
		if len(u) > 0 {
			userList = append(userList, u)
		}
	}
	count2 := len(userList)
	return fmt.Sprintf("当前总共参与抽奖的用户数: %d，成功导入用户数: %d\n", count2, (count2 - count1))
}

// GET http://localhost:8080/lucky
func (c *lotteryController) GetLucky() string {
	count := len(userList)
	if count > 1 {
		seed := time.Now().UnixNano()                                // 随机种子
		index := rand.New(rand.NewSource(seed)).Int31n(int32(count)) // 随机索引
		user := userList[index]                                      // 抽中用户
		userList = append(userList[0:index], userList[index+1:]...)  // 从名单移除
		return fmt.Sprintf("当前中奖用户: %s, 剩余用户数: %d\n", user, count-1)
	} else if count == 1 {
		user := userList[0]
		userList = userList[0:0]
		return fmt.Sprintf("当前中奖用户: %s, 剩余用户数: %d\n", user, count-1)
	} else {
		return fmt.Sprintf("已经没有参与用户，请先通过 /import 导入用户 \n")
	}
}
```

技术点总结：

- Iris 的 MVC 约定：`Get`/`PostImport`/`GetLucky` 方法名自动映射 `GET /`、`POST /import`、`GET /lucky`。
- 随机索引使用 `rand.New(rand.NewSource(seed)).Int31n(int32(count))`，保证落在 `[0, count)`。
- 用切片"拼接"而非 `delete` 来移除元素，避免产生空洞。
- 该版本在单用户顺序调用下功能完备，但 `userList` 作为全局共享切片尚未加锁，存在并发安全隐患（下一节用单元测试暴露）。
