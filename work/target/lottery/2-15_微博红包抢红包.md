# Go 企业级抽奖项目: 微博红包之抢红包实现

## 纲要

- 抢红包接口（GET `get`）凭红包唯一 ID 领取，参数包含 `id` 与 `ip`，先做参数格式校验。
- 从全局 `packageList` 读取对应红包切片，不存在或长度为 0 时返回"红包不存在"异常。
- 在红包切片内随机选取一个位置，读出该小红包金额。
- 领取后更新切片：删除被抽中的位置（首/中/尾三种情况用不同拼接方式），若红包被抽空则从 `packageList` 删除。
- 返回本次抢到的金额；异常处理（参数错误、红包不存在）是工作重点，必须覆盖。

## 参数校验与读取红包

抢红包比发红包简单，核心入参就是前面生成的随机红包 ID。先把 ID、IP 参数解析并校验格式，异常时返回提示；校验通过后再从 `packageList` 取出红包。

```go
package main

import (
	"fmt"
	"math/rand"
	"time"
)

// GetPacket 抢红包：返回抢到的金额（分）；红包不存在或已空返回错误
func GetPacket(id int) (int, error) {
	amounts, ok := packageList[id]
	if !ok || len(amounts) < 1 {
		return 0, fmt.Errorf("红包不存在或已抢光")
	}
	// 在切片内随机选一个位置
	r := rand.New(rand.NewSource(time.Now().UnixNano()))
	idx := r.Intn(len(amounts))
	money := amounts[idx]
	// 更新切片：删除被抽中的位置
	packageList[id] = removeAt(amounts, idx)
	// 抽空则删除整个红包
	if len(packageList[id]) == 0 {
		delete(packageList, id)
	}
	return money, nil
}

// removeAt 从切片中删除第 i 个元素
func removeAt(s []int, i int) []int {
	switch {
	case i == 0:
		return s[1:] // 首个：丢弃头部
	case i == len(s)-1:
		return s[:i] // 末个：截断尾部
	default:
		// 中间：前后两段拼接
		return append(s[:i], s[i+1:]...)
	}
}
```

## 更新切片的三种情况

被抽中的位置可能是切片的首、中、尾，删除方式不同：

- 第一个（`i == 0`）：直接取 `s[1:]`。
- 最后一个（`i == len(s)-1`）：取 `s[:i]`。
- 中间：用 `append(s[:i], s[i+1:]...)` 拼接前后两段。

当红包内所有小红包都被抽走（`len == 0`），调用 `delete(packageList, id)` 把整个红包从全局集合移除，避免空红包继续被抢。

## 完整流程串联

```go
func main() {
	id, err := SetPacket(1, 100, 5)
	if err != nil {
		fmt.Println("发红包失败:", err)
		return
	}
	fmt.Printf("红包 %d 已生成，金额明细: %v\n", id, packageList[id])

	for i := 0; i < 5; i++ {
		m, err := GetPacket(id)
		if err != nil {
			fmt.Println("抢红包:", err)
			continue
		}
		fmt.Printf("第 %d 次抢到 %d 分\n", i+1, m)
	}
	fmt.Printf("剩余红包: %v\n", packageList)
}
```

## API 速览

- `GetPacket(id int) (int, error)`：抢红包，凭 ID 随机领取一个小红包金额，返回金额（分）。
- `removeAt(s []int, i int) []int`：从切片安全删除第 `i` 个元素，覆盖首/中/尾三种情形。
- 抢红包接口（GET `get`）：参数 `id`（必填）、`ip`。
