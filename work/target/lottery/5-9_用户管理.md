# Go 企业级抽奖项目: 用户管理

## 纲要

- 用户管理只有列表页，不提供用户资料编辑；核心操作是设置/解除黑名单。
- 黑名单时长被固化为几档：洗白（0 天）、黑一周、黑一月、黑一年，按「天数」参数化。
- `GetBlack()`：读取用户 `id` 与 `days` 天数，计算 `blackTime = now + days*86400` 并定点更新。
- 更新仅动 `black_time` 与 `sys_updated` 两列，复用 `Cols` 定点更新，避免整行覆盖。
- 列表查询/分页/总数优化与前几个模块一致，本讲重点只讲黑名单设置。

## 黑名单设置动作 GetBlack

```go
package controllers

import (
    "time"

    "github.com/kataras/iris/v12/mvc"

    "lottery/services"
    "lottery/models"
)

// AdminUserController 用户管理后台
type AdminUserController struct {
    mvc.Controller
    UserService services.UserService
}

const secondsPerDay = 86400

// GetBlack 设置/解除黑名单
// days=0 表示洗白；days>0 表示拉黑天数（周/月/年对应 7/30/365）
func (c *AdminUserController) GetBlack() mvc.Result {
    id, err := c.Ctx.URLParamInt("id")
    if err != nil || id <= 0 {
        return mvc.Response{Path: "/admin/user"}
    }

    // 两种取参风格均可：带异常校验 / 带默认值
    days := c.Ctx.URLParamIntDefault("days", 0)

    blackTime := 0
    if days > 0 {
        blackTime = int(time.Now().Unix()) + days*secondsPerDay
    }

    c.UserService.Update(&models.LtUser{
        Id:        id,
        BlackTime: blackTime,
        SysUpdated: int(time.Now().Unix()),
    }, "black_time", "sys_updated")

    return mvc.Response{Path: "/admin/user"}
}
```

> 说明：黑名单以「到期时间戳」表达——`BlackTime=0` 即未拉黑（洗白），大于当前时间即处于黑名单中。前端展示时把 `BlackTime` 格式化为日期即可看到「黑名单到期时间」。

## 列表动作 Get（复用骨架）

```go
// Get 用户列表，无特定搜索条件时直接全量分页
func (c *AdminUserController) Get() mvc.Result {
    page := c.Ctx.URLParamIntDefault("page", 1)
    if page < 1 {
        page = 1
    }
    pageSize := 100

    dataList := c.UserService.GetAll(page, pageSize)
    total := c.UserService.CountAll()

    return mvc.View{
        Name: "admin/user.html",
        Data: iris.Map{
            "Title":    "用户管理",
            "Channel":  "user",
            "UserList": dataList,
            "Total":    total,
            "Page":     page,
        },
        Layout: "shared/layout.html",
    }
}
```

## API 速览

| 方法 | 说明 |
| --- | --- |
| `URLParamIntDefault("days", 0)` | 读取拉黑天数，默认 0=洗白 |
| `days * secondsPerDay` | 把「天」换算成「秒」，叠加到当前 Unix 时间 |
| `UserService.Update(m, "black_time", "sys_updated")` | 定点更新黑名单到期时间与修改时间 |

## Demo 示例

运行说明：将本讲 `AdminUserController` 与 `user_dao.go` 合并，路由挂到 `admin.Party("/user")`。在用户列表点击「黑一年」即请求 `/admin/user/black?id=1001&days=365`，可见该用户 `BlackTime` 变为一年后；点击「洗白」请求 `days=0` 即清零。

代码说明：黑名单本质是「一个到期时间戳」字段，所有时长档位都被归约为 `days` 参数，逻辑极度精简。更新用 `Cols` 限定列，安全且高效。

技术点总结：

- 把「时间区间」语义收敛为「到期时间戳」，是后台时间型字段的通用建模方式。
- 多档操作（周/月/年/洗白）不需要多个接口，一个 `days` 参数即可统一。
- 列表查询在多个后台模块间完全同构，体现「后台即增删改查」的设计复用。
