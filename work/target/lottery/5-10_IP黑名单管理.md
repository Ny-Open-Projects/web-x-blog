# Go 企业级抽奖项目: IP 黑名单管理

## 纲要

- IP 黑名单管理与用户管理高度同源：同样只有列表页，操作同样是洗白/黑一周/黑一月/黑一年。
- 唯一差异：操作对象从「用户」变为「IP」，模型由 `LtUser` 换为 `LtBlackIP`，控制器由 `AdminUserController` 换为 `AdminBlackIPController`。
- `GetBlack()` 逻辑完全复用：读取 `id` 与 `days`，计算 `blackTime = now + days*86400` 后定点更新。
- 最快实现方式：复制用户管理控制器，替换对象与字段即可，无需重写业务逻辑。
- 后台五大模块至此全部完成，抽奖接口（下一章）将完全依赖这些后台维护的数据。

## 黑名单设置动作 GetBlack（与用户管理同构）

```go
package controllers

import (
    "time"

    "github.com/kataras/iris/v12/mvc"

    "lottery/services"
    "lottery/models"
)

// AdminBlackIPController IP 黑名单管理后台
type AdminBlackIPController struct {
    mvc.Controller
    BlackIPService services.BlackIPService
}

const secondsPerDay = 86400

// GetBlack 设置/解除 IP 黑名单
func (c *AdminBlackIPController) GetBlack() mvc.Result {
    id, err := c.Ctx.URLParamInt("id")
    if err != nil || id <= 0 {
        return mvc.Response{Path: "/admin/blackip"}
    }

    days := c.Ctx.URLParamIntDefault("days", 0)
    blackTime := 0
    if days > 0 {
        blackTime = int(time.Now().Unix()) + days*secondsPerDay
    }

    c.BlackIPService.Update(&models.LtBlackIP{
        Id:        id,
        BlackTime: blackTime,
        SysUpdated: int(time.Now().Unix()),
    }, "black_time", "sys_updated")

    return mvc.Response{Path: "/admin/blackip"}
}
```

## 列表动作 Get（复用骨架）

```go
// Get IP 黑名单列表
func (c *AdminBlackIPController) Get() mvc.Result {
    page := c.Ctx.URLParamIntDefault("page", 1)
    if page < 1 {
        page = 1
    }
    pageSize := 100

    dataList := c.BlackIPService.GetAll(page, pageSize)
    total := c.BlackIPService.CountAll()

    return mvc.View{
        Name: "admin/blackip.html",
        Data: iris.Map{
            "Title":     "IP 黑名单管理",
            "Channel":   "blackip",
            "BlackIPList": dataList,
            "Total":     total,
            "Page":      page,
        },
        Layout: "shared/layout.html",
    }
}
```

## 与用户管理的对照

| Service | `UserService` | `BlackIPService` |
| 路由 | `/admin/user` | `/admin/blackip` |
| 黑名单字段 | `black_time` | `black_time` |

## Demo 示例

运行说明：将本讲 `AdminBlackIPController` 与 `blackip_dao.go` 合并，路由挂到 `admin.Party("/blackip")`。在列表点击「黑一年」即请求 `/admin/blackip/black?id=1&days=365`，该 IP 的 `BlackTime` 变为一年后；点击「洗白」请求 `days=0` 即清零。

代码说明：本模块是用户管理的「克隆」，仅替换数据对象。重复功能最快的实现方式就是复制粘贴后局部改名，避免无意义的重复编码。

技术点总结：

- 后台管理模块高度同构，列表 + 分页 + 黑名单设置可跨模块复用。
- 「复制 + 改名」是处理同构模块的高效手段，只要确认业务逻辑一致即可。
- 五大后台模块（奖品/优惠券/中奖记录/用户/IP 黑名单）构成了抽奖系统完整的数据维护面，下一章抽奖接口将直接消费这些数据。
