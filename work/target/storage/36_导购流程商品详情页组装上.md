# 36. 六大数据库存储实战: 商品详情页的多模型级联组装

## 纲要

- 详情页痛点：基础 `Item` 只存 ID 类字段，缺商家名、类目、品牌、SKU 与库存，需运行时拼装
- 扩展实体：`Item` 用 `@TableField(exist=false)` 冗余 `sellerName` / `category` / `brand` / `skuList`；`Sku` 冗余属性名值与 `stockCount`
- 组装逻辑 `ItemServiceImpl.getItem`：取 Item → 补商家/品牌/类目名 → 按 `item_id` 查 SKU → 委托 `SkuService.listByShopId` 补属性与库存
- `SkuServiceImpl.listByShopId`：循环补 `SkuAttributeInfo` 的名称/值，并按 `shop_id` 关联 `Stock` 得到库存

## 详情页为什么需要二次组装

商品详情页展示的不仅是 `Item` 基础字段，还需要商家名、类目、品牌、SKU 列表及每个 SKU 的属性和库存。这些分散在 `seller` / `category` / `brand` / `sku` / `sku_attribute_info` / `stock` 多张表中。存储层为了范式与查询效率，不会把商家名直接冗余进 `item`，因此必须在查询时做级联拼装。

## 扩展实体：用 exist=false 标注意义外字段

在 `Item` 上追加非持久化字段，仅用于对外展示：

```java
@TableField(exist = false)
private String sellerName;

@TableField(exist = false)
private String category;

@TableField(exist = false)
private String brand;

@TableField(exist = false)
private List<Sku> skuList = new ArrayList<>();
```

`exist = false` 告诉 MybatisPlus 这些字段不映射到数据库列，避免查询时去表里找不存在的列。同理，`Sku` 上追加：

```java
@TableField(exist = false)
private List<SkuAttributeInfo> skuAttributeInfoList = new ArrayList<>();

// 仅当通过 shopId 请求 SKU 时才有库存信息
@TableField(exist = false)
private Integer stockCount;
```

`SkuAttributeInfo` 也把 `attributeNameId` / `attributeValueId` 对应的可读文本冗余出来：

```java
@TableField(exist = false)
private String attributeName;

@TableField(exist = false)
private String attributeValue;
```

## 详情页组装：ItemServiceImpl.getItem

`getItem(id,shopId)` 负责把分散信息拼成完整详情：

```java
@Override
public Item getItem(Long id, Long shopId) {
    Item item = getById(id);
    if (item == null) {
        return null;
    }
    // 补商家名、品牌名、类目名
    item.setSellerName(sellerService.getById(item.getSellerId()).getSellerName());
    item.setBrand(brandService.getById(item.getBrandId()).getName());
    item.setCategory(categoryService.getById(item.getCategoryId()).getName());

    // 按 item_id 查出 SKU 列表，并委托 SkuService 补全属性与库存
    QueryWrapper<Sku> skuQueryWrapper = new QueryWrapper<>();
    skuQueryWrapper.eq("item_id", item.getId());
    List<Sku> skuList = skuService.listByShopId(skuQueryWrapper, shopId);
    item.setSkuList(skuList);
    return item;
}
```

这里通过 `shopId` 而非只靠 `itemId` 查询，是因为同一个商品在不同门店的库存不同——库存依附于「商品 + 门店」的组合。

## SKU 级联补全：SkuServiceImpl.listByShopId

`listByShopId` 对每个 SKU 做两级补全：属性名值、库存：

```java
@Override
public List<Sku> listByShopId(QueryWrapper<Sku> queryWrapper, Long shopId) {
    List<Sku> objectList = super.list(queryWrapper);
    objectList.forEach(obj -> {
        // 1、补全 SKU 属性名 / 属性值
        QueryWrapper attributeQueryWrapper = new QueryWrapper();
        attributeQueryWrapper.eq("sku_id", obj.getId());
        obj.setSkuAttributeInfoList(skuAttributeInfoService.list(attributeQueryWrapper));
        obj.getSkuAttributeInfoList().forEach(attributeInfo -> {
            attributeInfo.setAttributeName(
                attributeNameService.getById(attributeInfo.getAttributeNameId()).getName());
            attributeInfo.setAttributeValue(
                attributeValueService.getById(attributeInfo.getAttributeValueId()).getValue());
        });

        // 2、按 sku_id + shop_id 关联库存
        QueryWrapper<Stock> stockQueryWrapper = new QueryWrapper<>();
        stockQueryWrapper.eq("sku_id", obj.getId());
        stockQueryWrapper.eq("shop_id", shopId);
        List<Stock> stockList = stockService.list(stockQueryWrapper);
        if (stockList.size() > 0) {
            obj.setStockCount(stockList.get(0).getStockCount());
        } else {
            obj.setStockCount(0);
        }
    });
    return objectList;
}
```

逻辑要点：

- **属性补全**依赖 `sku_attribute_info` 表，再用 `attributeNameId` / `attributeValueId` 去名称表、值表取可读文本。
- **库存补全**必须同时命中 `sku_id` 与 `shop_id`，因为库存行「要么存在一条，要么没有」，取首条即可，无则库存为 0。

## API 速览

| 方法 | 作用 |
| --- | --- |
| `ItemService.getItem(id,shopId)` | 返回拼装完整的商品详情 |
| `SkuService.listByShopId(wrapper,shopId)` | 按门店补全 SKU 属性与库存 |
| `@TableField(exist = false)` | 声明非持久化展示字段 |
| `QueryWrapper.eq(col,val)` | 等值关联查询 |

## Demo 示例

**运行说明**：启动应用（9090 端口），访问 `GET /item/get?id=1&shopId=1`。调试阶段曾因 `shopId` 未传、以及 `getAttributeNameId` 误写成 `getId` 导致空指针，修正后正常返回 `data` 含 `sellerName` / `category` / `brand` / `skuList`（含 `attributeName`/`attributeValue`/`stockCount`）。

**代码说明**：`Item` / `Sku` 用 `exist=false` 承载冗余展示字段；组装在 Service 层通过多次关联查询完成。

**技术点总结**：关系型存储下，详情页是「多表级联 + 冗余展示字段」的典型产物；用 `exist=false` 区分持久化与展示模型，把拼装逻辑收敛到 Service，是保持实体干净、接口完整的常用手法。
