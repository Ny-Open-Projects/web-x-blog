# LeetCode 541. 反转字符串 II (ts)

> 来源：[Wang's Blog](https://blog.csdn.net/tyro_java/article/details/145565975)
> 语言：**ts**（博客原文）

## 题目描述

- - 给定一个字符串 s 和一个整数 k，从字符串开头算起，每计数至 2k 个字符，就反转这 2k 字符中的前 k 个字符。 
- - 如果剩余字符少于 k 个，则将剩余字符全部反转。
- - 如果剩余字符小于 2k 但大于或等于 k 个，则反转前 k 个字符，其余字符保持原样。

## 示例

```
输入：s = "abcdefg", k = 2
输出："bacdfeg"

输入：s = "abcdefg", k = 2
输出："bacdfeg"

输入：s = "abcd", k = 2
输出："bacd"

输入：s = "abcd", k = 2
输出："bacd"
```
