### 卡片 5：什么叫"可见性"问题的硬件根源
每个 CPU 核有自己的 L1/L2 缓存。线程 A 在核 0 改了变量，改的是核 0 的缓存；
线程 B 在核 1 读，读到核 1 缓存的旧值。硬件层靠 **MESI 缓存一致性协议** 同步，
但编译器/CPU 还会优化（写缓冲、重排），所以 Java 在语言层再加一堵墙——**JMM（Java 内存模型）**。
