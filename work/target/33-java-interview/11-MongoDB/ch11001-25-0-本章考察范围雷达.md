# 第 25 章 MongoDB 与文档数据库 —— 从文档模型到分片集群

> MongoDB 是 NoSQL 面试的第一大常客（Redis 之后），Java 后端 P10 面试考察重点不在 CRUD，
> 而在**选型判断、副本集/分片的分布式机制、索引设计原则、与 MySQL 的混合架构**。
> 学习方法：先建立"文档模型 vs 关系模型"的心智转换，再进入分布式机制。

---


## 25.0 本章考察范围雷达

| 维度 | P5-P6 | P7 | P8-P10 |
|------|-------|----|--------|
| 文档模型 | CRUD/嵌套文档 | 建模：嵌入 vs 引用 | 大文档迁移/16MB 边界设计 |
| 索引 | 会建索引 | ESR 原则/TTL/partial | 索引选型对性能的量化影响 |
| 副本集 | 概念 | oplog/选举/读写关注 | 选举细节/回滚场景/写关注权衡 |
| 分片 | 概念 | 分片键选择 | 键选错的补救/reshard/混合架构 |
| Java 集成 | 会用 driver | MongoTemplate/Repository | 连接池/事务/大厂混合架构案例 |
