### 题 25.4.2：从 MySQL 迁移商品数据到 MongoDB，怎么迁？

**【参考回答（框架可背）】** 复用第 5 章 5.3.2 的双写四步法（两领域同构）：① 建模转换（表→文档，嵌套化设计先评审）；② 存量迁移（快照导出→转换→导入）；③ 增量双写（CDC 捕获 MySQL 变更→写 MongoDB，对账工具逐文档比对）；④ 切读切写。**MongoDB 特有风险点**：建模错误返工成本极高（文档结构改动=全量重写），所以建模评审在迁移前必须做两次；事务语义差异（MySQL 多表事务 → MongoDB 单文档原子+少量多文档事务）。

**【追问链】** 为什么不直接用 Flink CDC 同步？→ 可以，正是推荐方案；关键是 MongoDB 侧的**幂等写**（upsert by _id）与乱序容忍（按 updated_at 版本号丢弃旧写）。
