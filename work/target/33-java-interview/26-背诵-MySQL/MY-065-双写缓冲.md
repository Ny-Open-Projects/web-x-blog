## 存储 · 双写缓冲（doublewrite）

- **事实**：doublewrite buffer 防止"部分页写失效"（页 16KB 而磁盘 IO 原子单位更小）
- **原理**：写数据页先写 doublewrite 再落盘，崩溃时用它恢复完整页，是 InnoDB 数据可靠性的隐性防线
- **常见误区**：
  1. doublewrite 是可选优化（错）
  2. 部分页写由 redo 直接解决（错）
  3. doublewrite 在内存无 IO 代价（错）
- **工程用法**：可靠性机制八股
- **版本锚点**：InnoDB 文档
