## 分库分表 · 拆分（方式）

- **事实**：垂直拆分（按业务/按冷热列）与水平拆分（按行分片）
- **原理**：垂直：订单库存分库解耦；水平：单表数据量过大按分片键散列/区间，先垂直后水平是通用路径
- **常见误区**：
  1. 水平拆分是第一步（错）
  2. 垂直拆分解决数据量问题（错）
  3. 两者只能选一（错）
- **工程用法**：拆分路线图
- **版本锚点**：实战方法论
