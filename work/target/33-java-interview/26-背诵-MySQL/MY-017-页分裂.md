## 存储 · 页分裂（页）

- **事实**：InnoDB 以 16KB 页为管理单位插入满页时分裂（数据有序时顺序写入免分裂）
- **原理**：自增插入永远追加到最右页免分裂，随机插入命中率低且分裂频繁，碎片需要 OPTIMIZE TABLE 重建
- **常见误区**：
  1. 页分裂只影响内存（错）
  2. InnoDB 页大小 32KB（错）
  3. 分裂不会产生碎片（错）
- **工程用法**：理解 B+ 树写入放大
- **版本锚点**：InnoDB 文档
