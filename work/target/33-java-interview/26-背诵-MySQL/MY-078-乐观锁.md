## SQL · 乐观锁（锁）

- **事实**：乐观锁更新：update ... set version=version+1 where id=? and version=? 判断影响行数
- **原理**：无锁化高并发更新标准手法（库存扣减、状态机流转），失败重试或业务提示，与 select for update 悲观锁对比选型
- **常见误区**：
  1. 乐观锁需要数据库锁支持（错）
  2. 乐观锁失败自动重试（错）
  3. 影响行数为 1 表示成功（错）
- **工程用法**：高并发更新模式
- **版本锚点**：实战共识
