## 分库分表 · 基因法（分片键）

- **事实**：分片键选择与基因法：订单号嵌入用户 ID 基因，使订单表与用户表同路由
- **原理**：同一用户数据落同一分片免跨片 join，订单查询按订单号（带基因）与按用户（同基因）都单分片命中，是电商通用手法
- **常见误区**：
  1. 分片键随意选不影响查询（错）
  2. 基因法指 DNA 数据库（是"主键嵌入路由基因"的哈希技巧）（错）
  3. 跨片 join 总能靠中间件解决（错）
- **工程用法**：分库分表设计核心考点
