## SQL · 小表驱动（join）

- **事实**：join 优化核心是小表驱动大表
- **原理**：驱动表行数决定外层循环次数，straight_join 强制指定驱动顺序，"小表"指过滤后行数少而非物理小
- **常见误区**：
  1. 大表做驱动表更快（错）
  2. 小表指物理文件小（错）
  3. join 顺序由 SQL 书写决定（错）
- **工程用法**：join 慢查询的第一分析点
- **版本锚点**：实战共识
