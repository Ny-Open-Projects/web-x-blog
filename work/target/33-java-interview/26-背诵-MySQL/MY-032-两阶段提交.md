## 事务 · 两阶段提交（两阶段）

- **事实**：binlog 与 redo 之间用两阶段提交：redo prepare→写 binlog→redo commit
- **原理**：保证 redo 与 binlog 逻辑一致（崩溃恢复时 binlog 完整则提交否则回滚），否则主从数据不一致（本项目反复核对的机制）
- **常见误区**：
  1. redo 与 binlog 独立提交无协调（错）
  2. 两阶段提交指分布式事务（错）
  3. 先写 binlog 再写 redo（错）
- **工程用法**：崩溃恢复一致性根基
- **版本锚点**：InnoDB 文档
