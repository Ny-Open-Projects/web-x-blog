## 锁 · 意向锁（意向）

- **事实**：表级意向锁（IS/IX）表明事务将持行锁，用于快速判断表锁冲突
- **原理**：加行锁前先加意向表锁，DDL（MDL 排他）与 LOCK TABLES 通过意向锁快速检测，不阻塞行级操作
- **常见误区**：
  1. 意向锁会阻塞行锁（错）
  2. 意向锁是行级锁（错）
  3. 没有意向锁表锁检查更高效（错）
- **工程用法**：锁体系分层知识
- **版本锚点**：InnoDB 文档
