## 分库分表 · 雪花（ID）

- **事实**：分布式 ID：雪花算法（64 位时间戳+机器+序列）时钟回拨问题与号段模式（DB 批量取号）
- **原理**：雪花本地生成高性能但依赖时钟（回拨需等待或备位），号段模式 DB 一次取一段内存分发（美团 Leaf 两种都实现）
- **常见误区**：
  1. 雪花 ID 全球唯一靠数据库（错）
  2. 时钟回拨自动解决无风险（错）
  3. 号段模式每次写库取号（错）
- **工程用法**：分布式 ID 是分库分表标配
- **版本锚点**：实战共识
