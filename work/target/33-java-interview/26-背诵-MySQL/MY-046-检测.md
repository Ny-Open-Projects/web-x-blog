## 锁 · 检测（死锁）

- **事实**：InnoDB 自动检测死锁（innodb_deadlock_detect 默认 ON）回滚代价小的事务
- **原理**：SHOW ENGINE INNODB STATUS 看 LATEST DETECTED DEADLOCK，热点行更新高并发时死锁检测本身耗 CPU（关掉+排队是优化方案）
- **常见误区**：
  1. 死锁需要人工发现（错）
  2. 死锁检测默认关闭（错）
  3. 发生死锁两个事务都回滚（错）
- **工程用法**：死锁问题排查入口
- **版本锚点**：InnoDB 文档
