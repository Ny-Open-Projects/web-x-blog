## 运维 · 降级（容量）

- **事实**：容量预警指标：磁盘空间（binlog+数据）、连接数使用率、buffer pool 命中率、QPS 趋势
- **原理**：容量规划按增长趋势提前扩容，磁盘满会写挂（先 binlog 满），监控四项指标设阈值告警
- **常见误区**：
  1. 磁盘满 MySQL 自动清理（错）
  2. 连接数不用监控（错）
  3. QPS 趋势无预警价值（错）
- **工程用法**：运维监控基线
- **版本锚点**：实战方法论
