## 实践 · 分离（报表）

- **事实**：OLTP 与 OLAP 分离：报表/分析走从库或数仓（ClickHouse），主库只服务交易
- **原理**：大查询拖垮主库（buffer pool 污染+CPU），数据通过 binlog→CDC（Flink/Canal）入数仓，实时与离线分层
- **常见误区**：
  1. 报表查询放主库没问题（错）
  2. OLAP 必须用 MySQL 主库（错）
  3. CDC 同步是实时的（有秒级延迟需容忍）（错）
- **工程用法**：架构分层设计
- **版本锚点**：实战方法论
