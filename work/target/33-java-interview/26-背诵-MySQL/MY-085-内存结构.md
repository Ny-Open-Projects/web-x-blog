## InnoDB · 内存结构（架构）

- **事实**：InnoDB 内存结构：buffer pool（数据页）、change buffer（二级索引写）、log buffer、AHI（自适应哈希）
- **原理**：buffer pool 按 LRU 变体（young/old 区防全表扫描污染）管理，预读与老生代窗口参数（innodb_old_blocks_time）调优
- **常见误区**：
  1. buffer pool 用标准 LRU（错）
  2. change buffer 缓存数据页（错）
  3. AHI 默认关闭（错）
