## 索引 · 最左前缀（联合）

- **事实**：联合索引 (a,b,c) 只有从 a 开始的连续前缀才能走索引
- **原理**：B+ 树先按 a 排序再按 b，跳过 a 无法定位，where b=1 单独查询不走该索引
- **常见误区**：
  1. 联合索引任意列都能单独走索引（错）
  2. 顺序无关紧要（错）
  3. (a,c) 查询能用到 a 与 c 两列（错）
- **工程用法**：建联合索引先定首列
- **版本锚点**：最左前缀原则
