## 实践 · 冷热（归档）

- **事实**：冷热分离：热数据（近 N 月）在线库，冷数据归档库（压缩表/对象存储），查询路由按时间
- **原理**：在线库保持小容量（索引高效），归档按 partition drop 秒级清理，归档库查询走专门服务
- **常见误区**：
  1. 归档数据必须保留在原表（错）
  2. 冷热分离影响业务查询（错）
  3. 归档只能定时全量导出（错）
- **工程用法**：大表生命周期管理
- **版本锚点**：实战方法论
