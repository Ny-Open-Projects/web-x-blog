## 运维 · 清理（大表）

- **事实**：大表数据清理：分批 delete（每批几千行+sleep）避免长事务与主从延迟，归档走 PT-archiver
- **原理**：一次性删百万行产生大事务（undo 膨胀、复制延迟、锁堆积），按主键分批+间隔是标准做法，drop/truncate 直接重置
- **常见误区**：
  1. 一次 delete 百万行没问题（错）
  2. 分批删除不需要主键顺序（错）
  3. 归档与清理是一回事（错）
- **工程用法**：大表运维实操
- **版本锚点**：实战共识
