## SQL · 最小权限（权限）

- **事实**：账号权限最小化：业务账号只授 DML（无 DDL/无 drop），只读账号专供报表，root 隔离运维
- **原理**：权限泄漏与误操作是数据事故主源，grant 按 IP 限定来源，审计日志（audit plugin）记录敏感操作
- **常见误区**：
  1. 业务账号需要全部权限（错）
  2. 权限只按库不按表（可按表粒度）（错）
  3. 授权后立即生效需重启（错）
- **工程用法**：数据库安全基线
- **版本锚点**：实战共识
