## 索引 · 回表（回表）

- **事实**：二级索引查询需拿主键回聚簇索引再取整行称为回表
- **原理**：二级索引只存 (索引列, 主键)，需要的列不在索引里就回表，回表次数是优化关键
- **常见误区**：
  1. 二级索引包含全部行数据（错）
  2. 回表只发生在非聚簇引擎（错）
  3. 回表成本可以忽略（错）
- **工程用法**：优化 select * 的第一步是减少回表
- **版本锚点**：实战共识
