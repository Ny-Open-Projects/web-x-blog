## 索引 · B+ 树（结构）

- **事实**：InnoDB 索引是 B+ 树：非叶子节点只存键叶子节点存数据且叶子双向链表相连
- **原理**：非叶子不存数据使单节点容纳更多键降低树高，链表支撑范围扫描，这是 B+ 树取代 B 树/二叉树的原因
- **常见误区**：
  1. InnoDB 用 B 树存储（错）
  2. B+ 树叶子单向链表（错）
  3. B+ 树支持哈希查找（错）
- **工程用法**：索引结构八股的基准点
- **版本锚点**：InnoDB 文档
