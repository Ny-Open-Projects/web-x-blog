## 主键 · 自增主键（设计）

- **事实**：InnoDB 主键推荐自增或趋势递增值（UUID 随机导致页分裂）
- **原理**：随机主键使插入落点分散引发页分裂与碎片、buffer pool 命中率下降，雪花 ID 趋势递增兼得分布式唯一与写入友好
- **常见误区**：
  1. UUID 与自增主键无性能差异（错）
  2. 页分裂只发生在删除时（错）
  3. 主键选择不影响二级索引（错）
