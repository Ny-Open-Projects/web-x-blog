## 日志 · 格式（binlog）

- **事实**：binlog 是 Server 层逻辑日志默认 ROW 格式（8.0 默认 ROW，官方文档核对零差异）
- **原理**：ROW 记录行级变更（主从最安全）、STATEMENT 记 SQL（体积小但 now()/uuid() 不安全）、MIXED 自动切换
- **常见误区**：
  1. 8.0 默认 STATEMENT（错）
  2. ROW 格式无法用于恢复（错）
  3. MIXED 是 8.0 默认（错）
- **工程用法**：binlog 格式选型
- **版本锚点**：MySQL 8.0 官方文档
