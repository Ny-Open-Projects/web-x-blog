## 复制 · 主从复制（流程）

- **事实**：主从复制流程：主库 dump 线程发 binlog→从库 IO 线程写 relay log→SQL 线程重放
- **原理**：异步复制默认主库不等从库，从库延迟时读到旧数据，GTID（8.0 默认支持）标识事务位置断点续传
- **常见误区**：
  1. 复制是主库拉取 binlog（错）
  2. relay log 存在主库（错）
  3. SQL 线程在主库执行（错）
- **工程用法**：复制拓扑与故障恢复基础
- **版本锚点**：MySQL 文档
