## 复制 · 主从延迟（延迟）

- **事实**：主从延迟根因：从库单线程重放赶不上主库并发写、大事务、从库机器弱
- **原理**：解法：并行复制（8.0 writeset/LOGICAL_CLOCK）、拆大事务、从库升级，延迟监控 Seconds_Behind_Master 与 pt-heartbeat
- **常见误区**：
  1. 从库多线程后延迟消失（错）
  2. 大事务对延迟无影响（错）
  3. Seconds_Behind_Master 精确可靠（并行复制下有偏差，pt-heartbeat 更准）（错）
- **工程用法**：读写分离架构的核心风险
- **版本锚点**：实战共识
