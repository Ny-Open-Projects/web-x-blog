## Spring AI · 宽松解析（结构化）

- **事实**：Spring AI 结构化输出的宽松解析：代码块包裹的 JSON 也能提取（模型爱包 ```json）
- **原理**：模型输出习惯带 Markdown 代码围栏，框架层做提取兜底，但极端格式仍需业务兜底（JA-099）
- **常见误区**：
  1. 代码围栏会导致解析失败（错）
  2. 宽松解析处理一切（错）
  3. 不需要业务兜底（错）
- **工程用法**：解析鲁棒性
- **版本锚点**：Spring AI 1.0 GA
