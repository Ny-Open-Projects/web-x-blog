## RAG · 归一化（相似度）

- **事实**：嵌入向量归一化与距离度量：cosine 相似度要求向量归一化，未归一化时点积与 cosine 不等价
- **原理**：度量选错检索排序就错（静默质量事故），入库与检索用同一度量口径，嵌入模型文档确认
- **常见误区**：
  1. 度量随意选无影响（错）
  2. 点积永远等于 cosine（错）
  3. 归一化是可选装饰（错）
- **工程用法**：相似度口径
- **版本锚点**：实战共识
