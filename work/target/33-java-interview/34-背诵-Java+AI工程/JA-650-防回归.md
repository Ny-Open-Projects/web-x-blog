## 工程 · 防回归（质量）

- **事实**：防回归的"三道闸"：提交时单测（快）→发布时评估集（准）→上线后影子（真），三道闸各防一类回归
- **原理**：JA-407/407 分层闸门的组织化，三道闸漏一道就有回归漏网，与质量左移思想联动
- **常见误区**：
  1. 一道闸足够（错）
  2. 三道闸是重复劳动（错）
  3. 闸门与质量无关（错）
- **工程用法**：质量闸门体系
- **版本锚点**：实战共识
