## 工程 · 对抗（测试）

- **事实**：对抗评测自动化：红队样本（JA-465）自动批量跑防线（注入/越狱/越权），防线回归自动化
- **原理**：JA-654 红队节奏的自动化：每次防线变更自动跑对抗样本，安全回归与功能回归同级（JA-156），与安全自动化联动
- **常见误区**：
  1. 对抗测试全人工（错）
  2. 自动化对抗不存在（错）
  3. 安全回归手动跑（错）
- **工程用法**：对抗自动化
- **版本锚点**：实战共识
