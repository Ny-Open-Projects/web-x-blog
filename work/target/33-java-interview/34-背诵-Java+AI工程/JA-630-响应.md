## 治理 · 响应（审计）

- **事实**：监管审计响应准备：AI 系统的数据流向图（JA-409）/留痕体系（JA-383）/模型卡（JA-405）随时可调取，问询响应预案
- **原理**：监管问询的备战（JA-551 强监管行业必答题），资产齐备则响应快，与合规演练联动
- **常见误区**：
  1. 监管问询不会发生（错）
  2. 响应时再准备（错）
  3. 资产分散无碍（错）
- **工程用法**：审计备战
- **版本锚点**：实战共识
