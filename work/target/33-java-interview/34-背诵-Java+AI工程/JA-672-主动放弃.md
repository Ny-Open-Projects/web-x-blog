## Agent · 主动放弃（能力）

- **事实**：Agent 的"不作为"能力：允许模型决定不调用工具（直接回答或说明无法完成），强制调用会逼出错误工具使用
- **原理**：工具不是越多调用越好（误用工具比不用更糟），放弃能力是成熟 Agent 标志（判断是否需要工具），与幻觉工具调用防线联动
- **常见误区**：
  1. Agent 必须每步调工具（错）
  2. 不作为是失败（错）
  3. 放弃能力无法实现（错）
- **工程用法**：Agent 决策成熟度
- **版本锚点**：实战共识
