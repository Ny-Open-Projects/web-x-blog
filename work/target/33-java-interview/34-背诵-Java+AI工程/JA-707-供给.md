## 数据 · 供给（契约）

- **事实**：知识库供给方 SLA：业务方承诺语料质量/更新时效/格式规范（数据契约），违反契约的语料拒绝入库

- **常见误区**：
  1. 语料来者不拒（错）
  2. 契约是形式主义（错）
  3. 上游无责任（错）
