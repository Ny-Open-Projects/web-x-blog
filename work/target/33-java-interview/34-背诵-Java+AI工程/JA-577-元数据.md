## 工程 · 元数据（模板）

- **事实**：prompt 版本元数据：作者/评审人/生效时间/评估分数/适用场景，模板即资产（JA-473 资产库的条目结构）
- **原理**：资产库条目的元数据面（可检索可审计），元数据缺失则资产库退化为片段堆，与知识管理联动
- **常见误区**：
  1. prompt 无需元数据（错）
  2. 元数据是可选装饰（错）
  3. 只有正文重要（错）
- **工程用法**：模板元数据
- **版本锚点**：实战共识
