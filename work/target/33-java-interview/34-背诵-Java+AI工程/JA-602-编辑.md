## 行业 · 编辑（传媒）

- **事实**：传媒内容生成工作流：AI 初稿→编辑修改（可编辑反馈 JA-576）→审核（JA-437）→发布，AI 是"初稿机器"而非发布者
- **原理**：传媒场景核心矛盾：时效与质量，AI 初稿把编辑从空白页解放（人审位置 JA-478），产出口径与风格一致性（JA-445）用 few-shot 锚定
- **常见误区**：
  1. 传媒内容全自动发布（错）
  2. AI 直接替代编辑（错）
  3. 风格无需锚定（错）
- **工程用法**：内容生产工作流
- **版本锚点**：实战共识
