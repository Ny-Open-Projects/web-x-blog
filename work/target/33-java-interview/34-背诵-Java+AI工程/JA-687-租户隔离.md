## 网关 · 租户隔离（缓存）

- **事实**：网关级缓存的租户隔离：缓存键含租户维度（防跨租户命中泄露数据）
- **原理**：JA-155 缓存键的多租户补充：语义缓存（JA-151）的键必须含租户（相似问题不同租户答案可能不同且隐私隔离），与 RD-067 key 规范联动
- **常见误区**：
  1. 缓存键无需租户（错）
  2. 跨租户命中无风险（错）
  3. 租户维度可选（错）
- **工程用法**：缓存租户隔离
- **版本锚点**：实战共识
