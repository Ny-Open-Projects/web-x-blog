## 工程 · 本地计数（token）

- **事实**：Java 侧本地 token 计数：jtokkit 是 tiktoken 的 Java 实现（BPE 编码本地计算）
- **原理**：预算估算（AI-062/103）需要本地计数（调 API 计数太贵），jtokkit 是 Java 生态事实标准
- **常见误区**：
  1. Java 没有 token 计数库（错）
  2. 计数必须调 API（错）
  3. 本地计数与供应商一致无偏差（近似值用于预算足够）（错）
- **工程用法**：token 工程工具
- **版本锚点**：实战共识
