## 工程 · 线上影子（评估）

- **事实**：线上影子评估：真实流量抽样（脱敏）跑新旧双管线对比（JA-234 的持续化），输出每日对比报告
- **原理**：影子评测（JA-336）的持续运营版，变更前后的质量曲线可视化，与 A/B（JA-271）互补（无用户感知）
- **常见误区**：
  1. 影子评估是一次性的（错）
  2. 持续对比无价值（错）
  3. 影子成本不可控（按抽样率控制）（错）
- **工程用法**：持续评估机制
- **版本锚点**：实战共识
