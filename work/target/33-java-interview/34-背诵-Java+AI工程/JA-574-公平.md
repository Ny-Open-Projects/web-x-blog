## 工程 · 公平（限流）

- **事实**：多租户公平调度：token server 公平队列（防大租户饿死小租户），加权公平而非先到先得
- **原理**：JA-320 配额的公平面：共享配额下的公平调度（加权轮询），与调度算法知识联动
- **常见误区**：
  1. 先到先得公平（错）
  2. 公平调度无必要（错）
  3. 大租户优先合理（错）
- **工程用法**：公平调度
- **版本锚点**：实战共识
