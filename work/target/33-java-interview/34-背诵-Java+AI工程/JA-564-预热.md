## 工程 · 预热（网络）

- **事实**：连接与 DNS 预热：启动时/定时预热连接池与 DNS 缓存（JA-215 检索预热的网络层），突发流量前主动预热
- **原理**：冷启动延迟的传输层面（与缓存预热 RD-066 同族），大促/活动前预热脚本，与容量保障联动
- **常见误区**：
  1. 连接自动预热（错）
  2. 预热无必要（错）
  3. DNS 不会成为瓶颈（错）
- **工程用法**：预热工程
- **版本锚点**：实战共识
