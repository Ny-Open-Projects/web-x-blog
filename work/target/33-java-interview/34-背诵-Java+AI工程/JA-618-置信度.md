## RAG · 置信度（输出）

- **事实**：检索置信度输出：检索结果带相似度分数，低于阈值的查询走拒答（JA-367），分数进响应供前端展示"依据强度"
- **原理**：置信度透明化让用户判断可信度（AI-011 引用的延伸），分数也是路由依据（JA-466）
- **常见误区**：
  1. 检索结果不带分数（错）
  2. 分数对用户无意义（错）
  3. 阈值只有检索用（错）
- **工程用法**：置信度透明化
- **版本锚点**：实战共识
