## 工程 · 运营（评测）

- **事实**：评测集运营节奏：月度新增（线上回流 JA-179）+季度清理（过时条目下线）+半年度全量基线重校（JA-347）
- **原理**：评估集是活资产（AI-012）的运营日历，增长/清理/重校三动作，与数据治理周期联动
- **常见误区**：
  1. 评估集只增不减（错）
  2. 运营无日历（错）
  3. 重校与基线无关（错）
- **工程用法**：评估资产运营
- **版本锚点**：实战共识
