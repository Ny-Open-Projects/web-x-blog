## 工程 · 虚拟线程（并发）

- **事实**：虚拟线程与 LLM 流式的组合（SP-083）：MVC+虚拟线程处理 SSE 长连接（阻塞式编程模型处理长 IO）
- **原理**：JA-297 三选一的第四姿势：虚拟线程让阻塞代码获得响应式吞吐（JDK21），回调地狱消除，与并发模型知识联动
- **常见误区**：
  1. 虚拟线程与流式无关（错）
  2. 必须 WebFlux（错）
  3. 虚拟线程不成熟（错）
- **工程用法**：并发模型新选项
- **版本锚点**：JDK21+
