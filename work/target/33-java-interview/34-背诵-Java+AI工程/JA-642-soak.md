## 工程 · soak（测试）

- **事实**：长稳测试（soak test）：AI 链路 24-72 小时持续跑（低流量），抓内存泄漏/连接泄漏/句柄泄漏
- **原理**：长稳问题短测抓不到（SSE 长连接/JA-535 连接面），泄漏在小时级才显现，与 soak 测试实践联动
- **常见误区**：
  1. 功能测试覆盖一切（错）
  2. 长稳测试不必要（错）
  3. 泄漏不存在于 Java（连接池泄漏真实存在）（错）
- **工程用法**：长稳测试
- **版本锚点**：实战共识
