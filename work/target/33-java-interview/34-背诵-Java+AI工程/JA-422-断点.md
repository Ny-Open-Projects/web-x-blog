## 流式 · 断点（续传）

- **事实**：流式中断恢复：SSE Last-Event-ID 语义在 AI 流的应用（重连后从断点续传或整段重生成）
- **原理**：长文本流断网率高，续传省重生成成本（JA-098 取消的对称面），幂等生成（低温+种子）是续传前提
- **常见误区**：
  1. 断流只能整段重来（错）
  2. 续传是前端职责（错）
  3. 幂等生成不必要（错）
- **工程用法**：流式可靠性
- **版本锚点**：实战共识
