## 多模态 · 管线（语音）

- **事实**：语音管线：ASR 转写→LLM 处理→TTS 合成，三段各自选型（转写准/处理强/合成自然）
- **原理**：JA-182 音频能力的工程化组装，分段管线比端到端语音模型可控，转写标点与分段影响下游
- **常见误区**：
  1. 端到端语音模型最优（错）
  2. 三段管线已过时（错）
  3. 转写质量不影响下游（错）
- **工程用法**：语音 Agent 组装
- **版本锚点**：实战共识
