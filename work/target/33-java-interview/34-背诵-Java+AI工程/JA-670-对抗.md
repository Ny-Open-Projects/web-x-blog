## RAG · 对抗（评测）

- **事实**：golden set 对抗增强：加入对抗性查询（同义改写/错别字/口语化/多语言混杂），检索在"脏查询"下的鲁棒性评测
- **原理**：干净查询评测掩盖真实分布（用户查询是脏的 JA-496），对抗样本让评估贴近线上，与注入评估（JA-156）同思想
- **常见误区**：
  1. 干净查询评测足够（错）
  2. 脏查询评测无价值（错）
  3. 对抗样本只测安全（错）
- **工程用法**：检索鲁棒性评测
- **版本锚点**：实战共识
