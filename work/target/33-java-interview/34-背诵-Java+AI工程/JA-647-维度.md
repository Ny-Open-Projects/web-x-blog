## 工程 · 维度（观测）

- **事实**：观测维度全景：租户/业务/模型/区域/环境五维标签体系（所有指标带五维），多维切片分析
- **原理**：标签体系是观测的地基（JA-277/091 的统一），五维切片回答"谁在用/用什么/哪里慢"，与标签设计规范联动
- **常见误区**：
  1. 观测只有时间维度（错）
  2. 五维过多（错）
  3. 标签体系无需设计（错）
- **工程用法**：观测维度体系
- **版本锚点**：实战共识
