## 工程 · map-reduce（摘要）

- **事实**：超长文本摘要链：分段摘要（map）→归并摘要（reduce），突破单次窗口限制
- **原理**：单次窗口装不下的长文档（JA-223 预算超限的解法），链式摘要质量衰减需评估，与分治思想同构
- **常见误区**：
  1. 超窗口只能截断（错）
  2. map-reduce 会丢关键信息（错）
  3. 摘要必须一次完成（错）
- **工程用法**：长文本处理
- **版本锚点**：实战共识
