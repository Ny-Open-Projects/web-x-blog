## 工程 · 模型卡（治理）

- **事实**：内部模型卡：每个接入模型的档案（能力边界/已评测场景/合规状态/负责人/下线计划）
- **原理**：模型卡是治理资产（JA-379 白名单的条目详情），接入评审的产物，与架构决策记录思想联动
- **常见误区**：
  1. 模型卡是外部概念（错）
  2. 内部不需要档案（错）
  3. 卡片与白名单重复（错）
- **工程用法**：模型治理资产
- **版本锚点**：实战共识
