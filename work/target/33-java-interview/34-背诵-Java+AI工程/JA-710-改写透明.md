## RAG · 改写透明（产品）

- **事实**：查询改写透明化：改写后的查询展示给用户（"已将您的查询理解为..."），用户可纠正（纠正=高质量反馈 JA-576）
- **原理**：JA-082 查询改写的产品面：透明化建立信任+获取纠偏信号，纠正是用户参与检索质量的建设，与可编辑反馈（JA-576）同构
- **常见误区**：
  1. 改写对用户隐藏（错）
  2. 透明化降低体验（错）
  3. 纠正无价值（错）
- **工程用法**：改写透明化
- **版本锚点**：实战共识
