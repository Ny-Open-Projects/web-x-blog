## 工程 · 影子库（测试）

- **事实**：影子检索库（JA-498/499）的运营：影子库定期与主库 diff（索引质量漂移检测），影子不是一次性
- **原理**：影子基建的持续运营面：影子库长期存在（新策略持续影子验证），diff 报告驱动切换决策
- **常见误区**：
  1. 影子库用完即弃（错）
  2. 影子与主库一致无需 diff（错）
  3. 运营影子成本高无收益（错）
- **工程用法**：影子运营
- **版本锚点**：实战共识
