## 工程 · 边界（教育）

- **事实**：用户教育页：AI 能力边界说明（会出错/知识截止/不适合的场景），降低误用与投诉（JA-396 深化）
- **原理**：预期管理的产品化：边界页+场景示例+反馈入口，与产品合规（JA-554）联动
- **常见误区**：
  1. 用户自然理解边界（错）
  2. 教育页是装饰（错）
  3. 投诉与预期无关（错）
- **工程用法**：用户预期产品化
- **版本锚点**：实战共识
