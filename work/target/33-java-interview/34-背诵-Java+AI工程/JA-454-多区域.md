## 工程 · 多区域（部署）

- **事实**：多区域部署延迟优化：模型区域就近（JA-267 驻留的延迟面），跨区调用延迟放大 RTT，路由按区域+延迟双维
- **原理**：与 DF-096 跨机房延迟知识同构，驻留合规（JA-267）与延迟优化统一在路由层解决
- **常见误区**：
  1. 区域只影响合规（错）
  2. 延迟与区域无关（错）
  3. 多区域是过度设计（错）
- **工程用法**：全球部署
- **版本锚点**：实战共识
