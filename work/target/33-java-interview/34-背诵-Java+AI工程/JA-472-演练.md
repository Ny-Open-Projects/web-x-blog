## 工程 · 演练（降级）

- **事实**：降级链演练矩阵：主→备模型切换/语义缓存降级/关 AI 功能三级，每级验证用户文案（JA-399）与监控告警
- **原理**：JA-286 演练在降级链的细化，每级独立演练（组合演练加压），与预案分级（JA-382）联动
- **常见误区**：
  1. 降级链演练一次（错）
  2. 三级演练无必要（错）
  3. 用户文案与演练无关（错）
- **工程用法**：降级验证
- **版本锚点**：实战共识
