## 工程 · 技能矩阵（能力）

- **事实**：团队 AI 工程技能矩阵：prompt 工程/评估体系/成本治理/安全合规/Agent 架构五域，按角色定掌握度
- **原理**：AI 工程不是一个人的活（AI-060 Java 定位），矩阵指导招聘与培养，与团队建设思想联动
- **常见误区**：
  1. 一个人全能搞定（错）
  2. 技能矩阵是形式主义（错）
  3. 只有算法岗需要 AI 技能（错）
- **工程用法**：团队建设
- **版本锚点**：实战共识
