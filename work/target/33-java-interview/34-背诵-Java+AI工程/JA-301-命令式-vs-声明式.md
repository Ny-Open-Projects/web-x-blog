## 选型 · 命令式 vs 声明式（范式）

- **事实**：两框架编程范式差异：Spring AI ChatClient 是命令式链（逐步组装请求），LangChain4j AiServices 是声明式接口（注解定义契约）
- **原理**：范式影响代码组织：命令式灵活（动态组装）、声明式简洁（接口即文档），团队风格决定偏好，与 SP-083 联动
- **常见误区**：
  1. 两种范式可以互相替代无差异（错）
  2. 声明式不能动态组装（错）
  3. 范式与可测试性无关（错）
- **工程用法**：范式对比深水区
- **版本锚点**：实战共识
