## MCP · 灰度（生产）

- **事实**：MCP 工具灰度：新工具版本先对部分客户端开放（server 端路由），或新增工具名 v2 并存
- **原理**：工具变更协议化灰度（JA-308 契约演进配套），新旧并存回退容易，与发布灰度（DF-050）同构
- **常见误区**：
  1. MCP 工具无法灰度（错）
  2. 灰度直接全量换（错）
  3. 并存导致混乱（错）
- **工程用法**：MCP 发布纪律
- **版本锚点**：MCP 生产化
