## 治理 · 版权（产权）

- **事实**：生成内容版权归属：企业生成内容的使用权条款（供应商条款审读）+生成物版权风险（相似性审查），法务前置
- **原理**：生成内容知识产权是合规盲区（AI-040 的产权面），供应商条款差异大（商用授权），与 JA-554 行业合规联动
- **常见误区**：
  1. 生成内容版权自动归企业（错）
  2. 条款不用审读（错）
  3. 版权风险不存在（错）
- **工程用法**：生成物产权
- **版本锚点**：实战共识
