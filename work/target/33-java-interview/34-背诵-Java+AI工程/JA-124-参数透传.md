## Spring AI · 参数透传（配置）

- **事实**：spring.ai.openai.chat.options 前缀可透传供应商支持的任意参数
- **原理**：配置与代码 options 双通道：配置给全局默认、代码做运行时覆盖，两层叠加
- **常见误区**：
  1. 配置层参数代码层无法覆盖（错）
  2. 只支持有限白名单参数（错）
  3. 透传参数不生效于 stream（错）
- **工程用法**：全局参数管理
- **版本锚点**：Spring AI 1.0 GA
