## 中台 · 三阶段（演进）

- **事实**：AI 平台化三阶段：直连供应商（业务各自为战）→统一网关（流量收敛）→AI 中台（治理闭环）
- **原理**：演进驱动：业务数增多倒逼收敛（SP-100 演进思想），跳级直上中台是常见失败（无流量数据支撑设计）
- **常见误区**：
  1. 可以直接上中台（错）
  2. 三阶段无先后逻辑（错）
  3. 收敛是成本浪费（错）
- **工程用法**：平台演进路线
- **版本锚点**：实战方法论
