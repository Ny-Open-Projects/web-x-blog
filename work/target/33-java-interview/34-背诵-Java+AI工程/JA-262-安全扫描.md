## 工程 · 安全扫描（流式）

- **事实**：流式输出的安全扫描：敏感词/合规扫描逐段进行（不等全文），命中即截断流
- **原理**：合规要覆盖流式（JA-207 管线的流式版），逐段扫描有误判窗口（上下文被切）需窗口缓冲
- **常见误区**：
  1. 流式内容免检（错）
  2. 等全文再扫描（体验与合规失衡）（错）
  3. 扫描不影响流（错）
- **工程用法**：流式合规
- **版本锚点**：实战共识
