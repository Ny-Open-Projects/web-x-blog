## 质量 · 细则（判分）

- **事实**：judge 评分细则设计：维度拆分（事实性/完整性/语言）+每档锚定描述+少样本判例，细则即 prompt
- **原理**：judge 质量=细则质量（JA-363 深化），细则迭代与业务 prompt 同纪律，判分漂移监控（JA-347）
- **常见误区**：
  1. judge 直接打 1-10 分最准（错）
  2. 细则不重要（错）
  3. 判例是可选装饰（错）
- **工程用法**：判分工程
- **版本锚点**：实战共识
