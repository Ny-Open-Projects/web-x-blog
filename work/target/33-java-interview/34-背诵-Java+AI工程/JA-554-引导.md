## 行业 · 引导（教育）

- **事实**：教育场景苏格拉底式：prompt 约束模型引导思考而非直接给答案（分步提示/反问），教学目标决定交互设计
- **原理**："直接给答案"损害学习目标（场景特殊性），prompt 约束+输出校验（不得含完整答案），与 prompt 工程（AI-023）联动
- **常见误区**：
  1. 教育场景直接给答案效率高（错）
  2. 引导模式无法约束（错）
  3. 场景不影响 prompt（错）
- **工程用法**：教育场景设计
- **版本锚点**：实战共识
