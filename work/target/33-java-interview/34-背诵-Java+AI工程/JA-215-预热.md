## RAG · 预热（冷启动）

- **事实**：检索冷启动预热：服务启动后用高频查询预热向量库连接与缓存
- **原理**：首波流量检索延迟毛刺（连接建立/缓存冷），与缓存预热（RD-066）同构
- **常见误区**：
  1. 冷启动无影响（错）
  2. 预热是可选装饰（错）
  3. 预热一次永久有效（错）
- **工程用法**：延迟稳定性
- **版本锚点**：实战共识
