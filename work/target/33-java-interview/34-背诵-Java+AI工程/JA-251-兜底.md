## RAG · 兜底（降级）

- **事实**：检索链路降级：向量库故障时降级到 ES 关键词检索或无 RAG 直答模式（标记降级降低预期）
- **原理**：RAG 是强依赖（JA-154 熔断的特化），降级模式让服务不断，质量损失向用户透明化
- **常见误区**：
  1. 向量库挂了就全停（错）
  2. 降级模式不需要标记（错）
  3. 关键词检索能完全替代（错）
- **工程用法**：RAG 高可用
- **版本锚点**：实战共识
