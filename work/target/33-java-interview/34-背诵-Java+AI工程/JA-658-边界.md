## 工程 · 边界（知识）

- **事实**：AI 知识地图的边界意识：框架/协议/管道快速演进（本域事实半年半衰期风险），复习锚定"原理与模式"而非"API 细节"（API 以官方文档为准）
- **原理**：知识半衰期的诚实认知（JA-060 版本锚定的原因），记忆策略：模式入脑、API 查文档，与学习方法论联动
- **常见误区**：
  1. 所有知识同等记忆（错）
  2. API 细节要背（错）
  3. 半衰期不影响学习（错）
- **工程用法**：知识保鲜策略
- **版本锚点**：实战方法论
