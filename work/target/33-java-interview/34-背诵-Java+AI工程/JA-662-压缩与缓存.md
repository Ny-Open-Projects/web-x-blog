## 工程 · 压缩与缓存（交互）

- **事实**：prompt 压缩与供应商缓存命中的冲突：压缩改变前缀破坏缓存命中，两者收益互斥需权衡
- **原理**：JA-269 压缩与 JA-279 prompt cache 的交互冲突：压缩省 token 但丢缓存折扣，按量测数据决策（压缩后净成本）
- **常见误区**：
  1. 压缩与缓存可兼得（错）
  2. 冲突不存在（错）
  3. 永远选压缩（错）
- **工程用法**：两者权衡
- **版本锚点**：实战共识
