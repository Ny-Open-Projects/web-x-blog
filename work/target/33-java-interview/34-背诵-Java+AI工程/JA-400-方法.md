## 工程 · 方法（压测）

- **事实**：AI 链路压测方法：mock 模型压测应用层（连接池/线程池/流式并发），真实模型小流量压测（成本控制），两层压测
- **原理**：供应商不能承受全量压测（JA-059 配额），mock 压应用、真实压小流量，与 MY-092 压测基线联动
- **常见误区**：
  1. 压测直接打真实模型（错）
  2. mock 压测无价值（错）
  3. 两层压测是过度设计（错）
- **工程用法**：压测方法论
- **版本锚点**：实战共识
