## LangChain4j · 属性前缀（Spring）

- **事实**：langchain4j-open-ai-spring-boot-starter 的配置属性前缀 langchain4j.open-ai.chat-model（api-key/model-name/temperature）
- **原理**：Spring 集成下属性与 builder 参数一一对应，自动装配 ChatLanguageModel bean 直接注入使用
- **常见误区**：
  1. 属性前缀是 spring.ai.open-ai（错）
  2. 无法配 temperature（错）
  3. 属性只支持 api-key（错）
- **工程用法**：Spring 配置管理
- **版本锚点**：LangChain4j 1.0
