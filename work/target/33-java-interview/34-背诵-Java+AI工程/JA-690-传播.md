## 缓存 · 传播（失效）

- **事实**：语义缓存失效传播：知识库更新（JA-668）时清受影响域的语义缓存（旧答案残留=脏），按域标签清
- **原理**：缓存与知识一致性（JA-456 的语义缓存版）：全清简单但昂贵，按域标签精准清，与失效传播思想联动
- **常见误区**：
  1. 语义缓存永不过期（错）
  2. 全清是唯一方案（错）
  3. 精准清不可实现（错）
- **工程用法**：失效传播
- **版本锚点**：实战共识
