## 工程 · 批大小（嵌入）

- **事实**：嵌入批量调用的批大小权衡：单批过大易触供应商限制，分批控制并行度，失败批重试幂等（嵌入天然幂等）
- **原理**：批量入库（万级文档）的吞吐工程，与 MY-051 拆批思想同构，批大小按供应商限制定
- **常见误区**：
  1. 嵌入批量无大小限制（错）
  2. 批越大越好（错）
  3. 批量调用不需要重试（错）
- **工程用法**：入库吞吐工程
- **版本锚点**：实战共识
