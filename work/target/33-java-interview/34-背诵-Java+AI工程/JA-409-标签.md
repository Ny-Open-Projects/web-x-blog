## 工程 · 标签（数据）

- **事实**：训练边界的数据面：明确哪些数据可进供应商（分级矩阵 JA-380），哪些必须私有化模型处理，数据流向图定期审计
- **原理**：数据流向可视化（AI-040 的工程化），流向图是安全审计的底图（JA-394 出口隔离配套），与数据治理联动
- **常见误区**：
  1. 数据流向不需要图（错）
  2. 分级矩阵覆盖全部场景（错）
  3. 审计是年度形式（错）
- **工程用法**：数据流向治理
- **版本锚点**：实战共识
