## 工程 · 超时（工具）

- **事实**：工具执行超时独立配置：单个工具超时（业务工具可能调慢下游）独立于 LLM 调用超时
- **原理**：工具链路含业务下游（DB/RPC），工具超时是熔断粒度的一部分（JA-154 联动），超限返回错误反馈给模型
- **常见误区**：
  1. 工具超时与模型相同（错）
  2. 工具不会超时（错）
  3. 超时后模型自动等待（错）
- **工程用法**：工具可靠性
- **版本锚点**：实战共识
