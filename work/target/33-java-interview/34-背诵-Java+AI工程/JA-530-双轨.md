## 工程 · 双轨（评审）

- **事实**：prompt 变更双轨评审：技术评审（工程正确性）+内容评审（业务语义/合规），两轨会签
- **原理**：prompt 是"代码+文案"双重属性（JA-025 变更纪律深化），单轨评审漏一半，与变更管理联动
- **常见误区**：
  1. prompt 技术评审足够（错）
  2. 内容评审是业务的事（业务必须参与）（错）
  3. 双轨拖慢迭代（错）
- **工程用法**：prompt 评审设计
- **版本锚点**：实战共识
