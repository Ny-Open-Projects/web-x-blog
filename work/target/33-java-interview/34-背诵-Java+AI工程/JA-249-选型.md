## RAG · 选型（隔离）

- **事实**：多租户向量隔离选型：海量租户用 filter 隔离（单库），高 SLA 租户独立库，按规模与隔离强度分级
- **原理**：JA-159 并存能力的选型决策面：过滤便宜但共享容量，独立库强隔离高成本
- **常见误区**：
  1. 所有租户都独立库（错）
  2. 过滤隔离强度足够所有场景（错）
  3. 隔离只有一种形态（错）
- **工程用法**：租户隔离选型
- **版本锚点**：实战共识
