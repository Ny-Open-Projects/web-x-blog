## 提示词 · 负面示例（负面）

- **事实**：prompt 中使用负面示例（"不要输出 X"）效果弱于正面示例（"输出 Y 格式"），负面清单作辅助
- **原理**：模型对"不要"指令遵循弱（训练分布偏正面示例），正面示例优先、负面补充，与 few-shot（JA-443）联动
- **常见误区**：
  1. 负面示例最有效（错）
  2. 负面与正面等效（错）
  3. 负面示例无用（错）
- **工程用法**：提示词技巧
- **版本锚点**：实战共识
