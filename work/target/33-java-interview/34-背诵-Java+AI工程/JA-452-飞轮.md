## 工程 · 飞轮（数据）

- **事实**：数据飞轮：用户修正（改写后的答案）入 few-shot 库（JA-443）与评估集（JA-179）双通道，产品越用越准
- **原理**：数据飞轮是 AI 产品的护城河（AI-057 数据面），修正数据质量高于标注（真实意图），与隐私脱敏（JA-198）联动
- **常见误区**：
  1. 飞轮自动运转无需设计（错）
  2. 修正数据无价值（错）
  3. 飞轮与评估无关（错）
- **工程用法**：数据飞轮
- **版本锚点**：实战共识
