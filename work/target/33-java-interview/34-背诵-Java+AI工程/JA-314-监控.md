## MCP · 监控（生产）

- **事实**：MCP server 监控：工具级 QPS/延迟/错误率/参数校验失败率，工具维度大盘
- **原理**：工具是"远程函数"（JA-026），监控粒度到工具才能定位坏工具，与 DF-092 指标体系联动
- **常见误区**：
  1. 监控只看进程存活（错）
  2. 工具级监控无意义（错）
  3. 错误率是唯一指标（错）
- **工程用法**：MCP 可观测
- **版本锚点**：MCP 生产化
