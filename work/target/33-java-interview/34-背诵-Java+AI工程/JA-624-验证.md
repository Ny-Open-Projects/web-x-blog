## Agent · 验证（拆分）

- **事实**：LLM 子任务拆分的质量验证：拆分结果（子任务列表）经规则/小模型校验（覆盖率/依赖闭环），防拆丢需求
- **原理**：拆解质量决定 Agent 上限（AI-057），拆分本身要用评估（拆分评估集），验证不通过重拆或人工
- **常见误区**：
  1. 拆分结果直接信任（错）
  2. 拆分不需要验证（错）
  3. 规则无法验证拆分（错）
- **工程用法**：拆解质量门
- **版本锚点**：实战共识
