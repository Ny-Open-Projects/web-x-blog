## 安全 · 层级（指令）

- **事实**：指令层级与注入面：system > user 的优先级是模型约定，注入攻击就是把恶意指令伪装成 system 级内容
- **原理**：理解优先级才能设计防线（JA-225 边界标签的原理），外部内容永远在 user/data 层
- **常见误区**：
  1. user 可以覆盖 system（错）
  2. 层级是框架概念（错）
  3. 注入与层级无关（错）
- **工程用法**：指令安全模型
- **版本锚点**：实战共识
