## MCP · 三原语（能力族）

- **事实**：MCP 三类核心能力原语：tools（可执行）、resources（可读取）、prompts（可复用提示模板）
- **原理**：工具之外的资源读取与提示模板复用同样是协议能力，只知 tools 是常见认知盲区
- **常见误区**：
  1. MCP 只有 tools 一种能力（错）
  2. resources 是数据库连接（错）
  3. prompts 是系统日志（错）
- **工程用法**：协议能力全景
- **版本锚点**：MCP 规范
