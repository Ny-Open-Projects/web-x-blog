## 质量 · 雷达图（报告）

- **事实**：多维评估雷达图报告：质量/安全/成本/延迟/稳定性五维，版本对比可视化
- **原理**：单一分数掩盖短板（JA-414 多维的呈现面），雷达图让 trade-off 一眼可见，报告进发布评审
- **常见误区**：
  1. 评估报告只有一个总分（错）
  2. 雷达图是装饰（错）
  3. 报告不进评审（错）
- **工程用法**：评估呈现
- **版本锚点**：实战共识
