## 工程 · 协作（组织）

- **事实**：AI 工程协作面：业务（需求/反馈）×工程（实现/可靠性）×算法（模型/评估）×安全（合规/红队）四方协作界面
- **原理**：JA-342 技能矩阵的组织面，界面清晰防"都管都不管"，与康威定律（DF-084）联动
- **常见误区**：
  1. AI 工程一个人搞定（错）
  2. 协作界面无需定义（错）
  3. 四方只有工程算法（错）
- **工程用法**：组织协作设计
