## 质量 · 新奇（效应）

- **事实**：新奇效应（novelty effect）：新功能/新模型初期指标虚高（用户新鲜感），需观察衰减后曲线再下结论
- **原理**：A/B 早期数据不可信（JA-271 的时间维度），观察 1-2 周衰减曲线，与实验纪律联动
- **常见误区**：
  1. 初期数据可靠（错）
  2. 新奇效应不存在（错）
  3. 结论可以当天出（错）
- **工程用法**：实验时间窗
- **版本锚点**：实战共识
