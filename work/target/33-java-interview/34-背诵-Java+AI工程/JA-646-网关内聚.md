## 工程 · 网关内聚（架构）

- **事实**：网关内部模块：协议层/策略层（限流/鉴权）/路由层/供应商适配层，四层内聚各可独立测试
- **原理**：JA-317 六职责的模块化落地，层内高内聚层间低耦合，与分层架构（DF-081）联动
- **常见误区**：
  1. 网关单体一把梭（错）
  2. 四层划分是过度设计（错）
  3. 模块不可独立测试（错）
- **工程用法**：网关内部架构
- **版本锚点**：实战共识
