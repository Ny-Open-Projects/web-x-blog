## 工程 · 记忆隔离（测试）

- **事实**：记忆隔离测试用例：并发两 memoryId 交替写入，断言互不污染
- **原理**：防串号（JA-097/135）的专项测试，竞态窗口在并发写入时暴露，与并发测试知识联动
- **常见误区**：
  1. 隔离靠框架保证无需测试（错）
  2. 串号只发生在单线程（错）
  3. 测试用例写不出来（错）
- **工程用法**：租户隔离验证
- **版本锚点**：实战共识
