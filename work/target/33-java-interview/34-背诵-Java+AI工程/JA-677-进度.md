## Agent · 进度（体验）

- **事实**：长任务阶段汇报：Agent 每完成阶段发进度事件（已完成/进行中/预计剩余），用户可中途干预
- **原理**：长任务的可感知性（JA-425 多路流的应用），进度事件协议化（阶段/百分比/摘要），无进度=用户流失
- **常见误区**：
  1. 长任务黑盒即可（错）
  2. 进度事件无价值（错）
  3. 汇报增加成本（错）
- **工程用法**：进度感知设计
- **版本锚点**：实战共识
