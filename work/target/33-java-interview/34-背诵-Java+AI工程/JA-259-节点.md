## Agent · 节点（人审）

- **事实**：人审节点落地：Agent 状态机插入 WAITING_APPROVAL 状态，审批 UI + 超时策略（超时自动拒绝或升级）
- **原理**：AI-068 审批的工程化，高危操作（AI-235 越权防线之外的第二道）挂审批，超时策略防任务悬挂
- **常见误区**：
  1. 审批节点可有可无（错）
  2. 超时自动批准（错）
  3. 审批不落轨迹（错）
- **工程用法**：人机协作落地
- **版本锚点**：实战共识
