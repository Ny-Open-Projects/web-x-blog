## 工程 · 拨测（监控）

- **事实**：供应商 SLA 拨测：独立探针定时调模型 API（最小请求），监控可用性/延迟基线，与内部监控分离
- **原理**：外部视角可用性（JA-055 降级决策的数据源），内部调用正常不代表供应商健康，与拨测监控思想联动
- **常见误区**：
  1. 供应商健康靠用户反馈（错）
  2. 拨测浪费 token（极小成本）（错）
  3. 内外监控是一回事（错）
- **工程用法**：供应商可观测
- **版本锚点**：实战共识
