## 工程 · 环境隔离（配置）

- **事实**：模型配置环境隔离：dev 用本地 Ollama、prod 用云模型，profile 切换零代码改动
- **原理**：成本与隐私分级（AI-055/056 联动），Spring profile 与属性覆盖是载体（SP-030），与 DF/云原生联动
- **常见误区**：
  1. 所有环境用同一配置（错）
  2. dev 也必须用云模型（错）
  3. 环境切换需要改代码（错）
- **工程用法**：环境策略
- **版本锚点**：实战共识
