## 工程 · 规范（团队）

- **事实**：AI 生成代码入库规范：AI 代码同样过 review+测试+扫描（JA-036），标注 AI 生成比例（可追溯），依赖幻觉 API 检查

- **常见误区**：
  1. AI 代码质量高于人工（错）
  2. 规范只约束人写代码（错）
  3. 标注比例无意义（错）
