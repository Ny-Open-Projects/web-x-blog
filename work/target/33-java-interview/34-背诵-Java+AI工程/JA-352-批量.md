## LangChain4j · 批量（向量）

- **事实**：LC4j embeddingStore.addAll 批量写入（配 embedAll 批量嵌入），与 Spring AI add 对等
- **原理**：两框架批量入库 API 对等（JA-351），生产入库管道实现任选，分批与幂等策略相同
- **常见误区**：
  1. LC4j 无批量接口（错）
  2. 批量必须逐条（错）
  3. 对等实现有差异（错）
- **工程用法**：批量入库对等
- **版本锚点**：LangChain4j 1.0
