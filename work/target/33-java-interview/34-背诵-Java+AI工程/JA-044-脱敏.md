## 工程 · 脱敏（日志）

- **事实**：LLM 应用日志纪律：prompt 与输出不得全量落日志（含用户隐私与业务数据）
- **原理**：日志里的 prompt 即数据出域（合规 AI-040），脱敏或采样记录，异常排障用 traceId 关联而非全文
- **常见误区**：
  1. prompt 全量落日志便于排查（错）
  2. 日志无合规要求（错）
  3. 脱敏会破坏排障能力（错）
- **工程用法**：合规与排障平衡
- **版本锚点**：实战共识
