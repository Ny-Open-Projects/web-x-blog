## MCP · 超时（生产）

- **事实**：MCP 工具超时分层：连接超时/工具执行超时/整体会话超时三层配置
- **原理**：工具含业务下游（JA-275 工具超时知识），MCP 层再加一层网络超时，三层独立调参
- **常见误区**：
  1. 超时只有一层（错）
  2. 工具执行超时不可配（错）
  3. 整体会话无超时（错）
- **工程用法**：MCP 超时体系
- **版本锚点**：MCP 生产化
