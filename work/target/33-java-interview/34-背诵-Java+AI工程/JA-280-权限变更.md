## 工程 · 权限变更（知识）

- **事实**：知识库权限变更同步机制：权限标签变更事件→向量元数据批量更新→抽查验证，滞后窗口监控
- **原理**：AI-214 的机制化：事件驱动（MQ）而非定时全量，与 CDC 思想（RD-046）同构
- **常见误区**：
  1. 权限同步定时全量即可（错）
  2. 变更事件不可靠（错）
  3. 滞后无需监控（错）
- **工程用法**：权限同步工程
- **版本锚点**：实战共识
