## 工程 · 端点（健康）

- **事实**：健康检查端点分层：应用自身健康（/health）与供应商健康（拨测 JA-273）分开暴露，K8s 探针只看自身
- **原理**：探针设计纪律：供应商抖动不应导致 Pod 重启（探针挂供应商会雪崩重启），与 K8s 探针知识（DF-097）联动
- **常见误区**：
  1. 健康检查合并供应商（错）
  2. 探针随便配（错）
  3. 分层无必要（错）
- **工程用法**：健康检查设计
- **版本锚点**：实战共识
