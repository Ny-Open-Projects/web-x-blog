## 工程 · 一致（人设）

- **事实**：客服人设一致性：人设 prompt（语气/边界/禁语）+少样本对话锚定+输出扫描（禁语检测），人设漂移检测
- **原理**：角色扮演一致性（JA-558 NPC 同思想在客服域），人设是产品资产（JA-473 库管理），漂移进评估集（JA-179）
- **常见误区**：
  1. 人设写在提示词就稳（错）
  2. 漂移不存在（错）
  3. 人设不需要资产化（错）
- **工程用法**：人设工程
- **版本锚点**：实战共识
