## Agent · 日志脱敏（工具）

- **事实**：工具调用日志脱敏：工具参数/结果含敏感数据（客户信息）时脱敏落日志（JA-044 的工具面）
- **原理**：工具日志是敏感数据重灾区（参数含身份证/账号），脱敏规则按工具声明，与审计（JA-312）平衡
- **常见误区**：
  1. 工具日志全量即可（错）
  2. 脱敏只对 prompt（错）
  3. 工具日志与隐私无关（错）
- **工程用法**：工具日志治理
- **版本锚点**：实战共识
