## 数据 · 标签（时效）

- **事实**：知识时效标签强制：入库时标记更新频率（日更/月更/静态），驱动检索衰减（JA-248）与缓存 TTL（JA-456）
- **原理**：时效策略的数据基础，无标签则衰减/TTL 无法差异化，入库表单强制字段
- **常见误区**：
  1. 时效标签可选（错）
  2. 所有知识同频更新（错）
  3. 标签不影响策略（错）
- **工程用法**：时效数据治理
- **版本锚点**：实战共识
