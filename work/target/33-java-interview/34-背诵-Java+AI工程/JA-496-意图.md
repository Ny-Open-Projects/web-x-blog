## 数据 · 意图（聚类）

- **事实**：用户查询聚类：发现意图分布与新需求（高频无覆盖查询=知识缺口）
- **原理**：查询聚类暴露知识库盲区（JA-440 冷启动的持续面），缺口驱动语料补齐优先级，与数据挖掘知识联动
- **常见误区**：
  1. 查询分析无价值（错）
  2. 知识缺口靠猜（错）
  3. 聚类需要标注（无监督聚类可行）（错）
- **工程用法**：意图挖掘
- **版本锚点**：实战共识
