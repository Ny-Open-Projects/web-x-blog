## 质量 · 质量换延迟（权衡）

- **事实**：质量-延迟联合优化：低端场景降模型/减 topK 换延迟（体验敏感路径），高端场景反之
- **原理**：JA-403 帕累托的场景化：不同路径不同配置（客服寒暄 vs 技术问答），路径级配置矩阵
- **常见误区**：
  1. 全场景统一配置（错）
  2. 质量优先永远正确（错）
  3. 延迟与质量无关（错）
- **工程用法**：路径级优化
- **版本锚点**：实战共识
