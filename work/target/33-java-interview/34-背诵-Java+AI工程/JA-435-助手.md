## 场景 · 助手（代码）

- **事实**：代码助手场景架构差异：补全要求毫秒级（小模型+本地缓存+前缀匹配），对话式助手秒级可接受
- **原理**：场景决定延迟预算（AI-030），补全与对话是两种延迟档位的产品（JA-423 TTFT），混用导致体验失败
- **常见误区**：
  1. 代码补全与大模型对话同架构（错）
  2. 补全不需要本地缓存（错）
  3. 延迟要求相同（错）
- **工程用法**：场景延迟档位
- **版本锚点**：实战共识
