## 工程 · HTTP2（网络）

- **事实**：HTTP/2 对流式的影响：多路复用避免队头阻塞（H1 同连接串行响应），LLM 客户端建议启用 H2
- **原理**：流式并发场景（JA-425 多路流）的传输层基础，H1 下并发流会阻塞，客户端/网关协商 H2
- **常见误区**：
  1. HTTP 版本无影响（错）
  2. H1 与 H2 流式一致（错）
  3. 强制 H1 更稳（错）
- **工程用法**：传输层优化
- **版本锚点**：实战共识
