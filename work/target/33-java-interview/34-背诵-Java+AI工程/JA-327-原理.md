## Spring AI · 原理（装配）

- **事实**：Spring AI 自动装配原理：starter 经条件注解（@ConditionalOnClass/@ConditionalOnProperty）装配 ChatModel 与 Builder
- **原理**：与 SP-031 条件装配同机制（spring.ai.model 属性选择 provider，JA-047），理解装配链才能排查"bean 不存在"问题
- **常见误区**：
  1. 自动装配是魔法无机制（错）
  2. 条件注解不适用 AI starter（错）
  3. 装配与 Spring 无关（错）
- **工程用法**：装配原理
- **版本锚点**：Spring AI 1.0 GA
