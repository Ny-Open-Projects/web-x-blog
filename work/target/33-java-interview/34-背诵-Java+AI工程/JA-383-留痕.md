## 中台 · 留痕（合规）

- **事实**：合规留痕年限：prompt/输出/工具调用记录按合规要求保留 N 年（审计可回放），到期清理
- **原理**：JA-198 保留策略的年限面，存储成本与合规要求平衡（冷存储归档），与备份保留（RD-094 RPO）思想同构
- **常见误区**：
  1. 日志保留越久越好（错）
  2. 保留年限随意定（错）
  3. 到期数据不清理（错）
- **工程用法**：合规存储治理
- **版本锚点**：实战共识
