## RAG · 预算（重排）

- **事实**：rerank 调用预算：重排模型的调用量（每次检索 topN 候选）单独计量与配额，rerank 是隐藏成本项
- **原理**：JA-102 重排的成本面：重排模型按候选数计费，高频检索场景成本可观，预算与配额管理（JA-461）联动
- **常见误区**：
  1. 重排免费（错）
  2. 成本只算生成模型（错）
  3. 预算只管 chat（错）
- **工程用法**：重排成本
- **版本锚点**：实战共识
