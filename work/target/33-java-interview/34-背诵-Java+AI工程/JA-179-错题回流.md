## 工程 · 错题回流（复盘）

- **事实**：AI 应用错题回流机制：线上失败/差评样本进入评估集（脱敏后），评估集持续长大
- **原理**：评估集是活资产（AI-012），回流让门禁覆盖真实失败模式，与 MQ 复盘思想（MQ-075）同构
- **常见误区**：
  1. 评估集静态不更新（错）
  2. 线上样本直接入库不脱敏（错）
  3. 回流与门禁无关（错）
- **工程用法**：质量飞轮
- **版本锚点**：实战共识
