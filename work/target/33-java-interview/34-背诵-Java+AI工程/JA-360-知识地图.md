## 工程 · 知识地图（收束）

- **事实**：Java AI 工程知识地图收束：框架双栈（Spring AI/LC4j）→MCP 协议→RAG 管道→Agent 骨架→中间件（网关/缓存/配额）→治理（评估/成本/安全/观测）
- **原理**：300 条事实的组织框架，复习按地图走而非线性（JA-180 答题主线的展开），与 MY-109 复习主线同构
- **常见误区**：
  1. 知识是碎片无需地图（错）
  2. 地图只适合入门（错）
  3. 治理与框架无关（错）
- **工程用法**：本域知识地图
- **版本锚点**：实战方法论
