## Agent · 分层落地（记忆）

- **事实**：Agent 记忆三分层落地：短期=消息窗口（JA-008）、任务=状态机字段（JA-255）、长期=向量库检索（用户偏好/历史结论）
- **原理**：AI-020 的 Java 组件映射，三层的读写时机与清理策略（JA-261）不同，设计期明确归属
- **常见误区**：
  1. 三层记忆混在一个窗口（错）
  2. 长期记忆是聊天记录（错）
  3. 分层无必要（错）
- **工程用法**：记忆架构
- **版本锚点**：实战共识
