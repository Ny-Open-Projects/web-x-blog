## 工程 · 数据最小化（安全）

- **事实**：数据最小化原则在 AI 的落地：prompt 只带完成任务必需的数据（不塞全量上下文），检索按需注入
- **原理**：最小化是隐私保护第一原则（AI-049/061 的 prompt 面），塞全量数据是"方便"驱动的反模式，与最小权限（DF）联动
- **常见误区**：
  1. prompt 数据越多越好（错）
  2. 最小化影响质量（按需检索平衡）（错）
  3. 原则只适用数据库（错）
- **工程用法**：数据最小化
- **版本锚点**：实战共识
