## 网关 · 探测（健康）

- **事实**：网关对上游的失败率探测：按供应商维度滑动窗口错误率，超阈标记不健康（路由降权的输入）
- **原理**：JA-321 降级路由的探测数据面：健康标记是路由决策的实时输入，与拨测（JA-273）互补（被动+主动）
- **常见误区**：
  1. 路由不依赖健康探测（错）
  2. 探测与路由无关（错）
  3. 失败率无法按供应商统计（错）
- **工程用法**：健康探测
- **版本锚点**：实战共识
