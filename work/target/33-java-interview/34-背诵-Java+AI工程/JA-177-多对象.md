## LangChain4j · 多对象（工具）

- **事实**：AiServices.tools(...) 可挂多个工具对象（按类分组组织工具族）
- **原理**：工具量大时按业务域拆类（订单工具/库存工具），框架聚合注册，与舱壁隔离思想（DF-027）呼应
- **常见误区**：
  1. 只能挂一个工具对象（错）
  2. 多对象会互相覆盖（错）
  3. 工具必须单类（错）
- **工程用法**：工具组织规范
- **版本锚点**：LangChain4j 1.0
