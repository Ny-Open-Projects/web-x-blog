## Agent · 冲突（并发）

- **事实**：多 Agent 并发写冲突：两个 Agent 修改同一资源（库存/工单），锁或幂等或资源级串行化
- **原理**：多 Agent 并发的正确性（JA-258 并行工具的资源面），与 DB 并发控制思想同构（乐观锁 JA-078 联动）
- **常见误区**：
  1. 多 Agent 不会写冲突（错）
  2. 冲突靠提示词避免（错）
  3. 锁影响性能不用（错）
- **工程用法**：并发正确性
- **版本锚点**：实战共识
