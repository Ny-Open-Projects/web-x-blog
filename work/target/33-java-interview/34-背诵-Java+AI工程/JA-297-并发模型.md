## 工程 · 并发模型（容量）

- **事实**：LLM 应用的并发模型选择：WebFlux 全链路响应式 vs MVC+SseEmitter 桥接，按团队技术栈与生态选
- **原理**：两种模式都能做流式（JA-169），响应式吞吐优但调试成本高（SP-082），虚拟线程（SP-083）是第三选项
- **常见误区**：
  1. 必须全链路响应式（错）
  2. MVC 做不了流式（错）
  3. 三种模式性能相同（错）
- **工程用法**：并发架构选型
- **版本锚点**：实战共识
