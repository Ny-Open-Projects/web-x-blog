## 工程 · 告警（观测）

- **事实**：告警分级与路由：P0（全不可用）电话、P1（降级生效）IM 即时、P2（质量下滑）日报、P3（成本）周报
- **原理**：JA-382 事故分级的告警路由面，分级匹配响应节奏（DF-074），告警风暴防（聚合/静默 DF-072）
- **常见误区**：
  1. 告警全部即时推送（错）
  2. 分级是形式主义（错）
  3. 告警不需要路由（错）
- **工程用法**：告警体系
- **版本锚点**：实战共识
