## 工程 · 评估成本（CI）

- **事实**：CI 中评估的成本控制：全量评估集按变更影响抽样跑（prompt 变更跑相关域子集）
- **原理**：评估集越大 CI 越贵越慢（AI-058），抽样+变更映射是平衡，发布前可全量补跑
- **常见误区**：
  1. CI 必须全量评估（错）
  2. 评估不进 CI（错）
  3. 抽样会漏问题（按影响面映射可控）（错）
- **工程用法**：CI 效率设计
- **版本锚点**：实战共识
