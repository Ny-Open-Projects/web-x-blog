## 工程 · SLO（验收）

- **事实**：AI 功能 SLO 定义：回答准确率（评估集代理）、P99 延迟、可用性、成本上限四维 SLO
- **原理**：把 AI 功能当服务治理（DF-056），四维分别有数据源（评估/监控/账单），缺维则治理盲区
- **常见误区**：
  1. AI 功能不需要 SLO（错）
  2. 准确率无法定义 SLO（错）
  3. 只有延迟重要（错）
- **工程用法**：SLO 设计
- **版本锚点**：实战共识
