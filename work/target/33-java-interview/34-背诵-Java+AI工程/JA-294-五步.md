## 工程 · 五步（上线）

- **事实**：AI 功能上线五步：评估集门禁（AI-058）→影子双发（JA-234）→小流量灰度（JA-205）→看板监控（JA-289）→错题回流（JA-179）
- **原理**：把发布链路串成 SOP，每步有工具支撑，与完整发布体系（DF-050/051）同构
- **常见误区**：
  1. 上线直接全量（错）
  2. 五步是形式主义（错）
  3. 只做评估就够（错）
- **工程用法**：发布 SOP
- **版本锚点**：实战方法论
