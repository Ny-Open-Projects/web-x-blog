## RAG · 多路聚合（聚合）

- **事实**：多路召回结果聚合：去重（同源片段）、按来源加权、截断组合，LC4j 的 ContentAggregator 抽象支撑
- **原理**：多 retriever（向量+关键词+多库）结果需统一归并才能注入，聚合策略决定最终上下文质量
- **常见误区**：
  1. 聚合就是简单 concat（错）
  2. 去重不需要（错）
  3. 聚合在模型侧自动完成（错）
- **工程用法**：多路召回编排
- **版本锚点**：实战共识
