## 工程 · 分层（配置）

- **事实**：AI 配置分层架构：供应商配置（key/base-url）/行为配置（温度/模型）/业务配置（prompt 版本/路由规则）三层分文件分权限
- **原理**：配置分层与权限分离（供应商密钥只有平台可改），变更频率不同层不同（密钥低频 prompt 高频），与配置治理（DF-106）联动
- **常见误区**：
  1. 配置一个文件全放（错）
  2. 分层是过度设计（错）
  3. 权限与配置无关（错）
- **工程用法**：配置架构
- **版本锚点**：实战共识
