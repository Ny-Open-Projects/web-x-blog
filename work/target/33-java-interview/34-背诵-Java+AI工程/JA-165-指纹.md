## 工程 · 指纹（排障）

- **事实**：prompt 指纹排障：全量 prompt 不落日志，但记录 prompt hash 与长度，问题复现时按指纹比对
- **原理**：合规（JA-044）与排障的平衡手法，指纹定位"同一请求是否变化"，与可观测三支柱联动
- **常见误区**：
  1. prompt 必须全量落日志（错）
  2. 指纹无排查价值（错）
  3. 两者不可兼得（错）
- **工程用法**：合规排障平衡
- **版本锚点**：实战共识
