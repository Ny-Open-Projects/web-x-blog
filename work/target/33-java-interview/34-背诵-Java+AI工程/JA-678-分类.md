## Agent · 分类（失败）

- **事实**：Agent 失败三分类：工具失败（外部依赖）→重试/换工具；规划失败（步骤错）→重规划；验证失败（结果不对）→回炉，分类驱动恢复策略
- **原理**：JA-505 补偿的精细化前置：不同失败恢复动作不同（与 MY-082 分级同思想），失败分类先于恢复设计
- **常见误区**：
  1. Agent 失败统一重试（错）
  2. 三分类是过度设计（错）
  3. 失败原因无法判别（错）
- **工程用法**：失败分类学
- **版本锚点**：实战共识
