## Spring AI · 桥接（MCP）

- **事实**：MCP 工具经 ToolCallbackProvider 桥接进 ChatClient.tools(...)（SyncMcpToolCallbackProvider 包装 McpSyncClient）
- **原理**：桥接后 MCP 工具与本地 @Tool 工具同池调用，Agent 双工具来源（JA-054 对应 LC4j 侧）
- **常见误区**：
  1. MCP 工具需要重写成 @Tool（错）
  2. 桥接层不存在（错）
  3. 两来源互斥（错）
- **工程用法**：MCP 工具进 Agent
- **版本锚点**：Spring AI 1.0 GA
