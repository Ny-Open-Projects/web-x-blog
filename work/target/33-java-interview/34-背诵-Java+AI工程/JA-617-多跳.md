## RAG · 多跳（进阶）

- **事实**：多跳检索：复杂问题拆解为多轮检索（检索→中间推理→再检索），迭代直到信息足够
- **原理**：单轮检索解决不了多跳问题（AI-044 GraphRAG 的轻量替代），迭代检索用 Agent 循环（JA-053）承载，成本与精度权衡
- **常见误区**：
  1. 单轮检索够用（错）
  2. 多跳检索无法实现（错）
  3. 迭代无上限（错）
- **工程用法**：多跳检索设计
- **版本锚点**：实战共识
