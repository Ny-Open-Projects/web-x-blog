## 工程 · 防串号（租户）

- **事实**：多租户上下文传递纪律：advisor 参数/ToolContext/MDC 三层都按会话与用户键隔离，测试覆盖并发两用户互不串
- **原理**：AI 上下文串号是高危事故（泄露他人数据），与 AI-085 并发隔离知识联动，review 专项检查项
- **常见误区**：
  1. 上下文框架自动隔离（错）
  2. 串号只影响日志（错）
  3. 并发下无需测试串号（错）
- **工程用法**：租户隔离红线
- **版本锚点**：实战共识
