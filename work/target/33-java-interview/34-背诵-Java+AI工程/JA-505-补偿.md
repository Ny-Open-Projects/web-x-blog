## Agent · 补偿（失败）

- **事实**：Agent 失败补偿：已执行不可逆工具的逆操作补偿（撤销通知/回滚库存预留），补偿链与 SAGA（DF-063）同构
- **原理**：Agent 是分布式执行的特例（每工具是一笔"事务"），补偿设计让失败可恢复，幂等优先补偿兜底（JA-257）
- **常见误区**：
  1. Agent 失败无需补偿（错）
  2. 补偿自动完美执行（补偿本身可能失败，需重试+人工兜底）（错）
  3. SAGA 与 Agent 无关（错）
- **工程用法**：失败恢复架构
- **版本锚点**：实战共识
