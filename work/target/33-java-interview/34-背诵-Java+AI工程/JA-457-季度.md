## 工程 · 季度（评测）

- **事实**：供应商对比评测季度化：候选新模型季度横评（评估集+价格+政策），趋势报告进选型（JA-391 下线预案联动）
- **原理**：模型市场动态（AI-071 趋势），季度机制平衡追新与稳定（JA-306），评测资产复用
- **常见误区**：
  1. 评测一次永久（错）
  2. 季度太频繁（错）
  3. 对比只看价格（错）
- **工程用法**：供应商评测机制
- **版本锚点**：实战共识
