## 工程 · SLA（平台）

- **事实**：平台 SLA 承诺给业务：中台向业务承诺（网关可用性/评估服务时效/工单响应），SLA 是平台与业务契约
- **原理**：JA-384 平台运营的契约面：无 SLA 的平台服务不可信（业务自建回潮），与 DF-056 SLO 联动
- **常见误区**：
  1. 平台无需 SLA（错）
  2. SLA 与平台无关（错）
  3. 承诺随意定（错）
- **工程用法**：平台契约
- **版本锚点**：实战共识
