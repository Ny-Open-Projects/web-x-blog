## 工程 · 运营（知识）

- **事实**：知识库运营节奏：月度知识缺口报告（JA-496 聚类）→补齐排期→入库→效果验证闭环，知识库是运营出来的
- **原理**：知识库不是建完就完（JA-440 冷启动后的持续面），运营节奏让库"活着"，与内容运营联动
- **常见误区**：
  1. 知识库建完即完（错）
  2. 缺口报告无价值（错）
  3. 闭环不需要验证（错）
- **工程用法**：知识库运营
- **版本锚点**：实战共识
