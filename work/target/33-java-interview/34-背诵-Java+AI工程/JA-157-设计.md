## RAG · 设计（元数据）

- **事实**：RAG 元数据设计：source（来源）/chunk 序号/权限标签/更新时间四件随段入库
- **原理**：溯源引用（AI-011）、权限过滤（AI-061）、增量更新（AI-067）全靠元数据，入库时设计优于事后补
- **常见误区**：
  1. 元数据可有可无（错）
  2. 只有正文入库（错）
  3. 元数据在检索后无关（错）
- **工程用法**：RAG 数据设计
- **版本锚点**：实战共识
