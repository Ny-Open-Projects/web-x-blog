## 场景 · 批处理（营销）

- **事实**：营销文案批处理管线：批量生成（batch API 降本 AI-026）→质量筛选（判分）→人工审核队列→发布，人机协作流程
- **原理**：批处理场景是成本敏感（AI-065 并发治理），人审是质量兜底（AI-068），全自动化营销文案不可控
- **常见误区**：
  1. 营销文案全自动无需人审（错）
  2. 批处理不影响成本（错）
  3. 管线只能在线生成（错）
- **工程用法**：内容生产管线
- **版本锚点**：实战共识
