## 版本 · 版本线（锚点）

- **事实**：版本锚点总表：Spring AI 1.0 GA（2025-05）、LangChain4j 1.0 GA（2025）、MCP Java SDK（2024 起，Spring AI 1.0 依赖其 0.10+ 线）
- **原理**：回答任何框架 API 问题先报版本（禁绝对化），本域所有结论锚定 1.0 GA 语义，旧版本教程差异先查迁移说明
- **常见误区**：
  1. Spring AI 1.0 在 2024 年 GA（错）
  2. LangChain4j 没有 1.0（错）
  3. MCP 是 Spring 私有规范（错）
- **工程用法**：版本锚点纪律
- **版本锚点**：2025
