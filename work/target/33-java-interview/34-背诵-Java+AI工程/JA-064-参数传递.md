## Spring AI · 参数传递（Advisor）

- **事实**：advisor 运行时参数经 .advisors(a -> a.param(...)) 传递，记忆会话 id 即经 ChatMemory.CONVERSATION_ID 参数传入
- **原理**：同一 ChatClient 服务多用户，会话标识按调用传入而非构建时绑定，多租户隔离的标准姿势
- **常见误区**：
  1. ChatClient 构建时绑定用户（错）
  2. advisor 参数不能动态传（错）
  3. conversationId 写死在代码（错）
- **工程用法**：多会话隔离装配
- **版本锚点**：Spring AI 1.0 GA
