## 工程 · 同步（文档）

- **事实**：多语言知识库同步：多语言版本文档的内容同步机制（原文变更→各语言版本待更新清单）
- **原理**：JA-281/217 的运营面：语言版本漂移（不同步）导致检索答案不一致（JA-463），同步机制是知识运营的一部分
- **常见误区**：
  1. 多语言版本自动同步（错）
  2. 漂移无影响（错）
  3. 同步靠人工记忆（错）
- **工程用法**：多语言知识治理
- **版本锚点**：实战共识
