## 工程 · 流式结构化（结构化）

- **事实**：流式结构化输出：逐段 JSON 无法解析，需流式 JSON 解析器（增量解析）或聚合后解析（JA-221 权衡）
- **原理**：流式+结构化叠加的场景（实时表格填充），增量解析复杂度高，多数场景聚合后解析足够
- **常见误区**：
  1. 流式与结构化自然兼容（错）
  2. 必须逐段解析（错）
  3. 聚合解析丢失流式优势（错）
- **工程用法**：流式结构化权衡
- **版本锚点**：实战共识
