## RAG · 批量（评估）

- **事实**：RAG 离线批量问答：评估流水线（golden set 批量跑全链路）与数据修复后全量回归（JA-361 的流水线化）
- **原理**：评估从手工单条到批量流水线（并行跑+结果聚合+分域报告），数据修复（JA-492）后的回归自动化，与 CI 集成（JA-665）联动
- **常见误区**：
  1. 评估逐条手工跑（错）
  2. 批量流水线不必要（错）
  3. 回归不需要自动化（错）
- **工程用法**：评估流水线
- **版本锚点**：实战共识
