## 模型 · ICL vs 微调（选型）

- **事实**：ICL 与微调的选型更新：新旗舰模型 ICL 能力增强，微调需求集中在风格/格式/小模型降本（AI-013 矩阵的更新版）
- **原理**：选型矩阵随模型代际演进（JA-056 版本锚定），旧答案"复杂任务必微调"已过时，评估集决策（JA-013）
- **常见误区**：
  1. 微调需求在增长（错）
  2. ICL 永远够用（错）
  3. 选型矩阵静态不变（错）
- **工程用法**：选型矩阵更新
- **版本锚点**：实战共识
