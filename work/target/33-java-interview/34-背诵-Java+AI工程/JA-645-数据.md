## 工程 · 数据（安全）

- **事实**：prompt 数据分级处理：不同密级 prompt（含用户数据 vs 公开）走不同模型与日志策略（JA-380 矩阵的运行时面）
- **原理**：密级在运行时的执行（不是纸面制度）：密级标签随请求流转，路由与日志策略按标签分派，与数据分级（JA-380）联动
- **常见误区**：
  1. prompt 密级无运行时面（错）
  2. 全部同策略处理（错）
  3. 标签无法流转（错）
- **工程用法**：密级运行时
- **版本锚点**：实战共识
