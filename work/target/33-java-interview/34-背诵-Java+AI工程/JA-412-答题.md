## 工程 · 答题（面试）

- **事实**：Java AI 面试答题的三层结构：业务场景（ROI/为什么做）→架构与管道（选型/组件）→工程治理（可靠性/成本/安全）
- **原理**：JA-060/298 答题主线在面试场景的组装，三层递进覆盖 P7 到 P10 提问面，与分层答题方法论联动
- **常见误区**：
  1. 答题只讲技术（错）
  2. 场景与治理是废话（错）
  3. 三层结构固定顺序（按追问动态展开）（错）
- **工程用法**：本域面试框架
- **版本锚点**：实战方法论
