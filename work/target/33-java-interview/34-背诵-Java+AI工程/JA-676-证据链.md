## Agent · 证据链（输出）

- **事实**：Agent 输出附证据链：结论+支撑证据（工具结果片段/引用），结论与证据可点对核对
- **原理**：Agent 输出的可信度设计（AI-011 引用思想的 Agent 版），无证据的结论标注低可信，与审计（JA-219）联动
- **常见误区**：
  1. Agent 输出不需要证据（错）
  2. 证据链无法自动生成（错）
  3. 结论与证据分离输出（错）
- **工程用法**：可信输出设计
- **版本锚点**：实战共识
