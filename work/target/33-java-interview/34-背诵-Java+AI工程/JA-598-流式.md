## 工程 · 流式（体验）

- **事实**：流式与非流式的场景分配：聊天类流式（体验）、内部批处理非流式（简单），API 设计按场景暴露两种模式
- **原理**：JA-426 传输选型的产品面：同一能力两种暴露（API 设计），流式接口的客户端复杂度要评估
- **常见误区**：
  1. 所有接口都流式（错）
  2. 场景无关全流式（错）
  3. 非流式是过时设计（错）
- **工程用法**：接口模式设计
- **版本锚点**：实战共识
