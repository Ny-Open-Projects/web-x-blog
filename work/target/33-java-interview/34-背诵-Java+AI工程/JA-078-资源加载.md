## Spring AI · 资源加载（模板）

- **事实**：PromptTemplate 可从 classpath 资源文件构建，提示词与代码分离管理
- **原理**：提示词资产化（版本管理/评审/灰度），与 AI-064 版本管理联动，改提示词可不发版
- **常见误区**：
  1. PromptTemplate 只能代码内字符串（错）
  2. 资源加载不被支持（错）
  3. 模板修改必须重新编译（错）
- **工程用法**：提示词资产管理
- **版本锚点**：Spring AI 1.0 GA
