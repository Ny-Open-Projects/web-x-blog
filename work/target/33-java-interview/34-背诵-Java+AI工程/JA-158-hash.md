## RAG · hash（增量）

- **事实**：增量入库按文档内容 hash 判断：hash 未变的文档跳过重嵌入，变更才重建
- **原理**：全量重嵌入成本高（AI-060 成本联动），hash 增量是入库管道标配，删除的文档需同步清理向量
- **常见误区**：
  1. 每次全量重嵌入（错）
  2. 增量会漏更新（错）
  3. hash 与内容无关（错）
- **工程用法**：入库管道效率
- **版本锚点**：实战共识
