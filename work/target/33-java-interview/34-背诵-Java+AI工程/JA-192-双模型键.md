## LangChain4j · 双模型键（Spring）

- **事实**：LC4j starter 同时支持 chat-model 与 streaming-chat-model 两组属性（同步与流式分别装配）
- **原理**：同步与流式可用不同 provider/模型（流式用轻量模型），两个 bean 并存注入
- **常见误区**：
  1. 同步流式只能同模型（错）
  2. streaming 属性不存在（错）
  3. 两 bean 会冲突（错）
- **工程用法**：分层模型装配
- **版本锚点**：LangChain4j 1.0
