## 工程 · 流式（审计）

- **事实**：流式输出的逐段审计：流式段落（JA-262 扫描过的）逐段留痕（审计完整性），聚合留痕与逐段留痕的选择
- **原理**：JA-383 留痕的流式面：逐段留痕成本高（量大），聚合留痕+抽样逐段，与留痕年限策略联动
- **常见误区**：
  1. 流式无需留痕（错）
  2. 逐段留痕必须全量（错）
  3. 留痕只有聚合一种（错）
- **工程用法**：流式留痕
- **版本锚点**：实战共识
