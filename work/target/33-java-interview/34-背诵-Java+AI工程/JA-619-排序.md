## RAG · 排序（注入）

- **事实**：注入内容排序：检索片段按重要性重排（最相关放首尾，JA-510 布局工程），而非按检索分数顺序
- **原理**：分数序≠注意力序（中间遗忘），布局策略是免费的精度提升，与上下文预算（JA-223）联动
- **常见误区**：
  1. 按分数顺序注入最优（错）
  2. 排序无影响（错）
  3. 首尾布局无依据（错）
- **工程用法**：注入布局优化
- **版本锚点**：实战共识
