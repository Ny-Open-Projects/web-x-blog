## 数据 · 快照（版本）

- **事实**：知识库版本快照与 diff：入库批次打版本，检索问题可回放"当时知识状态"复现
- **原理**：RAG 问题的复现需要知识库状态（JA-355 复盘联动），快照让 bug 可重现，与 DB 备份思想同构
- **常见误区**：
  1. 知识库无版本概念（错）
  2. 快照成本高不可行（增量快照可控）（错）
  3. 复现不需要状态（错）
- **工程用法**：知识库可复现性
- **版本锚点**：实战共识
