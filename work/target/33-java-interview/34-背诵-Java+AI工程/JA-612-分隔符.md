## 提示词 · 分隔符（结构）

- **事实**：prompt 分隔符规范：XML 标签/Markdown 标题/三引号分区（指令/上下文/示例/输入各就各位）
- **原理**：分隔符让模型解析输入结构（JA-225 边界标签的泛化），结构化输入降低注入面与混淆，与格式规范联动
- **常见误区**：
  1. 分隔符是装饰（错）
  2. 所有内容平铺即可（错）
  3. 三种分隔符不能混用（错）
- **工程用法**：提示词结构规范
- **版本锚点**：实战共识
