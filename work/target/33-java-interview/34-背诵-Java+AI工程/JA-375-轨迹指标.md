## Agent · 轨迹指标（评测）

- **事实**：Agent 轨迹评测指标：任务成功率、步数效率（最少步完成）、工具选择正确率、预算内完成率
- **原理**：AI-059 的指标清单化，轨迹可回放（JA-219）所以可自动评，与单元测试断言思想同构
- **常见误区**：
  1. Agent 只看最终对错（错）
  2. 轨迹指标无意义（错）
  3. 评测必须人工（错）
- **工程用法**：Agent 评测体系
- **版本锚点**：实战共识
