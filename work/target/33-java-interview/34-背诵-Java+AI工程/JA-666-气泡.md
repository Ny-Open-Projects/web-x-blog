## RAG · 气泡（个性化）

- **事实**：检索气泡（filter bubble）风险：个性化检索（JA-579）让用户只见偏好内容，信息窄化（产品伦理问题）
- **原理**：个性化的负外部性：加多样性约束（强制注入非偏好域内容），与推荐系统气泡同构，产品价值观问题
- **常见误区**：
  1. 个性化无副作用（错）
  2. 气泡风险不存在（错）
  3. 多样性约束是伪需求（错）
- **工程用法**：个性化伦理
- **版本锚点**：实战共识
