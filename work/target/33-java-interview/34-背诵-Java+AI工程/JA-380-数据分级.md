## 中台 · 数据分级（治理）

- **事实**：数据分级接入矩阵：不同密级数据（公开/内部/敏感）可用的模型与部署形态（云端/私有化）不同
- **原理**：密级×部署形态矩阵是合规落地（AI-040/270），敏感数据强制私有化模型（Ollama/transformers JA-017/183）
- **常见误区**：
  1. 数据分级与模型选择无关（错）
  2. 敏感数据可上云（错）
  3. 矩阵是合规部门的事（错）
- **工程用法**：分级接入矩阵
- **版本锚点**：实战共识
