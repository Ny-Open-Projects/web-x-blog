## 评测 · 采纳（指标）

- **事实**：采纳率与满意度的差异：采纳（直接用）≠满意（体验好但没用上），两指标背离时分别归因
- **原理**：JA-289 指标的语义辨析：采纳是行为、满意是态度，背离说明"好但不适用"或"有用但难用"，指标语义辨析能力
- **常见误区**：
  1. 两指标等价（错）
  2. 背离无意义（错）
  3. 只看采纳即可（错）
- **工程用法**：指标语义
- **版本锚点**：实战共识
