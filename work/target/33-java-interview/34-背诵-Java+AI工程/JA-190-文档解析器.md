## LangChain4j · 文档解析器（解析）

- **事实**：LC4j 文档解析以独立模块提供（如 langchain4j-document-parser-apache-pdf）
- **原理**：解析器模块化按需引入（PDF/poi/tika），与 Spring AI 的 reader 族对等（JA-129），按格式选解析器
- **常见误区**：
  1. 解析内置无需模块（错）
  2. 只有 PDF 一种解析器（错）
  3. 解析与切分是一步（错）
- **工程用法**：RAG 入库组件
- **版本锚点**：LangChain4j 1.0
