## 工程 · 预测（容量）

- **事实**：AI 用量容量预测：用量增长外推（业务增长系数×AI 渗透率），提前扩配额/供应商合同（JA-337 联动）
- **原理**：容量规划在 AI 依赖的版本（MY-092 基线外推），配额与成本都要前瞻（供应商合同周期长），与容量知识联动
- **常见误区**：
  1. 容量到时再扩（错）
  2. 预测不必要（错）
  3. 配额随时可加（错）
- **工程用法**：容量前瞻
- **版本锚点**：实战共识
