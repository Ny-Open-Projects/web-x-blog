## 中间件 · 性能（网关）

- **事实**：网关额外一跳的延迟代价：流式场景网关转发增加毫秒级，配额校验本地缓存降低检查成本
- **原理**：网关不是免费（多一跳网络+处理），收益（治理）与代价（延迟/可用性）权衡，与 DF-047 负载均衡位置思想同构
- **常见误区**：
  1. 网关零延迟（错）
  2. 延迟代价大于收益（治理收益通常更大）（错）
  3. 性能与治理无关（错）
- **工程用法**：网关成本认知
- **版本锚点**：实战共识
