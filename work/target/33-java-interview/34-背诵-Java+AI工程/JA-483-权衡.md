## 质量 · 权衡（阈值）

- **事实**：评估判分阈值权衡：阈值严（假阳性多阻塞发布）vs 松（假阴性多放走退化），按发布风险分级阈值
- **原理**：JA-414 分层阈值的统计面，核心功能严、实验功能松，假阳/假阴代价不对称分析
- **常见误区**：
  1. 阈值只有一种设置（错）
  2. 越严越好（错）
  3. 阈值与风险无关（错）
- **工程用法**：阈值设计
- **版本锚点**：实战共识
