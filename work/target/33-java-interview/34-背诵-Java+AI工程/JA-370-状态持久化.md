## Agent · 状态持久化（编排）

- **事实**：编排状态持久化选型：自研落库（JA-255）vs 工作流引擎（Temporal/Camunda），长任务高可靠用引擎
- **原理**：工作流引擎送重试/超时/补偿/可视化，代价是引入重件，任务时长与可靠性需求决定（AI-021 权衡）
- **常见误区**：
  1. 引擎一定优于自研（错）
  2. 自研足够所有场景（错）
  3. 两者互斥（组合使用也常见）（错）
- **工程用法**：编排基建选型
- **版本锚点**：实战共识
