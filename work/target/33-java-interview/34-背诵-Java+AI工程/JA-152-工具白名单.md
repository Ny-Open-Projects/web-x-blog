## 工程 · 工具白名单（安全）

- **事实**：工具白名单按环境区分：生产只暴露只读工具，写操作工具仅在显式开启时可用
- **原理**：最小权限落地（AI-068 联动），误配写工具是事故源，配置中心开关+审计
- **常见误区**：
  1. 所有环境工具一致（错）
  2. 白名单是可选装饰（错）
  3. 写工具优先上线（错）
- **工程用法**：生产安全基线
- **版本锚点**：实战共识
