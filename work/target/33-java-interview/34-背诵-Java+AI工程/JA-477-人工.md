## 工程 · 人工（评估）

- **事实**：人工评估的组织：标注指南+双人标注+仲裁（JA-364），标注任务按批分发+质量抽检
- **原理**：golden set 标注是项目管理（JA-245 执行面），标注质量决定标尺（JA-364 联动），与标注平台知识联动
- **常见误区**：
  1. 标注一个人做即可（错）
  2. 指南与仲裁是形式（错）
  3. 抽检没必要（错）
- **工程用法**：标注项目管理
- **版本锚点**：实战共识
