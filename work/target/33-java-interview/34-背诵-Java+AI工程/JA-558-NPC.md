## 行业 · NPC（游戏）

- **事实**：游戏 NPC 对话：角色人设 prompt+记忆（与玩家关系）+内容安全（防违规对话），体验与安全双约束
- **原理**：游戏 NPC 是 prompt 人设工程（AI-023）的极致场景，长期记忆（与该玩家历史）与内容过滤（JA-262）并重
- **常见误区**：
  1. NPC 直接接大模型即可（错）
  2. 人设不重要（错）
  3. 游戏无内容安全要求（错）
- **工程用法**：游戏 NPC 设计
- **版本锚点**：实战共识
