## 质量 · 映射（金字塔）

- **事实**：AI 测试金字塔完整映射：单测（mock 模型，占 70%）→集成（本地小模型跑链路，20%）→评估集（质量回归，快）→线上影子（持续），层间比例与普通应用金字塔一致
- **原理**：JA-203 的比例细化，底层快而多、顶层真而少，每层回答不同问题（逻辑对/链路通/质量好/真实好）
- **常见误区**：
  1. AI 测试只有评估一层（错）
  2. 比例与普通应用不同（错）
  3. 顶层最重要其他可省（错）
- **工程用法**：测试体系全景
- **版本锚点**：实战共识
