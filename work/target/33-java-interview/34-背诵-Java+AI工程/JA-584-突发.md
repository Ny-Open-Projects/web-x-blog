## 工程 · 突发（配额）

- **事实**：突发配额申请流程：大促/活动临时提额（供应商工单提前 N 天），容量保障（MY-092）的供应商面
- **原理**：配额弹性的商务流程（JA-516 合同条款覆盖），临时提额有审批周期，与容量日历联动
- **常见误区**：
  1. 配额随时可提（错）
  2. 突发提额无需流程（错）
  3. 大促不涉及 AI 配额（错）
- **工程用法**：配额弹性流程
- **版本锚点**：实战共识
