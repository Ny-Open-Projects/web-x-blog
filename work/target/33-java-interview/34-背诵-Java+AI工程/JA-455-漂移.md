## 工程 · 漂移（配置）

- **事实**：配置漂移检测：生产配置 vs 基线（Git 版本）定期 diff，未审批变更告警
- **原理**：配置即代码（JA-402 版本化）的漂移面，人工改线上配置是事故源，与 MY-105 变更规范联动
- **常见误区**：
  1. 配置漂移不存在（错）
  2. diff 是人工做（错）
  3. 漂移无风险（错）
- **工程用法**：配置治理
- **版本锚点**：实战共识
