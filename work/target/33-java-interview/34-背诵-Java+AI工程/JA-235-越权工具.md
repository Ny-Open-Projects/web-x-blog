## 工程 · 越权工具（安全）

- **事实**：工具越权防线：工具执行前按当前用户权限校验（ToolContext 用户 → RBAC 判断），防"借 AI 之手越权"
- **原理**：AI-068 沙箱+JA-069 ToolContext 的组合落地，提示词注入可能诱导调高危工具（AI-024），权限校验是硬防线
- **常见误区**：
  1. 模型会遵守权限（错）
  2. 工具执行不需要权限校验（错）
  3. 防线只在提示词（错）
- **工程用法**：工具安全红线
- **版本锚点**：实战共识
