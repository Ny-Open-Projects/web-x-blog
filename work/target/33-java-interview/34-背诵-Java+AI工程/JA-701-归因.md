## 评测 · 归因（漂移）

- **事实**：评估漂移三维归因：分数变化拆解为模型漂移（供应商更新）/数据漂移（语料变化）/配置漂移（prompt 改动）三个控制变量实验
- **原理**：JA-347/392 漂移的归因方法：控制变量重跑（JA-572 方法论），三维归因定位真因，与实验纪律联动
- **常见误区**：
  1. 漂移归因靠猜（错）
  2. 三维无法拆解（错）
  3. 实验成本高（抽样可控）（错）
- **工程用法**：漂移归因
- **版本锚点**：实战共识
