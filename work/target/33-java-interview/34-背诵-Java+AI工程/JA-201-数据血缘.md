## 工程 · 数据血缘（评估）

- **事实**：评估集条目带血缘：来源（线上回流/人工构造）、创建版本、覆盖意图
- **原理**：血缘让评估集可审计可进化（AI-179 回流联动），污染排查（AI-088）靠血缘追溯
- **常见误区**：
  1. 评估集条目无需元数据（错）
  2. 血缘是测试数据要求太高（错）
  3. 只有数量重要（错）
- **工程用法**：评估资产管理
- **版本锚点**：实战共识
