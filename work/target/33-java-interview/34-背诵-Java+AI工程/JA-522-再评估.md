## 工程 · 再评估（选型）

- **事实**：框架选型的年度再评估：能力矩阵（JA-391 对比表）年度刷新+社区健康度（发版/issue 响应），防锁定
- **原理**：选型不是终身（JA-039 动态化），框架演进方向变化（如合并/停滞）触发再评估，与供应商治理联动
- **常见误区**：
  1. 选型一次终身（错）
  2. 年度评估是浪费（错）
  3. 社区健康不重要（错）
- **工程用法**：选型再评估
- **版本锚点**：实战共识
