## Spring AI · 枚举（结构化）

- **事实**：entity 支持枚举返回（输出约束到枚举值集），分类任务直接映射 Java 枚举
- **原理**：分类/意图识别的零解析方案（JA-003 特例），枚举约束比自由文本稳定
- **常见误区**：
  1. 枚举返回不支持（错）
  2. 枚举值模型自行发挥（错）
  3. 分类必须 if-else 解析（错）
- **工程用法**：分类任务落地
- **版本锚点**：Spring AI 1.0 GA
