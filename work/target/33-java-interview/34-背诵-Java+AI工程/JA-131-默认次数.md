## Spring AI · 默认次数（重试）

- **事实**：spring.ai.retry.max-attempts 默认值为 10（指数退避）
- **原理**：框架默认重试较激进（容忍供应商抖动），成本敏感或非幂等场景需评估调整（JA-056 幂等前提）
- **常见误区**：
  1. 默认不重试（错）
  2. 默认重试 3 次（错）
  3. 调整重试需要重启（配置类启动期读取）（错）
- **工程用法**：重试参数治理
- **版本锚点**：Spring AI 1.0 GA
