## RAG · 保护（隔离）

- **事实**：多租户检索资源保护：大租户重查询降级（topK 动态缩减）保护小租户延迟，租户级检索限流
- **原理**：共享向量库（JA-249）的公平性：大租户查询放大（宽 topK）拖垮全库，租户级配额（JA-206 思想延伸到检索）
- **常见误区**：
  1. 向量库查询天然公平（错）
  2. 大租户不影响他人（错）
  3. 检索限流无必要（错）
- **工程用法**：检索公平性
- **版本锚点**：实战共识
