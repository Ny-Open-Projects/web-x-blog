## 数据 · 影子索引（换代）

- **事实**：嵌入模型换代影子索引：新模型并行建全量索引（旧索引在线服务），评估对比后一次性切流
- **原理**：换嵌入模型=全量重嵌入（JA-101），影子索引让切换零停机可回退，存储成本双份是代价
- **常见误区**：
  1. 换模型停机重建（错）
  2. 影子索引浪费（错）
  3. 切换无回退（错）
- **工程用法**：嵌入换代工程
- **版本锚点**：实战共识
