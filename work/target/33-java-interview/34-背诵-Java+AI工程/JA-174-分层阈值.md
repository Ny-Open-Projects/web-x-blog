## 工程 · 分层阈值（评估）

- **事实**：评估门禁分层阈值：核心指标（忠实度/准确率）硬门禁，体验指标（长度/风格）软告警
- **原理**：一刀切阈值要么门禁太松要么天天阻断（AI-077 联动），按指标业务权重分层，与 SLO 分级思想（DF-056）同构
- **常见误区**：
  1. 所有指标同权重阻断（错）
  2. 软指标也必须硬门禁（错）
  3. 分层阈值无意义（错）
- **工程用法**：门禁设计
- **版本锚点**：实战共识
