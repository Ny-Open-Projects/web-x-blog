## RAG · 切分（多语言）

- **事实**：中英混排文档切分：token 粒度切分天然兼容（tokenizer 按语言计量），字符切分对中文粒度失真
- **原理**：中英混合知识库的切分陷阱（JA-068/189 联动），选 token 切分器+合适 tokenizer
- **常见误区**：
  1. 字符切分对中英文一样（错）
  2. 中文必须按字切（错）
  3. 多语言需要分开建库（错）
- **工程用法**：多语言知识库
- **版本锚点**：实战共识
