## 工程 · 长会话（归档）

- **事实**：超长会话治理：会话超阈值把早期历史摘要归档（压缩窗口），活跃窗口保持轻
- **原理**：长对话 token 膨胀（JA-223 预算），摘要归档比硬截断保留语义（AI-045），与会话产品逻辑联动
- **常见误区**：
  1. 超长会话直接截断（错）
  2. 摘要归档会丢上下文（错）
  3. 无上限保留最好（错）
- **工程用法**：长会话策略
- **版本锚点**：实战共识
