## 行业 · 导购（电商）

- **事实**：电商导购多模态：商品图理解（拍图识商品）+商品库检索+比价/推荐，视觉+检索+对话三栈组合
- **原理**：JA-072 电商组合的深化：拍图搜商品是视觉检索（JA-547）+商品结构化库的经典组合，转化率是北极星（AI-414）
- **常见误区**：
  1. 导购纯文本即可（错）
  2. 拍图识商品无法落地（错）
  3. 三栈组合是过度设计（错）
- **工程用法**：电商导购架构
- **版本锚点**：实战共识
