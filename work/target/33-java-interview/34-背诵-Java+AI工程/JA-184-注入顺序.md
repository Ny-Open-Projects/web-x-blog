## Spring AI · 注入顺序（Advisor）

- **事实**：QuestionAnswerAdvisor 应排在记忆 advisor 之前或之后取决于"检索内容是否要进历史"
- **原理**：顺序错误导致检索内容污染记忆或记忆重复注入（JA-121 排序语义），装配时要推演数据流
- **常见误区**：
  1. 顺序随意不影响（错）
  2. 记忆 advisor 永远最前（错）
  3. RAG 内容默认会进记忆（错）
- **工程用法**：advisor 装配推演
- **版本锚点**：实战共识
