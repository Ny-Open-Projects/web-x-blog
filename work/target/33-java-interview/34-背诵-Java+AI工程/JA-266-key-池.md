## 工程 · key 池（配额）

- **事实**：供应商多 key 池轮转：多账号分摊配额（RPM/TPM 独立计），轮转+熔断（坏 key 摘除）
- **原理**：单 key 配额是吞吐天花板（AI-065 的扩展），合规前提是供应商条款允许多账号，与限流知识联动
- **常见误区**：
  1. 多 key 违规不能用（错）
  2. key 池无运维成本（错）
  3. 坏 key 自动恢复（错）
- **工程用法**：配额扩展手段
- **版本锚点**：实战共识
