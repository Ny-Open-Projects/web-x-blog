## RAG · 粒度（引用）

- **事实**：引用粒度选择：chunk 级引用（精确到段）vs 文档级引用（粗但稳），产品形态决定
- **原理**：chunk 引用精确但碎（AI-202），文档引用稳定但难定位，问答产品 chunk 级、合规归档文档级
- **常见误区**：
  1. 引用只有一种粒度（错）
  2. 粒度越细越好（错）
  3. 粒度与产品无关（错）
- **工程用法**：引用设计
- **版本锚点**：实战共识
