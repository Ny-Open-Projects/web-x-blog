## RAG · HyDE（进阶）

- **事实**：HyDE（假设文档嵌入）：让模型先生成假设答案，用假设答案的向量去检索（答案与文档同分布）
- **原理**：查询与文档向量分布错位的解法（问题短答案长），假设文档桥接分布差，代价是每次检索多一次模型调用
- **常见误区**：
  1. HyDE 是检索领域的杜撰词（错）
  2. 直接检索总是更好（错）
  3. HyDE 无成本（错）
- **工程用法**：检索进阶技巧
- **版本锚点**：实战共识
