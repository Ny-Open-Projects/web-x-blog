## RAG · 查询扩展（扩展）

- **事实**：查询扩展：同义词/上位词扩展（"发货"扩展到"物流/配送"），扩展词表或模型改写，提升召回
- **原理**：单查询召回盲区（术语差异 JA-496），扩展换召回广度，代价是噪声，与混合检索（JA-241）互补
- **常见误区**：
  1. 查询原样检索最优（错）
  2. 扩展必引入噪声所以不用（错）
  3. 扩展词表无法维护（错）
- **工程用法**：召回扩展技巧
- **版本锚点**：实战共识
