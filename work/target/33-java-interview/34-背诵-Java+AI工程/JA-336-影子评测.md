## 工程 · 影子评测（评测）

- **事实**：新模型影子评测：批量跑评估集对比主模型（质量/延迟/成本三维度），数据支撑切换决策（JA-035 模型评测落地）
- **原理**：换模型不是"试几条"，评估集全量+维度对比出报告（AI-035），决策有据
- **常见误区**：
  1. 换模型试几条就行（错）
  2. 只看质量不看成本（错）
  3. 评测与切换无关（错）
- **工程用法**：模型切换决策
- **版本锚点**：实战共识
