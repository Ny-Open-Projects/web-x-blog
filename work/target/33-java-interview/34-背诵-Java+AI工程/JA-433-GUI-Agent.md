## 多模态 · GUI Agent（桌面）

- **事实**：GUI Agent（桌面/浏览器操作型 Agent）：视觉模型看屏+操作指令循环，2025 兴起方向（AI-071 趋势）
- **原理**：Agent 从 API 工具扩展到 GUI 操作（无 API 的老系统自动化），Java 侧经 MCP/Playwright 类桥接，安全边界（操作审计）极重要
- **常见误区**：
  1. GUI Agent 已成熟量产（错）
  2. 老系统自动化无价值（错）
  3. 视觉操作不需要审计（错）
- **工程用法**：Agent 前沿方向
- **版本锚点**：2025
