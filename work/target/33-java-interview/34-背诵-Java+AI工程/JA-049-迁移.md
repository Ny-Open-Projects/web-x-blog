## Spring AI · 迁移（版本）

- **事实**：Spring AI 版本迁移注意：function calling 命名在 1.0 统一为 tools（ToolCallback）
- **原理**：旧教程/代码的 .functions(...) 写法在 1.0 迁移为 .tools(...)，迁移先查废弃 API 再升版本，与 SP-106 迁移方法联动
- **常见误区**：
  1. functions 与 tools 写法等价共存（错）
  2. 迁移只是改版本号（错）
  3. 命名从未变化（错）
- **工程用法**：1.0 迁移清单
- **版本锚点**：Spring AI 1.0 GA
