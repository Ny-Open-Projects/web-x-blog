## 工程 · playground（调试）

- **事实**：本地调试页（playground）：开发环境直连模型的对话调试工具（框架 devtools 或手写页），试 prompt 免发版
- **原理**：prompt 迭代效率工具（AI-064 变更纪律的配套），生产隔离（只在 dev profile 开启），与测试策略联动
- **常见误区**：
  1. 调试只能发版验证（错）
  2. playground 可开放生产（错）
  3. 调试工具与框架无关（错）
- **工程用法**：开发效率工具
- **版本锚点**：实战共识
