## 工程 · 输入限制（接口）

- **事实**：输入长度限制在接口层前置：超长输入直接 4xx（附长度上限说明），不进模型（省 token 防异常）
- **原理**：防线前移（MY-108 保护思想），模型侧超限报错晚且贵，前端+接口双重校验，与输入校验（SP-068）联动
- **常见误区**：
  1. 超长输入交给模型处理（错）
  2. 接口层限制多余（错）
  3. 前置校验与模型上限重复（错）
- **工程用法**：输入防线
- **版本锚点**：实战共识
