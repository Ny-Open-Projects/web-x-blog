## 工程 · 分摊模式（成本）

- **事实**：成本分摊两模式：showback（展示不收费，初期）→chargeback（真分摊计费，成熟期），按组织成熟度演进
- **原理**：JA-290 分摊的运营模式面：showback 培养成本意识、chargeback 强约束，与平台运营（JA-377）联动
- **常见误区**：
  1. 直接 chargeback（错）
  2. 分摊模式一成不变（错）
  3. 模式与成熟度无关（错）
- **工程用法**：成本运营演进
- **版本锚点**：实战共识
