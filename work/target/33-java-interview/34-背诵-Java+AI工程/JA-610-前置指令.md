## 提示词 · 前置指令（结构）

- **事实**：输出前置指令技巧："始终以 JSON 开头"类强约束放 prompt 首尾双位置（首尾锚定），提升格式遵循率
- **原理**：模型对首尾内容注意力高（JA-510 中间遗忘），格式锚定双保险（JA-228 宽松解析的前置配合）
- **常见误区**：
  1. 格式指令放哪都一样（错）
  2. 只需开头锚定（错）
  3. 双锚定是过度设计（错）
- **工程用法**：格式遵循技巧
- **版本锚点**：实战共识
