## MCP · 测试（生产）

- **事实**：MCP server 测试：schema 契约测试（inputSchema 与实现签名一致）+mock 客户端回归
- **原理**：工具契约（JA-308）的自动化验证，SDK 从 POJO 生成 schema（JA-176）后契约漂移要测
- **常见误区**：
  1. MCP server 无法测试（错）
  2. 测试只测工具逻辑（错）
  3. schema 漂移无害（错）
- **工程用法**：MCP 质量门
- **版本锚点**：MCP 生产化
