## 行业 · 底座（策略）

- **事实**：跨行业策略：统一底座（网关/评估/治理 JA-376）+行业层（合规/术语/场景 prompt），新行业接入只做行业层

  1. 每个行业从零建（错）
  2. 底座与行业耦合（错）
