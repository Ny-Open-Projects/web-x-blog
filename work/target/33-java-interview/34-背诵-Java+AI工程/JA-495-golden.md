## 数据 · golden（挖掘）

- **事实**：检索日志挖 golden set：真实查询+用户点击的正确文档为候选（自动），人工确认后入评估集
- **原理**：评估集持续扩产的自动化管道（JA-179 的检索版），点击即隐式反馈（JA-233），人工确认防噪声
- **常见误区**：
  1. golden set 纯人工构造（错）
  2. 点击数据无价值（错）
  3. 自动候选不需要确认（错）
- **工程用法**：评估集扩产管道
- **版本锚点**：实战共识
