## 工程 · 事件驱动（架构）

- **事实**：AI 能力事件化：模型调用结果发布事件（供下游消费——审计/缓存/评估采样），事件驱动解耦横切关注
- **原理**：同步调用与事件发布的双轨（审计/缓存走事件异步），与事件驱动架构（JA-045 Spring 事件/MQ-001）联动
- **常见误区**：
  1. AI 调用只能同步消费（错）
  2. 事件化是过度设计（错）
  3. 横切关注在调用点硬编码（错）
- **工程用法**：事件驱动架构
- **版本锚点**：实战共识
