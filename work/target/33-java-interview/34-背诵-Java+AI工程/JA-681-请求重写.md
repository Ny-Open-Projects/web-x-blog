## 网关 · 请求重写（适配）

- **事实**：网关请求重写：供应商特有参数适配（同一语义参数名不同），应用免感知供应商差异
- **原理**：JA-318 兼容层的参数面：协议兼容不止消息结构还有参数映射，重写规则配置化
- **常见误区**：
  1. 参数名全行业统一（错）
  2. 重写不需要配置（错）
  3. 应用自己适配参数（错）
- **工程用法**：参数适配
- **版本锚点**：实战共识
