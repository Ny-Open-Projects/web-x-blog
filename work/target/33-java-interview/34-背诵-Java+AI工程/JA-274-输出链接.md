## 工程 · 输出链接（安全）

- **事实**：模型输出链接防护：生成 URL 经白名单校验（防幻觉域名/钓鱼链接直达用户）
- **原理**：幻觉 URL 是真实攻击面（AI-043 幻觉的 Web 维度），白名单+域名校验在输出管线（JA-207）落地
- **常见误区**：
  1. 模型输出链接可信（错）
  2. 链接校验是可选装饰（错）
  3. 幻觉只影响文本（错）
- **工程用法**：输出安全
- **版本锚点**：实战共识
