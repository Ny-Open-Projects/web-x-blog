## 工程 · 清单（风险）

- **事实**：Java AI 项目风险清单：供应商锁定、成本失控、质量回归、数据合规、团队能力断层、框架 immature——每项有缓解手段
- **原理**：JA-239 失败模式的立项面（立项评审用），风险与缓解成对出现，与架构评审（DF-099）联动
- **常见误区**：
  1. AI 项目无特殊风险（错）
  2. 风险清单是形式（错）
  3. 缓解手段不存在（错）
- **工程用法**：立项评审框架
- **版本锚点**：实战方法论
