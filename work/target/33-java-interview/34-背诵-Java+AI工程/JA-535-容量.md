## 工程 · 容量（运维）

- **事实**：SSE 长连接容量模型：连接数=并发用户×会话时长系数，网关/负载均衡的连接上限是瓶颈（非 QPS）
- **原理**：JA-230 容量修正的连接面：SSE 占用连接句柄（LB 连接数上限），容量按连接规划，与长连接运维联动
- **常见误区**：
  1. 容量按 QPS 规划（错）
  2. 连接不占句柄（错）
  3. LB 无连接上限问题（错）
- **工程用法**：长连接容量
- **版本锚点**：实战共识
