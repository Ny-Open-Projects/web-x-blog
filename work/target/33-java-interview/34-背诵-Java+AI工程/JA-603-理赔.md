## 行业 · 理赔（保险）

- **事实**：保险理赔材料审核：单据 OCR+条款 RAG（保单条款比对）+欺诈信号识别，分级人审（JA-439）
- **原理**：理赔场景三栈组合：单据理解（多模态）+条款检索（RAG）+审核分级，误赔/错赔代价高→人审强介入（JA-478 责任链）
- **常见误区**：
  1. 理赔全自动通过（错）
  2. 条款比对靠人工（错）
  3. 欺诈识别不需要（错）
- **工程用法**：保险场景管线
- **版本锚点**：实战共识
