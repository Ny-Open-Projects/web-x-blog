## 模型 · 采样（调参）

- **事实**：temperature 与 top_p 组合调参：两者都调会叠加随机性，调优时单变量原则（先 temperature 后 top_p）
- **原理**：JA-161 的组合面，采样参数族（top_k/top_p/temperature）语义区分，与多变量实验纪律（JA-450）联动
- **常见误区**：
  1. 三参数随意组合调（错）
  2. top_p 比 temperature 重要（错）
  3. 组合调参更快（错）
