## 工程 · 键设计（缓存）

- **事实**：响应缓存键设计：模型标识+消息序列 hash+options hash，任一变化键不同
- **原理**：缓存正确性靠键完整（模型/参数变更返回不同结果），与缓存 key 规范（RD-067）联动
- **常见误区**：
  1. 键只含用户问题（错）
  2. options 不参与键（错）
  3. 键冲突无影响（错）
- **工程用法**：缓存正确性
- **版本锚点**：实战共识
