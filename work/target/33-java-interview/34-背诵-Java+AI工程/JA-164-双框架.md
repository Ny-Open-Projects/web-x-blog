## 工程 · 双框架（共存）

- **事实**：Spring AI 与 LangChain4j 同用 Spring 时的共存注意：bean 名冲突与依赖版本对齐，按模块隔离引用
- **原理**：混用有真实动机（各取所长），风险是 starter 自动装配互相干扰，团队规范建议单框架优先（AI-039）
- **常见误区**：
  1. 两框架 bean 自动兼容（错）
  2. 共存无任何冲突（错）
  3. 依赖版本无关（错）
- **工程用法**：共存风险治理
- **版本锚点**：实战共识
