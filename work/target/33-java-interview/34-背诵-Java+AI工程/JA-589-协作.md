## 工程 · 协作（安全）

- **事实**：与安全团队协作界面：AI 安全事件上报（JA-520）→安全团队响应，AI 特有风险的知识转移（注入/越权/数据外泄）
- **原理**：安全协作的组织面（JA-408 四方协作的安全支线），安全团队需要 AI 知识输入（红队 JA-465），与安全运营联动
- **常见误区**：
  1. AI 安全工程自己扛（错）
  2. 协作界面无需定义（错）
  3. 安全团队懂 AI（需要知识转移）（错）
- **工程用法**：安全组织协作
- **版本锚点**：实战共识
