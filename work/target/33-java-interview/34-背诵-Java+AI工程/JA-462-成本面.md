## 工程 · 成本面（观测）

- **事实**：成本观测四指标：单次成本分布（P50/P99）、缓存命中率、模型混合占比、单位任务成本
- **原理**：成本观测与性能观测并列（JA-091/354 SLO 四维的成本维），看板化（JA-236），趋势比绝对值重要
- **常见误区**：
  1. 成本只看月总额（错）
  2. 单次成本无意义（错）
  3. 观测与成本无关（错）
- **工程用法**：成本观测体系
- **版本锚点**：实战共识
