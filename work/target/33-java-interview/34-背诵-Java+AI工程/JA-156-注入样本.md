## 工程 · 注入样本（评估）

- **事实**：评估集必须包含提示词注入与越狱样本（安全回归与功能回归同权重）
- **原理**：安全回归防"改 prompt 破坏防线"（AI-024/025 联动），注入样本命中即门禁失败，与 AI-077 门禁联动
- **常见误区**：
  1. 评估只测功能不测安全（错）
  2. 注入样本不需要更新（错）
  3. 安全与功能分开测（错）
- **工程用法**：安全回归纪律
- **版本锚点**：实战共识
