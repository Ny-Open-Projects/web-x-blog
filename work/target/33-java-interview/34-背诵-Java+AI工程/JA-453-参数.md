## 工程 · 参数（安全）

- **事实**：用户可控参数白名单：模型/温度/topK 等接口参数白名单校验（防用户传 0 温度绕约束/巨 maxTokens）
- **原理**：接口层参数校验（AI-070 输入防线延伸），参数即成本与行为杠杆，与三级限流（JA-206）联动
- **常见误区**：
  1. 参数透传用户无风险（错）
  2. 白名单限制功能（错）
  3. 校验是可选装饰（错）
- **工程用法**：参数安全
- **版本锚点**：实战共识
