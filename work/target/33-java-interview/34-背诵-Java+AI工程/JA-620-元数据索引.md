## RAG · 元数据索引（存储）

- **事实**：元数据过滤的索引：向量库对高频过滤字段建元数据索引（否则过滤退化为全扫后过滤）
- **原理**：JA-063/187 过滤的性能面：无索引过滤在大库上延迟爆炸，过滤字段设计与检索模式联动
- **常见误区**：
  1. 过滤自动有索引（错）
  2. 元数据索引不必要（错）
  3. 过滤性能与索引无关（错）
- **工程用法**：过滤性能工程
- **版本锚点**：实战共识
