## RAG · 备份（运维）

- **事实**：向量库备份与恢复：定期快照（含元数据与索引配置），恢复演练（JA-286）覆盖向量库
- **原理**：向量库是核心数据资产（JA-101 重建成本高），快照+演练让故障可恢复，与备份体系（RD-094）联动
- **常见误区**：
  1. 向量库不用备份（错）
  2. 重建快照即可（全量重嵌入按成本评估）（错）
  3. 恢复不需要演练（错）
- **工程用法**：向量库灾备
- **版本锚点**：实战共识
