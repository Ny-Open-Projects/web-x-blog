## Agent · 生命周期（清理）

- **事实**：Agent 任务终态清理：中间状态/临时文件/记忆挂载在任务 DONE/FAILED 后清理，防长尾泄漏
- **原理**：长运行 Agent 的资源纪律（JA-160 记忆清理的任务级版本），清理失败进补偿任务
- **常见误区**：
  1. 任务结束自动清理（错）
  2. 泄漏无后果（错）
  3. 清理与终态无关（错）
- **工程用法**：资源生命周期
- **版本锚点**：实战共识
