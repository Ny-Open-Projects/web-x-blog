## Spring AI · 校验（工具）

- **事实**：工具参数校验：模型回填的参数在执行前做应用层校验（类型/范围/权限）
- **原理**：模型填参可能错（幻觉参数），校验失败把错误信息回喂模型自修复（AI-043 联动），防线在应用层
- **常见误区**：
  1. 模型参数永远正确（错）
  2. 校验失败直接终止会话（错）
  3. 校验是可选装饰（错）
- **工程用法**：工具健壮性
- **版本锚点**：实战共识
