## 工程 · 契约（测试）

- **事实**：AI 组件契约测试：mock 模型验证业务逻辑（JA-041），契约测试验证"调用参数符合预期"（温度/模型/消息结构）
- **原理**：比 mock 更进一步：断言发出去的请求形态（回归保护 prompt/options 变更），与消费者契约测试思想同构
- **常见误区**：
  1. 测试只看返回值（错）
  2. 调用参数无需断言（错）
  3. 契约测试是可选装饰（错）
- **工程用法**：AI 测试深化
- **版本锚点**：实战共识
