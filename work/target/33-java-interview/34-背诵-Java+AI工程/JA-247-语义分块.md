## RAG · 语义分块（切分）

- **事实**：语义分块：按语义边界（句向量相似度断点）切分而非固定长度，质量更好成本更高
- **原理**：固定长度切断语义（JA-068 的局限），语义断点切分提升检索精度，嵌入成本换质量按域选
- **常见误区**：
  1. 语义分块不存在（错）
  2. 语义分块总是更优（错）
  3. 语义分块零成本（错）
- **工程用法**：切分策略选型
- **版本锚点**：实战共识
