## 工程 · 主备（合同）

- **事实**：多供应商合同策略：主供应商量大价优+备供应商小量保底（可快速放量条款），商务结构匹配技术降级链
- **原理**：JA-055 降级链的商务面：备供应商有合同与预热流量才真可切（JA-210 演练联动），与容灾商务结构（MY-094）同构
- **常见误区**：
  1. 备供应商随时可加（错）
  2. 合同与技术无关（错）
  3. 单供应商足够（错）
- **工程用法**：商务容灾
- **版本锚点**：实战共识
