## 工程 · 模型层（演进）

- **事实**：模型层能力自建的演进判断：调 API→网关→自部署开源模型→自训练，每步的成本/能力/团队门槛跃迁
- **原理**：JA-060 Java 定位的深度面：自建模型层的门槛评估（数据/算力/人才），多数企业停在网关+微调，与 AI-078 定位联动
- **常见误区**：
  1. 自训练是必经之路（错）
  2. 演进无门槛差异（错）
  3. 一直调 API 最好（错）
- **工程用法**：模型层演进
- **版本锚点**：实战共识
