## 工程 · 单测（模板）

- **事实**：prompt 模板单测：占位符渲染断言（缺参报错/特殊字符转义/长度边界）
- **原理**：模板是"代码"（AI-025 变更纪律），渲染失败要 fail-fast，与模板资源化（JA-078）配套
- **常见误区**：
  1. 模板不需要单测（错）
  2. 渲染失败静默跳过可接受（错）
  3. 单测只测业务逻辑（错）
- **工程用法**：模板质量门
- **版本锚点**：实战共识
