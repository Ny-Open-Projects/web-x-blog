## RAG · 版本（答案）

- **事实**：RAG 答案附知识版本：回答标注"基于知识库 vX（更新时间）"，答案可追溯知识状态
- **原理**：JA-490 快照的用户面：答案与知识版本绑定（可解释"为什么这么答"），审计与争议处理有据
- **常见误区**：
  1. 答案无需标注版本（错）
  2. 版本对用户无意义（错）
  3. 追溯不需要绑定（错）
- **工程用法**：答案可追溯
- **版本锚点**：实战共识
