## 流式 · 多路（合并）

- **事实**：多路流合并场景：主回答流+工具执行进度流并行推给前端（分通道渲染）
- **原理**：Agent 流式（JA-073 工具循环）的前端呈现：回答与"正在做什么"并行，通道化协议（事件类型字段）
- **常见误区**：
  1. 流只能单路（错）
  2. 工具进度不可见（错）
  3. 合并增加协议复杂度无收益（错）
- **工程用法**：Agent 流式体验
- **版本锚点**：实战共识
