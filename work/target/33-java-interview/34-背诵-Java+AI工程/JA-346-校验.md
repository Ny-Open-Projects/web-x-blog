## 工程 · 校验（配置）

- **事实**：AI 配置启动校验：密钥非空/模型名合法/超时关系合理（读超时>连接超时），fail-fast 在启动期
- **原理**：配置错误运行期才暴露是事故（AI-046），启动期校验（ConfigurationProperties 校验）把问题前移，与 MY 参数审查联动
- **常见误区**：
  1. 配置错误运行时自然暴露（错）
  2. 校验是可选装饰（错）
  3. 启动失败比运行失败更糟（错）
- **工程用法**：配置质量门
- **版本锚点**：实战共识
