## Spring AI · 聚合（流式）

- **事实**：流式聚合需求：Flux<String> 拼接完整回复做后处理（聚合完再落库/校验）
- **原理**：流式给用户、聚合给系统（校验/存档/审计）双消费，与 JA-207 后处理管线衔接
- **常见误区**：
  1. 流式与聚合互斥（错）
  2. 聚合要重新调用模型（错）
  3. 拼接不是流式用法（错）
- **工程用法**：流式消费双轨
- **版本锚点**：实战共识
