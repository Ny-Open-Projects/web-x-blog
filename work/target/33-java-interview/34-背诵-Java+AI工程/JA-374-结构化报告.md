## Agent · 结构化报告（输出）

- **事实**：Agent 任务输出结构化：最终产出按 schema（结论/依据/步骤/成本）交付，供程序消费
- **原理**：Agent 输出不是聊天文本而是工作产物（结构化 JA-003 思想），schema 化后可测可审可归档
- **常见误区**：
  1. Agent 输出纯文本即可（错）
  2. 结构化限制发挥（错）
  3. 输出无需 schema（错）
- **工程用法**：Agent 交付设计
- **版本锚点**：实战共识
