## 工程 · 池化（连接）

- **事实**：底层 HTTP 连接池随并发调优：LLM 长连接占用与普通 RPC 不同，池参数与并发模型匹配
- **原理**：LLM 响应慢导致连接占用时间长（DF-090 Little 定律联动），池小排队池大占资源，压测定参
- **常见误区**：
  1. 连接池默认最优（错）
  2. 池越大越好（错）
  3. LLM 连接短不需要池（错）
- **工程用法**：底层网络调优
- **版本锚点**：实战共识
