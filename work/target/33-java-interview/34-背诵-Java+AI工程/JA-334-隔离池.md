## 工程 · 隔离池（线程）

- **事实**：LLM 调用线程池独立隔离（不与业务 RPC 共享池）：LLM 慢响应占满共享池拖垮全服务
- **原理**：舱壁隔离（DF-027/SP-103）在 AI 依赖上的落地，WebFlux 则用事件循环（不阻塞），与超时分级（JA-166）配套
- **常见误区**：
  1. LLM 调用用公共线程池即可（错）
  2. 隔离池降低吞吐（错）
  3. WebFlux 也需要独立池（错）
- **工程用法**：线程池架构
- **版本锚点**：实战共识
