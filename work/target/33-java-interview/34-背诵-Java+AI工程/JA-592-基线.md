## 工程 · 基线（质量）

- **事实**：质量基线的版本绑定：每个发布版本的评估分数存档（版本-分数历史），回滚决策有据可查
- **原理**：JA-487 基线的存档面：分数历史是"质量账本"，回滚对比（新旧版本分数），与版本管理（JA-402）联动
- **常见误区**：
  1. 分数无需存档（错）
  2. 基线是当前值（错）
  3. 回滚凭感觉（错）
- **工程用法**：质量账本
- **版本锚点**：实战共识
