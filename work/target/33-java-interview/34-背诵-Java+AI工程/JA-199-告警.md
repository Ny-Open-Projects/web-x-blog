## 工程 · 告警（成本）

- **事实**：成本告警：日预算阈值告警（token 费用按域/租户聚合）+超预算自动降级到小模型
- **原理**：预算失控要有自动刹车（AI-026 成本四招的治理化），与 MY-082 容量告警思想同构
- **常见误区**：
  1. 成本只看月账单（错）
  2. 告警后人工处理即可（错）
  3. 降级与预算无关（错）
- **工程用法**：成本治理自动化
- **版本锚点**：实战共识
