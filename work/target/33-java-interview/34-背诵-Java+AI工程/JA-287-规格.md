## LangChain4j · 规格（工具）

- **事实**：LC4j 手动构建 ToolSpecification（不经注解）：名称/描述/JSON Schema 参数动态组装
- **原理**：与 Spring AI 手动规格（JA-178）对等，动态工具场景双框架同解，注解是静态场景捷径
- **常见误区**：
  1. LC4j 工具只能注解（错）
  2. 手动规格无 schema（错）
  3. 动态注册不存在（错）
- **工程用法**：动态工具对等
- **版本锚点**：LangChain4j 1.0
