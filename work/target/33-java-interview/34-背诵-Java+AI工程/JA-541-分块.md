## 多模态 · 分块（计费）

- **事实**：图像 token 计费的分块模式：按分辨率切成 tile 计费（大图分块多 token 多），控制尺寸即控制成本
- **原理**：AI-080 分辨率降本的计费机制面，理解分块才能精确预算（不同供应商分块规则不同，读文档）
- **常见误区**：
  1. 图像按张固定计费（错）
  2. 分块规则全行业统一（错）
  3. 成本无法预估（错）
- **工程用法**：多模态计费机制
- **版本锚点**：实战共识
