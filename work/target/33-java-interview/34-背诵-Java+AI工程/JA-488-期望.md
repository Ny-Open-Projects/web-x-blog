## 质量 · 期望（分群）

- **事实**：用户分群质量差异：新用户要引导性回答、专家用户要精确答案，分群评估防"平均数陷阱"
- **原理**：统一评估掩盖群体体验差（JA-289 分域的深化），分群看板（JA-395 灰度分群配套），与用户研究联动
- **常见误区**：
  1. 平均分代表一切（错）
  2. 分群评估是过度设计（错）
  3. 用户期望相同（错）
- **工程用法**：分群质量分析
- **版本锚点**：实战共识
