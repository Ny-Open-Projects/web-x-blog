## 中间件 · 降级路由（网关）

- **事实**：网关降级路由：主模型错误率超阈自动切备模型（路由表+健康检查驱动）
- **原理**：JA-055 降级链的网关侧自动化，切流决策基于拨测（JA-273）与实时错误率，与 DF-053 主从切换思想同构
- **常见误区**：
  1. 降级只能人工切（错）
  2. 自动切流不会误切（错）
  3. 路由表是静态的（错）
- **工程用法**：自动降级实现
- **版本锚点**：实战共识
