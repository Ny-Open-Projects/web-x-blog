## Agent · 任务模板（模板）

- **事实**：Agent 任务模板库：常见任务（工单处理/报告生成）的 prompt+工具组合模板化，新任务从模板派生
- **原理**：Agent 任务工程化复用（JA-623 与 prompt 资产库 JA-473 同构），模板带评估基线，派生后回归
- **常见误区**：
  1. Agent 任务每次手写（错）
  2. 模板限制灵活性（错）
  3. 模板无评估基线（错）
- **工程用法**：任务工程化
- **版本锚点**：实战共识
