## 多模态 · 多图（输入）

- **事实**：多图对比理解：单请求多图输入（对比两版本文档/两图找差异），图像顺序与编号引用
- **原理**：多图任务（比对/关联）与单图任务 prompt 结构不同，图像编号引用（图 1/图 2）让模型可指代
- **常见误区**：
  1. 多图输入不支持（错）
  2. 多图顺序无关（错）
  3. 对比任务与单图同 prompt（错）
- **工程用法**：多图任务设计
- **版本锚点**：实战共识
