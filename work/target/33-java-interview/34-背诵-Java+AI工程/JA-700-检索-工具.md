## RAG · 检索+工具（组合）

- **事实**：RAG 与工具混合回答：检索拿"文档知识"+工具拿"实时数据"（库存/价格）联合生成，路由决定用哪个或都用
- **原理**：RAG（静态知识）与工具（动态数据）的分工（JA-700 组合范式），Agent 框架天然支持（JA-053），按问题类型路由
- **常见误区**：
  1. RAG 与工具互斥（错）
  2. 全走工具最准（错）
  3. 路由不需要（错）
- **工程用法**：RAG+工具组合
- **版本锚点**：实战共识
