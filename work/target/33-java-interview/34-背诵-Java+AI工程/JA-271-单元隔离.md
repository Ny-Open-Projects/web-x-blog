## 工程 · 单元隔离（实验）

- **事实**：A/B 实验单元按用户 hash 分桶（同用户始终同版本），避免同一用户见到两版本
- **原理**：实验单元错配（按请求）导致体验混乱与数据污染（AI-063），与灰度（DF-050）联动
- **常见误区**：
  1. 实验单元按请求即可（错）
  2. 同一用户见两版本无影响（错）
  3. 分桶是可选装饰（错）
- **工程用法**：实验设计
- **版本锚点**：实战共识
