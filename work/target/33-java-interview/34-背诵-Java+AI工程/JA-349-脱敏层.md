## 工程 · 脱敏层（安全）

- **事实**：脱敏在两处：入库脱敏（知识库源数据）与出站脱敏（prompt 组装时替换 PII 为占位符）
- **原理**：双向防线（AI-040），入站防知识库泄露、出站防用户数据出域，占位符可回填还原（业务需要时）
- **常见误区**：
  1. 脱敏只在一处（错）
  2. 占位符无法还原（错）
  3. 脱敏影响模型质量必须放弃（错）
- **工程用法**：脱敏架构
- **版本锚点**：实战共识
