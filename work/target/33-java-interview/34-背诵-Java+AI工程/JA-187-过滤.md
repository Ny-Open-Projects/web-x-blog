## LangChain4j · 过滤（检索）

- **事实**：EmbeddingStoreContentRetriever 支持 .filter(...) 元数据过滤（与 LC4j Filter 表达式）
- **原理**：检索层过滤与 Spring AI filterExpression 同思想（JA-063），权限/类目隔离落地
- **常见误区**：
  1. RAG 不支持过滤（错）
  2. 过滤在生成层做（错）
  3. 过滤器是字符串拼接（错）
- **工程用法**：检索过滤对等实现
- **版本锚点**：LangChain4j 1.0
