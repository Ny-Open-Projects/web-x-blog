## 工程 · 可编辑（反馈）

- **事实**：输出可编辑性设计：用户可编辑 AI 输出后保存，编辑 diff 是最高质量反馈（用户想要什么一目了然）
- **原理**：JA-452 数据飞轮的富反馈面：编辑 diff 比点踩信息量大，编辑后版本可入 few-shot（JA-443），与产品交互设计联动
- **常见误区**：
  1. 输出不可编辑（错）
  2. 编辑数据无价值（错）
  3. 反馈只有点赞踩（错）
- **工程用法**：富反馈设计
- **版本锚点**：实战共识
