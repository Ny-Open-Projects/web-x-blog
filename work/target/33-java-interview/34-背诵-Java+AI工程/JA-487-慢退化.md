## 质量 · 慢退化（基线）

- **事实**：长期质量基线：季度对比防"慢退化"（每版本小退化累积成大滑坡）
- **原理**：单次回归抓瞬时退化（JA-392），跨版本累积趋势靠基线对比，趋势告警比阈值告警灵敏
- **常见误区**：
  1. 慢退化不存在（错）
  2. 只看单次回归（错）
  3. 基线对比是过度设计（错）
- **工程用法**：趋势监控
- **版本锚点**：实战共识
