## 工程 · 出口（网络）

- **事实**：LLM 出口流量隔离：独立出口 IP/网段（代理层），审计与防火墙策略针对 AI 出口单独设
- **原理**：AI-268 出网适配的安全面：出口隔离让审计（JA-312）与封禁策略独立，与网络分区思想联动
- **常见误区**：
  1. LLM 流量无需隔离（错）
  2. 隔离增加延迟不可接受（错）
  3. 审计在应用层足够（错）
- **工程用法**：网络层安全
- **版本锚点**：实战共识
