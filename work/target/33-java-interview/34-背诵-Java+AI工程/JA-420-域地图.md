## 工程 · 域地图（收束）

- **事实**：Java AI 域知识地图收束：框架双栈→协议（MCP）→管道（RAG/ETL）→Agent→中间件（网关/缓存/配额）→治理（评估/成本/安全/组织），420 条事实的组织骨架
- **原理**：与 JA-360 知识地图呼应（半程收束），后续批次填充剩余分支，复习按地图检索矩阵行
- **常见误区**：
  1. 知识地图是入门工具（错）
  2. 地图覆盖不了全部（错）
  3. 治理不是知识的一部分（错）
- **工程用法**：本域半程收束
- **版本锚点**：实战方法论
