## 工程 · 演练（灾备）

- **事实**：AI 依赖灾备演练矩阵：供应商宕机（切网关）、限流（降级）、上下文超限（裁剪）、成本失控（熔断）四场景季度演练
- **原理**：失败模式矩阵（JA-239）的演练化，每场景验证降级链与告警，与 DF-076 混沌工程联动
- **常见误区**：
  1. 演练只覆盖宕机（错）
  2. AI 依赖不需要演练（错）
  3. 演练一次永久有效（错）
- **工程用法**：韧性验证
- **版本锚点**：实战共识
