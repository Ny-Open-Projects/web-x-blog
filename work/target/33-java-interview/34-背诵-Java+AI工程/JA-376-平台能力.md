## 中台 · 平台能力（定位）

- **事实**：AI 中台四大平台能力：统一模型接入（网关）、评估服务（评测集+判分）、成本治理（配额/归集/告警）、安全合规（护栏/审计/脱敏）
- **原理**：把 JA-317 网关扩展为中台全景，多业务复用一套治理（DF-088 平台化），P10 视角的组织级架构
- **常见误区**：
  1. 中台就是网关（错）
  2. 四能力各自建没协同（错）
  3. 中台是伪需求（错）
- **工程用法**：中台架构定义
- **版本锚点**：实战方法论
