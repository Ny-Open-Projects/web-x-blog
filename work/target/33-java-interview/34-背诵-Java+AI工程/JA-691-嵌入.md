## 缓存 · 嵌入（成本）

- **事实**：语义缓存自身的嵌入成本：查询向量化是缓存检查的前置成本（高频查询向量化开销可观），嵌入结果缓存（JA-578）配套
- **原理**：语义缓存不是零成本（JA-578 嵌入缓存的联动面），净收益=省的调用-嵌入成本，与成本核算（JA-290）联动
- **常见误区**：
  1. 语义缓存零成本（错）
  2. 嵌入成本可忽略（错）
  3. 净收益不用算（错）
- **工程用法**：缓存净收益
- **版本锚点**：实战共识
