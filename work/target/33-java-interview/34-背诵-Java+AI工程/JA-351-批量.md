## Spring AI · 批量（向量）

- **事实**：VectorStore.add 批量写入的事务性考量：大批量分批写+失败批重试（幂等，upsert 语义按 id）
- **原理**：与 JA-100 嵌入批量配套，向量库批量写入失败恢复（部分成功场景），与 MY-081 批处理思想同构
- **常见误区**：
  1. 批量写入全成功或全失败（错）
  2. 失败重试会重复（错）
  3. 写入不需要幂等（错）
- **工程用法**：入库可靠性
- **版本锚点**：实战共识
