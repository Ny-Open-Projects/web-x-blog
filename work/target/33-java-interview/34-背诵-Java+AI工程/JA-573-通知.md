## 工程 · 通知（灰度）

- **事实**：灰度期用户通知：灰度用户可见"体验新版功能"标识（反馈通道绑定版本），反馈可归因到版本
- **原理**：反馈归因（JA-451/404）的前提：无版本标识的反馈无法分桶，通知与反馈通道设计联动
- **常见误区**：
  1. 灰度静默进行（错）
  2. 用户通知无必要（错）
  3. 反馈无需版本关联（错）
- **工程用法**：灰度-反馈闭环
- **版本锚点**：实战共识
