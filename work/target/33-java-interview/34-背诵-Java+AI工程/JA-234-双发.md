## 工程 · 双发（回滚）

- **事实**：模型/prompt 双发（shadow）：新版本影子流量跑（不返回用户），对比效果后再放量
- **原理**：比 A/B 更保守的验证（用户无感），影子结果进评估管线，与全链路灰度（DF-051）同构
- **常见误区**：
  1. 双发会重复计费无价值（影子成本可控是设计项）（错）
  2. 影子流量直接返回用户（错）
  3. 双发与灰度等价（错）
- **工程用法**：低风险验证
- **版本锚点**：实战共识
