## 工程 · 合规（风险）

- **事实**：跨境数据合规细节：模型调用数据的出境评估（数据含用户数据出境合规）、网关区域路由（JA-267）落地证据
- **原理**：数据出境是法务硬要求（JA-551 行业叠加），技术证据（路由日志）支撑合规声明，与合规审计（JA-630）联动
- **常见误区**：
  1. 出境合规与工程无关（错）
  2. 路由即合规（还需证据链）（错）
  3. 评估一次性（错）
- **工程用法**：跨境合规细节
- **版本锚点**：实战共识
