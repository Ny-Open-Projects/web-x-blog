## 工程 · 清单（验收）

- **事实**：AI 项目验收清单：功能验收（评估分达 SLO JA-354）+工程验收（JA-525 五项）+文档验收（JA-343 六段）+运营移交（值班/运营日历）
- **原理**：项目交付的完整验收框架（交付≠上线），验收清单防"开发完就散"，与项目治理联动
- **常见误区**：
  1. AI 项目验收看演示（错）
  2. 清单是形式主义（错）
  3. 运营移交不需要（错）
- **工程用法**：验收框架
- **版本锚点**：实战共识
