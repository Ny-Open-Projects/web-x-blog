## Spring AI · 异常（Advisor）

- **事实**：advisor 链异常传播：前置异常阻断调用（降级 advisor 实现），异常沿链上抛给调用方
- **原理**：advisor 是拦截器语义（SP-066 对比），异常处理在链路层统一（兜底 advisor 吞异常给降级），与熔断（JA-154）组合
- **常见误区**：
  1. advisor 异常被框架吞掉（错）
  2. 异常传播会破坏链（错）
  3. 异常处理只能在业务层（错）
- **工程用法**：链路异常设计
- **版本锚点**：Spring AI 1.0 GA
