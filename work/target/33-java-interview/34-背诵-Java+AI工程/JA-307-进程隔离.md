## MCP · 进程隔离（生产）

- **事实**：MCP server 子进程的资源与安全隔离：容器化运行（限额 CPU/内存/文件系统只读）
- **原理**：子进程默认继承宿主权限（AI-076 沙箱思想），容器隔离防恶意/失控 server 影响宿主
- **常见误区**：
  1. 子进程隔离不必要（错）
  2. 容器化影响功能（错）
  3. 隔离只对远程 server（错）
- **工程用法**：本地 server 安全
- **版本锚点**：MCP 生产化
