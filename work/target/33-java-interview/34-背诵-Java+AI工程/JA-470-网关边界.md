## 工程 · 网关边界（架构）

- **事实**：网关边界职责收缩：业务语义（prompt 模板/评估集）不上网关（网关只管流量语义），边界混则平台僵化
- **原理**：JA-317 六职责的边界纪律（什么不该做），中台各层职责清晰（JA-376），与单一职责原则联动
- **常见误区**：
  1. 网关管所有 AI 事（错）
  2. 边界不重要（错）
  3. 业务语义上网关灵活（错）
- **工程用法**：平台边界纪律
- **版本锚点**：实战共识
