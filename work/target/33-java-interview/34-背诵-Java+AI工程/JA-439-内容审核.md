## 场景 · 内容审核（审核）

- **事实**：内容审核管线：机审（模型+规则）→置信度分级→低置信度人审→复审闭环，准确率与审核量权衡
- **原理**：审核场景的特征（高吞吐+误判代价不对称），分级审核优化人力（JA-437 思想），与风控知识联动
- **常见误区**：
  1. 内容审核全自动（错）
  2. 人审队列无优先级（错）
  3. 置信度不需要分级（错）
- **工程用法**：审核管线设计
- **版本锚点**：实战共识
