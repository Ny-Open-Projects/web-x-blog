## 流式 · 增量渲染（渲染）

- **事实**：流式 UI 的 Markdown 增量渲染：半截 Markdown（未闭合代码块/表格）的渲染策略（缓冲到块边界再渲染）
- **原理**：逐 token 直染会出现闪烁与格式错乱，按块边界渲染是体验工程，与前端协作的接口约定
- **常见误区**：
  1. 流式渲染逐字直出最优（错）
  2. 渲染是前端的事与后端无关（错）
  3. 缓冲会增加首字延迟（权衡可配）（错）
- **工程用法**：流式体验工程
- **版本锚点**：实战共识
