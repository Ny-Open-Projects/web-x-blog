## 工程 · 演进（架构）

- **事实**：网关到路由智能化的演进：静态路由表→规则路由（JA-232）→智能路由（按历史表现学习），演进有数据支撑
- **原理**：JA-321 降级路由的智能化方向，路由决策从配置到学习（保守演进），与平台演进（JA-377）同构
- **常见误区**：
  1. 路由智能化一步到位（错）
  2. 学习路由风险低（错）
  3. 演进无必要（错）
- **工程用法**：路由演进
- **版本锚点**：实战共识
