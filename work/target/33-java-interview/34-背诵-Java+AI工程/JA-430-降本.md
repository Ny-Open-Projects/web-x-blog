## 多模态 · 降本（预处理）

- **事实**：图像预处理降本：分辨率压缩到模型有效分辨率、裁剪无关区域，token 成本线性下降
- **原理**：AI-080 计费按分辨率的工程对策，预处理管线（压缩/裁剪/格式转换）在发送前执行
- **常见误区**：
  1. 原图直接发最优（错）
  2. 预处理影响理解质量（适度压缩无碍）（错）
  3. 成本无法下降（错）
- **工程用法**：多模态成本工程
- **版本锚点**：实战共识
