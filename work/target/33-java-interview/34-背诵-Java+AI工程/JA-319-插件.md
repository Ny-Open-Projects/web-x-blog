## 中间件 · 插件（网关）

- **事实**：网关插件链：敏感词过滤/注入检测/审计/配额校验按序执行（类似 Servlet 过滤器链）
- **原理**：横切能力下沉网关（应用免重复实现），插件顺序影响行为（先审计后过滤），与 JA-225 注入防线呼应
- **常见误区**：
  1. 网关不可扩展插件（错）
  2. 插件顺序无关（错）
  3. 横切能力放应用层（错）
- **工程用法**：网关扩展模型
- **版本锚点**：实战共识
