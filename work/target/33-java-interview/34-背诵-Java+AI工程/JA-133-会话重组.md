## Spring AI · 会话重组（消息）

- **事实**：完整对话重组：把历史 Message 列表加当前 UserMessage 一次传入 ChatModel.call
- **原理**：绕过记忆 advisor 手动组装消息序列（迁移/批处理场景），与记忆机制等价但显式可控
- **常见误区**：
  1. 历史必须经记忆 advisor 注入（错）
  2. 手动组装会被框架拒绝（错）
  3. 一次只能传一条消息（错）
- **工程用法**：批处理/迁移场景
- **版本锚点**：Spring AI 1.0 GA
