## 工程 · 训练边界（数据）

- **事实**：企业数据与供应商训练边界：API 数据默认不用于训练（供应商条款），仍需合同与脱敏双保险
- **原理**：AI-040 合规的条款面，技术措施（脱敏/网关）+合同措施并行，与安全审计联动
- **常见误区**：
  1. API 数据一定被训练（错）
  2. 条款足够无需技术措施（错）
  3. 脱敏与条款二选一（错）
- **工程用法**：合规双保险
- **版本锚点**：实战共识
