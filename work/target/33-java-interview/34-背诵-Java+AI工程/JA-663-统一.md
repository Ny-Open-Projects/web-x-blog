## 多模态 · 统一（预算）

- **事实**：多模态与文本 token 预算统一管理：图像 token 折算后与文本同池预算（一个请求的总预算视图）
- **原理**：JA-223 预算分配的多模态版：图像占预算大（JA-541 分块），统一视图才能做取舍（减图 or 减文本）
- **常见误区**：
  1. 图像与文本预算分开管（错）
  2. 统一预算无必要（错）
  3. 图像不计入预算（错）
- **工程用法**：统一预算管理
- **版本锚点**：实战共识
