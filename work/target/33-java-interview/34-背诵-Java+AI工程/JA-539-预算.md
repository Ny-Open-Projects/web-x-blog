## 工程 · 预算（测试）

- **事实**：测试环境模型预算：测试环境也计费（评估/集成测试调用真实供应商），测试预算与生产隔离统计
- **原理**：测试成本是隐性成本（JA-204 评估成本延伸），测试配额独立（防止测试挤占生产配额 JA-059），与成本分摊（JA-290）联动
- **常见误区**：
  1. 测试环境不产生成本（错）
  2. 测试与生产共享配额（错）
  3. 预算只管生产（错）
- **工程用法**：测试成本治理
- **版本锚点**：实战共识
