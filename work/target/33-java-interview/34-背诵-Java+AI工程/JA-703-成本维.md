## 评测 · 成本维（AB）

- **事实**：A/B 实验的成本维度：两版本 token 成本对比进实验报告（质量赢了但成本翻倍要权衡）
- **原理**：实验不只看质量（JA-271 的成本维），成本差异是决策维度（JA-403 帕累托），与预算治理（JA-461）联动
- **常见误区**：
  1. A/B 只看质量（错）
  2. 成本与实验无关（错）
  3. 报告不需要成本（错）
- **工程用法**：实验成本维度
- **版本锚点**：实战共识
