## 中间件 · 兼容层（网关）

- **事实**：网关的 OpenAI 协议兼容层：统一对外 OpenAI 协议，对内翻译各家协议（Anthropic/通义等）
- **原理**：应用只学一套协议（JA-096），协议转换在网关（含消息结构与流式格式差异），是网关存在的第一理由
- **常见误区**：
  1. 各供应商协议完全相同（错）
  2. 兼容层无转换成本（错）
  3. 应用直连更简单（错）
- **工程用法**：协议适配
- **版本锚点**：实战共识
