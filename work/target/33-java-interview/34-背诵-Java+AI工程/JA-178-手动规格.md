## Spring AI · 手动规格（工具）

- **事实**：Spring AI 支持手动构建 ToolCallback（不经 @Tool 注解），动态注册运行时工具
- **原理**：动态工具场景（插件化/配置驱动工具），规格在运行时组装，与 MCP 动态工具（JA-094）联动
- **常见误区**：
  1. 工具只能注解静态声明（错）
  2. 动态注册不被支持（错）
  3. 手动规格是旧 API（错）
- **工程用法**：动态工具场景
- **版本锚点**：Spring AI 1.0 GA
