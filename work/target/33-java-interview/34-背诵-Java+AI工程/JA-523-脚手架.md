## 工程 · 脚手架（开发）

- **事实**：AI 功能脚手架：模板工程（ChatClient 装配/评估集骨架/降级配置/观测埋点四件预置），新功能半天起步
- **原理**：标准化的开发效率（JA-343 组件文档的代码面），脚手架固化最佳实践（JA-285 清单内置），与脚手架工程实践联动
- **常见误区**：
  1. 脚手架是过度设计（错）
  2. 每个功能从零搭（错）
  3. 模板固化过时实践（错）
- **工程用法**：开发效率工程
- **版本锚点**：实战共识
