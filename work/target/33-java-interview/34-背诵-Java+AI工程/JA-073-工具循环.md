## Spring AI · 工具循环（流式）

- **事实**：stream 模式同样支持工具调用循环（流式输出中穿插工具执行）
- **原理**：流式与工具能力正交，流式期间工具结果回填后继续生成，前端体验与能力兼得
- **常见误区**：
  1. stream 模式不支持工具（错）
  2. 工具结果只有流结束后才处理（错）
  3. 流式调用必须关闭工具（错）
- **工程用法**：流式 Agent 场景
- **版本锚点**：Spring AI 1.0 GA
