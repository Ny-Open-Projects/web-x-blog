## 工程 · 自动化（演进）

- **事实**：运维自动化演进：手动处理→runbook 脚本化→自动处置（限流/切流自动执行），人工只审批异常
- **原理**：JA-583 演练自动化的推广（运维成熟度阶梯），自动化范围逐步扩大（审批保留在关键动作），与 AIOps 思想联动
- **常见误区**：
  1. 运维永远手动（错）
  2. 自动化一步到位（错）
  3. 审批是多余（错）
- **工程用法**：运维成熟度
- **版本锚点**：实战共识
