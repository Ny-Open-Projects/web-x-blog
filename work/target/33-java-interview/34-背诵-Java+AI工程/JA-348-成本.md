## 工程 · 成本（结构化）

- **事实**：结构化输出的 token 成本：schema 注入增加输入 token（大 schema 显著），schema 精简也是成本优化
- **原理**：JA-062 瘦身的 schema 版：嵌套描述/示例可精简，与输出稳定性权衡（JA-298）
- **常见误区**：
  1. schema 注入免费（错）
  2. schema 越详细越好（错）
  3. 成本与 schema 无关（错）
- **工程用法**：结构化成本
- **版本锚点**：实战共识
