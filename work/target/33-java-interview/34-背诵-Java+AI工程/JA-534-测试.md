## 工程 · 测试（安全）

- **事实**：工具诱导专项测试：诱导 Agent 调用高危工具（删除/转账）的对抗样本，验证权限防线（JA-235）
- **原理**：JA-474 注入测试的 Agent 特化：工具诱导是最危险的注入（真实副作用），防线测试是安全验收项
- **常见误区**：
  1. 工具诱导无法测试（错）
  2. 权限校验已足够（错）
  3. 测试样本随机构造（错）
- **工程用法**：工具安全测试
- **版本锚点**：实战共识
