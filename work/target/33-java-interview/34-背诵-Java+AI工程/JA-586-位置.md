## 评测 · 位置（偏差）

- **事实**：评测的位置偏差控制：few-shot 示例顺序/golden 集排列随机化（位置影响判分与生成）
- **原理**：评估严谨性细节（JA-364 同族）：位置偏差让评测分数不稳定，随机化+多次评测取均值
- **常见误区**：
  1. 位置无影响（错）
  2. 固定顺序更稳定（错）
  3. 偏差无需控制（错）
- **工程用法**：评测严谨性
- **版本锚点**：实战共识
