## 模型 · 失败分类（结构化）

- **事实**：结构化输出失败三分类：截断（LENGTH 咬掉 JSON 尾）/格式漂移（字段名错/多 Markdown 包裹）/幻觉字段（编造枚举值），各对应不同修法
- **原理**：JA-099 的分类细化：截断调 maxTokens、格式靠宽松解析、幻觉靠 schema 约束+重试，混修错配
- **常见误区**：
  1. 失败原因无法分类（错）
  2. 统一重试解决一切（错）
  3. 分类是过度设计（错）
- **工程用法**：结构化排障
- **版本锚点**：实战共识
