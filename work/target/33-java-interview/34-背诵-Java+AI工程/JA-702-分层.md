## 评测 · 分层（采样）

- **事实**：评估抽样策略随错误率自适应：错误率高时全量细查，错误率低时抽样维护，资源按风险分配
- **原理**：JA-204 抽样的自适应版：固定比例不经济（稳定期浪费/风险期不足），自适应比例，与风险驱动思想联动
- **常见误区**：
  1. 固定比例抽样最优（错）
  2. 自适应无法实现（错）
  3. 抽样与风险无关（错）
- **工程用法**：自适应抽样
- **版本锚点**：实战共识
