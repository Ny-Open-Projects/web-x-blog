## 工程 · 护栏（质量）

- **事实**：护栏分级执行：硬护栏（合规红线，阻断）与软护栏（风格建议，标注不阻断），分级避免护栏过度
- **原理**：JA-019/193 护栏的分级面，全部硬护栏会误伤（风格问题不该阻断），分级配置化
- **常见误区**：
  1. 护栏全部阻断（错）
  2. 分级是形式主义（错）
  3. 软护栏无价值（错）
- **工程用法**：护栏分级
- **版本锚点**：实战共识
