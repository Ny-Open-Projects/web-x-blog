## 工程 · 演进（架构）

- **事实**：AI 应用架构演进：MVP（直连+硬编码 prompt）→组件化（框架+RAG）→平台化（网关+中台）→智能化（Agent+自动化评估）
- **原理**：JA-377 演进在应用层的版本，每阶段有触发信号（业务量/质量要求），与演进式架构（DF-084）联动
- **常见误区**：
  1. 架构一步到位（错）
  2. 演进无触发信号（错）
  3. 智能化是终点（错）
- **工程用法**：架构演进路线
- **版本锚点**：实战方法论
