## LangChain4j · 校验（工具）

- **事实**：LC4j 工具同样需要应用层参数校验：ToolExecutionRequest 的 arguments 反序列化后先验后执行
- **原理**：两框架同构知识（JA-171），错误反馈机制让 Agent 自我修复，校验逻辑写进工具入口
- **常见误区**：
  1. LC4j 自动校验参数（错）
  2. 校验与框架冲突（错）
  3. 不做校验更稳定（错）
- **工程用法**：工具健壮性
- **版本锚点**：LangChain4j 1.0
