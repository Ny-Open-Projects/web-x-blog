## RAG · 组装（管道）

- **事实**：Java 侧 RAG 管道组装顺序：Reader 读→Splitter 切→EmbeddingModel 向量化→VectorStore 写入→检索时 QuestionAnswerAdvisor/ContentRetriever 注入
- **原理**：离线入库与在线检索两段式，两框架组件一一对应（思想同构），管道每步可替换实现
- **常见误区**：
  1. RAG 管道必须离线在线一体（错）
  2. 向量化在检索时才做（错）
  3. 切分在检索时进行（错）
- **工程用法**：RAG 架构答题框架
- **版本锚点**：实战共识
