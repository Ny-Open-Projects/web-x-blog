## Spring AI · 循环观测（工具）

- **事实**：工具循环的观测埋点：每轮（第 N 轮/调用了什么/耗时）打点，循环异常（步数超阈/重复调用）告警
- **原理**：Agent 轨迹（JA-219）的轻量版（观测事件而非落库），与步数上限（JA-276）联动，循环分析定位 Agent 卡点
- **常见误区**：
  1. 循环内部不可观测（错）
  2. 埋点影响性能显著（错）
  3. 重复调用是正常（错）
- **工程用法**：循环可观测
- **版本锚点**：实战共识
