## RAG 评测 · 判分（忠实度）

- **事实**：忠实度自动判分：LLM judge 比对答案与检索片段（答案的断言是否被片段支持），输出支持/不支持/部分
- **原理**：JA-272 判分机制在 RAG 的特化，幻觉的自动化度量（人工全评不可行），judge 提示词定义"支持"标准
- **常见误区**：
  1. 忠实度无法自动评（错）
  2. judge 与答案模型必须相同（错）
  3. 判分结果无需校准（错）
- **工程用法**：RAG 生成评测
- **版本锚点**：实战共识
