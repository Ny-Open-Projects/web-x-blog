## 质量 · 多模型（集成）

- **事实**：多模型投票集成：多供应商同题生成，判分器选优或合并，供应商多样性防单点
- **原理**：比自一致性更贵但更多样（JA-446 扩展），关键决策类任务用（成本容忍），与降级链（JA-055）区分（主动质量 vs 被动容错）
- **常见误区**：
  1. 多模型投票与降级相同（错）
  2. 集成提升一切任务（错）
  3. 成本可忽略（错）
- **工程用法**：集成策略
- **版本锚点**：实战共识
