## 工程 · 标签（反馈）

- **事实**：反馈标签体系：点踩原因枚举（事实错误/答非所问/格式差/太慢/其他），结构化回流定位
- **原理**：无标签的点踩无法归因（JA-341 闭环的输入质量），标签驱动分类统计（JA-289 看板），与工单分类联动
- **常见误区**：
  1. 点踩只有一个按钮（错）
  2. 标签体系是过度设计（错）
  3. 标签用户不会选（错）
- **工程用法**：反馈结构化
- **版本锚点**：实战共识
