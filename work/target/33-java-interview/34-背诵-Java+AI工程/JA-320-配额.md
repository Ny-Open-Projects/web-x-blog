## 中间件 · 配额（网关）

- **事实**：网关多租户配额：按租户/业务/模型三维配额（token/请求数），超限 429+升级路径
- **原理**：JA-206 三级限流的网关侧实现，配额数据结构（令牌桶按租户分桶），与 Redis 限流（RD-057）联动
- **常见误区**：
  1. 配额只有全局一种（错）
  2. 超限直接丢弃无升级（错）
  3. 三维互斥（错）
- **工程用法**：配额模型
- **版本锚点**：实战共识
