## 多模态 · 解析（PDF）

- **事实**：扫描件 PDF 解析两路线：传统 OCR 管线（识别+版面）vs 视觉模型直读（端到端），精度与成本权衡
- **原理**：企业文档大量扫描件（JA-190 解析器局限），视觉直读简单但贵、OCR 便宜但管线复杂，按量选
- **常见误区**：
  1. 扫描件无法数字化（错）
  2. OCR 已被视觉模型淘汰（错）
  3. 两路线不能混用（错）
- **工程用法**：文档数字化选型
- **版本锚点**：实战共识
