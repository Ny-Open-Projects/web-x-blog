## MCP · 错误码（错误）

- **事实**：MCP 基于 JSON-RPC 的错误码体系返回失败（方法不存在/参数错误/工具执行失败）
- **原理**：错误处理按码分派（区别业务失败与协议失败），客户端把工具失败回喂模型重试
- **常见误区**：
  1. MCP 错误没有结构（错）
  2. 所有失败都是异常抛出（错）
  3. 错误码可自定义语义（错）
- **工程用法**：MCP 错误处理
- **版本锚点**：MCP 规范
