## Agent · 追溯（可解释）

- **事实**：Agent 可解释性：轨迹（JA-219）+每步推理文本（模型思考过程）+工具证据（结果快照）构成解释链
- **原理**：用户/审计问"为什么这么做"的回答材料，解释链与轨迹分离（轨迹给系统、解释给人类），与可解释 AI 实践联动
- **常见误区**：
  1. 可解释性不可实现（错）
  2. 只有轨迹就够（错）
  3. 推理文本不可获得（错）
- **工程用法**：解释链设计
- **版本锚点**：实战共识
