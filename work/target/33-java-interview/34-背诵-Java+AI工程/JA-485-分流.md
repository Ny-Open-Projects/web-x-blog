## 质量 · 分流（triage）

- **事实**：回归失败 triage 流程：先查评估集（条目是否过时/标注错）再查模型（供应商更新）最后查代码，三段排查
- **原理**：回归失败不等于真退化（JA-347 漂移/JA-364 标注噪声），triage 防"误回滚"，与故障分流（JA-356）同构
- **常见误区**：
  1. 回归失败立即回滚（错）
  2. 评估集永远正确（错）
  3. triage 是浪费时间（错）
- **工程用法**：回归治理
- **版本锚点**：实战共识
