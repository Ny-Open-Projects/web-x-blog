## GC · 可达性分析（判定）

- **事实**：存活判定用 GC Roots 可达性分析而非引用计数
- **原理**：引用计数无法解决循环引用（A 引 B、B 引 A 都不再使用），Java 用的就是可达性分析
- **常见误区**：
  1. Java 用引用计数判活（错）
  2. 循环引用的对象会被可达性分析回收掉（错）
  3. 可达性分析必须全程 STW（实际是并发标记）（错）
- **工程用法**：回答"Java 如何判定对象死亡"的标准答案
- **版本锚点**：理论共识
