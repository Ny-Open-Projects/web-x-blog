## GC · 引用处理（清理）

- **事实**：处理 Reference（软/弱/虚）本身在 GC 的 STW 或并发阶段执行
- **原理**：大量 Reference 对象（如海量 WeakReference 缓存）会拉长引用处理阶段，软引用缓存泛滥是老年代暴涨经典案例
- **常见误区**：
  1. 引用处理免费（错）
  2. 软引用是推荐的通用缓存方案（错）
  3. Reference 数量与 GC 无关（错）
- **工程用法**：软引用缓存的反面教材
- **版本锚点**：HotSpot
