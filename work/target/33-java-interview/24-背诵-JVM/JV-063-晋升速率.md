## GC · 晋升速率（指标）

- **事实**：GC 分析核心指标：分配速率、晋升速率、回收后堆占用趋势
- **原理**：分配速率高→Minor GC 频繁；晋升速率高→老年代增长快→Full GC；回收后老年代持续走高=泄漏或缓存过大，趋势比单次数字重要
- **常见误区**：
  1. Minor GC 频繁一定是坏事（错）
  2. 老年代占用上升就是泄漏（错）
  3. GC 次数是唯一重要指标（错）
- **工程用法**：容量规划与告警都基于趋势
- **版本锚点**：实战方法论
