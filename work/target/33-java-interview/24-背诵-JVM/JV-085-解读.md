## GC · 解读（日志）

- **事实**：一次 GC 日志四要素：触发原因、回收前后各代占用、停顿时长、GC 线程数
- **原理**：触发原因（Allocation Failure/G1 Humongous Allocation/System.gc）直接指明优化方向，Pause 时间是 SLO 对账依据
- **常见误区**：
  1. 日志看不出触发原因（错）
  2. 回收前后数字是 MB 单位的哈希值（错）
  3. 停顿时间不需要关注（错）
- **工程用法**：日志分析模板化
- **版本锚点**：实战方法论
