## GC · 模板（排查）

- **事实**：GC 问题排查模板：先看趋势（jstat/日志）→ 定位代与阶段 → 找触发原因 → 看对象（dump/JFR）→ 改参数或代码 → A/B 验证
- **原理**：每步有对应工具与关键字，形成可复用的方法论而非背零散参数，是 P10 层面的回答框架
- **常见误区**：
  1. 排查从换收集器开始（错）
  2. dump 分析是第一步（错）
  3. 排查不需要基线数据（错）
- **工程用法**：回答"线上 GC 问题怎么排查"的框架
- **版本锚点**：实战方法论
