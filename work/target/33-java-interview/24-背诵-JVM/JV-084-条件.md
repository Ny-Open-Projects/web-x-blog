## 类加载 · 条件（卸载）

- **事实**：类卸载三条件：该类所有实例已回收、ClassLoader 已回收、Class 对象无引用
- **原理**：三者缺一不可，所以自定义 ClassLoader 泄漏导致其加载的全部类无法卸载（元空间泄漏放大器）
- **常见误区**：
  1. 类不用了就会被卸载（错）
  2. Class 对象可以单独被卸载（错）
  3. 卸载由 GC 主动定时执行（错）
- **工程用法**：动态类生成框架必须管好 ClassLoader 生命周期
- **版本锚点**：JVM 规范
