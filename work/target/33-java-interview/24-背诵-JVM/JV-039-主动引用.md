## 类加载 · 主动引用（初始化）

- **事实**：主动引用才触发类初始化：new、读写非编译期常量静态字段、反射调用、子类初始化触发父类等
- **原理**：访问 static final 编译期常量（入常量池）不触发初始化，通过数组定义引用类也不触发
- **常见误区**：
  1. 访问任何 static 字段都触发初始化（错）
  2. 读取 static final 常量也会触发初始化（错）
  3. 父类初始化需要子类先完成（错）
- **工程用法**：解释"常量不触发初始化"的经典案例
- **版本锚点**：JLS 12.4.1
