## 收集器 · SATB（G1）

- **事实**：G1 用 SATB（原始快照）解决并发标记时对象消失问题
- **原理**：标记开始时拍逻辑快照，并发期被删引用的对象按快照保留（可能产生浮动垃圾），CMS 用增量更新只记录新引用
- **常见误区**：
  1. G1 与 CMS 用同一种并发标记方案（错）
  2. SATB 不会产生浮动垃圾（错）
  3. SATB 在标记结束后重新扫描全部根（错）
- **工程用法**：对比 G1 与 CMS 的并发标记差异
- **版本锚点**：理论共识
