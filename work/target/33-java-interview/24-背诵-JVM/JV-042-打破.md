## 类加载 · 打破（双亲委派）

- **事实**：SPI、Tomcat webapp、OSGi 等场景打破双亲委派
- **原理**：SPI 核心接口由 Bootstrap 加载但实现类在 classpath，用线程上下文类加载器反向委派；Tomcat 每 webapp 独立加载器实现应用隔离
- **常见误区**：
  1. 打破双亲委派是不安全行为被禁止（错）
  2. 线程上下文类加载器与双亲委派无关（错）
  3. Tomcat 遵循严格双亲委派（错）
- **工程用法**：回答"双亲委派可以被打破吗"必举例
- **版本锚点**：实战共识
