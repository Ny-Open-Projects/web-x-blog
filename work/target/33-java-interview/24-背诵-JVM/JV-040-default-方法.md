## 类加载 · default 方法（接口）

- **事实**：带 default 方法的接口会在实现类初始化时被初始化
- **原理**：JLS 12.4.1 规定（Java8 引入 default 后修订），纯抽象接口不被实现类初始化触发（本项目实测验证）
- **常见误区**：
  1. 接口永远不被初始化（错）
  2. 所有接口都随实现类初始化（错）
  3. 接口初始化早于实现类（错）
- **工程用法**：判断接口静态块执行时机的依据
- **版本锚点**：JLS 12.4.1 实测
