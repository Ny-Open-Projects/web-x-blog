## 内存 · 元空间（泄漏）

- **事实**：元空间泄漏源：动态生成类未卸载（CGLib 代理、Groovy 脚本、反射 inflation）
- **原理**：每个生成的 Class 都进元空间，类卸载需要其 ClassLoader 卸载，反复生成新类（如每次 new 代理）撑爆元空间
- **常见误区**：
  1. 元空间不会泄漏（错）
  2. CGLib 代理类会被自动回收（错）
  3. 类卸载与 ClassLoader 无关（错）
- **工程用法**：动态代理必须缓存代理类
- **版本锚点**：实战共识
