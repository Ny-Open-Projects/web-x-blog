## List · quicklist（编码）—— 7 类问法与标准话术

**Qredis-22（概念考察·P1-P3）**
【面试官】请谈谈你对「List」中「quicklist」的理解。
【标准回答话术】List 底层是 quicklist（双向链表串起的紧凑节点），7.0 起节点从 ziplist 换成 listpack。背后的原理是：兼顾链表的插入效率与紧凑结构的内存效率，7.0 用 listpack 消除 ziplist 的级联更新问题。
【评分点】① 准确说出核心机制（quicklist）；② 能带出原理层而非背结论。 ③ 版本锚点：Redis 7.0
