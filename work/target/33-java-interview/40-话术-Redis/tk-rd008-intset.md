## Set · intset（编码）—— 7 类问法与标准话术

**Qredis-50（概念考察·P1-P3）**
【面试官】请谈谈你对「Set」中「intset」的理解。
【标准回答话术】Set 全整数且数量少时用 intset（紧凑整数数组）编码。背后的原理是：整数数组二分查找省内存，加入字符串元素自动转 hashtable，编码自动升级不可逆。
