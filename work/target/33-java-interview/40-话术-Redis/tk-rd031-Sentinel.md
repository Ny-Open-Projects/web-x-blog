## 哨兵 · Sentinel（机制）—— 7 类问法与标准话术

**Qredis-211（概念考察·P4-P6）**
【面试官】请谈谈你对「哨兵」中「Sentinel」的理解。
【标准回答话术】Sentinel（哨兵）提供监控+通知+自动故障转移，生产至少 3 节点且奇数。背后的原理是：主观下线（单个哨兵判断）→客观下线（quorum 多数同意）→选举哨兵 leader（Raft 风格）→从库择优提升，2 节点无法形成多数派。
【评分点】① 准确说出核心机制（Sentinel）；② 能带出原理层而非背结论。 ③ 版本锚点：官方文档
