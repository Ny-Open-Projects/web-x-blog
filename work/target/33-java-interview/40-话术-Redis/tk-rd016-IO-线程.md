## 线程模型 · IO 线程（6.0）—— 7 类问法与标准话术

**Qredis-106（概念考察·P1-P3）**
【面试官】请谈谈你对「线程模型」中「IO 线程」的理解。
【标准回答话术】Redis 6.0 多线程默认关闭需 io-threads 配置开启。背后的原理是：开启后读请求解析与写回复并行化，命令执行仍单线程保证原子性，大流量实例收益明显。
【评分点】① 准确说出核心机制（IO 线程）；② 能带出原理层而非背结论。 ③ 版本锚点：Redis 6.0
