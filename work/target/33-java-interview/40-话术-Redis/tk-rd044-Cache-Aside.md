## 缓存 · Cache Aside（一致性）—— 7 类问法与标准话术

**Qredis-302（概念考察·P1-P3）**
【面试官】请谈谈你对「缓存」中「Cache Aside」的理解。
【标准回答话术】标准缓存模式 Cache Aside：读 miss 查库回填，写时先更新库再删除缓存。背后的原理是：先删缓存后更库（并发读回填旧值概率高）与先更缓存（并发写乱序）都有问题，先库后删是最优实践（Martin Kleppmann 分析）。
【评分点】① 准确说出核心机制（Cache Aside）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
