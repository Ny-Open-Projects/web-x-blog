## Cluster · full-coverage（可用性）—— 7 类问法与标准话术

**Qredis-729（概念考察·P1-P3）**
【面试官】请谈谈你对「Cluster」中「full-coverage」的理解。
【标准回答话术】cluster-require-full-coverage 默认 yes：任一槽无主节点则整个集群拒绝服务。背后的原理是：保证数据完整性（缺失槽区间不可用），设 no 则缺失部分仍服务其余槽（可用性优先），按业务对"部分可用"的容忍度选择。
【评分点】① 准确说出核心机制（full-coverage）；② 能带出原理层而非背结论。 ③ 版本锚点：官方文档
