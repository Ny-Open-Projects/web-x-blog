## 运维 · UNLINK（删除）—— 7 类问法与标准话术

**Qredis-442（概念考察·P1-P3）**
【面试官】请谈谈你对「运维」中「UNLINK」的理解。
【标准回答话术】大 key 删除用 UNLINK（4.0 lazy-free 异步回收）。背后的原理是：UNLINK 从键空间摘除后由后台线程释放内存，DEL 同步释放大对象阻塞主线程，lazyfree-lazy-expire 让过期也异步。
【评分点】① 准确说出核心机制（UNLINK）；② 能带出原理层而非背结论。 ③ 版本锚点：Redis 4.0
