## 扩展类型 · Stream（Stream）—— 7 类问法与标准话术

**Qredis-71（概念考察·P1-P3）**
【面试官】请谈谈你对「扩展类型」中「Stream」的理解。
【标准回答话术】Redis Stream（5.0）是带消费组的持久化消息流（类 Kafka）。背后的原理是：XADD/XREADGROUP/XACK，支持消费组与 pending 列表，弥补 Pub/Sub 不持久不确认的缺陷，小规模消息场景可用。
【评分点】① 准确说出核心机制（Stream）；② 能带出原理层而非背结论。 ③ 版本锚点：Redis 5.0
