## 数据类型 · 编码（String）—— 7 类问法与标准话术

**Qredis-631（概念考察·P1-P3）**
【面试官】请谈谈你对「数据类型」中「编码」的理解。
【标准回答话术】String 编码自动选择：int（纯整数）→embstr（≤44 字节一次性分配）→raw。背后的原理是：embstr 将 SDS 与 redisObject 一次分配（缓存友好）但不可修改（修改转 raw），44 字节是分配器 jemalloc 单元决定。
【评分点】① 准确说出核心机制（编码）；② 能带出原理层而非背结论。 ③ 版本锚点：源码实现
