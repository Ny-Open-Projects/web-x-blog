## 数据结构 · 为什么不用 B+树（选型）—— 7 类问法与标准话术

**Qredis-512（概念考察·P8-P10）**
【面试官】请谈谈你对「数据结构」中「为什么不用 B+树」的理解。
【标准回答话术】Redis 不用 B+ 树：内存场景 hash/skiplist/listpack 更快且快照友好。背后的原理是：B+ 树为磁盘优化（减少 IO 深页缓存），内存访问 hash O(1) 已够，持久化用整体快照而非 B+ 树原地更新。
【评分点】① 准确说出核心机制（为什么不用 B+树）；② 能带出原理层而非背结论。 ③ 版本锚点：架构思维
