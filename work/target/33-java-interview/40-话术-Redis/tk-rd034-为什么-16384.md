## Cluster · 为什么 16384（设计）—— 7 类问法与标准话术

**Qredis-232（概念考察·P1-P3）**
【面试官】请谈谈你对「Cluster」中「为什么 16384」的理解。
【标准回答话术】Cluster 用 16384 而非 65536 槽：gossip 心跳携带槽位图 16384×2bit=2KB 更省。背后的原理是：心跳消息里槽位图按位压缩，65536 要 8KB，集群规模大时心跳开销显著，作者 antirez 的权衡结论。
【评分点】① 准确说出核心机制（为什么 16384）；② 能带出原理层而非背结论。 ③ 版本锚点：作者博客
