## Cluster · 迁移（伸缩）—— 7 类问法与标准话术

**Qredis-484（概念考察·P1-P3）**
【面试官】请谈谈你对「Cluster」中「迁移」的理解。
【标准回答话术】Cluster 扩缩容：迁移 slot（redis-cli --cluster reshard）在线进行。背后的原理是：slot 迁移期间 ASK 重定向保证可用，大数据量 slot 迁移有延迟抖动，扩容规划提前做。
【评分点】① 准确说出核心机制（迁移）；② 能带出原理层而非背结论。 ③ 版本锚点：官方文档
