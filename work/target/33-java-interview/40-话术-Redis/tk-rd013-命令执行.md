## 线程模型 · 命令执行（单线程）—— 7 类问法与标准话术

**Qredis-85（概念考察·P1-P3）**
【面试官】请谈谈你对「线程模型」中「命令执行」的理解。
【标准回答话术】Redis 命令执行是单线程的（6.0 起网络 IO 与协议解析可多线程）。背后的原理是：单线程免锁免上下文切换，瓶颈在网络而非 CPU，6.0 多线程只处理读写 socket 不执行命令。
【评分点】① 准确说出核心机制（命令执行）；② 能带出原理层而非背结论。 ③ 版本锚点：Redis 6.0
