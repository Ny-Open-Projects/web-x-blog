## 语言杂项 · 可变静态日期（误用）—— 7 类问法与标准话术

**Qjava-basics-519（概念考察·P6-P8）**
【面试官】请谈谈你对「语言杂项」中「可变静态日期」的理解。
【标准回答话术】SimpleDateFormat 非线程安全（内部 Calendar 共享），多线程共享实例会产生数据错乱。背后的原理是：官方建议每次创建新实例或用 ThreadLocal 包装。
【评分点】① 准确说出核心机制（可变静态日期）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK8+

**Qjava-basics-522（工程落地·P7-P9）**
