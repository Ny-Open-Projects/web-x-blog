## static · 类加载初始化（语法语义）—— 7 类问法与标准话术

**Qjava-basics-393（概念考察·P4-P6）**
【面试官】请谈谈你对「static」中「类加载初始化」的理解。
【标准回答话术】static 字段在类初始化（<clinit>）时按代码顺序赋值，仅执行一次且线程安全（JVM 保证）。背后的原理是：<clinit> 由 JVM 加锁保证单线程执行。
【评分点】① 准确说出核心机制（类加载初始化）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 12.4
