## 异常 · 异常性能（误用）—— 7 类问法与标准话术

**Qjava-basics-652（概念考察·P6-P8）**
【面试官】请谈谈你对「异常」中「异常性能」的理解。
【标准回答话术】异常构造会填充堆栈（fillInStackTrace），高频路径用异常做流程控制有显著性能代价。背后的原理是：JVM 需要捕获当前线程栈快照。
【评分点】① 准确说出核心机制（异常性能）；② 能带出原理层而非背结论。 ③ 版本锚点：JIT 通用
