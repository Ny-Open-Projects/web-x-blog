## final · 安全发布（内存）—— 7 类问法与标准话术

**Qjava-basics-386（概念考察·P4-P6）**
【面试官】请谈谈你对「final」中「安全发布」的理解。
【标准回答话术】final 字段写具有"构造器完成即对其他线程可见"的内存语义（无需 synchronized）。背后的原理是：JMM 为 final 专门定义了读写内存屏障规则（JSR-133）。
【评分点】① 准确说出核心机制（安全发布）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 17.5
