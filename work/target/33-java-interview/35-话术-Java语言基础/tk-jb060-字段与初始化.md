## 接口 · 字段与初始化（语法语义）—— 7 类问法与标准话术

**Qjava-basics-414（概念考察·P4-P6）**
【面试官】请谈谈你对「接口」中「字段与初始化」的理解。
【标准回答话术】接口的字段隐式为 public static final，且接口不允许静态初始化块。背后的原理是：接口无法用 <clinit> 控制，字段初始化靠常量表达式或引用其他类的初始化逻辑。
【评分点】① 准确说出核心机制（字段与初始化）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 12.4.1
