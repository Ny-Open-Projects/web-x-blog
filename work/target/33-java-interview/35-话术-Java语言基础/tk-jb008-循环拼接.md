## String · 循环拼接（性能）—— 7 类问法与标准话术

**Qjava-basics-50（概念考察·P6-P8）**
【面试官】请谈谈你对「String」中「循环拼接」的理解。
【标准回答话术】循环体内拼接字符串必须手动使用 StringBuilder（在循环外创建）。背后的原理是：循环内即使编译器改写，每轮也会新建 Builder 对象，产生大量临时对象与 GC 压力。
【评分点】① 准确说出核心机制（循环拼接）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK9+
