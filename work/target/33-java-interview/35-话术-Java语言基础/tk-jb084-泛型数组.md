## 集合通用 · 泛型数组（误用）—— 7 类问法与标准话术

**Qjava-basics-582（概念考察·P6-P8）**
【面试官】请谈谈你对「集合通用」中「泛型数组」的理解。
【标准回答话术】不能直接创建泛型数组（new T[] 编译错误），因为数组是协变且运行时携带精确类型，与擦除冲突。背后的原理是：堆污染（heap pollution）风险：数组协变+泛型不变的设计冲突。
【评分点】① 准确说出核心机制（泛型数组）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 15.10
