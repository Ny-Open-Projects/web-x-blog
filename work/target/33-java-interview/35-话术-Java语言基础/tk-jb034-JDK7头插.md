## HashMap · JDK7头插（版本）—— 7 类问法与标准话术

**Qjava-basics-232（概念考察·P8-P10）**
【面试官】请谈谈你对「HashMap」中「JDK7头插」的理解。
【标准回答话术】JDK7 的 HashMap 扩容迁移用头插法，并发扩容会形成环形链表导致 CPU 100%。背后的原理是：两线程同时迁移时指针交换顺序错乱成环；JDK8 改为尾插并保持顺序。
【评分点】① 准确说出核心机制（JDK7头插）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK 7→8 版本史
