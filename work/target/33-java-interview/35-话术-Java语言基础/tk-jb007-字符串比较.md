## String · 字符串比较（误用）—— 7 类问法与标准话术

**Qjava-basics-43（概念考察·P6-P8）**
【面试官】请谈谈你对「String」中「字符串比较」的理解。
【标准回答话术】比较 String 内容必须用 equals，== 只比较引用地址。背后的原理是：== 在两个相同字面量（同入常量池）时碰巧为 true，造成"有时对有时错"的隐蔽 bug。
【评分点】① 准确说出核心机制（字符串比较）；② 能带出原理层而非背结论。 ③ 版本锚点：阿里手册强制条款

**Qjava-basics-46（工程落地·P7-P9）**
