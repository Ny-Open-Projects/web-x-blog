## 泛型 · 泛型方法（语法语义）—— 7 类问法与标准话术

**Qjava-basics-631（概念考察·P4-P6）**
【面试官】请谈谈你对「泛型」中「泛型方法」的理解。
【标准回答话术】泛型方法的类型参数声明在返回类型之前（<T> T f(...)），由编译器按实参推断。背后的原理是：推断规则在 JDK8 改进（目标类型推断）。
【评分点】① 准确说出核心机制（泛型方法）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 8.4.4

**Qjava-basics-634（工程落地·P7-P9）**
