## ArrayList · 1.5倍扩容（性能）—— 7 类问法与标准话术

**Qjava-basics-148（概念考察·P6-P8）**
【面试官】请谈谈你对「ArrayList」中「1.5倍扩容」的理解。
【标准回答话术】ArrayList 扩容为新容量的 1.5 倍（oldCapacity + oldCapacity >> 1）：10→15→22。背后的原理是：1.5 倍平衡扩容次数与内存浪费；2 倍浪费内存，1.1 倍扩容太频繁。
【评分点】① 准确说出核心机制（1.5倍扩容）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK 8+ 源码（本项目实测）
