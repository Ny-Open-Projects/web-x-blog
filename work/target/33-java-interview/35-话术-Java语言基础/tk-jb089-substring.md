## String · substring（性能）—— 7 类问法与标准话术

**Qjava-basics-617（概念考察·P6-P8）**
【面试官】请谈谈你对「String」中「substring」的理解。
【标准回答话术】JDK7u6 前 substring 共享原字符数组导致内存泄漏风险，之后改为拷贝实现。背后的原理是：旧实现 offset+count 指向原数组，大字符串截取小片段会"钉住"整个大数组。
【评分点】① 准确说出核心机制（substring）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK7u6
