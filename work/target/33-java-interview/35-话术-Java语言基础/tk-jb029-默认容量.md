## HashMap · 默认容量（语法语义）—— 7 类问法与标准话术

**Qjava-basics-197（概念考察·P4-P6）**
【面试官】请谈谈你对「HashMap」中「默认容量」的理解。
【标准回答话术】new HashMap<>() 首次 put 时分配容量 16 的表（threshold=12）。背后的原理是：16 是 2 的幂，支撑 (n-1)&hash 定位；0.75 负载下 12 个即扩容。
【评分点】① 准确说出核心机制（默认容量）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK 8+ 源码
