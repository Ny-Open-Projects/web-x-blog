## 包装类 · Boolean与Byte（语法语义）—— 7 类问法与标准话术

**Qjava-basics-596（概念考察·P4-P6）**
【面试官】请谈谈你对「包装类」中「Boolean与Byte」的理解。
【标准回答话术】Boolean 缓存仅 true/false 两个实例；Byte 因范围小（-128~127）全部缓存。背后的原理是：小范围类型的所有值都值得缓存。
【评分点】① 准确说出核心机制（Boolean与Byte）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 5.1.7
