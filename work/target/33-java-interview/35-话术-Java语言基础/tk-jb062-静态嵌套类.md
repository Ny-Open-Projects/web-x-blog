## 内部类 · 静态嵌套类（语法语义）—— 7 类问法与标准话术

**Qjava-basics-428（概念考察·P4-P6）**
【面试官】请谈谈你对「内部类」中「静态嵌套类」的理解。
【标准回答话术】static 嵌套类不持有外部实例引用，可独立实例化；语义上更接近"把类组织进外部类的命名空间"。背后的原理是：不需要访问外部实例就应声明为 static——Effective Java 相关条目。
【评分点】① 准确说出核心机制（静态嵌套类）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 8.1
