## String · 线程安全（线程）—— 7 类问法与标准话术

**Qjava-basics-71（概念考察·P1-P3）**
【面试官】请谈谈你对「String」中「线程安全」的理解。
【标准回答话术】String 天然线程安全：不可变对象无并发修改风险。背后的原理是：不可变对象发布后任何线程都无法修改其状态。
【评分点】① 准确说出核心机制（线程安全）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 17.5（不可变）
