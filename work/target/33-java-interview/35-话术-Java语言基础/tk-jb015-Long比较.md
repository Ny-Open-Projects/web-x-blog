## 包装类 · Long比较（误用）—— 7 类问法与标准话术

**Qjava-basics-99（概念考察·P6-P8）**
【面试官】请谈谈你对「包装类」中「Long比较」的理解。
【标准回答话术】Long 类型用 == 比较，超出缓存范围（-128~127）时即使值相等也返回 false。背后的原理是：== 比较引用，超缓存范围的 Long 是不同对象。
【评分点】① 准确说出核心机制（Long比较）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 5.1.7（缓存 -128~127）
