**Qjava-basics-463（概念考察·P8-P10）**
【面试官】请谈谈你对「语言杂项」中「自动模块化」的理解。
【标准回答话术】JDK9 引入模块系统（JPMS）：module-info.java 声明依赖与导出，JDK 内部 API（如 sun.misc.Unsafe 部分）被强封装。背后的原理是：强封装破坏了直接依赖 JDK 内部 API 的老代码——升级 JDK 的最大阻力源。
【评分点】① 准确说出核心机制（自动模块化）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK9+
