## String · 字符串常量池（内存）—— 7 类问法与标准话术

**Qjava-basics-15（概念考察·P4-P6）**
【面试官】请谈谈你对「String」中「字符串常量池」的理解。
【标准回答话术】字符串常量池从 JDK7 起位于堆中，JDK6 及之前位于永久代。背后的原理是：常量池入堆后可被 GC 回收，缓解永久代 OOM 问题。
【评分点】① 准确说出核心机制（字符串常量池）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK 7（常量池移入堆）
