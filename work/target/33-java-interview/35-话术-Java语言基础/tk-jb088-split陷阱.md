## String · split陷阱（误用）—— 7 类问法与标准话术

**Qjava-basics-610（概念考察·P6-P8）**
【面试官】请谈谈你对「String」中「split陷阱」的理解。
【标准回答话术】String.split 的参数是正则表达式，且默认省略尾部空串——特殊字符（点号与星号）必须转义。背后的原理是：正则语义导致 "." 会匹配任意字符；limit 参数传负数保留尾部空串。
