## TreeMap · 红黑树（语法语义）—— 7 类问法与标准话术

**Qjava-basics-295（概念考察·P4-P6）**

【标准回答话术】TreeMap 底层是红黑树，按 key 排序（自然序或 Comparator），基本操作 O(log n)。背后的原理是：红黑树通过旋转与染色维持近似平衡。
