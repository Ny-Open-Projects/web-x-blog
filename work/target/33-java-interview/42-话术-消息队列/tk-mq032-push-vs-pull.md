## 消费 · push vs pull（模式）—— 7 类问法与标准话术

**Qmq-218（概念考察·P1-P3）**
【面试官】请谈谈你对「运维」中「压缩」的理解。
【标准回答话术】消息压缩（lz4/zstd/gzip）网络与磁盘双降，生产端压缩 broker 原样存。背后的原理是：zstd 压缩比与速度均衡（Kafka 2.1+），批量大消息压缩收益大（批量本身就是压缩前提），消费端解压 CPU 代价。
【评分点】① 准确说出核心机制（压缩）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
