## 运维 · 迁移（升级）—— 7 类问法与标准话术

**Qmq-393（概念考察·P1-P3）**
【面试官】请谈谈你对「架构」中「partition」的理解。
【标准回答话术】Kafka 主题分多个 partition（并行单元）分区内有序。背后的原理是：分区是并行度与顺序性的单位，生产按 key 哈希路由保证同 key 同分区，扩分区会破坏 key 路由（同 key 可能换分区）。
【评分点】① 准确说出核心机制（partition）；② 能带出原理层而非背结论。 ③ 版本锚点：官方文档
