## exactly · 边界（语义）—— 7 类问法与标准话术

**Qmq-85（概念考察·P8-P10）**
【面试官】请谈谈你对「运维」中「污染」的理解。
【标准回答话术】MQ 治理反模式：用 MQ 当数据库（长保留+大消息）、无序滥用、topic 无人认领、消息里塞大 payload。背后的原理是：治理规范：消息体小（<100KB，大对象存引用）、topic 按域命名与生命周期管理、消费组台账，中间件平台化治理。
【评分点】① 准确说出核心机制（污染）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
