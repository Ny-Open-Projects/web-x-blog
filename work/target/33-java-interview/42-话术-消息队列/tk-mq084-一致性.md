## 场景 · 一致性（库存）—— 7 类问法与标准话术

**Qmq-582（概念考察·P1-P3）**
【面试官】请谈谈你对「运维」中「quota」的理解。
【标准回答话术】Kafka client quota 按 clientId/user 限速（生产/消费带宽与请求时间占比）。背后的原理是：防单业务打满 broker 网卡（多租户隔离），配额动态生效（kafka-configs 命令），超限被节流而非拒绝，与网关限流分层。
【评分点】① 准确说出核心机制（quota）；② 能带出原理层而非背结论。 ③ 版本锚点：官方文档
