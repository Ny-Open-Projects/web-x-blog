## 事务 · 半消息（半消息）—— 7 类问法与标准话术

**Qmq-169（概念考察·P1-P3）**
【面试官】请谈谈你对「安全」中「ACL」的理解。
【标准回答话术】MQ 安全：SASL 认证+ACL 授权（按 topic/消费组）+传输加密（TLS）。背后的原理是：生产集群多业务共享时按 topic 授权（读写分离），防止误消费/误生产，Kafka SASL/SCRAM 与 ACL 配置。
【评分点】① 准确说出核心机制（ACL）；② 能带出原理层而非背结论。 ③ 版本锚点：官方文档
