## 线程池 · 有界（队列选择）

- **事实**：生产线程池必须用有界队列加显式拒绝策略
- **原理**：无界队列让 maximumPoolSize 与拒绝策略形同虚设，过载信号被延迟到 OOM 才暴露，有界队列+拒绝策略构成完整反压
- **常见误区**：
  1. 无界队列吞吐更高所以更优（错）
  2. 有界队列会导致线程频繁创建销毁（错）
  3. 拒绝策略选 Discard 最安全（错）
- **工程用法**：容量=峰值 QPS×可容忍延迟
- **版本锚点**：JCiP 8.x
