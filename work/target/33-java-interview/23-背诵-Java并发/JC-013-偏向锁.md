## synchronized · 偏向锁（锁升级）

- **事实**：偏向锁已在 JDK15 标记废弃并于 JDK21 彻底移除
- **原理**：现代应用中撤销偏向锁的昂的操作超过收益，JDK21 中 -XX:+UseBiasedLocking 直接报 Unrecognized VM option（本机 JDK 21.0.2 实测）
- **常见误区**：
  1. JDK21 仍支持偏向锁（错）
  2. 偏向锁被移除是因为有 bug（错）
  3. 锁升级路径仍从偏向锁开始（错）
- **工程用法**：描述锁升级时按当前 JDK 说无锁到轻量级到重量级
- **版本锚点**：JEP 369 与 JDK21
