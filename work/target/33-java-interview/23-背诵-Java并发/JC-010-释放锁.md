## wait/notify · 释放锁（锁行为）

- **事实**：wait 会释放当前持有的 monitor 而 Thread.sleep 不会释放任何锁
- **原理**：sleep 只是定时暂停，锁所有权不变，持锁 sleep 会拖死其他线程
- **常见误区**：
  1. sleep 也会释放锁（错）
  2. wait 不释放锁只是等待（错）
  3. 两者释放锁的行为取决于 JVM 实现（错）
- **工程用法**：需要短暂暂停且持有锁时绝不使用 sleep
- **版本锚点**：JLS 17.2
