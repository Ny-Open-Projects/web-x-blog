## 安全发布 · this 逸出（误用）

- **事实**：构造器中把 this 交给外部（注册监听器、启动线程）导致未构造完成的对象被并发访问
- **原理**：发布时 final 字段尚未赋值，其他线程可能读到默认值，修复：构造完成后统一发布或用静态工厂
- **常见误区**：
  1. 构造器内启动线程是安全的（错）
  2. this 逸出只影响性能（错）
  3. final 字段可以防止 this 逸出问题（错）
- **工程用法**：监听器注册放构造后或工厂方法内
- **版本锚点**：JCiP 4.3
