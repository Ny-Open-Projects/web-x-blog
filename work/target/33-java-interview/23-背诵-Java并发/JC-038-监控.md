## 线程池 · 监控（运维）

- **事实**：线程池监控看活跃线程数、队列长度与拒绝次数三个核心指标
- **原理**：getActiveCount、getQueue().size()、拒绝策略计数（需自行埋点）构成健康度画像，队列增长斜率是过载前兆
- **常见误区**：
  1. 线程池监控只需要看线程总数（错）
  2. 队列长度无法获取（错）
  3. 拒绝次数 JDK 自带统计（错）
- **工程用法**：接入监控大盘告警队列积压
- **版本锚点**：实战经验
