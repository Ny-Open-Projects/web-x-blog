## synchronized · 轻量级锁（锁升级）

- **事实**：无竞争时 synchronized 通过 CAS 获取轻量级锁避免重量级开销
- **原理**：轻量级锁在栈帧建立 Lock Record 并 CAS 替换对象头 Mark Word，失败则膨胀为重量级（OS mutex，涉及用户态内核态切换）
- **常见误区**：
  1. 轻量级锁靠自旋等待获取（错）
  2. 重量级锁不涉及系统调用（错）
  3. 锁一旦膨胀就永久无法降级（错）
- **工程用法**：低竞争短临界区用 synchronized 性能很好
- **版本锚点**：HotSpot 内部机制
