## volatile · 内存屏障（内存语义）

- **事实**：volatile 的有序性靠编译器在读写前后插入内存屏障实现
- **原理**：volatile 写之后插入 StoreLoad 屏障（最重的屏障），读之后插入 LoadLoad 与 LoadSrc 屏障，阻止跨屏障重排
- **常见误区**：
  1. volatile 有序性靠 CPU 自动完成无需屏障（错）
  2. 所有屏障都插入在 volatile 读之前（错）
  3. volatile 修饰后代码不再有任何重排包括非 volatile 部分（错）
- **工程用法**：理解 JMM 时用屏障模型推演可见性
- **版本锚点**：JSR-133
