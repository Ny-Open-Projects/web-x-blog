## 线程基础 · 守护线程（线程属性）

- **事实**：JVM 退出只看是否还有非守护线程
- **原理**：main 线程结束后若只剩守护线程（如 GC 线程），JVM 直接退出且守护线程被硬杀不做清理
- **常见误区**：
  1. 守护线程会阻止 JVM 退出（错）
  2. main 线程默认是守护线程（错）
  3. 守护线程退出前会执行 finally（错）
- **工程用法**：后台监控、心跳类任务设为 daemon 并接受被硬杀
- **版本锚点**：Thread.setDaemon javadoc
