## JMM · 传递性（happens-before）

- **事实**：happens-before 具有传递性可串起长链推理
- **原理**：volatile 写 hb 后续读、写 hb 前面的程序顺序操作，链式推导可证明跨线程可见性，这是判断数据竞争的根本工具
- **常见误区**：
  1. 传递性在 JMM 中不成立（错）
  2. 只在单线程内有传递性（错）
  3. 传递性需要显式声明才生效（错）
- **工程用法**：复杂可见性 bug 复盘时按链推导
- **版本锚点**：JLS 17.4.5
