## AQS · 共享（共享模式）

- **事实**：AQS 支持独占与共享两种获取模式
- **原理**：独占（ReentrantLock）一次一个线程，共享（Semaphore、CountDownLatch、读锁）可多个线程同时通过，tryAcquireShared 返回剩余量决定传播
- **常见误区**：
  1. AQS 只支持独占锁（错）
  2. 共享模式与独占模式不能共存（错）
  3. CountDownLatch 是独占模式（错）
- **工程用法**：区分读写锁与 CountDownLatch 的 AQS 用法
- **版本锚点**：JDK 源码
