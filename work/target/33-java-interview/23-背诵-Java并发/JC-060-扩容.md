## 并发容器 · 扩容（CHM）

- **事实**：CHM 支持多线程协助扩容（helping transfer）
- **原理**：扩容时其他线程 put 会先帮忙迁移部分桶再完成自己的写，这是 CHM 高并发的关键设计之一，单线程扩容会成瓶颈
- **常见误区**：
  1. CHM 扩容是单线程完成的（错）
  2. 扩容期间读写全部阻塞（错）
  3. 协助扩容只在 HashMap 中存在（错）
- **工程用法**：谈 CHM 性能必提协助扩容
- **版本锚点**：JDK8 源码
