## 异步 · 组合（CompletableFuture）

- **事实**：allOf 等全部完成 anyOf 任一完成 join/get 阻塞取结果
- **原理**：allOf 返回的 CF 需再 join 拿各任务结果，anyOf 用于多源竞速（多缓存源取最快）
- **常见误区**：
  1. allOf 直接返回结果列表（错）
  2. anyOf 等待全部完成（错）
  3. join 与 get 语义完全相同（错）
- **工程用法**：并行聚合（多下游并发调用）标准写法
- **版本锚点**：JDK 文档
