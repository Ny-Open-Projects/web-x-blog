## 显式锁 · ReentrantLock（公平性）

- **事实**：ReentrantLock 默认非公平锁吞吐更高
- **原理**：非公平允许新请求直接抢锁减少线程切换，公平锁按队列顺序避免饥饿但吞吐低，可构造函数选择
- **常见误区**：
  1. 默认是公平锁（错）
  2. 公平锁性能总是更优（错）
  3. 非公平锁可能导致某些线程饿死但语义正确（错）
- **工程用法**：默认用非公平，公平需求明确才显式选
- **版本锚点**：JDK 文档
