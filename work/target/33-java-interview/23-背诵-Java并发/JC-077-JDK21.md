## 虚拟线程 · JDK21（版本）

- **事实**：虚拟线程是 JDK21 正式特性由 JVM 调度到少量载体线程
- **原理**：创建成本极低（栈在堆上）可开百万级，阻塞时让出载体线程由 JVM 换入下一个虚拟线程，面向 IO 密集高并发
- **常见误区**：
  1. 虚拟线程能加速 CPU 计算任务（错）
  2. 虚拟线程比平台线程运行更快（错）
  3. 虚拟线程需要线程池管理（错）
- **工程用法**：IO 密集微服务高并发吞吐利器
- **版本锚点**：JEP 444
