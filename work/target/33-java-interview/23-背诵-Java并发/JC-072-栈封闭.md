## 线程封闭 · 栈封闭（模式）

- **事实**：局部变量天然线程封闭是实现线程安全的最简方式
- **原理**：变量只存在于栈帧不被共享，无状态 Service 的并发安全正来源于此
- **常见误区**：
  1. 局部变量也可能被并发修改（错）
  2. 栈封闭需要加锁保证（错）
  3. Service 单例必须为每个方法加锁（错）
- **工程用法**：Spring 单例 Service 无状态的并发安全性来源
- **版本锚点**：JCiP 3.x
