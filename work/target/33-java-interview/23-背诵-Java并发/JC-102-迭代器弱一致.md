## 并发容器 · 迭代器弱一致（Snapshot）

- **事实**：并发容器迭代器是弱一致的不抛 ConcurrentModificationException
- **原理**：CHM/COW 的迭代器反映创建时或创建后的某状态，不保证看到后续修改，COW 是严格快照，CHM 是弱一致
- **常见误区**：
  1. 并发容器迭代器会 fail-fast（错）
  2. 弱一致等于错误数据必须加锁（错）
  3. COW 与 CHM 迭代语义相同（错）
- **工程用法**：遍历并发容器时理解弱一致语义即可
- **版本锚点**：JDK 文档
