## 死锁 · 锁对象（误用）

- **事实**：synchronized 的锁对象不能是字符串常量、包装类缓存值或可变引用
- **原理**：字符串常量全局共享可能锁到别人的锁，Integer 缓存 -128~127 不同代码锁同一对象，可变引用被替换后两线程锁不同对象形同虚设
- **常见误区**：
  1. 锁对象可以是任意对象随意选（错）
  2. String 常量做锁是常见推荐写法（错）
  3. new String 做锁与常量等价（错）
- **工程用法**：锁对象专用 final 字段（new Object 或专用锁类）
