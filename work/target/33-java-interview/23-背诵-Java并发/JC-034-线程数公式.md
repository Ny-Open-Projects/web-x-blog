## 线程池 · 线程数公式（调优）

- **事实**：线程数经验公式：CPU 密集型约 N+1，IO 密集型约 N×(1+等待时间/计算时间)
- **原理**：CPU 密集多一个线程用于缺页等暂停；IO 密集等待期间可切换线程提高吞吐，实际以压测为准
- **常见误区**：
  1. 线程数一律设为 CPU 核数最优（错）
  2. IO 密集型线程数越少越好（错）
  3. 2N 是所有场景的标准答案（错）
- **工程用法**：按业务类型给初值再压测微调
- **版本锚点**：Java Concurrency in Practice
