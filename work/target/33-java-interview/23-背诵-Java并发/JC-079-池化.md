## 虚拟线程 · 池化（误用）

- **事实**：虚拟线程不应池化每次任务新建一个
- **原理**：池化的意义（复用昂贵资源）对虚拟线程不成立，限流应该用 Semaphore 控制并发数而非限制线程数
- **常见误区**：
  1. 虚拟线程也应该放进线程池（错）
  2. 虚拟线程创建成本与平台线程相同（错）
  3. Semaphore 不能用于虚拟线程限流（错）
- **工程用法**：newVirtualThreadPerTaskExecutor 直接用
- **版本锚点**：JDK 文档
