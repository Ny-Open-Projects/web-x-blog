## volatile · i++（原子性）

- **事实**：i++ 即使变量声明为 volatile 也不是线程安全的
- **原理**：i++ 是读取、加一、写回三个操作，两个线程交错执行会丢失更新，实测丢失可达数万次
- **常见误区**：
  1. 加 volatile 后自增就安全了（错）
  2. i++ 丢失更新只发生在解释执行时（错）
  3. 用 AtomicLong 与 volatile long 行为完全一样（错）
- **工程用法**：计数场景改用 AtomicLong 或加锁
- **版本锚点**：JLS 17.7
