## ThreadLocal · 0x61c88647（实现细节）

- **事实**：ThreadLocalMap 的哈希增量是魔数 0x61c88647（斐波那契散列）
- **原理**：相邻 ThreadLocal 的 hash 以黄金分割数递增，2 的幂容量下能均匀散列减少冲突
- **常见误区**：
  1. 魔数是随机选的（错）
  2. 0x61c88647 是 MD5 截断（错）
  3. 斐波那契散列适合所有场景（错）
- **工程用法**：面试谈 ThreadLocal 冲突优化时引用此数
- **版本锚点**：JDK 源码
