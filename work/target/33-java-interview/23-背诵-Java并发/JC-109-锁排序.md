## 死锁 · 锁排序（预防）

- **事实**：预防死锁最实用手段是全局一致的锁获取顺序
- **原理**：按业务键排序（账户 ID 从小到大）转账互转不再死锁，tryLock 超时回退是补充手段，这两招覆盖绝大多数死锁
- **常见误区**：
  1. 死锁主要靠检测和恢复解决（错）
  2. 按获取时间排序最有效（错）
  3. ReentrantLock 天然防死锁（错）
- **工程用法**：转账、库存扣减等双资源场景
- **版本锚点**：JCiP 10.x
