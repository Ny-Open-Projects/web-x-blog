## 线程池 · 舱壁（隔离）

- **事实**：不同业务的线程池必须隔离（舱壁模式）避免相互拖垮
- **原理**：共用线程池时一个慢业务占满队列殃及全服务，按下游/重要性拆池（核心池、非核心池），配合 Hystrix/Sentinel 语义
- **常见误区**：
  1. 一个服务一个全局线程池最优（错）
  2. 线程池隔离只对 CPU 密集任务有意义（错）
  3. 隔离池数量越少越好（错）
- **工程用法**：核心交易与边缘任务分池
- **版本锚点**：舱壁模式
