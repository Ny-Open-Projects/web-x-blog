## JMM · 工作内存（模型）

- **事实**：JMM 抽象为主内存与线程工作内存每线程有本地副本
- **原理**：线程操作的是副本，何时刷回主存未定义，需要 volatile、锁或 final 等同步动作建立可见性通道，这是可见性问题的根源
- **常见误区**：
  1. Java 变量直接操作主内存（错）
  2. 工作内存就是 CPU 缓存本身（它是抽象模型）（错）
  3. JMM 是内存物理结构规范（错）
- **工程用法**：从模型层面解释可见性 bug
- **版本锚点**：JSR-133
