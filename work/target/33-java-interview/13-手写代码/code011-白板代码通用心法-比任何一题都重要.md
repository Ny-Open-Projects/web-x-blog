## 白板代码通用心法（比任何一题都重要）

1. **先说思路再动笔**：30 秒讲清"数据结构 + 关键不变量"，方向错了面试官会拉住你；
2. **边界先行**：空参/单元素/并发条件，主动说"我假设……"，不等人问；
3. **写不完就降维**：时间不够时写核心方法骨架 + 口述其余，比涂改强；
4. **自我 review**：写完必说"我检查一下边界"——展示 review 习惯本身就是评分项；
5. **并发题三问自查**：谁可见（volatile/锁）？谁原子（CAS/锁）？谁等待（wait/while）？
