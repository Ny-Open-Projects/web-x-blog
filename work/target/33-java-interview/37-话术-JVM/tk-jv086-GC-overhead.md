## OOM · GC overhead（类型）—— 7 类问法与标准话术

**Qjvm-596（概念考察·P1-P3）**
【面试官】请谈谈你对「OOM」中「GC overhead」的理解。
【标准回答话术】GC overhead limit exceeded：JVM 花超 98% 时间做 GC 但回收不足 2% 堆。背后的原理是：本质是堆接近死满，参数 -XX:-UseGCOverheadLimit 只是关闭该报错不解决问题，根因仍是泄漏或堆不足。
【评分点】① 准确说出核心机制（GC overhead）；② 能带出原理层而非背结论。 ③ 版本锚点：HotSpot
