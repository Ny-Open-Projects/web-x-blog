## 内存 · 元空间（泄漏）—— 7 类问法与标准话术

**Qjvm-428（概念考察·P1-P3）**
【面试官】请谈谈你对「内存」中「元空间」的理解。
【标准回答话术】元空间泄漏源：动态生成类未卸载（CGLib 代理、Groovy 脚本、反射 inflation）。背后的原理是：每个生成的 Class 都进元空间，类卸载需要其 ClassLoader 卸载，反复生成新类（如每次 new 代理）撑爆元空间。
【评分点】① 准确说出核心机制（元空间）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识

【标准回答话术】这个说法不正确。准确的表述是：元空间泄漏源：动态生成类未卸载（CGLib 代理、Groovy 脚本、反射 inflation）。原因是：每个生成的 Class 都进元空间，类卸载需要其 ClassLoader 卸载，反复生成新类（如每次 new 代理）撑爆元空间。
【评分点】① 快速识别误区不顺着说；② 给出正确的版本锚定表述（实战共识）。

【评分点】① 讲出泄漏层面的机制；② 结论与机制对应不脱节。

**Qjvm-431（工程落地·P7-P9）**
