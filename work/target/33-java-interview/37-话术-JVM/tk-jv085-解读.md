## GC · 解读（日志）—— 7 类问法与标准话术

**Qjvm-589（概念考察·P1-P3）**
【面试官】请谈谈你对「GC」中「解读」的理解。
【标准回答话术】一次 GC 日志四要素：触发原因、回收前后各代占用、停顿时长、GC 线程数。背后的原理是：触发原因（Allocation Failure/G1 Humongous Allocation/System.gc）直接指明优化方向，Pause 时间是 SLO 对账依据。
【评分点】① 准确说出核心机制（解读）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
