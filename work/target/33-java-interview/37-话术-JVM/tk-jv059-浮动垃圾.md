## GC · 浮动垃圾（浮动垃圾）—— 7 类问法与标准话术

**Qjvm-407（概念考察·P1-P3）**
【面试官】请谈谈你对「GC」中「浮动垃圾」的理解。
【标准回答话术】SATB 期间被删除引用的对象本轮不回收称为浮动垃圾。背后的原理是：按标记开始时的快照保留，下一轮 GC 回收，代价换取更短的重新标记停顿，是 G1 选择 SATB 的权衡。
【评分点】① 准确说出核心机制（浮动垃圾）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识
