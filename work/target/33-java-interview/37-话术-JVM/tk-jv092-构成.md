## GC · 构成（停顿）—— 7 类问法与标准话术

**Qjvm-638（概念考察·P1-P3）**
【面试官】请谈谈你对「GC」中「构成」的理解。
【标准回答话术】GC 停顿=STW 阶段总和（初始标记、复制/清理等），并发阶段不贡献停顿。背后的原理是：G1 的 Initial Mark 随 Minor GC 发生、Remark 与 Cleanup 是主要 STW，ZGC 仅极短 STW，分析停顿构成才能对症。
【评分点】① 准确说出核心机制（构成）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
