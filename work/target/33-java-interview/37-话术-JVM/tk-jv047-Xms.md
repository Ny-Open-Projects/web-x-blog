## 参数 · -Xms（堆）—— 7 类问法与标准话术

**Qjvm-323（概念考察·P1-P3）**
【面试官】请谈谈你对「参数」中「-Xms」的理解。
【标准回答话术】-Xms 与 -Xmx 设为相同值避免堆动态伸缩抖动。背后的原理是：堆动态扩容触发 Full GC 或影响延迟稳定性，服务器固定负载场景等值是标配，容器环境用 MaxRAMPercentage 更优。
【评分点】① 准确说出核心机制（-Xms）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
