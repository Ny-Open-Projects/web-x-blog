## OOM · native thread（类型）—— 7 类问法与标准话术

**Qjvm-603（概念考察·P1-P3）**
【面试官】请谈谈你对「OOM」中「native thread」的理解。
【标准回答话术】unable to create native thread 根因：线程数撞系统限制或内存不足创建栈失败。背后的原理是：排查：线程总数（jcmd Thread.print 统计）、ulimit -u、可用内存；解法：虚拟线程改造或线程池治理。
【评分点】① 准确说出核心机制（native thread）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
