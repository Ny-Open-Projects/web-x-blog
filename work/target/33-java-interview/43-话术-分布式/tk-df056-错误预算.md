【标准回答话术】SLA/SLO/SLI：SLI 指标（延迟 P99/错误率）→SLO 目标（99.9%）→SLA 对外承诺+赔偿，错误预算=1-SLO。背后的原理是：错误预算是"允许失败额度"：用完冻结发布保稳定（Google SRE 实践），SLO 要少而关键（3-5 个），对外 SLA 承载商业承诺。
