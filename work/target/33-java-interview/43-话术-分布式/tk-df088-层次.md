## 网关 · 层次（限流）—— 7 类问法与标准话术

**Qdistributed-610（概念考察·P1-P3）**
【面试官】请谈谈你对「网关」中「层次」的理解。
【标准回答话术】限流层次：CDN/运营商→网关（全局限流）→服务（接口级）→DB（连接池上限），层次越深越靠近资源。背后的原理是：每层保护不同对象（网关保护集群、服务保护下游、DB 保护自身），全局限流（集群精确）与单机限流（本地快速）叠加，与 Redis 限流知识联动。
【评分点】① 准确说出核心机制（层次）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
