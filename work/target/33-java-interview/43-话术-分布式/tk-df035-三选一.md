## 锁 · 三选一（对比）—— 7 类问法与标准话术

**Qdistributed-239（概念考察·P1-P3）**
【面试官】请谈谈你对「锁」中「三选一」的理解。
【标准回答话术】分布式锁对比：Redis（AP 高性能可能丢锁）、ZK/etcd（CP 可靠但慢）、DB（唯一行锁简单）。背后的原理是：按业务分级：防重执行用 Redis（效率锁），强互斥（资金）用 ZK/etcd 或 DB 乐观锁（正确性锁），P10 观点：Redis 锁的正确性争议决定了它只适合效率场景。
【评分点】① 准确说出核心机制（三选一）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
