## 数据 · TSO（时钟）—— 7 类问法与标准话术

**Qdistributed-113（概念考察·P1-P3）**
【面试官】请谈谈你对「数据」中「TSO」的理解。
【标准回答话术】TSO（中心授时服务）：集中节点发放全局时间戳（TiDB PD）。背后的原理是：简单可靠保证全局有序，瓶颈在授时节点（批量授时缓解）与单点（多副本），Spanner 用 TrueTime（GPS+原子钟）去中心授时。
【评分点】① 准确说出核心机制（TSO）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
