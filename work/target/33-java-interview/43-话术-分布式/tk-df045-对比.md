## RPC · 对比（HTTP）—— 7 类问法与标准话术

**Qdistributed-309（概念考察·P1-P3）**
【面试官】请谈谈你对「RPC」中「对比」的理解。
【标准回答话术】HTTP 与 RPC 对比：HTTP 通用（跨语言零成本）语义弱，RPC 定制化（长连接/压缩/治理）性能好。背后的原理是：外部开放 API 用 HTTP/REST，内部微服务 RPC（治理：超时/重试/负载均衡内建），REST 演进（HATEOAS）国内少用。
【评分点】① 准确说出核心机制（对比）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
