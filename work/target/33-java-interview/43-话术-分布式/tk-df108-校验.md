【标准回答话术】数据迁移校验工具化：分块 checksum（按主键区间）+抽样内容比对+差异修复闭环。背后的原理是：全量比对成本高（读两遍库），分块 checksum 增量校验（如 pt-table-checksum 思路），差异进入修复队列二次确认，迁移可信度靠工具链不靠人肉。
【评分点】① 准确说出核心机制（校验）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
