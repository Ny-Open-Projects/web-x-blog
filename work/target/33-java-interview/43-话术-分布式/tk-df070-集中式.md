## 会话 · 集中式（Session）—— 7 类问法与标准话术

**Qdistributed-484（概念考察·P1-P3）**
【面试官】请谈谈你对「会话」中「集中式」的理解。
【标准回答话术】分布式会话：集中存储（Redis：Spring Session）或无状态（JWT），按可撤销性需求选。背后的原理是：Redis session 可随时踢人（运维友好），JWT 自包含但撤销难（黑名单/短过期+refresh），与单机 session 对比：粘性路由是过渡方案。
【评分点】① 准确说出核心机制（集中式）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
