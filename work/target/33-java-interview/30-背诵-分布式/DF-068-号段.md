## ID · 号段（号段）

- **事实**：号段模式：DB 批量取号段（如 1-1000）内存分发，双 buffer 预取消抖动
- **原理**：号段表（biz_tag+max_id+step）乐观锁更新，取号高峰 DB 压力被号段长度摊薄，双 buffer 在用到 10% 时预取下段，美团 Leaf 实现
- **常见误区**：
  1. 号段模式每次写库（错）
  2. 号段号不趋势递增（错）
  3. 双 buffer 无必要（错）
- **工程用法**：ID 方案第二课
- **版本锚点**：美团 Leaf
