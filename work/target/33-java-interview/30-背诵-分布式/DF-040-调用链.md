## RPC · 调用链（原理）

- **事实**：RPC 原理：动态代理拦截调用→序列化→网络传输→服务端反序列化→反射调用→原路返回
- **原理**：与本地调用的差异全在这条链（网络不可靠/超时/序列化），理解链路才能定位"RPC 无故失败"，Dubbo/Feign/gRPC 都是此模型
- **常见误区**：
  1. RPC 就是 HTTP 调用（错）
  2. 反射是必需的（有字节码优化）（错）
  3. 序列化与 RPC 无关（错）
- **工程用法**：RPC 基础八股
- **版本锚点**：实战共识
