## RPC · 选型（序列化）

- **事实**：序列化选型：JSON（可读通用慢）、Protobuf（紧凑跨语言）、Hessian（Java 生态）、Kryo（快但不跨语言）
- **原理**：考量维度：体积/速度/兼容性（字段增删）/跨语言/安全性（反序列化漏洞），Java 内部 Hessian/Kryo，对外 API JSON，跨服务 Protobuf
- **常见误区**：
  1. JSON 是性能最优（错）
  2. 序列化只看速度（错）
  3. Kryo 适合对外接口（错）
- **工程用法**：序列化安全与性能
- **版本锚点**：实战共识
