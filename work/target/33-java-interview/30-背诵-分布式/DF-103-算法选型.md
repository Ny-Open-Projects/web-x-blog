## 可靠性 · 算法选型（限流）

- **事实**：分布式限流算法选型：中心计数（Redis Lua 固定/滑窗）、中心令牌桶（token server）、本地估算（同步衰减）
- **原理**：中心精确但网络往返与单点，本地无依赖但实例间漂移，组合"中心粗粒度+本地细粒度"兼顾精度与延迟，与 RD-057/DF-024 联动
- **常见误区**：
  1. 分布式限流必须每请求中心确认（有本地混合方案）（错）
  2. 精度与延迟可兼得（错）
  3. 只有 Redis 一种实现（错）
- **工程用法**：限流架构设计题
- **版本锚点**：实战方法论
