## 理论 · CAP（CAP）

- **事实**：CAP 三选二是分区发生时的选择：CP 保一致牺牲可用、AP 保可用容忍暂时不一致
- **原理**：网络分区（P）在分布式系统必然发生无法取舍，实际是在 C 与 A 之间权衡（如注册中心选型）
- **常见误区**：
  1. CAP 永远三选二（平时无分区可兼得部分）（错）
  2. P 是可选项（错）
  3. CP 一定优于 AP（错）
- **工程用法**：架构选型第一理论
- **版本锚点**：理论共识
