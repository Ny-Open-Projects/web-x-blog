## 数据 · 校验（迁移）

- **事实**：数据迁移校验工具化：分块 checksum（按主键区间）+抽样内容比对+差异修复闭环
- **原理**：全量比对成本高（读两遍库），分块 checksum 增量校验（如 pt-table-checksum 思路），差异进入修复队列二次确认，迁移可信度靠工具链不靠人肉
- **常见误区**：
  1. 迁移后人工抽查就够（错）
  2. 校验影响线上读写必须停机（错）
  3. 差异直接覆盖修复（错）
- **工程用法**：迁移质量门（与 MY-062 联动）
- **版本锚点**：实战方法论
