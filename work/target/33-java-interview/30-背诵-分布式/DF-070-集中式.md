## 会话 · 集中式（Session）

- **事实**：分布式会话：集中存储（Redis：Spring Session）或无状态（JWT），按可撤销性需求选
- **原理**：Redis session 可随时踢人（运维友好），JWT 自包含但撤销难（黑名单/短过期+refresh），与单机 session 对比：粘性路由是过渡方案
- **常见误区**：
  1. JWT 无任何存储依赖（错）
  2. 粘性路由是推荐方案（错）
  3. session 方案与扩容无关（错）
- **工程用法**：会话架构选型
- **版本锚点**：实战共识
