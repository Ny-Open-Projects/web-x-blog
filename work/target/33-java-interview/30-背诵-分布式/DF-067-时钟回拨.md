## ID · 时钟回拨（雪花）

- **事实**：雪花 ID：64 位（1 符号+41 时间戳+10 机器+12 序列）毫秒级趋势递增，时钟回拨需处理
- **原理**：41 位时间戳约 69 年，序列号毫秒内 4096 个，时钟回拨：等待/备机位/扩展位策略（美团 Leaf-snowflake 检测+等待），分布式唯一 ID 基础方案
- **常见误区**：
  1. 雪花 ID 绝对唯一无边界（错）
  2. 时钟回拨自动解决（错）
  3. 机器位可省略（错）
- **工程用法**：ID 方案第一课
- **版本锚点**：实战共识
