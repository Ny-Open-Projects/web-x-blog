## RPC · 对比（HTTP）

- **事实**：HTTP 与 RPC 对比：HTTP 通用（跨语言零成本）语义弱，RPC 定制化（长连接/压缩/治理）性能好
- **原理**：外部开放 API 用 HTTP/REST，内部微服务 RPC（治理：超时/重试/负载均衡内建），REST 演进（HATEOAS）国内少用
- **常见误区**：
  1. HTTP 一定比 RPC 慢（错）
  2. 内部也该用 HTTP（错）
  3. 两者二选一不能共存（错）
- **工程用法**：通信选型论证
- **版本锚点**：实战共识
