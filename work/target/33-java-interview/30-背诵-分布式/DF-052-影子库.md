## 压测 · 影子库（全链路）

- **事实**：全链路压测：流量染色+影子库/影子表（压测数据隔离）+旁路验证（DB 写隔离）
- **原理**：压测数据写真实库会污染生产，影子表（同库不同表）或影子库（独立实例）承接压测写，读流量正常回源，大促前容量验证必备
- **常见误区**：
  1. 压测写生产库没关系（错）
  2. 影子库是独立环境（错）
  3. 全链路压测只有读（错）
- **工程用法**：容量验证体系
- **版本锚点**：实战方法论
