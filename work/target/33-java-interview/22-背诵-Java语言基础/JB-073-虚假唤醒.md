## Object · 虚假唤醒（误用）

- **事实**：等待条件必须用 while 循环判断而非 if：被唤醒后条件可能已被其他线程改变。
- **原理**：notifyAll 会唤醒所有等待线程，先到者可能改变条件。
- **常见误区**：
  1. if 判条件与 while 完全等价。（错）
  2. 虚假唤醒在 Java 中不存在所以 if 是安全的。（错）
  3. notifyAll 只唤醒一个线程。（错）
- **工程用法**："手写生产者消费者"笔试题的核心考点就是 while+notifyAll。
- **版本锚点**：JLS 17.2.3
