## String · 字符串拼接底层（版本）

- **事实**：JDK9+ 的字符串拼接由 javac 编译为 invokedynamic 调用 StringConcatFactory，运行时按拼接形态选择最优策略。
- **原理**：相比 JDK8 固定生成 StringBuilder 链，策略化实现可预估长度、避免多余拷贝，基准更快。
- **常见误区**：
  1. JDK9 之后字符串拼接退化成了手工 StringBuilder。（错）
  2. 字符串拼接在 JDK9+ 全部变成了运行时反射调用。（错）
  3. StringConcatFactory 只用于常量折叠。（错）
- **工程用法**：单行拼接不必手写 StringBuilder 的底层依据。
- **版本锚点**：JDK9+
