## 集合通用 · 泛型数组（误用）

- **事实**：不能直接创建泛型数组（new T[] 编译错误），因为数组是协变且运行时携带精确类型，与擦除冲突。
- **原理**：堆污染（heap pollution）风险：数组协变+泛型不变的设计冲突。
- **常见误区**：
  1. new T[10] 在 Java 中是合法的。（错）
  2. 泛型数组与普通数组行为完全一致。（错）
  3. 堆污染是编译错误不是运行时风险。（错）
- **工程用法**：@SafeVarargs 标注是可变参数+泛型的官方豁免方式。
- **版本锚点**：JLS 15.10
