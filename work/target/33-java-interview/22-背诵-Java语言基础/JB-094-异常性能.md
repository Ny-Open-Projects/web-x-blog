## 异常 · 异常性能（误用）

- **事实**：异常构造会填充堆栈（fillInStackTrace），高频路径用异常做流程控制有显著性能代价。
- **原理**：JVM 需要捕获当前线程栈快照。
- **常见误区**：
  1. 异常抛出的性能开销可以忽略。（错）
  2. fillInStackTrace 是可选项且默认关闭。（错）
  3. 异常对象创建后堆栈不会变化。（错）
- **工程用法**：性能敏感路径用返回值/Optional 表达"未找到"，异常留给真正的异常。
- **版本锚点**：JIT 通用
