## String · 常量折叠（误用）

- **事实**：两个编译期常量拼接（final String a="x"; String s=a+"y";）在编译期直接折叠为常量；含变量的拼接只能运行期计算。
- **原理**：常量折叠是编译器优化，变量拼接无法折叠。
- **常见误区**：
  1. 任何字符串拼接都会在编译期折叠。（错）
  2. final 变量拼接也不能折叠。（错）
  3. 常量折叠只发生在运行期。（错）
- **工程用法**：可验证：折叠后的 s == "xy" 为 true（同池引用）。
- **版本锚点**：JLS 15.28
