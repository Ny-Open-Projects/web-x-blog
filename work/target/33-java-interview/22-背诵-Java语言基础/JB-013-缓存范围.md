## 包装类 · 缓存范围（语法语义）

- **事实**：Integer/Long/Short/Byte 的缓存范围是 -128~127，Character 是 0~127，Boolean 缓存 true/false。
- **原理**：缓存由 valueOf 触发，超出范围的值每次都新建对象。
- **常见误区**：
  1. 所有整数值的包装类都有缓存。（错）
  2. Integer 缓存范围是 0~255。（错）
  3. Long 没有缓存机制。（错）
- **工程用法**：包装类比较一律用 equals，避开缓存边界陷阱。
- **版本锚点**：缓存上限可用 -XX:AutoBoxCacheMax 调整（仅 Integer）。
