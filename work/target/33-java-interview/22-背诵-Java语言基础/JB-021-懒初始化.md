## ArrayList · 懒初始化（内存）

- **事实**：new ArrayList() 不分配数组，首次 add 时才分配容量 10 的数组。
- **原理**：节省空集合的内存占用。
- **常见误区**：
  1. new ArrayList() 立即分配容量为 10 的数组。（错）
  2. new ArrayList() 的默认容量是 0 且永远不会增长。（错）
  3. ArrayList 底层是链表结构。（错）
- **工程用法**：本机反射验证：首插后 elementData.length==10。
- **版本锚点**：JDK 8+ 源码
