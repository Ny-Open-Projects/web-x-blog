## 内部类 · 内部类引用（语法语义）

- **事实**：非静态内部类对象隐式持有外部类实例引用（Outer.this），可能导致外部类无法被 GC。
- **原理**：静态嵌套类（static nested class）不持有外部引用。
- **常见误区**：
  1. 非静态内部类不会引用外部类实例。（错）
  2. 静态嵌套类持有外部类实例。（错）
  3. 内部类导致外部类泄漏是不存在的说法。（错）
- **工程用法**：Handler 泄漏（Android）与回调泄漏（Java）都是此机制的产物。
- **版本锚点**：JLS 8.1.3
