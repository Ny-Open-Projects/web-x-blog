## String · 字符串去重（内存）

- **事实**：JDK8u20+ 提供 -XX:+UseStringDeduplication（G1 专属）：后台去重相同内容的 String 底层数组。
- **原理**：适用于大量重复长字符串（如缓存 JSON）场景。
- **常见误区**：
  1. 字符串去重默认开启。（错）
  2. 字符串去重会修改 String 的内容。（错）
  3. 去重只对 intern 池的字符串生效。（错）
- **工程用法**：开启前需评估 CPU 开销与实际重复率。
- **版本锚点**：JDK8u20+ / G1
