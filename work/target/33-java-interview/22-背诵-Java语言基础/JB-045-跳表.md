## ConcurrentSkipListMap · 跳表（语法语义）

- **事实**：ConcurrentSkipListMap 用跳表（多级索引链表）实现有序 + 高并发，基本操作 O(log n)。
- **原理**：跳表无需旋转即可维持平衡，天然适合无锁化并发读。
- **常见误区**：
  1. ConcurrentSkipListMap 底层是红黑树。（错）
  2. ConcurrentSkipListMap 的读操作需要加锁。（错）
  3. 它是有序并发场景的替代品这一说法是错的。（错）
- **工程用法**：有序 + 高并发（如排行榜）场景用它替代 TreeMap+Synchronized。
- **版本锚点**：JDK 6+ ConcurrentSkipListMap
