## 语言杂项 · var与模式匹配（版本）

- **事实**：JDK10 var 局部变量类型推断（仅局部变量，不能用于字段/参数/返回值）；JDK21 switch 模式匹配转正。
- **原理**：var 保留静态类型（编译期确定），不是动态类型。
- **常见误区**：
  1. var 使 Java 变成动态类型语言。（错）
  2. var 可以用于方法参数与返回值。（错）
  3. switch 模式匹配在 JDK8 已可用。（错）
- **工程用法**：var 适用于右侧类型明显的局部声明；字段/公共 API 不建议。
- **版本锚点**：JDK10/JDK21
