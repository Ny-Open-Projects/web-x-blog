## static · 静态可变状态（误用）

- **事实**：static 可变字段是全局共享状态，多线程并发访问必须自行同步，且影响测试隔离。
- **原理**：静态生命周期 = 类加载器生命周期，泄漏风险大。
- **常见误区**：
  1. static 可变字段是线程安全的。（错）
  2. static 字段随对象创建而初始化。（错）
  3. static 字段在 GC 中永远不会被回收是正常且无害的。（错）
- **工程用法**：阿里手册限制滥用 static 可变变量；静态常量（final）不受限。
- **版本锚点**：并发设计通用
