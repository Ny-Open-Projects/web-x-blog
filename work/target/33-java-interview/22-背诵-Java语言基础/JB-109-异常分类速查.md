## 异常 · 异常分类速查（语法语义）

- **事实**：高频运行时异常速查：NPE（null 解引用）、ArrayIndexOutOfBounds（越界）、ClassCast（强转）、NumberFormat（字符串转数字失败）、ArithmeticException（整数除零）、IllegalState（状态不符）、IllegalArgument（参数不符）。
- **原理**：整数除零抛异常而浮点除零得 Infinity/NaN——IEEE754 规范行为。
- **常见误区**：
  1. 浮点数除以零会抛 ArithmeticException。（错）
  2. NumberFormatException 属于 Checked 异常。（错）
  3. 所有运行时异常都必须捕获。（错）
- **工程用法**：NumberFormat 的 message 通常包含导致失败的字符串——排查入口。
- **版本锚点**：JDK 文档
