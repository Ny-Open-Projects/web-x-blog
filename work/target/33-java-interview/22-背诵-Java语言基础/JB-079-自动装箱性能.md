## 语言杂项 · 自动装箱性能（误用）

- **事实**：循环中的包装类累加（Long sum = 0L; sum += i）每轮触发拆箱+装箱，性能差数倍。
- **原理**：装箱创建新对象（超缓存范围），产生大量临时对象。
- **常见误区**：
  1. 自动装箱没有性能开销。（错）
  2. 装箱拆箱只发生在集合操作中。（错）
  3. Long 累加和 long 累加性能相同。（错）
- **工程用法**：算法题累加统一用基本类型。
- **版本锚点**：Effective Java 经典测量：装箱拖慢约数倍
