## 语言杂项 · 浮点比较（语法语义）

- **事实**：浮点数（float/double）不能直接用 == 比较相等，应使用误差范围或 BigDecimal。
- **原理**：IEEE754 二进制无法精确表示 0.1 等十进制小数。
- **常见误区**：
  1. 0.1 + 0.2 在 Java 中精确等于 0.3。（错）
  2. double 运算是精确的十进制运算。（错）
  3. float 精度比 double 高。（错）
- **工程用法**：资金计算用 BigDecimal 或长整型分单位；String 构造 BigDecimal 必用（double 构造有精度坑）。
- **版本锚点**：JLS 4.2.3
