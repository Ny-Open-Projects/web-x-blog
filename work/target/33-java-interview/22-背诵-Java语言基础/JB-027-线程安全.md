## ArrayList · 线程安全（线程）

- **事实**：ArrayList 非线程安全：并发结构修改会抛 ConcurrentModificationException 或数据丢失。
- **原理**：多线程共享时用 CopyOnWriteArrayList 或 Collections.synchronizedList。
- **常见误区**：
  1. ArrayList 通过 synchronized 保证线程安全。（错）
  2. ArrayList 并发修改只会静默失败不会抛异常。（错）
  3. Vector 是 ArrayList 的现代替代品。（错）
- **工程用法**：Vector 全方法 synchronized 性能差，现代代码不再使用。
- **版本锚点**：fail-fast 已实测：迭代中 put 抛 CME。
