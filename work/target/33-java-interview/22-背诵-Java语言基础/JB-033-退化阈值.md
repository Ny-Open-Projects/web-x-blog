## HashMap · 退化阈值（语法语义）

- **事实**：红黑树节点数减到 6（UNTREEIFY_THRESHOLD）时退化回链表。
- **原理**：留 2 的缓冲（8 与 6 之间）防止在阈值附近插入删除导致树↔链表来回抖动。
- **常见误区**：
  1. 退化阈值也是 8。（错）
  2. 退化阈值是 7。（错）
  3. 树一旦形成永远不会退化回链表。（错）
- **工程用法**：resize 迁移时树会被拆分，数量≤6 转回链表。
- **版本锚点**：JDK 8+ 源码
