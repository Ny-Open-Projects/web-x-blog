## 泛型 · 限制（语法语义）

- **事实**：类型擦除导致：不能 new T()、不能 new T[]、不能 instanceof T、静态成员不能用类的泛型参数。
- **原理**：运行时没有 T 的类型信息，静态成员属于类不属于实例。
- **常见误区**：
  1. 泛型类中可以创建 T 的实例。（错）
  2. 泛型类的静态方法可以访问类的泛型参数。（错）
  3. T[] 数组可以正常 new 出来。（错）
- **工程用法**：绕行方案：传 Class<T> 用反射构造、或用数组列表。
- **版本锚点**：JLS 4.x
