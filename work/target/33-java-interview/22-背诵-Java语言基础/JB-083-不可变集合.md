## 集合通用 · 不可变集合（语法语义）

- **事实**：JDK9+ 的 List.of/Set.of/Map.of 创建不可变集合：add/remove 抛 UnsupportedOperationException，不允许 null 元素。
- **原理**：不可变集合是防御性编程与安全发布的标准做法。
- **常见误区**：
  1. List.of 返回的集合可以排序。（错）
  2. List.of 允许 null 元素。（错）
  3. List.of 返回的就是 ArrayList。（错）
- **工程用法**：跨方法边界返回不可变集合可防调用方误改。
- **版本锚点**：JDK9+
