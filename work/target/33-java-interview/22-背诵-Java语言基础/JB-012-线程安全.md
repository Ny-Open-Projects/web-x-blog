## StringBuilder · 线程安全（语法语义）

- **事实**：StringBuilder 非线程安全，StringBuffer 的主要方法加了 synchronized。
- **原理**：StringBuffer 牺牲锁开销换取安全，单线程场景 StringBuilder 更快。
- **常见误区**：
  1. StringBuilder 是线程安全的。（错）
  2. StringBuffer 在 JDK9 后被废弃。（错）
  3. 两者底层存储结构完全不同。（错）
- **工程用法**：方法局部变量拼串用 StringBuilder；极少出现需要共享可变拼串的场景。
- **版本锚点**：StringBuilder javadoc（非同步）
