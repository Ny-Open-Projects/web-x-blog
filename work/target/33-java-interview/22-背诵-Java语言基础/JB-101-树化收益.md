## HashMap · 树化收益（性能）

- **事实**：树化把最坏查询从 O(n) 降到 O(log n)，防御 hash 碰撞攻击（恶意构造同 hash key）。
- **原理**：Tomcat 曾因 hash 碰撞 DoS 加固——树化是安全加固不只是性能优化。
- **常见误区**：
  1. 树化的目的仅仅是提升正常场景的查询速度。（错）
  2. 树化对安全性没有意义。（错）
  3. 正常业务一定会触发树化。（错）
- **工程用法**：正常负载下树化几乎不触发（泊松分布保证）。
- **版本锚点**：JDK 8+ 源码
