## HashMap · 扩容翻倍（语法语义）

- **事实**：HashMap 元素数超过 threshold（容量×0.75）时扩容为原来的 2 倍并重排元素。
- **原理**：2 倍保证容量始终是 2 的幂，位运算定位继续有效。
- **常见误区**：
  1. HashMap 扩容为原来的 1.5 倍。（错）
  2. HashMap 扩容后容量可能变成非 2 的幂。（错）
  3. HashMap 扩容时所有元素 hash 会全部重新计算。（错）
- **工程用法**：JDK8 优化：hash&oldCap 判断原位或 i+oldCap，不重算 hash。
- **版本锚点**：JDK 8+ 源码
