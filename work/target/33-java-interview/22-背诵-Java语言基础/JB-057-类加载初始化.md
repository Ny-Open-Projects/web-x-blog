## static · 类加载初始化（语法语义）

- **事实**：static 字段在类初始化（<clinit>）时按代码顺序赋值，仅执行一次且线程安全（JVM 保证）。
- **原理**：<clinit> 由 JVM 加锁保证单线程执行。
- **常见误区**：
  1. static 字段每次访问类时重新初始化。（错）
  2. static 字段的初始化是非线程安全的。（错）
  3. static 块在构造器之后执行。（错）
- **工程用法**：单例的 Holder 模式正是利用 <clinit> 的 JVM 线程安全。
- **版本锚点**：JLS 12.4
