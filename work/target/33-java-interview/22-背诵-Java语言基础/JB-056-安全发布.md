## final · 安全发布（内存）

- **事实**：final 字段写具有"构造器完成即对其他线程可见"的内存语义（无需 synchronized）。
- **原理**：JMM 为 final 专门定义了读写内存屏障规则（JSR-133）。
- **常见误区**：
  1. final 字段的可见性和其他普通字段完全相同。（错）
  2. final 字段在构造器中可以二次赋值而不报错。（错）
  3. final 语义只影响编译器不影响运行时。（错）
- **工程用法**：不可变对象+final 是线程安全设计的基石。
- **版本锚点**：JLS 17.5
