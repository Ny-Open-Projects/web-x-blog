## String · 线程安全（线程）

- **事实**：String 天然线程安全：不可变对象无并发修改风险。
- **原理**：不可变对象发布后任何线程都无法修改其状态。
- **常见误区**：
  1. String 需要配合 synchronized 才能多线程使用。（错）
  2. String 的 intern() 操作是线程不安全的。（错）
  3. String 拼接必须加锁。（错）
- **工程用法**：不可变对象是多线程共享数据的默认选择。
- **版本锚点**：JLS 17.5（不可变）
