## ArrayList · 中间插入（性能）

- **事实**：ArrayList 中间插入/删除是 O(n)（后续元素整体移动），尾部追加均摊 O(1)。
- **原理**：System.arraycopy 移动后续元素的成本随规模线性增长。
- **常见误区**：
  1. ArrayList 在任意位置插入都是 O(1)。（错）
  2. ArrayList 尾部插入是 O(n)。（错）
  3. LinkedList 插入一定比 ArrayList 快。（错）
- **工程用法**：频繁中间插入的场景考虑 LinkedList 或改数据结构。
- **版本锚点**：List javadoc
