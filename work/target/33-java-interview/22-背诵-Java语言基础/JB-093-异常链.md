## 异常 · 异常链（误用）

- **事实**：构造新异常必须传入 cause（new Exception(msg, e)）保留根因链，否则堆栈断链无法溯源。
- **原理**：initCause 可事后补充；printStackTrace 会输出 Caused by 链。
- **常见误区**：
  1. 新异常不需要携带原始异常。（错）
  2. cause 信息会自动继承无需传递。（错）
  3. getCause() 默认返回原始异常即使未传入。（错）
- **工程用法**：日志规范：每个 catch 至少保留 cause 或堆栈。
- **版本锚点**：JDK 1.4+（initCause）
