## 技巧 · 栈深（递归）

- **事实**：递归栈深控制：树深 1e5 级别改迭代（显式栈），Java 默认栈 512K-1M（JV-002 联动）
- **原理**：笔试/LeetCode 数据规模陷阱（链表长/树深爆栈），尾递归 Java 不优化（AL-002），迭代改写（Morris/显式栈）是工程素养
- **常见误区**：
  1. 递归深度无限制（错）
  2. 爆栈会自动扩容（错）
  3. 尾递归 Java 安全（错）
- **工程用法**：工程与算法交叉点
- **版本锚点**：理论共识
