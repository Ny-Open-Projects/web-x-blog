## 排序 · 分区（快排）

- **事实**：快排核心 partition：选 pivot 分区（小于/大于），随机 pivot 或三数取中防最坏
- **原理**：单边/双边扫描两种写法，三路分区（<=>三段）处理大量重复元素（荷兰国旗问题），递归深度 O(logN)
- **常见误区**：
  1. 固定首元素 pivot 最优（错）
  2. 快排是稳定排序（错）
  3. partition 是 O(N²)（错）
- **工程用法**：手写快排的考点
- **版本锚点**：理论共识
