## 并发 · 生产者消费者（手写）

- **事实**：生产者消费者手写：synchronized+wait/notify（while 防虚假唤醒）或 ReentrantLock 双 Condition 或 BlockingQueue 三版本（本项目实测）
- **原理**：wait 用 while（JB/并发知识联动），双 Condition 精准唤醒（SP-098 联动），BlockingQueue 版最简，考察并发基础综合
- **常见误区**：
  1. if 判断即可（错）
  2. notify 与 notifyAll 等价（错）
  3. 必须手写锁（BlockingQueue 也是手写范围）（错）
- **工程用法**：并发手写第一名（本项目实测）
- **版本锚点**：本项目实测
