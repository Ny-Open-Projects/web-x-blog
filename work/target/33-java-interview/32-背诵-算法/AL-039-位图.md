## 海量 · 位图（判重）

- **事实**：海量判重：bitmap（int 位图 40 亿整数 512MB）、布隆过滤器（允许误判更省）
- **原理**：1 个 int 1 bit（32 倍压缩），布隆误判率可控（位数组+多哈希），Redis bitmap/RD-009 联动，与缓存穿透方案联动
- **常见误区**：
  1. 位图支持任意类型（错）
  2. 布隆无误判（错）
  3. 位图内存与元素数成正比（按值域范围）（错）
- **工程用法**：海量题基础工具
- **版本锚点**：理论共识
