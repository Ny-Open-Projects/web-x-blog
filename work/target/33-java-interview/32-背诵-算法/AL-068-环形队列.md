## 设计 · 环形队列（手写）

- **事实**：手写环形队列：数组+头尾指针+取模入队出队，判满用 (tail+1)%cap==head 或 size 计数
- **原理**：牺牲一个槽位或维护 size 区分满与空，ArrayDeque 内部即循环数组思想，与 ArrayDeque（循环数组实现）联动
- **常见误区**：
  1. 环形队列不需要取模（错）
  2. 判满与判空条件相同（不做处理会混）（错）
  3. 环形队列只能固定容量（错）
- **工程用法**：手写数据结构高频（生产者消费者载体）
- **版本锚点**：理论共识
