## 复杂度 · 空间复杂度（空间）

- **事实**：空间复杂度算辅助空间：递归深度（栈）、显式数据结构，尾递归 Java 不优化
- **原理**：Java JIT 不做尾递归优化（栈溢出风险），递归改迭代是深度大时的常规改造，与 JVM 栈（JV-002）联动
- **常见误区**：
  1. Java 优化尾递归（错）
  2. 空间复杂度不含输入（错）
  3. 递归一定比迭代差（错）
- **工程用法**：工程与算法结合点
- **版本锚点**：理论共识
