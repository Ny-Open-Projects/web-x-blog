## 面试 · 复习（主线）

- **事实**：算法复习主线：复杂度→数组双指针/滑窗→链表→二分→排序→堆/TopK→树/图→DP 三经典→手写并发与设计题
- **原理**：按笔试出场频率排序（滑窗/二分/TopK/DP 最高频），手写题（LRU/生产者消费者）是 Java 岗特色（与纯算法岗差异），与 AL-046 清单联动
- **常见误区**：
  1. 图论最重要（错）
  2. 手写题不需要准备（错）
  3. DP 必须刷 100 题（错）
- **工程用法**：复习时间分配
- **版本锚点**：实战方法论
