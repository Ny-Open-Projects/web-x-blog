## 贪心 · 贪心（思想）

- **事实**：贪心：局部最优推出全局最优（需证明交换不劣化），区间调度/跳跃游戏/分发饼干
- **原理**：贪心正确性难证明（反例思维），与 DP 对比：贪心快但不保正确（无后效性才可用），活动选择按结束时间排序是经典
- **常见误区**：
  1. 贪心总是正确（错）
  2. 贪心与 DP 等价（错）
  3. 局部最优=全局最优无需证明（错）
- **工程用法**：策略类题辨析
- **版本锚点**：理论共识
