## DP · LCS（经典）

- **事实**：最长公共子序列（LCS）：dp[i][j] 依赖左/上/左上，编辑距离是其变形（增删改代价）
- **原理**：字符串相似度/版本 diff 的算法基础，空间优化两行滚动，输出具体序列需回溯路径，与 Git diff 思想关联
- **常见误区**：
  1. LCS 是最长公共子串（子序列可不连续）（错）
  2. LCS 必须 O(N²) 空间（错）
  3. 回溯路径不需要额外记录（错）
- **工程用法**：字符串 DP 经典
- **版本锚点**：理论共识
