## 树 · 遍历（遍历）

- **事实**：二叉树遍历：前中后序（递归/迭代栈）+层序（队列 BFS），中序遍历 BST 得有序序列
- **原理**：迭代版用显式栈（与 JVM 栈联动），Morris 遍历 O(1) 空间（利用线索），层序按层处理（右视图/之字形变形），手写必须熟练
- **常见误区**：
  1. 遍历递归版空间 O(1)（错）
  2. 层序用栈（错）
  3. 中序遍历任意树有序（错）
- **工程用法**：树题基本功
- **版本锚点**：理论共识
