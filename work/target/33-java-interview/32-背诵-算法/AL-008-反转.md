## 链表 · 反转（技巧）

- **事实**：链表反转：迭代三指针（prev/cur/next）O(N) O(1)，递归版 O(N) 栈空间
- **原理**：迭代逐节点改 next 指向，递归到尾再回改，K 组反转是组合题，手写必须零 bug（笔试常考）
- **常见误区**：
  1. 反转需要 O(N) 额外空间（错）
  2. 递归版空间 O(1)（错）
  3. 反转后原链表可恢复（错）
- **工程用法**：链表题基本功
- **版本锚点**：理论共识
