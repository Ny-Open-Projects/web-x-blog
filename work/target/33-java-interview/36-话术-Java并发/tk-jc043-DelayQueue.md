## 阻塞队列 · DelayQueue（实现）—— 7 类问法与标准话术

**Qconcurrency-295（概念考察·P4-P6）**
【面试官】请谈谈你对「阻塞队列」中「DelayQueue」的理解。
【标准回答话术】DelayQueue 按到期时间出队元素必须实现 Delayed 接口。背后的原理是：内部优先堆按剩余延迟排序，take 阻塞到队首到期，用于订单超时关单等延迟任务（小规模方案，大规模用时间轮或 RocketMQ 延迟消息）。
【评分点】① 准确说出核心机制（DelayQueue）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK 文档
