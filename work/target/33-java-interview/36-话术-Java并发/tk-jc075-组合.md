## 异步 · 组合（CompletableFuture）—— 7 类问法与标准话术

**Qconcurrency-519（概念考察·P1-P3）**
【面试官】请谈谈你对「异步」中「组合」的理解。
【标准回答话术】allOf 等全部完成 anyOf 任一完成 join/get 阻塞取结果。背后的原理是：allOf 返回的 CF 需再 join 拿各任务结果，anyOf 用于多源竞速（多缓存源取最快）。
【评分点】① 准确说出核心机制（组合）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK 文档
