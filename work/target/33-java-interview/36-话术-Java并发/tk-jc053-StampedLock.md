## 显式锁 · StampedLock（乐观读）—— 7 类问法与标准话术

**Qconcurrency-365（概念考察·P1-P3）**
【面试官】请谈谈你对「显式锁」中「StampedLock」的理解。
【标准回答话术】StampedLock 提供乐观读：读时不加锁事后 validate 校验。背后的原理是：乐观读返回一个 stamp，读完后 validate 判断期间是否有写，失败升级为悲观读锁；吞吐高于读写锁，但不可重入且不支持 Condition。
【评分点】① 准确说出核心机制（StampedLock）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK 文档
