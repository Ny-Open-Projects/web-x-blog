## 并发容器 · 树化（CHM）—— 7 类问法与标准话术

**Qconcurrency-428（概念考察·P1-P3）**
【面试官】请谈谈你对「并发容器」中「树化」的理解。
【标准回答话术】CHM 树化条件与 HashMap 一致：bin 中已有 8 个节点时插入第 9 个触发且表长需不小于 64。背后的原理是：MIN_TREEIFY_CAPACITY=64，表太小时优先扩容而非树化；8 语义是"bin 已有 8 个节点"而非"链长到 8 才树化"。
【评分点】① 准确说出核心机制（树化）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK8 源码实测
