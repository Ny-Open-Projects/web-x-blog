## 线程池 · 线程数公式（调优）—— 7 类问法与标准话术

**Qconcurrency-232（概念考察·P6-P8）**
【面试官】请谈谈你对「线程池」中「线程数公式」的理解。
【标准回答话术】线程数经验公式：CPU 密集型约 N+1，IO 密集型约 N×(1+等待时间/计算时间)。背后的原理是：CPU 密集多一个线程用于缺页等暂停；IO 密集等待期间可切换线程提高吞吐，实际以压测为准。
【评分点】① 准确说出核心机制（线程数公式）；② 能带出原理层而非背结论。 ③ 版本锚点：Java Concurrency in Practice
