## volatile · 内存屏障（内存语义）—— 7 类问法与标准话术

**Qconcurrency-15（概念考察·P4-P6）**
【面试官】请谈谈你对「volatile」中「内存屏障」的理解。
【标准回答话术】volatile 的有序性靠编译器在读写前后插入内存屏障实现。背后的原理是：volatile 写之后插入 StoreLoad 屏障（最重的屏障），读之后插入 LoadLoad 与 LoadSrc 屏障，阻止跨屏障重排。
【评分点】① 准确说出核心机制（内存屏障）；② 能带出原理层而非背结论。 ③ 版本锚点：JSR-133
