## CAS · cmpxchg（原子性）—— 7 类问法与标准话术

**Qconcurrency-302（概念考察·P4-P6）**
【面试官】请谈谈你对「CAS」中「cmpxchg」的理解。
【标准回答话术】CAS 依赖 CPU 的原子比较交换指令（x86 上 cmpxchg 配 lock 前缀）。背后的原理是：Java 通过 Unsafe 调用硬件原子指令，失败则自旋重试，全程无锁，JDK9 后推荐 VarHandle。
【评分点】① 准确说出核心机制（cmpxchg）；② 能带出原理层而非背结论。 ③ 版本锚点：x86 手册
