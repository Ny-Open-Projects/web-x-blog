## 线程池 · 有界（队列选择）—— 7 类问法与标准话术

**Qconcurrency-673（概念考察·P1-P3）**
【面试官】请谈谈你对「线程池」中「有界」的理解。
【标准回答话术】生产线程池必须用有界队列加显式拒绝策略。背后的原理是：无界队列让 maximumPoolSize 与拒绝策略形同虚设，过载信号被延迟到 OOM 才暴露，有界队列+拒绝策略构成完整反压。
【评分点】① 准确说出核心机制（有界）；② 能带出原理层而非背结论。 ③ 版本锚点：JCiP 8.x
