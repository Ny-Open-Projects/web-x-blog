## 并发容器 · 参数（CHM）—— 7 类问法与标准话术

**Qconcurrency-442（概念考察·P1-P3）**
【面试官】请谈谈你对「并发容器」中「参数」的理解。
【标准回答话术】CHM 默认初始容量 16 负载因子 0.75 与 HashMap 相同。背后的原理是：可传 initialSize 与 loadFactor 构造参数，预估条数设 initialSize=预期/负载因子避免扩容抖动。
