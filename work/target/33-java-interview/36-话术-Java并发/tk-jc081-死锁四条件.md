## 死锁 · 死锁四条件（排查）—— 7 类问法与标准话术

**Qconcurrency-561（概念考察·P6-P8）**
【面试官】请谈谈你对「死锁」中「死锁四条件」的理解。
【标准回答话术】死锁四条件：互斥、占有且等待、不可剥夺、循环等待。背后的原理是：破坏任一条件即可预防：按序加锁破坏循环等待、tryLock 超时破坏占有等待，jstack 可直接检出死锁。
【评分点】① 准确说出核心机制（死锁四条件）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识
