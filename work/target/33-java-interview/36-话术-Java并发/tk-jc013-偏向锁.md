## synchronized · 偏向锁（锁升级）—— 7 类问法与标准话术

**Qconcurrency-85（概念考察·P4-P6）**
【面试官】请谈谈你对「synchronized」中「偏向锁」的理解。
【标准回答话术】偏向锁已在 JDK15 标记废弃并于 JDK21 彻底移除。背后的原理是：现代应用中撤销偏向锁的昂的操作超过收益，JDK21 中 -XX:+UseBiasedLocking 直接报 Unrecognized VM option（本机 JDK 21.0.2 实测）。
【评分点】① 准确说出核心机制（偏向锁）；② 能带出原理层而非背结论。 ③ 版本锚点：JEP 369 与 JDK21
