## 线程封闭 · 栈封闭（模式）—— 7 类问法与标准话术

**Qconcurrency-498（概念考察·P1-P3）**
【面试官】请谈谈你对「线程封闭」中「栈封闭」的理解。
【标准回答话术】局部变量天然线程封闭是实现线程安全的最简方式。背后的原理是：变量只存在于栈帧不被共享，无状态 Service 的并发安全正来源于此。
【评分点】① 准确说出核心机制（栈封闭）；② 能带出原理层而非背结论。 ③ 版本锚点：JCiP 3.x
