## 虚拟线程 · JDK21（版本）—— 7 类问法与标准话术

**Qconcurrency-533（概念考察·P8-P10）**
【面试官】请谈谈你对「虚拟线程」中「JDK21」的理解。
【标准回答话术】虚拟线程是 JDK21 正式特性由 JVM 调度到少量载体线程。背后的原理是：创建成本极低（栈在堆上）可开百万级，阻塞时让出载体线程由 JVM 换入下一个虚拟线程，面向 IO 密集高并发。
【评分点】① 准确说出核心机制（JDK21）；② 能带出原理层而非背结论。 ③ 版本锚点：JEP 444
