## 线程基础 · yield（yield）—— 7 类问法与标准话术

**Qconcurrency-617（概念考察·P1-P3）**
【面试官】请谈谈你对「线程基础」中「yield」的理解。
【标准回答话术】yield 只是提示调度器让出当前 CPU 无任何保证。背后的原理是：可能立即被再次调度，也不保证让给谁，测试中用于模拟竞争但生产代码不依赖其语义。
【评分点】① 准确说出核心机制（yield）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK 文档

【评分点】① 快速识别误区不顺着说；② 给出正确的版本锚定表述（JDK 文档）。
