## JMM · as-if-serial（重排）—— 7 类问法与标准话术

**Qconcurrency-470（概念考察·P1-P3）**
【面试官】请谈谈你对「JMM」中「as-if-serial」的理解。
【标准回答话术】单线程内程序表现为串行语义（as-if-serial）编译器与 CPU 可自由重排。背后的原理是：重排只在不改变单线程结果的前提下进行，多线程下重排导致可见性问题，需要 happens-before 约束。
【评分点】① 准确说出核心机制（as-if-serial）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 17.4
