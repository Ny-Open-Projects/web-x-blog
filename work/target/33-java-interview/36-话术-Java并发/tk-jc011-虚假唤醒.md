## wait/notify · 虚假唤醒（误用）—— 7 类问法与标准话术

**Qconcurrency-71（概念考察·P6-P8）**
【面试官】请谈谈你对「wait/notify」中「虚假唤醒」的理解。
【标准回答话术】等待条件必须用 while 循环判断而不能用 if 以防虚假唤醒。背后的原理是：OS 或 notifyAll 唤醒后条件可能已被其他线程消费，while 在唤醒后重新检查条件，JLS 明确允许虚假唤醒存在。
【评分点】① 准确说出核心机制（虚假唤醒）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 17.2.3
