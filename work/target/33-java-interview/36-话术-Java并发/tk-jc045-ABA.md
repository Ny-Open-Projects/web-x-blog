## CAS · ABA（误用）—— 7 类问法与标准话术

**Qconcurrency-309（概念考察·P6-P8）**
【面试官】请谈谈你对「CAS」中「ABA」的理解。
【标准回答话术】CAS 存在 ABA 问题：值从 A 改回 A 时 CAS 无法察觉。背后的原理是：解决方式是加版本号，AtomicStampedReference 维护引用加 stamp 二元组，数据库乐观锁 version 字段同理。
【评分点】① 准确说出核心机制（ABA）；② 能带出原理层而非背结论。 ③ 版本锚点：学术与实战共识
