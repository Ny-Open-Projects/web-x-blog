## 线程池 · CallerRunsPolicy（拒绝策略）—— 7 类问法与标准话术

**Qconcurrency-218（概念考察·P1-P3）**
【面试官】请谈谈你对「线程池」中「CallerRunsPolicy」的理解。
【标准回答话术】CallerRunsPolicy 让提交任务的线程自己执行以实现反压。背后的原理是：执行期间提交线程被占用，上游生产速度被迫降速，是简洁的背压手段但会阻塞调用方。
【评分点】① 准确说出核心机制（CallerRunsPolicy）；② 能带出原理层而非背结论。 ③ 版本锚点：实战经验
