## JMM · 工作内存（模型）—— 7 类问法与标准话术

**Qconcurrency-463（概念考察·P4-P6）**
【面试官】请谈谈你对「JMM」中「工作内存」的理解。
【标准回答话术】JMM 抽象为主内存与线程工作内存每线程有本地副本。背后的原理是：线程操作的是副本，何时刷回主存未定义，需要 volatile、锁或 final 等同步动作建立可见性通道，这是可见性问题的根源。
【评分点】① 准确说出核心机制（工作内存）；② 能带出原理层而非背结论。 ③ 版本锚点：JSR-133
