## 死锁 · 锁排序（预防）—— 7 类问法与标准话术

**Qconcurrency-757（概念考察·P1-P3）**
【面试官】请谈谈你对「死锁」中「锁排序」的理解。
【标准回答话术】预防死锁最实用手段是全局一致的锁获取顺序。背后的原理是：按业务键排序（账户 ID 从小到大）转账互转不再死锁，tryLock 超时回退是补充手段，这两招覆盖绝大多数死锁。
【评分点】① 准确说出核心机制（锁排序）；② 能带出原理层而非背结论。 ③ 版本锚点：JCiP 10.x
