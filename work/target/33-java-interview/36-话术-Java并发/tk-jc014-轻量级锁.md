## synchronized · 轻量级锁（锁升级）—— 7 类问法与标准话术

**Qconcurrency-92（概念考察·P4-P6）**
【面试官】请谈谈你对「synchronized」中「轻量级锁」的理解。
【标准回答话术】无竞争时 synchronized 通过 CAS 获取轻量级锁避免重量级开销。背后的原理是：轻量级锁在栈帧建立 Lock Record 并 CAS 替换对象头 Mark Word，失败则膨胀为重量级（OS mutex，涉及用户态内核态切换）。
【评分点】① 准确说出核心机制（轻量级锁）；② 能带出原理层而非背结论。 ③ 版本锚点：HotSpot 内部机制
