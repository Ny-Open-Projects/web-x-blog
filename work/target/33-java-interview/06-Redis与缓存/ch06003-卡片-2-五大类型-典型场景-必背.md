### 卡片 2：五大类型 + 典型场景（必背）
| 类型 | 场景 | 底层编码（简） |
|------|------|----------------|
| String | 缓存、计数器、分布式锁 | SDS（简单动态字符串：O(1) 取长度、二进制安全、预分配） |
| Hash | 对象缓存、购物车 | listpack（小）/ hashtable |
| List | 消息列表、最新动态 | quicklist（双向链表+listpack 节点） |
| Set | 去重、抽奖、共同好友 | intset（全整数小集合）/ hashtable |
| ZSet | 排行榜、延迟队列 | listpack（小）/ **跳表+字典**（一个结构两种索引） |

扩展类型：BitMap（签到）、HyperLogLog（UV 估算，0.81% 误差 12KB）、GEO（附近的人）、Stream（消息队列，消费者组）。
