## 异步 · 线程池（@Async）

- **事实**：@Async 默认线程池的版本演进：Boot 2.1+ 自动配置 applicationTaskExecutor（core 8 队列无界 OOM 风险），Boot 3.2 开虚拟线程后是 SimpleAsyncTaskExecutor
- **原理**：纯 Spring 无 Boot 时回退 SimpleAsyncTaskExecutor（每任务新线程），@Async 必须显式配线程池防 OOM 与线程爆炸（本项目核对的版本结论）
- **常见误区**：
  1. @Async 默认池有界队列（错）
  2. 默认池是 FixedThreadPool（错）
  3. Boot 各版本默认池一致（错）
- **工程用法**：@Async 上线前必配自定义 Executor
- **版本锚点**：Boot 版本核对
