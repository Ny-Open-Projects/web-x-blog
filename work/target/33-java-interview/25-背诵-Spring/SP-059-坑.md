## 事务 · 坑（事件）

- **事实**：AFTER_COMMIT 监听器里再写数据库不会自动开新事务
- **原理**：此时事务资源已提交完成，写操作可能以 autoCommit 游离执行，需要 @Transactional(propagation=REQUIRES_NEW) 显式开新事务
- **常见误区**：
  1. 提交后写库自动有事务（错）
  2. 监听器继承原事务上下文（错）
  3. 该阶段不可能写库（错）
- **工程用法**：提交后补偿写库必须显式开新事务
