## Boot · 异常（web）

- **事实**：@RestControllerAdvice+@ExceptionHandler 全局异常映射
- **原理**：统一异常响应体（code/message/traceId），按异常类型精确匹配优先级高于父类，兜底 Exception.class 兜住未预期异常
- **常见误区**：
  1. @ExceptionHandler 在 Controller 内注册才生效（错）
  2. 全局异常处理器只能处理一个异常类型（错）
  3. 兜底 handler 会覆盖精确匹配（错）
- **工程用法**：异常体系的统一出口
- **版本锚点**：Spring MVC 文档
