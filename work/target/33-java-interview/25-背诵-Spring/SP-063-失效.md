## 异步 · 失效（@Async）

- **事实**：@Async 失效场景：同类自调用、未加 @EnableAsync、方法非 public
- **原理**：与事务失效同源（代理绕过），@Async 异常对 void 方法进入 AsyncUncaughtExceptionHandler，返回 Future 则留在 Future 里
- **常见误区**：
  1. @Async 默认启用无需 @EnableAsync（错）
  2. 自调用异步生效（错）
  3. void 方法异常自动打印全栈（默认走 handler 打日志但不会传播）（错）
- **工程用法**：异步任务失效排查三板斧
- **版本锚点**：实战共识
