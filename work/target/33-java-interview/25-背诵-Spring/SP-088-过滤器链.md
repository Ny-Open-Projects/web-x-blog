## 安全 · 过滤器链（Spring Security）

- **事实**：Spring Security 基于 Servlet Filter 链（FilterChainProxy 代理一串安全过滤器）
- **原理**：认证（AuthenticationManager）、授权（AuthorizationManager）、CSRF、会话管理各是一环，与业务拦截器（HandlerInterceptor）职责分层
- **常见误区**：
  1. Spring Security 是拦截器实现（错）
  2. FilterChainProxy 只有一个过滤器（错）
  3. 安全配置在 Controller 层（错）
- **工程用法**：认证授权体系的主干
- **版本锚点**：Spring Security 文档
