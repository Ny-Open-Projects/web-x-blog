## IoC · 综合（面试）

- **事实**：Spring 高频面试主线：Bean 生命周期→三级缓存→AOP 代理时机→事务传播→自动配置
- **原理**：这条链覆盖 80% Spring 面试题，每环都有源码级细节（本项目已逐环核对源码与文档）
- **常见误区**：
  1. 面试只考注解用法（错）
  2. 源码细节面试不问（错）
  3. 事务与 AOP 是两个独立体系（错）
- **工程用法**：复习主线图
- **版本锚点**：复习方法论
