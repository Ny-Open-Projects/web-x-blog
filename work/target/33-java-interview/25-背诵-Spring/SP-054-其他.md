## 事务 · 其他（传播）

- **事实**：MANDATORY 强制要求已有事务、NEVER 禁止事务、SUPPORTS 有则用无则非事务、NOT_SUPPORTED 挂起以非事务执行
- **原理**：四种边界型传播用于约束调用契约（如查询方法 MANDATORY 保证必须被事务包裹）
- **常见误区**：
  1. SUPPORTS 会新建事务（错）
  2. NEVER 表示需要新事务（错）
  3. NOT_SUPPORTED 与 SUPPORTS 等价（错）
- **工程用法**：契约型方法设计
- **版本锚点**：Spring 文档
