## WebFlux · 响应式（对比）

- **事实**：WebFlux 是响应式非阻塞栈（Reactor）吞吐高于阻塞栈但心智与调试成本高
- **原理**：少量线程处理大量连接（Netty），回溯调试难、生态（JDBC 阻塞）受限，R2DBC 弥补数据库层，选型看团队与场景
- **常见误区**：
  1. WebFlux 吞吐一定高于 MVC（错）
  2. WebFlux 让接口延迟更低（错）
  3. 响应式无需学习成本（错）
- **工程用法**：IO 密集高并发网关场景
- **版本锚点**：Spring WebFlux 文档
