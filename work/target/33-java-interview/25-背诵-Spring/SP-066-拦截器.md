## Boot · 拦截器（web）

- **事实**：HandlerInterceptor 在 Controller 前后执行（preHandle/postHandle/afterCompletion），Bean 由 Spring 容器管理
- **原理**：Filter 是 Servlet 规范在 DispatcherServlet 之前，拦截器能拿 Handler 信息与容器 Bean，afterCompletion 在视图渲染后必执行（适合清理）
- **常见误区**：
  1. 拦截器比 Filter 更早执行（错）
  2. Filter 能访问 HandlerMethod（错）
  3. 拦截器是 Servlet 规范一部分（错）
- **工程用法**：登录态/幂等/审计用拦截器，编码/全链路 header 用 Filter
- **版本锚点**：Spring MVC 文档
