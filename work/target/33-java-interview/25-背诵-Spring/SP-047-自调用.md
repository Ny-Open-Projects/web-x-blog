## 事务 · 自调用（失效）

- **事实**：@Transactional 自调用失效是最高频事务坑
- **原理**：同类 this 调用不走代理事务拦截器不介入，与 AOP 失效同源，表现：内层注解方法无事务
- **常见误区**：
  1. 自调用时事务仍生效（错）
  2. 把方法改 private 能修复（错）
  3. 事务失效只有传播行为一种原因（错）
- **工程用法**：事务失效八股的第一条
- **版本锚点**：实战共识
