## Boot · 3.x（版本）

- **事实**：Spring Boot 3.x 要求 JDK17+ 且 javax.* 迁移到 jakarta.*
- **原理**：Servlet 规范jakarta EE 9+ 命名空间迁移，第三方依赖（如老 MyBatis 老版本）不兼容 jakarta 时升级受阻，需升依赖版本
- **常见误区**：
  1. Boot 3 支持 JDK8（错）
  2. jakarta 只是改了包名无 API 变化（签名等价但二进制不兼容需重新编译）（错）
  3. 可以渐进式混用 javax 与 jakarta（错）
- **工程用法**：Boot 3 升级评估清单
- **版本锚点**：Boot 3.0
