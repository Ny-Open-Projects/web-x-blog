## 综合 · 优先级（复习）

- **事实**：Spring 复习优先级：事务失效与传播 > Bean 生命周期与三级缓存 > AOP 原理 > Boot 自动配置 > MVC 流程
- **原理**：按面试命中率排序（P7 岗位 JD 高频），每块都配手写复述（不看书讲清楚）再进下一块
- **常见误区**：
  1. MVC 流程最重要（错）
  2. 自动配置占比最大（错）
  3. 事务不是重点（错）
- **工程用法**：复习时间分配依据
- **版本锚点**：复习方法论
