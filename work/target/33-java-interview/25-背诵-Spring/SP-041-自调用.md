## AOP · 自调用（失效）

- **事实**：同类内 this 调用注解方法 AOP 失效（事务/异步/缓存）
- **原理**：this 指向原始对象而非代理，绕过代理拦截，解法：注入自身代理、AopContext.currentProxy（需 exposeProxy）、拆类
- **常见误区**：
  1. 自调用 AOP 依然生效（错）
  2. 只有 @Transactional 受影响（错）
  3. 把方法改 public 就能解决自调用（错）
- **工程用法**：事务/异步注解失效第一原因
- **版本锚点**：实战共识
