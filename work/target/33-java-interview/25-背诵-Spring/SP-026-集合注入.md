## IoC · 集合注入（注入）

- **事实**：注入 List/Map 类型会收集容器内所有匹配类型的 Bean
- **原理**：策略模式的 Spring 实现：注入 List<Handler> 或 Map<String,Handler>（key 为 Bean 名），配合 @Order 排序
- **常见误区**：
  1. 集合注入只会注入一个 Bean（错）
  2. 集合注入不支持泛型匹配（错）
  3. 无法控制顺序（错）
- **工程用法**：策略模式落地标准写法
- **版本锚点**：Spring 文档
