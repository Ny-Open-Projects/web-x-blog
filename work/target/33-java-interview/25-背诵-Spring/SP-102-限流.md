## AOP · 限流（场景）

- **事实**：限流切面：Sentinel/@RateLimiter 注解 + 切面读取阈值
- **原理**：接口级限流注解化，底层令牌桶/滑动窗口，超限快速失败或降级，与网关层限流分层（网关粗粒度、应用细粒度）
- **常见误区**：
  1. 应用层限流可以替代网关限流（错）
  2. 限流是单机概念无集群版（错）
  3. 注解限流性能开销巨大（错）
- **工程用法**：接口 QPS 治理
- **版本锚点**：实战共识
