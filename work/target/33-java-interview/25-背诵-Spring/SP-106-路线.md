## Boot · 路线（升级）

- **事实**：升级路线：Boot 1.5（EOL）→2.7（过渡）→3.x（JDK17/jakarta），依赖版本同步升级
- **原理**：2.x 尾版 2.7 是迁移缓冲，先升 2.7 修废弃 API 再跨 3.0，spring-boot-properties-migrator 自动提示配置变更
- **常见误区**：
  1. 可直接从 1.5 跳 3.0（错）
  2. 升级只改父版本号（错）
  3. jakarta 迁移工具自动完成（错）
- **工程用法**：老系统升级路线图
- **版本锚点**：Boot 官方迁移指南
