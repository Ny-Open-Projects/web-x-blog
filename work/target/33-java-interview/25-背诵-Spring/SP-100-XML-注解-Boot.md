## 演进 · XML→注解→Boot（历史）

- **事实**：Spring 演进：XML 配置→注解+JavaConfig→Spring Boot 自动配置→云原生
- **原理**：每个阶段解决上一阶段的配置复杂度，理解演进脉络才能回答"为什么 Spring Boot 能流行"
- **常见误区**：
  1. XML 配置当前仍是主流（错）
  2. Boot 放弃了 XML（其实支持）（错）
  3. 演进只是语法变化（错）
- **工程用法**：体系化回答 Spring 是什么
- **版本锚点**：历史共识
