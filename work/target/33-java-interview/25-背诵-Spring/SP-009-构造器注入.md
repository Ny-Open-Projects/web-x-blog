## 循环依赖 · 构造器注入（限制）

- **事实**：构造器注入的循环依赖 Spring 无法解决
- **原理**：实例化前就需要依赖方，提前曝光机制尚未生效（对象还没 new 出来），Spring Boot 2.6 起默认禁止一切循环依赖并要求重构
- **常见误区**：
  1. 构造器注入循环依赖可以解决（错）
  2. setter 注入循环依赖在 Boot 2.6+ 默认仍可注入（错）
  3. @Lazy 不能解决循环依赖（错）
- **工程用法**：用 @Lazy 或重构消除依赖链
- **版本锚点**：Boot 2.6 release note
