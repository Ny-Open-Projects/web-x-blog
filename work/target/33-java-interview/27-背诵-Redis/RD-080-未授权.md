## 安全 · 未授权（暴露）

- **事实**：Redis 未授权访问是经典安全事故源（bind 0.0.0.0+无密码）
- **原理**：攻击面：写 crontab/SSH key 控制机器，防御：内网 bind+ACL+禁用危险命令+网络隔离，安全扫描必查项
- **常见误区**：
  1. 内网部署就安全（错）
  2. 密码复杂度是唯一防线（错）
  3. 攻击只影响 Redis 数据（错）
- **工程用法**：安全审计知识点
- **版本锚点**：实战共识
