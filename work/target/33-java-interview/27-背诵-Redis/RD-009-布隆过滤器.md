## 扩展类型 · 布隆过滤器（布隆）

- **事实**：布隆过滤器以低空间判断"元素一定不存在"（可能误判存在）
- **原理**：位数组+多哈希函数，用于缓存穿透前置过滤，官方 module（RedisBloom）或 Lua/位图模拟
- **常见误区**：
  1. 布隆过滤器判断存在的一定存在（错）
  2. 布隆过滤器支持删除（标准版不支持，Counting 版支持）（错）
  3. 误判率可以降到 0（错）
- **工程用法**：缓存穿透方案组件
- **版本锚点**：RedisBloom
