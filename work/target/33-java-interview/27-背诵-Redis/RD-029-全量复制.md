## 复制 · 全量复制（全量）

- **事实**：主从首次同步走全量复制：主 bgsave RDB 发送+期间增量缓冲
- **原理**：从库清空旧数据载入 RDB，复制缓冲区补发期间写命令，大实例全量复制是分钟级风险窗口
- **常见误区**：
  1. 全量复制不影响主库（错）
  2. RDB 传输不占带宽（错）
  3. 从库保留旧数据混合（错）
- **工程用法**：主从搭建与抖动知识
- **版本锚点**：官方文档
