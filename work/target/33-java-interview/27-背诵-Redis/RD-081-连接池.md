## 客户端 · 连接池（连接池）

- **事实**：客户端连接池参数：maxTotal/maxIdle/minIdle/maxWait，池满阻塞与获取超时监控
- **原理**：连接数估算：maxTotal ≈ 单机 QPS×平均耗时（秒），池太小排队池太大压 Redis，Jedis 依赖池 Lettuce 默认单连接
- **常见误区**：
  1. 连接池越大越好（错）
  2. 池参数无需监控（错）
  3. maxIdle 与 maxTotal 相同是最佳实践（错）
- **工程用法**：客户端调优
- **版本锚点**：实战共识
