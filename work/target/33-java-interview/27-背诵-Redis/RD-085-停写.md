## 运维 · 停写（持久化）

- **事实**：持久化异常处理：AOF 重写失败/磁盘满时 Redis 可能停止写入
- **原理**：磁盘监控+持久化状态告警（rdb_last_bgsave_status），appendfsync 出错策略 appendfsync-on-rewrite 折中，磁盘是 Redis 的隐形依赖
- **常见误区**：
  1. 磁盘满不影响 Redis（错）
  2. 持久化失败自动恢复（错）
  3. 持久化状态不需要监控（错）
- **工程用法**：故障预防知识
- **版本锚点**：实战共识
