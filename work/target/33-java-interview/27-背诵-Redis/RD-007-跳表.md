## ZSet · 跳表（原理）

- **事实**：跳表通过多层索引链表实现 O(logN) 查找层高随机生成（幂次定律）
- **原理**：每层节点概率性上浮形成多级索引，插入删除只改指针免旋转，比红黑树实现简单且范围查询友好
- **常见误区**：
  1. 跳表层高固定（错）
  2. 跳表查找 O(1)（错）
  3. 跳表需要像红黑树一样旋转（错）
- **工程用法**：高频追问"为什么用跳表不用红黑树"（范围查询+实现简单）
- **版本锚点**：算法原理
