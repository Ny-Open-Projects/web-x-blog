## 事务 · 原子性（Lua）

- **事实**：Lua 脚本执行期间原子（单线程不被打断）
- **原理**：整段脚本作为一个命令执行，适合"检查+操作"复合逻辑（分布式锁释放、库存扣减），脚本过长阻塞主线程
- **常见误区**：
  1. Lua 脚本可以并行执行（错）
  2. Lua 脚本出错会自动回滚已执行部分（错）
  3. Lua 与事务等价无优势（错）
- **工程用法**：复合操作原子化标准方案
- **版本锚点**：官方文档
