## Lua · 脚本复制（复制）

- **事实**：Lua 脚本复制默认复制"脚本的执行效果"（7.0 起改为复制写命令效果，effect replication）
- **原理**：Redis 7 前复制脚本本身（从库需载入相同脚本），7.0 起 effects 复制（从库执行等效写命令，免脚本传播问题），涉及脚本复制的版本兼容知识
- **常见误区**：
  1. 脚本复制的是脚本文本（7.0 前是）（错）
  2. 从库执行脚本与主库结果可能不同（7.0 前的已知问题）（错）
  3. Lua 脚本不复制（错）
- **工程用法**：脚本版本升级知识
- **版本锚点**：Redis 7.0
