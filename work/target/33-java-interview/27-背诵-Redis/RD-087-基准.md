## 运维 · 基准（压测）

- **事实**：压测基准：redis-benchmark（QPS 单机 10 万级），瓶颈在网络与单线程命令复杂度
- **原理**：官方工具测基线，生产实例看实际 QPS 与 CPU（单线程模型下 CPU 100%=单分片极限），扩容靠分片不是加配置
- **常见误区**：
  1. Redis 单机百万 QPS（错）
  2. 压测不需要做（错）
  3. CPU 高就加从库（错）
- **工程用法**：容量与极限知识
- **版本锚点**：实战方法论
