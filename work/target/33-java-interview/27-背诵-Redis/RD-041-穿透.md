## 缓存 · 穿透（穿透）

- **事实**：缓存穿透：查询不存在的数据每次打到库
- **原理**：方案：布隆过滤器前置拦截、缓存空值（短 TTL）、接口参数校验，恶意穿透要网关限流
- **常见误区**：
  1. 缓存穿透可以靠加长 TTL 解决（错）
  2. 穿透与雪崩是一回事（错）
  3. 缓存空值是反模式（错）
- **工程用法**：缓存三大问题之一
- **版本锚点**：实战共识
