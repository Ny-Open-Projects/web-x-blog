## 运维 · 估算（容量）

- **事实**：容量估算：内存=Σ(key 长度+value 编码开销+元数据)×副本数+ fragmentation 余量
- **原理**：粗估公式：业务对象序列化后×1.5（元数据与碎片），设计阶段估算防线上缩容，jemalloc 分配器放大系数需考虑
- **常见误区**：
  1. 容量=数据量直接相加（错）
  2. Redis 内存开销很小可忽略（错）
  3. 副本不占内存（错）
