## 线程模型 · 命令执行（单线程）

- **事实**：Redis 命令执行是单线程的（6.0 起网络 IO 与协议解析可多线程）
- **原理**：单线程免锁免上下文切换，瓶颈在网络而非 CPU，6.0 多线程只处理读写 socket 不执行命令
- **常见误区**：
  1. Redis 6.0 全面多线程（错）
  2. 多线程模式下命令并行执行（错）
  3. Redis 单线程指整个进程单线程（后台线程有多个：fsync/close 等）（错）
- **工程用法**：回答单线程模型必须分 6.0 前后
- **版本锚点**：Redis 6.0
