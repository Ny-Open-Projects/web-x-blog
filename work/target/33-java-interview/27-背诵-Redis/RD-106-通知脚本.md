## 哨兵 · 通知脚本（扩展）

- **事实**：哨兵故障事件可触发通知脚本（sentinel notification-script）与客户端重配脚本
- **原理**：事件（+sdown/-sdown/+switch-master）推送运维（邮件/webhook），重配脚本在切主后通知 LB/代理更新路由，是哨兵体系的运维扩展点
- **常见误区**：
  1. 哨兵只改配置不通知任何人（错）
  2. 通知脚本必须存在才能切换（错）
  3. 脚本同步阻塞切换流程（错）
- **工程用法**：哨兵运维集成
- **版本锚点**：官方文档
