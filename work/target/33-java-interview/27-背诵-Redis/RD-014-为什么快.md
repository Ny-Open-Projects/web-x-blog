## 线程模型 · 为什么快（性能）

- **事实**：Redis 快的原因：内存操作+单线程无锁竞争+IO 多路复用+高效数据结构
- **原理**：四个因素缺一不可，面试按此框架展开（内存、无锁、epoll、编码优化）
- **常见误区**：
  1. Redis 快是因为多线程（错）
  2. 快主要靠缓存不命中也无所谓（错）
  3. C 语言写的就是快（语言不是主因）（错）
- **工程用法**：性能原理八股主线
- **版本锚点**：通用
