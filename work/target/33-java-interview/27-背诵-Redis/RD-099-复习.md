## 面试 · 复习（主线）

- **事实**：Redis 复习主线：数据结构与编码→持久化→主从/哨兵/Cluster→缓存三大问题→分布式锁→场景设计
- **原理**：按面试频率排序，缓存一致性与分布式锁是 P7 分水岭，Cluster 细节是 P8+ 深度，场景设计（秒杀/排行榜/延迟队列）是 P9-P10 综合题
- **常见误区**：
  1. Cluster 最重要（错）
  2. 数据结构可以跳过（错）
  3. 场景题不重要（错）
- **工程用法**：复习时间分配
- **版本锚点**：复习方法论
