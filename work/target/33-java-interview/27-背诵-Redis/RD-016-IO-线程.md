## 线程模型 · IO 线程（6.0）

- **事实**：Redis 6.0 多线程默认关闭需 io-threads 配置开启
- **原理**：开启后读请求解析与写回复并行化，命令执行仍单线程保证原子性，大流量实例收益明显
- **常见误区**：
  1. 6.0 开启后吞吐降低（错）
  2. io-threads 默认开启（错）
  3. 多线程后不需要持久化（错）
- **工程用法**：大流量实例网络瓶颈优化
- **版本锚点**：Redis 6.0
