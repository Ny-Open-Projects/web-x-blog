## 数据类型 · 编码（String）

- **事实**：String 编码自动选择：int（纯整数）→embstr（≤44 字节一次性分配）→raw
- **原理**：embstr 将 SDS 与 redisObject 一次分配（缓存友好）但不可修改（修改转 raw），44 字节是分配器 jemalloc 单元决定
- **常见误区**：
  1. String 编码手动指定（错）
  2. embstr 可原地修改（错）
  3. 44 是随机值（错）
- **工程用法**：编码细节深入题
- **版本锚点**：源码实现
