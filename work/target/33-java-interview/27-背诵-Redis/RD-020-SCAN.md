## 运维 · SCAN（遍历）

- **事实**：SCAN 用游标渐进遍历不阻塞，但可能返回重复元素且不保证一致快照
- **原理**：游标记录遍历位置，rehash 期间反向二进制迭代器保证不漏（可能重），业务侧去重
- **常见误区**：
  1. SCAN 保证精确一致（错）
  2. SCAN 一定不会重复（错）
  3. SCAN 是并行多线程遍历（错）
- **工程用法**：全库扫描的标准姿势
- **版本锚点**：官方文档
