## 运维 · 备份（备份）

- **事实**：RDB 文件即备份产物（定期异地保存），AOF 用于更细恢复点
- **原理**：备份策略：每日 bgsave 产物上传对象存储+跨机房副本，恢复演练定期做，Redis 数据多为缓存可容忍重建（持久化数据另议）
- **常见误区**：
  1. Redis 不需要备份（缓存数据也要重建成本评估）（错）
  2. AOF 文件可以直接 scp 当备份（错）
  3. 恢复不需要演练（错）
- **工程用法**：备份体系
- **版本锚点**：实战方法论
