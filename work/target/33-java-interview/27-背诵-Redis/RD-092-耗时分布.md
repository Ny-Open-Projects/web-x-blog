## 运维 · 耗时分布（性能）

- **事实**：性能分析三板斧：慢日志（命令级）、LATENCY（事件级）、MONITOR（命令流，慎用）
- **原理**：慢日志看单条命令耗时，LATENCY 看停顿事件（fork/过期风暴），MONITOR 生产禁用（全量命令流放大流量）
- **常见误区**：
  1. MONITOR 可以随便开（错）
  2. 慢日志含网络时间（错）
  3. LATENCY 是客户端概念（错）
- **工程用法**：性能诊断工具链
- **版本锚点**：实战共识
