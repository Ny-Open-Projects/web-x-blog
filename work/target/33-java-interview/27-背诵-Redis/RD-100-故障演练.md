## 运维 · 故障演练（演练）

- **事实**：故障演练：主动杀 Redis 主库验证哨兵切换时长、业务降级有效性（混沌工程）
- **原理**：演练暴露预案缺陷（降级没生效/客户端重连风暴），ChaosBlade/脚本模拟，演练报告归档，季度常态化
- **常见误区**：
  1. 演练影响业务不做（错）
  2. 切换演练只做一次（错）
  3. 演练是 DBA 的事与业务无关（错）
- **工程用法**：稳定性体系
- **版本锚点**：实战方法论
