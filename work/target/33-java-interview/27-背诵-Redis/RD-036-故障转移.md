## Cluster · 故障转移（高可用）

- **事实**：Cluster 每个主节点带从节点，故障时从节点多数派选举自动升主
- **原理**：类 Raft 从库选举（新主为复制 offset 最靠前者），无需独立哨兵进程，半数以上主节点可用才能选举（cluster-require-full-coverage）
- **常见误区**：
  1. Cluster 需要另配哨兵（错）
  2. 从库选举不需要多数派（错）
  3. 一个从库故障导致集群不可用（错）
- **工程用法**：Cluster 高可用模型
- **版本锚点**：官方文档
