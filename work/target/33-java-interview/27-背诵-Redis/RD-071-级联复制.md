## 复制 · 级联复制（级联）

- **事实**：从库可以再挂从库（级联复制）分摊主库同步压力
- **原理**：一主多从主库 fork 与网络开销大，级联树形复制分摊，代价是末端延迟叠加
- **常见误区**：
  1. 从库不能再挂从库（错）
  2. 级联复制降低一致性（错）
  3. 级联是 Cluster 特性（错）
- **工程用法**：大规模主从架构
- **版本锚点**：官方文档
