## 分布式锁 · 锁丢失（主从）

- **事实**：主从架构下主库加锁未同步即宕机，从库升主后锁丢失
- **原理**：解决：RedLock 多实例独立加锁过半成功才持锁，或业务 fencing token（令牌单调递增校验），单实例锁+主从异步复制天然有此窗口
- **常见误区**：
  1. 主从复制不影响锁（错）
  2. 锁丢失概率为零（错）
  3. 从库同步完成才返回（Redis 主库不等从库）（错）
- **工程用法**：锁失效排查知识
- **版本锚点**：实战共识
