## 运维 · 清单（治理）

- **事实**：Redis 上线检查单：maxmemory+淘汰策略、持久化配置、ACL、慢日志阈值、监控接入、备份任务、key 规范
- **原理**：每项默认值不适合生产需显式配置，变更走评审，本项目总结的上线基线
- **常见误区**：
  1. 默认配置生产可用（错）
  2. 检查单一次配置终身有效（错）
  3. 治理与开发无关（错）
- **工程用法**：运维标准化
- **版本锚点**：实战方法论
