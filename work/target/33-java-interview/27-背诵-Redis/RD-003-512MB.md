## String · 512MB（限制）

- **事实**：单个 String 值上限 512MB
- **原理**：大值属于反模式（大 key），序列化大对象应拆分或外置，512MB 是协议层限制
- **常见误区**：
  1. String 无大小限制（错）
  2. 上限是 1MB（错）
  3. 超限自动分片（错）
- **工程用法**：大 key 治理的边界知识
- **版本锚点**：官方文档
