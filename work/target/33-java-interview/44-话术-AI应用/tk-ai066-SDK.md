## Java · SDK（集成）—— 7 类问法与标准话术

**Qai-456（概念考察·P1-P3）**
【面试官】请谈谈你对「Java」中「SDK」的理解。
【标准回答话术】Java SDK 层细节：超时（连接/读分开）、重试（429 退避）、流式（SSE 客户端）、连接池、代理配置。背后的原理是：LLM SDK 是特殊"HTTP 客户端"（长响应/流式/限流语义），超时长于生成时间、429 与 5xx 区别重试、SSE 断线处理，与 HTTP 客户端工程知识联动。
【评分点】① 准确说出核心机制（SDK）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
