## Java · 并发调用（并发）

- **事实**：LLM 并发调用治理：限流（供应商 RPM/TPM 配额）、批量接口（batch API 半价）、并发池隔离（不同业务独立配额）
- **原理**：供应商按 token/请求限流（429），应用侧限流+排队（防雪崩）、批处理（离线任务），与 Redis 限流/MQ 削峰知识同构
- **常见误区**：
  1. 供应商无限流（错）
  2. 429 重试即可（错）
  3. 并发越大越好（错）
- **工程用法**：配额治理
- **版本锚点**：实战共识
