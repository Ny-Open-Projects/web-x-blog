## Agent · 工具结果（上下文）

- **事实**：工具结果必须截断/摘要后再入上下文（防单次工具调用撑爆窗口）
- **原理**：大 JSON/长日志工具结果一次性进上下文挤掉任务关键信息且费用陡增，策略：截断+字段筛选+摘要（LLM 二次加工），是 Agent 工程常见事故点
- **常见误区**：
  1. 工具结果越大越好（错）
  2. 上下文窗口大就不用截断（错）
  3. 截断影响正确性不能做（错）
- **工程用法**：Agent 稳定性工程
- **版本锚点**：实战共识
