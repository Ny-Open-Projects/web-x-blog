## RAG · 自适应（进阶）

- **事实**：自适应 RAG：按问题复杂度路由（简单问题直答/复杂问题多轮检索），检索质量自评（不够则改写重查）
- **原理**：一刀切 RAG 浪费成本（简单问题也检索）且质量不稳（复杂问题单轮不够），self-RAG/CRAG 思路，评估驱动路由，与 Agent 规划模块联动
- **常见误区**：
  1. RAG 流程固定最好（错）
  2. 自适应更贵没有收益（错）
  3. 检索一次必然够用（错）
- **工程用法**：RAG 架构演进
- **版本锚点**：实战共识
