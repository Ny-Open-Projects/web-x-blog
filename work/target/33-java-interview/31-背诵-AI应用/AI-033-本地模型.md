## Java · 本地模型（集成）

- **事实**：本地部署模型：Ollama（易用）/vLLM（高吞吐生产），Java 通过 OpenAI 兼容接口接入
- **原理**：数据不出域（隐私/合规）场景本地部署，Ollama 开发体验好（一行拉模型），vLLM 生产吞吐高（PagedAttention），硬件要求（显存）是门槛
- **常见误区**：
  1. 本地模型无法生产使用（错）
  2. Ollama 就是生产方案（错）
  3. 本地模型无硬件要求（错）
- **工程用法**：部署选型
- **版本锚点**：实战共识
