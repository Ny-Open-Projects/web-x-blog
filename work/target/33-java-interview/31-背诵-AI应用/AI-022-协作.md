## Agent · 协作（多智能体）

- **事实**：多 Agent 协作模式：主从（orchestrator 分发）、流水线（串行传递）、辩论（相互校验），复杂度与收益成正比需谨慎
- **原理**：单 Agent+好工具通常优于多 Agent（通信/一致性开销），多 Agent 适合角色分工明确场景（ coder/reviewer），P10 观点：先榨干单 Agent 再上多 Agent
- **常见误区**：
  1. 多 Agent 一定更强（错）
  2. 多 Agent 无额外成本（错）
  3. 协作模式随意选（错）
- **工程用法**：复杂 Agent 架构权衡
- **版本锚点**：实战共识
