## Java · 断线（流式）

- **事实**：SSE 流式断线处理：客户端断开停止生成（节约成本）与重连续传（Last-Event-ID）
- **原理**：用户关闭页面应取消生成（省 token），意外断线用 Last-Event-ID 续传（SSE 标准），Java 侧 SseEmitter 完成/超时/错误回调清理资源
- **常见误区**：
  1. 断线后模型继续生成（应取消）（错）
  2. SSE 断线自动续传（需实现）（错）
  3. 流式不能用断点续传（错）
- **工程用法**：交互体验与成本平衡
- **版本锚点**：实战共识
