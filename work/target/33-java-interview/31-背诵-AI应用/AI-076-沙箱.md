## Agent · 沙箱（安全）

- **事实**：Agent 工具执行沙箱：代码执行用隔离容器（无网络/限时/资源限额）、SQL 用只读账号+行数限制、Shell 白名单命令
- **原理**：Agent 生成的代码/命令不可信（与用户输入同级），执行环境最小权限（与 SQL 注入防御 MY-095 同思路），沙箱逃逸测试纳入安全评审
- **常见误区**：
  1. 沙箱影响能力可去掉（错）
  2. 模型生成代码是安全的（错）
  3. 容器隔离绝对安全（错）
- **工程用法**：执行安全
- **版本锚点**：实战共识
