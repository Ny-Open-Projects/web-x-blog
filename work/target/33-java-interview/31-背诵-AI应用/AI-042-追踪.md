## Agent · 追踪（观测）

- **事实**：Agent 可观测：每次 LLM 调用（prompt/token/耗时/成本）+工具调用（入参/结果）全量追踪
- **原理**：Agent 步数多且不确定（循环），无追踪则无法定位"为什么答错"（检索差/工具错/模型错），token 与成本按调用聚合，Langfuse/OpenTelemetry GenAI 语义约定
- **常见误区**：
  1. Agent 不需要观测（错）
  2. 日志就够了（错）
  3. 观测影响性能（错）
- **工程用法**：Agent 工程化标配
- **版本锚点**：实战共识
