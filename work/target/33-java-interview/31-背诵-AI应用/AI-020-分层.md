## Agent · 分层（记忆）

- **事实**：Agent 记忆分层：短期=上下文窗口内对话、工作记忆=任务状态结构化、长期=向量库/数据库持久化
- **原理**：窗口内记忆随对话滚动丢失，长期记忆检索注入（用户偏好/历史结论），记忆写入策略（什么值得记）比存储更关键
- **常见误区**：
  1. 记忆全放上下文（错）
  2. 长期记忆=聊天记录（错）
  3. 记忆越大越好（错）
- **工程用法**：多轮/跨会话 Agent 设计
- **版本锚点**：实战共识
