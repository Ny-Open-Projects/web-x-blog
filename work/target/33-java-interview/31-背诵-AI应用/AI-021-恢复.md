## Agent · 恢复（checkpoint）

- **事实**：长任务 Agent 需 checkpoint：每步持久化状态（任务/中间结果），失败从断点恢复
- **原理**：Agent 跑数分钟到数小时（多工具多步），中断重跑成本高，checkpoint+幂等工具是可靠性基础，与工作流引擎（Temporal）思想同构
- **常见误区**：
  1. Agent 失败自动恢复（错）
  2. 状态只在内存（错）
  3. checkpoint 是可选项（错）
- **工程用法**：长任务可靠性
- **版本锚点**：实战共识
