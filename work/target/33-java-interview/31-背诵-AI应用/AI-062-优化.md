## 成本 · 优化（token）

- **事实**：token 成本优化细节：system prompt 精简（长指令压缩为要点）、历史摘要（滚动压缩）、few-shot 精选（2-3 个高质量）、结构化输出（JSON 短于自然语言）
- **原理**：每 token 都是钱（输入输出同价），prompt 瘦身是零风险优化（先离线评估不降质），缓存 system prompt（供应商 prompt caching 折扣），与 AI-026 四招配合
- **常见误区**：
  1. prompt 长效果必然好（错）
  2. 历史全量保留（错）
  3. 输出格式不影响成本（错）
- **工程用法**：token 工程细节
- **版本锚点**：实战共识
