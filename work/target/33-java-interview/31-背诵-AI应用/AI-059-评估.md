## Agent · 评估（测试）

- **事实**：Agent 评估：任务成功率（端到端）、步数/成本效率、工具调用准确率、边界场景（工具失败/恶意输入）
- **原理**：Agent 评估比单轮问答复杂（多步轨迹），轨迹回放（记录 trace 评估每步决策），离线模拟环境（mock 工具）+线上灰度，与 AI-034 评估体系联动
- **常见误区**：
  1. Agent 无法评估（错）
  2. 成功率是唯一指标（错）
  3. 测试环境等于生产（错）
- **工程用法**：Agent 质量工程
- **版本锚点**：实战共识
