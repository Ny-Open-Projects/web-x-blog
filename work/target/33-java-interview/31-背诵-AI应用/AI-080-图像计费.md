## 成本 · 图像计费（多模态）

- **事实**：多模态图像按分辨率折算 token（一张图数百到数千 token）
- **原理**：图像 token 远高于同信息量文本（描述性文本更省），缩图降分辨率直接降成本，批处理图片任务先评估 token 预算
- **常见误区**：
  1. 图像不计费（错）
  2. 图像 token 固定每张 100（错）
  3. 分辨率与成本无关（错）
- **工程用法**：图像批量任务成本估算
- **版本锚点**：通用
