## LLM · LoRA（微调）

- **事实**：LoRA（低秩适配）：冻结原模型只训练小矩阵（参数量 <1%），单卡可微调，效果接近全参
- **原理**：大幅降低微调门槛（显存/数据/时间），适配器可插拔（多任务多 adapter），与量化（QLoRA）组合进一步降本，是企业微调的主流方法
- **常见误区**：
  1. LoRA 效果远差于全参（错）
  2. LoRA 改变基座模型（错）
  3. LoRA 需要 8 卡集群（错）
- **工程用法**：微调技术选型
- **版本锚点**：实战共识
