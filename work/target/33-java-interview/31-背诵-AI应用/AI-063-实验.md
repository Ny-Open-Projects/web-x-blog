## 应用 · 实验（A/B）

- **事实**：LLM 功能 A/B 实验：prompt 版本/模型版本灰度对比（采纳率/成本/质量指标），评估集回归+线上灰度双保险
- **原理**：prompt 与模型都是"代码"（变更要实验），线上灰度小流量对比（统计显著性），回滚预案（评估集退化即回滚），与发布灰度知识（DF-050）同构
- **常见误区**：
  1. prompt 改了直接全量（错）
  2. 实验不需要对照组（错）
  3. 评估集可以代替线上（错）
- **工程用法**：迭代工程
- **版本锚点**：实战共识
