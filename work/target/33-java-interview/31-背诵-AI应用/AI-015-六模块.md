## Agent · 六模块（架构）

- **事实**：Agent 架构六模块：规划（任务拆解）、记忆（短期上下文+长期向量库）、工具（function calling）、执行循环、护栏（安全边界）、可观测（追踪评估）
- **原理**：Agent=LLM+工具+循环（观察-思考-行动），规划与记忆决定复杂任务能力，护栏与可观测决定能否生产化，本项目总结的架构框架
- **常见误区**：
  1. Agent 就是聊天机器人（错）
  2. Agent 无需护栏（错）
  3. 工具越多越好（错）
- **工程用法**：Agent 系统设计主线
- **版本锚点**：实战方法论
