## Java · 会话隔离（并发）

- **事实**：多用户并发会话隔离：上下文（历史/记忆）按 session key 隔离，禁止共享可变状态
- **原理**：串用他人上下文是严重事故（隐私+错误回答），实现：会话存储按 sessionId 分区+并发集合，Java 侧用 ThreadLocal 传 session 上下文（与线程池场景 TTL 知识联动）
- **常见误区**：
  1. 全局单例上下文自动隔离（错）
  2. 并发会话不需要隔离（错）
  3. sessionId 只用于鉴权（错）
- **工程用法**：多用户应用的安全底线
- **版本锚点**：实战共识
