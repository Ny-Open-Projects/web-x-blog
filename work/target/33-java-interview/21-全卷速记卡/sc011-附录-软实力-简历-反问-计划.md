## 附录（软实力/简历/反问/计划）

1. STAR-R：情境-任务-行动-结果-沉淀；每条带数字。
2. P10 语言：为什么做、放弃了什么、团队因此变强在哪里。
3. 技术分歧：翻译成业务风险 → 给选项带代价 → 数据 → 止损点。
4. "I disagree, but I commit"：分歧表达在决策前，承诺给足在决策后。
5. 规范落地：试点出结果 → 接入门禁制造摩擦 → 数据推广；落地率要可度量。
6. P0 事故 IC 头 30 分钟：判级 → 止血（回滚优先）→ 沟通；IC 不修代码、专人记时间线。
7. 一深两宽：一个领域到源码层，两个相邻领域到选型层。
8. 定级 = 对未来承诺的定价：能力到位证据 + 不可替代性 + 业务收益。
9. 反问三连：最大挑战 / 前任怎么失败 / 最近被否的方案。
10. 30/60/90 天：内功 → 中间件 → 场景实战；输出块（口播/手写）绝不能省。
