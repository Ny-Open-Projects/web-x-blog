## 第 10 章 AI：LLM 与 Agent

1. LLM = 概率续写机器：无记忆、会幻觉、上下文为王。
2. Temperature 低温做结构化任务；结构化输出用 JSON Mode/FC，别抠正则。
3. RAG 链路：切分 → Embedding → 向量库 → 混合检索 → 重排 → 生成带引用。
4. RAG 调优第一原则：检索归因 vs 生成归因，分开查。
5. 企业 RAG 三命门：权限过滤、知识时效、评测集。
6. Agent 六模块：规划、记忆、工具（MCP）、编排、护栏、可观测。
7. 上下文管理 = 成本与效果核心：滑动窗口 + 摘要压缩 + 结构化提取。
8. 成本四刀：降单价（路由/私有化）、降 token、降次数（语义缓存）、预算熔断。
9. 模型网关 = AI 时代的 API 网关：路由/缓存/配额/审计/降级。
10. AI 输出必须有三出口：可用、人审、拒绝；高风险操作永远 human-in-the-loop。
11. Prompt 注入 = 新 SQL 注入：防线在系统层（最小权限/沙箱/审计），prompt 规则只是概率性的。
12. 多模态解析成本账：分层解析（轻 OCR→命中再深解析）+ 结果缓存。
13. Agent 可恢复四件套：checkpoint、幂等工具、续跑策略、预算熔断。
14. 评测集是 AI 团队最值钱的资产；LLM-as-judge 要双评交换顺序 + 人工校准。
