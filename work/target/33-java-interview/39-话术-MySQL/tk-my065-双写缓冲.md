## 存储 · 双写缓冲（doublewrite）—— 7 类问法与标准话术

**Qmysql-449（概念考察·P1-P3）**
【面试官】请谈谈你对「存储」中「双写缓冲」的理解。
【标准回答话术】doublewrite buffer 防止"部分页写失效"（页 16KB 而磁盘 IO 原子单位更小）。背后的原理是：写数据页先写 doublewrite 再落盘，崩溃时用它恢复完整页，是 InnoDB 数据可靠性的隐性防线。
【评分点】① 准确说出核心机制（双写缓冲）；② 能带出原理层而非背结论。 ③ 版本锚点：InnoDB 文档
