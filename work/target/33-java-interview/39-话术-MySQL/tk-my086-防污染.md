## InnoDB · 防污染（LRU）—— 7 类问法与标准话术

**Qmysql-596（概念考察·P1-P3）**
【面试官】请谈谈你对「InnoDB」中「防污染」的理解。
【标准回答话术】InnoDB LRU 改进：新页先进 old 区（5/8 处）停留 innodb_old_blocks_time 后才进 young 区。背后的原理是：全表扫描的页只污染 old 区不挤掉热点页，这是与教科书 LRU 的关键差异，防止一次性扫描冲垮缓存。
【评分点】① 准确说出核心机制（防污染）；② 能带出原理层而非背结论。 ③ 版本锚点：InnoDB 文档
