## 实践 · 唯一键（幂等）—— 7 类问法与标准话术

**Qmysql-694（概念考察·P1-P3）**
【面试官】请谈谈你对「实践」中「唯一键」的理解。
【标准回答话术】幂等落地：业务唯一键（订单号）+插入冲突处理（on duplicate/捕获重复异常）。背后的原理是：唯一键是幂等最后防线（消息重投、请求重试），配合 upsert 或 insert ignore 语义明确，业务键设计决定幂等粒度。
【评分点】① 准确说出核心机制（唯一键）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
