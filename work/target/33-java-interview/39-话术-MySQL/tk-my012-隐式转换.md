## 索引 · 隐式转换（失效）—— 7 类问法与标准话术

**Qmysql-78（概念考察·P1-P3）**
【面试官】请谈谈你对「索引」中「隐式转换」的理解。
【标准回答话术】字符串列与数字比较发生隐式转换使索引失效。背后的原理是：MySQL 把字符串转数字比较（相当于对列套 cast 函数），手机号 varchar 列 where phone=13800138000 失效，参数必须传字符串。
【评分点】① 准确说出核心机制（隐式转换）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
