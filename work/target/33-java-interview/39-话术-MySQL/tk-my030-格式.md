## 日志 · 格式（binlog）—— 7 类问法与标准话术

**Qmysql-204（概念考察·P1-P3）**
【面试官】请谈谈你对「日志」中「格式」的理解。
【标准回答话术】binlog 是 Server 层逻辑日志默认 ROW 格式（8.0 默认 ROW，官方文档核对零差异）。背后的原理是：ROW 记录行级变更（主从最安全）、STATEMENT 记 SQL（体积小但 now()/uuid() 不安全）、MIXED 自动切换。
【评分点】① 准确说出核心机制（格式）；② 能带出原理层而非背结论。 ③ 版本锚点：MySQL 8.0 官方文档
