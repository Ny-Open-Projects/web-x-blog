## 存储 · 页分裂（页）—— 7 类问法与标准话术

**Qmysql-113（概念考察·P1-P3）**
【面试官】请谈谈你对「存储」中「页分裂」的理解。
【标准回答话术】InnoDB 以 16KB 页为管理单位插入满页时分裂（数据有序时顺序写入免分裂）。背后的原理是：自增插入永远追加到最右页免分裂，随机插入命中率低且分裂频繁，碎片需要 OPTIMIZE TABLE 重建。
【评分点】① 准确说出核心机制（页分裂）；② 能带出原理层而非背结论。 ③ 版本锚点：InnoDB 文档
