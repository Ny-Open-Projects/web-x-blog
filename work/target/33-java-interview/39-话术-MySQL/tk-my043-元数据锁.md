## 锁 · 元数据锁（MDL）—— 7 类问法与标准话术

**Qmysql-295（概念考察·P1-P3）**
【面试官】请谈谈你对「锁」中「元数据锁」的理解。
【标准回答话术】MDL 元数据锁保护表结构：查询持 MDL 读锁 DDL 需 MDL 写锁。背后的原理是：长事务/慢查询持 MDL 读锁时 DDL 阻塞，且后续所有查询排在 DDL 之后（表完全不可用），online DDL 与运维操作必须避开高峰。
【评分点】① 准确说出核心机制（元数据锁）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
