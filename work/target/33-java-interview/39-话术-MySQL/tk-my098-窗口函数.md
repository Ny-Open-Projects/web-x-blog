## SQL · 窗口函数（窗口）—— 7 类问法与标准话术

**Qmysql-680（概念考察·P1-P3）**
【面试官】请谈谈你对「SQL」中「窗口函数」的理解。
【标准回答话术】窗口函数 over(partition by ... order by ...) 做分组内排名/累计/同比不减少行数。背后的原理是：与 group by 的区别（不聚合行数），row_number/rank/dense_rank 排名差异（并列处理），lag/lead 取前后行。
【评分点】① 准确说出核心机制（窗口函数）；② 能带出原理层而非背结论。 ③ 版本锚点：MySQL 8.0
