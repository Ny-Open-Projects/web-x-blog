## 锁 · 全表锁（隐患）—— 7 类问法与标准话术

**Qmysql-330（概念考察·P6-P8）**
【面试官】请谈谈你对「锁」中「全表锁」的理解。
【标准回答话术】update where 条件未走索引时逐行加锁接近锁全表。背后的原理是：server 层按扫描路径加锁，全表扫描则所有行（含间隙）加 Next-Key，索引设计不当的 update 是生产事故源。
【评分点】① 准确说出核心机制（全表锁）；② 能带出原理层而非背结论。 ③ 版本锚点：实战教训
