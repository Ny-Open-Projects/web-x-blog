## SQL · select *（优化）—— 7 类问法与标准话术

**Qmysql-176（概念考察·P6-P8）**
【面试官】请谈谈你对「SQL」中「select *」的理解。
【标准回答话术】select * 的危害：无法覆盖索引、传输无效列、buffer pool 污染。背后的原理是：按需 select 列表配合覆盖索引，宽表大字段（TEXT/BLOB）必须拆分按需读。
【评分点】① 准确说出核心机制（select *）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
