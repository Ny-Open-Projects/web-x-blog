## 实践 · 冷热（归档）—— 7 类问法与标准话术

**Qmysql-743（概念考察·P1-P3）**
【面试官】请谈谈你对「实践」中「冷热」的理解。
【标准回答话术】冷热分离：热数据（近 N 月）在线库，冷数据归档库（压缩表/对象存储），查询路由按时间。背后的原理是：在线库保持小容量（索引高效），归档按 partition drop 秒级清理，归档库查询走专门服务。
【评分点】① 准确说出核心机制（冷热）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
