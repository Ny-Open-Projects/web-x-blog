## 索引 · 顺序（设计）—— 7 类问法与标准话术

**Qmysql-43（概念考察·P1-P3）**
【面试官】请谈谈你对「索引」中「顺序」的理解。
【标准回答话术】联合索引列顺序：等值条件列在前、排序列随后、范围列最后。背后的原理是：等值确定后排序才连续（免 filesort），范围列之后的列不再有序，与 MongoDB ESR 同构。
【评分点】① 准确说出核心机制（顺序）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
