## SQL · 深分页（分页）—— 7 类问法与标准话术

**Qmysql-148（概念考察·P1-P3）**
【面试官】请谈谈你对「SQL」中「深分页」的理解。
【标准回答话术】深分页 limit 100000,10 需扫描前 100010 行再丢弃。背后的原理是：优化：游标方式 where id>last_id limit 10（连续翻页）或延迟关联（先查 id 再回表），ES 与业务层配合规避深翻页。
【评分点】① 准确说出核心机制（深分页）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
