## 分库分表 · 翻倍（扩容）—— 7 类问法与标准话术

**Qmysql-414（概念考察·P1-P3）**
【面试官】请谈谈你对「分库分表」中「翻倍」的理解。
【标准回答话术】扩容方案：翻倍扩容（成倍迁移路由简单）或一致性哈希（数据迁移少）。背后的原理是：翻倍扩容按位翻番，旧分片数据一半迁新片，停写窗口小；一致性哈希只迁移 1/n 数据但节点波动影响大。
【评分点】① 准确说出核心机制（翻倍）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
