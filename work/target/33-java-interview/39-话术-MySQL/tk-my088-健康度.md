## 运维 · 健康度（监控）—— 7 类问法与标准话术

**Qmysql-610（概念考察·P1-P3）**
【面试官】请谈谈你对「运维」中「健康度」的理解。
【标准回答话术】MySQL 健康监控：QPS/TPS、慢查询数、主从延迟、连接数、buffer pool 命中率、锁等待。背后的原理是：Prometheus+mysqld_exporter 标准化采集，核心告警：延迟超阈值、连接拒绝、磁盘水位，健康大盘是稳定性基础。
【评分点】① 准确说出核心机制（健康度）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
