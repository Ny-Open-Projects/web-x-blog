## SQL · 小表驱动（join）—— 7 类问法与标准话术

**Qmysql-162（概念考察·P1-P3）**
【面试官】请谈谈你对「SQL」中「小表驱动」的理解。
【标准回答话术】join 优化核心是小表驱动大表。背后的原理是：驱动表行数决定外层循环次数，straight_join 强制指定驱动顺序，"小表"指过滤后行数少而非物理小。
【评分点】① 准确说出核心机制（小表驱动）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
