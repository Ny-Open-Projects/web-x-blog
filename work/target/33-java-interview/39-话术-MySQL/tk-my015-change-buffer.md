## 索引 · change buffer（change buffer）—— 7 类问法与标准话术

**Qmysql-99（概念考察·P1-P3）**
【面试官】请谈谈你对「索引」中「change buffer」的理解。
【标准回答话术】唯一索引不能使用 change buffer 而普通二级索引可以。背后的原理是：change buffer 把非唯一二级索引的写缓存起来合并减少随机读页，唯一索引必须立即判重无法缓存，写多读少场景普通索引更优。
【评分点】① 准确说出核心机制（change buffer）；② 能带出原理层而非背结论。 ③ 版本锚点：InnoDB 文档
