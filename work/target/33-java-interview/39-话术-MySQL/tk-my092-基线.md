## 运维 · 基线（压测）—— 7 类问法与标准话术

**Qmysql-638（概念考察·P1-P3）**
【面试官】请谈谈你对「运维」中「基线」的理解。
【标准回答话术】数据库压测基线：sysbench 按模型压出单机极限（TPS/QPS/延迟 P99），容量规划与降级阈值依据。背后的原理是：线上流量不超基线的 60-70% 留冗余，压测报告随架构变更更新，全链路压测（染色+影子库）验证真实流量。
【评分点】① 准确说出核心机制（基线）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
