## 架构 · Server 层（分层）—— 7 类问法与标准话术

**Qmysql-575（概念考察·P1-P3）**
【面试官】请谈谈你对「架构」中「Server 层」的理解。
【标准回答话术】MySQL 架构分层：Server 层（连接器/分析器/优化器/执行器）+ 存储引擎层（InnoDB）。背后的原理是：连接器管连接与权限、分析器词法语法、优化器选索引与 join 顺序、执行器调引擎接口，缓存（query cache）8.0 已移除。
【评分点】① 准确说出核心机制（Server 层）；② 能带出原理层而非背结论。 ③ 版本锚点：MySQL 8.0
