## 索引 · 函数（失效）—— 7 类问法与标准话术

**Qmysql-71（概念考察·P1-P3）**
【面试官】请谈谈你对「索引」中「函数」的理解。
【标准回答话术】索引列上使用函数或运算会失效（8.0 函数索引除外）。背后的原理是：B+ 树按原始值有序，函数变换后无法利用排序，改写为对常量做运算或建函数索引（8.0.13+）。
【评分点】① 准确说出核心机制（函数）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
