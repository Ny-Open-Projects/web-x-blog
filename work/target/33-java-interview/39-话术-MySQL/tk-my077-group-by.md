## SQL · group by（分组）—— 7 类问法与标准话术

**Qmysql-533（概念考察·P1-P3）**
【面试官】请谈谈你对「SQL」中「group by」的理解。
【标准回答话术】group by 无索引时走临时表+排序（8.0 默认不排序了），group by 结果需要 order by 显式声明。背后的原理是：8.0 起 group by 不再隐式排序（5.7 隐式按分组列排序），依赖旧行为的 SQL 升级后出 Bug。
【评分点】① 准确说出核心机制（group by）；② 能带出原理层而非背结论。 ③ 版本锚点：MySQL 8.0
