## SQL · 流程（优化）—— 7 类问法与标准话术

**Qmysql-491（概念考察·P6-P8）**
【面试官】请谈谈你对「SQL」中「流程」的理解。
【标准回答话术】SQL 优化流程：慢日志定位→explain（analyze）分析→索引优化或 SQL 改写→回归验证。背后的原理是：先看 type/rows/Extra 三要素，改索引最常见，改写（join 顺序、子查询转 join）其次，最后才是参数与架构。
【评分点】① 准确说出核心机制（流程）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
