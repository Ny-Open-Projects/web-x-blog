## 字符集 · utf8mb4（utf8mb4）—— 7 类问法与标准话术

**Qmysql-505（概念考察·P1-P3）**
【面试官】请谈谈你对「字符集」中「utf8mb4」的理解。
【标准回答话术】MySQL 的 utf8 是不完整实现（最多 3 字节），存 emoji 必须 utf8mb4。背后的原理是：utf8mb4 是真 UTF-8（4 字节），建表默认 utf8mb4+utf8mb4_0900_ai_ci（8.0 默认排序规则），老库迁移要评估索引长度变化。
【评分点】① 准确说出核心机制（utf8mb4）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
