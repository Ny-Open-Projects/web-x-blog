## 主键 · 自增主键（设计）—— 7 类问法与标准话术

**Qmysql-106（概念考察·P1-P3）**
【面试官】请谈谈你对「主键」中「自增主键」的理解。
【标准回答话术】InnoDB 主键推荐自增或趋势递增值（UUID 随机导致页分裂）。背后的原理是：随机主键使插入落点分散引发页分裂与碎片、buffer pool 命中率下降，雪花 ID 趋势递增兼得分布式唯一与写入友好。
【评分点】① 准确说出核心机制（自增主键）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
