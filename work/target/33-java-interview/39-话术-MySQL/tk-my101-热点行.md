## 实践 · 热点行（热点）—— 7 类问法与标准话术

**Qmysql-701（概念考察·P1-P3）**
【面试官】请谈谈你对「实践」中「热点行」的理解。
【标准回答话术】热点行更新优化：内存队列合并（单线程串行扣减）、库存分段（拆多行）、Redis 预扣。背后的原理是：秒杀热点行死锁检测与锁竞争是瓶颈，分段库存把 1 行拆 N 行随机路由，Redis 预扣减 DB 兜底，是电商库存三段式方案。
【评分点】① 准确说出核心机制（热点行）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
