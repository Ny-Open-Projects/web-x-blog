## SQL · NLJ（join）—— 7 类问法与标准话术

**Qmysql-155（概念考察·P1-P3）**
【面试官】请谈谈你对「SQL」中「NLJ」的理解。
【标准回答话术】join 实现：Nested-Loop Join 逐行驱动被驱动表（有索引走 Index NLJ）。背后的原理是：驱动表每行到被驱动表查一次（走索引则很快），无可用索引时 Block NLJ 用 join buffer 缓存驱动表批量匹配，8.0.18 起无索引等值 join 可用 Hash Join。
【评分点】① 准确说出核心机制（NLJ）；② 能带出原理层而非背结论。 ③ 版本锚点：MySQL 8.0.18
