## 运维 · 压缩（压缩）

- **事实**：消息压缩（lz4/zstd/gzip）网络与磁盘双降，生产端压缩 broker 原样存
- **原理**：zstd 压缩比与速度均衡（Kafka 2.1+），批量大消息压缩收益大（批量本身就是压缩前提），消费端解压 CPU 代价
- **常见误区**：
  1. 压缩只省网络（错）
  2. 压缩无 CPU 代价（错）
  3. 单条消息压缩效果好（批量才有效）（错）
- **工程用法**：性能优化配置
- **版本锚点**：实战共识
