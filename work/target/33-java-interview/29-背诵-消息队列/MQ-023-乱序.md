## 语义 · 乱序（乱序）

- **事实**：乱序处理：按 key 分区路由保序+消费端单线程/串行队列
- **原理**：跨分区无法保序，消费端并发处理同 key 需按 key 分发到串行队列（内存排队），P10 级别能说出"保序的完整链路"（生产路由+分区+消费串行）
- **常见误区**：
  1. MQ 自动全局保序（错）
  2. 消费端多线程不影响顺序（错）
  3. 分区键任意选（错）
- **工程用法**：顺序链路设计
- **版本锚点**：实战方法论
