## 性能 · 页缓存（页缓存）

- **事实**：Kafka 依赖 OS 页缓存而非 JVM 堆缓存消息
- **原理**：消息文件 mmap/顺序读写经页缓存，JVM 堆小 GC 轻（Kafka 堆通常 6GB 内），重启后页缓存仍有效
- **常见误区**：
  1. Kafka 用 JVM 堆缓存消息（错）
  2. 页缓存冷启动无效（错）
  3. 堆越大越好（错）
- **工程用法**：JVM 调参与存储联动知识
- **版本锚点**：官方文档
