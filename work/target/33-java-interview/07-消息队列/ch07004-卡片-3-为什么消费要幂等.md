### 卡片 3：为什么消费要幂等？
网络抖动/重平衡/超时都会导致重复投递，这不是可以消灭的异常，而是常态。幂等四法：
1. **唯一键约束**：消息 ID 落库 unique index（最硬）；
2. **状态机**：订单状态只能单向流转，重复消息更新无效；
3. **版本号/乐观锁**：更新带 version 条件；
4. **Redis setnx 去重表**（弱，Redis 丢失会重，需 DB 兜底）。
