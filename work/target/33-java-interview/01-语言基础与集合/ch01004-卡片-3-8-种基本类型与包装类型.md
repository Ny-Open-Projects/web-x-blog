### 卡片 3：8 种基本类型与包装类型
| 类型 | 字节 | 范围/备注 | 包装类 |
|------|------|-----------|--------|
| byte | 1 | -128~127 | Byte |
| short | 2 | | Short |
| int | 4 | 约 ±21 亿 | Integer |
| long | 8 | | Long |
| float | 4 | 单精度 | Float |
| double | 8 | 双精度 | Double |
| char | 2 | Unicode | Character |
| boolean | — | JVM 规范未定大小，通常按 1 byte 或 int 处理 | Boolean |

为什么要包装类？**泛型不支持基本类型**（List<int> 非法），且包装类提供了
MAX_VALUE、parseInt 等工具与 null 语义（数据库字段可空）。
