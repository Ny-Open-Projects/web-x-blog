### 卡片 7：栈、堆、方法区（先记结论，第 3 章展开）
- 局部变量、方法调用 → **栈**（线程私有，栈溢出 StackOverflowError）。
- new 出来的对象 → **堆**（线程共享，GC 主战场，OOM）。
- 类信息、常量、静态变量 → **元空间/方法区**（JDK8 起字符串常量池已从方法区挪到堆）。
