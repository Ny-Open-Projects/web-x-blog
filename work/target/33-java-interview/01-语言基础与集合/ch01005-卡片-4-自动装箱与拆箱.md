### 卡片 4：自动装箱与拆箱
- `Integer a = 127;` 自动装箱 = 编译器插入 `Integer.valueOf(127)`。
- `int b = a;` 自动拆箱 = `a.intValue()`。
- **必背坑点**：Integer 缓存 -128~127。`Integer a=127, b=127; a==b` 为 true；
  `Integer c=128, d=128; c==d` 为 false（128 超出缓存，new 了新对象）。
  阿里规约禁止用 == 比较包装类，必须用 equals。
