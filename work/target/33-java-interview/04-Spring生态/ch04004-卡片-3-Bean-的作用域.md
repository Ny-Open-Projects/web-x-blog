### 卡片 3：Bean 的作用域
singleton（默认，容器内唯一）/ prototype（每次新建）/ request / session / websocket。
**坑**：singleton 注入 prototype 时 prototype 也会变单例——要用 @Lookup、ObjectFactory 或 scoped proxy。
