## DP · DP（入门）—— 7 类问法与标准话术

**Qalgorithm-176（概念考察·P1-P3）**
【面试官】请谈谈你对「DP」中「DP」的理解。
【标准回答话术】动态规划：状态定义+转移方程+初始化+遍历顺序四要素，重叠子问题+最优子结构两前提。背后的原理是：自顶向下（记忆化递归）与自底向上（填表）等价，空间优化（滚动数组）常见，背包/LCS/编辑距离三经典，与回溯对比（DP 记子问题）。
【评分点】① 准确说出核心机制（DP）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识
