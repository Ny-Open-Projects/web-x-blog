## 链表 · 反转（技巧）—— 7 类问法与标准话术

**Qalgorithm-50（概念考察·P1-P3）**
【面试官】请谈谈你对「链表」中「反转」的理解。
【标准回答话术】链表反转：迭代三指针（prev/cur/next）O(N) O(1)，递归版 O(N) 栈空间。背后的原理是：迭代逐节点改 next 指向，递归到尾再回改，K 组反转是组合题，手写必须零 bug（笔试常考）。
【评分点】① 准确说出核心机制（反转）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识
