**Qalgorithm-204（概念考察·P1-P3）**
【面试官】请谈谈你对「回溯」中「回溯」的理解。
【标准回答话术】回溯：选择→递归→撤销（三段模板），组合/排列/子集三模板，剪枝优化。背后的原理是：排列用 used 数组、组合用 startIndex 防重复、去重排序+跳过同层相同，复杂度指数级（剪枝是关键），与全排列/N 皇后。
【评分点】① 准确说出核心机制（回溯）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识
