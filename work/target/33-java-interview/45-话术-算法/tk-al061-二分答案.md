## 二分 · 二分答案（变形）—— 7 类问法与标准话术

**Qalgorithm-421（概念考察·P1-P3）**
【面试官】请谈谈你对「二分」中「二分答案」的理解。
【标准回答话术】二分答案：在答案区间上二分并验证可行性（最大化最小值/最小化最大值）。背后的原理是：将"求最优值"转化为"判定可行"再二分边界，check 函数 O(N)，总复杂度 O(N logV)。
【评分点】① 准确说出核心机制（二分答案）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识
