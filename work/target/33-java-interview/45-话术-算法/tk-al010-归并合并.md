## 链表 · 归并合并（合并）—— 7 类问法与标准话术

**Qalgorithm-64（概念考察·P1-P3）**
【面试官】请谈谈你对「链表」中「归并合并」的理解。
【标准回答话术】合并两个有序链表：哑结点（dummy）统一头处理，O(N+M)。背后的原理是：哑结点消除头节点特判（空链表场景），递归版简洁但栈深，K 链表合并用小顶堆 O(N logK)。
【评分点】① 准确说出核心机制（归并合并）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识
