## DP · LCS（经典）—— 7 类问法与标准话术

**Qalgorithm-190（概念考察·P1-P3）**
【面试官】请谈谈你对「DP」中「LCS」的理解。
【标准回答话术】最长公共子序列（LCS）：dp[i][j] 依赖左/上/左上，编辑距离是其变形（增删改代价）。背后的原理是：字符串相似度/版本 diff 的算法基础，空间优化两行滚动，输出具体序列需回溯路径，与 Git diff 思想关联。
【评分点】① 准确说出核心机制（LCS）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识
