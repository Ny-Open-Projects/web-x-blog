## 复杂度 · 大 O（分析）—— 7 类问法与标准话术

**Qalgorithm-1（概念考察·P1-P3）**
【面试官】请谈谈你对「复杂度」中「大 O」的理解。
【标准回答话术】大 O 表示增长趋势：O(1)<O(logN)<O(N)<O(NlogN)<O(N²)<O(2^N)。背后的原理是：只保留最高阶项与常数忽略，O(NlogN) 与 O(N) 在 N 小时差距不明显（常数项主导），面试先给复杂度再给推导。
【评分点】① 准确说出核心机制（大 O）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识

**Qalgorithm-2（误用纠错·P4-P7）**
【面试官】我在别的团队见过这样的说法：「大 O 是精确执行次数」。你觉得对吗？
【标准回答话术】这个说法不正确。准确的表述是：大 O 表示增长趋势：O(1)<O(logN)<O(N)<O(NlogN)<O(N²)<O(2^N)。原因是：只保留最高阶项与常数忽略，O(NlogN) 与 O(N) 在 N 小时差距不明显（常数项主导），面试先给复杂度再给推导。
【评分点】① 快速识别误区不顺着说；② 给出正确的版本锚定表述（理论共识）。
