## 数组 · 前缀和（技巧）—— 7 类问法与标准话术

**Qalgorithm-29（概念考察·P1-P3）**
【面试官】请谈谈你对「数组」中「前缀和」的理解。
【标准回答话术】前缀和：预处理 prefix[i]=Σ(0..i-1)，区间和 O(1) 查询。背后的原理是：建表 O(N) 换查询 O(1)，二维前缀和扩展（子矩阵和），差分数组是其逆操作（区间批量加），高频统计类题套路。
【评分点】① 准确说出核心机制（前缀和）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识
