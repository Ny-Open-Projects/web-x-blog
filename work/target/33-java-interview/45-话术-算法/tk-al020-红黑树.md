## 树 · 红黑树（红黑）—— 7 类问法与标准话术

**Qalgorithm-134（概念考察·P1-P3）**
【面试官】请谈谈你对「树」中「红黑树」的理解。
【标准回答话术】红黑树：近似平衡 BST（红黑性质），插入/删除/查找 O(logN)，旋转维护平衡。背后的原理是：相比 AVL：平衡宽松（旋转少）适合频繁增删，Java TreeMap/HashMap 树化（JB 体系）与 Linux CFS 应用，B+ 树是磁盘场景进化。
【评分点】① 准确说出核心机制（红黑树）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识
