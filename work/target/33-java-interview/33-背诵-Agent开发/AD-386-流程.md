## 治理 · 流程（权限）

- **事实**：权限变更流程实现：权限矩阵（AD-348）变更走工单（申请/审批/生效/审计 AD-684），紧急提权走临时授权（AD-179 带过期）
- **原理**：权限变更的流程实现（变更即审计 AD-382），紧急通道与常规通道并存，与权限治理（AD-233）联动
- **常见误区**：
  1. 权限变更直接改配置（错）
  2. 流程实现不必要（错）
  3. 紧急通道无审计（错）
- **工程用法**：权限变更流程
- **版本锚点**：实战共识
