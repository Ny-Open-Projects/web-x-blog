## 评测 · 判定（轨迹）

- **事实**：轨迹评测自动判定：规则判定（步数/禁用工具/超预算）+LLM 判定（步骤合理性），规则先行 LLM 补充
- **原理**：轨迹判定自动化（JA-375 执行件），规则判定确定性强零成本，LLM 判定补"合理性"这种软维度，与判分（JA-651）联动
- **常见误区**：
  1. 轨迹判定全人工（错）
  2. LLM 判定优先于规则（错）
  3. 规则判定是过度设计（错）
- **工程用法**：轨迹判定设计
- **版本锚点**：实战共识
