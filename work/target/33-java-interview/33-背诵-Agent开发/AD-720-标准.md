## 工程 · 标准（观测）

- **事实**：Agent 可观测标准：trace（OTel GenAI 约定 JA-583）/metrics（JA-462）/logs（AD-106 分级）三支柱的标准化，观测标准让 Agent 可运维
- **原理**：观测标准的标准化（OTel GenAI 的 Agent 落地 JA-083），三支柱统一（JA-256 串联），与观测标准联动
- **常见误区**：
  1. Agent 观测无标准（错）
  2. 三支柱冗余（错）
  3. 标准化不必要（错）
- **工程用法**：观测标准
- **版本锚点**：实战共识
