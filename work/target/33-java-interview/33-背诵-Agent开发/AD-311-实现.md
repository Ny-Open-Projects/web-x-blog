## 手写 · 实现（工厂）

- **事实**：Agent 工厂实现：按配置（AD-198 配置类）创建 Agent 实例（组装 ModelClient/Registry/Executor），工厂让配置到实例的装配集中
- **原理**：工厂模式集中装配逻辑（装配点单一可测试），不同配置产生不同能力 Agent（AD-060 分场景），与工厂模式联动
- **常见误区**：
  1. Agent 实例直接散落 new（错）
  2. 工厂是过度设计（错）
  3. 装配逻辑可以分散（错）
- **工程用法**：工厂实现
- **版本锚点**：实战共识
