## 多模态 · 工具（手写）

- **事实**：图像理解工具手写：输入（图像 URL/base64+问题）→视觉模型调用→结构化结果返回，作为 Agent 工具注册（AD-153 视觉工具的手写面）
- **原理**：视觉工具的手写与文本工具同构（输入输出 schema 化 JA-109），注册进 Agent 即获得视觉能力，与视觉 prompt（JA-542）联动
- **常见误区**：
  1. 图像工具无法手写（错）
  2. 输入不需要 schema（错）
  3. 结果非结构化（错）
- **工程用法**：图像工具实现
- **版本锚点**：实战共识
