## 多模态 · 视觉（schema）

- **事实**：视觉工具 schema：输入 schema 含图像引用与问题字段，输出 schema 按任务（表格/描述/判断），schema 决定视觉工具可组合性
- **原理**：视觉工具的 schema 设计（AD-052 纪律的视觉面），输出结构化（JA-003 思想）供 Agent 决策，与视觉 prompt（JA-542）联动
- **常见误区**：
  1. 视觉工具无 schema（错）
  2. 输出自由文本最优（错）
  3. schema 与视觉无关（错）
- **工程用法**：视觉工具 schema
- **版本锚点**：实战共识
