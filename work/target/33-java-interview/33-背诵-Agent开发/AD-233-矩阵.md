## 治理 · 矩阵（权限）

- **事实**：Agent 权限矩阵集中管理：全部 Agent 的工具权限矩阵（行=Agent 列=工具），集中评审与变更审计
- **原理**：权限分散在各 Agent 配置=治理盲区（组合风险 JA-081 的全局面），矩阵让"谁能做什么"一目了然，与权限治理（JA-233 同思想）联动
- **常见误区**：
  1. 权限分散管理足够（错）
  2. 矩阵是过度设计（错）
  3. 集中与分散无区别（错）
- **工程用法**：权限矩阵治理
- **版本锚点**：实战共识
