## 协作 · 管理（演化）

- **事实**：Agent 群体演化管理：新增 Agent（评审 AD-381）/下线 Agent（AD-232）/能力升级（AD-218）的群体级管理，演化影响协作拓扑
- **原理**：群体演化是系统级管理（新增/下线改变协作拓扑），演化评审（影响面分析），与治理（AD-159）联动
- **常见误区**：
  1. Agent 群体静态不变（错）
  2. 演化管理不必要（错）
  3. 拓扑变化无影响（错）
- **工程用法**：群体演化管理
- **版本锚点**：实战共识
