## 评测 · 构建（任务集）

- **事实**：Agent 任务集构建 SOP：真实任务采样（JA-495 挖掘）+边界任务构造（JA-470 拒绝）+对抗任务（JA-734 诱导），三层的构建流程与配比（真实为主边界对抗为辅）
- **原理**：JA-090 三层任务集的执行流程：采样清洗→分层标注→评审入库，任务集是 Agent 评测的根基资产，与评估即代码（JA-665）联动
- **常见误区**：
  1. 任务集随机构造（错）
  2. 三层配比随意（错）
  3. 构建不需要流程（错）
- **工程用法**：任务集构建 SOP
- **版本锚点**：实战共识
