## 工程 · 依赖（漂移）

- **事实**：依赖版本漂移检测：框架/SDK 版本 vs 声明版本（BOM 对齐检查 JA-105），依赖升级未走流程检测（CI 检查 pom 一致性）
- **原理**：依赖漂移的检测（JA-565 SDK 治理的自动化），CI 检查依赖一致性，与依赖治理联动
- **常见误区**：
  1. 依赖漂移不存在（错）
  2. 检查不必要（错）
  3. 漂移无风险（错）
- **工程用法**：依赖漂移检测
- **版本锚点**：实战共识
