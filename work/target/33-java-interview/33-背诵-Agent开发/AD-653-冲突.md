## 协作 · 冲突（合并）

- **事实**：多 Agent 输出合并冲突：多 Agent 对同一任务产出不同结论的合并（投票/加权/裁决 AD-132），合并冲突的解决策略
- **原理**：输出合并冲突与记忆冲突（AD-074）同构：裁决策略配置化，合并质量评测（JA-375 轨迹面），与聚合（AD-132）联动
- **常见误区**：
  1. 合并就是拼接（错）
  2. 冲突不需要策略（错）
  3. 拼接总是可行（错）
- **工程用法**：合并冲突解决
- **版本锚点**：实战共识
