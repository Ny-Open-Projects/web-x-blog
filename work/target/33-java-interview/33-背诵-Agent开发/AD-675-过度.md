## 安全 · 过度（自主）

- **事实**：Agent 过度自主风险：自主决策链过长（无人审点）的不可控性，风险=累积错误+不可追溯，防线=关键点人审（AD-046）+步数上限（AD-017）
- **原理**：过度自主的风险设计（自主性与可控性 JA-018 的深水区），人审点的自动规划（按动作风险分级），与自主性权衡联动
- **常见误区**：
  1. Agent 越自主越好（错）
  2. 自主链无风险（错）
  3. 人审点自动规划不存在（错）
- **工程用法**：过度自主防线
- **版本锚点**：实战共识
