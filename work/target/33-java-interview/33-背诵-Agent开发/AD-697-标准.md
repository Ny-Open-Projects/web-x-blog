## 记忆 · 标准（接口）

- **事实**：记忆标准接口：行业记忆接口趋势（Mem0/LangChain Memory 抽象趋同），标准接口让记忆可插拔（JA-689 服务化的接口面）
- **原理**：记忆接口的标准化趋势（JA-290/689 的生态面），标准接口让存储可换（AD-474 迁移），与生态知识联动
- **常见误区**：
  1. 记忆接口无标准趋势（错）
  2. 标准化不必要（错）
  3. 接口各写各的（错）
- **工程用法**：记忆接口趋势
- **版本锚点**：实战共识
