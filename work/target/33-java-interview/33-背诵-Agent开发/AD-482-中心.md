## 工具 · 中心（注册）

- **事实**：工具注册中心：工具的注册/发现/版本/健康集中管理（工具的"注册中心"），与微服务注册中心同思想
- **原理**：注册中心让工具治理集中（分散配置的治理盲区），与 AD-051 注册表的区别（注册表是运行时、中心是治理），与治理联动
- **常见误区**：
  1. 工具注册分散即可（错）
  2. 注册中心是过度设计（错）
  3. 集中与分散无区别（错）
- **工程用法**：工具注册中心
- **版本锚点**：实战共识
