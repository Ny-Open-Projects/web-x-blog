## 循环 · 双上限（防线）

- **事实**：Agent 双上限防线：步数上限（防循环）+token 预算（防成本），双触发任一即强制收尾
- **原理**：两个维度防两类失控（JA-276/500），强制收尾是优雅输出（非报错），防线参数按任务类型分档
- **常见误区**：
  1. 单上限足够（错）
  2. 触发上限直接报错（错）
  3. 上限不分任务类型（错）
- **工程用法**：双防线设计
- **版本锚点**：实战共识
