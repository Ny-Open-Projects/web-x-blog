## 手写 · 组合（终止）

- **事实**：终止条件组合器实现：多条件（完成/步数/预算/取消）的组合判断（任一触发），条件可扩展注册（新终止条件插入）
- **原理**：终止条件的组合器模式（条件策略化），扩展性让新终止条件（如时间窗）可插入，与策略模式联动
- **常见误区**：
  1. 终止条件硬编码 if（错）
  2. 组合器是过度设计（错）
  3. 条件不可扩展（错）
- **工程用法**：终止组合器
- **版本锚点**：实战共识
