## 手写 · 实现（流式）

- **事实**：Agent 流式实现：模型 stream 调用（Flux）+事件转换（token 事件/工具事件）→下游，流式版循环的复杂点（流中工具调用要暂停收集）
- **原理**：流式 Agent 的手写难点（流与循环交织 JA-073），事件协议（AD-146）承载，流式与工具循环的组合是框架级难点
- **常见误区**：
  1. 流式与工具不能组合（错）
  2. 流式实现与同步相同（错）
  3. Flux 直接返回即可（错）
- **工程用法**：流式手写
- **版本锚点**：实战共识
