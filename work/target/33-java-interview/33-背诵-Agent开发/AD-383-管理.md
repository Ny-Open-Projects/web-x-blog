## 治理 · 管理（元数据）

- **事实**：Agent 版本元数据管理：版本号/宪法 hash/工具集 hash/模型配置/评测基线（AD-059 三元组的元数据化），元数据查询 API
- **原理**：版本元数据的管理实现（三元组的可查性），hash 绑定让“行为指纹”可验证（配置漂移 JA-455 检测），与版本治理联动
- **常见误区**：
  1. 元数据不需要（错）
  2. hash 绑定可选（错）
  3. 元数据无查询（错）
- **工程用法**：元数据管理
- **版本锚点**：实战共识
