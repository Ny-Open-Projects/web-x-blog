## 案例 · Agent（法务）

- **事实**：法务合同审查 Agent：条款抽取（版面分析 JA-545）→条款库比对（RAG）→风险标注→差异报告（人签发），术语库锚定（JA-552）
- **原理**：法务场景的引用零容忍（JA-555），Agent 产出是"风险标注报告"（草稿），律师签发，与责任链（JA-478）联动
- **常见误区**：
  1. 合同审查全自动出结论（错）
  2. 条款引用可编造（错）
  3. 无需术语库（错）
