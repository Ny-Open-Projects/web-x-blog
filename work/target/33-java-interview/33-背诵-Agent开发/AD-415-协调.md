## 协作 · 协调（发布）

- **事实**：多 Agent 发布协调：子 Agent 版本升级需检查父 Agent 兼容（工具契约/消息协议），协调发布（依赖对齐）
- **原理**：发布协调防"子升级父不兼容"（JA-415 变更矩阵的多 Agent 面），协调工具（依赖图 AD-214 支撑），与发布管理联动
- **常见误区**：
  1. 子 Agent 独立发布无协调（错）
  2. 兼容检查不必要（错）
  3. 协调拖慢发布（错）
- **工程用法**：发布协调
- **版本锚点**：实战共识
