## 评测 · 格式（导出）

- **事实**：轨迹导出为评测格式：轨迹 JSON Lines（AD-246）转评测条目（任务/轨迹/结果三元组），导出即评测集扩产（JA-162 通道）
- **原理**：轨迹到评测格式的转换（JA-162 轨迹数据集的工程面），导出管线化（评测集持续扩产），与评测资产（JA-202）联动
- **常见误区**：
  1. 轨迹无法转评测（错）
  2. 导出不需要格式（错）
  3. 评测集只人工建（错）
- **工程用法**：轨迹导出
- **版本锚点**：实战共识
