## 协作 · 回路（反馈）

- **事实**：人机协作反馈回路设计：人纠正 AI（JA-576 编辑）→纠正数据回流（JA-452 飞轮）→模型/提示改进→效果验证（JA-255），回路闭环
- **原理**：反馈回路的完整设计（飞轮的流程化），回路断点检查（回流→改进→验证每环），与数据飞轮联动
- **常见误区**：
  1. 反馈无回路（错）
  2. 回路断点无所谓（错）
  3. 改进无需验证（错）
- **工程用法**：反馈回路设计
- **版本锚点**：实战共识
