## 记忆 · 实现（读取）

- **事实**：记忆读取路径实现：检索请求→权限校验（租户 AD-471）→检索（AD-537 排序）→脱敏（AD-497）→返回，读取五步
- **原理**：读取路径的五步（记忆读取的完整链），权限与脱敏在读路径（JA-061 权限检索），与读取知识（AD-013）联动
- **常见误区**：
  1. 记忆读取直接查库（错）
  2. 五步是过度设计（错）
  3. 脱敏在读路径（是）（错）
