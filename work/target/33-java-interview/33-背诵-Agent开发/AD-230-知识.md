## 案例 · 知识（企业）

- **事实**：企业知识助手通用案例：全员问答（RAG）+工单创建（工具）+知识缺口回流（JA-496），是大多数企业的第一个 Agent
- **原理**：企业知识助手是"第一个 Agent"的最佳候选（ROI 清晰风险低 JA-441），知识运营（JA-532）决定上限，与 RAG 知识（JA-051）联动
- **常见误区**：
  1. 企业知识助手是伪需求（错）
  2. 第一个 Agent 应该做复杂场景（错）
  3. 知识运营无价值（错）
- **工程用法**：通用知识助手
- **版本锚点**：实战共识
