## 协作 · 策略总结（失败）

- **事实**：跨 Agent 失败传播策略总结：重试（子级）/替换（换子 Agent）/跳过（标注继续）/升级（人工），四策略按任务容错度选
- **原理**：失败传播策略的汇总（AD-133 的系统化），策略选择矩阵（容错度×阶段），与失败知识联动
- **常见误区**：
  1. 失败统一重试（错）
  2. 策略随意选（错）
  3. 跳过不标注（错）
- **工程用法**：失败策略总结
- **版本锚点**：实战共识
