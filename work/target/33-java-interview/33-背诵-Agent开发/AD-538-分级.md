## 记忆 · 分级（存储）

- **事实**：记忆多级存储：热（活跃会话，内存）/温（近期，KV/DB）/冷（归档，对象存储），分级存储按访问频率（JA-536 分层联动）
- **原理**：记忆多级存储（JA-536 分层的记忆版），访问频率驱动分级，冷记忆归档可检索（JA-668），与存储分层（MY-107）联动
- **常见误区**：
  1. 记忆单级存储（错）
  2. 分级是过度设计（错）
  3. 冷记忆必须在线（错）
- **工程用法**：记忆分级存储
- **版本锚点**：实战共识
