## 测试 · 剧本（mock）

- **事实**：Agent 测试用工具 mock 剧本：按测试场景定义工具返回序列（成功/失败/超时），断言轨迹与结果
- **原理**：JA-212 的实现面：剧本让测试确定可重复，轨迹断言（调用了什么/顺序）比只看结果强，与测试金字塔（JA-481）联动
- **常见误区**：
  1. Agent 测试连真实模型（错）
  2. mock 只返回成功（错）
  3. 只断言最终答案（错）
- **工程用法**：剧本化测试
- **版本锚点**：实战共识
