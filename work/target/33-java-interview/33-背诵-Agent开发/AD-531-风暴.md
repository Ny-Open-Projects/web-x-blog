## 工具 · 风暴（重试）

- **事实**：工具重试风暴防护：工具失败→模型重试→再失败的重试风暴（循环放大），防护：重试次数进预算（AD-303）+错误反馈明确“不可重试”（AD-116）
- **原理**：重试风暴的工具面（JA-020 重试风暴的 Agent 内部版），预算刹车+可重试判定双防，与重试知识联动
- **常见误区**：
  1. 工具重试不会风暴（错）
  2. 防护不必要（错）
  3. 重试是模型自主的（可控设计）（错）
- **工程用法**：重试风暴防护
- **版本锚点**：实战共识
