## 手写 · 实现（沙箱）

- **事实**：Agent 工具沙箱实现要点：容器隔离（AD-077 三限）+文件白名单（AD-078）+网络出口（AD-079）+逃逸测试（AD-496）四件，沙箱是“实现的工程”不是“配置的开关”
- **原理**：沙箱实现四件（JA-076 思想的工程化），容器运行时选择（安全 vs 性能），与沙箱知识联动
- **常见误区**：
  1. 沙箱配置即实现（错）
  2. 四件是过度设计（错）
  3. 逃逸测试可选（错）
- **工程用法**：沙箱实现要点
- **版本锚点**：实战共识
