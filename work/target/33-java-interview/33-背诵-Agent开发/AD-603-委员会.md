## 治理 · 委员会（变更）

- **事实**：Agent 变更委员会：重大变更（宪法重写/新工具类/新模型）评审会（AD-381 准入的治理会），委员会决议留痕
- **原理**：变更委员会的治理面（AD-381 的组织化），重大变更界定标准（影响行为的三元组变更 AD-059），与治理组织（AD-159）联动
- **常见误区**：
  1. 变更无需委员会（错）
  2. 委员会拖慢迭代（重大变更才触发）（错）
  3. 决议不留痕（错）
- **工程用法**：变更委员会
- **版本锚点**：实战共识
