## 安全 · 改进（复盘）

- **事实**：安全复盘与改进：安全事件复盘（根因→防线缺口）→防线补丁→样本入库（AD-581）→回归（AD-720），安全改进闭环
- **原理**：安全复盘的改进闭环（JA-355 的安全专章），防线补丁+样本回流双产出，与安全知识联动
- **常见误区**：
  1. 安全复盘走形式（错）
  2. 闭环不必要（错）
  3. 改进无验证（错）
- **工程用法**：安全改进闭环
- **版本锚点**：实战共识
