## 工程 · 上下文（预取）

- **事实**：上下文预取：Agent 决策前预取可能的工具结果/记忆（推测性预取），预取让决策时数据已就绪
- **原理**：预取是延迟优化（决策等待时间隐藏），推测成本（预取了不用的），按命中率启用
- **常见误区**：
  1. 预取不存在（错）
  2. 推测成本无影响（错）
  3. 预取总是启用（错）
- **工程用法**：预取策略
- **版本锚点**：实战共识
