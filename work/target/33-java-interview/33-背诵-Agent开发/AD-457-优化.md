## 工程 · 优化（内存）

- **事实**：Agent 内存优化：长会话的消息序列内存膨胀（裁剪及时 AD-023）+工具结果副本（引用复用），内存优化防长任务 OOM
- **原理**：长任务的内存面（消息序列堆积），及时裁剪（AD-023）是内存治理，与 JVM 内存知识联动
- **常见误区**：
  1. 内存由 GC 处理无需优化（错）
  2. 裁剪与内存无关（错）
  3. 长任务不会 OOM（错）
- **工程用法**：内存优化
- **版本锚点**：实战共识
