## 手写 · 执行器（并行）

- **事实**：并行工具执行器实现：独立工具 CompletableFuture 并行（AD-260 依赖图判断后），allOf 等待全部，依赖工具串行
- **原理**：并行执行器是 JA-260 的代码面（依赖图→并行分组→allOf），并行前提是工具独立声明，与并发知识联动
- **常见误区**：
  1. 工具全部串行执行（错）
  2. 并行无需依赖判断（错）
  3. allOf 不适用（错）
- **工程用法**：并行执行器
- **版本锚点**：实战共识
