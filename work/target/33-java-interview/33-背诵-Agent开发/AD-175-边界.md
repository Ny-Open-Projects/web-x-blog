## 安全 · 边界（信任）

- **事实**：多 Agent 系统信任边界：子 Agent 输出对父 Agent 是"外部输入"（子 Agent 可能被劫持），父级验证子结果
- **原理**：信任边界在多 Agent 划分（每个 Agent 是信任域边界），子结果不盲信（AD-502 verifier 思想跨 Agent），与零信任联动
- **常见误区**：
  1. 内部 Agent 互相信任（错）
  2. 信任边界不需要（错）
  3. 子结果直接可用（错）
- **工程用法**：多 Agent 信任
- **版本锚点**：实战共识
