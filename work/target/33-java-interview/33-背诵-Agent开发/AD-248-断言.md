## 手写 · 断言（测试）

- **事实**：Agent 单元测试断言清单：终止原因正确/消息序列完整（工具结果都回填）/轨迹步数符合/预算未超/脱敏生效，五断言最小集
- **原理**：断言清单让 Agent 单测有章法（JA-048 五 bug 的测试面），断言遗漏=回归盲区，与测试断言实践联动
- **常见误区**：
  1. 单测只跑通不断言（错）
  2. 五断言是过度设计（错）
  3. 断言与手写无关（错）
- **工程用法**：断言清单
- **版本锚点**：实战共识
