## 治理 · 规范（协作）

- **事实**：多团队 Agent 协作规范：工具共享规范（发布流程 AD-358）/评测共享（JA-597）/事故通报（JA-355），规范让多团队协作有序
- **原理**：多团队的协作规范（JA-408 组织面的落地件），共享与通报机制防孤岛，与平台治理（AD-102）联动
- **常见误区**：
  1. 多团队协作无规范（错）
  2. 规范是形式主义（错）
  3. 共享与通报可选（错）
- **工程用法**：协作规范
- **版本锚点**：实战共识
