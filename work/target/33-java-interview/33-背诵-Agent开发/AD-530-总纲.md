## 工程 · 总纲（漂移）

- **事实**：漂移治理总纲：四类漂移（配置/依赖/行为/成本）各有检测与响应，漂移治理是“AI 系统的防腐”，总纲进运维手册（AD-416）
- **原理**：四类漂移的治理总纲（本章漂移知识收束），漂移是 AI 系统特有运维主题（传统系统配置静态），与运维体系联动
- **常见误区**：
  1. 漂移治理不必要（错）
  2. 四类覆盖不全没关系（错）
  3. 传统运维经验直接套用（错）
- **工程用法**：漂移治理总纲
- **版本锚点**：实战共识
