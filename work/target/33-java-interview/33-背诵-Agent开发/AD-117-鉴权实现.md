## MCP · 鉴权实现（安全）

- **事实**：MCP 远程 server 鉴权实现：OAuth 资源服务器模式（JA-148 规范的落地），token 校验+scope 检查（工具级 scope）
- **原理**：远程 server 必须鉴权（公网暴露），工具级 scope 让授权精细化（JA-235 思想在 MCP 层），与 Spring Security 资源服务器配置同构
- **常见误区**：
  1. 远程 server 无需鉴权（错）
  2. scope 是可选装饰（错）
  3. 鉴权与应用级一致（MCP 有规范）（错）
