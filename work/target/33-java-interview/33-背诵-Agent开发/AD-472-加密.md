## 记忆 · 加密（安全）

- **事实**：记忆存储加密：记忆含用户个人数据（画像/历史），存储加密（静态加密）+传输加密，加密是合规底线（JA-198 延伸）
- **原理**：记忆是高敏数据聚集（JA-176 轨迹同级），静态加密（数据库 TDE/字段加密），与加密知识联动
- **常见误区**：
  1. 记忆明文存储可行（错）
  2. 加密影响性能（字段级加密可控）（错）
  3. 合规不涉及记忆（错）
- **工程用法**：记忆加密
- **版本锚点**：实战共识
