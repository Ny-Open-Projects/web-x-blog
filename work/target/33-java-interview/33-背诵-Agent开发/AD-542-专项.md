## 评测 · 专项（延迟）

- **事实**：延迟专项评测：分阶段延迟（首 token/总时长/工具耗时）的专项评测与回归，延迟回归进发布门禁（JA-339 性能基线的评测化）
- **原理**：延迟评测的专项化（JA-339 性能基线的评测执行），分阶段指标（JA-423 TTFT），与延迟知识联动
- **常见误区**：
  1. 延迟不进评测（错）
  2. 专项评测不必要（错）
  3. 只测功能质量（错）
- **工程用法**：延迟专项评测
- **版本锚点**：实战共识
