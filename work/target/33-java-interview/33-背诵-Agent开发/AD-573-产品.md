## 评测 · 产品（联动）

- **事实**：评测与产品指标联动验证：评测分提升应传导到产品指标（采纳率/解决率），不传导=评测失真或指标错位（JA-490 语义辨析）
- **原理**：评测与产品的传导验证（JA-233 双通道的一致性检查），传导断裂的排查，与在线指标（JA-233）联动
- **常见误区**：
  1. 评测分与产品指标无关（错）
  2. 传导自动发生（错）
  3. 不传导是正常（错）
- **工程用法**：传导验证
- **版本锚点**：实战共识
