## 工程 · 领域（预热）

- **事实**：Agent 上下文预热：启动时注入领域知识（业务规则/术语表），免每次检索注入（知识稳定的领域）
- **原理**：稳定领域知识预热比检索快（JA-145 预热思想的 prompt 面），预热知识体积控制（窗口预算 JA-223），与 RAG 取舍（JA-509）联动
- **常见误区**：
  1. 领域知识全靠检索（错）
  2. 预热影响灵活性（错）
  3. 预热无体积代价（错）
- **工程用法**：预热策略
- **版本锚点**：实战共识
