## 工程 · 配置（漂移）

- **事实**：配置漂移检测实现：生产配置 vs Git 基线定期 diff（JA-455 实现），漂移告警+自动回滚（基线为准），漂移是“手工改线上”的检测
- **原理**：配置漂移检测的代码实现（JA-455 的落地），diff 范围（宪法/工具/模型配置 AD-205），与配置治理联动
- **常见误区**：
  1. 配置漂移不存在（错）
  2. diff 手工做（错）
  3. 漂移无风险（错）
- **工程用法**：配置漂移检测
- **版本锚点**：实战共识
