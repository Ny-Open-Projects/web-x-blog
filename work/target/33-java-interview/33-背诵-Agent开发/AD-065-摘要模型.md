## 上下文 · 摘要模型（压缩）

- **事实**：历史摘要用小模型执行（摘要任务不需要旗舰模型），成本降一个量级
- **原理**：摘要质量要求低于主任务模型（摘要是中间产物），小模型摘要+主模型决策的分工，与分级路由（JA-232）同构
- **常见误区**：
  1. 摘要必须用同一模型（错）
  2. 摘要模型越强越好（错）
  3. 成本差异不存在（错）
- **工程用法**：摘要模型选型
- **版本锚点**：实战共识
