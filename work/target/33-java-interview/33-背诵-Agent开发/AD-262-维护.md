## 手写 · 维护（序列）

- **事实**：循环中消息序列的维护顺序：user 追加→assistant 追加（含工具调用意图）→每工具一条 tool 结果追加→循环，追加顺序错=上下文错乱
- **原理**：序列维护顺序是手写最易错点（AD-200 bug 清单第一条），assistant 消息与 tool 消息必须成组（AD-063 关联），与序列构建器（AD-244）联动
- **常见误区**：
  1. 追加顺序无关紧要（错）
  2. 工具结果可与调用合并一条（错）
  3. 顺序错误无后果（错）
- **工程用法**：序列维护顺序
- **版本锚点**：实战共识
