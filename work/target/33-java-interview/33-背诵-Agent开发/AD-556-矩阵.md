## 协作 · 矩阵（测试）

- **事实**：多 Agent 协作测试矩阵：协作场景×失败注入（某 Agent 失败/慢/返回错误）的测试矩阵，矩阵覆盖协作健壮性
- **原理**：协作测试矩阵（AD-414 组合测试的执行化），失败注入验证降级（AD-133），与混沌（AD-396）联动
- **常见误区**：
  1. 协作测试只测正常（错）
  2. 矩阵是过度设计（错）
  3. 失败注入不影响结果（错）
- **工程用法**：协作测试矩阵
- **版本锚点**：实战共识
