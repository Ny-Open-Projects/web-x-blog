## 运维 · 设计（混沌）

- **事实**：Agent 混沌实验设计：实验场景（模型延迟注入/工具失败注入/配额收缩）+稳态假设（降级生效）+爆炸半径控制（灰度实例），实验设计模板
- **原理**：混沌实验的设计模板（DF-076 的 Agent 面），稳态假设先行（无假设的演练是盲测），与演练矩阵（AD-338）联动
- **常见误区**：
  1. 混沌实验随意注入（错）
  2. 稳态假设不必要（错）
  3. 爆炸半径不可控（错）
- **工程用法**：实验设计模板
- **版本锚点**：实战共识
