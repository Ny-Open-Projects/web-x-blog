## 协作 · 选型矩阵（总结）

- **事实**：多 Agent 五模式选型矩阵：主从（任务可拆）/流水线（阶段固定）/辩论（质量敏感）/工作区（共享状态）/自由协作（探索），按任务结构与确定性需求选
- **原理**：五模式（AD-026~030）的选型收敛，选型矩阵是面试与设计的决策工具（JA-651 场景题骨架），与多 Agent 知识联动
- **常见误区**：
  1. 多 Agent 只有一种模式（错）
  2. 选型随意（错）
  3. 模式与任务无关（错）
- **工程用法**：多模式选型矩阵
- **版本锚点**：实战共识
