## 多模态 · 图像（消息）

- **事实**：消息中的图像表示：图像以 URL/base64 附件挂在 user 消息（Media 结构 JA-109），模型侧需多模态支持
- **原理**：图像消息的协议表示（JA-109 的消息层），与文本消息混合序列（JA-185 组装），协议不支持时降级（描述文本）
- **常见误区**：
  1. 图像塞在文本里（错）
  2. Media 结构不存在（错）
  3. 所有模型支持图像（错）
- **工程用法**：图像消息表示
- **版本锚点**：实战共识
