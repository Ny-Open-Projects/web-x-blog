## 评测 · 周期（生命）

- **事实**：评测集生命周期管理：创建→维护（JA-471）→老化（条目过时下线）→归档，评测集的完整生命周期（JA-202 的周期面）
- **原理**：评测集的周期管理（资产的全生命周期），老化检测（条目与当前业务脱节），与评测资产（JA-202）联动
- **常见误区**：
  1. 评测集永久有效（错）
  2. 生命周期不必要（错）
  3. 老化条目保留（错）
- **工程用法**：评测集周期
- **版本锚点**：实战共识
