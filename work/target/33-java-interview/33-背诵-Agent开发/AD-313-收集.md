## 手写 · 收集（指标）

- **事实**：Agent 执行指标收集：步数分布/每步耗时/token 消耗分布的定时器实现（Micrometer Timer/DistributionSummary AD-309）
- **原理**：分布指标比均值有价值（P99 定位毛刺），指标实现是观测三件（AD-041）的代码面，与 JA-647 维度体系联动
- **常见误区**：
  1. 指标只记平均值（错）
  2. 分布指标不必要（错）
  3. 指标与手写无关（错）
