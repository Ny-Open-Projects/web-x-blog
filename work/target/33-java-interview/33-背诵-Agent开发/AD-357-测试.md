## 工具 · 测试（AB）

- **事实**：工具 A/B 测试：同一工具两个实现（新旧）按流量分流，对比成功率/延迟/成本，数据驱动保留哪个
- **原理**：工具实现的 A/B（与 prompt A/B JA-271 同机制），流量切分与指标对比，与评测驱动（AD-255）联动
- **常见误区**：
  1. 工具实现直接替换（错）
  2. A/B 是过度设计（错）
  3. 对比只看延迟（错）
- **工程用法**：工具 A/B
- **版本锚点**：实战共识
