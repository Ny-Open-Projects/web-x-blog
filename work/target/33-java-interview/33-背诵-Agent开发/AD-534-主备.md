## 工具 · 主备（降级）

- **事实**：工具降级与主备切换：主工具失败切备工具（同语义 AD-359），切换决策（错误类型+健康度 JA-481），切换事件进轨迹
- **原理**：工具主备切换（模型降级 AD-370 的工具版），切换决策依据（错误分类+健康度），与降级知识联动
- **常见误区**：
  1. 工具无主备（错）
  2. 切换随机（错）
  3. 切换无记录（错）
- **工程用法**：工具主备
- **版本锚点**：实战共识
