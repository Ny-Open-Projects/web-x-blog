## 治理 · 合规（评测）

- **事实**：评测数据合规：评测集含真实用户数据时的合规（脱敏 JA-252/授权），评测数据的法律边界与生产数据同要求
- **原理**：评测数据的合规面（评测≠法外之地），脱敏与授权是评测集合规双件，与隐私知识（JA-198）联动
- **常见误区**：
  1. 评测数据无合规要求（错）
  2. 脱敏授权冗余（错）
  3. 生产要求更高（同级才是准确认知）（错）
- **工程用法**：评测合规
- **版本锚点**：实战共识
