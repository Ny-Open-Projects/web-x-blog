## 循环 · 终止条件（终止）

- **事实**：Agent 四类终止条件：任务完成（模型声明完成）、步数上限、预算耗尽、用户取消，终止后要有收尾动作
- **原理**：只设计"成功终止"不设计"失败终止"是事故源（JA-004 的展开），收尾动作（清理/汇报/落轨迹）是完整性的标志
- **常见误区**：
  1. 终止就是任务完成（错）
  2. 失败终止不需要收尾（错）
  3. 用户取消无法实现（错）
- **工程用法**：终止条件设计
- **版本锚点**：实战共识
