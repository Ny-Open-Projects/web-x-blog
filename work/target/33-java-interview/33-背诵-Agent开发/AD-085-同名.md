## MCP · 同名（冲突）

- **事实**：多 MCP server 接入的工具名冲突：同名工具（两个 server 都有 search）需命名空间消歧（server 前缀）
- **原理**：多 server 是常态（JA-021 多连接），同名工具让模型选择混乱（歧义），命名空间是接入层职责
- **常见误区**：
  1. 同名工具自动合并（错）
  2. 冲突不存在（错）
  3. 命名空间可选装饰（错）
- **工程用法**：工具命名空间
- **版本锚点**：实战共识
