## 工具 · 质量（描述）

- **事实**：工具描述（description）质量决定调用准确率：写清功能/参数含义/何时用/何时不用
- **原理**：模型靠描述选工具（JA-108 核心），描述含糊的后果是误调用与漏调用，描述评审（JA-671）是工具上线门槛
- **常见误区**：
  1. 描述随便写（错）
  2. 模型会猜参数含义（错）
  3. 描述与调用率无关（错）
- **工程用法**：工具描述纪律
- **版本锚点**：实战共识
