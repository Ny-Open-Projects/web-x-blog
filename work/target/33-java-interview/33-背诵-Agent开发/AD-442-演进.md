## 工具 · 演进（参数）

- **事实**：工具参数设计演进：参数过多让模型填参错误率上升（与工具数量阈值 AD-143 同构的参数面），参数精简（派生参数工具内计算）
- **原理**：参数设计的阈值效应（参数多=填错率高），精简策略（工具内计算派生值），与 schema 纪律（AD-052）联动
- **常见误区**：
  1. 参数越多越灵活（错）
  2. 参数数量无影响（错）
  3. 精简损失功能（工具内计算平衡）（错）
- **工程用法**：参数设计演进
- **版本锚点**：实战共识
