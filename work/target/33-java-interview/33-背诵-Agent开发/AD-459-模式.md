## 工程 · 模式（批处理）

- **事实**：Agent 批处理模式：批量任务（千级文档处理）的批 Agent 模式（任务分片+并行 Agent+聚合），批处理是成本与吞吐平衡（AI-026 批处理）
- **原理**：批处理模式的工程（JA-437 的 Agent 版），分片+并行+聚合（JA-026/132），与批处理成本联动
- **常见误区**：
  1. 批处理不需要 Agent（错）
  2. 模式单一（错）
  3. 吞吐与成本无关（错）
- **工程用法**：批处理模式
- **版本锚点**：实战共识
