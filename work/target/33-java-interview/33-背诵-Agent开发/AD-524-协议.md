## 治理 · 协议（第三方）

- **事实**：Agent 第三方数据处理协议：供应商数据处理协议（DPA）审读（用途/留存/子处理商），协议条款进供应商评审（JA-515 合同面）
- **原理**：第三方数据协议（AI-237 条款的合同化），DPA 审读清单化（用途/留存/子处理商三查），与供应商治理（AD-435）联动
- **常见误区**：
  1. 供应商协议不用审（错）
  2. DPA 是法务的事（工程要参与审读）（错）
  3. 条款与工程无关（错）
- **工程用法**：DPA 审读
- **版本锚点**：实战共识
