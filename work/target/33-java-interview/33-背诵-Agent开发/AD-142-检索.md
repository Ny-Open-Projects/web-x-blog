## 工程 · 检索（工具）

- **事实**：工具检索式选择：工具数量多（>20）时按任务检索相关工具子集注入（而非全列），选择准确率回升
- **原理**：工具过多让模型选择准确率下降（JA-143 注意力稀释），工具检索（嵌入工具描述）是规模化方案，与 RAG 思想同构
- **常见误区**：
  1. 工具全列给模型最好（错）
  2. 工具数量无影响（错）
  3. 检索式选择是过度设计（错）
- **工程用法**：工具规模化方案
- **版本锚点**：实战共识
