## 工程 · 注入（故障）

- **事实**：Agent 故障注入测试：工具失败/模型限流/上下文超限/配额耗尽四类注入（AD-396 模板的执行），验证 Agent 的容错行为（错误反馈/降级/收尾）
- **原理**：故障注入的 Agent 特化（JA-591 混沌的 Agent 面），注入验证容错（AD-016 反馈等），与混沌知识联动
- **常见误区**：
  1. Agent 无需故障注入（错）
  2. 四类注入随意（错）
  3. 容错行为不验证（错）
- **工程用法**：故障注入测试
