## 协作 · 结论（冲突）

- **事实**：多 Agent 结论冲突解决：两 Agent 结论矛盾时裁决机制（裁判 Agent/多数投票/规则优先级），冲突是常态要设计
- **原理**：结论冲突是多 Agent 常态（独立视角必然分歧，AD-029 辩论动机），无裁决机制则输出随机，与聚合策略（AD-132）联动
- **常见误区**：
  1. 结论天然一致（错）
  2. 冲突直接报错（错）
  3. 裁决不需要设计（错）
- **工程用法**：冲突解决设计
- **版本锚点**：实战共识
