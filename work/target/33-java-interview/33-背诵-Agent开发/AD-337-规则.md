## 运维 · 规则（告警）

- **事实**：Agent 告警规则设计：成功率跌破基线（AD-094）/步数分布异常（JA-139 探索度）/成本速率异常（JA-717）/队列积压（AD-108），四类规则各有阈值
- **原理**：告警规则的四类设计（每类对应一种故障模式 JA-044），阈值基于基线（AD-165），与告警路由（JA-526）联动
- **常见误区**：
  1. 告警只看成功率（错）
  2. 四类规则冗余（错）
  3. 阈值拍脑袋（错）
- **工程用法**：告警规则设计
- **版本锚点**：实战共识
