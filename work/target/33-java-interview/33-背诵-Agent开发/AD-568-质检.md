## 案例 · 质检（客服）

- **事实**：客服质检 Agent（AI 质检人工）：人工客服对话全量质检（合规用语/流程遵循），质检标准 few-shot（JA-443），质检结果进客服培训（JA-341 闭环）
- **原理**：质检 Agent 的反向应用（AI 质检人），全量质检（人检抽样 JA-439 反向），质检闭环（培训联动），与客服知识联动
- **常见误区**：
  1. 客服质检纯人工抽检（错）
  2. 质检标准不需要（错）
  3. 质检结果不用（错）
- **工程用法**：客服质检案例
- **版本锚点**：实战共识
