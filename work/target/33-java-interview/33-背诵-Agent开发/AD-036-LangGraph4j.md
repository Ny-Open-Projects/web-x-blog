## 编排 · LangGraph4j（Java）

- **事实**：LangGraph4j（JA-369）核心概念：StateGraph 状态图、节点处理器、条件边路由、编译后执行，把 LangGraph 模式带进 Java
- **原理**：Java 生态的图编排选项（社区项目），与自研骨架权衡（成熟度 vs 控制力），概念与 Python LangGraph 同源可迁移
- **常见误区**：
  1. LangGraph4j 是官方产品（错）
  2. 概念与 Python 完全不同（错）
  3. Java 不需要图编排（错）
- **工程用法**：Java 图编排认知
- **版本锚点**：2025
