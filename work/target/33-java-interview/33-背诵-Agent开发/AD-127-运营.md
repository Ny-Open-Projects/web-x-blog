## 案例 · 运营（电商）

- **事实**：电商运营 Agent：竞品监控（搜索工具）+文案生成（batch JA-437）+上架工具（确认），ROI 在高频商品运营
- **原理**：电商运营是高频规则化任务（Agent ROI 三高 JA-048），文案风格 few-shot（JA-443），上架动作强确认（JA-080）
- **常见误区**：
  1. 运营 Agent 全自动上架（错）
  2. 竞品监控靠人工（错）
  3. 文案无需风格锚定（错）
- **工程用法**：电商运营案例
- **版本锚点**：实战共识
