## 工具 · 模式（幂等）

- **事实**：工具幂等实现模式汇总：唯一键（DF-019）/条件更新（MY-078）/去重表（JA-060 版本）/token 预取（RD-097），四模式按场景选
- **原理**：幂等实现模式的汇总（工具幂等 JA-218 的实现族），按工具操作类型选模式，与幂等知识联动
- **常见误区**：
  1. 幂等实现只有一种（错）
  2. 模式随机选（错）
  3. 汇总无价值（错）
- **工程用法**：幂等模式汇总
- **版本锚点**：实战共识
