## 分类 · 谱系（类型）

- **事实**：Agent 谱系：工具型（单工具调用助手）→规划型（多步任务）→多 Agent（协作）→自主型（长任务），复杂度与风险递增
- **原理**：谱系帮助选型（从谱系低端起步验证），跳级到自主型是常见失败，与 AI-049 分类知识联动
- **常见误区**：
  1. 所有 Agent 同一类型（错）
  2. 谱系与复杂度无关（错）
  3. 直接做自主型最好（错）
- **工程用法**：Agent 谱系认知
- **版本锚点**：实战共识
