## 治理 · 实现（计费）

- **事实**：Agent 计费实现：用量聚合（token 按租户/Agent 聚合 JA-657）→价格表计算（JA-264）→账单输出（周期），计费数据与观测同源
- **原理**：计费的实现链（观测数据→聚合→价格→账单），计费准确性依赖 usage 采集（JA-065/079），与对账（JA-265）联动
- **常见误区**：
  1. 计费手工统计（错）
  2. 实现与观测无关（错）
  3. 账单不需要周期（错）
- **工程用法**：计费实现
- **版本锚点**：实战共识
