## 治理 · 登记册（风险）

- **事实**：Agent 风险登记册：每个 Agent 的风险项（幻觉/越权/成本/合规）登记与缓解措施跟踪，风险册是治理台账（JA-413 风险清单的运行态）
- **原理**：风险登记册的运行态（JA-413 的持续管理面），缓解措施有 owner 与期限，与风险治理联动
- **常见误区**：
  1. 风险登记无必要（错）
  2. 册子是形式主义（错）
  3. 缓解不跟踪（错）
- **工程用法**：风险登记册
- **版本锚点**：实战共识
