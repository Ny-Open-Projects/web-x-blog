## 评测 · 价值（成本）

- **事实**：评测成本与价值平衡：评测投入（token+人力）vs 评测价值（拦住的退化价值），ROI 评估决定评测规模
- **原理**：评测自身的 ROI（JA-653 成本的决策面），价值=拦截的退化×发生概率，与成本治理（JA-653）联动
- **常见误区**：
  1. 评测无成本概念（错）
  2. 价值无法估算（错）
  3. 规模越大越好（错）
- **工程用法**：评测 ROI
- **版本锚点**：实战共识
