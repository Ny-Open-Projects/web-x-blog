## 运维 · 监控（水位）

- **事实**：Agent 容量水位监控：并发任务/队列深度/供应商配额三维水位（JA-131/637），水位看板与告警（AD-394），水位数据驱动扩缩容
- **原理**：水位监控的维度设计（三维各监控），扩缩容联动（JA-478 HPA 类比），与容量模型（AD-340）联动
- **常见误区**：
  1. 水位不监控（错）
  2. 三维只有一维（错）
  3. 监控与扩缩容无关（错）
- **工程用法**：水位监控
- **版本锚点**：实战共识
