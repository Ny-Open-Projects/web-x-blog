## Agent · 事件（协议）

- **事实**：Agent 执行事件协议：任务开始/步骤开始结束/工具调用/进度/完成/失败的标准事件流（JA-425 通道化的协议定义）
- **原理**：事件协议让前端/监控/审计统一消费（JA-677 进度），协议字段固定（类型/负载/时间戳），与流式协议知识联动
- **常见误区**：
  1. 事件流无协议约定（错）
  2. 协议是过度设计（错）
  3. 事件随意定义（错）
- **工程用法**：事件协议设计
- **版本锚点**：实战共识
