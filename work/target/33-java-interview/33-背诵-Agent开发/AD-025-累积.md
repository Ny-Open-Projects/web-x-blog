## 成本 · 累积（陷阱）

- **事实**：成本陷阱：长任务上下文累积导致后期单步成本是初期数倍（线性增长叠加），总成本近平方级
- **原理**：JA-024 的推论：20 步任务后期单步成本可达 5 倍，总成本估算要用累积模型（JA-401 模拟器），裁剪是平方级救命
- **常见误区**：
  1. 总成本按首步线性估算（错）
  2. 累积增长不存在（错）
  3. 成本陷阱是伪命题（错）
- **工程用法**：成本累积陷阱
- **版本锚点**：实战共识
