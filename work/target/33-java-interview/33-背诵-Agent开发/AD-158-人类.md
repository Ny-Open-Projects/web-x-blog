## 评测 · 人类（对照）

- **事实**：与人类专家对照评测：Agent 产出与专家基线盲评对比（专家打分不分来源），差距即能力边界地图
- **原理**：Agent 能力边界的度量（JA-043 失败模式的量化），对照基线让"达到专家水平"有据，与评测（JA-375）联动
- **常见误区**：
  1. Agent 已达专家水平（错）
  2. 对照评测无必要（错）
  3. 盲评不可行（错）
- **工程用法**：对照评测设计
- **版本锚点**：实战共识
