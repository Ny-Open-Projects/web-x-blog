## 案例 · 提升（质量）

- **事实**：Agent 质量提升案例：轨迹分析发现工具选择错误率高（描述不清 JA-015）→重写描述→评测提升，描述质量是杠杆
- **原理**：质量提升案例（工具描述是最高杠杆 JA-015），描述改写的评估验证（AD-255 节奏），与工具描述知识联动
- **常见误区**：
  1. 描述质量无影响（错）
  2. 提升靠换模型（错）
  3. 案例无验证（错）
