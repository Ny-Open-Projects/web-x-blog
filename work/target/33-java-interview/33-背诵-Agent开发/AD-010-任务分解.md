## 规划 · 任务分解（分解）

- **事实**：复杂任务先分解：Agent 先产出子任务清单（计划），再逐项执行，分解质量决定上限
- **原理**：JA-057 规划先行的落地：分解让大任务可控（每步可验证），分解本身要用 LLM（模型拆解），拆解要验证（JA-624）
- **常见误区**：
  1. 复杂任务直接开跑（错）
  2. 分解是可选装饰（错）
  3. 拆解不需要验证（错）
- **工程用法**：任务分解设计
- **版本锚点**：实战共识
