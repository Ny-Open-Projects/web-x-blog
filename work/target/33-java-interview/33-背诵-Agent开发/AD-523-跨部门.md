## 治理 · 跨部门（共享）

- **事实**：Agent 跨部门数据共享治理：共享的数据范围审批/脱敏要求/用途限定/审计（AD-433 的跨部门面），跨部门共享是高风险动作
- **原理**：跨部门共享的治理（部门边界=信任边界 JA-175），审批+脱敏+审计三件，与数据治理（JA-409）联动
- **常见误区**：
  1. 跨部门共享随意（错）
  2. 治理是部门墙（合规必要性优先）（错）
  3. 共享无风险（错）
- **工程用法**：跨部门治理
- **版本锚点**：实战共识
