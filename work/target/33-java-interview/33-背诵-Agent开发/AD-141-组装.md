## 工程 · 组装（宪法）

- **事实**：Agent system prompt 组装管线：静态宪法+动态上下文（用户信息/时间/环境）分段组装（JA-061 参数模板），分段可测
- **原理**：宪法不是纯静态（动态注入运行时事实），组装管线让分段可单测（JA-209 模板单测），与提示词结构（JA-612）联动
- **常见误区**：
  1. 宪法纯静态字符串（错）
  2. 动态注入不需要测试（错）
  3. 组装管线是过度设计（错）
- **工程用法**：宪法组装管线
- **版本锚点**：实战共识
