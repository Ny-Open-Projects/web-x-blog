## 安全 · 传递（依赖）

- **事实**：依赖传递风险：工具依赖第三方库的漏洞（AD-497 CVE）→Agent 行为受影响，依赖传递链审计（SBOM 思想）
- **原理**：依赖传递的 Agent 面（AD-497 的 SBOM 化），工具依赖链可视（依赖清单 JA-721），与供应链安全（AD-177）联动
- **常见误区**：
  1. 依赖传递无风险（错）
  2. SBOM 不必要（错）
  3. 审计只在直接依赖（错）
- **工程用法**：依赖传递审计
- **版本锚点**：实战共识
