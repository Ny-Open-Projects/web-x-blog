## 手写 · 标准（评分）

- **事实**：手写题评分标准设计：功能正确（40%）/边界处理（20%，错误反馈/终止）/工程质量（20%，结构/命名/脱敏）/并发与安全（20%），四维加权
- **原理**：评分标准让手写评分有据（AL-051 规范的 Agent 版），边界与安全权重高（Agent 特性），与评分实践联动
- **常见误区**：
  1. 手写只看能否跑（错）
  2. 四维无权重设计（错）
  3. 边界与安全不重要（错）
- **工程用法**：评分标准
- **版本锚点**：实战共识
