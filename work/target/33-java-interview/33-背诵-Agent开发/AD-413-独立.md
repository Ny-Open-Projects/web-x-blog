## 协作 · 独立（版本）

- **事实**：多 Agent 独立版本管理：每个 Agent 独立版本三元组（AD-059），组合版本（发布快照）记录整体状态
- **原理**：独立版本+组合快照（发布时全组合可追溯），组合版本让"整体行为"可复现（JA-402 延伸），与版本治理联动
- **常见误区**：
  1. 多 Agent 共享一个版本（错）
  2. 组合快照不必要（错）
  3. 版本管理只管单 Agent（错）
- **工程用法**：组合版本管理
- **版本锚点**：实战共识
