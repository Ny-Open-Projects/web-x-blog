## 协作 · 隔离（验证）

- **事实**：多 Agent 故障隔离验证：注入单 Agent 故障，验证其余 Agent 与系统整体不受影响（隔离生效验证）
- **原理**：隔离设计（JA-373）要验证（演练 AD-338 的多 Agent 面），隔离失效=级联故障，与混沌工程联动
- **常见误区**：
  1. 隔离天然生效（错）
  2. 验证不必要（错）
  3. 注入故障影响全局（错）
- **工程用法**：隔离验证
- **版本锚点**：实战共识
