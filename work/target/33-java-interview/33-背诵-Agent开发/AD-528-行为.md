## 工程 · 行为（漂移）

- **事实**：行为漂移双通道检测：评测分数漂移（JA-392）+线上质量指标漂移（JA-399），双通道交叉定位漂移源（模型/数据/配置 JA-701）
- **原理**：行为漂移的双通道（JA-392/399 的组合），交叉定位（两通道同时变的=模型变更），与漂移归因联动
- **常见误区**：
  1. 行为漂移无检测（错）
  2. 双通道冗余（错）
  3. 漂移源单一（错）
- **工程用法**：行为漂移检测
- **版本锚点**：实战共识
