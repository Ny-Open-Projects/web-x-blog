## 演进 · 观察（生态）

- **事实**：Agent 生态观察项：MCP server 生态增长、A2A 协议 adoption、框架合并趋势，季度评估（JA-529 雷达）
- **原理**：生态演进影响技术选型（JA-522 再评估），观察项清单化（不追热点但不错过拐点），与技术雷达联动
- **常见误区**：
  1. 生态观察无必要（错）
  2. 追新即评估（错）
  3. 季度太频繁（错）
- **工程用法**：生态观察机制
- **版本锚点**：实战共识
