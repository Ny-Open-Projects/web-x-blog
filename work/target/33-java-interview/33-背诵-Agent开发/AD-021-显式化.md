## 架构 · 显式化（状态）

- **事实**：Agent 任务状态显式化：任务/阶段/上下文快照落库（JA-255），支持恢复/审计/取消
- **原理**：状态在代码变量里=不可恢复不可审计，显式化是长任务（JA-370 引擎）与多租户（隔离）的前提
- **常见误区**：
  1. 状态隐式在循环里即可（错）
  2. 显式化是过度设计（错）
  3. 状态与恢复无关（错）
- **工程用法**：状态显式化
- **版本锚点**：实战共识
