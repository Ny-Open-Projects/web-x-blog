## 工具 · 实现（重入）

- **事实**：工具的可重入实现：重复调用同参数返回同结果（缓存 AD-578）或登记跳过（JA-504 登记模式），可重入让 Agent 重试与恢复安全
- **原理**：工具可重入的实现模式（缓存/登记两模式），与幂等实现（JA-218/AD-038）联动，与恢复安全联动
- **常见误区**：
  1. 工具天然可重入（错）
  2. 实现模式不需要（错）
  3. 重入无所谓（错）
- **工程用法**：工具重入
- **版本锚点**：实战共识
