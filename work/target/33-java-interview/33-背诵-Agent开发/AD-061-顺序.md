## 上下文 · 顺序（组装）

- **事实**：上下文组装顺序约定：system（宪法）→任务描述→长期记忆→历史轮次→工具结果→当前输入，顺序影响注意力分布
- **原理**：首尾注意力强（JA-510），宪法置顶、当前输入置尾是布局纪律（JA-619 排序同理），顺序错误导致"忘记宪法"
- **常见误区**：
  1. 顺序随意无影响（错）
  2. 当前输入放中间最好（错）
  3. 组装顺序框架自动最优（错）
- **工程用法**：组装顺序纪律
- **版本锚点**：实战共识
