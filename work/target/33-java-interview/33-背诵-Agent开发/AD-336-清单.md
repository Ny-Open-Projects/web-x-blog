## 运维 · 清单（发布）

- **事实**：Agent 发布检查清单：评测门禁通过（AD-092）/宪法评审（JA-530）/工具评审（AD-671）/降级演练（AD-672 类比）/监控接入（AD-207）/回滚方案（AD-258）六项，清单通过才发布
- **原理**：发布清单是 AD-525 准入的 Agent 特化版：六项覆盖质量/安全/运维，清单化防漏（MY-110 思想），与发布体系联动
- **常见误区**：
  1. 发布检查口头确认（错）
  2. 六项清单是形式主义（错）
  3. 清单可部分跳过（错）
- **工程用法**：发布清单
- **版本锚点**：实战共识
