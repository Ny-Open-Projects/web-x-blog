## 能力 · 不作为（放弃）

- **事实**：Agent 的"放弃/求助"能力：模型可声明无法完成或需要人工，强撑完成任务是幻觉重灾区
- **原理**：JA-672 的机制化：宪法中定义放弃条件与求助通道，放弃是正确行为（不是失败），与拒答（JA-367）同思想
- **常见误区**：
  1. Agent 必须完成任务（错）
  2. 放弃就是失败（错）
  3. 求助能力不需要设计（错）
- **工程用法**：放弃能力设计
- **版本锚点**：实战共识
