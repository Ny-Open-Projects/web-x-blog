## 安全 · 分数（度量）

- **事实**：Agent 安全分数：注入拦截率/越狱率/越权拦截率/外泄拦截率的加权安全分，安全分数进发布门禁（JA-525 安全维）
- **原理**：安全分数的度量设计（安全可量化的汇总），加权按风险（外泄权重最高），与安全门禁（AD-387）联动
- **常见误区**：
  1. 安全无法量化（错）
  2. 分数不需要（错）
  3. 维度权重随意（错）
- **工程用法**：安全分数设计
- **版本锚点**：实战共识
