## 案例 · 全流程（采购）

- **事实**：采购 Agent 全流程：需求理解→供应商询价（工具）→比价分析（JA-227 供应链经验）→采购建议（人确认）→订单跟踪，供应商数据实时性关键
- **原理**：采购全流程案例（AD-227 供应链的采购深化），实时工具（价格/库存），建议制（决策链长），与供应链案例联动
- **常见误区**：
  1. 采购全自动下单（错）
  2. 供应商数据静态（错）
  3. 比价靠人工（错）
