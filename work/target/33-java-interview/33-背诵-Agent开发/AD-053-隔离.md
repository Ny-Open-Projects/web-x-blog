## 手写 · 隔离（执行）

- **事实**：工具执行的隔离：超时（单独超时非整体 JA-275）/资源限制/异常捕获（失败转错误消息回喂 JA-016）
- **原理**：隔离让单工具失败不拖垮 Agent（舱壁 JA-103 工具级），隔离是工具执行包装器的职责
- **常见误区**：
  1. 工具执行裸调即可（错）
  2. 异常直接终止 Agent（错）
  3. 隔离是过度设计（错）
- **工程用法**：执行隔离设计
- **版本锚点**：实战共识
