## 手写 · 实现（限流）

- **事实**：Agent 限流实现：提交入口检查配额（用户/租户/全局三级 JA-206），Redis 计数（RD-057）或本地令牌桶，超限返回明确错误码（AD-284）
- **原理**：限流实现是配额的执行（AD-099 配置的执行面），三级检查顺序（先用户后全局），超限错误码标准化，与限流知识联动
- **常见误区**：
  1. Agent 入口不限流（错）
  2. 限流实现随机（错）
  3. 三级检查顺序随意（错）
- **工程用法**：限流实现
- **版本锚点**：实战共识
