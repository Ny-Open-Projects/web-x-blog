## 上下文 · 目标置顶（锚定）

- **事实**：任务目标在长会话中重复锚定：关键目标 periodically 重申（防上下文膨胀后目标被"稀释"）
- **原理**：lost in the middle（JA-510）让早期目标被稀释，锚定是目标保持的主动手段，锚定文案要精简（不重复全文）
- **常见误区**：
  1. 目标说一次就够（错）
  2. 锚定会占空间（精简锚定代价小）（错）
  3. 稀释不影响任务（错）
- **工程用法**：目标锚定技巧
- **版本锚点**：实战共识
