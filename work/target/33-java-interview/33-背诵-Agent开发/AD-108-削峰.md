## 架构 · 削峰（队列）

- **事实**：Agent 任务队列削峰：任务异步排队（用户提交即返回任务 id），执行结果通知，长任务异步化
- **原理**：同步长任务占用连接（JA-535 连接容量），异步队列解耦提交与执行，与 MQ 削峰（MQ-043）联动
- **常见误区**：
  1. Agent 任务全部同步（错）
  2. 异步队列无必要（错）
  3. 任务 id 无意义（错）
- **工程用法**：异步任务架构
- **版本锚点**：实战共识
