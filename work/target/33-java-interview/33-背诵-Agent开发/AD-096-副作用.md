## 安全 · 副作用（半径）

- **事实**：Agent 副作用半径评估：上线前评估"Agent 最坏能造成什么"（最大权限组合下的破坏面），按半径设计防线
- **原理**：副作用半径是安全设计的度量（JA-082 组合风险的量化），半径大→防线强（人审/沙箱），半径评估写进架构评审（JA-524）
- **常见误区**：
  1. 副作用半径无需评估（错）
  2. 防线与半径无关（错）
  3. 最坏情况不考虑（错）
- **工程用法**：半径评估
- **版本锚点**：实战共识
