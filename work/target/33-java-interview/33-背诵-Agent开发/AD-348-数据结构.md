## 安全 · 数据结构（权限）

- **事实**：Agent 权限矩阵数据结构：Map<AgentId, Set<ToolId>> 的集中存储（AD-233 矩阵的代码面），权限检查 O(1)，变更走审计（JA-684）
- **原理**：权限矩阵的代码实现（集中存储+O(1) 检查），变更记录（谁改的权限），与权限治理（AD-233）联动
- **常见误区**：
  1. 权限检查每次查库（错）
  2. 数据结构随意（错）
  3. 变更不审计（错）
- **工程用法**：权限矩阵实现
- **版本锚点**：实战共识
