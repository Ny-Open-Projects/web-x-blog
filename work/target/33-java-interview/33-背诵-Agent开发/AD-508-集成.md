## 手写 · 集成（降级）

- **事实**：Agent 降级集成实现要点：模型降级链（AD-370）+工具 fallback（AD-359）+功能开关（AD-105）+兜底文案（JA-399）四层贯通，降级集成让“降了就能用”
- **原理**：降级集成四件（降级链的完整化），每层的触发与恢复（JA-672 演练验证），与降级体系（JA-053）联动
- **常见误区**：
  1. 降级只有模型层（错）
  2. 四层贯通无必要（错）
  3. 降级与开关无关（错）
- **工程用法**：降级集成要点
- **版本锚点**：实战共识
