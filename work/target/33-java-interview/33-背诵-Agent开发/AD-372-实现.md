## 手写 · 实现（dry-run）

- **事实**：dry-run 模式实现：Agent 配置 dryRun 标志，工具执行阶段跳过真实调用（返回模拟结果），产出计划轨迹供人工审（AD-104 的代码面）
- **原理**：dry-run 的代码实现（执行器层拦截），模拟结果的生成（按工具声明返回示例），与 dry-run 设计（AD-104）联动
- **常见误区**：
  1. dry-run 无法实现（错）
  2. 全部工具真实执行（错）
  3. 模拟结果随机（错）
- **工程用法**：dry-run 实现
- **版本锚点**：实战共识
