## 安全 · 应急（事件）

- **事实**：Agent 安全事件应急：注入成功/越权执行/数据外泄三类事件的应急流（AD-180 止血→根因→改进），安全事件与功能事件分开管理
- **原理**：安全事件的应急专流（JA-180 的安全专章），三类事件各有止血动作，与安全运营（AD-520）联动
- **常见误区**：
  1. 安全事件按功能故障处理（错）
  2. 应急专流不必要（错）
  3. 三类事件无区分（错）
- **工程用法**：安全应急专流
- **版本锚点**：实战共识
