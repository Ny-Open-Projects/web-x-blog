## 评测 · 保障（复现）

- **事实**：评测可复现性保障：固定种子（模型温度 0 或固定种子）/固定工具 mock 剧本/固定检索结果，可复现让回归可信（JA-490 基线对比前提）
- **原理**：可复现性的工程保障（JA-344 抽样可复现的扩展），三固定（种子/剧本/检索快照），与评测纪律联动
- **常见误区**：
  1. 评测天然可复现（错）
  2. 可复现性不必要（错）
  3. 固定种子不可能（低温近似可复现）（错）
- **工程用法**：可复现性保障
- **版本锚点**：实战共识
