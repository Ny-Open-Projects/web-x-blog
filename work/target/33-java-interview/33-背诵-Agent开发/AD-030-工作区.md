## 多Agent · 工作区（共享）

- **事实**：共享工作区（scratchpad）模式：多 Agent 读写同一工作区（文档/状态），协作更自然但需并发控制
- **原理**：工作区是"共享内存"（JA-503 写冲突管控），版本与锁是工作区工程核心，与主从（传递式）对比：共享式耦合更高
- **常见误区**：
  1. 共享工作区无并发问题（错）
  2. 工作区与消息传递等价（错）
  3. 版本控制不必要（错）
- **工程用法**：工作区模式
- **版本锚点**：实战共识
