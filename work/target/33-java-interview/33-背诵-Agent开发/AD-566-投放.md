## 案例 · 投放（广告）

- **事实**：广告投放 Agent：创意生成（JA-437 batch）+投放策略建议（数据工具）+效果分析（归因报告），投放执行人确认（预算动作）
- **原理**：广告案例的创意+分析双能（生成与数据工具组合），预算动作确认（AD-080），效果闭环（JA-219）
- **常见误区**：
  1. 广告投放全自动（错）
  2. 创意无事实核查（错）
  3. 效果分析不需要（错）
- **工程用法**：广告案例
