## 协作 · 技能（路由）

- **事实**：技能路由（skill-based routing）：按任务所需技能（代码/检索/分析）路由到具备该技能的 Agent，技能注册与匹配是路由基础
- **原理**：JA-128 路由的技能化：路由依据是"能力画像"而非固定规则，技能画像随评测更新（AD-094），与路由知识联动
- **常见误区**：
  1. 路由随机分配（错）
  2. 技能画像不需要（错）
  3. 路由与技能无关（错）
- **工程用法**：技能路由设计
- **版本锚点**：实战共识
