## 手写 · 可重入（设计）

- **事实**：Agent 执行可重入：同一任务的重入（续跑）不重复执行已完成的工具步骤（步骤幂等登记），可重入靠步骤级登记
- **原理**：可重入是恢复的精细版（AD-195 checkpoint 的步骤粒度），步骤登记（已执行清单）让续跑跳过，与幂等（AD-038）联动
- **常见误区**：
  1. 重入必然重复执行（错）
  2. 可重入无实现价值（错）
  3. 登记机制不必要（错）
- **工程用法**：可重入实现
- **版本锚点**：实战共识
