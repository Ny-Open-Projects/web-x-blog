## 上下文 · 长结果（分块）

- **事实**：长工具结果的上下文分块：结果超长时切块注入（分块间引用），或摘要化（JA-256），按结果类型选
- **原理**：长结果的两策略（分块保细节/摘要保要点），选择按下游需求（Agent 是否需要细节），与裁剪（AD-069）联动
- **常见误区**：
  1. 长结果截断一刀切（错）
  2. 分块与摘要二选一（错）
  3. 结果类型无关（错）
- **工程用法**：长结果策略
- **版本锚点**：实战共识
