## 工具 · 预算（性能）

- **事实**：工具性能预算：单工具执行 P99 预算（超预算优化或标注慢工具），慢工具拖累 Agent 步进延迟
- **原理**：工具耗时直接叠加 Agent RT（JA-298 容量的工具面），性能预算让工具开发有性能意识，与性能工程联动
- **常见误区**：
  1. 工具性能无所谓（错）
  2. 预算是过度设计（错）
  3. P99 与工具无关（错）
- **工程用法**：工具性能预算
- **版本锚点**：实战共识
