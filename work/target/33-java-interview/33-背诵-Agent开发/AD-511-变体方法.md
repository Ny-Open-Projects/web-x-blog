## 手写 · 变体方法（出题）

- **事实**：Agent 手写题的变体设计方法：基础骨架上换约束（加预算/加并发/加记忆/加流式）生成变体（AD-403 的系统化），每变体考察不同维度
- **原理**：变体设计的系统化（约束矩阵组合出题），变体覆盖能力面（并发/流式/记忆/成本），与出题方法联动
- **常见误区**：
  1. 手写题只有一版（错）
  2. 变体随意组合（按考察维度设计）（错）
  3. 变体无需评分标准适配（错）
- **工程用法**：变体设计方法
- **版本锚点**：实战共识
