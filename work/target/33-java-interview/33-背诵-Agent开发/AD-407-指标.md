## 治理 · 指标（运营）

- **事实**：Agent 平台运营指标：接入 Agent 数/活跃 Agent/自助创建率/平台 SLA 达成率，平台运营的北极星（JA-414 思想）
- **原理**：平台运营指标定义（AD-102 平台的价值度量），自助率是平台化成熟标志（JA-654），与平台治理联动
- **常见误区**：
  1. 平台运营无指标（错）
  2. 指标越多越好（错）
  3. 北极星可以多个（错）
- **工程用法**：平台运营指标
- **版本锚点**：实战共识
