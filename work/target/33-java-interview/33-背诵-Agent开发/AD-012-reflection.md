## 模式 · reflection（反思）

- **事实**：反思模式：Agent 完成后自我批评（检查结果/找漏洞）再改进，质量敏感任务的第二循环
- **原理**：反思循环提升质量但成本翻倍（多轮 LLM 调用），质量敏感（对外交付物）开启、内部流程关闭，与自一致性（AI-446）权衡
- **常见误区**：
  1. 反思是免费的质量提升（错）
  2. 所有任务都该反思（错）
  3. 反思不需要评估验证（错）
- **工程用法**：反思模式设计
- **版本锚点**：实战共识
