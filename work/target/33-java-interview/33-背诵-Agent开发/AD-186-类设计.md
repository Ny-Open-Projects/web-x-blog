## 手写 · 类设计（结构）

- **事实**：手写 Agent 的类结构设计：AgentExecutor（循环）/ToolRegistry（注册表 AD-051）/Message（AD-062）/ModelClient（抽象 AD-189）/TrajectoryRecorder（AD-040）五类，类图即架构
- **原理**：五类划分是手写 Agent 的最小架构（每类单一职责 JA-051 注册表），类设计先于编码（面试手写先画类图），与面向对象设计联动
- **常见误区**：
  1. 手写 Agent 一个类搞定（错）
  2. 五类是过度设计（错）
  3. 类图与手写无关（错）
- **工程用法**：手写类设计
- **版本锚点**：实战共识
