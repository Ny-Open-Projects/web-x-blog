## 手写 · 提取（输出）

- **事实**：最终答案提取：终止后从最后 assistant 消息提取文本（或结构化 entity），提取时剥离工具调用残留
- **原理**：最终提取是 Agent 的“出口”（输出的契约 AD-047），残留工具调用标记会污染输出，与输出结构化联动
- **常见误区**：
  1. 直接返回全部消息（错）
  2. 提取无残留问题（错）
  3. 提取是可选步骤（错）
- **工程用法**：答案提取
- **版本锚点**：实战共识
