## 评测 · 专项（成本）

- **事实**：成本专项评测：任务成本回归（单任务 token/费用对比基线 JA-528），成本回归进发布门禁（与延迟并列），成本专项的根因（prompt 膨胀/工具循环）
- **原理**：成本评测的专项化（JA-528 成本门禁的评测执行），根因关联（JA-633 案例），与成本治理联动
- **常见误区**：
  1. 成本不进评测（错）
  2. 专项评测不必要（错）
  3. 成本回归可有可无（错）
- **工程用法**：成本专项评测
