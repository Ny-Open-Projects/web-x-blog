## 手写 · 工作（线程）

- **事实**：Agent 工作线程实现：从队列取任务→执行（AgentExecutor.run）→结果回写→继续取，线程数=并发度（JA-131 水位），优雅停机（AD-307 停止取任务）
- **原理**：工作线程的实现要点（循环取任务/异常不退出/优雅停机），线程数与配额（AD-322）联动，与线程池实践联动
- **常见误区**：
  1. 工作线程异常即退出（错）
  2. 线程数随意（错）
  3. 停机直接 kill（错）
- **工程用法**：工作线程实现
- **版本锚点**：实战共识
