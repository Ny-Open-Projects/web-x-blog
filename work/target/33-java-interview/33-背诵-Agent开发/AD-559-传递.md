## 协作 · 传递（SLA）

- **事实**：跨 Agent SLA 传递：父任务 SLA 分解到子 Agent SLA（预算传递 AD-028 思想），子 SLA 不达触发父级策略
- **原理**：SLA 分解让端到端 SLA 可控（子不达父兜底），SLA 传递与超时传递（AD-149）同构，与 SLA 管理（AD-485）联动
- **常见误区**：
  1. SLA 只在入口定义（错）
  2. 分解不必要（错）
  3. 子 SLA 无意义（错）
- **工程用法**：SLA 传递
- **版本锚点**：实战共识
