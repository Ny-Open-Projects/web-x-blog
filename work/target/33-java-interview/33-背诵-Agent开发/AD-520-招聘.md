## 案例 · 招聘（HR）

- **事实**：HR 招聘 Agent 案例：简历解析（多模态 JA-545）+岗位匹配（语义检索）+面试题生成，公平性防线（JA-559 偏见评估）强制，人审最终决策
- **原理**：招聘案例的公平性强制（JA-559 的落地），简历多模态解析（JA-545），匹配可解释（决策依据 JA-506）
- **常见误区**：
  1. 招聘 Agent 自动筛人（错）
  2. 公平性评估可选（错）
  3. 匹配不需要解释（错）
