## 多Agent · 分工（角色）

- **事实**：Agent 角色分工：planner（拆解）/executor（执行）/reviewer（审查）/reporter（汇报），角色=system prompt 差异
- **原理**：角色化让职责单一（每个 Agent 宪法简单清晰），角色间契约明确，与 SRP 设计思想联动
- **常见误区**：
  1. 所有 Agent 同一角色（错）
  2. 角色只是名字差异（错）
  3. 分工与 prompt 无关（错）
- **工程用法**：角色化设计
- **版本锚点**：实战共识
