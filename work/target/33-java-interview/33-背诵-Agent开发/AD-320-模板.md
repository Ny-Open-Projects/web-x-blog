## 手写 · 模板（配置）

- **事实**：Agent 生产配置模板：模型（key 走环境变量 JA-043）/限制（步数/预算）/工具（清单与权限）/观测（采样率）四段模板，模板即生产的起点配置
- **原理**：生产配置模板让部署标准化（新 Agent 从模板复制 JA-523 脚手架），模板四段对应 AD-198 四组，与配置模板实践联动
- **常见误区**：
  1. 生产配置从零写（错）
  2. 模板固化过时配置（错）
  3. 模板与手写无关（错）
- **工程用法**：生产配置模板
- **版本锚点**：实战共识
