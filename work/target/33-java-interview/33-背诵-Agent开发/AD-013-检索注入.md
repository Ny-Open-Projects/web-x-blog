## 记忆 · 检索注入（长期）

- **事实**：长期记忆的读取：按当前任务检索相关历史（向量检索），注入上下文供决策参考
- **原理**：记忆不是全量塞（JA-673 重排），检索注入让 Agent"记得该记的"，记忆写回策略（JA-504）配套
- **常见误区**：
  1. 长期记忆全量进上下文（错）
  2. 记忆检索不需要相关度（错）
  3. 记忆与 RAG 无关（错）
- **工程用法**：长期记忆读取
- **版本锚点**：实战共识
