## 手写 · 格式（轨迹）

- **事实**：轨迹序列化格式设计：JSON Lines（每步一行）+任务级元数据头，格式决定下游分析便利性
- **原理**：轨迹格式是观测生态的接口（JA-040 分析工具消费），JSON Lines 流式友好（逐行解析），与轨迹基建联动
- **常见误区**：
  1. 轨迹自定义二进制（错）
  2. 格式无关紧要（错）
  3. JSON Lines 不适合（错）
- **工程用法**：轨迹格式设计
- **版本锚点**：实战共识
