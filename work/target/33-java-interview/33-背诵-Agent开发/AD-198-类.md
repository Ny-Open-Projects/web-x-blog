## 手写 · 类（配置）

- **事实**：Agent 配置类设计：模型配置/工具配置/限制配置（步数/预算/超时）/安全配置四组，配置与代码分离（SP-027 绑定）
- **原理**：配置类让 Agent 参数化（不同场景不同配置实例化），四组配置与 JA-345/AD-059 对应，与配置校验（JA-346）联动
- **常见误区**：
  1. 配置硬编码在代码（错）
  2. 配置类是过度设计（错）
  3. 四组配置无关联（错）
- **工程用法**：配置类设计
- **版本锚点**：实战共识
