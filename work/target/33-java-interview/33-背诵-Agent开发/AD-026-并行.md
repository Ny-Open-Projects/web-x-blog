## 多Agent · 并行（并发）

- **事实**：多 Agent 并行执行：独立子任务分发给多个 Agent 同时跑（JA-260 工具并行的 Agent 级），结果聚合
- **原理**：并行缩短墙钟时间（总时长=最慢子任务），聚合阶段处理结果合并（JA-244 思想），并行前提是子任务独立
- **常见误区**：
  1. 多 Agent 只能串行（错）
  2. 并行无聚合问题（错）
  3. 独立性不需要判断（错）
- **工程用法**：并行执行设计
- **版本锚点**：实战共识
