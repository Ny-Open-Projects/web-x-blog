## 编排 · 状态机（图）

- **事实**：图状态机编排：任务为节点、转移为边、条件路由（LLM 决策边走向），显式图让流程可审计
- **原理**：图编排把"自主性"约束在图内（可控可测），与自由 ReAct 对比：图是"有围栏的自主"，与工作流引擎（JA-370）权衡
- **常见误区**：
  1. 图编排限制灵活性（错）
  2. 图与状态机无关（错）
  3. 条件路由不需要 LLM（错）
- **工程用法**：图编排理解
- **版本锚点**：实战共识
