## 手写 · 幻觉工具（容错）

- **事实**：未知工具调用的处理：模型调用了未注册的工具名（幻觉工具），处理=返回“工具不存在”错误消息回喂（模型可纠正），不终止
- **原理**：幻觉工具是模型常见错误（AD-044 清单），终止式处理让 Agent 脆弱，错误反馈让模型换正确工具，与错误反馈（AD-194）联动
- **常见误区**：
  1. 幻觉工具调用直接终止（错）
  2. 返回错误是浪费轮次（错）
  3. 幻觉不存在（错）
- **工程用法**：幻觉工具处理
- **版本锚点**：实战共识
