## 面试 · 分享（经验）

- **事实**：Agent 面试经验：回答带场景（做过什么）/带数据（评测分/成本）/带权衡（选型理由），经验型回答优于背诵
- **原理**：经验型回答的优势（JA-401 背景的真实性），场景+数据+权衡三件，与答题方法论（JA-652）联动
- **常见误区**：
  1. 背诵标准答案足够（错）
  2. 经验无法表达（错）
  3. 三件是形式主义（错）
- **工程用法**：经验回答方法
- **版本锚点**：实战共识
