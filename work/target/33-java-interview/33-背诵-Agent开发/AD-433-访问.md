## 治理 · 访问（数据）

- **事实**：Agent 数据访问治理：Agent 可访问的数据源清单（权限矩阵 AD-348）+数据密级（JA-380）+访问审计（AD-084），数据面治理
- **原理**：数据访问的三维治理（权限/密级/审计），Agent 数据访问是合规重点（AI-040），与数据治理联动
- **常见误区**：
  1. Agent 数据访问无治理（错）
  2. 三维治理冗余（错）
  3. 审计可选（错）
- **工程用法**：数据访问治理
- **版本锚点**：实战共识
