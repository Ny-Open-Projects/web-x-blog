## 工程 · 绑定（版本）

- **事实**：Agent 版本三元组：宪法（system prompt）+工具集+模型配置绑定打版本，评测基线按版本（AI-064 的 Agent 版）
- **原理**：Agent 行为由三元组决定（任一变更行为变），版本化让"行为可复现可回滚"，与语义化版本（JA-402）联动
- **常见误区**：
  1. Agent 无版本概念（错）
  2. 只版本化代码（错）
  3. 三元组是过度设计（错）
- **工程用法**：Agent 版本化
- **版本锚点**：实战共识
