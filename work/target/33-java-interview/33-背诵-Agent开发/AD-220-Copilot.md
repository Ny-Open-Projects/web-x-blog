## 演进 · Copilot（谱系）

- **事实**：Copilot 到 Agent 的演进谱系：Copilot（人主 AI 辅）→半自主（人审关键点）→全自主（人监督），演进按信任积累推进
- **原理**：谱系帮助规划产品形态（信任未积累前上全自主是失败模式，AD-046 确认交互的谱系定位），与 AD-019 分类互补
- **常见误区**：
  1. 直接做全自主最好（错）
  2. 谱系无意义（错）
  3. 演进不需要信任积累（错）
- **工程用法**：Copilot 谱系
- **版本锚点**：实战共识
