## 工程 · 域地图（主线）

- **事实**：agent-dev 域知识地图：架构与循环（本批）→上下文与记忆→多 Agent 协作→工具工程→评测与安全→手写笔试（压轴），域主线与 java-ai 域衔接（JA-660 分工）
- **原理**：地图是后续批次的路标（JA-360 方法论），每批填充一分支，复习按地图检索，与域收官（JA-715）联动
- **常见误区**：
  1. 域知识是碎片（错）
  2. 地图不需要（错）
  3. 分支无逻辑顺序（错）
- **工程用法**：域地图起点
- **版本锚点**：实战方法论
