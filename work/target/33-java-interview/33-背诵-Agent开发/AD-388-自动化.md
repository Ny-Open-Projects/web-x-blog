## 治理 · 自动化（发布）

- **事实**：Agent 发布自动化：评测门禁通过→灰度切流（AD-321）→监控观察（AD-207）→自动放量或回滚（指标驱动），发布流水线化
- **原理**：发布自动化的实现（灰度指标驱动放量/回滚决策），自动决策的护栏（异常自动暂停），与发布自动化实践联动
- **常见误区**：
  1. 发布手动逐步（错）
  2. 自动化不必要（错）
  3. 自动放量危险（护栏可控）（错）
- **工程用法**：发布自动化
- **版本锚点**：实战共识
