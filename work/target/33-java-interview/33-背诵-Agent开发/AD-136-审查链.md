## 安全 · 审查链（输出）

- **事实**：Agent 输出合规审查链：护栏（JA-193）→敏感信息扫描（JA-262）→引用校验（JA-202）→人工签发（高风险 JA-478），链式流水线
- **原理**：输出审查链是 Agent 上生产的硬门槛（输出即副作用），链式让审查可组合可测试，与输出管线（JA-207）联动
- **常见误区**：
  1. Agent 输出直接交付（错）
  2. 审查链是形式主义（错）
  3. 单点审查足够（错）
- **工程用法**：输出审查链
- **版本锚点**：实战共识
