## 案例 · 检索（法务）

- **事实**：法务检索 Agent：判例检索（向量+关键词混合 JA-241）+条款比对（JA-555）+检索报告（引用可溯源 JA-202），输出是检索报告非法律意见
- **原理**：法务检索的场景边界（检索≠法律意见，JA-555 责任链），引用可溯源是生命线（编造判例=事故），与法务知识联动
- **常见误区**：
  1. 法务 Agent 给法律意见（错）
  2. 引用无需溯源（错）
  3. 判例靠模型记忆（错）
- **工程用法**：法务检索案例
- **版本锚点**：实战共识
