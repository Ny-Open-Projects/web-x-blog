## 记忆 · 性（扩展）

- **事实**：记忆可扩展性：容量扩展（分片 AD-696→水平扩展）/检索扩展（索引分片）/写入扩展（分批），扩展性三面
- **原理**：记忆扩展性的实现面（AD-696 的扩展细化），分片策略（按租户/时间），与扩展性知识联动
- **常见误区**：
  1. 记忆无法扩展（错）
  2. 扩展性不需要（错）
  3. 分片策略随意（错）
- **工程用法**：记忆扩展性
- **版本锚点**：实战共识
