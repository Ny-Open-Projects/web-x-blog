## 评测 · 优先级（队列）

- **事实**：评测任务优先级队列：发布前评测优先级高于日常评测，优先队列保证关键评测先跑
- **原理**：评测队列的优先级实现（发布阻塞在评测，关键先跑），与队列知识（AL-014 堆）联动，与发布流程（AD-336）联动
- **常见误区**：
  1. 评测队列 FIFO 不分优先（错）
  2. 优先级是过度设计（错）
  3. 发布可以等（错）
- **工程用法**：优先级队列
- **版本锚点**：实战共识
