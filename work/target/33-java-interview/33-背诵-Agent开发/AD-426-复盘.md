## 案例 · 复盘（事故）

- **事实**：Agent 事故复盘案例：客服 Agent 幻觉承诺赔付（宪法边界缺失）→止血（下线+回滚）→根因（宪法无边界声明）→修复（宪法+拒答）→评估集回流
- **原理**：真实形态事故复盘案例（边界缺失是最常见根因），复盘五步产出（修复+评估集+宪法更新），与复盘模板（JA-355）联动
- **常见误区**：
  1. 幻觉承诺不会发生（错）
  2. 止血只是下线（错）
  3. 评估集回流可选（错）
- **工程用法**：事故复盘案例
- **版本锚点**：实战共识
