## 工具 · 链路（追踪）

- **事实**：工具调用链路追踪：工具调用 span 挂 Agent trace（JA-596），工具内下游调用继续 span（二级链路 AD-239），全链可追
- **原理**：工具链路追踪的完整面（Agent→工具→下游三级 span），追踪断裂=排障断链，与分布式追踪联动
- **常见误区**：
  1. 工具调用无 span（错）
  2. 三级追踪不必要（错）
  3. 追踪只到工具（错）
- **工程用法**：工具链路追踪
- **版本锚点**：实战共识
