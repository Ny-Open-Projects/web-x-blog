## 协作 · 分配（决策）

- **事实**：人机任务分配决策树：错误代价（高→人主导）/任务频率（高→AI 主导）/任务结构（固定→工作流），决策树驱动模式选择（JA-546/547 的选择器）
- **原理**：分配决策树（两种模式的选择器），树是设计工具（JA-651 场景题的分配步骤），与任务分析（AD-048）联动
- **常见误区**：
  1. 任务分配拍脑袋（错）
  2. 决策树不必要（错）
  3. 树覆盖所有场景（边界场景人审）（错）
- **工程用法**：分配决策树
- **版本锚点**：实战共识
