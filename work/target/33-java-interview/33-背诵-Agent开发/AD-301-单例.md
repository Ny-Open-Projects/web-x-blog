## 手写 · 单例（并发）

- **事实**：Agent 单例与并发：AgentExecutor 设计为无状态单例（状态在任务实例），并发任务各自持有独立任务状态，单例+任务对象分离
- **原理**：无状态单例+有状态任务分离是并发正确性的设计（JA-058 并发的架构面），单例共享工具/模型（AD-107 线程安全），与状态显式化（AD-021）联动
- **常见误区**：
  1. AgentExecutor 每任务新建（错）
  2. 单例有并发问题（错）
  3. 状态放单例字段（错）
- **工程用法**：单例设计
- **版本锚点**：实战共识
