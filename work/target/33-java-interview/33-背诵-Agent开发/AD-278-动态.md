## 手写 · 动态（注册）

- **事实**：工具运行时动态注册：registry.register(tool) 运行时调用（插件式工具加载），与静态注册（启动期）并存，动态注册要校验（重名/schema）
- **原理**：动态注册支撑插件化（AD-723 插件思想），校验防坏工具（重名/schema 缺失），与 MCP 动态发现（AD-372→JA-094）联动
- **常见误区**：
  1. 工具只能启动期注册（错）
  2. 动态注册无校验（错）
  3. 插件化不需要（错）
- **工程用法**：动态注册
- **版本锚点**：实战共识
