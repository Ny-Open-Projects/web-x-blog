## 记忆 · 租户（隔离）

- **事实**：记忆多租户隔离：租户级记忆命名空间（AD-696 分片的租户面），隔离让多租户记忆安全（JA-503 跨租户红线）
- **原理**：记忆租户隔离（JA-503 红线的存储实现），命名空间/分库分表选型，与多租户（AD-503）联动
- **常见误区**：
  1. 记忆多租户自动隔离（错）
  2. 隔离实现不必要（错）
  3. 跨租户共享可接受（错）
- **工程用法**：记忆租户隔离
- **版本锚点**：实战共识
