## 安全 · 输出（签名）

- **事实**：Agent 输出签名（防篡改）：对输出内容计算签名（HMAC），下游校验签名防中间篡改（输出作为决策依据的场景）
- **原理**：输出完整性保护（Agent 输出驱动下游动作时），签名让"输出未被改"可验证，与安全完整性思想联动
- **常见误区**：
  1. 输出无需签名（错）
  2. 签名影响性能（HMAC 极快）（错）
  3. 下游不校验（错）
- **工程用法**：输出签名
- **版本锚点**：实战共识
