## 协作 · 归因（成本）

- **事实**：多 Agent 成本归因到 Agent：系统成本按 Agent 拆分（每 Agent token 消耗），成本热点 Agent 优先优化（JA-208 的多 Agent 版）
- **原理**：成本归因到 Agent 粒度（优化决策的依据），拆分靠轨迹（AD-040 记录归属），与成本治理（JA-461）联动
- **常见误区**：
  1. 系统成本不拆分（错）
  2. 归因到 Agent 无价值（错）
  3. 成本均匀分布（实际热点集中）（错）
- **工程用法**：成本归因
- **版本锚点**：实战共识
