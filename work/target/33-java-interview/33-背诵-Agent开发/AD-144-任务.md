## 工程 · 任务（分组）

- **事实**：工具按任务分组注入：不同任务类型只注入该任务域的工具子集（工具包模式）
- **原理**：AD-142 检索的确定性替代（规则分组更可控），分组按业务域（订单工具包/库存工具包），与舱壁（DF-027）思想联动
- **常见误区**：
  1. 工具包模式不存在（错）
  2. 分组限制灵活性（错）
  3. 全量注入更灵活（准确率代价）（错）
- **工程用法**：工具包模式
- **版本锚点**：实战共识
