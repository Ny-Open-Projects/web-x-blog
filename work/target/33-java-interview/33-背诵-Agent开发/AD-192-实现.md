## 手写 · 实现（轨迹）

- **事实**：轨迹记录器实现：每步追加轨迹条目（时间戳/类型/内容摘要/token），异步落库（JA-040 不阻塞主循环），轨迹 ID 关联任务
- **原理**：轨迹记录器的实现要点（异步/结构化/可导出），记录器与 Agent 主逻辑解耦（观察者模式），与轨迹基建（AD-040）联动
- **常见误区**：
  1. 轨迹同步写阻塞主循环（错）
  2. 轨迹可选（错）
  3. 轨迹无结构（错）
