## 架构 · 组成（四件套）

- **事实**：Agent 四件套：LLM 大脑（决策）、工具（行动手脚）、记忆（上下文）、规划（任务分解）
- **原理**：四件齐备才是完整 Agent，缺工具是纯聊天、缺规划是被动响应，架构设计从四件盘点起步
- **常见误区**：
  1. Agent 只有 LLM 就够（错）
  2. 记忆是可选项（多轮必需）（错）
  3. 规划与 LLM 无关（错）
- **工程用法**：四件套盘点法
- **版本锚点**：实战共识
