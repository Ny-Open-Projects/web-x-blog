## 观测 · 记录（轨迹）

- **事实**：Agent 轨迹记录：每步（模型输入输出/工具调用/耗时/token）持久化，轨迹是调试/评测/审计的共同底座
- **原理**：轨迹三用（JA-219/042/678），轨迹缺失=Agent 黑盒，轨迹格式标准化（JSON 结构）便于工具分析
- **常见误区**：
  1. 轨迹只在日志文件（错）
  2. 轨迹与评测无关（错）
  3. 记录影响性能（异步落库）（错）
- **工程用法**：轨迹基建
- **版本锚点**：实战共识
