## 工具 · 评审（安全）

- **事实**：工具安全评审清单：副作用声明（AD-115）/权限最小化（AD-495）/沙箱需求（AD-077）/审计（AD-613）/依赖审计（AD-497）五查，安全评审进工具上线
- **原理**：工具安全评审的五查（AD-671 四查的安全扩展），五查覆盖工具安全面，与安全评审（JA-299）联动
- **常见误区**：
  1. 工具安全评审可选（错）
  2. 五查是形式主义（错）
  3. 评审与上线无关（错）
- **工程用法**：工具安全评审
- **版本锚点**：实战共识
