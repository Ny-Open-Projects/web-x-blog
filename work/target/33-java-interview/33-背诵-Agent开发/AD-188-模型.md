## 手写 · 模型（消息）

- **事实**：Message 模型实现：role（枚举）+content+可选 toolCallId/工具调用列表，序列化为供应商消息格式
- **原理**：消息模型是协议适配的内核（AD-062 的代码化），工具调用字段设计（请求列表/结果引用）决定并行支持（AD-008）
- **常见误区**：
  1. Message 只有字符串 content（错）
  2. 工具字段不必要（错）
  3. 消息模型与序列化无关（错）
- **工程用法**：消息模型实现
- **版本锚点**：实战共识
