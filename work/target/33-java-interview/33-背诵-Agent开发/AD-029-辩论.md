## 多Agent · 辩论（辩论）

- **事实**：辩论模式：多个 Agent 对同一问题独立作答后相互批评（互查漏洞），最终裁决者合并，质量敏感任务提升准确率
- **原理**：独立视角+交叉批评降低单一模型偏见（与 AI-447 多模型投票同思想），成本×N，用于高风险决策而非日常
- **常见误区**：
  1. 辩论提升所有任务（错）
  2. 辩论无成本代价（错）
  3. 裁决不需要独立方（错）
- **工程用法**：辩论模式
- **版本锚点**：实战共识
