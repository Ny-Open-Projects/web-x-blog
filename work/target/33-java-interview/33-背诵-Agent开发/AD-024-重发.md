## 成本 · 重发（构成）

- **事实**：Agent 的 token 成本构成：每轮都重发全量上下文（历史+工具结果），单步成本随轮次线性增长
- **原理**：理解成本模型才能理解优化方向（裁剪/摘要都是降重发），与成本治理（AI-062）联动
- **常见误区**：
  1. 每轮只发增量（错）
  2. 成本与轮次无关（错）
  3. 上下文不发重复（错）
- **工程用法**：成本模型理解
- **版本锚点**：实战共识
