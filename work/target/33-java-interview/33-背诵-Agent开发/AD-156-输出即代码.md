## 安全 · 输出即代码（代码）

- **事实**：Agent 生成代码执行防线：生成代码→静态扫描（危险 API 黑名单）→沙箱执行（AD-077）→人工确认（高危），多层防线
- **原理**：生成代码执行是最高危 Agent 能力（JA-156 沙箱的完整防线链），黑名单+沙箱+确认三层缺一，与代码沙箱纪律联动
- **常见误区**：
  1. 生成代码直接执行（错）
  2. 静态扫描足够（错）
  3. 人工确认可选（错）
- **工程用法**：代码执行防线
- **版本锚点**：实战共识
