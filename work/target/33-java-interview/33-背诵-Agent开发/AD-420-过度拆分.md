## 协作 · 过度拆分（反模式）

- **事实**：多 Agent 反模式：过度拆分（每步一个 Agent，通信开销>收益）与过少拆分（单 Agent 塞全部工具），拆分粒度按任务自然边界
- **原理**：拆分粒度的反模式（JA-085 分布式单体的 Agent 版），拆分标准：独立职责+独立演化+明确接口，与微服务拆分原则（DF-084）联动
- **常见误区**：
  1. Agent 拆得越细越好（错）
  2. 粒度无所谓（错）
  3. 过度拆分没有代价（错）
- **工程用法**：拆分粒度反模式
- **版本锚点**：实战共识
