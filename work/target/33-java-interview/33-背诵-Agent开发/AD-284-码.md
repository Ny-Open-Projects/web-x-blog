## 手写 · 码（错误）

- **事实**：Agent 错误码设计：任务级错误码（CONFIG_INVALID/QUOTA_EXCEEDED/TOOL_FAILED/CONTEXT_OVERFLOW/TIMEOUT），码标准化让客户端处理
- **原理**：错误码标准化是 API 契约（JA-684 网关错误思想），客户端按码处理（重试/提示），与错误分层（JA-104）联动
- **常见误区**：
  1. 错误码随意字符串（错）
  2. 码不需要规范（错）
  3. 客户端只看 message（错）
- **工程用法**：错误码设计
- **版本锚点**：实战共识
