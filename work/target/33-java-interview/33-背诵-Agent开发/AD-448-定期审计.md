## 安全 · 定期审计（权限）

- **事实**：Agent 权限定期审计：权限矩阵（AD-348）定期审计（权限最小化校验 JA-018），僵尸权限清理（不再使用的工具权限收回）
- **原理**：权限定期审计（权限漂移治理 JA-455 的权限版），僵尸权限是攻击面，与权限治理（AD-386）联动
- **常见误区**：
  1. 权限一次配置永久（错）
  2. 定期审计不必要（错）
  3. 僵尸权限无风险（错）
- **工程用法**：权限定期审计
- **版本锚点**：实战共识
