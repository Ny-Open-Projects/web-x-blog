## 记忆 · 分级（隐私）

- **事实**：记忆隐私分级：记忆条目按敏感度分级（高敏加密 AD-472/常规/公开），分级驱动存储与展示策略，分级在写入时标记
- **原理**：记忆隐私分级（JA-521 用途限定的记忆面），分级驱动策略（加密/展示/删除），与隐私分级（JA-380）联动
- **常见误区**：
  1. 记忆无隐私分级（错）
  2. 分级在读取时（写入时标记）（错）
  3. 分级是过度设计（错）
- **工程用法**：记忆隐私分级
- **版本锚点**：实战共识
