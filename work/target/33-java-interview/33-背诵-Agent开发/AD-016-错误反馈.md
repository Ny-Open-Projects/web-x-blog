## 工具 · 错误反馈（容错）

- **事实**：工具执行失败把错误信息回喂模型（而非终止），模型可修正参数重试
- **原理**：错误反馈让 Agent 自我修复（AI-043），错误信息要可读（模型能理解），终止式失败处理让 Agent 脆弱
- **常见误区**：
  1. 工具失败应该直接终止（错）
  2. 错误信息给用户即可（错）
  3. 重试不需要反馈（错）
- **工程用法**：工具容错设计
- **版本锚点**：实战共识
