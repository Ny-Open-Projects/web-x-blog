## 测试 · 实现（集成）

- **事实**：Agent 集成测试实现：Testcontainers 起 Redis/DB（依赖中间件）+mock 模型（AD-197），验证持久化/队列/并发全链，集成测试环境与生产同构
- **原理**：集成测试的实现要点（真实中间件+mock 模型 JA-203 分层），Testcontainers 让环境一致（AI-058 风格），与测试分层（AD-201）联动
- **常见误区**：
  1. 集成测试 mock 一切中间件（错）
  2. Testcontainers 是可选装饰（错）
  3. 集成测试不需要同构（错）
- **工程用法**：集成测试实现
