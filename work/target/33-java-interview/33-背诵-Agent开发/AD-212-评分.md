## 协作 · 评分（信任）

- **事实**：子 Agent 结果可信评分：按历史表现（成功率）与产出校验（AD-502）给子 Agent 打可信分，路由参考
- **原理**：信任不是均等的（各 Agent 历史表现差异），评分驱动任务分派（好的多派），与评分思想（JA-493）联动
- **常见误区**：
  1. 子 Agent 结果同等可信（错）
  2. 评分无法量化（错）
  3. 历史表现无意义（错）
- **工程用法**：可信评分
- **版本锚点**：实战共识
