## 案例 · 分析（数据）

- **事实**：数据分析 Agent：NL2SQL（JA-438 四防线）+执行+图表生成+解读，工具=数仓连接+图表库，产出=分析报告
- **原理**：数据分析是"检索+计算+表达"复合任务（Agent 优势区），SQL 防线是安全核心（JA-438），报告结构化（AD-047）
- **常见误区**：
  1. 分析 Agent 手写 SQL 直执行（错）
  2. 不需要图表（错）
  3. 结果无需校验（错）
- **工程用法**：数据分析 Agent
- **版本锚点**：实战共识
