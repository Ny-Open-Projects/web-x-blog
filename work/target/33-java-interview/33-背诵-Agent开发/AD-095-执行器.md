## 安全 · 执行器（注入）

- **事实**：工具是注入的执行器面：注入攻击诱导 Agent 调工具（JA-734 诱导样本），防线=输出侧检测（JA-458）+权限校验（JA-235）+最小授权（AD-500 思想）
- **原理**：注入在 Agent 的危害升级（工具执行=真实副作用，JA-394），三层防线缺一，与注入知识（JA-225）联动
- **常见误区**：
  1. 注入只影响文本输出（错）
  2. 防线只有提示词（错）
  3. 工具调用免注入风险（错）
- **工程用法**：注入执行器面
- **版本锚点**：实战共识
