## 手写 · 讲解（对照）

- **事实**：手写与框架代码对照讲解：手写骨架映射到框架概念（循环→AgentExecutor/注册表→ToolCallback），对照讲解证明“知其所以然”
- **原理**：手写与框架的对照是深度证明（P10 加分项 JA-049 框架认知），会手写才会用框架排障，与框架知识联动
- **常见误区**：
  1. 手写与框架无关（错）
  2. 对照讲解没必要（错）
  3. 框架是黑盒用就行（错）
- **工程用法**：对照讲解
- **版本锚点**：实战共识
