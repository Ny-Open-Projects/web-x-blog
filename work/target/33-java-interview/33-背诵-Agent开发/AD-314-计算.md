## 手写 · 计算（窗口）

- **事实**：上下文窗口动态计算实现：system+消息序列逐条 token 估算（AD-067 jtokkit）累加，剩余预算=窗口-已用，裁剪决策依据剩余预算
- **原理**：窗口计算是裁剪的依据实现（AD-068 策略的输入），逐条估算开销可控（缓存 token 数），与窗口管理（AD-014）联动
- **常见误区**：
  1. 窗口计算不需要实现（错）
  2. 估算逐条太慢（缓存后可控）（错）
  3. 剩余预算无用途（错）
