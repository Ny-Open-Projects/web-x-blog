## 手写 · 实现（影子）

- **事实**：影子执行实现：影子 Agent 用 dry-run（AD-372）跑真实任务副本（不产生副作用），影子结果与主版本对比记录
- **原理**：影子执行的手写实现（dry-run 复用 JA-372），影子与主版本结果对比（JA-596 报告），与影子运营（JA-593）联动
- **常见误区**：
  1. 影子执行产生副作用（错）
  2. 影子实现复杂（dry-run 复用简单）（错）
  3. 影子结果不对比（错）
- **工程用法**：影子实现
- **版本锚点**：实战共识
