## 工程 · 切换（灾备）

- **事实**：Agent 灾备切换：区域故障时 Agent 任务切换（任务重调度到健康区域+记忆可访问性验证），记忆跨区可用是多活前提
- **原理**：灾备切换的 Agent 面（JA-599 多活的切换面），记忆可访问性是前提（JA-473 备份），与灾备切换（MY-094）联动
- **常见误区**：
  1. 灾备切换与 Agent 无关（错）
  2. 记忆跨区天然可用（错）
  3. 切换不需要验证（错）
- **工程用法**：灾备切换
- **版本锚点**：实战共识
