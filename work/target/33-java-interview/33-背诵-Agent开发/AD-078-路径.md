## 工具 · 路径（沙箱）

- **事实**：文件操作工具的路径沙箱：白名单根目录+路径校验（防 ../ 逃逸），工作目录外拒绝
- **原理**：路径穿越（../）是文件工具经典攻击（与 Web 路径穿越同源），白名单根目录+规范化校验，与文件安全知识联动
- **常见误区**：
  1. 文件工具可访问任意路径（错）
  2. 路径校验影响灵活（安全优先）（错）
  3. 穿越攻击不存在（错）
- **工程用法**：文件工具沙箱
- **版本锚点**：实战共识
