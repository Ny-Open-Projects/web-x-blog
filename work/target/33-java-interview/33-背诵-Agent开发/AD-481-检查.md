## 工具 · 检查（健康）

- **事实**：工具健康检查：工具级健康探针（下游连通/响应时间），不健康工具摘除（AD-105 开关联动）
- **原理**：工具健康探针（JA-273 拨测的工具版），摘除联动开关（运行时下线），与健康检查（JA-582）联动
- **常见误区**：
  1. 工具无需健康检查（错）
  2. 探针成本高（轻量探针）（错）
  3. 摘除影响功能（降级备选）（错）
- **工程用法**：工具健康检查
- **版本锚点**：实战共识
