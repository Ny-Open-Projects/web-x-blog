## 测试 · 格式（剧本）

- **事实**：mock 模型剧本格式：JSON 序列（每步 expectedResponse），支持工具调用与文本混合步骤，剧本文件与测试同仓
- **原理**：剧本格式设计（AD-039 的文件化），格式简单（JSON 行）与表达力（多步骤）平衡，与 mock 实现（AD-197）联动
- **常见误区**：
  1. 剧本硬编码在测试（错）
  2. 格式随意（错）
  3. 剧本与代码同仓不需要（错）
- **工程用法**：剧本格式设计
- **版本锚点**：实战共识
