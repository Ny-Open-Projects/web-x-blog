## 协作 · 优先级（调度）

- **事实**：Agent 任务优先级调度：按任务优先级（付费用户/紧急度）调度执行顺序，优先级队列（AD-345 任务级）的调度层
- **原理**：优先级调度让稀缺资源（配额 JA-535）给高价值任务，抢占策略（高优先抢占低优先）设计，与调度知识联动
- **常见误区**：
  1. 任务 FIFO 不分优先（错）
  2. 抢占不可能（错）
  3. 优先级是装饰（错）
- **工程用法**：优先级调度
- **版本锚点**：实战共识
