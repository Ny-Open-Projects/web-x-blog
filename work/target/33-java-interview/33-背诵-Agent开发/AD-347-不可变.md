## 安全 · 不可变（审计）

- **事实**：Agent 审计日志不可变存储：append-only（WORM 存储/对象存储版本控制），审计日志不可修改删除（合规要求 JA-097）
- **原理**：审计日志的可信度来自不可变（可改的审计无法律效力），WORM 存储或对象存储版本化，与合规留存（JA-383）联动
- **常见误区**：
  1. 审计日志可修改（错）
  2. 不可变存储是过度设计（错）
  3. append-only 难实现（对象存储现成）（错）
- **工程用法**：审计不可变
- **版本锚点**：实战共识
