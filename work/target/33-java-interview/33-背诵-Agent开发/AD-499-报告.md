## 安全 · 报告（合规）

- **事实**：Agent 合规报告：数据流向（JA-409）/权限矩阵（AD-348）/审计完整性（AD-347）/事故记录（AD-180）四维合规报告，报告支撑监管响应（JA-630）
- **原理**：合规报告的四维结构（合规审读的组织化），报告自动化生成（AD-334 延伸），与合规知识联动
- **常见误区**：
  1. 合规报告手工整理（错）
  2. 四维不必要（错）
  3. 报告无监管用途（错）
- **工程用法**：合规报告
- **版本锚点**：实战共识
