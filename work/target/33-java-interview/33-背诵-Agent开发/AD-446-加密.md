## 安全 · 加密（输出）

- **事实**：Agent 敏感输出加密：输出含敏感数据（用户数据/密钥）时端到端加密（下游解密），输出加密让中间环节不可见
- **原理**：输出加密的落地（传输加密 TLS 之外的端到端面），中间环节（网关/队列）不可见，与加密知识联动
- **常见误区**：
  1. 输出有 TLS 就够（错）
  2. 端到端加密无必要（错）
  3. 中间环节可信（错）
- **工程用法**：输出加密
- **版本锚点**：实战共识
