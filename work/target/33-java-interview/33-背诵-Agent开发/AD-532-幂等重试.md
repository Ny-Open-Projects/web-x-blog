## 工具 · 幂等重试（组合）

- **事实**：工具幂等与重试的组合实现：重试前提是幂等校验（非幂等工具禁自动重试），组合实现（幂等声明→重试策略绑定）
- **原理**：幂等与重试的组合（JA-056 的工程化），非幂等工具的人工确认重试，与幂等知识（AD-218）联动
- **常见误区**：
  1. 重试与幂等无关（错）
  2. 非幂等也能重试（错）
  3. 组合实现复杂（声明式简单）（错）
- **工程用法**：幂等重试组合
- **版本锚点**：实战共识
