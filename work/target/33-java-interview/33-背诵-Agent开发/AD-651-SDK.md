## 协作 · SDK（接口）

- **事实**：Agent 团队的编程接口（Agent SDK）：任务提交/状态查询/结果获取/取消四 API 的 SDK 化（AD-281 接口的 SDK 封装），SDK 让协作标准化
- **原理**：SDK 化让 Agent 间协作免协议细节（JA-567 生态的 Java 面），SDK 版本兼容（JA-565），与 API 设计（JA-641）联动
- **常见误区**：
  1. 协作直接 HTTP 调用（错）
  2. SDK 是过度设计（错）
  3. 版本兼容可选（错）
- **工程用法**：Agent SDK 设计
- **版本锚点**：实战共识
