## 案例 · Agent（客服）

- **事实**：客服 Agent 架构：意图路由 Agent→知识问答（RAG）→工单工具（创建/查询）→情绪升级人工（JA-434 漏斗的 Agent 化），全程轨迹（JA-219）
- **原理**：客服是 Agent 首选落地（JA-441 ROI），Agent 化后"解决+转接+工单"一气呵成，边界：赔付类强确认（AD-080）
- **常见误区**：
  1. 客服 Agent 直接回复不调工具（错）
  2. 情绪识别可选（错）
  3. 赔付自动化（错）
