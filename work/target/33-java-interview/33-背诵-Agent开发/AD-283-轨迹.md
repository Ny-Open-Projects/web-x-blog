## 手写 · 轨迹（SSE）

- **事实**：SSE 轨迹事件推送：轨迹事件（AD-146）经 SseEmitter 推前端（AD-169 桥接），事件过滤（哪些事件推前端 vs 只落库）
- **原理**：轨迹推送让用户实时看到 Agent 在做什么（JA-677 进度的事件面），过滤策略（敏感步骤不推），与轨迹分级（AD-106）联动
- **常见误区**：
  1. 轨迹只落库不推（错）
  2. 推送全部事件（敏感过滤需求）（错）
  3. SseEmitter 与轨迹无关（错）
- **工程用法**：SSE 轨迹推送
- **版本锚点**：实战共识
