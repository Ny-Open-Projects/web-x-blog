## 手写 · 优雅（停机）

- **事实**：Agent 优雅停机：进行中任务处理（等待完成或暂停 checkpoint），停机前拒绝新任务（AD-108 队列关闭），与 SP-098 优雅停机同构
- **原理**：停机对长任务的影响（硬杀丢任务，checkpoint 续跑 AD-147），停机流程（关队列→等任务→checkpoint→退出），与优雅停机（SP-098）联动
- **常见误区**：
  1. 停机直接杀进程（错）
  2. 任务自动保存（错）
  3. 优雅停机不必要（错）
- **工程用法**：优雅停机实现
- **版本锚点**：实战共识
