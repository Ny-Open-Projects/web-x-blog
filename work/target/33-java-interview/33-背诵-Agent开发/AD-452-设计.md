## 评测 · 设计（多轮）

- **事实**：多轮对话 Agent 评测设计：多轮任务集（上下文依赖的任务链），评测"跨轮信息保持"与"指代消解"（JA-711 的 Agent 版）
- **原理**：多轮评测的单轮盲区（跨轮能力），多轮任务集构造（轮次依赖设计），与多轮评测知识联动
- **常见误区**：
  1. 多轮评测=单轮拼接（错）
  2. 跨轮能力无法评测（错）
  3. 任务链不需要设计（错）
- **工程用法**：多轮评测设计
- **版本锚点**：实战共识
