## 工程 · 域定稿（收官）

- **事实**：agent-dev 域收官：725 条覆盖架构/上下文/多 Agent/工具/MCP/评测/安全/多模态/案例/治理/手写 11 分支，双 5000 达成（面试 720×7=5040/笔试≈6350），交接总交付（与 java-ai 域并列）
- **原理**：域收官的定义（JA-715 收官的 agent-dev 版）：地图分支全覆盖+双 5000+手册八册（AD-645），收官后进入手写套卷编写与总交付
- **常见误区**：
  1. 域无收官概念（错）
  2. 收官不需要清单（错）
  3. 地图分支有缺口（错）
- **工程用法**：域收官管理
- **版本锚点**：实战方法论
