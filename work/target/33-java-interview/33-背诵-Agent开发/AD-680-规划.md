## 工具 · 规划（容量）

- **事实**：工具容量规划：工具下游容量（DB/API 承受力）→工具并发上限→Agent 并发上限（逐层推导），容量链对齐（JA-108 保护链）
- **原理**：工具容量规划（AD-340 的工具面），下游容量是天花板（JA-535），与容量知识联动
- **常见误区**：
  1. 工具容量无限（错）
  2. 规划不必要（错）
  3. 下游与 Agent 无关（错）
- **工程用法**：工具容量规划
- **版本锚点**：实战共识
