## 治理 · 合规（手册）

- **事实**：Agent 合规手册：合规矩阵（AD-601）+数据分级（JA-380）+审计（AD-097）+政策（JA-628）+监管响应（JA-630）五件，合规手册让合规可执行
- **原理**：合规手册的五件集成（合规治理的手册化），合规可执行（非纸面），与合规知识（JA-544）联动
- **常见误区**：
  1. 合规无手册（错）
  2. 手册不必要（错）
  3. 合规与执行脱节（错）
- **工程用法**：合规手册
- **版本锚点**：实战共识
