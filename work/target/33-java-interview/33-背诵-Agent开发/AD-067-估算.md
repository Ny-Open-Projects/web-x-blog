## 上下文 · 估算（计量）

- **事实**：上下文窗口的 token 估算：本地 tokenizer（jtokkit AI-263）估算决定裁剪时机（调用前判定能否装下）
- **原理**：超窗提交报错浪费一次调用，本地估算前置判定，估算与供应商计数有偏差留余量
- **常见误区**：
  1. 提交后由框架处理（错）
  2. 本地估算不必要（错）
  3. 估算与实际一致（留余量）（错）
- **工程用法**：窗口计量
- **版本锚点**：实战共识
