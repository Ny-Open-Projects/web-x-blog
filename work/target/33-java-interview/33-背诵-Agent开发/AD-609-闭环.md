## 治理 · 闭环（数据）

- **事实**：数据治理闭环：语料质量（JA-475）→知识缺口（JA-496）→补齐→验证（JA-475），数据治理与知识运营（JA-532）一体
- **原理**：数据治理的闭环化（JA-532 运营的治理面），数据质量 SLA（AD-707 契约），与数据知识联动
- **常见误区**：
  1. 数据治理无闭环（错）
  2. 闭环不必要（错）
  3. 与知识运营分开（一体更准确）（错）
- **工程用法**：数据闭环
- **版本锚点**：实战共识
