## 手写 · 扣分（评分）

- **事实**：手写常见扣分点：未恢复中断标志（AD-018 约定）/-5、工具结果未回填/-10、无终止条件/-15、预算未实现/-10、上下文未裁剪/-5，扣分点权重表
- **原理**：扣分点权重表让评分一致（AD-402 标准的细化），权重按严重度（正确性>健壮性>性能），与评分标准联动
- **常见误区**：
  1. 扣分凭感觉（错）
  2. 权重表不必要（错）
  3. 所有扣分等价（错）
- **工程用法**：扣分点权重
- **版本锚点**：实战共识
