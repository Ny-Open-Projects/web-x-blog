## 平台 · 市场（模板）

- **事实**：Agent 模板市场：经过评测的 Agent 模板（任务/宪法/工具组合）共享复用，模板质量分级
- **原理**：模板复用的市场机制（JA-623 模板库的平台化），质量分级（评测分数背书），与组件复用治理联动
- **常见误区**：
  1. 模板无法复用（错）
  2. 市场无质量分级（错）
  3. 复用导致同质化（错）
- **工程用法**：模板市场设计
- **版本锚点**：实战共识
