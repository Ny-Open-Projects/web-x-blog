## 手写 · 三版（变体）

- **事实**：手写变体三版：基础版（同步循环）/流式版（事件回调 AD-282）/并行版（多任务 AD-271），变体考察不同并发与流式能力
- **原理**：变体设计覆盖能力面（同一骨架的三种演化），面试按 JD 选变体（IO 密集选流式版），与并发模型（JA-297）联动
- **常见误区**：
  1. 手写只有一种版本（错）
  2. 变体无考察价值（错）
  3. 流式版最难所以不考（错）
- **工程用法**：手写变体设计
- **版本锚点**：实战共识
