## Agent · ROI（场景）

- **事实**：Agent 场景 ROI 判断：任务频率×人工成本×自动化可行度，三高场景优先（工单/报告/巡检），与内部工具先行（JA-441）联动
- **原理**：Agent 立项的决策框架（JA-027 ROI 公式化），频率低或可行性差的任务不值得，与 AI-027 联动
- **常见误区**：
  1. Agent 场景拍脑袋选（错）
  2. ROI 无法量化（错）
  3. 高频场景不一定适合（错）
- **工程用法**：场景决策框架
- **版本锚点**：实战共识
