## 面试 · 标准（评分）

- **事实**：Agent 面试评分标准：架构能力（P10 系统设计）/工程能力（落地细节）/安全意识（红线）/成本意识（治理）四维，评分四维（AD-402 的面试版）
- **原理**：面试评分的四维（AD-402 手写评分的面试版），四维覆盖 P10 要求，与评分标准联动
- **常见误区**：
  1. 面试评分凭感觉（错）
  2. 四维不必要（错）
  3. 标准无用（错）
- **工程用法**：面试评分标准
- **版本锚点**：实战共识
