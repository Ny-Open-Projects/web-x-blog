## 案例 · 成功（客服）

- **事实**：客户成功 Agent（CS）：客户健康分（使用数据工具）→流失预警→主动触达建议→健康报告，CS 的数据驱动续约
- **原理**：客户成功案例（数据工具+预警 Agent），健康分计算（数据 JA-452），触达人执行（JA-547 人主导），与 CS 知识联动
- **常见误区**：
  1. CS Agent 自动触达客户（错）
  2. 健康分无依据（错）
  3. 预警不需要（错）
- **工程用法**：客户成功案例
- **版本锚点**：实战共识
