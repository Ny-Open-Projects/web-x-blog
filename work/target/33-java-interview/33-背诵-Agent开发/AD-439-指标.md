## 记忆 · 指标（观测）

- **事实**：记忆可观测：命中率（检索命中比例）/注入量（token）/更新频率，记忆健康度三指标
- **原理**：记忆的观测指标（JA-468 的记忆面），命中率低=记忆库空或检索差，与观测知识联动
- **常见误区**：
  1. 记忆不需要观测（错）
  2. 命中率无意义（错）
  3. 三指标冗余（错）
- **工程用法**：记忆观测
- **版本锚点**：实战共识
