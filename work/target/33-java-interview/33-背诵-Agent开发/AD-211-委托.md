## 协作 · 委托（协议）

- **事实**：Agent 间任务委托消息结构：任务描述/约束/预算/验收标准/交付格式，委托即"结构化派单"
- **原理**：委托消息是主从模式的契约（AD-027），结构化派单让子 Agent 理解无歧义，与通信协议（AD-032）联动
- **常见误区**：
  1. 委托用自然语言随意描述（错）
  2. 结构与预算可省（错）
  3. 派单是简单传话（错）
- **工程用法**：委托消息设计
- **版本锚点**：实战共识
