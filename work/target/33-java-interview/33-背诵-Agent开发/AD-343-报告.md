## 评测 · 报告（对比）

- **事实**：评测版本对比报告：新旧版本按维度对比（成功率/成本/延迟/安全），报告含显著性（AD-164）与结论建议，报告是发布决策输入
- **原理**：对比报告的自动化（AD-342 存储的对比面），报告结构化（数据+结论），与发布评审（AD-336）联动
- **常见误区**：
  1. 对比靠人工看数据（错）
  2. 报告不进决策（错）
  3. 自动化报告无必要（错）
- **工程用法**：对比报告
- **版本锚点**：实战共识
