## 工具 · 调用（配额）

- **事实**：工具调用配额：单工具调用配额（下游配额对齐 JA-535），配额检查在调用前，配额告警（AD-394 同思想）
- **原理**：工具调用配额（下游配额的对齐面），配额超限错误反馈模型（JA-016），与配额知识联动
- **常见误区**：
  1. 工具调用无配额（错）
  2. 配额与下游无关（错）
  3. 超限直接失败（反馈让模型适应）（错）
- **工程用法**：工具配额
- **版本锚点**：实战共识
