## 循环 · 执行循环（骨架）

- **事实**：Agent 执行循环骨架：while（任务未完成 && 步数未超限 && 预算未耗尽）{ 调模型→执行工具→回填结果 }
- **原理**：三条件缺一不可：完成条件驱动终止、步数上限防死循环、预算防成本失控（JA-276/505 联动），手写 Agent 就是这个骨架
- **常见误区**：
  1. 循环只有完成条件一个判断（错）
  2. 步数上限可选（错）
  3. 预算与循环无关（错）
- **工程用法**：手写 Agent 的骨架
- **版本锚点**：实战共识
