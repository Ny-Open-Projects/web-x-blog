## 记忆 · 延迟（性能）

- **事实**：记忆检索延迟预算：记忆检索在 Agent 循环内（每次决策前），延迟预算独立（如 100ms），超预算降级（少注入）
- **原理**：记忆检索在关键路径（循环内检索），延迟预算与降级策略（JA-667 同思想），与延迟知识联动
- **常见误区**：
  1. 记忆检索延迟无影响（错）
  2. 预算不需要（错）
  3. 降级不存在（错）
- **工程用法**：记忆延迟
- **版本锚点**：实战共识
