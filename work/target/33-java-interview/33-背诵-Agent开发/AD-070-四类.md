## 记忆 · 四类（分类）

- **事实**：Agent 记忆四分类：工作记忆（当前上下文）/情景记忆（历史交互事件）/语义记忆（事实与偏好）/程序性记忆（学到的操作模式），分类指导存储选型
- **原理**：认知科学分类映射工程组件（窗口/事件库/向量库/模板），不同记忆读写模式不同，分类是记忆架构设计的第一步
- **常见误区**：
  1. 记忆只有一种类型（错）
  2. 分类是学术概念无工程价值（错）
  3. 所有记忆同一种存储（错）
- **工程用法**：记忆分类架构
- **版本锚点**：实战共识
