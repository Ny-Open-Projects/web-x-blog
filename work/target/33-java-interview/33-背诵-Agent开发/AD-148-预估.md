## 工程 · 预估（成本）

- **事实**：Agent 执行前成本预估 API：按任务类型+历史轨迹估算 token 与费用（JA-401 模拟器的 API 化），超预估阈值需确认
- **原理**：成本预估让用户/系统决策（值不值得跑），预估模型基于历史轨迹统计（JA-135 数据），与预算池（AD-500→JA-461 联动）
- **常见误区**：
  1. 成本无法预估（错）
  2. 预估 API 无价值（错）
  3. 预估与历史无关（错）
- **工程用法**：成本预估 API
- **版本锚点**：实战共识
