## 手写 · 数据类（工具）

- **事实**：ToolDefinition 数据类：name/description/parametersSchema/executor 四字段，注册表（AD-051）的条目结构
- **原理**：四字段是工具的最小完备描述（与 MCP ToolSpecification 对齐 JA-176），数据类设计清晰则注册与执行解耦
- **常见误区**：
  1. 工具定义只有函数指针（错）
  2. description 是可选字段（错）
  3. schema 与定义分离（错）
- **工程用法**：ToolDefinition 设计
- **版本锚点**：实战共识
