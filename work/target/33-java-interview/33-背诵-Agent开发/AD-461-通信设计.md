## 协作 · 通信设计（节奏）

- **事实**：多 Agent 协作的同步/异步设计：同步（链式等待结果）vs 异步（消息驱动继续），同步简单异步解耦，按任务时效选
- **原理**：同步与异步的协作节奏（与 MQ-032 push/pull 选型同构），同步链路故障放大（JA-073 级联），异步需处理任务状态（AD-021）
- **常见误区**：
  1. 协作全同步最简单（错）
  2. 异步无需状态管理（错）
  3. 按时效与故障面选（错）
- **工程用法**：协作节奏设计
- **版本锚点**：实战共识
