## 评测 · 与单测（分层）

- **事实**：Agent 评测与单元测试的分层：单测测工具逻辑（mock 模型）/评测测 Agent 行为（真实或 mock 剧本）/线上影子测真实分布，三层不互相替代
- **原理**：JA-481 金字塔的 Agent 版：三层各回答不同问题（逻辑对/行为对/真实好），混淆层级让测试低效，与测试策略联动
- **常见误区**：
  1. 评测替代单测（错）
  2. 三层可以合并（错）
  3. 分层是过度设计（错）
- **工程用法**：Agent 测试分层
- **版本锚点**：实战共识
