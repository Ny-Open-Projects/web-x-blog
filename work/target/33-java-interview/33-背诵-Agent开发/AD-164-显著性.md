## 评测 · 显著性（统计）

- **事实**：Agent 成功率的统计显著性：任务集样本量决定结论可信度（小样本差异是噪声），给最小样本量公式（按预期差异计算）
- **原理**：评测结论的统计纪律（AI-213 延伸到 Agent），样本不足的"提升"是幻觉，与实验设计联动
- **常见误区**：
  1. 样本量无关（错）
  2. 差异明显即可信（错）
  3. 统计是企业过度设计（错）
- **工程用法**：评测统计纪律
- **版本锚点**：实战共识
