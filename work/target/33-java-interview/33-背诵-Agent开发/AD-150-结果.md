## 工程 · 结果（缓存）

- **事实**：Agent 任务结果缓存：同幂等键任务（AD-057）结果缓存（重复任务秒回），缓存与轨迹关联（命中记录）
- **原理**：任务结果缓存是幂等的兑现（AD-057），缓存键设计（任务参数 hash+版本 AD-059），与缓存策略（RD-067）联动
- **常见误区**：
  1. 任务结果不缓存（错）
  2. 缓存有正确性问题（错）
  3. 幂等与缓存无关（错）
- **工程用法**：结果缓存
- **版本锚点**：实战共识
