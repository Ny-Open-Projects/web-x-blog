## 记忆 · 性（可靠）

- **事实**：记忆可靠性：备份（AD-473）+多副本（存储层）+一致性（AD-437），记忆可靠性三件
- **原理**：记忆可靠性的实现面（AD-473 的扩展），多副本与一致性权衡（JA-014 NWR 联动），与可靠性知识联动
- **常见误区**：
  1. 记忆丢失可接受（错）
  2. 可靠性三件不必要（错）
  3. 一致性永远强（错）
- **工程用法**：记忆可靠性
- **版本锚点**：实战共识
