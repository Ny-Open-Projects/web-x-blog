## 手写 · 敏感（扫描）

- **事实**：敏感信息扫描实现：正则规则（身份证/手机号/密钥模式）+词典扫描输出与 prompt（JA-349 双向），命中处理（阻断/替换/告警分级 AD-537）
- **原理**：敏感扫描的代码实现（入站与出站两处 JA-349），分级处理（硬阻断 vs 替换），与合规扫描（JA-262）联动
- **常见误区**：
  1. 敏感扫描只做一次（错）
  2. 分级处理不必要（错）
  3. 正则扫描足够（词典补充）（错）
