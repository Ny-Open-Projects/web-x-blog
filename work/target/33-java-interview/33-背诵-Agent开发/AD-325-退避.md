## 手写 · 退避（重试）

- **事实**：Agent 重试实现：指数退避+jitter（JA-021 算法），重试只对可重试异常（JA-606 Transient），重试次数进预算（AD-303）
- **原理**：重试的代码实现（退避算法手写或 resilience4j Retry），可重试判定（异常分类），与重试知识联动
- **常见误区**：
  1. 重试立即连续重试（错）
  2. 所有异常都重试（错）
  3. 重试与预算无关（错）
- **工程用法**：重试实现
- **版本锚点**：实战共识
