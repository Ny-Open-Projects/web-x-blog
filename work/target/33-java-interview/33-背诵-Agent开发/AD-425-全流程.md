## 案例 · 全流程（运维）

- **事实**：运维 Agent 全流程：告警接入→分诊（AD-222）→预案执行（确认）→复盘记录→知识回流（runbook 更新），闭环设计
- **原理**：运维 Agent 的闭环设计（执行→学习闭环 JA-135），预案知识回流让 Agent 越用越强，与运维案例（AD-124/222）联动
- **常见误区**：
  1. 运维 Agent 无闭环（错）
  2. 预案不更新（错）
  3. 复盘记录无用（错）
- **工程用法**：运维闭环案例
- **版本锚点**：实战共识
