## 手写 · 实现（取消）

- **事实**：任务取消实现：设置取消标志（AtomicBoolean）→循环每步检查→终止并收尾，已提交工具调用无法撤回（幂等/补偿 JA-505）
- **原理**：取消的协作式实现（与线程中断同思想 AD-018 类比），取消后收尾（清理/汇报），与优雅取消（JA-098）联动
- **常见误区**：
  1. 取消直接杀线程（错）
  2. 取消标志可选（错）
  3. 已执行操作可撤回（错）
- **工程用法**：取消实现
- **版本锚点**：实战共识
