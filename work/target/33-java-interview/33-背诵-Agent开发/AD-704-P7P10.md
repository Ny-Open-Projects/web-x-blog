## 面试 · P7P10（差异）

- **事实**：P7 与 P10 的 Agent 面试差异：P7 考会用（框架/工具），P10 考治理（评测/成本/安全/组织），差异决定准备深度
- **原理**：P7-P10 差异的 Agent 面（AD-634 评分的职级面），P10 的治理与组织视角是分水岭，与职级体系（SP-017）联动
- **常见误区**：
  1. P7 与 P10 考的一样（错）
  2. 治理不是 P10 的考项（错）
  3. 差异只在代码能力（错）
- **工程用法**：P7P10 差异
- **版本锚点**：实战共识
