## 编排 · 传播（失败）

- **事实**：子 Agent 失败传播策略：子失败→父重试（换子 Agent）→父降级（跳过该子任务并标注）→父失败，逐级降级
- **原理**：失败传播设计决定系统韧性（JA-286 的编排面），跳过并标注比整体失败好（部分结果有价值），与降级链（JA-053）联动
- **常见误区**：
  1. 子失败导致父必失败（错）
  2. 降级无标注（错）
  3. 传播无需设计（错）
- **工程用法**：失败传播
- **版本锚点**：实战共识
