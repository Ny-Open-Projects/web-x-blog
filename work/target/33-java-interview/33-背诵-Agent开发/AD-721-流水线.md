## 工程 · 流水线（CI/CD）

- **事实**：Agent CI/CD 流水线：代码提交（单测 AD-201）→评测抽样（AD-666）→门禁（AD-387）→灰度发布（AD-388），CI/CD 覆盖代码与配置（JA-402 三元组）
- **原理**：CI/CD 的 Agent 面（评测/门禁/灰度的流水线集成），三元组变更全走流水线，与 CI/CD 知识联动
- **常见误区**：
  1. Agent 无 CI/CD（错）
  2. 流水线不必要（错）
  3. 配置变更不走流水线（错）
- **工程用法**：CI/CD 流水线
- **版本锚点**：实战共识
