## 安全 · 测试（外泄）

- **事实**：数据外泄测试：构造诱导场景（让 Agent 读敏感数据+外发），验证外泄路径防线（AD-178）全部拦截
- **原理**：外泄测试的构造（JA-178 路径的测试化），每条路径有测试用例，与外泄防线联动
- **常见误区**：
  1. 外泄测试不必要（错）
  2. 路径防线足够无需测（错）
  3. 测试用例难以构造（路径可构造）（错）
- **工程用法**：外泄测试
- **版本锚点**：实战共识
