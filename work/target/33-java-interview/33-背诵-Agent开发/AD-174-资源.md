## 安全 · 资源（DoS）

- **事实**：Agent 拒绝服务面：诱导无限循环/超大任务烧钱（恶意或无意），防线=双上限（AD-017）+任务配额（AD-099）+异常检测（成本曲线）
- **原理**：DoS 是成本维度攻击（JA-299 成本攻击的 Agent 面），防线让"恶意用户"的破坏有上限，与限流三级（JA-206）联动
- **常见误区**：
  1. Agent 不会被 DoS（错）
  2. 循环用户无恶意（错）
  3. 配额限制影响体验（安全优先）（错）
- **工程用法**：Agent DoS 防线
- **版本锚点**：实战共识
