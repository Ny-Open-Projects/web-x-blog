## 安全 · 报告（审计）

- **事实**：Agent 访问审计报告：周期生成（谁在什么时候让 Agent 做了什么），审计报告面向合规与管理（AD-334 的 Agent 面）
- **原理**：访问审计报告的生成面（AD-334 的定期化），审计报告是治理资产（JA-630 备战），与审计知识联动
- **常见误区**：
  1. 访问审计无报告（错）
  2. 周期报告不必要（错）
  3. 报告与合规无关（错）
- **工程用法**：访问审计报告
- **版本锚点**：实战共识
