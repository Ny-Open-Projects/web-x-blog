## 安全 · 投毒（记忆）

- **事实**：Agent 记忆投毒：恶意输入让错误信息写入长期记忆（JA-504 污染的攻击面），后续会话持续被污染，防线=写回审计+记忆异常检测
- **原理**：记忆投毒是持久化攻击（一次注入长期生效），写回审计（JA-504 策略的执行）+异常检测（记忆内容突变告警），投毒恢复=记忆回滚
- **常见误区**：
  1. 记忆投毒不存在（错）
  2. 写入即正确（错）
  3. 投毒影响有限（错）
- **工程用法**：记忆投毒防线
- **版本锚点**：实战共识
