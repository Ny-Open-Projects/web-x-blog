## 上下文 · 策略族（超窗）

- **事实**：超窗处理策略族：截断（丢最旧）/摘要（压缩历史）/拒绝（提示过复杂拆任务），按任务类型配置
- **原理**：JA-223 预算的执行族：策略选择影响任务成败（硬截断丢关键信息），拒绝策略让复杂任务显式失败（可拆），策略可配置
- **常见误区**：
  1. 超窗自动完美处理（错）
  2. 截断是唯一策略（错）
  3. 拒绝策略损害体验（错）
- **工程用法**：超窗策略族
- **版本锚点**：实战共识
