## 治理 · 流程（准入）

- **事实**：Agent 准入评审流程实现：评审工单（架构评审 AD-524 材料清单）→评审会→结论记录→准入/整改，流程线上化（工单系统）
- **原理**：准入流程的工程实现（工单化让评审可追溯），评审材料模板化（JA-413 风险清单），与治理组织（AD-159）联动
- **常见误区**：
  1. 准入口头过（错）
  2. 流程实现不必要（错）
  3. 材料无模板（错）
- **工程用法**：准入流程实现
- **版本锚点**：实战共识
