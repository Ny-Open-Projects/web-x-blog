## 工程 · 热路径（优化）

- **事实**：Agent 热路径优化：循环内的热路径（消息构建/工具分发/token 计数）的性能优化（对象复用/缓存），热路径优化让步均延迟下降
- **原理**：热路径的识别与优化（AD-313 指标定位），优化有基准（AD-339 性能基线），与性能工程联动
- **常见误区**：
  1. Agent 无性能问题（错）
  2. 热路径不需要优化（错）
  3. 优化无度量（基线支撑）（错）
- **工程用法**：热路径优化
- **版本锚点**：实战共识
