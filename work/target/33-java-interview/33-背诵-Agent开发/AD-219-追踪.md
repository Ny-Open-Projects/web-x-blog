## 演进 · 追踪（效益）

- **事实**：Agent 成本效益持续追踪：单位任务成本（JA-417）与人工基线对比趋势，ROI 转负触发治理
- **原理**：Agent 的经济性是动态（成本漂移/人工流程变化），ROI 追踪让 Agent 值得性持续验证，与成本观测（JA-462）联动
- **常见误区**：
  1. ROI 上线时算一次（错）
  2. 追踪无必要（错）
  3. 转负不管（错）
- **工程用法**：效益追踪
- **版本锚点**：实战共识
