## 记忆 · 质量（测试）

- **事实**：记忆质量测试：写入正确性（写入可读回）/检索相关性（期望记忆命中）/隔离性（用户间不串 JA-208），记忆测试三件
- **原理**：记忆组件的测试面（与工具测试 AD-237 同构），隔离测试是红线（JA-097），与测试知识联动
- **常见误区**：
  1. 记忆不需要测试（错）
  2. 三件测试冗余（错）
  3. 隔离测试可选（错）
- **工程用法**：记忆测试
- **版本锚点**：实战共识
