## 上下文 · 评测（压缩）

- **事实**：上下文压缩的质量评测：压缩后任务继续成功率对比（压缩 vs 不压缩），压缩策略变更过评估（JA-661 同纪律）
- **原理**：压缩有损（JA-023 风险），压缩质量要评测（压缩策略是"prompt 变更"同级），评测驱动压缩调参，与压缩知识（JA-269）联动
- **常见误区**：
  1. 压缩无损不需要评测（错）
  2. 压缩策略随意换（错）
  3. 评测压缩成本高（抽样可控）（错）
- **工程用法**：压缩评测
- **版本锚点**：实战共识
