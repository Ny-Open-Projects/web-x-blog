## 工程 · 实现（隔离）

- **事实**：Agent 资源隔离实现：任务级资源配额（token/并发/沙箱资源），配额实现（信号量/容器限额），隔离防单任务拖垮全局
- **原理**：资源隔离的实现（AD-500 预算池的资源面），配额实现（信号量并发 JA-320），与隔离知识（AD-503）联动
- **常见误区**：
  1. 资源隔离不必要（错）
  2. 配额实现复杂（信号量简单）（错）
  3. 隔离与配额无关（错）
- **工程用法**：资源隔离实现
- **版本锚点**：实战共识
