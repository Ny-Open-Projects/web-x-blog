## 协作 · 策略（测试）

- **事实**：多 Agent 测试策略：单 Agent 测试（各自 mock）+组合测试（真实协作链），两层策略防"单好组合差"
- **原理**：分层测试（AD-201 的多 Agent 版）：单 Agent 好不代表协作好（组合行为），组合测试覆盖协作协议，与测试金字塔联动
- **常见误区**：
  1. 单 Agent 测试足够（错）
  2. 组合测试是过度设计（错）
  3. 两层可以合并（错）
- **工程用法**：多 Agent 测试策略
- **版本锚点**：实战共识
