## 协作 · 因果（调试）

- **事实**：跨 Agent 因果链重建：从轨迹重建"决策因果链"（哪个决策导致哪个结果），因果链是调试多 Agent 的钥匙
- **原理**：因果链重建（JA-674 观测的调试深化），轨迹含决策上下文（AD-040 记录决策依据），与轨迹知识联动
- **常见误区**：
  1. 多 Agent 无法调试（错）
  2. 因果链不存在（错）
  3. 调试只看最终结果（错）
- **工程用法**：因果链重建
- **版本锚点**：实战共识
