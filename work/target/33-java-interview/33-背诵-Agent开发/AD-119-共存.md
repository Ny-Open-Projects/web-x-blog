## MCP · 共存（版本）

- **事实**：MCP 工具多版本共存：create_order_v1/v2 并行注册，客户端按能力选择，v1 下线走弃用公告（JA-391 思想）
- **原理**：工具 API 演进与 REST API 版本管理同构（破坏性变更共存过渡），共存让客户端迁移平滑，与契约演进（JA-308）联动
- **常见误区**：
  1. 工具原地改版（错）
  2. 版本共存不必要（错）
  3. 下线立即删除（错）
- **工程用法**：工具版本共存
- **版本锚点**：实战共识
