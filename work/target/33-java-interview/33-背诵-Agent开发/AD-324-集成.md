## 手写 · 集成（熔断）

- **事实**：Agent 熔断集成（resilience4j）：ChatClient 调用点包熔断器（错误率/慢调用率触发），熔断打开快速失败走降级
- **原理**：熔断的代码集成（JA-154 的实现面），熔断与重试的顺序（先重试后熔断判断），与熔断知识（DF-022）联动
- **常见误区**：
  1. Agent 调用无需熔断（错）
  2. resilience4j 不适用（错）
  3. 熔断与重试顺序随意（错）
- **工程用法**：熔断集成
- **版本锚点**：实战共识
