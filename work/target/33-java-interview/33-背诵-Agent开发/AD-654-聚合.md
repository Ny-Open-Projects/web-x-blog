## 协作 · 聚合（监控）

- **事实**：Agent 群体监控聚合视图：全群体大盘（AD-416 系统层）+可下钻单 Agent（AD-207），聚合视图是群体的驾驶舱
- **原理**：聚合视图的驾驶舱定位（群体健康的单屏），下钻路径（群体→Agent→任务→轨迹），与监控大盘（AD-207/398）联动
- **常见误区**：
  1. 监控只有单 Agent 视图（错）
  2. 聚合视图是过度设计（错）
  3. 下钻不可实现（错）
- **工程用法**：群体监控聚合
- **版本锚点**：实战共识
