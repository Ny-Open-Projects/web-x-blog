## 安全 · 基线（门禁）

- **事实**：安全基线与门禁：安全分数基线（上线时分数）+门禁（低于基线阻断发布），安全回归（JA-720）驱动分数
- **原理**：安全门禁的实现（JA-387 的安全维），基线管理（AD-165 同思想），与安全分数（AD-587）联动
- **常见误区**：
  1. 安全无门禁（错）
  2. 基线不必要（错）
  3. 门禁可选（错）
- **工程用法**：安全门禁
- **版本锚点**：实战共识
