## 安全 · 上下文（污染）

- **事实**：上下文污染攻击：多轮会话中逐步注入恶意上下文（每轮一点累积），防线=上下文内容审计（JA-673 的记忆审计面）
- **原理**：上下文污染是渐进注入（JA-172 会话劫持的深入），审计上下文内容（注入检测每轮 JA-393），与注入知识联动
- **常见误区**：
  1. 上下文污染不存在（错）
  2. 逐轮注入可检测（错）
  3. 防线只有首轮（错）
- **工程用法**：上下文污染防线
- **版本锚点**：实战共识
