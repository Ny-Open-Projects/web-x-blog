## 测试 · 工具（断言）

- **事实**：Agent 测试断言工具：封装常用断言（assertToolCalled(name,times)/assertTrajectoryLength/assertFinalOutput），断言工具让测试可读
- **原理**：断言工具化让测试表达业务语义（JA-248 断言清单的代码化），可读断言降低维护成本，与测试工程联动
- **常见误区**：
  1. 断言散写在测试里（错）
  2. 断言工具是过度设计（错）
  3. 可读性无关紧要（错）
- **工程用法**：断言工具化
- **版本锚点**：实战共识
