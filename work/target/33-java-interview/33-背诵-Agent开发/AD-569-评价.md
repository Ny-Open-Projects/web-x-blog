## 案例 · 评价（电商）

- **事实**：电商评价分析 Agent：评价聚类（JA-496 意图）+情感分析+问题归因（商品/物流/客服），归因驱动运营改进，评价量大（HyperLogLog 式聚合思维 JA-429 不适用——评价是全文本）
- **原理**：评价分析的规模化（海量文本的批量处理 JA-437），归因驱动商品改进（JA-496 聚类），评价数据是质量信号源
- **常见误区**：
  1. 评价分析纯人工（错）
  2. 聚类无价值（错）
  3. 归因不需要（错）
- **工程用法**：评价分析案例
- **版本锚点**：实战共识
