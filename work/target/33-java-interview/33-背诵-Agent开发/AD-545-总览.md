## 评测 · 总览（矩阵）

- **事实**：评测多维矩阵总览：功能×安全×性能×成本四维×版本序列，矩阵总览一眼看“哪个维度退化”，与雷达图（JA-484）联动
- **原理**：评测矩阵的总览（JA-484 的维度全集），矩阵驱动发布决策（JA-343 报告），与评测体系收束联动
- **常见误区**：
  1. 评测只看功能维（错）
  2. 矩阵总览不必要（错）
  3. 维度越少越好（错）
- **工程用法**：评测矩阵总览
- **版本锚点**：实战共识
