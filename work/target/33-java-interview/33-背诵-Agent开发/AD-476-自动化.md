## 工具 · 自动化（文档）

- **事实**：工具文档自动化：从代码注解生成工具文档（描述/参数/示例自动汇编），文档与代码同步（JA-015 描述纪律的自动化）
- **原理**：文档自动化防"文档漂移"（代码改文档没改），生成源是单一真源（代码注解），与文档自动化工具联动
- **常见误区**：
  1. 工具文档手写维护（错）
  2. 自动化不必要（错）
  3. 漂移无影响（错）
- **工程用法**：工具文档自动化
- **版本锚点**：实战共识
