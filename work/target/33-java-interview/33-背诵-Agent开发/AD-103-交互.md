## 调试 · 交互（步进）

- **事实**：Agent 交互式步进调试：逐步执行（每步暂停查看上下文/决策），可修改后继续（调试器语义）
- **原理**：Agent 调试的交互式形态（JA-093 重放的交互版），步进让"Agent 为什么这么走"可见，与 IDE 调试器思想同构
- **常见误区**：
  1. Agent 调试只能看日志（错）
  2. 步进执行无法实现（错）
  3. 调试工具是过度设计（错）
- **工程用法**：步进调试设计
- **版本锚点**：实战共识
