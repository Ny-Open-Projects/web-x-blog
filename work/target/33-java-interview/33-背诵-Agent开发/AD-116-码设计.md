## MCP · 码设计（错误）

- **事实**：MCP 工具错误码设计：业务错误（可重试/不可重试）与协议错误分层，错误 message 写给模型读（可自我修复 JA-016）
- **原理**：错误码与错误文案双设计（码给程序、message 给模型），模型读得懂才能自修复，与工具容错（AD-016）联动
- **常见误区**：
  1. 错误码随意定（错）
  2. message 给用户看（错）
  3. 错误设计与模型无关（错）
- **工程用法**：错误设计
- **版本锚点**：实战共识
