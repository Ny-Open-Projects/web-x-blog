## 治理 · 计费（平台）

- **事实**：Agent 平台计费实践：按 token 成本加平台服务费（成本加成）或按任务计费（业务友好），计费透明（账单可查 JA-332）
- **原理**：平台计费的两模式（JA-626 的平台面），计费透明让业务信任（账单可查），与平台运营（AD-407）联动
- **常见误区**：
  1. 平台不计费（错）
  2. 计费不透明（错）
  3. 模式单一（错）
- **工程用法**：平台计费实践
- **版本锚点**：实战共识
