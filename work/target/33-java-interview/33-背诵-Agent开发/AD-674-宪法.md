## 安全 · 宪法（泄露）

- **事实**：system prompt 泄露防护：诱导模型输出 system prompt（宪法泄露=攻击面全暴露），防线=宪法保密指令+输出过滤（JA-458 宪章模式匹配）
- **原理**：宪法泄露的防护（宪法是"密钥级"资产），输出中宪法内容检测（前缀匹配），与输出安全（AD-458）联动
- **常见误区**：
  1. 宪法泄露无危害（错）
  2. 泄露防护不必要（错）
  3. 宪法内容可公开（错）
- **工程用法**：宪法泄露防护
- **版本锚点**：实战共识
