## 手写 · 异步（轨迹）

- **事实**：轨迹异步写入实现：内存队列（BlockingQueue）+后台消费线程批量落库，主循环只入队（不阻塞），队列满丢弃策略（采样）
- **原理**：异步写入让轨迹不拖慢主循环（AD-040 异步落地），队列满策略（丢调试保审计 AD-106 分级），与异步日志实践联动
- **常见误区**：
  1. 轨迹同步写（阻塞主循环）（错）
  2. 异步队列是过度设计（错）
  3. 队列满必须阻塞（错）
- **工程用法**：轨迹异步化
- **版本锚点**：实战共识
