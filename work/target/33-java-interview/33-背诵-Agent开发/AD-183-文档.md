## 多模态 · 文档（案例）

- **事实**：文档理解 Agent 案例：发票/合同/报告混合文档流（版面分析 JA-545→字段抽取→校验），多文档类型路由到不同抽取模板
- **原理**：文档理解是多模态 Agent 的最成熟落地（JA-431/546 组装），模板路由按文档类型（JA-144 工具包思想），产出进业务系统
- **常见误区**：
  1. 文档理解纯人工（错）
  2. 单模板处理所有文档（错）
  3. 抽取结果直接可信（错）
- **工程用法**：文档 Agent 案例
- **版本锚点**：实战共识
