## 记忆 · 实现（删除）

- **事实**：记忆删除实现：用户删除权（AD-075 主体权利）→级联删除（向量/索引/备份 JA-473）→删除审计（JA-622），删除三步
- **原理**：删除路径的三步（JA-075 主体权利的落地），级联删除（备份也要删 JA-473），与删除合规联动
- **常见误区**：
  1. 删除只删主存储（错）
  2. 三步是过度设计（错）
  3. 备份保留删除记录（合规要求）（错）
