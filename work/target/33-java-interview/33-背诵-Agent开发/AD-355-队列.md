## 上下文 · 队列（优先）

- **事实**：上下文条目优先级队列：裁剪时按优先级保留（宪法>当前任务>工具结果>历史），优先级随任务阶段更新
- **原理**：裁剪的优先级实现（AD-023 策略的代码化），优先级模型（哪些必留），与裁剪策略族联动
- **常见误区**：
  1. 裁剪按时间顺序（错）
  2. 优先级无法建模（错）
  3. 所有内容同级（错）
- **工程用法**：优先级裁剪
- **版本锚点**：实战共识
