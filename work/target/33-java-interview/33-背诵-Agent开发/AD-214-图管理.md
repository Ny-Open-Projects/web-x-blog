## 协作 · 图管理（依赖）

- **事实**：多 Agent 任务依赖图管理：子任务依赖关系显式化（DAG AD-129 的 Agent 级），调度按依赖拓扑执行
- **原理**：依赖图让编排正确性可验证（AL-024 拓扑），依赖错误=结果错乱，依赖图可视化（运维友好）
- **常见误区**：
  1. 依赖靠 Agent 自己协调（错）
  2. 依赖图是过度设计（错）
  3. 拓扑执行不必要（错）
- **工程用法**：依赖图管理
- **版本锚点**：实战共识
