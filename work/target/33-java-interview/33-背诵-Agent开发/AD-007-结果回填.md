## 工具 · 结果回填（回填）

- **事实**：工具结果作为消息回填对话序列（工具角色消息），模型看到结果后继续推理
- **原理**：回填是循环的信息闭环（AD-003 的 Observe），结果格式化（JSON/摘要）影响下一轮推理质量
- **常见误区**：
  1. 工具结果直接返回用户（错）
  2. 结果不进对话序列（错）
  3. 回填格式无关推理（错）
- **工程用法**：信息闭环机制
- **版本锚点**：2025 共识
