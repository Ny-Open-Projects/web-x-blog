## 平台 · AgentSaaS（即服务）

- **事实**：Agent 即服务（内部平台）：任务模板/工具注册/评测/监控自助化，业务团队自助创建 Agent
- **原理**：JA-654 自助化的 Agent 版：平台化让长尾需求自助（JA-654 平台价值），模板（AD-060）+审核是质量门，与中台（JA-376）联动
- **常见误区**：
  1. 每个 Agent 手工开发（错）
  2. 平台化是过度设计（错）
  3. 自助化质量崩坏（模板+门禁保障）（错）
- **工程用法**：Agent 平台化
- **版本锚点**：实战共识
