## 安全 · 路径（外泄）

- **事实**：Agent 数据外泄路径分析：prompt 注入诱导读取敏感数据→经网络工具外发（JA-079/171 组合路径），路径分析画出"数据流出图"并逐路径设防
- **原理**：外泄路径的系统性分析（AI-099 数据流向的 Agent 版），每条路径有防线（路径穷举），与 DLP（数据防泄漏）思想联动
- **常见误区**：
  1. 外泄路径单一（错）
  2. 路径分析是过度设计（错）
  3. 防线只在一处（错）
- **工程用法**：外泄路径治理
- **版本锚点**：实战共识
