## 案例 · Agent（供应链）

- **事实**：供应链 Agent：库存查询+供应商比价+采购建议（人审批），多源数据工具（ERP/WMS API），异常检测（缺货预警）
- **原理**：供应链场景的多系统工具集成（AD-077 API 类），建议制（决策链长），数据时效（实时库存查询非检索）
- **常见误区**：
  1. 供应链 Agent 自动下单（错）
  2. 多源数据不需要（错）
  3. 库存靠模型记忆（错）
