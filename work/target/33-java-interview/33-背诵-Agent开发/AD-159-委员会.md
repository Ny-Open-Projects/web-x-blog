## 治理 · 委员会（组织）

- **事实**：Agent 治理委员会：新 Agent 场景准入评审（JA-524）/权限矩阵审批（JA-379 同思想）/事故复盘（JA-355），委员会是治理载体
- **原理**：Agent 规模化后的治理组织（多团队多 Agent 时代），委员会机制防失控（权限与场景发散），与治理组织（JA-384）联动
- **常见误区**：
  1. Agent 治理不需要组织（错）
  2. 委员会是形式主义（错）
  3. 准入自助即可（错）
- **工程用法**：治理组织设计
- **版本锚点**：实战共识
