## Agent · 基线（评测）

- **事实**：Agent 行为基线：每个版本的评测分数存档对比（JA-592 质量账本的 Agent 版），升级/改宪法前后对比
- **原理**：行为基线让 Agent 演进有据（改宪法=行为变更要对比），基线对比防"改好这坏"，与版本三元组（AD-059）联动
- **常见误区**：
  1. 基线对比不必要（错）
  2. 只看新版本分数（错）
  3. 行为不可比（错）
- **工程用法**：行为基线
- **版本锚点**：实战共识
