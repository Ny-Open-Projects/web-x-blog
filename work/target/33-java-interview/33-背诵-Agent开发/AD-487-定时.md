## 评测 · 定时（持续）

- **事实**：评测持续运行：定时评测（每日抽样跑 JA-392 静默更新检测+每周全量跑基线），评测调度（AD-345 优先级）
- **原理**：评测的持续运行机制（一次性评测到持续评测的运营跃迁），定时任务+调度，与评测运营（JA-471）联动
- **常见误区**：
  1. 评测只在发布跑（错）
  2. 持续运行不必要（错）
  3. 调度不必要（错）
- **工程用法**：评测持续运行
- **版本锚点**：实战共识
