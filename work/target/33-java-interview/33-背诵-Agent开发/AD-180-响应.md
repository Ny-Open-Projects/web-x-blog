## 安全 · 响应（应急）

- **事实**：Agent 事故应急响应流程：发现（监控告警 JA-501/520）→止血（工具开关 AD-106/权限收回 AD-179）→根因（轨迹回放 AD-093）→复盘（JA-355），Agent 专用响应流
- **原理**：Agent 事故的响应工具与传统不同（工具开关/权限收回/记忆回滚），runbook（JA-416）含 Agent 专章，与应急体系联动
- **常见误区**：
  1. Agent 事故按传统流程（错）
  2. 止血手段传统（有 Agent 专属手段）（错）
  3. 复盘可省（错）
- **工程用法**：应急响应设计
- **版本锚点**：实战共识
