## 可靠性 · 幂等（前提）

- **事实**：checkpoint 恢复的前提是工具幂等：从 checkpoint 重放会重复执行工具，幂等（JA-218）让重放安全
- **原理**：恢复正确性与工具幂等的强关联（JA-505 补偿的根），非幂等工具（发邮件）需要"执行前登记"模式
- **常见误区**：
  1. 重放不会重复执行工具（错）
  2. 幂等与恢复无关（错）
  3. 所有工具天然幂等（错）
- **工程用法**：恢复正确性
- **版本锚点**：实战共识
