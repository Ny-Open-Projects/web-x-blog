## 评测 · 查询（存储）

- **事实**：评测结果存储与查询：结果按版本/时间/任务类型入库，查询支持对比（版本间/任务间），存储是评测运营（JA-471）的基建
- **原理**：评测结果的存储设计（对比查询是运营需求），入库结构（版本+维度+分数），与评测看板（AD-254）联动
- **常见误区**：
  1. 评测结果打印即弃（错）
  2. 存储无结构（错）
  3. 查询不需要（错）
- **工程用法**：评测存储
- **版本锚点**：实战共识
