## 手写 · 并发（预算）

- **事实**：预算计数器线程安全：AtomicLong 累加 token（多 Agent 并发共享池），CAS 无锁累加，阈值判断用 getAndUpdate
- **原理**：并发预算（AD-500 池）的线程安全实现（AtomicLong 是标准答案），普通 long 累加有竞态（JA-058 联动），与原子类知识（JC-046）联动
- **常见误区**：
  1. 预算计数普通 long 即可（错）
  2. AtomicLong 不必要（错）
  3. 竞态不影响预算（错）
- **工程用法**：预算线程安全
- **版本锚点**：实战共识
