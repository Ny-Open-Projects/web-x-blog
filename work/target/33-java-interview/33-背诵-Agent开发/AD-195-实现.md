## 手写 · 实现（恢复）

- **事实**：checkpoint 实现：每步后序列化状态（消息序列+任务状态）→存储（内存/DB），恢复=反序列化+继续循环（AD-037 的代码面），幂等工具前提（AD-038）
- **原理**：checkpoint 的代码实现要点（序列化完整消息序列是关键），存储选型（内存调试/DB 生产），与恢复工程（JA-370）联动
- **常见误区**：
  1. checkpoint 不需要实现（错）
  2. 恢复自动完成（错）
  3. 只存任务状态不存消息（错）
