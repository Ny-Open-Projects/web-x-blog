## 手写 · 清单（缺陷）

- **事实**：手写 Agent 常见 bug 清单：消息序列错位（tool_call_id 不匹配）/终止条件遗漏（死循环）/工具结果未回填/并发上下文污染/预算未累计，五 bug 自查
- **原理**：手写常见 bug 的清单化（面试手写自查用，生产 review 用），每 bug 对应防线（JA-448 失败清单的代码面），与代码规范（AL-051）联动
- **常见误区**：
  1. 手写不会出 bug（错）
  2. 清单是形式主义（错）
  3. bug 无法预防（错）
- **工程用法**：手写 bug 清单
- **版本锚点**：实战共识
