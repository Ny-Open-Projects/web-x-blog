## 协作 · 规划（容量）

- **事实**：多 Agent 系统容量规划：总容量=Σ各 Agent 容量×协作放大系数（协作等待叠加），放大系数实测（JA-259 压测）
- **原理**：多 Agent 容量的协作放大（串行协作时长叠加），放大系数压测获得，与容量模型（AD-340）联动
- **常见误区**：
  1. 容量=单 Agent×数量（错）
  2. 放大系数不存在（错）
  3. 协作不影响容量（错）
- **工程用法**：协作容量规划
- **版本锚点**：实战共识
