## 协作 · 观察（涌现）

- **事实**：多 Agent 涌现行为观察：Agent 群体的整体行为（非单个可预测），涌现观察（轨迹聚合分析）发现系统性模式
- **原理**：多 Agent 系统有涌现（组合行为超单 Agent 设计），涌现观察发现意外模式（好/坏），与轨迹分析（JA-357）联动
- **常见误区**：
  1. 涌现行为不存在（错）
  2. 观察无价值（错）
  3. 系统行为完全可预测（错）
- **工程用法**：涌现观察
- **版本锚点**：实战共识
