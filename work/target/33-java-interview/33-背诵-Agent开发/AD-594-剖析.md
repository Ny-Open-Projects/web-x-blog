## 工程 · 剖析（延迟）

- **事实**：Agent 延迟剖析：首 token/工具耗时/循环轮次的延迟分布（JA-644 四象限的 Agent 版），延迟剖析定位体验瓶颈（TTFT 优化 JA-423）
- **原理**：延迟剖析的 Agent 面（JA-594 的轨迹耗时），首 token 与步进延迟分开，与延迟知识联动
- **常见误区**：
  1. 延迟剖析不必要（错）
  2. 只看总延迟（错）
  3. 剖析无优化价值（错）
- **工程用法**：延迟剖析
- **版本锚点**：实战共识
