## 运维 · 检测（循环）

- **事实**：循环检测实现：Agent 轨迹的重复模式检测（相同工具+相同参数连续 N 次=循环），检测到注入终止建议
- **原理**：循环的运行时检测（AD-017 步数上限的精细版：上限前发现循环），检测算法（滑动窗口比对），循环早停省钱
- **常见误区**：
  1. 循环只靠步数上限（错）
  2. 检测不必要（错）
  3. 终止建议无价值（错）
- **工程用法**：循环检测
- **版本锚点**：实战共识
