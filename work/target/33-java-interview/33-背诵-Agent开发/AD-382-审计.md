## 治理 · 审计（变更）

- **事实**：Agent 变更审计：宪法/工具/模型三元组变更（AD-059）全部留痕（变更人/时间/diff），变更审计与发布关联（未审计不可发布）
- **原理**：变更审计的实现（AD-059 版本化的审计面），未审计阻断发布（JA-525 门禁），与变更管理（JA-682）联动
- **常见误区**：
  1. 变更不需要审计（错）
  2. 审计与发布无关（错）
  3. diff 记录可选（错）
- **工程用法**：变更审计实现
- **版本锚点**：实战共识
