## 治理 · 共享（工具）

- **事实**：共享工具治理：共享工具市场（内部）注册/评测/版本/废弃流程，共享工具是平台资产（JA-473 同思想）
- **原理**：共享工具的治理（工具复用的治理面），市场流程（注册→评测→发布→废弃），与工具规范（AD-236）联动
- **常见误区**：
  1. 工具各自开发不共享（错）
  2. 共享无治理（错）
  3. 市场流程多余（错）
- **工程用法**：共享工具治理
- **版本锚点**：实战共识
