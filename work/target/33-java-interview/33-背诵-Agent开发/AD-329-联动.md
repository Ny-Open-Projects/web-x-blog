## 手写 · 联动（取消）

- **事实**：取消与清理联动实现：取消标志（AD-274）触发后，清理资源（沙箱容器/临时文件）+收尾汇报，取消不等于清理遗漏
- **原理**：取消与清理的联动（取消只停执行、清理回收资源），清理失败进补偿任务（JA-505），与清理知识（AD-261）联动
- **常见误区**：
  1. 取消后资源自动回收（错）
  2. 清理可省（错）
  3. 取消与清理无关（错）
- **工程用法**：取消清理联动
- **版本锚点**：实战共识
