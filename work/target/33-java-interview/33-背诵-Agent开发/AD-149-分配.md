## 工程 · 分配（超时）

- **事实**：Agent 任务超时预算分配：总预算按阶段拆分（规划/执行/验证），阶段超时独立管理（JA-107 三级的任务级）
- **原理**：长任务的阶段超时（DA-107 深化），阶段超限的处理（跳过/重试/收尾），与预算传递（DF-028）联动
- **常见误区**：
  1. 任务超时不分配（错）
  2. 阶段超时无意义（错）
  3. 超限只有失败一种处理（错）
- **工程用法**：阶段超时
- **版本锚点**：实战共识
