## 架构 · 自主性（权衡）

- **事实**：自主性与确定性权衡：自主性高（灵活）但不可控，确定性高（可控可测）但不灵活，按任务错误代价定
- **原理**：错误代价高的任务（支付/删除）要确定性（工作流/强人审），代价低的（总结/草稿）给自主性，与 JA-368 选型联动
- **常见误区**：
  1. 自主性越高越好（错）
  2. 权衡不存在（错）
  3. 按模型能力定自主性（错）
- **工程用法**：自主性权衡
- **版本锚点**：实战共识
