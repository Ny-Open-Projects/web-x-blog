## 工具 · 标准（观测）

- **事实**：工具可观测标准：四埋点（AD-240）+健康（AD-481）+SLA（AD-485）+追踪（AD-484）的标准组合，标准让所有工具观测一致
- **原理**：工具观测的标准组合（AD-240 的标准化），标准让工具面板统一（JA-468），与观测标准联动
- **常见误区**：
  1. 工具观测各自实现（错）
  2. 标准是过度设计（错）
  3. 一致性无价值（错）
- **工程用法**：工具观测标准
- **版本锚点**：实战共识
