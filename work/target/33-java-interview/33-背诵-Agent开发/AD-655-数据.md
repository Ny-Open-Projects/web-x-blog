## 协作 · 数据（契约）

- **事实**：Agent 间数据契约：Agent A 输出 schema 与 Agent B 输入 schema 的契约管理（变更影响分析），契约是协作的接口治理
- **原理**：数据契约防"上游改了下游崩"（JA-308 契约演进的 Agent 面），契约测试（JA-282）进协作 CI，与契约知识联动
- **常见误区**：
  1. Agent 间无契约（错）
  2. 契约管理不必要（错）
  3. 变更无影响分析（错）
- **工程用法**：数据契约管理
- **版本锚点**：实战共识
