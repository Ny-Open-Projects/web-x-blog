## MCP · MCP vs API（选型）

- **事实**：MCP 与直接 API 集成选型：MCP（生态复用/动态发现/标准化）vs 直接 API（定制深/无中间层），工具数量少且固定时直接 API 简单
- **原理**：选型按工具规模与生态需求（JA-090 对比的 Agent 侧），MCP 的价值在生态与动态性，单工具固定场景直接集成更简
- **常见误区**：
  1. MCP 永远优于直接 API（错）
  2. 直接 API 过时（错）
  3. 选型与规模无关（错）
- **工程用法**：MCP 选型
- **版本锚点**：实战共识
