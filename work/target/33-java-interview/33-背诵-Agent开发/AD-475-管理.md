## 记忆 · 管理（容量）

- **事实**：记忆容量管理：记忆条数/存储量增长监控（JA-694 同思想），容量驱动归档（JA-668）与合并（AD-469），增长预测
- **原理**：记忆容量的增长治理（膨胀是默认趋势 JA-160），监控+归档+合并三招，与容量管理联动
- **常见误区**：
  1. 记忆容量无管理（错）
  2. 增长监控不必要（错）
  3. 归档与合并重复（错）
- **工程用法**：记忆容量治理
- **版本锚点**：实战共识
