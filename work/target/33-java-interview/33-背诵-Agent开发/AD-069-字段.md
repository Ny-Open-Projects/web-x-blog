## 上下文 · 字段（裁剪）

- **事实**：工具结果的结构化裁剪：JSON 结果按字段白名单筛选（只留模型需要的字段），而非全量回填
- **原理**：工具返回对象通常远大于模型所需（全量回填浪费 JA-256），字段白名单按工具声明，裁剪后语义完整
- **常见误区**：
  1. 工具结果全量回填（错）
  2. 裁剪破坏数据（错）
  3. 白名单按模型需求设计（错）
- **工程用法**：工具结果裁剪
- **版本锚点**：实战共识
