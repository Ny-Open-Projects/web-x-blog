## 手写 · 实现（解析）

- **事实**：工具调用解析器实现：模型输出的工具调用 JSON→参数对象（schema 校验 AD-016），解析失败包装为错误反馈（模型重试）
- **原理**：解析器是模型与执行器的桥梁（AD-006 协议的代码面），解析失败处理（反馈而非崩溃），与 JSON 处理实践联动
- **常见误区**：
  1. 解析器不需要失败处理（错）
  2. JSON 解析总成功（错）
  3. 解析与 schema 无关（错）
- **工程用法**：解析器实现
- **版本锚点**：实战共识
