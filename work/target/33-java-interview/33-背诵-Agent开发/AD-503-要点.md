## 手写 · 要点（多租户）

- **事实**：Agent 多租户实现要点：租户上下文传递（AD-097）+配额隔离（AD-099）+记忆隔离（AD-072）+检索隔离（JA-669）四层，层层有隔离才可多租户
- **原理**：多租户四层（任何一层缺失即串号/成本污染），四层联动测试（AD-208 串号测试），与租户架构（AD-331）联动
- **常见误区**：
  1. 租户隔离自动完成（错）
  2. 四层是过度设计（错）
  3. 配额与租户无关（错）
- **工程用法**：多租户四层
- **版本锚点**：实战共识
