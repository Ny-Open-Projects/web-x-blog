## 演进 · 视觉工具（多模态）

- **事实**：多模态 Agent：视觉工具（看图/读表/截图理解）加入工具集，Agent 从文本扩展到视觉任务（JA-433 GUI Agent 的基础）
- **原理**：视觉工具让 Agent 触达"非文本世界"（文档/图表/屏幕），工具协议已支持（JA-093 content 类型），与多模态（AI-041）联动
- **常见误区**：
  1. Agent 只能处理文本（错）
  2. 视觉工具不存在（错）
  3. 多模态 Agent 无场景（错）
- **工程用法**：多模态 Agent
- **版本锚点**：实战共识
