## 面试 · 复习（主线）

- **事实**：MongoDB 复习主线：文档模型与建模→索引 ESR→副本集（oplog/选举/回滚/关注）→分片（键/reshard）→混合架构
- **原理**：P5-P6 考建模与索引，P7-P8 考副本集与分片机制，P9-P10 考混合架构与迁移，与 MySQL 知识同构可迁移
- **常见误区**：
  1. 分片最重要（错）
  2. 建模不重要（错）
  3. 与 MySQL 无关（错）
- **工程用法**：复习时间分配
- **版本锚点**：复习方法论
