## 存储引擎 · 压缩（压缩）

- **事实**：WiredTiger 支持块压缩（snappy 默认/zlib/zstd）与前缀压缩（索引）
- **原理**：磁盘占用显著降低（压缩比 2-5 倍），CPU 换空间，按数据特征选择压缩算法
- **常见误区**：
  1. 压缩默认关闭（错）
  2. 压缩不影响查询性能（错）
  3. zstd 是默认算法（错）
- **工程用法**：容量成本优化
- **版本锚点**：官方文档
