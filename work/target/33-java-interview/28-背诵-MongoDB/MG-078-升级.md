## 运维 · 升级（版本）

- **事实**：版本升级路径：4.x→5.0（reshard/时序集合）→6.0→7.0（查询引擎优化）
- **原理**：升级评估 feature compatibility version（先降级兼容设置），从库先升再切主灰度，驱动与 ODM 同步升级
- **常见误区**：
  1. 版本可直接跳级（错）
  2. 升级无兼容风险（错）
  3. featureCompatibility 无用（错）
- **工程用法**：版本治理
- **版本锚点**：官方文档
