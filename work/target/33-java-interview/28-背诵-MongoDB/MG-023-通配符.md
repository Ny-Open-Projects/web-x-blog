## 索引 · 通配符（通配符）

- **事实**：通配符索引（4.2+）对 schema 多变字段（子文档所有路径）建索引
- **原理**：{$**":1} 覆盖未知字段查询，代价是写放大与空间，schema 不可预估场景适用
- **常见误区**：
  1. 通配符索引性能更好（错）
  2. 通配符索引免费（错）
  3. 4.0 就有通配符索引（错）
- **工程用法**：异构属性查询
- **版本锚点**：官方文档
