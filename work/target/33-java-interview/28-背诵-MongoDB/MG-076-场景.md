## 运维 · 场景（故障）

- **事实**：故障场景预案：主库挂（自动选举）、从库延迟（摘读流量）、config 挂（分片元数据不可用）、mongos 挂（路由层扩容）
- **原理**：每层故障有不同影响面与恢复动作（选举秒级/重同步小时级），预案按层文档化
- **常见误区**：
  1. 任何节点挂集群都不可用（错）
  2. config 挂不影响现有服务（元数据只读操作受影响）（错）
  3. mongos 是单点（错）
- **工程用法**：高可用预案
- **版本锚点**：实战方法论
