## 副本集 · 选举（选举）

- **事实**：主库挂触发选举：多数派投票、term 递增、日志新度优先，通常数秒完成
- **原理**：日志新度（oplog 位置最靠前）保证新主数据最新，priority 影响优先级，选举期间无法写
- **常见误区**：
  1. 选举选举数据最新的从库（是日志最靠前者）（错）
  2. term 不重要（错）
  3. 选举期间可以读（secondary 读也受影响需客户端处理）（错）
- **工程用法**：故障转移机制
- **版本锚点**：官方文档
