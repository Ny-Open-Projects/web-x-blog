## 建模 · 时序集合（时序）

- **事实**：时序集合（time series，5.0+）专为指标/日志优化（自动分桶列式存储）
- **原理**：meta 字段（设备 ID 等）分组分桶，自动过期（expireAfterSeconds），压缩率与查询效率优于手工分集合，是 5.0 后时序场景首选
- **常见误区**：
  1. 时序集合是普通集合加索引（错）
  2. 5.0 之前有原生时序集合（错）
  3. 时序集合不支持任何索引（错）
- **工程用法**：监控指标/设备数据落地
- **版本锚点**：官方文档
