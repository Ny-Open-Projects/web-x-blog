## 分片 · 三原则（分片键）

- **事实**：分片键三原则：高基数、查询必带、写分布均匀
- **原理**：单调递增值（ObjectId 全打到最后分片）用 hashed 分片解，查询不带分片键全分片广播，官方文档核对（选型同 MySQL 分片键原则）
- **常见误区**：
  1. 分片键随意选不影响性能（错）
  2. 单调递增键最优（错）
  3. 查询不带分片键自动路由（错）
- **工程用法**：分片键是 MongoDB 最重大的一次性决策
- **版本锚点**：官方文档核对
