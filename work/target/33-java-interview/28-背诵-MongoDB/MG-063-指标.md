## 运维 · 指标（监控）

- **事实**：MongoDB 监控核心：opcounters（读写 QPS）、复制延迟、连接数、cache 使用、队列
- **原理**：ops/replication/wiredTiger cache 分节，队列（currentQueue）持续非零=瓶颈信号，Prometheus exporter 标准化
- **常见误区**：
  1. 监控只需看 CPU（错）
  2. 复制延迟无法监控（错）
  3. 队列是错误统计（错）
- **工程用法**：运维基线
- **版本锚点**：实战共识
