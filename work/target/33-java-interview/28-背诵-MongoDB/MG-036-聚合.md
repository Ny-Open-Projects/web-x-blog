## 聚合 · 聚合（管道）

- **事实**：聚合管道（aggregation pipeline）$match→$group→$sort→$project 等阶段流水处理
- **原理**：$match 前置走索引（效率关键），$group 内存默认 100MB 限制（allowDiskUse），与 SQL GROUP BY 同构
- **常见误区**：
  1. 聚合必须在应用层做（错）
  2. $match 顺序无关（错）
  3. $group 无内存限制（错）
- **工程用法**：报表统计类查询实现
- **版本锚点**：官方文档
