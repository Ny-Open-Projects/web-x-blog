## 索引 · multikey（多键）

- **事实**：数组字段自动建多键索引（每个数组元素一个索引项）
- **原理**：数组查询走索引，多键索引与 $in 组合时索引项爆炸（写放大），单文档多键索引有限制（一个数组字段）
- **常见误区**：
  1. 数组不能建索引（错）
  2. 多键索引是集合级（错）
  3. 多键索引性能优于普通索引（错）
- **工程用法**：标签/类目数组查询
- **版本锚点**：官方文档
