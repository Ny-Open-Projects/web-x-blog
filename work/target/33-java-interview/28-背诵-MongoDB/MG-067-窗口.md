## 运维 · 窗口（balancer）

- **事实**：balancer 迁移窗口配置（业务低峰迁移 chunk）
- **原理**：迁移消耗 IO 与网络（文档逐个搬），高峰迁移引发抖动，balanceWindow 限制时段，迁移速率限流
- **常见误区**：
  1. balancer 不影响业务（错）
  2. 迁移是瞬时的（错）
  3. balancer 必须一直开着不能配窗口（错）
- **工程用法**：分片运维细节
- **版本锚点**：官方文档
