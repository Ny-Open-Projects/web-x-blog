## 索引 · 覆盖查询（覆盖）

- **事实**：projection 排除 _id 且所有返回字段在索引中则覆盖查询免回表
- **原理**：explain 看 FETCH 阶段消失（PROJECTION_COVERED），与 MySQL 覆盖索引同构
- **常见误区**：
  1. 覆盖查询自动发生（错）
  2. _id 不排除也能覆盖（错）
  3. 覆盖查询更快是因为内存大（错）
- **工程用法**：查询优化技巧
- **版本锚点**：官方文档
