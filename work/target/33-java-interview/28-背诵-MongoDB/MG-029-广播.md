## 分片 · 广播（路由）

- **事实**：mongos 对不带分片键的查询广播全分片再聚合
- **原理**：广播是 O(分片数) 放大，QPS 高时全集群被拖累，查询必带分片键是性能第一原则
- **常见误区**：
  1. 广播自动优化不影响性能（错）
  2. 广播只在配置错误时发生（错）
  3. mongos 会缓存查询结果（错）
