## 架构 · 混合架构（混合）

- **事实**：主流混合架构：核心账务 MySQL+商品/内容/行为 MongoDB+搜索 ES，以 binlog/CDC 同步
- **原理**：按数据特征分工而非全替换，同步层（CDC）是最脆弱最值得投入的环节，对账兜底
- **常见误区**：
  1. 混合架构是过渡态最终会统一（错）
  2. MongoDB 与 MySQL 必须二选一（错）
  3. 同步层是可选组件（错）
- **工程用法**：大厂落地架构
- **版本锚点**：实战方法论
