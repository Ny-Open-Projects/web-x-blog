## 同步 · 幂等（CDC）

- **事实**：CDC 同步 MongoDB 侧要点：幂等写（upsert by _id）+乱序容忍（按版本号丢旧写）
- **原理**：消息重复与乱序是常态，upsert 保证幂等，updated_at 比较丢弃旧版本，Flink CDC 是推荐实现
- **常见误区**：
  1. CDC 同步保证有序可靠不需要幂等（错）
  2. upsert 会插入重复文档（错）
  3. 乱序自动丢弃（错）
- **工程用法**：同步层正确性设计
- **版本锚点**：实战共识
