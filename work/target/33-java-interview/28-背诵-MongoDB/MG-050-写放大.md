## 索引 · 写放大（代价）

- **事实**：索引越多写放大越大：每次写更新所有相关索引
- **原理**：与 MySQL 相同的权衡，集合索引数量控制（高频查询建索引，长尾查询接受扫描）
- **常见误区**：
  1. 索引越多查询越快无代价（错）
  2. 写放大只影响磁盘（错）
  3. 索引可以事后无限加（错）
- **工程用法**：索引治理原则
- **版本锚点**：实战共识
