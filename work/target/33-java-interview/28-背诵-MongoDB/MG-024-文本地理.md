## 索引 · 文本地理（特殊）

- **事实**：特殊索引：text（全文检索）、2dsphere（地理）、hashed（分片散列）
- **原理**：text 适合简单全文（复杂搜索用 ES），2dsphere 支持球面地理查询，hashed 用于 hashed 分片
- **常见误区**：
  1. text 索引可替代 ES（错）
  2. 2dsphere 是平面坐标（错）
  3. hashed 索引用于排序（错）
- **工程用法**：索引类型全景
- **版本锚点**：官方文档
