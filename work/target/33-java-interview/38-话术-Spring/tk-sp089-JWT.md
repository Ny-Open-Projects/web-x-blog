## 安全 · JWT（认证）—— 7 类问法与标准话术

**Qspring-617（概念考察·P1-P3）**
【面试官】请谈谈你对「安全」中「JWT」的理解。
【标准回答话术】JWT 无状态认证：签发→携带→过滤链校验签名。背后的原理是：服务端不存会话水平扩展友好，缺点：无法主动失效（需黑名单）、payload 明文（不放敏感信息、HS256/RSA 签名）。
【评分点】① 准确说出核心机制（JWT）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
