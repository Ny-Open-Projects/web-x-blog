## Agent · 资源池（预算）—— 7 类问法与标准话术

**Qjava-ai-4649（概念考察·P1-P3）**
【面试官】请谈谈你对「Agent」中「资源池」的理解。
【标准回答话术】Agent token 预算池按任务隔离：每任务独立预算池（超限熔断），任务间互不挤占。背后的原理是：JA-276 步数上限的资源版：步数防循环、预算池防成本，双重防线，预算池与租户预算（JA-461）联动。
【评分点】① 准确说出核心机制（资源池）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
