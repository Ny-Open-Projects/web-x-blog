## Spring AI · 订阅（流式）—— 7 类问法与标准话术

**Qjava-ai-799（概念考察·P1-P3）**
【面试官】请谈谈你对「Spring AI」中「订阅」的理解。
【标准回答话术】Flux 是冷流：不订阅不执行，ChatClient.stream 返回后必须有人订阅才发起模型调用。背后的原理是：响应式基本语义，误把 Flux 当 Future 用会导致"没有调用发生"的假象，与 SP/WebFlux 知识联动。
【评分点】① 准确说出核心机制（订阅）；② 能带出原理层而非背结论。 ③ 版本锚点：Spring AI 1.0 GA
