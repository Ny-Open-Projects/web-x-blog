## MCP · stdio（传输）—— 7 类问法与标准话术

**Qjava-ai-169（概念考察·P1-P3）**
【面试官】请谈谈你对「MCP」中「stdio」的理解。
【标准回答话术】MCP 传输层决定通信方式：stdio 常用于本地子进程，SSE/HTTP 用于远程服务。背后的原理是：Claude Desktop 等客户端以 stdio 子进程方式拉起本地 MCP server，远程共享则用 SSE transport，选型按部署形态。
【评分点】① 准确说出核心机制（stdio）；② 能带出原理层而非背结论。 ③ 版本锚点：MCP 规范
