## 工程 · 密钥管理（安全）—— 7 类问法与标准话术

**Qjava-ai-295（概念考察·P1-P3）**
【面试官】请谈谈你对「工程」中「密钥管理」的理解。
【标准回答话术】API key 管理：环境变量或配置中心注入，严禁提交仓库与打进镜像。背后的原理是：key 泄漏即计费风险与数据风险，Spring 的属性覆盖机制天然支持环境变量注入，与配置外部化知识（SP-087）联动。
【评分点】① 准确说出核心机制（密钥管理）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
