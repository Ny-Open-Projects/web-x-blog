**Qjava-ai-1205（概念考察·P1-P3）**
【面试官】请谈谈你对「Spring AI」中「本地化」的理解。
【标准回答话术】spring-ai-transformers 提供本地嵌入（ONNX 模型，免 API 调用）。背后的原理是：本地嵌入零成本零出域（AI-055 隐私联动），质量弱于云端旗舰嵌入模型，按场景分级选型。
