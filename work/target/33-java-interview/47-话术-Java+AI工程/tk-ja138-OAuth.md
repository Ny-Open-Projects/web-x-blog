## MCP · OAuth（鉴权）—— 7 类问法与标准话术

**Qjava-ai-960（概念考察·P1-P3）**
【面试官】请谈谈你对「MCP」中「OAuth」的理解。
【标准回答话术】MCP 2025 规范为 HTTP 传输引入 OAuth 鉴权框架（客户端授权访问远程 server）。背后的原理是：远程 server 的访问控制协议化（不再靠网络隔离），企业接入必备认知，与 SP-088 安全链知识互补。
【评分点】① 准确说出核心机制（OAuth）；② 能带出原理层而非背结论。 ③ 版本锚点：MCP 2025 规范
