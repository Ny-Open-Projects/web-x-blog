## MCP · 错误码（错误）—— 7 类问法与标准话术

**Qjava-ai-918（概念考察·P1-P3）**
【面试官】请谈谈你对「MCP」中「错误码」的理解。
【标准回答话术】MCP 基于 JSON-RPC 的错误码体系返回失败（方法不存在/参数错误/工具执行失败）。背后的原理是：错误处理按码分派（区别业务失败与协议失败），客户端把工具失败回喂模型重试。
【评分点】① 准确说出核心机制（错误码）；② 能带出原理层而非背结论。 ③ 版本锚点：MCP 规范
