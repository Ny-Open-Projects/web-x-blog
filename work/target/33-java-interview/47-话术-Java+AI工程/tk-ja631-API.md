## 工程 · API（架构）—— 7 类问法与标准话术

**Qjava-ai-4411（概念考察·P8-P10）**
【面试官】请谈谈你对「工程」中「API」的理解。
【标准回答话术】对外 AI API 设计要点：流式开关/幂等键（JA-467）/超时声明/配额头（剩余量）/错误码规范，API 即产品。背后的原理是：对外 AI API 与内部调用差异（契约/配额/SLA 显式化），与 REST 设计规范联动，网关强制（JA-317）。
【评分点】① 准确说出核心机制（API）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
