【标准回答话术】Spring AI 内置重试：spring.ai.retry 前缀配置最大尝试与退避策略。背后的原理是：模型服务限流与瞬时故障常见，框架层指数退避兜底，重试耗尽异常上抛由业务降级处理。
【评分点】① 准确说出核心机制（retry）；② 能带出原理层而非背结论。 ③ 版本锚点：Spring AI 1.0 GA
