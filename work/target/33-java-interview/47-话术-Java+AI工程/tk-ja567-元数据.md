## 工程 · 元数据（模板）—— 7 类问法与标准话术

**Qjava-ai-3963（概念考察·P1-P3）**
【面试官】请谈谈你对「工程」中「元数据」的理解。
【标准回答话术】prompt 版本元数据：作者/评审人/生效时间/评估分数/适用场景，模板即资产（JA-473 资产库的条目结构）。背后的原理是：资产库条目的元数据面（可检索可审计），元数据缺失则资产库退化为片段堆，与知识管理联动。
【评分点】① 准确说出核心机制（元数据）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
