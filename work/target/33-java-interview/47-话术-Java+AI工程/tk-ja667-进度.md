## Agent · 进度（体验）—— 7 类问法与标准话术

**Qjava-ai-4663（概念考察·P1-P3）**
【面试官】请谈谈你对「Agent」中「进度」的理解。
【标准回答话术】长任务阶段汇报：Agent 每完成阶段发进度事件（已完成/进行中/预计剩余），用户可中途干预。背后的原理是：长任务的可感知性（JA-425 多路流的应用），进度事件协议化（阶段/百分比/摘要），无进度=用户流失。
【评分点】① 准确说出核心机制（进度）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
