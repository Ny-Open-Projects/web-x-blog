## MCP · 子进程（生命周期）—— 7 类问法与标准话术

**Qjava-ai-659（概念考察·P1-P3）**
【面试官】请谈谈你对「MCP」中「子进程」的理解。
【标准回答话术】stdio 型 MCP server 由宿主客户端以子进程拉起（stdin/stdout 通信，生命周期随客户端）。背后的原理是：本地工具 server 随客户端启停（IDE/桌面端管理），server 崩溃即工具不可用，重连策略归客户端。
【评分点】① 准确说出核心机制（子进程）；② 能带出原理层而非背结论。 ③ 版本锚点：MCP 规范
