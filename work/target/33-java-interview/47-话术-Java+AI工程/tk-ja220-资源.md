## 工程 · 资源（部署）—— 7 类问法与标准话术

**Qjava-ai-1534（概念考察·P1-P3）**
【面试官】请谈谈你对「工程」中「资源」的理解。
【标准回答话术】LLM 应用自身资源需求：流式并发下 Netty/Servlet 线程占用、SSE 长连接数，容量规划与普通接口不同。背后的原理是：长连接+慢响应的并发模型（DF-090 并发=QPS×RT），RT 长导致并发数放大，容量按并发而非 QPS。
【评分点】① 准确说出核心机制（资源）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
