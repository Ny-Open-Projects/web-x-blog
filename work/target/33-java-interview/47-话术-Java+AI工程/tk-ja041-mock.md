## 工程 · mock（测试）—— 7 类问法与标准话术

**Qjava-ai-281（概念考察·P1-P3）**
【面试官】请谈谈你对「工程」中「mock」的理解。
【标准回答话术】LLM 应用可测性：ChatModel 是接口，单测注入 mock 实现（固定返回）隔离真实模型。背后的原理是：AI 应用测试原则：业务逻辑用 mock 模型测（快且确定），模型质量用评估集测（AI-034），两者分开。
【评分点】① 准确说出核心机制（mock）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
