## MCP · prompts（模板）—— 7 类问法与标准话术

**Qjava-ai-1289（概念考察·P1-P3）**
【面试官】请谈谈你对「MCP」中「prompts」的理解。
【标准回答话术】MCP prompts 原语提供服务端预置提示模板（带参数）供客户端取用。背后的原理是：把"优质提示词"生态化复用（客户端无需内置），与 resources/tools 并列（JA-143 三原语）。
【评分点】① 准确说出核心机制（prompts）；② 能带出原理层而非背结论。 ③ 版本锚点：MCP 规范
