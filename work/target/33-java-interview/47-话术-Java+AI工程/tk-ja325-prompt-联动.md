## 工程 · prompt 联动（灰度）—— 7 类问法与标准话术

**Qjava-ai-2269（概念考察·P1-P3）**
【面试官】请谈谈你对「工程」中「prompt 联动」的理解。
【标准回答话术】prompt 版本与灰度联动：灰度桶绑定 prompt 版本（桶内稳定），版本切换按桶推进。背后的原理是：prompt 灰度不是简单百分比（同桶内版本漂移会污染实验数据），与实验单元隔离（JA-271）联动。
【评分点】① 准确说出核心机制（prompt 联动）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
