## 多模态 · GUI Agent（桌面）—— 7 类问法与标准话术

**Qjava-ai-2955（概念考察·P1-P3）**
【面试官】请谈谈你对「多模态」中「GUI Agent」的理解。
【标准回答话术】GUI Agent（桌面/浏览器操作型 Agent）：视觉模型看屏+操作指令循环，2025 兴起方向（AI-071 趋势）。背后的原理是：Agent 从 API 工具扩展到 GUI 操作（无 API 的老系统自动化），Java 侧经 MCP/Playwright 类桥接，安全边界（操作审计）极重要。
【评分点】① 准确说出核心机制（GUI Agent）；② 能带出原理层而非背结论。 ③ 版本锚点：2025
