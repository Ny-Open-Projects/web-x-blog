## 工程 · 版本对齐（运维）—— 7 类问法与标准话术

**Qjava-ai-1527（概念考察·P6-P8）**
【面试官】请谈谈你对「工程」中「版本对齐」的理解。
【标准回答话术】框架版本与模型能力对齐：新模型新参数（如 reasoning/结构化模式）需要框架版本支持。背后的原理是：供应商新能力滞后于 API 发布（框架适配周期），升级框架才能用新参数，与 JA-175 锁版纪律平衡。
【评分点】① 准确说出核心机制（版本对齐）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
