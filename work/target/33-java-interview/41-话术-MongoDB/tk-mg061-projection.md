## 查询 · projection（投影）—— 7 类问法与标准话术

**Qmongodb-421（概念考察·P1-P3）**
【面试官】请谈谈你对「查询」中「projection」的理解。
【标准回答话术】projection 只取需要的字段减少网络与反序列化开销。背后的原理是：配合覆盖索引免 FETCH，大文档（嵌套深）查询必须投影，与 SQL select 列同理。
