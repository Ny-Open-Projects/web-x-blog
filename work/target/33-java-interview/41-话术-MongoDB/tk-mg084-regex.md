## 索引 · $regex（$regex）—— 7 类问法与标准话术

**Qmongodb-582（概念考察·P1-P3）**
【面试官】请谈谈你对「索引」中「$regex」的理解。
【标准回答话术】正则查询前缀锚定（/^abc/）可走索引，中间匹配（/abc/）全扫。背后的原理是：B 树按前缀有序，锚定前缀才能定位范围，大小写敏感选项（i）使前缀优化失效，与 MySQL like 前缀同构。
【评分点】① 准确说出核心机制（$regex）；② 能带出原理层而非背结论。 ③ 版本锚点：官方文档
