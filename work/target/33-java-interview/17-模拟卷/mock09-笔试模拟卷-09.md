## 参考答案与解析（自测后再看）

**1.1**（来源 ai）
**答案：C**
**解析：** 量化（INT8/INT4）：降低模型精度换推理速度与显存（4bit 约 1/4 显存），精度损失可控。原因：边缘/本地部署的基础技术（消费级显卡跑 7B-14B），GPTQ/AWQ/GGUF 格式，量化后需评估精度回归，与 LoRA 组合（QLoRA）。

**1.2**（来源 algorithm）
**答案：C**
**解析：** 堆：完全二叉树数组存储（i 子节点 2i+1/2i+2），插入/删除 O(logN) 查顶 O(1)。原因：Java PriorityQueue 默认小顶堆，大顶堆用 Collections.reverseOrder()，建堆 O(N)（自底向上下沉）比逐个插入 O(NlogN) 优。

**1.3**（来源 java-ai）
**答案：D**
**解析：** Spring AI 的 advisor 机制：.advisors(...) 挂载拦截链，请求在调用模型前后经过 advisor。原因：RAG 检索、对话记忆、日志审计都以 advisor 实现，业务代码组合 advisor 即可叠加能力，是 Spring AI 的扩展主轴。

**1.4**（来源 agent-dev）
**答案：C**
**解析：** 会话隔离验证自动化：隔离测试（JA-208）进 CI（并发两会话注入不同标记，断言互不串），隔离回归每次发布跑。原因：隔离验证的自动化（JA-208 的 CI 化），隔离是红线（JA-097）所以回归必跑，与 CI 纪律联动。

**1.5**（来源 java-basics）
**答案：C**
**解析：** JDK7 的 CHM 用 Segment 分段锁（默认 16 段，段继承 ReentrantLock），并发度等于段数。原因：分段把锁竞争分散，但并发度上限固定、hash 到同段的操作仍串行。

**1.6**（来源 concurrency）
**答案：B**
**解析：** DelayQueue 按到期时间出队元素必须实现 Delayed 接口。原因：内部优先堆按剩余延迟排序，take 阻塞到队首到期，用于订单超时关单等延迟任务（小规模方案，大规模用时间轮或 RocketMQ 延迟消息）。

**1.7**（来源 jvm）
**答案：D**
**解析：** 方法内联是 JIT 最重要的优化且是其他优化的前提。原因：把被调方法体展开进调用方消除调用开销并扩大优化视野，热点小方法自动内联，方法过大不内联。

**1.8**（来源 spring）
**答案：B**
**解析：** @PostConstruct 方法由 CommonAnnotationBeanPostProcessor 在初始化阶段调用。原因：JSR-250 注解，Spring 用 BPP 桥接实现，依赖注入完成后才执行。

**1.9**（来源 mysql）
**答案：A**
**解析：** 半同步复制：主库等至少一个从库收到 binlog（ACK）才返回客户端。原因：降低宕机丢事务风险，异步复制主库宕机可能丢最新事务，semi-sync 超时降级异步（rpl_semi_sync_master_timeout），8.0.26+ 半同步内置为 lossless 复制选项。

**1.10**（来源 redis）
**答案：A**
**解析：** RDB 快照 save（阻塞）/bgsave（fork 子进程）。原因：fork 利用写时复制（COW）主线程继续服务，期间写操作复制页导致内存可能翻倍，大实例 fork 是秒级停顿源。

**1.11**（来源 mongodb）
**答案：B**
**解析：** 连接 URI 携带 replicaSet 参数（副本集自动发现与故障切换的前提）。原因：指定 replicaSet 后驱动自动发现全部成员并在主挂时切换，不指定则只连单个节点（主挂不切换），高可用配置第一参数。

**1.12**（来源 mq）
**答案：A**
**解析：** 事务消息 vs 本地消息表：半消息方案免建表但绑定 RocketMQ，本地消息表通用但多一跳。原因：P10 答题框架：先说目标（业务与消息原子），再对比两方案实现与代价，最后给选型建议（已用 RocketMQ 选事务消息）。

**1.13**（来源 distributed）
**答案：C**
**解析：** 阿姆达尔定律：加速比受串行部分限制（串行 10% 则最高 10 倍加速）。原因：水平扩展的极限：全局锁/单点（DB 单库/中心授时）是串行部分，架构优化方向是削减串行段（分片/去中心），扩展性设计的理论指导。

**1.14**（来源 ai）
**答案：B**
**解析：** LLM 按 token 处理文本：中文约 1 字≈1-2 token，英文 1 词≈1.3 token，计费与上下文都按 token。原因：上下文窗口与费用都以 token 计，Prompt 长度预算与成本估算的基础单位，压缩提示（精简指令）直接省成本。

**1.15**（来源 algorithm）
**答案：C**
**解析：** Dijkstra：单源最短路（非负权），优先队列 O((V+E)logV)。原因：贪心每次取最近未定节点，负权失效（Bellman-Ford 处理），网络路由/地图导航基础，与负载均衡（响应时间加权）概念关联。

**2.1**（来源 java-ai）
**答案：B**
**解析：** 正确表述应为——金融场景 AI 特化：监管要求输出留痕可审计（JA-383）、免责声明强制、投资建议类强人工签发（JA-478 责任链）、模型与数据境内（JA-267）。原因：行业监管叠加通用治理：金融是合规最重行业（AI-054 强监管场景），架构上留痕/签发/境内三件套先行。

**2.2**（来源 agent-dev）
**答案：C**
**解析：** 正确表述应为——Agent 输出结构化：最终产出按 schema（结论/证据/步骤/置信度），程序可消费（JA-374 细化），输出质量纳入评测。原因：结构化输出让 Agent 从"演示"变"生产组件"（下游可集成），schema 是 Agent 的输出契约，与评测（JA-375）联动。

**2.3**（来源 java-basics）
**答案：B**
**解析：** 正确表述应为——String 是不可变类：内部 value 数组为 final 且不提供修改方法。原因：不可变保证常量池安全共享、hashCode 可缓存、天然线程安全。

**2.4**（来源 concurrency）
**答案：D**
**解析：** 正确表述应为——CompletableFuture 未指定线程时回调在完成线程或调用线程执行。原因：thenApply 不带 Async 由完成线程直接执行，thenApplyAsync(fn) 落到 ForkJoinPool.commonPool，IO 回调务必显式指定自定义线程池。

**2.5**（来源 jvm）
**答案：D**
**解析：** 正确表述应为——-Xms 与 -Xmx 设为相同值避免堆动态伸缩抖动。原因：堆动态扩容触发 Full GC 或影响延迟稳定性，服务器固定负载场景等值是标配，容器环境用 MaxRAMPercentage 更优。

**3.1**（来源 spring）
**答案：错。** 正确表述：ApplicationContext 是 BeanFactory 的超集增强版。原因：BeanFactory 基础容器懒加载，ApplicationContext 增加事件、国际化、资源加载、注解支持且默认预初始化 singleton

**3.2**（来源 mysql）
**答案：对。** 解析：count(*) 由优化器专门优化（任选最小索引数行），count(col) 需逐行判空，count(distinct col) 去重且忽略 null

**3.3**（来源 redis）
**答案：错。** 正确表述：架构选型：单机+哨兵（数据量小）/Cluster（分片需求）/多级（本地+Redis）。原因：数据量 <25GB 且无分片需求用主从+哨兵（简单可靠），超限或需要水平扩展才上 Cluster，避免过早分片

**3.4**（来源 mongodb）
**答案：错。** 正确表述：连接 URI 携带 replicaSet 参数（副本集自动发现与故障切换的前提）。原因：指定 replicaSet 后驱动自动发现全部成员并在主挂时切换，不指定则只连单个节点（主挂不切换），高可用配置第一参数

**3.5**（来源 mq）
**答案：错。** 正确表述：Kafka 客户端 OOM：max.poll.records 过大+消息大（批量内存），或消费者积压内存缓冲膨胀。原因：控制批大小与消息体、消费者内存监控，fetch.max.bytes 限制单次拉取，客户端也是要调优的 JVM

**3.6**（来源 distributed）
**答案：错。** 正确表述：一致性哈希（虚拟节点环）与槽位分片（固定槽映射）是两大分片流派。原因：一致性哈希节点增删迁移少但元数据在客户端（Cassandra/Dynamo），槽位分片路由表集中可控易迁移（Redis Cluster 16384 槽），按"迁移灵活性 vs 元数据复杂度"权衡

**3.7**（来源 ai）
**答案：错。** 正确表述：AI 面试深水区问题：幻觉怎么治理（工程手段）、成本怎么控（分级/缓存/压缩）、Agent 怎么生产化（护栏/审批/观测）、RAG 怎么评估（离线+在线）。原因：这些问题的回答框架都指向"工程治理"而非"模型调参"，Java P10 的差异化答题（把分布式可靠性经验迁移到 AI），禁绝对化（"RAG 消除幻觉"是错误表述）

**3.8**（来源 algorithm）
