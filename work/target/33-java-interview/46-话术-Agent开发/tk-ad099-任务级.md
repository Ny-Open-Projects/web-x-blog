## 工程 · 任务级（配额）—— 7 类问法与标准话术

**Qagent-dev-687（概念考察·P1-P3）**
【面试官】请谈谈你对「编排」中「意图」的理解。
【标准回答话术】路由 Agent：意图识别（分类）分发到对应专家 Agent/工作流，路由是"多 Agent 的入口调度员"。背后的原理是：多 Agent 系统的入口模式（JA-027 主从的变体），路由可用小模型（成本 JA-414），误路由的代价与路由准确率权衡。
【评分点】① 准确说出核心机制（意图）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识

【评分点】① 快速识别误区不顺着说；② 给出正确的版本锚定表述（实战共识）。
