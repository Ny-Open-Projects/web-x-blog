**Qagent-dev-4698（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「注册」的理解。
【标准回答话术】手写 Agent 的工具注册：Map<名称, 工具函数>注册表+描述列表（给模型），执行时按名称查表调用。背后的原理是：注册表模式是所有框架的工具管理本质（SP 框架的 ToolCallback 也如此），理解注册表=理解框架。
