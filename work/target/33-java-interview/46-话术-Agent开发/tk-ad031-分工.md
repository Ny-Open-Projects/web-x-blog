## 多Agent · 分工（角色）—— 7 类问法与标准话术

**Qagent-dev-211（概念考察·P1-P3）**
【面试官】请谈谈你对「多Agent」中「分工」的理解。
【标准回答话术】Agent 角色分工：planner（拆解）/executor（执行）/reviewer（审查）/reporter（汇报），角色=system prompt 差异。背后的原理是：角色化让职责单一（每个 Agent 宪法简单清晰），角色间契约明确，与 SRP 设计思想联动。
【评分点】① 准确说出核心机制（分工）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
