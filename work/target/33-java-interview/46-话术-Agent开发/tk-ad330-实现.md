## 治理 · 实现（计费）—— 7 类问法与标准话术

**Qagent-dev-2304（概念考察·P1-P3）**
【面试官】请谈谈你对「治理」中「管理」的理解。
【标准回答话术】Agent 版本元数据管理：版本号/宪法 hash/工具集 hash/模型配置/评测基线（AD-059 三元组的元数据化），元数据查询 API。背后的原理是：版本元数据的管理实现（三元组的可查性），hash 绑定让“行为指纹”可验证（配置漂移 JA-455 检测），与版本治理联动。
【评分点】① 准确说出核心机制（管理）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
