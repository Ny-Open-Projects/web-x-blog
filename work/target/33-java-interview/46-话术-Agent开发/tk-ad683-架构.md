## 工具 · 架构（插件）—— 7 类问法与标准话术

**Qagent-dev-4775（概念考察·P1-P3）**
【面试官】请谈谈你对「MCP」中「同名」的理解。
【标准回答话术】多 MCP server 接入的工具名冲突：同名工具（两个 server 都有 search）需命名空间消歧（server 前缀）。背后的原理是：多 server 是常态（JA-021 多连接），同名工具让模型选择混乱（歧义），命名空间是接入层职责。
【评分点】① 准确说出核心机制（同名）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
