## 编排 · 传播（失败）—— 7 类问法与标准话术

**Qagent-dev-925（概念考察·P1-P3）**
【面试官】请谈谈你对「安全」中「消息」的理解。
【标准回答话术】Agent 输出即外发消息的防线：Agent 生成邮件/消息发送（外发类工具），防线=输出审查链（AD-136）+收件人白名单+内容确认。背后的原理是：外发是"出域"动作（JA-171 防线的消息面），错误外发不可撤回（不可逆 AD-080 同级），外发工具三防。
【评分点】① 准确说出核心机制（消息）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
