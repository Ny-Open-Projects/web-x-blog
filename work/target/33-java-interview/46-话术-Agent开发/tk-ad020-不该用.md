## 架构 · 不该用（反模式）—— 7 类问法与标准话术

**Qagent-dev-134（概念考察·P1-P3）**
【面试官】请谈谈你对「架构」中「不该用」的理解。
【标准回答话术】不该用 Agent 的场景：固定流程（工作流更可控）、强一致要求（分布式事务）、毫秒延迟（Agent 多轮慢）。背后的原理是：Agent 不是万能（JA-018 权衡的反面清单），"能不用就不用"是 P10 判断（AI-049），误用 Agent 是架构债。
【评分点】① 准确说出核心机制（不该用）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识

**Qagent-dev-135（误用纠错·P4-P7）**
【面试官】我在别的团队见过这样的说法：「Agent 适用于一切场景」。你觉得对吗？
【标准回答话术】这个说法不正确。准确的表述是：不该用 Agent 的场景：固定流程（工作流更可控）、强一致要求（分布式事务）、毫秒延迟（Agent 多轮慢）。原因是：Agent 不是万能（JA-018 权衡的反面清单），"能不用就不用"是 P10 判断（AI-049），误用 Agent 是架构债。
【评分点】① 快速识别误区不顺着说；② 给出正确的版本锚定表述（实战共识）。
