【标准回答话术】消息四角色：system（宪法）/user（用户与任务）/assistant（模型输出含工具调用）/tool（工具结果），角色是协议结构。背后的原理是：角色让模型理解对话结构（谁说的/工具结果），角色混用是解析错误根源，与消息抽象（JA-076/088）对等。
【评分点】① 准确说出核心机制（四角色）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
