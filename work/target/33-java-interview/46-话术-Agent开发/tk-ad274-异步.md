## 手写 · 异步（轨迹）—— 7 类问法与标准话术

**Qagent-dev-1912（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「实现」的理解。
【标准回答话术】Agent 任务队列实现：BlockingQueue 或 Redis List（跨实例），入队（提交）/出队（工作线程 AD-328）/拒绝策略（队列满），队列深度可配。背后的原理是：任务队列的代码实现（单机 BlockingQueue 与分布式 Redis 版），队列深度与拒绝策略（AD-017 类比），与队列知识（RD-053）联动。
【评分点】① 准确说出核心机制（实现）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
