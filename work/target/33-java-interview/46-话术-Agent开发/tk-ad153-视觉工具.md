## 演进 · 视觉工具（多模态）—— 7 类问法与标准话术

**Qagent-dev-1065（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「实现」的理解。
【标准回答话术】轨迹记录器实现：每步追加轨迹条目（时间戳/类型/内容摘要/token），异步落库（JA-040 不阻塞主循环），轨迹 ID 关联任务。背后的原理是：轨迹记录器的实现要点（异步/结构化/可导出），记录器与 Agent 主逻辑解耦（观察者模式），与轨迹基建（AD-040）联动。
【评分点】① 准确说出核心机制（实现）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
