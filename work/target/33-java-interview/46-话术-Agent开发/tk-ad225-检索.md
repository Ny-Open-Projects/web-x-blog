**Qagent-dev-1569（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「必填」的理解。
【标准回答话术】参数必填校验：schema 的 required 字段缺失时返回“缺少参数 X”错误反馈，不做默认值猜测。背后的原理是：缺失必填参数时猜默认值会执行错误操作（隐错），显式报错让模型补全，与参数校验（JA-171 联动）。
【评分点】① 准确说出核心机制（必填）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
