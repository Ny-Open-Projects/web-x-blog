## 多模态 · 工具（手写）—— 7 类问法与标准话术

**Qagent-dev-2017（概念考察·P1-P3）**
【面试官】请谈谈你对「评测」中「查询」的理解。
【标准回答话术】评测结果存储与查询：结果按版本/时间/任务类型入库，查询支持对比（版本间/任务间），存储是评测运营（JA-471）的基建。背后的原理是：评测结果的存储设计（对比查询是运营需求），入库结构（版本+维度+分数），与评测看板（AD-254）联动。
【评分点】① 准确说出核心机制（查询）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
