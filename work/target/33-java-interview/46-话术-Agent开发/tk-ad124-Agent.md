**Qagent-dev-862（概念考察·P1-P3）**
【面试官】请谈谈你对「评测」中「数据集」的理解。
【标准回答话术】轨迹数据集构建：从线上轨迹（AD-040）抽取成功/失败样本，成功轨迹做 few-shot（JA-135）失败轨迹做评测（JA-531）。背后的原理是：轨迹是评测数据的最真实来源（合成任务失真），双通道分流（成功进示例/失败进评测），与数据飞轮（JA-452）联动。
【评分点】① 准确说出核心机制（数据集）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
