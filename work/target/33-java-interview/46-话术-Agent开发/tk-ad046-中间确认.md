## 交互 · 中间确认（确认）—— 7 类问法与标准话术

**Qagent-dev-316（概念考察·P1-P3）**
【面试官】请谈谈你对「交互」中「中间确认」的理解。
【标准回答话术】Agent 与用户的中间确认：关键动作（删除/支付）执行前请求用户确认（JA-259 人审的交互面），确认 UX 与超时策略。背后的原理是：自主性与确认的平衡：全自动体验 vs 安全（JA-018），确认点设计（哪些动作要确认）是产品决策，与 AI-068 联动。
【评分点】① 准确说出核心机制（中间确认）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
