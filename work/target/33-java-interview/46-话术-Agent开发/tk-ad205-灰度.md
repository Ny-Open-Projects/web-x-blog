## 工程 · 灰度（发布）—— 7 类问法与标准话术

**Qagent-dev-1429（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「序列」的理解。
【标准回答话术】多轮消息序列构建器实现：消息追加（user/assistant/tool）+窗口裁剪（AD-068 策略挂载）+序列导出（调模型），构建器封装序列操作。背后的原理是：构建器封装让序列操作不散落（散落是 bug 源 AD-200），裁剪策略作为构建器策略注入，与消息模型（AD-188）联动。
【评分点】① 准确说出核心机制（序列）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
