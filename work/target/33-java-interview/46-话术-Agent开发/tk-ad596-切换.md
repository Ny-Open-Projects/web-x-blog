## 工程 · 切换（灾备）—— 7 类问法与标准话术

**Qagent-dev-4166（概念考察·P1-P3）**
【面试官】请谈谈你对「协作」中「SDK」的理解。
【标准回答话术】Agent 团队的编程接口（Agent SDK）：任务提交/状态查询/结果获取/取消四 API 的 SDK 化（AD-281 接口的 SDK 封装），SDK 让协作标准化。背后的原理是：SDK 化让 Agent 间协作免协议细节（JA-567 生态的 Java 面），SDK 版本兼容（JA-565），与 API 设计（JA-641）联动。
【评分点】① 准确说出核心机制（SDK）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
