## 多Agent · 工作区（共享）—— 7 类问法与标准话术

**Qagent-dev-204（概念考察·P1-P3）**
【面试官】请谈谈你对「多Agent」中「工作区」的理解。
【标准回答话术】共享工作区（scratchpad）模式：多 Agent 读写同一工作区（文档/状态），协作更自然但需并发控制。背后的原理是：工作区是"共享内存"（JA-503 写冲突管控），版本与锁是工作区工程核心，与主从（传递式）对比：共享式耦合更高。
【评分点】① 准确说出核心机制（工作区）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
