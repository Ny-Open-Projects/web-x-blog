## 记忆 · 管理（时效）—— 7 类问法与标准话术

**Qagent-dev-3249（概念考察·P1-P3）**
【面试官】请谈谈你对「案例」中「服务台」的理解。
【标准回答话术】企业 IT 服务台 Agent：密码重置（自助工具）+权限申请（审批流 AD-333）+故障报修（工单），高频 IT 请求自动化（JA-441 ROI 场景）。背后的原理是：IT 服务台案例的高频自助（密码重置占 IT 服务量大头），审批流集成（AD-333），与内部工具案例（JA-441）联动。
【评分点】① 准确说出核心机制（服务台）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
