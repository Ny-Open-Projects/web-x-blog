## Agent · 基线（评测）—— 7 类问法与标准话术

**Qagent-dev-652（概念考察·P1-P3）**
【面试官】请谈谈你对「案例」中「分析」的理解。
【标准回答话术】数据分析 Agent：NL2SQL（JA-438 四防线）+执行+图表生成+解读，工具=数仓连接+图表库，产出=分析报告。背后的原理是：数据分析是"检索+计算+表达"复合任务（Agent 优势区），SQL 防线是安全核心（JA-438），报告结构化（AD-047）。
【评分点】① 准确说出核心机制（分析）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
