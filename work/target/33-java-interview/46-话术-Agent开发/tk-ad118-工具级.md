## MCP · 工具级（限流）—— 7 类问法与标准话术

**Qagent-dev-820（概念考察·P1-P3）**
【面试官】请谈谈你对「安全」中「输出即代码」的理解。
【标准回答话术】Agent 生成代码执行防线：生成代码→静态扫描（危险 API 黑名单）→沙箱执行（AD-077）→人工确认（高危），多层防线。背后的原理是：生成代码执行是最高危 Agent 能力（JA-156 沙箱的完整防线链），黑名单+沙箱+确认三层缺一，与代码沙箱纪律联动。
【评分点】① 准确说出核心机制（输出即代码）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
