## 工程 · 清单（评审）—— 7 类问法与标准话术

**Qagent-dev-1450（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「边界」的理解。
【标准回答话术】Agent 的异常边界设计：哪些异常往外抛（配置错误/认证失败=启动期 fail-fast），哪些内部消化（工具失败反馈模型），边界清晰。背后的原理是：异常边界的工程决策（启动期 fail-fast 与运行期反馈的分离），边界模糊导致"一半报错一半吞"，与异常处理（MY-087 类比）联动。
【评分点】① 准确说出核心机制（边界）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
