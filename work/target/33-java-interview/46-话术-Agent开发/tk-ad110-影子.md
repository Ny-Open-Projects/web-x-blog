**Qagent-dev-764（概念考察·P1-P3）**
【面试官】请谈谈你对「评测」中「指标」的理解。
【标准回答话术】Agent 探索度指标：工具多样性/路径多样性（低多样性=死板，过高=乱试），探索度与任务类型匹配。背后的原理是：轨迹指标（JA-375）的细化：探索度反映 Agent 决策健康度，确定性任务低探索、开放任务高探索，指标配任务类型。
