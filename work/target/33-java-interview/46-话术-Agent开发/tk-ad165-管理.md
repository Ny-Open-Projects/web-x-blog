【标准回答话术】长任务 Agent 分段验收：长任务（数小时）按阶段验收（每阶段产出达标再继续），避免跑完才发现早期错误。背后的原理是：长任务的验收策略（JA-255 状态机的验收面），早期错误晚发现成本高（重跑代价），分段验收与人审点（AD-168）结合。
