## 手写 · 幻觉工具（容错）—— 7 类问法与标准话术

**Qagent-dev-1828（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「实现」的理解。
【标准回答话术】历史摘要器实现：触发时取旧消息→小模型摘要（AD-065）→摘要替换原消息序列，摘要 prompt 模板化（保留任务目标/关键结论/未完事项）。背后的原理是：摘要器是窗口治理的执行件（AD-068 策略实现），摘要 prompt 是资产（JA-473 管理），摘要质量评估（压缩后任务继续成功）。
【评分点】① 准确说出核心机制（实现）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
