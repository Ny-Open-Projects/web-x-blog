## 工程 · 运维（手册）—— 7 类问法与标准话术

**Qagent-dev-4432（概念考察·P1-P3）**
【面试官】请谈谈你对「记忆」中「MaaS」的理解。
【标准回答话术】记忆即服务（Memory as a Service）：记忆能力服务化（统一 API 多 Agent 共享），服务化让记忆能力复用（AD-101 平台的记忆面）。背后的原理是：记忆服务化（AD-353 外部记忆的平台化），统一 API 让 Agent 免各自实现，与平台化（AD-102）联动。
【评分点】① 准确说出核心机制（MaaS）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
