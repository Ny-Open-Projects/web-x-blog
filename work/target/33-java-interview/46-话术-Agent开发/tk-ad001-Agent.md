## 架构 · Agent（定义）—— 7 类问法与标准话术

**Qagent-dev-1（概念考察·P1-P3）**
【面试官】请谈谈你对「架构」中「Agent」的理解。
【标准回答话术】Agent 的定义：能感知任务、自主决策（规划/反思）、调用工具行动、迭代直到完成目标的系统，与单轮问答的本质区别是"循环与自主决策"。背后的原理是：单轮问答一问一答结束，Agent 在循环中自主决定下一步（调工具/继续推理/结束），自主性是定义核心。
【评分点】① 准确说出核心机制（Agent）；② 能带出原理层而非背结论。 ③ 版本锚点：2025 共识
