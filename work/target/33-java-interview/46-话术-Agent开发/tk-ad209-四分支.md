【标准回答话术】Agent 单元测试断言清单：终止原因正确/消息序列完整（工具结果都回填）/轨迹步数符合/预算未超/脱敏生效，五断言最小集。背后的原理是：断言清单让 Agent 单测有章法（JA-048 五 bug 的测试面），断言遗漏=回归盲区，与测试断言实践联动。
