## 多Agent · 辩论（辩论）—— 7 类问法与标准话术

**Qagent-dev-197（概念考察·P1-P3）**
【面试官】请谈谈你对「多Agent」中「辩论」的理解。
【标准回答话术】辩论模式：多个 Agent 对同一问题独立作答后相互批评（互查漏洞），最终裁决者合并，质量敏感任务提升准确率。背后的原理是：独立视角+交叉批评降低单一模型偏见（与 AI-447 多模型投票同思想），成本×N，用于高风险决策而非日常。
【评分点】① 准确说出核心机制（辩论）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
