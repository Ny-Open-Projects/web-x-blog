## 循环 · 终止条件（终止）—— 7 类问法与标准话术

**Qagent-dev-29（概念考察·P1-P3）**
【面试官】请谈谈你对「循环」中「终止条件」的理解。
【标准回答话术】Agent 四类终止条件：任务完成（模型声明完成）、步数上限、预算耗尽、用户取消，终止后要有收尾动作。背后的原理是：只设计"成功终止"不设计"失败终止"是事故源（JA-004 的展开），收尾动作（清理/汇报/落轨迹）是完整性的标志。
【评分点】① 准确说出核心机制（终止条件）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
