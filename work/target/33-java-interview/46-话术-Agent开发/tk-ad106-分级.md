## 工程 · 分级（日志）—— 7 类问法与标准话术

**Qagent-dev-736（概念考察·P1-P3）**
【面试官】请谈谈你对「学习」中「few-shot」的理解。
【标准回答话术】跨任务学习：历史成功任务的轨迹摘要作为 few-shot 示例（相似任务检索注入），Agent 越用越熟练。背后的原理是：数据飞轮（JA-452）的 Agent 版：成功轨迹是最好的示例，检索注入（JA-013），失败轨迹不注入（JA-531 分类）。
【评分点】① 准确说出核心机制（few-shot）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
