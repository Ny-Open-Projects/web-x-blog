## 工程 · 实现（埋点）—— 7 类问法与标准话术

**Qagent-dev-2143（概念考察·P1-P3）**
【面试官】请谈谈你对「工具」中「指南」的理解。
【标准回答话术】工具版本迁移指南：旧工具→新工具迁移（参数映射/行为差异/客户端迁移），迁移指南是工具版本共存（AD-119）的配套文档。背后的原理是：工具迁移的文档化（共存期的迁移指引），迁移完成度追踪（客户端迁移率），与版本治理联动。
【评分点】① 准确说出核心机制（指南）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
