## 手写 · 清单（套卷）—— 7 类问法与标准话术

**Qagent-dev-4915（概念考察·P1-P3）**
【面试官】请谈谈你对「工程」中「模型」的理解。
【标准回答话术】模型升级对 Agent 行为影响：新模型工具调用风格变化（参数格式/多工具倾向）改变 Agent 轨迹，模型升级必须过 Agent 回归套件（JA-680）。背后的原理是：模型是 Agent 的"大脑"（AD-059 三元组），换脑=行为全变，回归是唯一保障（JA-094 基线），与模型升级纪律（JA-391）联动。
【评分点】① 准确说出核心机制（模型）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
