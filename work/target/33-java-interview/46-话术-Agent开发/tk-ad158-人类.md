**Qagent-dev-1100（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「mock」的理解。
【标准回答话术】mock 模型实现：ModelClient 的测试实现（按剧本返回预设响应序列），剧本驱动（AD-039），mock 也要模拟 token 计数（预算路径测试）。背后的原理是：mock 模型的实现要点（剧本序列化/usage 模拟/错误注入），mock 保真（AD-169）与可控平衡，与测试代码实践联动。
【评分点】① 准确说出核心机制（mock）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
