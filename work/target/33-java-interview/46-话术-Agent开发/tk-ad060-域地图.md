## 工程 · 域地图（主线）—— 7 类问法与标准话术

**Qagent-dev-414（概念考察·P1-P3）**
【面试官】请谈谈你对「记忆」中「矛盾」的理解。
【标准回答话术】记忆冲突处理：新旧记忆矛盾（用户改偏好）时新记忆优先+旧记忆归档，冲突检测靠写入时比对。背后的原理是：记忆不管理冲突导致行为不一致（JA-463），写入时检测（同主题覆盖），用户改偏好是常见触发。
【评分点】① 准确说出核心机制（矛盾）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
