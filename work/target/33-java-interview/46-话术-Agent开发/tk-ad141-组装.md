## 工程 · 组装（宪法）—— 7 类问法与标准话术

**Qagent-dev-981（概念考察·P1-P3）**
【面试官】请谈谈你对「安全」中「时间」的理解。
【标准回答话术】Agent 权限的时间边界：临时授权（JA-679 提权）带过期时间，任务结束权限自动收回（JA-500 动态授权的回收面）。背后的原理是：权限的时间边界防"提权永久化"（租约思想 DF-013），过期自动收回+回收审计，与权限生命周期管理联动。
【评分点】① 准确说出核心机制（时间）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
