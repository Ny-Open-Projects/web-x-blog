## 治理 · 流程（准入）—— 7 类问法与标准话术

**Qagent-dev-2647（概念考察·P1-P3）**
【面试官】请谈谈你对「治理」中「共享」的理解。
【标准回答话术】共享工具治理：共享工具市场（内部）注册/评测/版本/废弃流程，共享工具是平台资产（JA-473 同思想）。背后的原理是：共享工具的治理（工具复用的治理面），市场流程（注册→评测→发布→废弃），与工具规范（AD-236）联动。
【评分点】① 准确说出核心机制（共享）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
