## 架构 · 组成（四件套）—— 7 类问法与标准话术

**Qagent-dev-8（概念考察·P1-P3）**
【面试官】请谈谈你对「架构」中「组成」的理解。
【标准回答话术】Agent 四件套：LLM 大脑（决策）、工具（行动手脚）、记忆（上下文）、规划（任务分解）。背后的原理是：四件齐备才是完整 Agent，缺工具是纯聊天、缺规划是被动响应，架构设计从四件盘点起步。
【评分点】① 准确说出核心机制（组成）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
