**Qagent-dev-1639（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「并发」的理解。
【标准回答话术】预算计数器线程安全：AtomicLong 累加 token（多 Agent 并发共享池），CAS 无锁累加，阈值判断用 getAndUpdate。背后的原理是：并发预算（AD-500 池）的线程安全实现（AtomicLong 是标准答案），普通 long 累加有竞态（JA-058 联动），与原子类知识（JC-046）联动。
【评分点】① 准确说出核心机制（并发）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
