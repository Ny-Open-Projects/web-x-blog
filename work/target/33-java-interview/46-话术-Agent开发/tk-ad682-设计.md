## 工具 · 设计（SDK）—— 7 类问法与标准话术

**Qagent-dev-4768（概念考察·P1-P3）**
【面试官】请谈谈你对「Agent」中「版本」的理解。
【标准回答话术】工具版本升级对 Agent 行为影响：工具语义变化（参数/返回结构）改变 Agent 行为，工具版本纳入 Agent 版本三元组（AD-059）。背后的原理是：工具是 Agent 行为的组成部分（JA-059 三元组），升级工具=潜在行为变更，工具升级走评估回归（JA-680 套件）。
【评分点】① 准确说出核心机制（版本）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
