## 治理 · 管理（元数据）—— 7 类问法与标准话术

**Qagent-dev-2661（概念考察·P1-P3）**
【面试官】请谈谈你对「治理」中「合规」的理解。
【标准回答话术】评测数据合规：评测集含真实用户数据时的合规（脱敏 JA-252/授权），评测数据的法律边界与生产数据同要求。背后的原理是：评测数据的合规面（评测≠法外之地），脱敏与授权是评测集合规双件，与隐私知识（JA-198）联动。
【评分点】① 准确说出核心机制（合规）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
