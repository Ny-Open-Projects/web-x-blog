## 多模态 · 视觉（prompt）—— 7 类问法与标准话术

**Qagent-dev-1261（概念考察·P1-P3）**
【面试官】请谈谈你对「演进」中「Copilot」的理解。
【标准回答话术】Copilot 到 Agent 的演进谱系：Copilot（人主 AI 辅）→半自主（人审关键点）→全自主（人监督），演进按信任积累推进。背后的原理是：谱系帮助规划产品形态（信任未积累前上全自主是失败模式，AD-046 确认交互的谱系定位），与 AD-019 分类互补。
【评分点】① 准确说出核心机制（Copilot）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
