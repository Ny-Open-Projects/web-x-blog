## 多模态 · 任务（评测）—— 7 类问法与标准话术

**Qagent-dev-2150（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「聚合器」的理解。
【标准回答话术】Agent 流式事件聚合器实现：token 事件聚合为完整响应+工具事件单独收集，聚合器让流式消费端拿“分通道”结果（AD-282 流式的消费面）。背后的原理是：流式聚合是流式 Agent 的消费端实现（AD-221 双消费），聚合器封装分通道逻辑，与流式知识联动。
【评分点】① 准确说出核心机制（聚合器）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
