### Q6683 · 包年包月 / 预留实例与按量付费的成本分界：数据层的账

难度：P6 ｜ 标签：成本工程、计费模式、容量规划
基线：通用云计费模型（包年约为按量的 3-5 折，预留以承诺时长换折扣）。

**问**：团队的数据库与 Redis 有三类负载：7x24 常驻主库、白天 12 小时高峰的分析从库、每周两次 4 小时的离线跑批。三类负载分别该选包年包月还是按量？分界点的账怎么算？

**答**：**结论**：分界变量只有两个——**利用率与时长占比**。包年单价约为按量的 35-50%，但锁死规格与时长：7x24 常驻负载（利用率≈100%）包年必赢；时长占比 < 40% 且规格可弹性伸缩的负载按量通常更省；40%-60% 之间要看"削峰后能否降规格"——能把按量实例规格降一档，等效单价立刻改善。另外按量模式下磁盘、备份、流量等按真实用量计，包年模式这些也可能按预购容量计——账要含存储与 IO，不能只比实例单价。

**取舍**：包年的隐性成本是**规格刚性**：业务扩张要变更规格，有的云厂商不支持包年降配只支持升配，浪费沉淀在"最高水位规格"上。所以工程实践是**分层组合**：主库包年（稳态）+ 从库按量定时开关机（跟随业务时段）+ 跑批走 Serverless/按量（短时爆量）。从库用 API 定时启停（云厂商支持释放/重建或暂停计费）可以把 12h 高峰负载的账再压 50%，但要算上每次重建的数据恢复时间——恢复 30 分钟意味着每天多 0.5 小时不可用窗口。

**实战**：写一个通用分界计算器，评审时把三类负载各跑一遍：

```python
# 包年 vs 按量的成本分界计算器
def compare(on_demand_h: float, od_price: float, yearly_ratio: float = 0.4):
    """on_demand_h: 每天实际运行小时数；od_price: 按量每小时单价。"""
    cost_od = od_price * on_demand_h * 30          # 按量月成本
    cost_year = od_price * 24 * 30 * yearly_ratio  # 包年月成本（全月按折扣价）
    breakeven_h = cost_year / (od_price * 30)      # 盈亏平衡小时数
    return cost_od, cost_year, breakeven_h

od_price = 4.0  # 元/小时
loads = {
    "常驻主库 7x24": 24,
    "白天高峰从库": 12,
    "每周两次跑批": 4 * 2 / 7,   # 折算到每天
}
for name, h in loads.items():
    od, yr, be = compare(h, od_price)
    pick = "包年" if h > be else "按量"
    print(f"{name:10s} 日均 {h:5.1f}h | 按量 {od:8,.0f} 元/月 | "
          f"包年 {yr:8,.0f} 元/月 | 分界 {be:5.1f}h -> 选{pick}")

# 从库定时启停：12h 按量再打折（只跑 12h 已是按量账），对比降规格
od, _, _ = compare(12, od_price)
downsized = od * 0.55  # 高峰后降一档规格跑余量
print(f"\n从库按量 {od:,.0f} 元/月；高峰降规格组合约 {downsized:,.0f} 元/月；"
      f"包年 {od_price*24*30*0.4:,.0f} 元/月 -> 组合策略胜出")

# 包年的规格刚性成本：预估峰值误差
peak_error = 0.3  # 低估峰值 30%，包年被迫按最高水位购入
print(f"包年因规格刚性多付约 {od_price*24*30*0.4*peak_error:,.0f} 元/月")
```

**追问 1**：为什么时长占比 40%-60% 的灰区不能直接查表选？
提示：灰区结果取决于弹性能力——能随流量升降规格的负载等效单价显著改善；灰区决策要看 3 个月负载 P95 曲线而不看均值。

**追问 2**：预留实例（RI）与包年包月有什么差别？数据库场景怎么用？
提示：RI 是对按量实例的折扣承诺（可抵扣），保留规格灵活性，适合规格会变的负载；包年是实打实买机器，更便宜但刚性。数据库主从拓扑常主库包年、读副本 RI。

**追问 3**：从库定时启停的方案有什么运维代价？
提示：每次重建要恢复数据（快照+binlog 回放），恢复窗口不可用且拖慢备份链；替代方案是选支持暂停计费的实例类型，或用只读降配代替关机。

## 背诵要点
1. 分界只看利用率与时长占比：包年约为按量 4 折，时长占比 <40% 选按量、>60% 选包年、40-60% 看弹性能力。
2. 账要含存储/备份/流量，不只比实例单价；包年的隐性成本是规格刚性，浪费沉淀在最高水位规格。
3. 组合策略：常驻包年 + 高峰从库按时段启停/降配 + 短时跑批走按量/Serverless。
