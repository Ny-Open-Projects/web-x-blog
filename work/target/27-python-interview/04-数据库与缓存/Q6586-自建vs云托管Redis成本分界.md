### Q6586 · 自建 vs 云托管 Redis 的成本分界

难度：P6 ｜ 标签：Redis / 成本工程 / 选型

**问**：团队一套自建 Redis 主从每月云主机成本约 800 元，云托管同规格实例报价 3000 元。老板要求"全迁云托管"或"全自建二选一"，你怎么算这笔账？成本分界点在哪里？

**答**：
- **结论**：直接比机器价格是错的账。自建的真实成本 = 机器 + 人力（值班、升级、备份、故障演练）+ 隐性风险成本（一次未演练的故障恢复可能损失数小时 RTO）；托管的真实成本 = 实例费 + 部分仍有的人力（参数调优、客户端治理、成本监控）+ 锁定成本（备份格式、迁移工具是厂商私有的，回迁要付"搬运税"）。经验分界：小规模（<5 个实例、无专职 DBA）托管更省——人力占大头；大规模（几十个实例、有平台团队）自建或开源管控方案（如基于 K8s 的 Redis Operator）更省——机器单价差 × 规模会反超人力摊薄。临界点通常在"实例数 × 单实例差价 > 0.5 个 DBA 月成本"附近开始反转。
- **取舍**：更细的分层策略往往优于二选一：缓存类（可重建、丢了重启预热）用自建或 K8s 部署压成本；数据类（分布式锁、计数器、去重集合，丢了有业务后果）用托管买 SLA 与自动 failover。迁移回滚：托管 → 自建的回迁要提前验证 RDB/AOF 兼容导出与带宽成本（数据出云流量费有时一晚就吃掉一个月差价）。
- **实战**：算账模板：① 列自建全成本：机器 + 多机房冗余 + 每月人力小时数 × 单价 + 年度故障期望损失（故障概率 × MTTR × 业务时薪）；② 列托管全成本：实例费 + 出流量 + 同样的人力残项；③ 用"实例数"做敏感性分析找交叉点；④ 决策后写 ADR 记录假设，每季度复核一次（云厂商常改价、人力结构常变化）。

```python
# 自建 vs 托管 Redis 成本交叉点分析（纯标准库）
# 基线：Python 3.9+

def monthly_cost_selfbuilt(n: int, machine: float = 800,
                           labor_h: float = 6.0, labor_rate: float = 300,
                           incident_expected: float = 500) -> float:
    """自建：机器 + 每实例人力小时 + 期望故障损失"""
    return n * machine + n * labor_h * labor_rate + incident_expected


def monthly_cost_managed(n: int, price: float = 3000,
                         labor_h: float = 0.5, labor_rate: float = 300) -> float:
    """托管：实例费 + 少量人力残项"""
    return n * price + n * labor_h * labor_rate


def crossover(machine=800, price=3000, labor_rate=300) -> int:
    """求托管反超自建的实例数临界点"""
    n = 1
    while monthly_cost_managed(n, price, 0.5, labor_rate) <= \
          monthly_cost_selfbuilt(n, machine, 6.0, labor_rate):
        n += 1
    return n


def main() -> None:
    for n in (1, 5, 10, 20):
        s = monthly_cost_selfbuilt(n)
        m = monthly_cost_managed(n)
        print(f"n={n:>2}  自建={s:>8.0f}  托管={m:>8.0f}  "
              f"{'自建省' if s < m else '托管省'}")
    # n=1: 自建 800+1800+500=3100 vs 托管 3150 → 差不多
    # n=20: 自建 20*(800+1800)+500=52500 vs 托管 61500 → 自建省
    c = crossover()
    print(f"交叉点: 约 {c} 个实例以上自建开始更省")
    assert c <= 10
    print("OK")


if __name__ == "__main__":
    main()
```

**追问 1**：为什么"出云流量费"能一晚吃掉一个月差价？
→ 一句话提示：数据出口按 GB 计费且单价远高于入向，迁移几十 GB 的 RDB/AOF 快照、以及回迁后的持续同步流量，都走出向带宽；迁移设计要算流量账并优先用物理拷贝/专线。

**追问 2**：托管实例的哪些能力是自建很难低成本复刻的？
→ 一句话提示：自动 failover + 备份保留 + 免费监控告警这套"运维自动化包"；自建要达到同等 RTO，需要哨兵/集群 + 备份演练 + 值班体系，人力成本才是大头。

## 背诵要点
- 成本账三项：机器单价差 × 规模、人力小时 × 单价、期望故障损失（概率 × MTTR × 业务时薪）；比机器价是错的。
- 分界经验：约"实例数 × 单差价 > 0.5 DBA 月成本"反转；小规模托管、大规模自建/Operator。
- 分层策略：可重建缓存走自建、有业务后果的数据走托管；回迁要预付出云流量"搬运税"。

## 复盘追问
- 为什么建议决策写 ADR 并按季度复核？提示：云价与人力结构都会漂移，当时最优的临界点会移动；不复核的选型决策会在两年后变成沉默的 double payment。
- 缓存与数据类混在同一实例里对成本账有什么影响？提示：无法按"丢了可重建"分级降规格/降冗余，被迫整体按最高可靠性付费；按数据等级拆实例是成本工程的第一步。
