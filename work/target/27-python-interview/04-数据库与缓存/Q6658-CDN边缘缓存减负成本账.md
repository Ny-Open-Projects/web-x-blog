### Q6658 · CDN/边缘缓存为数据库减负的成本账

难度：P6-P7 | 标签：成本工程、CDN、缓存体系

**问**：商品图片与静态详情页占了 70% 出口带宽，回源打满数据库读副本。把这一层上移到 CDN/边缘缓存，成本账怎么算？什么数据适合上边缘、什么不适合？

**答**：结论：CDN 的账是**带宽费换 DB 算力费+命中率曲线**。回源一次 = DB 查询 + 应用渲染 + 出口带宽费；边缘命中一次只付 CDN 单价（约为直连带宽的 1/3-1/5）。收益 = 命中率 × (回源成本 - CDN 成本)。适合上边缘的是**内容寻址、读极多改极少**的资源（图片、版本化静态页、公开 JSON）；不适合的是带个人态、强实时、地域一致性要求的数据（购物车、库存）。

实战要点：
1. 命中率决定盈亏平衡：带宽费用通常是大头，命中率 80% 以下的项目先做 URL 规范化（去 query 抖动、统一编码）再谈成本。
2. 主动失效成本：边缘缓存改一个 SKU 要 invalidate 几千个 URL，失效 API 也按次计费——能靠"版本化 URL"（路径带 hash）就不主动失效。
3. 回源保护：CDN 回源也要设合并回源（singleflight）与限速，防止缓存冷启动回源打挂源站（Q1419 预热纪律同样适用）。

```python
"""CDN 上移成本账与盈亏平衡命中率（标准库，可运行）"""
from dataclasses import dataclass


@dataclass
class CdnLedger:
    monthly_requests: int     # 月请求量
    direct_cost_per_m: float  # 直连源站每百万请求成本（元）=DB算力+带宽
    cdn_cost_per_m: float     # CDN 每百万请求成本（元）
    invalidate_per_month: int = 0
    invalidate_price: float = 0.02  # 每次失效单价（元）

    def savings_at(self, hit_rate: float) -> float:
        miss = 1 - hit_rate
        served = self.monthly_requests / 1e6
        return served * (self.direct_cost_per_m - self.cdn_cost_per_m) * hit_rate

    def breakeven_hit_rate(self) -> float:
        """失效费摊进来后，多少命中率才不亏"""
        fixed = self.invalidate_per_month * self.invalidate_price
        served = self.monthly_requests / 1e6
        unit = self.direct_cost_per_m - self.cdn_cost_per_m
        if unit <= 0:
            return 1.01  # CDN 比直连还贵，必亏
        return min(fixed / (served * unit), 1.0)


led = CdnLedger(
    monthly_requests=900_000_000,
    direct_cost_per_m=18.0,   # 直连：DB算力+应用+带宽
    cdn_cost_per_m=4.5,
    invalidate_per_month=50_000,
)
print("盈亏平衡命中率:", f"{led.breakeven_hit_rate():.1%}")
for hr in (0.70, 0.85, 0.95):
    print(f"命中率 {hr:.0%} -> 月节省 {led.savings_at(hr):,.0f} 元")

# 内容寻址化：URL 带 hash 后基本不需要主动失效
print("版本化URL可省月失效费:",
      f"{50_000 * led.invalidate_price:,.0f} 元")
```

**追问 1**：为什么"统一 URL 规范化"常常比换 CDN 供应商收益更大？
**提示**：同一资源多个 query 组合（utm、时间戳）会把命中率打碎；规范化是命中率分子上的免费修复。

**追问 2**：公开 JSON 接口上边缘有什么新风险？
**提示**：缓存键要含鉴权结论或只缓存匿名可访问内容，否则出现越权缓存（Q2577 多租户隔离的边缘版）。

## 背诵要点
- CDN 账 = 命中率 × (回源成本 - CDN 成本) - 失效费；盈亏平衡命中率先算再做。
- 适合上边缘：内容寻址、读多改少；个人态/库存类禁入边缘。
- 版本化 URL（路径带 hash）替代主动失效，失效 API 按次计费是隐性成本。
