### A281 · 最少会议室数与可行分配：堆算法的贪心最优性论证

> 难度:★★★★ | 标签:区间调度, 最小堆, 贪心, 扫描线, 下界论证, 半开区间

**问**（笔试·编程题）：「给 n 场会议分配最少会议室并输出每场用哪间」——LeetCode 253/1094 的进阶版，面试官要的是**分配方案 + 最优性论证**而不是只报一个数：① `min_rooms(meetings)`：扫描线端点法求最少会议室数——半开区间 `[start, end)` 语义，`end == start`（一场结束一场开始）**不冲突**，排序时结束事件必须排在开始事件之前；② `assign(meetings)`：最小堆分配输出具体方案——堆存 `(结束时间, 房间号)`，新会议先看最早结束的房间能否复用，能复用不新开；返回房间总数与每场会议的房间号；③ **双重自证**：分配方案的房间数必须等于扫描线的峰值（上界=下界），且逐房间校验同房间任意两场会议不重叠；④ 随机对拍：30 组随机区间（含 `end == start` 边界），`assign` 的房间数与「任意时刻最大并发数」暴力扫描线逐组相等；⑤ **贪心正确性论证**写在答案里：为什么「按开始时间排序 + 复用最早结束的房间」不会多开房间——下界与构造两个方向都要说清。请说清与 A003（合并区间：只输出合并后的不重叠列表，不分配资源）、A261（区间合并与日程冲突：半开边界/跨天/时区归一的冲突**判定**）的分工——本题只回答「**最少资源数的下界论证与可行分配方案的构造**」。

**答**：① 分工：A003 是区间预处理（合并完就完，不回答「同时要多少个资源」），A261 是冲突判定（判定「撞不撞」，不回答「最少用几间、怎么分」）——本题是**资源分配**：输出既是数字也是方案，且要论证数字为什么不可能更小。② 下界（任何算法都躲不开）：任意时刻的**最大并发数** = 覆盖该时刻的区间数，是房间数的硬下界——并发数 k 的时刻，k 场会议两两重叠，会议室图在此处是完全子图，少于 k 间必有人没房间；扫描线 `+1/-1` 事件流求峰值就是这个下界的精确值。③ 构造（堆算法达到下界）：按开始时间排序逐场处理，堆里存每间房的释放时间——新会议 `s` 到来时，若最早释放的房间 `end <= s`（半开语义），复用它（弹出重压），否则开新房间。论证关键：**只有当堆顶房间的结束时间都 > s 时才开新房**，意味着此刻至少有 `已开房间数` 场已开始且未结束的会议压在时间轴上——并发数 ≥ 已开房间数，所以开的每一间都被下界「批准」了，总数不可能超过峰值；又不可能低于峰值（②），两者夹死，算法输出 = 峰值 = 最优。④ 实现的两个坑：排序按开始时间（**不是结束时间**——最少房间问题的正确序，与「最多不重叠区间」问题按结束时间排序是两个对偶问题，混用是最常见错误）；结束事件先于开始事件（`(t, -1)` 排在 `(t, +1)` 前）实现半开语义——`end == start` 时房间先释放再被新会议接住，实测边界组恰好多复用一间。⑤ 方案自证是笔试加分项：拿到房间数后**逐房间排序校验相邻会议 `prev_end <= next_start`**——证明这是可行分配而不仅仅是数字对得上；随机对拍把「扫描线峰值（下界）」与「堆分配（构造）」在 30 组含边界的数据上强制相等，任何一处半开语义写错（比如把 `<=` 写成 `<`）对拍立刻爆。

```python
# 全部标准库；区间调度：扫描线下界 + 最小堆分配方案 + 双重自证 + 随机对拍
import heapq
import random


def min_rooms(meetings):
    """扫描线端点法：峰值并发数 = 最少房间数的下界（也是精确值）。"""
    events = []
    for s, e in meetings:
        events.append((s, 1))                  # 开始 +1
        events.append((e, -1))                 # 结束 -1
    events.sort()                              # 同时刻 -1 排在 +1 前：end==start 不冲突
    cur = peak = 0
    for _, d in events:
        cur += d
        peak = max(peak, cur)
    return peak


def assign(meetings):
    """最小堆分配：按开始时间处理，复用最早结束的房间；返回 (房间数, 方案)。"""
    order = sorted(range(len(meetings)), key=lambda i: meetings[i][0])
    free = []                                  # 最小堆 (结束时间, 房间号)
    n_rooms = 0
    plan = [None] * len(meetings)
    for i in order:
        s, e = meetings[i]
        if free and free[0][0] <= s:           # 半开语义：end<=start 可复用
            _, room = heapq.heappop(free)
        else:
            n_rooms += 1                       # 堆顶都在用：只能开新房
            room = n_rooms
        plan[i] = room
        heapq.heappush(free, (e, room))
    return n_rooms, plan


def validate(meetings, plan):
    """逐房间校验：同房间排序后相邻会议不重叠（可行分配证明）。"""
    by_room = {}
    for (s, e), room in zip(meetings, plan):
        by_room.setdefault(room, []).append((s, e))
    for room, ivs in by_room.items():
        ivs.sort()
        for (s1, e1), (s2, e2) in zip(ivs, ivs[1:]):
            assert e1 <= s2, (room, s1, e1, s2, e2)   # 半开：e1<=s2 不重叠
    return len(by_room)


if __name__ == "__main__":
    # 1) 经典样例 + end==start 半开边界
    ms = [(0, 30), (5, 10), (15, 20)]
    assert min_rooms(ms) == 2
    rooms, plan = assign(ms)
    assert rooms == 2 == min_rooms(ms) == validate(ms, plan)
    print("经典样例: 3 场会议最少 %d 间，方案 %s，逐房间校验可行 ✅" % (rooms, plan))

    touch = [(0, 5), (5, 10), (10, 15)]        # 首尾相接：半开语义一间够
    assert min_rooms(touch) == 1
    rooms, plan = assign(touch)
    assert rooms == 1 and plan == [1, 1, 1]
    print("半开边界: (0,5)(5,10)(10,15) 首尾相接只需 1 间 ✅")

    # 2) 重叠全并发：3 场同一时刻 → 3 间，且等于峰值
    clash = [(4, 8), (4, 6), (4, 7)]
    assert min_rooms(clash) == 3
    rooms, plan = assign(clash)
    assert rooms == 3 == validate(clash, plan)
    print("全并发: 三场同时开始 → 3 间（下界=构造）✅")

    # 3) 随机对拍：30 组含边界数据，构造值 == 下界，方案逐房间可行
    rng = random.Random(2026)
    for _ in range(30):
        n = rng.randint(1, 40)
        ms = []
        for _ in range(n):
            s = rng.randint(0, 48)
            e = s + rng.randint(1, 12)         # 时长 ≥1：零长 [s,s) 是空集不占资源
            ms.append((s, e))
        lower = min_rooms(ms)
        rooms, plan = assign(ms)
        assert rooms == lower, (ms, rooms, lower)
        assert validate(ms, plan) == rooms
    print("随机对拍: 30 组（含首尾相接与长重叠）构造值与扫描线下界逐组相等 ✅")

    # 4) 单会议与空输入边界
    assert min_rooms([]) == 0 and assign([]) == (0, [])
    assert min_rooms([(3, 9)]) == 1 and assign([(3, 9)]) == (1, [1])
    print("边界: 空输入 0 间、单会议 1 间 ✅")
```

**追问**：1) 「最少会议室」按开始时间排，「最多不重叠区间」按结束时间排——为什么同一族问题排序键相反？—— 两个问题互补：最多不重叠区间是「选」（选出一个最大相容子集），证明靠**交换论证**：按结束时间排序后，当前选中的最早结束区间若被交换法替换成其他选择，只会让后面剩余时间更多或不变——贪心解逐项不劣于最优解，故最优；而最少会议室是「覆盖」（给每个区间找资源），任何时刻的并发数是硬下界，构造只需保证「新开房间时并发数恰好追平下界」——按开始时间处理，开新房的瞬间堆顶全在占用，房间数 ≤ 并发数恒成立。**两题混排是最常见的笔试翻车点**：拿按结束排的贪心去答最少房间，遇到 `(0,20)(19,21)(20,22)` 直接给出错误房间数。2) 交换论证和下界论证分别适用于哪类贪心题？—— 交换论证适合「选子集最大化」类（活动选择、任务调度贪心）：证明任意最优解可以逐步替换成贪心解而不变差；下界论证适合「资源最小化」类（本题、区间覆盖）：先找一个任何方案都突破不了的数量（并发数、覆盖长度下界），再证明贪心构造恰好达到它——**有下界才能证明「最少」**，只跑随机对拍只是经验相等不是证明。面试口述模板：先给下界（这个数字任何解都达不到更小），再给构造不变式（我的算法每次变差都发生在下界也变差时），两条夹住。3) 房间要按「贵宾房/普通房」分层定价怎么办？—— 简单堆分配立刻失效：这是区间图上的**加权分配**，等价于二部图匹配，贪心可能给出可行但昂贵的方案；正确姿势是最小费用流（会议 → 时段房间，费用即租金）或分段贪心（贵宾会议只进贵宾池，池内仍用本题堆算法）——工程上几乎都选后者：先按约束把会议分桶（楼层/设备/容量），桶内退化回无权重的最少房间问题。另一条隐藏简化：若房间同质且只问总数，区间图着色定理保证色数 = 团数 = 最大并发数——**峰值并发就是答案，堆只是把它算出来的方式**。
