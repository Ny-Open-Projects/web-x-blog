### A288 · 二分答案最小化最大负载：可行性的贪心证明、边界收缩写法与小规模 DP 对拍

> 难度:★★★★ | 标签:二分答案, 贪心, 单调性, 分割数组, 对拍

**问**（笔试·编程题）：船运载力（`ship_within_days(weights, days)`）与分割数组最大和是同一道题的两种包装，面试官盯「**答案空间上二分 + 可行性判定**」：① 说清「二分答案」到底在二分什么：答案 `cap` 的可行域为什么是**从某个下界开始的连续后缀**，单调性从哪来；② `feasible(cap)` 用**贪心**判定：顺序装船、装不下就开新船，证明「贪心用最少天数」；③ 给出 `lo = max(weights)`、`hi = sum(weights)` 的闭区间写法，以及 `while lo < hi` + `hi = mid / lo = mid + 1` 的收缩不变量，说明为什么不能写成 `lo <= hi` 再返回 `lo-1`；④ 与暴力 DP（`dp[k][i]`，O(days·n²)）在 n ≤ 9 的小规模上做 40 组逐值对拍；⑤ 说清与 A008（旋转数组二分·二分的对象是下标）、A281（区间调度·贪心选择）的分工——本题只回答「**二分的是答案、判定靠贪心**」。

**答**：① 分工：A008 在**有序下标**上二分找旋转点，二分对象是数组位置；A281 用贪心+堆决定选哪些区间；本卡二分对象是**答案值域**——`cap` 越小越难装下，`feasible(cap)` 关于 `cap` 是单调的（`cap` 增大不可能从可行变不可行），所以可行解构成 `[ans, +∞)` 的连续后缀，二分就是找这个后缀的左端点。② 可行性贪心：按原顺序扫描，能塞进当前船就塞，塞不下才开新船——**不提前开船、不回头重排**。证明用交换论证：任意最优方案的第一船若装得比贪心少，把后面能塞进来的货挪进来不会增加船数；归纳到每一船，贪心用船数 ≤ 任何方案，因此 `need ≤ days` 当且仅当 `cap` 可行。③ 边界：下界 `max(weights)`（单件必须装得下），上界 `sum(weights)`（一天全装完，必然可行）；循环 `while lo < hi`，`mid = (lo + hi) // 2`，可行就 `hi = mid`（保留答案、砍右半），不可行就 `lo = mid + 1`（`mid` 已知不可行，可以安全跳过）——区间始终是「`lo` 可能可行、`hi` 可行」的闭区间，退出时 `lo == hi` 即答案。写成 `lo <= hi` 再用 `ans` 记录也行，但多一个变量、边界更易错；写成 `hi = mid - 1` 则可能把唯一可行解丢掉。④ 易错点：`feasible` 里先判 `w > cap` 直接返回 False（否则会死循环开船）；`need` 初始为 1 不是 0（第一船就存在）；空数组要单独返回 0（`max()` 会炸）；`days ≥ n` 时答案应等于 `max(weights)`，这是很好的自检断言。⑤ 对拍地基：DP 的 `dp[k][i]` 表示「前 i 件用至多 k 段的最小最大段和」，转移枚举最后一段的起点 `j`，正确性来源是**枚举全部分割点**，与二分的「值域搜索」完全独立；n ≤ 9 时 DP 是 O(days·n²)，40 组随机逐值比较，才能证明二分没有把「不可行」误判成「可行」。

```python
# 全部标准库；二分答案（船运/分割数组） vs O(days*n^2) DP，小规模逐值对拍
import random


def feasible(weights, cap, days):
    """贪心判定：顺序装船，装不下才开新船，看总船数是否 <= days。"""
    need, cur = 1, 0
    for w in weights:
        if w > cap:
            return False
        if cur + w <= cap:
            cur += w
        else:
            need += 1
            cur = w
            if need > days:
                return False
    return True


def ship(weights, days):
    """目标实现：在 [max, sum] 上二分最小可行载力。"""
    if not weights:
        return 0
    lo, hi = max(weights), sum(weights)
    while lo < hi:
        mid = (lo + hi) // 2
        if feasible(weights, mid, days):
            hi = mid          # mid 可行，答案在左半边（含 mid）
        else:
            lo = mid + 1      # mid 不可行，答案严格在右侧
    return lo


def ship_dp(weights, days):
    """参考实现：dp[k][i] = 前 i 件分至多 k 段的最小最大段和。"""
    n = len(weights)
    if n == 0:
        return 0
    pre = [0] * (n + 1)
    for i, w in enumerate(weights):
        pre[i + 1] = pre[i] + w
    INF = float("inf")
    prev = [INF] * (n + 1)
    prev[0] = 0
    for _ in range(1, days + 1):
        cur = [INF] * (n + 1)
        cur[0] = 0                     # 前 0 件用 0 段，代价 0
        for i in range(1, n + 1):
            for j in range(i):
                seg = pre[i] - pre[j]
                cand = max(prev[j], seg)
                if cand < cur[i]:
                    cur[i] = cand
        prev = cur
    return prev[n]


if __name__ == "__main__":
    rng = random.Random(2881)

    # 1) 40 组随机（n<=9，天数 1..n+2）与 DP 逐值对拍
    for _ in range(40):
        n = rng.randint(1, 9)
        w = [rng.randint(1, 20) for _ in range(n)]
        d = rng.randint(1, n + 2)
        assert ship(w, d) == ship_dp(w, d), (w, d, ship(w, d), ship_dp(w, d))
    print("二分对拍: 40 组随机 vs O(days*n^2) DP，全等 ✅")

    # 2) 边界：单元素、days>=n、days=1、全相同、极值
    assert ship([5], 1) == 5
    assert ship([1, 2, 3, 4, 5], 5) == 5          # 每天一件 -> max
    assert ship([1, 2, 3, 4, 5], 99) == 5         # days 超过 n 也退化到 max
    assert ship([1, 2, 3, 4, 5], 1) == 15         # 一天全装 -> sum
    assert ship([7, 7, 7, 7], 2) == 14
    assert ship([10 ** 9, 10 ** 9, 10 ** 9], 2) == 2 * 10 ** 9
    assert ship([], 3) == 0
    print("边界断言: 单元素/days≥n/days=1/全相同/10^9/空 全过 ✅")

    # 3) 单调性实证：cap 从 max 到 sum 逐点判可行，可行域必须是连续后缀
    w = [3, 2, 2, 4, 1, 4]
    flags = [feasible(w, cap, 3) for cap in range(max(w), sum(w) + 1)]
    assert flags == sorted(flags), flags        # False...False True...True
    first = max(w) + flags.index(True)
    assert first == ship(w, 3)
    print("单调性: 可行域为连续后缀，首个 True 即答案 ✅")

    # 4) 经典样例：weights=[1..10], days=5 -> 15
    assert ship(list(range(1, 11)), 5) == 15
    assert ship_dp(list(range(1, 11)), 5) == 15
    print("对拍通过：二分答案 40 组随机 + 7 条边界 + 单调性实证全绿")
```

**追问**：1) 答案空间能不能不用 `sum(weights)` 上界？—— 可以，用 `max(weights) * ceil(n/days)` 之类的构造上界也行，甚至 `max(weights) << 20` 也能跑，但 `sum` 是最不需要证明的可行解（一天全装），**上界必须可证可行**，否则二分会停在一个不可行的值上。下界 `max(weights)` 也必须可证「小于它必不可行」，这两条是二分答案的合法性根基，比优化常数重要。2) `feasible` 的贪心为什么不是「尽量装满当前船」这么一句就完了？—— 严格说法是：给定 `cap`，贪心产生的船数是**所有合法装载方案中的最小值**。交换论证：设最优方案第一船装到下标 `j`，贪心第一船装到 `j' ≥ j`（贪心能装就装），把最优方案里 `j+1..j'` 的货物从后续船挪到第一船不违反容量（贪心已验证可装），后续船只会更空，船数不增；对剩余部分归纳。只说「尽量装满」会被追问「凭什么最优」。3) 这题和「最小化最大子段和」是同一题吗？—— 是，`split_array(nums, m)` 就是把 `weights` 当 `nums`、`days` 当 `m`，**同一份代码换个变量名**；面试时先点破这层同构（「这题也叫分割数组的最大值 / 抄书问题」），再讲二分，会显得你在题库层面有地图，而不是背了一道题。区别只在题面是否允许「不按原顺序」——两题都要求**保持原序连续分段**，若允许重排，答案会退化成「尽量均分」，那是另一道题。
