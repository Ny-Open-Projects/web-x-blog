### A006 · 盛最多水的容器

> 难度:★★☆ | 标签:双指针, 贪心

**问**:每条竖线高度 `h[i]`,与 x 轴围成容器,求能盛最多水的面积。

**答**:双指针从两端收拢:面积 = 宽 × 短板高度;移动**短板一侧**指针(短板是瓶颈,动长板不可能变大)。每次 O(1) 评估,总 O(n) 时间 O(1) 空间。

```python
# 示例:code/07_算法专题/(docs 内嵌,复制可运行) a006_container_most_water.py
def max_area(height: list[int]) -> int:
    l, r = 0, len(height) - 1
    best = 0
    while l < r:
        best = max(best, (r - l) * min(height[l], height[r]))
        if height[l] < height[r]:    # 移动短板一侧
            l += 1
        else:
            r -= 1
    return best

if __name__ == "__main__":
    assert max_area([1, 8, 6, 2, 5, 4, 8, 3, 7]) == 49
    assert max_area([1, 1]) == 1
    assert max_area([4, 3, 2, 1, 4]) == 16
    print("A006 ok")
```

**追问**:
- 为什么移动短板是对的?——保留短板、缩宽度,面积必然不增;而移动短板后新短板可能更高,才有机会超过当前值。这是「局部贪心不漏最优」的论证,面试要求说出口。
- 和「接雨水」的区别?——接雨水求总量,逐柱算左右最大高度(前缀最大值或单调栈);一个考双指针贪心论证,一个考前缀/栈,常被连问。
- 反证怎么讲?——假设最优解被跳过:跳过发生在移动短板时,而被跳过的状态以当前短板为高,面积 ≤ 当前已记录值,矛盾。
