### A003 · 合并区间

> 难度:★☆☆ | 标签:数组, 排序

**问**:给定若干区间,合并所有重叠区间,返回不重叠的区间列表。

**答**:按左端点排序后线性扫描:当前区间与已合并的最后一个区间重叠(`s <= last_end`)就扩张右端点(取 max),否则新开一个区间。排序 O(n log n) 是瓶颈,扫描 O(n),空间 O(n)(输出)。重叠判断必须取 max,因为前一个区间可能完全包含后一个。

```python
# 示例:code/07_算法专题/(docs 内嵌,复制可运行) a003_merge_intervals.py
def merge(intervals: list[list[int]]) -> list[list[int]]:
    intervals.sort(key=lambda iv: iv[0])     # 按左端点排序
    merged: list[list[int]] = []
    for s, e in intervals:
        if merged and s <= merged[-1][1]:    # 与最后一个区间重叠
            merged[-1][1] = max(merged[-1][1], e)
        else:
            merged.append([s, e])
    return merged

if __name__ == "__main__":
    assert merge([[1, 3], [2, 6], [8, 10], [15, 18]]) == [[1, 6], [8, 10], [15, 18]]
    assert merge([[1, 4], [4, 5]]) == [[1, 5]]        # 端点相接算重叠
    assert merge([[1, 10], [2, 3], [4, 5]]) == [[1, 10]]  # 完全包含,必须取 max
    assert merge([]) == []
    print("A003 ok")
```

**追问**:
- 不排序直接扫描行吗?——不行,重叠关系只在左端点有序时才局部化;不排序就得两两比较 O(n²)。
- 端点相接 `[1,4][4,5]` 算重叠吗?——业务定义问题:合并(闭区间语义)或不合并,代码只差一个 `<`;面试要先问清口径再写。
- 工程变体?——日历忙闲合并、IP 段合并、文件区间去重(见 Q066 大块数据合并时同样先排序再线性归并)。
