### A266 · 带时间窗的最短路径

> 难度:★★★★ | 标签:Dijkstra, 时间窗, 等待语义, 分层图, 状态扩展

**问**（笔试·编程题）：物流调度里的经典变体：图上每条边带一个**通过窗口** `[w_open, w_close]`（轮渡只在 8:00-8:30 开航、卸货口只在那半小时开放），边权是通行耗时。要求：① 实现**带时间窗的 Dijkstra**：允许在节点**原地等待**窗口开放，状态从「节点」扩展为「（节点，最早到达时刻）」，求从源点出发的最早到达时刻；② 用一个「无视窗口的普通 Dijkstra 会给出**不可行解**」的反例，说明为什么窗口约束不能事后校验、必须进状态；③ 用第二个反例证明**早到不一定优**——一条边数更少的路径因为要干等窗口，反而输给绕路的路径，验证 `dep = max(t, w_open)` 这一行等待语义的正确性；④ 实现禁止等待的变体（到达即必须出发），此时「按节点记最优」失效，状态必须扩成（节点，时刻）的**分层图**——同一张图两个语义给出不同答案，都要断言；⑤ 全窗口关闭时返回 None。请说清与 A012（无权图 BFS：层序即最短路的前提是边权全 1）、A251（拓扑排序：DAG 上的依赖时序，不是图上移动）、A122（资源隔离）的分工。

**答**：① 分工：A012 的 BFS 是「边权全等时 Dijkstra 的特例」（队列天然单调），A251 的拓扑是「依赖顺序」不是「空间移动」，本题是**标准 Dijkstra 在边约束下还能不能用、怎么用**——考点是状态设计与贪心前提，不是堆的用法。② 核心结论：**允许等待时，普通 Dijkstra 原样成立**，只改松弛那一行。原因要讲透：Dijkstra 的贪心前提是「到达某节点的最早时刻，支配之后的一切」——等待语义下 `dep = max(t, w_open)` 是 t 的单调不减函数，**早到永远不亏**（大不了多等一会儿，晚到只会更差），所以每个节点只需保留最早到达态，`best[node]` 一个数就够。状态还是 O(n) 个，复杂度不变 O(E log V)。反例验证：源点直达轮渡边权 10、窗口 `[50,60]`，绕行陆路边权 100——无视窗口的 Dijkstra 会答 10（在时刻 10 出发，根本没开航，不可行）；正确答案 60（等到 50 出发）。这证明窗口约束**不能跑完再校验**：普通 Dijkstra 会先收缩到错误的最优值，事后校验只能发现错了，不能找到对的那条。③ 早到不优的时机：窗口是「一次性开放段」，早到 + 长等 vs 晚到 + 恰好赶上，后者总时间更短——到达时刻决定了你能用的窗口，所以**中间节点的到达时刻是路径质量的一部分**。这正是「等待允许」与「等待禁止」的分水岭：允许等待时单调支配成立（④的反例在允许等待下不成立），禁止等待时早到反而可能错过窗口，支配关系断裂。④ 禁止等待 → 状态必须扩成 `(node, t)`：同一节点的不同到达时刻**互不支配**（t=40 与 t=45 各能赶上不同的窗口），这是一张**时间分层图**——每个可达时刻复制一层图。可达时刻由路径唯一确定，状态数 = 实际可达的 (节点, 时刻) 对数（远小于时间轴全长，本题演示用集合去重即可，工程上把时刻离散化到分钟或事件点）。同一张图：允许等待的答案 ≤ 禁止等待的答案，且禁止等待可能直接不可达（只能干等的转机会消失）——代码里两个变体在同一张图上分别断言，答案确实不同。⑤ 边界与工程点：窗口非法（`w_close < w_open`）入口拒绝；不可达返回 None 要与「超时未到」区分（None = 结构性不可达，超时 = 时窗内的可行集耗尽，两者告警级别不同）；大图上 `dep > w_close` 的剪枝（这条边这辈子都赶不上了）要放在 push 之前，别把注定失败的候选堆进去白耗 log。周期窗口（每天循环）是追问的重灾区：把窗口按天展开成一次性窗口序列，或状态加「日期相位」维度——不管哪种，**窗口语义先在纸上写死，再动代码**。

```python
# 全部标准库；带时间窗的 Dijkstra：窗口边 + 节点等待 + 禁止等待的分层图变体
import heapq

INF = float("inf")


def _adj(edges, n):
    adj = [[] for _ in range(n)]
    for u, v, c, a, b in edges:
        if b < a:
            raise ValueError("窗口非法：w_open > w_close")
        adj[u].append((v, c, a, b))
    return adj


def shortest_with_wait(n, edges, src, dst, t0=0):
    """允许原地等待：dep = max(t, w_open)，早到不亏 → 按节点记最优即可。
    返回最早到达时刻；结构性不可达返回 None。"""
    adj = _adj(edges, n)
    best = {src: t0}                      # node -> 已确定的最早到达时刻
    pq = [(t0, src)]
    while pq:
        t, u = heapq.heappop(pq)
        if u == dst:
            return t
        if t > best.get(u, INF):
            continue                      # 过期态：更早的到达已处理过
        for v, c, a, b in adj[u]:
            dep = max(t, a)               # 等待语义：窗口没开就原地等到开
            if dep > b:
                continue                  # 本窗口已关，剪枝
            arr = dep + c
            if arr < best.get(v, INF):
                best[v] = arr
                heapq.heappush(pq, (arr, v))
    return None


def shortest_no_wait(n, edges, src, dst, t0=0):
    """禁止等待（到达即出发）：早到可能错过窗口，(node, t) 互不支配
    → 状态扩成分层图 (node, t)，按到达时刻升序弹出，首个命中 dst 即最优。"""
    adj = _adj(edges, n)
    seen = set()                          # 已展开的 (node, t) 状态
    pq = [(t0, src)]
    while pq:
        t, u = heapq.heappop(pq)
        if u == dst:
            return t
        if (u, t) in seen:
            continue
        seen.add((u, t))
        for v, c, a, b in adj[u]:
            if not (a <= t <= b):
                continue                  # 到达即出发：当前时刻不在窗内就过不去
            heapq.heappush(pq, (t + c, v))
    return None


if __name__ == "__main__":
    # 1) 反例一：无视窗口的 Dijkstra 给出不可行解
    #    直达轮渡边权 10、窗口 [50,60]；绕行陆路边权 100、随时可走
    edges1 = [(0, 1, 10, 50, 60), (0, 1, 100, 0, 10 ** 9)]
    got = shortest_with_wait(2, edges1, 0, 1)
    assert got == 60, got                 # 等 50 出发 + 10 = 60，赢过陆路 100
    print("反例一: 无视窗口答 10（时刻 10 轮渡没开，不可行）；正解 60 ✅")

    # 2) 反例二：早到 + 干等 输给 晚到 + 恰好赶上（等待语义正确性）
    #    A 线: 0→1 耗时 0，再 1→3 轮渡窗口 [40,45] 耗时 5 → 干等 40 后到 45
    #    B 线: 0→2 耗时 30，再 2→3 耗时 10 → 时刻 40 到达，不等待
    edges2 = [(0, 1, 0, 0, 10 ** 9), (1, 3, 5, 40, 45),
              (0, 2, 30, 0, 10 ** 9), (2, 3, 10, 0, 10 ** 9)]
    assert shortest_with_wait(4, edges2, 0, 3) == 40   # B 线赢
    print("反例二: A 线边少但要干等 40 分钟（到 45）；B 线绕路恰好赶上（到 40）✅")

    # 3) 禁止等待的分层图变体：同一张图，语义不同答案不同
    assert shortest_no_wait(4, edges2, 0, 3) == 40      # 时刻 0 不在 [40,45] → A 线断
    edges3 = [(0, 1, 10, 50, 60)]                       # 只剩轮渡：0 时刻出不去
    assert shortest_with_wait(2, edges3, 0, 1) == 60    # 允许等待 → 60
    assert shortest_no_wait(2, edges3, 0, 1) is None    # 禁止等待 → 结构性不可达
    print("分层图: 禁止等待时 A 线消失、纯轮渡图不可达——(node,t) 互不支配 ✅")

    # 4) 全窗口关闭 / 窗口非法
    edges4 = [(0, 1, 5, 10, 20), (0, 1, 5, 30, 40)]
    assert shortest_with_wait(2, edges4, 0, 1, t0=41) is None   # 两窗都已关
    try:
        _adj([(0, 1, 5, 30, 10)], 2)
        raise AssertionError("窗口非法必须拒绝")
    except ValueError:
        pass
    print("边界: 窗口全关返回 None、非法窗口入口拒绝 ✅")

    # 5) 手工枚举对账：两条候选路径各自的最优值，与 Dijkstra 结果一致
    edges5 = [(0, 1, 4, 0, 10 ** 9), (1, 2, 3, 20, 25), (0, 2, 9, 22, 10 ** 9)]
    route_a = max(4, 20) + 3        # 0→1→2：时刻 4 到节点 1，等到 20 出发 → 23 到
    route_b = max(0, 22) + 9        # 0→2：等到窗口 22 开放出发 → 31 到
    assert shortest_with_wait(3, edges5, 0, 2) == min(route_a, route_b) == 23
    print("枚举对账: 1→2 窗口 [20,25] 逼出等待路径，Dijkstra 与手工枚举一致 ✅")
```

**追问**：1) 窗口是「每天循环」的怎么办？—— 两种扩展：**按天展开**——把 `[a,b]` 复制成未来 N 天的一次性窗口（N = 最长可行路径天数上界），代码一行不改，状态数乘 N；**相位分层**——状态加「当天时刻 + 星期相位」，适合窗口密度高、展开爆炸的场景。选型看窗口密度：一天几百个窗口的轮渡图，展开即可；分钟级班次的高铁图，必须相位分层。共同前提是**路径长度上界要存在**，否则「等到下个月窗口开了再走」会让搜索不终止——工程上用截止时刻 `deadline` 硬剪枝，超过就当不可达。2) 为什么允许等待时「按节点记最优」是对的、禁止等待就错了？—— 等待语义下 `dep = max(t, w_open)` 单调不减，到达时刻越早，后续每条边的可用出发时刻越不劣——**早到支配晚到**，每个节点一个最早时刻就够，这正是 Dijkstra 贪心成立的前提。禁止等待后支配关系断裂：早到 40 的节点赶不上 `[45,50]` 的窗口，晚到 45 的反而能走——到达时刻本身携带「窗口通行资格」信息，必须进状态。记住这个判据：**松弛函数对旧状态单调时才能按节点坍缩状态，否则时间（或任何被约束引用的量）都要进状态**。3) 图大了怎么优化？—— 三板斧：**剪枝**（`dep > w_close` 在 push 前过滤，注定失败的候选不进堆）；**A\***——用「到目标的欧氏距离 ÷ 最高限速」做可采纳启发，仍是 Dijkstra 骨架；**时刻离散化**——把时间轴切成分钟/五分钟档，状态从连续变离散，配合位图去重。还有一个常被忽略的：**双向搜索在时间窗下要小心**——反向边的时间窗语义不是简单取反（到达时刻决定出发资格），随便双向会给出错误上界，这是用 A\* 而不是双向 Dijkstra 的真正原因。

## 背诵要点
1. 允许等待时 Dijkstra 原样成立，只改松弛：`dep = max(t, w_open)`；等待是单调的，早到不亏 → 按节点记最早到达即可，复杂度不变。
2. 无视窗口会先收缩到不可行解，事后校验救不回来——窗口约束必须进状态；禁止等待时 (node, t) 互不支配，扩成分层图。
3. 边界：`w_close < w_open` 入口拒绝；None = 结构性不可达（区别于超时）；周期窗口按天展开或相位分层，必须有 deadline 剪枝保终止。
