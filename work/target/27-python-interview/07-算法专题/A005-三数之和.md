### A005 · 三数之和

> 难度:★★☆ | 标签:数组, 双指针, 排序

**问**:找出数组中所有和为 0 的不重复三元组。

**答**:排序后固定最小数 `nums[i]`,右区间用双指针找两数之和 `-nums[i]`。剪枝:`nums[i] > 0` 直接停(后面全正);固定数与指针命中后都要**跳过重复值**防答案重复。O(n²) 时间、O(1) 额外空间(不算输出与排序栈),比暴力 O(n³) 降一维。

```python
# 示例:code/07_算法专题/(docs 内嵌,复制可运行) a005_three_sum.py
def three_sum(nums: list[int]) -> list[list[int]]:
    nums.sort()
    res: list[list[int]] = []
    n = len(nums)
    for i in range(n - 2):
        if nums[i] > 0:                      # 最小数已为正,不可能凑出 0
            break
        if i > 0 and nums[i] == nums[i - 1]:  # 跳过重复的固定数
            continue
        l, r = i + 1, n - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s < 0:
                l += 1
            elif s > 0:
                r -= 1
            else:
                res.append([nums[i], nums[l], nums[r]])
                l += 1
                r -= 1
                while l < r and nums[l] == nums[l - 1]:  # 跳过重复的左值
                    l += 1
                while l < r and nums[r] == nums[r + 1]:  # 跳过重复的右值
                    r -= 1
    return res

if __name__ == "__main__":
    assert three_sum([-1, 0, 1, 2, -1, -4]) == [[-1, -1, 2], [-1, 0, 1]]
    assert three_sum([0, 0, 0, 0]) == [[0, 0, 0]]   # 三重重复只留一组
    assert three_sum([1, 2, -2, -1]) == []
    print("A005 ok")
```

**追问**:
- 去重的三处分别防什么?——固定数去重防「同一最小数重复开扫」,双指针去重防「同一对 (l,r) 重复入答案」;漏任何一处输出就有重复,是本题最大失分点。
- 为什么排序后双指针可行?——有序性给了确定移动方向:和偏小移左指针、偏大移右指针,不会漏解;无序时两个方向都可能漏。
- 四数之和怎么推广?——外层再套一层固定数,内层复用双指针,O(n³);通用「N 数之和」用递归化剪枝,面试说清套层思路即可。
