### A008 · 旋转排序数组中的最小值

> 难度:★★☆ | 标签:二分查找

**问**:原升序数组在某个点旋转过(如 `[4,5,6,7,0,1,2]`),找出最小值,要求 O(log n)。

**答**:二分,与**右端点** `nums[r]` 比较:`nums[m] > nums[r]` 说明最小值在右半(m 之后),`l = m+1`;否则最小值在 m 及其左侧,`r = m`。收敛时 `nums[l]` 即最小。若允许重复元素,`nums[m] == nums[r]` 时 `r -= 1`(无法判断方向,安全收缩)。

```python
# 示例:code/07_算法专题/(docs 内嵌,复制可运行) a008_find_min_rotated.py
def find_min(nums: list[int]) -> int:
    l, r = 0, len(nums) - 1
    while l < r:
        m = (l + r) // 2
        if nums[m] > nums[r]:    # 旋转点在右半
            l = m + 1
        else:                    # 最小值在 m 及其左侧
            r = m
    return nums[l]

def find_min_with_dup(nums: list[int]) -> int:
    l, r = 0, len(nums) - 1
    while l < r:
        m = (l + r) // 2
        if nums[m] > nums[r]:
            l = m + 1
        elif nums[m] < nums[r]:
            r = m
        else:                    # 无法定向,安全收缩一格(最坏 O(n))
            r -= 1
    return nums[l]

if __name__ == "__main__":
    assert find_min([4, 5, 6, 7, 0, 1, 2]) == 0
    assert find_min([3, 4, 5, 1, 2]) == 1
    assert find_min([1]) == 1
    assert find_min([2, 1]) == 1
    assert find_min_with_dup([2, 2, 2, 0, 1]) == 0
    assert find_min_with_dup([1, 1, 1]) == 1
    print("A008 ok")
```

**追问**:
- 为什么和右端点比而不是左端点?——和左端点比无法区分「m 在旋转点前还是后」;右端点(或 last)是稳定参照,这是旋转数组二分的标准技巧。
- `r = m` 为什么不会死循环?——m = (l+r)//2 向下取整,m < r 恒成立,区间严格缩小;若写 `r = m` 配上取整的 m 才会死循环,边界是二分题的必考点。
- 有重复时退化到 O(n),还能更优吗?——不能,极端 `[1,1,1,...,1,0]` 里 0 的位置信息被重复抹掉,任何算法最坏都要 O(n);主动说出这个下界是 L3 答案。
