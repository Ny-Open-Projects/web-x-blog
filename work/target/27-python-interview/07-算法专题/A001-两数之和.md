### A001 · 两数之和

> 难度:★☆☆ | 标签:数组, 哈希表

**问**:给定整数数组 `nums` 和目标值 `target`,返回和为 target 的两个下标。每个输入恰好有一个解,同一元素不能用两次。要求优于 O(n²)。

**答**:一遍哈希:遍历数组,对每个 `x` 先查 `target - x` 是否已在哈希表中(命中即返回两个下标),再把 `x: i` 存入。时间 O(n)、空间 O(n)。关键细节是**先查后存**:这样 `[3, 3]`、target=6 这类含重复元素的输入也能命中,不会自己和自己配对。

```python
# 示例:code/07_算法专题/(docs 内嵌,复制可运行) a001_two_sum.py
def two_sum(nums: list[int], target: int) -> list[int]:
    seen: dict[int, int] = {}          # 值 -> 下标
    for i, x in enumerate(nums):
        if target - x in seen:         # 先查补数,再存自己
            return [seen[target - x], i]
        seen[x] = i
    return []                          # 题目保证有解,这里只是兜底

if __name__ == "__main__":
    assert two_sum([2, 7, 11, 15], 9) == [0, 1]
    assert two_sum([3, 2, 4], 6) == [1, 2]     # 不能用同一个 3 两次
    assert two_sum([3, 3], 6) == [0, 1]        # 重复元素也能命中
    print("A001 ok")
```

**追问**:
- 为什么先查后存?——后存保证「自己」不在 seen 里,自动排除用同一元素两次;先存再查就要额外判断 `j != i`。
- 数组已排序时怎么做?——双指针 O(n) 时间 O(1) 空间(见 A006 的指针框架);空间换时间还是时间换空间由面试官追问时你主动说出。
- 哈希表 O(1) 查找的成立前提?——key 可哈希且冲突可控,CPython dict 是开放寻址;海量数据时哈希表内存是真实成本,可换成排序+双指针降空间。
