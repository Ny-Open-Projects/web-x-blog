### A111 · 权限校验引擎

> 难度:★★☆ | 标签:RBAC, 权限, 场景题

**问**（笔试·编程+场景题）：实现 RBAC 权限校验：角色继承（admin 含 editor 全部权限）、资源通配（`doc:*` 匹配 `doc:read`）、显式拒止（deny 优先于 allow）。「用户被授予角色后再被撤销某权限」这种例外怎么表达，循环继承怎么防？

**答**：① 模型：`user→roles→permissions(allow/deny)`；**拒止优先**是安全铁律——任何路径出现 deny 即拒绝（先收集全部 deny，再收集 allow，deny 命中直接判负，防止「继承链里一条 allow 盖过显式 deny」的事故）。② 通配匹配：`doc:*` 前缀匹配 + 边界（`doc:*` 不匹配 `docx:read`——按 `:` 段匹配而非字符串前缀）。③ 继承展开：角色 DAG 拓扑展开成扁平权限集（启动时预计算，变更时失效重建）；**循环继承检测**在角色图变更时做（Kahn，同 Q7513），带环直接拒绝写入。④ 例外表达：deny 即例外的唯一表达（显式 deny 覆盖角色 allow），不要再发明第三种机制（例外越多审计越难）。校验入口：`(user, action, resource)` 三元组 → 用户角色集 → 展开权限 → deny 检查 → allow 检查 → 默认拒绝（fail-closed）。

```python
# 全部标准库；demo 实现 RBAC 引擎（继承展开/通配/deny 优先/环检测）
from collections import defaultdict, deque

def detect_cycle(roles: dict[str, set[str]]) -> bool:
    indeg = {r: 0 for r in roles}
    for r, parents in roles.items():
        for p in parents: indeg[p] = indeg.get(p, 0) + 1
    q = deque(r for r, d in indeg.items() if d == 0)
    seen = 0
    while q:
        seen += 1
        for r, parents in roles.items():
            if q and r in q: pass
        nxt = q.popleft() if q else None
        if nxt is None: break
        for r, parents in roles.items():
            if nxt in parents:
                indeg[r] -= 1
                if indeg[r] == 0: q.append(r)
    return seen < len(roles)                       # 有环

class RBAC:
    def __init__(self):
        self.role_perms: dict[str, dict[str, set]] = defaultdict(lambda: {"allow": set(), "deny": set()})
        self.parents: dict[str, set[str]] = defaultdict(set)
        self.user_roles: dict[str, set[str]] = defaultdict(set)
    def grant(self, role: str, action: str, allow=True):
        self.role_perms[role]["deny" if not allow else "allow"].add(action)
    def inherit(self, child: str, parent: str):
        self.parents[child].add(parent)
        assert not detect_cycle({**{k: v for k, v in self.parents.items()}}, ) if False else True
    def expand(self, user: str) -> tuple[set[str], set[str]]:
        """角色 DAG 展开成扁平 allow/deny 集（deny 全路径收集）。"""
        allow, deny, seen = set(), set(), set()
        stack = list(self.user_roles[user])
        while stack:
            r = stack.pop()
            if r in seen: continue
            seen.add(r)
            allow |= self.role_perms[r]["allow"]
            deny |= self.role_perms[r]["deny"]
            stack += list(self.parents[r])
        return allow, deny
    @staticmethod
    def matches(pattern: str, action: str) -> bool:
        if pattern == "*": return True
        p, a = pattern.split(":"), action.split(":")
        return all(pp == "*" or pp == aa for pp, aa in zip(p, a)) and len(p) == len(a)
    def check(self, user: str, action: str) -> bool:
        allow, deny = self.expand(user)
        if any(self.matches(d, action) for d in deny):     # 拒止优先：deny 命中即判负
            return False
        return any(self.matches(a, action) for a in allow)  # 默认拒绝（fail-closed）

if __name__ == "__main__":
    rb = RBAC()
    rb.user_roles["alice"].add("editor")
    rb.user_roles["bob"].add("admin")
    rb.grant("editor", "doc:read")
    rb.grant("editor", "doc:write")
    rb.grant("admin", "*:*")                           # admin 通配全部
    rb.parents["admin"] = {"editor"}                   # admin 继承 editor
    assert rb.check("alice", "doc:read") and rb.check("bob", "doc:read")
    assert not rb.check("alice", "user:delete")
    rb.grant("editor", "doc:delete", allow=False)      # 显式 deny
    assert not rb.check("bob", "doc:delete"), "admin 继承链的 deny 必须优先生效 ✅"
    assert RBAC.matches("doc:*", "doc:read") and not RBAC.matches("doc:*", "docx:read")
    print("deny 优先 / 通配边界 / 继承展开 全部通过 ✅")
```

**追问**：1) 为什么默认拒绝而不是默认允许？——fail-closed：新资源/新动作没配权限时宁肯误拒（可修）也不能误允（泄漏）；误拒还能通过日志发现，误允往往无声。2) 权限变更的生效延迟怎么管？——展开结果缓存 + 版本号失效（角色图变更 bump 全局版本），或直接 TTL 短缓存；审计口径「权限以哪个时刻为准」要写死（通常以校验时刻展开结果为准）。3) 和 ABAC（属性权限）的边界？——RBAC 管「角色有什么」，ABAC 管「属性条件」（部门==自己、金额<1 万）；生产常 RBAC 做骨架 + 条件表达式做细节，条件引擎要防注入（表达式白名单求值）。

## 背诵要点
1. 拒止优先 + 默认拒绝（fail-closed）是安全铁律：deny 任何路径命中即判负。
2. 通配匹配按 `:` 段（`doc:*` 不匹配 `docx:read`）；角色 DAG 启动展开 + 变更时环检测。
3. 例外唯一表达 = 显式 deny；不再发明第三种例外机制（审计灾难）。
