### A009 · 数组中第 K 大的元素

> 难度:★★☆ | 标签:快速选择, 堆

**问**:不排序求第 K 大的元素。要求平均 O(n)。

**答**:快速选择:随机选 pivot 分区(大于 pivot 的在左),pivot 落位下标与 `k-1` 比较,只递归一侧,平均 O(n)(每轮期望砍半,n + n/2 + n/2/2 … = 2n),最坏 O(n²) 由随机 pivot 概率化规避。备选:`heapq.nlargest(k, nums)[-1]` O(n log k) 空间 O(k),适合数据流。

```python
# 示例:code/07_算法专题/(docs 内嵌,复制可运行) a009_kth_largest.py
import random

def find_kth_largest(nums: list[int], k: int) -> int:
    a = list(nums)                  # 不动调用方数据
    target = k - 1                  # 降序语义下第 k 大的下标
    lo, hi = 0, len(a) - 1
    while True:
        if lo == hi:
            return a[lo]
        p = _partition(a, lo, hi, random.randint(lo, hi))
        if p == target:
            return a[p]
        if p < target:
            lo = p + 1
        else:
            hi = p - 1

def _partition(a: list[int], lo: int, hi: int, pivot_idx: int) -> int:
    pivot = a[pivot_idx]
    a[pivot_idx], a[hi] = a[hi], a[pivot_idx]   # pivot 挪到末尾
    store = lo
    for i in range(lo, hi):
        if a[i] > pivot:            # 大的甩到左边(降序分区)
            a[i], a[store] = a[store], a[i]
            store += 1
    a[store], a[hi] = a[hi], a[store]
    return store

if __name__ == "__main__":
    assert find_kth_largest([3, 2, 1, 5, 6, 4], 2) == 5
    assert find_kth_largest([3, 2, 3, 1, 2, 4, 5, 5, 6], 4) == 4  # 含重复
    assert find_kth_largest([1], 1) == 1
    print("A009 ok")
```

**追问**:
- 为什么随机 pivot?——固定取首/尾在已排序输入上退化 O(n²)(快排经典攻击);随机化让期望 O(n) 与输入分布无关。
- 数据流场景怎么办?——维护大小为 k 的小顶堆,`heapq.heappushpop`,O(n log k) 空间 O(k);流式 TopK 是生产高频变体(日志 TopN、排行榜)。
- 「TopK 频繁项」呢?——Counter 计数 + 堆,或海量数据时分桶/Count-Min Sketch 估算(Q349 水位对账的同一套「先分块再归并」思想)。
