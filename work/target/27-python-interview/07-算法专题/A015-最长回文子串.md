### A015 · 最长回文子串

> 难度:★★☆ | 标签:字符串, 双指针, 动态规划

**问**:求字符串中的最长回文子串。

**答**:中心扩展:每个位置尝试奇数中心(i,i)与偶数中心(i,i+1)向两边扩展,记录最大区间。时间 O(n²)、空间 O(1),常数小于 DP 表法(O(n²) 空间),是空间最优的通用解法。Manacher O(n) 是加分谈资,面试通常不要求现场写。

```python
# 示例:code/07_算法专题/(docs 内嵌,复制可运行) a015_longest_palindrome.py
def longest_palindrome(s: str) -> str:
    if len(s) < 2:
        return s
    start = end = 0

    def expand(l: int, r: int) -> tuple[int, int]:
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1
            r += 1
        return l + 1, r - 1            # 退回最后一次有效匹配

    for i in range(len(s)):
        for l, r in (expand(i, i), expand(i, i + 1)):   # 奇/偶中心
            if r - l > end - start:
                start, end = l, r
    return s[start:end + 1]

if __name__ == "__main__":
    assert longest_palindrome("babad") in ("bab", "aba")
    assert longest_palindrome("cbbd") == "bb"
    assert longest_palindrome("a") == "a"
    assert longest_palindrome("ac") == "a"
    assert longest_palindrome("aaaa") == "aaaa"
    print("A015 ok")
```

**追问**:
- 为什么必须同时试奇偶两种中心?——`"bb"` 的回文中心在两字符之间;只试单字符中心会漏掉全部偶数长度回文,是本题最高频 bug。
- DP 表法什么时候反而合适?——要回答「任意区间是否回文」的多查询场景,`is_pal[i][j]` 一次构建;单次查询中心扩展更省内存。
- O(n) 的 Manacher 核心思想?——利用已求回文的镜像对称性复用信息;面试能说清「右边界+镜像」两句话即可,除非岗位明确考字符串算法。
