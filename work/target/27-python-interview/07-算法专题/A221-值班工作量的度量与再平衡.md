### A221 · 值班工作量再平衡

> 难度:★★☆ | 标签:值班, 度量, 团队

**问**（笔试·编程+场景题）：值班表里 zhang 每月 40 次告警、li 每月 12 次——「工作量不均」的量化（告警负担 = 告警数 × 处置时长，不是简单次数），再平衡的手段（告警重新路由/轮换表重排/噪声治理——三个杠杆各自影响什么），「均衡 ≠ 平均」（能力差异导致的处置时长不同怎么算），再平衡后的效果验证（负担分布的基尼系数变化）？

**答**：① 负担量化：`负担 = Σ(告警数 × 单次处置时长)`——zhang 的 40 次 × 10 分钟 = 400 分钟，li 的 12 次 × 30 分钟 = 360 分钟——**次数少不等于负担轻**（次数与时长两个维度都要看）；处置时长来自工单/trace 记录（客观，非自报）。② 三杠杆：**告警重新路由**（路由矩阵调整：zhang 背的告警分给其他 owner——治「分配不均」）、**轮换表重排**（A188 排班：高频告警时段轮换——治「时段集中」）、**噪声治理**（Top 噪声源专项——治「总量过大」Q7039）——不均的原因决定用哪个杠杆。③ 均衡≠平均：senior 的处置时长天然短（熟练），按「时长」算会显得 senior 负担轻——正确的公平口径是「告警次数 × 岗位责任」（次数均摊，时长差异是能力差异不强行平均）——「公平」是机会公平（都有相同次数的班），不是产出平均。④ 验证：负担分布的**基尼系数**（不均衡度）治理前后对比 + 主观疲劳调研（客观数据+主观感受双验证）。

```python
# 全部标准库；demo 实现「负担量化 + 再平衡」
import statistics

def burden(alerts: list[dict]) -> dict[str, float]:
    """负担 = Σ(告警数 × 单次处置分钟)。"""
    b = {}
    for a in alerts:
        b[a["owner"]] = b.get(a["owner"], 0) + a["minutes"]
    return b

def gini(values: list[float]) -> float:
    """基尼系数（0=完全均衡，1=完全不均）。"""
    xs = sorted(values)
    n = len(xs)
    total = sum(xs)
    if total == 0: return 0.0
    cum = sum((i + 1) * x for i, x in enumerate(xs))
    return (2 * cum - (n + 1) * total) / (n * total)

def rebalance_lever(burden: dict[str, float], avg: float) -> list[str]:
    """再平衡杠杆：按不均类型选。"""
    out = []
    for p, b in burden.items():
        if b > avg * 2:
            out.append(f"{p}: 负担 {b:.0f}min（{b/avg:.1f}× 平均）→ 告警重路由 + Top 噪声专项")
    return out or ["负担分布健康"]

if __name__ == "__main__":
    alerts = ([{"owner": "zhang", "minutes": 10}] * 40 +
              [{"owner": "li", "minutes": 30}] * 12)
    b = burden(alerts)
    print("负担分钟:", b)
    avg = statistics.mean(b.values())
    print("基尼系数:", round(gini(list(b.values())), 2))
    print("再平衡杠杆:", rebalance_lever(b, avg))
    # 口径：负担 = 次数×时长（双维度）；公平=机会公平（次数）而非产出平均；
    # 基尼系数验证再平衡效果 + 主观疲劳调研双验证。
```

**追问**：1) 为什么「次数 × 时长」比「次数」更准确的量化负担？——10 次 5 分钟的告警（30 分钟）比 3 次 40 分钟的告警（120 分钟）负担轻得多；次数口径会把「长尾难题的承担者」误判为轻负担——时长是真正的精力消耗度量（时长从工单/trace 客观取）。2) 「能力差异不强行平均」的边界？（提示：能力差异（senior 快）不平均（那是成长红利）；但「机会分配」要平均（senior 不能永远挑简单班）——公平分层：班次机会公平 + 产出时长自然差异 + 培养机会（Q190）向 junior 倾斜——三层各自的公平口径不同）3) 基尼系数 >0.5 的团队会发生什么？（提示：高不均衡 = 少数人 burnout（离职→更不均衡的恶性循环）+ 多数人「没成长」（没参与核心告警处置）——再平衡不只是福利，是团队韧性与梯队建设（Q190 覆盖矩阵联动））

## 背诵要点
1. 负担 = Σ(告警数 × 处置时长) 双维度量化，时长客观取自工单/trace——次数口径会误判长尾承担者。
2. 三杠杆按不均根因选：重路由（分配不均）/轮换重排（时段集中）/噪声专项（总量过大）。
3. 公平 = 机会公平（次数均摊）而非产出平均（时长是能力差异）；基尼系数 + 主观调研双验证。

## 复盘追问
1. 再平衡后 zhang 投诉「分给我的告警都是难缠的」（次数少了时长没少），怎么破？（提示：暴露了「时长口径」的问题——分派时按「预估时长」配平（不只按次数）+ 难缠告警配 mentor 协助（成长机会）——配平的粒度要从次数升级到时长预估）
2. 「客观负担 + 主观疲劳」两个数据打架（客观负担低但大家都说累），信哪个？（提示：都信——客观负担低可能因「告警少但每次都是硬仗」（时长统计漏了隐性消耗：被打断的上下文切换成本）——主观调研的「上下文切换疲劳」维度补客观口径盲区，两个数据合起来才是真相）
