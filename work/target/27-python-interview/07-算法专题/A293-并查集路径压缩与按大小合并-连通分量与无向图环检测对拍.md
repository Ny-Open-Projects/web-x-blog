### A293 · 并查集路径压缩与按大小合并：连通分量、无向图环检测与 BFS 对拍

> 难度:★★★☆ | 标签:并查集, 路径压缩, 按秩合并, 环检测, 对拍

**问**（笔试·编程题）：给 n 个点和 m 条无向边（边可能重复、可能自环），用并查集回答「有几个连通块」和「有没有环」：① `parent` 与 `size` 各表示什么，`find` 为什么必须写迭代 + 两趟压缩，递归版在 20 万点的链上会发生什么；② 按大小合并为什么能把树高压到 O(log n)，叠加路径压缩后为什么是摊还 O(α(n))，α(n) 到底有多小、为什么不能直接说「O(1)」；③ `union` 返回 `False` 意味着什么，自环算不算环，无向图里的重边（平行边）算不算环，输入里的重复边在工程上应该怎么处理；④ 连通分量数怎么在合并过程中 O(1) 维护，为什么恒等于 n 减去成功合并次数，孤立点算不算；⑤ 与 BFS 数连通块 + DFS 带父边判环的参考实现做 80 组随机图对拍（含重边与自环），再用 20 万点长链、长链加一条边成环、星形跑极值，并说清与 A251（拓扑排序判环）的分工。

**答**：① `parent[x]` 是 x 的父指针，只有根满足 `parent[x] == x`；`size[x]` 只对根有意义，表示该连通块的点数。`find` 写成两趟迭代：第一趟沿父指针走到根，第二趟把路径上每个点直接挂到根。不能用递归，因为递归是「先下潜到根、回溯时才压缩」，下潜阶段没有任何压缩，20 万点的链会先递归 20 万层，Python 默认递归上限 1000，直接 `RecursionError`——注意这不是「加了路径压缩就不会爆栈」，压缩发生在回溯，救不了下潜。② 按大小合并保证每次都是小树挂到大树下面，任何点的深度最多在「所在块大小翻倍」时加 1，所以树高 ≤ ⌊log2 n⌋；路径压缩把被访问路径压成「根的直接孩子」，两者叠加后单次操作的摊还代价是 O(α(n))，α 是反阿克曼函数，n 到 2^65536 时 α 也只有 5 左右。但不能说 O(1)：单次 `find` 在压缩前仍可能走 O(log n) 步，O(α(n)) 是**摊还**界，面试要主动区分「单次最坏」与「m 次摊还」。③ `union` 返回 `False` ⇔ 两个端点已经同根，这条边加入会形成回路——因为树上的两点之间本来就有唯一路径，再连一条就是环。自环 `(u,u)` 两端同根，返回 `False`，判环正确。无向图里同一条边出现两次，第二次也会因同根返回 `False`，在**多重图**语义下这确实是长度 2 的环；但工程输入里的重复边往往是日志重复投递、上游 join 放大导致的脏数据，正确做法是先按 `(min(u,v), max(u,v))` 去重再建图，否则会把数据质量问题误报成业务环——这一点必须向面试官问清「图是否允许平行边」。④ 初始化 `components = n`，每次成功 `union` 减 1，失败不减：成功合并恰好把两个不同的连通块并成一个，块数精确减 1，所以恒有 `components == n - 成功合并次数`；孤立点从未出现在任何边里，但它自身就是一个连通块，初始的 n 已经把它算进去了，不需要额外补偿。⑤ 对拍：参考实现用邻接表 BFS 数连通块；判环用 DFS，但邻接表里要存 **边 id** 而不是只存父节点——只比较「邻居 != 父节点」会把重边误判成环，用边 id 跳过「来的那条边」才和 DSU 的多重图语义一致。随机 80 组 n=0..12、m=0..18，含自环与重边；极值用 20 万点长链（1 个块、无环）、长链再加 `(0, n-1)`（有环）、星形（1 个块、合并后树高 ≤ 2）。与 A251 的分工：A251 处理**有向**依赖图，用 Kahn 拓扑排序给出分层批次、并能输出一条具体的环路径；本题处理**无向**图的连通性与环的**存在性**，DSU 只能回答「有没有环」，给不出环路径，也不能直接用于有向图（`u→v` 与 `v→u` 是不同关系，合并会丢掉方向）。

```python
# 全部标准库；并查集（路径压缩 + 按大小合并）连通分量与无向图环检测，与 BFS/DFS 对拍
import random
from collections import deque


class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
        self.components = n
        self.merges = 0

    def find(self, x):
        # 迭代找根 + 两趟路径压缩，避免递归在 20 万链上爆栈
        root = x
        while self.parent[root] != root:
            root = self.parent[root]
        while self.parent[x] != root:
            self.parent[x], x = root, self.parent[x]
        return root

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False                 # 同根：这条边会成环
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra              # 按大小合并，小的挂到大的下面
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        self.components -= 1
        self.merges += 1
        return True


def dsu_summary(n, edges):
    d = DSU(n)
    cycle = False
    for u, v in edges:
        if not d.union(u, v):
            cycle = True
    return d.components, cycle


def bfs_summary(n, edges):
    """参考实现：邻接表 + BFS 数连通块；DFS 带父边判无向环（边 id 区分重边）。"""
    adj = [[] for _ in range(n)]
    for eid, (u, v) in enumerate(edges):
        adj[u].append((v, eid))
        adj[v].append((u, eid))
    seen = [False] * n
    comp = 0
    for s in range(n):
        if seen[s]:
            continue
        comp += 1
        seen[s] = True
        q = deque([s])
        while q:
            x = q.popleft()
            for y, _ in adj[x]:
                if not seen[y]:
                    seen[y] = True
                    q.append(y)

    cycle = False
    visited = [False] * n
    for s in range(n):
        if visited[s]:
            continue
        visited[s] = True
        stack = [(s, -1)]
        while stack:
            x, pe = stack.pop()
            for y, eid in adj[x]:
                if eid == pe:            # 同一条边不能原路返回
                    continue
                if visited[y]:
                    cycle = True
                else:
                    visited[y] = True
                    stack.append((y, eid))
    return comp, cycle


if __name__ == "__main__":
    rng = random.Random(2931)

    # 1) 80 组随机无向图（n=0..12，含重边与自环）与 BFS/DFS 参考实现对拍
    for _ in range(80):
        n = rng.randint(0, 12)
        m = rng.randint(0, 18)
        edges = [(rng.randrange(n), rng.randrange(n)) for _ in range(m)] if n else []
        assert dsu_summary(n, edges) == bfs_summary(n, edges), (n, edges)
    print("并查集对拍: 80 组随机图（含重边/自环）分量数+环标记 vs BFS/DFS，全等 ✅")

    # 2) 边界：0 点、1 点自环、单边、树、三角形、重边
    assert dsu_summary(0, []) == (0, False)
    assert dsu_summary(1, []) == (1, False)
    assert dsu_summary(1, [(0, 0)]) == (1, True)          # 自环成环
    assert dsu_summary(2, [(0, 1)]) == (1, False)
    assert dsu_summary(4, [(0, 1), (1, 2), (2, 3)]) == (1, False)   # 树：3 条边 4 点
    assert dsu_summary(3, [(0, 1), (1, 2), (2, 0)]) == (1, True)    # 三角形
    assert dsu_summary(2, [(0, 1), (0, 1)]) == (1, True)            # 重边在多图里也是环
    print("边界: 空图/单点自环/树/三角形/重边 全过 ✅")

    # 3) 分量数守恒：components == n - 成功合并次数，且每次成功合并恰好减 1
    d = DSU(10)
    ok = 0
    for u, v in [(0, 1), (2, 3), (1, 3), (5, 6), (7, 7), (1, 2), (8, 9)]:
        if d.union(u, v):
            ok += 1
        assert d.components == 10 - ok
    assert d.components == 5 and d.merges == ok == 5
    print("守恒律: components = n - 成功合并次数，逐次断言 ✅")

    # 4) 极值：20 万点长链 + 长环 + 星形；路径压缩后树高有界
    n = 200000
    chain = [(i, i + 1) for i in range(n - 1)]
    assert dsu_summary(n, chain) == (1, False)
    assert dsu_summary(n, chain + [(0, n - 1)]) == (1, True)
    star = [(0, i) for i in range(1, n)]
    d = DSU(n)
    for u, v in star:
        d.union(u, v)
    assert d.components == 1
    depth = 0
    x = n - 1
    while d.parent[x] != x:
        x = d.parent[x]
        depth += 1
    assert depth <= 2                                # 星形合并后要么是根要么是根的儿子
    print("极值: 20 万点长链/加一条边成环/星形，树高 <= 2 ✅")

    print("对拍通过：并查集 80 组随机 + 7 条边界 + 守恒律 + 20 万极值全绿")
```

**追问**：1) 带权并查集怎么做？—— 在 `parent` 之外再维护 `weight[x]` 表示「x 到 parent[x] 的边权」，`find` 压缩时把路径上的权累加并改写为「x 到根的权」，`union` 时根据两个根之间的约束反解偏移；典型题是食物链（模 3 距离）、等式方程可满足性（相等/不等约束）。此时不能再随便按大小合并，权值方向要跟着根一起换。2) 并查集能支持删边吗？—— 不能直接删，因为合并是不可逆的。标准套路是**离线倒序**：把所有操作读进来，从最终状态建图，逆序把「删边」变成「加边」；若要求在线动态连通性，需要 LCT（Link-Cut Tree）或 Euler Tour Tree，远超笔试范围。3) 有向图判环为什么不能用并查集？—— 并查集表达的是无向等价关系，`u→v` 和 `v→u` 被合并成同一集合后方向信息就丢了；有向图要用 Kahn（入度归零）或 DFS 三色标记（白/灰/黑），而且这两种方法还能还原出一条具体环路径，DSU 只能说「有环」。
