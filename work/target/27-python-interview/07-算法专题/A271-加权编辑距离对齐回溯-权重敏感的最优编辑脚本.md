### A271 · 加权编辑距离与对齐回溯

> 难度:★★★★ | 标签:编辑距离, 动态规划, 回溯, 对齐, 编辑脚本

**问**（笔试·编程题）：Levenshtein 距离人人会背，面试官要往下挖两层：实现**加权版**编辑距离——插入/删除/替换各带权重（如错字纠正场景替换代价 1、增删代价 2；DNA 序列场景替换是「突变」代价反而最高），并做到：① O(nm) DP 求最小总代价，状态转移要写清三个来源；② **完整回溯**：从 (n,m) 反推操作序列，输出**对齐展示**（两行带空位 `-` 的对齐串）与**编辑脚本**（= 保留 / + 插入 / - 删除 / s 替换）；③ 用同一对字符串验证**权重改变最优解**：`abc→axc` 在替换权重 1 时最优脚本是一次替换，替换权重 3 时最优脚本变成「删 b 插 x」——断言两种权重下的脚本不同、总代价不同；④ 脚本**回放自证**：把操作序列应用回源串必须精确还原目标串；⑤ 边界：等长无差异应零代价、脚本是纯保留链。请说清与 A244（Myers 行级 diff：只许 insert/delete、LCS 语义、O((N+M)·D) 速度优化，不处理权重与替换）、Q2748（编辑距离截断的候选集裁剪优化）、Q2100（difflib 库用法）的分工——本题只回答「**带权代价模型的 DP 本体、回溯还原与权重如何改变最优解**」。

**答**：① 分工：A244 的 Myers 是「行级、只删增、求最短脚本」的速度特化，代价模型里替换 = 删 + 增；本题反其道——**代价模型是可配的**，替换可以比删加便宜（错字）也可以比删加贵（突变），而 DP 本体在两个模型下都成立。这正是笔试考点：编辑距离不是「一个数」，是「一族代价模型下的最优值」——换权重答案就变，背答案的当场露馅。② 状态转移三个来源：`dp[i][j] = min(dp[i-1][j] + w_del, dp[i][j-1] + w_ins, dp[i-1][j-1] + (0 or w_sub))`——删除吃掉 a[i-1]、插入补出 b[j-1]、替换/匹配对齐两者；相等字符走 0 代价分支，这保证「无损对齐」永远优先。边界 `dp[0][j] = j·w_ins`、`dp[i][0] = i·w_del`。③ 回溯：从 (n,m) 出发，检查当前格由哪个来源转移而来（优先级顺序决定并列时的 tie-break，本题按「替换/匹配 > 删除 > 插入」检查——**并列时 tie-break 决定输出哪条最优脚本**，多个最优解时没有唯一答案，面试里说清这一点是加分项），把操作 push 进列表再反转。对齐展示：保留与替换消耗两串各一字符，插入在 a 行补 `-`，删除在 b 行补 `-`——输出的两行就是序列比对教科书里的 alignment 图。④ 权重敏感实测：`abc→axc`，替换权重 1：最优 = 一次替换 b→x，代价 1；替换权重 3：替换比「删 + 插」（代价 2×1=2）更贵，最优脚本翻转为删除 b、插入 x，代价 2。两种模型下脚本与代价都不同——这就是「代价模型决定最优解」的最小反例。对 kitten→sitting（全 1 权重）距离仍是教科书值 3（k→s 替换、e 删除、g 插入）。⑤ 回放自证：把 ops 顺序应用回源串得到目标串，逐例断言——回溯代码最容易出「对齐对了但脚本错了」的 bug（如替换记成删除+插入），回放是唯一可信校验。工程注脚：全矩阵 O(nm) 内存是回溯的代价（A244 里 Myers 为此付出快照内存）；只求距离不求对齐时滚动数组压到 O(min(n,m))，但**一旦要脚本就必须存全矩阵或用 Hirschberg 分治换空间**——「要不要对齐」决定了内存预算，这是本题与纯距离题的分界。

```python
# 全部标准库；加权编辑距离：O(nm) DP + 回溯对齐 + 编辑脚本回放自证
GAP = "-"


def weighted_edit(a, b, w_ins=1.0, w_del=1.0, w_sub=1.0):
    """返回 (总代价, ops, row_a, row_b)。
    ops: ('=', c) 保留 / ('s', old, new) 替换 / ('-', c) 删除 / ('+', c) 插入。
    row_a/row_b: 带空位对齐串。权重必须显式传参，无隐式默认耦合。"""
    n, m = len(a), len(b)
    dp = [[0.0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        dp[i][0] = dp[i - 1][0] + w_del
    for j in range(1, m + 1):
        dp[0][j] = dp[0][j - 1] + w_ins
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            sub = dp[i - 1][j - 1] + (0.0 if a[i - 1] == b[j - 1] else w_sub)
            dele = dp[i - 1][j] + w_del
            ins = dp[i][j - 1] + w_ins
            dp[i][j] = min(sub, dele, ins)

    # 回溯：并列时 tie-break 决定输出哪条最优脚本（替换/匹配 > 删除 > 插入）
    ops, ra, rb = [], [], []
    i, j = n, m
    while i > 0 or j > 0:
        if i > 0 and j > 0:
            if a[i - 1] == b[j - 1] and dp[i][j] == dp[i - 1][j - 1]:
                ops.append(("=", a[i - 1]))
                ra.append(a[i - 1]); rb.append(b[j - 1])
                i -= 1; j -= 1
                continue
            if a[i - 1] != b[j - 1] and dp[i][j] == dp[i - 1][j - 1] + w_sub:
                ops.append(("s", a[i - 1], b[j - 1]))
                ra.append(a[i - 1]); rb.append(b[j - 1])
                i -= 1; j -= 1
                continue
        if i > 0 and dp[i][j] == dp[i - 1][j] + w_del:
            ops.append(("-", a[i - 1]))
            ra.append(a[i - 1]); rb.append(GAP)
            i -= 1
        else:
            ops.append(("+", b[j - 1]))
            ra.append(GAP); rb.append(b[j - 1])
            j -= 1
    ops.reverse(); ra.reverse(); rb.reverse()
    return dp[n][m], ops, "".join(ra), "".join(rb)


def apply_ops(a, ops):
    """编辑脚本回放：从源串逐段还原目标串，回溯正确性的自证。"""
    out, i = [], 0
    for op in ops:
        if op[0] == "=" or op[0] == "s":
            i += 1                              # 源串消耗一个字符
        if op[0] == "=":
            out.append(a[i - 1])
        elif op[0] == "s":
            out.append(op[2])                   # 替换成新字符
        elif op[0] == "-":
            i += 1                              # 删除：只消耗不产出
        else:
            out.append(op[1])                   # 插入：只产出不消耗
    return "".join(out)


if __name__ == "__main__":
    # 1) 教科书例：kitten->sitting，全 1 权重距离 = 3
    cost, ops, ra, rb = weighted_edit("kitten", "sitting")
    assert cost == 3.0, cost
    assert apply_ops("kitten", ops) == "sitting"
    print("kitten->sitting: 距离 %d，对齐 %s / %s，脚本 %d 步 ✅"
          % (cost, ra, rb, len(ops)))

    # 2) 权重改变最优解：abc->axc，替换贵时「一次替换」翻转为「删 + 插」
    cost1, ops1, ra1, rb1 = weighted_edit("abc", "axc", w_sub=1.0)
    assert cost1 == 1.0 and ops1 == [("=", "a"), ("s", "b", "x"), ("=", "c")], ops1
    cost3, ops3, ra3, rb3 = weighted_edit("abc", "axc", w_sub=3.0)
    assert cost3 == 2.0 and {op[0] for op in ops3 if op[0] != "="} == {"+", "-"}, ops3
    assert apply_ops("abc", ops3) == "axc"
    print("权重敏感: w_sub=1 最优 [替换 b->x] 代价 %.0f；w_sub=3 翻转为 %s 代价 %.0f ✅"
          % (cost1, [op[0] for op in ops3 if op[0] != "="], cost3))

    # 3) 对齐展示：等长替换时两行无空位，错位时补 '-'
    print("对齐一: %s / %s（无空位）" % (ra1, rb1))
    print("对齐二: %s / %s（含空位）" % (ra3, rb3))

    # 4) 等长无差异：零代价，脚本是纯保留（全 '='）
    cost0, ops0, _, _ = weighted_edit("same", "same")
    assert cost0 == 0.0 and all(op[0] == "=" for op in ops0), ops0
    print("零差异: same==same，代价 0、脚本全保留 ✅")

    # 5) 纯增删混排：回放自证覆盖插入/删除/保留混合路径
    cost, ops, ra, rb = weighted_edit("abcdef", "azcfm", w_ins=1.0, w_del=1.0, w_sub=2.0)
    assert apply_ops("abcdef", ops) == "azcfm" and cost <= 6.0
    print("混排自证: abcdef -> azcfm 代价 %.0f，脚本回放精确还原，对齐 %s / %s ✅"
          % (cost, ra, rb))
```

**追问**：1) 为什么权重敏感时「距离最优」的脚本可能「不唯一」？—— 多条回溯路径的代价和相等（比如先删后插与先插后删代价相同），DP 只保证总和最小、不保证路径唯一；回溯时 tie-break 检查顺序决定输出哪一条。工程上如果对「哪种等价脚本更好读」有要求（比如 diff 工具倾向聚合删除段），是在 tie-break 规则里加偏好，而不是改代价模型——A244 里 patience/histogram「主动放弃最小性换可读性」是同一问题的更激进版本。2) 只求距离不要对齐时，能省什么？—— 时间上做 **Ukkonen 带状裁剪**：只算 `|i-j| ≤ k` 的对角带（k 是答案上界），复杂度降到 O(k·min(n,m))；空间上滚动数组压到 O(min(n,m))。但**要脚本/对齐就必须存全矩阵**（或 Hirschberg 分治：空间 O(n)、时间翻倍常数）——面试官问「滚动数组为什么不能出对齐」时，答案是被丢弃的行正是回溯需要的路径，这就是「距离题」与「对齐题」的分界线。3) 权重模型里替换为什么有时比删+增贵？—— 代价模型编码的是**领域语义**：文本纠错里替换=打错一个字（便宜），删+增=重写（贵）；生物序列比对里替换=点突变（贵），插入/删除=片段移位（相对便宜）——所以 DNA 比对（Needleman-Wunsch）的经典权重矩阵让 mismatch 比 gap pair 更贵。权重表甚至可以不是三个数而是 256×256 的代价矩阵（字符相似度：o↔0、l↔1 近零代价），DP 转移一行不改——这正是「代价模型与算法本体解耦」的价值：**面试里能说清「算法不变、代价可插拔」，比背出 O(nm) 高一个层级**。

## 背诵要点
1. 转移三来源：dp[i][j] = min(删+wdel, 插+wins, 对齐+0/wsub)；相等字符走 0 代价分支；边界 dp[0][j]=j·w_ins、dp[i][0]=i·w_del。
2. 回溯从 (n,m) 反推，tie-break 决定等价脚本输出哪条；对齐串用 `-` 补空位；脚本回放自证是唯一可信校验。
3. 权重敏感：abc→axc 在 w_sub=1 最优是一次替换，w_sub=3 翻转为删+插——代价模型决定最优解；只要距离可滚动数组+带状裁剪，要对齐必须存全矩阵（或 Hirschberg 分治）。
