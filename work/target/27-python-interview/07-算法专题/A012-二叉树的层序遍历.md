### A012 · 二叉树的层序遍历

> 难度:★☆☆ | 标签:树, BFS

**问**:按层输出二叉树节点值(每层一个列表)。

**答**:BFS + 队列:每轮先记 `len(q)` 得到当前层节点数,恰好出队这么多个,把子节点入队——层级信息用「按层计数」而不是往队列里塞 None。O(n) 时间,空间 O(宽度)。

```python
# 示例:code/07_算法专题/(docs 内嵌,复制可运行) a012_level_order.py
from collections import deque

class TreeNode:
    def __init__(self, val: int, left: "TreeNode | None" = None, right: "TreeNode | None" = None):
        self.val, self.left, self.right = val, left, right

def level_order(root: "TreeNode | None") -> list[list[int]]:
    if root is None:
        return []
    res: list[list[int]] = []
    q: deque[TreeNode] = deque([root])
    while q:
        level: list[int] = []
        for _ in range(len(q)):     # 固定本层节点数
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        res.append(level)
    return res

if __name__ == "__main__":
    root = TreeNode(3, TreeNode(9), TreeNode(20, TreeNode(15), TreeNode(7)))
    assert level_order(root) == [[3], [9], [20], [15, 7]]
    assert level_order(None) == []
    print("A012 ok")
```

**追问**:
- 为什么用 deque 不用 list?——`list.pop(0)` 是 O(n) 搬移,deque popleft O(1)(Q061 同一个知识点);用 list 写 BFS 是常见性能失分。
- 「之字形层序」怎么改?——奇数层反向:出队后 `level.reverse()`,或双端队列交替 appendleft;BFS 框架不变。
- 层序在工程里的样子?——目录树逐层遍历、图的最短路(BFS 天然最短边数)、消息队列的逐层扇出;树题先问「能不能层序」是面试习惯。
