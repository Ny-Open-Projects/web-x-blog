### A117 · 任务调度器

> 难度:★★☆ | 标签:调度, 优先级队列, 公平性

**问**（笔试·编程题）：实现一个多租户任务调度器：任务带优先级（1-10），要求① 高优先级先执行；② **同优先级下租户间公平**（租户 A 1000 个任务不能饿死租户 B 的 1 个）；③ 支持动态调整优先级。为什么「只用一个堆按 (priority, submit_time) 排」不满足 ②？写出公平调度实现。

**答**：单一堆的问题：`(priority, submit_time)` 排序下，租户 A 高频提交会占据每层优先级的前列（submit_time 早），租户 B 的任务永远排后——**饿死**。公平调度 = **加权轮转（WRR）在租户层 + 堆在任务层**的两级结构：① 顶层：按租户轮转（带权重：付费租户权重 2，免费 1——轮询时按权重领名额）；② 底层：每个租户一个自己的堆（内部按优先级+时间）。防饿死关键：**轮转是按租户循环的，不是按任务时间**——B 只有 1 个任务，轮到 B 时它必然被执行。③ 动态调优先级：lazy 更新（堆里放旧优先级，pop 时发现与最新不符则用最新值重新压入——标准「无效条目跳过」模式），避免堆内删除（heapq 不支持高效删除）。

```python
# 全部标准库；demo 实现两级公平调度 + lazy 优先级更新
import heapq, itertools

class Scheduler:
    def __init__(self, weights: dict[str, int] | None = None):
        self.tenants: dict[str, list] = defaultdict(list)   # tenant -> 堆
        self.seq = itertools.count()                        # 同优先级 FIFO 兜底
        self.weights = weights or {}
        self.cursor = 0
    def submit(self, tenant: str, priority: int, task: str):
        heapq.heappush(self.tenants[tenant], (priority, next(self.seq), task))
    def tenant_order(self, tenants: list[str]) -> list[str]:
        """加权轮转顺序（权重=w 的租户在每轮出现 w 次）。"""
        order = []
        for t in sorted(tenants):                           # 排序保证确定性
            order += [t] * self.weights.get(t, 1)
        return order
    def pop(self) -> tuple[str, str] | None:
        tenants = [t for t, heap in self.tenants.items() if heap]
        if not tenants:
            return None
        order = self.tenant_order(tenants)
        t = order[self.cursor % len(order)]                 # 加权轮转
        self.cursor += 1
        heap = self.tenants[t]
        # lazy 优先级更新：pop 时跳过过期条目（valid 检查略，演示直接 pop）
        prio, _seq, task = heapq.heappop(heap)
        if not heap:
            del self.tenants[t]
        return t, task

class LazyPriority:
    """动态调优先级的 lazy 模式：入口表存最新值，pop 时校验。"""
    def __init__(self):
        self.heap = []                                      # (prio, seq, task)
        self.latest: dict[str, int] = {}                    # task -> 最新优先级
        self.seq = itertools.count()
    def submit(self, task: str, prio: int):
        self.latest[task] = prio
        heapq.heappush(self.heap, (prio, next(self.seq), task))
    def update(self, task: str, prio: int):
        self.latest[task] = prio                            # 只改入口表，堆不动
        heapq.heappush(self.heap, (prio, next(self.seq), task))  # 压入新条目
    def pop(self) -> str | None:
        while self.heap:
            prio, _, task = heapq.heappop(self.heap)
            if self.latest.get(task) != prio:
                continue                                    # 过期条目：跳过
            del self.latest[task]
            return task
        return None

if __name__ == "__main__":
    from collections import defaultdict
    s = Scheduler(weights={"a": 2, "b": 1})
    for i in range(100):                                    # 租户 a 密集提交
        s.submit("a", 1, f"a-{i}")
    s.submit("b", 1, "b-0")                                 # 租户 b 只有 1 个
    got_b = None
    for i in range(50):                                     # 50 次调度内 b 必被执行（不饿死）
        r = s.pop()
        if r and r[0] == "b":
            got_b = i
            break
    assert got_b is not None and got_b < 10, f"b 在第 {got_b} 次被调度"
    print(f"公平性：b 的任务在第 {got_b} 次调度即执行（a 有 100 个也没饿死它）✅")
    lp = LazyPriority()
    lp.submit("t1", 9)
    lp.update("t1", 1)                                      # 临时调到最高
    lp.submit("t2", 5)
    assert lp.pop() == "t1"                                 # lazy 更新生效
    print("动态优先级（lazy 双条目跳过旧值）✅")
    # 口径：单一堆按时间排序必饿死低频租户；两级结构=租户 WRR+租户内堆；
    # lazy 更新用「压新条目+pop 校验」替代堆内删除。
```

**追问**：1) 为什么权重轮转而非「按租户任务量比例分时间片」？——比例分配（processor sharing）在任务极不均时实现复杂且突发下抖动；WRR 简单确定、饿死免疫，权重粗粒度足够表达「付费优先」。2) `cursor` 在租户增减时会错位吗？——会（order 长度变化），影响一轮内顺序但不影响公平性（轮转本质是循环）；要严格稳定就用每租户虚拟时间（DRF/weighted fair queueing），成本换精度看业务。3) 同优先级 FIFO 用 seq 保证——为什么不用提交时间戳？——时钟回拨/精度问题，单调 seq 更可靠（生成时间戳的坑与 Q505 一致）。

## 背诵要点
1. 单一堆按 (priority, time) 排必饿死低频租户；公平调度 = 租户层加权轮转 + 租户内堆，两级。
2. 动态优先级 lazy 更新：压入新条目 + pop 时校验跳过旧条目，替代堆内删除。
3. 同优先级 FIFO 用单调 seq 而非时间戳（时钟回拨免疫）。
