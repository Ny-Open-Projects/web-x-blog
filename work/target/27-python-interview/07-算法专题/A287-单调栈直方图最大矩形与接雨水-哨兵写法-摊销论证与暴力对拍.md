### A287 · 单调栈双题：直方图最大矩形与接雨水，哨兵写法、O(n) 摊销论证与暴力对拍

> 难度:★★★☆ | 标签:单调栈, 直方图, 接雨水, 摊销分析, 对拍

**问**（笔试·编程题）：同一套单调栈骨架解两道经典题，面试官看的是「**不变量 + 摊销**」而不是背模板：① `largest_rect(h)`：直方图最大矩形面积，要求**两端加 0 哨兵**、栈内下标对应高度严格递增，弹出时一次性结算「以该柱为最矮柱的区间」；② `trap(h)`：接雨水，分别给出**单调栈版**（按层结算凹槽）与**双指针版**（从左右最大值较小侧推进），两版互相对拍；③ 论证两题的 **O(n) 摊销**：每个下标最多入栈一次、出栈一次；④ 与暴力 O(n²) 参考实现做 40 组随机对拍，并覆盖空、单元素、全相同、含 0 与极大值边界；⑤ 说清与 A006（盛最多水的容器·双指针贪心）、A281（区间调度·堆分配）的分工——本题只回答「**用单调栈结算贡献、以及为什么它是线性的**」。

**答**：① 分工：A006 求「两条线 + 底边」围成的容器，双指针每步丢弃较短边有贪心证明；A281 用堆做区间资源分配；本卡是**单调栈**家族——直方图求「以某柱为最小值的最大跨度」，接雨水求「每个凹槽按层蓄水」，两题共用「栈内单调 + 弹出即结算」的骨架。② 直方图的不变量：栈内保存**高度递增的下标**；扫到 `i` 时若 `h[stack[-1]] > h[i]`，栈顶柱的右边界首次确定（就是 `i`），左边界是弹出后的新栈顶（第一个比它矮的柱），面积 `h[mid] * (i - stack[-1] - 1)`——两端补 0 哨兵把「循环结束后清栈」统一成一次普通弹出，不用写后处理，且空数组也不用特判。③ 接雨水栈版：栈内是**高度递减**的下标，遇到更高的 `x` 就弹出 `mid`，`mid` 形成凹槽底部、左右墙为 `stack[-1]` 与 `i`，这一层水量 `(min(h[left], x) - h[mid]) * (i - left - 1)`；双指针版的不变量是「左右最大值中较小的一侧，其蓄水量已可确定」，每步只推进较小侧，O(1) 额外空间。④ 摊销论证：每个下标恰好入栈一次，出栈也只可能一次（弹出后不再回栈），故 `while` 总执行次数 ≤ n，外层 n 次，合计 O(n)——注意这不是「单次均摊 O(1) 查询」，而是**总操作数的紧上界**；最坏单次仍可能连弹 n 个，写复杂度时口径别混。⑤ 易错点：直方图用 `>` 而非 `>=` 决定相同高度是否当场结算（用 `>` 让相同高度靠后那根柱结算更大跨度，结果不变且不重不漏）；接雨水栈版弹空后必须 `break`（左边无墙存不住水），漏了会越界或算出负水量；双指针循环用 `l < r` 而不是 `<=`（相遇点无需再算）。

```python
# 全部标准库；单调栈双题：直方图最大矩形 + 接雨水（栈版/双指针版），与暴力对拍
import random


def largest_rect_brute(h):
    """参考实现：枚举左右端点，区间最小值即高，O(n^2)。"""
    best = 0
    for i in range(len(h)):
        lo = h[i]
        for j in range(i, len(h)):
            lo = min(lo, h[j])
            best = max(best, lo * (j - i + 1))
    return best


def largest_rect(h):
    """目标实现：高度递增栈 + 两端 0 哨兵，弹出即结算。"""
    hs = [0] + list(h) + [0]
    stack = [0]
    best = 0
    for i in range(1, len(hs)):
        while hs[stack[-1]] > hs[i]:
            mid = stack.pop()
            best = max(best, hs[mid] * (i - stack[-1] - 1))
        stack.append(i)
    return best


def trap_brute(h):
    """参考实现：逐格取左右最大值，O(n^2)。"""
    total = 0
    for i in range(len(h)):
        left = max(h[:i + 1])
        right = max(h[i:])
        total += min(left, right) - h[i]
    return total


def trap_stack(h):
    """目标实现 A：高度递减栈，按层结算凹槽。"""
    stack = []
    total = 0
    for i, x in enumerate(h):
        while stack and h[stack[-1]] < x:
            mid = stack.pop()
            if not stack:                      # 左边没墙，存不住水
                break
            left = stack[-1]
            total += (min(h[left], x) - h[mid]) * (i - left - 1)
        stack.append(i)
    return total


def trap_two_ptr(h):
    """目标实现 B：左右最大值较小侧推进，O(1) 空间。"""
    l, r = 0, len(h) - 1
    lm = rm = 0
    total = 0
    while l < r:
        if h[l] < h[r]:
            lm = max(lm, h[l])
            total += lm - h[l]
            l += 1
        else:
            rm = max(rm, h[r])
            total += rm - h[r]
            r -= 1
    return total


if __name__ == "__main__":
    rng = random.Random(2871)

    # 1) 直方图：40 组随机（高度 0~30，长度 0~40）与 O(n^2) 暴力对拍
    for _ in range(40):
        h = [rng.randint(0, 30) for _ in range(rng.randint(0, 40))]
        assert largest_rect(h) == largest_rect_brute(h), h
    print("直方图对拍: 40 组随机 vs O(n^2) 暴力，全等 ✅")

    # 2) 接雨水：40 组随机，栈版与双指针版分别对齐暴力（三方互证）
    for _ in range(40):
        h = [rng.randint(0, 30) for _ in range(rng.randint(0, 40))]
        ref = trap_brute(h)
        assert trap_stack(h) == ref, ("stack", h)
        assert trap_two_ptr(h) == ref, ("two_ptr", h)
    print("接雨水对拍: 40 组随机，栈版/双指针版/暴力三方全等 ✅")

    # 3) 手写边界：空、单元素、全相同、全 0、单调升降、极大值
    assert largest_rect([]) == 0 and trap_stack([]) == 0
    assert largest_rect([7]) == 7 and trap_two_ptr([7]) == 0
    assert largest_rect([2, 2, 2, 2]) == 8 and trap_stack([2, 2, 2]) == 0
    assert largest_rect([0, 0, 0]) == 0 and trap_two_ptr([0, 0, 0]) == 0
    assert largest_rect([1, 2, 3, 4]) == 6 and trap_stack([1, 2, 3, 4]) == 0
    assert largest_rect([4, 3, 2, 1]) == 6 and trap_two_ptr([4, 3, 2, 1]) == 0
    assert trap_two_ptr([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]) == 6
    assert trap_stack([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]) == 6
    print("边界断言: 空/单元素/全相同/全0/单调/经典样例 全过 ✅")

    # 4) 极大值：10^9 高度 × 5000 柱，面积 5*10^12 仍在 int 内，且线性时间
    big = [10 ** 9] * 5000
    assert largest_rect(big) == 10 ** 9 * 5000
    assert trap_two_ptr(big) == 0
    print("极大值: 5000 柱 10^9 高度，面积 5e12 无溢出 ✅")

    print("对拍通过：单调栈双题 80 组随机 + 9 条边界全绿")
```

**追问**：1) 直方图为什么一定要加哨兵，不加会怎样？—— 不加哨兵时，遍历结束后栈里还压着一批「右边界为数组末尾」的柱，必须再写一段清栈循环（`i` 用 `n` 结算）；补一个 0 高度哨兵后所有柱都会在扫到哨兵时被弹掉，**代码只有一条主循环**。左端 0 哨兵则保证弹到栈空时 `stack[-1]` 始终存在，省掉 `if not stack` 分支。代价是多两个元素的空间，收益是「边界情形不需要特判」。2) 接雨水栈版和双指针版该写哪个？—— 双指针版 O(1) 空间、无栈、循环只走 n 步，**笔试首选**；栈版的价值是它和直方图共用同一套「单调栈 + 弹出结算」的心智模型，面试官追问「能不能用同一类结构解两题」时用它回答。两版对拍是必要的：栈版的按层结算涉及「弹空 break」这类易错分支，双指针版涉及「先更新 lm 再累加」的顺序，错误模式完全不同，互相对拍才能真正兜住。3) 摊销 O(n) 在面试里怎么讲才不被挑刺？—— 不要只说「每个元素进出一次」，要把它写成计数论证：设入栈操作为 I、出栈为 O，则 `I = n`（每个下标恰入一次）、`O ≤ I`（弹出的是曾经入栈的），总操作数 `I + O ≤ 2n`，所以主循环总代价是 O(n) 而非「每次 O(1) 乘 n」。同时承认最坏单次是 O(n)（一次弹出全部），复杂度上界不依赖输入分布，这与快排的「期望 O(n log n)」是两种不同口径。
