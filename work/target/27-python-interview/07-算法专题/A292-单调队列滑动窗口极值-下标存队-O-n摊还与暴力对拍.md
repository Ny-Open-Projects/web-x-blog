### A292 · 单调队列滑动窗口极值：下标存队、相等元素取舍与 O(n) 摊还对拍

> 难度:★★★☆ | 标签:单调队列, 滑动窗口, 摊还分析, 对拍

**问**（笔试·编程题）：给长度 n 的整数数组和窗口大小 k，返回每个长度 k 窗口的最大值（再顺手给出最小值版本），要求：① 队列里为什么存下标而不是存值，窗口左边界过期怎么判，为什么必须在取队首之前判；② 队尾淘汰条件写 `<=` 还是 `<`，遇到相等元素留旧的还是留新的，对答案、队列长度、以及「全相等数组」各有什么影响；③ 证明总复杂度是 O(n) 而不是 O(nk)——每个下标到底入队几次、出队几次，严格递增、全相等、锯齿三种最坏形态分别长什么样；④ 边界：k=1、k=n、k>n、空数组、k=0、单元素各自返回什么，返回空列表还是抛异常怎么选；⑤ 与 O(nk) 的切片暴力做 200 组随机对拍并统计入队/出队操作数，再用 n=200000 的递增与全相等数组跑极值，最后说清本题与 A248（滑动窗口限流）里「窗口」的语义差别。

**答**：① 存下标是唯一正确选择：值相同的新旧元素无法区分，而「是否过期」只能由位置决定；有了下标就能用 `dq[0] < i-k+1` 在 O(1) 判断队首是否滑出窗口。过期判断必须放在取 `dq[0]` 当作答案之前，也必须放在队尾淘汰之前——否则一个已经过期的下标可能因为值大而把新元素弹掉，队首留下一个不在窗口内的「幽灵最大值」。② 求最大值时队尾用 `nums[dq[-1]] <= x` 弹出，相等也弹：保留更靠右的新下标，队列里永远不会同时存在「值相等但更旧」的元素，于是队列长度不超过 k，全相等数组的队列长度恒为 1；若写成 `<`，答案仍然对（旧元素没过期前仍是合法极值），但重复值会层层堆积，全相等时队列长度达到 k，最坏空间退化，且队首可能是即将过期的旧下标，语义变脆。求最小值完全对称，把比较改成 `>=` 即可。③ 摊还账：每个下标恰好入队一次，共 n 次；出队只有两个来源——队尾淘汰或队首过期，一个下标一旦出队就不再回来，所以总出队 ≤ n；总操作 ≤ 2n，是 O(n) 而不是 O(nk)。严格递增时每个新元素都把队尾弹空，出队 n-1 次、队列长度 1；全相等且用 `<=` 时同样是每次弹空，队列长度 1；锯齿形（大、小、大、小）时旧的大值留在队首直到过期，队列长度在 1~2 之间抖动，出队次数仍被 n 封顶。④ k=1 时每个元素自成窗口，直接返回原数组；k=n 时只有一个窗口，返回 `[极值]`；k>n、空数组、k<=0 都没有合法窗口，代码统一返回 `[]`——这是为了让对拍与调用方在「冷启动、数据不足一个窗口」时不必写 try，工程接口里更严谨的做法是 k<=0 抛 `ValueError`（参数非法）、k>n 返回空（数据不足），面试时应先说出这个取舍再写。⑤ 对拍：随机 n=1..40、k=1..n、值域 -5..5 制造大量重复，最大与最小各 200 组，与 `max/min(nums[i:i+k])` 切片暴力逐元素比较；再用 20 万递增与 20 万全相等跑极值，并用 stats 统计操作数断言 ≤ 2n。与 A248 的分工：A248 的「窗口」是**时间语义**——限流窗口内请求计数、分桶近似、补币越窗，关心的是时间推进与计数精度；本题的窗口是**数组下标语义**的定长区间，只关心区间极值，没有时间、没有计数，两者不能互相替代。

```python
# 全部标准库；单调队列求滑动窗口最大值/最小值，与暴力切片对拍，并统计摊还操作数
import random
from collections import deque


def window_extreme(nums, k, want_max=True, stats=None):
    """单调队列：队列存下标，队列内的值从队首到队尾单调（最大队列递减）。

    stats 若传入一个 list，会把本次的元素入队 + 出队总次数追加进去，
    用于验证摊还 O(n)：每个下标最多入队一次、出队一次。
    """
    if k <= 0 or not nums or k > len(nums):
        return []
    dq = deque()
    out = []
    ops = 0
    for i, x in enumerate(nums):
        left = i - k + 1
        # 1) 队首过期：下标 < 窗口左边界
        while dq and dq[0] < left:
            dq.popleft()
            ops += 1
        # 2) 队尾淘汰：不可能成为未来窗口极值的元素
        if want_max:
            while dq and nums[dq[-1]] <= x:
                dq.pop()
                ops += 1
        else:
            while dq and nums[dq[-1]] >= x:
                dq.pop()
                ops += 1
        dq.append(i)
        ops += 1
        if left >= 0:
            out.append(nums[dq[0]])
    if stats is not None:
        stats.append(ops)
    return out


def brute(nums, k, want_max=True):
    if k <= 0 or not nums or k > len(nums):
        return []
    pick = max if want_max else min
    return [pick(nums[i:i + k]) for i in range(len(nums) - k + 1)]


if __name__ == "__main__":
    rng = random.Random(2921)

    # 1) 200 组随机（n=1..40，k=1..n，值域含负数与大量重复）双向对拍
    for _ in range(200):
        n = rng.randint(1, 40)
        nums = [rng.randint(-5, 5) for _ in range(n)]
        k = rng.randint(1, n)
        assert window_extreme(nums, k, True) == brute(nums, k, True), ("max", nums, k)
        assert window_extreme(nums, k, False) == brute(nums, k, False), ("min", nums, k)
    print("窗口极值对拍: 200 组随机 × (最大/最小) vs 暴力切片，全等 ✅")

    # 2) 边界：k=1、k=n、k>n、空数组、k=0、单元素
    assert window_extreme([3, 1, 4, 1, 5], 1) == [3, 1, 4, 1, 5]
    assert window_extreme([3, 1, 4, 1, 5], 5) == [5]
    assert window_extreme([3, 1, 4], 4) == []
    assert window_extreme([], 2) == []
    assert window_extreme([7], 0) == []
    assert window_extreme([7], 1) == [7] == window_extreme([7], 1, False)
    print("边界: k=1/k=n/k>n/空数组/k=0/单元素 全过 ✅")

    # 3) 重复元素语义：相等时也弹掉旧下标，只保留最靠右的，队首仍是最新窗口极值
    assert window_extreme([2, 2, 2, 2], 2) == [2, 2, 2]
    assert window_extreme([1, 3, 3, 1], 2) == [3, 3, 3]
    assert window_extreme([1, 3, 3, 1], 2, False) == [1, 3, 1]
    print("重复元素: 相等值淘汰旧下标，窗口极值不受影响 ✅")

    # 4) 摊还分析实证：入队 n 次，出队至多 n 次，总操作 <= 2n
    for _ in range(20):
        n = rng.randint(1, 300)
        nums = [rng.randint(0, 3) for _ in range(n)]
        st = []
        window_extreme(nums, rng.randint(1, n), True, st)
        assert st[0] <= 2 * n, (n, st[0])
    print("摊还验证: 20 组随机窗口，入队+出队操作数均 <= 2n ✅")

    # 5) 极值：n=200000 递增（每个新元素弹空队列）与全相等（相等也弹，队列长度恒为 1）
    n = 200000
    inc = list(range(n))
    out = window_extreme(inc, 100)
    assert len(out) == n - 100 + 1 and out[0] == 99 and out[-1] == n - 1
    flat = [7] * n
    out = window_extreme(flat, 1000)
    assert len(out) == n - 1000 + 1 and set(out) == {7}
    assert window_extreme(flat, 1000, False) == out
    print("极值: n=200000 严格递增/全相等，最大与最小窗口均正确 ✅")

    print("对拍通过：单调队列 200 组随机 + 6 类边界 + 2 组 20 万极值全绿")
```

**追问**：1) 如果要求窗口内「第 k 大」而不是最大，单调队列还够吗？—— 不够。单调队列只能维护一个可比较的极值，序统计需要能删任意元素的有序结构：`SortedList`（非标准库）、双堆 + 延迟删除（O(n log k)，但堆里会堆过期元素）、或值域 BIT（先离散化）。这是「极值」与「序统计」的分界线，面试官常在这里把题从 ★★★ 拉到 ★★★★。2) 数据流式到达、k 还会变化怎么办？—— 单调队列天然在线，`push` 时维护、滑窗时过期；k 变化若要求重建，最坏 O(n)；若要求支持任意窗口大小与任意可结合聚合（和、最大值、矩阵乘），用两个栈模拟队列（SWAG），每个栈维护前缀聚合，摊还 O(1) 摊到每次 push/pop，空间 O(n)。3) 为什么不用 `heapq` + 延迟删除？—— 可以，答案也对，但复杂度是 O(n log n)、空间最坏 O(n)（所有元素都进堆、过期的才慢慢弹）；单调队列是 O(n) 时间、O(k) 空间，且常数更小。判断标准是：**只求极值就别上堆，求 Top-K 或序统计才需要堆**。
