### A004 · 无重复字符的最长子串

> 难度:★★☆ | 标签:滑动窗口, 哈希表

**问**:求字符串中不含重复字符的最长子串长度。

**答**:滑动窗口:右指针扩,遇到重复字符时把左指针直接跳到「重复字符上次出现位置 + 1」,而不是一步步收缩。用 `last: dict[str, int]` 记录每个字符最后出现下标,全程 O(n) 时间 O(k) 空间(k 是字符集大小)。暴力枚举所有子串是 O(n²) 起步。

```python
# 示例:code/07_算法专题/(docs 内嵌,复制可运行) a004_longest_substring_no_repeat.py
def length_of_longest_substring(s: str) -> int:
    last: dict[str, int] = {}   # 字符 -> 最后出现下标
    start = 0                   # 窗口左端
    best = 0
    for i, ch in enumerate(s):
        if ch in last and last[ch] >= start:
            start = last[ch] + 1          # 左端直接跳过重复字符
        last[ch] = i
        best = max(best, i - start + 1)
    return best

if __name__ == "__main__":
    assert length_of_longest_substring("abcabcbb") == 3   # "abc"
    assert length_of_longest_substring("bbbbb") == 1
    assert length_of_longest_substring("pwwkew") == 3     # "wke"
    assert length_of_longest_substring("abba") == 2       # 左指针只能前进不能后退
    assert length_of_longest_substring("") == 0
    print("A004 ok")
```

**追问**:
- 为什么用 `last[ch] >= start` 而不是无条件跳?——`"abba"`:第二个 `a` 的 last=0 已经在窗口左边,若跳到 1 会让左指针后退,答案错成 3;左指针只进不退是滑窗正确性前提。
- 窗口类题的通用框架?——右扩左缩 + 「窗口状态」维护(A005 的计数窗口、最小覆盖子串同理),模板一致只是状态不同。
- 字符流式输入怎么办?——滑窗天然单遍、O(k) 状态,配合生成器逐行喂(Q019),内存与流长无关。
