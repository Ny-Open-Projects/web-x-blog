### A002 · 有效的括号

> 难度:★☆☆ | 标签:栈, 字符串

**问**:判断只含 `()[]{}` 的字符串是否合法:括号必须以正确顺序闭合。

**答**:栈:左括号入栈;右括号时栈顶必须是同类型左括号,弹出不匹配即非法;结束时空栈才合法。时间 O(n)、空间 O(n)。

```python
# 示例:code/07_算法专题/(docs 内嵌,复制可运行) a002_valid_parens.py
PAIRS = {")": "(", "]": "[", "}": "{"}

def is_valid(s: str) -> bool:
    stack: list[str] = []
    for ch in s:
        if ch in PAIRS:                      # 右括号:检查栈顶
            if not stack or stack.pop() != PAIRS[ch]:
                return False
        else:                                # 左括号:入栈
            stack.append(ch)
    return not stack                         # 有剩余左括号也非法

if __name__ == "__main__":
    assert is_valid("()[]{}") is True
    assert is_valid("([{}])") is True
    assert is_valid("(]") is False
    assert is_valid("([)]") is False         # 交叉嵌套
    assert is_valid("((") is False           # 剩余未闭合
    assert is_valid("") is True
    print("A002 ok")
```

**追问**:
- `not stack` 的检查为什么不能省?——`"]"` 这种以右括号开头时栈为空,pop 会 IndexError;先判空再弹是栈类题的固定动作。
- 用 list 模拟栈的代价?——append/pop 尾部均 O(1) 摊还;CPython list 是连续指针数组,扩容有摊还成本但无单次 O(n) 风险,链栈在 Python 里反而更慢(Q330)。
- 扩展成「求最长合法括号子串」怎么做?——栈存下标或 DP,LeetCode 32;思路仍是栈,但栈底要压「最后一个未匹配位置」当标尺。
