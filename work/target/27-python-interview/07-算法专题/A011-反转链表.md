### A011 · 反转链表

> 难度:★☆☆ | 标签:链表

**问**:反转单链表,要求迭代实现 O(1) 空间,并说出递归版的代价。

**答**:三指针迭代:`prev/curr/nxt`,每次把 curr.next 指向 prev 再整体右移。O(n) 时间 O(1) 空间。递归版同样 O(n) 时间但 O(n) 栈深——长链表会 RecursionError(Python 默认递归上限 1000),这是 Python 面试必须主动说的点。

```python
# 示例:code/07_算法专题/(docs 内嵌,复制可运行) a011_reverse_list.py
class ListNode:
    def __init__(self, val: int = 0, next: "ListNode | None" = None):
        self.val, self.next = val, next

def reverse_list(head: "ListNode | None") -> "ListNode | None":
    prev, curr = None, head
    while curr:
        nxt = curr.next     # 先存后继
        curr.next = prev    # 反指
        prev, curr = curr, nxt
    return prev             # 新头

def build(vals: list[int]) -> "ListNode | None":
    dummy = ListNode()
    cur = dummy
    for v in vals:
        cur.next = ListNode(v)
        cur = cur.next
    return dummy.next

def to_list(head: "ListNode | None") -> list[int]:
    out = []
    while head:
        out.append(head.val)
        head = head.next
    return out

if __name__ == "__main__":
    assert to_list(reverse_list(build([1, 2, 3, 4, 5]))) == [5, 4, 3, 2, 1]
    assert to_list(reverse_list(build([1]))) == [1]
    assert to_list(reverse_list(None)) == []
    print("A011 ok")
```

**追问**:
- 迭代版每步在做什么不变量?——`prev` 是已反转部分的头,`curr` 是未反转部分的头;循环结束时 curr=None、prev 即新头。讲不变量比背代码加分。
- 区间反转(LeetCode 92)思路?——定位到区间前驱,区间内做同样的局部反转再接回;头节点可能变化时用 dummy 节点统一处理。
- Python 递归版实际能用吗?——链表长 2000 就超默认递归上限,且每次调用栈帧有开销(Q019 的栈帧模型);工程上链表操作一律迭代。
