### A161 · 统计功效与样本量

> 难度:★★★ | 标签:AB 测试, 统计, 实验设计

**问**（笔试·编程+场景题）：想验证「新按钮提升转化率 1%」（基线 10%）——实验要做多久（样本量公式：α/β/最小可检测效应 MDE 三参数），「功效 80%」是什么意思（漏掉真效应的概率），跑了两周 p=0.08 不显著怎么办（继续跑/提前判负/加大效应），样本量不够的实验结论怎么表述才诚实？

**答**：① 样本量公式（单侧/双侧近似）：`n ≈ (z_{α/2} + z_β)² × 2 × p(1-p) / MDE²`——三参数：α（假阳性，0.05）、β（漏检率，1-功效 0.2 → z_β≈0.84）、MDE（业务上值得检测的最小效应，1%）。基线 10% 检测 1% 提升 ≈ 每组 ~17 万样本——**实验时长 = 样本量 ÷ 日流量**，流量不够就拉长或加大 MDE。② 功效 80% 的含义：若真效应是 1%，有 80% 概率实验能检出它、20% 概率「白跑」（不显著≠无效，是不够灵敏）——反过来说：不显著 + 样本量达标 = 「效应小于 MDE」的概率很高，这是有效的「判负」。③ 不显著的处置：**先算当前样本量对应的最小可检测效应**（observed power/MDE 回推）——若样本已达计划但 p=0.08：结论「效应 < MDE，判负」（诚实且可行动）；若样本远未达标：继续跑至计划样本量（但不要 peeking，Q116）；若业务等不了：承认「实验窗口内无法检测 1%，要么接受更大的 MDE 要么改实验设计（提高转化基数/分层降低方差）」。④ 诚实表述：「实验显示提升不显著（p=0.08，功效对 1% 效应不足）」而不是「实验证明无效」——措辞差异是统计素养。

```python
# 全部标准库；demo 实现「样本量计算 + MDE 回推 + 不显著处置」
import math

def z_from_alpha(alpha: float) -> float:
    """双侧 z 分位（近似 erf 逆运算）：alpha=0.05 → 1.96。"""
    lo, hi = 0.0, 6.0
    for _ in range(80):
        mid = (lo + hi) / 2
        p = math.erfc(mid / math.sqrt(2))
        if p > alpha: lo = mid
        else: hi = mid
    return (lo + hi) / 2

def sample_size(p_base: float, mde: float, alpha: float = 0.05,
                power: float = 0.80) -> int:
    """每组样本量（双侧）：n ≈ (z_{α/2}+z_β)² × 2p(1-p) / MDE²。"""
    z_a, z_b = z_from_alpha(alpha), z_from_alpha((1 - power) * 2)  # 单侧近似
    z_b = 0.84 if power == 0.80 else z_b
    return math.ceil((z_a + z_b) ** 2 * 2 * p_base * (1 - p_base) / mde ** 2)

def achieved_mde(n: int, p_base: float, alpha: float = 0.05,
                 power: float = 0.80) -> float:
    """样本量回推：当前样本能检测的最小效应。"""
    z_a, z_b = z_from_alpha(alpha), 0.84
    return math.sqrt((z_a + z_b) ** 2 * 2 * p_base * (1 - p_base) / n)

def honest_verdict(p: float, planned_n: int, actual_n: int, mde: float) -> str:
    if actual_n < planned_n:
        return f"继续跑：样本 {actual_n}/{planned_n}（不足），勿提前下结论"
    if p >= 0.05:
        return f"判负：样本达标，效应 < MDE {mde:.1%}（不显著≠无效，是不够灵敏）"
    return "显著：按序贯边界确认后放量（Q116）"

if __name__ == "__main__":
    n = sample_size(p_base=0.10, mde=0.01)
    print(f"基线 10% 检测 +1%（MDE 1%）：每组约 {n} 样本")
    assert 100000 < n < 250000
    days = n // 5000                                   # 日流量每组 5000
    print(f"日流量 5000 → 实验约 {days} 天")
    # 跑了两周（每组 7 万）不显著：
    mde_now = achieved_mde(actual_n := 70000, p_base=0.10)
    print(f"两周后实际可检测效应（MDE 回推）：{mde_now:.2%}")
    print("处置:", honest_verdict(0.08, n, 70000, 0.01))
    assert "继续跑" in honest_verdict(0.08, n, 70000, 0.01)
    print("样本达标不显著:", honest_verdict(0.08, n, n, 0.01))
    # 口径：样本量三参数（α/β/MDE）先行；不显著+达标=判负；措辞诚实（不显著≠无效）。
```

**追问**：1) 为什么 MDE 要「业务值得检测的最小效应」而不是越小越好？——MDE 0.1% 的样本量是 MDE 1% 的 100 倍（平方关系）——检测无业务意义的微小效应是纯浪费；MDE 由「改动成本 vs 效应价值」决定（按钮改动成本低值得测 0.5%，重构实验 5% 起测）。2) 「分层降低方差」怎么减少样本量？（提示：CUPED（Q7031）用前期数据修正方差，方差降 30-50% → 样本量等比降——先算公式再上分层，是实验设计的杠杆）3) 多指标实验的 α 怎么处理？（提示：多指标多重检验 α 膨胀（Q116 同源）——主指标定一个（预注册），其余为护栏指标（不做显著性判定只做护栏告警），Bonferroni 或 Holm 校正用于真要多指标判定的场景）

## 背诵要点
1. 样本量公式三参数：α（0.05）/β（0.2→功效 80%）/MDE（业务最小效应）——实验时长 = 样本 ÷ 日流量，先行计算。
2. 不显著两分支：样本达标 = 判负（效应 < MDE）；未达标 = 继续跑，不 peeking。
3. 诚实措辞：「不显著≠无效，是不够灵敏」；MDE 回推告诉业务「当前样本能检测什么」。

## 复盘追问
1. 老板说「实验跑了三天没效果，砍了吧」，你怎么回应？（提示：算 MDE 回推——三天样本只能检测 ±5% 的效应，1% 的真实提升此刻「检测不到」≠「不存在」；要么按计划跑完，要么老板明确接受「只检测大效应」的妥协并记录）
2. 两个实验 A 显示 +2%（显著）、B 显示 +2%（不显著），结论矛盾吗？（提示：不矛盾——显著性受样本量与方差影响，效应点估计相同但置信度不同；比较时看置信区间重叠而非 p 值大小；也警惕 B 只是没跑够）
