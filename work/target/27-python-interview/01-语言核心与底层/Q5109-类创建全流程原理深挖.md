### Q5109 · 类创建全流程原理深挖

> 难度:★★★★☆ | 标签:原理深挖, 元类, 类创建

**问**:`class Foo:` 这一行执行时，解释器到底做了哪几步？各步顺序与失败点是什么？

**答**:结论：类创建是一条五步流水线：① 求值基类、关键字参数（metaclass=）与类体，把类体当成普通代码块执行得到 namespace dict（3.12/PEP 667 下是独立快照语义）；② 决定元类：显式指定 > 各基类元类中最派生的那个，基类元类不兼容直接 TypeError（Q422）；③ 调用 `metaclass(name, bases, ns, **kw)`，即 `type.__new__`：算 MRO、准备 `__slots__`、先对类体里的描述符逐个调 `__set_name__`（Q5014）、再触发基类钩子 `__init_subclass__`（Q030）；④ 元类 `__init__` 收尾；⑤ 结果绑定到当前名字空间。装饰器（`@deco`）在整个流程**之后**作用于成品类。失败点分布：元类冲突在第②步裁定、`__set_name__`/`__init_subclass__` 抛错在第③步且中断类创建（不会留下半成品类）。掌握顺序才能解释"为什么描述符在 init_subclass 阶段就已经知道自己的名字"。

```python
step = []

class Meta(type):
    def __new__(mcls, name, bases, ns, **kw):
        step.append("type.__new__")
        return super().__new__(mcls, name, bases, ns, **kw)
    def __init__(cls, name, bases, ns, **kw):
        step.append("metaclass.__init__")
        super().__init__(name, bases, ns, **kw)

class Base:
    def __init_subclass__(cls, **kw):
        step.append("init_subclass")
        super().__init_subclass__(**kw)

class Desc:
    def __set_name__(self, owner, name):
        step.append(f"set_name:{name}")

def deco(cls):                       # 类装饰器：整个流水线之后
    step.append("decorator")
    return cls

@deco
class Foo(Base, metaclass=Meta):
    attr = Desc()

print(step)   # ['type.__new__', 'set_name:attr', 'init_subclass', 'metaclass.__init__', 'decorator']

# 元类冲突：两个基类元类互不相容（且非派生关系），第②步裁定直接炸
class Meta2(type): pass
class A(metaclass=Meta): pass
class B(metaclass=Meta2): pass
try:
    class Bad(A, B): pass
except TypeError as e:
    print("冲突:", e)
print("Foo 的元类:", type(Foo).__name__)
```

**追问一层**:`__init_subclass__` 拿到的 cls 与最终绑定的类是同一个对象吗？此时 `__set_name__` 是否已经执行完？
**追二层**:dataclass 的 `field` 与 `__set_name__` 谁先谁后？为什么 dataclass 要在装饰器阶段重写 `__init__`？

**背诵要点**
- 五步序：类体执行→元类裁定→type.__new__（MRO/slots/init_subclass/set_name）→元类 init→绑定。
- 类装饰器在流水线之后；type.__new__ 内先 set_name 后 init_subclass。
- 元类冲突发生在裁定步，TypeError 中断类创建。

**复盘追问**
- 插件自动注册应该用 init_subclass 还是 metaclass？提示：成本与继承侵入性（Q2887）。
- 类体执行期间抛异常，类对象会残留吗？提示：ns 未绑定，无半成品类。
