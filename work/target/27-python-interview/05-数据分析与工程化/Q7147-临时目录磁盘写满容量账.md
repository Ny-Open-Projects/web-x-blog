### Q7147 · 临时目录 /tmp 磁盘写满容量账

难度：P6 | 标签：容量规划、磁盘、事故预防

**问**：数据管道大量用 `tempfile` 存中间结果，某天 /tmp 写满，全机写操作瘫痪。临时目录的容量账怎么算？如何防止"写完就删"变成"写完没删"？

**答**：结论：临时目录的容量账 = **峰值并发任务数 × 单任务中间产物大小 × 安全系数**，且必须回答三个问题：写入分区是哪个（tmpfs 占内存还是占磁盘）、清理方是谁（应用删、systemd-tmpfiles 清、还是没人管）、异常路径有没有删（try/finally + 启动清扫）。事故的典型链条：异常退出跳过清理 → 残留累积 → 平时不报错因为总余量够 → 某天大任务叠加写穿。预防靠"账 + 兜底清扫 + 水位告警"三层。

实战要点：
1. 显式指定目录与配额：不要混用系统 /tmp，给管道单独挂盘/目录，超水位（如 80%）就拒绝新任务并告警——失败好过拖垮全机。
2. `NamedTemporaryFile`/`mkdtemp` 与 `TemporaryDirectory` 上下文管理器保证异常路径也删；多进程共享产物要避免同名冲突（Q7091）。
3. 兜底清扫按 **mtime 年龄**而非"每次启动全删"：删除超过 N 小时的残留，防止误删正在跑任务的产物；清扫要限速避免 IO 抖动。

```python
"""临时目录水位账 + 按年龄清扫（标准库，可运行）"""
import shutil
import tempfile
import time
from pathlib import Path


class TmpBudget:
    def __init__(self, path: Path, limit_bytes: int,
                 max_age_hours: float = 6.0) -> None:
        self.path = path
        self.limit = limit_bytes
        self.max_age = max_age_hours

    def used(self) -> int:
        total = 0
        for p in self.path.rglob("*"):
            if p.is_file():
                try:
                    total += p.stat().st_size
                except FileNotFoundError:
                    pass  # 清扫中的竞态容忍
        return total

    def headroom_tasks(self, per_task_bytes: int) -> int:
        """还能容纳几个并发任务"""
        return max(0, (self.limit - self.used()) // per_task_bytes)

    def admit(self, per_task_bytes: int) -> bool:
        """水位 80% 拒绝新任务"""
        return self.used() + per_task_bytes <= self.limit * 0.8

    def sweep(self, now: float | None = None) -> int:
        """按 mtime 清超龄残留，返回删除数"""
        now = now or time.time()
        removed = 0
        for p in self.path.iterdir():
            if p.stat().st_mtime < now - self.max_age * 3600:
                shutil.rmtree(p, ignore_errors=True) if p.is_dir() else p.unlink(missing_ok=True)
                removed += 1
        return removed


work = Path(tempfile.mkdtemp())
(work / "a.bin").write_bytes(b"x" * 300)
(work / "b.bin").write_bytes(b"y" * 100)

budget = TmpBudget(work, limit_bytes=1000, max_age_hours=6)
print("已用:", budget.used(), "可容任务:", budget.headroom_tasks(200))
print("admit 700B:", budget.admit(700))   # 400+700 > 800 -> False
print("admit 300B:", budget.admit(300))
```

**追问 1**：为什么"启动时全删临时目录"是危险策略？
**提示**：滚动发布时会删掉老实例正在写的产物；按 mtime 年龄+限速清扫才与滚动共存。

**追问 2**：tmpfs 上的 /tmp 写满会怎样？
**提示**：占的是内存/swap，写满直接触发系统级 OOM 或冻结，比磁盘更致命；数据管道产物必须落真实磁盘。

## 背诵要点
- 容量账=峰值并发 × 单任务产物 × 安全系数；80% 水位拒绝新任务，失败好过拖垮全机。
- 异常路径清理靠 TemporaryDirectory 上下文；兜底清扫按 mtree 年龄限速删，不搞启动全删。
- tmpfs 写满伤内存，管道产物必须落真实磁盘并单独分区。
