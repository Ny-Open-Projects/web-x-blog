### Q7296 · 置换重要性的共线性盲区：为什么删掉整组特征才掉分

难度：P7 ｜ 标签：permutation importance、共线性、特征重要性、分组置换、SHAP

基线：库知识库外知识卡，用纯 Python 的线性预测器与置换实验模拟共线特征的重要性摊薄，不依赖 sklearn。

**问**：风控模型里"近 30 天交易额"和"近 30 天交易笔数"相关性 0.96，`permutation_importance` 显示两者各 0.02，排名垫底。评审时有人提议删掉它们，结果整组删掉后 AUC 从 0.81 掉到 0.74。为什么单独置换几乎不掉分，整组置换却很重要？`shap` 能解决吗？特征重要性到底该怎么读？

**答**：

- **结论**：共线特征在模型里是**可替代**的：单独打乱 `交易额` 时，模型还能用 `交易笔数` 补上同样的信息，预测几乎不变，重要性被"摊薄"到接近 0；但两个一起打乱，信息源整体消失，性能才掉。**单特征置换度量的是"这个特征相对于其他特征的边际贡献"，不是"这个特征本身的因果重要性"**。共线越强，单特征重要性越低估；完全共线时甚至会出现"两个都 0、整组很大"的极端。
- **取舍**：① 分组置换（group permutation）：把共线特征聚成一组一起打乱，度量"这组信息"的贡献，最贴近"删掉这组会怎样"；② 条件置换（conditional permutation）：按相关特征分层置换，保留联合分布，计算更贵但更公平；③ SHAP：基于 Shapley 值分摊，理论上更合理，但共线时仍受背景数据集选择影响，且计算成本高；④ 只看 `feature_importances_`（树模型不纯度）：对共线更不稳定，不能作为删除依据。
- **实战**：① 先做相关性聚类（`|r| > 0.9` 聚组），按组做置换，而不是逐列看；② 重要性与"删除后重训"交叉验证：真要做特征选择，删掉后重训看 CV，而不是只看置换分数；③ 业务解释时用"组"讲故事（交易活跃度 = 额 + 笔数），不要硬拆到单列；④ 监控线上单特征分布，共线特征之一漂移可能被另一个掩盖，PSI 要按组看。

下面用两个完全共线的特征演示：单独置换各掉 2 个方差单位，一起置换掉 6 个。

```python
# 共线特征: 单独置换可被替代, 整组置换才暴露真实贡献
import random


random.seed(0)
n = 400
x1 = [random.gauss(0, 1) for _ in range(n)]
x2 = list(x1)                      # 完全共线
y = [2 * a for a in x1]            # 真实关系只由 x1 决定
pred = [a + b for a, b in zip(x1, x2)]   # 模型把权重平摊到两个特征


def mse(p):
    return sum((a - b) ** 2 for a, b in zip(p, y)) / len(p)


base = mse(pred)
perm1 = x1[:]
perm2 = x2[:]
random.shuffle(perm1)
random.shuffle(perm2)

imp1 = mse([a + b for a, b in zip(perm1, x2)]) - base
imp2 = mse([a + b for a, b in zip(x1, perm2)]) - base
group = mse([a + b for a, b in zip(perm1, perm2)]) - base

print(f"[1] 基线 MSE={base:.4f}")
print(f"[2] 单独置换 x1: +{imp1:.3f}; 单独置换 x2: +{imp2:.3f}")
print(f"[3] 整组置换: +{group:.3f}")
assert base == 0
assert abs(imp1 - imp2) < 0.5
assert group > imp1 + imp2
print(f"    → 实测 单列之和 {imp1 + imp2:.3f} < 整组 {group:.3f}, 单列重要性被摊薄")

# 分组置换: 按相关性聚类, 一组一起打乱
groups = {"活跃度": ["x1", "x2"]}
perm_both = dict(zip(["x1", "x2"], [perm1, perm2]))
group_imp = mse([perm_both["x1"][i] + perm_both["x2"][i] for i in range(n)]) - base
print(f"[4] 分组置换[活跃度]: +{group_imp:.3f}")
assert abs(group_imp - group) < 1e-9

# 删除后重训: 单删 x1 模型仍可用 x2, 整组删才掉分
def retrain_mse(features):
    if not features:
        return mse([0] * n)
    w = 2 / len(features)
    p = [sum(w * f[i] for f in features) for i in range(n)]
    return mse(p)


print(f"[5] 删除 x1 后重训 MSE={retrain_mse([x2]):.4f}; 整组删除 MSE={retrain_mse([]):.4f}")
assert retrain_mse([x2]) == 0
assert retrain_mse([]) > 1
print("    → 实测 单删不影响, 整组删才崩; 重要性要按组读, 特征选择要重训验证")
```

**追问一**：SHAP 能给出"正确"的单特征重要性吗？—— SHAP 给的是 Shapley 分摊，满足可加性，但共线时"每个特征分多少"仍取决于背景分布/采样方式：把相关特征当独立采样，会给共线特征分配"重复计算"的贡献；用真实联合分布采样，又会把贡献集中到其中一个。它能帮你解释"模型用了什么"，但不能直接回答"删掉这个特征业务会怎样"。

**追问二**：为什么"删除后重训"比"置换重要性"更适合做特征选择？—— 置换是**在固定模型上**做扰动，模型仍可利用替代特征；删除后重训会让模型重新分配权重，度量的是"没有这组信息时能达到的最好性能"。前者回答"当前模型多依赖它"，后者回答"没有它行不行"。特征选择要问后者。

## 背诵要点

- 共线特征单独置换可被替代，重要性被摊薄；完全共线时会出现"单列都 0、整组很大"。
- 按 `|r|` 聚类做**分组置换**，或做"删除后重训"交叉验证；`feature_importances_` 更不稳定，不能单独作为删除依据。
- 重要性回答"模型依赖什么"，不回答"业务删掉会怎样"；两者要用不同实验。
