### Q7160 · 数据集重复计算成本账：三个人各算一遍同一张宽表

难度：P6-P7 | 标签：成本工程、数据工程、特征复用

**问**：盘点发现三个分析师各自维护一份"几乎相同"的用户行为宽表，每天合计白烧 6 个机时。重复计算的成本账怎么算？怎么治理而不打击自服务的积极性？

**答**：结论：重复计算的账 = 重复算力成本（可直接计量）+ 数据不一致成本（隐性但更大：三份宽表口径漂移后，同一指标三个数，决策成本飙升）。治理不是"禁止自算"而是**把重复变成可发现的复用**：特征/数据集注册表 + 按输入指纹聚类（Q2867 指纹思想、Q7155 节点指纹）自动发现"同输入同逻辑"的作业，推送给 owner 合并。

取舍与实战：
1. 成本账结构：显性成本 = 重复作业的机时/查询费（从调度系统直接聚合）；隐性成本 = 口径不一致引发的返工与决策错误，按"指标口径工单量"间接计量。汇报治理收益时两个都要列，后者往往是说服管理层的关键。
2. 发现机制：对管道作业算"逻辑指纹"——输入表集合 + 关键变换签名（SELECT 列集合 + 聚合方式 + 过滤条件的规范化表示），指纹相同/相似度 > 0.9 即标记候选合并；纯代码 diff 不可靠（三个人代码风格不同），要规范化到语义层。
3. 治理路径：候选合并 → owner 认领公共层（数仓分层：ODS→DWD→ADS，宽表进公共层）→ 老作业下线（给缓冲期，不是直接杀）；考核上把"复用次数"计入公共层 owner 的产出，激励对齐。
4. 自服务平衡：允许个人"探索性作业"（临时、无 owner 意图），但超过 14 天的常驻作业必须注册或自动降级到低优先级队列——用资源配额而不是行政禁令引导。

```python
"""作业逻辑指纹聚类：发现候选合并的重复计算（标准库，可运行）"""

def norm_signature(sql: str) -> str:
    """把 SQL 规范化到语义签名：去空白/大小写、抽取结构要素"""
    import re
    s = re.sub(r"\s+", " ", sql.strip().lower())
    tables = sorted(set(re.findall(r"from\s+(\w+)|join\s+(\w+)", s)))
    tables = sorted({t for pair in tables for t in pair if t})
    agg = sorted(set(re.findall(r"(sum|count|avg|max|min)\s*\(", s)))
    cols = sorted(set(re.findall(r"select\s+(.+?)\s+from", s)))
    return f"tables={tables}|agg={agg}|cols={cols}"

jobs = {
    "job_alice": "SELECT user_id, sum(amt) FROM orders JOIN users WHERE dt > '2026-01' GROUP BY 1",
    "job_bob":   "select user_id, sum(amt) from orders join users where dt > '2026-01' group by 1",
    "job_carol": "SELECT count(*) FROM events",
}
sigs = {k: norm_signature(v) for k, v in jobs.items()}
clusters: dict[str, list[str]] = {}
for k, s in sigs.items():
    clusters.setdefault(s, []).append(k)
for s, members in clusters.items():
    if len(members) > 1:
        print(f"[候选合并] {members} 逻辑指纹相同: {s[:60]}...")
assert len(set(sigs.values())) == 2
```

**追问 1**：为什么"代码 diff 相同"不可靠，语义指纹又会漏报哪些情况？
**提示**：代码 diff 因风格/等价写法误判；语义指纹的规范化只覆盖抽取到的要素，等价但写法不同的聚合（如 `sum(x)/count(*)` vs `avg(x)`）会漏报——所以是"候选发现需人工确认"，不是自动合并。

**追问 2**：公共层合并后，原 owner 离职/转岗导致公共层无人维护怎么办？
**提示**：注册表里公共数据集必须有 owner 字段 + 双人备份 + 调用方清单（下游引用计数）；下游引用数是下线决策与维护责任分配的依据，无 owner 且无引用的自动归档。

## 背诵要点
- 重复计算双成本：显性机时费 + 口径漂移的隐性决策成本，后者更大。
- 发现靠语义指纹聚类（表集合+聚合+列的规范化签名），候选合并需 owner 人工确认。
- 治理用分层复用 + 复用次数激励 + 常驻作业注册配额，不用行政禁令。
