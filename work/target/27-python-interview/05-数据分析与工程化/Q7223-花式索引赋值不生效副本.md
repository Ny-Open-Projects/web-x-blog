### Q7223 · arr[mask] += 1 没生效：花式索引给你的是副本

难度：P6 ｜ 标签：NumPy、视图与副本、fancy indexing、np.add.at

基线：Python 3.12；NumPy 2.x 基本索引返回视图、高级索引返回副本；纯 Python 模拟视图/副本语义。

**问**：想把所有负数加 1，写 `a[a < 0] += 1`，数组一点没变，也不报错；改成 `a[a < 0] = a[a < 0] + 1` 就生效。可 `a[0:3] += 1` 是生效的。同样是中括号，为什么行为不同？

**答**：
- **结论**：NumPy 索引分两类。**基本索引**（切片、整数、`...`）返回**视图**，`+=` 通过 `__iadd__` 原地写回原数组；**高级索引**（布尔数组、整数数组）返回**副本**，`a[mask] += 1` 等价于 `tmp = a[mask]; tmp += 1`，tmp 用完即弃，原数组不变。同理 `df[mask]["col"] = x` 这种链式赋值只改了临时对象（pandas 会发 `SettingWithCopyWarning`）。
- **取舍**：视图零拷贝、快，但"看起来像引用"容易误改源数据；副本安全但要显式写回。`np.where(cond, a + 1, a)` 语义最清楚但会分配新数组（内存翻倍）。需要**重复下标累加**时，`a[idx] += 1` 会漏加，必须用 `np.add.at(a, idx, 1)` 或 `np.bincount`。
- **实战**：① 条件赋值统一写 `a[mask] = ...` 或 `np.copyto(a, values, where=mask)`；② 重复索引累加用 `np.add.at`；③ 判断是视图还是副本看 `arr.base is None` / `arr.flags.owndata`；④ 只读输入设 `arr.flags.writeable = False`，把"静默不生效"变成 `ValueError`。

```python
"""基本索引 = 视图（写回原数组），高级索引 = 副本（改不到原数组）。"""
from array import array


def iadd_view(view: memoryview, delta: float) -> None:
    """模拟 ndarray.__iadd__：就地修改这块内存。"""
    for i in range(len(view)):
        view[i] += delta


if __name__ == "__main__":
    # 1) 切片 = 视图：写回原数组，且受切片边界约束
    a = array("d", [1.0, -2.0, -3.0, 4.0])
    iadd_view(memoryview(a)[0:3], 1.0)
    print("基本索引 +=:", list(a), "-> 只有前三个被改")

    # 2) 布尔/整数索引 = 副本：原数组不变
    b = array("d", [1.0, -2.0, -3.0, 4.0])
    idx = [i for i, v in enumerate(b) if v < 0]
    tmp = array("d", (b[i] for i in idx))        # 副本
    iadd_view(memoryview(tmp), 1.0)
    print("高级索引 +=:", list(b), "| 副本:", list(tmp), "-> 原数组没变")

    # 3) 正确写法：显式写回
    for i in idx:
        b[i] += 1.0
    print("显式写回:", list(b))

    # 4) 重复下标：a[idx] += 1 只加一次，np.add.at 才逐次累加
    c = [0, 0, 0, 0]
    dup = [0, 0, 0, 2]
    snap = [c[i] for i in dup]                   # 取副本
    for k in range(len(snap)):
        snap[k] += 1
    for pos, i in enumerate(dup):                # 整体写回，0 号被覆盖三次
        c[i] = snap[pos]
    print("a[idx] += 1 ->", c, "| 期望 [3, 0, 1, 0]")

    d = [0, 0, 0, 0]
    for i in dup:                                # 等价 np.add.at
        d[i] += 1
    print("np.add.at   ->", d)

    # 5) 判断视图还是副本
    mv = memoryview(a)
    print("memoryview(a).obj is a ->", mv.obj is a, "| slice 仍共享:", mv[0:2].obj is a)
```

**追问一**：`a[idx] += 1` 为什么在 idx 有重复时会"少加"？
→ 解析：`a[idx]` 先取副本（长度等于 idx 长度，重复位置各自一份），加 1 后整体写回时，同一个目标位置被覆盖多次，最终值只等于"最后一次写"的结果。`np.add.at` 按出现次序逐次累加，`np.bincount(idx)` 直接出频次，两者才是直方图/累加的正确工具。

**追问二**：pandas 为什么 `df.loc[mask, "col"] = x` 就没这个问题？
→ 解析：`.loc` 是一次 `__setitem__` 调用，直接在底层 Block 上按位置写入，中间没有临时对象；`df[mask]["col"] = x` 是两次操作——先取出子 DataFrame（副本或临时视图），再对它设列，改动可能丢在临时对象里，pandas 只能发警告提醒。
