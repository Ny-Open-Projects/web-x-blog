### Q7561 · 多供应商计费口径差异与对账

难度：P7 | 标签：成本工程、计费对账、多供应商、tokenizer

**问**：平台同时接了三家模型供应商，月底发现"内部统计的成本"和"供应商账单"差 7%。多供应商的计费口径差异有哪些来源？对账体系怎么设计才能把差异追到单请求？

**答**：
- **结论**：差异四大来源：① token 计数差异——各家 tokenizer 不同，同一段文本各家算出的 token 不同（内部估算用的通用 tokenizer 与供应商计费计数必然有偏差）；② 计费范围差异——失败请求的输入 token 计不计费、缓存命中的 prompt 是否折扣价、系统工具 token 是否入账，各家政策不同；③ 汇率与阶梯价——月用量跨阶梯后单价变化、美元计价的汇率取值日；④ 时间窗差异——账单周期跨月、出账延迟。对账设计：内部按"供应商自己的计费口径"分别记账（记录每请求的供应商 usage 原文），月底按供应商分册对账，差异定位到单请求级别（按 request_id join 供应商明细）。
- **取舍**：用供应商返回的 usage 记账（准、但流式中断时缺失）vs 内部 tokenizer 估算（完整、但有偏差）——正确姿势是"供应商 usage 为主、估算补缺、偏差率进监控"（估算偏差率 >5% 说明估算器该校准了）。
- **实战**：落地三件套：① 网关原样保存每请求的 usage JSON（审计凭证）；② 每周抽样请求与供应商明细 API 对单（不是等月底账单才发现）；③ 单价配置版本化：阶梯价、缓存折扣、汇率进配置并带生效日期，账单按当时单价重算复核。

```python
"""多供应商计费对账：按各家口径分别记账，差异定位到单请求。"""
from collections import defaultdict

# 内部记录：每请求保存供应商返回的原始 usage
ledger = [
    {"rid": "r1", "vendor": "A", "in_tok": 3000, "out_tok": 600, "billed": 0.0552},
    {"rid": "r2", "vendor": "B", "in_tok": 3200, "out_tok": 600, "billed": 0.0560},
    {"rid": "r3", "vendor": "A", "in_tok": 1000, "out_tok": 0,   "billed": 0.0080},  # 失败也计费
]

PRICE = {"A": (8.0, 24.0), "B": (8.5, 26.0)}   # 各家单价不同

def reconcile(ledger, vendor_invoice):
    by_vendor = defaultdict(float)
    mismatches = []
    for r in ledger:
        pin, pout = PRICE[r["vendor"]]
        expect = r["in_tok"]/1e6*pin + r["out_tok"]/1e6*pout
        by_vendor[r["vendor"]] += expect
        if abs(expect - r["billed"]) > 1e-6:      # 单请求级 diff
            mismatches.append((r["rid"], expect, r["billed"]))
    for v, total in by_vendor.items():
        diff = total - vendor_invoice[v]
        print(f"{v}: 内部重算 {total:.4f} vs 账单 {vendor_invoice[v]:.4f} (diff {diff:+.4f})")
    return mismatches

bad = reconcile(ledger, {"A": 0.0632, "B": 0.0560})
print("单请求差异:", bad)
print("要点：按供应商各自口径分册记账 + request_id 级 join 对账，差异必须可追到单请求")

```
