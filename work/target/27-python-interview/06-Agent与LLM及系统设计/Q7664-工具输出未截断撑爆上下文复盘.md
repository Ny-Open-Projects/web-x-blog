### Q7664 · 工具输出未截断撑爆上下文复盘：一个 read_file 只吃掉整个窗口

难度：P6-P7 | 标签：Agent、上下文管理、事故复盘

**问**：Agent 读一个 20MB 的日志文件，工具把整个内容塞进上下文，请求直接超限报错；重试后换个文件又超限，会话报废。复盘：工具输出为什么要做"分层截断"？截断策略怎么设计才能既防爆窗口又不让 Agent 拿不到关键信息？

**答**：结论：事故结构是"**工具输出直通上下文**"——工具返回值未经过体积治理直接 append 进消息历史，一次大输出就超过上下文预算，且截断发生在 API 报错时为时已晚。正确设计是**在工具层做体积治理**：分级输出（先给摘要/头部 + 尺寸说明 + 分页句柄），Agent 按需分页取细节；截断必须"信息保真"——保留头部、结构化行（错误行/关键行）与总量说明，并明确告知"被截断、可用分页工具取更多"。

取舍与实战：
1. 输出预算三级：单工具输出上限（如 30KB）、单轮全部工具输出上限、会话工具输出累计占比（工具输出是上下文大头，Q7645 会话历史裁剪的输入源头）。超限时分级响应：头部 + `[截断: 显示前 N 行/共 M 行，用 read_file(offset=...) 续读]`。
2. 保真截断原则：文本保留头尾 + 匹配关键行（grep 式预筛）；表格/JSON 保留 schema + 前几行 + 行数；二进制只回摘要与哈希。**禁止静默截断**——Agent 不知道被截会基于残缺信息推理，比超限报错更危险。
3. 结构化输出通道：大结果不该走上下文而走旁路——落盘/存对象存储，只把"句柄 + 摘要"给模型（Q7632 中间工件存储思路），Agent 需要时用工具按页取。
4. 重试防放大：超限报错后的重试必须先清理上一轮大输出，否则换个小文件也被历史里的大块头挤爆——工具输出治理与上下文水位（Q2033/Q7660 分层预算）联动。

```python
"""工具输出分层截断器：预算内保真输出 + 分页句柄（标准库，可运行）"""

def tool_output_guard(
    content: str, budget_chars: int = 3000, page: int = 1,
) -> str:
    lines = content.splitlines()
    if len(content) <= budget_chars:
        return content
    # 保真截断：头部 + 关键行（错误/警告）+ 总量说明 + 分页句柄
    import re
    important = [l for l in lines if re.search(r"error|warn|fail|exception", l, re.I)][:20]
    head = lines[:30]
    body = "\n".join(head + (["...关键行..."] + important if important else []))
    tail_note = (f"\n[截断] 共 {len(lines)} 行 / {len(content)} 字符，"
                 f"已显示头部+关键行；用 page={page + 1} 续读")
    return body + tail_note

log = "\n".join([f"line {i}: ok" for i in range(500)] + ["line E1: ERROR disk full"])
out = tool_output_guard(log, budget_chars=200)
assert len(out) < 2000 and "截断" in out and "ERROR disk full" in out
print(out[-200:])
```

**追问 1**：为什么"截断后告知总量与续读方式"比直接给前 N 字符重要？
**提示**：Agent 的推理依赖对信息完备性的认知——知道"共 50 万行、已看前 30 行"会走分页/预筛策略，不知道就会把残缺当全量；截断元信息本身就是给模型的关键上下文。

**追问 2**：分页句柄（offset/page）的状态管理有什么坑？
**提示**：文件在多轮之间可能被修改，固定 offset 会读到错位内容——句柄应携带内容指纹/版本号（Q2296 哈希校验思想），失效时返回"文件已变更"而不是静默错位数据。

## 背诵要点
- 工具输出必须经体积治理再入上下文：单输出/单轮/会话累计三级预算，超限分级截断。
- 保真截断三要素：头部+关键行保留、总量与截断说明、分页续读句柄；禁止静默截断。
- 大结果走旁路（落盘+句柄），上下文只留摘要；重试前先清理上一轮大输出防连锁超限。
