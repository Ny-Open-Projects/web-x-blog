### Q7538 · Self-Consistency：采样 5 次取多数，值不值？

> 难度:★★★ | 标签:推理策略, 成本工程, 可靠性

**问**：提高答案可靠性的自一致性（同一问题采样 N 次取多数）成本直接 N 倍——什么任务值得用？N 怎么定？"多数"在开放生成任务里怎么定义？单次+置信自评的级联策略能省多少？为什么说置信自评不可全信？

**答**：结论：自一致性是"**N 倍推理成本换准确率**"，适合高价值低频、答案可对齐（分类/数学/结构化抽取）的任务；开放生成没有"多数"可定义，不适合。N=3→5 增益显著、5→10 边际递减（二项模型下准确率提升快速趋平），N>10 通常不划算。省钱主力是**级联**：先单次+置信自评，低置信样本才升级 N 次采样——大多数流量走 1 倍快路径，平均成本 2-3 倍即可接近全量投票的准确率。

机理与实战：
- **准确率-成本曲线要实测**：二项模型给出理论形状（p=0.7 单次 → N=5 达 84%），但真实任务样本间相关（错误模式集中）会削弱投票收益——用任务自身的 badcase 分布校准，别直接信理论曲线。
- **投票策略分层**：分类/选择题用字面多数；生成任务先做语义聚类（同义答案合并）再多数，聚类错误率要评估；可按自评置信加权。
- **级联的纪律**：置信自评与真实正确率弱相关——"自信地错"不会被拦截，阈值要按线上 badcase 的置信分布校准（找"低置信且真错"的召回率 vs "低置信但真对"的误升级率的平衡点）；级联的额外收益是延迟分层（多数用户拿快路径）。
- **共享与缓存**：同一 prompt 的采样结果可跨用户复用（高频问题天然共享）；Agent 内部高价值节点（工具选择、汇总结论）用自一致性，中间步骤不用——把 N 倍成本花在决策点。

```python
# 基线:Python 3.10+;纯标准库模拟自一致性(self-consistency)的准确率-成本曲线与级联策略
# 真实场景:N 次采样多数投票;级联 = 单次+置信自评,低置信才升级 N 次采样
from __future__ import annotations
import math


def vote_accuracy(p: float, n: int) -> float:
    """二项模型:n 次独立采样,多数正确的概率(p>0.5 才有正收益)。"""
    assert 0.5 < p < 1
    return sum(math.comb(n, k) * p ** k * (1 - p) ** (n - k)
               for k in range(n // 2 + 1, n + 1))


def cost_multiple(n: int) -> int:
    return n


def cascade(p_easy_pass: float, p_correct_easy: float, p_correct_hard: float,
            hard_cost_n: int = 5, confidence_precision: float = 0.8) -> dict:
    """级联:单次快路径,自评置信不足的样本升级 N 次投票。"""
    escalated = (1 - p_easy_pass) * confidence_precision + p_easy_pass * (1 - confidence_precision)
    acc = (1 - escalated) * p_correct_easy + escalated * vote_accuracy(p_correct_hard, hard_cost_n)
    cost = (1 - escalated) * 1 + escalated * hard_cost_n
    return {"escalated": escalated, "accuracy": acc, "cost": cost}


def demo() -> None:
    p = 0.7                                             # 单次正确率 70%
    print("自一致性准确率-成本曲线(单次 p=0.7):")
    for n in (1, 3, 5, 10):
        acc = vote_accuracy(p, n) if n > 1 else p
        print(f"  N={n:>2}: 准确率 {acc:.1%},成本 {cost_multiple(n)}x ✅")
        assert acc >= p
    assert vote_accuracy(p, 10) > vote_accuracy(p, 3) > p
    print("边际递减:N=5→10 的增益远小于 1→5;N>10 常不划算 ✅")

    print("级联策略(单次+置信自评,低置信升级 N=5):")
    for prec in (0.9, 0.8, 0.6):
        r = cascade(p_easy_pass=0.8, p_correct_easy=0.75,
                    p_correct_hard=p, hard_cost_n=5, confidence_precision=prec)
        print(f"  自评精度 {prec:.0%}: 升级率 {r['escalated']:.0%},"
              f"准确率 {r['accuracy']:.1%},平均成本 {r['cost']:.1f}x ✅")
    base5 = vote_accuracy(p, 5)
    r8 = cascade(0.8, 0.75, p, 5, 0.9)
    assert r8["cost"] < 5 and r8["accuracy"] > 0.75
    print(f"级联 vs 全量 N=5:成本 {r8['cost']:.1f}x vs 5x,准确率 "
          f"{r8['accuracy']:.1%} vs {base5:.1%} -> 大多数流量走快路径 ✅")


if __name__ == "__main__":
    demo()
```

**追问一**：为什么"错误样本间相关"会让投票收益低于二项模型预测？
答：二项假设独立采样，但同一模型在同一 prompt 上的错误高度相关（同样的误解会重复出现）——5 次采样可能 4 次错在同一处。缓解：调高温度/改写 prompt 变体制造多样性，或混合两个模型投票（成本更高但去相关）；收益评估必须用真实相关度而不是独立假设。

**追问二**：高价值低频场景（合同审查）和低频高价值怎么组合级联？
答：把"价值"编码进路由——合同金额/风险等级高的请求直接走 N 次采样+人工复核（不心疼成本），低风险请求走单次快路径；路由规则要可审计（为什么这条走了重路径），避免"拍脑袋升级"成为成本黑洞。

## 背诵要点
- 自一致性 = N 倍成本换准确率，适合可对齐答案（分类/数学/抽取）；开放生成"多数"不可定义，改用 critic/自我校验。
- N=3→5 显著、5→10 边际递减；真实收益受样本相关性削弱，要用自家 badcase 分布校准。
- 级联（单次+置信自评+低置信升级）把平均成本压到 2-3 倍；置信自评弱相关，阈值按 badcase 置信分布校准。

## 复盘追问
- 上线自一致性后成本翻倍但投诉率没降，哪里出了问题？（提示：先查任务答案空间是否可对齐（多数是否定义有效）、样本相关性是否吃掉增益、再查升级路由是否把"真错的"放进了快路径）
- 如何向老板证明"这 2 倍成本花得值"？（提示：按决策分级统计——高价值节点的错误率下降幅度 × 单次错误业务损失，给出成本/收益比而非笼统准确率）
