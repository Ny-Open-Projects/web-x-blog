### Q7656 · 模型降价/更换供应商的迁移成本账

难度：P6-P7 | 标签：成本工程、供应商切换、评测

**问**：竞品模型降价 40%，质量声称相当。换模型的账怎么算——降价收益之外，迁移本身有哪些隐性成本？怎么决策？

**答**：结论：换模型的净收益 = token 节省 − 迁移成本 − 质量风险损失。迁移隐性成本五笔：① 评测成本：跑全量回归评测集 + 业务指标对齐（Q7607 防泄漏），人力 1-2 周；② 提示词适配：新模型对 system/指令格式敏感度不同，存量 prompt 要重调，这是**最大也最易低估**的一笔；③ 行为差异返工：输出风格、结构化格式、工具调用习惯变化，下游解析与人工审核流程要改；④ 双跑观察期成本：灰度期新旧两份调用量并行（费用短暂翻倍）；⑤ 工程适配：SDK/参数差异、限流配额重建。决策准则：只有当降价幅度 > 30% 且评测无回归时，迁移才稳赚；小幅降价不值得动。

实战要点：
1. 抽象层前置：调用统一走网关/适配层（Q7550 封装隔离思想），换供应商只改配置——没有抽象层时迁移成本×3。
2. 灰度对拍：按流量比例 5%→25%→100%，逐档对比业务指标（采纳率、返工率），而不是只看离线评测。
3. 回滚预案：旧供应商合同/配额保留一个季度，网关一层开关回切。

```python
"""换模型净收益账（标准库，可运行）"""
from dataclasses import dataclass


@dataclass
class MigrationLedger:
    monthly_spend: float        # 现月度 LLM 费用
    price_cut: float            # 竞品降价幅度
    eval_cost: float = 30000    # 评测人力折算
    prompt_rework: float = 50000  # prompt 重调（最易低估）
    dual_run_weeks: float = 4   # 双跑观察期
    engineering: float = 15000  # SDK/配额适配

    def one_time_cost(self) -> float:
        dual = self.monthly_spend * (self.dual_run_weeks / 4.33)
        return self.eval_cost + self.prompt_rework + dual + self.engineering

    def yearly_saving(self) -> float:
        return self.monthly_spend * 12 * self.price_cut

    def verdict(self) -> str:
        payback = self.one_time_cost() / max(
            self.yearly_saving() / 12, 1)
        if payback > 6:
            return f"不值得：回本 {payback:.0f} 个月"
        return f"可行：回本 {payback:.1f} 个月（须评测无回归）"


led = MigrationLedger(monthly_spend=200_000, price_cut=0.40)
print(led.verdict())
print("一次性迁移成本:", f"{led.one_time_cost():,.0f} 元")
print("其中 prompt 重调占比:",
      f"{led.prompt_rework / led.one_time_cost():.0%}")

# 小降价反例
print(MigrationLedger(monthly_spend=200_000, price_cut=0.10).verdict())
```

**追问 1**：为什么 prompt 重调是最容易被低估的一笔？
**提示**：存量 prompt 是对旧模型行为的过拟合；新模型上"能用"不等于"最优"，重调要按调用点逐个做，调用量大的团队这块常占总迁移成本一半。

**追问 2**：灰度对拍时新旧模型流量并行，用户侧如何不被污染？
**提示**：按会话维度切流（同一会话不混模型），保证上下文与输出风格一致性；对拍指标按会话归因而不是按请求归因。

## 背诵要点
- 净收益=token节省−迁移成本−质量风险；降价>30% 且评测无回归才值得迁。
- 迁移五笔账：评测、prompt 重调（最大头）、行为返工、双跑期费用、工程适配。
- 无网关抽象层时迁移成本×3；灰度按会话维度切流并保留一季回滚配额。
