### Q7539 · 评测集污染：模型会"背题"、语料库收录了考卷怎么办？

> 难度:★★★★ | 标签:评估治理, 数据泄漏, 污染检测

**问**：评测集分数虚高的一个隐蔽原因是"泄漏"。评测样本进入模型训练语料、评测内容被 RAG 知识库收录、团队反复对着评测集调参——三类泄漏怎么检测？模型"背诵"评测答案怎么探测？盲测集封存和轮换怎么落地？

**答**：结论：三类泄漏三道闸——① **训练语料泄漏**（供应商拿评测集训练了模型）靠背诵探测：模型对评测样本逐字复现（长片段一致性异常高）即疑似记忆，样本作废轮换；② **RAG 语料污染**（评测 FAQ 被贴进知识库，检索直接送答案）靠语料入库指纹闸（精确指纹 + 字符级 n-gram 高重叠拦截改写版）；③ **行为泄漏**（反复按评测集调参）靠盲测封存 + 季度轮换重采（Q7533）。

机理与实战：
- **背诵探测**：把模型输出与评测样本做字符级 n-gram 重叠比对——输出中长片段逐字命中评测答案（重叠 >60%）而正常改写只有零星重叠，即为可疑记忆信号；确认后样本必须作废换新，否则该样本永久虚高。
- **入库闸的必要性**：评测材料与业务文档常存同一套文档系统，"检索一切"的 RAG 管道会把考卷一起索引——入库闸必须包含评测材料指纹，且拦截要发生在"收录时"而不是"检索时"。
- **盲测封存**：封存集由独立保管人持有（或 hash 存证、隔离环境），日常迭代用轮换的公开集，版本发布终验才解封盲测集——解封后的盲测集作废并重采。
- **权限与水印**：评测集仓库权限最小化（数据平台团队持有），样本带水印字段追踪外流；评测集的任何导出走审计。
- **检测的误杀控制**：业务高频 FAQ 与评测样本天然相似（都是常见问答），阈值要按"逐字长片段"校准而不是任意重叠——重叠检测的粒度（10 字符窗口）与阈值需要按误杀率调优。

```python
# 基线:Python 3.10+;纯标准库实现评测集污染检测(背诵探测)与语料入库指纹闸
# 真实场景:评测样本被 RAG 语料收录/被模型背诵;入库两级查重 + 盲测封存
from __future__ import annotations
import hashlib
from dataclasses import dataclass


def ngrams(text: str, n: int = 10) -> set[str]:
    """字符级 n-gram(中文无空格,按字切)。"""
    t = "".join(text.lower().split())
    return {t[i:i + n] for i in range(len(t) - n + 1)}


class CorpusGate:
    """语料入库指纹闸:评测集样本禁止进入 RAG 语料(第二类泄漏)。"""

    def __init__(self, eval_fingerprints: set[str], eval_samples: list[str]) -> None:
        self.eval_fps = eval_fingerprints
        self.eval_grams = set().union(*[ngrams(s) for s in eval_samples])

    @staticmethod
    def fp(text: str) -> str:
        norm = " ".join(text.lower().split())
        return hashlib.sha256(norm.encode()).hexdigest()[:16]

    def admit(self, doc: str) -> tuple[bool, str]:
        # 两级查重:精确指纹 + 高重叠 n-gram(改写也拦)
        if self.fp(doc) in self.eval_fps:
            return False, "精确命中评测样本,拒绝入库"
        grams = ngrams(doc)
        overlap = len(grams & self.eval_grams) / max(len(grams), 1)
        if overlap >= 0.5:
            return False, f"n-gram 重叠 {overlap:.0%},疑似评测样本改写,拒绝入库"
        return True, "通过"


class MemorizationDetector:
    """背诵探测:模型对评测样本逐字复现 = 可疑记忆(第一类泄漏的信号)。"""

    def __init__(self, eval_samples: list[str]) -> None:
        self.eval_grams: list[set] = [ngrams(s) for s in eval_samples]

    def suspicious(self, output: str, threshold: float = 0.6) -> tuple[bool, float]:
        grams = ngrams(output)
        if not grams:
            return False, 0.0
        best = max((len(grams & g) / len(grams) for g in self.eval_grams),
                   default=0.0)
        return best >= threshold, best


def demo() -> None:
    eval_samples = [
        "Q: 客户签约后多久可以申请退款 A: 七个工作日内可提交退款申请",
        "Q: 如何修改发票抬头 A: 在账户设置-发票管理中修改次月生效",
    ]
    gate = CorpusGate({CorpusGate.fp(s) for s in eval_samples}, eval_samples)

    # 泄漏二:有人把评测 FAQ 贴进了知识库
    ok, why = gate.admit("FAQ 整理:Q: 客户签约后多久可以申请退款 A: 七个工作日内可提交退款申请")
    assert not ok
    print(f"入库闸拦截 ✅:{why}")
    ok2, why2 = gate.admit("新品发布会将于下周举行,欢迎各团队报名参加线下交流活动")
    assert ok2
    print(f"无关文档放行:{why2} ✅")

    # 泄漏一:模型逐字背诵评测答案(输出了评测集原文)
    det = MemorizationDetector(eval_samples)
    memorized = "客服话术:Q: 客户签约后多久可以申请退款 A: 七个工作日内可提交退款申请 谢谢"
    flag, score = det.suspicious(memorized)
    assert flag
    print(f"背诵探测 ✅:与评测样本 n-gram 重叠 {score:.0%} -> 疑似记忆,样本作废轮换")
    normal = "建议您在签约后的第一周内联系客服处理退款事宜,需要准备订单号"
    flag2, score2 = det.suspicious(normal)
    print(f"正常输出:重叠 {score2:.0%} 不误杀 ✅")

    print("治理三件套:盲测集封存(终验才解封) + 评测集季度轮换重采 + 语料入库指纹闸 ✅")


if __name__ == "__main__":
    demo()
```

**追问一**：供应商训练语料不可见，"训练泄漏"怎么主动探测？
答：出题式探测——故意构造"不存在于公开网络、只在评测集"的合成样本（如内部造的术语问答），新版本上线后测逐字复现率；复现率异常高说明该版本可能见过这些数据。更系统的做法是把评测集分"公开可得/内部私有"两轨，私有轨的分数变化单独监控。

**追问二**：评测集轮换会不会让版本间分数不可比？
答：会——轮换后新旧集分数有系统性差异，必须做"重叠期双跑校准"（新旧集同版本各跑一次得到校准系数，Q7533 的思路），并在指标平台标注"集版本"；跨版本的提升对比只能用同集版本或校准后的数字。

## 背诵要点
- 三类泄漏：训练语料背诵（探测=逐字复现率）、RAG 语料收录评测样本（入库指纹闸）、团队行为泄漏（盲测封存+轮换）。
- 入库闸两级：精确指纹 + 字符级 n-gram 高重叠（拦改写版），拦截发生在收录时；评测材料指纹必须进闸。
- 盲测集独立保管、终验解封后即作废重采；轮换后的版本对比需重叠期双跑校准。

## 复盘追问
- 分数连续三个季度上升但业务侧无感知，你怎么排除泄漏？（提示：先查评测集样本的"服役时长"与复现率、跑公开/私有双轨对比、再做一次盲测封存集验证——三个信号交叉定位）
- 运营团队要求"把客服 FAQ 全部放进知识库"，其中混有评测来源内容，流程怎么防？（提示：入库闸 + 评测样本指纹清单对接文档平台入库 API，命中即拒并通知数据平台复核来源）
