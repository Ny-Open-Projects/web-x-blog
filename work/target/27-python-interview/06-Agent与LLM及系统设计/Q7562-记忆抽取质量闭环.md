### Q7562 · Agent 记忆抽取质量闭环

难度：P7 | 标签：Agent 记忆、抽取质量、评估闭环

**问**：Agent 的长期记忆是 LLM 从对话里抽取的。抽错一条记忆会污染所有后续会话。"抽取质量"怎么量化、怎么闭环？低置信记忆怎么处理？

**答**：
- **结论**：抽取质量用标准信息抽取的方法量化：构造金标集（对话 + 应抽事实），跑抽取器算 precision/recall——幻觉抽取（P 的损失）与漏抽（R 的损失）都要看。闭环四步：① 金标集定期扩充（真实会话抽样人工标注）；② 抽取 prompt/模型变更跑金标回归；③ 低置信样本进人工抽检队列（置信度阈值可调，抽检结果回流金标集）；④ 记忆条目带来源引用与置信度，用户可查看/删除——可解释是信任底线。
- **取舍**：抽取模型的取舍：强模型抽得准但贵（每会话一次批量抽取可摊薄）vs 规则+小模型便宜但召回差。置信度阈值是产品决策：阈值高则记忆少而准（冷启动慢），低则多而脏（污染风险）。
- **实战**：事故复盘：用户抱怨"Agent 记错了我的偏好"——根因是反讽语句被抽成事实。防线：① 抽取 prompt 要求"只抽显式陈述，反问/比喻不抽"；② 记忆条目注入时带"来源会话可回溯"；③ 冲突检测：新记忆与既有记忆矛盾时降置信进人工队列而不是直接覆盖。

```python
"""记忆抽取质量闭环：抽出的记忆与期望对账，算 precision/recall，低置信进人工抽检。"""

def extract(dialog):
    """模拟 LLM 抽取：返回 (事实, 置信度)。"""
    out = []
    if "只喝美式" in dialog:
        out.append(("偏好:美式咖啡", 0.9))
    if "上海出差" in dialog:
        out.append(("行程:上海", 0.6))
        out.append(("偏好:上海咖啡", 0.4))          # 幻觉抽取
    return out

GOLD = {"偏好:美式咖啡", "行程:上海"}
dialogs = ["用户说只喝美式，下周去上海出差"]
extracted = {f: c for d in dialogs for f, c in extract(d)}

tp = set(extracted) & GOLD
fp = set(extracted) - GOLD
fn = GOLD - set(extracted)
precision = len(tp) / (len(tp) + len(fp))
recall = len(tp) / (len(tp) + len(fn))
print(f"抽取: {list(extracted)}")
print(f"P={precision:.2f} R={recall:.2f}  幻觉: {fp}  漏抽: {fn}")
review = [f for f, c in extracted.items() if c < 0.7]
print("进人工抽检:", review)
print("要点：记忆写入前先量化抽取质量；低置信样本进抽检队列，错误记忆污染后续会话")
```

**追问链**：
1. 追问一层：为什么幻觉抽取比漏抽危害更大？（漏抽只是"没记住"，幻觉是"记错"——错误记忆每次检索都注入上下文，影响面随时间放大且用户难发现）
2. 追问二层：记忆冲突（"用户说讨厌甜食" vs 三个月后"最近爱喝奶茶"）怎么处理？（带时间戳，新记忆高置信可覆盖旧记忆但保留版本链；偏好类冲突进人工确认）

**背诵要点**：
1. 抽取质量 = 金标集上的 P/R，幻觉比漏抽危害大。
2. 低置信进人工抽检，结果回流金标集；变更跑金标回归。
3. 记忆带来源引用与置信度，用户可查可删；冲突降置信不直接覆盖。

**复盘追问**：
1. 记忆库运行半年后"答非所问的注入"变多，量化哪个指标？（注入命中率与噪声比——检索到的记忆里与当前任务相关的比例）
2. 为什么抽取要在会话结束批量做而不是每轮做？（成本摊薄 + 上下文完整（反讽要靠全对话判断），每轮抽取上下文不全更容易错）
