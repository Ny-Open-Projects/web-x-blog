### Q7523 · 引用溯源与幻觉防线：怎么证明"答案是检索内容说出来的"？

> 难度:★★★★ | 标签:RAG, 幻觉, 评估

**问**：RAG 系统上线后被质疑"编造数据"。除了换更强的模型，工程上有哪些"可验证"的防线？引用标注 `[1][2]` 挂在答案上就够了吗？

**答**：结论：不够。引用标注只证明"模型看见了证据"，不证明"结论出自证据"。可验证防线分三层：**生成时约束**（prompt 强制逐句挂引用 + 引用必须指向检索到的块 id）、**生成后校验**（机械层：引用 id 合法性、关键数字必须能在证据中字面找到；语义层：NLI/蕴含校验——每句话是否被其引用的证据支持）、**拒答降级**（证据支持度不足时明说"知识库中没有依据"而不是硬答）。三层由便宜到贵，机械层先拦掉 80% 明显幻觉。

机理与实战：
- 机械校验的具体口径：答案中的数字、日期、金额逐个在证据文本中做归一化匹配（1,200 与 1200 等价）；引用 id 必须存在于本次检索返回集；答案里出现证据外的专名（公司名/产品名）标黄人工复核。这些全是字符串工程，毫秒级完成。
- 蕴含校验（NLI）：把"句子 + 其引用的证据"喂给轻量判别（小模型或本地 NLI 模型，budget 低）判 entailment/contradiction/neutral；contradiction 即拦截。它是 rerank 成本之外的第二层模型成本，按句数预算，长答案只抽关键句（含数字/结论的句子）校验。
- 拒答的产品化：拒答率是可监控的 SLA 指标——拒答率骤升通常意味着检索坏了（索引过期、embedding 服务降级），而不是"问题变难了"。把"拒答率 + 引用覆盖率（带引用句子占比）"做成防线仪表盘。

```python
# 基线:Python 3.9+ 纯标准库 ;NLI 层标注降级口径,可接小模型
import re
from dataclasses import dataclass


@dataclass
class Evidence:
    cid: str
    text: str


def normalize_num(s: str) -> set[str]:
    """数字归一:1200 / 1,200 / 1200.0 视为同一。"""
    out = set()
    for m in re.findall(r"\d[\d,\.]*", s):
        out.add(m.replace(",", "").rstrip("0").rstrip(".") or "0")
    return out


def check_citations(answer: str, evidences: list[Evidence]) -> list[str]:
    """机械校验:引用 id 合法性 + 数字溯源。返回违规清单。"""
    issues = []
    cited_ids = set(re.findall(r"\[(\w+)\]", answer))
    valid_ids = {e.cid for e in evidences}
    ghost = cited_ids - valid_ids
    if ghost:
        issues.append(f"幽灵引用(不在检索集): {ghost}")
    ev_nums = normalize_num(" ".join(e.text for e in evidences))
    ans_nums = normalize_num(answer)
    unsupported = {n for n in ans_nums if len(n) >= 3 and n not in ev_nums}
    if unsupported:
        issues.append(f"证据外数字(疑似编造): {unsupported}")
    return issues


def nli_gate(sentences: list[str], evidences: list[Evidence],
             nli_fn=None) -> list[str]:
    """蕴含校验:nli_fn 可接本地 NLI/小模型;缺省用词面重叠降级口径。"""
    bad = []
    ev_text = {e.cid: e.text for e in evidences}
    for sent in sentences:
        ref = re.search(r"\[(\w+)\]", sent)
        if not ref or ref.group(1) not in ev_text:
            continue
        ctx = ev_text[ref.group(1)]
        words = set(re.findall(r"[\w]{2,}", sent.lower()))
        overlap = len(words & set(re.findall(r"[\w]{2,}", ctx.lower()))) / max(len(words), 1)
        if nli_fn:
            verdict = nli_fn(sent, ctx)            # entail/contradict/neutral
            if verdict == "contradict":
                bad.append(sent)
        elif overlap < 0.25:                       # 降级:词面支持度过低
            bad.append(sent)
    return bad


def main() -> None:
    evs = [Evidence("1", "2026年Q3营收为 1,200 万元,同比增长 18%"),
           Evidence("2", "研发人员共 350 人,占全员 42%")]
    answer = "根据财报,2026年Q3营收 1,200 万元[1],研发团队 500 人[2],获客成本 3.8 元[3]。"
    issues = check_citations(answer, evs)
    for i in issues:
        print("机械层违规:", i)
    risky = nli_gate([answer], evs)
    print("词面支持度不足句:", len(risky))
    print("拒答决策:", "拦截复核" if issues or risky else "放行")


if __name__ == "__main__":
    main()
```

**追问一**：数字校验会不会把合理的"计算结论"误杀（比如证据给了单价与数量，答案算出总额）？
答：会，这是机械层的已知假阳性。对策：把"推导型数字"与"引用型数字"分开——prompt 要求模型区分表述（"共计 3600 元（依据 [1] 计算）"），校验层对标注了"计算"的数字改用可执行校验（如果证据里有单价与数量则重算核对），而不是字面匹配。

**追问二**：拒答率目标定多少合理？
答：不是越低越好——拒答率是召回健康度的代理指标。合理做法：按业务分域设基线（法规问答域允许 10-20% 拒答，闲聊域接近 0），监控的是"相对基线的漂移"；漂移 >2σ 触发检索链路排查。防线优先级排序：先修检索，再调 prompt，最后才怪模型。

**背诵要点**：
- 引用标注只证明"看见"，三层防线（机械校验→NLI 蕴含→拒答）才证明"出自证据"。
- 机械层零模型成本：引用 id 合法性 + 数字归一化溯源，先拦 80% 幻觉。
- 拒答率是检索健康度的代理指标，监控漂移而非绝对值。

## 背诵要点
- 校验分层由便宜到贵：字符串工程 → 轻量 NLI → 人工复核。
- 计算型数字与引用型数字分开校验，防机械层假阳性。
- 引用覆盖率 + 拒答率是幻觉防线的两个仪表盘指标。
