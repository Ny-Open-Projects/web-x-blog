# Go PaaS 平台开发: 环境安装与版本说明

## 纲要

- 本章目标：搭建后续 PaaS 平台微服务开发所需的 Go、Docker、Docker Compose 基础环境
- 版本基线：Go 1.13（课程最低要求、默认开启 Go Module）/ 课程演示使用 1.16；Docker 20.10；Docker Compose 1.27
- Go 安装：从官方网站下载对应系统的安装包
- Docker 与 Docker Compose 安装：macOS 通过 Docker Desktop（内置 Compose），Linux / Windows 取独立发行版
- 安装完成后用 `go version`、`docker version`、`docker compose version` 校验环境是否就绪

## 本章环境范围

本章围绕「基础开发环境」展开，主要覆盖三部分：

- Go Module 代理设置，以及私有代码仓库（如课程私有 Git）的拉取配置
- 微服务工程目录的生成与目录职责说明
- Docker Compose 的安装、镜像构建与容器编排使用

其中版本一致是后续一切操作的前提，下面先明确各组件的版本基线。

## 版本要求

| 组件 | 最低版本 | 课程演示版本 | 说明 |
| --- | --- | --- | --- |
| Go | 1.13 | 1.16 | 1.13 起默认开启 Go Module（`GO111MODULE=on`），无需额外开关 |
| Docker | 20.10 | 20.10 | 后续编译镜像、运行容器均依赖此版本 |
| Docker Compose | 1.27 | 1.27 | 用于多容器编排与一键构建 |

> 若本机已安装多个 Go SDK，默认 `go` 命令对应的版本以 `go version` 实际输出为准；课程演示机默认指向 1.13。

## Go 语言安装

访问 Go 官方下载页，按操作系统选择安装包：

- 地址：`https://go.dev/dl/`
- macOS：下载 `pkg` 安装包双击安装
- Linux：下载 `tar.gz` 解压到 `/usr/local`
- Windows：下载 `msi` 安装包

安装后建议确认 `GOPATH`、`GOROOT` 已就位（现代 Go 默认 `GOPATH=$HOME/go`）。

## Docker 与 Docker Compose 安装

- macOS / Windows：安装 Docker Desktop，启动后 Docker 与 Docker Compose 同时可用
  - 地址：`https://www.docker.com/products/docker-desktop`
- Linux：Docker Engine 与 Docker Compose 需分别安装
  - Docker Compose 发行版：`https://github.com/docker/compose/releases`

## 验证安装

安装完成后在终端执行以下命令，确认版本输出正常：

```bash
# 查看 Go 版本与模块状态
go version
go env GO111MODULE

# 查看 Docker 与 Compose 版本
docker version
docker compose version
```

若以上命令均能正常输出，说明基础环境已准备完毕，可进入下一节进行代理与私有仓库配置。
