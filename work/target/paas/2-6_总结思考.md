## 本章回顾

本章依次打通了后续 PaaS 平台开发的全部基础环境：

- **版本基线**：Go 1.13（默认开启 Go Module）/ 课程使用 1.16，Docker 20.10，Docker Compose 1.27
- **依赖与私有仓库**：通过 `GOPROXY` 加速公共模块，用 `GOPRIVATE` 与 `git config` 的 `insteadOf` 解决私有仓库拉取
- **目录结构**：约定 `model / repository / service / handler / proto` 分层，以及 `go.mod`、`Dockerfile`、`Makefile` 等配套文件
- **代码生成**：用 cap-tool（Docker 镜像 `cap1573/cap-tool`）一键生成标准工程与基础代码，`make proto` 借助 `cap-v3` 生成 proto 对应 Go 代码
- **容器编排**：用 `docker-compose.yml` 统一构建、启动与停止多个服务

这些操作在第三章及之后的微服务开发中会被频繁使用，建议在本章就做到熟练。

## 实践作业

- 完成 Go 开发环境安装，并正确配置 Go Module 代理与私有仓库（这是后续所有内容的前提）
- 使用 cap-tool 创建一个项目，确认目录结构与基础代码已生成
- 安装 Docker Compose，并对生成的服务执行 `build` / `up` / `down`，熟悉其用法

> 若对 Docker Compose 的写法或镜像体系结构还想深入了解，可参考课程配套的扩展阅读资料与示例 Compose 文件。
