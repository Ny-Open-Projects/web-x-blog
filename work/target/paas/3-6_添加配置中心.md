# Go PaaS 平台开发: go-micro v3 添加配置中心

## 纲要

- 注册中心与配置中心都可以基于 Consul 实现，本节用 Consul 的 KV 存储充当配置中心。
- 配置中心解决的问题：把易变的配置（数据库连接、功能开关等）从代码中剥离，集中存放、动态读取。
- go-micro v3 配置能力由 `github.com/asim/go-micro/v3/config` 提供，数据源通过 `config/source/consul/v3` 插件接入 Consul KV。
- 通过 Consul UI 的 Key/Value 页面写入 JSON 配置，服务启动时读取。

## 为什么用配置中心

单体应用常把配置写在配置文件里，但微服务实例众多、环境各异，硬编码或散落各处的配置文件难以维护。配置中心把"经常变动的量"集中管理，支持：

- 统一存放：一个仓库/一个 KV 前缀管理全部服务的配置。
- 动态读取：服务启动时拉取，部分实现还支持运行时热更新。
- 环境隔离：本地、测试、生产通过不同前缀或地址区分。

## 配置中心的数据结构

配置中心里存放的是结构化文件（常见 JSON / YAML）。例如存放一个 `mysql` 配置：

```json
{
  "mysql": {
    "host": "127.0.0.1",
    "port": 3306,
    "user": "root",
    "password": "123456",
    "dbname": "paas"
  }
}
```

在 Consul KV 中，这个配置的 key 通常由"前缀 + 服务名"组成，例如 `micro/config/go.micro.srv.paas/mysql`，值为上面的 JSON 字符串。

## API 速览

### config.NewConfig

```go
func config.NewConfig(opts ...config.Option) (config.Config, error)
```

通过 `config.WithSource(source)` 追加数据源。

### consul.NewSource

```go
func consul.NewSource(opts ...source.Option) source.Source
```

常用选项：

- `consul.WithAddress("127.0.0.1:8500")`：Consul 地址。
- `consul.WithPrefix("micro/config")`：读取的 KV 前缀。
- `consul.WithStripPrefix(true)`：读取后是否去掉前缀。

### 读取配置值

```go
val := conf.Get("mysql", "host").String("127.0.0.1")
```

`Get` 返回 `config.Value`，`String(default)` 在缺失时返回默认值。

## Demo 示例

### 运行说明

1. 确保 Consul 集群已启动（见 3-4）。
2. 拉取依赖：

```bash
go get github.com/asim/go-micro/v3/config
go get github.com/asim/go-micro/plugins/config/source/consul/v3
```

### 代码说明

```go
package main

import (
	"log"

	"github.com/asim/go-micro/v3/config"
	consul "github.com/asim/go-micro/plugins/config/source/consul/v3"
)

func main() {
	src := consul.NewSource(
		consul.WithAddress("127.0.0.1:8500"),
		consul.WithPrefix("micro/config"),
	)

	conf, err := config.NewConfig(config.WithSource(src))
	if err != nil {
		log.Fatalf("load config failed: %v", err)
	}

	// 读取 mysql.host，缺省回退到 127.0.0.1
	host := conf.Get("mysql", "host").String("127.0.0.1")
	port := conf.Get("mysql", "port").Int(3306)
	log.Printf("mysql address = %s:%d", host, port)
}
```

### 在 Consul UI 写入配置

1. 打开 `http://127.0.0.1:8500`，进入 `Key/Value`。
2. 点击 `Create` 新建 key：`micro/config/go.micro.srv.paas/mysql`。
3. value 填入上面的 JSON 字符串。
4. 运行程序，即可打印出从配置中心读到的 MySQL 地址。

### 技术点总结

- 配置中心与注册中心共用 Consul，降低中间件数量。
- `config.Value` 的 `String` / `Int` 等方法带默认值，配置缺失时不至于直接崩溃。
- 读取到的 JSON 需要反序列化为结构体才能方便使用，下一节连接 MySQL 时会演示映射过程。
