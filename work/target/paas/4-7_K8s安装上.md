# Go PaaS 平台开发: K8s 安装（上）

## 纲要

- 课程演示基于阿里云 ECS，单 Master + 单 Worker 的最小集群（生产建议多 Master）
- 最低配置：每个节点 CPU ≥ 2 核、内存 ≥ 4G；系统 CentOS 7.6/7.7/7.8 或 CentOS Stream 8
- K8s 版本固定为 **1.21.5**；网络插件使用 **Flannel**
- 安装脚本：`check_host.sh`（主机检查）、`base_install.sh`（所有节点基础环境）
- 关键前置：固定内网 IP、关闭防火墙/Swap/SELinux、配置 K8s yum 源

> 本集群的所有 PaaS 平台代码都将基于 K8s 开发，因此必须先把集群装好。课程提供经过测试的便捷安装脚本，把脚本放到目标机器执行，约十几二十分钟即可完成。

## 准备云主机

课程演示在阿里云 ECS 上完成，你也可以在本机用虚拟机虚拟出几台机器。无论哪种方式，建议准备**至少两台**机器：一台 Master 节点、一台 Worker（工作）节点。

选购时注意几点：

- **节点规格**：最低 2 核 4G，Master 与 Worker 都一样，否则安装时的检测项无法通过。
- **系统版本**：CentOS 7.8（7.6/7.7 及 CentOS Stream 8 也可以）。
- **K8s 版本**：固定使用 **1.21.5**，版本搞错会导致后续很多东西对不上。
- **网络**：勾选 IPv4，使用 100M 按量带宽；安全组默认开放 80/443，若要对外暴露 apiserver 的 6443 端口，需要在安全组单独放行。
- **地域**：学习阶段建议使用香港节点，避免国内节点绑定域名需备案的问题。
- **节点命名**：hostname 不能使用 localhost，且不能包含下划线、小数点、大写字母；每个节点需有固定的内网 IP。

## 主机检查

在每台机器上执行 `check_host.sh`，确认系统版本、CPU 核数、hostname 符合要求：

```bash
# 在 master 节点和 worker 节点都要执行
cat /etc/redhat-release

# 此处 hostname 的输出将作为该机器在 K8s 集群中的节点名，不能用 localhost
hostname

# 核对 CPU 信息：架构需为 x86_64，CPU(s) 不能低于 2
lscpu
```

## 所有节点基础安装

把 `base_install.sh` 拷贝到每台服务器，先设置阿里云镜像地址，再执行脚本并传入 K8s 版本号：

```bash
# 所有节点都要执行（master 和 worker）
# 指定阿里云 docker hub 镜像加速地址
export REGISTRY_MIRROR=https://registry.cn-shanghai.aliyuncs.com

# 传入版本号 1.21.5 进行基础安装
./base_install.sh 1.21.5
```

`base_install.sh` 在后台会自动完成以下关键步骤（节选自脚本）：

```bash
# 卸载旧版本 docker
yum remove -y docker docker-client docker-ce-cli ...

# 安装 docker 并配置镜像加速与 cgroup 驱动
yum install -y docker-ce docker-ce-cli
cat > /etc/docker/daemon.json <<EOF
{
  "registry-mirrors": ["${REGISTRY_MIRROR}"],
  "exec-opts": ["native.cgroupdriver=systemd"],
  "log-driver": "json-file",
  "log-opts": { "max-size": "100m" },
  "storage-driver": "overlay2"
}
EOF
systemctl enable docker && systemctl restart docker

# 关闭防火墙 / SELinux / Swap
systemctl stop firewalld && systemctl disable firewalld
setenforce 0
swapoff -a

# 配置 K8s 的 yum 源并安装 kubelet / kubeadm / kubectl
yum install -y kubelet-1.21.5 kubeadm-1.21.5 kubectl-1.21.5
systemctl enable kubelet && systemctl start kubelet
```

> 说明：1.21.5 版本默认仍支持 Docker 作为运行时（课程沿用 Docker 方式）。若后续升级到更高版本，containerd 成为默认运行时，脚本中已预留相关配置（注释部分）可按需开启。

安装完成后，用 `docker --version` 与 `kubelet --version` 验证版本是否正确。基础环境就绪后，下一步将在 Master 节点初始化集群并加入 Worker 节点（见下篇）。
