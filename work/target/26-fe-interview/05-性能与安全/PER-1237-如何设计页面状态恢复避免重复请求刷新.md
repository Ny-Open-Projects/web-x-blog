## PER-1237：如何设计"页面状态恢复"避免重复请求（刷新/回退场景）

**答**：
- 场景：列表翻到第 5 页刷新后回第 1 页——体验差且重复请求。
- 方案：状态入 URL（页码/筛选可分享可恢复）、滚动位置+数据快照入 sessionStorage（bfcache 之外的兜底）、bfcache 优先（pageshow 持久化）。
- 一致性：恢复的快照带时间戳，超过 TTL 静默刷新；写操作后快照失效。
- 度量：状态恢复成功率、恢复后重复请求率（目标 0）。

```javascript
// 列表状态恢复
function saveListState(key, state) {
  sessionStorage.setItem(`ls:${key}`, JSON.stringify(
    { ...state, scroll: scrollY, at: Date.now() }));
}
function restoreListState(key, { ttl = 5 * 60_000 } = {}) {
  const raw = sessionStorage.getItem(`ls:${key}`);
  if (!raw) return null;
  const s = JSON.parse(raw);
  if (Date.now() - s.at > ttl) return null;      // 过期不恢复
  return s;
}
// 页面加载：restore ? 恢复+跳滚动 : 正常请求
const s = restoreListState('orders');
if (s) { applyFilters(s.filters); scrollTo(0, s.scroll); }
else fetchFirstPage();
```
