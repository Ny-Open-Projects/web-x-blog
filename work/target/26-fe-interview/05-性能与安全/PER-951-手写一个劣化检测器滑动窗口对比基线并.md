## PER-951：手写一个劣化检测器：滑动窗口对比基线并输出连续劣化事件

**答**：
- 需求：实现 detectRegressions(points, opts)。points 为按时间的 { t, p75 }；基线 baseline；当连续 streak 个点超过 baseline*(1+rate) 时输出一个事件 { from, to, peak }，不重复报已开启事件，恢复（低于阈值）后可再次触发。
- 边界：点乱序需按 t 排序；样本不足 streak 时不触发；rate/streak 有默认值。
- 评分点：排序；连续计数与去重；未闭合事件处理；恢复重置

```javascript
function detectRegressions(points, { baseline = 2500, rate = 0.08, streak = 3 } = {}) {
  const sorted = [...points].sort((a, b) => a.t - b.t);
  const events = []; let run = null;
  for (const p of sorted) {
    const bad = p.p75 > baseline * (1 + rate);
    if (bad) {
      if (!run) run = { from: p.t, peak: p.p75, len: 0 };
      run.peak = Math.max(run.peak, p.p75); run.len++;
    } else if (run) {
      if (run.len >= streak) events.push({ from: run.from, to: p.t, peak: run.peak });
      run = null;                                       // 恢复后允许再次触发
    }
  }
  if (run && run.len >= streak) events.push({ from: run.from, to: null, peak: run.peak });
  return events;
}
```
