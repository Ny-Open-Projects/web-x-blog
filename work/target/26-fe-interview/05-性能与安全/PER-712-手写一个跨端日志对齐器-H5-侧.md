## PER-712：手写一个跨端日志对齐器：H5 侧生成/接收 traceId、维护时钟偏移并按协议上报

**答**：
- H5 职责：从启动参数/UA 提取容器 traceId（没有则自生成并回传 Native）；计算与 Native 单调时钟的偏移（用 bridge 调用往返估计）；所有上报带协议字段。
- 要点：时钟偏移估计用多次往返取最小值（网络延迟单侧化假设）；traceId 提取失败标记 `traceSource: 'self'`；上报字段按协议清单校验。
- 边界：bridge 不可用（浏览器直开）时偏移为 0 且标记降级；偏移漂移要周期重估（长会话时钟漂移）。
- 评分点：往返估计偏移与降级标记。

```javascript

class CrossStackLogger {
  constructor(bridge) {
    this.traceId = extractTraceFromBoot() ?? genTrace();
    if (!extractTraceFromBoot()) bridge?.call('reportTrace', { traceId: this.traceId }); // 回传 Native
    this.offset = 0;
    this.estimateOffset(bridge);
  }
  async estimateOffset(bridge, samples = 5) {                   // 往返估计时钟偏移
    const offsets = [];
    for (let i = 0; i < samples; i++) {
      const t0 = Date.now();
      const nativeNow = await bridge?.call('getNativeTime') ?? t0;
      const rtt = Date.now() - t0;
      offsets.push(nativeNow - (t0 + rtt / 2));                 // 最小 RTT 样本最准
    }
    this.offset = Math.min(...offsets.map(Math.abs)) * Math.sign(offsets.find(o => Math.abs(o) === Math.min(...offsets.map(Math.abs))) ?? 1) || offsets[0] ?? 0;
    if (!bridge) this.degraded = true;                          // 浏览器直开降级
  }
  log(event) {                                                  // 协议字段校验后上报
    navigator.sendBeacon('/collect/xlog', JSON.stringify({
      traceId: this.traceId, traceSource: extractTraceFromBoot() ? 'container' : 'self',
      nativeTs: Date.now() + this.offset,                       // 对齐 Native 时钟
      dims: { route: location.pathname, containerVersion: window.__CONTAINER_VER,
        deviceTier: window.__deviceTier },
      event,
    }));
  }
}
```
