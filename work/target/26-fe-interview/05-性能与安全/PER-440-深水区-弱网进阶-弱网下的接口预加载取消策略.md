## PER-440：弱网下的预加载取消策略：预取的 abort 时机与带宽让路？

**答**:
- 问题：弱网带宽稀缺，预取请求与用户真实请求抢带宽——用户点进详情页时，预取的推荐流还在占带宽，详情主接口被排队（INP + LCP 双输）。预取必须"可让路"。
- 让路策略：① 带宽感知降级——弱网档位下预取并发降为 1 甚至 0（PER-333 分级）；② 真实请求抢占——用户真实请求发起时 abort 同域低优先级预取（AbortController 注册表，PER-109 的 extend）；③ 预取超时——预取超过 10s 未完成直接 abort（弱网下大概率无用，省用户流量）；④ saveData 全禁（PER-326）。
- 实现要点：预取请求全部带标记与 controller 注册（可枚举可取消）；abort 后预取结果视为未预取（缓存不写入半成品）；优先级用 fetchpriority（浏览器侧调度）+ 应用层并发池双轨。
- 验收：弱网档位模拟"预取进行中用户点击"场景——主接口 TTFB 应不受预取影响（对照无让路版本）。

```javascript
class PrefetchManager {
  #inflight = new Map();                                // key -> {ctrl, url}
  prefetch(key, url) {
    if (navigator.connection?.saveData || networkTier() === 'slow') return;
    const ctrl = new AbortController();
    this.#inflight.set(key, { ctrl, url, at: Date.now() });
    fetch(url, { signal: ctrl.signal, priority: 'low' })
      .then((r) => cachePut(url, r))
      .catch(() => { /* abort/失败：缓存不写半成品 */ })
      .finally(() => this.#inflight.delete(key));
    setTimeout(() => this.cancel(key, 'timeout'), 10000);   // 弱网超时让路
  }
  yieldTo(key) {                                        // 真实请求发起：abort 同域预取让路
    for (const [k, p] of this.#inflight) {
      if (new URL(p.url).host === new URL(location.href).host) this.cancel(k, 'yield');
    }
  }
  cancel(key, reason) { const p = this.#inflight.get(key); if (p) { p.ctrl.abort(reason); this.#inflight.delete(key); } }
}
// 弱网语义：预取可随时牺牲（abort 不影响业务）；真实请求永远优先于预取
// 验收：Slow 档模拟"预取中点击"——主接口 TTFB 不被预取挤占
```
