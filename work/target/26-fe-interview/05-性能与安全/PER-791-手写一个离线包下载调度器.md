## PER-791：手写一个离线包下载调度器：带宽预算、优先级队列与失败重试退避

**答**：
- 需求：多个包排队下载，按优先级（基础包 > 高频业务包 > 低频）出队；同时刻并发 ≤ 2；全局带宽预算（每分钟最多 X MB），超预算推迟；失败指数退避重试（最多 3 次），失败 3 次降级为在线模式。
- 边界：高优先级包可插队；正在下载的任务不可被取消抢占（等完成）；网络切换到弱网自动暂停。
- 评分点：优先级插队；退避重试与降级路径；带宽预算控制。

```javascript
class OfflineDownloader {
  constructor({ concurrency = 2, budgetMB = 10 } = {}) {
    this.queue = []; this.running = 0; this.usedMB = 0; this.windowStart = Date.now();
    this.concurrency = concurrency; this.budget = budgetMB; this.retries = new Map();
  }
  push(task) { this.queue.push(task); this.queue.sort((a, b) => a.priority - b.priority); this.drain(); }
  drain() {
    while (this.running < this.concurrency && this.queue.length) {
      if (this.usedMB >= this.budget) return;          // 预算耗尽：本窗口暂停
      const task = this.queue.shift();
      this.running++;
      task.run().then(sizeMB => { this.tick(sizeMB); })
        .catch(() => this.retry(task))
        .finally(() => { this.running--; this.drain(); });
    }
  }
  retry(task) {
    const n = (this.retries.get(task.id) || 0) + 1;
    this.retries.set(task.id, n);
    if (n > 3) return this.fallbackOnline(task);       // 降级在线模式
    setTimeout(() => this.push({ ...task, priority: task.priority }), 2 ** n * 1000);  // 指数退避
  }
  tick(sizeMB) {                                       // 滑动分钟窗口流量记账
    const now = Date.now();
    if (now - this.windowStart > 60000) { this.windowStart = now; this.usedMB = 0; }
    this.usedMB += sizeMB;
  }
  fallbackOnline(task) { /* 上报降级，页面走在线 */ }
}
```
