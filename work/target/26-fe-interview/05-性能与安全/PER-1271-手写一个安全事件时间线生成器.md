## PER-1271：手写一个安全事件时间线生成器

**答**：
- 需求：implement timeline(events)。events 为 [{ ts, type: inject/detect/contain/fix/report, detail }]；按 type 顺序约束（inject < detect < contain < fix）验证合理性；输出 { ordered: events, gaps: [{ between, hours }], mtt }：gaps 为相邻关键节点间隔（detect-inject、contain-detect）；mtt = contain - detect（MTTD 到 MTTC）。
- 边界：乱序事件标注 anomaly；type 缺失按 unknown 排最后；空输入返回 { ordered: [], gaps: [], mtt: null }。
- 评分点：类型排序；乱序标注；间隔计算；MTTC

```javascript
function timeline(events) {
  const ORDER = { inject: 0, detect: 1, contain: 2, fix: 3, report: 4 };
  const sorted = [...events].sort((a, b) =>
    (ORDER[a.type] ?? 9) - (ORDER[b.type] ?? 9) || a.ts - b.ts);
  const ordered = [], gaps = []; let detect = null;
  for (const e of sorted) {
    const prev = ordered[ordered.length - 1];
    if (prev && ORDER[e.type] < ORDER[prev.type]) e.anomaly = true;   // 乱序
    ordered.push(e);
    if (e.type === 'detect') detect = e.ts;
    if (e.type === 'detect' && ordered.some(x => x.type === 'inject'))
      gaps.push({ between: 'inject->detect',
        hours: +((e.ts - ordered.find(x => x.type === 'inject').ts) / 3600_000).toFixed(1) });
  }
  const contain = sorted.find(e => e.type === 'contain');
  const mtt = detect && contain ? +((contain.ts - detect) / 3600_000).toFixed(1) : null;
  return { ordered, gaps, mtt };
}
```
