## PER-1131：手写一个输出编码器：按上下文选择转义策略

**答**：
- 需求：实现 encodeFor(ctx, value)。ctx: html/html-attr/js/url/css；各上下文规则：html → & < > 转义；html-attr → 加 " → &quot；js → 非 ASCII 与特殊符 \u 转义（防 </script> 逃逸）；url → encodeURIComponent 并拒绝 javascript:；css → 移除 url() 与表达式。
- 边界：非字符串先转字符串；空串返回空；js 上下文同时处理 </script> 切分（\u003c）；url 校验失败返回井号。
- 评分点：五上下文规则；js 转义防逃逸；url 协议校验；css 注入

```javascript
function encodeFor(ctx, value) {
  const v = String(value ?? '');
  switch (ctx) {
    case 'html':
      return v.replace(/&/g, '&amp;').replace(/</g, '&lt;')
        .replace(/>/g, '&gt;');
    case 'html-attr':
      return encodeFor('html', v).replace(/"/g, '&quot;').replace(/'/g, '&#39;');
    case 'js':
      return v.replace(/[<>'"&\\\u0000-\u001f]/g, c =>
        '\\u' + c.charCodeAt(0).toString(16).padStart(4, '0'));
    case 'url': {
      try {
        const u = new URL(v, 'https://x.example');
        if (!['http:', 'https:'].includes(u.protocol)) return '#';
        return encodeURIComponent(v);
      } catch { return '#'; }
    }
    case 'css':
      return v.replace(/url\s*\(/gi, '').replace(/expression\s*\(/gi, '')
        .replace(/[<>"']/g, '');
    default: return encodeFor('html', v);
  }
}
```
