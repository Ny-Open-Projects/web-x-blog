## PER-900：手写一个性能安全风险审计器：扫描常见性能手段（离线包、缓存、预取）的安全风险

**答**：
- 需求：实现 perfSecurityScan(config)：config 为 {offline: {signed: bool, blacklist: bool}, cache: {encrypt: bool, clearOnLogout: bool, sensitiveKeys: [...]}, prefetch: {authChecked: bool, crossUser: bool}}；按风险规则输出 findings [{item, level: high|medium|low, fix}]；规则：离线包无签名=high；缓存含敏感键未加密=high；登出不清缓存=medium；预取未鉴权=high；跨用户预取=high；输出整体 verdict（有 high 则 block）。
- 边界：缺省配置项按"未做"处理（fail-closed）；sensitiveKeys 匹配不区分大小写；findings 按 level 排序。
- 评分点：fail-closed 缺省处理；规则覆盖完整；verdict 收敛。

```javascript
function perfSecurityScan(config, { sensitiveDefault = ['token', 'user', 'order'] } = {}) {
  const f = [];
  const off = config.offline ?? {};                            // fail-closed：缺省视为未做
  if (!off.signed) f.push({ item: 'offline-signature', level: 'high', fix: '整包聚合签名校验' });
  if (!off.blacklist) f.push({ item: 'offline-blacklist', level: 'medium', fix: '版本黑名单通道' });
  const cache = config.cache ?? {};
  const keys = (cache.sensitiveKeys ?? []).map(k => k.toLowerCase());
  if (keys.some(k => sensitiveDefault.some(s => k.includes(s))) && !cache.encrypt)
    f.push({ item: 'cache-sensitive-plain', level: 'high', fix: '敏感键落盘加密' });
  if (!cache.clearOnLogout) f.push({ item: 'cache-logout-clear', level: 'medium', fix: '登出清缓存' });
  const pf = config.prefetch ?? {};
  if (!pf.authChecked) f.push({ item: 'prefetch-auth', level: 'high', fix: '预取接口鉴权检测' });
  if (pf.crossUser) f.push({ item: 'prefetch-cross-user', level: 'high', fix: '禁止预取他人数据' });
  const order = { high: 0, medium: 1, low: 2 };
  return { findings: f.sort((a, b) => order[a.level] - order[b.level]),
    verdict: f.some(x => x.level === 'high') ? 'block' : 'pass' };
}
```
