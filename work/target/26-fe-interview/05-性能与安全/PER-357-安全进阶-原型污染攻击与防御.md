## PER-357：原型污染攻击是什么？前端深度合并/查询解析场景怎么防？

**答**：
- 机理：攻击者构造 `{"__proto__": {"isAdmin": true}}` 输入，若代码用不安全的深合并/Object.assign 递归/URL 参数展开把它合并到目标对象，会**修改 Object.prototype**——所有对象继承污染属性，后续逻辑（权限判断、模板渲染、配置读取）被劫持。
- 高危场景：前端路由 query 参数合并到配置、表单值 deepMerge 到状态、低代码平台 JSON 配置注入、`JSON.parse` 后未净化的数据进合并器。
- 防御：① 合并器屏蔽危险键——`__proto__`/`constructor`/`prototype` 一律跳过；② 用 `Object.create(null)` 的字典容器（无原型可污染）；③ 冻结关键原型（`Object.freeze(Object.prototype)` 兜底，注意影响扩展）；④ 输入校验白名单（schema 校验后再合并）。
- 检测：单测覆盖"污染 payload 合并后 Object.prototype 不变"；fuzz 深合并函数；第三方深合并库审计（历史 CVE 多）。

```javascript
const BLOCKED = new Set(['__proto__', 'constructor', 'prototype']);
function safeMerge(target, source) {
  for (const [k, v] of Object.entries(source)) {
    if (BLOCKED.has(k)) continue;                       // 核心防线：危险键跳过
    if (v !== null && typeof v === 'object' && !Array.isArray(v)) {
      target[k] = target[k] && typeof target[k] === 'object' ? { ...target[k] } : {};
      safeMerge(target[k], v);
    } else target[k] = v;
  }
  return target;
}
// payload 验证：safeMerge({}, JSON.parse('{"__proto__":{"isAdmin":true}}'))
// => Object.prototype.isAdmin === undefined  （防御生效）
// 字典容器方案：const dict = Object.create(null); —— dict 没有 __proto__ 可污染
```
