## PER-852：手写一个图片格式探测与选型器：能力检测加收益估算输出最优格式

**答**：
- 需求：实现 pickFormat(canvas, candidates)：用 canvas.toDataURL 探测各格式支持（avif/webp 逐个测）；结合收益表（各格式 saving）与当前网络档（弱网优先高压缩格式）输出最优格式；全部不支持回退 jpeg。
- 边界：探测失败（toDataURL 抛错/返回 data:,）视为不支持；同 saving 时取兼容更广者；探测结果缓存（会话级）。
- 评分点：探测方法正确；缓存探测结果；弱网策略加权。

```javascript
const SAVING = { avif: 0.45, webp: 0.3, jpeg: 0 };
function pickFormat(canvas, { net = 'wifi', cache = new Map() } = {}) {
  const key = 'fmt-probe';
  if (cache.has(key)) return cache.get(key);
  const supported = [];
  for (const f of ['image/avif', 'image/webp']) {
    try {
      const url = canvas.toDataURL(f);       // 探测：不支持时返回 data:,
      if (url && url.startsWith('data:' + f.split('/')[1])) supported.push(f.split('/')[1]);
    } catch { /* 不支持 */ }
  }
  if (!supported.length) return 'jpeg';      // 全不支持回退
  // 弱网加权：saving 权重提高
  const score = f => SAVING[f] * (net === 'wifi' ? 1 : 2) + (f === 'webp' ? 0.05 : 0);  // webp 兼容广微加分
  const best = supported.sort((a, b) => score(b) - score(a))[0];
  cache.set(key, best);
  return best;
}
```
