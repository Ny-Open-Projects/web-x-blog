## PER-1235：大数据量图表的降采样算法怎么选

**答**：
- 算法：LTTB（保形状）、min-max 抽取（保极值）、M4（保四分位桶）、简单等距抽样（最快最糙）。
- 选择：折线趋势用 LTTB；要看到尖峰（监控）用 min-max/M4；散点用密度聚合（分桶计数）。
- 参数：目标点数 800~2000（像素宽度相关，超过无视觉增益）。
- 组合：服务端预降采样（原始存明细，查询层出降采样结果）+ 客户端再降（zoom 到原始区间再取）。

```javascript
// min-max 降采样：保极值
function minmaxSample(data, target = 1000) {
  if (data.length <= target) return data;
  const bucket = Math.floor(data.length / (target / 2));
  const out = [];
  for (let i = 0; i < data.length; i += bucket) {
    const seg = data.slice(i, i + bucket);
    let mn = seg[0], mx = seg[0];
    for (const p of seg) {
      if (p.v < mn.v) mn = p;
      if (p.v > mx.v) mx = p;
    }
    out.push(mn.ts < mx.ts ? mn : mx, mn.ts < mx.ts ? mx : mn);
  }
  return out.slice(0, target);
}
```
