## PER-1185：前端如何处理"数据本地化要求"（境内存储）

**答**：
- 要求：关键信息基础设施/百万级用户个人信息处理者在境内存储；出境按 1173 评估。
- 工程：境内用户数据落境内机房（域名 ICP 备案 + 服务器境内）、CDN 境内节点、境外 SDK 替换为境内等价物或拦截。
- 前端：上报域名按用户区域解析（1002）、地图/分析 SDK 用境内版（如高德替代 Google Maps）。
- 验证：抓包确认境内用户全部流量落境内域，无境外 SDK 请求。

```javascript
// 境内 SDK 替换表
const SDK_MAP = {
  'maps': { intl: 'maps.googleapis.com', cn: 'api.amap.com' },
  'analytics': { intl: 'analytics.vendor.com', cn: 'analytics.cn-vendor.com' },
};
function pickSDK(kind, region) {
  const s = SDK_MAP[kind];
  const url = region === 'CN' ? s.cn : s.intl;
  if (region === 'CN') assertDomestic(url);        // 断言境内域
  return url;
}
function assertDomestic(url) {
  const host = new URL('https://' + url).host;
  if (!/(\.cn|alicdn|aliyun|qcloud)/.test(host))
    throw new Error('境内用户不得加载境外 SDK: ' + host);
}
```
