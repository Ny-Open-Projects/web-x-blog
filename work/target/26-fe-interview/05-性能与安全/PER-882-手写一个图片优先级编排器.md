## PER-882：手写一个图片优先级编排器：fetchpriority、preload 与 LCP 监听联动

**答**：
- 需求：实现 ImagePriorityPlanner：register(imgs) 接收图片清单 [{src, viewport: bool, isLcp}]，输出每张的编排动作（preload-high / eager / lazy+margin），规则：isLcp → preload+eager；viewport 且非 LCP → eager；非 viewport → lazy（margin 300px）；若 LCP 缺失自动选取 viewport 中面积最大的图为 LCP。提供 verify(observer) 用 PerformanceObserver 校验实际 LCP 元素与计划一致，不一致输出偏差报告。
- 边界：同 src 多实例只编排一次；面积计算用 width×height 缺失时按声明尺寸估算；verify 未产出 LCP 时返回 pending。
- 评分点：LCP 自动推断；动作规则覆盖完整；verify 偏差报告。

```javascript
class ImagePriorityPlanner {
  register(imgs) {
    let lcp = imgs.find(i => i.isLcp);
    if (!lcp) {                                                // 自动推断：首屏最大面积
      const inView = imgs.filter(i => i.viewport);
      lcp = inView.sort((a, b) => (b.width * b.height) - (a.width * a.height))[0];
    }
    this.plan = new Map();
    const seen = new Set();
    for (const img of imgs) {
      if (seen.has(img.src)) continue;                         // 同 src 去重
      seen.add(img.src);
      const action = img === lcp ? { act: 'preload-high', attrs: 'fetchpriority=high loading=eager' }
        : img.viewport ? { act: 'eager', attrs: 'fetchpriority=eager loading=eager' }
        : { act: 'lazy', attrs: 'loading=lazy margin=300px' };
      this.plan.set(img.src, action);
    }
    return this.plan;
  }
  verify() {
    return new Promise(resolve => {
      new PerformanceObserver(list => {
        const e = list.getEntries().at(-1);
        if (!e) return resolve({ status: 'pending' });
        const src = e.element?.currentSrc || e.element?.src;
        const expected = this.plan.get(src)?.act;
        resolve({ status: expected === 'preload-high' ? 'ok' : 'mismatch',
          actualLcp: src, expectedAction: expected });
      }).observe({ type: 'largest-contentful-paint', buffered: true });
    });
  }
}
```
