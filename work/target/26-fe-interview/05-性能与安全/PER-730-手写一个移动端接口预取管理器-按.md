## PER-730：手写一个移动端接口预取管理器：按路由漏斗预取下一跳数据，带命中率反馈收缩

**答**：
- 预取策略：从埋点漏斗取当前页 -> 下一跳概率 TopN（> 30%），进入页面 idle 时预取其核心接口；预取结果进内存缓存（带 TTL），真实请求命中缓存直接返回。
- 要点：预取请求与真实请求共用同一 key（route+params 规范化）才能命中；弱网/省电档禁预取；命中率反馈——低于 30% 的预取项自动移出清单（省流量）。
- 边界：POST/带副作用接口绝不预取；预取与真实请求并发时去重（inflight 合并，同一 URL 只发一次）；缓存与登录态绑定（登出清空）。
- 评分点：inflight 去重与命中率收缩。

```javascript

class PrefetchManager {
  constructor({ ttlMs = 60000 } = {}) { this.cache = new Map(); this.inflight = new Map();
    this.ttl = ttlMs; this.stats = new Map(); }
  candidateRoutes() { return funnelTopN(currentRoute(), 2, 0.3); }  // 漏斗 Top2 且概率>30%
  warm() {
    if (navigator.connection?.effectiveType?.match(/2g|slow/)) return;   // 弱网禁预取
    (window.requestIdleCallback ?? setTimeout)(() => {
      this.candidateRoutes().forEach(r => this.prefetch(r));
    }, { timeout: 3000 });
  }
  async prefetch(route) {
    const key = normKey(route);
    if (this.cache.has(key) || this.inflight.has(key)) return;  // 去重
    const p = fetch(route.api).then(r => r.json());
    this.inflight.set(key, p);
    try {
      const data = await p;
      this.cache.set(key, { data, ts: Date.now() });
      this.stats.set(key, (this.stats.get(key) ?? { pre: 0, hit: 0 }).pre++);
    } finally { this.inflight.delete(key); }
  }
  async get(route) {                                            // 业务请求入口
    const key = normKey(route);
    const hit = this.cache.get(key);
    if (hit && Date.now() - hit.ts < this.ttl) {
      const s = this.stats.get(key); if (s) s.hit++;
      return hit.data;                                          // 命中预取
    }
    return fetch(route.api).then(r => r.json());
  }
  report() {                                                    // 命中率 < 30% 移出预取
    for (const [k, { pre, hit }] of this.stats)
      if (pre > 10 && hit / pre < 0.3) this.removeCandidate(k);
  }
}
```
