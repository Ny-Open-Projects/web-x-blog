## PER-1233：如何做"数据集变化"下的渲染性能保障（大数据量场景）

**答**：
- 场景：数据从 1k 行涨到 100k 行，原实现崩——渲染策略必须与数据规模解耦。
- 策略矩阵：<1k 直接渲染；1k-10k 虚拟滚动；>10k 虚拟滚动+分页聚合（聚合层给趋势、明细按需取）；>1M 服务端聚合+客户端只拿窗口。
- 保护机制：渲染超时熔断（>16ms/帧自动降级到聚合模式）、数据量探测定级、提示用户加过滤条件。
- 验收：数据量倍增测试（10x 压测）进 CI。

```javascript
// 数据量自适应渲染
function renderStrategy(n, { frameBudget = 16 } = {}) {
  if (n <= 1000) return { mode: 'direct' };
  if (n <= 10000) return { mode: 'virtual', overscan: 8 };
  if (n <= 100000) return { mode: 'virtual+aggregate',
    aggregate: { topN: 100, detail: 'on-demand' } };
  return { mode: 'server-window', pageSize: 50,
    hint: '请加过滤条件或用聚合视图' };
}
// 熔断：单帧超预算自动降级
function withFallback(render, fallback) {
  return data => {
    const t0 = performance.now();
    render(data);
    if (performance.now() - t0 > 16) fallback();
  };
}
```
