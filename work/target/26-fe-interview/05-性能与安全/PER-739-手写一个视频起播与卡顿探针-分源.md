## PER-739：手写一个视频起播与卡顿探针：分源归因（网络/解码/渲染）并上报卡顿率

**答**：
- 探针：监听 waiting/stalled/playing 统计卡顿；归因——同时采样 bufferAhead（hls API 或 video.buffered）、解码帧率（requestVideoFrameCallback 帧间隔）、网络速度（fetch 分片计时）；buffer 不足归网络，帧间隔大归解码，两者正常但掉帧归渲染。
- 要点：buffered 计算取当前播放时间后的可用区间；帧率采样窗口 1s；卡顿事件携带播放位置与码率档位（定位特定档位问题）。
- 边界：seek 造成的 waiting 不算卡顿（标记 seek 状态）；静音自动播放策略拦截要单独上报；探针开销低（rVFC 只在播放时跑）。
- 评分点：seek 排除与三源归因。

```javascript

class VideoStallProbe {
  constructor(video, hls) {
    this.video = video; this.hls = hls; this.stallStart = 0; this.seeking = false;
    this.stats = { stalls: 0, stallMs: 0, byCause: { net: 0, decode: 0, render: 0 } };
    video.addEventListener('seeking', () => this.seeking = true);
    video.addEventListener('seeked', () => this.seeking = false);
    video.addEventListener('waiting', () => {
      if (this.seeking) return;                                 // seek 不算卡顿
      this.stallStart = performance.now();
      this.stallCause = this.attribute();
    });
    video.addEventListener('playing', () => {
      if (!this.stallStart) return;
      const ms = performance.now() - this.stallStart;
      this.stats.stalls++; this.stats.stallMs += ms;
      this.stats.byCause[this.stallCause] += ms;
      report('video-stall', { ms: Math.round(ms), cause: this.stallCause,
        time: video.currentTime, level: hls?.currentLevel });
      this.stallStart = 0;
    });
    this.frameProbe();                                          // 解码帧率采样
  }
  attribute() {
    const v = this.video;
    const bufferAhead = Math.max(0, (v.buffered.end(v.buffered.length - 1) ?? 0) - v.currentTime);
    if (bufferAhead < 1) return 'net';                          // buffer 不足 -> 网络
    if (this.frameGap > 100) return 'decode';                   // 解码帧间隔大 -> 解码
    return 'render';                                            // 其余 -> 渲染
  }
  frameProbe() {                                                // rVFC 帧间隔
    let last = 0;
    const cb = (_now, meta) => {
      const gap = meta.mediaTime - last; last = meta.mediaTime;
      if (gap > 0 && gap < 1) this.frameGap = gap * 1000;
      this.video.requestVideoFrameCallback(cb);
    };
    this.video.requestVideoFrameCallback(cb);
  }
}
```
