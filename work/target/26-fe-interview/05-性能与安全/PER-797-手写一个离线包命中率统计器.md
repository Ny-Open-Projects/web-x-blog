## PER-797：手写一个离线包命中率统计器：拦截命中、回源与缺失三类事件的统计与漏斗

**答**：
- 需求：拦截器每次请求产生事件 {url, pkg, type: hit|fallback|miss, bytes}，实现按包聚合的漏斗统计：总请求 → 有映射（可拦截）→ 命中本地；输出命中率、回源率、miss 率与 bytes 节省，支持时间窗与 TopN URL 明细。
- 边界：无映射的 miss 不计入该包分母（归因到"未纳入离线包"）；fallback（映射存在但校验失败）要单独计数——它是健康度问题的信号。
- 评分点：三分母口径（可拦截/命中/回源）清晰；fallback 单列。

```javascript
function hitRateStats(events, { topN = 10 } = {}) {
  const byPkg = new Map(), missTop = new Map();
  for (const e of events) {
    if (e.type === 'miss' && !e.pkg) {                       // 未纳入离线包的请求
      missTop.set(e.url, (missTop.get(e.url) || 0) + 1);
      continue;
    }
    const s = byPkg.get(e.pkg) ??= { req: 0, hit: 0, fallback: 0, bytes: 0 };
    s.req++;
    if (e.type === 'hit') { s.hit++; s.bytes += e.bytes; }
    if (e.type === 'fallback') s.fallback++;                 // 校验失败回源：健康度信号
  }
  return {
    packages: [...byPkg].map(([pkg, s]) => ({ pkg,
      hitRate: s.hit / s.req, fallbackRate: s.fallback / s.req,
      savedMB: +(s.bytes / 1048576).toFixed(2) })),
    notCoveredTop: [...missTop].sort((a, b) => b[1] - a[1]).slice(0, topN),  // 候选纳入清单
  };
}
```
