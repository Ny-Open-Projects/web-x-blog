## PER-535：手写一个自动化弱网回归套件：对核心页跑四档网络并断言骨架屏、超时提示与降级文案出现

**答**：
- 套件结构：网络档位定义（离线/慢 3G/抖动/超时）+ 页面场景 + 断言函数；用 Playwright/Puppeteer 的 CDP 节流驱动。
- 要点：抖动档要随机化延迟范围（而非固定值）；离线档要断言"可恢复"（网络恢复后自动重试或手动重试入口）。
- 边界：断言的是 UI 表现（骨架屏出现时机 < 300ms、错误文案出现、重试按钮存在），不是数据正确性——那是功能测试的事。
- 评分点：档位-断言矩阵设计与离线恢复断言。

```javascript

const puppeteer = require('puppeteer');
const NETS = {
  offline: { offline: true },
  slow2g:  { latency: 800, down: 50 * 1024 / 8, up: 20 * 1024 / 8 },
  fast3g:  { latency: 150, down: 1.6 * 1024 * 1024 / 8, up: 750 * 1024 / 8 },
};
async function assertFallback(page, net) {
  const cdp = await page.createCDPSession();
  await cdp.send('Network.emulateNetworkConditions',
    { offline: !!net.offline, latency: net.latency ?? 0,
      downloadThroughput: net.down ?? -1, uploadThroughput: net.up ?? -1 });
  await page.goto('https://example.com/list', { waitUntil: 'domcontentloaded' }).catch(() => {});
  const ui = await page.evaluate(() => ({
    skeleton: !!document.querySelector('[data-testid="skeleton"]'),   // 骨架屏已出现
    errTip: document.querySelector('[data-testid="error-tip"]')?.textContent ?? '',
    retry: !!document.querySelector('[data-testid="retry-btn"]'),     // 重试入口存在
  }));
  return ui;
}
(async () => {
  const browser = await puppeteer.launch();
  const page = await browser.newPage();
  for (const [name, net] of Object.entries(NETS)) {
    const ui = await assertFallback(page, net);
    if (!ui.skeleton && !ui.errTip) throw new Error(`${name}: 无任何降级 UI`);
    if (net.offline && !ui.retry) throw new Error('离线必须有重试入口'); // 可恢复性
    console.log(name, 'PASS', ui);
  }
  await browser.close();
})();
```
