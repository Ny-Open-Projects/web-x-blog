## PER-1009：手写一个合成层预算检查器：预估层显存并给出整改建议

**答**：
- 需求：实现 checkLayers(layers)。layers 为 [{ sel, width, height, dpr, reason: will-change/transform/fixed }]；总显存 > 64MB 或单层 > 16MB 视为超标；对 reason 为 will-change 且宽高 > 500px 的层建议"缩小提升范围"；对 fixed 全屏层建议"降低 dpr 或裁剪"。输出 { totalMB, over: bool, items } 按 MB 降序。
- 边界：dpr 默认 1；尺寸为 0 跳过；重复 sel 去重保留首条。
- 评分点：显存公式；去重；阈值分级；建议生成

```javascript
function checkLayers(layers) {
  const seen = new Set();
  const items = layers
    .filter(l => l.width > 0 && l.height > 0 && !seen.has(l.sel) && seen.add(l.sel))
    .map(l => {
      const mb = l.width * l.height * 4 * (l.dpr ?? 1) ** 2 / 1024 / 1024;
      let advice = null;
      if (mb > 16) advice = '单层过大：裁剪内容或降低 dpr';
      else if (l.reason === 'will-change' && Math.max(l.width, l.height) > 500)
        advice = '缩小 will-change 范围至动画子元素';
      else if (l.reason === 'fixed' && l.width * l.height > 1_000_000)
        advice = '全屏 fixed 层考虑合成位图或降级';
      return { sel: l.sel, mb: +mb.toFixed(1), reason: l.reason, advice };
    })
    .sort((a, b) => b.mb - a.mb);
  const totalMB = +items.reduce((s, i) => s + i.mb, 0).toFixed(1);
  return { totalMB, over: totalMB > 64, items };
}
```
