## PER-1282：手写一个双写指标一致性校验器（迁移期）

**答**：
- 需求：implement dualWriteCheck(pairs, tol=0.05)。pairs 为 [{ id, oldV, newV }]（迁移期新旧口径同请求采集）；相对偏差 <= tol 判一致；输出 { consistent, mismatches: [{ id, ratio }], note }：mismatches 按 ratio 降序；ratio 为 |old-new|/old。
- 边界：oldV 为 0 且 newV 非 0 视为不一致（ratio = Infinity）；两侧都 0 一致；缺失项跳过。
- 评分点：相对偏差；0 值特判；排序；切换建议

```javascript
function dualWriteCheck(pairs, tol = 0.05) {
  const mismatches = [];
  for (const p of pairs) {
    if (p.oldV == null || p.newV == null) continue;
    const o = p.oldV, n = p.newV;
    if (o === 0 && n === 0) continue;
    if (o === 0) { mismatches.push({ id: p.id, ratio: Infinity }); continue; }
    const ratio = Math.abs(o - n) / Math.abs(o);
    if (ratio > tol) mismatches.push({ id: p.id, ratio: +ratio.toFixed(3) });
  }
  mismatches.sort((a, b) => b.ratio - a.ratio);
  return { consistent: !mismatches.length, mismatches,
    note: consistent0(mismatches) };
}
function consistent0(m) { return m.length ? '存在口径漂移，禁止切换' : '双写一致，可切换新口径'; }
```
