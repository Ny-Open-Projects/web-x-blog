## PER-1004：用户数据的最小化设计：埋点字段级审批怎么落地

**答**：
- 机制：埋点字典化——每个事件的字段必须注册（名称/类型/敏感级/目的/保留期），未注册字段 SDK 直接拒绝发送。
- 敏感级：P0 公开（页面/指标）、P1 内部（uid 哈希）、P2 敏感（位置/订单金额需专项审批）。
- 执行：SDK 发送前按注册表过滤 + 敏感级检查；CI 校验代码里的埋点调用与注册表一致。
- 收益：字段即文档，合规审计直接输出注册表，新需求默认走最小化。

```javascript
// 埋点注册表与发送过滤
const REGISTRY = {
  'page_view': { fields: { page: 0, ref: 0 }, keep: 90 },
  'order_done': { fields: { amount: 2, cnt: 0 }, keep: 365 },
};
function track(event, fields) {
  const def = REGISTRY[event];
  if (!def) return report({ type: 'unregistered', event });
  const out = {};
  for (const [k, v] of Object.entries(fields)) {
    const level = def.fields[k];
    if (level === undefined) return report({ type: 'field-not-registered', event, k });
    if (level >= 2 && !consent.get().personal) continue;    // P2 需同意
    out[k] = v;
  }
  send(event, out);
}
```
