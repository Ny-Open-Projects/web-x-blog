## PER-1203：手写一个差分隐私计数器：预算管理

**答**：
- 需求：实现 PrivateCounter(epsilon)。query(fn) 执行 fn 得真值，加 Laplace(1/epsilon) 噪声返回整数；每查询扣 1 预算，日预算 20 超出则抛错 BudgetExceeded；reset(date) 重置；spent() 返回已用量。
- 边界：负噪声结果 clamp 到 0；fn 抛错不计预算；同日重复 reset 保留已用量？——按需求 reset 清零并记录次数（>3 次告警）。
- 评分点：预算扣减；噪声 clamp；异常不计费；reset 防滥用

```javascript
class PrivateCounter {
  constructor(epsilon = 1, daily = 20) {
    this.e = epsilon; this.daily = daily;
    this.spentToday = 0; this.day = today(); this.resets = 0;
  }
  query(fn) {
    this.#roll();
    let truth;
    try { truth = fn(); }
    catch (e) { return Promise.reject(e); }        // 抛错不计预算
    if (this.spentToday >= this.daily)
      throw new Error('BudgetExceeded');
    this.spentToday++;
    const scale = 1 / this.e;
    const u = Math.random() - 0.5;
    const noise = -scale * Math.sign(u) * Math.log(1 - 2 * Math.abs(u));
    return Math.max(0, Math.round(truth + noise));
  }
  reset() {
    this.#roll();
    this.spentToday = 0;
    if (++this.resets > 3) report({ type: 'dp-reset-spam' });
  }
  spent() { this.#roll(); return this.spentToday; }
  #roll() { if (today() !== this.day) { this.day = today(); this.spentToday = 0; this.resets = 0; } }
}
function today() { return new Date().toISOString().slice(0, 10); }
```
