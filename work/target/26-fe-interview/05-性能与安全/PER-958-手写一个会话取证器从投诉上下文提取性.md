## PER-958：手写一个会话取证器：从投诉上下文提取性能证据链

**答**：
- 需求：实现 evidence(session, window)。session 为按时间的事件流 [{ t, type: "nav"|"req"|"perf"|"err", data }]；window 为 [from, to]；输出证据链：首条 nav 的 ttfb/lcp（来自 perf 事件）、窗口内最慢 3 个请求、错误序列（type/时间间隔）、结论 hint（错误集中且紧跟请求失败 -> 后端问题；lcp 高但请求正常 -> 前端渲染问题）。
- 边界：窗口过滤按 t 包含边界；缺失 perf 事件时 lcp 为 null；hint 至少给出"个案/后端/前端"三选一。
- 评分点：窗口过滤；排序取证；证据关联推理；缺省处理

```javascript
function evidence(session, [from, to]) {
  const ev = session.filter(e => e.t >= from && e.t <= to);
  const nav = ev.find(e => e.type === 'nav');
  const perf = ev.find(e => e.type === 'perf');
  const reqs = ev.filter(e => e.type === 'req')
    .sort((a, b) => b.data.ms - a.data.ms).slice(0, 3);
  const errs = ev.filter(e => e.type === 'err');
  let hint = '个案';
  const errAfterFail = errs.some(e =>
    reqs.some(r => Math.abs(r.t - e.t) < 1000 && !r.data.ok));
  if (errAfterFail) hint = '后端/网络问题';
  else if (perf && perf.data.lcp > 2500 && reqs.every(r => r.data.ok)) hint = '前端渲染问题';
  return { nav: nav?.data ?? null, lcp: perf?.data.lcp ?? null,
    slowest: reqs, errors: errs, hint };
}
```
