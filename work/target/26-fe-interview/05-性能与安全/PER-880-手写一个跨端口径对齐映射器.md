## PER-880：手写一个跨端口径对齐映射器：各端原始指标映射到统一口径并标注差异

**答**：
- 需求：实现 unifyMetrics(records, registry)：registry 为 {platform: {map: fn(raw)->ms, metric}}；输出统一记录 [{platform, unified, ms, rawMs, note}]；同页面多端对比输出 diff 矩阵（页面 × 端，值为 ms，标出同页跨端差 > 30% 的格子为 inconsistent）；registry 缺端输出 unregistered。
- 边界：map 返回 null/undefined 视为该端不支持此口径（note: not-supported）；矩阵页面按最小 ms 升序。
- 评分点：映射与不支持标注；inconsistent 阈值判定；缺端处理。

```javascript
function unifyMetrics(records, registry) {
  const unified = records.map(r => {
    const reg = registry[r.platform];
    if (!reg) return { ...r, unified: null, note: 'unregistered' };
    const ms = reg.map(r.raw);
    return { ...r, unified: reg.metric, ms,
      note: ms == null ? 'not-supported' : 'ok' };
  });
  const pages = [...new Set(unified.map(r => r.page))];
  const matrix = pages.map(page => {
    const row = {};
    for (const r of unified.filter(x => x.page === page && x.note === 'ok'))
      row[r.platform] = r.ms;
    const vals = Object.values(row);
    for (const [pf, ms] of Object.entries(row))
      if (vals.some(v => Math.abs(v - ms) / ms > 0.3)) row[pf + '_flag'] = 'inconsistent';
    return { page, row, min: Math.min(...vals) };
  }).sort((a, b) => a.min - b.min);
  return { unified, matrix };
}
// registry 例：{ h5: { metric: 'u-second-open', map: raw => raw.tti } }
```
