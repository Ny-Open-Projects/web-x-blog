## PER-1145：员工内部数据访问的合规：最小权限与操作留痕

**答**：
- 内部系统同样受个保法约束：客服查用户信息、运营导出名单都要有合法基础与留痕。
- 控制：按角色授权（工单关联才可查）、查询留痕（谁/何时/查了谁/为什么）、批量查询双人审批。
- 技术：内部系统接入 SSO + 行为审计，敏感字段查看水印（员工工号）防拍照外泄。
- 演练：定期抽查留痕完整性，"无理由查询"告警。

```javascript
// 内部查询留痕
async function lookupUser(operator, uid, reason) {
  if (!reason || reason.length < 8) throw new Error('必须填写查询事由');
  const ticket = await assertTicket(operator, uid);   // 必须关联有效工单
  logAudit(operator.id, `lookup:${hash(uid)}`, `ticket:${ticket.id}`);
  const user = await db.user.find(uid);
  return withWatermark(user, `员工${operator.id} ${new Date().toISOString()}`);
}
// 批量查询：> 10 条需第二人审批
async function bulkLookup(operator, uids) {
  if (uids.length > 10) return { needApproval: true, approver: 'team-lead' };
}
```
