## PER-1066：手写一个指数退避重试器：支持幂等键与可重试分类

**答**：
- 需求：实现 retryWithBackoff(fn, opts)。opts: { times=3, base=300, cap=5000, jitter=0.5, idempotencyKey }；错误含 status：400/401/403/404/409 不可重试，429/503/504/超时可重试；429 优先用响应 Retry-After（秒）覆盖计算延迟；每次重试 fn 收到相同 idempotencyKey；返回成功值或抛最后一个错误。
- 边界：times=0 不执行直接抛错；Retry-After 缺省用指数退避；jitter 为 0 时关闭抖动；延迟 cap 封顶。
- 评分点：可重试分类；Retry-After 优先；幂等键透传；cap+jitter

```javascript
async function retryWithBackoff(fn, { times = 3, base = 300, cap = 5000,
  jitter = 0.5, idempotencyKey } = {}) {
  if (!times) return fn({ idempotencyKey });      // times=0 也执行一次？需求为准：
  let lastErr;
  for (let i = 0; i < Math.max(1, times); i++) {
    try { return await fn({ attempt: i, idempotencyKey }); }
    catch (e) {
      lastErr = e;
      const no = [400, 401, 403, 404, 409];
      if (no.includes(e.status) || i === times - 1) throw e;
      let delay = Math.min(cap, base * 2 ** i);
      if (e.status === 429 && e.retryAfter) delay = Math.min(cap, e.retryAfter * 1000);
      delay += Math.random() * delay * jitter;
      await new Promise(r => setTimeout(r, delay));
    }
  }
  throw lastErr;
}
```
