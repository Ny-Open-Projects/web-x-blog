## PER-1057：页面加载的预加载边界：过度预加载的代价案例

**答**：
- 代价一：带宽挤占——预取 5MB 图占满带宽，用户真实点击的请求被排队，LCP 反而劣化。
- 代价二：流量费用——移动端用户为没看的资源买单，合规与体验双输。
- 代价三：缓存污染——预取的新版本把正在使用的旧版本挤出缓存。
- 纪律：预取必须有配额与优先级（Speculation Rules 的 eagerness 分级）、移动端默认保守（moderate 以下）、监控预取利用率（预取资源的真实消费率 < 30% 说明策略失败）。

```javascript
// 预取利用率审计
const prefetchLog = new Map();       // url -> prefetchedAt
function onPrefetch(url) { prefetchLog.set(url, performance.now()); }
function onActualUse(url) {
  const t = prefetchLog.get(url);
  if (t) prefetchLog.set(url, { used: true });      // 标记消费
}
function prefetchUtilization() {
  const all = [...prefetchLog.values()];
  const used = all.filter(v => v.used).length;
  return { rate: +(used / all.length * 100).toFixed(1) + '%',
    verdict: used / all.length < 0.3 ? '预取策略失败，收缩 eagerness' : 'ok' };
}
```
