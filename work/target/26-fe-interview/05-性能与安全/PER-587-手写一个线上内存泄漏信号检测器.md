## PER-587：手写一个线上内存泄漏信号检测器：周期采样 heap，对长会话计算 GC 后基线斜率并上报嫌疑样本

**答**：
- 在 586 基础上实现完整检测：滑动窗口采样、每分钟取最小值做基线、最小二乘拟合斜率、带上下文（路由/存活时长/慢任务数）上报。
- 要点：斜率拟合至少 5 个基线点；上报前剔除处于高峰交互的样本（用户正打字时 heap 自然波动）；嫌疑样本还要附带当时的长任务计数用于关联。
- 边界：`performance.memory` 不存在时直接退出并上报兼容性标记（iOS 分流统计用）。
- 评分点：最小二乘斜率与短会话过滤。

```javascript

function leakDetector(route) {
  if (!performance.memory) {
    navigator.sendBeacon('/collect/mem', JSON.stringify({ unsupported: true, ua: navigator.userAgent }));
    return;
  }
  const start = Date.now(); const samples = []; let longTasks = 0;
  new PerformanceObserver(l => longTasks += l.getEntries().length)
    .observe({ type: 'longtask', buffered: true });
  setInterval(() => samples.push({ t: Date.now() - start,
    heap: performance.memory.usedJSHeapSize / 1048576 }), 10000);
  addEventListener('pagehide', () => {
    if (Date.now() - start < 60000) return;
    const byMin = {};
    samples.forEach(s => { const k = Math.floor(s.t / 60000);
      byMin[k] = Math.min(byMin[k] ?? Infinity, s.heap); });  // GC 后基线
    const pts = Object.entries(byMin).map(([x, y]) => [+x, y]);
    if (pts.length < 5) return;
    const n = pts.length, sx = pts.reduce((s, p) => s + p[0], 0),
      sy = pts.reduce((s, p) => s + p[1], 0),
      sxy = pts.reduce((s, p) => s + p[0] * p[1], 0),
      sxx = pts.reduce((s, p) => s + p[0] ** 2, 0);
    const slope = (n * sxy - sx * sy) / (n * sxx - sx * sx);  // 最小二乘斜率 MB/min
    if (slope > 1)                                             // 嫌疑样本
      navigator.sendBeacon('/collect/mem', JSON.stringify({ route, slope: +slope.toFixed(2),
        aliveMin: Math.round(sx / n), longTasks, pts }));
  });
}
leakDetector('/list');
```
