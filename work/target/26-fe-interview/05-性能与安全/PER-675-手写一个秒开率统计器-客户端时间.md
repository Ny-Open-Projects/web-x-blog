## PER-675：手写一个秒开率统计器：客户端时间戳与页面分段埋点关联，输出分档秒开率

**答**：
- 页面侧：从启动参数/URL 里拿 Native 记录的点击时间戳（`t0`），页面在可读"（首屏渲染完）与可交互"（JS 绑定完成）两个时刻打点，上报 `t1/t2`，秒开 = t2 - t0 < 1000ms。
- 要点：t0 可能缺失（直接打开/推送进入），标注来源（click/push/refresh）分开统计；低端机分档阈值（1500ms）；统计口径在会话去重（同一会话多页面）。
- 边界：本地时间不可信时用容器注入的 monotonic 时钟（performance.timeOrigin 对齐）；秒开率按 version/deviceTier/net 分桶输出。
- 评分点：t0 来源标注与分桶输出。

```javascript

function reportSecondOpen(source) {
  const boot = window.__HYBRID_BOOT ?? {};
  const t0 = boot.clickTs;                                     // Native 点击时间戳(ms)
  const origin = performance.timeOrigin;
  // 首屏可读：首屏关键节点渲染完成（MutationObserver 或业务标记）
  markReadable(() => {
    const t1 = Math.round(performance.timeOrigin + performance.now());
    // 可交互：首屏 JS 绑定完成
    requestIdleCallback?.(() => {}, { timeout: 800 });
    setTimeout(() => {
      const t2 = Math.round(performance.timeOrigin + performance.now());
      navigator.sendBeacon('/collect/second-open', JSON.stringify({
        route: location.pathname, source: t0 ? 'click' : source,   // 来源标注
        totalMs: t0 ? t2 - t0 : null,
        pageMs: t2 - origin,
        deviceTier: navigator.hardwareConcurrency >= 8 ? 'flag' : 'low', // 分桶
        net: navigator.connection?.effectiveType,
        secondOpen: t0 ? (t2 - t0) <= (boot.lowEnd ? 1500 : 1000) : null,
      }));
    }, 0);
  });
}
function markReadable(cb) { /* MutationObserver 首屏节点出现后 cb() */ }
```
