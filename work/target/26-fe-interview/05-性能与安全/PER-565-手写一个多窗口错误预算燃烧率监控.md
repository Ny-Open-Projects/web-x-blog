## PER-565：手写一个多窗口错误预算燃烧率监控器：滑动维护 5m/1h/30m/6h 四个窗口的错误计数并输出告警

**答**：
- 数据结构：错误事件流（时间戳数组或环形桶），四个窗口用固定 1 分钟桶 + 窗口求和实现，避免存全部事件。
- 要点：桶用环形数组按分钟轮转，过期桶清零；总请求量同样按桶维护；燃烧率按 564 的公式算，双条件输出 page/ticket。
- 边界：低流量时段（凌晨）请求基数小，燃烧率会虚高，要加最小样本量门槛（如窗口内 < 500 请求不判 page）。
- 评分点：环形分钟桶结构与低流量门槛。

```javascript

class BurnMonitor {
  constructor(slo = 0.995) {
    this.slo = slo;
    this.buckets = new Map();                             // minuteTs -> {err, total}
  }
  record(ts, isError) {
    const min = Math.floor(ts / 60000) * 60000;
    const b = this.buckets.get(min) ??= { err: 0, total: 0 };
    b.total++; if (isError) b.err++;
    for (const k of this.buckets.keys())                  // 清理 6h 前的桶
      if (ts - k > 6 * 3600 * 1000) this.buckets.delete(k);
  }
  sum(winMin, now) {
    let err = 0, total = 0;
    for (let m = 1; m <= winMin; m++) {
      const b = this.buckets.get((Math.floor(now / 60000) - m) * 60000);
      if (b) { err += b.err; total += b.total; }
    }
    return { err, total, min: winMin };
  }
  br(w, now) {
    const budget = (1 - this.slo) * w.total;
    return budget ? (w.err / budget) / (w.min / 43200) : 0;
  }
  check(now = Date.now()) {
    const fast5 = this.sum(5, now), slow60 = this.sum(60, now),
          fast30 = this.sum(30, now), slow360 = this.sum(360, now);
    if (fast5.total < 500) return { level: 'none', note: '低流量，不判' }; // 最小样本门槛
    if (this.br(fast5, now) > 14.4 && this.br(slow60, now) > 14.4) return { level: 'page' };
    if (this.br(fast30, now) > 6 && this.br(slow360, now) > 6) return { level: 'ticket' };
    return { level: 'ok' };
  }
}
```
