## PER-747：移动端页面栈的内存治理：页面销毁时机、大对象释放清单与 DOM 节点预算

**答**：
- 内存模型：SPA 页面栈每页独立 DOM 树+组件状态，Android WebView 单进程多页共享堆，一个页面泄漏拖垮全站；iOS WKWebView 各自进程但容器整体内存告警联动。
- 治理三层：**栈深度预算**（keep-alive 上限 5 页 + DOM 节点总数 5 万）、**大对象释放清单**（图片位图/大数组/离屏 canvas 按注册释放）、**销毁时机**（路由离开且不在栈内即销毁，销毁前执行清理钩子）。
- 常见泄漏点：页面级定时器/observer 忘清理、闭包引用大对象（fetch 后 response.text() 常驻）、全局事件总线监听未解绑。
- 度量：页面进出循环 N 次的 heap 增长（泄漏检测）、栈内存总量曲线（应随淘汰回落）。

```javascript

const pageStackMemory = {
  budget: { keepAlive: '栈上限 5 页', domNodes: '总节点 < 5 万' },
  releaseList: '图片位图/大数组/离屏 canvas 按注册释放（destroy 时遍历执行）',
  timing: '路由离开且不在栈内即销毁，销毁前跑清理钩子',
  leakProne: ['页面定时器/observer 未清', '闭包引用大响应体', '全局事件总线未解绑'],
  metrics: ['页面循环 N 次 heap 增长', '栈内存总量随淘汰回落'],
};
class PageMemoryGuard {
  constructor() { this.releasables = new Map(); }
  register(pageKey, name, freeFn) {                             // 页面注册可释放资源
    const list = this.releasables.get(pageKey) ?? [];
    list.push({ name, freeFn });
    this.releasables.set(pageKey, list);
  }
  destroyPage(pageKey) {
    for (const { name, freeFn } of this.releasables.get(pageKey) ?? []) {
      try { freeFn(); } catch (e) { warn(`释放失败 ${pageKey}/${name}`, e); }
    }
    this.releasables.delete(pageKey);
  }
}
// 用法：guard.register('/detail', 'big-image-bitmaps', () => imgCache.release())
```
