## PER-683：手写一个弱网自适应请求器：按网络档位动态调整并发、超时与图片档位，网络突变时平滑切换

**答**：
- 核心：网络档位状态机（fast/mid/weak/offline），信号源 connection 事件 + 主动探速；请求器读当前档位决定并发上限与超时；图片组件读档位选 URL 档。
- 要点：档位切换要平滑（在途请求不动，新请求按新档位）；探速要便宜（HEAD 小图或复用业务请求耗时）；offline 档直接走缓存队列。
- 边界：connection API 不可用时降级为实测错误率推断档位；档位抖动（临界值来回切）要加滞回（切换需连续 2 次同判）。
- 评分点：滞回防抖与在途请求不动。

```javascript

class AdaptiveRequester {
  constructor() {
    this.tier = 'mid'; this.inflight = 0;
    this.cfg = { fast: { conc: 8, timeout: 8000, img: 'hd' },
      mid: { conc: 6, timeout: 10000, img: 'sd' },
      weak: { conc: 2, timeout: 15000, img: 'ld' },
      offline: { conc: 0, timeout: 0, img: 'placeholder' } };
    navigator.connection?.addEventListener('change', () => this.retier());
    this.retier(); this.watch();
  }
  retier() {                                                    // 连续同判才切换（滞回）
    const t = tierFromConnection();
    this.candidate = this.candidate === t ? t : (this.pendingTier = t, null);
    if (this.candidate) this.tier = this.candidate;
  }
  watch() {                                                     // 错误率兜底推断
    let errs = 0, total = 0;
    setInterval(() => {
      if (total > 10 && errs / total > 0.3) this.tier = 'weak'; // 实测错误率推断
      errs = total = 0;
    }, 30000);
  }
  async fetch(url, opts) {
    const c = this.cfg[this.tier];
    if (c.conc === 0) return cacheGet(url);                     // offline 走缓存
    while (this.inflight >= c.conc) await waitSlot();           // 并发上限
    this.inflight++;
    try {
      return await withTimeout(fetch(url, opts), c.timeout);
    } finally { this.inflight--; }
  }
}
// 图片组件读 cfg.img 选 hd/sd/ld URL；档位切换只影响新请求，在途不动
```
