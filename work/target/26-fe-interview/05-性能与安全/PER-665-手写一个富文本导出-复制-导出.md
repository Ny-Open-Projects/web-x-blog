## PER-665：手写一个富文本导出（复制/导出 Word）链路的净化器：剪贴板 HTML 净化与复制劫持防护

**答**：
- 剪贴板是双向攻击面：**粘贴进富文本编辑器**的 HTML 可能带 script/on*（paste 事件拦截 + 净化）；**复制劫持**（恶意脚本改写 copy 事件把剪贴板换成钓鱼文本）。
- 实现：paste 监听 `event.clipboardData.getData('text/html')` -> 净化 -> `preventDefault` + 插入净化版；copy 监听做完整性水印"（复制内容带溯源标记），并阻止第三方改写（记录复制内容 hash，粘贴时校验——应用内自校验）。
- 边界：图片粘贴（截图上传场景）要走文件处理；纯文本模式（shift粘贴）保留；净化规则与富文本编辑器白名单一致。
- 评分点：paste 拦截净化与 copy 篡改校验。

```javascript

const ALLOWED = new Set(['P', 'B', 'I', 'STRONG', 'A', 'UL', 'LI', 'SPAN']);
function installClipboardGuard(editor) {
  editor.addEventListener('paste', (e) => {
    e.preventDefault();                                          // 阻断原始 HTML 注入
    const html = e.clipboardData.getData('text/html');
    const text = e.clipboardData.getData('text/plain');
    if (html) {
      const doc = new DOMParser().parseFromString(html, 'text/html');
      doc.querySelectorAll('*').forEach(el => {
        if (!ALLOWED.has(el.tagName)) return el.replaceWith(...el.childNodes); // 剥壳保文
        [...el.attributes].forEach(a => el.removeAttribute(a.name));  // 属性全剥
      });
      insertPasted(editor, doc.body.innerHTML);                  // 净化后插入
    } else insertPasted(editor, escapeHtml(text));
  });
  let lastCopyHash = null;
  editor.addEventListener('copy', () => {
    lastCopyHash = hash(editor.innerText);                       // 复制内容指纹
  });
  editor.addEventListener('paste', (e) => {                      // 粘贴时校验是否被改写
    if (lastCopyHash && hash(e.clipboardData.getData('text/plain')) !== lastCopyHash) {
      report('clipboard-tampered');                              // copy 劫持嫌疑
    }
  });
}
```
