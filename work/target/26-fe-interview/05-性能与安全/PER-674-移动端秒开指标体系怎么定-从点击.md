## PER-674：移动端秒开指标体系怎么定？从点击到可用的全链路分解与各段预算

**答**：
- 秒开定义：从用户点击到首屏内容可读且可交互，全链路分段：**点击->容器启动**（webview/小程序初始化 200~400ms）、**容器->页面首字节**（路由+离线包命中，目标 50ms）、**首字节->首屏渲染**（接口+渲染 500ms）、**渲染->可交互**（JS 执行，目标 200ms）。
- 预算分配原则：给每段设独立预算（加起来 < 1s），单段超标单独治理；总预算不能用平均，分档位（低端机 < 1.5s）。
- 采集口径：客户端埋点为主（点击时间戳由 Native 记，页面无法感知点击前的时间），页面内埋点做细分段，两端用 traceId 关联。
- 秒开率 = 秒开会话/总会话（分容器版本、设备档、网络），优化目标挂在秒开率而不是平均耗时——对齐体验分布。

```javascript

const secondOpenBudget = {
  stages: [
    { name: '点击->容器启动', budget: 300, owner: '客户端', metric: 'native-elapsed' },
    { name: '容器->首字节', budget: 100, owner: '前端+离线包', metric: 'ttfb-local' },
    { name: '首字节->首屏渲染', budget: 500, owner: '前端', metric: 'fcp-local' },
    { name: '渲染->可交互', budget: 200, owner: '前端', metric: 'tti-local' },
  ],
  total: { budget: 1000, lowEnd: 1500 },
  define: '秒开 = 全链路 < 1s 且首屏可交互，客户端埋点为基准口径',
  breakdown: 'traceId 关联 Native 点击时间戳与页面分段埋点',
};
console.log(secondOpenBudget.define);
```
