## PER-806：手写一个小程序列表节点回收器：可视区加缓冲区渲染、回收复用与占位高度

**答**：
- 需求：给定总行数 N、行高 H、视口高 VH、缓冲行数 B，实现滚动处理器：输出 {start, end, topPad, bottomPad, reuseNodes}，其中回收节点（上一区间有、新区间没有的索引）返回给调用方复用；新增节点从复用池取，池空才新建。
- 边界：start/end 越界裁剪；快速滚动跨度大时（区间完全错开）仍正确计算复用集；repeat 滚动（来回小幅）无节点新建。
- 评分点：区间错开时的复用正确性；占位高度不为负；新建节点最少化。

```javascript
function makeRecycler(N, H, VH, B = 5) {
  let prev = { start: 0, end: 0 };
  const pool = [];
  return function onScroll(scrollTop) {
    const start = Math.max(0, Math.floor(scrollTop / H) - B);
    const end = Math.min(N, Math.ceil((scrollTop + VH) / H) + B);
    const cur = new Set();
    for (let i = start; i < end; i++) cur.add(i);            // 当前区间索引集
    const reuseNodes = [], fresh = [];
    for (const i of cur) {
      if (i >= prev.start && i < prev.end) continue;         // 已渲染：复用
      pool.length ? reuseNodes.push({ idx: i, node: pool.pop() })
                  : fresh.push({ idx: i, node: null });      // 池空：新建
    }
    for (let i = prev.start; i < prev.end; i++)              // 离场：入池
      if (!cur.has(i)) pool.push({ idx: i });
    prev = { start, end };
    return { start, end,
      topPad: start * H,
      bottomPad: Math.max(0, (N - end) * H),
      reuseNodes, freshCount: fresh.length };
  };
}
```
