## PER-1150：差分隐私在前端数据统计的入门实践

**答**：
- 思想：查询结果加噪声，使单条数据的存在与否不显著影响结果，ε 越小隐私越强噪声越大。
- 适用：统计报表对外发布（DAU 分桶/转化率），个体明细永不外发。
- 实现：拉普拉斯机制（计数查询加 Laplace(1/ε) 噪声）；聚合在服务端做，前端只提交个体事件。
- 权衡：业务可用性 vs 隐私预算——总量预算按天分配，超预算拒绝查询。

```javascript
// 拉普拉斯机制
function laplaceNoise(sensitivity, epsilon) {
  const scale = sensitivity / epsilon;
  const u = Math.random() - 0.5;
  return -scale * Math.sign(u) * Math.log(1 - 2 * Math.abs(u));
}
function privateCount(trueCount, epsilon = 1) {
  return Math.max(0, Math.round(trueCount + laplaceNoise(1, epsilon)));
}
// 预算管理：
function budgetGuard(spent, daily = 10) {
  return { remaining: +(daily - spent).toFixed(2),
    allow: spent < daily };   // 超预算 -> 拒绝查询并返回缓存结果
}
```
