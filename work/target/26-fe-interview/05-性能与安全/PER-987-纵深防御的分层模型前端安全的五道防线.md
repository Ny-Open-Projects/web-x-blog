## PER-987：纵深防御的分层模型：前端安全的五道防线怎么布置

**答**：
- 第一道：输入侧治理——信任边界划分，所有外部输入（URL/表单/三方回调）默认不可信。
- 第二道：输出编码——框架默认转义 + 危险 API 白名单（innerHTML/v-html 审批制）。
- 第三道：浏览器策略——CSP（nonce + strict-dynamic）、Trusted Types、Cookie 隔离（SameSite/HttpOnly/Secure）。
- 第四道：供应链——依赖锁定 + SRI + 私有镜像 + 变更审计。
- 第五道：监控响应——异常上报（XSS 探针/CSP violation report）+ 应急下线能力。

```javascript
<!-- 纵深防御配置示例 -->
<meta http-equiv="Content-Security-Policy"
  content="script-src 'nonce-xyz' 'strict-dynamic'; object-src 'none'; report-uri /csp-log">
<meta http-equiv="Content-Security-Policy-Report-Only"
  content="require-trusted-types-for 'script'; report-uri /tt-log">
<script>
// Trusted Types：禁止裸 innerHTML，强制经过策略
const policy = trustedTypes?.createPolicy('app', {
  createHTML: s => DOMPurify.sanitize(s),   // 唯一出口
});
function safeHTML(s) { return policy?.createHTML(s) ?? DOMPurify.sanitize(s); }
el.innerHTML = safeHTML(userInput);
</script>
```
