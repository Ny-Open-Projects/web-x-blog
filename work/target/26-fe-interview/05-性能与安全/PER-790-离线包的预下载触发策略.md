## PER-790：离线包的预下载触发策略：WiFi 条件、使用频次与空闲时段的下载决策模型

**答**：
- 盲发全量包浪费流量与电量，决策模型三输入：网络条件（WiFi/蜂窝/弱网）、使用频次（高频用户先发）、时段（夜间/空闲）。
- 策略矩阵：WiFi + 高频 → 全量包立即下；WiFi + 低频 → 下次启动 idle 下；蜂窝 → 只下差量包且给用户确认或静默限额；弱网 → 不下，等网络恢复。
- 频次画像：连续 N 天访问某业务才预装对应业务包，新用户只装基础包（防"装了一堆用不上的包"占配额）。
- 度量：预下载命中率（下载后 7 天内实际使用占比）、流量成本、下载失败重试成本。

```javascript
const downloadPolicy = {
  decision(net, freq, quota) {
    if (net === 'offline' || net === 'slow-2g') return { action: 'skip' };
    if (net === 'wifi') {
      if (freq.days7 >= 3) return { action: 'full', when: 'now' };          // 高频全量
      return { action: 'full', when: 'idle' };                              // 低频空闲
    }
    // 蜂窝：仅差量 + 静默限额（quota 内静默，超出提示用户）
    if (freq.days7 >= 3) return { action: 'patch', when: 'idle', silent: quota.patchMb < 2 };
    return { action: 'skip' };
  },
};
// 频次画像：连续访问才预装业务包
function shouldPreloadBiz(bizId, visits) {
  return visits.filter(d => d.biz === bizId).length >= 3;   // 7天内访问≥3次
}
```
