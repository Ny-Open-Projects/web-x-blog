## PER-553：性能测试怎么做用户分布仿真？固定档位跑分和按真实分布随机采样各有什么用？

**答**：
- 固定档位跑分（Moto G4 + Fast 3G）的价值是**可比与门禁**——每次环境一致才能判回归；分布仿真的价值是**估算整体体验**——回答"我的用户平均体验如何"这类总量问题。
- 分布仿真做法：从 RUM 拿设备/网络联合分布，压测时按分布随机抽档位跑样本，加权聚合出"全站加权 p75"；权重用会话占比而不是 UV（不同机型会话时长差异大）。
- 两者配合：门禁用固定档（防噪声），季度体检用分布仿真（找最差用户群体），分布仿真发现的"最差分群"反过来固化成新的固定档位进门禁。
- 追问钩子：为什么不直接看 RUM 的真实 p75 就够了？——RUM 是现状，仿真可以做 what-if（如果这批用户升了 5G/换机，体验会怎样），指导决策。

```javascript

// 用户分布仿真：按 RUM 联合分布抽档位，加权聚合
const dist = [ // 来自 RUM：设备档 × 网络 联合分布
  { profile: 'mid/3g',   share: 0.35, lcpP75: 2600 },
  { profile: 'mid/4g',   share: 0.30, lcpP75: 2100 },
  { profile: 'flag/4g',  share: 0.20, lcpP75: 1400 },
  { profile: 'low/3g',   share: 0.15, lcpP75: 4100 },
];
function weightedP75(dist) {
  const flat = dist.flatMap(d => Array(Math.round(d.share * 1000)).fill(d.lcpP75));
  flat.sort((a, b) => a - b);
  return flat[Math.floor(flat.length * 0.75)];           // 按会话占比加权
}
console.log('全站加权 LCP p75:', weightedP75(dist), 'ms');
// 最低档 low/3g 占 15% 却贡献最大恶化 -> 固化成新门禁档位
```
