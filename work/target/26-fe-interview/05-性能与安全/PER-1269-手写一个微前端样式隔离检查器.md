## PER-1269：手写一个微前端样式隔离检查器

**答**：
- 需求：实现 styleIsolationCheck(apps)。apps 为 [{ name, styles: [cssText] }]；检查：全局选择器（body/*/html 开头）跨应用冲突数；!important 使用次数（> 10 告警）；@import 外链（应打包）；输出 { conflicts: [{ selector, apps }], importantAbuse, externalImports, pass }。
- 边界：shadow DOM 应用（标记 isolated: true）跳过检查；空 styles 应用跳过；冲突按 selector 聚合。
- 评分点：全局选择器冲突；important 统计；import 检测；隔离跳过

```javascript
function styleIsolationCheck(apps) {
  const globalMap = {}; let importantAbuse = 0;
  const externalImports = [];
  for (const app of apps) {
    if (app.isolated || !app.styles.length) continue;
    for (const css of app.styles) {
      importantAbuse += (css.match(/!important/g) ?? []).length;
      if (/@import\s+url\(/.test(css))
        externalImports.push({ app: app.name });
      for (const m of css.matchAll(/(^|})\s*(body|html|\*)\s*[{,]/g))
        (globalMap[m[2]] ??= new Set()).add(app.name);
    }
  }
  const conflicts = Object.entries(globalMap)
    .filter(([, set]) => set.size > 1)
    .map(([selector, set]) => ({ selector, apps: [...set] }));
  return { conflicts, importantAbuse, externalImports,
    pass: !conflicts.length && importantAbuse <= 10 && !externalImports.length };
}
```
