## PER-959：手写一个棘轮阈值控制器：基线改善自动收紧

**答**：
- 需求：实现 Ratchet 类：update(value) 记录最近 N 个周期值；threshold() 返回当前门禁阈值 = max(SLO, 最近中位数 × tighten)；只有最近 N 个值全部 <= 当前阈值（基线确已改善）才下调阈值至 max(SLO, 中位数 × tighten)，否则保持。输出调整历史。
- 边界：N 未满时返回初始阈值 = max(SLO, 首值 × tighten)；value 非法忽略；SLO 可为 null（则无下限）。
- 评分点：中位数阈值；改善确认条件；历史日志；SLO 下限

```javascript
class Ratchet {
  constructor(slo, { n = 5, tighten = 1.05 } = {}) {
    this.slo = slo; this.n = n; this.tighten = tighten;
    this.hist = []; this.cur = null; this.log = [];
  }
  update(v) {
    if (!Number.isFinite(v)) return;
    this.hist.push(v); if (this.hist.length > this.n) this.hist.shift();
    if (!this.hist.length) return;
    if (this.cur === null) {
      const med = median(this.hist);
      this.cur = this.slo === null ? med * this.tighten : Math.max(this.slo, med * this.tighten);
      this.log.push({ set: +this.cur.toFixed(1), reason: 'init' });
      return;
    }
    if (this.hist.length === this.n && this.hist.every(h => h <= this.cur)) {
      const med = median(this.hist);
      const next = this.slo === null ? med * this.tighten : Math.max(this.slo, med * this.tighten);
      if (next < this.cur) {
        this.cur = next;
        this.log.push({ set: +this.cur.toFixed(1), reason: 'tighten' });
      }
    }
  }
  threshold() { return this.cur; }
}
function median(a) { const s = [...a].sort((x, y) => x - y);
  return s.length % 2 ? s[(s.length - 1) >> 1] : (s[s.length / 2 - 1] + s[s.length / 2]) / 2; }
```
