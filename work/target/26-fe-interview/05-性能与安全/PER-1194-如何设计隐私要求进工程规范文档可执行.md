## PER-1194：如何设计"隐私要求"进工程规范文档（可执行版）

**答**：
- 文档形态：不是合规长文，而是"开发规则 20 条"（每条可执行可检查）+ 场景速查表。
- 条目示例：所有上报必须走 SDK 统一出口 / 禁止 localStorage 存手机号 / 敏感接口必须掩码展示 / 新 SDK 必须先过隐私评审。
- 落地方式：规则转 lint/CI/评审 checklist，文档只是规则的"为什么"。
- 维护：规则与代码同步（规则编号被 lint 引用），季度评审规则有效性。

```javascript
// 规则 20 条（节选）与自动检查映射
const RULES = {
  'R01': { text: '上报必须走 track() 统一出口', check: 'lint no-direct-beacon' },
  'R05': { text: '禁止 localStorage 存 S3+ 字段', check: 'lint no-sensitive-storage' },
  'R09': { text: '敏感数据展示必须掩码', check: 'review checklist' },
  'R14': { text: '新 SDK 上线前必须过隐私评审', check: 'CI vendor-gate' },
};
function ruleIndex() {
  return Object.entries(RULES).map(([id, r]) =>
    ({ id, automated: r.check.startsWith('lint') || r.check.startsWith('CI') }));
}
// 自动化覆盖率目标 > 70%
```
