## PER-582：手写一个告警升级与值班轮转调度器：按轮值表派发告警，超时未认领自动升级

**答**：
- 调度核心：告警进来 -> 查当前值班人 -> 推送并开始计时 -> 超时（如 5 分钟）未 ack 通知下一级（同班次备份人）-> 再超时升级到负责人；节假日与调班支持 override。
- 要点：ack 状态要有唯一性（一人 ack 全员静默）；升级链要可配置（primary -> backup -> manager）；值班表按周期轮转（每周一 10 点切换）。
- 边界：同一指纹告警在升级中不重复派发（合并）；值班人请假要先调表才能生效。
- 评分点：ack 唯一性与升级链。

```javascript

class OnCallScheduler {
  constructor(rota, { ackTimeoutMs = 5 * 60 * 1000 } = {}) {
    this.rota = rota;                       // [{primary, backup, manager, until}]
    this.ackTimeoutMs = ackTimeoutMs;
    this.pending = new Map();               // fp -> timer
  }
  current() {
    const now = Date.now();
    return this.rota.find(r => r.until > now) ?? this.rota.at(-1);
  }
  dispatch(alert) {
    const fp = alert.fp;
    if (this.pending.has(fp)) return;       // 升级中不重复派发
    const chain = [this.current().primary, this.current().backup, this.current().manager];
    let i = 0;
    const notify = () => {
      const person = chain[i];
      notify(person, alert);                // 推送 IM/电话
      const timer = setTimeout(() => {
        this.pending.delete(fp);
        if (++i < chain.length) notify();   // 超时未 ack -> 升级下一级
        else escalateToManager(alert);
      }, this.ackTimeoutMs);
      this.pending.set(fp, timer);
    };
    this.onAck = (fp2) => {                 // 一人 ack -> 全链静默
      if (fp2 === fp && this.pending.has(fp)) {
        clearTimeout(this.pending.get(fp)); this.pending.delete(fp);
      }
    };
    notify();
  }
}
```
