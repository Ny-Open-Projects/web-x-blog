## PER-859：首屏接口的聚合与拆分决策：一个大接口与多个小接口在移动端的取舍

**答**：
- 大接口优势：一次 RTT、一次鉴权、前端编排简单；劣势：任一子数据慢拖垮整体、缓存粒度粗、后端耦合高。
- 多小接口优势：独立缓存（命中高的先出）、并行请求、失败隔离（一个失败不阻塞首屏）；劣势：RTT 串行风险（依赖链）、连接数压力（HTTP/1.1 队头）。
- 决策依据：数据依赖关系（强依赖聚合，无依赖拆分并行）、缓存特征（热点数据拆出来吃缓存）、失败容忍度（核心数据与可降级数据分离）、网络代际（HTTP/2 多路复用降低拆分成本）。
- 移动端实践：首屏 2~3 个接口为宜——1 个聚合主接口（关键路径）+ 0~2 个并行次接口（可降级）；超 5 个并发小请求在弱网下 RTT 浪费明显，应合批。

```javascript
function decideAggregation(deps) {             // deps: [{api, cacheHitRate, critical, dependsOn}]
  const critical = deps.filter(d => d.critical);
  const clusters = [];                          // 依赖聚类：强依赖归一组
  for (const d of deps) {
    if (!d.dependsOn) clusters.push([d]);
    else findCluster(clusters, d.dependsOn)?.push(d) ?? clusters.push([d]);
  }
  const mergeHot = clusters.filter(c =>         // 高缓存命中簇独立拆出
    c.every(d => d.cacheHitRate > 0.5));
  return {
    main: clusters.filter(c => !mergeHot.includes(c)).flat(),   // 关键路径聚合
    parallel: mergeHot.flat(),                                  // 可缓存数据并行
    rationale: '关键路径聚合省 RTT；高命中数据拆出吃缓存；失败可降级',
  };
}
function findCluster(clusters, id) {
  return clusters.find(c => c.some(d => d.api === id || d.dependsOn === id));
}
```
