## PER-702：手写一个内存告警响应执行器：按分级清单依次执行降级动作，带防重复与效果回收统计

**答**：
- 在 701 基础上完整实现：模块注册 `registerReleasable(name, freeFn)`；告警按级执行，执行结果统计（耗时/是否成功/内存变化估计）；告警恢复（内存回落）时可选恢复部分降级。
- 要点：动作要幂等且可失败（try/catch 隔离，单个动作失败不阻断后续）；执行耗时记录（告警处理本身不能卡主线程 > 50ms，重动作放 idle）；内存变化用 `performance.memory` 前后采样对比。
- 边界：连续告警（短时间内多次）要合并处理（同一轮只执行一次清单）；动作清单按设备档裁剪（低端更多动作）。
- 评分点：失败隔离与效果统计。

```javascript

class MemoryResponseExecutor {
  constructor() { this.registry = new Map(); this.lastRun = 0; }
  register(name, freeFn, tier = 'all') { this.registry.set(name, { freeFn, tier }); }
  async onAlarm(level) {
    if (Date.now() - this.lastRun < 5000) return;               // 连续告警合并
    this.lastRun = Date.now();
    const before = memoryNow();
    const tier = window.__deviceTier ?? 'mid';
    const plan = { 1: ['image-cache', 'route-state'],
      2: ['animation', 'image-tier', 'list-window'],
      3: ['big-objects', 'save-reload'] }[level] ?? [];
    const results = [];
    for (const name of plan) {
      const reg = this.registry.get(name);
      if (!reg || (reg.tier !== 'all' && reg.tier !== tier)) continue;
      const t0 = performance.now();
      try {
        await new Promise(r => (window.requestIdleCallback ?? setTimeout)(() => {
          reg.freeFn(); r();
        }, { timeout: 100 }));                                  // 重动作放 idle
        results.push({ name, ok: true, ms: +(performance.now() - t0).toFixed(1) });
      } catch (e) {
        results.push({ name, ok: false, err: e.message });      // 失败隔离
      }
    }
    setTimeout(() => {
      const after = memoryNow();
      track('mem-alarm-result', { level, before, after,
        freedMB: +(before - after).toFixed(1), results });       // 效果统计
    }, 3000);
  }
}
function memoryNow() { return performance.memory ? performance.memory.usedJSHeapSize / 1048576 : 0; }
```
