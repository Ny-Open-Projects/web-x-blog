## PER-1106：如何验证前端"修复"真的修好了（安全回归测试）

**答**：
- 每修复配回归用例：XSS 修复配注入 payload 集（OWASP cheat sheet）自动化验证；权限修复配越权用例矩阵。
- CI 集成：安全用例与功能用例同池跑，修复不回归才允许关闭漏洞单。
- 渗透验证：重大修复安排红队/外部渗透复测。
- 知识沉淀：漏洞单模板关联复现步骤与用例代码，同类问题扫描全局。

```javascript
// XSS 回归用例集
const PAYLOADS = [
  '<img src=x onerror=alert(1)>', '<svg onload=alert(1)>',
  '"><script>alert(1)</script>', 'javascript:alert(1)',
  '<a href="javascript:alert(1)">x</a>', '{{7*7}}',
];
function xssRegression(render) {
  return PAYLOADS.map(p => {
    render(p);
    const leaked = document.body.innerHTML.includes('onerror=alert') ||
      document.querySelector('[onclick],svg[onload]');
    return { payload: p.slice(0, 30), pass: !leaked };
  });
}
// 全 pass 才能关闭对应漏洞单
```
