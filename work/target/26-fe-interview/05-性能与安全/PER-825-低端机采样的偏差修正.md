## PER-825：低端机采样的偏差修正：低配用户上报率低导致的指标偏差与修正方法

**答**：
- 偏差来源：低端机用户上报成功率低（页面崩溃/上报失败/弱网丢弃），导致大盘指标偏乐观——劣化最严重的用户恰好没进样本。
- 识别方法：按设备档对比上报样本量占比 vs 真实 DAU 占比（来自业务侧统计），占比差即为采样偏差；或对比"进入页面数"与"完成上报数"的漏斗差。
- 修正方法：分层加权（post-stratification）——按设备档分别计算指标，再按真实档位分布加权汇总，而不是用上报样本的自然分布。
- 配套动作：修正只是统计补救，根因治理是提高低端机上报可靠性（批量重试、落盘补传、指标本地聚合）。

```javascript
function correctBias(samples, trueDist) {    // trueDist: {low:0.4, mid:0.35, high:0.25}
  const byTier = {};
  for (const s of samples) (byTier[s.tier] ??= []).push(s.metric);
  const sampleDist = {}, weighted = [];
  let total = 0;
  for (const t of Object.keys(trueDist)) {
    sampleDist[t] = (byTier[t]?.length || 0);
    total += sampleDist[t];
  }
  for (const [tier, trueRatio] of Object.entries(trueDist)) {
    const arr = byTier[tier] || [];
    const sampleRatio = total ? sampleDist[tier] / total : 0;
    const w = sampleRatio > 0 ? trueRatio / sampleRatio : 0;   // 权重 = 真实占比/样本占比
    arr.forEach(v => weighted.push({ v, w }));
  }
  const sumW = weighted.reduce((s, x) => s + x.w, 0);
  return {
    correctedMean: weighted.reduce((s, x) => s + x.v * x.w, 0) / sumW,
    rawMean: samples.reduce((s, x) => s + x.metric, 0) / samples.length,
    bias: Object.fromEntries(Object.keys(trueDist)
      .map(t => [t, total ? +(sampleDist[t] / total - trueDist[t]).toFixed(3) : null])),  // 偏差诊断
  };
}
```
