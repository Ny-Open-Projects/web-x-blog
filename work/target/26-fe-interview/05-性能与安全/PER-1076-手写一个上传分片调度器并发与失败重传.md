## PER-1076：手写一个上传分片调度器：并发与失败重传

**答**：
- 需求：实现 uploadChunks(file, uploadFn, { chunkSize=5MB, concurrency=3, retries=2 })。按分片并发上传（uploadFn(idx, blob) 返回 Promise）；单片失败最多重试 retries 次（每次换 delay 200ms）；onProgress(sent, total)；任一分片超重试上限整体 reject 但已完成分片保留在已传集合中（支持续传）。
- 边界：文件大小 0 直接 resolve；concurrency 超过总分片数按实际；进度按已成功分片计数。
- 评分点：worker 池模式；单片重试；失败携带已完成集合；进度语义

```javascript
async function uploadChunks(file, uploadFn,
    { chunkSize = 5 * 1024 * 1024, concurrency = 3, retries = 2, onProgress } = {}) {
  const total = Math.ceil(file.size / chunkSize);
  if (!total) return { done: 0, total: 0 };
  const done = new Set();
  let cursor = 0;
  async function worker() {
    while (cursor < total) {
      const idx = cursor++;
      const blob = file.slice(idx * chunkSize, (idx + 1) * chunkSize);
      let ok = false;
      for (let a = 0; a <= retries && !ok; a++) {
        try { await uploadFn(idx, blob); ok = true; }
        catch (e) {
          if (a === retries) throw Object.assign(e, { idx, done: [...done] });
          await new Promise(r => setTimeout(r, 200 * (a + 1)));
        }
      }
      done.add(idx);
      onProgress?.(done.size, total);
    }
  }
  await Promise.all(
    Array.from({ length: Math.min(concurrency, total) }, worker));
  return { done: done.size, total };
}
```
