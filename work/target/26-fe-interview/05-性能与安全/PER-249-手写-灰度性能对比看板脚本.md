## PER-249：手写灰度性能对比——按实验分组聚合 p75 并做显著性方向判断

**题目**：实现 `compareGroups(rows, metric)`：① rows 含 `{ exp: 'A'|'B', lcp }` 等字段；② 对指定 metric 分别计算 A/B 组 p75、样本数；③ 输出 `{ A, B, delta, better, significant }`；④ significant 判定用简化 bootstrap：重采样 200 次，统计 p75(B) > p75(A) 的比例，比例 > 0.95 或 < 0.05 才算显著；⑤ 样本数 < 100 的组直接返回 insufficient。

**答**：性能灰度对比的关键难点：性能分布长尾、方差大，直接比 p75 差值会被抖动骗。Bootstrap 重采样是轻量可行的显著性检验（不必上 t 检验——性能数据非正态）。

```javascript
function p75(arr) {
  const s = [...arr].sort((a, b) => a - b);
  const idx = (s.length - 1) * 0.75, lo = Math.floor(idx), hi = Math.ceil(idx);
  return s[lo] + (s[hi] - s[lo]) * (idx - lo);
}
function bootstrapP75Significant(a, b, times = 200) {
  let bWins = 0;
  for (let t = 0; t < times; t++) {
    const sa = Array.from({ length: a.length }, () => a[(Math.random() * a.length) | 0]);
    const sb = Array.from({ length: b.length }, () => b[(Math.random() * b.length) | 0]);
    if (p75(sb) > p75(sa)) bWins++;
  }
  return bWins / times;      // 比例趋近 1 => B 稳定更差；趋近 0 => B 稳定更好
}
function compareGroups(rows, metric = 'lcp') {
  const g = { A: [], B: [] };
  for (const r of rows) g[r.exp]?.push(r[metric]);
  if (g.A.length < 100 || g.B.length < 100) return { insufficient: true, samples: [g.A.length, g.B.length] };
  const pa = p75(g.A), pb = p75(g.B);
  const ratio = bootstrapP75Significant(g.A, g.B);
  return {
    A: +pa.toFixed(1), B: +pb.toFixed(1),
    delta: +(pb - pa).toFixed(1),
    better: pb > pa ? 'A' : 'B',
    significant: ratio > 0.95 || ratio < 0.05,
    bWinsRatio: +ratio.toFixed(3),
  };
}
```

**评分点**：
- 分组 p75 用线性插值；小样本（<100）保护返回 insufficient。
- bootstrap 实现正确：有放回重采样、200 次以上、统计 p75(B)>p75(A) 的比例。
- 显著性判定阈值合理（0.05/0.95），并能说明为什么性能数据不用 t 检验。
- delta 方向语义明确（better 标到组上，不是裸数字）。
