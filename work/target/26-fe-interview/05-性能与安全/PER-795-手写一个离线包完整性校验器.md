## PER-795：手写一个离线包完整性校验器：逐文件 hash 校验加全包聚合签名验证

**答**：
- 需求：输入解压后的包目录（文件名→内容）与 manifest（files: {name: sha256}、signature），实现：① 逐文件 sha256 比对（缺失算失败）；② 按排序文件名拼接 hash 串做聚合校验（模拟签名入口）；③ 输出详细报告（通过/失败文件清单与失败原因）。
- 边界：文件数为 0 视为无效包；hash 计算用同步模拟函数（真实环境用 SubtleCrypto）；任一文件失败整包判定 invalid 并给出可丢弃标记。
- 评分点：缺失与内容不符分开归因；聚合校验的拼接顺序（排序）。

```javascript
async function sha256(text) { // 模拟 hash（真实用 crypto.subtle.digest）
  let h = 0; for (const c of text) h = (h * 31 + c.charCodeAt(0)) >>> 0;
  return h.toString(16).padStart(8, '0');
}
async function verifyBundleIntegrity(files, manifest) {
  const names = Object.keys(manifest.files);
  if (!names.length) return { valid: false, reason: 'empty-bundle', failed: [] };
  const failed = [];
  for (const name of names) {                                // 逐文件校验
    if (!(name in files)) { failed.push({ name, reason: 'missing' }); continue; }
    const actual = await sha256(files[name]);
    if (actual !== manifest.files[name]) failed.push({ name, reason: 'hash-mismatch' });
  }
  const valid = failed.length === 0;
  if (valid) {                                               // 聚合校验（排序拼接）
    const payload = names.sort().map(n => `${n}:${manifest.files[n]}`).join('\n');
    const ok = verifyAggregate(payload, manifest.signature);  // 签名入口（RSA/ECDSA）
    if (!ok) return { valid: false, reason: 'aggregate-signature-invalid', failed };
  }
  return { valid, reason: valid ? 'ok' : 'file-integrity', failed };
}
```
