## PER-875：移动端 H5 与容器容灾：容器崩溃、白屏的前端自检与自动恢复方案

**答**：
- 容灾分层：前端自检（关键节点存在性+渲染探针）→ 页面级恢复（重载数据/刷新组件）→ 容器级恢复（reload WebView）→ 引导用户（兜底文案+重试按钮）。级别越低代价越小。
- 自检设计：首屏关键元素选择器清单（可配置），页面加载超时（如 3s）后逐项检查；渲染探针用 getBoundingClientRect 判断真实可见（防 display:none 假象）。
- 自动恢复要防循环：恢复动作记录次数（同一路由最多 2 次），超过后停止自动恢复转人工提示，并上报高优先级告警（带黑匣子）。
- 容器侧协同：与容器约定"重载降级参数"（如 ?recovered=1），恢复后加载走简化版，避免再次触发同样问题死循环。

```javascript
class RecoveryGuard {
  constructor({ selectors, timeout = 3000, maxRetry = 2 } = {}) {
    this.sels = selectors; this.timeout = timeout; this.max = maxRetry;
    this.retries = 0;
  }
  arm() {
    setTimeout(() => this.check(), this.timeout);              // 超时自检
  }
  check() {
    const missing = this.sels.filter(sel => {
      const el = document.querySelector(sel);
      return !el || el.getBoundingClientRect().width === 0;    // 渲染探针：可见才算
    });
    if (!missing.length) return { ok: true };
    if (++this.retries > this.max) {                           // 防循环
      report('recovery-exhausted', { missing, blackbox: window.__bb?.snapshot?.() });
      showFallbackUI();
      return { ok: false, action: 'manual' };
    }
    report('white-screen-auto-recover', { attempt: this.retries, missing });
    if (this.retries === 1) retryData();                       // 一级：重载数据
    else location.href += (location.search ? '&' : '?') + 'recovered=1';   // 二级：简化版重载
    return { ok: false, action: this.retries };
  }
}
```
