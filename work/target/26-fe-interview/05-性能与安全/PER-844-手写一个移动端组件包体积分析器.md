## PER-844：手写一个移动端组件包体积分析器：按组件粒度统计 JS 与 CSS 体积与依赖引用

**答**：
- 需求：输入构建产物清单 [{module, sizeKB, type: js|css, deps: [module]}]，统计：每个组件（module）自身体积与含依赖的累计体积；找出被重复打包的模块（多个组件共同依赖且未抽公共 chunk）；输出按累计体积降序的组件报告与公共依赖抽取建议（被 >= 3 个组件依赖且累计 > 30KB）。
- 边界：依赖环检测（防无限递归）；type 为 css 的依赖单独归类；重复打包判定以"未标记为 common"为准。
- 评分点：递归累计含环检测；公共依赖建议条件；css/js 分列。

```javascript
function componentSizeReport(modules, { commonTh = 3, commonKB = 30 } = {}) {
  const byId = new Map(modules.map(m => [m.module, m]));
  const totalOf = (id, seen = new Set(), type = 'all') => {
    if (seen.has(id)) return 0;                                // 环检测
    seen.add(id);
    const m = byId.get(id);
    if (!m) return 0;
    let sum = (type === 'all' || m.type === type) ? m.sizeKB : 0;
    for (const d of m.deps) sum += totalOf(d, seen, type);
    return sum;
  };
  const comps = modules.filter(m => m.type === 'js' && !m.isCommon);
  const depCount = new Map();
  for (const c of comps) for (const d of c.deps)
    depCount.set(d, (depCount.get(d) || 0) + 1);
  const report = comps.map(c => ({ component: c.module,
    selfKB: c.sizeKB, totalKB: +totalOf(c.module).toFixed(1),
    jsKB: +totalOf(c.module, new Set(), 'js').toFixed(1),
    cssKB: +totalOf(c.module, new Set(), 'css').toFixed(1) }))
    .sort((a, b) => b.totalKB - a.totalKB);
  const suggestCommon = [...depCount].filter(([d, n]) =>
    n >= commonTh && (byId.get(d)?.sizeKB ?? 0) >= commonKB && !byId.get(d)?.isCommon)
    .map(([d, n]) => ({ module: d, usedBy: n, sizeKB: byId.get(d)?.sizeKB }));
  return { report, suggestCommon };
}
```
