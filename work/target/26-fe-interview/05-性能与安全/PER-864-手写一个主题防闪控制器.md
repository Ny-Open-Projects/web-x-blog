## PER-864：手写一个主题防闪控制器：缓存主题、内联关键 CSS 与首帧校验

**答**：
- 需求：实现 ThemeGuard：init(storage) 读取缓存主题并同步设置 html 属性与背景色（返回要内联的样式文本）；setTheme(t) 切换主题并写缓存（带时间戳）；verifyFirstFrame(expected) 用 getBoundingClientRect + getComputedStyle 检查首屏容器背景色是否等于期望主题色，不等输出 mismatch 报告（含实际值与来源）。
- 边界：storage 不可用时降级为内存缓存；非法主题值回退 light；verify 在 DOM 未就绪时返回 pending。
- 评分点：初始化早于渲染；非法值回退；verify 报告含来源。

```javascript
class ThemeGuard {
  constructor(storage) { this.storage = storage; this.mem = 'light'; }
  init() {                                                     // 必须在渲染前调用
    let t = 'light';
    try { t = this.storage.getItem('theme') || this.mem; } catch { t = this.mem; }
    if (!['light', 'dark'].includes(t)) t = 'light';           // 非法回退
    this.apply(t);
    return { theme: t, inlineCss: `html[data-theme='${t}']{background:${t === 'dark' ? '#111' : '#fff'}}` };
  }
  apply(t) {
    document.documentElement.dataset.theme = t;
    document.documentElement.style.background = t === 'dark' ? '#111' : '#fff';
    try { this.storage.setItem('theme', t); } catch { /* 降级内存 */ }
    this.mem = t;
  }
  setTheme(t) { if (!['light', 'dark'].includes(t)) return; this.apply(t); }
  verifyFirstFrame(expected, sel = '[data-first-screen]') {
    const el = document.querySelector(sel);
    if (!el) return { status: 'pending' };
    const actual = getComputedStyle(el).backgroundColor;
    const want = expected === 'dark' ? 'rgb(17, 17, 17)' : 'rgb(255, 255, 255)';
    return { status: actual === want ? 'ok' : 'mismatch', actual, expected: want,
      source: this.mem === expected ? 'cache-ok' : 'theme-not-applied' };
  }
}
```
