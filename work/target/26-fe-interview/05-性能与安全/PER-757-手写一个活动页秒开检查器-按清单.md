## PER-757：手写一个活动页秒开检查器：按清单自动检查预热、预算与降级预案的完备性

**答**：
- 检查项：CDN 资源可达性与命中率（HEAD 抽样）、离线包版本就位、首屏资源体积预算、降级预案注册（降级开关/骨架屏/兜底数据）、埋点就绪（秒开打点）。
- 实现：清单驱动（数组配置每项 check 函数），输出 PASS/WARN/FAIL 三级报告；FAIL 阻断活动上线。
- 要点：CDN 命中检查用多节点探测（至少 3 地运营商出口）；预算检查在构建期做（产物体积）；降级预案检查验证开关真的能下发（配置中心连通性）。
- 边界：检查器自身要快（< 30s），可并行；检查结果归档与活动关联（复盘依据）。
- 评分点：多节点 CDN 探测与 FAIL 阻断。

```javascript

const CAMPAIGN_CHECKS = [
  { name: 'CDN 多节点命中率', check: async () => {
      const nodes = ['bj', 'sh', 'gz'].map(n => probeCDN(n, ASSETS));
      const ok = (await Promise.all(nodes)).filter(r => r.cached).length;
      return ok >= 3 ? 'PASS' : ok === 2 ? 'WARN' : 'FAIL'; } },
  { name: '离线包版本就位', check: async () =>
      (await fetchManifest()).version === EXPECTED_PKG ? 'PASS' : 'FAIL' },
  { name: '首屏体积预算 < 500KB', check: () => {
      const size = gzipSize('dist/index.html') + firstScreenChunks();
      return size < 500 * 1024 ? 'PASS' : 'FAIL'; } },
  { name: '降级预案注册', check: async () => {
      const switches = await configCenter.get(['campaign-fallback', 'skeleton-enabled']);
      return switches.every(Boolean) ? 'PASS' : 'FAIL'; } },
  { name: '秒开埋点就绪', check: () =>
      window.__secondOpenProbe ? 'PASS' : 'FAIL' },
];
async function runCampaignGate() {
  const results = [];
  for (const c of CAMPAIGN_CHECKS) {                            // 可并行化
    const verdict = await c.check();
    results.push({ name: c.name, verdict });
    if (verdict === 'FAIL') process.exitCode = 1;               // FAIL 阻断上线
  }
  archive(results, campaignId);                                 // 归档供复盘
  return results;
}
```
