## PER-1275：手写一个多端指标对齐校验器

**答**：
- 需求：实现 alignMetrics(web, mini, rn)。三者分别为 { lcp, inp, err }（Web 用标准口径，小程序/RN 为近似口径）；校验：同页面三端 err 率差 > 3x 报口径异常（可能采集 bug）；输出 { ok, table, anomalies }；缺失端标记 N/A 不参与校验。
- 边界：值为 null 视为缺失；err 率为 0 时与另一端 0 比较不算异常；anomalies 说明哪两端差异过大。
- 评分点：缺失端；比值判定；异常说明；口径告警

```javascript
function alignMetrics(web, mini, rn) {
  const table = { web, mini, rn };
  const anomalies = [];
  const ends = [['web', web], ['mini', mini], ['rn', rn]]
    .filter(([, m]) => m != null);
  for (let i = 0; i < ends.length; i++)
    for (let j = i + 1; j < ends.length; j++) {
      const [a, ma] = ends[i], [b, mb] = ends[j];
      const ea = ma.err ?? 0, eb = mb.err ?? 0;
      const ratio = Math.max(ea, eb) / Math.min(Math.max(ea, eb, 1e-9), 1e-9);
      if (Math.max(ea, eb) > 0 && Math.max(ea, eb) / Math.min(ea, eb || 1e-9) > 3)
        anomalies.push({ between: `${a}(${ea}) vs ${b}(${eb})`,
          why: 'err 率差 > 3x，疑采集口径不一致' });
    }
  return { ok: !anomalies.length, table, anomalies };
}
```
