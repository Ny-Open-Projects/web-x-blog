## PER-895：移动端弱网模拟测试的工程化：弱网档位定义、代理工具与自动化压测

**答**：
- 弱网档位要定义成可复现的数字：如 Good(4G: 20Mbps/50ms)、Fair(3G: 2Mbps/200ms)、Bad(边缘: 400kbps/600ms, 丢包 2%)、Offline；每个档位写清楚上下行/延迟/丢包，团队统一口径。
- 工具链：Charles/devtools 网络节流（开发自测）、Android emulator network shape、iOS Network Link Conditioner（真机档位）、代理脚本注入（自动化）。
- 自动化压测：CI 中跑弱网用例（关键页面在 Bad 档加载，断言骨架出现时间与最终可用时间），输出弱网通过率；每周全量跑防回归。
- 误区：只测 Offline 不测中间档（大多数用户在 Fair 档）；弱网测试只看能不能用不看耗时预算（要在每个档位定预算）。

```javascript
const networkProfiles = {
  good:  { down: '20Mbps', up: '10Mbps', rtt: 50, loss: 0 },
  fair:  { down: '2Mbps',  up: '1Mbps',  rtt: 200, loss: 0 },
  bad:   { down: '400kbps', up: '200kbps', rtt: 600, loss: 0.02 },
  offline: { down: 0, up: 0, rtt: null, loss: 1 },
};
const budgets = { fair: { fsMs: 4000, apiMs: 3000 }, bad: { fsMs: 8000, apiMs: 6000 } };
// 自动化弱网用例（伪代码结构）
async function weakNetCase(page, profile) {
  await proxy.setProfile(profile);                            // 注入弱网
  const t0 = Date.now();
  await page.goto(page.url);
  await page.waitForSelector('[data-first-screen]', { timeout: 15000 });
  const fsMs = Date.now() - t0;
  const budget = budgets[profile];
  report('weaknet-case', { page: page.name, profile, fsMs, budget });
  return { pass: fsMs <= budget.fsMs };
}
```
