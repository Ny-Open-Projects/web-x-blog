## PER-1272：手写一个安全扫描误报过滤器

**答**：
- 需求：实现 dedupeFindings(findings, verified)。findings 为 [{ id, rule, file, line, severity }]；verified 为确认过的 (rule,file) 集合；过滤规则：同 (rule,file,line) 去重；同一文件同 rule 多行合并为一条（line 列表化）；verified 命中的标记 confirmed，其余 potential；输出 { confirmed, potential } 各按 severity 降序。
- 边界：verified 支持通配 file: rule|*；severity 缺失按 medium；空 findings 返回空。
- 评分点：合并多行；通配 verified；severity 取高；双列输出

```javascript
function dedupeFindings(findings, verified = new Set()) {
  const SEV = { critical: 4, high: 3, medium: 2, low: 1 };
  const grouped = {};
  for (const f of findings) {
    const key = `${f.rule}|${f.file}`;
    (grouped[key] ??= { rule: f.rule, file: f.file, lines: [],
      severity: f.severity ?? 'medium' });
    grouped[key].lines.push(f.line);
    if (SEV[f.severity] > SEV[grouped[key].severity])
      grouped[key].severity = f.severity;
  }
  const items = Object.values(grouped).map(g => ({
    ...g, lines: [...new Set(g.lines)].sort((a, b) => a - b),
    confirmed: verified.has(`${g.rule}|${g.file}`) || verified.has(`${g.rule}|*`),
  }));
  const cmp = (a, b) => SEV[b.severity] - SEV[a.severity];
  return {
    confirmed: items.filter(i => i.confirmed).sort(cmp),
    potential: items.filter(i => !i.confirmed).sort(cmp),
  };
}
```
