## PER-1214：手写一个同意率与拒绝率监控看板数据

**答**：
- 需求：实现 consentMetrics(logs)。logs 为 [{ ts, bucket, choice: accept/decline, source: banner/panel }]；输出 { byBucket: { bucket: { acceptRate, declineRate, total } }, bySource, trend }（trend 为按天的 accept 率序列）；declineRate 保留 1 位；按天用本地日期分桶。
- 边界：空 logs 返回空结构；bucket 未出现不进结果；trend 按时间升序；choice 非法记录忽略。
- 评分点：非法忽略；多维聚合；趋势排序；rate 精度

```javascript
function consentMetrics(logs) {
  const valid = logs.filter(l =>
    ['accept', 'decline'].includes(l.choice));
  const byBucket = {}, bySource = {}, trend = {};
  for (const l of valid) {
    (byBucket[l.bucket] ??= { accept: 0, decline: 0, total: 0 });
    byBucket[l.bucket].total++;
    byBucket[l.bucket][l.choice === 'accept' ? 'accept' : 'decline']++;
    (bySource[l.source] ??= { accept: 0, total: 0 });
    bySource[l.source].total++;
    if (l.choice === 'accept') bySource[l.source].accept++;
    const day = new Date(l.ts).toISOString().slice(0, 10);
    (trend[day] ??= { accept: 0, total: 0 });
    trend[day].total++;
    if (l.choice === 'accept') trend[day].accept++;
  }
  for (const b of Object.values(byBucket)) {
    b.acceptRate = +(b.accept / b.total * 100).toFixed(1);
    b.declineRate = +(b.decline / b.total * 100).toFixed(1);
  }
  return { byBucket, bySource,
    trend: Object.entries(trend).sort(([a], [b]) => a < b ? -1 : 1)
      .map(([d, v]) => ({ day: d,
        rate: +(v.accept / v.total * 100).toFixed(1) })) };
}
```
