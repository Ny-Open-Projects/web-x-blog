## PER-1163：前端如何实现"隐私影响提示"的标准化组件

**答**：
- 场景：权限申请前置说明（为什么需要相机）、敏感操作确认（导出数据/公开资料）、采集提示（本页使用分析 SDK）。
- 标准化：统一组件 API（type/title/detail/confirm/decline），拒绝成本 ≤ 同意成本。
- 文案规范：说人话（不说"提升您的体验"这类空话，说"用于推荐内容，关闭后不影响核心功能"）。
- 埋点：展示/同意/拒绝率监控，拒绝率异常高说明文案有问题或请求不必要。

```javascript
// 权限说明组件协议
function PrivacyNotice({ type, title, detail, onConfirm, onDecline }) {
  report({ type: 'notice-view', notice: type });
  return {
    confirm: () => { report({ type: 'notice-accept', notice: type }); onConfirm(); },
    decline: () => { report({ type: 'notice-decline', notice: type }); onDecline(); },
    a11y: { role: 'dialog', focusTrap: true, esc: 'decline' },
  };
}
// 拒绝率 > 60% -> 文案评审或重新评估必要性
```
