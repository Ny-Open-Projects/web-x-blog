## PER-858：手写一个存储基准测试器：批量读写三类存储输出耗时基线与选型建议

**答**：
- 需求：实现 benchStorage(adapters)：adapters 为 [{name, put(key, val), get(key), del}]；对每个 adapter 执行：写 N 条（每条 sizeKB）、批量读 N 条、删除，记录总耗时与单条均值；输出按"写入总耗时"排序的基线表与建议（读多写少场景取读最快者，写密集取写最快者）。
- 边界：adapter 抛错（容量/隐私模式）记录 error 并跳过后续项；测试数据随机生成防缓存假命中；单条耗时 < 1ms 标记为 fast。
- 评分点：读写删三段计时；错误隔离；建议逻辑依据数据。

```javascript
async function benchStorage(adapters, { n = 100, sizeKB = 4 } = {}) {
  const results = [];
  for (const ad of adapters) {
    try {
      const items = Array.from({ length: n }, (_, i) =>
        ({ key: `bench_${Math.random().toString(36).slice(2)}`, val: 'x'.repeat(sizeKB * 1024) }));
      const t0 = performance.now();
      for (const it of items) await ad.put(it.key, it.val);       // 写
      const writeMs = performance.now() - t0;
      const t1 = performance.now();
      for (const it of items) await ad.get(it.key);               // 读
      const readMs = performance.now() - t1;
      const t2 = performance.now();
      for (const it of items) await ad.del(it.key);               // 删
      results.push({ name: ad.name, writeTotal: +writeMs.toFixed(1),
        readTotal: +readMs.toFixed(1),
        readPerItem: readMs / n, fast: readMs / n < 1,
        error: null,
        _writeSort: writeMs });
    } catch (e) {
      results.push({ name: ad.name, error: String(e).slice(0, 100) });
    }
  }
  const ok = results.filter(r => !r.error).sort((a, b) => a._writeSort - b._writeSort);
  return {
    baseline: ok,
    advice: {
      readHeavy: [...ok].sort((a, b) => a.readTotal - b.readTotal)[0]?.name,   // 读最快
      writeHeavy: ok[0]?.name,                                               // 写最快
    },
  };
}
```
