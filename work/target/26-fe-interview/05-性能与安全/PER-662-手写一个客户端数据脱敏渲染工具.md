## PER-662：手写一个客户端数据脱敏渲染工具：按规则把 PII 字段转为掩码并支持点击查看（带审计）

**答**：
- 掩码规则表驱动：手机号 `138****8000`、身份证保留前后 3、姓名保留姓、银行卡保留后 4；规则可配置且带查看按钮的完整度控制（查看动作写审计日志）。
- 要点：脱敏在渲染层做而不是数据层（数据内存里完整、展示受控）；查看动作带权限校验 + 审计（谁在何时查看了什么字段）；防复制出来是完整值的旁路（查看态的复制也脱敏）。
- 边界：规则误伤检查（非 11 位手机号不套规则）；对旧数据的兼容（字段缺失时降级为全掩码）。
- 评分点：查看审计与复制旁路。

```javascript

const MASK_RULES = {
  phone: v => v.length === 11 ? v.replace(/(\d{3})\d{4}(\d{4})/, '$1****$2') : '*'.repeat(v.length),
  idcard: v => v.length >= 8 ? v.slice(0, 3) + '*'.repeat(v.length - 6) + v.slice(-3) : '*'.repeat(v.length),
  name: v => v.length >= 2 ? v[0] + '*'.repeat(v.length - 1) : '*',
  bank: v => '*'.repeat(Math.max(0, v.length - 4)) + v.slice(-4),
};
const audit = [];
function maskedView(field, value, rule, { canReveal = false } = {}) {
  const mask = MASK_RULES[rule]?.(value) ?? '*'.repeat(value.length);
  return {
    display: mask,
    reveal() {                                                   // 点击查看
      if (!canReveal) throw new Error('无查看权限');
      audit.push({ field, by: currentUser.id, at: Date.now() }); // 审计留痕
      return {
        value,
        copySafe: false,                                         // 查看态复制仍脱敏
        toString: () => MASK_RULES[rule](value),
      };
    },
  };
}
maskedView('phone', '13812348000', 'phone').display;  // => '138****8000'
```
