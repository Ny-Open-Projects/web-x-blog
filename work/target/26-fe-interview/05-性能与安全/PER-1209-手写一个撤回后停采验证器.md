## PER-1209：手写一个"撤回后停采"验证器

**答**：
- 需求：实现 WithdrawalVerifier。arm(bucket) 撤回后开启观察窗（24h）；observe(fn) 在窗口内定期调用 fn() 采集上报样本（fn 返回该 bucket 相关事件数）；verify() 窗口结束时判定：窗口内事件数 > 0 即 fail（consent-not-honored），触发 alert 回调；pass 则记录证据（时间窗+样本数）。
- 边界：窗口内 fn 抛错按 0 计但记录 error 次数（>10 次探针失效单独告警）；重复 arm 重置窗口；验证进行中重复 verify 返回 in-progress。
- 评分点：观察窗；样本聚合；探针失效；重复验证

```javascript
class WithdrawalVerifier {
  constructor({ windowMs = 24 * 3600_000, alert } = {}) {
    this.windowMs = windowMs; this.alert = alert;
    this.state = null;
  }
  arm(bucket) {
    this.state = { bucket, from: Date.now(), samples: [], errors: 0, verifying: false };
    return this.state.from + this.windowMs;
  }
  observe(fn) {
    const s = this.state;
    if (!s || Date.now() - s.from > this.windowMs) return;
    try { s.samples.push({ t: Date.now(), n: fn() ?? 0 }); }
    catch { s.errors++; }
  }
  verify() {
    const s = this.state;
    if (!s) return { ok: false, reason: 'not-armed' };
    if (Date.now() - s.from <= this.windowMs && !s.force)
      return { ok: null, reason: 'in-progress' };
    const total = s.samples.reduce((a, x) => a + x.n, 0);
    const ok = total === 0;
    if (!ok) this.alert?.({ bucket: s.bucket, events: total,
      window: { from: s.from, to: s.from + this.windowMs } });
    if (s.errors > 10) report({ type: 'probe-broken', bucket: s.bucket });
    return { ok, events: total, errors: s.errors,
      evidence: { window: 24 * 3600_000, samples: s.samples.length } };
  }
}
```
