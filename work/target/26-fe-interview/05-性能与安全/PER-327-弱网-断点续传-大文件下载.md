## PER-327：弱网下载大文件（离线包/视频）如何断点续传？Range 请求与进度管理怎么写？

**答**：
- Range 续传：服务器支持 `Accept-Ranges: bytes`，请求带 `Range: bytes=offset-` 从断点继续；响应 206 Partial Content + `Content-Range`。前端收到失败（网络中断）时记录已收字节数，重试用 Range 接着拉。
- 进度管理：用 ReadableStream reader 逐块读取累加 received 字节（响应头 Content-Length 或 Content-Range end 得知总量），实时更新进度条；块写入临时 IndexedDB（或内存 buffer），完成后合并落盘。
- 边界：服务器不支持 Range（206 失败）→ 整体重下；Range 起点超过文件大小（416）→ 从头或提示重试；弱网超时控制（每块 30s 无进展即中断重连）；并发分块下载（多个 Range 块并行）提速但弱网下建议单流（避免抢带宽）。
- 校验：完成后对整体做 hash 校验（或服务端给分块 ETag），保证弱网重传拼接不损坏。

```javascript
async function downloadWithResume(url, { onProgress, saveChunk } = {}) {
  let received = await getResumeOffset(url);             // 从 IDB 恢复断点
  for (;;) {
    const res = await fetch(url, { headers: received ? { Range: `bytes=${received}-` } : {} });
    if (res.status === 416) { received = 0; continue; }  // 断点过期：从头
    const total = res.status === 206
      ? parseInt(res.headers.get('content-range').split('/')[1], 10)
      : +res.headers.get('content-length');
    if (res.status !== 206 && received > 0) { received = 0; continue; }   // 不支持 Range：重下
    const reader = res.body.getReader();
    for (;;) {
      const { done, value } = await reader.read();       // 逐块读
      if (done) break;
      received += value.byteLength;
      await saveChunk?.(url, value, received);           // 块落 IDB（断点持久化）
      onProgress?.(received, total);
      if (await isStalled()) { reader.cancel(); break; } // 弱网停滞检测→外层重试带 Range
    }
    if (received >= total) break;
  }
  return finalize(url, received);                        // 合并块 + 校验
}
```
