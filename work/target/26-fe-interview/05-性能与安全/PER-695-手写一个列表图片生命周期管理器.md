## PER-695：手写一个列表图片生命周期管理器：IntersectionObserver 控制加载/回收，与虚拟列表协同

**答**：
- 职责：视口内加载（真实 src）、临近预载（rootMargin 提前 1 屏）、离屏 2 屏回收（src 置占位，dataset 保留原址），虚拟列表的行销毁时同步解除观察。
- 要点：observer 复用单例（多列表共享一个实例，用 Map 记录目标状态）；回收阈值按设备档调整（低端更激进）；恢复加载要防抖（快速滚动来回不重复解码）。
- 边界：IntersectionObserver 不可用降级 scroll 节流检查；图片加载失败有占位兜底。
- 评分点：单例复用与销毁联动。

```javascript

class ImageLifecycle {
  constructor({ preMargin = '100%', recycleMargin = '200%' } = {}) {
    this.states = new Map();
    this.io = new IntersectionObserver(es => es.forEach(e => this.onIO(e)), {
      rootMargin: `${preMargin} 0px ${recycleMargin} 0px` });   // 单例复用
  }
  attach(img) {
    img.src = PLACEHOLDER; img.dataset.src = img.dataset.origSrc ?? img.src;
    this.states.set(img, { loaded: false, visible: false });
    this.io.observe(img);
  }
  detach(img) { this.io.unobserve(img); this.states.delete(img); } // 虚拟行销毁联动
  onIO(e) {
    const st = this.states.get(e.target);
    if (!st) return;
    st.visible = e.isIntersecting;
    if (e.isIntersecting && !st.loaded) this.load(e.target);    // 视口或临近：加载
    if (!e.isIntersecting && Math.abs(e.boundingClientRect.top) > innerHeight * 2 && st.loaded) {
      e.target.src = PLACEHOLDER; st.loaded = false;            // 离屏 2 屏回收
    }
  }
  load(img) {
    const st = this.states.get(img);
    st.loading = true;
    img.src = img.dataset.src;
    img.onload = () => { st.loaded = true; st.loading = false; };
    img.onerror = () => { img.src = FALLBACK; st.loaded = true; };
  }
}
```
