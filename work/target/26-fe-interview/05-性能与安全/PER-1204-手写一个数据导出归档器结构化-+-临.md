## PER-1204：手写一个数据导出归档器：结构化 + 临时链接

**答**：
- 需求：实现 exportArchive(uid, datasets)。datasets 为 { name: rows }；输出 bundle { schema, subject: hash(uid), generatedAt, data }；大文件（>5MB）分片存（chunk = 1MB 数组），putTemp 接口接收并返回 url；下载链接 sign(url, ttl) 一小时有效；记录审计 export。
- 边界：datasets 为空仍导出（空 data）；putTemp 失败重试 2 次后抛错；hash 不可逆（sha256 前 16 位）。
- 评分点：bundle 结构；重试；不可逆哈希；审计

```javascript
async function exportArchive(uid, datasets, putTemp, sign) {
  const bundle = { schema: 'export-v2', subject: hash(uid),
    generatedAt: new Date().toISOString(),
    data: Object.fromEntries(Object.entries(datasets).map(([k, v]) =>
      [k, v.length])) };
  const body = JSON.stringify(bundle);
  let url = null;
  for (let i = 0; i < 3 && !url; i++) {
    try { url = await putTemp(body); } catch (e) {
      if (i === 2) throw e;
      await new Promise(r => setTimeout(r, 500));
    }
  }
  logAudit(hash(uid), 'export', 'portability');
  return { downloadUrl: sign(url, 3600_000), size: body.length,
    expires: '1h' };
}
async function hash(s) {
  const buf = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(s));
  return [...new Uint8Array(buf)].slice(0, 8)
    .map(b => b.toString(16).padStart(2, '0')).join('');
}
```
