## PER-1278：手写一个隐私合规快照对比器：政策版本变更 diff

**答**：
- 需求：implement policyDiff(oldP, newP)。政策为 { fields: { name: { purpose, keep, level } }, vendors: [name] }；输出 { changedFields, addedFields, removedFields, newVendors, needReConsent }：任何字段 keep/level 变化或新增 vendor 都触发重新同意。
- 边界：purpose 变化只记录不触发重同意（低敏）；fields 结构变化健壮（缺 key 视为变化）；两边为 null 返回 no-op。
- 评分点：三类字段 diff；vendor 新增；重同意判定；健壮性

```javascript
function policyDiff(oldP, newP) {
  if (!oldP && !newP) return { needReConsent: false, note: 'no-op' };
  const oldF = oldP?.fields ?? {}, newF = newP?.fields ?? {};
  const names = new Set([...Object.keys(oldF), ...Object.keys(newF)]);
  const changedFields = [], addedFields = [], removedFields = [];
  for (const n of names) {
    const o = oldF[n], w = newF[n];
    if (!o) addedFields.push(n);
    else if (!w) removedFields.push(n);
    else if (o.keep !== w.keep || o.level !== w.level)
      changedFields.push({ name: n, keep: [o.keep, w.keep], level: [o.level, w.level] });
  }
  const oldV = new Set(oldP?.vendors ?? []), newV = new Set(newP?.vendors ?? []);
  const newVendors = [...newV].filter(v => !oldV.has(v));
  return { changedFields, addedFields, removedFields, newVendors,
    needReConsent: changedFields.length > 0 || addedFields.length > 0 || newVendors.length > 0 };
}
```
