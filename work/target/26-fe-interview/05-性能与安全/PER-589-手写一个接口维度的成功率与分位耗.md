## PER-589：手写一个接口维度的成功率与分位耗时统计器：按业务结果分类聚合，支持分层下钻

**答**：
- 前端侧先做本地聚合（减少上报量）：内存中按 `api+status+netTier` 聚合计数与耗时数组（限长），定时输出分位数与成功率再上报。
- 要点：耗时数组用环形上限（每桶最多 500 条，超出丢旧）防内存膨胀；分位数用排序取位；上报时带窗口起止时间。
- 边界：AbortError 计 cancelled 不进失败率；重试要带 retrySeq 标记，统计时可分离首次请求成功率。
- 评分点：本地聚合与 cancelled 的口径处理。

```javascript

class ApiStatsAggregator {
  constructor(flushMs = 30000, maxPerBucket = 500) {
    this.buckets = new Map(); this.flushMs = flushMs; this.maxPerBucket = maxPerBucket;
    setInterval(() => this.flush(), flushMs);
  }
  track(api, status, ms, { netTier = 'unknown', retrySeq = 0 } = {}) {
    const key = `${api}|${status}|${netTier}`;
    const b = this.buckets.get(key) ??= { count: 0, times: [] };
    b.count++;
    if (retrySeq === 0 && ms != null) {                     // 只统计首次请求耗时
      b.times.push(ms);
      if (b.times.length > this.maxPerBucket) b.times.shift(); // 环形上限
    }
  }
  flush() {
    const out = [];
    for (const [key, b] of this.buckets) {
      const [api, status, netTier] = key.split('|');
      const t = b.times.slice().sort((a, z) => a - z);
      out.push({ api, status, netTier, count: b.count,
        p75: t[Math.floor(t.length * 0.75)] ?? null,
        p95: t[Math.floor(t.length * 0.95)] ?? null, ts: Date.now() });
    }
    if (out.length) navigator.sendBeacon('/collect/api', JSON.stringify(out));
    this.buckets.clear();
  }
}
// 用法：wrapper(fetch) 分类后喂 track；成功率 = success/(success+retryable+biz-error)，cancelled 不进分母
```
