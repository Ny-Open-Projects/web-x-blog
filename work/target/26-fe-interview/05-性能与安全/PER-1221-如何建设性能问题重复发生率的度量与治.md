## PER-1221：如何建设"性能问题重复发生率"的度量与治理

**答**：
- 定义：同类问题（同反模式/同资源类型）在修复后 N 个月内再次发生的比率。
- 度量：问题打标（反模式 ID），修复关联反模式；重复发生 = 同反模式新案例 / 历史修复数。
- 治理：重复率高的反模式升级为自动化检测（lint/CI），推动重复率趋零。
- 目标：重复发生率 < 10%，高于则说明"修了个案没修系统"。

```javascript
// 重复发生率
function recurrenceRate(cases, windowDays = 90) {
  const byPattern = {};
  for (const c of cases) {
    (byPattern[c.pattern] ??= []);
    byPattern[c.pattern].push(c.ts);
  }
  const out = {};
  for (const [p, ts] of Object.entries(byPattern)) {
    const fixed = ts.filter(t => true);
    const re = ts.filter((t, i) =>
      i > 0 && t - ts[i - 1] < windowDays * 86400_000);
    out[p] = { fixed: fixed.length, recurred: re.length,
      rate: +(re.length / fixed.length * 100).toFixed(1) + '%' };
  }
  return out;
}
// rate 高的反模式 -> 下一批自动化 lint 规则候选
```
