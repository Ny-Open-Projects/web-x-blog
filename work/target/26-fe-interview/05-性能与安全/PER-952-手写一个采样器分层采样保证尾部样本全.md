## PER-952：手写一个采样器：分层采样保证尾部样本全保留并给出权重还原函数

**答**：
- 需求：实现 stratifiedSampler。输入 records（含 value）与 rate；value 超过 tailThreshold 的全保留，其余按 rate 概率采样（用稳定哈希而非 Math.random，保证同一 id 多次调用结果一致）；返回 { sample, reweight }，reweight(sample) 能按层权重估算总量与 P75。
- 边界：rate 在 (0,1]；空输入返回空；tailThreshold 默认 0.95 分位需由调用方传入或内部计算。
- 评分点：分层逻辑；稳定哈希；权重还原；边界处理

```javascript
function stratifiedSampler(records, rate, tailThreshold) {
  const sorted = [...records].map(r => r.value).sort((a, b) => a - b);
  const tail = tailThreshold ?? sorted[Math.floor(sorted.length * 0.95)];
  const head = records.filter(r => r.value < tail);
  const sample = records.filter(r => r.value >= tail ||
    (hash(r.id) % 1000) < rate * 1000);            // 稳定哈希采样
  const wHead = head.length / records.length;
  const keptHead = sample.filter(r => r.value < tail).length;
  function reweight(s) {
    const vals = s.map(r => r.value).sort((a, b) => a - b);
    const headVals = vals.filter(v => v < tail);
    const headP75 = headVals.length ? headVals[Math.floor(headVals.length * 0.75)] : 0;
    const tailVals = vals.filter(v => v >= tail);
    return { total: Math.round(keptHead / rate + tailVals.length),
      p75: headVals.length / vals.length >= 0.75 ? headP75 : tailVals[0] ?? null };
  }
  return { sample, reweight };
}
function hash(s) { let h = 0; for (const c of String(s)) h = (h * 31 + c.charCodeAt(0)) >>> 0; return h; }
```
