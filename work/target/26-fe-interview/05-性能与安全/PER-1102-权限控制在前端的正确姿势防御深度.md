## PER-1102：权限控制在前端的正确姿势（防御深度）

**答**：
- 认知：前端权限控制只是 UX（隐藏按钮），服务端才是裁决者——接口必须独立鉴权。
- 模型：RBAC（角色-权限点）或 ABAC（属性），权限点下发到前端做 UI 显隐与路由守卫。
- 防绕过：路由守卫只拦"进入体验"，真正数据靠接口 403；不要把敏感数据（金额明细）给无权限用户再靠前端隐藏。
- 降级路径：权限服务不可用时默认拒绝（fail-closed），提供只读缓存权限。

```javascript
// 权限点驱动的 UI 守卫
const perms = new Set(user.permissions);             // 服务端下发
function can(p) { return perms.has(p); }
// 路由守卫
router.beforeEach(to => {
  if (to.meta.perm && !can(to.meta.perm)) return '/403';
});
// 组件级
// { can('order:export') && <ExportButton /> }
// 铁律：导出接口本身仍需鉴权，前端隐藏只是体验层
// fail-closed：权限接口超时不渲染敏感模块
const permsReady = await withTimeout(loadPerms(), 3000).catch(() => false);
if (!permsReady) renderReadOnlyMode();
```
