## PER-884：手写一个滚动进度条组件：rAF 节流、transform 更新与滚动结束回调的实现

**答**：
- 需求：实现 ScrollProgressBar：进度条随页面滚动 scaleX 变化（transform 更新、rAF 合帧）；滚动停止 150ms 后触发 onScrollEnd(progress)（含最终进度）；提供 destroy 清理；进度用文档高度实时计算（图片懒加载导致高度变化要正确）。
- 边界：页面高度不足一屏时进度恒 1；rAF 在无滚动时不空转（滚动事件驱动，不常驻循环）；resize 后重新计算文档高度。
- 评分点：rAF 合帧；scrollEnd 去抖；高度实时计算。

```javascript
class ScrollProgressBar {
  constructor(el, { endDelay = 150 } = {}) {
    this.el = el; this.endDelay = endDelay;
    this.ticking = false; this.endTimer = null;
    this.onScroll = this.onScroll.bind(this);
    addEventListener('scroll', this.onScroll, { passive: true });
    addEventListener('resize', () => { this.h = document.documentElement.scrollHeight; }, { passive: true });
    this.h = document.documentElement.scrollHeight;
  }
  progress() {
    const max = this.h - innerHeight;
    return max <= 0 ? 1 : Math.min(scrollY / max, 1);          // 不足一屏恒 1
  }
  onScroll() {
    if (!this.ticking) {
      this.ticking = true;
      requestAnimationFrame(() => {
        const p = this.progress();
        this.el.style.transform = `scaleX(${p})`;              // 只写 transform
        this.ticking = false;
      });
    }
    clearTimeout(this.endTimer);                               // 滚动结束去抖
    this.endTimer = setTimeout(() => {
      this.onScrollEnd?.(this.progress());
    }, this.endDelay);
  }
  destroy() {
    removeEventListener('scroll', this.onScroll);
    clearTimeout(this.endTimer);
  }
}
```
