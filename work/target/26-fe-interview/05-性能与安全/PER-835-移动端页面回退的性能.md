## PER-835：移动端页面回退的性能：bfcache、页面栈缓存与回退秒显的实现

**答**：
- 回退慢的根因：回退重新加载页面（网络+JS 重新执行）。理想是"回退即显"——数据与滚动位置都在缓存里。
- 三层方案：① bfcache（浏览器前进后退缓存，页面完全不卸载，注意 unload 监听会禁用 bfcache，要用 pagehide/pageshow）；② SPA 内页面栈缓存（keep-alive 思路，路由切走时保留组件实例与数据）；③ 自管理数据缓存（列表页数据 + 滚动位置存 sessionStorage/内存，返回时先渲染缓存再后台刷新）。
- 缓存失效策略：缓存数据带时间戳，回显旧数据同时静默请求新数据，到达后 diff 更新（SWR 模式）——保证"秒显"与"新鲜"兼得。
- 注意：带表单/敏感输入的页面慎用栈缓存（数据残留与串号风险），进入前清理或白名单管理。

```javascript
// SWR 式回退秒显
const pageCache = new Map();                 // key: routeId -> {data, scrollTop, ts}
function onEnter(routeId) {
  const c = pageCache.get(routeId);
  if (c) {
    render(c.data); restoreScroll(c.scrollTop);   // 秒显缓存
    if (Date.now() - c.ts > 30000) {              // 过期则后台刷新
      fetchData(routeId).then(fresh => {
        if (fresh.version !== c.data.version) render(fresh);   // 版本变了才重渲染
        else patchDiff(c.data, fresh);           // 同版本增量补
        pageCache.set(routeId, { data: fresh, scrollTop: c.scrollTop, ts: Date.now() });
      });
    }
  } else fetchData(routeId).then(d => render(d));
}
function onLeave(routeId) {                    // 离开时快照
  pageCache.set(routeId, { data: currentState(), scrollTop: window.scrollY, ts: Date.now() });
}
addEventListener('pagehide', () => onLeave(currentRoute));   // 用 pagehide 保 bfcache
```
