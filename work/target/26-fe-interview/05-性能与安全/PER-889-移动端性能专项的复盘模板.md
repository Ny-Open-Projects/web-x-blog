## PER-889：移动端性能专项的复盘模板：专项从立项到收口的阶段产出与验收标准

**答**：
- 专项四阶段与产出：① 立项（问题量化：指标现状 vs 目标、收益估算、优先级）；② 诊断（分段归因报告：Top 问题清单+根因+方案）；③ 治理（按方案排期落地，每项带验证方式）；④ 收口（指标达标验证+防劣化机制上线+文档归档）。
- 复盘必答四问：目标达成率（实际 vs 承诺）；哪些优化收益超预期/低于预期及原因；哪些手段被放弃及教训；机制是否真正常态化（值班/门禁运行数据）。
- 常见失败模式：只做快赢不做机制（三个月劣化回原点）；目标定均值不看长尾；归因不清就开工（方案全靠猜）。
- 产出物清单化：立项书/诊断报告/优化清单/验收报告/规范文档五件套，缺一项不算收口。

```javascript
const reviewTemplate = {
  phases: [
    { name: '立项', deliver: ['指标现状 vs 目标', '收益估算', '优先级排序'] },
    { name: '诊断', deliver: ['分段归因报告', 'Top 问题清单', '根因+方案'] },
    { name: '治理', deliver: ['排期落地', '每项验证方式'] },
    { name: '收口', deliver: ['达标验证', '防劣化机制上线', '五件套归档'] },
  ],
  questions: ['目标达成率', '超/低预期项及原因', '被放弃手段的教训', '机制常态化证据'],
  acceptance: (result) => ({
    metricOk: result.achieved >= result.target * 0.95,
    mechanismOn: result.guardRunningDays >= 30,
    docsDone: result.deliverables.length === 5,
    verdict: '全过才算收口，否则列遗留项转下轮',
  }),
};
```
