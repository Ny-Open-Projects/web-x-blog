## PER-872：手写一个唤端耗时探针：测量唤端全链路耗时并输出失败率与兜底建议

**答**：
- 需求：实现 InvokeProbe：mark(click) 起点；visibilitychange hidden 时算耗时（点击→hidden）；恢复可见（回跳）视为失败；输出报告：尝试次数、成功率、p75 耗时、失败分类（timeout-无响应 / bounce-回跳 / blocked-UA 命中拦截环境）；给出兜底建议（失败率 > 30% 且 blocked 占比高 → 切 UL 方案）。
- 边界：hidden 前多次 mark 以最后一次为准；探针实例复用（连续多次唤端）统计要重置当前次；报告保留最近 50 次。
- 评分点：hidden/回跳状态机；失败分类；建议逻辑。

```javascript
class InvokeProbe {
  constructor() { this.recs = []; }
  mark(tag) { this.cur = { click: performance.now(), tag, bounced: false, hidden: false }; }
  observe() {
    document.addEventListener('visibilitychange', () => {
      if (!this.cur) return;
      if (document.hidden) { this.cur.hidden = true; this.cur.ms = performance.now() - this.cur.click; }
      else if (this.cur.hidden) { this.cur.bounced = true; }   // 回跳 = 失败
    });
  }
  report({ bounceTh = 30 } = {}) {
    this.recs.push(this.cur); this.cur = null;
    const recs = this.recs.slice(-50);
    const ok = recs.filter(r => r.hidden && !r.bounced);
    const fail = recs.length - ok.length;
    const blocked = fail && /MicroMessenger|Weibo/i.test(navigator.userAgent);
    const failRate = recs.length ? fail / recs.length : 0;
    return {
      attempts: recs.length, successRate: recs.length ? ok.length / recs.length : 0,
      p75: ok.length ? p75(ok.map(r => r.ms)) : null,
      failTypes: { timeout: recs.filter(r => !r.hidden).length,
        bounce: recs.filter(r => r.bounced).length },
      advice: failRate > bounceTh / 100 && blocked
        ? '被拦截占比高：切 Universal Link / 引导浏览器打开' : '维持当前方案',
    };
  }
}
function p75(a) { const s = [...a].sort((x, y) => x - y); return s[Math.floor(s.length * 0.75)]; }
```
