## PER-696：手写一个滚动位置恢复器：列表页返回时恢复滚动位置且不重新请求（缓存页性能）

**答**：
- 场景：列表 -> 详情 -> 返回，要求瞬间回到原位置且列表数据不变（不重新请求）——组合：页面数据缓存（sessionStorage/内存 store）+ 滚动位置记录 + 恢复时用 `scrollTo` + 数据重建后等渲染完成再滚（否则滚不到底）。
- 要点：恢复时机在列表渲染完成（虚拟列表要等已渲染到目标位置——先滚到估算位置再精调）；缓存带过期（30 分钟）；位置精度用锚点元素 index + 偏移而不是纯像素（数据变化仍能大致恢复）。
- 边界：数据可能过期（服务端更新），恢复后要静默刷新并保持位置；bfcache 可用时优先依赖浏览器原生恢复。
- 评分点：锚点恢复法与渲染完成时机。

```javascript

const scrollMemory = new Map();                                 // key -> {anchorIndex, offset, data, ts}
function saveListState(key, listEl, items) {
  const anchor = findAnchorIndex(listEl);                       // 视口顶部的列表项 index
  const rect = listEl.querySelector(`[data-index="${anchor}"]`)?.getBoundingClientRect();
  scrollMemory.set(key, { anchorIndex: anchor,
    offset: rect ? innerHeight - rect.top : 0,                  // 锚点相对视口偏移
    data: items, ts: Date.now() });                             // 30 分钟过期
}
function restoreListState(key, renderList) {
  const s = scrollMemory.get(key);
  if (!s || Date.now() - s.ts > 30 * 60e3) return false;
  renderList(s.data);                                           // 用缓存数据渲染，不请求
  requestAnimationFrame(() => {
    const target = s.anchorIndex * ROW_H + s.offset;            // 估算位置
    scrollTo(0, target);
    requestAnimationFrame(() => {                               // 渲染后精调
      const el = document.querySelector(`[data-index="${s.anchorIndex}"]`);
      if (el) scrollTo(0, scrollY + el.getBoundingClientRect().top - (innerHeight - s.offset));
    });
  });
  return true;
}
```
