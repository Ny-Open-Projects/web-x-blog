## PER-1279：手写一个性能数据脱敏导出器

**答**：
- 需求：implement exportPerfData(records, opts)。records 含 { url, uid, lcp, inp, cls, ua }；导出规则：uid -> 不可逆哈希；url -> sanitizeUrl（953 逻辑内联简化）；ua -> 仅浏览器族（Chrome/Safari/Firefox/其他）；输出 CSV 行数组与 header；opts: { includeUA, hashSalt }。
- 边界：空记录返回仅 header；uid 缺失跳过该行；hashSalt 参与 hash（防彩虹表）。
- 评分点：哈希加盐；URL 脱敏；UA 归族；缺失跳行

```javascript
function exportPerfData(records, { includeUA = false, hashSalt = 's1' } = {}) {
  const header = ['uid', 'url', 'lcp', 'inp', 'cls', ...(includeUA ? ['browser'] : [])];
  const rows = records.map(r => {
    if (r.uid == null) return null;
    const uid = hash(hashSalt + r.uid);
    const url = sanitize(r.url ?? '');
    const browser = /chrome/i.test(r.ua ?? '') ? 'Chrome'
      : /safari/i.test(r.ua ?? '') && !/chrome/i.test(r.ua ?? '') ? 'Safari'
      : /firefox/i.test(r.ua ?? '') ? 'Firefox' : 'Other';
    return [uid, url, r.lcp ?? '', r.inp ?? '', r.cls ?? '',
      ...(includeUA ? [browser] : [])];
  }).filter(Boolean);
  return { header, rows };
}
function hash(s) { let h = 0; for (const c of String(s)) h = (h * 31 + c.charCodeAt(0)) >>> 0; return h.toString(16); }
function sanitize(url) {
  return url.split('?')[0].replace(/\d{6,}/g, 'N');
}
```

## 补充：评分点与变体

**评分点**：

- 识别并脱敏 PII 字段：URL query、UA 中的设备标识、用户 ID。
- 保留可分析维度（机型档位、网络类型），不做无差别全抹。
- 导出带 schema 版本号，便于回溯与兼容。
- 脱敏可验证：单测断言原始值不出现在产物中。

**变体与延伸**：

1. URL 参数怎么处理？ → 白名单保留分析用参数，其余键值置空。
2. 哈希脱敏够吗？ → 低熵字段（手机号）必须加盐，否则可被彩虹表还原。
3. 导出格式怎么选？ → 分析场景用 NDJSON 便于流式处理，交付场景用 CSV。
