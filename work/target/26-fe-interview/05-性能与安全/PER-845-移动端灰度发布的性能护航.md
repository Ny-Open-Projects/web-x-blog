## PER-845：移动端灰度发布的性能护航：灰度期间的指标哨兵与自动暂停条件

**答**：
- 灰度期护航的本质：把性能指标当作发布健康信号，劣化即暂停——性能事故控制在灰度小流量内，而不是全量后救火。
- 哨兵设计：核心指标（秒开率、崩溃率、白屏率、JS 错误率）实时对比灰度组 vs 基线组，按设备档分层；任何一项超阈值（如崩溃率翻倍）触发自动暂停（停止扩量，不自动回滚——回滚需人工确认影响面）。
- 自动暂停条件要防误伤：最小样本量（如灰度组 500+ 用户/档）、时间窗对齐、已知大促/节假日流量波动豁免。
- 恢复流程：暂停 → 归因（分段+diff）→ 修复或回滚 → 重新从小流量灰度。全程留痕（暂停原因/恢复人/结论）。

```javascript
const sentinel = {
  rules: [
    { metric: 'crash-rate', cmp: (g, b) => g > b * 2, minSample: 500, action: 'pause' },
    { metric: 'second-open-rate', cmp: (g, b) => g < b * 0.95, minSample: 1000, action: 'pause' },
    { metric: 'white-screen-rate', cmp: (g, b) => g > b + 0.01, minSample: 500, action: 'pause' },
  ],
  async tick(releaseId) {
    const { gray, base, exempt } = await fetchMetrics(releaseId);
    if (exempt) return;                                        // 大促豁免窗口
    for (const r of this.rules) {
      const g = gray[r.metric], b = base[r.metric];
      if (g.sample < r.minSample) continue;                    // 防误伤
      if (r.cmp(g.value, b.value)) {
        await release.pause(releaseId, {                       // 自动暂停（不自动回滚）
          reason: `${r.metric} 劣化`, gray: g.value, base: b.value });
        notifyOnCall(releaseId, r.metric);
        return;
      }
    }
  },
};
```
