## PER-461：OAuth 回调页的性能预算与安全清单？

**答**:
- 性能特殊性：回调页生命周期极短（code 换 token → 跳转目标页，<2s）——常规优化（CWV）无意义，预算指标是"回调完成耗时"（p75 < 1.5s）与"失败率"。性能坑：回调页同步等 token 接口（串行阻塞）→ 预热连接 + 并行校验 state；redirect 循环（token 校验失败重定向回回调页）。
- 安全清单：① state 参数——CSRF 防护（随机值 + 会话绑定 + 一次性）；② 回调 URL 白名单——redirect_uri 精确匹配（开放重定向=授权码窃取）；③ code 一次性——服务端消费后立即失效；④ token 不落 URL——code 换 token 在服务端完成，前端只见 session；⑤ 回调页 CSP 收紧（最小脚本面）。
- 度量：回调耗时分布、失败原因分布（state 失效/网络/服务端）、循环重定向检测（同 URL 连续 2 次即熔断提示）。

```text
OAuth 回调页专项：
性能预算：回调完成耗时 p75 < 1.5s（code→token→跳转全链路）
  坑：同步等 token 接口 → 预热连接 + 并行校验；redirect 循环检测（同 URL ×2 熔断）
安全清单：
  [ ] state 随机 + 会话绑定 + 一次性（CSRF）
  [ ] redirect_uri 精确白名单（开放重定向 = 授权码窃取）
  [ ] code 一次性消费
  [ ] token 服务端交换，前端不触碰
  [ ] 回调页 CSP 最小化
度量：耗时分布 / 失败原因分布 / 循环重定向率
```
