## PER-877：移动端性能数据的脱敏与合规上报：设备信息与位置类信号的合规边界

**答**：
- 性能数据里混着个人信息：设备指纹（IMEI/IDFA 类）、精确位置（弱网优化用的基站信息）、用户操作路径——未经同意采集就上报违反个保法/GDPR。
- 合规三原则：最小必要（性能归因只需要设备档与粗网络档，不需要唯一标识与精确位置）；同意前置（未同意前不上报或只报聚合匿名数据）；脱敏与假名化（用户标识用不可逆哈希+盐，且定期轮换）。
- 落地机制：上报 SDK 内置字段白名单（未在白名单的字段直接丢弃并审计日志）；同意状态变化时（撤回）停止采集并清缓存；数据出境/三方共享要二次评估。
- 工程细节：采样上报的 IP 在服务端截断（不落全量 IP）；时间戳/时区保留但去除会暴露位置的语言区域字段。

```javascript
const ALLOWLIST = new Set(['tier', 'netType', 'fsMs', 'fps', 'route', 'ts',
  'deviceModel', 'osVersion', 'appId']);
function sanitizeReport(payload, consent) {
  if (!consent.analytics) return null;                         // 未同意：不上报
  const clean = {}, dropped = [];
  for (const [k, v] of Object.entries(payload)) {
    if (ALLOWLIST.has(k)) clean[k] = v;
    else { dropped.push(k); auditLog('field-dropped', { k }); } // 白名单外丢弃+审计
  }
  clean.uid = consent.uid ? pseudonymize(consent.uid) : null;  // 假名化（哈希+盐）
  delete clean.ip; delete clean.geo;                           // 位置类不出前端
  return clean;
}
function pseudonymize(uid) {                                   // 不可逆 + 定期轮换盐
  const salt = currentSalt(Date.now());
  return sha256Hex(salt + uid).slice(0, 32);
}
```
