## PER-843：移动端组件库的性能要求：按需加载、样式体积与低端机适配

**答**：
- 移动端组件库三大性能负担：JS 体积（全量引入动辄几百 KB）、CSS 体积（含主题变量与全组件样式）、运行时开销（每个组件的监听/动画）。
- 按需加载：ES Module tree-shaking（sideEffects 标注）+ 组件级动态 import（重组件如日历/级联选择器按需）；样式按组件拆分随 JS 同步加载。
- 低端机适配：组件库内置降级接口（动画可关、阴影用纯色替代、blur 类效果降级为半透明）；重组件（Swiper/DatetimePicker）提供 lite 版本。
- 度量：组件库引入后的页面体积增量（按使用组件清单计算）、首屏组件挂载耗时；组件库升级要做体积 diff 报告（防止"顺手升级"体积暴涨）。

```javascript
// 组件级按需加载（移动端组件库接入侧）
const lazyComponents = {
  DatetimePicker: () => import('ui/lib/picker'),     // 重组件动态加载
  Calendar: () => import('ui/lib/calendar'),
  SwiperLite: () => import('ui/lib/swiper-lite'),    // 低端机 lite 版
};
function pickSwiper(tier) {
  return tier === 'low' ? lazyComponents.SwiperLite : lazyComponents.Swiper;
}
// 体积增量计算（CI 报告）
function bundleImpact(usedComponents, manifest) {
  const total = usedComponents.reduce((s, c) => s + manifest[c].jsKB + manifest[c].cssKB, 0);
  return { totalKB: +total.toFixed(1),
    verdict: total > 150 ? 'over-budget: 考虑按需或 lite 版' : 'ok' };
}
```
