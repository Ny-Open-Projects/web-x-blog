## PER-743：手写一个页面冻结恢复处理器：页面生命周期（frozen/resumed）下的状态保存与资源挂起

**答**：
- 生命周期：现代浏览器引入 `frozen`（页面冻结，定时器/请求暂停）与 `resumed` 事件——冻结前要保存关键状态（表单草稿/播放进度），冻结期间不能假设任何任务会跑。
- 实现：`document.addEventListener('freeze')` 前用 `visibilitychange`（hidden）做最后保存窗口；resumed 时恢复资源、重连长连接、刷新可能过期的数据；冻结期间的定时器任务改为 resumed 后补跑（记录期望执行时间）。
- 要点：hidden 不是 frozen（hidden 可能短暂，frozen 是系统决策）；补跑任务要幂等（冻结时长不可控）；WebSocket/轮询在 resumed 后重连带退避。
- 边界：iOS 无 freeze 事件，用 visibilitychange + pagehide 近似；补跑风暴（大量积压任务）要限流。
- 评分点：补跑幂等与限流。

```javascript

class FreezeHandler {
  constructor() {
    this.pendingTasks = [];                                     // 冻结期积压任务
    document.addEventListener('visibilitychange', () => {
      if (document.visibilityState === 'hidden') this.onHidden();
      else this.onResumed();
    });
    document.addEventListener('freeze', () => this.onFrozen()); // Chrome 专有
    document.addEventListener('resumed', () => this.onResumed());
  }
  onHidden() {
    this.hiddenAt = Date.now();
    saveCriticalState();                                        // 最后保存窗口
  }
  onFrozen() { /* 系统冻结前最后时机：flush 上报 */ navigator.sendBeacon?.('/freeze', ''); }
  onResumed() {
    const awayMs = Date.now() - (this.hiddenAt ?? Date.now());
    reconnectWS({ backoff: true });                             // 重连长连接
    if (awayMs > 60000) refreshStaleData();                     // 数据过期刷新
    this.drainPending(awayMs);                                  // 补跑积压（限流）
  }
  scheduleDuringFreeze(fn, expectedAt) {                        // 冻结期任务登记
    this.pendingTasks.push({ fn, expectedAt });
  }
  async drainPending(awayMs) {                                  // 补跑：幂等 + 限流
    const due = this.pendingTasks.filter(t => t.expectedAt <= Date.now());
    this.pendingTasks = this.pendingTasks.filter(t => t.expectedAt > Date.now());
    for (const t of due) {
      try { await t.fn(); } catch {}                            // 幂等任务失败可弃
      await sleep(200);                                         // 限流防补跑风暴
    }
  }
}
```
