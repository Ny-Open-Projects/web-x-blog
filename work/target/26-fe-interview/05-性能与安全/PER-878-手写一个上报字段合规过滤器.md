## PER-878：手写一个上报字段合规过滤器：白名单裁剪、位置类脱敏与审计日志

**答**：
- 需求：实现 complianceFilter(payload, {allowlist, consent})：允许的字段按类型校验后保留；字符串字段执行位置类脱敏（IP 保留前两段、坐标保留 2 位小数、手机号掩码）；未允许字段记入审计日志（字段名+原因）并丢弃；consent 为 false 时返回空对象且整包标记 blocked。
- 边界：嵌套对象递归脱敏（保留结构）；数组元素逐个处理；审计日志容量上限（100 条，LRU 丢弃旧）。
- 评分点：递归脱敏；掩码格式正确；审计 LRU。

```javascript
function complianceFilter(payload, { allowlist, consent }) {
  const audit = makeAuditLRU(100);
  if (!consent) { audit.log({ blocked: true }); return { data: {}, blocked: true }; }
  const mask = {
    ip: s => s.split('.').slice(0, 2).join('.') + '.*.*',
    coord: n => +Number(n).toFixed(2),
    phone: s => s.replace(/(\d{3})\d{4}(\d{4})/, '$1****$2'),
  };
  function clean(v) {                                          // 递归脱敏
    if (typeof v === 'string') {
      if (/^\d{1,3}(\.\d{1,3}){3}$/.test(v)) return mask.ip(v);
      if (/^1\d{10}$/.test(v)) return mask.phone(v);
      return v;
    }
    if (typeof v === 'number' && Math.abs(v) > 10) return mask.coord(v);   // 疑似坐标
    if (Array.isArray(v)) return v.map(clean);
    if (v && typeof v === 'object')
      return Object.fromEntries(Object.entries(v).map(([k, x]) => [k, clean(x)]));
    return v;
  }
  const data = {};
  for (const [k, v] of Object.entries(payload)) {
    if (allowlist.includes(k)) data[k] = clean(v);
    else audit.log({ field: k, reason: 'not-allowlisted' });   // 审计
  }
  return { data, blocked: false, audit: audit.dump() };
}
function makeAuditLRU(max) {
  const buf = [];
  return { log: e => { buf.push({ t: Date.now(), ...e }); if (buf.length > max) buf.shift(); },
    dump: () => [...buf] };
}
```
