## PER-822：手写一个内存水位降级控制器：水位分档、降级动作分级与滞回恢复

**答**：
- 需求：输入 heap 使用率序列，控制器输出每时刻的动作等级：> 85% → L3（精简版）；> 75% → L2（缩缓存）；> 60% → L1（关动效）；否则 L0。升级立即生效；降级需低于当前档阈值再留 10% 余量（滞回）且距上次变更 >= 30 秒，逐级下降。
- 边界：水线附近抖动不产生动作（滞回保证）；从未进入过的档不能直接跳降两级。
- 评分点：滞回恢复正确；逐级下降；30 秒冷却。

```javascript
function createMemoryGovernor({ L = [0.6, 0.75, 0.85], hyst = 0.1, coolMs = 30000 } = {}) {
  let state = 0, last = 0;
  return function tick(ratio, now) {
    const up = ratio > L[2] ? 3 : ratio > L[1] ? 2 : ratio > L[0] ? 1 : 0;
    if (up > state) {                       // 升级：立即逐级升到目标
      state = up; last = now;
      return { state, action: ACTIONS[state] };
    }
    if (up < state && now - last >= coolMs) {
      const recoverLine = L[state - 1] - hyst;      // 滞回余量
      if (ratio < recoverLine) {            // 逐级降一档
        state--; last = now;
        return { state, action: ACTIONS[state] };
      }
    }
    return { state, action: null };         // 无动作
  };
}
const ACTIONS = ['normal', 'off-effects', 'shrink-cache', 'lite-page'];
// 序列 [0.5, 0.9, 0.7, 0.5] → normal, L3, (0.7<0.75 但冷却不足无动作), L2/L1 视冷却
```
