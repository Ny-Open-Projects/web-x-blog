## PER-1013：手写一个渲染阶段探针：标记每帧走的管线深度

**答**：
- 需求：实现 probeFrames(ms)。在 ms 时间内用 rAF 每帧采样，记录该帧是否发生 layout（读 document.body.offsetHeight 前后对比脏标记——用 PerformanceObserver layout-shift 不适用，改用：注册 MutationObserver 监听 style 变化 + 在帧内读取 offsetWidth 触发检测）、是否 paint（利用 PerformanceObserver paint entry）。输出帧统计 { frames, layoutFrames, paintFrames }。
- 边界：ms 为 0 返回空统计；探针自身读写不得计入（读操作前先判断当前帧已统计）；页面隐藏时提前结束。
- 评分点：帧循环统计；脏标记检测；paint 观测；终止条件

```javascript
function probeFrames(ms = 1000) {
  return new Promise(resolve => {
    let frames = 0, layoutFrames = 0, paintFrames = 0;
    let dirty = false;
    const mo = new MutationObserver(() => dirty = true);
    mo.observe(document.body, { attributes: true, subtree: true, attributeFilter: ['style', 'class'] });
    const po = new PerformanceObserver(list =>
      list.getEntries().forEach(e => { if (e.name === 'paint') paintFrames++; }));
    po.observe({ type: 'paint', buffered: true });
    const end = performance.now() + ms;
    function frame() {
      if (performance.now() >= end || document.visibilityState === 'hidden') {
        mo.disconnect(); po.disconnect();
        return resolve({ frames, layoutFrames, paintFrames });
      }
      frames++;
      if (dirty) { void document.body.offsetWidth; layoutFrames++; dirty = false; }
      requestAnimationFrame(frame);
    }
    requestAnimationFrame(frame);
  });
}
```
