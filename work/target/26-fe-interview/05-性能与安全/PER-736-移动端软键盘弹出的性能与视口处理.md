## PER-736：移动端软键盘弹出的性能与视口处理：键盘顶起布局、visualViewport 监听与输入流畅性

**答**：
- 键盘行为三派：iOS（视口缩小，visualViewport 变化）、Android（resize 或 overlap 取决于 windowSoftInputMode）、桌面忽略——适配统一走 **VisualViewport API**（resize/scroll 事件拿真实可视区）。
- 性能要点：viewport resize 回调节流（键盘动画期高频触发，rAF 对齐）；键盘弹起时避免同步读 layout（offsetTop 链式读取）；输入框聚焦时 `scrollIntoView` 由浏览器做，手动滚动计算要等 viewport 事件后。
- 交互治理：键盘弹起时暂停重动画（视频/粒子降帧）、fixed 底部栏跟随 viewport 而不是 fixed（iOS fixed 在键盘期错位）、失焦收起时恢复。
- 度量：聚焦->输入可用延迟（focus 到 compositionstart）、键盘动画期间掉帧。

```javascript

const keyboardPerf = {
  unify: '三派行为统一走 VisualViewport API（resize/scroll 事件）',
  perf: ['viewport 回调 rAF 节流', '键盘期暂停重动画', '底部栏跟随 viewport 不用 fixed',
    '避免键盘期同步读 layout'],
  metrics: ['focus->输入可用延迟', '键盘动画期掉帧率'],
};
function keyboardAdapter(bottomBar, { onFocusPause } = {}) {
  const vv = window.visualViewport;
  if (!vv) return;
  let ticking = false;
  const layout = () => {
    ticking = false;
    const kbHeight = innerHeight - vv.height - vv.offsetTop;    // 键盘占用高度
    bottomBar.style.transform = `translateY(${-kbHeight}px)`;   // transform 跟随
    bottomBar.style.position = 'fixed';
    bottomBar.style.bottom = '0';
  };
  vv.addEventListener('resize', () => {
    if (!ticking) { ticking = true; requestAnimationFrame(layout); }
    onFocusPause?.(kbHeight > 100);                             // 键盘期暂停重动画
  });
  vv.addEventListener('scroll', layout, { passive: true });
}
```
