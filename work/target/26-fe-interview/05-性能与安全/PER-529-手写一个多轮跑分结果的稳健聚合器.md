## PER-529：手写一个多轮跑分结果的稳健聚合器：剔除异常样本后输出分位数，并给出可信度标注

**答**：
- 跑分样本总有离谱值（GC 卡顿、机器抖动），直接取分位数会被污染：先做**抗离群聚合**（IQR 法剔除 Q1-1.5IQR 以下、Q3+1.5IQR 以上的样本），再算分位数。
- 可信度标注：有效样本数 < 5 标 "low"，IQR 剔除比例 > 20% 标 "unstable"，两者都正常标 "solid"——下游（门禁/报告）根据可信度决定是否强拦。
- 边界：样本全被剔除时要返回失败而不是硬凑数字；分位数计算对已排序数组用线性插值。
- 评分点：IQR 剔除与可信度分级是否完整。

```javascript

function robustAggregate(samples) {
  const a = samples.filter(Number.isFinite).sort((x, y) => x - y);
  if (a.length < 3) return { verdict: 'fail', reason: '有效样本不足' };
  const q = p => { const i = (a.length - 1) * p, lo = Math.floor(i);
    return a[lo] + (a[Math.min(lo + 1, a.length - 1)] - a[lo]) * (i - lo); };
  const q1 = q(0.25), q3 = q(0.75), iqr = q3 - q1;
  const lo = q1 - 1.5 * iqr, hi = q3 + 1.5 * iqr;
  const kept = a.filter(v => v >= lo && v <= hi);              // IQR 抗离群
  const dropRatio = 1 - kept.length / a.length;
  if (!kept.length) return { verdict: 'fail', reason: '全部样本被判离群，环境异常' };
  const kp = p => { const i = (kept.length - 1) * p, l = Math.floor(i);
    return kept[l] + (kept[Math.min(l + 1, kept.length - 1)] - kept[l]) * (i - l); };
  const confidence = kept.length < 5 ? 'low'
    : dropRatio > 0.2 ? 'unstable' : 'solid';
  return { p50: Math.round(kp(0.5)), p75: Math.round(kp(0.75)), p95: Math.round(kp(0.95)),
    dropped: a.length - kept.length, confidence };
}
console.log(robustAggregate([2100, 2150, 2200, 2260, 9000, 2180]));
```
