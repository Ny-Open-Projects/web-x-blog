## PER-1050：上传大文件的优化：分片、并发与秒传

**答**：
- 分片上传：切片（如 5MB）并行上传（限 3 并发），服务端聚合；失败只重传单片。
- 秒传：先算文件哈希（Worker 分块 sha256）查询服务端已有文件，命中直接建引用。
- 断点续传：记录已传分片序号，恢复时跳过；分片哈希校验防错序。
- 体验：进度聚合（单片进度加权）、暂停/恢复、弱网自动降并发。

```javascript
async function uploadFile(file, { chunkSize = 5 * 1024 * 1024, onProgress } = {}) {
  const total = Math.ceil(file.size / chunkSize);
  const hash = await hashFile(file);                    // Worker 分块哈希
  const exist = await fetch(`/upload/exist?hash=${hash}`).then(r => r.json());
  if (exist.found) return { url: exist.url, dedupe: true };   // 秒传
  const uploaded = new Set(exist.uploaded ?? []);       // 续传
  for (let i = 0; i < total; i += 3) {                  // 3 并发
    const batch = [...Array(3)].map((_, k) => i + k).filter(k => k < total && !uploaded.has(k));
    await Promise.all(batch.map(async k => {
      const blob = file.slice(k * chunkSize, (k + 1) * chunkSize);
      await fetch('/upload/chunk', { method: 'POST',
        body: form({ idx: k, hash, blob }) });
      uploaded.add(k); onProgress?.(uploaded.size / total);
    }));
  }
  return fetch('/upload/merge', { method: 'POST', body: JSON.stringify({ hash, total }) });
}
```
