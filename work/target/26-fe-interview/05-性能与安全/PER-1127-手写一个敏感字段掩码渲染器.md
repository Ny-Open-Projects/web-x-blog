## PER-1127：手写一个敏感字段掩码渲染器

**答**：
- 需求：实现 maskField(type, value)。规则：phone 前 3 后 4；idCard 前 3 后 4 中间 11 星；bankCard 后 4；name：<=1 全掩码，2 姓保留，>=3 保留首尾；email 用户名保留首 2 字符（不足全掩）+ 域名保留；未知类型全掩码（长度保留，>6 用 6 个星）。
- 边界：空值返回空；非字符串先转字符串；掩码字符固定 *；长度不足时按实际长度掩。
- 评分点：各类型规则；长度不足兜底；email 拆分；未知类型

```javascript
function maskField(type, value) {
  const v = String(value ?? '');
  if (!v) return '';
  const stars = n => '*'.repeat(n);
  switch (type) {
    case 'phone': return v.length < 7 ? stars(v.length)
      : v.slice(0, 3) + stars(v.length - 7) + v.slice(-4);
    case 'idCard': return v.length < 15 ? stars(v.length)
      : v.slice(0, 3) + stars(11) + v.slice(-4);
    case 'bankCard': return v.length < 4 ? stars(v.length)
      : stars(v.length - 4) + v.slice(-4);
    case 'name': return v.length === 1 ? stars(1)
      : v.length === 2 ? v[0] + stars(1)
      : v[0] + stars(v.length - 2) + v[v.length - 1];
    case 'email': {
      const [user, domain] = v.split('@');
      if (!domain) return stars(Math.min(6, v.length));
      const head = user.slice(0, 2) + stars(Math.max(0, user.length - 2));
      return `${head}@${domain}`;
    }
    default: return stars(Math.min(6, v.length));
  }
}
```
