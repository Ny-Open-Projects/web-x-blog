## PER-561：手写一个监控上报的分层采样器：按路由权重、用户档位与指标类型组合决定是否上报

**答**：
- 全量上报成本不可承受，采样要**分指标分层**：错误类低采样高保真（错误重要，采样率 100% 或按错误指纹去重上报）、性能类按会话采样（20%）、诊断类按需触发（命中异常才追加采集）。
- 要点：采样决策要在会话开始时定死（会话级一致性），中途改变会破坏指标分布；采样率配置从服务端下发支持热调。
- 边界：采样标签要随数据上报（`sampled: true/false` 且只上报命中的），服务端聚合时才能正确还原全量估算；加权还原公式要文档化。
- 评分点：会话级采样决策与采样率随数据上报。

```javascript

class Sampler {
  constructor(remoteConfig) {
    this.cfg = null;
    remoteConfig.then(c => this.cfg = c);            // 服务端热下发
    // 会话级采样决策：一次会话只掷一次骰子
    this.sessionHit = Math.random() < (this.cfg?.sessionRate ?? 0.2);
  }
  shouldReport(type, meta = {}) {
    const c = this.cfg ?? { error: 1, perf: 0.2, diag: 0 };
    let rate;
    switch (type) {
      case 'error': rate = c.error; break;            // 错误类保真
      case 'perf':  rate = this.sessionHit ? 1 : 0; break; // 性能类跟会话
      case 'diag':  rate = meta.anomaly ? 1 : c.diag; break; // 异常触发追加采集
      default: rate = 0;
    }
    return Math.random() < rate;
  }
  report(type, payload) {
    if (!this.shouldReport(type, payload)) return;
    navigator.sendBeacon('/collect', JSON.stringify({
      type, ...payload, sampleRate: this.cfg?.sessionRate ?? 0.2, // 采样率随数据走
    }));
  }
}
```
