## PER-1130：手写一个越权测试用例矩阵生成器

**答**：
- 需求：实现 genAuthzMatrix(resources, roles)。resources 为 [{ id, actions: [read, write, delete], level }]；roles 为 [{ name, allowed: { resourceId: [actions] } }]；输出矩阵 { rows: [资源], cols: [角色], cells: allow/deny }，并输出用例列表：每个 deny 单元生成一条越权测试（角色以低权身份调用该资源动作，预期 403）。
- 边界：allowed 缺资源默认全 deny；actions 缺失按空数组；用例含 method 映射（read→GET，write/delete→POST/DELETE）。
- 评分点：矩阵生成；deny→用例；method 映射；默认 deny

```javascript
function genAuthzMatrix(resources, roles) {
  const METHOD = { read: 'GET', write: 'POST', delete: 'DELETE' };
  const cells = [], cases = [];
  for (const r of resources)
    for (const role of roles) {
      const allowed = role.allowed[r.id] ?? [];
      for (const a of r.actions) {
        const ok = allowed.includes(a);
        cells.push({ resource: r.id, role: role.name, action: a,
          cell: ok ? 'allow' : 'deny' });
        if (!ok) cases.push({ name: `越权:${role.name}#${r.id}:${a}`,
          req: { method: METHOD[a] ?? 'POST', path: `/api/${r.id}`,
            auth: role.fakeToken ?? `token:${role.name}` },
          expect: 403 });
      }
    }
  return { rows: resources.map(r => r.id), cols: roles.map(x => x.name),
    cells, cases };
}
```
