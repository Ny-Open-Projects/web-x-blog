## PER-950：手写一个 P75 计算器：支持增量插入与合并（可合并草图）

**答**：
- 需求：实现 P75Sketch 类：add(v) 插入、merge(other) 合并另一个草图、p(q) 取分位数（线性插值），内存不随样本数线性增长。
- 边界：v 必须为有限正数（NaN/负数丢弃并计数）；空草图 p() 返回 null；merge 后计数正确累加。
- 评分点：桶直方图设计；非法值过滤；合并正确性；分位扫描

```javascript
class P75Sketch {
  constructor(bin = 100) { this.bin = bin; this.bins = new Map();
    this.n = 0; this.bad = 0; }
  add(v) {
    if (!Number.isFinite(v) || v < 0) { this.bad++; return; }
    const b = Math.floor(v / this.bin);
    this.bins.set(b, (this.bins.get(b) ?? 0) + 1); this.n++;
  }
  merge(o) {
    if (this.bin !== o.bin) throw new Error('bin 不一致不可合并');
    for (const [b, c] of o.bins) this.bins.set(b, (this.bins.get(b) ?? 0) + c);
    this.n += o.n; this.bad += o.bad;
  }
  p(q) {
    if (!this.n) return null;
    const keys = [...this.bins.keys()].sort((a, b) => a - b);
    let acc = 0;
    for (const b of keys) {
      acc += this.bins.get(b);
      if (acc >= this.n * q) return (b + 1) * this.bin;   // 桶上界近似
    }
    return keys[keys.length - 1] * this.bin + this.bin;
  }
}
```
