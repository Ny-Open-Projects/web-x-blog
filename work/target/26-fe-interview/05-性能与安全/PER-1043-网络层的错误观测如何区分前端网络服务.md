## PER-1043：网络层的错误观测：如何区分前端/网络/服务端故障

**答**：
- 分类信号：DNS 失败、连接失败、超时、5xx、4xx——各自对应责任方；fetch 只有笼统的 TypeError，需要细化。
- 手段：Beacon 上报 failure 原因码（error.type），resource timing 的 responseStatus 与 duration 辅助；网关日志关联 traceId。
- 聚合分析：按错误类型×网络类型×地域聚合，找出"某省 4G 用户 DNS 失败率高"这类结构性故障。
- 联动：网络层故障率异常时自动触发弱网策略与降级，而不是等用户投诉。

```javascript
// fetch 包装：错误分类
async function robustFetch(url, init, { timeout = 8000 } = {}) {
  const c = AbortSignal.timeout(timeout);
  try {
    const r = await fetch(url, { ...init, signal: c });
    if (!r.ok) {
      const kind = r.status >= 500 ? 'server' : 'client';
      report({ type: 'req-fail', kind, status: r.status, url: sanitizeUrl(url) });
      throw Object.assign(new Error(kind), { status: r.status });
    }
    return r;
  } catch (e) {
    if (e.name === 'TimeoutError') report({ type: 'req-fail', kind: 'timeout', url: sanitizeUrl(url) });
    else report({ type: 'req-fail', kind: 'network', msg: e.message });
    throw e;
  }
}
```
