## PER-530：如何测试弱网下的前端体验？弱网测试要覆盖哪几档网络与哪几类异常？

**答**：
- 网络档位四档：离线、极慢（Slow 2G/50kbps）、弱网（Fast 3G/1.6Mbps）、抖动网（延迟/丢包随机的 4G）——只测固定慢速会漏掉"时好时坏"的真实体验问题。
- 异常类型五类：超时、5xx、4xx、断流（请求发出后中断）、慢响应（30 秒才返回）——每类对应前端不同的正确行为（重试/降级/骨架屏/可取消）。
- 重点测的是交互路径而不是首屏：弱网下提交订单会不会重复提交？请求取消逻辑是否生效（切页后旧请求还在占带宽）？超时提示是否可恢复？
- 工具组合：DevTools 网络节流做粗筛 + Service Worker 注入做剧本化故障（见注入工具）+ 真机弱网仪（Network Link Conditioner/手机开发者选项）做验收。

```javascript

// 弱网剧本清单：自动化驱动 DevTools 节流 + 断言前端行为
const scenarios = [
  { name: 'slow-3g', cdp: { latency: 400, down: 1.6 * 1024 * 1024 / 8 }, expect: 'skeleton<300ms' },
  { name: 'timeout', patch: { url: /api\/list/, delayMs: 35000 }, expect: 'manual-retry-ui' },
  { name: '5xx',     patch: { url: /api\/list/, status: 500 }, expect: 'fallback-data' },
  { name: 'abort',   flow: 'click-item-then-back', expect: 'request-cancelled' }, // 切页取消旧请求
];
async function runScenario(page, s) {
  if (s.cdp) {
    const cdp = await page.createCDPSession();
    await cdp.send('Network.emulateNetworkConditions',
      { offline: false, latency: s.cdp.latency, downloadThroughput: s.cdp.down, uploadThroughput: 750 * 1024 / 8 });
  }
  await page.goto('https://example.com/list');
  return s.expect; // 每个剧本对应一条断言：骨架屏出现时机/降级文案/请求取消日志
}
// 弱网测试的价值不在"跑得完"，而在断言降级路径是否符合设计
```
