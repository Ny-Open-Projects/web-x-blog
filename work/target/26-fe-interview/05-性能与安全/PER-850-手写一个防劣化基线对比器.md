## PER-850：手写一个防劣化基线对比器：每次发版对比核心性能指标基线并输出劣化项

**答**：
- 需求：实现 baselineDiff(current, baseline, rules)：rules 描述每指标的允许劣化（如 fsP75 允许 +5%、whiteRate 绝对值 +0.3pp）；按设备档分层对比（每档独立判定）；输出劣化项列表（指标/档/当前/基线/超预算量）与 overall（pass/block）；无基线的新指标输出 new-metric。
- 边界：样本量不足的档输出 insufficient 不参与 block 判定；多档劣化只 block 一次但列出全部劣化档；规则支持相对与绝对两种阈值。
- 评分点：相对/绝对阈值双支持；分层判定；block 收敛。

```javascript
function baselineDiff(current, baseline, rules, { minSample = 300 } = {}) {
  const regressions = [], notes = [];
  for (const r of rules) {
    for (const tier of Object.keys(current[r.metric] || {})) {
      const c = current[r.metric][tier], b = baseline[r.metric]?.[tier];
      if (!b) { notes.push({ metric: r.metric, tier, note: 'new-metric' }); continue; }
      if (c.sample < minSample || b.sample < minSample) {
        notes.push({ metric: r.metric, tier, note: 'insufficient' }); continue;
      }
      const allowed = r.abs != null ? r.abs : b.value * r.rel;   // 绝对或相对阈值
      const worse = r.lowerIsBetter ? (b.value - c.value) > allowed
                                    : (c.value - b.value) > allowed;
      if (worse) regressions.push({ metric: r.metric, tier,
        now: c.value, base: b.value, over: +(c.value - b.value).toFixed(4) });
    }
  }
  return { overall: regressions.length ? 'block' : 'pass',
    regressions, notes };
}
// rules 例：[{metric:'fsP75', rel:0.05, lowerIsBetter:true},
//            {metric:'whiteRate', abs:0.003, lowerIsBetter:true}]
```
