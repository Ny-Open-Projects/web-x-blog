## PER-826：手写一个采样偏差修正计算器：按分档加权把样本分布修正回真实设备分布

**答**：
- 需求：输入样本 [{tier, metric}] 与真实设备分布 {tier: ratio}，实现：① 输出各档样本占比与真实占比的偏差；② 计算加权修正后的均值与 p75（p75 用加权分位数：累计权重达到 75% 的值）；③ 样本占比为 0 的档输出无样本警告。
- 边界：权重 = 真实占比 / 样本占比；加权 p75 需先按值排序再累计权重；真实分布总和不等于 1 时归一化处理。
- 评分点：加权分位数实现；零样本档警告；分布归一化。

```javascript
function biasCorrector(samples, trueDistRaw) {
  const sumR = Object.values(trueDistRaw).reduce((a, b) => a + b, 0);
  const trueDist = Object.fromEntries(                       // 真实分布归一化
    Object.entries(trueDistRaw).map(([k, v]) => [k, v / sumR]));
  const byTier = {};
  for (const s of samples) (byTier[s.tier] ??= []).push(s.metric);
  const total = samples.length;
  const diag = {};
  for (const t of Object.keys(trueDist)) {
    const arr = byTier[t] || [];
    diag[t] = { sampleRatio: total ? arr.length / total : 0, trueRatio: trueDist[t],
      warn: arr.length === 0 ? 'no-sample' : null };
  }
  const items = [];
  for (const [t, arr] of Object.entries(byTier)) {
    const w = diag[t].sampleRatio > 0 ? trueDist[t] / diag[t].sampleRatio : 0;
    arr.forEach(v => items.push({ v, w }));
  }
  items.sort((a, b) => a.v - b.v);
  const sumW = items.reduce((s, x) => s + x.w, 0);
  let acc = 0, wp75 = null;
  for (const it of items) { acc += it.w; if (wp75 === null && acc >= sumW * 0.75) wp75 = it.v; }
  return {
    diag,
    correctedMean: items.reduce((s, x) => s + x.v * x.w, 0) / sumW,
    weightedP75: wp75,
    rawMean: total ? samples.reduce((s, x) => s + x.metric, 0) / total : null,
  };
}
```
