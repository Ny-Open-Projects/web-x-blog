## PER-1182：如何实现"隐私测试"进自动化测试体系

**答**：
- 测试类型：单元（脱敏函数正确性）、集成（同意关闭后 SDK 不上报）、E2E（撤回流程端到端）、抓包（上报内容无明文敏感值）。
- 接入：隐私用例与功能用例同池跑，CI 门禁含隐私断言。
- 工具：Playwright 拦截网络请求断言上报体、固定同意状态夹具（同意/拒绝两种场景各跑一遍）。
- 防退化：任何采集行为变更必须带对应隐私测试更新。

```javascript
// 同意状态的 E2E 断言
test('拒绝 analytics 后无分析上报', async ({ page }) => {
  await setConsent(page, { analytics: false });
  const beacons = [];
  page.on('request', r => beacons.push(r.url()));
  await page.goto('/product');
  await page.waitForTimeout(2000);
  const analytics = beacons.filter(u => u.includes('analytics.vendor'));
  expect(analytics).toEqual([]);                  // 必须为 0
});
test('同意后字段最小化', async ({ page }) => {
  await setConsent(page, { analytics: true });
  const body = await captureReportBody(page);
  expect(Object.keys(body)).toEqual(expect.arrayContaining(['page', 'metrics']));
  expect(body).not.toHaveProperty('uid_raw');     // 无明文 uid
});
```
