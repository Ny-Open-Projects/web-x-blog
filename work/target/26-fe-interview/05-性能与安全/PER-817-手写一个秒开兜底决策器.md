## PER-817：手写一个秒开兜底决策器：按超预算段与设备档输出兜底动作

**答**：
- 需求：输入 {segs: {load, data, render}, tier, net, flags}，按决策表输出动作列表（可多选）：load 超且 net 非 weak → 用缓存页；data 超 → 骨架+分步；render 且 tier=low → 精简版；net=weak → 全部图片降档。输出需含每条动作的触发原因，动作优先级排序（缓存页 > 精简版 > 骨架）。
- 边界：flags 为 false 的手段永不输出；动作去重；无可触发条件输出空数组。
- 评分点：多条件并行判断；原因随动作输出；优先级排序。

```javascript
function decideFallback({ segs, tier, net, flags }) {
  const rules = [
    { when: s => s.load > 500 && net !== 'weak' && flags.cachePage,
      action: 'cached-page', pri: 1, why: `load ${segs.load}ms 超预算` },
    { when: () => tier === 'low' && flags.litePage,
      action: 'lite-page', pri: 2, why: `低端机 ${tier}` },
    { when: s => s.data > 800 && flags.skeleton,
      action: 'skeleton+step', pri: 3, why: `data ${segs.data}ms 超预算` },
    { when: () => net === 'weak' && flags.imgDegrade,
      action: 'img-tier-down', pri: 4, why: `弱网 ${net}` },
  ];
  const actions = rules.filter(r => r.when(segs))
    .sort((a, b) => a.pri - b.pri)
    .map(({ action, why }) => ({ action, why }));
  const seen = new Set();
  return actions.filter(a => !seen.has(a.action) && seen.add(a.action));   // 去重
}
```
