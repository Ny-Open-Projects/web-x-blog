## PER-1132：手写一个安全响应头校验器

**答**：
- 需求：实现 headerAudit(headers)。headers 为响应头对象；检查项与权重：HSTS（max-age≥31536000，10）、nosniff（5）、frame-ancestors 或 XFO（10）、CSP 含 script-src（20）、Referrer-Policy（5）、cookie Secure+HttpOnly+SameSite（15）、无 Server 版本泄露（5）；输出 { score, max, fails }。
- 边界：多 cookie 任一缺属性即 fail 该项；HSTS 含 includeSubDomains 加分但不影响 pass；未知头忽略；headers 大小写不敏感读取。
- 评分点：大小写归一；权重打分；多 cookie 全查；fails 列表

```javascript
function headerAudit(headers) {
  const h = Object.fromEntries(Object.entries(headers)
    .map(([k, v]) => [k.toLowerCase(), v]));
  const CHECKS = [
    { id: 'hsts', w: 10, test: () =>
      +(/max-age=(\d+)/.exec(h['strict-transport-security'] ?? '') ?? [])[1] >= 31536000 },
    { id: 'nosniff', w: 5, test: () => h['x-content-type-options'] === 'nosniff' },
    { id: 'framing', w: 10, test: () =>
      (h['content-security-policy'] ?? '').includes('frame-ancestors') ||
      !!h['x-frame-options'] },
    { id: 'csp', w: 20, test: () =>
      (h['content-security-policy'] ?? '').includes('script-src') },
    { id: 'referrer', w: 5, test: () => !!h['referrer-policy'] },
    { id: 'cookie', w: 15, test: () => {
      const cs = [].concat(h['set-cookie'] ?? []);
      return cs.every(c => c.includes('Secure') && c.includes('HttpOnly')
        && /samesite=(strict|lax)/i.test(c)); } },
    { id: 'server', w: 5, test: () =>
      !(h['server'] ?? '').includes('/') },               // 不暴露版本
  ];
  const max = CHECKS.reduce((s, c) => s + c.w, 0);
  const fails = CHECKS.filter(c => !c.test()).map(c => c.id);
  return { score: max - fails.reduce((s, f) =>
    s + CHECKS.find(c => c.id === f).w, 0), max, fails };
}
```
