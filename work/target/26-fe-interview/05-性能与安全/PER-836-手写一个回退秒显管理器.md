## PER-836：手写一个回退秒显管理器：页面快照与缓存数据双通道实现回退零等待

**答**：
- 需求：实现 BackInstantManager：register(route, { fetchData, render, maxAge })；leave 时自动快照（数据+滚动位置）；enter 时：有快照且未过期（maxAge）→ 先渲染快照并后台 revalidate（数据到达后若版本不同则回调更新）；无快照或过期 → 正常加载但保留骨架。提供 invalidate(route) 强制失效。
- 边界：后台刷新中再次 enter 不重复请求（in-flight 去重）；快照容量上限（LRU 5 个页面）；render 抛错不影响缓存流程。
- 评分点：in-flight 去重；LRU 容量；revalidate 版本比对。

```javascript
class BackInstantManager {
  constructor({ maxPages = 5 } = {}) { this.cache = new Map(); this.inflight = new Map(); this.max = maxPages; }
  register(route, { fetchData, render, maxAge = 30000 }) {
    this.cache.get(route)?.snap;             // 触发 LR U 顺序
    this.cache.set(route, { ...this.cache.get(route), fetchData, render, maxAge });
  }
  async enter(route) {
    const e = this.cache.get(route);
    if (e?.snap && Date.now() - e.snap.ts < e.maxAge) {
      e.render(e.snap.data); scrollTo(0, e.snap.scrollTop);        // 秒显
      if (!this.inflight.has(route)) {                               // in-flight 去重
        this.inflight.set(route, true);
        try {
          const fresh = await e.fetchData();
          if (fresh.version !== e.snap.data.version) e.render(fresh);
          this.cache.set(route, { ...e, snap: { data: fresh, scrollTop: e.snap.scrollTop, ts: Date.now() } });
        } finally { this.inflight.delete(route); }
      }
    } else { e.render(null); }                                       // 无快照走骨架
  }
  leave(route, { data, scrollTop }) {
    const e = this.cache.get(route);
    this.cache.set(route, { ...e, snap: { data, scrollTop, ts: Date.now() } });
    while (this.cache.size > this.max) {                             // LRU 淘汰最旧
      this.cache.delete(this.cache.keys().next().value);
    }
  }
  invalidate(route) { const e = this.cache.get(route); if (e) e.snap = null; }
}
```
