## PER-1010：手写一个长任务切片器：保证每片 < 50ms 且可取消

**答**：
- 需求：实现 chunkTask(items, fn, opts) 返回 Promise。opts: { chunkTime=40, onProgress, signal }；循环处理 items，当当前片耗时接近 chunkTime 时让出（scheduler.yield 或 setTimeout）；signal.aborted 时停止并 reject AbortError；onProgress(done, total) 每片回调。
- 边界：fn 抛错整个 Promise reject 并停止；空数组直接 resolve；signal 支持中途 abort（让出点检查）。
- 评分点：时间片判定；让出兼容；abort 检查点；进度回调

```javascript
async function chunkTask(items, fn, { chunkTime = 40, onProgress, signal } = {}) {
  if (signal?.aborted) throw new DOMException('aborted', 'AbortError');
  const total = items.length; let done = 0; let sliceStart = performance.now();
  for (const item of items) {
    try { fn(item); } catch (e) { throw e; }        // 抛错即终止
    done++;
    if (performance.now() - sliceStart >= chunkTime) {
      onProgress?.(done, total);
      if (signal?.aborted) throw new DOMException('aborted', 'AbortError');
      if (scheduler?.yield) await scheduler.yield();
      else await new Promise(r => setTimeout(r));
      sliceStart = performance.now();
    }
  }
  onProgress?.(done, total);
}
```
