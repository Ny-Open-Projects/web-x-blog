## PER-954：手写一个告警去抖器：滑动窗口内相同指纹只发一条

**答**：
- 需求：实现 Alerter 类：fire(fingerprint, payload)。同一指纹在 silenceMs 内重复触发只保留第一条（合并 count 与最近 payload）；窗口过期后再次触发重新告警；支持 flush() 返回当前待发告警列表（按首次触发时间排序）。
- 边界：payload 可能为 null；fingerprint 任意字符串；实例需支持多指纹并行；count 反映被合并次数 +1。
- 评分点：指纹合并；窗口过期清理；count 统计；排序输出

```javascript
class Alerter {
  constructor(silenceMs = 10 * 60_000) { this.silenceMs = silenceMs;
    this.pending = new Map(); }
  fire(fp, payload) {
    const now = Date.now();
    const old = this.pending.get(fp);
    if (old && now - old.firstTs < this.silenceMs) {
      old.count++; old.lastPayload = payload ?? old.lastPayload;
      old.lastTs = now;
    } else {
      this.pending.set(fp, { fingerprint: fp, firstTs: now, lastTs: now,
        count: 1, lastPayload: payload });
    }
  }
  flush() {
    const now = Date.now();
    const out = [];
    for (const [fp, a] of this.pending) {
      if (now - a.firstTs >= this.silenceMs) this.pending.delete(fp);
      else out.push(a);
    }
    return out.sort((a, b) => a.firstTs - b.firstTs);
  }
}
```
