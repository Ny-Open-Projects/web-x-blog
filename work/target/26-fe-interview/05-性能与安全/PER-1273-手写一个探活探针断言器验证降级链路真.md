## PER-1273：手写一个探活探针断言器：验证降级链路真的可用

**答**：
- 需求：implement degradeProbe(steps)。steps 为降级链 [{ name, action: () => Promise<status> }]；按序执行：第一个返回 status 为 ok 的环节生效；全部失败 -> 触发 onAllFail；输出 { active, results }（每步 status/耗时）；超时（3s）按 fail 处理。
- 边界：action 抛错按 fail；status 非 ok/fail 其他值按 fail；results 保留全部尝试记录。
- 评分点：链式探测；超时；异常归 fail；全败回调

```javascript
async function degradeProbe(steps, { timeout = 3000, onAllFail } = {}) {
  const results = []; let active = null;
  for (const s of steps) {
    const t0 = Date.now();
    let status = 'fail';
    try {
      status = await Promise.race([
        Promise.resolve(s.action()),
        new Promise((_, rej) => setTimeout(() => rej(new Error('timeout')), timeout)),
      ]);
    } catch { status = 'fail'; }
    if (status !== 'ok') status = 'fail';
    const r = { name: s.name, status, ms: Date.now() - t0 };
    results.push(r);
    if (status === 'ok') { active = s.name; break; }
  }
  if (!active) onAllFail?.(results);
  return { active, results };
}
```
