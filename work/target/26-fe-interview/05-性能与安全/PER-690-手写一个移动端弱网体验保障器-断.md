## PER-690：手写一个移动端弱网体验保障器：断网检测、离线队列与网络恢复同步的完整实现

**答**：
- 三件套：**断网检测**（online/offline 事件 + 实测心跳双信号，防止事件不准）；**离线队列**（写操作进 IndexedDB 队列，带幂等 id 与时间戳）；**恢复同步**（online 触发按序重放，指数退避重试，冲突以服务端为准并提示用户）。
- 要点：队列操作要幂等（服务端按 id 去重）；重放顺序保证（同资源操作按序，跨资源可并行）；队列上限与过期（超 24h 的操作提示用户手动确认）。
- 边界：offline 事件可能误报（连接着但不通），心跳验证才下结论；恢复瞬间的请求风暴要限流（队列重放并发 1~2）。
- 评分点：心跳双信号与重放限流。

```javascript

class OfflineGuard {
  constructor() { this.online = navigator.onLine; this.queue = []; this.replaying = false;
    addEventListener('online', () => this.probe());
    addEventListener('offline', () => { this.online = false; this.showOfflineUI(); });
    setInterval(() => this.probe(), 30000);                     // 心跳双信号
  }
  async probe() {                                               // 心跳验证防误报
    try {
      await fetch('/ping', { method: 'HEAD', cache: 'no-store', signal: AbortSignal.timeout(3000) });
      if (!this.online) { this.online = true; this.hideOfflineUI(); this.replay(); }
    } catch { this.online = false; this.showOfflineUI(); }
  }
  enqueue(op) {                                                 // 写操作入队（幂等 id）
    this.queue.push({ id: crypto.randomUUID(), op, ts: Date.now() });
    if (this.queue.length > 200) this.queue.shift();            // 上限
    this.persist();
    if (this.online) this.replay();
  }
  async replay() {                                              // 恢复同步，限流
    if (this.replaying || !this.online) return;
    this.replaying = true;
    try {
      while (this.queue.length) {
        const item = this.queue[0];
        if (Date.now() - item.ts > 86400e3) {                   // 过期操作提示确认
          promptUserConfirm(item); this.queue.shift(); continue;
        }
        await this.exec(item.op);                               // 服务端按 id 幂等去重
        this.queue.shift();
        await sleep(300);                                       // 重放限流防风暴
      }
    } finally { this.replaying = false; this.persist(); }
  }
}
```
