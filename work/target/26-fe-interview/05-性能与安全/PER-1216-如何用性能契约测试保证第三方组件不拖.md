## PER-1216：如何用"性能契约测试"保证第三方组件不拖累页面

**答**：
- 问题：业务组件/三方 SDK 接入后偷偷做同步布局/注册监听/发请求——性能契约测试锁定行为边界。
- 测试内容：挂载耗时预算、零强制布局断言（instrumented API）、网络请求白名单、监听器数量上限、GC 后 retained size 上限。
- 执行：组件单测环境注入性能探针（读写 hook + fetch stub），超契约即 fail。
- 价值：性能问题在组件入库时暴露，而不是上线后全页排查。

```javascript
// 性能契约测试骨架
function componentPerfContract(mount, { budgetMs = 16, netAllow = [] } = {}) {
  let layoutReads = 0, netCalls = [];
  hookReads(() => layoutReads++);
  stubFetch(u => netCalls.push(u));
  const t0 = performance.now();
  const un = mount();
  const dur = performance.now() - t0;
  un();
  const failures = [];
  if (dur > budgetMs) failures.push(`挂载 ${dur.toFixed(1)}ms > ${budgetMs}ms`);
  if (layoutReads > 0) failures.push(`挂载期强制布局 ${layoutReads} 次`);
  for (const u of netCalls)
    if (!netAllow.some(a => u.includes(a))) failures.push(`非法请求 ${u}`);
  return { pass: !failures.length, failures };
}
```
