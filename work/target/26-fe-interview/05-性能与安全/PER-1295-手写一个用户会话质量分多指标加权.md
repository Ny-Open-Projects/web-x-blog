## PER-1295：手写一个"用户会话质量分"（多指标加权）

**答**：
- 需求：implement sessionScore(session, weights)。session 为 { lcp, inp, cls, errCount, durationMin }；weights 默认 { lcp: 0.3, inp: 0.3, cls: 0.2, err: 0.2 }；每指标归一化到 0~1（阈值同 Chrome 口径，err 按 0 次=1 分每错 -0.2）；总分 = Σ 归一×权重 ×100；输出 { score, breakdown }。
- 边界：缺失指标权重重分配到剩余项；score 保留 1 位；errCount 超 5 按封顶 0。
- 评分点：线性归一；权重重分配；err 封顶；breakdown

```javascript
function sessionScore(session, weights = { lcp: 0.3, inp: 0.3, cls: 0.2, err: 0.2 }) {
  const norm = {
    lcp: v => v <= 2500 ? 1 : v >= 4000 ? 0 : (4000 - v) / 1500,
    inp: v => v <= 200 ? 1 : v >= 500 ? 0 : (500 - v) / 300,
    cls: v => v <= 0.1 ? 1 : v >= 0.25 ? 0 : (0.25 - v) / 0.15,
    err: n => Math.max(0, 1 - n * 0.2),
  };
  const parts = [];
  let wSum = 0;
  for (const [k, w] of Object.entries(weights)) {
    const val = k === 'err' ? session.errCount : session[k];
    if (val == null) continue;
    parts.push({ metric: k, n: norm[k](val), w });
    wSum += w;
  }
  if (!parts.length) return { score: null, breakdown: [] };
  const score = parts.reduce((s, p) => s + p.n * (p.w / wSum), 0) * 100;
  return { score: +score.toFixed(1),
    breakdown: parts.map(p => ({ ...p, n: +p.n.toFixed(2) })) };
}
```
