## PER-572：性能告警的动态基线怎么做？为什么固定阈值在流量波动站点必然误报？

**答**：
- 固定阈值的死穴：白天高峰 LCP 天然比凌晨慢 30%，固定 2.5s 阈值会在高峰误报、凌晨漏报；动态基线让阈值跟随正常波动范围。
- 基线构造：过去 7~14 天同时段同星期几"（hour-of-day × day-of-week 网格）的 p95 作为上界，当前窗口 p75 超过基线上界 10% 才算异动——既吸收周期性又吸收周末效应。
- 特殊日处理：节假日/大促要先打标剔除，否则污染基线（大促的慢会成为之后每天都误报的理由）。
- 基线质量守护：基线自身的数据量要求（每网格 > 1000 样本，不足时回退到更大网格）与漂移修正（基线滚动更新，新数据加权进入）。

```javascript

function dynamicBaseline(history, now, { lift = 0.1 } = {}) {
  const gridKey = (d) => {
    const t = new Date(d.ts);
    return `${t.getDay()}-${t.getHours()}`;                // 星期几-小时 网格
  };
  const byGrid = {};
  history.forEach(h => (byGrid[gridKey(h)] ??= []).push(h.lcp));
  const key = gridKey(now);
  let samples = byGrid[key] ?? [];
  if (samples.length < 1000)                              // 样本不足回退更大网格
    samples = history.filter(h => new Date(h.ts).getHours() === new Date(now.ts).getHours()).map(h => h.lcp);
  const sorted = samples.sort((a, b) => a - b);
  const p95 = sorted[Math.floor(sorted.length * 0.95)];
  return {
    baselineP95: Math.round(p95),
    alertLine: Math.round(p95 * (1 + lift)),               // 基线上浮 10% 为告警线
    currentP75: now.lcp,
    abnormal: now.lcp > p95 * (1 + lift),
    note: '节假日流量已从 history 中剔除打标',
  };
}
```
