## PER-748：手写一个虚拟列表滚动锚定器：顶部插入新数据时保持用户视觉位置（IM 场景）

**答**：
- 场景：IM/评论列表在顶部插入新消息时，用户停留在中部/底部——直接刷新会把内容顶下去；锚定原理：插入 N 条后，先按插入高度补偿 scrollTop（物理列表）或调整 offset（虚拟列表），保证可视内容不动。
- 要点：插入高度在渲染前估算（行高一致用 N×rowH，不一致要实测锚点元素位置差）；虚拟列表在数据替换时同步调整内部 offset 而不是 scrollTop（避免滚动跳动）；补偿要在同帧完成（插入与补偿之间不能有渲染帧）。
- 边界：用户已滚到顶部时（正在看新消息）不锚定（自然跟随）；补偿后要校验（锚点元素位置偏差 > 1px 二次修正）。
- 评分点：同帧补偿与顶部跟随例外。

```javascript

class ScrollAnchoredList {
  constructor(listEl, { rowH = 60 } = {}) {
    this.el = listEl; this.rowH = rowH;
  }
  prepend(items, renderFn) {
    const atTop = this.el.scrollTop < 10;
    const anchorEl = this.el.firstElementChild;                 // 锚点：当前可视首行
    const anchorTopBefore = anchorEl?.getBoundingClientRect().top ?? 0;
    renderFn(items);                                            // 数据+DOM 同步渲染
    if (atTop) return;                                          // 顶部跟随：不锚定
    // 同帧补偿：插入高度 = 渲染后锚点位移
    const anchorAfter = this.el.querySelector(`[data-id="${anchorEl?.dataset.id}"]`);
    const shift = (anchorAfter?.getBoundingClientRect().top ?? 0) - anchorTopBefore;
    if (Math.abs(shift) > 0) {
      this.el.scrollTop += shift;                               // 补偿 scrollTop
      requestAnimationFrame(() => {                             // 二次校验
        const re = this.el.querySelector(`[data-id="${anchorEl?.dataset.id}"]`);
        const drift = (re?.getBoundingClientRect().top ?? 0) - anchorTopBefore;
        if (Math.abs(drift) > 1) this.el.scrollTop += drift;
      });
    }
  }
}
// 虚拟列表变体：数据替换时同步调整内部 offset（startIndex -= items.length），不动 scrollTop
```
