## PER-1270：手写一个路由级代码分割审计器

**答**：
- 需求：实现 routeSplitAudit(routes, chunks)。routes 为 [{ path, imports: [模块名] }]；chunks 为 { chunk: modules[] }；检查：所有路由共享的 chunk 不应超过 3 个（公共过度拆分）；单路由独享 chunk 总体积（bytes 映射）超 300KB 告警；输出 { shared, heavy: [{ path, kb }], pass }。
- 边界：模块无 chunk 归 main；体积映射缺失按 0；imports 为空的路由跳过。
- 评分点：模块归属；共享判定；重路由告警；pass 汇总

```javascript
function routeSplitAudit(routes, chunks, sizes) {
  const count = {}; const perRoute = {};
  for (const r of routes) {
    if (!r.imports.length) continue;
    const used = new Set();
    for (const mod of r.imports) {
      const chunk = Object.entries(chunks)
        .find(([, mods]) => mods.includes(mod))?.[0] ?? 'main';
      used.add(chunk);
      count[chunk] = (count[chunk] ?? 0) + 1;
    }
    perRoute[r.path] = [...used].reduce((s, c) => s + (sizes[c] ?? 0), 0);
  }
  const shared = Object.entries(count).filter(([, n]) => n === routes.length).map(([c]) => c);
  const heavy = Object.entries(perRoute)
    .filter(([, b]) => b > 300 * 1024)
    .map(([path, b]) => ({ path, kb: Math.round(b / 1024) }));
  return { shared, heavy, pass: shared.length <= 3 && !heavy.length };
}
```
