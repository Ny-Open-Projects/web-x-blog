## PER-960：手写一个性能周报生成器：聚合多页面数据为可分发报告

**答**：
- 需求：实现 weeklyReport(pages, slo)。pages 为 [{ page, owner, samples: { lcp: [], inp: [], cls: [] } }]；每个页面计算 lcp/inp 的 P75 与 cls 中位数，与 slo 比对得出状态 ok/warn/page；按 owner 分组输出报告 { owners: [{ owner, pages: [...], worst }], globalWorst }；worst 为状态最差的页面（page > warn > ok，同级比 lcp P75）。
- 边界：样本为空数组页面标记 no-data 不参与 worst 竞争；分位计算对空数组返回 null；owner 缺失归 unassigned。
- 评分点：分位与中位数；状态分级；Owner 分组；worst 竞争规则

```javascript
function weeklyReport(pages, slo) {
  const q = (arr, p) => { if (!arr?.length) return null;
    const s = [...arr].sort((a, b) => a - b);
    return s[Math.min(s.length - 1, Math.floor(s.length * p))]; };
  const status = (lcp, inp) => lcp === null ? 'no-data'
    : (lcp > slo.lcp || inp > slo.inp ? 'page'
      : (lcp > slo.lcp * 0.8 ? 'warn' : 'ok'));
  const rank = { 'page': 3, 'warn': 2, 'ok': 1, 'no-data': 0 };
  const byOwner = {};
  for (const pg of pages) {
    const lcp = q(pg.samples.lcp, 0.75), inp = q(pg.samples.inp, 0.75);
    const item = { page: pg.page, owner: pg.owner ?? 'unassigned',
      lcpP75: lcp, inpP75: inp, cls: q(pg.samples.cls, 0.5),
      status: status(lcp, inp) };
    (byOwner[item.owner] ??= []).push(item);
  }
  const owners = Object.entries(byOwner).map(([owner, list]) => {
    const ranked = list.filter(p => rank[p.status] >= 2)
      .sort((a, b) => rank[b.status] - rank[a.status] || b.lcpP75 - a.lcpP75);
    return { owner, pages: list, worst: ranked[0]?.page ?? null };
  });
  const global = owners.flatMap(o => o.pages).filter(p => rank[p.status] >= 2)
    .sort((a, b) => rank[b.status] - rank[a.status] || b.lcpP75 - a.lcpP75);
  return { owners, globalWorst: global[0]?.page ?? null };
}
```

## 补充：评分点与变体

**评分点**：

- 聚合维度齐全（页面、版本、机型），并区分 P50/P75/P95。
- 有周环比与阈值告警，能标出劣化 TopN。
- 输出可直接分发的格式并附口径说明。
- 空数据或样本不足时降级，不给误导性结论。

**变体与延伸**：

1. 样本量不足怎么办？ → 标注置信度或回落到更长统计周期。
2. 怎么防"报表好看线上没变"？ → 口径固定并与原始 RUM 查询对账，抽查明细。
3. 周报该怎么排序？ → 按影响用户数乘劣化幅度排，而非按劣化百分比。
