## PER-1016：手写一个懒加载图片预解码调度器

**答**：
- 需求：实现 imageScheduler(images, opts)。images 为 [{ el, src }]；IntersectionObserver rootMargin 可配置；进入预热区后按优先级（视口内 > 预热区）排队，解码用 createImageBitmap（Worker 外简化为 Image.decode()），解码完成赋 src；同时最多 2 个解码任务。
- 边界：元素已被移除则跳过；重复触发只入队一次；提供 destroy() 停止全部。
- 评分点：IO 预热；并发上限；decode 时机；destroy 清理

```javascript
function imageScheduler(images, { rootMargin = '200px', concurrency = 2 } = {}) {
  const queue = []; let active = 0; const seen = new Set(); let stopped = false;
  function drain() {
    while (active < concurrency && queue.length && !stopped) {
      const job = queue.shift(); active++;
      if (!job.el.isConnected) { active--; continue; }
      const img = new Image();
      img.src = job.src;
      img.decode().then(() => {
        job.el.src = job.src;
      }).catch(() => report({ type: 'decode-fail', src: job.src }))
        .finally(() => { active--; drain(); });
    }
  }
  const io = new IntersectionObserver(es => {
    for (const e of es) if (e.isIntersecting && !seen.has(e.target)) {
      seen.add(e.target);
      const item = images.find(i => i.el === e.target);
      if (item) queue.push(item);
    }
    drain();
  }, { rootMargin });
  images.forEach(i => io.observe(i.el));
  return { destroy() { stopped = true; io.disconnect(); queue.length = 0; } };
}
```
