## PER-1072：手写一个请求熔断器：滑动窗口失败率驱动

**答**：
- 需求：实现 CircuitBreaker 类。record(success) 记录到滑动窗口（容量 20）；failureRate() 返回窗口失败率（样本 < 10 返回 0）；allow() 状态机：closed（允许）/ open（拒绝，60s）/ half-open（放行 1 个探测）；half-open 探测成功回 closed 失败回 open；状态变化触发 onChange 回调。
- 边界：样本不足时保持 closed；open 到期自动转 half-open；record 在 half-open 期间只影响探测结果；并发探测只放一个。
- 评分点：状态机迁移；窗口失败率；半开单探测；到期转换

```javascript
class CircuitBreaker {
  constructor({ window = 20, minSamples = 10, threshold = 0.5, cooldown = 60_000 } = {}) {
    this.win = []; this.min = minSamples; this.th = threshold;
    this.cooldown = cooldown;
    this.state = 'closed'; this.openedAt = 0; this.probing = false;
    this.onChange?.(this.state);
  }
  allow() {
    if (this.state === 'open') {
      if (Date.now() - this.openedAt >= this.cooldown)
        { this.state = 'half-open'; this.probing = false; }
      else return false;
    }
    if (this.state === 'half-open') {
      if (this.probing) return false;
      this.probing = true;                        // 只放一个探测
    }
    return true;
  }
  record(success) {
    this.win.push(success); if (this.win.length > 20) this.win.shift();
    if (this.state === 'half-open') {
      this.probing = false;
      this.state = success ? 'closed' : 'open';
      if (!success) this.openedAt = Date.now();
    } else if (this.state === 'closed' && this.win.length >= this.min) {
      const fr = this.win.filter(v => !v).length / this.win.length;
      if (fr > this.th) { this.state = 'open'; this.openedAt = Date.now(); }
    }
  }
  failureRate() {
    return this.win.length >= this.min
      ? +(this.win.filter(v => !v).length / this.win.length).toFixed(3) : 0;
  }
}
```
