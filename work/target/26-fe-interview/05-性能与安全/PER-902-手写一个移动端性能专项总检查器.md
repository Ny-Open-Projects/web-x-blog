## PER-902：手写一个移动端性能专项总检查器：按维度清单生成体检报告与改进路线

**答**：
- 需求：实现 mobilePerfCheck(checks)：checks 为各维度检查结果 {dim, item, pass: bool, evidence}；输出体检报告：按六维度（container/resource/crossEnd/experience/environment/mechanism）分组统计通过率，总分 = 各维通过率均值；低于 60% 的维度列出未过项并生成改进路线（每未过项给 {action, priority}，priority 按 维度权重×(1-该维通过率) 排序）。
- 边界：维度无检查项视为未覆盖（不计入总分并输出 uncovered）；重复 (dim,item) 去重取最后一条；路线最多输出 Top5。
- 评分点：分组通过率；权重排序；uncovered 处理。

```javascript
function mobilePerfCheck(checks, { weights = { container: 1, resource: 1, crossEnd: 1,
    experience: 1.5, environment: 1, mechanism: 1.5 }, topK = 5 } = {}) {
  const seen = new Map();
  for (const c of checks) seen.set(c.dim + '|' + c.item, c);   // 去重取最后
  const byDim = {};
  for (const c of seen.values()) (byDim[c.dim] ??= []).push(c);
  const dims = {}, uncovered = [];
  for (const dim of Object.keys(weights)) {
    const items = byDim[dim];
    if (!items) { uncovered.push(dim); continue; }             // 未覆盖维度
    dims[dim] = { rate: items.filter(i => i.pass).length / items.length };
  }
  const covered = Object.keys(dims);
  const score = covered.length
    ? covered.reduce((s, d) => s + dims[d].rate, 0) / covered.length : 0;
  const actions = [];
  for (const [dim, { rate }] of Object.entries(dims)) {
    for (const item of (byDim[dim] || []).filter(i => !i.pass))
      actions.push({ dim, item: item.item, fix: item.evidence || '按规范补齐',
        priority: weights[dim] * (1 - rate) });
  }
  return { dims, score: +score.toFixed(3), uncovered,
    roadmap: actions.sort((a, b) => b.priority - a.priority).slice(0, topK) };
}
```
