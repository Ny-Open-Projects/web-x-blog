## PER-1212：手写一个数据地图查询器：追踪字段流向

**答**：
- 需求：实现 DataMap(nodes, edges)。nodes 为 { path: { owner, level, retention } }；edges 为 [{ from, to, transform }]（支持通配 from orders.*）；trace(field) 返回直接下游与递归下游（BFS，防环）；levelOf(field) 返回传播后级别（agg 降 1 级、hash 降 1 级、其他继承，下限 1）；export() 输出邻接表。
- 边界：未知字段返回 null；环检测用 visited 集合；transform 未识别按继承。
- 评分点：通配边；BFS 防环；级别传播；未知兜底

```javascript
class DataMap {
  constructor(nodes, edges) { this.nodes = nodes; this.edges = edges; }
  #next(field) {
    return this.edges.filter(e =>
      e.from.endsWith('*') ? field.startsWith(e.from.slice(0, -1)) : e.from === field)
      .map(e => ({ to: e.to, transform: e.transform }));
  }
  trace(field) {
    const seen = new Set([field]); const out = []; const queue = [field];
    while (queue.length) {
      const cur = queue.shift();
      for (const n of this.#next(cur)) {
        if (seen.has(n.to)) continue;              // 防环
        seen.add(n.to); out.push({ from: cur, ...n }); queue.push(n.to);
      }
    }
    return out;
  }
  levelOf(field) {
    const base = this.nodes[field]?.level;
    if (base === undefined) return null;
    let level = base;
    for (const step of this.trace(field))
      level = propagate(level, step.transform);
    return level;
  }
}
function propagate(level, t) {
  if (t === 'agg' || t === 'hash') return Math.max(1, level - 1);
  return level;
}
```
