## PER-760：移动端页面加载的分步渲染策略：首屏关键内容先行、次要模块延迟挂载的编排器

**答**：
- 分步模型：Step1 关键内容（标题/主图/主 CTA，< 300ms）、Step2 次要模块（推荐/评论，数据回来即挂）、Step3 延迟模块（重交互组件/广告，idle 挂载）——编排器按优先级与数据就绪驱动。
- 挂载成本控制：Step2/3 模块挂载是 layout 操作，要错峰（一次一个模块，间隔一帧）；用户滚动接近的模块提前挂（rootMargin 预挂载）；挂载过程禁用动画（一次 layout 完成比渐入的多次 layout 便宜）。
- 与骨架屏的关系：骨架屏覆盖 Step1 空窗，Step2/3 用占位高度预留（防 CLS）；分步边界要在设计期约定（哪些组件属于哪步），运行时按注册执行。
- 度量：各步完成时间、Step 间 CLS、分步对秒开的贡献（A/B）。

```javascript

const stepRenderModel = {
  steps: { s1: '标题/主图/CTA < 300ms', s2: '推荐/评论数据回来即挂', s3: '重组件/广告 idle 挂' },
  rules: ['Step2/3 错峰挂载（一次一模块隔一帧）', '滚动临近预挂载（rootMargin）',
    '挂载禁渐入动画（一次 layout 比多次便宜）', '占位高度预留防 CLS'],
  design: '分步边界设计期约定（组件注册所属步），运行时按编排执行',
};
class StepRenderer {
  constructor(steps) { this.steps = steps; }                    // [{name, selector, loader}]
  async run() {
    for (const step of this.steps) {
      await step.ready();                                       // 数据/条件就绪
      const targets = document.querySelectorAll(step.selector);
      for (const t of targets) {
        mountModule(t, step.loader);                            // 错峰：一次一模块
        await nextFrame();
      }
      track('step-mounted', { step: step.name, at: Math.round(performance.now()) });
    }
  }
}
function nextFrame() { return new Promise(r => requestAnimationFrame(() => requestAnimationFrame(r))); }
// 滚动临近预挂载：Step3 模块用 IntersectionObserver rootMargin 200% 提前触发
```
