## PER-1070：手写一个弱网自适应图片参数选择器

**答**：
- 需求：实现 pickImageParams(meta, tier)。meta 为 { w, h, formats: [{ type: avif/webp/jpeg, bytes }] }，tier 为 good/mid/bad；规则：bad 只返回最大宽度 360 的 jpeg/webp；mid 720 且优先 webp；good 1080 优先 avif；输出 { url, type, bytes, savingPct }（相对 jpeg 原始尺寸的节省比例，保留 1 位）。
- 边界：meta.formats 缺目标类型时逐级回退（avif→webp→jpeg）；tier 非法按 mid；savingPct 按同宽度估算（bytes 按宽度比例缩放）。
- 评分点：档位映射；格式回退链；宽度缩放估算；saving 计算

```javascript
function pickImageParams(meta, tier = 'mid') {
  if (!['good', 'mid', 'bad'].includes(tier)) tier = 'mid';
  const maxW = { good: 1080, mid: 720, bad: 360 }[tier];
  const prefer = { good: ['avif', 'webp', 'jpeg'],
    mid: ['webp', 'avif', 'jpeg'], bad: ['webp', 'jpeg', 'avif'] }[tier];
  const base = meta.formats.find(f => f.type === 'jpeg') ??
    meta.formats[meta.formats.length - 1];
  let picked = null;
  for (const t of prefer) {
    const f = meta.formats.find(f => f.type === t);
    if (f) { picked = f; break; }
  }
  picked = picked ?? base;
  const scale = maxW / meta.w;                     // 按目标宽度估算
  const bytes = Math.round(picked.bytes * scale);
  const origBytes = Math.round((base?.bytes ?? picked.bytes) * scale);
  return { url: `${meta.id}?w=${maxW}&f=${picked.type}`, type: picked.type,
    bytes, savingPct: +((1 - bytes / origBytes) * 100).toFixed(1) };
}
```
