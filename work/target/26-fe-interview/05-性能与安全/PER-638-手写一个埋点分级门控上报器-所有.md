## PER-638：手写一个埋点分级门控上报器：所有埋点按合规级别分类，未授权类别静默丢弃并支持撤回后清理

**答**：
- 在 637 基础上实现完整上报器：事件带级别（necessary/analytics/marketing），上报前查 CMP；撤回事件触发时清空对应级别的待发队列与本地缓存。
- 要点：队列中的事件在撤回时也要被清除（不能撤回后还把存量发出去）；necessary 级别白名单字段（只允许会话 id 等最小字段，防止借 necessary 夹带 PII）；批量上报时按级别分桶（不同级别可走不同通道/保留期）。
- 边界：CMP 未初始化时的兜底策略 = 只放行 necessary；上报体不含设备指纹类字段除非 marketing 且已授权。
- 评分点：撤回清队列与 necessary 字段白名单。

```javascript

const NECESSARY_FIELDS = new Set(['sid', 'ts', 'route']);    // 最小必要白名单
class GatedTracker {
  constructor(cmp) {
    this.cmp = cmp; this.queue = [];
    addEventListener('cmp-withdraw', (e) => this.purge(e.detail));  // 撤回清队列
  }
  track(level, event, fields = {}) {
    if (level === 'necessary') {
      fields = Object.fromEntries(Object.entries(fields)
        .filter(([k]) => NECESSARY_FIELDS.has(k)));            // 防夹带 PII
    } else if (!this.cmp.has(level)) return null;              // 未授权静默丢弃
    const item = { level, event, fields, ts: Date.now() };
    if (level !== 'necessary') this.queue.push(item);
    return item;
  }
  purge(categories) {
    this.queue = this.queue.filter(i => !categories.includes(i.level));
    categories.forEach(c => localStorage.removeItem(`tk-${c}`)); // 本地缓存一并清理
  }
  flush() {
    const byLevel = this.queue.reduce((m, i) => (m[i.level] ??= []).push(i), m);
    Object.entries(byLevel).forEach(([lv, items]) =>           // 分级分桶上报
      navigator.sendBeacon(`/collect/${lv}`, JSON.stringify(items)));
    this.queue = [];
  }
}
```
