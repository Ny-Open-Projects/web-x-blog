## PER-774：移动端传感器使用（加速度计/陀螺仪）的性能与功耗：采样频率、节流与页面后台处理

**答**：
- 功耗核心是采样频率：DeviceMotion/Orientation 事件高频触发（60Hz+），处理器若做重计算（计步/摇一摇判定）就是持续 CPU 占用——节流到业务最低需求（摇一摇 20Hz 足够）。
- 实现要点：监听器懒启动（进入需要传感器的页面才监听）、页面隐藏即停止（后台没有理由采样）、处理器轻量（只记录样本，判定算法抽稀/批量）。
- 权限与体验：iOS 13+ 需要 `DeviceOrientationEvent.requestPermission()`（必须手势内调用）；拒绝后给降级体验（按钮代替摇动）。
- 度量：采样事件频率、处理器耗时占比、页面后台期间是否归零。

```javascript

const sensorPerf = {
  power: '采样频率是功耗核心：摇一摇 20Hz 足够，60Hz 全开是持续 CPU 税',
  rules: ['懒启动（进页才监听）', '页面隐藏即停止', '处理器只记样本，判定抽稀批量'],
  permission: 'iOS13+ requestPermission 必须手势内调用；拒绝给按钮降级',
};
class ShakeDetector {
  constructor(onShake, { hz = 20 } = {}) {
    this.minInterval = 1000 / hz; this.last = 0;
    this.samples = [];
  }
  start() {
    this.handler = e => this.onMotion(e);
    window.addEventListener('devicemotion', this.handler);
  }
  stop() {                                                       // 页面隐藏必须调用
    window.removeEventListener('devicemotion', this.handler);
    this.samples = [];
  }
  onMotion(e) {
    const now = performance.now();
    if (now - this.last < this.minInterval) return;              // 节流到目标频率
    this.last = now;
    const { x, y, z } = e.accelerationIncludingGravity ?? {};
    this.samples.push(Math.hypot(x, y, z));
    if (this.samples.length < 10) return;                        // 批量判定：10 样本一算
    const variance = varianceOf(this.samples);
    this.samples = [];
    if (variance > THRESHOLD) this.onShake();
  }
}
```
