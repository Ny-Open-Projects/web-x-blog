## PER-1208：手写一个会话假名生成器：定期轮换

**答**：
- 需求：实现 PseudonymManager(rotateMs=30min)。current() 返回当前假名（设备随机种子 + 轮次哈希）；过期自动轮换（懒检查：调用时判断）；persist() 输出当前假名供上报；同一会话内假名一致，跨轮次不同；seed 存 sessionStorage（会话结束即失效）。
- 边界：seed 缺失生成新 seed；rotateMs=0 每次调用都换；假名输出 16 位 hex；sessionStorage 不可用时用内存（并标记 ephemeral）。
- 评分点：种子管理；轮次哈希；懒轮换；sessionStorage 兜底

```javascript
class PseudonymManager {
  constructor(rotateMs = 30 * 60_000) {
    this.rotateMs = rotateMs;
    try { this.seed = sessionStorage.getItem('pseed') ??
      (sessionStorage.setItem('pseed', crypto.randomUUID()), sessionStorage.getItem('pseed'));
      this.ephemeral = false;
    } catch { this.seed = crypto.randomUUID(); this.ephemeral = true; }
    this.round = Math.floor(Date.now() / (rotateMs || 1));
  }
  #sync() {
    const r = Math.floor(Date.now() / (this.rotateMs || 1));
    if (r !== this.round) this.round = r;
  }
  current() {
    this.#sync();
    return hash(this.seed + ':' + this.round).slice(0, 16);
  }
  persist() { return { id: this.current(), ephemeral: this.ephemeral }; }
}
function hash(s) { let h = 0; for (const c of String(s)) h = (h * 31 + c.charCodeAt(0)) >>> 0;
  return h.toString(16).padStart(16, '0') + h.toString(16).padStart(16, '0'); }
```
