## PER-1256：手写一个监听器泄漏检测器

**答**：
- 需求：实现 listenerLeakCheck(before, after, { growthLimit = 50 })。before/after 为 EventTarget 原型方法计数快照（{ EventTarget.addEventListener: n, ... }）；增长超过 limit 的类型判泄漏嫌疑；输出 { suspects: [{ type, growth }], ok }。
- 边界：快照缺失类型按 0；负增长（被移除）正常；growthLimit 可为函数（按总量比例）。
- 评分点：快照 diff；增长阈值；动态 limit；负增长

```javascript
function listenerLeakCheck(before, after, growthLimit = 50) {
  const types = new Set([...Object.keys(before), ...Object.keys(after)]);
  const suspects = [];
  for (const t of types) {
    const growth = (after[t] ?? 0) - (before[t] ?? 0);
    const limit = typeof growthLimit === 'function'
      ? growthLimit(after[t] ?? 0) : growthLimit;
    if (growth > limit) suspects.push({ type: t, growth });
  }
  return { suspects, ok: !suspects.length };
}
```
