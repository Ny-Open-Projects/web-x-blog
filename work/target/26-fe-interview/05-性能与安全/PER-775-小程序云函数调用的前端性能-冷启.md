## PER-775：小程序云函数调用的前端性能：冷启动规避、批量聚合与失败重试策略

**答**：
- 冷启动问题：云函数闲置后首次调用有 500ms~2s 冷启动——规避手段：**预热**（定时触发器保活/用户进入页面预调用）、**关键路径避开云函数**（首屏接口走容器网关不走冷函数）。
- 前端优化：多个小请求合并成一个云函数调用（batch 参数）、调用并发限制（同时 3 个，排队）、失败重试带指数退避（云函数限流常见）、调用耗时上报区分冷/热（首调用标记）。
- 架构权衡：高频低延迟接口放云函数不合适（冷启动+网络链路长），适合异步任务（通知/统计/生成类）；实时读走数据库直连（云开发 SDK 直查）比套一层函数更快。
- 度量：冷启动占比、p95 调用耗时、批量聚合节省的 RTT 总量。

```javascript

const cloudFnPerf = {
  coldStart: { warm: '定时触发器保活 + 进页预调用', avoid: '首屏关键路径避开云函数' },
  batch: { merge: '多小请求合并单调用', concurrency: 3, retry: '指数退避（限流常见）' },
  architecture: '实时读直查数据库比套云函数快；异步任务（通知/统计/生成）才适合云函数',
  metrics: ['冷启动占比（首调用标记）', 'p95 耗时', '批量节省 RTT 总量'],
};
class CloudFnPool {
  constructor(name) { this.name = name; this.queue = []; this.inflight = 0; this.max = 3; }
  async call(data, { priority = 'normal' } = {}) {
    return new Promise((resolve, reject) => {
      const item = { data, resolve, reject, retried: 0 };
      priority === 'high' ? this.queue.unshift(item) : this.queue.push(item);
      this.pump();
    });
  }
  async pump() {
    if (this.inflight >= this.max || !this.queue.length) return;
    const item = this.queue.shift();
    this.inflight++;
    const t0 = Date.now();
    try {
      const res = await wx.cloud.callFunction({ name: this.name, data: item.data });
      item.resolve(res.result);
      track('cloudfn', { cold: Date.now() - t0 > 1500, ms: Date.now() - t0 }); // 冷启动标记
    } catch (e) {
      if (++item.retried <= 3) {
        setTimeout(() => { this.inflight--; this.queue.unshift(item); this.pump(); },
          2 ** item.retried * 500);                               // 指数退避重试
        return;
      }
      item.reject(e);
    } finally { this.inflight--; this.pump(); }
  }
}
```
