## PER-640：手写一个浏览器指纹熵检测器：量化当前环境的可指纹化程度并输出隐私暴露评级

**答**：
- 把 639 的体检落成量化工具：对一组信号（UA/时区/屏幕/硬件并发/canvas/webgl/字体）分别计算可区分值并赋熵权重，加总输出暴露评级（low/medium/high）。
- 要点：熵权重参考（canvas 10bit、webgl renderer 8bit、字体列表 10bit、硬件并发 3bit 等）；检测浏览器对抗状态（RFP/加噪时信号熵降低）；输出建议（哪些信号可通过配置收敛，如关 WebGL renderer 暴露）。
- 边界：检测器自身不得上报原始信号值（只报熵评分），避免它成为新的采集器；时区/语言等低熵信号不单列。
- 评分点：熵权重表与对抗状态识别。

```javascript

const ENTROPY = { canvas: 10, webglRenderer: 8, fonts: 10, hardwareConcurrency: 3,
  screen: 4, timezone: 4, touch: 2 };
async function entropyAudit() {
  const bits = {};
  const gl = document.createElement('canvas').getContext('webgl');
  const dbg = gl?.getExtension('WEBGL_debug_renderer_info');
  const rfp = navigator.userAgentData?.brands === undefined &&
    /Firefox/.test(navigator.userAgent);                    // 粗略对抗标记
  bits.canvas = rfp ? 2 : ENTROPY.canvas;                    // 加噪后熵骤降
  bits.webglRenderer = dbg ? ENTROPY.webglRenderer : 1;      // 扩展被禁则熵低
  bits.fonts = ENTROPY.fonts;
  bits.hardwareConcurrency = Math.min(3, Math.log2(navigator.hardwareConcurrency ?? 1));
  bits.screen = Math.log2(screen.width * devicePixelRatio);
  bits.timezone = ENTROPY.timezone;
  const total = Object.values(bits).reduce((s, v) => s + v, 0);
  const rating = total > 25 ? 'high（近乎唯一标识）'
    : total > 15 ? 'medium（群体内可区分）' : 'low（对抗良好）';
  return { bits, totalBits: total, rating,
    advice: total > 20 ? '收敛 WebGL renderer 与字体暴露（合规要求）' : 'ok',
    note: '仅报评分不上报原始值' };
}
entropyAudit().then(console.log);
```
