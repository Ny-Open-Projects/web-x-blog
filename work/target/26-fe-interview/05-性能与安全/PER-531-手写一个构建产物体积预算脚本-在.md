## PER-531：手写一个构建产物体积预算脚本：在 CI 里比对 bundle 体积并对超预算 chunk 报错

**答**：
- 数据来源是构建 stats（webpack stats.json 或打包产物目录扫描），对比预算文件 `budget.json`，超预算 chunk 报 error、接近预算报 warn。
- 要点：按 chunk 维度而不是总量设卡，才能精确定位"哪个路由的包胖了"；用 gzip 后体积作为口径（与用户实际下载一致）。
- 边界：新增 chunk（预算文件没有条目）按默认预算处理而不是放行；输出 diff 让 PR 评论可读。
- 评分点：gzip 口径与新增 chunk 兜底两处。

```javascript

const fs = require('fs');
const path = require('path');
const zlib = require('zlib');

function gzSize(file) {
  return zlib.gzipSync(fs.readFileSync(file)).length; // 用户实际下载口径
}

function checkBudget(distDir, budgetFile) {
  const budget = JSON.parse(fs.readFileSync(budgetFile, 'utf8'));
  const violations = [], warns = [];
  for (const file of fs.readdirSync(distDir).filter(f => f.endsWith('.js'))) {
    const chunk = path.basename(file, '.js');
    const limit = budget.chunks[chunk] ?? budget.default;    // 新增 chunk 用默认预算
    const size = gzSize(path.join(distDir, file));
    const entry = { chunk, sizeKB: +(size / 1024).toFixed(1), limitKB: +(limit / 1024).toFixed(1) };
    if (size > limit) violations.push(entry);
    else if (size > limit * 0.9) warns.push(entry);          // 90% 预警带
  }
  if (violations.length) {
    console.error('体积预算超限:', JSON.stringify(violations, null, 2));
    process.exit(1);                                          // CI 红灯
  }
  console.log('体积检查通过', warns.length ? `(预警: ${warns.map(w => w.chunk)})` : '');
}
checkBudget('dist/assets', 'budget.json');
```
