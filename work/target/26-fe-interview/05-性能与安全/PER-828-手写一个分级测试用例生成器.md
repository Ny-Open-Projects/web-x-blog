## PER-828：手写一个分级测试用例生成器：按功能矩阵与设备档生成用例清单与优先级

**答**：
- 需求：输入功能矩阵 [{feature, scenes, heavy: 0-3}] 与设备档列表，生成用例：heavy >= 2 的功能在所有档都生成（低端标注 priority P0，旗舰 P2）；heavy < 2 的功能只在 high/low 档生成（抽中间档）；核心功能（core: true）在所有档为 P0。输出按优先级排序的用例清单（用例 ID = 档-功能-场景）。
- 边界：同功能多场景各生成一条；去重；P0 总量超过上限（如 50）时按 heavy 降序裁剪并记录被裁项。
- 评分点：档位裁剪规则；P0 上限裁剪；ID 唯一性。

```javascript
function genTierCases(features, tiers = ['high', 'mid', 'low'], { p0Limit = 50 } = {}) {
  const cases = [];
  for (const f of features) {
    for (const scene of f.scenes) {
      const useTiers = f.heavy >= 2 ? tiers : ['high', 'low'];       // 重场景全档，轻场景抽两档
      for (const tier of useTiers) {
        const pri = f.core || (tier === 'low' && f.heavy >= 2) ? 'P0'
          : f.heavy >= 2 ? 'P1' : 'P2';
        cases.push({ id: `${tier}-${f.feature}-${scene}`, tier, pri,
          heavy: f.heavy });
      }
    }
  }
  const seen = new Set();
  const uniq = cases.filter(c => !seen.has(c.id) && seen.add(c.id));
  const order = { P0: 0, P1: 1, P2: 2 };
  uniq.sort((a, b) => order[a.pri] - order[b.pri] || b.heavy - a.heavy);
  const p0 = uniq.filter(c => c.pri === 'P0');
  if (p0.length > p0Limit) {                                          // P0 裁剪
    const cut = p0.slice(p0Limit);
    cut.forEach(c => c.pri = 'P1');
    uniq.push(...cut.map(c => ({ id: c.id, cutNote: 'p0-overflow', pri: 'P1' })));
  }
  return uniq;
}
```
