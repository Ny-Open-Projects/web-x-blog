## PER-824：手写一个降级配置合并器：本地默认、下发配置与实验配置三层合并与冲突仲裁

**答**：
- 需求：合并三层配置生成最终 flags：本地默认（最低优先级）→ 服务端下发（按设备档）→ 实验配置（最高优先级）。规则：后层覆盖前层；对象深合并、标量直接覆盖；实验配置中标记 force: true 的键忽略其余层；合并后输出每个键的来源（便于排查）。
- 边界：非法值类型（如 flags.imgTier 传字符串）拒绝该键并记录；循环嵌套不超过 3 层。
- 评分点：优先级仲裁正确；来源追踪；类型校验拒绝非法键。

```javascript
function mergeConfigs(defaults, remote, exp) {
  const out = {}, source = {}, rejected = [];
  const SCHEMA = { imgTier: 'number', effects: 'string', disableHeavy: 'boolean' };
  const deep = (base, over, srcName, forceSet = new Set()) => {
    for (const [k, v] of Object.entries(over)) {
      if (typeof v === 'object' && v !== null && !Array.isArray(v)) {
        out[k] ??= {}; deep(out[k], v, srcName);
      } else {
        const expect = SCHEMA[k];
        if (expect && typeof v !== expect) { rejected.push({ k, v, from: srcName }); continue; }  // 类型非法拒绝
        if (forceSet.has(k)) continue;                             // force 键已被更高层锁定
        out[k] = v; source[k] = srcName;
        if (v && typeof v === 'object' ? false : exp?.[k]?.force) source[k] = srcName + '(force)';
      }
    }
  };
  deep(out, defaults, 'default');
  deep(out, remote, 'remote');
  const forceKeys = new Set(Object.keys(exp || {}).filter(k => exp[k]?.force));
  deep(out, exp, 'exp', forceKeys);
  return { flags: out, source, rejected };
}
```
