## PER-1148：第三方数据共享（广告/分析）的合规协议与前端控制

**答**：
- 共享前提：政策披露第三方名单+目的、法律基础（同意/合同）、数据处理协议（DPA）签署。
- 前端控制：按同意桶决定是否向第三方发数据；数据最小化（发脱敏/聚合后数据而非原始）。
- 名单管理：第三方注册表（名称/用途/数据项/区域），新 SDK 接入强制登记；用户可见"数据接收方列表"。
- 退出：用户撤回同意后，通知第三方删除（转发删除请求）。

```javascript
// 第三方共享网关
const VENDORS = {
  analytics: { domain: 'analytics.vendor.com', fields: ['page', 'metrics'],
    basis: 'consent' },
  ads: { domain: 'ads.vendor.com', fields: ['cohort'], basis: 'consent' },
};
function shareTo(vendor, payload) {
  const v = VENDORS[vendor];
  if (!v) throw new Error('未登记的第三方');
  if (v.basis === 'consent' && !consent.get()[vendor]) return null;
  const filtered = Object.fromEntries(Object.entries(payload)
    .filter(([k]) => v.fields.includes(k)));                // 最小化
  report({ type: 'vendor-share', vendor, fields: Object.keys(filtered) });
  return filtered;
}
```
