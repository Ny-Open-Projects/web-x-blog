## PER-1151：联邦学习/端侧计算对隐私架构的意义

**答**：
- 思路：数据不出端，模型/统计在端侧计算后只上传梯度或聚合结果——原始数据留在设备。
- 适用场景：输入预测（键盘）、个性化推荐（端侧排序）、异常检测。
- 工程要求：端侧模型更新机制（安全下发+版本管理）、上传内容审计（确认无原始数据）、安全聚合（多端混淆防单点反推）。

```javascript
// 端侧统计上报（只传聚合不传原始）
function localAggregate(events) {
  const buckets = {};
  for (const e of events) {
    const key = Math.floor(e.value / 100) * 100;     // 分桶粗化
    buckets[key] = (buckets[key] ?? 0) + 1;
  }
  return { buckets, raw: undefined };                // 原始明细不出端
}
// 服务端安全聚合：单端结果加盲值，聚合后盲值抵消
function blindAggregate(contribs) {
  const sum = contribs.reduce((s, c) => s + c.value, 0);
  const blinds = contribs.reduce((s, c) => s + c.blind, 0);
  return sum - blinds;                               // 盲值抵消得真值
}
```
