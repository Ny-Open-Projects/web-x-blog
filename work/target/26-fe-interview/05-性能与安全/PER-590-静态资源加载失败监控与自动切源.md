## PER-590：静态资源加载失败监控与自动切源：CDN 域名挂了前端怎么自愈？

**答**：
- 检测：`<script>`/`<link>`/`<img>` 的 error 事件（捕获阶段）+ Performance 资源条目里的失败标记；按域名聚合失败率，单域名失败率突增（如 > 30%）触发切源。
- 自愈手段：**域名切换**（备用 CDN 域名动态替换 src/href 并重载资源）、**动态 import 兜底**（chunk 加载失败时改写 publicPath 重试）、**版本回退**（引用上一版本的静态资源清单）。
- 实现要点：切源要有次数与冷却控制（防止备用源也挂导致雪崩式重试）；切源动作本身要上报（运维要知道主源挂了）。
- 配套：多域名预连接（dns-prefetch 备用域）让切换时省掉 DNS 时间；资源清单（manifest）集中管理 URL，切源才有统一入口。

```javascript

const failCounter = {};                                     // domain -> {fail, total}
function hookResourceError() {
  addEventListener('error', e => {
    const el = e.target;
    if (!['SCRIPT', 'LINK', 'IMG'].includes(el.tagName)) return;
    const url = el.src || el.href;
    const host = new URL(url, location.href).host;
    const c = (failCounter[host] ??= { fail: 0, total: 0 });
    c.fail++;
    maybeSwitch(host, el);
  }, true);
}
let switched = false, coolDown = 0;
function maybeSwitch(host, el) {
  if (switched || Date.now() < coolDown) return;            // 冷却防雪崩
  const c = failCounter[host];
  if (c && c.fail >= 3 && c.fail / Math.max(1, c.fail + 1) > 0.3) {
    switched = true;
    const backup = window.__CDN_BACKUP;                     // manifest 里的备用域
    document.querySelectorAll('script[src], link[href], img[src]').forEach(node => {
      const u = node.src || node.href;
      if (u && u.includes(host)) {
        const nu = u.replace(host, backup);
        node.tagName === 'LINK' ? node.href = nu : node.src = nu; // 原地重载
      }
    });
    coolDown = Date.now() + 60000;
    navigator.sendBeacon('/collect/cdn-switch', JSON.stringify({ from: host, to: backup }));
  }
}
```
