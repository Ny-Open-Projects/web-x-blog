## PER-862：手写一个三层预加载编排器：按意图强度分层触发与预算占用回收

**答**：
- 需求：实现 PreloadOrchestrator：register(level, task)；当 intent(level) 触发时：预算未满则执行该层任务并占预算位；预算满时若新触发层优先级更高，回收（取消）正在执行的低层任务腾位（低层任务须可取消），否则排队。任务完成/取消释放预算。提供 stats（各层执行/取消/排队次数）。
- 边界：level 数字越大优先级越高；不可取消的低层任务不能被回收（等它完成）；同一 task id 未完成前重复触发去重。
- 评分点：高优先级抢占与可取消性校验；预算释放；去重。

```javascript
class PreloadOrchestrator {
  constructor(cap = 3) { this.cap = cap; this.running = new Map(); this.stats = {}; }
  stat(k) { return this.stats[k] = (this.stats[k] || 0) + 1; }
  register(id, level, task) {                                  // task: {run, cancel?}
    if (this.running.has(id)) return this.stat('dup-skip');
    const exec = { id, level, task };
    if (this.running.size < this.cap) return this.start(exec);
    // 预算满：找可取消的更低优先级任务
    const victims = [...this.running.values()]
      .filter(e => e.level < level && typeof e.task.cancel === 'function')
      .sort((a, b) => a.level - b.level);
    if (victims.length) {
      this.cancel(victims[0]); return this.start(exec);
    }
    this.stat('queued');
  }
  start(exec) { this.stat('run'); this.running.set(exec.id, exec);
    exec.task.run().finally(() => { this.running.delete(exec.id); }); }
  cancel(exec) { exec.task.cancel?.(); this.running.delete(exec.id); this.stat('preempted'); }
}
```
