## PER-508：手写一个弱网/慢接口注入工具：用 Service Worker 给指定 API 注入延迟与失败，构造可复现的慢场景

**答**：
- 比"DevTools 里拖一下节流"更工程化的做法：用 Service Worker 拦截 fetch，按 URL 规则注入延迟/超时/假数据，规则可以版本化进仓库，让"慢场景"在任何环境一键复现。
- 要点：规则匹配支持 path 正则与延迟区间（随机抖动更真实）；要能注入失败与 5xx，测前端的重试与降级。
- 边界：注入只在测试开关打开时启用；SW 作用域与缓存更新要处理好，防止注入规则本身缓存住不更新。
- 评分点：是否考虑了"规则热更新"与"一键卸载"，否则测试环境会被 SW 缓存污染。

```javascript

// sw-inject.js：根据 query 开关注入故障
const RULES = [
  { match: /\/api\/list/, delay: [1500, 3000], failRate: 0.2 }, // 列表接口慢且 20% 失败
  { match: /\/api\/user/, delay: [200, 400], failRate: 0 },
];

self.addEventListener('fetch', (event) => {
  if (!new URL(event.request.url).searchParams.has('__chaos')) return; // 开关注入
  const rule = RULES.find(r => r.match.test(event.request.url));
  if (!rule) return;
  event.respondWith((async () => {
    const d = rule.delay[0] + Math.random() * (rule.delay[1] - rule.delay[0]);
    await new Promise(r => setTimeout(r, d));           // 注入抖动延迟
    if (Math.random() < rule.failRate) {
      return new Response(JSON.stringify({ error: 'injected' }), { status: 503 });
    }
    const res = await fetch(event.request);
    return res;
  })());
});
// 页面侧注册：navigator.serviceWorker.register('/sw-inject.js')
// 价值：把"网络很慢"从口头描述变成带规则文件的可复现故障剧本
```
