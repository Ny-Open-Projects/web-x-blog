## PER-1140：自动化决策与画像的合规要求（算法透明）

**答**：
- 要求：完全自动化决策（无人工介入且产生法律/重大影响）需告知、可要求人工复核、可异议；个保法要求"透明度"。
- 工程实现：决策记录（输入特征+规则版本+结果），提供"申请人工复核"入口，复核结果可推翻自动决策。
- 画像边界：用户画像用于个性化推荐需提供关闭选项（推荐个性化开关）。
- 前端配合：决策结果页展示"为什么"（规则摘要，非算法细节）、一键申诉入口。

```javascript
// 自动化决策记录与复核
function recordDecision(uid, decision) {
  const rec = { uid: hash(uid), ts: Date.now(),
    model: decision.modelVersion, features: decision.featureSummary,
    outcome: decision.outcome, humanReview: false };
  if (decision.significant) rec.appealUrl = `/review/apply?did=${decision.id}`;
  return rec;
}
async function applyHumanReview(did, uid) {
  await queueReview(did);                        // 人工复核队列
  logAudit(hash(uid), 'appeal', `decision:${did}`);
  return { status: 'queued', slaHours: 48 };     // 承诺时限
}
```
