## PER-520：前端如何做组件级性能测试？页面级跑分定位不了单个组件渲染慢时怎么办？

**答**：
- 页面级指标只能告诉你"慢"，组件级测试才能告诉你"谁慢"：核心手段是 React `Profiler` API 测单组件 commit 耗时、`why-did-you-render` 找多余渲染、Vue 的 `onRenderTracked` 同理。
- 组件级测试要构造**受控 props 场景**：固定数据规模（如 1000 行列表）、单次 mount、多次 update，分别记录 mount/update 毫秒数作为组件预算。
- 落地成"组件性能单测"：把 Profiler onRender 回调接入断言，PR 里组件渲染超预算直接红灯，防止列表组件被悄悄写坏。
- 追问钩子：Profiler 测出来的耗时和用户感受对不上怎么办？——Profiler 只含 React commit，不含布局绘制，要配合浏览器 Performance 面板的 scripting/rendering 分解互证。

```javascript

import { Profiler } from 'react';

const budgets = { ProductList: { mount: 50, update: 16 } }; // 组件渲染预算(ms)
let phaseCost = {};

function PerfGate({ id, children }) {
  return (
    <Profiler id={id} onRender={(id, phase, duration) => {
      const p = (phaseCost[id] ??= {});
      p[phase] = Math.max(p[phase] ?? 0, duration);  // 记录最差一次
    }}>
      {children}
    </Profiler>
  );
}
```
