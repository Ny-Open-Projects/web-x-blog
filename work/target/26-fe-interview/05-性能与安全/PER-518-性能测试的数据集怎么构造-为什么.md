## PER-518：性能测试的数据集怎么构造？为什么造数不当会让整个压测白做？

**答**：
- 数据集决定性能结论的真实性：10 条 vs 10 万条列表、热门大图 vs 普通图、正常分类树 vs 千层嵌套，测出来完全两个世界——造数偏小是压测白做的头号原因。
- 构造三原则：**分布对齐生产**（字段长度、对象规模、图片尺寸按真实分位数）、**规模打满边界**（至少覆盖 p95 与 max 两个档位）、**可重置可复现**（快照入库，每次压测同一份）。
- 特殊档位必须单独造：首屏含广告位/异步组件的页、数据为空的空态页、网络失败的重试路径，这些"非典型页面"往往才是事故现场。
- 追问钩子：为什么不能直接拷生产库？——可以，但要脱敏；真实分布的价值远大于合成造数，前提是过合规。

```javascript

// 数据集生成器：按生产分位数造数，规模分档
const profile = { listLen: { p50: 60, p95: 500, max: 5000 },
                  imgKB: { p50: 180, p95: 900, max: 3200 } };
function makeDataset(profile) {
  return Object.entries(profile).flatMap(([name, q]) => [
    { name: `${name}-p50`, size: q.p50, tag: 'typical' },
    { name: `${name}-p95`, size: q.p95, tag: 'stress' },   // 压测主打档
    { name: `${name}-max`, size: q.max, tag: 'boundary' }, // 边界档
  ]);
}
const dataset = makeDataset(profile);
console.log(dataset.filter(d => d.tag !== 'typical'));
// 每个指标三个档位：典型档看体验、p95 档做压测主口径、max 档验证不崩
```
