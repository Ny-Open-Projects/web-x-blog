## PER-761：手写一个分步渲染编排器：按步挂载模块、错峰调度与临近预挂载

**答**：
- 完整实现：模块注册（selector/loader/step/预挂载距离）-> Step1 同步 -> Step2 数据驱动 -> Step3 idle + IntersectionObserver 预挂载混合调度。
- 要点：同一步内模块按注册顺序逐个挂（每模块间隔一帧）；预挂载触发时若步还没到（数据未就绪）则挂占位；编排器暴露进度（Step 完成埋点，秒开分析用）。
- 边界：模块挂载失败不影响后续（try/catch 隔离）；用户快速滚动到底时跳过预挂载直接全量挂载（减少等待感）。
- 评分点：预挂载与步调度的合并。

```javascript

class StepOrchestrator {
  constructor() { this.modules = []; }
  register({ name, selector, loader, step = 3, preMargin = '200%' }) {
    this.modules.push({ name, selector, loader, step, preMargin, mounted: false });
  }
  async run() {
    const s1 = this.modules.filter(m => m.step === 1);
    s1.forEach(m => this.mount(m));                             // Step1 同步
    await dataReady('step2');
    for (const m of this.modules.filter(m => m.step === 2)) {
      this.mount(m); await nextFrame();                         // 错峰
    }
    this.scheduleStep3();                                       // Step3：idle + 预挂载
  }
  scheduleStep3() {
    const io = new IntersectionObserver(es => es.forEach(e => {
      const m = this.modules.find(x => x.selector && e.target.matches(x.selector));
      if (m && !m.mounted && dataReady('step3', m)) this.mount(m);
    }), { rootMargin: '200% 0px' });
    this.modules.filter(m => m.step === 3 && !m.mounted)
      .forEach(m => { const el = document.querySelector(m.selector); el && io.observe(el); });
    requestIdleCallback(() => {                                 // idle 兜底全量挂
      if (this.nearBottom()) this.modules.filter(m => !m.mounted).forEach(m => this.mount(m));
    });
  }
  mount(m) {
    if (m.mounted) return;
    m.mounted = true;
    try { m.loader(document.querySelector(m.selector)); }
    catch (e) { warn(`模块挂载失败 ${m.name}`, e); }            // 失败隔离
    track('module-mounted', { name: m.name, at: Math.round(performance.now()) });
  }
}
function dataReady(step, m) { return STEP_DATA[step]?.isReady(m); }
```
