## PER-1144：跨设备/跨端的数据同步与隐私边界

**答**：
- 原则：跨端同步基于同一账号且在政策披露范围内；未登录设备数据不跨端合并（隐私边界）。
- 实现：同步以账号为中心，设备侧本地数据同步前先获取增量同意（新类型数据）；登出时选择是否清除云端副本。
- 技术：端到端加密同步（高敏笔记类）、同步冲突的隐私审计（谁在何时改了什么）。
- 风险点：共享设备场景（家庭平板）——提供"退出并清除本机数据"明确入口。

```javascript
// 跨端同步的同意门槛
async function syncDeviceData(device, account) {
  const types = ['notes', 'settings'];
  const granted = await consent.multi(account.uid, types);   // 各类型同意状态
  const syncable = types.filter(t => granted[t]);
  const denied = types.filter(t => !granted[t]);
  if (denied.length) report({ type: 'sync-partial', denied });
  return { sync: syncable,
    encrypt: true,                                           // 端到端加密
    logoutOption: { wipeLocal: true, wipeCloud: 'ask' } };
}
```
