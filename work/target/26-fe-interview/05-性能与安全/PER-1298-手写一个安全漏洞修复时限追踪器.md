## PER-1298：手写一个"安全漏洞修复时限"追踪器

**答**：
- 需求：implement vulnSla(vulns)。vulns 为 [{ id, severity, foundAt, fixedAt }]；时限：critical 7 天/high 30 天/medium 90 天/low 180 天；输出 { overdue: [{ id, daysOver }], onTrack: [id], open: [{ id, daysLeft }] }。
- 边界：未知 severity 按 medium；fixedAt 缺失为 open；daysLeft 负数即已逾期（归 overdue）；按逾期降序。
- 评分点：分级时限；三态；未知降级；排序

```javascript
function vulnSla(vulns) {
  const SLA = { critical: 7, high: 30, medium: 90, low: 180 };
  const now = Date.now();
  const overdue = [], onTrack = [], open = [];
  for (const v of vulns) {
    const limit = (SLA[v.severity] ?? 90) * 86400_000;
    if (v.fixedAt) {
      const days = (v.fixedAt - v.foundAt) / 86400_000;
      days * 86400_000 > limit
        ? overdue.push({ id: v.id, daysOver: +(days - limit / 86400_000).toFixed(1) })
        : onTrack.push(v.id);
    } else {
      const left = +(limit / 86400_000 - (now - v.foundAt) / 86400_000).toFixed(1);
      left < 0 ? overdue.push({ id: v.id, daysOver: -left }) : open.push({ id: v.id, daysLeft: left });
    }
  }
  overdue.sort((a, b) => b.daysOver - a.daysOver);
  return { overdue, onTrack, open };
}
```
