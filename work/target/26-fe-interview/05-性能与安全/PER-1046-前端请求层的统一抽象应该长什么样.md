## PER-1046：前端请求层的统一抽象应该长什么样

**答**：
- 职责：URL 构造/参数序列化、鉴权注入、错误分类、重试/熔断、缓存、埋点、弱网策略、取消管理——业务只写语义。
- 设计：分层（传输层 fetch 封装 → 策略层中间件 → 业务层资源方法），中间件链处理横切关注。
- 可测试：策略层纯函数化（输入配置与响应，输出动作），易单测；传输层可 mock。
- 红线：请求层禁止业务逻辑（写死字段映射），保持通用。

```javascript
// 中间件链请求层
const middlewares = [];
function use(fn) { middlewares.push(fn); }         // fn(ctx, next)
async function request(ctx) {
  let i = -1;
  async function next() {
    i++;
    if (i < middlewares.length) await middlewares[i](ctx, next);
    else ctx.res = await rawFetch(ctx);
  }
  await next();
  return ctx.res;
}
use(async (ctx, next) => { ctx.headers.Authorization = token(); await next(); }); // 鉴权
use(async (ctx, next) => { const t0 = Date.now(); await next();
  report({ url: ctx.url, ms: Date.now() - t0 }); });                              // 埋点
use(async (ctx, next) => { ctx.signal ??= AbortSignal.timeout(8000); await next(); }); // 超时
```
