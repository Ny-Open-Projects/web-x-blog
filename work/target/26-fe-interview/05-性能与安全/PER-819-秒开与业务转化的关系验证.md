## PER-819：秒开与业务转化的关系验证：性能改善对转化率影响的实验设计

**答**：
- 目的：把性能优化的价值翻译成业务语言（转化率/GMV/留存），为继续投入争取资源——性能专项最常死在"无法证明业务价值"。
- 实验设计：同一页面的性能优化以 A/B 发布（优化版 vs 现状版），主指标为页面转化率（如下单率/停留时长），协变量控制设备档、网络档、用户画像，实验周期 >= 2 周覆盖周末效应。
- 关联分析：中间指标（秒开率、首屏 LCP）与转化率在实验分组间的差异方向要一致，否则怀疑数据口径问题；分段看"秒开 vs 未秒开"用户的转化差，用于估算收益天花板。
- 陷阱：性能优化可能提升跳出用户的留存但降低单次停留（页面变快内容曝光更多）；不要用观测数据（无随机分组）做因果结论。

```javascript
// 实验判定（简化）
function evaluateAB(exp, { minSamples = 5000, alpha = 0.05 } = {}) {
  const { a, b } = exp;                       // a 现状版, b 优化版: {users, conversions, msOpenRate}
  if (a.users < minSamples || b.users < minSamples) return { verdict: 'insufficient' };
  const cr1 = a.conversions / a.users, cr2 = b.conversions / b.users;
  const se = Math.sqrt(cr1 * (1 - cr1) / a.users + cr2 * (1 - cr2) / b.users);
  const z = (cr2 - cr1) / se;
  const p = 2 * (1 - normalCdf(Math.abs(z)));
  const pass = p < alpha;
  return {
    verdict: pass ? (cr2 > cr1 ? '性能优化带来显著转化提升' : '显著负向，需复盘') : '无显著差异',
    crDelta: +(cr2 - cr1).toFixed(4), p: +p.toFixed(4),
    openRateDelta: b.msOpenRate - a.msOpenRate,   // 与转化方向一致性检查
  };
}
```
