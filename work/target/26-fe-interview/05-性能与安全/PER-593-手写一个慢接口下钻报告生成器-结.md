## PER-593：手写一个慢接口下钻报告生成器：结合 Server-Timing 把前端耗时分解为网络/服务端/渲染三段并生成报告

**答**：
- 数据源：fetch 包装器记录每请求客户端总耗时，解析响应 `Server-Timing` 头拿后端耗时，差值为网络段；渲染段用交互完成回调（双 rAF）测。
- 要点：Server-Timing 头格式 `dur;desc=xx, db;dur=45` 要按逗号分号解析；同接口多样本聚合出分位数再判慢，单样本不下结论。
- 边界：跨域接口没有 `Timing-Allow-Origin` 时拿不到 Server-Timing，标注不可分解；HEAD/OPTIONS 预检不计入。
- 评分点：Server-Timing 解析与 TAO 缺失降级。

```javascript

function parseServerTiming(header) {
  if (!header) return null;
  const out = {};
  header.split(',').forEach(part => {                      // "db;dur=45, app;dur=78"
    const [name, ...kvs] = part.split(';');
    kvs.forEach(kv => {
      const [k, v] = kv.split('=');
      if (k === 'dur') out[name.trim()] = +v;
    });
  });
  return Object.keys(out).length ? { serverMs: out.dur ?? out.total, detail: out } : null;
}
function apiBreakdown(fetchLike) {
  return async (input, init) => {
    const t0 = performance.now();
    const res = await fetchLike(input, init);
    const total = performance.now() - t0;
    const st = parseServerTiming(res.headers.get('Server-Timing'));
    const isCors = !res.headers.has('Server-Timing') && !res.url.startsWith(location.origin);
    navigator.sendBeacon?.('/collect/api-bd', JSON.stringify({
      url: new URL(res.url).pathname,
      totalMs: +total.toFixed(1),
      serverMs: st?.serverMs ?? null,
      netMs: st ? +(total - st.serverMs).toFixed(1) : null, // 网络+等待段
      taoMissing: isCors,                                   // 跨域无 TAO 不可分解
    }));
    return res;
  };
}
const tracedFetch = apiBreakdown(window.fetch);
```
