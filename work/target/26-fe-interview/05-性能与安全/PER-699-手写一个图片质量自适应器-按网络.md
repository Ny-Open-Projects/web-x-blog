## PER-699：手写一个图片质量自适应器：按网络档位与设备屏选 URL 档，并在加载失败时逐级回退

**答**：
- 档位决策：网络档（683）定清晰度上限（weak->ld 480w，mid->sd 720w，fast->hd 1080w），DPR 定目标宽；URL 模板化（`{w}` 占位符）按 CDN 裁剪参数生成。
- 要点：回退链 hd->sd->ld->原图（CDN 参数不识别 4xx 时逐级降）；弱网切档时新图按新档，已加载不重载；同屏同档（避免混档抖动）。
- 边界：gif/动图不走裁剪参数；透明图保留 png/webp-alpha；`accepts` 探测（webp/avif 支持缓存到会话）。
- 评分点：URL 模板与回退链。

```javascript

class AdaptiveImage {
  constructor(requester) { this.requester = requester; this.support = null; }
  async formatSupport() {                                       // 会话级缓存探测
    if (this.support) return this.support;
    this.support = { webp: await probe('image/webp'), avif: await probe('image/avif') };
    return this.support;
  }
  urlFor(tpl, naturalW) {
    const cap = { weak: 480, mid: 720, fast: 1080 }[this.requester.tier] ?? 720;
    const w = Math.min(naturalW, Math.min(cap, Math.ceil(devicePixelRatio * 400)));
    const fmt = this.support?.avif ? 'avif' : this.support?.webp ? 'webp' : 'jpg';
    return tpl.replace('{w}', String(w)).replace('{fmt}', fmt);
  }
  async load(img, tpl, naturalW) {
    const chain = ['hd', 'sd', 'ld'];                           // 回退链
    for (const tier of chain) {
      const u = this.urlFor(tpl, naturalW).replace(tpl, tpl);   // 档位含在模板
      try {
        const res = await fetch(u, { method: 'HEAD' });
        if (res.ok) { img.src = u; return; }
      } catch { /* 弱网：HEAD 失败直接降档 */ }
    }
    img.src = tpl.replace('{w}', 'orig').replace('{fmt}', 'jpg'); // 兜底原图
  }
}
async function probe(mime) {                                     // canvas 探测格式支持
  const c = document.createElement('canvas'); c.width = c.height = 1;
  return c.toDataURL(mime).startsWith(`data:${mime}`);
}
```
