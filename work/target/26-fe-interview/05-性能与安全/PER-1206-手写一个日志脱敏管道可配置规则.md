## PER-1206：手写一个日志脱敏管道（可配置规则）

**答**：
- 需求：实现 createRedactor(rules)。rules 为 [{ name, re, mask } ]，mask 为函数或固定串；redact(obj) 深遍历：字符串值执行全部规则；键名命中 SENSITIVE_KEYS（phone/idCard/bankCard）整值掩码；返回新对象不修改原对象；cycle 引用处理（重复对象用 Circular 标记）。
- 边界：null/undefined 原样；数组递归；正则全局匹配（re 必须带 g，否则自动加）；性能：大对象（>10000 节点）抛错 TooLarge。
- 评分点：深遍历；键名整值掩码；循环引用；规模上限

```javascript
const SENSITIVE_KEYS = new Set(['phone', 'idCard', 'bankCard']);
function createRedactor(rules) {
  const norm = rules.map(r => ({ ...r,
    re: r.re.global ? r.re : new RegExp(r.re.source, r.re.flags + 'g') }));
  let nodes = 0;
  function walk(v, seen = new WeakMap()) {
    if (++nodes > 10000) throw new Error('TooLarge');
    if (v == null) return v;
    if (typeof v === 'object') {
      if (seen.has(v)) return '[Circular]';
      seen.set(v, true);
      if (Array.isArray(v)) return v.map(x => walk(x, seen));
      return Object.fromEntries(Object.entries(v).map(([k, val]) =>
        [k, SENSITIVE_KEYS.has(k) ? '***' : walk(val, seen)]));
    }
    if (typeof v !== 'string') return v;
    let out = v;
    for (const r of norm) out = out.replace(r.re, r.mask ?? '***');
    return out;
  }
  return { redact(obj) { nodes = 0; return walk(obj); } };
}
```
