## PER-1133：手写一个重放攻击检测器

**答**：
- 需求：实现 replayGuard({ windowMs=60_000 })。verify({ ts, nonce, sig, body })：ts 漂移超窗拒绝（code: expired）；nonce 已见拒绝（code: replay）；通过则记录 nonce（带过期自动清理）；sig 校验由调用方注入的 verifySig 回调完成。返回 { ok, code }。
- 边界：nonce 记录只存窗口时长内的；verify 失败不记录 nonce（允许客户端修正后重试）；并发相同 nonce 只有一次通过（先记录后返回，原子性由单线程 JS 保证）。
- 评分点：时间窗；nonce 一次性；签名回调；并发原子性

```javascript
function replayGuard({ windowMs = 60_000, verifySig } = {}) {
  const seen = new Map();                                  // nonce -> expireAt
  function clean(now) {
    for (const [k, t] of seen) if (t < now) seen.delete(k);
  }
  return function verify({ ts, nonce, sig, body }) {
    const now = Date.now();
    clean(now);
    if (Math.abs(now - ts) > windowMs) return { ok: false, code: 'expired' };
    if (seen.has(nonce)) return { ok: false, code: 'replay' };
    if (!verifySig({ ts, nonce, body }, sig)) return { ok: false, code: 'bad-sign' };
    seen.set(nonce, now + windowMs);                       // 先记录防并发重放
    return { ok: true, code: 'ok' };
  };
}
// 测试：同一请求第二次 verify -> { ok:false, code:'replay' }
```
