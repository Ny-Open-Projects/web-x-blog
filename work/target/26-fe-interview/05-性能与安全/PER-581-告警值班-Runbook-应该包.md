## PER-581：告警值班 Runbook 应该包含什么？为什么有告警没手册等于没有监控？

**答**：
- Runbook 是告警的说明书，每条 page 级告警必须配：**告警含义**（什么指标、什么口径、多大概率是真事故）、**确认动作**（30 秒内能做的验证命令/看板链接）、**分级响应**（先止血还是先定位）、**升级路径**（超 10 分钟未定位升级到谁）、**历史案例链接**（过去同告警的复盘）。
- 止血优先于定位：切降级开关、回滚版本、扩容——Runbook 里止血动作放最前面，且每个动作要有可回退保证。
- 维护机制：每次告警复盘后更新 Runbook（新经验写入）；季度演练抽 2 条 Runbook 真跑一遍，过期手册比没有手册更危险（误导值班）。
- 追问钩子：Runbook 谁写？——谁建的告警谁写初版，复盘迭代共修，写不完的告警说明告警太多了，先减告警。

```javascript

const runbook = {
  alert: 'LCP p75 burnRate > 14.4 (fast5+slow60)',
  meaning: '前端首屏体验在大面积恶化，>70% 概率为真事故',
  confirm: ['打开值班看板 sloStatus', '看发版时间线最近 30min 是否发版', '抽样 3 个慢会话回放'],
  mitigate: [   // 止血优先，每步可回退
    { act: '有发版 -> 一键回滚', revert: '重新发布原版本' },
    { act: '无发版 -> 切静态兜底开关', revert: '关闭开关' },
  ],
  escalate: '10min 未定位 -> 升级前端负责人 + 后端 oncall',
  history: '复盘链接 x3',
  maintain: '每次复盘更新；季度演练 2 条；写不出手册的告警先砍',
};
```
