## PER-533：手写一个交互路径分段计时器：把点击到请求发出、响应到达、UI 更新四段耗时拆开上报

**答**：
- 价值在于归因：总耗时 2s 时，是请求慢还是渲染慢？分段打点用 `performance.mark/measure` 加 fetch 包装实现。
- 要点：请求段从"点击处理中调用 fetch 的时刻"起算；渲染段用 `requestAnimationFrame` 双帧确认（下一帧才真正 paint）；段与段之间要防重入（连续点击）。
- 边界：并多请求时以最后一个 settle 为响应完成时刻；取消的请求要打 abort 标记不计入渲染等待。
- 评分点：双 rAF 确认渲染完成与 abort 分支。

```javascript

function traceInteraction(name) {
  const t0 = performance.mark(`${name}:click`).startTime;
  let fetchAt, respAt, aborted = false;
  return {
    wrapFetch(promise) {                                   // 在点击处理里包住业务请求
      fetchAt = performance.now();
      return promise.finally(() => { respAt = performance.now(); })
        .catch(e => { if (e.name === 'AbortError') aborted = true; throw e; });
    },
    done() {
      const finish = () => {
        if (aborted) return;                               // 取消的交互不计渲染段
        const uiAt = performance.now();                    // 双 rAF 后才算 UI 完成
        const seg = {
          click2fetch: +(fetchAt - t0).toFixed(1),         // 点击到发请求（JS 逻辑耗时）
          fetch2resp: +(respAt - fetchAt).toFixed(1),      // 网络耗时
          resp2ui: +(uiAt - respAt).toFixed(1),            // 渲染耗时
          total: +(uiAt - t0).toFixed(1),
        };
        navigator.sendBeacon('/perf/interact', JSON.stringify({ name, ...seg }));
      };
      requestAnimationFrame(() => requestAnimationFrame(finish));
    },
  };
}
// 用法：const tr = traceInteraction('add-cart'); const p = tr.wrapFetch(addCart());
// p.then(() => tr.done()); -> 上报 { click2fetch: 12, fetch2resp: 890, resp2ui: 130 }
```
