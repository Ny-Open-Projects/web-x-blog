## PER-763：手写一个小程序组件复用池：列表项组件实例的回收、重置与再分配

**答**：
- 实现：`acquire()` 从池取空闲实例（隐藏占位）或新建；`release(inst)` 重置内部状态（清 data/observer、断开子组件）后归还；池上限与类型分桶（不同组件模板不同池）。
- 要点：重置要彻底（组件 data 恢复初始值、定时器/订阅清理——组件实现 reset 钩子协议）；复用时要重新绑定数据（properties 更新触发 observer 重载数据）；池按设备档（低端池小）。
- 边界：实例池与虚拟列表配合（可见区渲染 + 池供给）；组件创建成本高的才值得池化（简单文本组件不值得）。
- 评分点：reset 钩子协议与类型分桶。

```javascript

class ComponentPool {
  constructor(factory, { max = 10 } = {}) {
    this.factory = factory; this.max = max; this.idle = []; this.active = new Set();
  }
  acquire(props) {
    let inst = this.idle.pop();
    if (!inst && this.total() < this.max) inst = this.factory(); // 池空且未达上限：新建
    if (!inst) throw new Error('pool exhausted');                // 或等待释放
    inst.reset?.();                                             // 重置钩子：清 data/定时器
    Object.assign(inst.properties, props);                      // 重新绑定数据
    inst.show();
    this.active.add(inst);
    return inst;
  }
  release(inst) {
    inst.hide();
    inst.detach?.();                                            // 断开子组件/订阅
    this.active.delete(inst);
    this.idle.push(inst);
  }
  total() { return this.idle.length + this.active.size; }
}
// 组件侧实现协议：reset() { this.setData(initialData); clearInterval(this.timer); }
// 配合虚拟列表：可见区向池 acquire，滚出区 release
```
