## PER-868：手写一个长表单分步渲染控制器：按步挂载、自动滚动定位与校验去抖

**答**：
- 需求：实现 StepFormController：addStep(fields)；goTo(n)：卸载当前步（存草稿）、挂载目标步、滚动到步首（smooth）；validateStep(n) 做该步全量校验（异步支持），全部通过才允许 goTo(n+1)；字段 blur 校验带 200ms 去抖；提供 draft() 导出全部草稿。
- 边界：goTo 跳步（n > 当前+1）需先逐校验中间步；挂载中重复 goTo 排队（防竞态）；卸载时未保存的输入自动入草稿。
- 评分点：跳步逐校验；goTo 竞态排队；blur 去抖。

```javascript
class StepFormController {
  constructor() { this.steps = []; this.cur = 0; this.drafts = {}; this.mounting = false; }
  addStep(fields) { this.steps.push({ fields }); }
  debounce(fn, ms = 200) { let t; return (...a) => { clearTimeout(t); t = setTimeout(() => fn(...a), ms); }; }
  blurValidate = this.debounce(f => this.validateField(f), 200);   // blur 去抖
  async goTo(n) {
    if (this.mounting) return;                                  // 竞态排队
    if (n > this.cur + 1) {                                     // 跳步：逐校验
      for (let i = this.cur; i < n; i++)
        if (!(await this.validateStep(i))) return { ok: false, failStep: i };
    }
    this.mounting = true;
    try {
      this.saveCurrent();
      await this.mount(n);
      this.cur = n;
      scrollIntoViewSmooth(this.steps[n].el);                   // 平滑滚动到步首
      return { ok: true };
    } finally { this.mounting = false; }
  }
  saveCurrent() {
    this.drafts[this.cur] = this.steps[this.cur].fields
      .map(f => ({ name: f.name, value: f.value ?? '' }));      // 未保存输入入草稿
  }
  async validateStep(n) {
    const results = await Promise.all(this.steps[n].fields.map(f => this.validateField(f)));
    return results.every(Boolean);
  }
  draft() { return { ...this.drafts }; }
}
```
