## PER-602：手写一个前端安全需求预检生成器：输入功能描述关键词，输出对应的安全 checklist 条目

**答**：
- 把安全经验固化为规则库：功能关键词（上传/富文本/支付/导出/登录/分享）映射到对应 checklist 条目，生成器在 PR/需求单里自动附加，防止人工评审漏项。
- 要点：规则条目带为什么"（风险说明）与验证方法，否则沦为形式主义勾选；支持组合（"上传+图片触发图片特化条目）。
- 边界：规则库版本化并支持热更新（新漏洞类型及时补）；输出按风险排序，高危条目置顶。
- 评分点：关键词组合匹配与高危排序。

```javascript

const RULES = {
  upload: [{ item: '文件类型白名单（MIME+魔数双重校验）', why: '绕过扩展名上传 webshell', verify: '改包伪造 MIME 测试' },
           { item: '文件名服务端重命名+路径隔离', why: '路径穿越与覆盖', verify: '上传 ../../test 文件名' },
           { item: '文件域名与业务域隔离', why: '同域上传即同源 XSS', verify: '直接访问文件 URL 执行脚本' }],
  richtext: [{ item: '白名单净化（DOMPurify 类）', why: '黑名单枚举不全', verify: 'mXSS 用例集' },
             { item: 'CSP 兜底', why: '净化被绕过时有第二道墙', verify: '违规上报是否清零' }],
  pay: [{ item: '金额/价格服务端计算', why: '前端价格可篡改', verify: '改包测试' },
        { item: '幂等 token 防重复提交', why: '重复扣款', verify: '并发双击' }],
};
function precheck(desc) {
  const hits = Object.keys(RULES).filter(k => desc.includes(k));
  const items = hits.flatMap(k => RULES[k].map(r => ({ ...r, tag: k })));
  return items.sort((a, b) => (a.tag === 'pay' ? -1 : 1)); // 高危域置顶
}
console.log(precheck('支持图片上传与富文本评论'));
```
