## PER-751：手写一个启动关键路径瘦身器：从构建产物分析出首屏实际需要的模块并输出瘦身清单

**答**：
- 思路：以首屏入口为根，用构建 stats（模块依赖图）做可达性分析——首屏实际执行到的模块集合 vs 打进首屏 chunk 的集合，差集就是可移出的（懒加载/拆包）。
- 要点：可达性依据运行时插桩（首屏执行时记录实际 require/import 的模块）比静态分析准（条件分支不会全跑）；输出清单按体积排序（可省字节数）；重复依赖（多版本 lodash）单独列出。
- 边界：运行时插桩只覆盖首次执行路径，懒触发模块会漏（保守标记）；分析结果要与 sourcemap 交叉验证。
- 评分点：运行时插桩可达性与体积排序。

```javascript

const fs = require('fs');
function slimFirstScreen(statsFile, executedModules) {
  const stats = JSON.parse(fs.readFileSync(statsFile, 'utf8'));
  const modules = new Map(stats.modules.map(m => [m.name, m.size]));
  const executed = new Set(executedModules);                    // 运行时插桩记录
  const slim = [];
  for (const [name, size] of modules) {
    if (!executed.has(name)) slim.push({ name, sizeKB: +(size / 1024).toFixed(1) });
  }
  slim.sort((a, b) => b.sizeKB - a.sizeKB);                     // 体积排序
  const totalKB = +(slim.reduce((s, m) => s + m.sizeKB, 0)).toFixed(0);
  const dupDeps = findDupVersions(stats.modules);               // 重复版本依赖
  return { top: slim.slice(0, 15), totalKB, dupDeps,
    advice: `首屏 chunk 可移出约 ${totalKB}KB（插桩未覆盖的懒触发模块需人工确认）` };
}
function findDupVersions(mods) {
  const versions = new Map();
  mods.forEach(m => { const pkg = m.name.match(/node_modules\/(.+?)\//)?.[1];
    if (pkg) versions.set(pkg, (versions.get(pkg) ?? new Set()).add(m.name)); });
  return [...versions.entries()].filter(([, s]) => s.size > 1).map(([k]) => k);
}
// 运行时插桩：webpack require 钩子/import 回调记录首屏实际执行模块列表
```
