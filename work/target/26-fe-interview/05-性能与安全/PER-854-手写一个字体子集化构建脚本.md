## PER-854：手写一个字体子集化构建脚本：按字符集生成 woff2 子集与按需分包

**答**：
- 需求：实现 buildFontSubsets(texts, options)：收集页面文案（输入字符串数组）去重得到字符集；按每片 maxChars（如 500 字）切片，输出每片的 {range: [minCode, maxCode], chars} 与对应的 unicode-range CSS 声明文本；生成分片清单（真实环境接 pyftsubset 命令，这里输出命令行数组）。
- 边界：字符按码位排序后连续区段合并声明（不连续字符用逗号分隔多个 range）；空文案返回空清单；同一字符多页共用只保留一份。
- 评分点：切片与 range 合并；unicode-range CSS 语法正确；幂等去重。

```javascript
function buildFontSubsets(texts, { maxChars = 500, fontFile = 'cn.otf' } = {}) {
  const chars = [...new Set(texts.join(''))].sort((a, b) => a.codePointAt(0) - b.codePointAt(0));
  if (!chars.length) return { slices: [], commands: [] };
  const slices = [];
  for (let i = 0; i < chars.length; i += maxChars)
    slices.push(chars.slice(i, i + maxChars));
  const toRange = slice => {                   // 连续区段合并成 unicode-range
    const codes = slice.map(c => c.codePointAt(0)).sort((a, b) => a - b);
    const parts = [];
    let s = codes[0], p = codes[0];
    for (const c of codes.slice(1).concat(Infinity)) {
      if (c === p + 1) { p = c; continue; }
      parts.push(s === p ? `U+${s.toString(16)}` : `U+${s.toString(16)}-${p.toString(16)}`);
      s = p = c;
    }
    return parts.join(', ');
  };
  return {
    slices: slices.map((sl, i) => ({ id: i, chars: sl.join(''),
      range: toRange(sl),
      css: `@font-face{font-family:'CN-Sub${i}';src:url('sub${i}.woff2') format('woff2');unicode-range:${toRange(sl)};}` })),
    commands: slices.map((sl, i) =>
      `pyftsubset ${fontFile} --text="${sl.join('')}" --flavor=woff2 --output-file=sub${i}.woff2`),
  };
}
```
