## PER-1200：手写一个同意状态机：覆盖授予/撤回/过期/合并

**答**：
- 需求：实现 ConsentStore。grant(bucket, policyVersion) 授予并记录时间与版本；withdraw(bucket) 撤回并记录；snapshot() 返回当前 { bucket: bool }；merge(device, account) 从严合并（false 优先）；过期：grant 超过 180 天且策略版本已更新则需重新确认（state 返回 stale）。
- 边界：同 bucket 重复 grant 覆盖；withdraw 未授予的 bucket 也记录（防重复询问）；policyVersion 变化时 snapshot 中该 bucket 标记 stale。
- 评分点：日志驱动状态；stale 标记；过期撤回；从严合并

```javascript
class ConsentStore {
  constructor(currentPolicy) { this.policy = currentPolicy; this.log = []; }
  grant(bucket, policyVersion) {
    this.log.push({ bucket, granted: true, ts: Date.now(), v: policyVersion });
  }
  withdraw(bucket) {
    this.log.push({ bucket, granted: false, ts: Date.now() });
  }
  snapshot() {
    const state = {};
    for (const e of this.log) {
      state[e.bucket] = e.granted ? { on: true, ts: e.ts, v: e.v } :
        { on: false, ts: e.ts, v: null, declined: true };
    }
    for (const [b, s] of Object.entries(state)) {
      if (s.on && this.policy.updatedAt > s.ts)
        s.stale = true;                              // 需重新确认
      if (s.on && Date.now() - s.ts > 180 * 86400_000 && s.stale)
        s.on = false;                                // 过期未确认视为撤回
    }
    return state;
  }
  static merge(device, account) {
    const out = {};
    for (const b of new Set([...Object.keys(device), ...Object.keys(account)])) {
      const d = device[b]?.on, a = account[b]?.on;
      out[b] = { on: d === false || a === false ? false : (a ?? d ?? false) };
    }
    return out;
  }
}
```
