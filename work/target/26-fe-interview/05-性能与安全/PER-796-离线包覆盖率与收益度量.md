## PER-796：离线包覆盖率与收益度量：包命中率、流量节省与秒开提升的归因

**答**：
- 三个度量维度：① 命中率（拦截命中次数/总请求数，分包统计）；② 流量节省（命中文件大小求和，折算成用户流量成本）；③ 秒开收益（命中用户的首屏耗时 vs 未命中回源用户对比）。
- 归因陷阱：命中用户本身可能是高频老用户（设备/网络画像偏移），不能直接对比——用同请求回源用户的同期对比，或按用户分档分层对比。
- 健康度指标：错配率（miss 中因版本不一致导致的比例）、回源率、包体积趋势。错配率突增通常先于秒开劣化。
- 产出物：每周离线包收益周报（分业务包：命中率/节省流量/秒开 delta），指导包拆分与预下载策略调整。

```javascript
function offlineReport(events, manifests) {
  const byPkg = {};
  for (const e of events) {                                  // e: {pkg, url, bytes, hit, firstScreenMs, hitType}
    const s = byPkg[e.pkg] ??= { req: 0, hit: 0, bytesSaved: 0, fsHit: [], fsMiss: [] };
    s.req++;
    if (e.hit) { s.hit++; s.bytesSaved += e.bytes; }
    (e.hit && e.hitType !== 'fallback' ? s.fsHit : s.fsMiss).push(e.firstScreenMs);
  }
  return Object.entries(byPkg).map(([pkg, s]) => ({
    pkg, hitRate: +(s.hit / s.req).toFixed(3),
    savedMB: +(s.bytesSaved / 1048576).toFixed(2),
    fsDeltaP75: p75(s.fsHit) - p75(s.fsMiss),                // 命中 vs 回源首屏差
    caveat: '需按用户分档校正（高频用户偏移）',
  }));
}
```
