## PER-558：手写一个视频起播性能自动化测试：断言冷起播时长、首帧后卡顿与自动降档行为

**答**：
- 用 puppeteer 驱动视频页：CDP 节流到弱网档，点播放按钮计时到 `requestVideoFrameCallback` 首帧；监听 waiting/playing 统计卡顿；通过页面 API 查询当前码率档位验证自动降档。
- 要点：冷起播要每次清缓存与 storage（hls.js/dash.js 的本地缓冲也要清）；断言值按网络档位分档设预算（4G 起播 1s、3G 起播 2.5s）。
- 边界：视频元素自动播放被浏览器策略拦截时（非静音），要先测静音自动播放分支；找不到视频源时 fail 并输出源 URL。
- 评分点：冷起播清态与分档预算。

```javascript

const puppeteer = require('puppeteer');
const BUDGET = { '4g': 1000, '3g': 2500 };
async function videoStartTest(url, net) {
  const browser = await puppeteer.launch();
  const page = await browser.newPage();
  const cdp = await page.createCDPSession();
  await cdp.send('Network.setCacheDisabled', { cacheDisabled: true }); // 冷态
  await cdp.send('Network.emulateNetworkConditions', {
    offline: false, latency: net === '3g' ? 300 : 100,
    downloadThroughput: net === '3g' ? 0.5e6 / 8 : 4e6 / 8, uploadThroughput: 1e6 / 8 });
  await page.goto(url, { waitUntil: 'domcontentloaded' });
  const r = await page.evaluate(() => new Promise(res => {
    const v = document.querySelector('video');
    if (!v) return res({ fail: 'no-video' });
    const t0 = performance.now();
    v.muted = true;                                       // 静音过自动播放策略
    v.play();
    const onFrame = () => res({ firstFrameMs: +(performance.now() - t0).toFixed(0),
      level: window.__hls?.currentLevel ?? -1 });
    'requestVideoFrameCallback' in v ? v.requestVideoFrameCallback(onFrame) : (v.onplaying = onFrame);
    setTimeout(() => res({ fail: 'start-timeout' }), 15000);
    let rebuffers = 0;
    v.addEventListener('waiting', () => rebuffers++);     // 首帧后的卡顿单独统计
    v.addEventListener('playing', () => { if (v.readyState >= 3 && performance.now() - t0 > 100) {} });
  }));
  await browser.close();
  const budget = BUDGET[net];
  return { net, ...r, pass: r.firstFrameMs ? r.firstFrameMs <= budget : false, budget };
}
videoStartTest('https://example.com/course/1', '3g').then(console.log);
```
