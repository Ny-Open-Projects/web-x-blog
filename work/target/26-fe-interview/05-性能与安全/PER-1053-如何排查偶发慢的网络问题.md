## PER-1053：如何排查"偶发慢"的网络问题

**答**：
- 偶发慢的来源：连接池竞争（高并发时排队）、CDN 单节点劣化、运营商 QoS、DNS 轮询到坏节点、GC 与主线程阻塞让"网络显得慢"。
- 排查法：扩大采样（偶发问题靠样本量）、按时段/节点/运营商分桶对比、用 resource timing 完整瀑布还原单次请求。
- 工具：发起端打点（发起时间/排队时长）+ 服务器端打点（到达时间），两端时钟差用 NTP 近似校准。
- 预案：偶发慢高频出现时自动开启请求降并发与关键请求优先，而不是人工观察。

```javascript
// 排队时长观测：请求发起延迟
let activeCount = 0;
function timedFetch(url, init) {
  const queuedAt = performance.now();
  const p = (async () => {
    const waitMs = performance.now() - queuedAt;   // 进调度器前等待
    activeCount++;
    const t0 = performance.now();
    try { return await fetch(url, init); }
    finally { activeCount--;
      report({ url: sanitizeUrl(url), waitMs: Math.round(waitMs),
        ms: Math.round(performance.now() - t0), concurrent: activeCount }); }
  })();
  return p;
}
// waitMs 高 -> 客户端并发排队问题；否则看服务端/网络
```
