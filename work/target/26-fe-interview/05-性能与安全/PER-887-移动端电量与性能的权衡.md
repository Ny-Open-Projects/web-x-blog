## PER-887：移动端电量与性能的权衡：哪些前端行为最耗电、如何度量与优化

**答**：
- 耗电大户：高频定位（GPS 持续开启）、持续传感器采样（陀螺仪 100Hz）、长连接心跳过密、常驻动画（即使不可见）、高频定时器、视频后台不解码暂停。
- 度量手段：设备档 + 电量 API（getBattery，Chrome 支持，iOS 不支持需降级用 CPU 时间估算）；对比实验（开关某功能跑 30 分钟测耗电百分比）。
- 优化清单：定位改"用时开启"（页面可见+相关交互才 start）；传感器降采样（100Hz → 20Hz 对摇一摇足够）；心跳按网络档自适应（WiFi 4 分钟 / 蜂窝 2 分钟内合并其他保活）；动画在 document.hidden 时暂停。
- 组织层面：耗电敏感行为清单进 code review checklist（新增持续采集类代码需注明理由与停止条件）。

```javascript
const batteryAware = {
  sensors: { gps: '用时开启：enter 场景 start，leave/hidden stop',
    imu: '20Hz 足够，游戏场景才 100Hz' },
  heartbeat: { wifi: 240000, cellular: 120000 },              // 心跳自适应
  animation: 'document.hidden 时 pause，恢复时 resume',
};
addEventListener('visibilitychange', () => {
  if (document.hidden) { anim.pause(); sensors.stopAll(); }    // 后台全停
  else anim.resume();
});
// 电量 API 度量（可用时）
navigator.getBattery?.().then(b => {
  report('battery', { level: b.level, charging: b.charging });
  if (!b.charging && b.level < 0.2) enablePowerSaveMode();     // 低电量省电模式
});
```
