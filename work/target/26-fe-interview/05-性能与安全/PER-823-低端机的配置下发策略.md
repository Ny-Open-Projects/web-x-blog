## PER-823：低端机的配置下发策略：动画开关、图片档位与功能裁剪的服务端下发与缓存

**答**：
- 思路：低端机的具体动作（关哪些动效、图片降到哪档、裁哪些功能）不写死在客户端，而是服务端下发"分档配置"，客户端按设备档应用——调整策略不需要发版。
- 配置结构：{ tier: low, flags: { effects: off, imgTier: 400, disableA: true } }；下发时机：启动时拉取 + 缓存本地（弱网兜底用上次配置），支持按版本/渠道/灰度人群定向。
- 缓存与容灾：配置请求失败用本地缓存；缓存也没有用编译期默认值（三级 fallback）；配置带版本号与生效时间，避免新旧实例混跑冲突。
- 验证闭环：配置下发要有"生效埋点"（实际应用的 flags 上报），防止"以为发了但没生效"。

```javascript
const tierConfig = {
  fetch: async () => {
    try {
      const remote = await fetchTierConfig();       // 1. 服务端按档下发
      saveCache(remote);                            //    版本号+时间戳落盘
      return applyFlags(remote);
    } catch {
      const cached = readCache();                   // 2. 本地缓存兜底
      return cached ? applyFlags(cached) : applyFlags(DEFAULTS);   // 3. 编译期默认
    }
  },
};
const DEFAULTS = { low: { effects: 'off', imgTier: 400, disableHeavy: true },
                   mid: { effects: 'reduced', imgTier: 800 }, high: {} };
function applyFlags(cfg) {
  report('tier-config-applied', { v: cfg.version, flags: cfg.flags });   // 生效埋点
  return cfg.flags;
}
```
