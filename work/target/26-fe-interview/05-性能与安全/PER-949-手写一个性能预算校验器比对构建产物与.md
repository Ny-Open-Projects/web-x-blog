## PER-949：手写一个性能预算校验器：比对构建产物与预算并输出超标明细

**答**：
- 需求：实现 checkBudget(manifest, budgets)。manifest 为 { file: { type, size } }，budgets 为 { type: maxBytes } 与 { total: maxBytes }；输出 { byType, total, overruns }，overruns 按 超出比例 降序，含 file/type/size/limit/over。
- 边界：未知 type 的文件计入 total 但不参与分类型预算；size 为 0 忽略；total 预算不存在时跳过总额检查。
- 评分点：类型聚合；总额检查；0 字节忽略；超限比例排序

```javascript
function checkBudget(manifest, budgets) {
  const { total, ...byTypes } = budgets;
  const byType = {}, overruns = [];
  let sum = 0;
  for (const [file, { type, size }] of Object.entries(manifest)) {
    if (size <= 0) continue;                          // 0 字节忽略
    sum += size;
    if (byTypes[type]) {
      byType[type] = (byType[type] ?? 0) + size;
      if (byType[type] > byTypes[type])
        overruns.push({ file, type, size, limit: byTypes[type],
          over: +(byType[type] / byTypes[type]).toFixed(2) });
    }
  }
  const totalOver = total && sum > total
    ? [{ file: '__total__', type: 'total', size: sum, limit: total,
         over: +(sum / total).toFixed(2) }] : [];
  return { byType, total: sum,
    overruns: [...totalOver, ...overruns].sort((a, b) => b.over - a.over) };
}
```
