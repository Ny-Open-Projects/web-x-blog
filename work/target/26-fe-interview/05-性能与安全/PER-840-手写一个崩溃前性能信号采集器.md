## PER-840：手写一个崩溃前性能信号采集器：异常发生时回溯最近 N 秒的性能时序并上报

**答**：
- 需求：实现 BlackBoxRecorder：环形缓冲保存最近 N 秒（默认 30s）的性能样本（时间、heapMB、fps、长任务数、路由）；提供 push(sample) 与 snapshot()；提供 hookError(handler)——任何异常上报时自动附带快照；内存约束：样本超过 maxCount（如 60 条）丢弃最旧。
- 边界：snapshot 返回深拷贝（防上报过程中缓冲变化）；hookError 支持多个 handler；push 的时间戳缺失时自动补当前时间。
- 评分点：环形缓冲双约束（时间窗+条数）；深拷贝；异常钩子自动附加。

```javascript
class BlackBoxRecorder {
  constructor({ windowMs = 30000, maxCount = 60 } = {}) {
    this.buf = []; this.windowMs = windowMs; this.max = maxCount; this.handlers = [];
  }
  push(sample) {
    const s = { t: sample.t ?? Date.now(), ...sample };        // 时间戳兜底
    this.buf.push(s);
    while (this.buf.length > this.max ||                       // 条数上限
      (this.buf.length && s.t - this.buf[0].t > this.windowMs)) // 时间窗
      this.buf.shift();
  }
  snapshot() { return this.buf.map(x => ({ ...x })); }         // 深拷贝
  hookError(fn) {
    this.handlers.push(fn);
    return (err, ctx) => fn({ error: String(err?.message ?? err),
      stack: String(err?.stack ?? '').slice(0, 2000), ctx,
      blackbox: this.snapshot() });                            // 自动附带快照
  }
}
// 使用：window.addEventListener('error', recorder.hookError(r => report('crash', r)))
```
