## PER-1196：如何应对"数据跨境回传"的实时风控类场景

**答**：
- 场景：风控引擎境外（全球厂商），国内用户行为实时出境评估——合规与实时性冲突。
- 方案：境内风控引擎前置（境内决策），境外引擎只接收脱敏特征（无直接标识）；或本地推理（端侧风控 1151）。
- 评估：出境特征清单评审（每个特征证明无个体重识别可能）。
- 降级：出境通道不可用时境内引擎兜底（阈值保守化）。

```javascript
// 风控特征出境白名单
const SAFE_FEATURES = ['cart_value_band', 'session_depth', 'device_tier'];
function outboundRiskPayload(features) {
  const safe = Object.fromEntries(Object.entries(features)
    .filter(([k]) => SAFE_FEATURES.includes(k)));
  if (Object.keys(safe).length !== Object.keys(features).length)
    report({ type: 'risk-features-dropped',
      dropped: Object.keys(features).filter(k => !SAFE_FEATURES.includes(k)) });
  return safe;                                     // 分桶特征无个体标识
}
```
