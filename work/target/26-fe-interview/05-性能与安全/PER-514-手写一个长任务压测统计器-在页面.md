## PER-514：手写一个长任务压测统计器：在页面持续交互 60 秒内采集 Long Task，输出阻塞时长分布

**答**：
- 用 `PerformanceObserver` 的 `longtask` 类型采集，关键字段 `duration` 与 `attributedContainerType`（归因到 script/layout-shift 等）。
- 要点：压测期间要模拟真实交互（点击、滚动、输入），纯静置页面测不出 TBT 问题；统计输出 p50/p90/max 与总阻塞时长（>50ms 部分之和）。
- 边界：observer 回调里不要做重计算，先入队、结束后统一聚合；页面 unload 前要把数据 flush 出去（sendBeacon）。
- 评分点：TBT 计算（每任务超出 50ms 的部分累加）是否正确。

```javascript

function longTaskProbe(interactMs = 60000) {
  const tasks = [];
  new PerformanceObserver(list => {
    list.getEntries().forEach(e => tasks.push({
      dur: e.duration,
      over: e.duration - 50,                                  // TBT：超出 50ms 的部分
      who: e.attributedContainerType || 'unknown',
    }));
  }).observe({ type: 'longtask', buffered: true });

  return new Promise(resolve => {
    const timer = setInterval(() => {                         // 模拟真实交互压测
      window.scrollBy(0, 300);
      document.body.click();
      window.dispatchEvent(new Event('resize'));
    }, 250);
    setTimeout(() => {
      clearInterval(timer);
      const q = p => tasks.map(t => t.dur).sort((a, b) => a - b)[Math.floor(tasks.length * p)] ?? 0;
      resolve({
        count: tasks.length,
        p50: q(0.5), p90: q(0.9), max: Math.max(0, ...tasks.map(t => t.dur)),
        tbt: tasks.reduce((s, t) => s + Math.max(0, t.over), 0),
        top: tasks.sort((a, b) => b.dur - a.dur)[0],
      });
    }, interactMs);
  });
}
longTaskProbe().then(r => navigator.sendBeacon('/perf/longtask', JSON.stringify(r)));
```
