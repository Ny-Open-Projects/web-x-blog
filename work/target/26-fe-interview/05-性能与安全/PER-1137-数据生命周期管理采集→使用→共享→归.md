## PER-1137：数据生命周期管理：采集→使用→共享→归档→销毁的工程控制

**答**：
- 每阶段控制点：采集（同意+最小化）、使用（目的绑定，跨目的需重新评估）、共享（合同+技术限制）、归档（降级访问）、销毁（可证明的删除）。
- 保留期：字段级声明（注册表 1004），到期自动删除任务；超期保留需审批留痕。
- 销毁证明：删除任务执行记录（影响行数/时间/操作人），支持监管问询。
- 备份特殊：备份销毁随滚动过期，承诺删除时限必须 ≤ 备份周期。

```javascript
// 保留期清理任务
const RETENTION = { 'page_view': 90, 'order_done': 1095, 'consent-log': 1825 };
function purgeExpired(now = Date.now()) {
  const tasks = [];
  for (const [event, days] of Object.entries(RETENTION)) {
    const cutoff = now - days * 86400_000;
    tasks.push({ event, cutoff, sql:
      `DELETE FROM events WHERE type='${event}' AND ts < ${cutoff}` });
  }
  return tasks;   // 执行后写审计：{ task, rows, at, by: 'system' }
}
// 备份对齐：max(RETENTION) <= 备份保留周期，否则调整备份策略
```
