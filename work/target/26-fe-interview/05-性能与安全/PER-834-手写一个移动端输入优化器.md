## PER-834：手写一个移动端输入优化器：composition 感知防抖与受控更新节流

**答**：
- 需求：实现 createInputOptimizer：包装输入元素，提供 onRaw（每字符本地回显，零延迟）与 onSync（防抖 300ms 且组合期挂起，compositionend 后立即触发一次 sync）；提供 syncNow() 强制同步（失焦/提交前调用）；销毁清理定时器与监听。
- 边界：组合期内连续 input 不重置防抖计时（组合结束统一处理）；syncNow 在组合期调用要等 compositionend（排入待同步）；重复调用防抖合并。
- 评分点：组合期挂起逻辑；syncNow 的组合期排队；清理完整性。

```javascript
function createInputOptimizer(input, { sync, debounceMs = 300 } = {}) {
  let timer = null, composing = false, pendingForce = false;
  const doSync = () => { timer = null; sync(input.value); };
  const onCompStart = () => { composing = true; };
  const onCompEnd = () => {
    composing = false;
    if (pendingForce) { pendingForce = false; return doSync(); }   // 排队的强制同步
    if (!timer) doSync();                 // 组合结束立即同步一次
  };
  const onInput = () => {
    if (composing) return;                // 组合期挂起
    if (!timer) { timer = setTimeout(doSync, debounceMs); }   // 防抖合并：已有定时器不重置
  };
  const onBlur = () => forceSync();
  function forceSync() {
    if (composing) { pendingForce = true; return; }   // 组合期：排队等 compend
    clearTimeout(timer); doSync();
  }
  input.addEventListener('compositionstart', onCompStart);
  input.addEventListener('compositionend', onCompEnd);
  input.addEventListener('input', onInput);
  input.addEventListener('blur', onBlur);
  return {
    syncNow: forceSync,
    destroy() {                           // 清理
      clearTimeout(timer);
      input.removeEventListener('compositionstart', onCompStart);
      input.removeEventListener('compositionend', onCompEnd);
      input.removeEventListener('input', onInput);
      input.removeEventListener('blur', onBlur);
    },
  };
}
```
