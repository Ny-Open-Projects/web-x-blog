## PER-1281：手写一个发布风险评分器：按变更内容预估性能风险

**答**：
- 需求：implement releaseRisk(diff, thresholds)。diff 为 { jsAddedKB, cssAddedKB, newSyncScripts, newImages, newThirdParties }；评分：jsAddedKB/100 × 2 + newSyncScripts × 8 + newImages × 1 + newThirdParties × 10；> 20 高危（需性能评审）、> 8 中危（冒烟必跑）、否则低危；输出 { score, level, reasons }。
- 边界：负增量（删除）不计分但记录 savings；缺失字段按 0；reasons 列出主要贡献项。
- 评分点：加权评分；等级判定；贡献项；负增量

```javascript
function releaseRisk(diff, { jsW = 2, syncW = 8, imgW = 1, thirdW = 10 } = {}) {
  const d = { jsAddedKB: 0, newSyncScripts: 0, newImages: 0,
    newThirdParties: 0, ...diff };
  const parts = [
    ['JS 增量', Math.max(0, d.jsAddedKB) / 100 * jsW],
    ['同步脚本', d.newSyncScripts * syncW],
    ['新增图片', d.newImages * imgW],
    ['新增三方', d.newThirdParties * thirdW],
  ];
  const score = Math.round(parts.reduce((s, [, v]) => s + v, 0));
  const reasons = parts.filter(([, v]) => v >= 5).map(([n, v]) => `${n}(${Math.round(v)})`);
  return { score, savings: Math.min(0, d.jsAddedKB) || 0,
    level: score > 20 ? 'high' : score > 8 ? 'mid' : 'low',
    reasons };
}
// high -> 强制性能评审；mid -> 冒烟必跑；low -> 常规
```
