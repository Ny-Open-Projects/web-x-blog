## PER-1069：手写一个断点续传下载器

**答**：
- 需求：实现 resumableDownload(url, { chunk, onProgress, storage })。用 IndexedDB（storage 抽象）持久化已下载分片 { etag, parts: Map(idx->blob) }；HEAD 获取 total 与 etag，etag 变化清空续传；中断后再次调用跳过已有分片；全部完成后合并 Blob 并清理存储。
- 边界：服务器不支持 Range（HEAD 无 Accept-Ranges: bytes）直接一次性下载；onProgress 收到 (done, total)；重复调用共享 etag 校验逻辑。
- 评分点：Range 校验；etag 变更清空；持久化续传；合并清理

```javascript
async function resumableDownload(url, { chunk = 1024 * 1024, onProgress, storage } = {}) {
  const head = await fetch(url, { method: 'HEAD' });
  if (!head.headers.get('accept-ranges')?.includes('bytes')) {
    const r = await fetch(url);                   // 整体下载兜底
    return r.blob();
  }
  const total = +head.headers.get('content-length');
  const etag = head.headers.get('etag');
  const saved = await storage.get(url);
  const parts = (saved && saved.etag === etag) ? new Map(saved.parts) : new Map();
  const totalParts = Math.ceil(total / chunk);
  for (let i = 0; i < totalParts; i++) {
    if (parts.has(i)) continue;
    const start = i * chunk, end = Math.min(start + chunk, total) - 1;
    const r = await fetch(url, { headers: { Range: `bytes=${start}-${end}` } });
    if (r.status !== 206) throw new Error('range failed');
    if (r.headers.get('etag') && r.headers.get('etag') !== etag)
      { await storage.clear(url); throw new Error('etag changed'); }
    parts.set(i, await r.blob());
    await storage.put(url, { etag, parts: Object.fromEntries(parts) });   // 持久化
    onProgress?.(parts.size, totalParts);
  }
  const merged = new Blob([...Array(totalParts).keys()].map(i => parts.get(i)));
  await storage.clear(url);
  return merged;
}
```
