## PER-1202：手写一个 k-匿名检查与泛化建议器

**答**：
- 需求：实现 kCheck(rows, quasi, k=5)。返回 { ok, minGroup, offenders }（offenders 为小于 k 的桶 key 列表）；实现 generalize(rows, quasi, k)：对未达标桶做泛化——数值字段按 10 分箱粗化、字符串字段截断 3 字符，循环直到达标（最多 5 轮），返回泛化后 rows 与轮数。
- 边界：quasi 为空抛错；全部字段泛化到最粗仍不达标返回 { ok: false, rounds: 5, rows }；rows 为空直接 ok。
- 评分点：分桶统计；offenders；泛化迭代；轮数上限

```javascript
function kCheck(rows, quasi, k = 5) {
  if (!quasi.length) throw new Error('quasi required');
  if (!rows.length) return { ok: true, minGroup: 0, offenders: [] };
  const groups = {};
  for (const r of rows) {
    const key = quasi.map(q => r[q]).join('|');
    groups[key] = (groups[key] ?? 0) + 1;
  }
  const offenders = Object.entries(groups).filter(([, c]) => c < k).map(([x]) => x);
  return { ok: !offenders.length,
    minGroup: Math.min(...Object.values(groups)), offenders };
}
function generalize(rows, quasi, k = 5) {
  let out = rows.map(r => ({ ...r })); let rounds = 0;
  while (rounds < 5 && !kCheck(out, quasi, k).ok) {
    rounds++;
    out = out.map(r => ({ ...r,
      ...Object.fromEntries(quasi.map(q => [q, generalizeValue(r[q])])),
    }));
  }
  return { rows: out, rounds, ok: kCheck(out, quasi, k).ok };
}
function generalizeValue(v) {
  return typeof v === 'number'
    ? Math.floor(v / 10) * 10                      // 数值 10 分箱
    : String(v).slice(0, 3);                       // 字符串截断
}
```
