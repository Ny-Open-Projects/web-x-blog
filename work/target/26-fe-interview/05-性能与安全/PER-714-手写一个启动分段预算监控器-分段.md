## PER-714：手写一个启动分段预算监控器：分段计时 + 超预算自动执行裁剪预案 + 触发率统计

**答**：
- 实现：分段 mark/measure（container/html/js/api/interact），每段设预算，超预算时查该段的裁剪预案（函数注册表）执行并计数；上报分段耗时与裁剪触发。
- 要点：裁剪动作要幂等可恢复（用户刷新后按新预算重新决策）；触发率统计（触发次数/会话数，> 20% 说明基础体验不行）；预案按段注册（html 段超标 -> 关非关键 preload；js 段超标 -> 延后非首屏组件）。
- 边界：裁剪本身不能引入卡顿（动作轻量，重动作放 idle）；预算按设备档查表。
- 评分点：分段-预案映射与触发率健康线。

```javascript

class StartupBudgetMonitor {
  constructor(budgetTable) { this.table = budgetTable; this.trimCounts = new Map(); }
  async run() {
    const stages = ['container', 'htmlCss', 'jsExec', 'firstApi', 'interact'];
    for (const s of stages) {
      const t0 = performance.now();
      await this.stageDone(s);                                  // 各段就绪钩子
      const dur = performance.now() - t0;
      const budget = this.table[window.__deviceTier]?.[s] ?? this.table.default[s];
      if (dur > budget) await this.trim(s, dur, budget);        // 超预算裁剪
    }
    this.report();
  }
  async trim(stage, dur, budget) {
    const plan = TRIM_PLANS[stage];                             // 分段-预案映射
    if (!plan) return;
    const over = dur / budget;
    if (over > 1.3) await plan.execute({ over });               // 超 30% 才动
    this.trimCounts.set(stage, (this.trimCounts.get(stage) ?? 0) + 1);
  }
  report() {
    const sessions = tracker.sessions ?? 1;
    for (const [s, n] of this.trimCounts) {
      const rate = n / sessions;
      track('trim-trigger', { stage: s, rate: +rate.toFixed(2),
        unhealthy: rate > 0.2 });                               // 触发率 > 20% 要立项
    }
  }
  stageDone(s) { return STAGE_HOOKS[s](); }
}
const TRIM_PLANS = {
  htmlCss: { execute: () => removeNonCriticalPreload() },
  jsExec: { execute: () => deferNonFirstScreenComponents() },
  firstApi: { execute: () => cutNonCoreApis() },
};
```
