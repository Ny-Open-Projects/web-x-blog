## PER-827：旗舰机与低端机的体验分级测试：分级用例设计与验收标准

**答**：
- 核心观念：同一个功能在旗舰机"能用"不等于低端机"能用"，验收标准必须按档分级——旗舰机保流畅（60fps）、低端机保可用（30fps+ 可完成核心流程）。
- 分级用例设计：核心流程（下单/支付/IM 收发）全档必测；重资源场景（长列表/动画/直播）按档设差异化断言（如低端机断言"触发降级后帧率达标"而非"全动效流畅"）。
- 量化验收表：每档定义帧率、内存峰值、冷启动、秒开四项阈值；测试产出填表对比，超阈值项阻断合入。
- 执行机制：接入云真机批量跑分（覆盖 Top 机型），PR 阶段跑核心用例快检，版本阶段跑全量矩阵。

```javascript
const tierStandards = {                    // 分级验收阈值
  high: { fps: 55, memMB: 400, coldStartMs: 1500, fsMs: 1200 },
  mid:  { fps: 45, memMB: 300, coldStartMs: 2500, fsMs: 2000 },
  low:  { fps: 28, memMB: 220, coldStartMs: 4000, fsMs: 3500, note: '允许降级后达标' },
};
function gradeAcceptance(results) {          // results: {tier, case, fps, memMB, ...}
  return results.map(r => {
    const std = tierStandards[r.tier];
    const fails = Object.entries(std)
      .filter(([k, v]) => typeof v === 'number' &&
        (k === 'fps' ? r[k] < v : r[k] > v))
      .map(([k]) => k);
    return { ...r, pass: fails.length === 0, failedMetrics: fails };
  });
}
```
