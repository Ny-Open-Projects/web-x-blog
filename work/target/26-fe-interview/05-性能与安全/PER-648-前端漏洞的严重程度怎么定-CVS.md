## PER-648：前端漏洞的严重程度怎么定？CVSS 评分在前端场景的裁剪与务实分级

**答**：
- CVSS 通用但常与前端实际不符：前端没有直接 RCE，多数漏洞的影响范围 C/I/A"要按数据面重估——DOM-XSS 能偷 cookie/token 时是高危，只能改页面文案且无敏感数据时是中危。
- 务实分级四问：**能偷什么**（凭据/PII/支付数据？）、**谁能触发**（需要受害者交互还是自动触发？）、**能持续多久**（存储型持续 vs 反射型一次性）、**利用门槛**（需要登录态/特定配置吗？）。
- 前端裁剪表：XSS+token 窃取=高；XSS 仅页面篡改=中；CSRF+资金操作=高、CSRF+偏好设置=低；点击劫持+支付确认=高、其余=中；信息泄漏（内网地址/版本号）=低；开放重定向+OAuth=高、纯钓鱼=中。
- 分级驱动响应：高危 24h 修复、中危 1 周、低危排期；分级由安全+前端双方评审定，不单方说了算。

```javascript

const severityMatrix = {
  fourQuestions: ['能偷什么（凭据/PII/支付）', '谁触发（自动/需交互）',
    '持续多久（存储型/反射型）', '利用门槛（登录态/配置）'],
  cut: {   // 前端裁剪表
    'DOM-XSS+token 可窃': 'high',
    'XSS 仅文案篡改': 'medium',
    'CSRF+资金操作': 'high', 'CSRF+偏好设置': 'low',
    '点击劫持+支付确认': 'high', '点击劫持+普通页': 'medium',
    '内网地址/版本号泄漏': 'low',
    '开放重定向+OAuth链路': 'high', '开放重定向+纯钓鱼': 'medium',
  },
  sla: { high: '24h', medium: '1 周', low: '排期' },
  rule: '分级由安全+前端双方评审，四问重估 CVSS 的 CIA 面向',
};
console.log(severityMatrix.sla);
```
