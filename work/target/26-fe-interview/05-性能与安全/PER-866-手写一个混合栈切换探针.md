## PER-866：手写一个混合栈切换探针：记录 Native 与 H5 互切各段耗时并检测异常切换

**答**：
- 需求：实现 HybridSwitchProbe：record({from, to, segs}) 记录每次切换的分段（containerPrepare/load/animate），聚合输出各转换方向（h5->native/native->h5/h5->h5）的 p75 与样本数；检测异常切换（总耗时 > 800ms 或动画段掉帧 > 5）输出告警列表；提供与历史基线对比输出劣化方向。
- 边界：缺段的记录标记 incomplete 仍计入总数但不计入 p75；方向枚举外的记录归 other；基线对比仅对两基线都存在的方向输出。
- 评分点：方向聚合；incomplete 处理；劣化方向判定。

```javascript
function createSwitchProbe(baseline = {}) {
  const recs = [];
  return {
    record(r) { recs.push({ ...r, total: (r.segs.container ?? 0) + (r.segs.load ?? 0) + (r.segs.animate ?? 0) }); },
    report({ slowMs = 800, frameTh = 5 } = {}) {
      const by = {};
      for (const r of recs) {
        const k = ['h5->native', 'native->h5', 'h5->h5'].includes(r.dir) ? r.dir : 'other';
        (by[k] ??= { n: 0, totals: [], animFrames: [] });
        by[k].n++;
        if (r.segs.container != null && r.segs.load != null && r.segs.animate != null) {
          by[k].totals.push(r.total);
          by[k].animFrames.push(r.animDropped ?? 0);
        }
      }
      const alerts = recs.filter(r => r.total > slowMs || (r.animDropped ?? 0) > frameTh)
        .map(r => ({ dir: r.dir, total: r.total, animDropped: r.animDropped }));
      return { dirs: Object.fromEntries(Object.entries(by).map(([k, v]) =>
        [k, { n: v.n, p75: v.totals.length ? p75(v.totals) : null,
          animP75: v.animFrames.length ? p75(v.animFrames) : null,
          baselineP75: baseline[k] ?? null,
          regressed: baseline[k] != null && v.totals.length && p75(v.totals) > baseline[k] * 1.2 }])),
        alerts };
    },
  };
}
function p75(a) { const s = [...a].sort((x, y) => x - y); return s[Math.floor(s.length * 0.75)]; }
```
