## PER-576：手写一个监控查询聚合器：支持按指标/维度/时间窗/分位数聚合的 DSL 并执行

**答**：
- 实现一个迷你查询引擎：DSL 形如 `{ metric: 'lcp', dims: ['route','deviceTier'], window: '1h', agg: 'p75', filter: { net: '3g' } }`，对样本数组执行过滤 -> 分组 -> 分位数聚合。
- 要点：分位数聚合对每组样本排序取位；filter 支持等值与 in；输出要带样本量（避免小样本被当成结论）。
- 边界：样本量 < 100 的组标记 low-confidence；时间窗过滤用样本时间戳。
- 评分点：分组维度组合与样本量标注。

```javascript

function query(samples, q) {
  const pct = (arr, p) => { const a = arr.slice().sort((x, y) => x - y);
    return a[Math.floor(a.length * p)] ?? null; };
  const inWin = samples.filter(s => s.ts >= Date.now() - parseWindow(q.window)
    && s.ts < Date.now());
  const filtered = inWin.filter(s => Object.entries(q.filter ?? {})
    .every(([k, v]) => Array.isArray(v) ? v.includes(s[k]) : s[k] === v));
  const groups = new Map();
  filtered.forEach(s => {
    const key = q.dims.map(d => s[d]).join('/');
    (groups.get(key) ??= []).push(s[q.metric]);
  });
  const aggFn = { p50: a => pct(a, 0.5), p75: a => pct(a, 0.75),
    p95: a => pct(a, 0.95), avg: a => a.reduce((x, y) => x + y, 0) / a.length };
  return [...groups.entries()].map(([key, vals]) => ({
    dims: key, value: Math.round(aggFn[q.agg](vals)), n: vals.length,
    lowConfidence: vals.length < 100,                     // 小样本标注
  })).sort((a, b) => b.value - a.value);
}
function parseWindow(w) { const m = w.match(/(\d+)([hm])/); return +m[1] * (m[2] === 'h' ? 3600e3 : 60e3); }
// query(lcpSamples, { metric: 'lcp', dims: ['route', 'deviceTier'], window: '1h', agg: 'p75', filter: { net: '3g' } })
```
