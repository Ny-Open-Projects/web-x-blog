## PER-524：性能测试如何左移到开发期？让每个工程师在本地提交前就能看到性能影响？

**答**：
- 左移的本质是把"上线后才发现慢"提前到"PR 里就能看见慢"：本地 CLI 卡口（pre-commit 可选跑）+ PR 机器人评论（自动跑分并 diff 主干基线）+ 本地可视化（一键起带节流的预览环境）。
- 关键设计：**本地跑分要快**（单页 20 秒内出结果、只测受影响路由），全量矩阵留给夜间 CI，本地全量没人会跑。
- 配套工程：性能预算文件进仓库（budget.json），CLI 与 CI 共用同一份预算，避免"本地标准"和"门禁标准"不一致。
- 追问钩子：左移最大的阻力是什么？——开发机噪声大、跑分慢；解法是分层（本地粗筛 + CI 精测）而不是要求本地结果精确。

```javascript

// perf-cli.js：本地性能粗筛，20 秒内出结果，预算与 CI 共用
const fs = require('fs');
const puppeteer = require('puppeteer');
const budget = JSON.parse(fs.readFileSync('budget.json', 'utf8')); // 与 lighthouserc 同源

async function quickCheck(route) {
  const browser = await puppeteer.launch();
  const page = await browser.newPage();
  const cdp = await page.createCDPSession();
  await cdp.send('Emulation.setCPUThrottlingRate', { rate: 4 });
  await page.goto(`http://localhost:3000${route}`, { waitUntil: 'load' });
  const lcp = await page.evaluate(() => new Promise(res => {
    new PerformanceObserver(l => res(l.getEntries().at(-1)?.startTime ?? 0))
      .observe({ type: 'largest-contentful-paint', buffered: true });
    setTimeout(() => res(0), 8000);
  }));
  await browser.close();
  const limit = budget.routes[route]?.lcp ?? budget.default.lcp;
  const ok = lcp <= limit;
  console.log(`${route} LCP=${Math.round(lcp)}ms / 预算 ${limit}ms ${ok ? '✓' : '✗ 超预算'}`);
  return ok; // pre-commit 挂钩：失败给提示但不强拦（本地噪声大），CI 才强拦
}
quickCheck(process.argv[2] || '/home').then(ok => process.exit(ok ? 0 : 0));
```
