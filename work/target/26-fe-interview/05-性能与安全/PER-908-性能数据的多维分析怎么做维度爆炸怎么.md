## PER-908：性能数据的多维分析怎么做？维度爆炸怎么处理

**答**：
- 核心维度：页面、版本、机型档位、网络类型、地域/运营商、时段；分析时先固定次要维度再看主指标。
- 维度爆炸解法：预聚合（按天×页面×档位物化）、基数控制（地域聚合到省、机型映射到低中高三档）、查询走 ClickHouse 物化视图。
- 异动定位用"贡献度分析"：P75 劣化时按分桶拆分，找出拉高整体分位的桶（如某省低端机占比上升），区分"代码劣化"与"流量结构变化"。
- 追问点：辛普森悖论——整体指标变好但某子桶变差，必须看分桶而非只看大盘。

```javascript
// 贡献度分析：定位拉高分位的桶
function topContributors(rows, metric = 'lcp') {
  // rows: [{ bucket, p75, count }]
  const total = rows.reduce((s, r) => s + r.count, 0);
  return rows
    .map(r => ({ ...r, weight: r.count / total, score: r.p75 * r.count / total }))
    .sort((a, b) => b.score - a.score)
    .slice(0, 5)
    .map(r => ({ bucket: r.bucket, p75: r.p75,
                 share: +(r.weight * 100).toFixed(1) + '%' }));
}
// 若 top 桶是"low + 2G/3G"，说明是环境结构问题而非代码回归
```
