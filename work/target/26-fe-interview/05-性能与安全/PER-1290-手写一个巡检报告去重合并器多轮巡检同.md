## PER-1290：手写一个"巡检报告去重合并"器（多轮巡检同问题只留最新）

**答**：
- 需求：implement mergeInspections(runs)。runs 为按时间序的巡检结果 [{ at, findings: [{ rule, target, sev }] }]；同 (rule,target) 保留最新一次状态；持续存在的计算连续轮数；新消失的标记 resolved；输出 { open: [{ rule, target, sev, streak }], resolved: [...] }。
- 边界：sev 变化取最新；streak = 连续出现轮数（中断重计）；runs 为空返回空。
- 评分点：最新状态保留；连续轮数；resolved 标记；中断重计

```javascript
function mergeInspections(runs) {
  const state = new Map();
  for (const run of runs) {
    const seen = new Set();
    for (const f of run.findings) {
      const key = `${f.rule}|${f.target}`;
      seen.add(key);
      const prev = state.get(key);
      state.set(key, { rule: f.rule, target: f.target, sev: f.sev,
        streak: prev && prev.lastRun === run.at - 1 ? prev.streak + 1 : 1,
        lastRun: run.at, resolved: false });
    }
    for (const [k, v] of state)
      if (!seen.has(k) && !v.resolved) { v.resolved = true; v.resolvedAt = run.at; }
  }
  return {
    open: [...state.values()].filter(v => !v.resolved),
    resolved: [...state.values()].filter(v => v.resolved),
  };
}
// open 按 streak 降序排 -> 长期未修的优先处理；
```
