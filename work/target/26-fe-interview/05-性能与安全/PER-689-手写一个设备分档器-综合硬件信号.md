## PER-689：手写一个设备分档器：综合硬件信号给设备定档，档位贯穿性能策略与埋点

**答**：
- 分档信号：`deviceMemory`、`hardwareConcurrency`、`connection.downlink`、UA 机型库（主档映射）、屏幕尺寸；打分制：各信号赋分加权出总分映射到 low/mid/flag 三档。
- 要点：分档结果要稳定（同一设备重复打开一致——纯硬件信号，无随机）；UA 机型库优先级最高（厂商标注准确）；分档结果挂到 window 全局 + 埋点公共字段。
- 边界：desktop 环境不算分档（按 flag 处理）；分档不可用时降级 mid（中性策略）；iOS 无 deviceMemory 用机型库补。
- 评分点：机型库优先与结果稳定性。

```javascript

const UA_TIER = { 'iPhone15': 'flag', 'iPhone11': 'mid', 'Redmi 9A': 'low' }; // 机型库示例
function deviceTier() {
  if (!('ontouchstart' in window)) return 'flag';               // 桌面按 flag
  const uaModel = matchModelFromUA(navigator.userAgent);
  if (uaModel && UA_TIER[uaModel]) return UA_TIER[uaModel];     // 机型库优先
  let score = 0;
  score += (navigator.deviceMemory ?? 4) >= 6 ? 3 : (navigator.deviceMemory ?? 4) >= 3 ? 2 : 1;
  score += (navigator.hardwareConcurrency ?? 4) >= 8 ? 3 : (navigator.hardwareConcurrency ?? 4) >= 4 ? 2 : 1;
  score += (navigator.connection?.downlink ?? 10) >= 5 ? 2 : 1;
  const tier = score >= 7 ? 'flag' : score >= 5 ? 'mid' : 'low';
  window.__deviceTier = tier;                                   // 全局贯穿 + 埋点公共字段
  tracker.setCommonFields({ deviceTier: tier });
  return tier;
}
function matchModelFromUA(ua) {
  const m = ua.match(/\b(Redmi [0-9A-Z]+|iPhone\d+|SM-[A-Z0-9]+)\b/);
  return m?.[1] ?? null;
}
```
