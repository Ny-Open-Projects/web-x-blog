## PER-1199：手写一个字段注册表校验器：埋点事件的隐私合规检查

**答**：
- 需求：实现 validateEvent(event, registry)。registry 为 { eventName: { fields: { name: level }, keep, basis } }；检查：事件已注册（否则 reject unregistered）；字段都登记（未登记字段即违规）；level >= 3 的字段必须 event.consent 为 true；keep 必须为正整数且 <= 3650。
- 边界：registry 缺事件字段定义按空对象处理（任何字段都违规）；consent 缺失视为 false；输出 { pass, violations: [{ field, reason }] }。
- 评分点：注册检查；字段白名单；S3 同意门控；保留期校验

```javascript
function validateEvent(event, registry) {
  const def = registry[event.name];
  const violations = [];
  if (!def) return { pass: false,
    violations: [{ field: '*', reason: 'unregistered' }] };
  const fields = def.fields ?? {};
  for (const k of Object.keys(event.fields ?? {})) {
    if (!(k in fields))
      violations.push({ field: k, reason: 'field-not-registered' });
    else if (fields[k] >= 3 && event.consent !== true)
      violations.push({ field: k, reason: 's3+-requires-consent' });
  }
  if (!(def.keep > 0 && def.keep <= 3650))
    violations.push({ field: '*', reason: 'invalid-retention' });
  return { pass: violations.length === 0, violations };
}
```
