## PER-596：手写一个监控心跳与拨测探针：定时上报心跳、检测断流，并验证采集链路端到端可用

**答**：
- 心跳模式：采集 SDK 每 60 秒发一条 `{type:'heartbeat'}`；服务端断流检测（3 分钟无心跳告警）。拨测模式：无头浏览器定时访问核心页，断言 vitals 到库，失败即告警——两者互补：心跳证明采集活着，拨测证明链路全通。
- 前端实现要点：心跳不能阻塞页面（idle 时发）；页面不可见时心跳可以暂停但要打 `suspended` 标记（服务端区分用户挂着与采集挂了"）。
- 边界：心跳间隔 > 断流阈值的一半否则误判；拨测要带版本标记区分是版本问题还是链路问题。
- 评分点：suspended 标记与心跳-断流阈值关系。

```javascript

function heartbeat(report, { intervalMs = 60000 } = {}) {
  let suspended = false;
  document.addEventListener('visibilitychange', () => {
    suspended = document.visibilityState === 'hidden';     // 后台暂停但不瞒报
    if (!suspended) report({ type: 'heartbeat', resumed: true, ts: Date.now() });
  });
  const timer = setInterval(() => {
    if (suspended) return;
    report({ type: 'heartbeat', ts: Date.now() });         // 断流阈值须 > 2x interval
  }, intervalMs);
  addEventListener('pagehide', () => { clearInterval(timer);
    report({ type: 'heartbeat-end', ts: Date.now() }); });
}
// 服务端规则：3min 无心跳且非 suspended -> 告警采集断流"
// 拨测侧：puppeteer 每 5min 打开 /home，等 15s 断言 /collect 收到该会话 vitals，失败告警
```
