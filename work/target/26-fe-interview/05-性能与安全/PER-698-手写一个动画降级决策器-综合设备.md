## PER-698：手写一个动画降级决策器：综合设备档/用户偏好/实测帧率输出动画等级，并支持运行时自动降档

**答**：
- 决策器：`motionLevel()` 返回 full/reduced/minimal；输入三信号加权——设备档（静态）、prefers-reduced-motion（尊重用户）、运行时帧率探针（连续掉帧自动降一档，恢复一段时间升回来但带滞回防抖）。
- 要点：降档触发要有冷却（降档后至少 10s 不再评估）；升档更保守（需连续 30s 流畅）；决策结果广播（事件）让动画组件监听切换。
- 边界：prefers-reduced-motion 直接 minimal（用户意愿最高优先）；探针开销低采样；等级变化要埋点。
- 评分点：滞回升降档与冷却。

```javascript

class MotionController {
  constructor(fpsProbe) {
    this.level = window.__deviceTier === 'low' ? 'reduced' : 'full';
    if (matchMedia('(prefers-reduced-motion: reduce)').matches) this.level = 'minimal';
    this.coolUntil = 0; this.smoothSince = Date.now();
    fpsProbe.onJank(() => this.downgrade());
    fpsProbe.onSmooth(() => this.maybeUpgrade());
  }
  downgrade() {
    if (Date.now() < this.coolUntil) return;                    // 冷却期不评估
    const order = ['full', 'reduced', 'minimal'];
    const i = order.indexOf(this.level);
    if (i < 2) {
      this.level = order[i + 1];
      this.coolUntil = Date.now() + 10000;                      // 降档后 10s 冷却
      document.body.dataset.motion = this.level;
      track('motion-downgrade', { level: this.level });
      emit('motion-change', this.level);
    }
  }
  maybeUpgrade() {                                              // 连续 30s 流畅才升档
    if (Date.now() - this.smoothSince > 30000 && this.level === 'reduced') {
      this.level = 'full'; this.smoothSince = Date.now();
      emit('motion-change', this.level);
    } else if (this.level !== 'full') this.smoothSince = Date.now();
  }
  level() { return this.level; }                                // 动画组件读取决策
}
```
