## PER-1073：手写一个页面卸载前的数据上报保障器

**答**：
- 需求：实现 createFlusher(sizeLimit = 60_000)。push(data) 收集待上报；flush() 在 pagehide/visibilitychange(hidden) 时触发：优先 fetch keepalive（携带 headers），超 64KB 或 keepalive 失败回退 sendBeacon；都失败存 sessionStorage 下次启动重发；返回 { push, flush, pendingCount }。
- 边界：JSON 序列化后超限自动截断（保留前 N 条凑满限额）；重复 flush 空队列 no-op；sessionStorage 读写 try-catch（隐私模式）。
- 评分点：64KB 截断；keepalive 回退 beacon；存储兜底；剩余保留

```javascript
function createFlusher(limit = 60_000) {
  const buf = [];
  function flush() {
    if (!buf.length) return;
    let body = JSON.stringify(buf), send = buf.slice();
    if (body.length > limit) {                    // 截断凑额
      send = []; body = '';
      for (const d of buf) {
        const s = JSON.stringify([...send, d]);
        if (s.length > limit) break;
        send.push(d); body = s;
      }
    }
    const ok = (() => {
      try {
        return fetch('/rum', { method: 'POST', keepalive: true,
          headers: { 'Content-Type': 'application/json' },
          body }).ok;
      } catch { return false; }
    })();
    if (!ok) {
      try { navigator.sendBeacon('/rum', body); } catch {}
    }
    // sendBeacon 也可能静默失败 -> 存储兜底
    try { sessionStorage.setItem('rum-retry', JSON.stringify(send)); } catch {}
    buf.length = buf.length - send.length;        // 剩余保留
  }
  addEventListener('pagehide', flush);
  addEventListener('visibilitychange', () =>
    document.visibilityState === 'hidden' && flush());
  return { push: d => buf.push(d), flush,
    pendingCount: () => buf.length };
}
// 启动时重发上次残留：
try { const prev = sessionStorage.getItem('rum-retry');
  if (prev) { fetch('/rum', { method: 'POST', body: prev }); sessionStorage.removeItem('rum-retry'); } } catch {}
```
