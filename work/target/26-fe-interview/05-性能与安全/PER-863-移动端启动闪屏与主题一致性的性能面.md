## PER-863：移动端启动闪屏与主题一致性的性能面：启动白屏、闪白与主题错闪的治理

**答**：
- 三类闪动：① 启动白屏（HTML/CSS 未到）；② CSS 异步加载完成瞬间的样式跳动（FOUC）；③ 深色主题页面先白后黑的主题错闪（闪瞎用户）。
- 治理：HTML 内联关键 CSS（< 14KB 不阻塞且无 FOUC）；主题色以 Cookie/localStorage 记忆，在 <head> 内联脚本首行设置背景色与 class（先于任何渲染）；预加载 CSS 的字体资源。
- 主题一致性链路：客户端主题偏好 → 容器启动参数传给 H5 → H5 首行脚本读参数/缓存立即套用 → CSS 变量切换渲染——任何一环缺位都会闪一次。
- 度量与验收：录制启动视频帧分析（逐帧检测颜色跳变次数），自动化断言"首帧背景色 == 目标主题色"。

```javascript
// <head> 内联首行：主题防闪（先于一切渲染）
<head>
<script>
  (function () {
    var theme = '{{containerTheme}}'                          // 容器注入
      || localStorage.getItem('theme')                        // 本地缓存
      || (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
    document.documentElement.dataset.theme = theme;
    document.documentElement.style.background =               // 首帧背景即目标色
      theme === 'dark' ? '#111' : '#fff';
  })();
</script>
<style>/* 关键 CSS 内联 < 14KB：布局骨架 + 主题变量 */</style>
</head>
// 帧级验收：逐帧比对颜色
function assertNoFlash(videoFrames) {
  const jumps = videoFrames.filter((f, i) => i && bgLumaDelta(f, videoFrames[i - 1]) > 0.5);
  return { flashCount: jumps.length, pass: jumps.length === 0 };
}
```
