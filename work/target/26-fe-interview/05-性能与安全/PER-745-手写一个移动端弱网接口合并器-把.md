## PER-745：手写一个移动端弱网接口合并器：把高频小请求合并为批量请求，降低 RTT 消耗

**答**：
- 场景：弱网下 RTT 300ms+，页面发 5 个小接口 = 串行 1.5s——合并器在 50ms 窗口内收集同域 GET 请求，打包成一次批量 POST（`/api/batch`），响应按 reqId 分发。
- 要点：合并只对幂等读请求；单个请求失败不影响批内其他（响应逐条 status）；窗口大小平衡延迟与合并率（50ms）；批量接口响应上限（服务端裁剪，超时单拆重发）。
- 边界：弱网才启用（fast 网直发，合并反而增加延迟）；需要 streaming 的接口排除；鉴权头一致才能合并（不同用户态不合并）。
- 评分点：弱网启用条件与逐条失败隔离。

```javascript

class BatchMerger {
  constructor({ windowMs = 50, weakOnly = true } = {}) {
    this.queue = []; this.timer = null; this.weakOnly = weakOnly;
  }
  async get(url) {
    if (!this.shouldBatch()) return fetch(url).then(r => r.json());  // fast 网直发
    return new Promise((resolve, reject) => {
      this.queue.push({ url, resolve, reject });
      if (!this.timer) this.timer = setTimeout(() => this.flush(), 50);
    });
  }
  shouldBatch() {
    if (!this.weakOnly) return true;
    const t = navigator.connection?.effectiveType ?? '4g';
    return /2g|3g/.test(t) || (navigator.connection?.rtt ?? 0) > 200;   // 弱网才合并
  }
  async flush() {
    this.timer = null;
    const batch = this.queue.splice(0);                         // 上限 10 条
    if (!batch.length) return;
    try {
      const res = await fetch('/api/batch', { method: 'POST',
        headers: { 'Content-Type': 'application/json', ...authHeaders() },
        body: JSON.stringify({ reqs: batch.map(b => ({ url: b.url })) }) });
      const { results } = await res.json();
      results.forEach((r, i) =>                                 // 逐条分发，失败隔离
        r.ok ? batch[i].resolve(r.data) : batch[i].reject(new Error(r.error)));
    } catch (e) {
      // 批量整体失败：单拆重发（逐个 GET）
      batch.forEach(b => fetch(b.url).then(r => r.json()).then(b.resolve, b.reject));
    }
  }
}
```
