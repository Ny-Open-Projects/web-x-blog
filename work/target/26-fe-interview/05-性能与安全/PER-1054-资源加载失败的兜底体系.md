## PER-1054：资源加载失败的兜底体系

**答**：
- 兜底分级：重试（网络抖动）→ 本地缓存（SW/IndexedDB）→ 降级版本（旧资源仍可用）→ 功能降级（去掉该模块）。
- 实现要点：关键资源加载失败事件统一上报与处理；多 CDN 源切换（fallback 域名）；版本列表兜底（老版本资源在线上保留期 ≥ 2 个版本）。
- 防雪崩：全站资源失败时（疑似发布事故）触发整体降级页，而不是每个组件各自报错。
- 演练：断网/半断网/CDN 故障三种场景的兜底路径验证。

```javascript
// 多源加载兜底
function loadScriptWithFallback(srcs, { timeout = 5000 } = {}) {
  return srcs.reduce((p, src) => p.catch(() => new Promise((resolve, reject) => {
    const s = document.createElement('script');
    s.src = src;
    const t = setTimeout(() => { s.remove(); reject(new Error('timeout ' + src)); }, timeout);
    s.onload = () => { clearTimeout(t); resolve(); };
    s.onerror = () => { clearTimeout(t); report({ type: 'src-fail', src }); s.remove(); reject(new Error('fail ' + src)); };
    document.head.appendChild(s);
  })), Promise.reject());
}
// loadScriptWithFallback(['https://a.cdn/x.js','https://b.cdn/x.js'])
```
