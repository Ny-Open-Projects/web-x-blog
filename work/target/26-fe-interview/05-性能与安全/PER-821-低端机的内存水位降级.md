## PER-821：低端机的内存水位降级：内存压力信号、降级触发与恢复的滞回设计

**答**：
- 压力信号：JS heap（performance.memory）、容器内存告警（onLowMemory/桥事件）、页面被系统回收的前兆（高频触发 trim 回调）。
- 降级设计分级：轻压 → 关动效/降图片档；中压 → 释放非可视缓存、虚拟列表窗口减半；重压 → 精简版页面/暂停非核心轮询。
- 滞回（hysteresis）是关键：触发阈值与恢复阈值要拉开（如 85% 触发降级、70% 才恢复），否则内存在水线附近抖动会导致降级反复横跳（比不降更卡）。
- 恢复节奏：逐级恢复（重压→中压等 30s 观察→轻压），避免一次性全量恢复造成内存尖峰二次触发。

```javascript
class MemoryGovernor {
  constructor({ levels = [0.85, 0.75, 0.6], recoverGap = 0.1 } = {}) {
    this.levels = levels;                     // [重压线, 中压线, 轻压线]
    this.gap = recoverGap; this.state = 0;    // 0 正常 1 轻 2 中 3 重
    this.lastChange = 0;
  }
  tick(heapMB, maxMB) {
    const ratio = heapMB / maxMB;
    const want = ratio > this.levels[0] ? 3 : ratio > this.levels[1] ? 2
      : ratio > this.levels[2] ? 1 : 0;
    if (want > this.state) return this.upgrade(want);            // 升级即时
    if (want < this.state && ratio < this.levels[this.state - 1] - this.gap)
      return this.downgrade();               // 恢复带滞回
  }
  upgrade(n) { this.state = n; report('mem-degrade', { level: n }); return ACTIONS[n]; }
  downgrade() {                              // 逐级恢复，间隔 30s
    if (Date.now() - this.lastChange < 30000) return null;
    this.state--; this.lastChange = Date.now(); return ACTIONS[this.state];
  }
}
const ACTIONS = { 0: 'normal', 1: 'off-effects', 2: 'shrink-cache+list', 3: 'lite-page' };
```
