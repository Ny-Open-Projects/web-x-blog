## PER-948：性能平台的「故障演练」：如何验证性能防御体系真的有效

**答**：
- 演练目的：验证告警会不会响、门禁会不会拦、降级会不会生效、值班会不会处理——纸面机制未经演练都是未知数。
- 演练手段：注入故障（构造慢接口/劣化版本发布到灰度/人为超阈值数据），观察各环节反应时间与正确性。
- 度量：MTTD（发现时间）、MTTA（认领时间）、MTTR（恢复时间）与演练目标差距，作为体系改进输入。
- 节奏：季度小演练（单环节）、年度大演练（全链路 + 大促场景），结果纳入团队健康度。

```javascript
// 演练计时器
function drill({ inject, detect, expectMins = 15 }) {
  const t0 = Date.now();
  inject();                                        // 注入劣化
  return new Promise(resolve => {
    const timer = setInterval(() => {
      if (detect()) {                              // 平台告警/门禁触发
        clearInterval(timer);
        const mins = (Date.now() - t0) / 60_000;
        resolve({ pass: mins <= expectMins, MTTD: +mins.toFixed(1) });
      }
    }, 5_000);
  });
}
// 例：注入慢接口，detect = 轮询告警系统是否有对应事件
```
