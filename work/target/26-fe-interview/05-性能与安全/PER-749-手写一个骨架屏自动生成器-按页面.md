## PER-749：手写一个骨架屏自动生成器：按页面 DOM 结构生成骨架 HTML 并保证切换时布局稳定

**答**：
- 原理：遍历目标容器 DOM，按元素类型映射骨架块（文本->灰色条、图片->灰块、按钮->胶囊），尺寸取真实 rect，输出骨架 HTML/截图两派取 HTML 派（体积小可更新）。
- 要点：生成时机（首屏渲染完成后克隆结构）、骨架与真实内容**同结构**（同一 DOM 层级，切换时只换内容不换布局，CLS 为 0）；样式用占位 class（灰底+动画）不带真实样式依赖；嵌套过深的容器截断（骨架只 2 层）。
- 边界：动态尺寸（百分比宽）骨架要用相同容器约束；列表数量按首屏实际条数生成；骨架总节点数限制（< 100）。
- 评分点：同结构切换保证 CLS 为 0。

```javascript

function generateSkeleton(container, { maxDepth = 2, maxNodes = 100 } = {}) {
  let count = 0;
  const build = (el, depth) => {
    if (depth > maxDepth || count >= maxNodes) return null;
    const rect = el.getBoundingClientRect();
    if (rect.width < 8 || rect.height < 8) return null;
    const div = document.createElement('div');
    div.style.cssText = `width:${rect.width}px;height:${rect.height}px;` +
      `margin:${getComputedStyle(el).margin};border-radius:4px;`;
    div.className = skeletonClass(el);                          // 按类型：text/image/button
    count++;
    [...el.children].slice(0, 5).forEach(c => {                 // 每层最多 5 子
      const child = build(c, depth + 1);
      if (child) div.appendChild(child);
    });
    return div;
  };
  function skeletonClass(el) {
    if (el.tagName === 'IMG') return 'sk-img';
    if (el.tagName === 'BUTTON' || el.tagName === 'A') return 'sk-btn';
    if (el.children.length === 0) return 'sk-text';             // 灰色条
    return 'sk-block';
  }
  const skeleton = build(container, 0);
  return skeleton;                                              // 与真实内容同结构 -> 切换 CLS = 0
}
// 用法：骨架 = generateSkeleton(document.querySelector('#app'));
// 真实数据到达后：skeleton.replaceWith(realContent) —— 同层级同尺寸，布局零偏移
```
