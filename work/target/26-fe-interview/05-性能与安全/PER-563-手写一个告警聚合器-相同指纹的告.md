## PER-563：手写一个告警聚合器：相同指纹的告警在时间窗口内合并，窗口结束输出一条带计数的摘要

**答**：
- 实现核心是滑动窗口 + 指纹分组"：告警进来按指纹（错误堆栈 hash + 路由 + 版本）分桶，桶内更新计数与首末时间，定时 flush 输出摘要。
- 要点：窗口用去抖（同指纹持续到达就顺延）还是固定窗口（简单可预期）？——固定窗口 + 尾窗补发更可控；摘要里要带首末发生时间与样本条数。
- 边界：指纹计算要截断堆栈深度（取前 3 帧）并剥离行号（bundle 变化行号漂移），否则聚合率上不去。
- 评分点：固定窗口 flush 与指纹脱敏。

```javascript

function fingerprint(err, ctx) {
  const frames = (err.stack ?? '').split('\n').slice(1, 4)      // 前 3 帧
    .map(l => l.replace(/:\d+:\d+/g, ''))                       // 剥行号防 bundle 漂移
    .join('|');
  return `${frames}@${ctx.route}@${ctx.version}`;
}
class AlertAggregator {
  constructor(windowMs = 5 * 60 * 1000, sink) {
    this.windowMs = windowMs; this.sink = sink;
    this.buckets = new Map();
    setInterval(() => this.flush(), windowMs);           // 固定窗口 flush
  }
  push(alert) {
    const fp = fingerprint(alert.err, alert.ctx);
    const b = this.buckets.get(fp) ??= { fp, count: 0, firstAt: alert.ts, sample: alert };
    b.count++; b.lastAt = alert.ts;                       // 只存一条样本省内存
  }
  flush() {
    for (const b of this.buckets.values())
      this.sink({ ...b, durMs: b.lastAt - b.firstAt });   // 一条摘要：计数+首末时间+样本
    this.buckets.clear();
  }
}
```
