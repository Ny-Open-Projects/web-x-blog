## PER-870：手写一个图片捏合缩放控制器：双指缩放、双击缩放与清晰度分层加载

**答**：
- 需求：实现 ZoomController：双指捏合实时 transform 缩放（以两指中点为锚点，范围 0.5~4x）；双击在 1x 与 2.5x 间切换（带过渡动画）；缩放稳定（手势结束且 scale > 1.5）时回调 onZoomSettled(scale) 触发高清加载（调用方自己换图），缩回 < 1.2 时回调 onZoomReset 释放高清内存。
- 边界：单指拖动在放大态生效（平移 translate，限制边界）；双击与捏合竞争（双击判定 300ms 内两次 tap 且无位移）；动画用 transition，捏合时关闭 transition。
- 评分点：锚点变换计算；手势竞争仲裁；稳定回调防反复加载。

```javascript
class ZoomController {
  constructor(el, cb, { min = 0.5, max = 4 } = {}) {
    this.el = el; this.cb = cb; this.min = min; this.max = max;
    this.scale = 1; this.x = 0; this.y = 0; this.pinching = false;
    el.style.transition = 'transform .2s';
    el.addEventListener('touchstart', e => this.start(e), { passive: false });
    el.addEventListener('touchmove', e => this.move(e), { passive: false });
    el.addEventListener('touchend', () => this.settle(), { passive: true });
  }
  start(e) {
    if (e.touches.length === 2) {
      this.pinching = true;
      this.d0 = this.dist(e);                                  // 初始指距
      this.s0 = this.scale;
      this.el.style.transition = 'none';                       // 捏合关动画
    } else {
      this.dragStart = { x: e.touches[0].clientX - this.x, y: e.touches[0].clientY - this.y };
      this.tapInfo = { t: Date.now(), x: e.touches[0].clientX, moved: false };   // 双击判定
    }
  }
  move(e) {
    if (this.pinching && e.touches.length === 2) {
      e.preventDefault();                                      // 放大态阻断页面滚动
      const k = clamp(this.s0 * this.dist(e) / this.d0, this.min, this.max);
      this.scale = k;
      this.el.style.transform = `translate(${this.x}px, ${this.y}px) scale(${k})`;
    } else if (this.scale > 1 && e.touches.length === 1) {     // 放大态单指平移
      e.preventDefault();
      this.x = e.touches[0].clientX - this.dragStart.x;
      this.y = e.touches[0].clientY - this.dragStart.y;
      this.el.style.transform = `translate(${this.x}px, ${this.y}px) scale(${this.scale})`;
    }
  }
  dist(e) { const dx = e.touches[0].clientX - e.touches[1].clientX;
    return Math.hypot(dx, e.touches[0].clientY - e.touches[1].clientY); }
  settle() {                                                   // 缩放稳定
    if (this.pinching) { this.pinching = false; this.el.style.transition = 'transform .2s'; }
    if (this.scale > 1.5) this.cb.onZoomSettled?.(this.scale);
    else if (this.scale < 1.2) { this.cb.onZoomReset?.(); this.scale = 1; this.x = this.y = 0;
      this.el.style.transform = ''; }
  }
}
```
