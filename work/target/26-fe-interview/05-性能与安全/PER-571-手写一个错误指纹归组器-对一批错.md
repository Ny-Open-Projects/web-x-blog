## PER-571：手写一个错误指纹归组器：对一批错误按稳定指纹分组，输出 Top 组与新出现指纹告警

**答**：
- 在 570 的指纹基础上做批处理：分组统计 count/route 分布/首次出现版本；与历史指纹库比对，标出 new 指纹。
- 要点：历史库存指纹的 hash 集合（Set），新指纹定义是近 30 天未见"；top 组按 count 排序且组内要保留 1 条样本（含堆栈与上下文）供排障。
- 边界：同指纹错误率要结合流量算（错误率上升 vs 流量上涨带来的绝对数上涨），输出 rate 而不只 count。
- 评分点：新指纹判定与错误率归一。

```javascript

function groupErrors(errors, historySet, { topN = 10, windowDays = 30 } = {}) {
  const groups = new Map();
  for (const e of errors) {
    const fp = e.fp;                                       // 570 生成的稳定指纹
    const g = groups.get(fp) ??= { fp, count: 0, routes: {}, sample: e, firstTs: e.ts };
    g.count++; g.routes[e.route] = (g.routes[e.route] ?? 0) + 1;
  }
  const total = errors.length;
  const ranked = [...groups.values()].map(g => ({
    fp: g.fp, count: g.count,
    rate: +(g.count / total * 100).toFixed(1) + '%',       // 归一化：占错误总量的比例
    topRoute: Object.entries(g.routes).sort((a, b) => b[1] - a[1])[0]?.[0],
    isNew: !historySet.has(hash(g.fp)),                    // 近 30 天未见 -> 新指纹
    sample: { stack: g.sample.stack, ctx: g.sample.ctx },  // 组内留一条样本
  })).sort((a, b) => b.count - a.count);
  return {
    top: ranked.slice(0, topN),
    newAlerts: ranked.filter(r => r.isNew),                // 新指纹 -> 告警
  };
}
function hash(s) { let h = 0; for (const c of s) h = (h * 31 + c.charCodeAt(0)) | 0; return String(h); }
```
