## PER-771：手写一个游戏帧率分级控制器：固定步长逻辑 + 渲染分级 + thermal 降频响应

**答**：
- 实现：逻辑固定步长（STEP=16.6ms）保证确定性；渲染分级（level: 60/30/15fps）通过跳帧实现；容器 thermal 回调（降频事件）触发降级；帧耗时统计区分 update 与 render 超支。
- 要点：降级决策带滞回（降快升慢）；thermal 恢复（冷却事件）后才允许升回；30fps 模式下逻辑步长不变（游戏逻辑确定性），只是渲染跳帧。
- 边界：切后台暂停循环（页面不可见）；多渲染器（主 canvas + UI canvas）分级联动。
- 评分点：thermal 滞回与逻辑渲染解耦。

```javascript

class GameFrameController {
  constructor(containerBridge, { step = 16.6 } = {}) {
    this.step = step; this.acc = 0; this.last = performance.now();
    this.renderEvery = window.__deviceTier === 'low' ? 2 : 1;    // 渲染分级：每 N 帧渲染 1 次
    this.frameCount = 0;
    containerBridge?.on('thermal', (level) => {                  // 降频事件
      if (level === 'throttled') this.renderEvery = 4;           // 快速降
      else if (level === 'normal' && this.cooledLong()) this.renderEvery = window.__deviceTier === 'low' ? 2 : 1;
    });
    this.running = true;
    this.loop(performance.now());
  }
  loop(t) {
    requestAnimationFrame((nt) => {
      if (!this.running) return;
      this.acc += nt - t;
      let steps = 0;
      while (this.acc >= this.step && steps < 5) {               // 补步上限防螺旋
        this.update(this.step);
        this.acc -= this.step; steps++;
      }
      this.frameCount++;
      if (this.frameCount % this.renderEvery === 0) this.render(); // 渲染分级跳帧
      this.loop(nt);
    });
  }
  cooledLong() { return Date.now() - this.lastThrottleAt > 60000; } // 冷却 60s 才升回
  update(ms) { /* 游戏逻辑：确定性固定步长 */ }
  render() { /* 渲染：分级跳帧不改变逻辑 */ }
}
```
