## PER-848：手写一个万级节点渲染压力测试器：递增节点数测帧率拐点并输出容量报告

**答**：
- 需求：实现 stressTest：从 initial（如 500）开始按 step 递增节点数，每档渲染 N 个节点并滚动 2 秒采样 FPS（rAF 计帧），FPS < 30 的档位记为拐点；输出容量报告 {maxStableNodes, samples: [{nodes, fps, memMB}]}，测试结束清理全部节点并归还内存。
- 边界：每档测试间强制 GC 间隙（等待 1s）防上一档内存干扰；FPS 采样剔除前 10 帧（滚动加速期）；连续两档低于 30 提前终止。
- 评分点：拐点判定（首个 < 30 或连续两档）；样本清洗；清理回收。

```javascript
async function stressTest({ initial = 500, step = 500, max = 20000, fpsTh = 30 } = {}) {
  const samples = []; let nodes = initial, breakpoint = null, badStreak = 0;
  while (nodes <= max && badStreak < 2) {
    const container = mountNodes(nodes);                       // 渲染 N 节点
    await sleep(1000);                                         // GC 间隙
    const fps = await measureFps({ scroll: true, skipFrames: 10 });   // 滚动采样
    samples.push({ nodes, fps: +fps.toFixed(1), memMB: memoryMB() });
    if (fps < fpsTh) { badStreak++; breakpoint ??= nodes; }    // 拐点只记首个
    else badStreak = 0;
    container.remove();                                        // 清理回收
    nodes += step;
    await sleep(300);
  }
  return { maxStableNodes: breakpoint ? breakpoint - step : nodes, samples };
}
function measureFps({ skipFrames = 10 } = {}) {
  return new Promise(resolve => {
    let frames = 0, skipped = 0, start;
    const tick = t => {
      if (skipped++ < skipFrames) { start = t; return requestAnimationFrame(tick); }
      frames++;
      if (t - start >= 2000) resolve(frames / ((t - start) / 1000));   // 2 秒窗口
      requestAnimationFrame(tick);
    };
    requestAnimationFrame(tick);
  });
}
```
