## PER-1201：手写一个数据保留期清理调度器

**答**：
- 需求：实现 RetentionScheduler。register(event, days) 注册保留期；run(now) 返回到期数据的清理任务列表（每任务含 event、cutoff、sql），执行回调 collect(task) 后记录审计（{ task, rows, at }）；同 event 重复注册覆盖；days <= 0 抛错。
- 边界：无注册任务 run 返回空；审计记录含前一条 hash 形成链；清理失败（collect 抛错）不写审计并继续下一任务。
- 评分点：注册覆盖；任务生成；审计链；失败不阻断

```javascript
class RetentionScheduler {
  constructor() { this.rules = new Map(); this.audit = []; }
  register(event, days) {
    if (days <= 0) throw new Error('days must be positive');
    this.rules.set(event, days);                   // 覆盖
  }
  run(now, collect) {
    const tasks = [];
    for (const [event, days] of this.rules) {
      const cutoff = now - days * 86400_000;
      const task = { event, cutoff, sql:
        `DELETE FROM events WHERE type='${event}' AND ts < ${cutoff}` };
      try {
        const rows = collect(task);
        const prev = this.audit[this.audit.length - 1];
        this.audit.push({ task: task.event, rows, at: now,
          prev: prev ? prev.h : null,
          h: hash(task.event + rows + now) });
        tasks.push({ ...task, rows });
      } catch (e) { report({ type: 'purge-fail', event, msg: e.message }); }
    }
    return tasks;
  }
}
function hash(s) { let h = 0; for (const c of String(s)) h = (h * 31 + c.charCodeAt(0)) >>> 0; return h.toString(16); }
```
