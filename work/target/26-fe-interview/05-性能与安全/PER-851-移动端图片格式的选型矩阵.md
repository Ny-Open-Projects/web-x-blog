## PER-851：移动端图片格式的选型矩阵：WebP、AVIF、HEIC 在各端的兼容与收益差异

**答**：
- 三格式对比：WebP 兼容极广（iOS14+/全安卓），压缩比 ~25-35%；AVIF 压缩比更高（~40-50%）但编码慢、兼容略窄（iOS16+/近年安卓）；HEIC 主苹果生态，安卓兼容差，H5 场景基本不用。
- 选型矩阵维度：目标设备档（高端机 AVIF 优先）、流量敏感度（弱网/流量包场景 AVIF 收益大）、编码成本（CDN 实时转 AVIF 的 CPU 成本高，常用预转）。
- 落地方式：内容协商（Accept 头含 image/avif 则回 AVIF）或 CDN 按 UA 选择；前端不做格式嗅探，交给 CDN 协商（缓存键含协商结果，防 Vary 误配）。
- 收益验证：分格式统计实际下发占比与平均体积（不要只看"支持率"），关注协商失败回退 JPEG 的比例。

```javascript
// 图片格式协商（CDN 侧逻辑的前端视角）
const formatMatrix = {
  avif: { support: 'iOS16+/Android12+', saving: '40-50%', encodeCost: 'high' },
  webp: { support: 'iOS14+/Android4.2+', saving: '25-35%', encodeCost: 'mid' },
  jpeg: { support: '全兼容', saving: 0, encodeCost: 'low' },
};
// 前端只需：Accept 由浏览器自动携带 + <picture> 兜底
const pic = `
<picture>
  <source type="image/avif" srcset="hero.avif">
  <source type="image/webp" srcset="hero.webp">
  <img src="hero.jpg" alt="商品图">              <!-- JPEG 兜底 -->
</picture>`;
// 度量：下发占比与回退率
function formatStats(deliveries) {
  return Object.fromEntries(['avif', 'webp', 'jpeg'].map(f => {
    const arr = deliveries.filter(d => d.format === f);
    return [f, { ratio: arr.length / deliveries.length,
      avgKB: +(arr.reduce((s, d) => s + d.bytes, 0) / (arr.length || 1) / 1024).toFixed(1) }];
  }));
}
```
