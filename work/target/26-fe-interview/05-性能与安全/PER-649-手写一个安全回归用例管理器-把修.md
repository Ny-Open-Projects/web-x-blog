## PER-649：手写一个安全回归用例管理器：把修复过的漏洞固化为回归用例并统计攻击面覆盖率

**答**：
- 数据模型：漏洞记录（id/类型/入口点/修复版本）-> 关联回归用例（e2e 文件+断言）；攻击面地图（入口点清单）与用例关联算覆盖率。
- 实现要点：入口点唯一 id（route+param/sink 组合）；覆盖率 = 有用例入口/总入口，按类型分组输出（哪类入口覆盖薄弱）；漏洞复发检测——同入口同类型再次出现时自动关联历史用例验证用例为什么没拦住。
- 边界：用例失效（入口下线）要标记并同步覆盖率；新入口进地图必须标注是否已有用例作为 PR 检查项。
- 评分点：入口点建模与复发关联。

```javascript

const ENTRY_TYPES = ['query-render', 'postmessage', 'upload', 'redirect-param', 'api-authz'];
function buildSecurityRegression(vulns, entries, cases) {
  const byEntry = new Map(cases.map(c => [c.entryId, c]));
  const coverage = ENTRY_TYPES.map(t => {
    const es = entries.filter(e => e.type === t);
    const covered = es.filter(e => byEntry.has(e.id));
    return { type: t, total: es.length, covered: covered.length,
      rate: es.length ? +(covered.length / es.length * 100).toFixed(0) + '%' : 'n/a' };
  });
  const regressed = vulns.filter(v => vulns.some(o =>
    o.id !== v.id && o.entryId === v.entryId && o.type === v.type && o.id < v.id));
  return {
    coverage,
    weakSpots: coverage.filter(c => c.rate !== 'n/a' && parseInt(c.rate) < 60),
    reoccurred: regressed.map(v => ({ ...v, why: '历史用例未拦截，检查用例断言强度' })),
    prCheck: '新入口 PR 必须声明关联用例，否则阻塞合并',
  };
}
// entries 来自攻击面地图（603 产出），cases 是 e2e 用例清单
```
