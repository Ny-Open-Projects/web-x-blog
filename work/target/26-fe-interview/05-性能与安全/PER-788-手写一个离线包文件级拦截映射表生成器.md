## PER-788：手写一个离线包文件级拦截映射表生成器：URL 到本地文件路径的映射与缺失兜底

**答**：
- 需求：输入多个包的 manifest（id/version/files），生成全局 URL→本地路径映射表；规则：URL 命中映射表且本地文件 hash 校验存在则走本地，否则回源（在线）。同名文件多包冲突时按包优先级仲裁。
- 边界：映射表需记录来源包与 hash；查询不存在或校验失败的键要返回 fallback URL；映射表输出需带版本快照（可 diff）。
- 评分点：冲突仲裁；缺失兜底路径。

```javascript
function buildUrlMap(manifests, priorityOrder) {
  const map = new Map();
  const order = new Map(priorityOrder.map((id, i) => [id, i]));
  for (const m of manifests) {
    for (const [file, hash] of Object.entries(m.files)) {
      const url = `https://cdn.example.com/${m.id}/${file}`;
      const prev = map.get(url);
      // 冲突：优先级高的包赢（同包内后写覆盖）
      if (!prev || (order.get(m.id) ?? 99) < order.get(prev.pkg)) {
        map.set(url, { pkg: m.id, hash, local: `${OFFLINE_ROOT}/${m.id}/${file}` });
      }
    }
  }
  return {
    resolve(url, verifyHash) {                // 拦截查询入口
      const e = map.get(url);
      if (!e) return { type: 'miss', url };                      // 无映射：直接回源
      if (!verifyHash(e.local, e.hash)) return { type: 'corrupt', url };  // 校验失败：回源
      return { type: 'hit', local: e.local };
    },
  };
}
```
