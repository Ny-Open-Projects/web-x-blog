## PER-1257：手写一个图片体积审计器：对比压缩收益

**答**：
- 需求：实现 imageAudit(images, budgets)。images 为 [{ url, type, bytes, w, h }]；规则：单图 > 200KB P0；jpeg 大图可转 webp（估算 -50%）P1；尺寸超显示需求 2 倍（oversized）P1；输出 { items: [{ url, bytes, level, advice, savingKB }], totalSavingKB }。
- 边界：type 已是 avif/webp 不建议转；w/h 缺失跳过 oversized 检查；savingKB 相对当前。
- 评分点：阈值分级；格式建议；oversized 计算；节省汇总

```javascript
function imageAudit(images, { singleMaxKB = 200 } = {}) {
  const items = images.map(img => {
    const kb = img.bytes / 1024;
    if (kb > singleMaxKB)
      return { url: img.url, bytes: img.bytes, level: 'P0',
        advice: `单图 ${kb.toFixed(0)}KB 超限，压缩/转 AVIF`,
        savingKB: Math.round(kb * 0.5) };
    if (img.type === 'jpeg' || img.type === 'png')
      return { url: img.url, bytes: img.bytes, level: 'P1',
        advice: '转 WebP/AVIF 预计 -50%',
        savingKB: Math.round(kb * 0.5) };
    if (img.w && img.h && img.displayW && img.w > img.displayW * 2)
      return { url: img.url, bytes: img.bytes, level: 'P1',
        advice: `oversized：${img.w}px 用于 ${img.displayW}px`,
        savingKB: Math.round(kb * (1 - (img.displayW * 2) / img.w)) };
    return { url: img.url, bytes: img.bytes, level: null, advice: null, savingKB: 0 };
  });
  return { items, totalSavingKB: items.reduce((s, i) => s + i.savingKB, 0) };
}
```
