## PER-619：手写一个防点击劫持检测页：验证目标站点的 frame 嵌套防护是否真实生效

**答**：
- 测试页加载目标站到 iframe，检测加载结果：被 CSP/XFO 拦截时 iframe 触发 error 或 contentDocument 为 null/抛异常；成功嵌入即防护失效。
- 要点：跨域 iframe 的 onload 也会触发（加载成功与否不能只看 onload），要用 `contentDocument` 访问异常或 `fetch` no-cors 探测对比；多层级测试（同域嵌入/跨域嵌入/嵌套 iframe 绕过尝试）。
- 边界：有些站断帧 JS 会把 top 跳走，测试页要在 iframe 内 `sandbox` 阻断 top 导航以便观察；结果要输出到报告（哪些域名可被嵌入）。
- 评分点：onload 陷阱处理与 sandbox 辅助。

```javascript

function frameBustAudit(targetUrl) {
  return new Promise(resolve => {
    const iframe = document.createElement('iframe');
    iframe.src = targetUrl;
    iframe.sandbox = 'allow-scripts';                       // 阻断对 top 的跳转，便于观察
    let result;
    iframe.onload = () => {
      try {
        // 跨域被拦截时 contentDocument 为 null；能访问说明同域未设防
        const doc = iframe.contentDocument;
        result = doc === null
          ? { blocked: true, how: '跨域隔离或 XFO/CSP 拦截（需结合响应头确认）' }
          : { blocked: false, note: '同域且 contentDocument 可访问 -> 未设防' };
      } catch {
        result = { blocked: true, how: '跨域访问异常（大概率已被拦截）' };
      }
      finish();
    };
    iframe.onerror = () => { result = { blocked: true, how: '加载错误' }; finish(); };
    function finish() { iframe.remove(); resolve({ targetUrl, ...result }); }
    document.body.appendChild(iframe);
  });
}
// 结论要结合响应头人工确认：CSP frame-ancestors / X-Frame-Options 哪层生效
```
