## PER-755：手写一个乐观更新管理器：乐观态标记、逆操作回滚、服务端终态对齐与排队防并发写

**答**：
- 实现：`apply(key, optimisticFn, request, rollbackFn)`——先执行 optimisticFn 更新本地、标记乐观态，请求成功后 fetch 服务端终态覆盖；失败执行 rollbackFn；同 key 已有乐观未决时排队等待。
- 要点：乐观态标记进 UI 层（灰显/角标同步中"），回滚要恢复到乐观前快照（深拷贝关键字段）；超时（10s）视为失败回滚并进重试队列；终态对齐用响应体（避免二次请求）。
- 边界：页面卸载前未决乐观操作要 flush（sendBeacon 或取消并回滚）；批量乐观（点赞列表）逐条管理。
- 评分点：快照回滚与未决 flush。

```javascript

class OptimisticManager {
  constructor(retryQueue) { this.pending = new Map(); this.retryQueue = retryQueue; }
  async apply(key, { optimistic, snapshot, request, rollback }) {
    if (this.pending.has(key)) return this.enqueue(key, arguments[1]);  // 同 key 排队
    const undoSnapshot = snapshot();                            // 回滚快照
    optimistic();                                               // 本地先行
    const entry = { key, undoSnapshot, rollback, timer: null };
    this.pending.set(key, entry);
    entry.timer = setTimeout(() => this.fail(key, 'timeout'), 10000);   // 超时回滚
    try {
      const serverState = await request();
      clearTimeout(entry.timer);
      this.pending.delete(key);
      applyServerState(key, serverState);                       // 服务端终态覆盖本地推导
    } catch (e) {
      this.fail(key, e.message);
    }
  }
  fail(key, reason) {
    const entry = this.pending.get(key);
    if (!entry) return;
    clearTimeout(entry.timer);
    entry.rollback(entry.undoSnapshot);                         // 快照回滚
    this.pending.delete(key);
    this.retryQueue.push({ key, reason });                      // 进重试队列（694）
    toast('同步失败，已恢复原状态，稍后自动重试');
  }
  flushOnUnload() {                                             // 卸载前处理未决
    for (const [key, entry] of this.pending) {
      clearTimeout(entry.timer);
      entry.rollback(entry.undoSnapshot);                       // 回滚保守正确
    }
    this.pending.clear();
  }
}
addEventListener('pagehide', () => optimisticMgr?.flushOnUnload());
```
