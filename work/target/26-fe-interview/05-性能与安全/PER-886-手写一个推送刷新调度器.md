## PER-886：手写一个推送刷新调度器：按页面可见性与数据版本决定是否刷新

**答**：
- 需求：实现 PushScheduler：onPush({entity, version})；规则：页面不可见 → 只记版本不刷新；可见 → 100ms 合帧后对每个实体调 fetchDelta(entity, localVersion)，返回 null（服务端版本相同）则跳过、返回数据则 patch(entity, data)；连续 3 次同实体版本无变化时暂停该实体订阅 5 分钟（退避）；提供 resume(entity) 手动恢复。
- 边界：fetchDelta 抛错不进入退避计数（网络错误 vs 无变化区分）；合帧窗口内同实体多版本取最新；退避期间到达的推送只记版本。
- 评分点：可见性分支；版本无变化与错误区分；实体级退避。

```javascript
class PushScheduler {
  constructor({ windowMs = 100 } = {}) {
    this.buf = new Map(); this.backoff = new Map(); this.fails = new Map();
    this.timer = null; this.wm = windowMs;
  }
  onPush(msg) {
    if (document.hidden) { this.buf.set(msg.entity, msg.version); return; }   // 后台只记版本
    this.buf.set(msg.entity, msg.version);                     // 同实体取最新
    if (!this.timer) this.timer = setTimeout(() => this.flush(), this.wm);
  }
  async flush() {
    this.timer = null;
    const entries = [...this.buf]; this.buf.clear();
    await Promise.all(entries.map(([entity, ver]) => this.handle(entity, ver)));
  }
  async handle(entity, ver) {
    const until = this.backoff.get(entity);
    if (until && Date.now() < until) return;                   // 退避期只记版本
    try {
      const data = await fetchDelta(entity, ver);
      if (data == null) {                                      // 无变化
        const n = (this.noChange ||= new Map()).get(entity) || 0;
        if (n + 1 >= 3) { this.backoff.set(entity, Date.now() + 300000); this.noChange.set(entity, 0); }
        else this.noChange.set(entity, n + 1);
        return;
      }
      this.noChange.set(entity, 0);
      patch(entity, data);
    } catch (e) { report('push-fetch-error', { entity }); }    // 错误不进退避
  }
  resume(entity) { this.backoff.delete(entity); }
}
```
