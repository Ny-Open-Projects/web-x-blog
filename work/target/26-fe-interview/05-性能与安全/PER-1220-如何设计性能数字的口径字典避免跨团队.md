## PER-1220：如何设计"性能数字的口径字典"避免跨团队争论

**答**：
- 问题：首屏时间有 5 种定义（FCP/LCP/接口完成/骨架消失/业务自定义），争论源于口径不一。
- 字典内容：每个指标一个词条——定义、采集方式、分位口径、适用场景、不适用场景、Owner。
- 治理：指标命名唯一（新增需注册），废弃指标标记 deprecated 并给替代指标。
- 落地：字典即代码（平台 API），看板/报告/门禁全部引用词条 ID，禁止手写口径。

```javascript
// 口径字典
const METRIC_DICT = {
  'first-screen': { def: 'LCP 元素渲染完成', collect: 'web-vitals onLCP',
    quantile: 'P75', applies: ['营销页', '列表页'],
    notApplies: ['SPA 内部切换'], owner: 'fe-platform', status: 'active' },
  'business-first-screen': { def: '核心接口集合完成+骨架消失',
    collect: 'SDK custom', quantile: 'P75',
    applies: ['工作台'], owner: 'biz-fe', status: 'active' },
  'tti': { def: '已废弃，改用 INP', status: 'deprecated',
    replacedBy: 'inp' },
};
function lookupMetric(id) {
  const m = METRIC_DICT[id];
  if (!m) throw new Error(`未注册口径 ${id}，请先走指标注册`);
  if (m.status === 'deprecated') throw new Error(`口径已废弃，用 ${m.replacedBy}`);
  return m;
}
```
