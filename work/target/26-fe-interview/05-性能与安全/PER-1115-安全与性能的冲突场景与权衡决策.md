## PER-1115：安全与性能的冲突场景与权衡决策

**答**：
- 冲突清单：CSP nonce 禁 HTML 缓存（性能损失）、加密计算拖慢启动、风控校验增加延迟、SRI 禁动态 CDN 切换。
- 决策框架：资损/合规相关 → 安全优先；体验相关 → 找兼容方案（如 nonce 页面只对登录态用户 no-cache）。
- 量化权衡：把两项都折算成业务指标（安全事件损失 vs 转化率损失）交给业务决策，技术提供选项。
- 记录：权衡结论写入 ADR（架构决策记录），避免反复横跳。

```javascript
// 权衡决策记录模板
function makeADR(decision) {
  return {
    title: decision.title,                        // 例：CSP nonce 与 HTML 缓存
    conflict: decision.conflict,                  // 安全 vs 性能
    options: decision.options,                    // 各选项代价
    chosen: decision.chosen,
    metrics: decision.metrics,                    // 量化依据
    review: decision.date + ' 3 个月后复评',
  };
}
// 例：登录态页面 no-cache + nonce（安全优先，页面占比 15%，性能影响可控）
```
