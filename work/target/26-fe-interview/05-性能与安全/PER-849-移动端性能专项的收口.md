## PER-849：移动端性能专项的收口：从专项治理到常态防劣化的机制设计

**答**：
- 专项的宿命：没有防劣化机制，专项收益三个月内被新需求吃掉——收口不是"做完了"，而是把成果固化成常态机制。
- 四件套收口：① 预算制（体积/耗时指标写进 CI 门禁）；② 基线对比（每次发版自动 diff 核心指标）；③ 看板常驻（分档秒开/卡顿/白屏实时看板+告警值班）；④ 演练机制（弱网/低端机季度演练，保证降级手段真实可用）。
- 组织收口：性能指标进团队 OKR/晋升材料口径；新功能立项带性能预算评审；专项产出文档沉淀为团队规范（不是个人经验）。
- 验收专项完成的标准：指标达成 + 机制上线 + 告警值班运行一个迭代无漏报 + 文档归档。

```javascript
const sustainSystem = {
  ci: { rules: ['bundle-size < budget', 'first-screen < budget', 'no-blocking-sync-api'],
        runner: 'pre-merge + nightly' },
  releaseBaseline: {                          // 发版基线 diff
    async onRelease(v) {
      const diff = await metrics.diff(v, { metrics: ['fsP75', 'fpsP10', 'whiteRate'], byTier: true });
      const regressions = diff.filter(d => d.worse && d.significant);
      if (regressions.length) blockRelease(v, regressions);    // 阻断 + 归因
    },
  },
  drill: { cadence: 'quarterly', cases: ['弱网档位', '低端机矩阵', '降级开关演练', '黑名单回滚'] },
  acceptance: ['指标达标', '机制上线', '值班一个迭代', '文档归档'],   // 专项验收四条
};
```
