## PER-1231：如何为"第三方地图/图表组件"做性能封装

**答**：
- 问题：地图/图表组件重（500KB+），全量引入拖慢首屏。
- 封装策略：动态 import（进入视口/点击才加载）、容器占位（骨架）+ 加载超时兜底、实例池复用（多图表共用实例切换数据）。
- 配置纪律：关闭组件默认动画、限制数据点数（降采样 1235）、按需注册组件模块（echarts 按需 import）。
- 验收：封装组件接入契约测试（1216）。

```javascript
// 重组件懒加载封装
const cache = new Map();
async function loadHeavy(name, loader, { timeout = 8000 } = {}) {
  if (cache.has(name)) return cache.get(name);
  const p = Promise.race([
    loader(),
    new Promise((_, rej) => setTimeout(() =>
      rej(new Error(`${name} load timeout`)), timeout)),
  ]);
  cache.set(name, p);
  p.catch(() => cache.delete(name));             // 失败允许重试
  return p;
}
// 使用：进入视口时
io.onintersect = el => loadHeavy('chart',
  () => import('echarts/core').then(m => initChart(el, m)));
```
