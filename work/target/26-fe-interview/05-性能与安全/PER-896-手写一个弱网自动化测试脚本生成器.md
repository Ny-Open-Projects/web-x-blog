## PER-896：手写一个弱网自动化测试脚本生成器：按弱网档位生成代理配置与测试用例

**答**：
- 需求：实现 genWeakNetSuite(pages, profiles, budgets)：为每个 page × profile 生成用例 {id, proxyConfig, assert}——proxyConfig 为该档位的节流参数（down/up/rtt/loss 映射为代理工具配置对象），assert 为断言列表（首屏选择器存在、耗时 <= 预算、无致命错误）；offline 档只生成离线可用性用例（缓存命中检查）不做耗时断言。输出用例清单与预计执行时间（每用例按 profile 耗时系数估算）。
- 边界：页面对某 profile 显式 excluded 时跳过；budget 缺省档用默认值；用例 ID 唯一。
- 评分点：offline 特殊分支；排除规则；耗时估算。

```javascript
function genWeakNetSuite(pages, profiles, budgets, { defaultBudget = { fsMs: 5000, apiMs: 4000 } } = {}) {
  const cases = [], perCaseMin = { good: 0.5, fair: 1, bad: 2, offline: 0.5 };
  for (const pg of pages) {
    for (const [name, p] of Object.entries(profiles)) {
      if (pg.excluded?.includes(name)) continue;
      const id = `${pg.name}-${name}`;
      if (name === 'offline') {                                // 离线特殊分支
        cases.push({ id, proxyConfig: p,
          assert: [{ type: 'cache-hit', selector: pg.criticalSelector }],
          estMin: perCaseMin[name] });
        continue;
      }
      const b = budgets?.[name] ?? defaultBudget;
      cases.push({ id,
        proxyConfig: { down: p.down, up: p.up, rtt: p.rtt, loss: p.loss },
        assert: [
          { type: 'selector-exists', selector: pg.criticalSelector },
          { type: 'max-duration', budgetMs: b.fsMs },
          { type: 'no-fatal-error' },
        ],
        estMin: perCaseMin[name] });
    }
  }
  return { cases, totalEstMin: +(cases.reduce((s, c) => s + c.estMin, 0)).toFixed(1) };
}
```
