## PER-600：手写一个告警规则审计器：扫描规则集，输出僵尸规则、无 owner、无 Runbook 的违规清单

**答**：
- 审计逻辑：遍历规则 -> 校验必填字段（owner/runbook/expr 合法）-> 结合触发历史（90 天窗口）标记僵尸 -> 输出违规清单与处置建议。
- 要点：expr 的合法性可以做轻校验（括号配对、函数在白名单内）；触发历史按 ruleId 关联；僵尸的定义可配置（零触发或 acked=0）。
- 边界：新规则（创建 < 90 天）豁免僵尸判定；季节性规则（大促专用）用 `seasonal: true` 标记豁免。
- 评分点：豁免机制与处置建议分级。

```javascript

function auditRules(rules, fireHistory, { windowDays = 90, now = Date.now() } = {}) {
  const violations = [];
  for (const r of rules) {
    const issues = [];
    if (!r.owner) issues.push('缺 owner');
    if (r.level === 'page' && !r.runbook) issues.push('page 缺 Runbook');
    if (!balanced(r.expr)) issues.push('expr 括号不配对');
    const createdAge = (now - r.createdAt) / 86400000;
    const fires = fireHistory[r.id]?.length ?? 0;
    const acked = fireHistory[r.id]?.filter(f => f.acked).length ?? 0;
    if (createdAge > windowDays && !r.seasonal && (fires === 0 || acked === 0))
      issues.push(fires === 0 ? '僵尸：90 天零触发' : '僵尸：有触发无人处理');
    if (issues.length) violations.push({ id: r.id, owner: r.owner ?? 'N/A',
      issues, action: issues.some(i => i.startsWith('僵尸')) ? '下线评审' : '限期整改' });
  }
  return violations;
}
function balanced(expr) { let n = 0;
  for (const c of expr) { if (c === '(') n++; if (c === ')') n--; if (n < 0) return false; }
  return n === 0; }
// 新规则 createdAt < 90 天天然豁免；seasonal: true 的大促规则豁免僵尸判定
```
