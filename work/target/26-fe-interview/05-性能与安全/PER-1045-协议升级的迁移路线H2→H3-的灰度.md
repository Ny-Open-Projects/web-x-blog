## PER-1045：协议升级的迁移路线：H2→H3 的灰度与回退

**答**：
- 协商机制：Alt-Svc 头宣告 H3 可用，浏览器试探连接，失败自动回退 H2——天然灰度。
- 灰度监控：按 nextHopProtocol 统计各协议占比与指标差异；H3 的 TTFB/LCP 若劣化（UDP 被限速区域）需要按地域回退。
- 坑：企业网络/防火墙禁 UDP 的场景占比需先评估（试点地区先行）；QUIC 连接迁移在双栈下的地址选择策略要验证。
- 回退预案：Alt-Svc 短 TTL（如 300s）保证下线 H3 生效快。

```javascript
// 协议占比监控
function protocolMix() {
  const mix = {};
  for (const r of performance.getEntriesByType('resource')) {
    const p = r.nextHopProtocol || 'unknown';
    mix[p] = (mix[p] ?? 0) + 1;
  }
  return Object.fromEntries(Object.entries(mix)
    .map(([k, v]) => [k, +(v / performance.getEntriesByType('resource').length * 100).toFixed(1) + '%']));
}
// 服务端：Alt-Svc: h3=":443"; ma=300 短 TTL 便于快速回退
```
