## PER-573：手写一个动态基线计算器：维护按小时乘星期网格的历史数据，输出当前时段的告警线

**答**：
- 比上一题更工程化：维护内存中的网格 Map，`record()` 持续写入（带大促打标剔除），`check()` 输出告警线；数据要支持持久化快照（服务端拉取）。
- 要点：网格样本用环形上限（每格最多存 2000 条，超出随机淘汰旧样本防内存膨胀）；节假日标记列表由配置下发。
- 边界：时钟回拨/跨天边界用服务端时间而非客户端时间作为网格键。
- 评分点：大促剔除、样本上限、服务端时间三个工程细节。

```javascript

class DynamicBaseline {
  constructor({ maxPerGrid = 2000, holidays = [] } = {}) {
    this.grid = new Map(); this.maxPerGrid = maxPerGrid;
    this.holidays = new Set(holidays);                    // 服务端下发的节假日
  }
  gridKey(serverTs) {
    const d = new Date(serverTs);
    return `${d.getDay()}-${d.getHours()}`;
  }
  record(lcp, serverTs) {
    const day = new Date(serverTs).toISOString().slice(0, 10);
    if (this.holidays.has(day)) return;                   // 大促/节假日不入基线
    const k = this.gridKey(serverTs);
    const arr = this.grid.get(k) ??= [];
    arr.push(lcp);
    if (arr.length > this.maxPerGrid)
      arr.splice(0, arr.length - this.maxPerGrid);        // 淘汰最旧样本
  }
  check(serverTs) {
    const k = this.gridKey(serverTs);
    const arr = (this.grid.get(k) ?? []).slice().sort((a, b) => a - b);
    if (arr.length < 1000) return { ok: false, note: '样本不足，回退小时级网格' };
    const p95 = arr[Math.floor(arr.length * 0.95)];
    return { baseline: Math.round(p95), alertLine: Math.round(p95 * 1.1) };
  }
}
```
