## PER-557：视频类页面（课程/直播回放）的首帧性能怎么测？和普通页面的指标口径有什么不同？

**答**：
- 视频页的"首屏"不是 LCP 而是**首帧播放时刻**：video 元素渲染海报不算完，第一帧视频画面上屏（`timeupdate` 首次触发或 `requestVideoFrameCallback` 首次回调）才是用户感知的"开始看了"。
- 指标口径三段：起播耗时（点播放到首帧，含加载与缓冲）、首帧后卡顿率（7 秒内 rebuffer 次数与时长）、清晰度就绪时间（首帧可能是低档位，切到目标档的时间）。
- 测试要点：要分冷起播（无缓冲池）与热起播（已缓存 segment）；弱网档位重点测"起播失败重试"与"自动降档"是否生效；自动播放策略（静音起播）在移动端的兼容分支要覆盖。
- 对普通页面指标的关系：海报图参与 LCP，会导致 LCP 达标但起播很慢的"假达标"，视频页必须以首帧口径为准并单独设预算。

```javascript

function videoPerfProbe(video) {
  const mark = { playClickAt: 0, firstFrameMs: -1, rebuffers: 0, rebufferMs: 0, stalled: false };
  video.addEventListener('play', () => { if (!mark.playClickAt) mark.playClickAt = performance.now(); });
  // 首帧：requestVideoFrameCallback 比 timeupdate 更准
  if ('requestVideoFrameCallback' in video) {
    video.requestVideoFrameCallback(() => {
      if (mark.firstFrameMs < 0) mark.firstFrameMs = +(performance.now() - mark.playClickAt).toFixed(0);
    });
  }
  video.addEventListener('waiting', () => {               // rebuffer 开始
    mark.stalled = true; mark.stallStart = performance.now(); mark.rebuffers++;
  });
  video.addEventListener('playing', () => {
    if (mark.stalled) { mark.rebufferMs += performance.now() - mark.stallStart; mark.stalled = false; }
  });
  return { report: () => ({ ...mark, rebufferRate: +(mark.rebufferMs / 60000).toFixed(3) }) };
}
// 预算口径：起播 p75 < 1000ms、7s 内 rebuffer < 1 次、总 rebuffer < 500ms
```
