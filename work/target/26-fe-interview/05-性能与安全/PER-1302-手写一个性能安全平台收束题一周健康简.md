## PER-1302：手写一个"性能安全平台收束题"：一周健康简报生成器

**答**：
- 需求：implement weeklyDigest(data)。data 为 { perf: { sloRate, regressions }, sec: { score, incidents }, privacy: { dsarOnTime, violations }, actions: [{ what, owner }] }；输出 { headline, sections: [性能/安全/合规 各一段], next: actions }；headline 一句话总评（三域全绿/有红项）。
- 边界：各域全绿判定标准内联（sloRate=100、score>=90、violations=0、dsarOnTime=true）；红项列入 sections 高亮；actions 直接透传为 next。
- 评分点：三域判定；红项高亮；一句话 headline；透传 next

```javascript
function weeklyDigest(data) {
  const green = {
    perf: data.perf.sloRate === 100 && !data.perf.regressions.length,
    sec: data.sec.score >= 90 && !data.sec.incidents.length,
    privacy: data.privacy.dsarOnTime && !data.privacy.violations.length,
  };
  const sections = [
    { domain: '性能', ok: green.perf,
      text: green.perf ? 'SLO 全达成，无劣化' : `SLO ${data.perf.sloRate}%，劣化 ${data.perf.regressions.length} 起` },
    { domain: '安全', ok: green.sec,
      text: green.sec ? `评分 ${data.sec.score}` : `评分 ${data.sec.score}，事件 ${data.sec.incidents.length} 起` },
    { domain: '合规', ok: green.privacy,
      text: green.privacy ? 'DSAR 按时，无违规' : `DSAR 逾期/违规 ${data.privacy.violations.length}` },
  ];
  const bad = sections.filter(s => !s.ok).map(s => s.domain);
  return { headline: bad.length ? `本周红项: ${bad.join('/')}` : '三域全绿',
    sections, next: data.actions };
}

```
