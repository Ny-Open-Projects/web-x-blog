## PER-218：手写"字体加载完成前隐藏/预热"方案——FontFace API + document.fonts 配合占位渲染

**题目**：实现 `ensureFont(fontCss, text)`：① 用 FontFace API 从 URL 动态加载字体；② 加载中给根元素挂 `fonts-loading` class（CSS 里隐藏关键文本或显示占位）；③ 成功后移除 class 并返回耗时；④ 失败（超时 3s）也移除 class 并降级为 fallback 字体，返回 null；⑤ 同一字体只加载一次（缓存去重）。

**答**：FontFace API 允许 JS 精确控制字体生命周期，比纯 CSS `font-display` 多了"可编程的时机"：能在加载完成那一刻才展示文本，并上报加载耗时做监控。

```javascript
const loaded = new Map();   // url -> Promise<{ family, ms } | null>

function ensureFont(url, family = 'BizFont', text = '加载预热文本 ABC123') {
  if (loaded.has(url)) return loaded.get(url);
  const p = new Promise((resolve) => {
    const face = new FontFace(family, `url(${url})`, { display: 'swap' });
    document.documentElement.classList.add('fonts-loading');
    const t0 = performance.now();
    const done = (ok) => {
      document.documentElement.classList.remove('fonts-loading');
      resolve(ok ? { family, ms: Math.round(performance.now() - t0) } : null);
    };
    const timer = setTimeout(() => done(false), 3000);          // 超时降级
    face.load().then((f) => {
      clearTimeout(timer);
      document.fonts.add(f);
      document.fonts.load(`16px ${family}`, text).finally(() => done(true)); // 预热字形
    }).catch(() => { clearTimeout(timer); done(false); });
  });
  loaded.set(url, p);
  return p;
}
/* 配套 CSS：
.fonts-loading .hero-title { visibility: hidden; }   // 加载中隐藏，避免 FOUT 跳动
.fonts-loading { background: var(--skeleton-bg); }
*/
```

**评分点**：
- 同字体去重缓存（Map），避免重复请求。
- 超时 3s 降级路径正确，任何分支都移除 `fonts-loading`（不留死锁）。
- `document.fonts.load` 预热指定文本字形（子集字体尤其需要）。
- 返回加载耗时可供上报；CSS 占位与真实内容尺寸一致防 CLS。
