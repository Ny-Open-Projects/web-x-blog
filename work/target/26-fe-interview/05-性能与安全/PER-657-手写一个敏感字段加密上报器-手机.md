## PER-657：手写一个敏感字段加密上报器：手机号/身份证等字段在埋点与服务端通信时逐字段加密

**答**：
- 场景：合规要求 PII 字段传输与日志都不落地明文"——封装 `encryptFields(obj, fieldList)`：指定字段逐个 AES-GCM 加密（密钥由服务端会话下发），其他字段不动。
- 要点：密钥协商（服务端下发带 RSA 包裹的会话钥）后加密，字段值带版本前缀（`v1:`）支持密钥轮换；日志采集层同步脱敏（加密值展示为掩码），不是加密了就不会泄漏。
- 边界：空值/非字符串跳过；加密失败要阻塞上报而不是降级明文发送（fail-closed）；字段列表配置化（新 PII 字段及时加入）。
- 评分点：fail-closed 与密钥版本前缀。

```javascript

class FieldEncryptor {
  constructor(sessionKeyProvider) { this.provider = sessionKeyProvider; }
  async encryptValue(value) {
    const { key, version } = await this.provider.current();    // 服务端下发的会话钥
    const iv = crypto.getRandomValues(new Uint8Array(12));
    const ct = await crypto.subtle.encrypt({ name: 'AES-GCM', iv }, key,
      new TextEncoder().encode(value));
    const packed = [iv, new Uint8Array(ct)];
    return `v${version}:` + packed.map(b => btoa(String.fromCharCode(...b))).join('.');
  }
  async encryptFields(obj, fieldList) {
    const out = { ...obj };
    for (const f of fieldList) {
      const v = out[f];
      if (typeof v !== 'string' || !v) continue;               // 空值跳过
      try { out[f] = await this.encryptValue(v); }
      catch (e) { throw new Error(`PII 字段加密失败，阻断上报: ${f}`); }  // fail-closed
    }
    return out;
  }
}
// 用法：tracker.track('order', await enc.encryptFields(order, ['phone', 'receiverIdcard']))
```
