## PER-1260：手写一个页面加载分段计时器

**答**：
- 需求：实现 loadSegments(nav)。nav 为 navigation timing；分段：redirect/dns/tcp/tls/request/response/processing/paint；各段 ms（缺失段 0）；输出 segments 与 share%（保留 1 位）。
- 边界：secureConnectionStart 为 0 时 tls 并入 tcp；processing = domContentLoadedEventStart - responseEnd；paint 段 = loadEventEnd - domContentLoadedEventEnd。
- 评分点：分段公式；缺失段；share 计算；tls 归属

```javascript
function loadSegments(nav) {
  const seg = {
    redirect: Math.max(0, nav.redirectEnd - nav.redirectStart),
    dns: Math.max(0, nav.domainLookupEnd - nav.domainLookupStart),
    tcp: Math.max(0, nav.connectEnd - nav.connectStart),
    tls: nav.secureConnectionStart
      ? Math.max(0, nav.connectEnd - nav.secureConnectionStart) : 0,
    request: Math.max(0, nav.responseStart - nav.requestStart),
    response: Math.max(0, nav.responseEnd - nav.responseStart),
    processing: Math.max(0, nav.domContentLoadedEventStart - nav.responseEnd),
    paint: Math.max(0, nav.loadEventEnd - nav.domContentLoadedEventEnd),
  };
  const total = Object.values(seg).reduce((s, v) => s + v, 0) || 1;
  return { segments: seg,
    share: Object.fromEntries(Object.entries(seg)
      .map(([k, v]) => [k, +(v / total * 100).toFixed(1)])) };
}
```
