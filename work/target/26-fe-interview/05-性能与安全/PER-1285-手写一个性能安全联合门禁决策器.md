## PER-1285：手写一个"性能安全联合门禁"决策器

**答**：
- 需求：implement jointGate(perf, sec, privacy)。三个子门禁各输出 { pass, blockers }；联合规则：任一 P0 blocker -> block；perf/ssec 各有 P1 -> warn；privacy violations > 0 -> block（隐私一票否决）；输出 { verdict, byDomain, summary }。
- 边界：子门禁结果缺失按 block（fail-closed）；summary 一句话含各域结论；blockers 为 id 数组。
- 评分点：三域聚合；一票否决；fail-closed；summary

```javascript
function jointGate(perf, sec, privacy) {
  const domains = { perf: perf ?? { pass: false, blockers: ['missing'] },
    sec: sec ?? { pass: false, blockers: ['missing'] },
    privacy: privacy ?? { pass: false, blockers: ['missing'] } };
  const p0 = [], p1 = [];
  for (const [d, r] of Object.entries(domains)) {
    if (!r.pass) {
      const high = r.blockers?.filter(b => b.startsWith('P0')) ?? [];
      (high.length ? p0 : p1).push(...(high.length ? high : r.blockers ?? []));
    }
  }
  const privacyFail = !domains.privacy.pass;
  const verdict = p0.length || privacyFail ? 'block'
    : p1.length ? 'warn' : 'pass';
  return { verdict,
    byDomain: Object.fromEntries(Object.entries(domains)
      .map(([d, r]) => [d, r.pass ? 'pass' : 'fail'])),
    summary: verdict === 'block' ? `P0 或隐私违规: ${[...p0, ...(privacyFail ? domains.privacy.blockers : [])].join(',')}`
      : verdict === 'warn' ? `P1 关注项: ${p1.join(',')}` : '三域全过' };
}
```
