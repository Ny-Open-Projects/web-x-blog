## PER-1147：前端如何支撑"隐私设置中心"

**答**：
- 设计：集中式设置页——同意状态一览（各桶开关）、数据管理（导出/删除入口）、历史记录（同意变更）。
- 技术：设置变更即时生效（下发到各 SDK）、生效可验证（变更后探针确认采集停止）、跨端同步。
- 交互红线：开启路径不得深埋（三步内）、关闭路径同等顺畅（反模式：关闭藏在五层菜单）。
- 审计：每次变更记录到同意日志，可回放任意时点的设置状态。

```javascript
// 隐私设置中心
function privacyCenter(uid) {
  return {
    consent: consent.get(),
    switches: {
      analytics: v => consent.set({ analytics: v }),       // 即时生效
      personalization: v => consent.set({ personal: v }),
      ads: v => consent.set({ ads: v }),
    },
    dataTools: {
      export: () => exportUserData(uid),                   // 1139
      erase: () => handleErasure(hash(uid)),               // 1006
      history: () => consentLog(uid),                      // 变更历史
    },
    probe: () => verifyCollectionStopped(uid),             // 生效验证
  };
}
```
