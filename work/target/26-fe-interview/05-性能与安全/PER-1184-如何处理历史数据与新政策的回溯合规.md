## PER-1184：如何处理历史数据与新政策的回溯合规

**答**：
- 场景：政策收紧（新敏感字段定义/新保留期）后，存量数据如何处理。
- 盘点：数据地图（1161）定位受影响数据集 → 影响行数评估 → 整改方案（删除/降敏/迁移）。
- 执行：批量任务限流执行（避免业务高峰冲击）、进度可观测、异常可断点续跑。
- 留证：整改执行记录（范围/时间/结果）作为合规证据。

```javascript
// 回溯整改任务
async function retroPurge(dataset, newPolicy) {
  const affected = await count(dataset, newPolicy.filter);
  const batch = 10_000;
  let done = 0;
  while (done < affected) {
    const n = await deleteBatch(dataset, newPolicy.filter, batch);
    if (!n) break;                                  // 防死循环
    done += n;
    report({ type: 'retro-purge', dataset, done, total: affected });
    await new Promise(r => setTimeout(r, 1000));    // 限流
  }
  logAudit('system', 'retro-purge', `${dataset} ${done} rows per ${newPolicy.basis}`);
  return { done, total: affected };
}
```
