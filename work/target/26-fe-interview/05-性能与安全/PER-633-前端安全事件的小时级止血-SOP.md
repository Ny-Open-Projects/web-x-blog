## PER-633：前端安全事件的小时级止血 SOP：发现 XSS/注入类事故后前 60 分钟做什么？

**答**：
- 时间轴动作：**0-10 分钟**确认（漏洞真实性、影响面、是否正在被利用——查访问日志里的可疑请求样本）；**10-30 分钟**止血（选最快生效的手段：CSP 紧急收紧/网关拦截特征请求/下线受影响页面/回滚版本）；**30-60 分钟**评估与上报（数据是否外泄、合规上报流程启动、通知相关负责人）。
- 止血手段的优先级：网关侧拦截（不用发版，分钟级）> 页面下线 > 紧急发版（小时级）；不要在止血期做根因修复。
- 前端要预置的止血弹药：紧急 CSP 收敛通道（配置中心下发）、页面开关（按路由下线）、紧急公告组件、接口熔断开关——事故现场没有时间写代码，弹药必须提前备好。
- 复盘固化：漏洞原因进 checklist、止血动作进 Runbook、检测规则进监控（同类攻击特征告警）。

```javascript

const xssIncidentSop = {
  t0_10: ['确认真实性：日志找可疑请求样本（含 payload 的 query/UA）',
          '定影响面：哪些页面哪些参数、时间范围、样本量'],
  t10_30: [   // 止血优先级从快到慢
    { act: '网关拦截特征（WAF 规则/UA/query 正则）', speed: '分钟级' },
    { act: '配置中心下发紧急 CSP（收紧 script-src）', speed: '分钟级' },
    { act: '按路由下线受影响页', speed: '分钟级' },
    { act: '紧急发版修复', speed: '小时级，止血期不做' },
  ],
  t30_60: ['评估外泄数据与合规上报', '通知链：安全 -> 业务负责人 -> 法务'],
  ammo: ['紧急 CSP 通道', '路由下线开关', '公告组件', '接口熔断'],   // 提前备好
  postmortem: 'checklist + Runbook + 监控特征告警三件套固化',
};
console.log(xssIncidentSop.ammo.join(', '));
```
