## PER-220：手写一个响应式图片组件（aspect-ratio 占位 + srcset 挑选 + 懒加载边界处理）

**题目**：实现 `createResponsiveImg({ src, ratio, sizes, alt, lazy })` 返回 img 元素：① 按 ratio 设置 aspect-ratio 保证加载前占位（零 CLS）；② srcset 生成 480/720/1080 三档 + sizes 描述；③ lazy 时必须同时保证浏览器支持 IntersectionObserver 的 loading=lazy，否则用手动观察实现；④ 加载失败展示兜底占位且不位移；⑤ 首屏图（lazy=false）加 fetchpriority=high。

**答**：核心是"占位先于加载"：aspect-ratio 在任何图片到达前就把高度定死，后面 srcset/优先级策略只影响画质与时机，不再影响布局。

```javascript
function createResponsiveImg({ src, ratio = '16 / 9', sizes = '(max-width:600px) 100vw, 50vw',
                               alt = '', lazy = true }) {
  const img = document.createElement('img');
  const [w, h] = ratio.split('/').map(Number);
  img.width = w * 100; img.height = h * 100;              // 属性声明比例（相对值即可）
  img.style.aspectRatio = ratio; img.style.width = '100%';
  img.style.height = 'auto'; img.alt = alt;
  img.srcset = [480, 720, 1080].map(d => `${src}?w=${d} ${d}w`).join(', ');
  img.sizes = sizes;

  if (lazy && 'loading' in HTMLImageElement.prototype) img.loading = 'lazy';
  else if (lazy) {                                        // 降级：手动 IntersectionObserver
    img.dataset.src = src; img.src = 'data:image/svg+xml,%3Csvg xmlns=%22http://www.w3.org/2000/svg%22/%3E';
    const io = new IntersectionObserver(([e]) => {
      if (!e.isIntersecting) return;
      img.src = img.dataset.src; io.disconnect();
    }, { rootMargin: '200px' });
    io.observe(img);
  } else {
    img.fetchPriority = 'high';                           // 首屏高优
    img.loading = 'eager';
  }
  img.onerror = () => { img.srcset = ''; img.src = '/fallback.svg'; };
  return img;
}
```

**评分点**：
- aspect-ratio / width+height 属性双保险占位，加载前高度确定（零 CLS）。
- srcset 三档 + sizes 表达式正确；首屏图 fetchPriority=high 且不懒加载。
- loading=lazy 做特性检测并给出手动 IO 降级（rootMargin 提前量）。
- onerror 兜底占位且不改变布局尺寸。
