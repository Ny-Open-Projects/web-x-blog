## PER-677：手写一个移动端图片内存控制器：全页同时解码位图总量限制 + LRU 回收

**答**：
- 思路：图片加载统一走控制器，跟踪当前活跃位图的估算内存（宽×高×4），超过预算（如 80MB）时按 LRU 回收最久未见的位图（src 置为占位）。
- 要点：内存估算用解码尺寸（bitmap.width/height）而不是下载体积；回收后重新进入视口要能恢复（dataset 保留原地址）；预算按设备分档（低端 50MB）。
- 边界：正在视口内的图不回收；回收动作在 idle 时做避免掉帧；`createImageBitmap` 不可用时降级直接 img.src（不精确控制）。
- 评分点：解码尺寸内存估算与视口内保护。

```javascript

class ImageMemoryController {
  constructor({ budgetMB = 80 } = {}) {
    this.budget = budgetMB * 1024 * 1024; this.active = new Map();   // url -> {bitmap, at, inView}
  }
  async acquire(img, src) {
    const blob = await fetch(src).then(r => r.blob());
    const bitmap = await createImageBitmap(blob, { resizeQuality: 'medium' });
    const mem = bitmap.width * bitmap.height * 4;
    this.active.set(src, { bitmap, mem, at: Date.now(), inView: isOverlap(img) });
    this.enforce();                                              // 超预算 LRU 回收
    return bitmap;
  }
  enforce() {
    let total = [...this.active.values()].reduce((s, i) => s + i.mem, 0);
    if (total <= this.budget) return;
    const idleRecycle = () => {
      const sorted = [...this.active.entries()]
        .filter(([, i]) => !i.inView)                            // 视口内不回收
        .sort((a, b) => a[1].at - b[1].at);                      // LRU
      for (const [url, item] of sorted) {
        if (total <= this.budget) break;
        item.bitmap.close();                                     // 释放位图
        const img = document.querySelector(`img[data-src="${url}"]`);
        if (img) { img.dataset.src = url; img.src = PLACEHOLDER; } // 可恢复
        this.active.delete(url); total -= item.mem;
      }
    };
    (window.requestIdleCallback ?? setTimeout)(idleRecycle);     // idle 时回收
  }
  touch(src) { const i = this.active.get(src); if (i) i.at = Date.now(); }
}
```
