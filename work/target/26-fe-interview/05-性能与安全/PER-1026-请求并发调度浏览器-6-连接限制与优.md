## PER-1026：请求并发调度：浏览器 6 连接限制与优先级队列

**答**：
- H1 时代每域名 6 个连接是并发瓶颈，H2/H3 单连接多路复用后瓶颈转移到带宽与优先级。
- 调度原则：关键请求（首屏接口/LCP 资源）高优先级先发；非关键（埋点/预取/报表）进低优先级队列或 idle 执行。
- 实现：统一请求管理器——按优先级排队、限制同域并发、失败降级重试；避免业务代码各自 fetch 造成惊群。
- 深水：H2 的流优先级被部分服务端忽略，客户端仍需自行排队兜底。

```javascript
class RequestScheduler {
  constructor({ maxConcurrent = 6 } = {}) { this.max = maxConcurrent;
    this.q = { high: [], mid: [], low: [] }; this.active = new Set(); }
  push(url, init, priority = 'mid') {
    return new Promise((resolve, reject) => {
      this.q[priority].push({ url, init, resolve, reject });
      this.#drain();
    });
  }
  #drain() {
    while (this.active.size < this.max) {
      const next = this.q.high.shift() ?? this.q.mid.shift() ?? this.q.low.shift();
      if (!next) break;
      const { url, init, resolve, reject } = next;
      this.active.add(url);
      fetch(url, init).then(resolve, reject)
        .finally(() => { this.active.delete(url); this.#drain(); });
    }
  }
}
```
