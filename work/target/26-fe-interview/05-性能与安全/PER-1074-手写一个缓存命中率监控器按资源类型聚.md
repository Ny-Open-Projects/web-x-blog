## PER-1074：手写一个缓存命中率监控器：按资源类型聚合

**答**：
- 需求：实现 cacheReport(entries)。entries 为 resource timing；分类规则：按扩展名 js/css/img/font/api；命中判定 transferSize === 0 且 decodedBodySize > 0；输出 { byType: { type: { total, hit, rate } }, overall, worst }（rate 保留 1 位百分数，worst 为命中率最低类型）。
- 边界：decodedBodySize 为 0（如 304 响应）也计命中；扩展名未识别归 other；空输入返回 null。
- 评分点：扩展名分类；命中判定含 304；rate 汇总；worst 选取

```javascript
function cacheReport(entries) {
  if (!entries.length) return null;
  const TYPE = { js: 'js', mjs: 'js', css: 'css', png: 'img', jpg: 'img',
    jpeg: 'img', webp: 'img', avif: 'img', woff2: 'font', woff: 'font' };
  const byType = {};
  for (const e of entries) {
    const ext = (new URL(e.name).pathname.match(/\.(\w+)$/) ?? [])[1] ?? '';
    const type = TYPE[ext] ?? 'other';
    const hit = e.transferSize === 0;
    (byType[type] ??= { total: 0, hit: 0 });
    byType[type].total++;
    if (hit) byType[type].hit++;
  }
  for (const t of Object.values(byType)) t.rate = +(t.hit / t.total * 100).toFixed(1);
  const worst = Object.entries(byType)
    .sort((a, b) => a[1].rate - b[1].rate)[0][0];
  const total = entries.length, hit = entries.filter(e => e.transferSize === 0).length;
  return { byType, overall: +(hit / total * 100).toFixed(1), worst };
}
```
