## PER-720：手写一个长按手势识别器：长按判定、位移取消与振动反馈（ vibrations API）的时序

**答**：
- 判定：touchstart 后启动 500ms 定时器，touchmove 超过 10px 或 touchend/touchcancel 提前取消；触发时调用 `navigator.vibrate(10)`（支持的设备）给触觉反馈。
- 要点：定时器与触摸生命周期严格配对（泄漏的定时器会误触发长按）；触发后标记 handled，touchend 不再派发 click 语义；长按期间页面滚动要被抑制（touch-action 或 preventDefault，此处需非 passive）。
- 边界：iOS Safari 无 vibrate API，降级视觉反馈；长按与系统手势（边缘滑动）冲突在容器内常见，监听点要避开系统手势区。
- 评分点：生命周期配对与 handled 标记。

```javascript

class LongPressGesture {
  constructor(el, { duration = 500, onLongPress } = {}) {
    this.el = el; this.duration = duration; this.onLongPress = onLongPress;
    el.addEventListener('touchstart', e => this.onStart(e), { passive: true });
    el.addEventListener('touchmove', e => this.onMove(e), { passive: true });
    el.addEventListener('touchend', () => this.onEnd(), { passive: true });
    el.addEventListener('touchcancel', () => this.cleanup());
  }
  onStart(e) {
    this.startXY = { x: e.touches[0].clientX, y: e.touches[0].clientY };
    this.handled = false;
    this.timer = setTimeout(() => {                             // 与触摸生命周期配对
      this.handled = true;
      navigator.vibrate?.(10);                                  // 触觉反馈（iOS 降级视觉）
      this.onLongPress(this.startXY);
    }, this.duration);
  }
  onMove(e) {
    const t = e.touches[0];
    if (Math.hypot(t.clientX - this.startXY.x, t.clientY - this.startXY.y) > 10)
      this.cleanup();                                           // 位移取消
  }
  onEnd() { this.cleanup(); }
  cleanup() { clearTimeout(this.timer); this.timer = null; }
  isHandled() { return this.handled; }                          // click 判定前查此标记
}
// click 处理里：if (longPress.isHandled()) return;  // 长按触发后不再当 click
```
