## PER-779：手写一个真机矩阵热力图数据生成器：机型×页面的秒开率矩阵，自动标记劣化组合

**答**：
- 数据：真机批量跑分产出（机型、页面、秒开率、样本数）；生成器聚合成矩阵（行机型列页面），并标记异常格（低于全站均值 15% 且样本 > 50）。
- 要点：样本不足的格子标记 low-confidence 不参与告警判定；异常组合按机型劣势（全机型此页都差=页面问题）vs 页面劣势（此机型全页都差=机型问题）"分型——归因方向不同。
- 边界：新机型/新页面格子（无历史）豁免；矩阵数据版本化（每次跑分生成新矩阵，diff 可看趋势）。
- 评分点：异常分型归因方向。

```javascript

function heatmapMatrix(runs, { minSamples = 50, threshold = 0.15 } = {}) {
  const overall = avg(runs.map(r => r.secondOpenRate));          // 全站均值
  const byDevice = groupBy(runs, 'device'), byPage = groupBy(runs, 'page');
  const devices = Object.keys(byDevice), pages = Object.keys(byPage);
  const cells = devices.map(d => pages.map(p => {
    const rs = runs.filter(r => r.device === d && r.page === p);
    if (!rs.length) return { v: null, note: 'no-data' };
    const rate = avg(rs.map(r => r.secondOpenRate));
    const n = rs.reduce((s, r) => s + r.samples, 0);
    if (n < minSamples) return { v: rate, note: 'low-confidence' }; // 样本不足豁免
    const bad = rate < overall * (1 - threshold);
    let cause = null;
    if (bad) {
      const pageAvg = avg(byPage[p].map(r => r.secondOpenRate));
      const deviceAvg = avg(byDevice[d].map(r => r.secondOpenRate));
      cause = rate < pageAvg * (1 - threshold) && deviceAvg >= overall
        ? 'device-issue' : 'page-issue';                          // 分型归因方向
    }
    return { v: rate, bad, cause };
  }));
  return { devices, pages, cells, overall,
    issues: flatten(cells).filter(c => c.bad).map(c => c.cause) };
}
function avg(a) { return a.reduce((s, v) => s + v, 0) / Math.max(1, a.length); }
```
