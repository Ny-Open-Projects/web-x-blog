## PER-223：手写三方脚本加载器（预连接、idle/交互触发、超时熔断、并发去重）

**题目**：实现 `loadScript({ src, trigger = 'idle', timeout = 8000 })`：① 同 src 并发调用只注入一次（Promise 复用）；② 加载前自动 preconnect/dns-prefetch；③ trigger 支持 'idle' / 'load' / 事件名（如 'pointerdown'）；④ 超时 reject 并熔断该 src（后续调用立即 reject）；⑤ 支持 crossOrigin 与 nonce 参数透传。

**答**：要点是幂等缓存（Map<src, Promise>）、触发时机阶梯（idle → load → 交互事件）与熔断状态（失败后不再重试注毒）。

```javascript
const pending = new Map();   // src -> Promise<HTMLScriptElement>
const burned = new Set();    // 熔断集合

function loadScript({ src, trigger = 'idle', timeout = 8000, crossOrigin, nonce }) {
  if (burned.has(src)) return Promise.reject(new Error(`熔断: ${src}`));
  if (pending.has(src)) return pending.get(src);

  const p = new Promise((resolve, reject) => {
    const hint = document.createElement('link');
    hint.rel = 'preconnect'; hint.href = new URL(src).origin;
    document.head.append(hint);

    const run = () => {
      const s = document.createElement('script');
      s.src = src; s.async = true;
      if (crossOrigin) s.crossOrigin = crossOrigin;
      if (nonce) s.nonce = nonce;                 // 配合 CSP script-src 'nonce-xxx'
      const timer = setTimeout(() => {
        burned.add(src); s.remove(); reject(new Error(`超时熔断: ${src}`));
      }, timeout);
      s.onload = () => { clearTimeout(timer); resolve(s); };
      s.onerror = () => { clearTimeout(timer); burned.add(src); reject(new Error(`加载失败: ${src}`)); };
      document.head.append(s);
    };
    if (trigger === 'load') addEventListener('load', run, { once: true });
    else if (trigger === 'idle') (window.requestIdleCallback || ((f) => setTimeout(f, 200)))(run, { timeout: 3000 });
    else addEventListener(trigger, run, { once: true });   // 首次交互预热
  });
  pending.set(src, p);
  return p;
}
// 并发去重：loadScript({src}) 多处调用共享同一个 Promise，script 只注入一次
```

**评分点**：
- Map 缓存 Promise 实现并发去重（不是缓存 script 元素，而是缓存加载 Promise）。
- 触发时机三档（idle/load/事件名）实现完整，idle 带 timeout 兜底。
- 超时与失败都要进入 burned 熔断集，且移除已注入的 script。
- preconnect 提示 + nonce/crossOrigin 透传（与 CSP 配套）。
