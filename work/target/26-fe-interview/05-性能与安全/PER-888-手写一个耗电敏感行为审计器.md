## PER-888：手写一个耗电敏感行为审计器：扫描高频定位、传感器与唤醒锁等耗电 API 使用

**答**：
- 需求：实现 powerAudit(pageScript)：静态扫描源码字符串，检测：geolocation.watchPosition（计数与是否有 clearWatch 配对）、DeviceMotion/DeviceOrientation 监听、setInterval 周期 < 1000ms 的数量、wakeLock 请求；输出风险报告（每项：出现次数、是否配对清理、风险等级），全页无配对清理项标记 leak-risk。
- 边界：字符串内注释中的调用也计入（保守告警）；watchPosition 与 clearWatch 按 ID 配对（无法静态判定的标记 manual-check）；风险等级：高频 interval + 无清理 = high。
- 评分点：配对清理检测；风险分级；manual-check 兜底。

```javascript
function powerAudit(source) {
  const count = re => (source.match(re) || []).length;
  const watch = count(/watchPosition\s*\(/g);
  const clearWatch = count(/clearWatch\s*\(/g);
  const motion = count(/(DeviceMotion|DeviceOrientation)/g);
  const fastInterval = (source.match(/setInterval\s*\([^,]+,\s*(\d+)\s*\)/g) || [])
    .map(s => +s.match(/(\d+)\s*\)/)[1]).filter(ms => ms < 1000).length;
  const wakeLock = count(/wakeLock\s*\.\s*request/g);
  const items = [
    { api: 'watchPosition', n: watch, paired: clearWatch >= watch,
      risk: watch > 0 && clearWatch < watch ? 'leak-risk' : watch > 0 ? 'manual-check' : 'ok' },
    { api: 'device-sensors', n: motion, risk: motion > 0 ? 'manual-check' : 'ok' },
    { api: 'fast-interval', n: fastInterval, risk: fastInterval >= 3 ? 'high' : fastInterval ? 'medium' : 'ok' },
    { api: 'wakeLock', n: wakeLock, risk: wakeLock ? 'manual-check' : 'ok' },
  ];
  return { items, verdict: items.some(i => i.risk === 'high' || i.risk === 'leak-risk')
    ? 'block-review' : 'pass' };
}
```
