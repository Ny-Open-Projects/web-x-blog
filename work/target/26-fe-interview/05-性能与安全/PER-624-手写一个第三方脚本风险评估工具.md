## PER-624：手写一个第三方脚本风险评估工具：扫描页面引入的外部脚本并输出风险分级报告

**答**：
- 扫描 `<script src>` 外部脚本，评估维度：是否 SRI 锁定、是否 latest 跟随、域名信誉名单、是否 async/defer（加载时序风险）、CSP 是否覆盖该域。
- 要点：域名分级名单（可信 CDN/官方域 vs 未知域）可配置热更新；`script[src*=latest]` 或无版本号路径视为跟随更新高风险；输出按风险排序并给处置建议（加 SRI/塞 iframe/删掉）。
- 边界：内联 script 的 nonce 检查一并输出；动态 `createElement('script')` 静态扫描不到，运行时用 Performance resource entries 兜底收集。
- 评分点：SRI 缺失判定与动态脚本兜底收集。

```javascript

const TRUSTED = ['cdn.example.com', 'static.example.com', 'unpkg.com', 'jsdelivr.net'];
function auditThirdPartyScripts() {
  const rows = new Map();
  // 静态 script 标签
  document.querySelectorAll('script[src]').forEach(s => {
    const u = new URL(s.src, location.href);
    rows.set(u.href, { url: u.href, sri: !!s.integrity, el: s });
  });
  // 运行时动态加载兜底
  performance.getEntriesByType('resource')
    .filter(r => r.initiatorType === 'script' && !rows.has(r.name))
    .forEach(r => rows.set(r.name, { url: r.name, sri: false, dynamic: true }));
  return [...rows.values()].map(r => {
    const host = new URL(r.url).host;
    const followed = /latest|@\d+\.x|\/current\//.test(r.url);   // 跟随更新
    return {
      url: r.url.slice(0, 60),
      sri: r.sri,
      trustedHost: TRUSTED.includes(host),
      level: !r.sri && !TRUSTED.includes(host) ? 'high'
        : !r.sri && followed ? 'medium'
        : !r.sri ? 'medium' : 'low',
      advice: !r.sri ? '加 SRI 或锁版本；能塞 iframe 的塞 iframe' : 'ok',
    };
  }).sort((a, b) => ['high','medium','low'].indexOf(a.level) - ['high','medium','low'].indexOf(b.level));
}
console.table(auditThirdPartyScripts());
```
