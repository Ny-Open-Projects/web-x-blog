## PER-537：手写一个字体加载探针：测量关键 webfont 的实际加载与首次渲染时间，输出阻塞窗口

**答**：
- 用 `document.fonts` API（`FontFaceSet`）观察字体加载事件：`loadingdone` 的时间点减去首次使用该字体的元素出现时间，得到"文字不可见/闪烁窗口"。
- 要点：给关键字体加 `font-display: swap` 后，测的是 FOUT 窗口（先用回退字体再换）；用 `document.fonts.load('16px ' + family)` 可主动预热并计时。
- 边界：CSS 里未实际使用的字形不会触发下载，探针要确认字体真的被页面用到（检查 `document.fonts.check()`）；跨域字体要确认 CORS 头否则静默失败。
- 评分点：`loadingdone` 事件与 `check` 校验的组合使用。

```javascript

function fontProbe(family, testText = '字体加载探针') {
  return new Promise(resolve => {
    const t0 = performance.now();
    document.fonts.addEventListener('loadingdone', (e) => {
      const hit = e.fontfaces.some(f => f.family.replace(/['"]/g, '') === family);
      if (!hit) return;
      resolve({
        loadMs: +(performance.now() - t0).toFixed(1),        // 从探针启动到字体就绪
        usable: document.fonts.check(`16px "${family}"`, testText), // 关键字形真的可用
      });
    }, { once: true });
    document.fonts.load(`16px "${family}"`, testText)        // 主动触发并预热
      .catch(() => resolve({ loadMs: -1, usable: false, note: '加载失败，检查 CORS/路径' }));
  });
}
// fontProbe('PingFang-Brand').then(r => console.log(r))
// -> { loadMs: 420, usable: true } 配合 FCP 时间算出文字不可见窗口
```
