## PER-853：移动端字体加载的性能：子集化、font-display 与闪动治理

**答**：
- 中文字体的体量问题：全量中文字体 3~10MB，必须子集化——按页面实际用字生成 woff2 子集（几十 KB），或用分片字体（unicode-range 切成上百片按需加载）。
- font-display 策略：swap（立即显示回退字体，加载完替换，有 FOUT 闪动）vs block（短暂阻塞，FOIT 白块）vs optional（几乎不阻塞，系统字体可能永久生效）——移动端首屏推荐 swap + 尽量小子集缩短替换窗口。
- 闪动治理：回退字体与目标字体的度量对齐（size-adjust/ascent-override 减少布局跳动）；关键文字（标题）用 preload 提前拉字体。
- 缓存：字体设长缓存（immutable + hash 文件名）；子集随内容变化频率低，缓存命中率高。

```javascript
// 子集字体接入清单
const fontPlan = {
  subset: '构建期按文案字符集生成 woff2（pyftsubset）',
  slices: 'unicode-range 分片：每片 ~100KB，按需下载',
  css: `@font-face {
  font-family: 'CN-Bold';
  src: url('cn-bold.subset.woff2') format('woff2');
  font-display: swap;                          /* 移动端首屏 swap */
  unicode-range: U+4E00-9FFF;                  /* 分片声明 */
}`,
  metricAlign: 'size-adjust: 105%; ascent-override: 90%;  /* 减少替换跳动 */',
  preload: '<link rel="preload" href="cn-bold.subset.woff2" as="font" crossorigin>',
};
// 监控：字体加载完成时间与替换闪动时长
document.fonts.ready.then(() => report('font-ready', { ms: +(performance.now() - t0).toFixed(0) }));
```
