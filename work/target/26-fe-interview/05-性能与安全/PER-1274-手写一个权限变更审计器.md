## PER-1274：手写一个权限变更审计器

**答**：
- 需求：实现 permChangeAudit(changes, users)。changes 为 [{ ts, operator, action: grant/revoke, target, perm }]；users 为 { uid: Set(perms) } 当前状态；重放 changes 验证每步合法（revoke 不存在的 perm 标 anomaly）；输出 { finalState, anomalies }；operator 无 grant 权限（不在 ADMINS）也 anomaly。
- 边界：grant 幂等（已有不再报）；changes 按时间排序后重放；目标 uid 不存在则跳过该条并 anomaly。
- 评分点：重放验证；幂等；非法撤销；管理员校验

```javascript
function permChangeAudit(changes, users, ADMINS) {
  const sorted = [...changes].sort((a, b) => a.ts - b.ts);
  const anomalies = [];
  const state = Object.fromEntries(
    Object.entries(users).map(([k, v]) => [k, new Set(v)]));
  for (const c of sorted) {
    const u = state[c.target];
    if (!u) { anomalies.push({ ...c, why: 'target 不存在' }); continue; }
    if (!ADMINS.includes(c.operator))
      anomalies.push({ ...c, why: 'operator 非管理员' });
    if (c.action === 'grant') {
      if (u.has(c.perm)) anomalies.push({ ...c, why: '重复授权' });
      u.add(c.perm);
    } else {
      if (!u.has(c.perm)) anomalies.push({ ...c, why: '撤销未持有的权限' });
      u.delete(c.perm);
    }
  }
  return { finalState: Object.fromEntries(Object.entries(state)
    .map(([k, v]) => [k, [...v]])), anomalies };
}
```
