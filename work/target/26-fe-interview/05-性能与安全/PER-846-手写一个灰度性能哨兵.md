## PER-846：手写一个灰度性能哨兵：灰度组与基线组指标对比与劣化自动告警

**答**：
- 需求：实现 sentinelTick(grayMetrics, baseMetrics, rules)：rules 为 [{metric, type: rate|latency, pauseIf: fn(g,b), minSample}]；输出动作列表：样本不足的规则输出 skip（含原因）；命中劣化条件的输出 pause + 明细；其余输出 pass。同一次 tick 多条规则命中只保留最严重一条（rate 劣化优先于 latency）。
- 边界：基线值为 0 时跳过比例比较（输出 insufficient-baseline）；指标缺失视为无数据不参与判定。
- 评分点：分类型比较；样本不足 skip；最严重一条收敛。

```javascript
function sentinelTick(gray, base, rules) {
  const out = [];
  for (const r of rules) {
    const g = gray[r.metric], b = base[r.metric];
    if (!g || !b) { out.push({ rule: r.metric, action: 'no-data' }); continue; }
    if (g.sample < r.minSample || b.sample < r.minSample) {
      out.push({ rule: r.metric, action: 'skip', reason: 'insufficient-sample' }); continue;
    }
    if (r.type === 'rate' && b.value === 0) {
      out.push({ rule: r.metric, action: 'insufficient-baseline' }); continue;
    }
    if (r.pauseIf(g.value, b.value))
      out.push({ rule: r.metric, action: 'pause', type: r.type,
        gray: g.value, base: b.value, delta: +(g.value - b.value).toFixed(4) });
    else out.push({ rule: r.metric, action: 'pass' });
  }
  const pauses = out.filter(o => o.action === 'pause');
  if (pauses.length > 1) {                                     // 收敛最严重一条
    const worst = pauses.find(p => p.type === 'rate') || pauses[0];
    return out.map(o => o.action === 'pause' && o !== worst ? { ...o, action: 'paused-suppressed' } : o);
  }
  return out;
}
```
