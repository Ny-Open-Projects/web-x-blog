## PER-442：WebSocket/SSE 在弱网下的心跳、断线检测与消息补偿协议？

**答**:
- 弱网三问题：半开连接（TCP 未断但实际不通）、心跳误杀（弱网 RTT 大，心跳超时阈值要按网络档位自适应）、消息丢失（断线期间的推送缺失）。
- 心跳设计：ping 间隔 30s + 超时 2×RTT 档位自适应（快网 5s、弱网 15s）；连续 N 次心跳超时才断线重连（防单次抖动误杀）。PONG 延迟作为 RTT 信号回馈网络档位（PER-325 融合）。
- 断线重连：指数退避 + 抖动（HW-063 模式）；重连成功后**消息补偿**——携带 lastReceivedId 服务端补发缺口（幂等去重）；不可补偿的场景（行情）标记 gap 提示用户数据有间断。
- 弱网降级：3 次重连失败降级为 HTTP 轮询（弱网下 WS 心跳本身耗流量，轮询批量更经济）——恢复快网再升回 WS。

```javascript
class WeakNetWS {
  constructor(url) { Object.assign(this, { url, lastId: null, failures: 0 }); }
  heartbeat() {
    this.pingTimer = setTimeout(() => {
      const t0 = performance.now();
      this.send({ type: 'ping', id: ++this.seq });
      this.pongTimeout = setTimeout(() => {
        this.failures++;                                  // 弱网自适应阈值后仍超时
        if (this.failures >= 2) this.reconnect();         // 连续 2 次才断线（防抖动误杀）
        else this.heartbeat();
      }, Math.max(5000, this.rttEstimate * 2));           // RTT 档位自适应超时
    }, 30000);
  }
  reconnect() {
    const delay = Math.min(1000 * 2 ** this.failures, 30000) * (0.5 + Math.random() / 2);
    setTimeout(async () => {
      await this.connect();
      this.send({ type: 'resume', lastId: this.lastId });  // 消息补偿：补发断线期间缺口
    }, delay);
  }
  onMessage(msg) { this.lastId = msg.id; }               // 记最后收到 id（补偿游标）
  degradeToPolling() { /* 3 次重连失败 → HTTP 轮询（弱网更经济） */ }
}
```
