## PER-693：手写一个移动端滚动白屏检测器：快速滑动长列表时检测空白区域并统计白屏时长

**答**：
- 场景：虚拟列表快滚时新行未渲染完出现空白——检测方法：滚动期间周期采样视口中心区域的有效内容（子元素覆盖密度），连续 N 次采样为空则记一次白屏事件并计时。
- 要点：采样用 `elementsFromPoint` 或视口切片统计（便宜，不截图）；采样间隔 100ms；白屏定义 = 中心 60% 区域无有效子元素且无骨架屏。
- 边界：图片加载中不算白（有占位）；列表底部天然空白（滚动超出内容区）要排除（scrollTop + viewport >= scrollHeight - margin）；页面不可见暂停。
- 评分点：切片统计法与底部排除。

```javascript

function installBlankDetector({ interval = 100, blankCount = 3 } = {}) {
  let streak = 0, blankStart = 0, timer = null;
  const tick = () => {
    if (!document.hidden && isScrolling()) {
      const blank = viewportCenterBlank();
      if (blank) {
        if (!streak) blankStart = performance.now();
        if (++streak >= blankCount) {                           // 连续 3 次采样为空
          const dur = performance.now() - blankStart;
          if (!atListBottom())                                  // 排除列表底部
            report('list-blank', { durMs: Math.round(dur), scrollTop, route: location.pathname });
        }
      } else streak = 0;
    }
  };
  const viewportCenterBlank = () => {
    const h = innerHeight * 0.6, top = innerHeight * 0.2;
    let valid = 0;
    for (let y = top; y < top + h; y += h / 5) {
      const els = document.elementsFromPoint(innerWidth / 2, y);
      valid += els.some(e => e.dataset.skeleton || e.children.length) ? 1 : 0;
    }
    return valid === 0;                                         // 全空 = 白
  };
  timer = setInterval(tick, interval);
}
function atListBottom() {
  return Math.ceil(scrollY + innerHeight) >= document.body.scrollHeight - innerHeight * 0.5;
}
```
