## PER-1267：手写一个灰度发布性能哨兵：自动熔断劣化版本

**答**：
- 需求：实现 canarySentinel(opts)。watch(buildId) 定期拉取灰度桶指标；指标劣化 > 10%（影响面 > 100 用户）触发 promote(false) 回滚回调并记录事件；连续 2 次确认才熔断（防抖动）；恢复监控新版本。
- 边界：样本 < 30 跳过判定（样本不足）；回调抛错重试 1 次；输出决策日志。
- 评分点：样本门槛；双确认熔断；回调重试；决策日志

```javascript
class canarySentinel {
  constructor({ rate = 0.1, minSamples = 30, fetchMetrics, promote, log = [] } = {}) {
    Object.assign(this, { rate, minSamples, fetchMetrics, promote, log });
    this.strikes = 0;
  }
  async check(buildId) {
    const m = await this.fetchMetrics(buildId);
    if (m.samples < this.minSamples)
      return this.#log(buildId, 'skipped', `样本不足 ${m.samples}`);
    const bad = m.p75 > m.baseline * (1 + this.rate);
    if (bad) {
      if (++this.strikes >= 2) {
        try { this.promote(buildId, false); }
        catch (e) { try { this.promote(buildId, false); } catch {} }
        this.#log(buildId, 'rolled-back', `P75 ${m.p75} vs 基线 ${m.baseline}`);
        this.strikes = 0;
      } else this.#log(buildId, 'strike-1', `劣化疑似`);
    } else { this.strikes = 0; this.#log(buildId, 'ok', `P75 ${m.p75}`); }
  }
  #log(buildId, action, detail) { this.log.push({ buildId, action, detail, at: Date.now() }); }
}
```
