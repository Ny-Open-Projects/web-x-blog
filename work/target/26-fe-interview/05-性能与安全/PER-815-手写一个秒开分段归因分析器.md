## PER-815：手写一个秒开分段归因分析器：输入分段埋点数据，输出各段 p75 与超预算段

**答**：
- 需求：输入埋点样本 [{seg, ms, deviceTier}]，按段聚合输出 p75 与超预算标记；要求支持按设备档过滤（高端/低端分别归因）；输出"超预算量最大段"为首要行动项。
- 边界：样本 < 10 的段标记 insufficient 不参与超预算判定；耗时为负或 > 60s 的样本视为脏数据剔除；预算表按段可配置。
- 评分点：脏数据剔除；分档归因双视图；insufficient 不误报。

```javascript
function analyzeSegs(samples, budgets, { minSample = 10 } = {}) {
  const clean = samples.filter(s => s.ms > 0 && s.ms < 60000);   // 脏数据剔除
  const bySeg = {};
  for (const s of clean) {
    const key = `${s.seg}`;
    (bySeg[key] ??= { all: [], low: [], high: [] });
    bySeg[key].all.push(s.ms);
    bySeg[key][s.deviceTier === 'low' ? 'low' : 'high'].push(s.ms);
  }
  const result = Object.entries(bySeg).map(([seg, d]) => {
    const insufficient = d.all.length < minSample;
    const p75v = p75(d.all);
    return { seg, p75: p75v, budget: budgets[seg] ?? Infinity,
      lowP75: p75(d.low), highP75: p75(d.high),
      insufficient, over: !insufficient && p75v > (budgets[seg] ?? Infinity) };
  });
  const actionable = result.filter(s => s.over)
    .sort((a, b) => (b.p75 - b.budget) - (a.p75 - a.budget))[0];
  return { segs: result, priority: actionable?.seg ?? 'none' };
}
function p75(a) { if (!a.length) return null; const s = [...a].sort((x, y) => x - y); return s[Math.floor(s.length * 0.75)]; }
```
