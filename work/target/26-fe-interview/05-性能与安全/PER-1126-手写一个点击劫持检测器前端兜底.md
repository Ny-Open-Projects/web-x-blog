## PER-1126：手写一个点击劫持检测器（前端兜底）

**答**：
- 需求：实现 antiClickjack()。检测 self !== top 时：尝试 top.location 跳出（try-catch）；失败则整页隐藏并上报（含 document.referrer 与尝试的嵌入方）；返回当前是否处于被嵌入状态；同源嵌入（白名单场景）通过 message 握手放行。
- 边界：top 不可访问（跨源）时 catch；referrer 为空也要上报；白名单通过 parent.postMessage 握手（超时 1s 未响应仍隐藏）。
- 评分点：跳出尝试；跨源兜底；白名单握手；隐藏+上报

```javascript
function antiClickjack(WHITELIST = []) {
  if (self === top) return { framed: false, action: 'none' };
  try { top.location = self.location; return { framed: true, action: 'escaped' }; }
  catch {}                                                 // 跨源无法跳出
  const src = document.referrer || 'unknown';
  const allowed = WHITELIST.some(h => src.includes(h));
  if (allowed) {
    let ok = false;
    parent.postMessage({ type: 'embed-handshake' }, '*');
    addEventListener('message', e => { if (e.data?.type === 'embed-ack') ok = true; });
    setTimeout(() => { if (!ok) deny(); }, 1000);          // 握手超时仍隐藏
    return { framed: true, action: 'whitelist-pending' };
  }
  deny();
  return { framed: true, action: 'hidden' };
}
function deny() {
  document.documentElement.style.display = 'none';
  report({ type: 'framing-denied', ref: document.referrer, url: location.href });
}
```
