## PER-1032：弱网优化专项：高延迟高丢包下的策略矩阵

**答**：
- 弱网特征：RTT > 500ms / 丢包 > 2% / 带宽 < 400kbps；表现是 TTFB 飙升与重传雪崩。
- 策略矩阵：请求合并（减少 RTT 轮次）、资源预取降级（只拉首屏必需）、图片降级（低分辨率/更激进压缩）、协议升级（H3/QUIC 抗丢包）。
- 探测：NetworkInformation.downlink/rtt + 业务实测（最近 N 个请求 TTFB 分位）动态判定弱网档位。
- 执行：弱网档位作为全局配置下发，SDK 按档位调整采样率/图片参数/预取策略。

```javascript
function networkTier() {
  const c = navigator.connection ?? {};
  const rtt = c.rtt ?? 100, dl = c.downlink ?? 10;
  if (rtt > 500 || dl < 0.5) return 'bad';
  if (rtt > 200 || dl < 2) return 'mid';
  return 'good';
}
const POLICY = {
  bad:  { imgW: 360, prefetch: false, batchSize: 5 },
  mid:  { imgW: 720, prefetch: 'visible', batchSize: 20 },
  good: { imgW: 1080, prefetch: true, batchSize: 50 },
};
addEventListener('change', () => applyPolicy(POLICY[networkTier()]));
applyPolicy(POLICY[networkTier()]);
```
