## PER-1252：手写一个资源瀑布分析器：找串行瓶颈

**答**：
- 需求：实现 waterfallBottlenecks(entries)。entries 为 [{ name, startTime, duration }]；找关键路径：从最早开始资源起，串行链（下一资源 start >= 上一资源 end）累计时长最长的链；输出 { chain: [name], totalMs, parallelizable }（与链并行且可提前的资源名）。
- 边界：重叠资源不算串行；duration 为 0 忽略；空输入返回 null；链长 < 2 无瓶颈。
- 评分点：串行链判定；最长链搜索；并行可提前；边界过滤

```javascript
function waterfallBottlenecks(entries) {
  const es = entries.filter(e => e.duration > 0)
    .sort((a, b) => a.startTime - b.startTime);
  if (es.length < 2) return null;
  let best = { chain: [], totalMs: 0 };
  for (let i = 0; i < es.length; i++) {
    const chain = [es[i]]; let end = es[i].startTime + es[i].duration;
    for (let j = i + 1; j < es.length; j++) {
      if (es[j].startTime >= end) { chain.push(es[j]); end = es[j].startTime + es[j].duration; }
    }
    const totalMs = chain.reduce((s, c) => s + c.duration, 0);
    if (totalMs > best.totalMs) best = { chain: chain.map(c => c.name), totalMs };
  }
  const chainNames = new Set(best.chain);
  const chainEnd = best.totalMs;
  const parallelizable = es.filter(e => !chainNames.has(e.name) &&
    e.startTime < chainEnd && e.startTime > es[0].startTime)
    .map(e => e.name).slice(0, 5);
  return { chain: best.chain, totalMs: +best.totalMs.toFixed(1), parallelizable };
}
```
