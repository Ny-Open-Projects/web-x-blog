## PER-890：手写一个性能专项立项计算器：按收益估算、人力成本与风险输出立项优先级

**答**：
- 需求：实现 prioritize(projects)：每个项目 {name, gainMs: 预计用户耗时收益(ms×覆盖用户数折算), users: 受益用户占比, cost: 人日, risk: 0-1}；评分 = 归一化收益 / (成本 + 风险权重×成本)；输出按分降序的立项清单，并标注 quick-win（收益高成本低，score 前 20% 且 cost < 5 人日）。
- 边界：收益与成本先做 min-max 归一化（0~1）再算；risk 为 0 处理正确；同分按 cost 升序。
- 评分点：归一化正确；评分公式含风险惩罚；quick-win 标注。

```javascript
function prioritize(projects) {
  const norm = (arr, k) => { const vs = arr.map(p => p[k]);
    const min = Math.min(...vs), max = Math.max(...vs);
    return new Map(arr.map(p => [p, max === min ? 1 : (p[k] - min) / (max - min)])); };
  const g = norm(projects, 'gainMs'), c = norm(projects, 'cost');
  const scored = projects.map(p => {
    const adjCost = c.get(p) * (1 + p.risk);                   // 风险惩罚放大成本
    return { ...p, score: +(g.get(p) / Math.max(adjCost, 0.01)).toFixed(3) };
  }).sort((a, b) => b.score - a.score || a.cost - b.cost);
  const topN = Math.max(1, Math.ceil(scored.length * 0.2));
  return scored.map((p, i) => ({ ...p,
    quickWin: i < topN && p.cost < 5 ? true : undefined }));
}
```
