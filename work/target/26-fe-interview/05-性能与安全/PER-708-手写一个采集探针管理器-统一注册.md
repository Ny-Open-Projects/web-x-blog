## PER-708：手写一个采集探针管理器：统一注册/开关/懒安装与一键熔断，采集税可观测

**答**：
- 设计：探针注册表 `{name, install, tier, lazy}`——tier 决定采样率，lazy 的探针首屏后安装；总开关配置中心下发；熔断开关一键全关（探针全部 uninstall）；各探针暴露 self 统计（回调次数/耗时估计）。
- 要点：uninstall 要完整（observer 断开、事件移除、定时器清除——install 返回 cleanup 函数约定）；self 统计聚合上报形成采集税看板"；熔断状态持久化（重启仍关闭）。
- 边界：核心探针（错误采集）不参与熔断（最后一道防线）；安装顺序记录（首屏前只允许核心探针）。
- 评分点：cleanup 约定与核心探针豁免。

```javascript

class ProbeManager {
  constructor(config) {
    this.probes = new Map(); this.active = new Map();
    this.enabled = config.enabled ?? true;
    this.coreOnly = !config.fullEnabled;                        // 熔断态只留核心
  }
  register({ name, install, core = false, lazy = false }) {
    this.probes.set(name, { install, core, lazy });
    if (!lazy) this.maybeStart(name);                           // lazy 探针等首屏后
  }
  maybeStart(name) {
    const p = this.probes.get(name);
    if (!this.enabled || (this.coreOnly && !p.core)) return;    // 熔断豁免核心探针
    if (this.active.has(name)) return;
    const cleanup = p.install();                                // 约定：install 返回清理函数
    this.active.set(name, { cleanup, calls: 0, selfMs: 0 });
  }
  afterFirstScreen() { [...this.probes.keys()].forEach(n => this.maybeStart(n)); }
  selfReport(name, ms) { const a = this.active.get(name); if (a) { a.calls++; a.selfMs += ms; } }
  circuitBreak() {                                              // 一键熔断
    for (const [name, a] of this.active) {
      if (this.probes.get(name).core) continue;                 // 核心豁免
      a.cleanup?.(); this.active.delete(name);
    }
    this.coreOnly = true;
    localStorage.setItem('probe-break', '1');                   // 重启保持
    track('probe-circuit-break');
  }
  taxReport() {                                                 // 采集税看板数据
    return [...this.active.entries()].map(([n, a]) =>
      ({ n, calls: a.calls, selfMs: +a.selfMs.toFixed(1) }));
  }
}
```
