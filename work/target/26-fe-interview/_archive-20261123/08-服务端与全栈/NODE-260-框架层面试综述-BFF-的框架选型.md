## NODE-260：框架层面试综述：BFF 的框架选型与演进？
**答**:
- 综述框架：中间件原理（NODE-251/253）→ 性能来源（254）→ 选型矩阵（255）→ 架构分层（258 适配层）→ 流式（259）。
- BFF 演进三阶段：Express/Koa 胶水层（聚合+裁剪）→ 契约化（Fastify schema / tRPC，NODE-29x）→ 网关化（聚合下沉 API 网关，BFF 只留个性化）。
- 高频追问："为什么不用 Express"→ 生态老但无 schema/洋葱；"Koa ctx 全局态怎么治理"→ ALS（256）+ 命名空间；"性能差距怎么测"→ autocannon 同口径压测。
- 收束一句：框架选型 = 团队存量 × 契约化程度 × 性能预算三个输入的加权决策。

```javascript
// 演进一页纸
// 阶段1：BFF = Koa + 中间件（鉴权/聚合/裁剪）—— 灵活但无契约
// 阶段2：Fastify schema / tRPC —— 契约即代码（类型/文档/校验一份产出）
// 阶段3：聚合下沉网关（GraphQL Federation/网关聚合），BFF 收缩为个性化层（权限/埋点/AI 代理）
// 面试话术："BFF 的终点是变薄——把通用的东西下沉，留给人写的只剩业务个性化的胶水"
```
