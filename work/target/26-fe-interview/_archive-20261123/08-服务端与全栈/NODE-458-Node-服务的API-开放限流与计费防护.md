## NODE-458：开放 API 防滥用
**答**:
- 滥用画像：爬取式滥用（全量分页扫描——低速率但持续性）、转售套利（免费额度批量注册）、功能滥用（用开放 API 做非约定用途）。检测：调用模式分析（速率曲线/参数分布/结果集覆盖度），画像异常告警（NODE-448 调用方画像扩展）。
- 分层防线：准入（appKey 审核 + 实名）、配额（NODE-439 分档配额）、速率（NODE-360 令牌桶 + 突发限制）、内容防护（敏感字段脱敏返回、分页深度限制——防全量爬取）、异常熔断（单 appKey 行为异常自动降级至暂停 + 人工审核）。
- 计费防护：计量防刷（NODE-401 幂等计量）、免费额度防批量注册（设备/支付凭证校验）、账单异常预警（调用量突增 → 潜在盗用）。
- 处置流程：分级处置（限速 → 降配 → 暂停 → 封禁），每级有申诉通道与解封条件；处置审计留痕。
- 数据防护：高价值数据接口专项（防爬取的采样/水印/追溯标识——泄露可定位到 appKey）。
```javascript
// 爬取模式检测
function crawlPattern(appKey, window = '1h') {
  const s = usageProfile(appKey, window);
  return s.pageCoverage > 0.9 && s.rate < limitRate(appKey) * 0.5; // 低速全覆盖 = 疑似爬取
}
// 处置：crawlPattern → 自动降速 50% → 通知 → 持续则暂停 + 人工审核（申诉入口）
```
