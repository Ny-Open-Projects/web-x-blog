## NODE-521：API 网关限流体系
**答**:
- 限流矩阵：维度组合（按 IP——匿名/防刷、按用户——登录态、按 appKey——开放 API NODE-397、按接口——接口容量、按租户——多租户 NODE-462、按灰度标签——发布保护），每接口声明适用维度与配额（配置化 NODE-499）。
- 优先级与叠加：维度限流叠加（用户限流 100/s × 接口限流 5000/s × 全局 10w/s——任一触发即限），优先级语义（全局兜底最粗、用户最细——细的先触发给用户反馈）。
- 分类响应：限流响应语义（429 + Retry-After + 限流头 NODE-360）、区分"正常限流"（用户超额——友好提示）与"攻击限流"（异常模式——风控联动 NODE-456）、白名单豁免（探活/内部调用）。
- 动态调整：限流配置热更（NODE-499 配置灰度）、应急限流（故障时全局收紧——保护性限流预案一键下发 NODE-429）。
- 观测：限流触发率按维度/接口分桶（哪个维度在限——容量或攻击判断）、限流后的用户行为（重试风暴？——Retry-After 遵守率）。
```yaml
# 限流矩阵声明
/api/goods:
  limits:
    - { dim: ip, rate: 100/s, burst: 200 }          # 匿名防刷
    - { dim: user, rate: 50/s }                      # 登录态
    - { dim: global, rate: 50000/s, note: '容量保护' }
  classify: { user: 'friendly', ip: 'antibot' }      # 响应语义分类
```
