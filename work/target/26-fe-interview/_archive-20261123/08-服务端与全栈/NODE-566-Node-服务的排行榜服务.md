## NODE-566：排行榜服务
**答**:
- 榜单类型：实时榜（ZSET 原子加分——Redis 有序集合）、周期榜（日/周/月——窗口切分：多 ZSET 分桶 + 定期归档）、防刷榜（异常值过滤——风控标记不计分）。
- 实现要点：ZSET 加分（原子 INCRBY——并发安全）、并列处理（分数相同按时间排序——ZSET score 组合：score * 1e8 - ts）、分页查询（ZREVRANGE 分页 + 自己排名 ZREVRANK）、大榜读取缓存（榜单快照 5s 缓存——读热点 ARC-537）。
- 归档与一致性：周期归档（定时任务：日榜归档快照——NODE-437）、清零与重置（新周期 ZSET 重建——归档先于清零）、分布式计数（多业务写同一榜——事件驱动统一加分入口幂等）。
- 展示协议：榜单协议（前 N + 我的名次/分数——分段返回）、变化动画数据（排名变化 delta——端上动画 ARC-537）。
- 边界：超大榜（百万成员——ZSET 拆桶 topN 汇总 / 只保留 topN 全量+分位数近似）、隐私（榜单展示的用户信息脱敏配置）。
```javascript
// 实时榜（并列按时间）
await redis.zadd(`rank:${period}`, score * 1e8 - (1e9 - Date.now() % 1e8), uid);
// 归档：cron → ZREVRANGE 快照存档 → 新周期 DEL + 重建（先归档后清零）
```
