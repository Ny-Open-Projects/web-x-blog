## NODE-599：实验数据回流链路
**答**:
- 数据链路：分桶信息注入（所有日志/事件带实验维度 ARC-390）→ 数仓切片（按实验/桶聚合用户行为明细）→ 指标计算（核心指标/护栏指标——按桶对比）→ 显著性判定（统计引擎：t 检验/贝叶斯——样本量与功效 ARC-289）→ 结论输出。
- 指标体系：北极星指标（实验目标）、护栏指标（不许劣化：错误率/性能/资损类）、辅助指标（机制理解：中间行为）——指标从字典取（口径一致 ARC-614）。
- 实时性分层：实验监控实时（护栏分钟级——快速止损 ARC-446）、结论指标 T+1（完整数据——稳定性）、长期指标（留存类——实验延长观察期）。
- 数据质量：曝光定义（进入实验 = 曝光——曝光延迟（分桶后未渲染）的处理）、分桶-行为对齐（行为数据必须带桶——漏桶数据占比告警）、SRM 持续监控。
- 结论可信度：显著性报告自动生成（p 值/置信区间/样本量——非统计同学可读的呈现）、结论模板（胜出/持平/负向——各结论的标准动作 ARC-555）。
```javascript
// 回流管道
eventStream.pipe(tagExperiments).pipe(warehouseSink);            // 全事件带桶
evaluator.run(expId, {
  metrics: { north: 'conversion', guard: ['errorRate', 'latencyP99'] },
  significance: { method: 'ttest', alpha: 0.05, power: 0.8 },
  output: autoReport(expId)                                      // 结论报告
});
```
