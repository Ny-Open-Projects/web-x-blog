## NODE-527：多实例一致性监控
**答**:
- 问题：多实例本应行为一致，但漂移常见（不同实例配置版本不同——灰度配置未全覆盖、代码版本混合——滚动发布窗口、本地缓存内容不同——L1 各自失效节奏、JIT/内存差异——性能抖动）。
- 监控维度：版本分布（各实例代码版本——滚动发布进度与卡住检测 NODE-406）、配置版本分布（NODE-499 生效审计）、行为指标按实例分桶（P95/错误率按实例——某实例劣化 = 实例级问题而非全局）、缓存命中率按实例（命中差异大 = key 分布或预热不均 NODE-526）。
- 告警：实例级离群检测（某实例 P95 显著高于同伴——实例特有的问题：GC/局部网络/脏配置）、版本混合超时（发布卡住 30min 未完成——半新半旧运行风险）。
- 数据来源：实例标识进所有指标（pod name/instance id 维度——NODE-372 标签）、配置生效快照上报（NODE-499 审计数据）。
- 处置联动：离群实例自动隔离（摘流 → 排查 → 重建——单实例故障的自动处置）。
```javascript
// 实例离群检测
setInterval(() => {
  const byInst = metrics.byInstance('p95', window('5m'));
  const median = medianOf(byInst);
  for (const [inst, p95] of byInst)
    if (p95 > median * 2) isolate(inst);                         // 离群摘流 + 告警
}, 60e3);
```
