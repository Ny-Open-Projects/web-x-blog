## SCN-972：体检报告的解读服务与免责声明

**答**：
- 解读：AI 预解读（指标异常分类说明）+ 医生人工解读（付费服务）。
- 免责：AI 解读标注"仅供参考，不构成诊疗建议"，异常引导就医。
- 合规：解读内容不支持诊断结论（法规边界）。

```javascript
// 报告解读
function reportInterpret(lab, mode) {
  const abnormal = lab.items.filter(i => i.status !== 'normal');
  if (mode === 'ai')
    return { summary: abnormal.map(i => `${i.name} ${i.status}`),
      disclaimer: '本解读仅供参考，不构成诊疗建议，异常请咨询医生' };
  return { doctor: true, note: '人工解读由执业医师出具' };
}
// 异常引导：显著异常（deviation > 30%）-> 强引导就医
```
