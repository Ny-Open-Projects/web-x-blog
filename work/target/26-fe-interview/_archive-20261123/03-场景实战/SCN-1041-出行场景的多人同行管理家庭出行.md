## SCN-1041：出行场景的多人同行管理（家庭出行）

**答**：
- 管理：家庭组（成员管理/儿童标注），一人代全家购票（乘车人快捷选择）。
- 提醒：全家行程统一提醒（出发前集合时间/地点）。
- 座位：全家连座优先（1006）。

```javascript
// 家庭出行
async function familyBooking(familyId, schedule) {
  const members = await api('/family/members', { familyId });
  const passengers = members.map(m => m.passengerId);
  const seats = assignSeats(await remainSeats(schedule), passengers.length, {});
  return { passengers, seats,
    reminder: { time: schedule.departAt - 90 * 60_000,
      text: `集合：${schedule.from}，发车 ${schedule.departAt}` } };
}
```
