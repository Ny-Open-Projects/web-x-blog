## SCN-500：手写多端一致性测试框架：双端会话操作、状态断言、隔离用例集

**需求与边界**：
- 输入：两个端（用户 A/B）的会话驱动器、用例集；输出：一致性测试报告。
- 边界要求：① 双端并行操作（模拟真实并发）；② 状态断言（A 做完 B 能看到且值正确）；③ 隔离用例（A 写 B 查不能看到——隔离验证 AGT-493 复用）；④ 时序控制（操作间隔可控——确定性）。

**答**：
```javascript
class ConsistencyTest {
  constructor({ clientA, clientB }) {
    this.a = clientA; this.b = clientB;        // 双端驱动器
  }
  async run(cases) {
    const report = [];
    for (const c of cases) {
      // 用例：{ steps: [{who, op, expectOnOther}]
      //         , isolated: bool }
      for (const step of c.steps) {
        const client = step.who === 'A' ? this.a : this.b;
        await client.op(step.op);              // 端上操作
        await sleep(c.gap ?? 500);             // 同步窗口（确定性）
        if (step.expectOnOther) {
          const other = step.who === 'A' ? this.b : this.a;
          const state = await other.getState(step.target);
          report.push({ case: c.id, step: step.op,
            ok: assertEq(state, step.expectOnOther) });  // 断言
        }
      }
      if (c.isolated) {                        // 隔离用例
        await this.a.set('k1', 'secretA');
        const leak = await this.b.get('k1');
        report.push({ case: c.id,
          ok: leak !== 'secretA', type: 'isolation' });  // 隔离断言
      }
    }
    const failed = report.filter(r => !r.ok);
    return { report,
      pass: failed.length === 0,
      failed };                                // 失败明细
  }
}
// 用例示例：
// A 发消息 → B 500ms 内可见且 seq 正确（一致性）
// A 写缓存 k1 → B 查 k1 不可见（隔离性）
// 双端并发拖同一卡片 → 服务端定序一致（冲突）
```

**评分点**:
- 双端并行操作+同步窗口确定性（时序可控）。
- 三类断言：一致性/隔离性/冲突定序。
- 隔离用例（A 写 B 查不可见）显式建模。
- 失败明细报告（case/step/expect/actual 可定位）。
