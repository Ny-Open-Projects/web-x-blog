## SCN-371：在线问卷系统（设计器/逻辑跳题/分发回收）怎么实现？

**答**:
- 问卷设计器：题型注册表（单选/多选/填空/矩阵/评分/上传——SCN-246 表单引擎复用扩展），问卷 schema（题目列表+逻辑规则），编辑交互（拖拽排序/题目复制/批量编辑——SCN-242 画布复用）。
- 逻辑跳题：跳题规则（选 A 跳到 Q5——条件路由：选项→目标题），显隐逻辑（某题显示条件：前题答案=xx），必答与验证（分页校验），逻辑环检测（跳题形成环——设计器校验）。
- 分发与回收：分发渠道（链接/二维码/嵌入——渠道参数溯源：渠道来源统计）、回答限制（每人一次/微信授权答题/匿名——身份策略）、回收数据（实时统计看板：SCN-257 图表联动复用）。
- 防刷与质量：答题时长检测（过快提交标记——无效卷过滤）、机器人防护（验证码/行为采集）、开放题审核（SCN-326 审核复用）。

```javascript
// 跳题逻辑
const survey = {
  questions: [...],
  logic: [{ when: 'q1 == A', goto: 'q5' },
    { show: 'q3', if: 'q2 includes B' }],
};
// 运行时：nextQuestion(cur, answers) →
//   匹配 logic → 跳转/显隐 → 环检测在设计器完成。
// 渠道：/s/abc?ch=wechat → 归因渠道统计
// 限制：once per openid（授权态）或 device。
// 统计：stats realtime → 联动图表（SCN-257）。
// 质量标记：duration < n*2s → suspicious。
```
