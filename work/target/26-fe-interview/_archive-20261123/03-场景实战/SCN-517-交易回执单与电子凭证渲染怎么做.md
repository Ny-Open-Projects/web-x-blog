## SCN-517：交易回执单/电子凭证怎么设计？
**答**：
- 数据单源：凭证内容全部由服务端按流水号渲染（返回结构化数据或直接返回凭证快照），前端只负责展示，禁止本地拼装业务字段——防止改参数生成假凭证。
- 防篡改标识：凭证带防伪要素（流水号 + 校验码/二维码，扫码到官方验真页），前端渲染二维码与「验真」入口。
- 保存渠道：截图引导（网页端）、生成图片（Canvas 绘制 + 水印）、PDF 下载（服务端生成，前端不自己排 PDF 以保证法律效力）。
- 分享安全：分享图片自动脱敏可选（隐藏卡号/姓名部分字段），转发链接带时效。
- 追问钩子：为什么 PDF 用服务端出——盖章/电子签与文件哈希都在服务端完成，前端产物无法律效力。

```javascript
async function downloadReceipt(flowId) {
  const { url, checksum } = await api.get(`/receipt/${flowId}/pdf`);
  const blob = await fetch(url).then(r => r.blob());
  if (await sha256Hex(blob) !== checksum) return toast('文件校验失败，请重试'); // 完整性校验
  saveBlob(blob, `回执_${flowId}.pdf`);
}
```
