## SCN-910：政务材料上传的合规校验（格式/大小/内容预检）

**答**：
- 前端校验：格式白名单（jpg/pdf）、大小限制（10MB）、页数检测（pdf）。
- 预检：OCR 识别关键信息（姓名/证号）与申请人比对，不匹配即时提示（减少退件）。
- 体验：拍照直传（移动端调相机）、多材料批量上传 + 逐个进度。

```javascript
// 材料预检
async function precheckMaterial(file, applicant, spec) {
  if (!spec.formats.includes(file.type)) return { ok: false, reason: '格式不支持' };
  if (file.size > spec.maxBytes) return { ok: false, reason: '超过大小限制' };
  if (spec.ocrCheck) {
    const ocr = await ocrExtract(file);
    if (ocr.name !== applicant.name)
      return { ok: false, reason: `材料姓名(${ocr.name})与申请人不符`,
        action: 're-upload' };
  }
  return { ok: true };
}
```
