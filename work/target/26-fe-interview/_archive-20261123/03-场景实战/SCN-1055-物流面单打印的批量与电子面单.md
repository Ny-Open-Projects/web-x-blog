## SCN-1055：物流面单打印的批量与电子面单

**答**：
- 电子面单：平台下单取号（运单号生成）→ 面单渲染（热敏打印模板）→ 批量打印。
- 前端：打印队列（失败重打）、面单模板配置（网点 logo/自定义区）。
- 体积：单页面单渲染（避免千单一次渲染卡死），分批 100 单一批。

```javascript
// 面单批量打印
async function printWaybills(orders) {
  const batches = chunk(orders, 100);
  for (const b of batches) {
    const labels = await Promise.all(b.map(o => renderLabel(o)));   // 取号+渲染
    await printQueue(labels);
  }
}
function chunk(arr, n) { const out = []; for (let i = 0; i < arr.length; i += n) out.push(arr.slice(i, i + n)); return out; }
function renderLabel(o) { return api('/waybill/label', o); }
function printQueue(labels) { return true; }
```
