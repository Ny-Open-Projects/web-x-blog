## SCN-824：联想缓存一致性怎么设计？
**答**：
- 缓存层级与 TTL：CDN 边缘（非个性化热门联想，TTL 5min）→ 服务端前缀缓存（TTL 1min）→ 前端 LRU（30s）——层级越靠近用户 TTL 越短，容忍度越低。
- 主动失效：热词大更新/屏蔽词变更触发主动失效（CDN purge + 缓存版本号 bump）；商品下架等长尾变更靠 TTL 自然过期（不值得主动失效的成本）。
- 版本号协商：前端缓存带版本号，服务端版本不一致全量失效——避免「屏蔽词在前端缓存里又活了 30 秒」的风控事故。
- 一致性分级：屏蔽词类（安全）要求秒级失效走主动通道；排序调整类（体验）TTL 过期即可。
- 追问钩子：为什么失效要分级——主动失效（CDN purge/广播）成本高，只给安全级变更用；体验级变更用短 TTL 自然过期，成本收益平衡。

```javascript
const cacheStrategy = {
  layers: { cdn: { ttl: 300_000 }, server: { ttl: 60_000 }, client: { ttl: 30_000 } },
  invalidation: {
    safety: 'active purge (block words) + version bump',   // 秒级
    experience: 'ttl-expire',                              // 自然过期
  },
  versionCheck: (clientVer, serverVer) => clientVer !== serverVer && clearClientCache(),
};
```
