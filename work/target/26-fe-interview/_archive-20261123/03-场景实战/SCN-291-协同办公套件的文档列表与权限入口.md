## SCN-291：协同办公套件的文档列表（搜索/协作状态/权限入口）怎么设计？

**答**:
- 列表信息密度：文档条目（标题/所有者/最后编辑时间/协作状态：几人正在编辑/权限标识），协作状态实时更新（awareness 推送——SCN-232 复用，列表页显示"3 人在编辑"）。
- 搜索体系：全文搜索（标题+内容检索——服务端索引）、筛选维度（我创建的/最近协作/共享给我的）、搜索结果跳转（命中片段高亮+定位到文档内位置——深度链接 schema）。
- 权限与分享入口：列表项快捷分享（权限设置面板：SCN-225 模型复用）、外链状态标识（公开链接提示）、转交所有权。
- 性能与组织：虚拟列表（大量文档）、分组/置顶/回收站、批量操作（批量移动/删除——确认与进度）。

```javascript
// 协作状态实时
awareness.remote.on('presence', ({ docId, users }) =>
  listStore.patch(docId, { collaborators: users.length }));
// 搜索定位：searchApi.query(q) → hits
//   [{docId, snippet, position}] → 跳转
//   `/doc/${docId}?hl=${position}`
//   → 文档内定位并高亮片段。
// 批量：selected → move/trash → confirm + progress
// 外链标识：doc.publicLink → 🌐 图标。
```
