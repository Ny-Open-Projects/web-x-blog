## SCN-980：医疗问诊中的紧急情况识别与转诊

**答**：
- 识别：主诉关键词（胸痛/呼吸困难/大出血）触发紧急提示。
- 动作：终止线上问诊 -> 引导急诊（最近急诊地图/120）。
- 记录：紧急转诊留痕（医生端同步知情）。

```javascript
// 紧急转诊
const EMERGENCY_KEYWORDS = ['胸痛', '呼吸困难', '大出血', '意识不清'];
function emergencyCheck(chiefComplaint) {
  const hit = EMERGENCY_KEYWORDS.find(k => chiefComplaint.includes(k));
  if (!hit) return { emergency: false };
  return { emergency: true, keyword: hit,
    action: { guide: 'nearest-emergency', terminate: true },
    note: '线上问诊终止，引导线下急救' };
}
```
