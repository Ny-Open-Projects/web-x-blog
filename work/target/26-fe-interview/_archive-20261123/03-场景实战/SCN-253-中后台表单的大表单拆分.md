## SCN-253：中后台超长表单（几十字段/多分组/跨页步骤）怎么组织？

**答**:
- 结构组织：分组建表（按业务域分组折叠，只展开编辑组）、分步向导（强顺序流程：步骤间校验+可回退，进度指示）、抽屉/弹窗分层（主表单+子资源编辑抽屉）——按业务复杂度选形态。
- 状态管理：表单状态树（字段级 value/error/touched）、联动声明式（schema deps，SCN-246 复用）、草稿自动保存（本地+服务端，防误关丢失——中后台大表单填半小时丢了是事故）。
- 校验体系：即时校验（blur）、分组校验（展开组时校验该组）、提交全量校验（错误定位滚动到首个错误字段）、服务端校验回显（错误码→字段映射）。
- 性能：字段组件懒挂载（折叠组不渲染）、大字段懒加载（富文本/上传组件按需）、联动最小更新（依赖图拓扑更新）。

const form = useFormEngine(schema, {
  groups: ['basic', 'detail', 'advanced'],
  draft: { local: true, server: true, interval: 30e3 },
});
