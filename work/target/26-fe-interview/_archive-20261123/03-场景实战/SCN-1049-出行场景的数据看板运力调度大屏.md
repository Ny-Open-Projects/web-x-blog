## SCN-1049：出行场景的数据看板（运力调度大屏）

**答**：
- 指标：实时供需热力（区域呼叫量 vs 运力）、应答率/完单率、司机在线数。
- 调度：热力区域补贴提示（调度费调整）、运力引导（司机端气泡）。
- 刷新：地图热力 30s 更新，指标 1 分钟。

```javascript
// 运力热力
function supplyHeatMap(gridData, drivers) {
  return gridData.map(g => ({
    region: g.region, calls: g.calls,
    supply: drivers.filter(d => inRegion(d, g.region)).length,
    gap: g.calls - drivers.filter(d => inRegion(d, g.region)).length,
    suggest: g.calls > supply2(g) * 2 ? '调费引导运力' : null,
  }));
}
function supply2(g) { return 0; }
function inRegion(d, region) { return false; }
```
