## SCN-408：手写动态高度虚拟列表：估算+实测修正、锚定滚动不跳

**需求与边界**：
- 输入：数据数组、行渲染器（高度不定）；输出：虚拟列表组件逻辑。
- 边界要求：① 未知高度先估算渲染，实测后修正偏移表；② 修正不导致滚动跳动（锚定补偿）；③ 快速滚动白屏兜底（估算渲染+渲染中占位）；④ 二分查找定位可视首行。

**答**：
```javascript
class VirtualList {
  constructor({ items, estHeight = 60, viewport, onRender }) {
    this.items = items;
    this.offsets = items.map((_, i) => i * estHeight); // 前缀和
    this.measured = new Map();                 // 实测高度
    this.viewport = viewport; this.onRender = onRender;
    this.anchor = null;
    viewport.onscroll = () => this.render();
  }
  locate(scrollTop) {                          // 二分定位
    let lo = 0, hi = this.items.length - 1;
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      this.offsets[mid] < scrollTop ? lo = mid + 1 : hi = mid;
    }
    return lo;
  }
  render() {
    const start = Math.max(0, this.locate(this.viewport.scrollTop) - 3);
    const end = Math.min(this.items.length,
      this.locate(this.viewport.scrollTop + this.viewport.height) + 3);
    const els = this.onRender(start, end,
      (i, h) => this.measure(i, h));           // 渲染+实测回调
  }
  measure(i, h) {                              // 实测修正
    if (this.measured.get(i) === h) return;
    const prev = this.offsets[i + 1] - this.offsets[i];
    const diff = h - prev;
    this.measured.set(i, h);
    for (let j = i + 1; j <= this.items.length; j++)
      this.offsets[j] += diff;                 // 后缀偏移修正
    // 锚定补偿：修正发生在视口上方 → 补偿 scrollTop 防跳
    if (this.viewport.scrollTop > this.offsets[i])
      this.viewport.scrollTop += diff;
  }
}
```

**评分点**:
- 前缀和偏移表 + 二分定位（O(logn)）实现正确。
- 估算渲染+实测修正双阶段；修正带视口上方 scrollTop 锚定补偿（不跳）。
- 上下 buffer 3 行缓解快速滚动白屏。
- measured 去重（同高度不重复修正）。
