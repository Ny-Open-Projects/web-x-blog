## SCN-327：评论区（盖楼嵌套/热评排序/楼中楼展开）的完整实现？

**答**:
- 数据模型：两层扁平化（评论+回复两组数据，回复带 parent 引用——避免深嵌套的渲染与同步复杂度），盖楼展示（同话题串联楼中楼："查看 X 条回复"展开懒加载）。
- 排序体系：热评排序（点赞数+回复数加权+时间衰减——服务端算），时间序切换（最新/最热 tab）、作者置顶与官方回复标识。
- 渲染性能：SCN-216 洪峰渲染复用（虚拟列表/长评折叠：超长评论"展开全文"）、图片懒加载、楼中楼展开的局部渲染（展开只渲染该楼回复）。
- 互动细节：回复引用（回复某人显示@层级——扁平化的回复目标清晰化）、点赞热评上浮动画、评论区表情包/图片评论（审核联动 SCN-326）、举报入口（评论级举报）。

```javascript
// 两层扁平化
const comments = [{ id, author, content, likes, replies: n }];
function CommentItem({ c }) {
  return <>
    <CommentBody {...c} />
    {c.replies > 0 && <ExpandReplies cid={c.id}
      onExpand={() => lazyLoadReplies(c.id)} />}   // 楼中楼懒加载
  </>;
}
// 排序：sort = likes * decay(now - ts)（服务端算好下发）
// 长评：len > 300 → 折叠 + 展开全文
// 引用：回复带 replyToAuthor → '@张三：' 前缀清晰化。
```
