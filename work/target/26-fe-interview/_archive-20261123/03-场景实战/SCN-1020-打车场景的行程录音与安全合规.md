## SCN-1020：打车场景的行程录音与安全合规

**答**：
- 合规：行程录音告知（一键开启声明）、录音数据加密留存（纠纷举证）。
- 前端：录音状态图标（车内屏+乘客端）、紧急联系人行程自动分享。
- 隐私：录音仅纠纷调取（无场景不查看），留存期自动删除。

```javascript
// 行程录音
function rideRecorder(consent) {
  if (!consent) return { enabled: false, note: '未开启录音' };
  return { enabled: true,
    retentionDays: 7,                                  // 自动删除
    access: 'dispute-only',                            // 仅纠纷调取
    shareToContacts: true,                             // 行程自动分享
  };
}
```
