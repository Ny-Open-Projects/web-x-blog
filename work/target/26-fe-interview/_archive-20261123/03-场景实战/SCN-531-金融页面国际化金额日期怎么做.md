## SCN-531：金融页面国际化怎么做？
**答**：
- 金额本地化：Intl.NumberFormat 处理千分位/小数位/币种符号位置（如 € 在后）；阿拉伯语 RTL 下金额数字仍保持 LTR 嵌入。
- 日期与时区：服务端统一存 UTC + 业务时区，展示按用户时区；「账期」「交易日」是业务日期（无时间），与时间戳展示分开处理，避免跨时区偏移一天。
- 复数与文案：金额类文案（如「3 笔交易」）用 ICU MessageFormat 复数规则，禁止字符串拼接「1 笔s」。
- 布局弹性：德语长文案、俄语长词导致按钮溢出——文案驱动布局测试（伪本地化 pseudolocale 检查溢出）。
- 追问钩子：为什么金额不用 toLocaleString 现场算——不同浏览器 ICU 版本输出不一致，关键页用服务端下发格式规则或锁定 Intl polyfill。

```javascript
const money = (fen, { currency = 'CNY', locale = 'zh-CN' } = {}) =>
  new Intl.NumberFormat(locale, { style: 'currency', currency, currencyDisplay: 'narrowSymbol' })
    .format(fen / 100);
const bizDate = (ymd, tz) => Intl.DateTimeFormat('zh-CN', { timeZone: tz, dateStyle: 'medium' }).format(new Date(ymd + 'T00:00:00Z')); // 业务日期不做时区换算
// ICU 复数：
// en: {count, plural, one {# transaction} other {# transactions}}
```
