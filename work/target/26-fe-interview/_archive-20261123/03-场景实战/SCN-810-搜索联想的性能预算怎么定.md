## SCN-810：联想性能预算怎么定？
**答**：
- 全链预算 250ms：按键 → 请求发出（防抖后 150ms 内）→ 网络往返 ≤ 60ms → 渲染 ≤ 30ms；超过 300ms 用户感知「跟手性差」。
- 渲染预算：下拉列表 ≤ 10 条、虚拟滚动（超过 30 条历史）、DOM 复用（diff 更新不重建）。
- 首字符策略：首个字符请求「热门补全」（预计算缓存，P99 < 50ms），后续字符走完整链路。
- 监控口径：input-to-suggest-latency（输入到下拉出现）作为核心指标，P95 预算 250ms，超预算按段拆解归因（防抖/网络/渲染）。
- 追问钩子：为什么防抖 150ms 而不是 50ms——50ms 会在打字中间发大量请求（成本+噪声），150ms 已低于人类连续击键间隔感知阈值；同时配合「前缀收敛」让等待不空白。

```javascript
const PERF_BUDGET = {
  total: 250, debounce: 150, network: 60, render: 30,
  breakdown: (measured) => {
    const stage = measured.total > 300 ? slowestStage(measured) : null;
    if (stage) report({ type: 'SUG_SLOW', stage, ...measured });   // 分段归因
  },
};
```
