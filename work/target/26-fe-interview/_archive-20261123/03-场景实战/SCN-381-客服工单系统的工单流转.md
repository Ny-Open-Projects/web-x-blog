## SCN-381：客服工单系统（创建/流转/SLA/协作）怎么实现？

**答**:
- 工单状态机：创建→分配→处理中→待客户→已解决→关闭（重开回路），状态驱动 UI（SCN-282 状态机复用），流转动作（分配/转派/升级/合并工单/挂起——挂起原因必选）。
- SLA 管理：SLA 倒计时（响应 SLA/解决 SLA——按优先级不同 SLA），倒计时呈现与预警（临近超时变色+提醒——SCN-349 提醒复用）、超时升级（自动升级到上级/主管看板）。
- 协作处理：内部协作（工单内内部备注（客户不可见）vs 对客户回复——双通道呈现）、跨部门转派（转派带上下文——SCN-219 衔接复用）、知识库辅助（处理中推荐相关 SOP——AGT-310 检索复用）。
- 客户侧视图：工单进度自助查询（进度时间线——SCN-282 复用）、补充信息请求（客服请求补充材料→客户上传）、满意度评价（解决后触发）。

```javascript
function TicketView({ t, role }) {
  const sla = slaTimer(t, { respond: 30e3, solve: 24h });
  return <>
    <TicketTimeline t={t} />              {/* 状态机时间线 */}
    <SlaBadge {...sla} warn={sla.left < 20e3} />  {/* 预警变色 */}
    {role === 'agent' && <>
      <ReplyChannel customer />           {/* 对客户 */}
      <InternalNote />                    {/* 内部备注通道 */}
      <Suggest kb={searchKB(t.title)} />  {/* SOP 推荐 */}
    </>}
  </>;
}
// 超时：sla.expired → escalate(auto) → 主管看板。
// 合并：merge(t1, t2) → 主从关系+通知双方上下文。
```
