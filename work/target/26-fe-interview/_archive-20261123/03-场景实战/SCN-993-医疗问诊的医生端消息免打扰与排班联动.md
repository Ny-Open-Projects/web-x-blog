## SCN-993：医疗问诊的医生端消息免打扰与排班联动

**答**：
- 联动：医生出诊/手术时段自动免打扰（患者消息转同事或排队）。
- 值班：值班医生接收转诊消息（分诊规则）。
- 体验：免打扰期间患者提示预计回复时间。

```javascript
// 排班联动
function doctorAvailability(doctor, schedule) {
  const busy = schedule.some(s => s.type === 'surgery' &&
    inRange(now(), s.start, s.end));
  return busy
    ? { available: false, delegate: doctor.delegateId,     // 转同事
        patientNote: '医生手术中，消息已转交值班医生' }
    : { available: true };
}
```
