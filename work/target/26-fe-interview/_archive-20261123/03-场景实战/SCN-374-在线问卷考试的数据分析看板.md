## SCN-374：问卷/考试的数据分析看板（回收/分布/交叉分析）怎么实现？

**答**:
- 回收看板：回收进度（实时回收数/渠道分布——SCN-257 联动复用）、完成率漏斗（开始→完成各题流失——哪题流失多）、时长分布。
- 题目分析：单题统计（选项分布/均分——图表化）、交叉分析（按维度交叉：部门×满意度——交叉表+卡方可视化）、开放题聚合（词云/主题聚类——AGT-353 归因复用）。
- 导出与深钻：明细导出（SCN-255 异步导出复用）、交叉自定义（用户自选维度交叉）、数据钻取（统计图表→明细行下钻）。
- 实时性：大样本实时聚合（服务端聚合+增量推送——万人答题的统计实时性）、看板性能（聚合数据缓存+变更推送）。

```javascript
function SurveyDashboard({ id }) {
  const stats = useLiveStats(id);            // 服务端聚合推送
  return <>
    <Funnel steps={stats.funnel} />          // 完成漏斗
    <QuestionCharts per={stats.perQ} />      {/* 单题分布 */}
    <CrossTable dims={pick(['dept','score'])}
      onData={(cell) => drill(cell)} />      {/* 交叉+下钻 */}
    <ExportAsync filters={current} />        {/* 异步导出 */}
  </>;
}
// 聚合：服务端按题聚合 → ws 推增量（大样本实时）
// 开放题：clusterAnswers(openQ) → 词云/主题。
```
