## SCN-945：政务大厅的办事指南视频引导（短视频教程）

**答**：
- 内容：复杂事项配 1~2 分钟操作视频（步骤演示）。
- 实现：视频懒加载（点击播放才拉）、关键步骤字幕、倍速。
- 度量：视频完播率与办事转化关联（内容效果度量）。

```javascript
// 教程视频
function guideVideo(item) {
  return {
    lazy: true,                                       // 点击才加载
    preload: 'metadata',
    captions: true,                                   // 字幕
    playbackRate: [0.5, 1, 1.5, 2],
    track: { play: 'guide-video-play', complete: 'guide-video-complete',
      item: item.id },
  };
}
```
