## SCN-961：医保结算页面的费用明细分解

**答**：
- 明细：总费用 = 自费 + 医保统筹 + 个人账户 + 大病二次报销——分解条目可视化。
- 校验：结算前医保资格校验（参保地/待遇状态）。
- 体验：明细可展开（药品/项目级），报销比例一目了然。

```javascript
// 费用分解
function settleBreakdown(bill) {
  return {
    total: bill.total,
    items: [
      { label: '医保统筹', amount: bill.fund, color: 'blue' },
      { label: '个人账户', amount: bill.account, color: 'green' },
      { label: '自费', amount: bill.self, color: 'orange' },
    ].filter(i => i.amount > 0),
    ratio: +(bill.fund / bill.total * 100).toFixed(1) + '%',   // 报销比例
  };
}
// 明细展开：drillDown(bill.items) 按药品/检查分组
```
