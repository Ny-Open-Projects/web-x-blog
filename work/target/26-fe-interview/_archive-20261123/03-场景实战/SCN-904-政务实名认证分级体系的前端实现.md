## SCN-904：政务实名认证分级体系的前端实现

**答**：
- 分级：L0 匿名（浏览）→ L1 手机号验证 → L2 实名（身份证+姓名）→ L3 刷脸/数字证书（强实名）。
- 按需升级：办事事项要求等级，未达标时引导升级（流程中断点友好化）。
- 前端：认证 SDK 封装（活体检测 H5），认证结果缓存（会话级），防重复认证。

```javascript
// 认证分级守卫
const AUTH_LEVELS = { L0: 0, L1: 1, L2: 2, L3: 3 };
async function guardAuth(item, user) {
  const need = AUTH_LEVELS[item.authLevel];
  if (AUTH_LEVELS[user.level] >= need) return { ok: true };
  const r = await upgradeAuth(need);                 // 引导升级流程
  if (!r.ok) return { ok: false, reason: '未完成实名认证',
    action: 'guide', level: need };
  user.level = need;
  return { ok: true };
}
// upgradeAuth：L2 走身份证 OCR+公安校验，L3 走活体 SDK
```
