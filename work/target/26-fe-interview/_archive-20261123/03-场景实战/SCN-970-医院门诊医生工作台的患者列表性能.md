## SCN-970：医院门诊医生工作台的患者列表性能

**答**：
- 列表：当日患者（分诊队列）实时更新 + 病历摘要预加载（当前患者前 3 个）。
- 性能：患者卡片轻量渲染，详情点击才拉全量病历。
- 隐私：工作台离开锁屏（医生离开自动锁定）。

```javascript
// 医生工作台
function doctorWorkbench(patients) {
  return {
    queue: patients.map(p => ({ id: p.id, name: mask(p.name), no: p.queueNo })),
    prefetch: patients.slice(0, 3).map(p => prefetchRecord(p.id)),   // 预取
    idleLock: idleTimer(120_000, () => lockScreen()),   // 2 分钟无操作锁屏
  };
}
```
