## SCN-1023：出行订单的发票管理与电子行程单

**答**：
- 发票：多订单合并开票（行程单/增值税电子票），抬头管理。
- 状态：开票进度/红冲重开（错误发票冲红）。
- 导出：报销用行程单 PDF（带电子章）。

```javascript
// 合并开票
async function invoiceBatch(tripIds, title) {
  const r = await api('/invoice/batch', { tripIds, title });
  return { applyNo: r.applyNo, eta: '24 小时内开票',
    track: () => pollInvoice(r.applyNo),               // 进度追踪
    red: (applyNo) => api('/invoice/red', { applyNo, reason: '信息错误' }),   // 红冲
  };
}
```
