## SCN-406：手写弹幕渲染：固定轨道对象池、洪峰采样、动画循环

**需求与边界**：
- 输入：弹幕消息流（洪峰可达千条/秒）、轨道数；输出：滚动弹幕渲染。
- 边界要求：① DOM 对象池复用（不频繁创建销毁）；② 轨道选择（选最空轨道，避免重叠）；③ 洪峰采样（超阈值丢弃普通弹幕，礼物不可丢）；④ 暂停/恢复（页面隐藏暂停动画）。

**答**：
```javascript
class DanmakuPool {
  constructor({ lanes = 10, perLane = 3, maxRate = 300 }) {
    this.lanes = Array.from({ length: lanes },
      () => ({ items: [], speed: 80 }));       // px/s
    this.pool = [];                            // 空闲 DOM 池
    this.maxRate = maxRate; this.dropped = 0;
    this.tick();
  }
  push(d) {
    if (d.kind === 'gift') return this.spawn(d, this.leastBusyLane());
    this.rate++;                               // 普通弹幕限流
    if (this.rate > this.maxRate / 1000) {
      this.dropped++; return;                  // 洪峰采样丢弃
    }
    this.spawn(d, this.leastBusyLane());
  }
  leastBusyLane() {                            // 最空轨道
    return this.lanes.reduce((a, b) =>
      a.items.length < b.items.length ? a : b);
  }
  spawn(d, lane) {
    const el = this.pool.pop() ?? createEl();  // 池复用
    el.textContent = d.text; lane.el.appendChild(el);
    lane.items.push({ el, x: laneWidth });
  }
  tick() {                                     // 动画循环
    requestAnimationFrame(() => {
      for (const lane of this.lanes) {
        lane.items = lane.items.filter(it => {
          it.x -= lane.speed; it.el.style.transform =
            `translateX(${it.x}px)`;
          if (it.x + it.el.offsetWidth < 0) {
            it.el.remove(); this.pool.push(it.el);
            return false;                      // 出屏回池
          }
          return true;
        });
      }
      this.tick();
    });
  }
  pause() { /* rAF 停止 */ } resume() { this.tick(); }
}
```

**评分点**:
- 对象池复用（出屏回池）避免高频 DOM 创建销毁。
- 最空轨道分配防重叠；礼物消息独立高优通道不采样。
- 洪峰限流（普通弹幕采样，dropped 计数可观测）。
- rAF 单循环 + 页面隐藏暂停恢复。
