## SCN-1096：物流运单的运力调配（车辆调度大屏）

**答**：
- 调度：干线车辆排班（线路/载重/在途），空载率优化（去程配货）。
- 展示：车辆地图（在途/空载/装载中）+ 排班甘特。
- 告警：超时未到车辆告警（1078 缺口联动）。

```javascript
// 车辆调度
function fleetBoard(vehicles, schedules) {
  return {
    map: vehicles.map(v => ({ id: v.id, state: v.state,   // onroad/empty/loading
      pos: v.lastPos })),
    gantt: schedules.map(s => ({ vehicle: s.vehicleId,
      from: s.startAt, to: s.endAt, line: s.line })),
    emptyRate: +(vehicles.filter(v => v.state === 'empty').length / vehicles.length * 100).toFixed(1) + '%',
  };
}
```
