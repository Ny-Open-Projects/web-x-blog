## SCN-814：联想安全过滤怎么设计？
**答**：
- 过滤链路：入库前过滤（热词爬取源先过滤）→ 实时过滤（用户输入命中敏感词直接不请求/返回空）→ 展示兜底（前端敏感词标记的词折叠）。
- 输入侧风控：用户输入本身含违规意图（测审核漏洞的输入）——风控返回「无结果 + 平静呈现」（不提示违规，防对抗探测）。
- 组合风险：单词安全但组合违规（分词绕过）——服务端组合检测，前端不做（拿不到全库规则）。
- 热词时效安全：热点事件联想词需要人工/风控双审后放行（热点期敏感词风险最高）。
- 追问钩子：为什么违规输入要「平静返回空」而不是提示违规——提示违规等于告诉探测者「这里有个雷」，帮黑产定位边界；安全体验默认沉默。

```javascript
const safeFilter = {
  input: (q) => riskCheck(q).safe ? requestSuggest(q) : renderEmpty(),  // 平静返回
  display: (item) => item.flagged ? foldItem(item) : item,              // 标记词折叠
  hotword: { gate: 'manual+risk-review', note: '热点期双审放行' },
};
```
