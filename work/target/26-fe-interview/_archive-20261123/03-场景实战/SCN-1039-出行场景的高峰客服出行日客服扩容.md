## SCN-1039：出行场景的高峰客服（出行日客服扩容）

**答**：
- 高峰：春运/节假日客服排队暴增——自助优先（常见问题卡片）+ 排队透明（位置/预计时长）。
- 分流：AI 客服先答（改签/退票规则），人工兜底。
- 体验：排队可挂断回电（承诺时限）。

```javascript
// 高峰客服
function peakHotline(peak) {
  return {
    aiFirst: true,                                     // AI 先答
    selfService: faqCards(['改签规则', '退款时效', '候补说明']),
    queue: { position: true, eta: true, callback: true },   // 可回电
    note: peak ? '高峰期预计等待较长，建议使用自助服务' : null,
  };
}
function faqCards(topics) { return topics; }
```
