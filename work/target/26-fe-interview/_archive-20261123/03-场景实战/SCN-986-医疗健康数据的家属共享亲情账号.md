## SCN-986：医疗健康数据的家属共享（亲情账号）

**答**：
- 共享：主账号授权家属查看（范围：报告/处方/缴费，可选），有效期管理。
- 隐私：敏感报告（精神类/传染病）默认不共享（需单独授权）。
- 撤回：授权随时撤回，撤回即时生效。

```javascript
// 亲情共享
function familyShare(owner, member, scope) {
  const allowed = scope.filter(s => !SENSITIVE_GROUPS.has(s));
  const denied = scope.filter(s => SENSITIVE_GROUPS.has(s));
  return { grant: { member: member.id, scope: allowed, expireAt: +90d },
    deniedNote: denied.length ? `${denied} 类需单独授权` : null };
}
```
