## SCN-1045：出行场景的行程冲突检测（时间重叠提醒）

**答**：
- 冲突：新购票与已有行程时间重叠（同日两段行程间隔 < 3h 且异地）提示冲突。
- 展示：冲突行程对比卡片（去留选择）。
- 容错：同城冲突（市内通勤）不提示。

```javascript
// 行程冲突
function tripConflict(newTrip, existing) {
  const overlap = existing.filter(t =>
    Math.abs(t.departAt - newTrip.departAt) < 3 * 3600_000 &&
    t.toCity !== newTrip.fromCity);
  if (!overlap.length) return { conflict: false };
  return { conflict: true,
    with: overlap.map(t => ({ no: t.no, departAt: t.departAt })),
    advice: '两段行程时间冲突，请确认是否为联程' };
}
```
