## SCN-935：政务大厅的评价数据看板（差评归因）

**答**：
- 指标：好评率趋势、差评 Top 原因（标签聚合）、部门/事项维度下钻。
- 归因：差评标签 + 文本聚类（关键词提取）辅助定位服务短板。
- 闭环：看板直接生成整改任务派发部门。

```javascript
// 差评归因
function badRatingAnalysis(ratings) {
  const tagCount = {};
  ratings.filter(r => r.stars <= 2).forEach(r =>
    r.tags.forEach(t => tagCount[t] = (tagCount[t] ?? 0) + 1));
  const keywords = extractKeywords(ratings.map(r => r.comment));
  return { topTags: Object.entries(tagCount)
      .sort((a, b) => b[1] - a[1]).slice(0, 5),
    keywords, tasks: Object.entries(tagCount)
      .filter(([, c]) => c >= 5).map(([t]) => ({ action: `整改: ${t}` })) });
}
```
