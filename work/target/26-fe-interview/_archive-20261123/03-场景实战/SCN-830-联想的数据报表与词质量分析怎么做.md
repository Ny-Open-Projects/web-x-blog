## SCN-830：联想数据报表怎么做？
**答**：
- 词级报表：每词的曝光/采纳/点击/零结果转化（采纳后是否找到内容）——词质量四件套；低质量词清单自动产出（曝光高采纳低 = 干扰词）。
- 位置效应校正：CTR 按 rank 分层归一（同位置对比），否则头部词永远「赢」。
- 时效分析：热词生命周期（爆发-峰值-衰退）用于热词池轮换策略。
- 与业务联动：联想词 → 搜索 → 成交的全链漏斗（电商场景），量化联想对 GMV 的贡献。
- 追问钩子：为什么词质量不能只看 CTR——CTR 高可能是诱导性词（标题党联想）但采纳后搜索体验差；「采纳后零结果率/结果 CTR」才是真质量，CTR 只是入口指标。

```javascript
const wordQuality = {
  perWord: { expose, adopt, ctr, zeroAfterAdopt, resultCTR },
  rankNormalized: true,                                // 位置效应校正
  lifecycle: (hotword) => phaseOf(hotword.trend),      // 爆发/峰值/衰退
  action: (w) => w.expose > N && w.adopt < base && flagLowQuality(w),  // 自动产清单
};
```
