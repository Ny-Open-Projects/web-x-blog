## SCN-776：多语言内容审核怎么处理？
**答**：
- 语言路由：语言检测（机审附带）→ 按语言分发到对应技能组审核员；小语种审核员少时跨区排班或机翻辅助。
- 机翻辅助：小语种文字稿机翻成审核员语言双语对照展示——辅助不替代（机翻可能引入偏差，原文并列展示）。
- 跨语言风险信号：图文不匹配（配图与文字语义矛盾）是绕审常见手段，工作台同屏呈现多模态对照。
- 品类与语言矩阵排班：技能组 = 品类 × 语言，排班系统按矩阵缺口预警。
- 追问钩子：为什么机翻不能只显示译文——审核判定要依据原文语境（俚语/双关），纯译文可能误导判罚；双语对照 + 原文可查是合规底线。

```javascript
const languageRouting = {
  detect: (content) => content.language ?? langDetect(content),
  route: (lang) => teams.byLanguage(lang) ?? crossRegion(lang),
  assist: (content, reviewerLang) => ({
    original: content.text,
    translated: mt(content.text, reviewerLang),    // 双语对照
    disclaimer: '机翻仅供参考，判罚以原文为准',
  }),
};
```
