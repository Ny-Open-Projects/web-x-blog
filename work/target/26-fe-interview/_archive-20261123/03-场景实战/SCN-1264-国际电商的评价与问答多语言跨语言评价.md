## SCN-1264：国际电商的评价与问答多语言（跨语言评价展示）

**答**：
- 展示：各国评价混合展示（原文+机器翻译对照开关）， helpfulness 排序。
- 翻译：评价翻译懒加载（展开才翻），翻译质量标注。
- 合规：评价真实性（合规审查，禁刷单展示）。

```javascript
// 跨语言评价
function reviewDisplay(review, userLang) {
  if (review.lang === userLang) return { text: review.text, translated: false };
  return {
    original: review.text,
    translated: lazyTranslate(review.text, userLang),   // 展开才翻译
    machine: true,
  };
}
function lazyTranslate(t, l) { return api('/translate', { text: t, to: l }); }
```
