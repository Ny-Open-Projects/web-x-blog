## SCN-411：手写大文件分片上传：分片并发、断点续传、秒传、完整性校验

**需求与边界**：
- 输入：File、上传接口；输出：上传控制器（start/pause/resume/progress）。
- 边界要求：① 文件 hash 秒传（服务端已有直返）；② 分片并发受限（3 路）；③ 断点续传（已传分片跳过——本地+服务端已传清单）；④ 分片 MD5 校验失败重传该片；⑤ 暂停/恢复。

**答**：
```javascript
class ChunkUploader {
  constructor(file, { chunkSize = 5 * 1024 * 1024, concurrency = 3 }) {
    this.file = file;
    this.chunks = Math.ceil(file.size / chunkSize);
    this.chunkSize = chunkSize;
    this.concurrency = concurrency;
    this.done = new Set();
    this.paused = false;
    this.hash = null;
  }
  async start() {
    this.hash = this.hash ?? await md5OfFile(this.file); // 全量 hash（秒传）
    const exist = await api.check({ hash: this.hash });
    if (exist.uploaded) return { instant: true, url: exist.url };
    // 断点续传：服务端已传分片清单
    (exist.chunks ?? []).forEach(i => this.done.add(i));
    const pending = [...Array(this.chunks).keys()]
      .filter(i => !this.done.has(i));
    let idx = 0;
    const worker = async () => {               // 并发池
      while (idx < pending.length && !this.paused) {
        const i = pending[idx++];
        await this.uploadChunk(i);
      }
    };
    await Promise.all(Array.from({ length: this.concurrency }, worker));
    if (this.done.size === this.chunks) {
      const r = await api.merge({ hash: this.hash,
        total: this.chunks });
      return { url: r.url };
    }
  }
  async uploadChunk(i) {
    const blob = this.file.slice(i * this.chunkSize,
      (i + 1) * this.chunkSize);
    const md5 = await md5Of(blob);             // 分片校验
    const r = await api.chunk({ hash: this.hash, index: i,
      blob, md5 }).catch(() => ({ ok: false }));
    if (r.ok) this.done.add(i);                // 成功记账（断点续传）
    else this.retryQueue.push(i);              // 校验失败重传
    this.onProgress?.(this.done.size / this.chunks);
  }
  pause() { this.paused = true; }              // 暂停
  resume() { this.paused = false; this.start(); }
  progress() { return this.done.size / this.chunks; }
}
```

**评分点**:
- 秒传（全量 hash 服务端命中直返）+ 断点续传（服务端已传分片清单跳过）双优化。
- 并发池受限（worker 模式 3 路），分片 MD5 校验失败重传。
- pause/resume 状态可控，progress 按分片比例。
- merge 阶段以 hash 关联（服务端聚合分片）。
