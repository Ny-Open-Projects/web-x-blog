## SCN-795：手写举报优先级与滥用防护

**需求与边界**：
- 需求：举报优先级 = 基础分 + 举报人信誉分（历史准确率）× 权重 + 举报量聚合；同一内容多举报合并；恶意举报者（日超 N 条且准确率低）限流降权。
- 边界：① 信誉分 = 历史举报被采纳比例，样本 < 5 次给中性分 0.5；② 聚类：同内容 24h 内举报合并计数（不重复进审）；③ 限流命中返回明确原因码。

**答**：
```javascript
function reportPriority(report, { credWeight = 10, mergeWindow = 24 * 3600_000 } = {}) {
  const cred = report.history.length < 5 ? 0.5          // 样本不足中性分
    : report.history.filter(h => h.adopted).length / report.history.length;
  const dup = recentReports(report.contentId, mergeWindow);   // 同内容窗口内合并
  const clusterBonus = Math.min(5, dup.count);          // 聚合加成封顶
  const abuse = report.dailyCount > 20 && cred < 0.2;   // 恶意举报判定
  if (abuse) return { action: 'RATE_LIMITED', code: 'ABUSE', retryAfter: 3600_000 };
  return {
    action: 'SUBMIT',
    priority: 50 + cred * credWeight + clusterBonus,
    merged: dup.count,                                  // 合并计数呈现
    contentId: report.contentId,
  };
}
```

**评分点**:
- 信誉分小样本中性兜底（<5 次不冤枉新用户）。
- 同内容窗口合并（重复举报不重复进审）+ 加成封顶。
- 恶意判定双条件（频次 + 低准确率）与明确原因码。
- 优先级公式参数化。
