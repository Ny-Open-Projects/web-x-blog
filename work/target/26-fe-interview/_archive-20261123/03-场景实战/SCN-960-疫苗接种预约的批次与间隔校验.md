## SCN-960：疫苗接种预约的批次与间隔校验

**答**：
- 规则：疫苗批次、剂次间隔（第 2 剂距第 1 剂 ≥ 21 天）前端预校验。
- 校验：接种史查询（对接免疫规划系统），不符合间隔禁选。
- 提示：接种后注意事项（留观 30 分钟倒计时）。

```javascript
// 剂次间隔校验
function doseIntervalCheck(history, vaccine) {
  const last = history.filter(h => h.vaccine === vaccine.name).pop();
  if (!last) return { ok: true };
  const gapDays = (Date.now() - last.date) / 86400_000;
  if (gapDays < vaccine.minIntervalDays)
    return { ok: false, reason: `需间隔 ${vaccine.minIntervalDays} 天（上次接种 ${last.date}）` };
  return { ok: true, doseNo: history.length + 1 };
}
// 留观倒计时：接种完成后 30 分钟倒计时 + 到点提醒离开
```
