## SCN-1259：国际电商的本地化营销（节日/大促日历）

**答**：
- 日历：各国营销日历（黑五/双 11/Prime Day/斋月）——活动配置按国家生效。
- 前端：活动氛围（主题皮肤按活动切换）、倒计时（时区正确）。
- 合规：促销价对比（原价划线规则按国家法规，如欧盟原价须为 30 天最低价）。

```javascript
// 促销合规
function promoPriceDisplay(current, lowest30d, country) {
  if (country in EU && current < lowest30d)
    return { strike: lowest30d,                       // 划线价须为 30 天最低
      legal: true, note: '欧盟 Omnibus 指令合规' };
  return { strike: lowest30d, legal: false,
    note: '该地区划线价规则不同，需法务确认' };
}
```
