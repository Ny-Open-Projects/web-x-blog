## SCN-783：审核埋点体系怎么设计？
**答**：
- 双线埋点：效率线（领取/播放/seek/标注/提交各步耗时）与质量线（揭露打码/音频开启/标注修改——还原审核行为供质检分析）。
- 行为还原：审核关键动作（揭露打码时刻/倍速使用/循环播放）全记录，质检争议时可回放审核过程（脱敏）。
- 工作台体验埋点：预取命中率/切换耗时/快捷键使用率——工作台自身的优化依据。
- 埋点分级：效率与行为线采样（10%），质量争议相关（申诉/质检样本）全量。
- 追问钩子：为什么「揭露打码」动作要埋点——该动作与审核质量强相关（看了打码内容的审核质量显著不同），是质检归因与防疲劳策略的输入。

```javascript
const reviewTracking = {
  efficiency: ['claim', 'firstPlay', 'seek', 'mark', 'submit'],   // 各步耗时
  behavior: ['revealBlur', 'unmute', 'clipLoop', 'speedChange'],  // 行为还原
  workbench: ['prefetchHit', 'switchCost', 'hotkeyUsage'],
  sampling: { efficiency: 0.1, behavior: 0.1, appealRelated: 1.0 },  // 分级采样
};
```
