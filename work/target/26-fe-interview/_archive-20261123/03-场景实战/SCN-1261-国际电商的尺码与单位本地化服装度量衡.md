## SCN-1261：国际电商的尺码与单位本地化（服装/度量衡）

**答**：
- 单位：长度/重量按地区（cm vs inch，kg vs lb），切换全局联动。
- 尺码：尺码表本地化（欧码/美码/日码对照），推荐尺码（身高体重输入）。
- 精度：单位换算精度（1 英寸 = 2.54cm）与四舍五入规则。

```javascript
// 尺码本地化
function sizeLocalize(sizeCm, unit) {
  return unit === 'inch' ? +(sizeCm / 2.54).toFixed(1) : sizeCm;
}
function sizeChart(region) {
  return { EU: 'EU 38', US: 'US 8', JP: 'JP 24' }[region] ?? 'EU 38';
}
// 推荐：身高体重 -> 推荐尺码（品牌尺码表映射）
```
