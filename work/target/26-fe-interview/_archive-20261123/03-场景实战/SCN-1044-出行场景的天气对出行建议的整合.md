## SCN-1044：出行场景的天气对出行建议的整合

**答**：
- 整合：目的地天气（出行日）影响建议（雨雪提醒提前出发/航班延误概率）。
- 展示：行程卡片天气标注 + 机场延误概率（历史统计）。
- 建议：恶劣天气改签建议（风险提示非强制）。

```javascript
// 天气出行建议
function weatherAdvice(trip, weather) {
  const bad = ['暴雨', '大雪', '台风'].some(w => weather.cond.includes(w));
  return {
    weather: `${weather.cond} ${weather.temp}°C`,
    advice: bad ? `目的地 ${weather.cond}，建议预留更多时间，关注航班动态` : null,
    delayRisk: airportDelayProb(weather),              // 历史延误概率
  };
}
function airportDelayProb(weather) { return 0.35; }
```
