## SCN-1076：物流仓储大屏（吞吐量/积压监控）

**答**：
- 指标：入库/出库吞吐（每小时）、积压订单量（超时效订单）、设备状态（分拣机）。
- 告警：积压超阈值告警（调度增员）、设备故障告警。
- 刷新：吞吐 1 分钟、设备状态 10s。

```javascript
// 仓储大屏
function warehouseBoard(metrics) {
  return {
    throughput: metrics.hourlyThroughput,
    backlog: metrics.backlogOrders,
    backlogAlert: metrics.backlogOrders > 500 ? '需增员' : null,
    devices: metrics.devices.map(d => ({ id: d.id,
      state: d.fault ? 'fault' : 'ok' })),
  };
}
```
