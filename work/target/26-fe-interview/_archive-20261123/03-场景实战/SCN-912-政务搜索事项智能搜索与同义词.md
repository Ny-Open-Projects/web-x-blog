## SCN-912：政务搜索：事项智能搜索与同义词

**答**：
- 挑战：口语化搜索（"办社保"vs"社会保险参保登记"）——同义词库 + 拼音/纠错。
- 实现：联想（热门事项）、结果高亮、无结果兜底（推荐相关事项）。
- 数据：搜索词埋点驱动同义词库迭代。

```javascript
// 事项搜索
function searchItems(query, items, synonyms) {
  const q = normalize(query);                        // 拼音/繁简/去空格
  const expanded = [q, ...(synonyms[q] ?? [])];
  return items.map(it => ({
    item: it, score: expanded.reduce((s, kw) =>
      s + (it.name.includes(kw) ? 2 : it.keywords?.some(k => k.includes(kw)) ? 1 : 0), 0),
  })).filter(r => r.score > 0)
    .sort((a, b) => b.score - a.score).slice(0, 10)
    .map(r => ({ ...r.item, hit: expanded.find(kw => r.item.name.includes(kw)) }));
}
```
