## SCN-1063：物流快递员端派件列表优化（路径排序）

**答**：
- 排序：派件按地址聚类排序（就近原则），用户预约时段优先。
- 交互：批量联系（电话/短信通知）、异常件快捷处理（拒收/无法联系）。
- 性能：列表懒加载（百件级分页），地图模式切换。

```javascript
// 派件排序
function deliverySort(parcels, courierPos) {
  return parcels.sort((a, b) =>
    haversineKm(courierPos, a.addr) - haversineKm(courierPos, b.addr));
}
function haversineKm(a, b) {
  const d = Math.PI / 180;
  return 6371 * Math.asin(Math.sqrt(
    Math.sin((b.lat - a.lat) * d / 2) ** 2 +
    Math.cos(a.lat * d) * Math.cos(b.lat * d) *
    Math.sin((b.lng - a.lng) * d / 2) ** 2));
}
```
