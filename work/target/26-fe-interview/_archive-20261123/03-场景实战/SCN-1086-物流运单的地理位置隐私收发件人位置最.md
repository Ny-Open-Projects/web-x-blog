## SCN-1086：物流运单的地理位置隐私（收发件人位置最小化）

**答**：
- 最小化：轨迹展示仅限相关方（商家看节点不看向户轨迹）。
- 脱敏：轨迹点聚合（精确位置不给商家）。
- 合规：位置数据留存期限（30 天自动删除）。

```javascript
// 位置隐私
function trackPrivacy(viewer, waybill) {
  if (viewer.role === 'merchant')
    return { nodes: waybill.nodes, raw: false,        // 不给原始轨迹
      note: '商家可见节点状态，不含实时轨迹' };
  if (viewer.role === 'receiver')
    return { courierTrack: waybill.delivering, ttl: 30 * 86400_000 };
  return { denied: true };
}
```
