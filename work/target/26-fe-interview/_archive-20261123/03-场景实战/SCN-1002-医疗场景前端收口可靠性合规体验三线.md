## SCN-1002：医疗场景前端收口（可靠性/合规/体验三线）

**答**：
- 可靠性：掉单对账（971）/危急值闭环（987）/系统隔离（1000）。
- 合规：敏感数据单独同意（999）/访问留痕（955）/证据保全（989）。
- 体验：适老化（908/963）/秒级叫号（959）/报告可视化（957）。

```javascript
// 医疗前端检查清单
const MED_CHECK = [
  { id: 'reconcile', test: s => s.payReconcileRate === 100 },
  { id: 'critical-loop', test: s => s.criticalCloseRate > 0.99 },
  { id: 'consent', test: s => s.sensitiveConsentRate === 100 },
  { id: 'elder-task', test: s => s.elderCompletion > 90 },
  { id: 'audit', test: s => s.accessAuditRate === 100 },
];
function medicalAudit(signals) {
  return MED_CHECK.filter(c => !c.test(signals)).map(c => c.id);
}
```
