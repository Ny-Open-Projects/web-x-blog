## SCN-1265：国际电商的库存与仓库网络展示（就近发货）

**答**：
- 展示：发货仓展示（从哪个仓发货）、预计送达（分仓时效），缺货替代仓切换。
- 策略：多仓库存分配（就近仓优先/拆单合并展示）。
- 透明：拆单提示（多个包裹分开发货，运费不重复收取说明）。

```javascript
// 分仓展示
function warehouseDisplay(item, addr) {
  const warehouses = item.stockByWh
    .filter(w => w.qty > 0)
    .sort((a, b) => etaDays(a, addr) - etaDays(b, addr));
  return {
    shipFrom: warehouses[0]?.name ?? '缺货',
    etaDays: warehouses[0] ? etaDays(warehouses[0], addr) : null,
    split: item.items.length > 1 ? '多个包裹分开发货' : null,
  };
}
function etaDays(w, addr) { return 7; }
```
