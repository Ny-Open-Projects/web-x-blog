## SCN-879：活动期值班监控怎么设计？
**答**：
- 前端值班看板：白屏率/JS 错误率/接口成功率/排队进入率/下单成功率，按分钟粒度 + 同比日常基线——异常即红并自动关联发版/配置变更。
- 分级告警：P0（白屏/下单链路断，电话+IM）、P1（错误率突增，IM）、P2（性能劣化，看板标注）——值班只处理 P0/P1。
- 应急动作前置：看板直接挂「降级开关」快捷入口（SCN-861 矩阵），值班一键降级无需翻配置系统——监控到动作的路径最短化。
- 值班 SOP：活动期间值班表/响应时限（P0 5 分钟响应）/升级路径，交接班 checklist。
- 追问钩子：为什么降级入口要嵌在监控看板里——事故处理的时间花在「发现→找到工具→执行」路径上；把执行入口前置到发现点，MTTR 从分钟级压到秒级。

```javascript
const oncallBoard = {
  metrics: { whiteScreenRate, jsErrorRate, apiSuccess, queueEnter, orderSuccess },
  compare: 'vs-daily-baseline, per-minute',
  alerts: { P0: ['whiteScreen', 'orderFail'], call: true, respondIn: '5min' },
  quickActions: degradeMatrix,                         // 降级开关嵌看板
  sop: { roster: true, escalation: true, handoverChecklist: true },
};
```
