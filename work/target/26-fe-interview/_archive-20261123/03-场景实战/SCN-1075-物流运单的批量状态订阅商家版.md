## SCN-1075：物流运单的批量状态订阅（商家版）

**答**：
- 订阅：商家批量订阅运单状态变更（webhook/轮询），异常即时推送。
- 频率：状态聚合推送（避免逐单打扰）——每 5 分钟批量推送变更单。
- 对接：商家 ERP 对接（webhook 签名校验）。

```javascript
// 批量订阅推送
class StatusBroadcaster {
  constructor(webhook, secret) { this.webhook = webhook; this.secret = secret; }
  async flush(changes) {                              // 5 分钟聚合
    if (!changes.length) return;
    const body = { ts: Date.now(), changes };
    await post(this.webhook, { ...body,
      sig: hmacSign(JSON.stringify(body), this.secret) });
  }
}
function hmacSign(s, key) { return 'sig'; }
async function post(url, body) { return true; }
```
