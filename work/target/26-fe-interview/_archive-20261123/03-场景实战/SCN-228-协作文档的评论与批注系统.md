## SCN-228：文档评论批注锚定在文字上，文字被编辑后锚怎么跟随？

**答**:
- 锚定模型：批注锚用 CRDT 相对位置（同光标锚定 SCN-223）——文字插入删除后锚自动伸缩跟随；锚区间收缩为 0（被全部删除）→ 批注转为"锚丢失"态（显示在原位置附近+提示原文已删除）。
- 批注数据模型：{id, anchor: {start, end 相对锚}, author, thread: [comments], status: open/resolved}——thread 支持多轮回复，resolved 态可重开。
- 呈现交互：边栏批注列表（与正文高亮双向联动：点正文滚边栏、点边栏跳正文）、批注态筛选（全部/未解决/我相关的）、resolved 态正文去高亮+边栏折叠归档。
- 协作细节：批注通知（被 @/被回复→通知）、批读权限（commenter 可批注不可改文）、批注导出（导出文档时批注可选附带）。

```javascript
const comments = ymap.get('comments');      // 批注也进 CRDT（多端一致）
function addComment(range, text) {
  const anchor = {
    start: relPos(range.start),             // 相对锚
    end: relPos(range.end),
  };
  comments.set(uid(), { anchor, author: me,
    status: 'open', thread: [{ author: me, text, ts: now() }] });
}
comments.observe(() => renderSidebar());    // 双向联动
// 锚丢失：absPos(anchor) === null → 渲染"原文已删除"态
// Resolved：正文高亮移除+边栏折叠；
// Reopen：恢复 open 态与高亮。
```
