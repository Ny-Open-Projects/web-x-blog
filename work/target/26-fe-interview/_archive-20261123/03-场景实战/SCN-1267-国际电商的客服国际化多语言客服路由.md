## SCN-1267：国际电商的客服国际化（多语言客服路由）

**答**：
- 路由：按用户语言/国家路由客服（语言匹配），AI 翻译兜底（小语种）。
- 工具：客服工作台翻译辅助（双向翻译），术语库（商品/物流术语）。
- SLA：分语言 SLA（小语种 SLA 放宽公示）。

```javascript
// 客服路由
function supportRoute(userLang, agents) {
  const match = agents.filter(a => a.langs.includes(userLang));
  if (match.length) return { agent: match[0], direct: true };
  return { agent: agents[0], translate: true,
    note: '将通过 AI 翻译沟通' };
}
```
