## SCN-880：封网期怎么运转？
**答**：
- 冻结范围：封网=冻结常规发版，但保留「紧急修复通道」（P0 bug 走加急审批双人复核 + 灰度验证后全量）。
- 封网前收尾：分支合并截止/未合需求降级处理/全量回归测试/预案与降级开关就位——封网不是暂停开发，是锁定发布面。
- 封网期开发：新需求正常开发（分支上），只不发版；封网解除后按风险排序发布（低风险先）。
- 解封发布潮：解封瞬间集中发版是新的风险点——解封节奏分批（按依赖与风险），不搞「积压全发」。
- 追问钩子：为什么解封不能「积压全发」——两周积压的变更一次性上线，变更集巨大且互相影响，出问题无法定位；分批发布让每批变更面可控。

  during: { devOnBranch: true, noDeploy: true },
  after: { batched: '按风险分批', first: 'low-risk', note: '不积压全发' },
};
