## SCN-540：手写表单校验引擎：规则链、字段依赖、异步校验去抖

**需求与边界**：
- 需求：规则链（每个字段可挂多条规则，按序短路）、跨字段规则（收款人存在 + 金额 ≤ 余额）、异步规则（服务端校验收款人）带去抖与竞态防护。
- 边界：① 同步失败不触发异步规则；② 异步结果只采纳最新一次请求；③ 提交时全量校验，返回首错并聚焦。

**答**：
```javascript
function createValidator(schema) {
  const results = {};                            // field -> error
  const asyncTimers = new Map(), asyncSeq = new Map();
  function runRules(field, value, form) {
    for (const rule of schema[field] || []) {
      if (rule.deps?.some(d => results[d])) continue;   // 依赖字段已有错则跳过
      const err = rule.validate(value, form);
      if (err) return err;
      if (rule.async) return null;                     // 同步全过后交给异步
    }
    return null;
  }
  async function asyncCheck(field, value, form) {
    const rule = (schema[field] || []).find(r => r.async);
    if (!rule) return;
    const seq = (asyncSeq.get(field) || 0) + 1;
    asyncSeq.set(field, seq);
    clearTimeout(asyncTimers.get(field));
    asyncTimers.set(field, setTimeout(async () => {
      const err = await rule.validate(value, form);
      if (asyncSeq.get(field) !== seq) return;         // 竞态：只采纳最新
      results[field] = err;
      rule.onResult?.(err);
    }, 400));
  }
  async function validateField(field, form) {
    const err = runRules(field, form[field], form);
    if (err) { results[field] = err; return err; }
    delete results[field];
    await asyncCheck(field, form[field], form);
    return results[field] || null;
  }
  async function submit(form, onFirstError) {
    for (const field of Object.keys(schema)) {
      const err = await validateField(field, form);
      if (err) return onFirstError(field, err);        // 顺序遍历保证「首错」确定性
    }
    return true;
  }
  return { validateField, submit, errors: results };
}
// schema 示例：
// { amount: [{validate: v => v > 0 ? '' : '金额必须大于 0'},
//            {validate: (v, f) => v <= f.balance ? '' : '超过可用余额', deps: ['balance']}],
//   payee: [{validate: v => /^1\d{10}$/.test(v) ? '' : '手机号格式错误'},
//           {async: true, validate: async v => (await checkPayee(v)).exists ? '' : '收款人不存在'}] }
```

**评分点**:
- 规则链短路 + 依赖字段跳过（deps 已错不再触发后续）。
- 异步校验去抖 + seq 竞态防护（只采纳最新请求结果）。
- submit 顺序遍历保证首错聚焦。
- 同步失败不发起异步请求（省接口 + 防风控误报）。
