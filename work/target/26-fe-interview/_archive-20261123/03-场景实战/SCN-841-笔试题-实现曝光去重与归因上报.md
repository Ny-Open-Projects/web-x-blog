## SCN-841：手写曝光去重上报

**需求与边界**：
- 需求：同一次下拉会话内每条建议只计一次曝光；可见 ≥ 300ms 且 ≥ 50% 面积；采纳事件携带 sid+rank+traceId；会话结束（下拉关闭/提交搜索）生成会话摘要。
- 边界：① 快速滚动经过（<300ms）不计曝光；② 下拉关闭未上报的曝光 flush；③ traceId 从 suggest 请求贯穿到结果页。

**答**：
```javascript
function createImpressionTracker(traceId, { minMs = 300, minRatio = 0.5 } = {}) {
  const reported = new Set();                          // sid 去重
  const pending = new Map();                           // sid -> enterTs
  const io = new IntersectionObserver(entries => {
    for (const e of entries) {
      const sid = e.target.dataset.sid;
      if (e.isIntersecting && e.intersectionRatio >= minRatio)
        pending.set(sid, Date.now());
      else if (pending.has(sid)) {                     // 离开视口：检查时长
        const dt = Date.now() - pending.get(sid);
        pending.delete(sid);
        if (dt >= minMs && !reported.has(sid)) {
          reported.add(sid);
          report({ type: 'sug_expose', sid, rank: e.target.dataset.rank, traceId,
                   dwellMs: dt });
        }
      }
    }
  }, { threshold: [0.5] });
  function adopt(sid, rank) {                          // 采纳（全量 urgent）
    report({ type: 'sug_adopt', sid, rank, traceId }, { urgent: true });
    close();
  }
  function close() {                                   // 会话结束 flush
    pending.forEach((ts, sid) => {
      if (!reported.has(sid) && Date.now() - ts >= minMs) {
        reported.add(sid);
        report({ type: 'sug_expose', sid, traceId });
      }
    });
    pending.clear();
    io.disconnect();
    report({ type: 'sug_session_end', exposed: reported.size, traceId });  // 会话摘要
  }
  return { observe: el => io.observe(el), adopt, close };
}
```

**评分点**:
- 双条件曝光（时长 + 面积比）与离开时结算。
- 会话级 Set 去重 + 关闭时 flush 防漏。
- 采纳带 rank/traceId（归因完整）。
- 会话摘要（曝光数）供漏斗统计。
