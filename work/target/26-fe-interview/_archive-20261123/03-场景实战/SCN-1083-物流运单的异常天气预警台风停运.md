## SCN-1083：物流运单的异常天气预警（台风停运）

**答**：
- 预警：台风/暴雪区域停运公告（受影响运单批量通知），恢复时效预估。
- 联动：受影响订单自动顺延承诺时效（对商家透明）。
- 建议：紧急件改走其他线路的建议。

```javascript
// 停运预警
function weatherStop(zone, resumeEta) {
  const affected = waybillsInZone(zone);
  affected.forEach(w => {
    notify({ to: w.merchant, text: `${zone} 停运，承诺时效顺延`,
      newEta: w.promiseH + resumeEta });
  });
  return { affected: affected.length,
    resumeEta, alt: '紧急件建议改空运/邻近分拨' };
}
function waybillsInZone(zone) { return []; }
```
