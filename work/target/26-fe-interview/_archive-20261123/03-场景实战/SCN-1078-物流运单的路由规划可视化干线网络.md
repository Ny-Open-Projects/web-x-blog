## SCN-1078：物流运单的路由规划可视化（干线网络）

**答**：
- 展示：干线路网图（分拨中心节点/线路），运单路由路径高亮。
- 调度：线路调整（新增/停运）对时效的影响预览。
- 性能：路网拓扑渲染（节点百级 SVG/Canvas）。

```javascript
// 干线路网
function routeNetworkDisplay(waybill, network) {
  const path = network.shortest(waybill.from, waybill.to);
  return {
    nodes: path.map(n => n.hub),
    edges: path.slice(1).map((n, i) => ({ from: path[i].hub, to: n.hub,
      etaH: n.etaH })),
    highlight: true,
  };
}
const network = { shortest(a, b) { return [{ hub: a, etaH: 0 }, { hub: '分拨中心', etaH: 8 }, { hub: b, etaH: 16 }]; } };
```
