## SCN-1266：国际电商的退货政策国际化（各国法规差异）

**答**：
- 法规：欧盟 14 天无理由退货（消费者权利指令）、各国退货期差异——按收货国展示政策。
- 流程：退货入口/标签生成（预付退货单）/退款时效展示。
- 例外：不可退货品类（内衣/定制）按国法规明示。

```javascript
// 退货政策
function returnPolicy(country, category) {
  const days = { EU: 14, US: 30, JP: 8 }[country] ?? 14;
  const nonReturnable = NON_RETURNABLE[country]?.includes(category);
  return {
    windowDays: nonReturnable ? null : days,
    reason: nonReturnable ? `${category} 属该国不可退货品类` : null,
    label: '预付退货标签',
  };
}
const NON_RETURNABLE = { DE: ['内衣', '定制商品'] };
```
