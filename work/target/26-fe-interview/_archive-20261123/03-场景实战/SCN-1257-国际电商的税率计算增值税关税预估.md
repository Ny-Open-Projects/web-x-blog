## SCN-1257：国际电商的税率计算（增值税/关税预估）

**答**：
- 税制：欧盟 VAT（含税价展示）、美国销售税（州级下单时计算）、关税（DDU 用户承担预估）。
- 前端：价格展示模式（含税/不含税标注）、税费明细行（结算页拆分）。
- 合规：IOSS/OSS（欧盟一站式申报）编号展示。

```javascript
// 税费计算
function taxBreakdown(amount, country, mode) {
  if (mode === 'vat-included') {                     // 欧盟含税
    const vat = amount - amount / (1 + VAT_RATE[country]);
    return { display: '含 VAT', vat: +vat.toFixed(2) };
  }
  const salesTax = US_TAX[country] ? amount * US_TAX[country] : 0;
  return { display: '价外税', tax: +salesTax.toFixed(2),
    note: '结算时按收货地址州税率计算' };
}
const VAT_RATE = { DE: 0.19, FR: 0.20, JP: 0.10 };
const US_TAX = { CA: 0.0725, NY: 0.04 };
```
