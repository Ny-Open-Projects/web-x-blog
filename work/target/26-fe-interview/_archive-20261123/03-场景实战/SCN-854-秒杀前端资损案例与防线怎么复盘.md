## SCN-854：秒杀资损怎么复盘与设防？
**答**：
- 典型资损路径：价格展示错误（缓存旧价/币种错位）、优惠叠加计算错误（前端算优惠）、重复支付（幂等失效）、库存超卖（前端展示与后端库存脱节）、机器人薅羊毛（防刷缺失）。
- 前端防线清单化：金额展示双源校验（SCN-520）、优惠计算服务端为准前端只展示、幂等键贯穿支付、按钮防重、Bot 特征信号上报（SCN-556）。
- 复盘动作：每笔资损定位到防线缺口（哪条防线缺失/失效），防线清单更新并进发布前 checklist。
- 资损分级响应：实时资损监控（订单金额分布突变告警），发现即熔断秒杀（宁停不损）。
- 追问钩子：为什么优惠金额必须服务端算——前端算优惠即把定价权交给了可篡改的客户端，改 JS 就能 1 元购；前端只做展示校验不做定价。

```javascript
const lossDefense = {
  display: { dualSourceAmountCheck: true, currencySnapshot: true },
  pricing: { serverOnly: true, clientDisplayVerify: true },   // 前端不算价
  pay: { idempotencyKey: true, submitLock: true },            // SCN-541
  bot: { behaviorSignals: true, riskGuard: 'pay' },
  monitor: { amountDistributionAlert: true, circuitBreaker: true },  // 实时熔断
};
```
