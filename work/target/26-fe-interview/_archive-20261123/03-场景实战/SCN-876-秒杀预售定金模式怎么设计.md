## SCN-876：预售定金模式怎么设计？
**答**：
- 两阶段状态机：预售期（付定金）→ 尾款期（补尾款）→ 超时未补尾款（定金不退 + 订单关闭）；每阶段时间与规则显式展示（定金不退的合规提示必须不可跳过）。
- 定金膨胀计算：膨胀后价格 = 定金 × 膨胀倍数抵扣——前端展示口径与结算口径必须一致（服务端计算为准，SCN-854），展示处标注「示意」。
- 尾款期高峰：尾款支付是第二波洪峰（集中开闸）——复用秒杀的排队/预热/倒计时全套机制。
- 状态提醒：尾款期开始提醒（推送+短信）、截止前强提醒（SCN-862 模式）、补款失败重试引导。
- 追问钩子：为什么定金不退提示必须「不可跳过」——预售规则涉消费者权益，合规要求显著告知；可跳过的提示在纠纷仲裁中不构成有效告知。

```javascript
const presaleFSM = {
  stages: ['DEPOSIT', 'BALANCE', 'CLOSED'],
  guard: (payDeposit) => confirmDialog({   // 不可跳过的合规确认
    content: '定金支付后如未按时补尾款将不予退还',
    requireScrollToEnd: true, checkbox: true,
  }),
  balance: { queue: true, warmup: true, countdown: true },   // 尾款期复用秒杀机制
  remind: ['balance-open', 'balance-due-3min'],
};
```
