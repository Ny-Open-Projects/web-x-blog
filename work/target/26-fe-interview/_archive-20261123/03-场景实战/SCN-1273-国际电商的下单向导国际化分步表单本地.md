## SCN-1273：国际电商的下单向导国际化（分步表单本地化）

**答**：
- 向导：地址→配送→支付→确认，各步按国家适配（1258 地址/1256 支付）。
- 校验：每步本地化错误提示（语言+法规），进度指示。
- 放弃挽回：步骤放弃埋点（漏斗分析优化本地化短板）。

```javascript
// 下单漏斗
function checkoutFunnel(steps, events) {
  return steps.map((s, i) => ({
    step: s,
    entered: events.filter(e => e.step === s).length,
    dropRate: i === 0 ? null
      : +(1 - events.filter(e => e.step === s).length /
          events.filter(e => e.step === steps[i - 1]).length).toFixed(2),
  }));
}
```
