## SCN-1005：航班动态的延误状态推送与改签引导

**答**：
- 状态：准点/延误/取消——航变数据推送（订阅航班号）。
- 改签：延误超阈值主动推送改签入口（同航司免费改签规则展示）。
- 兜底：取消航班一键退票+替代航班推荐。

```javascript
// 航变推送
function flightStatusSubscribe(flightNo, date) {
  return subscribe({
    event: `flight:${flightNo}:${date}`,
    on: (status) => {
      renderStatus(status);
      if (status.delayMin >= 120 || status.cancelled)
        showRebook({ free: true,                        // 航司免费改签
          candidates: status.alternatives });
    },
  });
}
```
