## SCN-775：审核运营大盘怎么设计？
**答**：
- 管理三问：内容安全吗（漏杀率/抽检结果）、效率够吗（积压/时效达标率）、成本合理吗（人均吞吐/机审直放率）。
- 趋势与预警：违规率趋势（分品类）、申诉翻案率（标准偏差信号）、机审直放率变化（模型迭代效果）。
- 分层呈现：大盘（全公司）→ 品类 → 团队 → 个人；下钻时注意个人数据的管理伦理（用于辅导不用于公开排名）。
- 异常自动标注：某品类违规率突增 3σ 标注（可能拍事件也可能攻击），关联到审核标准与外部事件。
- 追问钩子：为什么漏杀率不能只靠抽检估计——抽检是低比例采样置信区间宽，需要结合用户举报后翻案的漏杀（事后暴露）联合估计，两个口径互相校准。

```javascript
const opsBoard = {
  safety: { missRate: estimateMiss({ sampleQC, userReportReversed }), note: '双口径校准' },
  efficiency: { backlogEta, slaCompliance, throughputPerCapita },
  cost: { directRate: directRateTrend, humanCost },
  anomaly: (series) => markSigma3(series, { window: '30d' }),
  ethics: '个人数据用于辅导，不做公开排名',
};
```
