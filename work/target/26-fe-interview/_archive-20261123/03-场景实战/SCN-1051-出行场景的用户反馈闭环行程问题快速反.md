## SCN-1051：出行场景的用户反馈闭环（行程问题快速反馈）

**答**：
- 反馈：行程中/后快速反馈（问题标签+一键申诉），处理进度可见。
- SLA：反馈分类 SLA（费用争议 48h/安全问题 2h）。
- 闭环：处理结果通知+满意度回评。

```javascript
// 反馈闭环
async function feedbackSubmit(rideId, issue, evidence) {
  const sla = { fee: 48, safety: 2, service: 24 }[issue.category];
  const r = await api('/feedback', { rideId, ...issue, evidence, slaHours: sla });
  return { ticket: r.no, slaHours: sla,
    track: () => pollFeedback(r.no) };
}
```
