## SCN-1087：物流运单的多次投递尝试管理（三次派送规则）

**答**：
- 规则：三次投递失败（无人/拒收）转自提或退回——每次尝试记录（时间/照片/联系记录）。
- 前端：投递尝试时间线展示给商家/用户。
- 优化：第二次失败时短信预约投递时间。

```javascript
// 投递尝试
function deliveryAttempts(waybill) {
  const tries = waybill.attempts;                      // [{ at, result, photo }]
  if (tries.length >= 3)
    return { final: 'self-pickup-or-return',
      note: '三次投递未成功，请选择自提网点或退回' };
  if (tries.length === 2)
    return { next: '预约投递时间',
      action: smsAppointment(waybill) };
  return { next: '继续派送' };
}
function smsAppointment(w) { return true; }
```
