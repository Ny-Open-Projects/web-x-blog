## SCN-677：大屏可访问性与合规怎么做？
**答**：
- 色觉无障碍：告警色板选择色盲可辨组合（红/青替换红/绿），同时叠加形状/大小/动效第二通道（严重=大脉冲）；关键状态不单靠颜色。
- 对比度合规：数据大屏深色底高饱和字，但正文对比度 ≥ WCAG AA（4.5:1）；图表配色经过对比度校验工具。
- 数据合规：大屏物理暴露场景下的脱敏策略——人员轨迹/人脸相关数据匿名化（聚合人数不展示个体），金额按展示权限脱敏；展示数据最小化（大屏不需要的敏感字段不下发）。
- 记录合规：大屏对参观者可见时的隐私声明（区域有监控数据可视化）。
- 追问钩子：怎么验证色盲友好——用模拟色盲滤镜（Chrome DevTools vision deficiency 模拟）全屏走查，纳入发布检查清单。

```javascript
const CVD_SAFE_PALETTE = {
  alarm: { critical: '#d62728', major: '#ff7f0e', minor: '#bcbd22', info: '#17becf' },
  // 红-橙-黄-青：红绿色盲下仍可分辨（青替代绿做对比）
};
function statusStyle(level) {
  return { color: CVD_SAFE_PALETTE.alarm[level],
           shape: { critical: 'pulse-large', major: 'pulse', minor: 'ring', info: 'dot' }[level] };  // 形状第二通道
}
```
