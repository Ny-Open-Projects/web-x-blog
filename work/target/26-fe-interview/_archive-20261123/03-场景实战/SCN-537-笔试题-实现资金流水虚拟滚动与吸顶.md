## SCN-537：手写资金流水虚拟滚动：动态行高、月汇总吸顶、增量插头

**需求与边界**：
- 输入：流水数组（时间倒序）；输出：虚拟滚动渲染器。
- 边界要求：① 行高不固定（有备注的行更高），增量更新高度不整表重算；② 当月汇总头吸顶显示当月合计；③ 新流水插入头部不跳动当前视口；④ 快速滚动不白屏。

**答**：
```javascript
function createVirtualizer(rows, estimate = { header: 44, item: 72 }) {
  const heights = rows.map(r => r.type === 'header' ? estimate.header : estimate.item);
  let offsets = [], dirtyFrom = 0;
  function reflow(from = 0) {                  // 增量重算：只改 from 之后的偏移
    let h = from === 0 ? 0 : offsets[from];
    for (let i = from; i < rows.length; i++) {
      offsets[i] = h;
      h += heights[i];
    }
    offsets[rows.length] = h;                  // 总高哨兵
    dirtyFrom = rows.length;
  }
  reflow();
  return {
    total: () => offsets[rows.length],
    measure(i, h) {                            // 渲染后实测校正
      if (heights[i] !== h) { heights[i] = h; reflow(i); }
    },
    range(scrollTop, viewport) {               // 二分可视区 + overscan
      let lo = 0, hi = rows.length - 1;
      while (lo < hi) { const m = (lo + hi + 1) >> 1; offsets[m] <= scrollTop ? lo = m : hi = m - 1; }
      let end = lo;
      while (end < rows.length && offsets[end + 1] < scrollTop + viewport) end++;
      return { start: Math.max(0, lo - 3), end: Math.min(rows.length - 1, end + 3) };
    },
    stickyHeader(scrollTop) {                  // 吸顶头：首个可视 header
      const i = this.range(scrollTop, 1).start;
      for (let j = i; j >= 0; j--)
        if (rows[j].type === 'header') return rows[j].key;
    },
    prepend(newRows, scrollTop, viewport) {    // 头插保持视口不动
      const shift = newRows.reduce((s, r) =>
        s + (r.type === 'header' ? estimate.header : estimate.item), 0);
      rows.unshift(...newRows);
      heights.unshift(...newRows.map(r => r.type === 'header' ? estimate.header : estimate.item));
      reflow(0);
      return scrollTop + shift;                // 滚动位置补偿，视觉零跳动
    },
  };
}
```

**评分点**:
- 动态行高增量重算（reflow(from) 只更新尾部偏移，非全量）。
- 二分定位可视区 + overscan 防快速滚动白屏。
- 吸顶头取「首个可视行之前最近的 header」。
- 头插补偿滚动位置（scrollTop += shift）——防跳动是最容易被忽略的边界。
