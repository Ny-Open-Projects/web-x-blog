## SCN-1035：出行场景的行程评价与司机信用体系

**答**：
- 评价：星级+标签（驾驶平稳/车内整洁）双向评价（司乘互评）。
- 信用：司机信用分（接单率/投诉率/好评率）影响派单权重。
- 申诉：恶意差评申诉（证据提交，复核改判）。

```javascript
// 司机信用
function driverCredit(driver, rides) {
  const recent = rides.slice(-100);                    // 近百单窗口
  return {
    score: Math.round(
      recent.filter(r => r.rating >= 4).length / recent.length * 100),
    complaintRate: recent.filter(r => r.complaint).length / recent.length,
    dispatchWeight: creditWeight(driver.creditScore),
  };
}
function creditWeight(score) { return 0.5 + score / 200; }
```
