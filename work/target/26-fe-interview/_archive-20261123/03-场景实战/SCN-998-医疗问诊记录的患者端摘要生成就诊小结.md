## SCN-998：医疗问诊记录的患者端摘要生成（就诊小结）

**答**：
- 小结：问诊结束后生成就诊小结（诊断/处方/医嘱/复诊建议）。
- 生成：医生端模板生成 + 患者端展示（可下载 PDF）。
- 复诊：复诊建议（时间/科室）转化为日历提醒。

```javascript
// 就诊小结
function consultSummary(consult) {
  return {
    diagnosis: consult.diagnoses.map(d => d.name),
    prescriptions: consult.rx?.items.map(i => i.name) ?? [],
    advice: consult.advice,
    followUp: consult.followUp ? { date: consult.followUp.date,
      calendar: addToCalendar(consult.followUp) } : null,
    pdf: `/consult/${consult.id}/summary.pdf`,
  };
}
```
