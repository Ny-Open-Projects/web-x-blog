## SCN-302：直播回放（长视频倍速学习/笔记/知识点跳转）怎么设计？

**答**:
- 播放体验：倍速（0.5~2x 音质保真处理——变速不变调）、进度条增强（章节标记/知识点标签直接可视化在进度条上、AI 转写生成段级标记——点击跳转）、断点续播（进度服务端存储多端同步）、后台播放与画中画。
- 学习增强：笔记与视频锚定（笔记记在时间点上——点击笔记跳播）、字幕（转写字幕+双语）、课件同步（回放里课件翻页随视频时间轴联动——SCN-234 信令录制回放同源）。
- 大视频性能：HLS 多码率自适应、CDN 拉取+预加载下一片段、内存管理（长视频播放的泄漏防护——切集释放）、进度条缩略图（雪碧图预览帧，按需加载）。
- 教师侧回放管理：回放生成（直播录制→转码→上线延迟透明化：转码中状态）、回放剪辑（剪掉无用片段——标记区间剪辑，源视频不动生成新时间轴）、观看数据（谁看到几分钟——完课率统计）。

```javascript
// 知识点标记 + 笔记锚定
const marks = course.marks;   // [{t: 320, label: 'TCP握手'}]
progressBar.renderMarks(marks);              // 进度条标记
noteEditor.onSave((note) => ({ ...note,
  t: player.currentTime() }));               // 笔记锚时间
notes.on('click', (n) => player.seek(n.t));  // 点击跳播
```
