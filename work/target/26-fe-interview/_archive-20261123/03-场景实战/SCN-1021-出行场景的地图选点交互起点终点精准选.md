## SCN-1021：出行场景的地图选点交互（起点/终点精准选择）

**答**：
- 交互：POI 搜索 + 地图长按选点 + 定位微调；选点逆向地理编码显示地址。
- 精度：GPS 偏移修正（道路吸附 snap to road）。
- 体验：历史地点/收藏地点快捷选择。

```javascript
// 地图选点
async function pickPoint(kind) {
  const raw = await map.pickLocation();
  const snapped = await api('/geo/snap', { lng: raw.lng, lat: raw.lat });   // 道路吸附
  const addr = await api('/geo/reverse', snapped);
  return { ...snapped, name: addr.name,
    saved: kind === 'dest' ? recentPoints(raw) : null };
}
```
