## SCN-1074：物流国际件的清关状态与关税展示

**答**：
- 清关：国际件清关状态（出口/进口/放行/查验），查验原因与补充资料入口。
- 税费：关税预估（申报价值 × 税率）透明展示，税费支付引导。
- 多语言：清关状态多语言（收件人境外）。

```javascript
// 清关状态
function customsStatus(waybill) {
  const stages = ['export-clear', 'transit', 'import-clear', 'released'];
  return {
    stage: waybill.customs.stage,
    index: stages.indexOf(waybill.customs.stage),
    inspection: waybill.customs.inspection
      ? { reason: waybill.customs.reason, docs: uploadDocsUrl(waybill) }
      : null,
    duty: waybill.duty ? { amount: waybill.duty, pay: dutyPayUrl(waybill) } : null,
  };
}
function uploadDocsUrl(w) { return `/customs/${w.id}/docs`; }
function dutyPayUrl(w) { return `/duty/${w.id}`; }
```
