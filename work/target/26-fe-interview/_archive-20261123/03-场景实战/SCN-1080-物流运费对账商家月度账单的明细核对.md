## SCN-1080：物流运费对账（商家月度账单）的明细核对

**答**：
- 账单：月度运费账单（按运单明细核对：计费重/金额/附加费），差异行标红。
- 争议：差异行发起争议（挂起待核），争议不影响其余结算。
- 导出：账单明细导出（对账用）。

```javascript
// 运费对账
function freightReconcile(bill, orders) {
  const diffs = bill.items.map(b => {
    const o = orders.find(o => o.waybill === b.waybill);
    const expect = o ? freightCalc(o.pkg, b.rule).total : null;
    return { waybill: b.waybill, billed: b.amount, expect,
      diff: expect != null ? b.amount - expect : null };
  }).filter(d => d.diff !== 0 && d.diff != null);
  return { diffs, dispute: d => api('/bill/dispute', d),
    exportAll: () => exportBill(bill) };
}
```
