## SCN-1099：物流运单的批量发货排队（商家发货高峰）

**答**：
- 场景：商家集中发货（日均万单）——发货请求排队（限流保护）。
- 实现：提交进队列（批号），处理进度（已处理 n/total），失败重试。
- 优先：大客户/时效件优先级队列。

```javascript
// 发货排队
async function bulkShip(orders, priority) {
  const { batchId } = await api('/ship/queue', { orders, priority });
  return {
    batchId, total: orders.length,
    progress: () => pollProgress(batchId),             // n/total
    failed: () => fetchFailed(batchId),                // 失败重试
  };
}
async function pollProgress(id) { return { done: 0, total: 0 }; }
async function fetchFailed(id) { return []; }
```
