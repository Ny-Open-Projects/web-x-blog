## SCN-1254：国际化电商的多语言内容管理（商品详情翻译）

**答**：
- 内容：商品标题/详情/规格/售后政策多语言——机翻初稿 + 人工审核（重点类目）。
- 展示：缺翻译回退默认语言（标注机翻），语言切换全站一致。
- SEO：hreflang 标签（多语言站 SEO），URL 结构（/en /ja 路径）。

```javascript
// 商品多语言
function productI18n(product, lang) {
  const loc = product.i18n[lang];
  return {
    title: loc?.title ?? product.title,
    machineTranslated: !loc?.reviewed,
    hreflang: product.locales.map(l =>
      `<link rel="alternate" hreflang="${l}" href="/${l}/p/${product.id}">`),
  };
}
// 机翻标注：machineTranslated 为 true 时展示"机器翻译"提示
```
