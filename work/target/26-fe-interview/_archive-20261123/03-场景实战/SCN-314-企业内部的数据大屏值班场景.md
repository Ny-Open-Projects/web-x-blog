## SCN-314：运维值班大屏（7x24 挂屏运行）的稳定性设计？

**答**:
- 长时运行稳定性：内存巡检（长时运行的图表实例泄漏防护——AGT-499 资源守卫+定时 reload 策略：24h 低峰整页 reload）、时钟漂移修正（挂屏跑数天的时间显示定期校正）、断网自恢复（WS 断连自动重连+数据补偿拉取）。
- 渲染策略：低功耗模式（夜间降低刷新频率/亮度适配——值班场景夜间无人仍保持数据正确性优先）、图表增量化（append 数据点不全量重渲）、可视化分级（正常时段安静呈现，异常时段高亮闪烁+声音告警——值班大屏的核心是异常显著性）。
- 告警联动：告警渲染（critical 告警→大屏顶部横幅+蜂鸣、值班认领按钮——点认领通知到人）、告警降级过滤（风暴时聚合显示）、值班排班感知（当前值班人高亮）。
- 远程运维：大屏页面远程刷新/配置下发（无需到现场）、多屏编排（一块大屏多面板布局配置化——SCN-241 楼层协议复用）、可用性自检（每日自检报告：数据源连通性/渲染正常）。

```javascript
// 7x24 挂屏
setInterval(() => memoryCheck() > THRESH &&
  location.reload(), 3600e3);                // 内存巡检 reload
ws.on('reconnect', () => compensatePull());   // 断连补偿
ws.on('alarm', (a) => a.level === 'critical'
  ? banner(a) + beep() + ackBtn(a)            // 认领通知到人
  : panelTick(a));
// 夜间模式：22:00-07:00 → refreshInterval ×2 + 降亮度
// 自检：daily → report({datasourceOk, renderOk})。
```
