## SCN-1084：物流运单的批量改址（商家批量修正地址）

**答**：
- 场景：批量发单后发现地址错误（区域错误）——批量改址申请（未揽收件）。
- 校验：改址后运费重算（跨区差异），差价补收/退还。
- 结果：批量结果报表（成功/失败原因）。

```javascript
// 批量改址
async function batchAddrChange(waybills, newAddr) {
  const results = await Promise.all(waybills.map(async w => {
    const diff = freightDiff(w, newAddr);              // 运费差
    const r = await api('/addr/change', { waybill: w, newAddr, diff });
    return { waybill: w, ok: r.ok, diff, reason: r.reason };
  }));
  return { ok: results.filter(r => r.ok).length,
    failed: results.filter(r => !r.ok), totalDiff: results.reduce((s, r) => s + (r.diff ?? 0), 0) };
}
function freightDiff(w, addr) { return 0; }
```
