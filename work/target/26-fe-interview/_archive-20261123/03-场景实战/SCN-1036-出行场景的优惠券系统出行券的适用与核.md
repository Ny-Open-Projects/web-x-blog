## SCN-1036：出行场景的优惠券系统（出行券的适用与核销）

**答**：
- 券：满减券/折扣券，适用范围（车型/时段/城市）校验，叠加规则（不可叠加展示）。
- 核销：下单自动匹配最优券（用户可改选），核销失败回退价格。
- 成本：券核销率统计（营销效果）。

```javascript
// 券匹配
function bestCoupon(coupons, order) {
  const usable = coupons.filter(c =>
    c.scope.cities.includes(order.city) &&
    order.total >= c.threshold &&
    !c.expired);
  const best = usable.sort((a, b) => discount(a, order) - discount(b, order))[0];
  return { best, saving: best ? discount(best, order) : 0,
    stacked: false,                                    // 不可叠加，明示规则
    alternatives: usable.slice(0, 3) };
}
function discount(c, order) { return Math.min(c.off, order.total * (c.rate ?? 1)); }
```
