## SCN-1038：出行场景的学生票/儿童票规则前端校验

**答**：
- 规则：儿童票（身高/年龄双轨）、学生票（学生证+区间限制）前端预检，服务端终审。
- 体验：证件类型选择联动规则提示（不符原因即时说明）。
- 更新：规则版本化（政策变更热更）。

```javascript
// 票种规则
function ticketTypeRule(passenger, type, schedule) {
  if (type === 'child') {
    const okAge = age(passenger.birthday) < 14;
    const okHeight = passenger.height ? passenger.height <= 150 : true;
    if (!okAge && !okHeight)
      return { ok: false, reason: '不符合儿童票条件（年龄或身高）' };
  }
  if (type === 'student' && passenger.studentCert.region !== schedule.region)
    return { ok: false, reason: '学生票仅限优惠区间内' };
  return { ok: true, discount: type === 'student' ? 0.75 : type === 'child' ? 0.5 : 1 };
}
function age(birthday) { return (Date.now() - birthday) / 86400_000 / 365; }
```
