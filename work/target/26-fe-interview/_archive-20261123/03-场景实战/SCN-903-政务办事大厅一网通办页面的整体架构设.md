## SCN-903：政务办事大厅「一网通办」页面的整体架构设计

**答**：
- 挑战：多部门系统异构、事项配置化、材料原件上传、身份强认证（实名/刷脸）。
- 架构：统一事项中心（办事指南元数据）+ 统一表单引擎（动态 schema）+ 材料中心（上传/预审）+ 统一身份（单点登录 + 实名等级）。
- 体验目标：事项可搜索、材料免提交（电子证照调用）、进度可查可订阅。

```javascript
// 事项中心元数据模型
interface Item {
  id: string;                       // 事项编码
  name: string;                     // 事项名称
  dept: string;                     // 归属部门
  materials: MaterialSpec[];        // 材料清单
  formSchema: JSONSchema;           // 动态表单 schema
  eLicenses: string[];              // 可调电子证照（免提交）
  flow: { steps: { name: string; slaHours: number }[] };
}
// 表单引擎按 schema 渲染，材料中心按 eLicenses 自动调证照
```
