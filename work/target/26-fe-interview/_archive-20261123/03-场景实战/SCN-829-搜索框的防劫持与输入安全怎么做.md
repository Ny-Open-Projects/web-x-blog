## SCN-829：搜索框输入安全怎么做？
**答**：
- XSS 防线：用户输入只走 textContent/转义渲染（SCN-805 已用 escapeHtml），禁止把 query 拼进 HTML/URL 片段；结果页 title 中的 query 同样转义。
- URL 参数安全：q 参数从 URL 恢复时校验长度与字符白名单，防止 `javascript:` 协议注入到跳转链接。
- 输入长度限制：query 上限（如 100 字符），超长截断并提示——防超长输入打垮联想与结果接口。
- 跳转白名单：建议项跳转 URL 校验域名白名单（联想数据被污染时防外链跳转钓鱼）。
- 追问钩子：为什么跳转 URL 要白名单——联想数据链路长（词库/运营配置/爬取源），任何一环被污染都可能注入恶意跳转；前端白名单是最后一道防线。

```javascript
const inputSafety = {
  maxLength: 100,
  sanitizeUrl: (u) => WHITELIST_HOSTS.includes(new URL(u, location.origin).hostname) ? u : null,
  renderQuery: (q) => escapeHtml(truncate(q, 100)),    // 全转义 + 截断
  restoreFromUrl: (q) => /^[\w\u4e00-\u9fa5\s-]{1,100}$/.test(q) ? q : '',  // 白名单校验
};
```
