## SCN-1026：出行场景的道路阻断与灾害预警联动

**答**：
- 预警：暴雨/道路封闭信息推送（途经路线）+ 自动重规划。
- 展示：地图路况图层（封路/拥堵色块）+ 绕行方案对比。
- 安全：极端天气出行的取消建议（司机端/乘客端双侧）。

```javascript
// 灾害重规划
function hazardReroute(route, hazards) {
  const crossed = hazards.filter(h => routeCrosses(route, h.zone));
  if (!crossed.length) return { reroute: false };
  return { reroute: true,
    alt: replan(route, crossed),                       // 绕行方案
    extraMin: etaDiff(route, replan(route, crossed)),
    notice: `途经 ${crossed.map(h => h.type)} 区域，已自动绕行` };
}
function routeCrosses(route, zone) { return true; }
function replan(route, hazards) { return route; }
function etaDiff(a, b) { return 12; }
```
