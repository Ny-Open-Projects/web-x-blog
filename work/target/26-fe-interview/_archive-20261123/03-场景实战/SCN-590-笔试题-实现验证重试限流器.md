## SCN-590：手写验证重试限流器

**需求与边界**：
- 需求：滑动窗口内失败次数超限则锁定；连续失败指数延长锁定时间（30s → 1min → 2min…上限 30min）；成功后计数清零；查询当前是否可试与剩余等待。
- 边界：① 按维度组合限流（手机号+IP）；② 窗口清理防内存泄漏（定时 prune）；③ 锁定期间返回剩余秒数供 UI 倒计时。

**答**：
```javascript
function createRetryLimiter({ windowMs = 60_000, maxFails = 5,
                              baseLock = 30_000, maxLock = 30 * 60_000 } = {}) {
  const records = new Map();      // key -> { fails: [ts], lockUntil, streak }
  function prune(now) {
    for (const [k, r] of records)
      if (r.fails.every(t => now - t > windowMs) && (!r.lockUntil || r.lockUntil < now)) {
        if (!r.streak) records.delete(k);        // 窗口外且无累积惩罚：清理
        else r.fails.length = 0;
      }
  }
  setInterval(() => prune(Date.now()), windowMs);
  return {
    check(key) {
      const now = Date.now(), r = records.get(key);
      if (!r) return { allowed: true };
      if (r.lockUntil > now)
        return { allowed: false, waitMs: r.lockUntil - now, locked: true };
      const recent = r.fails.filter(t => now - t < windowMs);
      if (recent.length >= maxFails) {
        r.streak = (r.streak || 0) + 1;
        r.lockUntil = now + Math.min(baseLock * 2 ** (r.streak - 1), maxLock); // 指数惩罚
        return { allowed: false, waitMs: r.lockUntil - now };
      }
      return { allowed: true };
    },
    fail(key) {
      const now = Date.now();
      const r = records.get(key) ?? { fails: [], lockUntil: 0, streak: 0 };
      r.fails.push(now); records.set(key, r);
    },
    success(key) {
      const r = records.get(key);
      if (r) { r.fails.length = 0; r.streak = 0; r.lockUntil = 0; }  // 成功清零
    },
  };
}
```

**评分点**:
- 滑动窗口失败计数 + 超限锁定。
- 指数惩罚（2^n）带上限，成功清零 streak。
- 定时 prune 防内存泄漏。
- check 返回 waitMs 支撑 UI 倒计时。
