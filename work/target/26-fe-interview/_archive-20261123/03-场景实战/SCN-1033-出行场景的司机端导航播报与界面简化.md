## SCN-1033：出行场景的司机端导航播报与界面简化

**答**：
- 简化：驾驶态 UI 极简（大按钮/语音优先），禁止驾驶中复杂操作（合规）。
- 播报：转向/限速/订单消息语音播报，界面只保留关键信息。
- 合规：驾驶中锁定输入（接单语音确认）。

```javascript
// 驾驶态简化
function drivingModeUI(speed) {
  if (speed < 5) return { full: true };                // 停车可操作
  return { full: false,
    locked: ['input', 'menu'],                         // 驾驶中锁定
    voice: true,
    visible: ['next-turn', 'eta', 'sos'] };
}
```
