## SCN-1050：出行场景的支付方式管理与风控（大额出行消费）

**答**：
- 管理：多支付方式（余额/绑卡/先乘后付），默认方式记忆。
- 风控：大额支付二次验证（短信/指纹）、异常下单频控。
- 先乘后付：信用产品（免密代扣行程结束后扣款）额度校验。

```javascript
// 支付风控
async function ridePayment(order, method) {
  if (order.total > 500 && method !== 'balance')
    await stepUpVerify();                              // 大额二次验证
  if (method === 'credit') {
    const quota = await creditQuota();
    if (quota < order.total)
      return { ok: false, reason: '先乘后付额度不足', alt: 'switch-balance' };
  }
  return charge(order, method);
}
```
