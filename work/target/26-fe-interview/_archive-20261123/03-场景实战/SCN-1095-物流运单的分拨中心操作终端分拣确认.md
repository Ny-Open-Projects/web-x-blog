## SCN-1095：物流运单的分拨中心操作终端（分拣确认）

**答**：
- 分拣：包裹扫码 → 分拣口指示（亮灯/屏幕指向）→ 确认入格；错分报警。
- 性能：扫码到指示 < 300ms（本地缓存分拣表）。
- 统计：分拣效率（件/小时）与错分率。

```javascript
// 分拣终端
class SorterTerminal {
  constructor(sortTable) { this.table = sortTable; }   // 本地缓存分拣表
  scan(barcode) {
    const target = this.table.get(barcode);
    if (!target) return { alarm: '未知运单' };
    lightUp(target.slot);                              // 分拣口指示灯
    return { slot: target.slot, ms: performance.now() - t0 };
  }
}
```
