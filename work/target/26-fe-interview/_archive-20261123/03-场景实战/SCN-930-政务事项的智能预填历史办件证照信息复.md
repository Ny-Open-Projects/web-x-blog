## SCN-930：政务事项的智能预填（历史办件/证照信息复用）

**答**：
- 来源：用户历史办件字段、电子证照、人口库（授权查询）。
- 确认：预填内容高亮标注来源，用户确认/修改（防错用旧信息）。
- 合规：预填查询留痕与授权范围一致。

```javascript
// 智能预填
async function prefillForm(schema, user) {
  const prefill = {};
  for (const f of schema.fields) {
    if (f.source === 'elicense') {
      const lic = await fetchELicense(f.elicenseType, { id: schema.itemId });
      if (lic.ok) prefill[f.name] = lic.parsed[f.mapTo];
    } else if (f.source === 'history') {
      const last = await lastSubmission(schema.itemId);
      if (last) prefill[f.name] = last.form[f.name];
    }
  }
  return { prefill, editable: true, markedSource: true };   // 标注来源待确认
```
