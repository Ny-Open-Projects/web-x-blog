## SCN-431：手写低代码渲染器：schema 递归渲染、白名单、表达式安全求值

**需求与边界**：
- 输入：页面 schema（节点树+表达式）、组件注册表；输出：渲染结果。
- 边界要求：① 白名单（未注册类型跳过或占位）；② 表达式沙箱（受限解析，禁 eval/Function）；③ 深度限制（防递归爆栈）；④ props 白名单校验（防原型污染）。

**答**：
```javascript
const MAX_DEPTH = 30;
function renderNode(node, ctx, depth = 0) {
  if (depth > MAX_DEPTH) return null;          // 深度护栏
  const reg = REGISTRY.get(node.type);
  if (!reg) return placeholder(node.type);     // 白名单外占位
  const props = {};
  for (const [k, v] of Object.entries(node.props ?? {})) {
    if (!reg.allowedProps?.includes(k) && reg.allowedProps)
      continue;                                // props 白名单
    props[k] = typeof v === 'string' && v.startsWith('{{')
      ? safeEval(v.slice(2, -2), ctx)          // 表达式
      : v;
  }
  const children = (node.children ?? [])
    .map(c => renderNode(c, ctx, depth + 1));
  return h(reg.comp, props, children);
}
function safeEval(expr, ctx) {                 // 受限表达式
  // 只支持：标识符.属性 / 字面量 / 比较 / 逻辑 / 三元
  const tokens = tokenize(expr);               // 词法分析
  const ast = parseExpr(tokens);               // 语法树
  return evalAst(ast, {                        // 受控求值
    get(path) {                                // 白名单取值
      let v = ctx;
      for (const k of path) {
        if (v == null || !Object.prototype
          .hasOwnProperty.call(v, k))
          return undefined;                    // 防原型链污染
        v = v[k];
      }
      return v;
    },
    ops: { '==': (a,b)=>a==b, '>': (a,b)=>a>b,
      '&&': (a,b)=>a&&b, '?:': (c,a,b)=>c?a:b },
  });
}
// 禁 eval/new Function；求值器无全局访问、无函数调用。
```

**评分点**:
- 白名单双层：组件类型注册表 + props 白名单。
- 表达式沙箱：自实现解析求值，禁 eval/Function，无全局访问。
- 原型链污染防护（hasOwnProperty 取值）。
- 递归深度护栏 + 未注册类型占位降级。
