## SCN-1069：物流运单隐私面单（手机号脱敏与虚拟号）

**答**：
- 隐私面单：收件人姓名/手机号脱敏打印（张*，138****1234），详情走 App 虚拟号联系。
- 保护：面单不泄露完整信息（防信息贩卖）。
- 联系：快递员通过 App 加密呼叫（AXB）。

```javascript
// 隐私面单
function privacyLabel(order) {
  return {
    name: maskName(order.receiver.name),
    phone: order.receiver.phone.replace(/(\d{3})\d{4}(\d{4})/, '$1****$2'),
    address: partialMask(order.receiver.address),      // 只到小区
    contact: 'App 虚拟号联系',
  };
}
function partialMask(addr) { return addr.split('栋')[0] + '栋**室'; }
```
