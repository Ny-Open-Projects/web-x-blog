## SCN-1017：出行场景的行程分享与电子凭证转赠

**答**：
- 分享：行程卡片分享（图片合成/链接），接收方仅见脱敏信息。
- 转赠：车票转赠（实名核验接收方），原票失效新票生效。
- 安全：转赠需双方实名+短信确认。

```javascript
// 行程分享卡片
async function shareTripCard(trip) {
  const img = await renderCard({ route: `${trip.from}→${trip.to}`,
    time: trip.departAt,
    masked: maskName(trip.passenger),                   // 接收方只见脱敏
    qr: tripDetailUrl(trip.id, { scoped: 'summary' }) });
  return shareImg(img);
}
// 转赠：transferTicket(ticketId, toIdcard) -> 双短信确认 -> 出新票作废旧票
```
