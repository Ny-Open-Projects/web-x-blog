## SCN-1094：物流运单的客服工单与运单关联

**答**：
- 关联：客服工单挂运单号（一个运单多工单合并），处理历史可溯。
- 转办：跨部门转办（网点→干线→客服）留痕。
- SLA：工单分类 SLA 与超时升级（1059 模式）。

```javascript
// 工单关联
function ticketLink(ticket, waybills) {
  return { ticket: ticket.no,
    waybills: waybills,                                // 关联运单
    history: ticket.transfers,                         // 转办留痕
    merge: (other) => api('/ticket/merge', { from: other.no, to: ticket.no }),
    sla: ticket.categorySla };
}
```
