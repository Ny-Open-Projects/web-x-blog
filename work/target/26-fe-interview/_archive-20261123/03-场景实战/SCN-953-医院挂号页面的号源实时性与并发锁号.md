## SCN-953：医院挂号页面的号源实时性与并发锁号

**答**：
- 模型：医生×日期×时段号源，实时余号；锁号幂等（同患者同医生同时段唯一）。
- 并发：多人抢同一号——锁号原子操作，失败即时刷新余号。
- 体验：余号 < 5 提示紧张、放号时间倒计时提醒。

```javascript
// 号源锁号
async function lockSlot(slotId, patientId) {
  const r = await api('/registration/lock', { slotId, patientId,
    idempotencyKey: `${patientId}:${slotId}` });
  if (r.conflict) {
    refreshRemain(slotId);
    return { ok: false, reason: '号源刚被预约' };
  }
  return { ok: true, no: r.queueNo, expireMin: 10 };  // 10 分钟支付时限
}
```
