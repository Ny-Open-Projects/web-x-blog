## SCN-319：审计要求"操作日志可追溯并支持时间线回放"，怎么实现？

**答**:
- 日志采集：结构化操作日志（谁/何时/对什么/做了什么/前后差异 diff——关键：记录 before/after 而非仅动作），采集覆盖面清单（页面操作/数据变更/权限变更/导出——按合规要求全覆盖），前端埋点+服务端双写（前端记交互、服务端记数据事实——双源互证）。
- 时间线回放：实体级时间线（单条数据的所有变更按时间排列：操作人/字段 diff 高亮）、字段级 diff 渲染（before→after 可视化：文本 diff/数值变化/状态流转）、时间轴缩放（分钟级密集操作聚合展开）。
- 回放体验：按操作人/操作类型过滤时间线、关键节点快照（重要变更保存数据快照——可查看当时完整状态）、导出（审计报告导出——SCN-255 异步导出）。
- 性能与存储：日志分层存储（近期热数据可查/历史归档冷存）、diff 计算（服务端预计算存储 diff 而非前端现算）、海量日志检索（SCN-296 统一搜索复用）。

```javascript
// 实体时间线
function EntityTimeline({ entityId }) {
  const logs = useAudit(entityId);   // 服务端预计算 diff
  return logs.map(l => (
    <LogEntry key={l.id} who={l.operator} at={l.ts}
      diffs={l.diffs}    // [{field, before, after}]
      onExpand={() => fetchSnapshot(l.snapshotId)} />
  ));  // 字段级 diff 高亮 + 快照查看当时完整状态
}
// 双写：前端记交互日志（用于行为分析），
//   服务端记数据事实日志（审计事实源）——回放用服务端。
// 过滤：byOperator/byType/时间范围；
// 导出：asyncExport(logs)（大日志量）。
```
