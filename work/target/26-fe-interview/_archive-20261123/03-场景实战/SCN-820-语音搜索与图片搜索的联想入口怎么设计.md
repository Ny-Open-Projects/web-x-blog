## SCN-820：语音/图片搜索联想怎么设计？
**答**：
- 语音搜索：识别中间态实时展示（部分转写 + 波形），识别完成转文本后走同一联想链路；识别置信度低时展示候选列表供选择。
- 图片搜索：上传即搜（拍照/相册），联想表现为「相似图预览 + 识别主体标签」，标签可点击修正搜索意图。
- 多模态融合：语音说「找这个（展示图片）」——文本与图片意图融合，联想返回融合建议。
- 权限与降级：麦克风/相机权限拒绝时给出引导（首次拒绝后跳系统设置指引），能力不支持时隐藏入口。
- 追问钩子：为什么语音识别中间态要展示——用户说出长句时实时反馈「被听见了」，错误早发现早重说；识别完成才展示等于让用户盲等 2 秒。

```javascript
const multimodalSearch = {
  voice: { partial: true, waveform: true, lowConfidenceCandidates: true },
  image: { upload: 'immediate', tags: editable, similar: preview },
  fuse: (text, image) => suggest({ text, imageFeatures: extract(image) }),
  permission: { denied: showSetupGuide, unsupported: hideEntry },
};
```
