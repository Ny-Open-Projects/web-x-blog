## SCN-357：文档多语言协作（段落级翻译/双语对照/译文同步原文变更）怎么实现？

**答**:
- 双语文档模型：段落级对齐（源文档段落 ↔ 译文段落映射关系——段落 id 关联），双语对照渲染（左右/上下对照视图——段落级对齐滚动联动），译文也是协作文档（译者协同翻译——CRDT 复用）。
- 机器翻译辅助：段落级 MT 初翻（AI 翻译填充译文初稿——AGT-341 AI 嵌入复用）、术语表（术语强制统一译法——企业术语库注入）、译后编辑（人工润色，MT 与人工段标注区分）。
- 同步问题：源文档变更后的译文同步（源段落修改→对应译文标"待更新"——段落 hash 变更检测，不自动覆盖人工译文）、段落增删（译文段落跟随增删——对齐关系维护）。
- 交付与导出：双语文档导出（对照表/单语版切换导出）、翻译进度（段落级翻译完成度——任务化分派）。

```javascript
// 段落对齐模型
const pairs = ymap.get('translations');  // srcParaId → {text, status}
srcDoc.observe(() => {
  for (const p of changedParas()) {
    const t = pairs.get(p.id);
    if (t && hashOf(p.text) !== t.srcHash)
      t.status = 'stale';                  // 原文变更 → 待更新
  }
});
// MT 初翻：pairs.set(id, { text: mt(p.text),
//   status: 'mt' })（人工润色后 status='human'）
// 术语：mt 时注入 glossary 约束；
// 对照视图：srcPara ↔ transPara 滚动联动。
```
