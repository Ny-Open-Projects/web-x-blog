## SCN-586：风控验证场景综合收束
**答**：
- 架构主线：采集（指纹/行为/环境）→ 决策（服务端评分分级）→ 执行（验证器插件按级挂载）→ 凭证（一次性 token 绑定业务参数）——前端永不决策（SCN-553/565/567）。
- 可用性主线：降级链（滑块→短信→邮箱→限流放行）、配置回退缓存、悬挂检测、限流配合排队（SCN-558/579/581/585）——验证组件挂了不能挂业务。
- 对抗主线：环境特征检测、轨迹模型、SDK 混淆轮换、开关矩阵应急预案、红队演练（SCN-554/569/573/576）——目标是抬高攻击成本。
- 体验与合规主线：转化漏斗优化、适老低摩擦通道、敏感采集单独授权、性能预算（SCN-561/562/583/584）。
- 面试答法：以「一次支付被风控挑战」讲全流程——页面加载预热 SDK → 点击支付发起验证 → 无感/滑块分级 → token 绑单 → 失败降级 → 数据回流看板。
