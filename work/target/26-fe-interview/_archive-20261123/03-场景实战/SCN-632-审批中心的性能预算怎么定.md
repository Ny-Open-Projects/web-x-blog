## SCN-632：审批中心性能预算怎么定？
**答**：
- 分页预算：待办列表首屏 < 1.5s（FCP）、可交互 < 2.5s（TTI）；详情页首屏 < 1.2s（表单是关键）；流程图布局 < 300ms（200 节点内）；操作响应（提交到反馈）< 1s。
- 请求预算：详情页首屏请求 ≤ 3 个（实例聚合 + 权限 + 当前节点），其余懒加载；列表页分页 20 条/页 + 计数接口并行。
- 长任务治理：流程图布局计算放 Worker（大图不阻塞主线程）；批量操作进度用分帧更新。
- 预算守护：CI Lighthouse 门禁（详情页 ≥ 85）+ RUM 分位数监控超预算告警；新组件合入前 bundle diff 检查。
- 追问钩子：审批详情页为什么不能像普通页一样慢慢加载——审批是工作流瓶颈环节，加载慢=全员等待，性能直接影响组织效率。
