## SCN-257：仪表盘多图表联动（点图表 A 过滤图表 B）与实时刷新怎么设计？

**答**:
- 联动架构：全局筛选状态（dashboard filters：时间范围/维度选择），图表订阅筛选状态（任何筛选变更→相关图表重新取数），图表间联动（点选图表 A 的某分类→注入筛选状态→B/C 更新——单向数据流，图表是筛选状态的消费者与生产者）。
- 取数策略：按图表独立取数（并行+各自缓存）、聚合取数（同源数据一次拉取分发给多图）、请求去抖（筛选快速变化 300ms 防抖）、取消过期请求（筛选又变→取消飞行中请求）。
- 实时刷新：轮询/推送分级（核心指标 30s 轮询，实时曲线推送）、可见性控制（不可见暂停刷新）、数据点追加（增量 append 而非全量重渲）、刷新动画克制（数字滚动仅关键指标）。
- 性能：图表实例复用（setOption 增量而非销毁重建）、大数据量降采样（LTTB，SCN 算法库同源）、大屏场景定时全量刷新（电视挂屏场景的内存巡检防泄漏）。

```javascript
const filters = createStore({ region: null, dateRange: [...] });
function bindChart(chartId, queryBuilder) {
  return filters.subscribe(debounce(async (f) => {
    abortStale(chartId);                     // 取消过期请求
    const data = await api.query(queryBuilder(f));
    charts[chartId].setOption(buildOption(data), { lazyUpdate: true });
  }, 300));
}
// 图表 A 点选 → filters.set({region: clicked}) →
//   B/C 的 subscription 自动触发。
// 大屏：setInterval(refreshAll, 30e3) +
//   每 24h reload 防内存泄漏（挂屏场景惯例）。
```
