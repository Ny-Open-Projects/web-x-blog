## SCN-1098：物流运单的物流信息透明度（用户信任设计）

**答**：
- 透明：节点时间/网点/操作类型如实展示（不美化延误），异常原因明示。
- 一致性：客服话术与页面信息一致（防止口径不一）。
- 补偿：延误补偿规则前置公示（事后不争议）。

```javascript
// 信息透明
function transparencyPolicy(waybill) {
  return {
    showAll: true,                                     // 节点如实展示
    abnormalReason: waybill.abnormal?.reason,          // 异常原因明示
    compensationRule: '超 24h 未更新可申请运费补偿',
    note: '客服口径以页面展示为准',
  };
}
```
