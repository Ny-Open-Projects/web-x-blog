## SCN-1027：出行场景的常旅客体系（积分/等级）

**答**：
- 体系：里程积分（消费/评价获取）、等级权益（优先候补/免费改签次数）。
- 前端：积分明细/权益卡片/等级进度条。
- 防薅：积分获取风控（评价积分限频/实名门槛）。

```javascript
// 常旅客权益
function loyaltyProfile(user, points) {
  const tier = points >= 20000 ? 'gold' : points >= 5000 ? 'silver' : 'normal';
  const perks = {
    gold: ['priority-waitlist', 'free-rebook-3', 'lounge'],
    silver: ['priority-waitlist', 'free-rebook-1'],
    normal: [],
  }[tier];
  return { tier, points, perks,
    nextTierAt: tier === 'gold' ? null : tier === 'silver' ? 20000 : 5000 };
}
```
