## SCN-983：医疗问诊的处方用法说明（用药指导卡片）

**答**：
- 卡片：药品名/用法用量/餐前餐后/注意事项（配伍禁忌）/疗程。
- 警示：相互作用提示（同服药品冲突查询）、过敏史校验（处方与过敏史比对）。
- 依从：用药日历视图（每天服用清单，联动 968 打卡）。

```javascript
// 用药指导
function medicationCard(rx, patient) {
  const allergy = rx.items.filter(i =>
    patient.allergies.includes(i.allergen));
  if (allergy.length)
    return { blocked: true, reason: `过敏史冲突: ${allergy.map(a => a.name)}` };
  return { items: rx.items.map(i => ({
    name: i.name, dosage: i.dosage,
    timing: i.meal ? (i.before ? '餐前' : '餐后') : '不限',
    warning: interactionCheck(i, rx.items),
  })) };
}
```
