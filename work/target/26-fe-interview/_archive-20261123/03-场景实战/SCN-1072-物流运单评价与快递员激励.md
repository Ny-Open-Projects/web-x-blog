## SCN-1072：物流运单评价与快递员激励

**答**：
- 评价：签收后评价（服务态度/时效），评价关联快递员绩效。
- 激励：好评奖励（积分/红包），差评申诉（105 类似）。
- 合规：不得诱导好评（平台规则）。

```javascript
// 快递员激励
function courierIncentive(courierId, month) {
  const ratings = monthRatings(courierId, month);
  const good = ratings.filter(r => r.stars >= 4).length;
  return {
    goodRate: +(good / (ratings.length || 1) * 100).toFixed(1) + '%',
    bonus: good > 100 ? { points: 50 } : null,
    note: '激励不与诱导好评挂钩',
  };
}
```
