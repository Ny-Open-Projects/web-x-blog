## SCN-410：手写支付结果确认：回跳查询+推送+轮询兜底，超时引导

**需求与边界**：
- 输入：payNo、各通道事件；输出：最终态（paid/failed/processing）。
- 边界要求：① 三通道任一确认即终态（互不覆盖：终态后取消其他通道）；② 未确认超时→processing 态+后台长轮询；③ 绝不把"未确认"当失败；④ 幂等（重复确认安全）。

**答**：
```javascript
class PayConfirm {
  constructor(payNo, { api, push, onFinal }) {
    this.payNo = payNo; this.api = api;
    this.push = push; this.onFinal = onFinal;
    this.state = 'init'; this.stopped = false;
  }
  start() { this.query(); this.listenPush(); }
  async query() {                              // 通道 1：回跳查询
    for (let i = 0; i < 3; i++) {
      const r = await this.api.status(this.payNo);
      if (this.settle(r)) return;
      await sleep(2000);
    }
    this.backgroundPoll();                     // 转后台长轮询
  }
  listenPush() {                               // 通道 2：推送
    this.push.on(`pay:${this.payNo}`, (r) => this.settle(r));
  }
  backgroundPoll() {                           // 通道 3：兜底轮询
    this.timer = setInterval(async () => {
      if (this.stopped) return clearInterval(this.timer);
      const r = await this.api.status(this.payNo).catch(() => null);
      if (r && this.settle(r)) clearInterval(this.timer);
      if (Date.now() - this.t0 > 120e3) {      // 超时兜底
        clearInterval(this.timer);
        if (!this.stopped) this.onFinal('processing',
          { guide: '稍后在订单列表查看' });    // 引导出口
      }
    }, 3000);
  }
  settle(r) {                                  // 终态裁决
    if (this.stopped || !['paid', 'failed'].includes(r.status))
      return false;
    this.stopped = true; this.state = r.status;
    clearInterval(this.timer);
    this.push.off(`pay:${this.payNo}`);
    this.onFinal(r.status, r);                 // 终态一次回调
    return true;
  }
}
```

**评分点**:
- 三通道并行冗余，settle 终态裁决保证单次回调（互不覆盖）。
- 未确认转 processing + 后台长轮询，绝不把未确认当失败。
- 超时兜底给确定出口（订单列表引导）而非无限等待。
- 终态后清理所有通道（interval/push 订阅）。
