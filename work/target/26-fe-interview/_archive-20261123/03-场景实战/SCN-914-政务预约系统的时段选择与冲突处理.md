## SCN-914：政务预约系统的时段选择与冲突处理

**答**：
- 模型：事项 × 网点 × 时段容量；前端展示剩余号源，选择后锁定（幂等锁号）。
- 冲突：并发锁号失败（他人先锁）即时提示换时段；爽约惩罚规则展示。
- 体验：日历+时段矩阵（剩余数标色），候补登记（满时段排队）。

```javascript
// 锁号流程
async function bookSlot(slotId) {
  const r = await api('/booking/lock', { slotId, idempotencyKey: genToken() });
  if (r.conflict) {
    const remain = await api(`/slots/${slotId}/remain`);
    toast(`该时段刚被预约，当前剩余 ${remain}，请刷新选择`);
    return refreshSlots();
  }
  return r;                                          // 锁号成功进入确认页
```
