## SCN-927：政务信息的无障碍读屏兼容清单

**答**：
- 要点：图片 alt、表单 label 关联、动态更新 aria-live、焦点管理（弹窗焦点圈）。
- 测试：NVDA/VoiceOver 走查核心流程（登录/申报/查进度）。
- 工具：axe 扫描进 CI（违反 WCAG AA 阻断）。

```javascript
// aria-live 进度播报
function announceProgress(step) {
  const live = document.getElementById('a11y-live');
  live.setAttribute('aria-live', 'polite');
  live.textContent = `当前进度：${step.name}，${step.status}`;
}
// axe 扫描：
// npx axe http://localhost:3000/service --exit
```
