## SCN-774：多内容形态审核复用怎么设计？
**答**：
- 形态抽象：内容预览器（视频播放器/图文渲染/音频波形）是插件，队列/表单/质检/申诉框架复用——内容形态只影响「预览与标注」两层。
- 标注模型统一：位置标注泛化（视频=时间段，图文=区域框，音频=时间段），统一 mark 模型 `{ span|rect, type, confidence }`。
- 机审接口统一：各形态机审结果统一为 marks + score，工作台不感知模型差异。
- 组合内容：视频里嵌图文（封面/贴片）——多形态嵌套标注（视频时间段 + 帧内区域）支持两层定位。
- 追问钩子：为什么统一标注模型是复用关键——质检/申诉/数据回流全部围绕标注运转，标注模型统一后这些子系统一次开发全形态受益。

```javascript
const markModel = {
  video: (m) => ({ span: [m.startTs, m.endTs], ...common(m) }),
  image: (m) => ({ rect: [m.x, m.y, m.w, m.h], ...common(m) }),
  audio: (m) => ({ span: [m.startTs, m.endTs], waveform: true, ...common(m) }),
};
const common = (m) => ({ type: m.type, confidence: m.confidence, source: m.source });
// 预览器插件注册
registry.set('video', VideoPreviewer); registry.set('article', ArticlePreviewer);
```
