## SCN-976：医疗问诊的电子病历结构化录入（医生端）

**答**：
- 结构化：主诉/现病史/查体/诊断（ICD 编码选择器）/处方——模板化录入。
- 效率：常用模板（按科室/病种）、语音转文字录入（医生口述）。
- 校验：诊断与处方一致性提示（诊断高血压开降压药）。

```javascript
// 结构化录入
function recordEditor(template) {
  return {
    fields: template.fields,                           // 主诉/现病史...
    icd: { search: icdSearch, recent: recentDiagnoses() },
    voice: { on: speechToText, target: 'chief-complaint' },
    validate: (record) => diagnoseRxMatch(record),     // 诊断-处方一致性
  };
}
// 模板：感冒模板预填"咽痛/流涕"等主诉，医生修改
```
