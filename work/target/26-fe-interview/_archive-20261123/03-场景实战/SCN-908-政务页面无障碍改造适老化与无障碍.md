## SCN-908：政务页面无障碍改造（适老化与无障碍）

**答**：
- 适老化：大字模式（字体缩放）、高对比度、语音辅助、简化流程（长辈版）。
- 无障碍：ARIA 标签、键盘可达、读屏兼容（焦点顺序/表单标签）。
- 落地：长辈版开关（记忆偏好）、关键流程语音播报。

```javascript
// 长辈版适配
function elderMode(enable) {
  document.documentElement.style.setProperty('--font-scale', enable ? '1.3' : '1');
  document.documentElement.style.setProperty('--contrast', enable ? 'high' : 'normal');
  localStorage.setItem('elder-mode', enable ? '1' : '0');
  report({ type: 'elder-mode', enable });
}
// 高对比度 CSS：
// .elder .btn { background: #000; color: #fff; border: 2px solid #000; }
```
