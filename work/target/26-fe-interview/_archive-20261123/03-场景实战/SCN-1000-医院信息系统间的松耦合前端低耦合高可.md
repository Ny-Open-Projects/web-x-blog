## SCN-1000：医院信息系统间的松耦合前端（低耦合高可用）

**答**：
- 原则：前端聚合层（BFF）隔离 HIS/LIS/PACS 系统差异——单系统故障局部降级。
- 降级：LIS 不可用时报告列表显示"检验数据暂不可用"（其他模块正常）。
- 监控：各子系统健康度独立探测（可观测）。

```javascript
// 系统隔离
function hospitalBFF(resolvers) {
  return Promise.allSettled(resolvers.map(r => r.fetch()));
}
function renderWithDegradation(results, modules) {
  return results.map((r, i) => r.status === 'fulfilled'
    ? modules[i].render(r.value)
    : modules[i].fallback(r.reason));                  // 局部降级
}
}
```
