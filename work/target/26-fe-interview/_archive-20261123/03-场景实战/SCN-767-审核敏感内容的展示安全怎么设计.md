## SCN-767：审核敏感内容展示安全怎么设计？
**答**：
- 分级展示：高危内容（血腥/暴力）默认打码/模糊预览，审核员确认需要时逐步取消（点击揭露），且可配置「自动打码强度」——既看清违规又降低冲击。
- 意外暴露防护：审核页面禁止录屏提示（App 端）、禁止内容外发（复制/右键禁用 + 水印工号）、外发截图追责水印。
- 音频保护：违规音频默认静音播放 + 文字稿先行，确认需要再开声。
- 环境隔离：审核系统独立域、不可外链跳转、剪贴板写审计——防内容泄露是安全红线。
- 追问钩子：打码会不会影响审核判断——分级策略：结构判断（是否存在违规元素）在打码态即可完成，细节确认时才揭露；用「先结构后细节」的两步法保效率。

```javascript
function protectStage(video) {
  return {
    blurDefault: video.riskLevel >= 3,               // 高危默认模糊
    reveal: { stepwise: true, logReveal: true },     // 揭露操作留痕
    audio: { muted: true, transcriptFirst: true },   // 文字稿先行
    copy: { blocked: true, watermark: `工号${auditorId}:${Date.now()}` },   // 防外发
  };
}
```
