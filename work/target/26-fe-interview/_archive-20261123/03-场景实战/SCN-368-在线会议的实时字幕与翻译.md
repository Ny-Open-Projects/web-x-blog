## SCN-368：会议实时字幕（语音识别/翻译/多语言）怎么实现？

**答**:
- 字幕管线：音频流→ASR（端上采集→服务端流式 ASR——低延迟分片上传）、字幕流分发（识别结果信令广播：段落级增量——修正机制：ASR 修正已发内容）、延迟控制（识别延迟 <2s 目标——分片与流式协议）。
- 呈现设计：字幕样式（底部叠加条：说话人+文本——说话人归属：与会议成员 voice print 绑定）、滚动模式（滚动条/逐句替换——可配置）、双字幕（原文+译文双行——实时翻译：MT 流式）。
- 多语言：多语言字幕（按观众语言偏好各自订阅——分发按端语言），翻译延迟（翻译比原文慢——双行错位呈现的可接受性）、专有名词（会议热词表：人名/产品名注入 ASR 提升准确率）。
- 无障碍与留存：字幕的无障碍价值（听障参会者核心功能——字号/位置可调）、字幕留存（会后字幕转纪要——SCN-293 复用、字幕搜索）。

```javascript
// 采集→识别→分发
audioStream.pipe(asrStream({ hotwords: MEETING_TERMS }));
asr.on('partial', (seg) => subtitle.render(seg));  // 增量修正
ws.on('subtitle', (seg) => {                 // 他人字幕
  subtitle.render({ speaker: memberOf(seg.uid),
    text: seg.text, trans: transFor(seg, myLang) }); // 双行
});
// 呈现配置：字号/位置/滚动模式——无障碍可调。
// 会后：asr.segments → 纪要生成（SCN-293 复用）。
```
