## SCN-714：看板权限与对外客户版怎么设计？
**答**：
- 内部版/客户版分离：内部版全量（含各业务线明细/根因标注）；客户版只展示合同 SLA 相关指标 + 达标月报，敏感维度（内部业务线/成本/事故细节）不下发。
- 客户版口径合规：客户 SLA 计算口径与合同一致（口径卡公示），争议时以服务端存证数据为准；数据快照定期导出双方存证。
- 权限模型：行级权限（按业务线）+ 指标级权限（部分指标仅 SRE 可见）+ 导出权限独立控制。
- 脱敏在服务端：客户版接口服务端过滤与聚合，前端不持敏感数据（防爬）。
- 追问钩子：客户说「你们的达标率和我们自己测的不一样」怎么办——口径卡 + 数据快照仲裁；差异往往来自测量位置（客户端 vs 探测点），口径卡里写清。

```javascript
const boardACL = {
  internal: { rows: '*', metrics: '*', export: true },
  customer: {
    rows: (ctx) => ctx.customerBizLines,             // 行级
    metrics: ['availability', 'p95', 'error_rate'],  // 指标级白名单
    export: 'monthly-signed',                        // 导出走月报签名快照
    note: '口径与合同 SLA 附件一致，存证数据可仲裁',
  },
};
```
