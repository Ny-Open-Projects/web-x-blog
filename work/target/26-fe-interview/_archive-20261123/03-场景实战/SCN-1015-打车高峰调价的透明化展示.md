## SCN-1015：打车高峰调价的透明化展示

**答**：
- 透明：调度费/远途费/夜间费逐项展示（估价明细），实际价格与预估偏差说明。
- 确认：调价确认弹窗（超预估 30% 时二次确认）。
- 争议：行程后价格异议入口（明细级申诉）。

```javascript
// 调价明细
function fareBreakdown(estimate, actual) {
  const items = ['base', 'distance', 'time', 'surge', 'night', 'toll'];
  const detail = items.map(k => ({ label: k, amount: actual[k] }))
    .filter(i => i.amount > 0);
  const diff = actual.total - estimate.total;
  return { detail, diff,
    confirmNeeded: diff / estimate.total > 0.3,
    note: '计费规则公开可查，异议可发起申诉' };
}
```
