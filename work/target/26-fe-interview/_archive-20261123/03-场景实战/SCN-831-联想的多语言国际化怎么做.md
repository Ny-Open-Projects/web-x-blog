## SCN-831：联想国际化怎么做？
**答**：
- 多语种词库：词库按语言分库，用户语言检测（界面语言+历史语言）路由到对应词库；多语言混输（海外华人中英混输）双语索引。
- RTL 支持：阿拉伯语等 RTL 语言的下拉/高亮/键盘导航镜像（方向键左右反转），文字对齐 right。
- 高亮与截断：RTL 下截断方向反转（省略号在左）；高亮偏移用码点级（SCN-805）保证兼容。
- 本地化体验：各区域热词独立（美国 vs 日本热词完全不同），时区相关的季节词（节日）按区域日历。
- 追问钩子：为什么 RTL 不只是「翻转布局」——键盘导航语义（ArrowLeft 是「下一个」）、文本截断方向、高亮 offset 计算都要逻辑镜像；用 CSS logical properties + direction 属性系统性处理。

```javascript
const i18nSuggest = {
  langRoute: (user) => wordDB[user.lang] ?? bilingual(user.lang),   // 语言路由
  rtl: { dir: 'rtl', arrows: { Left: 'next', Right: 'prev' },      // 导航镜像
         truncate: 'start', highlight: 'codepoint-safe' },
  hotwords: { byRegion: true, seasonal: regionCalendar },
};
```
