## SCN-1269：国际电商的支付失败与本地化错误信息

**答**：
- 错误：支付失败码本地化（卡余额不足/风控拒绝），行动建议（换卡/换支付方式）。
- 重试：可重试错误自动重试（一次），不可重试引导客服。
- 安全：错误信息不泄露敏感（卡号掩码）。

```javascript
// 支付错误本地化
function payErrorLocalize(code, lang) {
  const MSG = { insufficient: { en: 'Insufficient funds', de: 'Nicht genügend Guthaben' },
    risk_reject: { en: 'Blocked by bank risk control' } };
  return {
    text: MSG[code]?.[lang] ?? MSG[code]?.en ?? '支付失败，请重试',
    retryable: ['timeout', '3ds_pending'].includes(code),
    action: code === 'insufficient' ? 'suggest-other-method' : null,
  };
}
```
