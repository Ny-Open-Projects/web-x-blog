## SCN-981：医院自助报告机的身份核验与防冒领

**答**：
- 核验：医保卡/身份证/扫码（就诊码）+ 单次打印验证码（短信）。
- 防冒领：敏感报告（生育/传染病）需本人+验证码双重核验。
- 留痕：打印记录（谁/何时/打印了什么报告）。

```javascript
// 报告打印核验
async function printReport(reportId, identity) {
  const sensitive = SENSITIVE_REPORTS.has(reportId.category);
  if (sensitive) {
    const code = await smsVerifyCode(identity.phone);
    const ok = await verifySmsCode(code);
    if (!ok) return { ok: false, reason: '验证码校验失败' };
  }
  await auditLog({ type: 'report-print', reportId, by: identity.hashed });
  return print(pdfRender(reportId));
}
```
