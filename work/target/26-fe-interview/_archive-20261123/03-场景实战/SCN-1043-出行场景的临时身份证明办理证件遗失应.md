## SCN-1043：出行场景的临时身份证明办理（证件遗失应急）

**答**：
- 应急：购票时证件遗失 -> 线上办临时乘车身份证明（铁路 12306 电子证明）。
- 流程：人脸核验 -> 生成电子临时证明（当日有效）-> 购票/进站使用。
- 提示：证明有效期与使用范围明确标注。

```javascript
// 临时身份证明
async function tempIdProof(identity) {
  const face = await faceVerify(identity);             // 人脸核验
  if (!face.ok) return { ok: false, reason: '人脸核验未通过' };
  const proof = await api('/temp-id', { name: identity.name, idNo: identity.idNo });
  return { proofNo: proof.no, validToday: true,
    use: ['购票', '进站'], qr: proof.qrCode };
}
```
