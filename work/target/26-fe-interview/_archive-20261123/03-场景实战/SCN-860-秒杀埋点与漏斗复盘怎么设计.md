## SCN-860：秒杀埋点与漏斗怎么设计？
**答**：
- 漏斗分层：曝光 → 详情页 → 点击抢购 → 排队进入 → 放行 → 下单 → 支付成功，每步转化率与流失原因标记（点击未排队=库存感知失败？排队放弃=等待过长？）。
- 埋点可靠性：秒杀瞬时流量巨大——埋点采样（行为线 10%）+ 关键事件（下单/支付）全量；本地缓冲批量上报防打爆埋点网关。
- 失败归因维度：下单失败按错误码分布（售罄/限流/风控/网络），占比直接指向瓶颈（限流占比高=容量不足，风控占比高=误杀）。
- 实时看板：活动进行中实时漏斗（分钟级），异常掉落自动告警——复盘数据一半来自实时监控而非事后统计。
- 追问钩子：为什么埋点要分级采样——全量埋点在秒杀流量下会占上行带宽（抢手机网络）且打爆采集端；关键转化事件才值得全量。

```javascript
const funnel = {
  steps: ['expose', 'detail', 'click', 'queue', 'admit', 'order', 'pay'],
  sampling: { default: 0.1, orderAndPay: 1.0 },        // 关键事件全量
  failureDims: ['stock_out', 'rate_limit', 'risk_reject', 'network'],
  realtime: { window: '1min', alert: 'step_drop > 30%' },
};
```
