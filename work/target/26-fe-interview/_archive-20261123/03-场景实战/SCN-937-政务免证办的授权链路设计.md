## SCN-937：政务「免证办」的授权链路设计

**答**：
- 链路：事项发起 -> 检查所需证照 -> 逐证照授权弹窗（一次一授权）-> 调取 -> 自动装填。
- 取消：授权可撤回（个人中心），撤回后历史办件不受影响。
- 审计：授权调用链路全程留痕（监管要求）。

```javascript
// 授权链路
async function licenseFlow(item) {
  for (const lic of item.eLicenses) {
    const ok = await grantLicense(lic);               // 一次一授权
    if (!ok) return { ok: false, missing: lic,
      note: '拒绝授权可手动上传替代' };
    auditLog({ type: 'license-grant', lic, item: item.id });
  }
  return { ok: true };
}
```
