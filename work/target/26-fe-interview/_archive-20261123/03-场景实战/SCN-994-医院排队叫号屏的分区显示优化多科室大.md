## SCN-994：医院排队叫号屏的分区显示优化（多科室大厅）

**答**：
- 分区：多科室大厅分屏显示（每屏 2-3 科室），滚动轮播。
- 刷新：叫号事件推送（WS）+ 兜底轮询；过号重叫高亮。
- 可读性：大字号/高对比/红绿蓝状态色。

```javascript
// 分区叫号屏
function zoneDisplay(zones) {
  return zones.map(z => ({
    dept: z.dept, current: z.calling[0]?.no,
    next: z.calling.slice(1, 4).map(c => c.no),
    refresh: 'ws-push', fallback: '10s-poll',
    highlight: z.recalled ? 'red' : null,              // 过号重叫高亮
  }));
}
```
