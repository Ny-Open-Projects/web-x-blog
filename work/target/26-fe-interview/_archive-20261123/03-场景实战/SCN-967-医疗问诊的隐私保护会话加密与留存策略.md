## SCN-967：医疗问诊的隐私保护（会话加密与留存策略）

**答**：
- 留存：问诊记录按医疗规范留存（诊疗记录永久），聊天记录限定期限匿名化。
- 加密：传输 TLS + 敏感字段（身份证/手机号）加密存储展示脱敏。
- 访问：患者可查看"谁访问了我的记录"清单（956）。

```javascript
// 问诊隐私
const RETENTION = { consultChat: 3 * 365, medicalRecord: Infinity };
function retentionPolicy(type, record) {
  const days = RETENTION[type] ?? 365;
  if (days === Infinity) return { keep: 'permanent' };
  const expireAt = record.createdAt + days * 86400_000;
  return { keep: 'until', expireAt,
    action: expireAt < Date.now() ? 'anonymize' : 'retain' };
}
```
