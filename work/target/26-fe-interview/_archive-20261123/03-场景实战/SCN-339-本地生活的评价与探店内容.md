## SCN-339：本地生活内容体系（探店笔记/评价/榜单/打卡）怎么设计？

**答**:
- 内容形态：探店笔记（图文/视频挂门店位置——POI 挂载：内容与实体关联协议）、评价（SCN-284 评价复用+维度扩展：环境/口味/服务分项分）、榜单（热榜/必吃榜：权威榜单页——榜单与门店卡联动）。
- 位置内容联动：附近内容（LBS 内容流：按距离与热度混合——SCN-266 联动复用）、打卡（到店打卡激励：定位校验在店——围栏判定 SCN-263 复用防作弊）、门店页内容聚合（门店详情页聚合该店笔记与评价）。
- 创作工具：探店模板（结构化模板：环境/菜品/价格——降低创作门槛）、POI 绑定（发布时挂门店——自动识别或搜索选择）、内容激励（曝光扶持/达人等级）。
- 合规：真实探店标注（商业推广内容标记——广告合规）、虚假探店治理（未到店判定：定位/消费凭证校验）、评价与笔记的审核链（SCN-326 复用）。

```javascript
function PoiNote({ note }) {
  return <>
    <NoteBody {...note} />
    <PoiCard poi={note.poi}                  // 挂载门店卡
      onClick={() => enterStore(note.poi)} />
    {note.sponsored && <AdTag />}            {/* 商业标记 */}
  </>;
}
// 打卡：checkin → verifyAtStore(locate(), poi)
//   （围栏判定防作弊）→ 激励发放。
// 门店页聚合：storePage.feed = notes.filter(poi === store)。
// 榜单：rankPage(list) → 门店卡跳转联动。
```
