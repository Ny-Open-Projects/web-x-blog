## SCN-680：数字孪生大屏场景综合收束
**答**：
- 渲染主线：分层混合渲染（3D/标注/2D）、按需渲染与合帧、InstancedMesh/BVH、LOD 与轻量化管线（SCN-658/661/671/678）——万级点位不掉帧。
- 数据主线：统一事件契约、订阅式接入、背压协同、降采样保真、数据健康度可见（SCN-653/663/665/675）——宁可显示陈旧不给假实时。
- 交互主线：TwinStore 单源联动、下钻层级、拾取优化、时间轴回放、多屏联动主从同步（SCN-654/659/660/669）。
- 运维主线：值守模式、watchdog 自恢复、诊断面板、快照导出、布局配置化（SCN-666/664/672/673）——大屏是 7×24 设备，按基础设施标准做。
- 面试答法：用「一块园区大屏从 0 到 1」讲：选型（SCN-668）→ 模型管线 → 数据接入 → 告警联动 → 值守运维，处处给预算和指标。

```javascript
const twinMethodology = {
  render: ['layered-hybrid', 'on-demand', 'instancing-bvh', 'lod-pipeline'],
  data: ['event-contract', 'subscribe-gateway', 'backpressure', 'health-visible'],
  interact: ['single-store', 'drill-hierarchy', 'raycast-optimized', 'replay-timeline'],
  ops: ['patrol-mode', 'watchdog', 'diag-panel', 'layout-config'],
};
```
