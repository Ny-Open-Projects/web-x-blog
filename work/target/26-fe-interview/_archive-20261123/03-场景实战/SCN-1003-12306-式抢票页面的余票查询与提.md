## SCN-1003：12306 式抢票页面的余票查询与提交架构

**答**：
- 挑战：放票瞬时高并发查询（余票轮询）+ 提交排队（队列化提交而非并发抢）。
- 前端：查询节流（2s 一次）、提交进入排队（排队号+预计等待）、轮询提交结果。
- 防刷：设备指纹+实名限购（一人一张同车次）+ 行为验证前置。

```javascript
// 排队提交
async function submitTicket(order) {
  const { queueId } = await api('/ticket/submit-queue', order);
  return pollSubmit(queueId);
}
async function pollSubmit(queueId, { interval = 2000 } = {}) {
  for (;;) {
    const r = await api(`/ticket/submit/${queueId}`).catch(() => null);
    if (r?.status === 'success') return r.ticket;
    if (r?.status === 'failed') throw new Error(r.reason);
    await sleep(interval);
  }
}
// 余票查询 2s 节流 + 服务端限流（60s/次/IP）
```
