## SCN-966：医院排队叫号与检查室导航（院内定位）

**答**：
- 导航：科室位置/路线（院内地图或简单楼层图），检查室指引。
- 实现：楼层平面图 + 路径高亮（静态路径），精确定位降级为文字指引。
- 体验：报告/缴费后自动提示下一站（检查地点导航）。

```javascript
// 院内导航
function hospitalNavigate(from, to) {
  const path = floorPlan.route(from, to);             // 预置路径图
  return {
    steps: path.map(p => ({ desc: p.desc, icon: p.icon })),
    etaMin: path.length * 1.5,                        // 估算步行
    fallback: to.floor ? `请前往 ${to.floor} 层 ${to.room}` : null,
  };
}
```
