## SCN-1059：物流异常件的客服处理工作台

**答**：
- 工作台：异常件队列（按异常类型/时效排序），处理动作（联系客户/改派/退回）。
- SLA：异常处理时效（24h 内响应），超时升级。
- 模板：常用话术模板（外呼/短信），处理记录留痕。

```javascript
// 异常工作台
function exceptionQueue(exceptions, { slaHours = 24 } = {}) {
  return exceptions
    .map(e => ({ ...e, overdue: Date.now() - e.createdAt > slaHours * 3600_000 }))
    .sort((a, b) => (b.overdue - a.overdue) || (b.priority - a.priority));
}
function resolveException(id, action, note) {
  return api('/exception/resolve', { id, action, note, at: Date.now() });   // 留痕
}
}
```
