## SCN-813：联想组件封装怎么设计？
**答**：
- 逻辑/视图分离：useSuggest hook（数据层：防抖/竞态/缓存/埋点）与 UI 层（下拉/键盘/样式）分离——顶部搜索框、首页大框、App 内嵌框共用数据层换皮肤。
- 变体配置：下拉宽度/分组显隐/直达卡样式/历史词开关按场景配置化（props 或配置下发）。
- 数据层复用边界：不同场景词源不同（商品搜索 vs 全站搜索）——词源路由也配置化（同一组件不同 suggest 接口）。
- 测试友好：数据层纯逻辑单测（竞态/缓存/防抖），UI 层交互测试（键盘/无障碍）分层覆盖。
- 追问钩子：为什么数据层做成 hook 而不是组件——逻辑复用频率远高于视觉复用；hook 组合（useSuggest + useImpression）比 HOC/继承更清晰。

```javascript
function useSuggest({ api, debounceMs = 150, minLen = 2 } = {}) {
  const [data, setData] = useState(null), [loading, setLoading] = useState(false);
  // 防抖/竞态/缓存（SCN-804）+ 埋点（SCN-807）全部内聚在 hook
  return { data, loading, suggest, adopt, exposeObserver };
}
// 视图层任意换肤
const NavSearch = () => <SearchBox slim useSuggest={useSuggest({ api: navApi })} />;
const HomeSearch = () => <SearchBox large showCards useSuggest={useSuggest({ api: mainApi })} />;
```
