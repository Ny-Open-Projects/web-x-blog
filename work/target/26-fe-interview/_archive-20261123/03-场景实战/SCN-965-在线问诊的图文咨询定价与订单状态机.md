## SCN-965：在线问诊的图文咨询定价与订单状态机

**答**：
- 状态机：待支付→咨询中→已完成/已退款；中途超时退款规则展示。
- 前端：状态时间轴、退款进度、发票申请入口。
- 并发：医生接单抢占（多人咨询同一医生排队）。

```javascript
// 问诊订单状态机
const CONSULT_FSM = createMachine({
  unpaid: { pay: 'in-progress', cancel: 'cancelled' },
  'in-progress': { complete: 'done', timeout: 'refunded' },
  done: { invoice: 'invoiced' },
});
// 超时退款：in-progress 超 24h 未接单自动退款 + 通知
// 发票：done 后申请电子发票（抬头/税号表单）
```
