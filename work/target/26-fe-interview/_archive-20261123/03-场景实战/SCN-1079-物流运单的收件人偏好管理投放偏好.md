## SCN-1079：物流运单的收件人偏好管理（投放偏好）

**答**：
- 偏好：投递偏好（快递柜/驿站/送货上门/免打扰时段）下单时选择，全程生效。
- 冲突：偏好与网点能力冲突（该区域无柜）降级提示。
- 默认：上次偏好记忆。

```javascript
// 投递偏好
function deliveryPreference(order, prefs) {
  const available = prefs.options.filter(o =>网点Supported(o, order.addr));
  if (!available.includes(prefs.choice))
    return { fallback: available[0],
      note: `${prefs.choice} 在该区域不可用，已选 ${available[0]}` };
  return { final: prefs.choice };
}
function 网点Supported(o, addr) { return true; }
```
