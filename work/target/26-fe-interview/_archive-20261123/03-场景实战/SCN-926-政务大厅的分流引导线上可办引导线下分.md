## SCN-926：政务大厅的分流引导（线上可办引导线下分流）

**答**：
- 目的：大厅取号前引导「线上可办」事项转网办，减少排队。
- 实现：取号时校验事项是否支持网办 -> 弹引导（网办步骤/材料清单）。
- 转化：引导成功率埋点（网办转化率）。

```javascript
// 分流引导
async function takeNumberWithGuide(itemId) {
  const item = await getItem(itemId);
  if (item.onlineAvailable) {
    const go = await confirmOnline(item);             // 引导弹窗
    if (go) { navigate(`/online-item/${itemId}`);
      report({ type: 'online-convert', itemId }); return; }
  }
  return normalTakeNumber(itemId);
}
```
