## SCN-433：手写表单联动引擎：依赖图拓扑更新、显隐/值联动、跨字段校验

**需求与边界**：
- 输入：表单 schema（字段+deps 联动规则）、值变更；输出：联动后的状态。
- 边界要求：① 依赖图（变更只影响依赖方——最小更新）；② 显隐联动（visibleIf）+值联动（计算字段）+必填动态；③ 隐藏字段提交时剔除；④ 跨字段校验（比较类规则）。

**答**：
```javascript
class FormEngine {
  constructor(schema) {
    this.schema = schema;
    this.deps = new Map();                     // field → 依赖它的字段
    for (const f of schema.fields)
      for (const d of f.deps ?? [])
        this.deps.set(d.on, (this.deps.get(d.on) ?? new Set()).add(f.id));
    this.values = {};
    this.errors = {};
  }
  setValue(field, value) {
    this.values[field] = value;
    const affected = this.deps.get(field) ?? new Set();
    for (const id of affected) {               // 最小更新：只算依赖方
      const f = this.schema.fields.find(x => x.id === id);
      // 显隐联动
      if (f.visibleIf && !evalCond(f.visibleIf, this.values))
        { this.visibility[id] = false;
          delete this.values[id]; continue; }  // 隐藏字段剔除值
      this.visibility[id] = true;
      // 值联动（计算字段）
      if (f.compute) this.values[id] = f.compute(this.values);
      // 跨字段校验
      for (const rule of f.validate ?? [])
        if (rule.cross && !evalCond(rule.expr, this.values))
          this.errors[id] = rule.msg;
      else delete this.errors[id];
    }
    return this.snapshot();
  }
  submitValues() {                             // 提交：剔除隐藏字段
    return Object.fromEntries(Object.entries(this.values)
      .filter(([k]) => this.visibility[k] !== false));
  }
  validateAll() {                              // 全量校验（含跨字段）
    // 依赖图拓扑序校验（先算值后校验）
  }
}
```

**评分点**:
- 依赖图（反向索引 deps）实现最小更新（只算依赖方）。
- 三类联动齐全：显隐/计算值/必填动态（visibleIf/compute）。
- 隐藏字段提交剔除 + 值清除（防脏数据提交）。
- 跨字段校验（cross 规则）与依赖序。
