## SCN-359：在线表格自动化（当单元格变更则执行动作的规则引擎）怎么实现？

**答**:
- 规则模型：when-then 规则（触发条件：字段变更/满足条件/定时；动作：通知/改字段/调 Webhook/创建任务），规则配置 UI（可视化 when-then 配置——SCN-243 动作编排复用），规则本身进 CRDT（团队共享规则——协同管理）。
- 执行架构：触发检测（表格变更事件流→匹配规则集——变更影响面匹配 SCN-477 复用）、执行位置（服务端执行——权威与可靠；前端只做配置与预览）、防循环（规则 A 改字段触发规则 B 改回字段——循环检测与抑制：同规则链深度上限）、幂等（同变更只触发一次）。
- 典型动作：通知（@负责人——SCN-346 引用联动）、字段自动化（状态联动：A 列改 B 列自动算）、Webhook（外部系统联动）、定时规则（每周一生成周报汇总行——AGT-449 调度复用）。
- 治理：规则执行日志（每次触发可查——排查自动化误操作）、规则测试（配置时试运行样例——before enable 验证）、权限（谁能建规则/规则影响范围）。

```javascript
// 规则定义
const rule = {
  when: { field: 'status', equals: 'done' },
  then: [{ type: 'notify', to: '{{owner}}',
    msg: '任务已完成' },
    { type: 'setField', field: 'closedAt', value: '{{now}}' }],
};
// 执行（服务端）：
tableChanges.on((chg) => {
  for (const r of rules.match(chg))
    if (!loopGuard(r, chg)) execute(r, chg);  // 防循环+幂等
});
// 日志：ruleExec.log(rule, chg, result)——可查可排障
// 测试：dryRun(rule, sampleRow) → 预览效果。
```
