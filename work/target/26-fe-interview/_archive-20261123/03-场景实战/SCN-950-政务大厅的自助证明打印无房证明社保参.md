## SCN-950：政务大厅的自助证明打印（无房证明/社保参保证明）

**答**：
- 流程：身份核验 -> 查询（证照库/业务库）-> 生成 PDF（带电子章/验证二维码）-> 打印。
- 防伪：证明带验证二维码（扫码验证真伪与有效期）。
- 频次：高频证明免预约直接打（即办即走）。

```javascript
// 证明打印
async function printCertification(certType, identity) {
  const data = await api('/cert/generate', { type: certType, identity });
  const pdf = await renderCertPDF(data, { seal: data.sealUrl,
    qr: verifyUrl(data.verifyToken) });
  await print(pdf);
  auditLog({ type: 'cert-print', certType, verifyToken: data.verifyToken });
}
// 扫码验证：verifyUrl 指向验证页（真伪+有效期即时核验）
```
