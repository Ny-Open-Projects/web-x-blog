## SCN-984：医院分诊台的智能预分诊（症状自查）

**答**：
- 自查：症状选择 -> 推荐科室（规则引擎：症状-科室映射）。
- 免责：推荐注明"仅供参考，以分诊台判断为准"。
- 效率：自查结果带入挂号（推荐科室预选，减少分诊台压力）。

```javascript
// 智能分诊
const SYMPTOM_DEPT = { '头痛': ['神经内科', '神经外科'],
  '胸闷': ['心内科'], '腹痛': ['消化内科', '普外科'] };
function preTriage(symptoms) {
  const counts = {};
  symptoms.forEach(s =>
    (SYMPTOM_DEPT[s] ?? []).forEach(d => counts[d] = (counts[d] ?? 0) + 1));
  const ranked = Object.entries(counts).sort((a, b) => b[1] - a[1]);
  return { recommend: ranked[0]?.[0] ?? '全科',
    alternatives: ranked.slice(1, 3).map(r => r[0]),
    disclaimer: '推荐仅供参考，以分诊台判断为准' };
}
```
