## SCN-525：多账户切换的状态隔离怎么做？
**答**：
- 状态空间隔离：所有账户维度的缓存 key 带 accountId（query key / store 分片），切换账户绝不复用旧数据；全局 store 用 per-account 命名空间。
- 请求隔离：切换时取消 in-flight 旧账户请求（AbortController），响应带 accountId 校验，防止旧响应覆盖新账户视图。
- 权限重置：切换后重新拉取功能权限与受限列表（不同账户权限不同），切换完成前禁用全部交易入口。
- UI 一致性：切换器在页面顶部常驻并高亮当前账户，防操作者误以为是 A 账户操作 B 账户——这是资损级 UX 缺陷。
- 追问钩子：SWR 缓存怎么清——`cache.delete(prefix+key)` 遍历或 `mutate` 全命名空间失效。

```javascript
function switchAccount(nextId) {
  abortAllInflight(prevId);                          // 取消旧账户请求
  queryClient.removeQueries({ queryKey: ['acct', prevId] }); // 或保留但隔离
  document.cookie = `active_acct=${nextId}`;
  return refetchPermissions(nextId).then(() => {
    queryClient.invalidateQueries({ queryKey: ['acct', nextId] }); // 全量失效刷新
  });
}
// 所有 useQuery 写法约束：queryKey 必须以 ['acct', accountId] 开头（lint 规则强制）
```
