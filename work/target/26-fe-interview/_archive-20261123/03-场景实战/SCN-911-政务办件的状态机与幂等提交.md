## SCN-911：政务办件的状态机与幂等提交

**答**：
- 提交防重：提交按钮防连点 + 幂等键（clientToken）服务端去重。
- 状态机：草稿→已提交→受理→办结/退回，各状态允许的操作不同（补正/撤回）。
- 断网处理：提交失败本地保存草稿，恢复后提示一键重提。

```javascript
// 幂等提交
async function submitItem(item) {
  const clientToken = item.clientToken ?? crypto.randomUUID();
  const r = await api('/items/submit', { ...item, clientToken });
  if (r.duplicated) return r.existing;               // 服务端去重返回原办件
  saveDraftClear(item.id);
  return r;
}
// 服务端：clientToken 唯一索引，重复提交返回首次结果
```
