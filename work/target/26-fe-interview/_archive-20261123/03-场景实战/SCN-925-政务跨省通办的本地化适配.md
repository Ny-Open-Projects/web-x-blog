## SCN-925：政务「跨省通办」的本地化适配

**答**：
- 差异：各地事项/材料/流程不同——按用户归属地加载本地事项配置。
- 实现：属地检测（IP/选择），切换属地后事项清单/表单 schema 更新。
- 兜底：属地未开通的事项展示引导（线下办理提示）。

```javascript
// 属地适配
async function loadByRegion(region) {
  const config = await api('/items/config', { region });
  if (!config.available)
    return { items: [], guide: `该事项请前往 ${config.offlineGuide} 办理` };
  return { items: config.items, formSchemas: config.schemas };
}
// 属地切换确认：切换后当前表单草稿按新属地 schema 校验
```
