## SCN-1101：物流运单的收件人信息纠错（姓名/电话错误件）

**答**：
- 纠错：电话空号/姓名错误件——客服联系商家核实（联系方式库），更正后续派。
- 沟通：多方沟通记录（商家/收件人/派件员）统一留痕。
- 效率：纠错模板化（常见错误类型快捷处理）。

```javascript
// 信息纠错
async function fixContact(waybill, issue) {
  const merchant = await contactMerchant(waybill);
  const corrected = merchant.correctedInfo;
  await api('/addr/fix', { waybill, corrected });
  auditLog({ type: 'contact-fix', waybill, issue,
    old: mask(waybill.receiver), new: mask(corrected) });
  return { redeliver: true };
}
```
