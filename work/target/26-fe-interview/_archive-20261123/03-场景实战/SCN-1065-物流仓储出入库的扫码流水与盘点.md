## SCN-1065：物流仓储出入库的扫码流水与盘点

**答**：
- 流水：扫码出入库（防错：SKU+库位双确认），流水不可改（审计）。
- 盘点：周期盘点任务（差异报表），盈亏审批流。
- 性能：离线扫码（断网缓存，恢复补传）。

```javascript
// 扫码流水
class ScanFlow {
  constructor() { this.buffer = []; }
  scan(sku, location, type) {
    const op = { sku, location, type, at: Date.now() };
    if (navigator.onLine) return api('/wms/scan', op);
    this.buffer.push(op);                              // 离线缓存
    return { offline: true };
  }
  async flush() {
    while (this.buffer.length)
      await api('/wms/scan', this.buffer.shift());
  }
}
addEventListener('online', () => flow.flush());
```
