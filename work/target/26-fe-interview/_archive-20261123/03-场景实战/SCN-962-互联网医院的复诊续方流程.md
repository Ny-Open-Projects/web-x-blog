## SCN-962：互联网医院的复诊续方流程

**答**：
- 流程：选择医生 -> 病情描述（历史处方引用）-> 医生开方 -> 药师审方 -> 配送。
- 限制：续方药品范围限定（慢病用药）、用量限制（不超过 30 天）。
- 前端：历史处方一键引用（修改用量）、用药提醒设置。

```javascript
// 续方校验
function refillCheck(rx, history) {
  const chronic = rx.items.every(i => i.chronic);     // 慢病药
  const days = rx.items.reduce((s, i) => s + i.days, 0);
  if (!chronic) return { ok: false, reason: '仅慢病用药支持续方' };
  if (days > 30) return { ok: false, reason: '续方用量不超过 30 天' };
  const lastRx = history.filter(h => h.overlap(rx)).pop();
  if (lastRx && Date.now() - lastRx.date < 25 * 86400_000)
    return { ok: false, reason: '距上次开方间隔不足' };
  return { ok: true };
}
```
