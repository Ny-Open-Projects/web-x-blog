## SCN-818：搜索联想场景综合收束
**答**：
- 交互主线：IME composing 守护、键盘导航单一 activeIndex、直达卡与建议词行为分离、无障碍 combobox 语义（SCN-805/806/811/812）。
- 数据主线：seq 竞态守卫 + abort、三层匹配（前缀/拼音/纠错）、LRU+TTL 缓存、前缀收敛预展示（SCN-804/811/804）。
- 服务主线：词源四层合并、降级链（本地历史兜底）、限流（1 字符不请求）、边缘缓存（SCN-803/809）。
- 度量主线：曝光去重按会话、归因 traceId 全链、采纳率反哺词质量、input-to-suggest 250ms 预算（SCN-807/810）。
- 面试答法：以「用户输入 app 三个字符」讲全链——composing 守护 → 防抖 seq 请求 → 缓存命中判断 → 服务端四源合并 → 高亮渲染 → 曝光埋点 → 采纳归因。

```javascript
const suggestMethodology = {
  interact: ['ime-guard', 'single-active', 'card-vs-query', 'combobox-a11y'],
  data: ['seq-guard', 'three-layer-match', 'lru-ttl', 'prefix-converge'],
  service: ['four-source-merge', 'local-fallback', 'rate-limit', 'edge-cache'],
  metrics: ['session-dedupe', 'trace-attribution', 'ctr-feedback', '250ms-budget'],
};
```
