## SCN-959：医院候诊队列的实时叫号（分诊台联动）

**答**：
- 队列：当前叫号/前方人数/预计等待（分诊台叫号驱动）。
- 提醒：前 3 位震动/语音提醒；过号规则（顺延 N 位）展示。
- 离场：临时离开登记（保留顺延一位）。

```javascript
// 候诊监控
function waitingRoom(queueNo) {
  let stopped = false;
  (async function tick() {
    while (!stopped) {
      const s = await api(`/queue/${queueNo}`).catch(() => null);
      if (s) {
        render(s);
        if (s.ahead <= 3) { vibrate(500); beep(); }
        if (s.called && !s.inRoom) showMissedPrompt();  // 过号处理
      }
      await sleep(10_000);
    }
  })();
  return () => stopped = true;
}
```
