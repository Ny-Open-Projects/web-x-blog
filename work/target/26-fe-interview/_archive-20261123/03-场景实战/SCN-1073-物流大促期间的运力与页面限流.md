## SCN-1073：物流大促期间的运力与页面限流

**答**：
- 大促：订单洪峰（爆单）——发货页限流（排队）、时效顺延公告。
- 前端：排队页（预计等待）、时效公告横幅（发货延迟说明）。
- 监控：下单成功率/发货积压量看板。

```javascript
// 大促限流
function promoThrottle(queueId) {
  return pollQueue(queueId, { interval: 3000,
    notice: '当前发货申请较多，请耐心等待',
    eta: queueEta(queueId) });
}
function queueEta(id) { return 5 * 60_000; }
// 时效公告：promoNotice('发货较平日延迟 1-2 天')
```
