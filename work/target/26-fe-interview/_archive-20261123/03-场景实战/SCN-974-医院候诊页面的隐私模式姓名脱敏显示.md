## SCN-974：医院候诊页面的隐私模式（姓名脱敏显示）

**答**：
- 展示：叫号屏与手机端姓名脱敏（张*三），全名仅分诊台可见。
- 联动：手机端显示全名（本人查看），公共屏脱敏。
- 合规：个人信息保护法最小化原则。

```javascript
// 候诊脱敏
function queueDisplay(name, context) {
  if (context === 'public-screen')
    return name.replace(/^(.).+(.)$/, '$1*$2');       // 张*三
  return name;                                         // 本人端全名
}
// 叫号语音：播报"请张先生到 3 诊室"（姓氏+称呼，不播全名）
```
