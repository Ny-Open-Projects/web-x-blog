## SCN-451：手写红包雨：canvas 粒子对象池、点击命中检测、领取幂等

**需求与边界**：
- 输入：活动配置（数量/时长）、点击事件；输出：红包雨渲染与领取。
- 边界要求：① canvas 粒子对象池（数量大不卡）；② 点击命中检测（红包包围盒）；③ 领取幂等（一红包一人一次）；④ 数量洪峰合并（>30/秒合并生成）。

**答**：
```javascript
class RedPacketRain {
  constructor(canvas, config) {
    this.ctx = canvas.getContext('2d');
    this.particles = []; this.pool = [];       // 对象池
    this.spawnCount = config.count;
    this.spawnRate = Math.min(config.count /
      config.durationMs * 1000, 30);           // 洪峰上限 30/s
    this.loop();
  }
  spawn() {
    const p = this.pool.pop() ?? { };          // 池复用
    Object.assign(p, { x: rand(w), y: -50,
      vy: rand(200, 350), grabbed: false });
    this.particles.push(p);
  }
  loop() {
    requestAnimationFrame(() => {
      if (active && this.particles.length < cap)
        for (let i = 0; i < this.spawnRate / 60; i++) this.spawn();
      this.ctx.clearRect(0, 0, w, h);
      this.particles = this.particles.filter(p => {
        p.y += p.vy / 60;
        drawPacket(this.ctx, p);
        if (p.y > h) { this.pool.push(p); return false; }  // 落底回池
        return true;
      });
      active ? this.loop() : null;
    });
  }
  async grab(x, y) {                           // 命中检测
    const hit = this.particles.find(p =>
      !p.grabbed && x > p.x && x < p.x + 60 &&
      y > p.y && y < p.y + 80);
    if (!hit) return;
    hit.grabbed = true;
    const r = await api.grab(hit.packetId,
      { idempotencyKey: `${hit.packetId}:${me.id}` });  // 幂等
    showResult(r);                             // 中/未中
    this.pool.push(hit);
  }
}
```

**评分点**:
- canvas 粒子+对象池（落底回池）性能正确。
- spawnRate 上限洪峰合并（30/s cap）。
- 命中检测（包围盒）+ grabbed 标记防重复点击。
- 领取幂等键（红包×用户）。
