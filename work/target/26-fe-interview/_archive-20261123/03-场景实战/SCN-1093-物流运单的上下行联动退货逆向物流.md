## SCN-1093：物流运单的上下行联动（退货逆向物流）

**答**：
- 逆向：退货申请 → 上门取件预约（与正向发货共用运力）→ 仓库签收 → 退款触发。
- 状态：退货物流状态与退款状态联动（签收即触发退款审核）。
- 凭证：退货面单免贴（电子码核验）。

```javascript
// 逆向物流
async function returnPickup(returnId, slot) {
  const r = await api('/return/pickup', { returnId, slot });
  return {
    waybill: r.waybill, eCode: r.eCode,                // 电子码免贴面单
    onDelivered: () => triggerRefundCheck(returnId),   // 签收联动退款
  };
}
function triggerRefundCheck(id) { return api('/refund/check', { returnId: id }); }
```
