## SCN-943：政务大厅自助机的无障碍硬件适配

**答**：
- 硬件：高度可调（轮椅可达）、盲文按钮/语音导航、放大镜功能。
- 交互：大按钮（> 48px）、高对比、语音确认关键操作。
- 合规：GB/T 无障碍标准走查。

```javascript
// 自助机无障碍
const KIOSK_A11Y = {
  minTouch: 48,                                       // px
  contrast: 'AAA',
  voiceGuide: true,                                   // 关键步骤播报
  brailleKey: true,                                   // 盲文按键
  reachable: '≤1.2m',                                 // 轮椅可及高度
};
function kioskCheck(cfg) {
  return Object.entries(KIOSK_A11Y)
    .filter(([k, v]) => cfg[k] !== v && cfg[k] !== true)
    .map(([k]) => `不达标: ${k}`);
}
```
