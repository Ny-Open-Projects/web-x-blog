## SCN-1270：国际电商的商品视频多语言（字幕/配音）

**答**：
- 字幕：商品视频多语言字幕（VTT 分语言），自动翻译字幕标注。
- 配音：AI 配音（重点市场），原声+字幕兜底。
- 加载：字幕懒加载（切换语言才拉对应 VTT）。

```javascript
// 视频多语言
function videoSubs(videoId, langs) {
  return langs.map(l => ({
    lang: l, src: `/videos/${videoId}/subs/${l}.vtt`,
    lazy: true, machine: !REVIEWED.has(l),
  }));
}
const REVIEWED = new Set(['en', 'de']);
```
