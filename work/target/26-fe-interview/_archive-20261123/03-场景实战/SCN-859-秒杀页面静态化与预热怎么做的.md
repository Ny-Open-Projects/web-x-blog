## SCN-859：秒杀页静态化与预热怎么做？
**答**：
- 页面静态化：秒杀页 HTML/JS/CSS 提前构建发布 CDN（活动配置版本化），动态数据（库存/价格）单独接口——页面骨架零服务端计算。
- 资源预热：CDN 预热（活动前推送资源到边缘节点）、客户端预热（SCN-856 预备态）、DNS/连接预热（提前建立 keep-alive 连接）。
- 接口预热：核心接口（库存/下单）在正式流量前用压测流量预热缓存与连接池。
- 版本冻结：活动开始前 24h 页面冻结（只允许紧急 bug 修复走灰度），防止最后改动引入事故。
- 追问钩子：为什么动态数据要拆出静态页——静态页可全链路缓存（CDN 命中率高、TTFB 低），动态数据小接口易扩容；混在一起则页面无法缓存，全部流量打源站。

```javascript
const warmup = {
  static: { cdnPrefetch: 'T-24h', pageFreeze: 'T-24h', configVersion: 'immutable' },
  dynamic: { apiSplit: ['/stock', '/buy'], cdnCache: 'no-store (动态小接口)' },
  client: { prefetchAt: 'start-5s', keepAlive: true, dnsPrefetch: true },
  drill: { loadTestAt: 'T-48h', target: '1.5× 预估峰值' },
};
```
