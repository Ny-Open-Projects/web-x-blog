## SCN-1030：出行场景的行程足迹与年度报告

**答**：
- 足迹：出行记录聚合（城市足迹图/年度里程/最常路线）。
- 报告：年度出行报告（可视化 H5，分享传播）。
- 隐私：足迹仅本人可见，分享图脱敏。

```javascript
// 年度报告
function annualTravelReport(trips, year) {
  const mine = trips.filter(t => t.year === year);
  return {
    trips: mine.length, cities: [...new Set(mine.map(t => t.toCity))].length,
    km: mine.reduce((s, t) => s + t.distanceKm, 0),
    topRoute: mode(mine.map(t => `${t.fromCity}-${t.toCity}`)),
    shareImg: true,                                    // 脱敏分享图
  };
}
function mode(arr) { const m = {}; arr.forEach(x => m[x] = (m[x] ?? 0) + 1);
  return Object.entries(m).sort((a, b) => b[1] - a[1])[0]?.[0]; }
```
