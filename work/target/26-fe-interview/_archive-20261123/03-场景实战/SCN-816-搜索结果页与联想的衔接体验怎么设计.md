## SCN-816：结果页与联想衔接怎么设计？
**答**：
- 零结果引导：无结果时展示「相关搜索建议」（来自联想词库同簇词）+ 放宽条件引导（去掉筛选）——联想与结果页共享词库形成闭环。
- 改词引导：结果页搜索框保留联想能力，用户改词时下拉沿用同一组件（上下文延续）。
- 采纳率闭环：联想词采纳后的搜索结果 CTR 反哺词质量（SCN-807 归因链路），低质量词降权。
- 跨页状态：结果页回退到搜索框时恢复上次联想状态（缓存保留，不重新请求）。
- 追问钩子：为什么零结果页要展示联想建议——零结果是流失点，联想建议把「搜索失败」转化为「重新发现」，是联想价值在结果页的延伸。

```javascript
function ZeroResult({ query }) {
  const related = useRelatedQueries(query);            // 同簇联想词
  return (
    <Empty>
      <p>没有找到「{query}」相关内容</p>
      <p>试试这些：</p>
      {related.map(r => <SuggestChip key={r.q} q={r.q} onClick={() => search(r.q)} />)}
      <FilterResetHint />
    </Empty>
  );
}
```
