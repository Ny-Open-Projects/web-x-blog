## SCN-1008：司机端订单推送的接单竞态处理

**答**：
- 竞态：订单同时推给多司机，先到先得（服务端原子抢单），客户端乐观 UI + 失败回退。
- 前端：接单按钮防连点，抢单失败（已被抢）即时提示下一单。
- 指标：接单响应时长（抢单到确认）。

```javascript
// 抢单竞态
async function grabOrder(orderId) {
  try {
    const r = await api('/order/grab', { orderId });   // 服务端原子
    showOrder(r);
    return { ok: true };
  } catch (e) {
    if (e.code === 'TAKEN') { toast('订单已被抢'); return nextOrder(); }
    throw e;
  }
}
// 客户端乐观：点击立即置灰，失败恢复
```
