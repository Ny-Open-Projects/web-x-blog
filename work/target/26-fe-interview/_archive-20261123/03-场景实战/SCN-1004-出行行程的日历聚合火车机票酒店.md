## SCN-1004：出行行程的日历聚合（火车/机票/酒店）

**答**：
- 聚合：多来源订单行程聚合到统一日历（出发时间/地点/凭证入口）。
- 数据：各平台同步（授权导入邮箱/平台 API），解析去重。
- 体验：行程卡片（出发倒计时/值机入口/延误状态）。

```javascript
// 行程聚合
function tripCalendar(trips) {
  return trips
    .map(t => ({ ...t, startTs: depTime(t), type: t.kind }))   // train/flight/hotel
    .filter(dedupeByRoute())
    .sort((a, b) => a.startTs - b.startTs);
}
function depTime(t) { return t.kind === 'hotel' ? t.checkinAt : t.departAt; }
function dedupeByRoute() {
  const seen = new Set();
  return t => { const k = `${t.kind}:${t.startTs}:${t.from}`; 
    if (seen.has(k)) return false; seen.add(k); return true; };
}
```
