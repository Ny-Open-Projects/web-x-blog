## SCN-292：多维表格（类似 Airtable）的表格/看板/日历多视图怎么设计？

**答**:
- 数据与视图分离：数据层（记录集：CRDT/服务端事实源）、视图层（视图=数据的一种投影配置：字段过滤排序分组+视图类型），同一数据源多个视图各自独立配置——视图配置本身也进协同（每人可建自己的视图）。
- 视图类型实现：表格视图（SCN-252 大表格复用）、看板视图（按分组字段分列：卡片拖拽改字段值——拖拽即编辑）、日历视图（日期字段映射）、画廊视图（首图字段）——视图类型注册表扩展。
- 协同细节：记录级实时（他人修改的单元格高亮闪现）、视图切换状态保持（各视图独立的滚动/筛选状态）、视图分享（只读视图链接——字段级权限裁剪）。
- 性能：视图投影计算（分组/排序在 Worker 或服务端）、视口渲染（各视图统一虚拟化基础）。

```javascript
// 视图 = 数据的投影配置
const view = { type: 'kanban',
  groupBy: 'status', fields: ['title','owner'],
  filter: { done: false } };
function project(records, view) {
  const visible = records
    .filter(r => matchFilter(r, view.filter))
    .sort(bySort(view.sort));
  return VIEWS[view.type].render(visible, view); // 分列/行/日历格
}
// 看板拖拽：卡片跨列 drop → record.status = targetCol
//   → CRDT 更新 → 所有视图 observe 同步。
// 视图配置也协同：viewConfig → Y.Map。
```
