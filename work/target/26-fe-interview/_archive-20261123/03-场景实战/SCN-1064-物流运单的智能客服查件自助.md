## SCN-1064：物流运单的智能客服（查件自助）

**答**：
- 自助：运单号查询即答（节点播报），人工兜底（复杂异常）。
- 意图：识别查询意图（查件/改地址/催件），改地址自助（条件校验：未派送前）。
- 满意度：会话结束满意度评价。

```javascript
// 查件机器人
async function trackBot(waybillNo, intent) {
  if (intent === 'track')
    return { text: nodesSummary(await getNodes(waybillNo)) };
  if (intent === 'change-address')
    return changeAddrAllowed(waybillNo)
      ? { text: '已为您改址', action: changeAddressForm }
      : { text: '包裹已派送，无法改址，可联系派件员' };
  return { transfer: true };                            // 转人工
}
function nodesSummary(nodes) { return nodes[nodes.length - 1].desc; }
function changeAddrAllowed(no) { return true; }
```
