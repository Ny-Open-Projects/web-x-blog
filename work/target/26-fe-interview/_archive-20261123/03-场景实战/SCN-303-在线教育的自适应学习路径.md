## SCN-303：自适应学习（根据掌握度推荐课程/练习）的前端怎么呈现？

**答**:
- 掌握度模型：知识点掌握度（正确率×难度加权——服务端计算），前端呈现掌握度雷达图/知识地图（强弱项可视化），掌握度随练习动态更新（每次作答后局部刷新）。
- 学习路径推荐：推荐引擎输出（薄弱知识点→推荐课程/练习），前端呈现"学习计划"（今日任务清单：复习 X/练习 Y——可跳过但要理由式设计：跳过记录影响后续推荐）、路径可视化（知识点依赖图：先修关系）。
- 练习闭环：错题驱动练习（错题本 SCN-301→针对性变式题）、间隔复习（艾宾浩斯：到期复习项提醒——到期队列）、难度自适应（连对升难度连错降——服务端定，前端呈现难度徽标）。
- 激励设计：学习报告（周报：时长/进步曲线）、成就体系（连续打卡/掌握徽章）、目标设定（目标驱动提醒）。

```javascript
function LearningPlan({ plan, mastery }) {
  return <>
    <RadarChart data={mastery} />             {/* 知识点掌握度 */}
    <TodayTasks items={plan.tasks}            // {type, target, reason}
      onSkip={(t) => recordSkip(t, 'not_interested')} />
    <KnowledgeGraph deps={plan.deps}          // 先修关系图
      current={plan.currentKp} />
  </>;
}
// 错题变式：mistakeBook → practiceApi.variant(qid)
// 间隔复习：dueList = items.filter(due(today)) → 首页提醒。
// 难度自适应：连对3 → server.upgrade() → 前端难度徽标。
```
