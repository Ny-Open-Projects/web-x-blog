## SCN-1053：物流运单跟踪页面的节点时间线设计

**答**：
- 节点：揽收→干线→分拨→派送→签收，每节点时间/网点/操作员（脱敏）。
- 异常：滞留/破损/退回节点标红 + 异常原因与处理建议。
- 实时：派送中节点实时位置（骑手轨迹）+ 预计送达时间段。

```javascript
// 运单时间线
function trackTimeline(waybill) {
  return waybill.nodes.map(n => ({
    ...n, operator: maskName(n.operator),
    status: n.type === 'abnormal' ? 'error' : 'done',
    advice: n.type === '滞留' ? '联系客服核实' : null,
  }));
}
// 派送轨迹：courierTrack(waybillId) 30s 刷新
```
