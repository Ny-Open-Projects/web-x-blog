## SCN-612：审批消息通知聚合怎么设计？
**答**：
- 聚合策略：同类事件（同一实例多次催办/多条待办）聚合成一条摘要通知（「你有 5 条新待办，其中 2 条即将超时」）；聚合窗口与上限由通知中心服务端控制。
- 渠道路由：紧急（超时风险高）走 IM 强提醒 + 短信；普通走站内 + 邮件摘要（每日一封）；用户可自定义偏好但关键通知不可关。
- 已读联动：IM 里的待办卡片点击跳转处理页，处理后回发「已处理」状态刷新卡片；站内红点与待办计数同源（同一事件流）。
- 免打扰：夜间/休假模式暂停普通通知（服务端侧过滤），超时类豁免。
- 追问钩子：通知已读状态与待办已处理状态是两回事——已读指用户看过通知，处理指业务动作完成，前端两个状态分开存。

```javascript
const NOTIFY_RULES = {
  aggregation: { window: 60_000, maxItems: 5, template: '你有 {n} 条新待办{overdue}' },
  route: (event) => {
    if (event.overdue) return ['im', 'sms'];       // 紧急双通道
    if (event.type === 'assigned') return ['im'];
    return ['inbox', 'email_digest'];              // 普通摘要
  },
  dnd: (user, event) => user.nightMode && !event.overdue,   // 免打扰豁免超时
};
```
