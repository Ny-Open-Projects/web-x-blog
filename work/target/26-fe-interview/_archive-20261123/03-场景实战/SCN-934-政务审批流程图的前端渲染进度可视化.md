## SCN-934：政务审批流程图的前端渲染（进度可视化）

**答**：
- 渲染：流程节点图（已过/当前/待办状态着色），泳道按部门分区。
- 交互：节点点击查看审批意见（有权限时）。
- 性能：节点 < 50 直接 SVG；大流程简化为阶段视图。

```javascript
// 流程图节点
function flowNodes(flow, currentStep) {
  return flow.steps.map((s, i) => ({
    id: s.id, name: s.name, dept: s.dept,
    status: i < currentStep ? 'approved'
      : i === currentStep ? 'processing' : 'waiting',
    comment: s.status === 'processing' ? s.latestComment : null,
    clickable: i <= currentStep,
  }));
}
```
