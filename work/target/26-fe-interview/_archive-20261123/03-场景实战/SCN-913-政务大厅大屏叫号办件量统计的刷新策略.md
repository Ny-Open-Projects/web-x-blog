## SCN-913：政务大厅大屏（叫号/办件量统计）的刷新策略

**答**：
- 数据分层：实时区（叫号 5s 刷新）+ 统计区（办件量 5 分钟）+ 公告区（手动推送）。
- 渲染：大屏低频全量更新（数据量小），动效克制（信息可读优先）。
- 断流：WS 断开显示"数据更新于 xx"并重连。

```javascript
// 大屏分区刷新
function bigScreenTicker(config) {
  const timers = config.zones.map(z => setInterval(async () => {
    try {
      const data = await api(z.api);
      renderZone(z.id, data);
      markFresh(z.id);
    } catch { markStale(z.id); }                     // 显示数据时间
  }, z.intervalMs));
  return () => timers.forEach(clearInterval);
}
// zones: [{ id: 'queue', api: '/queue/current', intervalMs: 5000 }, ...]
```
