## SCN-311：企业审批（低代码表单+流程编排+条件路由）怎么融合实现？

**答**:
- 表单与流程解耦：审批表单 schema（SCN-246 表单引擎复用：字段+校验+联动），流程定义（节点/条件路由：金额>5000 加签总监——条件表达式引用表单字段），两者通过字段引用绑定（路由条件读表单值）。
- 条件路由引擎：流程图配置（可视化节点连线）、条件表达式（表单字段对比——沙箱求值 SCN-241 复用）、动态节点（条件分支在运行时展开为实际路径——审批时间线只显示实际走过的节点）。
- 审批操作集成：SCN-254 审批交互复用（同意/驳回/转交/加签）、表单只读与驳回编辑切换、催办与超时自动升级（超时未审→自动提醒/上级接管）。
- 模板化沉淀：审批模板（请假/报销/采购模板：表单 schema+流程定义打包），模板市场（部门自定义模板复用），模板版本与存量实例兼容（改模板不影响进行中实例——实例锁定模板版本）。

```javascript
// 流程定义
const flow = {
  nodes: [{ id: 'n1', type: 'approval', assignee: '组长' },
    { id: 'n2', type: 'approval', assignee: '总监',
      condition: '{{amount > 5000}}' },
    { id: 'n3', type: 'finance' }],
};
// 运行时：evaluate(flow.nodes, formValues) →
//   实际路径 [n1, n3]（金额≤5000 跳过 n2）
// 时间线只渲染实际路径。
// 模板版本：instance.lockTemplateVersion = v3
//   （模板升级不影响进行中实例）。
// 超时：schedule(n, { sla: 48h }) →
//   提醒 → 升级上级接管。
```
