## SCN-1046：出行场景的车站大屏信息（检票口变更实时性）

**答**：
- 变更：检票口临时变更 -> 大屏+App 推送双通道（信息一致性保证）。
- 实现：变更事件广播（车站系统->大屏/客户端），延迟 < 5s。
- 冗余：大屏离线时静态兜底信息（最后已知检票口）。

```javascript
// 检票口变更
function gateChangeBroadcast(schedule, newGate) {
  broadcastScreen(schedule.station, { gate: newGate, schedule: schedule.no });
  pushPassengers(schedule.booked, { text: `${schedule.no} 检票口变更为 ${newGate}` });
  return { latency: '<5s',
    fallback: '大屏显示最后已知检票口' };
}
```
