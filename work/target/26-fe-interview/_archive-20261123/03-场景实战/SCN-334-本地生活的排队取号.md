## SCN-334：到店排队取号（远程取号/进度推送/过号处理）怎么实现？

**答**:
- 取号流程：远程取号（到家/公司取号——到店时间预估：当前排队数×均时）、取号凭证（号码+二维码——到店确认）、排队进度（前方桌数实时更新：WS 推送+轮询兜底）。
- 过号与顺延：过号规则透明（叫号后 N 分钟未到作废或顺延——规则展示）、过号预警（"前方 2 桌，预计 15 分钟，请提前到店"——预警推送）、重新排队（过号后重新排或罚后）。
- 进度呈现：进度条与可视化（我的号码 vs 当前叫号——差值可视化）、等待时打发时间（等位小游戏/菜单预点——点菜提前做）。
- 数据一致性：排队数以门店端为准（离店距离检测：太远提醒"您距离门店 3km，过号风险"——定位联动 SCN-263）、取消排队（随时取消+信用提示）。

```javascript
async function takeNumber(storeId, size) {
  const r = await queueApi.take({ storeId, size });
  queueStore.set(r);                          // {no, ahead, eta}
  ws.subscribe(`queue:${r.id}`);              // 进度推送
}
ws.on('queue_progress', ({ ahead }) => {
  ui.ahead = ahead;
  if (ahead <= 2 && distTo(store) > 1000)
    push('您前方仅 2 桌，请尽快到店');        // 过号预警
});
// 过号：ws.on('missed') → 顺延规则说明 + 重排按钮。
// 预点菜：排队中打开菜单（提前下单到店即吃）。
```
