## SCN-361：在线会议室页（入会流程/设备检测/布局切换）怎么设计？

**答**:
- 入会流程：入会前预检（设备检测页：麦克风/摄像头/扬声器测试——权限缺失引导、网络测速预估质量），入会方式（直接加入/等候室（主持人准入）——准入状态轮询），入会后身份（主持人/参会者能力差异）。
- 设备管理：设备切换（SCN-239 replaceTrack 复用）、音量与静音（本地静音/全员静音、说话检测驱动头像高亮——audio level 检测）、设备故障引导（无声→扬声器检测面板）。
- 布局系统：布局模板（宫格/聚焦（主讲大屏）/侧栏——按人数与发言状态自动切换），焦点切换（谁说话谁大屏——音量驱动 focus 或手动 pin），屏幕共享布局（共享大屏+人像小条）。
- 会议控制：成员管理（静音/移出/邀请）、录制状态指示（合规指示灯）、会议锁（锁定后不可加入）、举手/表情（SCN-233 复用）。

```javascript
// 入会预检
async function precheck() {
  const { mic, cam, speaker, net } = await detectDevices();
  renderChecklist({ mic, cam, speaker, net });
  if (!mic) guide('允许麦克风权限');
}
// 说话检测：audioLevel(track) > threshold →
//   highlight(speaker) → focusMode && focus(speaker)
// 布局：layoutEngine.apply('grid' | 'focus' | 'share',
//   { count, pin, sharing }) 带过渡动画。
// 等候室：ws.on('admitted') → join()；轮询兜底。
```
