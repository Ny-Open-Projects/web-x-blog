## SCN-779：审核员培训与考核怎么设计？
**答**：
- 上岗路径：标准学习 → 模拟审核（历史标注样本）→ 上岗考核（盲测达标）→ 试用期带质检加权 → 转正。
- 案例教学：用真实历史案例（已脱敏）做练习，错题自动归类（哪类标准理解偏差）定向补课。
- 标准变更再认证：重大标准变更后全员再考核（未通过不派受影响品类任务，SCN-770 联动）。
- 培训效果度量：模拟审核准确率 vs 上岗后真实准确率的相关性——校准培训题库有效性。
- 追问钩子：为什么培训要用真实案例而不是编题——真实案例带真实模糊性（边界样本），编题往往过于典型导致考核失真；脱敏后真实案例是唯一可信题源。

const training = {
  path: ['standard-learning', 'mock-review', 'certification', 'probation', 'full'],

  weakspots: (errors) => clusterByRule(errors),      // 错题归类定向补课
  recalibrate: (stdVersion) => requireCert(stdVersion, { blocking: true }),
