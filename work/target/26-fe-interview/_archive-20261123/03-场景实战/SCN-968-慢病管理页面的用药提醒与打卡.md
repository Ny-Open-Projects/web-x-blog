## SCN-968：慢病管理页面的用药提醒与打卡

**答**：
- 提醒：用药时间表（早/中/晚 餐前餐后）本地通知推送。
- 打卡：服药打卡（连续记录/漏服统计），数据同步给医生端（复诊参考）。
- 坚持激励：连续打卡天数展示（非游戏化过度，医疗场景克制）。

```javascript
// 用药提醒
function medicationReminders(plan) {
  return plan.items.map(item => ({
    time: item.time,
    notify: scheduleLocalNotify({ time: item.time,
      text: `${item.name} ${item.dosage}（${item.before ? '餐前' : '餐后'}）` }),
  }));
}
// 漏服统计：
function adherenceLog(logs, plan) {
  const expected = plan.items.length * days(plan);
  const taken = logs.filter(l => l.taken).length;
  return { adherence: +(taken / expected * 100).toFixed(1) + '%',
    missed: expected - taken };
}
```
