## SCN-273：主播讲解切换商品时，观众端商品卡片怎么联动？

**答**:
- 联动通道：商品切换信令（主播端操作→信令广播：goodsId+动作 show/hide/强调），观众端卡片更新（当前讲解商品卡：图/价/券/按钮）——信令与弹幕通道分离（商品切换是高优先级低频消息）。
- 数据预载：商品清单开播前下发（直播间商品池一次拉取），切换时本地取数据渲染（零延迟——不从网络拉）、商品详情懒加载（点开小 hawk 才拉详情）。
- 购买链路：点击卡片→半屏商品详情（不离开直播间——保持拉流）→加购/下单（轻量下单浮层）——直播间内闭环，购买动作不打断观看。
- 状态一致：信令丢失兜底（观众端心跳带当前 goodsId，服务端纠偏）、主播秒杀价变更（价格更新信令，卡片价格实时变——价格以下单页为准的免责标注）。

```javascript
ws.on('goods_switch', async ({ goodsId, action }) => {
  const goods = roomGoodsPool.get(goodsId)   // 开播前预载的商品池
    ?? await fetchGoods(goodsId);
  action === 'show' ? showCard(goods)
    : action === 'hide' ? hideCard()
    : emphasize(goods);                      // 强调动效
});
// 信令丢失纠偏：每 10s 心跳上报 currentGoodsId，
//   服务端返回正确值 → 校正卡片。
// 购买闭环：showCard → 半屏详情 → 下单浮层（不离开直播）。
```
