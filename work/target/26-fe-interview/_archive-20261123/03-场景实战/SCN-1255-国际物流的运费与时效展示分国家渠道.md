## SCN-1255：国际物流的运费与时效展示（分国家/渠道）

**答**：
- 展示：分国家渠道（标准/快速/经济）运费+时效矩阵，关税预估（DDP/DDU 模式）。
- 限制：禁运品类按国家校验（收货国法规），超重/超尺寸分渠道限制。
- 体验：结算页实时试算（地址变更即刷新渠道矩阵）。

```javascript
// 国际运费矩阵
function shippingMatrix(country, pkg, channels) {
  return channels.map(c => ({
    channel: c.name, fee: c.calc(pkg, country),
    etaDays: c.eta[country] ?? c.eta.default,
    dutyMode: c.ddp ? 'DDP 含税' : 'DDU 需自行清关',
    banned: BANNED[country]?.some(b => pkg.categories.includes(b)),
  })).filter(c => !c.banned);
}
const BANNED = { US: ['电子烟'], DE: ['食品补充剂'] };
```
