## SCN-946：政务大厅大屏与自助机的内容分发系统

**答**：
- 内容：公告/政策/叫号信息统一 CMS，多终端（大屏/自助机/门户）分发。
- 调度：各屏位内容排期（时段/优先级）、紧急插播。
- 状态：终端心跳（在线/离线监控），内容版本一致性。

```javascript
// 内容分发
class ContentDistributor {
  constructor(terminals) { this.terminals = terminals; }
  publish(content, { screens, priority = 'normal' } = {}) {
    this.terminals.filter(t => screens.includes(t.screen))
      .forEach(t => t.pull(content));
    report({ type: 'content-publish', content: content.id,
      screens, priority });
  }
  health() {
    return this.terminals.map(t => ({ screen: t.screen,
      online: Date.now() - t.lastHeartbeat < 60_000,
      contentVersion: t.version }));
  }
}
```
