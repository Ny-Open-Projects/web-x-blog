## SCN-947：政务大厅的服务评价大屏（满意度实时展示）

**答**：
- 展示：今日满意率/评价数/差评处理率实时刷新（30s）。
- 隐私：不展示个人评价明细，只聚合。
- 激励：满意度与窗口绩效挂钩的展示设计（避免诱导好评的合规边界）。

```javascript
// 满意度大屏
function satisfactionBoard(today) {
  return {
    rate: +(today.good / (today.total || 1) * 100).toFixed(1) + '%',
    total: today.total,
    processed: +(today.badHandled / (today.bad || 1) * 100).toFixed(1) + '%',
    refresh: '30s',
    note: '只展示聚合数据，明细走内部系统',
  };
}
```
