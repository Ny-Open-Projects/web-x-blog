## SCN-1001：医疗场景的无障碍与适老化综合改造

**答**：
- 综合：挂号/问诊/查报告三大核心流程适老化走查（大字/语音/简化步骤）。
- 评估：老年用户任务完成率（改造前后对比）作为北极星。
- 工具：读屏走查 + 真实老年用户可用性测试。

```javascript
// 适老评估
function elderUsability(tasks, participants) {
  const results = participants.map(p =>
    tasks.map(t => ({ task: t.name, done: p.completed(t),
      timeSec: p.timeOf(t), help: p.neededHelp(t) })));
  return tasks.map((t, i) => ({
    task: t.name,
    completion: +(results.filter(r => r[i].done).length / participants.length * 100).toFixed(1) + '%',
    avgTimeSec: Math.round(avg(results.map(r => r[i].timeSec))),
    helpRate: +(results.filter(r => r[i].help).length / participants.length * 100).toFixed(1) + '%',
  }));
}
function avg(a) { return a.length ? a.reduce((s, v) => s + v, 0) / a.length : 0; }
```
