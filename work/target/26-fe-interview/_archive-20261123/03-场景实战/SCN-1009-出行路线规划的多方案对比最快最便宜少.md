## SCN-1009：出行路线规划的多方案对比（最快/最便宜/少换乘）

**答**：
- 方案：公交/驾车/步行多方案，字段（耗时/价格/换乘次数/步行距离）。
- 交互：方案切换（地图路径联动高亮）、偏好记忆（默认选上次偏好）。
- 实时：公交到站时间（剩余站数/分钟）嵌入方案。

```javascript
// 方案对比
function routeOptions(routes, prefs) {
  const scored = routes.map(r => ({
    ...r, score: r.durationMin * (prefs.fast ? 1 : 0) +
      r.price * (prefs.cheap ? 1 : 0) +
      r.transfers * (prefs.fewTransfer ? 1 : 0),
  }));
  return scored.sort((a, b) => a.score - b.score);
}
// 公交到站：busETA(stationId) 嵌入方案卡片，30s 刷新
```
