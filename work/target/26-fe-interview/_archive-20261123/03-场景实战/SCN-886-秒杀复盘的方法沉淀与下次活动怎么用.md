## SCN-886：方法沉淀怎么用？
**答**：
- 案例库结构：每场活动复盘条目（时间/规模/事故/改进/生效情况），按主题索引（性能/资损/风控/配置）——查问题先查库不重新踩坑。
- Checklist 生成：案例库中的教训自动转化为下场活动的 checklist 项（「上次 WS 断连降级慢 → 本次演练必测 WS 断连切换耗时」）。
- 度量沉淀效果：checklist 覆盖率 vs 实际事故重发率——同类事故重复出现说明沉淀流程失效。
- 知识保鲜：案例库每季度评审归档（过时案例标注「已由新机制覆盖」），防止 checklist 膨胀失焦。
- 追问钩子：为什么「事故重发率」是沉淀效果的终极指标——沉淀的价值唯一体现是不重犯；重发率不降说明复盘只在「写报告」没在「改机制」。

```javascript
const knowledgeLoop = {
  caseBase: { indexedBy: ['perf', 'loss', 'risk', 'config'], entries: perActivity() },
  checklist: (cases) => cases.unresolved.map(c => ({
    item: c.lesson, drill: c.relatedDrill, owner: c.owner })),
  effectiveness: { metric: 'same-root-incident-recurrence', target: 'downward-trend' },
  refresh: '季度评审归档',
};
```
