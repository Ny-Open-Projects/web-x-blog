## SCN-358：在线表格的选项列（下拉/级联/跨表引用列）怎么设计？

**答**:
- 列类型体系：列类型定义（文本/数字/日期/单选/多选/人员/附件/引用列——列级类型驱动单元格渲染与校验 SCN-352 编辑器分型复用），列配置协同（列类型与选项进 CRDT——列定义变更全员同步）。
- 单选/多选列：选项集（颜色标记选项——看板分组 SCN-292 复用）、选项增删（加选项即改列配置——影响面：存量单元格保持）、多选单元格渲染（标签堆叠）。
- 级联列：级联数据源（省市区/类目树级联——父选子选项过滤）、级联配置（父列绑定——父值变化子值校验清空）。
- 跨表引用列（Lookup）：引用另一表格的记录（关系列：关联表+关联字段，显示关联记录字段值）、引用更新联动（源表变更→引用列值自动更新——订阅源表变更）、反向关联（源表显示被引用计数）。

```javascript
// 引用列模型
const col = { type: 'lookup',
  relation: { table: 'orders', field: 'status' } };
function renderLookupCell(row) {
  const rel = row[col.key];                  // 关联记录 id
  return sourceTable.get(rel)?.[col.relation.field];
}
// 联动：sourceTable.observeDeep(() =>
//   refreshLookupCells());                   // 源变更刷新
// 级联：父列值变 → 子列选项过滤 + 不合法子值清空。
// 选项：列配置进 CRDT（SCN-229 表格模型扩展）。
```
