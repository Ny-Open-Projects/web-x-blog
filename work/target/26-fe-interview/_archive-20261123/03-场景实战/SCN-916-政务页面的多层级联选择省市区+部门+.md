## SCN-916：政务页面的多层级联选择（省市区+部门+事项）

**答**：
- 数据：级联懒加载（选省级拉市级）、缓存已选路径（返回保留）。
- 性能：部门/事项数量大时搜索替代逐级浏览（912）。
- 联动：选择部门后过滤事项清单。

```javascript
// 级联懒加载
async function cascadeSelect(level, parentId) {
  const cacheKey = `${level}:${parentId}`;
  const cached = cascadeCache.get(cacheKey);
  if (cached) return cached;
  const children = await api(`/region/${level}`, { parentId });
  cascadeCache.set(cacheKey, children);
  return children;
}
// 选择路径保留：返回时 restorePath(path)
```
