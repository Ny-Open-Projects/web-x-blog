## SCN-1256：国际支付的支付方式矩阵（本地化支付）

**答**：
- 矩阵：分国家支付方式（欧洲 iDEAL/Klarna、东南亚 GrabPay、日本 konbini）——按收货地址/用户 locale 过滤。
- 体验：默认支付方式记忆、本地化支付 UI（各通道差异封装 adapter）。
- 合规：PCI-DSS（卡信息不落前端）、3DS 验证（欧盟 SCA 强制）。

```javascript
// 支付矩阵
const PAY_METHODS = {
  DE: ['paypal', 'klarna', 'card', 'sepa'],
  JP: ['card', 'konbini', 'paypay'],
  BR: ['pix', 'boleto', 'card'],
};
function paymentOptions(country, amount) {
  return (PAY_METHODS[country] ?? ['card']).map(m => ({
    method: m,
    sca: country in EU && m === 'card' ? '3DS 必须验证' : null,
  }));
}
const EU = { DE: 1, FR: 1, NL: 1 };
```
