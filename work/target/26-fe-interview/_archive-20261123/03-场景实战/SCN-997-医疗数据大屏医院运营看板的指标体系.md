## SCN-997：医疗数据大屏（医院运营看板）的指标体系

**答**：
- 指标：门诊量/住院量/床位使用率/平均住院日/危急值闭环率——按科室下钻。
- 刷新：实时区（床位/候诊）5 分钟 + 统计区（日指标）小时级。
- 权限：科室看板仅本科室数据（918 模式）。

```javascript
// 运营看板
function hospitalOpsBoard(dept, data) {
  return {
    outpatient: data.outpatientToday,
    bedOccupancy: +(data.bedsUsed / data.bedsTotal * 100).toFixed(1) + '%',
    avgStay: data.avgStayDays + '天',
    criticalClosed: +(data.criticalClosed / (data.criticalTotal || 1) * 100).toFixed(1) + '%',
    drill: (kpi) => drillToDept(dept, kpi),            // 下钻
  };
}
```
