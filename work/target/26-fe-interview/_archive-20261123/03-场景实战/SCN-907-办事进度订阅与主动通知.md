## SCN-907：办事进度订阅与主动通知

**答**：
- 状态机：受理→审核→补正→办结，每个节点可订阅（短信/小程序订阅消息/站内信）。
- 前端：进度时间轴（节点/时间/预计剩余 SLA）、补正提醒（材料重新上传入口直达）。
- 防扰：合并通知（同事项多节点合并）、免打扰时段。

```javascript
// 进度时间轴
function renderTimeline(flow, currentStep) {
  return flow.steps.map((s, i) => ({
    ...s, status: i < currentStep ? 'done'
      : i === currentStep ? 'active' : 'pending',
    eta: i === currentStep ? `${s.slaHours}h 内` : null,
  }));
}
// 补正通知直达：
function notifyCorrection(item) {
  pushSubscribe({ tplId: 'correction', path:
    `/correction?itemId=${item.id}` });               // 点击直达补正页
```
