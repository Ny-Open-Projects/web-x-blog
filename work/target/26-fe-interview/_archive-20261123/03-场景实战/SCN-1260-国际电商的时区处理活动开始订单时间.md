## SCN-1260：国际电商的时区处理（活动开始/订单时间）

**答**：
- 统一：服务端 UTC 存储，前端展示用户本地时区（Intl.DateTimeFormat timeZone）。
- 活动：活动开始时间展示双时区（本地+站点基准）。
- 坑：夏令时切换（DST）——用 UTC 计算，禁止本地时间加减小时。

```javascript
// 时区处理
function localTime(utcTs, tz) {
  return new Intl.DateTimeFormat(undefined, { timeZone: tz,
    dateStyle: 'medium', timeStyle: 'short' }).format(new Date(utcTs));
}
function countdownTo(utcTs, now = Date.now()) {
  return Math.max(0, utcTs - now);                   // 全用 UTC 计算差值
}
```
