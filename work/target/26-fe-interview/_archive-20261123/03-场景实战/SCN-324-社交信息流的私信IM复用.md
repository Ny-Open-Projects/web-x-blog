## SCN-324：社交 App 私信（陌生人 IM/群聊/消息漫游）与工具 IM 的差异怎么处理？

**答**:
- 社交 IM 的差异需求：陌生人消息过滤（陌生人首条消息进请求箱——骚扰防护）、关注关系影响（互关才能图片视频——隐私分级）、消息撤回与截图提示（截图通知社交语境）、在线状态隐私（在线状态可关）。
- 复用 IM 基座：可靠投递/seq 有序/未读同步（SCN-213~215 全复用）、消息类型扩展（社交特有：卡片分享/语音条转文字/拍一拍等轻互动消息——消息协议可扩展）、会话分组（关注/陌生人/群分类）。
- 内容安全：图片视频审核（先审后发 vs 发后审核——社交尺度）、举报与拉黑（拉黑即断链：双向不可见+历史处理策略）、未成年人保护（青少年模式 IM 限制）。
- 漫游与多端：消息漫游（云端保存期策略——会员权益点）、多端同步（SCN-215 复用）、撤回同步（217 复用）。

```javascript
// 陌生人过滤
ws.on('msg', (m) => {
  if (isStranger(m.from) && !hasHistory(m.from)) {
    requestBox.add(m);                       // 首条进请求箱
    return;
  }
  normalInbox(m);
});
// 隐私分级：canSendMedia = mutualFollow(from)  // 互关才可图视
// 拉黑：block(from) → 双向不可见 + 历史本地清除策略
// 漫游：pullHistory({ days: user.vip ? 365 : 7 })
// 扩展消息：{type:'poke', ...} → 特效渲染，协议可扩展。
```
