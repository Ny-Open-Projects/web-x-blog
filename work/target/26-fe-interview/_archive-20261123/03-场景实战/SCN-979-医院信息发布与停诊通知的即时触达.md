## SCN-979：医院信息发布与停诊通知的即时触达

**答**：
- 通知：医生停诊/改期 -> 已挂号患者即时通知（短信+推送+改期引导）。
- 改期：一键改期到同医生其他时段（余号过滤）。
- 补偿：停诊导致损失的提示与补偿规则（优先挂号权）。

```javascript
// 停诊通知
function onScheduleCancel(schedule) {
  const patients = schedule.bookedPatients;
  patients.forEach(p => {
    notify({ to: p.uid, tpl: 'schedule-cancel',
      altSlots: schedule.altSlots(p.date) });          // 改期候选
  });
  report({ type: 'schedule-cancel', patients: patients.length });
}
// 改期引导：点击通知直达改期页，预选同医生同时段候选
```
