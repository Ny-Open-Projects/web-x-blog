## SCN-1085：物流仓库的拣货波次看板（进度监控）

**答**：
- 波次：波次进度（拣货/复核/打包各环节人数与完成率），瓶颈环节标红。
- 调度：人力调度建议（瓶颈环节加人）。
- 刷新：10s 轮询（PDA 上报驱动）。

```javascript
// 波次看板
function waveBoard(wave) {
  const stages = ['pick', 'check', 'pack'].map(s => ({
    stage: s, done: wave[s].done, total: wave[s].total,
    workers: wave[s].workers,
    rate: +(wave[s].done / wave[s].total * 100).toFixed(1) + '%' }));
  const bottleneck = stages.sort((a, b) => a.rate - b.rate)[0];
  return { stages, bottleneck: bottleneck.stage,
    suggest: `建议向 ${bottleneck.stage} 环节增派人力` };
}
```
