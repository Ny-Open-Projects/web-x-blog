## SCN-929：政务数据可视化大屏的适配（多种分辨率大屏）

**答**：
- 适配：大屏分辨率（1920×1080 / 3840×2160 / 拼接屏非标比例）——缩放策略（scale 等比 + 留白策略）。
- 布局：分区模块化（各屏位独立配置，支持轮播）。
- 性能：ECharts 按需注册 + 数据增量更新（setOption merge）。

```javascript
// 大屏缩放
function fitScreen(designW = 1920, designH = 1080) {
  const scale = Math.min(innerWidth / designW, innerHeight / designH);
  document.getElementById('screen').style.transform =
    `scale(${scale}) translate(${(innerWidth - designW * scale) / 2 / scale}px, 0)`;
  return scale;
}
addEventListener('resize', () => fitScreen());
```
