## SCN-928：政务大厅「最多跑一次」的流程再造前端配合

**答**：
- 核心：前置告知（材料清单/条件自检）+ 一次提交 + 缺件容缺受理。
- 自检：条件自查问卷（是否符合办理条件），不合格提前告知（减少空跑）。
- 容缺：缺非关键材料可受理（承诺补交），前端标注容缺项与补交期限。

```javascript
// 条件自检
function selfCheck(questionnaire, item) {
  const failed = questionnaire.filter(q => !q.answer);
  return { eligible: failed.length === 0,
    guide: failed.map(f => f.ineligibleReason),
    note: failed.length ? '不符合条件，展示原因与替代方案' : '进入申报' };
}
// 容缺受理标注：
const tolerateFields = schema.fields.filter(f => f.tolerable);
```
