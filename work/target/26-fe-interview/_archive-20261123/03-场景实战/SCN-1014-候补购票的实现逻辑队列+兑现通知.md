## SCN-1014：候补购票的实现逻辑（队列+兑现通知）

**答**：
- 候补：无票时提交候补订单（预付），有退票按候补顺序兑现，未兑现自动全额退款。
- 前端：候补队列位置/兑现概率提示（历史兑现率）、兑现成功强提醒（限时支付）。
- 截止：候补截止时间（发车前 6h）展示。

```javascript
// 候补订单
async function waitlistOrder(schedule, passengers) {
  const r = await api('/waitlist', { scheduleId: schedule.id,
    passengers, prepaid: schedule.price * passengers.length });
  return {
    no: r.no, position: r.position,
    successRate: schedule.historyFulfillRate,          // 历史兑现率
    deadline: schedule.departAt - 6 * 3600_000,
    onFulfilled: () => strongNotify('候补成功，请 30 分钟内完成支付'),
  };
}
```
