## SCN-987：医院检验危急值的闭环处理前端

**答**：
- 闭环：检验出危急值 -> 系统通知医生（10 分钟内确认）-> 处理记录 -> 闭环归档。
- 前端：危急值弹窗（强提醒+声音，不可关闭直至确认）、未确认升级（上报科主任）。
- 合规：危急值处理时限与记录是医疗质量考核项。

```javascript
// 危急值闭环
function criticalValueHandler(value) {
  return {
    alert: { sound: true, modal: true, dismissible: false,
      deadline: 10 * 60_000 },
    escalate: () => {                                  // 超时未确认
      notifyHeadDoctor(value);
      report({ type: 'critical-escalate', valueId: value.id });
    },
    confirm: (action) => api('/critical/confirm',
      { valueId: value.id, action, at: Date.now() }),  // 确认即闭环开始
  };
}
```
