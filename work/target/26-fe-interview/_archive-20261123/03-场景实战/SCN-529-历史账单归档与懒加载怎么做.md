## SCN-529：历史账单归档与懒加载怎么设计？
**答**：
- 冷热分层：近 12 个月走实时流水接口；更早历史走归档接口（月维度快照），入口区分「查询近一年流水 / 下载历史账单」。
- 归档不可变：归档月份展示时标注「已出账，不可变」，不出新推送更新；对账口径以归档为准。
- 懒加载与预取：默认加载当月，滚动跨月触发相邻月预取；年份切换用日期选择器直接定位，不做逐年全量拉。
- 下载优先：超长历史（3 年前）引导走导出任务（SCN-512），在线浏览只保留摘要（月合计），明细按需展开单月。
- 追问钩子：归档月与实时月交界处怎么衔接——归档月封口时生成「期末余额」，实时列表首行带「期初余额」对齐。

```javascript
async function loadMonth(ym) {
  if (isArchived(ym)) {
    const snap = await api.get(`/archive/${ym}`);  // { opening, closing, summary, items }
    return { ...snap, frozen: true, openingText: `月初余额 ${fenToYuan(snap.opening)}` };
  }
  return { ...await api.get('/flows', { params: { month: ym } }), frozen: false };
}
const prefetch = (ym) => requestIdleCallback(() => loadMonth(nextMonth(ym))); // 空闲预取相邻月
```
