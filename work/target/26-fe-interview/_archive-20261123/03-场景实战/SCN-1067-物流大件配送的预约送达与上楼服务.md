## SCN-1067：物流大件配送的预约送达与上楼服务

**答**：
- 预约：大件送达时间预约（2 小时时段），上楼/安装增值服务选择。
- 校验：电梯/楼道尺寸预检（家具能否进电梯），爬楼费规则展示。
- 变更：预约时段改期（配送前 4 小时）。

```javascript
// 大件预约
async function bulkyDelivery(orderId, slot, services) {
  const check = await api('/delivery/feasibility', { orderId,
    elevator: services.elevator });
  if (!check.fits) return { ok: false, reason: '楼道尺寸不足，需吊装',
    extraFee: check.craneFee };
  return { ok: true, slot, fee: baseFee + servicesFee(services) };
}
function servicesFee(s) { return s.carryUp ? 30 : 0; }
```
