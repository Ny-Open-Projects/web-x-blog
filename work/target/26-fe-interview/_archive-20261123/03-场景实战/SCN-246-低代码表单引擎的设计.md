## SCN-246：运营配置的动态表单（schema 驱动）引擎怎么设计？

**答**:
- 表单 schema：字段定义（type/label/必填/默认值/校验规则），布局描述（栅格/分组/显隐条件），联动规则（字段 A 值→字段 B 显隐/选项/必填变化——声明式 dependency）。
- 校验体系：声明式规则（required/pattern/range/custom 表达式），联动校验（跨字段：开始日期<结束日期），提交前全量校验（错误聚合呈现：字段级错误+顶部摘要）。
- 渲染与状态：schema→受控组件树，字段级状态（value/error/touched/disabled），性能（大表单只渲染可视字段组、校验防抖、联动最小化更新——只更新受影响字段）。
- 特殊能力：子表单/明细表（动态行增删）、分步表单（步骤间校验与暂存）、服务端校验回显（提交后服务端错误映射回字段）。

```javascript
// 表单 schema 示例
{
  fields: [{
    id: 'startDate', type: 'date', label: '开始日期', required: true,
  }, {
    id: 'endDate', type: 'date', label: '结束日期', required: true,
    deps: [{ on: 'startDate', rule: 'min', value: '{{startDate}}' }],
  }, {
    id: 'reason', type: 'textarea', visibleIf: '{{type === "other"}}',
  }],
}
// 引擎：FormEngine(schema) → 状态树 + 渲染 + 校验；
// 联动：dependency 图拓扑序更新（只更新受影响字段）；
// 提交：全量校验 → 服务端校验 → 错误回显字段级映射。
```
