## SCN-988：互联网医院的多方音视频会诊（医医会诊）

**答**：
- 音视频：医生间会诊（SFU 多方，病人病历共享屏幕）。
- 协同：会诊中病历/影像同屏标注（白板叠加影像）。
- 记录：会诊全程录制（合规留档）+ 意见结构化录入。

```javascript
// 医医会诊
function doctorConsult(session) {
  return {
    av: { sfu: true, max: 6, record: true },           // 录制留档
    share: { image: session.examImages, annotate: true },  // 影像标注
    opinion: structuredForm(['会诊意见', '建议检查', '建议用药']),
  };
}
```
