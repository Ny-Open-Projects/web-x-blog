## SCN-956：在线问诊的消息流设计（图文/语音/检查单）

**答**：
- 消息类型：文本/图片/语音/处方/检查建议——统一消息 schema。
- 时序：问诊会话 seq 有序（IM 模式 419）；医生侧快速模板回复。
- 状态：未读/已读、超时未回复提示（问诊时效 SLA）。

```javascript
// 问诊消息
const MSG_TYPES = ['text', 'image', 'audio', 'prescription', 'advice'];
function consultMessage(type, payload) {
  if (!MSG_TYPES.includes(type)) throw new Error('未知消息类型');
  return { type, payload, ts: Date.now(),
    sender: role(), seq: nextSeq() };
}
// 超时提醒：医生 5 分钟未回复 -> 患者侧提示"医生正在看诊，请稍候" + 转诊选项
```
