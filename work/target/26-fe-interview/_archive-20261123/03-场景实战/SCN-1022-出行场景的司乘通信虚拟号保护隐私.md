## SCN-1022：出行场景的司乘通信（虚拟号保护隐私）

**答**：
- 隐私：手机号虚拟化（中间号 AXB），双方通话不暴露真实号。
- 消息：内置 IM 快捷短语（"我到了""请稍等"）替代电话（降低通信成本）。
- 异常：虚拟号失效（行程结束）自动回收。

```javascript
// 虚拟号
async function virtualCall(rideId) {
  const { virtualNo } = await api('/ride/call', { rideId });   // AXB 中间号
  return { dial: virtualNo, expire: '行程结束回收',
    im: quickPhrases(['我已到达上车点', '请稍等 5 分钟', '车上稍等']) };
}
```
