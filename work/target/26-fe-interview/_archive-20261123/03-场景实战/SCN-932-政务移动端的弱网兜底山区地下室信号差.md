## SCN-932：政务移动端的弱网兜底（山区/地下室信号差）

**答**：
- 兜底：表单本地暂存（每字段变更即存）、弱网提示（提交前检测）、短信兜底通道（提交码）。
- 实现：在线状态监测（navigator.onLine + 请求失败判弱网），恢复后自动重传。
- 度量：弱网提交成功率（暂存恢复率）。

```javascript
// 弱网暂存
function weakNetFormGuard(formId) {
  const save = debounce(data =>
    localStorage.setItem(`draft:${formId}`, JSON.stringify(data)), 500);
  form.on('change', save);
  addEventListener('online', async () => {
    const draft = localStorage.getItem(`draft:${formId}`);
    if (draft && !submitted) {
      const ok = await confirmRedraft();
      if (ok) submit(JSON.parse(draft));
    }
  });
}
```
