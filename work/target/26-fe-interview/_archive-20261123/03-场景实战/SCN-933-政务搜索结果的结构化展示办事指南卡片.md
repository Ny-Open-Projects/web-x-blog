## SCN-933：政务搜索结果的结构化展示（办事指南卡片）

**答**：
- 卡片：事项名/办理条件/材料数/办理时限/入口按钮（在线办/预约/指南）。
- 一致性：卡片字段来自事项元数据（903），缺字段灰显。
- 可访问性：卡片标题为 heading 结构（读屏友好）。

```javascript
// 指南卡片
function guideCard(item) {
  return {
    title: item.name,
    fields: [
      { label: '办理时限', value: `${item.flow.reduce((s, x) => s + x.slaHours, 0)}h`, missing: !item.flow },
      { label: '材料', value: `${item.materials.length} 项` },
      { label: '是否可网办', value: item.onlineAvailable ? '是' : '否' },
    ].filter(f => f.value != null),
    actions: item.onlineAvailable ? ['online', 'book'] : ['guide'],
  };
}
```
