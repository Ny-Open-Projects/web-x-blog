## SCN-1090：物流运单的批量导出（财务对账格式）

**答**：
- 导出：运单明细导出（财务格式：运单号/重量/金额/日期），大数据量异步任务。
- 字段权限：导出列按角色（财务全列/客服部分列）。
- 校验：导出行数与查询数一致性校验。

```javascript
// 财务导出
async function exportFinance(filter, role) {
  const columns = role === 'finance' ? FULL_COLUMNS : RESTRICTED_COLUMNS;
  const { taskId, expectRows } = await api('/export/finance', { filter, columns });
  const rows = await pollExport(taskId);
  if (rows.count !== expectRows)
    report({ type: 'export-mismatch', expect: expectRows, actual: rows.count });
  return rows;
}
```
