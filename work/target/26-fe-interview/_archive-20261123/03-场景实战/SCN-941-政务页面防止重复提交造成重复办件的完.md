## SCN-941：政务页面防止「重复提交造成重复办件」的完整方案

**答**：
- 三层：按钮防连点（提交中禁用）、客户端幂等键、服务端业务约束（同事项同人进行中不可重复）。
- 提示：已有进行中办件时提前拦截（提交前查询）。
- 体验：重复办件检测提示引导查看原办件。

```javascript
// 重复办件拦截
async function guardDuplicate(item, user) {
  const existing = await api('/items/active', { itemId: item.id, uid: user.id });
  if (existing.length) {
    const view = await confirm(`已有进行中的办件（${existing[0].no}），是否查看？`);
    if (view) navigate(`/item/${existing[0].no}`);
    return false;
  }
  return true;
}
```
