## SCN-894：手写降级开关执行器

**需求与边界**：
- 需求：监听配置中心推送的降级档位（L1~L4），按矩阵切换模块（关模块/切轮询/静态兜底）；配置拉取失败保持当前安全态；档位回退（L3→L1）时恢复被关模块。
- 边界：① 档位只升不降除非显式回退指令；② 每次档位变化记录（谁触发/何时）；③ 配置签名校验（防篡改下发）。

**答**：
```javascript
function createDegradeExecutor(matrix, { verify } = {}) {
  let current = 'L0';                                  // L0 = 正常态
  function apply(level, { source, signature } = {}) {
    if (verify && !verify(signature)) return { rejected: 'BAD_SIGNATURE' };
    if (levelRank(level) < levelRank(current) && source !== 'rollback')
      return { rejected: 'ONLY_EXPLICIT_ROLLBACK' };   // 非显式回退不降档
    const prev = current;
    current = level;
    for (const [mod, action] of Object.entries(matrix[level] ?? {}))
      execute(mod, action);                            // 关模块/切轮询/兜底
    auditLog.write({ level, prev, source, ts: Date.now() });
    return { applied: level, from: prev };
  }
  // 配置失败保持安全态：fetch 失败不重置 current
  async function syncConfig() {
    try { const cfg = await fetchConfig(); apply(cfg.level, cfg); }
    catch { report({ type: 'DEGRADE_CONFIG_FAIL', keep: current }); }   // 保持现状
  }
  return { apply, syncConfig, get level() { return current; } };
}
const levelRank = (l) => ({ L0: 0, L1: 1, L2: 2, L3: 3, L4: 4 }[l] ?? 0);
```

**评分点**:
- 档位只升不降 + 显式回退通道（防误回退扩大故障）。
- 签名校验（防篡改下发，SCN-573 同源）。
- 配置失败保持当前态（安全默认，fail-safe）。
- 每次变化审计（谁/何时/从哪到哪）。
