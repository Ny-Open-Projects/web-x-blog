## SCN-1011：机票值机的在线选座实现

**答**：
- 选座：机舱布局模板（宽体/窄体），占座状态（已占/可选/锁定），选中校验（安全出口限制）。
- 限制：紧急出口排需符合条件（年龄/行动能力），付费座位价格标注。
- 体验：同行连座（1005 算法适配机舱列号 ABC-DEF）。

```javascript
// 机舱选座
function cabinSeatMap(cabin, taken, passenger) {
  return cabin.rows.map(row => ({
    row: row.no,
    seats: row.seats.map(s => ({
      ...s, status: taken.has(s.id) ? 'taken'
        : s.exitRow && !passenger.eligibleExit ? 'blocked'   // 安全出口限制
        : s.paid ? `paid-${s.price}` : 'free',
    })),
  }));
}
```
