## SCN-293：会议纪要（录音转写+摘要生成+协同编辑）怎么一体化实现？

**答**:
- 三段管线：录音上传（分片上传大音频 SCN 断点续传复用）→ 转写任务（异步：进度可查——ASR 转写分钟级耗时，任务中心模式 AGT-449）、转写完成→AI 摘要（议题/结论/行动项结构化）→ 纪要文档（可协同编辑，转写原文与纪要双栏关联）。
- 转写文本与音频对齐：段落级时间戳（点击纪要/原文段落→音频跳播对应时间——锚点回放，SCN-315 同源）、说话人分离标注（diarization 结果标注说话人，可手动修正归属）。
- 协同编辑：纪要正文多人编辑（SCN-221 CRDT 复用）、行动项提取为任务（一键转任务分配——与任务系统打通）、修正回流（用户修正转写错字→修正记录用于 ASR 优化）。
- 隐私与合规：录音告知与同意（参会者知情）、敏感会议不入库（SCN-315 同款纪律）、转写内容访问权限跟随会议权限。

```javascript
async function createMinutes(meetingId) {
  const upload = await chunkUpload(recording);  // 分片上传
  const task = await asrApi.create(upload.id);  // 转写任务
  taskCenter.add(task);                         // 异步进度
  const done = await pollTask(task.id);
  const summary = await aiApi.summarize(done.transcript,
    { schema: ['议题','结论','行动项'] });
  const doc = await createDoc({                 // 协同纪要
    title: `纪要：${meeting.title}`,
    content: summary, transcript: done.segments,
  });
  return doc;   // 双栏：纪要↔原文锚点跳播
}
// 锚点：segment {startMs} → audio.currentTime = startMs
// 行动项：summary.actions → 一键转任务（assignee/deadline）。
```
