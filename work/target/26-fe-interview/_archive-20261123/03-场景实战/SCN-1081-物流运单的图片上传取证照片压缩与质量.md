## SCN-1081：物流运单的图片上传（取证照片）压缩与质量

**答**：
- 上传：取证照片（签收/破损）压缩（质量 0.8 + 尺寸上限 1280px），批量上传队列。
- 质量：保证可辨认（文字/标签区域不过度压缩）。
- 失败重试：弱网队列（离线缓存补传）。

```javascript
// 取证照片上传
async function evidenceUpload(photos, rideId) {
  const compressed = await Promise.all(photos.map(p => compressImage(p, {
    maxW: 1280, quality: 0.8, keepText: true })));     // 保留文字清晰
  return uploadQueue(compressed, { retries: 3 });
}
async function compressImage(p, o) { return p; }
async function uploadQueue(items, o) { return items.length; }
```
