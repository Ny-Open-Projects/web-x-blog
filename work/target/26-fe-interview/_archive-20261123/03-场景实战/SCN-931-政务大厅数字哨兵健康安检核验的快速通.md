## SCN-931：政务大厅数字哨兵（健康/安检核验）的快速通过

**答**：
- 场景：入厅核验（健康码/身份证刷卡/人脸）——核验速度决定通行效率。
- 实现：读卡即查（< 500ms 结果）、异常处理（设备离线降级人工核验）。
- 体验：核验结果大屏反馈（绿/黄/红 + 提示音）。

```javascript
// 快速核验
async function gateCheck(idCard) {
  const t0 = performance.now();
  try {
    const r = await Promise.race([
      api('/gate/verify', { idCard }),
      sleep(500).then(() => ({ offline: true })),
    ]);
    if (r.offline) return { pass: 'manual', note: '设备离线转人工核验' };
    report({ type: 'gate-verify', ms: performance.now() - t0, pass: r.pass });
    return r;
  } catch { return { pass: 'manual' }; }
}
```
