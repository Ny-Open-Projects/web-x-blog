## SCN-1037：出行场景的行程实时轨迹分享（家人守望）

**答**：
- 分享：行程实时轨迹链接（有效期=行程+30 分钟），查看方仅见位置不司乘信息。
- 权限：一次性链接（转发无效）、访问留痕（谁在什么时候看了）。
- 安全：轨迹偏移报警（路线异常通知紧急联系人）。

```javascript
// 轨迹分享
function trackShare(ride) {
  const token = genOneTimeToken(ride.id, { ttlMs: ride.etaMs + 30 * 60_000 });
  return {
    url: `/track/${token}`,
    access: 'view-only',                               // 不含司乘信息
    anomaly: () => offRouteAlarm(ride, token),         // 偏航报警
    audit: logViewerAccess(token),
  };
}
function genOneTimeToken(id, o) { return 'tk_' + id; }
function offRouteAlarm(ride, token) { return true; }
function logViewerAccess(token) { return true; }
```
