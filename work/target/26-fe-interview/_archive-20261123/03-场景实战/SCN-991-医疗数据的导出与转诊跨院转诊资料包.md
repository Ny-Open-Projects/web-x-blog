## SCN-991：医疗数据的导出与转诊（跨院转诊资料包）

**答**：
- 转诊：导出转诊资料包（病历摘要/关键报告/用药史）加密传输至目标医院。
- 授权：患者授权转诊（范围/有效期），转诊全程留痕。
- 格式：标准化健康档案格式（HL7 FHIR 理念），接收方可解析。

```javascript
// 转诊资料包
async function referralPackage(patientId, targetHospital, scope) {
  const data = await collectRecords(patientId, scope);
  const encrypted = await encryptFor(data, targetHospital.publicKey);
  const r = await api('/referral/send', { target: targetHospital.id,
    payload: encrypted, patientConsent: true });
  auditLog({ type: 'referral', patient: hash(patientId), target: targetHospital.id });
  return r;
}
```
