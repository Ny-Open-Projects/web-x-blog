## SCN-1102：物流场景前端收口（准确/透明/效率/合规）

**答**：
- 准确：地址解析（1058）/扫码防错（1065）/签收校验（1088）。
- 透明：时效进度（1066）/异常明示（1098）/ETA 预测（1082）。
- 效率：批量导入（1054）/排队（1099）/路径优化（1057）。
- 合规：隐私面单（1069）/位置隐私（1086）/取证留存（1061）。

```javascript
// 物流场景检查清单
const LOGISTICS_CHECK = [
  { id: 'addrParse', test: s => s.addrParseRate > 0.95 },
  { id: 'sla', test: s => s.slaRate > 0.95 },
  { id: 'privacy', test: s => s.privacyLabelRate === 100 },
  { id: 'scanAccuracy', test: s => s.misSortRate < 0.001 },
  { id: 'podArchive', test: s => s.podArchiveRate === 100 },
];
function logisticsAudit(signals) {
  return LOGISTICS_CHECK.filter(c => !c.test(signals)).map(c => c.id);
}
```
