## SCN-905：电子证照调用与材料免提交

**答**：
- 机制：用户授权 -> 调用省级证照服务拉取（身份证/社保卡/营业执照）-> 自动填充材料清单。
- 前端：证照列表展示（授权状态/有效期）、一键调用、调用失败降级为手动上传。
- 合规：调用留痕（谁/何时/用了哪个证照），授权可撤销。

```javascript
// 电子证照调用
async function fetchELicense(licenseType, item) {
  const granted = await checkGrant(licenseType);
  if (!granted) {
    const ok = await requestGrant(licenseType);       // 用户授权弹窗
    if (!ok) return { ok: false, fallback: 'manual-upload' };
  }
  const lic = await api('/elicense/fetch', { type: licenseType });
  await auditLog({ type: 'elicense-use', licenseType, item: item.id });
  return { ok: true, file: lic.fileUrl, expireAt: lic.expireAt };
}
```
