## SCN-1088：物流运单的签收码校验（防冒领）

**答**：
- 校验：贵重件签收需收件人验证码（短信下发），代收需登记代收人身份。
- 风险：无验证码签收的贵重件（风控标记），事后核查。
- 审计：签收全记录（验证码校验日志）。

```javascript
// 签收校验
async function signedDelivery(waybill, code) {
  if (waybill.valuable && !verifyCode(waybill, code))
    return { ok: false, reason: '签收验证码不匹配' };
  if (waybill.valuable && !code)
    return { ok: true, flag: 'risk',                   // 无码签收标记
      note: '贵重件无验证码签收，将事后核查' };
  return { ok: true };
}
function verifyCode(w, code) { return code === w.smsCode; }
```
