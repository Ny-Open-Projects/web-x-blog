## SCN-561：验证环节转化率怎么度量与优化？
**答**：
- 漏斗指标：曝光 → 开始拖动/输入 → 首次尝试通过 → 最终通过；分场景/验证器/机型统计，找流失最大环节。
- 失败归因：失败原因分布（答错/超时/中途放弃/风控拒绝）+ 耗时分布，区分「用户不会用」与「故意拦截」。
- 优化手段：可完成性（滑块容差放宽、重试不限次）、降难度实验（滑块 → 点选）、换验证器实验（A/B），以及减少曝光（无感验证优先）。
- 反向指标：验证通过率异常高（黑产过验证）或过低（误伤真人）都要告警，阈值由服务端基线动态给出。
- 追问钩子：优化转化与安全强度冲突怎么办——用「分段策略」：高分用户无感、可疑用户强验证，而非全量同一强度。

const funnel = metrics.funnel('pay', ['expose', 'interact', 'try', 'pass']);
funnel.report();   // { expose: 1000, interact: 920, try: 880, pass: 810 } => 81% 终转化
// 失败归因分布
