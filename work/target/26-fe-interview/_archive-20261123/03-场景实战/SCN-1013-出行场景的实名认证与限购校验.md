## SCN-1013：出行场景的实名认证与限购校验

**答**：
- 实名：乘车人列表管理（实名核验状态），未核验禁止购票。
- 限购：一人一证一车次一张（服务端强校验），学生票/儿童票规则前端预检。
- 体验：核验状态标注（待核验引导去核验）。

```javascript
// 乘车人校验
async function pickPassengers(selected, schedule) {
  const unverified = selected.filter(p => !p.verified);
  if (unverified.length)
    return { ok: false, guide: unverified, reason: '存在未核验乘车人' };
  const dup = selected.some(p => schedule.boughtIds.includes(p.id));
  if (dup) return { ok: false, reason: '同车次限购一张' };
  return { ok: true };
}
```
