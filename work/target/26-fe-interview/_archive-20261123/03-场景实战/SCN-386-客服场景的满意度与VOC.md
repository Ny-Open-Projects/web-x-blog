## SCN-386：客服满意度（CSAT）与 VOC（客户之声）的闭环怎么实现？

**答**:
- 满意度收集：评价时机（会话结束触发——不打断解决过程）、评价形式（评分+标签+开放题——SCN-284 评价复用）、低分拦截（差评→优先回访挽回——低分工作流）。
- VOC 分析：评价聚合（标签统计/开放题主题聚类——AGT-353 归因复用）、差评归因（产品问题 vs 服务问题分类——路由到不同团队）、趋势监控（满意度周报/下滑预警）。
- 改进闭环：问题→改进项（高频差评原因→知识库更新/产品改进单——AGT-353 闭环复用）、改进验证（同类问题满意度前后对比——闭环可验证）、客服反馈（一线洞察上报通道）。
- 数据一致性：评价的独立性与真实（客服不能诱导好评——合规）、低响应率纠正（抽样回访补充——样本偏差意识）。

```javascript
// 会话结束评价
session.on('resolved', () => csatSurvey({
  form: { score: 5, tags: TAGS, open: true } }));
// 低分拦截：score <= 2 → priorityCallback(customer)  // 回访
// VOC：clusterReviews(openAnswers) →
//   { product: [...], service: [...] } → 路由改进单
// 验证：beforeAfter(sameIssueRate) → 闭环效果。
// 防诱导：评价入口独立（客服不可见评价前状态）。
```
