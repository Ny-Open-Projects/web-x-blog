## SCN-785：审核移动端与紧急处置怎么支持？
**答**：
- 移动端定位：不做完整审核，做「紧急响应」——高危告警推送（直播违规/舆情爆发），移动端可执行「紧急下架/降权」两个动作，详细审核回 PC。
- 紧急处置安全：移动端处置需生物识别确认 + 双人复核（一人在端发起，另一人确认才生效）——防止误触和账号盗用。
- 舆情联动：舆情事件（某内容爆发传播）一键批量提审关联内容（转发/翻拍/同模板），移动端发起 PC 端执行。
- 推送分级：紧急处置推送不分时段（免打扰豁免），普通审核消息不发移动端。
- 追问钩子：为什么移动端处置要双人复核——移动环境（公共场合/误触）风险高，高危处置不可单人完成；双人复核把误操作率压到最低且责任可追溯。

```javascript
const mobileEmergency = {
  actions: ['emergency-takedown', 'reduce-weight'],
  guard: async (action, initiator) => {
    await biometric.verify(initiator);               // 生物识别
    const coSigner = await findOncallPeer(initiator);
    return coSigner.confirm(action);                 // 双人复核生效
  },
  batch: (event) => relatedContents(event).map(c => submitReview(c, 'P0')),
};
```
