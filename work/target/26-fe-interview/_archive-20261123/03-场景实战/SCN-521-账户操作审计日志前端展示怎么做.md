## SCN-521：账户操作审计日志前端展示怎么设计？
**答**：
- 事件模型：统一 auditEvent（操作者/动作/对象/时间/来源端/IP 脱敏），前端不识别各接口日志格式，映射层统一转时间线节点。
- 合并渲染：同对象连续操作（改手机号三步）聚合成一组，展开看子步骤；避免时间线刷屏。
- 排序与补漏：按 ts 排序，乱序到达（补录日志）插入正确位置；缺口的时段显示「加载中间记录」而非空白。
- 敏感处理：IP 只显示前两段，设备名指纹化；日志只读不可删，页面加防篡改水印。
- 追问钩子：审计日志和普通流水列表组件能否复用——数据模型不同（事件 vs 交易），但虚拟列表/分组层可复用。

```javascript
function mergeAudit(events) {                     // events 已按对象+动作可分组
  const groups = new Map();
  for (const e of events.sort((a, b) => a.ts - b.ts)) {
    const key = `${e.objectId}:${e.groupable ? e.actionGroup : e.id}`;
    if (!groups.has(key)) groups.set(key, { ...e, children: [] });
    else groups.get(key).children.push(e);        // 连续子步骤聚合
  }
  return [...groups.values()];
}
```
