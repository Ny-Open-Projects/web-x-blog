## SCN-614：审批代理委托怎么设计？
**答**：
- 委托模型：委托单（委托人/被委托人/范围：场景+金额上限/有效期），生效后待办自动分流到被委托人，原审批人仍可查看。
- 记录语义：时间线显示「张三（代李四审批）」，操作记录同时落 operator 与 principal——审计要求双向可查。
- 边界控制：金额超上限不委托（回到原审批人）；被委托人不能再转委托（禁止链式）；委托人提前销假可一键收回委托（回收后未处理的回到原人）。
- 提醒双方：委托生效/到期/收回双方都收到通知；被委托人的待办列表区分「我审批的」与「代理审批的」两个 Tab。
- 追问钩子：委托期间原审批人自己批了一条怎么算——有效，被委托人待办同步移除（同一实例幂等分流）。

```javascript
const DELEGATION_RULES = {
  create: (d) => d.amountCap > 0 && d.endTs > d.startTs && d.agentId !== d.ownerId, // 禁自委托
  canDelegate: (instance) => instance.amountFen <= instance.delegation.amountCap,   // 超上限回原人
  chainable: false,                              // 禁止链式转委托
  reclaim: async (d) => {                        // 收回：未处理待办回流
    const back = await api.post(`/delegation/${d.id}/reclaim`);
    notify(d.ownerId, 'reclaimed', back.count); notify(d.agentId, 'reclaimed', back.count);
  },
};
```
