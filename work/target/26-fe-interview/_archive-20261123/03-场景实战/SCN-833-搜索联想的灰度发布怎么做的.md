## SCN-833：联想灰度发布怎么做的？
**答**：
- 三层灰度对象：组件版本（前端构建产物按流量灰度）、排序策略（服务端配置灰度）、词库批次（数据灰度）——各自独立灰度通道与回滚开关。
- 前端组件灰度：SDK 化的搜索框按 CDN 版本灰度（与业务发版解耦，SCN-568 同模式）；错误率超阈值自动回切旧版本。
- 观察窗口：每层灰度 ≥ 3 天（覆盖工作日/周末行为差异），核心指标守门（采纳率/延迟/零结果率）。
- 紧急通道：线上坏词/事故一键回滚（词库回滚 < 1 分钟，组件回切 < 5 分钟）。
- 追问钩子：为什么词库回滚要 < 1 分钟——坏词上线是安全事故，回滚速度决定事故面积；词库变更天然支持按批次回滚，必须做到分钟级。

```javascript
const grayPipeline = {
  component: { cdnChannel: 'stable/beta', autoRollback: 'errorRate > 1%' },
  strategy: { configGray: true, window: '3d' },
  wordBatch: { pct: 0.1, rollbackSLO: '< 1min', trigger: 'manual or badWord' },
  gates: ['adopt_rate', 'latency_p95', 'zero_result'],
};
```
