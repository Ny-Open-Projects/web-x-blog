## SCN-1048：出行场景的电子围栏与合规运营（网约车合规提示）

**答**：
- 合规：网约车经营区域电子围栏（跨区域运营提示），证件到期预警（司机端）。
- 展示：跨城订单合规提示（目的地是否允许网约车运营）。
- 责任：合规风险前置告知（司机自主选择）。

```javascript
// 电子围栏
function operationFence(order, driver) {
  const inArea = fenceContains(order.toCity, driver.licenseArea);
  if (!inArea)
    return { warn: '目的地超出许可运营区域，请确认当地法规',
      proceed: driver.ackCrossCity };
  const expiring = driver.certExpireAt - Date.now() < 30 * 86400_000;
  return { warn: expiring ? '证件即将到期，请及时续期' : null };
}
function fenceContains(city, area) { return false; }
```
