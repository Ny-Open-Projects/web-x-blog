## SCN-1025：出行场景的多人拼车匹配（顺路度计算）

**答**：
- 匹配：起点终点顺路度（路径重叠率）+ 时间窗匹配，绕行上限（司机端设置）。
- 前端：拼友信息展示（脱敏）、上车点顺序展示。
- 计价：拼车价格分摊规则透明展示。

```javascript
// 顺路匹配
function matchCarpool(driver, riders) {
  return riders.map(r => ({
    rider: r.id,
    overlap: pathOverlap(driver.route, r.route),       // 路径重叠率 0~1
    detourMin: extraTime(driver.route, r.pickup),
  })).filter(m => m.overlap > 0.6 && m.detourMin < driver.maxDetour)
    .sort((a, b) => b.overlap - a.overlap);
}
function pathOverlap(a, b) { /* 路径相似度 */ return 0.7; }
function extraTime(route, point) { return 5; }
```
