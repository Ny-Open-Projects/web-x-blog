## SCN-906：政务动态表单引擎的设计（多部门表单差异大）

**答**：
- schema：字段类型（文本/日期/附件/级联选择）、校验规则、联动逻辑（显示条件/计算）、默认值来源（证照/用户信息）。
- 渲染：按 schema 生成控件，联动用表达式（条件求值沙箱防注入）。
- 版本：表单 schema 带版本，办件记录提交时快照（避免后续改表单影响历史件）。

```javascript
// 表单联动表达式沙箱
const SAFE_VARS = ['form', 'user'];
function evalCondition(expr, ctx) {
  const keys = Object.keys(ctx);
  if (/[;{}]|import|eval|Function/.test(expr)) return false;   // 黑名单
  try {
    return new Function(...SAFE_VARS, `"use strict"; return (${expr})`)(
      ...SAFE_VARS.map(k => ctx[k]));
  } catch { return false; }
}
// schema 示例：
// { field: 'income', visible: 'form.applyType === "low"' }
```
