## SCN-977：医院排班展示与号源联动的医生选择

**答**：
- 展示：医生排班表（出诊日期/号源量/剩余），按科室/职称筛选。
- 排序：剩余号多/职称高/距离近（用户偏好）。
- 详情：医生简介（擅长/患者评价摘要）辅助决策。

```javascript
// 医生选择
function doctorList(doctors, prefs = {}) {
  return doctors.map(d => ({
    ...d, score:
      (d.remain > 0 ? 2 : 0) +                          // 有号
      (d.title === '主任医师' ? 2 : d.title === '副主任医师' ? 1 : 0) +
      (prefs.dept && d.dept === prefs.dept ? 1 : 0),
  })).sort((a, b) => b.score - a.score);
}
```
