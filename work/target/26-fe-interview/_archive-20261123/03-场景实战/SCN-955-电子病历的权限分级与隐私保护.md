## SCN-955：电子病历的权限分级与隐私保护

**答**：
- 分级：患者本人（全量）/主治医生（诊疗范围内）/家属授权（部分）/其他（脱敏统计）。
- 前端：字段级掩码（952 模式）+ 访问留痕（谁看过我的病历）。
- 授权：家属授权（有效期+范围），可撤回。

```javascript
// 病历权限
const MEDICAL_CAPS = {
  self: ['all'], doctor: ['diagnosis', 'prescription', 'exam'],
  family: ['summary', 'prescription'],
};
function medicalAccess(viewer, record) {
  const caps = MEDICAL_CAPS[viewer.relation] ?? [];
  return {
    fields: Object.keys(record).filter(k =>
      caps.includes('all') || caps.some(c => record.fieldGroup?.[k] === c)),
    audit: true,                                       // 访问留痕
    masked: caps.length && !caps.includes('all') ? 'partial' : null,
  };
}
```
