## SCN-1034：出行场景的停车缴费无感支付

**答**：
- 无感：车牌识别+免密代扣（先离场后扣费），扣费通知即时推送。
- 风控：代扣限额/失败重试/余额不足提醒。
- 对账：停车费账单明细（时长/单价/优惠）可查。

```javascript
// 无感支付
function autoPayParking(entry, exit, plate) {
  const fee = parkingFee(entry, exit, plate.discounts);
  return { fee, pay: 'auto-deduct',
    notify: pushDeduct(fee),
    retry: fee.failed ? retryDeduct(3) : null,         // 扣费失败重试
    detail: { hours: parkingHours(entry, exit), plate: plate.no } };
}
function parkingFee(entry, exit, discounts) { return 15; }
function parkingHours(entry, exit) { return 2.5; }
function pushDeduct(fee) { return true; }
function retryDeduct(n) { return true; }
```
