## SCN-990：医院自助机的多语言支持（外籍患者）

**答**：
- 语言：英文/日文核心流程翻译（挂号/缴费/报告），术语准确性（医学术语库）。
- 切换：语言切换全局生效（记忆偏好），翻译缺失回退中文。
- 翻译：术语库由医务审核（机器翻译仅辅助）。

```javascript
// 医疗多语言
const i18n = createI18n({
  fallback: 'zh',
  terms: loadMedicalTerms,                             // 医学术语库（医务审核）
});
function bilingualLabel(zh, en) {
  return i18n.lang === 'en' && en ? en : zh;
}
// 示例：抽血 -> Blood Test（审核过的术语）
```
