## SCN-924：政务页面的会话超时与安全退出

**答**：
- 会话：政务登录短会话（15min 无操作超时），超时前提醒续期。
- 退出：清 token + 服务端吊销 + 敏感数据清除（1100）。
- 多标签：一标签登出全标签同步（BroadcastChannel）。

```javascript
// 会话超时提醒
function sessionWatchdog({ timeoutMs = 15 * 60_000 } = {}) {
  let lastActive = Date.now();
  ['click', 'keydown'].forEach(e => addEventListener(e,
    () => lastActive = Date.now(), { passive: true }));
  setInterval(() => {
    const idle = Date.now() - lastActive;
    if (idle > timeoutMs - 60_000 && idle < timeoutMs)
      showRenewPrompt();                              // 提前 1 分钟提醒
    if (idle > timeoutMs) forceLogout();
  }, 10_000);
}
```
