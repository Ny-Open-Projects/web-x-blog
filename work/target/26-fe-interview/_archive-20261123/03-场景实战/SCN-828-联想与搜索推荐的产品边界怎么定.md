## SCN-828：联想与推荐/广告边界怎么定？
**答**：
- 混排规则：联想位允许「广告建议词」（标「广告」角标）混排，但位置与密度受限（首条后不连续、≤1 条/屏）——合规（广告标识）与体验双约束。
- 相关性底线：广告词必须与输入前缀相关（否则用户体验崩坏），相关性判定服务端强制。
- 推荐词 vs 联想词：无输入时展示「发现/推荐」（推荐系统逻辑），有输入时切换为联想——两个系统共用搜索框但语义不同，切换要顺滑。
- 度量隔离：广告位 CTR 与自然联想 CTR 分开统计（混算会误导自然质量优化）。
- 追问钩子：为什么广告词必须标「广告」——监管硬要求（广告标识），同时也是信任管理：用户发现联想位有隐藏广告的信任损失远大于短期收入。

```javascript
function mixAds(natural, ads, { maxAds = 1, minRelated = true } = {}) {
  const valid = ads.filter(a => isRelated(a.q, currentPrefix) && a.labeled);
  const mixed = [...natural.slice(0, 2), ...valid.slice(0, maxAds), ...natural.slice(2)];
  return mixed;                                        // 首条自然 + 广告限频 + 标识强制
}
const metrics = { naturalCTR: separate, adCTR: separate };   // 度量隔离
```
