## SCN-1070：物流运单的改址与拦截召回

**答**：
- 改址：派送前改址（目的地/时间），条件校验（未出分拨）。
- 拦截：包裹召回（买家拒收/地址错误）——拦截指令下发网点，成功/失败状态跟踪。
- 时效：拦截响应时效（4h 内反馈结果）。

```javascript
// 拦截召回
async function interceptWaybill(waybillNo, reason) {
  const r = await api('/intercept', { waybillNo, reason });
  return {
    accepted: r.accepted, slaHours: 4,
    track: () => pollIntercept(r.taskId),
    note: r.accepted ? '拦截指令已下发网点' : '已派送无法拦截，可联系派件员' };
}
```
