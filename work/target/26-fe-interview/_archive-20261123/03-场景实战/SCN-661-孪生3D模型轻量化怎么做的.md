## SCN-661：3D 模型轻量化怎么做？
**答**：
- 模型处理管线：BIM/建模软件导出 → 服务端离线处理（减面/合并材质/烘培贴图）→ glTF + Draco/meshopt 压缩 + KTX2 纹理压缩 → CDN 分发。几百 MB BIM 处理后通常降到 10~30MB。
- 加载策略：按 LOD 分片加载（先低模后高模）、按视锥剔除（视野外楼层不加载）、首屏只加载园区外壳。
- 贴图优先：贴图占体积大头——KTX2（GPU 纹理压缩，省显存）+ 烘焙光照贴图替代实时光影。
- 运行时优化：InstancedMesh 复用重复构件（门窗/设备）；几何体顶点量化。
- 追问钩子：为什么不用 OBJ/FBX 直接上——无 LOD/无压缩管线/材质不合并，glTF 生态（Draco/KTX2）是为 Web 设计的。

```javascript
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import { DRACOLoader } from 'three/addons/loaders/DRACOLoader.js';
import { KTX2Loader } from 'three/addons/loaders/KTX2Loader.js';

const loader = new GLTFLoader();
loader.setDRACOLoader(new DRACOLoader().setDecoderPath('/draco/'));
loader.setKTX2Loader(new KTX2Loader().setTranscoderPath('/basis/').detectSupport(renderer));
loader.load('/models/park_lod0.glb', (gltf) => {
  const instanced = dedupeToInstances(gltf.scene);   // 重复构件转 InstancedMesh
  scene.add(instanced);
}, (e) => progressBar(e.loaded / e.total));            // 分片加载进度
// LOD 切换
const lod = new THREE.LOD();
lod.addLevel(highMesh, 0); lod.addLevel(lowMesh, 100); lod.addLevel(point, 500);
```
