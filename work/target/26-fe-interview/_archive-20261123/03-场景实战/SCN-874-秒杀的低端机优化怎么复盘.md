## SCN-874：低端机优化怎么复盘？
**答**：
- 分层策略：设备分档（内存/核数/CPU 基准跑分），低端机降级——动画关/图片降质/WebP→JPEG/长任务拆分/接口合并减请求。
- 公平性争议：低端机用户抢购成功率——前端分层不能造成「高端机先抢到」，按钮点击请求时序与设备无关（降级只影响渲染不影响请求时机）。
- 复盘数据：低端机占比 × 低端机转化率 vs 高端机——差距过大说明降级伤了体验；按档位看崩溃率/OOM 率。
- 测试资产：低端机真机池（TOP 5 机型）纳入每场活动回归；模拟器不算数。
- 追问钩子：为什么降级不能影响请求时机——秒杀是毫秒级竞争，若低端机因渲染慢才发请求就结构性输在起跑线；「点击先行」原则：用户点击立即发请求，渲染追赶。

```javascript
const lowEndPolicy = {
  tiering: { basis: ['memory', 'cores', 'benchmark'] },
  degrade: { animation: off, image: 'quality-down', longTask: 'split', requests: 'merge' },
  fairness: { requestFirst: true, note: '点击即发请求，渲染不阻塞抢购' },
  review: { byTier: ['conversion', 'crash', 'oom'], gap: '低端 vs 高端转化差' },
  regression: 'TOP5 真机池回归',
};
```
