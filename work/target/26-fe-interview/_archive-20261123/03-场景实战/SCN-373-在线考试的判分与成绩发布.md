## SCN-373：考试判分（自动判/主观题人工/成绩发布）怎么实现？

**答**:
- 判分流水线：客观题自动判（内容匹配+选项乱序适配——SCN-372 AB 卷）、主观题批改（教师批改台：按题分配批改/匿名批改——公平性：隐去考生信息）、AI 辅助批改（主观题预评分+相似答案聚类——AGT-314 人机协同复用，教师终审）。
- 复核机制：复核申请（考生申请复核→教师复核台）、分数修正审计（改分必须留痕——SCN-319 审计复用）、争议题处理（多答案给分——判分规则版本化）。
- 成绩发布：发布控制（教师选择发布时机/是否公开排名）、成绩单（个人成绩单：得分/排名/知识点分析——SCN-307 联动）、成绩申诉与修改重发布。
- 数据一致性：判分幂等（重判不改总分除非显式——判分版本化）、发布后的成绩不可变（修改走发布新版本——审计链）。

```javascript
// 判分流水线
const graded = autoGrade(answers, paper);    // 客观题
const subjective = graded.filter(isSubjective);
assignGraders(subjective, { blind: true });  // 匿名分配
aiSuggest(subjective);                       // AI 预分+聚类
// 教师终审 → 复核申请 → adjustScore(withAudit)
// 发布：publish({ showRank: opt, publicAt }) →
//   学生端 gradeReport（知识点分析联动 SCN-307）
// 修正：regrade → score v2（版本化，审计留痕）。
```
