## SCN-1100：物流运单的发货地址库管理（地址簿）

**答**：
- 地址簿：常用地址（默认发件/收件），地址校验入库（1062 解析）。
- 共享：团队共享地址簿（权限：可编辑/只读）。
- 合规：地址数据加密存储，删除即物理删除。

```javascript
// 地址簿
class AddressBook {
  constructor(role) { this.role = role; }              // owner/editor/viewer
  async add(addr) {
    const parsed = await parseAddress(addr.raw);       // 解析校验
    if (!parsed.ok) return parsed;
    return api('/addr-book/add', { ...parsed, encrypted: true });
  }
  async remove(id) {
    return api('/addr-book/remove', { id, hard: true });   // 物理删除
  }
}
```
