## SCN-262：地图上要展示 1 万个门店/车辆 marker，怎么渲染不卡？

**答**:
- 方案阶梯：点聚合（zoom 级别低时聚合显示，点击展开——最常用）、海量点图层（MapV/Canvas 直绘：不用 DOM marker，万级点走 canvas 批量绘制）、增量渲染（只渲染可视区+缓冲区 marker，视野变化增量增删）。
- 聚合策略：网格聚合或距离聚合（服务端预聚合 vs 前端实时聚合——1 万点前端聚合可接受，10 万点服务端预聚合）、聚合数字动画、聚合点击缩放展开。
- DOM marker 的替代：DOM marker（每个是 HTML 元素）上限约 500 个——超过必须 canvas/SVG 批量渲染或 WebGL（10 万级）；交互 marker（可点击弹窗）与展示 marker 分离（展示走 canvas，点击命中检测拾取）。
- 数据优化：坐标精度裁剪（展示用 6 位小数足够）、marker 分级（重要 marker DOM 渲染保交互、普通 marker canvas）、视野外清除。

```javascript
// 万级点：canvas 海量点图层
const layer = new MassMarksLayer({
  data: points,                            // 1w 点
  render: canvasDraw,                      // 批量绘制
});
map.on('moveend', () => layer.setViewport(map.getBounds()));
// 点击拾取：canvas 点击 → 命中检测（包围盒/最近点）
layer.on('click', (e) => {
  const hit = hitTest(e.lnglat, points);   // 空间索引（网格/kd）
  hit && openInfo(hit);
});
// 500 内交互 marker：DOM 渲染保可访问性；
// 聚合：zoom < 14 → clusterPoints(points, gridSize)。
```
