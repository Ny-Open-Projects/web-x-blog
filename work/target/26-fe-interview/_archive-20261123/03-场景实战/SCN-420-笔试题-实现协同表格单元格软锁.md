## SCN-420：手写表格单元格软锁：编辑中锁定、超时释放、冲突提示

**需求与边界**：
- 输入：单元格编辑事件流；输出：锁管理器。
- 边界要求：① 进入编辑→广播锁；② 完成/取消→释放；③ 持有者异常退出→超时自动释放（30s）；④ 他人持锁→只读态+锁定者提示；⑤ 锁是软约束（服务端不阻止提交——最后写入）。

**答**：
```javascript
class CellLockManager {
  constructor({ me, timeout = 30000 }) {
    this.me = me; this.timeout = timeout;
    this.locks = new Map();                  // cell → {user, ts}
  }
  acquire(cell) {
    const cur = this.locks.get(cell);
    if (cur && cur.user.id !== this.me.id &&
        Date.now() - cur.ts < this.timeout)
      return { ok: false, holder: cur.user };  // 他人持有→只读提示
    this.locks.set(cell, { user: this.me, ts: Date.now() });
    ws.send('cell_lock', { cell, user: this.me });
    this.renewTimer = setInterval(() =>       // 心跳续期
      ws.send('cell_lock', { cell, user: this.me,
        renew: true }), this.timeout / 3);
    return { ok: true };
  }
  release(cell) {
    if (this.locks.get(cell)?.user.id === this.me.id) {
      this.locks.delete(cell);
      clearInterval(this.renewTimer);
      ws.send('cell_unlock', { cell, user: this.me });
    }
  }
  onRemote(e) {                               // 远端锁事件
    if (e.user.id === this.me.id) return;
    if (e.type === 'lock') {
      this.locks.set(e.cell, { user: e.user, ts: Date.now() });
      markLocked(e.cell, e.user);             // 灰显+锁定徽标
    } else {
      this.locks.delete(e.cell);
      unmark(e.cell);
    }
  }
  sweep() {                                   // 超时释放
    for (const [cell, l] of this.locks)
      if (Date.now() - l.ts > this.timeout) {
        this.locks.delete(cell); unmark(cell);   // 持有者异常退出
      }
  }
}
// 提交不校验锁（软约束）：并发写服务端 last-write，
//   锁仅用于 UX 协调提示。
```

**评分点**:
- 锁生命周期完整：acquire（含他人持有拒绝）→心跳续期→release/超时 sweep。
- 他人持锁的 UX 呈现（灰显+徽标+持有者信息）。
- 软约束定位明确：锁只为体验协调，提交由服务端 last-write 裁决。
- 远端锁事件与本地锁的双向维护（幂等过滤自己）。
