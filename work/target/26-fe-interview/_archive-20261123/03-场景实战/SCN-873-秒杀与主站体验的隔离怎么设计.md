## SCN-873：秒杀与主站隔离怎么设计？
**答**：
- 入口隔离：秒杀独立域名/独立前端部署（独立 CDN 配置、独立限流），秒杀崩溃不影响主站浏览与正常购买。
- 资源隔离：秒杀专属资源包（图片/脚本独立 hash 独立缓存），不与主站共享 bundle——主站发版不影响已冻结的秒杀页。
- 依赖隔离：秒杀链路的共享依赖（登录/风控）设独立配额，秒杀流量不挤占主站配额（网关按业务分池限流）。
- 前端隔离检查：秒杀页禁用主站全局组件的重量级依赖（分析 SDK/客服组件按需加载）。
- 追问钩子：为什么秒杀要独立域名——独立域名让隔离从「代码层」上升到「网络层」（DNS/CDN/证书/WAF 独立），爆炸半径物理隔开；同域共享一切基础设施是最大的耦合。

```javascript
const isolation = {
  network: { domain: 'seckill.example.com', cdn: 'independent', rateLimit: 'per-domain' },
  assets: { bundle: 'separate-hash', cache: 'independent' },
  shared: { auth: 'quota-pooled', risk: 'quota-pooled' },   // 共享依赖分池
  freeze: '页面冻结期主站可独立发版',
};
```
