## SCN-948：政务大厅的自助填单终端与人工窗口协同

**答**：
- 协同：自助填单 -> 生成取号（凭填单码到窗口直接调出）——减少窗口占用时长。
- 实现：填单数据带码上传，窗口系统凭码调取；填单中断可续（草稿）。
- 度量：自助填单转化率（用了填单的办件占比）与窗口效率提升。

```javascript
// 填单协同
async function selfServiceForm(itemId) {
  const code = await api('/forms/draft', { itemId, form: currentForm() });
  printBarcode(code.code);                            // 凭码到窗口
  return { code: code.code, validMinutes: 120 };
}
// 窗口端：扫码拉起草稿 -> 确认提交，窗口停留时间 -40%
```
