## SCN-367：会议分组讨论（breakout room 分组/倒计时/回收）怎么实现？

**答**:
- 分组编排：主持人分组（自动均分/手动拖拽分配——拖拽分配 SCN-242 交互复用）、分组房间（每个分组独立 RTC 房间——信令与媒体隔离）、成员通知（被分组提示+确认跳转——拒绝留在主会）。
- 分组会话：组内小会议（独立布局/组内共享/组内白板——全功能子集），主持人巡场（主持人跳组旁听——跨组切换），组内求助（举手呼叫主持人——跨组信令）。
- 时间管理：讨论倒计时（全局倒计时同步——SCN-020 时钟）、到时提醒与回收（倒计时结束预警→自动回收回主会——可延长）。
- 状态同步：分组状态总览（主持人看各组状态：人数/讨论中）、分组结果保留（分组记录：讨论产出物关联分组——文档沉淀）。

```javascript
// 分组编排
const groups = autoAssign(members, n) || manualAssign(dnd);
groups.forEach((g, i) => signaling.createRoom(`br-${i}`, g));
ws.on('assigned', ({ roomId }) => {
  confirm(`进入分组 ${roomId}?`) ? switchRoom(roomId)
    : stayMain();
});
// 倒计时：globalTimer.sync(600e3) → 全组同步 →
//   到期前 1min 预警 → 回收 join(main)。
// 巡场：host.jumpTo(groupId) → 挂起主会流 → 订阅组流。
// 产出：group.notes → 汇总回主会白板。
```
