## SCN-958：检验检查报告的数字化展示（趋势图/参考区间）

**答**：
- 展示：指标数值 + 参考区间（超标标红）+ 历次趋势图（同指标对比）。
- 异常解读：超标程度分级（轻度/显著）+ 就医建议提示（免责声明）。
- 导出：报告 PDF 导出（带电子章）。

```javascript
// 指标趋势
function labTrend(results, refRange) {
  return results.map(r => ({
    date: r.date, value: r.value,
    status: r.value > refRange.max ? 'high'
      : r.value < refRange.min ? 'low' : 'normal',
    deviation: r.value > refRange.max
      ? +((r.value / refRange.max - 1) * 100).toFixed(1) + '%' : null,
  }));
}
// 渲染：趋势折线 + 参考区间带（ shaded band）+ 异常点标红
```
