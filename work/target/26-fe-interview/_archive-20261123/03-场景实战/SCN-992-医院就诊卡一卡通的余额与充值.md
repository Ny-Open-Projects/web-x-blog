## SCN-992：医院就诊卡（一卡通）的余额与充值

**答**：
- 余额：就诊卡余额查询/充值（在线+自助机）、消费明细。
- 退款：卡内余额退还（原路退回，审核流）。
- 对账：充值记录与支付流水对账（961 模式）。

```javascript
// 就诊卡
function cardAccount(card) {
  return {
    balance: card.balance,
    recharge: (amount) => payChannel({ type: 'card-recharge', card: card.id, amount }),
    history: card.transactions,                        // 消费/充值明细
    refund: () => api('/card/refund', { card: card.id }),   // 审核流退款
  };
}
```
