## SCN-938：政务大厅人流热力提示（错峰引导）

**答**：
- 数据：大厅实时人流（闸机计数）按时段展示热力。
- 引导：高负载时段建议预约/错峰（如"上午 10-11 点人流高峰"）。
- 前端：预约页嵌入热力提示 + 历史时段人流图。

```javascript
// 热力引导
function crowdGuide(history, capacity) {
  const byHour = groupBy(history, h => h.hour);
  const peak = Object.entries(byHour)
    .map(([h, rows]) => ({ hour: h, avg: avg(rows.map(r => r.count)) }))
    .sort((a, b) => b.avg - a.avg)[0];
  return { peakHour: peak?.hour,
    advice: peak && peak.avg > capacity * 0.8
      ? `建议避开 ${peak.hour} 点高峰` : null };
}
function avg(a) { return a.length ? a.reduce((s, v) => s + v, 0) / a.length : 0; }
function groupBy(arr, fn) { const m = {}; arr.forEach(x => { const k = fn(x); (m[k] ??= []).push(x); }); return m; }
```
