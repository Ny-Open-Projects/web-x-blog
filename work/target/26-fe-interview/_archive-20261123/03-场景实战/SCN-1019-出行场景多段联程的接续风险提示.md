## SCN-1019：出行场景多段联程的接续风险提示

**答**：
- 联程：中转时间过短风险提示（< 90 分钟国际/ < 40 分钟国内），延误联动后续段预警。
- 保护：同订单联程延误免费改后续段。
- 展示：联程时间轴（各段状态+缓冲时间可视化）。

```javascript
// 联程风险
function connectionRisk(segments) {
  return segments.slice(1).map((s, i) => {
    const bufferMin = (s.departAt - segments[i].arriveAt) / 60_000;
    const need = s.international ? 90 : 40;
    return { seg: i + 1, bufferMin, risk: bufferMin < need,
      advice: bufferMin < need ? `中转仅 ${bufferMin} 分钟，低于建议 ${need} 分钟` : null };
  });
}
```
