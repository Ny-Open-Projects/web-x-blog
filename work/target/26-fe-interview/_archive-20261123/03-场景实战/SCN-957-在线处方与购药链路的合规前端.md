## SCN-957：在线处方与购药链路的合规前端

**答**：
- 合规：处方需医生电子签名、药品分类（处方药需处方流转）、审方药师双签。
- 前端：处方展示（药品/用法/签名验真入口）、购药流转（处方外流至药房）。
- 限制：处方药隐藏购买按钮直至处方生效。

```javascript
// 处方流转
async function prescriptionFlow(rx) {
  if (!rx.signedBy || !rx.pharmacistApproved)
    return { ok: false, reason: '处方未完成双签' };
  const rxToken = await api('/rx/token', { rxId: rx.id });  // 外流令牌
  return { ok: true, pharmacyUrl: `/pharmacy?token=${rxToken}`,
    expireMin: 30 };
}
// 处方药按钮守卫：
const buyable = rx && rx.status === 'effective' && !rx.isRxOnlyBlocked;
```
