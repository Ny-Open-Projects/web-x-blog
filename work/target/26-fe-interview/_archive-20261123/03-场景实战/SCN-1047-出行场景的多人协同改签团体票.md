## SCN-1047：出行场景的多人协同改签（团体票）

**答**：
- 团体：团体票改签需全员一致（发起人发起，成员确认），超时视为放弃。
- 前端：确认进度（n/m 已确认）、倒计时、单方确认失败回滚。
- 兜底：不一致时支持拆分改签（部分成员改）。

```javascript
// 团体改签
async function groupRebook(orderId, newSchedule, members) {
  const confirmations = await collectConfirmations(members, { ttl: 10 * 60_000 });
  if (confirmations.all)
    return api('/rebook/group', { orderId, newSchedule });
  return { partial: true,
    note: `${confirmations.confirmed}/${members.length} 确认，可拆分改签` };
}
async function collectConfirmations(members, o) { return { all: true, confirmed: members.length }; }
```
