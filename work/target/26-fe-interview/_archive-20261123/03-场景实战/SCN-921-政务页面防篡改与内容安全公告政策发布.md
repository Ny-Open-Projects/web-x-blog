## SCN-921：政务页面防篡改与内容安全（公告/政策发布）

**答**：
- 发布：公告内容审核流（草稿→审核→发布），前端只渲染已发布。
- 防篡改：关键政策文本展示校验（内容 hash 比对，防注入篡改）。
- 留痕：访问审计（谁看了哪个政策）。

```javascript
// 内容防篡改
async function verifyPolicy(policy) {
  const expected = await api(`/policy/${policy.id}/hash`);
  const actual = await sha256(policy.content);
  if (actual !== expected) {
    report({ type: 'policy-tamper', id: policy.id });
    return { ok: false, action: '阻断展示' };
  }
  return { ok: true };
}
async function sha256(s) {
  const buf = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(s));
  return [...new Uint8Array(buf)].map(b => b.toString(16).padStart(2, '0')).join('');
}
```
