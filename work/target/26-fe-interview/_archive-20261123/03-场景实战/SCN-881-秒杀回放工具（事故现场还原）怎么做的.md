## SCN-881：回放工具怎么做的？
**答**：
- 会话回放：错误会话录制（rrweb 类 DOM 快照 + 事件流，采样录制），事故样本回放还原用户看到什么——白屏/按钮无响应类客诉的定位神器。
- 性能回放：关键链路 trace 回放（某用户从进入到下单的每步耗时），慢会话排序分析。
- 状态回放：秒杀按钮状态机事件流回放（SCN-857 状态变迁日志），还原「为什么用户点了没反应」。
- 隐私边界：回放内容脱敏（输入框内容掩码/敏感字段屏蔽），录制需合规声明，保留期限明确。
- 追问钩子：为什么回放要录「状态机事件流」而不只是画面——画面回放看到「按钮没反应」，状态流回放看到「卡在 SUBMITTING 是因为接口超时未终态」；后者直接给根因。

```javascript
const replayTools = {
  dom: { rrweb: { sample: 0.02, mask: 'inputs', privacy: 'declared' } },   // 采样录制
  trace: { perStep: true, slowFirst: true },
  fsm: { log: BTN_FSM.transitions, replay: (orderId) => eventTimeline(orderId) },
  use: '白屏/无响应类客诉定位 + 状态卡死根因',
};
```
