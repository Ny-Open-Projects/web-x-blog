## SCN-940：政务大厅的应急预案前端（系统故障降级页面）

**答**：
- 场景：审批系统故障 -> 线上申报转线下登记（纸表+事后补录）。
- 前端：降级横幅（系统维护中，线下办理指引）、表单导出空白模板。
- 恢复：系统恢复后提示补录线上（导出线下数据辅助）。

```javascript
// 降级横幅
function degradeBanner(systemStatus) {
  if (systemStatus.degraded) {
    showBanner({
      text: `${systemStatus.system} 系统维护中，可线下办理或稍后重试`,
      actions: ['下载空白表格', '查看线下网点'],
      level: 'warn',
    });
  }
}
// 恢复后：
systemStatus.on('restored', () => {
  showBanner({ text: '系统已恢复，未提交的线下件可补录', level: 'info' });
});
```
