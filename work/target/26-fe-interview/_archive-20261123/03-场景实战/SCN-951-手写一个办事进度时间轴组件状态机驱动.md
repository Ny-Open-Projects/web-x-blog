## SCN-951：手写一个办事进度时间轴组件（状态机驱动）

**答**：
- 需求：implement Timeline(steps, currentIndex)。渲染 { name, time?, status: done/active/pending/correction }；correction 状态可点击（展开补正材料列表）；预计剩余时间（active 节点 SLA 减已耗时）。
- 边界：currentIndex 越界按最后一步；correction 节点必须含 materials；输出纯数据供渲染。
- 评分点：状态推导；ETA 计算；补正交互；越界保护

```javascript
function Timeline(steps, currentIndex, startedAt, now = Date.now()) {
  return steps.map((s, i) => {
    const status = i < currentIndex ? 'done'
      : i === currentIndex ? (s.correction ? 'correction' : 'active') : 'pending';
    let eta = null;
    if (status === 'active' && s.slaHours && startedAt) {
      const elapsedH = (now - startedAt) / 3600_000;
      eta = Math.max(0, Math.round(s.slaHours - elapsedH));
    }
    return { ...s, status, eta,
      expandable: status === 'correction' && !!s.materials?.length };
  });
}
```
