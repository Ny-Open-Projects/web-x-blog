## SCN-1089：物流运单的数据看板（商家物流体验分）

**答**：
- 指标：物流体验分（时效/服务/破损率加权），分行业/竞对基准对比。
- 下钻：体验分差 → 差评运单明细（归因）。
- 改进：看板生成优化建议（换线路/换网点）。

```javascript
// 物流体验分
function logisticsScore(merchant, month) {
  const timeliness = month.slaRate;                    // 时效达成率
  const service = month.goodRate;
  const damage = 1 - month.damageRate;
  const score = Math.round(timeliness * 40 + service * 40 + damage * 20);
  return { score,
    vsIndustry: +(score - month.industryAvg).toFixed(1),
    advice: score < 80 ? '建议更换超时线路（见明细）' : null };
}
```
