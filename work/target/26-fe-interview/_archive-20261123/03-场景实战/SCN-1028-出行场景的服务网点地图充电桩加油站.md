## SCN-1028：出行场景的服务网点地图（充电桩/加油站）

**答**：
- 地图：充电桩状态（空闲/占用/故障）实时刷新，筛选（快充/品牌）。
- 规划：续航不足提醒 + 沿途充电站推荐（顺路+空闲概率）。
- 体验：扫码充电/支付一体化。

```javascript
// 充电桩推荐
function chargerRecommend(route, battery) {
  const remaining = battery.rangeKm;
  const along = stationsAlong(route).filter(s => s.free && s.fast);
  const needed = along.filter(s =>
    dist(route, s) < remaining * 0.8);                 // 可达
  return needed.sort((a, b) => dist(route, a) - dist(route, b)).slice(0, 3);
}
function stationsAlong(route) { return []; }
function dist(route, s) { return 30; }
```
