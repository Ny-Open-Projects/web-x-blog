## SCN-763：大视频审核怎么优化？
**答**：
- 分段加载：HLS/DASH 分片按需加载，配合机审标注跳转（只加载关键片段周边）；直播回放按审核任务切分成段落派单（每人审一段，并行降总时长）。
- 快速 seek：转码时生成多码率 + 关键帧索引，seek 到未加载区域秒切低清晰度再渐进升级。
- 声画分离加速：音频转文字（ASR）先行——审核员可先读文字稿定位违规言论，再跳转视频确认；画面违规用抽帧墙（雪碧图网格）快速扫视。
- 缓存复用：同视频二次进入（复审/仲裁）复用已加载分片与 ASR 结果（缓存键 videoId+version）。
- 追问钩子：2h 视频为什么切段落派单而不是单人审——单人 2h 是 throughput 瓶颈且注意力衰减；段落并行 + 段间上下文摘要传递，总时长除以人数且质量稳定。

```javascript
function splitTask(video, { segSec = 600 } = {}) {
  const segs = [];
  for (let t = 0; t < video.duration; t += segSec)
    segs.push({ videoId: video.id, start: t, end: Math.min(t + segSec, video.duration),
                asr: asrCache(video.id, t, t + segSec),      // 文字稿先行
                prevSummary: segs.at(-1)?.summary });        // 段间上下文
  return segs;                                               // 并行派单
}
```
