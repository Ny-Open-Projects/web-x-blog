## SCN-1262：国际电商的用户语言检测与切换（首次访问）

**答**：
- 检测：Accept-Language header（SSR 判定）→ 重定向对应语言站（可记忆拒绝）。
- 切换：手动切换优先级高于检测（localStorage 记忆），URL 路径切换（SEO 友好）。
- 避免：不要基于 IP 强制跳转（损害 SEO 与用户体验）。

```javascript
// 语言检测
function detectLang(acceptLanguage, saved) {
  if (saved) return saved;                           // 用户选择优先
  const first = acceptLanguage?.split(',')[0]?.split('-')[0];
  return SUPPORTED.has(first) ? first : DEFAULT_LANG;
}
const SUPPORTED = new Set(['en', 'de', 'ja', 'zh']);
// SSR 设置 Vary: Accept-Language（CDN 缓存区分）
```
