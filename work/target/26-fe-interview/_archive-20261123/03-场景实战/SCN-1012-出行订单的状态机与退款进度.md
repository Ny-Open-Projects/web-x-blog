## SCN-1012：出行订单的状态机与退款进度

**答**：
- 状态：待支付→已出票→已出行→退款中→已退款；退款进度（原路退回时效展示）。
- 前端：状态时间轴 + 各状态可用操作（改签/退票/开票）。
- 发票：行程后开票（电子发票抬头管理）。

```javascript
// 退款进度
function refundTimeline(refund) {
  return [
    { step: '申请退款', at: refund.appliedAt, done: true },
    { step: '商家审核', at: refund.auditedAt, done: !!refund.auditedAt },
    { step: '原路退回', at: refund.refundedAt, done: !!refund.refundedAt,
      eta: refund.auditedAt && !refund.refundedAt ? '1-7 个工作日' : null },
  ];
}
```
