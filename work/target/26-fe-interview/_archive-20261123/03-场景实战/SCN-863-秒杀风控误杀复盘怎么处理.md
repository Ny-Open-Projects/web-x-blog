## SCN-863：风控误杀怎么复盘？
**答**：
- 误杀识别：下单失败分布中「风控拒绝」占比 + 客诉抽样定性——真人特征误杀（公司出口 IP、无障碍用户、正常比价行为）是主要误杀类型。
- 复盘产出：误杀样本回流风控模型（SCN-553 反馈闭环）；检查阈值是否过紧（大促期临时收紧的阈值忘了放宽是高频原因）。
- 前端体验补救：被拦用户给明确路径（换网络重试/完成验证升级）而非死路；申诉通道直达。
- 预防机制：大促风控阈值变更记录「生效/失效时间表」，活动结束自动恢复默认——临时配置必须有自动回滚。
- 追问钩子：为什么大促临时收紧的阈值要自动回滚——临时配置靠人记忆恢复必然遗漏；「收紧容易放宽忘」导致大促后持续误杀，自动化失效时间表是工程解法。

```javascript
const riskMitigation = {
  detection: { failRatioByCode: true, complaintSampling: true },
  regression: { feedbackToModel: true, thresholdReview: '临时收紧项清单' },
  autoRestore: { schedule: (id) => scheduleAt(activityEndTs, () => restoreDefault(id)),
                 note: '临时配置自动失效' },
  ux: { blocked: retryGuide() + appealEntry },         // 死路变路径
};
```
