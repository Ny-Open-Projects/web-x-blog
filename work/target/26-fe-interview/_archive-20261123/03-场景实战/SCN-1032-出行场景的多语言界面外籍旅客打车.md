## SCN-1032：出行场景的多语言界面（外籍旅客打车）

**答**：
- 支持：英文界面+司机沟通翻译（目的地翻译给司机）、支付方式国际化（外卡）。
- 实现：i18n 术语表（出行术语审核）、翻译消息双向（乘客中文/司机中文互译）。
- 兜底：翻译失败展示地址卡片（司机看导航不受语言影响）。

```javascript
// 外籍打车
function foreignRideUI(lang, dest) {
  return {
    ui: i18n.lang(lang),
    driverMsg: translate(dest.address, 'zh'),          // 目的地翻译给司机
    fallback: dest.mapPin,                             // 导航不受语言影响
    pay: ['wechat', 'alipay', 'visa', 'mastercard'],
  };
}
```
