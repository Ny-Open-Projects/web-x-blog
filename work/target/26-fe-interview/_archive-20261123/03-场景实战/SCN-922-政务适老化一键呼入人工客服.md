## SCN-922：政务适老化「一键呼入」人工客服

**答**：
- 功能：长辈版悬浮按钮一键转人工（免排队优先）、通话中屏幕共享指导。
- 降级：客服忙线时排队位置提示 + 回拨承诺。
- 埋点：呼入率/接通率/解决率（适老化效果度量）。

```javascript
// 一键呼入
async function oneClickCall(user, context) {
  const r = await api('/hotline/call', { uid: user.id,
    priority: user.elder ? 'high' : 'normal',
    page: currentRoute() });
  report({ type: 'hotline', result: r.queued ? 'queued' : 'connected' });
  if (r.queued) showQueuePosition(r.position, r.eta);
}
// context 携带当前页面信息，客服可看到用户卡在哪一步
```
