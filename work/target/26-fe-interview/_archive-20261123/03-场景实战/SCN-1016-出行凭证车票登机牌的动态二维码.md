## SCN-1016：出行凭证（车票/登机牌）的动态二维码

**答**：
- 动态：检票二维码动态刷新（防截屏盗用），离线可用（预生成序列）。
- 实现：二维码内容 = 票号+时间戳签名（30s 轮换），本地缓存下一周期预生成。
- 亮度：二维码亮度增强（检票机识别）。

```javascript
// 动态凭证
function dynamicQR(ticket, { periodMs = 30_000 } = {}) {
  let cache = null;
  function gen(slot) {
    const payload = `${ticket.no}:${slot}:${sign(ticket.no, slot)}`;
    return renderQR(payload, { dark: '#000', light: '#fff', boost: true });
  }
  setInterval(() => { cache = gen(Math.floor(Date.now() / periodMs)); }, periodMs);
  return () => cache ?? gen(Math.floor(Date.now() / periodMs));
}
```
