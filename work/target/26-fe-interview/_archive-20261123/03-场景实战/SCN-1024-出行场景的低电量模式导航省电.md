## SCN-1024：出行场景的低电量模式（导航省电）

**答**：
- 省电：导航息屏语音模式（屏幕关闭语音继续）、降低定位频率（3s→5s）、暗色地图（OLED 省电）。
- 触发：电量 < 20% 建议切换省电导航。
- 安全：省电模式仍保留提醒播报。

```javascript
// 省电导航
function powerSaverNav(battery) {
  if (battery > 20) return { mode: 'normal' };
  return { mode: 'saver',
    screen: 'voice-only', gpsHz: 0.2,                  // 5s 一次
    dark: true, voice: true,                           // 播报保留
    note: '已进入省电导航' };
}
```
