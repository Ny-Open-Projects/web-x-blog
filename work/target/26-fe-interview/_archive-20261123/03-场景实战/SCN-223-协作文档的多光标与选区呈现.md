## SCN-223：多人编辑时其他人的光标与选区，怎么做到实时不串位？

**答**:
- 位置模型：光标位置必须存"文档位置锚"（相对字符的相对位置/CRDT 的相对引用），不能存像素坐标或偏移量——他人插入文字后锚自动跟随（这是不串位的关键）。
- 状态协议：awareness 通道（Yjs Awareness：用户身份/颜色/光标位置/选区，独立于文档内容通道，高频低量），光标更新节流（50ms 批量广播）、离开超时清理（30s 无心跳移除光标）。
- 渲染：光标层与文本层分离（overlay 层画他人光标，独立于编辑器文本渲染），颜色分配（稳定 hash 用户→色板），选区高亮半透明底色，重叠光标错开偏移。
- 性能：光标数上限（>20 人只显示前 N+计数）、视口外光标不渲染、动画克制（光标平滑移动只在低频会话启用）。

```javascript
const awareness = provider.awareness;
editor.on('selectionChange', throttle((sel) => {
  awareness.setLocalStateField('cursor', {
    anchor: Y.createRelativePositionFromTypeIndex(ytext, sel.anchor),
    head: Y.createRelativePositionFromTypeIndex(ytext, sel.head),
  });                                        // 相对锚，自动跟随插入
}, 50));
awareness.on('change', () => {
  const peers = [...awareness.getStates().entries()]
    .filter(([id]) => id !== awareness.clientID);
  renderCursors(peers.map(([id, st]) => ({
    user: st.user, color: colorOf(id),
    // 相对位置 → 当前绝对位置
    pos: toAbsolute(st.cursor, ydoc),
  })));                                      // overlay 层渲染
});
// 超时清理：awareness 30s 心跳，过期自动移除。
```
