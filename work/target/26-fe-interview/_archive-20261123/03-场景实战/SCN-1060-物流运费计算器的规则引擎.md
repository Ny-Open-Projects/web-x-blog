## SCN-1060：物流运费计算器的规则引擎

**答**：
- 规则：首重续重/体积重（长宽高/6000）/偏远地区附加费/时效产品加价。
- 前端：实时试算（输入即算，规则配置下发）。
- 透明：计费明细展示（每项费用构成）。

```javascript
// 运费试算
function freightCalc(pkg, rule) {
  const volumetric = pkg.w * pkg.h * pkg.d / 6000;
  const weight = Math.max(pkg.weight, volumetric);    // 计费重取大
  const first = rule.firstPrice, cont = Math.ceil((weight - 1) / 0.5) * rule.contPrice;
  const remote = REMOTE_ZONES.has(pkg.district) ? rule.remoteFee : 0;
  return { chargeWeight: weight,
    items: [ { label: '首重', amount: first },
      { label: '续重', amount: cont },
      { label: '偏远附加', amount: remote } ],
    total: first + cont + remote };
}
const REMOTE_ZONES = new Set(['那曲', '阿里']);
```
