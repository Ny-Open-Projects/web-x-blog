## SCN-915：政务评价（好差评）体系的前端实现

**答**：
- 触点：办结页主动评价 + 事后短信回访；差评触发回访工单。
- 表单：星级 + 标签（多选）+ 文本（敏感词过滤）；匿名选项。
- 闭环：差评处理进度对评价人可见（信任建立）。

```javascript
// 评价提交
async function submitRating(rating) {
  const clean = await sensitiveFilter(rating.comment);  // 1114 词库
  const r = await api('/rating', { ...rating,
    comment: clean.text, blocked: clean.blocked });
  if (rating.stars <= 2)
    showFollowUpInfo(r.ticketId);                    // 差评回访单号展示
  return r;
}
```
