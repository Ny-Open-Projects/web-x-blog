## SCN-1263：国际电商的搜索国际化（多语言分词）

**答**：
- 挑战：多语言分词（中文/日文无空格分词、德语复合词）——搜索引擎多语言分析器。
- 前端：搜索建议本地化（同义词库分语言）、输入法兼容（IME 组合保护）。
- 度量：分语言搜索无结果率（内容覆盖短板发现）。

```javascript
// 多语言搜索
function i18nSearch(q, lang, index) {
  const analyzer = { zh: 'ik', ja: 'kuromoji', de: 'german' }[lang] ?? 'standard';
  return api('/search', { q, lang, analyzer, index });
}
// 无结果率监控：
function noResultRate(lang, searches) {
  const rows = searches.filter(s => s.lang === lang);
  return +(rows.filter(s => s.hits === 0).length / (rows.length || 1) * 100).toFixed(1) + '%';
}
```
