## SCN-985：医院住院管理页面的床位与费用概览

**答**：
- 概览：床位号/主治医生/费用余额（预交金-已用）/待缴提醒。
- 明细：每日费用清单（药品/检查/护理）按日汇总。
- 提醒：预交金不足提前 1 天提醒充值。

```javascript
// 住院概览
function inpatientOverview(admission) {
  const balance = admission.prepaid - admission.used;
  return {
    bed: admission.bed, doctor: admission.attending,
    balance, needTopUp: balance < admission.dailyAvg * 3,
    daily: admission.dailyItems.map(d => ({ date: d.date,
      total: d.items.reduce((s, i) => s + i.amount, 0) })),
  };
}
```
