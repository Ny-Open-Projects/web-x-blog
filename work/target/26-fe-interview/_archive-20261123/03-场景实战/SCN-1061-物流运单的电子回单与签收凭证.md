## SCN-1061：物流运单的电子回单与签收凭证

**答**：
- 回单：签收拍照（POD）+ 电子签名，回单电子化归档（商家对账依据）。
- 校验：签收人与收件人一致性（代收需备注关系）。
- 调取：商家后台按运单批量调取回单（对账）。

```javascript
// 电子回单
async function podCapture(waybillId, photo, signature) {
  const r = await api('/pod', { waybillId, photo, signature,
    signedBy: confirmReceiver(photo) });
  return { podUrl: r.url, archive: true };
}
async function batchFetchPODs(waybillIds) {
  return api('/pod/batch', { ids: waybillIds });       // 商家对账批量调取
}
}
```
