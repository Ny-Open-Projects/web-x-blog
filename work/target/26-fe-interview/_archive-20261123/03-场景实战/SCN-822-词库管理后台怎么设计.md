## SCN-822：词库管理后台怎么设计？
**答**：
- 词生命周期：导入（运营/爬取/用户日志挖掘）→ 风控审 → 质量审（人工抽检相关度）→ 灰度上线 → 效果监控 → 降权/淘汰。
- 批量导入校验：去重、敏感词扫描、格式校验（长度/特殊字符）、与现有词冲突检测（同形异义）。
- 灰度与回滚：新词批次按百分比灰度放量，效果差（点击率低于基线）自动回滚——词库也是「数据代码」，变更要可回滚。
- 变更审计：每次词库变更记录（谁/何时/多少词/依据），支持按批次回滚。
- 追问钩子：为什么词要「效果监控+淘汰」——词库只进不出会膨胀（噪声词拖垮排序与缓存命中率），效果数据驱动的淘汰机制让词库保持高质量。

```javascript
const wordLifecycle = {
  stages: ['import', 'risk-review', 'quality-review', 'gray', 'monitor', 'retire'],
  importChecks: ['dedupe', 'sensitive-scan', 'format', 'conflict'],
  gray: { pct: 0.1, autoRollback: 'ctr < baseline*0.8', window: '7d' },
  audit: { perBatch: true, rollbackByBatch: true },
};
```
