## SCN-1274：国际电商的跨境合规提示（商品合规声明）

**答**：
- 合规：CE/FDA/FCC 标识（按品类/国家强制声明），合规声明展示（详情页/结算页）。
- 拦截：不合规商品按国家禁售拦截（结算校验）。
- 文档：合规文档下载（检测报告，监管要求）。

```javascript
// 合规声明
function complianceNotice(item, country) {
  const marks = item.certifications.filter(c =>
    REQUIRED_MARKS[country]?.includes(c.type));
  return {
    marks,                                             // 需展示的合规标识
    docs: item.certDocs,
    blocked: REQUIRED_MARKS[country] && !marks.length,
    note: '缺少该国要求的合规认证，禁止销售',
  };
}
const REQUIRED_MARKS = { DE: ['CE'], US: ['FCC'] };
```
