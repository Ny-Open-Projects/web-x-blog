## SCN-378：文档版本对比（双栏 diff/选择性合并变更）怎么实现？

**答**:
- diff 计算：段落级 diff（文本 diff 算法：段级→行级→字级三级 diff——层级化减少噪音）、结构化 diff（表格/列表的结构感知 diff——不是纯文本 diff）、移动检测（段落移动识别——移动而非删除+新增）。
- 双栏可视化：左右对照（旧版左/新版右，变更高亮连线——对应关系可视化）、变更列表（右侧变更清单：逐条跳转）、变更统计（新增 X 删 Y 改 Z——摘要条）。
- 选择性合并：逐条采纳（每处变更可单独接受/拒绝——不是全量回滚，SCN-226 反向补丁的细化版）、合并预览（选择后实时预览合并结果）、批量策略（全部接受/全部拒绝+个别调整）。
- 协同一致：合并操作进协作流水（合并也是编辑操作——多人可见、可再撤销）、合并期间文档锁定（合并冲突窗口——避免合并中他人再编辑的复杂度，或 CRDT 直接支持）。

```javascript
function VersionCompare(a, b) {
  const diff = hierarchicalDiff(a, b);     // 段→行→字
  return <>
    <DualPane left={a} right={b} diff={diff}
      moves={detectMoves(diff)} />         {/* 移动识别 */}
    <ChangeList items={diff.changes}       {/* 逐条采纳 */}
      onPick={(c, accept) => previewMerge(c, accept)} />
    <MergePreview result={applied} />      {/* 实时预览 */}
    <Apply onDone={(patch) => commitAsCollabOp(patch)} />
  </>;
}
// commitAsCollabOp：合并补丁进 seq 流水（SCN-226 复用）。
```
