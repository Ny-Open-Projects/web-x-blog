## SCN-939：政务大厅叫号屏的语音播报合成

**答**：
- 实现：TTS 合成（"请 A1024 号到 3 号窗口"）+ 音频缓存（常见模板预合成）。
- 降级：TTS 失败用预置录音模板拼接（号码分段录音）。
- 无障碍：同步文字展示（听障友好）。

```javascript
// 叫号播报
function voiceCall(ticketNo, windowNo) {
  const segs = [`请`, ...String(ticketNo).split(''), `号到`, String(windowNo), `号窗口`];
  const audio = segs.map(s => cachedAudio(s) ?? tts(s));
  return playSequence(audio);                         // 顺序播放
}
// 模板预合成：数字 0-9 + 常用词预录，拼接即用（无 TTS 延迟）
```
