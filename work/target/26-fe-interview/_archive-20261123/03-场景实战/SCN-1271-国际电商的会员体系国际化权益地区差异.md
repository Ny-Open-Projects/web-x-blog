## SCN-1271：国际电商的会员体系国际化（权益地区差异）

**答**：
- 差异：会员权益按国（免邮门槛/退换货次数），定价地区差异（购买力定价）。
- 合规：价格歧视合规（地区定价法规），权益公示透明。
- 展示：会员页按地区渲染权益矩阵。

```javascript
// 会员地区差异
function membershipPerks(tier, region) {
  const base = { freeShippingOver: FREE_SHIP[region], returns: RETURN_DAYS[region] };
  const extra = { gold: { prioritySupport: true }, silver: {} }[tier] ?? {};
  return { ...base, ...extra,
    note: '权益因地区而异，以当前站点公示为准' };
}
const FREE_SHIP = { US: 35, DE: 39, JP: 3000 };
```
