## SCN-971：医院缴费的多渠道支付与对账

**答**：
- 渠道：自助机扫码/移动端支付/窗口现金——统一订单号对账。
- 掉单：支付成功但业务未确认（回调丢失）——主动查询补偿。
- 体验：缴费成功即时推送电子票据。

```javascript
// 缴费对账
async function payWithReconcile(order) {
  const r = await payChannel(order);
  let status = await api(`/order/${order.id}/status`);
  if (status !== 'paid' && r.success) {
    await sleep(3000);                                 // 等回调
    status = await api(`/order/${order.id}/status`);
    if (status !== 'paid') {
      const fixed = await api(`/order/${order.id}/reconcile`,
        { channelTxId: r.txId });                      // 主动对账
      report({ type: 'pay-reconcile', fixed });
      status = fixed.status;
    }
  }
  return status;
}
```
