## SCN-1031：出行场景的失物找回流程（车内遗失物品）

**答**：
- 流程：提交失物登记（物品描述+行程信息）-> 司机端核查 -> 找到后归还方式选择（自取/快递到付）。
- 匹配：物品特征+行程匹配（AI 辅助比对车内拍摄物）。
- 状态：登记→司机核查→已找到→归还中→完成，全程进度可见。

```javascript
// 失物登记
async function lostItemReport(rideId, desc, photos) {
  const r = await api('/lost-item', { rideId, desc, photos });
  return {
    ticket: r.no,
    flow: ['司机核查', '结果反馈', '归还安排'],
    onFound: (way) => api(`/lost-item/${r.no}/return`, { way }),   // 自取/快递
  };
}
```
