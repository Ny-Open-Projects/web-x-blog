## SCN-256：中后台多标签页工作台（页签可开多个详情页）怎么设计？

**答**:
- 路由与页签模型：页签栈（每个页签=路由入口+参数+状态），路由映射（页签 id ↔ 路由，刷新后恢复页签栈——持久化页签列表），同路由多实例（同一详情页不同 id 多页签——路由参数区分）。
- 状态保持：KeepAlive 策略（页签切换保留组件状态：滚动位置/表单草稿/列表筛选），内存上限（最多 N 个活跃页签，LRU 释放非活跃页签状态——释放前状态快照可恢复），缓存键设计（路由+参数 hash）。
- 页签交互：关闭确认（有未保存内容的页签关闭提示）、右键菜单（关闭其他/关闭右侧/固定页签）、拖拽排序、页签标记（未读/错误状态徽标）。
- 数据一致性：A 页签改了数据，B 页签的同实体详情要更新（实体级事件总线：mutation 广播→相关页签局部刷新）。

```javascript
// 页签栈管理
const tabs = createStore({
  tabs: [],             // [{id, path, params, title, snapshot}]
  activeId: null,
});
function openTab(route) {
  const id = route.path + JSON.stringify(route.params);
  const exist = tabs.tabs.find(t => t.id === id);
  if (exist) return activate(exist.id);
  tabs.tabs.push({ id, ...route, title: route.meta.title });
  activate(id);                              // KeepAlive include
}
// 内存上限：>10 个活跃 → LRU 释放最久未用
//   （释放前 serialize 状态快照到 idb，激活时恢复）
```
