## SCN-1253：国际化电商的多币种展示与结算架构

**答**：
- 架构：商品以基准币定价 → 汇率服务（定期+实时锁汇）→ 用户币种展示换算 → 结算币种（支付通道支持币种）。
- 前端：币种切换（全局）、价格格式化（Intl.NumberFormat）、汇率时间戳标注（"汇率更新于 xx"）。
- 精度：显示两位小数（部分币种 0 位如日元），结算以支付通道实际汇率为准（展示免责）。

```javascript
// 多币种价格
function formatPrice(amount, currency, locale) {
  return new Intl.NumberFormat(locale, { style: 'currency', currency,
    maximumFractionDigits: currency === 'JPY' ? 0 : 2 }).format(amount);
}
function convert(baseUSD, rate, target) {
  return { amount: +(baseUSD * rate).toFixed(2), currency: target,
    rateAt: rate.timestamp,
    note: '结算金额以支付时汇率为准' };
}
```
