## SCN-978：医疗健康档案的数据可视化（健康趋势总览）

**答**：
- 总览：血压/血糖/体重等核心指标趋势卡片，异常标注。
- 数据源：自查录入 + 可穿戴设备同步（授权）+ 体检导入。
- 隐私：健康数据加密存储，共享需显式授权（家人查看）。

```javascript
// 健康总览
function healthOverview(records, { familyAccess = false } = {}) {
  const metrics = ['blood-pressure', 'blood-sugar', 'weight'];
  return metrics.map(m => {
    const series = records.filter(r => r.metric === m);
    const latest = series[series.length - 1];
    return { metric: m, latest: latest?.value,
      status: latest ? rangeStatus(latest.value, RANGES[m]) : 'no-data',
      series: familyAccess ? series.map(s => ({ ...s, detail: 'hidden' })) : series };
  });
}
```
