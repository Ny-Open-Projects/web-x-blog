## SCN-1018：出行场景的行程中断处理（列车晚点/航班取消的补偿流）

**答**：
- 晚点：晚点信息推送 + 退改免手续费规则自动应用。
- 取消：一键全额退款+住宿补偿申请（合规条款展示）。
- 记录：行程中断留痕（赔付依据）。

```javascript
// 晚点补偿
function delayCompensation(flight) {
  const rules = delayRules(flight.delayMin);           // 航司规则
  return {
    freeRebook: rules.rebook, freeRefund: rules.refund,
    hotel: rules.hotel (flight.delayMin >= 8 * 60) ,    // 过夜住宿
    evidence: { status: flight.statusRecord, ts: flight.updatedAt },
  };
}
function delayRules(min) {
  return { rebook: true, refund: true, hotel: min >= 480 };
}
```
