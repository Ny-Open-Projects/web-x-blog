## SCN-656：大屏分辨率适配怎么做？
**答**：
- 两种策略：等比缩放（transform: scale 整体缩放设计稿分辨率，所有元素位置绝对保真，但非 16:9 屏留黑边）vs 流式布局（grid/flex 重排，自适应但布局风险高）。行业大屏主流是等比缩放 + 少量关键面板局部重排。
- 混合方案：外层等比 scale 保构图；图表字号用 vw 相对单位或在 resize 时重绘；3D 相机 FOV 按宽高比调整而非缩放画布。
- 拼接屏：按物理像素映射（devicePixelRatio 处理），跨屏接缝处避免放置关键信息；整屏视为一个 canvas 容器。
- 校验手段：常见分辨率矩阵（1920×1080 / 2560×960 / 3840×2160）截图对比进 CI。
- 追问钩子：transform: scale 会不会导致文字模糊——比例非整数时会有，缓解手段是按 dpr 缩放 canvas/SVG 类元素，DOM 文字用 `will-change` 与整数倍设计稿。

```javascript
function fitScreen(designW = 3840, designH = 2160) {
  const el = document.getElementById('stage');
  function resize() {
    const { innerWidth: w, innerHeight: h } = window;
    const scale = Math.min(w / designW, h / designH);        // 等比取小，保完整
    el.style.transform = `translate(-50%, -50%) scale(${scale})`;
    el.style.width = designW + 'px'; el.style.height = designH + 'px';
    // 非目标比例时居中留黑边；3D 相机另按实际宽高比调 FOV
    camera.aspect = w / h; camera.updateProjectionMatrix();
  }
  window.addEventListener('resize', resize); resize();
}
```
