## SCN-781：机审模型版本与前端联动怎么设计？
**答**：
- 版本可见：机审结果带模型版本号，工作台展示（模型 v2026.3）——审核员对机器判断的信任度与版本表现相关，版本可追溯。
- 模型升级灰度：新模型影子运行（新旧双跑对比差异样本）→ 差异样本人审仲裁 → 分品类切流；前端差异对比视图辅助评估。
- 置信度语义随版本变化：新模型校准后分数分布改变，直放阈值必须随版本重校准——阈值与版本绑定存储，不全局共享。
- 前端呈现适配：不同版本机审标注密度差异大，工作台标注渲染性能按版本预估。
- 追问钩子：为什么阈值要跟版本绑定——旧模型 0.9 和新模型 0.9 语义可能完全不同（校准差异）；阈值全局共享会导致切版本瞬间直放率失控。

```javascript
const modelVersioning = {
  shadow: (newModel) => dualRun(newModel, { diffToHuman: arbitrateDiffs }),
  threshold: (version) => THRESHOLDS[version],       // 阈值与版本绑定
  rollout: (version, category) => switchTraffic(category, version, { canary: 0.1 }),
  render: (marks) => marks.length > MAX_MARKS && degradeMarkRender(marks),  // 渲染适配
};
```
