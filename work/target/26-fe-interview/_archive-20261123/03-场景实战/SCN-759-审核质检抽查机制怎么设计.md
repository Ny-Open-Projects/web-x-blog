## SCN-759：审核质检机制怎么设计？
**答**：
- 三种质检：盲测样例（队列混入已知答案的标准样本，测准确率）、交叉复审（同视频双人审比对一致性）、事后抽检（QA 团队按比例复查）。
- 一致性度量：双人审核一致率（同判/误判矩阵），分歧样本进仲裁并分析是标准模糊还是个人偏差。
- 质检结果应用：个人准确率进绩效参考（但不唯一指标，防「从严判」博弈——从严误杀不罚会驱动全判违规）；标准模糊样本回流标准优化。
- 质检队列 invisibility：盲测样本对审核员不可见（与普通任务混排），否则失效。
- 追问钩子：为什么不能只考核准确率——准确率可以用「宁可错杀」刷高，必须配合「误杀率」与「漏杀率」双指标 + 抽检校准。

```javascript
function reviewQuality(auditor) {
  const blind = auditor.blindSamples;              // 盲测样例结果
  const accuracy = correct(blind) / blind.length;
  const falseKill = blind.filter(b => b.truth === 'OK' && b.verdict === 'REJECT').length / blind.length;
  const miss = blind.filter(b => b.truth === 'REJECT' && b.verdict === 'OK').length / blind.length;
  // 双指标约束：accuracy 高但 falseKill 超阈值同样不合格
  return { accuracy, falseKill, miss,
    pass: accuracy > 0.95 && falseKill < 0.02 && miss < 0.03 };
}
```
