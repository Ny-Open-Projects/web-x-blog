## SCN-1010：出行场景的离线地图与弱网可用

**答**：
- 需求：地下车库/隧道无网——离线地图包（城市矢量瓦片预下载）+ 最后一公里指引缓存。
- 实现：路线详情离线缓存（出发前缓存），离线模式只读导航。
- 更新：Wi-Fi 下自动更新离线包。

```javascript
// 离线导航
async function prepareOffline(route) {
  const tiles = await tilesForRoute(route, { zoom: 12 });
  await idbPut('offline-map', route.id, tiles);
  return { offlineReady: true,
    note: '隧道/车库无网时使用缓存路线' };
}
// 恢复在线后自动同步实际行程
```
