## SCN-285：电商搜索框的联想词、纠错、无结果场景怎么设计？

**答**:
- 联想词：输入即联想（防抖 200ms+取消过期请求+缓存已输入联想）、联想结构（历史/热词/商品词分组展示）、键盘导航（上下键选择+回车确认——搜索框可用性基线）。
- 纠错：拼写纠错（"耐尅"→"耐克"提示"已为您显示耐克的结果"）、同义词扩展、拼音/首字母联想。
- 无结果页：无结果三件套（纠错建议/相似商品推荐/清空筛选引导）——把死路变成分流；筛选过严导致的空结果（提示放宽筛选+保留可关的筛选条件）。
- 性能与一致性：联想请求取消（AbortController）、搜索结果页与联想一致性（同一服务）、热搜词运营配置（可即时更新）。

```javascript
const ac = new AbortController();
input.on('input', debounce(async (q) => {
  ac.abort();                                // 取消上次
  const my = new AbortController(); setAC(my);
  const r = await suggestApi.get(q, { signal: my.signal });
  render(suggestGroups(r));                  // 历史/热/商品
}, 200));
// 纠错：results.corrected && banner(`已显示"${results.corrected}"的结果`)
// 无结果：<Empty suggestions={r.suggest}
//   altGoods={r.alternatives} onClearFilters={...}/>
```
