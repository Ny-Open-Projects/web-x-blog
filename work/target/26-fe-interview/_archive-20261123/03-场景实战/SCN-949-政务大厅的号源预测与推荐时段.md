## SCN-949：政务大厅的号源预测与推荐时段

**答**：
- 预测：历史排队数据预测各时段等待时长，预约页推荐「等待最短」时段。
- 模型：简单时间序列（同时段历史均值）+ 节假日修正。
- 前端：时段矩阵标注预计等待（绿/黄/红）。

```javascript
// 号源预测
function predictWait(history, slotHour) {
  const rows = history.filter(h => h.hour === slotHour && h.weekday === new Date().getDay());
  const waits = rows.map(r => r.avgWaitMin);
  const mean = waits.reduce((s, v) => s + v, 0) / (waits.length || 1);
  const level = mean < 10 ? 'green' : mean < 30 ? 'yellow' : 'red';
  return { estWaitMin: Math.round(mean), level,
    advice: level === 'red' ? '该时段平均等待超过 30 分钟' : null };
}
```
