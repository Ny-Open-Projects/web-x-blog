## SCN-777：审核系统权限与数据安全怎么设计？
**答**：
- 权限最小化：审核员只见被派任务的内容（不可搜索任意用户内容）；管理功能（改判/导出）独立角色强审批。
- 数据防泄露：内容 URL 短时效签名（审核会话内有效）、禁止下载原始文件、页面动态水印、外发检测（剪贴板大文本审计）。
- 操作留痕：每次内容访问（播放/查看详情）记访问日志，异常访问模式（深夜批量查看）触发审计。
- 离职管控：离职即时吊销凭证 + 权限回收自动化（HR 系统联动）。
- 追问钩子：为什么内容 URL 不能长期有效——审核员账号被盗或 URL 被转发即泄露；短时效签名 + 会话绑定把泄露窗口压到分钟级。

```javascript
const contentAccess = {
  url: (videoId) => signUrl(`/media/${videoId}`, { ttl: 900, bind: sessionId }),  // 15min 会话绑定
  audit: (action) => accessLog.write({ auditorId, action, ts: Date.now() }),
  anomaly: (logs) => detectPattern(logs, { rules: ['night-bulk', 'no-review-access'] }),
  offboard: (userId) => Promise.all([revokeToken(userId), releaseLocks(userId)]),
};
```
