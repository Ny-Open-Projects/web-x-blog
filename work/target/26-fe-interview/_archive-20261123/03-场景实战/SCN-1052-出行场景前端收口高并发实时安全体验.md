## SCN-1052：出行场景前端收口（高并发/实时/安全/体验）

**答**：
- 高并发：抢票排队（1003）/候补（1014）/风控（996）。
- 实时：航变推送（1005）/轨迹分享（1037）/大屏（1046）。
- 安全：动态凭证（1016）/虚拟号（1022）/录音合规（1020）。
- 体验：连座（1006）/省电（1024）/多语言（1032）。

```javascript
// 出行场景检查清单
const TRAVEL_CHECK = [
  { id: 'queue', test: s => s.submitQueueP95 < 30_000 },
  { id: 'push', test: s => s.flightPushLag < 30_000 },
  { id: 'qr', test: s => s.qrRefreshOk },
  { id: 'complaint', test: s => s.feedbackSlaHit > 0.95 },
  { id: 'offline', test: s => s.offlineNavReady },
];
function travelAudit(signals) {
  return TRAVEL_CHECK.filter(c => !c.test(signals)).map(c => c.id);
}
```
