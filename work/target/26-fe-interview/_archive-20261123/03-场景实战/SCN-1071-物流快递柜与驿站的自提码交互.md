## SCN-1071：物流快递柜与驿站的自提码交互

**答**：
- 自提：入柜/到站通知（取件码），超期提醒（占柜费规则）。
- 交互：扫码取件/取件码输入，代取（授权码）。
- 异常：柜满改派（驿站转投）通知。

```javascript
// 自提流程
function pickupFlow(parcel) {
  return {
    notify: pushCode(parcel.code),
    expireAt: parcel.expireAt,
    overdueFee: parcel.overdueFeeAfter,                // 超期占柜费
    proxy: genProxyCode(parcel),                       // 代取授权码
    fallback: parcel.full ? '已转投驿站，凭短信取件' : null,
  };
}
function genProxyCode(p) { return p.code + '-P'; }
```
