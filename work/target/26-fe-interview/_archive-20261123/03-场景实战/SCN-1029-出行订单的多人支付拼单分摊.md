## SCN-1029：出行订单的多人支付（拼单分摊）

**答**：
- 场景：团体票/拼车费多人分摊——发起者垫付+分摊链接（AA 收款）。
- 状态：各人支付进度（未付/已付），截止时间（未付者自动退出订单）。
- 兜底：未付满时发起者可补齐差额。

```javascript
// AA 分摊
async function splitPay(order, payers) {
  const share = Math.ceil(order.total / payers.length * 100) / 100;
  const links = payers.map(p => ({ uid: p.id,
    link: payLink(order.id, p.id, share) }));
  return { share, links, deadline: Date.now() + 30 * 60_000,
    onTimeout: '未付者自动移出，发起者可补差价' };
}
```
