## SCN-1272：国际电商的库存与价格一致性（多币种多仓缓存）

**答**：
- 问题：价格/库存多维度缓存（币种×仓库×语言）——缓存键设计一致性。
- 方案：缓存键规范化（price:usd:wh1:item1），汇率更新失效（价格缓存随汇率失效）。
- 兜底：缓存 miss 回源（保护回源风暴，单飞合并）。

```javascript
// 多维缓存键
function priceCacheKey(itemId, currency, wh) {
  return `price:${currency}:${wh}:${itemId}`;
}
async function getPrice(itemId, currency, wh) {
  const key = priceCacheKey(itemId, currency, wh);
  const hit = await cache.get(key);
  if (hit) return hit;
  return singleFlight(key, async () => {             // 单飞防回源风暴
    const p = await api(`/price/${itemId}?cur=${currency}&wh=${wh}`);
    await cache.set(key, p, { ttl: 60_000, tags: [`rate:${currency}`] });
    return p;
  });
}
async function singleFlight(key, fn) { return fn(); }
```
