## SCN-989：医疗问诊投诉与医疗纠纷的前端证据保全

**答**：
- 保全：聊天记录/处方/报告的完整性存证（哈希+时间戳，防篡改）。
- 投诉：纠纷投诉入口（提交时自动附带存证）。
- 合规：存证符合电子证据要求（第三方存证机构可选）。

```javascript
// 证据保全
async function evidencePreserve(sessionId) {
  const records = await api(`/consult/${sessionId}/evidence`);
  const hash = await sha256(JSON.stringify(records));
  const notarize = await api('/evidence/notarize', { hash, sessionId });
  return { certId: notarize.certId, hash,
    note: '第三方存证，可用于纠纷举证' };
}
```
