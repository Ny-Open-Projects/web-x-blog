## SCN-1042：出行场景的座位地图无障碍（轮椅席位）

**答**：
- 席位：轮椅席位（专用区域），预留规则（轮椅旅客优先，陪护相邻座）。
- 前端：轮椅席位标识与申请入口，客服协助通道。
- 合规：无障碍设施信息公示。

```javascript
// 轮椅席位
function wheelchairSeats(car, wheelchair) {
  if (!wheelchair)
    return car.seats.filter(s => s.wheelchair).map(s => ({ ...s, locked: 'reserved' }));
  return {
    seats: car.wheelchairSlots,
    companion: adjacentSeats(car.wheelchairSlots[0], 1),   // 陪护相邻
    assist: '客服协助通道 95xxx',
  };
}
function adjacentSeats(seat, n) { return [seat.nearby]; }
```
