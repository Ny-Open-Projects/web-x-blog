## SCN-1077：物流运单签收异常（拒收/破损）的处理流程

**答**：
- 流程：拒收登记（原因拍照）→ 退回/重寄决策（商家选择）→ 费用责任判定（谁承担）。
- 破损：破损举证（开箱视频要求），理赔流程（保价/未保价规则）。
- 前端：责任判定引导（按平台规则自动建议）。

```javascript
// 拒收处理
function rejectFlow(waybill, rejectInfo) {
  const responsible = judgeResponsible(rejectInfo);   // 责任判定
  return {
    evidence: rejectInfo.photos,                       // 拍照举证
    responsible,
    options: responsible === 'merchant'
      ? ['重寄（商家承担运费）', '退款']
      : ['退回', '协商'],
    claim: rejectInfo.damaged && waybill.insured
      ? claimInsured(waybill) : null,
  };
}
function judgeResponsible(info) { return 'merchant'; }
function claimInsured(w) { return { amount: w.value }; }
```
