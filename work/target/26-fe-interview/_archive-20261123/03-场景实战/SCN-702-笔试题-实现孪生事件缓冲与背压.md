## SCN-702：手写事件缓冲与背压控制器

**需求与边界**：
- 需求：事件进缓冲，rAF 合帧消费；缓冲水位三档（正常/高压/溢出），高压时向网关发降采样请求，溢出丢旧告警；critical 告警永不丢弃。
- 边界：① 同设备同类型事件在缓冲内去重（保留最新）；② 丢弃只针对 metric 类，alarm 类单独无界但告警风暴另限（SCN-698）；③ 背压请求幂等（相同档位不重复发）。

**答**：
```javascript
function createBackpressureBuffer(gateway, { high = 20_000, overflow = 50_000 } = {}) {
  const buffer = new Map();                            // key(deviceId:type) -> event（最新）
  const alarms = [];                                   // 无界但限流在 upstream
  let scheduled = false, currentLevel = 0;
  function push(event) {
    if (event.type === 'alarm') { alarms.push(event); return scheduleFlush(); }
    buffer.set(`${event.deviceId}:${event.metric}`, event);   // 去重保最新
    scheduleFlush();
    checkWater();
  }
  function checkWater() {
    const size = buffer.size;
    const level = size > overflow ? 2 : size > high ? 1 : 0;
    if (level === 2) {                                 // 溢出：丢一半最旧（Map 有序）
      const keys = [...buffer.keys()].slice(0, buffer.size / 2);
      keys.forEach(k => buffer.delete(k));
      report({ type: 'BUFFER_DROP', dropped: keys.length });
    }
    if (level !== currentLevel) {                      // 背压档位变化才发请求
      currentLevel = level;
      gateway.send({ op: 'rate', value: level === 2 ? 5 : level === 1 ? 20 : 100 });
    }
  }
  function scheduleFlush() {
    if (scheduled) return;
    scheduled = true;
    requestAnimationFrame(flush);
  }
  function flush() {
    scheduled = false;
    const metrics = [...buffer.values()];
    buffer.clear();
    if (metrics.length || alarms.length) apply([...alarms, ...metrics]);   // 告警优先
  }
  return { push, get size() { return buffer.size + alarms.length; } };
}
```

**评分点**:
- 按键去重保最新（同设备同指标多事件合一）。
- 三档水位 + 档位变化才发背压请求（幂等）。
- 溢出丢旧但 alarm 永不丢（分级策略）。
- rAF 合帧 + 告警优先应用。
