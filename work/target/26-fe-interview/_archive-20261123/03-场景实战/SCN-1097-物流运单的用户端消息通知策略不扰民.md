## SCN-1097：物流运单的用户端消息通知策略（不扰民）

**答**：
- 策略：关键节点通知（发货/派送/签收），中间节点不推（App 内可查）；静音时段。
- 合并：多包裹同时更新合并推送（一条消息列多单）。
- 设置：用户通知偏好（品类/时段自定义）。

```javascript
// 通知策略
function notifyStrategy(userPrefs, events) {
  const KEY = ['shipped', 'delivering', 'delivered'];
  const merged = groupByTime(events, 5 * 60_000);      // 5 分钟合并
  return merged.map(batch => ({
    send: batch.some(e => KEY.includes(e.type)),
    text: batch.length === 1 ? batch[0].desc
      : `${batch.length} 个包裹有新动态`,
    quiet: inQuietHours(userPrefs.quiet),
  }));
}
function groupByTime(events, ms) { return [events]; }
function inQuietHours(q) { return false; }
```
