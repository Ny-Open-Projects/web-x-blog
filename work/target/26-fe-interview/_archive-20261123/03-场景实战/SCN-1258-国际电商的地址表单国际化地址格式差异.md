## SCN-1258：国际电商的地址表单国际化（地址格式差异）

**答**：
- 差异：各国地址格式（日本都道府县/美国州 ZIP5/英国邮编正则）——地址 schema 按国适配。
- 前端：字段显隐/顺序/校验按国家配置化（address-form library 思路）。
- 验证：地址校验服务（邮编-城市匹配）。

```javascript
// 地址 schema
const ADDR_SCHEMAS = {
  JP: { fields: ['postal', 'prefecture', 'city', 'street'], zip: /^\d{7}$/ },
  US: { fields: ['street', 'city', 'state', 'zip'], zip: /^\d{5}(-\d{4})?$/ },
  GB: { fields: ['street', 'city', 'postcode'], zip: /^[A-Z]{1,2}\d[A-Z\d]? \d[A-Z]{2}$/i },
};
function addressForm(country) {
  const s = ADDR_SCHEMAS[country] ?? ADDR_SCHEMAS.US;
  return { fields: s.fields, zipPattern: s.zip };
}
```
