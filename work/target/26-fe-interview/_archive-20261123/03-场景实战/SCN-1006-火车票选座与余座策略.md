## SCN-1006：火车票选座与余座策略

**答**：
- 选座：靠窗/过道偏好 + 同行相邻（连座算法）；余座不足时提示拆分购买。
- 前端：座位图渲染（车厢布局模板），已售/可选/不可选状态。
- 兼容：无座提示（站票规则）与候补下单入口。

```javascript
// 连座分配
function assignSeats(remain, count, pref) {
  // remain: 可选座位 [{ car, row, col }]
  const sorted = remain.sort((a, b) => (a.car - b.car) || (a.row - b.row));
  for (let i = 0; i <= sorted.length - count; i++) {
    const chunk = sorted.slice(i, i + count);
    const sameRow = chunk.every(s => s.car === chunk[0].car &&
      s.row === chunk[0].row);
    if (sameRow && (!pref.window || chunk.some(s => s.col === 'A' || s.col === 'F')))
      return chunk;                                    // 连座命中
  }
  return { split: true, note: '无法连座，建议分开购买或候补' };
}
```
