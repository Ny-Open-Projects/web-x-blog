## SCN-1007：打车出行页面的状态机（呼叫/等待/行程中/支付）

**答**：
- 状态机：idle→calling(派单中)→matched(司机信息)→onboard(行程中)→payment→done；取消规则分阶段（派单后取消有责）。
- 前端：状态时间轴 + 司机位置地图（ETA 平滑更新）。
- 安全：行程分享（实时位置给紧急联系人）+ 一键报警。

```javascript
// 打车状态机
const RIDE_FSM = createMachine({
  idle: { call: 'calling' },
  calling: { matched: 'matched', timeout: 'idle', cancel: 'idle' },
  matched: { pickup: 'onboard', cancel: 'charged-cancel' },
  onboard: { arrive: 'payment' },
  payment: { paid: 'done' },
});
// 司机 ETA 平滑：新 ETA 与上次差值 > 3 分钟才更新（防跳变）
// 一键报警：onboard 状态常驻悬浮按钮
```
