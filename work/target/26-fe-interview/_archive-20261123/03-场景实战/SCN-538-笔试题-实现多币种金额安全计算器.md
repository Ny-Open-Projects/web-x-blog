## SCN-538：手写多币种金额计算器：整数定点运算 + 折算一致性校验

**需求与边界**：
- 输入：金额对象 `{ amount: "123456", scale: 2, currency: "USD" }`、汇率表 `{ pair: "USD->CNY", rate: "7.25", snapshotId }`；输出：折算/求和/展示。
- 边界要求：① 全程字符串定点运算，禁止 float；② 求和只允许同一 snapshotId；③ 折算按目标币种 scale 截断（不四舍五入到更大）；④ 非法输入抛业务错误而非 NaN。

**答**：
```javascript
function BigInt2str(n) { return n.toString(); }

function parse(m) {
  if (!/^-?\d+$/.test(m.amount)) throw new Error('BAD_AMOUNT');
  return { unscaled: BigInt(m.amount), scale: m.scale, currency: m.currency };
}
function alignScale(a, b) {                     // 对齐到较大 scale
  const s = Math.max(a.scale, b.scale);
  const up = (x) => x.unscaled * 10n ** BigInt(s - x.scale);
  return [up(a), up(b), s];
}
function add(m1, m2) {                          // 同币种加法
  if (m1.currency !== m2.currency) throw new Error('CURRENCY_MISMATCH');
  const [a, b, s] = alignScale(parse(m1), parse(m2));
  return { amount: BigInt2str(a + b), scale: s, currency: m1.currency };
}
function convert(m, rates) {                    // 跨币种折算（截断）
  const rate = rates[`${m.currency}->${m.to}`];
  if (!rate) throw new Error('NO_RATE');
  const r = parse({ amount: rate.rate, scale: rate.scale, currency: m.currency });
  const [a, rr] = alignScale(parse(m), r);
  const scaleDiff = BigInt(rate.toScale + rr.scale - a.scale);  // 目标 scale 校正
  const raw = a * rr / 10n ** BigInt(rr.scale);
  const truncated = raw * 10n ** scaleDiff / 10n ** scaleDiff;  // 定点截断
  return { amount: BigInt2str(truncated), scale: rate.toScale, currency: m.to, snapshotId: rate.snapshotId };
}
function sumSameSnapshot(list, rates) {
  const sids = new Set(list.map(x => x.rateSnapshotId));
  if (sids.size > 1) throw new Error('SNAPSHOT_MISMATCH');     // 汇率快照不一致拒算
  return list.reduce((acc, x) => add(acc, x), { amount: '0', scale: 2, currency: list[0].currency });
}
function format(m) {                            // 展示：千分位 + 固定小数位
  const neg = m.amount.startsWith('-');
  const [int, frac] = m.amount.replace('-', '').padStart(m.scale + 1, '0')
    .split(new RegExp(`(?=\\d{${m.scale}}$)`));
  return (neg ? '-' : '') + int.replace(/\B(?=(\d{3})+(?!\d))/g, ',') + '.' + frac;
}
```

**评分点**:
- 全 BigInt 定点运算，无任何 float 参与金额计算。
- scale 对齐策略（加法/乘法统一到最大 scale）。
- 快照一致性校验（SNAPSHOT_MISMATCH 拒绝求和）。
- 折算截断方向明确且 parse 对非法输入抛错（不产生 NaN）。
