## SCN-1056：物流轨迹地图的车辆实时位置（干线运输）

**答**：
- 轨迹：GPS 上报（30s）→ 轨迹纠偏（道路吸附）→ 地图回放（时间轴拖动）。
- 异常：长时间无上报（信号丢失）标注 + 最后位置显示。
- 性能：轨迹抽稀（Douglas-Peucker）后渲染（千点级）。

```javascript
// 轨迹回放
function trackReplay(points) {
  const simplified = douglasPeucker(points, 0.001);   // 抽稀
  return {
    draw(t) {                                          // t: 0~1 时间轴
      const idx = Math.floor(t * (simplified.length - 1));
      return simplified.slice(0, idx + 1);
    },
    gaps: findGaps(points, 5 * 60_000),                // 上报缺口标注
  };
}
function douglasPeucker(pts, tol) { return pts.filter((_, i) => i % 10 === 0); }
function findGaps(pts, th) { return []; }
```
