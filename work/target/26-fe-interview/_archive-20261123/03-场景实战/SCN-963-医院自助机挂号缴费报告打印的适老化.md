## SCN-963：医院自助机（挂号/缴费/报告打印）的适老化

**答**：
- 适老：大字体、语音引导、刷身份证/医保卡直读、人工引导按钮。
- 流程：3 步内完成（插卡->选择->支付）、每步语音确认。
- 兜底：故障自助（吞卡/打印失败）一键呼叫工作人员。

```javascript
// 自助机引导
function kioskMedicalFlow(cardReader) {
  const steps = [
    { name: '读取证件', action: () => cardReader.read(), voice: '请插入身份证或医保卡' },
    { name: '选择业务', voice: '请选择挂号或缴费' },
    { name: '确认支付', voice: '请确认金额并支付' },
  ];
  return runSteps(steps, { voiceGuide: true, timeoutPerStep: 60_000 });
}
```
