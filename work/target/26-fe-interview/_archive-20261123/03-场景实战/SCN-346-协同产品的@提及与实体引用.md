## SCN-346：协作产品里的 @提及（@人/@文档/@任务）联动体系怎么设计？

**答**:
- 实体引用协议：统一实体引用（type+id：@user/@doc/@task/@meeting——SCN-300 实体协议复用），渲染分型（@人高亮点击资料卡、@文档内联卡片可预览）、输入体验（@ 触发选择器：成员/文档搜索分片——SCN-218 联动复用）。
- 通知联动：提及通知（被@→通知中心+推送：来源上下文摘要——SCN-258 通知体系复用）、权限感知（@无权访问的文档→提示对方无权访问——引用前置校验）、引用即订阅（被@的文档变更通知提及者——可选订阅）。
- 任务联动：@任务显示状态卡（状态/负责人/截止——实时状态内联）、状态变更广播（任务状态变→所有引用处更新——SCN-477 增量更新复用）、文档转任务（选中文字→创建任务反向引用）。
- 数据一致性：被引用实体的生命周期（实体删除→引用处失效标记——SCN-217 撤回引用失效同源）、引用计数（实体被多少文档引用——删除影响面提示）。

```javascript
// 实体引用渲染
function MentionRef({ ref }) {
  const [state, setState] = useState(fetchState(ref)); // {status, owner}
  entityBus.on(`${ref.type}:${ref.id}`, setState);     // 状态广播更新
  return <EntityCard ref={ref} state={state}
    onClick={() => navigate(ref)} />;
}
// 通知：mention → notify({ target, context: snippet,
//   acl: checkAccess(target) })  // 无权 → 提示语替换
// 删除影响面：entity.delete → refCount(entity) > 0 &&
//   confirm('有 N 处引用，确认删除？') → 引用处失效标记。
```
