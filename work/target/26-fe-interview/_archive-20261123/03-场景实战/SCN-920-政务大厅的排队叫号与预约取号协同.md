## SCN-920：政务大厅的排队叫号与预约取号协同

**答**：
- 协同：预约用户到店取号（预约优先队列）、现场取号（普通队列）。
- 前端：取号机 UI 简化（大按钮/扫码）、取号凭证（二维码/短信）。
- 数据：队列状态与预约系统对接（预约未到释放号源）。

```javascript
// 预约取号协同
async function takeNumber(mode, identity) {
  const booked = mode === 'reserved'
    ? await api(`/booking/consume`, { identity })
    : null;
  const ticket = booked?.ticket ?? await api('/queue/take', { identity });
  printTicket(ticket);                               // 打印凭证
  notifySms(ticket.phone, ticket.no);
  return ticket;
}
```
