## SCN-861：降级开关矩阵怎么设计？
**答**：
- 开关分级：L1 关推荐/评论等非核心模块（保抢购）、L2 关实时库存推送改轮询、L3 静态兜底页（页面可开但购买关闭）、L4 活动页直接导流到正常商品页——每级预设触发条件。
- 开关生效：配置中心下发秒级生效 + 前端监听即时切换；开关本身有兜底默认值（配置中心挂了保持安全态）。
- 演练要求：活动前必须演练全档降级（每档人工触发验证 UI 与链路），未演练的开关视为不存在。
- 复盘联动：活动后统计各开关实际触发次数与效果，调整触发阈值。
- 追问钩子：为什么未演练的开关「视为不存在」——开关代码半年没跑过，真出事时大概率失效（配置丢失/逻辑过期）；演练是开关有效性的唯一证明。

```javascript
const degradeMatrix = {
  L1: { off: ['recommend', 'comment'], trigger: 'cpu > 70%' },
  L2: { off: ['stock-ws'], to: 'polling 5s', trigger: 'ws-fail-rate > 30%' },
  L3: { to: 'static-fallback', trigger: 'api-error > 50%' },
  L4: { to: 'redirect-normal', trigger: 'manual', note: '活动彻底失败时人工' },
  drill: { required: 'T-7d 全档演练', untestedAsMissing: true },
};
```
