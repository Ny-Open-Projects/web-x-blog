## SCN-996：医院号源放号的抢号体验（热门专家号）

**答**：
- 场景：热门专家号定时放号（秒杀模式）——排队机制（虚拟队列）替代并发抢。
- 实现：放号前进入等候室（排队号），放号按队列顺序分配（公平）。
- 防刷：一人一档（实名绑定限号）、频控（异常高频锁号风控）。

```javascript
// 排队放号
async function joinQueue(scheduleId) {
  const { position } = await api('/reg/queue/join', { scheduleId });
  return {
    position,
    eta: position * 2,                                 // 秒
    poll: () => pollPosition(scheduleId),              // 轮询位次
    note: '队列公平分配，无需反复刷新',
  };
}
// 风控：同身份证 24h 内取消 3 次 -> 限制当日挂号
```
