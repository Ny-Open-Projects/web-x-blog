## SCN-1040：出行场景的历史行程检索（多年订单查询）

**答**：
- 检索：多年订单搜索（按时间/线路/乘车人筛选），归档订单（冷存储）查询稍慢提示。
- 性能：索引化检索（服务端），前端分页+筛选条件下推。
- 导出：年度行程清单导出（报销用途）。

```javascript
// 历史检索
async function searchTrips(filter) {
  const r = await api('/trips/search', { ...filter,
    archived: filter.year < currentYear() });
  return { rows: r.rows, total: r.total,
    slow: r.archived ? '归档数据查询较慢' : null,
    export: () => exportTrips(filter) };
}
function currentYear() { return new Date().getFullYear(); }
```
