## SCN-917：政务跨部门联办事项的前端编排

**答**：
- 场景：一件事（如开餐馆）涉及多部门串联审批——前端展示联办进度总览。
- 编排：子事项并行/串行依赖图，材料复用（一次提交多部门共享）。
- 体验：统一表单（拆分到各部门字段），进度聚合展示。

```javascript
// 联办进度聚合
function jointProgress(jointItem) {
  const sub = jointItem.subItems;
  return {
    overall: sub.filter(s => s.status === 'done').length / sub.length,
    timeline: sub.flatMap(s => s.flow.steps.map(st => ({
      ...st, dept: s.dept, status: st.status }))),
    blockers: sub.filter(s => s.status === 'correction'),
  };
}
```
