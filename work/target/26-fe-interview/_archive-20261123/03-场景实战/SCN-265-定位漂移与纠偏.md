## SCN-265：定位漂移（高架下/写字楼一次跳 200 米），纠偏怎么设计？

**答**:
- 漂移识别：速度阈值（相邻两点距离/时间差 > 速度上限（步行 15km/h、驾车按上下文）→ 疑似漂移）、精度信号（accuracy 突然变大）、历史一致性（新点与预测位置（匀速外推）偏差过大）。
- 纠偏策略：滤波（卡尔曼滤波或简单指数平滑——位置平滑输出，消除抖动）、锚定吸附（若附近有可信历史位置/道路网，吸附到路网——地图厂商的路纠 API）、置信分级（高置信直用、中置信平滑、低置信保留上次位置并标注）。
- 展示策略：marker 平滑动画（位置更新插值移动而非瞬跳——用户体验的关键）、精度圈显示（accuracy 可视化让用户理解不确定性）、漂移时的状态提示（"定位信号弱"）。
- 业务联动：骑手/司机场景的位置上报带质量标记（服务端可区分可信位置），关键业务判定（是否到达）用服务端多源融合（GPS+基站+WiFi），前端只是采集与展示。

```javascript
class LocationFilter {
  constructor({ maxSpeed = 15 / 3.6, smooth = 0.3 }) { ... }
  feed(loc) {
    if (this.last) {
      const d = dist(this.last, loc);
      const dt = (loc.ts - this.last.ts) / 1000;
      const v = d / dt;
      if (v > this.maxSpeed || loc.accuracy > 100)
        return { ...this.last, drift: true };  // 漂移：沿用上次
    }
    // 指数平滑
    const out = this.last ? lerpLoc(this.last, loc, this.smooth) : loc;
    this.last = out;
    return { ...out, drift: false };
  }
}
// marker 动画：位置更新 → animate 800ms 移动（非瞬跳）
// 上报：{ ...out, quality: out.drift ? 'low' : 'ok' }
```
