## SCN-1058：物流配送地址的智能纠错与解析

**答**：
- 解析：非结构化地址 → 省/市/区/详细 结构化（地址库分词匹配）。
- 纠错：常见错误纠正（"杭州市西湖区"缺市补全）、行政区划更新（撤县设区映射）。
- 兜底：解析失败转人工审核（后台任务）。

```javascript
// 地址解析
async function parseAddress(raw) {
  const r = await api('/addr/parse', { text: raw });
  if (r.confidence < 0.8)
    return { ok: false, manual: true, candidates: r.candidates };
  const fixed = adminFix(r.parsed);                    // 行政区划修正
  return { ok: true, ...fixed };
}
function adminFix(addr) {
  const map = { '杭县': '杭州市' };
  return { ...addr, city: map[addr.city] ?? addr.city };
}
```
