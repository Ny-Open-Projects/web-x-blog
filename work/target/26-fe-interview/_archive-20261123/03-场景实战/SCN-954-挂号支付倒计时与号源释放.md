## SCN-954：挂号支付倒计时与号源释放

**答**：
- 规则：锁号后 10 分钟内支付，超时释放号源（放回池子）。
- 前端：倒计时强提醒（< 1 分钟变红）、超时后引导重新锁号。
- 兜底：支付中掉单（支付成功但挂号未确认）——对账补偿。

```javascript
// 支付倒计时
function payCountdown(expireAt, onExpire) {
  const timer = setInterval(() => {
    const left = expireAt - Date.now();
    renderCountdown(Math.max(0, left));
    if (left <= 60_000) document.body.classList.add('urgent');
    if (left <= 0) { clearInterval(timer); onExpire(); }
  }, 1000);
  return () => clearInterval(timer);
}
async function onExpire(slotId) {
  await api('/registration/release', { slotId });
  showRetryUI('号源已释放，请重新预约');
}
```
