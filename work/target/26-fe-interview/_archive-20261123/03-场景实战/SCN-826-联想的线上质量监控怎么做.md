## SCN-826：联想线上监控怎么做？
**答**：
- 三层监控：性能（input-to-suggest P95、服务端 P99）、质量（零结果率/采纳率/首条曝光点击率）、安全（坏词曝光计数——屏蔽词漏网的哨兵）。
- 质量哨兵：线上抽查（采样真实联想请求结果，离线质检器打分），坏词/不相关词自动进待处理队列。
- 告警阈值：零结果率突增（词库故障或服务异常）、延迟 P95 超 250ms、坏词计数 > 0（安全零容忍）。
- 归因维度：按版本/机房/词库批次切片定位。
- 追问钩子：为什么坏词监控是「零容忍」计数而不是比例——坏词（敏感/违规内容出现在联想位）是公关与合规事故，出现一次就是事故；比例容忍度不适用于安全类指标。

```javascript
const sugMonitoring = {
  perf: { inputToSuggestP95: 250, serverP99: 80 },
  quality: { zeroResultRate: { alert: 'baseline*2' }, adoptRate: { dropAlert: '10%' } },
  safety: { badWordCount: 0, policy: 'ZERO_TOLERANCE' },   // 计数告警非比例
  probe: { sample: 0.01, offlineJudge: true },             // 线上抽检离线打分
};
```
