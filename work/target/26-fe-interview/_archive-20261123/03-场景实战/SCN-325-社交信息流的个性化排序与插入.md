## SCN-325：信息流（推荐+关注+运营插入混合）的流式策略怎么实现？

**答**:
- 多源流混合：多队列合并策略（推荐主队列+关注队列+运营插入：广告/活动卡——按插入规则交错：每 N 条推荐插 1 条广告 M 条关注），插入规则配置化（运营可调——插入协议：{source, position, dedupe}）。
- 去重与连贯：已读去重（刷过的内容不再出现——浏览历史 fingerprint）、上下文连贯（话题连续内容聚合呈现）、回退保序（回滚到已看位置内容不变化——feed 快照窗口固定）。
- 刷新策略：下拉刷新语义（插入新内容在顶部+不重置当前位置——新内容提示条"有 12 条新内容"点击插入）、时间线模式与推荐模式切换（关注流按时间严格有序/推荐流无序）。
- 恢复与性能：无限流恢复（SCN 复用：位置+内容快照）、插入广告的曝光计费（曝光埋点准确性——可见性判定 IntersectionObserver 阈值，计费级曝光标准）。

```javascript
function mergeStreams({ recommend, following, inserts }) {
  const out = []; let ri = 0, fi = 0;
  for (let i = 0; out.length < 20; i++) {
    // 插入规则：第 5 位广告，每 8 条插 2 条关注
    const ins = inserts.find(x => x.position === out.length &&
      !x.used);
    if (ins) { out.push(ins.item); ins.used = true; continue; }
    out.push(i % 8 < 6 ? recommend[ri++] : following[fi++]);
  }
  return dedupeByFingerprint(out);           // 已读去重
}
// 刷新：newItems 检测 → 顶部提示条（不重置位置）
// 曝光计费：IO threshold 0.5 + 持续 1s → billable 曝光。
```
