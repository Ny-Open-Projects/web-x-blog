## SCN-326：内容审核状态（审核中/限流/下架）对可见性的影响怎么呈现？

**答**:
- 可见性矩阵：审核中（先发后审：粉丝可见+作者可见"审核中"标记；先审后发：仅作者可见）、限流（正常展示但不进推荐——作者可见限流提示）、下架（仅作者可见+下架原因）、违规删除（作者可见通知）——可见性矩阵服务端下发（策略可调），前端按矩阵渲染。
- 作者端呈现：状态透明（作品管理页每篇的状态与原因——审核中/限流/下架分别提示）、申诉通道（一键申诉+进度跟踪——申诉状态流转：待受理/复审中/结果）、修改重审（可编辑内容修复违规点重新审核）。
- 观众端呈现：审核通过前的过渡（点赞评论开放策略：审核中可互动吗——按合规策略）、下架内容的引用处理（转发了已下架内容→显示"内容已删除"占位——引用失效处理）。
- 通知体系：审核结果通知（驳回原因具体化：哪条规则违规——教育优于惩罚）、限流原因告知（"内容质量分不足，建议优化封面标题"）。

```javascript
// 可见性矩阵（服务端下发）
const VIS = {
  reviewing: { author: true, followers: fanFirst, public: false },
  limited:   { author: true, followers: true, public: true, noRec: true },
  removed:   { author: true, public: false },
};
function visibleTo(post, viewer) {
  const m = VIS[post.status];
  return viewer.id === post.author ? m.author
    : viewer.isFollower ? m.followers : m.public;
}
// 作者端：status + reason + appeal 入口
//   → appealApi.create(postId) → 进度跟踪
// 引用失效：repost of removed → '内容已删除' 占位。
```
