## SCN-1092：物流运单的下单向导（寄件流程步骤化）

**答**：
- 向导：寄/收地址→物品信息（类型/重量估值）→时效产品选择→确认下单。
- 校验：逐步校验（地址合法性/禁运品提示），物品类型联动限制（液体/电池限制）。
- 价格：实时试算（1060 规则引擎）嵌入步骤。

```javascript
// 寄件向导
const SHIP_STEPS = [
  { key: 'address', validate: validateAddr, next: 'items' },
  { key: 'items', validate: validateGoods, next: 'product' },   // 禁运提示
  { key: 'product', validate: () => true, next: 'confirm' },
  { key: 'confirm', validate: payReady, next: null },
];
function validateGoods(goods) {
  const banned = FORBIDDEN.find(f => goods.desc.includes(f));
  return banned ? { ok: false, reason: `${banned} 为禁运品` } : { ok: true };
}
```
