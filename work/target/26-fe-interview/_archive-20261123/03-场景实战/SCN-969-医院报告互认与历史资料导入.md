## SCN-969：医院报告互认与历史资料导入

**答**：
- 互认：不同医院检查结果互认（标注互认标识），避免重复检查。
- 导入：纸质报告拍照 OCR 导入个人健康档案（用户确认后入库）。
- 校验：OCR 结果与关键信息校对（医院/日期/项目名）。

```javascript
// 报告导入
async function importReport(photo) {
  const ocr = await ocrExtract(photo);
  const verified = {
    hospital: ocr.hospital, date: ocr.date,
    items: ocr.items.filter(i => KNOWN_ITEMS.has(i.name)),
  };
  const ok = await userConfirm(verified);             // 用户确认入库
  if (ok) await api('/health/import', verified);
  return { ok, unrecognized: ocr.items.filter(i => !KNOWN_ITEMS.has(i.name)) };
}
```
