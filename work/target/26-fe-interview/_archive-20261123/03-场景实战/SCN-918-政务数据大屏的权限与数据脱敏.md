## SCN-918：政务数据大屏的权限与数据脱敏

**答**：
- 权限：区/街道/部门数据范围隔离（按登录身份过滤）。
- 脱敏：大屏展示聚合数据（不出现个人明细），必要明细掩码。
- 水印：大屏截图水印（登录人+时间）防泄露溯源。

```javascript
// 大屏数据范围
function scopeFilter(user, query) {
  if (user.role === 'city') return query;             // 全市
  if (user.role === 'district') return { ...query, district: user.district };
  return { ...query, district: user.district, street: user.street };
}
function maskAgg(rows) {
  return rows.map(r => ({ ...r,
    name: r.name?.replace(/(.{1}).+(.)/, '$1**$2') }));  // 明细掩码
```
