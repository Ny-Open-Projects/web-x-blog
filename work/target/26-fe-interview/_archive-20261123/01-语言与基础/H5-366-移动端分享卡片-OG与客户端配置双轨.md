## H5-366：移动端分享卡片：OG 元信息与客户端配置双轨

**答**：
- 双轨机制：通用分享（浏览器/系统）读 Open Graph/Twitter meta 标签；微信/QQ 等客户端分享走 JS-SDK 配置（wx.updateAppMessageShareData）或服务端签名
- meta 标准清单：og:title/og:description/og:image/og:url（+ twitter:card），og:image 建议 1200×630 且 CDN 可达（爬虫抓不到就没卡片）；动态生成页要 SSR 输出 meta
- 微信特有：签名接口（jsapi_ticket）有时效，服务端缓存 + 域名白名单；未配置时分享卡片是默认抓取（图片随机）——分享转化率差异巨大
- 链接拼接规范：分享 URL 带分享者 ID/渠道参数（utm-like），落地页归因与安全校验（防伪造他人分享赚奖励）
- 落地体验：分享落地页要「直达内容 + 一键跳 App 深链」结构，而不是纯 H5 复制

```html
<meta property="og:title" content="我的年中账单">
<meta property="og:description" content="看看我这一年">
<meta property="og:image" content="https://cdn.example.com/share/2026/cover.png">
<meta property="og:url" content="https://m.example.com/bill/2026/u8821">
<meta name="twitter:card" content="summary_large_image">
```

```javascript
// 微信 JS-SDK 配置(签名由服务端下发)
wx.config({ ...await api.get('/jssdk/sign?url=' + location.href.split('#')[0]) });
wx.ready(() => {
  wx.updateAppMessageShareData({
    title: '我的年中账单', desc: '看看我这一年',
    link: `https://m.example.com/bill/2026/u8821?from=share&uid=${me.id}`,
    imgUrl: 'https://cdn.example.com/share/2026/cover.png',
  });
});
```
