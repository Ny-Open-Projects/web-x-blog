## CSS-405：笔试：手写文字特效

**题目**：实现三种文字效果：① 渐变字（background-clip: text + transparent 填充）；② 流动渐变（渐变位移动画，背景层动画而非文字重绘）；③ 描边字（-webkit-text-stroke 与 paint-order）；④ 镂空字（描边+透明填充）；⑤ 打字机效果（ch 宽度 + steps 动画）。写出核心实现与各自注意事项。

```css
/* ① 渐变字 */
.grad {
  background: linear-gradient(90deg, var(--primary), #ff8a00);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}
/* ② 流动渐变: 动画背景位置(重绘) vs 平移背景层(合成) —— 用 200% 宽层平移 */
.flow {
  position: relative; color: transparent;
}
.flow::before {
  content: attr(data-text);
  position: absolute; inset: 0;
  width: 200%;
  background: linear-gradient(90deg, var(--primary), #ff8a00, var(--primary));
  background-clip: text;
  -webkit-background-clip: text;
  animation: flow 2s linear infinite;
}
@keyframes flow { to { transform: translateX(-50%); } }
/* ③ 描边 + 填充顺序 */
.stroke {
  -webkit-text-stroke: 2px var(--primary);
  paint-order: stroke fill;          /* 描边在填色之下, 字不变形 */
}
/* ④ 镂空 */
.hollow { -webkit-text-stroke: 1px #333; color: transparent; }
/* ⑤ 打字机 */
.type {
  width: 12ch;                       /* 等宽步进 */
  white-space: nowrap; overflow: hidden;
  animation: typing 2s steps(12) forwards, caret .8s step-end infinite;
  border-right: 2px solid var(--primary);
}
@keyframes typing { from { width: 0; } }
@keyframes caret { 50% { border-color: transparent; } }
```

**评分点**：
- background-clip: text 三件套 + color transparent
- 流动渐变用伪元素平移（合成）而非 animate background-position（重绘）
- paint-order: stroke fill 解决描边吃字
- 打字机 ch + steps 步进 + 光标 border 动画
