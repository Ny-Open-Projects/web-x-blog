## WEB-370：开放重定向漏洞是什么？前端跳转逻辑要注意什么？
**答**：
- 形如 /login?redirect=https://evil.com：服务端/前端不校验就 302 或 location.href，被钓鱼利用（先到假登录页再回真站，用户难察觉）。
- 防御：白名单校验（只允许本站相对路径或已知域名）、禁止协议相对 //evil.com 与 javascript: 伪协议。
- 前端注意：router.push(redirect) 前校验 redirect.startsWith(斜杠) 且不以双斜杠开头；登录回跳场景必查。

```javascript
function safeRedirect(redirect) {
  if (!redirect || typeof redirect !== 'string') return '/';
  if (redirect.startsWith('//') || /^[a-z]+:/i.test(redirect)) return '/';
  return redirect.startsWith('/') ? redirect : '/';
}
console.log(safeRedirect('https://evil.com'));  // '/'
console.log(safeRedirect('//evil.com'));        // '/'
console.log(safeRedirect('/order/1'));          // '/order/1'
```
