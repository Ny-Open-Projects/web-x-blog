## JS-227：事件监听泄漏怎么系统性地防

**答**：
- 泄漏形态：window/document 上的监听器随组件反复挂载累积——匿名函数无法 removeEventListener（引用不同）
- 防线一：成对注册/注销（useEffect 返回 cleanup），handler 抽成稳定引用
- 防线二：AbortController 一键清理——`signal` 传入 addEventListener，`abort()` 移除全部该信号监听
- 防线三：注册中心统计（组件级 listener 计数，卸载时报告未释放项）
- 特殊场景：跨组件挂在 window 上的全局监听建议收敛到单例管理器，避免多处挂同一事件

```javascript
useEffect(() => {
  const ctl = new AbortController();
  window.addEventListener('resize', onResize, { signal: ctl.signal });
  document.addEventListener('click', onClick, { signal: ctl.signal });
  return () => ctl.abort(); // 一个调用清掉全部
}, []);
```
