## WEB-448：文件上传的前端校验有哪些，哪些能绕过

**答**：
- 前端校验三件套：扩展名白名单、MIME type 检查（file.type）、大小限制——全部可被篡改（改包/直调 API）
- 定位：前端校验只为体验（提前报错），真正的安全边界在服务端：魔数（magic bytes）校验、文件类型探测、重命名存储
- 存储防执行：上传目录禁止执行权限、存储域名与业务域名分离、图片服务单独域
- SVG 是特例：SVG 可内嵌 script，等于 XSS 载体，要么清洗要么禁上传
- 文件名：原始文件名不可信，做 slug 化与长度截断，防路径穿越（../../）

```javascript
// 前端体验层校验（安全边界在服务端）
const ACCEPT = { 'image/jpeg': [0xFF,0xD8], 'image/png': [0x89,0x50] };
async function sniff(file) {
  const head = new Uint8Array(await file.slice(0, 2).arrayBuffer());
  return Object.values(ACCEPT).some(sig => sig.every((b, i) => head[i] === b));
}
```
