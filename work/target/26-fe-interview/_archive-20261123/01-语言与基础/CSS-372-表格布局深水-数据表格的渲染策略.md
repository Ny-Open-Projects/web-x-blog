## CSS-372：表格布局深水：数据表格的渲染策略

**答**：
- 表格布局算法：table-layout: fixed 用首行定列宽（一次布局，快），auto 算法要看全部内容协调列宽（大表慢）——列宽固定的数据表一律 fixed + colgroup 定义
- 大表性能：千行表格 DOM 重、样式失效面大——方案：分页/虚拟滚动（行虚拟化）、固定列用 position: sticky（列头/首列 sticky 组合）、复杂单元格内容按需渲染
- sticky 表头组合：thead sticky top:0 + 首列 sticky left:0，注意 sticky 在 table 元素上的兼容实现（th 上 sticky 已支持）；斑马纹用 nth-child 伪类（paint 便宜）
- 与 div 网格的取舍：语义表格用 table（读屏可读行列关系），伪表格用 display: grid 布局（布局能力更强）——对外的数据表用语义 table + CSS 定制样式
- 行内编辑场景：编辑态切换单元格内容类型（text→input）引起行高跳变——单元格固定 min-height + 编辑控件尺寸对齐

```css
.data-table {
  table-layout: fixed;
  width: 100%;
  border-collapse: collapse;
}
.data-table th {
  position: sticky; top: 0;
  background: var(--bg);
  z-index: var(--z-sticky);
}
.data-table td:first-child { position: sticky; left: 0; }
.data-table tbody tr:nth-child(even) { background: color-mix(in oklab, var(--primary) 4%, white); }
```
