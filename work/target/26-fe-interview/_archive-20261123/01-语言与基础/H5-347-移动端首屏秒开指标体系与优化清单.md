## H5-347：移动端首屏秒开：指标体系与优化清单

**答**：
- 指标定义：秒开率 = FCP < 1s 的会话占比（App 内从点击到首屏可见）；采集用 performance timing + App 侧打点（点击→WebView 可见）；口径必须统一到「用户看到内容」
- 时间预算拆解：容器预热 100ms、HTML 获取 200ms（离线包/CDN）、资源加载 300ms（内联关键 CSS/预加载）、数据与渲染 400ms——按预算倒逼方案
- 方案清单按收益排序：离线包（Hybrid）> 接口预取（点击前预拉数据）> WebView 复用池 > SSR/流式渲染 > 图片策略 > 代码分包
- 数据与渲染并行：HTML 里内联首屏数据（服务端注入）或接口预取缓存命中，避免「资源好 → 再等接口」串行
- 监控闭环：按机型/网络/版本维度看秒开率分布，劣化自动告警；每次发版跑核心页面秒开回归

```javascript
// 首屏打点: 点击到 FCP 全链路
// App 侧: bridge 上报 clickTs, H5 侧对齐
const nav = performance.getEntriesByType('paint').find(p => p.name === 'first-contentful-paint');
const clickTs = Number(new URLSearchParams(location.search).get('t0') || 0);
beacon({
  fcp: nav?.startTime, clickToFCP: nav ? nav.startTime + nav.responseStart - clickTs : null,
  net: navigator.connection?.effectiveType, model: window.__DEVICE__,
});
```
