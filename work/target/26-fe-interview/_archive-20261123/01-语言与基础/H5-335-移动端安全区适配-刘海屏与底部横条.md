## H5-335：移动端安全区适配：刘海屏与底部横条

**答**：
- 核心 API：env(safe-area-inset-top/right/bottom/left)，需 viewport meta 带 `viewport-fit=cover` 才生效（默认 contain 模式下 inset 全 0）
- 典型场景：顶部导航加 `padding-top: calc(env(safe-area-inset-top) + 44px)`；底部操作栏 padding-bottom: env(safe-area-inset-bottom)（iPhone 底部横条）
- 兼容写法：`@supports (padding: max(0px))` 内用 max(env(), 原值) 保证不叠加；老内核不支持 env 时回退固定值
- 与 App 沟通：全屏 H5 在 App 内显示时，由原生告知沉浸式开关（WebBridge 约定），否则可能出现状态栏遮挡——CSS 适配 + 原生配置双保险
- 横屏与异形屏：inset 值随方向变化，用 CSS 变量封装 + resize 时重算（JS 端 getComputedStyle 读取）

```css
:root { --sat: env(safe-area-inset-top, 0px); --sab: env(safe-area-inset-bottom, 0px); }

.navbar {
  padding-top: calc(constant(safe-area-inset-top) + 44px);      /* 老 iOS */
  padding-top: max(env(safe-area-inset-top), 44px);
}
.footer-bar {
  padding-bottom: max(constant(safe-area-inset-bottom), 12px);
  padding-bottom: max(env(safe-area-inset-bottom), 12px);
}
```

```html
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
```
