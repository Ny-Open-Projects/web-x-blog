## WEB-535：公司代理环境下的开发联调排查

**答**：
- 常见故障：公司强制代理（PAC/全局）导致 npm 安装 404/超时、WebSocket 升级失败、SSE 被缓冲成一次性响应、自签证书报错
- 排查顺序：`env | grep -i proxy` 看环境变量 → 确认 npm/pip/git 各自的代理配置（各自独立）→ curl -v 看请求是否真的走了代理
- 典型场景对照：npm 装包失败设 registry 镜像或 proxy；WS 断连多为代理不支持 Upgrade；SSE 缓冲需代理透传（或本地直连绕过）
- 证书问题：公司代理做 HTTPS 解密时自签证书，Node 报 `UNABLE_TO_VERIFY_LEAF`——加公司根证书或 NODE_EXTRA_CA_CERTS
- 沟通产物：整理「新同学开发环境 checklist」，这类问题重复率极高

```bash
npm config set proxy http://proxy.corp.com:8080
export NODE_EXTRA_CA_CERTS=/path/corp-root.pem   # 公司代理自签证书信任
curl -v --proxy http://proxy.corp.com:8080 https://api.example.com
```
