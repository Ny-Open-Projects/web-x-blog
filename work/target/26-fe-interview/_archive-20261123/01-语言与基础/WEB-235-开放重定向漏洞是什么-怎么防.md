## WEB-235：开放重定向漏洞是什么？怎么防？

**答**：
- 漏洞：`https://login.example.com?redirect=xxx` 未校验就跳转。攻击者构造 `?redirect=https://evil.com`——钓鱼链接显示为可信域名，登录后却被带到仿冒站（常配合偷密码或继续钓鱼）。
- 升级危害：当 redirect_uri 参与 OAuth 授权码流程，code 会被发到攻击者域名，直接接管账号。
- 防御：白名单（只允许站内相对路径或预注册域名）；相对路径用 `/` 开头校验并拒绝 `//evil.com`（协议相对）与 `/\evil.com`（某些解析器当 /）；必须跳外域时给用户中间确认页。
- 前端注意：`location.href = getQueryParam('next')` 同样是前端重定向漏洞点。

```javascript
// 安全跳转
function safeRedirect(next) {
  // 只允许站内路径
  if (typeof next !== 'string' || !next.startsWith('/')) return '/default';
  if (next.startsWith('//') || next.startsWith('/\\')) return '/default'; // 防 protocol-relative
  return next;
}
location.href = safeRedirect(new URLSearchParams(location.search).get('next'));
```
