## CSS-232：oklch 色彩空间是什么，为什么设计系统在迁移

**答**：
- oklch 三轴：L 亮度（感知均匀）、C 色度（饱和度）、H 色相角——同样 L 值的任意色相，视觉亮度一致
- 相比 HSL 的优势：HSL 的「50% 亮度」在黄色与蓝色间视觉差异巨大；oklch 修正了这一点——梯度/色阶更均匀
- 广色域：oklch 可表达 P3 色域（比 srgb 艳丽的颜色），新设备上颜色更鲜亮，老设备自动降级
- 设计系统迁移动机：程序化生成色阶（L 等差）不再需要人工调；对比度计算更准确（无障碍达标容易）
- 兼容：Chrome 111+/Safari 15.4+/Firefox 113+；不支持时浏览器忽略整条声明，需提供 hex 兜底

```css
:root {
  /* 同亮度系列：视觉明度一致 */
  --brand:  oklch(62% 0.19 260);
  --danger: oklch(62% 0.19 25);
  --ok:     oklch(62% 0.19 145);
}
```
