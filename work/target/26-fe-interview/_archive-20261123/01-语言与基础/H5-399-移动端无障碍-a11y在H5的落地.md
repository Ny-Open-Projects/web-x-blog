## H5-399：移动端无障碍：a11y 在 H5 的落地

**答**：
- 移动端读屏（TalkBack/VoiceOver）依赖语义标签与 ARIA：自定义组件（下拉/弹层/开关）必须有 role/aria-expanded/aria-label，否则读屏读到「无标签按钮」
- 焦点管理：弹窗打开 focus 移入 + trap（Tab 循环在弹窗内）、关闭焦点还原；屏幕放大（iOS Zoom）下触达目标 ≥44pt
- 手势替代：滑动手势必须有按钮等价操作（纯手势操作对运动障碍用户不可用）、长按要有替代入口
- 动态内容播报：轮播切换/异步加载完成用 aria-live="polite" 通知读屏；toast 自动消失要可重新唤起
- 验证流程：iOS VoiceOver + Android TalkBack 真机走查核心链路（登录/下单），自动化用 axe-core 扫静态违规

```html
<!-- 自定义开关的正确语义 -->
<button role="switch" aria-checked="false" aria-label="接收推送">
  <span class="knob"></span>
</button>
<!-- 动态消息播报 -->
<div aria-live="polite" class="visually-hidden">{{ liveMsg }}</div>
<!-- 弹窗焦点陷阱 -->
<div role="dialog" aria-modal="true" aria-label="确认订单">
```

```javascript
dialog.addEventListener('keydown', (e) => {
  if (e.key !== 'Tab') return;
  const f = [...dialog.querySelectorAll('button,input,[tabindex="0"]')];
  const first = f[0], last = f[f.length - 1];
  if (e.shiftKey && document.activeElement === first) { last.focus(); e.preventDefault(); }
  else if (!e.shiftKey && document.activeElement === last) { first.focus(); e.preventDefault(); }
});
```
