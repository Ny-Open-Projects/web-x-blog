## JS-328：隐藏类与内联缓存：对象形状的性能

**答**：
- Hidden Class（Map）：V8 为每个对象形状维护隐藏类——属性添加顺序决定转换链（transition tree）；形状相同的对象共享同一隐藏类，属性访问走固定偏移，接近 C 结构体速度
- 内联缓存（IC）：属性访问点缓存「隐藏类 → 偏移」的映射；单态（一个形状）最快，多态（≤4 形状）变慢，超态（megamorphic）退回通用查表
- 破坏形状的写法：对象字面量中途增删属性（转换链）、不同顺序初始化相同属性对象（形状不同）、delete 属性——热点代码中这些都是 deopt 元凶
- 正确姿势：构造函数/class 里一次性声明全部属性（用 null 占位）、固定属性添加顺序、`Object.freeze` 高频只读配置对象
- 数组的形状：PACKED_SMI/PACKED_DOUBLE/PACKED_ELEMENTS 模式转换有成本——先 push 字符串再 push 数字会让数组进入通用模式，数值运算变慢

```javascript
// 反模式: 形状不一致
function make(o) { const r = { x: o.x }; if (o.y) r.y = o.y; return r; } // 两种形状
// 正确: 固定形状
function make2(o) { return { x: o.x, y: o.y ?? null }; } // 单一形状, IC 单态
// 数组模式
const a = [1, 2, 3];        // PACKED_SMI
a.push('s');                // 转为 PACKED_ELEMENTS, 后续数值运算变慢
```
