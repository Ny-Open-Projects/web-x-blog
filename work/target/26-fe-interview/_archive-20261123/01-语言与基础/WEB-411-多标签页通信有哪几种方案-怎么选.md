## WEB-411：多标签页通信有哪几种方案？怎么选？
**答**：
- BroadcastChannel：同源多页广播，最现代，API 简洁（postMessage/onmessage）。
- storage 事件：localStorage 写入触发其他页 storage 事件（自己页不触发），兼容性最好，但只能传字符串且低频。
- SharedWorker：共享一个 worker 中转，可维护连接状态；兼容性 Safari 已支持。选型：一般用 BroadcastChannel，老项目兜底 storage，需中心化状态用 SharedWorker。

```javascript
const bc = new BroadcastChannel('cart');
bc.postMessage({ type: 'ADD', sku: 1 });
bc.onmessage = (e) => syncCart(e.data);
// 兜底: window.addEventListener('storage', e => e.key === 'cart' && sync(e.newValue));
console.log('storage 事件自己页面不触发，广播靠别的页');
```
