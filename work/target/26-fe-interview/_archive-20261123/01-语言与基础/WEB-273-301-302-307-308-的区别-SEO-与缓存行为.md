## WEB-273：301/302/307/308 的区别？SEO 与缓存行为

**答**：
- 301 永久重定向：可被浏览器缓存（不设 Cache-Control 时启发式缓存），SEO 权重转移，换域名用它。
- 302 临时：不缓存，方法可被改为 GET（POST→GET 的历史兼容行为，叫「重新发动」）。
- 307：302 的严格版——不允许改变请求方法，POST 还是 POST；HSTS 内部跳转就是 307。
- 308：301 的严格版——永久 + 保持方法。
- 工程注意：登录后回跳表单页用 307/308 防 POST 丢 body；301 被浏览器缓存后想改回来极难（要 302 过渡或清缓存），谨慎下发。

```bash
# 观察缓存行为
curl -sI https://old.example.com | head -3
# HTTP/1.1 301  +  Cache-Control 缺失 → 浏览器可能长期缓存
curl -s -o /dev/null -w '%{redirect_url}\n' https://old.example.com
```
