## H5-408：移动端点击热区与交互反馈规范

**答**：
- 热区规范：可点击目标 ≥44×44pt（Apple）/48×48dp（Google），视觉小操作区用 padding 扩热区（button padding 或伪元素扩展）——列表删除按钮是高频误触点
- 误触防护：危险操作（删除/支付）二次确认或滑动验证；相邻按钮间距 ≥8pt；悬浮按钮避开系统手势区（底部横条）
- 反馈三件套：按下态（:active + touchstart 类切换，iOS :active 需要监听 touchstart 才生效）、loading 态防重复提交、结果反馈（toast/震动）
- 链接与按钮语义：a href 保持可中键/读屏使用；纯 JS 绑定 div 点击是不可接受的（无键盘/读屏支持）
- 验证：真机走查（拇指热区模拟）、highlight-tap 误触埋点（点空白区域占比）

```css
.icon-btn {
  min-width: 44px; min-height: 44px;
  display: inline-flex; align-items: center; justify-content: center;
  padding: 10px;                    /* 小图标扩热区 */
}
.icon-btn:active { opacity: .7; }   /* 按下反馈 */
```

```javascript
// iOS :active 失效修复
document.addEventListener('touchstart', () => {}, { passive: true });
// 防重复提交
btn.addEventListener('click', async () => {
  if (btn.disabled) return;
  btn.disabled = true; btn.classList.add('loading');
  try { await submit(); } finally { btn.disabled = false; btn.classList.remove('loading'); }
});
```
