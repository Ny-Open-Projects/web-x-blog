## CSS-400：笔试：手写树形列表缩进与连接线

**题目**：实现树形结构展示：① 嵌套 ul 缩进随层级递增；② 连接线（L 形引导线）用伪元素绘制，随层级对齐父节点；③ 展开/收起：details 原生或 class 控制，子树隐藏时引导线不残留；④ 节点图标（文件夹开/关）随展开态切换；⑤ 层级不限，无 JS 计算（缩进纯 CSS 继承）。写出核心实现。

```html
<ul class="tree">
  <li>
    <details open><summary>📁 src</summary>
      <ul>
        <li><details><summary>📁 app</summary>
          <ul><li class="leaf">📄 main.ts</li></ul>
        </details></li>
      </ul>
    </details>
  </li>
</ul>
```

```css
.tree, .tree ul {
  list-style: none;
  padding-inline-start: 0;
}
.tree ul {
  padding-inline-start: 24px;   /* 每层缩进: 纯CSS继承层级 */
  position: relative;
}
/* L 形引导线: 子列表左侧竖线 + 每个条目横线 */
.tree ul::before {
  content: ''; position: absolute;
  inset-block: 0; left: 8px;
  border-left: 1px solid #ddd;
}
.tree ul li {
  position: relative;
  padding-inline-start: 16px;
}
.tree ul li::before {
  content: ''; position: absolute;
  top: 12px; left: 8px; width: 12px;
  border-top: 1px solid #ddd;
}
/* 展开/收起图标随状态 */
summary .icon::before { content: '📁'; }
details[open] > summary .icon::before { content: '📂'; }
.tree .leaf { color: var(--fg); }
```

**评分点**：
- 嵌套 ul padding 递归缩进（层级自动，无 JS）
- 伪元素 L 线（列表竖线 + 条目横线）定位正确
- details 展开态与图标状态联动选择器
- 收起时子树整体隐藏无残留
