## WEB-472：证书过期事故，前端能提前做什么监控

**答**：
- 事故模式：自动续期静默失败 → 剩余天数归零 → 全站报 `ERR_CERT_DATE_INVALID`，用户无法访问，运营先于技术发现
- 监控三道哨兵：拨测服务每天读证书剩余天数（<14 天告警）→ CDN/网关层证书到期统一纳管 → 真实用户侧 RUM 采集 TLS 错误特征
- 前端可做的：页面 JS 捕获不到证书错误（发生在连接层），但可以在拨测脚本/CI 里用 openssl 检查
- 事后复盘要点：续期 timer 为何失效、ACME challenge 为何被拦（CDN 规则/防火墙）、多域名证书是否一损俱损
- 工程建议：证书到期纳入值班看板，与域名解析一起做「资产清单」

```bash
#!/bin/bash
# 到期日拨测（加入 cron）
for d in example.com api.example.com; do
  end=$(echo | openssl s_client -servername $d -connect $d:443 2>/dev/null | openssl x509 -noout -enddate | cut -d= -f2)
  days=$(( ($(date -d "$end" +%s) - $(date +%s)) / 86400 ))
  [ $days -lt 14 ] && echo "ALERT $d ${days}d" | tee -a cert-alert.log
done
```
