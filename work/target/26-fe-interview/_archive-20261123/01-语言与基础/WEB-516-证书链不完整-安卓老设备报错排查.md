## WEB-516：证书链不完整，安卓老设备报错怎么排查

**答**：
- 现象：桌面浏览器正常，部分安卓 WebView/老设备报证书错误——它们不擅长 AIA 补齐（服务端没发全链就自己去拉中间证书）
- 原理：服务器必须发送「服务器证书 + 中间证书」完整链；漏发中间证书时，系统信任库里有对应中间证书的设备碰巧能过，没有的就报错——于是「有些机器好有些坏」
- 排查工具：`openssl s_client -showcerts` 看服务端实际发了几个证书；SSL Labs 报告的 "Chain issues: Incomplete"
- 修复：重新拼接证书文件（fullchain.pem = server + intermediates），注意别把根证书也带进去
- 预防：证书更新流程里加链完整性校验步骤，换证书必跑 SSL Labs 或 openssl 验证

```bash
openssl s_client -connect example.com:443 -servername example.com -showcerts 2>/dev/null \
  | grep -c "BEGIN CERTIFICATE"   # 应为 2（服务器+中间证书），1 = 链不完整
```
