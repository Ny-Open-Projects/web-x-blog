## H5-404：移动端暗色模式落地：系统与业务双轨

**答**：
- 三来源优先级：App 下发（桥跟随 App 主题）> 用户站内选择（localStorage）> 系统偏好（prefers-color-scheme）；监听链各自维护
- CSS 方案：CSS 变量 + data-theme 属性切换（比 media query 单独写一套灵活，可被用户覆盖）；颜色 token 化（bg/fg/primary 三层语义变量）而不是逐处改色
- 图片适配：图片资产按主题出双套（SVG currentColor 首选）、照片类不反色（避免 filter: invert 简单粗暴导致肤色失真）
- 闪变防护：首屏内联主题判定脚本（data-theme 在 body 渲染前设置）+ transition 禁用窗口；cookie 同步服务端主题预判
- 灰度与度量：暗色模式开关灰度放量，对比暗色下的阅读完成率/退出率验证可用性；对比度抽检（WCAG AA）自动化

```css
:root { --bg: #fff; --fg: #222; --primary: #1677ff; }
[data-theme='dark'] { --bg: #121212; --fg: #e0e0e0; --primary: #4d9fff; }
body { background: var(--bg); color: var(--fg); }
/* 图片暗色微调: 仅降低亮度不反转 */
[data-theme='dark'] .photo { filter: brightness(.85); }
```

```javascript
// 首屏防闪: head 内联(渲染前)
const t = localStorage.getItem('theme')
  || (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
document.documentElement.dataset.theme = t;
```
