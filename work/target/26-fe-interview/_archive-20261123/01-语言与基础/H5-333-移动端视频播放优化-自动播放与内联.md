## H5-333：移动端视频播放优化：自动播放、内联与首帧加速

**答**：
- 自动播放规则：静音 + muted 属性 + playsinline 才允许自动播放（iOS/Android 一致），有声播放必须用户手势触发——营销页「进入即播」必须走静音方案
- 内联播放：iOS 必须 playsinline（或 webkit-playsinline 兼容）否则全屏接管；x5 内核（微信/QQ）要 x5-video-player-type="h5" 避免同层接管异常
- 首帧加速：poster 占位 + 预加载 metadata（preload="metadata"）、首帧关键帧对齐（服务端转码 GOP 设置）、进入视口才 load；HLS 用低延迟档位首开
- 弱网策略：video buffering 检测（stalled/waiting 事件）降码率或提示；ended 后 destroy 释放解码资源（移动端解码器是稀缺资源，多视频页面不释放会崩）
- 兼容坑集：微信 WeixinJSBridgeReady 后才能有声播放、X5 下 video 层级最高（同层渲染解决）、iOS 锁屏时 rAF 停但视频继续

```html
<video muted playsinline webkit-playsinline preload="metadata" poster="cover.jpg"
       x5-video-player-type="h5" x5-webkit-airplay="allow"></video>
```

```javascript
// 视口内才加载并自动播放
const io = new IntersectionObserver((ents) => {
  for (const e of ents) {
    const v = e.target;
    if (e.isIntersecting) { v.src ||= v.dataset.src; v.play().catch(() => {}); }
    else { v.pause(); }
  }
}, { threshold: 0.5 });
document.querySelectorAll('video[data-src]').forEach(v => io.observe(v));
```
