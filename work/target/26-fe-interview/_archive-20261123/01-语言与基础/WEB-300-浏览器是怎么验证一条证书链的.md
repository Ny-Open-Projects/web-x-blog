## WEB-300：浏览器是怎么验证一条证书链的？
**答**：
- 服务器下发"叶证书 → 中间证书"链，浏览器用内置信任的根 CA 公钥逐级验签：用上级公钥验证下级证书的签名。
- 逐级检查有效期、域名（CN/SAN）、密钥用法与扩展（Basic Constraints：CA=true 才能签发下级）、吊销状态。
- 常见事故：服务器忘了配中间证书，桌面浏览器靠 AIA 补链能救，但部分客户端/小程序环境直接报证书错误。

```javascript
const chain = [
  { subj: 'example.com', issuer: 'R3', ca: false },
  { subj: 'R3', issuer: 'ISRG Root X1', ca: true },
];
const roots = ['ISRG Root X1'];
function verify(chain, roots) {
  for (let i = 0; i < chain.length - 1; i++) {
    if (chain[i].issuer !== chain[i + 1].subj) return '链断裂';
    if (!chain[i + 1].ca) return '上级不是 CA';
  }
  const root = chain[chain.length - 1];
  return roots.includes(root.subj) ? '信任' : '不可信（缺中间证书时常见）';
}
console.log(verify(chain, roots));
```
