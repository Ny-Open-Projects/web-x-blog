## WEB-390：浏览器标签页为什么崩溃？内存上限是怎么回事？
**答**：
- 渲染进程崩溃常见原因：内存 OOM（超 V8 堆上限或系统内存压力）、native crash（GPU/驱动/第三方库）、被系统杀（移动端后台回收）。
- 上限不是固定值：64 位 V8 堆默认可达数 GB，但移动端更小；Canvas/WebGL 缓冲、Worker、iframe 都占进程内存。
- 工程对策：监控 memory（performance.memory + performance.measureUserAgentSpecificMemory）、大图缩略加载、分页渲染、崩溃自动 reload 与状态恢复。

```javascript
const mem = performance.memory;   // Chrome
console.log(mem.usedJSHeapSize / mem.jsHeapSizeLimit);
// > 0.8 触发降级：释放缓存/缩图/提示刷新
window.addEventListener('crash', () => location.reload()); // 渲染进程恢复
console.log('移动端更要当心：堆上限低且后台易被杀');
```
