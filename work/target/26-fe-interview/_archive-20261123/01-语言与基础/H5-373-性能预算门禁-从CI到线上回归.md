## H5-373：性能预算门禁：从 CI 到线上回归

**答**：
- 预算定义三层：传输预算（首屏 JS+CSS gzip < 200KB、图片 < 500KB）、运行时预算（JS 执行 < 1s @ 中端安卓、INP < 200ms）、业务预算（秒开率 ≥ 80%）
- CI 门禁：构建产物体积 diff 超 +5% 阻断（标注原因可豁免）；Lighthouse CI 跑核心页面指标不达阈值阻断合并——门禁要快（<10 分钟）否则会被绕过
- 线上回归：发布后自动对比上一版本核心指标（秒开/INP/错误率），劣化超阈值自动回滚或告警；性能数据按版本可追溯
- 预算治理：预算值由数据定（当前 P75 基线 × 改善目标），定期校准；豁免要留痕（原因+恢复期限）
- 文化配套：性能项进需求评审（动画/图片/接口数量预估）、CodeReview checklist（避免同步大循环、未懒加载图片）

```yaml
# lighthouserc (CI 门禁)
ci:
  collect: { numberOfRuns: 3, settings: { throttling: { rttMs: 150, throughputKbps: 1600 } } }
  assert:
    assertions:
      categories:performance: ['error', { minScore: 85 }]
      largest-contentful-paint: ['error', { maxNumericValue: 2500 }]
      total-byte-weight: ['error', { maxNumericValue: 700000 }]
      uses-responsive-images: warn
```
