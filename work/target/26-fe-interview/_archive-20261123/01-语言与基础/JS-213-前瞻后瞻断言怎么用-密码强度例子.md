## JS-213：前瞻后瞻断言怎么用：密码强度例子

**答**：
- 四种断言：前瞻 (?=…)/(?!…) 与后瞻 (?<=…)/(?<!…)[ES2018]——「只检查不消耗」位置
- 密码强度经典题：一个正则同时要求「含大写、含数字、含特殊字符、8 位以上」——用多个前瞻叠加
- 后瞻典型：`/(?<=¥)\d+/` 取人民币金额数字；`(?<!\d)5(?!\d)` 精确匹配独立的 5
- 性能提醒：断言链太长会放大回溯，配合长度上限使用

```javascript
// 8位以上 + 大写 + 数字 + 特殊字符
const strong = /^(?=.*[A-Z])(?=.*\d)(?=.*[!@#$%^&*]).{8,}$/;
strong.test('Ab1!xuyz');   // true
strong.test('ab1!xyz');    // false 无大写

// 后瞻：提取金额
'总价¥1299，优惠¥100'.match(/(?<=¥)\d+/g); // ['1299', '100']
```
