## CSS-402：笔试：手写聊天气泡

**题目**：实现 IM 气泡流：① 我方右侧靠右、对方左侧靠左（max-width 70%）；② 连续同发送者消息合并（首条带小尾巴三角、后续条目紧凑且隐藏尾巴；同发送者时间间隔 <3min 隐藏时间戳）；③ 撤回消息样式（居中灰色系统条）；④ 图片消息与文本消息混排；⑤ 消息复制悬浮操作按钮（桌面 hover 显示）。写出关键 CSS 与结构约定。

```html
<!-- 结构约定: data-mine / data-group-first / data-time-gap -->
<div class="msg mine group-first"><span class="tail"></span><p>你好</p><time>10:01</time></div>
<div class="msg mine"><p>在吗</p></div>
<div class="msg sys">对方撤回了一条消息</div>
```

```css
.msg {
  display: flex;
  margin: 2px 0;
  align-items: flex-end;
}
.msg p {
  background: #fff; border-radius: 12px;
  padding: 8px 12px; max-width: 70%;
  word-break: break-word;
}
.msg.mine { flex-direction: row-reverse; justify-content: flex-start; }
.msg.mine p { background: var(--primary); color: #fff; }

/* 小尾巴: 仅组首条 */
.msg [class] .tail { width: 0; border: 6px solid transparent; }
.msg .tail { border-left-color: #fff; }        /* 对方: 左尖 */
.msg.mine .tail { border-right-color: var(--primary); }
.msg:not(.group-first) .tail { display: none; }

/* 连续消息紧凑: 非组首去掉圆角过渡 */
.msg.mine:not(.group-first) p { border-top-right-radius: 4px; }

/* 时间戳: 间隔>3min 由渲染层标注 data-time */
.msg time { font-size: 11px; color: #999; align-self: flex-end; margin: 0 8px; }
.msg.sys {
  text-align: center; color: #999; font-size: 12px;
  background: none; padding: 8px 0;
}
/* 悬浮操作(桌面) */
.msg .ops { opacity: 0; transition: opacity .15s; }
.msg:hover .ops { opacity: 1; }
```

**评分点**：
- flex-direction: row-reverse 靠右 + max-width 70%
- 分组合并约定（group-first/tail 隐藏/圆角过渡）
- 时间戳折叠由渲染层 data 标注 + CSS 消费
- 系统消息独立样式、悬浮操作渐进显示
