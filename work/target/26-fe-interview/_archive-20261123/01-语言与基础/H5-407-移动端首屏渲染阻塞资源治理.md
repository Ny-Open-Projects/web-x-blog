## H5-407：移动端首屏渲染阻塞资源治理

**答**：
- 渲染阻塞清单：同步 CSS（必须但可拆分）、同步 JS（head 里不带 defer 的 script）、阻塞字体（font-display 未设 + preload 缺失）、同步第三方脚本（统计/广告 SDK）
- CSS 策略：关键 CSS 内联（首屏样式 <14KB）、非关键 CSS preload + onload 切换、媒体查询条件加载（print.css media=print）
- JS 策略：全部 defer/async，模块预加载（modulepreload）；第三方脚本延迟到 idle 加载或改服务端注入（埋点转发）
- 字体策略：font-display: swap + preload woff2 + 字体子集（H5-367）；FOIT 是移动端白屏文本主因
- 治理工具化：Lighthouse「Eliminate render-blocking resources」清单进 CI 门禁，新增阻塞资源 PR 必须解释

```html
<!-- 关键 CSS 内联 + 非关键异步 -->
<style>/* 首屏关键样式 内联 <14KB */</style>
<link rel="preload" href="/css/async.css" as="style" onload="this.rel='stylesheet'">
<noscript><link rel="stylesheet" href="/css/async.css"></noscript>
<!-- JS 全 defer + 预加载 -->
<link rel="modulepreload" href="/js/app.mjs">
<script type="module" src="/js/app.mjs" defer></script>
<!-- 字体 -->
<link rel="preload" href="/fonts/main.woff2" as="font" crossorigin>
```
