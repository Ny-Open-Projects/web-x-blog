## WEB-555：HTTP/3 迁移的监控指标体系怎么搭

**答**：
- 服务端面：h3 握手成功率、Retry 比例、0-RTT 接受率、h3 请求占比（命中率）、QUIC 连接迁移次数、UDP 缓冲区丢弃计数
- 前端面：nextHopProtocol 采样占比、按协议分组的 TTFB/LCP 分位数、h3 失败率（区分握手失败与请求失败）
- 网络面：分运营商/分地区的 h3 尝试失败率——UDP 拦截是按运营商聚集的，全局均值看不出问题
- 告警分级：命中率突降（Alt-Svc 没下发/证书问题）、失败率超阈（网络拦截/服务端故障）、长尾劣化（流控/拥塞配置）
- 数据闭环：监控发现异常地区 → 自动摘除该地区 Alt-Svc → 工单跟进，形成「探测-降级-恢复」自动化链路

```text
看板分层:
  L1 大盘: h3命中率 / 失败率 / TTFB分位(按proto)
  L2 维度: 运营商×地区 / RTT分桶 / 首连vs重连
  L3 内核: udp buffer errors / retry占比 / 0-RTT接受率
自动化: fail_ratio(地区)>15% 持续10min → 自动摘除该地区Alt-Svc + 告警
```
