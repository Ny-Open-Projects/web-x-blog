## WEB-384：拿到一个新站点，前端工程师先做哪些安全检查？
**答**：
- 响应头：CSP、HSTS、X-Frame-Options/frame-ancestors、X-Content-Type-Options: nosniff、Referrer-Policy 是否齐备。
- 注入面：用户输入渲染点（innerHTML/dangerouslySetInnerHTML）、文件上传类型限制、第三方脚本清单与 SRI。
- 凭证面：Cookie 属性（HttpOnly/Secure/SameSite）、token 存储位置、登出是否真吊销；再跑一次依赖 audit 与 sourcemap 泄漏检查。

```javascript
const checklist = [
  'CSP / HSTS / frame-ancestors 响应头',
  'innerHTML 注入点 & 富文本净化',
  'Cookie: HttpOnly+Secure+SameSite',
  'token 存储 & 登出吊销',
  '第三方脚本 SRI + CSP 白名单',
  'sourcemap 不上线 / npm audit',
];
console.log(checklist.join(' → '));
```
