## CSS-363：渐变引擎实现：插值空间、锯齿与性能

**答**：
- 渐变是绘制命令不是图片：linear/radial/conic 渐变在 paint 阶段由引擎光栅化——尺寸大/动画化（渐变动画）触发大面积重绘，性能差；动画渐变应改用 transform 移动渐变层（层已栅格化，仅合成）
- 插值空间：默认 sRGB 线性插值，两端色相跨度大时中间发灰——`linear-gradient(in oklch, ...)` 指定感知均匀空间；hue 插值方向（shorter/longer）也影响结果
- 条带（banding）：低色差渐变在 8bit 输出下出现色带——加噪（dithering 引擎自动）或叠加微噪纹理；oklch 空间 + 提高色差可缓解
- conic-gradient 应用：色环/进度环/饼图——配合 @property --p 注册数值变量做纯 CSS 进度环动画（变量动画触发 paint，注意成本，小面积可接受）
- 实战纪律：静态大背景渐变可栅格化一次缓存（同一元素不重绘）；渐变按钮 hover 用 color-mix 换色而不是重画渐变角度

```css
/* 动画渐变反例: 每帧全区域 repaint */
@keyframes bad { to { background: linear-gradient(90deg, red, blue); } }
/* 正解: 渐变层平移, 只合成 */
.strip { width: 200%; background: linear-gradient(90deg, in oklch, red, blue);
         animation: slide 3s linear infinite; }
@keyframes slide { to { transform: translateX(-50%); } }
/* 纯 CSS 进度环 */
@property --p { syntax: '<number>'; inherits: false; initial-value: 0; }
.ring { background: conic-gradient(var(--c) calc(var(--p)*1%), #eee 0); }
```
