## WEB-315：中间人攻击具体怎么发生？哪些环节能拦住它？
**答**：
- 典型链路：公共 WiFi ARP 欺骗/假热点 → 流量经攻击者 → 对 HTTP 直接篡改注入；对 HTTPS 则靠"假证书"骗用户点继续，或 DNS 劫持引导到假站。
- 防线：HTTPS 证书验证拦假证书、HSTS 拦降级与首跳、DNS over HTTPS 拦域名劫持、CT 日志拦 CA 滥签。
- 企业场景注意：装了公司根证书=公司可 MITM 你全部流量；证书报错时永远不要图省事点"继续访问"。

```javascript
// MITM 的三层拦截
const defense = {
  certCheck: '浏览器验证证书链，假证书报错',
  hsts: 'preload 列表域名拒绝用户点"继续"',
  doh: 'DNS 查询加密，防域名劫持',
};
const mitm = (site, defenses) =>
  defenses.hsts && defenses.certCheck ? 'HTTPS 站点被劫持难度极高' : '存在降级/假证书风险';
console.log(mitm('example.com', defense));
```
