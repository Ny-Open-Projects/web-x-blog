## JS-326：V8 堆结构：新生代、老生代与大对象空间

**答**：
- 新生代（New Space）：存放短命对象，Scavenge 算法（半空间复制）——From/To 两个空间来回拷贝存活对象，速度快、空间小（默认 1~8MB）；大部分对象「朝生夕死」在这里被快速回收
- 老生代（Old Space）：存活两轮 GC 的对象晋升于此，Mark-Compact（三色标记 + 整理）——空间大、耗时长，V8 用增量标记/并发标记把暂停拆碎，避免长停顿
- 大对象空间：超过半空间阈值（如 >256KB）的对象直接进 Large Object Space，不做复制——大 Buffer/长字符串在这里，分配成本高
- 其他区：Code Space（JIT 代码）、Map Space（隐藏类元数据）、Read-only Space（内置对象）
- 前端含义：高频创建大临时对象（大数组序列化）会直接打大对象空间，分配慢 + 晋升压力；优化方向是复用缓冲与流式处理

```javascript
// 触发不同空间行为的示例
const shortLived = { x: 1 };                  // 新生代: 快速回收
const bigBuffer = new ArrayBuffer(512 * 1024); // >256KB → 大对象空间, 慢分配
// 观察: DevTools Memory 快照 → 按 Space 分组看对象分布
```
