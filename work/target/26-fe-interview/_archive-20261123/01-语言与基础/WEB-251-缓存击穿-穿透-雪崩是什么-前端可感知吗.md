## WEB-251：缓存击穿、穿透、雪崩是什么？前端可感知吗？

**答**：
- 击穿：热点 key 缓存过期瞬间，大量请求同时打到数据库（对应 HTTP 侧就是热门资源 TTL 到期瞬间 CDN 回源风暴，CDN 有合并回源解决）。
- 穿透：查询不存在数据，缓存永远不可能命中，请求全部落库（对应 HTTP 侧是恶意扫描大量不存在的 URL 打回源）。
- 雪崩：大量 key 同一时刻过期（或缓存服务宕机），流量整体压垮数据库——HTTP 侧表现为全站静态资源同时到期。
- 通用解法：互斥重建（单飞 singleflight）、过期时间加随机抖动、逻辑过期不物理删除、空值缓存、多级缓存（浏览器→CDN→网关→Redis→DB）。
- 前端可感知/可做的：接口层请求去重（同 key 并发合并）、加 Jitter 的重试、监控 TTFB 突刺。

```javascript
// 前端请求去重（singleflight 思想）
const inflight = new Map();
function requestOnce(url) {
  if (!inflight.has(url)) {
    inflight.set(url, fetch(url).finally(() => inflight.delete(url)));
  }
  return inflight.get(url); // 10 个组件同时请求同 URL，只发一次
}
```
