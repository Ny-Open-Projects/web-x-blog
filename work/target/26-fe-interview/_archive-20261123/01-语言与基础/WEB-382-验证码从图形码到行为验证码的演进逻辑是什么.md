## WEB-382：验证码从图形码到行为验证码的演进逻辑是什么？
**答**：
- 图形码：OCR 已能批量破解，体验差基本淘汰；短信码防不住木马和 SIM 劫持，但有真实成本（限频）。
- 行为验证码（滑块/点选）：采集轨迹、加速度、环境特征给风控模型打分，人机分越小越像人；通过才放行或静默免验。
- 无感风控：正常用户零打扰，可疑用户加验证，高危直接拒绝——验证码正在从"人机区分"变成"风险分级"。

```javascript
const risk = await collect({ ua, fp, behavior, ipHistory });
if (risk.score < 0.3) return pass();           // 静默通过
if (risk.score < 0.7) return challenge('slider');
return deny();
console.log('无感验证：绝大多数用户不该见到验证码');
```
