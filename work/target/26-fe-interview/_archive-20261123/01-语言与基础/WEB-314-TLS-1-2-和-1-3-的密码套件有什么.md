## WEB-314：TLS 1.2 和 1.3 的密码套件有什么结构性差异？
**答**：
- 1.2 套件描述"密钥交换+认证+加密+摘要"四件套（如 ECDHE-RSA-AES128-GCM-SHA256）；1.3 套件只描述对称加密（如 TLS_AES_128_GCM_SHA256）。
- 因为 1.3 的密钥交换固定 ECDHE/PSK、认证固定证书，不再塞进套件名，套件数量从几十个缩到 5 个。
- 实战：1.3 里移除了 CBC、RC4、SHA1 与 RSA 静态交换，历史漏洞面大幅收窄。

```javascript
const suites = {
  '1.2': ['ECDHE-RSA-AES128-GCM-SHA256', 'DHE-RSA-AES256-SHA'], // 含交换算法
  '1.3': ['TLS_AES_128_GCM_SHA256', 'TLS_CHACHA20_POLY1305_SHA256'], // 纯对称
};
console.log('1.3 移除: RSA交换/CBC/RC4/SHA1 →', suites['1.3'].length, '个套件');
```
