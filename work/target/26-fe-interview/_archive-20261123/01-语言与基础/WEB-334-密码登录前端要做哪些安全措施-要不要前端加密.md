## WEB-334：密码登录前端要做哪些安全措施？要不要前端加密密码？
**答**：
- HTTPS 已保证传输加密，前端对密码做哈希/自定义加密的意义是防"密码原样进日志/内存堆栈"，不是替代 HTTPS，面试要先讲清这层认知。
- 必做：密码框 autocomplete="new-password" 防自动填充、type=password、错误提示模糊化（不区分"账号不存在/密码错"防撞库探测）。
- 配合：登录失败限次、设备指纹上报、可疑登录二次验证；绝不能把密码写进 URL 或埋点。

```javascript
// 前端仅做"防本地泄漏"处理，服务端负责加盐哈希
async function login(username, password) {
  const masked = '*'.repeat(password.length);      // 日志脱敏
  log('login attempt', username, masked);
  return api.post('/login', { username, password }); // TLS 保护传输
}
console.log('前端哈希若替代服务端哈希=把哈希当密码，错');
```
