## CSS-418：笔试：手写评论区楼中楼

**题目**：实现评论树：① 主楼 → 楼中楼嵌套（缩进 + 引导线，最多 3 层，更深折平）；② 「查看 N 条回复」折叠展开；③ 楼层序号自动编号（CSS counter）；④ 引用回复行（回复 @某人 高亮）；⑤ 头像+昵称+时间+操作行的布局。写出核心实现。

```html
<article class="cmt">
  <img class="av" src="a.jpg" alt="">
  <div class="body">
    <header><b>张三</b><span class="floor"></span><time>2小时前</time></header>
    <p>说得好</p>
    <div class="ops"><button>回复</button><button>赞</button></div>
    <button class="fold">查看 12 条回复</button>
    <div class="subs" hidden>
      <article class="cmt sub">
        <div class="body">
          <header><b>李四</b><span class="reply-to">@张三</span></header>
          <p>同意</p>
        </div>
      </article>
    </div>
  </div>
</article>
```

```css
.cmt { display: flex; gap: 12px; padding: 16px 0; }
.av { width: 40px; height: 40px; border-radius: 50%; }
.body { flex: 1; min-width: 0; }
.cmt header { display: flex; align-items: baseline; gap: 8px; }
.floor::after { content: counter(floor) '楼'; counter-increment: floor; font-size: 12px; color: #999; }
.cmts { counter-reset: floor; }

/* 嵌套缩进 + 引导线: 最多3层, 深层折平 */
.subs { margin-top: 12px; }
.cmt.sub { padding-inline-start: 0; border-inline-start: 2px solid #eee; padding-left: 12px; }
.cmt.sub .av { width: 28px; height: 28px; }
.cmt[data-depth='3'] .subs { margin-inline-start: 0; border: none; padding: 0; } /* 折平 */
.cmt[data-depth='3'] .subs .cmt { border: none; }

.reply-to { color: var(--primary); font-size: 13px; }
.fold { color: var(--primary); background: none; border: none; padding: 8px 0 0; font-size: 13px; }
.ops { opacity: 0; transition: opacity .15s; }
.cmt:hover .ops { opacity: 1; }
```

**评分点**：
- counter 楼层自动编号（reset 在列表容器）
- 嵌套引导线 border-inline-start + 3 层折平规则
- 「查看 N 条回复」折叠数据驱动
- min-width: 0 防长评论撑破布局、悬浮操作渐进显示
