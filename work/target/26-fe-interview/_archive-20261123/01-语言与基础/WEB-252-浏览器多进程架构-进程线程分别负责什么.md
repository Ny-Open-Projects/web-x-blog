## WEB-252：浏览器多进程架构：进程线程分别负责什么？

**答**：
- 主要进程：浏览器主进程（UI、书签、调度）、网络进程（HTTP 请求，独立于渲染进程）、GPU 进程（合成、WebGL）、插件进程、渲染进程（每站点一个，跑 Blink + V8，产出页面）。
- 渲染进程内线程：主线程（JS + 样式计算 + 布局）、合成线程（分层合成、滚动）、光栅线程、以及 Worker 线程。
- 为什么要多进程：进程隔离保证一个页面崩溃不拖垮浏览器；安全上渲染进程沙箱化，恶意页面拿不到系统权限。
- 对前端的实际影响：JS 与样式计算同线程互相阻塞（改大 DOM 触发重排卡帧）；合成器动画（transform/opacity）在合成线程跑所以不掉帧；跨进程通信（IPC）让 postMessage 有延迟。

- Renderer: 标签页进程（可能多个，站点隔离）
- Network Service
- GPU Process
