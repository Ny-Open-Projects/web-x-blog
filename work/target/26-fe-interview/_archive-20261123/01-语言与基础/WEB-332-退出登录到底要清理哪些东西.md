## WEB-332：退出登录到底要清理哪些东西？
**答**：
- 凭证：access/refresh token（内存、storage、Cookie 全清）；调服务端吊销 refresh，防止 token 继续有效。
- 缓存态：用户信息 store、权限码、路由注册的动态路由（resetRouter）、请求缓存与去重表、长轮询/WebSocket 连接。
- 其他：indexedDB/localStorage 里的业务缓存（如草稿可提示保留）、监控 SDK 的用户标识、清完后跳登录页防"回退键回到已登出页面"。

```javascript
async function logout() {
  await api('/logout').catch(() => {});   // 吊销 refresh
  clearTokens();                           // storage + cookie + memory
  store.resetUser();                       // 用户+权限
  router.getRoutes().forEach(r => r.meta?.dynamic && router.removeRoute(r.name));
  ws.close(); pollTimers.forEach(clearInterval);
  location.href = '/login';
}
console.log('清理清单越全，越少"退出后还能看到数据"的事故');
```
