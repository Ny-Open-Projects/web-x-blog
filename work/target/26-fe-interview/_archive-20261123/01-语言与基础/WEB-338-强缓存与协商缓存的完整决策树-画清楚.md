## WEB-338：强缓存与协商缓存的完整决策树，画清楚
**答**：
- 浏览器先查本地缓存副本并看 Cache-Control/Expires：max-age 未过期 → 直接用（200 from disk/memory cache），不发请求。
- 过期后带 If-None-Match（ETag）与 If-Modified-Since 去验证：服务器比对，未变回 304（空体），变了回 200 新内容+新缓存头。
- no-store 完全不缓存 > no-cache 强制协商 > max-age=0 也走协商；优先级 Cache-Control > Expires。

```javascript
// 请求决策树（伪代码）
const cache = disk.get(url);
if (cache && fresh(cache)) return cache.body;                 // 强缓存
const res = await fetch(url, { headers: {
  'If-None-Match': cache?.etag, 'If-Modified-Since': cache?.lastModified } });
if (res.status === 304) return cache.body;                    // 协商命中
disk.set(url, res.body, res.headers);                          // 更新
console.log('fresh = max-age 未超期且无 must-revalidate 限制');
```
