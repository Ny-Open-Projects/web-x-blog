## CSS-369：设计还原误差治理：像素级对齐流程

**答**：
- 误差来源分类：字体渲染差异（平台抗锯齿）、间距/尺寸实现偏差、色值转换偏差（sRGB/P3/设计工具色彩配置）、动效参数偏差——先归因再修
- 流程工具：设计稿标注导出（Figma dev mode token 同步）→ 实现 → 叠加对比（PerfectPixel/浏览器 overlay 截图对齐）→ 差异清单逐项闭环；token 同步脚本消灭「手抄色值」错误
- 尺寸体系约束：间距用 4/8 栅格 token、字号用 type scale——设计师与前端共用同一套 token 源，还原误差在源头消除
- 动效还原：缓动曲线/时长从设计标注直接导出 CSS 变量；复杂动效出 Lottie/参考视频帧对照
- 治理机制：像素 diff 报告进 PR（视觉回归截图）+ 设计走查清单（新页面必走），误差>2px 区域要标注原因或修正

```css
/* token 同步产物示例: Figma → CSS */
:root {
  --space-2: 8px;  /* from spacing/2 */
  --radius-md: 8px;
  --text-lg: 17px; /* from type/lg */
  --ease-out-quart: cubic-bezier(0.25, 1, 0.5, 1); /* from motion */
}
```
