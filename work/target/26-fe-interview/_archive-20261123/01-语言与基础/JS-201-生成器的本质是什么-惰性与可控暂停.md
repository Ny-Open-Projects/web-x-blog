## JS-201：生成器的本质是什么：惰性与可控暂停

**答**：
- 生成器函数（function*）不是「生成结果的函数」，而是「生成迭代器的工厂」——调用它不执行函数体，返回一个迭代器
- 核心能力：函数执行到 yield 处**暂停**，保存完整上下文（局部变量、执行位置），next() 时从断点恢复——普通函数做不到
- 惰性求值：不调 next 就不计算，序列可以无限长（按需产出）
- 控制流反转：生成器「被调用方推着走」，与普通函数「调用方被推着走」相反——这是 co/async 的基础
- 面试钩子：能说出「生成器 = 可暂停函数 + 迭代器协议」两个关键词即可

```javascript
function* counter() {
  console.log('start');
  yield 1;
  console.log('resumed');
  yield 2;
}
const g = counter();
console.log(g.next()); // { value: 1, done: false } ← 到这里才打印 start
console.log(g.next()); // 打印 resumed，返回 { value: 2, done: false }
console.log(g.next()); // { value: undefined, done: true }
```
