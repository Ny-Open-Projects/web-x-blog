## CSS-379：滚动综合案例：信息流首屏滚动性能优化全景

**答**：
- 案例背景：信息流（图片卡片流）滚动掉帧——排查路径：帧率采样定位 → Performance trace 归因 → 分项修复
- 常见归因一（JS）：scroll 里 getBoundingClientRect 逐卡检测曝光 → 换 IntersectionObserver（异步批量）；滚动中同步布局读写交错 → rAF 合并
- 归因二（样式）：卡片 hover 阴影动画（box-shadow 过渡全重绘）→ 换伪元素 opacity 过渡（预渲染阴影两层切透明度）；大圆角+阴影+模糊叠加提层爆炸 → 收敛层数
- 归因三（图片）：无宽高图片加载后高度跳变（layout 抖动+滚动锚定失效）→ aspect-ratio 占位；大图解码阻塞 → decoding: async + 按视口尺寸出图
- 归因四（层级）：content-visibility 缺失导致视口外卡片仍参与布局计算 → auto + intrinsic-size；修复后 P95 帧间隔从 25ms → 14ms

```css
/* 修复集 */
.card { content-visibility: auto; contain-intrinsic-size: auto 280px; }
.card__img { aspect-ratio: 16 / 10; object-fit: cover; width: 100%; }
.card__shadow {           /* 阴影动画: 伪元素透明度, 不重绘 */
  position: relative;
}
.card__shadow::after {
  content: ''; position: absolute; inset: 0;
  box-shadow: 0 4px 16px rgba(0,0,0,.15);
  opacity: 0; transition: opacity .2s;   /* 合成器动画 */
}
.card__shadow:hover::after { opacity: 1; }
```
