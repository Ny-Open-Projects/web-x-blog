## CSS-352：滚动条与滚动行为：自定义滚动条与平滑滚动

**答**：
- 自定义滚动条双轨：webkit 私有伪元素（::-webkit-scrollbar，Chrome/Safari）与标准 scrollbar-width/scrollbar-color（Firefox + Chrome 121+）——设计定制走双写，标准属性优先声明
- 滚动条占位差异：macOS 默认 overlay 滚动条（不占宽）、Windows 占宽（布局差 17px）——精确布局用 scrollbar-gutter: stable 预留，防止「有/无滚动条」切换抖动
- 平滑滚动：scroll-behavior: smooth 对 anchor/scrollTo 生效；JS 滚动 scrollTo({behavior:'smooth'}) 可控——但两者都走主线程路径，滚动期间用户再次操作要中断（scrollTo 不可取消的坑）
- scroll-snap：吸附点声明（snap-align/start-end proximity）+ scroll-padding 预留——轮播/卡片的正确工具，注意 snap 在惯性滚动中途不吸附（到静止才吸）的手感差异
- 隐藏滚动条的同时保可滚：width: none + overscroll containment——键盘/触摸仍可滚，无障碍上要保留滚动可达性

```css
.scroller {
  scrollbar-width: thin;                     /* 标准 */
  scrollbar-color: #999 transparent;
  scrollbar-gutter: stable;                  /* 预留滚动条位, 防抖动 */
  scroll-behavior: smooth;
}
.scroller::-webkit-scrollbar { width: 6px; } /* webkit 私有 */
.scroller::-webkit-scrollbar-thumb { background: #999; border-radius: 3px; }
.carousel { scroll-snap-type: x mandatory; }
.carousel > * { scroll-snap-align: center; }
```
