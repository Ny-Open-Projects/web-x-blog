## WEB-517：TLS 1.0/1.1 被禁用带来的兼容问题排查

**答**：
- 背景：主流 CA 与浏览器已禁用 TLS 1.0/1.1，只支持 1.2+；存量老设备（老安卓、老 POS、嵌入式 WebView）连接会握手失败
- 症状特征：只有特定机型/特定网络环境失败，报 `SSL protocol error` 或超时，桌面全正常
- 排查：先用 openssl 指定版本测试 `openssl s_client -tls1_2` 确认服务端支持；再从失败样本收集 TLS 版本（服务端日志/RUM）
- 应对：面向企业内部的老设备走单独网关（临时开 1.2 兼容）或客户端升级；对外业务直接要求升级
- 讲清取舍：为极小存量用户重新打开弱协议是安全倒退，多数公司选择「公告+统计后硬切换」

```bash
openssl s_client -connect api.example.com:443 -tls1_2 </dev/null 2>&1 | grep -E "Protocol|Cipher"
openssl s_client -connect api.example.com:443 -tls1 </dev/null 2>&1 | grep -E "alert|error" # 应失败
```
