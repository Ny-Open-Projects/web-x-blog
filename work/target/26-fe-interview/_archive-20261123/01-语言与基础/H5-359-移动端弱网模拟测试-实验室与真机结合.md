## H5-359：移动端弱网模拟测试：实验室与真机结合

**答**：
- 模拟手段分层：DevTools Network throttling（快速但粗糙）、代理工具 Charles/clumsy 注入延迟丢包、真机弱网测试仪（专业实验室模拟 2G/高丢包/高抖动）、真实弱网环境（电梯/地库实测）
- 弱网画像参数化：带宽 100kbps~1Mbps、RTT 200~800ms、丢包 1~5%、抖动——按业务用户分布设定矩阵（农村/地铁/跨境）
- 测试要点清单：首屏白屏时长、骨架屏显示时机、图片占位体验、请求超时与重试风暴、离线兜底文案、弱网下支付链路
- 自动化：CI 里用代理脚本注入弱网跑核心流程（登录/下单/支付），断言「白屏 < 3s、无卡死」；真机抽样人工走查每版本
- 数据交叉验证：实验室结论要与线上弱网用户（按 connection effectiveType 分桶）真实指标对比校准

```javascript
// 弱网体验探针: 记录骨架屏出现与首屏数据到达的时序
performance.mark('skeleton-shown');
await fetchFirstScreen();
performance.mark('data-ready');
performance.measure('skeleton-duration', 'skeleton-shown', 'data-ready');
// 弱网断言: skeleton-duration 应接近网络耗时, 且不出现长时间无反馈
```
