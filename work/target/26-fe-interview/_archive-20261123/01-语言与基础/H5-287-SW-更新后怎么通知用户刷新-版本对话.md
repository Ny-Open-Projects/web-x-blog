## H5-287：SW 更新后怎么通知用户刷新：版本对话

**答**：
- 检测更新：`registration.update()` 主动查 + 导航时自动查；发现 registration.waiting 即有新版本待激活
- 通知 UI：底部 toast「新版本已就绪，点击刷新」——比强制 reload 优雅，不打断用户操作
- 激活链路：用户点击 → 向 waiting SW 发 skipWaiting 消息 → 监听 controllerchange → reload
- 防重复提示：sessionStorage 记已提示；用户选择「稍后」则下次导航再提示
- 另一路径：告知用户但走「自然生效」——等用户关闭页面下次打开自动新版本，适合低频更新

```javascript
if (registration.waiting) showUpdateToast(async () => {
  registration.waiting.postMessage('SKIP_WAITING');
  navigator.serviceWorker.addEventListener('controllerchange', () => location.reload(), { once: true });
});
```
