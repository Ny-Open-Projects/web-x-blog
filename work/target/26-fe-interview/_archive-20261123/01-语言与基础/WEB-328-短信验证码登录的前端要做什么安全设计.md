## WEB-328：短信验证码登录的前端要做什么安全设计？
**答**：
- 发送侧：图形/行为验证码前置、按手机号+IP 双维度限频（如 1 分钟 1 条、1 天 10 条）、倒计时按钮防连点。
- 输入侧：验证码不回显不预填、错误次数锁定、防脚本暴力（6 位码只有 100 万种组合，必须限次）。
- 交互细节：粘贴板嗅探自动填码要小心（iOS 安全码自动填充是系统级、可信；自实现读取剪贴板涉及隐私合规）。

```javascript
const sendSms = async (phone) => {
  await captcha.verify();                       // 行为验证前置
  if (cooldown(phone) || quotaExceeded(phone, ip)) throw '发送过频';
  startCountdown(60);
};
const submit = async (code) => {
  if (attempt >= 5) return lock(phone);         // 限 5 次
  return login({ phone, code });
};
console.log('限频 + 限次 + 验证码前置 = 三道闸');
```
