## CSS-383：桌面端重页面性能案例：管理后台渲染优化

**答**：
- 案例背景：管理后台（大表格+多图表+侧栏）切换菜单卡 300ms——trace 归因：全页样式失效（全局 class 切换）+ 图表容器 reflow + 无效的全局过渡
- 修复一（失效面）：菜单切换动画从「body 加 class 全局过渡」改为「局部容器 transform」——失效范围从全页缩到容器；transition 禁用 `* { transition: all }` 模式
- 修复二（图表）：图表容器 contain: layout paint + 固定尺寸（数据更新只重绘 canvas）；窗口 resize 防抖重排
- 修复三（表格）：table-layout: fixed + content-visibility 隐藏区外行 + sticky 表头；列宽显式声明消除 auto 算法的全表协调
- 修复四（样式共享）：表格行 class 统一（状态类挂单元格而非行）保持共享命中——菜单切换时表格重算从 200ms → 8ms

```css
/* 修复集 */
.layout-main { transition: transform .3s; }        /* 局部动画 */
.chart { contain: layout paint; height: 320px; }  /* 图表隔离 */
.data-table { table-layout: fixed;
  contain-intrinsic-size: auto 44px; }
.data-table tr { content-visibility: auto; }      /* 视口外行跳过 */
```
