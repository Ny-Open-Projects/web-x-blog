## CSS-390：CSS 迁移工程：存量样式渐进重构

**答**：
- 迁移策略：增量冻结（新代码必须新规范，存量按页面改造）→ 死代码清除（coverage 工具找出未用选择器，多版本流量验证后删除）→ 分批重构（按组件域，每批带视觉回归）
- 工具链支撑：stylelint 规则分级（error 阻断新违规 / warning 存量白名单，白名单只减不增）；CSS coverage（Chrome coverage/PurgeCSS 报告）量化死代码
- 迁移安全网：视觉回归基线（迁移前截图锁定）+ 真机抽验 + 灰度发布（新样式按路由灰度）——样式重构没有单测，截图是唯一安全网
- 双轨共存技巧：@layer 声明新旧层顺序（新规范层优先），存量样式层不被新层意外覆盖；迁移完成后删除旧层
- 度量收敛：选择器复杂度分布/!important 数量/未用率趋势图进技术债看板——重构效果要可量化，防止「迁了个寂寞」

```text
迁移路线:
  W1: lint 分级 + 存量白名单冻结
  W2: coverage 报告 → 死代码清单 → 灰度删除
  W3~N: 按组件域重构, 每批: 截图基线 → 改造 → diff 评审 → 灰度
  收敛: 白名单清零, 新规范覆盖率 >95%
```
