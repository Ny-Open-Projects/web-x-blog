## WEB-393：为什么合成器线程还在跑时，主线程卡死滚动也能动？
**答**：
- 合成器滚动走的是独立的合成器线程：wheel/touch 触发的纯滚动位移直接在合成层上变换，不进主线程。
- 但滚动监听的 JS 回调在主线程：主线程卡顿不影响"画面跟手滚动"，影响的是滚动联动效果（header 缩放）与 scroll 事件频率。
- 推论：把滚动动效放在 CSS（scroll-timeline）或合成器可处理的地方，比 JS 监听 scroll 丝滑得多。

```javascript
// scroll 事件在主线程 → 卡顿时回调延迟
// CSS scroll-driven animation 在合成器 → 跟手
@keyframes grow { to { transform: scaleX(1); } }
/* .bar { animation: grow linear; animation-timeline: scroll(); } */
console.log('滚动位移=合成器线程；scroll 回调=主线程');
```
