## H5-398：折叠屏与大屏适配：多窗口形态的布局策略

**答**：
- 形态感知：折叠屏展开后视口宽高比与屏幕尺寸突变（+resize 事件/媒体查询），平板横竖屏切换——布局要「跟随视口」而非「跟随设备假设」
- 断点体系：手机竖屏（<768）单列 → 大屏/展开（768~1200）双列内容+侧栏 → 桌面（>1200）全布局；组件级用容器查询比页面级断点更灵活
- 动态视口单位：dvh/svh 替代 vh（地址栏/窗口变化），vmax/vmin 在旋转时的语义变化要注意
- 多窗口/分屏：Android 分屏时 H5 视口变小，布局要能自适应小窗；Chrome 桌面大屏模式（foldable desktop mode）出现「类平板」视口
- 测试矩阵：折叠屏展开/折叠过程动画期间的布局抖动（resize 节流重算）、铰链区不可点击区域规避（DisplayCutout 类似安全区）

```css
/* 容器查询: 组件级响应 */
.product-card { display: flex; flex-direction: column; }
@container (min-width: 480px) {
  .product-card { flex-direction: row; }
  .product-card__img { width: 40%; }
}
/* 视口单位 */
body { min-height: 100dvh; }
```
