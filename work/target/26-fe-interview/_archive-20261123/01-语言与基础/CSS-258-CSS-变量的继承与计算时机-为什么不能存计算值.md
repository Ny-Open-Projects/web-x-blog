## CSS-258：CSS 变量的继承与计算时机

**答**：
- 变量按「声明时的词法作用域」继承：元素读到的 --x 是最近祖先的声明值，子元素覆盖只影响自己子树
- 关键机制：变量值在使用处才求值（invalid at computed-value time）——`--x: 1px; width: var(--x) * 2` 不合法（var 是整体替换，不参与 calc 拆解）
- 经典坑：`calc(var(--w) / 2)` 合法，但 `var(--w) / 2` 直接写不合法；变量里存「表达式字符串」在继承后按接收方上下文解析
- @property 的解法：注册类型后变量有「计算值语义」，可参与插值/动画（回到 CSS-206）
- 面试话术：变量是「词法作用域 + 延迟求值 + 整体替换」，三点说全即懂

```css
.parent { --x: 10px; }
.child  { --x: 20px; }            /* 只影响 .child 子树 */
.thing  { width: calc(var(--x) * 2); } /* ✅ 20px 的 2 倍 */
/* .thing { width: var(--x) * 2; }   ❌ 整体替换后 "10px * 2" 语法错误 */
```
