## JS-209：无限序列与惰性求值：生成器的典型应用

**答**：
- 无限序列：生成器循环内 yield 即可——数组存不下，生成器「用到才算」
- 组合管道：多个生成器串联（map/filter 的生成器版）逐条流式处理，内存 O(1)
- 典型场景：斐波那契、素数筛、随机数流、日志尾部持续读取（tail -f 语义）
- 对比数组方案：百万级数据 map+filter 建多个中间数组；生成器管道瞬时处理一条

```javascript
function* fibonacci() {
  let [a, b] = [0, 1];
  while (true) yield [a, b = b, b + a][0];
}
function* take(it, n) {
  for (let i = 0; i < n; i++) {
    const { value, done } = it.next();
    if (done) return;
    yield value;
  }
}
console.log([...take(fibonacci(), 8)]); // [0,1,1,2,3,5,8,13]
```
