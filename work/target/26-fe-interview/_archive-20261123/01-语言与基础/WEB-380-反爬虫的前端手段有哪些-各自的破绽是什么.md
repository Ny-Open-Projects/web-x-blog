## WEB-380：反爬虫的前端手段有哪些？各自的破绽是什么？
**答**：
- 手段：代码混淆（jsjiami）、字体反爬（字形映射价格）、环境检测（headless 特征）、行为验证码、接口签名（time+sign）、TLS 指纹。
- 破绽：混淆可被还原AST、字体可采样破解、headless 可伪装、签名可被逆向——前端手段都是提高成本而非绝对防线。
- 正确姿势：前端抬门槛，后端做频控+风控+水印（数据里埋 traceID 追溯泄露源）。

```javascript
// 接口签名示意
const sign = (params, salt) => md5(qs(sortKeys(params)) + salt + ts());
fetch('/api/price', { headers: { 'X-TS': ts, 'X-SIGN': sign({ sku: 1 }, salt) } });
// salt 藏在 JS 里=可被逆向，本质是成本博弈
console.log('前端反爬 = 提高攻击成本，不是绝对防御');
```
