## CSS-399：笔试：手写步骤条

**题目**：实现横向步骤条：① 三种节点状态：完成（√ 填充）、当前（高亮呼吸）、未达（灰色）；② 节点间连接线按完成度渐进填充（用 ::before 按比例宽度）；③ 步骤数不定，均分宽度自适应；④ 当前节点数字/图标切换；⑤ 垂直变体（media 或 class 切换轴向）。写出核心实现。

```html
<ol class="steps" style="--cur: 2; --total: 4">
  <li class="done">注册</li>
  <li class="done">验证</li>
  <li class="cur">支付</li>
  <li>完成</li>
</ol>
```

```css
.steps {
  display: grid;
  grid-auto-flow: column;
  grid-auto-columns: 1fr;      /* 均分自适应步骤数 */
  counter-reset: step;
}
.steps li {
  position: relative;
  text-align: center;
  color: #999;
  counter-increment: step;
}
.steps li::before {          /* 节点 */
  content: counter(step);
  display: inline-flex; align-items: center; justify-content: center;
  width: 32px; height: 32px; border-radius: 50%;
  background: #eee; margin-bottom: 8px;
}
.steps li::after {           /* 连接线: 完成比例宽度 */
  content: ''; position: absolute;
  top: 16px; left: calc(50% + 20px);
  width: calc(100% - 40px); height: 2px;
  background: linear-gradient(to right, var(--primary) var(--fill, 0%), #eee 0);
}
.steps li:not(:last-child)::after { --fill: 100%; }
.steps li.done { color: var(--primary); }
.steps li.done::before { content: '✓'; background: var(--primary); color: #fff; }
.steps li.cur { color: var(--primary); }
.steps li.cur::before {
  background: var(--primary); color: #fff;
  animation: pulse 1.5s infinite;
}
@keyframes pulse { 50% { box-shadow: 0 0 0 6px color-mix(in oklab, var(--primary) 20%, transparent); } }
```

**评分点**：
- grid-auto-columns: 1fr 自适应任意步骤数
- 连接线用渐变 stop（--fill 百分比）实现部分填充
- done/cur/未来三态样式与 done::after 满填充逻辑
- counter 自动编号 + 当前态呼吸动画
