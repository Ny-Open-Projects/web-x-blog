## WEB-272：负载均衡的几种策略？会话保持怎么处理？

**答**：
- 常见策略：轮询（均摊）、加权轮询（按机器性能）、最少连接、IP hash（同 IP 固定机器）、一致性哈希（缓存场景，扩缩容只迁移少量 key）。
- 四层 vs 七层：四层（LVS）按 IP+端口转发快，七层（Nginx/网关）按 URL/Cookie 路由灵活。
- 会话保持：把 session 外置到 Redis（推荐，应用无状态化最干净）；或 ip_hash/粘性 cookie（ LB 种 cookie 路由），后端挂掉时粘性会话会丢登录态。
- 健康检查：主动探活 + 失败剔除，前端可感知的表现是偶发 502——排查时先看 LB 的 upstream 状态。

```nginx
upstream backend {
  server a:8080 weight=3;
  server b:8080;
  server c:8080 backup;     # 备机，主全挂才接流量
  keepalive 32;             # 复用到后端的长连接
}
proxy_pass http://backend;
```
