## H5-370：H5 版本发布与回滚：灰度、指纹与兜底

**答**：
- 发布原子性：HTML 是发布原子（文件名 hash 的资源 immutable 缓存，HTML 本身 no-cache/短缓存）——先传资源后切 HTML，回滚 = 切回旧 HTML
- 灰度手段：入口层按用户/设备哈希返回不同 HTML 版本（网关 rewrite），或双 HTML 并存（index.html / index-canary.html）按 cookie 分流
- 兜底版本：保留最近 N 个版本资源（不可立即删除），回滚与「旧 HTML 引用旧资源」都依赖；CDN 缓存刷新预案（强制刷新 URL 列表）
- 版本可观测：HTML 里注入版本号，报错与性能数据全带版本维度——「v2.3.1 报错率上升」这种归因靠它
- 灰度判定：新版先 1% 观察报错率/秒开率 30 分钟 → 5% → 50% → 全量；任一指标劣化自动暂停并告警

```html
<!-- index.html: 注入版本与指纹资源 -->
<script>window.__VER__='2026.11.21-8f3c';</script>
<link rel="stylesheet" href="/css/app.8f3c2a.css" integrity="sha384-xxx">
<script src="/js/app.8f3c2a.js" defer integrity="sha384-yyy"></script>
```

```text
发布流程: 构建产物上传(immutable, 保留N版) → 灰度网关配置(1%) → 观察30min → 逐级放量
回滚: 网关切回上一版本 HTML (秒级) / CDN 强刷兜底
```
