## CSS-340：文本布局深水：换行、断行与溢出省略的引擎规则

**答**：
- 换行判定：软换行机会由分词/断行规则（UAX#14）决定——CJK 逐字可断、西文按空格/连字符（hyphens: auto 需 lang 支持）、长单词 break-word 系列控制强制断
- word-break/break-all/keep-all 语义：break-all 任意断（URL 场景）、keep-all CJK 不在字间断（词组保持）、overflow-wrap: anywhere 与 break-word 的区别在「是否影响 min-content 宽度」（anywhere 会）
- 溢出省略机制：text-overflow: ellipsis 需要 white-space: nowrap + overflow: hidden 三件套；多行用 line-clamp（内部是 -webkit-box 实现，标准 line-clamp 崭新）；ellipsis 触发在「布局完成后裁剪绘制」——行高变化会引起抖动
- 性能关联：长文本大量换行计算是 layout 成本大头，长列表摘要文本预截断（服务端截 or line-clamp）优于全量渲染后再裁剪；font-size 与容器频繁变化的文本区域是抖动源
- RTL/竖排：direction/rtl 与 writing-mode 改变换行方向与省略方向，text-overflow 对竖排的省略在块方向

```css
/* 单行省略三件套 */
.ellipsis { overflow: hidden; white-space: nowrap; text-overflow: ellipsis; }
/* 多行截断 */
.clamp2 {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 2;
  overflow: hidden;
}
/* 长链接断行: anywhere 才能正确收缩 min-content */
.url { overflow-wrap: anywhere; }
```
