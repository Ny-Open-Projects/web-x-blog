## H5-271：移动端软键盘收起后页面错位怎么办

**答**：
- 现象：键盘收起后 viewport 恢复，但页面还停在「被顶起时的滚动位置」，底部露出空白或元素错位（iOS 高发）
- 根因：iOS 在键盘收起时不主动触发滚动重排，window.scrollY 残留旧值
- 修复：blur/visualViewport resize 时手动 `scrollTo(0, scrollY)` 或复位到焦点元素前记录的位置
- 记录时机：focus 时记 scrollY，blur 后延时恢复（键盘动画有延迟，直接恢复可能被打断）
- 防御性：表单页避免整页滚动 + 底部固定按钮的组合，用 flex 布局把表单放进固定高度容器

```javascript
let posBeforeFocus = 0;
input.addEventListener('focus', () => (posBeforeFocus = window.scrollY));
input.addEventListener('blur', () => setTimeout(() => window.scrollTo(0, posBeforeFocus), 300));
// 兜底：visualViewport 高度恢复时校验
visualViewport?.addEventListener('resize', () => {
  if (visualViewport.height === window.innerHeight) window.scrollTo(0, posBeforeFocus);
});
```
