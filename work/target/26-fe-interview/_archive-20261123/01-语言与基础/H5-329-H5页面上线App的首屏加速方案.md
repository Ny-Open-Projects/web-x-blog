## H5-329：H5 页面上线 App 的首屏加速方案（离线包与预加载）

**答**：
- 离线包是 Hybrid 首屏加速核心：静态资源打包签名后内置 App 或后台下发，WebView 拦截请求命中本地包，跳过网络与 DNS——首屏从 2~3s 降到几百 ms
- 离线包管理：版本号 + MD5 校验 + 增量差分（bsdiff 类）下载；灰度发布（按百分比下发新包）与一键回滚
- 更新时序：App 启动后台静默检查更新，下次打开生效；强更场景（紧急 bug）用线上兜底开关切回网络加载
- 预加载配合：App 启动时预创建 WebView（进程预热）+ 预渲染高频页面，点击入口直接显示
- 一致性保障：离线包内的 API 请求仍走线上，资源版本与接口版本解耦；HTML 入口文件建议不进离线包或强校验，避免「离线页面调线上新接口」的兼容坑

```text
离线包流程:
  构建机: 打包静态资源 → 签名(manifest+md5) → 上传发布平台
  App: 后台静默下载增量包 → 校验签名 → 落盘
  WebView: shouldInterceptRequest 匹配离线清单 → 直接返回本地文件
  兜底: 未命中离线清单 → 走网络 (线上环境为准)
```
