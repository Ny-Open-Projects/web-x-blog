## WEB-388：V8 分代垃圾回收的"新生代/老生代"是怎么回事？
**答**：
- 分代假说：大部分对象朝生夕死。新生代用 Scavenge（复制算法，空间小速度快），存活两轮晋升老生代；老生代用 Mark-Compact（标记-整理）。
- 停顿控制：增量标记（分步执行不卡主线程）、并发标记/清理（后台线程做）、Major GC 尽量让主线程只承担小段。
- 前端实践：避免一次性大数组/大对象（直接进老生代）、及时置 null 断引用、大对象池复用。

```javascript
// 新生代: from/to 半区复制，活对象翻转到 to
// 老生代: 三色标记(白灰黑) + 增量/并发
const leak = [];
setInterval(() => leak.push(new Array(1e6).fill(0)), 100); // 大数组快进老生代
// 修复: 用完置 leak.length = 0，或用环形缓冲
console.log('GC 压力=分配速率，先降分配再谈回收');
```
