## RBL-670：笔试：手写构建反模式检测器（配置扫描 + 分级建议）

**需求**：实现 `detectAntipatterns(config, stats)`。config: `{ cacheKeyIncludes?, parallel?, splitChunks?, devtool? }`；stats: `{ chunkCount, avgChunkKB, smallChunkCount, moduleCount, resolveMs, transformMs }`。检测规则：1) 'over-split'：chunkCount > 100 或 smallChunkCount/chunkCount > 0.5 且 avgChunkKB < 20 → 建议按变更频率分组；2) 'cache-key-broad'：cacheKeyIncludes 含 'package.json' → 建议最小完备键；3) 'parallel-blind'：parallel === 'max' 或 === cpuCores → 建议内存预算感知；4) 'resolve-hotspot'：resolveMs > transformMs（解析是热点但优化未做）→ 建议四级缓存；5) 'tiny-chunks'：smallChunkCount > 30 → 建议合并阈值。返回 `{ findings: Array<{ id, level: 'warn'|'info', fix }> }`（无问题返回空 findings）。stats 缺字段跳过对应检测。

```javascript
function detectAntipatterns(config = {}, stats = {}) {
  const f = [];
  const { chunkCount, avgChunkKB, smallChunkCount, resolveMs, transformMs } = stats;

  if (chunkCount != null && smallChunkCount != null && avgChunkKB != null) {
    const ratio = chunkCount > 0 ? smallChunkCount / chunkCount : 0;
    if (chunkCount > 100 || (ratio > 0.5 && avgChunkKB < 20))
      f.push({ id: 'over-split', level: 'warn',
        fix: '按变更频率/使用路径分组，合并 <20KB chunk' });
    else if (smallChunkCount > 30)
      f.push({ id: 'tiny-chunks', level: 'info', fix: '提高合并阈值（minChunkKB）' });
  }
  if (config.cacheKeyIncludes?.includes?.('package.json'))
    f.push({ id: 'cache-key-broad', level: 'warn',
      fix: '缓存键最小完备：只含影响产物的字段' });
  const cores = typeof require === 'function' ? 8 : 8;   // 注入替代
  if (config.parallel === 'max' || config.parallel === cores)
    f.push({ id: 'parallel-blind', level: 'info', fix: '按内存预算感知并发并复测' });
  if (resolveMs != null && transformMs != null && resolveMs > transformMs)
    f.push({ id: 'resolve-hotspot', level: 'warn', fix: 'resolve 四级缓存 + 并行解析' });

  return { findings: f };
}

// 自测
let r = detectAntipatterns(
  { cacheKeyIncludes: ['package.json', 'src/**'], parallel: 'max' },
  { chunkCount: 150, avgChunkKB: 12, smallChunkCount: 90, resolveMs: 4000, transformMs: 1000 });
console.log(r.findings.map(x => x.id).sort().join(','));
// cache-key-broad, over-split, parallel-blind, resolve-hotspot（4 项）

r = detectAntipatterns(
  { cacheKeyIncludes: ['src/**'] },
  { chunkCount: 8, avgChunkKB: 60, smallChunkCount: 0, resolveMs: 100, transformMs: 900 });
console.log(r.findings.length === 0);                    // 全绿

r = detectAntipatterns({}, { smallChunkCount: 40, chunkCount: 8, avgChunkKB: 60 });
console.log(r.findings[0].id === 'tiny-chunks');         // 不超 100 但小 chunk 多

r = detectAntipatterns({ parallel: 'max' }, {});         // stats 缺字段只检测 parallel
console.log(r.findings.length === 1);

r = detectAntipatterns({}, {});
console.log(r.findings.length === 0);
```

**评分点**：
- 五条规则正确（over-split 双条件或、resolve 热点比较、parallel 盲配）
- stats 缺字段跳过对应检测（防御缺失数据不误报）
- level 分级合理（warn 影响正确性/体验、info 建议性）；无问题返回空 findings
- 能说清「检测器配合 RBL-587 基准使用，优化按占比排序而非按检测清单」属于加分
