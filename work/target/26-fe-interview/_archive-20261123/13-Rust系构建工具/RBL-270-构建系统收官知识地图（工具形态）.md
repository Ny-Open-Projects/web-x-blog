## RBL-270：构建系统收官知识地图（工具形态视角）

**答**:
- 引擎层：Rspack（webpack 兼容）/ Rolldown（Rollup 兼容）/ Turbopack（dev 优先）——选型按生态兼容与场景
- 封装层：Rsbuild 类 preset（团队规范配置化）、场景化 DSL（约定优于配置 + 逃生舱）
- 增量层：指纹显式化、脏标记传播、持久化缓存三级架构
- 编排层：任务图、affected、远程缓存安全、CI 职责边界
- 质量层：产物分析四维度、hash 稳定性、SRI/CSP、升级风险评估
- 面试收束：把工具问题回答成「分层 + 边界 + 验收」，每层给一个失败案例（缓存投毒/指纹漏 env/hash 不稳）——高分结构

```text
五层心智图：引擎 → 封装 → 增量 → 编排 → 质量
回答骨架：分层职责 → 边界协议 → 失败案例 → 验收清单
```
