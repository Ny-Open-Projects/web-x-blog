## RBL-318：构建产物版本指纹与部署对账

**答**:
- 指纹内容：产物 hash 树（每文件 hash + 汇总 hash）+ 工具版本 + 配置 hash + env 清单——一份 manifest 描述「这次构建的一切」
- 对账场景：部署后线上运行的产物 hash 与 CI 构建记录比对（CDN 是否部署了正确版本）、回滚验证（回滚后 hash 应等于历史版本 hash）
- 事故定位：「用户报错版本不对」→ 版本指纹比对秒级定位（部署错分支/CDN 缓存旧版/灰度错桶）
- 实现：manifest 进构建产物 + 运行时暴露版本端点（/version 返回指纹）+ CI 存档每次构建指纹——三方可对账

```text
对账三方：CI 构建记录 hash 树 ↔ CDN 实际部署（探测拉取） ↔ 运行时 /version
用途：部署验证 / 回滚验证 / 事故定位
```
