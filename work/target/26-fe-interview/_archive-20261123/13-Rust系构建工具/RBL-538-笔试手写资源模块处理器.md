## RBL-538：手写资源模块处理器（hash 命名 + 内联阈值 + 引用替换）
**需求**：537 落地——实现 `processAssets(assets, refs, { inlineKB = 4, hashLen = 8 })`：1) 每个 asset 生成内容 hash 文件名（`name.contenthash.ext`）；2) 小于内联阈值 → data URL（不产出文件）；3) 引用替换：`refs` 里对 asset 的引用替换为新名/data URL，**未替换的引用报告 404 风险**；4) 附用例：内联/命名/漏引用报告。

```javascript
import { createHash } from 'crypto'

function processAssets(assets, refs, { inlineKB = 4, hashLen = 8 } = {}) {
  const outputs = new Map()      // 新文件名 -> content
  const urlMap = new Map()       // 原引用名 -> 新 URL（hash 名或 data URL）
  const unreplaced = []          // 漏替换引用

  // 1) 资源处理
  for (const [name, content] of assets) {
    const size = content.length
    if (size <= inlineKB * 1024) {
      urlMap.set(name, `data:application/octet-stream;base64,${Buffer.from(content).toString('base64')}`)
    } else {
      const hash = createHash('sha256').update(content).digest('hex').slice(0, hashLen)
      const ext = name.split('.').pop()
      const newName = `${name.replace(/\.[^.]+$/, '')}.${hash}.${ext}`
      outputs.set(newName, content)
      urlMap.set(name, `/${newName}`)
    }
  }

  // 2) 引用替换 + 漏引用报告
  const replaced = []
  for (const [file, refsInFile] of refs) {
    let code = refsInFile.code
    for (const [ref, transform] of refsInFile.refs) {
      if (urlMap.has(ref)) {
        code = code.replaceAll(ref, urlMap.get(ref))
        replaced.push(`${file}:${ref}`)
      } else {
        unreplaced.push({ file, ref, risk: '404——引用无对应资源' })   // 漏引用报告
      }
    }
    refsInFile.code = code
  }

  return { outputs, urlMap, replaced, unreplaced, inlineCount: [...urlMap.values()].filter((u) => u.startsWith('data:')).length }
}

// 用例
const assets = new Map([
  ['logo.png', 'x'.repeat(100)],                       // 小：内联
  ['hero.jpg', 'y'.repeat(5000)],                      // 大：hash 命名
])
const refs = new Map([
  ['app.js', { code: 'const a = "logo.png"; const b = "hero.jpg";', refs: ['logo.png', 'hero.jpg'] }],
  ['style.css', { code: 'background: url(missing.png)', refs: ['missing.png'] }],   // 漏引用
])
const r = processAssets(assets, refs)
console.log(r.inlineCount)                              // 1：logo 内联
console.log([...r.outputs.keys()])                      // ['hero.<hash>.jpg']
console.log(r.replaced)                                 // ['app.js:logo.png', 'app.js:hero.jpg']
console.log(r.unreplaced)                               // [{ file: 'style.css', ref: 'missing.png', risk: '404...' }]
console.log(r.urlMap.get('hero.jpg').startsWith('/hero.'))   // hash 命名 URL
```
**评分点**：
- 内容 hash 命名（hashLen 可配）
- 内联阈值（≤inlineKB → data URL）
- 引用替换 + 漏引用 404 风险报告（正确性工程）
- urlMap 双形态（data URL / hash 文件 URL）
