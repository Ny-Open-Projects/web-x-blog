## RBL-689：笔试：手写微前端共享依赖版本协商器（区间匹配 + 回退加载）

**需求**：实现 `negotiateShared(childDeps, hostLoaded, loaders)`。childDeps: `Record<name, { requiredVersion, singleton }>`；hostLoaded: `Record<name, { version, module }>`；loaders: `Record<name, () => Promise<module>>`（fallback 加载器）。规则：1) 宿主已有且版本满足 requiredVersion → `{ shared: true }`（复用）；2) 不满足 → 有 fallback loader 则 `{ shared: false, module: await loaders[name]() }`；3) 无 fallback → `{ error: 'incompatible' }`；4) singleton 冲突升级：宿主已有但版本不满足且 singleton=true → 不允许 fallback 双实例，直接 error；5) 协商结果缓存（同 name+version 不重复协商）。semver 用简化 ^ 匹配（主版本相等即满足；精确相等恒满足）。

```javascript
function semverSatisfies(v, req) {
  if (req === '*') return true;
  if (req === v) return true;
  if (req.startsWith('^')) {
    const [m1] = req.slice(1).split('.'), [m2] = v.split('.');
    return m1 === m2;
  }
  return false;
}

function createNegotiator() {
  const cache = new Map();
  return async function negotiateShared(childDeps, hostLoaded, loaders) {
    const out = {};
    for (const [name, spec] of Object.entries(childDeps)) {
      const key = name + '@' + spec.requiredVersion;
      if (cache.has(key)) { out[name] = cache.get(key); continue; }
      const host = hostLoaded[name];
      let result;
      if (host && semverSatisfies(host.version, spec.requiredVersion)) {
        result = { shared: true, version: host.version, module: host.module };
      } else if (host && spec.singleton) {
        result = { error: 'incompatible', detail: `singleton 冲突: 宿主 ${name}@${host.version} 不满足 ${spec.requiredVersion}` };
      } else if (loaders[name]) {
        result = { shared: false, module: await loaders[name]() };
      } else {
        result = { error: 'incompatible', detail: `${name} 无 fallback 且宿主版本不匹配` };
      }
      cache.set(key, result);
      out[name] = result;
    }
    return out;
  };
}

// 自测
const negotiate = createNegotiator();
const childDeps = {
  react: { requiredVersion: '^18.0.0', singleton: true },
  lodash: { requiredVersion: '^4.0.0', singleton: false },
  moment: { requiredVersion: '^2.0.0', singleton: false },
};
const hostLoaded = {
  react: { version: '18.2.0', module: { R: 1 } },
  lodash: { version: '3.10.1', module: { L: 'old' } },   // 版本不满足
};
const loaders = { lodash: async () => ({ L: 'fallback' }) };

let r = await negotiate(childDeps, hostLoaded, loaders);
console.log(r.react.shared === true && r.react.version === '18.2.0');
console.log(r.lodash.shared === false && r.lodash.module.L === 'fallback');
console.log(r.moment.error === 'incompatible');          // 无 fallback

// singleton 冲突：宿主 react 版本不符时禁止 fallback
const r2 = await negotiate(
  { react: { requiredVersion: '^19.0.0', singleton: true } }, hostLoaded, loaders);
console.log(r2.react.error === 'incompatible');

// 缓存：同需求重复协商返回同引用
const r3 = await negotiate(childDeps, hostLoaded, loaders);
console.log(r3.lodash.module === r.lodash.module);
```

**评分点**：
- 三分支完整：复用/fallback/报错；singleton 冲突禁止双实例（多实例上下文断裂的防线）
- 协商缓存按 name+版本键（同需求不重复加载）
- 简化 semver 语义清晰（^ 主版本、\* 通配、精确恒真）
- 能说清「协商把版本漂移从崩溃降级为显式分支」属于加分
