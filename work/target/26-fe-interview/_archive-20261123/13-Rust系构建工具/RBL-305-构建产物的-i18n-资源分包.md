## RBL-305：构建产物的 i18n 资源分包

**答**:
- 分包维度：按语言（每语言独立 chunk，按 locale 动态加载）+ 按命名空间（公共词库/页面词库分离）——两层组合减体积
- 构建期处理：语言包 JSON 编译（合并/校验 key 完整性/生成类型）→ 按语言 chunk → 运行时动态 import（locale 变化才拉对应包）
- 校验门禁：CI 检查各语言 key 集合一致（漏译检测）、未使用 key 清理（体积治理）、占位符类型校验（{name} 拼写错误运行时才炸）
- 切换体验：语言包预加载下一语言（用户可能切换）+ 切换过渡态

```text
结构：locales/zh/common.json + locales/zh/home.json
构建：key 一致性校验 → 按语言 chunk → 动态 import
门禁：漏译阻断 + unused key 清理
```
