## RBL-640：笔试：手写可取消构建管线（AbortSignal 贯穿 + 缓存保留）

**需求**：实现 `buildPipeline(stages, signal)`。stages: `{ name, run(ctx) }[]` 顺序执行；ctx: `{ signal, emit(name), cache: Map }`。规则：1) 每个 stage 开始前与 run 返回后检查 signal.aborted，已取消则抛 AbortError；2) stage 内部支持异步取消：run 可长期挂起，abort 时要立刻 reject（用 Promise.race 与 abort promise 竞速）；3) 取消时返回 `{ status: 'cancelled', completed: string[], cache }`（不抛错给调用方），cache 保留全部已完成 stage 写入的内容；4) 正常完成返回 `{ status: 'success', results }`；5) 幂等：cancel 调用多次安全；6) 非 abort 的 stage 错误照常抛出并中止。

```javascript
function buildPipeline(stages, signal) {
  const completed = []; const results = []; const cache = new Map();
  const abortErr = () => Object.assign(new Error('aborted'), { name: 'AbortError' });

  function throwIfAborted() { if (signal?.aborted) throw abortErr(); }

  async function raceAbort(p) {
    if (!signal) return p;
    const abortP = new Promise((_, rej) =>
      signal.addEventListener('abort', () => rej(abortErr()), { once: true }));
    return Promise.race([p, abortP]);
  }

  return (async () => {
    try {
      for (const s of stages) {
        throwIfAborted();
        const out = await raceAbort(s.run({ signal, emit: (n) => completed.push(n), cache }));
        throwIfAborted();                                  // run 返回后再查一次
        results.push({ name: s.name, out });
        completed.push(s.name);
      }
      return { status: 'success', results, cache };
    } catch (e) {
      if (e.name === 'AbortError')
        return { status: 'cancelled', completed: [...completed], cache };  // 幂等收敛
      throw e;                                             // 真错误抛出
    }
  })();
}

// 自测
// 1) 正常完成
let r = await buildPipeline(
  [{ name: 'a', run: async () => 'A' }, { name: 'b', run: async ({ cache }) => { cache.set('b', 'B'); return 'B'; } }]);
console.log(r.status === 'success' && r.results.length === 2);

// 2) 中途取消：stage 挂起时 abort 立即收敛
const c = new AbortController();
const p = buildPipeline([
  { name: 's1', run: async () => 'ok' },
  { name: 's2', run: () => new Promise(() => {}), },      // 永挂
], c.signal);
setTimeout(() => c.abort(), 30);
r = await p;
console.log(r.status === 'cancelled' && r.completed.includes('s1') &&
            r.cache.get('b') === 'B');                   // 上轮缓存保留（cache 同引用）

// 3) 幂等：重复 abort 不报错
c.abort(); c.abort();
console.log(r.status === 'cancelled');

// 4) 真 error 抛出
let e; try {
  await buildPipeline([{ name: 'x', run: async () => { throw new Error('boom'); } }], c.signal);
} catch (err) { e = err; }
console.log(e.message === 'boom');
```

**评分点**：
- 双重检查（stage 前后）与 raceAbort 竞速实现异步取消即时性
- 取消不抛错而是收敛为 { status: 'cancelled' }，completed 与 cache 完整保留（幂等取消语义）
- 真 error 与 AbortError 区分处理；abort 多次安全（once 监听 + 状态检查）
- 能说明「保留增量缓存是高频编辑场景取消的价值前提」属于加分
