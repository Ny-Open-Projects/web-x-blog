## RBL-582：笔试：手写构建缓存键计算器（多源指纹 + 环境变量白名单）

**需求**：实现 `computeCacheKey({ files, config, tool, envAllow, getEnv, hashFile })`。键 = SHA 风格 hash（用提供的 `hashFile(path)->Promise<string>` 与内置 djb2）拼接：1) files 按字典序逐个 hashFile 后再汇总 hash（顺序无关且稳定）；2) config 深度序列化（键排序后 JSON.stringify）；3) tool 版本串；4) envAllow 白名单内的环境变量 `K=V`（键排序）。files 含不存在路径时用占位 hash（djb2 of `MISSING:path`）。要求总键 64 字符内 hex、相同输入产出相同键。

```javascript
const djb2 = (s) => { let h = 5381; for (let i = 0; i < s.length; i++) h = ((h << 5) + h + s.charCodeAt(i)) >>> 0; return h.toString(16).padStart(8, '0'); };
const deepStable = (v) => {
  if (Array.isArray(v)) return '[' + v.map(deepStable).join(',') + ']';
  if (v && typeof v === 'object') return '{' + Object.keys(v).sort()
    .map(k => JSON.stringify(k) + ':' + deepStable(v[k])).join(',') + '}';
  return JSON.stringify(v);
};

async function computeCacheKey({ files, config, tool, envAllow = [], getEnv, hashFile }) {
  const parts = [];
  // 1) 文件指纹：字典序保证与提交顺序无关
  const sorted = [...files].sort();
  for (const f of sorted) {
    let h;
    try { h = await hashFile(f); }
    catch { h = djb2('MISSING:' + f); }                 // 缺失文件也参与指纹
    parts.push(`${f}:${h}`);
  }
  parts.push('cfg:' + deepStable(config ?? null));
  parts.push('tool:' + String(tool));
  // 4) 环境变量白名单
  for (const k of [...envAllow].sort()) parts.push(`${k}=${getEnv(k) ?? ''}`);
  // 汇总 hash：折叠所有 parts
  let acc = 'seed';
  for (const p of parts) acc = djb2(acc + p);
  return acc;                                            // 8 hex，可再级联扩位
}

// 自测：顺序无关 + env 缺失为空串 + 缺失文件占位
const fsMap = { '/a.js': 'hA', '/b.js': 'hB' };
const hashFile = (f) => fsMap[f] ? Promise.resolve(djb2(fsMap[f])) : Promise.reject(new Error('nf'));
const k1 = await computeCacheKey({ files: ['/a.js', '/b.js'], config: { minify: true, out: { dir: 'd' } },
  tool: 'rolldown@1.0', envAllow: ['MODE'], getEnv: (k) => ({ MODE: 'prod' })[k], hashFile });
const k2 = await computeCacheKey({ files: ['/b.js', '/a.js'], config: { out: { dir: 'd' }, minify: true },
  tool: 'rolldown@1.0', envAllow: ['MODE'], getEnv: (k) => ({ MODE: 'prod' })[k], hashFile });
const k3 = await computeCacheKey({ files: ['/a.js', '/c.js'], config: {}, tool: 'rolldown@1.0',
  envAllow: ['MODE'], getEnv: () => undefined, hashFile });
// 断言：k1 === k2（顺序/键序无关）；k3 !== k1（文件集不同）；/c.js 缺失走占位而非抛错
console.log(k1 === k2, k3 !== k1);
```

**评分点**：
- 文件指纹字典序处理正确（顺序无关、结果稳定），缺失文件占位参与而非抛错
- 配置用键排序的深度序列化（对象键序不敏感），数组保序
- 环境变量只取白名单（防止 CI 全量 env 把键打散），缺失变量按空串参与
- 汇总 hash 折叠实现稳定；能说出「env 白名单遗漏是错缓存重灾区」属于加分
