## RBL-800：笔试：手写分层缓存访问器（回退 + 仲裁 + 刷盘）

**需求**：实现 `class TieredCache`，注入 l2/l3 适配器（`get(key) -> { value, version } | null`，`set(key, entry)`）。`get(key)`：L1 → L2（命中回填 L1）→ L3（命中回填 L1+L2）；**仲裁**：L3 条目 version < L2 条目 version 时忽略 L3 用 L2（本地更可信）；均无返回 null。`put(key, value, version)`：写 L1 + 待刷队列（不直接写 L2/L3）；`flush()`：把待刷队列写入 L2（去重：同 key 保留最后版本）；`discard(key)`：三层全删。返回 get 结果直接是 value。边界：L3 为 null（无远程）；put 两次同 key 后 flush 只留最新。

```javascript
class TieredCache {
  constructor({ l2, l3 = null }) { this.l2 = l2; this.l3 = l3;
    this.l1 = new Map(); this.pending = new Map(); }
  async get(key) {
    if (this.l1.has(key)) return this.l1.get(key);
    const d = await this.l2.get(key);
    if (d) { this.l1.set(key, d.value); return d.value; }
    if (this.l3) {
      const r = await this.l3.get(key);
      if (r && (!d || r.version >= (d?.version ?? 0))) {
        this.l1.set(key, r.value);
        await this.l2.set(key, r);
        return r.value;
      }
    }
    return null;
  }
  put(key, value, version) { this.l1.set(key, value); this.pending.set(key, { value, version }); }
  async flush() {
    for (const [k, e] of this.pending) await this.l2.set(k, e);
    this.pending.clear();
  }
  async discard(key) {
    this.l1.delete(key); this.pending.delete(key);
    await this.l2.set(key, null); await this.l3?.set(key, null);
  }
}

// 自测
const store2 = new Map(), store3 = new Map();
const l2 = { get: async (k) => store2.get(k) ?? null, set: async (k, v) => { v === null ? store2.delete(k) : store2.set(k, v); } };
const l3 = { get: async (k) => store3.get(k) ?? null, set: async (k, v) => { v === null ? store3.delete(k) : store3.set(k, v); } };

const c = new TieredCache({ l2, l3 });
// L3 回退 + 回填
store3.set('a', { value: 'A3', version: 2 });
console.log(await c.get('a') === 'A3');
console.log(c.l1.get('a') === 'A3' && store2.get('a').value === 'A3');   // 双回填

// 仲裁：L3 旧于 L2
store2.set('b', { value: 'B2', version: 5 });
store3.set('b', { value: 'B3-old', version: 3 });
console.log(await c.get('b') === 'B2');                  // 本地胜

// L1 命中
c.put('c', 'C1', 1);
console.log(await c.get('c') === 'C1');
console.log(store2.has('c') === false);                  // 未刷盘

// flush 去重保最新
c.put('c', 'C2', 2);
await c.flush();
console.log(store2.get('c').value === 'C2' && store2.get('c').version === 2);

// discard
store3.set('d', { value: 'D', version: 1 });
await c.get('d');
await c.discard('d');
console.log(await c.get('d') === null && !c.l1.has('d'));

// 无 L3
const c2 = new TieredCache({ l2 });
console.log(await c2.get('ghost') === null);
```

**评分点**：
- 三层回退与回填正确（L3 命中回填 L1+L2）；仲裁方向正确（本地 version 高则忽略远程）
- put 只进 L1 + pending（写穿内存、异步刷盘）；flush 同 key 保最新版本
- discard 三层清理；无 L3 适配器安全
- 能说清「写入时机跟随产物稳定性（中间态不落盘）」属于加分
