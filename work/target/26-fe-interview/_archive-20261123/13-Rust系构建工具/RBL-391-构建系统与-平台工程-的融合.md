## RBL-391：构建系统与平台工程的融合

**答**:
- 定位：构建系统是平台工程的一部分（IDP 内部开发者平台的构建域）——平台工程的评价标准是「开发者自助完成率」
- 融合点：脚手架（新项目即获得完整构建能力）、自助面板（构建配置可视化修改）、金丝雀流水线（平台级模板）——构建能力从「配置代码」升级为「平台服务」
- 边界：平台工程管横切能力（部署/观测/安全/构建），构建组专注构建深度（引擎/优化）——共建接口（构建产物 manifest 是平台消费的契约）
- 成熟度模型：手工配置 → 模板化 → 自助平台 → 智能化（自动优化建议）——当前阶段的诚实评估

```text
融合：构建 = IDP 的构建域；评价 = 开发者自助完成率
边界：平台管横切，构建组管深度；契约 = 产物 manifest
成熟度：手工 → 模板 → 自助 → 智能
```
