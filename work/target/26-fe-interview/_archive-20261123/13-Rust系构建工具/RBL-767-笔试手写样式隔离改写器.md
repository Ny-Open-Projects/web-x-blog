## RBL-767：笔试：手写样式隔离改写器（前缀 + keyframes + layer）

**需求**：实现 `isolate(css, { prefix, layer, exemptions })`。规则：1) 选择器改写：每个顶层规则的选择器（逗号分隔逐个）加 `.prefix` 后代选择器；豁免选择器（exemptions 数组，如 ':root'、'body'）不改；2) `@keyframes name` → `@keyframes prefix-name`，且 animation/animation-name 引用同步重命名（跳过 global 名）；3) 指定 layer 时整段包 `@layer layer { }`；4) CSS 变量声明（--x:）不改（跨应用共享面）。返回改写后 CSS。边界：空 CSS；无选择器的 at-rule（@media 保留，内部规则继续处理）。

```javascript
function isolate(css, { prefix, layer, exemptions = [] } = {}) {
  const exempt = (sel) => exemptions.some(e => sel.trim() === e || sel.trim().startsWith(e));
  const renameKeyframe = (n) => n.startsWith('global-') ? n : `${prefix}-${n}`;

  // keyframes 名收集 + 重命名
  const kfNames = new Set();
  let out = css.replace(/@keyframes\s+([\w-]+)/g, (_, n) => {
    kfNames.add(n);
    return `@keyframes ${renameKeyframe(n)}`;
  });
  // animation 引用重命名
  out = out.replace(/(animation(?:-name)?:\s*)([\w-]+)/g, (m, prop, n) =>
    kfNames.has(n) ? `${prop}${renameKeyframe(n)}` : m);

  // 选择器前缀（逐规则块处理）
  out = out.replace(/([^{}@]+)\{/g, (m, sels) => {
    if (/^\s*@/.test(sels)) return m;                    // at-rule 内层不管
    const rewritten = sels.split(',').map(s => {
      const t = s.trim();
      if (!t || exempt(t)) return t ? ` ${t}` : t;
      return ` .${prefix} ${t}`;
    });
    return rewritten.join(',') + ' {';
  });
  return layer ? `@layer ${layer} {\n${out}\n}` : out;
}

// 自测
const css = `
:root { --brand: red; }
body { margin: 0; }
.card { color: var(--brand); }
.card:hover { opacity: .8; }
.modal, .dialog { position: fixed; }
@keyframes spin { to { transform: rotate(360deg); } }
.spin-box { animation: spin 1s linear infinite; }
.global-fade { animation: global-fade 2s; }
`;
let out = isolate(css, { prefix: 'mf-a', exemptions: [':root', 'body'] });
console.log(out.includes('.mf-a .card {'));
console.log(out.includes('.mf-a .card:hover'));
console.log(out.includes(' .dialog'));
console.log(out.includes(':root { --brand: red; }'));    // 豁免
console.log(out.includes('@keyframes mf-a-spin'));       // 重命名
console.log(out.includes('animation: mf-a-spin 1s'));    // 引用同步
console.log(out.includes('animation: global-fade 2s'));  // global- 前缀豁免
console.log(out.includes('--brand: red'));               // 变量不改

out = isolate('.x { color: red; }', { prefix: 'mf-b', layer: 'mf-app-b' });
console.log(out.startsWith('@layer mf-app-b'));
console.log(isolate('', { prefix: 'x' }) === '');
```

**评分点**：
- 选择器前缀正确（逗号分隔逐个处理、hover 等伪类保留在尾部、豁免清单跳过）
- keyframes 双向重命名（定义 + 引用同步）、global- 名豁免；变量声明不改（共享面）
- layer 包装与声明序语义；空输入安全
- 能说清「CSS 变量是跨应用故意暴露面（token 桥），不参与隔离」属于加分
