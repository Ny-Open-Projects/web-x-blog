## RBL-666：笔试：手写配置翻译器（规则映射 + 置信度分级 + skipped 清单）

**需求**：实现 `translate(webpackConfig, rules)`。rules: `{ match(c)->bool, apply(c)->{confidence: 'high'|'medium'|'low', note} }[]`。行为：1) 按序执行 match 命中的 apply（apply 可修改 config 副本）；2) 输出 `{ config, report }`，report: `{ high, medium, low, skipped }`——每类收集 note；3) **skipped 检测**：翻译结束后扫描 config.plugins 中名为 `XxxWebpackPlugin`（非 Rspack 前缀）的插件，推入 skipped `{ plugin, hint }`；4) config 不被修改（深拷贝语义）；5) apply 抛错则该规则记入 skipped 并继续后续规则；6) 无规则命中时 low 收集 'no-rules-matched'。

```javascript
function translate(config, rules) {
  const out = structuredClone(config);
  const report = { high: [], medium: [], low: [], skipped: [] };
  let matched = false;

  for (const rule of rules) {
    try {
      if (!rule.match(out)) continue;
      const r = rule.apply(out);                         // apply 修改 out（已拷贝）
      (report[r.confidence] || report.low).push(r.note);
      matched = true;
    } catch (e) {
      report.skipped.push({ plugin: rule.name ?? 'anonymous', hint: e.message });
    }
  }
  if (!matched) report.low.push('no-rules-matched');

  for (const p of out.plugins || []) {
    const name = p?.constructor?.name ?? p?.__name ?? '';
    if (name.endsWith('WebpackPlugin') && !name.startsWith('Rspack') && !/^(Html|Define|MiniCss)Rspack/.test(name))
      report.skipped.push({ plugin: name, hint: '查 rspack 等价插件映射表' });
  }
  return { config: out, report };
}

// 自测
const cfg = {
  entry: './src/index.js',
  module: { rules: [{ test: /\.js$/, use: ['babel-loader'] }] },
  plugins: [
    { constructor: { name: 'DefinePlugin' } },
    { constructor: { name: 'FancyWebpackPlugin' } },
  ],
};
const rules = [
  { match: (c) => c.module?.rules?.some(r => r.use?.includes?.('babel-loader')),
    apply: (c) => {
      c.module.rules[0].use = 'builtin:swc-loader';
      return { confidence: 'medium', note: 'babel -> swc 需核对选项' };
    } },
  { match: () => true,
    apply: (c) => { c.devtool = 'source-map'; return { confidence: 'high', note: 'devtool 直译' }; } },
  { name: 'badRule', match: () => true, apply: () => { throw new Error('boom'); } },
];

const { config, report } = translate(cfg, rules);
console.log(config.module.rules[0].use === 'builtin:swc-loader');
console.log(config.devtool === 'source-map');
console.log(JSON.stringify(cfg.module.rules[0].use));    // ["babel-loader"] 原配置未改
console.log(report.medium.length === 1 && report.high.length === 1);
console.log(report.skipped.some(s => s.plugin === 'FancyWebpackPlugin'));
console.log(report.skipped.some(s => s.plugin === 'badRule'));

// 无命中
const r2 = translate({}, [{ match: () => false, apply: () => ({ confidence: 'high', note: 'x' }) }]);
console.log(r2.report.low.includes('no-rules-matched'));
```

**评分点**：
- 深拷贝语义正确（原 config 不被污染）；apply 抛错降级为 skipped 且不中断后续规则
- 置信度三级收集正确；无命中显式标记（no-rules-matched）
- skipped 插件扫描正确（WebpackPlugin 后缀 + 排除 Rspack 系）
- 能说清「宁可少转换+显式提示，不可静默丢弃」的迁移安全哲学属于加分
