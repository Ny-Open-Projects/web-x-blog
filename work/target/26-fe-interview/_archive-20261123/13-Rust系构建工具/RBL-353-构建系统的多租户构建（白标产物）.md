## RBL-353：构建系统的多租户构建（白标产物）

**答**:
- 白标需求：同一代码为多个租户产出不同品牌产物（logo/主题/功能开关/域名）——构建矩阵 = 租户 × 环境
- 实现策略：租户配置清单驱动多构建（每租户独立 DefinePlugin/主题变量/entry 注入）→ 产物目录按租户命名 → 部署按租户分发
- 成本控制：租户数量增长构建矩阵爆炸——分层优化：公共 chunk 共享（同依赖同 hash 跨租户复用 CDN 缓存）、差异层最小化（只有主题/配置差异的产物尺寸小）
- 治理：租户配置 schema 校验（新增租户 fail-fast 校验）、租户产物 diff 审计（租户间应只有声明差异——未声明的差异是 bug）

```text
矩阵：租户 × 环境 → 公共 chunk 共享 + 差异层最小化
治理：租户配置 schema + 租户间 diff 审计（未声明差异 = bug）
```
