## RBL-366：Rust 构建工具的增量数据结构设计

**答**:
- 数据面：模块图（petgraph 类邻接结构）+ 模块元数据（hash/依赖指纹）+ 产物映射——增量持久化要求「可序列化 + 版本兼容」
- 持久化策略：bincode/postcard 紧凑序列化（比 JSON 快且小）+ mmap 加载（零拷贝读）+ 版本头校验（结构变更即作废）
- 增量更新：图的部分更新（变更子图替换而非全图重写）——写放大控制（全图重写在大项目是 GB 级 IO）
- 兼容性：数据结构版本与工具版本绑定（升级作废旧图重建）——正确性优先于缓存存活

```text
结构：模块图 + 元数据 + 产物映射
序列化：bincode + mmap 零拷贝 + 版本头
更新：子图替换（控制写放大）；升级 → 作废重建
```
