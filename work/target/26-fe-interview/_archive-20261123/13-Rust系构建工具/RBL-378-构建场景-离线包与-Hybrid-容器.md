## RBL-378：构建产物与离线包（Hybrid 容器）的适配

**答**:
- 离线包形态：全量产物打包（zip/自研格式）+ 版本清单 → 客户端预下载 → 容器内 file:// 或本地 server 加载——构建侧产出「可离线包」
- 构建适配：绝对路径禁用（离线包内相对路径）、资源内联倾向（减少文件数——离线包 IO 慢）、包体积分片（大包拆分按需下载）、JSBridge 依赖注入适配（window.bridge 存在性判断）
- 版本与热更：离线包版本协议（manifest + 增量 diff 下载）——构建产物 diff 即热更包（构建工具生成）
- 校验：离线包完整性（hash 清单）+ 容器内冒烟（真机验证 file:// 场景的路由/资源加载）

```text
适配：相对路径 / 资源内联 / 分片包体 / JSBridge 注入判断
热更：manifest + 构建期 diff 生成增量包
校验：包完整性 hash + 真机离线冒烟
```
