## RBL-885：笔试：手写桥协议调用校验器（方法集 + 版本）

**需求**：实现 `auditBridgeCalls(code, schema, { minAppVersion })`。schema: `{ version, methods: Record<name, { params: Record<string,string>, since: string }> }`. 规则：1) 提取 `bridge['app.x'](...)` 与 `bridge.call('app.x', ...)` 与 `bridge.appPay(...)`（驼峰转换 appPay → app.pay）调用：方法不在 schema → blocker 'undeclared-method'；2) 参数校验：调用传入对象字面量的键 ⊄ schema.params → warn 'param-mismatch'（列出多缺）；3) since 版本 > minAppVersion → info 'version-gated'（确认有 H5 降级）；4) 返回 `{ blockers, warnings, infos }`。边界：schema 空（全部 blocker）；无调用。

```javascript
const cmpVer = (a, b) => { const pa = a.split('.').map(Number), pb = b.split('.').map(Number);
  for (let i = 0; i < 3; i++) if ((pa[i] || 0) !== (pb[i] || 0)) return (pa[i] || 0) - (pb[i] || 0);
  return 0; };
const toDot = (camel) => camel.replace(/([A-Z])/g, '.$1').toLowerCase().replace(/^\./, '');

function auditBridgeCalls(code, schema = { methods: {} }, { minAppVersion = '0.0.0' } = {}) {
  const blockers = [], warnings = [], infos = [];
  const seen = new Set();
  const patterns = [
    /bridge(?:\??)\[(['"])(app\.[\w.]+)\1\]\s*\(/g,
    /bridge\.call\(\s*(['"])(app\.[\w.]+)\1/g,
    /bridge\.(\w+)\(/g,
  ];
  for (const re of patterns) {
    for (const m of code.matchAll(re)) {
      const method = m[2] ?? toDot(m[1] ?? m[3]);
      if (seen.has(method)) continue;
      seen.add(method);
      const spec = schema.methods[method];
      if (!spec) { blockers.push({ type: 'undeclared-method', method }); continue; }
      // 参数粗校验：调用点后 120 字符内的对象字面量键
      const tail = code.slice(m.index, m.index + 120);
      const keys = [...tail.matchAll(/(\w+)\s*:/g)].map(x => x[1]);
      const bad = keys.filter(k => !(k in spec.params));
      if (bad.length) warnings.push({ type: 'param-mismatch', method, props: bad });
      if (cmpVer(spec.since, minAppVersion) > 0)
        infos.push({ type: 'version-gated', method, since: spec.since });
    }
  }
  return { blockers, warnings, infos };
}

// 自测
const schema = { version: 3, methods: {
  'app.pay': { params: { orderId: 'string', amount: 'number' }, since: '8.0' },
  'app.share': { params: { title: 'string', url: 'string' }, since: '7.2' },
} };
const code = [
  "bridge['app.pay']({ orderId: 'o1', amount: 9.9 });",
  "bridge.call('app.share', { title: 't', url: 'u', extra: 1 });",   // 多参数 warn
  "bridge.appPay({ orderId: 'o2' });",                                // 驼峰识别同方法（去重）
  "bridge.appToast({ msg: 'x' });",                                   // 未声明
].join('\n');
let r = auditBridgeCalls(code, schema, { minAppVersion: '7.5' });
console.log(r.blockers[0].method === 'app.toast');
console.log(r.warnings[0].method === 'app.share' && r.warnings[0].props.includes('extra'));
console.log(r.infos[0].method === 'app.pay' && r.infos[0].since === '8.0');  // 8.0 > 7.5
console.log(r.infos.find(i => i.method === 'app.share') === undefined);     // 7.2 ≤ 7.5
console.log(r.blockers.length === 1);                    // appPay 去重后不重复报

console.log(auditBridgeCalls('no bridge here', schema).blockers.length === 0);
let r2 = auditBridgeCalls("bridge['app.x']({})", { methods: {} });
console.log(r2.blockers[0].type === 'undeclared-method');
```

**评分点**：
- 三形态调用提取（方括号/call/驼峰）与去重；驼峰转点号正确
- 参数键粗校验（多参数 warn——schema 严格性）；版本门禁 info（since > minAppVersion 提示降级）
- 边界：无调用/空 schema
- 能说清「跨进程字符串契约必须类型化，App 改名在前端构建期即红」属于加分
