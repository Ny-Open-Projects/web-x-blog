## RBL-759：笔试：手写多入口 HTML 标签清单生成器（排序 + SEO 诊断 + 转义）

**需求**：实现 `emitTags(entries, manifest, meta)`。manifest: `closureOf(entry) -> Array<{ url, type: 'js'|'css', kind?: 'polyfill', order }>`。规则：1) scripts 顺序：polyfill（nomodule）在前，其余 js 按 order 升序（type module）；2) styles 按 order 升序；3) meta 诊断：required = ['title','description','canonical','og:image']，缺失返回 diagnostics 数组（`RBL5001: 缺失 x`）；4) title/description 插入前转义（esc：`<>&"'` → HTML 实体），原始 HTML 需 `__html` 标记跳过转义；5) 返回 `{ perEntry: Record<entry, { scripts, styles }>, metaTags: string[], diagnostics }`。边界：入口闭包为空；meta 全缺。

```javascript
const esc = (s) => String(s).replace(/[<>&"']/g, c =>
  ({ '<': '&lt;', '>': '&gt;', '&': '&amp;', '"': '&quot;', "'": '&#39;' }[c]));

function emitTags(entries, manifest, meta = {}) {
  const perEntry = {};
  for (const e of entries) {
    const closure = manifest.closureOf(e) || [];
    const order = (a, b) => a.order - b.order;
    perEntry[e] = {
      scripts: [
        ...closure.filter(f => f.kind === 'polyfill')
          .sort(order).map(f => ({ tag: 'script', nomodule: true, src: f.url })),
        ...closure.filter(f => f.type === 'js' && f.kind !== 'polyfill')
          .sort(order).map(f => ({ tag: 'script', type: 'module', src: f.url })),
      ],
      styles: closure.filter(f => f.type === 'css').sort(order)
        .map(f => ({ tag: 'link', rel: 'stylesheet', href: f.url })),
    };
  }
  const required = ['title', 'description', 'canonical', 'og:image'];
  const diagnostics = required.filter(k => !meta[k]).map(k => `RBL5001: 缺失 ${k}（影响搜索/分享）`);
  const metaTags = [];
  if (meta.title != null) metaTags.push(`<title>${meta.title.__html ? meta.title.__html : esc(meta.title)}</title>`);
  if (meta.description != null)
    metaTags.push(`<meta name="description" content="${meta.description.__html ?? esc(meta.description)}">`);
  if (meta.canonical != null)
    metaTags.push(`<link rel="canonical" href="${esc(meta.canonical)}">`);
  if (meta['og:image'] != null)
    metaTags.push(`<meta property="og:image" content="${esc(meta['og:image'])}">`);
  return { perEntry, metaTags, diagnostics };
}

// 自测
const manifest = {
  closureOf: (e) => e === 'home'
    ? [{ url: '/p.js', type: 'js', kind: 'polyfill', order: 0 },
       { url: '/main.x.js', type: 'js', order: 2 },
       { url: '/vendor.y.js', type: 'js', order: 1 },
       { url: '/base.css', type: 'css', order: 1 }]
    : [{ url: '/admin.z.js', type: 'js', order: 0 }],
};
let r = emitTags(['home', 'admin'], manifest, { title: '商城 <首页>', canonical: '/home' });
console.log(r.perEntry.home.scripts.map(s => s.src).join(','));
// /p.js（nomodule polyfill）, /vendor.y.js, /main.x.js（order 排序，polyfill 首位）
console.log(r.perEntry.home.scripts[0].nomodule === true);
console.log(r.perEntry.home.styles[0].href === '/base.css');
console.log(r.perEntry.admin.scripts.length === 1);

console.log(r.metaTags[0] === '<title>商城 &lt;首页&gt;</title>');   // 转义
console.log(r.diagnostics.join('|'));                    // 缺 description 与 og:image

r = emitTags(['admin'], manifest, {
  title: { __html: 'A<b>B</b>' },                        // 原始 HTML 跳过转义
});
console.log(r.metaTags[0] === '<title>A<b>B</b></title>');
console.log(emitTags(['admin'], manifest, {}).diagnostics.length === 4);
```

**评分点**：
- 排序语义正确：polyfill（nomodule）先于 module 脚本、同组按 order；styles 独立排序
- SEO 四项诊断齐全；转义默认开启且 `__html` 显式跳过（防模板注入）
- 多入口独立闭包互不污染；空闭包/全缺 meta 边界
- 能说清「module 脚本 defer 语义下真正需要排序的是 nomodule/内联资源」属于加分
