## RBL-765：笔试：手写导出任务管理器（Worker 池 + 取消 + 防重复提交）

**需求**：实现 `createExportManager({ poolSize, runTask })`。runTask 注入（模拟 worker 执行 `({ payload, signal }) => Promise`）。规则：1) 任务按提交序入队，同时最多 poolSize 个执行；2) **同 key（如同一报表 ID）重复提交**：若有在途同 key 任务 → 返回该任务 promise（合并复用），不重复执行；3) `cancel(key)`：取消在途任务（signal abort，runTask 收到 abort 后 reject { name: 'AbortError' }），并从队列移除未开始的同 key 任务；4) 取消的任务不算失败（结果 { status: 'cancelled' }）；5) 返回 `{ submit(key, payload) -> Promise<{ status, data? }>, cancel(key), pending() }`。边界：完成后 cancel 无效；池空即时执行。

```javascript
function createExportManager({ poolSize = 2, runTask }) {
  const inflight = new Map();                            // key -> { promise, controller }
  const queued = [];                                     // { key, payload, resolve }
  let running = 0;

  function pump() {
    while (running < poolSize && queued.length) {
      const { key, payload, resolve } = queued.shift();
      if (!inflight.has(key)) { resolve({ status: 'cancelled' }); continue; }  // 已被取消
      running++;
      const controller = inflight.get(key);
      runTask({ payload, signal: controller.controller.signal })
        .then(data => resolve({ status: 'ok', data }))
        .catch(e => resolve(e?.name === 'AbortError'
          ? { status: 'cancelled' } : { status: 'error', error: e }))
        .finally(() => {
          running--;
          if (inflight.get(key)?.controller === controller) inflight.delete(key);
          pump();
        });
    }
  }

  return {
    submit(key, payload) {
      if (inflight.has(key)) return inflight.get(key).promise;   // 重复提交合并
      const controller = { controller: new AbortController() };
      const promise = new Promise(res => queued.push({ key, payload, resolve: res }));
      inflight.set(key, controller);
      pump();
      return promise;
    },
    cancel(key) {
      const c = inflight.get(key);
      if (!c) return false;
      c.controller.abort();                                // 在途/排队任务都被标取消
      queued.forEach(q => { if (q.key === key) q.resolve({ status: 'cancelled' }); });
      return true;
    },
    pending: () => inflight.size,
  };
}

// 自测
let active = 0, max = 0;
const runTask = async ({ payload, signal }) => {
  active++; max = Math.max(max, active);
  await new Promise((res, rej) => {
    const t = setTimeout(res, 30);
    signal?.addEventListener('abort', () => { clearTimeout(t); rej(Object.assign(new Error(), { name: 'AbortError' })); }, { once: true });
  });
  active--;
  return payload.id;
};
const em = createExportManager({ poolSize: 2, runTask });

// 防重复：同 key 合并
const p1 = em.submit('rptA', { id: 'A' });
const p2 = em.submit('rptA', { id: 'A2' });
console.log(p1 === p2);
// 并发上限
em.submit('rptB', { id: 'B' }); em.submit('rptC', { id: 'C' }); em.submit('rptD', { id: 'D' });
console.log(em.pending() === 4);
await p1; await em.submit('rptB', { id: 'B' });
console.log(max <= 2);

// 取消
const pc = em.submit('rptE', { id: 'E' });
console.log(em.cancel('rptE') === true);
const rc = await pc;
console.log(rc.status === 'cancelled');
console.log(em.cancel('rptE') === false);                // 已结束
console.log((await em.submit('rptF', { id: 'F' })).status === 'ok');
```

**评分点**：
- 防重复提交合并（同 key 返回同一 promise）；取消传播（abort 在途 + 清理排队）
- 池并发上限正确且任务完成后回收槽位 pump 续跑；max 断言不超池
- 取消任务归为 cancelled（不算 error）；完成后 cancel 无效
- 能说清「重复点击导出是双任务竞争的真实事故源」属于加分
