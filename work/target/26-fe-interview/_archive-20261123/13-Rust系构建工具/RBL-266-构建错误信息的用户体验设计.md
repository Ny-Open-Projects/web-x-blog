## RBL-266：构建错误信息的用户体验设计

**答**:
- 好错误三要素：定位（文件:行:列 + 代码帧高亮）、原因（一句话说清是什么错）、修复（可行动建议，最好带示例）——Rust 工具链（swc/oxc）的错误信息质量是竞争力
- 分类分级：语法错（parse）→ 类型错 → 配置错（invalid option + 最接近的正确项建议）→ 环境错（依赖缺失），不同类别输出模板不同
- 批量错误收敛：同类错误折叠（首条+计数），顶部给「最常见的 3 个修复方向」——用户先看到统计再下钻
- 机器可读：--json 输出结构化错误（供 IDE 插件/CI bot 二次呈现）

```text
坏：ERROR: build failed
好：ERROR in src/App.tsx:12:5
    Cannot find name 'useState'. Did you forget to import it?
      10 | import { useMemo } from 'react'
    > 12 | const [v, setV] = useState(0)
    Suggestion: add `import { useState } from 'react'`
```
