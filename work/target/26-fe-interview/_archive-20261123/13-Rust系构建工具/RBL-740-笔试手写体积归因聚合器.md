## RBL-740：笔试：手写体积归因聚合器（包聚合 + 复制标注 + 趋势 diff）

**需求**：实现 `aggregate(chunks, modules, baseline)`。chunks: `{ name, modules: Array<{ id, bytes, duplicated? }> }[]`；modules: `Record<id, { pkg }>`. 1) 按包聚合字节（duplicated 模块字节仍计入但单独标注 dupBytes）；2) 与 baseline（`Record<pkg, bytes>`）对比生成 `delta: Record<pkg, deltaBytes>`；3) 输出 `{ rows: Array<{ pkg, bytes, dupBytes, delta }>, total, advice }`——rows 按 bytes 降序，advice 只对 top1 生成（规则：dupBytes/bytes > 0.5 → '复制过多，检查 chunk 策略'；bytes > 200KB → '大包，检查按需导入'；否则 null）。边界：baseline 缺包 delta 记为 +bytes（新增）；chunks 为空。

```javascript
function aggregate(chunks, modules, baseline = {}) {
  const byPkg = new Map(), dupByPkg = new Map();
  let total = 0;
  for (const chunk of chunks)
    for (const m of chunk.modules) {
      const pkg = modules[m.id]?.pkg ?? '<unknown>';
      byPkg.set(pkg, (byPkg.get(pkg) || 0) + m.bytes);
      if (m.duplicated) dupByPkg.set(pkg, (dupByPkg.get(pkg) || 0) + m.bytes);
      total += m.bytes;
    }
  const rows = [...byPkg.entries()].map(([pkg, bytes]) => ({
    pkg, bytes,
    dupBytes: dupByPkg.get(pkg) || 0,
    delta: bytes - (baseline[pkg] ?? 0),
  })).sort((a, b) => b.bytes - a.bytes);

  const advice = (() => {
    const top = rows[0];
    if (!top) return null;
    if (top.dupBytes / top.bytes > 0.5) return `${top.pkg} 复制过多——检查 chunk 策略（RBL-597）`;
    if (top.bytes > 200 * 1024) return `${top.pkg} 大包——检查按需导入`;
    return null;
  })();
  return { rows, total, advice };
}

// 自测
const chunks = [
  { name: 'main', modules: [
    { id: 'lodash/lodash.js', bytes: 70000 },
    { id: 'app/home.js', bytes: 12000 } ] },
  { name: 'shop', modules: [
    { id: 'lodash/lodash.js', bytes: 70000, duplicated: true },
    { id: 'app/shop.js', bytes: 15000 } ] },
];
const modules = { 'lodash/lodash.js': { pkg: 'lodash' },
  'app/home.js': { pkg: '<app>' }, 'app/shop.js': { pkg: '<app>' } };
const baseline = { lodash: 70000, '<app>': 20000 };

const r = aggregate(chunks, modules, baseline);
console.log(r.total === 167000);
console.log(r.rows[0].pkg === 'lodash');                 // 140000 最大
console.log(r.rows[0].dupBytes === 70000);
console.log(r.rows[0].delta === 70000);                  // 复制导致翻倍
console.log(r.rows[1].delta === 7000);                   // app 27000-20000
console.log(r.advice === 'lodash 复制过多——检查 chunk 策略（RBL-597）');

const r2 = aggregate(chunks, modules, {});
console.log(r2.rows[0].delta === 140000);                // 基线缺失视为新增

console.log(aggregate([], modules).total === 0 && aggregate([], modules).advice === null);
```

**评分点**：
- 包聚合正确（duplicated 计入主字节并单独标注 dupBytes）
- 趋势 diff 正确（baseline 缺失包 delta = 全量，视为新增）；total 全量累计
- advice 只对 top1 且双规则（复制比/绝对阈值）；空输入安全
- 能说清「dupBytes 与主字节的关系：物理体积已付，虚胖来源标注」属于加分
