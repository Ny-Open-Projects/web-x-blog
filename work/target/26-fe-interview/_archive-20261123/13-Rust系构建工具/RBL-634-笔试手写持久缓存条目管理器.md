## RBL-634：笔试：手写持久缓存条目管理器（懒校验 + LRU 清理）

**需求**：实现 `class DiskCache`，注入 `store: Map` 与 `hash(s)`。`set(key, value, deps: string[])`：写入 `{ key, value, depHashes: deps.map(d=>hash(d)), version, at }`，version 构造传入。`get(key, currentDeps)`：version 不符返回 null；逐个比较 depHashes 与 currentDeps 的 hash，任一不符返回 null；命中返回 value 且更新访问序（LRU）。`evict(maxEntries)`：按 LRU 淘汰超限条目，返回被淘汰 key 数组。`clear()` 全清。get 不存在的 key 返回 null。set 相同 key 覆盖并重置访问序。

```javascript
class DiskCache {
  constructor(store, hash, version) { this.s = store; this.h = hash; this.v = version; }
  set(key, value, deps = []) {
    this.s.set(key, {
      key, value,
      depHashes: deps.map(d => this.h(d)),
      version: this.v, at: Date.now(),
    });
  }
  get(key, currentDeps = []) {
    const e = this.s.get(key);
    if (!e) return null;
    if (e.version !== this.v) { this.s.delete(key); return null; }   // 版本不符即弃
    const ok = e.depHashes.length === currentDeps.length &&
      e.depHashes.every((h, i) => h === this.h(currentDeps[i]));
    if (!ok) { this.s.delete(key); return null; }                     // 指纹不符失效
    return e.value;
  }
  evict(maxEntries) {
    if (this.s.size <= maxEntries) return [];
    // Map 迭代序即插入序：重插命中条目实现 LRU touch
    const entries = [...this.s.entries()];
    const evicted = [];
    for (const [k] of entries.slice(0, entries.length - maxEntries)) {
      this.s.delete(k); evicted.push(k);
    }
    return evicted;
  }
  clear() { this.s.clear(); }
}
// LRU touch：get 命中后重置插入序
const origGet = DiskCache.prototype.get;
DiskCache.prototype.get = function (k, d) {
  const v = origGet.call(this, k, d);
  if (v !== null && this.s.has(k)) { const e = this.s.get(k); this.s.delete(k); this.s.set(k, e); }
  return v;
};

// 自测
const h = (s) => 'h' + s;
const c = new DiskCache(new Map(), h, 'v1');
c.set('a', { out: 'A' }, ['dep1']);                     // depHashes: ['hdep1']
console.log(c.get('a', ['dep1']).out === 'A');
console.log(c.get('a', ['dep2']) === null);             // 指纹变 -> 失效并删除
c.set('b', 'B', []);
c.set('a', 'A2', ['dep1']);                             // 覆盖
console.log(c.get('a', ['dep1']) === 'A2');

// LRU：a 是最新访问，evict(1) 应淘汰 b
c.set('c', 'C', []);
console.log(c.evict(2).includes('b'));                  // b 最久未用
console.log(c.get('a', ['dep1']) === 'A2' && c.get('c', []) === 'C');

// 版本不符
const c2 = new DiskCache(c.s, h, 'v2');
console.log(c2.get('a', ['dep1']) === null);            // v1 条目被弃
```

**评分点**：
- 三级校验链正确：存在性 → version → dep 指纹（逐位比较，长度不符也失效）
- 命中即 LRU touch（重置插入序）；evict 淘汰最久未用条目
- 失效即删除（不返回旧值），覆盖 set 重置状态
- 能说清「mtime 快路径 vs 内容 hash 慢路径」与「懒校验只查要用的条目」属于加分
