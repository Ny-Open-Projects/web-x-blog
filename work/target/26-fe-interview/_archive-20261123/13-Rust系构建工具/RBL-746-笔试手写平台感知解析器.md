## RBL-746：笔试：手写平台感知文件解析器（后缀优先级 + 缓存隔离）

**需求**：实现 `resolvePlatform(importPath, importerDir, platform, fsExists)`。fsExists: `(path) => boolean` 模拟文件系统。规则：1) 相对导入：按扩展优先级试探（平台后缀优先：`.web.ts > .ts > .js`），含目录 index 变体（`./utils` → `./utils/index`）；2) 同名平台文件优先于通用文件（`btn.web.ts` 优先于 `btn.ts`）；3) 扩展名已写全的导入（`./a.ts`）先试平台变体 `./a.web.ts` 再回退声明扩展；4) 缓存键含平台（web 与 native 各自缓存，互不污染）；5) 全部候选不存在返回 null。返回解析到的完整路径。

```javascript
function resolvePlatform(importPath, importerDir, platform, fsExists, cache = new Map()) {
  const exts = platform === 'web'
    ? ['.web.ts', '.web.tsx', '.web.js', '.ts', '.tsx', '.js']
    : ['.native.ts', '.native.tsx', '.native.js', '.ts', '.tsx', '.js'];
  const base = importPath.startsWith('.')
    ? join(importerDir, importPath) : importPath;
  const key = `${platform}:${base}`;
  if (cache.has(key)) return cache.get(key);

  let result = null;
  const stripKnown = (p) => p.replace(/\.(ts|tsx|js)$/, '');
  const candidates = [];
  if (/\.(ts|tsx|js)$/.test(base)) {
    const stripped = stripKnown(base);
    for (const e of exts) candidates.push(stripped + e);   // 平台变体优先
  } else {
    for (const e of exts) candidates.push(base + e);
    for (const e of exts) candidates.push(`${base}/index${e}`);   // 目录 index
  }
  result = candidates.find(fsExists) ?? null;
  cache.set(key, result);
  return result;
}
const join = (dir, p) => `${dir}/${p}`.replace(/\/\.\//g, '/').replace(/\/$/, '');

// 自测
const files = new Set([
  '/src/btn.ts', '/src/btn.web.ts',                       // 平台变体
  '/src/utils/index.ts',                                  // 目录 index
  '/src/plain.js',                                        // 声明扩展
  '/src/plain.native.js',
]);
const exists = (p) => files.has(p);
const cache = new Map();

console.log(resolvePlatform('./btn', '/src', 'web', exists, cache) === '/src/btn.web.ts');
console.log(resolvePlatform('./btn', '/src', 'native', exists, cache) === '/src/btn.ts');  // 无 native 变体回退
console.log(resolvePlatform('./utils', '/src', 'web', exists, cache) === '/src/utils/index.ts');
console.log(resolvePlatform('./plain.js', '/src', 'web', exists, cache) === '/src/plain.js');   // 声明扩展
console.log(resolvePlatform('./plain.js', '/src', 'native', exists, cache) === '/src/plain.native.js');
console.log(resolvePlatform('./ghost', '/src', 'web', exists, cache) === null);

// 缓存平台隔离：修改文件系统后 web 缓存不污染 native
console.log(cache.size === 6);
```

**评分点**：
- 平台后缀优先级正确（.web/.native 优先于通用扩展）；声明扩展的导入先试平台变体
- 目录 index 变体处理；候选全 miss 返回 null
- 缓存键含平台（隔离验证：同 import 不同平台各自解析）
- 能说清「解析期分支让产物只含本平台代码（体积与泄漏双赢）」属于加分
