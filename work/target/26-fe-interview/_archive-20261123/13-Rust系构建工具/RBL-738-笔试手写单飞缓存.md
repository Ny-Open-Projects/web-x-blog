## RBL-738：笔试：手写单飞缓存（single-flight + 负缓存 + watch 失效）

**需求**：实现 `class SingleFlightCache`。`get(key, loader)`：loader 为 `() => Promise<{ value?, missing?: boolean }>`。规则：1) 正结果缓存（直接返回）；2) 负结果（missing）缓存带 TTL（get 时过期判定，过期重算）；3) 并发同 key：第一个 loader 执行，其余等待同一 Promise（单飞），完成后共享结果（错误也共享）；4) `invalidate(prefix)`：删除前缀匹配的正负缓存（watch 联动）；5) loader 抛错不缓存（下次重试）。返回 `{ value }` 或 `{ missing: true }`。边界：同 key 并发 100 次 loader 只跑一次；TTL 0 表示负缓存立即过期。

```javascript
class SingleFlightCache {
  constructor({ negTtlMs = 5000 } = {}) { this.pos = new Map(); this.neg = new Map(); this.negTtl = negTtlMs; this.flight = new Map(); }
  async get(key, loader) {
    if (this.pos.has(key)) return { value: this.pos.get(key) };
    const negAt = this.neg.get(key);
    if (negAt !== undefined) {
      if (Date.now() - negAt < this.negTtl) return { missing: true };
      this.neg.delete(key);                              // TTL 过期重算
    }
    if (this.flight.has(key)) return this.flight.get(key);   // 单飞等待
    const p = (async () => {
      try {
        const r = await loader();
        if (r.missing) this.neg.set(key, Date.now());
        else this.pos.set(key, r.value);
        return r;
      } catch (e) {
        throw e;                                         // 错误不缓存
      } finally {
        this.flight.delete(key);
      }
    })();
    this.flight.set(key, p);
    return p;
  }
  invalidate(prefix) {
    for (const m of [this.pos, this.neg])
      for (const k of [...m.keys()])
        if (k.startsWith(prefix)) m.delete(k);
  }
}

// 自测
const cache = new SingleFlightCache({ negTtlMs: 50 });
let calls = 0;
const loader = async () => { calls++; await sleep(20); return { value: 'V' }; };

// 并发单飞
const rs = await Promise.all(Array.from({ length: 100 }, () => cache.get('k1', loader)));
console.log(calls === 1);                                // 只跑一次
console.log(rs.every(r => r.value === 'V'));

// 命中缓存不再调 loader
await cache.get('k1', loader);
console.log(calls === 1);

// 负缓存 + TTL
const negLoader = async () => ({ missing: true });
await cache.get('k2', negLoader);
let r = await cache.get('k2', negLoader);
console.log(r.missing === true && calls === 1);
await sleep(60);                                         // TTL 过期
await cache.get('k2', negLoader);
console.log(calls === 2);

// 失败不缓存
let fails = 0;
const boom = async () => { fails++; throw new Error('io'); };
let e; try { await cache.get('k3', boom); } catch (x) { e = x; }
try { await cache.get('k3', boom); } catch {}
console.log(fails === 2);                                // 每次重试

// invalidate 前缀
cache.invalidate('k');
console.log(cache.pos.size === 0 && cache.neg.size === 0);
```

**评分点**：
- 单飞语义正确（并发共享同一 Promise，错误也共享、不缓存错误）
- 负缓存 TTL 判定与过期重算；TTL=0 立即过期边界
- invalidate 前缀匹配双缓存清理；正结果永久缓存（构建会话语义）
- 能说清「负缓存是 resolve 慢的最大优化点（防重复 stat 不存在路径）」属于加分
