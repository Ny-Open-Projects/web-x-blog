## AGT-808：租户把内部文档接入平台知识库，接入前要过哪些安全审查

**答**：
- 四关：内容审查（敏感分级扫描：人事/财务/客户数据打密级标签，密级决定检索权限）、合规审查（版权/许可/第三方数据合法性）、格式审查（解析质量门禁，垃圾文档不进库）、范围审查（哪些部门可见，权限模型映射）。
- 密级贯穿检索：检索时按用户密级过滤（用户密级低于文档密级则不召回，且不泄露"存在但无权"的信息——无权限命中不给数量提示，防侧信道）。
- 接入是租户管理员操作+平台审核双签，全流程留痕。

```javascript
async function reviewIngest(docs, tenant) {
  for (const d of docs) {
    d.classification = await classifySensitivity(d);   // 密级标签
    if (d.classification === 'restricted'
      && !tenant.approvedFor('restricted'))
      return reject(d, '密级超出租户授权范围');
  }
  await qualityGate(docs); await rightsCheck(docs);  // 质量+版权
  return ingest(docs, { visibility: tenant.visibilityMap }); // 权限映射
}
function retrieveFiltered(q, user) {
  return vector.search(q, { filter: {
    classification: { lte: user.clearance } } });   // 密级过滤
}
```
