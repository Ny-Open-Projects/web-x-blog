## 1272：笔试手写：实现 流式输出双写落盘器

**需求**：实现 dualWriter()：返回 { push(text), flush(), getDisplay(), getPersist() }。展示流按帧节流（累计 >= 20 字符或距上次 >= 100ms 才更新展示缓冲）；持久化流每条原样累积不做节流（保证完整性）。flush() 强制把展示缓冲清空合并。getPersist 永等于全量文本。

```js
function dualWriter() {
  let raw = '', display = '', lastFlush = 0;
  return {
    push(text) {
      raw += text; display += text;
      const now = Date.now();
      if (display.length >= 20 || now - lastFlush >= 100) { // 双条件触发
        // 展示层直接以 display 为准（真实实现此处触发 setState/渲染）
        lastFlush = now;
      }
    },
    flush() { lastFlush = Date.now(); },
    getDisplay: () => display,
    getPersist: () => raw,
  };
}
```

**评分点**：
- 展示与持久化分离（渲染节流不影响数据完整）
- 字符数或时间双条件触发节流
- raw 与 display 的关系（display 是 raw 的展示视图）
- 能讨论：双写与「渲染合帧器」（AGT-423）的分层——那是渲染侧，这是数据侧
