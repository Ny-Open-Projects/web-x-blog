## AGT-332：视觉 Agent（看屏幕/操作 GUI 的 Agent）的技术方案？

**答**:
- 感知层：截图/多模态模型理解（元素识别+布局理解——配合 accessibility tree（DOM/无障碍树）混合方案：树给精确结构，视觉给像素级验证——纯视觉慢且不稳，纯树拿不到非标准控件，混合最稳）。
- 动作层：定位（元素坐标/selector）→ 执行（点击/输入/滚动）→ 验证（执行后截图确认状态变化）——感知-行动-验证循环（AGT-153 的截图反馈同源），验证失败重试或回退。
- 可靠性工程：GUI 动态性大（弹窗/加载态）——每步验证+步数熔断+异常暂停转人（"屏幕状态异常，请接管"）；关键操作（支付/删除）强确认。
- 应用与评测：测试自动化（视觉回归/RPA 替代）、数据录入自动化；评测用任务成功率+步数+恢复能力（遇到弹窗能否正确处理）——GUI Agent 的评测必须含干扰场景。

```text
GUI Agent 循环：
感知：截图 VLM + accessibility tree 混合
行动：定位 → 点击/输入 → 执行
验证：执行后截图比对（循环），
  失败重试 → 熔断 → 转人
安全：关键操作强确认；
评测：任务成功率 + 干扰场景
  （弹窗/加载态）恢复能力。
```
