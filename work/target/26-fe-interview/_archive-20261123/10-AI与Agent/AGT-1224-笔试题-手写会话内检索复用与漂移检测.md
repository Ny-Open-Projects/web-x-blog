## 1224：笔试手写：实现多轮检索的复用判定与漂移告警

**需求**：实现 SessionRetrieval(sim, search)：search(q) 返回 hits；ask(q, { force })——与历史 query 最大相似度 >=0.92 且非 force 时复用（返回 { reused: true, hits, matchedQuery }），否则执行并记录；连续 3 次复用同一 matchedQuery 且用户负反馈 -> 漂移告警（返回 warn 字段）。

```js
function createSessionRetrieval(sim, search) {
  const history = [];               // { q, hits, reuseCount }
  let lastMatched = null, repeat = 0;
  return {
    async ask(q, { force = false } = {}) {
      if (!force) {
        let best = null, bestSim = 0;
        for (const h of history) {
          const s = sim(h.q, q);
          if (s > bestSim) { bestSim = s; best = h; }
        }
        if (best && bestSim >= 0.92) {
          best.reuseCount++;
          const warn = best === lastMatched && ++repeat >= 3
            ? 'same-source drift: consider widening search' : null;
          lastMatched = best;
          return { reused: true, hits: best.hits, matchedQuery: best.q, warn };
        }
      }
      repeat = 0; lastMatched = null;
      const hits = await search(q);
      history.push({ q, hits, reuseCount: 0 });
      return { reused: false, hits };
    },
  };
}
```

**评分点**：
- 复用判定（阈值+force 穿透）与历史记录双写一致
- 漂移告警（连续复用同一来源 + 负反馈信号——复用策略的自我纠偏）
- 复用计数（reuseCount 可观测复用率）
- 能讨论：漂移告警的消费（自动扩检索/转人工）、阈值分层（按意图 0.90/0.95）
