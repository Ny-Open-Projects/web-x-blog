## AGT-781：会话结束自动生成的摘要直接进记忆库，摘要质量怎么保证（漏关键/编造）

**答**：
- 摘要三验：完整性（关键槽位/决策是否覆盖——对照会话内固化的槽位清单）、忠实度（摘要断言能在原文找到依据，抽取式校验）、无泄漏（摘要不含敏感信息）。
- 结构化摘要模板：事实/决策/未决问题/情绪信号四段式，比自由摘要可控；未决问题段让跨会话续聊有抓手。
- 低质摘要拦截：忠实度校验不过的摘要进人工/重试队列，不直接入库——坏摘要会长期污染语义记忆。

```javascript
const SUMMARY_TEMPLATE = `四段式：事实清单/已做决策/未决问题/用户情绪与偏好信号。每条事实必须可溯源到原文。`;
async function summarizeSession(session) {
  const sum = await llm.summarize(session.transcript, SUMMARY_TEMPLATE);
  const checks = {
    slotsCovered: slotCoverage(sum, session.slots),   // 完整性
    faithful: await entailmentCheck(sum, session.transcript), // 忠实度
    clean: !SENSITIVE_RE.test(sum.text),              // 无泄漏
  };
  return Object.values(checks).every(Boolean)
    ? semantic.add(sum) : reviewQueue.add({ sum, checks });
}
```
