## AGT-761：记忆系统本身怎么评测（检索命中率/蒸馏质量/画像准确率）

**答**：
- 三组指标：检索质量（相关记忆命中率/误注入率——注入不相关记忆导致的错误回答）、蒸馏质量（蒸馏事实与人工金标的一致率/幻觉率——蒸馏出原文没有的"事实"最危险）、画像准确率（画像字段与用户自我报告的一致率）。
- 评测方法：蒸馏用金标对照（抽样人工标注"这句话是否真是用户的特征"）；端到端用「记忆消融」实验（开/关记忆对比回答质量），量化记忆的真实贡献。
- 持续监控：误注入率（引用了被用户否认的记忆）线上监控，直接负反馈关联。

```javascript
async function evalMemory(samples) {
  const distill = await judgeDistill(samples, GOLDEN_FACTS); // 蒸馏一致率
  const ablation = await abTest({
    withMemory: runAgent({ memory: true }),
    without: runAgent({ memory: false }),
  }, { metric: 'taskDoneRate' });                  // 记忆消融
  return {
    recallHit: hitRate(samples), misInject: misInjectionRate(samples),
    distill, ablation: ablation.delta,             // 记忆的净贡献
  };
}
```
