## AGT-717：图片/视频的访问权限如何继承所属文档（而非独立配置）

**答**：
- 权限绑定载体：多模态资产继承其所属文档/空间的权限（文档保密则内嵌图片同样保密），资产单独共享要显式"提升"操作并审计。
- 检索与展示双端校验：检索时权限剪枝（无权限图片不召回），展示时二次校验（引用渲染前验证当前用户对该资产权限，防会话分享等场景越权）。
- 缩略图也受控：缩略图 URL 签名短时效 + 权限校验中间件——泄密常从"缩略图没控"开始。

```javascript
function canViewAsset(asset, user) {
  const doc = asset.ownerDoc;                      // 权限继承
  return acl.can(user, 'read', doc) || asset.grants.has(user.id);
}
app.get('/asset/:id/thumb', auth, async (req) => {
  const asset = await getAsset(req.params.id);
  if (!canViewAsset(asset, req.user)) return 403;  // 缩略图也校验
  return signedUrl(asset.thumb, { ttl: 300 });
});
```
