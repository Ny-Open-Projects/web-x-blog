## AGT-732：问答时图片应该读字还是看整体，两种理解路径如何协调

**答**：
- 按 query 类型路由：找具体信息（"图里多少钱"）走 OCR/数据提取路径；理解语义（"这张图表达了什么"）走整体理解路径；混合问题两路都走再融合。
- 两路结果冲突处理（OCR 读出 A，整体理解说 B）：OCR 数值优先（机器提取可信度高于模型口述），语义冲突时回原图让模型带区域坐标重看。
- 成本视角：OCR 便宜可先行，整体理解贵按需触发——先 OCR 提取后判断"文字够不够回答"，够则不调 vision 大模型。

```javascript
async function understandImage(img, q) {
  const need = await routeQuery(q);                // 路径路由
  const ocr = await cheapOCR(img);
  if (need === 'lookup' && ocr.sufficientFor(q))
    return ocr;                                    // 文字够就不调vision
  const sem = await vision(img, { query: q, regions: ocr.conflictZones });
  return mergePaths(ocr, sem, { numericPriority: 'ocr' }); // 数值OCR优先
}
```
