## AGT-251：Agent 为什么比单轮 LLM 难评测——评测对象有哪些？

**答**:
- 难点本质：单轮 LLM 评测"一次输出的质量"，Agent 评测的是"一条轨迹"——多步决策序列中每一步都可能对错组合（搜索对了但没读懂、读对了但调错工具），终局对了不代表过程健康，终局错了也不知道坏在哪步。
- 评测对象四层：结果（任务是否完成，最硬）、轨迹（步骤序列是否合理：冗余/循环/危险操作）、单步质量（工具选择与传参、中间结论质量）、系统属性（成本/延迟/稳定性/安全合规）——四层独立打分再合成。
- 动态性问题：Agent 行为依赖环境（工具返回/网页内容），环境变了轨迹就变——评测要有受控环境（mock 工具/固定数据集）才能复现对比。
- 指标陷阱：只看任务成功率会掩盖成本灾难（成功但花 50 次调用）——生产评测必须结果指标与过程指标（步数/成本/失败模式分布）并重。

```text
Agent 评测四层对象：
结果层：任务成功率 / 部分完成度
轨迹层：步数分布 / 循环与冗余检测 /
  危险操作出现率
单步层：工具选择准确率 / 传参错误率 /
  中间结论质量
系统层：P95 延迟 / 单任务成本 /
  安全违规率
原则：结果与过程并重，受控环境复现，
  每层独立打分可归因。
```
