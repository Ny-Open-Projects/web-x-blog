## 1089：提示词/评估集作为资产，怎么记账防止重复建设

**答**：
- 资产账本：提示词模板（含版本、适用模型、评估分数）、评估集（含覆盖意图、规模）、工具封装——统一注册中心登记，新项目先查账本再自建。
- 记账驱动复用：每个资产记录「被引用次数 + 节省成本估算」（复用一份评估集省的建设工时），季度公布「高价值资产榜」，让写资产的人有署名与激励。
- 资产质量门槛：入账本必须有评估数据与维护人，无主的资产半年降级归档，防止账本腐化成垃圾场。
- 追问钩子：资产复用和「过度抽象」的边界？——复用数据与模板（事实资产），不复用代码路径（逻辑资产各项目差异大）；提示词是事实资产，编排代码是逻辑资产。

```ts
const assetRegistry = {
  register(a) { require(a.evalScore, '资产必须有评估数据'); require(a.owner);
    return db.assets.add({ ...a, refs: 0 }); },
  cite(id) { return db.assets.inc(id, 'refs'); },       // 引用计数
  audit() { return db.assets.stale('180d').archive(); } // 无主资产归档
};
```
