## AGT-701：PDF/扫描件进多模态知识库的解析管线怎么搭（版面分析→图文分离→索引）

**答**：
- 管线五步：① 版面分析（区分正文/表格/图/标题/页眉页脚）；② 分流：文本走文本管线（切块+embedding），图/表走多模态管线（描述+原文件存储）；③ 图文关联（图属于哪个章节/上下文段落，切块时保留归属）；④ 双索引（文本向量索引 + 图片描述索引 + 可选 CLIP 跨模态索引）；⑤ 质量门禁（解析置信度低的页进人工复核队列）。
- 关键设计：图片不直接做向量，而是「caption + OCR 文字 + 周边文本」三合一描述做索引——纯图像 embedding 召回语义精度差。
- 版面还原质量决定引用体验：保留页码与坐标，回答引用时可跳转并高亮原区域。

```javascript
async function parseDocument(pdf) {
  const layout = await layoutAnalysis(pdf);       // 版面分析
  const chunks = [];
  for (const region of layout.regions) {
    if (region.type === 'text')
      chunks.push(...textPipeline(region, layout));
    else if (region.type === 'image' || region.type === 'table') {
      const desc = await describe(region);        // caption+OCR+周边文本
      chunks.push({ kind: 'multimodal', desc, assetRef: region.blob,
        page: region.page, bbox: region.bbox,     // 坐标留引用
        belongsTo: layout.sectionOf(region) });   // 图文关联
    }
  }
  return qualityGate(chunks, { lowConf: 'human-review' });
}
```
