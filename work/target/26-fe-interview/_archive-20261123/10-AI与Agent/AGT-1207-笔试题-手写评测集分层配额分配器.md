## 1207：笔试手写：实现评测集的意图分层配额抽样

**需求**：实现 sampleStratified(items, quotas)：quotas 为 { [intent]: count }。按配额从各 intent 组抽取（不足配额取全部）；未在 quotas 中出现的 intent 不抽；同 intent 内打乱后取前 n（注入 rand 保持确定性）。返回 { sampled, skipped: { intent: 缺口数 } }。

```js
function shuffle(a, rand = Math.random) {
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rand() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}
function sampleStratified(items, quotas, rand = Math.random) {
  const groups = {};
  for (const it of items) (groups[it.intent] ??= []).push(it);
  const sampled = [], skipped = {};
  for (const [intent, q] of Object.entries(quotas)) {
    const g = shuffle([...(groups[intent] || [])], rand);
    sampled.push(...g.slice(0, q));
    if (g.length < q) skipped[intent] = q - g.length;   // 缺口显式暴露
  }
  return { sampled, skipped };
}
const items = [
  { id: 1, intent: 'fact' }, { id: 2, intent: 'fact' },
  { id: 3, intent: 'flow' },
];
console.log(sampleStratified(items, { fact: 2, flow: 2, reject: 1 }, () => 0));
// sampled: 1,2,3；skipped: { flow: 1, reject: 1 }
```

**评分点**：
- 配额语义正确（不足取全+缺口记录——分层抽样的诚实性）
- shuffle 拷贝不改原数组；rand 注入确定性
- quotas 外 intent 不抽（防泄漏未规划场景）
- 能讨论：缺口的处理（补题 vs 降权重）、配额与线上分布对齐的校准
