## AGT-369：Agent 给了错误回答，怎么系统排查是不是上下文的问题？

**答**:
- 上下文回放：trace 记录完整上下文（系统提示版本/注入的知识块/历史/工具结果——AGT-289 决策留痕），badcase 回放第一步是"看模型当时看到什么"——大多数"模型笨"实际是"上下文错"。
- 排查清单：该注入的没注入（检索没召回/记忆没命中）、注入了但位置差（埋在中部 AGT-225）、注入了但格式差（模型没读到结构）、注入了错误内容（知识库过时/冲突）、被压缩丢掉（AGT-363 保留规则失灵）、prompt 版本错（灰度配置错乱）。
- 归因方法：控制变量实验（去掉/替换可疑上下文块重跑，对比输出变化——上下文消融），定位到具体块的贡献或干扰。
- 预防性工具：上下文预览（调试模式直接渲染最终 prompt 供人检查）、注入审计日志（每块来源与命中分）、压缩前后 diff——把上下文变成可见可查的资产。

```javascript
function debugContext(badcase) {
  const ctx = replay(badcase.trace).context;   // 当时上下文
  return {
    missing: expectedBlocks(badcase).filter(b =>
      !ctx.blocks.includes(b)),                // 漏注入
    buried: positionOf(goldBlock(ctx)),        // 位置问题
    stale: ctx.blocks.filter(b => b.ts < STALE),
  };
}
// 消融实验：逐块去除重跑 → 定位干扰源。
```
