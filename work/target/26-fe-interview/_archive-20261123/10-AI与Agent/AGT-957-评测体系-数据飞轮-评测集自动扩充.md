## 957：评测数据飞轮怎么转起来

**答**：
- 飞轮闭环：线上流量 → 自动筛选高价值样本（负反馈、裁判低分、新意图）→ LLM 辅助生成评测项（query + 答案草案 + 证据）→ 人工审核入库 → 回归集扩容 → 驱动下一轮迭代。
- 筛选标准比全量入库重要：只收「有代表性或曾造成线上事故」的样本，无脑堆量会让回归集跑不动且稀释关键场景权重。
- 去重与漂移：入库前与存量题做语义近重检测；知识库更新后定期「复活」过期题重新标注，防评测集与产品脱节。
- 追问钩子：飞轮会不会把偏见固化？——会（只收负反馈会偏向极端场景），所以按意图分层配额入库，正常流量也要按比例采样。

```ts
async function flywheelLoop() {
  const candidates = await mineTraffic({
    filters: [negativeFeedback(), judgeScoreBelow(0.6), novelIntent()],
    quota: { fact: 30, flow: 20, reject: 10 },   // 分层配额防偏见固化
  });
  const items = await dedupeNear(candidates, evalStore);
  const drafted = await llmDraft(items);
  return humanQueue.push(drafted, { sla: '3d' }); // 人工审核后入增量集
}
```
