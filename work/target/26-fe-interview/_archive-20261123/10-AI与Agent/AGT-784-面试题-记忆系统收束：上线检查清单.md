## AGT-784：记忆系统上线的检查清单（质量/隐私/性能/治理）

**答**：
- 质量：蒸馏一致率金标验证过、检索命中率达标、记忆消融实验证明净贡献为正；隐私：敏感拦截双通道测试过、删除 SLA 演练（全层级联 <24h）、注入防指令越权测试；性能：P95 检索延迟达标、缓存失效链路正确（删除即失效）、降级演练；治理：用户管理页可用、审计报告可产出、批次回滚演练过。
- 清单的本质：记忆系统是「写进数据库的用户判断」，出错的影响是持续性的（不像单轮回答错完就过），所以上线标准要高于普通功能。

```javascript
const MEM_CHECKLIST = {
  quality: { distill: '>=0.9', recall: '>=0.85', ablation: '>0' },
  privacy: { sensitiveBlock: true, forgetSla: '<24h', injectTrust: true },
  perf: { p95: '<200ms', cacheBust: true, degradeDrill: true },
  govern: { userPanel: true, auditReport: true, rollbackDrill: true },
};
function goLive(results) {
  return Object.values(MEM_CHECKLIST).every(sec =>
    Object.entries(sec).every(([k, v]) => meets(results[k], v)));
}
```
