## 1237：笔试手写：实现知识库文档的新鲜度分布统计

**需求**：实现 freshness(docs, now)：docs 为 { id, publishedAt, type }[]；HALF_LIFE = { news: 7, policy: 90, spec: Infinity }（天）。每文档计算「剩余新鲜度」= 0.5^(days/halfLife)（spec 恒 1）；输出 { byType: { [type]: 平均新鲜度(3 位) }, stale: 新鲜度 <0.5 的文档 id 列表, staleRate }。

```js
const HALF_LIFE = { news: 7, policy: 90, spec: Infinity };
function freshness(docs, now) {
  const byType = {}, stale = [];
  for (const d of docs) {
    const hl = HALF_LIFE[d.type] ?? Infinity;
    const days = (now - new Date(d.publishedAt).getTime()) / 86400000;
    const fresh = hl === Infinity ? 1 : Math.pow(0.5, days / hl);
    (byType[d.type] ??= { sum: 0, n: 0 });
    byType[d.type].sum += fresh; byType[d.type].n++;
    if (fresh < 0.5) stale.push(d.id);
  }
  const avg = {};
  for (const [t, v] of Object.entries(byType))
    avg[t] = +(v.sum / v.n).toFixed(3);
  return { byType: avg, stale,
    staleRate: docs.length ? +(stale.length / docs.length).toFixed(3) : 0 };
}
const docs = [
  { id: 'n1', publishedAt: '2026-11-10', type: 'news' },   // 11 天 -> 0.336
  { id: 'p1', publishedAt: '2026-11-10', type: 'policy' }, // 0.926
  { id: 's1', publishedAt: '2024-01-01', type: 'spec' },   // 1
];
console.log(freshness(docs, Date.parse('2026-11-21')));
// byType { news: 0.336, policy: 0.926, spec: 1 }；stale ['n1']
```

**评分点**：
- 半衰期公式（0.5^(days/halfLife)）与 spec 的 Infinity 特判（无衰减）
- stale 阈值 0.5 语义（半衰期即分界）
- 按类型聚合（不同类型的新鲜度不可混谈）
- 能讨论：衰减参数的配置化（按内容类型）、staleRate 与巡检工单的联动
