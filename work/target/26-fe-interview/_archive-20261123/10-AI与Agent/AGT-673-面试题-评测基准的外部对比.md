## AGT-673：与外部基准（公开榜单/竞品产品）对比要避免哪些坑

**答**：
- 榜单坑：公开基准与你的任务分布不同（榜单高分≠你的场景好）；防止数据污染（基准题可能已在训练数据里）；榜单饱和（95 分的基准区分度没了）。
- 自建对外可比性的做法：公开基准只选非饱和+未污染的子集做「能力体检」，主打自建业务基准；竞品对比用「同题对测」（同一用例集喂竞品 API）+ 输出盲评，注意合规与配额。
- 对外报告纪律：引用外部数字必须带基准名+版本+日期，不给"我们比 XX 好 20%"这种无出处结论。

```javascript
function externalCompare(cases, competitors) {
  const clean = PUBLIC_BENCH.filter(b => !b.saturated && !b.contaminated);
  return {
    bench: runEval(clean),                        // 能力体检
    rivals: competitors.map(c => blindCompare(cases, c)), // 同题盲评
    disclaimer: '公开基准仅作能力体检，业务结论以自建基准为准',
  };
}
```
