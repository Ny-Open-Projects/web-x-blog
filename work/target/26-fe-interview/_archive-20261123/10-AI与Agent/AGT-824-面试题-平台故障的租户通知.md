## AGT-824：平台故障时如何通知租户（状态页/邮件/API）与事后报告

**答**：
- 通知三通道+节奏：状态页实时（检测到异常即标 degraded，不等确认）、邮件/Webhook 对订阅租户（P0 即时、P1 30 分钟内）、受影响租户定向通知（影响面分析后）。
- 事后报告（RCA）标准化：48h 内发布（时间线/根因/影响面/赔付/改进项），赔付自动计算（SLA credit 按分钟数），改进项带 owner 与期限公开跟踪。
- 通知内容纪律：说影响（哪些功能受影响）、不说猜测的根因（没查清就说"调查中"），避免错误信息二次传播。

```javascript
async function incidentNotify(inc) {
  statusPage.set(inc.severity, affectedServices(inc));   // 即时
  await Promise.all(subscribers(inc.severity).map(t =>
    notify(t, { channels: t.notifyChannels,
      template: inc.severity === 'P0' ? 'immediate' : '30min' })));
  schedule(inc, { rca: '48h', credit: autoCredit(inc.duration) });
}
```
