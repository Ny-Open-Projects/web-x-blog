## AGT-681：产品一周一变（新场景/新工具/新模板），评测体系怎么跟上节奏

**答**：
- 变更驱动建用例：产品需求评审时就写「验收评测用例」（需求文档→用例模板自动草稿+人工补金标），上线即有回归保护，而不是上线后出事再补。
- 场景退役同步：产品下线/改版的场景，对应用例 24h 内标记退役（挂版本号），防僵尸用例浪费预算并误报。
- 快速通道：新场景先用「结构骨架用例」（金标先宽松：格式对+关键要素在，judge 判据后补），跑通保护一周内再精化金标。

```javascript
function onProductChange(change) {
  if (change.type === 'new-scenario') {
    const draft = draftCasesFromPRD(change.prd);  // 需评审→用例草稿
    const skeleton = draft.map(c => ({ ...c,
      golden: { kind: 'loose', mustHave: c.keyElements } })); // 宽松金标先跑
    addToEval(skeleton, { refineDeadline: '+7d' });
  }
  if (change.type === 'deprecate')
    retireCases(change.scenario, { sla: '24h' });
}
```
