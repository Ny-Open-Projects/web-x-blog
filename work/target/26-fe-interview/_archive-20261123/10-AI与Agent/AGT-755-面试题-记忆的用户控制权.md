## AGT-755：用户查看/编辑/删除自己的 Agent 记忆，产品上怎么设计（合规+信任）

**答**：
- 记忆管理页是信任基础：列出全部语义记忆与画像字段（带来源与证据），支持编辑/删除/暂停记忆（隐私模式）；删除是硬删除（含向量与缓存）且有导出备份。
- 「这次为什么这样回答」可解释：回答引用记忆时给出管理页锚点链接，用户可溯源到具体记忆条目。
- 合规对齐：删除权（GDPR 式）级联清理所有层（语义/情景/画像/缓存/备份），删除日志留存（记录删了什么但不含内容）。

```javascript
async function forgetAll(userId) {
  const idx = await memoryIndex.byUser(userId);
  await Promise.all(idx.map(x => Promise.all([
    semantic.hardDelete(x.id), vector.remove(x.vecId),
    episodic.purge(userId), profile.clear(userId),
    cache.purgeUser(userId)])));                 // 全层级联
  audit.log({ action: 'memory.forget', userId: hashId(userId),
    count: idx.length });                        // 日志不含内容
}
```
