## AGT-707：培训视频/会议录屏进知识库，怎么分段索引与定位播放

**答**：
- 三层结构：视频 → 语义段（按字幕话题切分，5~10 分钟一段）→ 检索单元（字幕句子+关键帧描述）；检索命中到段，回答引用带时间戳。
- 关键帧策略：每段取 3~5 个关键帧做视觉描述（PPT 页/屏幕内容），与字幕共同索引——录屏类视频核心信息在画面而非语音。
- 前端联动：回答引用视频段时嵌入播放器并 seek 到时间戳，用户点击引用直接跳到对应画面。

```javascript
async function indexVideo(video) {
  const asr = await transcribe(video);             // 字幕
  const segments = topicSegment(asr, { targetMin: 5, targetMax: 10 });
  return Promise.all(segments.map(async seg => ({
    text: seg.text,
    frames: await Promise.all(keyFrames(seg, 4).map(f =>
      describe(f))),                               // 关键帧描述
    ref: { videoId: video.id, t0: seg.t0, t1: seg.t1 }, // 时间戳引用
  })));
}
// 前端：引用跳播
function citeToPlayer(cite) {
  player.load(cite.videoId);
  player.onReady(() => player.seek(cite.t0));
}
```
