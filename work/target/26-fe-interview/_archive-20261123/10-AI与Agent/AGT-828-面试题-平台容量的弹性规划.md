## AGT-828：Agent 任务量波动大（活动/月末报表），平台容量怎么弹性规划

**答**：
- 分层弹性：无状态层（网关/运行时）HPA 秒级扩容；有状态层（队列/向量库）预估扩容；模型侧弹性受供应商配额限制——真瓶颈在模型侧，规划核心是「配额储备+多供应商池」。
- 峰值预测：历史周期性（月末/活动日历）+租户预告（大客户报备活动）双输入；储备策略：常量基线+预测峰值+安全余量 20%。
- 过载保护预案：分级降载（低优先级任务延迟/批处理降速/非核心租户排队），过载时保核心租户核心任务——预案要演练过才有用。

```javascript
function capacityPlan(month) {
  const forecast = predict({ periodic: history(), events: tenantNotices });
  return {
    baseline: avg(history()),
    reserve: forecast.peak * 1.2,                  // 安全余量
    modelPool: vendorQuotas(),                     // 多供应商配额池
    shed: { lowPriority: 'delay', batch: 'slowdown',
      nonCore: 'queue' },                          // 分级降载预案
  };
}
```
