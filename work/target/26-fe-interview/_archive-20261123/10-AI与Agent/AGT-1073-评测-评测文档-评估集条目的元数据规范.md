## 1073：评估集条目该带哪些元数据

**答**：
- 必备元数据：id（稳定不变）、intent、difficulty、evidence（证据引用）、source（真实/合成/事故转化）、created/reviewed 时间与审校人、tags（改动影响面索引用）。
- 关键作用链：tags 支持「增量评估」（只跑受影响的题）、source 支持「分布审计」（合成占比过高报警）、difficulty 支持「分层抽样」——没有元数据的评估集就是一堆文本，没法工程化。
- 演进元数据：deprecated 标记与替代题链接、last_verified（知识库变更后该题是否复验过）——过期题带毒跑评测会误导决策。
- 追问钩子：元数据谁来维护？——创建时标注是义务（不完整不入库），复验时更新；元数据完整性进 PR 检查项。

```ts
interface EvalMeta {
  id: string; intent: Intent; difficulty: 1|2|3;
  evidence: string[]; source: 'real'|'synthetic'|'incident';
  tags: string[];                     // 增量评估索引
  reviewedBy: string; reviewedAt: string;
  deprecated?: string;                // 替代题 id
  lastVerified?: string;              // 知识库变更复验时间
}
```
