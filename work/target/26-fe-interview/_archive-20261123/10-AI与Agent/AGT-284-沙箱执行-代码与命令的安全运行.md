## AGT-284：Agent 需要执行代码/命令时，沙箱怎么设计？

**答**:
- 隔离层级：进程级（独立进程+资源限额：CPU/内存/时长——基本盘）、容器级（Docker/微 VM：文件系统只读挂载+无网络或代理网络+非 root 运行——生产标配）、内核级（gVisor/Firecracker 微 VM——高危场景）、网络级（出站白名单：沙箱只能访问声明过的 API 域名，堵外传通道）。
- 输入与输出治理：执行的代码先静态扫描（危险 API：fs 全盘/rm -rf/网络外发→拒绝）、输出限流（防打印爆炸）与超时强杀；代码只读写工作目录内的临时文件。
- 资源与成本护栏：并发沙箱数上限（防资源耗尽攻击）、单次执行配额（时长/CPU 秒计费）、失败重试预算——Agent "试错式写代码"会连环创建沙箱，必须有总预算。
- 分级策略：计算类（算数/数据处理）低危全自动；系统命令类高危逐条白名单；依赖安装类（pip/npm）需要锁版本并扫描——不是所有执行一个待遇。

```javascript
async function sandboxExec(code) {
  if (await staticScan(code).danger) return reject(code);
  return await microVM.run(code, {
    fs: { workdir: '/tmp/w', readonlyRoot: true },
    net: { whitelist: ['api.internal'] },   // 出站白名单
    limits: { cpu: 2, memMB: 512, wall: 10e3 },
    onTimeout: killAndSnapshot,             // 超时留证据
  });
}
```
