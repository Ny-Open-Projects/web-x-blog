## AGT-611：可观测体系里如何刻画「单个用户的使用画像」（高频用户/异常使用/成本大户）

**答**：
- 用户维度聚合（按日滚动）：调用量、成本、任务类型分布、采纳率、负反馈率；从聚合里产出画像标签：重度用户/成本大户/疑似脚本（速率模式异常）/体验受损用户（连续负反馈）。
- 成本大户不是直接限流：先归因（长上下文没压缩？批量脚本？），给个性化动作（提示压缩/推送批量 API/配额建议）。
- 隐私边界：画像只聚合不存原文，标签可解释（每个标签能追溯到聚合指标），符合最小化原则。

```javascript
function dailyProfile(userId) {
  const agg = metrics.user(userId, { window: '1d' });
  return {
    tags: [
      agg.cost > P99_COST && 'cost-heavy',
      agg.callsPerMin > THRESH && ratePattern(agg) === 'machine' && 'suspect-bot',
      agg.dislikeStreak >= 3 && 'experience-hurt',
    ].filter(Boolean),
    actions: agg.tags.includes('cost-heavy')
      ? suggestCompression(userId) : null,       // 归因后的个性化动作
  };
}
```
