## AGT-682：图像/语音输入输出的评测判据与纯文本有何不同

**答**：
- 视觉理解判据：要素检出（图中指定要素是否识别）、空间关系（左右/上下判断）、图表读数（数值容差）；这些用结构化问题+数值容差判定，judge 只做兜底。
- 生成类输出（图表/图片）：结构校验（schema 对）+ 视觉回归（关键元素存在+布局不崩，感知哈希比对）+ 语义判据（数据映射正确性）。
- 语音：ASR 准确率（WER）与语义判据分离；TTS 用 MOS 抽样+关键词可懂度（程序可判部分优先）。

```javascript
const MM_CHECKS = {
  vqa: (gold, out) => elementHit(gold.elements, out),      // 要素检出
  chartRead: (gold, out) => Math.abs(gold.value - out.value)
    <= gold.tolerance,                                     // 数值容差
  genChart: (gold, out) => schemaOk(out)
    && phashSimilar(gold.layout, out.render)               // 视觉回归
    && dataMapOk(gold.data, out.series),
  asr: (gold, out) => wer(gold.text, out.text) < 0.1,      // WER
};
function judgeMultimodal(c, out) {
  const prog = (MM_CHECKS[c.kind] ?? (() => null))(c.golden, out);
  return prog !== null && prog !== undefined
    ? { score: prog ? 1 : 0, how: 'programmatic' }
    : llmJudge(c.rubric, c, out);
}
```
