## AGT-825：新租户从签约到用上 Agent 的全流程（初始化/配置/试点/放量），平台怎么支撑

**答**：
- 五步：①初始化（区域绑定/SSO 对接/环境创建，向导化 <1 天）；②数据接入（知识库导入+安全审查+权限映射）；③Agent 配置（选模板/绑工具/配策略，模板市场加速）；④试点（小范围用户+观察指标+调优）；⑤放量（灰度→全量+SLA 生效+培训材料）。
- 每步有验收标准与卡点：SSO 打不通不进②，知识库质量门不过不进④——卡点防止"半配置上线出事故"。
- 全流程可视化：租户 onboarding 进度看板（哪步卡住/卡多久/谁负责），实施团队与租户共同维护。

```javascript
const ONBOARDING = [
  { step: 'init', gate: 'sso-ok', sla: '1d' },
  { step: 'data', gate: 'quality>=0.85', sla: '3d' },
  { step: 'config', gate: 'policy-review' },
  { step: 'pilot', gate: 'doneRate>=0.85', sla: '2w' },
  { step: 'scale', gate: 'training-done' },
];
function onboardingBoard(tenant) {
  return ONBOARDING.map(s => ({
    ...s, status: gateStatus(tenant, s),
    stuck: stuckDays(tenant, s) > s.sla ? 'escalate' : null,
  }));
}
```
