## 986：离线批处理任务（批量摘要/索引）怎么省钱跑

**答**：
- 批处理省钱三板斧：错峰跑（配额空闲时段）、批量接口（供应商 batch API 通常 5 折）、小模型+抽样校验（80% 任务小模型完成，抽 10% 用大模型复检校准）。
- 队列设计：优先级队列 + 速率跟随（根据下游配额动态调整消费速率），批任务永远给交互流量让路。
- 断点续跑：任务级 checkpoint，中断后从上次位置继续而不是全量重来——百万级文档批量 embedding 没有断点续跑等于灾难。
- 追问钩子：批任务中途改了 prompt 怎么办？——版本标记 + 未完成部分用新版本跑，已跑完的部分按「新旧混批」标注，评估时区分。

```ts
async function batchRun(items, fn, { checkpoint }) {
  let done = await checkpoint.load();
  for (const it of items.slice(done.index)) {
    while (!(await quota.tryTake(1, 'batch'))) await sleep(1000); // 速率跟随
    const r = await fn(it);
    done = await checkpoint.save({ index: items.indexOf(it) + 1, results: done.results.concat(r) });
  }
  return done.results;
}
```
