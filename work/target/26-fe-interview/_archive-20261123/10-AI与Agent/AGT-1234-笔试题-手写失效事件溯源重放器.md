## 1234：笔试手写：实现失效事件的溯源重放（验证一致性）

**需求**：实现 replay(graph, events, qc)：events 为按时间的 { event, payload }[]。按序触发 invalidateEvent（见依赖图遍历），并统计每个 pattern 的失效次数；输出 { calls, counts }（counts 为 pattern -> 次数）与 duplicateChains（同一 pattern 在相邻两次事件中被失效——疑似过度失效）。

```js
function replay(graph, events, qc) {
  const log = [], counts = {};
  let prev = [];
  const dupChains = [];
  for (const e of events) {
    const before = log.length;
    invalidateEvent(graph, e.event, qc, new Set(), log);
    const added = log.slice(before);
    added.forEach(p => counts[p] = (counts[p] || 0) + 1);
    const overlap = added.filter(p => prev.includes(p));
    if (overlap.length) dupChains.push({ at: e.event, patterns: overlap });
    prev = added;
  }
  return { calls: log, counts, duplicateChains };
}
const graph = { a: ['P1', 'on:b'], b: ['P1'] };   // P1 被双重失效
const calls = [];
replay(graph, [{ event: 'a' }], { invalidate: p => calls.push(p) }, );
// calls ['P1','P1'] —— duplicateChains 提示过度失效
```

**评分点**：
- 按序重放 + 计数聚合（失效行为的可审计）
- duplicateChains 的相邻重复检测（过度失效诊断——语义加分项）
- 事件序与失效序的对应
- 能讨论：过度失效的修复（图去重/合并）、溯源重放用于线上事故还原
