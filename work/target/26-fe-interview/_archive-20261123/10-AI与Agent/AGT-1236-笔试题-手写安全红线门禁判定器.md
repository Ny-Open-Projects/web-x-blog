## 1236：笔试手写：实现红队结果的分级门禁（零通过+基线）

**需求**：实现 redGate(results, cfg)：cfg = { hardZero: string[]（这些 vector 必须全拦截）, softMin: number }。results 为 { vector, bypass: bool }[]。规则：hardZero 任一 bypass -> block（列出违规 vector）；软类拦截率 < softMin -> block；否则 pass。输出 { verdict, reasons }。

```js
function redGate(results, cfg) {
  const reasons = [];
  const hardHit = results.filter(r => cfg.hardZero.includes(r.vector) && r.bypass)
    .map(r => r.vector);
  if (hardHit.length) reasons.push('hard bypass: ' + hardHit.join(','));
  const byVec = {};
  for (const r of results) {
    if (cfg.hardZero.includes(r.vector)) continue;
    (byVec[r.vector] ??= { blocked: 0, n: 0 });
    byVec[r.vector].n++;
    if (!r.bypass) byVec[r.vector].blocked++;
  }
  for (const [v, s] of Object.entries(byVec)) {
    const rate = s.blocked / s.n;
    if (rate < cfg.softMin) reasons.push(`soft low: ${v} ${(rate * 100).toFixed(0)}%`);
  }
  return { verdict: reasons.length ? 'block' : 'pass', reasons };
}
const cfg = { hardZero: ['exec', 'exfil'], softMin: 0.8 };
console.log(redGate([
  { vector: 'exec', bypass: true },
  { vector: 'jailbreak', bypass: true }, { vector: 'jailbreak', bypass: false },
], cfg));
// { verdict: 'block', reasons: ['hard bypass: exec'] }
```

**评分点**：
- 硬零通过（高危一票否决）与软基线（拦截率）双轨
- hardZero 向量不计入软统计（口径分离）
- reasons 可读（CI 报告直接引用）
- 能讨论：分级红线的产品语义（高危零容忍/低危目标值）、绕过样本回流红队库
