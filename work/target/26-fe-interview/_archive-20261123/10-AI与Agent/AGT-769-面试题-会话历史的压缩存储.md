## AGT-769：90 天情景记忆的存储成本与压缩策略（分级压缩/冷热分离/摘要替代）

**答**：
- 时间分级：7 天内全文热存（随时回看）、30 天压到「轮次摘要+关键原文」（被引用过的原文保留）、90 天只留会话摘要与蒸馏产物，全文到期删除。
- 引用保护：被语义记忆引用的原文片段延长保留（溯源需要），未引用的按期清理——引用计数驱动保留。
- 成本账：压缩后存储降 80%+，检索质量靠「蒸馏产物长期保留」兜底（知识在语义层不丢）。

```javascript
async function compressEpisodic() {
  const sessions = await episodic.olderThan(7 * 864e5);
  for (const s of sessions) {
    const cited = await semantic.citedQuotes(s.id);
    await episodic.compress(s, { keep: cited,        // 引用保护
      to: 'turn-summary' });
  }
  const old = await episodic.olderThan(90 * 864e5);
  for (const s of old) await episodic.finalize(s,    // 只留摘要
    { keep: 'summary+semantic-links' });
}
```
