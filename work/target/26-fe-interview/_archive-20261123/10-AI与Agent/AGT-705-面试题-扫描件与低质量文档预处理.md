## AGT-705：扫描件（歪斜/模糊/印章遮挡）进知识库前要做哪些预处理与质量门禁

**答**：
- 预处理链：去斜（版面矫正）、去噪（印章/水印分离——印章区域标记而非删除）、二值化自适应（低对比度）、分辨率提升（超分，成本换质量可选）。
- OCR 质量分级：OCR 置信度低于阈值的区域单独标记，整页低于阈值进人工/重扫队列；数字类内容（金额/日期）做「字典校验」（日期合法性/金额格式）兜底。
- 拒收比错收好：质量太差的文档明确告知用户"识别质量不足，建议提供电子版"，错误入库的垃圾内容会污染检索。

```javascript
async function preprocessScan(scan) {
  const deskewed = await deskew(scan);
  const clean = await denoise(deskewed, { stamps: 'mask-not-remove' });
  const ocr = await ocr(clean, { detailed: true });
  const pageConf = avg(ocr.blocks.map(b => b.conf));
  const suspectNums = ocr.blocks.filter(b =>
    b.type === 'number' && !plausible(b.text));    // 数字合法性校验
  if (pageConf < 0.7)
    return reject(scan, { reason: 'quality',
      hint: '识别质量不足，建议提供电子版或重扫' });
  return { text: ocr, flags: { suspectNums, stamped: clean.stampedRegions } };
}
```
