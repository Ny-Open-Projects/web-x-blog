## 1252：笔试手写：实现 中断残留清洗器

**需求**：用户点停止后，已到达的流文本常有半截内容。实现 cleanResidue(text)：删除最后一个未闭合的 markdown 代码围栏及其之后内容；删除末尾未闭合的行内代码反引号；截掉末尾不完整的句子（最后一个句号/问号/换行之后的部分），但至少保留 1 个字符。返回清洗后文本。

```js
function cleanResidue(text) {
  let t = text;
  const fences = t.match(/```/g) || [];
  if (fences.length % 2 === 1) {          // 未闭合围栏：从最后一个 ``` 起整段删
    t = t.slice(0, t.lastIndexOf('```'));
  }
  if (/(^|\n)[^\n]*`[^`]*$/.test(t)) {   // 行内代码未闭合
    t = t.replace(/`[^`]*$/, '');
  }
  const end = Math.max(
    t.lastIndexOf('。'), t.lastIndexOf('？'), t.lastIndexOf('!'), t.lastIndexOf('\n')
  );
  if (end >= 0 && end < t.length - 1) t = t.slice(0, end + 1);
  return t.slice(0, 1) || t;              // 至少保留 1 字符兜底
}
```

**评分点**：
- 围栏奇偶判定与「从最后一个围栏截断」的处理顺序
- 行内代码与块级围栏两类残留分别处理
- 句子边界截断的多分隔符取 max
- 能讨论：残留清洗与续传（AGT-042）的关系——清洗丢失的内容可由续传补回
