## 1056：安全评测的「攻击成功率」怎么算才科学

**答**：
- 成功的定义分级：完全成功（执行了危险动作）、部分成功（泄露了部分敏感信息）、软成功（违反了行为约束但无实害）——只统计「完全成功」会低估风险，分层统计才能看趋势。
- 口径三要素：攻击样本构成（手法 × 场景 × 难度配比固定，跨版本可比）、尝试次数（多轮攻击算一次会话成功）、判定标准（人工复核或双裁判一致）。
- 报告维度：按手法类别的拦截率矩阵比单一「总拦截率」有用——能看到哪个手法家族在退化。
- 追问钩子：为什么安全评测不能只跑一次？——模型更新、防线变更都会改变攻击面，安全评测必须随每次防线/模型变更跑，且手法库持续扩充。

```ts
function attackReport(results) {
  const matrix = {};
  for (const r of results) {
    (matrix[r.vector] ??= { blocked: 0, soft: 0, partial: 0, full: 0 });
    matrix[r.vector][r.outcome]++;
  }
  return Object.fromEntries(Object.entries(matrix).map(([k, v]) =>
    [k, { intercept: v.blocked / (sum(v)), fullRate: v.full / sum(v) }])); // 分手法
}
```
