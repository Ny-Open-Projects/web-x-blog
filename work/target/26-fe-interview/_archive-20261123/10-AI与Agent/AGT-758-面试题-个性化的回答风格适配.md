## AGT-758：同一问题不同用户要不同答案风格（新手/专家/老板），风格适配管线怎么设计

**答**：
- 风格三参数：深度（解释到什么层次）、形式（步骤/结论/对比表）、长度（简洁/详细）；由画像推导默认值，用户可会话内临时切换（"给我讲细点"立即生效并可选记住）。
- 适配在「指令层」而非重写层：把风格参数写进系统提示让模型一次生成，而不是生成后再改写（省一次调用且不破坏内容）。
- 边界：风格适配不改变事实内容；专家模式省略基础解释但保留关键前提（防止"以为对方懂"造成误解）。

```javascript
function stylePrompt(profile, override) {
  const s = { ...profile.style, ...override };    // 会话内覆盖优先
  return [
    s.depth === 'expert' ? '面向资深工程师：直接给方案与权衡，跳过基础概念，但保留关键前提。'
      : '面向入门者：分步骤解释，每步给示例。',
    s.form === 'compare' ? '用对比表格呈现选项。' : '',
    s.length === 'brief' ? '总长不超过 300 字。' : '',
  ].join('');
}
```
