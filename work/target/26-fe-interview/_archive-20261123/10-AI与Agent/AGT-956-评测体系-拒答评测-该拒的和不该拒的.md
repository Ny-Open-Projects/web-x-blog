## 956：拒答能力怎么评测：过度拒答和漏拒答是一对坑

**答**：
- 拒答评测双集合：应答集（知识库内有答案的题，测漏拒答）+ 应拒集（知识库外、超范围、危险请求，测过度拒答），漏拒 = 幻觉风险，过拒 = 可用性差，两边都要有红线。
- 核心指标：应答集回答率（越高越好）、应拒集拒答率（越高越好）、误拒率（应答集里被拒的比例，通常要求 < 5%）。
- 阈值联动：检索置信度阈值调高会同时改善漏拒、恶化误拒——评测要画出这对 trade-off 曲线，选业务可接受的点而不是拍脑袋。
- 追问钩子：应拒集怎么构造？——同领域改写（把题改成知识库没覆盖的变体）+ 跨域题 + 对抗题（诱导越权回答）三类，对抗题必须人工出。

```ts
function拒答Report(results) {
  const ans = results.filter(r => r.set === 'should_answer');
  const rej = results.filter(r => r.set === 'should_reject');
  return {
    answerRate: rate(ans, r => !r.rejected),      // 应答集回答率
    rejectRate: rate(rej, r => r.rejected),       // 应拒集拒答率
    falseReject: rate(ans, r => r.rejected),      // 误拒率红线 < 0.05
  };
}
```
