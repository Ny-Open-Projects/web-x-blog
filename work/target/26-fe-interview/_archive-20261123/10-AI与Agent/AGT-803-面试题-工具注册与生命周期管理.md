## AGT-803：平台上注册一个工具（CRM 查询）的完整生命周期（注册/评审/上线/变更/下线）

**答**：
- 生命周期五阶段：注册（OpenAPI/函数签名+schema+能力声明）→ 安全评审（数据敏感级/副作用分级/权限要求）→ 灰度上线（指定租户/白名单用户）→ 变更管控（schema 变更 semver，破坏性变更需迁移期）→ 下线（引用检测：还有 Agent 在用就不许下线，给迁移窗口）。
- 工具元数据是一等公民：描述（给模型看的）、参数 schema（给校验用）、风险级（给审批用）、SLA（给降级用）。
- 版本共存：v1/v2 并行期调用方迁移，平台流量报表辅助迁移决策。

```javascript
const TOOL_META = {
  name: 'crm.query', version: '2.1.0',
  schema: paramsSchema, description: '给模型的自然语言描述',
  risk: 'read', sensitivity: 'PII',               // 评审字段
  sla: { p95: 800, availability: 0.99 },
};
function canRetire(tool) {
  const refs = registry.referrers(tool);          // 引用检测
  return refs.length === 0
    || refs.every(r => r.migratedTo ?? false);
}
```
