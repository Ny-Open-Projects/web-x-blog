## AGT-504：把一段 AI 对话生成分享链接时，快照要做什么处理（脱敏、防篡改、过期）

**答**：
- 快照是服务端生成的只读副本（含消息树激活路径），不是前端截屏——保证渲染一致性且可控敏。
- 分享前强制跑脱敏管线：手机号/邮箱/内网域名/token 等正则+NER 双通道检测，命中项打码或拦截用户确认。
- 链接带过期与权限（登录可见/凭链接可见），快照内容加签名防篡改，访问日志留痕。

```javascript
// 服务端：生成分享快照
function createShareSnapshot(sessionId, opts = {}) {
  const msgs = getActivePath(sessionId);
  const redacted = msgs.map(m => ({
    ...m, content: redact(m.content, { // 脱敏管线：正则+NER
      patterns: [PHONE_RE, EMAIL_RE, INTRANET_RE],
      onHit: (hit) => opts.strict ? null : mask(hit), // strict 模式命中即拒绝
    }) }));
  const payload = { msgs: redacted, createdAt: Date.now(),
    expireAt: Date.now() + 7 * 864e5 };
  return { id: saveSnapshot(payload),
    sig: hmac(payload), access: opts.access || 'link' };
}
```
