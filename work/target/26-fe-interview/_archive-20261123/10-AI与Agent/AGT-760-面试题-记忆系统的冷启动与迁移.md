## AGT-760：新用户（无历史）与老用户换账号（迁移记忆），记忆冷启动怎么做

**答**：
- 新用户冷启动：显式引导（3 个问题快速画像：角色/技术栈/偏好）+ 默认画像（按角色模板），记忆随交互逐步积累；前 N 轮回答用保守风格（不过度个性化）。
- 账号迁移：记忆导出为标准格式（schema 版本化）+ 导入校验（schema 兼容/冲突检测）；跨系统迁移时语义记忆可迁移、行为推断需重新积累。
- 冷启动质量监控：新用户前 10 轮的负反馈率与留存对比，验证画像引导是否有效。

```javascript
const EXPORT_SCHEMA = { ver: 2, profile: 'schema',
  semantic: 'facts[]', episodic: 'optional' };
async function importMemory(payload) {
  assertSchema(payload, EXPORT_SCHEMA);           // 版本校验
  const conflicts = await profile.detectConflicts(payload.profile);
  if (conflicts.length)
    return ui.confirmMerge(conflicts);            // 冲突让用户裁决
  await profile.write(payload.profile, { source: 'migrated' });
  await semantic.bulk(payload.semantic, { evidence: 1, tag: 'migrated' });
}
```
