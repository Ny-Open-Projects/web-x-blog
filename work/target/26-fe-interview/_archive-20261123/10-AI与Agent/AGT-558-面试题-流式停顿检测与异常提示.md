## AGT-558：流式输出中途长时间没新 token，前端如何检测停顿并提示/恢复

**答**：
- 心跳检测：正常流 token 间隔 < 数秒，超过阈值（如 8s 无 delta 也无心跳事件）进入"疑似卡住"状态——UI 显示"响应变慢，正在等待"，但不立刻报错。
- 分级处理：15s 无响应→展示"重连"按钮（sse 重连补 seq gap）；服务端心跳（keepalive 事件）可区分"模型在算"与"链路断了"，有心跳就继续等。
- 卡住恢复后要对齐：重连拉取缺失 seq 的片段合并，已渲染部分不重复。

```javascript
let lastEvent = Date.now(), watchdog;
function startWatchdog(stream) {
  watchdog = setInterval(() => {
    const idle = Date.now() - lastEvent;
    if (idle > 15000) showStallUI({ canResume: true });   // 卡住可恢复
    else if (idle > 8000) showHint('响应变慢，正在等待…');  // 先温和提示
  }, 2000);
}
stream.on('data', () => { lastEvent = Date.now(); clearStallUI(); });
stream.on('heartbeat', () => { lastEvent = Date.now(); });   // 心跳≠卡死
async function resume() {
  const missed = await api.fetchGap(stream.lastSeq);        // 按 seq 补拉
  missed.forEach(applyDelta);
}
```
