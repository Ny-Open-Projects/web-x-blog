## AGT-554：Agent 并行发 4 个工具调用（搜索/查库/读文件/算数），进度 UI 怎么聚合呈现

**答**：
- 聚合视图 = 总进度（完成数/总数 + 预计剩余）+ 可展开的分项列表；分项之间不共享进度条（各工具进度语义不同，硬合成百分比是伪指标）。
- 部分失败不阻塞展示：3 成 1 败时总状态显示"部分完成"，失败的项可单独重试后与成功项合并（对应服务端部分结果合并）。
- 快任务（<300ms）完成后从"运行中"折叠进摘要，避免时间线闪跳抖动。

```javascript
function ParallelToolsProgress({ calls }) {
  const done = calls.filter(c => c.status === 'ok').length;
  const failed = calls.filter(c => c.status === 'error').length;
  const running = calls.length - done - failed;
  const summary = failed
    ? `${done}/${calls.length} 完成，${failed} 失败`      // 部分失败明确
    : `${done}/${calls.length} 完成`;
  return <>
    <ProgressBar value={done} max={calls.length} label={summary} />
    <Expandable>{calls.filter(c => c.status !== 'ok' || c.slow)
      .map(c => <ToolNode key={c.id} tc={c} />)}   // 快任务折叠进摘要
    </Expandable>
  </>;
}
```
