## 1065：评测周报自动生成的信息结构怎么设计

**答**：
- 周报四段：指标速览（本周 vs 上周核心指标，箭头标注升降）、本周改动与其评测结果（改了什么、过没过门禁）、badcase 摘要（top3 簇 + 状态）、下周计划（基于看板优先级的派工）。
- 自动化程度：指标与图表全自动生成，badcase 摘要 LLM 起草人工审 10 分钟，计划半自动（看板拉取 + 人定）。
- 受众适配：周报正文给团队（技术细节），自动派生一段「管理层视图」（趋势一句话 + 风险一句话）——一份数据两种呈现。
- 追问钩子：周报最容易失败在哪？——变成「数据搬运」没有判断；每个指标变化必须附一句「为什么 + 打算」，机制上强制评论字段必填。

```ts
async function weekly() {
  const m = await metrics.weekOverWeek();
  const annotated = m.map(d => ({ ...d, why: requireComment(d) })); // 强制归因
  const top = (await board(thisWeekFailures)).slice(0, 3);
  return render({
    metrics: annotated, changes: changelog.week(),
    badcases: top, plan: planner.fromBoard(), exec: oneLineForBoss(m),
  });
}
```
