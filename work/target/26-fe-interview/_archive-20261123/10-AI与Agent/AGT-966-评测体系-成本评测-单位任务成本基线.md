## 966：怎么给 Agent 任务建立成本基线并监控漂移

**答**：
- 建立基线：按任务类型统计「单位任务成本」（token 数 × 单价 + 工具调用费用），取 P50/P95 而不是均值（长尾任务会拉高均值掩盖典型体验）。
- 漂移监控：成本突增的常见原因——上下文泄漏（历史越滚越长）、重试风暴、模型路由错档（简单任务用了旗舰模型）、知识库膨胀导致检索结果变长。
- 预算护栏：单任务成本超 P95 × 1.5 时熔断并触发告警，防止一个坏 case 烧掉大量预算。
- 追问钩子：成本和质量哪个优先？——先定「质量红线」再在红线内优化成本；没有质量红线的成本优化会把系统调废。

```ts
function costDrift(current, baseline) {
  const ratio = current.p95 / baseline.p95;
  if (ratio > 1.5) return { action: 'circuit_break', reason: 'cost spike x' + ratio };
  if (ratio > 1.2) return { action: 'alert', top: topCostlySubtasks() }; // 定位最贵环节
  return { action: 'ok' };
}
```
