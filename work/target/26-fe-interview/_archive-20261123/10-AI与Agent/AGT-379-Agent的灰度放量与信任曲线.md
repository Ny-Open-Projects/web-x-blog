## AGT-379：Agent 功能从灰度到全量的放量节奏怎么设计？

**答**:
- 放量阶梯：影子（0 流量验证，AGT-256）→ 白名单内测（友好用户收集反馈）→ 5%（小流量护栏验证）→ 25% → 50% → 100%，每级停留期由"指标稳定期"决定（不是固定天数——指标连续 N 天达标才升档）。
- 信任曲线管理：放量越快，单用户的错误暴露越集中——升档前检查"错误类型分布"（新增错误模式？还是已知模式频率？新增模式即暂停）、用户负反馈率趋势（不升反降才继续）。
- 升级与暂停条件：核心指标达标+护栏指标无恶化+无新增高危失败模式 → 升档；任一护栏破线 → 自动缩量一档（AGT-322 开关联动），并可一键回滚。
- 全量后不是结束：30 天漂移观察（AGT-259 新奇效应）、成本水位复核（真实用量 vs 预算模型）、季度复盘（错误模式库更新）——放量纪律的本质是"用数据逐步赢得信任"。

```text
放量阶梯：
影子 → 白名单 → 5% → 25% → 50% → 100%
升档条件：指标连续稳定 + 无新增
  高危失败模式；
破线 → 自动缩一档，可一键回滚。
全量后：30 天漂移 + 成本复核 +
  季度复盘。
本质：用数据逐步赢得信任。
```
