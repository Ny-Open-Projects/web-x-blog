## AGT-576：工具调用参数传给后端前，前端能做哪些预检（schema 校验/危险词/依赖缺失）

**答**：
- 三层预检省一整个往返：schema 校验（JSON Schema 校验工具参数，类型/必填/枚举）、依赖检查（工具声明的 requires 如"需要已上传文件"，前端验证上下文满足）、危险词初筛（destructive 参数含 delete all 之类先本地提示）。
- 预检失败不上报后端：直接在时间线节点标"参数不合法"并展示哪个字段错了，Agent 下一轮自动收到结构化失败信息可自纠。
- 预检是优化不是防线：安全红线永远以服务端为准，前端预检只做体验加速。

```javascript
function precheckToolCall(tc, ctx) {
  const errs = [];
  const ajv = getValidator(tc.tool);       // 每工具一份编译过的 schema
  if (!ajv(tc.args)) errs.push(...ajv.errors.map(e => e.message));
  for (const req of tc.requires ?? [])     // 依赖检查
    if (!ctx.satisfies(req)) errs.push(`缺少前置条件：${req}`);
  if (tc.risk === 'destructive' && /delete\s+all/i.test(JSON.stringify(tc.args)))
    errs.push('疑似全量删除操作，需要人工确认');
  if (errs.length) return rejectLocally(tc, errs);  // 不发后端，Agent 可自纠
  return send(tc);
}
```
