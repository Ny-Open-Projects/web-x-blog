## 1273：笔试手写：实现 工具执行超时看门狗

**需求**：实现 withWatchdog(fn, ms, onTimeout)：fn 为返回 Promise 的工具执行。超时 ms 后：调用 onTimeout(partial) 尝试回收部分结果（fn 需通过参数接收 report 回调上报进度）；最终返回 { status: 'ok'|'timeout', result, elapsed }。超时后 fn 若稍后完成，结果丢弃但记录 late: true。

```js
function withWatchdog(fn, ms, onTimeout) {
  return new Promise(resolve => {
    const t0 = Date.now();
    let done = false;
    const report = partial => { if (!done && onTimeout) onTimeout(partial); };
    const timer = setTimeout(() => {
      if (done) return;
      const partial = onTimeout ? null : null;
      resolve({ status: 'timeout', result: null, elapsed: Date.now() - t0, late: false });
      done = true;
    }, ms);
    fn(report).then(
      r => {
        if (done) { /* 超时后才完成：丢弃 */ }
        else { clearTimeout(timer); done = true;
          resolve({ status: 'ok', result: r, elapsed: Date.now() - t0, late: false }); }
      },
      e => { if (!done) { clearTimeout(timer); done = true;
        resolve({ status: 'error', result: String(e), elapsed: Date.now() - t0, late: false }); } }
    );
  });
}
```

**评分点**：
- race 之外的显式 timer + done 标记（防晚到结果覆盖）
- report 回调给 fn 上报部分结果的通道
- error 分支也算终局（不只 ok/timeout 二分）
- 能讨论：真取消需 AbortSignal 贯穿工具内部，看门狗只是兜底
