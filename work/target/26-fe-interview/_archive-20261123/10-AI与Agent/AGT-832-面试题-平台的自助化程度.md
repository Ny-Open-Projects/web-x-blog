## AGT-832：平台运维自助化（租户自己开通/排查/扩容）到什么程度合适，边界在哪

**答**：
- 高自助：Agent 配置/发布/灰度/回滚、配额查询、告警订阅、审计导出——这些高频低风险操作全自助，人工介入是成本也是瓶颈。
- 人工把关：安全审查类（数据接入/工具上架/策略豁免）、不可逆操作（数据删除/区域迁移）、超配额扩容（合同动作）——自助化边界=风险边界。
- 自助化的度量：工单分类统计，"本应自助的工单占比"是平台体验的核心指标，目标把它压到 <20%。

```javascript
const SELF_SERVE = {
  auto: ['publish', 'canary', 'rollback', 'quota-view', 'audit-export'],
  gated: ['data-ingest', 'tool-onboard', 'policy-exempt', 'region-move'],
};
function ticketHygiene(tickets) {
  const shouldSelf = tickets.filter(t => SELF_SERVE.auto.includes(t.kind));
  return { selfServeRatio: 1 - shouldSelf.length / tickets.length,
    target: 0.8, action: topTicketKinds(shouldSelf) };  // 补自助能力
}
```
