## 1274：笔试手写：实现 提示词回归快照对比器

**需求**：实现 promptRegression(baseline, current)：baseline/current 为 { caseId, output }[]。按 caseId 对齐；输出 diff 列表（输出变化的 case）；漂移率 = 变化数 / 总数；对「基线通过、当前输出为空」的 case 额外标记 regression: true。返回 { driftRate, changed, regressions }。

```js
function promptRegression(baseline, current) {
  const base = new Map(baseline.map(c => [c.caseId, c.output]));
  const cur = new Map(current.map(c => [c.caseId, c.output]));
  const allIds = new Set([...base.keys(), ...cur.keys()]);
  const changed = [], regressions = [];
  for (const id of allIds) {
    const b = base.get(id), c = cur.get(id);
    if (b !== c) changed.push(id);
    if (b !== undefined && b !== '' && (c === undefined || c === '')) regressions.push(id);
  }
  return {
    driftRate: allIds.size ? +(changed.length / allIds.size).toFixed(3) : 0,
    changed, regressions,
  };
}
```

**评分点**：
- 按 caseId 对齐（Map 化，防顺序差异）
- 漂移率与回归的区分（漂移≠变差，回归=确定变差）
- 新增/删除 case 也计入变化
- 能讨论：黄金集快照是提示词改动的安全网，配合自动 diff 门禁
