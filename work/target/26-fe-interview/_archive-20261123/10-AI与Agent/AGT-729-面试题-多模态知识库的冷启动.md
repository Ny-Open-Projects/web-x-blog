## AGT-729：新上线多模态知识库（只有一堆 PDF），冷启动优先级怎么排

**答**：
- 按预期问答价值排序入库：先跑 query 日志/用户访谈拿到 top 问题清单，能回答这些问题的文档优先；没有 query 数据时按文档访问频次（网盘下载量/最近更新）排序。
- 冷启动三批：第一批只做文本+表格（最快可用），第二批补图片描述索引，第三批做视频/音频——每批都有可用产出，不做"全部入库才上线"。
- 冷启动质量验证：每批入库后用 top 问题做命中率验收，命中率不达标的批次回炉（解析质量问题）而非继续堆量。

```javascript
async function coldStart(docs, topQueries) {
  const ranked = rankByQueryCoverage(docs, topQueries); // 按价值排序
  const batches = [pick(ranked, { kinds: ['text', 'table'] }),
    pick(ranked, { kinds: ['image'] }),
    pick(ranked, { kinds: ['video', 'audio'] })];
  for (const b of batches) {
    await ingest(b);
    const hit = await acceptance(topQueries);      // 命中率验收
    if (hit < 0.7) return rework(b, hit.failures); // 不达标回炉
  }
}
```
