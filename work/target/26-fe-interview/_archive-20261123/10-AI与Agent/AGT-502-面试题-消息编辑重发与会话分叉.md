## AGT-502：对话消息的「编辑重发」如何实现？分叉（branch）后的历史树怎么管理

**答**：
- 编辑历史消息重发 = 从该消息截断出新分支，而不是原地修改：原分支要保留（用户可能对比两条回答）。
- 数据结构用消息树：每条消息带 parentId，激活路径 = 从当前叶子回溯到根；UI 只渲染激活路径。
- 侧边切换分支（如 ChatGPT 的 < 2/2 >）就是切换同一 parent 下的兄弟节点。

```javascript
// 消息树：parentId 指向 + activePath 激活路径
function buildActivePath(messages, leafId) {
  const byId = new Map(messages.map(m => [m.id, m]));
  const path = [];
  let cur = byId.get(leafId);
  while (cur) { path.unshift(cur); cur = byId.get(cur.parentId); }
  return path; // 从根到叶子的当前展示路径
}
function editAndResend(messages, targetId, newContent) {
  // 不改旧消息：以 target.parentId 为父，挂新 user 消息，触发新回复
  const node = messages.find(m => m.id === targetId);
  const fork = { id: genId(), parentId: node.parentId,
    role: 'user', content: newContent, branch: true };
  messages.push(fork);
  return fork.id; // 新叶子，激活路径自动切换到新分支
}
```
