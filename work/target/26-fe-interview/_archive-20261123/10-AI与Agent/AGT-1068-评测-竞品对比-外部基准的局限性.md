## 1068：跑公开基准（HumanEval 等）能代替自建评测吗

**答**：
- 公开基准的价值：跨团队可比、模型选型初筛（同预算下先跑公开基准缩小候选）；局限：分布与你的业务不符、可能被模型训练「记住」（分数虚高）、测不到你的关键场景。
- 正确用法：公开基准做「初筛 + 体检」，自建集做「选型 + 门禁」——两者分数冲突时信自建集（它贴近你的真实分布）。
- 业务相关性映射：从公开基准挑与你场景相近的子集（如做代码 Agent 就重点看 SWE-bench 类），别拿综合分决策。
- 追问钩子：为什么「模型在基准上刷分」这么普遍？——基准公开且静态，训练数据污染几乎不可避免；动态/私有基准才抗污染，这也是自建集必须「冻结 + 定期换血」的原因。

```ts
const strategy = {
  screening: 'public_bench',       // 初筛：公开基准缩小候选
  selection: 'own_eval',           // 选型：自建集决策
  gate: 'own_core_set',            // 门禁：只用自建集
  conflict: 'trust own_eval',      // 冲突时信自建（分布贴近业务）
};
```
