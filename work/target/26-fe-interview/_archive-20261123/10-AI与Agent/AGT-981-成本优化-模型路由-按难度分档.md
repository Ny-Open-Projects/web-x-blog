## 981：按任务难度路由到不同档位模型的方案怎么落地

**答**：
- 分档依据三层：显式规则（任务类型、用户等级、输入长度）→ 轻量分类器（小模型判难度）→ 级联兜底（低档跑完校验不过升档重跑）。
- 档位定义要挂钩评估数据：每个档位在该类任务上的历史通过率是路由阈值依据，「小模型通过率 ≥0.9 的任务类」才允许默认走小模型。
- 路由本身不能成为成本黑洞：规则优先，分类器用 1B 级小模型，绝不拿旗舰模型做路由判断。
- 追问钩子：路由错了怎么发现？——级联升级率与最终成功率分档监控，某类任务升级率持续 >30% 说明该类应整体换档而不是每次冒险。

```ts
const POLICY = {          // 分档策略表：通过率数据驱动
  rewrite: { model: 'small', passRate: 0.95 },
  qa: { model: 'mid', passRate: 0.88 },
  coding: { model: 'large', passRate: 0.72 },
};
async function route(task) {
  const p = POLICY[task.kind];
  const out = await run(task, p.model);
  if (await verifier.check(out)) return out;
  return run(task, nextTier(p.model));   // 级联兜底
}
```
