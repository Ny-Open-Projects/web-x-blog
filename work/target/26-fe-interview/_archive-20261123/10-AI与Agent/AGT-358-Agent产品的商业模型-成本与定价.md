## AGT-358：Agent 产品的定价与商业模式怎么设计？

**答**:
- 成本结构决定定价底线：单用户可变成本（token/工具调用）+ 固定成本（平台研发/评测运维）——先用单位经济学（AGT-280）算出成本基线，定价必须覆盖且有毛利；成本波动风险（模型涨价/用量长尾）留缓冲。
- 定价模式选择：按席位（SaaS 常规，但 Agent 成本与用量挂钩——席位制下重度用户吃掉利润）、按用量（成本转嫁直接但用户预算难控——需要用量预估与封顶）、混合（基础订阅+用量包/公平使用限额）——Agent 产品多用混合制，配额体系（AGT-323）既是安全网也是计费边界。
- 价值定价：按"替代的成本"定价（替代人工 X 小时→定价锚定人工成本的一部分）而非按成本加成——Agent 的商业逻辑是效率溢价；需要量化 ROI 帮用户算账（AGT-347 思路对内对外同构）。
- 免费策略与风险：免费额度是获客漏斗但也是成本攻击面（AGT-300 滥用）——免费层限任务复杂度/频次，风控兜底。

```text
Agent 商业模型：
底线：单位经济学成本基线 + 缓冲
模式：基础订阅 + 用量包（混合制），
  配额=计费边界+安全网
锚点：按替代人工成本定价（价值定价），
  提供 ROI 算账工具
免费层：限复杂度与频次 + 风控，
  防滥用套利。
```
