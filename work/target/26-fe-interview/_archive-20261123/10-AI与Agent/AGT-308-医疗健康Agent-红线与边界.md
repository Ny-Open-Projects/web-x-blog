## AGT-308：医疗健康类 Agent 的能力边界与红线怎么设计？

**答**:
- 定位红线：不做诊断与处方（诊断是执业医师法定行为）——Agent 定位为健康信息科普/就医引导/报告解读辅助；输出强制声明"不构成诊疗建议"；症状类问题引导就医而非给结论。
- 能力白名单：科普问答（引用权威指南库）、检验报告的指标解释（数值在参考区间内的解释，异常值提示就医）、就诊流程与科室推荐（规则引擎+知识库）、用药信息查询（说明书级信息，不给个性化剂量建议）。
- 高危拦截：自杀/急症关键词触发急救通道（120/热线直显，AGT-265 拒答的特殊形态——拒答+救生引导）；药物剂量/相互作用问题拒绝个性化回答，指向药师。
- 数据合规：健康数据是最敏类别——单独同意/加密存储/最小化使用/本地化部署；审计全留痕，数据保留期合规。

```text
医疗 Agent 边界：
定位：科普/引导/报告辅助，非诊断处方；
  强制声明 + 异常值提示就医
白名单：权威指南问答 / 报告指标解释 /
  科室推荐 / 说明书级用药信息
红线拦截：急症关键词→急救通道直显；
  剂量/相互作用→指向药师不给个性化
数据：单独同意 + 本地化 + 最小化 + 审计。
```
