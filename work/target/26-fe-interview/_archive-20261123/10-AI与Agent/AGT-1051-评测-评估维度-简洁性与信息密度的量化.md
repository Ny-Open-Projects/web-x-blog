## 1051：「答案太啰嗦」怎么量化成指标

**答**：
- 信息密度 = 有效信息单元数 / 输出 token 数；有效信息单元用「压缩后保留的要点数」估计（摘要压缩到 30% 仍覆盖的要点算有效），密度低的答案在灌水。
- 操作化：抽答案的「论点句」（含数字/结论/动作的句子），统计「论点句 / 总句数」作为代理指标——纯铺垫句占比高即啰嗦。
- 评测维度落地：简洁性进评估集（每题标注「理想长度区间」），长度超标且无增量信息的版本扣分；LLM-as-judge 的 rubric 里明确「重复信息不加分」。
- 追问钩子：压长度会不会压掉质量？——用「信息单元守恒」护栏：压缩前后有效要点数一致才允许通过，否则判定丢信息而非简洁。

```ts
function density(answer) {
  const sents = splitSentences(answer);
  const informative = sents.filter(hasFact).length;   // 含数字/结论/动作
  return { density: informative / (sents.length || 1),
    verdict: informative / sents.length < 0.4 ? 'verbose' : 'ok' };
}
```
