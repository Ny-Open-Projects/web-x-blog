## 1267：笔试手写：实现 语言脚本路由器

**需求**：实现 routeLang(text)：按字符脚本占比路由。统计中文字符、日文假名、韩文谚文、拉丁字母四类占比；假名占比 > 0.1 → 'ja'；谚文 > 0.1 → 'ko'；中文 > 0.15 → 'zh'；其余 → 'en'。中英混合（中文占比 0.15~0.6）返回 'zh-mixed' 并附拉丁占比。返回 { lang, ratios }。

```js
function routeLang(text) {
  const count = { zh: 0, ja: 0, ko: 0, latin: 0 };
  let total = 0;
  for (const ch of text) {
    let k = null;
    if (/\u4e00-\u9fff/.test(ch)) k = 'zh';
    else if (/[\u3040-\u30ff]/.test(ch)) k = 'ja';
    else if (/[\uac00-\ud7af]/.test(ch)) k = 'ko';
    else if (/[a-zA-Z]/.test(ch)) k = 'latin';
    if (k) { count[k]++; total++; }
  }
  const ratios = {};
  for (const k of Object.keys(count)) ratios[k] = total ? +(count[k] / total).toFixed(3) : 0;
  let lang = 'en';
  if (ratios.ja > 0.1) lang = 'ja';
  else if (ratios.ko > 0.1) lang = 'ko';
  else if (ratios.zh > 0.6) lang = 'zh';
  else if (ratios.zh >= 0.15) lang = 'zh-mixed';
  return { lang, ratios };
}
```

**评分点**：
- Unicode 区段判定脚本（假名/谚文优先级高于中文防误判）
- 比例阈值路由、判定顺序即优先级
- zh-mixed 混合态单独输出（中英混排路由到双语模型）
- 能讨论：仅拉丁字符时的英/法等细分需依 N-gram 或检测库
