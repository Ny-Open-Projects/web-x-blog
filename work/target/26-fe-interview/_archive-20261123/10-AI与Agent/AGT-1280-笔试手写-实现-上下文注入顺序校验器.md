## 1280：笔试手写：实现 上下文注入顺序校验器

**需求**：实现 validateContextLayout(blocks)：blocks 为 { kind: 'system'|'memory'|'rag'|'user', text }[]。规则：system 必须且只能在最前（允许多条连续）；user 必须在最后；memory 在 system 之后、rag 之前；rag 之间不允许插 user。校验顺序合法性与完整性（四类是否齐备）。返回 { valid, violations }。

```js
function validateContextLayout(blocks) {
  const violations = [];
  const kinds = blocks.map(b => b.kind);
  const firstNonSystem = kinds.findIndex(k => k !== 'system');
  if (kinds.slice(0, firstNonSystem < 0 ? kinds.length : firstNonSystem).some(k => k !== 'system'))
    violations.push('system 必须在最前且连续');
  // 期望序：system* -> memory* -> rag* -> user*
  const ORDER = { system: 0, memory: 1, rag: 2, user: 3 };
  let last = -1;
  kinds.forEach((k, i) => {
    if (ORDER[k] < last) violations.push(`位置 ${i}: ${k} 违反顺序（应在更早层）`);
    else last = ORDER[k];
  });
  if (kinds[kinds.length - 1] !== 'user') violations.push('user 必须在最后');
  for (const need of ['system', 'user']) {
    if (!kinds.includes(need)) violations.push(`缺少 ${need} 层`);
  }
  return { valid: violations.length === 0, violations };
}
```

**评分点**：
- 层序映射为数值后单遍比较（单调不降）
- system 前缀连续性 + user 收尾双重锚点
- 完整性检查（system/user 不可缺）
- 能讨论：顺序影响模型注意力——system 后置会被指令层级防线拦截
