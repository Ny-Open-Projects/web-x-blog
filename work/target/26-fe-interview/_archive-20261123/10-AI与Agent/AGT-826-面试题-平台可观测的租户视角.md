## AGT-826：租户自助看自己的 Agent 运行情况（自己租户的指标），平台怎么开放

**答**：
- 租户自助看板四块：用量与配额（实时余量/趋势/预测）、任务健康（完成率/失败 topN）、成本明细（按 Agent/工具分项）、审计日志（操作与数据访问记录）。全部数据按租户过滤（标签强制），看不到其他租户任何信息。
- 告警订阅开放：租户可自配告警规则（配额 80% 通知/错误率超阈值通知），走自己的通知渠道（Webhook/邮件）。
- 指标口径公开文档化（与平台内部口径一致），避免"平台说达标租户说没达标"的口径纠纷。

```javascript
function tenantDashboard(tenantId, viewer) {
  assertScope(viewer, { tenant: tenantId });       // 租户隔离兜底
  return {
    quota: quotaView(tenantId), health: healthView(tenantId),
    cost: costBreakdown(tenantId), audit: auditQuery({ tenant: tenantId }),
  };
}
function subscribeAlerts(tenant, rules) {
  return rules.map(r => scheduler.add({
    expr: r.expr, channel: tenant.webhook,        // 租户自有渠道
    scope: { tenant: tenant.id } }));
}
```
