## 965：人工评测的标注规范怎么写，怎么管标注一致性

**答**：
- 标注规范三要素：维度定义（每个分值档给具体例子，如 3 分=「答案正确但有轻微冗余」）、边界仲裁流程（分歧样本谁终裁）、标注上下文最小化（标注员只看「问题 + 答案 + 证据」不看系统信息，防锚定）。
- 一致性管理：定期抽 10% 双人背靠背标注，算一致率；低于 0.7 时通常是规范模糊，回头改规范而不是怪标注员。
- 校准会：每次规范变更后开 30 分钟对齐会，用 5 个争议样本集体标注达成一致，再放量。
- 追问钩子：标注规范多久迭代一次？——跟着评测体系演进（新增维度必改），但已标注数据要记录「基于规范 vN」，跨版本数据混用要声明。

```ts
const rubric = {
  dims: ['correctness', 'completeness', 'conciseness'],
  anchors: { 3: '正确且完整', 2: '正确但缺要点或轻微冗余', 1: '部分错误', 0: '错误/幻觉' },
  arbitration: '分歧由资深标注员终裁并记录理由',
};
async function spotCheck(done, rate = 0.1) {
  const dup = sample(done, rate);
  return kappa(dup.map(d => d.score), await relabel(dup)); // 一致率监控
}
```
