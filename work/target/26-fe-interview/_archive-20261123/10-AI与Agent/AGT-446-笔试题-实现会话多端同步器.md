## AGT-446：手写多端同步：同账号多标签页状态一致、服务端兜底、双写冲突处理

**需求与边界**：
- 输入：本地状态变更、跨端消息；输出：同步后的会话状态。
- 边界要求：① 标签页间 BroadcastChannel 即时同步；② 刷新/新标签页经服务端拉全量+增量（seq 对齐）；③ 双端同时写（都发消息）按服务端序合并；④ 本地乐观更新失败回滚。

**答**：
```javascript
class MultiTabSync {
  constructor({ convId, bc, server }) {
    this.convId = convId; this.bc = bc; this.server = server;
    this.seq = 0; this.pending = new Map();     // 本地乐观更新
  }
  // 1. 本地变更：乐观更新 + 广播 + 服务端
  async localChange(change) {
    const localId = uid();
    this.pending.set(localId, change);
    applyOptimistic(change);                    // 先渲染
    this.bc.postMessage({ type: 'change',
      from: this.tabId, convId: this.convId, change });
    try {
      const ack = await this.server.append(this.convId, change);
      this.pending.delete(localId);
      this.seq = ack.seq;
      this.bc.postMessage({ type: 'ack',
        from: this.tabId, localId, seq: ack.seq });
    } catch (e) {
      revertOptimistic(localId);                // 服务端拒绝→回滚
      this.bc.postMessage({ type: 'revert',
        from: this.tabId, localId });
    }
  }
  // 2. 跨端消息
  onMessage(msg) {
    if (msg.from === this.tabId) return;
    if (msg.type === 'change') applyRemote(msg.change, msg.from);
    if (msg.type === 'revert') revertOptimistic(msg.localId);
    if (msg.type === 'ack') confirmPending(msg.localId, msg.seq);
  }
  // 3. 新标签页/刷新：seq 对齐拉增量
  async catchUp() {
    const { events, latest } = await this.server.after(
      this.convId, this.seq);
    events.forEach(applyRemote);
    this.seq = latest;
  }
  // 双写冲突：server.append 按到达序分配 seq，
  // 双端各自收到 ack 后以服务端 seq 为准重排（最后一致）。
}
```

**评分点**:
- 乐观更新+服务端确认+失败回滚三段式，体验与一致性兼顾。
- BroadcastChannel 标签页即时同步 + 服务端 seq 增量对齐双通道。
- 双写冲突以服务端序为准（last-write-wins with server seq），本地只做乐观。
- from 字段防自收回环。
