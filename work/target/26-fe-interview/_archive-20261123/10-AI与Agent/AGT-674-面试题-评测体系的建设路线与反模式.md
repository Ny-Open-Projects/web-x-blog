## AGT-674：评测体系从零到成熟的建设顺序，以及最常见反模式

**答**：
- 路线：①手攒 50 条冒烟用例+脚本跑通（有基本回归能力）→②judge 接入+CI 门禁（自动化）→③分层+统计+漂移探针（可信）→④回流+对抗+平台化（规模化）。每一步解决上一步暴露的最痛问题，不跳级。
- 反模式 top4：只测自己能过的用例（自我安慰集）、judge 不校准直接信（分数漂移未知）、评测集只增不减（越跑越慢越贵）、分数与业务脱节（优化对了分丢了用户）。
- 判断成熟度的标志：提示词改动敢不敢直接上线——评测体系成熟 = 团队对回归分数有信任。

```javascript
const ROADMAP = {
  s1: '50条冒烟+脚本', s2: 'judge+CI门禁',
  s3: '分层+统计+漂移探针', s4: '回流+对抗+平台',
};
const ANTI = ['安慰剂用例集', '未校准judge', '只增不减', '分数业务脱节'];
function healthCheck() {
  return { anti: ANTI.filter(detected),           // 反模式自检
    mature: trustInRegressionScores() };          // 成熟度标志
}
```
