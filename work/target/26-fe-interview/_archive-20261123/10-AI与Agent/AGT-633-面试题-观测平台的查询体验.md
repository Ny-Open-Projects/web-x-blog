## AGT-633：给内部开发者一个 trace 查询界面，关键功能有哪些

**答**：
- 核心查询：按 traceId 精查、按属性组合检索（租户+版本+错误码+时间窗）、按「相似失败」找同类（指纹/嵌入检索）；结果直达 span 树与回放。
- 必备体验：span 树火焰图式时间轴、属性侧栏（复制/过滤）、与日志/指标互跳（点 span 看同时段日志）；常用查询存书签共享。
- 权限分级：普通开发看脱敏视图，调试权限才解密 L3；每次 L3 访问审计。

```javascript
function traceSearch(q, actor) {
  const hits = index.query({ ...q, tenant: scopeOf(actor) });
  return hits.map(h => ({
    tree: spanTree(h.id),          // 火焰图时间轴
    logs: linkByTime(h),           // 同时段日志
    similar: fingerprintNeighbors(h), // 相似失败
    masked: !actor.debugPerm,      // 脱敏视图
  }));
}
```
