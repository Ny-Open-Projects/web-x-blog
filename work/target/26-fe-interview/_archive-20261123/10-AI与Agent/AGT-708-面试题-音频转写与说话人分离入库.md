## AGT-708：会议录音进知识库，转写、说话人分离与脱敏怎么处理

**答**：
- 管线：ASR 转写 → 说话人分离（diarization，"说话人A/B"）→ 标点与段落重建 → 敏感信息脱敏（人名/手机号，除非用户开启保留）→ 分块索引。
- 会议纪要增值：入库时生成结构化纪要（决议/待办/争议点），纪要单独索引（检索命中率远高于逐句转写），原文转写作为引用底层。
- 转写质量门禁：专业术语纠错（自定义词表提升 ASR 准确率），WER 抽样检测，低质量段落标记低置信。

```javascript
async function indexMeeting(audio, { keepNames = false } = {}) {
  const { turns } = await asrDiarize(audio, {
    vocab: COMPANY_TERMS });                       // 自定义词表
  const text = turns.map(t => keepNames ? t.text
    : redact(t.text, { names: true, phones: true }))
    .join('\n');
  const minutes = await llm.summarize(text, MINUTES_TEMPLATE); // 结构化纪要
  return [
    { kind: 'minutes', text: minutes },            // 纪要优先索引
    ...chunk(text, { meta: { audioRef: audio.id } }),
  ];
}
```
