## AGT-713：文档里的图片被替换/删除，多模态索引如何增量失效

**答**：
- 图片以内容哈希为身份：文档更新时 diff 出「新增/替换/删除」三类，替换=删旧索引+入库新图；引用该图的缓存描述同步失效。
- 悬空引用防护：删除图片后，历史回答里的引用点击要给"原图已更新/移除"的兜底视图（存缩略图快照），不能 404。
- 增量成本控制：只有哈希变化的图片重新走 vision 管线（描述生成是最贵环节），文档文本变化不触发图片重索引。

```javascript
async function syncImages(docV1, docV2) {
  const diff = imageDiff(docV1, docV2, { by: 'contentHash' });
  await Promise.all([
    ...diff.removed.map(unindexImage),
    ...diff.added.map(indexImage),
    ...diff.changed.map(x => Promise.all([
      unindexImage(x.old), indexImage(x.new),
      descCache.invalidate(x.old.id)])),           // 替换双删双索引
  ]);
  return { ...diff, note: '快照已留存，历史引用可见旧图' };
}
```
