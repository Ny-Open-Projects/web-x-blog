## AGT-287：攻击者往知识库塞恶意文档（检索投毒）怎么防？

**答**:
- 攻击形态：往协作知识库/网页上传含隐藏指令或虚假事实的文档（白色小字/元数据藏指令），使其被 RAG 检索并影响所有用户的答案——比单次提示注入危害持久（毒文档一直在库里）。
- 摄入防线：入库审查管线（来源白名单/作者权限校验、内容审查：指令模式+事实可信度抽检、异常检测：与既有语料分布偏差大的文档人工审）、用户上传内容默认最低信任级（只影响该用户会话或标记不可引用）。
- 检索防线：答案只引用带来源的块（用户可点开溯源自行判断可信度）、多来源交叉（关键结论要求 ≥2 个独立来源支撑，单一可疑来源不给确定性结论）、可疑块降权（被标记过的来源降低检索权重）。
- 运营机制：投毒举报通道（用户对答案"来源可疑"一键举报→复核→拉黑来源）、定期对高引用文档做真实性抽检——知识库的可信度是运营出来的。

```javascript
async function ingest(doc, uploader) {
  if (!TRUSTED_SOURCES.has(doc.source))
    doc.trust = 'low';                        // 最低信任级
  const audit = await contentReview(doc);     // 指令模式+事实抽检
  if (audit.suspicious) return manualReview(doc);
  await index(doc, { trust: doc.trust,
    citable: doc.trust !== 'low' });          // 低信任不可引用
}
// 生成侧：关键结论要求 ≥2 独立来源；
// 举报 → 复核 → 来源降权拉黑。
```
