## AGT-567：Agent 反复调用同一工具卡在循环里，前端如何检测并给用户干预入口

**答**：
- 前端做轻量循环检测（服务端/运行时才是权威）：同一工具+相似参数连续出现 ≥3 次，UI 弹出干预条"Agent 似乎在重复查询，是否停止/给提示/跳过此步"。
- 干预动作映射：停止（cancel 任务保留已得结果）、提示（用户输入一句引导语注入下一轮）、跳过（标记该工具调用 skipped，让 Agent 换路）。
- 提示条不打断已渲染内容，以浮层形式出现，用户忽略则继续观察（服务端有硬上限兜底）。

```javascript
function detectLoop(toolCalls) {
  const key = (tc) => tc.tool + stableStringify(tc.args);
  let streak = 1;
  for (let i = 1; i < toolCalls.length; i++) {
    streak = key(toolCalls[i]) === key(toolCalls[i - 1]) ? streak + 1 : 1;
    if (streak >= 3) return true;
  }
  return false;
}
function LoopInterventionBar({ detected }) {
  if (!detected) return null;
  return <Bar actions={{
    stop: () => cancelTask('loop_detected'),
    hint: () => openHintInput(),           // 引导语注入下轮
    skip: () => markSkipped(lastToolCall.id),
  }} text="Agent 似乎在重复调用同一工具" />;
}
```
