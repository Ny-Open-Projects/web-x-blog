## AGT-252：Agent 的"任务成功"怎么定义——模糊目标怎么量化？

**答**:
- 成功判据要前置定义：任务创建时就写验收标准（可执行的断言：文件已创建且内容含 X / 订单状态变为 Y / 答案包含三个要点且引用正确）——没有验收标准的任务无法评测，这是评测集设计的核心。
- 分级计分：全对（1.0）/ 部分完成（按子目标清单比例，如 5 个子目标完成 3 个=0.6）/ 有效失败（正确拒答了无法完成的任务，计 0.5——诚实拒答好于编造）/ 错误（0）——二值成功率掩盖太多信息，分级才可优化。
- 模糊目标的处理：主观类任务（"写篇好文章"）用双评（LLM-judge 按 rubric 打分 + 人工抽检校准 judge）；rubric 要具体到维度（结构/事实/文风各多少分）。
- 成功的时间维度：当时对不代表稳定对（幻觉数字可能侥幸通过断言）——关键任务加"过程证据校验"（答案引用的依据必须真实存在）。

```javascript
function scoreTask(task, result) {
  if (task.asserts.every(a => a(result))) return 1.0;   // 全对
  const done = task.subgoals.filter(g => g.check(result)).length;
  if (done / task.subgoals.length >= 0.5) return done / task.subgoals.length;
  if (result.refusedProperly) return 0.5;               // 有效拒答
  return 0;
}
// rubric 主观任务：LLM-judge 按 {结构,事实,文风}
// 打分 + 5% 人工校准 judge 与人的一致率。
```
