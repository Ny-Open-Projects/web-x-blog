## AGT-621：Agent 观测本身很贵（全量 trace + L3 数据 + judge 评分），如何控制观测成本

**答**：
- 分层采样 + 数据生命周期：trace 采样率按错误/高成本/灰度分级；L3 大对象放对象存储生命周期自动降冷（7天热→90天冷→删）；摘要常驻、全量按需。
- judge 评分按需触发：只在异常时段/新版本/抽样触发，常态不跑；评分结果缓存（同 trace 不重复评）。
- 观测预算看板：观测成本（存储+judge 调用）与业务成本一起出账，观测开销超过业务成本 5% 时自动收紧采样。

```javascript
const OBS_BUDGET = { maxShareOfBusiness: 0.05 };
function samplingRate(turn) {
  if (turn.errCode || turn.cost > P95_COST) return 1.0;   // 异常全采
  if (turn.expGroup) return 1.0;                          // 灰度全采
  return dynamicSample();                                 // 常态动态
}
function obsCostGuard(month) {
  if (month.obs / month.business > OBS_BUDGET.maxShareOfBusiness)
    tightenSampling({ L3TTL: 3, judgeSample: 0.01 });     // 自动收紧
}
```
