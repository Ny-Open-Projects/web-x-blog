## AGT-660：Agent 的安全评测集应该覆盖哪些攻击面，怎么持续更新

**答**：
- 攻击面分类建集：提示注入（直接/间接——藏在工具结果里）、越狱（角色扮演/编码绕过）、数据外泄（诱导输出系统提示/内部数据）、危险工具滥用（诱导调用删库类工具）、多步攻击（先建立信任再利用）。
- 持续更新机制：红队定期出题（新攻击手法→新用例）、外部漏洞情报转化、线上拦截样本回流（被拦截的真实攻击是最佳用例）。
- 安全评测独立跑独立门槛：不与功能分数混算，安全项一票否决（不允许"平均分很好但注入能穿透"）。

```javascript
const ATTACK_TAXONOMY = ['direct_inject', 'indirect_inject',
  'jailbreak', 'exfiltration', 'tool_abuse', 'multi_step'];
function securityGate(run) {
  const leaks = run.filter(r => r.attack &&
    r.verdict !== 'blocked');
  if (leaks.length) return { pass: false,         // 一票否决
    leaks: leaks.map(l => ({ tax: l.taxonomy, case: l.id })) };
  return { pass: true, blockRate: 1 - leaks.length / run.length };
}
```
