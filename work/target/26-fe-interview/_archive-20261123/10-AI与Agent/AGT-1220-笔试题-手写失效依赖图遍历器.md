## 1220：笔试手写：实现失效事件的依赖图遍历（DAG 单向传播）

**需求**：实现 invalidateEvent(graph, event, qc)：graph = { [event]: [pattern...] } 且 pattern 可为「派生事件」（事件名——链式触发）；qc.invalidate(pattern) 为注入的失效函数（记录调用）。要求：DAG 遍历（环检测抛错防死循环）、已处理事件跳过（防重复失效）。返回失效 pattern 调用列表。

```js
function invalidateEvent(graph, event, qc, visited = new Set(), log = []) {
  if (visited.has(event)) return log;          // 已处理跳过（环/重复防护）
  visited.add(event);
  for (const node of graph[event] || []) {
    if (node.startsWith('on:')) {              // 派生事件：链式触发
      invalidateEvent(graph, node.slice(3), qc, visited, log);
    } else {
      qc.invalidate(node);
      log.push(node);
    }
  }
  return log;
}
// 环检测：入口处用 DFS 预检（或依赖 visited 天然防死循环）
const graph = {
  'order.paid': ['order.detail', 'on:stats.dirty'],
  'stats.dirty': ['stats.daily'],
};
const calls = [];
invalidateEvent(graph, 'order.paid', { invalidate: p => calls.push(p) }, new Set(), calls);
console.log(calls);   // ['order.detail', 'stats.daily']
```

**评分点**：
- 派生事件的链式触发（事件->失效->事件的图遍历）
- visited 双职责：防环死循环 + 防重复失效
- 混合节点（pattern 与派生事件）的分派
- 能讨论：环的静态检测（构建期校验优于运行时防护）、失效链的深度上限
