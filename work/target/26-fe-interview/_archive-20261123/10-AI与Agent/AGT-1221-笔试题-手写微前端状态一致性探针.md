## 1221：笔试手写：实现跨应用同实体数据的一致性探针

**需求**：实现 ConsistencyProbe(getters)：getters 为 { [app]: () => value }[]（各应用对同一实体的读取函数）。check() 并发调用全部 getter，全相等返回 { consistent: true }；否则 { consistent: false, values: { [app]: v }, divergent: 值不同的应用列表 }。支持 JSON 序列化比较（对象值）。

```js
function createConsistencyProbe(getters) {
  return {
    async check() {
      const names = Object.keys(getters);
      const rs = await Promise.all(names.map(a =>
        Promise.resolve(getters[a]()).then(
          v => ({ a, v }), e => ({ a, v: { __error: String(e) } }))));
      const values = Object.fromEntries(rs.map(r => [r.a, r.v]));
      const first = rs[0].v;
      const divergent = rs.filter(r =>
        JSON.stringify(r.v) !== JSON.stringify(first)).map(r => r.a);
      return { consistent: divergent.length === 0, values,
        divergent: divergent.length ? divergent : [] };
    },
  };
}
const probe = createConsistencyProbe({
  A: () => ({ st: 'paid' }), B: () => ({ st: 'paid' }), C: () => ({ st: 'shipping' }),
});
console.log(await probe.check());
// { consistent: false, divergent: ['C'], values: {...} }
```

**评分点**：
- 并发采样（同一时刻快照——串行采样会误判）
- JSON 序列化比较（对象值的深相等）
- divergent 列表（责任矩阵归因入口）
- getter 错误捕获（__error 包装——读崩也是一种「不一致」）
- 能讨论：采样时刻的对齐（理想是时钟同步）、探针的线上巡检调度与告警
