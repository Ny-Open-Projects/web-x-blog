## AGT-822：多区域租户的数据驻留要求（欧盟数据不出欧盟），平台怎么满足

**答**：
- 区域化部署：数据平面按区域独立（存储/检索/记忆全区域隔离），控制平面可全局（路由到对应区域）；租户创建时绑定 home region，数据永不跨区（除非显式授权）。
- 模型调用的数据流审查：模型端点也在区域内（区域化模型供应商清单），跨境调用（如仅美国有某模型）需要租户显式同意+脱敏。
- 可证明性：数据地图（哪些数据在哪个区域/哪些系统）自动生成，支撑合规审计；区域故障切换预案要预先报备（切换会涉及数据位置变化）。

```javascript
function resolveRegion(tenant, op) {
  const home = tenant.homeRegion;                 // 数据不出区
  if (op.dataClassification === 'restricted'
    && op.modelRegion !== home)
    return op.crossBorderConsent ? call(op) : reject(op,
      '受限数据不可跨境处理');
  return call({ ...op, region: home });
}
```
