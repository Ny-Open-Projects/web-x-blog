## 1253：笔试手写：实现 数值断言幻觉校验器

**需求**：实现 checkNumbers(answer, sources)：answer 中抽取所有数字（含百分号、金额单位），在 sources 文本中逐一查找；数字出现即通过；「数值 + 单位」组合在所有来源中都不存在时标记为幻觉嫌疑。返回 { checked, suspects }，并输出幻觉率。

```js
function checkNumbers(answer, sources) {
  const srcText = sources.join('\n');
  const nums = [...answer.matchAll(/\d+(?:\.\d+)?\s*(?:%|万元?|亿|条|人|次)?/g)]
    .map(m => m[0].replace(/\s+/g, ''));
  const suspects = [];
  for (const n of nums) {
    const bare = n.replace(/[^\d.]/g, '');
    const unit = n.replace(/[\d.\s]/g, '');
    const hit = srcText.includes(n)
      || (unit && srcText.includes(bare) && srcText.includes(unit) // 数值与单位都在但写法不同
          && new RegExp(bare.replace('.', '\\.') + '\\s*' + unit).test(srcText));
    if (!hit) suspects.push(n);
  }
  return {
    checked: nums.length,
    suspects: [...new Set(suspects)],
    rate: nums.length ? +(suspects.length / nums.length).toFixed(3) : 0,
  };
}
```

**评分点**：
- 数字+单位的组合匹配（裸数字匹配误报率高）
- 正则提取覆盖 %/万/亿 等单位
- 幻觉率定义明确、分母为 0 兜底
- 能讨论：数值改写（如 1.2万 vs 12000）需归一化后再比，是进阶要求
