## AGT-581：工具结果太长（10MB 日志），如何截断/摘要后进入模型与展示

**答**：
- 双层截断：给模型的（服务端截断到预算内，保留头尾+标记省略行数）与给 UI 的（前端虚拟滚动展示全量或分页）；两者独立，UI 不必与模型看到的一致，但要标注"模型看到的是截断版"。
- 截断策略带语义：日志类保头尾（错误常在尾）、表格类保前 N 行+行数声明、代码类保结构（函数签名+省略体），不是无脑 slice。
- 被省略部分给"展开查看完整结果"（存对象存储，按需拉）。

```javascript
function truncateForModel(result, budget) {
  if (result.type === 'log') return headTail(result.text, budget);   // 头尾保留
  if (result.type === 'table') return { rows: result.rows.slice(0, 20),
    truncated: result.rows.length - 20, note: `共${result.rows.length}行` };
  if (result.type === 'code') return skeleton(result.text, budget);  // 签名+省略
  return result.text.slice(0, budget);
}
```
