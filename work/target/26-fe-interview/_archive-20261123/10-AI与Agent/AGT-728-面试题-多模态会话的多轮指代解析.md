## AGT-728：用户第二轮说上面那个图放大看、这张表第二列，多模态上下文的指代解析怎么做

**答**：
- 会话内维护「多模态对象表」：每个出现的图/表/视频段注册 id+简要描述，指代解析（"那个图"）基于最近提及优先+描述匹配，解析结果显式化（回答引用时确认"您指的是第 3 步的架构图"）。
- 指代操作映射：放大=给高清原图+局部裁剪、第二列=表格列投影——把指代转成对结构化数据的操作而非重新理解原图。
- 失败兜底：指代不明（两张图都可能）时列出候选让用户点选，不猜。

```javascript
function resolveReference(utterance, session) {
  const candidates = session.objects.filter(o =>
    mentionMatch(utterance, o.desc));
  if (candidates.length === 1) return candidates[0];
  if (candidates.length === 0 && session.objects.length === 1)
    return session.objects[0];                     // 仅一个对象可推断
  return ui.pickObject(session.objects);           // 多候选让用户点选
}
function applyOp(obj, op) {
  if (op.type === 'zoom') return viewer(obj.asset, { region: op.region ?? 'full', hi: true });
  if (op.type === 'column') return tableProject(obj.asset, op.col); // 列投影
}
```
