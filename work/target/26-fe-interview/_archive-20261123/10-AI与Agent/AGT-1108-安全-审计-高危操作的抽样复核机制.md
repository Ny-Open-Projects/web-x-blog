## 1108：高危操作全人工复核不现实，抽样复核怎么设计

**答**：
- 抽样策略三层：全审层（不可逆 + 高危动作 100% 事后复核，虽然自动审批但事后全查）、抽审层（中危按比例 + 风险加权抽——异常特征优先抽）、专项层（新上线 Agent 前两周全审，稳定后降级到抽审）。
- 「事后复核」与「事前审批」的区别：事前审批拖慢自动化，事后复核保速度且能发现系统性问题（某类操作通过率高但事后发现问题 = 规则漏了）。
- 复核结果回流：复核发现的漏网样本自动转红队用例 + 修规则，复核系统的召回率自身也要被度量。
- 追问钩子：抽样怎么保证「抽到点子上」？——按风险特征加权抽（夜间操作、非常用工具组合、接近权限边界），均匀抽样会浪费在无聊样本上。

```ts
function sampleForReview(op) {
  if (op.risk === 3 || op.irreversible) return 'full';       // 全审层
  if (op.agentAge < 14) return 'full';                        // 新 Agent 全审
  const w = riskWeight(op);                                   // 特征加权
  return rand() < w ? 'sample' : 'skip';
}
review.on('miss', m => { rules.patch(m); redteam.add(m); }); // 漏网回流
```
