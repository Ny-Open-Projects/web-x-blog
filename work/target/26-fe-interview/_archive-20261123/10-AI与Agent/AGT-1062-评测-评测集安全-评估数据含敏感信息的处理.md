## 1062：评估集里有真实用户数据，怎么处理

**答**：
- 评估集也要过合规：真实样本入库前脱敏（PII 假名化，映射密钥独立保存）、访问权限收敛（评估集与生产数据同等级保护）、留存期限与删除机制。
- 脱敏的度：脱到「评测仍有意义」——查询意图、领域术语必须保留，只替换可识别字段（姓名→人名 A、手机号→假号）；脱过头评测就失真。
- 评估结果的衍生风险：评测报告/badcase 截图会被转发，报告里的样本要默认脱敏，badcase 浏览器按权限查看原文。
- 追问钩子：能不能干脆「合成」评估集不用真实数据？——合成集分布偏（见偏差审计卡），正确姿势是「合成打底 + 真实脱敏样本校准分布」。

```ts
async function sanitizeCase(c) {
  const { safe, map } = await pseudonymize(c.query + c.goldAnswer,
    { keep: ['术语', '产品名'], mask: ['姓名', '手机号', '邮箱'] });
  await keyVault.store(c.id, encrypt(map));       // 映射加密独立存
  return { ...c, query: apply(safe, c.query), goldAnswer: apply(safe, c.goldAnswer),
    sanitized: true };
}
```
