## AGT-606：用户抱怨 AI 回答慢，如何把一轮 30s 的延迟分解归因

**答**：
- 一轮延迟 = 排队（网关/配额）+ 前处理（RAG 检索/注入拼装）+ 模型首 token（TTFT）+ 生成（token 数 ÷ 速率）+ 后处理（审核/工具执行）。每段一个 span 属性，分位数（P50/P95）分别看。
- 常见坑：平均延迟被长生成拉高（长答案本来就慢），归因要按「标准化 token 生成」对比（TTFT 与 tokens/s 分开看），否则优化方向会错。
- 慢轮次 topN 聚类归因：按最慢 span 聚类（检索慢/工具慢/模型慢），给出可行动的结论而不是只有大盘曲线。

```javascript
function breakdown(turn) {
  const seg = ['queue', 'preprocess', 'ttft', 'generate', 'postprocess'];
  return Object.fromEntries(seg.map(s =>
    [s, turn.spans.find(x => x.name === s)?.duration]));
}
// 归因报告：P95 最慢段聚类
function latencyReport(traces) {
  const worst = traces.map(t => breakdown(t))
    .map(b => ({ ...b, bottleneck: maxKey(b) }));
  return groupCount(worst, 'bottleneck');   // { retrieve: 41%, generate: 33%, ... }
}
```
