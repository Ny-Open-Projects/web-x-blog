## AGT-225：什么是大海捞针测试——长上下文的使用有哪些注意事项？

**答**:
- 大海捞针（needle-in-a-haystack）：把一句关键信息埋入几十万 token 的无关文本中，测试模型能否找回——结论是各模型"标称窗口"与"有效窗口"差距很大，且中部信息召回最弱（lost in the middle）。
- 实践含义一：位置工程——关键事实放开头或结尾；多文档对比任务按"每文档内部结构一致"排布，避免模型在混乱结构中丢失对应关系。
- 实践含义二：任务拆分优先于堆上下文——100k 上下文里找 10 处信息，不如分成 10 个子任务各查各的（分治比一次长阅读召回率高且稳定）。
- 验证手段：自建领域捞针测试（把业务关键信息埋进真实长文档跑召回率），上线前量化"有效窗口"，不迷信厂商标称值。

```javascript
// 领域捞针测试
async function needleTest(needles, haystack) {
  let hit = 0, pos = [];
  for (const n of needles) {
    const at = Math.floor(Math.random() * 100);
    const doc = insertAt(haystack, n.text, at);   // 埋针
    const ans = await llm(`${doc}\n\n问题：${n.q}`);
    if (ans.includes(n.answer)) { hit++; pos.push(at); }
  }
  return { recall: hit / needles.length,
    // 按位置分桶看中部衰减
    byPos: bucket(pos, [0, 25, 50, 75, 100]) };
}
```
