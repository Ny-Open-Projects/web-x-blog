## 1212：笔试手写：实现 LLM 裁判与人工标注的一致率与分歧聚类

**需求**：实现 agreement(pairs)：pairs 为 { intent, llm: 'pass'|'fail', human: 'pass'|'fail' }[]。输出 { overall, byIntent: { [intent]: { rate, n } } }（一致率 3 位，一致 = verdict 相同），并返回 disputes（分歧样本索引数组）；分歧率 > 0.3 的 intent 列入 needsCalibration。

```js
function agreement(pairs) {
  const byIntent = {}, disputes = [];
  let match = 0;
  pairs.forEach((p, i) => {
    const same = p.llm === p.human;
    if (same) match++; else disputes.push(i);
    const g = (byIntent[p.intent] ??= { match: 0, n: 0 });
    g.n++; if (same) g.match++;
  });
  const rate = (m, n) => n ? +(m / n).toFixed(3) : null;
  const bi = {};
  for (const [k, v] of Object.entries(byIntent)) {
    bi[k] = { rate: rate(v.match, v.n), n: v.n };
  }
  const needsCalibration = Object.entries(bi)
    .filter(([, v]) => v.rate !== null && v.rate < 0.7)
    .map(([k]) => k);
  return { overall: rate(match, pairs.length), byIntent: bi,
    disputes, needsCalibration };
}
const pairs = [
  { intent: 'qa', llm: 'pass', human: 'pass' },
  { intent: 'qa', llm: 'pass', human: 'fail' },
  { intent: 'code', llm: 'fail', human: 'fail' },
  { intent: 'code', llm: 'fail', human: 'fail' },
];
console.log(agreement(pairs));
// overall 0.75；qa 0.5 -> needsCalibration ['qa']；disputes [1]
```

**评分点**：
- overall 与分 intent 一致率（分桶暴露弱项）
- disputes 带索引（人工仲裁队列可直接消费）
- needsCalibration 阈值 0.7 语义说明
- 空分组/除零保护
- 能讨论：一致率到裁判 prompt 修订的闭环、分歧样本进入锚点样例库
