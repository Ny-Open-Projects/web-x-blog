## AGT-703：用 vision 模型给图片生成描述做索引，如何保证描述质量与图文一致

**答**：
- 描述生成带结构模板：强制输出「图片类型 + 关键实体 + 数值/文字内容（OCR）+ 与上下文的关系」，而不是自由发挥——自由 caption 常漏掉图中关键数字。
- 图文一致性校验：生成的描述与图片本身做一次「反验」（让 vision 模型判断"该描述是否符合图片"），不一致的进人工队列；OCR 数字类内容与描述交叉核对。
- 描述版本化：vision 模型升级后旧描述可批量重生成，但按文档版本灰度（描述变化会影响召回，需评测护航）。

```javascript
const DESC_PROMPT = `描述这张图片，严格包含：1)图片类型 2)关键实体
3)图中所有文字与数值（逐字） 4)它在文档中的可能作用。不要推测图中没有的信息。`;
async function indexImage(img, ctx) {
  const desc = await vision(img, DESC_PROMPT);
  const ocr = await ocr(img);
  const check = await vision([img, desc],
    '该描述是否准确概括图片？逐项核对文字与数值。');
  if (check.verdict !== 'consistent')
    return queueHumanReview({ img, desc, check });  // 不一致进人工
  return { desc: desc + '\nOCR: ' + ocr.text, ctx, imgRef: img.id };
}
```
