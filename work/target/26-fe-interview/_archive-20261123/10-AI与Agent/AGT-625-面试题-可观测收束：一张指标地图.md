## AGT-625：把 Agent 可观测指标收敛成一张地图（四层：健康/成本/质量/业务），层间如何勾稽

**答**：
- 四层地图：健康层（错误率/延迟/依赖状态）、成本层（tokens/费用/缓存收益）、质量层（代理指标/judge 分/负反馈）、业务层（完成率/采纳率/留存）。自上而下是用户感受，自下而上是技术原因。
- 勾稽关系是地图的灵魂："完成率跌" → 拆健康层哪类错误涨 → 归因到依赖/模型/提示词 → 对应质量层指标佐证。没有勾稽的大盘只是数字墙。
- 每指标三要素：口径定义、采集位置（前端/网关/模型响应）、告警归属（谁负责），缺失任一项的指标不许上大盘。

```javascript
const METRIC_MAP = {
  health:  ['errRate', 'p95Latency', 'depStatus'],
  cost:    ['tokensPerTask', 'usdPerTask', 'cacheSaved'],
  quality: ['citeHit', 'judgeScore', 'dislikeRate'],
  business:['taskDoneRate', 'adoption', 'retention'],
};
// 勾稽：业务层异常自动下钻
drill('taskDoneRate↓', (b) => {
  const err = topRising(METRIC_MAP.health, b.window);   // 健康层哪个涨了
  return correlate(err, METRIC_MAP.quality);            // 质量层佐证
});
```
