## AGT-814：平台 API/Agent 运行时升级，如何对租户做兼容性承诺（版本策略/废弃流程）

**答**：
- 兼容承诺分级：API（semver，破坏性变更走新版本路径，旧版保 12 个月）、事件格式（只增不删不改，新字段可忽略）、运行时行为（提示词模板默认版本锁定，升级需租户显式 opt-in）。
- 废弃流程四步：公告（90 天）→ 废弃标记（响应头/文档）→ 流量监控（旧版本用量归零）→ 下线；每步有租户通知与迁移指南。
- 兼容性测试：平台发布前用「租户契约测试集」（租户常用的调用模式录制回放）验证不破坏。

```javascript
const COMPAT_POLICY = {
  api: { semver: true, deprecateWindow: '12mo' },
  events: 'additive-only',
  runtime: { promptDefault: 'locked', optIn: true },
};
function retirementCheck(v) {
  const usage = metrics.versionUsage(v);
  return usage < 0.001 && daysSince(announced(v)) > 90
    && notices(v).every(sent)                      // 公告+90天+通知齐
    ? retire(v) : extend(v);
}
```
