## 1061：用户点踩数据噪声大，怎么提高负反馈的信噪比

**答**：
- 噪声来源：用户误触、期待错位（问的问题本来知识库就没有）、情绪化反馈；信噪比提升三招——反馈时机（答案下方即时反馈比问卷转化率高且语境完整）、追问一步（点踩后弹「原因分类：答错/不全/跑题/其他」，强制结构化）、轻量验证（重复提问的用户是高置信负样本）。
- 信噪比度量：负反馈与「裁判打分」的一致率——一致率低说明采集设计有问题，先改采集再谈分析。
- 分层消费：高置信负反馈（带原因 + 复问）直接进 badcase 队列；低置信的只做趋势统计不进个案处理。
- 追问钩子：为什么「原因分类」是关键设计？——自由文本负反馈的分析成本极高且关键词不齐，结构化分类让「答错 vs 不全」的改进方向分开统计，直接对应不同团队。

```ts
function feedbackQuality(fb, judgeScores) {
  const matched = fb.filter(f => sign(f.negative) === sign(judgeScores[f.id] < 0.6)).length;
  return { agreement: matched / (fb.length || 1),   // 与裁判一致率
    action: fb.filter(f => f.reason && f.reasked) }; // 高置信子集
}
```
