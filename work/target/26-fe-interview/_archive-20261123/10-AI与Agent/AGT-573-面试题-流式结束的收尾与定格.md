## AGT-573：流式完成瞬间的收尾处理（光标移除/重渲染/按钮浮现）如何避免视觉跳变

**答**：
- 完成瞬间做三件事但要错峰：光标淡出（CSS transition 200ms）→ 二次增强（高亮/公式终渲染）错峰到 idle（requestIdleCallback）→ 操作按钮（复制/反馈）淡入。
- 完成后全文重渲染要避免：流式期间的渐进 DOM 与最终渲染结果应一致（同一渲染器），只在必要时（安全重渲染/公式）替换，替换要 transition。
- 定格测量：完成时间与内容哈希入库（对账用），UI 上"用时 Xs · N tokens"小字收尾给用户确定性。

```javascript
stream.on('done', async (final) => {
  typewriter.flush();
  cursorEl.classList.add('fade-out');            // 1. 光标淡出
  await transitionDone(cursorEl);
  requestIdleCallback(() => enhance(final));     // 2. 空闲时二次增强
  setTimeout(() => actionsFadeIn(final.id), 300); // 3. 按钮错峰浮现
  track('turn_done', { ms: final.elapsedMs,
    hash: hash(final.content) });                // 定格测量
});
```
