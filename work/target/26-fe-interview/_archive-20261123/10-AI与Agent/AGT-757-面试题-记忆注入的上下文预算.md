## AGT-757：记忆内容与检索内容都在抢上下文预算，注入策略怎么设计

**答**：
- 预算分区固定比例+动态借调：系统提示 10%、记忆 15%、RAG 40%、对话历史 30%、余量 5%；当某区不满可借调（无 RAG 命中时记忆区扩大）。
- 注入形式压缩：记忆不注入原文而是注入「蒸馏条目」（一行一条，带来源标注），比塞对话片段便宜一个量级。
- 注入前去重：记忆与 RAG 命中内容重复时只保留一处（记忆是事实，RAG 是出处），重复注入浪费预算还让模型困惑。

```javascript
function assembleContext(q, { rag, memories, history }) {
  const zones = { system: 0.1, memory: 0.15, rag: 0.4, history: 0.3, buffer: 0.05 };
  const mem = dedupe(memories, rag)               // 记忆与RAG去重
    .map(m => `- ${m.statement}（来源：${m.source}）`); // 蒸馏条目
  return fillZones({ system, mem, rag, history }, zones, { borrow: true });
}
```
