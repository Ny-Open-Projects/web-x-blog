## AGT-569：Agent 需要用户澄清时（信息不足），澄清问题如何卡片化呈现而不是自由文本一问一答

**答**：
- 澄清做成「选项卡片」：Agent 输出 clarifying schema（问题 + 候选选项 + 默认值 + 可跳过），前端渲染成单选/多选卡，用户点选即回传结构化答案——比打字快且约束了解析难度。
- 卡片要支持"都不对，我自己说"逃生口（文本输入兜底），避免选项覆盖不全造成死循环。
- 澄清轮不计时器不自动提交（与表单任务不同）：用户可能走开，回来还能答。

```javascript
function ClarifyCard({ schema, onAnswer }) {
  const [sel, setSel] = useState(schema.multi ? [] : null);
  return <Card>
    <Question q={schema.question} why={schema.why} />
    {schema.options.map(o => <Option key={o.value} {...o}
      selected={sel.includes(o.value)}
      onClick={() => toggle(sel, setSel, o.value, schema.multi)} />)}
    <Actions>
      <button disabled={!isValid(sel, schema)}
        onClick={() => onAnswer({ type: 'choice', value: sel })}>确认</button>
      <TextFallback onSubmit={v => onAnswer({ type: 'text', value: v })} />
      {schema.skippable && <button onClick={() => onAnswer({ type: 'skip' })}>
        跳过，用默认值 {schema.default}</button>}
    </Actions>
  </Card>;
}
```
