## AGT-767：画像批量更新出错（蒸馏 bug 把全用户画像写错），如何回滚

**答**：
- 记忆写入带批次号：每次蒸馏/画像更新是一个批次，出问题按批次回滚（恢复到批次前快照），而不是逐条修。
- 写前影子验证：大批次更新先影子跑（写入影子库+抽样对比质量指标），达标才切换——批量变更当发布对待。
- 变更可观测：画像字段变更率监控（一次蒸馏导致 50% 用户某字段变化=异常），异常自动暂停批次。

```javascript
async function distillBatch(userIds) {
  const batch = createBatch();
  await shadow.write(batch, await distillAll(userIds));  // 影子库
  const check = await sampleQuality(batch);
  if (check.fieldChangeRate > 0.3) {
    await shadow.discard(batch);
    alert({ type: 'memory_batch_anomaly', batch: batch.id });
    return;
  }
  await shadow.promote(batch);                    // 达标切换
}
async function rollbackBatch(batchId) {
  await memory.restoreSnapshot(batchId.prev);     // 按批次回滚
}
```
