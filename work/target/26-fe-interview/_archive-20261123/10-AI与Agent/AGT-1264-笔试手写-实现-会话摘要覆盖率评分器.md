## 1264：笔试手写：实现 会话摘要覆盖率评分器

**需求**：实现 summaryCoverage(summary, origin)：origin 为原始对话文本。抽取双方的 2-gram 关键词集合（去停用词简化为长度 >= 2 的中文词片），计算摘要对原文的覆盖率 = 摘要 grams 能在原文 grams 中命中的比例；列出未覆盖的高频原文词（疑似漏关键点，按原词频降序取前 5）。返回 { coverage, missing }。

```js
function summaryCoverage(summary, origin) {
  const tokenize = t => (t.match(/[\u4e00-\u9fa5]{2,4}|[a-zA-Z]+/g) || []);
  const freq = {};
  for (const w of tokenize(origin)) if (w.length >= 2) freq[w] = (freq[w] || 0) + 1;
  const sumSet = new Set(tokenize(summary));
  const originWords = Object.keys(freq);
  const covered = originWords.filter(w => sumSet.has(w));
  const missing = originWords.filter(w => !sumSet.has(w))
    .sort((a, b) => freq[b] - freq[a]).slice(0, 5);
  return {
    coverage: originWords.length ? +(covered.length / originWords.length).toFixed(3) : 1,
    missing,
  };
}
```

**评分点**：
- 分词简化为正则词片（真实场景用分词器，思路一致）
- 覆盖率定义：词级命中比例
- missing 按原词频排序 = 疑似漏掉的重点
- 能讨论：覆盖率是摘要质量的下界信号（AGT-781），与 LLM judge 互补
