## AGT-676：一次横评（5 个候选模型跑同一评测集），如何组织才能出可信结论

**答**：
- 同条件约束：同一用例、同一温度策略、同一天内跑完（防供应商更新）、同一 judge 版本；模型差异只有身份这一个变量。
- 分维度报告：总分数之外按能力维度（工具调用/长文本/格式遵循/中文）出雷达图——总榜第五的模型可能在你的核心维度第一。
- 成本维度并报：横评必须带「每质量点成本」（分数/每千次成本），没有成本的横评会误导选型。

```javascript
async function horizontalEval(cases, models) {
  const day = today();
  const runs = await pMap(models, m => runEval(cases, {
    model: m, temperature: TEMPER, judgeVer: JUDGE_VER, sameDay: day }));
  return runs.map(r => ({
    model: r.model, total: r.score,
    radar: byCapability(r),                        // 分维度
    costPerQuality: r.costPer1k / r.score,         // 每质量点成本
  }));
}
```
