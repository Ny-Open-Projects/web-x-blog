## AGT-290：Agent 安全的纵深防御体系怎么收束？

**答**:
- 六道防线全景：输入侧（注入检测/内容审查，AGT-281/282/288）、权限侧（最小权限/能力分级/动态授权，AGT-283）、执行侧（沙箱/白名单/确认流，AGT-284/286）、数据侧（DLP/脱敏/ACL，AGT-285）、知识侧（投毒防御/来源信任级，AGT-287）、运营侧（审计/红队/应急，AGT-289/299）——威胁从哪来，防线就在哪。
- 设计哲学：假设模型会被骗——所有防御不能依赖"模型不上当"，而要依赖"即使上当也做不成事"（权限收窄/沙箱隔离/出站白名单/人审兜底）——把安全建立在架构而非模型自觉上。
- 风险分级投入：读数据/生成文本低防御，写数据中防御，不可逆动作/资金/数据出站强防御——安全成本与影响半径成正比，避免无差别加锁拖垮体验。
- 持续对抗：注入与攻击手法在演化，安全是持续过程——红队常态化、安全回归集滚动更新、事件复盘进防御清单——安全水位 = 最近的对抗记录，不是一次性的清单。

```text
Agent 安全纵深：
输入：注入检测 / 内容审查 / 多轮锚定
权限：最小权限 / 能力分级 / 只降不升
执行：沙箱 / 白名单 / 分级确认流
数据：DLP / 脱敏代理 / 读写两端 ACL
知识：来源信任级 / 交叉验证 / 举报运营
运营：全链审计 / 红队常态化 / 应急演练
哲学：假设模型会被骗，
  安全建立在架构而非模型自觉上。
```
