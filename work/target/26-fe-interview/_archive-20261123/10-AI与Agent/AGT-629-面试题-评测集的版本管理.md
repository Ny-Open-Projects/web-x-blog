## AGT-629：评测集本身会迭代（加用例/删失效用例），如何管理评测集版本与结果可比性

**答**：
- 评测集当代码管：git 化（用例文件+评审+变更说明），每版语义化版本；跑分必带数据集版本+评分器版本+模型版本，三元组缺一不可比。
- 可比性策略：新增用例只追加新版本（旧分数不重算）；关键版本变更时用「锚定用例子集」（稳定不变的 50 条）重跑新旧评分器，校准分数漂移。
- 失效用例退役要留档（为什么失效：知识库变更/产品下线），防止评测集悄悄"退化成全对"。

```javascript
const evalVer = { dataset: 'v2.3.1', judge: 'gpt-judge@3', model: 'gpt-x' };
function anchorCalibration(newJudge, oldJudge) {
  const anchors = dataset.get('anchor-50');        // 稳定锚定子集
  const a = runEval(anchors, { judge: oldJudge });
  const b = runEval(anchors, { judge: newJudge });
  return { drift: b.score - a.score,               // 校准漂移
    note: drift > 2 ? '需重算历史分数' : '可直接对比' };
}
```
