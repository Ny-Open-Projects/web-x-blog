## AGT-624：Agent 可观测从零建设，先做什么后做什么（务实路线）

**答**：
- 第一阶段（有 trace 才能排查）：统一 traceId 贯穿前后端 + 每轮 LLM/工具 span + usage/cost 记录。没有这个，一切争论都是盲人摸象。
- 第二阶段（有数才能决策）：错误率/延迟/成本大盘 + 失败聚类 + 负反馈采集回流；此时可以回答"该优化哪"。
- 第三阶段（有闭环才能迭代）：质量代理指标告警、灰度对比看板、回流评测集、回放调试器。顺序不能倒：先上回放再补 trace 是本末倒置。

```javascript
const ROADMAP = {
  p1: ['traceId贯穿', 'llm/tool span', 'usage计量'],      // 排查能力
  p2: ['大盘三件套', '失败聚类', '负反馈回流'],            // 决策能力
  p3: ['质量告警', '灰度看板', '回流评测集', '回放调试'],   // 迭代闭环
};
function auditMaturity() {
  return Object.entries(ROADMAP).map(([p, items]) =>
    ({ phase: p, done: items.filter(has(items)).length, total: items.length }));
}
```
