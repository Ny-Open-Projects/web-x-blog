## AGT-820：平台统一错误码体系（租户/开发者都能看懂），怎么设计

**答**：
- 三段式错误码：域.类别.序号（model.quota.exceeded / tool.auth.denied / runtime.timeout），每个码带：给开发者的技术说明+给终端用户的文案+建议动作+是否可重试。错误码注册表统一管理（新增需评审，防重复语义）。
- 错误响应标准化：{ code, message(用户), detail(开发者), retryable, retryAfter, traceId }——一码多受众。
- 稳定性承诺：错误码只增不改语义（改语义=破坏下游判断），废弃走 deprecated 标记。

```javascript
const ERROR_REGISTRY = {
  'model.quota.exceeded': {
    user: '本月用量已满，请联系管理员或升级套餐',
    dev: 'tenant monthly token quota exceeded',
    retryable: false, action: 'upgrade' },
  'tool.auth.denied': {
    user: '暂无权限使用该功能',
    dev: 'rbac denied for tool',
    retryable: false, action: 'request-permission' },
};
function toResponse(code, ctx) {
  const e = ERROR_REGISTRY[code];
  return { code, message: e.user, detail: e.dev,
    retryable: e.retryable, retryAfter: ctx.retryAfter,
    traceId: ctx.traceId };
}
```
