## AGT-819：租户要测试环境与生产环境分离（Agent 配置/数据/配额独立），平台怎么支持

**答**：
- 环境即配置域：每租户默认 prod+test 两环境，Agent/工具/配额/知识库按环境隔离；测试环境强制用降配模型（省钱）与脱敏数据源。
- 环境晋升：test 验证过的 Agent 版本一键晋升 prod（配置 diff 预览——哪些工具/提示词/参数会变），晋升带自动评测门禁。
- 防呆：环境标识全程透传（trace/日志/UI 徽标），测试环境的 Agent 调不到生产数据源（数据源按环境绑定）。

```javascript
const ENV = {
  test: { modelTier: 'cheap', dataSources: 'masked', quota: 'low' },
  prod: { modelTier: 'per-contract', dataSources: 'real' },
};
async function promote(agentVer, from = 'test') {
  const diff = configDiff(agentVer.test, agentVer.prod);
  const ok = await evalGate(agentVer, 'prod');     // 晋升门禁
  if (!ok) return block(diff.failures);
  return deploy(agentVer, 'prod', { diff, by: currentUser });
}
```
