## 1270：笔试手写：实现 会话记忆检索打分器

**需求**：实现 scoreMemories(memories, query)：memories 为 { id, text, sim, ts, useCount }[]（sim 为向量相似度 0~1，ts 毫秒，useCount 使用次数）。综合分 = 0.5·sim + 0.3·新近度 + 0.2·使用率；新近度 = max(0, 1 - 天龄/30)；使用率 = min(1, useCount/10)。返回 Top-3 [{ id, score }]。

```js
function scoreMemories(memories, query, now = Date.now()) {
  const DAY = 86400000;
  return memories.map(m => {
    const recency = Math.max(0, 1 - (now - m.ts) / (30 * DAY));
    const usage = Math.min(1, m.useCount / 10);
    const score = 0.5 * m.sim + 0.3 * recency + 0.2 * usage;
    return { id: m.id, score: +score.toFixed(4), breakdown: { sim: m.sim, recency, usage } };
  }).sort((a, b) => b.score - a.score).slice(0, 3);
}
```

**评分点**：
- 三维加权：相关性主导、新近与使用率辅助（权重可配置）
- 新近度线性衰减带 0 下限
- breakdown 输出便于解释（可解释性意识）
- 能讨论：使用率的自我强化偏置（常用更常用）与时效惩罚的平衡
