## 1256：笔试手写：实现 评测门禁判定器

**需求**：实现 evalGate(results, rules)：results 为 { metric, score }[]，rules 为 { metric, min, weight, blocking: bool }[]。规则齐套校验（results 缺指标 = 0 分）；blocking 指标任一不达标 → verdict 'block'；否则加权总分 >= 80 → 'pass'，>= 70 → 'warn'，否则 'block'。返回 { verdict, total, failed }。

```js
function evalGate(results, rules) {
  const scoreOf = Object.fromEntries(results.map(r => [r.metric, r.score]));
  const failed = [];
  let total = 0, wSum = 0;
  for (const r of rules) {
    const s = scoreOf[r.metric] ?? 0; // 缺指标按 0 分
    if (s < r.min) failed.push({ metric: r.metric, score: s, min: r.min, blocking: r.blocking });
    total += s * r.weight; wSum += r.weight;
  }
  const totalNorm = wSum ? +(total / wSum).toFixed(2) : 0;
  const blockHard = failed.some(f => f.blocking);
  const verdict = blockHard ? 'block'
    : totalNorm >= 80 ? 'pass'
    : totalNorm >= 70 ? 'warn' : 'block';
  return { verdict, total: totalNorm, failed };
}
```

**评分点**：
- 缺指标按 0 分而非跳过（防漏报）
- blocking 一票否决优先于加权总分
- 加权分归一化（权重和不为 1 也正确）
- 能讨论：门禁接入 CI 与「warn 不阻断」的灰度语义
