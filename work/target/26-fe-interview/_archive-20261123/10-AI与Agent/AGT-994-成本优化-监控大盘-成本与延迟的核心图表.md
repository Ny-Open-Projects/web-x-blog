## 994：Agent 成本/延迟监控大盘放哪几张图

**答**：
- 必备五图：单任务成本分布（直方图，看长尾）、成本瀑布 top10 环节（找最贵）、TTFT 与总时长趋势（分任务类型）、缓存命中率、限流/熔断触发次数。
- 每张图都要「可下钻」：成本分布异常 → 点开看任务 ID → 拉出 trace 归因，大盘的价值是「发现 + 定位入口」而非展示。
- 告警与图联动：P95 延迟超阈值告警附「环比变化 + 疑似环节」，值班同学不用从零排查。
- 追问钩子：大盘谁看？——分层：值班看告警图、负责人看趋势图、老板看单位成本/单位质量的效率比，一张图塞所有受众是反模式。

```ts
const dashboard = [
  { title: 'cost_dist', query: 'histogram(task_cost)', alert: 'p95 > 0.5$' },
  { title: 'cost_waterfall', query: 'topk(sum(cost) by stage, 10)' },
  { title: 'ttft_trend', query: 'quantile(ttft, .95) by task_type', alert: 'p95 > 8s' },
  { title: 'cache_hit', query: 'rate(cache_hit)/rate(cache_req)', alert: '< 0.4' },
  { title: 'breaker_fired', query: 'count(breaker_open)', alert: '> 5/min' },
];
```
