## AGT-615：Agent 依赖十几个外部工具/API，如何观测每个依赖的健康度并联动降级

**答**：
- 依赖看板三指标：成功率、P95 延迟、成本；按依赖方（第三方 API）+ 工具名双维度，区分"依赖方故障"与"我们的调用姿势问题"（参数错误率高）。
- 健康度联动运行时：依赖降级（成功率跌破阈值）自动触发 Agent 的降级策略（换工具/跳过/缓存兜底），观测与控制闭环。
- 依赖变更感知：第三方 API 的响应结构变化（schema 漂移）往往先于报错——对工具结果做 schema 校验，漂移单独告警。

```javascript
function depHealth(dep, window) {
  const ok = window.successRate, p95 = window.latencyP95;
  return {
    ok, p95, argErrRate: window.argErrors / window.calls,
    status: ok < 0.9 ? 'down' : ok < 0.98 ? 'degraded' : 'healthy',
  };
}
watch('tool.search_web', (h) => {
  if (h.status === 'down') runtime.degrade('search_web',
    { to: 'cached_results', notify: 'oncall' });   // 联动降级
});
schemaCheck('tool.crm_query', resultSchema);        // 结构漂移告警
```
