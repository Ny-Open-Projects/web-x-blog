## 996：temperature、top_p、max_tokens 这些参数怎么影响延迟

**答**：
- max_tokens 直接决定上限：输出长度是延迟最大变量（每 token 固定时延），压输出长度是压延迟第一杠杆——「简洁指令 + 结构化输出」比调采样参数有效得多。
- 采样参数对延迟几乎无影响（temperature/top_p 不改变计算量），面试常见误区；真正相关的：模型档位（大模型每 token 更慢）、是否流式、并发批大小。
- 结构化输出的代价：某些供应商的 JSON 模式会限制解码（grammar 约束），可能略增单 token 延迟，但避免了「生成到一半 JSON 坏掉重试」——总时长通常反而更优。
- 追问钩子：延迟敏感场景选温度多少？——温度不影响速度，但低温输出更稳定可缓存（相同输入输出更一致），间接提升缓存命中率。

```ts
// 延迟敏感配置模板
const fastCfg = {
  max_tokens: 500,           // 第一杠杆：压输出
  temperature: 0.2,          // 稳定输出利于缓存，不影响速度
  stream: true,              // 感知延迟由首 token 决定
  // 反直觉：top_p / temperature 调到再低也不会更快
};
```
