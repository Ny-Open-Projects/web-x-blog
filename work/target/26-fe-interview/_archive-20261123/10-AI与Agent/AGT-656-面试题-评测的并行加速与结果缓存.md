## AGT-656：几千条用例跑一次几小时，如何加速评测（并行/缓存/增量）

**答**：
- 并行分层：用例间无依赖可全并行（限流约束下打满配额）；有依赖的会话型用例按会话分组串行、组间并行。
- 缓存三层：检索结果缓存（同一用例的 RAG 检索可复用）、LLM 响应缓存（同 prompt+参数+模型版本确定性缓存）、judge 缓存（同输出+同 rubric 不重判）——回归评测里 60~80% 节点可命中。
- 增量评测：提示词改动 diff 后只重跑受影响用例（按功能域映射），配合全量周跑兜底。

```javascript
async function runEvalParallel(cases, { concurrency = 20 } = {}) {
  const cacheKey = (c) => hash([c.prompt, c.params, MODEL_VER]);
  return pMap(cases, async (c) => {
    const cached = await evalCache.get(cacheKey(c));
    if (cached && cached.modelVer === MODEL_VER) return cached;  // 命中跳过
    const r = await evalCase(c);
    evalCache.set(cacheKey(c), { ...r, modelVer: MODEL_VER });
    return r;
  }, { concurrency });                            // 限流内打满
}
```
