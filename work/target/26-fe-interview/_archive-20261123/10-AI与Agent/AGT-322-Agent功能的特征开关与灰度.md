## AGT-322：AI 功能的灰度发布与传统功能有什么不同——开关粒度怎么设计？

**答**:
- 多维灰度维度：按用户（流量比例/白名单）、按场景（先灰低风险意图再灰高危）、按模型档（同功能多模型分别灰）、按参数（prompt 版本/温度/检索配置各自独立灰度）——AI 功能灰度的特殊性在于"同功能内还有模型/prompt 两个变更维度"。
- 开关体系：功能开关（上线/下线）、模型开关（A/B 与回滚）、prompt 开关（版本指针）、护栏开关（成本熔断/安全规则）——分层开关让出问题时能精准定位切哪一层（模型不行切模型，prompt 不行切 prompt）。
- 灰度观测与自动回收：灰度期核心指标护栏（质量/成本/延迟）异常自动缩量或回滚（AGT-256）；灰度配置与实验平台打通（分流一致性——同一用户同一版本）。
- 全量后的长期开关：AI 功能保留"一键降级到非 AI 流程"的总开关（供应商故障/安全事件时快速降级）——AI 功能的降级预案是产品能力的一部分。

```javascript
const flags = await featureFlags.get(user, {
  aiAnswer: { rollout: 0.1 },          // 功能：10%
  model: { variant: 'gpt-x', pct: 0.3 },// 模型灰度
  prompt: { version: 'v23', pct: 1 },   // prompt 指针
  guard: { costCap: 0.5 },              // 护栏参数
});
// 护栏指标异常 → flags.contract('aiAnswer')
// 一键降级：非 AI 流程总开关兜底。
```
