## AGT-733：文本命中与视觉命中的分数如何融合排序（分数不同尺问题）

**答**：
- 分数不可直接比（向量余弦 0.8 与 rerank 分 0.95 不同尺）：统一用 RRF（倒数排名融合）或分数归一化（各路分位归一）再融合，权重按 query 模态路由调整。
- 融合后必须过 rerank（跨模态 rerank 或 vision 辅助判相关性），否则不同路的"伪高分"会霸榜。
- 融合权重可配且可实验：文本/图片/视频各路权重做成实验参数，用评测集调优而非拍脑袋。

```javascript
function rrfFuse(lists, { k = 60 } = {}) {
  const scores = new Map();
  for (const list of lists)
    list.forEach((item, i) => {
      scores.set(item.id, (scores.get(item.id) ?? 0) + 1 / (k + i + 1));
    });
  return [...scores.entries()]
    .sort((a, b) => b[1] - a[1]).map(([id, s]) => ({ id, s }));
}
async function multimodalRank(query, { hasImage }) {
  const fused = rrfFuse([textHits, clipHits, descHits],
    { weights: hasImage ? { text: 1, clip: 1.2, desc: 0.8 } : { text: 1 } });
  return mmRerank(fused, query);                   // 融合后必rerank
}
```
