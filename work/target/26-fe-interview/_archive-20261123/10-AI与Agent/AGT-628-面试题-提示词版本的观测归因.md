## AGT-628：提示词频繁迭代（一天改三次），观测如何支持「按提示词版本」的性能与质量对比

**答**：
- promptVer 是一等公民标签：每轮 LLM span 记录提示词版本 + 实际渲染后 system 的哈希（防"版本号没变但内容变了"）；版本注册表记录变更人/变更说明/生效时间。
- 对比视图：任选两个版本看完成率/采纳率/成本/延迟四维对比 + 样本 diff；发现"v12 成本涨 30%"这类问题要能分钟级定位到版本切换点。
- 没注册的版本（本地改了直接发）要能被哈希发现并告警——观测抓"影子版本"。

```javascript
function attachPromptVer(span, rendered) {
  const h = hash(rendered.system);
  const reg = PROMPT_REGISTRY.get(span.tags['prompt.ver']);
  if (reg?.systemHash !== h)
    alert({ type: 'shadow_prompt', ver: span.tags['prompt.ver'], hash: h });
  span.tags['prompt.hash'] = h;
}
function comparePromptVer(a, b) {
  return metrics.diff({ promptVer: a }, { promptVer: b },
    ['doneRate', 'adoption', 'usdPerTask', 'p95']);
}
```
