## 1279：笔试手写：实现 会话画像指纹器

**需求**：实现 sessionFingerprint(messages)：messages 为 { role, content }[]。生成画像：任务类型（含「查/搜索」→ 'qa'；含「生成/写」→ 'create'；含「改/修复」→ 'fix'；默认 'chat'）、轮数（user 消息数）、工具使用数（tool 消息数）、关键词 Top-3（2-4 字中文词频）。输出稳定指纹字符串 `type|turns|tools|k1,k2,k3` 用于会话去重聚类。

```js
function sessionFingerprint(messages) {
  const text = messages.map(m => m.content).join('');
  const type = /查|搜索|找/.test(text) ? 'qa'
    : /生成|写|创建/.test(text) ? 'create'
    : /改|修复|修|调试/.test(text) ? 'fix' : 'chat';
  const turns = messages.filter(m => m.role === 'user').length;
  const tools = messages.filter(m => m.role === 'tool').length;
  const freq = {};
  for (const w of text.match(/[\u4e00-\u9fa5]{2,4}/g) || []) freq[w] = (freq[w] || 0) + 1;
  const top = Object.entries(freq).sort((a, b) => b[1] - a[1]).slice(0, 3).map(e => e[0]);
  return { fingerprint: [type, turns, tools, top.join(',')].join('|'), type, turns, tools, top };
}
```

**评分点**：
- 任务类型的关键词分派（规则先行，可换分类器）
- 指纹由低维可解释特征构成（可聚类可去重）
- 关键词按频次取 Top-3（空集也要输出空串）
- 能讨论：指纹驱动会话聚类 → badcase 归因（AGT-609）的链路
