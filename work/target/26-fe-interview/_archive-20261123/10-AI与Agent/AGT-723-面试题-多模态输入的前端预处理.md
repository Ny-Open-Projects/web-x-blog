## AGT-723：用户上传图片进问答前，前端可以做哪些预处理降低成本提升质量

**答**：
- 压缩与裁剪：大图下采样到模型有效分辨率（超出部分纯浪费 token）、自动裁掉无关边缘（聊天截图裁掉头像区）、多图合并提示用户选择关键页。
- 本地预检：格式/大小校验、本地 OCR 预判"图片里有没有文字"（纯照片提示用户补充说明）、敏感信息提醒（截图里有个人信息先提示打码）。
- 上传优化：原图压缩 60~80%（vision 对压缩不敏感）、断点续传、失败自动降分辨率重试。

```javascript
async function prepareUpload(file) {
  const bitmap = await createImageBitmap(file);
  const scaled = downscale(bitmap, { maxDim: 1568 });  // 模型有效分辨率
  const blob = await toBlob(scaled, { quality: 0.8 }); // 压缩
  const ocrHint = await quickOCR(blob);                // 本地预判
  const privacy = detectSensitive(ocrHint.text);       // 敏感信息提醒
  return { blob, ocrHint,
    warn: privacy.hits ? '检测到疑似个人信息，建议打码后上传' : null };
}
```
