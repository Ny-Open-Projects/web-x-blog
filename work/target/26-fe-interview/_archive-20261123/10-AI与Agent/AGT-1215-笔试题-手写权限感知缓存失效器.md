## 1215：笔试手写：实现权限变更触发的定向缓存失效

**需求**：实现 PermCacheBinder(qc)：bind(permission, queryKeyPrefix) 注册「权限 -> 缓存域」映射；onPermChange(change: { granted: string[], revoked: string[] })——revoked 的权限对应域失效、granted 触发预取（prefetch）；重复事件去重（同一权限 5s 内只处理一次）。返回失效/预取日志。

```js
function createPermCacheBinder(qc) {
  const map = new Map();        // perm -> [keyPrefix]
  const lastHandled = new Map();
  const log = [];
  return {
    bind(permission, prefix) {
      if (!map.has(permission)) map.set(permission, []);
      map.get(permission).push(prefix);
    },
    onPermChange(change) {
      const now = Date.now();
      const sig = JSON.stringify(change);
      if (now - (lastHandled.get(sig) || 0) < 5000) return log;  // 去重窗口
      lastHandled.set(sig, now);
      for (const p of change.revoked) {
        for (const key of map.get(p) || []) {
          qc.invalidateQueries({ queryKey: key });
          log.push({ type: 'invalidate', key });
        }
      }
      for (const p of change.granted) {
        for (const key of map.get(p) || []) {
          qc.prefetchQuery({ queryKey: key, queryFn: () => Promise.resolve(null) });
          log.push({ type: 'prefetch', key });
        }
      }
      return log;
    },
  };
}
// 用法：binder.bind('admin.view', ['admin']);
// binder.onPermChange({ granted: [], revoked: ['admin.view'] })
// -> invalidate ['admin']：降权后缓存即时收敛
```

**评分点**：
- revoke -> invalidate 与 grant -> prefetch 的方向语义正确
- 去重窗口（事件风暴防护）
- 日志可观测（失效/预取行为可审计）
- 能讨论：降权后的「缓存即泄露」风险（invalidate 清的是前端可见性——安全仍在服务端）、grant 预取的滥用风险
