## 978：P95 延迟比 P50 高 10 倍，长尾任务怎么治

**答**：
- 先画像再动手：把 P95 之外的请求聚类，通常是三类——超长任务（多步工具循环）、外部工具慢（某 API 偶发 3s）、上下文超大（会话历史失控）。
- 治理长任务：步数上限 + 中途流式汇报进度（用户感知到「在动」就不焦虑）；慢工具：独立超时 + 并行预取 + 失败快速降级；超上下文：会话历史自动压缩阈值。
- 队列策略：重任务（多步 Agent）和轻任务（单轮 QA）分队列，防止重任务占满并发把轻任务也拖慢。
- 追问钩子：为什么不直接给所有请求加更紧的超时？——会误杀正常长任务，正确做法是按任务类型设差异化超时预算。

```ts
const TIMEOUTS = { qa: 8000, agent_task: 120000 };   // 按任务类型差异化
function route(req) {
  const queue = req.type === 'agent_task' ? heavy : light; // 分队列防互相拖慢
  return queue.push({ ...req, timeout: TIMEOUTS[req.type],
    onProgress: sse => sse.send('step', { n: s.step }) });   // 进度流式上报
}
```
