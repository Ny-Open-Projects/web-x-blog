## 967：评测环境与生产环境怎么隔离才不会互相污染

**答**：
- 三层隔离：数据隔离（评测用独立知识库副本/独立索引别名，评测写入永远不进生产索引）、凭证隔离（评测环境用降权测试凭证，工具副作用走沙箱）、流量隔离（评测请求带 env 标记，监控里单独分桶）。
- 最常见污染：评测脚本「顺手」往生产缓存写数据（预热了不该有的答案缓存）——所有写操作按环境前缀路由。
- 沙箱工具：评测环境的发消息/写库类工具必须替换为 mock，且 mock 也要记录调用供评测断言，一举两得。
- 追问钩子：评测想用真实生产数据怎么办？——只读拉取 + 脱敏，评测环境的写路径永远指向影子资源。

```ts
const ENV = process.env.EVAL_ENV === 'shadow' ? 'shadow' : 'prod';
const routedIndex = ENV === 'shadow' ? 'rag-idx-shadow' : 'rag-idx';
const tools = ENV === 'shadow'
  ? mockTools({ recordCalls: true })          // 副作用 mock + 记录
  : prodTools;
// 监控打点带环境标记，评测流量单独分桶不干扰生产大盘
metrics.tag({ env: ENV });
```
