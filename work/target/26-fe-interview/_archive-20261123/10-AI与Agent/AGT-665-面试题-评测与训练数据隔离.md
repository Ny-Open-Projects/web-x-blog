## AGT-665：防止评测用例泄漏进提示词/工具描述/知识库造成虚高，隔离机制怎么做

**答**：
- 物理隔离：评测集仓库独立权限，只有评测服务可读；运行时资产（提示词/知识库）的构建流程禁止引用评测仓库——CI 校验依赖图无评测仓库边。
- 内容隔离：评测用例的场景与线上真实流量有分布差异，用「线上新样本月度盲测」（当月新流量样本不进评测集直接盲测）作为防泄漏探针——盲测分数与评测分数背离超阈值即疑似泄漏。
- 语义泄漏检测：对提示词/知识库全文与评测用例做嵌入相似度扫描，高度相似的用例标记疑泄漏并替换。

```javascript
function leakScan(runtimeAssets, evalCases) {
  const hits = [];
  for (const c of evalCases) {
    const sim = maxSim(embed(c.input),
      runtimeAssets.map(a => embed(a.text)));
    if (sim > 0.9) hits.push({ case: c.id, asset: sim.asset }); // 疑泄漏
  }
  return { suspects: hits,
    action: hits.length ? replaceCases(hits) : null,
    blindProbe: monthlyBlindScore(),              // 盲测探针
  };
}
```
