## AGT-675：把评测体系收敛成一张总图（用例生产/执行/判定/消费四环），环间如何咬合

**答**：
- 四环：用例生产（人工+回流+对抗生成，带去重与难度标定）→ 执行（分层调度+缓存并行+预算控制）→ 判定（规则+judge 多评委+仲裁，带校准与 flaky 隔离）→ 消费（CI 门禁/周报/灰度决策/业务对齐），消费产生的新问题回流生产环形成闭环。
- 咬合的关键接口：用例带元数据（能力/难度/来源/判据版本），分数带三元组（用例版本/judge 版本/模型版本）——没有这些元数据，环与环之间就断了。
- 一致性原则：任何环节的变更（用例/judge/判据）都必须版本化并触发校准，保证跨时间可比。

```javascript
const EVAL_LOOP = {
  produce: { sources: ['manual', 'reflux', 'adversarial'],
    meta: ['cap', 'diff', 'source', 'rubricVer'] },
  execute: { strategy: ['tiered', 'cached', 'parallel', 'budgeted'] },
  judge:   { panel: ['rules', 'llm-judges', 'arbitration'],
    meta: ['judgeVer', 'calibrated'] },
  consume: { outputs: ['ci-gate', 'weekly', 'canary', 'northstar'] },
};
function loopHealth() {
  return Object.entries(EVAL_LOOP).every(([k, v]) =>
    v.meta ? metaComplete(k, v.meta) : true);     // 元数据完整=环咬合
}
```
