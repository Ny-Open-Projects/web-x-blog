## AGT-754：Agent 的用户画像应该有哪些字段（技术栈/偏好/水平/约束），如何采集与更新

**答**：
- 字段分层：静态事实（技术栈/角色/语言）、偏好（代码风格/回答详细度/输出格式）、能力水平（按领域估分，决定解释深度）、约束（禁用工具/合规要求）。每个字段 { value, confidence, evidence[], updatedAt }。
- 采集三通道：显式配置（用户设置页，最高优先级）、对话挖掘（从历史蒸馏）、行为推断（采纳/拒绝信号），优先级显式 > 行为 > 挖掘，低置信推断不打扰用户。
- 水平自适应：能力估分驱动回答风格（新手给步骤、专家给结论），估分来自问答交互的难度匹配度而非单次事件。

```javascript
const PROFILE_SCHEMA = {
  stack: { type: 'array', source: ['explicit', 'mined'] },
  style: { verbosity: 'enum', format: 'enum' },
  skill: { type: 'map<domain, 1-5>', from: 'interaction-fit' },
  constraints: { type: 'array', immutable: true }, // 合规约束不可挖掘覆盖
};
function applyProfile(prompt, profile) {
  return [
    profile.skill.js <= 2 ? '解释时给出步骤与示例' : '直接给结论与权衡',
    profile.style.verbosity === 'brief' ? '回答控制在 300 字内' : '',
  ].filter(Boolean).join('；');                    // 画像→回答风格
}
```
