## AGT-762：记忆系统记什么不记什么（敏感信息排除/自动脱敏/保留期限）

**答**：
- 负面清单硬编码：身份证/银行卡/密码/健康隐私等不入记忆（正则+NER 双通道拦截，命中即拒写并提示用户）；即使显式要求也拒绝存储（合规红线）。
- 自动脱敏入档：业务数据（客户名/金额）记忆时脱敏存抽象（"客户 A 的合同 3 月到期"），需要时实时反查权限内的原文。
- 保留期限分层：画像永久（用户可删）、情景 90 天、临时工作记忆会话级；过期自动清理，清理前摘要降级。

```javascript
const SENSITIVE = [ID_CARD_RE, BANK_RE, PASSWORD_HINT_RE, HEALTH_RE];
async function writeMemory(stmt) {
  for (const re of SENSITIVE)
    if (re.test(stmt))
      return { blocked: true,
        note: '该内容包含敏感信息，不会存入记忆' };  // 硬拒绝
  return semantic.write(redactAbstract(stmt), { ttl: 'permanent' });
}
```
