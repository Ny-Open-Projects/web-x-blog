## 1063：评估基线多久重校一次，怎么重校

**答**：
- 重校触发：季度例行、模型大版本升级、知识库结构性变更、业务对象切换——基线过期会让「达标」变成自我安慰。
- 重校内容三件：指标目标值（按业务重新核定）、评估集构成（过期题替换、盲区补齐）、裁判校准（LLM 裁判与人工的一致率复测）。
- 重校纪律：新旧基线并行跑一个周期（两周），出「基线迁移报告」明确「旧达标 ≈ 新多少分」，保证历史数据可解读。
- 追问钩子：重校后分数普涨是好事吗？——不一定：可能是题目变简单或裁判变松，用「冻结锚点题」（10 条永不改动的高区分度题）校验，锚点分数稳定才算真涨。

```ts
async function recalibrate() {
  const anchor = await runEval(anchorSet);          // 锚点题校验裁判与管线
  if (anchorDrift(anchor) > 0.02) return fixPipelineFirst(anchor);
  const newBase = await runEval(evalSet.vNext);
  return migrate({ old: baseline.vN, new: baseline.vN1, parallel: '2w',
    report: '基线迁移报告' });
}
```
