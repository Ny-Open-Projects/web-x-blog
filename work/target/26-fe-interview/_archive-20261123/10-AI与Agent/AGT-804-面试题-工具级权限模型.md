## AGT-804：Agent 调用工具的权限如何建模（RBAC+ABAC 混合：角色决定能不能用、属性决定数据范围）

**答**：
- 两级授权：工具级（RBAC：销售角色可用 crm.query，实习不可）+ 数据级（ABAC：查询结果按用户部门/区域过滤）。Agent 永远以用户身份（on-behalf-of）携带用户权限，不能有平台级万能凭据。
- 组合授权：Agent 自身有角色（能发起哪些工具请求），实际执行取交集（Agent 权限 ∩ 用户权限）——Agent 权限是"可请求上限"，用户权限是"数据真实边界"。
- 危险操作加审批流：destructive 工具强制双人审批（发起人+审批人），审批链留痕。

```javascript
async function authorizeTool(tc, user, agent) {
  const rbac = await role.allow(user.role, tc.tool)
    && agent.grants.includes(tc.tool);            // 交集
  if (!rbac) return { ok: false, reason: 'rbac' };
  const scope = await abac.filter(tc.args, {      // 数据范围过滤
    user, dept: user.dept, region: user.region });
  if (tc.risk === 'destructive')
    return { ok: false, needApproval: true, chain: [user.id, 'manager'] };
  return { ok: true, args: scope };
}
```
