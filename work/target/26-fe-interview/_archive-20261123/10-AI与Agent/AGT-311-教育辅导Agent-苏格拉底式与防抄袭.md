## AGT-311：教育辅导 Agent 怎么做到"引导学习"而不是"直接给答案"？

**答**:
- 教学法约束：按苏格拉底式引导配置 prompt（先问学生已想到哪一步→给提示不给答案→学生多轮无进展才逐步揭示，AGT-96 已有基础，本卡聚焦工程化）；答案揭示分级（提示→思路→关键步骤→完整解答），按学生表现解锁。
- 学情记忆：错题与薄弱知识点入学情记忆（AGT-223 语义记忆），后续练习按薄弱点自适应出题——个性化是教育 Agent 的核心价值。
- 防代写模式：作业场景检测（整题粘贴求解→触发引导模式拒绝直答+提示教师端可见）、家长/学生角色区分；教师端仪表盘（学生用 AI 的方式数据）——把"防代写"做成产品设计而不是 prompt 恳求。
- 事实安全：知识性错误在教学场景零容忍（学生会记住错误答案）——教学内容走审核过的知识库，解析类内容带引用。

```text
教育 Agent 设计：
引导：分级揭示（提示→思路→步骤→解答）
  按表现解锁；拒绝整题直答
学情：错题/薄弱点入语义记忆 →
  自适应出题
防代写：整题粘贴→引导模式+
  教师端可见；角色区分
事实：教学内容走审核库+引用，
  错误零容忍。
```
