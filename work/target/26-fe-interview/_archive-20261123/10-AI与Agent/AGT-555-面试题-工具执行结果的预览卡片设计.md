## AGT-555：工具返回大结果（500 行表格/长文档），预览卡片如何裁剪呈现

**答**：
- 预览三原则：裁剪（默认展示前 N 行/摘要字段）、可展开（展开后虚拟滚动看全量）、可定位（"模型用了第 3~7 行"这种被引用的行高亮——答案与证据对齐）。
- 不同工具结果有不同预览模板：SQL 结果给表格+行数+耗时，文件读取给 diff 视图，API 调用给状态码+关键字段。
- 大结果二次消费（导出/复制）入口在卡片上，不要求用户展开到原始工具界面。

```javascript
const PREVIEW_TEMPLATES = {
  sql: (r) => <TablePreview rows={r.rows.slice(0, 10)}
    total={r.rowCount} elapsed={r.ms} />,
  file: (r) => <DiffPreview added={r.added} removed={r.removed} />,
  api: (r) => <KVPreview status={r.status} fields={pick(r.json, KEY_FIELDS)} />,
};
function ToolResultCard({ tc }) {
  const used = tc.citedLines ?? [];     // 模型实际引用的行
  const T = PREVIEW_TEMPLATES[tc.tool] ?? DefaultPreview;
  return <Card>
    <T result={tc.result} />
    <Footer actions={['expand', 'export']}
      highlight={used} />   {/* 展开视图高亮被引用行 */}
  </Card>;
}
```
