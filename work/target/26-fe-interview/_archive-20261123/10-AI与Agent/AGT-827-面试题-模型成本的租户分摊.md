## AGT-827：平台统一采购模型算力，成本如何分摊回租户（计量/加价/对账）

**答**：
- 计量即分摊：模型网关按请求记录 tokens+模型单价+重试标记，租户成本=Σ(实际用量×单价×加价系数)；重试造成的重复计量由平台承担（不转嫁），缓存命中按折扣价计。
- 加价透明：加价系数（平台毛利）写进合同与账单，明细列出"用量/单价/系数/小计"——模糊计价是企业客户投诉第一名。
- 对账三源：网关计量 vs 供应商账单 vs 租户自助账单，三方偏差 <1%；偏差超阈值自动冻结出账并人工核查。

```javascript
function billTenant(tenant, month) {
  const rows = gateway.usage(tenant, month)
    .filter(r => !r.isRetry)                       // 重试不转嫁
    .map(r => ({ model: r.model,
      tokens: r.usage.total,
      unit: price(r.model, r.at),                  // 快照单价
      amount: r.usage.total * price(r.model, r.at) * tenant.factor }));
  const cached = rows.map(r => r.cached ? r.amount * 0.3 : r.amount);
  return { rows, cachedDiscount: sum(rows) - sum(cached), total: sum(cached) };
}
```
