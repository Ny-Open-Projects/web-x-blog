## AGT-667：评测报告里怎么呈现不确定性（分数±区间），避免决策被点估计误导

**答**：
- 每个分数带置信区间（Wilson/ bootstrap），报告用「区间条」而非裸数字；两版本对比画「区间重叠图」——区间不重叠才说显著胜出，重叠就标"无法区分"。
- 样本量透视：区间宽度直接暴露样本量问题（宽度大的指标标黄提示"多跑样本再决策"），比让读者自己发现靠谱。
- 决策规则前置：什么区间条件对应什么动作（pass/fail/pending）写进工具，报告只是呈现规则结果，避免每次人工争论。

```javascript
function renderScore(runA, runB) {
  return {
    a: { score: runA.rate, ci: wilson(runA.pass, runA.n) },
    b: { score: runB.rate, ci: wilson(runB.pass, runB.n) },
    verdict: noOverlap(wilson(runA.pass, runA.n), wilson(runB.pass, runB.n))
      ? (runA.rate > runB.rate ? 'A胜(显著)' : 'B胜(显著)')
      : '区间重叠，无法区分',                      // 可视化核心话术
    hint: ciWidth > 0.08 ? '样本不足，建议补充用例' : null,
  };
}
```
