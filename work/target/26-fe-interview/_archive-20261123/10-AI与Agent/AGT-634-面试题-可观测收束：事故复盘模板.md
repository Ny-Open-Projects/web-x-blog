## AGT-634：一次 Agent 质量事故（新版提示词上线导致大量负反馈），复盘模板要点

**答**：
- 时间线还原：变更（谁/何时/哪个版本指纹）→ 首个告警（哪个代理指标/延迟多久）→ 处置（回滚耗时）→ 影响面（多少会话/租户/成本损失）。
- 三个为什么：为什么告警慢（指标盲区？阈值？）、为什么影响大（灰度没拦住？全量？）、为什么回滚慢（指纹定位？配置下发？）——每个 why 对应一条机制改进项而非"下次注意"。
- 落实追踪：改进项带 owner+期限进工单，复盘后 30 天验证项关闭率；同一根因复发要追复盘失效。

```javascript
const RETRO_TEMPLATE = {
  timeline: ['change@ver', 'firstAlert@metric', 'mitigate@action', 'impact@scope'],
  whys: ['alert_latency→机制', 'blast_radius→机制', 'rollback_time→机制'],
  actions: [{ item, owner, due, verify: '30天关闭率' }],
};
function retroCheck(lastRetro) {
  return lastRetro.actions.every(a =>
    a.closedBy !== null || a.overdueAlert());   // 验证项不烂尾
}
```
