## AGT-570：流式输出到一半被审核拦截（部分内容已展示），前端怎么处理

**答**：
- 拦截是「截断 + 替换」事件：服务端发 moderation_stop 事件，前端立刻停止渲染后续 delta，已生成部分按策略处理——整条替换为拦截提示，或保留已展示部分+"后半部分未通过审核"标注。
- 已展示部分是否保留要看合规等级：一般场景保留（用户看到了就看到了，标注即可），严格场景（未成年人模式）整条隐藏。
- 拦截事件与错误事件分流处理：拦截不算错误（不重试），但要有"申诉"入口与"换个说法再问"引导。

```javascript
stream.on('moderation_stop', ({ keep, policy }) => {
  stream.abort();
  if (policy === 'strict' || !keep) replaceMessage(moderationNotice);
  else markPartialModerated({ shown: renderedLength,
    notice: '后半部分内容未通过审核' });
  showActions(['appeal', 'rephrase']);     // 申诉与改写引导，非重试
});
```
