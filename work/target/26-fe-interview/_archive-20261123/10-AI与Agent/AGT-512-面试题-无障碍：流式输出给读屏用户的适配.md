## AGT-512：流式打字机效果对屏幕阅读器用户是灾难，AI 对话的无障碍怎么做

**答**：
- 读屏用户不需要逐 token 播报：流式期间对 aria-live 区域保持静默或只播报"正在生成"，完成后一次性 aria-busy=false 并播报完整内容。
- 打字机动画尊重 prefers-reduced-motion；加载与生成状态要有文本等价物（不能只用转圈动画）。
- 消息列表用语义化结构（article/role=log），工具调用、引用等复杂组件提供键盘可达的操作入口。

```css
@media (prefers-reduced-motion: reduce) {
  .typing-cursor { animation: none; }   /* 关闭光标动画 */
}
```
```javascript
const live = useAriaLive();
stream.on('delta', () => { live.set({ busy: true, text: '' }); });  // 流式期间不播报
stream.on('done', (full) => {
  live.set({ busy: false, text: full }); // 完成后整段播报
  announce('回答已完成，共' + countWords(full) + '字');
});
```
