## AGT-399：Agent 平台接入图像/语音/视频类工具（生成/处理）的生态设计？

**答**:
- 工具类型图谱：分析类（OCR/ASR/图像理解——低风险自动）、转换类（格式转换/压缩/翻译配音——中风险）、生成类（文生图/文生视频/语音克隆——高风险：版权与滥用）、编辑类（图像修改/视频剪辑）——按风险分级授权（AGT-286）。
- 生态统一：多模态工具的统一接口抽象（输入/输出/参数 schema 规范化——不同供应商的生成 API 差异在适配层消化，AGT-345 出口思想）、MCP 封装（AGT-241 三原语：生成类走 Tools、素材库走 Resources）。
- 生成类的特殊治理：内容安全（生成物审核——AGT-314 机审管线）、版权与溯源（生成内容带水印/元数据标识——AI 生成内容标识法规）、深度伪造防护（人脸/声音克隆需要授权凭证）、成本高企（生成类成本远超文本——配额与预览确认后再全量生成）。
- 质量评测：多模态工具的评测维度（图像：一致性/文字准确率；语音：自然度/错字率；视频：连贯性）——各模态专项评测集与人工评审。

```text
多模态工具生态：
分级：分析（自动）/ 转换（中）/
  生成（高风险强授权）
统一：schema 抽象 + MCP 封装
生成治理：内容审核 / AI 标识水印 /
  人脸声音克隆需授权 / 成本配额
  + 预览确认
评测：各模态专项集 + 人工评审。
```
