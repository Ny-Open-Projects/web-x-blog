## 969：评测集覆盖不到的低频高危场景怎么办

**答**：
- 低频高危场景（如「用户要求删除生产数据库」）在自然流量里样本太少，靠挖掘流量永远凑不齐——必须人工构造 + 合成放大。
- 合成方法：真实样本做「种子」，LLM 做改写变异（换个说法、换个业务对象、加干扰上下文），变异样本全部人工快审；每类高危场景保证至少 20 条。
- 上线保障双轨：评测集覆盖（回归）+ 运行时护栏（规则拦截，不依赖模型判断），高危场景不能只有评测没有运行时防线。
- 追问钩子：合成样本会不会「太标准」测不出真实攻击？——会，所以要保留一部分从真实事故/社区攻击报告转化的样本作为「野生集」。

```ts
async function amplify(seeds, perSeed = 4) {
  const variants = [];
  for (const s of seeds) {
    for (const v of await llm(`改写以下高危请求为4种不同表述，保持危险意图不变：\n${s.text}`)) {
      variants.push({ ...s, text: v, origin: 'synthetic' });  // 标记来源
    }
  }
  return humanQuickReview(variants);   // 全量快审（高危集不放行未审样本）
}
```
