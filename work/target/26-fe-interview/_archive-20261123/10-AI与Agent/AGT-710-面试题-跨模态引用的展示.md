## AGT-710：回答引用了图片/视频/表格，前端如何展示跨模态引用（缩略图/跳转/高亮）

**答**：
- 引用卡按类型渲染：图片引用给缩略图+页码坐标（点击弹原图并高亮 bbox 区域）、视频引用给关键帧+时间戳（点击内嵌播放 seek）、表格引用给行级定位（"引用了第 3 行"）。
- 引用与答案对齐：答案中每个数据点标注来自哪个引用（角标指向具体图表的具体行），而不是笼统列参考文献。
- 加载策略：缩略图懒加载（视口内才加载），原图/播放器按需拉取，避免一条回答带 10 个引用就把页面拖垮。

```jsx
function MultimodalCite({ cite }) {
  if (cite.type === 'image') return <LazyThumb src={cite.thumbUrl}
    onClick={() => openViewer(cite, { highlight: cite.bbox })} />;
  if (cite.type === 'video') return <FrameChip frame={cite.keyFrame}
    onClick={() => seekPlayer(cite.videoId, cite.t0)} />;
  if (cite.type === 'table') return <RowChip table={cite.tableId}
    row={cite.rowRef} />;
  return <TextCite cite={cite} />;
}
```
