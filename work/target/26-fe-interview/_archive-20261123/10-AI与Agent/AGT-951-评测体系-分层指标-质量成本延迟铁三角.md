## 951：Agent 评测体系的指标框架怎么搭

**答**：
- 铁三角三维度缺一不可：质量（任务完成率、事实准确率、人工评分）、成本（token/调用次数/单任务费用）、延迟（P50/P95、首 token 时间）；只看质量会把系统调得又贵又慢。
- 质量再分两层：端到端（用户视角）与环节级（检索命中率、工具调用成功率、拒答准确率）——环节级指标才能指导改哪里。
- 每个指标必须有：定义、采集方式、目标值、告警阈值；没有目标值的指标只是装饰。
- 追问钩子：指标打架怎么办（准确率升但延迟涨）？——预先定义综合分（如质量 ×0.7 - 延迟超时惩罚），评估时按综合分排序，避免每轮口头扯皮。

```ts
const SCORECARD = {
  quality: { acc: w(0.4, target: 0.85), fact: w(0.3, target: 0.9) },
  cost:    { tokensPerTask: w(0.15, ceiling: 8000) },
  latency: { p95: w(0.15, ceiling: 8000) },
};
function composite(r) {           // 预先定义综合分，防口头扯皮
  return SCORECARD.quality.acc.w * r.acc + SCORECARD.quality.fact.w * r.fact
    - (r.p95 > 8000 ? 0.1 : 0) - (r.tokensPerTask > 8000 ? 0.05 : 0);
}
```
