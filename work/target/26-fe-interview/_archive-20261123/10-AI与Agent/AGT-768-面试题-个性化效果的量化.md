## AGT-768：个性化上线后如何证明它有用（对比实验/满意度/效率指标）

**答**：
- 三层证据：效率指标（个性化组轮次更少/修正更少——一步到位率提升）、满意度（点赞率/负反馈率对比）、留存（个性化组次周留存）。用会话级随机分组的 AB 实验，对照组关闭个性化。
- 分维度归因：哪个画像字段贡献最大（消融实验逐字段关闭），把投资集中在高贡献字段（通常是技术栈与详细度偏好）。
- 负面证据同样重要：个性化导致的信息茧房（推荐越来越窄）与过度适配（用户改了习惯后模型还在用旧画像），监控「画像滞后抱怨」。

```javascript
async function personalizationAB() {
  const exp = abAssign({ key: 'personalization', sticky: 'user' });
  const m = await watch(exp, ['oneShotRate', 'likeRate', 'd7Retention',
    'regenRate']);
  const contrib = await ablationByField(['stack', 'style', 'skill']);
  return { metrics: m, contrib,
    cocoon: diversityIndex(exp.treat) < diversityIndex(exp.ctrl)
      ? 'watch-filter-bubble' : null };
}
```
