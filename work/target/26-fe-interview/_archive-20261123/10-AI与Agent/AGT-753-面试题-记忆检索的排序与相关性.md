## AGT-753：上下文组装时从记忆库检索哪些记忆（相关性/时近性/重要性三因子）

**答**：
- 三因子融合：语义相关性（与当前 query 的向量相似）、时近性（越近越相关，指数衰减）、重要性（被引用次数/用户标注），加权排序后按 token 预算截断。
- 任务型检索特殊：执行任务时检索「怎么做过的」（相似历史任务的过程记忆），问答型检索「知道什么」（事实记忆）——检索目标不同，索引分开。
- 记忆检索结果要「可解释」：注入上下文时标注来源（来自 3 月 5 日的对话），回答引用记忆时用户可核对。

```javascript
function rankMemories(query, memories) {
  return memories.map(m => ({
    ...m, score: 0.5 * cosSim(embed(query), m.emb)
      + 0.3 * recency(m.at)                       // 指数衰减
      + 0.2 * m.importance,
  })).sort((a, b) => b.score - a.score)
    .slice(0, budgetTokens(MEM_BUDGET));
}
function retrieveFor(task) {
  return task.kind === 'execution'
    ? vector.search(embed(task.goal), { index: 'episodic-procedures' })
    : vector.search(embed(task.query), { index: 'semantic-facts' });
}
```
