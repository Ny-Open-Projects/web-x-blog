## AGT-774：把记忆系统收束成一张架构图（写入/存储/检索/注入/治理五模块），关键接口怎么定

**答**：
- 五模块：写入管线（会话事件→蒸馏→准入门槛→分域）、存储（四层记忆：工作/情景/语义/画像，各自 TTL）、检索（三因子排序+任务型路由）、注入（预算分区+格式规范+去重）、治理（用户控制/隐私红线/版本回滚/公平审计）。
- 三个关键接口：write(fact, { source, domain })（带来源与域）、retrieve(query, { task, budget })（带预算）、forget(scope)（用户删除权）——接口稳定则实现可替换（换向量库/换蒸馏模型不动上层）。
- 一句话收束：记忆系统的本质是「把对话流变成可持续演化的用户模型」，所有机制都围绕"写得准、查得对、用得省、删得掉"。

```javascript
const MEMORY_ARCH = {
  write: { pipeline: 'extract→admit→domain-tag',
    api: 'write(fact, {source, domain})' },
  store: { tiers: ['working', 'episodic', 'semantic', 'profile'],
    ttl: 'session/90d/permanent' },
  retrieve: { factors: ['sim', 'recency', 'importance'],
    api: 'retrieve(query, {task, budget})' },
  inject: { rules: ['dedupe', 'zone-budget', 'format-spec'] },
  govern: { user: ['view/edit/delete/pause'],
    ops: ['version', 'rollback', 'fairness-audit'] },
};
```
