## AGT-752：用户说我现在改用 Vue 了（与画像里 React 冲突），记忆更新怎么处理冲突

**答**：
- 冲突策略分级：显式修正（用户明确说"我改用 X 了"）立即覆盖旧记忆并标注修正时间；隐式冲突（新行为与旧画像矛盾但不明确）进证据池观察，不直接覆盖。
- 记忆带版本与时间：被覆盖的记忆不是删除而是降级存档（用户可能临时切换），画像字段记录「当前值+历史值+变更原因」。
- 时效性衰减：带时间敏感的记忆（"用户在准备面试"）到期自动降权/失效，避免过期记忆污染回答。

```javascript
async function updateMemory(stmt, source) {
  const conflicts = await semantic.findConflicts(stmt);
  if (source.type === 'explicit') {               // 显式修正立即生效
    for (const c of conflicts)
      await semantic.archive(c, { reason: 'superseded', by: stmt });
    await semantic.upsert(stmt, { confirmedAt: Date.now() });
  } else {                                        // 隐式冲突进观察
    await candidate.add(stmt, { conflicts });
    if (await candidate.evidence(stmt) >= 3)
      await proposeUpdate(stmt, conflicts);       // 攒够证据才提议更新
  }
}
```
