## AGT-560：用户想对比两个模型的回答（左/右双栏同时生成），双流渲染怎么实现

**答**：
- 两个独立流各自一套 delta 缓冲与渲染管线，共享输入上下文（同一 prompt 同时发两模型）；UI 双栏各自独立的打字机与状态（完成时间不同很正常，快的先定格）。
- 对齐交互：两栏内容块按 markdown 块序号对齐（第 2 段对第 2 段），滚动联动可开关；"采纳左边"按钮把选中栏内容确立为主回答（另一栏降级为对比参考）。
- 性能：双流渲染成本翻倍，低端机降级为串行对比（先 A 后 B）或只渲染 diff 摘要。

```javascript
function useDualStream(prompt, models) {
  const [a, b] = models.map(m => useStream({ ...prompt, model: m }));
  return { a, b,
    adopt: (side) => setMain(side === 'a' ? a.final : b.final),
    syncScroll: enable => bus.set('dualScroll', enable),
  };
}
// 低端机降级：串行对比
if (deviceTier === 'low') return <SerialCompare prompt={prompt} />;
```
