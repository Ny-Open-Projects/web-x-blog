## AGT-340：从聊天框到协作界面——Agent 的交互范式有哪些？

**答**:
- 范式谱系：对话式（聊天框问答——最低门槛）、副驾式（嵌入工作流旁边辅助，如 IDE Copilot）、指令式（下达任务 Agent 后台执行，进度可见）、委托式（规则化授权：符合条件自动执行）——授权度递增，人的介入递减；不同任务适配不同范式（创作类对话/流程类委托）。
- 混合界面：同一产品内多范式共存（快问快答用对话、长任务用委托面板）——范式选择的判据是"任务的异步性与风险度"：同步低险→对话，异步有险→委托+审批。
- 信任演化设计：新用户低授权（多确认），信任积累后逐步放权（白名单/自动执行，AGT-286 分级确认的长期版）——授权是渐进旅程而非静态配置。
- 反馈与掌控感：无论哪种范式，三要素不可少——过程可见（在做什么）、随时可停（打断/撤销）、结果可查（做了什么改了什么）——掌控感是 Agent UI 的第一设计原则。

```text
交互范式谱系（授权度递增）：
对话式 → 副驾式 → 指令式 → 委托式
选择：同步低险→对话；
  异步有险→委托+审批；
  创作类对话 / 流程类委托。
信任演化：新用户多确认 →
  白名单 → 自动执行（渐进放权）
三要素：过程可见 / 随时可停 /
  结果可查 —— 掌控感第一。
```
