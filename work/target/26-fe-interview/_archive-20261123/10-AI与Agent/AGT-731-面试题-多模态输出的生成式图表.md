## AGT-731：让 Agent 输出图表（不只引用已有图），生成式图表的流程与校验

**答**：
- 流程：数据来自检索（表格/数据库）→ Agent 输出图表 spec（类型/轴/数据系列，结构化 JSON）→ 前端图表引擎渲染 spec → 数据回显校验（渲染的数据与 spec 一致）。
- 校验三层：spec schema 校验（字段完整/类型合法）、数据一致性（渲染值=检索值，防模型抄错数）、可读性（类型与数据形态匹配：趋势用折线、占比用饼图，不匹配给建议）。
- 引用溯源：图表数据点标注来源引用（"数据来自报表 X 第 3 行"），图表可下钻到原始数据——生成式图表不能变成无源之水。

```javascript
function validateChartSpec(spec, source) {
  const schemaOk = chartSchema(spec);              // 结构校验
  const dataOk = spec.series.every(s =>
    deepEqual(s.data, lookup(source, s.from)));    // 数据一致
  const fit = typeFit(spec.type, dataShape(spec)); // 类型匹配
  return { ok: schemaOk && dataOk, fit,
    suggestion: fit.ok ? null : `建议改用${fit.better}`,
    citation: source.cite };                       // 溯源
}
```
