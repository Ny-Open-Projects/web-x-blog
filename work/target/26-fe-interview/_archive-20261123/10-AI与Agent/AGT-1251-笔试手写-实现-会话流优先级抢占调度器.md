## 1251：笔试手写：实现 会话流优先级抢占调度器

**需求**：实现 preemptiveScheduler(tasks)：tasks 为 { id, priority: 0(前台)|1(后台), run: (onPause) => Promise }[]。前台任务立即执行；前台到达时后台任务被暂停（调用 onPause 通知其保存状态），前台全部结束后恢复后台。返回完成顺序数组。要求后台不被饿死（前台持续到达时后台至少每 10 个前台插空一轮）。

```js
function preemptiveScheduler(tasks) {
  const order = [];
  let fgRunning = 0, fgSinceBg = 0;
  const fgQ = [], bgQ = [];
  const drainBg = () => {
    if (fgRunning > 0 || !bgQ.length) return;
    const t = bgQ.shift();
    return t.run(() => Promise.resolve('paused')).then(r => { order.push(t.id); drainBg(); });
  };
  const runFg = t => {
    fgRunning++;
    return t.run(() => Promise.resolve('paused')).then(r => {
      order.push(t.id); fgRunning--; fgSinceBg++;
      if (fgSinceBg >= 10 && bgQ.length) { fgSinceBg = 0; drainBg(); } // 防饿死插空
      if (fgQ.length) return runFg(fgQ.shift());
      drainBg();
    });
  };
  for (const t of tasks) {
    if (t.priority === 0) { fgQ.push(t); if (fgRunning === 0 && !order.includes(fgQ[0].id)) runFg(fgQ.shift()); }
    else { bgQ.push(t); drainBg(); }
  }
  return { order, flush: () => Promise.all([drainBg()]) };
}
```

**评分点**：
- 前台计数器判断是否允许后台运行
- fgSinceBg 计数实现防饿死（调度公平性硬要求）
- onPause 回调传递暂停语义（真实实现需 promise 可暂停封装）
- 能讨论：流式场景下暂停 = 停止读 chunk 而非断连接
