## AGT-620：把离线评测指标（准确率/相关性）变成生产可监控指标的可行做法

**答**：
- 低成本代理指标进监控：引用命中率（回答是否引用了检索结果）、格式合规率（JSON/模板校验通过率）、拒答合理率——可实时计算，作为离线评测的"前哨"。
- 抽样实时评分：小比例（1~5%）请求异步调 LLM 评分器（judge）打分，作为准实时质量指标；成本可控且能发现离线集覆盖不到的回归。
- 两层指标联动：生产代理指标异常→触发定向离线评测（把异常时段样本入评测集跑一遍），定位是提示词/模型/知识库哪层坏了。

```javascript
async function productionQuality(turn) {
  const proxy = {
    citeHit: turn.sources?.length > 0 && turn.citedCount > 0,
    formatOk: validateFormat(turn.output, turn.expectFormat),
  };
  if (sampled(0.03)) {                            // 3% 抽样 judge
    proxy.judgeScore = await judge(turn, { async: true });  // 异步不打扰用户
  }
  metrics.gauge('quality.proxy', proxy);
  if (proxy.citeHit === false && spikeDetected())
    triggerOfflineEval(sampleWindow(15));         // 异常→定向离线评测
}
```
