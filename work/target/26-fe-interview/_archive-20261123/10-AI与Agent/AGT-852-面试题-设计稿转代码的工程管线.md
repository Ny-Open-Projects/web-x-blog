## AGT-852：设计稿（Figma）→ 代码的 AI 管线怎么工程化（token 对齐/组件映射/验收）

**答**：
- 管线三段：① 结构化输入（Figma API 拉取图层树+设计 token，而不是截图——截图转代码质量差且不接设计系统）；② 映射生成（图层→组件库组件的映射表驱动，AI 只负责"找映射+组合"，不凭空造组件）；③ 验收（视觉 diff：渲染结果 vs 设计稿像素/结构比对+人工抽检）。
- 关键是「映射表」工程：设计系统每个组件的 Figma 特征→代码组件的映射维护在配置里，命中率随积累上升，AI 的自由发挥空间被压缩到布局层。
- 产出的代码要过设计系统 lint（禁用裸颜色/裸间距，必须用 token）。

```javascript
async function designToCode(figmaUrl) {
  const tree = await figma.exportTree(figmaUrl, { tokens: true });
  const mapped = tree.map(node =>
    MAPPER[node.type]?.(node)                    // 组件映射表驱动
    ?? aiCompose(node, components));             // 未映射的交给AI组合
  const code = render(mapped, { styling: 'tokens-only' });
  const lint = designLint(code, { bareColor: 'error' });  // 裸样式拒绝
  return { code, lint, visualDiff: await snapCompare(code, figmaUrl) };
}
```
