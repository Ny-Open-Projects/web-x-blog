## AGT-668：评测指标如何与产品北极星对齐（而不是停留在答得准）

**答**：
- 指标翻译链：产品北极星（如"工单自助解决率"）→ Agent 代理指标（任务完成率/一次解决率/转人工率）→ 评测判据（对应场景用例的完成判据）。评测的"对"必须定义为"用户任务完成"而非"答案语义正确"。
- 校准：用线上真实结果回归评测判据权重——"哪类评测通过率变化与线上北极星相关性最高"，权重定期重估。
- 反指标预警：评测分数涨但北极星不动甚至跌 = 优化错了方向，触发"评测-业务脱节"审查。

```javascript
function alignToNorthStar(evalMetrics, northStar) {
  // 找与北极星相关性最高的评测指标做主指标
  const corrs = evalMetrics.map(m => ({
    m, r: corr(m.weeklySeries, northStar.weeklySeries) }));
  const primary = maxBy(corrs, 'r');
  return { primary: primary.m,
    weightRevise: corrChanged(primary.r),         // 权重定期重估
    disconnect: evalUpAndNorthStarFlat() && 'audit_alignment' };
}
```
