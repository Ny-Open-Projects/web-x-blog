## 1107：模型对齐（拒绝危险请求的能力）会漂移吗，怎么监控

**答**：
- 会漂移：供应商更新、上下文变化、微调都会改变拒绝行为；表现是「以前拒的现在答了」——这是静默的安全退化。
- 监控探针：固定「危险请求探针集」（明确应拒的 50 类请求）每日跑生产模型，拒答率日环比下降即告警；探针覆盖各危险类别（暴力/违法/隐私/越权）。
- 漂移响应：短期 prompt 加固（system 强约束）+ 长期反馈给供应商或切换版本；期间安全防线（工具权限）保持不变——prompt 层漂移时架构层兜底。
- 追问钩子：探针集会不会「教会」模型被测内容？——探针是单向只读探测，不进入训练；但要防「探针过拟合」：探针定期轮换变体，防止防线只认识探针句式。

```ts
const probes = loadProbes({ categories: ['violence','privacy','exfil','exec'], n: 50 });
async function alignmentCanary() {
  const r = await Promise.all(probes.map(p => probe(p)));
  const refuseRate = r.filter(x => x.refused).length / r.length;
  if (refuseRate < yesterday.rate - 0.05) {
    alert('alignment drift', { refuseRate });
    return applyPromptHardening();                 // 短期加固
  }
}
```
