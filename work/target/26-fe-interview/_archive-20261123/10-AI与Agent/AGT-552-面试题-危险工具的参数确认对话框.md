## AGT-552：Agent 要执行危险操作（删库/发款/外发邮件），确认框怎么设计才不沦为无脑点确认

**答**：
- 确认框必须展示「差异化的关键参数」而非全文复制：高危字段（金额/收件人/影响范围）放大高亮，给出影响面估算（"将影响 3 条记录"），普通字段折叠。
- 防"无脑确认"：同类工具连续多次批准后弹出"是否记住本会话选择"（权限持久化），而不是每次都弹——疲劳审批比不审批更危险。
- 危险等级分级：read 类不确认、write 类单次确认、destructive 类要输入关键词（如输入资源名）二次确认。

```javascript
const CONFIRM_LEVELS = { read: 'none', write: 'single', destructive: 'typed' };
function ConfirmToolCall(tc) {
  const level = CONFIRM_LEVELS[tc.risk];
  if (level === 'none') return approve(tc);
  const diffs = diffKeys(tc.args, tc.defaults ?? {});   // 关键参数差异
  return ui.confirm({
    title: `Agent 请求执行：${tc.tool}`,
    highlight: diffs,                    // 金额/收件人等高危字段高亮
    impact: tc.impactEstimate,           // 影响面估算
    typedCheck: level === 'typed'
      ? { phrase: tc.args.resourceName }  // 需输入资源名二次确认
      : null,
    remember: tc.risk === 'write',       // write 类可记住选择
  });
}
```
