## 982：Agent 流程里哪些步骤可以并行，怎么安全并行

**答**：
- 并行机会识别：数据依赖图里无依赖的节点都可并行——典型如「同时查三个数据源」「多路检索（BM25+向量）」「独立子任务」；串行执行往往只是实现惯性。
- 安全并行的前提：无共享可变状态、下游能接受乱序聚合（用结果标注来源而不是靠顺序）、下游限流能承载并发峰值。
- 延迟收益估算：串行总时长 = Σ各步，并行 = max(各步)；把最慢一步当瓶颈优化（如最慢的数据源单独加缓存）。
- 追问钩子：并行会不会放大故障面？——会，任何一个分支失败都会牵连聚合；用 allSettled + 部分结果降级，别让一个慢源拖死整体。

```ts
async function fanout(tasks, { degrade = true } = {}) {
  const rs = await Promise.allSettled(tasks.map(t => t.run()));
  const ok = rs.filter(r => r.status === 'fulfilled').map(r => r.value);
  if (!ok.length) throw new Error('all branches failed');
  if (degrade && ok.length < tasks.length) {
    metrics.inc('partial_result', tasks.length - ok.length); // 部分结果降级
  }
  return merge(ok);   // 聚合按来源标注，不依赖顺序
}
```
