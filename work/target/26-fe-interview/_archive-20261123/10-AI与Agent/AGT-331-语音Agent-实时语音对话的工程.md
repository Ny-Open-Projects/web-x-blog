## AGT-331：实时语音 Agent（语音进语音出）的工程链路怎么设计？

**答**:
- 链路结构：ASR（流式转写+VAD 断句）→ LLM（对话）→ TTS（流式合成）全双工——延迟是生命线（对话级体验要求端到端 <1.5s）；两个架构选择：级联管线（ASR→LLM→TTS，可控性强）vs 端到端语音模型（延迟低但可控性弱），生产多用级联+各环节流式。
- 打断处理：用户中途插话（barge-in）——VAD 检测到说话即停 TTS 播放、取消当前生成、转写接入新输入；打断的响应速度决定"像不像真人对话"。
- 上下文管理：语音会话的转写历史进 LLM 上下文（含说话人角色），噪声过滤（ASR 错误率会累积污染上下文——重要指令确认机制：关键操作 TTS 复述确认）。
- 成本结构：ASR/TTS 按时长计费——长通话成本高，多模态模型调用（语音直进）与级联的成本对比按场景算；静音段裁剪降本。

```text
语音 Agent 链路：
Mic → VAD断句 → 流式ASR → LLM(流式)
  → 流式TTS → Speaker
延迟预算：<1.5s 端到端（对话级）
打断：VAD 检测 → 停TTS+取消生成
  → 新输入接入
确认机制：关键操作 TTS 复述确认
  （ASR 错误率兜底）。
```
