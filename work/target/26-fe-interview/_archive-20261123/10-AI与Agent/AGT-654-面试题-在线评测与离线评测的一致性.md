## AGT-654：离线评测 92 分的功能上线后用户负反馈率反而涨了，如何校验离线与在线的一致性

**答**：
- 离线评测的盲区：评测集分布≠线上分布（线上长尾/组合复杂度/用户真实问法）、离线判据≠用户判据（judge 觉得好用户未必觉得好）。
- 一致性校验机制：定期把「离线高分但线上负反馈」的配对样本拿出来归因——是评测集缺这个分布，还是判据错了；据此修评测集或修 rubric。
- 在线 interleaving 补充：两个版本对同一用户交替出答案让用户盲选，比 A/B 快且直接反映用户偏好，作为离线分数的在线校验。

```javascript
async function offlineOnlineAudit(window) {
  const pairs = window.filter(r => r.offlineScore > 0.9 && r.onlineBad);
  const causes = await classify(pairs, ['coverage_gap',   // 评测集缺分布
    'rubric_mismatch', 'context_shift']);                  // 判据错/上下文漂移
  if (causes.coverage_gap > 5) addCases(pairs.slice(0, 30)); // 补评测集
  if (causes.rubric_mismatch > 5) reviseRubric(pairs);
}
```
