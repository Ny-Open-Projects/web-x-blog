## 1209：笔试手写：实现按桶下发 Query 策略配置

**需求**：实现 resolveStrategy(uid, route, config)：config = { default: { staleTime, refetch }, overrides: { [routePattern]: {...} }, buckets: { [bucket]: {...} } }。桶 = uid 尾号 %100 <10 ? 'canary' : 'stable'；策略合并顺序：default <- bucket <- route override（后者覆盖前者，浅合并）。返回合并后策略与命中来源。

```js
function resolveStrategy(uid, route, config) {
  const num = Number(String(uid).replace(/\D/g, '').slice(-2) || 0);
  const bucket = num < 10 ? 'canary' : 'stable';
  let s = { ...config.default }, src = ['default'];
  const b = config.buckets[bucket];
  if (b) { s = { ...s, ...b }; src.push('bucket:' + bucket); }
  const ov = Object.entries(config.overrides || {}).find(([p]) =>
    route.startsWith(p));
  if (ov) { s = { ...s, ...ov[1] }; src.push('route:' + ov[0]); }
  return { strategy: s, bucket, sources: src };
}
const cfg = {
  default: { staleTime: 30000, refetch: false },
  buckets: { canary: { staleTime: 0 } },
  overrides: { '/market': { staleTime: 0, refetch: true } },
};
console.log(resolveStrategy('u07', '/market/quote', cfg));
// { strategy: { staleTime: 0, refetch: true }, bucket: 'canary',
//   sources: ['default','bucket:canary','route:/market'] }
```

**评分点**：
- 三层合并顺序正确（default <- bucket <- route，后者覆盖）
- 桶判定（尾号取数与 NaN 保护——uid 无数字时 fallback 0）
- sources 记录命中链（灰度归因）
- 能讨论：策略配置中心的热更新、canary 桶的监控指标分离
