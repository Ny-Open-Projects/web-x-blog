## AGT-875：AI 时代前端工程师的核心能力怎么变（面试常问），如何自证

**答**：
- 能力重心上移：从"会写"到"会判断"——需求拆解与上下文工程（把模糊需求变成 AI 可执行的任务）、产出鉴别力（一眼看出 AI 代码/测试/方案的问题）、系统思维（AI 产出放进系统的边界与影响）。
- 自证方式（面试怎么说）：带数据讲（AI 参与度与质量指标/提效数据）、带案例讲（一次 AI 翻车如何被你发现与修复——鉴别力的最好证明）、带体系讲（你建立的 AI 使用规范/门禁，而不是"我会用 Copilot"）。
- 反向能力不能丢：基础功（性能/原理/手写）仍是鉴别 AI 产出的前提——判断力来自比 AI 更懂。

```javascript
const CAPABILITY_V2 = {
  up: ['需求拆解', '上下文工程', '产出鉴别', '系统思维'],
  keep: ['性能与原理', '架构取舍'],                 // 判断力根基
  proof: (m) => [
    m.metrics ? `AI提效数据：${m.metrics}` : null,
    m.caught ? `鉴别案例：发现AI的${m.caught}` : null,
    m.systems ? `建立规范：${m.systems}` : null,
  ].filter(Boolean),                               // 面试自证三件套
};
```
