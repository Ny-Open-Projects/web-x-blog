## 1079：Agent 长任务的「感知延迟」优化怎么做

**答**：
- 感知延迟 ≠ 实际延迟：总时长 30s 但每 2s 有进度反馈的任务，体验优于 10s 无反馈；优化分实际层（真提速）与感知层（让等待可理解）。
- 进度语义要「真」：显示「正在检索 3 个知识库…」这类真实步骤而不是假进度条——假进度（匀速到 90% 卡住）比没有更伤信任。
- 中间产物先行：检索结果列表先渲染（用户可先浏览来源），答案流式追加——等待被转化为浏览。
- 追问钩子：什么时候不该做感知优化？——高频短任务（<2s）加进度动画反而增加视觉噪音；感知优化留给预期超过 3s 的任务。

```ts
sse.send('phase', { label: '正在检索知识库…', real: true });
const hits = await retrieve(q);
sse.send('artifacts', hits);              // 中间产物先行渲染
sse.send('phase', { label: '正在生成回答…' });
for await (const d of llmStream) sse.send('delta', d);   // 流式追加
```
