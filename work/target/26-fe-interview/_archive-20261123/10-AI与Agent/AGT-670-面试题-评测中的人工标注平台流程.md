## AGT-670：judge 搞不定的用例要人工标注，标注平台与流程怎么设计

**答**：
- 任务分派：按能力域/语言路由到对应标注员；双盲双人标注，分歧进仲裁（第三人或评审会）；标注指南版本化（指南变更后旧标注要标"旧指南"）。
- 质量监控：每标注员有抽检符合率（与金标/共识对比），低于阈值暂停派单回炉培训；标注耗时分布监控（过快=乱标信号）。
- 效率设计：预填 judge 分数让人只做确认/修正（比从零标注快 3 倍），但要防"锚定偏差"（预填分影响判断）——部分任务盲标对照测锚定效应。

```javascript
function annotateTask(case, annotators) {
  const pair = sample(annotators, 2);             // 双盲双人
  return Promise.all(pair.map(a => send(a, {
    case: blindVersion(case),                     // 双盲：不见彼此
    prefill: case.judgeScore,                     // 预填加速
    anchorTest: Math.random() < 0.2,              // 20% 盲标对照
  }))).then(([x, y]) => agree(x, y)
    ? commit(x) : arbitrate(case, x, y));         // 分歧仲裁
}
```
