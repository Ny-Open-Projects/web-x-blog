## AGT-632：trace 采样（10%）后，P95 延迟/错误率还能信吗

**答**：
- 错误率不能靠采样：错误必须 100% 采集（head sampling 会漏稀有错误）；延迟分位数可以用采样估计但样本量要够（P95 稳定需要 ~1000+ 样本/窗口），尾部（P99）采样偏差大，建议尾延迟用全量指标（直方图）而非 trace 推算。
- 采样偏差校正：若按「高成本任务加权采样」，统计前要按采样率反加权（每个样本除以它的采样概率），否则高成本任务占比虚高。
- 结论：trace 用于排查（可采样），metrics 用于统计（全量），两者别混。

```javascript
function unbiasedAggregate(samples) {
  // 反加权：样本代表 1/p 个真实请求
  const weighted = samples.map(s => ({ ...s, w: 1 / s.sampleProb }));
  const p95 = weightedPercentile(weighted, 'latency', 0.95);  // 加权分位
  return { p95, n: sum(weighted, 'w') };        // 有效样本量
}
```
