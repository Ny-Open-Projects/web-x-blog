## AGT-780：企业要求提供记忆系统合规报告（记了什么/谁有权访问/删除SLA），怎么产出

**答**：
- 三张报告：内容清单（按用户/按字段统计记忆条数与类别，不含明文——明文只有用户自己可见）、访问审计（谁/何时/以什么目的读取记忆，DPO 可查）、删除 SLA（用户删除请求的完成时间分布，承诺 24h 内全层级联）。
- 自动化产出：审计事件流（读/写/删全埋点）定期聚合成报告，异常访问（单用户批量拉取他人记忆）实时告警。
- 合规证据链：每条记忆可追溯到「来源会话+蒸馏版本+准入依据」（为什么这条被记住了），应对监管问询。

```javascript
async function complianceReport(period) {
  return {
    inventory: memoryStats({ by: 'field', hashed: true }),
    access: audit.query({ type: 'memory.read', period,
      anomalies: bulkReadDetectors() }),
    deletionSla: slaDistribution({ type: 'memory.forget', period }),
    provenance: (id) => memory.provenance(id),      // 来源+蒸馏版本
  };
}
```
