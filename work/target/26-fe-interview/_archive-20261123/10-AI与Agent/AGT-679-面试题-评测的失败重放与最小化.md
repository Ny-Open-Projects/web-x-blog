## AGT-679：一个失败用例包含 20 轮长对话，如何最小化到可调试的最小复现

**答**：
- 二分裁剪：从完整对话逐步删轮次/删上下文片段，每删一次重跑，仍失败则保留删除——直到最小失败集（类似测试最小化 delta debugging）。
- 裁剪保序：删除不能破坏语义连贯（裁剪后输入对模型是合理提问），裁剪验证器把关；裁剪结果存为「最小复现用例」挂到原用例下。
- 价值：最小复现让归因从"读 20 轮对话找问题"变成"看 3 条消息"，也便于提示词修复时精确验证。

```javascript
async function minimize(failingCase) {
  let cur = failingCase.turns;
  for (let size = cur.length - 1; size >= 2; size--) {
    const subset = pickMostInformative(cur, size);   // 保留关键轮
    if (validConversation(subset)                     // 裁剪验证器
      && await stillFails({ ...failingCase, turns: subset }))
      cur = subset;
  }
  return { minimal: cur, parent: failingCase.id };
}
```
