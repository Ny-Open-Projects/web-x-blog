## AGT-759：个人记忆之外，团队共享记忆（团队规范/项目上下文）如何管理

**答**：
- 三域分离：个人记忆（私有）、团队记忆（规范/术语/决策记录，管理员治理）、项目记忆（项目上下文，成员可见）；检索时个人+团队+项目三级合并，个人偏好可覆盖团队默认但合规约束不可覆盖。
- 团队记忆治理：写入需审核（防止个人把错误"事实"写进团队库），版本化+变更通知（规范更新后所有成员的 Agent 自动感知）。
- 冲突顺序：约束 > 显式配置 > 团队规范 > 个人偏好 > 模型默认。

```javascript
function mergeMemories(user, team, project) {
  return precedence([
    user.constraints,          // 约束最高
    user.explicit, team.norms, project.context,
    user.preferences,          // 个人偏好最低
  ], { conflict: 'higher-wins',
    audit: (k, from) => log(`采纳 ${k} 来自 ${from}`) });
}
async function publishTeamNorm(norm) {
  await review(norm);                             // 写入需审核
  await teamNorms.publish(norm.versioned());
  notifyAll(norm.members, { type: 'norm-update', ver: norm.version });
}
```
