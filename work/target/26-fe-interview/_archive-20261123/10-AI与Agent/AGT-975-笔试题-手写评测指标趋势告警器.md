## 975：笔试手写：实现指标日环比趋势告警（含噪声过滤）

**需求**：实现 alert(series, cfg)：series 为按日的 { day, value }[]（按时间升序）。规则：今日环比昨日降幅超过 cfg.dropPct（如 0.03）触发；但若「昨日相对前日上涨超过 cfg.risePct」（脉冲噪声，今日回落属正常）则抑制告警；连续 3 天下降即使单日未超阈值也告警（慢性漂移）。输出告警列表带 reason。

```js
function alert(series, cfg) {
  const out = [];
  for (let i = 2; i < series.length; i++) {
    const [d2, d1, d0] = [series[i - 2].value, series[i - 1].value, series[i].value];
    const dayDrop = (d1 - d0) / d1;
    const prevRise = (d1 - d2) / d2;
    if (dayDrop > cfg.dropPct) {
      if (prevRise > cfg.risePct) continue;              // 脉冲回落，抑制
      out.push({ day: series[i].day, reason: `drop ${(dayDrop * 100).toFixed(1)}%` });
    }
  }
  // 慢性漂移：最近 3 日连续下降（允许单日波动小）
  const last3 = series.slice(-3).map(s => s.value);
  if (last3.length === 3 && last3[0] > last3[1] && last3[1] > last3[2]) {
    const total = (last3[0] - last3[2]) / last3[0];
    if (total > cfg.chronicPct) out.push({ day: series.at(-1).day,
      reason: `chronic drift ${(total * 100).toFixed(1)}% in 3d` });
  }
  return out;
}
alert([{day:1,value:100},{day:2,value:130},{day:3,value:95}], { dropPct:0.03, risePct:0.1, chronicPct:0.05 });
// day3 环比降 27%，但 day2 涨了 30%（脉冲）-> 抑制，无告警
```

**评分点**：
- 脉冲抑制逻辑方向正确（前日大涨 + 今日回落 = 噪声）
- 慢性漂移检测独立于单日阈值，覆盖「温水煮青蛙」
- 除零保护（d1、d2 为 0 时跳过或记 0）
- 能讨论参数经验值：dropPct 3%~5% 视指标波动性、chronicPct 通常更宽松（5%~10%）
