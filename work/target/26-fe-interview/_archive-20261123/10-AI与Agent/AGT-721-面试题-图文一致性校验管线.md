## AGT-721：入库的图片描述/提取数据如何定期校验与原图的一致性（防模型升级后漂移）

**答**：
- 一致性巡检：抽样重跑「描述生成→对比存储描述」，漂移大（语义相似度跌）的批量重生成；巡检频率跟随 vision 模型版本变更触发。
- 数值类强校验：提取的数据序列与原图 OCR 数字逐点比对（数值错=事故），不一致立即修复。
- 巡检成本控制：只巡检「被实际引用过」的资产（低频资产漂移无感知），引用频次作为巡检优先级。

```javascript
async function consistencyPatrol({ full = false } = {}) {
  const assets = full ? allAssets()
    : topUsedAssets({ by: 'citationCount', n: 500 }); // 引用优先
  const bad = [];
  for (const a of assets) {
    const fresh = await regenerate(a);
    if (a.kind === 'data' && !numbersMatch(a.data, fresh.data))
      bad.push({ ...a, fix: 're-extract' });       // 数值错立即修
    else if (semSim(a.desc, fresh.desc) < 0.85)
      bad.push({ ...a, fix: 're-describe' });
  }
  return { checked: assets.length, bad,
    action: bad.length / assets.length > 0.1
      ? 'vision_model_drift' : null };
}
```
