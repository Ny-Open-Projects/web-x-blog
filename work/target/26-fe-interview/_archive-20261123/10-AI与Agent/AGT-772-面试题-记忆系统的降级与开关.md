## AGT-772：记忆服务故障时，Agent 如何降级运行（无记忆模式的质量保障）

**答**：
- 降级阶梯：记忆检索超时→跳过记忆只留会话上下文；画像服务故障→用默认风格模板；全部故障→无记忆模式+UI 提示"个性化暂不可用"。降级开关在网关，熔断自动触发。
- 无记忆模式的质量兜底：系统提示补「保守通用风格」指令（不给个性化指令时模型别乱猜用户身份），敏感场景（用户提到"我之前说过"）引导用户重述而非编造。
- 降级可观测：降级率与降级期间的质量指标单独统计（降级不该背质量的锅，但要知道降级多不多）。

```javascript
async function withMemoryFallback(task) {
  try {
    const mem = await memoryService.retrieve(task, { timeout: 800 });
    return { mem, mode: 'full' };
  } catch (e) {
    meter.count('memory.degraded', { at: e.name });
    return { mem: [], mode: 'no-memory',
      promptSuffix: '（个性化暂不可用：请使用通用专业风格；'
        + '用户提及历史信息时请请其补充，不要假设。）' };
  }
}
```
