## 1254：笔试手写：实现 工具注册表完整性校验器

**需求**：实现 validateRegistry(tools)：tools 为 { name, description, params: { key: { type, required, enum? } } }[]。校验：name 唯一且符合 ^[a-z_]{3,32}$；description 非空且 >= 20 字；params 至少 1 个；required 字段必须存在于 params；enum 存在时 type 必须为 string。返回 { valid, errors: [{ name, reason }] }。

```js
function validateRegistry(tools) {
  const errors = [];
  const seen = new Set();
  for (const t of tools) {
    if (!/^[a-z_]{3,32}$/.test(t.name)) errors.push({ name: t.name, reason: '命名不合法' });
    if (seen.has(t.name)) errors.push({ name: t.name, reason: '重名' });
    seen.add(t.name);
    if (!t.description || t.description.length < 20)
      errors.push({ name: t.name, reason: '描述缺失或过短' });
    const keys = Object.keys(t.params || {});
    if (!keys.length) errors.push({ name: t.name, reason: '无参数定义' });
    for (const k of keys) {
      const p = t.params[k];
      if (p.enum && p.type !== 'string')
        errors.push({ name: t.name, reason: `enum 仅支持 string: ${k}` });
    }
    // required 校验：约定 params 内 required 数组或布尔均可，这里按布尔
    for (const k of keys) {
      if (t.params[k].required === true && !(k in t.params))
        errors.push({ name: t.name, reason: 'required 指向自身外的字段缺失' });
    }
  }
  return { valid: errors.length === 0, errors };
}
```

**评分点**：
- 唯一性与命名规范前置（模型靠 name 路由）
- 描述长度下限的工程意义（模型选工具的依据）
- enum 与 type 的联动校验
- 能讨论：注册表校验应进 CI，与工具描述投毒防线（AGT-1003）互补
