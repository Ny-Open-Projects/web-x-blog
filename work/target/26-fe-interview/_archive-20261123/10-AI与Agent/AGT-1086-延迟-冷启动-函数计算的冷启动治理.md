## 1086：Agent 网关跑在函数计算上，冷启动怎么治

**答**：
- 冷启动成本构成：运行时启动 + 依赖加载（SDK/模型客户端初始化，常占大头）+ 首请求建连；治理三板斧：预留实例（保底并发避免冷启动）、精简依赖（客户端 SDK 惰性初始化）、快照恢复（内存快照秒级拉起）。
- Agent 特有：prompt 模板与工具定义编译产物缓存在实例内存，冷启动会丢失——把编译产物外置到缓存服务，实例拉起后 10ms 内回填。
- 触发频率低的功能（如管理后台的 AI 功能）不值得为冷启动付费，接受首次请求慢 + loading 提示。
- 追问钩子：预留实例的钱和冷启动的体验怎么平衡？——按「冷启动发生的时段分布」付费：预留覆盖高峰，低谷释放；监控冷启动率（目标 1% 以下），超标加预留。

```ts
// 惰性初始化：首次请求才建重依赖
let client; // 模块级缓存
async function handler(req) {
  client ??= await initHeavyClient();       // 实例复用期内只初始化一次
  return client.chat(req.body);
}
// 预留并发保底
provider.reserve({ minConcurrency: 2, metric: 'cold_start_rate', target: 0.01 });
```
