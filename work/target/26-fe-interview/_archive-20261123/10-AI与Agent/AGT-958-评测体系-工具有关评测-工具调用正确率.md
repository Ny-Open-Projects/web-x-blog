## 958：Agent 的工具调用怎么评测

**答**：
- 三个层次：选对工具没有（工具选择准确率）、参数对不对（参数 F1：必填全、类型对、值合理）、序列合理吗（调用顺序、冗余调用、死循环）。
- 评测方式：mock 工具环境回放——把真实工具替换成 mock（固定返回、记录调用），断言「调用序列 + 参数」与标注一致；mock 让评测可重复且零成本。
- 失败容错也评：工具报错后 Agent 的重试/换路是否合理，好的 Agent 在 mock 返回 500 时应重试或降级而不是放弃。
- 追问钩子：为什么不能直接连真实工具测？——副作用不可回滚（真实发消息、改数据），且结果不确定导致评测不可重复。

```ts
function makeMockTool(name, canned) {
  const calls = [];
  return { calls, impl: async (...args) => { calls.push({ name, args });
    return canned.shift() ?? { error: 500 }; } };  // 记录调用供断言
}
// 断言示例：先搜索后读取，且没有冗余第二次搜索
expect(calls.map(c => c.name)).toEqual(['search', 'read']);
```
