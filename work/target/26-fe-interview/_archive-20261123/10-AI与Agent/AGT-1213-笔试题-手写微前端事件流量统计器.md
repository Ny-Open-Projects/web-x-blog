## 1213：笔试手写：实现总线事件的发布/订阅扇出统计

**需求**：实现 FlowMeter：instrument(bus)（包装 publish 与 subscribe 记录）；report() 输出每事件 { publishes, subscribers, fanout }（fanout=publishes×subscribers）与 deadEvents（subscriber=0 的事件列表）、hotEvents（fanout top3）。

```js
class FlowMeter {
  constructor(bus) {
    this.pub = {}; this.subs = bus._subsMap || {};
    const orig = bus.publish.bind(bus);
    bus.publish = (event, payload) => {
      this.pub[event] = (this.pub[event] || 0) + 1;
      return orig(event, payload);
    };
  }
  report() {
    const rows = Object.keys(this.pub).map(e => ({
      event: e, publishes: this.pub[e],
      subscribers: (this.subs[e]?.size) || 0,
    }));
    rows.forEach(r => r.fanout = r.publishes * r.subscribers);
    return {
      rows,
      deadEvents: rows.filter(r => r.subscribers === 0 && r.publishes > 0)
        .map(r => r.event),
      hotEvents: [...rows].sort((a, b) => b.fanout - a.fanout)
        .slice(0, 3).map(r => r.event),
    };
  }
}
// 用法：new FlowMeter(bus) 包装后跑一个会话，report() 治理看板
// deadEvents -> 事件下线候选；hotEvents -> 耦合热点评审
```

**评分点**：
- publish 包装不改语义（透传）
- deadEvents（零订阅死事件——清理候选）与 hotEvents（高扇出耦合热点）双指标
- subscriber 计数实时性（包装 subscribe 更严谨——讨论项）
- 能讨论：事件治理的量化依据（死事件删/热点拆）、采样窗口与统计偏差
