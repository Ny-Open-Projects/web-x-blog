## 1104：外部 Agent 安全情报（新攻击手法）怎么吸收进自家防线

**答**：
- 吸收流程四步：情报评估（与本系统攻击面相关性——不是所有新手法都适用）、复现验证（在预发环境复现，确认自家是否受影响）、防线决策（修 or 接受风险，附理由）、回归入库（手法转红队用例，永久看护）。
- 时效 SLA：高危手法（可执行任意动作类）48h 内完成复现与决策，一般手法一周——没有 SLA 的情报流程等于没有。
- 情报源分级：官方通告（供应商安全公告）> 社区验证报告（有复现细节）> 自媒体转述（需自行验证）；每条情报记录来源等级。
- 追问钩子：情报吸收和自家红队的关系？——互补：外部情报是「别人的子弹」，红队是「自制子弹」；两者都进同一个攻击知识库，避免重复建设。

```ts
async function absorbIntel(intel) {
  const rel = relevance(intel, ourAttackSurface);
  if (!rel.applicable) return archive(intel, '不适用，理由：' + rel.reason);
  const repro = await reproduce(intel, staging);
  const decision = repro.vulnerable ? fixAndGate(intel) : acceptRisk(intel, repro);
  await redteam.add(toCase(intel));                 // 永久看护
  return decision;
}
```
