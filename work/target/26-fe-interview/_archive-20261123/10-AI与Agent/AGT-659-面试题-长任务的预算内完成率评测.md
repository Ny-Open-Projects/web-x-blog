## AGT-659：Agent 长任务评测不能只看做没做对，还要看花多少，预算内完成率怎么评测

**答**：
- 双约束评测：正确性（结果达标）+ 预算（tokens/成本/轮次/时长上限）；产出四象限——预算内正确（理想）、预算内错误、超预算正确（质量好但贵）、超预算错误（最差）。只报完成率会掩盖"靠烧钱做对"的版本。
- 预算档位曲线：同一任务在宽松/标准/紧张三档预算下跑，得到「预算-质量曲线」，看版本的性价比而不是单点。
- 轮次浪费分析：超预算的案例聚类原因（循环调用/过度检索/重试风暴），反哺运行时限制。

```javascript
async function evalWithBudget(cases, budgets) {
  return pMap(cases, async (c) => {
    const runs = await Promise.all(budgets.map(b =>
      runAgentCase(c, { maxTokens: b })));         // 三档预算
    return { case: c.id,
      curve: runs.map((r, i) => ({ budget: budgets[i],
        ok: r.correct, tokens: r.usage.total })), // 预算-质量曲线
      quadrant: classify(runs[1], { budget: budgets[1] }),
    };
  });
}
```
