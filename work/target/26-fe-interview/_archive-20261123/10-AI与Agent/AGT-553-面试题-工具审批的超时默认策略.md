## AGT-553：工具审批等待用户确认超时（如用户离开工位），默认策略怎么设计

**答**：
- 默认策略按风险反着来：高危操作超时=自动拒绝并告知原因（宁可任务暂停，不可默认放行）；低危只读操作超时=自动放行并在时间线上标注"超时自动通过"。
- 超时不是简单取消：任务进入 paused 状态保留上下文，用户回来可以"继续审批"而不是从头跑——Agent 任务的前几步工具结果都在。
- 超时策略要可配置（租户/会话级），且默认值写进产品文档，审计日志记录每次自动决策。

```javascript
const TIMEOUT_POLICY = {
  read:       { action: 'approve', note: '只读操作超时自动通过' },
  write:      { action: 'pause',   note: '写入操作超时挂起，回来可继续' },
  destructive:{ action: 'reject',  note: '高危操作超时自动拒绝' },
};
async function onApprovalTimeout(tc) {
  const p = TIMEOUT_POLICY[tc.risk];
  audit.log({ tool: tc.tool, risk: tc.risk, auto: p.action, at: Date.now() });
  if (p.action === 'pause') return task.pause(`等待审批：${tc.tool}`);
  return p.action === 'approve' ? approve(tc, { auto: true })
    : reject(tc, { auto: true, reason: '审批超时自动拒绝' });
}
```
