## AGT-391：数据库 Agent 除了 Text2SQL，还有哪些高价值能力？

**答**:
- 能力清单：schema 理解与血缘问答（"这个字段上游是谁在写"——元数据+血缘图的问答）、慢查询诊断（执行计划解读+优化建议——只读诊断）、数据校验助手（跨表一致性检查 SQL 生成——只读）、变更脚本辅助（DDL/迁移脚本生成——写操作强人审+预演 dry-run）。
- 安全骨架：只读账号分权（查询类全自动走只读账号）、写操作白名单+dry-run 预演+人审（AGT-286）、行级权限注入（Agent 的查询自动带用户数据权限 AGT-217）、审计全留痕（每条 SQL 与结果可追溯）。
- 防误伤：危险语句模式拦截（无 WHERE 的 UPDATE/DELETE、TRUNCATE/DROP——程序级拦截不靠 prompt）、影响面预估（变更前 EXPLAIN/行数估算呈现给人）。
- 评测：SQL 正确率金标集（AGT-304 同款）、诊断建议的采纳率、危险拦截的漏报率（安全红线零容忍）。

```text
数据库 Agent 能力域：
问答：schema/血缘 / 慢查询诊断 / 校验助手
变更：脚本生成 → dry-run 预演 → 人审
安全：只读账号分权 / 行级 ACL 注入 /
  危险语句程序级拦截 / 全审计
评测：SQL 金标集 / 采纳率 /
  危险拦截漏报率（零容忍）。
```
