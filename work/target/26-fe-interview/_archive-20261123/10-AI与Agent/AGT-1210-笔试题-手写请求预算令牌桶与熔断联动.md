## 1210：笔试手写：实现带熔断的令牌桶请求调度

**需求**：实现 BudgetedScheduler(limit, rate, breakerAfter)：take(fn) 令牌不足排队；连续 breakerAfter 次「等待超时」（排队超 500ms 未执行）触发熔断（isBroken()=true，后续 take 直接 reject，直到 reset）。执行完释放槽位并 drain 队列。

```js
class BudgetedScheduler {
  constructor(limit, rate, breakerAfter = 3) {
    this.limit = limit; this.active = 0; this.q = [];
    this.breakerAfter = breakerAfter; this.timeouts = 0;
    this.broken = false;
  }
  isBroken() { return this.broken; }
  reset() { this.broken = false; this.timeouts = 0; }
  take(fn, waitMs = 500) {
    if (this.broken) return Promise.reject(new Error('breaker open'));
    return new Promise((resolve, reject) => {
      const entry = { fn, resolve, reject, enqueuedAt: Date.now(), timer: null };
      const tryStart = () => {
        if (this.broken) return reject(new Error('breaker open'));
        if (this.active < this.limit) {
          this.active++;
          clearTimeout(entry.timer);
          fn().then(resolve, reject).finally(() => {
            this.active--; this._drain();
          });
          return true;
        }
        return false;
      };
      if (!tryStart()) {
        entry.timer = setTimeout(() => {
          // 排队超时：从队列移除并计数
          const i = this.q.indexOf(entry);
          if (i !== -1) this.q.splice(i, 1);
          this.timeouts++;
          if (this.timeouts >= this.breakerAfter) this.broken = true;
          reject(new Error('queue timeout'));
        }, waitMs);
        this.q.push(entry);
      }
    });
  }
  _drain() {
    while (this.active < this.limit && this.q.length && !this.broken) {
      const e = this.q.shift();
      clearTimeout(e.timer);
      this.active++;
      e.fn().then(e.resolve, e.reject).finally(() => { this.active--; this._drain(); });
    }
  }
}
```

**评分点**：
- 排队超时计数 -> 熔断联动（连续超时阈值——防风暴的结构）
- 超时 entry 从队列移除（防 drain 后重复执行——漏移除是双重执行 bug）
- 熔断后 take 直接 reject（fail-fast）与 reset 恢复
- 能讨论：熔断恢复的探测策略（半开状态）、与限流器（令牌速率）的组合分工
