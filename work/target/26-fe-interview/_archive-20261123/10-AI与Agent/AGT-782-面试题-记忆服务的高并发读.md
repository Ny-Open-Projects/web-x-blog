## AGT-782：记忆检索在高并发下的性能设计（缓存/分区/降采样）

**答**：
- 三级缓存：画像热缓存（内存，命中率最高）、语义记忆向量检索缓存（query 哈希短 TTL）、情景检索按需；缓存键带用户版本号（画像更新即失效）。
- 分区与限流：按用户分片（检索天然按用户隔离），单用户限流防脚本；高峰期语义检索降采样（topK 减半）而不是拒绝服务。
- 一致性窗口：缓存带来的画像延迟更新可接受（秒级），但「删除」必须同步失效所有缓存（删除不被缓存是合规红线）。

```javascript
async function retrieveCached(userId, query, { budget }) {
  const ver = await profile.version(userId);        // 版本号进键
  const key = hash([userId, ver, query, budget]);
  return cache.through(key, () => vector.search(embed(query), {
    filter: { userId }, topK:高峰期() ? 5 : 10,     // 降采样不拒服务
  }), { ttl: 60e3 });
}
async function forgetUser(userId) {
  await memory.purge(userId);
  await cache.bustPrefix(`mem:${userId}:`);         // 删除同步失效
}
```
