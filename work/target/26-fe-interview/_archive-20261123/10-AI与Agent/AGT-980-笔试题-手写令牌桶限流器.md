## 980：笔试手写：实现支持突发与优先级的令牌桶

**需求**：实现 TokenBucket(capacity, refillPerSec)：take(n) 同步判断能否立即取（能则扣减返回 true）；tryTakeFor(n, waitMs) 在时限内等待 refill 后重试；refill 按流逝时间线性补充不超过容量。线程安全性可用单线程事件循环假设说明。

```js
class TokenBucket {
  constructor(capacity, refillPerSec) {
    this.cap = capacity; this.rate = refillPerSec;
    this.tok = capacity; this.last = Date.now();
  }
  refill() {
    const now = Date.now();
    this.tok = Math.min(this.cap, this.tok + ((now - this.last) / 1000) * this.rate);
    this.last = now;
  }
  take(n = 1) {
    this.refill();
    if (this.tok >= n) { this.tok -= n; return true; }
    return false;
  }
  tryTakeFor(n, waitMs) {
    const deadline = Date.now() + waitMs;
    while (Date.now() < deadline) {
      if (this.take(n)) return true;
      const needMs = ((n - this.tok) / this.rate) * 1000;  // 补够还需多久
      await sleep(Math.min(needMs, 50, deadline - Date.now()));
    }
    return this.take(n);   // 最后再试一次
  }
}
const b = new TokenBucket(5, 1);
console.log(b.take(3), b.take(3)); // true false（容量5取3后再取3不够）
```

**评分点**：
- refill 按时间线性补充且封顶容量（不能一次睡久就白嫖满桶）
- tryTakeFor 的等待时间估算基于缺口量而非固定轮询
- 容量语义：允许突发（初始满桶）但拒绝超容量请求
- 能讨论：单线程 JS 无锁竞态问题；多实例部署时令牌桶要下沉到 Redis（分布式限流）
