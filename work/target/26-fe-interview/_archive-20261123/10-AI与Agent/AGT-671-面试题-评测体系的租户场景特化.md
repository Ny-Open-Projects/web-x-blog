## AGT-671：通用评测集之外，如何为大客户/特定场景建专属评测集

**答**：
- 特化三层：客户专属用例（客户提供的真实业务问法脱敏后入库）、行业模板（金融/医疗等合规话术与拒答规则）、租户配置判据（同一问题不同租户期望不同答案口径）。
- 优先级：客户专属集跑在客户灰度与专属模型路由上；通用集保底。客户续约/投诉高的租户优先建专属集。
- 维护责任：客户专属集由 CS 与评测组共建，客户业务变更（产品下线/政策变化）触发用例同步——过期用例比没有更糟。

```javascript
function tenantEval(tenant) {
  return {
    cases: [...tenant.providedCases.filter(desensitized),
      ...INDUSTRY_TEMPLATES[tenant.industry]],
    rubric: mergeRubric(BASE_RUBRIC, tenant.configRubric), // 口径特化
    trigger: ['tenant-canary', 'tenant-complaint', 'quarterly'],
  };
}
function retireStale(tenantCases, tenantChangelog) {
  return tenantCases.filter(c =>
    !stale(c, tenantChangelog));                  // 业务变更触发退役
}
```
