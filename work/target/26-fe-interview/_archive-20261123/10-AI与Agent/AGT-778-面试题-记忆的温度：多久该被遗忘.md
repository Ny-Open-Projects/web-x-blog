## AGT-778：记忆不是越多越好，遗忘策略怎么设计（衰减/主动遗忘/负反馈遗忘）

**答**：
- 三种遗忘：自然衰减（长期未引用的记忆降权，检索时几乎不出现）、主动遗忘（用户删除/修正）、负反馈遗忘（用户否认的记忆立即降置信，连续否认即删除——"我不是前端"被否认两次就该消失）。
- 衰减不是删除：衰减的记忆保留在库（用户可能需要），只是检索分打折；删除是不可逆的明确操作。
- 遗忘的评测：记忆库膨胀率 vs 回答质量曲线——库无限膨胀通常检索质量先降，找到拐点设定库容量策略。

```javascript
async function decayPass() {
  const stale = await semantic.unreferencedSince(180 * 864e5);
  await Promise.all(stale.map(m =>
    semantic.decay(m.id, { factor: 0.5 })));         // 衰减不删除
}
async function onDenial(memId) {
  const m = await semantic.get(memId);
  if (++m.denials >= 2) await semantic.delete(memId); // 连续否认删除
  else await semantic.decay(memId, { factor: 0.3 });  // 一次先降权
}
```
