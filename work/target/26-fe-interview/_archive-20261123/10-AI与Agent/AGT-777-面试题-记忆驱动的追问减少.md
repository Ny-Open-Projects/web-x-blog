## AGT-777：好的记忆应该让用户少追问（如我上次说过用TS），如何量化与优化追问减少率

**答**：
- 定义追问减少率：个性化组中"重复提供已知信息"的轮次占比 vs 对照组——用户重复说"用 TypeScript"就是记忆失职的信号。
- 自动检测：识别用户消息中的「已知信息重复」（消息内容与画像字段重合且是陈述性），记为 missed-memory 事件；按字段聚合找记忆盲区。
- 优化闭环：missed-memory 高的字段提高其检索权重/注入优先级，并验证该字段蒸馏质量（可能是蒸馏漏了而不是检索漏了）。

```javascript
function detectRepeat(msg, profile) {
  const known = profile.facts.filter(f =>
    isStatedIn(msg.text, f.statement));
  if (known.length)
    track('missed_memory', { fields: known.map(f => f.key) });
  return known;
}
function optimizeBlindField(field) {
  const bl = missedStats.byField(field);
  if (bl.distillQuality < 0.8) fixDistill(field);   // 蒸馏漏了
  else bumpRetrievalWeight(field, bl.rate);          // 检索权重不足
}
```
