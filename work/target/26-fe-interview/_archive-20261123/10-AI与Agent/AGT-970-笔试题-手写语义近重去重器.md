## 970：笔试手写：用 Jaccard 相似度做评测题去重

**需求**：实现 dedupe(items, threshold=0.85)：items 为 { id, text }[]，text 先转字符 3-gram 集合，两两计算 Jaccard 相似度，相似度 ≥ 阈值视为重复，保留先出现者。要求 O(n^2) 可接受但给出优化思路；返回 { kept, dropped }。

```js
function grams(text, n = 3) {
  const s = new Set();
  for (let i = 0; i <= text.length - n; i++) s.add(text.slice(i, i + n));
  return s;
}
function jaccard(a, b) {
  let inter = 0;
  for (const g of a) if (b.has(g)) inter++;        // 遍历小集合更优
  return inter / (a.size + b.size - inter || 1);
}
function dedupe(items, threshold = 0.85) {
  const kept = [], dropped = [], keptG = [];
  for (const it of items) {
    const g = grams(it.text);
    const dup = keptG.some(k => jaccard(k.g, g) >= threshold);
    dup ? dropped.push(it) : (kept.push(it), keptG.push({ id: it.id, g }));
  }
  return { kept, dropped };
}
const items = [{ id: 1, text: '如何配置灰度发布' }, { id: 2, text: '怎样配置灰度发布？' }];
console.log(dedupe(items).dropped.length > 0); // true（3-gram 高度重叠）
```

**评分点**：
- 3-gram 集合构建正确（中文无需分词，字符级即可）
- Jaccard 分母是并集大小，除零保护
- 保留先出现者的语义正确；dropped 不丢失（可回溯）
- 优化讨论：LSH/MinHash 分桶降为近似 O(n)、长度差过大先剪枝
