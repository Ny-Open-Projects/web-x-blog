## AGT-563：打字机效果按 token 直渲染会卡，如何做节流与帧率控制

**答**：
- delta 进缓冲区，rAF 每帧最多消费固定字符数（自适应：缓冲越长消费越快，追赶积压），渲染帧率稳定在 ~60fps 而不是随 token 速率抖动。
- 完成时冲刷缓冲（flush），保证最终内容完整；中途 abort 也冲刷，保留已收内容。
- 光标动画用 CSS transform 独立层，不随文本重绘；大文本（>10k 字）流式期间切换到分块渲染。

```javascript
class TypeWriter {
  constructor(el) { this.buf = ''; this.el = el; this.pos = 0; this.loop(); }
  push(delta) { this.buf += delta; }
  loop = () => {
    if (this.buf.length) {
      // 自适应步长：积压越多每帧吐越多，避免越追越远
      const step = Math.max(1, Math.ceil(this.buf.length / 30));
      this.el.textContent += this.buf.slice(0, step);
      this.buf = this.buf.slice(step);
    }
    requestAnimationFrame(this.loop);
  };
  flush() { this.el.textContent += this.buf; this.buf = ''; }
}
```
