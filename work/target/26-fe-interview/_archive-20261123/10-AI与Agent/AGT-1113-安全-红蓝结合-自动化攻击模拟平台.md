## 1113：自动化攻击模拟（LLM 红队）平台怎么搭

**答**：
- 平台三能力：攻击生成（LLM 基于手法模板自动变异出攻击变体——改写、编码、拼接）、执行编排（变体批量打目标 Agent，收集响应）、判定（规则判定高危类，LLM 裁判判定约束违反类）。
- 变体配额：每手法族保底 50 个活跃变体（定期轮换防过拟合），高价值手法（间接注入）300+；变体命中即转正式用例。
- 与 CI 集成：防线变更触发相关手法族模拟（增量），夜间全家族扫描；「新手法首杀」要能告警到值班。
- 追问钩子：攻击模拟会不会误伤生产？——模拟流量打影子环境 + 标记隔离；打生产的仅限只读探测类，副作用类永远在沙箱。

```ts
const platform = {
  generate: async fam => llmMutate(fam.templates, { variants: fam.quota }),
  run: async variants => shadowAttack(variants, { env: 'staging', tagged: true }),
  judge: async results => classify(results, { rule: HIGH_RISK, llm: RESTRAINT }),
  promote: hit => { redteam.add(hit); alert('new_bypass', hit); }, // 首杀告警
};
```
