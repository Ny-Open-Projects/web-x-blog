## AGT-715：含公式（数学/化学）的文档如何检索与回答（LaTeX/结构式）

**答**：
- 公式统一规范化：OCR/解析出的公式转 LaTeX 标准形式存储，索引时「LaTeX 文本 + 语义描述（"贝叶斯定理公式"）」双表示——纯 LaTeX 字符串检索无法匹配自然语言提问。
- 渲染一致性：回答中引用公式必须用同一渲染器（KaTeX/MathJax），流式场景未闭合公式走挂起态（前面 AGT-564 联动）。
- 化学结构式：转 SMILES 标准串做精确检索，图示做描述索引；名称/SMILES/结构图三向映射。

```javascript
function indexFormula(formula, ctx) {
  const latex = normalizeLatex(formula);           // 规范化
  return {
    latex,
    desc: `${ctx.topic}的公式：${formulaName(latex)}`, // 语义描述索引
    render: 'katex',                               // 渲染器统一
  };
}
// 化学式：SMILES 精确检索
function indexMolecule(mol) {
  return { smiles: toSmiles(mol), name: mol.name,
    desc: `${mol.name}结构式` };
}
```
