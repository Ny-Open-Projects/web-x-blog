## AGT-816：给平台运营方（SaaS 团队）看的报表体系（增长/健康/收入/成本）

**答**：
- 四象限：增长（新租户/活跃用户/任务量趋势）、健康（各租户 SLA 达成/错误率/工单量）、收入（MRR/用量超费/续约风险预警——用量骤降是流失信号）、成本（模型成本/毛利按租户，识别亏损租户）。
- 报表钩子：异常自动标注（某租户成本翻倍/用量骤降 50%）而不是让人看曲线发现；每指标可下钻到租户明细。
- 运营动作闭环：亏损租户标记后触发定价/优化动作（提示词压缩/缓存策略建议），报表给结论也给行动。

```javascript
function opsDashboard(month) {
  return {
    growth: { newTenants, activeUsers, tasksTrend },
    health: { slaByTenant, errorTopN },
    revenue: { mrr, overage,
      churnRisk: tenantsWith({ usageDrop: '>50%' }) },
    cost: { gross: costByTenant, margin,
      losing: tenantsWith({ margin: '<0' })        // 亏损租户
        .map(t => ({ ...t, action: 'pricing-or-optimize' })) },
  };
}
```
