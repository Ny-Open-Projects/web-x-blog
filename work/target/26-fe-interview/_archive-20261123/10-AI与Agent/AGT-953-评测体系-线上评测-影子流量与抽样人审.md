## 953：评测集之外，线上怎么持续评测

**答**：
- 影子评测：线上真实流量复制一份到候选版本跑，结果不返回用户、只记 diff——新版本在「真实分布」上验证，比离线评估集更接近实战。
- 抽样人审：按风险分层抽样（高风险场景 100% 审、低风险 1% 抽），审的不是全量而是「裁判与模型分歧」的样本，人审效率最高。
- 代理指标监控：点踩率、重问率、转人工率是免费的「用户裁判」，趋势异常要能自动关联到当天的版本变更。
- 追问钩子：影子流量的结果能直接当上线依据吗？——能提供证据但不能只看它：影子环境可能缺真实副作用（支付、外发），副作用类路径仍需灰度验证。

```ts
async function shadow(realReq) {
  const [prod, cand] = await Promise.all([
    prodAgent.run(realReq), candAgent.run(clone(realReq))   // 候选版影子跑
  ]);
  const diff = await judgePair(prod, cand, rubric);
  metrics.inc('shadow_' + diff);        // win/lose/tie 分布即升级依据
  return prod;                          // 用户永远拿生产版结果
}
```
