## 1250：笔试手写：实现 BM25 简版评分器

**需求**：实现 bm25(query, docs)：query 为词数组，docs 为 { id, tokens: string[] }[]。实现 BM25 公式：score = Σ IDF(q) · tf·(k1+1)/(tf + k1·(1-b+b·len/avgLen))，k1=1.5，b=0.75，IDF = ln((N - df + 0.5)/(df + 0.5) + 1)。返回按分数降序的 [{ id, score }]。

```js
function bm25(query, docs, k1 = 1.5, b = 0.75) {
  const N = docs.length;
  const avgLen = docs.reduce((s, d) => s + d.tokens.length, 0) / (N || 1);
  const df = new Map();
  for (const d of docs) {
    new Set(d.tokens).forEach(t => df.set(t, (df.get(t) || 0) + 1));
  }
  const tf = doc => {
    const m = new Map();
    doc.tokens.forEach(t => m.set(t, (m.get(t) || 0) + 1));
    return m;
  };
  return docs.map(d => {
    const freq = tf(d), len = d.tokens.length;
    let score = 0;
    for (const q of query) {
      const f = freq.get(q) || 0;
      if (!f) continue;
      const idf = Math.log((N - (df.get(q) || 0) + 0.5) / ((df.get(q) || 0) + 0.5) + 1);
      score += idf * (f * (k1 + 1)) / (f + k1 * (1 - b + b * len / avgLen));
    }
    return { id: d.id, score: +score.toFixed(4) };
  }).sort((a, b2) => b2.score - a.score);
}
```

**评分点**：
- IDF 公式带 +1 防负值（词全文档出现时不惩罚为负）
- tf 饱和与长度归一（k1/b 参数作用能说清）
- df 用 Set 去重统计（文档级而非词频级）
- avgLen 分母为 0 的空库兜底
