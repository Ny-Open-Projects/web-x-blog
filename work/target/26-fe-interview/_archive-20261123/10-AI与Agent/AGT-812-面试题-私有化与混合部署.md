## AGT-812：大客户要求私有化部署 Agent 平台，部署形态与更新策略怎么设计

**答**：
- 三形态：SaaS（共享）、专有云（单租户独立集群）、私有化（客户机房）；代码同源但部署清单不同（模型端点/存储/SSO 全部可配置）。
- 私有化的关键约束：模型要么客户自带端点（客户采购的 API）要么本地开源模型（质量预期管理）；数据绝不出客户边界（遥测关闭或本地化）。
- 更新策略：版本列车（季度大版本+月度补丁），客户侧灰度（先测试租户后生产），回滚包随版本发布；与 SaaS 的功能差异矩阵公开维护（避免销售乱承诺）。

```javascript
const DEPLOYMENT = {
  saas: { model: 'platform', telemetry: 'full' },
  vpc: { model: 'bring-your-endpoint', telemetry: 'anonymized' },
  onprem: { model: 'local-or-customer', telemetry: 'off-or-local' },
};
function releaseTrain(client) {
  return client.tier === 'onprem'
    ? quarterly(client, { canary: client.testTenant })
    : rolling(client);
}
```
