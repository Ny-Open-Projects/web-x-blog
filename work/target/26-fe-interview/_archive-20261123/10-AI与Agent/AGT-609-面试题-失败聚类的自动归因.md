## AGT-609：每天几千次失败，如何自动聚类归因（而不是人工翻日志）

**答**：
- 失败先打「结构化指纹」：错误码 + 失败 span 位置 + 依赖状态（哪家的 API 挂了）+ 输入特征（超长/特殊字符），指纹相同合并为一簇。
- 聚类策略：规则层先吃掉 80%（已知错误码→已知原因），剩余用文本嵌入聚类（错误消息相似度）发现新簇，新簇进规则库形成闭环。
- 每簇输出行动卡：影响面（次数/用户数/租户）、置信归因、建议动作（重试策略调整/依赖方工单/提示词修复）。

```javascript
async function clusterFailures(day) {
  const raw = await failures(day);
  const ruled = raw.map(f => ({ ...f, fp: fingerprint(f) }));
  const known = groupBy(ruled, 'fp');            // 规则层：已知指纹
  const unknown = ruled.filter(f => !RULES[f.fp]);
  const clusters = await embedCluster(unknown,   // 嵌入聚类发现新簇
    (a, b) => cosine(embed(a.msg), embed(b.msg)) > 0.92);
  return [...toActionCards(known), ...toActionCards(clusters, { novel: true })];
}
```
