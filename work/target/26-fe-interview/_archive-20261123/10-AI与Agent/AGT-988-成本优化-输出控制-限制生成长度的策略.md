## 988：怎么控制模型输出长度防止成本失控

**答**：
- 三层控制：指令层（prompt 明确字数/格式约束，最有效的是「给格式模板」）、参数层（max_tokens 硬上限兜底）、结构层（要求分点输出，天然收敛长度且便于截断）。
- max_tokens 的坑：截断可能截在 JSON 中间导致解析失败——结构化输出要在 prompt 里要求「先写结论再展开」，截断至少保住结论；或用供应商结构化输出能力。
- 长度与质量的关系：多数 QA 场景输出压缩 30% 质量不降，评估集里加「简洁性」维度对齐预期。
- 追问钩子：怎么发现「模型话痨」？——输出 token P95 与答案有效信息比（压缩后长度/原长度），比值低说明在灌水。

```ts
const res = await llm(prompt, { max_tokens: 600 });   // 硬上限兜底
if (res.stop_reason === 'length') {
  // 截断保护：JSON 场景尝试修复或降级为「结论 + 标注截断」
  return res.finishSafe ? res.parsed : degradeWithPartial(res.text);
}
```
