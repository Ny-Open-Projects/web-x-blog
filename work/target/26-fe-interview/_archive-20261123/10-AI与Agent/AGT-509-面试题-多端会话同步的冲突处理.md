## AGT-509：同一账号在 PC 与手机同时使用，AI 会话的实时同步与冲突怎么处理

**答**：
- 会话同步走服务端推送（WS/SSE 订阅会话变更事件），前端只维护「活跃路径视图」；另一端发消息时本端追加渲染，不要求双向合并文本。
- 冲突本质是「分叉」：两端同时发消息 = 同一 parent 下两个分支，用消息树天然表达，UI 提示"在另一设备上产生了一条新回复"。
- 敏感操作（删除会话/清空）用服务端权威 + 版本号（rev）校验，过期版本操作返回 409 让前端刷新后重试。

```javascript
sessionWs.on('session.update', ({ rev, op }) => {
  if (rev <= localRev) return;          // 幂等：过期事件丢弃
  localRev = rev;
  applyOp(op);                           // append/update 等纯追加操作
  if (op.type === 'append' && op.deviceId !== myDeviceId) {
    ui.banner('另一设备上有一条新消息');   // 跨端提示而非静默合并
  }
});
function deleteSession(id, rev) {
  return api.del(id, { ifMatch: rev })   // 乐观锁
    .catch(e => e.status === 409 && refreshThenConfirm());
}
```
