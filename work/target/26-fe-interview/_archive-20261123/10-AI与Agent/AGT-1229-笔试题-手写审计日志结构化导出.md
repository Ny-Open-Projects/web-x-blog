## 1229：笔试手写：实现审计日志按任务聚合的导出

**需求**：实现 exportTimeline(entries, taskId)：entries 为 { taskId, agent, action, ts, sideEffects?: string[] }[]。输出该任务的时线 [{ ts, desc }]（按 ts 升序，desc = 'agent action [副作用: x,y]'），并汇总 sideEffects 去重列表。

```js
function exportTimeline(entries, taskId) {
  const rows = entries.filter(e => e.taskId === taskId)
    .sort((a, b) => a.ts - b.ts);
  const effects = new Set();
  const timeline = rows.map(e => {
    (e.sideEffects || []).forEach(s => effects.add(s));
    const fx = e.sideEffects?.length ? ` [副作用: ${e.sideEffects.join(',')}]` : '';
    return { ts: e.ts, desc: `${e.agent} ${e.action}${fx}` };
  });
  return { timeline, sideEffects: [...effects].sort() };
}
const entries = [
  { taskId: 't1', agent: 'coder', action: 'fs.write', ts: 2, sideEffects: ['/a'] },
  { taskId: 't1', agent: 'reviewer', action: 'approve', ts: 1 },
  { taskId: 't2', agent: 'x', action: 'y', ts: 3 },
];
console.log(import_timeline = exportTimeline(entries, 't1'));
// timeline: [{1,'reviewer approve'},{2,'coder fs.write [副作用: /a]'}]
// sideEffects: ['/a']
```

**评分点**：
- 过滤+排序+desc 格式化三步正确
- sideEffects 去重汇总（影响面清单——应急定界的直接产物）
- 无副作用的条目无副作用段
- 能讨论：定界（影响面清单驱动 undo）、导出的合规用途（监管可导出）
