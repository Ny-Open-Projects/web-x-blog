## AGT-704：用户问图 3 里 2023 年哪个月最高，多模态 RAG 如何准确回答图表数据问题

**答**：
- 最好在入库时就抽取图表底层数据：能用数据源（生成图表的原始数据）就存数据；只有图片时用 vision 提取「数据序列」（轴标签+数值点），存为结构化 JSON 与图片关联。
- 问答时分两步：先定位图表（文本/描述检索），再把「图表数据 JSON + 原图」一起给模型回答——只给原图容易读错数值，只给描述丢失细节。
- 置信度标注：vision 提取的数据带置信度，低置信数据回答时提示"图表为图像识别结果，数值可能存在误差"，并给原图引用让用户核对。

```javascript
async function answerChartQuestion(q) {
  const chart = await retrieveChart(q);            // 定位图表
  const data = chart.dataJson
    ?? await vision(chart.img, EXTRACT_DATA_PROMPT); // 提取数据序列
  return llm.answer(q, {
    imageData: data, image: chart.img,
    confidence: data.confidence,
    caveat: data.confidence < 0.8
      ? '图表数值来自图像识别，可能存在误差，请核对原图' : null,
    citation: { page: chart.page, bbox: chart.bbox },   // 引用可跳转
  });
}
```
