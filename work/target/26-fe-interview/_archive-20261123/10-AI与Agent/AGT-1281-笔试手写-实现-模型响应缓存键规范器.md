## 1281：笔试手写：实现 模型响应缓存键规范器

**需求**：实现 cacheKey(req)：req 为 { model, messages, temperature, top_p, tools? }。生成稳定键：模型名 + 参数归一化（temperature 保留 2 位、undefined 参数跳过）+ 消息内容哈希（简单 djb2）；tools 存在时必须纳入（否则不同工具集命中同键 = 错误复用）。键格式 `model:p1=v1;p2=v2:h{hash}`。

```js
function cacheKey(req) {
  const djb2 = s => {
    let h = 5381;
    for (let i = 0; i < s.length; i++) h = ((h << 5) + h + s.charCodeAt(i)) >>> 0;
    return h.toString(36);
  };
  const parts = [`model=${req.model}`];
  if (req.temperature !== undefined) parts.push(`t=${(+req.temperature).toFixed(2)}`);
  if (req.top_p !== undefined) parts.push(`p=${(+req.top_p).toFixed(2)}`);
  if (req.tools?.length) parts.push(`tools=${req.tools.map(t => t.name).sort().join(',')}`); // 排序防顺序抖动
  const content = req.messages.map(m => `${m.role}:${m.content}`).join('\n');
  return `${parts.join(';')}:h${djb2(content)}`;
}
```

**评分点**：
- 数值参数定精度归一（0.700 与 0.7 同键）
- undefined 跳过而非 'undefined' 字面量（防键污染）
- tools 名排序后纳入（语义缓存必含工具维度）
- 能讨论：djb2 是演示哈希——生产用 SHA-256 且存原文供冲突校验
