## AGT-770：用户在 PC 与手机上的画像/偏好同步（冲突与实时性）

**答**：
- 画像与偏好服务端权威：任何设备修改即时写服务端，其他设备订阅变更（WS 推送）实时生效；本地缓存只是视图。
- 冲突极少但存在（双设备同时改偏好）：按字段最后写入胜（LWW）+ 时间戳，重要字段（约束类）冲突时让用户确认。
- 会话不跨设备合并（各是各的情景记忆），画像/偏好/语义记忆跨设备一致——分层同步策略。

```javascript
function syncProfile(device) {
  ws.subscribe(`profile:${userId}`, (patch) =>
    applyPatch(device.localProfile, patch, {
      strategy: 'lww',                             // 字段级LWW
      confirm: (k) => k in CONSTRAINT_FIELDS,      // 约束类冲突确认
    }));
}
async function setPreference(k, v, at) {
  await api.patchProfile({ [k]: v }, { ifUnchangedSince: at }); // 乐观锁
}
```
