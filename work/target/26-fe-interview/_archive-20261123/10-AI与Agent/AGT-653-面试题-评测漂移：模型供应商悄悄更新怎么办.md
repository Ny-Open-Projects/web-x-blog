## AGT-653：供应商说模型没变但评测分数掉了 3 分，如何发现与应对评测漂移

**答**：
- 侦探针（canary cases）：一组固定用例+固定温度，每天跑，分数是"模型版本指纹"——漂移超阈值即认定上游变了（不管对方承认不承认）。
- 漂移应对三步：锁定（请求带模型版本快照/缓存关键输出）、隔离（把漂移期间的判定结果标记不可比）、重校准（judge 提示词对新模型重新校准，judge 也是模型也会漂移）。
- judge 与被测模型耦合漂移是深坑：换模型后 judge 分数变化的两个来源要分离（被测真的变了 vs judge 判分标准漂了），用固定金标集分离。

```javascript
const CANARY = dataset.get('canary-fixed');
async function dailyProbe() {
  const score = await runEval(CANARY, { temperature: 0 });
  if (Math.abs(score - CANARY.baseline) > 1.5) {
    alert({ type: 'model_drift', delta: score - CANARY.baseline,
      action: ['pin_version', 'mark_window_incomparable', 'recalibrate_judge'] });
    judgeRecalibrate(GOLDEN_SET);               // 金标集分离 judge 漂移
  }
}
```
