## 1057：怎么画「单位质量成本」曲线指导优化方向

**答**：
- 定义：单位质量成本 = 单任务成本 / 任务质量分；曲线按「成本投入档位」画（如 1k/4k/16k token 预算档各跑评估），得到质量-成本边际曲线。
- 用法：找「边际收益拐点」——从 1k 到 4k token 质量提升 0.15，4k 到 16k 只提升 0.02，则生产档位定 4k，再往上是为烧钱而烧钱。
- 分意图画曲线：不同意图的拐点不同（事实问答拐点早、复杂推理拐点晚），路由按意图选档位。
- 追问钩子：曲线会漂移吗？——会，模型升级、prompt 改进都会移动拐点，季度重画；拐点数据是「要不要上更大模型」的决策依据。

```ts
async function qualityCostCurve(evalSet, budgets = [1000, 4000, 16000]) {
  const pts = [];
  for (const b of budgets) {
    const r = await runEval(evalSet, { maxTokens: b });
    pts.push({ budget: b, acc: r.acc, uqc: avgCost(r) / r.acc }); // 单位质量成本
  }
  return pts;   // 拐点：acc 增量 < 0.02 的下一档即生产档位
}
```
