## 1259：笔试手写：实现 上下文重叠去重器

**需求**：实现 dedupeContext(segments)：segments 为 { source: 'system'|'memory'|'rag'|'user', text }[]。多来源片段常有重叠内容。用 4-gram Jaccard 相似度判定重叠（阈值 0.5），重叠时保留优先级高者（system > rag > memory > user），同优先级保留更长片段。返回去重后的数组（保持原顺序）。

```js
function dedupeContext(segments, threshold = 0.5) {
  const PRIO = { system: 3, rag: 2, memory: 1, user: 0 };
  const grams = t => {
    const s = t.replace(/\s+/g, ''), g = new Set();
    for (let i = 0; i + 4 <= s.length; i++) g.add(s.slice(i, i + 4));
    return g;
  };
  const G = segments.map(s => ({ ...s, g: grams(s.text) }));
  const jacc = (a, b) => {
    let inter = 0;
    a.forEach(x => { if (b.has(x)) inter++; });
    const uni = a.size + b.size - inter;
    return uni ? inter / uni : 0;
  };
  const drop = new Set();
  for (let i = 0; i < G.length; i++) {
    for (let j = i + 1; j < G.length; j++) {
      if (drop.has(i) || drop.has(j)) continue;
      if (jacc(G[i].g, G[j].g) >= threshold) {
        const loser = PRIO[G[i].source] < PRIO[G[j].source] ? i
          : PRIO[G[i].source] > PRIO[G[j].source] ? j
          : (G[i].text.length >= G[j].text.length ? j : i);
        drop.add(loser);
      }
    }
  }
  return G.filter((_, i) => !drop.has(i)).map(({ g, ...s }) => s);
}
```

**评分点**：
- n-gram Jaccard 是文本去重的通用手段（与 SimHash 思路互通）
- 优先级覆盖顺序与同优先级长度裁决
- 被判定过的一次性 loser 不再参与比较
- 能讨论：token 预算紧张时去重是压缩的前置步骤
