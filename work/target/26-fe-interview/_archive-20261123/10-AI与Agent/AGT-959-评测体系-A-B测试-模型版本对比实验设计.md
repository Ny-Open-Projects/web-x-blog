## 959：两个模型/两个 prompt 版本怎么设计 A/B 对比实验

**答**：
- 三种对比方式按成本递增：离线评测集对比（快、便宜、分布偏）→ 影子流量对比（真实分布、无用户影响）→ 线上 A/B（真实用户行为指标，金标准但慢）。
- 样本量先算再跑：按预期提升与方差估算最小样本，避免看两天数据就下结论（p 值不到 0.05 的「胜利」大多是噪声）。
- 多指标决策：主指标（任务完成率）显著 + 护栏指标（成本、延迟、点踩率）不劣化才判胜；只看主指标会赢质量输成本。
- 追问钩子：A/B 期间用户会感受到不一致吗？——按用户粒度分流（同一用户固定版本），会话内绝不换版本，否则体验割裂污染数据。

```ts
function sampleSize(p0, mde, power = 0.8, alpha = 0.05) {
  // 近似：n = 16 * p(1-p) / mde^2
  return Math.ceil(16 * p0 * (1 - p0) / (mde ** 2));
}
// 完成率基线 0.7，想检测 +0.03：每组约 3734 个任务
const n = sampleSize(0.7, 0.03);
```
