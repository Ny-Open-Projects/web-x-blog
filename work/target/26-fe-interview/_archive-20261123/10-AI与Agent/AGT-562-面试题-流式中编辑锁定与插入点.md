## AGT-562：流式生成中，用户想在已生成内容中间插入评论/批注，交互怎么处理

**答**：
- 已生成部分是"只读态 + 可批注"：正文不可编辑（编辑会造成与流内容冲突），但支持选区批注（选中→浮出批注框），批注以 anchor（块 id + 偏移）记录。
- 批注提交后两个去向：作为"下轮提示"注入（Agent 看到批注后可修改后续生成），或作为静态评论存档。
- 流结束后批注 anchor 要能对抗内容重渲染（按块 id 定位而非字符偏移）。

```javascript
function addAnnotation(sel, turn) {
  const block = sel.anchorNode.closest('[data-block-id]');
  return api.annotate({
    turnId: turn.id, blockId: block.dataset.blockId,   // 块级锚点，抗重渲染
    quote: sel.toString(),
    target: 'nextTurn',   // 注入下轮提示 or 'archive' 仅存档
  });
}
```
