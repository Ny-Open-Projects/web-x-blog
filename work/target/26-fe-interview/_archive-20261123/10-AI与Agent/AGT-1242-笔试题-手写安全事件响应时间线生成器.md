## 1242：笔试手写：实现 P0 事故的时间线与 SLA 达成判定

**需求**：实现 incidentReport(events, sla)：events 为 { type: 'alert'|'ack'|'mitigate'|'fix', ts }[]（升序）；sla = { P0: { ackMin: 5, mitigateMin: 60, fixMin: 1440 } }。计算各阶段耗时并判定 SLA 达成：ackMs = ack-alert、mitigateMs = mitigate-ack、fixMs = fix-mitigate；输出 { ackMs, mitigateMs, fixMs, met: { ack, mitigate, fix } }（缺失事件计 null 且不达成）。

```js
function incidentReport(events, sla) {
  const get = t => events.find(e => e.type === t)?.ts ?? null;
  const alert = get('alert'), ack = get('ack'),
    mitigate = get('mitigate'), fix = get('fix');
  const diff = (a, b) => a !== null && b !== null ? (b - a) / 60000 : null;
  const ackMs = diff(alert, ack), mitigateMs = diff(ack, mitigate),
    fixMs = diff(mitigate, fix);
  const s = sla.P0;
  return {
    ackMs, mitigateMs, fixMs,
    met: {
      ack: ackMs !== null && ackMs <= s.ackMin,
      mitigate: mitigateMs !== null && mitigateMs <= s.mitigateMin,
      fix: fixMs !== null && fixMs <= s.fixMin,
    },
  };
}
const ev = [
  { type: 'alert', ts: 0 }, { type: 'ack', ts: 3 * 60000 },
  { type: 'mitigate', ts: 40 * 60000 }, { type: 'fix', ts: 1000 * 60000 },
];
console.log(incidentReport(ev, { P0: { ackMin: 5, mitigateMin: 60, fixMin: 1440 } }));
// ackMs 3 met.true；mitigateMs 37 true；fixMs 960 true
```

**评分点**：
- 阶段差计算（以事件存在为前提——缺失 null 且不达成）
- SLA 阈值单位（分钟）与毫秒换算
- met 三维独立判定
- 能讨论：事件缺失的语义（未 ack 即超时——用 now 兜底的进阶）、时间线与复盘报告的联动
