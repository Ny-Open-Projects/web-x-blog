## AGT-779：画像不只影响回答，还影响界面（默认工具/常用功能置顶），界面个性化怎么设计

**答**：
- 界面个性化三层：默认值个性化（新会话默认开哪些工具）、布局个性化（常用功能前置）、提醒策略个性化（提醒时机按用户活跃习惯）；全部基于「行为统计置信」——用得多的才前置，避免拍脑袋。
- 显式优先：用户手动固定/隐藏的操作永远覆盖算法排序（用户主权），算法只排用户没表达过偏好的区域。
- 变更通知与可逆：算法调整布局要轻提示"已按你的习惯调整，可还原"，所有个性化布局一键重置。

```javascript
function personalizeLayout(profile, behavior) {
  const stats = behavior.frequency({ window: '30d' });
  const ranked = actions.sort((a, b) =>
    stats[b.id] - stats[a.id]);
  return {
    order: [...profile.pinned, ...ranked.filter(a =>
      !profile.pinned.includes(a.id) && !profile.hidden.includes(a.id))],
    hidden: profile.hidden,                          // 显式隐藏最优先
    notice: '已按使用习惯排序，可随时还原默认',
  };
}
```
