## AGT-834：Agent 平台长期竞争力靠什么（不是模型本身），如何构建

**答**：
- 护城河四层：数据层（租户知识与记忆的沉淀，迁移成本高）、工作流层（与企业系统的深度集成：OA/CRM/审批流，越深越难换）、治理层（审计/合规/安全能力的认证积累——企业采购的硬门槛）、生态层（工具市场/开发者/模板）。
- 模型本身不是护城河（会被追平），「把模型变成企业可靠生产力」的工程层才是；竞品对比要打"接入你企业系统的第一天就能安全干活"。
- 构建节奏：先打治理与集成（企业买单的第一理由），再建生态（锁定），数据沉淀是自然结果不是起点。

```javascript
const MOAT = {
  data: 'tenant-knowledge + memory lock-in',
  workflow: 'OA/CRM/approval deep integrations',
  govern: 'audit/compliance certifications',
  ecosystem: 'tool-market + templates + devs',
};
function pitch() {
  return '接入第一天即可安全地在你的系统上干活，'
    + '而不是又一个聊天框';                        // 差异化一句话
}
```
