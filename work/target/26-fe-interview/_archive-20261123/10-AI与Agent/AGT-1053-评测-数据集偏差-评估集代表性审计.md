## 1053：评估集本身的偏差怎么审计

**答**：
- 偏差审计四查：来源偏差（全来自某个渠道的题，覆盖不了真实分布）、意图偏差（高频意图过采样）、难度偏差（都是简单题，分数虚高）、时间偏差（旧版本产品的题已过期）。
- 对照法：评估集意图分布 vs 线上真实 query 分布做卡方检验，分布显著偏离即为偏差警报；定期用线上抽样重新校准。
- 盲区主动补齐：线上 query 聚类出的簇没有对应评估条目的（评估盲区），按簇规模优先补题。
- 追问钩子：为什么「分数高」也可能是偏差信号？——评估集与开发集同源时，模型「背会」了出题风格，评估分数虚高；留出集（不同来源、同期构建）才是照妖镜。

```ts
function auditBias(evalSet, liveQueries) {
  const e = dist(evalSet.map(c => c.intent));
  const l = dist(liveQueries.map(q => classifyIntent(q)));
  const chi = chiSquare(e, l);
  const gaps = Object.keys(l).filter(k => !(k in e) && l[k] > 0.03); // 盲区
  return { chi, drift: chi > 11.07 /* df=5 p=.05 */, gaps };
}
```
