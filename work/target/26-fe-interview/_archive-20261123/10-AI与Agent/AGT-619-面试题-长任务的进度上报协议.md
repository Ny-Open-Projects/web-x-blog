## AGT-619：跑几分钟的 Agent 任务，进度上报怎么做（阶段事件/百分比语义/断点续跑观测）

**答**：
- 进度用「阶段事件」而非百分比：Agent 任务步骤动态，百分比是伪指标（60% 之后可能发现还要做三件事）；阶段 = plan→retrieve→execute→verify，每阶段完成发事件 + 当前步骤人话描述。
- 断点续跑观测：任务 checkpoint（已完成步骤+产物引用）入 trace，中断恢复后 trace 树续接（同一 traceId 带 resumed 标记），统计恢复成功率。
- 进度事件与心跳分离：心跳证明链路活着，进度证明任务在推进；心跳正常但进度长时间不动=疑似循环，触发循环告警。

```javascript
function emitProgress(task, stage, detail) {
  bus.emit('progress', { traceId: task.traceId, stage,   // 阶段事件
    detail: humanize(detail), step: task.stepIdx, at: Date.now() });
}
// 心跳与进度分离
setInterval(() => bus.emit('heartbeat', { traceId }), 5000);
watchdog.on('stalled_progress', ({ sinceLastProgress }) => {
  if (sinceLastProgress > 60000) alertLoop(task);    // 心跳活但进度停→循环
});
```
