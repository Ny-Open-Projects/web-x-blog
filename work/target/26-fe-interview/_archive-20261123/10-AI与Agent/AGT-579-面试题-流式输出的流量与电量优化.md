## AGT-579：移动端长时间流式对话，如何优化流量与电量（合并/压缩/降频）

**答**：
- 流量：SSE 改 WS 后 delta 攒批发（每 50~100ms 一批而非每 token 一帧）；文本 gzip/br 压缩；低带宽模式降级为"整段完成再推送"。
- 电量：流式期间避免高频 DOM 写入（rAF 合帧已做）与持续 GPS/动画；后台 tab 中流式暂停渲染（visibilitychange），只累计 buffer，回前台一次性渲染。
- 锁屏/切后台时的连接策略：iOS 切后台 SSE 会被挂起，回来走 seq 补拉而不是依赖长连接存活。

```javascript
document.addEventListener('visibilitychange', () => {
  if (document.hidden) stream.pauseRender();      // 后台只攒 buffer
  else { stream.flushRender(); stream.reconcile(); } // 回前台冲刷+对账
});
// 低带宽模式：整段模式
if (netInfo.effectiveType === 'slow-2g' || netInfo.saveData)
  stream.setMode('buffered');                     // 完成才推送
```
