## AGT-661：多语言产品评测集怎么建（语言覆盖/文化差异/翻译污染）

**答**：
- 不是翻译集：核心能力用例按语言原生书写（当地真实问法），而非英文翻译版——翻译腔用例测不出真实体验；共享的判据但答案分语言金标。
- 语言专项维度：习语/敬语/RTL 布局/数字与日期本地化，每语言有专属冒烟；低资源语言单独设门槛（可以分数低但必须测）。
- 防翻译污染：评测集与训练语料来源隔离标注；用回译校验用例语义（翻译过去再翻回来，语义漂移大的用例重写）。

```javascript
function buildMultilangEval(baseCases, langs) {
  return langs.flatMap(lang => baseCases.map(c => ({
    ...c, lang,
    input: c.native[lang] ?? c.input,             // 原生问法优先
    golden: c.goldenByLang?.[lang] ?? translate(c.golden, lang),
    checks: [...c.checks, ...LANG_CHECKS[lang]],  // 语言专项校验
  })));
}
function validateByBacktranslate(case) {
  const rt = translate(case.input, { from: case.lang, to: 'en', back: case.lang });
  return semanticSim(case.input, rt) > 0.85;      // 回译保真
}
```
