## 1282：笔试手写：实现 评测集版本快照管理器

**需求**：实现 snapshotManager()：返回 { commit(cases, note), list(), checkout(version), diff(v1, v2) }。commit 生成递增版本号并深拷贝冻结（Object.freeze 递归）存档；diff 输出两版本的 added/removed/changed（按 caseId，内容 JSON 相等判定）。返回结构含每个版本的 { version, note, size, ts }。

```js
function snapshotManager() {
  const store = new Map();
  let v = 0;
  const deepFreeze = o => {
    if (o && typeof o === 'object') Object.values(o).forEach(deepFreeze);
    return Object.freeze(o);
  };
  const keyOf = arr => new Map(arr.map(c => [c.caseId, JSON.stringify(c)]));
  return {
    commit(cases, note) {
      const version = ++v;
      store.set(version, { version, note, size: cases.length, ts: Date.now(), cases: deepFreeze(structuredClone(cases)) });
      return version;
    },
    list: () => [...store.values()].map(({ cases, ...meta }) => meta),
    checkout: version => store.get(version)?.cases ?? null,
    diff(v1, v2) {
      const a = keyOf(store.get(v1)?.cases || []), b = keyOf(store.get(v2)?.cases || []);
      const added = [...b.keys()].filter(k => !a.has(k));
      const removed = [...a.keys()].filter(k => !b.has(k));
      const changed = [...a.keys()].filter(k => b.has(k) && a.get(k) !== b.get(k));
      return { added, removed, changed };
    },
  };
}
```

**评分点**：
- 递增版本 + 深拷贝冻结（快照不可变语义）
- diff 用 JSON 串比对（内容级而非引用级）
- checkout 未知版本返回 null 不抛错
- 能讨论：评测集与代码同源管理（入 git 或存档库）的取舍
