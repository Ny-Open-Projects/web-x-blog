## 1080：大促/活动高峰前，Agent 服务怎么预热

**答**：
- 预热三层：连接层（提前建立模型 API/检索引擎连接池）、缓存层（用历史热门 query 提前填充语义缓存与检索缓存）、索引层（扩容分片提前完成数据均衡，避免高峰时搬迁）。
- 热门预测：从历史高峰（去年同期/上周同型活动）提取热门 query 集合，预热命中率通常能覆盖高峰 20%~40% 流量。
- 降级预案同步演练：预热完成做一次全链路压测，验证高峰容量与降级链路——预热了但压测没做等于裸奔。
- 追问钩子：预热会不会冲垮供应商配额？——会，预热流量单独申请配额窗口或用批量接口（便宜且配额独立），错峰预热。

```ts
async function warmup(hotQueries) {
  await Promise.all([
    pool.warm(64),                                  // 连接层
    batchEmbed(hotQueries).then(fillSemanticCache), // 缓存层：批量接口错峰
    index.ensureShards(targetShards),               // 索引层提前均衡
  ]);
  await loadTest({ rps: PEAK_RPS * 1.2 });          // 预热后压测验证
}
```
