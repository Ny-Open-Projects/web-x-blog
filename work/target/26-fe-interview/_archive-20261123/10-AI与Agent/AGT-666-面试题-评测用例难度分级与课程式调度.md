## AGT-666：评测用例有难有易，如何分级并用难度调度提升评测信息量

**答**：
- 难度标定：三通道综合——模型通过率（强模型也失败=难）、多步深度（工具链长度）、判据复杂度；分级后每层都有用例（curriculum），避免评测集全是简单题"全对无信息"。
- 调度策略：回归跑按难度加权抽样（难题权重高——信息量大）；发版前必跑 hard 层；新版本先过 easy 层（快速失败）再进 hard。
- 难度会漂移：模型升级后旧难题变简单，定期用通过率重标难度（难度=1-通过率），过易用例降级或退役。

```javascript
function recalibrateDifficulty(cases, run) {
  return cases.map(c => ({ ...c,
    diff: relabel(1 - run.passRate(c),            // 通过率重标难度
      { hard: 0.3, mid: 0.7 }) }));               // <30%通过=hard
}
function scheduleByDifficulty(cases, trigger) {
  if (trigger === 'release') return cases.filter(c => c.diff === 'hard');
  return weightedSample(cases, c => ({ easy: 1, mid: 2, hard: 4 }[c.diff]));
}
```
