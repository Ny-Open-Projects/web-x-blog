## 1103：「上下文最小必要」在工程上怎么落地

**答**：
- 落地四步：声明式需求（任务书声明需要哪些数据字段）、注入时裁剪（编排器按声明注入而不是全量塞）、途中不扩（Agent 请求额外数据要给理由并记审计）、用后即弃（会话结束敏感上下文清除，不进长期记忆）。
- 技术手段：字段级视图（不同 Agent 看到的用户数据是不同投影）、动态脱敏（按 Agent 等级渲染不同详略）。
- 收益不止安全：最小上下文同时降成本、提质量（无关信息稀释注意力）——安全和性能在这里同向。
- 追问钩子：最小化与任务完成率的矛盾怎么破？——用评估数据校准：先按最小集跑，完成率下降的意图逐类放宽并记录理由，「必要」由实验定义而不是拍脑袋。

```ts
function injectContext(brief, userData) {
  const projection = pick(userData, brief.declaredFields); // 按声明裁剪
  const masked = projectByTier(projection, brief.agentTier); // 按等级脱敏
  audit.push({ fields: Object.keys(masked), why: brief.taskId });
  return masked;
}
```
