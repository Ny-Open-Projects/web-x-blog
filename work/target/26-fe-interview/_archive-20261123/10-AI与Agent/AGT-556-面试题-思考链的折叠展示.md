## AGT-556：模型返回 reasoning/thinking 内容，前端怎么展示（折叠/摘要/性能影响）

**答**：
- 思考内容默认折叠为"思考了 Xs（点击展开）"：完整思考通常上千 token，直接流式渲染会抢占正文注意力并拖慢渲染。
- 展开态做两件事：等宽小字渲染 + 只读（不可复制到输入框造成污染）；部分产品允许用户点"展开后保持展开"记偏好。
- 性能上思考流与正文流分开处理：思考 delta 只累计不渲染（或节流渲染），正文 delta 才走完整渲染管线；流结束后思考块懒渲染。

```javascript
function ThinkingBlock({ stream }) {
  const [len, setLen] = useState(0);
  const [open, setOpen] = useState(false);
  useEffect(() => stream.on('thinking', (d) => {
    setLen(l => l + d.length);         // 流式期间只累计长度
  }), []);
  const content = stream.thinkingDone ? stream.thinkingText : null;
  return <details onToggle={e => e.target.open && preload(content)}>
    <summary>思考了 {(stream.thinkMs / 1000).toFixed(1)}s · {len} 字</summary>
    {open && <pre className="thinking">{content}</pre>}
  </details>;
}
```
