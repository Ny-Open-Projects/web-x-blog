## AGT-627：SaaS 多租户的观测数据（trace/日志/成本）如何做租户隔离与配额

**答**：
- 所有观测数据强制带 tenant 标签（采集端注入而非查询端补），存储按租户分索引/分区；查询层做租户过滤兜底（防标签遗漏导致的跨租户泄漏）。
- 观测配额租户级：trace 量/日志量/回放次数按套餐配额，超配额降采样（保留错误全量）而非停采（停采会瞎）。
- 平台侧跨租户视图仅内部运维角色可用，且聚合展示（不暴露单用户对话）。

```javascript
function emit(span, ctx) {
  if (!ctx.tenantId) throw new Error('TENANT_REQUIRED');  // 采集端强制
  span.tags['tenant.id'] = ctx.tenantId;
  if (overQuota(ctx.tenantId)) span.tags['sampled'] = true; // 超额降采样
  store.write(span, { partition: ctx.tenantId });
}
function query(q, actor) {
  if (actor.tenantId) q = { ...q, tenant: actor.tenantId }; // 查询端兜底
  return store.search(q);
}
```
