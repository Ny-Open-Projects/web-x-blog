## AGT-583：流式事件协议升级（v1 文本流 → v2 结构化块流），客户端如何平滑过渡

**答**：
- 双版本窗口期：客户端握手时带 Accept-Version，服务端按客户端版本发事件；新客户端发 v2，旧客户端降级到 v1 兼容层。
- 客户端内置降级转换器：v2 块事件（block.start/delta/end）在旧渲染管线里退化为纯文本拼接（丢块语义但不丢内容）。
- 服务端下线旧版本前看监控里 v1 流量归零，再灰度关闭；客户端强更窗口期内必须双支持。

```javascript
function negotiate(clientVer, serverVers) {
  const v = serverVers.includes(clientVer)
    ? clientVer
    : Math.max(...serverVers.filter(x => x <= clientVer)); // 服务端降级选择
  return v;
}
// v2→v1 降级转换：老管线只吃文本流
function degradeV2toV1(ev) {
  return ev.type === 'block.delta'
    ? { type: 'text.delta', data: ev.data } : null;  // 丢块语义保内容
}
```
