## AGT-365：工具调用"成功返回"但结果可疑（空/异常/过时）怎么处理？

**答**:
- 结果校验层：schema 校验（结构合法）+ 语义校验（空结果/明显异常值：负数年龄/超范围日期）、新鲜度校验（结果带时间戳，过时数据降权或重查）、一致性校验（与已知信息矛盾时标记——"工具说 X，但上文记录 Y"触发复核）。
- 处置阶梯：可重试（空结果→换参数重查）、可替代（同能力多工具，AGT-247 优选备用）、可降级（带"数据可能不完整"的声明继续）、必须中止（关键数据缺失且不可替代→告知用户缺口而非编造）。
- 反馈给模型：校验结果结构化返回（`{data, warnings:[], confidence}`）——模型基于警告调整回答（低置信数据不用于强结论，AGT-263 联动）。
- 工具侧治理：工具实现自身做防御（超时/限流/缓存语义明确），校验层与工具层职责分明——校验是 Agent 侧的最后一道。

```javascript
function validateToolResult(res, ctx) {
  if (!schema(res)) return retryWith({ fix: '参数或重查' });
  if (isEmpty(res)) return tryAlternativeTools(ctx);
  if (isStale(res)) return { ...res, confidence: 0.5,
    warning: '数据超过 24h' };
  if (contradicts(ctx.known, res)) return flagReview(res);
  return res;   // warnings/confidence 供模型决策
}
```
