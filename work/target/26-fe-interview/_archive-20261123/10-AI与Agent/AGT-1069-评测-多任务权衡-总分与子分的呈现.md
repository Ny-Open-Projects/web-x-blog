## 1069：评测报告里「总分 0.85」该不该作为唯一指标

**答**：
- 总分的价值是排序方便，风险是掩盖结构：总分持平但「事实题 +0.05、拒答 -0.05」的系统可能已经更危险——拒答退化是安全事故前兆。
- 呈现规范：总分只做粗排，决策看子分矩阵（意图 × 指标）+ 护栏红线（拒答/安全类子分一票否决，无论总分多高）。
- 权重透明的总分：如果必须用总分，权重公式公开且版本化（权重变更=基线迁移），避免「调权重让分数好看」的指标游戏。
- 追问钩子：给谁看子分、给谁看总分？——工程师看子分矩阵找优化点，管理层看趋势与红线状态；报告默认两级视图。

```ts
function verdict(scores, weights) {
  const guards = { safety: 0.9, reject: 0.85 };     // 红线一票否决
  for (const [k, t] of Object.entries(guards)) {
    if (scores[k] < t) return { ok: false, reason: k + ' red line' };
  }
  const total = Object.entries(weights).reduce((s, [k, w]) => s + w * scores[k], 0);
  return { ok: total > 0.8, total, matrix: scores }; // 总分仅粗排
}
```
