## AGT-557：流式输出时自动滚动到底部，用户向上翻阅后怎么处理（跟随/锁定/回底按钮）

**答**：
- 策略：用户距底部 < 阈值（如 80px）视为"跟随"，新内容自动滚；用户上翻离开底部即"锁定"，停止自动滚动并出现"回到底部（有新内容）"气泡。
- 锁定判定要防误触：触摸滚动中（momentum）不判定，惯性停稳后再判定；键盘翻页（PageUp）也触发锁定。
- 内容高度暴涨时（大表格/图片渲染完成）若在跟随态要重新锚定底部，锚定用 scrollTop = scrollHeight 且 requestAnimationFrame 内做防抖跳变。

```javascript
let following = true;
list.addEventListener('scroll', () => {
  const gap = list.scrollHeight - list.scrollTop - list.clientHeight;
  if (!touched && gap > 80) following = false;   // 离底→锁定
  if (gap <= 8) { following = true; hideBubble(); }
});
function onDelta() {
  renderDelta();
  if (following) requestAnimationFrame(() => {
    list.scrollTop = list.scrollHeight;          // rAF 内锚定防抖
  });
  else showBubble('回到底部 · 有新内容');
}
// 触摸惯性期间不判定锁定
list.addEventListener('touchmove', () => touched = true);
list.addEventListener('touchend', () => setTimeout(() => touched = false, 300));
```
