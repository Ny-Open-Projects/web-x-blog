## AGT-571：用户对某工具批准过一次，会话内后续同样调用还要每次确认吗

**答**：
- 权限记忆按「工具+参数模式」粒度：完全相同参数模式（如"只读查询 orders 表"）可记住本会话；参数变化大（不同表/不同金额）重新确认——记住的是模式不是无差别全放。
- 记忆的呈现与撤销：批准时明示"本会话内不再询问"，时间线上自动通过的调用标注"依据你之前的授权"，会话工具栏提供"查看已授权并撤销"。
- 作用域严格限制会话内（不跨会话持久），高危工具（destructive）永远每次确认，不提供记忆选项。

```javascript
function authorize(tc, session) {
  if (tc.risk === 'destructive') return confirmAlways(tc); // 高危永不记忆
  const pattern = sameParamPattern(tc, session.grants);
  const hit = session.grants.find(g => g.tool === tc.tool
    && matchPattern(g.pattern, tc.args));
  if (hit) { audit.log({ auto: true, grant: hit.id });
    return approve(tc, { via: hit.id }); }
  return confirm(tc, { rememberInSession: true });
}
```
