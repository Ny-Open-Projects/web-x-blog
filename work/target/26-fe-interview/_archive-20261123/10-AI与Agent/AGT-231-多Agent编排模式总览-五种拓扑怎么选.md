## AGT-231：多 Agent 系统的编排拓扑有哪些——怎么按任务选型？

**答**:
- 五种基本拓扑：流水线（串行分工，适合固定流程如"解析→生成→审查"）、中心路由（主 Agent 派发子 Agent 并行处理，适合可分解任务）、辩论/评审（多 Agent 互相批判提升质量，适合高风险决策）、黑板模式（共享工作区异步协作，适合松耦合探索）、状态机图（显式 DAG 编排，适合强流程可控的业务）。
- 选型判据按任务性质：流程固定→流水线/状态机（可控性最高）；任务可并行分解→中心路由（吞吐最高）；质量优先于成本→辩论（成本最高）；探索性/创造性→黑板。
- 工程原则：拓扑越复杂越难调试——先用最简单能达成质量的拓扑，复杂度是被迫引入的而非默认的；任何拓扑都要有 trace（每跳输入输出可回放）。
- 混合形态：生产系统常是嵌套结构（状态机外框 + 内部中心路由并行 + 关键节点辩论），按节点选模式而不是全局单一模式。

```text
多 Agent 拓扑选型表：
流水线：固定流程 / 可控最高 / 无并行
中心路由：可分解任务 / 吞吐高 / 单点风险
辩论评审：质量优先 / 成本 3~5 倍
黑板模式：探索性任务 / 松耦合 / 难收敛
状态机 DAG：强流程业务 / 可视可控
原则：用达成质量的最简拓扑，
  每跳必须可 trace 回放。
```
