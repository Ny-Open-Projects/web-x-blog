## 1214：笔试手写：实现事件序列的记录与重放（bug 复现）

**需求**：实现 Recorder(machine)：attach 后记录每次 send 的 { event, payload, before }（迁移前状态）；replay(def, events) 用全新机器实例按序 send，返回最终状态与每步迁移是否成功（与录制对比可发现行为漂移）。要求非法事件也记录。

```js
function createRecorder(machine, def) {
  const events = [];
  const orig = machine.send.bind(machine);
  machine.send = (event, payload) => {
    const before = machine.getState().state;
    const ok = orig(event, payload);
    events.push({ event, payload, before, ok });
    return ok;
  };
  return {
    events: () => [...events],
    replay() {
      const fresh = createMachine(def).start();
      const steps = events.map(e => ({ ...e,
        okNow: fresh.send(e.event, e.payload) }));
      return { final: fresh.getState(), drifted: steps.some(s => s.ok !== s.okNow) };
    },
  };
}
// 用法：录制用户操作序列 -> 回放对比 drifted -> 行为漂移即回归
```

**评分点**：
- 记录含迁移前状态与结果（漂移对比的最小信息集）
- replay 用全新实例（不污染录制实例）
- drifted 判定（任一步结果不一致即漂移——bug->回归的直通路径）
- 能讨论：payload 的脱敏序列化、与 XState getPersistedSnapshot 的互补
