## AGT-724：图片理解结果的缓存体系（描述/提取/ embedding 三层）怎么设计

**答**：
- 三层缓存：描述层（caption+OCR，按图片内容哈希键，永不过期除非模型升级）、提取层（结构化数据 dataJson，同哈希键）、embedding 层（向量，模型版本键）；任何一层命中都跳过对应的贵调用。
- 会话级短缓存：同会话内同一图片重复出现（用户追问）直接复用会话内存缓存，零延迟零成本。
- 失效语义：只有「内容哈希变化」或「模型版本升级」触发失效，URL 变化不算（同图不同 URL 常见）。

```javascript
const mmCache = {
  async understand(img) {
    const h = await contentHash(img);              // 内容哈希键
    const hit = await cache.get(`desc:${h}:${VISION_VER}`);
    if (hit) return hit;
    const out = await visionPipeline(img);
    await cache.set(`desc:${h}:${VISION_VER}`, out, { persistent: true });
    return out;
  },
  session: new Map(),                              // 会话级短缓存
};
```
