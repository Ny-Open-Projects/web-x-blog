## AGT-612：语义缓存上线后，如何观测命中率、误命中（相似但答错）与收益

**答**：
- 三个指标：命中率（命中/总请求）、收益（saved tokens/成本/延迟）、误命中率（命中后被用户负反馈或重新生成的比例）——误命中率是语义缓存的健康红线，命中率好看但误命中高就是事故。
- 误命中归因：把"命中后 regen/dislike"的样本抓出来，分析相似度阈值与 embedding 模型；调阈值前先看 PR 曲线（阈值抬高→命中率降误命中降）。
- 缓存观测要带版本维度：embedding 模型升级会让旧缓存全部失真，按缓存版本分段统计。

```javascript
function cacheHealth(window) {
  const hit = window.filter(r => r.fromCache);
  const bad = hit.filter(r => r.regen || r.dislike);   // 误命中样本
  return {
    hitRate: hit.length / window.length,
    savedUsd: sum(hit, 'cost.saved'),
    falseHitRate: bad.length / Math.max(hit.length, 1),  // 健康红线
    action: falseHitRate(bad) > 0.05 ? 'raise_threshold' : null,
  };
}
```
