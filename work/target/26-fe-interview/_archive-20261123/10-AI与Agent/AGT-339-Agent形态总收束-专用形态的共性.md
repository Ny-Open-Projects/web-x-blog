## AGT-339：语音/视觉/浏览器/长任务等专用 Agent 形态的共性设计规律？

**答**:
- 共性一（感知-行动-验证循环）：所有与环境交互的 Agent（语音听环境/GUI 看屏幕/浏览器操作页面）都是"感知→决策→行动→验证结果"循环——差异只在感知模态与行动通道，循环骨架相同。
- 共性二（确定性优先）：能用结构化手段（DOM/无障碍树/系统提示的固定锚）就不用纯概率手段（纯视觉/纯对话记忆）——专用 Agent 的可靠性来自"结构化锚点+AI 兜底"而非"AI 全包"。
- 共性三（人机接管设计）：所有专用形态都有"卡住转人"机制（语音静默超时/GUI 异常暂停/长任务阶段确认）——接管不是失败，是设计的一部分；接管点即信任点。
- 共性四（延迟与成本的特殊预算）：每个形态有自己的延迟生命线（语音 <1.5s/GUI 步级秒级/长任务分钟级）与成本结构（语音按时长/GUI 按步数/长任务按阶段）——形态工程=在形态的约束下重排通用 Agent 组件。

```text
专用 Agent 共性：
循环：感知 → 决策 → 行动 → 验证
  （骨架同，模态不同）
锚点：结构化优先（DOM/树/固定锚），
  AI 兜底 —— 可靠性来自结构+AI
接管：卡住转人是设计的一部分
预算：各形态延迟生命线与成本结构
  不同（语音<1.5s / GUI 秒级 /
  长任务分钟级）。
```
