## AGT-756：用户周一说的事周五来问，跨会话记忆如何保持一致与可追溯

**答**：
- 记忆条目全局唯一 id + 会话溯源（来自哪个会话哪句话），跨会话引用时回答带"你上次提到…"的可核对引用（点击回看原会话）。
- 一致性维护：记忆更新走单一写入通道（防并发写冲突），画像字段乐观锁版本化；跨会话检索时带时间线（用户需求的演化轨迹），而不是只给最新快照——有些问题需要"你上周说 A 这周又说 B"的轨迹。
- 会话摘要作为情景记忆入口：每个会话结束时生成摘要入库，摘要与原文互链。

```javascript
async function recallAcrossSessions(query) {
  const hits = await vector.search(embed(query), { index: 'semantic' });
  const timeline = await episodic.timeline(hits.map(h => h.userId));
  return {
    facts: hits.map(h => ({ ...h, source: h.originSessionId })),  // 溯源
    timeline: timeline.filter(t => related(t, query)),  // 演化轨迹
  };
}
function citeMemory(m) {
  return `<a data-session="${m.originSessionId}">你此前提到：${m.quote}</a>`;
}
```
