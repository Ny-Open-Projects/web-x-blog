## AGT-716：多模态检索结果在回答前/回答中如何预览（缩略图墙/来源地图）

**答**：
- 生成前的「来源预览」：Agent 检索阶段把命中的文档/图/视频段以缩略图墙展示（用户可提前看到"它参考了什么"，甚至取消某个来源），这是信任建设的关键交互。
- 来源地图：长回答完成后给「证据地图」——每个论点连到具体来源（含模态图标），支持反向核对。
- 性能：预览缩略图走低清变体+懒加载，10+ 来源时折叠为分页。

```jsx
function SourcePreview({ hits, onToggle }) {
  return <div className="sources">
    {hits.map(h => <SourceCard key={h.id} hit={h}
      thumb={h.thumbLow}                            // 低清变体
      excluded={h.excluded}
      onToggle={() => onToggle(h.id)} />)}          // 用户可排除来源
    {hits.length > 10 && <Pager total={hits.length} size={10} />}
  </div>;
}
```
