## AGT-561：模型输出图片（生成式图表/图像），渐进展示怎么做（占位→低清→高清）

**答**：
- 图片输出走三级渐进：base64 缩略图（流中先到，几十字节级）→ 中清图（完成时）→ 高清/原图（按需加载，点开大图才拉）；每级用 LQIP 占位防布局跳变。
- 生成中的图像给进度事件（服务端推进度百分比或中间帧），前端展示模糊化的中间帧而不是空白。
- 多图输出（一组候选）用网格缩略图 + 选定后单图放大，未选图在会话保存后按 TTL 清理（省存储）。

```javascript
function GenImage({ ev }) {
  const [stage, setStage] = useState('thumb'); // thumb→mid→full
  const src = { thumb: ev.thumbUrl, mid: ev.midUrl, full: ev.fullUrl }[stage];
  return <figure className={`img-${stage}`}>
    <img src={src} onLoad={() => stage === 'mid' && preloadFull()}
      style={{ filter: stage === 'thumb' ? 'blur(12px)' : '' }} />
    {ev.progress < 1 && <progress value={ev.progress} />}
    {stage === 'mid' && <button onClick={() => setStage('full')}>查看高清</button>}
  </figure>;
}
```
