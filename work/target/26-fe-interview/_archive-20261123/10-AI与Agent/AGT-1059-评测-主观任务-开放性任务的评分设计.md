## 1059：「写得好不好」这类开放任务怎么评

**答**：
- 开放任务没有唯一答案，评分靠「维度拆解 + 锚点样例」：拆成若干可判维度（结构完整、逻辑连贯、符合受众），每维度给 1/3/5 分的锚点样例（真实文本），裁判按锚点对齐打分——锚点样例是主观评分的锚，没有锚点分数漂移。
- 两两比较优于绝对打分：开放任务的绝对分不稳定，A/B 对比 + Elo 积分做版本排名更可靠。
- 人机混合：LLM 裁判初评 + 人工审「裁判分歧大的样本」，分歧率本身就是任务难度的信号。
- 追问钩子：锚点样例从哪来？——历史真实产出里挑（好评/差评各若干），人工定级后冻结；锚点过时（受众/风格变化）会带偏裁判，定期复审。

```ts
const rubric = {
  dims: ['structure', 'coherence', 'audience_fit'],
  anchors: { 5: loadSample('anchor/5.md'), 3: loadSample('anchor/3.md'), 1: loadSample('anchor/1.md') },
};
async function judgeOpen(essay, dim) {
  return llm(`按锚点对齐评分（1/3/5）：\n锚点5：${rubric.anchors[5]}\n...\n待评：${essay}\n维度：${dim}`);
}
```
