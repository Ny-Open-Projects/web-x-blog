## 1083：内部平台怎么建「计量计费」体系

**答**：
- 计量三件事：统一计量点（网关层埋点，所有模型/工具调用必经）、计量维度（调用方/服务/模型/任务类型）、单价表（含折扣与缓存折扣，公开维护）。
- 账单生成：日聚合 + 月结算，误差对账（计量点数据 vs 供应商账单差异小于 2%，超了查漏埋点）。
- 计费驱动优化：成本可见后团队自然优化（可视性本身就是治理手段），配合「成本红黑榜」与预算护栏形成闭环。
- 追问钩子：计量漏了哪些隐性成本？——常漏：rerank/embedding 调用（量大单价低）、重试消耗、失败请求（同样计费）、存储与索引成本；完整账单要把这些单列。

```ts
// 网关统一计量点
async function gatewayCall(call) {
  const r = await vendor.chat(call);
  meter.record({ caller: call.service, model: call.model,
    inTok: r.usage.prompt_tokens, outTok: r.usage.completion_tokens,
    cacheHit: r.usage.cache_hit ?? 0, ok: true });
  return r;
}
// 对账：日批
reconcile(meter.daily(), vendorInvoice.daily(), { tolerance: 0.02 });
```
