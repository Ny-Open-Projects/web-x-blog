## AGT-765：超长会话的工作记忆管理（滑动窗口+摘要锚点+关键信息固化）

**答**：
- 三机制：滑动窗口（最近 N 轮全文）、摘要锚点（更早部分压缩成滚动摘要）、关键信息固化（用户明确的事实/决策即时提取为会话内结构化槽位，永不丢失——"预算 50 万"这种约束不能被摘要压掉）。
- 固化槽位由意图触发：检测到约束/决策/命名实体时即时写入槽位并回显确认（"已记住：预算 50 万"），比等会话结束蒸馏更可靠。
- 摘要锚点更新策略：每 K 轮增量更新摘要而非每次全量重sum（成本），关键槽位变化时强制刷新摘要。

```javascript
function workingMemory(session) {
  return {
    slots: session.slots,                          // 固化槽位
    summary: session.rollingSummary,               // 摘要锚点
    recent: session.turns.slice(-8),               // 滑动窗口
  };
}
function onConstraintDetected(turn) {
  const slot = extractConstraint(turn.text);       // { budget: '50万' }
  if (slot) {
    session.slots[slot.key] = slot.value;
    ui.confirm(`已记住：${slot.key} = ${slot.value}`);  // 回显确认
    scheduleSummaryRefresh();                      // 槽位变化刷摘要
  }
}
```
