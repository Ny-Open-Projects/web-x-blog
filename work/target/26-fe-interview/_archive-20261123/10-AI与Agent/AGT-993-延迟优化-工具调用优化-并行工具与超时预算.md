## 993：工具调用阶段的延迟怎么压

**答**：
- 工具调用延迟构成：模型决定调用（不可控）+ 工具执行（可控大头）；优化重点在执行侧——独立工具并发执行、慢工具加缓存、只读工具预取。
- 超时预算分配：整个任务有总预算，每个工具按「历史 P95 + 缓冲」分配子预算，超时快速失败并让模型换路，而不是无限等。
- 结果裁剪：工具返回的大 JSON 不必全量进 prompt——按「模型需要的字段」裁剪（如日志只取 error 级最近 50 条），既省 token 又降延迟。
- 追问钩子：工具缓存什么时候是危险的？——写后读一致性场景，写入后立刻读不能命中旧缓存，写入操作必须失效相关缓存键。

```ts
async function execTools(calls, budget) {
  const { independent, dependent } = analyzeDeps(calls);
  const rs = await Promise.all(independent.map(t =>
    withTimeout(cacheable(t), budget[t.name] ?? 3000)));  // 并发 + 独立超时
  const trimmed = rs.map(r => trimForPrompt(r));          // 只留模型需要的字段
  return { rs: trimmed, dependent };                      // 依赖项下一轮执行
}
```
