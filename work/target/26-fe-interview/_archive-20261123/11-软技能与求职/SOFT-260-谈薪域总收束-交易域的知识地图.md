## SOFT-260：交易域总收束：谈薪知识地图——从策略到签约的完整链路？

**答**:
- 交易域全景五层：信息层（市场对标/带宽/系数——SOFT-212/251）、筹码层（BATNA/稀缺证据/时间——SOFT-250）、策略层（锚定/条件交换/反套路——SOFT-205/213）、执行层（话术/渠道/节奏——SOFT-259/241）、条款层（书面核对/试用期/竞业——SOFT-206/217/219）——每层都有独立工具，缺层必翻车。
- 交易域与其他域的关系：简历域（SOFT-101~140）生产的证据是"稀缺能力筹码"的原材料；行为域（SOFT-141~180）的表现决定你拿到什么档 offer；复盘域（SOFT-181~200）让每轮谈判变成下轮的经验。
- 五域贯通的一句话：软技能面试的本质是"证据工程"——平时生产证据，面试展示证据，谈判为证据定价（SOFT-100 的主轴在交易域的兑现）。
- 毕业标准：给定任意 offer 场景，能不查资料走完"探底→锚定→磋商→书面核对"全流程并说出每步的纪律与话术。

```text
交易域知识地图（收束）：
信息层：对标四源 / 系数折算 / 城市换算
筹码层：BATNA 经营 / 筹码四类 / 信息差
策略层：不先报价 / 区间锚定 / 条件交换 /
        反四套路 / 挽回阶梯
执行层：电话+文字分工 / 沉默与慢回复 /
        留痕三动作
条款层：六项书面 / 试用期 / 竞业 / 流水应对
贯通主轴：证据工程——
  简历域生产证据 → 行为域展示证据
  → 交易域为证据定价。
毕业自检：任意 offer 场景全流程脱稿走通。
```
