## SOFT-277：层级与晋升域总收束——大厂职业游戏的底层认知模型？

**答**:
- 游戏规则三句话：职级是"证据链的定价"（SOFT-261~264 的画像条目就是证据清单）、晋升是"名额+共识的零和排序"（SOFT-268/272）、跳槽是"市场对证据链的重新定价"（SOFT-275）——三条规则决定了所有策略。
- 策略总纲：证据要"可验证+跨团队可见"，时机要"顺组织周期"，路径要"P7 前用市场、P8 后用组织"——三句话覆盖本章全部技巧。
- 风险管理：组织调整期自保（SOFT-276）+ 绩效风险时钟（SOFT-266）——大厂游戏的下半场是"不被出局"，比"往上走"更基础。
- 毕业标准：能说出自己目标职级的画像三条件、当前缺口、补齐节奏与窗口期判断——有完整计划的晋升不是抽奖。

```text
层级域认知模型（收束）：
规则：职级=证据链定价 / 晋升=零和排序 /
      跳槽=市场重新定价
策略：证据可验证+跨团队可见
      时机顺组织周期（扩张冲级/收缩保绩效）
      路径：P7 前用市场，P8 后用组织
风险：调整期自保 + 绩效风险时钟
      （2 个 C = 启动外部机会）
毕业自检：
[ ] 目标职级画像三条件是什么
[ ] 我的缺口是什么
[ ] 补齐节奏与窗口期判断
——有计划的晋升不是抽奖。
```
