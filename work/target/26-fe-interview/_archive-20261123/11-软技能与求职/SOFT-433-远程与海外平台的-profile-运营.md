## SOFT-433：想投远程/海外机会，平台 profile 怎么运营？

**答**:
- 三平台差异：英文自由职业平台（Upwork 等）重 profile 完成度与历史评价；远程招聘板（RemoteOK/WeWorkRemotely 等）重简历与 GitHub；国内远程社区（电鸭等）重社区活跃与作品链接——按目标平台配置主展示物。
- 英文简历要点：动词开头、量化结果、去中式表达（不写"熟练掌握 XX 技术"堆砌），一页为限；GitHub README 视为第二简历（英文项目说明+在线 demo）。
- 信任构建：远程雇佣最怕不确定性，可验证的证据权重最高（开源贡献/可访问的 demo/技术博客/时区说明）——比自我描述的形容词有效得多。
- 时区与稳定性自查：profile 里主动写明时区、可用时段与每周投入，远程岗位筛选第一关就是"能不能稳定在线"。

```text
远程 profile checklist：
平台匹配：Upwork→评价/完成度
  RemoteOK/WWWR→简历+GitHub
  电鸭→社区活跃+作品链接
英文简历：动词开头 + 量化 +
  一页 + 无堆砌形容词
GitHub：README 英文项目说明 +
  在线 demo 链接
主动声明：时区 UTC+8 / 可用时段 __ /
  每周 __h / 响应时效 __
证据优先：开源 > demo > 博客 > 描述。
```
