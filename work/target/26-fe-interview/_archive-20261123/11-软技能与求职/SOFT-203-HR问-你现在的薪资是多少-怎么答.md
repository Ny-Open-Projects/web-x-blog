## SOFT-203：HR 问"你现在的薪资是多少"——诚实与博弈之间怎么答？

**答**:
- 基线原则：当前薪资可以说，但给"全口径版本"（base + 实际拿到的奖金 + 津贴）——只报 base 会压低你的锚点，多数公司的涨幅公式按"现总包 ×1.2~1.3"算。
- 现薪资偏低（倒挂吃亏）时：如实报 + 立刻补充"但这个数字是两年前谈的，当时职级低；我现在承担的是 {更高级职责}，市场对位是 {X}"——用职责对位拉锚，不用谎报。
- 现薪资虚高（前公司高薪）时：如实报 + 预答"涨幅"问题（"我知道按比例涨不动，我的期望更多基于岗位价值而非涨幅比例"）。
- 造假红线：薪资说谎在背调（SOFT-381 域）会连环暴露——银行流水/个税 APP 都能查，永远不虚报。

```text
全口径报法："我现在总包是 {base×12 + 奖金实际
  兑现 + 补贴} ≈ {X}，其中 base {Y}。"

倒挂补充话术："这个数字是 {两年前} 入职时谈的，
  那时我负责 {A}；现在我承担 {B+C}，带 {N} 人，
  市场同等职责的价位在 {X'}——我的期望基于
  职责对位，不基于涨幅比例。"

高薪补充话术："涨幅空间我知道有限，
  我更看重 {业务/平台}，期望值可以按贵司
  职级带宽谈。"
```
