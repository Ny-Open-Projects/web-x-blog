## SOFT-420：作品集与个人主页怎么做才有求职转化？

**答**:
- 转化导向三原则：首页 3 秒能看懂你是谁（一句话定位+方向）、每个作品有"业务问题→技术方案→量化结果"的故事而非截图堆砌、简历/主页/GitHub 三处信息一致（SOFT-397 叙事一致性）。
- 作品选题：宁可一个做透的项目（真实可用、有性能数据、有技术决策记录）也不要五个 demo——面试官只深挖一个，demo 经不起两问。
- 流量配置：简历放短链，投递后主动在简历顶部放"在线作品"入口；对校招/转行人群作品集的边际价值最高，社招资深岗则 GitHub 技术沉淀权重更高。
- 维护纪律：每次求职季前统一翻新（死链/过时技术栈/旧数据），一个停在两年前的主页比没有更减分。

```text
作品集页面结构：
Hero：一句话定位 + 方向 + 简历短链
作品卡 ×1~3（做透优先）：
  业务问题：__
  技术方案：__（关键技术决策 ×2）
  量化结果：__（性能/用户/稳定性）
  在线地址 + 源码
一致性自查：简历/主页/GitHub
  三处技术栈与数据一致？
季前翻新 checklist：死链/栈版本/
  数据时效/联系方式。
```
