## SOFT-122：简历写"从 0 到 1 搭建"，被拆解追问"第一版怎么定的、怎么演进的"怎么答？

**答**：
- 从 0 到 1 的可信叙述是"演进三段式"：V1 解决什么最小问题（刻意简陋）→ 什么信号触发 V2 重构 → 现在的形态，一条时间线讲透。
- V1 必须讲出"当时的合理约束"：一周要上线、只有你一个人、需求未定型——简陋的 V1 是决策，不是水平差。
- 演进触发器要具体（"接入第 3 个业务方后配置耦合爆了"），有触发器的演进是工程判断，没有触发器的重构是炫技。
- 深挖收尾亮出"如果重来"的分叉判断：哪些 V1 决策现在仍是对的，哪些已经被证伪——展示决策能力而非结果崇拜。

```text
演进三段式模板：
V1（{时间}）：最小可用——{技术栈/形态}，约束是
  {工期 X 天 / 一人 / 需求未定型}，刻意没做 {Y}。
触发器（{时间}）：{第 N 个业务方接入时暴露了 XX 问题}，
  信号是 {具体指标/事件}。
V2：{重构方案}，收益 {数据}；保留了 V1 的 {Z}，
  事实证明那个决策仍然正确。

收尾句："所以从 0 到 1 我学到的是：第一版的目标不是
先进，是'低成本试出真实约束'。"
```
