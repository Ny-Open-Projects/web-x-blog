## SOFT-108：简历写了 GitHub/开源项目，面试官当场翻仓库怎么办？

**答**：
- 简历上只放"翻得起的仓库"：README 完整、有 demo 链接、最近 3 个月有提交；半年没动的老仓库不如不放。
- 提交历史会被交叉验证：全靠周末一次性提交几千行、或者与工作日 commit 邮箱冲突，都会被注意到，提前想好解释。
- 被当场问仓库里的某段代码时，答不出自己写的设计意图是致命的——所以只放自己逐行理解的项目，fork/跟练项目不写。
- 把仓库当成深挖弹药库：主动说"这个仓库的 XX 模块就是把贵司业务里的 XX 抽象成了通用方案"，引导到你的主场。

```text
仓库放行清单（全部满足才写上简历）：
[ ] README 有：解决什么问题 / 快速开始 / demo 截图
[ ] 有 issue 或 commit message 级别的迭代痕迹
[ ] 最近 3 个月内有 commit
[ ] 每个核心文件我都能讲出设计意图
[ ] 无"AI 一次性生成未消化"的痕迹（面试官看得出）

面试话术钩子：
"这个仓库其实是从我业务里真实需求抽出来的，比如 XX
设计就是为了解决 {场景}，正好和贵司 {业务} 相关。"
```
