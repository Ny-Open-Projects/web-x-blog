## SOFT-409：猎头建档——长期关系管理的字段与节奏？

**答**:
- 字段设计：姓名/所属公司（KA or PS）/擅长方向（行业+职能）/覆盖公司群/合作体验评级（给信息/护信息/快跟进，SOFT-294 三标准）/末次互动/备注（靠谱度）。
- 节奏：求职期每周更新，在职期每半年轻触一次（互通市场温度 SOFT-300）——建档不维护等于没建。
- 分级运营：A 级（2~3 个核心猎头，深维护）、B 级（5~8 个正常协作）、C 级（记录在案不主动）——精力按级分配。
- 交接价值：换城市/换方向时，档案里按"擅长方向"筛选激活——猎头网络是跨地域跨时间的职业基础设施。

```text
猎头档案字段：
姓名 / KA|PS / 擅长方向 / 覆盖公司群 /
体验评级（信息/护信/跟进，SOFT-294）/
末次互动 / 靠谱度备注
节奏：求职期每周更 / 在职期半年轻触
分级：A 2~3 个深维护 / B 5~8 正常 /
  C 记录不主动。
价值：换城市换方向时按"擅长方向"
  激活——猎头网 = 职业基础设施。
```
