## SOFT-202：offer 总包怎么拆解——base/奖金/股票/补贴的真实价值换算？

**答**:
- 换算规则给折扣系数：base 按 100% 计；年终奖按"绩效系数×公司兑现历史"打折（说 4 个月的按历史实际兑现 ×0.7~0.8 估）；股票按 vesting 周期与现价波动折价（未上市 ×0.3~0.5）；加班费/补贴按实际发生频率估。
- base 是最硬的资产：所有系数都建立在 base 上——base 每低 1k，全年少 12k 且影响公积金基数与下一家谈薪锚点；谈崩时优先守 base。
- 现金流视角：入职 1 年内你实际到手的钱（base×12 + 首年可兑现奖金 + 首年可 vest 股票）才是比较 offer 的真实口径，四年 vesting 的股票别按四年全算。
- 隐性成本也要入表：通勤、加班时长、五险一金基数、试用期折扣（80% base 常见）——比较 offer 时入总账。

```text
总包换算表（示例）：
A offer：base 35k×12 + 年终 4 个月 + 期权
  = 35k×12 + 35k×4×0.75(兑现率) + 期权×0.4
  ≈ 420k + 105k + 按兑现概率估
B offer：base 40k×12 + 年终 2 个月
  = 480k + 80k = 560k
→ 名义 A"总包更高"，实际 B 首年现金流更高。

隐性项入表：试用期折扣 / 公积金基数 /
通勤成本 / 平均月加班小时×时薪折算。
守则：谈判冲突时，base > 现金类 > 延迟类。
```
