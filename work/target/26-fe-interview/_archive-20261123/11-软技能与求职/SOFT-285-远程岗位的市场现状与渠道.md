## SOFT-285：远程岗位的市场现状与甄别——哪些渠道真、哪些是坑？

**答**:
- 真实渠道：出海公司（国内团队服务海外业务，远程常态）、外企在华（混合为主但灵活）、开源商业化公司（Remote-first 文化）、远程招聘平台（电鸭社区等垂直渠道）——Boss/拉勾上标"远程"的多为过渡性安排，要核实。
- 甄别四问：远程是公司文化还是阶段性福利（问"团队有多少人远程超过一年"）、薪资是否按城市系数打折、晋升路径对远程员工是否开放、设备与补贴政策——四问可甄别"真远程"与"假远程"。
- 常见坑：以"远程"为名的低薪岗（用灵活性替代薪酬）、外包挂远程名义、试用期转坐班套路——offer 前把远程条款书面化（SOFT-227）。
- 时区与协作：出海远程常涉跨时区——问清核心协作时段（overlap hours），评估对自己的生活影响。

```text
远程岗甄别清单：
真渠道：出海公司 / 外企 / 开源商业化 /
  电鸭等垂直社区
四问甄别：
[ ] 团队远程超一年的人占比多少
[ ] 是否按城市系数打折
[ ] 晋升对远程开放吗
[ ] 设备/补贴/核心协作时段
坑识别：低薪换灵活 / 外包挂名 /
  试用期转坐班——条款必须书面（SOFT-227）。
跨时区：确认 overlap hours。
```
