## SOFT-246：签约前的总检查清单——签字前最后一遍核对什么？

**答**:
- 钱的四项：base 数字与结构、年终口径（保底/浮动+基数）、股票条款（数量/vesting/回购）、签字费与追回条款——任何一项与口头谈判不符，立即回谈（SOFT-206 六项的完整版）。
- 岗位与身份四项：职级与 title、试用期时长与折扣、工作地点与远程条款、竞业与保密条款（SOFT-217/219）——身份条款影响长期，比钱项更不能错。
- 流程三项：入职日期、背调启动时间与口径确认（你提供的联系人已打过招呼）、离职证明与社保衔接——流程项出错会造成入职日事故。
- 最后一道动作：所有条款逐条与"你记忆中的谈判结果"对照——不一致就回谈；签字即视为接受全部条款，这是最后窗口。

```text
签约前 11 项总核对：
钱：
[ ] base [ ] 年终口径 [ ] 股票三件套
[ ] 签字费+clawback
身份：
[ ] 职级 title [ ] 试用期（时长+折扣）
[ ] 工作地点/远程 [ ] 竞业保密
流程：
[ ] 入职日期 [ ] 背调口径已对齐
[ ] 离职证明/社保衔接

动作：逐条对照记忆中的谈判结果，
任何不符 → 回谈；签字 = 接受一切，
无后悔药。
```
