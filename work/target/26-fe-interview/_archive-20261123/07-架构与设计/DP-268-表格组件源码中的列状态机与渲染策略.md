## DP-268：源码识别：大数据表格组件源码中的列状态与渲染策略？
**答**:
- 组合模式：列定义树（column.children 分组表头），渲染递归展开（DP-193 续）。
- 状态机+备忘录：列宽/排序/选中状态独立维护（immutable state），变更走 reducer 式命令（dispatch({type:'RESIZE'})）。
- 策略：渲染策略按规模切换——<1000 行直接渲染 / 大数据行列双向虚拟化 / 编辑态走独立 overlay 层（编辑单元格覆盖在只读格上，防全表重渲）。
- 识别要点：能说清"单元格更新精确化"——列宽变化只重排该列 DOM（CSS 变量 --w-col3）而不是整表重渲染。

```typescript
// 表格状态与渲染策略
function tableReducer(state, action) {          // 命令 → 不可变状态转移
  switch (action.type) {
    case 'RESIZE': return { ...state, widths: { ...state.widths, [action.col]: action.w } };
    case 'SORT':   return { ...state, sort: action.col === state.sort?.col ? flip(action) : { ...action } };
    case 'SELECT': return { ...state, selection: action.range };
  }
}
const renderStrategy = (rows: number) =>
  rows < 1000 ? plainRender : virtualRender;    // 策略选择
// 列宽精确更新：
// document.documentElement.style.setProperty('--col-w-3', `${w}px`);
// CSS: .col-3 { width: var(--col-w-3) } —— 状态变量下推 CSS，DOM 不动
// 编辑 overlay：onlyOverlay = <div style={{ position: absolute, top: cellTop, left: cellLeft }}><input/></div>
```
