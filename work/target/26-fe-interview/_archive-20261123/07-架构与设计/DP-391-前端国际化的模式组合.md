## DP-391：国际化模式组合

**答**：
- i18n 的模式组合：策略（复数/格式化按 locale 策略——Intl API）、注册表（翻译键注册）、观察者（locale 变更通知所有消费组件）
- 实战结构：createI18n（内核：t 函数+locale 状态+订阅）+ 框架绑定（Vue 的 computed t / React 的 useSyncExternalStore）——内核框架无关
- 高级语义：插值（{name} 占位）、复数（Intl.PluralRules——one/other/few）、嵌套（消息内引用另一消息）
- 性能要点：翻译函数高频调用（列表每行）——消息查找是 Map O(1) 可接受；插值结果缓存（不变参数不重算）
- 深水点：切换语言的「全量重渲」——locale 变更触发所有文本组件重渲（响应式自动）——大页面切换语言的性能（chunk 懒加载语言包 + transition 过渡）

```javascript
function createI18n({ fallback = 'en' }) {
  let locale = fallback;
  const packs = new Map();
  const subs = new Set();
  const t = (key, params) => {
    const tpl = packs.get(locale)?.[key] ?? packs.get(fallback)?.[key] ?? key;
    return tpl.replace(/\{(\w+)\}/g, (_, k) => params?.[k] ?? `{${k}}`);
  };
  return { t, sub(fn) { subs.add(fn); return () => subs.delete(fn); },
    async setLocale(l) { packs.set(l, await import(`/locales/${l}.json`)); locale = l; subs.forEach((f) => f(l)); } };
}
```
