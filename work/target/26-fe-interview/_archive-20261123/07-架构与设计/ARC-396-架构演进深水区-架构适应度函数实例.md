## ARC-396：架构适应度函数：给架构装上自动回归仪表
**答**:
- 适应度函数（Fitness Function）= 对架构特性的自动验证：分层依赖不许倒置、模块间不许循环依赖、包体积不超预算、a11y 不回归、API 兼容不破坏。特性像测试一样在 CI 跑。
- 常见实例：dependency-cruiser 校验分层规则、madge 查循环依赖、size-limit 卡体积、 axe 自动扫 a11y、api-extractor 校验导出兼容性、性能预算工具卡 LCP 预算。
- 设计要点：阈值从"当前真实值 + 小步收紧"出发（一次卡太严全员被阻断会废掉体系）；违规需显式豁免（basline 文件留痕 + 有效期）。
- 演进式架构的核心：架构不再靠人记，而是靠函数守护；文档说"禁止直接引 service"没用，CI 拦截才有用。
- 覆盖节奏：先卡最容易破的（循环依赖/体积），逐步增加（性能预算/a11y/权限码规范）。
```javascript
// dependency-cruiser 规则示例
module.exports = {
  forbidden: [
    { name: 'no-view-to-service-import',
      from: { path: '^src/views' },
      to: { path: '^src/services', pathNot: '^src/services/index' } },  // 视图不得直引服务实现
    { name: 'no-circular', from: {}, to: { circular: true } }
  ]
};
```
