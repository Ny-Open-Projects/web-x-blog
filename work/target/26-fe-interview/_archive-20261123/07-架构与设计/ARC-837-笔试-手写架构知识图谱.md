## ARC-837：手写知识图谱

**题目**：实现架构知识的图谱化 `ArchKnowledgeGraph`：① 节点类型：决策（ADR）/模块/团队/人/故障/规范——多类型节点；② 关系类型：决策影响模块/模块归属团队/人维护模块/故障关联模块/规范约束模块——关系语义化；③ 查询能力：`impactOf(adrId)`（该决策影响了哪些模块→哪些团队）、`whoKnows(moduleId)`（谁维护该模块——专家定位）、`relatedIncidents(moduleId)`（该模块历史故障）；④ 图谱的自动构建：从 ADR 库/CODEOWNERS/故障库自动同步（手动维护必然过时）；⑤ 孤岛检测：无关联的孤立节点（没被任何决策/故障引用的模块——可能死代码）。写出实现。

```javascript
class ArchKnowledgeGraph {
  #nodes = new Map(); #edges = [];
  addNode(id, type, props) { this.#nodes.set(id, { id, type, ...props }); }
  relate(from, to, relation) {
    if (!this.#nodes.has(from) || !this.#nodes.has(to))
      throw new Error(`悬空边: ${from} → ${to}`);
    this.#edges.push({ from, to, relation });
  }
  query(type, id) {
    const out = { [type]: id };
    const traverse = (nodeId, relation, collected) => {
      for (const e of this.#edges)
        if (e.from === nodeId && e.relation === relation && !collected.has(e.to)) {
          collected.add(e.to);
          traverse(e.to, relation, collected);
        }
    };
    traverse(id, type === 'adr' ? 'affects' : 'maintains', new Set());
    return [...out[Object.keys(out)[0]]];
  }
  impactOf(adrId) {
    const modules = this.#neighbors(adrId, 'affects');
    const teams = modules.flatMap((m) => this.#neighbors(m, 'owned-by'));
    return { modules, teams: [...new Set(teams)] };    // 决策影响链
  }
  whoKnows(moduleId) { return this.#neighbors(moduleId, 'maintains'); }
  orphans() {
    const referenced = new Set(this.#edges.flatMap((e) => [e.from, e.to]));
    return [...this.#nodes.keys()].filter((id) => !referenced.has(id) && this.#nodes.get(id).type === 'module');
  }
  #neighbors(id, relation) {
    return this.#edges.filter((e) => e.from === id && e.relation === relation).map((e) => e.to);
  }
  syncFromSources({ adrs, codeowners, incidents }) {
    for (const adr of adrs) {
      this.addNode(`adr-${adr.id}`, 'adr', { title: adr.title });
      for (const mod of adr.affects ?? []) {
        this.addNode(`mod-${mod}`, 'module', { path: mod });
        this.relate(`adr-${adr.id}`, `mod-${mod}`, 'affects');
      }
    }
    // codeowners / incidents 同理自动同步 — 图谱保鲜
  }
}
```

**评分点**：
- 多类型节点与语义化关系（决策影响模块/人维护模块）
- 三种查询（影响链/专家定位/故障关联——图谱的实用查询）
- 自动同步（ADR/OWNER/故障库驱动——防手动过时）
- 孤岛检测（无关联模块——死代码线索）
