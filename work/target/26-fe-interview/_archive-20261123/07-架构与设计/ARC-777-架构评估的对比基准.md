## ARC-777：对比基准

**答**：
- 基准的三层：自身历史基准（环比——我有没有进步）、内部对等基准（横比——同类应用对比）、行业基准（Lighthouse 分位——行业水平在哪）——三层基准回答「好不好」
- 内部对等的公平性：业务复杂度不同的应用对比要校准（复杂度加权）——裸比会误导
- 行业基准的获取：公开数据（HTTP Archive/Core Web Vitals 行业分位）+ 同行交流——外部基准防止内卷式自我满足
- 基准的动态性：基准随行业标准演进（INP 替代 FID）——基准体系也要升级
- 深水点：基准的「使用纪律」——基准用于定位差距而非排名羞辱——排名文化会扭曲数据

```text
对比基准:
  三层: 自身环比 / 内部横比 / 行业分位
  公平: 复杂度加权
  外部: HTTP Archive / CWV 分位
  动态: 基准随标准演进
  纪律: 定位差距, 非排名羞辱
```
