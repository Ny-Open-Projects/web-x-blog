## DP-548：笔试：手写快捷键系统

**题目**：实现应用的快捷键系统 `ShortcutManager`：① 注册：`register('mod+s', 'save', handler, { scope: 'editor' })`——组合键解析（mod = ctrl/meta 平台自适应）；② 作用域：editor 作用域内生效（输入框 focus 时编辑快捷键让位于输入——scope 栈）；③ 冲突检测：注册时同组合键冲突告警（先注册者优先——或提示冲突）；④ 快捷键的命令绑定：快捷键触发命令（命令模式——快捷键是命令的触发器）；⑤ 帮助面板：所有快捷键清单自动生成（? 键弹出——注册表即文档）。写出实现。

```javascript
class ShortcutManager {
  #bindings = new Map();   // combo -> { command, scope, handler }
  #scopeStack = ['global'];
  register(combo, command, handler, { scope = 'global' } = {}) {
    if (this.#bindings.has(combo))
      console.warn(`[shortcut] 冲突: ${combo} 已绑定 ${this.#bindings.get(combo).command}`);
    this.#bindings.set(combo, { command, handler, scope });
  }
  handle(e) {
    const combo = normalize(e);                        // 'mod+s' (mod = ctrl|meta)
    const binding = this.#bindings.get(combo);
    if (!binding) return;
    const activeScope = this.#scopeStack.at(-1);       // 作用域栈顶
    if (binding.scope !== 'global' && binding.scope !== activeScope) return;
    e.preventDefault();
    commandRegistry.exec(binding.command);             // 命令模式: 触发命令
  }
  pushScope(s) { this.#scopeStack.push(s); }
  popScope() { this.#scopeStack.pop(); }
  list() { return [...this.#bindings.entries()].map(([combo, b]) => ({ combo, command: b.command, scope: b.scope })); }
}
// normalize: e.ctrlKey/metaKey + e.key.toLowerCase() → 'mod+s'
```

**评分点**：
- mod 的平台自适应（ctrl/meta 统一）
- 作用域栈（输入框内编辑快捷键让位——scope 优先级）
- 冲突检测 + 命令绑定（快捷键是命令的触发器）
- 注册表即帮助文档（? 键面板自动化）
