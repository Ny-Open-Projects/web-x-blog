## DP-454：任务队列模式

**答**：
- 任务队列的模式分解：策略（调度策略：FIFO/优先级/截止时间）、观察者（队列状态订阅：深度/活跃数）、命令（任务即命令——可取消可重试）、状态机（任务状态：queued→running→done/failed/cancelled）
- 优先级与饿死防护：优先级队列 + 老化（等待超时自动升级——低优先级不被饿死）
- 队列的可观测性：深度告警（积压=产能不足）、耗时分布（排队 vs 执行——优化归因）
- 取消语义：惰性取消（执行时检查标记——比堆删除简单且正确）
- 深水点：队列的「并发维度隔离」——全局并发上限 + 按类并发上限（图片队列不影响 API 队列）——舱壁模式的队列化

```javascript
class TaskQueue {
  #lanes = { high: [], normal: [], low: [] }; #flying = 0;
  push(key, fn, lane = 'normal') {
    // 同 key 去重 + 返回 promise
    return new Promise((res, rej) => { this.#lanes[lane].push({ key, fn, res, rej, cancelled: false }); this.#drain(); });
  }
  #drain() {
    while (this.#flying < this.max) {
      const t = this.#lanes.high.shift() ?? this.#lanes.normal.shift() ?? this.#lanes.low.shift();
      if (!t) break; if (t.cancelled) continue;       // 惰性取消
      this.#flying++;
      t.fn().then(t.res, t.rej).finally(() => { this.#flying--; this.#drain(); });
    }
  }
}
```
