## ARC-781：评估改进闭环

**答**：
- 闭环的完整环：评估发现 → 改进立项 → 执行 → 复测验证 → 指标改善（或调整方案）——评估的价值在闭环完成时兑现
- 闭环的关键环节：发现到立项的转化率（多少评估发现真的立项——转化率低=评估白做）→ 立项到完成的达成率 → 完成到指标改善的验证率——三率健康 = 闭环有效
- 闭环的拖累因素：改进项与业务冲突（资源排不上）、改进项无 owner、复测缺失——每个拖累因素有对策
- 闭环的节奏管理：改进项进迭代（20% 容量——与还债同池）
- 深水点：闭环的「优先级纪律」——评估发现按「影响面×修复成本」排序——全修不可能，Top N 才有效

```text
评估闭环:
  环: 发现→立项→执行→复测→改善
  三率: 立项转化率/达成率/验证率
  拖累: 业务冲突/无owner/无复测 → 对策
  排序: 影响面×修复成本 Top N
```
