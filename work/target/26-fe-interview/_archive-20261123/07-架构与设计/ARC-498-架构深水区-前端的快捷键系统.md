## ARC-498：快捷键系统架构
**答**:
- 架构核心：全局快捷键注册表（keymap：键 → 命令引用 + 上下文条件 + 作用域），统一 keydown 捕获分发（capture 阶段），按键规范化（大小写/修饰符顺序/代码 vs 键值——用 e.code 支持非英文布局）。
- 作用域与冲突：作用域栈（全局 < 路由 < 组件 < 弹层），内层优先；命令系统引用（ARC-456），命令不可用时快捷键自动失效；冲突治理：注册时检测重复告警，平台保留键（浏览器/系统）禁用清单。
- 平台差异：Mac（Meta）vs Win/Linux（Ctrl）自动映射；非 Mac 上禁用 Meta 组合；输入法组合态（composition）不触发。
- 可发现性：快捷键面板（? 唤起 cheat sheet 自动从 keymap 生成）、菜单标注（菜单项显示绑定键）、自定义键位（用户覆盖，持久化，冲突提示）。
- 录制与测试：键位录制器（用户按键生成 binding）、E2E 键盘操作走同一 keymap（保证 UI 展示与实际行为一致）。
```javascript
const keymap = new ScopeStack();
keymap.register({ keys: 'mod+k', scope: 'global', command: 'openSearch', when: () => !editing });
keymap.register({ keys: 'Escape', scope: 'dialog', command: 'closeDialog' });
document.addEventListener('keydown', (e) => {
  if (e.isComposing) return;                                  // IME 保护
  const binding = keymap.match(normalize(e), currentScope());
  if (binding) { e.preventDefault(); commands.run(binding.command); }
}, true);
```
