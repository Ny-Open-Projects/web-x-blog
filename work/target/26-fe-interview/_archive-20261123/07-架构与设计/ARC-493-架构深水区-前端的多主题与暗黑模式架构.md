## ARC-493：多主题与暗黑模式架构
**答**:
- 实现基线：Design Token 三层（ARC-029）+ CSS 变量切换——语义 token（--bg-surface）在 theme class/data-theme 下重新映射，组件只用语义 token 不感知主题。
- 暗黑模式细节：跟随系统（prefers-color-scheme）+ 用户手动覆盖（三态：auto/light/dark，持久化）；图片与富内容适配（dark 下的图片蒙版/重绘插画）；第三方组件强制覆盖（Chart 主题同步切换）。
- 无闪变：首屏主题在 HTML 解析期确定（cookie/sessionStorage 内联 script 提前设置 data-theme，防 FOUC）；SSR 时按 cookie 服务端注入。
- 平台差异：小程序/App 端主题方案不同（wxss 变量/原生主题），token 源头唯一生成各端产物（ARC-163）。
- 治理：色值对比度自动检测（暗黑下 WCAG AA）进 CI；新增颜色必须走 token 申请流程（禁硬编码 hex）。
```javascript
// 无闪变主题初始化（HTML head 内联）
(function () {
  const pref = localStorage.getItem('theme') || 'auto';
  const dark = pref === 'dark' || (pref === 'auto' && matchMedia('(prefers-color-scheme: dark)').matches);
  document.documentElement.dataset.theme = dark ? 'dark' : 'light';
})();
// 切换：setTheme(p) → 持久化 + documentElement.dataset.theme 更新（CSS 变量随选择器切换）
```
