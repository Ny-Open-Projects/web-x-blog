## ARC-505：空间型应用架构
**答**:
- 特征：元素无固定布局（自由定位）、缩放平移（视口坐标系）、可能协作（ARC-379）。架构核心：场景模型（元素列表 + 空间索引）+ 视口渲染（只渲染可见区域，ARC-122 画布引擎）。
- 空间索引：元素数量大时用网格/四叉树索引（拾取/视口剔除 O(logn)），索引增量维护（元素移动时更新索引而非重建）。
- 视口渲染：世界坐标 ↔ 屏幕坐标变换收口；层级分层（背景网格/元素层/选择框层/协作者光标层各自 Canvas/DOM 层）；缩放时 LOD（缩得小渲染简化版）。
- 数据模型：元素 schema 版本化（新增元素类型兼容旧文档）、位置精度（浮点世界坐标 + 相对锚点）、序列化紧凑（万元素文档体积控制——二进制/扁平数组）。
- 性能预算：平移缩放 60fps（transform 层级不动数据）、拾取 < 16ms、万元素场景内存 < 200MB（离屏元素卸载）。
```javascript
// 视口剔除 + 空间索引
class SpaceGrid {                                                // 简单网格索引
  constructor(cell = 500) { this.cell = cell; this.map = new Map(); }
  key(x, y) { return `${Math.floor(x / this.cell)},${Math.floor(y / this.cell)}`; }
  insert(el) { this.map.get(this.key(el.x, el.y))?.push(el.id) ?? this.map.set(this.key(el.x, el.y), [el.id]); }
  query(bbox) {                                                  // 视口内元素
    const out = new Set();
    for (const id of cellsIn(bbox, this.cell).flatMap(k => this.map.get(k) ?? [])) out.add(id);
    return out;                                                  // 只渲染可见
  }
}
```
