## DP-440：框架内化的模式

**答**：
- 框架即模式的集合：React（观察者：setState 订阅、命令：事件合成、策略：lane 优先级）、Vue（代理：reactive、观察者：依赖收集、策略：patchFlag）、Vue Router/React Router（责任链：守卫链、状态机：导航生命周期）
- 面试的高级表达：讲框架 API 时点破其模式本质（useSyncExternalStore = 观察者+快照代理；v-perm = 装饰器）——「知其然知其所以然」
- 模式内化的收益：理解框架的扩展点（框架的 hook 体系就是模板方法的函数式内化）
- 举例深挖：Context 是提供者模式的内置化（React 18 的 useSyncExternalStore 补齐撕裂防护——模式演进的案例）
- 深水点：框架选择模式的「原因」——React 选 vdom（并发渲染需要快照语义）而非细粒度——模式选择是架构约束驱动

```text
框架 = 模式集合:
  React: setState(观察者) + lane(策略) + ErrorBoundary(空对象/边界)
  Vue:   reactive(代理) + watch(观察者) + KeepAlive(备忘录+享元)
  Router: 守卫链(责任链) + meta(策略)
高级表达: 讲 API 点破模式本质 → 知其所以然
```
