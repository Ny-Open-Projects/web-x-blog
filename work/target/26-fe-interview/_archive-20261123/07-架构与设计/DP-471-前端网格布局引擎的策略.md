## DP-471：瀑布流策略

**答**：
- 瀑布流的策略分解：列分配策略（最短列优先——高度均衡）、测量策略（已知宽高比/异步实测）、重排策略（resize 防抖重排）、占位策略（宽高比预占防 CLS）
- 与虚拟列表的组合：瀑布流 + 虚拟化（列内独立虚拟化复杂——按行分块渲染的折中）
- 图片加载的插入策略：加载完成插入 vs 预留插入（跳动的根源）——「尺寸已知才插入」的纪律
- 深水点：瀑布流的「移动端性能」——transform 定位（不触发 layout）+ will-change 节制——绝对定位的批量 diff

```javascript
function layout(items, colCount) {
  const heights = new Array(colCount).fill(0);
  for (const item of items) {
    const col = heights.indexOf(Math.min(...heights));   // 最短列优先
    const h = colWidth * item.h / item.w;
    item.pos = { x: col * (cw + gap), y: heights[col] };
    heights[col] += h + gap;
  }
  return Math.max(...heights);
}
// 占位: <div style="aspect-ratio: w/h"> — 尺寸已知才插 DOM
```
