## DP-472：草稿自动保存

**答**：
- 草稿保存的策略组合：触发策略（防抖 3s/失焦/切后台/关键节点）、存储策略（本地 IndexedDB vs 服务端草稿接口——跨端续写需服务端）、冲突策略（服务端已有新版本——本地草稿冲突处理）、清理策略（TTL 过期/提交后删除）
- 自动保存的「价值判断」——dirty 检测（无变化不保存——避免无意义写入）
- 恢复的用户告知：检测到草稿 → 「恢复/放弃」选择（静默恢复会让用户困惑——显式确认）
- 深水点：草稿的「敏感数据处理」——草稿含敏感信息（身份证）的加密存储与 TTL 短期清理——草稿是数据泄漏面

```javascript
const draft = createDraftSaver({
  key: 'form:order',
  trigger: [debounceInput(3000), onBlur, onHide],
  dirtyCheck: (state) => !deepEqual(state, initial),
  conflict: (local, remote) => showConflictDialog(local, remote),   // 三路合并 UI
  ttl: 24 * 3600e3,
});
// 恢复告知: 检测到草稿 → dialog('检测到未完成的表单, 恢复?')
```
