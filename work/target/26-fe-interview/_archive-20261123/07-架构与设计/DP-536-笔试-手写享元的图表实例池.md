## DP-536：笔试：手写图表池

**题目**：实现 ECharts 实例池（大屏场景）：① 同配置复用：相同尺寸+主题的图表实例共享（回收隐藏实例——新图表先取池）；② 生命周期：mount（池取/建）→ update（setOption）→ unmount（归还池）；③ 实例的清理协议：归还前清 option（旧数据残留）+ 解绑事件；④ 池上限与淘汰：池满最久未用的销毁（dispose——显存释放）；⑤ 防泄漏：页面卸载时全部池实例 dispose（泄漏兜底）。写出实现。

```javascript
class ChartPool {
  #pool = []; #active = new Map();
  acquire(el, config) {
    const key = `${config.width}x${config.height}:${config.theme}`;
    let inst = this.#pool.find((x) => x.key === key)?.inst;
    if (inst) {
      this.#pool = this.#pool.filter((x) => x.inst !== inst);   // 从池取出
      el.appendChild(inst.getDom());
      inst.resize();
    } else {
      inst = echarts.init(el, config.theme);
    }
    this.#active.set(el, { inst, key, at: Date.now() });
    return inst;
  }
  release(el) {
    const entry = this.#active.get(el);
    if (!entry) return;
    entry.inst.clear();                                  // 清 option (防数据残留)
    entry.inst.off();                                    // 解绑事件
    entry.inst.getDom().remove();
    this.#pool.push(entry);
    if (this.#pool.length > this.max) {
      const oldest = this.#pool.shift();
      oldest.inst.dispose();                             // 淘汰: 显存释放
    }
    this.#active.delete(el);
  }
  disposeAll() { [...this.#active.values(), ...this.#pool].forEach((x) => x.inst.dispose()); }   // 泄漏兜底
}
```

**评分点**：
- 同配置复用（key = 尺寸+主题——享元的缓存键覆盖全部内部状态）
- 清理协议（clear+off——归还前清数据与事件）
- 池上限淘汰（最久未用 dispose——显存管理）
- disposeAll 的泄漏兜底（页面卸载）
