## DP-476：权限按钮渲染

**答**：
- 权限按钮的策略选项：隐藏（remove DOM——干净但不留痕）、禁用（disabled+tooltip 说明——用户知道功能存在）、替换（降级为「申请权限」按钮——转化引导）——三种策略的 UX 语义
- 策略的选择依据：权限是否可申请（可申请 → 引导按钮转化；不可申请 → 隐藏）——「无权限」不是统一处理
- 响应式权限：权限集变更（切角色）时按钮自动更新（观察者订阅权限 store）
- 深水点：权限渲染的「闪烁问题」——权限接口未返回时按钮闪现（默认隐藏 + 权限就绪后渲染——default-deny 渲染策略）

```javascript
const strategies = {
  hide: (el) => el.remove(),
  disable: (el, tip) => { el.disabled = true; el.title = tip; },
  upgrade: (el, applyUrl) => replaceWithApplyBtn(el, applyUrl),   // 申请权限转化
};
// default-deny: 权限未就绪 → 不渲染按钮 (防闪现)
// v-perm="{ perm: 'order:delete', fallback: 'upgrade' }"
```
