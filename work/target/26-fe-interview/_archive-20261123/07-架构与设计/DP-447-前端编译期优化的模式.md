## DP-447：编译期优化模式

**答**：
- 编译期的模式应用：访问者（AST 遍历——Babel/Vue 编译器）、策略（按目标环境产出不同代码——browserslist）、缓存（编译产物缓存——code cache）、备忘录（快照对比——增量编译）
- Vue 编译器的策略应用：patchFlag（编译期标记动态性——运行时靶向更新的策略输入）——「编译期收集信息为运行时策略服务」
- React Compiler 的边界：静态可分析的自动 memo——动态性（第三方突变）放弃优化降级运行时
- 深水点：编译期优化的「可观测性」——编译产物的 diff review（优化是否生效——快照进 PR）
- 
```javascript
// 访问者: 自定义编译插件 (Vue template → 收集静态节点)
module.exports = () => ({
  visitor: {
    ElementNode(path) {
      if (isStatic(path.node)) path.node.patchFlag = HOISTED;   // 标记供运行时策略
    },
  },
});
// 编译产物 diff 进 PR — 优化可 review
```
