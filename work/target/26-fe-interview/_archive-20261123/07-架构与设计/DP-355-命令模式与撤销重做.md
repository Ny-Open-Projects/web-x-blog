## DP-355：命令模式：撤销重做

**答**：
- 命令模式核心：把操作封装为对象（execute/undo）——编辑器撤销/画布操作/审批流回退
- 实战结构：Command { execute, undo, label } + History（undo 栈/redo 栈/指针）；undo 是「精确逆操作」不是「恢复快照」（快照法内存大——两者取舍：命令法精确但每操作要写逆操作）
- 组合命令：宏命令（Composite——一组命令作为一次 undo 单元：拖拽 = 移动+吸附）——复合操作的原子性
- 与不可变状态法的取舍：immer + 状态快照（简单通用）vs 命令对象（内存省/可带语义——「撤销了粘贴」而非「回到三步前」）
- 深水点：撤销的「语义分组」——连续输入合并为一次撤销（500ms 窗口内 merge）——命令的 merge 协议

```javascript
class History {
  #undo = []; #redo = [];
  execute(cmd) {
    cmd.execute();
    this.#undo.push(cmd);
    this.#redo = [];                              // 新操作清空 redo
  }
  undo() { const c = this.#undo.pop(); c?.undo(); c && this.#redo.push(c); }
  redo() { const c = this.#redo.pop(); c?.execute(); c && this.#undo.push(c); }
}
// 命令示例: { label: '移动节点', execute: () => move(a, b), undo: () => move(b, a) }
// 合并协议: cmd.merge?.(nextCmd) — 连续输入 500ms 内合并为一条
```
