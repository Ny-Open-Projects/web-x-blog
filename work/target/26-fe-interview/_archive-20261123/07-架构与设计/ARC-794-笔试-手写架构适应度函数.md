## ARC-794：架构适应度函数

**题目**：实现架构适应度函数集（Architectural Fitness Functions）——架构规则的自动化测试：① 依赖规则：「UI 组件不得直接 import API 层」（必须经 service 层）；② 分层规则：「底层不得 import 上层」（layered 依赖方向校验）；③ 尺寸规则：「单文件 ≤300 行 / 单组件 ≤200 行」；④ 循环依赖检测（模块间环 = fail）；⑤ 输出：违规清单（文件+规则+建议）+ 退出码（CI 门禁）。基于文件依赖扫描实现。写出实现。

```javascript
const fs = require('fs'), path = require('path');
const RULES = [
  { name: 'ui-no-direct-api', test: (from, to) =>
      !(from.startsWith('src/ui/') && to.includes('/api/')),
    hint: 'UI 必须经 service 层调用 API' },
  { name: 'layer-direction', layers: ['ui', 'service', 'store', 'core'],
    test: (from, to) => {
      const fl = from.split('/')[1], tl = to.split('/')[1];
      const i = this.layers.indexOf(fl), j = this.layers.indexOf(tl);
      return i === -1 || j === -1 || i >= j;   // 只准向下依赖
    } },
  { name: 'file-size', maxLines: 300 },
];

function fitnessCheck(srcDir) {
  const violations = [];
  const files = collect(srcDir);
  const depGraph = buildGraph(files);              // import 语句解析
  for (const [from, deps] of depGraph) {
    for (const to of deps) {
      for (const rule of RULES) {
        if (rule.test && !rule.test(from, to))
          violations.push({ rule: rule.name, from, to, hint: rule.hint });
      }
    }
  }
  // 循环依赖 (DFS 环检测)
  const cycle = findCycle(depGraph);
  if (cycle) violations.push({ rule: 'no-cycle', cycle });
  // 文件大小
  for (const f of files)
    if (f.lines > 300) violations.push({ rule: 'file-size', file: f.path, lines: f.lines });
  console.log(violations.length ? violations : 'FITNESS OK');
  process.exit(violations.length ? 1 : 0);          // CI 门禁
}
// buildGraph: 解析 import/export 语句 → { file: [deps] }
// findCycle: DFS 三色标记 → 返回环路径
```

**评分点**：
- 依赖方向规则的形式化（分层 test 函数）
- 循环依赖检测（DFS 环路径输出）
- 尺寸类静态规则与依赖类规则统一处理
- CI 门禁语义（违规清单 + exit 1）
