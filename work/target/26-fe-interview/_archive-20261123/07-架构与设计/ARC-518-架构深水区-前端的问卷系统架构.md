## ARC-518：问卷系统前端架构
**答**:
- 题型引擎：题型注册表（单选/多选/填空/矩阵/评分/排序/上传，各有 render + 校验 + 数据 schema）——新题型插件化注册，引擎不感知具体题型。
- 逻辑跳转：显题逻辑（前题答案决定后题显隐/必填）声明为条件 DAG（ARC-506），运行时按当前答案集求值；跳题后返回时答案保留但按新逻辑重验。
- 分页与进度：长问卷自动分页（按逻辑组断页）、进度条按"有效题数"算（跳过的题不计入，防止进度倒退困惑）。
- 数据可靠性：草稿自动保存（断网可续答 ARC-374）、提交幂等（防双击重复提交）、题目随机化与选项随机（按被试 hash 固定防刷新变化）。
- 合规与质量：匿名/实名声明、必答与预筛选（甄别题防乱答）、提交后确认页防回改。
```javascript
// 显题逻辑求值
const logic = [{ show: 'q5', when: { all: [{ q: 'q3', op: 'eq', value: 'yes' }] } }];
function visibleQuestions(answers) {
  return questions.filter(q => {
    const rule = logicMap[q.id];
    if (!rule) return true;
    return evalConditions(rule.when, answers);                   // 沿 DAG 重算显隐
  });
}
// 提交：只收集可见题答案 + 逻辑路径快照（便于分析跳转漏斗）
```
