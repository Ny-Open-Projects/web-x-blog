## ARC-515：网盘类应用前端架构
**答**:
- 上传链路（ARC-377 深化）：哈希计算下沉 Worker（大文件主线程算哈希会冻结 UI，分块流式哈希边读边算）；秒传（哈希命中即完成）；分片直传 + 分片并发池 + 失败重试；上传队列持久化（IndexedDB，关浏览器恢复续传）。
- 下载体验：大文件下载走签名 URL + Range 断点续传（ARC-340）；预览优先（视频边下边播、Office 转码预览、图片缩略图链路 ARC-341）。
- 列表架构：万级文件列表虚拟滚动 + 分页懒加载；目录树导航与面包屑；排序/筛选状态持久化。
- 传输调度：多任务并发上限（全局 2~3 个活跃任务，避免抢带宽互相饿死）、优先级（用户点击的置顶）、速度显示与预估剩余。
- 可靠性对账：任务状态机（服务端任务表 + 端上状态同步），异常任务（哈希不符/配额满）明确报因；回收站与误删恢复。
```javascript
// Worker 流式哈希
hashWorker.postMessage({ cmd: 'hash', file }, [transferable]);  // 边读边算
hashWorker.onmessage = async ({ data: { hash } }) => {
  const r = await api.fastUpload(hash);                          // 秒传检查
  if (!r.exists) await uploadChunks(file, hash, pool);           // 分片直传
};
// 全局调度器：QueueManager.maxActive = 3，任务优先级可变（点击提权）
```
