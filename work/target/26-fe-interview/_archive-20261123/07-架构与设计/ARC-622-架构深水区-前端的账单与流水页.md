## ARC-622：账单流水页
**答**:
- 数据量挑战：账户流水百万级——查询协议（cursor 分页 + 时间范围 + 类型筛选——服务端索引适配 NODE-400）、月度汇总（按月分组 + 月小计——服务端聚合返回，前端不做合计计算 ARC-582）。
- 展示架构：虚拟滚动（ARC-442）+ 按月吸顶分组（ARC-567 分组列表）、类型筛选联动（收支/业务类型——筛选状态入 URL ARC-389）、明细展开（单笔流水展开关联单据：跳订单/退款单）。
- 导出与对账：流水导出（ARC-581 合规链路——含敏感脱敏）、对账自证（余额 = 期初 + 流水累计——提供"余额核对"入口：服务端校验并展示核对结果，用户自助验证数据正确性——减少客诉）。
- 一致性：流水与余额同源（同接口同缓存键——ARC-386 列表详情一致性）、实时性标注（流水延迟说明——支付中状态的流水单独分区展示）。
- 性能：金额列格式化收敛（Price 组件——千分位/币种 ARC-569）、流水行 memo（值变更局部更新）。
```javascript
// 流水分页 + 月汇总
const { items, monthSummary } = await api.flows({ cursor, range, type }); // cursor 分页
renderVirtualList(items, { groupBy: 'month', sticky: true, summary: monthSummary }); // 月小计吸顶
// 余额核对：GET /api/balance/reconcile → { ok, checkedAt }   // 服务端校验自证
```
