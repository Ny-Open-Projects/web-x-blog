## ARC-479：前端相关成本的可观测与优化闭环
**答**:
- 前端相关成本构成：CDN 流量与请求数、第三方 API 调用（地图/短信验证/风控）、媒体处理（转码/缩略图）、推送通道。特征是随流量线性增长，浪费源于资源治理缺失。
- 成本可观测：按应用/域分账（CDN 日志按 Referer 归集）、按资源类型拆解（图片占 70%？视频预载失控？）、趋势与异动告警（成本周环比 > 20% 排查）。
- 优化闭环杠杆：图片治理（格式/尺寸/懒加载，通常最大头）、请求治理（合并/缓存命中率提升）、第三方调用治理（SDK 懒加载、调用去重）、媒体分级（清晰度档位与预载策略）。
- 架构约束进流程：新页面发布前成本预估（资源清单 × 单价），大促前带宽预算审批（ARC-446）。
- 防异动：异常大的单用户流量（爬虫/异常客户端）识别与限流。
```javascript
// 成本分账与异动检测
function costBreakdown(cdnLog) {
  const byApp = groupBy(cdnLog, l => appOf(l.referer));
  const byType = groupBy(cdnLog, l => extType(l.path));        // js/css/img/video
  return { byApp, byType, top: topObjects(cdnLog, 10) };       // Top 对象定位浪费源
}
// 异动：weekly(img.cost) / lastWeek > 1.2 → 排查（新页面未压缩？爬虫？）
```
