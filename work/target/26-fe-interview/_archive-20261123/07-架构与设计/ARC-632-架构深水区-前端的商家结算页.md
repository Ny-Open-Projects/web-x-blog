## ARC-632：商家结算页
**答**:
- 结算模型：账期制（订单完成 → 账期结算周期 → 结算单生成——结算单状态机：待结算/结算中/已结算）、结算单明细（订单清单 + 扣项：佣金/退款/罚款——金额构成透明）。
- 页面架构：结算概览（各账期余额汇总 ARC-622 账单模式）、结算单列表与明细（虚拟滚动 + 筛选——结算单 → 订单级明细下钻）、提现（可提余额 → 提现流程 ARC-621——账期未到的余额不可提）。
- 对账能力：商家对账单导出（ARC-630 财务导出合规链路）、差异申诉（商家对结算金额有异议 → 申诉工单——关联订单明细定位）。
- 一致性：结算金额与订单流水一致性（可核对入口：结算单金额 = 订单明细加总——自证路径 ARC-622）、扣项透明（每项扣款有依据链接：违规记录/协议条款）。
- 多店铺/多主体：主体切换（ARC-559 完全环境切换）、多币种结算（跨境商家 ARC-569）。
```javascript
// 结算单明细
const st = await api.settlement(settlementId);                   // { gross, deductions[], net, state }
<SettlementBill {...st} drillDown={orderDetail} />               // 明细下钻 + 扣项依据链接
if (st.state === 'settled') <WithdrawPanel available={st.net} /> // 已结算可提现
```
