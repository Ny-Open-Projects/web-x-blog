## ARC-591：深色模式图片适配
**答**:
- 适配分层：透明底图标（跟随主题着色——单色图标用 currentColor/CSS mask，一套资源两主题）、内容图（照片不动——深色下加轻蒙版防刺眼）、设计图/插画（双版本资源：dark 变体，命名约定 + 自动选择）、富文本内嵌图（作者上传——运行时滤镜降级方案 brightness(0.85) 配置化）。
- 资源管理：dark 变体命名协议（xxx.dark.avif）+ 按主题选择（picture media query 或 CSS 变量切换 src——收口在 Img 组件）、缺失 dark 变体的降级（原图 + 蒙版）。
- 自动生成链路：上传时批量生成 dark 变体（亮度/对比度自动调整 ARC-341 处理链路扩展）——运营不用手动出双版本。
- 体验细节：图片加载的占位（暗色骨架——亮色占位闪屏）、混排内容对比度（图下文字背景保证对比度 WCAG ARC-493）、动效与主题（暗色下动画时长/强度一致——只换色不换行为）。
- 验证：双主题视觉回归（ARC-561 快照矩阵）、对比度自动检测进 CI。
```css
/* dark 变体选择 */
<img srcset="hero.avif" media="(prefers-color-scheme: light)">
<picture>
  <source srcset="hero.dark.avif" media="(prefers-color-scheme: dark)">
  <img src="hero.avif" alt="...">
</picture>
/* 内容图轻蒙版 */
:root[data-theme=dark] .rich img { filter: brightness(.85); }
```
