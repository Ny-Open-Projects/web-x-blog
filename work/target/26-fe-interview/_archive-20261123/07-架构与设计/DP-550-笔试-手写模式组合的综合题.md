## DP-550：笔试：营销活动页综合设计

**题目**：设计一个营销活动页（倒计时 + 秒杀 + 分享裂变 + 实时库存）的模式组合方案：① 倒计时（观察者 ticker + 状态机：预热/进行中/结束——三阶段 UI）；② 秒杀下单（命令幂等 + 乐观 UI + 失败重试）；③ 实时库存（观察者推送 + 阈值显示策略：>50 显示充足 / <10 显示紧张 / 0 售罄）；④ 分享裂变（命令 + 归因参数 + 防刷）；⑤ 要求：画出模式协作链（用户操作 → 模式 → 数据流）、说明每个模式的选型理由、标注边界（秒杀防刷的层级）。写出设计方案。

```text
模式协作链:
  进入页面 → [备忘录: 上次数据缓存渲染] → [策略: 三阶段 UI]
  倒计时 → [观察者: ticker] → [状态机: 预热→进行中(秒杀按钮亮)→结束]
  秒杀点击 → [命令: 幂等键 skuId+uid] → [乐观: 按钮立即"抢购中"]
           → 失败 → [策略: 重试1次 → 提示补货提醒]
  库存推送 → [观察者: ws] → [策略: 阈值显示] → 进度条/售罄
  分享 → [命令: shareId] → 落地解析 → [策略: 防刷(设备+频率)]
选型理由:
  倒计时用观察者(多点消费) / 秒杀用命令(幂等+可审计) / 库存用策略(阈值是产品规则)
边界: 防刷三层(前端频率+服务端幂等+风控规则) — 前端只是第一层
```

**评分点**：
- 模式协作链的完整性（用户操作 → 模式 → 数据流）
- 每模式的选型理由（为什么观察者/为什么命令——意图驱动）
- 边界的诚实标注（防刷三层——前端只是第一层）
- 倒计时三阶段的状态机（预热/进行中/结束——UI 联动）
