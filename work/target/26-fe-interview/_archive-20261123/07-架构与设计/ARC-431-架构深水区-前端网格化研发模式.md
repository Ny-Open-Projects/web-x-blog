## ARC-431：前端网格化/Fullstack 化研发模式如何设计？
**答**:
- 模式定义：前端工程师按业务域纵向切分（商品域/交易域），域内前后端一体（BFF 由前端写），横向有平台组供基建。减少跨团队接口沟通成本，交付单元从"页面"变成"业务域"。
- 前提条件：Node/BFF 基建成熟（NODE 系列）、全栈能力培训体系、稳定性责任前移（前端承担域内服务可用性）。
- 平台组与域组分工：平台组提供框架/构建/监控/发布（产品化服务），域组自助消费；域内技术选型自由度在平台框架边界内。
- 协作协议：域间通过 API/契约交互，组件与工具通过平台共享；跨域公共逻辑（登录/权限）由平台统一提供，防止各域重复造轮子。
- 度量与风险：域内交付周期变短是收益；风险是能力参差——用平台兜底（默认配置/脚手架）+ code review 跨域支援机制。
```javascript
// 组织与技术架构映射（康威定律应用）
const org = {
  platform: ['framework', 'build', 'monitor', 'release'],       // 横向基建
  domains: [
    { name: 'goods', fe: 4, be: 2, bff: 'frontend-owned' },     // 纵向域
    { name: 'trade', fe: 5, be: 3, bff: 'frontend-owned' }
  ],
  boundary: '域间只走 API 契约，公共能力走平台 SDK'
};
```
