## ARC-579：多语言无障碍交叉
**答**:
- 交叉点：lang 属性正确（每语言切换 html lang——屏幕阅读器按 lang 切发音引擎，lang 错误 = 全文乱读）、图片替代文本翻译（alt 文案进语言包——alt 是内容不是装饰）、方向与焦点（RTL 下焦点顺序与屏幕阅读器导航 ARC-567）、数字/日期的读法（"3.5k"读作什么——aria-label 展开为完整表达）。
- 架构落点：i18n 协议扩展 a11y 字段（语言包条目支持 alt/aria 描述——翻译流水线覆盖 a11y 文案，不只可见文案 ARC-242）、组件库 a11y 文案国际化（组件内置的"加载中/关闭"等 aria 文案走 i18n——组件库多语言提供）。
- 切换一致性：语言切换时动态更新（lang 属性/文档标题/动态 aria——切换不是只换文本）。
- 检测：自动化（lang 属性/missing aria-label 扫描进 a11y 巡检 ARC-577 扩展多语言规则）+ 多语言屏幕阅读器抽查（主语言手工 + 次语言抽查关键路径）。
- 组织：翻译团队包含 a11y 意识培训（alt 文案的质量标准——"图片"两个字的 alt 等于没有）。
```javascript
// a11y 文案国际化协议
const pack = {
  en: { 'dialog.close': 'Close', 'img.chart.alt': 'Sales trend chart, up 12% this month' },
  zh: { 'dialog.close': '关闭', 'img.chart.alt': '销售趋势图，本月上涨 12%' }
};
<img src={chart} alt={t('img.chart.alt')} />                     // alt 进语言包
// 语言切换：document.documentElement.lang = locale（读法联动）
```
