## ARC-833：手写多租户配置

**题目**：实现 SaaS 前端的多租户配置隔离 `TenantConfig`：① 租户配置：{ tenantId, theme, features: {}, limits: {}, brandAssets }——按租户隔离；② 配置优先级：租户配置 > 租户套餐默认（free/pro/enterprise）> 全局默认——三层；③ 能力门控：`can(tenantId, capability)`——套餐决定可用能力（enterprise 才有 SSO）；④ 配置热更新：租户配置变更 → 订阅的页面实例收到通知（不刷新页面——主题/开关即时生效）；⑤ 隔离审计：租户 A 的配置变更不影响租户 B（变更影响面=单租户——发布语义）。写出实现。

```javascript
const PLAN_DEFAULTS = {
  free: { features: { sso: false, export: true, customTheme: false }, limits: { seats: 5 } },
  pro: { features: { sso: false, export: true, customTheme: true }, limits: { seats: 50 } },
  enterprise: { features: { sso: true, export: true, customTheme: true }, limits: { seats: Infinity } },
};
const GLOBAL = { theme: { primary: '#1677ff' }, features: {} };

class TenantConfig {
  #tenants = new Map(); #subs = new Map();
  register(tenantId, { plan, overrides = {} }) {
    this.#tenants.set(tenantId, { plan, overrides });
  }
  resolve(tenantId) {
    const t = this.#tenants.get(tenantId);
    if (!t) throw new Error(`unknown tenant: ${tenantId}`);
    const plan = PLAN_DEFAULTS[t.plan];
    return deepMerge(deepMerge(structuredClone(GLOBAL), structuredClone(plan)), t.overrides);
  }
  can(tenantId, capability) {
    return !!this.resolve(tenantId).features[capability];
  }
  update(tenantId, patch, changedBy) {
    const t = this.#tenants.get(tenantId);
    t.overrides = deepMerge(t.overrides, patch);
    // 隔离审计: 只影响该租户
    this.#subs.get(tenantId)?.forEach((fn) => fn(this.resolve(tenantId)));   // 热更新订阅
    this.#audit(tenantId, patch, changedBy);
    return this.resolve(tenantId);
  }
  subscribe(tenantId, fn) {
    (this.#subs.get(tenantId) ?? this.#subs.set(tenantId, new Set()).get(tenantId)).add(fn);
    return () => this.#subs.get(tenantId)?.delete(fn);
  }
  #audit(tenantId, patch, by) { /* 变更审计: 影响面=单租户 */ }
}
// 用法: can('acme', 'sso') → enterprise true / free false
// update('acme', { theme: { primary: '#ff6600' } }) → 订阅页面即时生效
```

**评分点**：
- 三层配置优先级（租户 > 套餐 > 全局）+ deepMerge 语义
- 套餐能力门控（can() 的套餐判定）
- 热更新订阅（配置变更即时生效不刷新）
- 隔离语义（变更影响面=单租户——审计与发布语义清晰）
