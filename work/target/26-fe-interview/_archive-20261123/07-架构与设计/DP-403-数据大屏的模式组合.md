## DP-403：数据大屏模式组合

**答**：
- 大屏模式全景：组合模式（楼层化布局——JSON 配置驱动组件树）、观察者（数据源推送 → 多组件订阅）、策略（数据更新频率分级：秒级行情直驱图表/分钟级指标走响应式）、适配器（多数据源统一：WebSocket/轮询/mock 统一 DataSource 接口）、享元（图表实例复用）
- 数据流架构：DataSource（统一适配）→ DataBus（分发）→ 各组件订阅自己关心的 channel——组件间零耦合
- 性能模式：高频数据绕过框架（图表实例直接 setOption）+ 低频数据走响应式——「频率分层」是核心决策
- 自适应缩放：scale 策略（等比缩放 vs 宽度自适应——大屏分辨率适配的策略模式）
- 深水点：大屏的「降级设计」——数据源挂了显示最后快照 + 「数据延迟」标注（大屏不能白屏——最后一帧缓存）

```javascript
// DataSource 适配器: 统一 { subscribe(channel, cb) } 接口
class WsSource { subscribe(ch, cb) { ws.on(ch, cb); } }
class PollSource { subscribe(ch, cb) { pollLoop(url, cb); } }    // 轮询也适配成订阅
```
