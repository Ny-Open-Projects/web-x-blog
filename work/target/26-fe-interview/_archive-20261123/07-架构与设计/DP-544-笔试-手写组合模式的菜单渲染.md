## DP-544：笔试：手写递归菜单

**题目**：实现递归菜单组件：① 数据模型统一：{ id, label, children?, icon?, perm? }——叶子与分支统一接口（组合模式）；② 权限过滤：带 perm 的节点按权限过滤（父有权限子才显示——权限传递）；③ 递归渲染：menu-group 递归（深度限制——>5 层提示数据异常）；④ 展开状态管理：expand 状态独立于数据（Set<id>——扁平存储）；⑤ 键盘导航：上下左右在菜单树内导航（roving tabindex）。写出实现。

```javascript
function filterByPerm(nodes, auth, inherited = true) {
  return nodes
    .filter((n) => !n.perm || auth.has(n.perm) || (inherited && auth.has(`${n.perm}:view`)))
    .map((n) => ({ ...n, children: n.children ? filterByPerm(n.children, auth) : undefined }));
}
function MenuTree({ nodes, expanded, onToggle, depth = 0 }) {
  if (depth > 5) console.warn('菜单深度超 5 层, 检查数据');
  return (
    <ul role="menu">
      {nodes.map((n) => n.children ? (
        <li key={n.id}>
          <button role="menuitem" aria-expanded={expanded.has(n.id)}
            onClick={() => onToggle(n.id)}>{n.label}</button>
          {expanded.has(n.id) && <MenuTree nodes={n.children} expanded={expanded} onToggle={onToggle} depth={depth + 1} />}
        </li>
      ) : (
        <li key={n.id}><button role="menuitem">{n.label}</button></li>
      ))}
    </ul>
  );
}
// expand: Set<id> 独立于数据 — 展开状态持久化 (localStorage)
```

**评分点**：
- 统一节点模型（叶子/分支同构——组合模式）
- 权限过滤的传递（父过滤子——递归权限）
- 展开状态与数据分离（扁平 Set）
- 深度限制与键盘导航（健壮性+可达性）
