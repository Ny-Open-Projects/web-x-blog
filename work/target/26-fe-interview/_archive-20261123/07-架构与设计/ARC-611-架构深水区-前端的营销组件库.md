## ARC-611：营销组件库沉淀
**答**:
- 沉淀动机：营销活动高频重复（签到/抽奖/邀请/砍价形态复用率高 ARC-503）——每次重写是浪费；组件库沉淀"形态 + 配置"双复用。
- 组件设计：活动组件协议（统一 props：活动 ID/用户上下文/埋点/配置中心数据源 + 统一事件：参与/中奖/分享），业务差异走配置（奖品配置/规则文案/视觉主题——代码复用配置差异化）。
- 与后端协议对齐：活动通用接口协议（参与/记录/结果/核销——各活动类型共享一个协议族，后端活动平台配合）——前后端协议同沉淀。
- 质量复用：组件内置风控防刷（ARC-520 前端配合标准化）、埋点标准事件（ARC-535 活动事件族）、合规文案（概率公示插槽 ARC-458）——每次使用不重新踩坑。
- 治理：组件使用统计（哪些形态高频——优先沉淀）、版本演进（活动组件破坏性变更少——配置兼容优先）、效果归档（每次活动的组件+配置快照——复盘与复用模板）。
```tsx
// 活动组件协议
<LotteryActivity
  activityId="act-2026-spring"                                   // 配置中心数据源
  user={userCtx}                                                 // 用户上下文
  track={standardTrack}                                          // 标准活动事件
  theme={{ primary: '#ff4d4f' }}                                 // 视觉配置
  onResult={(r) => showPrize(r)} />                              // 统一结果协议
```
