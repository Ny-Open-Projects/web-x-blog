## ARC-602：复杂选择状态设计
**答**:
- 全选语义的三种（ARC-486 延伸）：本页全选（确定集合）、全结果集选择（动态集合——服务端筛选条件语义：勾选"全部" = 按当前筛选条件操作所有匹配，含未加载的）、排除式选择（全选后取消若干——记录 excluded 集合而非 selected 全集，数据量小时更省）。
- 跨页/跨筛选保持：用户切换筛选后选择集处理（保留但标注"属于其他筛选条件"——批量操作时明确范围确认；筛选即上下文切换的语义要显式 ARC-599）。
- 选择状态机：selected（显式勾选）× excluded（全选后排除）× filterCtx（选择时的筛选快照）——操作执行时服务端按 (filterCtx - excluded) 展开全集（前端不知道全集——服务端按条件展开，防误操作十万元数据）。
- UX 要点：操作前影响面确认（"将操作 12345 条"精确数字——服务端 count）、选择摘要 chips（可单个撤销）、大集合操作转异步任务（ARC-486）。
- 一致性：选择集与数据版本（数据刷新后失效项处理：已删除项从选择集剔除并提示）。
```javascript
// 排除式全选
const sel = { mode: 'all-matching', filterCtx: currentFilter, excluded: new Set([12, 34]) };
async function batchOp(op) {
  const { count } = await api.countMatching(sel.filterCtx);      // 影响面确认
  if (!confirm(`将操作 ${count - sel.excluded.size} 条`)) return;
  await api.executeByFilter({ ...sel, op });                     // 服务端按条件展开
}
```
