## DP-547：笔试：手写协作光标

**题目**：实现协同文档的多光标渲染：① 光标状态：{ userId, color, position, selection }——多用户光标集合；② 位置变换：远端光标位置经过 OT 变换补偿（本地插入后远端光标偏移——transform 补偿）；③ 渲染节流：光标更新高频（远端每 100ms 广播）——rAF 合帧渲染；④ 光标生命周期：断线用户的光标淡出（5s 无更新移除——超时清理）；⑤ 深水点：光标的「位置在插入后漂移」——每次本地插入后所有远端光标偏移调整（本地插入长度补偿）。写出实现。

```javascript
class RemoteCursors {
  #cursors = new Map();   // userId -> { pos, color, lastUpdate }
  #pendingLocalOps = [];
  updateRemote(userId, position) {
    // 变换补偿: 本地在途插入 → 远端光标偏移调整
    let adjusted = position;
    for (const op of this.#pendingLocalOps)
      if (op.type === 'insert' && op.pos <= adjusted) adjusted += op.text.length;
    this.#cursors.set(userId, { pos: adjusted, color: colorFor(userId), lastUpdate: Date.now() });
    this.#scheduleRender();                            // rAF 合帧
  }
  #scheduleRender() {
    this.#raf ??= requestAnimationFrame(() => {
      this.#raf = null;
      const now = Date.now();
      for (const [uid, c] of this.#cursors) {          // 超时清理: 断线用户淡出
        if (now - c.lastUpdate > 5000) this.#cursors.delete(uid);
        else renderCursor(uid, c);
      }
    });
  }
  onLocalInsert(op) { this.#pendingLocalOps.push(op); }
}
```

**评分点**：
- 变换补偿（本地插入后远端光标偏移调整——OT 的光标版）
- rAF 合帧（高频更新——每帧一次渲染）
- 超时清理（断线用户淡出——生命周期）
- pending 操作队列（变换的上下文）
