## ARC-575：批量导入导出统一协议
**答**:
- 目标：各业务的导入导出（ARC-490/382）协议统一——做成平台能力而非每业务重写（模板生成/行级校验/进度/错误报告/回滚全链路复用）。
- 统一协议四段：模板（字段定义 schema → 模板文件生成 + 填写说明）、导入（解析 → 映射 → 校验（分级 ARC-490）→ 预览 → 提交异步任务）、进度与结果（任务协议统一 NODE-437：taskId/进度/失败明细/部分成功语义）、回滚（导入批次可整体撤销——导入记录 batchId，按批次反向操作；不可撤销类（真实发货）导入前强提示）。
- 校验协议：格式校验（前端即时）+ 业务校验（服务端预检批量化）+ 依赖校验（引用的主数据存在性）——错误报告结构统一（行/列/原因/修复建议）。
- 前端组件化：ImportWizard（上传/映射/预览/确认/进度/结果统一组件——业务传 schema 即可）。
- 度量：导入成功率/失败 Top 原因（模板可读性优化依据）、模板下载→成功导入转化。
```javascript
// 统一导入组件
<ImportWizard schema={goodsImportSchema}                       // 字段/校验/模板定义
  onImport={api.importGoods}                                     // 提交到统一任务协议
  allowRollback />                                               // 批次可撤销标记
// 服务端：taskId → progress → { success: 980, failed: 20, batchId } → rollback(batchId)
```
