## ARC-578：键盘可达性体系化
**答**:
- 目标：核心功能全程键盘可完成（Tab 序合理/焦点可见/快捷键一致/焦点陷阱正确）——不是个别组件的特殊处理，而是体系。
- 焦点管理架构：焦点顺序（DOM 顺序 = 逻辑顺序，禁 tabIndex 滥用——正 tabindex 是反模式）、焦点陷阱（Modal/抽屉关闭时焦点归位触发元素 ARC-322 Portal 配套）、跳转链接（Skip to main——长导航页必备）、焦点可见性（:focus-visible 统一样式 token 化）。
- 组件库基线：交互组件全部支持键盘操作（Tree/Table/Slider 等——组件库开发期键盘测试用例化 ARC-577）、roving tabindex（列表类组件焦点模式：容器单 tab + 内部方向键）。
- 与快捷键体系协同（ARC-498）：快捷键是增强（效率）不是替代（可达性）——两者注册表统一避免冲突。
- 验证：键盘走查脚本（核心路径键盘操作 E2E：Tab 序断言/焦点落点断言）、屏幕阅读器联合验证（NVDA/VoiceOver 走核心路径）。
```javascript
// 焦点陷阱（Dialog 基线）
function useFocusTrap(ref, { onEscape }) {
  const trap = (e) => {
    if (e.key === 'Escape') return onEscape();
    if (e.key === 'Tab') {
      const f = focusableIn(ref.current);
      if (f.length && (e.shiftKey ? f[0] === document.activeElement : f.at(-1) === document.activeElement))
        e.preventDefault(), (e.shiftKey ? f.at(-1) : f[0]).focus();   // 循环焦点
    }
  };
  useEffect(() => { document.addEventListener('keydown', trap); return cleanup; }, []);
}
```
