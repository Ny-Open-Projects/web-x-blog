## ARC-581：数据导出合规链路
**答**:
- 导出即出域：合规链路四道——权限（字段级导出权限 ARC-420，敏感字段默认脱敏 ARC-570）、审批（批量/含敏感字段导出需审批，工单流转 ARC-509）、水印（页面水印 + 文件水印：用户 ID 隐写——泄露溯源 ARC-346/496）、审计（导出事件哈希链留痕 NODE-442 服务端配合）。
- 前端实现：导出入口统一（ExportButton 组件：权限检查 + 审批发起 + 任务中心进度 ARC-576——散落的导出按钮是治理失控点）、页面水印（导出预览界面即带水印——防截图）、导出范围声明（用户可见的"将导出哪些字段"透明化）。
- 频次治理：导出配额（ARC-439）+ 异常模式检测（高频批量导出 → 风控复核 NODE-458）。
- 敏感级别路由：不同敏感级数据的导出走不同链路（公开数据直接导、内部数据审批导、个人数据走合规通道 NODE-443 用户数据权利专项）。
- 审计闭环：导出后的使用追踪（外发检测/泄露事件溯源演练）、季度导出审计报告（谁导了什么——合规检查材料）。
```javascript
// 统一导出组件
<ExportButton fields={goodsExportFields}                       // 字段级权限已在服务端校验
  sensitiveLevel={2}                                           // 内部级：走审批链
  watermark={{ user: uid, ts: Date.now() }}                    // 水印参数
  onSubmit={(q) => taskCenter.create('export', q)} />          // 任务中心统一进度
// 服务端：审批通过 → 生成（水印注入）→ 签名 URL → audit.hashChain(entry)
```
