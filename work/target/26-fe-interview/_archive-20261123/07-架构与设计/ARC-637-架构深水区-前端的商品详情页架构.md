## ARC-637：商品详情页架构
**答**:
- 模块化：详情页 = 模块集合（头图轮播/价格区/SKU 选择器/促销/评价/详情富文本/推荐——模块注册制，运营可调顺序显隐 ARC-552 运营位协议）。
- 数据分层：静态骨架缓存（商品基础信息长缓存——ARC-565 热点预案）、动态数据实时（价格/库存/活动——短 TTL + 变更推送：价格变动页内更新提示）、SKU 依赖（选 SKU → 价格/库存/优惠切换——SKU 联动协议服务端下发矩阵）。
- 价格展示：价格构成（原价/券后价/到手价——服务端计算明细 ARC-582 红线）、价格变动感知（浏览期间降价 → 通知组件——价保提示）。
- 交互链路：加购/立即购买（SKU 校验 → 购物车/结算 ARC-599）、库存状态（售罄→到货提醒订阅）。
- 性能：重资源懒加载（详情富文本图/视频视口内加载 ARC-436）、推荐流懒加载（ARC-493）、秒开优化（预取 ARC-441 列表→详情链路）。
```javascript
// 模块化详情
const modules = await api.detailLayout(goodsId);                 // 模块清单（运营配置）
modules.map(m => <ModuleRenderer key={m.type} {...m} />);        // 注册表渲染
// SKU 联动：api.skuMatrix(goodsId) → { skuId: { price, stock, promos } } 全量矩阵
selectSku(id) => priceZone.update(matrix[id])                    // 端上即时切换（矩阵预下发）
```
