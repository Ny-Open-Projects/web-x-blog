## DP-445：降级矩阵

**答**：
- 降级的模式组合：策略（每功能定义降级策略：隐藏/静态化/缓存数据/简化版）、责任链（多级降级：数据降级→功能降级→整页降级）、观察者（触发器：错误率/QPS/手动开关 → 自动/手动降级）、命令（降级/恢复——审计与确认）
- 降级矩阵的设计：feature × level（核心不可降/重要可半降/边缘可全降）——矩阵定义「降级权限」
- 降级的触发与恢复：自动触发（指标超阈）+ 手动恢复（二次确认——防误恢复引起雪崩）
- 深水点：降级的「联动效应」——降级 A 功能可能加重 B（关闭缓存 → 接口压力上升）——降级顺序的设计（先关低依赖功能）

```javascript
const MATRIX = {
  recommend: { level: 3, fallback: () => null, triggers: ['qps>1000'] },       // 可全降
  search: { level: 2, fallback: () => cachedResults, triggers: ['errorRate>5%'] },  // 半降
  checkout: { level: 1 },                              // 核心不可降
};
// 恢复需确认: restore(feature) → confirm dialog (防误操作)
// 顺序: 先降 level3 (低依赖) → level2 → level1 永不降
```
