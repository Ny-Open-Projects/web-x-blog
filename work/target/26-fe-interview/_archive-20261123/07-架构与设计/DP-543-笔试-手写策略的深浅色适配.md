## DP-543：笔试：手写主题切换

**题目**：实现主题切换器 `ThemeManager`：① 三级来源：用户选择 > 系统偏好 > 默认——优先级链；② 系统跟随：未手动选择时监听 prefers-color-scheme 变化自动切换；③ 手动后取消跟随：与系统一致时清除存储（恢复跟随语义）；④ 首帧防闪：切换在渲染前（SSR 内联脚本 + CSR head 脚本）；⑤ 第三方组件的适配：图表主题重算（CSS 管不了的组件——观察者通知）。写出实现。

```javascript
class ThemeManager {
  #subs = new Set();
  get current() {
    const user = localStorage.getItem('theme');        // L1: 用户选择
    if (user) return user;
    return matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';   // L2: 系统
  }
  set(theme) {
    const system = matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
    if (theme === system) localStorage.removeItem('theme');   // 与系统一致 → 恢复跟随
    else localStorage.setItem('theme', theme);
    this.#apply(theme);
    this.#subs.forEach((f) => f(theme));               // 观察者: 图表重绘等
  }
  #apply(theme) {
    document.documentElement.dataset.theme = theme;
    document.documentElement.style.colorScheme = theme;
  }
  init() {                                             // 首帧防闪: 渲染前调用
    this.#apply(this.current);
    matchMedia('(prefers-color-scheme: dark)').addEventListener('change', () => {
      if (!localStorage.getItem('theme')) this.#apply(this.current);   // 跟随系统时自动切
    });
  }
}
```

**评分点**：
- 三级优先级链（用户 > 系统 > 默认）
- 「与系统一致清存储恢复跟随」的语义设计
- 首帧防闪（渲染前 apply + SSR 内联）
- 观察者通知覆盖 CSS 管不了的组件（图表）
