## ARC-831：手写多站点配置

**题目**：实现国际化多站点的配置分发 `SiteConfigDistributor`：① 配置继承：global（全局默认）→ region（区域覆盖）→ site（站点覆盖）——三层合并（site 优先）；② 合并语义：对象深合并 / 数组整体替换（数组不做逐项合并——语义清晰）/ 值类型直接覆盖；③ 差异审计：每个站点的「diff from global」（哪些配置被覆盖——本地化差异清单）；④ 配置校验：合并后跑 schema 校验（合并结果非法 → 拒绝发布——指出是哪层导致）；⑤ 发布确认：配置变更列出「受影响站点」清单——发布人确认（爆炸半径可见）。写出实现。

```javascript
class SiteConfigDistributor {
  #global; #regions = new Map(); #sites = new Map();
  #schema;
  constructor(globalConfig, schema) { this.#global = globalConfig; this.#schema = schema; }
  setRegion(region, config) { this.#regions.set(region, config); }
  setSite(site, config) { this.#sites.set(site, config); }

  resolve(siteId) {
    const site = this.#sites.get(siteId);
    const region = site?.region ? this.#regions.get(site.region) : null;
    return deepMerge(deepMerge(structuredClone(this.#global), region ?? {}), site ?? {});
  }
  diffFromGlobal(siteId) {
    const resolved = this.resolve(siteId);
    const out = [];
    walkDiff(this.#global, resolved, '', out);
    return out;                                        // 本地化差异清单
  }
  publish(siteId, changedBy) {
    const resolved = this.resolve(siteId);
    const schemaResult = this.#schema.validate(resolved);
    if (!schemaResult.ok) throw new Error(`配置合并后非法: ${schemaResult.errors.join(';')} — 检查覆盖层`);
    const affected = { site: siteId, diffCount: this.diffFromGlobal(siteId).length };
    return { ...affected, confirmedBy: changedBy, publishedAt: Date.now() };
  }
}
function deepMerge(base, override) {
  const out = { ...base };
  for (const [k, v] of Object.entries(override))
    out[k] = Array.isArray(v) || typeof v !== 'object' || v === null || typeof out[k] !== 'object'
      ? v : deepMerge(out[k], v);                      // 数组整体替换
  return out;
}
function walkDiff(a, b, path, out) {
  for (const k of new Set([...Object.keys(a ?? {}), ...Object.keys(b ?? {})])) {
    const p = path ? `${path}.${k}` : k;
    if (Object.is(a?.[k], b?.[k])) continue;
    if (typeof a?.[k] === 'object' && typeof b?.[k] === 'object') walkDiff(a[k], b[k], p, out);
    else out.push({ path: p, global: a?.[k], site: b?.[k] });
  }
}
```

**评分点**：
- 三层继承合并（global→region→site 优先级）
- 数组整体替换的合并语义（防逐项合并歧义）
- 合并后 schema 校验（拒绝非法发布——指出层级）
- diffFromGlobal（本地化差异清单——审计用）
