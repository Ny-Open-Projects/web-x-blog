## ARC-815：手写模块注册表

**题目**：实现大型应用的「页面模块注册表」——架构约束的落地：① 模块声明：registerModule({ id, pages, routes, deps: [其他模块], provides: [共享导出], requires: [需要的共享导出] })；② 依赖校验：requires 必须 ∈ 某 module 的 provides（未满足 → fail）；③ 循环依赖检测（module 间环——DFS）；④ 路由唯一性校验：两模块注册同一路由 → error（路由归属唯一）；⑤ 导出解析：模块的 provides 在构建时校验真实导出（声明了 provides 但没导出 → fail）。写出实现。

```javascript
class ModuleRegistry {
  #modules = new Map();
  register(mod) {
    const m = { ...mod, id: mod.id };
    // requires 满足性校验
    for (const r of m.requires ?? []) {
      const provider = [...this.#modules.values()].find((x) => x.provides?.includes(r));
      if (!provider) throw new Error(`module ${m.id} requires "${r}" — 无提供方 (可能依赖循环注册顺序)`);
    }
    // 路由唯一性
    for (const route of m.routes ?? [])
      for (const [id, existing] of this.#modules)
        if (existing.routes?.includes(route))
          throw new Error(`路由冲突: ${route} 已被 ${id} 注册`);
    this.#modules.set(m.id, m);
  }
  validate() {
    // 循环依赖
    const state = new Map();
    const visit = (id, stack) => {
      if (state.get(id) === 'done') return [];
      if (state.get(id) === 'visiting') return [...stack.slice(stack.indexOf(id)), id];
      state.set(id, 'visiting'); stack.push(id);
      for (const dep of this.#modules.get(id).deps ?? []) {
        if (!this.#modules.has(dep)) throw new Error(`unknown dep: ${dep}`);
        const cycle = visit(dep, stack);
        if (cycle.length) return cycle;
      }
      stack.pop(); state.set(id, 'done');
      return [];
    };
    for (const id of this.#modules.keys()) {
      const cycle = visit(id, []);
      if (cycle.length) throw new Error(`模块循环依赖: ${cycle.join(' → ')}`);
    }
    // provides 真实导出校验 (构建时)
    for (const [id, m] of this.#modules)
      for (const p of m.provides ?? [])
        if (!realExportExists(m.dir, p))
          throw new Error(`module ${id} declares provides "${p}" but not exported`);
    return { modules: this.#modules.size, ok: true };
  }
}
// 用法:
// registry.registerModule({ id: 'cart', routes: ['/cart'], deps: ['user'],
//   provides: ['useCartStore'], requires: ['useAuthStore'] })
```

**评分点**：
- requires/provides 的满足性校验（声明式依赖）
- 循环依赖 DFS 检测（模块环路径输出）
- 路由唯一性（归属唯一防冲突）
- provides 与真实导出的构建时校验（声明≠实现）
