## ARC-634：地理位置服务
**答**:
- 定位授权策略：授权时机（用户上下文触发——非启动弹窗）、授权降级链（精确定位 → IP 城市 → 手动选城市——每级显式标注精度）、授权拒绝恢复（设置引导 + 手动选城市兜底——功能不全禁用）。
- 城市体系：城市选择器（热门/历史/GPS 定位城市——城市数据服务端下发版本化）、城市切换语义（切换 = 全站业务上下文切换——缓存/列表全部按城市失效刷新，ARC-559 切换协议）、跨城提示（定位城市 ≠ 当前选择 → 提示切换）。
- 距离与展示：距离计算（前端展示性距离：Haversine 近似——排序/筛选以服务端为准）、精度脱敏（展示模糊化位置——隐私合规 ARC-154）、坐标系统一（ARC-455 收口）。
- 隐私合规：定位频率控制（非必要不定位——后台定位场景显式声明 ARC-571 同意管理）、位置数据分级（城市级 vs 精确坐标的用途区分）。
- 与地图服务联动：POI 选点（ARC-510）、附近服务列表（距离排序——服务端计算）。
```javascript
// 定位降级链
async function locate() {
  try { const p = await geolocate({ timeout: 3000 }); return { level: 'precise', ...p }; }
  catch { const city = await ipCity(); return { level: 'city', ...city }; }  // 降级 IP
}
// 城市切换：cityStore.switch(id) → cache.flushByCity() + reload  // 上下文切换
```
