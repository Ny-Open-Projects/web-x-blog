## ARC-830：手写弃用追踪

**题目**：实现接口弃用的全生命周期追踪 `DeprecationTracker`：① 弃用声明：{ api, deprecatedAt, removalAt(硬截止), migration(迁移指南链接), codemod }；② 使用量追踪：运行时埋点统计「老 API 使用量」（按调用方应用分组）——使用量归零 = 可安全移除；③ 迁移进度看板：各调用方的迁移状态（未开始/进行中/完成）；④ 硬截止执行：removalAt 到达 → 构建期 lint error（旧 API 引用报错）+ 运行时警告升级为 throw（dev 模式）；⑤ 自动提醒：截止前 2 周/1 周/3 天阶梯提醒（使用量不为零的调用方）。写出实现。

```javascript
class DeprecationTracker {
  #items = new Map();   // api -> { ..., usage: Map<caller, count> }
  deprecate({ api, removalAt, migration, codemod }) {
    this.#items.set(api, { api, deprecatedAt: Date.now(), removalAt: new Date(removalAt).getTime(),
      migration, codemod, usage: new Map() });
  }
  trackUsage(api, caller) {                            // 运行时埋点(dev 模式)
    const item = this.#items.get(api);
    if (!item) return;
    item.usage.set(caller, (item.usage.get(caller) ?? 0) + 1);
  }
  migrationBoard() {
    return [...this.#items.values()].map((item) => {
      const daysLeft = Math.ceil((item.removalAt - Date.now()) / 86400e3);
      const callers = [...item.usage.entries()];
      return { api: item.api, daysLeft,
        callers: callers.map(([c, n]) => ({ caller: c, uses: n,
          status: n === 0 ? 'done' : n > 100 ? 'not-started' : 'in-progress' })),
        safeToRemove: callers.every(([, n]) => n === 0) };
    });
  }
  enforceAtDeadline(lintContext) {                     // 硬截止执行
    const now = Date.now();
    for (const item of this.#items.values())
      if (now >= item.removalAt)
        lintContext.addRule(item.api, { level: 'error',
          message: `${item.api} 已到硬截止, 迁移指南: ${item.migration}` });
  }
  reminders(now = Date.now()) {
    const out = [];
    for (const item of this.#items.values()) {
      const days = (item.removalAt - now) / 86400e3;
      for (const mark of [14, 7, 3])
        if (days <= mark && days > mark - 1 && item.usage.size > 0)
          out.push({ api: item.api, daysLeft: Math.ceil(days),
            notify: [...item.usage.keys()].filter((c) => item.usage.get(c) > 0) });
    }
    return out;
  }
}
```

**评分点**：
- 运行时使用量追踪（按调用方分组——使用量归零才安全移除）
- 三阶段提醒（14/7/3 天阶梯——只提醒有使用量的调用方）
- 硬截止的执行（lint error + dev throw——有迁移支持为前提）
- 迁移看板（各调用方状态——未开始/进行中/完成）
