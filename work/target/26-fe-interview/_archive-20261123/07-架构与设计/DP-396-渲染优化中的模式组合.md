## DP-396：渲染优化组合

**答**：
- 渲染优化的模式：代理（响应式依赖追踪——Vue reactive）、备忘录（memo/useMemo——计算缓存）、享元（虚拟列表的节点复用）、策略（更新策略：同步/并发/deferred）、观察者（细粒度订阅——selector）
- 组合的层级：框架层（响应式/vdom）、组件层（memo/memoized selector）、应用层（虚拟列表/分页）
- selector 模式的核心：store 大对象 → 组件只订阅自己关心的切片（useSelector with equalityFn——无关更新不触发渲染）
- 虚拟列表 = 享元 + 策略：节点池复用（享元）+ 渲染窗口策略（只渲染可见区）
- 深水点：优化的「度量先行」——Profiling 定位真瓶颈再套模式（盲用 memo 反而增加比较成本——浅比较本身有开销）

```javascript
// selector + memo 组合
const selectCartTotal = createSelector(
  [(s) => s.cart.items],
  (items) => items.reduce((s, i) => s + i.price, 0),  // memoized: items 引用不变不重算
);
const total = useSelector(selectCartTotal);           // 只有 total 变才重渲
// 虚拟列表: rowVirtualizer.getVirtualItems() — 只渲染可见区 (享元+策略)
```
