## ARC-268：大促移动端 H5 在弱网与低端机上的专项优化？
**答**：
- 分档策略：设备内存（navigator.deviceMemory）+ 连接类型（effectiveType）分"高/中/低"三档；低端档：砍动效、关预加载、图片降质、延迟非关键 JS。
- 弱网优化：图片渐进（LQIP/缩略图先行）、接口超时分级（核心 3s 非核心 8s）+ 快速骨架、请求合并减少 RTT、HTML 内联首屏数据（省一次往返）。
- 低端机优化：避免长任务（大列表虚拟滚动、动画用 transform/合成层）、减少内存（虚拟列表+图片回收）、页面复杂度降级（楼层减量）。
- 验证方式：真机测试矩阵（3 档机型 × 2 网络档）+ RUM 按档位拆分看指标——低端档 LCP 不高于高端档 2 倍才达标。

```typescript
function deviceTier(): 'low' | 'mid' | 'high' {
  const mem = (navigator as any).deviceMemory ?? 4;
  const net = (navigator as any).connection?.effectiveType ?? '4g';
  if (mem <= 2 || net === 'slow-2g' || net === '2g') return 'low';
  if (mem <= 4 || net === '3g') return 'mid';
  return 'high';
}
// 低档：disableAnimations(); imagesQuality(0.6); disablePrefetch(); floorsLimit(5)
// RUM：perf.report('LCP', { value, tier: deviceTier() }) → 大盘按 tier 分桶看达标率
```
