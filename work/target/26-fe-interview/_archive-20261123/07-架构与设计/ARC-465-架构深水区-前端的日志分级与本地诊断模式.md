## ARC-465：前端日志分级与本地诊断模式
**答**:
- 日志分级（生产默认）：error（必报）、warn（采样报）、info（关键路径里程碑）、debug（默认关闭）。分级走统一 logger，禁止 console 散用。
- 本地诊断模式（用户工单自证）：用户报障时开启"诊断开关"——动态调高日志级别（debug + 网络面板摘要 + 行为序列），运行 10 分钟导出诊断包（脱敏后），用户上传随工单提交。复现率低的 bug 靠这个闭环拿到现场。
- 诊断包内容：环境信息（UA/内存/网络类型）、错误历史、最近 50 条行为事件、最近 20 次请求摘要（url/状态/耗时，不含响应体敏感字段）、性能指标快照。
- 隐私与安全：诊断包内容白名单（不含页面业务数据明文）、导出前用户确认、传输加密、保留期与删除权（合规）。
- 工程约束：logger 是唯一出口（拦截 console 统一接入诊断环形缓冲），诊断开启对性能影响 < 5%。
```javascript
class DiagMode {
  static enable() {
    logger.setLevel('debug');
    startNetPulse(); startBehaviorRing();                     // 环形缓冲各 50 条
  }
  static async export() {
    const pack = { env: envInfo(), errors: errHistory(), actions: behaviorRing.dump(),
      requests: netPulse.dump(), vitals: vitalsSnapshot() };
    const blob = new Blob([sanitize(JSON.stringify(pack))]);   // 白名单脱敏
    return { blob, confirm: await uiConfirmUpload() };         // 用户确认后上传
  }
}
```
