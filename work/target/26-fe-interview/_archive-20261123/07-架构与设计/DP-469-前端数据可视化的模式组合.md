## DP-469：数据可视化组合

**答**：
- 可视化的模式全景：适配器（数据 → 图表 option 的转换层——业务数据与图表库解耦）、策略（图表类型选择：趋势用线/占比用环/分布用箱线——按数据形态）、观察者（数据更新订阅 → 增量 setOption）、享元（同配置图表实例池）、备忘录（视图状态：缩放/筛选联动）
- 联动的模式实现：多图联动（A 图缩放 → B 图同步——事件总线/共享状态驱动）——「联动是观察者网」
- 大数据量的策略：降采样（LTTB 抽样——视觉等价数据量减半）、渐进渲染（分块绘制）、聚合下推（服务端聚合——前端只画聚合结果）
- 深水点：可视化的「主题一致性」——图表配色从设计 token 生成（策略——token → 主题对象）——暗色模式下的图表适配走同一管道

```javascript
// 适配器: 业务数据 → 图表 option
function toLineOption(series) {
  return { xAxis: { type: 'time' }, series: series.map((s) => ({ type: 'line', data: downsample(s.points, 2000) })) };
}
// 联动: chartA.on('dataZoom', (range) => chartB.dispatchAction({ dataZoom: range }));   // 观察者网
// 降采样: LTTB 策略 — 视觉等价, 数据量减半
```
