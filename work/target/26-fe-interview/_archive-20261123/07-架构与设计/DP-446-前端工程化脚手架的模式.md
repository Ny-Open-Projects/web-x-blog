## DP-446：脚手架组合

**答**：
- 脚手架的模式全景：模板方法（脚手架流程固定：询问→渲染→安装→git init）、策略（模板策略：React/Vue/Vanilla 变体选择）、工厂（模板引擎选择）、备忘录（脚手架配置持久化——二次生成一致）
- 共享配置包：@company/eslint-config/tsconfig/vite-preset——「继承式共享」（extends 配置）——工具链统一的载体
- 版本升级策略：配置包 minor 自动（renovate）+ major 迁移指南（批量升级工具——npx @company/migrate）
- 深水点：脚手架的「逃生口设计」——业务仓 override 配置（显式声明+说明——防影子配置的一刀切）

```javascript
// 脚手架主流程 (模板方法)
async function scaffold(answers) {
  const template = await resolveTemplate(answers.framework);    // 策略
  await renderTemplate(template, answers);                       // 渲染
  await renderSharedConfigs(answers);                            // 共享配置包引用
  await installDeps();                                           // 固定步骤
  await gitInit();                                               // 固定步骤
}
// 逃生口: vite.config.ts 里 // @company-override: 自定义插件 — 显式标注
```
