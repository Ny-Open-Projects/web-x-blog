## DP-415：看板模式组合

**答**：
- 看板模式全景：命令（卡片移动/增删——可撤销）、观察者（列间卡片流动的联动：列计数/泳道统计）、状态机（卡片状态流转与列绑定——Done 列的卡片锁编辑）、策略（排序策略：手动排序/按优先级自动）
- 跨列拖拽的原子性：一次拖拽 = 「源列删除 + 目标列插入」的复合命令（宏命令——undo 恢复两列）
- 实时协作：他人移动卡片（观察者接收 → 本地状态更新 → 冲突以服务端序为准）
- 深水点：看板的「乐观与回滚」——拖拽立即生效（乐观）+ 服务端冲突时回弹（卡片飞回原列——回滚的动画语义）

```javascript
// 宏命令: 跨列移动
const moveCard = {
  execute() { src.remove(card); dest.add(card); },
  undo() { dest.remove(card); src.add(card); },      // 原子回滚两列
};
// 乐观 + 回弹: onDragEnd → local move → api.move → 409 ? flyBack() : confirm
```
