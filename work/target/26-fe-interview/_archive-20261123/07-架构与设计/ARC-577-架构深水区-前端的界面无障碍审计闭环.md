## ARC-577：无障碍审计闭环
**答**:
- 从"想起来查一查"到"常态化闭环"：自动审计（CI axe 扫描 ARC-458）+ 人工审计（真实屏幕阅读器走查核心路径——自动化只能覆盖 ~40% 问题）+ 用户反馈（障碍用户工单通道）。
- 自动化层：组件库级（组件开发时单测含 a11y 断言——源头保证）、页面级（CI 关键页面扫描、违规分级阻断）、回归层（a11y 快照进视觉回归流程）。
- 修复闭环：违规清单按组件归属开单 → 修复 → 验证（自动化 + 手工）→ 基线更新（修复后违规不再出现——防回退）；违规趋势看板（新页面引入违规率）。
- 能力建设：开发 a11y checklist（ARC-433 组件库基线）、常见问题案例库（焦点陷阱/对比度/aria 误用）、屏幕阅读器体验培训（开发者亲耳听一次）。
- 度量：违规数趋势、修复时长、核心路径屏幕阅读器可完成率（人工评测季度化）。
```javascript
// CI a11y 门禁（组件级 + 页面级）
test('Dialog a11y 基线', async () => {
  render(<Dialog open>content</Dialog>);
  const r = await axe(container);
  expect(r.violations.filter(v => v.impact === 'critical')).toHaveLength(0);   // 阻断级
  expect(focusTrapActive()).toBe(true);                          // 手写断言补 axe 盲区
});
```
