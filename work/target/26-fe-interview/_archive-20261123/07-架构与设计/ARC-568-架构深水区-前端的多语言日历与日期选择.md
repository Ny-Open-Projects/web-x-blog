## ARC-568：多语言日历与日期选择
**答**:
- 差异面：周起始日（周日/周一/周六按 locale）、月份显示（数字/名称/名称+数字）、纪年（公元/佛历/民国）、历法（公历/伊斯兰历——业务场景多为公历但显示格式 locale 化）、文本方向（RTL 日历镜像布局 ARC-244）。
- 架构收口：Intl API 为基座（locale 自动处理上述差异——不自己写周起始规则）、日历网格计算与显示分离（网格逻辑 locale 无关，显示层 locale 注入）。
- 输入解析：多格式输入解析（用户输入"2026/11/19"“11-19"“明天"——解析器按 locale 习惯支持 + 相对日期），解析结果回显规范化。
- 业务日期语义：营业日/账期日显式声明业务时区（ARC-481）——"本周"在日历 UI 按用户 locale 起，在业务按业务时区起，两套语义标注清楚。
- 无障碍：日历键盘导航（方向键移动/翻页、aria-live 宣报当前焦点日期）、屏幕阅读器日期朗读格式（locale 化）。
```javascript
// locale 感知日历
function buildGrid(year, month, locale) {
  const firstDay = firstDayOfWeek(locale);                       // Intl 派生（0=周日/1=周一）
  const start = startOfWeek(new Date(Date.UTC(year, month, 1)), firstDay);
  return range(42).map(i => ({ date: addDays(start, i), label: fmtDay(addDays(start, i), locale) }));
}
// RTL：dir=rtl 容器下网格自动镜像（CSS 逻辑属性实现）
```
