## DP-388：插槽模式

**答**：
- 插槽的三层：默认插槽（内容投影）、具名插槽（多区域：header/footer）、作用域插槽（子传数据给插槽——Vue scoped slot / React render props）
- 作用域插槽的核心：插槽内容「由子组件数据驱动」（列表项渲染由父定制但数据是子的）——控制反转的 UI 版
- 实战取舍：props 传递 vs 作用域插槽——「子知道结构父知道长相」用插槽（Table 的 cell 渲染）；纯数据传递用 props
- 组件库的插槽设计规范：插槽命名语义化（header/content/footer/extra）、插槽作用域数据的文档化（slot props 是 API 的一部分）
- 深水点：插槽的「性能陷阱」——作用域插槽在 Vue2 是「子组件每次更新重建」（作用域已修复但历史心智仍在）——React render props 每渲染新函数 → 子组件 memo 失效（useCallback/useMemo 配合）

```jsx
// 作用域插槽 (render props): Table 的 cell 定制
function Table({ data, columns }) {
  return <table>{data.map((row) => (
    <tr key={row.id}>{columns.map((col) => (
      <td key={col.key}>{col.render
        ? col.render(row)                              // 作用域插槽: 父定制渲染, 子供数据
        : row[col.key]}</td>
    ))}</tr>
  ))}</table>;
}
// columns: [{ key: 'status', render: (row) => <Badge type={row.status}/> }]
```
