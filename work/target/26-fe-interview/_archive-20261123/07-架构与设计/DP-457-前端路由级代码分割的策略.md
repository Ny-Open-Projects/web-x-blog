## DP-457：代码分割策略

**答**：
- 代码分割的策略层级：路由级（懒加载页面——默认）、组件级（重组件懒加载——图表/编辑器）、依赖级（大库按需）、条件级（特定功能才加载）
- 预加载策略：preload（关键路径——鼠标 hover 预取）、prefetch（空闲预取——下一页）、modulepreload（模块依赖预加载）——预加载的优先级策略
- 分割与缓存的权衡：共享 chunk（缓存命中）vs 独立 chunk（变更隔离）——按「变更频率 × 复用度」决策
- 深水点：分割的「过度碎片化」——几百个小 chunk（请求开销+瀑布）——chunk 数量与并行度的平衡（HTTP2 下 6~20 个合理）

```javascript
// 路由级
const routes = [{ path: '/detail', component: () => import('./Detail') }];
// 条件级: 富文本只在编辑模式
if (isEdit) { const { Editor } = await import('./Editor'); }
// 预加载: hover 预取
onMouseEnter={() => import('./Detail')}             // 预热 chunk
```
