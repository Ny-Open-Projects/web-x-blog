## DP-430：低代码引擎组合

**答**：
- 低代码的模式全景：组合模式（组件树——DSL 的树形结构）、工厂（组件注册表——类型到实现）、命令（画布操作可撤销）、观察者（属性面板 ↔ 画布双向联动）、备忘录（历史版本快照）、策略（表达式求值策略：安全子集）
- 双向绑定的架构：画布选中组件 → 属性面板显示（观察者）；属性修改 → 画布更新（命令）——双向的中介者协调
- 出码与运行时：DSL → 代码（出码模式）vs DSL → 运行时渲染（runtime 模式）——策略按交付形态选择
- 深水点：DSL 的「表达式安全」——用户写的绑定表达式（自研求值器禁 Function/eval——白名单操作符）——低代码的安全边界

```javascript
// DSL: { type: 'Button', props: { text: "{{state.count > 3 ? '确定' : '下一步'}}" } }
function evalExpr(expr, scope) {
  // 安全子集求值: 仅支持属性访问/比较/三元 — 禁 Function
  const ast = parseSafe(expr);                        // 自研解析器
  return evaluate(ast, scope);
}
// 命令: 画布拖拽 = MoveNode 命令 — 可撤销
```
