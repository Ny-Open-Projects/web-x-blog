## ARC-225：权限系统的审计与风控埋点如何设计？
**答**：
- 审计三层：授权变更审计（谁给谁加了什么角色）、权限使用审计（谁在什么时候用了高危权限）、拒绝审计（被 403 的请求——大量 403 可能是越权探测）。
- 前端埋点点位：路由拦截（无权访问尝试）、按钮渲染为置灰（说明有 UI 但无权）、请求 403（带上意图接口与页面路径）。
- 风控信号：同账号短时间高频 403、敏感操作前的异常路径（直接手输敏感 URL）、非工作时间高危操作——聚合后进风控引擎。
- 隐私与留存：审计日志不含敏感业务数据，只留"动作+对象 ID+操作者+时间+页面路径"，保留期按合规要求（如 180 天）。

```typescript
// 403 拦截器统一审计上报
axios.interceptors.response.use(r => r, (err) => {
  if (err.response?.status === 403) {
    audit.report({
      type: 'perm-denied',
      url: err.config.url,
      page: location.pathname,
      permVersion,                                  // 当时的权限快照版本，方便回溯
      ts: Date.now(),
    });
  }
  return Promise.reject(err);
});
// 前端本地计数器：60s 内 403 ≥ 3 次给用户提示 + 上报 'perm-probe-suspect' 风控信号
```
