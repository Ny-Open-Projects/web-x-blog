## DP-416：倒计时模式组合

**答**：
- 倒计时的模式全景：观察者（tick 事件订阅——多处 UI 消费同一倒计时）、状态机（running/paused/finished）、策略（结束策略：暂停页面/跳转/提示——可配）、命令（暂停/恢复/重置）
- 精度核心：服务端时间基准（endTime 从服务端取）+ performance.now 计算（本地时钟漂移免疫）——「绝对时间差」而非 setInterval 累加
- 多实例共享：页面多个倒计时共享一个 ticker（rAF 循环分发——每实例注册自己的 endTime）——ticker 是被共享的观察目标
- 深水点：倒计时的「页面隐藏恢复」——切后台回来时间跳变（绝对时间差自动正确——但 UI 刷新要 resume 触发）——visibilitychange 驱动刷新

```javascript
class Countdown {
  #subs = new Set();
  constructor(endAtServer) { this.endAt = endAtServer - Date.now() + performance.now(); }
  onTick(fn) { this.#subs.add(fn); return () => this.#subs.delete(fn); }
  start() {
    const tick = () => {
      const left = this.endAt - performance.now();
      this.#subs.forEach((f) => f(Math.max(0, Math.ceil(left / 1000))));
      if (left > 0) this._raf = requestAnimationFrame(tick);   // rAF: 页面隐藏自动停
    };
    tick();
  }
}
// 多实例: 每个促销位一个 Countdown 实例, 共享页面 ticker 可再优化
```
