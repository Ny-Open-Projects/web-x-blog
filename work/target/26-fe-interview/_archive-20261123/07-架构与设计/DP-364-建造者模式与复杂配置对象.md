## DP-364：建造者模式：流式配置

**答**：
- 建造者的价值：复杂对象的「分步构建」——图表配置（ECharts option 十几个维度）、请求构建（fetch 的链式配置）
- 实战形态：链式 builder（`builder.setSize(400,300).setTheme('dark').build()`）——每个 setter 返回 this
- 前端取舍：JS 的对象字面量 + 默认值常比 builder 顺手——builder 在「配置项有依赖顺序/需要校验组合」时才值得（如 ECharts option 的 axis 与 series 关联校验）
- builder + 校验：build() 时做组合校验（同时启用 A 和 B 冲突——早期报错）
- 深水点：builder 的「不可变变体」——每步返回新实例（immutable builder——配置可安全共享/回溯）

```javascript
class ChartBuilder {
  #cfg = { theme: 'light' };
  size(w, h) { return this.#with({ width: w, height: h }); }
  theme(t) { return this.#with({ theme: t }); }
  #with(patch) { return Object.assign(Object.create(ChartBuilder.prototype), this, { #cfg: { ...this.#cfg, ...patch } }); }
  build() {
    if (this.#cfg.theme === 'dark' && this.#cfg.disableAnimation === undefined)
      this.#cfg.disableAnimation = true;             // 组合校验/默认联动
    return this.#cfg;
  }
}
```
