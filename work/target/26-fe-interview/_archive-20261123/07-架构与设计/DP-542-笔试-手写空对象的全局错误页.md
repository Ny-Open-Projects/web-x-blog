## DP-542：笔试：手写错误页体系

**题目**：实现全局错误页体系：① 错误分类路由：404（页面不存在）/403（无权限）/500（服务异常）/network（断网）——分类驱动错误页选择；② 每类错误页的「行动设计」：404 → 回首页+搜索、403 → 权限申请入口、500 → 重试按钮（自动重试倒计时）、network → 重连检测自动恢复；③ 恢复的自动化：network 页监听 online 事件自动刷新（用户不用手动）；④ 错误页的上下文保留：来源页面记录（恢复后返回原页面）；⑤ 防循环：错误页自身出错 → 最简静态 HTML（兜底的兜底）。写出实现。

```javascript
const ERROR_PAGES = {
  404: { title: '页面不存在', actions: [{ label: '回首页', to: '/' }, { label: '搜索', to: '/search' }] },
  403: { title: '无权限', actions: [{ label: '申请权限', to: '/perm-request' }] },
  500: { title: '服务异常', actions: [{ label: '重试', retry: true }] },
  network: { title: '网络异常', autoRecover: true },
};
function renderErrorPage(type, ctx) {
  if (type === 'network') {
    // 自动恢复: online 事件 → 返回原页面
    addEventListener('online', () => navigate(ctx.from), { once: true });
  }
  if (type === '500') {
    // 自动重试倒计时: 5s → reload
    countdown(5, () => reload(ctx.from));
  }
  // 兜底的兜底: 错误页组件异常 → document.body.innerHTML = 最简 HTML (无 JS 依赖)
  try { mountErrorPage(type, ctx); }
  catch { document.body.innerHTML = '<h1>出错了</h1><a href="/">回首页</a>'; }
}
```

**评分点**：
- 分类驱动的错误页选择（404/403/500/network 各异）
- 行动设计（每类错误有可行动出口——不是死页）
- 自动恢复（online 监听/重试倒计时——减少用户操作）
- 兜底的兜底（错误页自身异常 → 静态 HTML）
