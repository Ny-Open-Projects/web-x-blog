## DP-474：离线优先

**答**：
- 离线优先的模式架构：本地优先（读：IDB 先行 → 网络刷新）、队列（写：离线操作入队——重放）、状态机（同步状态：synced/pending/conflict）、策略（冲突解决：LWW/合并/用户裁决）、观察者（网络恢复触发重放）
- 读的离线优先：首屏数据从 IDB 秒开 → 网络回来对比更新——「快」与「新」的分层
- 写的可靠性：操作入队带幂等键（重放不重复）——SW background sync（页面死了也重放）
- 深水点：离线优先的「同步冲突」——离线期间的本地写 vs 服务端已被他人改——乐观锁（If-Match）+ 冲突 UI（让用户裁决而非静默覆盖）

```javascript
// 读: IDB 先行
const cached = await idb.get(key); render(cached);
fetch(key).then((fresh) => { render(fresh); idb.set(key, fresh); });
// 写: 入队 + 幂等
await idb.append('oplog', { op, idempotencyKey: uuid() });
navigator.serviceWorker.ready.then((r) => r.sync.register('replay'));
```
