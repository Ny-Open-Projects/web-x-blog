## DP-467：列表页模式链

**答**：
- 列表页的模式链：URL 状态（筛选条件进 query——可分享）、策略（筛选变更的请求策略：防抖/立即）、状态机（loading/empty/error/success）、备忘录（滚动位置+已加载数据——返回恢复）、观察者（数据推送增量更新）、享元（虚拟列表）
- 筛选变更的语义：筛选改变 → 重置页码重新请求（增量条件是追加加载）——两种筛选语义
- 返回恢复的组合：列表数据缓存（内存）+ 滚动位置（sessionStorage）+ 筛选条件（URL）——三处恢复源
- 深水点：列表的「增量更新」——详情页改了状态 → 返回列表时只更新该行（按 id 定向 patch——不整页重拉）

```javascript
// 筛选进 URL
const { q, sort, page } = route.query;               // 状态源: URL
// 筛选变更 → 重置
watch(filters, () => { page = 1; refetch(); });
// 返回恢复: 数据在 store 缓存 + scroll 存 sessionStorage + 筛选在 URL
// 增量: onShow 时只 patch 变化的行 (id 匹配)
```
