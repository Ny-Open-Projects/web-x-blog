## ARC-379：实时协作的通用前端架构如何设计？
**答**：
- 通用协作架构 = 数据层（CRDT/OT，ARC-117/118）+ 传输层（WebSocket 通道 + 心跳 + 重连 + 消息序号）+ presence 层（光标/选区/状态广播）+ 持久层（快照 + 增量存储）。
- 消息可靠性三件套：seq 保证有序、ack + 超时重发保证不丢、幂等处理保证重发不重复；本地 op 先应用后广播（低延迟），服务端仲裁后广播给他人。
- presence 设计：轻量高频消息（光标）节流（50~100ms）与合并，走独立通道不与文档 op 混流；离线成员 TTL 清理。
- 离线协作：CRDT 天然支持离线编辑，重连后 merge；OT 需要服务端 transform，离线支持弱——离线需求强的选 CRDT（Yjs/Automerge）。
- 房间与规模：大房间（>100 人）不做全量 op 广播——presence 聚合、op 按关注区域订阅（分区/视口过滤）。
```javascript
class CollabSession {
  constructor(doc, ws) {
    this.doc = doc; this.seq = 0;
    ws.on('op', ({ from, op, serverSeq }) => {
      if (seen(serverSeq)) return;                   // 幂等
      this.doc.apply(op); emit('remoteUpdate');
    });
  }
  localOp(op) { this.doc.apply(op);                  // 本地先应用（低延迟）
    this.ws.send({ type: 'op', op, clientSeq: ++this.seq }); } // ack 超时重发
  presence(cursor) { throttleSend({ type: 'cursor', cursor }, 80); }
}
```
