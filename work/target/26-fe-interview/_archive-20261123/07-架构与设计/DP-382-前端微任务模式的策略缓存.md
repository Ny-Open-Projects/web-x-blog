## DP-382：多级缓存策略组合

**答**：
- 多级缓存：内存（LRU）→ IndexedDB（持久）→ 网络——查询逐级回退，写入逐级下沉
- 策略组合的语义：cache-first / network-first / stale-while-revalidate——策略是「读路径的选择器」，策略模式在这里是「读策略可配置」
- 实战结构：cache-strategy 对象 { get(key), put(key, value) }——每级实现同接口（组合模式）——策略选择逐级调用
- SWR 的实现要点：先回旧值（快）+ 后台刷新（新）——新旧替换时的通知（订阅者更新）
- 深水点：缓存的「失效传播」——写操作后的多级失效（内存清 + IDB 清 + 通知订阅者）——只清内存会让 IDB 旧数据复活

```javascript
function createMultiCache({ mem, persistent, strategy = 'stale-while-revalidate' }) {
  return {
    async get(key, fetcher) {
      const memHit = mem.get(key);
      if (memHit) return memHit;
      const disk = await persistent?.get(key);
      if (disk && strategy !== 'network-first') {
        mem.set(key, disk);
        if (strategy === 'stale-while-revalidate') fetcher(key).then((v) => { mem.set(key, v); persistent?.set(key, v); notify(key, v); });
        return disk;                                 // 旧值快回 + 后台刷新
      }
      const fresh = await fetcher(key);
      mem.set(key, fresh); persistent?.set(key, fresh);
      return fresh;
    },
    invalidate(key) { mem.delete(key); persistent?.delete(key); },  // 多级失效
  };
}
```
