## ARC-471：前端动画体系的架构设计
**答**:
- 分层：原子动画（CSS transition/animation、Web Animations API）→ 组件动画（进出场/列表 FLIP/手势驱动）→ 页面编排（路由转场/时间轴编排）→ 动效系统（token 化：时长/缓动曲线统一，设计侧同源）。
- 选型原则：能用 CSS 不用 JS（合成器线程驱动，主线程卡顿不中断）；手势/物理动画用 JS（WAAPI 或 motion 库）；复杂时间轴编排用编排层（GSAP timeline / motion one）。
- 架构约束：动效 token 全局唯一（时长/缓动从设计 token 读取，禁散写 300ms）；动画可关闭（prefers-reduced-motion 全局降级）；动画不阻塞数据（先提交状态后动画，动画失败不影响功能）。
- FLIP 与列表：列表重排用 FLIP（First-Last-Invert-Play）统一实现，避免每个组件手写过渡；路由转场用 View Transitions API（跨文档 MPA 也可用）。
- 性能预算：动画只动 transform/opacity（防 layout 抖动 lint，ARC-46x 参考）；同屏并发动画数量限制（低端机降级策略）。
```javascript
// 动效 token + reduced-motion 降级
const motionToken = { fast: 150, normal: 250, slow: 400, ease: [0.4, 0, 0.2, 1] };
const respectReduced = matchMedia('(prefers-reduced-motion: reduce)').matches;
export function animate(el, keyframes, opts) {
  if (respectReduced) return;                                 // 用户偏好优先
  return el.animate(keyframes, { ...opts, duration: opts.duration ?? motionToken.normal,
    easing: `cubic-bezier(${motionToken.ease})` });
}
```
