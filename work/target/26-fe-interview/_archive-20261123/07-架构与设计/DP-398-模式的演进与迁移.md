## DP-398：模式演进与迁移

**答**：
- 模式随框架演进：HOC → render props → hooks（装饰/复用的形态迁移）；mixin → composable；类组件模式 → 函数组件模式——「模式意图不变，形态随范式」
- 迁移的等价映射：HOC withData(Component) → useData() + Component（同样的逻辑不同载体）——迁移时先建映射表
- 存量迁移策略：新旧共存（新代码用新模式，存量渐进）——「绞杀者」在模式层面同样适用
- 模式迁移的风险：行为差异（HOC 的 props 注入 vs hook 的作用域）——迁移不是语法转换是语义重审
- 深水点：迁移的「终局判断」——有些模式不该迁移（合理的 HOC 是静态增强——hooks 化反而复杂）——按语义而非潮流迁移

```text
HOC → Hooks 迁移映射:
  withAuth(Component)        → useAuth() + 条件渲染
  withSubscription(C, src)   → useEffect + useSyncExternalStore
  connect(mapState)(Comp)    → useSelector(mapState)
判断: 语义等价才迁; 静态增强类 HOC 保留
```
