## DP-439：安全模式组合

**答**：
- 安全的模式组合：装饰器/代理（输出编码统一包装——innerHTML 的安全代理）、策略（CSP 策略配置）、观察者（MutationObserver 防水印篡改）、命令（安全事件的应急 SOP）
- 水印的防篡改：MutationObserver 监听水印节点删除/改样式 → 立即重建（观察者的防御性应用）
- 富文本的安全层：统一 sanitizer 组件（策略——白名单清洗策略按业务配置）——「每个业务自己 escape」必漏
- CSP 的策略演进：report-only 先行（观察违规不阻断）→ 收紧 enforce——安全策略的灰度
- 深水点：安全的「架构级 vs 补丁级」——XSS 泛滥的根因是架构缺输出编码层（补单个漏洞是打地鼠）——架构师的安全职责

```javascript
// 水印防篡改 (观察者)
new MutationObserver(() => {
  if (!document.getElementById('__wm__')) mountWatermark(userTag);   // 被删即重建
}).observe(document.body, { childList: true });
// 统一 sanitizer (策略)
export const sanitize = (html, profile) => sanitizeHtml(html, PROFILES[profile]);   // profile: comment/article
```
