## ARC-607：评论互动体系
**答**:
- 互动模型：多类型回应（👍❤️😂 多表情——每类型独立计数 + 我的回应集合）、点赞/踩（二态互斥）、计数展示（折叠策略：>1k 显示 1k+——精确数不实时刷）。
- 状态一致性：我的互动状态（是否已赞——本地状态 + 服务端权威 ARC-460）、乐观更新（点击立即 +1 与高亮 → 失败回滚）、重复点击语义（再点取消——toggle 协议幂等）。
- 高并发计数：计数不实时精确（最终一致 + 定期对账——展示层聚合，ARC-382 服务端）、热评论互动风暴（单条评论爆赞——计数异步聚合防写热点 NODE-412 攒批）。
- 渲染性能：千条评论的互动状态映射（Map by commentId O(1) 更新——列表局部 patch 不重渲全列表 ARC-442）、表情面板懒加载（emoji 资源分包）。
- 合规与治理：互动数据可清理（用户删除账号时互动数据匿名化 NODE-443）、刷赞风控（异常互动模式上报 ARC-158）。
```javascript
// 互动 toggle + 乐观
async function react(commentId, type) {
  const prev = store.get(commentId);                             // 乐观
  store.patch(commentId, toggleState(prev, type));
  try { await api.react({ commentId, type, on: !prev.mine.has(type) }, { idempotencyKey: `${uid}:${commentId}:${type}` }); }
  catch { store.patch(commentId, prev); }                        // 回滚
}
```
