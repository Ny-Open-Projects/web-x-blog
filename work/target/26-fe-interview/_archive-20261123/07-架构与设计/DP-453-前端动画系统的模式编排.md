## DP-453：动画系统组合

**答**：
- 动画系统的模式全景：状态机（动画状态：idle→running→paused→done——中断恢复语义）、策略（缓动策略：linear/ease/spring——可插拔）、命令（动画编排序列——序列化）、观察者（进度事件订阅——进度条联动）
- 中断接续：动画中途新手势——「从当前值接续」（WAAPI 的 currentTime 保留 / JS 维护 current 值——不跳回起点）
- 序列编排：多段动画的编排（A 完成 → B 开始 / 并行——命令的序列与并行组合）
- 弹簧物理：缓动策略的升级（spring 参数：刚度/阻尼——真实物理感——中断自然）
- 深水点：动画的「渲染路径纪律」——只动 transform/opacity（合成器线程）——动画编排的属性选择是性能前提

```javascript
// 状态机 + 策略 + 观察者
const anim = createAnimation({
  from: 0, to: 100,
  easing: spring({ stiffness: 120, damping: 14 }),   // 策略: 可插拔缓动
  onUpdate: (v) => el.style.transform = `translateX(${v}px)`,   // 观察者: 进度
});
// 中断接续: 新目标 → from = current, to = newTarget — 从当前值继续
```
