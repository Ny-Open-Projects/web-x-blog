## DP-401：富文本编辑器的模式组合

**答**：
- 编辑器的模式全景：命令模式（每个操作是可撤销命令）、备忘录/快照（文档版本）、组合模式（文档树——段落含行内元素）、观察者（选区变化/内容变化广播）、状态机（编辑态：普通/选区/IME 组合中）、策略（粘贴清洗策略：Word/HTML/纯文本）
- 核心难点一（undo 语义）：命令粒度（一次粘贴=一条命令，连续输入合并）——命令的 merge 协议
- 核心难点二（协同）：OT/CRDT 的操作模型——「操作可交换」的数学保证（这是命令模式的分布式升级）
- 插件系统：工具栏按钮 → 命令注册（插件即命令+快捷键+菜单项的组合注册）
- 深水点：IME 组合期（中文输入法）——composition 期间冻结命令栈（拼音过程中不产生撤销点——compositionend 才入栈）

```javascript
class EditorCommand {
  constructor(undo, redo, { mergeWindow = 500 } = {}) { this.undo = undo; this.redo = redo; this.mergeWindow = mergeWindow; }
  merge(next) { return next.ts - this.ts < this.mergeWindow && next.type === this.type ? next : null; }
}
// 命令栈 + 粘贴清洗策略:
// strategies.set('paste:html', (html) => sanitize(html))   ← 策略按来源选
// IME: compositionstart → 冻结栈; compositionend → 入栈
```
