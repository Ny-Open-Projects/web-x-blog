## DP-432：支付渠道策略路由

**答**：
- 支付渠道的策略组合：策略（渠道选择：微信/支付宝/银行卡——按容器/金额/用户偏好路由）、责任链（渠道降级链：首选失败 → 备选）、命令（支付发起/取消/查单）、状态机（支付状态：init→paying→success/failed/pending）
- 渠道路由的策略输入：容器检测（微信内只能 JSAPI 支付）、金额限制（银行卡限额）、AB 配置（渠道权重实验）——策略是多输入的函数
- 降级链：首选渠道失败 → 责任链下一个渠道（自动降级 + 用户提示）
- 深水点：渠道策略的「结果确认统一」——各渠道的回调机制不同（同步回调/异步通知）——门面统一「查单为准」的确认协议

```javascript
const channelStrategies = [
  { match: (ctx) => ctx.inWeChat, channel: 'jsapi' },
  { match: (ctx) => ctx.amount > 50000, channel: 'bank' },
  { match: () => true, channel: 'h5' },
];
const pick = (ctx) => channelStrategies.find((s) => s.match(ctx)).channel;
// 降级链: pay(channel) fail → next channel → 全败 → 错误页
// 确认统一: 门面 pay() 内 pollOrderState(orderId) — 服务端为准
```
