## DP-407：搜索联想模式组合

**答**：
- 搜索联想的模式全景：策略（联想策略：历史+热词+拼写纠错的合并策略）、命令（可撤销：清除搜索）、状态机（idle→typing→loading→shown→selected）、观察者（选中事件广播——搜索历史/埋点订阅）
- 竞态防御是核心：旧请求响应不覆盖新结果（seq 令牌 + abort）——状态机的 loading 态与竞态守卫配合
- 联想合并策略：多源结果按「源优先级 + 去重」合并（历史去重、热词排序）——策略管道
- 键盘交互的状态机：↑↓导航（activeIndex）+ Enter 选择 + Esc 关闭——状态机消费键盘事件
- 深水点：联想的「IME 兼容」——中文输入法 composition 期间不发请求——状态机加「composing」中间态

```javascript
// 联想合并策略管道
const mergeStrategies = [dedupe, bySourcePriority, limit(10)];
const suggestions = mergeStrategies.reduce((acc, s) => s(acc), rawResults);
// IME 兼容: composing ? skip : fetch   ← 状态机中间态
// 竞态: const mySeq = ++seq; ... if (mySeq !== seq) return;
```
