## DP-428：动态权限路由

**答**：
- 动态路由的模式组合：工厂（按权限动态生成路由表）、策略（路由守卫策略）、观察者（权限变更 → 路由表重建）、备忘录（刷新后路由恢复——权限持久化）
- 动态注册的实现：router.addRoute（权限过滤静态表后动态挂载）——「注册即校验」（路由的权限元信息在注册时检查）
- 刷新恢复的时序：权限接口未返回时导航（守卫等待权限就绪——pending promise 闸门）
- 404 与权限的关系：无权限页面返回 404（不暴露页面存在）vs 403（暴露但禁入）——安全语义的产品决策
- 深水点：登出/切租户的路由清理——动态注册的路由要 removeRoute（旧权限的路由残留 = 越权访问）

```javascript
async function setupDynamicRoutes(router, authReady) {
  await authReady;                                    // pending 闸门
  const perms = authStore.permissions;
  for (const r of STATIC_ROUTES) {
    if (r.meta?.perm && !perms.has(r.meta.perm)) continue;
    router.addRoute(r);                               // 工厂: 权限过滤后注册
  }
  router.addRoute({ path: '/:pathMatch(.*)', component: NotFound });
}
// 登出: 注册的动态路由全部 removeRoute (清理)
```
