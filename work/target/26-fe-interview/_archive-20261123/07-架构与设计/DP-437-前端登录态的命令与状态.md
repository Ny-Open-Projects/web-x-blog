## DP-437：登录态组合

**答**：
- 登录态的模式全景：状态机（会话状态：anonymous→authenticating→authenticated→expired）、命令（登录/登出/刷新——可审计）、观察者（token 变更广播——多标签同步）、策略（token 存储策略：memory+refresh cookie——XSS 面）、代理（fetch 包装自动带 token+401 重放）
- 401 重放的竞态：多个请求同时 401（单飞刷新——共享一次登录）——命令的单飞变体
- 多标签一致性：登出广播（storage 事件/BroadcastChannel——所有 tab 同步失效）
- 深水点：刷新令牌的「竞态安全」——refresh 进行中其他请求等待（pending promise 复用）而非各自 refresh（token 互相覆盖）

```javascript
let refreshing = null;
async function getToken() {
  let token = mem.get();
  if (token) return token;
  refreshing ??= doRefresh().finally(() => { refreshing = null; });  // 单飞
  return refreshing;
}
// 广播: bc.onmessage = ({ data }) => data.type === 'logout' && clearLocal();
// fetch 代理: 401 → getToken() → 重放一次 (幂等方法)
```
