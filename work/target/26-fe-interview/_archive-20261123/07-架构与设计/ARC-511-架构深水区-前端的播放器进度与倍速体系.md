## ARC-511：播放器进阶架构：倍速/进度记忆/续播
**答**:
- 进度记忆：定时快照（10s 节流）到服务端（跨设备续播）+ 本地即时（防服务端丢失）；关键结构 { videoId, position, duration, updatedAt }；快播结束判定（position/duration > 95% 视为看完，续播从头或下一集）。
- 倍速体系：0.5~2.0 档位（preservesPitch 保音调）；倍速下进度记忆与打点统计仍按真实时间；移动端后台播放与锁屏控制（MediaSession API：快进/倍速远程控制）。
- 续播 UX：冷启动"上次看到 12:34，继续播放"确认卡；自动续播与手动续播两种模式按业务选择。
- 弹幕与进度联动：弹幕按播放时间轴分布（ARC-178），倍速下弹幕密度自适应（不因倍速堆积）。
- 可靠性：进度快照幂等（videoId + 端设备号去重）、多端冲突取最新时间戳；崩溃恢复（本地进度领先服务端时以本地为准提示确认）。
```javascript
// 进度记忆
const save = throttle(async (pos) => {
  const p = { videoId, position: Math.floor(pos), duration, updatedAt: Date.now() };
  localStorage.setItem(`prog:${videoId}`, JSON.stringify(p));
  if (p.position % 10 < 1) await api.saveProgress(p);          // 服务端节流快照
}, 1000);
player.on('timeupdate', () => save(player.currentTime));
// 续播：const last = await api.getProgress(videoId); if (last && last.position/duration < 0.95) seek(last.position)
```
