## DP-422：图表库封装

**答**：
- 图表封装的模式全景：适配器（多图表库统一 Chart 接口——echarts/chartjs 可换）、策略（数据更新策略：setOption merge vs 替换）、观察者（数据源订阅）、享元（实例池——同配置图表复用）、命令（交互事件：zoom/click 回调封装）
- 封装的核心价值：业务依赖统一 Chart API（换库/升级不改业务）——「库的替换成本」被适配器锁死在封装层
- 实战要点：生命周期的封装（mount/dispose/resize——业务忘 dispose 是泄漏大头——封装层兜底）、配置合并策略（默认配置 + 业务覆盖——深合并）
- 深水点：图表的「数据 diff」——setOption 全量 vs 增量（大数据量 merge 性能——notMerge: false 的语义掌握）

```javascript
class ChartFacade {
  #inst = null;
  mount(el, option) {
    this.#inst ??= echarts.init(el);                 // 享元: 复用实例
    this.#inst.setOption(this.#mergeDefaults(option));
    this._resizeObserver ??= observeEl(el, () => this.#inst.resize());   // 兜底 resize
    return this;
  }
  update(data) { this.#inst.setOption({ series: [{ data }] }, { lazyUpdate: true }); }  // 增量策略
  dispose() { this.#inst?.dispose(); this._resizeObserver?.disconnect(); }   // 防泄漏
}
```
