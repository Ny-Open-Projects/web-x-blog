## ARC-648：评价体系
**答**:
- 评价结构：评分（星级 + 维度分：描述/物流/服务）、图文（图片上传 ARC-605 + 文字——敏感词过滤 ARC-548）、标签评价（预设标签快选——标签服务端配置）、追评（时间窗口内追加——原评关联）。
- 展示架构：评价列表（筛选：好评/带图/追评 + 排序——ARC-524 搜索结果模式）、评价摘要（好评率/标签云——服务端聚合统计）、有图优先（图墙模式——瀑布流）、商家回复（评价 → 回复嵌套展示）。
- 合规与审核：评价审核状态（ARC-608 状态流——通过后展示）、刷评治理（异常评价模式隐藏——风控标记后不展示但作者可见）、恶意评价申诉。
- 激励：评价有礼（晒图返券——激励合规披露）、评价提醒（订单完成 N 天提醒评价——频控）。
- 一致性：评分统计与评价列表同步（新评价 → 好评率更新——缓存失效 ARC-507）、删除评价（作者删除 → 统计重算异步——最终一致标注）。
```javascript
// 评价提交
const review = { orderId, stars: 5, dims: { desc: 5, logistics: 4 }, tags: ['包装好'], images: [mediaIds], content: cleanText };
await api.submitReview(review, { idempotencyKey: orderId });     // 一单一评幂等
// 状态：{ audit: 'pending' } → 审核通过后列表可见（ARC-608）
```
