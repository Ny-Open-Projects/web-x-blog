## DP-406：拖拽排序模式组合

**答**：
- 拖拽的模式全景：状态机（拖拽状态：idle→pressing→dragging→settling——每态的手势语义）、策略（排序策略：交换/插入/依赖容器）、命令（一次拖拽=一条命令——可撤销）、观察者（跨容器拖拽的事件广播）
- 跟手与动画的分离：拖拽中 transform 直写（跟手，无动画）+ 松手 FLIP 动画（settle）——「跟手态与惯性态」的策略切换
- 跨容器拖拽：拖入目标容器时源容器移除+目标容器插入（观察者广播 + 命令封装为原子操作）
- 深水点：拖拽的「状态机中断处理」——拖拽中组件卸载/触摸取消（pointercancel）——任意状态可安全回 idle（不残留半拖拽状态）

```javascript
const dragFSM = createMachine({
  idle: { on: { pointerdown: 'pressing' } },
  pressing: { on: { move: 'dragging', pointerup: 'idle' } },
  dragging: { on: { pointerup: 'settling', pointercancel: 'idle' } },  // 任意取消安全
  settling: { on: { transitionend: 'idle' } },
});
// 命令: { execute: () => reorder(from, to), undo: () => reorder(to, from) } — 撤销排序
```
