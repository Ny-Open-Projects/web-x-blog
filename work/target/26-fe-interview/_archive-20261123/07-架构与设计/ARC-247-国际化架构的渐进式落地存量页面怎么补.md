## ARC-247：国际化架构的渐进式落地：存量页面怎么补？
**答**：
- 先有引擎后有翻译：第一步把 i18n 运行时（fallback 到原文案）接入，`t(key)` 找不到时返回中文原文——未翻译页面先"能跑"，再逐步补 key。
- 存量文案收敛：AST 扫描 JSX 文本节点自动生成"key 建议 + 文案清单"，人工确认后批量替换；高频/面向海外用户页面优先。
- 分级策略：P0（首页/下单/支付）必须全量翻译后开放语言入口；P1 渐进；P2 暂不开放该语言。语言入口按"覆盖率达标"灰度开放，避免"半吊子翻译"伤品牌。
- 防回流：ESLint 禁裸文案（ARC-242）+ 新增页面 PR 模板勾选 i18n 检查项。

```javascript
// 兜底 t：缺 key 返回源文案，而非报错
function t(key, params) {
  const raw = dict[key];
  if (raw == null) {
    missing.report(key);                       // 上报收集 → 进翻译任务池
    return keyFallback(key);                   // keyFallback: 取 key 最后一段还原中文默认文案
  }
  return interpolate(raw, params);
}
// 迁移脚本输出：pages/home.tsx: '欢迎回来' → key 'home.welcome'（人工确认后 codemod 替换）
```
