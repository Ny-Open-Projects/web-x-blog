## ARC-536：用户行为回溯分析架构
**答**:
- 行为数据链路：端上行为流（ARC-535 协议）→ 聚合上报 → 数仓行为明细表（session 维度有序）→ 分析引擎（漏斗/路径/留存/聚类）。
- 漏斗分析架构：漏斗定义（步骤序列 + 时间窗）→ 引擎按 session 重放事件序列匹配步骤（步长窗口/顺序语义可配置）→ 转化率与流失归因（流失用户下一步去哪了——出口分析）。
- 路径分析：桑基图数据构建（session 的页面/动作转移矩阵）、路径剪枝（TopN 路径 + 其他聚合）。
- 用户分群：行为特征构建（RFM/功能使用深度）→ 分群 → 与实验/推送联动（ARC-390）。
- 隐私与合规：行为数据脱敏与同意管理（ARC-154）、分析查询权限分级（明细级查询需审批）。
```javascript
// 漏斗引擎（session 重放）
function funnel(events, steps, { windowMs = 30 * 60e3 } = {}) {
  let idx = 0;
  for (const e of events) {                                      // session 内有序事件
    if (e.name === steps[idx]) { idx++; if (idx === steps.length) return true; }
    else if (e.at - events[steps[idx].lastAt] > windowMs) return false; // 超窗
  }
  return false;
}
// 出口分析：流失 session 在最后一步后 10min 内的事件 topN → 流失去向
```
