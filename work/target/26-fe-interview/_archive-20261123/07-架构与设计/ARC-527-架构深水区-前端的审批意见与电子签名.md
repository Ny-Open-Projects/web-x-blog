## ARC-527：电子签名与手写批注架构
**答**:
- 手写签名：Canvas 笔迹采集（pointer 事件 + 平滑贝塞尔插值）、压力/速度模拟笔锋、签名数据归档（矢量路径优先——可缩放无损，PNG 快照兜底）。
- 签名合规链路：签名动作绑定身份（签署前二次认证 ARC-415）、时间戳与文档哈希存证（签名时刻 + 签署内容指纹，服务端存证不可改）、签署留痕审计。
- 批注系统：文档上叠加批注层（批注锚定到文档位置——文档变更后批注锚点跟随 ARC-379 相对锚点思想）、批注列表与文档视图联动、批量回复。
- 移动端适配：触摸签名（防误触：专用签名区域 + 手势屏蔽）、横屏签名板。
- 数据安全：签名图片/文档哈希上传签名 URL（ARC-377）、签署完成后文档只读化（版本锁定 + 修改告警）。
```javascript
// 签名采集 + 存证
const strokes = [];
canvas.onpointermove = (e) => { if (drawing) strokes.push(smoothPoint(e)); };
async function sign() {
  await reauth();                                                // 签署前二次认证
  const docHash = await sha256(docBytes);
  const r = await api.signDoc({ docHash, sig: toSvg(strokes),
    signedAt: serverTime() });                                   // 服务端存证
  lockDocument(docId);                                           // 只读锁定
}
```
