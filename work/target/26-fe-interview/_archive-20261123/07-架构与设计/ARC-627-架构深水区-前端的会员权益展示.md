## ARC-627：会员权益展示
**答**:
- 权益模型：权益矩阵（会员等级 × 权益项——每权益的可用状态/次数/有效期）、权益核销（使用权益：领取/使用/失效——状态机服务端权威 ARC-469 组合矩阵）。
- 展示架构：权益卡片注册表（权益类型 → 展示组件 + 操作组件——新权益类型注册接入）、权益状态驱动（可用/已用完/未生效/已过期四态渲染——服务端下发状态，前端不判权限 ARC-509 操作集下发）、升级引导（当前等级 vs 下一等级对比——转化组件）。
- 核销流程：权益使用（点击使用 → 核销接口 → 结果反馈——幂等防重复核销 ARC-460 涉账类）、次数型权益（剩余次数实时扣减展示——乐观 + 对账）。
- 跨端一致：权益状态多端同步（App 领取 Web 使用——服务端单源 ARC-415）、权益变更推送（等级变化 → 权益重刷 ARC-550）。
- 合规：权益规则透明（规则说明页 + 生效时间标注）、自动续费提示合规（取消入口明显）。
```tsx
<EntitlementGrid entitlements={entitlements} />                  // 权益矩阵（状态服务端下发）
// 权益卡片：{ type: 'coupon', state: 'available', remain: 3, action: { key: 'claim', form: null } }
// 注册表：EntitlementRenderer['coupon'] → CouponCard（新权益类型注册即接入）
```
