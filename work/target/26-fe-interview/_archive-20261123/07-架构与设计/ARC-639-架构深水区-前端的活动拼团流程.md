## ARC-639：拼团流程
**答**:
- 状态机：团状态（开团 → 拼团中（人数进度）→ 成团/超时解散）+ 团员状态（已参团/待支付/已退款）——服务端权威，推送驱动（成团/解散通知 ARC-394）。
- 流程交互：开团（支付后创建团——分享邀请链接带团 ID 签名——防伪造参团）、参团（链接进入 → 团详情（剩余名额/倒计时）→ 参团支付）、成团后履约（发货——团状态驱动）。
- 分享链路：邀请海报/链接（参数携带 + 短链——分享追踪 ARC-617）、小程序与 H5 互跳参团（跨端参团一致性 ARC-415）。
- 异常场景：超时未成团（自动退款——退款状态展示 ARC-625、解散通知）、成员退出（未支付成员自动退出——名额释放）、重复参团（一人一团的限制——服务端校验前端置灰）。
- 展示一致性：团进度实时（成员列表 + 倒计时——倒计时到期本地触发刷新确认 ARC-481 钟差）、虚拟成团配置（机器人补位——合规与体验的产品决策展示透明）。
```javascript
// 团状态订阅
ws.subscribe(`group:${groupId}`, (st) => groupStore.patch(st));  // 成员/进度推送
// 参团：join(groupUrl) → 校验签名 → 团详情 → pay → { joined, remain }
sm.on('timeout', () => showRefundFlow('超时未成团，自动退款'));   // 解散退款联动
```
