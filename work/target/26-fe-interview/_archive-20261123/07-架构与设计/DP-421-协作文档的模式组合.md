## DP-421：协作文档组合

**答**：
- 协作文档的模式全景：命令模式（本地操作 = 命令——可撤销且可传输）、观察者（远端操作接收 → 应用到本地）、状态（连接/同步状态）、策略（冲突解决策略：OT 变换/CRDT 合并）、备忘录（版本快照）
- 协作的核心抽象：操作（operation）是一等公民——本地执行 + 广播 + 远端重放（命令模式的分布式化）
- 光标与选区：他人的光标渲染（观察者接收 + 位置变换——OT 的 transform 补偿）
- 深水点：本地撤销与协同撤销的语义——「撤销我的操作」而非「撤销最后操作」（OT 的 undo 变换——撤销要考虑并发操作的变换补偿）——这是协同编辑器最深的难点

```javascript
// 本地操作: { type: 'insert', pos: 5, text: 'hello' }
// 本地执行 → 广播; 远端操作到达 → transform(远端op, 本地pendingOps) → 应用
// 撤销: myUndoOp = transform(inverse(myOp), concurrentOps) — 变换补偿后撤销
```
