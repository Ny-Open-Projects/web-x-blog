## DP-463：表单库核心模式

**答**：
- React Hook Form 的模式内核：非受控优先（ref 注册——性能：输入不触发整表重渲）、观察者（订阅字段变更——watch 精确订阅）、策略（校验器可插拔：yup/zod/自定义）、代理（Proxy 追踪字段访问——只在 touched 时校验）
- 非受控的性能原理：input 不走 React 受控（ref 直读 DOM 值）——每次输入零重渲（提交时统一取值）
- 受控字段共存：Controller 组件包裹受控第三方（DatePicker）——非受控主体 + 受控插件的混合架构
- 深水点：RHF 的「订阅粒度」——watch('email') 只订阅 email（无关字段更新不触发）——观察者的 selector 化与状态库同构

```javascript
const { register, watch, handleSubmit, control } = useForm();
<input {...register('email', { required: true })} />   // 非受控: ref 注册
const email = watch('email');                          // 精确订阅
<Controller name="date" control={control} render={...} />  // 受控插件混入
// 性能本质: 输入不重渲 — ref 直读 + 精确订阅
```
