## DP-443：灰度发布组合

**答**：
- 灰度的模式全景：策略（分桶策略：哈希/白名单/地域）、状态机（灰度阶段：1%→5%→25%→100%——每阶段门禁）、观察者（指标监控 → 自动回滚）、命令（推进/回滚——审计）
- 分桶一致性：同用户稳定同组（哈希——体验一致：灰度用户不能来回切版本）
- 灰度指标的自动门禁：错误率/性能劣化超阈 → 自动回滚（凌晨不用人守——观察者+命令的组合自动化）
- 深水点：灰度的「样本陷阱」——低频功能 1% 流量样本不足（统计无意义）——低频功能用定向白名单（内部用户/自愿者）而非百分比

```javascript
class Rollout {
  #stages = [1, 5, 25, 100]; #current = 0;
  isUserIn(userId) { return hash(`${this.version}:${userId}`) < this.#stages[this.#current] / 100; }
  async advance() {
    const gate = await metrics.check(this.appId);      // 观察者: 指标门禁
    if (!gate.pass) return this.rollback('auto: ' + gate.reason);   // 自动回滚
    this.#current = Math.min(this.#current + 1, this.#stages.length - 1);
  }
}
```
