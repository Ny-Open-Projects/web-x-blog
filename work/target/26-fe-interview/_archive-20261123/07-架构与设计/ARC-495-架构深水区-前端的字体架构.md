## ARC-495：前端字体架构：中文字体加载策略
**答**:
- 中文全量字体 5~10MB 不可直载——架构手段：子集化（按使用字符集切分，unicode-range 分片按需下载，cn-font-split 工具链）、woff2 + 预加载关键分片。
- 策略分级：品牌标题字（少量字符全子集化 < 100KB，preload）、正文系统字体栈（不加载）、特殊场景（营销页艺术字：页面静态后服务端按页面文本生成精确子集）。
- font-display 策略：swap（闪换风险：CLS）vs optional（可能整页不生效）——标题字用 swap + 尺寸度量对齐（fallback 字体 metrics-adjust 防位移），正文用系统栈避免 swap。
- 缓存架构：字体分片 immutable 缓存（内容哈希文件名），子集按版本更新（版本号进 URL）；多页面共享同一套分片。
- 可观测：字体加载耗时与失败率、swap 引发的 CLS 归因进监控。
```css
/* unicode-range 分片：浏览器只下载页面用到的分片 */
@font-face {
  font-family: 'BrandTitle';
  src: url('/fonts/brand-title.0.woff2') format('woff2');
  unicode-range: U+4E00-4FFF;                 /* 分片 0 */
  font-display: swap;
}
@font-face { font-family: 'BrandTitle'; src: url('/fonts/brand-title.1.woff2'); unicode-range: U+5000-5FFF; font-display: swap; }
```
