## ARC-609：IM 多媒体消息渲染与传输
**答**:
- 消息模型：多媒体消息 = 元数据（类型/尺寸/时长/缩略图）+ 资源引用（媒体 ID，正文不含二进制——消息轻量资源走对象存储 ARC-339）。
- 发送链路：本地立即展示（发送中状态 + 本地预览——先显示后上传）、上传（分片直传 + 进度 ARC-377）→ 上传完成换正式 ID → 消息状态更新（发送中→已发送）；失败重试（幂等键）。
- 渲染链路：缩略图优先（列表内缩略图——大图点击后原图渐进加载 ARC-341）、语音（录制波形 UI/播放进度/未读红点——语音未听标记）、视频（首帧封面 + 时长 + 流式播放）、文件（大小/类型图标 + 下载进度）。
- 生命周期：媒体资源与消息绑定（消息撤回 → 资源清理策略：延迟删除——防引用失效）、过期清理（远端媒体保留期 + 端上缓存清理 ARC-434）。
- 性能：多媒体消息列表虚拟化 + 图片懒加载 + 视口外媒体不加载（ARC-442/436 优先级）、端上媒体缓存上限管理。
```javascript
// 多媒体消息发送
async function sendImage(file) {
  const localUrl = URL.createObjectURL(file);                    // 本地先显
  const msg = store.append({ type: 'image', localUrl, state: 'uploading', meta: await probe(file) });
  const { mediaId } = await upload(file, { onProgress: p => store.patch(msg.id, { progress: p }) });
  store.patch(msg.id, { mediaId, url: cdnUrl(mediaId), state: 'sent' });
}
```
