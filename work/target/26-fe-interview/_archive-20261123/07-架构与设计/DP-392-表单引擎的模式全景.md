## DP-392：表单引擎模式全景

**答**：
- 表单引擎的模式组合全景：策略（校验规则）、观察者（字段变更通知）、中介者（跨字段联动）、备忘录（草稿）、状态机（提交状态）、命令（撤销）
- 一张图看清：字段值变更 → 观察者通知 → 中介者联动 → 策略校验 → 状态机流转（editing→validating→submitting）→ 备忘录存草稿
- 模式组合的边界：不是所有表单都需要全套——「简单表单用库，复杂表单用引擎」——引擎是模式组合的实战教材
- 自研 vs 库（React Hook Form/vee-validate）：schema 复杂度/动态表单需求/跨端复用——RHF 够用就不自研
- 深水点：表单引擎的「schema 即数据」——校验规则/联动规则/渲染配置全部数据化（schema 可序列化——低代码表单的基座）

```javascript
// 表单引擎内核的模式协作
const form = createForm({
  fields: { email: { rules: ['required', 'email'] } },        // 策略
  links: [{ when: 'type=enterprise', require: ['taxId'] }],   // 中介者联动规则
});
form.on('change', persistDraft);                              // 观察者→备忘录
form.submit();                                                 // 状态机: idle→submitting
// 每个模式独立可测, 组合出引擎
```
