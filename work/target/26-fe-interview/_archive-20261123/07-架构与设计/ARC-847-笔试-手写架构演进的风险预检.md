## ARC-847：手写风险预检

**题目**：实现架构演进方案的「风险预检」`EvolutionRiskCheck`：① 检查维度：团队能力（新架构技能覆盖——SkillMatrix 联动）、依赖就绪（生态兼容矩阵）、业务窗口（大促冻结期冲突）、回滚可行（回滚成本估算）、数据兼容（存储格式影响）；② 每维度的检查函数：pass/warn/fail（fail = 方案不可行需调整）；③ 检查报告：五维雷达 + 阻塞项清单（fail 项的调整建议）；④ 与风险登记表联动：预检发现的新风险自动登记（owner 指派）；⑤ 演练建议：高风险维度建议的演练场景（回滚演练/兼容演练）。写出实现。

```javascript
class EvolutionRiskCheck {
  #checks;
  constructor({ skillMatrix, compatMatrix, calendar, storage }) {
    this.#checks = [
      { dim: '团队能力', check: (plan) => {
        const gaps = skillMatrix.match(plan.requiredSkills).gaps;
        return gaps.length ? { level: 'warn', detail: `技能缺口: ${gaps.map((g) => g.skill).join(',')}` } : { level: 'pass' };
      } },
      { dim: '依赖就绪', check: (plan) => {
        const notReady = plan.deps.filter((d) => !compatMatrix.supports(d));
        return notReady.length ? { level: 'fail', detail: `生态未支持: ${notReady.join(',')}`, fix: '等待生态或 polyfill' } : { level: 'pass' };
      } },
      { dim: '业务窗口', check: (plan) => {
        const conflict = calendar.frozenWindows.some(([s, e]) => plan.timeline.some((t) => t >= s && t <= e));
        return conflict ? { level: 'warn', detail: '与大促冻结期重叠' } : { level: 'pass' };
      } },
      { dim: '回滚可行', check: (plan) => {
        const cost = plan.rollbackCostDays;
        return cost > 10 ? { level: 'warn', detail: `回滚需 ${cost} 人日, 建议分更多检查点` }
          : cost === null ? { level: 'fail', detail: '未设计回滚方案' } : { level: 'pass' };
      } },
      { dim: '数据兼容', check: (plan) => {
        const breaking = storage.hasSchemaBreakingChange(plan.storageChanges);
        return breaking ? { level: 'fail', detail: '存储 schema 破坏性变更', fix: '加版本号+迁移函数' } : { level: 'pass' };
      } },
    ];
  }
  run(plan) {
    const results = this.#checks.map(({ dim, check }) => ({ dim, ...check(plan) }));
    const fails = results.filter((r) => r.level === 'fail');
    const radar = results.map((r) => (r.level === 'pass' ? 5 : r.level === 'warn' ? 3 : 1));
    const newRisks = fails.map((f) => ({ category: '架构演进', description: f.detail, probability: 4, impact: 4 }));
    return { pass: fails.length === 0, results, radar, newRisks,
      drills: results.filter((r) => r.level === 'warn').map((r) => `${r.dim} 演练建议: 回滚/兼容演练`) };
  }
}
```

**评分点**：
- 五维检查函数（能力/依赖/窗口/回滚/数据——可插拔）
- fail/warn/pass 三级（fail 阻塞方案）
- 与 SkillMatrix/风险表联动（数据复用）
- 演练建议输出（warn 项的演练场景）
