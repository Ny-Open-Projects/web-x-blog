## DP-429：直播间组合

**答**：
- 直播间的模式全景：状态机（推流/拉流状态：loading→playing→buffering→ended——错误恢复策略链）、观察者（弹幕/礼物/在线人数多通道订阅——通道分流）、策略（消息渲染策略：弹幕高优/礼物特效/聊天低优——分级渲染）、享元（弹幕 DOM 复用——弹幕池）
- 多通道的频率分层：弹幕（高频可丢——datagram 语义）、消息（可靠有序——stream 语义）、人数（低频快照）——WebTransport/WebSocket 的通道分流
- 弹幕渲染的性能模式：DOM 池 + rAF 批量渲染（弹幕池享元——超量丢弃最旧——「弹幕不排队」）
- 深水点：直播间的「异常恢复」——推流中断重连（观众端感知：卡顿→重连→无缝续播——GOP 对齐）——状态机的恢复路径设计

```javascript
// 通道分流
ws.subscribe('danmaku', renderDanmakuPool);          // 高频: 弹幕池, 可丢
ws.subscribe('gift', renderGiftEffect);              // 中频: 特效队列
ws.subscribe('viewers', (n) => setCounter(n));       // 低频: 快照
// 弹幕池: 超过 50 条/屏 丢最旧 (不排队 — 排队必延迟)
```
