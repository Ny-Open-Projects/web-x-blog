## DP-470：工作流引擎

**答**：
- 工作流引擎的模式：状态机（节点流转）、责任链（节点审批链）、策略（节点类型策略：审批/会签/抄送/条件分支）、命令（通过/驳回/转办）、备忘录（流程快照——刷新恢复）
- 条件分支的策略化：网关（金额>5w 走财务分支——DSL 声明条件路由）——流程图的数据化
- 驳回的语义选择：驳回到发起人（重填）vs 驳回上一节点（修改）——驳回策略是产品决策
- 深水点：工作流的「前端与服务端状态机对齐」——前端的状态机是服务端的镜像（渲染用）——真实流转以服务端为准（前端只是投影）

```javascript
// 流程 DSL
const flow = {
  nodes: [{ id: 'start' }, { id: 'approve1', type: 'approve' }, { id: 'gateway', type: 'exclusive' }, ...],
  edges: [{ from: 'gateway', to: 'finance', when: (ctx) => ctx.amount > 50000 }],
};
// 前端渲染: 当前节点 = 服务端返回的 activeNode — 前端状态机只是投影
```
