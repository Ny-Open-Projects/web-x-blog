## DP-412：文件上传组合

**答**：
- 上传的模式全景：状态机（任务状态：pending→uploading→done/failed/cancelled）、策略（上传策略：直传/分片/秒传——按文件大小选）、命令（取消/重试/暂停——每个是命令对象）、观察者（进度事件广播）、队列（并发控制——背压）
- 策略选择器：小文件直传 / 大文件分片（>10MB 切片）——策略按文件特征路由
- 断点续传：分片状态持久化（已完成分片集合——重启后跳过）——备忘录 + 策略组合
- 深水点：上传的「失败恢复矩阵」——网络切换（重试当前分片）/凭证过期（重签再试）/服务端 5xx（退避）——不同失败原因不同策略

```javascript
function pickStrategy(file) {
  if (file.size < 10 * 1024 * 1024) return directUpload;
  return chunkedUpload({ chunkSize: 4 * 1024 * 1024, resume: !!file.resumeToken });
}
// 上传队列: 并发 3 + 优先级 (用户手动 > 自动) + abort 全部
// 分片持久化: { fileId, doneChunks: [0,1,2] } → 重启跳过已完成
```
