## DP-420：前端沙箱组合

**答**：
- 沙箱的模式全景：代理（window 的 Proxy 代理——伪环境拦截全局访问）、策略（沙箱策略：Proxy 快照/with 作用域/iframe 天然隔离）、外观（沙箱暴露的安全 API 门面）、观察者（沙箱内事件上报）
- 代理沙箱：new Proxy(fakeWindow)——子应用读写 window 落到代理（互不污染）；快照沙箱：进入时拍快照、退出时还原（简单但切换成本高）
- CSS 隔离：shadow DOM（天然）或 scoped 前缀（代理构建时改写）
- 逃逸面审计：setInterval/setTimeout/事件监听的残留（沙箱退出要清——代理拦截注册并登记）
- 深水点：沙箱的「伪环境完备性」——document 的代理难度（真实 DOM 无法完全代理）——「DOM 共享但 JS 隔离」是工程折衷

```javascript
function createSandbox(appId) {
  const fakeWindow = new Proxy({}, {
    get(t, k) { return t[k] ?? window[k]; },         // 未覆盖 fallback 到真 window (只读共享)
    set(t, k, v) { t[k] = v; registerCleanup(appId, k); return true; },  // 写入登记
  });
  const cleanups = [];
  function registerCleanup(appId, k) { cleanups.push(() => delete fakeWindow[k]); }
  return {
    window: fakeWindow,
    dispose() { cleanups.forEach((c) => c()); },     // 退出清残留
  };
}
```
