## ARC-504：中后台表格页标准化架构
**答**:
- 中后台 80% 页面是"查询表单 + 表格 + 行操作"模式——标准化价值巨大：一个 ProTable 级组件 + schema 声明，消灭重复样板。
- schema 声明：列定义（字段/类型/渲染格式/宽度/固定）、筛选定义（字段/控件类型/联动）、操作定义（行操作/批量操作 + 权限码）、导出/导入声明（ARC-490）。
- 内建能力：筛选状态 ↔ URL 同步（ARC-389）、列设置（显隐/排序持久化到用户偏好）、批量操作与任务进度（ARC-486）、行级权限显隐（ARC-420）、空态/加载/错误态统一。
- 扩展点：自定义单元格渲染、自定义工具栏、事件钩子（查询前/行点击）——schema 覆盖 80%，钩子覆盖 20%。
- 治理：页面代码量度量（schema 化后单页 < 100 行）、组件库版本统一、跨项目复用（ARC-462 npm 包路线）。
```tsx
// schema 化表格页
const pageSchema = {
  filters: [
    { name: 'status', control: 'select', options: ORDER_STATUS },
    { name: 'createdAt', control: 'dateRange' }
  ],
  columns: [
    { key: 'no', title: '订单号', copyable: true },
    { key: 'amount', title: '金额', type: 'money' },
    { key: 'ops', actions: [{ key: 'detail', perm: 'order:read' },
      { key: 'cancel', perm: 'order:cancel', confirm: true }] }
  ],
  export: { perm: 'order:export' }, url: '/orders'
};
```
