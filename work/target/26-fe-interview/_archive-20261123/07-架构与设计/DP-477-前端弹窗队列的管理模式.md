## DP-477：弹窗队列

**答**：
- 弹窗的模式问题：多个弹窗同时触发（登录过期 + 系统通知 + 营销弹窗）——堆叠混乱/互相遮挡
- 弹窗队列的模式：优先级队列（P0 登录 > P1 系统 > P2 营销——按优先级出队）、状态机（单活跃弹窗 + 队列等待）、去重（同 ID 弹窗不重复入队——防循环触发）
- 队列的交互协议：弹窗关闭（resolve）→ 出队下一个（串行展示——用户一次处理一个）
- 深水点：弹窗的「生命周期冲突」——页面跳转时未关闭弹窗（路由变化自动清队——还是跨路由保留？按弹窗性质决定）

```javascript
class ModalQueue {
  #queue = []; #active = null;
  push(modal) {
    if (this.#active?.id === modal.id) return;       // 去重
    this.#queue.push(modal);
    this.#queue.sort((a, b) => a.priority - b.priority);
    this.#showNext();
  }
  #showNext() {
    if (this.#active || !this.#queue.length) return;
    const m = this.#queue.shift();
    this.#active = m;
    m.show().finally(() => { this.#active = null; this.#showNext(); });   // 串行
  }
  clearOnRouteChange() { this.#queue = []; /* active 弹窗保留或关闭按性质 */ }
}
```
