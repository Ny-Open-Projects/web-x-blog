## DP-456：构建产物优化

**答**：
- 构建产物的模式应用：策略（按环境产出不同产物——browserslist/条件编译）、享元（共享 chunk——多入口共享依赖）、备忘录（构建缓存——增量构建）、命令（构建流水线的原子步骤）
- code cache 的利用：稳定 URL hash（浏览器缓存编译产物——二次访问免编译）——「稳定的产物指纹」是缓存命中前提
- chunk 拆分的权衡：太碎（请求多+缓存利用率低）太粗（改动全失效）——按「变更频率 × 复用度」拆分
- 深水点：产物分析的「 actionable」——体积报告要指向具体模块（哪个依赖多大、为什么打进来了——source-map-explorer）——报告能行动才有价值

```text
产物优化清单:
  稳定 hash URL → code cache 命中
  按变更频率拆 chunk → 缓存利用率最大化
  共享依赖 externals/ federation → 多应用去重
  体积报告 actionable → 定位到具体模块
```
