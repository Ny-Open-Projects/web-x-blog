## DP-441：日志系统组合

**答**：
- 日志系统的模式全景：策略（日志级别过滤：debug/info/warn/error——级别阈值可配）、责任链（处理管道：采样→脱敏→批量→传输）、观察者（多 sink 订阅：console/上报/存储）、空对象（关闭日志时的空实现——零开销）
- 脱敏的责任链节点：日志中的手机号/token 正则脱敏（管道处理——合规节点）
- 日志的分级路由：error 即时上报 / info 批量 / debug 仅 dev——级别决定通道
- 深水点：日志系统的「零开销关闭」——production 关 debug 时 debug() 调用是空函数（无序列化成本——惰性求值：debug(() => expensive())）

```javascript
function createLogger({ level, sinks }) {
  const LEVELS = { debug: 0, info: 1, warn: 2, error: 3 };
  const log = (lvl) => (...args) => {
    if (LEVELS[lvl] < LEVELS[level]) return;          // 级别过滤
    const entry = { lvl, args: args.map(sanitize), t: Date.now() };
    sinks.forEach((s) => s.write(entry));             // 多 sink
  };
  return { debug: log('debug'), info: log('info'), warn: log('warn'), error: log('error') };
}
// 零开销: prod 关 debug 后 logger.debug 仍被调用但立即 return (无序列化)
```
