## DP-384：不可变数据 + 结构共享

**答**：
- 不可变的核心：改数据 = 产新对象（旧对象不变）——React/Vue 的更新检测依赖引用比较
- 结构共享（Structural Sharing）：更新深层数据时「未变路径共享旧引用」——immer 的核心价值（不整树克隆——内存与比较成本双赢）
- 实战形态：immer produce（draft 修改 → COW 生成新树）/ 手写展开运算符（浅层）/ Immutable.js（Map 结构——学习成本高已边缘化）
- 不可变的收益：变更检测 O(1)（引用比较）、时间旅行（快照天然可用）、并发安全（无中间态）
- 深水点：不可变的「性能边界」——大数组频繁更新（每次 O(n) 拷贝）—— immer 的冻结与 COW 缓解，但高频场景（60fps 动画）仍建议可变 + 手动通知

```javascript
import produce from 'immer';
const nextState = produce(state, (draft) => {
  draft.orders[42].status = 'paid';    // 直接改 draft
});                                     // 未变路径共享旧引用 — O(log n)
// 手写浅版: { ...state, orders: state.orders.map((o, i) => i === 42 ? { ...o, status: 'paid' } : o) }
```
