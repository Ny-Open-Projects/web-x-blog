## DP-529：笔试：手写三态渲染器

**题目**：实现异步状态的三态渲染器：① Result 类型：loading/error/data 三态构造器——统一 { match } 接口；② match 的穷尽性：必须提供三个分支（TS 类型约束——缺分支编译报错）；③ 空态的第四种：data 为空数组时的 empty 态（空数据与加载完成是两种语义）；④ 组合：三态 + 骨架的自动映射（loading → Skeleton / error → RetryUI / data → Children / empty → EmptyUI）；⑤ 错误的重试携带（error 态包含 retry 回调——错误对象可行动）。写出实现。

```typescript
type Result<T, E> =
  | { status: 'loading' }
  | { status: 'error'; error: E; retry: () => void }
  | { status: 'empty' }
  | { status: 'data'; data: T };

function renderResult<T, E>(result: Result<T, E>, ui: {
  loading: () => ReactNode;
  error: (e: E, retry: () => void) => ReactNode;
  empty: () => ReactNode;
  data: (d: T) => ReactNode;
}): ReactNode {
  switch (result.status) {
    case 'loading': return ui.loading();
    case 'error': return ui.error(result.error, result.retry);
    case 'empty': return ui.empty();
    case 'data': return ui.data(result.data);
  }
}
// TS 穷尽性: switch 漏分支 → 编译报错 (return type 检查)
// retry 携带: error 态自带重试回调 — 错误可行动
```

**评分点**：
- 四态建模（loading/error/empty/data——empty 独立语义）
- TS 穷尽性约束（漏分支编译报错）
- retry 携带（错误可行动——不只是展示）
- 空对象模式与状态机的结合
