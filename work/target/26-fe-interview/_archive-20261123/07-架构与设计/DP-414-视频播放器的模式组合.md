## DP-414：视频播放器组合

**答**：
- 播放器的模式全景：状态机（播放状态：idle/loading/ready/playing/paused/buffering/error——事件驱动）、命令（播放控制：play/pause/seek——可序列化为快捷键）、观察者（timeupdate/进度事件订阅）、策略（清晰度切换策略：自动降码率）、适配器（多播放器内核适配：video/hls.js/dash——统一 Player 接口）
- 状态机的完整性：video 原生事件到状态机的映射（playing/waiting/ended/error → 状态迁移）——状态机是「事件到 UI 的翻译层」
- 控制条的解耦：控制条组件只依赖 Player 接口（适配器换内核控制条不动）
- 深水点：播放器的「错误恢复策略」——stalled 5s 重载保进度 + error 3 次降级源 + 最终 fallback UI——错误恢复的策略链

```javascript
// 统一 Player 接口 (适配器)
class PlayerFacade {
  constructor(engine) { this.e = engine; }          // hls.js / native / dash 适配器
  play() { this.e.play(); }
  seek(ratio) { this.e.currentTime = ratio * this.e.duration; }
  setQuality(q) { this.e.switchQuality(q); }        // 策略: 清晰度
}
// 状态机: waiting 5s → reload 保 currentTime; error×3 → fallbackSrc
```
