## ARC-306：低代码平台的多租户与资产复用体系？
**答**：
- 资产分层：平台资产（官方物料/模板）、租户资产（租户内自建物料/页面模板）、个人草稿。租户间资产隔离（ARC-222 多租户权限），平台资产统一升级。
- 复用三级：组件物料（最小）、页面模板（成套页面，改数据即用）、解决方案模板（多页面+数据模型+流程打包，如"进销存方案"）——模板是低代码平台规模化交付的核心杠杆。
- 模板版本：模板升级要兼容已实例化的页面（模板是"源"，实例化时拷贝），升级只能"推荐更新"不能强制覆盖。
- 计量与配额：租户级配额（页面数/数据量/月活），超配额引导升级套餐——平台的商业化基建。

```typescript
// 模板实例化（拷贝语义）
async function instantiate(templateId, tenantId) {
  const tpl = await templateRepo.get(templateId);
  const page = cloneDsl(tpl.dsl);                                  // 深拷贝，与模板脱钩
  const dataModel = cloneEntities(tpl.entities);
  return { pageId: createPage(page, tenantId), modelId: createModel(dataModel, tenantId) };
}
// 模板更新推荐：tpl.version > inst.baseVersion → 提示"模板有新版本"，diff 预览，用户决定是否手工合并
// 配额：assertQuota(tenantId, 'pages', +1) → 超限 throw QuotaError → 前端引导升级套餐
```
