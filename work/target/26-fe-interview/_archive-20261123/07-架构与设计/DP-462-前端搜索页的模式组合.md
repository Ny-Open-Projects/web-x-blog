## DP-462：搜索页组合

**答**：
- 搜索页的模式全景：策略（防抖/联想合并/结果高亮）、状态机（idle→typing→loading→result/empty）、命令（搜索历史——可清除）、备忘录（历史持久化）、观察者（搜索事件埋点）、代理（联想请求的 in-flight 合并）
- 搜索状态机与竞态：typing→loading 的转移 + 旧响应丢弃（seq）——「loading 态不是装饰」是竞态守卫的语义化
- 空态与零结果：无输入（推荐热搜）vs 有输入无结果（空态引导换词）——两种「空」的差异化 UI
- 深水点：搜索的「URL 同步」——搜索词进 URL（分享/回退保留——query 参数是状态的一部分）——「搜索词是状态」的架构认知

```javascript
const searchFSM = createMachine({
  idle: { on: { input: 'typing' } },
  typing: { on: { submit: 'loading', clear: 'idle' } },
  loading: { on: { result: 'result', empty: 'empty' } },
});
// 竞态: loading 态 + seq 令牌 — 旧结果不覆盖
// URL: /search?q=xxx&sort=price — 搜索词是状态
```
