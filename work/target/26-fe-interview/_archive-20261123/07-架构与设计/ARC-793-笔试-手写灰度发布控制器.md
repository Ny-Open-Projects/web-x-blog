## ARC-793：笔试：手写灰度控制器

**题目**：实现发布灰度控制器 `RolloutController`：① 灰度规则：{ appId, version, stages: [1,5,25,50,100], current, metricGate: { errorRate: 0.01 } }；② advance()：进入下一阶段前检查「当前阶段观察时长 ≥N + 指标达标」——不满足返回拒绝原因；③ rollback(reason)：回退到上一版本（记录回滚历史）；④ 用户分桶：`isInRollout(userId)`——一致性哈希（同用户稳定同桶）；⑤ 自动守护：外部指标源轮询（错误率超阈自动 rollback + 告警）；⑥ 操作审计（每次 advance/rollback 记录操作人/时间/原因）。写出实现。

```javascript
class RolloutController {
  #history = []; #audit = [];
  constructor(config, metrics, { notify } = {}) {
    this.cfg = config; this.metrics = metrics; this.notify = notify;
    this.#startGuard();
  }
  isInRollout(userId) {
    if (this.cfg.current >= 100) return true;
    const h = this.#hash(`${this.cfg.appId}:${this.cfg.version}:${userId}`);
    return h < this.cfg.current / 100;
  }
  #hash(s) { let h = 0; for (const c of s) h = (h * 31 + c.charCodeAt(0)) >>> 0; return (h % 10000) / 10000; }

  async advance(operator) {
    const { stages, current } = this.cfg;
    const idx = stages.indexOf(current);
    const next = stages[idx + 1];
    if (next == null) return { ok: false, reason: 'already at 100%' };
    const ok = await this.metrics.checkGate(this.cfg.appId, this.cfg.metricGate);
    if (!ok.pass) return { ok: false, reason: `metric gate failed: ${ok.detail}` };
    this.cfg.current = next;
    this.#audit.push({ op: 'advance', from: current, to: next, operator, t: Date.now() });
    this.notify?.(`灰度推进 ${current}%→${next}%`);
    return { ok: true, current: next };
  }
  rollback(reason, operator) {
    this.cfg.current = 0; this.cfg.version = this.cfg.previousVersion;
    this.#audit.push({ op: 'rollback', reason, operator, t: Date.now() });
    this.notify?.(`灰度回滚: ${reason}`);
  }
  #startGuard() {                                     // 自动守护
    this._guard = setInterval(async () => {
      const ok = await this.metrics.checkGate(this.cfg.appId, this.cfg.metricGate);
      if (!ok.pass && this.cfg.current > 0) this.rollback(`auto: ${ok.detail}`, 'guard');
    }, 60_000);
  }
}
```

**评分点**：
- 一致性哈希分桶（同用户稳定——灰度体验一致）
- advance 的双门检查（观察时长 + 指标达标）
- 自动守护轮询（凌晨自动回滚不依赖人工）
- 操作审计完整（advance/rollback 到人）
