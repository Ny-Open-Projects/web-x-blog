## ARC-606：实时协作列表
**答**:
- 场景：共享购物清单/团队待办——多人增删改排的并发一致性（ARC-379 协作架构在列表形态的应用）。
- 数据模型：列表项为 CRDT 元素（Yjs Array——并发插入自动排序、删除标记）或服务端仲裁 op 序列（轻量场景）；项内容冲突（两人改同一项文本）——按字段合并或 LWW 提示。
- 交互细节：他人正在编辑提示（软锁：输入中的项标"某人编辑中"——防覆盖感 ARC-379 presence）、删除被正在编辑项（编辑者收到"该项已被删除"）、拖拽排序并发（ARC-530 序号冲突处理）。
- 通知与同步：变更推送（增删改 op 实时推）+ 列表级摘要（"张三添加了 3 项"——高频操作聚合通知防轰炸 ARC-394 合并）。
- 离线协作：离线增删改 → 重连合并（CRDT 自动合并；OT/仲裁型需要冲突提示）——列表场景 CRDT 收益明显。
- 性能：万项清单虚拟化 + CRDT（虚拟化与 CRDT 索引协同——按文档位置虚拟窗口）。
```javascript
// CRDT 列表协作
const list = ydoc.getArray('items');
list.observe(() => render(list.toArray()));                      // 远端变更自动合并渲染
function addItem(text) { list.push([{ id: nanoid(), text, done: false }]); }
presence.onEdit(itemId, () => ui.markEditing(itemId, peer));     // 软锁提示
```
