## ARC-230：前端权限缓存策略：快照存哪、有效期多久？
**答**：
- 位置选择：**内存（全局 store）为主**——登录会话内有效；sessionStorage 用于刷新页面免等待；**绝不写 localStorage**（换账号/过期风险，权限是敏感数据）。
- 有效期策略：短 TTL（5~15 分钟）+ 版本号校验双保险；TTL 到期后台静默刷新，用户无感；任何一次 403/PERM_STALE 立即强刷。
- 与登录态绑定：快照 key 带上会话 ID，登出/切换账号立即作废；token 刷新成功后顺带刷新快照（一次往返两件事）。
- 多标签页：BroadcastChannel 同步权限版本变更，避免一个标签页改角色另一个还在旧权限。

```typescript
const bc = new BroadcastChannel('perm-sync');
bc.onmessage = ({ data }) => data.version > localVersion && refreshSnapshot(data.version);
async function refreshSnapshot(v?: number) {
  const snap = await api.get('/me/perm-snapshot');
  store.set('perm', { snap, version: snap.version, ts: Date.now() });
  sessionStorage.setItem(`perm:${sessionId()}`, JSON.stringify(store.get('perm')));
  bc.postMessage({ version: snap.version });       // 广播给其他标签页
}
// TTL 检查：setInterval(15min) 里 isStale() ? refreshSnapshot() : null；403 时 clearTimeout 后立即强刷
```
