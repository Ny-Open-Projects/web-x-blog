## ARC-454：数据可视化平台的架构分层
**答**:
- 分层：渲染引擎（ECharts/AntV/自研 WebGL）→ 图表组件层（统一 props 协议：数据/配置/交互事件）→ 组合层（仪表盘布局、联动、下钻）→ 平台层（图表注册、权限、导出、分享）。
- 统一协议设计：平台层不直接依赖具体图表库——图表以"适配器"注册（render(container, spec)），spec 是库无关的描述（类型/编码/交互），换图表库只换适配器。
- 大数据量策略：降采样（LTTB 保留视觉特征）、聚合下推（服务端按桶聚合）、增量渲染（数据更新只重绘变化系列）、WebGL 路线（百万点散点图）。
- 交互协议：联动（高亮同一维度）、刷选过滤（brush → filter store）、下钻（维度层级定义）；交互事件统一 emit，由组合层编排。
- 性能与可用性：仪表盘图表懒渲染（进入视口才建实例）、销毁回收；无障碍（数据表替代视图）与导出（服务端渲染 PNG）标配。
```javascript
// 图表适配器协议
const registry = new Map();
function registerChart(type, adapter) { registry.set(type, adapter); }
function renderChart(container, spec) {
  const a = registry.get(spec.type);
  if (!a) throw new Error(`未注册图表类型: ${spec.type}`);
  return a.render(container, spec.data, spec.encoding, spec.interaction);  // 库无关
}
registerChart('line', echartsAdapter);   // 换 AntV 只改这一行
```
