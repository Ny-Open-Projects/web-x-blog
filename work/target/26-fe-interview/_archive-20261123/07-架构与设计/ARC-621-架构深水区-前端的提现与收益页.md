## ARC-621：提现与收益页
**答**:
- 资金展示：余额/可提现/冻结分列（口径来源服务端——前端不推算 ARC-460）、明细流水（可对账的自证路径）、金额精度组件统一（ARC-582 Price）。
- 提现流程：额度校验（服务端限额 NODE-457）、收款账户确认（改绑冷静期提示——安全协议展示）、提现确认（二次确认 + 验证码 ARC-454）、结果三态（成功/失败/处理中——处理中可查询进度页轮询）。
- 状态机与刷新：提现状态机（申请→处理→到账/失败）——状态推送（WS/轮询 ARC-416）+ 到账通知（ARC-394）；失败原因可懂化（渠道错误转译——余额不足/限额/账户异常）。
- 安全配合：页面水印（ARC-346）、敏感字段脱敏（卡号/手机号掩码 ARC-570）、防截屏引导（可选）。
- 多币种/多账户：账户切换（余额隔离——切换重置 ARC-559）、币种精度（ARC-569）。
```javascript
// 提现状态机轮询
async function withdraw(amountCents, accountId) {
  const r = await api.withdraw({ amountCents, accountId }, { idempotencyKey: genKey() });
  if (r.state === 'processing') await poll(r.withdrawId, { interval: 3000, until: s => s.done });
  else if (r.state === 'rejected') showReason(r.reason);          // 渠道错误转译文案
  notify.onDone(r.withdrawId, () => balanceStore.refresh());      // 到账推送刷新余额
}
```
