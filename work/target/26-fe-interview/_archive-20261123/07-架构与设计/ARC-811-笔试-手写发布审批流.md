## ARC-811：手写发布审批流

**题目**：实现发布审批流引擎 `ReleaseFlow`：① 发布申请：{ appId, version, changeLog, riskLevel(low/mid/high), evidence(CI 链接/回归报告) }；② 审批路由按风险分级：low → 自动通过（CI 全绿即放行）、mid → TL 审批、high → TL+架构师双签；③ 审批状态机：draft → pending → approved/rejected → published/rolledBack——每步审计（谁/何时/意见）；④ 超时自动处理：pending 超 48h → 提醒 + 升级到上级；⑤ 冻结期拦截：发布时间在冻结窗口 → 拒绝（特批通道走 override + 理由）。写出实现。

```javascript
class ReleaseFlow {
  #approvals = new Map(); #frozen = [];
  #route(risk) {
    return risk === 'low' ? [] : risk === 'mid' ? ['tl'] : ['tl', 'architect'];
  }
  submit(request) {
    const now = Date.now();
    if (this.#frozen.some(([s, e]) => now >= s && now <= e))
      if (!request.override?.reason) throw new Error('冻结期发布需特批理由');
    const approvers = this.#route(request.riskLevel);
    const flow = { ...request, id: crypto.randomUUID(),
      status: approvers.length === 0 ? 'approved' : 'pending',
      audits: [{ op: 'submit', by: request.submitter, t: now }],
      approvals: approvers.map((role) => ({ role, done: false })),
    };
    if (flow.status === 'approved') this.#audit(flow, 'auto-approve (low risk)');
    this.#approvals.set(flow.id, flow);
    return flow;
  }
  approve(id, role, opinion, operator) {
    const flow = this.#approvals.get(id);
    const step = flow.approvals.find((a) => a.role === role && !a.done);
    if (!step) throw new Error(`no pending approval for ${role}`);
    step.done = true; step.opinion = opinion; step.by = operator; step.t = Date.now();
    if (flow.approvals.every((a) => a.done)) {
      flow.status = 'approved';
      this.#audit(flow, 'approved');
    }
    return flow;
  }
  #audit(flow, op) { flow.audits.push({ op, t: Date.now() }); }
  checkTimeout() {
    for (const flow of this.#approvals.values())
      if (flow.status === 'pending' && Date.now() - flow.audits[0].t > 48 * 3600e3)
        escalate(flow);                                    // 升级提醒
  }
}
```

**评分点**：
- 风险分级的审批路由（low 自动通过/mid 单签/high 双签）
- 状态机审计完整（每步谁/何时/意见）
- 冻结期拦截 + 特批通道（override 带理由）
- pending 超时升级机制
