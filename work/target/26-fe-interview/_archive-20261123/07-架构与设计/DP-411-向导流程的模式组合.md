## DP-411：向导流程组合

**答**：
- 向导的模式全景：状态机（步骤流转 + 校验门禁——guard 拦截下一步）、备忘录（每步快照——回退不丢数据）、命令（步骤提交可撤销）、策略（步骤跳过策略：可选步骤按条件跳过）
- 步骤门禁：guard（当前步校验通过才允许 next——状态机的 guard 拦截非法前进）
- 动态步骤：步骤列表按条件增减（企业用户多一步认证——步骤链动态构建）
- 跨步数据：步骤间共享数据（context 贯穿——后步依赖前步结果）
- 深水点：向导的「中断恢复」——用户中途离开（进度+数据持久化——回来从步骤 3 继续）——状态机持久化 + 备忘录组合

```javascript
const wizard = createMachine({
  steps: [
    { id: 'basic', guard: basicValid },
    { id: 'auth', skipWhen: (ctx) => !ctx.isEnterprise },   // 动态跳过
    { id: 'pay', guard: payReady },
  ], initial: 'basic',
});
// 中断恢复: save({ step: 'pay', ctx }) → 回来 restore → 从 pay 继续
```
