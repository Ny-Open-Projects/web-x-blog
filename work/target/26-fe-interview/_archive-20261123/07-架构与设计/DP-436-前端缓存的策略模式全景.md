## DP-436：缓存策略全景

**答**：
- 缓存策略家族：cache-first（静态资源）、network-first（用户数据——新鲜优先）、stale-while-revalidate（列表——快+新）、network-only（支付——不缓存）——按数据性质选策略
- 策略的实现统一：每策略实现 `get(key, fetcher)` 同接口——策略模式的可插拔（同一缓存层换策略）
- 策略与 TTL 的组合：策略决定「读路径」TTL 决定「存活期」——两个正交维度
- 缓存策略的声明位置：SW（路由级策略）、请求层（接口级策略）、组件层（数据级）——声明位置与失效面匹配
- 深水点：策略的「数据性质推导」——配置类→cache-first、列表→SWR、个人数据→network-first——策略是「数据性质」的映射

```javascript
const STRATEGIES = {
  'cache-first': async (key, fetcher, cache) => (await cache.get(key)) ?? put(fetcher(key)),
  'swr': async (key, fetcher, cache) => {
    const cached = await cache.get(key);
    if (cached) { fetcher(key).then((v) => cache.put(key, v)); return cached; }
    return put(fetcher(key));
  },
  'network-first': async (key, fetcher, cache) => {
    try { const v = await fetcher(key); cache.put(key, v); return v; }
    catch { return cache.get(key); }
  },
};
// 按数据性质选: config→cache-first / feed→swr / me→network-first
```
