## ARC-605：文件选择与上传预检
**答**:
- 预检层次：选择期（accept 过滤 + 文件选择器定制）、即检期（选择后立即校验：类型魔数（非扩展名 ARC-339）、大小、数量上限、配额余量——秒级反馈不等上传后失败）、上传期（服务端最终裁决——前端预检只是体验）。
- 预检策略配置化：场景声明（头像：单图 5MB jpg/png；素材：百文件单 500MB 总 5GB——每场景一个预检配置），预检器按配置执行（可复用组件 UploadPicker 统一）。
- 失败体验：逐文件失败原因（文件名 + 原因列表——部分成功部分失败时明确哪些过了哪些没过）、超配额引导（剩余空间不足 → 清理入口/升级引导）、重选优化（失败文件保留选择框可直接重选补传）。
- 图片专项：尺寸校验（最小分辨率——低质图预检拒绝）、EXIF 处理（方向修正/隐私剥离 ARC-341）、压缩预处理（超尺寸前端压缩后传——节省带宽用户无感）。
- 移动端差异：相册多选限制/文件系统访问差异（iOS Files 集成）——预检配置含端差异表。
```javascript
// 预检配置与执行
const precheck = definePrecheck({
  maxFiles: 100, maxSize: 500e6, totalSize: 5e9, quota: userQuota(),
  accept: { mime: ['image/jpeg', 'image/png'], magic: true }     // 魔数校验
});
const { ok, failed } = precheck.run(files);                      // 秒级反馈
// 失败列表：[{name: 'a.exe', reason: '类型不支持'}, ...]
```
