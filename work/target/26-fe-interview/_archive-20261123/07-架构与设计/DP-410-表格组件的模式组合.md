## DP-410：表格组件模式组合

**答**：
- 表格的模式全景：策略（列渲染策略：render 函数/默认文本）、观察者（排序/筛选变更 → 数据重查）、命令（操作：编辑/删除/批量——可撤销批量操作）、组合模式（表头分组：多级表头的树）、享元（行组件复用——大数据量）
- 功能的模式归属：排序（策略：客户端排序/服务端排序的切换）、列固定（布局策略）、行选择（状态：selected Set + 批量命令）、展开行（组合模式：子表格递归）
- API 设计的组合：columns 定义即「策略注册表」（每列的 render/sorter/filters）——列配置数据化
- 深水点：表格的「大数据分治」——虚拟滚动（享元）+ 服务端分页（策略）+ 增量更新（观察者推送 delta）——三者组合才是万级数据方案

```javascript
// 列定义 = 策略注册表
const columns = [
  { key: 'name', title: '名称' },                     // 默认渲染
  { key: 'status', render: (r) => <Badge t={r.status} /> },   // 策略: 定制渲染
  { key: 'amount', sorter: (a, b) => a.amount - b.amount },   // 策略: 排序
  { key: 'ops', fixed: 'right', render: (r) => rowOps(r) },
];
// 虚拟滚动 + 服务端分页 + ws 增量推送 (库存数变化)
```
