## DP-424：微前端通信组合

**答**：
- 微前端通信的模式菜单：观察者（事件总线——基座广播）、外观（基座暴露门面 API——受控能力）、备忘录（共享内存快照）、中介者（基座作为协调中枢——子应用互不认识）
- 选型矩阵：状态共享（store 桥——观察者+备忘录）、事件通知（总线——观察者）、能力调用（门面——基座 API）、路由协调（中介者——基座路由分发）
- 反模式：子应用直接 import 彼此（强耦合——基座总线才是正解）、全局 window 变量通信（命名冲突+无类型）
- 深水点：通信的「契约治理」——消息 schema 注册（类型化消息——防拼错）+ 版本兼容（基座升级子应用不受惊吓）

```javascript
// 基座门面 (受控 API)
class ShellFacade {
  constructor(bus, store) { this.bus = bus; this.store = store; }
  getUser() { return this.store.user; }              // 读: 状态桥
  navigate(to) { this.bus.emit('navigate', { to }); }// 路由: 中介者
  notify(level, msg) { /* 基座统一 toast */ }
}
// 子应用只拿 facade — 不认识其他子应用 (星型解耦)
```
