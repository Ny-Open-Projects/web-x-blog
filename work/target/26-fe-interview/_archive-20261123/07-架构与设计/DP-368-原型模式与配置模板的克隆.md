## DP-368：原型模式：克隆变体

**答**：
- 原型核心：通过克隆已有对象创建新对象（而不是从类构造）——前端形态：配置模板克隆（表格列配置克隆后微调）、预置状态克隆
- 与 deepClone 的关系：原型模式是「设计意图」（克隆+微调=变体），deepClone 是「实现手段」——structuredClone / immer 的 produce 都是原型式创建
- immer 正是原型模式的现代形态：draft（原型克隆）→ mutate → 生成变体（原对象不动）——「以克隆为基础的变更」
- 实战要点：克隆的成本意识（大对象克隆贵——按需浅克隆+引用共享不可变数据）；克隆的「模板注册表」（preset 池）
- 深水点：克隆的「共享陷阱」——浅克隆后修改嵌套属性污染原模板（模板被第一个使用者改坏——后续全错）——必须深克隆或 COW

```javascript
const presets = new Map([
  ['basic', { columns: [{ key: 'name' }], pageSize: 20, sticky: false }],
  ['rich', { columns: [{ key: 'name' }, { key: 'ops' }], pageSize: 50, sticky: true }],
]);
function createTable(kind, overrides) {
  const base = structuredClone(presets.get(kind));   // 深克隆防污染
  return deepMerge(base, overrides);                  // 克隆 + 微调 = 变体
}
// immer 版: produce(presets.get('basic'), (d) => { d.pageSize = 30 })
```
