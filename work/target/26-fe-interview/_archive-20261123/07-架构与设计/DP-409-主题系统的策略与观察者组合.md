## DP-409：主题系统组合

**答**：
- 主题的模式全景：策略（主题集切换：light/dark/品牌主题——token 集是策略）、观察者（主题变更广播 → 图表/第三方组件重绘）、备忘录（用户主题选择持久化）、适配器（第三方组件库的主题变量映射——Element 变量 → 自家 token）
- 实现的最佳解：CSS 变量 + data-theme（CSS 层解决 90%）——框架层只管「切换属性 + 持久化」——观察者只服务「CSS 解决不了的」（图表重绘）
- 图表的暗色适配：ECharts 主题从 token 生成（策略——token → 主题对象映射）
- 深水点：主题切换的「闪烁防治」——首帧前设置主题（内联脚本）+ 切换时禁 transition（双 rAF 恢复）——观察者通知的时序设计

```javascript
// 主题策略: token → 图表主题
const chartTheme = (tokens) => ({
  color: tokens.chartPalette,
  backgroundColor: tokens.bg,
});
```
