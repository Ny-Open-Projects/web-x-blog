## ARC-580：多端表单一致性架构
**答**:
- 一致性层次：校验逻辑一致（同一 schema 三端执行 ARC-448 共享校验——规则永不漂移）、交互模式适配（键盘 vs 触屏：Web 键盘提交/小程序触屏分步/App 原生键盘——校验统一交互适配）、文案一致（错误提示同源 i18n）。
- 架构方案：表单 schema 单源（字段/校验/联动声明）→ 各端渲染适配器（Web 用 JSON Schema Form/小程序自定义引擎/App 原生表单桥接）——渲染差异允许，行为差异禁止。
- 端差异显式管理：端能力差异表（哪些校验在端上做不了：小程序无 file API 限制上传）、降级路径（能力缺失的替代交互）。
- 一致性验证：跨端表单回归（同 schema 三端跑断言校验结果一致——自动化跨端测试矩阵）。
- 收敛治理：新表单必须走 schema 引擎（脚手架默认 + code review 卡点——散写表单是漂移起点）、端特有逻辑显式标记（platform 分支白名单化）。
```javascript
// 跨端 schema 单源
export const AddressFormSchema = {                               // Web/MP/App 共用
  fields: [{ name: 'phone', validate: phoneCN, required: true },
           { name: 'region', type: 'cascader', source: 'region-tree' }]
};
// Web 渲染器 / 小程序引擎 / App 桥接 各自消费同一 schema——校验结果跨端一致
```
