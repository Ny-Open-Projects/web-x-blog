## DP-466：语言切换竞态

**答**：
- 语言切换的竞态场景：快速连续切换语言（en→zh→ja）——异步加载语言包（旧包后到覆盖新语言）——竞态守卫
- 处理方案：seq 令牌（最后一次切换的 locale 才生效）+ 加载中状态（切换按钮 pending——防连点）
- 切换的原子性：语言包加载 + locale 设置 + 持久化三步原子化（部分完成 = 混合语言页面）——事务语义
- 深水点：切换的「回退策略」——新语言包加载失败 → 保持旧语言（不白屏）+ 告知用户（「切换失败请重试」）——失败不污染当前态

```javascript
let seq = 0;
async function setLocale(l) {
  const my = ++seq;
  setPending(l);
  try {
    const pack = await loadPack(l);
    if (my !== seq) return;                          // 旧切换丢弃
    i18n.setMessages(l, pack); i18n.locale = l;      // 原子: 包+locale 同步
    localStorage.set('locale', l);
  } catch { setPending(null); toast('切换失败'); }   // 失败保持旧语言
}
```
