## ARC-308：低代码平台的开放能力：第三方物料接入？
**答**：
- 生态开放 = 物料市场允许第三方团队发布物料，但必须守住三道关：协议符合（物料描述协议校验 ARC-294）、质量门禁（构建/测试/快照 CI）、安全扫描（ARC-304 行为分析）。
- 物料运行隔离：第三方物料与官方物料同页渲染，隔离手段——依赖强制 externals（不得自带 react 等框架单例）、样式 scope 强制、API 面受限（只能用平台注入的 context，不能摸 window）。
- 兼容承诺：平台 API 升级给 deprecation 周期，第三方物料版本矩阵测试（平台维护主流第三方物料的回归集）。
- 激励与治理：物料评分/使用量排行（生态繁荣指标）；违规物料一键下架机制（安全事件响应）。

```typescript
// 第三方物料上架门禁
async function review(pkg) {
  const meta = validateProtocol(pkg.metadata);          // 1) 协议校验
  const deps = analyzeDependencies(pkg);                // 2) externals 强制
  if (deps.bundled.includes('react')) throw new Error('框架依赖必须 external，禁止自带单例');
  const scan = await behaviorScan(pkg);                 // 3) 静态+动态：域名白名单、危险 API
  if (scan.risky) throw new Error(`安全扫描未通过：${scan.reasons}`);
  return publish({ ...pkg, meta, scanId: scan.id });
}
// 运行时注入：thirdParty.Comp 由平台包装 <ScopeProvider api={limitedContext}>，拿不到 window
```
