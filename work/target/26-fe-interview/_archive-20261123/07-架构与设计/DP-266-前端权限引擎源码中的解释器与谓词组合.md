## DP-266：源码识别：前端权限引擎源码中的谓词与解释器？
**答**:
- 解释器：权限规则表达式（"role:admin OR dept:finance AND NOT region:south"）解析成谓词树，can(user) 解释执行——CASL 的 ability 定义就是这种 DSL。
- 组合模式：规则由简单谓词组合成复合谓词（and/or/not），统一 test() 接口。
- 策略：条件注入（字段级/数据级条件 as function）让"同一权限码"在不同上下文结果不同。
- 识别要点：能写出 mini 谓词组合器（and/or/not）并解释"权限引擎是纯函数核心 + 缓存（快照版本）"。

```typescript
// 权限谓词引擎（源码级简化）
type Predicate = (ctx: PermCtx) => boolean;
const and = (...ps: Predicate[]): Predicate => c => ps.every(p => p(c));
const or = (...ps: Predicate[]): Predicate => c => ps.some(p => p(c));
const not = (p: Predicate): Predicate => c => !p(c);
const has = (perm: string): Predicate => c => c.perms.includes(perm);
const fieldIn = (field: string, values: string[]): Predicate => c => values.includes(c.data[field]);
// 组合成规则：
const canAuditOrder = or(has('order:audit'), and(has('order:read'), fieldIn('dept', ['finance'])));
function can(ctx: PermCtx, rule: Predicate) {
  return rule(ctx);                            // 解释执行（纯函数，可缓存 per 快照版本）
}
const cache = new Map<string, boolean>();      // memo：ctx.version + ruleId → 结果
```
