## DP-417：无限滚动组合

**答**：
- 无限滚动的模式全景：策略（加载触发策略：滚动阈值/IO observer/按钮）、命令（加载更多——幂等键防重）、观察者（新数据到达 → 渲染）、享元（DOM 复用——真虚拟列表）、备忘录（滚动位置保存——返回恢复）
- 触发策略选择：IO observer（rootMargin 预加载——现代首选）vs scroll 阈值（可控性强）——策略按场景
- 数据增长的管理：窗口化（保留最近 N 屏——DOM 上限）vs 全保留（搜索场景需要回看）——数据保留策略
- 深水点：无限滚动的「URL 状态」——滚到第 5 页分享/刷新后恢复（页码 + 锚点恢复——备忘录与 URL 的组合）

```javascript
// IO 触发 + 去重 + 窗口化
const io = new IntersectionObserver((es) => {
  if (es[0].isIntersecting && !loading && !done) loadMore();
}, { rootMargin: '400px' });
io.observe(sentinel);
// loadMore: 幂等 (page 键) + 满屏裁剪 (keepLast 30 screens)
```
