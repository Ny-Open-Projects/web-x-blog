## ARC-698：变更广播与兼容窗口

**答**：
- 变更分类分级：L1 破坏性（API 删除/行为变化——全通知+迁移支持）、L2 语义变化（默认值变化——定向通知）、L3 新增能力（增量——发布说明）——分级决定通知强度
- 广播通道矩阵：邮件（正式记录）+ 飞书群（即时触达）+ 变更日志页（持久可查）——多通道冗余（单一通道必漏）
- 兼容窗口的执行：旧 API 保留 2 个版本周期 + 运行时警告（dev 模式提示迁移）——警告让迁移可被「发现」
- 迁移支持包：codemod + 迁移文档 + 答疑值班——「迁移支持到位」是硬截止的道德前提
- 深水点：变更的「漏接兜底」——运行时警告不只 console（进监控上报未迁移使用量）——未迁移使用量是硬截止的决策依据

```text
变更广播:
  分级: L1 破坏性 / L2 语义 / L3 增量
  通道: 邮件+群+变更日志 (冗余)
  兼容: 旧 API 保 2 版 + dev 警告
  支持: codemod + 文档 + 值班
  兜底: 未迁移使用量进监控 (硬截止依据)
```
