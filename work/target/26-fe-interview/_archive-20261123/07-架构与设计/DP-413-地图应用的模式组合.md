## DP-413：地图应用组合

**答**：
- 地图的模式全景：策略（标记渲染策略：聚合/单点——按缩放级别）、观察者（地图事件订阅：moveend/zoom）、享元（标记对象池——海量 marker 复用）、组合模式（图层树：底图/覆盖物/热力图层叠）、命令（地图操作：缩放/平移——可撤销）
- 标记聚合策略：缩放级别决定聚合粒度（zoom 10 聚合 500 点为 5 簇——策略按 zoom 切换）——聚合是海量标记的必须
- 图层的观察者：图层显隐 → 地图重绘（观察者驱动）+ 图层间依赖（热力图依赖点位图层）
- 深水点：地图的「事件节流」——moveend（拖动结束才查询视口内数据——非 move 每帧）——事件选择的性能语义

```javascript
map.on('zoomend', () => renderMarkers(clusterBy(zoomLevel)));    // 策略: zoom 驱动聚合
// marker 池: getMarker(icon) — 享元复用 DOM/实例
// 图层: layerGroup.add(heatmapLayer).add(markerLayer) — 组合模式
```
