## ARC-644：价格计算展示
**答**:
- 红线：到手价/优惠分解服务端计算（促销规则复杂：跨店满减/券/会员价叠加顺序——前端永远不自己算 ARC-582）。
- 明细协议：价格构成树（商品价 → 促销优惠（逐项列名与金额）→ 券优惠 → 运费 → 应付——层级化 breakdown 服务端下发，前端只渲染）、优惠项 id 化（每项可展开解释：命中哪条规则——透明化减少纠纷）。
- 交互联动：改数量/换券 → 重算（结算预检 ARC-599——重算期间价格区 loading 防旧值误导）、凑单（差 X 元享满减——凑单推荐入口 ARC-600）。
- 一致性：列表页"到手价"与结算页一致（同接口同缓存键 ARC-386；活动价格切换时点——价格变更事件广播刷新）。
- 边界：价格小数与分摊（跨店满减按比例分摊到商品——服务端分摊结果，前端展示分摊明细）、价格保护的展示（价保标识——一键申请价保入口）。
```javascript
// 价格构成树
const breakdown = await api.priceBreakdown({ items, coupons });   // 服务端算
<PriceTree nodes={breakdown} />                                   // {label:'商品价',v:...},{label:'跨店满减',v:-20,ruleId:...}
// 每项可展开：ruleId → 规则说明（透明化）
```
