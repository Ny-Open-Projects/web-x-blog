## ARC-733：样式迁移

**答**：
- 典型迁移：less/sass → 原生 CSS 变量+层级、CSS Modules → 原子化、全局样式 → scoped——样式迁移的「视觉等价」验证最难
- token 先行策略：先抽设计 token（颜色/间距→CSS 变量）——样式方案怎么换 token 层不动（视觉不漂移的锚点）
- 渐进的「页面级切换」：逐页迁移新样式体系（新旧共存——变量层做桥）——样式共存期的优先级冲突要显式化（@layer）
- 视觉回归护栏：迁移前截图基线——「像素级 diff」是样式迁移唯一可靠的验收
- 深水点：样式迁移的「死样式清理」——迁移后的老样式文件删除（死样式是维护噪音）——coverage 工具找死样式

```text
样式迁移:
  token 先行: 变量层不动 (视觉锚点)
  页面级切换: 新旧共存 + @layer 显式
  验收: 视觉回归截图基线 (像素 diff)
  清理: 死样式删除 (coverage 工具)
```
