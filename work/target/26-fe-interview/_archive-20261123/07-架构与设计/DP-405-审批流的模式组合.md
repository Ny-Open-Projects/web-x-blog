## DP-405：审批流模式组合

**答**：
- 审批流模式全景：状态机（单据状态：draft→submitting→approving→approved/rejected）、责任链（审批链：主管→部门→财务——逐级审批或会签）、策略（审批条件策略：金额阈值决定审批级数）、备忘录（每步快照——回退审计）、命令（同意/驳回/转交都是命令对象）
- 动态审批链：责任链的构建由配置驱动（金额 >5 万加财务节点——链的组装是策略）
- 会签与或签：责任链的两种推进语义（会签=全部同意才过/或签=任一同意）——链节点的「聚合语义」参数化
- 审批 UI 的状态驱动：当前节点可做什么（同意/驳回/转交按钮）由状态机回答——按钮渲染自动化
- 深水点：审批流的「乐观更新 + 版本仲裁」——审批人在移动端批了 PC 端也批了（并发冲突——409 刷新）

```javascript
// 动态审批链
function buildChain(amount) {
  const chain = [supervisor];
  if (amount > 50000) chain.push(dept);
  if (amount > 500000) chain.push(finance);
  return chain;                                       // 策略构建链
}
// 会签: all(nodes.map(n => n.approve())) / 或签: any(...)
// 状态机驱动按钮: can('approve') && renderButton()
```
