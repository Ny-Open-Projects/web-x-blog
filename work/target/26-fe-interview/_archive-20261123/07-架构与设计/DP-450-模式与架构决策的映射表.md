## DP-450：模式→架构映射表

**答**：
- 架构问题的模式映射：状态共享 → 观察者+备忘录（store）、复杂流程 → 状态机+命令、第三方差异 → 适配器+外观、性能隔离 → 代理+享元、可扩展 → 插件+责任链、错误治理 → 边界+空对象——「架构问题 → 模式组合」的查表能力
- 映射表的使用：架构设计时按「问题清单」查表选模式组合——设计评审时按「模式使用」反查问题覆盖
- 映射表的演进：新模式（信号/编译优化）进表——映射表是活文档
- 深水点：映射表的「组合克制」——一个架构问题通常 2~3 个模式足够（组合爆炸是过度设计）——模式数量与问题复杂度匹配

```text
架构问题 → 模式组合:
  状态共享     → 观察者 + 备忘录 (store)
  复杂流程     → 状态机 + 命令 (撤销/审计)
  第三方差异   → 适配器 + 外观 (SDK 统一)
  性能隔离     → 代理 + 享元 (缓存/池)
  可扩展性     → 插件 + 责任链 (hook 管道)
  错误治理     → 边界 + 空对象 + 重试
  高频事件     → 批处理 + 限流 (合帧/防抖)
每问题 2~3 模式 — 组合克制
```
