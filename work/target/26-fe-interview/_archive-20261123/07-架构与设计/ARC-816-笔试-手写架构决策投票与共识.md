## ARC-816：手写决策共识流程

**题目**：实现架构决策的共识流程工具 `DecisionFlow`：① RFC 流程状态机：draft → review(评论期, 48h) → vote(相关方投票) → accepted/rejected → superseded；② 投票规则：相关方（受影响团队）各一票 + 架构师一票（权重 2）——反对票必须附理由；③ 挑战机制：rejected 决策可在 1 周内被 challenge（补充数据后重开 review）；④ 决策记录自动生成：投票详情/理由/反对意见 → ADR 草稿；⑤ 时限管理：review 期结束自动进入 vote（无评论也算——防止无限搁置）。写出实现。

```javascript
class DecisionFlow {
  #flows = new Map();
  create({ title, proposal, stakeholders }) {
    const flow = {
      id: crypto.randomUUID(), title, proposal,
      stakeholders,                     // [{ team, rep }] 受影响团队
      status: 'review', reviews: [], votes: [],
      reviewEndsAt: Date.now() + 48 * 3600e3,
      audit: [{ op: 'create', t: Date.now() }],
    };
    this.#flows.set(flow.id, flow);
    return flow;
  }
  comment(id, { team, comment }) {
    const f = this.#flows.get(id);
    if (f.status !== 'review') throw new Error('只能在 review 期评论');
    f.reviews.push({ team, comment, t: Date.now() });
  }
  async tickCheck() {                                  // 定时: review 到期自动进 vote
    for (const f of this.#flows.values())
      if (f.status === 'review' && Date.now() >= f.reviewEndsAt) {
        f.status = 'vote';
        f.audit.push({ op: 'auto-move-to-vote', t: Date.now() });
      }
  }
  vote(id, team, approve, reason) {
    const f = this.#flows.get(id);
    if (f.status !== 'vote') throw new Error('not in vote phase');
    if (!f.stakeholders.some((s) => s.team === team) && team !== 'arch')
      throw new Error(`${team} 不是相关方`);
    if (!approve && (!reason || reason.length < 10))
      throw new Error('反对票必须附理由 (≥10字)');
    const weight = team === 'arch' ? 2 : 1;
    f.votes.push({ team, approve, reason, weight });
    const yes = f.votes.filter((v) => v.approve).reduce((s, v) => s + v.weight, 0);
    const no = f.votes.filter((v) => !v.approve).reduce((s, v) => s + v.weight, 0);
    if (f.votes.length >= f.stakeholders.length + 1) {
      f.status = yes > no ? 'accepted' : 'rejected';
      f.audit.push({ op: `vote-result: ${yes} vs ${no}`, t: Date.now() });
    }
    return f;
  }
  challenge(id, newEvidence) {
    const f = this.#flows.get(id);
    if (f.status !== 'rejected') throw new Error('仅 rejected 可挑战');
    if (Date.now() - f.audit.at(-1).t > 7 * 86400e3) throw new Error('挑战窗口已过');
    f.status = 'review';
    f.reviews.push({ team: 'challenger', comment: newEvidence, t: Date.now() });
  }
  toADR(id) { /* accepted/rejected → ADR 草稿生成 */ }
}
```

**评分点**：
- RFC 状态机完整（含 challenge 通道与窗口）
- 加权投票（架构师权重 2）+ 反对必附理由
- 时限自动化（review 到期自动进 vote——防搁置）
- 决策到 ADR 的自动生成
