## DP-385：限流模式组合

**答**：
- 三种限流的语义：防抖（等停——搜索输入）、节流（限频——滚动）、背压（生产阻塞——消费不过来暂停生产）——按「事件形态」选
- 组合实战：滚动加载 = 节流（事件）+ 队列（请求并发上限）+ 标记去重（同页不重复请求）——三种模式协同
- 背压的前端形态：流式消费（ReadableStream 的 pull 模式天然背压——消费慢上游自动暂停）；上传队列（并发上限即是背压）
- 实战要点：防抖的 maxWait（防永远不打字）、节流的 trailing（防丢最后一次）、队列的优先级（用户操作 > 后台任务）
- 深水点：限流「位置」的选择——限在源头（事件层）还是消费端（请求层）——源头发限流 UX 立即生效；消费端限流保护后端

```javascript
// 滚动加载三合一
const onScroll = throttle((e) => {                   // 限频
  if (this._loading) return;                          // 背压: 在途挂起
  if (this._loadedPages.has(this._nextPage)) return;  // 去重
  this._loading = true;
  api.list(this._nextPage).finally(() => { this._loading = false; });
}, 200);
// 搜索: debounce(300) + in-flight 合并 + abort 旧请求
```
