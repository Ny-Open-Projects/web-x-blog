## DP-419：分步表单组合

**答**：
- 分步表单的模式：策略（每步校验策略独立）、状态机（步骤流转 + guard）、备忘录（各步数据快照）、命令（上一步/下一步）
- 校验的时机策略：步内即时校验（blur）vs 步间校验（next 时统一校验本步）——UX 与实现复杂度的平衡
- 数据的生命周期：步数据暂存（本步 state）→ 完成并入全局（final submit 才发服务端）vs 每步即存服务端（草稿）——两种持久化策略
- 深水点：动态步骤的「guard 跳转」——跳过步骤后 next 的目标计算（状态机的动态 target——函数式 target）

```javascript
const steps = [
  { id: 'basic', validate: basicRules, next: (ctx) => ctx.type === 'enterprise' ? 'auth' : 'pay' },   // 动态 target
  { id: 'auth', validate: authRules, skipWhen: (ctx) => ctx.type !== 'enterprise' },
  { id: 'pay', validate: payRules },
];
// next(): guard(当前步校验) → 动态 target → 跳过 skipWhen 的步骤
```
