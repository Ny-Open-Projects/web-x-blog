## ARC-477：前端团队 oncall 值班体系
**答**:
- 值班范围定义：前端 oncall 处理用户可见故障（白屏/错误激增/性能劣化/发布事故），后端域问题转派；转派协议明确（哪个告警归谁、转派时限）。
- 值班工具箱：值班看板（当前告警/健康分/进行中发布）、Runbook（每类告警的处理步骤链接 ARC-353）、权限预授权（值班期间可执行回滚/开关的审批豁免）。
- 响应 SLA：P0 告警 5 分钟响应、30 分钟内定性（恢复/转派/升级）；处理分级——先止血（回滚/开关）后根治（修复发布）。
- 交接与复盘：值班日志模板（处理了什么/遗留什么）；每周值班例会回看告警质量；值班发现的高频问题转基建改进项（降低未来值班负担）。
- 健康度：值班负荷度量（周均告警数/夜间告警数），超标说明可观测性或稳定性欠账，优先还债而不是加人。
```javascript
// 值班处理 SOP（伪流程）
const oncallSop = {
  onAlert: ['确认影响面（看板）', '5min 内响应', '止血优先：rollback / flagOff / degrade'],
  escalate: ['30min 未定性 → 升级 TL', '涉资/涉隐私 → 安全联动'],
  close: ['值班日志', '复盘链接（P0/P1 必做）', '改进项录入基建 backlog']
};
```
