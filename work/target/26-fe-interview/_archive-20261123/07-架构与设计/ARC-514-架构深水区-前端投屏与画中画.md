## ARC-514：投屏/画中画/跨设备播放
**答**:
- 画中画（PiP）：documentPictureInPicture（窗口级，可放自定义 DOM）与 video PiP（原生）；PiP 内控件事件回传主窗口（消息通道）；PiP 时主页面休眠策略（省电但保持状态同步）。
- 投屏路线：浏览器原生（Cast API/AirPlay 协议探测）与 App 桥（JSBridge 调原生投屏 ARC-112）；投屏时本地播放暂停、进度由投屏端回报（状态回传协议）。
- 跨设备续播：登录态统一（ARC-415）+ 进度快照（ARC-511）+ 设备能力协商（目标设备支持码率/格式降级选择源）。
- 状态一致性：多播放端同时存在的策略（抢占：新端播放旧端暂停，带提示）——服务端播放会话锁。
- 探测与降级：能力探测矩阵（PiP/投屏/DRM）收口在能力层，不支持时隐藏入口而非报错。
```javascript
// 画中画 + 事件回传
const pipWin = await documentPictureInPicture.requestWindow({ width: 320, height: 180 });
pipWin.document.body.append(playerEl);                          // DOM 迁移进 PiP
pipWin.addEventListener('pagehide', () => mainBody.append(playerEl)); // 关闭回归
// 投屏状态回传：bridge.on('cast:progress', ({ position }) => syncUI(position))
// 抢占：api.acquirePlayback(videoId) 返回 occupied 时提示"已在手机上播放，是否接管"
```
