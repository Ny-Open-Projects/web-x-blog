## DP-473：登录页安全

**答**：
- 登录页的模式组合：策略（防爆破：前端倒计时锁定+验证码升级）、状态机（登录态流转）、代理（凭证的内存管理——不落 storage）、观察者（多端会话失效广播）
- 密码的处理纪律：不记日志、不明文 storage、autofill 属性的正确使用（autocomplete=current-password）——「凭证处理红线」
- 验证码的升级策略：首次登录无验证码 → 失败 N 次升级滑块 → 再失败短信——防爆破的阶梯
- 深水点：登录页的「账号枚举防御」——「用户不存在」与「密码错误」的提示统一（不泄露账号存在性）——安全提示的信息设计

```javascript
// 状态机: idle → captcha(失败2次) → sms(失败5次) → locked(10次, 10分钟)
// 提示统一: 「账号或密码错误」—— 不区分账号不存在
// 密码: password 字段 autocomplete="current-password", 不进任何持久化
```
