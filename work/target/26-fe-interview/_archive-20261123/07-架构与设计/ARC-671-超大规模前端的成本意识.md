## ARC-671：架构的成本意识

**答**：
- 前端成本清单：CDN 流量费（带宽单价 × 流量）、构建集群（CI 机器时）、监控存储（日志/APM 采样量）、人力（最大头）——「人力成本 > 基础设施成本」通常成立
- 成本可视化的抓手：月度成本账单（按应用分摊——CDN 按域名/CI 按团队）——「谁用谁付」驱动业务线自查
- 高频成本黑洞：全量监控日志（采样率失控）、构建缓存失效（全量重构建）、图片未压缩（CDN 流量）——三黑洞的定期巡检
- 成本与性能的联动：页面体积每减 30%，CDN 费与转化率双收益——性能优化的 ROI 常被低估
- 深水点：架构决策的成本维度——微前端的 runtime 叠加/监控全量采集/CI 并发膨胀——「每个架构决策都有月账单」

```text
前端成本清单:
  人力 (最大头) / CDN 流量 / CI 机器时 / 监控存储
账单: 按应用分摊 (谁用谁付)
黑洞: 监控采样失控 / 缓存失效全量构建 / 图片未压缩
联动: 体积 -30% → CDN 费↓ + 转化率↑
```
