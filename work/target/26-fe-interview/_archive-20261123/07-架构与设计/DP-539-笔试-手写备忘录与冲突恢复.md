## DP-539：笔试：手写草稿冲突

**题目**：实现表单草稿的冲突恢复：① 本地草稿（离线期间的修改）vs 服务端版本（他人已改）——冲突检测（updatedAt 比较）；② 三种冲突解决策略注入：本地覆盖/服务端覆盖/字段级合并——策略可配；③ 字段级合并的实现：逐字段比较（本地改了的字段用本地值，本地没改的用服务端——字段级 diff）；④ 恢复 UI 的数据支撑：冲突报告（哪些字段冲突/本地值/服务端值——三路对比表）；⑤ 恢复后的重新校验（合并后的表单重新校验——合并可能非法）。写出实现。

```javascript
function resolveConflict(local, server, strategy) {
  const conflicts = [];
  for (const key of new Set([...Object.keys(local), ...Object.keys(server)])) {
    if (!Object.is(local[key], server[key]))
      conflicts.push({ field: key, local: local[key], server: server[key] });
  }
  if (!conflicts.length) return { merged: server, conflicts };
  if (strategy === 'local') return { merged: local, conflicts };
  if (strategy === 'server') return { merged: server, conflicts };
  // 字段级合并: 本地改了用本地, 没改用服务端
  const merged = { ...server };
  for (const c of conflicts) merged[c.field] = local[c.field];   // 简化: 全取本地冲突字段
  return { merged, conflicts };                        // UI: 三路对比表 + 用户裁决
}
// 恢复后重新校验: validateForm(merged) — 合并可能非法
```

**评分点**：
- 冲突检测（updatedAt + 字段级 diff）
- 三策略注入（本地/服务端/字段级合并——策略可配）
- 字段级合并的语义（本地改了的用本地——diff 驱动）
- 恢复后重校验（合并可能非法——闭环）
