## ARC-487：错误提示的统一协议
**答**:
- 分层呈现：字段级（表单 inline）、区块级（卡片内 banner）、页面级（整页错误态 + 重试）、全局级（toast/通知中心）。错误路由到正确层级——现在是"所有错误 toast 一把梭"的反模式。
- 文案协议：用户语言（不说 stack/500），动作导向（"网络不稳，已自动重试 2 次失败，点击重试"），文案字典化管理（错误码 → 文案 + 兜底），禁止裸露原始错误。
- 错误分类到呈现映射：网络类（toast + 自动重试状态）、鉴权类（跳登录，带 returnUrl）、业务类（业务上下文内呈现）、系统类（页面级 + 客服入口）。
- 重试协议统一：可重试错误（网络/超时/5xx）带自动重试与手动重试按钮；不可重试（4xx 业务错）不给重试按钮。
- 监控联动：提示曝光事件上报（同一错误码提示曝光率 = 用户实际遇到的比率，比埋点错误率更接近体感）。
```javascript
// 错误呈现路由
function presentError(err, ctx) {
  const spec = errorDict[err.code] ?? { level: 'toast', text: '出错了，请稍后重试' };
  const el = spec.level === 'field' ? ctx.fieldRef
    : spec.level === 'page' ? pageErrorSlot
    : toastSlot;
  el.show({ text: spec.text, retryable: spec.retryable && err.retryable,
    action: spec.action });                                    // 字典统一文案与动作
}
```
