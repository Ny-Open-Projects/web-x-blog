## ARC-797：笔试：手写双跑比对器

**题目**：实现迁移双跑比对器 `DualRunComparator`：① 并行执行：`runBoth(input)`——新旧实现对同一输入并行执行（Promise.allSettled），超时保护（10s）；② 三层比对：渲染 diff（DOM 快照结构对比——忽略动态 id）、数据 diff（提交 payload 深对比——白名单字段忽略）、行为 diff（事件序列对比）；③ 差异分类：白名单差异（预定义可接受——时间戳/随机数）/真差异（缺陷候选）；④ 结果统计：diff 率/白名单命中率/超时率——迁移健康度报表；⑤ 真差异自动建单（去重——同 diff 指纹只建一次）。写出实现。

```javascript
class DualRunComparator {
  constructor({ whitelist = [], timeout = 10_000, onDefect } = {}) {
    Object.assign(this, { whitelist: new Set(whitelist), timeout, onDefect, stats: { total: 0, diff: 0, wl: 0, timeout: 0 } });
    this._fingerprints = new Set();
  }
  async runBoth(input, legacyFn, newFn) {
    this.stats.total++;
    const [l, n] = await Promise.allSettled([
      withTimeout(legacyFn(input), this.timeout),
      withTimeout(newFn(input), this.timeout),
    ]);
    if (l.status === 'rejected' || n.status === 'rejected') {
      this.stats.timeout++; return { verdict: 'timeout' };
    }
    const diffs = [
      ...diffDeep(l.value.data, n.value.data, this.whitelist),
      ...diffDom(l.value.dom, n.value.dom),
      ...diffEvents(l.value.events, n.value.events),
    ].filter((d) => !this.whitelist.has(d.path));
    if (!diffs.length) return { verdict: 'match' };
    this.stats.diff++;
    const fp = hash(JSON.stringify(diffs.map((d) => d.path)));
    if (!this._fingerprints.has(fp)) {
      this._fingerprints.add(fp);
      this.onDefect?.({ input, diffs, fingerprint: fp });
    }
    return { verdict: 'diff', diffs };
  }
}
function diffDeep(a, b, wl, path = '') {
  const out = [];
  if (Object.is(a, b)) return out;
  if (typeof a !== 'object' || typeof b !== 'object' || !a || !b)
    return [{ path, legacy: a, modern: b }];
  const keys = new Set([...Object.keys(a ?? {}), ...Object.keys(b ?? {})]);
  for (const k of keys)
    out.push(...diffDeep(a?.[k], b?.[k], wl, path ? `${path}.${k}` : k));
  return out;
}
```

**评分点**：
- 并行执行 + 超时保护（allSettled——一方挂不影响比对）
- 三层 diff 与白名单过滤（可接受差异预先定义）
- 差异指纹去重建单（同 diff 不重复）
- 统计报表（diff 率/超时率——迁移健康度）
