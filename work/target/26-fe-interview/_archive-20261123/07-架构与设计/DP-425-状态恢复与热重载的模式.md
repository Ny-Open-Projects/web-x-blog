## DP-425：状态恢复组合

**答**：
- 状态恢复的模式全景：备忘录（快照持久化）、策略（恢复策略：全量恢复/部分恢复/过期不恢复）、观察者（恢复完成通知）、命令（恢复动作可撤销）
- 恢复的数据分级：必须恢复（表单草稿/列表状态）、可选恢复（滚动位置/筛选条件）、不恢复（临时态/密码）——分级决定恢复清单
- 恢复的时序：数据加载 → 状态恢复 → 用户交互（恢复在数据后——否则状态指向不存在的数据）
- 版本兼容：持久化的状态结构随版本演进（schema 版本号 + 迁移函数链）——旧版本状态可升级
- 深水点：恢复的「过期判定」——30 分钟前的筛选条件恢复有意义吗（业务决策）——staleness 策略是产品决策的技术化

```javascript
function restoreState(saved, currentData) {
  const { schemaVersion, data, savedAt } = saved;
  const migrated = migrateChain(schemaVersion, CURRENT)(data);   // 版本迁移
  if (Date.now() - savedAt > STALE_MS) return false;             // 过期不恢复
  // 时序: 数据先就绪
  store.patch(migrated);
  return true;
}
```
