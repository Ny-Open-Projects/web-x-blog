## ARC-640：直播切片与回放
**答**:
- 回放架构：直播结束 → 录制转码（服务端异步——回放可用性延迟管理："回放生成中"状态）、回放播放器（VOD 链路 ARC-378 复用：进度记忆/倍速 ARC-511）、时间轴事件（直播中的关键事件锚点：讲解商品切换/抽奖时刻——时间轴标记可跳转）。
- 切片链路：主播端切片（直播中标记片段起止——切片任务提交）、自动切片（精彩时刻识别——服务端算法，前端展示切片卡片）、切片播放（短片段 VOD——加载策略：预加载下一条）。
- 时间轴协议：事件流（直播事件时间戳 —— 回放页时间轴渲染——点击跳转对应商品卡/回放位置）、深链（分享"第 3 分钟的商品"——时间参数定位）。
- 转码质量策略：清晰度档位（回放转码多档——ARC-341/378 ABR）、生成优先级（热门直播优先转码——容量调度）。
- 合规：回放内容审核（直播回放复审——违规段落裁剪：时间轴标注"该段不可用"——跳过处理）、切片传播水印。
```javascript
// 回放时间轴
const events = await api.replayEvents(replayId);                 // [{t, type: 'goods', ref}]
<Timeline events={events} onSeek={(t) => player.seek(t)} />       // 事件锚点跳转
// 切片卡片：{ clipId, start, end, cover } → 独立 VOD 播放 + 预加载下一条
```
