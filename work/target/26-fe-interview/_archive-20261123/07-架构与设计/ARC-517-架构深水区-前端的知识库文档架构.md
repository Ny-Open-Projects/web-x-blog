## ARC-517：知识库文档中心架构
**答**:
- 三层架构：目录层（文档树懒加载 + 拖拽排序移动 ARC-485/497）、内容层（富文本编辑器 ARC-472 + 块级结构）、检索层（全文搜索 ARC-383 + 双链/反链）。
- 编辑与浏览双态：只读渲染（SSR/静态化优先，ARC-060）、编辑态按需加载编辑器（重 SDK 懒加载 ARC-086）；草稿与版本管理（ARC-483/387）。
- 双链体系：@提及与 #标签 → 引用关系存储 → 反链面板（谁引用了我）；引用失效处理（目标删除 → 占位）。
- 权限与分享：文档级权限（继承目录 + 覆盖）、外链分享（签名 + 有效期 + 水印 ARC-340）。
- 性能：大文档分段渲染（千段文档虚拟化段落）、图片懒加载、目录滚动同步（ARC-348 锚点联动）；搜索结果高亮与定位。
```javascript
// 反链查询 + 文档树定位
async function openDoc(id, { highlight }) {
  const doc = await cache.ensure(['doc', id], () => api.getDoc(id));   // 编辑态才拉编辑器
  renderReadOnly(doc);                                           // 默认只读渲染
  if (highlight) scrollToBlock(highlight);                       // 从搜索/反链跳入
}
backlinks: await api.getBacklinks(id)   // 引用关系图 → 反链列表
```
