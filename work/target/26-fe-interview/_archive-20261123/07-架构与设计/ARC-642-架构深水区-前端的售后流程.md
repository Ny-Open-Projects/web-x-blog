## ARC-642：售后流程前端架构
**答**:
- 售后类型：仅退款/退货退款/换货——类型决定流程分支（表单动态：退货需物流单号/换货需换货规格选择——ARC-570 动态 schema）。
- 申请流程：选商品行（部分商品售后——行级选择 + 数量/原因）、原因与凭证（原因结构化 + 图片上传——预检 ARC-605）、提交（售后单创建幂等——防重复申请）、审核状态（商家审核 → 退货物流 → 退款——状态时间线 ARC-625）。
- 状态机：申请中/商家处理/待退货/退货中/退款中/完成/拒绝——每态可操作集服务端下发（补充物流/撤销售后/申诉）、超时语义（商家超时未处理 → 自动同意——倒计时展示）。
- 物流填写：退货物流（运单号校验/物流选择——快递公司字典 ARC-532）、退货地址展示（复制/导航）。
- 撤销与再申请：撤销（状态机允许态）→ 重新申请；争议升级（平台介入入口——工单化 ARC-509）。
```javascript
// 售后单状态时间线
const aftersale = await api.afterSaleDetail(id);
<Timeline states={aftersale.history} actions={aftersale.actions} />  // 操作集下发
// 退货物流：aftersale.state === 'wait-return' → <LogisticsForm carriers={carrierDict} />
sm.on('auto-agree', () => toast('商家超时未处理，已自动同意退货'));   // 超时语义提示
```
