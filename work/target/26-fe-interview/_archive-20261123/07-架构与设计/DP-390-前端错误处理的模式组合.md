## DP-390：错误处理组合

**答**：
- 错误处理的模式组合：错误边界（组件树隔离——React ErrorBoundary）、空对象降级（数据失败用兜底数据）、重试（可恢复错误）、上报（全局兜底）——四模式各管一段
- 分层设计：错误分类（致命/可恢复/可忽略）→ 分层处置（致命→边界、可恢复→降级、可忽略→记录）——分类先行处置才对
- 错误边界的「恢复协议」：边界捕获 → 展示 fallback → 重试（key 重置强制重建）——「捕获」容易「恢复」难
- 实战要点：错误边界不捕异步（异步错误同步化——throw promise/use）；全局兜底（unhandledrejection → 上报）
- 深水点：错误的「用户语义翻译」——技术错误（NetworkError）→ 用户语义（「网络不稳，稍后重试」）——错误码到文案的映射表

```jsx
// 分层组合
<ErrorBoundary fallback={<RetryUI onRetry={reset} />}>   // 边界: 渲染错误
  <Suspense fallback={<Skeleton />}>
    <DataSection />                                      // 内部: 数据错误降级
  </Suspense>
</ErrorBoundary>
// DataSection 内: try { data = await fetch() } catch { setData(cachedData); toast('展示缓存数据'); }
```
