## ARC-249：国际化运行时与状态管理：热切换如何实现？
**答**：
- 热切换要求：语言变更后**所有已渲染文案即时更新**且不整页刷新。核心是把"当前语言"做成响应式状态，t() 订阅它。
- 实现：i18n 实例内部是 mini store（version 计数器），t() 在组件里通过 useSyncExternalStore/observable 订阅；切换语言 = 加载新语言包 → 置换字典 → version++ → 全部订阅组件重渲染。
- 切换体验：新语言包加载期显示旧语言+进度态（不是白屏）；切换持久化（Cookie/localStorage）同步 URL（/?lang=）保证分享一致。
- 防水合错误：SSR 与客户端字典必须同一版本（HTML 内联字典版本号，客户端版本不符则等待加载完成再水合）。

```typescript
// mini reactive i18n
class I18nStore {
  #listeners = new Set<() => void>();
  lang = 'zh-CN'; version = 0;
  async switch(lang: string) {
    await loadLocale(lang, ['common', 'current-ns']);   // 先加载后切换，切换瞬间原子完成
    this.lang = lang; this.version++;
    document.cookie = `lang=${lang}`;
    this.#listeners.forEach(l => l());
  }
  subscribe = (l: () => void) => { this.#listeners.add(l); return () => this.#listeners.delete(l); };
}
// 组件：const { lang } = useSyncExternalStore(i18n.subscribe, () => i18n.version);
// t() 每次调用读当前字典 —— version 变化触发组件重渲染拿到新文案
```
