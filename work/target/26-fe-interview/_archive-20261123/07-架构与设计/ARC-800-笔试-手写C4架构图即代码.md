## ARC-800：手写 C4 图即代码

**题目**：实现 C4 模型的 DSL 与渲染器：① 数据模型：Person/Container/Component/Relationship（四层 C4 元素——element: { id, type, name, tech, description }）；② DSL 构建 API：`model.person().container().component().relates()`——链式声明；③ 渲染输出：Mermaid 格式（C4Context/C4Container 语法）——diff 友好（架构图进 git 可 review）；④ 分层过滤：L1 上下文图（只 Person+Container）/L2 容器图 /L3 组件图——按层级裁剪元素与关系；⑤ 校验：关系引用的元素必须存在（悬空关系报错）。写出实现。

```javascript
class C4Model {
  #elements = new Map(); #relations = [];
  #add(id, type, props) { this.#elements.set(id, { id, type, ...props }); return this; }
  person(id, name, desc) { return this.#add(id, 'Person', { name, description: desc }); }
  container(id, name, tech, desc) { return this.#add(id, 'Container', { name, tech, description: desc }); }
  component(id, name, tech, desc, containerId) { return this.#add(id, 'Component', { name, tech, description: desc, containerId }); }
  relates(fromId, toId, label, tech) {
    if (!this.#elements.has(fromId) || !this.#elements.has(toId))
      throw new Error(`悬空关系: ${fromId} → ${toId}`);
    this.#relations.push({ from: fromId, to: toId, label, tech });
    return this;
  }
  toMermaid(level = 1) {                       // L1=Context, L2=Container, L3=Component
    const keep = this.#elementsInLevel(level);
    const lines = ['C4Context'];
    for (const e of keep) {
      const fn = { Person: 'Person', Container: 'Container', Component: 'Component' }[e.type];
      lines.push(`  ${fn}(${e.id}, "${e.name}", "${e.tech ?? ''}", "${e.description ?? ''}")`);
    }
    for (const r of this.#relations)
      if (keep.has(r.from) && keep.has(r.to))
        lines.push(`  Rel(${r.from}, ${r.to}, "${r.label}"${r.tech ? `, "${r.tech}"` : ''})`);
    return lines.join('\n');
  }
  #elementsInLevel(level) {
    const keep = new Set();
    for (const e of this.#elements.values())
      if (level >= 2 || e.type !== 'Component') keep.add(e.id);
    return keep;
  }
}
```

**评分点**：
- 四层 C4 元素建模 + 链式 DSL
- 悬空关系校验（引用完整性）
- 分层过滤（L1/L2/L3 按受众裁剪）
- Mermaid 输出（图即代码进 git——架构图可 review/diff）
