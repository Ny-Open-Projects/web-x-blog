## DP-460：数据一致性组合

**答**：
- 一致性的模式全景：命令（写操作带版本号）、观察者（变更广播——多视图同步）、备忘录（乐观快照回滚）、策略（冲突策略：LWW/CAS/人工合并）、代理（store 写入口统一仲裁）
- 一致性问题的三源：多请求乱序、乐观更新并发、缓存与真实态漂移——三个模式组合对应
- 时间线仲裁的实现：store.apply(data, timeline)——timeline 单调才接受（旧响应丢弃）——「单调递增」是核心不变量
- 深水点：一致性的「最终兜底」——前端策略失效后（乐观+仲裁都错了）——「下拉刷新」是最诚实的恢复机制（重置为服务端真值）

```javascript
function createStore(initial) {
  let state = initial, timeline = 0;
  return {
    apply(data, fromTimeline) {
      if (fromTimeline <= timeline) return false;    // 旧时间线丢弃
      timeline = fromTimeline; state = data; return true;
    },
    next() { return ++timeline; },                   // 乐观更新占用新时间线
  };
}
// 最终兜底: 手动刷新 = 放弃本地仲裁, 接受服务端真值
```
