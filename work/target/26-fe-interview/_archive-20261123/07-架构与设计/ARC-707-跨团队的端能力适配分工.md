## ARC-707：端能力适配分工

**答**：
- 多端矩阵：H5/小程序/App 内嵌/桌面端——同一业务多端的适配工作分配（谁做哪端）
- 分工原则：业务域团队全端负责（自己业务的多端）——「按端拆团队」（H5 组/小程序组）会导致业务逻辑三份实现
- 端能力的公共下沉：多端共享的适配层（登录/支付/分享的能力矩阵——平台统一封装）——各团队只调适配层 API
- 端差异的决策记录：每端的功能差异清单（为什么小程序没有 X 功能）——产品/技术/合规三视角的决策记录
- 深水点：端适配的「回归成本」——同功能多端各自回归——「多端 BehaviorSpec」（FRP-390）一次编写双端验证

```text
端能力分工:
  原则: 业务域团队全端负责
  下沉: 多端适配层 (平台封装)
  差异: 端功能差异决策记录 (产品/技术/合规)
  回归: 多端 BehaviorSpec 一次编写双端验证
```
