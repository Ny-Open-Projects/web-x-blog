## ARC-817：手写技术债利息

**题目**：实现技术债的利息量化 `DebtRegistry`：① 债务登记：{ id, desc, rootCause, interestPerSprint(每迭代额外耗时——小时), payoffCost(偿还人日), owner, createdAt, status }；② 利息累计：按迭代自动累计「已付利息」（利息 × 已经历迭代数）——总成本 = 利息累计 + 未来预计利息；③ 偿还决策辅助：payoffCost × 8h < 未来预计利息 → 建议「该还了」（量化排序——利息最高的债优先还）；④ 债务的「自然消亡」检测：关联模块下线（git 检测目录删除）→ 自动标记消亡；⑤ 报表：债务总利息趋势（每迭代新增利息 vs 偿还节省——正负曲线）。写出实现。

```javascript
class DebtRegistry {
  #debts = new Map(); #sprintCount = 0;
  register(debt) {
    const d = { ...debt, id: crypto.randomUUID(), createdAt: Date.now(),
      paidInterest: 0, status: 'open', sprints: 0 };
    this.#debts.set(d.id, d);
    return d;
  }
  tickSprint() {                                      // 每迭代结算利息
    this.#sprintCount++;
    for (const d of this.#debts.values())
      if (d.status === 'open') { d.paidInterest += d.interestPerSprint; d.sprints++; }
  }
  payoffAdvice() {
    return [...this.#debts.values()]
      .filter((d) => d.status === 'open')
      .map((d) => {
        const remainingSprints = 8;                    // 预估项目剩余迭代
        const futureInterest = d.interestPerSprint * remainingSprints;
        const payoffHours = d.payoffCost * 8;
        return { ...d, futureInterest, payoffHours,
          advice: payoffHours < futureInterest ? '建议偿还 (利息>成本)' : '暂缓' };
      })
      .sort((a, b) => b.interestPerSprint - a.interestPerSprint);
  }
  markDead(dirGone) {                                 // 自然消亡检测
    for (const d of this.#debts.values())
      if (d.status === 'open' && d.rootDir && dirGone.includes(d.rootDir))
        d.status = 'dead (module removed)';
  }
  trendReport() {
    const open = [...this.#debts.values()].filter((d) => d.status === 'open');
    const totalInterest = open.reduce((s, d) => s + d.interestPerSprint, 0);
    return { openDebts: open.length, interestPerSprint: totalInterest,
      note: totalInterest > 0 ? '每迭代仍在支付利息' : '债务清零' };
  }
}
```

**评分点**：
- 利息量化的核心（interestPerSprint × 迭代数 = 累计成本）
- 偿还决策量化（payoffCost vs 未来利息——数据驱动排序）
- 自然消亡检测（模块下线自动消债——避免还死债）
- 利息趋势报表（每迭代正负曲线——治理可视化）
