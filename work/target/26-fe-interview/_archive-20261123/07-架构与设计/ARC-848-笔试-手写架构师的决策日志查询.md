## ARC-848：手写决策日志查询

**题目**：实现架构决策日志的查询系统 `DecisionLog`：① 索引构建：ADR 库 → 全文索引（title/context/decision 分词）+ 标签索引（类型/状态/团队）——双索引查询；② 查询能力：关键词搜索、按标签过滤（status=accepted AND type=选型）、按时间范围、按团队；③ 关联查询：`related(adrId)`——引用了该决策的其他 ADR（决策链）、影响的应用、关联的故障（决策后的事故）；④ 查询结果排序：相关度（全文匹配度）+ 时效性（新决策权重高——旧决策可能过时）加权；⑤ 输出：查询结果 + 每条的状态标注（accepted/superseded——过时决策标注防误导）。写出实现。

```javascript
class DecisionLog {
  #adrs = []; #fullIndex = new Map(); #tagIndex = new Map();
  constructor(adrs) {
    this.#adrs = adrs;
    for (const adr of adrs) {
      const tokens = tokenize(`${adr.title} ${adr.context} ${adr.decision}`);
      for (const t of tokens)
        (this.#fullIndex.get(t) ?? this.#fullIndex.set(t, new Set()).get(t)).add(adr.id);
      for (const tag of [adr.type, adr.status, adr.team].filter(Boolean))
        (this.#tagIndex.get(tag) ?? this.#tagIndex.set(tag, new Set()).get(tag)).add(adr.id);
    }
  }
  search({ keywords, tags = [], team, dateRange }) {
    let candidates;
    if (keywords) {
      const tokenSets = tokenize(keywords).map((t) => this.#fullIndex.get(t) ?? new Set());
      candidates = intersect(tokenSets);              // AND 语义
    } else candidates = new Set(this.#adrs.map((a) => a.id));
    for (const tag of tags) {
      const tagged = this.#tagIndex.get(tag) ?? new Set();
      candidates = new Set([...candidates].filter((id) => tagged.has(id)));
    }
    const results = [...candidates].map((id) => {
      const adr = this.#adrs.find((a) => a.id === id);
      const staleness = adr.status === 'superseded' ? ' [已过时]' : '';
      const recency = 1 / (1 + (Date.now() - new Date(adr.date).getTime()) / (365 * 86400e3));
      return { ...adr, staleness, score: matchScore(adr, keywords) * (0.5 + 0.5 * recency) };
    });
    return results.sort((a, b) => b.score - a.score);
  }
  related(adrId) {
    const refs = this.#adrs.filter((a) => a.supersededBy === adrId || a.references?.includes(adrId));
    const impacts = this.#adrs.find((a) => a.id === adrId)?.affectedApps ?? [];
    return { referencedBy: refs.map((r) => r.id), affectedApps: impacts };
  }
}
```

**评分点**：
- 双索引（全文 + 标签——AND 语义组合）
- 时效性加权（新决策权重高——旧决策降权防误导）
- superseded 标注（过时决策防误导——状态可见）
- 关联查询（决策链/影响应用——知识网络）
