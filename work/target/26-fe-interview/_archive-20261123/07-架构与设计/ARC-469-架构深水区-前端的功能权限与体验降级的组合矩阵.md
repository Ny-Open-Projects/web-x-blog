## ARC-469：功能权限 × 体验降级的组合矩阵
**答**:
- 两维交叉：功能可用性（有权/无权/未开通）× 运行状态（正常/降级/不可用）产生九宫格。多数 bug 出在边界格：有权但服务降级（显示什么）、无权但缓存里有旧数据（要不要展示）。
- 矩阵设计原则：无权 → 永远不展示数据（哪怕缓存里有——权限优先于可用性）；有权但降级 → 展示缓存/兜底数据并标注"数据非实时"；未开通 → 引导页（转化机会）而非白屏。
- 实现收口：一个 resolve(feature) 函数统一输出渲染指令（render: 'full' | 'degraded' | 'upsell' | 'hidden' + 数据来源 + 提示文案），UI 层按指令渲染，判断逻辑集中可测。
- 边界细节：权限临时失效（会话过期）与权限永久失效（未购买）的处理路径不同；降级数据的时效标注（"3 分钟前数据"）。
- 测试：矩阵组合用例表驱动（feature 状态 × 运行状态 9 个组合各一条断言）。
```javascript
type RenderInstruction = 'full' | 'degraded' | 'upsell' | 'hidden';
function resolve(feature, runtime): { render: RenderInstruction, source: 'live'|'cache', notice?: string } {
  if (!feature.granted) return feature.purchasable ? { render: 'upsell' } : { render: 'hidden' };
  if (runtime === 'ok') return { render: 'full', source: 'live' };
  if (runtime === 'degraded' && hasCache(feature)) return { render: 'degraded', source: 'cache', notice: '当前展示缓存数据' };
  return { render: 'hidden' };                                // 降级且无缓存：隐藏区块
}
```
