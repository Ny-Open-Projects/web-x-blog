## DP-387：状态机进阶

**答**：
- 状态机的进阶价值：迁移表是「数据」——可自动生成可视化（状态图）与测试用例（迁移矩阵遍历）
- 可视化：迁移表 → mermaid stateDiagram（状态图随代码同步——文档即代码）
- 测试生成：所有迁移路径遍历（每个 event × 每个状态 = 用例矩阵）——「非法迁移也应测试」（send 不存在的事件应拒绝）
- 并发与层次：嵌套状态（state 含子机——审批流内的支付子流程）、并行状态（同时活跃的区域）——XState 的完整模型
- 深水点：状态机的「上下文管理」——context（状态机的数据）与状态的迁移联动（action 更新 context）——纯状态无数据的状态机无意义

```javascript
function toMermaid(states) {
  const lines = ['stateDiagram-v2'];
  for (const [state, def] of Object.entries(states))
    for (const [event, t] of Object.entries(def.on ?? {}))
      lines.push(`  ${state} --> ${t.target}: ${event}`);
  return lines.join('\n');                            // 迁移表 → 状态图
}
```
