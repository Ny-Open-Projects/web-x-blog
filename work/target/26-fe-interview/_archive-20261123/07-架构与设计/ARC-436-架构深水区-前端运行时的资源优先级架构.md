## ARC-436：资源优先级架构：priority hints 全景
**答**:
- 优先级工具族：preload（当前页必需，提前加载）、prefetch（下一页可能需要，空闲加载）、preconnect（提前建连：DNS+TCP+TLS）、modulepreload（ESM 依赖图预载）、fetchpriority（同资源间相对优先级）、Priority Hints on images。
- 架构决策框架：关键渲染路径资源（首屏 CSS/字体/首图）用 preload + fetchpriority=high；路由级 chunk 用 prefetch/空闲预取（ARC-405）；第三方域名统一 preconnect 清单。
- 反模式治理：preload 滥用（preload 了一堆没用的 → 挤占带宽且告警"preloaded but not used"）；字体 preload 要注意跨域 crossorigin 属性匹配否则双重下载。
- 动态优先级：加载编排器按页面阶段调整——首屏完成后提升交互资源优先级；弱网下自动降级非关键预取（Navigation API/网络状态 API 感知）。
- 度量闭环：预取命中率、preload 未使用率进性能看板，作为预算回归的一部分。
```html
<!-- 关键路径优先级声明 -->
<link rel="preconnect" href="https://cdn.example.com" crossorigin>
<link rel="preload" as="font" href="/fonts/main.woff2" type="font/woff2" crossorigin fetchpriority="high">
<link rel="modulepreload" href="/chunk-home.js">
<img src="hero.jpg" fetchpriority="high" loading="eager">
<script src="analytics.js" fetchpriority="low" defer></script>
```
