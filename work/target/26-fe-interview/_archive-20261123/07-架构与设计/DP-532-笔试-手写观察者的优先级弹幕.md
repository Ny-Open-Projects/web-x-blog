## DP-532：笔试：手写弹幕池

**题目**：实现弹幕渲染器：① 弹幕池：固定 DOM 槽位（如 20 条/屏——槽位复用而非每次创建）；② 分配策略：新弹幕找空闲槽位（无空闲丢最旧——弹幕不排队）；③ 轨道分配：按内容高度选轨道（避让——同轨道不重叠）；④ 超量丢弃：高峰期丢低价值弹幕（普通用户 < VIP——优先级丢弃）；⑤ rAF 批量渲染：位置更新在 rAF 内统一（每帧一次——不逐条更新）。写出实现。

```javascript
class DanmakuPool {
  #slots = []; #active = [];
  constructor({ slots = 20, lanes = 6 } = {}) {
    for (let i = 0; i < slots; i++) {
      const el = document.createElement('div');
      el.className = 'danmaku';
      this.#slots.push(el);
    }
    this.lanes = lanes;
  }
  push(danmaku) {
    const slot = this.#slots.pop() ?? this.#evictOldest();
    if (!slot) return;                                 // 全忙: 丢弃 (不排队)
    const lane = this.#pickLane(danmaku.priority);     // 轨道避让
    slot.el.textContent = danmaku.text;
    slot.el.style.top = `${lane * 28}px`;
    slot.el.style.transform = 'translateX(100vw)';
    slot.lane = lane;
    slot.prio = danmaku.priority;
    slot.t = Date.now();
    this.#active.push(slot);
  }
  #evictOldest() {                                     // 丢最旧 (VIP 优先保)
    const oldest = this.#active.filter((s) => s.prio < 3).sort((a, b) => a.t - b.t)[0];
    if (!oldest) return null;
    this.#active = this.#active.filter((s) => s !== oldest);
    return oldest.el;
  }
  render() {                                           // rAF 统一更新
    for (const s of this.#active) {
      const x = 100 - ((Date.now() - s.t) / 8000) * 100;
      s.el.style.transform = `translateX(${x}vw)`;
    }
    requestAnimationFrame(() => this.render());
  }
}
```

**评分点**：
- 槽位池复用（固定 DOM——零创建成本）
- 无空闲丢最旧（弹幕不排队——排队必延迟）
- 优先级丢弃（VIP 保护——低价值先丢）
- rAF 批量渲染（每帧一次——不逐条更新）
