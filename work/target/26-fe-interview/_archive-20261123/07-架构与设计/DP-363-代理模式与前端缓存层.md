## DP-363：代理模式：缓存与控制

**答**：
- 代理的核心：控制对目标的访问（缓存代理/权限代理/懒加载代理/日志代理）——与装饰器的区别：代理控制「访问」，装饰器增强「行为」（实践中界限模糊，意图不同）
- 缓存代理实战：API 代理（同参数请求缓存——in-flight 合并是代理的经典变体：并发请求共享同一 Promise）
- 权限代理：路由守卫（访问页面前检查权限——不通过则重定向）——「访问控制」在代理层统一
- 懒加载代理：重资源对象首次访问才初始化（图像的 blurhash 占位 → 真图代理）
- 深水点：Proxy 元编程的陷阱——get 拦截返回函数时 this 绑定（方法调用丢失 this——bind 处理）；Vue reactive 就是 Proxy 代理的工业级应用

```javascript
function cachedProxy(target, { ttl = 60_000 } = {}) {
  const cache = new Map();
  return new Proxy(target, {
    async get(t, prop) {
      if (typeof t[prop] !== 'function') return t[prop];
      return async (...args) => {
        const key = `${String(prop)}:${JSON.stringify(args)}`;
        const hit = cache.get(key);
        if (hit && Date.now() - hit.at < ttl) return hit.value;
        const value = await t[prop](...args);
        cache.set(key, { value, at: Date.now() });
        return value;
      };
    },
  });
}
// const api = cachedProxy(rawApi) — 业务无感知获得缓存
```
