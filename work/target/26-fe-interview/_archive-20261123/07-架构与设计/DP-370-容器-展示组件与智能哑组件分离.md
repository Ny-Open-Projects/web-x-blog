## DP-370：容器/展示分离

**答**：
- 模式定义：容器组件（取数/状态/副作用——聪明）+ 展示组件（纯渲染——哑，props 进 UI 出）——关注点分离的经典
- Hooks 时代的演化：容器被「自定义 Hook 取代」（useUserData + 展示组件同文件）——分离从「组件拆分」演化为「逻辑与视图分离」
- 展示组件的价值不变：纯 props 可测（storybook 快照）/可复用（不绑数据源）/可替换
- 判别标准：组件里有 fetch/store 访问 = 容器职责——抽成 hook 后组件回归纯展示
- 深水点：过度分离的反模式——「每个展示组件配一个容器」（教条化）——现代实践：hook 就近、展示组件按复用需求提取

```jsx
// Hook = 容器职责
function useUser(id) {
  const [user, setUser] = useState(null);
  useEffect(() => { fetchUser(id).then(setUser); }, [id]);
  return user;
}
// 展示组件 = 纯哑
function UserCard({ user }) {
  if (!user) return <Skeleton />;
  return <div className="card">{user.name}</div>;
}
// 组装: function Page() { const user = useUser(1); return <UserCard user={user} />; }
```
