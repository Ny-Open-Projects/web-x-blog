## ARC-419：国际化运行时与文案协议的进阶设计
**答**:
- 文案协议带上下文：key 命名带场景（button.pay.now 而非 pay）、注释说明使用位置、占位符类型化（{count:number}）、复数规则（ICU MessageFormat 全语法而非简单拼接）。
- 运行时设计：t(key, params, { locale, context }) —— fallback 链（请求 locale → 地区变体 → 默认语言 → key 兜底显示）、缺失文案上报（运行时发现翻译空洞）、热更新（文案包版本化拉取，无需发版）。
- 格式化与文案分离：日期/数字/货币走 Intl API 按locale 格式化，不硬编码格式；文案中的标点/空格属于翻译范畴由译员负责。
- 与设计系统协同：文案长度弹性（按钮最小宽度、截断策略 ellipsis vs 换行）、RTL 下图标方向语义翻转。
- 质量闭环：截图级文案审核（伪本地化用 [!!!] 包裹暴露硬编码）、翻译记忆库、上线后缺失率与客诉指标监控。
```javascript
// ICU 复数 + fallback 链
const messages = { en: { cart: '{count, plural, =0 {Your cart is empty} one {# item} other {# items}}' } };
function t(key, params, locale) {
  for (const l of fallbackChain(locale)) {
    const msg = messages[l]?.[key];
    if (msg) return icuFormat(msg, params);
    reportMissing(key, locale);                                // 缺失上报
  }
  return `[${key}]`;                                           // 兜底可见
}
t('cart', { count: 3 }, 'zh-CN'); // fallback → en
```
