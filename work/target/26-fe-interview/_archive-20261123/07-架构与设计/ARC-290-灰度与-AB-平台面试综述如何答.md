## ARC-290：灰度与 AB 平台面试综述如何答？
**答**：
- 综述框架：先分清两个工具（发布灰度=工程安全，AB=产品决策，ARC-281），再按"流量决策层 → 版本共存层 → 观测对账层 → 治理层"四层展开。
- 四层要点：决策（入口服务/边缘函数分桶，稳定可复现，ARC-276/282）；共存（新旧产物共存+样式/SW/存储兼容，ARC-284）；观测（版本指纹+曝光事件+SRM 对账+自动止损，ARC-279/283）；治理（审批流+实验生命周期+成本治理，ARC-286/288）。
- 加分点：说出"灰度的本质是版本共存+比例渐进，回滚=指针回拨"；"实验结论的可信度来自分桶稳定+埋点完整+统计纪律"三句话总结。
- 收尾给场景：面试官追问"5% 灰度发现错误率 3 倍怎么办"→ 立即止损（指针回 0）→ 对账 SRM 排除分桶 bug → 根因修复后重新灰度。

// 共存层：/builds/v1 /builds/v2 + 样式scope + SW策略 + 存储迁移
