## ARC-455：地图类应用的架构设计
**答**:
- 架构分层：底图层（栅格/矢量瓦片）、业务图层（marker/热力/轨迹，按数据类型分层管理）、交互层（拾取/绘制/测距）、数据层（地理编码/聚合/轨迹压缩）。
- 大数据量图层策略：矢量瓦片（数据分片按视野加载）、点聚合（Grid/Supercluster 按缩放级别聚合）、热力图（预聚合网格）、轨迹抽稀（Douglas-Peucker，万点轨迹减 90% 无视觉差）。
- 图层生命周期：视野变化驱动数据加载（moveend → bbox 查询），防抖 + 请求取消（快速平移时旧请求作废）；图层显隐是资源管理（隐藏即卸载数据）。
- 性能：marker 上千个用 Canvas/WebGL 渲染（deck.gl/MapLibre symbol layer）而非 DOM；动画（轨迹回放）走 GPU transform。
- 坐标与精度治理：坐标系统一（GCJ02/WGS84 转换收口到一个模块）、精度脱敏（对外展示坐标降精度防隐私问题）。
```javascript
// 视野驱动加载 + 取消
map.on('moveend', debounce(async () => {
  bboxReq?.abort();                                          // 取消旧视野请求
  bboxReq = fetchMarks(map.getBounds()).then(rs =>
    marksLayer.setData(cluster(rs)));                        // 聚合后渲染
}, 300));
// 轨迹抽稀
function simplify(pts, eps = 1e-5) {                          // Douglas-Peucker
  if (pts.length < 3) return pts;
  const [a, ...rest] = pts, b = rest[rest.length - 1];
  const { max, idx } = farthest(rest, a, b);
  return max > eps ? [...simplify(pts.slice(0, idx + 1), eps), ...simplify(pts.slice(idx), eps)] : [a, b];
}
```
