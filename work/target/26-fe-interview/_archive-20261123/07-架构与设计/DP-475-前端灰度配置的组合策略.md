## DP-475：灰度组合策略

**答**：
- 灰度的组合维度：用户属性（地区/机型/会员等级）、比例（百分比哈希）、白名单（内部用户/种子用户）——多维度组合的优先级（白名单 > 属性 > 比例）
- 组合的确定性：同用户多维度判定的「稳定结果」（判定顺序固定——否则灰度用户来回漂移）
- 灰度的分层生效：发布灰度（新版本代码）与功能灰度（新功能开关）独立——两层灰度的叠加语义
- 深水点：灰度的「冲突检测」——两个灰度实验同时作用于同一用户且改同一 UI（冲突——实验分层正交解决）

```javascript
function inRollout(user, rule) {
  if (rule.whitelist?.includes(user.id)) return true;          // 白名单最优先
  if (rule.region && !rule.region.includes(user.region)) return false;
  return hash(`${rule.id}:${user.id}`) < rule.percent / 100;    // 比例哈希
}
// 发布灰度与功能灰度独立: 新版本(flag: versionB) × 新功能(flag: newCart)
```
