## ARC-582：页面性能归因看板
**答**:
- 看板回答三问：哪个页面劣化了（页面级 P75 与预算对比 ARC-547）、为什么劣化（版本 diff/资源 diff/依赖接口 diff——ARC-358 归因的页面特化）、谁负责修（资源 owner/接口 owner 自动定位）。
- 归因数据：版本维度（劣化窗口内的发布列表 + 每版本样本对比——灰度期即可发现）、资源维度（bundle 体积 diff/图片尺寸/第三方脚本新增——构建产物对账）、接口维度（页面依赖接口的 P95 变化——请求瀑布对比 ARC-546）。
- 看板形态：页面健康列表（预算达标率排序）→ 点入单页 → 时间线（指标曲线 + 发布/资源变更事件叠加标注）→ 差异明细（新旧版本资源清单 diff）。
- 闭环：劣化自动开单（归因结论附工单——定位到具体改动点）、修复验证（修复版本上线后指标回归确认）。
- 防呆：样本量守门（劣化判定要求最小样本，小流量页面防误报——ARC-289 统计功效）、大盘波动剥离（同时段全站对比——区分页面问题还是大盘问题）。
```javascript
// 页面归因报告
async function attributePage(route, { from, to }) {
  const releases = await releases.between(from, to, { routes: [route] });
  const bundleDiff = await bundleDiffOf(releases);               // 资源 diff
  const apiDiff = await apiPerfDiff(route, from, to);            // 接口 diff
  return { metricDelta: await rum.delta(route, from, to),
    suspects: rank([...releases.map(asSuspect), ...bundleDiff, ...apiDiff]) };
}
```
