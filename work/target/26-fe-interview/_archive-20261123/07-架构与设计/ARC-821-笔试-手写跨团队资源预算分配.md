## ARC-821：手写资源预算

**题目**：实现多团队的共享资源预算分配器 `ResourceBudget`：① 资源池：{ totalCiConcurrency, totalCdnQuota, platformSupportHours }——总量固定；② 分配策略：基线分配（按团队规模/流量占比）+ 弹性池（20% 总量——先到先得但可协商）；③ 用量追踪：各团队实际用量 vs 预算（超用告警——下期预算调整依据）；④ 借还机制：A 团队闲置预算可临时借给 B（大促）——到期归还；⑤ 分配建议：基于历史用量 + 业务权重（大促团队临时加权）的季度再分配建议。写出实现。

```javascript
class ResourceBudget {
  #pools; #allocations = new Map(); #usage = new Map(); #loans = [];
  constructor(total, teams) {
    this.#pools = total;
    // 基线: 按流量占比分配, 保留 20% 弹性池
    const totalTraffic = teams.reduce((s, t) => s + t.trafficShare, 0);
    const basePool = total.ciConcurrency * 0.8;
    for (const t of teams)
      this.#allocations.set(t.name, {
        ci: Math.floor(basePool * (t.trafficShare / totalTraffic)),
        cdnQuota: total.cdnQuota * (t.trafficShare / totalTraffic),
        supportHours: t.supportHours ?? 4,
      });
    this.#elastic = total.ciConcurrency * 0.2;
  }
  use(team, resource, amount) {
    const alloc = this.#allocations.get(team);
    const used = (this.#usage.get(team) ?? {})[resource] ?? 0;
    // 优先用自身预算, 超出检查弹性池
    if (used + amount > alloc[resource]) {
      const over = used + amount - alloc[resource];
      if (over > this.#elastic) throw new Error(`${team} 超预算且弹性池不足`);
      console.warn(`[budget] ${team} 使用弹性池 ${over}`);
    }
    this.#record(team, resource, amount);
  }
  loan(from, to, amount, days) {                      // 借还机制
    this.#loans.push({ from, to, amount, due: Date.now() + days * 86400e3 });
    this.#allocations.get(from).ci -= amount;
    this.#allocations.get(to).ci += amount;
  }
  reclaimDue() {                                      // 到期归还
    const now = Date.now();
    this.#loans = this.#loans.filter((l) => {
      if (l.due <= now) {
        this.#allocations.get(l.from).ci += l.amount;
        this.#allocations.get(l.to).ci -= l.amount;
        return false;
      }
      return true;
    });
  }
  rebalanceAdvice() { /* 历史用量 vs 预算 → 季度再分配建议 */ }
}
```

**评分点**：
- 基线分配（流量占比）+ 弹性池（20%）的双层设计
- 超用告警与弹性池检查
- 借还机制（到期自动归还——loans 清理）
- 季度再分配建议（历史用量驱动）
