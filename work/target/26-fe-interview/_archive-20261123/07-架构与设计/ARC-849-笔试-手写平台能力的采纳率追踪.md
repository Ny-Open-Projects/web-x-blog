## ARC-849：手写采纳率追踪

**题目**：实现平台能力的采纳率追踪 `AdoptionTracker`：① 能力登记：{ capability(监控 SDK/组件库/构建模板), targetApps(目标应用清单), mandatory(强制/推荐) }；② 采纳状态追踪：各目标应用的采纳状态（adopted/in-progress/not-started）+ 采纳时间；③ 采纳率计算：按能力（adopted/target）与按团队（团队采纳数/目标数）双维；④ 强制能力的门禁联动：mandatory 能力未采纳 → CI 警告 + 到期升级阻断；⑤ 推荐能力的价值证明：采纳方 vs 未采纳方的指标对比（用监控 SDK 的错误发现率更高——数据驱动推广）。写出实现。

```javascript
class AdoptionTracker {
  #capabilities = new Map();
  register({ capability, targetApps, mandatory = false }) {
    this.#capabilities.set(capability, { capability, targetApps: new Set(targetApps),
      mandatory, adoption: new Map() });               // appId -> { status, adoptedAt }
  }
  markAdopted(capability, appId, evidence) {
    const c = this.#capabilities.get(capability);
    if (!c.targetApps.has(appId)) throw new Error(`${appId} 不在目标清单`);
    if (!evidence) throw new Error('采纳需证据 (PR/配置链接)');
    c.adoption.set(appId, { status: 'adopted', adoptedAt: Date.now(), evidence });
  }
  rates() {
    const byCapability = {}, byTeam = {};
    for (const [cap, c] of this.#capabilities) {
      const adopted = [...c.adoption.values()].filter((a) => a.status === 'adopted').length;
      byCapability[cap] = { adopted, target: c.targetApps.size,
        rate: +(adopted / c.targetApps.size * 100).toFixed(0) + '%', mandatory: c.mandatory };
    }
    return { byCapability, overall: avg(Object.values(byCapability).map((x) => parseFloat(x.rate))) };
  }
  enforceDeadlines(now = Date.now()) {
    const escalations = [];
    for (const [cap, c] of this.#capabilities)
      if (c.mandatory && c.deadline && now > c.deadline)
        for (const appId of c.targetApps)
          if (c.adoption.get(appId)?.status !== 'adopted')
            escalations.push({ capability: cap, appId, action: 'CI 阻断' });
    return escalations;
  }
  valueProof(capability, metricApi) {                  // 价值证明: 采纳 vs 未采纳
    const c = this.#capabilities.get(capability);
    const adopted = [...c.adoption.keys()];
    const notAdopted = [...c.targetApps].filter((a) => !adopted.includes(a));
    return {
      adopted: metricApi.avg(adopted, 'errorDiscoveryDays'),
      notAdopted: metricApi.avg(notAdopted, 'errorDiscoveryDays'),
      conclusion: null,   // 采纳方发现错误更快 → 数据驱动推广
    };
  }
}
```

**评分点**：
- 采纳需证据（防口头采纳——PR/配置链接）
- 双维采纳率（按能力/按团队）
- mandatory 的门禁联动（到期阻断——强制力）
- 价值证明的对比分析（采纳 vs 未采纳指标——数据驱动推广）
