## DP-404：购物车模式组合

**答**：
- 购物车模式全景：命令（加购/删改——可撤销）、观察者（购物车变更 → 角标/推荐/结算按钮联动）、策略（价格计算：满减/优惠叠加的计价策略）、备忘录（跨端同步的本地快照）、代理（乐观加购——本地先加服务端确认）
- 计价策略的组合：优惠叠加规则（满减+折扣+运费的叠加顺序）——策略管道（计价规则按序应用——顺序是业务规则）
- 并发一致性：多端购物车同步（乐观写 + 版本号仲裁——服务端版本旧则拉取合并）
- 深水点：购物车的「幂等键」——重复点击加购不重复（skuId+活动 id 幂等）——命令模式与幂等的组合

```javascript
// 计价策略管道 (顺序=业务规则)
const pricingPipeline = [applyFullReduction, applyCoupon, addShipping];
const finalPrice = pricingPipeline.reduce((price, strategy) => strategy(price, cart), basePrice);
// 观察者: cartStore.subscribe(() => { updateBadge(); updateCheckoutBtn(); })
// 幂等: addToCart(skuId, { idempotencyKey: `${skuId}:${activityId}` })
```
