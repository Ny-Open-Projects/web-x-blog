## ARC-628：订阅与自动续费交互
**答**:
- 订阅状态模型：订阅计划（周期/价格/续费方式）+ 状态机（生效中/宽限期/已暂停/已取消——服务端权威）+ 续费记录（扣款历史——ARC-622 流水联动）。
- 关键交互合规：自动续费明示（开通时明确告知扣款周期与金额——合规文案 ARC-571 强制）、扣款前通知（扣款前 N 天提醒——可取消）、取消入口显著（取消流程 ≤ 3 步——合规红线，挽留弹窗有度）、扣款失败处理（宽限期展示 + 补扣引导——支付方式更新入口）。
- 变更流程：升级/降级（按比例折算——服务端计算差价 ARC-582）、暂停与恢复、取消确认（权益终止时间明确展示）。
- 状态同步：扣款结果推送（ARC-394）、订阅状态多端一致（ARC-500）、续费失败的多端提醒优先级（Push/短信按 NODE-453 路由）。
- 体验细节：到期时间展示（精确到日 + 时区 ARC-481）、试用转正提示（试用到期前提醒——转化与合规平衡）。

```javascript
// 订阅状态展示 + 取消流
const sub = await api.subscription();                            // { plan, state, nextChargeAt }
<SubscriptionCard {...sub} onCancel={cancelFlow} />              // 取消 ≤3 步
// 扣款前通知：notify.schedule(sub.nextChargeAt - 3d, '续费提醒', { canCancel: true })
```
