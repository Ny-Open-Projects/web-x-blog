## OPS-268：灰度结束条件怎么定？
**答**：
- 成功定义三层：技术成功（硬指标达标满最小观察窗）、业务成功（守护指标不劣化且主指标达成预期）、验收成功（人工验收清单完成）——三层全绿才算灰度成功，任一缺失不放全量。
- 结束动作绑定：灰度成功 → 自动进入全量放量编排（不等于结束，是最后一档）；灰度失败 → 决策树（SCN-OPS-234）。
- 观察窗的完整性：至少覆盖一个完整的业务周期（工作日+周末各一段）——只在工作日灰度会漏掉周末行为差异。
- 结束报告：灰度总结（各档位指标曲线/决策记录/遗留问题）自动生成归档——灰度知识沉淀（SCN-OPS-248）。
- 追问钩子：为什么观察窗要「覆盖完整业务周期」——用户行为在工作日与周末差异显著（B 端产品尤其）；只在工作日灰度的版本，周末流量模式（低值守+行为差异）下的问题将直接暴露在全量用户——周期覆盖是灰度代表性的最低要求。

```javascript
function graySuccess(gray) {
  const tech = hardMetrics.allPass() && gray.coversCycle(['weekday', 'weekend']);
  const biz = guardMetrics.ok() && mainMetric.met();
  const acceptance = acceptanceChecklist.allPass();
  if (tech && biz && acceptance) return advanceToFull();   // 三层全绿 → 最后一档
  return decisionTree(gray);                               // OPS-234
}
// 结束报告自动归档
archive(grayReport({ stages: gray.stageCurves, decisions: gray.decisionLog }));
```
