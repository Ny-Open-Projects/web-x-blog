## OPS-267：发布全成本怎么算？
**答**：
- 成本构成：机器成本（CI 构建/双版本存储/边缘缓存）、人力成本（审批/盯守/验收的工时）、机会成本（发布窗口占用的值守资源）、风险准备成本（演练/预案维护的摊销）。
- 成本可见的意义：成本账让「发布策略」可优化（比如验收自动化的 ROI）——没有成本账的优化是凭感觉。
- 按发布类型分账：常规发布 vs 大版本发布 vs hotfix 的单位成本差异——hotfix 成本高是「提升质量减少 hotfix」的量化依据。
- 成本趋势：单位发布成本随自动化程度下降——工程化投入的价值曲线。
- 追问钩子：为什么「人力成本」比机器成本更值得算——CI 机器成本通常每月几百元，而一次大版本发布消耗的审批/盯守/验收工时折算数千元；成本账如果只算机器费会误导决策（以为发布很便宜），人力工时才是发布策略的真实约束——ROI 计算必须含人力（SCN-ENG-326 同理）。

```javascript
function releaseCost(release) {
  return {
    machine: ciMinutes * price + dualVersionStorageDays * storagePrice,
    labor: (approvalTime + watchTime + acceptanceTime) / 60 * hourlyRate,
    opportunity: oncallOccupancyHours * oncallRate,
    amortized: drillAndPlaybookCost / releasesPerQuarter,
    perType: compareCost({ normal, major, hotfix }),   // hotfix 最贵 → 质量投资依据
  };
}
```
