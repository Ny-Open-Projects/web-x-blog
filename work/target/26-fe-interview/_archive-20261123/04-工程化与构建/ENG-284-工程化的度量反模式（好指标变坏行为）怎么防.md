## ENG-284：度量反模式怎么防？
**答**：
- 典型坑：覆盖率当 KPI → 写无断言测试凑数；CI 时长当 KPI → 砍重测试；发布频率当 KPI → 小改也频繁发布制造风险。
- 防御设计：指标成组解读（覆盖率必须配变异分数/缺陷逃逸率，SCN-TST 同源）；指标只用于「发现与改进」不直接考核个人（ENG-226）；反指标监控（每个指标配一个「它被操纵了会怎样」的哨兵）。
- 指标 retire：被操纵的指标下线或重定义——保留被博弈的指标等于鼓励博弈。
- 文化防线：度量透明（全员可见口径与公式）——黑箱度量最易被滥用。
- 追问钩子：为什么「覆盖率配变异分数」能防刷数——无断言测试能提高覆盖率但不提高变异分数（ mutants 依然存活）；成组解读让「写空测试刷覆盖」在变异分数上现形，单一指标的可操纵性被对冲。

```javascript
const antiGoodhart = {
  pairs: {
    coverage: 'mutationScore',          // 空测试现形
    ciDuration: 'gateCatches',          // 砍测试现形
    deployFreq: 'changeFailRate+mttr',  // 小改刷频现形
  },
  rules: { noIndividualKPI: true, transparent: true, retireGamed: true },
};
```
