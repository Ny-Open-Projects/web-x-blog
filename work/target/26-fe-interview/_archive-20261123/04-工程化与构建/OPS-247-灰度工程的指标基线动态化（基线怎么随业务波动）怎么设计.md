## OPS-247：基线动态化怎么设计？
**答**：
- 基线失效场景：大促期错误率天然升高/节假日流量结构变化——固定基线会造成灰度误判（全在告警或全不告警）。
- 动态基线：基线取「同时段历史」（同 weekday 同小时 4 周滑动），排除事件时段（SCN-SLA-742 异常检测同手法）——基线随业务节律而动。
- 基线置信：样本不足时段（新功能无历史）基线缺失——降级为「绝对阈值」模式并标注基线不可用。
- 基线审计：基线漂移看板（基线随时间的曲线），基线突变（业务模式变化）告警——基线本身也要被监控。
- 追问钩子：为什么动态基线要「同时段历史」而不是「过去 24 小时均值」——业务指标有强昼夜/周节律（晚间错误率天然高）；24h 均值会把节律抹平，晚间灰度时基线偏低导致全在告警；同 weekday 同小时对比剥离节律，是灰度判定口径正确的关键。

```javascript
function dynamicBaseline(metric, at) {
  const seasonal = pastWeeks(4)
    .filter(w => sameWeekdayHour(w, at) && !inEventWindow(w))   // 同时段 + 排除事件
    .map(w => w[metric]);
  if (seasonal.length < 3)
    return { baseline: absoluteThreshold(metric), note: '样本不足，降级绝对阈值' };
  return { baseline: median(seasonal), ci: confidenceInterval(seasonal) };
}
```
