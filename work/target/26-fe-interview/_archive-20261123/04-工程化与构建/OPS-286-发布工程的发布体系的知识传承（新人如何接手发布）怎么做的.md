## OPS-286：发布知识传承怎么做的？
**答**：
- 传承资产：发布 runbook（操作手册）、预案卡片、案例库、演练剧本——四件套是可传承的知识形态（都在版本管理里）。
- 传承路径：新人读文档 → 旁观发布（影子）→ 副驾驶发布（老人监督）→ 独立发布（带验证期）——渐进授权。
- 知识的活性：runbook 与系统同步更新（发布编排变更必须同步 runbook，门禁项）；案例库持续生长（SCN-OPS-248）。
- 单点防御：发布知识不依赖单个人（bus factor 检查进 ownership 健康度，SCN-ENG-314）——每次发布至少两人熟悉全流程。
- 追问钩子：为什么「副驾驶发布」是传承的关键阶段——直接从旁观跳到独立发布，新人会遇到文档没写的隐性决策点（指标怎么看/什么时候该升级）；副驾驶阶段让隐性知识在真实场景中传递——文档只能传显性知识，隐性知识必须靠共同实践。

```javascript
const knowledgeTransfer = {
  assets: ['runbook', 'playbook-cards', 'case-base', 'drill-scripts'],   // 全在版本管理
  path: ['read-docs', 'shadow-publish', 'copilot-publish', 'solo-with-verification'],
  freshness: { runbookSync: '编排变更必须同步（门禁项）', caseBase: '持续生长' },
  busFactor: min(2, peopleWhoKnowFullFlow()),          // 至少两人熟悉全流程
};
```
