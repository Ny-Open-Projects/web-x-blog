## BLD-291：手写迷你打包器

**需求与边界**：
- 需求：从入口递归构建模块图（识别 import 语句）→ 每模块包装为函数 → 生成 runtime（require 实现 + 缓存）→ 产物单文件。
- 边界：① import 解析用正则/AST 提取（相对路径 resolve 加扩展名）；② 循环依赖不死循环（visited 集合——SCN-BLD-209 部分初始化语义保持）；③ 产物可直接运行（模块注册表 + 缓存单例）。

**答**：
```javascript
import fs from 'fs';
import path from 'path';

function createBundler(entry) {
  const modules = {};                                  // id -> { code, deps }
  const idMap = {};                                    // 相对路径 -> 数字 id
  function build(file, seen = new Set()) {
    const abs = resolve(file);                         // 加 .js 扩展名
    if (abs in idMap) return idMap[abs];               // 循环依赖：返回已有 id（不递归）
    const id = (idMap[abs] = Object.keys(idMap).length);
    const code = fs.readFileSync(abs, 'utf8');
    const deps = [];
    const transformed = code.replace(
      /import\s+\{?\s*([^}]*?)\s*\}?\s*from\s+['"](.+?)['"]/g,
      (_, names, spec) => {
        const depId = build(path.resolve(path.dirname(abs), spec), new Set(seen));
        deps.push({ spec, depId, names });
        return `const {${names}} = __require(${depId});`;   // 转换 import → require
      });
    modules[id] = { transformed, deps };
    return id;
  }
  const entryId = build(entry);
  const bundle = `
    const __modules = { ${Object.entries(modules).map(([id, m]) =>
      `${id}: function (exports, __require) {\n${m.transformed}\n}`).join(',\n')} };
    const __cache = {};
    function __require(id) {                            // 单例缓存（SCN-BLD-208）
      if (__cache[id]) return __cache[id].exports;
      const m = __cache[id] = { exports: {} };
      __modules[id](m.exports, __require);
      return m.exports;
    }
    __require(${entryId});
  `;
  return { bundle, graph: idMap };
}
```

**评分点**:
- 模块图递归构建 + visited 防循环死循环（保留部分初始化语义）。
- import → require 转换 + 依赖 id 映射。
- runtime 三要素（注册表/缓存单例/require 实现）。
- 产物可直接执行（可运行性——不是伪代码）。
