## OPS-305：手写发布决策支持

**需求与边界**：
- 需求：聚合四因子（风险分级/系统健康度/历史相似成功率/日历冲突）输出建议；建议必须可解释（每条建议列依据）；「系统不健康 → DELAY」优先级最高；建议不替代决策（人拍板）。
- 边界：① 相似发布画像匹配维度（触及模块/diff 规模/发布类型）；② 健康度取多指标合取（错误率/性能/依赖健康任一劣化即不健康）；③ 建议置信度随因子数据质量降级。

**答**：
```javascript
function publishAdvice(plan, ctx) {
  const reasons = [], checks = [];
  const health = ctx.health;                           // { errorRate, perfP95, depHealth }
  const unhealthy = health.errorRate > health.baseline * 2
    || health.perfP95 > health.baseline * 1.3 || !health.depHealth.ok;
  checks.push({ name: 'systemHealth', ok: !unhealthy, detail: health });
  if (unhealthy) reasons.push(`系统异常（错误率 ${health.errorRate} vs 基线 ${health.baseline}）`);
  const similar = searchSimilar(plan);                 // { modules, size, type } 匹配
  checks.push({ name: 'history', ok: similar.successRate >= 0.8, detail: similar });
  if (similar.successRate < 0.8) reasons.push(`相似发布成功率仅 ${similar.successRate}`);
  const conflict = ctx.calendar.conflicts(plan.window);
  checks.push({ name: 'calendar', ok: !conflict, detail: conflict });
  if (conflict) reasons.push(`业务日历冲突: ${conflict.type}`);
  const advice = unhealthy ? 'DELAY'
    : !checks.every(c => c.ok) ? 'NARROW-SCOPE'
    : 'PROCEED';
  return { advice, reasons, checks, confidence: dataQuality(checks),
    note: '建议供决策参考，最终由人拍板' };
}
```

**评分点**:
- 带病发布 DELAY 优先级最高（SCN-OPS-283 核心拦截）。
- 四因子合取 + 每因子带 detail（可解释）。
- 相似画像匹配维度明确（模块/规模/类型）。
- 置信度随数据质量降级 + 「建议不替代决策」声明。
