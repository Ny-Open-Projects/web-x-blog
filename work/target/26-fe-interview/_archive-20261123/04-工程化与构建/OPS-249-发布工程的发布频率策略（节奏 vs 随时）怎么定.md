## OPS-249：发布频率怎么定？
**答**：
- 两种模式：固定节奏（每日/每周一次聚合发布——变更批量化，观察窗口固定）vs 随时发布（merge 即发，小变更低风险）——选择取决于变更风险分布与值守能力。
- 折中主流：随时发布小风险（L0/L1）+ 固定节奏聚合大风险（L2/L3）——分级频率（SCN-OPS-202 风险分级驱动频率）。
- 固定节奏的价值：发布流程熟练度（高频演练）、回滚决策肌肉记忆、变更批量归因——低频发布的团队每次发布都是「大事件」。
- 频率度量：DORA 部署频率为目标而非手段——频率提升应来自流程自动化而非强行拆发布。
- 追问钩子：为什么「低频发布团队每次发布都是大事件」是恶性循环——发布稀少 → 流程生疏 → 出事概率高 → 更不敢多发 → 更加生疏；高频小发布把发布变成日常动作（熟练度+小爆炸半径），这是 DORA elite 组织「on-demand deployments」的本质。

```javascript
function releaseCadence(pr) {
  const risk = riskLevel(pr);
  return risk.level === 'L0' || risk.level === 'L1'
    ? 'on-merge (随时)'                                // 小风险随时
    : 'aggregated-window (每日聚合)';                  // 大风险聚合
  // 高频价值: 熟练度 + 小爆炸半径 + 批量归因
}
```
