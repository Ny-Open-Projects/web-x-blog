## ENG-258：发布日历怎么管理？
**答**：
- 发布窗口设计：固定窗口（如工作日 14:00-17:00）——白天有完整值班人力观察，避开周五下午与节前（出事无人接盘）。
- 冲突检测：发布日历与运营活动/大促/封网期联动，同一时段限并发发布数（同时发两个版本出问题无法归因）。
- 紧急发布通道：hotfix 不受窗口限制但需升级审批 + 事后复盘窗口决策合理性。
- 数据回流：发布窗口质量统计（各时段发布的异常率），异常率高的窗口自动封禁。
- 追问钩子：为什么「周五下午禁止发布」是硬规则而非迷信——周五发布的异常会跨越周末，值班人力最薄的 48 小时；数据显示周末事故平均 MTTR 是工作日的 2~3 倍，这是用血换来的日历规则。

```javascript
const releaseCalendar = {
  windows: { allowed: 'Mon-Thu 14:00-17:00', banned: ['friday-afternoon', 'pre-holiday'] },
  conflicts: ['campaign', 'freeze', 'other-releases(max-2-concurrent)'],
  hotfix: { bypass: true, approval: 'escalated', postReview: true },
  quality: (window) => incidentRate(window) > base ? ban(window) : allow,
};
```
