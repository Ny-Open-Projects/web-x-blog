## OPS-309：手写审计链校验

**需求与边界**：
- 需求：校验发布记录——① 留痕完整性（必填字段：触发人/审批链/commit/产物 hash/时间）；② 审批链与风险级别匹配（L3 必须三节点）；③ 灰度绕过统计（bypass 需豁免记录，无豁免 = 违规）；④ 输出合规报告与违规清单。
- 边界：① 产物 hash 校验（与 CDN 实际产物比对——SCN-OPS-246 签名链）；② 审批人不可为申请人（SoD）；③ 绕过带豁免算合规，豁免过期算违规。

**答**：
```javascript
async function releaseAudit(releases, cdnProbe) {
  const violations = [];
  for (const r of releases) {
    const required = ['by', 'approvals', 'commit', 'artifactHash', 'ts'];
    const missing = required.filter(k => r[k] === undefined);
    if (missing.length)
      violations.push({ release: r.id, type: 'MISSING_FIELDS', fields: missing });
    const expected = APPROVAL_TEMPLATES[r.level]?.length ?? 0;
    if ((r.approvals?.length ?? 0) < expected)
      violations.push({ release: r.id, type: 'APPROVAL_SHORT', expected, actual: r.approvals?.length });
    if (r.approvals?.some(a => a.by === r.by))
      violations.push({ release: r.id, type: 'SELF_APPROVAL' });   // SoD
    const actual = await cdnProbe(r.artifactHash);     // 与 CDN 实际产物比对
    if (!actual.match)
      violations.push({ release: r.id, type: 'ARTIFACT_MISMATCH',
        note: '线上产物与留痕 hash 不符——篡改或留痕造假' });
    if (r.grayBypass && (!r.waiver || waiverExpired(r.waiver)))
      violations.push({ release: r.id, type: 'BYPASS_NO_VALID_WAIVER' });
  }
  return {
    complianceRate: 1 - violations.length / releases.length,
    violations: groupBy(violations, 'type'),           // 按类型聚合（流程修订依据）
  };
}
```

**评分点**:
- 五要素留痕校验 + 与 CDN 实际产物比对（签名链闭环——SCN-OPS-246/289）。
- SoD 校验（自批检测）。
- 绕过三态（有豁免合规/豁免过期违规/无豁免违规）。
- 违规按类型聚合（流程修订可导航）。
