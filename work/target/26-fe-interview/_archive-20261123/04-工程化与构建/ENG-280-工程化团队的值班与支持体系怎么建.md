## ENG-280：工程支持体系怎么建？
**答**：
- 三级支持：文档与 FAQ 自助（第一道，覆盖 60%）→ 社区答疑群（champion 用户互助，第二道）→ 平台值班工单（真 bug/权限类，第三道）。
- 工单治理：工单分类统计（使用问题/平台 bug/新需求），「使用问题」回流文档——工单是文档缺口的探测器。
- 防客服化：同类工单 ≥ 3 次必须产出自助方案（工具/文档/自动化），否则平台团队会被答疑吞没。
- 值班响应 SLA：平台故障 P0 15 分钟响应（全团队阻塞面），普通工单 1 工作日。
- 追问钩子：为什么「同类工单 3 次必须自助化」是防客服化的关键规则——答疑的边际成本为零诱惑（答一句很快），但同类问题会无限重复；强制转化规则把「重复答疑」变成「一次建设」，支持量随时间下降而非上升。

```javascript
const supportTiers = [
  { tier: 1, selfServe: 'docs/FAQ', target: '覆盖 60%' },
  { tier: 2, community: 'champion 群', target: '互助消化' },
  { tier: 3, platform: '工单', sla: { p0: '15min', normal: '1d' } },
];
const antiSupport = (ticket) =>
  similarCount(ticket) >= 3 && requireSelfServeSolution(ticket);   // 强制转化
```
