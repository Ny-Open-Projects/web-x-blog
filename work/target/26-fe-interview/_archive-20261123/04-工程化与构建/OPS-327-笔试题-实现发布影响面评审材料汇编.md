## OPS-327：手写评审材料汇编

**需求与边界**：
- 需求：发布评审会的材料自动汇编（SCN-OPS-261）——① 影响面报告（SCN-ENG-203）、② 相似历史案例 Top3（SCN-OPS-248 检索）、③ 回滚预案摘要、④ 待决策清单（评审会上要拍板的选项）——评审只做决策不整理事实。
- 边界：① 案例检索按失败模式标签匹配（不是全文检索）；② 待决策项从「未自动化的判断点」提取（灰度节奏/回滚阈值）；③ 材料页数上限（超限摘要化——评审会不读长文档）。

**答**：
```javascript
async function reviewMaterial(plan) {
  const impact = impactReport(plan);                   // SCN-ENG-203
  const cases = searchCases(plan.failureModeTags)      // 失败模式标签匹配
    .slice(0, 3).map(c => ({ id: c.id, symptom: c.symptom, lesson: c.prevention }));
  const rollback = { entry: plan.rollback.entry, eta: plan.rollback.eta, cost: assessRollbackCost(plan) };
  const decisions = plan.openQuestions.filter(q => !q.autoResolvable)   // 未自动化判断点
    .map(q => ({ question: q.text, options: q.options, default: q.recommended }));
  const material = { impact, cases, rollback, decisions };
  const pages = estimatePages(material);
  if (pages > 3) material.summary = compress(material, { to: 3 });   // 超限摘要化
  return material;
}
```

**评分点**:
- 四段材料（影响面/案例/预案/待决策——SCN-OPS-261 事实前置）。
- 案例按失败模式标签匹配（精准而非全文模糊）。
- 待决策项提取「未自动化判断点」（评审会拍板清单）。
- 页数上限摘要化（评审效率保护）。
