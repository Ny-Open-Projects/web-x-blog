## ENG-250：AI 助手上下文准备怎么做？
**答**：
- 上下文分层：静态层（README/ADR/规范——慢变）+ 结构层（模块依赖图/API 导出清单——构建期生成）+ 动态层（当前任务相关文件——检索）——按变频率管理。
- 仓库地图生成：CI 产出模块清单/导出面/依赖图摘要（结构化 JSON），AI 助手用地图定位再精读——全文喂给模型既贵又超窗。
- 检索质量：代码检索用符号级（函数/类名）优于文本级；语义索引（embedding）补充「概念性查找」（"哪里处理退款"）。
- 上下文预算：任务模板声明所需上下文上限，超限引导拆任务（SCN-ENG-214 规则预算同源）。
- 追问钩子：为什么「先地图后精读」优于「关键词全文检索」——全文检索返回大量近似文件淹没关键上下文；依赖图地图先锁定模块边界，再读边界内文件，命中率与 token 成本都优一个数量级。

```javascript
// CI 生成仓库地图（供 AI 上下文）
const map = {
  packages: packages.map(p => ({ name: p, exports: exportsOf(p), deps: depsOf(p) })),
  adrIndex: listAdr(),
};
writeJson('.ai/repo-map.json', map);
// 助手流程: map -> 定位模块 -> 精读文件 -> 生成
```
