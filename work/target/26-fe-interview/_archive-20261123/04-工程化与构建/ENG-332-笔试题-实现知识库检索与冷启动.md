## ENG-332：手写知识库检索

**需求与边界**：
- 需求：`fe how <query>` ——① 分词检索 ADR/案例库（标题权重 > 正文）；② 状态过滤（superseded 的 ADR 降权并标注）；③ 输出 Top5 + 每条摘要行（状态/日期/一句话结论）；④ 零命中时提示「提交为新案例」。
- 边界：① TF 简易打分（标题 ×3 权重）；② superseded 结果显示最新生效版本（链上溯）；③ 大小写/中英混排分词容错。

**答**：
```javascript
function feHow(query, corpus) {
  const terms = query.toLowerCase().split(/[\s,]+/).filter(Boolean);
  const scored = corpus.map(doc => {
    const titleHits = terms.filter(t => doc.title.toLowerCase().includes(t)).length;
    const bodyHits = terms.filter(t => doc.body.toLowerCase().includes(t)).length;
    let score = titleHits * 3 + bodyHits;
    let status = doc.status, note = '';
    if (doc.status === 'superseded') {                 // 链上溯到最新生效
      const latest = followSupersedeChain(doc);
      score *= 0.3;                                    // 降权但不隐藏（演进有价值）
      note = `已被 ${latest.id} 取代 → ${latest.oneLiner}`;
    }
    return { id: doc.id, title: doc.title, status, score, note, oneLiner: doc.oneLiner };
  }).filter(s => s.score > 0)
    .sort((a, b) => b.score - a.score).slice(0, 5);
  return scored.length ? scored
    : { empty: true, hint: '未命中，考虑提交为新案例（fe how --add）' };
}
```

**评分点**:
- 标题加权 TF 打分（标题命中价值高于正文）。
- superseded 降权 + 链上溯显示最新生效（不误导，ENG-272）。
- 零命中引导提交新案例（知识库生长机制）。
- Top5 + 一句话结论（检索结果可扫读）。
