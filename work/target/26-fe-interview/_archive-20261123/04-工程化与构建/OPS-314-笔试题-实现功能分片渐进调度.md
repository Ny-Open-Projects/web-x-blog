## OPS-314：手写功能分片调度

**需求与边界**：
- 需求：大功能拆片（slices+depends+risk）——① 按风险升序 + 依赖拓扑决定开启顺序；② 每片独立灰度进度追踪；③ 片依赖未满足时置灰（不可开启）；④ 全片完成后检查「flag 收敛」（提示代码化，SCN-OPS-254）。
- 边界：① 风险升序与依赖拓扑冲突时依赖优先（依赖是硬约束）；② 每片灰度门槛独立（低风险片可快速全量）；③ 收敛检查含「片 flag 引用统计」（还有多少代码引用）。

**答**：
```javascript
function sliceScheduler(slices, grays) {
  const order = slices.slice().sort((a, b) =>
    (b.depends.includes(a.id) ? -1 : a.riskRank - b.riskRank));   // 依赖硬约束优先，再按风险升序
  return order.map(s => {
    const depsReady = s.depends.every(d => grays[d]?.stage === 100);
    const gray = grays[s.id];
    return {
      id: s.id, risk: s.risk,
      enabled: depsReady && gray?.stage > 0,           // 依赖未满足 → 置灰
      grayStage: gray?.stage ?? 0,
      nextGate: depsReady ? gray?.nextGate : `依赖未就绪: ${s.depends}`,
      cleanupHint: null,
    };
  }).map(item => {
    if (item.grayStage === 100) {                      // 全量完成 → 收敛检查
      const refs = countFlagRefs(item.id);
      item.cleanupHint = refs > 0
        ? `flag 仍有 ${refs} 处引用，建议代码化（SCN-OPS-224）` : '可移除 flag';
    }
    return item;
  });
}
```

**评分点**:
- 依赖硬约束优先于风险排序（拓扑正确性）。
- 依赖未就绪置灰（不可开启的分片不冒进）。
- 每片独立灰度进度与门槛（低风险快速通道）。
- 全量后收敛检查（flag 引用统计 → 代码化提示）。
