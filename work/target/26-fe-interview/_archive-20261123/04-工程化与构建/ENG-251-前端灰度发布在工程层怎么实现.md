## ENG-251：前端灰度发布怎么实现？
**答**：
- 产物级灰度：HTML 入口按规则返回不同版本入口（v1/v2 chunk 清单）——同一资源池两个版本共存，切换只改 HTML 引用，回滚秒级。
- 灰度规则中心：按用户 ID 哈希百分比/地域/设备/白名单，规则配置中心下发，网关或 SSR 层执行（前端不自行判断灰度，防篡改）。
- 灰度观察：两版本的核心指标对比（错误率/性能/转化）自动看板，异常自动回切。
- 灰度卫生：灰度期限制（不超过 7 天必须全量或回退），避免长期双版本维护成本。
- 追问钩子：为什么灰度切「HTML 引用」而不是「CDN 路径重写」——HTML 是唯一不被缓存稳定更新的锚点；产物 immutable（SCN-ENG-241），切入口文件即可切换整版本，回滚 = 切回旧入口，不需要刷新任何 hash 资源。

```javascript
// SSR/网关层灰度路由
function resolveEntry(user, { rules }) {
  const v = rules.find(r => matchRule(r, user))?.version ?? 'stable';
  return entryManifest[v];           // /entries/index-v2-abc123.html
}
// 灰度看板
compareBoards('v1', 'v2', ['errorRate', 'ttiP75', 'conversion']);
```
