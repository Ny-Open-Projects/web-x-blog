## OPS-204：灰度节奏怎么定？
**答**：
- 准入门槛：灰度前必须完成——冒烟通过/降级预案就位/哨兵配置/回滚演练（未演练不灰度）；灰度是控制爆炸半径，不是替代测试。
- 放量节奏：1% → 5% → 25% → 50% → 100%，每档最小停留（观察窗口）随档位缩短（首档 24h，末档 2h）；每档放量的准入门指标（错误率不高于基线）。
- 自动放量 vs 手动：硬指标自动判定（错误率达标自动进下一档），软指标人工确认——自动化放速度，人工守边界。
- 放量与封网协调：灰度跨越封网期怎么办——灰度暂停（保持当前档位）而非回滚，封网后继续。
- 追问钩子：为什么「未演练不灰度」——灰度的价值依赖回滚可用；回滚流程半年没跑过，灰度出事时回滚本身可能失败，等于把单点故障换成了复合故障；演练是灰度的保险单。

```javascript
const rampPlan = {
  gates: { entry: ['smoke-pass', 'rollback-drilled', 'sentinel-ready'] },
  stages: [{ pct: 1, dwell: '24h' }, { pct: 5, dwell: '12h' },
           { pct: 25, dwell: '6h' }, { pct: 50, dwell: '4h' }, { pct: 100 }],
  autoAdvance: (gate) => gate.errorRate <= baseline.errorRate,   // 硬指标自动
  manualGate: ['conversion', 'satisfaction'],                    // 软指标人工
  freezePolicy: 'pause-at-current-stage',                        // 封网暂停不回滚
};
```
