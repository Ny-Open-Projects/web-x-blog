## OPS-239：灰度看板怎么设计？
**答**：
- 核心视图：双列对比（灰度组 vs 基线）——指标按「硬指标（错误/崩溃/性能，自动判红绿）」与「业务指标（转化，看趋势不下结论）」分区；每指标显示当前值/基线/差值/置信状态。
- 放量决策视图：当前档位/停留时长/下一档门槛达成情况——看板直接回答「能不能放量」。
- 异常详情联动：指标红点点击下钻到错误明细（错误类型 Top5/受影响用户样本）——看板不是终点，是排障入口。
- 快照导出：灰度日报自动生成（对比快照+决策建议）——跨班次灰度交接的数据载体（SCN-OPS-210）。
- 追问钩子：为什么业务指标「看趋势不下结论」而硬指标「自动判红绿」——硬指标（错误率）有明确基线可自动判定；业务指标（转化）受季节/运营活动影响大，1% 流量的转化差异噪声远大于信号——把它交给统计检验与更大样本，看板只呈现趋势，防止小样本误判驱动错误放量决策。

```javascript
const grayBoard = {
  hard: { errorRate: autoVerdict, crashRate: autoVerdict, ttiP75: autoVerdict },   // 自动红绿
  biz: { conversion: trendOnly },                      // 趋势不结论
  ramp: { stage, dwellLeft, nextGateReady },           // 能否放量
  drill: (metric) => errorDetails(metric),             // 红点下钻排障
  daily: grayReportSnapshot(),                         // 交接载体
};
```
