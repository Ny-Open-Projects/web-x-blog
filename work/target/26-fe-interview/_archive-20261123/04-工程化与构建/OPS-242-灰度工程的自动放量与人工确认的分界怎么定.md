## OPS-242：自动/人工分界怎么定？
**答**：
- 分界原则：可自动判定的指标（错误率/崩溃/性能与基线比较）驱动自动放量；需要业务判断的（转化波动/客诉情绪/策略风险）必须人工——自动化处理「客观」，人工处理「主观」。
- 自动放量的护栏：自动放量有上限（最多到 25% 自动，25% 以上必须人工确认）——自动化失控时的最大损失可限定。
- 人工确认的便捷性：确认动作一键化（看板直接按钮），确认超时默认维持当前档（不自动放量也不回滚）——人工是守门员不是瓶颈。
- 混合模式记录：每次放量记录「自动判定依据 + 人工/自动决策者」——放量的可解释性。
- 追问钩子：为什么自动放量要设「25% 上限」——自动化的判定依据是历史基线对比，无法覆盖未知风险（新功能的业务副作用）；25% 以内爆炸半径可控，超过之后错误的自动放量影响面放大——用上限给自动化「兜底即止损」的边界。

```javascript
function nextStageDecision(gray) {
  const hardOk = hardMetrics.pass();                   // 客观指标自动判定
  if (!hardOk) return { action: 'hold', reason: hardMetrics.fails };
  if (gray.nextPct <= 25 && gray.dwellDone)
    return { action: 'auto-advance', basis: hardMetrics.report };   // ≤25% 自动
  return { action: 'await-human', default: 'hold',     // 人工确认，超时维持
           summary: grayBoard.daily() };
}
```
