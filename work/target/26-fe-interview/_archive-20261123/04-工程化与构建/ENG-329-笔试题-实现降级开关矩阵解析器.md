## ENG-329：手写降级矩阵解析器

**需求与边界**：
- 需求：解析降级矩阵配置（L1~L4 每档动作清单：off/remove/replace），档位变更时 diff 出要执行的动作（升档执行新增动作，降档恢复）；「只升不降」除非显式 rollback；动作校验（引用的模块/开关必须存在）。
- 边界：① 档位间动作继承（L3 包含 L1+L2 动作）；② 降档恢复按「当前生效动作集」逆向；③ 配置 schema 校验（动作类型白名单）。

**答**：
```javascript
function degradeMatrix(config, current, next, { rollback = false } = {}) {
  const RANK = { L0: 0, L1: 1, L2: 2, L3: 3, L4: 4 };
  if (RANK[next] < RANK[current] && !rollback)
    return { rejected: true, note: '降档需显式 rollback（防误回退扩大故障）' };
  const actionsAt = (l) => {                           // 档位继承：累积动作
    const acc = {};
    for (let i = 1; i <= RANK[l]; i++)
      Object.assign(acc, config[`L${i}`] ?? {});
    return acc;
  };
  const cur = actionsAt(current), nxt = actionsAt(next);
  const toApply = Object.entries(nxt).filter(([k]) => !(k in cur));
  const toRestore = Object.entries(cur).filter(([k]) => !(k in nxt));
  // 配置校验
  const errors = [];
  for (const [, action] of [...toApply, ...toRestore]) {
    if (!['off', 'remove', 'replace'].includes(action.type))
      errors.push({ code: 'BAD_ACTION_TYPE', action });
    if (action.target && !moduleExists(action.target))
      errors.push({ code: 'TARGET_MISSING', action });
  }
  return { rejected: false, toApply, toRestore, errors };
}
```

**评分点**:
- 档位动作继承（L3 = L1+L2 累积，ENG-894 一致）。
- 只升不降 + 显式 rollback 通道。
- diff 执行（升档 apply / 降档 restore 逆向）。
- 动作类型白名单 + 目标存在性校验（配置 fail-fast）。
