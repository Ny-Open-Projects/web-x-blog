## OPS-318：手写知识传承检查

**需求与边界**：
- 需求：检查发布知识传承状态——① bus factor（能独立发布的人数 < 2 告警，SCN-OPS-286）；② 传承路径进度追踪（每人处于 read/shadow/copilot/solo 哪个阶段）；③ 知识资产活性（runbook 最后更新距编排最后变更的间隔——漂移检测）。
- 边界：① 「独立发布」判定 = 近 90 天 solo 发布 ≥1 次且无重大失误；② 资产活性按文件粒度（runbook 某章节漂移定位到章节）；③ 传承瓶颈（多人卡在 copilot 阶段）输出培训建议。

**答**：
```javascript
function transferCheck(publishers, runbook, lastOrchChange, { soloWindow = 90 } = {}) {
  const solo = publishers.filter(p =>
    p.releases.filter(r => r.mode === 'solo' && withinDays(r.ts, soloWindow)).length >= 1
    && !p.majorMistake);                               // solo 判定：近期独立且无重大失误
  const busFactor = solo.length;
  const stages = publishers.map(p => ({
    name: p.name, stage: p.currentStage,
    stuckDays: p.currentStage === 'copilot' ? daysInStage(p) : 0,
  }));
  const stuck = stages.filter(s => s.stage === 'copilot' && s.stuckDays > 30);
  // 资产活性：漂移检测
  const drift = runbook.sections.filter(sec =>
    sec.relatedOrchChanges.some(c => c.ts > sec.lastVerified));   // 编排变更晚于验证
  return {
    busFactor, alert: busFactor < 2 ? { fix: '培养第二 solo 发布人' } : null,
    stages, training: stuck.length ? `副驾驶阶段超 30 天: ${stuck.map(s => s.name)}，安排专项带教` : null,
    assetDrift: drift.map(d => ({ section: d.title, fix: '按最新编排变更更新' })),
  };
}
```

**评分点**:
- bus factor 用「近期 solo 且无重大失误」的活跃口径（名单过期防御）。
- 传承四阶段进度 + 卡点检测（copilot 超 30 天 → 专项带教）。
- 资产漂移按章节粒度（编排变更晚于验证即漂移——SCN-OPS-286 活性）。
- 每项输出带修复动作。
