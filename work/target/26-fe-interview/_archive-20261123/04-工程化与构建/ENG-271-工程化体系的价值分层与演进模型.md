## ENG-271：工程化演进四阶段是什么？
**答**：
- L0 脚本期：个人 dotfiles/零散脚本——能力在人身上，人走能力走。
- L1 规范期：统一 lint/构建模板/基础 CI——能力进仓库，新人可复现（可复现是 L1 的验收线）。
- L2 平台期：monorepo 治理/自服务平台/度量闭环——能力有护栏与度量，规模化复用。
- L3 智能期：AI 深度融入（生成/评审/诊断）+ 数据驱动的工程决策——能力自动进化。
- 判定方式：看「关键工程动作是否依赖特定个人」——依赖个人是 L0/L1，看板与平台承载是 L2，自动闭环是 L3。
- 追问钩子：为什么「可复现」是 L0 到 L1 的分水岭——L0 的知识在人的脑子里（环境靠口口相传），L1 的核心是把环境与流程固化到仓库（devcontainer/一键 setup），任何人 clone 即可工作——能力从「人」迁移到「仓库」。

```javascript
const maturity = {
  L0: { signal: '环境靠口传', risk: 'bus-factor=1' },
  L1: { signal: 'clone 即可构建 + CI 门禁', gate: '一键 setup ≤ 15min' },
  L2: { signal: '自服务平台 + DORA 看板 + 治理护栏' },
  L3: { signal: 'AI 生成/评审/诊断进流水线，指标驱动演进' },
  assess: (team) => criticalActionsDependOnPersons(team) ? 'L0/L1' : 'L2+',
};
```
