## OPS-304：手写动态基线

**需求与边界**：
- 需求：给定指标历史与事件日历，计算「同时段」动态基线——筛选同 weekday+hour 的历史值、排除事件窗口、输出中位数 + 置信区间；样本不足降级绝对阈值。
- 边界：① 时区一致性（同时段按目标地域时区对齐——SCN-OPS-221）；② 事件排除含「事件前后缓冲」（活动影响的尾巴）；③ 基线漂移检测（本周基线 vs 上月基线偏离 >30% 告警——业务模式变化）。

**答**：
```javascript
function dynamicBaseline(history, at, eventCalendar, { tz, weeks = 4, buffer = 2 * 3600_000 } = {}) {
  const target = sameWeekdayHour(ts => ts, at, tz);    // 时区对齐的「同时段」
  const samples = history.filter(h =>
    matches(h.ts, target, tz)
    && !eventCalendar.within(h.ts, { buffer }));       // 事件含前后缓冲排除
  if (samples.length < 3)
    return { fallback: ABSOLUTE[metric], note: '样本不足' };
  const values = samples.map(s => s.value).sort((a, b) => a - b);
  const med = median(values);
  const ci = [values[Math.floor(values.length * 0.25)],
              values[Math.ceil(values.length * 0.75) - 1]];   // IQR 置信带
  // 基线漂移检测
  const prevBaseline = baselineCache.get(metric, shiftWeeks(at, 4));
  if (prevBaseline && Math.abs(med - prevBaseline) / prevBaseline > 0.3)
    alert({ type: 'BASELINE_DRIFT', metric, med, prevBaseline,
      note: '业务模式变化，复核基线适用性' });
  return { baseline: med, ci };
}
```

**评分点**:
- 时区对齐的「同时段」（SCN-OPS-221 全球适配）。
- 事件排除含前后缓冲（活动影响尾巴）。
- IQR 置信带（小样本不确定性显式化）。
- 基线漂移告警（基线自身被监控——SCN-OPS-247）。
