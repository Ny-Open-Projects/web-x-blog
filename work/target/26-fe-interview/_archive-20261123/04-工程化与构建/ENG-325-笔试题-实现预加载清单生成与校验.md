## ENG-325：手写预加载清单

**需求与边界**：
- 需求：从构建 manifest 生成预加载编排——① 入口静态依赖链的全部 chunk modulepreload；② 字体 preload 带 crossorigin（SCN-ENG-241 双重下载坑）；③ 首屏图片 fetchpriority 标注；④ 校验：清单内文件全部存在于产物（防引用悬空）。
- 边界：① 深度限制（依赖链超过 N 层不预载，防预载爆炸）；② 动态导入不预载（运行时按需）；③ 字体自动识别（woff/woff2）并补 crossorigin。

**答**：
```javascript
function preloadPlan(manifest, { maxDepth = 3 } = {}) {
  const tags = [], errors = [];
  const walk = (entry, depth = 0, seen = new Set()) => {
    if (depth > maxDepth || seen.has(entry)) return;   // 深度限制防爆炸
    seen.add(entry);
    for (const dep of manifest[entry].imports ?? []) {
      tags.push(`<link rel="modulepreload" href="${dep.file}">`);
      walk(dep.file, depth + 1, seen);
    }
  };
  walk(manifest.entry);
  for (const asset of manifest.assets) {
    if (/\.woff2?$/.test(asset.file))
      tags.push(`<link rel="preload" href="${asset.file}" as="font" type="font/woff2" crossorigin>`);   // 必须 crossorigin
    if (asset.hero)                                    // 首屏图标记
      tags.push(`<img src="${asset.file}" fetchpriority="high">`);
  }
  for (const tag of tags) {                            // 悬空校验
    const file = tag.match(/href="([^"]+)"/)?.[1];
    if (file && !existsInDist(file)) errors.push({ tag, file });
  }
  return { tags, errors };
}
```

**评分点**:
- 静态依赖链遍历 + 深度限制（预载爆炸防御）。
- 字体 crossorigin 自动补（双重下载坑的工程化修复）。
- 动态导入排除（按需加载语义保留）。
- 悬空引用校验（HTML 与产物一致性，SCN-ENG-241 发布一致性）。
