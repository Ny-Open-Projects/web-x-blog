## BLD-280：可信赖构建收束
**答**：
- 正确性主线：增量一致性验证/产物 lint/多目标行为一致/可预测性回归（BLD-266/235/278/252）——产物正确性的验证体系。
- 可信主线：provenance 签名链/contenthash 输入完整性/确定性治理/secret 扫描（BLD-279/274/254/263）——产物可信与供应链安全。
- 效率主线：调度器/懒编译/内存治理/缓存键对齐（BLD-272/275/253/251）——速度与资源的可持续优化。
- 面试答法：「可信赖构建」= 正确性（产物语义符合预期）× 可信性（产物来源可验证）× 可持续（速度与资源可运营）——三者缺一，构建体系就只完成了一半。

```javascript
const trustworthyBuild = {
  correctness: ['incremental-invariant', 'artifact-lint', 'multi-target-consistency'],
  trust: ['provenance-chain', 'hash-input-complete', 'determinism', 'secret-scan'],
  efficiency: ['scheduler-critical-path', 'lazy-compile', 'cache-key-align'],
};
```
