## ENG-274：技术雷达怎么运营？
**答**：
- 四环语义：采纳（默认选型）/试验（有边界地用）/评估（调研中）/暂缓（明确不推荐及原因）——关键价值在「暂缓环的理由」而非新工具罗列。
- 运营节奏：季度评审会（工具状态变迁需提案 + 试验报告）；状态迁移必须带证据（试验环 → 采纳环需要试点数据）。
- 防形式主义：雷达不超过 ~40 项（超了说明是清单不是决策）；每项带 owner 与「下季度动作」。
- 与工程落地联动：雷达状态约束技术选型（采纳环之外的技术进生产需要豁免评审）。
- 追问钩子：为什么「暂缓环的理由」是雷达最值钱的部分——团队真正的选型分歧不在「用什么」而在「为什么不用某物」；暂缓理由记录了权衡结论，防止同一工具每年被重新提一遍。

```javascript
const techRadar = {
  rings: ['adopt', 'trial', 'assess', 'hold'],
  move: (tool, from, to) => requireEvidence(tool),   // 状态迁移要证据
  cap: 40,                                            // 超量即清单不是决策
  hold: { reason: required, note: '最值钱的部分' },
  enforce: (tech) => ringOf(tech) !== 'adopt' && inProduction(tech)
    ? requireWaiver(tech) : ok,
};
```
