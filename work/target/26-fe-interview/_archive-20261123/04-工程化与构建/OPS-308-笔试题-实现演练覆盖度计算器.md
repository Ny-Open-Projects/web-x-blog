## OPS-308：手写演练覆盖度

**需求与边界**：
- 需求：三层覆盖（场景/流程/角色）滚动计算（近 N 月）；演练债务清单（未演练的故障模式按风险排序）；覆盖度与真实事故对照（演练覆盖的模式处置更顺利——价值验证）。
- 边界：① 滚动窗口（按月衰减防高估，SCN-OPS-279）；② 角色覆盖含「参与深度」（旁观不算）；③ 债务排序 = 风险等级 × 时间未覆盖。

**答**：
```javascript
function drillCoverage(drills, failureModes, runbookSteps, roles,
  { windowMonths = 1 } = {}) {
  const cutoff = Date.now() - windowMonths * 30 * 864e5;
  const recent = drills.filter(d => d.ts > cutoff);
  const coveredModes = new Set(recent.flatMap(d => d.scenarios));
  const scenario = coveredModes.size / failureModes.length;
  const process = runbookSteps.filter(s =>
    recent.some(d => d.steps.includes(s.id))).length / runbookSteps.length;
  const role = roles.filter(r =>
    recent.some(d => d.participants.some(p => p.role === r.role && p.depth === 'executor')))
    .length / roles.length;                            // executor 深度才算
  const debt = failureModes
    .filter(m => !coveredModes.has(m.id))
    .sort((a, b) => b.riskLevel * monthsSinceLastDrill(b) - a.riskLevel * monthsSinceLastDrill(a));
  // 价值验证：演练覆盖模式 vs 未覆盖模式的事故 MTTR 对比
  const incidentsByCoverage = groupBy(recentIncidents(), i =>
    coveredModes.has(i.failureMode) ? 'covered' : 'uncovered');
  return {
    scenario, process, role,
    health: (scenario + process + role) / 3,
    debt,
    valueProof: {
      coveredMttr: median(incidentsByCoverage.covered?.map(i => i.mttr) ?? []),
      uncoveredMttr: median(incidentsByCoverage.uncovered?.map(i => i.mttr) ?? []),
    },
  };
}
```

**评分点**:
- 三层覆盖 + 滚动窗口（衰减防高估——SCN-OPS-279）。
- 角色覆盖按参与深度（executor，旁观不算）。
- 债务排序 = 风险 × 未覆盖时长（利息模型同构）。
- 价值验证（covered/uncovered MTTR 对比——覆盖度有用性的实证）。
