## BLD-283：体积异常检测怎么做？
**答**：
- 异常定义：单 PR 引起的跳变（bundle diff 直接可见——SCN-ENG-290）vs 缓慢劣化（多 PR 累积——单 PR 都在阈值内）vs 结构性异常（某 chunk 突然膨胀——依赖变化）。
- 检测方法：趋势检测（滚动基线 + 斜率——SCN-SLA-723 缓变检测同构）、离群检测（chunk 体积分布的 3σ）、重复模式（新增多版本依赖——SCN-ENG-293）。
- 与预算的关系：预算是「硬门槛」（超了拦），异常检测是「软哨兵」（趋势预警——在硬门槛触发前发现问题）。
- 追问钩子：为什么「缓慢劣化」比「单 PR 跳变」更危险——单 PR 跳变被 diff 门禁拦截（PR 作者当场解决）；缓慢劣化是每个 PR +20KB（都在阈值内），半年后产物翻倍无人察觉——趋势检测（斜率超阈值）是防「温水煮青蛙」的唯一手段，Ratchet（SCN-ENG-291）是它的硬约束版。

```javascript
// 缓变检测（滚动斜率）
const slope = linearRegression(last30Builds.map(b => b.size)).slope;
if (slope > dailyGrowthLimit) alert({ type: 'SIZE_CREEP', slope });
// 结构异常
const outlier = chunkSizes.find(s => Math.abs(zScore(s)) > 3);
```
