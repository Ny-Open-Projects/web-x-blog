## ENG-310：手写字体子集管线校验

**需求与边界**：
- 需求：校验字体切片（unicode-range 分片）能否覆盖站点实际用到的字符集——① 扫描源码/文案库的实际字符；② 每字符映射到分片；③ 未覆盖字符告警（会 fallback 到系统字体，视觉跳变）；④ 输出冗余分片（零使用的 range）。
- 边界：① 字符集来源：静态文案 + 动态数据字典（服务端下发的可能文案）；② emoji/surrogate pair 按码点（非 UTF-16 单元）扫描；③ 冗余分片体积量化。

**答**：
```javascript
function fontCoverage(fontSlices, charSources, { dynamicDicts = [] } = {}) {
  const chars = new Set();
  for (const src of [...charSources, ...dynamicDicts])
    for (const ch of src) chars.add(ch.codePointAt(0));   // 码点级（emoji 安全）
  const sliceOf = (cp) => fontSlices.find(s =>
    s.ranges.some(([a, b]) => cp >= a && cp <= b));
  const uncovered = [], usage = new Map();
  for (const cp of chars) {
    const slice = sliceOf(cp);
    if (!slice) uncovered.push(cp);                   // 会 fallback 系统字体
    else usage.set(slice.id, (usage.get(slice.id) ?? 0) + 1);
  }
  const unused = fontSlices.filter(s => !usage.get(s.id))
    .map(s => ({ id: s.id, sizeKB: s.sizeKB }));      // 冗余分片
  return {
    uncoveredChars: uncovered.slice(0, 50),
    uncoveredCount: uncovered.length,
    unusedSlices: unused, savingKB: unused.reduce((s, u) => s + u.sizeKB, 0),
    suggest: uncovered.length ? '扩充分片 range 或将动态字典纳入子集化输入' : null,
  };
}
```

**评分点**:
- 码点级扫描（surrogate pair 正确，ENG-805 同意识）。
- 动态字典纳入输入（服务端文案的覆盖盲区）。
- 冗余分片量化（下载体积优化可执行）。
- 未覆盖字符告警带修复建议。
