## ENG-241：静态资源缓存工程化怎么做？
**答**：
- 基础矩阵：内容 hash 文件名 + `Cache-Control: immutable, max-age=31536000`（一年强缓存）；HTML 不缓存或 short max-age——「hash 文件强缓存 + HTML 短缓存」是万能底座。
- 预加载编排：关键 chunk modulepreload、字体 preload（crossorigin 别忘）、首屏图片 fetchpriority——预加载清单由构建器生成（入口依赖图），不手写。
- 发布一致性：HTML 与新资源同步发布（先发资源后切 HTML），回滚时旧 hash 资源仍在（immutable 好处：历史版本永久可用）。
- 缓存污染防御：构建期校验「HTML 引用的资源全部存在」；CDN 缓存刷新只针对 HTML。
- 追问钩子：为什么字体 preload 忘 crossorigin 会双重下载——preload 匹配请求凭 crossorigin 属性，字体 fetch 默认 anonymous 模式，不带 crossorigin 的 preload 是另一条缓存记录，等于下了两次。

```html
<!-- 构建器生成的预加载编排 -->
<link rel="modulepreload" href="/assets/index-abc123.js">
<link rel="preload" href="/fonts/noto.woff2" as="font" type="font/woff2" crossorigin>
<img src="/hero.webp" fetchpriority="high">
```
```
# nginx
location /assets/ { add_header Cache-Control "public, immutable, max-age=31536000"; }
location = /index.html { add_header Cache-Control "no-cache"; }
```
