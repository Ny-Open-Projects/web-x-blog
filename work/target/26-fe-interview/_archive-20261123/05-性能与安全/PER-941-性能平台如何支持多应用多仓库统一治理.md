## PER-941：性能平台如何支持多应用/多仓库统一治理

**答**：
- 注册制：应用接入平台即注册（仓库、路由清单、构建产物地址），平台定期同步路由与 Owner。
- 统一门禁模板：共享 budget 模板 + 应用可覆盖字段，避免每个仓库自写一套配置漂移。
- 全局视角：全站总榜（应用×页面健康度）、跨应用公共问题（如所有应用都在用的某个劣化 SDK）提升为基础设施专项。
- 成本分摊：SDK 与平台维护成本按接入应用数分摊，激励复用而非自建。

```javascript
// 应用注册与统一门禁
const BASE_BUDGET = { js: 350, css: 80, lcp: 2500 };
const apps = {
  shop:   { repo: 'fe-shop',   override: { js: 400 } },  // 图表多，放宽
  im:     { repo: 'fe-im',     override: { lcp: 2000 } }, // IM 首屏更严格
};
function budgetOf(app) {
  return { ...BASE_BUDGET, ...apps[app].override };
}
// CI 读取 budgetOf(appName)，模板统一、覆盖显式可审计
```
