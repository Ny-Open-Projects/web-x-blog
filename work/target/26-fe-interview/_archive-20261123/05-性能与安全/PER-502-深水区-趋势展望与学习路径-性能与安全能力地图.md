## PER-502：性能与安全能力地图与持续学习路径（收官）？

**答**:
- 能力树五枝（本目录 500 题的知识地图）：① 度量枝——CWV 语义/Event Timing/LoAF/采样与分位数（PER-203~262/229/243/454）；② 优化枝——渲染管线/调度/内存/弱网/存储（PER-281~341/403~410/436~442）；③ 归因枝——拆段归因/版本对照/因果推断/自动化 Retainer（PER-293~302/428~430/451）；④ 安全枝——CSP/SRI/供应链/存储安全/隐私合规（PER-303~317/357~364/411~412/446/490）；⑤ 体系枝——指标注册/预算/告警/实验/组织（PER-335~344/413~425/465~500）。
- 持续学习路径：官方信源（web.dev/vitals-changelog、Chrome DevTools Blog、W3C WebPerf WG Draft）季度扫读；新技术验证节奏（新 API 先在影子环境验证再进生产基线）；年度能力自评（PER-460 矩阵）定学习重点。
- 2026 视角的趋势关注点：INP 后的下一候选指标（渲染侧）、CSS scroll-driven animations 的普及、Speculation Rules 的生态成熟、H3 全面普及对采集口径的影响、隐私沙盒对 RUM 标识的冲击——保持"口径演进敏感度"（PER-419/250）。
- 收官寄语：性能与安全的终局不是"记住答案"而是"建立度量-归因-修复-防线的循环"——本目录 500 题是这个循环在每个角落的展开。

```text
性能与安全能力树（500 题知识地图）：
① 度量枝：CWV 语义 / Event Timing / LoAF / 采样与分位数
② 优化枝：渲染管线 / 调度 / 内存 / 弱网 / 存储

学习路径：web.dev + DevTools Blog 季扫；新 API 影子环境先行；年度能力自评（PER-460）
2026 关注：下一候选指标 / scroll-driven animations / Speculation Rules 成熟 / H3 口径影响 / 隐私沙盒冲击
终局：度量-归因-修复-防线的循环 —— 500 题是这个循环的展开
```
