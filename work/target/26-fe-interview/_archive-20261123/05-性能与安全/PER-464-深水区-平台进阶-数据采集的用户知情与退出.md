## PER-464：性能采集的隐私声明粒度与退出权实现？

**答**:
- 知情粒度：隐私声明要说清"采什么"（性能指标/交互时长/DOM 结构回放）、"不含什么"（输入内容/精确位置）、"保留多久"（明细 14 天）——声明粒度与实际采集严格一致（采集清单变更 = 声明变更同步）。
- 退出权实现：设置项"关闭性能数据收集"→ SDK 配置中心（PER-423）即时生效（停采集 + 清本地缓冲 + 通知其他标签页）；已采集数据的删除请求——按设备/会话标识清理（PER-446）；退出状态持久化（localStorage），跨会话尊重。
- 技术细节：退出后 SDK 仍需"空转"（错误边界等功能依赖的钩子保留，仅数据出口关闭）；退出不是"不初始化"（页面功能可能依赖 SDK 的非采集能力）——区分"采集开关"与"功能开关"。
- 审计：退出请求的响应时长（法定时限内完成）、退出后采样确认（该标识下应无新增数据——自动验证）。

```text
采集知情与退出权：
声明粒度 = 实际采集清单（性能指标/回放/保留期），变更同步
退出实现：设置项 → 配置中心即时生效（停采集+清缓冲+广播）；退出持久化跨会话
技术区分："采集开关"≠"SDK 功能开关"（错误边界等能力保留，仅数据出口关闭）
删除权：按设备/会话标识清理（PER-446）
审计：退出响应时长 + 退出后自动验证无新增数据
```
