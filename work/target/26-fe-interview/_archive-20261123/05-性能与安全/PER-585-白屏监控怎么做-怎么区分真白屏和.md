## PER-585：白屏监控怎么做？怎么区分真白屏和内容还在加载？

**答**：
- 白屏检测两派：**DOM 采样法**（关键容器内有效元素数量/文本长度低于阈值判白屏）和**渲染截图法**（canvas 截图采样像素多样性），DOM 法成本低为主力，截图法用于兜底抽样。
- 防假白屏三招：延迟判定（load 后 2~3 秒再检测，给加载留时间）、关键容器锚定（只看内容区不看骨架屏节点）、二次确认（首次命中后 3 秒复检，仍白屏才上报）。
- 白屏根因标注：检测时同步采集 JS 错误与关键接口状态，白屏样本自动关联同会话错误，多数白屏是 JS 异常阻断渲染。
- 告警口径：白屏率 = 白屏会话/总会话（分设备档），阈值按档位分层；单次白屏样本要带 DOM 快照与错误现场便于排障。

```javascript

function whiteScreenDetect({ container = '#app', delay = 3000, threshold = 3 } = {}) {
  const check = () => {
    const root = document.querySelector(container);
    if (!root) return true;
    const valid = [...root.querySelectorAll('*')].filter(el =>
      el.textContent.trim().length > 0 || el.tagName === 'IMG').length;
    return valid < threshold;                              // 有效元素过少
  };
  return new Promise(resolve => {
    setTimeout(() => {                                     // 给加载留时间
      if (!check()) return resolve({ white: false });
      setTimeout(() => {                                   // 3 秒后二次确认
        const white = check();
        if (white) {
          resolve({ white: true, errs: window.__pre?.err?.slice(-3),
            api: window.__lastApiStatus, snapshot: document.body.innerHTML.slice(0, 2000) });
        } else resolve({ white: false });
      }, 3000);
    }, delay);
  });
}
whiteScreenDetect().then(r => r.white && navigator.sendBeacon('/collect/white', JSON.stringify(r)));
```
