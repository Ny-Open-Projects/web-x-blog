## PER-1149：数据匿名化与假名化的技术差异与工程选择

**答**：
- 假名化（pseudonymization）：可逆（映射表隔离保管），仍是个人数据，需保护映射表。
- 匿名化（anonymization）：不可逆且不可重识别（k-匿名/l-多样性/t-接近），出脱个人数据范畴。
- 工程选择：内部分析用假名化（可回溯客服场景）+ 严格访问控制；对外发布统计用匿名化（差分隐私加噪更稳）。
- 验证：匿名化后做重识别攻击测试（链接攻击），通过才可标记"匿名"。

```javascript
// k-匿名检查
function kAnonymity(rows, quasi, k = 5) {
  const groups = {};
  for (const r of rows) {
    const key = quasi.map(q => r[q]).join('|');
    groups[key] = (groups[key] ?? 0) + 1;
  }
  const bad = Object.entries(groups).filter(([, c]) => c < k);
  return { ok: bad.length === 0,
    minGroup: Math.min(...Object.values(groups)),
    advice: bad.length ? `泛化 ${bad.length} 个小桶（如合并年龄段/粗化地域）` : 'ok' };
}
// 发布统计前必须 kAnonymity(rows, ['age','district']) 通过
```
