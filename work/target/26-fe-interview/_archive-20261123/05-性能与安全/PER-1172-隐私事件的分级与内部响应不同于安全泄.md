## PER-1172：隐私事件的分级与内部响应（不同于安全泄露）

**答**：
- 分级：P0 采集违反同意（停采+评估通报）、P1 未登记字段/超期保留（限期整改）、P2 文案/流程瑕疵（随迭代修）。
- 响应：P0 先停损（关 SDK/开关）再评估范围与通报义务（1146 联动）。
- 复盘：根因归到流程（注册表未用/评审缺失）而非个人，流程修补。
- 演练：季度隐私事件演练（模拟 P0），验证停损通道 30 分钟可用。

```javascript
// 隐私事件分级器
function classifyPrivacyEvent(e) {
  if (e.type === 'consent-violation') return { level: 'P0',
    actions: ['kill-sdk', 'assess-notify', 'root-cause'] };
  if (e.type === 'undeclared-field' && FIELD_LEVEL[e.field] >= 3)
    return { level: 'P1', actions: ['stop-field', 'register', 'retro-purge'] };
  return { level: 'P2', actions: ['backlog'] };
}
// P0 演练目标：kill-sdk 到位 < 30 分钟
```
