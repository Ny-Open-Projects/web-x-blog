## PER-1096：如何做"前端安全培训"让它不只是走形式

**答**：
- 内容分层：全员（密码卫生/钓鱼识别）→ 开发（XSS/CSRF/安全编码）→ 平台（威胁建模/应急）。
- 形式：真实案例复盘分享 > 讲义灌输；CTF 小赛/漏洞奖励内测激发参与。
- 嵌入流程：code review 安全 checklist、上线安全门禁，让安全能力沉淀在流程而非个人。
- 度量：季度漏洞发现数（自查 vs 外部报告比例）、修复时长、培训后扫描问题下降率。

```javascript
// 培训后能力自测（开发向）
const QUIZ = [
  { q: 'innerHTML 赋值用户输入的安全替代', a: ['textContent', 'sanitizer + Trusted Types'] },
  { q: 'CSRF 三防线', a: ['SameSite', 'CSRF token', 'Origin 校验'] },
  { q: '依赖投毒的 CI 拦截手段', a: ['audit 扫描', 'lockfile diff 评审', '禁 postinstall'] },
];
function grade(answers) {
  return QUIZ.map((q, i) => ({ q: q.q,
    pass: q.a.every(a => JSON.stringify(answers[i]).includes(a)) }));
}
// 全部 pass 才算完成年度安全培训
```
