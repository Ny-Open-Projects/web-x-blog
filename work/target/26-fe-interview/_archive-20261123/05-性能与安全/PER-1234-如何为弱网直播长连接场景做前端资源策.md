## PER-1234：如何为"弱网直播/长连接"场景做前端资源策略

**答**：
- 场景：直播页依赖长连接与视频流，弱网下体验崩塌。
- 策略：视频分层（音流优先保底）、弹幕/礼物消息限流合并（100ms 批量渲染上限 N 条）、连接多路冗余（主备 CDN）。
- UI 降级：弱网时隐藏弹幕只保留视频、清晰度自动降、进度条缓冲提示。
- 度量：卡顿率（buffer 时长占比）、消息延迟 P90、降级触发率。

```javascript
// 直播弱网策略
function livePolicy(state) {
  const { rtt, loss, bufferSec } = state;
  const weak = rtt > 300 || loss > 0.03 || bufferSec > 2;
  return weak ? {
    danmu: 'hidden', quality: 'low', backupCdn: true,
    msgBatch: { windowMs: 200, maxPerFlush: 5 },
    ui: { bufferingHint: true } } : {
    danmu: 'normal', quality: 'auto', backupCdn: false };
}
// bufferSec 持续 > 2s -> 主动降清晰度而非等卡死
```
