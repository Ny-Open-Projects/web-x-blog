## PER-1288：手写一个前端"预算分配计算器"（按页面权重）

**答**：
- 需求：implement allocBudget(totalKB, pages)。pages 为 [{ path, weight, min }]；按 weight 比例分配 totalKB，但不低于 min；min 之和超 total 时按 min 分配并标记 over；输出 { allocs, over }。
- 边界：weight 缺失按 1；min 缺失按 0；分配结果四舍五入 KB；weight 全 0 按均分。
- 评分点：加权分配；min 下限；超支标记；均分兜底

```javascript
function allocBudget(totalKB, pages) {
  const ws = pages.map(p => p.weight ?? 1);
  const minSum = pages.reduce((s, p) => s + (p.min ?? 0), 0);
  const over = minSum > totalKB;
  const pool = over ? minSum : totalKB;
  const wSum = ws.reduce((s, v) => s + v, 0) || pages.length;
  const allocs = pages.map((p, i) => {
    const w = ws[i] || 1;
    const byW = !over ? Math.round(pool * w / wSum) : 0;
    return { path: p.path, kb: Math.max(byW, p.min ?? 0) };
  });
  return { allocs, over };
}
// over=true 时 min 之和超预算，提示收缩 min 或增加总额
```
