## PER-630：手写一个构建产物敏感信息扫描器：检查 sourcemap、JS bundle 里泄漏的密钥、内网域名与调试开关

**答**：
- 泄漏面三类：**sourcemap 上线**（把源码、注释里的密钥全暴露）、**bundle 内硬编码**（AK/SK、上报 key、内网 URL、测试账号）、**调试后门**（`?debug=1` 开启的内部能力）。
- 扫描规则：密钥正则（AKIA 开头的 AWS key、AccessKey 模式、`-----BEGIN` 私钥）、内网特征（`\.internal`、`192\.168`、`\.local`）、sourcemap 文件是否进产物目录。
- 要点：规则命中要有上下文（文件+行+片段前 50 字符）；白名单机制（某些公开 key 合法）；CI 里在 build 之后、deploy 之前跑，high 级阻断。
- 评分点：sourcemap 检查与上下文输出。

```javascript

const fs = require('fs'), path = require('path');
const RULES = [
  { re: /AKIA[0-9A-Z]{16}/, name: 'AWS-AccessKey', level: 'high' },
  { re: /LTAI[0-9A-Za-z]{12,}/, name: 'Aliyun-AccessKey', level: 'high' },
  { re: /-----BEGIN [A-Z ]*PRIVATE KEY-----/, name: 'PrivateKey', level: 'high' },
  { re: /[a-z0-9-]+\.(internal|local)\b/, name: 'Internal-Domain', level: 'medium' },
  { re: /192\.168\.|10\.\d+\./, name: 'Private-IP', level: 'medium' },
  { re: /__DEBUG__|window\.DEBUG\s*=\s*true/, name: 'Debug-Hook', level: 'low' },
];
function scanDist(distDir) {
  const findings = [];
  for (const f of fs.readdirSync(distDir)) {
    if (f.endsWith('.map')) { findings.push({ file: f, name: 'Sourcemap-Dist', level: 'high' }); continue; }
    if (!/\.(js|css|html|json)$/.test(f)) continue;
    const text = fs.readFileSync(path.join(distDir, f), 'utf8');
    RULES.forEach(r => {
      const m = text.match(r.re);
      if (m) findings.push({ file: f, name: r.name, level: r.level,
        ctx: text.slice(Math.max(0, m.index - 30), m.index + 50) });
    });
  }
  const high = findings.filter(x => x.level === 'high');
  if (high.length) { console.error('高危泄漏:', high); process.exit(1); } // deploy 前阻断
  console.log('扫描完成', findings);
}
scanDist('dist');
```
