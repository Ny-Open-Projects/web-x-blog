## PER-1086：敏感页面（支付/实名）的前端防护特殊点

**答**：
- 输入防窥：安全键盘（自定义渲染）、密码框禁用粘贴外的自动填充、短信验证码单独输入与防重放。
- 防自动化：行为验证（轨迹/频率）前置，页面关键操作绑定一次性 token（表单内嵌，后端校验）。
- 防篡改：订单金额等敏感展示由服务端签名，提交时回传签名由服务端复核（前端值不可信）。
- 会话强化：支付页要求重新认证（step-up auth），短会话超时。

```javascript
// 支付表单防篡改提交
async function submitPayment(order) {
  // 服务端预签名：金额/订单号由服务端生成签名
  const { sig } = await api('/pay/prepare', { orderId: order.id });
  const r = await api('/pay/confirm', { orderId: order.id, sig,   // 前端只透传
    otp: otpInput.value, payToken: oneTimeToken() });
  if (r.reauth) startStepUpAuth();            // 要求二次认证
}
// 铁律：金额等关键数据永远以服务端为准，前端值仅用于展示
```
