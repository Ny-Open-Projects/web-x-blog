## PER-915：性能预算如何在设计阶段就介入？与设计师怎么协作

**答**：
- 设计评审引入"性能预算卡"：首页总重、图片格式与尺寸、动效数量（同时运行的 transform/opacity 动画 ≤ 3）、字体方案（子集化/可变字体）。
- 交付约束写进设计稿标注：大图给压缩目标 KB、Lottie 给帧数与图层上限、视频给码率与预加载策略。
- 协作工具：给设计师一个"设计稿→预估加载成本"的计算器（图片 KB×张数+JS 估算），评审时当场看超支。
- 验收标准前移：设计验收不只看还原度，还看 Lighthouse 快照，还原度与性能双达标。

```javascript
// 设计稿成本预估器
const COST = { img: 0.09, video: 2.4, font: 0.03, lottie: 0.25 }; // KB/ms 经验系数
function estimate(assets, netMbps = 4) {          // netMbps: 目标网络
  const kb = assets.reduce((s, a) => s + a.count * COST[a.type] * a.kb, 0);
  return { totalKB: Math.round(kb),
    slow4G: +(kb * 8 / (netMbps * 1024)).toFixed(2) + 's',
    verdict: kb > 900 ? '超预算（>900KB），需压缩或删减' : '预算内' };
}
console.log(estimate([{ type: 'img', count: 6, kb: 120 }, { type: 'lottie', count: 1, kb: 400 }]));
// -> { totalKB: 1048, slow4G: '2.04s', verdict: '超预算...' }
```
