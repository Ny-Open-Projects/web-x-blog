## PER-1276：手写一个弱网降级决策器

**答**：
- 需求：implement weakNetDecision({ rtt, downlink, loss })。good: rtt<200 && downlink>2 && loss<0.02；bad: rtt>500 || downlink<0.5 || loss>0.05；其余 mid；各档输出策略（1232 矩阵）；输出 { tier, policy, reason }。
- 边界：参数缺失用默认值（rtt=100, downlink=10, loss=0）；tier 输出后 policy 按 POLICY 表查；未知 tier 按 mid。
- 评分点：阈值判定；默认值；策略表；理由输出

```javascript
function weakNetDecision({ rtt = 100, downlink = 10, loss = 0 } = {}) {
  const POLICY = {
    good: { imgW: 1080, prefetch: true, anim: true },
    mid:  { imgW: 720, prefetch: 'visible', anim: true },
    bad:  { imgW: 360, prefetch: false, anim: false },
  };
  let tier = 'mid', reason = '';
  if (rtt > 500 || downlink < 0.5 || loss > 0.05) {
    tier = 'bad'; reason = `rtt=${rtt} dl=${downlink} loss=${loss} 触发坏网阈值`;
  } else if (rtt < 200 && downlink > 2 && loss < 0.02) {
    tier = 'good'; reason = '全指标优';
  } else reason = '中等档位';
  return { tier, policy: POLICY[tier] ?? POLICY.mid, reason };
}
```
