## PER-1116：如何为"零信任"趋势调整前端架构

**答**：
- 零信任核心：不再信任内网边界，每次请求都验证（身份+设备+上下文）。
- 前端影响：内网应用也要登录+设备校验；Token 短时效高频刷新；设备健康检查（合规状态）作为访问条件。
- 工程：网关统一认证（前端透明）、敏感操作 step-up、会话风险评分（异地/新设备触发 MFA）。
- 迁移：内网系统先加 SSO 与设备指纹，再逐步收紧会话时长与操作校验。

```javascript
// 会话风险评分
function sessionRisk(ctx) {   // ctx: { newDevice, geoChanged, oddHour, failedLogins }
  let risk = 0;
  if (ctx.newDevice) risk += 40;
  if (ctx.geoChanged) risk += 30;
  if (ctx.oddHour) risk += 10;
  if (ctx.failedLogins > 2) risk += 20;
  return { risk,
    action: risk >= 60 ? 'require-mfa' : risk >= 30 ? 'require-stepup' : 'allow' };
}
// 前端按 action 引导：MFA 弹窗 / 二次验证 / 放行
```
