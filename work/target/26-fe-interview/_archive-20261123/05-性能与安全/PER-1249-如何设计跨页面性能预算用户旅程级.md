## PER-1249：如何设计"跨页面性能预算"（用户旅程级）

**答**：
- 动机：单页达标不等于旅程达标——用户旅程（列表→详情→下单）累计等待才是体验。
- 预算：旅程总时间预算（如 6s）分解到各页（列表 2s/详情 1.5s/下单 2.5s）。
- 度量：旅程埋点串联（traceId 跨页），各页耗时与剩余预算实时展示。
- 优化视角：瓶颈页优先（消耗预算最多且可压缩），页面间预取共享预算（下一页资源在上页空闲期取）。

```javascript
// 旅程预算分解
const JOURNEY = { order: { total: 6000, pages: { list: 2000, detail: 1500, pay: 2500 } } };
function journeyTrack(path, spent, journey = 'order') {
  const j = JOURNEY[journey];
  const idx = Object.keys(j.pages).indexOf(path);
  const used = spent;
  const remaining = j.total - j.pages[path];       // 后续页可用
  return { path, budget: j.pages[path], used,
    over: used > j.pages[path],
    nextPagesBudget: j.pages[Object.keys(j.pages)[idx + 1]] ?? 0,
    hint: used > j.pages[path] ? '本页超支，请压缩或让下一页预取' : 'ok' };
}
```
