## PER-1101：数据导出功能的安全设计（防越权导出）

**答**：
- 风险：导出接口被越权调用拉取全量数据（水平/垂直越权）、导出文件被爬取链接遍历。
- 防线：导出走异步任务 + 权限校验（行级数据权限带到导出查询）、任务与文件绑定请求者（下载时二次校验归属）。
- 文件安全：临时链接（短时效签名 URL）、下载审计日志、敏感导出水印（文件内嵌请求者标识）。
- 前端配合：导出按钮按权限渲染、大导出走任务中心轮询、下载链接一次性使用。

```javascript
// 导出任务与一次性下载
async function requestExport(params) {
  const { taskId } = await api('/export', { method: 'POST', body: params });
  return pollTask(taskId);                           // 任务中心轮询
}
async function downloadExport(taskId) {
  const { url, token } = await api(`/export/${taskId}/link`);   // 短时效签名
  const a = document.createElement('a');
  a.href = `${url}?t=${token}`;                      // 一次性 token
  a.download = '';
  a.click();
  report({ type: 'export-download', taskId });       // 审计
}
```
