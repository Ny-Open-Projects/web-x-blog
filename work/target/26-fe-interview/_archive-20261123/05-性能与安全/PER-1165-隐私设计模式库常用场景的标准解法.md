## PER-1165：隐私设计模式库：常用场景的标准解法

**答**：
- 模式一：数据最小化（能聚合不明细、能短存不长存、能本地不上传）。
- 模式二：默认脱敏（展示层掩码 + 点击查看留痕）。
- 模式三：同意门控（SDK 延迟初始化、采集前置检查）。
- 模式四：可撤回（一切采集能力可关，关闭即停 + 验证）。
- 模式五：可证明（审计日志贯穿，任何处理可回溯依据）。

```javascript
// 模式库索引
const PATTERNS = {
  minimize: { apply: '字段注册+聚合上报', refs: ['1004', '1150'] },
  maskByDefault: { apply: '渲染层掩码+查看留痕', refs: ['1113', '1127'] },
  consentGate: { apply: 'CMP 先行+SDK 延迟初始化', refs: ['1001', '1141'] },
  revocable: { apply: '开关即停+验证探针', refs: ['1158'] },
  provable: { apply: 'append-only 审计+版本绑定', refs: ['1005'] },
};
function pickPattern(problem) {
  return Object.entries(PATTERNS).filter(([k]) => problem.includes(k))
    .map(([k, v]) => ({ pattern: k, ...v }));
}
```
