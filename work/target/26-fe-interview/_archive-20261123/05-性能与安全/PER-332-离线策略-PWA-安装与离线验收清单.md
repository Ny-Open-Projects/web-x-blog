## PER-332：PWA 离线能力上线前，验收清单应该有哪些项？常见翻车点？

**答**：
- 验收清单：① 断网冷启动可用（ airplane mode 下打开 PWA，壳完整渲染）；② 核心路径离线可走（浏览/查看已缓存详情）；③ 离线写操作入队且恢复后正确重放（不重复提交）；④ SW 更新发布后旧客户端平滑升级（下次访问拿到新版本，无白屏中间态）；⑤ 二次访问启动耗时（离线应显著快于在线）；⑥ 存储 Quota 满时的降级（清旧缓存不崩）；⑦ iOS Safari 专项（7 天 cap、不支持 Background Sync 的兜底路径）。
- 常见翻车点：SW 缓存了带鉴权的接口响应（把 A 用户数据缓存给 B 用户读——**必须按用户维度区分或不缓存鉴权接口**）；缓存了 POST 响应；版本切换时旧缓存没清导致混版本渲染；导航预加载与自定义逻辑冲突；manifest 图标/name 不达标导致安装提示不出。
- 监控配套：SW 注册率、离线命中率、sync 重放成功率、SW 错误率四指标进 RUM；灰度发布（SW 逻辑也走灰度——不同用户组加载不同 SW 版本）。

```text
PWA 离线验收 checklist：
[ ] 飞行模式冷启动：壳 + 已浏览内容可用
[ ] 离线写操作：入队提示可见，恢复网络后重放成功且幂等（同键不重复）
[ ] 鉴权接口不入缓存（或缓存键带 userId 分区）—— 翻车率最高项
[ ] SW 发新版本：旧客户端下次访问升级，无白屏、无双版本混渲染
[ ] Quota 满：LRU 清理触发，核心数据有保护
[ ] iOS：安装 PWA 豁免 7 天 cap 验证；无 sync API 的页面内重放路径通过
[ ] RUM 四指标：SW 注册率 / 离线命中率 / sync 成功率 / SW 错误率
```
