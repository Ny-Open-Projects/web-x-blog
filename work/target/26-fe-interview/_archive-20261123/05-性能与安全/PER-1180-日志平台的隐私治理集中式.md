## PER-1180：日志平台的隐私治理（集中式）

**答**：
- 问题：日志是隐私泄漏重灾区（调试 print、异常 message 带数据）。
- 治理：SDK 统一脱敏（1087）、敏感字段黑名单（字段名级拦截）、保留期分级（S3+ 日志 7 天）、访问权限（S3+ 日志需审批）。
- 技术：日志 schema 化（禁止自由文本塞对象）、结构化字段按级别自动掩码。
- 巡检：抽样扫描线上日志明文敏感值（手机号/卡号正则），命中即告警并溯源产生方。

```javascript
// 日志巡检扫描
const SENSITIVE_RE = [ /1[3-9]\d{9}/, /\d{17}[\dXx]/, /\d{16,19}/ ];
function logPatrol(entries) {
  const hits = entries.filter(e =>
    SENSITIVE_RE.some(r => r.test(JSON.stringify(e.fields))) &&
    !e.redacted);
  return { sampled: entries.length, hits: hits.length,
    offenders: [...new Set(hits.map(h => h.producer))],
    action: hits.length ? '通知产生方整改 + 已泄漏日志立即删除' : 'ok' };
}
```
