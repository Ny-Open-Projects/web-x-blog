## PER-1292：手写一个"探针覆盖缺口"分析器

**答**：
- 需求：implement probeGaps(routes, probes)。routes 为全量路由；probes 为 [{ route, checks: [checkId] }]；输出 { uncovered: [route], partial: [{ route, missing }] }：uncovered 无探针路由；partial 为探针路由缺少 REQUIRED_CHECKS 中项。
- 边界：REQUIRED_CHECKS 常量（lcp/err/security）；probes 中未登记路由忽略；routes 为空返回空。
- 评分点：覆盖对比；必检项；缺口分类；比例建议

```javascript
const REQUIRED_CHECKS = ['lcp', 'err', 'security'];
function probeGaps(routes, probes) {
  const map = new Map(probes.map(p => [p.route, p.checks ?? []]));
  const uncovered = [], partial = [];
  for (const r of routes) {
    const checks = map.get(r);
    if (!checks) { uncovered.push(r); continue; }
    const missing = REQUIRED_CHECKS.filter(c => !checks.includes(c));
    if (missing.length) partial.push({ route: r, missing });
  }
  return { uncovered, partial };
}
// uncovered > 30% -> 探针扩量专项
```
