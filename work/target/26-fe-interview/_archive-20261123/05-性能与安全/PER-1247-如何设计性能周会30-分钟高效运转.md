## PER-1247：如何设计"性能周会"（30 分钟高效运转）

**答**：
- 议程固定：10 分钟看板走查（劣化项）、10 分钟专项进展、5 分钟新增问题认领、5 分钟决策事项。
- 纪律：不带数据不开会（看板即事实源）、讨论超时转专项会、每个议题有结论与 Owner。
- 频率：每周一次 30 分钟，参会人 = 页面 Owner 轮值 + 平台。
- 产出：会议纪要自动生成（议题→结论→Owner→due），下周一开场先过上周结论。

```javascript
// 周会议程生成
function weeklyAgenda(board, lastActions) {
  return [
    { item: '劣化走查', data: board.regressions, time: 10 },
    { item: '专项进展', data: board.projects.map(p => p.progress), time: 10 },
    { item: '上期结论复查', data: lastActions.filter(a => a.due < Date.now()), time: 5 },
    { item: '新增认领', data: board.unassigned, time: 5 },
  ];
}
// 纪要模板：{ topic, decision, owner, due }
```
