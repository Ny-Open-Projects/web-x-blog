## PER-1042：页面间数据传递：状态共享代替重复请求

**答**：
- 问题：列表页请求过详情数据，详情页又请求一遍；同接口在多组件重复请求。
- 方案：请求层缓存（1028）+ 预取详情数据随路由跳转传递（router state）+ 全局状态层（store/Query 缓存）。
- 一致性：预取数据带版本戳，详情页 hydrate 后台 revalidate，数据不一致以服务端为准。
- 收益量化：跳转详情页的接口 RTT 从 1 次降到 0（命中预取），LCP 显著提前。

```javascript
// 路由跳转携带预取数据
router.push({ path: `/detail/${id}`, state: { prefetch: await prefetchDetail(id) } });
// 详情页消费
const { state } = history;
if (state?.prefetch?.[id]) renderDetail(state.prefetch[id]);
revalidateDetail(id);                     // 后台校准
// prefetchDetail 内部走 dedupeFetch + APICache，列表页已请求过的直接命中
```
