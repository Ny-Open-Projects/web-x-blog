## PER-909：如何搭建性能劣化的自动告警体系？怎么控制误报

**答**：
- 告警分三级：门禁级（CI 直接拦截）、看板级（日环比劣化标注）、值班级（P75 连续 N 个周期超 SLO 触发电话/IM）。
- 防误报三板斧：min-fraction（受影响用户占比 > 5% 才告警）、连续周期确认（连续 3 个 15min 窗口超阈值）、对比同版本历史基线而非绝对阈值。
- 告警必须带上下文：指标、当前值、基线、影响用户数、嫌疑发版、看板直达链接，做到"收到即能定位"。
- 静默与升级：低峰期已知问题静默，超时未认领自动升级到上级。

```javascript
// 告警判定：连续窗口 + 影响面双条件
function shouldAlert(windows, { threshold = 2500, minAffected = 0.05, streak = 3 } = {}) {
  const bad = windows.slice(-streak).filter(w =>
    w.p75 > threshold && w.affected / w.total > minAffected);
  return bad.length === streak
    ? { alert: true, reason: `连续${streak}个窗口 P75 超阈且影响面达标` }
    : { alert: false };
}
// SLO burn-rate 变体：errors = (p75 超 SLO 的请求数/总数)/预算消耗速率
```
