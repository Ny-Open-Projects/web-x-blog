## PER-544：性能测试的通过标准怎么定？比上版快 10% 和 LCP p75 达标哪种口径更健康？

**答**：
- 两种口径的本质：相对口径（比上版快 X%）只防回归不设底线——全站都很慢时"每版快 10%"依然全是 FAIL 用户；绝对口径（LCP p75 < 2.5s）设了用户体验底线但可能脱离现实（遗留大页永远达不了标）。
- 健康做法是双层：**底线层用绝对口径**（对核心转化页生效），**回归层用相对口径**（所有页面，超阈值挡合并）；两层解耦，底线层达标后可以逐步收紧。
- 绝对阈值来源要有依据：Core Web Vitals 官方推荐值（LCP 2.5s / INP 200ms / CLS 0.1）+ 自家业务转化率对性能的敏感度实验数据。
- 追问钩子：为什么用 p75 而不是 p50 或 p99 判达标？——Web Vitals 口径是 p75，p50 掩盖长尾，p99 被极端样本支配不可治理。

```javascript

const gatePolicy = {
  absolute: {  // 底线层：核心转化页，绝对阈值
    pages: ['/home', '/pay', '/sku'],
    metrics: { lcpP75: 2500, inpP75: 200, clsP75: 0.1 },   // CWV 口径
  },
  relative: {  // 回归层：全部页面，防回归
    tolerance: { good: -0.05, warn: 0.05, fail: 0.10 },    // 改善5%/预警5%/拦截10%
    compareWith: 'previous-release-p75',
  },
  escalate: (page, pass) => pass ? '达标页逐步收紧预算 5%/季度' : '未达标页限期治理',
};
// 双层门禁：relative 层每次 PR 生效；absolute 层只对核心页发版时强拦
```
