## PER-1143：未成年人保护的工程要求

**答**：
- 要求：不满 14 周岁个人信息属敏感信息，需监护人同意（单独同意）；儿童模式（内容/时长限制）。
- 实现：年龄申报节点（注册/首次使用）、未成年人标识贯穿会话（服务端下发，前端只读）、家长同意流程（短信/支付验证）。
- 前端注意：儿童模式下禁用个性化推荐与广告、诱导性 UI（充值按钮弱化）、夜间时段限制。
- 审计：未成年人数据单独标记存储与保留策略。

```javascript
// 未成年人模式守卫
function guardMinor(session) {
  if (!session.isMinor) return { features: 'all' };
  return {
    features: { recommend: false, ads: false, pay: 'guardian-confirm',
      nightUse: false },
    storage: { level: 'S4', separateRetention: true },
    ui: { weakenPayButton: true, showGuardianNotice: true },
  };
}
// 服务端权威判定 isMinor，前端仅按下发结果降级，不可自行绕过
```
