## PER-1293：手写一个"告警值班交接"生成器

**答**：
- 需求：implement handover(alerts, actions)。alerts 为本周期未关闭告警；actions 为已执行动作 [{ alertId, what, at, by }]；输出 { open: alerts, done: actions, brief }：brief 一句话（N 条未关闭，M 条已处理，最老告警 X 小时）。
- 边界：未关联动作的告警标记 untouched；最老告警按 createdAt；空周期 brief 为 无告警；按 createdAt 升序输出 open。
- 评分点：未动标记；最老时长；排序；一句话 brief

```javascript
function handover(alerts, actions) {
  const actedIds = new Set(actions.map(a => a.alertId));
  const open = [...alerts].sort((a, b) => a.createdAt - b.createdAt)
    .map(a => ({ ...a, untouched: !actedIds.has(a.id) }));
  const now = Date.now();
  const oldestH = open.length
    ? +((now - open[0].createdAt) / 3600_000).toFixed(1) : 0;
  return { open, done: actions,
    brief: open.length
      ? `${open.length} 条未关闭（${open.filter(a => a.untouched).length} 条未动），已处理 ${actions.length} 条，最老 ${oldestH}h`
      : '无告警' };
}
```
