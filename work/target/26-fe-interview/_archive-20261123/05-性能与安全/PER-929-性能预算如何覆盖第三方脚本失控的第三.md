## PER-929：性能预算如何覆盖第三方脚本？失控的第三方怎么治理

**答**：
- 第三方预算单列：广告/统计/客服脚本预算独立核算（如 ≤ 总预算 30%），防止业务方被外部拖累却无从下手。
- 入库流程：新第三方必须走"性能评审"——实测体积/阻塞行为/加载策略，登记后才允许接入，否则 CSP 拦截。
- 治理手段：统一经代理网关加载（可缓存/可熔断）、facade 模式懒加载（iframe 占位点击才加载）、sandbox iframe 隔离。
- 监控：为每个第三方建立独立指标（加载耗时、主线程占用），劣化可直接追责供应商。

```javascript
// 第三方 facade：点击才加载真实嵌入
function facade(container, { src, width, height, poster, onLoad }) {
  const ph = document.createElement('div');
  ph.style.cssText = `width:${width}px;height:${height}px;background:url(${poster}) center/cover;cursor:pointer`;
  ph.onclick = () => {
    const f = document.createElement('iframe');
    f.src = src; f.loading = 'lazy';
    f.setAttribute('title', 'third-party embed');
    f.onload = onLoad;                    // 独立指标上报
    ph.replaceWith(f);
  };
  container.appendChild(ph);
}
// 未点击前 0 成本；配合 CSP allowlist 登记制
```
