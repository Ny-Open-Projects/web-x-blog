## PER-1294：手写一个"资源预算执行报表"（月度）

**答**：
- 需求：implement budgetReport(months, budgets)。months 为 [{ month, jsKB, imgKB, lcpP75 }]；budgets 为 { jsKB, imgKB, lcpP75 }；输出逐月 { month, pass, over: [metric] } 与趋势（连续超标的月数）；输出 { rows, streak }：streak 为最近连续超标月数（>2 触发专项）。
- 边界：某月缺指标按达标（宽松）但记录 missing；streak 从最新往前数；rows 按时间升序。
- 评分点：逐月判定；缺失宽松；连续计数；专项触发

```javascript
function budgetReport(months, budgets) {
  const rows = [...months].sort((a, b) => a.month < b.month ? -1 : 1)
    .map(m => {
      const missing = Object.keys(budgets).filter(k => m[k] == null);
      const over = Object.keys(budgets)
        .filter(k => m[k] != null && m[k] > budgets[k]);
      return { month: m.month, pass: !over.length, over, missing };
    });
  let streak = 0;
  for (let i = rows.length - 1; i >= 0 && !rows[i].pass; i--) streak++;
  return { rows, streak,
    alert: streak > 2 ? `连续 ${streak} 月超标，启动专项` : null };
}
```
