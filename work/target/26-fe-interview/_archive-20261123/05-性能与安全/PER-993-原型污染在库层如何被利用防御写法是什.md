## PER-993：原型污染在库层如何被利用？防御写法是什么

**答**：
- 污染点：merge/deepExtend/qs 解析把 __proto__/constructor.prototype 当普通键写入，污染 Object.prototype 后全站对象继承恶意属性。
- 利用链：污染后若代码有 if (cfg.safe) 分支，攻击者让所有对象 safe 默认为 true 绕过校验；再配合 gadget（如某些模板引擎的自动执行属性）执行代码。
- 防御：入口过滤 __proto__/constructor/prototype 键；用 Object.create(null) 做字典；深拷贝用 structuredClone；npm audit + 锁版本防投毒库。
- 检测：库升级后跑原型污染单测（merge 后 Object.prototype 是否变化）。

```javascript
// 安全 merge
const DANGEROUS = new Set(['__proto__', 'constructor', 'prototype']);
function safeMerge(target, src) {
  for (const k of Object.keys(src)) {
    if (DANGEROUS.has(k)) continue;              // 入口过滤
    const v = src[k];
    if (v && typeof v === 'object' && !Array.isArray(v) &&
        Object.getPrototypeOf(v) === Object.prototype)
      target[k] = safeMerge(target[k] ?? {}, v);
    else target[k] = v;
  }
  return target;
}
// 回归测试：
const o = {}; safeMerge(o, JSON.parse('{"__proto__":{"polluted":1}}'));
console.log(({}).polluted);   // undefined 才通过
```
