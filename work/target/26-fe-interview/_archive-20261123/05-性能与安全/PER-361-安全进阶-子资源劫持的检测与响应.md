## PER-361：供应链劫持事件的检测信号与响应演练：从异常脚本到止血的分钟级动作？

**答**：
- 检测信号矩阵：① CSP report 突增（未知域 script 被拦——CSP 在攻击时是探测器）；② SRI 校验失败率上升（CDN 字节被改）；③ 新增外部请求（CSP/网络层未知域）；④ LoAF invoker 出现陌生 URL；⑤ 构建产物 hash 与 manifest 不符（PER-317 探活）；⑥ 行为信号——页面出现非预期弹层/外发请求（RUM 采样里的行为审计）。
- 响应剧本（演练化，分钟级）：T+1min 确认信号（交叉验证 CSP report + CDN 字节 hash）；T+5min 止血——一键下线可疑资源（配置开关/CDN 摘除）+ CSP 紧急收紧（移除可疑域）；T+15min 评估影响面（哪些页面/用户受影响、是否有数据外泄——结合服务端日志）；T+1h 根因（CDN 账号/构建机/依赖投毒三路排查）+ 恢复发布；T+24h 复盘与加固（SRI 全覆盖、CSP 收紧、账号 2FA）。
- 演练：季度红蓝对抗——蓝队模拟"CDN 脚本被篡改"，考核检测到止血的耗时；剧本文档化且值班人人可执行。

```text
劫持响应剧本（值班卡）：
信号确认：CSP report 未知域 ↑ + SRI 失败 ↑ + LoAF 陌生 invoker → 确认劫持
止血（T+5min）：开关下线该脚本（功能降级可接受）→ CSP 紧急策略（移除该域）
评估（T+15min）：受影响页面清单 + 外发请求日志（数据是否外泄）
根因（T+1h）：CDN 账号 2FA？构建机被入侵？依赖投毒？→ 三路并行
恢复：从 CI 重发布（新 manifest）→ 探活 → 恢复功能
加固：SRI 全覆盖、CSP 白名单收敛、账号审计、季度演练记录
```
