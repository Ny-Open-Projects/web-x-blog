## PER-1082：前端安全事件应急响应流程是什么

**答**：
- 分级：P0（资损/数据泄露，立即下线）、P1（功能被滥用）、P2（隐患）。每级有响应时限与决策人。
- 动作链：确认范围（影响版本/页面/用户量）→ 止血（下线/开关/回滚/热修）→ 溯源（日志/探针/指纹）→ 修复与复测 → 复盘归档。
- 准备：热修通道（容器热更/网关 JS 注入修复补丁）、CSP 应急收紧能力、第三方脚本一键断供开关。
- 演练：季度红色演练（注入模拟事件），验证止血通道 15 分钟内可用。

```javascript
// 应急开关中心（见 938 扩展）
const KILL_SWITCH = {
  '3p-ads': () => unloadScript('ads.sdk.js'),
  'rich-text': () => flag('disableRichEditor', true),   // 受 XSS 影响模块下线
};
export function kill(id, reason) {
  KILL_SWITCH[id]?.();
  report({ type: 'kill-switch', id, reason, by: currentUser });
}
// 网关配合：CSP 从 report-only 切 enforce 的开关由服务端下发
```
