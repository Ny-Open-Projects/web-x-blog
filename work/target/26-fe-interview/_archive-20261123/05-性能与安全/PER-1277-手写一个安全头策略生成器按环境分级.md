## PER-1277：手写一个安全头策略生成器（按环境分级）

**答**：
- 需求：implement securityHeaders(env)。env: dev/staging/prod；prod 全量：HSTS+CSP enforce+nosniff+frame-ancestors；staging：CSP report-only + 其余 enforce；dev：只 nosniff（本地调试方便）；输出 { headers: { name: value } }；CSP 模板由参数注入（nonce）。
- 边界：nonce 缺失时 prod 抛错；staging 也要求 nosniff；未知 env 按 prod。
- 评分点：环境分级；nonce 校验；report-only；dev 简化

```javascript
function securityHeaders(env, nonce) {
  if (env === 'prod' && !nonce) throw new Error('prod 需要 nonce');
  const base = { 'X-Content-Type-Options': 'nosniff' };
  const csp = env === 'dev' ? null :
    `script-src 'nonce-${nonce ?? 'staging'}' 'strict-dynamic'; object-src 'none'`;
  if (env === 'staging' || env === 'prod')
    base['Content-Security-Policy' + (env === 'staging' ? '-Report-Only' : '')] = csp;
  if (env === 'prod') {
    base['Strict-Transport-Security'] = 'max-age=31536000; includeSubDomains';
    base['Content-Security-Policy'] += "; frame-ancestors 'self'";
  }
  return { headers: base };
}
```
