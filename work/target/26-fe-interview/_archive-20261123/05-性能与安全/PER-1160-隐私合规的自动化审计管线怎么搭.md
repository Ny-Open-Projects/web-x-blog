## PER-1160：隐私合规的自动化审计管线怎么搭

**答**：
- 管线：代码扫描（敏感 API/字段引用）→ 构建产物扫描（密钥/明文）→ 运行时抓包抽样（实际上报内容）→ 注册表比对 → 报告。
- 触发：每次发版自动跑全量快检，月度全站深度审计。
- 输出：合规报告（通过项/违规项/整改单），违规阻塞发布。
- 持续：管线自身误报率监控，规则季度评审。

```javascript
// 合规审计管线
async function privacyAudit(build, registry) {
  const codeScan = scanSensitiveAPI(build.src);
  const bundleScan = scanSecrets(build.bundle);
  const runtimeSample = await sampleReports(build, 100);   // 抓 100 条上报
  const undeclared = runtimeSample.flatMap(r =>
    Object.keys(r.fields).filter(f => !registry[r.event]?.fields[f]));
  return {
    violations: [...codeScan, ...bundleScan,
      ...undeclared.map(f => ({ type: 'undeclared-field', field: f }))],
    verdict: undeclared.length || bundleScan.length ? 'block' : 'pass',
  };
}
```
