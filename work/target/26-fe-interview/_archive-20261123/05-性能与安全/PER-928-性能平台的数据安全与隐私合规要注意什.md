## PER-928：性能平台的数据安全与隐私合规要注意什么

**答**：
- 最小化采集：性能数据天然低敏，但 URL 可能带 token/订单号，上报前必须脱敏（正则 + 参数白名单）。
- 用户标识：用不可逆哈希 uid，禁止明文设备号/手机号入性能库；会话回放需打码输入框内容。
- 跨境合规：数据落地区域遵循当地法规（GDPR 数据不出欧），SDK 按区域路由上报域名。
- 权限与留存：明细数据访问走权限申请，留存期到期自动删除并留审计日志。

```javascript
// URL 脱敏
const SENSITIVE = /((token|key|auth|session|id)_?=?)[^&]+/gi;
function clean(url) {
  const u = new URL(url, location.origin);
  for (const k of [...u.searchParams.keys()])
    if (/token|key|auth|session|sign/i.test(k)) u.searchParams.set(k, '***');
  return u.pathname.replace(/\d{6,}/g, 'N') + u.search;  // 路径长数字也打码
}
// clean('/order/88273412?token=abc') -> '/order/N?token=***'
```
