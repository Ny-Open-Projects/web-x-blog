## PER-1218：如何做"多版本共存"时代的性能归因（灰度/AB 并行）

**答**：
- 问题：同页面多版本并行（灰度 5% / 实验 10%），大盘指标混入实验噪声，劣化归因失真。
- 方法：指标按 buildId/实验分组归因，基线只对比"稳定版本桶"；实验桶劣化找实验 Owner 而非页面 Owner。
- 平台能力：发版事件自动标注看板、桶级 SLO（实验桶独立阈值）、合并报表时显式声明口径。
- 坑：灰度桶流量小样本少，分位数抖动——按 uid 稳定分流保证桶内可比。

```javascript
// 桶级归因
function attributeByBucket(records, releases, experiments) {
  const stable = records.filter(r => !experiments.some(e => e.uid === r.uid));
  const exp = records.filter(r => experiments.some(e => e.uid === r.uid));
  const base = p75(stable.map(r => r.lcp));
  return { stableP75: base,
    experiments: experiments.map(e => ({
      id: e.id, p75: p75(exp.filter(r => e.uid === r.uid).map(r => r.lcp)),
      vsStable: +(p75(exp.filter(r => e.uid === r.uid).map(r => r.lcp)) / base - 1).toFixed(3),
      owner: e.owner })),
  };
}
function p75(a) { const s = [...a].sort((x, y) => x - y);
  return s[Math.floor(s.length * 0.75)] ?? 0; }
```
