## PER-475：PR 性能评论/基线选择/豁免的完整 CI 工作流？

**答**:
- 完整工作流：PR 触发 → CI 跑性能基准（实验室 + 产物 diff）→ 结果以 PR 评论形式输出（表格：指标/基线/当前/Δ/判定）→ 预算内自动通过；超标项标红并要求处理（修复或申请豁免）。
- 基线选择策略：默认 target 分支最新版；共享基础组件的 PR 用"受影响页面集合"的基线（组件库 PR 对所有使用页跑）；大 PR（架构级）允许申请"重建基线"（当前版已是如此差，重建后从新起点收紧——要评审）。
- 豁免机制：perf-exception 标签 + 影响说明 + 自动过期（48h/一周内必须还债，PER-339）；豁免使用率监控（常态化豁免 = 预算定错或团队超载——信号回炉）。
- 抖动处理：实验室数据有噪声（同 PR 两次跑差 5%）——关键判定用两次中位数 + 噪声带（±3% 内不判超标）；噪声持续大 = 环境问题优先修。

```text
PR 性能 CI 工作流：
PR → 基准跑（实验室 + 产物 diff）→ PR 评论表格（指标/基线/当前/Δ/判定）
基线：target 最新；组件 PR 用受影响页面集合；大 PR 可申请重建基线（评审）
豁免：perf-exception 标签 + 影响说明 + 自动过期（48h 还债）；使用率监控回炉
抖动：两次中位数判定 + ±3% 噪声带；持续大噪声优先修环境
产出：PR 内 3 分钟拿到性能 diff（PER-374 反馈即时原则）
```
