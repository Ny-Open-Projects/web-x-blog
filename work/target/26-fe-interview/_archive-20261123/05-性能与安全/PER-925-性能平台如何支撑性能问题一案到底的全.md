## PER-925：性能平台如何支撑「性能问题一案到底」的全链路追踪

**答**：
- 一案到底：从告警→看板→单用户会话回放→资源瀑布→代码提交，一条链路打通，不用切换五个系统。
- 关键技术：统一 traceId 贯穿（RUM 记录↔资源请求↔后端 span）、构建产物 sourcemap 与 manifest 归档（可回查任意版本的资源构成）。
- 会话回放：记录交互序列 + rrweb 片段（采样），性能问题伴随交互可复现。
- 归档策略：每次发版归档 bundle 报告与 Lighthouse 快照，劣化归因时任意回放历史状态。

```javascript
// 告警上下文装配
function alertContext(alert, deps) {
  return {
    ...alert,
    board: deps.boardUrl(alert.page, alert.metric),
    sessions: deps.sessionSearch({ page: alert.page, t: alert.window, slow: true }),
    waterfall: deps.resourceTrace(alert.page, alert.window),
    suspectCommits: deps.commitsBetween(alert.prevRelease, alert.release),
  };   // 一个对象包含定位所需全部入口，值班从收到告警到开单 < 15min
}
```
