## PER-1176：如何设计面向用户的"数据透明度报告"

**答**：
- 内容：本产品采集哪些数据/为什么/给谁/保留多久/如何控制——用户语言（非术语）。
- 形态：设置页内嵌"数据页"（我的数据一览+管理入口）、年度透明度报告（政府请求/泄露事件统计）。
- 交互：每个数据项可点击查看"最近一条实际采集样例"（脱敏展示），透明到可验证。
- 更新：政策变更时数据页自动高亮变化项。

```javascript
// 数据透明度页数据源
function transparencyData(uid) {
  return Object.entries(fieldRegistry).map(([field, def]) => ({
    field: def.userLabel,                        // 用户可读名称
    purpose: def.purpose, retention: def.keep + '天',
    sharedWith: def.vendors ?? [],
    sample: lastSample(hash(uid), field),        // 脱敏样例
  }));
}
// 配合管理入口：consent/导出/删除（1147）
```
