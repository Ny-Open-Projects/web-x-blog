## PER-956：手写一个发版归因器：把指标劣化窗口与发版记录配对

**答**：
- 需求：实现 attribute(releases, regressions)。releases 为 [{ version, ts, hotfix }]，regressions 为劣化事件 [{ from, to, metric, peak }]；对每个劣化事件找出其 from 之前最近的一次发版作为嫌疑版本；无发版记录则标记 infra（怀疑基础设施）；同一版本被多个事件引用时在结果中聚合。
- 边界：时间比较用 <=；to 为 null（未恢复）也需归因；输出按嫌疑版本分组且含事件列表。
- 评分点：最近前驱匹配；infra 兜底；按版本聚合；排序

```javascript
function attribute(releases, regressions) {
  const rel = [...releases].sort((a, b) => a.ts - b.ts);
  const out = new Map();
  for (const r of regressions) {
    let suspect = null;
    for (const v of rel) if (v.ts <= r.from) suspect = v;
    const key = suspect ? suspect.version : '__infra__';
    if (!out.has(key)) out.set(key, { version: key, hotfix: suspect?.hotfix ?? false,
      events: [] });
    out.get(key).events.push({ metric: r.metric, from: r.from, to: r.to, peak: r.peak });
  }
  return [...out.values()].sort((a, b) => b.events.length - a.events.length);
}
```
