## PER-427：慢样本的深度采样策略：哪些样本值得带全量明细？

**答**:
- 成本分级：全量明细（资源瀑布/LoAF/回放）成本高，全部样本都带 = 成本爆炸。分级采样让信息密度最大化：普通样本只带骨架字段（指标值+维度，~200B），慢样本（超阈值）升级为深度样本（+资源明细，~2KB），超慢样本（p99）再升级（+回放触发，PER-368）。
- 深度触发条件（叠加式）：INP > 400ms 或 LCP > 4000ms 或 CLS > 0.15 → 深度样本；INP > 800ms 或"同页面深度样本率突增"（异常检测）→ 超慢样本 + 回放。
- 配额保护：深度样本有每会话上限（防病态页面刷爆）；深度样本率监控（> 10% 说明阈值定太松或页面真的烂）。
- 采样偏差防护：慢样本升级不改变其他样本的采样概率（PER-243 的分层逻辑不受影响），分位数计算的权重按原始采样率回算。

```javascript
// 分级采样：骨架 → 深度 → 超慢
function sampleGrade(m) {
  if (m.inp > 800 || m.lcp > 6000) return 'ultra';    // + 回放触发（PER-368）
  if (m.inp > 400 || m.lcp > 4000 || m.cls > 0.15) return 'deep';   // + 资源瀑布/LoAF
  return 'basic';                                      // 骨架字段 ~200B
}
const PAYLOADS = {
  basic: (m) => ({ ...m, dims: ['page', 'device', 'ver'] }),
  deep: (m) => ({ ...m, dims: [...], resources: resourceBreakdown(), loafTop: loafTop5() }),  // ~2KB
  ultra: (m) => ({ ...PAYLOADS.deep(m), replayTrigger: true }),
};
// 配额：每会话 deep ≤ 3 条、ultra ≤ 1 条；深度样本率监控（> 10% 告警阈值调参）
// 分位数权重按原始采样率回算——升级采样不影响总体分布计算
```
