## PER-278：手写"操作前后内存回归"自动检测（固定操作序列 + GC 后采样 + 台阶判定）

**题目**：实现 `detectLeak({ action, rounds = 10, toleranceMB = 5 })`：① 执行 action 前，连续采样 usedJSHeapSize 取最小值作为基线（近似 GC 后水位）；② 循环执行 action 共 rounds 次，每轮结束采样"稳定水位"（等待 idle 后最小值）；③ 用最后 3 轮水位均值与基线比较，差值 > toleranceMB 判定疑似泄漏；④ 返回 { baseline, waters[], leaked, deltaMB }。

**答**：要点是"GC 后采样"（连续采样取最小值逼近 GC 后水位）与"最后 N 轮均值"（前几轮含预热与正常缓存填充，判定看稳态）。

```javascript
async function detectLeak({ action, rounds = 10, toleranceMB = 5 }) {
  const stableWater = async () => {                 // GC 后水位：连续采样取最小
    const m = () => performance.memory?.usedJSHeapSize ?? null;
    if (!m()) return null;
    const vals = [];
    for (let i = 0; i < 8; i++) {
      vals.push(m());
      await new Promise(r => requestIdleCallback?.(r) ?? setTimeout(r, 120));  // 等 GC 与 idle
    }
    return Math.min(...vals) / 1048576;             // MB
  };
  await new Promise(r => setTimeout(r, 1000));      // 页面静置
  const baseline = await stableWater();
  if (baseline == null) return { skipped: true, reason: 'no performance.memory' };

  const waters = [];
  for (let i = 0; i < rounds; i++) {
    await action(i);
    waters.push(await stableWater());
  }
  const tail = waters.slice(-3).filter(v => v != null);
  const tailAvg = tail.reduce((s, v) => s + v, 0) / tail.length;
  const deltaMB = +(tailAvg - baseline).toFixed(1);
  return { baseline: +baseline.toFixed(1), waters: waters.map(v => +v.toFixed(1)),
           deltaMB, leaked: deltaMB > toleranceMB };
}
// 用法：await detectLeak({ action: async () => { openModal(); await closeModal(); } })
// deltaMB 每轮台阶上涨 + leaked => 泄漏；前 2 轮上涨后稳定 => 正常缓存/预热
```

**评分点**：
- "GC 后水位"实现正确：连续多次采样取最小值 + idle 等待。
- 判定用最后 3 轮稳态均值而不是第一轮（区分预热填充与真泄漏）。
- toleranceMB 容差存在（不能拿绝对相等判定），返回完整数据便于人工复核。
- 无 performance.memory 时优雅跳过（skipped + reason）。
