## PER-1052：网络性能的量化验收：如何定义"网络优化完成"

**答**：
- 验收指标：TTFB P75、资源下载 P75、缓存命中率、弱网档位下的首屏完成时间。
- 对照实验：优化前后在相同弱网模拟（100ms RTT/2% 丢包）下跑同一脚本，取分位对比。
- 验收门槛：明确目标值（如弱网 3G 首屏 < 5s）而非"更快"；未达标项列出剩余瓶颈与责任方。
- 防回退：优化结果固化为预算与门禁（网络段指标进 CI 断言），防止后续迭代悄悄退化。

```javascript
// 网络优化验收报告
function netAcceptance(before, after, targets) {
  const items = Object.keys(targets).map(k => ({
    metric: k, before: before[k], after: after[k],
    target: targets[k], pass: after[k] <= targets[k],
    gain: +(100 * (before[k] - after[k]) / before[k]).toFixed(1) + '%',
  }));
  return { pass: items.every(i => i.pass), items };
}
// 输出直接贴到发布单，未过项写明瓶颈归属（前端/网络/服务端）
```
