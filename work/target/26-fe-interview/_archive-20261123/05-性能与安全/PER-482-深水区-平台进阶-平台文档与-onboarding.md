## PER-482：新业务线接入性能平台的完整流程？

**答**:
- 接入五步（目标 1 天完成，PER-447 衡量标准）：① 自助接入——脚手架内置 SDK（业务方 npm install + 初始化 10 行代码）；② 页面模板注册——路由规则自动识别（或 15 分钟配置）；③ SLO 基线——按页面角色自动套默认值（PER-351），业务方可调；④ 看板开通——自动生成 L1 概览（下钻自助，PER-415）；⑤ 告警接线——默认告警规则（阈值/路由到接入人），warn 模式 1 周。
- Onboarding 文档的三层：快速接入（1 小时上手）、概念手册（口径/采样/看板概念，半天读完）、深钻指南（按需）。文档验证方式：新人按文档独立接入——卡壳点回填文档（PER-340 案例库同款纪律）。
- 接入后的 30/60/90 天关怀：30 天回访（数据完整吗/看板用上了吗）、60 天（首个性能工单支持）、90 天（首次性能评审邀请）——接入不是结束，是治理关系的开始。

```text
平台 Onboarding 五步（目标 1 天）：
① SDK 自助接入（脚手架内置，10 行代码）
② 页面模板注册（自动识别或 15min 配置）
③ SLO 基线（按角色自动套默认，可调）
④ 看板开通（L1 自动生成，下钻自助）
⑤ 告警接线（默认规则 warn 模式 1 周）
文档三层：快速接入(1h) / 概念手册(半天) / 深钻指南；新人实测回填卡壳点
关怀：30 天回访 / 60 天工单支持 / 90 天首次评审 —— 接入是治理关系的开始
```
