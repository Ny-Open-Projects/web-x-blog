## PER-1226：如何做性能数据与用户反馈（应用商店评分/NPS）的关联分析

**答**：
- 假设检验：性能差（LCP 高桶）的用户评分/NPS 是否显著更低——分桶对比+显著性检验。
- 产出：每 1s LCP 对评分的影响系数，进入 ROI 模型（924）。
- 数据源：商店评分无法回连 uid，用版本+时间窗近似对齐；站内 NPS 可直接关联。
- 坑：评分还受功能变更影响——控制变量（只比同版本内的性能分桶）。

```javascript
// 同版本内性能分桶 vs NPS
function perfNps(nps, rum, version) {
  const rows = nps.filter(n => n.version === version)
    .map(n => ({ ...n, lcp: rum.find(r => r.uid === n.uid)?.lcp }));
  const buckets = { fast: [], slow: [] };
  for (const r of rows)
    if (r.lcp != null) (r.lcp <= 2500 ? buckets.fast : buckets.slow).push(r.score);
  const mean = a => a.reduce((s, v) => s + v, 0) / (a.length || 1);
  return { fast: +mean(buckets.fast).toFixed(2),
    slow: +mean(buckets.slow).toFixed(2),
    delta: +(mean(buckets.fast) - mean(buckets.slow)).toFixed(2),
    n: rows.filter(r => r.lcp != null).length };
}
```
