## PER-938：性能平台的「降级开关中心」如何设计

**答**：
- 开关模型：每个降级项（关动效/关骨架屏/切静态页/关第三方）有唯一 ID、默认态、影响面说明与回滚方式。
- 分级生效：全局 / 页面 / 用户分桶三级配置，配置中心下发 + SDK 本地缓存兜底（配置服务挂了用上次快照）。
- 演练常态化：大促前全量演练一次"一键降级"，验证开关真的能关掉且页面可用，不做演练的开关等于没有。
- 审计：每次开关变更记录（谁/何时/为什么），自动关联发版与告警，方便复盘。

```javascript
// 降级开关 SDK
const flags = { fancyAnim: true, skeleton: true, thirdParty: true };
let snapshot = { ...flags };
async function syncFlags() {
  try { snapshot = { ...flags, ...(await fetch('/flags?app=fe').then(r => r.json())) }; }
  catch { /* 用上次快照，配置中心不可用不影响页面 */ }
}
function isOn(name) { return !!snapshot[name]; }
// 演练脚本：turnOff('fancyAnim') 后用探针确认动画节点已移除
```
