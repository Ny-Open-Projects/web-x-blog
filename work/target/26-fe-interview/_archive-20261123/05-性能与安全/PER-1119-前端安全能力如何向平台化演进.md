## PER-1119：前端安全能力如何向"平台化"演进

**答**：
- 平台化内容：统一安全 SDK（脱敏/签名/探针/开关）、安全配置中心（CSP/头策略集中下发）、漏洞台账系统。
- 复用：各业务不再自写脱敏/签名逻辑，平台提供经过审计的实现；新项目脚手架内置安全基线。
- 运营：安全平台有自身的 SLO（配置下发成功率、探针在线率）与值班。
- 演进路线：SDK 统一 → 配置集中 → 检测自动化（扫描+探针）→ 响应自动化（自动收紧/断供）。

```javascript
// 安全平台 SDK 门面
export const security = {
  redact, signedFetch, trustScore,
  killSwitch: (id) => kill(id),
  policy: () => policyCenter.get(),                  // 集中配置
  probe: { injection: injectionProbe, csp: cspMonitor },
};
// 新项目：npm i @fe/security + 脚手架自动配置
// 平台 SLO：policy 下发 P95 < 1s、探针在线率 > 99%
```
