## PER-1250：如何收口"性能与安全双治理"的年度报告

**答**：
- 结构：指标大盘（性能 SLO 达成率/安全评分）、年度专项成果、事件复盘汇总（性能劣化/安全事件）、预算与人力投入、次年规划。
- 数据自动化：平台直接导出（报告手工部分 < 20%）。
- 受众分层：管理层版（一页纸：趋势+投入产出）、工程版（完整明细+待办）。
- 价值：让性能与安全从"隐形成本"变成"可汇报的资产"。

```javascript
// 年度报告装配
function annualReport(year, perf, sec) {
  return {
    exec: { perfSLO: perf.sloRate, secScore: sec.score,
      invest: perf.days + sec.days,
      incidents: perf.regressions.length + sec.incidents.length,
      oneLiner: `SLO 达成 ${perf.sloRate}%，安全评分 ${sec.score}，事件 ${perf.regressions.length + sec.incidents.length} 起` },
    detail: { perf, sec },
    next: { perf: perf.nextYear, sec: sec.nextYear },
  };
}
// 管理层版只取 exec 字段生成一页纸
```
