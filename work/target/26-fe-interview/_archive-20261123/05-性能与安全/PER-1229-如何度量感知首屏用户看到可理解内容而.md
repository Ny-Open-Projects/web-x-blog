## PER-1229：如何度量"感知首屏"（用户看到可理解内容）而非技术首屏

**答**：
- 动机：LCP 可能是一张大图/骨架屏，用户"看懂页面"另有时刻——定义"内容可懂时刻"（Meaningful Paint）。
- 定义：核心信息元素（标题+关键数据）全部可见且非加载态，业务自定义打点。
- 度量：SDK 在业务标记点上报（如列表首条数据渲染完成），与 LCP 差值作为"感知缺口"指标。
- 治理：缺口大说明骨架时间过长或信息层级有问题——产品与前端联合优化。

```javascript
// 感知首屏打点
function markMeaningful(name) {
  performance.mark(`mp:${name}`);
  const nav = performance.getEntriesByType('navigation')[0];
  const lcp = window.__lcpValue ?? 0;
  report({ metric: 'meaningful-paint', name,
    ts: performance.now(), gapVsLcp: lcp ? +(performance.now() - lcp).toFixed(0) : null });
}
// 使用：列表首条数据渲染后 markMeaningful('list-first-item')
// gapVsLcp 高 -> 骨架期过长，考虑并行请求或流式渲染
```
