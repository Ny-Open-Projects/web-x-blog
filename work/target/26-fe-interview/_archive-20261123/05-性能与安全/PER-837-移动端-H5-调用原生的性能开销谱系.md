## PER-837：移动端 H5 调用原生的性能开销谱系：哪些 JSAPI 慢、慢在哪、怎么规避

**答**：
- 开销谱系（经验量级）：同步取值类（getAppVersion）< 5ms；存储类（set/getStorage）10~30ms；涉及 UI 的（toast/dialog/选图）50~200ms（含 Native 渲染）；重型类（扫码/支付/拍照）秒级且切页面。
- 慢的来源：桥通信本身（序列化+线程切换）、Native 实现（IO/渲染）、页面栈切换（H5 与 Native 层来回）。
- 规避手段：高频轻 API 合并批量调用；重型 API 提前预热（如选图页提前初始化相机权限）；同步 API 能避免就避免（阻塞 JS 线程）；调用结果可缓存的做本地缓存（版本号类）。
- 度量先行：建立 JSAPI 耗时基线表（批量跑分），超基线的调用点告警——很多"莫名卡顿"最后都查到某个高频重型 JSAPI。

```javascript
const API_COST_BASELINE = {                // JSAPI 耗时基线（ms, p75）
  getVersion: 3, getStorage: 15, setStorage: 25, toast: 80, chooseImage: 400, scan: 1500,
};
const apiTimer = {
  wrap(bridge) {
    return new Proxy(bridge, { get(t, name) {
      return async (...args) => {
        const s = performance.now();
        const r = await t[name](...args);
        const ms = performance.now() - s;
        const base = API_COST_BASELINE[name];
        report('jsapi-cost', { api: name, ms: +ms.toFixed(1) });
        if (base && ms > base * 2) warnSlowApi(name, ms, base);   // 超基线 2 倍告警
        return r;
      };
    } });
  },
};
// 缓存型 API：版本号类调用本地化
let cachedVersion;
async function getVersion(b) { return cachedVersion ??= await b.getVersion(); }
```
