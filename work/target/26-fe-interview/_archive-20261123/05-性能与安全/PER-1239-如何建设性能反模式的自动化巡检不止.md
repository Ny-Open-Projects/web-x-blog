## PER-1239：如何建设"性能反模式的自动化巡检"（不止 lint）

**答**：
- 巡检对象：线上运行时行为（不只代码）——长任务频率、强制布局次数、监听器增长、内存水位。
- 实现：探针 SDK 周期采样 + 规则判定 → 巡检报告（页面×反模式矩阵）→ 违规开单。
- 与 lint 分工：lint 拦代码层（写法），巡检拦运行层（数据规模/三方交互导致的实际问题）。
- 节奏：巡检每 6h 一轮，新页面自动纳入。

```javascript
// 运行时巡检规则
const INSPECT_RULES = [
  { id: 'layout-thrash', test: s => s.forcedLayoutPerMin > 30,
    sev: 'P1' },
  { id: 'listener-leak', test: s => s.listenerGrowthPerDay > 100,
    sev: 'P0' },
  { id: 'long-task-heavy', test: s => s.longTaskRate > 0.2, sev: 'P1' },
];
function inspect(signals) {
  return INSPECT_RULES.filter(r => r.test(signals))
    .map(r => ({ id: r.id, sev: r.sev, ticket: true }));
}
// 周期执行：setInterval(() => inspect(sample()), 6 * 3600_000)
```
