## PER-1092：安全配置基线：上线前必须检查的清单

**答**：
- 传输：全站 HTTPS（HSTS max-age ≥ 1 年 + includeSubDomains）、禁 TLS 1.0/1.1、证书链完整。
- 响应头：CSP（至少 report-only 全覆盖）、X-Content-Type-Options: nosniff、frame-ancestors、Referrer-Policy: strict-origin-when-cross-origin。
- Cookie：HttpOnly + Secure + SameSite 全覆盖，会话 cookie 不设持久过期。
- 依赖：audit 无高危、无 postinstall 脚本、SRI 覆盖全部 CDN 资源。

```javascript
// 上线安全检查单（自动执行）
const CHECKS = [
  { id: 'hsts', test: h => /max-age=[3-9]\d{6,}/.test(h['strict-transport-security'] ?? '') },
  { id: 'nosniff', test: h => h['x-content-type-options'] === 'nosniff' },
  { id: 'csp', test: h => (h['content-security-policy'] ?? '').includes('script-src') },
  { id: 'cookie-secure', test: h => (h['set-cookie'] ?? '').includes('Secure') },
];
function baselineScan(headers) {
  return CHECKS.map(c => ({ id: c.id, pass: c.test(headers) }));
}
// CI 每次发版跑一遍，全绿才允许上线
```
