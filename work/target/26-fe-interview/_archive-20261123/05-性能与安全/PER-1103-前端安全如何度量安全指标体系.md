## PER-1103：前端安全如何度量（安全指标体系）

**答**：
- 指标：高危漏洞存量与新增（扫描器）、XSS/CSP 违规事件率、依赖高危数、SRI 覆盖率、敏感日志泄漏抽样命中、安全修复 MTTR。
- 基线：每季度安全基线扫描（响应头/依赖/配置）输出评分。
- 预警类指标：CSP violation report 按域名聚合（突增 = 攻击尝试）、异常登录率。
- 汇报：安全看板 + 季度报告，让管理层看见投入产出。

```javascript
// 安全健康度评分
function securityScore(checks) {
  // checks: [{ id, weight, pass }]
  const total = checks.reduce((s, c) => s + c.weight, 0);
  const got = checks.filter(c => c.pass).reduce((s, c) => s + c.weight, 0);
  return { score: +(got / total * 100).toFixed(1),
    fails: checks.filter(c => !c.pass).map(c => c.id) };
}
// checks 例：hsts(10)/csp-enforce(20)/audit-clean(20)/sri(10)/
// sourcemap-404(10)/cookie(15)/mttr<3d(15)
```
