## PER-1006：被遗忘权（删除请求）在前端体系的实现

**答**：
- 链路：用户发起删除 → 全链路（埋点明细/会话回放/日志/备份）定位主体数据 → 删除或匿名化 → 回执。
- 技术要点：主体以不可逆哈希关联，各系统持有哈希即可执行删除；备份按滚动过期处理（承诺期 ≤ 备份生命周期）。
- 前端动作：本地数据清理（storage/indexedDB）、采集 SDK 停止上报该主体、会话回放按 uid 检索删除。
- 时限：GDPR 要求 30 天内响应，工程上应做到小时级自动处理。

```javascript
// 删除协调器（前端侧示意）
async function handleErasure(uidHash) {
  await Promise.all([
    clearIndexedDBFor(uidHash),
    clearLocalStorageFor(uidHash),
  ]);
  await fetch('/privacy/erase', { method: 'POST',
    body: JSON.stringify({ subject: uidHash }) });
  trackingDisabled = true;                     // 本 SDK 永久停止采集
  logAudit(uidHash, 'erase', 'DSAR');
  return { done: true, at: new Date().toISOString() };
}
```
