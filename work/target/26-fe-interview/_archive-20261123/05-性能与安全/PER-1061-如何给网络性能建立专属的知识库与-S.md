## PER-1061：如何给"网络性能"建立专属的知识库与 SLO

**答**：
- SLO 定义：TTFB P75 ≤ 800ms、资源命中率 ≥ 90%、错误率 < 0.5%、弱网首屏 ≤ 5s——可度量可追责。
- 知识库内容：协议特性决策记录（为何选 H3）、缓存策略矩阵、弱网策略库、故障案例（DNS 劫持/UDP 限制）。
- 联动：SLO 违约自动开单到对应 Owner（前端资源命中率 / 后端 TTFB），周会过趋势。
- 沉淀节奏：每次网络专项后更新 SLO 基线与策略库，防止"优化一次又退化"。

```javascript
// 网络 SLO 看板数据
function netSLOBoard(rum, { ttfb = 800, hitRate = 90, errRate = 0.5 } = {}) {
  const ttfbP75 = quantile(rum.map(r => r.ttfb), 0.75);
  const hit = rum.filter(r => r.transferSize === 0).length / rum.length * 100;
  const err = rum.filter(r => r.failed).length / rum.length * 100;
  return { ttfbP75, hitRate: +hit.toFixed(1), errRate: +err.toFixed(3),
    violations: [
      ttfbP75 > ttfb && `TTFB P75 ${ttfbP75}ms > ${tttfb ?? ttfb}`,
      hit < hitRate && `命中率 ${hit.toFixed(1)}% < ${hitRate}%`,
      err > errRate && `错误率 ${err.toFixed(2)}% > ${errRate}%`,
    ].filter(Boolean) };
}
function quantile(a, q) { const s = [...a].sort((x, y) => x - y);
  return s[Math.floor(s.length * q)] ?? 0; }
```
