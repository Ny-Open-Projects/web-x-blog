## PER-1170：前端埋点的"隐私安全设计模式"总结

**答**：
- 原则一：事件级注册（1004）——字段即文档，未注册不发。
- 原则二：ID 最小化——用会话哈希而非持久设备 ID 做分析；长期 ID 仅登录场景。
- 原则三：内容不入埋点——埋点记"发生了什么"，不记"内容是什么"（搜索词脱敏/文档标题截断）。
- 原则四：端侧聚合优先——能用本地聚合就不发明细（1151）。
- 原则五：可关闭可验证——采集可停且停了能证明（1158）。

```javascript
// 埋点隐私守卫（SDK 统一出口）
function privacyGuard(event) {
  const rules = [
    e => !registry[e.name] && 'unregistered',
    e => Object.keys(e).some(k => /content|title|text|query/.test(k))
        && 'content-field-forbidden',               // 内容字段拦截
    e => e.uid && !e.pseudonymized && 'raw-uid-forbidden',
  ];
  for (const r of rules) { const v = r(event); if (v) return { send: false, reason: v }; }
  return { send: true };
}
```
