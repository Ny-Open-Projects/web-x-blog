## PER-1105：前端如何配合风控系统做设备指纹（合规版）

**答**：
- 合规前提：指纹用于风控（合法利益）需在隐私政策披露；不用作广告画像；GDPR 下需 DPIA 评估。
- 数据项：UA/屏幕/时区/语言/Canvas 特征（低精度）——避免高识别度组合，加噪声（Privacy Sandbox 思路）。
- 存储：设备 ID 存本地（first-party cookie/IDFV），跨会话稳定但不跨站共享。
- 生命周期：用户可请求重置（换新指纹），风控模型容忍一定重置率。

```javascript
// 合规版设备指纹（低精度 + 披露）
function deviceFingerprint() {
  const raw = [navigator.userAgent, screen.width + 'x' + screen.height,
    Intl.DateTimeFormat().resolvedOptions().timeZone,
    navigator.language].join('|');
  return {
    id: hash(raw),                                   // 不可逆哈希
    precision: 'low',                                // 只用于风控
    disclosed: true,                                 // 隐私政策已披露
  };
}
// 用户重置：
function resetFingerprint() { localStorage.removeItem('fp');
  logAudit(currentUser, 'fp-reset', 'user request'); }
```
