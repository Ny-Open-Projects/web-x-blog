## PER-1166：隐私与用户体验的冲突怎么破（同意疲劳问题）

**答**：
- 问题：频繁弹窗导致"同意疲劳"——用户不看就点同意，同意失去意义。
- 解法：一次性 granular 设置（首次给完整面板而非连环弹窗）、按场景延迟请求（用到相机才问相机）、渐进披露。
- 技术：上下文记忆（拒绝过的权限不再重复弹，给替代路径）、面板代替弹窗（集中管理减少打扰）。
- 底线：合规要求的告知不可省，但可以整合与去重（一次说明覆盖多 SDK）。

```javascript
// 同意疲劳缓解策略
function consentStrategy(history) {
  const declined = history.filter(h => h.choice === 'decline');
  return {
    mode: declined.length >= 3 ? 'panel-first' : 'inline',
    rememberDecline: true,                       // 拒绝过不再弹
    alternative: { camera: '手动上传照片', location: '手动选择城市' },
  };
}
// panel-first：进入设置面板一次配完所有桶，替代连环弹窗
```
