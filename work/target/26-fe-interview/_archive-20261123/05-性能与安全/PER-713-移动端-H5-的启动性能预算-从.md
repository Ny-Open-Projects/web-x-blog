## PER-713：移动端 H5 的启动性能预算：从容器创建到可交互的全预算表与超预算时的裁剪顺序

**答**：
- 预算表（低端机口径）：容器启动 300ms、HTML+关键 CSS 150ms、首屏 JS 执行 150ms、首屏接口 500ms、可交互收尾 100ms，总 < 1.2s（中高端 < 800ms）。
- 超预算裁剪顺序（按用户感知损失从小到大）：非首屏模块延后 -> 动画/特效关闭 -> 图片降档 -> 非核心接口砍掉 -> 骨架屏兜底；裁剪动作要预先声明（降级清单模式，见 701/702）。
- 预算的动态性：按实测量自动收敛（探针发现某段持续超标 -> 自动触发对应档位的裁剪预案并记录），而不是人工盯。
- 度量闭环：预算表进 CI 与监控告警（分段超预算告警），裁剪触发率进周报（触发率过高说明基础体验不行，要立项而不是靠裁剪续命）。

```javascript

const h5StartupBudget = {
  lowEnd: { container: 300, htmlCss: 150, jsExec: 150, firstApi: 500, interact: 100, total: 1200 },
  flagship: { total: 800 },
  trimOrder: ['非首屏模块延后', '动画关闭', '图片降档', '砍非核心接口', '骨架屏兜底'],
  dynamic: '探针发现分段持续超标 -> 自动执行该段裁剪预案并记录',
  closure: '预算进 CI+告警；裁剪触发率进周报（过高要立项，不靠裁剪续命）',
};
console.log(h5StartupBudget.trimOrder.join(' -> '));
```
