## PER-940：性能数据的可视化选型有什么原则？看板技术栈怎么选

**答**：
- 原则：看板是高频低复杂度场景——时序折线 + 下钻表为主，避免炫技 3D；首屏与查询速度比美观重要。
- 技术栈：ECharts（生态全）/ 低代码看板（Grafana 若数据在 Prometheus/CH）+ 服务端预聚合接口，前端只做装配。
- 性能要求：看板自身要快（< 2s 出图），数据量大时分页/增量加载、聚合下推到数据库。
- 一致性：指标颜色/阈值色带全平台统一（绿/黄/红语义固定），降低认知成本。

```javascript
// 看板接口设计：聚合下推
// GET /api/board?page=shop&metric=lcp&from=..&to=..&granularity=day
function boardSQL(q) {
  return `SELECT toDate(ts) d, quantile(0.75)(lcp) p75, count() n
          FROM perf WHERE page = '${q.page}'
            AND ts BETWEEN '${q.from}' AND '${q.to}'
          GROUP BY d ORDER BY d`;      // 聚合在 CH 完成，前端拿小结果集
}
// 反模式：拉明细 10 万行到前端再算分位
```
