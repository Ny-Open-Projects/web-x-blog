## PER-1191：隐私工程与数据中台的协作界面

**答**：
- 中台视角：统一数据模型/质量/血缘；隐私视角：字段级别/合法基础/保留期——两者必须在同一元数据层合流。
- 接口：字段注册表与中台数据目录打通（一处登记处处生效）；ETL 任务的隐私策略继承上游字段级别。
- 执行：下游任务自动继承（订单号是 S2，派生表也是 S2，除非聚合脱敏）。
- 治理：血缘图支持"某字段流到了哪些下游"查询（DSAR/泄露评估直接用）。

```javascript
// 隐私级别血缘传播
function propagateLevel(fieldLevel, transform) {
  if (transform === 'agg-count') return 1;          // 聚合计数降为公开
  if (transform === 'hash') return Math.max(1, fieldLevel - 1);  // 假名化降一级
  return fieldLevel;                                // 默认继承
}
// 派生表登记时自动计算：
// orders.amount(S2) -> daily_revenue(agg) -> level 1
// orders.phone(S3) -> crm_contact(hash) -> level 2（仍需权限）
```
