## PER-1198：隐私工程路线图：从合规底线到隐私领先

**答**：
- L1 合规底线：政策/同意/DSAR/审计——不做即风险。
- L2 工程化：注册表/管线/数据地图/测试——合规可自动化。
- L3 隐私领先：差分隐私/端侧计算/透明度报告——隐私成为产品竞争力。
- 演进节奏：L1 半年、L2 一年、L3 按业务价值选择试点。
- 验收：每级有硬指标（L1 零违规、L2 自动化率 > 70%、L3 试点上线且有用户价值）。

```javascript
// 隐私成熟度模型
const LEVELS = {
  L1: { name: '合规底线', gates: ['policy', 'consent', 'dsar', 'audit'] },
  L2: { name: '工程化', gates: ['registry', 'pipeline', 'datamap', 'tests'] },
  L3: { name: '隐私领先', gates: ['dp', 'ondevice', 'transparency'] },
};
function maturity() {
  const done = new Set(capabilities());
  return Object.entries(LEVELS).map(([lv, def]) =>
    ({ level: lv, name: def.name,
      progress: +(def.gates.filter(g => done.has(g)).length / def.gates.length * 100).toFixed(0) + '%' }));
}
```
