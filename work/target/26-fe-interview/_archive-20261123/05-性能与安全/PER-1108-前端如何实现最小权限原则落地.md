## PER-1108：前端如何实现"最小权限原则"落地

**答**：
- API 层面：请求层只带必要凭证（不全局挂 token）；按页面注入最小 scope 的权限。
- 能力层面：高敏感能力（剪贴板/摄像头/文件系统）按需请求 + 用完释放（Permission-Policy 限制 iframe）。
- 依赖层面：SDK 按需引入而非全家桶；第三方脚本不给全局 window 污染权限。
- 代码层面：模块内变量不逃逸全局；不滥用 window.xxx 做通信（改事件/依赖注入）。

```javascript
// 最小权限的凭证注入
// 反模式：window.TOKEN = xxx（全局可读，任何注入脚本可窃）
// 正解：模块闭包 + 按请求注入
let _token = null;                                    // 闭包私有
export function setToken(t) { _token = t; }
export function api(url, init = {}) {
  return fetch(url, { ...init,
    headers: { ...init.headers, Authorization: `Bearer ${_token}` } });
}
// iframe 场景：
// <iframe allow="camera" credentials> 只授子页真正需要的能力
// 权限用完：navigator.permissions 撤销提示用户关闭
```
