## PER-1266：手写一个性能告警分级器：按影响面与持续时长

**答**：
- 需求：实现 classifyPerfAlert(evt)。evt: { metric, value, baseline, affectedPct, durationMin }；分级：affectedPct > 20% 且 duration > 30min -> P0；affectedPct > 5% 或 duration > 60min -> P1；其余 P2；metric 为 Core Web Vitals 时影响面权重 ×1.5；输出 { level, reason }。
- 边界：baseline 为 0 时按超 SLO 判定（传 slo 参数）；duration 缺失按 0；affectedPct clamp [0,100]。
- 评分点：影响面权重；持续时长；clamp；分级理由

```javascript
function classifyPerfAlert(evt, { slo = 2500 } = {}) {
  const core = ['lcp', 'inp', 'cls'].includes(evt.metric);
  const affected = Math.min(100, Math.max(0, evt.affectedPct ?? 0)) * (core ? 1.5 : 1);
  const dur = evt.durationMin ?? 0;
  const isCore = core && evt.value > slo;
  if (affected > 20 * (core ? 1.5 : 1) && dur > 30)
    return { level: 'P0', reason: `影响面 ${affected.toFixed(0)}% 且持续 ${dur}min` };
  if (affected > 5 * (core ? 1.5 : 1) || dur > 60 || isCore)
    return { level: 'P1', reason: isCore ? 'Core Web Vitals 超 SLO' : `影响面/持续达标` };
  return { level: 'P2', reason: '低影响面观察' };
}
```
