## PER-1190：前端如何做"隐私风险自查"（开发者自查清单）

**答**：
- 自查十问：字段注册了吗/级别对吗/默认开还是关/能关吗/日志脱敏吗/保留期声明了吗/第三方登记了吗/删除路径通吗/测试覆盖了吗/证据留了吗。
- 形式：MR 模板内置自查 checklist（勾选才可提交）、平台 CLI 一键预检。
- 抽查：每月随机抽 MR 复核自查真实性，造假通报。
- 进化：从审计发现问题反推清单条目，清单保持 ≤ 15 条（太长没人看）。

```javascript
// 自查清单 CLI
const CHECKLIST = ['字段注册', '级别正确', '默认最小', '可关闭',
  '日志脱敏', '保留期', '第三方登记', '删除路径', '测试覆盖', '审计留痕'];
function selfCheck(mr) {
  const missing = CHECKLIST.filter(c => !mr.checks?.[c]);
  return { pass: missing.length === 0, missing,
    hint: missing.map(m => `${m}: 参见模式库（1165）` });
}
// 平台 CLI：npx fe-privacy-check --mr 123
```
