## PER-911：性能问题如何与业务指标挂钩？怎么说服老板投入

**答**：
- 建立"性能→业务"漏斗：LCP 每提升 1s → 跳出率下降 x% → 转化率提升 y%，用 RUM 关联分析或历史专项数据佐证。
- 经典数据锚点：Google/Deloitte 等公开研究（加载 0.1s 级别改善带来转化提升）+ 自己业务的分桶回归（LCP 分桶 vs 转化的散点）。
- 成本量化：一个专项投入 N 人日，预期 LCP -800ms，折算 GMV/留存收益，与需求排期对比。
- 持续机制：把性能指标纳入业务 OKR/发版门禁，让它从"专项运动"变成"日常工程"。

```javascript
// RUM 关联分析：LCP 分桶 vs 转化率
function lcpConversion(rows) {
  // rows: [{ lcpBucket, sessions, conversions }]
  return rows.map(r => ({ ...r,
      cvr: +(r.conversions / r.sessions * 100).toFixed(2) }))
    // 输出后拟合线性段：cvr ≈ a - b * lcp，b 即"每多 1s 损失多少转化"
    .sort((a, b) => a.lcpBucket - b.lcpBucket);
}
// 汇报模板：基线→目标→收益折算→人力成本→ROI
```
