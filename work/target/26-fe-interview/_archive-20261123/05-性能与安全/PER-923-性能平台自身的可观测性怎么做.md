## PER-923：性能平台自身的可观测性怎么做

**答**：
- 平台也是系统：SDK 上报成功率、上报延迟、网关写入 TPS、聚合任务延迟都要被监控（自指监控）。
- 数据质量监控：字段缺失率、异常值比例（lcp<0 或 >60000）、采样比例漂移，数据坏了告警先于业务发现。
- 影子验证：SDK 新版本先 1% 影子流量对比新旧指标差异（口径漂移检测），确认一致再放量。
- 平台 SLO：看板查询 P95 < 3s、告警延迟 < 10min、数据完备率 > 99.5%。

```javascript
// SDK 上报质量自检
function healthCheck(sent, acked, dropped) {
  const total = sent + dropped;
  return {
    deliveryRate: +(acked / total * 100).toFixed(2) + '%',   // 到达率
    dropRate: +(dropped / total * 100).toFixed(2) + '%',
    ok: acked / total > 0.995,       // 平台 SLO：完备率 99.5%
  };
}
// 到达率异常 -> 先怀疑网关/压缩 bug，而不是业务页面问题
```
