## PER-1091：移动端 H5 的安全差异点（相对桌面 Web）

**答**：
- WebView 配置：JS 注入接口（addJavascriptInterface/JSBridge）是最大攻击面——Bridge 方法白名单 + 调用签名校验。
- 剪贴板风险：读剪贴板拿粘贴的敏感信息（卡号/验证码），仅在用户明确操作时读取。
- URL Scheme 劫持：scheme 跳转参数注入（仿冒deeplink），服务端校验跳转目标。
- 本地存储加密：WebView 缓存的 localStorage 与 App 同目录，敏感数据加密或走原生 KeyChain。

```javascript
// JSBridge 白名单 + 签名校验
const BRIDGE_API = new Set(['getDeviceInfo', 'scanCode', 'share']);
window.__native_bridge = (call) => {
  const { method, params, sign, ts } = JSON.parse(call);
  if (!BRIDGE_API.has(method)) throw new Error('method not allowed');
  if (Math.abs(Date.now() - ts) > 10_000) throw new Error('expired');
  if (!verifySign(method, params, ts, sign)) throw new Error('bad sign');
  return NATIVE_IMPL[method](params);
};
// App 侧注入时只暴露 __native_bridge，真实能力在原生侧校验
```
