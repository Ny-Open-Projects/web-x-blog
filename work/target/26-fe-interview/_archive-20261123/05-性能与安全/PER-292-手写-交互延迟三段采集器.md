## PER-292：手写交互延迟三段拆解采集器（input/processing/presentation 上报与归一化）

**题目**：实现 `trackInteractionPhases(report, threshold = 100)`：① 用 Event Timing 采集交互，按 interactionId 聚合取最长 duration 的事件；② 拆解三段：input delay = processingStart - startTime；processing = processingEnd - processingStart；presentation = duration - (processingEnd - startTime)；③ 只上报 duration > threshold 的交互；④ 附语义化目标元素标签（复用 closest 按钮/输入框逻辑）；⑤ 上报后防止同交互重复。

**答**：Event Timing entry 的字段天然支持三段拆解；聚合取 max 的规则见 PER-230。语义化目标是让看板能按"点击了什么"聚合。

```javascript
function semanticTarget(el) {
  const t = el?.closest?.('button, a, [role=button], input, select, [data-test-id]');
  return t?.dataset.testId || t?.tagName || el?.tagName || 'unknown';
}

function trackInteractionPhases(report, threshold = 100) {
  const seen = new Map();                  // interactionId -> best {dur, phases}
  new PerformanceObserver((list) => {
    for (const e of list.getEntries()) {
      if (e.interactionId == null) continue;
      const prev = seen.get(e.interactionId);
      if (prev && prev.dur >= e.duration) continue;            // 同交互只取最长事件
      const input = +(e.processingStart - e.startTime).toFixed(1);
      const proc  = +(e.processingEnd - e.processingStart).toFixed(1);
      const pres  = +(e.duration - (e.processingEnd - e.startTime)).toFixed(1);
      seen.set(e.interactionId, { dur: e.duration,
        phases: { input, processing: proc, presentation: pres },
        target: semanticTarget(e.target), type: e.name });
    }
  }).observe({ type: 'event', durationThreshold: threshold, buffered: true });

  const flush = () => {
    for (const [, s] of seen) {
      if (s.dur > threshold) report({ type: 'interaction-phases', ...s });
    }
    seen.clear();
  };
  document.addEventListener('visibilitychange', () => {
    if (document.visibilityState === 'hidden') flush();
  });
}
// 看板按 target × type 聚合三段分布：哪类点击的 input delay 大 => 主线程忙；
// processing 大 => handler 慢；presentation 大 => 渲染贵
```

**评分点**：
- 三段公式正确（尤其 presentation = duration - (processingEnd - startTime)）。
- 同 interactionId 取最长 duration（聚合规则），不重复上报。
- durationThreshold 同时充当 observer 参数与上报阈值。
- 目标元素语义化（closest + testId），上报结构可直接驱动看板聚合。
