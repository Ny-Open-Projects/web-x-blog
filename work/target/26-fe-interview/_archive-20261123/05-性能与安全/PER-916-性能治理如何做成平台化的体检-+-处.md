## PER-916：性能治理如何做成平台化的"体检 + 处方"能力

**答**：
- 体检：定期（每次发版 + 每周巡检）对全站页面跑规则引擎（100+ 检查项：未压缩图片、阻塞脚本、内存泄漏迹象、过期依赖）。
- 处方：每个检查项挂修复 playbook（怎么做、预期收益、常见坑），体检报告一键生成改进任务并指派 Owner。
- 分级：P0（阻塞项，门禁拦截）、P1（建议项，限期整改）、P2（观察项），避免"报告很厚没人看"。
- 闭环度量：问题发现→修复→复检通过率、平均修复时长，作为平台核心 KPI。

```javascript
// 规则引擎示例
const RULES = [
  { id: 'img-uncompressed', test: r => r.type === 'image' && r.size > 200_000,
    level: 'P0', fix: '转 WebP/AVIF + 构建期压缩，预期 -60% 体积' },
  { id: 'sync-script', test: r => r.type === 'script' && !r.async && !r.defer,
    level: 'P0', fix: '改 defer/async 或动态注入' },
  { id: 'long-task-leak', test: s => s.longTaskRate5min > 0.15,
    level: 'P1', fix: '排查定时器/监听器泄漏' },
];
function audit(resources, signals) {
  return RULES.filter(r => resources.some(r.test) || (r.test.length && r.test(signals)))
    .map(r => ({ id: r.id, level: r.level, playbook: r.fix }));
}
```
