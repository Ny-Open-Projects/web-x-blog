## PER-227：手写 RUM 采样归一——按导航类型过滤 back_forward/reload，统一为"首次进入"口径

**题目**：实现 `normalizeSample(entry)`：① 输入 navigation entry，输出 `{ navType, isCacheHit, valid }`；② navigate 计 valid，reload/back_forward 标记后默认剔除（可配置保留）；③ bfcache 恢复（pageshow persisted 或 notRestoredReasons 为空且 type 为 back_forward）计 isCacheHit 且剔除；④ 时间字段用 entry 的类型字段而非 UA 猜测。

**答**：RUM 数据要可比，必须先归一导航类型。判定优先用 PerformanceNavigationTiming.type 与 pageshow persisted，不要用 performance.navigation（已废弃）。

```javascript
function normalizeSample(entry, { keepReload = false, keepBackForward = false } = {}) {
  const navType = entry?.type ?? 'unknown';        // PerformanceNavigationTiming.type
  const sample = { navType, isCacheHit: false, valid: false };

  // bfcache 判定：back_forward + 页面从缓存恢复（persisted）视为缓存命中
  addEventListener('pageshow', function onShow(e) {
    if (e.persisted && navType === 'back_forward') sample.isCacheHit = true;
    removeEventListener('pageshow', onShow);
  }, { once: true });

  switch (navType) {
    case 'navigate': sample.valid = true; break;                      // 正常首跳
    case 'reload':    sample.valid = keepReload; break;               // 可选保留
    case 'back_forward': sample.valid = keepBackForward && !sample.isCacheHit; break;
    default: sample.valid = false;                                    // prerender 等另算
  }
  return sample;
}

// 用法：只上报归一后的有效样本
new PerformanceObserver((list) => {
  for (const nav of list.getEntries()) {
    const s = normalizeSample(nav);
    if (s.valid) sendBeacon('/rum/nav', JSON.stringify({ ...s, ttfb: nav.responseStart - nav.startTime }));
  }
}).observe({ type: 'navigation', buffered: true });
```

**评分点**：
- 用 PerformanceNavigationTiming.type 判定（不用已废弃的 performance.navigation）。
- bfcache（persisted + back_forward）识别为缓存命中并剔除。
- reload/back_forward 可配置保留与否（策略可调，不写死）。
- 输出结构包含 navType/isCacheHit/valid，便于看板分组统计。
