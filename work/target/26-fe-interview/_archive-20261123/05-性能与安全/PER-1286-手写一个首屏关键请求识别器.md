## PER-1286：手写一个"首屏关键请求"识别器

**答**：
- 需求：implement criticalRequests(entries, nav, lcpUrl)。关键 = 首屏 2s 内开始且满足其一：LCP 图片本身、阻塞 CSS、首屏接口（fetch/xmlhttprequest 且 responseEnd < 2000）；输出 { critical: [name], wasted: [name] }（2s 内开始但非关键的为浪费请求）。
- 边界：initiatorType 判断由 entry.requestStart 存在近似；lcpUrl 匹配用 endsWith；entries 无 navigation 类型按传入 nav。
- 评分点：时间窗；三类关键；浪费识别；路径归一

```javascript
function criticalRequests(entries, lcpUrl) {
  const critical = [], wasted = [];
  for (const e of entries) {
    if (e.startTime > 2000) continue;
    const path = new URL(e.name, location.href).pathname;
    const isLcp = lcpUrl && e.name.endsWith(lcpUrl);
    const isBlocking = /\.css$/.test(path);
    const isApi = ['fetch', 'xmlhttprequest'].includes(e.initiatorType);
    if (isLcp || isBlocking || isApi) critical.push(path);
    else wasted.push(path);
  }
  return { critical, wasted };
}
// wasted 高 -> 检查预取策略与三方脚本时机
```
