## PER-1087：日志脱敏的工程化：哪些字段必须脱敏

**答**：
- 强敏：手机号/身份证/银行卡（掩码 + 哈希可关联）、地址、姓名（高保真日志禁全量）。
- 中敏：IP（截断末段）、地理位置（城市级）、设备 ID（哈希）。
- 机制：日志 SDK 统一脱敏管道（正则 + 字段白名单），原始值不出业务域；诊断日志走独立权限通道并留审计。
- 验证：定期抽样检查线上日志明文敏感值命中数为 0。

```javascript
// 日志脱敏管道
const RULES = [
  { re: /1[3-9]\d{9}/g, to: m => m.slice(0, 3) + '****' + m.slice(7) },      // 手机号
  { re: /(\d{6})\d{9}(\d{2})/g, to: (m, p1, p2) => p1 + '**********' + p2 }, // 卡号
  { re: /\d{17}[\dXx]/g, to: () => 'ID-REDACTED' },                          // 身份证
  { re: /(\d+\.\d+\.\d+)\.\d+/g, to: (m, p1) => p1 + '.0' },            // IP 截断
];
function redact(msg) {
  let out = String(msg);
  for (const { re, to } of RULES) out = out.replace(re, to);
  return out;
}
console.log(redact('用户13812345678从192.168.1.23登录'));
```
