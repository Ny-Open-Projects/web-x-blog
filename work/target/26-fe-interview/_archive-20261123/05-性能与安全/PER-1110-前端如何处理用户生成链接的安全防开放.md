## PER-1110：前端如何处理"用户生成链接"的安全（防开放重定向）

**答**：
- 风险：跳转参数（?redirect=）未校验即成钓鱼跳板（可信域名跳转到恶意站）。
- 校验：白名单域名（或仅站内相对路径）、禁止协议相对 URL（//evil.com）、编码绕过全解码后校验。
- 体验平衡：外部链接给确认页（展示目标域名让用户确认），营销场景常用。
- 测试：编码绕过用例集（%2f%2f、\/\/、双编码）进回归。

```javascript
// 开放重定向防护
const ALLOW_HOSTS = new Set(['example.com', 'm.example.com']);
function safeRedirect(target) {
  if (!target) return '/';
  let t = target;
  for (let i = 0; i < 3; i++) t = decodeURIComponent(t);   // 多重解码
  if (/^\/[^/]/.test(t) && !t.startsWith('//')) return t; // 站内相对路径
  try {
    const u = new URL(t);
    if (u.protocol === 'https:' && ALLOW_HOSTS.has(u.host)) return t;
  } catch {}
  return '/redirect-confirm?to=' + encodeURIComponent(t);  // 外链确认页
}
// 用例：'//evil.com' 'https://evil.com' '/%2f%2fevil.com' 全部拦截
```
