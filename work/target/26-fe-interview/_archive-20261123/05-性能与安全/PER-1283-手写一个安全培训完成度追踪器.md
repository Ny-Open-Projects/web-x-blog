## PER-1283：手写一个安全培训完成度追踪器

**答**：
- 需求：implement trainingTracker(people, required)。people 为 [{ uid, passed: [courseId], lastAt }]；required 为必修课程 ID 数组；完成 = required 全过且 lastAt 在 365 天内；输出 { compliant: [uid], overdue: [{ uid, missing }], rate }。
- 边界：lastAt 缺失视为过期；missing 按未过课程列表；rate 保留 1 位；passed 含已过但过期的课程不计入完成。
- 评分点：时效判定；缺失课程；完成率；过期重修

```javascript
function trainingTracker(people, required) {
  const now = Date.now();
  const compliant = [], overdue = [];
  for (const p of people) {
    const fresh = p.lastAt && now - p.lastAt <= 365 * 86400_000;
    const missing = required.filter(c => !fresh || !p.passed?.includes(c));
    if (!missing.length) compliant.push(p.uid);
    else overdue.push({ uid: p.uid, missing });
  }
  return { compliant, overdue,
    rate: +(compliant.length / (people.length || 1) * 100).toFixed(1) + '%' };
}
```
