## PER-897：移动端真机云测平台的接入与产出：云真机跑分的任务设计与数据消费

**答**：
- 云真机的价值：无法自建全机型矩阵时，用云测平台批量跑分覆盖 Top 机型（150+ 台），产出客观的分机型性能数据。
- 任务设计：跑分任务要可控——固定网络档（平台支持弱网注入）、固定账号与预热状态（区分冷热启）、版本绑定（跑的是哪个 commit 的包）；单机型单用例执行时间可控（< 5 分钟）。
- 产出消费：跑分数据回流性能平台（机型×页面×指标矩阵），用于：发版前矩阵体检（新版本在 10 台代表机型回归）、机型专项（Top 劣化机型清单驱动优化）。
- 工程化要点：跑分脚本与业务测试解耦（探针 SDK 统一注入）、结果数据 schema 版本化、平台不稳定因素（虚拟机/温度）要在数据里标注。

```javascript
const cloudLabTask = {
  design: {
    network: '固定 fair 档（平台注入）',
    state: '区分 cold-start / warm-start 两次跑分',
    build: 'commit-sha 绑定产物指纹',
    timeLimit: '单机型单用例 < 5 分钟',
  },
  async submit(task) {
    const jobId = await cloudLab.create({ devices: task.deviceMatrix,   // Top 机型矩阵
      apk: task.fingerprint, cases: task.cases });
    return jobId;
  },
  async consume(jobId) {                                       // 数据回流
    const results = await cloudLab.results(jobId);
    return results.map(r => ({ device: r.model, page: r.page,
      metrics: r.metrics, env: r.envFlags }));                 // env: 温度/虚拟机标记
  },
};
```
