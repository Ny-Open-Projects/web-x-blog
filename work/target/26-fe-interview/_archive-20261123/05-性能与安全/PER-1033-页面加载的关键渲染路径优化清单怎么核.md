## PER-1033：页面加载的关键渲染路径优化清单怎么核对

**答**：
- 关键路径：HTML → 阻塞 CSS → 阻塞 JS → DOM/CSSOM → 渲染；优化即"缩短这条链"。
- 清单：CSS 内联关键样式 + 其余异步加载；JS defer/async；字体 preload + swap；LCP 资源 fetchpriority=high；图片响应式 + 预留位。
- 核对方法：Lighthouse 的 "Eliminate render-blocking resources" + Coverage 面板看未用代码比例。
- 深水：关键 CSS 提取要自动化（构建期扫描首屏用到的规则），手维护必腐化。

```javascript
/* 构建期关键 CSS 提取（critters 思路示意） */
// build: 扫描首屏 HTML 用到的 class -> 提取规则内联
<style>/* inlined critical css */</style>
<link rel="preload" href="/full.css" as="style" onload="this.rel='stylesheet'">
<noscript><link rel="stylesheet" href="/full.css"></noscript>
<script>
// 验证未用 CSS 比例
const rules = [...document.styleSheets].flatMap(s => { try { return [...s.cssRules]; } catch { return []; } });
const used = rules.filter(r => r.selectorText && document.querySelector(r.selectorText));
console.log('unused:', +( (1 - used.length / rules.length) * 100 ).toFixed(1) + '%');
</script>
```
