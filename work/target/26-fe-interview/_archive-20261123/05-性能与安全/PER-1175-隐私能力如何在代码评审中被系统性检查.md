## PER-1175：隐私能力如何在代码评审中被系统性检查

**答**：
- 评审清单（隐私段）：新增字段已注册？新 SDK 已过隐私评审？日志/上报脱敏？默认值是否最小？删除路径完备？
- 自动化辅助：diff 中出现 sendBeacon/fetch 到新域、新增 localStorage 写入时机器人评论提醒登记。
- 评审者赋能：清单模板 + 平台自动预检结果附在 MR 里，评审者只需确认例外。
- 度量：隐私相关评审评论数、缺陷逃逸率（上线后审计发现的问题中评审期可发现的占比）。

```javascript
// MR 隐私预检机器人
function privacyBot(diff) {
  const alerts = [];
  if (/sendBeacon|navigator\.sendBeacon/.test(diff) && !/registry/.test(diff))
    alerts.push('检测到新上报调用：确认字段已注册（1004）');
  if (/localStorage\.setItem/.test(diff))
    alerts.push('本地写入：确认不含个人信息（S3+ 禁止）');
  if (/new Image\(\)[\s\S]*src=.*track/.test(diff))
    alerts.push('疑似追踪像素：走第三方评审（1162）');
  return { alerts, verdict: alerts.length ? 'needs-review' : 'ok' };
}
```
