## PER-756：大促活动页的移动端性能专项：活动页秒开优化的清单化打法与压测验收

**答**：
- 活动页特点：流量脉冲（瞬时 10x）、资源重（动画/视频/皮肤）、链路短（一屏转化）、缓存冷（新页面无历史缓存）——秒开打法要针对这四点。
- 清单：**静态化预热**（CDN 预热 + 边缘缓存提前推）、**离线包提前下发**（活动前 1 小时灰度推送包）、**接口降级预案**（热点接口静态兜底数据）、**图片预算**（首屏 < 500KB，动画用 CSS/Lottie 而非视频）、**秒开链路演练**（预取协议/容器预热真机演练）。
- 压测验收：全链路压测（634）+ 前端专项（首屏接口限流响应验证降级 UI、CDN 命中率抽检、低端真机秒开达标）。
- 兜底：秒开不达标时的可感知降级"（骨架屏 + 分步加载）好过白屏；活动结束资源下线 SOP（回收 CDN/离线包/DNS，见 629）。

```javascript

const campaignChecklist = {
  preheat: { cdn: '资源提前预热到边缘', offline: '活动前 1h 灰度推离线包', dns: 'DNS/TLS 预建' },
  budget: { firstScreenKB: 500, anim: 'CSS/Lottie 不用视频', api: '热点接口静态兜底数据' },
  drill: ['预取协议真机演练', '容器预热演练', '首屏接口限流降级 UI 验证', '低端真机秒开抽检'],
  teardown: '活动结束 SOP：下线 CDN/离线包/DNS（防子域接管 629）',
  principle: '秒开不达标要有可感知降级（骨架屏+分步加载），绝不白屏',
};
console.log(campaignChecklist.principle);
```
