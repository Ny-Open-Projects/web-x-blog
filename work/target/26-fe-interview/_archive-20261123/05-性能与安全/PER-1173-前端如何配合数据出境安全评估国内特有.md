## PER-1173：前端如何配合"数据出境安全评估"（国内特有）

**答**：
- 要求：向境外提供个人信息需通过出境安全评估/标准合同/认证；触发条件看数量与敏感度。
- 工程识别：上报域名境外（.com 全球 CDN）、第三方 SDK 数据出境（境外厂商）——盘点出境链路是第一步。
- 方案：境内数据境内存储（1002 区域路由）、出境数据走申报（法务主导）、技术措施（加密/假名化降低风险）。
- 前端动作：出境域清单维护、SDK 区域分流配置、出境数据脱敏。

```javascript
// 出境链路盘点
const OUTBOUND = [
  { domain: 'cdn.global-vendor.com', region: 'US', data: 'error-logs' },
  { domain: 'cn.col.example.com', region: 'CN', data: 'rum' },
];
function crossBorderCheck() {
  return OUTBOUND.filter(o => o.region !== 'CN')
    .map(o => ({ ...o, need: '安全评估/标准合同',
      mitigation: o.data === 'error-logs' ? '脱敏后出境（无个人信息）' : '待评估' }));
}
// 脱敏后不含个人信息可降低出境评估门槛，但需法务确认
```
