## PER-937：性能告警风暴（雪崩式误报）怎么防

**答**：
- 风暴来源：发版同时劣化几十个页面、采集 SDK bug、上游数据延迟，都会让告警瞬间爆炸。
- 聚合降噪：同版本/同根因的告警聚合成一个事件（按版本 + 指标 + 时间窗聚类），只发一条带受影响页面列表的通知。
- 熔断机制：单位时间告警数超上限（如 20 条/10min）自动进入"风暴模式"——静默低优先级，只保留 P0 并通知值班。
- 恢复复盘：风暴结束后自动生成事件报告，统计根因分布，回头修采集或阈值。

```javascript
// 告警聚类聚合
function clusterAlerts(alerts, { windowMs = 10 * 60_000 } = {}) {
  const out = [];
  for (const a of alerts.sort((x, y) => x.ts - y.ts)) {
    const c = out.find(c => c.version === a.version && c.metric === a.metric &&
      a.ts - c.ts <= windowMs);
    if (c) { c.pages.push(a.page); c.ts = Math.max(c.ts, a.ts); }
    else out.push({ version: a.version, metric: a.metric, ts: a.ts, pages: [a.page] });
  }
  return out.map(c => ({ ...c, count: c.pages.length }));
}
// 20 个页面同版本劣化 -> 1 条事件而非 20 条
```
