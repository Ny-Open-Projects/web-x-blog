## PER-1159：隐私培训与文化建设（工程团队版）

**答**：
- 内容分层：全员（隐私意识/钓鱼）→ 工程（最小化/脱敏/注册表使用）→ 平台（法规要点/事件响应）。
- 形式：隐私评审实战演练（拿真实新功能过一遍数据流）、案例复盘分享（行业罚单案例）。
- 度量：培训覆盖率和考核通过率、评审 gaps 发现数（越多说明越会发现问题）、整改闭环率。
- 文化信号：表扬主动发现隐私问题的工程师，不惩罚报障。

```javascript
// 工程师隐私能力自测
const CHECK = [
  { q: '新埋点字段的第一步', a: '注册字段并声明级别与保留期' },
  { q: '日志里出现手机号', a: '走脱敏管道，原始值不出业务域' },
  { q: '用户撤回广告同意', a: '停止 SDK 并通知第三方删除' },
];
function privacyQuiz(answers) {
  return CHECK.map((c, i) => ({ q: c.q, pass: answers[i] === c.a }));
}
// 季度全员测试，未过补训
```
