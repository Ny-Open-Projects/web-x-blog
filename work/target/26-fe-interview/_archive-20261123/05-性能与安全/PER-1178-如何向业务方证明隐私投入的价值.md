## PER-1178：如何向业务方证明"隐私投入"的价值

**答**：
- 转化语言：合规罚款风险折算（案例金额）、客户采购的安全合规门槛（B 端投标要求 SOC2/个保认证）、用户信任指标（设置页使用率/投诉率）。
- 成本对比：一次隐私整改 5 人日 vs 一次通报事件的公关与法务成本。
- 先发优势：隐私能力成为产品卖点（B 端客户尽调直接给证据包 1167）。
- 机制化：隐私做成默认（脚手架+管线），业务无感合规。

```javascript
// 隐私 ROI 汇报
function privacyROI(invest, cases) {
  const fineRisk = cases.reduce((s, c) => s + c.fine, 0);   // 同类罚单均值
  return {
    investDays: invest,
    avoidedRisk: Math.round(fineRisk),                       // 风险敞口下降
    b2bValue: '尽调证据包可复用，缩短客户安全审查 2 周',
    trust: { settingsUsage: '12%', complaints: '-30% YoY' },
  };
}
```
