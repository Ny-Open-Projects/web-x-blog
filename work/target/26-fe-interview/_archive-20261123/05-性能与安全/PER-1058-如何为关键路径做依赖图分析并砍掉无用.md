## PER-1058：如何为关键路径做"依赖图"分析并砍掉无用请求

**答**：
- 方法：从 LCP 元素反推依赖链（它的 CSS/字体/图片/接口），再从首屏组件反推接口依赖；画出有向图。
- 砍掉无用：依赖图之外的请求（旧埋点、废弃接口、unused polyfill）直接移除；Coverage/Network 面板交叉验证。
- 时序优化：依赖链上的串行请求改并行（预加载 hint）、能合并的走 BFF。
- 持续防劣化：构建产物报告生成依赖图快照，diff 每次发版的新增节点。

```javascript
// 首屏依赖图快照
function snapshotDeps() {
  const nav = performance.getEntriesByType('navigation')[0];
  const res = performance.getEntriesByType('resource');
  return {
    critical: res.filter(r => r.startTime < 2000).map(r =>
      ({ url: new URL(r.name).pathname, start: Math.round(r.startTime),
         dur: Math.round(r.duration), proto: r.nextHopProtocol })),
    requests: res.length,
    beforeLCP: res.filter(r => r.responseEnd < nav.lcp?).length,
  };
}
// 每次发版 diff：新增 start<2000 的请求必须写明用途，否则评审打回
```
