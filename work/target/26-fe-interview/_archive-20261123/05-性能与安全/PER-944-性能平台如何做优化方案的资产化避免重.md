## PER-944：性能平台如何做「优化方案的资产化」避免重复造轮子

**答**：
- 方案库：每类优化（图片/预加载/虚拟滚动/懒加载）沉淀标准实现（封装组件/构建插件/配置模板）+ 适用条件 + 已验证收益。
- 一键接入：把方案做成脚手架插件或平台提供的 npm 包，接入成本从"研究两天"降到"装包十分钟"。
- 案例挂接：每个方案关联真实案例数据（前后指标），增强可信度。
- 版本管理：方案标注适用环境（框架版本/浏览器基线），过期方案下架并提示迁移。

```javascript
// 方案库注册表
const PLAYBOOK = {
  'img-webp': { pkg: '@fe/preset-image', gain: '-55% 图片体积',
    apply: '构建配置一键接入', case: 'PER-903 案例' },
  'route-split': { pkg: '@fe/preset-route-split', gain: '首屏 JS -35%',
    apply: '路由组件 lazy() 包裹 + 门禁校验', case: 'PER-904 案例' },
};
function recommend(problem) {
  return Object.entries(PLAYBOOK)
    .filter(([k]) => k.includes(problem))
    .map(([k, v]) => ({ id: k, ...v }));
}
```
