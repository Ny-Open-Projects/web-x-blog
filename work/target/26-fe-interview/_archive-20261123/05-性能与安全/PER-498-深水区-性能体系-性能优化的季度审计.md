## PER-498：性能治理的季度审计四维度？

**答**:
- 四维审计：① 数据质量审计——采样偏差验证（PER-454 对照）、口径漂移检查（注册中心 vs 实际采集 diff）、血缘覆盖率（PER-469）；② 防线有效性审计——逐条防线抽查（lint 规则还在生效吗/卡口被豁免多少次/告警误报率趋势）、防线清单完备性（PER-496）；③ 成本审计——平台成本 vs 价值（PER-418/495）、单条数据成本趋势；④ 组织健康审计（PER-494 三反模式信号 + 技能矩阵覆盖 PER-460）。
- 审计报告结构：每维度——现状量化 / 与上季对比 / 发现的问题（按严重度）/ 行动项（进下季路线图 PER-371）。审计独立于执行团队（或至少交叉互审）保证客观。
- 与复盘的区别：复盘是单事件（PER-496），审计是系统性体检（覆盖所有防线与数据的横向检查）——复盘找"这次为什么没拦住"，审计找"哪些防线可能已经在失效"。

```text
性能治理季度审计四维：
① 数据质量：采样偏差对照（PER-454）/ 口径漂移 diff / 血缘覆盖率（PER-469）
② 防线有效性：逐条防线抽查（lint 生效?/卡口豁免率/告警误报趋势）+ 清单完备性（PER-496）
③ 成本：成本 vs 价值（PER-418/495）+ 单条数据成本趋势
④ 组织健康：三反模式信号（PER-494）+ 技能矩阵覆盖（PER-460）
报告：量化现状 / 季度对比 / 问题分级 / 行动项进路线图
区别：复盘=单事件纵向；审计=全防线横向体检
```
