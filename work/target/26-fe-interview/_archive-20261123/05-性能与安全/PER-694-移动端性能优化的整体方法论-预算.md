## PER-694：移动端性能优化的整体方法论：预算制、分档制与回归门禁如何组成闭环？

**答**：
- 闭环三件套：**预算制**（秒开 < 1s/首屏 JS < 150KB/长任务 < 100ms，按低端机定档）、**分档制**（设备三档 × 网络四档，策略与阈值全部分档）、**门禁制**（发版跑分 vs 预算，回归超阈值挡合并）。
- 闭环运转：门禁拦住的回归 -> 归因到具体提交 -> 修复进回归用例 -> 预算随治理收紧（每季度 5%）——让性能只紧不松。
- 组织配套：性能 owner 制（每条业务线有人背指标）、性能周报（分档秒开率趋势）、性能值班（告警响应）。
- 度量健康度：门禁拦截次数、秒开率分档趋势、预算收紧记录——三个数字说明体系是否真的在转。

```javascript

const mobilePerfLoop = {
  budget: { secondOpen: '1s(低端1.5s)', firstScreenJs: '150KB gzip', longTask: '100ms',
    base: '按低端机定档' },
  tiering: { device: 'low/mid/flag', net: 'offline/slow3g/fast3g/4g',
    rule: '策略与阈值全部分档' },
  gate: { ci: '发版跑分 vs 预算', block: '回归 > 8% 挡合并', tighten: '每季度预算收紧 5%' },
  org: { owner: '业务线指标到人', weekly: '分档秒开率周报', oncall: '性能告警值班' },
  health: ['门禁拦截次数', '分档秒开率趋势', '预算收紧记录'],
  essence: '预算制定目标、分档制保公平、门禁制防回归，三者闭环让性能只紧不松',
};
console.log(mobilePerfLoop.essence);
```
