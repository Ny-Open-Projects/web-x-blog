## PER-1217：如何建立"页面性能证书"制度

**答**：
- 定义：页面通过全部性能验收（指标门禁+契约测试+体检规则）后签发证书，随版本有效。
- 过期机制：依赖大版本升级/新增资源类型时证书失效，需复验。
- 展示：页面头部注入证书徽章（内部工具可见），招标/汇报可引用。
- 签发自动化：CI 全绿自动签发（记录 commit/指标快照），人工只复核例外。

```javascript
// 性能证书签发
function issueCert(page, { gates, contract, audit }) {
  const pass = gates.pass && contract.pass && audit.pass;
  const cert = { page, version: BUILD_ID, issuedAt: new Date().toISOString(),
    metrics: gates.snapshot, expiresOnNextMajor: true };
  if (pass) storeCert(cert);
  return { pass, cert: pass ? cert : null,
    blockers: [...gates.fails ?? [], ...contract.failures ?? []] };
}
```
