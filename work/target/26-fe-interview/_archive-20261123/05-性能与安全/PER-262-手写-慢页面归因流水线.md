## PER-262：手写单页性能归因报告生成（LCP 归因 + INP 归因 + 长任务清单，输出结构化结论）

**题目**：实现 `attributePage()`，在页面 hidden 时输出结构化归因报告：① LCP：元素 tag、若为图片读 Resource Timing 判断资源加载/渲染延迟；② INP：最慢交互的三段拆解（input/processing/presentation）+ 超过 200ms 才记录；③ 长任务：duration > 100ms 的任务计数与总时长；④ 输出 `report = { lcp, inp, longTasks, suggestions[] }`，suggestions 按归因结果给出 2~3 条建议文本。

**答**：这是把前几题的采集器串成"归因流水线"：采集 → 拆解 → 规则化建议。重点是建议的生成逻辑要可解释（每条建议能对应到证据字段）。

```javascript
function attributePage() {
  let lcp = null, worst = null;
  const longTasks = { count: 0, total: 0 };

  new PerformanceObserver((l) => { lastLCP = l.getEntries().at(-1); })
    .observe({ type: 'largest-contentful-paint', buffered: true });
  let lastLCP = null;

  new PerformanceObserver((l) => {                 // 最慢交互 + 三段拆解
    for (const e of l.getEntries()) {
      if (e.interactionId == null || e.duration < 200) continue;
      if (!worst || e.duration > worst.duration) {
        worst = { name: e.name, tag: e.target?.tagName, dur: Math.round(e.duration),
          input: Math.round(e.processingStart - e.startTime),
          proc: Math.round(e.processingEnd - e.processingStart),
          pres: Math.round(e.duration - (e.processingEnd - e.startTime)) };
      }
    }
  }).observe({ type: 'event', durationThreshold: 200, buffered: true });

  new PerformanceObserver((l) => {                 // 长任务
    for (const e of l.getEntries()) if (e.duration > 100) { longTasks.count++; longTasks.total += e.duration; }
  }).observe({ type: 'longtask', buffered: true });

  const report = () => {
    const suggestions = [];
    if (lastLCP) {
      const res = lastLCP.url ? performance.getEntriesByName(lastLCP.url)[0] : null;
      lcp = { tag: lastLCP.element?.tagName, url: lastLCP.url || null,
              isImg: !!lastLCP.url,
              resourceDelay: res ? Math.round(res.responseEnd) : null };
      if (lastLCP.url && res?.responseEnd > 2000) suggestions.push('LCP 图片加载慢：压缩/转 AVIF 并加 fetchpriority=high');
      if (!lastLCP.url) suggestions.push('LCP 是文本/容器：检查 TTFB、SSR 直出与字体阻塞');
    }
    if (worst) {
      if (worst.input > 50) suggestions.push(`input delay ${worst.input}ms：切长任务，用 scheduler.yield`);
      if (worst.proc > 100) suggestions.push(`handler ${worst.proc}ms：拆分 ${worst.tag} 的同步逻辑`);
      if (worst.pres > 100) suggestions.push(`渲染 ${worst.pres}ms：检查强制同步布局与大范围重绘`);
    }
    if (longTasks.count > 3) suggestions.push(`长任务 ${longTasks.count} 个共 ${Math.round(longTasks.total)}ms：整体切片`);
    return { lcp, inp: worst, longTasks, suggestions };
  };
  document.addEventListener('visibilitychange', () => {
    if (document.visibilityState === 'hidden') report();
  });
  return report;
}
```

**评分点**：
- LCP 归因区分图片/文本/注入三类路径，图片场景对齐 Resource Timing 判断加载或渲染延迟。
- INP 三段拆解正确且只收 >200ms 慢交互（阈值防噪音）。
- 长任务统计（count + total）独立采集。
- suggestions 每条都有证据支撑（对应采集字段），不是模板套话；hidden 时机触发。
