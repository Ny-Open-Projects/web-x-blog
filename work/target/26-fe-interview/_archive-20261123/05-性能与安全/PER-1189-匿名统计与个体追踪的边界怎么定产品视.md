## PER-1189：匿名统计与个体追踪的边界怎么定（产品视角）

**答**：
- 边界原则：产品健康度（DAU/崩溃率）用匿名聚合即可；个体追踪（跨会话归因）必须有明确同意与目的。
- 技术边界：会话级假名（每会话新 ID）用于分析；持久 ID 仅登录+必要功能（订单/客服）。
- 审查问题：这个数据"换了用户也成立吗"？成立就用聚合；需要区分个体才用假名/实名。
- 定期复检：每个持久 ID 用途年审，无必要即降级为会话假名。

```javascript
// ID 分级使用守卫
const ID_LEVELS = { session: '分析可自由用', pseudonym: '登录功能可用',
  real: '法定义务场景' };
function idGuard(purpose) {
  if (['analytics', 'ab-test'].includes(purpose)) return 'session';
  if (['order', 'support', 'consent'].includes(purpose)) return 'pseudonym';
  return 'real';                                   // 需合规审查
}
// 年审：持久 ID 的 purpose 清单比对，无主 ID 降级
```
