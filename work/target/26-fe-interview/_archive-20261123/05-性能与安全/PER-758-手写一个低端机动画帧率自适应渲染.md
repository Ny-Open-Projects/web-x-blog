## PER-758：手写一个低端机动画帧率自适应渲染循环：帧预算驱动的内容分级渲染

**答**：
- 思路：渲染循环每帧测实际耗时，滚动窗口统计帧率——持续低于目标（55fps）时降低渲染内容等级（粒子减半->关特效->降帧 30fps），恢复后升回（滞回）。
- 要点：帧耗时用 rAF 时间差（含 JS+渲染总预算）；等级切换作用于渲染器配置（粒子数/特效开关/分辨率 scale）；降帧模式用计数器跳帧（每 2 帧渲染 1 次）而不是改 rAF 频率（rAF 固定跟随 vsync）。
- 边界：页面不可见暂停循环；等级变化通知业务（埋点）；低端机起始等级就低。
- 评分点：跳帧实现与滞回升降。

```javascript

class AdaptiveRenderLoop {
  constructor(renderer, { target = 55 } = {}) {
    this.renderer = renderer;
    this.level = window.__deviceTier === 'low' ? 1 : 2;         // 0 最简 / 1 标准 / 2 完整
    this.frameTimes = [];
    this.skip = false; this.tick = 0;
    this.running = true;
    document.addEventListener('visibilitychange', () =>
      this.running = document.visibilityState === 'visible');
    this.loop();
  }
  loop() {
    requestAnimationFrame(() => {
      if (!this.running) return this.loop();
      const now = performance.now();
      // 降帧模式：每 2 帧渲染 1 次（rAF 固定跟随 vsync，跳帧降负载）
      this.tick++;
      if (this.level === 0 && this.tick % 2 === 0) return this.loop();
      this.render();
      this.frameTimes.push(now);
      if (this.frameTimes.length > 30) this.evaluate();          // 30 帧窗口评估
      this.loop();
    });
  }
  evaluate() {
    const gaps = this.frameTimes.slice(1).map((t, i) => t - this.frameTimes[i]);
    const avg = gaps.reduce((s, g) => s + g, 0) / gaps.length;
    const fps = 1000 / avg;
    if (fps < this.target - 10 && this.level > 0) {             // 持续低于目标
      this.level--;
      this.applyLevel();
      track('render-downgrade', { level: this.level, fps: +fps.toFixed(0) });
    } else if (fps > this.target && this.level < 2 && this.stableLong()) {
      this.level++; this.applyLevel();                          // 滞回升档
    }
    this.frameTimes = [];
  }
  applyLevel() {
    const cfg = [ { particles: 10, fx: false }, { particles: 30, fx: false }, { particles: 80, fx: true } ][this.level];
    this.renderer.configure(cfg);
  }
  render() { this.renderer.draw(); }
  stableLong() { return this.frameTimes.length >= 90; }         // 升档需更稳
}
```
