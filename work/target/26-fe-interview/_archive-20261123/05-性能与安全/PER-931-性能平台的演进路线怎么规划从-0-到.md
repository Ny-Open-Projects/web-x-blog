## PER-931：性能平台的演进路线怎么规划？从 0 到 1 分几步

**答**：
- 第一阶段（MVP，1~2 月）：SDK 采集核心指标 + 简单看板 + 阈值告警，先让数据可见。
- 第二阶段（3~6 月）：发版基线对比与劣化归因、CI 门禁接入，让数据可行动。
- 第三阶段（6~12 月）：平台化能力——预算登记、体检规则引擎、实验支持、多端统一，让治理可持续。
- 原则：每个阶段有明确北极星（如 MTTD < 10min / 门禁拦截准确率 > 80%），拒绝一上来铺大平台。

```javascript
// 平台成熟度自评
const LEVELS = ['可见', '可行动', '可持续', '可预测'];
function maturity(features) {
  const has = k => features.includes(k);
  if (!has('collect')) return 0;
  if (!has('baseline-diff')) return 1;
  if (!has('budget') || !has('ci-gate')) return 2;
  return has('experiment') && has('forecast') ? 4 : 3;
}
// 每季度自评一次，作为平台 roadmap 的输入
```
