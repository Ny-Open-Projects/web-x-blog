## PER-1192：如何应对"用户质疑数据被滥用"的投诉

**答**：
- 响应流程：受理（24h 内确认）→ 调证（该用户数据流向与采集依据）→ 回复（说清依据与控制方式）→ 若属实即走事件流程（1172）。
- 话术原则：具体可验证（"您在 x 月 x 日同意了 y 政策版本"），不说敷衍话。
- 升级：投诉聚合同类问题 > 3 例即触发专项排查（可能是系统性问题）。
- 记录：全部投诉进合规台账，作为审计材料。

```javascript
// 数据投诉调证
async function investigateComplaint(uid, claim) {
  const flow = traceAll(hash(uid));                // 数据地图查询
  const consent = consentLog(uid);
  const evidence = { claim, flow, consent,
    sample: lastSamples(hash(uid), 5) };
  const valid = consent.some(c => c.choice && c.policyVersion === policyVersion());
  return { evidence, verdict: valid ? '采集有依据，提供控制入口' : '无有效同意，走事件流程' };
}
// verdict 无依据 -> 升级 P0 并启动 1146 评估
```
