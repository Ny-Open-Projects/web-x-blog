## PER-1152：位置信息的隐私处理分级

**答**：
- 分级：精确位置（GPS，S4 敏感）→ 粗化位置（城市/区级）→ IP 推断位置（区域级）。
- 原则：功能需要才请求权限（用位置才弹）、前台使用、可一次性与可撤销；后台定位需单独说明。
- 工程：上报前粗化（保留两位小数≈1km 或直接城市编码）、缓存位置结果避免重复采集、位置数据短保留。
- 合规：国内需"单独同意"，境外 GDPR 属敏感类。

```javascript
// 位置粗化上报
function reportLocation(coords, purpose) {
  const NEED_PRECISE = ['nearby-driver'];            // 只有这类功能要精确
  const precise = NEED_PRECISE.includes(purpose) && consent.get().location;
  const geo = precise
    ? { lat: +coords.latitude.toFixed(4), lng: +coords.longitude.toFixed(4) }  // ≈10m
    : { city: geoip.city(coords) };                  // 城市级
  return { purpose, geo, retention: precise ? '24h' : '30d' };
}
// 权限申请前先展示用途说明（解释为什么需要）
```
