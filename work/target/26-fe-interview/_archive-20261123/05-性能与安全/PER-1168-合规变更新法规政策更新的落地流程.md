## PER-1168：合规变更（新法规/政策更新）的落地流程

**答**：
- 流程：法规解读（法务）→ 影响评估（数据流比对）→ 方案设计（工程）→ 实施 → 验证 → 全员通知。
- 时限管理：法规生效日期倒排里程碑，高风险项优先。
- 版本管理：政策/注册表/SDK 同步升版，用户重新同意流程触发。
- 遗留处理：存量数据按新规回溯整改（如超期数据清理）。

```javascript
// 合规变更任务拆解
function complianceChange(regulation, effectiveAt) {
  const tasks = [
    { id: 'gap-analysis', owner: 'legal', due: -60 },    // 生效前 60 天
    { id: 'tech-design', owner: 'platform', due: -45 },
    { id: 'implement', owner: 'platform', due: -14 },
    { id: 're-consent', owner: 'fe', due: -7 },
    { id: 'backfill-purge', owner: 'data-eng', due: 0 },  // 存量整改
  ];
  return tasks.map(t => ({ ...t, deadline:
    new Date(effectiveAt + t.due * 86400_000).toISOString().slice(0, 10) }));
}
```
