## PER-688：移动端性能专项的低端机优先策略：低端机的性能特征与针对性优化清单

**答**：
- 低端机特征：CPU 单核弱（JS 执行慢 3~5 倍）、内存小（2GB，频繁低内存杀后台）、GPU 弱（光栅化慢）、存储慢（IO 高延迟）、网络差（占比更高）。
- 针对清单：**JS 执行预算减半**（首屏 JS < 150KB gzip，长任务 < 100ms）、禁用重动画（检测 deviceMemory 后降级动画）、图片降清与延迟解码、虚拟列表阈值收紧（更小窗口）、启动串行改并行、首屏数据预取更激进（弱网占比高）、关闭实验性重特效。
- 检测分档：`navigator.deviceMemory/hardwareConcurrency` + UA 机型库映射，分档要在启动早期确定并贯穿全部策略（埋点带档位）。
- 决策原则：低端机不是尽力兼容，是第一公民"——预算按低端机定，中高端自然达标；反之按旗舰定预算低端永远不达标。

```javascript

const lowEndStrategy = {
  detect: { signals: ['navigator.deviceMemory', 'hardwareConcurrency', 'UA 机型库'],
    timing: '启动早期确定，埋点贯穿带档位' },
  budgets: { firstScreenJsKB: 150, longTaskMs: 100, imageTier: 'ld', listWindow: '更小' },
  downgrades: { animation: 'deviceMemory <= 2 时禁用重动画', effects: '关闭模糊/大阴影',
    prefetch: '更激进首屏预取（低端弱网占比更高）' },
  principle: '预算按低端机定义（低端优先），中高端自然达标；反序则低端永不达标',
};
console.log(lowEndStrategy.principle);
```
