## PER-1174：如何设计"隐私优先"的错误上报

**答**：
- 错误上报天然携带风险：URL（含参数）、堆栈（含业务逻辑）、用户操作序列。
- 规则：URL 脱敏（953）、堆栈经 sourcemap 还原但不上传源码片段、用户操作只记类型不记内容。
- 采样与保留：错误明细保留 30 天、聚合指标长期；含个人信息的事件单独通道+短保留。
- 验证：错误事件抽样人工审查敏感内容命中数，纳入月度隐私审计。

```javascript
// 错误上报隐私化
function safeErrorReport(err) {
  return {
    type: err.name, msg: redact(err.message).slice(0, 200),   // 1087 脱敏
    stack: err.stack?.split('\n').slice(0, 5).map(s =>
      redact(s.replace(location.origin, ''))),                // 去域名+脱敏
    url: sanitizeUrl(location.href),                          // 953
    retention: 30,
  };
}
// 禁止：把表单内容/Redux state 整包 attach 到错误报告
```
