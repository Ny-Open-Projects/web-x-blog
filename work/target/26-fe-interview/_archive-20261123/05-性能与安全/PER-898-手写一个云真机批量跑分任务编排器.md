## PER-898：手写一个云真机批量跑分任务编排器：任务队列、失败重试与结果汇聚

**答**：
- 需求：实现 CloudLabOrchestrator：submit(deviceList, cases) 生成任务队列（每机型×用例一个 job），并发跑（平台并发上限 N）；单 job 失败重试 1 次（换一台同型号设备），再失败记录 failed；全部完成后汇聚输出 {perDevice: [{device, page, metrics}], failed: [...], coverage: 成功机型/总机型}。
- 边界：同型号设备池不足时重试用任意同型号空闲设备；超时（单 job 5 分钟）算失败；汇聚时同机型多 job 取成功的那次。
- 评分点：并发上限控制；换设备重试；超时判定与汇聚去重。

```javascript
class CloudLabOrchestrator {
  constructor(concurrency = 10) { this.conc = concurrency; }
  async submit(deviceList, cases) {
    const jobs = [];
    for (const d of deviceList) for (const c of cases)
      jobs.push({ model: d.model, device: d, case: c, tries: 0 });
    const running = new Set(), done = [], failed = [];
    return new Promise(resolve => {
      const drain = () => {
        while (running.size < this.conc && jobs.length) {
          const job = jobs.shift();
          const p = this.run(job, 5 * 60000).then(r => {
            running.delete(p);
            r.ok ? done.push(r) : failed.push({ ...job, reason: r.reason });
          }).finally(drain);
          running.add(p);
        }
        if (!running.size && !jobs.length)
          resolve(this.merge(done, failed, deviceList.length));
      };
      drain();
    });
  }
  async run(job, timeoutMs) {
    try {
      const device = job.tries > 0                             // 重试换同型号空闲设备
        ? await cloudLab.pickIdle(job.model) : job.device;
      if (!device) return { ok: false, reason: 'no-idle-device' };
      const r = await Promise.race([
        cloudLab.exec(device, job.case), rejectAfter(timeoutMs)]);
      return { ok: true, device: device.model, ...r };
    } catch (e) {
      if (job.tries++ < 1) return this.run(job, timeoutMs);    // 重试一次
      return { ok: false, reason: String(e).slice(0, 100) };
    }
  }
  merge(done, failed, total) {
    const perDevice = new Map();
    for (const d of done) perDevice.set(d.device + d.page, d);  // 同机型取成功
    return { perDevice: [...perDevice.values()],
      failed, coverage: +(new Set(done.map(d => d.device)).size / total).toFixed(2) };
  }
}
```
