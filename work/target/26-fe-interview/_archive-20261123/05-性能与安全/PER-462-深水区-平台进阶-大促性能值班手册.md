## PER-462：大促性能值班手册：T-7 到 T+1 时间线？

**答**:
- 时间线动作表：T-7 冻结非必要发版（性能基线锁定）；T-5 全链路压测 + 降级矩阵逐级演练（PER-377）；T-3 CDN 预热（活动页全量推边）+ 三方脚本白名单锁定（禁新接入）；T-1 值班排班确认 + runbook 刷新 + 降级开关全量验证；T-0 值班盯盘（性能大盘实时 + 降级触发条件监控），触发即执行预案；T+1 复盘（降级效果/误伤/漏预案）。
- 值班盯盘要点：核心页面 p75 LCP/INP 实时曲线 + 降级开关状态面板 + 服务端 QPS 联动——性能劣化与降级触发的双信号判定（PER-344 联合应急）。
- 角色分工：性能 oncall（盯数/触发降级）、发布 oncall（回滚执行）、业务 oncall（误伤确认）——三方通讯约定（专用群 + 电话升级链）。
- 遗产：大促预案沉淀为"常态化能力"（降级矩阵/开关体系平时也挂载，只是阈值更高）——不是一次性工程。

```text
大促性能值班时间线：
T-7  发版冻结（基线锁定）
T-5  压测 + 降级矩阵逐级演练（PER-377）
T-3  CDN 预热 + 三方白名单锁定
T-1  排班/runbook 刷新/降级开关全量验证
T-0  盯盘：核心页 p75 实时 + 降级开关状态 + QPS 双信号（PER-344 联合应急）
T+1  复盘：降级效果/误伤/漏预案 → 预案迭代
角色：性能 oncall（触发）/ 发布 oncall（回滚）/ 业务 oncall（误伤确认）
遗产：降级矩阵常态化挂载（平时阈值更高）—— 非一次性工程
```
