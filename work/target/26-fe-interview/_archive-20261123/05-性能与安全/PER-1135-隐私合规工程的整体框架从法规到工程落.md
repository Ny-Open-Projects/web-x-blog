## PER-1135：隐私合规工程的整体框架：从法规到工程落地怎么映射

**答**：
- 法规映射：GDPR/个保法/CCPA 共同要求——合法性基础（同意/合法利益）、目的限定、最小化、可问责（DPIA/记录）、主体权利（查询/更正/删除/可携）。
- 工程化四件套：采集清单化（字段注册）、同意管理（CMP）、数据生命周期（保留/删除）、审计留痕（可自证）。
- 角色分工：法务定红线与政策文本，工程实现技术控制，安全做泄露防护，产品做用户交互（同意弹窗/设置页）。
- 落地原则：默认隐私（Privacy by Default）——新功能默认最小采集，扩大采集需走评审。

```javascript
// 隐私控制矩阵
const CONTROLS = {
  'gdpr-art5-minimization': { impl: 'field-registry', owner: 'fe-platform' },
  'gdpr-art7-consent':       { impl: 'cmp-sdk',       owner: 'fe-platform' },
  'gdpr-art17-erasure':      { impl: 'erasure-pipeline', owner: 'data-eng' },
  'pipl-separate-consent':   { impl: 'consent-granular', owner: 'fe-platform' },
};
function complianceCheck(feature) {
  return Object.entries(CONTROLS).map(([rule, c]) =>
    ({ rule, impl: c.impl, covered: feature.controls?.includes(c.impl) }));
}
```
