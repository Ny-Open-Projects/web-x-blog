## PER-936：如何评估一次性能优化的真实因果收益

**答**：
- 反事实问题：没有对照就没有因果——上线优化前后指标变化里混着流量结构、季节、发版干扰。
- 方法一：灰度对照（最优）——按 uid 分桶对比实验组与对照组分位数。
- 方法二：断点回归（RDD）——以发版时刻为断点，比较断点前后斜率变化，适合无法灰度的修复。
- 方法三：双重差分（DID）——受影响页面 vs 未受影响页面，差掉共同趋势。没有对照时永远说"相关"不说"因果"。

```javascript
// DID 简易计算
function did(affected, control, key = 'lcp') {
  // 两组各含 [{ before, after }]（聚合 P75）
  const d1 = affected.after - affected.before;
  const d0 = control.after - control.before;
  return { effect: +(d1 - d0).toFixed(1),
    unit: 'ms',
    interpret: d1 - d0 > 0 ? '优化反而劣化' : `净收益 ${(d0 - d1).toFixed(0)}ms` };
}
// 对照组选同类型未改动页面，差掉大盘共同趋势
```
