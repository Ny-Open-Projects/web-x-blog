## PER-511：性能测试环境与生产环境有差异，如何校准才能让测试结论外推到线上？

**答**：
- 差异来源五类：硬件（测试机 vs 用户手机）、网络（机房 vs 蜂窝）、数据（造数 vs 真实分布）、服务（压测桩 vs 真实依赖）、并发（单用户 vs 高并发互相干扰）。
- 校准手段：设备降速倍率用主流用户机型跑分反推；数据集用生产脱敏快照；后端依赖用录放（traffic replay）或影子服务，而不是 stub 糊弄。
- 外推的原则：**同一档位内比较可信，跨档位换算谨慎**——"4x 节流约等于中端安卓"是经验近似不是物理定律，结论要写置信区间。
- 最终校准闭环：上线后用 RUM 数据反推"测试环境 1 分钟 ≈ 线上什么档位"，修正换算系数，让下一次测试更准。

```javascript

// 档位映射表：测试环境档位 <-> 真实用户档位，由 RUM 对账持续修正
const deviceMap = {
  '4x-throttle+fast3g': { approx: '中端安卓/4G', rumLcpP75: 2400 },
  '1x+4g':              { approx: '旗舰机/WiFi', rumLcpP75: 1300 },
};
function calibrate(testLcp, profile) {
  const k = deviceMap[profile].rumLcpP75 / testLcp; // 线上/实验室换算系数
  console.log(`实验室 ${testLcp}ms ≈ 线上 ${Math.round(testLcp * k)}ms (${profile})`);
  return k; // 每次发版后用最新 RUM 数据重算 k，防止映射过期
}
calibrate(2100, '4x-throttle+fast3g');
```
