## PER-1060：移动端 H5 的网络专项：离线包与 CDN 之外的手段

**答**：
- 离线包：核心资源打包下发 + 本地拦截（SW 或容器拦截器），弱网首屏直接本地取，版本增量更新。
- 启动预热：容器启动即预建连接与预取首屏接口，与页面渲染并行。
- 域名收敛：DNS 预热成本随域名数线性涨，收敛到 2~3 个核心域。
- 实测口径：移动专项指标按"冷启动首屏 P75（弱网档位）"单独考核，桌面口径无意义。

```javascript
// SW 离线包拦截
const OFFLINE_PKG = '/pkg/app-v7/';
self.addEventListener('fetch', e => {
  const url = new URL(e.request.url);
  if (url.origin === location.origin && MANIFEST.has(url.pathname)) {
    e.respondWith(caches.open('pkg-v7')
      .then(c => c.match(url.pathname))
      .then(hit => hit ?? fetch(e.request)));      // 本地优先
  }
});
// MANIFEST 来自离线包下发清单，版本差量更新由后台任务完成
```
