## PER-946：如何设计性能平台的「报告自动化」能力

**答**：
- 三类报告：日报（昨日核心指标 + 异动）、周报（分 Owner 页面健康度 + 待办）、专项报告（一次优化的前后对比 + 收益折算）。
- 自动化装配：数据自动拉取 + 模板渲染 + 自动分发（IM/邮件），人只负责异常解读与结论。
- 报告差异化：高管版只看趋势与业务挂钩结论；工程师版附完整下钻链接与修复建议。
- 质量要求：每张图自带口径注释（P75/样本量/版本范围），防止报告被误读。

```javascript
// 周报装配
function weekly(owner, data) {
  const pages = data.filter(d => d.owner === owner);
  const bad = pages.filter(p => p.lcp > 2500);
  return {
    summary: `负责 ${pages.length} 个页面，${bad.length} 个超 SLO`,
    items: bad.map(p => ({ page: p.page, lcp: p.lcp,
      delta: p.lcp - (p.baseline ?? p.lcp),
      action: p.pendingFixes?.[0] ?? '待开单' })),
    link: boardLink(owner),          // 每条都可点进下钻
  };
}
```
