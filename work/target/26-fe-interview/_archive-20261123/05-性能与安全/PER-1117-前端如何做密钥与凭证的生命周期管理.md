## PER-1117：前端如何做"密钥与凭证的生命周期管理"

**答**：
- 分类：公开密钥（三方 SDK key，需域名白名单）、会话凭证（token）、长期密钥（永不进前端）。
- 轮换：会话 token 自动刷新（1098）；公开 key 季度轮换 + 旧 key 宽限期；泄露即轮换。
- 注入：构建期环境变量注入（区分 dev/prod），禁止 prod 值出现在开发分支；secrets 管理平台集中托管。
- 审计：密钥使用日志（哪个构建/哪个环境用了哪个 key）。

```javascript
// 构建期密钥注入（禁止硬编码）
// vite.config.ts:
export default defineConfig(({ mode }) => ({
  define: { __SDK_KEY__: JSON.stringify(env(mode).SDK_KEY) },
}));
// env 校验：prod 构建时缺 SDK_KEY 直接 fail
function env(mode) {
  const e = loadDotenv(mode);
  if (mode === 'production' && !e.SDK_KEY)
    throw new Error('缺少 SDK_KEY，拒绝构建');
  return e;
}
// 轮换检查：CI 比对 key 更新时间 > 90 天则告警
```
