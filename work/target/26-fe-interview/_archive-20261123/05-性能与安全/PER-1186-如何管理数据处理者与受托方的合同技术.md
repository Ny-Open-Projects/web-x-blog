## PER-1186：如何管理"数据处理者"与"受托方"的合同技术落地

**答**：
- 概念：委托处理（代运营客服系统）需要委托协议；受托方只能按约定处理，不得另用。
- 技术落地：受托方接入走独立凭证（scope 限定）、数据处理行为日志（受托方可访问的字段与频率）、终止即断供。
- 前端：受托方客服系统嵌入走最小数据接口（工单上下文按需给，不给全量用户数据）。
- 审计：年度受托方合规审查（材料+抓包）。

```javascript
// 受托方数据接口 scope
const AGENT_SCOPES = {
  'support-vendor': { fields: ['ticket', 'maskedContact'],   // 只有掩码联系方式
    endpoints: ['/tickets/*'], rateLimit: 100 },
};
function agentDataAPI(agent, endpoint, fields) {
  const s = AGENT_SCOPES[agent];
  if (!s) return 403;
  const pathOk = s.endpoints.some(p => matchPath(p, endpoint));
  const fieldOk = fields.every(f => s.fields.includes(f));
  if (!pathOk || !fieldOk) return 403;             // 越界即拒
  return { data: maskedPayload(fields), audit: `agent:${agent}` };
}
```
