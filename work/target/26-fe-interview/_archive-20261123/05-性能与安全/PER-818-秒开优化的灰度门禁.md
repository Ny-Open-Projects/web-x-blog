## PER-818：秒开优化的灰度门禁：新版秒开率回归时如何阻断发布与定位劣化

**答**：
- 门禁设计：灰度期间对比实验组 vs 基线组的秒开率（同口径、同分档），劣化超过阈值（如 -2pp 或相对 -5%）自动触发阻断（灰度停止扩量/回滚）。
- 防误伤：分档对比（低端机与高端机分开判）+ 最小样本量（每组每档 >= 1000）+ 同时间窗对比（避开流量高峰错位）。
- 定位路径：秒开劣化 → 分段归因找出超预算段 → 段内子指标下钻（bundle 体积/接口耗时/图片档位）→ 关联发版 diff（资源清单对比）定位引入点。
- 机制落地：门禁数据由性能平台自动产出，发布系统订阅门禁结果，人工只处理阻断后的归因，不手工看板放行。

```javascript
const releaseGate = {
  async check(releaseId) {
    const exp = await metrics.compare(releaseId, { metric: 'second-open-rate',
      byTier: true, window: '1h', minSample: 1000 });
    const violated = exp.tiers.filter(t => t.sample >= t.minSample
      && t.expRate < t.baseRate - Math.max(0.02, t.baseRate * 0.05));  // 绝对/相对阈值
    if (violated.length) {
      await release.block(releaseId, { reason: '秒开劣化', tiers: violated.map(t => t.tier) });
      const seg = await attributeSegs(await metrics.segs(releaseId, violated[0].tier));
      return { pass: false, seg, hint: seg.action };
    }
    return { pass: true };
  },
};
```
