## PER-1120：如何写一份可执行的"安全需求评审"输入

**答**：
- 输入内容：功能涉及的资产与数据级别、鉴权模型（谁能做什么）、输入输出信任边界、第三方依赖、审计需求。
- 输出：安全需求条目（鉴权/脱敏/审计/风控）进 PRD 验收标准，不达成不发版。
- 评审会：开发+安全+业务三方，30 分钟内过完标准功能；重大功能（支付/数据导出）专项评审。
- 模板化：标准功能（CRUD/导入导出/消息）配安全需求模板，直接套用提效。

```javascript
// 安全需求清单生成器
function securityReq(feature) {
  const reqs = [];
  if (feature.writes) reqs.push('鉴权：接口级权限点 + CSRF/签名');
  if (feature.pii) reqs.push(`脱敏：${feature.pii.join('/')} 展示掩码+查看留痕`);
  if (feature.export) reqs.push('导出：异步任务+归属校验+水印+审计');
  if (feature.thirdParty) reqs.push('三方：数据流审查+CSP 影响评估');
  if (feature.money) reqs.push('资损：服务端金额裁决+step-up 认证');
  return reqs;
}
// 输出直接贴进 PRD 验收标准章节
```
