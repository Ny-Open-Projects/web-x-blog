## PER-1158：如何验证"同意撤回后真的停止采集"

**答**：
- 验证三层：本地验证（SDK 状态检查）、网络验证（撤回后窗口抓包确认无相关上报）、服务端验证（该主体新事件为 0）。
- 自动化：撤回同意触发验证探针（24h 内抽样比对），未停采即高危告警（合规事故）。
- 历史数据：撤回不自动删除历史（除非用户要求删除），但新采集必须停。
- 第三方联动：撤回后向已共享方转发停止信号，回执留痕。

```javascript
// 撤回验证探针
async function verifyWithdrawal(uid, bucket) {
  const checks = await Promise.all([
    localSDKState(bucket),                                // SDK 停了
    networkSample(uid, bucket, 24 * 3600_000),            // 无相关上报
    serverEventCount(hash(uid), bucket),                  // 服务端新增为 0
  ]);
  const ok = checks.every(c => c.pass);
  if (!ok) alert({ severity: 'P0', type: 'consent-not-honored',
    bucket, failed: checks.filter(c => !c.pass) });
  return { ok, checks };
}
```
