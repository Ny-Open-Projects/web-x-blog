## PER-778：移动端性能平台的移动端看板：分档秒开、卡顿归因与真机矩阵数据的呈现设计

**答**：
- 看板三层：**总览层**（分档秒开率/卡顿率趋势 + 发版时间线对齐）、**归因层**（卡顿样本下钻：设备档×页面×时间段，慢样本带会话回放/trace）、**真机层**（真机矩阵跑分结果：机型×网络×页面矩阵热力图）。
- 设计原则：移动端指标天然分档（设备/网络/容器版本），所有曲线默认分档下钻而不是全局平均；告警链接直达慢样本（点告警看到具体会话）。
- 真机矩阵呈现：热力图（行=机型，列=页面，色=秒开率）快速定位某机型某页面的组合问题；矩阵数据定时跑（夜间批量）+ 发版触发。
- 度量：看板使用率（值班/业务查询频次）、从告警到定位的 MTTD。

```javascript

const mobilePerfDashboard = {
  layers: {
    overview: '分档秒开/卡顿趋势 + 发版时间线对齐',
    drilldown: '卡顿样本按设备档×页面×时段下钻，慢样本带会话回放',
    devices: '真机矩阵热力图（机型×页面 色秒开率）',
  },
  principles: ['所有曲线默认分档下钻，拒绝全局平均', '告警链接直达慢样本会话',
    '矩阵夜间批量 + 发版触发跑分'],
  health: 'MTTD（告警->定位）与看板使用率度量自身价值',
};
```
