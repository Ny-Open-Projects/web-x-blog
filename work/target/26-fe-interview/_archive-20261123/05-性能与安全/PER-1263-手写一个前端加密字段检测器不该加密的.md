## PER-1263：手写一个前端加密字段检测器（不该加密的加密了/该加密的没加密）

**答**：
- 需求：实现 fieldEncryptionAudit(fields, rules)。fields 为 [{ name, value, encrypted, level }]；rules: { minLevelEncrypt: 3, forbiddenDouble: [token] }；检查：level >= 3 且未 encrypted -> 违规漏加密；token 类字段不应在前端二次加密（服务端 TLS 已保护，双加密破坏网关审计）-> 违规过度加密；输出 { violations, pass }。
- 边界：level 缺省按 2；encrypted 为 bool；未知字段按 level 2 处理。
- 评分点：级别规则；双重加密判定；缺省级别；权衡说明

```javascript
function fieldEncryptionAudit(fields, rules) {
  const violations = [];
  for (const f of fields) {
    const level = f.level ?? 2;
    if (level >= rules.minLevelEncrypt && !f.encrypted)
      violations.push({ name: f.name, rule: 'S3+ 应加密传输' });
    if (rules.forbiddenDouble.includes(f.name) && f.encrypted)
      violations.push({ name: f.name, rule: 'token 类禁止前端二次加密（TLS 已保护）' });
  }
  return { violations, pass: !violations.length };
}
// 设计取舍：前端加密只在"网关不可信"（如需经过第三方代理）场景使用，
```
