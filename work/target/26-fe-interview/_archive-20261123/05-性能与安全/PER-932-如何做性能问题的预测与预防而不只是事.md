## PER-932：如何做性能问题的预测与预防（而不只是事后发现）

**答**：
- 趋势预测：基于历史序列（ARIMA/简单线性回归）预测下季度指标走势，劣化趋势提前预警。
- 发版前预测：PR 阶段用产物 diff 特征（新增 JS 体积、同步脚本数、图片数量）训练轻量模型预估 LCP 变化，给评审者一个"预计影响"。
- 规则预防：把历史案例转成静态规则（如"新增 > 200KB 同步 chunk 必须评审"），比模型更可解释、先落地。
- 设计期预防：预算卡 + 设计稿成本预估（见 915），把问题挡在最上游。

```javascript
// 线性趋势预测
function forecast(points, horizon = 7) {   // points: [{ x: day, v }]
  const n = points.length;
  const sx = points.reduce((s, p) => s + p.x, 0);
  const sy = points.reduce((s, p) => s + p.v, 0);
  const sxy = points.reduce((s, p) => s + p.x * p.v, 0);
  const sxx = points.reduce((s, p) => s + p.x * p.x, 0);
  const b = (n * sxy - sx * sy) / (n * sxx - sx * sx);
  const a = (sy - b * sx) / n;
  const last = points[n - 1].x;
  return { slope: b,
    risk: Array.from({ length: horizon }, (_, i) =>
      ({ x: last + i + 1, v: +(a + b * (last + i + 1)).toFixed(1) })) };
}
// slope 持续为正且外推触及 SLO -> 提前预警
```
