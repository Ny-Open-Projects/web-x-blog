## PER-981：如何在微前端场景避免多应用渲染管线互相拖累

**答**：
- 问题：多应用同页运行，任一应用的全局样式变更/长任务都影响整体 INP 与首屏。
- 手段：应用级 shadow DOM 或 scoped 样式减少失效扩散；主应用统一调度（子应用渲染切片排队）；路由级懒加载保证同屏只有一个重应用。
- 共享资源：公共库去重（externals）减少多份 React 实例的重复渲染成本。
- 监控：按应用维度打 INP/长任务标（性能记录带 appId），劣化归因到应用而非页面。

```javascript
// 主应用统一渲染调度
const queue = []; let running = false;
async function scheduleAppRender(appId, task) {
  queue.push({ appId, task });
  if (running) return; running = true;
  while (queue.length) {
    const { appId, task } = queue.shift();
    const t0 = performance.now();
    await task();
    report({ appId, dur: performance.now() - t0 });   // 按应用归因
    if (scheduler?.yield) await scheduler.yield();    // 应用间让路
  }
  running = false;
}
```
