## PER-920：性能知识库怎么建设？如何避免经验流失

**答**：
- 沉淀三类内容：案例库（劣化事件复盘：现象→归因→修复→验证）、playbook（修复方案的 step-by-step）、指标字典（每个指标的定义/口径/坑）。
- 结构化模板：每个案例用统一模板录入（背景/根因/修复/数据/反模式），可检索、可导出为新员工培训材料。
- 与平台联动：体检告警直接链接对应 playbook，值班复盘自动生成案例草稿。
- 维护机制：季度评审过期内容，案例标注适用版本范围（如"仅 H2 前的网关场景"）。

```javascript
// 案例库统一模板
const CASE_TEMPLATE = {
  symptom: '现象：某页 P75 LCP 从 2.1s 劣化到 3.4s',
  attribution: '归因：新增 800KB polyfill 未做 browserslist 过滤',
  fix: '修复：corejs 按目标浏览器裁剪，门禁加 polyfill 体积检查',
  verify: '验证：发版后 P75 回落至 2.2s，门禁持续拦截同类问题',
  antiPattern: '反模式：全量引入 core-js3 而不配置 useBuiltIns',
};
function makeCase(fields) { return { ...CASE_TEMPLATE, ...fields }; }
```
