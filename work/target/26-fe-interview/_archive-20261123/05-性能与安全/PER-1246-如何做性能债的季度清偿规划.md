## PER-1246：如何做"性能债"的季度清偿规划

**答**：
- 盘点：巡检+体检+复盘产出的债（反模式/超标页面/过期依赖）统一台账。
- 排序：影响用户数 × 修复可行性 × 复发风险（924 模型）。
- 规划：季度容量 15%~20% 给性能债（固定配比防被需求挤掉），P0 债限期。
- 验收：季度末复检，未清偿债说明原因并滚动，连续两季未动的债升级。

```javascript
// 季度清偿计划
function quarterlyPlan(debts, capacityDays = 60) {
  const sorted = debts.map(d => ({ ...d,
    score: d.users * d.feasibility * d.risk / d.cost }))
    .sort((a, b) => b.score - a.score);
  const plan = []; let used = 0;
  for (const d of sorted) {
    if (used + d.cost > capacityDays) continue;   // 装不下跳过
    plan.push(d); used += d.cost;
  }
  return { plan, used, capacity: capacityDays };
}
```
