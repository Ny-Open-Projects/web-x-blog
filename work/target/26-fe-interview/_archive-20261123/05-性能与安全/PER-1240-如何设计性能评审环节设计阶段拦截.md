## PER-1240：如何设计"性能评审"环节（设计阶段拦截）

**答**：
- 时机：技术方案评审必含性能段落（数据量/交互频次/资源策略）。
- 检查项：预估数据规模与渲染策略、首屏资源清单与预算、第三方依赖、降级预案。
- 输出：评审通过的性能约束写进任务卡（验收条件），开发对照实现。
- 效率：模板化（CRUD 页用标准模板免评审），只评审重交互/大数据页面。

```javascript
// 性能评审模板
function perfDesignReview(design) {
  const checks = [
    d => d.dataScale ? null : '数据规模未评估',
    d => d.renderStrategy ? null : '渲染策略未定',
    d => d.resourceBudget ? null : '资源预算未声明',
    d => d.thirdParties.every(t => t.reviewed) ? null : '三方未评审',
    d => d.fallback ? null : '无降级预案',
  ];
  const fails = checks.map(c => c(design)).filter(Boolean);
  return { pass: !fails.length, fails,
    constraints: design.dataScale <= 10000 ? '标准模板' : '专项方案' };
}
```
