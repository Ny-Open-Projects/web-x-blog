## PER-1230：如何设计"低带宽优先"的默认体验（数据节省模式）

**答**：
- 动机：新兴市场/套餐用户希望省流量——提供"省流模式"开关（用户选择权）。
- 实现：检测 Save-Data 头 / connection.saveData，或用户手动开关；模式下图片低清、关闭自动播放视频、减少预取。
- 默认策略：移动端流量告警（navigator.connection 有限信息）+ 用户设置，默认不开启但易发现。
- 效果度量：省流模式下流量消耗对比（目标 -40%）与任务完成率不下降。

```javascript
// 省流模式
function dataSaver() {
  const byHeader = matchMedia('(prefers-reduced-data: reduce)').matches;
  const byConn = navigator.connection?.saveData === true;
  const byUser = localStorage.getItem('data-saver') === 'on';
  const on = byHeader || byConn || byUser;
  return { on,
    policy: on ? { imgWidth: 480, autoplay: false, prefetch: 'off',
      fonts: 'system-only' } : null };
}
// header 层：Save-Data 请求头由服务端读，驱动响应瘦身
```
