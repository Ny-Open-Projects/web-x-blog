## PER-1296：手写一个"发布前自检清单"执行器

**答**：
- 需求：implement preReleaseCheck(items)。items 为 [{ id, run: () => bool|Promise, severity }]；并行执行；失败项按 severity（P0 阻塞）分级；输出 { pass, failed: [{ id, severity }], durationMs }。
- 边界：run 抛错按 fail；severity 缺失 P1；pass = 无 P0 失败；总耗时统计。
- 评分点：并行执行；异常归 fail；分级判定；耗时

```javascript
async function preReleaseCheck(items) {
  const t0 = Date.now();
  const results = await Promise.all(items.map(async i => {
    let ok = false;
    try { ok = !!(await i.run()); } catch { ok = false; }
    return { id: i.id, ok, severity: i.severity ?? 'P1' };
  }));
  const failed = results.filter(r => !r.ok);
  return { pass: !failed.some(f => f.severity === 'P0'),
    failed, durationMs: Date.now() - t0 };
}
// P0 例：安全头校验/冒烟测试；P1 例：体积预算（可豁免）
```
