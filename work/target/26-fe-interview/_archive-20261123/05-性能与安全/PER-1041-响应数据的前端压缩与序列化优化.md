## PER-1041：响应数据的前端压缩与序列化优化

**答**：
- 大 JSON 的成本不只是传输：解析 10MB JSON 可占主线程数百 ms；方案是分页/裁剪/二进制。
- 二进制协议：Protobuf/MessagePack 体积减半、解析更快；配合 ArrayBuffer 在 Worker 解析。
- 流式解析：超大数组响应用流式 JSON parser 边到边处理，首条数据先渲染。
- Worker 化：JSON.parse 大对象移到 Worker，主线程只收结构化克隆结果。

```javascript
// Worker 中解析大 JSON
const worker = new Worker('json-worker.js');
function parseBigJSON(text) {
  return new Promise(resolve => {
    worker.onmessage = e => resolve(e.data);
    worker.postMessage(text);
  });
}
// json-worker.js:
self.onmessage = e => self.postMessage(JSON.parse(e.data));
// 结构化克隆回传主线程，解析期间主线程不阻塞
// 更优：服务端直接输出 protobuf，前端解码省 50%+ 体积
```
