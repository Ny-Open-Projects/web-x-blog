## PER-242：手写周报生成器——聚合 RUM 上报数据，按页面出 CWV 达标表与环比变化

**题目**：实现 `weeklyReport(rows, prevRows)`：① 输入本周与上周的指标明细数组 `{ page, lcp, inp, cls, device }`；② 按 page × device 聚合出 LCP/INP 的 p75 与 CLS 的 p75（CLS 用 p75 口径统一处理）；③ 判定每行 PASS/FAIL（2500/200/0.1）；④ 输出环比变化（p75 差值与百分比），样本数 < 30 的分组标记 insufficient 不参与判定。

**答**：纯数据聚合题，考点：分组 reduce、分位数计算、小样本保护（等价 k-匿名）、环比符号方向（性能变好应为负差值）。

```javascript
const LIMITS = { lcp: 2500, inp: 200, cls: 0.1 };
const MIN_SAMPLE = 30;

function medianP75(arr) {
  const s = [...arr].sort((a, b) => a - b);
  const idx = (s.length - 1) * 0.75, lo = Math.floor(idx), hi = Math.ceil(idx);
  return s[lo] + (s[hi] - s[lo]) * (idx - lo);
}

function aggregate(rows) {
  const groups = new Map();
  for (const r of rows) {
    const key = `${r.page}|${r.device}`;
    if (!groups.has(key)) groups.set(key, { lcp: [], inp: [], cls: [] });
    groups.get(key).lcp.push(r.lcp); groups.get(key).inp.push(r.inp); groups.get(key).cls.push(r.cls);
  }
  const out = new Map();
  for (const [key, { lcp, inp, cls }] of groups) {
    if (lcp.length < MIN_SAMPLE) { out.set(key, { insufficient: true, samples: lcp.length }); continue; }
    const p75 = { lcp: medianP75(lcp), inp: medianP75(inp), cls: medianP75(cls) };
    out.set(key, {
      samples: lcp.length, p75,
      verdict: p75.lcp <= LIMITS.lcp && p75.inp <= LIMITS.inp && p75.cls <= LIMITS.cls ? 'PASS' : 'FAIL',
    });
  }
  return out;
}

function weeklyReport(rows, prevRows) {
  const cur = aggregate(rows), prev = aggregate(prevRows);
  const table = [];
  for (const [key, stat] of cur) {
    const old = prev.get(key);
    table.push({
      page_device: key, ...stat,
      delta: old && !stat.insufficient && !old.insufficient
        ? Object.fromEntries(Object.entries(stat.p75).map(([m, v]) =>
            [m, +(v - old.p75[m]).toFixed(3)]))          // 负数 = 变好
        : null,
    });
  }
  return table.sort((a, b) => (b.p75?.inp ?? -1) - (a.p75?.inp ?? -1)); // INP 差的排前面
}
```

**评分点**：
- 分组聚合用 Map + key 正确（page × device），不做隐式字符串拼接进对象键以外的歧义。
- p75 用线性插值分位数（不是排序取中位）。
- 小样本保护：samples < 30 标记 insufficient 且不进 PASS/FAIL 判定。
- 环比方向语义正确（负差值 = 改善），并处理上周分组缺失。
