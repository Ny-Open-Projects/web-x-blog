## PER-1112：安全债务的管理：遗留漏洞的治理策略

**答**：
- 盘点：漏洞台账（severity/影响面/修复成本/暴露时长），老漏洞按"暴露时长 × 影响面"优先级排序。
- 策略：高危清零（限期）、中危分批（季度专项）、低危随迭代顺手修；不可修复的（老组件停维）用缓解措施（WAF/限流/下线）。
- 防新增：门禁拦截新增漏洞，台账只减不增是底线。
- 沟通：遗留风险向管理层透明（风险接受单签字），不做"沉默负债"。

```javascript
// 安全债务台账排序
function rankDebts(debts) {
  const w = { critical: 4, high: 3, medium: 2, low: 1 };
  return debts.map(d => ({ ...d,
    score: w[d.severity] * Math.min(d.daysOpen / 30, 6) * d.exposure }))
    .sort((a, b) => b.score - a.score);
}
// exposure: 1 全站暴露 / 0.5 部分 / 0.1 内部
// score 超阈值 -> 本季必须处理；其余出"风险接受单
```
