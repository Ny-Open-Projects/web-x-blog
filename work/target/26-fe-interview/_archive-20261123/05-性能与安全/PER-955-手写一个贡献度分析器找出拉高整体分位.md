## PER-955：手写一个贡献度分析器：找出拉高整体分位的分桶

**答**：
- 需求：实现 topBuckets(buckets, overall, k)。buckets 为 [{ name, p75, count }]；输出对"整体 P75 被拉高"贡献最大的 k 个桶，贡献度 = 桶 p75 相对整体 p75 的超出量 × 桶样本占比；只输出 p75 超过整体的桶，并附 share（样本占比）与 excess。
- 边界：count 为 0 跳过；k 大于桶数返回全部符合的；整体 p75 未给时按加权平均计算。
- 评分点：贡献度公式；加权整体；占比；排序截断

```javascript
function topBuckets(buckets, overall, k = 3) {
  const total = buckets.reduce((s, b) => s + b.count, 0);
  const base = overall ?? buckets.reduce((s, b) => s + b.p75 * b.count, 0) / total;
  return buckets.filter(b => b.count > 0 && b.p75 > base)
    .map(b => ({ name: b.name, p75: b.p75,
      share: +(b.count / total).toFixed(3),
      excess: +(b.p75 - base).toFixed(1),
      contribution: +((b.p75 - base) * b.count / total).toFixed(1) }))
    .sort((a, b) => b.contribution - a.contribution).slice(0, k);
}
// 结论解读：contribution 最高且 share 大 -> 环境结构问题；share 小 p75 极高 -> 长尾个案
```
