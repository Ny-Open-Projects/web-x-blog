## PER-1167：如何向监管/客户证明合规（审计应对）

**答**：
- 证据包：隐私政策版本史、字段注册表、同意记录样例、DSAR 处理记录、审计报告、DPIA 文档、事件响应记录。
- 可答性问题清单：你们采集什么/在哪存/保留多久/谁有权访问/如何删除——每个问题有数据支撑可直接调取。
- 演练：模拟监管问询，24h 内出具指定 uid 的完整数据清单与处理依据。
- 工具化：一键生成证据包（按模板导出），避免临时手忙脚乱。

```javascript
// 监管问询证据包生成
function evidencePack(uid, framework = 'gdpr') {
  return {
    policy: { version: policyVersion(), history: policyHistory() },
    collected: fieldRegistrySnapshot(),
    consent: consentLog(uid),                    // 同意记录
    dsar: dsarHistory(hash(uid)),
    dataMap: traceAll(hash(uid)),                // 数据全流向
    generated: new Date().toISOString(),
  };
}
// 演练 SLA：从问询到证据包导出 < 4 小时
```
