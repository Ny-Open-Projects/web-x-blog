## PER-1242：如何设计"性能预算的成本分摊"（谁的超支谁承担）

**答**：
- 问题：全局预算被某业务超支挤压其他业务——预算按页面/团队切分。
- 机制：总预算 → 页面预算（Owner 认领）→ 团队配额；超支团队用自己的配额（新功能挤压存量或申请扩容走评审）。
- 交易机制：预算可在团队间交易（A 精简释放给 B），平台记账。
- 度量：配额使用率、扩容申请通过率（衡量预算是否合理）。

```javascript
// 预算配额
const QUOTA = { 'team-commerce': 400, 'team-im': 200, 'team-growth': 150 };
function usageReport(team, used) {
  const quota = QUOTA[team] ?? 100;
  return { team, used, quota, rate: +(used / quota * 100).toFixed(1) + '%',
    state: used > quota ? 'overdrawn（新功能冻结或申请扩容）'
      : used > quota * 0.9 ? 'warning' : 'ok' };
}
// overdrawn 团队的合并请求自动要求评审说明
```
