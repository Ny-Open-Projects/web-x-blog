## PER-1224：如何做性能平台的"用户研究"：平台用户是工程师

**答**：
- 用户调研：工程师使用平台完成什么任务（看趋势/查劣化/修问题），NPS 与任务完成时长。
- 度量：看板 DAU、从告警到开单的转化率、功能使用漏斗（劣化报告→下钻→开单）。
- 改进：任务完成时长 > 30min 的功能是重设计候选；低使用功能下线而非维护。
- 机制：平台版本发布附 changelog 与教程，季度用户访谈 5 人。

```javascript
// 平台功能漏斗
function funnel(events, steps) {
  const out = [];
  let prev = null;
  for (const s of steps) {
    const n = events.filter(e => e.step === s).length;
    out.push({ step: s, count: n,
      rate: prev ? +(n / prev * 100).toFixed(1) + '%' : '100%' });
    prev = n;
  }
  return out;
}
// steps: ['alert-received', 'board-viewed', 'drilled', 'ticket-created']
```
