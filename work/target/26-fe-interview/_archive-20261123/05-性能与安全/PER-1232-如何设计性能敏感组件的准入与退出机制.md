## PER-1232：如何设计"性能敏感组件"的准入与退出机制

**答**：
- 准入：组件进核心包前过契约测试 + 体积预算（单组件 ≤ 5KB gzip）+ 依赖审查（禁止引入 moment 类重依赖）。
- 退出：季度使用率统计（< 3% 页面使用）移出核心包转独立包，旧引用给迁移提示。
- 治理：核心包组件数上限（防膨胀），新进一评估一。
- 工具：组件体积报告自动生成（构建期），超标阻塞合并。

```javascript
// 组件准入检查
function componentGate(meta) {
  const failures = [];
  if (meta.gzipKB > 5) failures.push(`体积 ${meta.gzipKB}KB > 5KB`);
  if (meta.deps.some(d => ['moment', 'lodash'].includes(d)))
    failures.push('重依赖禁止，用 dayjs/按需工具');
  if (!meta.contractPass) failures.push('契约测试未通过');
  return { pass: !failures.length, failures };
}
// 使用率退出：
function retireCandidate(usage) {
  return usage.pagesUsing / usage.totalPages < 0.03;
}
```
