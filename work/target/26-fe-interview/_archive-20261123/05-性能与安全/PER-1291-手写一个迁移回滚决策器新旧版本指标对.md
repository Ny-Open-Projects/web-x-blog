## PER-1291：手写一个"迁移回滚决策"器（新旧版本指标对比触发）

**答**：
- 需求：implement rollbackDecision(newM, oldM, { tol = 1.1, minSamples = 200 })。newM/oldM 为 { lcpP75, inpP75, errRate, samples }；触发回滚：任一核心指标劣化 > tol 且样本达标；inpP75 容差 +50ms；输出 { rollback, reasons }；样本不足输出 observe。
- 边界：errRate 容差绝对 +0.5%；reasons 列出触发指标；两边样本都需达标才判定。
- 评分点：容差差异；样本门槛；三态判定；理由列表

```javascript
function rollbackDecision(newM, oldM, { tol = 1.1, minSamples = 200 } = {}) {
  if (newM.samples < minSamples || oldM.samples < minSamples)
    return { rollback: false, verdict: 'observe', reason: '样本不足继续观察' };
  const reasons = [];
  if (newM.lcpP75 > oldM.lcpP75 * tol)
    reasons.push(`LCP ${newM.lcpP75} vs ${oldM.lcpP75}`);
  if (newM.inpP75 > oldM.inpP75 + 50)
    reasons.push(`INP ${newM.inpP75} vs ${oldM.inpP75}（容差+50ms）`);
  if (newM.errRate > oldM.errRate + 0.005)
    reasons.push(`errRate ${newM.errRate} vs ${oldM.errRate}`);
  return { rollback: reasons.length > 0, verdict: reasons.length ? 'rollback' : 'promote',
    reasons };
}
```
