## PER-1118：如何设计"安全探针"持续验证线上防线有效性

**答**：
- 探针类型：注入探针（模拟 payload 到测试通道验证 CSP/转义）、CSP 探针（report 频率监控）、降级探针（定期触发 kill switch 验证可用）。
- 频率：低频无害探针（小时级），不干扰业务；结果进安全看板。
- 价值：防线"看起来配了"≠"真生效"——探针持续证明防线活着。
- 误报处理：探针事件单独标记（不进业务告警），探针自身失败也告警（探针死了更危险）。

```javascript
// 注入探针：验证输出转义
async function injectionProbe() {
  const marker = 'xss-probe-' + Date.now();
  await api('/search', { q: `<b id="${marker}">` });   // 走测试通道
  await new Promise(r => setTimeout(r, 500));
  const injected = !!document.getElementById(marker);
  report({ type: 'probe', probe: 'xss-escape',
    pass: !injected });                                // 被渲染=转义失效
}
// 定时执行：setInterval(injectionProbe, 3600_000)
```
