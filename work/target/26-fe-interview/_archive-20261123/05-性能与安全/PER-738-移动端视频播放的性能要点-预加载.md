## PER-738：移动端视频播放的性能要点：预加载分片、卡顿定位与后台播放的策略矩阵

**答**：
- 视频卡顿定位四源：**网络**（分片下载速度 < 播放码率 -> buffer 不足）、**解码**（低端机硬解不支持当前编码档位 -> 掉帧）、**渲染**（合成层压力大）、**前台切换**（切后台回来 buffer 重置）——埋点分源统计。
- 预加载策略矩阵：Wi-Fi 预取下一视频首片（约 500KB）、蜂窝只预 meta（moov box 前置）、列表页只预 poster——按网络档与用户意图分档。
- 后台播放：iOS 需要开启后台音频能力 + 音频焦点管理（与音乐 App 抢占）；切后台时视频降级为音频流（省解码电耗）。
- 度量：起播时间（点播 -> 首帧）、卡顿率（stall 时长/播放时长）、切后台电量影响（容器侧提供）。

```javascript

const videoPerfMatrix = {
  stallAttribution: { net: '分片下载速度 < 码率 -> buffer 不足', decode: '硬解档位不支持 -> 掉帧',
    render: '合成层压力大', bg: '切后台 buffer 重置' },
  preload: { wifi: '下一视频首片 ~500KB', cell: '只预 meta（moov 前置）', list: '仅 poster' },
  background: '切后台降级音频流省电；音频焦点管理与音乐 App 抢占处理',
  metrics: ['起播时间', '卡顿率 = stall 时长/播放时长', '切后台电耗（容器侧）'],
};
// moov 前置：ffmpeg -movflags faststart 输出，浏览器才能边下边播
```
