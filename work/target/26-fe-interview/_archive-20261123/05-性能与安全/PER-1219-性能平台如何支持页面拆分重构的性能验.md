## PER-1219：性能平台如何支持"页面拆分"重构的性能验收

**答**：
- 场景：老页面拆成微前端/路由拆分，验收"拆分不劣化"——分段加载总成本可控。
- 验收模型：拆分后首屏指标 ≤ 拆分前 × 1.1；交互路径（点击到下一屏）总加载 ≤ 原单页；内存峰值下降。
- 度量：链路级指标（跨页面路径 P75）而非单页面指标；链路埋点带 traceId 串联。
- 回滚标准：验收不过 48h 内可整体切回原页面（资源双保留）。

```javascript
// 链路级验收
function linkAcceptance(before, after, { tol = 1.1 } = {}) {
  return {
    firstScreen: { b: before.lcp, a: after.lcp,
      pass: after.lcp <= before.lcp * tol },
    interaction: { b: before.pathMs, a: after.pathMs,
      pass: after.pathMs <= before.pathMs },
    memory: { b: before.peakMB, a: after.peakMB,
      pass: after.peakMB <= before.peakMB },
    verdict: after.lcp <= before.lcp * tol &&
             after.pathMs <= before.pathMs &&
             after.peakMB <= before.peakMB,
  };
}
```
