## PER-1280：手写一个探针调度健康监控：探针本身死没死

**答**：
- 需求：implement probeHealth(probes, now)。probes 为 [{ id, lastRun, intervalMs, lastResult }]；健康判定：lastRun 距今 > 2×intervalMs -> dead；lastResult 连续 fail -> broken；输出 { healthy, dead: [id], broken: [id] }；healthy = 无 dead 且无 broken。
- 边界：lastRun 缺失视为从未运行 -> dead；intervalMs 缺失按 60s；healthy 输出同时给 reason。
- 评分点：失联判定；持续失败；健康汇总；理由

```javascript
function probeHealth(probes, now = Date.now()) {
  const dead = [], broken = [];
  for (const p of probes) {
    const interval = p.intervalMs ?? 60_000;
    if (!p.lastRun || now - p.lastRun > 2 * interval)
      dead.push(p.id);
    else if (p.lastResult === 'fail')
      broken.push(p.id);
  }
  return { healthy: !dead.length && !broken.length,
    dead, broken,
    reason: dead.length ? `探针失联: ${dead.join(',')}`
      : broken.length ? `探针持续失败: ${broken.join(',')}` : 'ok' };
}
```
