## PER-1121：前端安全的年度规划怎么做

**答**：
- 输入：威胁模型缺口、漏洞台账、合规新要求（如新隐私法）、行业事件（供应链攻击案例）。
- 规划结构：基线加固（Q1）→ 平台化能力（Q2）→ 专项治理（Q3）→ 度量与演练（Q4），滚动迭代。
- 资源匹配：每项估人力与收益（风险敞口下降），与业务需求平衡（安全占比 10%~15% 合理）。
- 复盘：年末对照年初目标逐项验收，未完成项分析原因进下年。

```javascript
// 年度规划模板
const ROADMAP = {
  Q1: { goal: '安全基线 100% 覆盖', items: ['CSP 全站 enforce', '依赖治理清零'] },
  Q2: { goal: '安全 SDK 平台化', items: ['脱敏管道', '签名中间件', '探针系统'] },
  Q3: { goal: '高危专项清零', items: ['遗留 XSS 治理', '越权扫描修复'] },
  Q4: { goal: '度量与演练', items: ['红队演练', '应急响应验证', '年度评分'] },
};
function planCheck(quarter, done) {
  return { quarter, progress: +(done.length / ROADMAP[quarter].items.length * 100).toFixed(0) + '%' };
}
```
