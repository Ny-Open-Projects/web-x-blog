## PER-1287：手写一个错误率-性能联动告警器

**答**：
- 需求：implement jointAlert(perfWin, errWin)。两窗口各 { p75, errRate, samples }；联动规则：errRate > 5% 且 p75 劣化 > 20% 判 incident（疑似故障而非优化问题）；仅 perf 劣化判 perf；仅错误升判 error；正常判 ok；样本 < 50 输出 insufficient。
- 边界：errRate 基线来自参数（默认 1%）；p75 基线同上；两窗口样本独立校验；输出含 reason。
- 评分点：联动判定；样本门槛；四态输出；理由

```javascript
function jointAlert(perfWin, errWin, { errBase = 0.01, perfBase = 2500 } = {}) {
  if (perfWin.samples < 50 || errWin.samples < 50)
    return { verdict: 'insufficient', reason: '样本不足' };
  const perfBad = perfWin.p75 > perfBase * 1.2;
  const errBad = errWin.errRate > 0.05;
  if (perfBad && errBad)
    return { verdict: 'incident', reason: '性能与错误同升，疑似线上故障' };
  if (perfBad) return { verdict: 'perf', reason: `P75 ${perfWin.p75}ms 劣化 >20%` };
  if (errBad) return { verdict: 'error', reason: `错误率 ${errWin.errRate} 超 5%` };
  return { verdict: 'ok' };
}
```
