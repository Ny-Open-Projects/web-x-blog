## PER-933：性能门禁的阈值怎么科学设定而不是拍脑袋

**答**：
- 三源定标：业务对标（竞品同场景数据）、用户分布（当前 P75 与目标 SLO 的差距）、技术可行性（优化空间上限）。
- 动态阈值：门禁阈值 = max(SLO, 当前基线 × 1.05)，随基线改善逐步收紧（棘轮机制），防止一次性定过高被绕过。
- 分桶阈值：低端机与桌面机不同阈值（如移动 4G P75 2500ms vs 桌面 1800ms），统一阈值会误伤。
- 校准闭环：统计门禁拦截后真实发版的指标变化，若拦截项目大多数并未实际劣化，说明阈值过严需回调。

```javascript
// 棘轮阈值
const SLO = { lcp: 2500, inp: 200 };
function ratchet(currentP75, tighten = 1.05) {
  return {
    lcp: Math.max(SLO.lcp, Math.round(currentP75.lcp * tighten)),
    inp: Math.max(SLO.inp, Math.round(currentP75.inp * tighten)),
  };
}
// 基线 3000ms 时门禁 = 3150ms；改善到 2400 后自动回到 SLO 2500
```
