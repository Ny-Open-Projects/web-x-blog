## PER-1289：手写一个"页面健康卡"生成器（汇总一页指标）

**答**：
- 需求：implement healthCard(page, data, slo)。data 为 { lcpP75, inpP75, clsP75, errRate, bundleKB, cacheHitRate }；slo 为各指标阈值；输出 { page, score: 0~100, items: [{ metric, value, slo, pass }], worst }：每达标项 100/项数*1 权重均分；worst 为分差最大项。
- 边界：缺失指标跳过不计分；bundleKB 超标也算 fail；score 保留整数；数据全缺 score = null。
- 评分点：缺失跳过；均分计分；worst 比率；全缺 null

```javascript
function healthCard(page, data, slo) {
  const metrics = ['lcpP75', 'inpP75', 'clsP75', 'errRate', 'bundleKB', 'cacheHitRate']
    .filter(k => data[k] != null);
  if (!metrics.length) return { page, score: null, items: [], worst: null };
  const items = metrics.map(k => ({ metric: k, value: data[k], slo: slo[k],
    pass: data[k] <= slo[k] }));
  const score = Math.round(items.filter(i => i.pass).length / items.length * 100);
  const worst = items.filter(i => !i.pass)
    .sort((a, b) => (b.value / b.slo) - (a.value / a.slo))[0]?.metric ?? null;
  return { page, score, items, worst };
}
```
