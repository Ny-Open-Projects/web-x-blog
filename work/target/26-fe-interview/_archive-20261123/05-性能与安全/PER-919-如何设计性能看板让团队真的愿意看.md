## PER-919：如何设计性能看板让团队真的愿意看

**答**：
- 一屏原则：默认视图只放 3 个核心指标（LCP/INP/错误率）+ 劣化标注，细节靠下钻，不要堆 20 张图。
- 上下文自带：每条曲线标注发版竖线、灰度区间、大促流量标注，看到曲线异常能立刻关联事件。
- 可行动性：看板上每个异常点都能一键跳转到劣化报告与 Owner，看板是入口不是终点。
- 订阅机制：周报自动发给各页面 Owner（只含自己页面的数据），榜单公示促进横向比较。

```javascript
// 看板数据装配：曲线 + 事件标注
function assemble(series, releases, slo) {
  const marks = releases.map(r => ({ x: r.ts, label: r.version,
      color: r.hotfix ? 'red' : 'gray' }));
  return series.map(s => ({ ...s,
    marks: marks.filter(m => m.x >= s.from && m.x <= s.to),
    sloLine: slo[s.metric],            // SLO 参考线
    regression: s.points.some((p, i) =>
      i > 0 && p.v > s.points[i - 1].v * 1.08) }));  // 劣化点标记
}
```
