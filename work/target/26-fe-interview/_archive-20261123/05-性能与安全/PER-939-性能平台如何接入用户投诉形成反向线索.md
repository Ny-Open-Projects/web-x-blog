## PER-939：性能平台如何接入「用户投诉」形成反向线索

**答**：
- 投诉→指标映射：用户说"卡"映射到候选指标集合（INP/掉帧/内存），投诉说"慢"映射到 LCP/TTFB，先按页面与时间段聚合定位。
- 单用户取证：投诉附带 uid 时，拉取该用户会话的性能记录 + 设备信息 + 会话回放，确认是普遍问题还是个案（低端机/特定版本）。
- 闭环统计：投诉驱动的问题占比、平均定位时长，验证 RUM 指标与主观体验的相关性，反过来校准指标权重。
- 反哺：高频投诉场景提升为专项，并在平台加对应自动化检测，让同类问题下次被系统先发现。

```javascript
// 投诉聚类定位
function triage(complaints, rum) {
  const byPage = {};
  for (const c of complaints)
    (byPage[c.page] ??= { n: 0, metrics: {} }).n++;
  return Object.entries(byPage).map(([page, v]) => {
    const rows = rum.filter(r => r.page === page);
    const p75 = arr => arr.sort((a, b) => a - b)[Math.floor(arr.length * 0.75)];
    return { page, complaints: v.n,
      lcpP75: p75(rows.map(r => r.lcp)),
      inpP75: p75(rows.map(r => r.inp)),
      suspect: rows.length && p75(rows.map(r => r.lcp)) > 2500 ? '加载慢' : '交互卡/个案' };
  }).sort((a, b) => b.complaints - a.complaints);
}
```
