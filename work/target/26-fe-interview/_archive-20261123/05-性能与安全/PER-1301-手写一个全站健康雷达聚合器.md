## PER-1301：手写一个"全站健康雷达"聚合器

**答**：
- 需求：implement radar(pages, slo)。pages 为 [{ page, lcpP75, errRate, secScore, privacyPass }]；雷达五维：性能（lcp 达标率）、稳定（err 达标率）、安全（secScore 均值/100）、合规（privacyPass 比例）、覆盖（有探针路由占比 coverage 传入）；每维 0~100；输出 { dims, overall }（均分）。
- 边界：某维无数据该维按 0 计并在 missing 标注；overall 保留 1 位；dims 按 [性能, 稳定, 安全, 合规, 覆盖] 顺序。
- 评分点：五维计算；缺失按 0；均分；标注缺失

```javascript
function radar(pages, slo, coverage = 1) {
  const n = pages.length || 1;
  const perf = pages.filter(p => p.lcpP75 <= slo.lcp).length / n * 100;
  const stable = pages.filter(p => p.errRate <= slo.errRate).length / n * 100;
  const secScores = pages.filter(p => p.secScore != null);
  const security = secScores.length
    ? secScores.reduce((s, p) => s + p.secScore, 0) / secScores.length : 0;
  const privacy = pages.filter(p => p.privacyPass).length / n * 100;
  const dims = [perf, stable, security, privacy, coverage * 100].map(v => +v.toFixed(1));
  return { dims, overall: +(dims.reduce((s, v) => s + v, 0) / 5).toFixed(1),
    missing: [secScores.length ? null : 'security'].filter(Boolean) };
}
```
