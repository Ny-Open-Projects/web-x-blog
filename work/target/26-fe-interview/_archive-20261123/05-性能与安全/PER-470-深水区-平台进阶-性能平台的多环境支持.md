## PER-470：多环境性能采集与预发基线的可信度边界？

**答**:
- 环境隔离：上报带 env 字段（dev/staging/prod），管道按环境分流（生产进正式库，测试进沙箱库定期清理）——压测数据污染生产看板是经典事故（压测流量带专用标记 → 管道丢弃/沙箱路由）。
- 预发基线可信度边界：预发能测"代码性能"（bundle/渲染/交互，与生产等价）；测不了"规模性能"（数据量/并发/CDN 分布都是缩小的）。结论：预发基线用于"同环境回归对比"（新旧版本 diff 有效），用于"绝对 SLO 判定"不可信。
- 用法规范：CI 卡口（预发跑 LHCI）用同口径 diff 判定；生产 SLO 判定只用生产 RUM；预发数据量失真用缩放系数外推（标注为估算）。
- 工程细节：预发与生产的采集 SDK 同版本（口径一致，PER-435）；环境间指标不可直接比（用户行为差异大——测试账号的行为不代表真实用户）。

```text
多环境采集规范：
env 字段贯穿 + 管道分流（测试沙箱库）；压测流量专用标记 → 丢弃/沙箱路由
预发基线可信度：✓ 同环境回归对比；✗ 绝对 SLO 判定（数据量/CDN 缩水）
规范：CI 卡口用同口径 diff；生产 SLO 只用生产 RUM；失真补偿用缩放系数（标注估算）
细节：预发与生产 SDK 同版本；环境间指标不可直接比（测试账号行为 ≠ 真实用户）
```
