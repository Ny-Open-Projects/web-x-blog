## PER-1177：隐私工程的技术债优先级：先修什么

**答**：
- 优先级排序：违背同意（P0 级合规风险）> 敏感数据裸奔（日志/存储）> 未登记字段 > 文档过期。
- 修复成本与风险矩阵：高风险低成本立即修；高风险高成本立项；低风险低成本顺手修。
- 快速验证修复：审计管线复跑（1160），通过即关闭。
- 预防再犯：每个债对应一条管线规则或评审 checklist 项。

```javascript
// 隐私债优先级
function prioritizePrivacyDebts(debts) {
  const risk = { 'consent-violation': 5, 'sensitive-log': 4,
    'undeclared-field': 3, 'stale-doc': 1 };
  return debts.map(d => ({ ...d,
    score: risk[d.type] * 2 - d.fixCost }))
    .sort((a, b) => b.score - a.score);
}
// score 最高且 fixCost 低 -> 本周修；其余进季度专项
```
