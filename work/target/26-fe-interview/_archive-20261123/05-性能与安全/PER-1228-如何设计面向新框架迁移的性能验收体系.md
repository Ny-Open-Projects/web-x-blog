## PER-1228：如何设计面向"新框架迁移"的性能验收体系

**答**：
- 场景：Vue2→Vue3/React18 迁移，性能不能回退（新框架运行时差异）。
- 验收集：核心页面 LCP/INP 对比（容差 5%）、包体积对比（运行时增量解释）、内存对比、长任务率对比。
- 方法：新旧版本并行部署（路由级灰度），RUM 按 buildId 分组对比（1218）；固定环境 Lab 复测。
- 风险点：新框架的编译产物差异（Tree-shaking 改善或劣化）、Suspense/Transition 引入的布局变化。

```javascript
// 迁移对比报告
function migrationPerf(oldM, newM, { tol = 1.05 } = {}) {
  const items = ['lcp', 'inp', 'jsKB', 'memMB'].map(k => ({
    metric: k, old: oldM[k], new: newM[k],
    ratio: +(newM[k] / oldM[k]).toFixed(3),
    pass: newM[k] <= oldM[k] * tol || k === 'inp' && newM[k] <= oldM[k] + 20 }));
  return { pass: items.every(i => i.pass), items };
}
// inp 容差放宽到 +20ms（新框架交互模型差异）
```
