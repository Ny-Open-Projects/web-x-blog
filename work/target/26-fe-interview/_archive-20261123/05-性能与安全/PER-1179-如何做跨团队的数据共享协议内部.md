## PER-1179：如何做跨团队的数据共享协议（内部）

**答**：
- 场景：A 团队数据给 B 团队分析/产品——内部共享也需要目的限定与登记。
- 协议要素：数据范围（字段级）、目的、保留期、访问人员范围、是否可再分发。
- 技术落地：数据网关按协议授权（越界查询拒绝）、共享登记表（谁/什么/多久）。
- 审计：季度盘点共享协议有效性，过期协议自动断供。

```javascript
// 内部数据共享登记
const SHARES = [
  { from: 'commerce', to: 'growth', fields: ['order_id', 'amount'],
    purpose: '转化分析', until: '2026-12-31', redistributable: false },
];
function shareGateway(from, to, fields) {
  const s = SHARES.find(s => s.from === from && s.to === to);
  if (!s || s.until < new Date().toISOString().slice(0, 10))
    throw new Error('无有效共享协议或已过期');
  const extra = fields.filter(f => !s.fields.includes(f));
  if (extra.length) throw new Error('越界字段: ' + extra.join(','));
  return { allowed: s.fields, redistri: s.redistributable };
}
```
