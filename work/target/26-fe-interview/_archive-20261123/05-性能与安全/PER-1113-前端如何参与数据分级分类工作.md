## PER-1113：前端如何参与数据分级分类工作

**答**：
- 分级标准：S1 公开、S2 内部、S3 个人信息、S4 敏感个人信息（金融/健康/生物特征）——每级有采集/展示/传输/存储/日志规则。
- 前端动作：S3+ 数据展示默认脱敏（点开查看需权限并留痕）、S4 不落本地存储、导出 S3+ 走审批。
- 标注机制：接口元数据标注字段级别，前端 SDK 按标注自动脱敏，不靠开发者记忆。
- 审计：S3+ 页面截图水印 + 访问日志，泄露可溯源。

```javascript
// 字段级自动脱敏
const FIELD_LEVEL = { phone: 3, idCard: 4, name: 3, amount: 2 };
function renderField(field, value, { perms, watermarked = true } = {}) {
  const level = FIELD_LEVEL[field] ?? 2;
  if (level <= 2) return value;
  if (!perms.canView(level)) return mask(value);     // 无权自动掩码
  logAudit(currentUser, `view:${field}`, 'explicit');
  return watermarked ? withWatermark(value) : value;
}
function mask(v) { return String(v).replace(/.(?=.{2})/g, '*'); }
```
