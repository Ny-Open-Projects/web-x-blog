## PER-1197：如何做"隐私能力"的开源与行业共享（提升影响力）

**答**：
- 可共享：脱敏规则库、同意管理 SDK、隐私测试夹具、审计管线规则——通用能力不影响业务机密。
- 收益：行业影响力、招聘吸引力、外部贡献反哺（社区发现规则漏洞）。
- 边界：业务字段示例脱敏、内部域名替换、审计规则可开源但公司名单不出。
- 运营：文档+示例+版本化发布，PR 流程与内部评审同标准。

```javascript
// 开源包结构
const OSS_PKG = {
  name: '@fe/privacy-toolkit',
  modules: ['redact', 'consent', 'audit-rules', 'test-fixtures'],
  sanitized: s => s.replace(/example\.com/g, 'your-domain.example')
    .replace(/FE_[A-Z_]+/g, 'YOUR_ENV_VAR'),
};
function publishCheck(code) {
  const leaks = /internal\.corp|FE_[A-Z_]+/.test(code) ? ['内部信息未脱敏'] : [];
  return { ok: !leaks.length, leaks };
}
```
