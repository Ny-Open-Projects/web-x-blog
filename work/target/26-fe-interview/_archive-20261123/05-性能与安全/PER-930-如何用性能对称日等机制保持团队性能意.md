## PER-930：如何用「性能对称日」等机制保持团队性能意识

**答**：
- 机制设计：每月固定性能日——处理看板积压 P1 项、复检历史修复是否回退、分享一个新案例。
- 游戏化：团队性能分（页面健康度加权）排名 + 月度改进奖，把冷数据变成可感知荣誉。
- 新人机制：入职第一周完成"一次性能体检 + 一个小修复"，建立手感。
- 防形式化：性能日产出必须落任务单并复检，不做"只开会不落地"。

```javascript
// 团队性能分
function teamScore(pages) {   // pages: [{ page, owner, lcp, cls, inp }]
  const s = pages.map(p => ({
    owner: p.owner,
    score: (p.lcp <= 2500 ? 1 : p.lcp <= 4000 ? 0.5 : 0) * 0.5 +
           (p.cls <= 0.1 ? 1 : 0) * 0.2 +
           (p.inp <= 200 ? 1 : p.inp <= 500 ? 0.5 : 0) * 0.3 }));
  const agg = {};
  for (const { owner, score } of s) agg[owner] = (agg[owner] ?? 0) + score;
  return Object.entries(agg).map(([o, v]) => ({ owner: o, score: +v.toFixed(2) }))
    .sort((a, b) => b.score - a.score);
}
```
