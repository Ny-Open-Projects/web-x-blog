## PER-1183：如何做"隐私设计"的架构评审（区别于安全评审）

**答**：
- 差异：安全评审问"怎么防攻击"，隐私评审问"数据处理是否正当"——数据流合法性是主线。
- 输入：数据流图（1136）、字段清单、同意模型、第三方名单、保留期。
- 评审问题清单：每字段有合法基础？最小化了吗？默认值关还是开？用户能关吗？关了能验证吗？删得了吗？
- 输出：评审结论（通过/有条件通过/打回）+ 整改项进台账。

```javascript
// 隐私架构评审问题清单
const QUESTIONS = [
  f => f.fields.every(x => x.basis) ? null : '存在无合法基础字段',
  f => f.fields.every(x => x.level <= 2 || x.separateConsent) ? null : 'S3+ 需单独同意',
  f => f.defaultsMinimal ? null : '默认值非最小化',
  f => f.revocable ? null : '采集不可关闭',
  f => f.erasePath ? null : '无删除路径',
];
function privacyArchReview(feature) {
  const fails = QUESTIONS.map(q => q(feature)).filter(Boolean);
  return { verdict: fails.length ? 'conditional' : 'pass', fails };
}
```
