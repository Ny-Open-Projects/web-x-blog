## PER-525：手写一个性能数据快照对比工具：输入新旧两份指标 JSON，输出带回归标记的 Markdown 报告

**答**：
- 输入是两次跑分的聚合 JSON（含指标分位数），输出是可直接贴进 PR 的 Markdown 表格；核心是 diff 规则：绝对差与相对差结合，超阈值标 `⚠️ regression`，改善标 `✅ improved`。
- 要点：不同指标用不同容差与方向（LCP 越低越好、CLS 越低越好，不存在"越高越好"的常规指标）；样本量差异过大（<30%）时 diff 不可信要标注。
- 评分点：方向性（所有指标都是低好）与不可信标注这两处工程细节。

```javascript

function compareReports(prev, cur, { tol = 0.08 } = {}) {
  const lines = ['| 指标 | 旧 p75 | 新 p75 | 变化 | 结论 |', '| --- | --- | --- | --- | --- |'];
  const oldN = prev.samples, newN = cur.samples;
  const unreliable = Math.min(oldN, newN) / Math.max(oldN, newN) < 0.3; // 样本量差异过大
  for (const k of Object.keys(prev.metrics)) {
    const o = prev.metrics[k], n = cur.metrics[k];
    const delta = (n - o) / o;                    // 所有性能指标均为"越低越好"
    const verdict = unreliable ? '样本量差异大，不可信'
      : delta > tol ? '⚠️ 回归' : delta < -tol ? '✅ 改善' : '持平';
    lines.push(`| ${k} | ${o}ms | ${n}ms | ${(delta * 100).toFixed(1)}% | ${verdict} |`);
  }
  lines.push('', `样本量: ${oldN} -> ${newN}; 环境: ${prev.env === cur.env ? prev.env : '⚠️ 环境不一致，不可比'}`);
  return lines.join('\n');
}
// const md = compareReports(prev, cur); -> core-set-comment md 并触发告警
```
