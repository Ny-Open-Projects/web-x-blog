## PER-1005：隐私合规的技术自证：审计日志怎么建

**答**：
- 要证明合规需要证据链：同意记录、字段注册表、采集器配置版本、数据流向图、删除请求执行记录。
- 日志结构：不可变事件流（append-only），含主体哈希、动作、依据（政策版本/同意快照），保留期与业务数据对齐。
- 自动化：每次发版自动导出"当前采集配置 diff"作为审计附件；DSAR（数据主体请求）工单的导出/删除操作全留痕。
- 演练：半年一次模拟监管问询，能在 24h 内给出某 uid 的采集清单与依据。

```javascript
// 审计日志（append-only）
const audit = [];
function logAudit(subject, action, basis) {
  audit.push({ ts: Date.now(), subject: hash(subject), action,
    basis, prev: audit.length ? audit[audit.length - 1].h : null });
  audit[audit.length - 1].h = hash(JSON.stringify(audit[audit.length - 1]));
}
function hash(s) { let h = 0; for (const c of String(s)) h = (h * 31 + c.charCodeAt(0)) >>> 0; return h.toString(16); }
// DSAR 演练：logAudit(uid,'export','GDPR Art.15 consent-v3')
```
