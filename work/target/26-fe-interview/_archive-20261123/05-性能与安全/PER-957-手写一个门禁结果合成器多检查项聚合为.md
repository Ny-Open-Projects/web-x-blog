## PER-957：手写一个门禁结果合成器：多检查项聚合为通过/警告/拦截

**答**：
- 需求：实现 mergeGate(results)。results 为 [{ id, level: P0/P1/P2, fail: bool }]；合成规则：任一 P0 fail -> block；无 P0 fail 但存在 P1 fail -> warn；否则 pass。输出 { verdict, failed: [id], summary }，summary 生成一句人话（含各类计数）。
- 边界：空结果为 pass；未知 level 按 P1 处理并计入 warnings；重复 id 去重取最后一条。
- 评分点：去重；级别判定优先级；人话 summary；空输入

```javascript
function mergeGate(results) {
  const seen = new Map();
  for (const r of results) seen.set(r.id, r);        // 去重取最后
  const items = [...seen.values()];
  const level = i => ['P0', 'P1', 'P2'].includes(i.level) ? i.level : 'P1';
  const failed = items.filter(i => i.fail);
  const p0 = failed.filter(i => level(i) === 'P0');
  const p1 = failed.filter(i => level(i) === 'P1');
  const verdict = p0.length ? 'block' : (p1.length || p0.length === 0 && p1.length ? 'warn' : 'pass');
  const v2 = p0.length ? 'block' : (p1.length ? 'warn' : 'pass');
  return { verdict: v2, failed: failed.map(i => i.id),
    summary: `共${items.length}项检查：P0 失败${p0.length}，P1 失败${p1.length}，判定 ${v2}` };
}
```
