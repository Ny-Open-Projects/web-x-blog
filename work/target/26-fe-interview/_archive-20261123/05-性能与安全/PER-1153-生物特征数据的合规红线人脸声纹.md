## PER-1153：生物特征数据的合规红线（人脸/声纹）

**答**：
- 定位：生物特征是最高敏感级（个保法单独同意 + 必要性论证；部分辖区几乎禁止非必要采集）。
- 替代优先：能用设备本地验证（FaceID 由系统完成，特征不出设备）就不上传特征数据。
- 若必须：本地特征提取+仅上传比对结果向量（不可逆模板），传输加密、存储加密、短保留。
- 前端注意：人脸采集页必须有显著告知与单独勾选，且提供非生物替代方式（密码验证），不得强制。

```javascript
// 本地生物验证（特征不出设备）
async function biometricAuth(action) {
  if (!window.PublicKeyCredential) return fallbackPassword(action);
  const assertion = await navigator.credentials.get({
    publicKey: { challenge: crypto.getRandomValues(new Uint8Array(32)),
      userVerification: 'required' },
  });                                                // 设备本地校验
  return { verified: !!assertion, action,
    note: '特征数据留在设备安全区，仅传验证结果' };
}
```
