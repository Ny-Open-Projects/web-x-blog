## PER-945：性能平台如何支撑「性能面试题库」与新员工培训

**答**：
- 平台数据反哺培训：真实劣化案例改编为内部练习题，新员工在测试环境复现并修复，验收看指标变化。
- 分级课程：入门（指标概念/工具使用）→ 进阶（归因方法/门禁建设）→ 专家（平台架构/预测体系）。
- 实操环境：提供内置典型问题的沙箱仓库（内存泄漏/布局抖动/大图），配好采集与看板，练习闭环。
- 度量：培训后一个月内人均发现/修复问题数变化，验证培训有效性。

```javascript
// 沙箱题目验收器
function gradeExercise(before, after, { lcpTarget = 0.7, clsTarget = 0.05 } = {}) {
  const passLCP = after.lcp <= before.lcp * lcpTarget;
  const passCLS = after.cls <= clsTarget;
  return { pass: passLCP && passCLS,
    detail: { lcp: `${before.lcp} -> ${after.lcp}`, cls: `${before.cls} -> ${after.cls}`,
      hints: !passLCP ? '继续找主阻塞资源与 LCP 元素' : [] } };
}
```
