## PER-1095：前端埋点的"反作弊"：防刷与数据可信

**答**：
- 作弊形态：脚本模拟点击/曝光刷量、设备农场、API 直接打点。
- 防御：打点签名（同 1088）+ 行为特征（事件时间间隔/轨迹熵）+ 服务端频控与去重（设备+IP+uid 三元组窗口去重）。
- 数据治理：异常流量隔离桶（不进业务大盘），置信度标记；业务指标发布前过滤低置信样本。
- 平衡：过度风控误伤真实用户（低端机轨迹熵天然低），阈值分档而非一刀切。

```javascript
// 打点可信度评分
function trustScore(event) {
  let s = 100;
  if (event.dwell < 100) s -= 40;                    // 曝光停留过短
  if (event.pathEntropy !== undefined && event.pathEntropy < 0.5) s -= 20;
  if (event.noUserGesture) s -= 30;                  // 无用户手势的点击
  if (event.repeated > 10) s -= 30;                  // 短窗重复
  return { score: Math.max(0, s),
    bucket: s >= 70 ? 'trusted' : s >= 40 ? 'review' : 'suspect' };
}
// suspect 不进业务口径，review 人工抽查
```
