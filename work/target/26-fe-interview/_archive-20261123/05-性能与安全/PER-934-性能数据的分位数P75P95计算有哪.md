## PER-934：性能数据的分位数（P75/P95）计算有哪些坑

**答**：
- 分位数不能对"采样后均值"再平均：必须保留明细或用 t-digest/HdrHistogram 等可合并草图。
- 窗口拼接问题：跨窗口聚合时若各窗口只存了 P75，整体 P75 无法还原——平台设计时就要选可 merge 的结构。
- 分位选择：对外承诺用 P75（Chrome 口径），内部告警可加 P95 但要接受噪声；P99 通常不适合前端（异常设备主导）。
- 小样本陷阱：某页面日 UV < 100 时分位数抖动巨大，应聚合到周或标记"样本不足"。

```javascript
// 简易可合并分位草图（桶直方图）
function makeHist(binMs = 250) {
  const bins = new Map();
  return {
    add(v) { const b = Math.floor(v / binMs); bins.set(b, (bins.get(b) ?? 0) + 1); },
    merge(other) { for (const [b, c] of other.bins)
      bins.set(b, (bins.get(b) ?? 0) + c); },
    p(q) { const total = [...bins.values()].reduce((s, c) => s + c, 0);
      let acc = 0;
      for (const b of [...bins.keys()].sort((x, y) => x - y)) {
        acc += bins.get(b);
        if (acc >= total * q) return (b + 1) * binMs;
      } return Infinity; },
  };
}
const h = makeHist(); h.add(1200); h.add(800); h.add(3200);
console.log(h.p(0.75));  // -> 3250
```
