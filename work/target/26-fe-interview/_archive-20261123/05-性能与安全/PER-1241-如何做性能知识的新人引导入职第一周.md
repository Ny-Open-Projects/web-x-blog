## PER-1241：如何做"性能知识"的新人引导（入职第一周）

**答**：
- 路径：Day1 读口径字典+装调试工具；Day2 跑一次体检报告并读懂；Day3 修一个真实小问题（lint 命中项）；Day4 复盘汇报。
- 配套：沙箱仓库（内置 5 个典型问题）、导师制（第一个性能问题配 mentor）。
- 验收：独立完成一次"发现→归因→修复→验证"闭环。
- 目标：新人第 2 周起能独立处理 P2 性能问题。

```javascript
// 新人任务清单
const ONBOARD = [
  { day: 1, task: '读口径字典（1220）', done: '能说出 3 个核心指标定义' },
  { day: 2, task: '跑体检报告', done: '输出 3 个发现' },
  { day: 3, task: '修复 lint 命中项', done: 'PR 合并' },
  { day: 4, task: '闭环复盘', done: '5 分钟汇报' },
];
function onboardProgress(person) {
  return ONBOARD.map(t => ({ ...t,
    done: person.completed?.includes(t.day) }));
}
```
