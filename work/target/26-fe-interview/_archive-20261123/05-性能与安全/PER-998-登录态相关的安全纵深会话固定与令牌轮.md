## PER-998：登录态相关的安全纵深：会话固定与令牌轮换

**答**：
- 会话固定：登录前 URL/Storage 带来的 sessionId 登录后继续有效 → 攻击者预置 ID 劫持会话；登录成功必须重新签发会话。
- 令牌轮换：refresh token 一次性使用 + 检测重用（旧 token 再次使用即判定泄露，撤销整个令牌族）。
- 前端配合：登录流程不透传任何预置会话参数；检测到 401 之外的"会话重用"响应码时清空本地状态强制重登。
- 退出登录：前端清空 storage + 服务端吊销 refresh token，避免"退出后 token 仍可用"。

```javascript
// 令牌轮换客户端实现
async function refreshSession() {
  const r = await fetch('/token', { method: 'POST', credentials: 'include' });
  if (r.status === 409) {                     // 重用检测：令牌族已撤销
    clearLocalState();
    location.href = '/login?reason=reuse';
    throw new Error('session revoked');
  }
  const { token } = await r.json();
  auth.set(token);
  return token;
}
// 后端规则：refresh token 用后即弃；旧 token 复用 -> 全族吊销 + 409
```
