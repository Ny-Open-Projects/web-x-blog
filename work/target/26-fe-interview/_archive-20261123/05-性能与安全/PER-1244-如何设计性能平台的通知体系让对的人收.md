## PER-1244：如何设计"性能平台的通知体系"（让对的人收到对的信息）

**答**：
- 原则：通知按角色分发——Owner 收自己页面、平台收系统性问题、高管只收趋势与重大事件。
- 渠道：IM（即时告警）、周报邮件（趋势）、看板（自助）三级；电话仅 P0。
- 降噪：同一事件合并（937）、低优先级聚合为日报、静默已知问题。
- 度量：通知打开率、通知后行动率（开单/修复），低于 30% 的通知类型重新设计。

```javascript
// 通知路由
function routeNotification(evt, subs) {
  const targets = [];
  if (evt.sev === 'P0') targets.push({ role: 'oncall', channel: 'phone' });
  if (evt.scope === 'page') targets.push({ role: `owner:${evt.page}`, channel: 'im' });
  if (evt.scope === 'system') targets.push({ role: 'platform', channel: 'im' });
  if (evt.sev === 'trend') targets.push({ role: 'daily-digest', channel: 'email' });
  return targets.filter(t => subs[t.role]);
}
// 行动率统计：
function actionRate(sent, acted) { return +(acted / sent * 100).toFixed(1) + '%'; }
```
