## PER-740：移动端音频首播延迟优化：预加载策略、解码预热与 AudioContext 激活时机

**答**：
- 首播延迟链：点击 -> AudioContext 创建/恢复（用户手势要求）-> fetch 音频 -> 解码 -> 播放，各段都要预热：**AudioContext 提前创建**（首次任意手势时创建，iOS 限制必须手势内 resume）、**音频预取**（列表页 idle 预下载 + decode 存 ArrayBuffer）、**解码预热**（decodeAudioData 提前完成，播放时零解码）。
- 短音效场景用 WebAudio（AudioBufferSourceNode，延迟 < 50ms）；长音频用 `<audio>` + MediaSource 流式（不等全量下载）。
- 移动端坑：iOS 静音键与 WebAudio 无关（H5 控制不了）；后台播放被系统暂停要监听 visibilitychange 恢复；多音频同时解码内存暴涨（限制同时解码数量）。
- 度量：点击->出声延迟 p75、预取命中率、解码内存峰值。

```javascript

const audioLatency = {
  chain: '点击 -> AudioContext resume -> fetch -> decode -> 播放',
  prewarm: { ctx: '首次手势创建 AudioContext 并 resume', fetch: 'idle 预下载音频',
    decode: 'decodeAudioData 预解码存 ArrayBuffer' },
  choice: { sfx: '短音效 WebAudio < 50ms', long: '长音频 MSE 流式不等全量' },
  mobile: ['iOS 静音键 H5 无法控制', '后台暂停监听 visibilitychange 恢复',
    '限制同时解码数量防内存暴涨'],
};
class AudioPrewarmer {
  constructor() {
    this.ctx = null; this.buffers = new Map();
    addEventListener('pointerdown', () => this.ensureCtx(), { once: true });  // 手势内激活
  }
  ensureCtx() {
    this.ctx ??= new (window.AudioContext || webkitAudioContext)();
    this.ctx.resume();
  }
  async preload(url) {
    this.ensureCtx();
    if (this.buffers.has(url) || this.buffers.size >= 5) return; // 限流防内存暴涨
    const buf = await fetch(url).then(r => r.arrayBuffer());
    const decoded = await this.ctx.decodeAudioData(buf);        // 预解码
    this.buffers.set(url, decoded);
  }
  play(url) {                                                   // 零解码直播
    const src = this.ctx.createBufferSource();
    src.buffer = this.buffers.get(url);
    src.connect(this.ctx.destination);
    src.start();
  }
}
```
