## PER-1188：如何设计"最小可行数据"接口（响应瘦身）

**答**：
- 问题：接口返回全量对象，前端只用 3 个字段——过度暴露即过度采集。
- 实现：GraphQL 按需字段 / REST 字段参数（?fields=） / BFF 裁剪（1037）。
- 默认拒绝：接口默认只返回白名单字段，显式 expand 才给更多（且需权限）。
- 度量：响应对象字段使用率（前端实际消费的字段占比），低于 50% 的接口列入瘦身专项。

```javascript
// 接口字段使用率审计
function fieldUtilization(responses, consumed) {
  const all = new Set(responses.flatMap(r => Object.keys(r)));
  const used = new Set(consumed);
  return { fields: all.size, used: used.size,
    rate: +(used.size / all.size * 100).toFixed(1) + '%',
    trim: [...all].filter(f => !used.has(f)),
    action: used.size / all.size < 0.5 ? '列入瘦身专项（最小可行数据）' : 'ok' };
}
```
