## PER-947：性能平台如何应对指标爆炸？哪些指标该进核心看板

**答**：
- 核心三件套：LCP（加载）、INP（交互）、CLS（稳定）+ 业务定制一两个（如首屏接口完成率），其余进二级页面。
- 指标准入制：新指标上核心看板需评审——有明确业务含义、能行动、与现有指标低相关；相关系数 > 0.8 的重复指标不进。
- 生命周期：指标上线后季度复盘使用率，无人消费的指标下线，防止看板膨胀。
- 命名与口径统一：平台统一命名（禁止同一概念多个叫法），口径变更走 926 的流程。

```javascript
// 指标相关性去重
function corr(xs, ys) {
  const n = xs.length;
  const mx = xs.reduce((s, v) => s + v, 0) / n;
  const my = ys.reduce((s, v) => s + v, 0) / n;
  const cov = xs.reduce((s, v, i) => s + (v - mx) * (ys[i] - my), 0);
  const sd = Math.sqrt(xs.reduce((s, v) => s + (v - mx) ** 2, 0) *
                       ys.reduce((s, v) => s + (v - my) ** 2, 0));
  return cov / sd;
}
function dedupe(metrics, threshold = 0.8) {   // metrics: [{ id, series }]
  const kept = [];
  for (const m of metrics)
    if (!kept.some(k => Math.abs(corr(k.series, m.series)) > threshold))
      kept.push(m);
  return kept.map(k => k.id);
}
```
