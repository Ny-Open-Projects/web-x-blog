## MP-313：小程序存储体系：storage 限制与容量治理

**答**：
- 存储能力：wx.setStorageSync（单 key 1MB、总量 10MB）、文件系统（wx.env.USER_DATA_PATH，200MB）、CDN 云存储（大资源）——分级存储策略
- storage 的同步 API 阻塞：setStorageSync 大对象阻塞逻辑层——批量写用异步或拆分；「每次操作全量存」是性能反模式
- 容量治理：清理策略（LRU：浏览历史/草稿有上限与淘汰）、分域（配置类/缓存类/用户数据类 key 前缀）、监控（getStorageInfoSync 的 currentSize 接近 10MB 告警）
- 与 Web 的差异：无 IndexedDB（大数据用文件系统目录）、key 是扁平命名空间——前缀规范（module:key:field）模拟结构化
- 深水点：storage 的跨页面共享与生命周期——storage 持久（除非用户删除小程序），「上次会话数据恢复」是其价值；敏感数据（token）的清理时机

```javascript
// 分域 key 规范 + 容量监控
const NS = { cfg: 'cfg:', cache: 'cache:', user: 'user:' };
function safeSet(key, value) {
  const info = wx.getStorageInfoSync();
  if (info.currentSize > 8 * 1024) evictLRU(NS.cache);   // 接近上限先清缓存类
  try { wx.setStorageSync(key, value); }
  catch (e) { evictOldest(); wx.setStorageSync(key, value); }
}
// 大数据: 文件系统
const fs = wx.getFileSystemManager();
fs.writeFile({ filePath: `${wx.env.USER_DATA_PATH}/dataset.json`, data: JSON.stringify(big), encoding: 'utf8' });
```
