## FRP-273：React 迁移 Vue 的成本模型？
**答**：
- 成本项：学习曲线（3 人月/人）、组件重写（业务组件无自动转换）、状态层迁移（Redux→Pinia）、测试重写、招聘市场切换。
- 收益项：模板优化默认性能、生态一致性——但收益通常 < 迁移成本，除非有战略原因（被收购/平台统一）。
- 中间路线：微前端共存（新业务 Vue 旧业务 React）、共享层用 Web Components/纯 TS 核心包。
- 决策公式：Σ(迁移成本) vs Σ(收益×时间折现)，多数结果是不迁——「生态锁定」的理性面。
- 面试表达：迁移论证的关键是把「隐性成本」（协作摩擦、双栈维护）列全。
