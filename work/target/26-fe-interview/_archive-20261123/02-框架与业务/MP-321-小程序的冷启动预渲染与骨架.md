## MP-321：小程序冷启动：预渲染与骨架屏组合

**答**：
- initialRenderingCache：静态渲染缓存——页面「骨架结构」缓存到渲染层，冷启动先显示缓存骨架（数据仍要拉）；static/static+data 两档（data 档缓存上次数据）
- 组合拳：initialRenderingCache（骨架秒出）+ 上次数据缓存（wx.setStorageSync）+ 数据预取——冷启动「三段式」：骨架 → 缓存数据 → 最新数据
- 自定义骨架屏组件：CSS 骨架（shimmer）在 WXML 里预置——比 official skeleton 组件可控（按设计稿布局）
- 生效条件与坑：initialRenderingCache 只缓存「首次渲染的静态部分」（数据绑定部分不缓存）——动态结构不生效；导航栏标题/背景仍走系统渲染
- 度量：冷启动「可交互时间」（onReady 后首次可点击）——三段式各段的耗时拆解（缓存渲染 vs 网络等待）

```json
// page.json
{ "initialRenderingCache": "static" }
```

```javascript
// 三段式 onLoad
async onLoad() {
  const cached = wx.getStorageSync('home:cache');
  if (cached) { this.setData(cached); this._fromCache = true; }   // 段2: 立即渲染缓存
  const fresh = await api.home();
  this.setData(fresh);                                              // 段3: 最新数据
  wx.setStorageSync('home:cache', fresh);
}
```
