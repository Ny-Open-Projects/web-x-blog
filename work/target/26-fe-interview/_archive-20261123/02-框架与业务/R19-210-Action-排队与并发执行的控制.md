## R19-210：同一表单连续点击提交，Action 是排队还是并发？怎么控制？
**答**：
- React 对同一 action 的连续调用会**排队**（串行执行），保证前一次完成才开始下一次——不是并发丢失更新。
- 但 UI 上仍应禁用：isPending 期间 disable 按钮或隐藏表单，避免用户误以为点了两次发起了两次。
- 跨表单/跨 action 之间没有排队保证（各自独立），多字段联动更新要用单一 action 聚合。
- 服务端兜底幂等：requestId 去重（React 也会自动为 action 附带唯一 id，但不能依赖它做业务幂等）。
- 防双击的完整答案 = UI 层禁用（体验）+ 排队机制（框架）+ 服务端幂等（正确性），三层缺一不可。
