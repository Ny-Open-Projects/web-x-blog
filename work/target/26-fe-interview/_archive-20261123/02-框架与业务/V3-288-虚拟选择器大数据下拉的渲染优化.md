## V3-288：选择器（Select）大数据下拉的渲染优化怎么做？
**答**：
- 虚拟滚动：下拉面板万级 options 必须虚拟化（每项定高 32~40px），与表格虚拟化同原理；搜索过滤后重算偏移。
- 过滤策略：前端过滤用**前缀索引/分词索引**（万级内可接受），超过 10 万条转服务端搜索（防抖 300ms + 竞态取消）。
- 选中回显：大 options 里找 label 用 Map 索引（value→option），不要数组 find（选中回显 O(1)）。
- 多选优化：tag 列表超过 N 个折叠为 +M；全选用"选择过滤结果"语义；值集用 Set 存储，勾选判断 O(1)。
- 交互细节：键盘上下键跨虚拟窗口滚动（scrollIntoView 指定块）、打开面板保持上次滚动位置、远程搜索 loading 态。

```typescript
const optionMap = new Map(options.map((o) => [o.value, o]));  // O(1) 回显
const filtered = computed(() => {
  if (!keyword.value) return options.value;
  const kw = keyword.value.toLowerCase();
  return options.value.filter((o) => o.label.toLowerCase().includes(kw) || o.pinyin?.includes(kw));
});
// 虚拟面板：定高 36
const { list, containerProps, wrapperProps } = useVirtualList(filtered, 36);
// 键盘导航跨窗口
function onKeyDown(e) {
  if (e.key === 'ArrowDown') { activeIndex.value = Math.min(activeIndex.value + 1, filtered.value.length - 1);
    scrollToIndex(activeIndex.value); }
}
```
