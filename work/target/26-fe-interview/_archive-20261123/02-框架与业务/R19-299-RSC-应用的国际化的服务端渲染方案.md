## R19-299：RSC 应用的国际化方案？
**答**：
- locale 来源：URL 前缀（/en/...，利于 SEO）> cookie > Accept-Language 头——按优先级取。
- 服务端组件：直接读 locale 取词典渲染，无 hydration 成本；客户端组件：词典通过 props/RSC payload 下发或按需 fetch。
- next-intl 模式：Next 整合 request config（每个请求独立 locale 实例），server/client 统一 API。
- 复数/日期/货币用 Intl API（服务端 Node full-icu 与浏览器一致）。
- 缓存注意：locale 是 payload 缓存 key 的一部分（不同语言不同缓存条目）。
