## V3-389：SSR 的骨架与部分注水（partial hydration）策略是什么？
**答**：
- 现状：Vue SSR 默认整树水合；部分注水思路是「静态区域不水合，只有交互岛执行 JS」。
- 实现路径：Nuxt componentIslands（server-only / static 组件跳过客户端实例化）+ 客户端岛（client: only/visible 按需水合，参考 Astro 模型）。
- 配套：静态内容用 server 组件渲染、交互组件用 Island 组件，岛内才能用响应式/事件。
- 收益：大页面 JS 执行量骤减（水合时间与岛数量成正比而非 DOM 数量），INP 改善。
- 限制：岛间通信只能走 props/事件/全局 store；跨岛状态要谨慎设计，避免退化成全页 store 依赖。
