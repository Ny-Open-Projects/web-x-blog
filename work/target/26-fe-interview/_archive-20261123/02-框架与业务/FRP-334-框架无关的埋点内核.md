## FRP-334：框架无关的埋点内核

**答**：
- 内核分层：采集（事件归一化——click/expose/pv 统一 schema）、缓冲（批量队列 + pagehide flush）、传输（sendBeacon/fetch keepalive）——全部框架无关
- 框架层贡献的上下文：组件名/路由（各框架 hook 注入）——内核 schema 预留 context 字段，框架层填充
- 曝光埋点的框架无关实现：IntersectionObserver 内核 + 「目标元素注册协议」——框架层只负责把 ref 给内核
- 性能红线统一：批量/上限/丢弃计数（各框架同策略）——埋点不能拖垮业务
- SPA 路由 PV：内核监听 history patch（FRP-310 同机制）——「框架路由变化 → 内核 PV 事件」自动化

```javascript
// 内核
export const tracker = createTracker({
  schema: { event: 'string', props: 'object', context: 'object' },
  flush: { windowMs: 5000, maxSize: 20 },
});
// 框架层: React
useEffect(() => tracker.context({ route: location.pathname }));
// Vue: watch(() => route.path, (p) => tracker.context({ route: p }));
// 曝光: tracker.expose(el, { slotId })   ← IO 内核, 传 ref 即可
```
