## FRP-355：跨框架渲染中的样式注入时机

**答**：
- 注入时机光谱：全量 link（构建时确定，FOUC 风险）、按 chunk 注入（import css 随组件）、运行时 CSSOM（组件库 insertRule）、shadow adoptedStyleSheets——跨框架组件库的注入策略统一
- 双框架组件的样式冲突面：同 class 名（两个壳加载同一 CSS 无冲突，共享是正解）vs 各自 scoped（选择器不同但样式重复）——「共享一份 CSS」是体积正解
- SSR 注入：样式从流式 HTML 输出（framework CSS 提取）——cross-origin style 注入的 CSP 约束（style-src nonce）
- 卸载策略：组件卸载时样式是否移除——不移除（缓存命中）+ 全局去重 Map——「注入即注册」的幂等协议
- 深水点：CSS 加载顺序与优先级（两框架 CSS 的 @layer 分区）——跨框架样式分层防互覆

```javascript
// 幂等注入内核
const injected = new Set();
export function injectStyle(id, css) {
  if (injected.has(id)) return;                       // 幂等
  const sheet = new CSSStyleSheet();
  sheet.replaceSync(css);
  document.adoptedStyleSheets = [...document.adoptedStyleSheets, sheet];
  injected.add(id);
}
// 组件卸载不移除 (缓存命中 + 去重)
// 分层: @layer react-ui, vue-ui; → 优先级显式化
```
