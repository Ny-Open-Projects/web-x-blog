## FRP-308：响应式内核的一致性协议：signal 库的通用接口

**答**：
- signal 通用协议三件套：signal(value)（读写）、effect(fn)（副作用订阅）、computed(fn)（派生缓存）——Solid/Preact Signals/Vue ref 语义高度同构
- 一致性保证的关键设计：「读取时订阅」（读 signal 自动 track，无需手动 deps）+ 「批量传播」（同一同步块内多次写合并一次通知）——各库实现差异点在批处理时机
- Vue ref 与 signal 的互通：@vue/reactivity 可脱离组件独立使用——Vue 的响应式内核本身就是 signal 库（可当跨框架内核）
- 传播图与内存：依赖图（DAG）在「动态分支」下的重连——依赖清理（computed 重算时解除旧依赖）是正确性核心（V3-526 手写题）
- 标准演化：TC39 Signals 提案——标准化后框架适配层趋同，跨框架状态真内核

```javascript
// Vue reactivity 作为跨框架内核
import { ref, computed, effect, watch } from '@vue/reactivity';
const count = ref(0);
const double = computed(() => count.value * 2);
effect(() => console.log(double.value));       // 任何框架都可订阅
// Solid/Preact signals 同构: signal/computed/effect
```
