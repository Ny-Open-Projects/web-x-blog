## V3-482：大表单场景的 Vue 性能：细粒度绑定策略

**答**：
- 场景特征：表单字段 50~200 个、字段间有联动校验——「改一个字段全表单重渲」是大表单卡顿根因
- 细粒度绑定：每个字段块拆成子组件（props 只传该字段值 + 校验状态），form 对象用 reactive 但传递用 toRef——字段更新只重渲该字段块
- 校验链路解耦：校验结果独立 reactive map（fieldErrors），错误展示组件只依赖自己 field 的 entry——校验重算不牵连输入组件
- 联动计算：字段联动用 computed（如总额 = 明细求和）保持依赖精确；跨字段规则（密码确认）放字段块内部 computed
- 提交与脏检查：dirty 标记用版本号（每次编辑递增）而不是 deep watch 比对——提交时按版本判断 + 按字段 diff 发送变更项

```vue
<FieldBlock :value="toRef(form, 'email')" :error="fieldErrors.email" @update="v => form.email = v" />
<!-- 只有 email 变更会重渲 FieldBlock, 其余 200 个字段块不动 -->
<script setup>
const fieldErrors = reactive({});   // 校验结果独立
watchEffect(() => validateField(form.email).then(e => fieldErrors.email = e));
</script>
```
