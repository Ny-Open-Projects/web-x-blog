## MP-326：小程序的内存管理与后台存活

**答**：
- 存活模型：小程序切后台 5 分钟（安卓）/即时（iOS 内存压力）可能被杀——「onHide 清理重资源」是延长存活的关键
- 重资源清单：大 canvas、video 实例、WebSocket 之外的长连接、音频播放器——onHide 时 destroy/pause，onShow 恢复
- wx.onMemoryWarning：iOS 内存告警（level 分级）——收到告警主动释放缓存/重资源（「被杀预防」而非「被杀处理」）
- 状态恢复：被杀后冷启动——「关键状态持久化」（onHide 时写 storage）+ 启动恢复（onLoad 读回）——「无缝续用」的体验设计
- 深水点：后台运行的例外——音频后台播放（requiredBackgroundModes: audio）、直播推流——白名单能力才可后台存活；普通小程序 onShow 即「复活」

```javascript
Page({
  onHide() {
    this.videoCtx?.pause();
    ws.suspend();                                    // 连接挂起(不销毁, 保留状态)
    wx.setStorageSync('draft', this.data.form);      // 状态持久化
  },
  onShow() {
    ws.resume();
    const draft = wx.getStorageSync('draft');
    draft && this.setData({ form: draft });          // 被杀重启后恢复
  },
});
App({ onMemoryWarning(({ level }) => { level > 10 && releaseHeavyResources(); }) });
```
