## MP-342：小程序动画体系：CSS 动画、WXS 跟手与 worklet

**答**：
- 三层动画能力：CSS animation/transition（声明式、渲染层直接跑）、WXS 响应事件（跟手交互——touchmove 驱动样式）、Skyline worklet（新一代渲染线程动画）
- 跟手交互的架构约束：touchmove 在渲染层、数据在逻辑层——setData 跟手必然掉帧——「WXS 函数响应 touch 事件」（wxs module 的 touchmove 处理器）是 WebView 时代唯一跟手方案
- CSS 动画的触发：animation 属性 + 数据驱动类切换（setData 改 class）——复杂编排（序列动画）用 CSS 变量 + 多段 keyframes
- 动画与列表：列表项入场动画（IntersectionObserver 触发 class）——批量动画的性能（分批触发 + CSS 优先）
- 深水点：WXS 的能力边界（无 wx API/无 DOM——只能操作传入的 state）——「WXS 状态与逻辑层状态同步」的设计（单向：渲染层自持动画态）

```xml
<!-- WXS 跟手拖拽 -->
<wxs module="drag" src="./drag.wxs" />
<view class="card" style="{{drag.transform(state)}}" bindtouchstart="{{drag.start}}" bindtouchmove="{{drag.move}}" bindtouchend="{{drag.end}}" />
<!-- drag.wxs: touchmove 里直接计算 transform 返回 — 渲染层同线程, 跟手 -->
```
