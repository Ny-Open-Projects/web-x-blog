## FRP-349：跨框架按需加载策略

**答**：
- 加载单元的选择：路由级（两个框架各自 chunk）、组件级（壳组件独立 chunk）、内核共享 chunk（始终加载）——按「使用频率 × 体积」排优先级
- 双框架 runtime 的体积叠加：React + Vue 同时在页面 ≈ 80KB runtime——跨框架页面的成本现实；缓解「页面级隔离」（一个页面尽量单框架）或 MF 共享
- 预加载策略：内核 + 当前框架 runtime preload；另一框架按路由预测预取（空闲期）——跨框架导航的预加载矩阵
- 加载失败降级：壳组件 chunk 失败 → 重试 + 降级占位——动态 import 的错误边界
- 度量：跨框架页面的 TTI（双 runtime 加载完成）vs 单框架页面——「混用成本」量化进架构决策

```text
加载策略矩阵:
  始终: 内核 chunk (状态/工具)
  路由级: 各框架页面 chunk (懒)
  空闲预取: 另一框架 runtime (按导航概率)
  混用页面成本: React 45K + Vue 34K ≈ 80K runtime
  缓解: MF 共享 / 页面级单框架隔离
```
