## FRP-324：框架运行时剖析：运行时体积构成与 tree-shaking 边界

**答**：
- 运行时体积构成：调度器（React Scheduler/Vue scheduler）、渲染器（vdom diff / 编译产物运行时）、响应式内核、内置组件（Suspense/Transition）——React ~45KB、Vue3 ~34KB、Solid ~8KB、Svelte4 ~2KB/组件
- tree-shaking 边界：React 的 reconciler 单体导出（难摇）、Vue 的编译器运行时可选（预编译后摇掉 compiler-core）、Solid/Svelte 按组件编译（天然摇）
- 按需能力：Vue 可选 vdom（Vapor 去掉）、React 不可拆（架构耦合）、Qwik 按 handler 加载（最激进）
- 体积与功能的交换：runtime 小 → 编译产物大/心智成本高（Svelte4）；runtime 大 → 产物小、语义统一（React）——没有免费午餐
- 度量方法：bundle 分析（source-map-explorer 按模块）+ 「移除一个页面看 runtime 减多少」——摇不动的部分量化

```text
runtime 体积(gzip, 近似):
  React 18:  ~45KB (reconciler+scheduler 单体)
  Vue3:      ~34KB (可去 compiler-core)
  Solid:     ~8KB
  Svelte4:   ~2KB/组件 (运行时嵌在产物)
  Qwik:      ~1KB (按需加载 handler)
```
