## FRP-342：跨框架的构建配置统一

**答**：
- 统一构建栈：Vite 作为多框架统一底座（react/vue/solid 插件同仓）——构建配置的公共层（alias/postcss/压缩）与框架层（插件）分离
- Monorepo 结构：packages/{core,ui-react,ui-vue,app-react,app-vue}——内核与壳的依赖方向单向（壳依赖 core）
- 一致性保障：tsconfig base + eslint 统一（框架规则按目录覆盖）+ browserslist 单源——「构建行为一致性」的基建
- 产物协议统一：各包输出 ESM + d.ts（exports map）——跨包引用的类型与运行时一致
- 深水点：不同框架的 HMR 边界——Vite 对 react-refresh/vue-hmr 各自处理；混用页面（一个入口两框架）的 HMR 冲突调试

```text
Monorepo 拓扑:
  packages/core        (内核: 状态/工具/类型 — 无框架)
  packages/ui-react    (React 壳 → core)
  packages/ui-vue      (Vue 壳 → core)
  apps/*               (应用 → 壳)
依赖方向: 单向 (app → ui → core)
构建: vite + 框架插件, 公共配置层抽出
```
