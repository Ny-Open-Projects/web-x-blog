## V3-499：Vue3 应用的健康度指标体系

**答**：
- 框架特有指标：组件渲染耗时分布（慢组件 top）、更新触发源分布（哪个状态变更引起最多更新）、effect 数量/组件（副作用密度）、内存中存活组件实例数（泄漏信号）
- 采集手段：app.config.performance 开启 devtools 时间线（开发期）；生产用轻量探针——路由 hook 计时 + 采样 mark（performance.mark/measure 自定义帧）
- 与通用指标融合：Web Vitals（LCP/INP/CLS）按路由维度聚合 + 框架指标（组件耗时）交叉——「INP 差的页面 → 找该页面慢组件」的归因链
- 错误维度：errorHandler 上报按「组件名 × 错误指纹」聚合，附操作轨迹——Vue 组件名是天然的归因维度
- 看板设计：路由 × 版本 × 机型三维度，核心指标 P75 趋势 + 劣化自动标注（发版时间线叠加）

```javascript
// 轻量生产探针
router.afterEach((to, from) => {
  const t = performance.now();
  requestAnimationFrame(() => {
    beacon({ route: to.path, switchMs: +(performance.now() - t).toFixed(1) });
  });
});
// 组件采样(10%)
if (Math.random() < 0.1) performance.mark(`mount:${name}`);
```
