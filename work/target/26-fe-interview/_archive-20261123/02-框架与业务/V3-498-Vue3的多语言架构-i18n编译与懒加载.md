## V3-498：Vue3 的多语言架构：i18n 编译优化与懒加载

**答**：
- 消息加载策略：按语言分包懒加载（locale 动态 import）+ 公共包（组件库文案）合并——切换语言 = 异步加载 + vue-i18n setLocale（等待 loading 态）
- 编译期优化：vue-i18n 的编译器把 `$t('key')` 预编译为消息 AST（运行时免解析）；生产环境用 runtime-only 版（省编译器体积）
- 性能细节：翻译函数在高频列表里每条调用——消息 lookup 是 Map 查询很快，但插值拼接 GC 有成本——长列表静态文案预渲染或缓存插值结果
- 键治理：命名空间分层（模块.页面.键）+ CI 检查（未使用键/缺失键/硬编码中文扫描）——i18n 债的预防靠工具不是自觉
- RTL 与复数：逻辑属性布局 + i18n plural 规则（阿拉伯语 6 种复数形式）——国际化不仅是翻译，布局与语义都要适配

```javascript
// 语言包懒加载
const locales = {
  en: () => import('./locales/en.json'),
  ar: () => import('./locales/ar.json'),   // RTL 语言
};
async function setLocale(lang) {
  loading.value = true;
  const msgs = await locales[lang]();
  i18n.setLocaleMessage(lang, msgs.default);
  i18n.locale.value = lang;
  document.documentElement.dir = lang === 'ar' ? 'rtl' : 'ltr';
  loading.value = false;
}
```
