## MP-100：一套完整的"小程序面试复盘"知识图谱怎么串？
**答**：
- 主线：**双线程模型是根因**——setData 通信 → 数据优化 → 性能；native 管控 → 包体/审核/合规。
- 副线一：页面栈路由 → 生命周期 → 通信方式 → 状态管理。
- 副线二：组件体系 → 样式隔离 → 分包加载 → 原生组件同层。
- 工程线：Taro/uni-app 运行时原理 → npm/CI/自动化测试 → 监控与灰度。面试时能按"原理→限制→优化→验证"四段式回答即为高分结构。
