## R19-283：客户端组件为什么不能 import 服务端组件？
**答**：
- 本质：import 是「在客户端运行该模块」——服务端组件的代码（DB 调用、密钥）不该也无法进客户端 bundle。
- 服务端组件的存在形式是「渲染产物（Flight 树）」而非模块，客户端拿到的只有结果。
- 组合模式：客户端组件用 children 接收服务端组件渲染好的部分（在服务端渲染完成后作为 props 传入）。
- 场景示例：Tabs（client）包裹服务端渲染的面板内容——面板作为 children 传进去。
- Server Actions 是例外：它们是「客户端可引用的服务端函数」，通过加密 id 调用，代码仍不上行。
