## MP-335：小程序虚拟列表：长列表的渲染层约束

**答**：
- 约束差异：无 scroll 事件节流的 DOM 感知（offsetTop 不可用）——布局计算靠 boundingClientRect（异步跨线程）——「异步测量」改变虚拟列表实现
- 方案：官方 recycle-view 组件（npm）——固定高度池复用；或自研「分页池」——只渲染可视区 ±N，用 scroll-view 的 scroll 事件 + 缓存高度估算
- 定高 vs 不定高：定高公式直算（offset = i × h）；不定高用「测量缓存 + 预估」——测量异步（SelectorQuery.boundingClientRect）需要批量化（一次查可见区全部）
- 数据面优化：万级数据的 setData 量控制——只 setData 可见区数据（`list.slice(start, end)` 渲染 + 占位 spacer 高度撑滚动条）
- 深水点：scroll-view 的增强属性（enhanced + fast-deceleration）与 bounces 关闭——滚动体验与虚拟列表的配合

```javascript
// 分页池虚拟列表核心
async function onScroll(e) {
  const { scrollTop, scrollHeight } = e.detail;
  const start = Math.max(0, Math.floor(scrollTop / EST_H) - 5);
  const end = start + Math.ceil(VIEW_H / EST_H) + 10;
  if (start !== this._start) {
    this._start = start;
    // 批量测量修正(异步)
    const rects = await this.measureRange(start, end);
    rects.forEach((r, i) => this._hCache[start + i] = r.height);
    this.setData({ slice: this._data.slice(start, end), offsetTop: start * EST_H });
  }
}
// <scroll-view enhanced><view style="height:{{totalH}}px"><view style="transform:translateY({{offsetTop}}px)">...</view></view></scroll-view>
```
