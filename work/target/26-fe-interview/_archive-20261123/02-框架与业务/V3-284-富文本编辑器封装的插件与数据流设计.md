## V3-284：富文本编辑器封装：插件机制与数据流怎么设计？
**答**：
- 数据流单源：编辑器内部状态（wangEditor/tiptap 实例）为源，Vue 侧经 watch 深度节流同步到 v-model（`update:modelValue`），**反向**只在内容 hash 不一致时 setHtml，避免光标跳动。
- 插件机制：编辑器能力（@提及/表格/代码块/自定义粘贴清洗）按插件注册（tiptap 的 extension / wangEditor 的 menu 配置），Vue 封装层暴露 `plugins` prop 注入。
- 粘贴清洗：外部粘贴富文本（Word/网页）统一走 sanitize 管道（白名单标签 + 图片转存 OSS），防样式污染与 XSS。
- 图片上传：编辑器菜单回调接自定义上传（凭证从后端拿、OSS 直传、失败占位可重试）。
- 销毁与重建：路由离开/组件卸载必须 destroy 实例（防内存泄漏）；SSR 下编辑器 ClientOnly。

```vue
<script setup>
const props = defineProps({ modelValue: String, plugins: { type: Array, default: () => [] } });
const emit = defineEmits(['update:modelValue']);
const editorRef = ref(null);
let syncing = false;
function onChange(editor) {
  if (syncing) return;
  const html = sanitize(editor.getHtml());
  emit('update:modelValue', html);          // 内部 → 外部（节流 300ms）
}
watch(() => props.modelValue, (val) => {    // 外部 → 内部（hash 比对防光标跳）
  if (editorRef.value && hash(editorRef.value.getHtml()) !== hash(val ?? '')) {
    syncing = true;
    editorRef.value.setHtml(val ?? '');
    syncing = false;
  }
}, { deep: false });
onMounted(() => createEditor({ selector: editorRef.value, plugins: props.plugins, onChange }));
onBeforeUnmount(() => editorRef.value?.destroy?.()); // 必须销毁
</script>
```
