## V3-527：笔试：手写动态表单引擎

**题目**：实现 `SchemaForm` 组件：① props: schema（字段数组）、modelValue；② 字段类型映射组件注册表（text/select/number/自定义）；③ visibleWhen/disabledWhen 函数式联动（读 form 触发响应式）；④ 校验：rules 触发防抖异步校验，错误独立 map；⑤ emit('update:modelValue') 整表提交与按字段 emit。写出核心实现（含引擎与一个字段渲染）。

```vue
<script setup>
import { computed, reactive } from 'vue';

const props = defineProps({ schema: Array, modelValue: Object });
const emit = defineEmits(['update:modelValue']);
const REGISTRY = { text: TextField, select: SelectField };   // 可扩展注册表

const visibleFields = computed(() =>
  props.schema.filter(f => f.visibleWhen?.(props.modelValue) ?? true));

const errors = reactive({});      // 错误独立存储
const validators = new Map();     // 字段 -> 防抖定时器

function onFieldChange(name, value) {
  emit('update:modelValue', { ...props.modelValue, [name]: value });
  scheduleValidate(name, value);
}
function scheduleValidate(name, value) {
  clearTimeout(validators.get(name));
  validators.set(name, setTimeout(async () => {
    const field = props.schema.find(f => f.name === name);
    for (const rule of field.rules ?? []) {
      const msg = await rule(value, props.modelValue);
      if (msg) { errors[name] = msg; return; }
    }
    delete errors[name];
  }, 300));
}
</script>

<template>
  <form @submit.prevent="$emit('submit', modelValue)">
    <template v-for="f in visibleFields" :key="f.name">
      <component
        :is="f.component ?? REGISTRY[f.type]"
        :model-value="modelValue[f.name]"
        :label="f.label"
        :error="errors[f.name]"
        :disabled="f.disabledWhen?.(modelValue) ?? false"
        @update:model-value="v => onFieldChange(f.name, v)"
      />
    </template>
  </form>
</template>
```

**评分点**：
- 注册表 + 动态 component 渲染（类型可扩展）
- visibleWhen 函数式求值自动响应（读 modelValue 即追踪）
- 错误独立 reactive map（校验不牵连输入组件）
- 防抖校验 + 按字段 emit
