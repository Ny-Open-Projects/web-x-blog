## R19-408：并发渲染边界：并发特性对可访问性的影响

**答**：
- 焦点与打断：Transition 中断重渲染——焦点元素若被「丢弃的渲染」移除，焦点丢到 body——焦点保持策略：key 稳定 + transition 范围避开焦点容器
- 读屏与 pending 状态：aria-live 通知「内容已更新」要在 commit 后（useEffect）——transition 中途不播报（避免播报旧数据又播新数据）
- fallback 的语义：Suspense fallback 要有 aria-busy/loading 角色——读屏用户需要知道「在加载」而不是「内容消失」
- 乐观更新与读屏：乐观值变化也触发 aria 更新（双播报）——乐观期间用 aria-busy 抑制中间播报
- 测试：axe + 键盘走查在并发场景（快速操作中焦点不丢失）——并发下的 a11y 是新回归面

```jsx
const [isPending, start] = useTransition();
<div aria-busy={isPending} aria-live="polite">   {/* pending 抑制中间播报 */}
  {isPending ? <Spinner /> : <Results />}
</div>
```
