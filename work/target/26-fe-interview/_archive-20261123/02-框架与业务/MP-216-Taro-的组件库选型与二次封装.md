## MP-216：Taro 组件库选型与二次封装？
**答**：
- 候选：Taro UI（官方，多端覆盖全）、NutUI（京东，React/Vue 双栈质量高）、Vant Weapp（原生）+ 混用。
- 选型判据：多端覆盖（目标平台矩阵）、React/Vue 栈匹配、维护活跃度、样式定制能力。
- 二次封装原则：业务组件包一层（统一埋点/主题/校验），不直接散用库组件；跨端差异在封装层收敛。
- 按需引入与体积：库的 tree-shaking 支持（NutUI ESM）。
- 混用风险：两套组件库样式冲突——全局 token 统一 + css 前缀隔离。
