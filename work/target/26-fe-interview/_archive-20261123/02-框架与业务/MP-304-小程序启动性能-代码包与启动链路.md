## MP-304：小程序启动性能：代码包与启动链路优化

**答**：
- 启动链路：下载代码包 → 创建运行环境 → app.js 执行 → 首页渲染——每段都有优化点
- 代码包优化：主包 <2MB 预算、分包（subpackages 按业务域）、独立分包（登录/活动页不依赖主包启动更快）、分包预下载（preloadRule 用户路径预测）
- 按需注入：lazyCodeLoading: 'requiredComponents'——只注入当前页所需组件代码（默认全量注入 app 所有组件），启动 JS 执行时间显著下降
- 启动数据预取：cold start 时「入口参数预取」（wx.getLaunchOptionsSync 的场景值预判 + 提前请求首屏数据）
- 骨架屏：skeleton 组件/initialRenderingCache——首屏数据到达前的占位（体验优化）+ 数据缓存（wx.setStorageSync 上次首屏数据立即渲染）

```json
// app.json 关键配置
{ "lazyCodeLoading": "requiredComponents",
  "subpackages": [{ "root": "order", "pages": ["list", "detail"] }],
  "preloadRule": { "pages/index": { "network": "all", "packages": ["order"] } },
  "initialRenderingCache": "static" }
// 启动数据: 上次首屏数据缓存 → onLaunch 立即 setData → 网络刷新
```
