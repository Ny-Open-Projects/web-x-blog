## FRP-253：React 为什么选择 VDOM？
**答**：
- 设计目标优先级：可预测的心智模型 + 函数式组合 + 跨平台渲染——VDOM 是「声明式 UI 到任意渲染端」的统一中间表示。
- 细粒度响应式与 JSX 的自由表达冲突：任意 JS 表达式无法静态定位依赖，细粒度订阅需要显式 signal（改变 JSX 心智）。
- VDOM 允许「整函数重放」的简单模型：状态→UI 是纯映射，并发特性（可中断）建立在此模型上。
- 代价：重渲染开销 → 用 memo/Compiler/虚拟化补偿——React 的赌注是「简单模型 + 工程补偿」。
- 面试表达：不是 React 不知道细粒度更快，而是「模型简单性 > 微观性能」的架构取舍。
