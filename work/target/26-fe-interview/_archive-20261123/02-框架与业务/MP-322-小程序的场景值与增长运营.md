## MP-322：小程序场景值与增长运营：入口识别与归因

**答**：
- 场景值体系：wx.getLaunchOptionsSync / onAppRoute 的 scene（扫码 1047、群分享 1044、搜索 1089 等）——入口识别驱动「差异化落地」（扫码直达活动页 vs 分享进首页）
- 分享链路设计：onShareAppMessage 的 path 参数携带分享者/活动标识（inviter=xx&act=yy）——落地页解析归因（邀请关系绑定）
- 小程序码：wxacode.getUnlimited（服务端生成，scene 参数 32 字符限制）——scene 携带业务参数（活动 id 压缩编码），扫码进指定页面
- 归因埋点：launch 的 scene + query 上报（首访归因）+ 转化链路（分享 → 打开 → 注册 → 下单）——增长漏斗的埋点设计
- 深水点：热启动与冷启动的场景差异——热启动 onLaunch 不触发（只有 onShow）；「每次进入都刷新场景」用 onShow 的 options（scene 可能变化——从群聊再次点入）

```javascript
App({
  onLaunch(opts) { this.trackLaunch(opts); },        // 冷启动: scene + query
  onShow(opts) { this.trackScene(opts); },           // 热启动也要记 (场景可能变)
});
// 分享:
onShareAppMessage() {
  return { title: '帮我砍一刀', path: `/pages/kill/index?inviter=${this.uid}&act=42` };
}
// 落地页解析: scene=1044(群分享) & query.inviter → 归因绑定
```
