## R19-385：React19 迁移清单：从 18 到 19 的实际工作

**答**：
- 类型层面：useRef 需要「必传初始值」（ref(null) 写法变化）、ref prop 直传（forwardRef 逐步退役）、ref 回调 cleanup 语义——codemod（npx codemod react/19/...）自动化大半
- 行为变化：hydration 错误处理改进（diff 输出）、`useMemo/useCallback` 语义在 Compiler 下的退化、Suspense fallback 节流——「静默行为变化」的回归测试清单
- 新能力启用决策：form actions/useActionState（表单页收益大）、use 指令（数据流改造）、Server Functions（需要全栈框架支持）——逐特性评估不是全开
- 依赖兼容矩阵：React Query/zustand/测试库（testing-library v16）的 React19 peer 版本——升级顺序「测试库先行」保证验证能力
- 上线策略：灰度 + React Profiler 前后对比 + hydration 错误率监控——19 的行为变化靠数据收口

```text
迁移顺序:
  1. 升级依赖矩阵(testing-lib → react 19 peer)
  2. codemod: ref 语义 / forwardRef 清理
  3. hydration/错误率监控上线
  4. 灰度: 表单页先吃 form actions
  5. 全量 + Compiler 评估(独立开关)
```
