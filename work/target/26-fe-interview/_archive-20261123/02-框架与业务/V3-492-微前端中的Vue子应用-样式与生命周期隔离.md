## V3-492：微前端中的 Vue 子应用：样式与生命周期隔离

**答**：
- 样式隔离三方案：Shadow DOM（强隔离但全局样式/弹出层麻烦）、CSS Modules + 前缀约定（弱隔离零成本）、运行时 scoped 重写（qiankun 实验性 strictStyleIsolation 之外的 scoped 方案）——中后台常用「前缀 + scoping 类」折中
- JS 沙箱：Proxy window 快照沙箱（qiankun legacySandbox）——Vue app 的副作用（定时器/全局事件）要在 unmount 时清理，沙箱不兜底所有泄漏
- 生命周期契约：子应用导出 bootstrap/mount/unmount——Vue 对应 createApp/mount/unmount；路由实例、Pinia 都要在 unmount 中销毁（复用挂载时重建）——「子应用重复挂载状态残留」的根源
- 公共依赖共享：externals + 主应用提供（Vue/Pinia 单例）——版本升级协调是多团队痛点；组件库版本可以各自独立
- 路由同步：子应用路由 base 注入 + 主子路由同步（qiankun 的 activeRule）——历史模式必须配 base，hash 模式天然隔离

```javascript
// 子应用入口
let app;
export async function mount(props) {
  app = createApp(App);
  app.use(createPinia());
  app.use(routerFactory(props.base));
  app.mount(props.container);
}
export async function unmount() {
  app.unmount();
  app = null;                                  // 实例与路由/状态全部重建
}
```
