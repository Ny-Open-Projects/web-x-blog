## MP-317：小程序媒体能力：图片、视频与录制的性能面

**答**：
- 图片加载优化：image 组件的 lazy-load、mode 裁剪（aspectFill 防变形）、CDN 参数（?imageView2 缩放）——小程序无 <picture>，服务端格式协商（webp Accept）
- 视频组件的性能红线：video 是原生组件（层级最高，同层渲染解决）——同屏 video 数量控制（≤4 个，多余的 destroy）、autoplay 滥用（每个 video 一个解码器）
- 同层渲染：native-components 同层（video/live-player 嵌入视图树）——「层级穿透」解决后仍要注意真机兼容差异（部分安卓机型失效回退）
- 录制与压缩：wx.chooseMedia（拍摄/相册统一入口，sizeType compressed）、wx.compressVideo——上传前压缩（带宽与成功率双赢）
- 深水点：图片「先低清后高清」的两段式加载——缩略图立即渲染 + 高清图 onload 后替换；video 的 poster 占位防黑屏

```javascript
// video 性能治理: 视口外销毁
onPageScroll() { /* 或 IO observer */ }
// 用 IntersectionObserver (小程序版):
this._io = wx.createIntersectionObserver(this).relativeToViewport({ top: 400, bottom: 400 });
this._io.observe('.video-item', (res) => {
  const id = res.dataset.id;
  const active = res.intersectionRatio > 0;
  this.setData({ [`videos[${id}].src`]: active ? this.data.videos[id].realSrc : '' }); // 离屏释放解码器
});
// 图片两段式: <image src="{{thumb}}" binderror="retryHd" /> + onload 后 setData 高清
```
