## MP-327：小程序组件库设计：按需与体积治理

**答**：
- 组件引用机制：页面 json 的 usingComponents 显式声明（路径引用）——天然按需（不用即不打包进该页）；npm 组件（miniprogram_npm 构建）同理
- 全局组件 vs 按需：app.json 全局 usingComponents 方便但「全量注入」（配合 lazyCodeLoading: requiredComponents 缓解——运行时只注入用到的）
- 组件库体积治理：样式独立（组件 wxss 按需）、工具函数打包进组件（避免主包重复）、图片走 CDN 不进包
- 双平台兼容设计：组件库要兼容 Skyline 与 WebView——条件渲染（skyline 属性检测）+ 降级样式
- 深水点：usingComponents 的路径别名（npm 构建后的 miniprogram_npm 解析）——packNpm/构建 npm 的 CI 集成与版本锁定

```json
// app.json
{ "lazyCodeLoading": "requiredComponents",
  "usingComponents": { "tag": "@acme/ui/tag/index" } }   // 全局声明 + 按需注入
// 构建集成: package.json { "packNpmManually": true, "packNpmRelationList": [...] }
// CI: miniprogram-ci pack-npm + 体积检查
```
