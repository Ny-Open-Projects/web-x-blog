## FRP-323：框架无关的权限内核

**答**：
- 内核模型：权限点集合（Set<string>）+ 判定函数（has/hasAny/hasAll）+ 角色到权限点的映射（可服务端下发）——纯数据结构无框架
- 判定语义分级：has（单点）、hasAny（任一）、hasAll（全部）、match（通配符 'order:*'）——业务常混用，协议要显式
- 动态权限：登录/切换租户时权限集变更 → 内核通知订阅者（框架层重渲染权限相关 UI）——响应式封装在适配层
- 与路由/组件/指令的对接：各框架的守卫/指令/组件都消费同一 has()——「三处实现一处判定」
- 审计与测试：权限矩阵快照测试（角色 × 权限点表）——内核层可 100% 单测（无框架依赖）

```javascript
export function createAuth(perms) {
  let set = new Set(perms);
  const subs = new Set();
  return {
    has(p) { return set.has(p) || matchWildcard(p, set); },
    hasAny(list) { return list.some((p) => this.has(p)); },
    hasAll(list) { return list.every((p) => this.has(p)); },
    update(perms) { set = new Set(perms); subs.forEach((f) => f(set)); },
    sub(fn) { subs.add(fn); return () => subs.delete(fn); },
  };
}
// React: useSyncExternalStore(auth.sub, () => auth.has('order:delete'))
// Vue:   watchEffect(() => visible.value = auth.has(...))
```
