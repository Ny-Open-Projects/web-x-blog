## FRP-336：跨框架组件的性能预算

**答**：
- 预算四维：挂载（单组件 mount <5ms）、更新（交互响应 <16ms）、内存（实例 <10KB）、体积（壳层 <5KB gzip）——组件库的发布门禁
- 跨框架预算一致性的挑战：React 壳的 useSyncExternalStore 开销 vs Vue 壳的 customRef——「绑定方式」造成基准差异；预算按框架分档
- 预算的度量自动化：Storybook interaction test 内嵌 performance.mark——CI 门禁（超预算阻断发布）
- 预算破坏的治理：预算超标组件进「优化清单」（影响面 × 使用频率排序）——有量化才有优先级
- 与页级预算的关系：组件预算是分子，页面预算（LCP/INP）是分母——组件优化服务于页级指标

```text
组件性能预算卡点:
  mount < 5ms / update < 16ms / memory < 10KB / bundle < 5KB
CI: Storybook + performance.mark → 超标阻断
豁免: 原因 + 恢复期限 (留痕)
```
