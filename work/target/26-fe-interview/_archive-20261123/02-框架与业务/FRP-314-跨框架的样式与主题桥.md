## FRP-314：跨框架的样式与主题桥

**答**：
- 主题桥的设计：token 层（CSS 变量，框架无关）+ 各框架消费（CSS-in-JS 读变量 or 直接 class）——主题切换只动 data-theme，框架零参与
- 组件库跨框架：逻辑内核 + 各框架壳（FRP-306）之外，样式层全共享（一套 CSS）——「三份 JS 一份 CSS」的体积结构
- scoped 样式的边界：Vue scoped 属性选择器 / CSS Modules class hash——跨框架混用时冲突面（同名 class）——命名空间前缀规范
- shadow DOM 的样式注入：adoptedStyleSheets 共享样式表（多组件复用同一 CSSStyleSheet）——跨框架组件的样式桥
- 深水点：CSS 变量的失效范围——主题变量挂 :root 全页失效重算 vs 挂区域根（局部主题）——大页面的主题切换成本控制

```text
跨框架样式架构:
  tokens.css (CSS 变量, 唯一真源)
  ├── components.css (全框架共享)
  ├── react/ (壳组件, 无样式逻辑)
  └── vue/   (壳组件)
主题切换: document.documentElement.dataset.theme = 'dark' (框架零参与)
```
