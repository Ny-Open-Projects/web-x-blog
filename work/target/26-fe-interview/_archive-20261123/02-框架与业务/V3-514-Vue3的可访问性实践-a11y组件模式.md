## V3-514：Vue3 的可访问性实践：a11y 组件模式

**答**：
- 无头组件（headless）模式：逻辑与样式分离（Radix Vue/Reka UI 思路）——a11y 行为（键盘导航/aria）在逻辑层实现，样式自由；这是「组件库 a11y 质量」的现代解法
- 焦点管理三件套：焦点陷阱（对话框）、焦点还原（关闭返回触发者）、roving tabindex（列表导航）——实现成 useFocusTrap composable 复用
- aria 状态绑定：aria-expanded/selected/invalid 用响应式绑定自动同步——「视觉状态与语义状态同源」避免手工同步漂移
- 动态内容播报：aria-live 区域组件（toast/异步结果）——Vue 响应式驱动文本更新即自动播报
- 测试：axe-core 集成进组件测试（每个组件测试跑一次 a11y 断言）+ 键盘走查用例（Tab 序断言）

```javascript
// useFocusTrap
export function useFocusTrap(containerRef, active) {
  watch(active, (on) => {
    if (!on) return;
    const el = containerRef.value;
    const focusables = el.querySelectorAll('a,button,input,[tabindex="0"]');
    const trap = (e) => { /* Tab 循环 */ };
    el.addEventListener('keydown', trap);
    onCleanup(() => el.removeEventListener('keydown', trap));
  });
}
```
