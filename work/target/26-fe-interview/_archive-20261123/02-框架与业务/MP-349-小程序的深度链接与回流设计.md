## MP-349：小程序的深度链接与回流设计

**答**：
- 回流通道矩阵：小程序码（线下物料）、URL scheme（短信/App push）、聊天分享卡片、搜一搜——各通道的参数承载与到达率
- 短链设计：业务长参数 → 服务端短码（6 位）→ scheme/小程序码携带短码 → 落地解析还原——「参数隐私 + 长度限制」的双重动机
- 回流的落地路由：统一入口页（/pages/entry）解析短码 → redirect 目标页——「入口收敛」便于埋点与权限校验
- 冷启动参数：getLaunchOptionsSync（冷启动）vs onShow options（热启动）——双通道都要处理（用户在页面停留时点链接的场景）
- 深水点：回流失效的体验兜底——短码过期/活动结束 → 落地页兜底文案 + 引导主流程——「外链不可控」的设计

```javascript
// 统一入口页
Page({
  onLoad(query) { this.handleEntry(query); },
  onShow() { const opts = wx.getLaunchOptionsSync(); /* 热启动场景复核 */ },
  async handleEntry({ sid }) {
    const target = await api.resolveShortLink(sid);  // { page, params, expired }
    if (target.expired) return this.renderExpired();  // 兜底文案 + 主流程引导
    wx.redirectTo({ url: `${target.page}?${qs(target.params)}` });
  },
});
```
