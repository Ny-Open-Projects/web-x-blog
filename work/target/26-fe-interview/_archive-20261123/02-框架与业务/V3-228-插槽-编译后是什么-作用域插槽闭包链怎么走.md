## V3-228：slot 编译产物是什么？作用域插槽的数据闭包链怎么走的？
**答**：
- 普通插槽：编译为子组件的 children 函数（或 frag 数组），运行时在**父组件作用域**求值。
- 作用域插槽：编译为 `({ item, index }) => vnode` 的函数，数据在**子组件渲染时**传入求值——数据源是子，渲染时机由子决定。
- key 约定：具名插槽编译为 children 对象 `{ header: () => ..., default: ({ item }) => ..., _: 2 /* DYNAMIC_SLOTS */ }`。
- 动态插槽名 `v-slot:[name]`：标记 DYNAMIC_SLOTS，更新时走插槽 diff 分支。
- 性能：作用域插槽内容属于父 block 收集的动态节点，子组件传参变化只会触发插槽内容函数重执行，不重渲父组件。

```javascript
// 父：<List :items="arr"><template #item="{ item }">{{ item.name }}</template></List>
// 父编译产物
createVNode(List, { items: arr }, {
  item: ({ item }) => createTextVNode(toDisplayString(item.name)), // 作用域插槽=函数
  _: 2,
});
// 子组件内渲染：renderSlot(instance.$slots, 'item', { item: row })
// → 调用父传入函数并传入子数据；闭包链：父作用域变量在定义时捕获，子数据在调用时注入
```
