## V3-338：编译产物体积优化：预编译与运行时编译怎么取舍？
**答**：
- 运行时编译（runtimeCompiler）：打包完整 compiler（约 +15-20KB gzip），模板字符串在浏览器编译，适合 CSP 限制动态 eval 的场景不能用、模板动态拼接的场景才考虑。
- 预编译（推荐）：SFC 在构建期编译成 render 函数，产物只含 runtime，体积小且无运行时编译开销。
- 进一步：编译产物的「运行时 helper」按需 tree-shaking（vite 生产默认开启，`__VUE_OPTIONS_API__`/`__VUE_PROD_DEVTOOLS__` 等特性开关死代码消除）。
- defineConfig 里关闭不需要的特性：`features: { optionsAPI: false }` 可摇掉 Options API 兼容层。
- 验证：npm run build + visualizer 看 @vue/runtime-* 占比；模板里避免运行时拼接字符串模板。
