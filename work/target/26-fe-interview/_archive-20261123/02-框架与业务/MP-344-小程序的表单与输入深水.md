## MP-344：小程序表单与输入：输入组件的坑与校验体系

**答**：
- input 的坑集：键盘弹起遮挡（adjust-position 默认顶起——fixed 底部输入框要 cursor-spacing/adjustPosition:false + 手动布局）、iOS 中文输入的 composition（bindinput 高频 + 中文组词）、maxlength 与表情（emoji 占 2 字符——计数用 [...str].length）
- 表单体系：自建（数据双向 + 校验器——与 H5-375 同内核）或组件库 form——「校验逻辑跨端共享」的双端复用价值
- 输入防抖与搜索：bindinput 高频 → 防抖 300ms + 请求竞态守卫（同 Web 模式）
- 动态表单：schema 驱动（组件注册表 + 动态组件语法——component is 不支持，用 block + wx:if 分支或自定义节点）
- 深水点：textarea 的原生组件问题（层级/同层渲染）——同层渲染后仍有焦点切换异常——「表单页避免混排原生组件」的设计约束

```javascript
// 双向绑定 + 校验（小程序版）
Page({
  data: { form: { phone: '' }, errors: {} },
  onInput(e) { const { field } = e.currentTarget.dataset;
    this.setData({ [`form.${field}`]: e.detail.value });
    this._debounced(field); },
  _debounced: _.debounce(function (field) {
    validate(field, this.data.form[field]).then((msg) => {
      msg ? this.setData({ [`errors.${field}`]: msg }) : this.setData({ [`errors.${field}`]: '' });
    });
  }, 300),
});
// 键盘遮挡: <input adjust-position="{{false}}" cursor-spacing="120"> + 页面手动 padding-bottom
```
