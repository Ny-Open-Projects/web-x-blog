## FRP-325：跨框架的日志与调试桥

**答**：
- 调试桥的需求：跨框架调用链（React 页面调 Vue 组件的服务）——日志要「串联」（trace id 贯穿两框架）
- trace 协议：内核层注入 traceId（每次用户动作生成）+ 各框架的日志 hook 读取——跨框架请求在监控平台可拼出完整链路
- 状态快照调试：桥接层支持「导出当前内核状态」（跨框架一致的调试快照）——「React 侧看到的和 Vue 侧不一样」时的仲裁依据
- DevTools 的割裂与缓解：React DevTools/Vue DevTools 各看各的——统一内核状态面板（自建调试页）作为仲裁视图
- 生产 debug 模式：URL 参数开启内核日志（set/get 全记录 + 内存环形缓冲）——线上问题复现的关键开关

```javascript
// trace 贯穿
export function withTrace(fn, traceId) {
  return (...args) => {
    console.debug(`[trace:${traceId}] ${fn.name} start`);
    return fn(...args).finally(() => console.debug(`[trace:${traceId}] ${fn.name} end`));
  };
}
// 内核状态导出(仲裁视图)
window.__kernel_dump__ = () => ({
  auth: auth.snapshot(), cart: cart.snapshot(), t: Date.now(),
});
```
