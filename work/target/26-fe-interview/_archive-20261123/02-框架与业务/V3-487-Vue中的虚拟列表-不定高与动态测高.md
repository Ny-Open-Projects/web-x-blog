## V3-487：Vue 中的虚拟列表：不定高与动态测高

**答**：
- 定高 vs 不定高：定高用公式直算（offset = i * h）；不定高要「预估 + 实测校准」——渲染后测量实际高度更新 offset 缓存，类似 Fenwick/累计数组二分定位
- Vue 实现要点：滚动容器 ref + 计算属性算可见区间；item 用组件（内部 onMounted 测高上报）——高度缓存用 reactive Map，偏移重算用 computed
- 校准抖动治理：高度变更导致总高度变化 → 滚动位置漂移——「锚定补偿」（记录首个可见项，重算后修正 scrollTop）；或收敛策略（只允许向下校准）
- 与 KeepAlive/过渡的冲突：虚拟列表项用 Transition 会因卸载触发 leave 动画错位——列表项禁用过渡或用位移补偿
- 现成库认知：vue-virtual-scroller/vueuse useVirtualList——面试手写核心在「offsets 累计数组 + 二分 + 锚定补偿」三件套

```javascript
// 核心切片
const offsets = computed(() => {
  const arr = [0];
  for (let i = 0; i < items.value.length; i++)
    arr.push(arr[i] + (heightCache.get(items.value[i].id) ?? EST_H));
  return arr;
});
const start = computed(() => binarySearch(offsets.value, scrollTop.value));
```
