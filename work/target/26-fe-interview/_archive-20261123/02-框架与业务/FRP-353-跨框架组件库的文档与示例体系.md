## FRP-353：跨框架组件库的文档与示例体系

**答**：
- 文档挑战：同一组件双框架 API 展示（props/事件/插槽语义对齐但语法不同）——「单源文档 + 框架切换 tab」的结构
- 示例单源策略：逻辑单源（内核 demo——纯 JS）+ 各框架渲染模板——示例代码「逻辑写一次，模板各写各的」
- API 表生成：类型定义 → 文档表（typedoc 从内核 + 各壳 props 类型生成）——文档与代码同源（drift 防护）
- Playground：在线编辑（按框架 tab 切换实时预览）——内核热更新 + 各壳渲染的架构
- 深水点：文档即测试——示例代码抽出来跑快照（文档代码可运行验证）——文档腐烂的机械防护

```text
文档体系:
  单源: 内核 demo (纯 JS, 可运行)
  展示: React tab / Vue tab (模板层)
  API 表: typedoc 从类型生成
  验证: 示例代码快照进 CI (文档即测试)
```
