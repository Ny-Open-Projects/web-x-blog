## R19-228：列表页多个条目并发乐观操作怎么收敛状态？
**答**：
- 乐观操作以「目标项 id + 操作」为单位入队：reducer 按 id 定位条目应用变更，其他项不受影响。
- 同一 id 多操作叠加：队列顺序保证（点赞后马上收藏，两条都在队列里按序折叠）。
- 冲突场景：删除与点赞同时进行——reducer 里定义优先级（删除操作使后续点赞无效），或 UI 层禁止冲突组合。
- 状态来源收敛：optimistic base 是「服务端列表」，每项的状态由 serverState[id] + 该 id 的乐观队列推导，单一数据源不分裂。
- 深层坑：item key 稳定性（id 而非 index），否则回滚后 React 复用错行。
