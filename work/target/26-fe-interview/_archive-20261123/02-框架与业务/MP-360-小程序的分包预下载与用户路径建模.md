## MP-360：分包预下载与用户路径建模

**答**：
- preloadRule 机制：页面级触发（进入某页面时预下载指定分包）+ 网络条件（wifi/all）——「静态规则」需要用户路径数据支撑
- 路径建模：埋点数据统计「页面 → 下一页面」转移概率——Top 转移路径 → preloadRule 配置——数据驱动的预下载配置
- 预下载预算：分包预下载总和限制（2MB）——概率加权选择（转移概率 × 分包大小的性价比排序）
- 效果度量：分包首次到达「等待下载时间」（分包加载事件打点）——预下载命中 vs 未命中的对比
- 深水点：动态预下载（运行时判断）——wx.preDownloadSubpackage API（部分版本）——静态规则 + 动态 API 双轨（用户行为即时调整——如浏览到商品列表页预载详情分包）

```json
// 数据驱动配置示例 (埋点 Top 路径)
{ "preloadRule": {
    "pages/index": { "network": "wifi", "packages": ["order"] },        // 首页→订单 42%
    "pages/order/list": { "network": "all", "packages": ["order-detail"] }  // 列表→详情 78%
} }
```

```javascript
// 动态预下载(基础库 2.27+)
wx.preDownloadSubpackage({ packageType: 'workers', success: ... });
// 打点: 分包页 onLoad 时上报「等待时间」 → 预下载命中率报表
```
