## MP-362：小程序的合规与审核要点：技术侧准备

**答**：
- 类目与资质：小程序类目决定审核标准（电商要 ICP/食品经营许可等）——「资质先行」是提审前置
- 隐私合规：隐私协议（privacy 接口声明 + 用户同意弹层）、个人信息收集最小化、注销能力（账号删除——合规硬要求）
- 内容安全：UGC 内容（评论/图片）必须接内容安全 API（msgSecCheck/imgSecCheck——云调用）——「先审后发」是审核硬性要求
- 支付合规：虚拟支付限制（iOS 虚拟商品不可用微信支付——类目规则）、实物/服务支付的资质
- 深水点：审核被拒的技术原因 Top——「页面空白」（数据未做兜底，审核员网络异常时）、诱导分享文案、测试数据残留——「审核员视角」的自测清单

```javascript
// UGC 内容安全(云调用)
const res = await wx.cloud.callFunction({ name: 'secCheck', data: { content } });
// 云函数内: cloud.openapi.security.msgSecCheck({ content }) → risky 拦截
// 注销能力: 设置页 → 注销流程(二次确认 + 数据删除接口) — 合规硬要求
// 自测清单: 断网/慢网下各页面不空白 / 无测试数据 / 无诱导分享文案
```
