## R19-366：React19 内建文档元数据与资源加载

**答**：
- 组件树内直接写 <title>/<meta>/<link>：React 19 自动 hoist 到 head——组件内维护 SEO/OG 元信息，SSR 流式时在 flush 早期输出
- 资源加载 API（preload/preinit/preconnect）：在数据层调用 preload(href, { as }) 提前加载字体/样式/图片——「知道要渲染什么之前」就开始下载
- 与 async 模式的组合：deferred preload（渲染流中按需）vs 立即 preload（事件处理器中）——预加载的时机选择
- 深水点：资源去重——preload 同 href+as 去重、preinit 保证样式不重复注入；「组件库每个组件都 preload 自己样式」的场景由去重兜底
- 对比旧方案：react-helmet 类库的 useEffect 塞 head（首帧后才有 SEO）→ React19 渲染期原生支持（SSR HTML 里就有 meta）

```jsx
function ProductPage({ product }) {
  preload(product.heroImg, { as: 'image', fetchPriority: 'high' });
  preinit('/product-page.css', { as: 'style' });
  return (
    <>
      <title>{product.name} - Shop</title>
      <meta name="description" content={product.summary} />
      <img src={product.heroImg} />
    </>
  );
}
```
