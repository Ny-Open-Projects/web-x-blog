## MP-320：小程序授权体系：权限矩阵与隐私协议

**答**：
- 授权矩阵分类：一次性授权（chooseAddress 等——每次调用弹）、持久 scope（相册/位置/camera——拒绝后只能 openSetting）、静默能力（login/获取openid 不需授权）——三类策略不同
- 授权拒绝后的引导闭环：调 API fail → wx.getSetting 查状态 → denied 时 wx.openSetting 引导开启——「拒绝后的挽回路径」是转化关键
- 隐私协议（2023 强制）：wx.requirePrivacyAuthorize——隐私接口（获取手机号/位置/相册）调用前需用户同意隐私协议；privacy 契约（小程序管理后台声明 + 前端弹层）
- 兜底文案与场景化申请：申请理由前置展示（「用于生成专属海报，需要访问相册」）——「先讲价值再弹授权」的转化设计
- 深水点：wx.getSetting 的 authSetting 字典——运行时判断「授权状态」避免重复弹窗；「once 权限」的授权记录由系统管理，前端只做引导

```javascript
async function savePoster(path) {
  try { await wx.saveImageToPhotosAlbum({ filePath: path }); return toast('已保存'); }
  catch (e) {
    const { authSetting } = await wx.getSetting();
    if (authSetting['scope.writePhotosAlbum'] === false) {   // 明确拒绝过
      const { confirm } = await wx.showModal({ content: '需要相册权限保存海报，请在设置中开启' });
      confirm && wx.openSetting();                           // 引导设置页
    }
    // 非拒绝(首次弹窗取消): 下次调用自然再弹
  }
}
```
