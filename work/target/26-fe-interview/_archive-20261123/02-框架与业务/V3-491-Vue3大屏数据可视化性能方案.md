## V3-491：Vue3 大屏数据可视化性能方案

**答**：
- 数据更新频率分级：秒级轮询（表格指标）、毫秒级推送（行情线）——分级处理：低频进 Vue 响应式驱动组件重渲，高频走「图表实例直接 setData」（ECharts setOption）绕过 Vue 渲染层
- ECharts 集成要点：实例复用（不要 v-if 重建）、数据更新只 setOption 变更 series（notMerge:false）、resize 防抖——「图表实例放 ref 但数据不 reactive」避免深 proxy 序列化开销
- 大数据量渲染：downsample 服务端做（LTTB 抽样）、前端 sampling: 'lttb' 兜底、大数据集用 WebGL 系（echarts-gl/数据缩放 dataZoom + progressive 渲染）
- 页面布局策略：固定布局容器 + CSS Grid 区块独立更新（一个块更新不牵连整屏重排）——大屏「局部刷新」靠组件化隔离
- 内存与生命周期：页面隐藏暂停推送消费、图表实例 dispose 时机（路由离开必 dispose，泄漏高发）

```javascript
const chartRef = ref();
let chart;
onMounted(() => { chart = echarts.init(chartRef.value); });
// 高频数据绕过 Vue 响应式
ws.onmessage = ({ data }) => {
  const tick = JSON.parse(data);
  chart.setOption({ series: [{ data: tick.points }] }, { lazyUpdate: true });
};
onUnmounted(() => chart?.dispose());  // 泄漏高发点
```
