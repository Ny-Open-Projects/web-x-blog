## FRP-315：框架无关的错误监控与追踪

**答**：
- 分层监控：全局层（window.onerror/unhandledrejection——框架无关兜底）+ 框架层（React ErrorBoundary/Vue errorHandler 补上下文）+ 请求层（fetch 包装）
- 框架上下文增强：React 的 componentStack、Vue 的 instance 组件路径——框架层捕获取「组件树路径」是全局层拿不到的
- 归因指纹统一：跨框架项目用「文件+行号+消息」指纹（sourcemap 还原后）——框架名只是维度不是指纹
- 异步错误统一：Promise rejection 在两框架语义一致（unhandledrejection）——监控层统一接，框架层只增强
- trace 贯穿：用户操作轨迹（自定义 action log）在框架层注入（路由/点击 hook）——框架无关内核消费

```javascript
// 全局层(框架无关)
window.addEventListener('error', (e) => report({ type: 'js', ...normalize(e) }));
window.addEventListener('unhandledrejection', (e) => report({ type: 'promise', reason: String(e.reason) }));
// Vue 层增强
app.config.errorHandler = (err, instance) => report({ ...normalize(err), comp: compPath(instance) });
// React 层增强
class Boundary extends Component {
  componentDidCatch(err, info) { report({ ...normalize(err), compStack: info.componentStack }); }
}
```
