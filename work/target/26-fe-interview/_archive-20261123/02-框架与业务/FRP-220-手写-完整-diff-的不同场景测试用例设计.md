## FRP-220：手写 keyed diff 的测试用例设计？
**答**：
- 场景清单：头部插入、尾部插入、中间插入、头部删除、尾部删除、中间删除、反转、旋转（abcde→deabc）、乱序重排、key 重复（报错）、类型变化、key+type 同时变、空列表到满列表、满到空。
- 每个用例断言：最终 DOM 顺序正确 + 移动次数 ≤ 理论最小值（LIS 参考值）+ 复用节点数（identity 断言：DOM 元素引用不变）。
- 边界：单元素、新旧长度为 0、全 unknown key。
- 用例即文档：把 diff 算法的所有分支行为固化成测试，防回归。
- 工程化：用 property-based testing（随机列表对 + 已知目标）生成对抗用例，断言移动次数上界。
