## R19-414：并发渲染边界：多语言与时区在并发渲染的一致性

**答**：
- locale 切换与 transition：语言切换是「全局一致性」操作——用 flushSync（同步全树）而不是 transition（部分树新旧语言混合不可接受）
- 时区/Intl 的撕裂源：渲染中直读 Intl.DateTimeFormat().resolvedOptions().timeZone（系统设置变化）——locale/timezone 应进 React 状态（Context/快照）而不是运行时直读
- 服务端与客户端 locale 一致：SSR 用请求头/URL 推导 locale（进入状态），客户端水合用同一值——避免 hydration mismatch 与并发下的 locale 混合
- 翻译资源懒加载与并发：切换语言异步加载翻译包——transition 中新语言未就绪保持旧语言（资源缓存层承接），就绪后 flushSync 切换
- 复数/格式的一致性测试：多语言快照矩阵（切换前后）——并发渲染下的 i18n 一致性是回归重点

```javascript
function switchLocale(l) {
  loadMessages(l).then((msgs) => {
    i18n.set(l, msgs);
    flushSync(() => setLocale(l));       // 全树同步切换, 防新旧混合
  });
}
```
