## V3-472：运行时模板编译 vs 预编译：性能与安全的差异

**答**：
- 两种模式：完整版（含编译器，运行时 new Function 编译模板）vs 运行时版（预编译产物直接是 render 函数）——构建工具默认预编译
- 性能差异三处：运行时编译要 parse+transform+generate（每组件一次，无优化信息的普通 render）、产物无 patchFlag/静态提升（退化为 Vue2 式全量 diff）、new Function 在 CSP 环境直接被禁
- 预编译优势清单：编译期优化生效、错误提前到构建期、产物体积小（不含编译器 ~200KB）、CSP 安全
- 运行时编译的合法场景：动态表单/低代码平台「用户输入模板」——这时才需要完整版 vue.global.js 或按需引入 compiler-core；注意 XSS 面（模板 = 代码，用户输入必须过编译前校验）
- 深水点：动态模板的编译缓存——compile() 结果按 template 字符串缓存，同模板不重复编译

```javascript
// 运行时编译(完整版才有)
const { compile } = VueCompiler;
const render = compile(userTemplate);   // 缓存: compileCache.get(template)
createApp({ render }).mount('#app');
// 预编译产物: render 函数直接打包, 编译器不存在于 bundle
```
