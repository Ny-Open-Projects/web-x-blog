## V3-486：路由切换性能：懒加载、预取与过渡的调度

**答**：
- 懒加载的代价：动态 import 产生网络请求——首次进入路由白屏等待；策略是「lazy + 预取」组合：defineAsyncComponent 的高级选项（delay/loading）+ 手动 prefetch
- 预取时机：路由 hover/intent（菜单 hover、列表项可见）→ router.resolve + 动态 import 触发——用 requestIdleCallback 空闲期预取高频路由
- 切换动画与数据加载解耦：过渡动画不应等接口——骨架先入 + Suspense 包裹异步路由组件（数据请求在组件 async setup 里，Suspense 兜底），避免「动画被数据卡住」
- 组件级 keep-alive 选路：高频返回的路由（tab 页）包 KeepAlive + max；重数据路由不缓存（activated 时刷新数据）
- 度量：路由切换 P95（router.beforeEach mark → 目标 mounted）、预取命中率——路由切换是 SPA 的 INP 高发区

```javascript
// 路由预取
const hoverPrefetch = (name) => requestIdleCallback(() => {
  const r = router.resolve({ name });
  if (r.matched.every(m => m.components.default)) return;
  import(/* @vite-ignore */ r.href).catch(() => {});
});
// Suspense + 异步路由组件
<Suspense><RouterView /></Suspense>
```
