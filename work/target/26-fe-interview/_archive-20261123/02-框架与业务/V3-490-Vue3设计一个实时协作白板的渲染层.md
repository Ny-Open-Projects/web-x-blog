## V3-490：实战设计：Vue3 实时协作白板的渲染层

**答**：
- 分层：数据层（协同文档 CRDT/Yjs，独立于 Vue）、渲染层（Canvas 绘制，非 DOM）、交互层（Vue 管工具栏/面板 UI）——「高频率数据不进响应式」是核心决策
- CRDT 与 Vue 的桥接：Yjs 文档变更（observe）→ 防抖批量同步到 Vue 状态（只同步「面板需要的摘要」）；Canvas 画布直接消费 Yjs 原始数据（绕过响应式）
- 渲染性能：requestAnimationFrame 合帧绘制（每帧一次全量/脏区重绘）；远端光标用 overlay DOM（少量节点用 Vue 管理获得过渡动画）
- 冲突与撤销：撤销栈基于 Yjs undoManager（CRDT 级撤销，多端一致）——Vue 层只管 UI 按钮，不维护自己的撤销栈
- 通信：Yjs y-websocket provider（增量同步 + 断线重连）——Vue 组件只订阅「连接状态」ref 更新 UI

```javascript
// 桥接层
const ydoc = new Y.Doc();
ydoc.observe(() => {
  scheduleCanvasRender();                     // 直接驱动 canvas, 不过响应式
  debouncedSyncToVue(ydoc.getMap('meta'));    // 面板摘要才进 Vue
});
const connected = ref(false);
provider.on('status', ({ status }) => connected.value = status === 'connected');
```
