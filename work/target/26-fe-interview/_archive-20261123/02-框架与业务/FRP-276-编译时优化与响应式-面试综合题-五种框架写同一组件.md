## FRP-276：综合题：同一组件四种框架的产物差异分析？
**答**：
- 需求：列表 + 点击项计数。写法层面（略）——分析聚焦产物与更新链路。
- React：setState → 全组件重渲染 → reconcile 列表（key diff）→ DOM；Compiler 后行级 memo。
- Vue（VDOM）：reactive 数组 → render effect → block diff（patchFlag 列表）→ DOM。
- Vue Vapor：信号 → createFor 按项更新 → 直接 DOM 写。
- Solid：signal → For 组件按 key reconcile 块 → 细粒度 DOM 写。
- 结论：同一抽象（状态→视图），四条链路开销差异集中在「中间表示」层——面试时要能画出这条链路图。
