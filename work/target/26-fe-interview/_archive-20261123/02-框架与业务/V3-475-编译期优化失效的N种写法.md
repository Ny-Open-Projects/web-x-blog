## V3-475：编译期优化失效的写法盘点：哪些代码让优化白做

**答**：
- 动态样式全绑定：`:style="dynamicStyle"` 在根元素 + 全页结构——style 合并触发 NEED_PATCH，子树静态提升失效；改用 CSS 变量传值（:style 只挂 `--x` 一个变量）
- 大 JSON 直接进模板：v-for 渲染 5000 条 + 每项复杂表达式——block 内动态节点数千个，靶向更新退化；分页/虚拟滚动解决
- v-html 内嵌动态结构：v-html 的 HTML 内的动态性编译器看不见 → 全量 diff；且 XSS 面——富文本用组件化渲染
- 组件高频全 props 变化：对象引用每次新建（:config="computedConfig"）→ 子组件 props 恒变 → 子组件整树重渲；用 memoized computed + 基础类型 props 拆分
- 运行时字符串模板混用：局部 `compile()` 动态编译的组件无 block 优化——动态模板区域隔离到独立小组件，别让整页失去编译优化
- 排查工具：Vue DevTools Performance 面板（组件渲染耗时）、`vue-tsc` 无关但编译产物可查（vite-plugin-vue-devtools 的 inspector 看编译产物）

```vue
<!-- 反模式 -->
<div :style="`--all-dynamic-${i}`">...</div>
<!-- 正解: 变量单点 -->
<div :style="{ '--x': themeVar }" class="static-shell">...</div>
```
