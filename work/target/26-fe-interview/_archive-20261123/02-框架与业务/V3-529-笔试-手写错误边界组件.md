## V3-529：笔试：手写错误边界组件

**题目**：实现 `<ErrorBoundary>`：① onErrorCaptured 捕获子树渲染错误（阻止向上传播）；② 捕获后展示 fallback 插槽；③ 重试：点击重试按钮换 key 强制重建子树（修复渲染态）；④ 错误上报回调 emit('error', err, instance)；⑤ 异步错误（Promise）捕获不到的限制说明与配合方案（手动 throw 进边界）。写出实现。

```vue
<script setup>
import { ref, onErrorCaptured } from 'vue';

const props = defineProps({ retryable: { type: Boolean, default: true } });
const emit = defineEmits(['error']);
const hasError = ref(false);
const retryKey = ref(0);
let lastError = null;

onErrorCaptured((err, instance, info) => {
  hasError.value = true;
  lastError = err;
  emit('error', { err, instance, info });
  return false;                          // 阻止继续向上传播
});
function retry() {
  hasError.value = false;
  retryKey.value++;                      // 换 key 重建子树
}
</script>

<template>
  <template v-if="!hasError">
    <slot :key="retryKey" />
  </template>
  <div v-else class="error-boundary">
    <p>出错了: {{ lastError?.message }}</p>
    <button v-if="retryable" @click="retry">重试</button>
    <slot name="fallback" :error="lastError" />
  </div>
</template>
<!-- 注意: onErrorCaptured 捕获不到异步回调(Promise/setTimeout)中的错误
     — 异步错误需业务侧 try/catch 后手动 throw 或走全局 errorHandler -->
```

**评分点**：
- onErrorCaptured 返回 false 阻断传播（边界语义）
- 重试 = 换 key 强制重建（渲染态修复的正确方式）
- 异步错误不可捕获的认知与逃生方案
- fallback 插槽 + error 对象透传
