## V3-502：Vue3 并发数据获取：请求编排模式

**答**：
- 编排三模式：并行独立（Promise.allSettled 各自渲染）、依赖串行（前序结果作参数）、混合 DAG（关键依赖串行 + 独立并行）——DAG 执行器（JS-399）直接复用
- Vue 特有编排：computed 驱动请求（路由参数 ref → computed → watch 触发 fetch）——「参数化请求」的取消与竞态守卫模板化
- 请求竞态治理统一收口：路由切换时 AbortController 广播取消（onBeforeRouteLeave abort）——跨组件请求取消的中心化
- 骨架一致性：各接口完成时间差异大——「关键路径渲染门」（首屏数据 all + 增强数据渐进），用 Suspense 包关键、teleport 增强区
- 缓存与去重：路由级缓存（离开再回来不重拉，TTL 30s）——组合式 useQuery(key, fetcher, { ttl }) 的最小实现

```javascript
export function useParamQuery(buildKey, fetcher) {
  const data = ref(null), loading = ref(false);
  let ctrl;
  watch(buildKey, async (k) => {
    ctrl?.abort(); ctrl = new AbortController();   // 竞态守卫
    loading.value = true;
    try { data.value = await fetcher(k, ctrl.signal); }
    catch (e) { if (e.name !== 'AbortError') error.value = e; }
    loading.value = false;
  }, { immediate: true });
  return { data, loading };
}
```
