## MP-310：小程序的登录与会话体系：code2session 全链路

**答**：
- 登录链路：wx.login 拿 code（5 分钟有效、一次性）→ 服务端 code2session（appid+secret+code → openid/session_key）→ 服务端签发业务 token——「code 不出后端」是安全底线
- session_key 的敏感用途：解密手机号（getPhoneNumber 的 encryptedData）——前端不能存 session_key；新版直接用 phone code（getPhoneNumber 返回 code，服务端换手机号——更简单安全）
- 会话失效策略：wx.checkSession（校验 session_key 有效性）→ 失效静默重新 wx.login——「无感知续期」是体验关键（不弹登录授权）
- 登录态存储：业务 token 进 storage（与小程序会话独立生命周期）；多角色（企业微信/个人）的切换设计
- 深水点：wx.login 的调用时机——启动时静默登录（code2session 换 token）+ 接口 401 时「重登重放」幂等处理

```javascript
async function ensureToken() {
  let token = wx.getStorageSync('token');
  if (token && (await checkServer(token))) return token;
  const { code } = await wx.login();                 // 静默, 无授权弹窗
  const { token: t, expiresIn } = await api.code2session(code);
  wx.setStorageSync('token', t);
  scheduleRefresh(expiresIn - 300);                  // 提前 5 分钟刷新
  return t;
}
// 手机号: <button open-type="getPhoneNumber" bindgetphonenumber> — e.detail.code → 服务端换手机号
```
