## MP-379：笔试：手写骨架屏

**题目**：实现骨架屏组件 `Skeleton`：① props: rows/type（文本/卡片/头像组合预设）+ loading（true 显示骨架）；② 骨架块 shimmer 动画（WXML + WXSS——渐变位移动画，渲染层直接跑不耗逻辑层）；③ 骨架尺寸与真实内容一致（防 setData 后布局跳动——占位用固定高 + aspect-ratio 等价实现）；④ 骨架切换无闪（loading false 时淡出）；⑤ 组件化复用（按页面传入预设）。写出实现。

```xml
<!-- skeleton.wxml -->
<view wx:if="{{loading}}" class="sk-root sk-fade">
  <block wx:if="{{type === 'card'}}">
    <view class="sk sk-img"></view>
    <view class="sk sk-line w80"></view>
    <view class="sk sk-line w50"></view>
  </block>
  <block wx:elif="{{type === 'avatar'}}">
    <view class="sk sk-avatar"></view>
    <view class="sk sk-line w60"></view>
  </block>
  <block wx:else>
    <view wx:for="{{rows}}" wx:key="index" class="sk sk-line w{{90 - item * 15}}"></view>
  </block>
</view>
<slot wx:else></slot>
```

```css
/* skeleton.wxss */
.sk { position: relative; overflow: hidden; background: #eee; }
.sk::after {
  content: ''; position: absolute; top: 0; bottom: 0; left: -100%; width: 100%;
  background: linear-gradient(90deg, transparent, rgba(255,255,255,.6), transparent);
  animation: shimmer 1.2s infinite;
}
@keyframes shimmer { to { left: 100%; } }          /* 渲染层动画, 零 setData */
.sk-img { width: 100%; height: 400rpx; }            /* 尺寸=真实内容, 防 CLS */
.sk-line { height: 32rpx; border-radius: 8rpx; margin: 16rpx 0; }
.sk-avatar { width: 88rpx; height: 88rpx; border-radius: 50%; }
.sk-fade { animation: fade-in .2s; }
```

**评分点**：
- shimmer 渲染层动画（零 setData 成本）
- 尺寸与真实内容一致（防布局跳动）
- 多预设 type 与 slot 的组合模式
- wx:if/wx:else 的 loading 切换与淡出
