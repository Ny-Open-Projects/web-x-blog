## AIC-323：Agent 自治执行命令（安装依赖/跑测试）如何做沙箱隔离？
**答**：
- 文件系统隔离：专用容器/devcontainer + 最小挂载（只挂工作目录），禁止挂载密钥目录。
- 网络策略：默认断网或仅允许包管理器白名单域名（npm registry），出网需声明。
- 命令分级：只读命令白名单自动执行，写操作（rm/git push）需审批，高危命令直接拒绝。
- 资源限额：CPU/内存/时长上限，防止失控循环。

```javascript
const sandbox = {
  fs: { mount: ['./work'], noSecrets: true },
  net: { allow: ['registry.npmjs.org'], default: 'deny' },
  cmd: { auto: ['ls', 'vitest run', 'tsc'], confirm: ['git commit'], deny: ['rm -rf /', 'curl | sh'] },
  limits: { cpu: 2, mem: '4g', wall: '15m' },
};
r
```
