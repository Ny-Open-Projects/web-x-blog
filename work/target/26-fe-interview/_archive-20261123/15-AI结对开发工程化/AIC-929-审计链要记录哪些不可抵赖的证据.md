## AIC-929：为满足合规，AI 结对产出要记录哪些「不可抵赖」的证据？怎么保证这些证据本身不被篡改？
**答**：
- 证据分四类：① 谁发起（人/账号）、② 用什么（模型版本/prompt 版本）、③ 输入什么（上下文快照哈希）、④ 产出什么（代码哈希与落库 commit）——结论：缺一类就存在抵赖空间。
- 保证不可篡改用「哈希链」：每条审计记录包含前一条的哈希，任何中间记录被改都会导致链断裂；可再配合时间戳服务或只追加存储增强。
- 证据要最小化采集：只记必要元数据与哈希，不把敏感源码全文写进日志（呼应脱敏），在「可举证」与「数据合规」间平衡。
- 追问钩子：能说出「哈希链防篡改 + 只追加存储 + 时间戳服务」三件套，并强调「证据采集本身要合规」的候选人，兼顾了审计与隐私。

```typescript
// 哈希链审计记录：每条含前一条哈希，篡改即断链
function makeRecord(prevHash, payload) {
  const body = JSON.stringify({ ...payload, prev:prevHash, at:Date.now() });
  return { body, hash: hash(body) };
}
function hash(s){ let h=0; for(const c of s) h=(Math.imul(h,31)+c.charCodeAt(0))|0; return h>>>0; }
function verifyChain(records) {
  return records.every((r,i) => i===0 || JSON.parse(r.body).prev === records[i-1].hash);
}
const r1 = makeRecord('0', { actor:'alice', model:'gpt-x@v2', outHash:123 });
const r2 = makeRecord(r1.hash, { actor:'agent-b', promptVersion:'p13', outHash:456 });
console.log(verifyChain([r1,r2])); // true；改任意 body → false
```
