## AIC-289：自托管开源模型（如 DeepSeek/Qwen 本地部署）做编码助手，什么时候值得？
**答**：
- 值得的信号：涉密场景硬约束、云端 API 成本占研发成本比例过高（> 3%）、有闲置 GPU 算力。
- 不值得的信号：团队 < 50 人无专职运维、任务难度普遍偏高（本地模型通过率差距大）。
- 隐性成本：显卡采购/电费/运维人力/模型升级跟随——按 3 年 TCO 与云端对比。
- 折中路线：敏感仓库本地模型 + 公开仓库云端，按仓库标签自动路由。

```javascript
function tco3y(cloud: { perDev: number }, local: { gpu: number; ops: number; power: number }, devs: number) {
  const cloudCost = cloud.perDev * devs * 36;
  const localCost = local.gpu + local.ops * 36 + local.power * 36;
  return { cloudCost, localCost, breakEvenDevs: Math.ceil(localCost / (cloud.perDev * 36)) };
}
```
