## AIC-183：笔试：实现一个 AI 产出存活率统计器：7 天窗口判定、重写/回滚识别与分组报告？
**需求**：实现 `survivalReport(commits, { windowDays = 7 })`：
- commits: `[{hash, at, aiTask?, files, message}]`；aiTask 存在即 AI 提交；
- 判定存活：窗口期内该 commit 的文件未被 revert 且未被大幅重写（后续提交对同文件改动 > 60% 视为重写）；
- 输出：总体存活率 + 按「任务类型」分组存活率 + 被杀死的提交清单（含原因 revert/rewrite）。

```javascript
function isRevert(c) { return /^(revert|回滚)/i.test(c.message); }

function changedRatio(prev, next) {
  const a = new Set(prev), b = new Set(next);
  let inter = 0;
  for (const x of a) if (b.has(x)) inter++;
  return 1 - inter / (a.size + b.size - inter || 1); // 行集合 Jaccard 距离
}

function survivalReport(commits, { windowDays = 7 } = {}) {
  const aiCommits = commits.filter(c => c.aiTask);
  const killed = [];
  const byKind = new Map();

  for (const c of aiCommits) {
    const deadline = new Date(c.at).getTime() + windowDays * 864e5;
    let alive = true, reason = null;
    for (const later of commits) {
      const t = new Date(later.at).getTime();
      if (t <= new Date(c.at).getTime() || t > deadline) continue;
      const overlap = later.files.filter(f => c.files.includes(f.path));
      if (!overlap.length) continue;
      if (isRevert(later) && overlap.length) { alive = false; reason = `revert by ${later.hash}`; break; }
      const touched = overlap.some(f =>
        changedRatio(f.linesBefore ?? f.lines ?? [], f.linesAfter ?? f.lines ?? []) > 0.6);
      if (touched) { alive = false; reason = `rewrite by ${later.hash}`; break; }
    }
    const kind = c.aiTask.split(':')[0];
    const g = byKind.get(kind) ?? { total: 0, alive: 0 };
    g.total++; if (alive) g.alive++; else killed.push({ hash: c.hash, kind, reason });
    byKind.set(kind, g);
  }
  return {
    overall: aiCommits.length ? +(aiCommits.filter(c => aliveOf(c, killed)).length / aiCommits.length).toFixed(3) : 0,
    byKind: Object.fromEntries([...byKind.entries()].map(([k, g]) =>
      [k, +(g.alive / g.total).toFixed(3)])),
    killed,
  };
}
function aliveOf(c, killed) { return !killed.some(k => k.hash === c.hash); }

// 测试
const commits = [
  { hash: 'a1', at: '2026-11-01T10:00:00Z', aiTask: 'refactor:usePagination', files: [{ path: 'p.ts', lines: [1, 2, 3] }] },
  { hash: 'a2', at: '2026-11-03T10:00:00Z', aiTask: 'doc:readme', files: [{ path: 'r.md', lines: [1] }] },
  { hash: 'h1', at: '2026-11-04T10:00:00Z', files: [{ path: 'p.ts', lines: [9, 9, 9, 9] }], message: 'revert a1' },
];
console.log(survivalReport(commits));
// overall=0.5，byKind: doc=1, refactor=0，killed 含 a1（revert）
```

**评分点**：
1. 窗口语义正确：只看 commit 后 7 天内的后续提交，之前的与之外的都不算；
2. 两种死因判定：显式 revert + 隐式重写（行集合差异 > 0.6），只查 revert 会漏；
3. 分组存活率（按任务类型）是「哪些任务适合 AI」的决策依据；
4. killed 清单含原因与来源 hash，可回溯归因；
5. 追问：重写判定用行集合 Jaccard 是简化版，生产可用 diff hunk 比例。
