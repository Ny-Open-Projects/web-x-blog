## AIC-488：笔试：AI 出站请求的敏感内容扫描与阻断。
**题目**：出站 payload 扫描：密钥/内部域名/邮箱（PII）。命中即阻断并输出命中类别与位置；全部干净放行。实现 `scanOutbound(payload, rules)`。

```javascript
const RULES = [
  { kind: 'secret', re: /(?:sk-|AKIA)[A-Za-z0-9]{16,}/g },
  { kind: 'internal-domain', re: /[a-z0-9-]+\.internal\.[a-z.]+/gi },
  { kind: 'pii-email', re: /[\w.]+@[\w.]+\.(com|cn)/gi },
];
function scanOutbound(payload) {
  const hits = [];
  for (const r of RULES) {
    let m; const re = new RegExp(r.re.source, r.re.flags);
    while ((m = re.exec(payload))) hits.push({ kind: r.kind, at: m.index, sample: m[0].slice(0, 8) + '…' });
  }
  return { allow: hits.length === 0, hits };
}
console.log(scanOutbound('contact me at bob@corp.com, key sk-abcdefghijklmnop1234').allow); // false

```

**评分点**：
- 多模式检测 + 位置定位（index）。
- 命中任一即 block（安全默认，不放行部分）。
- 类别聚合（同类多条合并计数）。
- 性能说明：正则线性扫描，超长 payload 分块（加分讨论）。
