## AIC-730：多模型协作中如何找到成本-质量的帕累托前沿

**答**：
- 结论先行：帕累托前沿 = 「在不增加成本的前提下无法再提高质量」的一组模型配置；找它是为了给不同任务挑「性价比甜点」，而不是一味选最强或最便宜。
- 做法：跑评测集得到每个模型的（成本，质量）坐标，剔除被支配点（存在另一个配置成本更低且质量更高），剩下的前沿点按任务预算挑选。
- 应用：高价值任务（支付、安全）取前沿上端，低价值任务（格式化、mock）取下端；定期重算，因为模型升级会移动前沿。
- 追问钩子：为什么「被支配的配置」一定不该用？——它有更便宜且更好的替代，选它没有任何理由，除非有前沿外的约束（如数据合规）。

```javascript
// 帕累托前沿：剔除被支配点（成本更低且质量更高者支配）
function paretoFront(configs) {
  const front = configs.filter(c =>
    !configs.some(o => o !== c && o.cost <= c.cost && o.quality >= c.quality &&
                       (o.cost < c.cost || o.quality > c.quality)));
  return front.sort((a, b) => a.cost - b.cost);
}
const cfgs = [
  { name: 'cheap', cost: 1, quality: 0.7 },
  { name: 'mid', cost: 3, quality: 0.85 },
  { name: 'strong', cost: 8, quality: 0.93 },
  { name: 'bad', cost: 5, quality: 0.8 },   // 被 mid 支配
];
console.log(paretoFront(cfgs).map(c => c.name)); // ['cheap', 'mid', 'strong']
```
