## AIC-455：笔试：实现提示词版本 diff 与「危险变更」检测。
**题目**：比较两版提示词，变更分类：新增行/删除行/修改行。若被修改或删除的行包含「输出格式/安全约束/JSON」关键词 → danger:true。输出 `{added, removed, danger, reasons}`。

```javascript
const DANGER = /输出格式|安全约束|JSON|schema/i;
function promptDiff(v1, v2) {
  const a = v1.split('\n'), b = v2.split('\n');
  const removed = a.filter(l => !b.includes(l));
  const added = b.filter(l => !a.includes(l));
  const reasons = [...removed, ...added].filter(l => DANGER.test(l));
  return { added, removed, danger: reasons.length > 0,
           reasons: reasons.map(l => `危险变更行：${l}`) };
}
console.log(promptDiff(
  '输出必须为 JSON 格式\n评审代码',
  '评审代码')); // danger: true，命中输出格式行删除

```

**评分点**：
- 逐行 LCS 或简化为集合差集——说明简化取舍即可。
- 危险关键词命中即 danger 并给出命中行内容。
- 只新增（无删改）不判危险。
- 理由数组可读（带行内容）。
