## AIC-432：笔试：实现构建产物性能预算校验。
**题目**：预算 `{firstLoadJS: 170_000}`（字节）。输入 chunk 列表 `[{name, size, firstLoad}]`，首屏合计超预算 → fail；输出 `{ok, used, budget, overBy}` 与超标 chunk 排名（按 firstLoad 降序 top3）。

```javascript
function perfBudget(chunks, budget = 170_000) {
  const used = chunks.filter(c => c.firstLoad).reduce((s, c) => s + c.size, 0);
  const overBy = used - budget;
  const top = chunks.filter(c => c.firstLoad)
    .sort((a, b) => b.size - a.size).slice(0, 3)
    .map(c => `${c.name}(${c.size})`);
  return { ok: overBy <= 0, used, budget, overBy: Math.max(0, overBy),
           suggest: overBy > 0 ? top : [] };
}
console.log(perfBudget([
  { name: 'react', size: 45_000, firstLoad: true },
  { name: 'chart', size: 140_000, firstLoad: true },
  { name: 'admin', size: 200_000, firstLoad: false },
])); // ok:false overBy 15_000，suggest [chart, react]

```

**评分点**：
- 首屏合计只累加 firstLoad 为 true 的 chunk。
- overBy = used - budget（正数），ok 判定正确。
- 超标 chunk 建议清单（top3）可执行。
- 缺 firstLoad 字段视为 false（安全默认）。
