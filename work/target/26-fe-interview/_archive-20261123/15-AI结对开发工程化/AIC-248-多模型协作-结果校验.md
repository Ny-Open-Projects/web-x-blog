## AIC-248：不同模型产出质量参差，如何建立「多模型产出统一验收」机制？
**答**：
- 验收标准与模型无关：类型检查、测试通过、lint、规范评分——统一门禁不看出身。
- 置信度传递：弱模型产出要求附带自检清单，强模型产出可简化人工抽检比例。
- 同题对照：关键任务（如迁移方案）用双模型独立产出再 diff，分歧点即人类关注点。
- 模型评分卡：按任务类型统计各模型一次通过率，季度更新路由表。

```javascript
async function ensemble(task: Task) {
  const [a, b] = await Promise.all([call('strong-max', task), call('default-balanced', task)]);
  const diff = await semanticDiff(a, b);
  return { accepted: a, humanFocus: diff.points, // 分歧点 = 需要人看的点
           passGate: await gate(a) && await gate(b === a || gate(b)) };
}
```
