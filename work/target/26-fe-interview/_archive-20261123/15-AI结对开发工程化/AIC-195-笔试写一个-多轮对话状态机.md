## AIC-195：笔试：实现一个多轮对话任务状态机：澄清/实现/验收三态流转、超时重置与非法转移拦截？
**需求**：实现 `TaskFSM`：
- 状态：clarify（澄清中）→ implementing（实现中）→ reviewing（验收中）→ done / rejected（打回回 implementing）；
- 只允许合法转移（非法转移抛错并保留原状态——防止 agent 状态跳跃导致流程失控）；
- clarify 超过 5 轮强制进入 implementing（防无限澄清）；rejected 回 implementing 时必须携带 review 意见；
- `current()` 与 `history()` 可观测。

```javascript
const TRANSITIONS = {
  clarify: ['clarify', 'implementing'],      // 澄清可多轮
  implementing: ['reviewing'],               // 实现完必须先验收
  reviewing: ['done', 'implementing'],       // 通过 or 打回
  done: [],
};

class TaskFSM {
  #state = 'clarify'; #history = [{ state: 'clarify', at: Date.now() }];
  #clarifyRounds = 1;
  #CLARIFY_MAX = 5;

  transition(to, payload = {}) {
    if (to === 'clarify') this.#clarifyRounds++;
    if (this.#state === 'clarify' && this.#clarifyRounds > this.#CLARIFY_MAX) {
      throw new Error(`澄清超 ${this.#CLARIFY_MAX} 轮，强制进入 implementing`);
    }
    const legal = TRANSITIONS[this.#state] ?? [];
    if (!legal.includes(to)) {
      throw new Error(`非法转移: ${this.#state} → ${to}（合法: ${legal.join(',')}）`);
    }
    if (this.#state === 'reviewing' && to === 'implementing' && !payload.reviewFindings?.length) {
      throw new Error('打回必须携带 review 意见，否则实现方无从修复');
    }
    this.#state = to;
    this.#history.push({ state: to, at: Date.now(), payload });
    return this.#state;
  }
  current() { return this.#state; }
  history() { return [...this.#history]; }
}

// 测试
const fsm = new TaskFSM();
fsm.transition('clarify'); fsm.transition('clarify');   // 澄清多轮
fsm.transition('implementing');
try { fsm.transition('done'); } catch (e) { console.log(e.message); } // 非法：必须先 reviewing
fsm.transition('reviewing');
try { fsm.transition('implementing'); } catch (e) { console.log(e.message); } // 打回必须带意见
fsm.transition('implementing', { reviewFindings: ['缺空态处理'] });
fsm.transition('reviewing');
fsm.transition('done');
console.log(fsm.current(), fsm.history().length); // done, 8
```

**评分点**：
1. 转移表白名单而非 if 链——新增状态只改表（可维护性）；
2. 非法转移 fail-fast 且状态不被破坏（事务性）；
3. 打回必须携带意见——「为打回而打回」会制造无信息循环（呼应 AIC-049 意见质量）；
4. 澄清轮数上限防无限澄清（agent 成本守卫，AIC-087）；
5. history 全量可观测（复盘与度量）。
