## AIC-782：AI 工具链平台化中能力即服务如何设计

**答**：
- 结论先行：能力即服务（Capability-as-a-Service）= 把每个 AI 能力（补全、审查、测试生成）封装成有明确契约、可计量、可复用的服务，业务方按需调用而非各自造轮子。
- 契约要素：1) 标准化输入输出 schema；2) SLA（延迟、成功率）；3) 计量计费（按调用/token）；4) 版本与向后兼容承诺。
- 平台职责：能力注册、发现、鉴权、限流、观测；业务方只关心「调用哪个能力、传什么参数」。
- 追问钩子：为什么能力服务必须可计量？——不可计量就无法做成本分摊与容量规划，平台会沦为免费公地被滥用。

```javascript
// 能力服务目录
const CAPABILITIES = {
  'code.review': { schema: { in: ['diff'], out: ['comments'] }, slaMs: 3000, metered: true, version: '2.1' },
  'test.generate': { schema: { in: ['file', 'coverage'], out: ['tests'] }, slaMs: 5000, metered: true, version: '1.4' },
};
function invoke(name, params, meter) {
  const cap = CAPABILITIES[name];
  if (!cap) throw new Error('capability-not-found');
  meter?.(name);                          // 计量
  return { service: name, params, version: cap.version };
}
let calls = 0;
console.log(invoke('code.review', { diff: [] }, () => calls++).version); // 2.1
console.log(calls === 1); // 已计量
```
