## AIC-735：多模型协作中涌现协作与设计协作有何区别

**答**：
- 结论先行：设计协作 = 人预先规定「谁做什么、怎么交互」（可预测、可审计，适合生产）；涌现协作 = 让多个 agent 自由交互自组织出结果（灵活但不可控，适合探索）。生产系统优先设计协作。
- 设计协作特点：职责明确、接口契约化、失败可定位；缺点是灵活性差，需要人设计编排。
- 涌现协作特点：能产生设计者没预见的解法，但行为难复现、失败难归因、成本易失控；适合创意/探索阶段，不适合关键链路。
- 追问钩子：为什么生产环境忌讳涌现协作？——不可复现意味着同样输入可能得到不同结果，无法做回归测试和事故归因。

```javascript
// 设计协作：职责与交接都在人设计的契约里
function designedCollab(task) {
  const steps = [
    { role: 'planner', out: 'plan', owner: 'model-A' },
    { role: 'coder', in: 'plan', out: 'code', owner: 'model-B' },
    { role: 'reviewer', in: 'code', out: 'report', owner: 'model-C' },
  ];
  return steps.map(s => ({ ...s, deterministic: true, traceable: true }));
}
console.log(designedCollab('login')[0].owner); // model-A，可审计
```
