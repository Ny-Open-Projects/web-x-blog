## AIC-182：笔试：实现一个 AI 产出评分卡计算器：五维加权、阈值判定、趋势对比与打回建议？
**需求**：实现 `scoreCard(scores, prev?)`：
- 五维：correctness/consistency/simplicity/security/clarity（1~5），权重 {0.3, 0.15, 0.15, 0.25, 0.15}；
- 安全是硬约束：security < 3 直接 verdict=reject（无论总分）；
- 总分 < 3.5 reject / < 4.2 revise / else pass；reject 给出最低两维的打回建议；
- prev 存在时输出各维趋势（↑↓→）。

```javascript
const WEIGHTS = {
  correctness: 0.3, consistency: 0.15, simplicity: 0.15, security: 0.25, clarity: 0.15,
};
const DIMS = Object.keys(WEIGHTS);

function scoreCard(scores, prev) {
  for (const d of DIMS) {
    if (!(d in scores)) throw new Error(`缺少维度 ${d}`);
    if (scores[d] < 1 || scores[d] > 5) throw new Error(`${d} 分值越界`);
  }
  const total = +DIMS.reduce((s, d) => s + scores[d] * WEIGHTS[d], 0).toFixed(2);
  let verdict, reasons = [];
  if (scores.security < 3) {
    verdict = 'reject';
    reasons.push(`security=${scores.security} 低于安全硬线 3，必须整改后重审`);
  } else if (total < 3.5) verdict = 'reject';
  else if (total < 4.2) verdict = 'revise';
  else verdict = 'pass';

  if (verdict === 'reject') {
    const lowest = DIMS.filter(d => d !== 'security' || scores.security >= 3)
      .sort((a, b) => scores[a] - scores[b]).slice(0, 2);
    reasons = reasons.concat(lowest.map(d => `${d}=${scores[d]}：${ADVICE[d]}`));
  }
  const trend = prev ? Object.fromEntries(DIMS.map(d =>
    [d, scores[d] > prev[d] ? '↑' : scores[d] < prev[d] ? '↓' : '→'])) : null;
  return { total, verdict, reasons, trend };
}
const ADVICE = {
  correctness: '对照契约用例逐条验证；抽查 API 是否幻觉（AIC-155）',
  consistency: '对照规则文件与 few-shot 示例重写不符段落',
  simplicity: '删除未要求的抽象与防御代码，检查夹带功能',
  clarity: '注释与实现对齐；为公共 API 补意图说明',
  security: '运行红线扫描（AIC-075）并人工复核注入面',
};

// 测试
console.log(scoreCard({ correctness: 4, consistency: 4, simplicity: 3, security: 2, clarity: 4 }));
// verdict reject（安全硬线）
console.log(scoreCard(
  { correctness: 4, consistency: 4, simplicity: 4, security: 4, clarity: 3 },
  { correctness: 4, consistency: 4, simplicity: 4, security: 4, clarity: 4 }));
// verdict revise，trend.clarity='↓'
```

**评分点**：
1. 安全硬约束独立于加权总分——加权平均会稀释安全分数，硬线不可被总分补偿；
2. reject 时给出「最低两维 + 对应建议」的可执行打回理由；
3. 分值越界 fail-fast（评分卡脏数据比没数据更糟）；
4. 趋势对比（prev）支持产出质量的时间序列分析；
5. verdict 三档（pass/revise/reject）对应不同后续动作，不是二元判定。
