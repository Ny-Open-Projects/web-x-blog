## AIC-784：AI 工具链平台的插件化架构如何设计

**答**：
- 结论先行：插件化 = 核心平台只定义扩展点与契约，能力以插件形式热插拔；关键是「稳定核心 + 不稳定插件」隔离——插件崩溃不能拖垮平台。
- 设计要点：1) 明确扩展点（命令、能力、模型适配器）；2) 插件沙箱（权限最小化、资源限额）；3) 生命周期管理（注册、启用、禁用、卸载）；4) 版本兼容校验（插件声明支持的平台版本）。
- 反模式：插件直接访问核心内部状态、无隔离共享进程——会导致插件间互相污染。
- 追问钩子：为什么插件必须声明支持的平台版本？——平台接口演进后，老插件可能不兼容；加载前校验能防止运行时崩溃。

```javascript
// 插件注册：版本兼容校验 + 生命周期
const PLATFORM_VERSION = '3.0';
const registry = {};
function register(plugin) {
  if (!plugin.apiVersion?.startsWith(PLATFORM_VERSION[0]))
    throw new Error('incompatible-api-version');
  registry[plugin.name] = { ...plugin, enabled: false };
}
function enable(name) { if (registry[name]) registry[name].enabled = true; }
register({ name: 'reviewer', apiVersion: '3.2', activate: () => {} });
enable('reviewer');
console.log(registry.reviewer.enabled); // true
try { register({ name: 'old', apiVersion: '1.0' }); } catch (e) { console.log(e.message); }
// incompatible-api-version
```
