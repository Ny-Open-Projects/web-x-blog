## AIC-722：跨模型协作中如何设计统一的上下文协议与中间表示

**答**：
- 结论先行：不同模型对 prompt 格式偏好不同（XML 标签 / Markdown / JSON），直接把 A 的输出喂给 B 会「方言不通」；解决方式是定义与模型无关的中间表示（IR），由适配器负责译成各方方言。
- 三层结构：1) IR 层（统一的「角色/任务/约束/证据」字段）；2) Adapter 层（IR→各模型 prompt）；3) 归一化层（各模型输出→结构化结果）。
- 收益：换模型只改 Adapter，不动业务；上下文能在模型间无损传递（RBL-249）。
- 追问钩子：为什么不让模型直接读上一模型的原始输出？——原始输出含方言与噪声，会污染下游；IR 保证语义清晰、格式稳定。

```typescript
// 统一中间表示 IR + 模型适配器
type IR = { role: string; task: string; constraints: string[]; evidence: string[] };
function toPrompt(ir: IR, style: 'xml' | 'md'): string {
  if (style === 'xml')
    return `<role>${ir.role}</role><task>${ir.task}</task><constraints>${ir.constraints.join(',')}</constraints>`;
  return `角色：${ir.role}\n任务：${ir.task}\n约束：${ir.constraints.join('、')}`;
}
const ir: IR = { role: 'reviewer', task: '查空指针', constraints: ['只看 diff'], evidence: ['a.ts:10'] };
console.log(toPrompt(ir, 'xml')); // <role>reviewer</role>...
console.log(toPrompt(ir, 'md'));   // 角色：reviewer
任务：查空指针...
```
