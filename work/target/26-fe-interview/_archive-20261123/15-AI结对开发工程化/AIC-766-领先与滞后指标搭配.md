## AIC-766：AI 效能度量中领先指标与滞后指标如何搭配

**答**：
- 结论先行：领先指标（如「任务启动到首版产出时间」）能快速反馈但不一定代表最终结果；滞后指标（如「缺陷逃逸率」「交付周期」）真实但反馈慢；两者搭配才能既快速调优又锚定真实价值。
- 典型配对：领先（生成时长、返工轮数、采纳率）↔ 滞后（逃逸率、线上事故、NPS）；用领先指标做日常迭代，用滞后指标做季度复盘与方向校验。
- 陷阱：只看领先指标会「优化局部动作而非最终结果」（如追求采纳率却损害质量）；滞后指标恶化时要回溯领先指标找根因。
- 追问钩子：为什么滞后指标不能被领先指标替代？——领先指标只是「可能导向好结果的行为」，因果链未必成立，必须用滞后指标验证。

```javascript
// 双指标看板：领先异常预警，滞后确认价值
function healthCheck(leading, lagging) {
  const signals = [];
  if (leading.rework > 2) signals.push('返工偏高：检查 prompt/上下文');
  if (lagging.escapeRate > 0.05) signals.push('逃逸恶化：领先指标优化未转化为价值');
  return { signals, verdict: lagging.escapeRate <= 0.05 ? 'value-delivered' : 'value-at-risk' };
}
console.log(healthCheck({ rework: 3 }, { escapeRate: 0.02 }).signals); // ['返工偏高...']
console.log(healthCheck({ rework: 1 }, { escapeRate: 0.08 }).verdict); // value-at-risk
```
