## AIC-270：不同模型的上下文偏好差异（有的吃 markdown 有的吃 XML 标签），如何适配？
**答**：
- 抽象模板层：上下文以中立结构（sections）定义，渲染层按目标模型输出其偏好格式。
- 适配实验驱动：用基准测各模型在各格式下的遵循率，确定映射表（如 modelX 偏 XML 包裹）。
- 切换零成本：因为上下文结构中立，换模型只换渲染器，内容资产（规则/任务卡）不变。
- 持续校准：模型版本更新可能改变格式偏好，季度重跑格式基准。

```javascript
const renderer = {
  neutral: sections({ rules, task, examples }),
  render: { modelA: toXML(sections), modelB: toMarkdown(sections) },
  calibration: '季度格式基准：遵循率下降 > 5% 更新映射表',
};
```
