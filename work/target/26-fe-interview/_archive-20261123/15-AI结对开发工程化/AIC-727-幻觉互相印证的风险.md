## AIC-727：多模型协作中如何避免模型幻觉互相印证

**答**：
- 结论先行：多个模型若看到相同上下文/相同 prompt 措辞，容易产生「相关幻觉」——都基于同一错误前提给出一致结论，一致性反而制造虚假信心；多样性不是模型数量，而是「视角独立性」。
- 破解手段：1) 给不同模型不同的 prompt 框架（一个找支持证据、一个找反例）；2) 注入不同上下文切片；3) 要求引用可验证来源，无来源的结论不计入共识。
- 关键：一致性只能增强「独立且可验证」的结论；对无来源的一致结论要保持怀疑。
- 追问钩子：为什么「多模型一致」不等于「正确」？——一致可能来自共同的错误前提而非事实，需要外部证据校准。

```javascript
// 反相关幻觉：要求每个结论带可验证来源，无来源不计入共识
function corroborate(results) {
  const sourced = results.filter(r => r.source);              // 只有带来源的才算
  const claims = {};
  sourced.forEach(r => claims[r.claim] = (claims[r.claim] ?? 0) + 1);
  const consensus = Object.entries(claims).filter(([, n]) => n >= 2).map(([c]) => c);
  return { consensus, ignored: results.length - sourced.length };
}
console.log(corroborate([
  { claim: 'API 已弃用', source: 'changelog' },
  { claim: 'API 已弃用', source: 'changelog' },   // 同来源，需注意仍可能同源错误
  { claim: '性能差', source: null },              // 无来源，忽略
]).consensus); // ['API 已弃用']，但需检查两来源是否真正独立
```
