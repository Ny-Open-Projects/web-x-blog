## AIC-153：笔试：实现一个敏感信息扫描器，扫描 prompt 与 diff 中的密钥/PII/内网信息并输出脱敏建议？
**需求**：实现 `scanSensitive(text)`：
- 检测：通用 API key 模式（sk-/ghp_/AKIA）、手机号、身份证（18 位含校验位粗验）、内网 IP（10./172.16-31./192.168.）、私钥块、JWT；
- 输出 `{findings: [{type, snippet, masked}], risk}`，snippet 脱敏展示（保留首尾 4 字符）；
- 支持白名单排除（如测试环境固定测试号）。

```javascript
const RULES = [
  { type: 'api-key', re: /\b(?:sk-|ghp_|github_pat_)[A-Za-z0-9_]{20,}|AKIA[0-9A-Z]{16}\b/g },
  { type: 'jwt', re: /\beyJ[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}\b/g },
  { type: 'private-key', re: /-----BEGIN (?:RSA )?PRIVATE KEY-----/g },
  { type: 'phone', re: /1[3-9]\d{9}/g },
  { type: 'idcard', re: /\b[1-9]\d{5}(?:19|20)\d{2}(?:0[1-9]|1[0-2])(?:[0-2]\d|3[01])\d{3}[\dXx]\b/g },
  { type: 'intranet', re: /\b(?:10\.\d{1,3}|172\.(?:1[6-9]|2\d|3[01])|192\.168)\.\d{1,3}\.\d{1,3}\b/g },
];

function mask(s) {
  return s.length <= 8 ? '*'.repeat(s.length) : s.slice(0, 4) + '*'.repeat(s.length - 8) + s.slice(-4);
}

function scanSensitive(text, { allow = [] } = {}) {
  const findings = [];
  for (const rule of RULES) {
    for (const m of text.matchAll(rule.re)) {
      const raw = m[0];
      if (allow.some(w => (w instanceof RegExp ? w.test(raw) : w === raw))) continue; // 白名单
      findings.push({ type: rule.type, snippet: mask(raw), position: m.index });
    }
  }
  const risk = findings.some(f => ['api-key', 'private-key', 'jwt'].includes(f.type))
    ? 'P0_BLOCK' : findings.length ? 'P1_MASK' : 'CLEAN';
  return { findings, risk };
}

// 测试
const t = '用户 13812345678 报错，来自 10.2.3.4，token=eyJhbGciOiJIUzI1NiJ9.abc.def';
console.log(scanSensitive(t, { allow: [/^13812345678$/] }));
// 仅 jwt(P0_BLOCK) + intranet；手机号被白名单排除
```

**评分点**：
1. P0（可外泄凭据）与 P1（PII/内网）分级处理：P0 阻断、P1 脱敏放行——只有一刀切说明没想清流程；
2. 身份证要写日期段合法性粗验（01-12 月、01-31 日），纯 18 位数字正则会误报；
3. 白名单必须支持正则（测试数据场景）且作用在「命中片段」级别；
4. snippet 展示必须脱敏——扫描器本身不能变成泄漏源，这是安全工器具的自我修养；
5. JWT 前缀 eyJ（base64 的 {"）能识别加分。
