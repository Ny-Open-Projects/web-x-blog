## AIC-911：笔试：实现「确定性重放器」（固定随机源/时间/ID 生成器，让 AI 产出可复现）
**答**：
- 核心需求：实现 `withDeterminism(fn, opts)`，在 fn 执行期间临时替换全局 `Math.random`、`Date.now`、`crypto.randomUUID` 为可复现的伪实现，执行后必须恢复原函数（即使 fn 抛错也要恢复）。
- opts.seed 决定伪随机序列：用线性同余发生器（LCG）保证同 seed 产出同序列；`Date.now` 返回固定基准时间；`randomUUID` 返回基于递增计数器的确定性字符串。
- 边界：嵌套调用要支持（保存/恢复栈式管理）；fn 返回值原样透传；禁止污染其他并发任务——通过「执行期替换、结束即还原」把影响限制在同步调用窗口。
- 语义：这是「治理工程侧不确定性」的手段，让 AI 生成代码在同一 seed 下结果一致、易于 diff——但重放不保证代码本身正确。
- 追问钩子：能主动提出「try/finally 保证恢复」「同步窗口内有效、异步任务需另行处理」的候选人，对副作用管理有工程警觉。

```typescript
function withDeterminism(fn, opts = {}) {
  const seed = opts.seed ?? 42, base = opts.now ?? 1700000000000;
  let s = seed >>> 0, idc = 0;
  const origRandom = Math.random, origNow = Date.now, origUuid = crypto.randomUUID;
  const lcg = () => (s = (Math.imul(s, 1664525) + 1013904223) >>> 0) / 4294967296;
  Math.random = lcg;
  Date.now = () => base;
  crypto.randomUUID = () => 'id-' + (++idc).toString(16).padStart(8, '0');
  try { return fn(); }
  finally { Math.random = origRandom; Date.now = origNow; crypto.randomUUID = origUuid; }
}
console.log(withDeterminism(() => [Math.random(), Date.now(), crypto.randomUUID()], {seed:1}));
console.log(withDeterminism(() => [Math.random(), Date.now(), crypto.randomUUID()], {seed:1})); // 完全一致
```
**评分点**：
- 用 LCG 等可复现伪随机实现 Math.random，同 seed 同序列。
- Date.now 返回固定基准时间、randomUUID 用递增计数器，均确定性。
- try/finally 保证三个全局函数在异常时也恢复原值，不污染后续调用。
- fn 返回值原样透传，seed/now 可配置。
- 能说明同步窗口限制与「重放≠正确性」（加分项）。
