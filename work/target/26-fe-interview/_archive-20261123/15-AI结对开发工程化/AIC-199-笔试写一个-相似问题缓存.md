## AIC-199：笔试：实现一个相似问题缓存：语义指纹去重、精确匹配优先、TTL 与命中率统计？
**需求**：实现 `SimCache`：
- L1 精确缓存：prompt 原文 hash 为 key；
- L2 相似缓存：归一化文本（小写/去空白/去标点）+ 词集合 Jaccard ≥ 0.9 视为相似（扫最近 200 条）；
- TTL 过期失效；写入淘汰最旧（容量上限）；
- `stats()`：hit/exact/semantic/miss 计数与命中率。

```javascript
import { createHash } from 'crypto';

class SimCache {
  #exact = new Map(); #recent = []; #stats = { hit: 0, exact: 0, semantic: 0, miss: 0 };
  constructor({ ttlMs = 3600_000, capacity = 200 } = {}) {
    this.ttl = ttlMs; this.capacity = capacity;
  }
  #norm(s) { return s.toLowerCase().replace(/[\s\p{P}]+/gu, ' ').trim(); }
  #jaccard(a, b) {
    const A = new Set(a), B = new Set(b);
    let i = 0; for (const x of A) if (B.has(x)) i++;
    return i / (A.size + B.size - i || 1);
  }
  get(prompt) {
    const now = Date.now();
    const key = createHash('sha1').update(prompt).digest('hex');
    const e = this.#exact.get(key);
    if (e && now - e.at < this.ttl) { this.#stats.hit++; this.#stats.exact++; return e.answer; }

    const words = this.#norm(prompt).split(' ');
    for (const r of this.#recent) {
      if (now - r.at >= this.ttl) continue;
      if (this.#jaccard(words, r.words) >= 0.9) {
        this.#stats.hit++; this.#stats.semantic++;
        return r.answer;
      }
    }
    this.#stats.miss++;
    return null;
  }
  set(prompt, answer) {
    const key = createHash('sha1').update(prompt).digest('hex');
    const at = Date.now();
    this.#exact.set(key, { answer, at });
    this.#recent.push({ prompt, words: this.#norm(prompt).split(' '), answer, at });
    while (this.#recent.length > this.capacity) this.#recent.shift(); // 容量淘汰
  }
  stats() {
    const s = this.#stats;
    const total = s.hit + s.miss;
    return { ...s, rate: total ? +(s.hit / total).toFixed(3) : 0 };
  }
}

// 测试
const c = new SimCache();
c.set('帮我实现 debounce 函数', 'code-debounce');
console.log(c.get('帮我实现 debounce 函数'));      // exact hit
console.log(c.get('帮我实现 debounce 函数！'));     // semantic hit（归一化后几乎一致）
console.log(c.get('写一个防抖 hook'));              // miss
console.log(c.stats());                             // rate ≈ 0.667
```

**评分点**：
1. 两级结构：精确 hash O(1) 命中优先，相似层才是模糊匹配（性能分层）；
2. 归一化与 Jaccard 阈值合理（0.9 只抓近乎相同的问题，防错误复用答案）；
3. TTL 与容量双淘汰；过期条目读取时惰性剔除也可（说清取舍）；
4. 命中率统计分 exact/semantic——语义命中要人工抽检防「相似但不同义」误命中；
5. 追问：缓存只适用于确定性任务（temperature=0），并要可按 prompt 版本失效。
