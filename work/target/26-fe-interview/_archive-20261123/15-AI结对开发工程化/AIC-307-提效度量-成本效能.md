## AIC-307：「每元 AI 成本产出多少有效变更」怎么算？分母怎么定义才不掺水？
**答**：
- 分母用「有效变更」：过门禁合入且 30 天内未回滚的 PR，剔除垃圾产出。
- 分子为全成本：模型 API + 工具席位 + 自建基础设施分摊 + 评审算力。
- 分层计算：按任务类型（补全/生成/评审）分别计算成本效能，指导预算分配到高 ROI 场景。
- 趋势比绝对值重要：单位成本效能环比改善反映工具链优化方向正确。

```javascript
function costEfficiency(billing: Bill, prs: PR[]) {
  const effective = prs.filter(p => p.merged && !p.revertedIn30d);
  const totalCost = billing.api + billing.seats + billing.infra;
  return { perEffectivePR: totalCost / effective.length,
           byType: groupBy(effective, p => p.aiTaskType) };
}
```
