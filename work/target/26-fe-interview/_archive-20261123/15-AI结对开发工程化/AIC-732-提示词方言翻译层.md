## AIC-732：多模型协作中提示词方言的翻译层如何设计

**答**：
- 结论先行：同一语义在不同模型上要写成不同「方言」（Claude 偏 XML 标签、GPT 偏 Markdown 分段、国产模型偏中文指令）；翻译层把「一次编写」转成「多模型适配」，避免为每个模型维护一套 prompt。
- 设计要点：1) 定义与模型无关的结构化意图（任务、上下文、约束、输出格式）；2) 每个模型一个 renderer；3) 翻译层要保留语义、只改格式，并做「往返校验」。
- 注意：不要只做字符串替换——不同模型对「否定指令」「few-shot 位置」敏感度不同，翻译要包含策略适配。
- 追问钩子：为什么翻译后要做「往返校验」？——把翻译结果解析回结构化意图，确认没有丢失约束，防止格式转换引入语义漂移。

```javascript
// 方言翻译层：结构化意图 → 各模型 prompt
const INTENT = { task: '审查 diff', constraints: ['只看变更行', '输出 JSON'] };
function render(intent, dialect) {
  const c = intent.constraints.join(dialect === 'xml' ? '</c><c>' : '；');
  if (dialect === 'xml') return `<task>${intent.task}</task><c>${c}</c>`;
  if (dialect === 'md') return `## 任务\n${intent.task}\n## 约束\n${c}`;
  return `任务：${intent.task}；约束：${c}`;
}
console.log(render(INTENT, 'xml')); // <task>审查 diff</task><c>只看变更行</c><c>输出 JSON</c>
console.log(render(INTENT, 'md'));  // ## 任务
审查 diff
## 约束
只看变更行；输出 JSON
```
