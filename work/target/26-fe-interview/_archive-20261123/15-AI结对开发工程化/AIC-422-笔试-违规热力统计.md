## AIC-422：笔试：按目录统计 AI 产出违规，输出治理优先级。
**题目**：输入违规 `[{dir, rule}]` 与各目录 churn（改动频率）。优先级 = 违规数 × churn，输出排序后 top5 与「低 churn 高违规」的挂账清单（churn < 0.1 且违规 > 5）。

```javascript
function priority(dirs, violations) {
  const cnt = new Map();
  for (const v of violations) cnt.set(v.dir, (cnt.get(v.dir) || 0) + 1);
  const scored = [...cnt].map(([dir, n]) => ({ dir, n, churn: dirs[dir]?.churn ?? 0,
    score: n * (dirs[dir]?.churn ?? 0) }))
    .sort((a, b) => b.score - a.score || a.dir.localeCompare(b.dir));
  return {
    hot: scored.slice(0, 5),
    frozenDebt: scored.filter(s => s.churn < 0.1 && s.n > 5),
  };
}
console.log(priority({ 'src/a': { churn: 0.8 }, 'src/b': { churn: 0.05 } },
  [...Array(10).fill({ dir: 'src/a', rule: 'x' }), ...Array(8).fill({ dir: 'src/b', rule: 'y' })]));
// hot: src/a；frozenDebt: src/b（低 churn 高违规挂账）

```

**评分点**：
- 乘法排序 + 挂账清单双输出——治理策略分层。
- 排序稳定性（同分按目录名）。
- churn 缺省按 0 处理（不参与热区）。
- top5 用 slice 不改原数组。
