## AIC-298：工具选型后如何持续收集开发者真实反馈而不只看指标？
**答**：
- 嵌入式反馈：产出质量一键评分（好/一般/差）+ 可选一句话原因，顺手不打断。
- 季度深访：分层抽样访谈（重度/轻度/弃用用户），弃用原因是金矿。
- 行为数据与主观感受交叉：接受率高但评分低的场景（如被迫接受错误建议）要挖出来。
- 反馈闭环公示：每月「你反馈 → 我们改了什么」公告，维持反馈意愿。

const feedbackLoop = {
  inline: { rating: [1, 2, 3], note: 'optional', cost: '< 3s' },
  interviews: { cadence: 'quarterly', sample: ['power', 'light', 'churned'] },
  crossCheck: 'acceptRate 高 + rating 低 → 定向排查场景',
  publicize: 'monthly changelog: user feedback → shipped fix',
};
