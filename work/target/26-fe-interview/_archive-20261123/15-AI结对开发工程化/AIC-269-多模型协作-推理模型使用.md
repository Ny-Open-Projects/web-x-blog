## AIC-269：推理型模型（深度思考类）与普通模型如何分工使用，避免「杀鸡用牛刀」？
**答**：
- 推理模型适合：多步推理（复杂 debug/算法设计/方案推演），其优势在「思考深度」。
- 普通模型适合：代码生成/补全/格式转换——生成类任务推理模型反而慢且贵。
- 触发式使用：普通模型产出失败（测试不过/人否定）后，升级到推理模型重试。
- 混合流水线示例：普通模型写实现 → 测试失败 → 推理模型分析根因 → 普通模型按根因修改。

```javascript
async function tiered(task: Task) {
  let out = await fast(task);
  if (!await gate(out)) {
    const rootCause = await reasoning(`实现未通过验收：${gate.diff(out)}，分析根因`);
    out = await fast(`按以下根因修复：${rootCause}`);
  }
  return out;
}
```
