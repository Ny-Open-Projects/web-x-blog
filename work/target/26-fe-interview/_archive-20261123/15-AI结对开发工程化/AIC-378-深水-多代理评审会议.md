## AIC-378：用多个 AI 代理模拟「架构评审会」（安全官/性能官/可维护性官），可行吗？
**答**：
- 可行且有价值的部分：多角色并行检查比单提示全面（每个角色有专属清单与知识源），结论汇总成结构化报告。
- 局限：角色「辩论」的戏剧性大于实效，交叉质疑消耗大且容易形式主义——建议并行独立评审 + 人工汇总。
- 适用场景：重要架构决策的「预审」，生成多视角风险清单供评审会高效讨论。
- 成本控制：角色数 ≤ 3，只在重大决策启用，日常 PR 用单角色评审。

```javascript
const panel = {
  roles: ['security', 'perf', 'maintainability'].map(r => review(r, diff)),
  summary: '人工汇总多视角清单（并行独立优于辩论）',
  when: '仅重大架构决策启用，PR 日常单角色',
};
r
```
