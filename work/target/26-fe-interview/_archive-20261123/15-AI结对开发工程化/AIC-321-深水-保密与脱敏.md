## AIC-321：用云端 AI 编码工具时，如何建立「数据脱敏层」既保安全又不毁上下文？
**答**：
- 分级脱敏：密钥/凭证一律剥离（正则+密钥扫描器），内部域名/IP 做映射替换（api.internal.example → api.int），核心算法标识改名。
- 映射表本地保存，响应回来后本地还原——模型看到的是别名但结构完整。
- 脱敏不毁语义：保住变量用途、类型结构、控制流，只换可识别信息。
- 旁路校验：脱敏层后接泄漏扫描（出站 payload 再扫一遍密钥特征），双保险。

```javascript
const desens = {
  keys: /(?:sk-|AKIA)[A-Za-z0-9]{16,}/g,        // 直接剥离
  domain: s => s.replaceAll('api.internal.byted', 'api.int'), // 映射替换
  restore: s => s.replaceAll('api.int', 'api.internal.byted'), // 本地还原
  outbound: p => leakScan(p) ? abort() : send(desensAll(p)),    // 双保险
};
```
