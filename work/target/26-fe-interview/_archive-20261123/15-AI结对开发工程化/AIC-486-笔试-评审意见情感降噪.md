## AIC-486：笔试：合并同一问题的重复评审意见（跨 commit 持续存在）。
**题目**：意见流 `[{id, commit, file, line, message}]`（按 commit 序）。同 file+±3 行+相似 message（前 10 字相同）视为同一问题持续：只保留首条并标记 `persisted: [commits]`。

```javascript
function dedupeAcrossCommits(findings) {
  const out = [];
  for (const f of findings) {
    const hit = out.find(o => o.file === f.file && Math.abs(o.line - f.line) <= 3
      && o.message.slice(0, 10) === f.message.slice(0, 10));
    if (hit) hit.persisted.push(f.commit);
    else out.push({ ...f, persisted: [] });
  }
  return out;
}
console.log(dedupeAcrossCommits([
  { id: 1, commit: 'c1', file: 'a.ts', line: 10, message: 'NPE risk here' },
  { id: 2, commit: 'c2', file: 'a.ts', line: 12, message: 'NPE risk there still' },
])); // 合并为 1 条，persisted [c2]

```

**评分点**：
- 跨 commit 归并（不是同 commit 内去重）。
- persisted 记录经历过的 commit 列表（持续未修证据）。
- message 相似度用前缀比较（简化，说明可用 embedding 改进）。
- 输出按首次出现顺序。
