## AIC-775：如何构建团队 AI 效能的健康度综合指数

**答**：
- 结论先行：健康度指数 = 把效率、质量、成本、采纳、公平等多维指标归一化后加权成单一分数，用于「一眼看健康」和趋势追踪；但单一指数不能替代分维度下钻，否则会掩盖结构性问题。
- 构建：1) 各维度归一到 0-100；2) 设定权重（质量红线维度权重更高或设一票否决）；3) 输出总分 + 各维度雷达图；4) 指数要能下钻到具体维度找问题。
- 陷阱：加权平均会掩盖短板（效率 90、质量 30 也能得 60）——关键维度必须设红线或乘性因子。
- 追问钩子：为什么「加权平均」不适合健康度？——它允许用高分维度抵消致命短板；健康度应反映「最弱环节」，可用乘性或红线制。

```javascript
// 健康度：乘性因子惩罚短板
function healthIndex(dims) {
  const { efficiency, quality, cost, adoption } = dims; // 各 0-100
  const avg = (efficiency + quality + cost + adoption) / 4;
  const min = Math.min(efficiency, quality, cost, adoption);
  return Math.round(avg * (0.5 + 0.5 * (min / 100))); // 短板越强，总分折扣越大
}
console.log(healthIndex({ efficiency: 90, quality: 30, cost: 80, adoption: 85 }));
// avg=71.25, min=30 → 71.25*0.65≈46，短板被放大
console.log(healthIndex({ efficiency: 85, quality: 85, cost: 80, adoption: 85 })); // 均衡→高分
```
