## AIC-725：如何用小模型预筛选、大模型精加工构建两级协作

**答**：
- 结论先行：两级协作 = 用便宜小模型做「量大但简单」的粗筛（分类、抽取、初判），只把「难而少」的候选交给贵模型精加工——用成本结构换整体质量。
- 适用条件：任务可分「易/难」两层，且小模型在易层有足够准确率（如 >90%）；若小模型误杀率高，粗筛反而漏掉关键项。
- 设计要点：预筛选要「宽进」（宁可多留候选也别误杀），精加工只做最后决策；用小模型给候选打轻量分，按分排序取 top-N 进精加工。
- 追问钩子：为什么预筛选要「宽进」而非「严选」？——漏杀的候选永远没有第二次机会，而多留的候选只是多花一点精加工成本。

```javascript
// 两级协作：小模型宽进预筛，大模型精加工 top-N
function twoStage(items, smallScore, bigJudge, topN = 3) {
  const candidates = items.map(x => ({ x, s: smallScore(x) })).sort((a, b) => b.s - a.s);
  const shortlist = candidates.slice(0, topN).map(c => c.x); // 宽进：取分最高的 N 个
  return shortlist.map(x => ({ x, verdict: bigJudge(x) })); // 精加工
}
const items = ['login', 'list', 'pay', 'button'];
console.log(twoStage(items, s => s.length, s => 'checked:' + s, 2).map(r => r.verdict));
// ['checked:button', 'checked:login'] —— 小模型按长度粗排，大模型精判
```
