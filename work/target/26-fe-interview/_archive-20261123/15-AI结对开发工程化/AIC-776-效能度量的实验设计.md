## AIC-776：AI 效能度量的实验设计如何设置对照组

**答**：
- 结论先行：要证明「AI 带来提升」必须做对照实验——随机把团队/任务分到实验组（用 AI）和对照组（不用），控制其他变量，比较结果差异；否则无法排除时间趋势、学习效应等混淆因素。
- 设计要点：1) 随机分配且样本量足够；2) 组间任务难度、人员经验可比（分层随机）；3) 明确单一主指标 + guardrail 指标（质量红线）；4) 实验周期覆盖学习曲线，避免只看新鲜期。
- 现实约束：团队级很难完美随机，可用「交错实验」（不同周切换 AI 开关）或「合成对照」（历史相似团队）近似，但要标注证据强度。
- 追问钩子：为什么实验周期要覆盖学习曲线？——AI 提效往往在熟练后显现，短期实验可能低估效果或高估新鲜感带来的数字。

```javascript
// 分层随机：按任务难度分层后再随机分组，保证可比
function stratifiedAssign(tasks, seed = 1) {
  const groups = { control: [], treatment: [] };
  const byLevel = {};
  tasks.forEach(t => (byLevel[t.level] ??= []).push(t));
  let s = seed;
  const rnd = () => (s = (s * 9301 + 49297) % 233280) / 233280; // 可复现随机
  for (const list of Object.values(byLevel)) {
    for (const t of list) groups[rnd() < 0.5 ? 'control' : 'treatment'].push(t.id);
  }
  return groups;
}
const g = stratifiedAssign([{ id: 1, level: 'easy' }, { id: 2, level: 'easy' }, { id: 3, level: 'hard' }, { id: 4, level: 'hard' }]);
console.log(g.control.length + g.treatment.length === 4); // 全覆盖且分层
```
