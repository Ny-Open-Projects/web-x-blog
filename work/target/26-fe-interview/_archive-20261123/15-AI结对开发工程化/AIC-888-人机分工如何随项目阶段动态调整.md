## AIC-888：项目早期和收尾期，人和 AI 的分工应该一样吗？
**答**：
- 不该一样。**分工应随「不确定性」和「风险」动态调整**：早期不确定性高（需求模糊、架构未定），人主导探索与决策，AI 做信息搜集与原型；中期确定性高（任务清晰），AI 主导实现，人做 review；收尾期风险高（集成、上线），人主导验证与把关，AI 做回归与文档。
- 一个判断框架：把任务按「**探索性 × 风险性**」分象限——高探索（人主导，AI 辅助）、高重复（AI 主导，人把关）、高风险（人主导且加倍验证）、低风险低探索（AI 全自动）。
- 动态调整的信号：需求变更频率、缺陷发现率、AI 产出存活率——这些指标变化时重新评估分工，而不是一开始就定死。
- 人的角色始终是**设定目标、定义约束、验证结果、承担决策**；AI 的角色是**加速执行与探索选项**。分工变的是比例，不是责任归属（AIC-882）。
- 追问钩子：能给出「按探索性 × 风险性分象限动态分工」且强调「责任归属不变」的候选人，既有框架又有边界意识。

```typescript
type Task = { name: string; exploratory: number; risk: number; phase: string };

function assign(task: Task) {
  if (task.risk >= 0.7) return { lead:'human', aiRole:'仅辅助验证/文档', note:'高风险，人主导且加倍验证' };
  if (task.exploratory >= 0.7) return { lead:'human', aiRole:'搜集信息/生成原型', note:'高探索，人做决策' };
  if (task.phase === 'closing') return { lead:'human', aiRole:'回归测试/文档', note:'收尾期人把关' };
  return { lead:'ai', aiRole:'主导实现', note:'低风险低探索，AI 主导人 review' };
}
console.log(assign({ name:'支付重构', exploratory:0.3, risk:0.9, phase:'mid' }).lead);          // human
console.log(assign({ name:'列表页 CRUD', exploratory:0.2, risk:0.2, phase:'mid' }).lead);      // ai
console.log(assign({ name:'新交互探索', exploratory:0.9, risk:0.2, phase:'early' }).lead);     // human
// 责任归属永远是人，分工只是执行比例
```
