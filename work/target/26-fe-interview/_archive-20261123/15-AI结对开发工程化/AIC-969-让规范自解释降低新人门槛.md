## AIC-969：新人看不懂一堆 AI 规范条目，如何让规范「自解释」降低上手门槛？
**答**：
- 每条规范都要回答「为什么」而不只是「必须怎么做」：写清它防范的风险/事故案例——结论：理解原因的人才会在规则未覆盖的场景做出正确判断。
- 给规范配「正例/反例」代码片段：新人看一眼就知道怎么改；反例最好来自团队真实事故（脱敏后），有说服力。
- 把规范做成「可交互的」：新人写第一段代码时，IDE 提示直接链接到对应规范说明与示例；规范即文档、即教程。
- 追问钩子：能提出「规范的成熟度看『新人能否在无老人帮助下单据规范独立完成第一个 PR』」的候选人，把可上手性当成了规范的验收标准。

```typescript
// 自解释规范：规则 + 原因 + 正反例
const RULE = {
  id:'PRICE-INT',
  must:'金额用整数分存储',
  why:'浮点计算在大促对账时出现过 0.01 元误差（事故 INC-2042）',
  good:'const cents = Math.round(price * 100);',
  bad:'const price = 19.99; price * 3 // 59.969999...',
};
function explain(rule) {
  return [`【${rule.id}】${rule.must}`,
    `原因：${rule.why}`, `✓ ${rule.good}`, `✗ ${rule.bad}`].join('\n');
}
console.log(explain(RULE)); // 新人一眼看懂，且知道为何
```
