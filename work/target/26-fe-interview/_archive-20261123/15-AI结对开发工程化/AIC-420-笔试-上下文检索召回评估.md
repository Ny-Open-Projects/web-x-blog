## AIC-420：笔试：实现上下文检索的召回率/精确率评估器。
**题目**：给定标注的必要文件集 groundTruth 与检索结果 retrieved：计算 recall、precision、F1（保留 3 位），并输出漏检文件清单（用于改进检索）。

```javascript
function evalRetrieval(truth, retrieved) {
  const t = new Set(truth), r = new Set(retrieved);
  const hit = [...t].filter(f => r.has(f));
  const recall = t.size ? hit.length / t.size : 1;
  const precision = r.size ? hit.length / r.size : 0;
  const f1 = recall + precision ? 2 * recall * precision / (recall + precision) : 0;
  return { recall: +recall.toFixed(3), precision: +precision.toFixed(3),
           f1: +f1.toFixed(3), missed: [...t].filter(f => !r.has(f)) };
}
console.log(evalRetrieval(['a.ts', 'b.ts', 'c.ts'], ['a.ts', 'd.ts']));
// recall .333 precision .5 f1 .4 missed: [b.ts, c.ts]

```

**评分点**：
- 集合运算正确（交集/漏检=truth-retrieved）。
- F1 公式正确，除零保护。
- 漏检清单输出——评估要能指导改进。
- 支持多个任务的聚合平均。
