## AIC-374：让两个模型评审同一 PR，一个说有问题一个说没问题——这类「评审分歧」如何系统性处理？
**答**：
- 分歧即信号：分歧条目直接进入人工评审重点清单（分歧处往往是最微妙的问题）。
- 分歧分类：事实分歧（代码行为判断错）→ 用测试/运行验证；标准分歧（规范理解不同）→ 规范文档澄清。
- 裁判机制：第三模型或更强模型做仲裁，仲裁历史沉淀为评审规则的补充说明。
- 分歧率监控：某类问题分歧率持续高 → 说明规范模糊，推动规范写清楚。

```javascript
async function reviewDisagree(a: Finding[], b: Finding[]) {
  const both = intersect(a, b), only = symmetricDiff(a, b);
  const arbitrated = await judge(only);        // 第三方仲裁
  return { consensus: both, humanFocus: arbitrated.uncertain, resolved: arbitrated.clear };
}
```
