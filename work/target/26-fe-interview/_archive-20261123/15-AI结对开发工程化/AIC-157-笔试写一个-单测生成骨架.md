## AIC-157：笔试：实现一个单测生成骨架器，从函数签名推导用例矩阵（正常/边界/异常）并生成 vitest 代码？
**需求**：实现 `genTestSkeleton(fnName, params, returns)`：
- params: `[{name, type: 'string'|'number'|'array'|'object', required}]`；
- 按 type 生成正常值 + 边界值（string: 空串/超长；number: 0/-1/MAX/NaN；array: 空/大数组；object: null/空对象）；
- required=false 的参数额外生成「缺省用例」；
- 产出可运行的 vitest 骨架（断言占位待人工填）。

```javascript
const EDGE = {
  string: ['', 'a'.repeat(10000)],
  number: [0, -1, Number.MAX_SAFE_INTEGER, NaN],
  array: [[], Array.from({ length: 1000 }, (_, i) => i)],
  object: [{}, null],
};

function casesFor(p) {
  const normal = { string: 'abc', number: 5, array: [1, 2], object: { a: 1 } }[p.type];
  const list = [[normal, '正常值'], ...EDGE[p.type].map(v => [v, '边界值'])];
  if (!p.required) list.push([undefined, '缺省']);
  return list;
}

function genTestSkeleton(fnName, params, returns) {
  const lines = [];
  for (const p of params) {
    for (const [val, kind] of casesFor(p)) {
      const call = params.map(q => q === p ? fmt(val) : fmt(defaults(q)))
        .join(', ');
      lines.push(`  it('${fnName}: ${p.name}=${kind}', () => {
    // TODO 人工确认断言
    expect(${fnName}(${call})).${returns === 'void' ? 'not.toThrow()' : `toBe(/* ${returns} */)`});
  });`);
    }
  }
  return `import { describe, it, expect } from 'vitest';
import { ${fnName} } from './${fnName}';

describe('${fnName}', () => {
${lines.join('\n')}
});
`;
}
function defaults(p) {
  return { string: 'x', number: 1, array: [], object: {} }[p.type];
}
function fmt(v) {
  return v === undefined ? 'undefined' : JSON.stringify(v) ?? 'NaN';
}
// 注意 JSON.stringify(NaN) 为 'null'，需要特判
function fmtSafe(v) {
  if (Number.isNaN(v)) return 'NaN';
  return v === undefined ? 'undefined' : JSON.stringify(v);
}

// 测试
console.log(genTestSkeleton('calcDiscount',
  [{ name: 'cart', type: 'object', required: true }, { name: 'rate', type: 'number', required: false }],
  'number'));
// 输出含 cart 的 4 类用例 + rate 的 6 类用例（含缺省）
```

**评分点**：
1. 用例矩阵按「参数 × 正常/边界/缺省」展开，覆盖缺省用例（required=false）是完整性标志；
2. NaN 的序列化陷阱（JSON.stringify(NaN)→'null'）能避开说明 JS 基本功扎实；
3. 生成的是「骨架」而非终稿——断言留 TODO 让人工填业务期望，直接生成断言会污染测试（这是 AI 单测生成的核心设计决策）；
4. void 返回用 not.toThrow() 兜底而非空断言；
5. 追问：可对接 AIC-134 变异分数验证骨架补全后的有效性。
