## AIC-796：平台化 AI 工具链中技能市场如何设计

**答**：
- 结论先行：技能市场 = 把团队沉淀的「可复用 AI 技能」（如「安全审查技能」「API 迁移技能」）做成可发现、可安装、可评分的资产，让优秀实践像 npm 包一样流通。
- 要素：1) 技能包标准（步骤、工具、prompt 模板、输入输出 schema）；2) 版本与依赖管理；3) 安装即用（集成到 IDE/Agent）；4) 评分与反馈（用的人越多越好）；5) 安全审核（防止恶意技能）。
- 治理：官方认证 + 团队自建并存；关键技能需审核签名；定期清理陈旧技能。
- 追问钩子：为什么技能需要「安全审核」？——技能里含 prompt 与工具调用，恶意技能可诱导 AI 泄露数据或执行危险操作，等同供应链攻击。

```javascript
// 技能包：标准化元信息 + 安装
const SKILLS = {
  'security-review@1.0': { steps: ['威胁建模', '注入检测'], tools: ['lint'], signed: true, installs: 120 },
  'api-migrate@2.1': { steps: ['扫描调用', '生成迁移'], tools: ['codemod'], signed: false, installs: 8 },
};
function install(name) {
  const s = SKILLS[name];
  if (!s) return { ok: false, reason: 'not-found' };
  if (!s.signed) return { ok: false, reason: 'unsigned-blocked' }; // 未签名技能拦截
  return { ok: true, steps: s.steps };
}
console.log(install('security-review@1.0').ok);    // true
console.log(install('api-migrate@2.1').reason);    // unsigned-blocked
```
