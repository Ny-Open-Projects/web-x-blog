## AIC-790：AI 工具链平台的自助服务如何设计

**答**：
- 结论先行：自助服务 = 业务方无需找平台团队排期，就能自己「发现能力 → 申请权限 → 调用 → 看用量」；平台团队从「人工客服」转型为「提供工具与护栏」。
- 四个自助入口：1) 能力目录（可搜索、带文档与示例）；2) 自助开通（申请即审批/自动审批低风险能力）；3) 自助调试（playground 试调用）；4) 用量看板（自己的成本/配额一目了然）。
- 护栏：自助不等于无管控——敏感能力仍需审批，配额与限流自动执行，防止自助变成滥用。
- 追问钩子：为什么「playground」能降低平台支持成本？——用户先在沙箱里试通再接入，避免大量「调用失败」的答疑工单。

```javascript
// 自助服务流程：高风险能力需审批护栏
function selfService(request) {
  const { capability, risk } = request;
  if (risk === 'high') return { auto: false, next: 'manual-approval' };
  return { auto: true, next: 'provision', credentials: 'issued', playground: `/try/${capability}` };
}
console.log(selfService({ capability: 'complete', risk: 'low' }).auto);  // true
console.log(selfService({ capability: 'db-write', risk: 'high' }).next); // manual-approval
```
