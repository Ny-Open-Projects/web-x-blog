## AIC-793：平台化 AI 工具链的成本控制如何做

**答**：
- 结论先行：平台级成本控制 = 把分散的 AI 调用收敛到统一网关，才能做「全局预算、按租户/团队分摊、异常告警、错峰调度」——分散调用时成本是黑盒，无法治理。
- 四个抓手：1) 统一入口计量（每次调用记录 token/成本/归属）；2) 配额与预算（团队/项目额度，超限降级或拒绝）；3) 成本归因报表（谁花了多少、花在哪）；4) 优化杠杆（缓存、模型路由、批量、错峰）。
- 关键：成本要「可归因」才有人负责；只设总额度不归因，团队没有节约动力。
- 追问钩子：为什么「缓存相似请求」能显著降本？——AI 任务中大量重复/近似查询（如相同代码审查），缓存命中可直接省掉模型调用。

```javascript
// 成本归因 + 预算守卫
function charge(team, tokens, pricePerToken, budgets) {
  const cost = tokens * pricePerToken;
  const used = budgets[team] ?? 0;
  if (used + cost > (budgets.limit ?? Infinity)) return { allowed: false, reason: 'over-budget' };
  budgets[team] = used + cost;
  return { allowed: true, cost, remaining: (budgets.limit ?? Infinity) - budgets[team] };
}
const budgets = { limit: 100 };
console.log(charge('fe', 10, 2, budgets).allowed);  // true，fe 花费 20
console.log(charge('fe', 50, 2, budgets).reason);  // over-budget（100 上限）
```
