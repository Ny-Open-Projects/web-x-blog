## AIC-191：笔试：实现一个快照测试生成器：状态序列回放、快照序列化规范化与差异阈值？
**需求**：实现 `SnapshotTester`：
- `record(name, state)`：记录状态序列；序列化时做规范化（排序对象键、过滤易变字段如时间戳/随机 id）；
- `assert(name, state, { threshold })`：与已存快照对比，结构差异率 > threshold 失败；
- 差异率：递归统计叶子节点变化占比；
- `snapshot()` 导出可提交到仓库的 JSON。

```javascript
const VOLATILE = /^(timestamp|ts|id|uuid|randomKey|at)$/;

function normalize(v, path = '') {
  if (v === null || typeof v !== 'object') return v;
  if (Array.isArray(v)) return v.map((x, i) => normalize(x, `${path}[${i}]`));
  const out = {};
  for (const k of Object.keys(v).sort()) {          // 键排序保证序列化稳定
    if (VOLATILE.test(k)) { out[k] = '<volatile>'; continue; }
    out[k] = normalize(v[k], `${path}.${k}`);
  }
  return out;
}
function leaves(obj, acc = []) {
  if (obj === null || typeof obj !== 'object') { acc.push(obj); return acc; }
  for (const k of Object.keys(obj)) leaves(obj[k], acc);
  return acc;
}
function diffRate(a, b) {
  const la = leaves(a), lb = leaves(b);
  const n = Math.max(la.length, lb.length);
  let diff = 0;
  for (let i = 0; i < n; i++) {
    if (JSON.stringify(la[i]) !== JSON.stringify(lb[i])) diff++;
  }
  return n ? diff / n : 0;
}

class SnapshotTester {
  #store = new Map();
  record(name, state) {
    const list = this.#store.get(name) ?? [];
    list.push(normalize(state));
    this.#store.set(name, list);
  }
  assert(name, state, { threshold = 0.2 } = {}) {
    const saved = this.#store.get(name);
    if (!saved) return { ok: false, reason: '无基线，请先 record' };
    const cur = normalize(state);
    const worst = Math.max(...saved.map(s => diffRate(s, cur)));
    return { ok: worst <= threshold, rate: +worst.toFixed(3), threshold };
  }
  snapshot() {
    return Object.fromEntries([...this.#store.entries()]);
  }
}

// 测试：AI 生成组件的行为快照（过滤时间戳噪音）
const t = new SnapshotTester();
t.record('goods-list', { rows: [{ id: 1, name: 'a', ts: 111 }], total: 2, timestamp: 123 });
console.log(t.assert('goods-list', { rows: [{ id: 1, name: 'a', ts: 999 }], total: 2, timestamp: 456 }));
// ok:true（ts/timestamp 已规范化，结构无实质变化）
console.log(t.assert('goods-list', { rows: [], total: 0, timestamp: 1 }));
// ok:false（rows/total 变化超阈值 → AI 改坏了行为）
```

**评分点**：
1. 规范化先行（键排序 + 易变字段过滤）——不规范化的时间戳会让快照测试永远红，这是 AI 特性（AI 代码常带 id/时间字段）；
2. 差异率用叶子节点统计，阈值可配（结构小调不失败，行为变化才失败）；
3. 无基线时的引导（先 record）而非报错崩溃；
4. snapshot 可导出提交（快照进 Git 走 review）；
5. 追问：快照测试适合「锁行为」，配合特征测试策略用于 AI 重构前基线。
