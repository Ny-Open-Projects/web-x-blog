## AIC-175：笔试：实现一个幂等 AI 任务队列：按内容指纹去重、完成标记、失败重试上限与死信处理？
**需求**：实现 `IdempotentQueue`：
- `push(task)`：按任务内容指纹（hash）去重——相同内容且未完成的任务拒绝重复入队；
- `take()` 取任务并标记处理中；`complete(id)` / `fail(id)`；
- fail 次数 < maxRetries 重新入队（退避由调度决定）；≥ 上限进死信队列（DLQ）；
- `stats()` 返回 pending/processing/done/dlq 数量。

```javascript
import { createHash } from 'crypto';

function fingerprint(task) {
  return createHash('sha1').update(JSON.stringify({ kind: task.kind, payload: task.payload }))
    .digest('hex').slice(0, 16);
}

class IdempotentQueue {
  #pending = []; #processing = new Map(); #done = new Set();
  #failCount = new Map(); #dlq = [];
  #fingerprints = new Map(); // fp -> taskId
  constructor({ maxRetries = 2 } = {}) { this.maxRetries = maxRetries; }

  push(task) {
    const fp = fingerprint(task);
    const existing = this.#fingerprints.get(fp);
    // 已有同内容任务且不在终态 → 幂等拒绝
    if (existing && !this.#done.has(existing) && !this.#dlq.some(t => t.id === existing)) {
      return { accepted: false, reason: 'duplicate', existingId: existing };
    }
    const id = `${fp}-${Date.now()}`;
    task.id = id;
    this.#fingerprints.set(fp, id);
    this.#pending.push(task);
    return { accepted: true, id };
  }
  take() {
    const t = this.#pending.shift();
    if (t) this.#processing.set(t.id, t);
    return t ?? null;
  }
  complete(id) {
    const t = this.#processing.get(id);
    this.#processing.delete(id); this.#done.add(id);
    return t;
  }
  fail(id, err) {
    const t = this.#processing.get(id);
    if (!t) return;
    this.#processing.delete(id);
    const n = (this.#failCount.get(id) ?? 0) + 1;
    this.#failCount.set(id, n);
    if (n > this.maxRetries) { t.lastError = String(err); this.#dlq.push(t); }
    else this.#pending.push(t);
  }
  stats() {
    return { pending: this.#pending.length, processing: this.#processing.size,
      done: this.#done.size, dlq: this.#dlq.length };
  }
}

// 测试
const q = new IdempotentQueue({ maxRetries: 2 });
console.log(q.push({ kind: 'fix', payload: { file: 'a.ts' } }).accepted);  // true
console.log(q.push({ kind: 'fix', payload: { file: 'a.ts' } }).accepted);  // false 重复
const t = q.take();
q.fail(t.id, 'boom'); q.fail(t.id, 'boom'); // 2 次 < 上限 → 重新入队
q.take(); q.fail(t.id, 'boom');             // 第 3 次 → 死信
console.log(q.stats()); // dlq: 1
```

**评分点**：
1. 幂等指纹按任务内容（kind+payload）而非引用——同内容任务在网络重试场景不重复执行；
2. 去重条件区分「进行中/待处理」与「终态」：done/dlq 的任务允许重新入队（新一轮需求）；
3. 重试上限与死信队列：失败任务不能无限循环（呼应 AIC-114 风暴保护）；
4. take/complete/fail 的状态机完整（processing 态可观测）；
5. failCount 按 id 记录，重入队不清零——语义是「同一任务最多重试 N 次」。
