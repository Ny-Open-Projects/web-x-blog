## AIC-332：线上事故复盘如何引入 AI？哪些环节适合哪些必须人做？
**答**：
- AI 适合：时间线整理（日志/告警/commits 关联）、根因假设清单、同类风险排查（还有哪里有相同模式）。
- 人必须做：根因裁决、责任界定、流程改进决策——复盘的组织属性 AI 承担不了。
- AI 产出「风险排查报告」：全仓扫描同类模式，把一次事故变成一次系统性加固。
- 改进项跟踪：AI 定期核对改进项完成度，未完成的自动提醒升级。

```javascript
async function postmortem(incident: Incident) {
  const timeline = await buildTimeline(incident);          // 日志+commit+告警对齐
  const hypotheses = await rootCauseCandidates(timeline);  // 假设清单
  const sweep = await scanSimilarPatterns(incident.pattern); // 全仓同类风险
  return { timeline, hypotheses, sweep, humanDecides: ['rootCause', 'actions'] };
}
```
