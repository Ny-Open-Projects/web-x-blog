## AIC-449：笔试：把评审批注锚定到行（含行号漂移修正）。
**题目**：评审时基于旧版本行号，新版本行号漂移（新增行导致）。输入旧锚 `{file, line, anchorText}` 与新文件行数组。用 anchorText 精确匹配修正行号；匹配多处取距原行号最近；找不到标记 stale。

```javascript
function relocate(anchor, lines) {
  const matches = [];
  lines.forEach((l, i) => { if (anchor.anchorText && l.includes(anchor.anchorText)) matches.push(i + 1); });
  if (!matches.length) return { ...anchor, stale: !anchor.anchorText ? false : true,
    line: anchor.anchorText ? anchor.line : anchor.line };
  if (anchor.anchorText === undefined || anchor.anchorText === '')
    return { ...anchor, stale: false };
  matches.sort((a, b) => Math.abs(a - anchor.line) - Math.abs(b - anchor.line));
  return { ...anchor, line: matches[0], stale: false };
}
console.log(relocate({ file: 'a.ts', line: 10, anchorText: 'expect(x)' },
  Array.from({ length: 20 }, (_, i) => `line${i + 1}`).map((s, i) => i === 14 ? 'expect(x).toBe(1)' : s)));
// 修正为 15

```

**评分点**：
- 文本锚定优先于行号——防漂移核心手段。
- 多匹配取最近（绝对距离最小）。
- 找不到文本 → stale 输出（提示人工定位）。
- 原行号兜底（文本空时）。
