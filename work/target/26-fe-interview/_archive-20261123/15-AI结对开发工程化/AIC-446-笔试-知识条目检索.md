## AIC-446：笔试：实现知识条目按任务描述检索（简化打分）。
**题目**：条目 `{id, tags[], refs}`。任务描述分词后与 tags 交集计分，refs 作为权重加成（+refs×0.1）。输出 top3 `{id, score}`，score 0 的不返回。

```javascript
function searchKB(entries, task) {
  const words = task.toLowerCase().split(/\s+/);
  return entries.map(e => {
    const inter = e.tags.filter(t => words.includes(t.toLowerCase())).length;
    const boost = Math.min(e.refs, 2) * 0.1;
    return { id: e.id, score: +(inter + boost).toFixed(1), refs: e.refs };
  }).filter(x => x.score > 0)
    .sort((a, b) => b.score - a.score || b.refs - a.refs)
    .slice(0, 3).map(({ id, score }) => ({ id, score }));
}
console.log(searchKB([
  { id: 'k1', tags: ['ssr', 'cache'], refs: 5 },
  { id: 'k2', tags: ['ssr'], refs: 0 },
], '如何处理 ssr cache 一致性')); // k1 2.0 > k2 1.0

```

**评分点**：
- 分词 + 交集打分（大小写归一）。
- refs 加成有上限（防单条垄断，cap 至 2）。
- top3 截取，0 分不返回。
- 并列分数按 refs 降序。
