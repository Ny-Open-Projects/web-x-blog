## AIC-343：代码评审时如何让 AI 校验「实现是否符合需求意图」而不只是「代码对不对」？
**答**：
- 需求结构化：需求单的结构化摘要（用户故事+验收标准）作为评审输入。
- 逐条映射：AI 输出「验收标准 ↔ 实现位置」映射表，无映射的标准即疑似遗漏。
- 反向检查：列出 diff 中「不在任何标准内」的行为变更（私自加的需求/顺手改的行为）。
- 遗漏与越界并列输出给产品/开发双线确认——意图对齐是产品问题不是纯技术问题。

```javascript
async function intentCheck(requirement: Req, diff: string) {
  const map = await mapAcceptance(requirement.criteria, diff);
  const extra = await extraBehaviors(diff, requirement.criteria); // 越界变更
  return { missing: map.filter(m => !m.located), outOfScope: extra,
           reviewers: ['pm', 'dev'] };
}
```
