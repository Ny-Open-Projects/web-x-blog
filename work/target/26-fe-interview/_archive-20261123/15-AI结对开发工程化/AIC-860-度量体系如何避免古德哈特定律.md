## AIC-860：古德哈特定律说「指标一旦成为目标就失效」，度量体系怎么避坑？
**答**：
- 古德哈特定律的本质：当度量被用于决策/考核，被度量者会优化**指标**而非**真实目标**，导致指标好看、真实情况恶化（采纳率刷到 99% 但存活率 10%）。
- 防御分层：**① 永远用指标组合而非单一指标**，且组合中要有相互制衡的关系（采纳↑必须存活↑）；**② 设置不可刷的护栏**（线上事故、逃逸缺陷一票否决）；**③ 不用于个人考核**，只用于团队改进——这是最有效的一条。
- **④ 定期审视指标本身**：每季度问「这个指标还在反映真实价值吗？有没有新的刷法？」发现被污染就换指标或调整口径；保留指标版本历史，避免悄悄改口径。
- **⑤ 保留定性信号**：定期做开发者访谈/满意度调研，数字之外听真实声音——被刷的指标往往是定量的，定性反馈能揭示失真。
- 追问钩子：能说出「对抗古德哈特定律最有效的不是算法检测，而是不把指标和个人考核绑定 + 组合制衡 + 定期审视」的候选人，把度量当社会技术系统而非纯数据问题。

```typescript
type Metrics = { adoption:number; survival:number; revertRate:number; bugs:number; deployFreq:number };

function goodhartCheck(m: Metrics) {
  // 组合制衡：指标之间出现"不可能同时好"的背离，说明可能被刷
  const contradictions: string[] = [];
  if (m.adoption > 0.9 && m.survival < 0.5) contradictions.push('高采纳低存活：疑似无脑接受');
  if (m.deployFreq > 20 && m.bugs > 5) contradictions.push('高频部署高缺陷：疑似灌水');
  if (m.adoption > 0.85 && m.revertRate > 0.4) contradictions.push('高采纳高回滚：疑似刷量');
  return { suspectGaming: contradictions.length > 0, contradictions,
    // 真实目标用"调整后价值"衡量，刷单一指标无法提升它
    trueValue: +(m.adoption * m.survival * (1 - m.revertRate) / (1 + m.bugs)).toFixed(3),
  };
}
console.log(goodhartCheck({ adoption:0.99, survival:0.2, revertRate:0.5, bugs:4, deployFreq:30 }));
// suspectGaming:true，且 trueValue 很低 —— 指标被刷但真实目标没达成
```
