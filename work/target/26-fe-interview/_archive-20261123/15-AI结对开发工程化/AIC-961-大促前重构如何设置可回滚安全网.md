## AIC-961：大促前两天要做一次 AI 重构，如何设置「可回滚安全网」把风险降到最低？
**答**：
- 大促前的基本原则是「非必要不重构」——结论：能推迟到大促后就不要在封版期动结构，这是最大的安全网。
- 必须做时要有「开关化回滚」：用 feature flag 隔离重构后的逻辑，出问题一键切回旧路径，无需回滚代码与重新发版；旧代码暂时保留。
- 配套：① 小步提交 + 灰度放量（先 1% 流量）；② 关键指标（错误率/响应时间/请求量）实时监控与自动熔断；③ 明确回滚决策人与触发阈值。
- 追问钩子：能说出「封版期的重构安全网 = 开关 + 灰度 + 监控 + 明确回滚阈值，其中最有效的是『别在此时重构』」的候选人有风险分级意识。

```typescript
// 开关化回滚 + 灰度放量
function usePriceLogic(ctx) {
  return ctx.flag.newPrice && ctx.grayHit(0.01) // 先放 1% 流量
    ? newComputePrice(ctx.input)
    : oldComputePrice(ctx.input); // 旧路径随时可切回
}
function monitor(metrics, thresholds) {
  return Object.entries(thresholds).filter(([k,v]) => metrics[k] > v)
    .map(([k])=>k);
}
const breached = monitor({ errorRate:0.05, p95:800 }, { errorRate:0.01, p95:500 });
if (breached.length) console.log('触发回滚:', breached, '→ 关闭 flag');
```
