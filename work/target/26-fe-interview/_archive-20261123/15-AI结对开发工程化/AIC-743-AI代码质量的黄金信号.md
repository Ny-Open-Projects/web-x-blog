## AIC-743：评估 AI 代码质量时应该关注哪些黄金信号

**答**：
- 结论先行：黄金信号是「少数能真实反映质量的指标」——首选「变更后的缺陷逃逸率」「评审返工轮数」「测试变异分数」，而不是代码行数、生成速度这类虚荣指标。
- 候选信号：1) 缺陷逃逸率（上线后发现的 AI 代码 bug 比例）；2) 返工率（需要人工大幅修改的生成比例）；3) 变异分数（测试杀死变异体的能力）；4) 回滚率。
- 挑选原则：信号要「可观测、可归因、难造假」；采纳率（是否接受建议）是过程指标，不能等同质量——接受得快可能只是审查者疲劳。
- 追问钩子：为什么「采纳率」不是好信号？——高采纳率可能意味着审查者盲目接受而非代码真的好；它与质量的相关性弱，与审查投入负相关。

```javascript
// 黄金信号 vs 虚荣指标
const SIGNALS = {
  gold: ['缺陷逃逸率', '评审返工轮数', '变异分数', '回滚率'],
  vanity: ['生成代码行数', '生成速度', '采纳率'],
};
function qualityVerdict(metrics) {
  const escapes = metrics['缺陷逃逸率'] ?? 0;
  return escapes < 0.05 ? 'healthy' : 'needs-attention';
}
console.log(qualityVerdict({ '缺陷逃逸率': 0.02, '采纳率': 0.9 }));  // healthy
console.log(qualityVerdict({ '缺陷逃逸率': 0.12, '采纳率': 0.95 })); // needs-attention（采纳率高但逃逸高）
```
