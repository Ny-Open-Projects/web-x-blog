## AIC-345：让 Agent 主动「猎捕」代码库潜在缺陷（不是等评审），如何设计？
**答**：
- 猎捕策略：从历史 bug 提炼「缺陷模式库」（空值/竞态/边界），Agent 按模式全库扫描候选点。
- 候选点验证：对每个候选生成复现测试（先证明能失败），只有可复现的才提报。
- 分级提报：确认级（有复现测试）开 issue，疑似级进周报人工筛。
- 防误报疲劳：每轮提报上限 10 条，复现率数据进周报，模式库按复现率优胜劣汰。

```javascript
async function hunt(patterns: BugPattern[]) {
  const candidates = await scanByPatterns(patterns);
  const verified = [];
  for (const c of candidates.slice(0, 30)) {
    const tc = await genReproTest(c);
    if (tc?.fails) verified.push({ ...c, test: tc });
  }
  return { issues: verified.slice(0, 10), weeklyReport: verified.length };
}
```
