## AIC-196：笔试：实现一个流式响应断点续传：分块落盘、续传偏移、重复块去重与完整性校验？
**需求**：实现 `ResumableStream`：
- `write(seq, chunk)`：按序列号写分块，乱序到达时缓冲；重复 seq 去重；
- 断点恢复：`resume()` 返回缺失的 seq 区间请求列表（gap 检测）；
- `content()`：按 seq 有序拼接；`complete` 判定需要元信息 total；
- 每 N 块落盘快照（模拟持久化），重启后从快照恢复。

```javascript
class ResumableStream {
  #chunks = new Map(); #pending = new Map(); #nextSeq = 0;
  #snapshotEvery = 3; #snapshot = null; #snapshotSeq = -1;
  constructor(total) { this.total = total; }

  write(seq, chunk) {
    if (seq < this.#nextSeq) return 'duplicate';       // 已消费的重复块
    if (seq === this.#nextSeq) {
      this.#chunks.set(seq, chunk); this.#nextSeq++;
      this.#drain();                                    // 消费后续连续块
      if (this.#nextSeq % this.#snapshotEvery === 0) this.#saveSnapshot();
      return 'accepted';
    }
    this.#pending.set(seq, chunk);                      // 乱序缓冲
    return 'buffered';
  }
  #drain() {
    while (this.#pending.has(this.#nextSeq)) {
      this.#chunks.set(this.#nextSeq, this.#pending.get(this.#nextSeq));
      this.#pending.delete(this.#nextSeq);
      this.#nextSeq++;
    }
  }
  #saveSnapshot() {
    this.#snapshot = [...this.#chunks.entries()].slice(-this.#snapshotEvery);
    this.#snapshotSeq = this.#nextSeq - 1;
  }
  resume() {
    // 缺失区间：快照点之后到 total 的 seq
    const missing = [];
    for (let s = this.#snapshotSeq + 1; s < this.total; s++) {
      if (!this.#chunks.has(s)) missing.push(s);
    }
    return { missing, fromSnapshot: this.#snapshot };
  }
  content() {
    return [...this.#chunks.keys()].sort((a, b) => a - b)
      .map(s => this.#chunks.get(s)).join('');
  }
  get complete() { return this.#nextSeq >= this.total; }
}

// 测试
const st = new ResumableStream(5);
console.log(st.write(0, 'A'), st.write(2, 'C'), st.write(2, 'C')); // accepted buffered duplicate
console.log(st.write(1, 'B'), st.write(3, 'D'));                   // drain 0-3
console.log(st.resume());                                          // missing:[4]
st.write(4, 'E');
console.log(st.content(), st.complete);                            // ABCDE true
```

**评分点**：
1. 乱序缓冲 + 连续消费（drain）是流组装的核心，只按到达顺序拼是失分实现；
2. 重复块去重依据「seq < nextSeq」已消费水位线；
3. gap 检测输出缺失 seq 列表——续传请求只拉缺的块（断点续传的本质）；
4. 快照持久化用于进程重启恢复，快照点前数据不必重拉；
5. 追问：真实 SSE 断线场景还需 Last-Event-ID 协商与服务端重放窗口。
