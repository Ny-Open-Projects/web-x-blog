## AIC-313：「AI 友好的验收标准」长什么样？如何让验收自动化而不是靠人眼？
**答**：
- 可执行判据：测试通过 + 类型检查 + 行为断言（Gherkin/单测），而非「看起来正常」。
- 负面验收：明确「不许做什么」（不改公共接口/不动 legacy 目录），AI 最容易越界。
- 验收脚本化：acceptance 写成可运行脚本，任务完成的判定机器说了算。
- 多档验收：冒烟级（编译+冒烟测试）/完整级（全测试+规范检查），任务卡指定档位。

```javascript
// 验收即脚本
const acceptance = async (task: TaskCard) => {
  const smoke = task.tier === 'smoke';
  await shell('tsc --noEmit');
  await shell(smoke ? 'vitest run smoke' : 'vitest run && eslint src');
  for (const c of task.constraints) assertNotViolated(c); // 负面约束检查
};
```
