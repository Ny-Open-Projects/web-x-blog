## AIC-295：AI 工具/模型版本频繁升级，如何管理升级节奏而不被「静默变差」坑到？
**答**：
- 固定基准：规则升级后跑内部基准，通过率波动 > 3% 需评估再全量推。
- 灰度升级：新版本先给志愿小组用两周，收集 diff 数据。
- 记录快照：基准题目+判定脚本+结果存档，任何时点可回溯比较。
- 下游兼容：提示词/规则里引用的模型行为特征（如 JSON 输出格式）升级后要回归验证。

```javascript
async function upgradeGate(newVersion: string) {
  const base = await runBench(currentVersion);
  const next = await runBench(newVersion);
  const drift = next.passRate - base.passRate;
  return { ok: drift >= -0.03, drift,
           action: drift >= -0.03 ? 'rollout-canary' : 'hold-and-investigate' };
}
```
