## AIC-024：团队要选型 AI 编码工具，评估维度有哪些？给出一个可落地的选型清单。
**答**：
- 能力维度：补全质量（内部代码风格贴合度）、Chat 检索准确度、Agent 多文件任务成功率、对私有依赖的理解。
- 安全合规维度：隐私模式/零保留条款、私有化部署选项、安全审计报告、数据出境合规。
- 工程维度：IDE 生态覆盖（VSCode/JetBrains）、规则文件体系、API/遥测（度量用）、成本按席位还是按用量。
- 落地方法：选 2~3 个候选、固定一组基准任务（一个 bugfix + 一个 feature + 一个重构）、各做一周试点，按「任务完成率 × 存活率 / 干预次数」量化对比。
- 试点期收集工程师主观评分（是否愿意自费购买）——这个信号比指标更真实。
- 追问钩子：能提出「工具是易耗品，选型结论半年复审一次」避免被锁定。

```markdown
<!-- 选型基准任务包（每个候选工具跑同一套） -->
- T1 bugfix：修复 goods 列表分页跳变 bug（存量问题，有标准答案）
- T2 feature：购物车加优惠码（含类型、hooks、UI、测试）
- T3 refactor：Options API → Composition API 迁移 5 个组件

评分表（每项 1~5）：
补全贴合度 / Agent 任务完成率 / 干预次数(越少越好) / 产出 7 天存活率 / 安全合规 / 团队意愿
```
