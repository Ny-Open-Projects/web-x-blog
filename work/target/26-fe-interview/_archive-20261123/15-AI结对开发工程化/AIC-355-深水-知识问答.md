## AIC-355：让 AI 回答「这个函数为什么这么写」类历史问题，如何提升准确率？
**答**：
- 三层证据：代码注释/commit message/关联 PR 描述与评审讨论——AI 综合回答并引用出处。
- 决策文档优先：如果存在 ADR/设计文档，答案以文档为准，代码只是实现。
- 置信度分级：有明确文档依据（高）/ 从 commit 推断（中）/ 纯猜测（低，需人工确认）。
- 回答纠错闭环：用户纠正 AI 答案时，纠正记录回写知识库（关联到对应代码位置）。

```javascript
async function whyCode(fn: Fn) {
  const evidence = await Promise.all([docFor(fn), commitsFor(fn), prDiscussionFor(fn)]);
  const answer = await llm(`回答「为什么这么写」，必须引用出处：
${evidence.map(e => e.text).join('\n')}，无依据时明确说「不确定」并给置信度。`);
  return { answer, citations: evidence.map(e => e.ref) };
}
```
