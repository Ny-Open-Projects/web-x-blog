## AIC-340：全栈仓（TS/Go/Python）里 AI 跨语言上下文理解不一致，如何处理？
**答**：
- 契约文件跨语言一致：OpenAPI/proto 作为唯一事实源，各语言生成类型，AI 优先读契约。
- 语言专属规则分目录注入：不同语言目录挂不同 rules（Go 的错误处理/Python 的类型标注习惯）。
- 跨语言调试任务：明确给 AI「语言映射表」（如 TS 的 Promise.catch ≈ Go 的 err 返回值）。
- 分别评测：内部基准按语言分卷，避免「TS 强 Python 弱」被平均值掩盖。

```javascript
const polyglot = {
  contract: 'openapi.yaml → ts/go/py 类型全部生成，不手写',
  rules: { 'server/go/**': 'go-rules.mdc', 'scripts/**': 'python-rules.mdc' },
  bench: 'per-language passRate 分别统计与达标',
};
```
