## AIC-009：笔试：实现一个 Agent 命令权限过滤器，支持通配符白/黑名单与风险分级？
**题目**：实现 `check(cmd, policy)`，返回 `'allow' | 'deny' | 'ask'`。规则：黑名单优先级最高；其次白名单；否则 ask。模式支持 `*` 通配（匹配任意字符含空格），`cmd` 需先做基础归一化（去多余空白）。

```typescript
type Policy = { allow: string[]; deny: string[] };

function toRegExp(pattern: string): RegExp {
  const escaped = pattern.replace(/[.+^${}()|[\]\\?]/g, '\\$&');
  return new RegExp(`^${escaped.replace(/\*/g, '.*')}$`);
}

function check(rawCmd: string, policy: Policy): 'allow' | 'deny' | 'ask' {
  const cmd = rawCmd.trim().replace(/\s+/g, ' ');
  if (!cmd) return 'deny'; // 空命令直接拒绝
  if (policy.deny.some(p => toRegExp(p).test(cmd))) return 'deny';
  if (policy.allow.some(p => toRegExp(p).test(cmd))) return 'allow';
  return 'ask';
}

const policy = {
  allow: ['pnpm lint', 'pnpm test*', 'git status', 'git diff*'],
  deny: ['rm *', 'git push*', '* publish*', 'sudo *'],
};

console.log(check('pnpm test --run', policy));        // allow
console.log(check('git  diff --stat', policy));       // allow（空白归一化）
console.log(check('rm -rf dist', policy));            // deny
console.log(check('git push --force origin', policy));// deny
console.log(check('cat package.json', policy));       // ask
console.log(check('npm publish --access public', policy)); // deny
```
**评分点**：
- 黑名单先于白名单判断（顺序错了 `git push*` 会被 `git diff*` 之类覆盖式放行是常见 bug，即便本题白名单不含，也要体现优先级意识）。
- 正则构造前对特殊字符转义，`*` 单独替换。
- 空命令/异常输入返回 deny 或 ask 而不是 allow（fail-safe 原则）。
- 能说出更完善的方案：拆分管道命令（`&&`、`|`）逐段检查、识别 base64/变量拼接的绕过手段。
