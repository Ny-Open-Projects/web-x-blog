## AIC-964：笔试：实现「重构安全门禁」（多守卫聚合判定：行为等价/测试强度/范围/风险分）
**答**：
- 核心需求：实现 `refactorGate(checks)`。`checks: { behaviorDiff:{passed,failures}, testStrength:{ok}, scopeGuard:{ok,violations}, risk:{score,level} }`。返回 `{ pass, blockers, summary }`。
- 聚合规则：所有守卫必须通过（behaviorDiff.passed && testStrength.ok && scopeGuard.ok && risk.level!=="高"）才 pass；任一失败项列入 blockers（带原因与守卫名）。
- fail-closed 语义：任何守卫数据缺失（undefined/null）视为不通过并加入 blockers——结论：门禁宁可误拦，不可漏放。
- 边界：checks 为空返回 pass=false/blockers=["无守卫数据"]；blockers 按守卫名排序保证确定性；summary 为简短中文结论。
- 语义：门禁是「自动化决策点」——它聚合多个信号给出放行/拦截的单一决定，规则要透明可审计。
- 追问钩子：能指出「fail-closed 与『缺失数据视为失败』是门禁的安全底线；同时要有明确的例外审批通道应对误拦」的候选人懂门禁的工程落地。

```typescript
function refactorGate(checks={}) {
  const blockers=[];
  const must = (val, name, reason) => { if(!val) blockers.push(`${name}: ${reason}`); };
  must(checks.behaviorDiff, '行为等价', '缺少数据');
  must(checks.behaviorDiff?.passed, '行为等价', '差分校验未通过');
  must(checks.testStrength?.ok, '测试强度', '测试被改弱');
  must(checks.scopeGuard?.ok, '变更范围', '越界改动: '+(checks.scopeGuard?.violations||[]).join(','));
  must(checks.risk && checks.risk.level!=='高', '风险分', '风险过高('+(checks.risk?.score??'?')+')');
  blockers.sort();
  return { pass:blockers.length===0, blockers,
    summary: blockers.length? `拦截：${blockers.length}项未通过` : '放行：全部守卫通过' };
}
console.log(refactorGate({ behaviorDiff:{passed:true,failures:[]},
  testStrength:{ok:true}, scopeGuard:{ok:false,violations:['package.json']}, risk:{score:2,level:'低'} }));
```
**评分点**：
- 聚合四守卫：行为等价/测试强度/范围/风险分全部通过才 pass。
- fail-closed：守卫数据缺失视为不通过并加入 blockers。
- blockers 带守卫名与原因、按名排序确定性，summary 中文结论。
- checks 为空返回 pass=false，边界处理正确。
- 明确「例外审批通道应对误拦」（加分项）。
