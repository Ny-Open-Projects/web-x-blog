## AIC-302：PR 周期变短了，怎么证明是 AI 工具的功劳而不是别的因素？
**答**：
- 对照设计：AI 已开通/未开通团队（或灰度期前后）同期对比，控制任务类型分布。
- 中断期对照：工具故障/配额停用期间的自然实验，观察指标回落幅度。
- 自报告交叉：开发者问卷「这个 PR 用了 AI 吗，省了多少时间」，与指标趋势互相验证。
- 排除混淆因子：同期是否换了流程/加了人/砍需求，写进归因声明。

```javascript
function attributeLift(before: Win, after: Win, paused: Win) {
  const gain = median(after.cycle) - median(before.cycle);
  const pauseLoss = median(paused.cycle) - median(after.cycle); // 停用期回落≈真实贡献
  return { gain, attribution: pauseLoss / gain, confounders: ['headcount', 'scope-change'] };
}
```
