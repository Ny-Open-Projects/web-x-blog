## AIC-267：新模型发布想替换现有主力模型，如何做替换决策？
**答**：
- 内部基准全跑：自家任务集通过率对比（不是厂商榜单），重点看弱项场景。
- 成本与延迟复核：同任务 token 消耗对比（新模型可能更啰嗦）+ 实际响应延迟。
- 灰度替换：20% 流量两周 → 对比质量与成本 → 全量；期间保留一键回切。
- 提示词重调：新模型对旧提示词的响应特性不同，替换前做提示词微调实验。

```javascript
async function modelSwapDecision(newM: string) {
  const bench = await runBenchAll([current, newM]);
  const cost = await runCostCompare([current, newM]);
  return { ok: bench[newM].passRate >= bench[current].passRate - 0.01
                && cost[newM].perTask <= cost[current].perTask * 1.1,
           canary: '20% traffic × 2 weeks → decide' };
}
```
