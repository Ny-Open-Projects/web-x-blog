## AIC-435：笔试：审计抽样：从任务日志随机抽 20 个做回放。
**题目**：实现 `sample(log, n=20)`：均匀抽样（确定性伪随机：seed 固定），保证可复现（同 seed 同结果）；返回样本 + 其余作为对照组。

```javascript
function sample(log, n = 20, seed = 42) {
  let s = seed;
  const rand = () => (s = (s * 9301 + 49297) % 233280) / 233280;
  const idx = log.map((_, i) => i);
  for (let i = idx.length - 1; i > 0; i--) {
    const j = Math.floor(rand() * (i + 1));
    [idx[i], idx[j]] = [idx[j], idx[i]];
  }
  const k = Math.min(n, log.length);
  return { sampled: idx.slice(0, k).map(i => log[i]),
           control: idx.slice(k).map(i => log[i]) };
}
console.log(sample([1, 2, 3, 4, 5], 2).sampled.length); // 2，且同 seed 可复现

```

**评分点**：
- 确定性伪随机（LCG 固定 seed）——可复现是核心考点。
- 抽样不重复（洗牌取前 n）。
- n > 总数时全取并说明。
- 样本与对照不重叠。
