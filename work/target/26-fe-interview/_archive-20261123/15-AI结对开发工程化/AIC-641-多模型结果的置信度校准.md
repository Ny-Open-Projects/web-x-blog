## AIC-641：多模型输出的「置信度」怎么校准才可信？

**答**：
- 结论先行：**LLM 自报的置信度基本不可信（校准差），可信的置信度必须来自「外部校验」**——测试通过率、多模型一致性、历史准确率，而非模型说「我 90% 确定」。
- 为什么自报不可信：LLM 的「我很确定」和实际正确率相关性很弱；它常被 prompt 措辞、答案长度影响——写得越详细越显得自信，但详细 ≠ 正确。
- 校准方法：1) **测试校准**：让输出跑测试/类型检查，通过率是最硬的置信度代理；2) **一致性校准**：多个异质模型独立得出相同结论 → 提高置信度；但要防同质化盲点（AIC-638）；3) **历史校准**：统计该模型/该任务类型的历史准确率（AIC-274 能力档案），用频率近似概率；4) **温度校准**：多次采样（temperature>0），看答案稳定性——稳定=高置信。
- 使用：把校准后的置信度用于「决定是否人工复核」——低置信度强制人工审，高置信度可快速通道，但永远保留抽检（AIC-078 评审抽样）。
- 追问钩子：为什么「多次采样一致性」能反映置信度？——因为如果模型对答案确定，不同随机采样都会收敛到同一答案；如果它「拿不准」，采样结果会分散。答案的方差本身就是不确定性的度量，这比让模型自评可靠得多。

```typescript
function calibrateConfidence(
  selfReported: number,        // 模型自报（不可信，仅参考）
  testPassRate: number,        // 测试通过率（硬信号）
  agreement: number,           // 异质模型一致度（0-1）
  historicalAccuracy: number,  // 历史准确率
): number {
  // 外部信号加权，自报只占很小权重
  const calibrated = testPassRate * 0.5 + agreement * 0.3
    + historicalAccuracy * 0.15 + selfReported * 0.05;
  return Math.min(1, Math.max(0, calibrated));
}

console.log(calibrateConfidence(0.95, 0.4, 0.5, 0.7)); // ≈0.555 —— 自报很高但外部信号弱
console.log(calibrateConfidence(0.6, 1.0, 1.0, 0.85)); // 0.93 —— 自报低但外部强
```
