## AIC-797：如何衡量 AI 工具链平台的采用率与留存

**答**：
- 结论先行：采用率看「有多少人用」，留存看「用了之后是否持续用」——高采用低留存说明工具「尝鲜后不好用」，是产品问题而非推广问题；两个指标必须一起看。
- 指标定义：1) 采用率 = 活跃用户/目标用户；2) 留存 = 第 N 周仍活跃的用户/首周用户；3) 深度 = 人均调用次数/使用的能力数（区分「装了不用」和「真用起来」）。
- 分析：按角色/团队分层看留存，找哪类用户流失；结合反馈定位是「能力不足」还是「体验差」。
- 追问钩子：为什么「安装量」不是好指标？——安装只需一次点击，不代表实际使用；留存与使用深度才反映真实价值。

```javascript
// 采用 + 留存 + 深度
function platformHealth(week1Users, weekNUsers, totalCalls) {
  const adoption = week1Users.length ? week1Users.length / 100 : 0; // 假设目标用户 100
  const retained = week1Users.filter(u => weekNUsers.includes(u));
  return {
    adoption: +adoption.toFixed(2),
    retention: week1Users.length ? +(retained.length / week1Users.length).toFixed(2) : 0,
    depth: week1Users.length ? +(totalCalls / week1Users.length).toFixed(1) : 0,
  };
}
console.log(platformHealth(['a', 'b', 'c'], ['a', 'c'], 100));
// { adoption:0.03, retention:0.67, depth:33.3 } —— 留存尚可
```
