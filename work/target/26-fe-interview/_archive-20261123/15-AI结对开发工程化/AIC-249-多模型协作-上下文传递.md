## AIC-249：一个任务跨多个模型接力（如 A 分析 B 实现），上下文如何传递才不失真？
**答**：
- 结构化交接：A 输出规定 schema（结论/证据/待办），禁止自由文本直传——丢信息。
- 保留证据链：交接物里带文件路径+行号，下游模型可自行验证而非盲信结论。
- 压缩有度：总结去掉推理过程会丢「为什么」，保留关键决策依据。
- 最终校验闭环：下游产出必须过统一门禁，错误回流到上游重做而不是下游硬补。

```javascript
const handoff = {
  schema: {
    conclusion: 'string',        // 结论
    evidence: ['file:line'],     // 证据链（下游可验证）
    decisions: ['为什么这样做'],  // 保留依据
    todos: ['下游要做什么'],
  },
  rule: '禁止自由文本直传；下游过门禁失败 → 回流上游，不允许下游自行脑补',
};
```
