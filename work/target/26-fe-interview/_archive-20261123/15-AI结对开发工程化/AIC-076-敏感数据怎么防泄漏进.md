## AIC-076：使用 AI 编码工具时，敏感数据防泄漏的技术手段有哪些？「数据分级」怎么做？
**答**：
- 手段四层：① 工具层——隐私模式/零保留协议/私有化部署（对应 AIC-010 的合规条款）② 网络层——出口代理审计，未批准的 AI 域名可拦截 ③ 内容层——prompt 网关做敏感信息检测与脱敏（手机号/密钥/内网拓扑打码后再外发）④ 制度层——数据分级 + 允许清单。
- 数据分级实操：P0（密钥、用户 PII）禁止进任何外部 AI；P1（业务核心代码）仅限企业版/私有化；P2（通用技术代码、开源项目）可用 SaaS 工具。分级表要落到「目录级」（哪些 repo/目录是什么级别）。
- 关键难点：开发者无意识泄漏——贴报错日志带着内网 URL、贴配置带着真实 host；所以内容层网关比培训更可靠。
- 度量：网关的拦截日志按周统计类型分布，高频拦截项转化为规则文件里的显式禁令。
- 追问钩子：面试加分点在于指出「分级表的生命周期」——新项目立项时定级，季度复审，比一次性定义重要。

```javascript
// prompt 网关的脱敏中间件（内容层防线）
const maskRules = [
  { re: /1[3-9]\d{9}/g, to: '[PHONE]' },
  { re: /\b(?:sk-|ghp_|AKIA)[A-Za-z0-9]{16,}/g, to: '[TOKEN]' },
  { re: /\b(?:10|172\.(?:1[6-9]|2\d|3[01]))\.\d+\.\d+\b/g, to: '[INTRANET]' },
];
function sanitize(prompt) {
  let masked = prompt, hits = 0;
  for (const r of maskRules) { masked = masked.replace(r.re, r.to); hits++; }
  return { masked, hits, level: hits > 0 ? 'WARN_AND_LOG' : 'PASS' };
}
```
