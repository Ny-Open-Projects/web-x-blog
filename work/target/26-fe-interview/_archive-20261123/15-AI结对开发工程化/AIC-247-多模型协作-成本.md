## AIC-247：多模型协作下如何做成本治理？单靠人工看账单为什么不够？
**答**：
- 按任务维度记账：请求打标（任务类型/仓库/用户），成本归因到「用途」而非只到「模型」。
- 缓存前置：prompt cache 命中（稳定前缀：规则+代码骨架）能省 50%+ 输入成本。
- 预算分级：个人/CI/批量任务分预算池，CI 批量任务设日限额熔断。
- 单位成本指标：用「每次合并的 AI 成本」而非「总 token 数」衡量，防止为省 token 降低质量。

```javascript
const costRecord = (req: Req, usage: Usage) => ({
  taskType: req.tag, repo: req.repo,
  inTok: usage.in, cachedTok: usage.cacheHit, outTok: usage.out,
  cost: price(req.model, usage),        // 缓存命中部分按折扣计价
  meta: { pr: req.pr, user: req.user },
}); // 周报：成本/任务类型分布、缓存命中率、人均成本
r
```
