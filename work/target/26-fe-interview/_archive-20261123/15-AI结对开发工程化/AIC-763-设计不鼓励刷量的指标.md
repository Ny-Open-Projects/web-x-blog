## AIC-763：如何设计不鼓励刷量（Goodhart 定律）的 AI 效能指标

**答**：
- 结论先行：Goodhart 定律——「当指标成为目标，它就不再是好指标」；防刷的核心是「用难造假的结果指标替代易造假的过程指标」，并配套反向制衡指标。
- 具体手法：1) 少用「补全次数/采纳率」（易刷），多用「缺陷逃逸率/交付周期」（难刷）；2) 成对指标（提效 + 质量红线同时考核）；3) 设置不可控的对照（随机抽检人工复核）；4) 指标分级——团队级为主、个人级弱化为参考。
- 关键认知：团队级指标比个人级更抗刷，因为刷量需要多人合谋，成本高。
- 追问钩子：为什么「采纳率」特别容易刷？——审查者为赶进度「无脑点采纳」就能提高数字，但质量没提升甚至更差。

```javascript
// 成对指标：效率 + 质量红线，刷效率触发质量红线则判无效
function balancedScore({ throughput, quality, qualityFloor }) {
  if (quality < qualityFloor) return { valid: false, reason: 'quality-below-floor' };
  return { valid: true, score: throughput * (quality - qualityFloor) };
}
console.log(balancedScore({ throughput: 100, quality: 0.6, qualityFloor: 0.8 }).valid); // false（刷量被拦）
console.log(balancedScore({ throughput: 80, quality: 0.9, qualityFloor: 0.8 }).score > 0); // true
```
