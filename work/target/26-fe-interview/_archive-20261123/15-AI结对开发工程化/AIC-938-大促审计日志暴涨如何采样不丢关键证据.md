## AIC-938：大促期间 AI 调用量暴涨十倍，审计日志存储和写入压力骤增，如何采样又不丢关键证据？
**答**：
- 采样要「分层差异化」：普通成功调用按比例采样（如 10%）；高危操作（写生产、改价格、删数据）、失败/回滚、异常模型调用 100% 全留——结论：采样的关键是区分证据价值，而非均匀随机。
- 用「确定性采样」而非随机：基于 traceId/会话 ID 哈希取模决定采不采，保证同会话要么全采要么全不采，便于按会话回放，且结果可复现。
- 保留「全量计数 + 摘要」：未采样的记录仍登记轻量摘要（哈希 + 关键字段），保证链不断、总量可统计，需要时可按需回放。
- 追问钩子：能提出「采样策略本身要可配置、可审计，且紧急时一键切回全量」的候选人，兼顾了性能与应急能力。

```typescript
// 差异化确定性采样
function shouldSample(rec, rate = 0.1) {
  if (rec.highRisk || !rec.success || rec.model === 'experimental') return true; // 关键证据全留
  let h = 0; for (const c of String(rec.traceId)) h = (Math.imul(h,31)+c.charCodeAt(0))>>>0;
  return (h % 1000) / 1000 < rate; // 确定性采样：同 traceId 结果一致
}
const logs = [
  { traceId:'t1', highRisk:false, success:true, model:'gpt-x' },
  { traceId:'t2', highRisk:true,  success:true, model:'gpt-x' },
  { traceId:'t3', highRisk:false, success:false, model:'gpt-x' },
];
console.log(logs.map(l => ({ id:l.traceId, keep:shouldSample(l) })));
```
