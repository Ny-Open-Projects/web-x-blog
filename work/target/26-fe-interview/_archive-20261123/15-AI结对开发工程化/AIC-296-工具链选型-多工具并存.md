## AIC-296：团队同时用多个 AI 工具，如何避免体验割裂与重复成本？
**答**：
- 统一资产：规则/技能/上下文文档一份多处同步（脚本化），禁止各工具各自维护。
- 统一度量：所有工具的产出都过同一门禁与统计口径，数据可比。
- 场景分工明确并写进规范：交互补全用 A、批量任务用 B、CI 用 C，避免「哪个顺手用哪个」的数据不可比。
- 定期收敛：季度评估砍掉使用率低的工具，减少许可证与维护成本。

```javascript
const multiTool = {
  assets: 'docs/standards → sync 脚本 → cursor/copilot/cli 三端',
  metrics: '统一门禁 + 统一埋点（task_type/model/duration/passRate）',
  split: 'ide: 日常 / cli: 批量与CI / api: 流水线定制',
  prune: '季度使用率 < 5% 的工具进入退订流程',
};
```
