## AIC-738：多模型协作结果的可信度如何汇总与呈现

**答**：
- 结论先行：可信度不是「投票多数」，而是「多信号加权」——模型一致性、证据充分度、历史准确率、置信度自评共同决定；呈现时要带「为什么可信」的可解释依据。
- 汇总信号：1) 跨模型一致率；2) 引用来源的可验证性；3) 该模型在此类任务的历史准确率；4) AI 自评置信度（需校准，不可全信）。
- 呈现原则：分层展示（结论 + 可信度分数 + 依据 + 分歧点），让人能「依据可信度决定复核深度」，而不是盲目接受或全盘否定。
- 追问钩子：为什么 AI 自评置信度必须校准？——模型常过度自信，未经校准的自评会抬高整体可信度，制造虚假安全感。

```javascript
// 可信度汇总：多信号加权
function trustScore(signals, weights) {
  const wsum = Object.values(weights).reduce((a, b) => a + b, 0);
  return wsum ? Object.entries(signals).reduce((s, [k, v]) => s + v * (weights[k] ?? 0), 0) / wsum : 0;
}
const score = trustScore(
  { agreement: 0.9, evidence: 0.8, history: 0.7, selfConf: 0.95 },
  { agreement: 0.4, evidence: 0.3, history: 0.2, selfConf: 0.1 }
);
console.log(score.toFixed(2)); // 0.84（自评权重低，避免虚高）
```
