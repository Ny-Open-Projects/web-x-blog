## AIC-441：笔试：为评审组装「最小充分上下文」。
**题目**：输入 diff 涉及文件与全仓 import 图。规则：diff 文件全文 + 其直接依赖的签名摘要（mock 为 `sig(file)` 函数）。输出 `{fullFiles, sigFiles}`，sigFiles 去重且不含 fullFiles。

```javascript
function buildReviewCtx(diffFiles, imports, sig) {
  const full = new Set(diffFiles);
  const sigSet = new Set();
  for (const f of diffFiles) {
    for (const dep of imports[f] || []) {
      if (!full.has(dep)) sigSet.add(dep);
    }
  }
  return { fullFiles: [...full].sort(),
           sigFiles: [...sigSet].sort().map(f => sig(f)) };
}
console.log(buildReviewCtx(
  ['a.ts'], { 'a.ts': ['b.ts', 'b.ts', 'c.ts'] }, f => `sig(${f})`));
// fullFiles [a.ts]，sigFiles [sig(b.ts), sig(c.ts)] 去重

```

**评分点**：
- 直接依赖解析（import 图一跳）。
- 去重 + 排除全文集（不重复注入）。
- 依赖图缺失文件容错（跳过不抛）。
- 输出排序稳定（字典序）。
