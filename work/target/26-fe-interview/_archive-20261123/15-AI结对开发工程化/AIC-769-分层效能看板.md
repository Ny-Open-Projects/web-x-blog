## AIC-769：团队 AI 效能的分层看板（个人/小组/组织）如何设计

**答**：
- 结论先行：分层看板 = 不同层级看不同粒度的指标——个人看「行为改进」（返工、采纳），小组看「协作效率」（交付周期、评审时长），组织看「业务结果」（逃逸率、ROI）；避免用同一套指标压到所有人。
- 设计原则：1) 个人层弱化排名（防刷、防焦虑），强调自助改进；2) 小组层是主战场（可归因、可干预）；3) 组织层看趋势与结构（跨组对比要谨慎，任务差异大）。
- 关键：层级间指标要能「下钻」（组织指标恶化能定位到小组/任务类型），否则无法行动。
- 追问钩子：为什么个人层不适合做强考核排名？——个人指标最易刷且受任务分配影响大，强考核会诱导刷量与隐瞒失败。

```javascript
// 分层看板：按角色返回不同指标视图
const VIEWS = {
  individual: ['返工轮数', '采纳率', '学习曲线'],
  team: ['交付周期', '评审时长', '返工率'],
  org: ['缺陷逃逸率', 'ROI', '交付吞吐'],
};
function dashboard(role, data) {
  return VIEWS[role].map(k => ({ metric: k, value: data[k] ?? null }));
}
console.log(dashboard('individual', { '采纳率': 0.7 })); // 个人改进视图
console.log(dashboard('org', { '缺陷逃逸率': 0.03 }));   // 组织结果视图
```
