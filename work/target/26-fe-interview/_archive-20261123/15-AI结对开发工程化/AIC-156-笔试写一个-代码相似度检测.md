## AIC-156：笔试：实现一个代码相似度检测器（n-gram 指纹 + 倒排索引），找出疑似抄袭/复现片段？
**需求**：实现 `findSimilar(genCode, corpus, { n = 8, threshold = 0.15 })`：
- 归一化代码 token（去注释/空白，统一空白为单空格）；
- 对 genCode 提取 n-gram 指纹，在语料倒排索引里查每个 gram 的命中文件；
- 输出命中 gram 比例超阈值的文件与最长连续命中片段；
- 用于 AI 产出与公开代码的许可风险比对（AIC-056）。

```javascript
function normalize(code) {
  return code.replace(/\/\*[\s\S]*?\*\//g, '').replace(/\/\/.*$/gm, '')
    .replace(/\s+/g, ' ').trim();
}
function grams(text, n) {
  const t = normalize(text).split(' ');
  return t.slice(0, Math.max(t.length - n + 1, 0)).map((_, i) => t.slice(i, i + n).join(' '));
}

function buildIndex(corpus, n) {
  const index = new Map(); // gram -> Set(fileId)
  for (const [id, code] of Object.entries(corpus)) {
    for (const g of grams(code, n)) {
      if (!index.has(g)) index.set(g, new Set());
      index.get(g).add(id);
    }
  }
  return index;
}

function findSimilar(genCode, corpus, { n = 8, threshold = 0.15 } = {}) {
  const index = buildIndex(corpus, n);
  const gs = grams(genCode, n);
  if (!gs.length) return [];
  const hitCount = new Map();
  let run = new Map(); // fileId -> 当前连续命中长度
  for (const g of gs) {
    const hits = index.get(g);
    const active = new Map();
    for (const f of hits ?? []) {
      hitCount.set(f, (hitCount.get(f) ?? 0) + 1);
      active.set(f, (run.get(f) ?? 0) + 1);   // 连续段累加
    }
    run = active; // 不命中则连续段清零
  }
  return [...hitCount.entries()]
    .filter(([f, c]) => c / gs.length >= threshold)
    .map(([f, c]) => ({
      file: f, ratio: +(c / gs.length).toFixed(3),
      longestRun: longestRunOf(corpus[f], gs, n),
      verdict: c / gs.length >= 0.4 ? 'NEED_LICENSE_REVIEW' : 'REVIEW',
    }))
    .sort((a, b) => b.ratio - a.ratio);
}
function longestRunOf(code, gs, n) {
  const src = normalize(code);
  let best = 0;
  for (const g of gs) if (src.includes(g)) best = Math.max(best, n);
  return best; // 简化版：确认存在即可，精确最长段可用后缀数组（面试提一句）
}

// 测试
const corpus = { 'gpl-lib': 'function deepClone(obj) { if (obj === null) return null; const r = Array.isArray(obj) ? [] : {}; for (const k in obj) r[k] = deepClone(obj[k]); return r; }' };
console.log(findSimilar('function deepClone(o) { /* 注释 */ if (o === null) return null; const r = []; for (const k in o) r[k] = deepClone(o[k]); return r; }', corpus));
```

**评分点**：
1. 归一化必须先去注释再压空白，否则注释差异会击穿指纹；
2. 倒排索引而非线性双循环——语料大时复杂度差距是面试区分点；
3. 连续命中段追踪（run 断裂重置）用于定位「抄袭片段」位置；
4. 阈值分级：高命中直接 NEED_LICENSE_REVIEW；
5. 主动说明简化版 longestRun 的局限（可用滑动哈希/后缀数组优化）。
