## AIC-078：AI 时代为什么强调「评审抽样」？抽什么样、抽多少才有代表性？
**答**：
- 背景：AI 让产出量翻倍，全量深评不可行；但全量浅评（扫一眼就过）等于没有评审。抽样是把有限注意力投到高风险产出的方法。
- 抽什么：按风险加权抽样——核心业务/支付权限/新依赖引入必抽；模式化 CRUD 低抽；AI 一次生成量特别大的（>500 行）必抽，因为大产出里藏坏代码的概率高。
- 抽多少：经验值是「每个 PR 至少 1 个文件深评 + 每周 1 次团队级抽查（每人随机 1 个已合并 PR 复盘）」；团队级抽查对齐评审标准，比单点抽更有校准价值。
- 抽样结果双用途：个人反馈（哪里理解不到位）+ 门禁调优（AI 漏了什么、人漏了什么）。
- 追问钩子：抽样发现的系统性问题要变成规则/清单（AIC-042），否则同样的问题会重复出现。

```javascript
// 风险加权抽样器
function sampleForReview(pr) {
  const weight = (f) => f.lines > 300 ? 5 : f.path.includes('payment') ? 5 :
    f.path.includes('auth') ? 4 : f.lines > 100 ? 2 : 1;
  return pr.files.sort((a, b) => weight(b) - weight(a)).slice(0, 1); // 每PR深评1个最高风险文件
}
```
