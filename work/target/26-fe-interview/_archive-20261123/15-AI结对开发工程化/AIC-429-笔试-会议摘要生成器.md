## AIC-429：笔试：把值班交接记录压缩成结构化交接摘要。
**题目**：记录 `[{type, text}]`（type: done/todo/risk/pending-decision）。实现 `handoff(records)`：按 type 分组输出四要素摘要对象；todo/risk 为空时显式标 'none'（防漏）。

```javascript
function handoff(records) {
  const g = { risk: [], todo: [], done: [], pendingDecisions: [] };
  for (const r of records) (g[r.type] ?? g.todo).push(r.text);
  return {
    risks: g.risk.length ? g.risk : ['none'],
    next: g.todo.length ? g.todo : ['none'],
    state: g.done,
    pendingDecisions: g.pendingDecisions.length ? g.pendingDecisions : ['none'],
  };
}
console.log(handoff([
  { type: 'done', text: '支付告警已确认恢复' },
  { type: 'risk', text: 'CDN 流量异常待观察' },
])); // risks 1 条；next 'none' 显式

```

**评分点**：
- 四要素分组齐全，空组显式 'none' 而非缺省（防漏报）。
- risk 排前（交接重点）。
- pending-decision 需带 owner 字段（记录中提取，简化为原文）。
- 输出对象键固定，便于下游消费。
