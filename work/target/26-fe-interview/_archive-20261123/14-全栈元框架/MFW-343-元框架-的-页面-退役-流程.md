## MFW-343：页面退役

**答**:
- 五步退役：①流量确认（30 天 UV≈0？外部链接盘点——search console/外链扫描）②替代物就位（相关页 301 映射表——SEO 权重转移）③应用层下线（路由删 + 410 Gone 响应——比 404 语义准，爬虫快速弃索引）④依赖清理（该页专属 Action/组件/依赖卸载——体积与攻击面同步缩）⑤缓存与引用清扫（CDN purge + sitemap 移除 + 内部链接 grep 清零）
- 自动化：退役清单文件（routes.retire.json: { path, to, date }）→ CI 生成 410 中间件映射 + 完成后自动删条目——流程即配置
- 反模式：直接删路由（外链用户撞 500 而非 410）、只删 UI 留 Action（攻击面残留——死 Action 仍可被直接调用）

```json
[{ "path": "/old-campaign", "to": "/new-campaign", "code": 301, "until": "2027-01" },
 { "path": "/deprecated-tool", "code": 410 }]
// 中间件读表：命中 → 301/410；`until` 过期自动移除映射（外链自然衰减）
// 红线：删路由必配条目；删页必删其 Action（攻击面同步缩）
```
