## MFW-893：构建缓存键要覆盖哪些输入才算完整，漏掉输入会导致什么

**答**：
- 结论：缓存键必须覆盖所有「影响产物」的输入——源码、依赖锁、构建配置、相关环境变量、构建工具版本；漏掉任何一项都会产生「假命中」（用了旧产物却以为命中）。
- 落地：用内容哈希汇总所有输入；把构建工具/Node 版本也纳入；新增影响产物的输入时同步更新键计算。
- 追问钩子：怎么知道有没有漏输入？——做「改输入→看缓存是否失效」的对拍测试，或定期用干净环境重建比对产物哈希。

```javascript
function cacheKey(ctx) {
  return stableHash({
    src: ctx.sourceHashes,        // 源码哈希集合
    lock: ctx.lockHash,           // 依赖锁
    config: ctx.buildConfig,      // 构建配置
    env: pickEnv(ctx.env, ['NODE_ENV', 'API_BASE']), // 影响产物的 env
    toolchain: ctx.toolVersion    // 构建工具/Node 版本
  });
}
// 对拍测试：改任一输入，缓存键必须变化
const k1 = cacheKey(ctx);
const k2 = cacheKey({ ...ctx, buildConfig: { minify: true } });
console.assert(k1 !== k2, '改了配置却命中旧缓存 → 键漏了输入！');
```
