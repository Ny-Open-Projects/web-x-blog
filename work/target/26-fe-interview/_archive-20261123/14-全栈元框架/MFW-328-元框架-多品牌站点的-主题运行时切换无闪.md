## MFW-328：主题切换防闪

**答**:
- 闪变三源：CSS 变量晚注入（FOUC）、字体 swap 跳宽、图片占位比失衡——主题切换 = 三者叠加的视觉事故
- 协议：主题变量随 HTML 首字节内联（SSR layout 读租户/用户偏好 → <style>:root{...}</style> 在 body 前——RBL-318 同款）；class/data-theme 在 html 标签属性级（最先解析）；切换动画用 ViewTransitions 包变量变更（旧新状态交叉淡入）
- 字体与图：品牌字体多套预加载（用户品牌命中即 zero-swap）；品牌插画用 aspect-ratio 盒固定
- 持久化与同步：偏好存 cookie（服务端首屏即知）+ localStorage 镜像——双写以 cookie 为准（SSR 一致性优先）

```text
协议：变量 ∈ 首字节内联 + html 属性级主题标 + VT 包切换
字体/图：品牌集预载 + aspect-ratio 固定盒
存储：cookie 为准（SSR 首屏一致），localStorage 镜像
```
