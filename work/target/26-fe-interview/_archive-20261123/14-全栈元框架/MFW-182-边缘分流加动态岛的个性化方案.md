## MFW-182：边缘渲染下怎么做首屏个性化（分流 + 动态岛）？
**答**：
- 目标：营销页主体 99% 用户一致（可缓存），但首屏有登录名、会员价、推荐位等千人千面——不能因个性化把整页打成动态。
- 核心方案：把页面拆成「静态壳 + 个性化孔」。壳走 CDN 长缓存；孔用以下三种之一填充：
  - ① Server Islands（Astro）：服务端按 cookie/geo 单独渲染孔并流式注入，HTML 里只有占位符，壳缓存不被污染。
  - ② RSC/PPR 思路（Next）：静态部分 prerender，动态部分读 cookies 后流式补齐。
  - ③ 客户端岛：孔由客户端 JS 取 `/api/me` 填充——实现最简单，但首屏有闪现。
- 边缘分流配合：Middleware/边缘函数按 cookie 读写用户分组、区域等「变体标识」，把变体编入缓存 key（如 `Vary` / cache key 拼接 bucket），保证不同人群命中各自缓存版本。
- 取舍：Server Island 每请求多一次服务端往返（但可并行流式）；客户端岛省服务端但牺牲首屏一致性；高变体数（>10 个变体）时缓存命中率崩塌，应退回客户端岛。

```astro
---
// Astro Server Islands：壳是静态缓存，孔按请求者渲染
const user = Astro.cookies.get('session');
---
<Layout> <!-- 整个 Layout 命中 CDN 缓存 -->
  <h1>今日精选</h1>
  <ServerIsland component={MemberPrice} props={{ sku: 'A1' }} /> <!-- 按登录态单独渲染 -->
</Layout>
```
