## MFW-047：预取的 Payload 在导航时怎么复用？过期怎么校验？
**答**：
- 流程：Link 可见时 prefetch 拉取 Payload 存入 Client Router Cache；点击导航时命中缓存**立即渲染**，同时后台可重新校验（revalidate 后的数据下次导航生效）。
- 过期校验两层：**时间层**（staleTime 决定是否直接用）与**版本层**（服务端在响应头携带 buildId/时间戳，客户端发现不匹配则丢弃缓存重新拉）。
- 动态路由只预取「loading 壳」的设计正是为了过期问题：动态数据不预取、点击时现取，天然不过期。
- 应用层自定义预取（如表格分页预取下一页）：用 TanStack Query 的 `queryClient.prefetchQuery` 或自己封装 Map 缓存 + TTL。
- 复用进行中的请求：预取返回 Promise 时，导航 `get(url)` 直接拿到**同一个 Promise**，不重复发请求（请求合并）。

```jsx
'use client';
// 分页预取下一页：导航前把数据备好，切页零等待
import { useQuery, useQueryClient } from '@tanstack/react-query';

export function usePrefetchPage(listKey, page) {
  const qc = useQueryClient();
  return () => qc.prefetchQuery({
    queryKey: [listKey, page + 1],
    queryFn: () => fetchList(listKey, page + 1),
    staleTime: 30_000, // 30s 内预取结果保持新鲜
  });
}

export function Table({ page }) {
  const prefetchNext = usePrefetchPage('orders', page);
  useEffect(() => {
    prefetchNext(); // 当前页渲染完即预取下一页
  }, [page]);
  const { data } = useQuery({ queryKey: ['orders', page], queryFn: () => fetchList('orders', page) });
  return <tbody>{data?.rows.map((r) => <tr key={r.id}>{/*...*/}</tr>)}</tbody>;
}
```
