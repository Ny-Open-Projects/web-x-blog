## MFW-850：用户关闭页面/切换路由，怎么让服务端停止无谓的流式渲染

**答**：
- 结论：客户端断开连接后，服务端通过 request.signal / res.on(close) 感知，把 abort 信号沿渲染链传播到数据源（取消 DB 查询、停止 Suspense 渲染）。
- 落地：每个异步数据获取接收 signal；流写入前检查 aborted；断开后不再 flush 剩余补丁。
- 追问钩子：无法取消的查询怎么办？——至少停止渲染与写入、释放连接，避免占用资源。

```javascript
async function streamPage(req, res) {
  const ac = new AbortController();
  res.on('close', () => ac.abort());                 // 客户端断开
  res.setHeader('Content-Type', 'text/html');

  for await (const chunk of renderChunks(ac.signal)) {
    if (ac.signal.aborted) break;                    // 停止输出
    res.write(chunk);
    // 把 signal 传到数据层，取消在途查询
  }
  res.end();
}

async function* renderChunks(signal) {
  const data = await db.query(sql, { signal });      // 可取消查询
  yield render(data);
}
```
