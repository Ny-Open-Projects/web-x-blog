## MFW-274：RSC 下分页选型

**答**:
- offset 分页：可跳页/SEO 友好（/list?page=3 独立 URL 可缓存 ISR）——深翻性能差与漂移（插入导致重复/漏）
- cursor 分页：性能稳定（WHERE id > ? INDEX）+ 无漂移——适合无限滚动；不可跳页、URL 语义弱（cursor 不透明）
- RSC 语境加分项：searchParams 变化 = 新路由渲染（服务端取数天然按页）——cursor 编码进 searchParams 同样可分享（cursor 是签名过的稳定 token 时）
- 混合惯例：列表主体 cursor（无限流）+ 页码目录（跳页用预计算页首 id 映射——目录表定时刷新）——两个世界各取所长

```javascript
// cursor 进 searchParams（可分享）
/search?q=x&cursor=eyJIYXNoIjoimCJ9&dir=next
// 查询侧
where: { id: { lt: decode(cursor).lastId } }, take: 20, orderBy: { id: 'desc' }
// 跳页：pageDirectory 表（pageNo → firstId，定时任务刷新）
```
