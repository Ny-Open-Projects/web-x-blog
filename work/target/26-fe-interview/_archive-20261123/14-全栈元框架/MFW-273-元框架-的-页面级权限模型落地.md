## MFW-273：页面级权限落地

**答**:
- 双层守卫：路由级（layout/loader 判角色重定向 403——体验层）+ 数据级（每个查询带主体做行级过滤——真正的墙）；前端路由守卫只是体验优化，接口裸奔等于没防
- RSC 落位：layout 内 getSession + 角色判定（框架请求上下文自然可用——比 SPA 守卫更早更可靠，服务端渲染前就拦截）
- 细粒度：字段级脱敏在数据函数（按角色 select 白名单——同接口不同视图）；操作级在 Action（MFW-227 的 handler 内 canWrite）
- 组织化：权限码表单点维护（can(user, 'order:read', res) 统一入口）——散落的 if(role) 是权限债务

```javascript
// layout 路由级
export default async function AdminLayout() {
  const u = await getUser()
  if (!can(u, 'admin:access')) notFound()          // 或 redirect('/403')
}
// 数据级（真正防线）
order.findMany({ where: tenantScope(user) })       // RLS/显式 where
```
