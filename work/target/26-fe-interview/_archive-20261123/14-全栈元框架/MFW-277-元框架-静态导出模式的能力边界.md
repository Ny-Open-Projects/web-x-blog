## MFW-277：静态导出能力边界

**答**:
- 边界清单（output: 'export' 下不可用）：Server Actions/Route Handler 动态逻辑、ISR 按需再生成、middleware、图片优化器（需替换第三方 loader）、fetch 缓存语义退化（无服务端）、i18n 路由部分能力
- 可行替代映射：表单提交 → 外部 API/第三方表单服务；按需数据 → 客户端 fetch 直连（带 CORS/鉴权调整）；重写/鉴权前置 → CDN 边缘函数（CF Workers 同栈）
- 适用判定：内容型站点（文档/博客/落地页）+ 客户端能自足的交互 → 静态导出（部署成本最低）；任何「每请求决策」需求出现即出界
- 混合出口：主站动态 + 文档站静态导出分仓——按页需求选部署形态而非全站一刀切

```text

替代：外部 API / CDN 边缘函数 / 客户端直连
判定：出现「每请求决策」需求 → 出界，回动态部署
```
