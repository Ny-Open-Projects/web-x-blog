## MFW-294：限流三维落位

**答**:
- 三维键设计：IP 维（防扫描——Middleware/CDN 层，匿名可判）、用户维（业务配额——鉴权后 RSC/Action 层，登录态才有 uid）、接口维（单接口成本保护——DB 重查询独立预算）
- 层级顺序：CDN WAF（粗）→ Middleware IP 桶（轻量内存/KV）→ Handler 用户配额（Redis 令牌桶）——越靠外越便宜，重查贵资源只在深层的用户/接口维
- 实现：分布式令牌桶（Redis Lua 原子扣减——实例并发安全）；429 响应带 Retry-After + 桶状态头（客户端礼貌退避 MFW-268 呼应）
- 白名单与豁免：内部探活/付费高配额——限流规则即代码（可测试），不带特例硬编码

```javascript
// Action 内用户维（示例：Redis Lua 令牌桶）
const ok = await evalBucket(`u:${user.id}:order:create", { cap: 10, window: 60_000 })
if (!ok) return new Response(JSON.stringify({ error: 'rate' }), { status: 429,
  headers: { 'Retry-After': String(retryAfterSec) } })
```
