## MFW-882：多层灰度叠加（业务灰度 × 基础设施灰度）同时命中同一用户怎么决策

**答**：
- 结论：多层实验必须明确优先级与互斥关系——同一用户可能同时落进多个层，需定义哪层优先、哪些层互斥，否则会出现互相覆盖或矛盾体验。
- 落地：每层有 domain（正交域）与优先级；正交层可叠加、互斥层二选一；决策时按优先级合并并记录审计日志。
- 追问钩子：为什么正交层可以叠加？——它们影响不同维度（如按钮颜色 vs 推荐算法），互不干扰。

```javascript
const LAYERS = [
  { name: 'ui', domain: 'ui', priority: 10, exclusive: false },
  { name: 'pricing', domain: 'price', priority: 20, exclusive: true },
  { name: 'infra', domain: 'render', priority: 5, exclusive: false }
];
function resolveLayers(hits) {
  const sorted = hits.sort((a, b) => b.priority - a.priority);
  const used = new Set(), out = [];
  for (const h of sorted) {
    const layer = LAYERS.find(l => l.name === h.layer);
    if (layer.exclusive && used.has(layer.domain)) continue; // 互斥层跳过
    used.add(layer.domain);
    out.push({ layer: layer.name, variant: h.variant });
  }
  return out;
}
```
