## MFW-853：怎么根据客户端带宽动态调整流式渲染的内容量

**答**：
- 结论：用首块 RTT 或客户端上报的下载速率估带宽，低带宽用户走「精简流」——减少补丁、压缩 HTML、跳过次要内容。
- 落地：客户端上报 Network Information API（effectiveType），服务端按 2g/3g/4g 分档决定渲染哪些边界。
- 追问钩子：带宽估计不准怎么办？——多信号融合 + 保守降级，宁可多给也别丢关键内容。

```javascript
// 客户端上报网络类型
navigator.connection?.addEventListener('change', () =>
  fetch('/api/net', { method: 'POST', body: navigator.connection.effectiveType }));

// 服务端分档渲染
const TIER = { 'slow-2g': 0, '2g': 0, '3g': 1, '4g': 2 };
function tierFor(effectiveType) { return TIER[effectiveType] ?? 2; }
function boundariesFor(tier) {
  const all = ['hero', 'price', 'reviews', 'recommend', 'video'];
  return all.slice(0, [1, 3, 5][tier]);              // 低档只给关键内容
}
console.log(boundariesFor(tierFor('2g')));           // ['hero']
```
