## MFW-372：4xx/5xx 分化

**答**:
- 分化表核心：4xx 是「客户端的事实」（可缓存短 TTL、结构化 body、无告警或低级——404 洪水另说 MFW-309）；5xx 是「我们的故障」（绝不缓存、必告警、body 只给 traceId 不漏栈）
- 细则行：401→挑战头（WWW-Authenticate + 登录入口）；403→不解释原因（防枚举——与 404 同文案可选）；409→带服务端最新态（冲突合并 MFW-272）；422→字段级 errors 数组；429→Retry-After+桶状态（MFW-294）；500/503→traceId+状态页链接，Retry-After 给爬虫（礼貌性延迟重抓）
- 一致性：所有错误走同一信封（{ error: { code, path?, message, traceId } }）——客户端解析器一个实现（MFW-339 协议的服务端总表）
- 演练：故障注入断言各码不串（限流不返回 500、内部错误不返回 403——状态码语义漂移是集成事故高发）

```text
分化铁律：4xx=客户端事实（短缓存/结构化/低噪） | 5xx=我方故障（零缓存/必告警/只给 traceId）
信封统一：{ error: { code, path?, message, traceId } } 全码一个解析器
```
