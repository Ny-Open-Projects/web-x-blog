## MFW-242：跨框架缓存语义统一

**答**:
- 背景：团队同时有 Next（revalidateTag）与 Start/Nuxt（各自失效语义）——业务同学学三套失效 API 是灾难
- 统一面设计：`cacheApi.get(key, { tags, ttl }) / invalidate(domain, id?)` 薄适配层——各框架后端实现映射（Next → fetch tag + revalidateTag；Start → Query cache；自建 → Redis）
- 失效协议标准化：域事件（{ domain, ids, level: 'mark'|'refetch'|'clear' }）广播 → 各框架适配器翻译执行——与 ZSM-448 失效图同构（前端状态层与元框架缓存层共用一套协议思想）
- 收益：业务代码零框架绑定（换框架只换 adapter）+ 失效演练/监控做一次全框架生效

```javascript
// 统一面（团队包 @team/cache）
export const cache = {
  async get(k, o) { return adapters[current].get(k, o) },
  async invalidate(domain, opts) { bus.emit('cache:invalidate', { domain, ...opts }) },
}
// adapters.next.get = (k, { tags, ttl }) => fetch(url, { next: { tags, revalidate: ttl } })
```
