## MFW-349：实验代码清理自动化

**答**:
- 债务模型：每实验留下双分支代码 + flag 判定——30 个并存实验 = 状态空间爆炸与测试矩阵不可维护；清理必须有截止压力
- 自动化链：实验注册表（MFW-466 式带 eolDate）→ eol-7d 自动建清理 PR（codemod 删 flag 保留胜出变体——实验结论写入 PR 描述）→ 合并后 flag 键从配置矩阵删除（MFW-348 死键检测兜底验证）
- 未决策实验处理：eol 到达无结论 → 强制二选一（默认回 control——不作为也是一种决策，由规则代替拖延）
- 度量：并存实验数 / 平均实验存活时长 / 清理 PR 自动化率——三项进平台季度报告（实验卫生积分）

```text
链：注册表 eol → -7d 自动清理 PR（codemod 留胜者）→ flag 键矩阵删除（死键检测验证）
规则：eol 无结论 = 默认回 control（不决策也是决策）
度量：并存数/平均存活/自动化率 → 季度实验卫生分
```
