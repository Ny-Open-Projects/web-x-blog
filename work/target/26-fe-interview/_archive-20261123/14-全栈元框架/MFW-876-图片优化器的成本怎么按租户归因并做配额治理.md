## MFW-876：图片优化器的成本怎么按租户归因并做配额治理

**答**：
- 结论：图片优化（实时缩放/格式转换）消耗 CPU 与带宽，需按租户计量并设配额，防止单租户滥用拖垮共享优化器。
- 落地：优化请求带 tenantId，记录原图尺寸/输出尺寸/耗时，按租户聚合成本；超额租户降级（限尺寸、走缓存、拒绝实时优化）。
- 追问钩子：为什么不无限缓存所有尺寸？——长尾尺寸会撑爆对象存储，需按热度淘汰。

```javascript
function optimize(req, res) {
  const t = req.tenantId;
  const cost = estimateCost(req.width, req.height);      // CPU 估算
  if (quota.used(t) + cost > quota.limit(t)) {
    return res.json({ url: cachedOriginal(req), degraded: true }); // 降级
  }
  quota.consume(t, cost);
  const out = sharp(req.buffer).resize(req.width, req.height).webp().toBuffer();
  metrics.inc('img.cost', cost, { tenant: t });
  return out;
}
function estimateCost(w, h) { return Math.round(w * h / 10000); }
```
