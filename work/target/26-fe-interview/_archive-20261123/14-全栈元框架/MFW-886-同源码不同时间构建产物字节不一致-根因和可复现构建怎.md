## MFW-886：同源码不同时间构建产物字节不一致，根因和可复现构建怎么做

**答**：
- 结论：构建非确定性主要来自四类——嵌入的时间戳、绝对路径、遍历顺序不稳定、随机 ID；可复现构建要求「相同输入→逐字节相同产物」。
- 落地：固定构建时间戳（SOURCE_DATE_EPOCH）、路径相对化、稳定排序、禁用随机种子；产物按内容哈希命名。
- 追问钩子：为什么可复现构建重要？——安全审计（验证产物确实由某源码生成）、缓存命中（内容寻址）、供应链可信。

```javascript
// 稳定排序：避免遍历顺序影响产物
function stableStringify(obj) {
  if (Array.isArray(obj)) return '[' + obj.map(stableStringify).join(',') + ']';
  if (obj && typeof obj === 'object')
    return '{' + Object.keys(obj).sort().map(k => JSON.stringify(k) + ':' + stableStringify(obj[k])).join(',') + '}';
  return JSON.stringify(obj);
}
// 固定时间戳 + 路径相对化
const ts = process.env.SOURCE_DATE_EPOCH || '0';
const output = stableStringify(config).replace(/\/abs\/path/g, '.');
// 两次构建 output 逐字节相同 → 内容哈希一致
```
