## MFW-399：URL 状态边界

**答**:
- 进 URL 判据三问：刷新要还原吗？要分享吗？要被搜索引擎索引吗？——三问任意「是」才进（筛选/页码/排序/选中实体 id）
- 不进清单：草稿正文（大且私密——走 server 草稿 MFW-317）、多选集合大集（>20 项——压缩后仍是 URL 攻击面 RBL-416 长度上限）、一次性动作状态（confirm 弹窗——sessionStorage）、AB 桶位（服务端头已定——URL 双写打架）
- 编码纪律：层级嵌套 ≤2（a.b.c 语义压成两个 param）、布尔用存在性（?dark 而非 dark=1）、枚举白名单出 URL 解析器（MFW-366 状态机入口）
- 演进：URL 参数也是契约（书签存量）——弃用参数走 301 归一（MFW-368 表），不做静默忽略（用户书签静默失效=信任损耗）

```text
三问进 URL；草稿/大集合/一次性/桶位不进
编码：嵌套≤2 / 布尔存在性 / 枚举白名单出解析器
演进：弃用参数 301 归一（书签是契约）
```
