## MFW-337：BFF/网关分层

**答**:
- 职责表：网关（横向安全：鉴权粗验/限流/WAF/路由/可观测注入——不碰业务语义）；BFF/元框架 server（纵向编排：聚合多服务/字段裁剪/端适配/业务鉴权）——交叉即混乱（网关做字段裁剪=业务进基建；BFF 做 IP 限流=重复建设）
- 契约点：网关传递可信上下文头（内部签名：uid/tenant/roles——BFF 免重复解析与信任问题；外部伪造被网关签名剥离保证）
- 演进安全：BFF 下沉服务化（多前端复用同编排）时机 = 第三个消费端出现（复制粘贴第三次前抽）
- 反模式清单：BFF 直连生产库（应走服务 API——BFF 是编排层不是 DB 客户端）；网关做业务路由重写（语义决策漏进基建）

```text
分层：网关=横向安全与透传（签名上下文头） / BFF=纵向编排与业务鉴权
契约：内部上下文签名头（防伪造）
演进：第三个消费端出现前抽服务化
```
