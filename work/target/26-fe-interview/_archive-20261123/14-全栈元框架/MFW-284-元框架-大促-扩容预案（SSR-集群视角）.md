## MFW-284：SSR 大促预案

**答**:
- 容量模型：SSR 节点 QPS 上限 = CPU 核 × (1000ms/单请求 CPU ms)——压测得单请求 CPU（如 30ms）→ 8 核节点 ~260 QPS → 目标峰值反推节点数 ×1.5 冗余
- 分级降级链：SSR 过载 → ①延长 ISR TTL（缓存顶上）②关停非核心个性化段（PPR 动态岛回退骨架）③全站降级到最近 ISR 快照（「旧但可用」）——每级预设开关与触发指标（CPU>80% 持续 1min）
- 热点隔离：爆款商品页独立缓存组（单 key 热点不挤普通页的再生成队列）
- 演练硬要求：预案级每级在预发真实触发过一次（没演练过的降级 = 没有降级）

```text
容量：8核×(1000/30ms CPU)≈260QPS/节点 → 目标峰值 ×1.5 冗余
降级三级：ISR TTL↑ → 关动态岛 → 全量快照（开关+CPU 指标预演）
```
