## MFW-321：组合式布局深水

**答**:
- 嵌套语义三问：布局树与路由树是否同构（不一致 = 匹配歧义源）、共享 layout 的数据是否按路由级分片获取（顶层 layout 重查询 = 每页都付）、布局切换时状态保留策略（同布局实例复用——不卸载；跨布局 = 全新挂载）
- 槽位化替代深嵌套：@slot 并行段（MFW-254）+ 组件组合比 5 层目录嵌套更可测——布局深度是可维护性负债
- 性能守则：layout 的数据获取独立于页面（其失败不应毁页面——layout 级 error.js 分开）；跨路由稳定区域（导航/侧栏）放共享 layout 避免重渲染
- 反模式清单：layout 里做页面级数据预取、用布局层级表达权限（应数据层判）、为复用强行抽 8 层布局

```text
三问自查：树同构？ / layout 数据按级分片？ / 状态保留语义明确？
守则：layout 轻 + 槽位化替代深嵌套 + 稳定区域上提
```
