## MFW-890：环境变量注入构建产物会带来哪些确定性和安全问题

**答**：
- 结论：构建期注入的环境变量会固化进产物；把不该公开的 secrets 注入会泄露，把易变值（时间戳/随机值）注入会破坏可复现。
- 落地：区分构建期变量（NEXT_PUBLIC_*，会进产物）与运行期变量（仅服务端）；只白名单确定性的构建变量，secrets 走运行期注入。
- 追问钩子：一个变量该构建期还是运行期注入怎么判断？——值是否随部署环境变化且需即时生效：是则运行期，否则构建期。

```javascript
// ❌ 危险：secrets 注入客户端产物
const apiKey = process.env.SECRET_KEY;   // 打进 bundle → 泄露

// ✅ 构建期：只放确定性的公开常量
const publicCfg = { apiBase: process.env.NEXT_PUBLIC_API_BASE }; // 白名单

// ✅ 运行期：敏感/易变值由服务端在请求时读取
export async function GET() {
  const key = process.env.SECRET_KEY;    // 仅服务端，运行期读取
  return NextResponse.json(await callApi(key));
}
// 指纹计算：只把 NEXT_PUBLIC_* 中白名单项纳入输入
```
