## MFW-852：慢网用户的流式渲染怎么做背压丢弃，只保留首屏关键内容

**答**：
- 结论：背压时不阻塞渲染，而是按优先级丢弃低价值内容（推荐位、评论），保证首屏关键内容（标题/价格/CTA）先到。
- 落地：给每个边界打优先级；监测 socket 可写缓冲或客户端带宽反馈，超阈值时跳过低优先级边界，输出精简占位。
- 追问钩子：丢弃后内容还能补吗？——可延后通过客户端二次请求补齐，但首屏体验已保住。

```javascript
const BOUNDARIES = [
  { name: 'hero', priority: 10 },
  { name: 'price', priority: 9 },
  { name: 'comments', priority: 3 },
  { name: 'recommend', priority: 1 }
];
function backpressureFilter(boundaries, pressure) {
  const threshold = pressure > 0.8 ? 5 : pressure > 0.5 ? 2 : 0;
  return boundaries.filter(b => b.priority >= threshold); // 丢弃低优先级
}
async function render(req, res) {
  const pressure = res.writableLength / (res.writableHighWaterMark || 1);
  for (const b of backpressureFilter(BOUNDARIES, pressure)) {
    res.write(await b.render());                     // 关键内容优先
  }
}
// 高背压只留 hero/price，评论/推荐延后客户端补
```
