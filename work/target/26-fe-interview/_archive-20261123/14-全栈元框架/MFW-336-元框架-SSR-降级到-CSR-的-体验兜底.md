## MFW-336：SSR→CSR 兜底

**答**:
- 决策树：SSR 集群不可用（网关 5xx/超载熔断）→ 边缘切「静态壳 + 客户端全量拉数」模式（无服务端渲染但应用可用——用户可感知变慢而非不可用）
- 实现三件：①静态壳预生成（每路由极简骨架 html 常驻边缘——含 loader 引导代码）②客户端数据直连（绕过死掉的 SSR 层，直打只读 API/缓存网关）③功能降级清单（依赖 server 的能力显式隐藏——搜索联想关、下单只读提示）
- 恢复回切：健康探测连续通过 → 指针回 SSR（灰度回切防抖动——RBL-496 同款稳定窗）
- 演练：每季度强制触发一次（拔掉 SSR 探活——降级链没跑过就等于没有）

```text
决策：SSR 挂 → 静态壳+客户端直连（可用性>渲染性）
三件：预置壳 / 只读数据直连 / 功能显式降级清单
纪律：季度强制演练 + 稳定窗回切
```
