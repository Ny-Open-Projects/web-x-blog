## TST-697：混沌实验的安全边界与伦理怎么把握？

**答**：
- 结论：生产混沌必须避开资金、隐私、合规红线——这些域只在预发做，绝不在真实用户上注入。
- 建立实验审批制：影响面、时长、回滚方案、止损人四要素缺一不可。
- 对用户透明：告知与补偿机制；保留实验审计日志供复盘。
- 追问钩子：老板要求「偷偷」做一次生产混沌看真实效果，你怎么回应？

```javascript
function complianceCheck(exp, policy) {
  const blocked = exp.domains.filter(d => policy.forbidden.includes(d));
  return {
    allowed: blocked.length === 0 && exp.approved && exp.rollbackReady,
    blocked,
    need: ['domains', 'duration', 'owner', 'killSwitch']
      .filter(k => !exp[k]),
  };
}
console.log(complianceCheck({ domains: ['pay'], approved: false,
  rollbackReady: true }, { forbidden: ['pay'] }));
```
