## TST-961：测试数据的「留存期限与自动销毁」怎么设计才合规？
**答**：
- 结论：测试数据也适用数据最小化与留存限制——给每份数据集设 TTL，到期自动销毁并记录销毁凭证，禁止「永久躺在库里」。
- 做法：数据集登记 createdAt/expiresAt/purpose；定时任务扫描过期集并软删除→硬删除；审计日志保留销毁记录。
- 例外：需长期留存的基线数据必须脱敏且通过合规审批。
- 追问钩子：一个测试库里躺着 3 年前的真实用户快照，没人记得是谁导的，你怎么安全清理且不误删还在用的数据？

```javascript
const DATASETS = [
  { id: 'D1', createdAt: '2026-01-01', ttlDays: 90, lastUsed: '2026-03-01', purpose: '功能测试' },
  { id: 'D2', createdAt: '2026-11-01', ttlDays: 90, lastUsed: '2026-11-20', purpose: '大促回归' },
];
function findExpired(datasets, now = Date.now()) {
  return datasets.filter(d => {
    const ttlEnd = new Date(d.createdAt).getTime() + d.ttlDays * 864e5;
    const idleEnd = new Date(d.lastUsed).getTime() + 30 * 864e5; // 30 天未用也可清理
    return now > ttlEnd || now > idleEnd;
  }).map(d => ({ id: d.id, reason: now > new Date(d.createdAt).getTime() + d.ttlDays * 864e5
    ? '超过留存期' : '长期未使用' }));
}
console.log(findExpired(DATASETS)); // [{ id:'D1', reason:'超过留存期' }] → 先通知 owner 再销毁
```
