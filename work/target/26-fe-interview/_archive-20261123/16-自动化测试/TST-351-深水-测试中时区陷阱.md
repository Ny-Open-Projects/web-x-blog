## TST-351：跨时区功能（活动开始时间/国际化日期）的测试设计？
**答**：
- 内部统一 UTC 存储 + 展示层转换——单测锁存储层（不因时区漂移）。
- 展示断言用「绝对时刻 + 指定时区」：测试固定 timezoneId 而非依赖 runner 时区。
- 跨日边界：UTC+8 与 UTC-5 的「同一天」语义差异专项用例。
- 夏令时：美区时区的 DST 切换日回归（每年两次）。

```javascript
test.use({ timezoneId: 'America/New_York' });
test('DST 切换日活动', async ({ page }) => {
  await page.clock.install({ time: new Date('2026-03-08T07:00:00Z') }); // DST 当日
  await expect(page.getByTestId('event-time')).toHaveText('2:00 AM'); // 边界正确
});
```
