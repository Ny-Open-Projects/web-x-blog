## TST-260：微前端共享依赖（externals/react 同版本）的测试保障？
**答**：
- 版本一致性测试：构建产物中 React 等共享依赖只出现一份（bundle 分析断言）。
- 共享依赖升级演练：升级共享 React 版本 → 全子应用兼容矩阵跑通后发布。
- fallback 行为：共享依赖加载失败的兜底（本地降级副本）测试。
- 依赖声明协议：子应用声明 requires: {react: '18'}，主应用满足性校验进 CI。

```javascript
// bundle 断言：共享依赖单实例
const bundles = await analyzeDist();
const reactCopies = bundles.filter(b => /node_modules[\\/]+react[\\/]/.test(b.src));
expect(reactCopies.length).toBe(1);   // 多副本 → 内存双实例风险

```
