## TST-243：组件库支持多主题（暗色/品牌定制）时测试怎么组织？
**答**：
- token 断言为主：每个主题文件校验「必要 token 全覆盖且映射有效」（暗色下无硬编码亮色）。
- 视觉 diff 抽代表组件跑各主题（不必全量组件 × 全主题）。
- 对比度自动校验：文本色/背景色组合跑对比度计算（WCAG AA ≥ 4.5:1）。
- 主题切换行为测试：切换后 CSS 变量更新且组件重渲染正确。

```javascript
import { tokens } from 'design-tokens/dark';
test.each(Object.entries(tokens.color))('%s 满足对比度', (name, color) => {
  const bg = tokens.color.surface;
  expect(contrastRatio(color, bg)).toBeGreaterThanOrEqual(4.5);
});
```
