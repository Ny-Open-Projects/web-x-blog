## TST-513：测试框架技术选型：Vitest/Jest/Playwright/Cypress 怎么权衡

**答**：
- 结论：按测试层次选型——单元/组件层优先 Vitest（ESM 原生、快、与 Vite 复用配置）；E2E 优先 Playwright（跨浏览器、自动等待、trace）；Cypress 适合调试体验优先的团队。
- 评估维度：执行速度、生态与维护活跃度、调试与可观测、团队学习成本、与构建工具一致性。 migrated 项目要评估 Jest 兼容层与迁移成本。
- 追问钩子：团队已有大量 Jest 资产要不要迁 Vitest？——算迁移 ROI：若 CI 时长是主要痛点且依赖 ESM，则渐进迁移（先新模块用 Vitest），否则保持现状不折腾。

```javascript
// 选型打分卡：按团队权重对候选框架评分
const weights = { speed: 0.3, eco: 0.2, debug: 0.2, learn: 0.15, buildFit: 0.15 };
const scores = {
  vitest:    { speed: 5, eco: 4, debug: 4, learn: 4, buildFit: 5 },
  jest:      { speed: 3, eco: 5, debug: 4, learn: 5, buildFit: 3 },
  playwright:{ speed: 3, eco: 5, debug: 5, learn: 3, buildFit: 4 },
};
function pick(weights, scores) {
  return Object.entries(scores).map(([name, s]) => ({
    name, score: +Object.keys(weights).reduce(
      (a, k) => a + weights[k] * s[k], 0).toFixed(2),
  })).sort((a, b) => b.score - a.score);
}
console.log(pick(weights, scores));
```
