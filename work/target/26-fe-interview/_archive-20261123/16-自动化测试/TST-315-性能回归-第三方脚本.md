## TST-315：第三方脚本（统计/广告/客服）对性能的影响如何纳入回归？
**答**：
- 第三方 stub 化：测试环境用本地 stub 替代真第三方，体积/延迟可控可测。
- budget 断言：third-party 请求数量与字节量上限（Lighthouse budget resourceCounts）。
- 隔离验证：主线程阻塞归因（Long Task attributions）识别第三方长任务。
- 第三方变更监控：线上 RUM 中第三方加载时长漂移告警（对方改了脚本你不知道）。

```javascript
// 第三方 stub：可控延迟与体积
await page.route('**/analytics.js', route =>
  route.fulfill({ body: STUB_JS, headers: { 'content-type': 'application/javascript' } }));
expect(thirdPartyBytes).toBeLessThan(50_000);
```
