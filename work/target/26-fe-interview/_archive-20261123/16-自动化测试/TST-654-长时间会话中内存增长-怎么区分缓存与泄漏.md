## TST-654：长时间会话中内存增长：怎么区分缓存与泄漏？

**答**：
- 结论：GC 后回落是缓存，持续不回落才是泄漏——关键看「多轮操作后的基线是否单调上升」。
- 做 5 轮相同操作，每轮后强制 GC 再取堆，比较相邻轮次 retained size 的斜率。
- 缓存通常有上限（增长趋平），泄漏近似线性增长。
- 追问钩子：增长趋平但仍比初始高 30%，算泄漏吗？

```javascript
function classifyGrowth(snapshots) {
  const bases = snapshots.map(s => s.afterGC);
  const slopes = bases.slice(1).map((v, i) => v - bases[i]);
  const avg = slopes.reduce((a, b) => a + b, 0) / slopes.length;
  const last = slopes[slopes.length - 1];
  return {
    avgSlope: +avg.toFixed(1),
    lastSlope: last,
    verdict: avg <= 0 ? 'cache' : last < avg * 0.3 ? 'bounded-cache' : 'leak',
  };
}
console.log(classifyGrowth([{ afterGC: 100 }, { afterGC: 120 },
  { afterGC: 140 }, { afterGC: 160 }]).verdict); // leak
```
