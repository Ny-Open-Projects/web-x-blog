## TST-254：微前端的集成测试环境（主+多子）如何搭建与稳定运行？
**答**：
- 版本编排：主应用固定子应用版本号（注册表），集成环境按注册表拉对应版本——避免「全是 latest」的漂移。
- 每个子应用独立部署 + 独立 mock 后端，主应用联调环境只管编排。
- 联调环境健康检查：各子应用 mount 成功标记聚合到健康页。
- 测试数据在子应用间共享要走明确协议（shared state API），禁止隐式读对方 DOM/存储。

```javascript
// 子应用注册表（集成环境按此编排）
const registry = {
  portal: { version: '3.2.1', entry: 'https://cdn/portal/3.2.1' },
  trade: { version: '1.8.0', entry: 'https://cdn/trade/1.8.0' },
}; // 升级子应用 = 改注册表 + 跑集成套件
r
```
