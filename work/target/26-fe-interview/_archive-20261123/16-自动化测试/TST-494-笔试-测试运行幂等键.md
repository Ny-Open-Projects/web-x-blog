## TST-494：笔试：重复触发测试的幂等键设计与合并。
**题目**：触发 `{suite, ref, sha}`。幂等键 = sha + suite。实现 `idempotentTrigger(store, req)`：同键进行中 → 返回进行中 runId（不重复跑）；已完成 → 重新跑（新 runId）。

```javascript
function idempotentTrigger(store, req) {
  const key = `${req.sha}|${req.suite}`;
  const prev = store.get(key);
  if (prev?.status === 'running') return { reused: true, runId: prev.runId };
  const runId = `R-${Date.now()}`;
  store.set(key, { status: 'running', runId });
  return { reused: false, runId };
}
const s = new Map();
console.log(idempotentTrigger(s, { sha: 'a1', suite: 'e2e' }).reused); // false
console.log(idempotentTrigger(s, { sha: 'a1', suite: 'e2e' }).reused); // true（复用）

```

**评分点**：
- 键设计（sha+suite）。
- 进行中复用 / 已完成重跑语义。
- store 状态三值（running/done）。
- 返回 runId 可追溯。
