## TST-340：测试数据中的合规问题（真实用户数据进测试）如何治理？
**答**：
- 红线：生产 PII 禁止进测试环境——拉数必须过脱敏管道（映射/泛化）。
- 脱敏一致性：同一用户脱敏后跨环境映射稳定（便于追踪），但不可逆。
- 合规审计：测试库抽样扫描 PII 模式（手机号/身份证正则），命中即告警。
- 替代方案：合成数据工厂优先，确需真实分布时用统计相似合成。

```javascript
// 脱敏管道（生产 → 测试）
const desens = (row) => ({
  ...row,
  phone: maskedPhone(row.phone),        // 138****1234 → 保留分布
  name: deterministicAlias(row.name),   // 稳定映射便于追踪
});
```
