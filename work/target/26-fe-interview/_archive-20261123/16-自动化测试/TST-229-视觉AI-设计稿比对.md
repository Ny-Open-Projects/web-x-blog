## TST-229：AI 视觉比对「实现 vs 设计稿」的可行性与边界？
**答**：
- 可行：VLM 对比设计稿与实现截图，输出「布局/间距/颜色」偏差清单——比像素 diff 更懂语义。
- 边界：设计稿与实现的技术表达差异（响应式/字体回退）会造成固有偏差，AI 需上下文说明。
- 实践：AI 输出「偏差分级」（关键偏差/可接受偏差），关键偏差进设计走查会。
- 不适合做硬门禁（误报率高），定位为「自动化设计走查的初筛」。

```javascript
const review = await vlm(`设计稿与实现截图对比，输出偏差清单（布局/间距/颜色/文案），
分级：critical / acceptable。考虑响应式与字体回退的合理差异。`);
// critical 项 → 设计走查会议讨论，不做自动阻塞
r
```
