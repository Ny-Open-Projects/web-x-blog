## TST-620：收束题：面试中如何讲清一条完整的架构决策链？

**答**：
- 结论：用「背景约束 → 候选方案 → 权衡取舍 → 决策 → 验证与回滚」五段式，30 秒讲清。
- 关键是把「为什么不做另一个方案」讲透，体现权衡能力而非背结论。
- 结尾补一句数据：决策后哪个指标改善了，证明不是纸上谈兵。
- 追问钩子：如果现在让你推翻自己半年前的决策，你会从哪个信号开始？

```javascript
const adr = {
  context: 'CI 从 10 分钟涨到 45 分钟',
  options: [['加机器', '成本高'], ['分层裁剪', '需改造']],
  decision: '分层裁剪 + 结果缓存',
  tradeoff: '牺牲夜间全量覆盖，换 PR 反馈 <5 分钟',
  verify: { before: 45, after: 4.2, unit: 'min' },
};
console.log(`${adr.decision}: ${adr.verify.before}→${adr.verify.after}${adr.verify.unit}`);
```
