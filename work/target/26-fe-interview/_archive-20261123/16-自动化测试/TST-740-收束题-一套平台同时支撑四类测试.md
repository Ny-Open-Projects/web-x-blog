## TST-740：收束题：用一套平台同时支撑功能、性能、安全、混沌四类测试

**答**：
- 结论：统一抽象是「测试任务」——四类测试都是「对目标施加动作 + 采集信号 + 按策略判定」，差异只在插件。
- 平台层统一四件事：任务模型、调度与资源隔离、结果模型、门禁策略；类型插件实现各自的执行逻辑。
- 难点在资源与时序协调：性能/混沌互斥、安全扫描错峰、功能用例可高频，靠统一编排器仲裁。
- 追问钩子：四类测试结果都「通过」但线上仍出事，平台模型缺了什么？

```javascript
// 四类测试统一任务模型 + 类型路由
const EXECUTORS = {
  functional: t => ({ ok: t.assertions.every(Boolean) }),
  perf: t => ({ ok: t.latencyMs <= t.budgetMs }),
  security: t => ({ ok: t.findings.every(f => f.severity !== 'high') }),
  chaos: t => ({ ok: t.recoveredWithinMs <= t.sloMs }),
};
function execute(task) {
  const exec = EXECUTORS[task.type];
  return exec ? { type: task.type, ...exec(task) } : { ok: false, why: '未知类型' };
}
console.log(execute({ type: 'chaos', recoveredWithinMs: 500, sloMs: 1000 }));
```
