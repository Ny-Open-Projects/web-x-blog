## TST-623：大规模测试体系的「三级缓存」怎么设计？

**答**：
- 结论：结果缓存（同代码同环境不重跑）+ 依赖缓存（node_modules/构建产物）+ 环境缓存（快照复用）。
- 每级缓存都要有精确指纹：代码树 hash、lockfile hash、环境镜像 hash。
- 缓存失效要保守——不确定就重跑，宁可慢不可错报绿。
- 追问钩子：缓存命中率 90% 但仍出现「没跑却挂了」的逃逸，你查哪一层？

```javascript
function cacheKey({ srcHash, lockHash, envHash, testId }) {
  return [srcHash, lockHash, envHash, testId].join(':');
}
function lookup(cache, ctx) {
  const k = cacheKey(ctx);
  const hit = cache.get(k);
  return hit && hit.envHash === ctx.envHash
    ? { hit: true, result: hit.result }
    : { hit: false };
}
console.log(lookup(new Map(), { srcHash: 'a', lockHash: 'b',
  envHash: 'c', testId: 't1' }).hit);
```
