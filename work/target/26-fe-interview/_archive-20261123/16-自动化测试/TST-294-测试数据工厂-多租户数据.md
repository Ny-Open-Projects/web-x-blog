## TST-294：多租户产品的测试数据工厂如何处理租户隔离？
**答**：
- 每个测试运行分配独立测试租户（租户 ID 前缀 E2E-），数据全挂该租户下。
- 跨租户场景（隔离验证）工厂同时建两个租户的对称数据。
- 清理按租户级联删除（租户删除接口），天然整批。
- 租户配额/套餐差异用 builder 变体（aFreeTenant/aProTenant）表达。

```javascript
const t1 = await TenantBuilder.aTenant().plan('pro').build();     // E2E-T-001
const t2 = await TenantBuilder.aTenant().plan('free').build();
// 跨租户隔离用例：t1 用户访问 t2 数据必须 403
r
```
