## TST-659：前端随机数的可预测性怎么测试？

**答**：
- 结论：凡用于令牌、nonce、验证码的随机数都必须来自 crypto，而不是 Math.random。
- 测试手段：静态扫描禁用 Math.random 出现在安全敏感路径；运行时统计分布与重复率。
- 对已生成令牌做熵估计与前缀规律检测。
- 追问钩子：同一页面两个模块各自生成 token，撞车概率怎么测？

```javascript
function randomnessAudit(src, tokens) {
  const usesMathRandom = /Math\.random/.test(src);
  const unique = new Set(tokens).size;
  const dupRate = 1 - unique / Math.max(1, tokens.length);
  const lengths = new Set(tokens.map(t => t.length));
  return {
    usesMathRandom,
    dupRate: +dupRate.toFixed(3),
    lengthConsistent: lengths.size === 1,
    pass: !usesMathRandom && dupRate < 0.001 && lengths.size === 1,
  };
}
```
