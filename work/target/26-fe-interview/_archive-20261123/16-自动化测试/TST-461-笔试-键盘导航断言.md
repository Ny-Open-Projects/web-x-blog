## TST-461：笔试：实现键盘导航可达性断言（Tab 顺序收集）。
**题目**：模拟元素树 `[{tag, focusable, role}]` 按文档序。Tab 循环 = 可聚焦元素顺序；断言「期望顺序」列表；trap 检测（Dialog 场景：焦点不出容器）。

```javascript
function tabOrder(tree, containerId) {
  const focusables = tree.filter(el => el.focusable);
  return {
    order: focusables.map(el => el.role),
    trapOk: containerId
      ? focusables.every(el => el.container === containerId)   // 焦点不出容器
      : true,
  };
}
console.log(tabOrder([
  { role: 'textbox', focusable: true, container: 'dlg' },
  { role: 'heading', focusable: false, container: 'dlg' },
  { role: 'button', focusable: true, container: 'outside' },
], 'dlg')); // trapOk false（按钮在容器外 → 焦点泄漏）

```

**评分点**：
- 可聚焦过滤 + 顺序收集。
- 期望顺序比对（输出首个偏差点）。
- trap 检测：容器内集合闭合断言。
- 不可聚焦元素的 aria-hidden 断言（加分）。
