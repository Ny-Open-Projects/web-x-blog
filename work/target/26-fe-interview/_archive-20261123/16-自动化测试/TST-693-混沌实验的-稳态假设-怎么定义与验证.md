## TST-693：混沌实验的「稳态假设」怎么定义与验证？

**答**：
- 结论：稳态假设 = 一组可观测的 SLI 阈值（如下单成功率 >99%、P95 <2s），实验期间持续校验。
- 先跑基线窗口确认稳态成立，再注入故障；任一 SLI 越界立即停止实验。
- 假设要写成可执行的断言函数，而不是口头描述。
- 追问钩子：稳态指标本身被故障影响了（埋点挂了），你怎么判断？

```javascript
function steadyCheck(metrics, hypothesis) {
  const violations = [];
  Object.entries(hypothesis).forEach(([key, rule]) => {
    const v = metrics[key];
    if (v == null) { violations.push({ key, why: '指标缺失' }); return; }
    if (rule.min != null && v < rule.min)
      violations.push({ key, why: `低于 ${rule.min}` });
    if (rule.max != null && v > rule.max)
      violations.push({ key, why: `高于 ${rule.max}` });
  });
  return { stable: violations.length === 0, violations };
}
const h = { orderSuccess: { min: 0.99 }, p95: { max: 2000 } };
console.log(steadyCheck({ orderSuccess: 0.995, p95: 1800 }, h).stable);
```
