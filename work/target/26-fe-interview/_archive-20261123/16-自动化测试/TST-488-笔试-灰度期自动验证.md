## TST-488：笔试：灰度期间的自动验证判定（多指标达标放量）。
**题目**：灰度指标 `[{metric, value, baseline, maxDelta}]`。判定：每指标劣化 ≤ maxDelta → 全达标放量；任一超 → 保持灰度并输出超指标。

```javascript
function canaryJudge(metrics, { current, expected }) {
  const over = [];
  for (const m of metrics) {
    const v = current[m.metric], b = expected[m.metric];
    if (v === undefined || b === undefined) { over.push(`${m.metric}: 数据缺失`); continue; }
    if (v > b * (1 + m.maxDelta)) over.push(`${m.metric}: ${v} > 基线 ${b}×(1+${m.maxDelta})`);
  }
  return { promote: over.length === 0, over };
}
console.log(canaryJudge(
  [{ metric: 'errRate', maxDelta: 0.2 }],
  { current: { errRate: 0.012 }, expected: { errRate: 0.01 } }).promote); // false

```

**评分点**：
- 劣化方向判定（value vs baseline，方向由指标语义定——简化：value ≤ baseline*(1+maxDelta)）。
- 多指标全过才放量。
- 超指标清单（可读）。
- 指标缺失按超处理（保守）。
