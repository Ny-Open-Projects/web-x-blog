## TST-898：前端灾备：多活/降级/回源在前端侧如何测试？
**答**：
- 结论：前端灾备测试验证「当一个地域/一个源站挂了，用户是否被自动切到可用节点且数据不错乱」——测的是切换链路与状态一致性。
- 多活切换：mock 主地域 API 故障，验证 DNS/网关切换到备地域，前端请求重试到新节点成功。
- 降级/回源：CDN 回源失败时切到静态兜底页或缓存，保证核心内容可读。
- 状态一致性：切换过程中用户已提交的操作不重复、不丢失（幂等 + 本地队列）。
- 追问钩子：多活切换后用户看到的数据「旧了几秒」，这算灾备成功还是失败？如何定义可接受标准？

```javascript
// 灾备切换测试：主地域故障 -> 切备地域
async function failoverTest(page, gateway) {
  gateway.failRegion('cn-east'); // 主地域故障
  const start = Date.now();
  await page.goto('/checkout');
  const switched = await page.getByText('订单页').isVisible();
  const switchMs = Date.now() - start;
  gateway.restore();
  return {
    switched,                 // 是否成功切到备地域
    switchMs,                 // 切换耗时（RTO）
    acceptable: switched && switchMs < 10000,
  };
}
```
