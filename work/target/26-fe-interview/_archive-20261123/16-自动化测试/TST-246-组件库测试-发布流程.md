## TST-246：组件库版本发布前必须过哪些测试门禁？
**答**：
- 全量单测 + a11y 扫描 + 视觉 diff 三门禁全绿。
- breaking 变更检测：TS 类型 diff 输出 API 变更清单，major 版本必须人工确认。
- 下游冒烟：在 1-2 个真实业务仓库跑组件冒烟套件（消费侧真实用法）。
- 发布后监控：组件错误率/视觉异常回滚预案（版本回退开关）。

```javascript
# 发布流水线
pnpm test && pnpm test:a11y && pnpm test:visual
node scripts/api-diff.js --from v3.2.0 --to HEAD   # breaking 清单
pnpm release --dry-run                              # 人工确认 changelog
r
```
