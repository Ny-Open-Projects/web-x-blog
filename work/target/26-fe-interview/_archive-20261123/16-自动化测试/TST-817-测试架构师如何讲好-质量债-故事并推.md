## TST-817：测试架构师如何讲好「质量债」故事并推动偿还？
**答**：
- 结论：把质量债类比财务债——用「本金（缺失测试）+ 利息（每次改动的额外排查时间）」量化，让管理层看到「不还债的复利效应」。
- 量化利息：统计因缺测试导致的回归 bug 数、平均定位时长、返工工时，折算成每月损失的「利息」。
- 制定偿债计划：把质量债纳入迭代（如每 sprint 20% 容量），优先偿还高频改动区的高息债。
- 建立防新增机制：新代码必须带测试（Definition of Done），避免「边还边欠」。
- 追问钩子：业务方说「先还债就没时间做需求」，你如何在两者间找平衡？

```javascript
// 质量债的「利息」估算：让债务可感知
function qualityDebtInterest({ missingTests, avgDebugMinutes, regressionsPerMonth }) {
  const monthlyInterestHours = (regressionsPerMonth * avgDebugMinutes) / 60;
  const annualCost = monthlyInterestHours * 12 * 200; // 200 元/工时
  return {
    缺失测试数: missingTests,
    月利息工时: Number(monthlyInterestHours.toFixed(1)),
    年利息成本: Math.round(annualCost),
    结论: '每月不还得付这么多「利息」，还债本金一次性投入',
  };
}
console.log(qualityDebtInterest({ missingTests: 120,
  avgDebugMinutes: 90, regressionsPerMonth: 8 })); // 年利息约 17.3 万
```
