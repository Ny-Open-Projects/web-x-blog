## TST-379：测试文档（用例说明/覆盖率解读）如何自动生成保持新鲜？
**答**：
- 用例即文档：测试名/描述规范化（场景+期望），自动生成用例索引。
- 覆盖率报告自动解读：AI 生成「盲区解读 + 建议」附在报告页。
- 变更驱动更新：代码变更 PR 自动列出受影响测试文档段落。
- 文档与代码同源：说明文字写在测试文件注释中，工具提取。

```javascript
/** 覆盖：购物车金额汇总（含优惠券叠加/满减边界）
 *  依赖：GoodsBuilder.couponStack()
 *  已知盲区：跨店满减未覆盖 */
describe('cart-total', () => { /* ... */ });
// 文档站自动抽取注释渲染
r
```
