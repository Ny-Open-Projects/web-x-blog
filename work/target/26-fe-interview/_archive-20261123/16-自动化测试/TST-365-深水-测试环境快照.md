## TST-365：「环境快照」技术（整个后端状态快照/恢复）用于测试？
**答**：
- DB 快照：种子完成后打快照，每个测试类恢复快照（比重建快一个量级）。
- 快照一致性：恢复后自增 ID/时间游标也重置（防跨快照污染）。
- 适用：重型集成测试/E2E 数据准备昂贵的场景。
- 维护成本：快照版本与代码 schema 同步升级（迁移管道跑快照）。

```javascript
beforeAll(async () => await db.restoreSnapshot('seed-v3'));
// 每 class 独立起点，快照 2 秒恢复 vs 种子 90 秒
r
```
