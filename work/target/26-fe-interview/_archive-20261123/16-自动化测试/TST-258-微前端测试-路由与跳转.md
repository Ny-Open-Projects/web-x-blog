## TST-258：微前端跨应用路由跳转（主↔子/子↔子）的测试要点？
**答**：
- 路径前缀约定测试：跳转 URL 拼接符合注册表前缀（防硬编码域名）。
- 状态传递：跳转带参（query/state）在目标应用正确还原。
- 来回往返：子 A → 子 B → 返回，状态与滚动位置语义正确（或明确重置）。
- 未加载→懒加载：首次跳转子应用异步加载的 loading/超时/失败兜底。

```javascript
test('子应用间跳转', async ({ page }) => {
  await page.goto('/portal');
  await page.getByRole('link', { name: '去交易' }).click();
  await page.waitForURL('**/trade/orders');
  await expect(page.getByTestId('trade-root')).toBeVisible(); // 子应用 mount
});
```
