## TST-368：测试自身的观测性（执行轨迹/资源/趋势）如何建设？
**答**：
- 执行轨迹：每次运行记录（时长/环境/结果/重试），全量入库可查。
- 资源画像：用例级 CPU/内存采集，资源异常的用例单独标记。
- 趋势视图：时长/通过率/flaky 三曲线，异动自动标注关联变更。
- 观测数据反哺：慢用例 topN 进治理看板，趋势预测容量。

```javascript
class TracingReporter {
  onTestEnd(test, result) {
    ingest({ name: test.title, ms: result.duration,
             cpu: this.profiler.peek(), retry: result.retry });
  }
}
```
