## TST-240：沉淀「视觉测试规范」应包含哪些条目？
**答**：
- 分层策略（token/组件/整页）与各自阈值、频率。
- 稳定性清单（时钟/动画/字体/视口）统一工具函数强制使用。
- 基线管理流程（首次人审、更新走 PR、孤儿清理）。
- 门禁定位（组件阻塞/整页建议）与逃生通道（审计留痕）。

```javascript
<!-- visual-testing-standard.md 摘要 -->
1. 分层：token 单测 / 组件级 diff（阻塞）/ 整页（建议+人审）
2. 统一 stableShot()：冻结时钟+禁动画+等字体，禁止裸 toHaveScreenshot
3. 基线：首次人审，更新走 PR 附 diff 图，CI 清孤儿
4. 阈值：组件 ≤ 0.5%，图表类 ≤ 2%，整页建议级

```
