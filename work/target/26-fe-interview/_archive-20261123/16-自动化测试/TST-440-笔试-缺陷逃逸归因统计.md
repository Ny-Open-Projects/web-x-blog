## TST-440：笔试：逃逸缺陷的「测试层缺口」归因统计。
**题目**：缺陷 `[{id, escapedFrom: 'unit'|'api'|'e2e'|'none', layer: 缺陷本该被哪层拦}]`。输出每层缺口计数与「缺口率」（缺该层用例的缺陷占比）；最高缺口层给出补测建议。

```javascript
function escapeAttribution(defects) {
  const gaps = {};
  let none = 0;
  for (const d of defects) {
    if (d.escapedFrom === 'none') { none++; continue; }
    if (d.escapedFrom !== d.layer)
      gaps[d.layer] = (gaps[d.layer] || 0) + 1;   // 本该 d.layer 拦但没拦
  }
  const top = Object.entries(gaps).sort((a, b) => b[1] - a[1])[0];
  return { gaps, noneRelated: none,
    total: defects.length,
    topGap: top ? { layer: top[0], count: top[1],
      suggest: `优先补 ${top[0]} 层用例（缺口 ${top[1]}/${defects.length}）` } : null };
}

```

**评分点**：
- 双字段对齐判断（escapedFrom vs 应拦截层）。
- 缺口率计算（分母是逃逸总数）。
- 最高缺口层建议（含具体层名）。
- 归为 none 的缺陷单独列（需求/流程问题非测试缺口）。
