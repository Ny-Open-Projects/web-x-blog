## TST-289：有关联的数据（订单依赖商品依赖用户）工厂如何编排？
**答**：
- 嵌套 builder：OrderBuilder.forUser(u).withItems([g1, g2]) 自动补全关联必需数据。
- 懒创建：关联对象在需要时才 build（避免无谓的种子数据爆炸）。
- 固定关系引用：用例间共享的实体（如全局测试店铺）用命名 fixture 复用。
- 级联清理：工厂登记创建实体，teardown 按依赖逆序清理（先订单后商品）。

```javascript
const order = await OrderBuilder.anOrder()
  .forUser(user)                       // 懒创建用户
  .withItems([GoodsBuilder.aGoods().withPrice(50).build()])
  .payWith('wallet')
  .create();                           // 登记进清理清单
```
