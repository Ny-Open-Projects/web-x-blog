## TST-256：子应用「独立可测」与「联合可测」的边界如何划分？
**答**：
- 子应用默认独立测：mock 主应用提供的运行时（注入的 props/共享状态），不依赖主应用真身。
- 联合测只测「边界」：mount/unmount 生命周期、路由切换、跨应用跳转、共享状态同步。
- 边界用例清单固定（10-20 条核心），联合环境昂贵且慢——控制规模。
- 主应用作为「测试宿主」提供 minimal host（只注入运行时壳），比真主应用轻且稳。

```javascript
// 子应用独立测试：mock 运行时注入
render(<SubApp runtime={{ getUser: async () => mockUser, locale: 'zh' }} />);
// 联合测试只验证：window.__subApp.mount() 后路由可达 + 卸载干净
r
```
