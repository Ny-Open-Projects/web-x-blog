## TST-354：测试自身的性能开销（覆盖率插桩/快照/trace）如何权衡？
**答**：
- 覆盖率插桩拖慢单测 30-50%：本地默认关，CI 专项 job 开。
- trace 采集成本：retain-on-failure（失败才留）平衡。
- 组件测试挂真实浏览器（Storybook test）比 jsdom 慢一个量级——按需分层。
- 度量开销：测试套件自计时（框架耗时 vs 用例耗时分离）。

```javascript
// 覆盖率独立 job（不拖常规 PR 检查）
scripts: { 'test:fast': 'vitest run', 'test:cov': 'vitest run --coverage' }
// CI：PR 跑 fast；nightly 跑 cov
r
```
