## TST-442：笔试：多套件并行时的资源配额分配（内存预算装箱）。
**题目**：套件 `[{name, memMB}]` 与总预算 budgetMB。装箱：尽量多套件并行（FFD 首次适应递减），输出批次与每批内存峰值、批次数。

```javascript
function packSuites(suites, budgetMB) {
  const sorted = [...suites].sort((a, b) => b.memMB - a.memMB || a.name.localeCompare(b.name));
  const bins = [];
  for (const s of sorted) {
    if (s.memMB > budgetMB) throw new Error(`${s.name} 单套件超预算 ${s.memMB}MB`);
    const b = bins.find(bin => bin.used + s.memMB <= budgetMB);
    if (b) { b.used += s.memMB; b.items.push(s.name); }
    else bins.push({ used: s.memMB, items: [s.name] });
  }
  return { batches: bins, peakMB: Math.max(...bins.map(b => b.used)) };
}
console.log(packSuites([
  { name: 'pay', memMB: 3 }, { name: 'cart', memMB: 2 }, { name: 'ui', memMB: 2 },
], 4)); // [[pay],[cart,ui]]

```

**评分点**：
- FFD 装箱（递减 + 首个可容纳箱子）。
- 超预算单套件报错（无法装任何箱）。
- 批次数与内存峰值输出。
- 排序稳定性（同内存按名）。
