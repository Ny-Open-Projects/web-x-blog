## TST-947：大促会场页每天改文案换主图，视觉回归告警刷屏，如何专项治理？
**答**：
- 结论：大促页采用「分区分级」策略——运营配置区只做结构/几何断言不做像素比对，品牌一致区（导航、按钮、价格）做严格像素回归。
- 节奏：大促封版期冻结视觉基线，仅允许结构断言；大促后恢复像素回归并批量更新基线。
- 协作：运营改图走 CMS 预览截图存档，不进测试告警渠道。
- 追问钩子：大促当天运营临时换了主图导致布局溢出，结构断言能抓住吗？还是需要额外的几何守护？

```javascript
// 大促页视觉策略：按区分级
const promoPagePolicy = {
  strict: ['#nav', '#buy-button', '.price'],      // 品牌一致区：像素回归
  structural: ['#banner', '#recommend-list'],    // 运营配置区：只断言几何/结构
};
test('大促会场页', async () => {
  for (const sel of promoPagePolicy.strict)
    await expect(page.locator(sel)).toHaveScreenshot();
  for (const sel of promoPagePolicy.structural) {
    const box = await page.locator(sel).boundingBox();
    expect(box.height).toBeGreaterThan(0);
    expect(box.y + box.height).toBeLessThanOrEqual(900); // 防溢出
  }
});
```
