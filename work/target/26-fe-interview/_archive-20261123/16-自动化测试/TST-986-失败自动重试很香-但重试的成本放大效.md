## TST-986：失败自动重试很香，但重试的成本放大效应怎么算？会不会越重试越慢？
**答**：
- 结论：重试放大因子 ≈ 1/(1-单用例失败率)，失败率越高重试收益越低、成本越高；只对「偶发失败」重试，稳定失败应立即失败。
- 做法：区分 flaky（历史偶发）与稳定失败（连续失败），只对前者重试；设全局重试预算上限，避免雪崩。
- 边界：非幂等用例（下单/支付）禁止自动重试。
- 追问钩子：CI 因为一批接口超时每个失败用例重试 3 次，结果整条流水线从 10 分钟变 40 分钟，你怎么控制？

```javascript
function retryCost({ totalCases, failRate, retries, retryMs }) {
  const expectedFailures = totalCases * failRate;
  const extraRuns = expectedFailures * retries;
  const totalMs = totalCases * 1000 + extraRuns * retryMs;
  return {
    extraRuns, totalMinutes: +(totalMs / 60000).toFixed(1),
    blowup: +(totalMs / (totalCases * 1000)).toFixed(2),
    advice: extraRuns > totalCases * 0.2 ? '失败率过高：先治根因，别靠重试' : '可接受',
  };
}
console.log(retryCost({ totalCases: 200, failRate: 0.3, retries: 3, retryMs: 5000 }));
// { extraRuns:180, totalMinutes:18, blowup:4.5, advice:'失败率过高：先治根因' }
```
