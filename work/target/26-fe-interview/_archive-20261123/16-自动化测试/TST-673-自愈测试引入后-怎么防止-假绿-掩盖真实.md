## TST-673：自愈测试引入后，怎么防止「假绿」掩盖真实 UI 缺陷？

**答**：
- 结论：自愈让测试不再红，但 UI 可能真的坏了——必须把每次自愈当成「疑似缺陷信号」。
- 自愈事件自动开低优先级 issue；同一选择器被自愈超过 3 次强制转人工。
- 定期审计自愈日志，把频繁变更的目标固化为新选择器。
- 追问钩子：自愈把按钮定位到了另一个同名按钮，测试通过了但点错了，怎么发现？

```javascript
function healingGuard(events, { maxPerSelector = 3 } = {}) {
  const count = new Map();
  events.forEach(e => count.set(e.from, (count.get(e.from) || 0) + 1));
  const suspects = [...count].filter(([, n]) => n > maxPerSelector)
    .map(([sel, n]) => ({ selector: sel, times: n, action: 'human-review' }));
  return {
    suspects,
    shouldOpenIssue: events.length > 0,
    pass: suspects.length === 0,
  };
}
```
