## TST-595：混沌测试常见误区与避坑

**答**：
- 结论：常见误区——把混沌当「搞破坏」、只看实验是否通过而不看发现了什么、没有护栏就上生产、稳态假设太弱、故障注入后不回滚。
- 避坑：从测试环境小步开始；每次实验必须有明确假设与护栏；重视「发现并修复」而非「通过率」；回滚与 kill switch 必备；无指责复盘。
- 追问钩子：只做「验证已知故障」算混沌吗？——不算完整混沌；混沌强调发现「未知未知」，应在受控前提下引入一定程度的随机性与组合故障。

```javascript
// 误区自检清单
const PITFALLS = {
  'no-guardrail': '无护栏就注入',
  'pass-only': '只看通过率不看发现',
  'no-rollback': '无回滚机制',
  'weak-steady': '稳态假设过弱',
  'prod-first': '一开始就在生产搞',
};
function auditChaos(experiment) {
  return Object.keys(PITFALLS).filter(k =>
    (k === 'no-guardrail' && !experiment.guardrails) ||
    (k === 'no-rollback' && !experiment.rollback) ||
    (k === 'weak-steady' && !experiment.steady));
}
```
