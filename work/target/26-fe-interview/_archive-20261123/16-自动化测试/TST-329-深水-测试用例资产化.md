## TST-329：测试用例如何从「脚本」升级为「资产」（可检索/可复用/可度量）？
**答**：
- 元数据化：每条用例声明覆盖面（功能域/组件/风险等级）——检索与影响分析的基础。
- 步骤复用：公共旅程（登录/下单）封装为共享步骤库，用例只写差异。
- 覆盖度可视化：功能域 × 用例覆盖热力图，找盲区。
- 淘汰机制：长期无缺陷发现且维护成本高的用例下线（防止僵尸用例）。

```javascript
const caseMeta = {
  covers: ['cart', 'coupon-stacking'],
  risk: 'high',
  steps: ['shared:loginAsBuyer', 'addTwoItems', 'assertTotal'],
  lastDefect: '2026-08-12',      // 长期无发现 → 淘汰候选
};
```
