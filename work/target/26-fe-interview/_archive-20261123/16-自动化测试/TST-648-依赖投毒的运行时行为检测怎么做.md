## TST-648：依赖投毒的运行时行为检测怎么做？

**答**：
- 结论：静态审计挡不住所有投毒，要在运行时监控依赖的「异常行为」——非预期外联、读环境变量、动态执行。
- 用沙箱/代理拦截 fetch、process.env、eval 调用，按包名建立行为基线。
- 偏离基线（如一个 UI 工具包突然访问支付域名）立即告警。
- 追问钩子：正常依赖也会动态加载 CDN，你怎么避免误报？

```javascript
function behaviorBaseline(calls, known) {
  const anomalies = [];
  calls.forEach(c => {
    if (c.kind === 'network' && !known.domains.includes(c.host))
      anomalies.push({ pkg: c.pkg, why: '异常外联', host: c.host });
    if (c.kind === 'env' && !known.envRead)
      anomalies.push({ pkg: c.pkg, why: '读环境变量' });
    if (c.kind === 'eval')
      anomalies.push({ pkg: c.pkg, why: '动态执行' });
  });
  return anomalies;
}
```
