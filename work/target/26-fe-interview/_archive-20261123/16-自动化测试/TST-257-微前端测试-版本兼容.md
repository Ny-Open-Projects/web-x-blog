## TST-257：主应用升级（如 qiankun 版本升级）时子应用回归怎么控制？
**答**：
- 兼容性套件：主应用升级 PR 触发「全子应用冒烟矩阵」（每个子应用 mount/核心路径跑通）。
- 子应用版本与主应用版本兼容矩阵显式化（supportedHost: ['^3.x']）。
- 灰度共存期：新旧主应用同时在线时，集成测试覆盖两种组合。
- 不兼容变更提前通知：主应用发 breaking 前的 deprecation 周期（至少一个大版本）。

```javascript
// 兼容矩阵
const compat = { portal: ['^3.0.0'], trade: ['^2.4.0', '^3.0.0'] };
// 主应用升级到 4.0 → trade 只支持 ^3 → 集成测试标记 fail
r
```
