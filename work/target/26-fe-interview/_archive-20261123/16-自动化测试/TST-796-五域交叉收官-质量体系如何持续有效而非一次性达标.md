## TST-796：五域交叉收官：如何证明你的质量体系「持续有效」而非一次性达标

**答**：
- 结论：持续有效性靠「闭环 + 度量 + 演进」——体系能随业务变化自我调整，而非建好就僵化。
- 三个证据：质量指标长期趋势（逃逸率/MTTD/覆盖率）、体系对变更的适应性（新业务接入成本）、发现问题后的改进闭环率。
- 定期做「体系健康体检」：用混沌/变异测试验证防线是否真的有效，用回顾会识别腐化信号。
- 追问钩子：所有指标都达标但团队开始绕过体系，说明什么？

```javascript
// 体系持续有效性：趋势 + 闭环 + 适应性
function systemHealth(trend, closureRate, adaptCost) {
  return {
    improving: trend.escapedBugDrop > 0 && trend.mttdDrop > 0,
    closing: closureRate >= 0.8,
    adaptable: adaptCost < 5, // 新业务接入人日
    sustainable: trend.escapedBugDrop > 0 && closureRate >= 0.8 && adaptCost < 5,
  };
}
console.log(systemHealth(
  { escapedBugDrop: 0.3, mttdDrop: 20 }, 0.85, 3
)); // sustainable:true
```
