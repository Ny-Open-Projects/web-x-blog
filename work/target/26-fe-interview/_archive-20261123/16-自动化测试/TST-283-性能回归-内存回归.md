## TST-283：内存回归（泄漏）的自动化测试怎么做？
**答**：
- 场景循环 N 次（打开/关闭弹窗）后取堆快照，对比第 1 次与第 N 次的 detached DOM/堆大小。
- CDP（Chrome DevTools Protocol）采集 heapUsed，回归阈值（如增长 > 20%）fail。
- 典型泄漏源：未解绑事件监听/定时器/闭包持有大对象——专项模板用例。
- 内存测试噪声大（GC 时机），多次采样 + 强制 GC（--expose-gc）提升稳定。

```javascript
test('弹窗无内存泄漏', async ({ page }) => {
  const heap = () => page.evaluate(() => (performance as any).memory?.usedJSHeapSize);
  for (let i = 0; i < 20; i++) { await openDialog(page); await closeDialog(page); }
  await page.evaluate(() => (window as any).gc?.());
  const used = await heap();
  expect(used).toBeLessThan(30 * 1024 * 1024);   // 循环后仍 < 30MB
});
```
