## TST-636：大规模测试的可观测性体系怎么搭建？

**答**：
- 结论：指标 + 日志 + 链路三件套，核心是「一次运行可下钻到单个用例为什么慢」。
- 指标分层：平台级（排队时长/成功率）、套件级（时长/通过率）、用例级（耗时/资源）。
- 统一 traceId 串联调度→执行→报告，失败自动带上环境快照链接。
- 追问钩子：可观测性本身也会拖慢测试，你怎么控制采集开销？

```javascript
function observe(run, { sampleRate = 1 } = {}) {
  const metrics = {
    queueMs: run.queueMs,
    execMs: run.execMs,
    passRate: +(run.passed / Math.max(1, run.total)).toFixed(3),
  };
  const traces = Math.random() < sampleRate
    ? [{ traceId: run.id, spans: run.spans }] : [];
  return { metrics, traces };
}
```
