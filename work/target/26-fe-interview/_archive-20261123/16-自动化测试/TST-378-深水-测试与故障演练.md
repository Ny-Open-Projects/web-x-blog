## TST-378：故障演练（混沌）与测试体系的融合？
**答**：
- 演练即测试：注入故障（服务超时/依赖挂）验证降级路径——预授权预案清单。
- 演练用例化：故障场景/预期行为/判定标准结构化（可重复执行）。
- 触发时机：大促前/架构变更后/季度例行。
- 结果归档：演练发现的问题进测试缺口清单（同一治理管道）。

const chaosCase = {
  inject: { target: 'order-svc', fault: 'timeout-3s', duration: '10m' },
  expect: ['降级开关生效', '下单改排队', '无资损写入'],
  gate: '全部满足才通过演练',
