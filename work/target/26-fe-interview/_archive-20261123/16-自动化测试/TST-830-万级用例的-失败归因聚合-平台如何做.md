## TST-830：万级用例的「失败归因聚合」平台如何做？（相同堆栈聚类）
**答**：
- 结论：失败归因的自动化 = 指纹提取（栈顶/错误信息）+ 聚类 + 历史匹配（是否已知问题）+ 责任人映射（按模块/owner）。
- 指纹提取：规范化错误信息（去掉行号/时间戳/动态 id），取栈顶帧作为根因指纹，避免同一根因被拆成多条。
- 历史匹配：与已知问题库比对，命中则直接标注「已知问题 #issue」并关联，避免重复排查。
- 责任映射：按失败模块 → CODEOWNERS → owner 自动 @人，缩短分诊时间。
- 追问钩子：规范化指纹时过度归一化可能把不同 bug 合并，如何平衡聚合率与准确性？

```javascript
// 失败指纹：规范化后取栈顶
function failureFingerprint(err) {
  const normalized = err.message
    .replace(/\d+/g, '#')          // 数字归一
    .replace(/[a-f0-9]{8,}/gi, '<id>') // hash 归一
    .replace(/\s+/g, ' ')
    .trim();
  const topFrame = (err.stack || '').split('\n')[1]?.replace(/:\d+:\d+/, '') || '';
  return `${normalized}@${topFrame}`;
}
console.log(failureFingerprint({
  message: 'Expected 42 but got 43 at user 8f3a2b1c',
  stack: 'Error\n  at check (a.js:12:5)'
})); // Expected # but got # at user <id>@  at check (a.js)
```
