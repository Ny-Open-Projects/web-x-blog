## TST-391：「测试守门人」（test gatekeeper）制度的价值与设计？
**答**：
- 角色：轮值负责审阅可疑测试变更（删测试/放宽断言/加 skip）。
- 价值：防止测试资产被无意识削弱（最常见腐化途径）。
- 流程：删改测试 PR 自动标记 → 守门人 24h 内审查（理由充分才放行）。
- 数据：被拦截的削弱变更数 = 制度价值证明。

```javascript
# 删测试的 PR 自动触发守门人审查
paths: ['**/*.test.*']
rules: { deleted-cases: 'gatekeeper-review', weakened-assert: 'gatekeeper-review' }
r
```
