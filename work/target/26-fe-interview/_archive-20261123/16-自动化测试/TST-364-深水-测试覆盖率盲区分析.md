## TST-364：覆盖率报告如何转化为「可行动的盲区清单」？
**答**：
- 分支级覆盖 + 未覆盖行聚类（按模块/函数复杂度加权排序）。
- 过滤噪声：生成代码/类型文件/纯声明排除出统计。
- 盲区分级：核心域未覆盖 → 立即补；边缘未覆盖 → 登记接受。
- 趋势管理：新增代码覆盖 ≥ 80% 门禁（增量覆盖而非全量）。

```javascript
const blindspots = coverage.uncoveredBranches
  .filter(b => !generated(b.file))
  .sort(byRisk);          // 复杂度 × 模块风险
// 增量门禁：diff 覆盖率 ≥ 80%
r
```
