## TST-936：微前端「样式隔离」如何从测试角度变成可验证的契约而不只是靠肉眼？
**答**：
- 结论：样式隔离契约 = 「类名命名空间 + 作用域属性 + 无全局污染」——用 DOM 快照与 CSS 规则扫描来断言，而非人工看。
- 验证点：子应用根容器带 data-qiankun 属性；样式选择器均被前缀限定；mount 后 document.head 中不残留裸全局选择器。
- 工具：解析 style 标签文本，断言所有选择器命中子元素；unmount 后样式节点被移除。
- 追问钩子：两个子应用都定义了 .btn，切来切去后按钮样式错乱，样式隔离契约测试怎么提前抓到？

```javascript
test('样式隔离契约', async () => {
  await mountSubApp('app-a', container);
  const styles = await page.$$eval('style[data-qiankun]', els => els.map(e => e.textContent));
  for (const css of styles) {
    const selectors = css.match(/[^}]+\{/g)?.map(s => s.replace('{', '').trim()) || [];
    for (const sel of selectors) {
      expect(sel).toMatch(/data-qiankun|\[data-app\]/); // 选择器被限定作用域
    }
  }
  await unmountSubApp('app-a');
  const leftover = await page.$$eval('style[data-qiankun]', els => els.length);
  expect(leftover).toBe(0); // 卸载后样式清理
});
```
