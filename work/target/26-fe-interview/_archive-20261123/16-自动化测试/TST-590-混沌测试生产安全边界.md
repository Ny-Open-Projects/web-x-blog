## TST-590：混沌测试如何保证不影响生产用户

**答**：
- 结论：靠「环境隔离 + 爆炸半径 + 熔断 + 可回滚」四道防线——优先在测试/预发做；生产仅极小流量或内部账号；有自动熔断与一键回滚。
- 做法：实验前评估影响面并审批；限定特定用户/区域；监控核心指标，超阈值立即停止（kill switch）；实验有明确的回滚脚本与演练。
- 追问钩子：如果实验导致真实用户受影响怎么办？——立刻触发 kill switch 停止注入并回滚，走事故流程；事后复盘为何爆炸半径失控，收紧规则后再做。

```javascript
// 熔断：监控指标越界立即停止实验
function shouldAbort(metrics, guardrails) {
  for (const [k, limit] of Object.entries(guardrails)) {
    if ((metrics[k] ?? 0) > limit) return { abort: true, cause: k, value: metrics[k] };
  }
  return { abort: false };
}
console.log(shouldAbort({ errorRate: 0.05 }, { errorRate: 0.01, p95Ms: 3000 }));
console.log(shouldAbort({ errorRate: 0.005 }, { errorRate: 0.01 })); // abort=false
// 多指标护栏：任一越界即熔断
const guardrails = { errorRate: 0.01, p95Ms: 3000, whiteScreen: false };
console.log(shouldAbort({ errorRate: 0.005, p95Ms: 3500 }, guardrails).cause); // 'p95Ms'
```
