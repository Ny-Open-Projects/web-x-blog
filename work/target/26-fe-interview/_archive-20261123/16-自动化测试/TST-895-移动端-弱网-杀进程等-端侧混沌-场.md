## TST-895：移动端/弱网/杀进程等「端侧混沌」场景如何测试？
**答**：
- 结论：端侧混沌关注「设备与网络的不稳定」——弱网、切后台、杀进程、低电量、内存不足，验证客户端状态恢复与数据一致性。
- 弱网/离线：CDP 注入延迟/丢包、飞行模式切换，验证加载与重试（呼应 TST-858）。
- 生命周期：App 切后台/被杀后重进，验证草稿恢复、未提交操作不丢、登录态合理处理。
- 资源约束：低内存/低电量下降级策略（停动画、减请求），避免 OOM 崩溃。
- 追问钩子：杀进程后重进，用户重复提交了订单，端侧混沌如何帮你在上线前发现？

```javascript
// 端侧混沌：切后台/杀进程后状态恢复
async function appResumeTest(page) {
  await page.getByText('填写订单').fill('草稿内容');
  await page.evaluate(() => window.dispatchEvent(new Event('pagehide'))); // 模拟切后台
  await page.reload(); // 模拟被杀后重进
  const draft = await page.getByText('填写订单').inputValue();
  const dupOrders = await page.evaluate(() => window.__orderCount);
  return {
    draftRestored: draft === '草稿内容',
    noDuplicateOrder: dupOrders === 1,
  };
}
```
