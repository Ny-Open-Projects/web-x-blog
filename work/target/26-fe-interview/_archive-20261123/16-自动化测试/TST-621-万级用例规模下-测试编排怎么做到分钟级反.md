## TST-621：万级用例规模下，测试编排怎么做到分钟级反馈？

**答**：
- 结论：靠「分层 + 增量 + 并行」三板斧——PR 只跑受影响用例，全量留给 nightly。
- 编排层用依赖图做拓扑调度，按资源配额分片；热点用例优先、慢用例靠后。
- 反馈链路上做流式报告，边跑边出结果，失败即刻通知不等全量结束。
- 追问钩子：增量选择漏掉了跨模块间接影响，你如何用线上逃逸数据反向校正选择算法？

```javascript
function orchestrate(cases, changed, { workers = 8 } = {}) {
  const affected = cases.filter(c => (c.deps || []).some(d => changed.includes(d)));
  const sorted = [...affected].sort((a, b) => a.estMs - b.estMs);
  const shards = Array.from({ length: workers }, () => []);
  sorted.forEach((c, i) => shards[i % workers].push(c));
  return {
    total: affected.length,
    shards: shards.map(s => s.map(c => c.id)),
    etaMs: Math.max(...shards.map(s => s.reduce((t, c) => t + c.estMs, 0))),
  };
}
console.log(orchestrate([{ id: 1, deps: ['a'], estMs: 100 }], ['a']).total);
```
