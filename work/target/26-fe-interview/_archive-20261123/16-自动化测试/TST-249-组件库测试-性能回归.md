## TST-249：组件库的性能回归测试（渲染时长/包体积）如何做？
**答**：
- 渲染时长：关键组件（Table/List）在固定数据规模下的 mount 时间断言（阈值 + 趋势）。
- 包体积：size-limit 断言每组件 chunk 上限，tree-shaking 生效验证（只 import Button 不带全库）。
- 重渲染次数：React Profiler 统计 props 变化下的重渲染次数（防不必要的全树重渲染）。
- 性能基线随版本归档，回归超 20% 必须解释。

```javascript
import { Profiler } from 'react';
let renders = 0;
test('Table 渲染性能', () => {
  render(<Profiler id="table" onRender={() => renders++}>
    <Table data={mockRows(500)} /></Profiler>);
  expect(renders).toBeLessThanOrEqual(2);      // 首渲染 + 可能的一次 effect
});
```
