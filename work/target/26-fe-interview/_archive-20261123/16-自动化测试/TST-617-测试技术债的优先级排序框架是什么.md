## TST-617：测试技术债的优先级排序框架是什么？

**答**：
- 结论：用「风险敞口 × 修复成本倒数 × 阻塞面」三因子排序，而不是按大声量。
- 风险敞口看近 90 天逃逸缺陷与核心链路覆盖；阻塞面看有多少用例/团队被它拖累。
- 每季度留固定比例（如 20%）工时还债，避免永远排不上。
- 追问钩子：技术债和业务排期冲突，你如何用数据说服 PM 让路？

```javascript
function debtPriority(items) {
  return items.map(d => ({
    id: d.id,
    score: +(d.exposure * d.blockScope / Math.max(1, d.fixDays)).toFixed(2),
  })).sort((a, b) => b.score - a.score);
}
console.log(debtPriority([
  { id: 'D1', exposure: 8, blockScope: 5, fixDays: 2 },
  { id: 'D2', exposure: 3, blockScope: 1, fixDays: 1 },
]));
```
