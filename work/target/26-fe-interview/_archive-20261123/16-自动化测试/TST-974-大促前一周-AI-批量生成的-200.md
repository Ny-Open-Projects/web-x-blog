## TST-974：大促前一周，AI 批量生成的 200 条回归用例要上线，可靠性验收该卡哪些指标？
**答**：
- 结论：大促验收看三条硬指标——flake 率 ≤2%、断言有效率 ≥90%、关键路径缺陷检出率不低于人工基线，任一不达标不进大促门禁。
- 做法：在封版前的稳定环境连跑 3 轮，取交集置信；对 AI 用例标注「建议级」不直接阻塞，人工复核后才升级为阻塞级。
- 兜底：大促期间 AI 用例只做旁路信号，真门禁仍由人工确认的核心用例把守。
- 追问钩子：AI 用例检出率比人工高 5%，但 flake 率 4%，大促要不要用？怎么折中？

```javascript
const GATE = { maxFlake: 0.02, minAssertionValidity: 0.9, minDetectVsHuman: 1.0 };
function promoAcceptance(stats) {
  const checks = [
    ['flake率', stats.flakeRate <= GATE.maxFlake],
    ['断言有效率', stats.assertionValidity >= GATE.minAssertionValidity],
    ['检出率不低于人工', stats.detectRate >= stats.humanDetectRate * GATE.minDetectVsHuman],
  ];
  const failed = checks.filter(([, ok]) => !ok).map(([n]) => n);
  return { pass: failed.length === 0, failed,
    strategy: failed.length ? '降级为建议级，人工复核后升级' : '可进大促门禁' };
}
console.log(promoAcceptance({ flakeRate: 0.04, assertionValidity: 0.95,
  detectRate: 0.9, humanDetectRate: 0.85 }));
// { pass:false, failed:['flake率'], strategy:'降级为建议级…' }
```
