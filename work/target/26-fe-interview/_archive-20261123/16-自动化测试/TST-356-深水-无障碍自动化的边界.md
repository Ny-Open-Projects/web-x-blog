## TST-356：a11y 自动化能测什么测不了什么？边界如何补齐？
**答**：
- 能测：axe 规则类（对比度/aria 属性/标签关联）、键盘可达路径。
- 测不了：屏幕阅读器实际体验（播报顺序/打断逻辑）、认知负担。
- 补齐：关键流程人工 SR 走查（季度）+ SR 用户测试（年度）。
- 自动化覆盖 70% 问题、人工补 30% 体验——比例持续校准。

```javascript
const a11yLayers = {
  auto: 'axe 规则 + keyboard path（每 PR）',
  manual: 'SR 走查（季度，关键流程清单）',
  user: '真实 SR 用户测试（年度）',
};
```
