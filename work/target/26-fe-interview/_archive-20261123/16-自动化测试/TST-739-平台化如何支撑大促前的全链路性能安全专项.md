## TST-739：平台化如何支撑「大促前」的全链路性能安全专项

**答**：
- 结论：大促专项=「全链路压测 + 安全攻坚 + 容量评估」的集中战役，平台提供统一作战室与资源保障。
- 平台侧准备：预留专属资源池、冻结非相关发布、开启增强监控与告警，避免专项期间噪声干扰。
- 专项用例来自历史大促缺陷与核心链路，按业务优先级排序，结果实时汇总到作战看板。
- 追问钩子：专项发现的问题太多，临近大促来不及全部修复，如何决策？

```javascript
// 大促专项：按业务等级与风险排优先级
function prioritize(issues) {
  const weight = { P0: 4, P1: 3, P2: 2, P3: 1 };
  return issues
    .map(i => ({ ...i, score: (weight[i.level] || 0) * (i.affectedUsers || 1) }))
    .sort((a, b) => b.score - a.score);
}
console.log(prioritize([
  { id: 'a', level: 'P0', affectedUsers: 1 },
  { id: 'b', level: 'P2', affectedUsers: 100 },
]).map(x => x.id)); // ['b','a']
```
