## TST-614：没有汇报关系的多个团队，测试架构怎么推动落地？

**答**：
- 结论：靠「价值 + 契约 + 样板」而非职权——先把一个试点团队做到可量化收益。
- 用 golden path（模板仓库 + CLI）降低采纳成本，让「正确做法」比「自己搞」更省事。
- 建立社区 RFC 与贡献回流机制，让早期采纳者成为布道者。
- 追问钩子：某个团队就是不用你的平台，你如何保证整体质量不出现缺口？

```javascript
function adoptionPlan(teams, pilotResult) {
  return teams.map(t => ({
    team: t.name,
    strategy: t.pain >= pilotResult.gain * 0.8 ? 'pull' : 'push',
    offer: 'golden-path-cli',
    guard: t.pain < pilotResult.gain * 0.5 ? 'org-gate' : 'soft-lint',
  }));
}
console.log(adoptionPlan([{ name: '交易', pain: 8 }], { gain: 6 }));
```
