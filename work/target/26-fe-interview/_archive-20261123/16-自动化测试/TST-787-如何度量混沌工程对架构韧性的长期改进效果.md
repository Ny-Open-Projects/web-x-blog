## TST-787：如何度量混沌工程对「架构韧性」的长期改进效果

**答**：
- 结论：长期效果看「同样的故障注入，系统恢复得更快、影响更小」，核心指标是 MTTR 下降与爆炸半径缩小。
- 度量方法：固定注入场景作为「韧性基准」，定期重跑对比恢复时间与影响面趋势。
- 辅助指标：实验发现的缺陷数、改进项闭环率、生产事故数变化，形成韧性趋势看板。
- 追问钩子：韧性指标变好了但用户仍投诉，可能漏了什么？

```javascript
// 韧性趋势：同场景多次重跑的恢复时间对比
function resilienceTrend(runs) {
  const sorted = [...runs].sort((a, b) => a.date - b.date);
  const first = sorted[0]?.mttrMs || 0;
  const last = sorted[sorted.length - 1]?.mttrMs || 0;
  return {
    first, last,
    improvement: first ? +((first - last) / first * 100).toFixed(1) : 0,
    trend: last < first ? 'improving' : 'degrading',
  };
}
console.log(resilienceTrend([
  { date: 1, mttrMs: 600000 }, { date: 2, mttrMs: 300000 },
])); // improvement:50
```
