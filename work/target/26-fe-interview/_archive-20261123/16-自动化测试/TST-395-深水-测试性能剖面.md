## TST-395：「用例级性能剖面」（哪个用例最耗时耗资源）如何采集与利用？
**答**：
- 采集：框架钩子计时 + 系统级资源采样（CPU/内存/net）按用例对账。
- 利用：慢用例 topN 定向优化（数据准备/等待/复用）。
- 趋势：性能剖面随代码演进漂移（新用例拖慢全量）预警。
- 容量规划：剖面数据预测新需求对 CI 时长的影响。

```javascript
const profile = perCase({
  wall: result.duration, cpu: proc.cpuTime,
  net: bytesSent, heap: peakHeap,
});
// top10 慢用例 → 治理看板 + 容量预测
```
