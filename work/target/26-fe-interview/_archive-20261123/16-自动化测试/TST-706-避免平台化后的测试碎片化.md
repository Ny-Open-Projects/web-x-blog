## TST-706：如何避免平台化后的「测试碎片化」：统一入口与场景化测试的平衡

**答**：
- 结论：碎片化根因是「每个团队自建一套入口和断言方言」，解法是统一调度入口 + 统一结果模型，允许场景化断言插件化扩展。
- 统一三件事：用例元数据 schema、结果模型、触发器协议；其余允许团队自定义。
- 建立「用例集市」复用高频场景，避免重复造轮子，用复用率指标牵引。
- 追问钩子：某团队坚持用自有 DSL 不愿接入统一入口，架构师怎么处理？

```javascript
// 统一结果模型：不同框架产物归一化
function normalizeResult(raw, adapter) {
  return adapter(raw); // 各框架只实现 adapter，平台只看统一结构
}
const jestAdapter = r => ({ id: r.fullName, ok: r.status === 'passed', ms: r.duration });
const pwAdapter = r => ({ id: r.title, ok: r.status === 'expected', ms: r.duration });
function aggregate(results) {
  const norm = results.map((r, i) => normalizeResult(r, i % 2 ? pwAdapter : jestAdapter));
  return { total: norm.length, passed: norm.filter(x => x.ok).length };
}
console.log(aggregate([
  { fullName: 'a', status: 'passed', duration: 10 },
  { title: 'b', status: 'expected', duration: 20 },
]));
```
