## TST-696：混沌测试的「反脆弱断言」怎么写（验证自愈而不只是不崩）？

**答**：
- 结论：断言分三级——不崩（可用性）、能恢复（自愈时间 < SLO）、恢复后无副作用。
- 注入故障后移除注入，持续观测关键指标直到回到基线，记录恢复时长。
- 若系统借故障变得更强（如自动降级策略被触发并保留），记录为正收益。
- 追问钩子：恢复后数据不一致（重复下单），算不算自愈成功？

```javascript
function antiFragile(series, { baseline, sloMs }) {
  const recoveredAt = series.find(p => Math.abs(p.metric - baseline) < 0.05);
  const stable = recoveredAt &&
    series.filter(p => p.ts >= recoveredAt.ts)
      .every(p => Math.abs(p.metric - baseline) < 0.05);
  return {
    recovered: !!recoveredAt,
    recoveryMs: recoveredAt ? recoveredAt.ts : Infinity,
    withinSLO: !!recoveredAt && recoveredAt.ts <= sloMs,
    stable: !!stable,
  };
}
```
