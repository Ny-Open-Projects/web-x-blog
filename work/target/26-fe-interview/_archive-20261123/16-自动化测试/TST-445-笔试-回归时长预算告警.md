## TST-445：笔试：回归时长超预算的告警与归因（哪个阶段拖慢）。
**题目**：阶段耗时 `[{stage, ms}]` 与各阶段预算。超预算阶段输出；总超时归因到「占比最大的超支阶段」。输出 `{overstages, culprit}`。

```javascript
function durationAlert(stages, budgets) {
  const over = stages.filter(s => s.ms > (budgets[s.stage] ?? Infinity))
    .map(s => ({ stage: s.stage, budget: budgets[s.stage], actual: s.ms,
      overRatio: +(s.ms / budgets[s.stage] - 1).toFixed(2) }))
    .sort((a, b) => b.overRatio - a.overRatio);
  return { overstages: over, culprit: over[0]?.stage ?? null };
}
console.log(durationAlert([
  { stage: 'seed', ms: 100_000 }, { stage: 'run', ms: 900_000 },
], { seed: 60_000, run: 800_000 }).culprit); // run

```

**评分点**：
- 逐阶段超支计算（绝对值 + 超比率）。
- culprit = 超比率最大者。
- 输出含预算/实际/超出。
- 全部达标时 culprit null。
