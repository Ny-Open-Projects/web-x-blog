## TST-348：回归套件的编排策略（顺序/分组/失败短路）？
**答**：
- 冒烟先行：5 分钟冒烟全红则终止全量（环境问题快速失败）。
- 关键域优先：支付/登录等高风险域排前（早发现）。
- 分组并行：无依赖域并行分片，有依赖域（数据准备）串行前置。
- 失败聚合：跑完全量再聚合失败（不逐条短路），除非环境级失败（多域同时崩）。

const orchestration = [
  { stage: 'smoke', failFast: true },
  { stage: 'critical-domains', order: ['auth', 'pay'] },
  { stage: 'full', parallel: 'shard', stopOn: 'env-wide-failure' },
];
