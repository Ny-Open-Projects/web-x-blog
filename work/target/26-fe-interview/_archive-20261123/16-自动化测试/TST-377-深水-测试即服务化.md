## TST-377：把测试能力服务化（按需触发测试的自助平台）？
**答**：
- 自助触发：任何人/工具可通过 API 触发指定套件（带参数：分支/环境/范围）。
- 结果服务化：结果 API + Webhook，供发布系统/机器人消费。
- 典型消费者：发布系统（灰度前自验）、值班机器人（怀疑变更时触发回归）。
- 配额与优先级：多请求排队（关键发布优先）。

```javascript
POST /api/test-runs
{ "suite": "e2e-smoke", "ref": "release-3.8", "env": "staging", "priority": "high" }
// webhook → 发布系统等待结果决定是否放量
r
```
