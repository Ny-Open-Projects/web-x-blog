## TST-774：笔试：实现混沌实验的「盲区」分析器（未覆盖的故障维度）

**题目**：输入维度定义 dims {dimension:[values...]}（如 {network:['delay','drop'], state:['dirty','expired']}）与已做实验 experiments [{dimension, value}]。输出未覆盖的组合（笛卡尔积中未出现的），按 dimension 分组，每组内按 dims 中 value 原顺序排列。

**答**：
- 先生成全量笛卡尔积，再剔除已覆盖。
- 分组按维度，组内保持 value 定义顺序。
- 已覆盖用 Set 查重。

```javascript
function findBlindSpots(dims, experiments) {
  const covered = new Set(experiments.map(e => `${e.dimension}:${e.value}`));
  const out = {};
  for (const [dim, values] of Object.entries(dims)) {
    out[dim] = values.filter(v => !covered.has(`${dim}:${v}`));
  }
  return out;
}
console.log(findBlindSpots(
  { network: ['delay', 'drop', 'reorder'], state: ['dirty', 'expired'] },
  [{ dimension: 'network', value: 'delay' }]
)); // network:['drop','reorder'], state:['dirty','expired']
```

**评分点**：
- 已覆盖集合构建正确
- 未覆盖过滤正确
- 分组与顺序保持
- 空实验数组全覆盖
