## TST-252：表单类组件（校验/联动/提交）的测试设计？
**答**：
- 校验规则表驱动：必填/格式/长度/自定义异步校验逐条断言（错误文案与时机）。
- 联动矩阵：字段 A 变化对 B 的可见性/选项/校验状态影响（耦合关系表驱动生成用例）。
- 异步校验竞态：连续快速输入时旧校验结果不覆盖新结果（防过期 promise 污染）。
- 提交流程：校验失败不提交、防重复提交、提交中禁用态。

```javascript
test('异步校验竞态', async () => {
  render(<UsernameField />);
  const input = screen.getByRole('textbox');
  await userEvent.type(input, 'ab{delay:none}');
  await userEvent.type(input, 'c');                 // 快速连续输入
  vi.advanceTimersByTime(600);
  await expect(screen.getByRole('alert')).toHaveTextContent(/用户名可用/); // 只信最后一次
});
```
