## TST-584：混沌实验的稳态假设如何定义与验证

**答**：
- 结论：稳态假设 = 「系统正常时应满足的可观测指标」（如错误率<0.1%、首屏<2.5s、无白屏）；混沌实验就是在注入故障时验证这些指标是否仍成立。
- 做法：稳态指标要可量化、可自动采集、与用户体感相关；实验前后对比，若偏离超阈值则实验失败并触发回滚；避免用「服务活着」这种太弱的定义。
- 追问钩子：稳态假设太严格导致实验总失败怎么办？——区分「必须保持」与「允许降级」的指标：错误提示可见是必须，部分功能降级是允许，分层定义更合理。

```javascript
// 稳态假设：多指标断言，区分 must 与 allowed-degrade
const STEADY = {
  must: { whiteScreen: false, errorBoundaryShown: true },
  soft: { firstPaintMs: 2500, apiErrorRate: 0.05 },
};
function checkSteady(observed, steady = STEADY) {
  const must = Object.entries(steady.must).every(([k, v]) => observed[k] === v);
  const soft = Object.entries(steady.soft).every(([k, lim]) => (observed[k] ?? 0) <= lim);
  return { mustHold: must, softHold: soft, resilient: must && soft };
}
```
