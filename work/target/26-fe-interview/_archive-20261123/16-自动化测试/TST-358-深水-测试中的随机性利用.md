## TST-358：随机性在测试中的正确使用（模糊测试/随机探索）？
**答**：
- property-based：性质 + 随机输入（fast-check）自动发现边界。
- monkey testing：随机点击爬行（探索性自动化）发现崩溃/白屏——轻量冒烟补充。
- 随机必须可复现：seed 落盘，失败可重放。
- 随机用例单独分组（不进门禁主链路），发现的问题转正为固定用例。

```javascript
import fc from 'fast-check';
it('金额计算性质', () => fc.assert(fc.property(
  fc.integer({ min: 0, max: 1e9 }), fc.integer({ min: 0, max: 1e9 }),
  (a, b) => expect(addFen(a, b)).toBe(a + b)), { seed: 42 }));
```
