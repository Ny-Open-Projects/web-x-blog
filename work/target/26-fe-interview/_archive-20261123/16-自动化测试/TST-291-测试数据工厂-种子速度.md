## TST-291：E2E 前种子数据量大导致环境准备慢，如何优化？
**答**：
- 批量插入：API 批量端点或直连 DB COPY，替代逐条 HTTP 调用。
- 按需种子：只种当前套件声明的实体（用例元数据声明依赖）。
- 种子缓存：只读数据（商品目录）跨运行复用（内容 hash 校验后跳过重建）。
- 并行种子：独立实体并行种（用户/商品互不依赖），有依赖的最后种。

```javascript
// 按需 + 并行种子
const needs = collectDeclaredEntities(tests);   // 用例元数据声明
await Promise.all([seedUsers(needs.users), seedGoods(needs.goods)]);
await seedOrders(needs.orders);                  // 依赖后置

```
