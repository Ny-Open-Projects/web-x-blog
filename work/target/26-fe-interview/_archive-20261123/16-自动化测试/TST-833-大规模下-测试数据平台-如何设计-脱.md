## TST-833：大规模下「测试数据平台」如何设计（脱敏/工厂/隔离）？
**答**：
- 结论：测试数据平台的三要素——生产数据脱敏后再用、用工厂批量造数、每用例数据隔离并自动回收。
- 脱敏：对手机号/身份证/敏感字段做脱敏或伪造，离线数据入库前经过脱敏流水线，合规可审计。
- 造数：Builder/Factory 模式按 schema 生成合法数据（呼应测试数据工厂），支持种子固定以便复现。
- 隔离：每条用例用独立数据集/账号（tenant id 隔离），用例结束回收，避免相互污染与并行冲突。
- 追问钩子：脱敏后数据「看起来真实但关系错乱」（如外键断开），你如何在脱敏时保持数据一致性？

```javascript
// 测试数据工厂：固定种子可复现 + 脱敏
function seededRandom(seed) {
  let s = seed >>> 0;
  return () => ((s = (s * 1664525 + 1013904223) >>> 0) / 2 ** 32);
}
const rnd = seededRandom(42);
function makeUser() {
  return {
    id: `u_${Math.floor(rnd() * 1e6)}`,
    phone: `138****${String(Math.floor(rnd() * 10000)).padStart(4, '0')}`,
    role: rnd() > 0.5 ? 'vip' : 'normal',
  };
}
console.log(makeUser(), makeUser()); // 固定种子 -> 每次运行结果一致，可复现 flaky
```
