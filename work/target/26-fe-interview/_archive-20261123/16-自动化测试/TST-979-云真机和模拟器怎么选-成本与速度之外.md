## TST-979：云真机和模拟器怎么选？成本与速度之外还要考虑什么？
**答**：
- 结论：模拟器快且便宜、适合广覆盖逻辑；云真机贵且慢但能抓真机专属问题（GPU、系统 WebView、推送、支付 SDK）。
- 策略：金字塔——大量逻辑用模拟器，云真机只跑「真机敏感」的关键路径（支付、相机、分享），按风险分级投放。
- 其他维度：数据合规（真机是否允许真实账号）、稳定性（云真机排队）、设备碎片化覆盖。
- 追问钩子：云真机队列高峰期排队 20 分钟，大促封版只有 1 小时窗口，你怎么安排真机测试？

```javascript
function devicePlan({ cases, budget }) {
  const realDeviceNeeded = c => /pay|camera|push|webview/i.test(c.tags.join(','));
  const emu = cases.filter(c => !realDeviceNeeded(c));
  const real = cases.filter(c => realDeviceNeeded(c));
  const realCost = real.length * 3; // 云真机单次成本系数 3
  return {
    emulator: emu.map(c => c.id),
    realDevice: real.slice(0, Math.floor(budget / 3)).map(c => c.id), // 预算内优先高风险
    deferred: real.slice(Math.floor(budget / 3)).map(c => c.id),
  };
}
console.log(devicePlan({
  cases: [{ id: 'c1', tags: ['pay'] }, { id: 'c2', tags: ['list'] }], budget: 3,
})); // { emulator:['c2'], realDevice:['c1'], deferred:[] }
```
