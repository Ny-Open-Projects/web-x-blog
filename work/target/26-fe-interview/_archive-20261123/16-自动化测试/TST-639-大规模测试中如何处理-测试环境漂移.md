## TST-639：大规模测试中如何处理「测试环境漂移」？

**答**：
- 结论：漂移的根治靠「不可变环境 + 指纹校验」——每次运行前校验环境 hash，不一致就重建。
- 区分「配置漂移」（依赖版本/环境变量）与「数据漂移」（脏数据累积），前者重建后者清理。
- 把环境指纹写进报告，失败时能还原当时环境。
- 追问钩子：环境每次重建太慢，如何在复用与漂移间取舍？

```javascript
function checkDrift(env, expected) {
  const diffs = [];
  Object.entries(expected).forEach(([k, v]) => {
    if (env[k] !== v) diffs.push({ key: k, want: v, got: env[k] });
  });
  return {
    drifted: diffs.length > 0,
    diffs,
    action: diffs.length > 2 ? 'rebuild' : 'patch',
  };
}
console.log(checkDrift({ node: '18' }, { node: '20', browser: 'chrome' }));
```
