## TST-677：探索性测试的发现怎么固化为可执行回归用例？

**答**：
- 结论：探索的价值不在当场发现 bug，而在把「发现路径」转成可重复执行的用例。
- 记录探索时的操作序列与观察点，去重后按风险排序进入回归套件。
- 只有能稳定复现的发现才固化；偶发的进 flaky 观察区。
- 追问钩子：探索发现的问题修复了，用例还要留吗？

```javascript
function solidify(findings, { minConfidence = 0.8 } = {}) {
  const groups = new Map();
  findings.filter(f => f.confidence >= minConfidence).forEach(f => {
    const key = f.steps.join('>');
    if (!groups.has(key))
      groups.set(key, { steps: f.steps, expect: f.expect, hits: 0 });
    groups.get(key).hits++;
  });
  return [...groups.values()]
    .sort((a, b) => b.hits - a.hits)
    .map(g => ({ ...g, regression: true }));
}
```
