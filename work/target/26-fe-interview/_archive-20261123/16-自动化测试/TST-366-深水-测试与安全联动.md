## TST-366：安全测试（DAST/注入）如何纳入常规测试流程？
**答**：
- SAST（静态）进 PR：semgrep 规则集（XSS/注入/敏感信息）。
- DAST（动态）进夜间：对测试环境跑注入用例（SQL/XSS payload 库）。
- 依赖漏洞：SCA 扫描 + 补丁 PR 自动化（CVE 驱动）。
- 安全用例与业务用例同库管理（复用数据工厂与报告）。

```javascript
# 夜间 DAST
zap-cli quick-scan -t http://staging.example.com --self-contained
# 结果合并进测试报告，高危进发布门禁
r
```
