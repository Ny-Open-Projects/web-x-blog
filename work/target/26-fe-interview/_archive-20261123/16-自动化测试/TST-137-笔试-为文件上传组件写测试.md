## TST-137：笔试：为文件上传组件写测试（类型校验/大小/进度/取消）
**答**：
- 场景：上传组件约束「仅图片、≤2MB」，上传中显示进度条、可取消；测试用 RTL 的 `fireEvent.change(input, { target: { files: [file] } })`（userEvent.upload 更推荐），配合 MSW delay 造进度窗口与取消窗口。
- 要点：File 对象在 jsdom 里用 `new File([blob], name, { type })` 构造；超限文件在**前端校验**就拦截（不发请求，断言请求数为 0）；进度条用 XMLHttpRequest onprogress 或 fetch 不支持——组件若用 XHR 则 mock 进度回调，或组件暴露 onProgress 用 fake 数据。
- 取消：AbortController 在组件里持有，测试点击「取消」后断言请求 abort、UI 回到初始态。

```jsx
import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { http, HttpResponse, delay } from 'msw';
import { server } from '@/mocks/server';
import Uploader from './Uploader';

const makeFile = (name, sizeMB, type = 'image/png') =>
  new File([new ArrayBuffer(sizeMB * 1024 * 1024)], name, { type });

test('非图片/超限文件被前端拦截，不发请求', async () => {
  const requests = [];
  server.use(http.post('/api/upload', async ({ request }) => {
    requests.push(request); return HttpResponse.json({ url: 'https://x/f.png' });
  }));
  render(<Uploader />);

  const user = userEvent.setup();
  const input = screen.getByLabelText('上传图片');
  await user.upload(input, makeFile('doc.pdf', 1, 'application/pdf'));   // 类型错
  await user.upload(input, makeFile('big.png', 3));                       // 超限
  expect(requests).toHaveLength(0);                                       // 都被拦截
  expect(screen.getByText('仅支持图片格式')).toBeInTheDocument();
  expect(screen.getByText('文件不能超过 2MB')).toBeInTheDocument();
});

test('上传中显示进度并可取消', async () => {
  let cancelled = false;
  server.use(http.post('/api/upload', async ({ request }) => {
    await delay(1000);
    if (request.signal.aborted) { cancelled = true; throw new DOMException('aborted', 'AbortError'); }
    return HttpResponse.json({ url: 'https://x/f.png' });
  }));
  render(<Uploader />);

  const user = userEvent.setup();
  await user.upload(screen.getByLabelText('上传图片'), makeFile('a.png', 1));
  expect(await screen.findByRole('progressbar')).toBeInTheDocument();     // 进度态

  await user.click(screen.getByRole('button', { name: '取消' }));
  await screen.findByText('已取消');
  await vi.waitFor(() => expect(cancelled).toBe(true));                   // 请求真被 abort
});
```

**评分点**：
1. 前端校验断言「请求数为 0」而非只看文案（防漏发）。
2. jsdom File 构造带正确 MIME 与 size（ArrayBuffer 造大文件）。
3. 取消用 AbortController 语义验证 signal.aborted，不是只断言 UI。
4. userEvent.upload 而非手改 input.value（触发真实 change 事件）。
