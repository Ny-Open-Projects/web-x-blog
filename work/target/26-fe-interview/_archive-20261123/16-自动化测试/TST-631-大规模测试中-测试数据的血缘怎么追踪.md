## TST-631：大规模测试中，测试数据的血缘怎么追踪？

**答**：
- 结论：把每条数据当成有身份的实体，记录「从哪来、被哪些用例消费、改了影响谁」。
- 血缘图节点是数据集/用例，边是生产/消费关系；变更一个数据集自动算出影响用例集合。
- 血缘来自代码静态分析 + 运行时埋点双通道，避免只靠人工登记。
- 追问钩子：血缘图很大，如何避免全图遍历拖慢每次 PR？

```javascript
function impact(graph, dataId) {
  const out = new Set(), q = [dataId];
  while (q.length) {
    const cur = q.shift();
    (graph[cur] || []).forEach(next => {
      if (!out.has(next)) { out.add(next); q.push(next); }
    });
  }
  return [...out];
}
console.log(impact({ user: ['case-a'], 'case-a': ['report'] }, 'user'));
```
