## TST-447：笔试：种子数据集的版本指纹与漂移检测。
**题目**：数据集指纹 = 实体数 + 内容 hash（排序后拼接）。实现 `datasetFingerprint(rows)` 与 `detectDrift(old, new)`：指纹不同输出差异摘要（实体数变化/hash 变化）。

```javascript
function datasetFingerprint(rows) {
  const s = [...rows].map(r => JSON.stringify(r)).sort().join('|');
  const h = [...s].reduce((x, c) => (x * 31 + c.charCodeAt(0)) | 0, 7);
  return { count: rows.length, hash: h };
}
function detectDrift(oldDs, newDs) {
  const a = datasetFingerprint(oldDs), b = datasetFingerprint(newDs);
  if (a.hash === b.hash) return { drifted: false };
  return { drifted: true,
    summary: `${a.count !== b.count ? `实体数 ${a.count}→${b.count}；` : ''}内容变化（hash ${a.hash}→${b.hash}）` };
}

```

**评分点**：
- 指纹确定性（排序后哈希）。
- 漂移摘要（数量/内容两类）。
- 浮点/顺序敏感性处理（排序归一）。
- 指纹碰撞说明（简化哈希局限）。
