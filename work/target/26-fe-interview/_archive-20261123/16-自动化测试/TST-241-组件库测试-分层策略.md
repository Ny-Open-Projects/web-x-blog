## TST-241：组件库（design system）的测试体系应如何分层？
**答**：
- L1 token/样式层：token 映射单测（颜色/间距变量与设计稿一致）。
- L2 组件交互层：Testing Library 语义断言（角色/键盘/状态切换）——核心层。
- L3 视觉层：Storybook + 视觉 diff——外观回归。
- L4 集成层：典型业务组合场景 E2E（表单全流程）——低频兜底。
- 比例：L2 为主（约 60%），纯快照堆量是组件库测试的常见误区。

```javascript
const layers = {
  L1: 'token 单测：expect(token.color.primary).toBe("#165DFF") 30%',
  L2: '语义交互：getByRole + keyboard 60%',
  L3: '视觉 diff：Storybook story 快照 8%',
  L4: '组合场景 E2E 2%',
};
```
