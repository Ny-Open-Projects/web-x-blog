## TST-818：高端面试收尾题：如果让你从零定义一家独角兽的质量文化，你会做哪几件事？
**答**：
- 结论：质量文化不是靠口号，而是靠「默认正确的工具链 + 可度量的反馈 + 责任共担的机制」三件事长期演化出来的。
- 第一件事：把质量内建进研发工作流——pre-commit、CI 门禁、覆盖率与 flaky 看板默认可见，让质量「看得见」。
- 第二件事：建立「谁改谁负责质量」的权责——测试不是守门员而是教练，开发对单测负责，测试对策略与工具负责。
- 第三件事：建立无指责的事后复盘(blameless postmortem)，把事故转化为体系改进而非追责个人。
- 追问钩子：文化变革最容易在哪个环节失败？你如何提前规避？（提示：中层管理者的不配合）

```javascript
// 质量文化的「三根支柱」落地清单
const qualityCulture = {
  工具链内建: ['pre-commit', 'CI 门禁', '覆盖率看板', 'flaky 看板'],
  责任共担: { 开发: ['单测', '组件测试'], 测试: ['策略', '工具', '探索性测试'] },
  无指责复盘: { 关注: '体系如何改进', 禁止: '追责个人', 产出: ['改进项', '门禁升级'] },
};
const pillars = Object.keys(qualityCulture);
console.log(`质量文化三支柱：${pillars.join(' / ')}`);
function auditCulture(practices) {
  return Object.keys(qualityCulture).filter(p => !practices.includes(p));
}
console.log('缺失支柱:', auditCulture(['工具链内建'])); // ['责任共担','无指责复盘']
```
