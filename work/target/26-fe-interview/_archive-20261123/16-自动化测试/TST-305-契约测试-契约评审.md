## TST-305：契约变更需要评审吗？评审什么？
**答**：
- breaking 变更必须评审：受影响消费者清单（broker 自动列出）+ 迁移计划。
- 评审点：语义合理性（字段命名/错误码语义）、兼容性、文档同步。
- 非 breaking 也留痕：自动生成 diff changelog 入契约 PR。
- 契约 owner 制：接口提供者 owner 签字，消费者代表确认无破坏。

```javascript
# 契约变更 PR 模板
affected-consumers: fe-cart(5.2.x), fe-admin(1.x)   # broker 自动生成
breaking: false   # CI 校验，true 时必须填迁移计划
migration-plan: N/A
reviewers: provider-owner, consumer-rep
r
```
