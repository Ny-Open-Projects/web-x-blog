## TST-308：组件级性能回归（render 时长）在测试里怎么落地？
**答**：
- React Profiler onRender 统计实际渲染时长，数据规模固定下断言阈值。
- 重渲染次数断言：props 不变时不应重渲染（memo 生效验证）。
- 列表类组件：500 行数据滚动帧率仿真（虚拟列表断言 DOM 节点数上限）。
- 基线版本对照：组件性能随组件库版本趋势，劣化 20% 内解释。

```javascript
test('memo 生效', () => {
  const { rerender } = render(<Row row={row} />);
  const before = renders;
  rerender(<Row row={row} />);       // 相同 props
  expect(renders).toBe(before);      // 未重渲染
});
```
