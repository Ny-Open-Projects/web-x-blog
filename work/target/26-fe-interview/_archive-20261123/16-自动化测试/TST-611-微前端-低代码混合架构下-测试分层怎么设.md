## TST-611：微前端 + 低代码混合架构下，测试分层怎么设计？

**答**：
- 结论：按「运行时边界」而非「代码仓库」分层——主框架层、子应用契约层、低代码产物层各自独立门禁。
- 低代码页面用 schema 快照 + 渲染冒烟替代手工用例；子应用用契约测试守住共享状态与事件。
- 跨层只测一件事：集成点（路由挂载、事件总线、主题注入）。
- 追问钩子：低代码 schema 每天变几十次，快照会不会天天红？怎么设计稳定基线？

```javascript
function layerFor(change) {
  if (change.kind === 'schema') return ['lowcode-render', 'contract'];
  if (change.kind === 'subapp') return ['subapp-unit', 'contract', 'integration'];
  if (change.kind === 'shell') return ['shell-unit', 'integration'];
  return ['unit'];
}
const plan = layerFor({ kind: 'schema' });
console.log(plan.join(' -> ')); // lowcode-render -> contract
```
