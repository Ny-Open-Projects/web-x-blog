## TST-771：笔试：实现混沌实验结果的「异常检测」器（区分预期稳态与真实故障）

**题目**：输入指标序列 samples [{at, value}] 与 expectedRange [min, max]（注入期间允许的正常波动范围）。检测「真实故障」：连续 exceedCount 个点超出 expectedRange 才判故障（单点超范围视为预期噪声）。返回 {fault:boolean, startAt:首次超范围起点或null, runLength:最长连续超范围数}。

**答**：
- 逐点标记是否超范围，统计连续段。
- 达到 exceedCount 阈值才判故障，记录首次故障起点。
- 空序列兜底。

```javascript
function detectFault(samples, expectedRange, exceedCount) {
  const [min, max] = expectedRange;
  let run = 0, maxRun = 0, faultStart = null;
  for (const s of samples) {
    const out = s.value < min || s.value > max;
    run = out ? run + 1 : 0;
    if (run === exceedCount && faultStart === null) faultStart = s.at;
    maxRun = Math.max(maxRun, run);
  }
  return { fault: maxRun >= exceedCount, startAt: faultStart, runLength: maxRun };
}
console.log(detectFault([
  { at: 1, value: 5 }, { at: 2, value: 20 }, { at: 3, value: 21 }, { at: 4, value: 6 },
], [0, 10], 2)); // fault:true, startAt:3
```

**评分点**：
- 连续超范围判定正确
- 首次故障起点记录正确
- 最长连续统计正确
- 空序列兜底
