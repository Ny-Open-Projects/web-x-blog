## TST-469：笔试：用受控调度检测数据竞争（模拟交错执行）。
**题目**：给定两个异步操作（以步骤数组表达，await 点显式）。实现 `interleave(a, b, order)` 按指定交错顺序执行，验证共享状态不变量；输出交错路径下的最终状态。

```javascript
function interleave(opA, opB, order, state) {
  // order: ['a','b','a','a','b'] 逐步推进
  const it = { a: opA[Symbol.iterator](), b: opB[Symbol.iterator]() };
  for (const who of order) {
    const step = it[who].next();
    if (!step.done) step.value(state);      // 每步是同步变换（模拟 await 间临界区）
  }
  return state;
}
// 示例：非原子读改写
const readModify = [s => s.v = s.v, s => s.v = s.v + 1];
const st = interleave(readModify, readModify, ['a','b','a','b'], { v: 0 });
console.log(st.v); // 1 而非 2 → 竞态复现（应加锁/原子操作）

```

**评分点**：
- 交错执行器（按 order 序列交替推进两操作步骤）。
- 不变量校验（执行后断言）。
- 枚举所有交错（小规模）可选实现。
- 检测到违反不变量输出交错序列（复现路径）。
