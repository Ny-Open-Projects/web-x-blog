## TST-721：平台如何承载「常态化性能回归」：性能用例的调度与基线管理架构

**答**：
- 结论：常态化性能回归=「定时跑 + 基线比 + 自动归因」，平台要把性能用例当一等公民调度，而非附属于功能用例。
- 调度要错峰、独占资源、固定环境规格，避免噪声；每次运行绑定环境指纹（机器/浏览器版本）。
- 基线管理用滚动中位数而非单次值，超阈值先判环境噪声再判回归。
- 追问钩子：性能用例跑得慢又占资源，如何决定哪些页面/场景值得纳入常态化？

```javascript
// 性能基线：滚动中位数 + 阈值判定
function baseline(history) {
  const sorted = [...history].sort((a, b) => a - b);
  const mid = Math.floor(sorted.length / 2);
  const median = sorted.length % 2 ? sorted[mid] : (sorted[mid - 1] + sorted[mid]) / 2;
  return median;
}
function isRegression(current, history, tolerance) {
  const base = baseline(history);
  return current > base * (1 + tolerance);
}
console.log(isRegression(1300, [1000, 1050, 980, 1020], 0.2)); // false
console.log(isRegression(1500, [1000, 1050, 980, 1020], 0.2)); // true
```
