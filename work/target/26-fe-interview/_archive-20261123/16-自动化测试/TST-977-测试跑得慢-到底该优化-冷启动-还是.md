## TST-977：测试跑得慢，到底该优化「冷启动」还是「热执行」？怎么建成本模型决策？
**答**：
- 结论：先拆总成本 = 冷启动（拉镜像/起浏览器/装依赖）+ 热执行（用例本身）+ 失败重跑；优化收益取决于三者占比。
- 模型：单次 CI 成本 = 冷启动时长 × 单价 + Σ用例时长 × 并发系数；100 个短用例冷启动占比高，应复用 worker/容器。
- 决策：冷启动占比 >40% 优先复用预热池；否则优化用例与分片。
- 追问钩子：把 500 个用例从「每次全新容器」改成「复用预热浏览器池」后快了 3 倍，但偶发状态污染，你怎么权衡？

```javascript
function costModel({ coldStartMs, caseDurations, concurrency, unitPricePerSec }) {
  const totalMs = coldStartMs + caseDurations.reduce((a, b) => a + b, 0) / concurrency;
  const coldRatio = coldStartMs / totalMs;
  return {
    totalSec: +(totalMs / 1000).toFixed(1),
    cost: +(totalMs / 1000 * unitPricePerSec).toFixed(3),
    coldRatio: +coldRatio.toFixed(2),
    advice: coldRatio > 0.4 ? '优化冷启动：预热池/复用容器' : '优化热执行：分片/裁剪用例',
  };
}
console.log(costModel({ coldStartMs: 30000, caseDurations: Array(100).fill(200),
  concurrency: 5, unitPricePerSec: 0.01 }));
// { totalSec:34, cost:0.34, coldRatio:0.88, advice:'优化冷启动：预热池/复用容器' }
```
