## TST-259：如何测试「一个子应用变慢不影响主应用」的性能隔离？
**答**：
- 注水测试：向某子应用注入长任务（mock 大计算），断言主应用交互仍在预算内（INP）。
- 内存泄漏检测：反复 mount/unmount 子应用 N 次，堆快照对比（无持续增长）。
- 加载互相影响：子 A 大 bundle 下载时不阻塞子 B 首屏（并行加载断言）。
- 指标采集：每个子应用独立上报 Web Vitals，按子应用维度看板归因。

```javascript
test('长任务不影响主应用', async ({ page }) => {
  await page.goto('/main');
  await page.evaluate(() => window.__subApp('heavy').runHeavyTask());
  const inp = await page.evaluate(() => window.__metrics.inp);
  expect(inp).toBeLessThan(200);                    // 主应用仍流畅
});
```
