## TST-640：收束题：三句话讲清大规模测试体系的核心挑战

**答**：
- 结论：规模问题的本质是「反馈速度 × 结果可信 × 资源成本」的三角权衡。
- 第一句讲分层与增量解决速度；第二句讲缓存幂等与血缘解决可信；第三句讲容量规划与降级解决成本。
- 收尾用一个数字证明：万级用例从 90 分钟优化到 8 分钟，逃逸率反而下降。
- 追问钩子：如果只能优化一个维度来打破三角，你选哪个？

```javascript
const summary = {
  speed: { lever: '分层+增量+并行', metric: '90min -> 8min' },
  trust: { lever: '缓存幂等+血缘+归因', metric: '误报率 12% -> 3%' },
  cost: { lever: '容量规划+降级', metric: 'CI 成本 -40%' },
};
console.log(Object.entries(summary).map(([k, v]) => `${k}: ${v.lever}`).join('\n'));
```
