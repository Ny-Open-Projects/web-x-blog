## TST-657：性能测试与安全测试如何协同？

**答**：
- 结论：两类测试共用「真实流量录制 + 受控注入」的基础设施，只是断言目标不同。
- 性能退化可能暴露安全问题：超长响应体、无限重试放大攻击面；安全加固（加密/校验）也会带来性能成本。
- 在 CI 中合并采集：一次运行同时输出性能预算与安全规则的判定。
- 追问钩子：为了性能关掉了 CSP 的 report-only，你怎么评估这个取舍？

```javascript
function combinedGate(run) {
  const perf = run.p95 <= run.perfBudget;
  const sec = run.securityFindings.filter(f => f.sev === 'block').length === 0;
  return {
    perf, sec,
    verdict: perf && sec ? 'pass' : 'fail',
    blockers: [
      ...(!perf ? [`p95 超预算 ${run.p95 - run.perfBudget}ms`] : []),
      ...(!sec ? ['存在高危安全告警'] : []),
    ],
  };
}
console.log(combinedGate({ p95: 120, perfBudget: 100,
  securityFindings: [] }).blockers);
```
