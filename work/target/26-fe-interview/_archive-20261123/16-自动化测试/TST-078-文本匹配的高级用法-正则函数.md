## TST-078：getByText 的高级匹配（正则/自定义函数/子串）怎么用？
**答**：
- 三层匹配器：字符串（默认整串精确匹配，忽略首尾空白）、正则（部分匹配，`/已支付/`）、自定义函数（参数 (content, element)，返回 boolean——处理嵌套文案、跨节点文本）。
- 常见坑：文本被拆在多个节点（`<span>¥</span>649`）时 getByText('¥649') 查不到——用函数匹配 element.textContent；数字格式化文案用正则 `/¥1,234\.50/`。
- `{ exact: false }` 开启子串+忽略大小写匹配；匹配范围控制 get多重报错时用 getAllByText 或 within 缩窄。

```jsx
import { render, screen, within } from '@testing-library/react';

render(
  <div>
    <span data-testid="price"><b>¥</b>1,234.50</span>  {/* 文本跨节点 */}
    <p>状态：已支付</p>
  </div>
);

// 正则：部分匹配
expect(screen.getByText(/已支付/)).toBeInTheDocument();
// exact: false：子串 + 忽略大小写
expect(screen.getByText('状态', { exact: false })).toBeInTheDocument();
// 自定义函数：跨节点文本拼接
expect(screen.getByText((_, el) => el?.textContent === '¥1,234.50')).toBeInTheDocument();
// 缩窄范围防 multiple
const price = screen.getByTestId('price');
expect(within(price).getByText((_, el) => el?.textContent.includes('1,234'))).toBeInTheDocument();
```
