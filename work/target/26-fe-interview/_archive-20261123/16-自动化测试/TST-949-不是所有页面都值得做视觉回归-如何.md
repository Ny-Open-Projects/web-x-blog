## TST-949：不是所有页面都值得做视觉回归——如何用「黄金样本」思路选页面？
**答**：
- 结论：选「高频访问 × 高品牌敏感 × 高变化风险」的页面做像素回归，其余用结构断言或快照覆盖，避免视觉测试泛滥。
- 评分模型：对每个页面按流量、品牌曝光、历史缺陷数、改版频率打分，取 Top N 作为黄金样本。
- 动态维护：每季度复盘，新增高价值页面、移除长期无变化且低流量的基线。
- 追问钩子：团队给 500 个页面都上了视觉回归，CI 慢了 10 倍告警还多，你怎么用数据说服缩减到 30 个？

```javascript
function goldenScore(page) {
  return page.traffic * 0.4 + page.brandSensitivity * 0.3 +
    page.pastBugs * 0.2 + page.changeFreq * 0.1;
}
const pages = [
  { name: '首页', traffic: 10, brandSensitivity: 10, pastBugs: 5, changeFreq: 8 },
  { name: '后台设置', traffic: 1, brandSensitivity: 1, pastBugs: 1, changeFreq: 1 },
];
const golden = pages.map(p => ({ name: p.name, score: goldenScore(p) }))
  .sort((a, b) => b.score - a.score)
  .slice(0, 30);
console.log(golden); // 首页入选，后台设置落选
```
