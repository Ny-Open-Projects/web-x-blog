## TST-791：交叉综合：一起涉及平台、性能、AI、混沌的全链路质量事故如何复盘

**答**：
- 结论：复杂事故复盘要「先还原时间线，再分域归因，最后找体系漏洞」——避免单点归因把系统性问题简化为某个人的失误。
- 方法：用故障树把平台（门禁漏过）、性能（容量不足）、AI（误判告警）、混沌（未覆盖该场景）四类因素串成因果链。
- 输出分三层：直接原因、放大因素、体系缺陷（门禁/覆盖/监控为何没挡住）。
- 追问钩子：四个环节都「按流程做了」仍出事，说明体系缺什么？

```javascript
// 事故多域归因：串联因果链
function reconstruct(domainFindings) {
  const chain = domainFindings.filter(f => f.contributed);
  return {
    timeline: chain.map(f => ({ domain: f.domain, at: f.at, what: f.what })),
    rootCause: chain.find(f => f.isRoot)?.what || null,
    amplifiers: chain.filter(f => !f.isRoot).map(f => f.domain),
  };
}
console.log(reconstruct([
  { domain: '平台', at: 1, what: '门禁漏过', contributed: true, isRoot: false },
  { domain: '混沌', at: 2, what: '场景未覆盖', contributed: true, isRoot: true },
]));
```
