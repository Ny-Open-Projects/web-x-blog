## TST-988：笔试：手写「成本-速度帕累托前沿分析器」，找出不被其他方案支配的候选方案
**答**：
- 需求：实现 paretoFront(plans)，plan = { name, cost, duration }（越小越好）。
- 规则：若存在另一方案 cost<=且 duration<= 且至少一个严格更小，则当前方案被支配，剔除；返回未被支配方案列表按 cost 升序。
- 边界：相同 cost/duration 的方案互不支配，全部保留；空数组返回 []。

```javascript
function paretoFront(plans) {
  const front = plans.filter(p =>
    !plans.some(q => q !== p &&
      q.cost <= p.cost && q.duration <= p.duration &&
      (q.cost < p.cost || q.duration < p.duration)));
  return front.sort((a, b) => a.cost - b.cost);
}
const plans = [
  { name: 'A', cost: 10, duration: 100 },
  { name: 'B', cost: 8, duration: 120 },   // cost 更小但更慢 → 不被支配
  { name: 'C', cost: 12, duration: 140 }, // 被 A 支配
  { name: 'D', cost: 5, duration: 200 },  // 更便宜但最慢 → 不被支配
];
console.log(paretoFront(plans).map(p => p.name)); // ['D','B','A']
```
**评分点**：
- 正确识别支配关系：cost/duration 均不劣且至少一项更优才剔除。
- cost 更小但 duration 更大的方案保留（权衡方案）。
- 相同 cost/duration 互不支配，全部保留。
- 输出按 cost 升序，空数组返回 []。
