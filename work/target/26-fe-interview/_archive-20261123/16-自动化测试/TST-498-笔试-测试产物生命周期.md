## TST-498：笔试：测试产物（trace/video）的存储生命周期策略。
**题目**：策略：failed 产物保留 30 天；passed 的 trace 不存；weekly 汇总产物保留 1 年。实现 `lifecycle(artifacts, now)` 输出待删除清单。

```javascript
const TTL = { 'failed-trace': 30, 'failed-video': 30, 'weekly-summary': 365 };
function lifecycle(artifacts, now) {
  const toDelete = artifacts.filter(a => {
    if (a.kind === 'passed-trace') return true;                 // 即删
    const ttl = TTL[a.kind];
    return ttl && now - a.createdAt > ttl * 86_400_000;
  });
  return toDelete.sort((a, b) => b.sizeMB - a.sizeMB).map(a => a.path);
}

```

**评分点**：
- 三类产物不同 TTL。
- 类型 + 创建时间联合判定。
- passed trace 即删（不进生命周期）。
- 待删除按大小排序（优先清大的）。
