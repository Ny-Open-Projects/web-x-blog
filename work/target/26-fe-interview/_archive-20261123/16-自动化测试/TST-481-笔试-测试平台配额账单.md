## TST-481：笔试：测试平台按团队出账（用量统计）。
**题目**：用量 `[{team, minutes, jobs}]` 与单价 `{perMin, perJob}`。输出每团队账单与占比；占比 > 40% 的团队标 dominant（容量治理提示）。

```javascript
function bill(usage, { perMin = 0.01, perJob = 0.5 } = {}) {
  const rows = usage.map(u => {
    const cost = +(u.minutes * perMin + u.jobs * perJob).toFixed(2);
    return { team: u.team, cost, minutes: u.minutes, jobs: u.jobs };
  });
  const total = rows.reduce((s, r) => s + r.cost, 0);
  return rows.map(r => ({ ...r, share: total ? +(r.cost / total).toFixed(2) : 0,
    dominant: total && r.cost / total > 0.4 }));
}
console.log(bill([
  { team: 'a', minutes: 1000, jobs: 20 }, { team: 'b', minutes: 100, jobs: 5 },
])[0].dominant); // true（占比 > 40%）

```

**评分点**：
- 两维计价（时长 + 任务数）。
- 占比计算与 dominant 判定。
- 保留两位小数。
- 空用量容错。
