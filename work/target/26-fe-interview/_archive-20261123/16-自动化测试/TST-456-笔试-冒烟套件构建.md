## TST-456：笔试：从全量用例中构建「冒烟子集」（风险加权抽取）。
**题目**：用例 `[{name, domain, risk}]`（risk: high/mid/low）。规则：所有 high 全收 + 每域至少 1 条 mid + low 抽 10%。输出冒烟清单与预计时长（用例 ms 求和）与预算比对。

```javascript
function buildSmoke(cases, { budgetMs = 300_000, seed = 42 } = {}) {
  let s = seed; const rnd = () => (s = (s * 9301 + 49297) % 233280) / 233280;
  const high = cases.filter(c => c.risk === 'high');
  const byDomain = new Map();
  for (const c of cases.filter(c => c.risk === 'mid'))
    if (!byDomain.has(c.domain)) byDomain.set(c.domain, c);
  const low = cases.filter(c => c.risk === 'low').filter(() => rnd() < 0.1);
  const picked = [...new Map([...high, ...byDomain.values(), ...low].map(c => [c.name, c])).values()];
  const est = picked.reduce((s2, c) => s2 + c.ms, 0);
  return { picked: picked.map(c => c.name), estMs: est, withinBudget: est <= budgetMs };
}

```

**评分点**：
- 规则三层抽取（high 全收/域代表/low 抽样）。
- 抽样确定性（固定 seed）可复现。
- 预计时长与预算比对输出。
- 域分组容错（无 mid 的域取第一条）。
