## TST-473：笔试：按模块关键度设分级覆盖率门槛。
**题目**：模块 `[{path, tier}]`（core ≥ 80 / normal ≥ 60 / tool ≥ 40）。实现 `coverageGate(modules, covMap)`：每模块对照门槛，输出违规清单与整体门槛达成率。

```javascript
const TIERS = { core: 0.8, normal: 0.6, tool: 0.4 };
function coverageGate(modules, covMap) {
  const violations = [];
  for (const m of modules) {
    const cov = covMap[m.path];
    const need = TIERS[m.tier] ?? 0.6;
    if (cov === undefined || cov < need)
      violations.push({ path: m.path, need, actual: cov ?? null,
        why: cov === undefined ? '新增模块零覆盖' : '低于门槛' });
  }
  return { violations, passRate: +( (modules.length - violations.length) / modules.length).toFixed(2) };
}

```

**评分点**：
- 分级阈值表驱动。
- 逐模块比对（违规带实际值）。
- 达成率 = 达标模块数 / 总数。
- 新增模块（无覆盖数据）算违规（不允许零覆盖静默）。
