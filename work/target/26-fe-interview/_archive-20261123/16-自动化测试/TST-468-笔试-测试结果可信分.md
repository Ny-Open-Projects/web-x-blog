## TST-468：笔试：给一次测试运行打「可信分」（环境/样本/历史综合）。
**题目**：因子：环境稳定性（预检通过率）/ 重试率（高=不稳定）/ 历史一致性（与上周通过率偏差）。可信分 = 三因子加权（0-1）。< 0.6 标「结果存疑需复核」。

```javascript
function trustScore({ preflightPassRate, retryRate, historyDeviation }, w = { env: 0.4, retry: 0.3, hist: 0.3 }) {
  const s = preflightPassRate * w.env + (1 - retryRate) * w.retry + (1 - historyDeviation) * w.hist;
  return { score: +s.toFixed(2), factors: { env: preflightPassRate, retry: retryRate, hist: historyDeviation },
    verdict: s < 0.6 ? '结果存疑，建议复核' : '可信' };
}
console.log(trustScore({ preflightPassRate: 1, retryRate: 0.05, historyDeviation: 0.02 }));
// score 0.97 可信

```

**评分点**：
- 三因子定义清晰且归一（0-1）。
- 加权公式与权重可配置。
- 低分触发复核建议（不是硬失败）。
- 各因子分项输出（可解释）。
