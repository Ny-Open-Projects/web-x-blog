## TST-424：笔试：实现测试执行的并发令牌桶（防外部依赖被打挂）。
**题目**：`Limiter(maxPerSec)`：`take()` 返回 promise（获得执行令牌）；按固定窗口限速；任务包裹器 `wrap(fn)`。

```javascript
export function Limiter(maxPerSec) {
  const q = []; let last = 0;
  async function take() {
    const gap = 1000 / maxPerSec;
    const wait = Math.max(0, last + gap - Date.now());
    if (wait) await new Promise(r => setTimeout(r, wait));
    last = Date.now();
  }
  return { async wrap(fn, ...args) { await take(); return fn(...args); }, take };
}
const lim = Limiter(5);          // 每秒最多 5 个请求打后端
const result = await lim.wrap(() => api.call());

```

**评分点**：
- 令牌桶实现（容量 + 速率）。
- take 排队（promise 队列，令牌释放唤醒）。
- wrap 自动 acquire/release。
- 并发上限与速率双约束（简化只做速率，说明取舍）。
