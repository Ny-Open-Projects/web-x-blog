## TST-387：E2E 从 90 分钟优化到 25 分钟的典型优化路径？
**答**：
- 数据准备 API 化（UI 建数据 → 接口直种，省 60%）。
- 受影响子集（全量 → diff 相关 + 夜间全量）。
- 并行度调整（workers×shards 打满 runner）。
- 等待优化（sleep → 条件等待）与复用（登录态 storageState）。
- 每步量化收益，避免盲目优化。

```javascript
const before = { seed: 'UI 8min', suite: '90min', parallel: 4 };
const after = { seed: 'API 40s', scope: 'affected 30min→9min',
                parallel: '4w×4s=16', waits: '条件等待' }; // 总 25min

```
