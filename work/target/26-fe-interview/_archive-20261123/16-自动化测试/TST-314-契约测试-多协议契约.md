## TST-314：REST 之外（GraphQL/gRPC/WebSocket）的契约测试怎么做？
**答**：
- GraphQL：schema 即契约，client 查询用 validate 校验（不被 schema 弃用字段击穿）。
- gRPC：proto 文件即契约，.buf breaking 检测（buf breaking against main）。
- WebSocket：消息 schema + 事件序列契约（握手后先发什么），mock server 按序列回放。
- 统一原则：每种协议都找「机器可校验的 schema 单一事实源」。

```javascript
# gRPC breaking 检测
buf breaking --against '.git#branch=main,path=proto'
# GraphQL client 查询校验
graphql-validate --schema schema.graphql queries/*.graphql
r
```
