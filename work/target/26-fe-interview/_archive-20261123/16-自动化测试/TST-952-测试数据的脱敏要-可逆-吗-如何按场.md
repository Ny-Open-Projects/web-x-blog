## TST-952：测试数据的脱敏要「可逆」吗？如何按场景做脱敏强度分级？
**答**：
- 结论：脱敏分三级——不可逆（哈希/截断，用于展示类测试）、可逆（加密/令牌化，用于需还原的联调）、动态脱敏（按权限实时遮蔽，用于排查）。
- 原则：能不可逆就不逆转，可逆密钥单独托管并审计；测试环境默认不可逆。
- 分级依据：数据敏感度（PII/金融/健康）× 使用目的（功能测试/联调/问题排查）。
- 追问钩子：联调需要真实手机号验证短信通道，但测试环境禁止明文，你怎么设计既合规又能联调的方案？

```javascript
const MASK_LEVELS = {
  irreversible: v => hash(v).slice(0, 8),      // 展示类测试
  reversible:   v => encrypt(v, KEY),          // 联调，可 decrypt 还原
  dynamic:      v => showMaskedByPermission(v),// 排查，按权限遮蔽
};
function mask(value, level = 'irreversible') {
  if (!MASK_LEVELS[level]) throw new Error(`未知脱敏级别 ${level}`);
  return MASK_LEVELS[level](value);
}
function hash(v) { /* crypto.createHash('sha256') */ return 'a1b2c3d4e5f6'; }
function encrypt(v, k) { return `enc:${v.length}`; }
function showMaskedByPermission(v) { return v.replace(/\d(?=\d{4})/g, '*'); }
console.log(mask('13800000000', 'dynamic')); // '*******0000'
```
