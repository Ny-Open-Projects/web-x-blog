## TST-459：笔试：用历史数据预测套件时长（回归均值+变异）。
**题目**：用例 `[{name, history: number[]}]`（各次运行毫秒）。预测 = 中位数；套件预测 = Σ中位数 / 并行度（向上取整余量 10%）。输出预测与置信区间（中位数 ±1 次历史极差/2）。

```javascript
function median(a) {
  const s = [...a].sort((x, y) => x - y);
  return s.length % 2 ? s[(s.length - 1) / 2] : (s[s.length / 2 - 1] + s[s.length / 2]) / 2;
}
function predictSuite(cases, { parallel = 4, defaultMs = 2000 } = {}) {
  const meds = cases.map(c => c.history?.length ? median(c.history) : defaultMs);
  const total = meds.reduce((a, b) => a + b, 0);
  const spread = Math.max(...meds) - Math.min(...meds);
  return { wallMs: Math.ceil(total / parallel * 1.1),
           ci: Math.round(spread / 2 / parallel) };
}
console.log(predictSuite([
  { history: [100, 120, 110] }, { history: [200, 500, 210] },
], { parallel: 2 })); // wall 242ms ±95

```

**评分点**：
- 中位数稳健（不受极值影响）。
- 并行度除法 + 余量（墙钟估算）。
- 置信区间给出（预测不确定度表达）。
- 无历史用例按默认值（可配置）计。
