## TST-785：笔试：实现混沌实验审批的「风险分级准入」决策器

**题目**：输入实验对象 exp {env, userRatio, durationMin, hasRollback} 与策略 policy {maxRatioByEnv:{...}, maxDurationMin, requireRollbackAboveRatio}。计算风险等级：env='prod' 且 userRatio>0.01 为 'high'；userRatio>0.1 或 durationMin>60 为 'medium'；否则 'low'。准入条件：userRatio <= maxRatioByEnv[env]、durationMin <= maxDurationMin、若 userRatio>requireRollbackAboveRatio 则 hasRollback 必须为 true。返回 {level, allowed, reasons:[]}。

**答**：
- 风险分级按条件优先级判定（high 优先于 medium）。
- 三条准入条件逐条收集原因。
- 返回等级与准入结论。

```javascript
function admission(exp, policy) {
  const level = (exp.env === 'prod' && exp.userRatio > 0.01) ? 'high'
    : (exp.userRatio > 0.1 || exp.durationMin > 60) ? 'medium' : 'low';
  const reasons = [];
  if (exp.userRatio > policy.maxRatioByEnv[exp.env]) reasons.push('超出比例上限');
  if (exp.durationMin > policy.maxDurationMin) reasons.push('超出时长上限');
  if (exp.userRatio > policy.requireRollbackAboveRatio && !exp.hasRollback) reasons.push('缺少回滚');
  return { level, allowed: reasons.length === 0, reasons };
}
console.log(admission(
  { env: 'prod', userRatio: 0.05, durationMin: 30, hasRollback: false },
  { maxRatioByEnv: { prod: 0.1 }, maxDurationMin: 60, requireRollbackAboveRatio: 0.01 }
)); // high, 缺少回滚
```

**评分点**：
- 风险分级优先级正确
- 三条准入条件检查齐全
- 原因收集完整
- level 返回正确
