## TST-627：数千工程师规模下，测试权限与审批流怎么设计？

**答**：
- 结论：RBAC 打底 + 风险分级审批——常规测试自助，高危操作（删基线/改门禁）才审批。
- 权限按「团队 × 环境 × 动作」三维建模；流水线用服务账号，不复用个人权限。
- 所有操作审计留痕，支持按 runId 回溯。
- 追问钩子：外包同学需要临时提测权限，你怎么做到「到期自动失效」？

```javascript
const ROLES = {
  dev: ['run:test', 'read:report'],
  lead: ['run:test', 'read:report', 'gate:waive'],
  admin: ['*'],
};
function can(role, action) {
  return (ROLES[role] || []).some(p => p === '*' || p === action);
}
function scoped(team, env, action, grants) {
  return grants.some(g => g.team === team &&
    (g.env === '*' || g.env === env) &&
    (g.actions || []).includes(action));
}
```
