## TST-996：灰度发布过程中（5%→50%→100%）门禁怎么动态变化？
**答**：
- 结论：门禁随灰度阶段递进收紧——低流量阶段看「是否崩溃/核心指标」，中流量看「业务指标 + 异常率」，全量前必须「全量回归 + 人工 go/no-go」。
- 要点：每阶段设「止损阈值」（错误率/延迟/P0 告警），触发即自动回滚；阶段间观察窗口要足够覆盖问题暴露。
- 信号：灰度期的真实指标反哺门禁模型，比预发环境更可信。
- 追问钩子：5% 灰度一切正常，但放大到 50% 后某个下游接口被压垮，门禁怎么提前预见这种「容量型」问题？

```javascript
const CANARY_STAGES = [
  { pct: 5, gates: ['无 P0 崩溃', '错误率<1%'], observeMin: 10 },
  { pct: 50, gates: ['业务指标不劣化', '下游 QPS 在容量内'], observeMin: 30 },
  { pct: 100, gates: ['全量回归通过', '人工 go/no-go'], observeMin: 0 },
];
function canaryGate(stageIdx, metrics) {
  const stage = CANARY_STAGES[stageIdx];
  failures = stage.gates.filter(g =>
    /错误率/.test(g) && metrics.errorRate >= 0.01);
  return { pct: stage.pct, pass: failures.length === 0, failures,
    next: failures.length ? 'rollback' : 'promote' };
}
let failures = [];
console.log(canaryGate(0, { errorRate: 0.02 }).next); // 'rollback'
```
