## TST-487：笔试：单文件用例过多的拆分建议（按时长与域）。
**题目**：用例 `[{name, ms, domain}]` 同文件。规则：总时长 > 5min 或域 ≥ 3 → 建议按域拆文件；输出每组（域）的用例数与时长，新文件命名建议。

```javascript
function splitAdvice(cases, { maxMs = 300_000 } = {}) {
  const total = cases.reduce((s, c) => s + c.ms, 0);
  const domains = [...new Set(cases.map(c => c.domain))];
  if (total <= maxMs && domains.length < 3)
    return { keep: true, total, domains: domains.length };
  const groups = {};
  for (const c of cases) {
    groups[c.domain] ??= { count: 0, ms: 0 };
    groups[c.domain].count++; groups[c.domain].ms += c.ms;
  }
  return { keep: false, groups: Object.fromEntries(Object.entries(groups)
    .map(([d, g]) => [d, { ...g, file: `spec-${d}.spec.ts` }])) };
}

```

**评分点**：
- 拆分触发条件（时长/域数）。
- 按域分组统计。
- 新文件命名规则（file-domain.spec）。
- 不满足条件输出 keep。
