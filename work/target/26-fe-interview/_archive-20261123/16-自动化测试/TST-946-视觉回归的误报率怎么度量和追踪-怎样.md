## TST-946：视觉回归的误报率怎么度量和追踪？怎样证明治理有成效？
**答**：
- 结论：建立「视觉告警台账」——每条告警标注 real/false 与根因，按周统计误报率、按根因分布，用趋势曲线证明治理成效。
- 指标：误报率 = 误报数 / 总告警数；MTTD（平均确认时间）；治理前后同口径对比。
- 闭环：误报根因自动回写分类器规则，下一轮同类误报自动抑制。
- 追问钩子：你上线了字体统一方案，怎么向老板证明「误报率从 70% 降到 15%」不是因为大家懒得报了？

```javascript
const ledger = [
  { week: 'W1', total: 40, false: 28, real: 12 },
  { week: 'W2', total: 38, false: 6,  real: 32 }, // 治理后，总量相近但误报骤降
];
function report(l) {
  return l.map(x => ({
    week: x.week,
    fpRate: +(x.false / x.total * 100).toFixed(1) + '%',
    realCount: x.real,
  }));
}
console.log(report(ledger));
// [{W1,fpRate:'70%',real:12},{W2,fpRate:'15.8%',real:32}]
// 关键佐证：总量相近（40→38）且 real 上升（12→32），说明不是「懒得报」
```
