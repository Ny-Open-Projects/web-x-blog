## TST-295：数据工厂如何与 API 契约（OpenAPI）联动防过期？
**答**：
- 工厂类型从 schema 生成（openapi-typescript），接口改字段工厂编译期报错。
- 必填字段缺失在工厂 build 时运行时校验（schema validate），不让坏数据进测试。
- 契约变更 → 工厂同步更新 → 全量用例跑通后才合入。
- 工厂版本与 API 版本对齐发布（monorepo 同仓天然对齐）。

```javascript
import type { components } from './api-schema.d.ts';
export const buildGoods = (v: Partial<components['schemas']['Goods']>): Goods =>
  GoodsSchema.parse({ ...defaults, ...v });     // 运行时校验 + 编译期类型
```
