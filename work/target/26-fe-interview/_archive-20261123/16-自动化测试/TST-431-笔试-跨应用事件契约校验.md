## TST-431：笔试：微应用间自定义事件（EventBus）的契约校验器。
**题目**：契约 `{event: {payloadSchema, direction: 'pub'|'sub'}}`。实现 `validateEvent(name, payload, side)`：事件名注册检查/方向匹配（pub 方只能 pub）/payload 校验。

```javascript
const EVENT_CONTRACT = {
  'order.paid': { payloadSchema: { orderId: 'string', amount: 'number' }, direction: 'pub' },
};
function validateEvent(name, payload, side) {
  const c = EVENT_CONTRACT[name];
  if (!c) return { ok: false, error: `未注册事件: ${name}` };
  if (side !== c.direction) return { ok: false, error: `${side} 方不允许 ${c.direction} 事件 ${name}` };
  const errors = Object.entries(c.payloadSchema)
    .filter(([k, t]) => typeof payload?.[k] !== t)
    .map(([k, t]) => `payload.${k} 应为 ${t}`);
  return { ok: errors.length === 0, errors };
}
console.log(validateEvent('order.paid', { orderId: '1', amount: 'x' }, 'pub').errors);
// ['payload.amount 应为 number']

```

**评分点**：
- 事件名注册表检查（未注册即违契约）。
- 方向校验（应用角色 vs 事件方向）。
- payload schema 校验（类型逐字段）。
- 错误输出带事件名与字段。
