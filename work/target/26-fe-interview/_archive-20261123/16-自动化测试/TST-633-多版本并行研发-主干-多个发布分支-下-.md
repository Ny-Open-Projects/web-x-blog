## TST-633：多版本并行研发（主干 + 多个发布分支）下，测试资源怎么分配？

**答**：
- 结论：按「分支风险 × 截止时间」分配——主干要快反馈，发布分支要稳覆盖。
- 主干跑增量 + 冒烟，发布分支跑全量回归；紧急分支可抢占配额。
- 同一 commit 在多分支复用结果，避免重复跑。
- 追问钩子：三个发布分支同一天截止，资源不够时你怎么排？

```javascript
function allocate(branches, capacity) {
  const scored = branches.map(b => ({
    name: b.name,
    urgency: b.risk * (1 / Math.max(1, b.daysLeft)),
  })).sort((a, b) => b.urgency - a.urgency);
  const total = scored.reduce((s, b) => s + b.urgency, 0) || 1;
  return scored.map(b => ({ name: b.name,
    slots: Math.max(1, Math.round(b.urgency / total * capacity)) }));
}
console.log(allocate([{ name: 'main', risk: 5, daysLeft: 1 },
  { name: 'rel-1', risk: 8, daysLeft: 3 }], 10));
```
