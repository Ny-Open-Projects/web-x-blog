## TST-338：测试失败的告警如何降噪（避免告警疲劳）？
**答**：
- 分级路由：主干阻塞 → 即时告警；夜间全量失败 → 日报聚合；flaky 隔离区 → 周报。
- 去重聚合：同一用例短窗多次失败合并一条（带次数）。
- 已知问题静默：登记的已知故障（环境维修中）静默期。
- 可操作性：每条告警带「立即行动」（重跑链接/trace 链接/owner）。

```javascript
const alertPolicy = {
  main: { channel: 'im', dedupe: '5min', action: 'retry-link + trace' },
  nightly: { channel: 'daily-digest' },
  quarantine: { channel: 'weekly' },
  knownIssues: { silence: 'env-maintenance window' },
};
```
