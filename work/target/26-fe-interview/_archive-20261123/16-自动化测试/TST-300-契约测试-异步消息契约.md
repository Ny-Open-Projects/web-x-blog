## TST-300：异步消息（MQ/事件）的契约测试怎么做？
**答**：
- 消息契约：消费者声明「期望的事件 schema 与语义版本」，提供者发布前验证消息体满足。
- schema registry（JSON Schema/Avro）为单一事实源，producer/consumer 各自校验。
- 兼容模式：schema 演进用 backward-compatible 规则校验（registry 内置检查）。
- 测试层级：schema 校验（快）+ 语义测试（消费逻辑对消息的处理）。

```javascript
// consumer 侧 schema 校验测试
const ev = JSON.parse(kafkaMessage);
const schema = await registry.get('order.paid@v2');
expect(ajv.compile(schema)(ev)).toBe(true);
// 语义测试：消费逻辑对 v2 消息正确入账

```
