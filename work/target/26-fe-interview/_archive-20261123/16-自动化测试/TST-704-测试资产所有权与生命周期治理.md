## TST-704：组织级测试平台里测试资产的所有权与生命周期怎么治理

**答**：
- 结论：每条用例/夹具/数据集必须有明确 owner 与生命周期状态（草案→稳定→Deprecated→归档），无主资产平台有权自动归档。
- 所有权绑定到团队而非个人，避免离职造成 orphan；用 CODEOWNERS 类似的机制自动指派。
- 生命周期靠策略驱动：连续 N 天未运行或长期失败无人认领，自动降级并通知。
- 追问钩子：业务线合并重组后大量用例 owner 失效，如何批量再分配又不破坏历史统计？

```javascript
// 资产生命周期状态机
const TRANSITIONS = {
  draft: ['stable', 'archived'],
  stable: ['deprecated'],
  deprecated: ['stable', 'archived'],
  archived: [],
};
function transition(asset, to, daysIdle) {
  if (!TRANSITIONS[asset.status].includes(to)) return { ok: false, reason: '非法流转' };
  if (to === 'archived' && daysIdle < 30) return { ok: false, reason: '未满 30 天冷静期' };
  return { ok: true, next: { ...asset, status: to } };
}
console.log(transition({ status: 'stable', owner: 'teamA' }, 'deprecated', 0).ok); // true
console.log(transition({ status: 'archived' }, 'stable', 0).ok); // false
```
