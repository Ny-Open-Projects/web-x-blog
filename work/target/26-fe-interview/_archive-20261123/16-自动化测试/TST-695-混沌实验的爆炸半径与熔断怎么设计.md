## TST-695：混沌实验的爆炸半径与熔断怎么设计？

**答**：
- 结论：爆炸半径用「用户分桶 × 功能开关 × 时长」三重限制，熔断用稳态指标越界自动触发。
- 分桶用稳定 hash（userId % 1000），保证同一用户不会反复被注入。
- 熔断后不仅停止注入，还要清理已注入的本地状态并刷新页面。
- 追问钩子：熔断后还有用户处于故障态（缓存了脏数据），怎么处理？

```javascript
function inBucket(userId, percent, salt = '') {
  const h = [...`${salt}${userId}`].reduce((a, c) => (a * 31 + c.charCodeAt(0)) >>> 0, 7);
  return h % 1000 < percent * 10;
}
function breaker(metrics, rules) {
  const trip = Object.entries(rules).some(([k, max]) => (metrics[k] || 0) > max);
  return { trip, action: trip ? 'abort-and-clean' : 'continue' };
}
```
