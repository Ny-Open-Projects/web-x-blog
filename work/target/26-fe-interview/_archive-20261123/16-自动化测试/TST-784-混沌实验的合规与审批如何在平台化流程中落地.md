## TST-784：混沌实验的「合规与审批」如何在平台化流程中落地

**答**：
- 结论：审批要「分级 + 自动化 + 留痕」——按风险等级走不同审批流，低风险自动放行并记录，高风险走多人审批。
- 平台把审批嵌入实验创建流程：未审批无法进入执行阶段，从流程上杜绝绕过。
- 全量留痕：谁申请、谁审批、影响范围、执行结果，满足审计与事后复盘。
- 追问钩子：紧急故障排查需要临时注入但来不及走审批，怎么办？

```javascript
// 风险分级审批流
function approvalFlow(risk) {
  if (risk === 'low') return { approvers: [], auto: true };
  if (risk === 'medium') return { approvers: ['team-lead'], auto: false };
  return { approvers: ['team-lead', 'sre', 'oncall'], auto: false };
}
function canExecute(flow, approvals) {
  return flow.approvers.every(a => approvals.includes(a));
}
const f = approvalFlow('high');
console.log(canExecute(f, ['team-lead', 'sre'])); // false，缺 oncall
```
