## TST-363：并发正确性（竞态/幂等）的测试手段有哪些？
**答**：
- 确定性并发模拟：可控调度器（手动推进 promise）模拟交错执行。
- 压力并发：真实并发 N 请求验证幂等（重复提交只成一单）。
- 时序注入：mock 网络延迟差异制造竞态窗口。
- 不变量断言：并发后聚合不变量（库存总和不变/无重复单）。

```javascript
test('并发提交幂等', async () => {
  const results = await Promise.allSettled(
    Array.from({ length: 10 }, () => submitOrder(payload)));
  const ok = results.filter(r => r.status === 'fulfilled' && r.value.success);
  expect(await countOrders(payload.idempotencyKey)).toBe(1);  // 只成一单
});
```
