## TST-286：性能回归测试的频率与范围如何分级？
**答**：
- PR 级：受影响页面的 Lighthouse + 体积门禁（快，< 5 分钟）。
- 日级：全关键页 + 长任务/内存专项（夜间）。
- 周级：全量性能套件 + 低端机仿真 + 弱网场景。
- 发布级：灰度期间 RUM 实时对比，劣化自动回滚触发评审。

```javascript
const cadence = {
  pr: ['affected-pages lighthouse', 'size-limit'],
  daily: ['all-key-pages', 'longtask', 'memory'],
  weekly: ['low-end-emu', 'slow-3g-scenarios'],
  release: ['RUM live compare → auto-rollback review'],
};

```
