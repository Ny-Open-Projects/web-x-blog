## TST-253：微前端（qiankun/wujie）应用的测试如何验证「样式与 JS 隔离」？
**答**：
- 样式隔离测试：子应用加载后主应用样式不受影响（关键选择器计算样式断言）。
- 全局变量污染检测：子应用 mount/unmount 前后 window 上新增键对比（应还原）。
- 沙箱行为：子应用对 window/document 的修改在卸载后撤销（Proxy 沙箱断言）。
- 测试方式：集成测试环境跑主+子应用，Playwright 断言跨应用边界行为。

```javascript
test('卸载后无全局污染', async ({ page }) => {
  await page.goto('/main');
  const before = await page.evaluate(() => Object.keys(window).length);
  await page.evaluate(() => window.__mountSubApp());
  await page.evaluate(() => window.__unmountSubApp());
  const after = await page.evaluate(() => Object.keys(window).length);
  expect(after).toBe(before);                       // 沙箱还原
});
```
