## TST-694：生产环境做前端混沌，怎么控制风险？

**答**：
- 结论：三道保险——用户分桶（先 0.1%）、一键熔断、实时稳态监控；缺一不可上生产。
- 时间段选低峰，注入时长设上限（如 5 分钟自动结束）。
- 提前公告并对受影响用户提供补偿；建立明确的 Go/No-Go 决策人。
- 追问钩子：实验中途发现影响面超预期，你按什么顺序止损？

```javascript
function canRunProduction(exp, { metrics } = {}) {
  const guards = [
    exp.radius <= 0.001,
    exp.hasKillSwitch,
    exp.maxDurationMin <= 5,
    !!exp.owner,
    metrics.errorRate < 0.01,
  ];
  return { go: guards.every(Boolean), failed: guards.map((ok, i) =>
    ok ? null : ['radius', 'killswitch', 'duration', 'owner', 'errorRate'][i])
    .filter(Boolean) };
}
```
