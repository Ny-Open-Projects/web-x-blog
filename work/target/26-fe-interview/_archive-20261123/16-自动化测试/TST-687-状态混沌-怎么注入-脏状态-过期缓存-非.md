## TST-687：状态混沌：怎么注入「脏状态」（过期缓存 / 非法持久化数据）测试容错？

**答**：
- 结论：前端容错常被忽视的点是「本地状态比后端更脏」——要主动注入过期缓存、非法 JSON、越界值。
- 手段：篡改 localStorage/sessionStorage/IndexedDB 与内存 store，模拟版本升级后的旧数据格式。
- 断言：应用能识别脏数据、走默认值或降级、不白屏。
- 追问钩子：旧版本缓存的字段在新版本被删了，你怎么保证不炸？

```javascript
function injectDirtyState(keys, { corrupt = 0.3 } = {}) {
  const backup = {};
  keys.forEach(k => {
    backup[k] = localStorage.getItem(k);
    const r = Math.random();
    if (r < corrupt) localStorage.setItem(k, '{bad json');
    else if (r < corrupt * 2) localStorage.setItem(k, 'null');
    else localStorage.setItem(k, JSON.stringify({ version: -1 }));
  });
  return () => Object.entries(backup).forEach(([k, v]) =>
    v == null ? localStorage.removeItem(k) : localStorage.setItem(k, v));
}
```
