## TST-285：RUM（真实用户指标）如何反哺性能回归？
**答**：
- RUM 数据（INP/LCP p75）按页面/版本聚合，发布后对比基线，劣化即告警。
- RUM 发现的慢页面回流进实验室测试清单（专项复现优化）。
- 实验室与 RUM 的差异解释（实验室测不到的地区/低端机）——RUM 权重更高。
- 回归责任归因：版本号打标，劣化定位到发布版本与变更 PR。

```javascript
// RUM 聚合看板查询
const report = await rum.query({
  metric: 'INP', page: '/checkout',
  groupBy: 'release', compare: 'previous',
  threshold: { p75: 200, alertDelta: 0.15 },   // 劣化 15% 告警
});
```
