## TST-610：测试工具「自研还是采购」，架构师的决策框架是什么？

**答**：
- 结论：先看现成方案能否满足 80% 需求；差异化能力是否构成核心竞争力，再谈自研。
- TCO 对比要算全周期：采购=许可+集成+升级；自研=人力+维护+机会成本。
- 可逆性优先：采购怕供应商锁定，自研怕人员流失，两者都要留退出通道。
- 追问钩子：采购后仍要写大量适配层，这算不算另一种形式的自研？

```javascript
function buildVsBuy(need, years = 3) {
  const buy = need.license * years + need.integration + need.upgrade * years;
  const build = need.devMonths * need.monthlyCost
    + need.maintainPerYear * years;
  const core = need.isCoreCompetency;
  return {
    buy, build,
    suggest: core && build < buy * 1.3 ? 'build' : 'buy',
    exitCost: core ? build * 0.4 : buy * 0.25,
  };
}
console.log(buildVsBuy({ license: 20, integration: 10, upgrade: 5,
  devMonths: 4, monthlyCost: 8, maintainPerYear: 6, isCoreCompetency: false }));
```
