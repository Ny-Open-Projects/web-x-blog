## TST-486：笔试：失败用例的证据链打包（截图/trace/日志关联）。
**题目**：证据 `[{kind: 'shot'|'trace'|'log', path, ts}]`。打包规则：失败时间 ±5s 内的证据关联；trace 全量关联；按关联时间排序输出 manifest。

```javascript
function evidenceBundle(evidence, failedAt, { windowMs = 5000 } = {}) {
  const related = evidence.filter(e =>
    e.kind === 'trace' || Math.abs(e.ts - failedAt) <= windowMs);
  related.sort((a, b) => a.ts - b.ts);
  return { manifest: related.map(e => e.path),
    note: `${related.length} 项证据（trace 全量 + 窗口内 ${related.filter(e => e.kind !== 'trace').length} 项）` };
}

```

**评分点**：
- 时间窗关联（±5s）。
- trace 例外（总是关联）。
- manifest 排序（时间序）。
- 输出 zip 清单（路径列表）。
