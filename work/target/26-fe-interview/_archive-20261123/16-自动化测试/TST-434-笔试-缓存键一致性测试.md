## TST-434：笔试：SSR 缓存键生成函数的等价类测试。
**题目**：缓存键 `cacheKey(url, {vary: [headers]})`。测试同 URL 不同 vary 头生成不同键、无关头不影响键、键稳定（同输入同输出）。实现 `sameKey/crossKey` 断言辅助。

```javascript
export function cacheKey(url, varyHeaders) {
  const parts = Object.keys(varyHeaders).sort()
    .map(k => `${k}=${varyHeaders[k]}`);
  return `${url}?${parts.join('&')}`;
}
const sameKey = (k1, k2) => expect(k1).toBe(k2);
test('vary 头顺序无关', () => {
  sameKey(cacheKey('/p', { 'x-a': '1', 'x-b': '2' }),
          cacheKey('/p', { 'x-b': '2', 'x-a': '1' }));
});
test('无关头不影响', () => {
  expect(cacheKey('/p', { 'x-a': '1' })).toBe(cacheKey('/p', {}));
});

```

**评分点**：
- vary 头集合参与键（排序归一——头顺序无关）。
- 无关头不影响（键不含）。
- 稳定性断言（两次调用同键）。
- 辅助断言函数输出可读差异。
