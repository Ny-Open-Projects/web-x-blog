## TST-699：混沌实验的度量与报告怎么做？

**答**：
- 结论：报告三件事——稳态是否守住、发现了什么弱点、自愈耗时多少。
- 指标：实验覆盖率（关键链路注入占比）、弱点发现数、修复闭环率、MTTR 改善。
- 每次实验生成可复盘的时间线（注入→异常→告警→止损→恢复）。
- 追问钩子：实验没发现任何弱点，是好事还是测试设计有问题？

```javascript
function chaosReport(exp, timeline) {
  const t = timeline;
  return {
    steady: t.every(p => p.metric >= exp.baseline * 0.95),
    findings: t.filter(p => p.type === 'weakness').map(p => p.desc),
    mttrMs: (t.find(p => p.type === 'recovered')?.ts || 0)
      - (t.find(p => p.type === 'injected')?.ts || 0),
    closedRate: +(exp.weaknessesClosed / Math.max(1, exp.weaknessesFound))
      .toFixed(2),
  };
}
```
