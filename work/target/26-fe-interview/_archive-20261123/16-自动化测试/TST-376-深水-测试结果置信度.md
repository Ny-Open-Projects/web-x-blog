## TST-376：单次测试通过/失败的「置信度」概念（如何不迷信单次结果）？
**答**：
- 通过 ≠ 没问题：覆盖不足/环境差异/时间不敏感都可能漏报。
- 提升置信：关键用例多次执行（采样）/环境矩阵扩展/变异测试验证断言力。
- 失败分类置信：确定性失败（复现 100%）vs 间歇失败——处理优先级不同。
- 决策表述：报告输出「置信级别」（如：3 次采样通过 + 变异分数 75% = high confidence）。

```javascript
const confidence = (c) => ({
  runs: c.samples,            // 3 次采样
  mutationScore: c.mutation,  // 断言力
  level: c.samples >= 3 && c.mutation > 0.7 ? 'high' : 'medium',
});
```
