## TST-730：性能与安全测试在 CI 中的「分层门禁」怎么设计

**答**：
- 结论：分层门禁按「反馈速度 vs 严格度」权衡——快反馈层（秒级）做静态安全扫描与包体积，慢层（分钟级）做性能回归与深度安全扫描。
- 每层有独立 SLA 与阈值，快层卡提交、慢层卡发布，避免把所有检查堆在发布前。
- 门禁要可降级：资源紧张时保留高优先级检查，低优先级转异步。
- 追问钩子：慢层门禁让发布从 5 分钟变 30 分钟，如何优化而不丢质量？

```javascript
// 分层门禁编排
function ciGates(stage) {
  const layers = {
    commit: [{ n: '依赖审计', ms: 3000 }, { n: '包体积', ms: 5000 }],
    mr: [{ n: '静态安全', ms: 20000 }, { n: '单测', ms: 60000 }],
    release: [{ n: '性能回归', ms: 300000 }, { n: '深度扫描', ms: 200000 }],
  };
  return (layers[stage] || []).map(l => l.n);
}
console.log(ciGates('commit')); // ['依赖审计','包体积']
console.log(ciGates('release')); // ['性能回归','深度扫描']
```
