## TST-396：测试工作外包/跨团队协作的边界与质量保障？
**答**：
- 外包适用：明确边界的工作（用例编写按 AC/手工执行/兼容性矩阵）。
- 不外包：测试策略/架构/自动化核心（组织能力不能外流）。
- 质量保障：外包产出过同一门禁（AI 生成测试同样标准）+ 抽样复核。
- 交接机制：文档/培训/轮岗过渡，防知识断档。

```javascript
const outsource = {
  ok: ['AC-driven 用例编写', '兼容性矩阵执行', '数据准备'],
  not: ['策略', '自动化架构', '门禁设计'],
  quality: '同一门禁 + 10% 抽样复核',
};
```
