## TST-397：让测试体系「反脆弱」（故障让体系变强）的机制？
**答**：
- 每次逃逸缺陷/重大 flaky 都产出「体系改进项」（不是只修个案）。
- 根因库持续扩充：新根因类别 → 标准修法 → 批量治理。
- 混沌思维：定期主动注入不稳定（慢依赖/数据冲突）验证体系韧性。
- 复盘文化：失败案例库全员可见（去敏），失败是被鼓励暴露的。

```javascript
const antifragile = {
  incidentToSystem: 'escape → gap-item → 批量补测',
  chaosDrill: '季度注入不稳定验证韧性',
  culture: '失败案例库公开（去敏）+ 暴露受奖励',
};
```
