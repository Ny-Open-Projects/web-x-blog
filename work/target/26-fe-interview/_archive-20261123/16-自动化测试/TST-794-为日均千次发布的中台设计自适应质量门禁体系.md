## TST-794：综合设计：为日均千次发布的中台设计「自适应质量门禁」体系

**答**：
- 结论：千次发布下门禁必须「按风险自适应」——高风险变更走严格门禁，低风险走轻量快检，避免一刀切成为瓶颈。
- 三层：提交前（秒级静态检查）、MR（按风险选测 + 增量覆盖）、发布（契约/性能/安全），每层有独立 SLA。
- 自适应依据：变更风险分、文件热度、历史缺陷、业务等级；门禁阈值随风险动态调整但保留硬底线。
- 追问钩子：自适应门禁被开发「调优」成永远低风险，如何防作弊？

```javascript
// 自适应门禁：按风险选层级
function adaptiveGate(change) {
  const risk = change.hotspot * 0.4 + change.bugDensity * 0.3 +
               change.bizLevel * 0.2 + change.depImpact * 0.1;
  const level = risk > 0.7 ? 'strict' : risk > 0.4 ? 'normal' : 'light';
  const gates = {
    light: ['lint', 'unit'],
    normal: ['lint', 'unit', 'contract', 'incremental-cov'],
    strict: ['lint', 'unit', 'contract', 'incremental-cov', 'perf', 'security'],
  };
  return { risk: +risk.toFixed(2), level, gates: gates[level] };
}
console.log(adaptiveGate({ hotspot: 0.9, bugDensity: 0.8, bizLevel: 1, depImpact: 0.5 }));
```
