## TST-624：跨地域测试结果的聚合与时钟偏差怎么校正？

**答**：
- 结论：调度可以就近，但聚合必须统一时间基准——所有分片结果换算到 UTC 后按 runId 归并。
- 偏差来自机器时钟不同步与跨时区展示，用 NTP 漂移量 + 显式 timeZone 字段双校正。
- 聚合幂等：同一用例重复上报按最大 seq 覆盖，避免重试造成重复计数。
- 追问钩子：两个地域同一用例结果相反，怎么判断是地域差异还是 flaky？

```javascript
function normalize(results, drift, tzOffsets = {}) {
  const normTs = r => r.ts + (drift[r.region] || 0)
    + (tzOffsets[r.region] || 0);
  const byCase = new Map();
  results.forEach(r => {
    const key = `${r.runId}|${r.caseId}`;
    const prev = byCase.get(key);
    if (!prev || r.seq > prev.seq || normTs(r) > normTs(prev))
      byCase.set(key, { ...r, utcTs: normTs(r) });
  });
  return [...byCase.values()];
}
```
