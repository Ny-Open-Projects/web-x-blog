## TST-638：海量测试资产如何检索与复用？

**答**：
- 结论：给每个用例打「能力标签 + 语义向量」双索引，关键字找精确的、向量找相似的。
- 复用前先做「适配检查」：依赖、环境、断言是否匹配当前上下文。
- 建立用例市场，展示复用次数与维护人，让资产可发现可治理。
- 追问钩子：向量检索召回了一堆「看起来像」的用例，怎么用重排提升精度？

```javascript
function retrieve(query, index, topK = 5) {
  const scored = index.map(item => ({
    item,
    kw: (item.tags || []).filter(t => query.includes(t)).length,
    vec: cosine(query.vec, item.vec),
  }));
  return scored.sort((a, b) =>
    (b.kw * 2 + b.vec) - (a.kw * 2 + a.vec)).slice(0, topK);
}
function cosine(a, b) {
  const dot = a.reduce((s, v, i) => s + v * b[i], 0);
  return dot / (Math.hypot(...a) * Math.hypot(...b) || 1);
}
```
