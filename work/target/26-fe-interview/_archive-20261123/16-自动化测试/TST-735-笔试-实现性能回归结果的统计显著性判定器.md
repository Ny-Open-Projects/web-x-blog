## TST-735：笔试：实现性能回归结果的「统计显著性」判定器（多次采样）

**题目**：输入基线样本 base 与当前样本 cur（均为数值数组），阈值阈值 threshold（如 0.1 表示 10% 恶化）。判定是否显著回归：两组的均值差异超过 threshold * base均值，且当前样本的最小值大于基线样本的最大值（完全分离，简化版显著性）。返回 {regressed, baseMean, curMean}。

**答**：
- 先算两组均值，差异比例判定阈值。
- 完全分离条件（curMin > baseMax）作为简化显著性，避免分布重叠误判。
- 两条件同时满足才判回归。

```javascript
function mean(a) { return a.reduce((s, x) => s + x, 0) / (a.length || 1); }
function isSignificantRegression(base, cur, threshold) {
  const bm = mean(base), cm = mean(cur);
  const diffRatio = (cm - bm) / (bm || 1);
  const separated = Math.min(...cur) > Math.max(...base);
  return {
    regressed: diffRatio > threshold && separated,
    baseMean: +bm.toFixed(1),
    curMean: +cm.toFixed(1),
  };
}
console.log(isSignificantRegression([1000, 1010, 990], [1300, 1320, 1280], 0.1));
// regressed:true
console.log(isSignificantRegression([1000, 1010, 990], [1050, 900, 1100], 0.1));
```

**评分点**：
- 均值差异比例判定正确
- 完全分离条件判定正确
- 两条件同时满足才回归
- 空数组兜底
