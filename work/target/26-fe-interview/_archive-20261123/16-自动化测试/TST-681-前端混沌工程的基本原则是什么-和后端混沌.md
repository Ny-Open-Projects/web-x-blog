## TST-681：前端混沌工程的基本原则是什么（和后端混沌有何不同）？

**答**：
- 结论：前端混沌的核心是「用户稳态」——后端看服务指标，前端看交互可用性与渲染正确性。
- 四原则：先定义稳态假设、小爆炸半径、可一键回滚、在受控环境先行。
- 差异点：前端状态在浏览器本地，故障注入要处理页面刷新与登录态重建。
- 追问钩子：注入故障后页面没崩但按钮点不动，算不算稳态被破坏？

```javascript
const PRINCIPLES = {
  steady: '关键交互可完成（登录/下单/支付）',
  radius: '按用户分桶，先 1% 灰度',
  rollback: '开关注入 + 页面刷新即恢复',
  env: '先预发再生产',
};
function guard(experiment) {
  return experiment.radius <= 0.01 && experiment.hasKillSwitch
    && !!experiment.steadyState;
}
```
