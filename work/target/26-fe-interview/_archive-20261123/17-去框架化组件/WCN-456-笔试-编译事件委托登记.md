## WCN-456：笔试：实现编译期事件绑定到「委托回调表」。
**题目**：输入节点树 `[{tag, events: {click: handlerName}}]`。产物：真实 addEventListener 只在根一次（委托）；编译期把 {node, event, handler} 登记进回调表；运行时按 e.target 匹配节点。

```javascript
const table = new WeakMap();
function register(node, event, handler) {
  const m = table.get(node) ?? {};
  m[event] = handler;
  table.set(node, m);
}
root.addEventListener('click', (e) => {
  let el = e.target;
  while (el && el !== root) {
    const h = table.get(el)?.click;
    if (h) { h(e); return; }        // 最近节点优先
    el = el.parentElement;
  }
});

```

**评分点**：
- 回调表结构（WeakMap node → {event: handler}）。
- 根级委托一次（监听数 O(1)）。
- target 匹配（closest 语义）。
- 动态节点登记/注销（增删时维护表）。
