## WCN-293：「文档驱动」的元素开发流程（docs 先行）？
**答**：
- 先写文档草案（API 用例/交互规格/a11y 要求）→ 评审 → 实现 → 文档演示即测试（play fn）。
- 文档即测试：demo 代码可直接跑（Storybook/tests），文档与实现永不脱节。
- 设计评审：设计师在文档站标注视觉规格 → token 化落实现。
- 验收闭环：PR 引用文档条目（覆盖哪些用例），未覆盖条目显式列出。

```javascript
// 文档 demo 即测试
export const Primary = { args: { variant: 'primary' },
  play: async ({ canvas }) => {
    await expect(canvas.getByRole('button')).toHaveStyle({ background: 'var(--ds-primary)' });
  } };
```
