## WCN-482：笔试：实现元素 a11y 自动基线检查（role/aria/键盘断言生成）。
**题目**：输入元素声明 `[{tag, role, aria: {expanded?...}, keys: ['Enter', 'Escape']}]`。生成检查代码：getByRole 断言 + 键盘流逐键断言骨架。

```javascript
function genA11yTests(decl) {
  const lines = [`expect(screen.getByRole('${decl.role}')).toBeInTheDocument();`];
  for (const [k, v] of Object.entries(decl.aria || {}))
    lines.push(`expect(el).toHaveAttribute('aria-${k}', '${v}');`);
  for (const key of decl.keys || [])
    lines.push(`await user.keyboard('${key}'); // 断言相应行为`);
  if (!decl.keys?.length) lines.push('// WARN: 交互元素未声明键盘流');
  return lines;
}
console.log(genA11yTests({ tag: 'ds-menu', role: 'menu',
  aria: { expanded: 'false' }, keys: ['ArrowDown', 'Escape'] }).length); // 4

```

**评分点**：
- 声明 → 断言代码生成（同源）。
- role/aria 逐项断言。
- 键盘流逐键断言骨架。
- 遗漏检测（交互元素无 keys 声明 → 告警）。
