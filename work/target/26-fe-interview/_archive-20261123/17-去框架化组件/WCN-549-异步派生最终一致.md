## WCN-549：信号应用的「竞态与一致性」：多个异步源写同一派生信号时如何保证最终一致？

**答**：
- 结论：用「版本号 + 取消令牌」双重防护——每次新请求递增版本并取消旧请求，只接受最新版本的结果。
- 写操作带 epoch，computed 结果附带 epoch；Epoch 落后直接丢弃。
- 聚合类场景（多个源都要等）用 allSettled + 版本校验，避免部分失败导致中间态。
- 追问：用户快速切换筛选条件时如何避免闪烁？（答：保留旧结果直到新结果就绪，再原子替换）

```javascript
function asyncDerived(fetcher, source) {
  const state = signal({ status: 'idle', value: null });
  let epoch = 0, ctrl = null;
  source.subscribe(async params => {
    const my = ++epoch; ctrl?.abort(); ctrl = new AbortController();
    state.set(s => ({ ...s, status: 'loading' }));           // 保留旧值避免闪烁
    try { const v = await fetcher(params, ctrl.signal);
      if (my === epoch) state.set({ status: 'success', value: v });
    } catch (e) { if (my === epoch && e.name !== 'AbortError') state.set({ status: 'error', error: e }); }
  });
  return state;
}
```
