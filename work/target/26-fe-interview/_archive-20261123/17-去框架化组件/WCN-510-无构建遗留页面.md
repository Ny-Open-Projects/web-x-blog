## WCN-510：企业内 WCN 组件如何在「无构建工具」的遗留页面（纯 script 标签）中安全使用？

**答**：
- 结论：提供 IIFE/UMD 产物，暴露全局命名空间（如 window.DS）， script 引入即 define。
- 避免裸 ESM import（遗留环境无 importmap），用动态 script 注入并带 onload 竞态保护。
- 样式用 adoptedStyleSheets 内联，不依赖外链构建；token 用 CSS 变量从 script 注入。
- 追问：遗留页面 CSP 不允许 inline script 怎么办？（答：外链 nonce script + 预置全局变量）

```javascript
(function (global) {
  const DS = global.DS || (global.DS = {});
  DS.whenReady = (tag) => customElements.whenDefined(tag);
  DS.reg = (tag, C) => { if (!customElements.get(tag)) customElements.define(tag, C); };
  // 组件类内部用 adoptedStyleSheets，零外链依赖
})(window);
// 页面：<script src="https://cdn/ds/v3/all.js" nonce="..."></script>

// 竞态：script onload 前调用需排队
```
