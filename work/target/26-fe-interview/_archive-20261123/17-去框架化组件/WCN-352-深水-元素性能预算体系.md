## WCN-352：元素库的性能预算体系（每元素限额）？
**答**：
- 预算维度：chunk 体积（≤8KB gzip）/mount 时长（≤5ms）/内存（每实例 ≤50KB）/样式体积。
- CI 门禁：超预算 block，豁免需说明（复杂组件白名单）。
- 回归追踪：每版本性能快照对比（劣化 > 15% 告警）。
- 预算协商：确需超预算 → 性能 owner 审批 + 记录（预算是架构决策）。

```javascript
# per-element budget
budgets:
  ds-button: { gzip: 3, mountMs: 2 }
  ds-table:  { gzip: 12, mountMs: 8, exempt-note: "虚拟滚动复杂" }
r
```
