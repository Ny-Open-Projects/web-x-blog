## WCN-657：编译器的「静态提升（hoistStatic）」与事件缓存分别解决什么问题？

**答**：
- 结论：静态提升把不变的节点/属性提到 render 函数外，避免每次渲染重建；事件缓存把内联 handler 缓存，避免每次生成新函数导致子组件无谓更新。
- 机制：编译期分析节点是否含动态绑定，纯静态则提升为模块级常量；事件 handler 用 cache 数组缓存引用。
- 追问钩子：为什么内联函数会导致子组件重渲染？因为引用变化——考察对「引用相等性影响更新」的理解。

```javascript
// 提升前：每次 render 都新建静态节点
function renderBefore() {
  return h('div', null, h('p', null, '静态文字')); // 每次新建
}
// 提升后：静态节点提到模块级
const HOISTED_P = h('p', null, '静态文字');
function renderAfter(handlers) {
  return h('div', null, [HOISTED_P, h('button', {
    onClick: handlers.cache[0] || (handlers.cache[0] = () => handlers.click()),
  })]);
}
// 事件缓存：同一 handler 引用稳定，子组件不会被无谓更新
```
