## WCN-503：从 0 到 100% 全量，如何设计「宿主页面 × 用户分桶」的灰度放量矩阵？

**答**：
- 结论：二维放量——页面维度（低风险页先放）+ 用户维度（hash 分桶），交叉命中才生效。
- 分桶用稳定 hash(uid + salt) % 100，保证同一用户每次命中一致，避免抖动。
- 放量阶段表：内部账号 → 1% → 10% → 50% → 100%，每阶段观察 ds-error 与性能阈值。
- 追问：灰度中某页面指标劣化如何单独熔断？（答：页面维度开关置 0，用户桶不变）

```javascript
function bucket(uid, salt, total = 100) {
  let h = 2166136261;
  for (const ch of `${salt}:${uid}`) { h ^= ch.charCodeAt(0); h = Math.imul(h, 16777619); }
  return (h >>> 0) % total;
}
function inGray(uid, page, conf) {
  if (!conf.pages[page]) return false;              // 页面维度门禁
  return bucket(uid, conf.salt) < conf.pages[page];  // 用户分桶
}
const conf = { salt: 'v3', pages: { 'home': 10, 'detail': 1, 'pay': 0 } };
```
