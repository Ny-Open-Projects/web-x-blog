## WCN-381：元素状态的持久化（localStorage/IndexedDB）协议设计？
**答**：
- 声明式：元素标注 persistable 字段清单（哪些 property 持久化），统一序列化器处理。
- 命名空间：存储 key = 元素 tag + 实例 id（防多实例冲突）。
- 版本：持久化 schema 版本，恢复时迁移（老数据不崩）。
- 敏感字段排除（token/密码不持久化）——持久化白名单制。

```javascript
DsTable.persist = ['pageSize', 'sortState', 'columnWidths'];   // 白名单
// key: ds-table:{instanceId}  schema v2 → 恢复时 migrate

```
