## WCN-989：压力题：「你们这套去框架化到底带来了什么业务价值」怎么量化回答

**答**：
- 结论先行：回答要用「业务语言 + 可验证数据」，不说「技术先进」——围绕「更快上线、更省成本、更稳体验、更合规」四个可量化维度。
- 效率：跨端复用率（一套组件覆盖 N 个框架/端）、需求交付周期缩短百分比、重复造轮子的组件数下降。
- 成本：维护人力下降（修一次全端生效）、体积/带宽节省、第三方许可或自建重复投入减少。
- 体验与风险：首屏 LCP/水合耗时改善、线上 a11y 合规通过率、跨框架一致性缺陷数下降、灰度回滚成功率。
- 追问钩子：面试官追问「怎么归因是去框架化的功劳」——答：用对照（迁移前后同口径指标 + 未迁移模块作对照组），控制变量说明趋势，坦承局限而非夸大。

```javascript
// 价值度量看板（示意数据聚合）
function valueReport(m) {
  return {
    efficiency: `跨端复用率 ${(m.reuseRate*100).toFixed(0)}%，交付周期 -${m.cycleDrop}%`,
    cost: `维护人力 -${m.headcountDrop}%，带宽 -${m.bandwidthDrop}%`,
    experience: `LCP -${m.lcpDrop}ms，a11y 通过率 ${m.a11yPass}%`,
    stability: `跨框架一致性缺陷 -${m.consistencyBugDrop}%`,
  };
}
console.log(valueReport({ reuseRate:0.8, cycleDrop:30, headcountDrop:25,
  bandwidthDrop:18, lcpDrop:400, a11yPass:98, consistencyBugDrop:60 }));
```
