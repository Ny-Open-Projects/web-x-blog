## WCN-208：自定义元素库大版本升级时，多框架宿主的共存迁移策略？
**答**：
- 双版本共存：customElements.define 同名冲突——用新标签名（goods-card-v2）过渡。
- 适配包版本对齐：@ds/react@3 对应 elements@3，宿主按矩阵升级。
- 元素行为回归套件独立于框架宿主（纯元素测试），宿主冒烟验证桥接层。
- 弃用周期：旧标签至少一个大版本内仍注册（deprecation 日志）。

```javascript
// 共存注册
customElements.define('goods-card', GoodsCardV1);      // legacy
customElements.define('goods-card-v2', GoodsCardV2);   // 过渡
// 路由级渐进替换，迁移完成后 v1 注册删除
r
```
