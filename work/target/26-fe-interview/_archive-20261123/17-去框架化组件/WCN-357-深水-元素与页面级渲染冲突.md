## WCN-357：元素 shadow 样式与宿主页面全局样式冲突的排障？
**答**：
- 隔离面：shadow 隔离「元素内部」，但元素占位（host）受外部影响（display/margin 继承）。
- 常见冲突：全局 * 选择器（box-sizing/line-height）影响 host——元素 :host 显式声明防御。
- 排障工具：computed style 双向对比（外部影响 vs shadow 内值）。
- 规范：:host { all: initial } 太重——按属性白名单防御（display/box-sizing/margin）。

```javascript
:host {
  display: block;
  box-sizing: border-box;
  margin: 0;               /* 防外部 margin 穿透 */
  font: inherit;           /* 显式选择继承项 */
}
```
