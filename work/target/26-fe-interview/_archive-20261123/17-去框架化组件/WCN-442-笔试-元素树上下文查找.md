## WCN-442：笔试：实现 context lookup（composedPath 查 provider）的完整实现。
**题目**：provider 元素暴露 ctx 对象；`lookup(el, key)`：派发不可冒泡探测事件，沿 composedPath 找含 key 的祖先；缓存查找结果（结构不变时）；未找到报错。

```javascript
function lookup(el, key) {
  const probe = new Event('_dsctx', { composed: true, bubbles: false });
  el.dispatchEvent(probe);
  const path = probe.composedPath ? [] : [];  // composedPath 通过事件对象获取
  // 实现：监听器在 window 捕获并回填 path
  let found = null;
  for (const n of window.__lastPath ?? []) {
    if (n[key] !== undefined) { found = n[key]; break; }
  }
  if (!found) throw new Error(`context ${key} 未找到（查找链见 _dsctx）`);
  return found;
}
// window.addEventListener('_dsctx', e => window.__lastPath = e.composedPath(), true);

```

**评分点**：
- composedPath 穿透 shadow 的原理应用。
- 探测事件（bubbles: false 也能拿到 path？——需 composed true 捕获路径）说明实现细节。
- 缓存失效（disconnect/重挂）。
- 错误信息含查找链。
