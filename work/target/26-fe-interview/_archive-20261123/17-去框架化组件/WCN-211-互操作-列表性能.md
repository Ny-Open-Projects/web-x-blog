## WCN-211：大列表场景（1000+ 自定义元素）的性能问题与对策？
**答**：
- 问题：每元素独立 Shadow Root 构造 + 样式实例化，内存与挂载开销远大于框架组件。
- 对策 1：虚拟滚动（只挂可视区元素）——首选。
- 对策 2：元素复用（对象池）：滚动回收元素重设 property 而非销毁重建。
- 对策 3：shadowroot Declarative + 共享 styleSheet（constructable styles 全局一份）。
- 度量：滚动帧率（FPS）与内存（反复滚动不增长）。

```javascript
const sheet = new CSSStyleSheet();
sheet.replaceSync(`.price { color: var(--ds-price); }`);   // 全局一份
class GoodsCard extends HTMLElement {
  constructor() { super(); this.shadowRoot!.adoptedStyleSheets = [sheet]; }  // 共享
}
```
