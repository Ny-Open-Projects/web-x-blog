## WCN-600：设计系统平台化「终局答辩」：用 3 分钟讲清从工具库到设计资产中台的演进与价值量化。

**答**：
- 结论：按「痛点 → 演进 → 基建 → 度量 → 展望」五段式，3 分钟讲清平台化的必要性、路径与收益。
- 痛点：重复造轮子、设计实现不一致、无治理；演进：工具库 → 平台 → 中台三阶段。
- 度量用硬指标：采用率、代码删除量、缺陷下降率、ROI；展望是 AI 辅助与标准化收敛。
- 追问：面试官追问「为什么不直接用 Antd」？（答：跨框架/多品牌/Design Token 治理是中台诉求，通用库解决不了）

```javascript
const PITCH = {
  pain: ['重复造轮子', '设计实现 drift', '无治理'],
  evolution: ['工具库(复用)', '组件平台(自助)', '资产中台(治理)'],
  infra: ['token 管线', '文档站', 'CI 门禁', '资产市场'],
  metrics: ['采用率', '代码删除量', '缺陷下降率', 'ROI'],
  future: ['AI 辅助生成/审查', 'TC39 标准化收敛'],
};
function threeMinute() {
  return Object.entries(PITCH).map(([k, v]) => `${k}: ${v.join(' / ')}`).join('\n');
}
```
