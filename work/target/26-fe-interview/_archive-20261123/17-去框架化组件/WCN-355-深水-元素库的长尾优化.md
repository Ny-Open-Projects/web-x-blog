## WCN-355：元素库的「长尾优化」（低频组件的维护决策）？
**答**：
- 使用数据驱动：零使用/极低频组件进入「候选冻结」名单（只修 bug 不加功能）。
- 冻结期满（两个版本）仍零使用 → 下线（deprecation 周期）。
- 反向信号：业务「想要但没用上」——可能是可用性问题（文档/API）而非真不需要。
- 决策记录：下线决策带数据证据 + 替代方案。

```javascript
const review = usageStats.filter(c => c.monthlyUses < 5)
  .map(c => ({ ...c, action: 'freeze-or-retire' }));
// 冻结两版本 → retire（附替代方案）
r
```
