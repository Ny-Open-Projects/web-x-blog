## WCN-343：元素处理敏感数据（表单/令牌）的安全设计？
**答**：
- 敏感值不走 attribute（可被 DOM 泄漏/序列化）——property + 不 reflect。
- 元素内部状态不暴露 debug 方法于生产构建（构建时剔除 _debugState）。
- CSP：元素内联样式经 nonce 策略（DSD 内联 style 需 CSP style-src 兼容）。
- 审计：敏感字段标注清单 + 泄漏扫描（DOM 快照扫描敏感模式）。

```javascript
set token(v) { this._token = v; }   // 不 reflect，不出现在 attribute/DOM
// CSP: style-src 'self' 'nonce-xxx'（DSD 内联样式需处理）
r
```
