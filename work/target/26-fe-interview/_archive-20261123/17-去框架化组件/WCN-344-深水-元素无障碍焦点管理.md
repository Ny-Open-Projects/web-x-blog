## WCN-344：Shadow DOM 内焦点管理的深水（焦点顺序/焦点丢失恢复）？
**答**：
- shadow 内可聚焦元素参与全局 Tab 序（按文档序插入）——顺序符合直觉但验证复杂。
- 动态内容（列表更新）导致焦点元素移除 → 焦点跳 body：需「焦点恢复」协议（记 lastFocused，重渲染后恢复）。
- delegatesFocus：宿主聚焦元素时自动转内部首焦点（元素声明）。
- 陷阱：slot 内容的焦点（light DOM 元素在 shadow 前后）——APG 用例覆盖。

```javascript
class DsDialog extends HTMLElement {
  static delegatesFocus = true;   // 外部 focus() 直达内部
  #lastFocused: Element | null = null;
  focusin(e) { this.#lastFocused = e.target; }
  restoreFocus() { (this.#lastFocused as HTMLElement)?.focus?.(); }
}
```
