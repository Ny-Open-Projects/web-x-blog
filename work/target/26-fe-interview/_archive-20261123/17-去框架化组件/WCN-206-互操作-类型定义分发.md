## WCN-206：自定义元素如何给多框架使用者提供类型？
**答**：
- 元素类型用 CustomElementDeclarations 扩展（declare global JSX.IntrinsicElements / Vue ComponentCustomProperties）。
- 提供框架专属类型包（@ds/react、@ds/vue 的 .d.ts），从同一元素定义生成。
- 事件类型：CustomEvent<T> 泛型化 detail，桥接层签名精确。
- 版本策略：类型包跟随元素库版本，破坏性变更走 major。

```javascript
// React 类型扩展
declare module 'react' {
  namespace JSX {
    interface IntrinsicElements {
      'goods-card': React.DetailedHTMLProps<React.HTMLAttributes<HTMLElement> & {
        sku: string; count?: number;
        'on-add-cart'?: (e: CustomEvent<{ sku: string }>) => void;
      }, HTMLElement>;
    }
  }
}
```
