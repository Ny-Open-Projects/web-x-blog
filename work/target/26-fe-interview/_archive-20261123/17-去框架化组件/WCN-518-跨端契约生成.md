## WCN-518：跨端一致性：Web / 小程序 / React Native 三端如何用一份元素契约生成各端实现骨架？

**答**：
- 结论：用平台无关的 JSON Schema 描述元素（props/events/slots），再由各端 codegen 生成符合本端习惯的骨架。
- Web 生成 Custom Element 类，小程序生成 Component 配置，RN 生成函数组件 + TS 类型。
- 事件/属性命名在 Schema 层统一，生成时做端名映射（如 onClick → bindtap / onPress）。
- 追问：三端样式差异如何表达？（答：Schema 里放语义 token 引用，各端映射到本端样式系统）

```javascript
const schema = {
  name: 'ds-button',
  props: [{ name: 'disabled', type: 'boolean' }, { name: 'variant', type: 'string' }],
  events: [{ name: 'press', payload: { value: 'string' } }],
};
function genWeb(s) { return `class ${s.name} extends HTMLElement { /* ${s.props.map(p=>p.name)} */ }`; }
function genMini(s) { return `Component({ properties: ${JSON.stringify(Object.fromEntries(s.props.map(p=>[p.name,{type:p.type}])))}, methods:{} })`; }
function genRN(s) { return `function ${s.name}(p){ return <TouchableOpacity onPress={p.onPress}/> }`; }

// 事件名映射保证三端语义一致，业务层无需感知平台差异
const events = schema.events.map(e => EVENT_MAP[platform](e.name));
```
