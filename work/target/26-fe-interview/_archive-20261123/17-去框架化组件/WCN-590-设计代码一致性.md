## WCN-590：设计系统「设计-代码一致性」自动化：如何做设计稿与线上组件的视觉回归 + 差异归因？

**答**：
- 结论：用视觉回归工具（如 Playwright + pixelmatch）比对设计稿基准图与线上截图，像素 diff 后归因到具体元素与 token。
- 基准图来自设计稿导出的组件快照，线上截图由 Storybook 固定状态生成。
- 差异归因：diff 区域映射到 DOM 元素，比对计算样式找出不同的 CSS 变量（token）。
- 追问：抗锯齿/字体差异导致噪声怎么办？（答：设 diff 阈值 + 忽略字体渲染区域 + 固定测试环境字体）

```javascript
async function visualRegression(page, baselinePath) {
  const shot = await page.screenshot();
  const diff = pixelmatch(baseline, shot, { threshold: 0.1 });
  if (diff.ratio < 0.001) return { pass: true };
  const region = diff.bbox;
  const el = await page.evaluate(box => document.elementFromPoint(box.x, box.y), region);
  const vars = await page.evaluate(e => getComputedStyle(e).getPropertyValue('--ds-color'), el);
  return { pass: false, region, element: el.tagName, suspectToken: vars };
}
```
