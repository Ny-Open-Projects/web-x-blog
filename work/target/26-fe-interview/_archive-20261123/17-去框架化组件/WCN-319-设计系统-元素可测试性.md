## WCN-319：元素的可测试性设计（依赖注入/时钟/网络）？
**答**：
- 依赖注入：数据获取函数可注入（property dataProvider 或静态配置）——测试注入 fake。
- 时钟：元素内部时间逻辑走可注入 clock（测试冻结）。
- 网络：统一经元素库封装的 http 通道（可全局 mock），禁止散落 fetch。
- 可测性 lint：扫描元素源码直连 window.fetch/Date.now 的违规。

```javascript
class GoodsCard extends HTMLElement {
  static dataProvider = defaultFetch;      // 可注入
  async load() { this._data = await GoodsCard.dataProvider(this.sku, { clock: DsClock.now }); }
}
```
