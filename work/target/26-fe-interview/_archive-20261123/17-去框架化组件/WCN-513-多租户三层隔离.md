## WCN-513：多租户 SaaS：同一元素库服务不同租户时，如何做「样式主题 + 数据权限 + 功能开关」三层隔离？

**答**：
- 结论：三层都用「上下文 provider 注入」，元素内部只读 context，不直接依赖租户全局状态。
- 样式层：租户 id → 主题 CSS 变量集合挂到根节点，元素通过 var() 继承。
- 数据/权限层：元素声明所需权限位，context 提供 hasPerm()，无权限则降级渲染或隐藏。
- 追问：租户 A 的元素里嵌了租户 B 的插件如何隔离 context？（答：子 provider 覆盖，composedPath 就近查找）

```javascript
const TENANT_CTX = Symbol('tenant');
function provideTenant(el, ctx) { el[TENANT_CTX] = ctx; }
function useTenant(el) {
  return (el.getRootNode().host || el).closest?.('[data-tenant]')?.[TENANT_CTX] || defaultCtx;
}
// 元素内部：读 context，不读全局
const ctx = useTenant(this);
this.style.setProperty('--brand', ctx.theme.brand);
if (!ctx.hasPerm('pay.show')) this.hidden = true;
```
