## WCN-233：元素实现代码的代码分割策略（多元素共享依赖）？
**答**：
- 公共依赖（图标/工具）独立 chunk，元素实现引用共享 chunk（避免每元素内联复制）。
- 路由级预取：高概率页面预加载对应元素 chunk（链表预测）。
- define 与实现分离：轻量「存根定义」先注册占位，实现 chunk 到达后替换行为（hydrate stub）。
- 预算：单元素 chunk < 8KB gzip，共享 chunk 全局审计（防意外膨胀）。

```javascript
// stub 定义：先注册占位
class Stub extends HTMLElement { connectedCallback() { enqueueHydrate(this); } }
customElements.define('goods-card', Stub);
// chunk 到达后升级
import('./goods-card-impl').then(({ GoodsCard }) => {
  customElements.upgrade && hydrateStubs('goods-card', GoodsCard);
});
```
