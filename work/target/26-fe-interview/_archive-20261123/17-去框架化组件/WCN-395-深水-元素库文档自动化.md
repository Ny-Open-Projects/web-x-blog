## WCN-395：文档与代码同源的自动化管线（类型→文档→demo→测试）？
**答**：
- 类型定义 → API 表自动生成（property/事件/slot/方法）。
- demo 从「用例注册表」生成（每个 API 用例一个 demo + 对应测试）。
- 变更联动：类型 diff → 文档 diff 预览（PR 内可见文档影响）。
- 验证：文档 demo 全量跑（CI），文档过期（API 改未更新文档）阻断。

```javascript
// 管线：types → apiTable → demos → tests（同源）
expect(docApiTable).toEqual(generateApiTable(types));  // 文档过期即红

```
