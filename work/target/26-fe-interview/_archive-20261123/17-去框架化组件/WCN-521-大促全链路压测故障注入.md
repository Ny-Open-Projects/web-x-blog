## WCN-521：大促演练：元素库「全链路压测」如何注入故障（chunk 超时 / 注册失败 / 渲染异常）？

**答**：
- 结论：在加载/注册/渲染三阶段埋故障注入点，通过开关按元素/比例注入，验证降级链是否生效。
- chunk 超时：代理层延迟响应；注册失败：define 抛错；渲染异常：connectedCallback 内抛错。
- 验收标准：任一故障下页面仍可交互（兜底组件），且 ds-error 上报可观测。
- 追问：如何避免演练影响真实用户？（答：仅对演练账号/固定分桶生效，开关独立）

```javascript
const FAULT = { chunkDelay: 0, defineFail: false, renderThrow: false, scope: 'drill-only' };
async function loadWithFault(url) {
  if (FAULT.chunkDelay) await new Promise(r => setTimeout(r, FAULT.chunkDelay));
  if (isDrillUser() && FAULT.scope === 'drill-only') return load(url);
  return load(url);
}
function defineWithFault(tag, Cls) {
  if (FAULT.defineFail && isDrillUser()) throw new Error('inject define fail');
  customElements.define(tag, Cls);
}
```
