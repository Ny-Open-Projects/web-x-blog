## WCN-584：设计平台「组件市场」：如何做元素的搜索、评分、采用率排行与 deprecation 提示？

**答**：
- 结论：市场数据由「静态元数据（API/文档）+ 动态数据（采用率/健康分/引用趋势）」聚合而成。
- 搜索支持 tag/能力/token 多维过滤；评分 = 健康分 × 采用广度 + 用户反馈。
- deprecation：被标记的元素在文档站/IDE 提示替代方案与迁移截止时间。
- 追问：如何防止「低质组件靠运营冲榜」？（答：排行榜以健康分为门槛，采用率只作加权因子）

```javascript
function rank(assets, usage) {
  return assets.map(a => {
    const u = usage[a.id] || { repos: 0, trend: 0 };
    const score = a.health * 0.5 + Math.log1p(u.repos) * 10 + u.trend * 5;
    return { ...a, score, badge: a.deprecated ? 'deprecated' : a.health >= 80 ? 'recommended' : 'normal' };
  }).sort((a, b) => (a.deprecated - b.deprecated) || (b.score - a.score));
}

// 搜索支持 tag/能力/token 多维过滤
function search(q) { return index.filter(a => a.tags.includes(q) || a.tokens.includes(q)); }
```
