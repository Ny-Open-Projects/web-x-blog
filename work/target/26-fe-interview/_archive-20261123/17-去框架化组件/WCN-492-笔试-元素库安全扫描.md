## WCN-492：笔试：实现元素源码安全扫描（innerHTML/反序列化/postMessage）。
**题目**：规则：innerHTML 赋值非转义调用 → 阻断；JSON.parse 输入未经 schema 校验 → 警告；postMessage 无 origin 校验 → 阻断。输出违规清单（行级）。

```javascript
const SEC_RULES = [
  { re: /innerHTML\s*=\s*(?!\s*(?:escapeHtml|DOMPurify))/, level: 'block', kind: 'xss' },
  { re: /JSON\.parse\((?!.*schema)/, level: 'warn', kind: 'unsafe-deserialize' },
  { re: /addEventListener\(['"]message['"]\)(?![\s\S]*origin)/, level: 'block', kind: 'postmessage-origin' },
];
function secScan(code) {
  return code.split('\n').map((line, i) => ({ line, n: i + 1 }))
    .filter(({ line }) => SEC_RULES.some(r => r.re.test(line)))
    .map(({ line, n }) => { const r = SEC_RULES.find(r => r.re.test(line));
      return { line: n, level: r.level, kind: r.kind, text: line.trim().slice(0, 60) }; });
}

```

**评分点**：
- 三类规则正则实现。
- 转义调用白名单（escapeHtml/DOMPurify 前缀）。
- 级别（block/warn）输出。
- 行号定位。
