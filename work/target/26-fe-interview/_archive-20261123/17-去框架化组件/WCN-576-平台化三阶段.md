## WCN-576：设计系统「平台化」三阶段：工具库 → 组件平台 → 设计资产中台，各阶段组织与基建差异是什么？

**答**：
- 结论：三阶段本质是从「交付代码」到「交付能力」再到「交付资产治理」的跃迁。
- 工具库：解决复用，基建是打包/发布，组织是少数维护者。
- 组件平台：解决自助消费，基建是文档站/token 管线/CI 门禁，组织设 Design Engineer 桥接设计工程。
- 追问：中台阶段新增什么？（答：资产市场、质量度量、准入治理、跨 BU 协同 SLA）

```javascript
const STAGES = {
  library: { infra: ['build', 'npm publish'], org: '核心维护者', metric: '组件数' },
  platform: { infra: ['docs', 'token管线', 'CI门禁'], org: 'Design Engineer', metric: '采用率' },
  midplatform: { infra: ['资产市场', '质量分', '准入治理'], org: '平台组+BU自治', metric: 'ROI/健康度' },
};
function stageOf(org) { return org.includes('自治') ? 'midplatform' : org.includes('Engineer') ? 'platform' : 'library'; }

// 阶段跃迁的驱动力：复用诉求 → 自助诉求 → 治理诉求
const nextStage = { library: 'platform', platform: 'midplatform' };
```
