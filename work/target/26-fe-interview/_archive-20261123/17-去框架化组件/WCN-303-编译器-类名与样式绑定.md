## WCN-303：编译器处理动态 class/style 的策略（合并/拆分）？
**答**：
- 静态 class 保留在模板，动态部分独立绑定（classList.add/remove 或 style.setProperty）。
- 对象/数组语法编译为逐项绑定（每 key 一个 effect）——精确到属性级。
- 字符串拼接表达式（`a ${b()}`）：编译为「静态前缀 + 动态片段」——只更新变化片段。
- 性能收益：单属性变化不重写整个 class 字符串。

```javascript
<div class={clsx('base', cond() && 'on', color() && `c-${color()}`)} />
// 编译产物：
n.classList.add('base');
createEffect(() => n.classList.toggle('on', !!cond()));
createEffect(() => n.style.setProperty('--c', color() || ''));

```
