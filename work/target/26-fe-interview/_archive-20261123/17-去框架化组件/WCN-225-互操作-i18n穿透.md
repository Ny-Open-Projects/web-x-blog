## WCN-225：国际化文案在自定义元素中的注入方案？
**答**：
- 方案 1：文案作为 attribute/property 传入（元素无 i18n 依赖，宿主全权管理）——最纯粹。
- 方案 2：全局 i18n 协议（window.__DS_I18N__ t 函数注入），元素内部调用——方便但耦合全局。
- 推荐方案 1 + 元素库提供宿主适配 hook（React/Vue 各一行接入）。
- 语言切换：property 更新触发元素重渲染；切换时序与框架 hydration 对齐。

```javascript
// React 适配
function useT() { const { t } = useI18n(); return t; }
<goods-card add-text={t('cart.add')} empty-text={t('cart.empty')} />
// 元素内部只消费字符串 props，切换语言 = props 更新 = 重渲染

```
