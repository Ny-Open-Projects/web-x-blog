## WCN-596：设计系统「性能预算平台化」：如何把体积/性能预算做成发布门禁 + 趋势看板？

**答**：
- 结论：为每个元素设体积/性能上限，CI 构建后校验超预算则阻断；历史数据入趋势看板预警劣化。
- 预算项：单元素 gzip 体积、首屏 JS 总量、CLS/LCP 贡献、信号图规模。
- 门禁：超预算 5% 内警告，超 20% 阻断；趋势看板按版本展示曲线。
- 追问：预算怎么定才合理？（答：基于基线版本 + 业务容忍度，逐元素分配总量）

```javascript
const BUDGET = { 'ds-button': 2, 'ds-table': 15 };  // KB gzip
function checkBudget(stats, budget = BUDGET) {
  const results = [];
  for (const [tag, kb] of Object.entries(stats)) {
    const max = budget[tag] || 10;
    const over = kb / max - 1;
    results.push({ tag, kb, max, level: over > 0.2 ? 'block' : over > 0.05 ? 'warn' : 'ok' });
  }
  return { results, blocked: results.some(r => r.level === 'block') };
}
```
