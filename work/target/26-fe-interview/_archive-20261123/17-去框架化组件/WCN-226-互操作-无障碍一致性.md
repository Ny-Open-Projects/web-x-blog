## WCN-226：同一元素在不同框架宿主下 a11y 表现一致的保障？
**答**：
- a11y 语义内聚在元素内部（role/aria/焦点管理）——框架侧只管「放哪里」，不管语义。
- 焦点陷阱等复杂行为元素内实现（如 Dialog focus trap），宿主零参与。
- 回归：元素 a11y 测试独立跑（不依赖框架），宿主集成只做「可达性冒烟」。
- 外部标签关联：aria-labelledby 指向宿主元素时，用 id 引用（跨 shadow 需 id 全局唯一约定）。

```javascript
// 元素内聚焦点管理
class DsDialog extends HTMLElement {
  connectedCallback() { this._trap = trapFocus(this.shadowRoot); }
  disconnectedCallback() { this._trap.release(); }
  // 宿主（任何框架）无需处理焦点
}
```
