## WCN-437：笔试：实现元素的多主题快照对比（light/dark 语义 diff）。
**题目**：对同一元素分别在 root 加 light/dark 类，取 computed style 关键属性（背景/文字/边框），断言「dark 值 ≠ light 值（有差异化）」且「都来自 token（无裸值）」。

```javascript
function themeDiff(el, props = ['backgroundColor', 'color', 'borderColor']) {
  const get = () => Object.fromEntries(props.map(p =>
    [p, getComputedStyle(el.shadowRoot.firstElementChild)[p]]));
  document.documentElement.classList.remove('dark');
  const light = get();
  document.documentElement.classList.add('dark');
  const dark = get();
  const unchanged = props.filter(p => light[p] === dark[p]);
  return { unchanged,
    warn: unchanged.length ? `dark 未差异化: ${unchanged}` : 'ok' };
}

```

**评分点**：
- 双主题切换 → computed style 采样。
- 差异化断言（dark === light 即漏配 dark token）。
- 来源校验（值可追溯到 token 变量）。
- 输出差异清单（哪些属性在 dark 下未变化）。
