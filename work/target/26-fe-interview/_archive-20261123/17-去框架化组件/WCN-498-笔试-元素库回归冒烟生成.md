## WCN-498：笔试：实现升级回归的冒烟清单生成（受影响元素 → 宿主页面映射）。
**题目**：输入升级元素清单与「页面 → 使用元素」映射。输出：需回归的页面清单（按使用元素数排序）与预计冒烟时长。

```javascript
function regressionPlan(upgradedTags, pageMap, { perPageMin = 2 } = {}) {
  const impacted = Object.entries(pageMap)
    .map(([page, tags]) => ({ page, hits: tags.filter(t => upgradedTags.includes(t)).length }))
    .filter(x => x.hits > 0)
    .sort((a, b) => b.hits - a.hits);
  return { pages: impacted.map(x => x.page),
    estMin: impacted.length * perPageMin,
    fallback: '夜间全量兜底' };
}

```

**评分点**：
- 页面 → 元素反向映射。
- 受影响页面排序（使用多者先）。
- 预计时长（每页固定值 + 数量加权）。
- 全量兜底说明（夜间）。
