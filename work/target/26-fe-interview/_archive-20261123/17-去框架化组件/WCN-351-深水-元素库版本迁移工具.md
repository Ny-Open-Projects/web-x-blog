## WCN-351：元素库大版本升级的 codemod 工具设计？
**答**：
- 映射表驱动：旧 API → 新 API（属性重命名/事件改名/标签迁移）。
- 覆盖面：HTML/JSX/Vue 模板/文档站点全格式扫描替换。
- 交互式确认：歧义迁移（多候选）标记人工决策。
- 验证：迁移后宿主冒烟 + 视觉 diff（token 层面应无变化）。

```javascript
ds-codemod v4-to-v5 \
  --rename-prop num:count \
  --rename-event add-cart:cart-added \
  --tag goods-card-v2:goods-card
# 输出：已迁移 42 处，3 处歧义待人工
r
```
