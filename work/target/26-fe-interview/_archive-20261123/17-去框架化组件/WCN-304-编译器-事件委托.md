## WCN-304：编译器/元素库的事件委托策略（减少监听数）？
**答**：
- 运行时库在 shadow 根统一委托（click/input 按 target 定位回调表）。
- 编译器把事件绑定登记到「回调表」而非真实 addEventListener——千节点个位数监听。
- 边界：不冒泡事件（focus/blur 用 capture 委托）、composed 边界处理。
- 调试影响：devtools 监听器列表显示委托——元素库需提供回调表导出（调试）。

```javascript
// shadow 根委托
root.addEventListener('click', (e) => {
  const el = e.composedPath()[0];
  const h = registry.get(el)?.click;   // 编译器登记的回调表
  h?.(e);
});
```
