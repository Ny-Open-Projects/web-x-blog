## WCN-529：Signals 在大型表单系统（数百字段）的「字段级订阅 + 联动图」工程实践怎么做？

**答**：
- 结论：每个字段一个 signal，联动规则声明成图（源字段 → 目标字段的校验/可见性/取值），字段只订阅与自己相关的规则。
- 避免全表单一个大对象信号——那会导致任一字段变化触发整表重渲染。
- 联动图拓扑排序后求值，环检测；异步校验用 epoch 防竞态。
- 追问：字段被卸载时如何清理订阅？（答：字段组件 effect 随自身 dispose 自动取消）

```javascript
function fieldSignal(initial) { const s = { value: initial, subs: new Set() };
  s.set = v => { s.value = v; s.subs.forEach(f => f(v)); }; return s; }
const fields = { city: fieldSignal(''), zip: fieldSignal('') };
const rules = [
  { when: ['city'], run: ([city]) => fields.zip.set(city === 'BJ' ? '100000' : '') },
  { when: ['zip'], run: ([zip]) => validateZip(zip) },
];
rules.forEach(r => r.when.forEach(f => fields[f].subs.add(() => r.run(r.when.map(k => fields[k].value)))));
fields.city.set('BJ'); // 只触发依赖 city 的规则，不动其他字段
```
