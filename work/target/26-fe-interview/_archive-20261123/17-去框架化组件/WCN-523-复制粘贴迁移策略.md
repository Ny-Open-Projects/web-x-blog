## WCN-523：平台迁移：数百个业务页面从「复制粘贴组件」迁移到 WCN 平台的渐进式策略是什么？

**答**：
- 结论：先建「影子对照」——新元素与旧代码并行渲染比对视觉/行为，确认一致后再灰度替换。
- 分值：按「高重复 + 低风险」组件优先（按钮/标签），复杂组件（表格/表单）押后。
- 迁移用 codemod 自动替换模板，人工只 review 差异；每批迁移带回滚开关。
- 追问：旧代码里被业务改得面目全非的「野生组件」怎么办？（答：不纳入平台，标记为遗留特例并隔离）

```javascript
const MIGRATE_ORDER = ['button', 'tag', 'badge', 'input', 'table', 'form'];
function planMigration(inventory) {
  return inventory
    .filter(c => c.type !== 'wild')                         // 野生组件不迁
    .sort((a, b) => MIGRATE_ORDER.indexOf(a.type) - MIGRATE_ORDER.indexOf(b.type))
    .map(c => ({ ...c, strategy: 'shadow-compare -> codemod -> gray-cutover' }));
}

// 每批迁移后跑影子对照断言，通过才切流
function assertShadow(ok) { if (!ok) throw new Error('block cutover'); }
```
