## WCN-452：笔试：静态分析表达式的信号依赖（提取 `sig()` 调用集合）。
**题目**：输入表达式字符串（如 `a() + b() * 2`），输出依赖集合 ['a','b']；无调用的表达式 → 标记 static（不生成 effect）。

```javascript
function analyzeDeps(expr) {
  const ids = [...expr.matchAll(/([a-zA-Z_$][\w$]*)\s*\(/g)]
    .map(m => m[1])
    .filter(id => !['if', 'for', 'while', 'switch', 'catch', 'function', 'return'].includes(id));
  const deps = [...new Set(ids)].sort();
  return { deps, static: deps.length === 0 };
}
console.log(analyzeDeps('a() + b() * 2'));   // { deps: ['a','b'], static: false }
console.log(analyzeDeps('"常量"'));           // { deps: [], static: true }

```

**评分点**：
- 正则提取 `ident()` 调用（排除关键字）。
- 无依赖 → static 标记（编译期优化）。
- 嵌套/方法调用容错（obj.sig() 提取 sig）。
- 输出排序去重。
