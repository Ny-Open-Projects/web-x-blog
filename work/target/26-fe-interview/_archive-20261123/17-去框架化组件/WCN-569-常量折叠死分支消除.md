## WCN-569：模板编译的「常量折叠与死分支消除」：编译期如何计算常量表达式并裁剪分支？

**答**：
- 结论：对纯字面量表达式在编译期求值（常量折叠），if 的条件若为常量则只保留命中分支（死代码消除）。
- 只对「无副作用、无响应式引用」的表达式折叠，含 signal 读取的不能折叠。
- 折叠结果回写 AST，后续代码生成只看到精简树，减小产物体积。
- 追问：折叠后 sourcemap 如何保持？（答：保留被裁剪节点的原始位置映射，便于调试）

```javascript
function foldConstants(node) {
  if (node.type === 'BinaryExpression' && isLiteral(node.left) && isLiteral(node.right)) {
    return { type: 'Literal', value: evalBinary(node.operator, node.left.value, node.right.value), src: node.src };
  }
  if (node.type === 'IfStatement' && node.test.type === 'Literal') {
    return foldConstants(node.test.value ? node.consequent : node.alternate || { type: 'Empty' });
  }
  return node;
}
function isLiteral(n) { return n.type === 'Literal'; }
function evalBinary(op, a, b) { return op === '+' ? a + b : op === '>' ? a > b : op === '==' ? a == b : 0; }
```
