## WCN-167：去框架化组件上线后的观测指标体系：组件健康度看板应包含哪些指标？

**答**：
- 可靠性：组件级错误率（wc-error 事件/调用数）、JS 异常按 tag+version 聚合、define 失败率（加载超时/抛错）。
- 性能：define 耗时 P75/P95、首次渲染耗时、组件加载对 LCP/INP 的贡献占比（RUM 中打归因标记）、体积预算达成率。
- 采用度：各宿主接入组件数、每组件调用量趋势、API 使用分布（哪些 attribute/事件在被用，为 deprecate 决策供数）。
- 质量：a11y 违规数（CI 门禁趋势）、视觉回归失败率、跨宿主一致性测试通过率。
- 版本治理：版本分布（多少流量在旧版本）、灰度回滚次数、双版本共存期冲突告警。
- 工程实现：统一上报通道（WCN-158 适配器）+ 看板按 tag/version 双维度下钻；SLA 设定（如 P95 define < 200ms）。

```javascript
// 归因埋点：给性能条目打组件标签
performance.mark('wc-define-start:acme-table');
customElements.whenDefined('acme-table').then(() => {
  performance.mark('wc-define-end:acme-table');
  performance.measure('wc-define:acme-table', 'wc-define-start:acme-table', 'wc-define-end:acme-table');
  // RUM SDK 采集 measure → 按 tag 聚合上报
});
```
