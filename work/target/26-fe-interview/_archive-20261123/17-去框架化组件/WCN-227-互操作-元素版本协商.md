## WCN-227：页面同时引入两个版本的元素库（微前端场景）时的冲突治理？
**答**：
- 同名 define 报错——微前端子应用必须用带前缀标签或「注册前检查」复用已有定义。
- 平台约定：标签前缀 = 应用域（trade-goods-card），避免碰撞。
- 共享库升级协商：核心元素由主应用注册，子应用消费（whenDefined 等待）。
- 检测工具：CI 扫描 define 调用清单，冲突预检。

```javascript
// 子应用防御式注册
if (!customElements.get('trade-goods-card')) {
  customElements.define('trade-goods-card', GoodsCard);
} // 主应用已注册时直接复用（版本协商在平台层）
```
