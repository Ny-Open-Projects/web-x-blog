## WCN-212：元素内部异步操作与宿主框架卸载的竞态处理？
**答**：
- 元素被移除后异步回调仍执行 → 操作 detached DOM/触发已失效监听。
- 标准做法：disconnectedCallback 里取消进行中的异步（AbortController/标志位）。
- 宿主侧：卸载前显式调用元素暴露的 dispose 方法（可选协议）。
- 请求类：元素内 fetch 全部走「元素级 abort 管理」，断开即 abort。

```javascript
class GoodsCard extends HTMLElement {
  #ac = new AbortController();
  async connectedCallback() {
    const data = await fetch(`/api/goods/${this.sku}`, { signal: this.#ac.signal })
      .then(r => r.json());
    if (!this.isConnected) return;        // 已断开，丢弃结果
    this._render(data);
  }
  disconnectedCallback() { this.#ac.abort(); }
}
```
