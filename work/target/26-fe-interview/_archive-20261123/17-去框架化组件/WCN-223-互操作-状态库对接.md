## WCN-223：自定义元素对接外部状态库（Zustand/Pinia）的推荐模式？
**答**：
- 推荐「selector 注入」：宿主传 selector 函数（property），元素订阅 store 派生值——元素不感知具体库。
- 禁止元素内部直接 import 状态库（破坏框架无关性）。
- 订阅清理与 disconnectedCallback 绑定。
- 复杂联动：宿主侧做中间组件（框架语言里订阅 store，把值作为 property 传入）更简单。

```javascript
// 元素：只认 selector 协议
set selector(fn) { this._unsub?.(); this._unsub = fn((v) => { this._value = v; this._render(); }); }
disconnectedCallback() { this._unsub?.(); }
// React 侧：<goods-card selector={(s) => selectPrice(s.store)} />
r
```
