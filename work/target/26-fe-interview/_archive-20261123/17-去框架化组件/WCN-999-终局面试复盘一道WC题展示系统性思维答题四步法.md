## WCN-999：终局面试复盘：从一道 WC 题出发怎么展示系统性思维

**答**：
- 结论先行：面试官考 WC 不是考 API，是考「能否把一个问题放到场景—约束—权衡—验证的系统框架里回答」——展示思考结构比背答案更重要。
- 答题四步法：① 先澄清场景与约束（多少端、多大流量、什么团队）；② 给结论并说依据（选 WC 还是框架，为什么）；③ 展开权衡与边界（利好与代价、什么时候不选）；④ 给验证与兜底（怎么测、失败怎么退）。
- 以小见大：一道「WC 如何跨框架复用」可延伸到协议设计、样式隔离、a11y、SSR、性能、治理——主动铺开体现广度，但始终回到场景约束。
- 诚实与边界：坦承取舍与局限（WC 调试弱、复杂状态仍用框架），不吹嘘银弹；用数据/经历支撑，避免空谈。
- 追问钩子：面试官问「你最深的教训是什么」——答：讲一个真实踩坑（如属性反射导致对象传参失效）如何倒逼协议分层，体现从错误中系统化改进的能力。

```javascript
// 答题四步法（面试回答结构）
const answerFrame = [
  '1. 澄清场景与约束',
  '2. 结论先行 + 依据',
  '3. 权衡与边界（何时不选）',
  '4. 验证与兜底',
];
function answer(question) {
  return { question, steps: answerFrame,
    depth: '协议/样式/a11y/SSR/性能/治理',
    attitude: '诚实取舍 + 数据支撑' };
}
console.log(answer('WC 如何跨框架复用？'));
```
