## WCN-527：TC39 Signals polyfill 与框架自带 signal 如何共存？双系统互操作边界在哪？

**答**：
- 结论： coexistence 的黄金法则——「一个真相源」，跨系统只在边界做单向同步，禁止双向直接订阅。
- 优先让框架 signal 做真相源，polyfill 信号通过 adapter 读取（读取时建立桥接 effect）。
- 边界处用显式 bridge(from, to)，并带循环防护标记，避免 A→B→A 抖动。
- 追问：两套系统都有 effect，谁先 flush？（答：统一到一个调度器，或用微任务排队保证顺序）

```javascript
const bridging = new WeakSet();
function bridge(fromSig, toSig) {
  fromSig.subscribe(v => {
    if (bridging.has(toSig)) return;              // 循环防护
    bridging.add(toSig);
    toSig.value = v;
    bridging.delete(toSig);
  });
}
// 规则：永远 A(框架) -> B(polyfill) 单向，B 不回写 A
```
