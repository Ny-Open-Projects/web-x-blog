## WCN-387：元素库的「长跑」性能（长时间运行会话的退化）？
**答**：
- 长跑退化源：事件监听累积/DOM 节点滞留（列表追加不回收）/动画残留。
- 巡检：内存长跑测试（8 小时仿真会话，快照趋势平稳）。
- 防护：元素内部「上限治理」（缓存条数/历史记录上限）+ 定期自检。
- 指标：长跑内存斜率（应 ≈ 0）+ detach 节点数。

```javascript
// 长跑测试
for (let i = 0; i < 10_000; i++) { await simulateInteraction(); if (i % 1000 === 0) heapSnapshot(); }
// 斜率 ≈ 0 → 通过；否则定位滞留源
r
```
