## WCN-198：去框架化组件路线的演进展望：原生平台还需要补齐什么？

**答**：
- 已到位：Custom Elements 生命周期、Shadow DOM 隔离（DSD SSR）、form-associated、popover/top layer、Constructable Stylesheets、CustomStateSet。
- 缺口一：响应式原语标准化——TC39 Signals 若落地，WC + 原生 Signals 将形成零依赖完整模型（补 WC 没有状态层的短板）。
- 缺口二：undefined 状态的表现力——`:--states` 已解决一部分；仍缺"组件 API 反射"（无原生 schema 内省，依赖 manifest 约定）。
- 缺口三：跨影子树 ARIA 关系引用（元素型 aria 属性在普及中）；cross-document view transitions（MPA 场景）在完善。
- 缺口四：CSS Anchor Positioning 与 scoped element registries（Shadow DOM 内独立 define，避免全局冲突）仍在推进。
- 对工程的启示：路线图按"原生补齐 → 替换 polyfill/自研"演进——现在自研的注册中心、样式注入器未来可能被平台取代，架构上保持可替换（适配层隔离）。

```text
演进对照
今天自研            → 明天原生
Signals 库          → TC39 Signals
全局 registry       → Scoped Custom Element Registries
浮层定位计算        → CSS Anchor Positioning
aria id 关系 hack   → 元素型 ARIA 属性
```
