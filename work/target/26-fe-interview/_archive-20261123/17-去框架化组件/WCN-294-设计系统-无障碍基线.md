## WCN-294：元素库的无障碍基线（强制项清单）？
**答**：
- 每个交互元素：完整 role/aria 映射（WAI-ARIA APG 模式对照）、键盘路径、焦点可见。
- 自动基线：axe 扫描 + 键盘遍历断言进每元素测试（不过不许发版）。
- 人工基线：屏幕阅读器走查清单（每组件季度覆盖）。
- 外部依赖：宿主侧 label 关联协议（aria-labelledby id 引用规范）。

test('ds-dialog 键盘路径', async () => {
  await open();
  await key('Tab'); expect(focused).toBe('cancel');
  await key('Escape'); expect(closed).toBe(true);   // APG 语义
});
