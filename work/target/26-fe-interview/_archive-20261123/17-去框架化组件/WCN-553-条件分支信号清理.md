## WCN-553：编译器如何处理「条件 hook 式」响应式（if 分支内的信号读取）与分支切换的清理？

**答**：
- 结论：每个分支编译成独立的 effect（或 block），分支切换时 dispose 旧 effect 再创建新 effect。
- 这样分支内读取的信号只在分支激活时被收集，避免「不显示的分支也订阅」导致多余重算。
- 切换时先清理旧订阅，防止闭包残留造成内存泄漏与重复触发。
- 追问：分支频繁切换（如 tab 快速点击）如何避免反复创建销毁？（答：缓存已创建分支实例，切回时复用）

```javascript
function compileIf(condExpr, thenFn, elseFn) {
  let current = null, currentKind = null;
  return effect(() => {
    const kind = condExpr() ? 'then' : 'else';
    if (kind === currentKind) return;             // 未变不重建
    current?.dispose();                           // 清理旧分支订阅
    current = createBranchEffect(kind === 'then' ? thenFn : elseFn);
    currentKind = kind;
  });
}
```
