## WCN-383：元素级可观测（日志/指标/追踪）统一规范？
**答**：
- 日志：元素库统一 logger（级别/tag/instanceId），生产默认 warn 以上。
- 指标：mount/交互耗时/错误率三类标准埋点（元素实现钩子自动采集）。
- 追踪：元素操作与宿主页面 trace 关联（traceId 经 context 传入）。
- 成本：生产采样（10%）+ 错误全量。

```javascript
DsLogger.configure({ level: 'warn', sample: 0.1 });
// 元素钩子：onMount(t0) → metrics.mount(tag, ms)
r
```
