## WCN-586：设计系统「无障碍合规平台化」：如何把 a11y 检查做成 CI 门禁 + 在线检测 + 报告中心？

**答**：
- 结论：三处布点——编码期（lint 规则）、提交期（CI axe 扫描 + 阈值门禁）、运行期（在线检测 + 报告中心）。
- CI 门禁用 axe-core + jsdom 跑关键路径，严重/严重级别问题数超阈值阻断合并。
- 报告中心按规则 × 组件 × 严重级别聚合，生成整改看板与责任人。
- 追问：动态渲染的影子树如何扫？（答：用包含 shadow DOM 的 axe 配置 + 自定义 serializer 展开 shadowRoot）

```javascript
const GATE = { critical: 0, serious: 2 };   // 允许阈值
function ciGate(violations) {
  const counts = {};
  for (const v of violations) counts[v.impact] = (counts[v.impact] || 0) + v.nodes.length;
  const blocked = Object.entries(GATE).some(([impact, max]) => (counts[impact] || 0) > max);
  return { counts, blocked, report: violations.map(v => ({ id: v.id, impact: v.impact, nodes: v.nodes.length })) };
}
```
