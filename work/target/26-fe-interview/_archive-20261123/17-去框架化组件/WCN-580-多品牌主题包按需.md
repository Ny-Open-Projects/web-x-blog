## WCN-580：设计系统「多品牌白标」平台化：一套组件 + N 个品牌主题包如何做构建与按需下发？

**答**：
- 结论：组件产物与品牌主题包解耦——组件只引用语义 token，主题包是独立的 CSS 变量 chunk，按品牌 id 按需加载。
- 构建产出：components.js（共享）+ brand-A.css / brand-B.css（各品牌 token 覆盖）。
- 运行时根据租户/品牌 id 动态 <link> 或注入 CSS 变量，切换品牌不换组件 JS。
- 追问：首屏如何避免主题闪烁？（答：SSR 阶段内联当前品牌 token 到 <style>，JS 只做增强）

```javascript
const BRANDS = { a: '/theme/a.css', b: '/theme/b.css' };
async function applyBrand(id) {
  let link = document.getElementById('ds-theme');
  if (!link) { link = document.createElement('link'); link.id = 'ds-theme'; link.rel = 'stylesheet'; document.head.append(link); }
  if (link.href && !link.href.endsWith(id)) await new Promise(r => { link.onload = r; link.href = BRANDS[id]; });
}
// SSR：<style>内联当前品牌 token</style>，避免 FOUT

// 品牌切换只换主题 chunk，组件 JS 不变，降低维护成本
const componentBundle = 'shared-v3.js';
```
