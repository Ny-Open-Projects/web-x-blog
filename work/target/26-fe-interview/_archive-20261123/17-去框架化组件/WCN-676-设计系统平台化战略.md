## WCN-676：从「组件库」升级到「设计系统平台」，平台化要解决哪些问题？

**答**：
- 结论：组件库只交付代码；平台化交付「设计资产 + 代码资产 + 工具链 + 治理流程」的完整闭环，解决规模化管理、多团队自助消费与一致性度量。
- 平台能力：token 中心、组件文档站、可视化搭建、变更与版本管理、质量门禁、采用率与满意度度量。
- 追问钩子：如何判断该不该平台化？看「组件数量 × 消费团队数」是否越过临界点——考察对「避免过度建设」的判断。

```javascript
const PLATFORM = {
  layers: [
    { name: '资产层', items: ['token', 'icons', '组件', '设计模式'] },
    { name: '工具层', items: ['文档站', 'token 生成器', 'codemod', '视觉回归'] },
    { name: '治理层', items: ['RFC', 'CODEOWNERS', '发布门禁', '采用率看板'] },
  ],
  northStar: '设计一致性与交付效率的乘积',
};
function shouldPlatformize(components, teams) {
  return components * teams > 200; // 经验阈值，示意
}
console.log(shouldPlatformize(40, 8)); // true：值得平台化投入
```
