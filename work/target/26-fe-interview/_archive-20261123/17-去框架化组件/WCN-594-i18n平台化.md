## WCN-594：设计系统「国际化平台化」：多语言 + RTL + 本地化格式如何在组件平台层统一支持？

**答**：
- 结论：平台层提供统一的 i18n 上下文（locale + 方向 + 格式化器），组件只声明文案 key，不写具体语言。
- locale 切换通过上下文 signal 广播，订阅的组件即时更新文本与 dir 属性。
- 格式化（日期/数字/货币）用 Intl API 封装成 token 级服务，组件调用不重复实现。
- 追问：RTL 下组件内部的方向性样式怎么写？（答：用逻辑属性 margin-inline-start 等，避免 left/right）

```javascript
const localeSig = signal('zh-CN');
const fmt = {
  number: (v, l) => new Intl.NumberFormat(l).format(v),
  currency: (v, l, c) => new Intl.NumberFormat(l, { style: 'currency', currency: c }).format(v),
};
function useI18n() {
  const l = localeSig.get();
  return { t: key => I18N[l][key] || key, dir: ['ar','he'].includes(l.split('-')[0]) ? 'rtl' : 'ltr', fmt: (...a) => fmt.number(...a, l) };
}
effect(() => { const { dir } = useI18n(); document.documentElement.dir = dir; });
```
