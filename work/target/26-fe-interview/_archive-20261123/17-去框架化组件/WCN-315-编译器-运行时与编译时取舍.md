## WCN-315：「编译时响应式」vs「运行时响应式」的选型决策框架？
**答**：
- 编译时（Solid/Svelte/Vapor）：产物小性能好，代价是编译复杂度/受限写法/调试心智。
- 运行时（Preact Signals/代理库）：写法自由，代价是运行时开销与包体。
- 中间态：编译器可选（Vue 两模式共存）——按组件级选择。
- 决策变量：团队 TS/编译链维护能力、性能预算严格度、写法自由度需求。

```javascript
const decision = {
  compile: { perf: '最优', cost: '构建复杂/写法受限', fit: '性能严格 + 团队能维护编译链' },
  runtime: { perf: '好', cost: '运行时开销', fit: '快速迭代 + 自由写法' },
  hybrid: 'Vue 式：组件级选择模式',
};
```
