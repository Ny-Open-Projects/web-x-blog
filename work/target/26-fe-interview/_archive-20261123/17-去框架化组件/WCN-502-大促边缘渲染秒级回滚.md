## WCN-502：字节大促场景：WCN 组件如何配合「CDN 边缘渲染 + 秒级回滚」做发布架构？

**答**：
- 结论：把「结构 HTML」推到边缘按 props 渲染，客户端只做升级与行为绑定，发布即切换边缘产物版本。
- 边缘节点用 DSD 字符串缓存，key = tag + props 摘要 + 主题；命中直接吐 HTML。
- 回滚是「原子切换边缘配置指针」，不等客户端刷新 JS，做到秒级；配合 ?dsver= 参数灰度。
- 追问：边缘与客户端实现版本不一致怎么办？（答：data-version 校验，不一致强制走客户端全量渲染）

```javascript
// 边缘 worker：按 props 摘要缓存 DSD
const cache = new CacheStorage();
async function edgeRender(req) {
  const { tag, props, theme } = parse(req.url);
  const key = `${tag}:${hash(props)}:${theme}`;
  let html = await cache.match(key);
  if (!html) { html = renderDSD(tag, props, theme); await cache.put(key, html); }
  return new Response(html, { headers: { 'content-type': 'text/html' } });
}
// 回滚：原子切指针
function rollback(slot, prevVersion) { edgeConfig.set(slot, prevVersion); }
```
