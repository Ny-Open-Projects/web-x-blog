## WCN-434：笔试：实现元素的懒注册器（IntersectionObserver + 竞态保护）。
**题目**：`lazyDefine(tag, loader)`：占位元素进入视口才 loader（chunk 内 define）；重复触发只加载一次（Promise 共享）；定义完成后自动 upgrade 同 tag 已有节点。

```javascript
function lazyDefine(tag, loader) {
  let loading = null;
  const el = document.querySelector(tag);
  if (!el || customElements.get(tag)) return;
  const io = new IntersectionObserver(() => {
    io.disconnect();
    loading ??= loader().then(() => {
      customElements.upgrade(document.querySelector(tag));   // 存量升级
    });
  });
  io.observe(el);
}

```

**评分点**：
- IntersectionObserver 触发 + disconnect。
- 加载 Promise 共享（防并发重复 import）。
- 已注册检查（customElements.get 短路）。
- 注册后 customElements.upgrade 补齐存量节点。
