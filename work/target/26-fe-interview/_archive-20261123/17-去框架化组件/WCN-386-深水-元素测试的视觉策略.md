## WCN-386：元素视觉测试的「语义优先」策略（减少像素快照数量）？
**答**：
- 优先断言语义：computed style 断言（getComputedStyle 值 = token 解析值）覆盖大部分视觉回归。
- 像素快照只保留：视觉复杂组件（图表/布局组合）——数量压到 20%。
- token 断言：组件样式引用 token 的静态扫描（引用对 → 值对自动成立）。
- 收益：快照维护量降 80%，token 变更零快照更新。

```javascript
expect(getComputedStyle(btn).backgroundColor)
  .toBe(getComputedStyle(document.documentElement).getPropertyValue('--ds-primary'));
// token 引用对 → 值随主题自动正确，无需像素快照

```
