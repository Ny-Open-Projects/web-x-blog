## WCN-468：笔试：实现构建产物的完整性校验（元素清单 vs 产物文件）。
**题目**：输入源码元素清单与 dist 文件清单：缺失产物（定义了没打包）/多余产物（打包了没定义）/入口校验（package.exports 覆盖）。输出缺口清单。

```javascript
function distCheck(sourceTags, distFiles, pkgExports) {
  const missing = sourceTags.filter(t => !distFiles.includes(`${t}.js`));
  const extra = distFiles.filter(f => f.endsWith('.js') && !sourceTags.includes(f.replace('.js', '')));
  const noExport = sourceTags.filter(t => !(t in pkgExports));
  return { missing, extra, noExport,
    exitCode: missing.length || extra.length || noExport.length ? 1 : 0 };
}

```

**评分点**：
- 双向比对（清单 vs 产物）。
- exports 映射校验。
- 缺失/多余分类。
- 退出码（CI）。
