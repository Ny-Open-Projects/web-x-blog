## WCN-368：元素库的长期成本模型（自建 vs 维持现状 vs 采购）？
**答**：
- 自建成本：初始建设（人月）+ 持续维护（人力/版本）+ 迁移成本（业务侧）。
- 收益：多框架复用节省 + 一致性缺陷减少 + 长寿命免重构。
- 模型：3 年 TCO 对比（自建 WC vs 维持 N 套框架组件库）。
- 盈亏平衡点：多框架消费数 × 组件数 —— 达到才自建划算。

```javascript
function tco3y(build, maintain, migration, saving) {
  const cost = build + maintain * 36 + migration;
  const benefit = saving * 36;
  return { cost, benefit, breakeven: 'benefit > cost 即正 ROI' };
}
```
