## WCN-287：编译器同时产出客户端与 SSR 双目标代码的机制？
**答**：
- 同一组件源码编译两份：client（effect/事件绑定）+ server（同步求值渲染 HTML）。
- 共享逻辑：组件体求值逻辑相同——信号读取在服务端直接取值（无订阅）。
- 匹配保证：DOM 结构由同一模板生成——水合一致天然成立。
- 条件编译：浏览器专属 API（resizeObserver 等）包在 client-only 块，SSR 跳过。

```javascript
// 编译输出
export function SSR(Component) { /* 同步求值 → HTML 字符串 */ }
export function CSR(Component) { /* effect 绑定 → 交互 */ }
// 两者共享编译期提取的「模板 + 动态表达式」中间表示
r
```
