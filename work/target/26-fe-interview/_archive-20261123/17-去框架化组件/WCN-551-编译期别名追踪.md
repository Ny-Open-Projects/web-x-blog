## WCN-551：编译期依赖分析的「别名追踪」：const a = sig; a() 时如何识别 a 指向 sig？

**答**：
- 结论：做轻量的「绑定解析」——维护变量名 → 信号定义的映射表，遇到调用/读取时回溯别名链。
- 作用域 sensitive：块级作用域内别名只在块内有效，出块失效，需按作用域栈管理。
- 无法静态确定（如函数参数、属性传递）时降级为运行时收集，标记「未知依赖」。
- 追问：const { x } = obj; x() 这种解构别名怎么追？（答：记录解构模式，把 x 绑定到 obj.x 的源信号）

```javascript
function resolveAlias(name, scope) {
  let s = scope;
  while (s) { if (s.bindings.has(name)) return resolveChain(s.bindings.get(name), s); s = s.parent; }
  return { unknown: true, name };                 // 降级运行时
}
function resolveChain(target, scope) {
  // target 可能是另一个别名，递归直到命中 signal 定义
  while (target?.kind === 'alias') target = resolveAlias(target.to, scope);
  return target;
}
// const a = sig  => scope.bindings.set('a', {kind:'alias', to:'sig'})
```
