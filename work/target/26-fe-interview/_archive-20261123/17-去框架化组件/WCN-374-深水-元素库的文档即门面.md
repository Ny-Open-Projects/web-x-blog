## WCN-374：元素文档站作为「平台门面」的信息架构？
**答**：
- 结构：快速开始 → 组件 API → 设计规范（token/动效）→ 生命周期与版本 → 贡献指南。
- 搜索：组件/prop/事件/token 全域搜索（文档数据同源索引）。
- 可运行性：每个 API 有可交互 demo（playground）——文档不许只有静态截图。
- 健康度：文档新鲜度标记（最后验证日期）+ CI 自动验证 demo。

```javascript
const docIA = {
  nav: ['快速开始', 'API', '设计规范', '版本', '贡献'],
  search: '全源索引（prop/event/token）',
  rule: 'API 必须可运行 demo + CI 验证',
};

```
