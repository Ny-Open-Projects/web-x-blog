## WCN-215：「组件库从 React 实现迁移到 Web Components」的分阶段路径？
**答**：
- 阶段 1：新组件用 WC 实现（增量验证基础设施：token/样式/测试）。
- 阶段 2：高频复用组件 WC 化（多端收益最大者优先），React 侧薄包装兼容旧 API。
- 阶段 3：旧 React 组件按退场节奏替换，API 兼容层保持（semver）。
- 完成判据：React 专属依赖清零（除适配包），多框架消费验证通过。

  p1: '新组件 WC + 基础设施验证',

  p3: '旧组件退场替换（API 兼容层）',
  exit: 'React 依赖清零 + 三框架消费冒烟全绿',
};
