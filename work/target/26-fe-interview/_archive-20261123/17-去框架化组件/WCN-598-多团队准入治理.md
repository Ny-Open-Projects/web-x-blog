## WCN-598：平台「多团队贡献」治理：外部团队提交元素时的「准入评审 + 质量评分 + 导师制」流程怎么设计？

**答**：
- 结论：把外部贡献当「PR 入职」——准入评审（API/场景合理性）+ 质量评分（门禁量化）+ 导师制（平台组对接人）三道关。
- 准入评审：元素是否通用、是否与现有重复、API 是否符合规范。
- 质量评分：a11y/测试覆盖/文档/性能四维打分，未达门槛不准入。
- 追问：贡献者动力不足怎么办？（答：排行榜 + 共建署名 + 绩效背书激励）

```javascript
const GATE_SCORE = 75;
function review(submission) {
  const checks = {
    uniqueness: !hasDuplicate(submission.api),          // 不与现有重复
    apiSpec: validateAPI(submission.api),
    a11y: submission.a11yScore >= 80,
    coverage: submission.coverage >= 0.7,
    docs: submission.hasDocs && submission.hasDemo,
  };
  const passed = Object.values(checks).every(Boolean);
  return { passed, checks, mentor: passed ? assignMentor(submission.domain) : null };
}
```
