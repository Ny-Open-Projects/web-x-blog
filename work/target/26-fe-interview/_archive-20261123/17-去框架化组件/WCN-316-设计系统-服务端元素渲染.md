## WCN-316：元素库服务端渲染（DSD）的实现与流式输出？
**答**：
- renderDSD(props) 返回 HTML 字符串（模板 + 已求值内容 + 内联 token 样式）。
- 流式：外壳立即输出，动态内容 chunk 后填充（与框架流式对齐）。
- 序列化信号初值进 DSD（data-signal-state）供客户端恢复。
- 验证：DSD 输出与客户端渲染快照一致性（同 props 双端 diff）。

```javascript
export function renderDSD(props) {
  return `<ds-card>
<template shadowrootmode="open"><style>${inlineTokens()}</style>${bodyHtml(props)}</template>
${slotHtml(props.children)}</ds-card>`;
}
```
