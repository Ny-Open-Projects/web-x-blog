## WCN-234：自定义元素的运行时错误如何归因监控（元素级埋点）？
**答**：
- 统一 error 事件协议 + 全局收集器（宿主装一次监听，按 tag 归因上报）。
- 上报字段：tag/版本/生命周期阶段（connected/attributeChanged/render）/错误码。
- 监控看板按元素聚合（哪个元素错误率异常）→ 定位元素版本。
- 与框架错误监控并存：元素错误带独立前缀，不与框架错误混算。

```javascript
document.addEventListener('ds-error', (e) => {
  const el = e.composedPath()[0];
  report({ type: 'wc-error', tag: el.tagName.toLowerCase(),
    version: el.dataset?.version, phase: e.detail.phase, code: e.detail.code });
});
```
