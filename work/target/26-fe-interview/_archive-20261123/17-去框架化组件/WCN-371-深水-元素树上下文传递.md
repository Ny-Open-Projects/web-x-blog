## WCN-371：跨层元素树的上下文（权限/主题/locale）传递设计？
**答**：
- CSS 变量管样式上下文；JS 上下文用「元素级 context provider」（上下文元素包裹，子元素 closest 查找）。
- closest 跨 shadow：event.composedPath() 回溯查找 provider（shadow 穿透用事件路径）。
- 替代：宿主显式注入（每层传递）——显式但繁琐；provider 元素折中。
- 规范：上下文只读（子元素不可写上下文——防止隐式依赖篡改）。

```javascript
// provider 元素
class DsProvider extends HTMLElement {
  get context() { return this._ctx; }
}
// consumer：沿 composedPath 查找
function lookupContext(el) {
  for (const node of el.dispatchEvent(new Event('_lookup')).composedPath())
    if (node.context) return node.context;
}
```
