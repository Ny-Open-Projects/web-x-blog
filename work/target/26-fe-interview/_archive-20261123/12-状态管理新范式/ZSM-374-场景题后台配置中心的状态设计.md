## ZSM-374：场景题示范：配置中心（草稿/发布/回滚）状态设计

**答**:
- 双数据流：线上生效配置（服务端真相，只读派生）与编辑中草稿（本地可变）严格分离——草稿写本地 store，发布成功后线上缓存失效刷新
- 版本化：每次发布生成版本快照（服务端），回滚=切到历史版本触发重新发布；前端维护「当前生效版本号」用于过期检测
- 冲突防护：编辑期间他人发布 → 版本号检测提示「基于旧版本编辑」，提供 diff 三方合并或强制刷新选项
- 校验链：草稿保存走轻校验（类型/必填），发布走全量校验（依赖/引用完整性），校验错误字段级回显

```javascript
const draft = useStore((s) => s.drafts[configKey])          // 本地草稿层
const { data: live } = useQuery({ queryKey: ['config', key], queryFn: fetchLive })   // 线上真相
const stale = live?.version !== draft?.baseVersion          // 编辑基线过期
// 发布：全量校验 → 带 baseVersion 提交 → 成功后 invalidate
await publish(key, draft, { baseVersion: draft.baseVersion })
queryClient.invalidateQueries({ queryKey: ['config', key] })
```
