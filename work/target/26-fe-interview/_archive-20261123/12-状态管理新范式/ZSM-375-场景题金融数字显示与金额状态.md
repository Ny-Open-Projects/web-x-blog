## ZSM-375：场景题示范：金额类状态（精度/汇率/展示一致性）

**答**:
- 存储层：金额一律「最小单位整数 + 币种」（分/cents），绝不用浮点数存——浮点 0.1+0.2 是事故之源；换算在边界处用整数运算或 decimal 库
- 展示层：格式化（Intl.NumberFormat 按币种/locale）与存储分离；同屏多个金额组件用同一派生（一个 formatter 工厂），避免格式不一致
- 汇率：快照进缓存带时间戳与来源，展示「按 xx 时点汇率」；汇率更新走失效重拉，不允许本地随算
- 一致性验收：购物车合计与明细逐项之和必须相等——用整数学保证；四舍五入规则统一（银行家舍入或明确策略）并在测试锁定

```javascript
// 存储：整数分
const totalCents = items.reduce((s, i) => s + i.priceCents * i.qty, 0)   // 整数无误
// 展示：统一 formatter
const fmt = (cents, currency) => new Intl.NumberFormat(locale, { style: 'currency', currency })
  .format(cents / 100)
// 汇率快照
const { data: rate } = useQuery({ queryKey: ['fx', 'USD'], queryFn: fetchFx, staleTime: 60_000 })
```
