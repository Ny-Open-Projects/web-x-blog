## 1011：微前端状态问题的调试工具链

**答**：
- 调试难点：状态分散在多个应用（各自 store/缓存）+ 事件异步传播（问题出现在「事件链的下游」）——定位需要「跨应用的全景视图」。
- 工具链：总线事件录制器（全量事件按时间轴记录——重放复现）、跨应用状态快照（一键抓取所有子应用 store/缓存状态——时间点全景）、事件链追踪（每事件带 traceId——跨应用传播链路可视化）。
- 录制回放：线上问题按会话 ID 拉事件序列（脱敏）——本地重放事件序列复现（与状态机调试同构）；录制开销低（事件量可控）。
- 追问钩子：为什么「事件时间轴」是微前端调试的核心？——微前端的状态问题几乎都是「事件交互问题」（A 发布/B 消费/时序错乱）——时间轴把异步事件流变成线性可读的叙事（异步问题的时间轴化是调试的通用解法）。

```ts
// 总线录制器：全量事件时间轴
bus.intercept((event, payload, direction) => {
  recorder.log({ t: Date.now(), event, payload, trace: ctx.traceId });
});
// 一键快照：所有子应用状态
function snapshotAll() {
  return Object.fromEntries(apps.map(a => [a.name, a.store.dump()]));
}
```
