## ZSM-770: 网络质量分级的状态适配：慢网/离线/弱连接的策略表

**答**：
- 网络质量不是一个布尔（在线/离线），而是分级：`offline → slow(RTT>1s) → normal → fast`。`navigator.connection`（effectiveType/rtt/downlink）+ 自测 RTT（心跳/请求耗时滑动平均）综合判定，防 API 缺失。分级进 store 全局广播，各消费点按级适配。
- 分级策略表：**offline**——只读缓存 + 离线队列 + UI 明示「离线模式」；**slow**——图片降质（CDN 参数）、请求超时收紧（8s）、轮询降频 3 倍、乐观更新更激进（减少等待）；**normal**——默认策略；**fast**——预取激进（悬停预加载、prefetch 下一页）。
- 慢网特有的状态问题：响应晚到率高（竞态翻倍）——signal 取消与版本号防御的优先级提升（ZSM-766 审计）；超时重试的预算收紧（避免慢网下重试风暴 ZSM-758）；骨架屏时长放宽 + 「仍在加载」渐进提示（转圈超过 5s 显示预估剩余）。
- 判定抖动的防抖：网络分级在边界值附近抖动（slow↔normal 反复）会造成策略震荡——分级变更需连续 2 次采样一致才切换（滞回）。
- 追问钩子：分级与「用户沟通」——慢网时主动显示「网络较慢，已为你优化加载」，把技术策略变成用户可感知的诚意，比默默卡顿体验好。

```javascript
// 网络质量分级器
class NetworkTier {
  #current = 'normal'
  #pendingTier = null
  #rttSamples = []
  #listeners = new Set()

  constructor() {
    navigator.connection?.addEventListener('change', () => this.#evaluate())
    // 自测 RTT：心跳请求耗时滑动平均
    setInterval(() => this.#probe(), 30000)
  }

  async #probe() {
    const t0 = performance.now()
    try {
      await fetch('/api/ping', { method: 'HEAD', cache: 'no-store' })
      const rtt = performance.now() - t0
      this.#rttSamples.push(rtt)
      if (this.#rttSamples.length > 5) this.#rttSamples.shift()
      this.#evaluate()
    } catch { this.#set('offline') }
  }

  #evaluate() {
    const conn = navigator.connection
    const avgRtt = this.#rttSamples.length
      ? this.#rttSamples.reduce((a, b) => a + b) / this.#rttSamples.length
      : conn?.rtt ?? 100
    const effective = conn?.effectiveType ?? (avgRtt < 300 ? '4g' : '2g')
    const raw = navigator.onLine === false ? 'offline'
      : effective === '2g' || avgRtt > 1000 ? 'slow'
      : effective === '4g' && avgRtt < 150 ? 'fast' : 'normal'
    // 滞回：连续 2 次一致才切换
    if (raw === this.#pendingTier) this.#set(raw)
    else this.#pendingTier = raw
  }

  #set(tier) {
    if (tier === this.#current) return
    this.#current = tier
    this.#listeners.forEach((fn) => fn(tier))
  }

  get tier() { return this.#current }
  subscribe(fn) { this.#listeners.add(fn); return () => this.#listeners.delete(fn) }
}

// 分级策略表消费
const TIER_STRATEGY = {
  offline: { timeoutMs: 0, pollFactor: 0, queueOnly: true, ui: '离线模式，操作将在联网后同步' },
  slow: { timeoutMs: 8000, pollFactor: 3, aggressiveOptimistic: true, imageQ: 60, ui: '网络较慢，已为你优化加载' },
  normal: { timeoutMs: 15000, pollFactor: 1, imageQ: 80 },
  fast: { timeoutMs: 15000, pollFactor: 1, prefetch: 'aggressive', imageQ: 100 },
}
```
