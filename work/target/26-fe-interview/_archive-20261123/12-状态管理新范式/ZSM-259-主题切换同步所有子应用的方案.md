## ZSM-259：主应用切主题怎么保证所有子应用即时同步

**答**:
- 共享层推 + 子应用拉：主应用 setGlobalState({theme})，子应用订阅后应用到自己的作用域（qiankun 场景）；iframe 场景用 postMessage 推
- CSS 优先：主题本质是 CSS 变量——主应用把变量挂到共享容器或 :root，子应用样式只消费 var(--app-color)，不需要 JS 状态也能同步；Shadow DOM 子应用要把变量透传进 shadow root
- 双轨制：CSS 变量管「样式主题」，JS 状态管「逻辑分支」（如暗色下图表配色），后者才走状态广播
- 一致性验收：切换后截图 diff 所有子应用；遗留应用内联写死颜色的部分单独改造清单跟踪

```javascript
// 主应用：CSS 变量 + 事件双通道
root.style.setProperty('--app-primary', theme === 'dark' ? '#111' : '#1890ff')
bus.emit('theme:changed', theme)      // 需要逻辑分支的子应用订阅
// Shadow DOM 子应用：变量透传
host.style.setProperty('--app-primary', cssVar('--app-primary'))
```
