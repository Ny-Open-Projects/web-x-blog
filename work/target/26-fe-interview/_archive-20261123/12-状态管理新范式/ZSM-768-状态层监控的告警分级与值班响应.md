## ZSM-768：状态层监控的告警分级：什么状态异常值得半夜叫人

**答**：
- 前端状态异常的告警分级（P0-P3，决定响应速度）：
- **P0（立即叫人）**：核心链路状态机卡死（下单停在 submitting 超 30s 的会话比例 > 5%）、登录态大面积失效（401 率突增）、幂等键冲突（重复下单信号）。
- **P1（工作时间处理）**：状态风暴（单会话 set > 100 次/s 的会话占比）、熔断常开（> 10 分钟）、乐观更新对账失败率 > 2%、内存趋势异常（ZSM-756）。
- **P2（周会复盘）**：selector 热路径劣化（p95 超预算）、INP p75 迁移、缓存命中率下降。
- **P3（观察）**：降级链触发次数、fallback 路径命中、HMR 状态保留失败（dev only）。
- 分级的原则：**影响用户资金/数据安全 = P0；影响功能可用 = P1；影响体验 = P2；基础设施退化 = P3**。告警必须带「上下文包」（状态日志片段 + traceId），否则值班只能盲查。
- 告警风暴防御：同类告警 5 分钟窗口聚合（一条告警带受影响会话数）；降级链触发的告警自动附「当前通道 + 降级原因」——值班第一眼就知道该看哪层。
- 追问钩子：「值班的可操作性」检验标准——每条告警的 runbook 三问（看什么仪表盘/先执行什么缓解动作/何时升级），写不出 runbook 的告警不该存在。

```javascript
// 告警分级与上下文包
const ALERT_LEVELS = {
  P0: { response: '立即', examples: ['状态机卡死率>5%', '401突增', '幂等键冲突'], runbook: 'oncall.md#p0' },
  P1: { response: '工作时间', examples: ['状态风暴占比', '熔断>10min', '对账失败>2%', '内存趋势'], runbook: 'oncall.md#p1' },
  P2: { response: '周会', examples: ['selector p95劣化', 'INP迁移', '缓存命中率'], runbook: null },
  P3: { response: '观察', examples: ['降级触发计数', 'fallback命中'], runbook: null },
}

// 告警发射：带上下文包 + 聚合
class AlertEmitter {
  #windows = new Map()       // key -> { count, firstTs, samples }
  #thresholds = { P0: 1, P1: 10, P2: 50 }    // P0 单条即发，P1 聚合 10 条

  emit(level, key, context) {
    const w = this.#windows.get(key) ?? { count: 0, firstTs: Date.now(), samples: [] }
    w.count++
    if (w.samples.length < 5) w.samples.push(context)   // 采样上下文包
    this.#windows.set(key, w)

    const threshold = this.#thresholds[level]
    const shouldFire = w.count >= threshold
      || (level === 'P0' && w.count === 1)
    if (shouldFire) {
      this.#send(level, key, {
        affectedSessions: w.count,
        windowMs: Date.now() - w.firstTs,
        samples: w.samples,                 // 状态日志片段 + traceId
        runbook: ALERT_LEVELS[level].runbook,
      })
      this.#windows.delete(key)             // 已发：窗口重置（防风暴）
    }
  }
}

// P0 示例：状态机卡死检测
function watchStateMachineStuck(actor, { maxMs = 30000 } = {}) {
  let enteredAt = Date.now()
  actor.subscribe((snap) => { enteredAt = Date.now() })   // 每次迁移刷新
  setInterval(() => {
    if (Date.now() - enteredAt > maxMs && snap.value === 'submitting') {
      alertEmitter.emit('P0', 'order-stuck', {
        traceId: TRACE.current, state: snap.value, dwellMs: Date.now() - enteredAt,
      })
    }
  }, 10000)
}
```
