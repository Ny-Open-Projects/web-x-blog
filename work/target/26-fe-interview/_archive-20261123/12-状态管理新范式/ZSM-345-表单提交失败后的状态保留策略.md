## ZSM-345：表单提交失败（长表单/断网）状态怎么不丢

**答**:
- 分层保底：输入值层（表单库内部保留，不因提交失败清空）、校验层（只标错误不清值）、提交层（失败值回显 + 服务器字段级错误映射回对应输入）
- 长表单（多步/大问卷）：步间数据入 store/草稿（debounce 落盘），失败后可从任意步恢复；提交失败自动回退到失败步骤
- 断网场景：提交进离线队列（见 ZSM-205）或明确提示「已保存为草稿」，用户重试成本为零
- 服务端字段级错误：response.errors 按字段名映射 setError，让用户看到「哪个字段错」而不是整表报错

```javascript
const onSubmit = async (data) => {
  try {
    await api.submit(data)
    clearDraft()
  } catch (e) {
    if (e.fieldErrors) Object.entries(e.fieldErrors).forEach(([f, m]) => form.setError(f, { message: m }))
    else toast.error('网络异常，内容已保留')    // 值仍在表单层，不清空
    saveDraft(data)                             // 草稿兜底
  }
}
```
