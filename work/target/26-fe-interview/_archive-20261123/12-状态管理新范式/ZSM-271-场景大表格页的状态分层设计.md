## ZSM-271：千行级大表格页的状态怎么分层设计

**答**:
- 三层拆分：服务端数据层（Query 缓存，分页/排序/筛选 key 化）、URL 可恢复层（筛选条件、页码、列配置写进 search）、纯 UI 层（选中行、展开态、列宽拖拽，组件内或 Zustand slice）
- 服务端状态与 UI 状态禁止混存：把「选中行集合」存进 Query 缓存会随失效消失；把筛选条件只存内存则刷新丢失
- 大表格性能配套：行数据归一化（id → map）避免嵌套引用、选中集合用 Set 保证 O(1)、虚拟滚动只渲染可视窗口
- 恢复语义：URL 层驱动服务端层（queryKey 包含 URL 参数），UI 层不进 URL，刷新后行为明确可预期

```javascript
const searchParams = useSearchParams()
const q = useQuery({
  queryKey: ['orders', searchParams.toString()],   // URL → 缓存 key
  queryFn: () => fetchOrders(searchParams),
})
const selected = useTableStore((s) => s.selectedSet)   // UI 层独立 store
const toggleRow = (id) => useTableStore.setState(s => {
  const n = new Set(s.selectedSet); n.has(id) ? n.delete(id) : n.add(id); return { selectedSet: n }
})
```
