## ZSM-739：跨端剪贴板与拖放：Clipboard API 的权限状态与降级链

**答**：
- 剪贴板是「用户授权才可用」的 API：`navigator.clipboard.writeText/readText` 需要 secure context（HTTPS/localhost）+ 权限（write 通常自动授予、read 需要用户手势与授权）。状态模型：`granted | denied | prompt`，`navigator.permissions.query({ name: 'clipboard-read' })` 查询——权限状态进 store，UI 依据它决定「直接复制」还是「提示用户手动 Ctrl+C」。
- 复制降级链：`navigator.clipboard.writeText`（现代）→ `document.execCommand('copy')`（老浏览器，需选中文本 trick）→ 手动复制面板（展示文本让用户自己选）。每级失败降下级，**成功状态上报埋点**（降级率监控）。
- read 场景（粘贴富文本/图片）权限更严格：仅在用户粘贴事件里读（`paste` event 的 clipboardData）不需要权限 API；主动 readText 需要授权且 Safari 不支持——「读剪贴板」的产品设计要给「手动粘贴」兜底。
- 拖放跨端状态：HTML5 drag&drop 的 `dataTransfer` 是「一次性数据」不是状态——复杂拖放（跨应用）用 DragEvent + 自定义 MIME（`application/x-our-app`）传递结构化数据；桌面端（Electron）File 对象跨进程要序列化路径。
- 追问钩子：剪贴板与「多端同步」的组合——复制到剪贴板的富文本要带「来源 app 标识」（自定义 MIME），粘贴端识别后走「内部结构化粘贴」（保留格式语义），普通环境降级为纯文本。

```javascript
// 剪贴板权限状态 + 三级降级
const useClipboard = create((set) => ({
  perm: 'prompt',          // granted|denied|prompt
  lastResult: null,

  async init() {
    try {
      const st = await navigator.permissions.query({ name: 'clipboard-read' })
      set({ perm: st.state })
      st.onchange = () => set({ perm: st.state })
    } catch { set({ perm: 'unsupported' }) }
  },

  async copy(text, html) {
    const strategy = [
      () => navigator.clipboard.write([new ClipboardItem({
        'text/plain': new Blob([text], { type: 'text/plain' }),
        ...(html ? { 'text/html': new Blob([html], { type: 'text/html' }) } : {}),
      })]),
      () => legacyCopy(text),          // execCommand 降级
    ]
    for (const fn of strategy) {
      try { await fn(); return { ok: true, via: fn.name } } catch { /* 降级 */ }
    }
    return { ok: false, fallback: 'manual' }     // 手动面板
  },
}))

function legacyCopy(text) {
  const ta = document.createElement('textarea')
  ta.value = text
  ta.style.position = 'fixed'
  ta.style.opacity = '0'
  document.body.appendChild(ta)
  ta.select()
  const ok = document.execCommand('copy')   // 老浏览器降级
  ta.remove()
  if (!ok) throw new Error('execCommand failed')
}

// 粘贴：事件内读 clipboardData（无权限要求）
el.addEventListener('paste', (e) => {
  const dt = e.clipboardData
  const internal = dt.getData('application/x-our-app')      // 内部结构化粘贴
  if (internal) {
    e.preventDefault()
    store.dispatch(pasteStructured(JSON.parse(internal)))   // 保留语义
  } else {
    const text = dt.getData('text/plain')                    // 外部：纯文本降级
  }
})
```
