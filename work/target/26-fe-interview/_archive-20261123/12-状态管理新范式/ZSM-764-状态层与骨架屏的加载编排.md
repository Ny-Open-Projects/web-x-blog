## ZSM-764：加载编排：多接口页面的关键数据与非关键数据分离加载

**答**：
- 页面级加载编排的原则：**关键路径数据**（首屏主内容）与**非关键数据**（侧栏推荐/统计角标）分优先级——关键数据并行拉取（Promise.all）+ 骨架，非关键数据 defer（关键完成后再发，或 idle 时），避免非关键接口占带宽拖慢关键路径。
- 编排模式：1) **瀑布避免**——能并行的绝不串行（A 的结果不需要 B 就并行）；2) **关键性标注**——`priority: 'critical' | 'deferred'`，deferred 用 `requestIdleCallback` 或 `afterCritical(promise)` 触发；3) **超时降级**——关键数据 3s 未到显示降级 UI（缓存旧值/空态+重试），不让用户等死。
- TanStack Query 的编排工具：`prefetchQuery`（关键数据提前发，路由切换前预取）、`staleTime` 分层（关键数据短、静态数据长）、Suspense 边界分层（关键数据 Suspense 包主内容，非关键数据独立边界——非关键挂起不阻塞关键）。
- 全局 loading 的反模式：一个「页面级 spinner」等所有接口——正确做法按区块各自 loading 态（ZSM-541 三态模型），关键区块完成即可交互。
- 追问钩子：加载编排与「状态注入」的协同——SSR 场景关键数据 prefetch 进 dehydrate（ZSM-632），非关键数据客户端挂载后再拉，首屏 HTML 只含关键内容。

```javascript
// 加载编排器
async function loadPage({ critical, deferred, onCriticalReady, timeoutMs = 3000 }) {
  // 关键数据并行 + 超时降级
  const criticalWithTimeout = critical.map((p) =>
    Promise.race([p, timeout(timeoutMs, null)]))
  const results = await Promise.all(criticalWithTimeout)
  const degraded = results.some((r) => r === null)
  onCriticalReady({ data: results, degraded })       // 关键就绪：立即渲染（可降级）

  // 非关键数据：idle 时补拉
  const runDeferred = () => Promise.allSettled(deferred)
  if ('requestIdleCallback' in window) {
    requestIdleCallback(() => runDeferred(), { timeout: 2000 })
  } else {
    setTimeout(runDeferred, 100)
  }
  return { degraded }
}

// TanStack Query 版：Suspense 边界分层
function Page() {
  return (
    <>
      {/* 关键数据：主内容 Suspense */}
      <Suspense fallback={<MainSkeleton />}>
        <MainContent />       {/* useSuspenseQuery 关键数据 */}
      </Suspense>
      {/* 非关键数据：独立边界，挂起不阻塞主内容 */}
      <Suspense fallback={null}>
        <SidebarStats />      {/* useSuspenseQuery 非关键数据 */}
      </Suspense>
    </>
  )
}

function MainContent() {
  // 关键数据：prefetch 已在路由级做（SSR/预取）
  const { data } = useSuspenseQuery({ queryKey: ['feed'], queryFn: api.getFeed })
  return <Feed items={data} />
}

// 路由级预取（关键数据提前发）
router.beforeEach(async (to) => {
  if (to.meta.prefetch) {
    await Promise.all(to.meta.prefetch.map((q) => queryClient.prefetchQuery(q)))
  }
})
```
