## ZSM-396：场景题示范：在线考试状态（防切屏/断点续考/交卷幂等）

**答**:
- 考试状态机：进入→作答→（异常暂停）→交卷→判分；切屏/失焦是「事件计数」不是状态转移（累计违规次数上报，达到阈值服务端裁决）
- 作答数据保底：每题作答 debounce 上报（服务端续考真相）+ 本地草稿兜底；断线重连以服务端答案为准恢复（本地可能落后）
- 交卷幂等：交卷带 attemptId 幂等键，重复点击/超时重试安全；交卷后本地进入锁定态（不可回改）
- 时钟权威：剩余时间以服务端下发截止时间为准（本地偏移校准），本地倒计时只做展示；到点自动交卷请求幂等

```javascript
let attemptId = exam.attemptId
async function submitExam() {
  await api.submit({ attemptId, answers })      // 幂等键：重复提交安全
  setStage('locked')
}
visibilitychange: () => { if (document.hidden) api.reportViolation({ attemptId, type: 'blur' }) }
// 断点续考：reconnect → fetchAttempt(attemptId) → 恢复答案与剩余时间
```
