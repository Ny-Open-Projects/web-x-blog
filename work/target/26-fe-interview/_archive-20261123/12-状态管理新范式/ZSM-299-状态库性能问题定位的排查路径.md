## ZSM-299：页面因状态更新卡顿怎么系统定位

**答**:
- 定位三步：Performance 录制找长任务 → 归因到「哪次 setState 引发的渲染树多大」（React DevTools Profiler 找 why did this render）→ 沿订阅链找根因（selector 粒度/依赖不稳定/通知扇出）
- 常见根因清单：整树订阅没 selector、派生返回新引用、高频输入没节流、大数组全量遍历在渲染期、Context value 未 memo
- 修复优先级：订阅粒度（收益最大）> 数据归一化 > 渲染虚拟化 > memo 补丁——先架构后补丁
- 防回归：关键交互帧率基线（CI Performance 测试）、非必要重渲染计数告警、lint 禁止整树订阅模式

```javascript
// Profiler 定位 + 修复示例
const Page = () => {
  const { data } = useQuery(...)            // 只订阅 data
  const ui = useStore(useShallow((s) => ({ selected: s.selected, mode: s.mode })))  // 粒度收窄
  return <Table data={data} ui={ui} />      // Profiler 确认 Table 不再因无关字段重渲染
}
```
