## ZSM-695：游标分页的状态语义：cursor 断裂、列表合并与刷新一致性

**答**：
- 游标分页 vs 偏移分页的状态差异：offset 分页「页码是绝对位置」（新增数据会顶掉内容，翻页重复/漏数据），cursor 分页「游标是锚点」（新数据不影响已加载页）——列表类产品一律 cursor。cursor 语义上要**冻结在「上次响应的最后一条 id」**，服务端按它继续向后读。
- 断裂处理：cursor 指向的数据被删除（服务端返回 404/空）——策略：1) 用「已加载的最后一条现存 id」重算 cursor 再试一次；2) 仍失败则截断列表（显示「内容有更新，点击刷新」），不静默跳页。
- 列表合并的幂等：加载中收到新数据推送（WS 新消息置顶）→ 合并规则「新数据 prepend + 去重 by id」；已加载页内出现重复 id（服务端游标漂移）→ 以**先加载的为准**（旧数据占位，不重复渲染）。合并器必须以 id 为唯一事实。
- 刷新一致性：下拉刷新 = 重新拉第一页 + 与现有列表 diff（保留 cursor 锚点语义）；「从中间刷新」不可行（游标断裂），要刷新就整列表重置——这是 cursor 的代价，UI 用「增量插入 + 顶部提示 N 条新内容」替代自动刷新。
- 追问钩子：无限滚动 + WS 实时置顶的组合，是「cursor 列表状态」的完整考题——prepend（新内容）、append（加载更多）、dedupe、refresh diff 四个操作各自的 id 处理。

```javascript
// cursor 列表状态引擎
class CursorList {
  items = []            // 已加载（含去重）
  cursor = null         // 冻结锚点：最后一条已加载 id
  ended = false

  async loadMore(fetchPage) {
    let cursor = this.cursor
    for (let retry = 0; retry < 2; retry++) {
      const { data, nextCursor } = await fetchPage(cursor)
      if (!data.length && retry === 0 && this.items.length) {
        // 断裂重试：用现存最后一条重算锚点
        cursor = this.items.at(-1).id
        continue
      }
      const seen = new Set(this.items.map((i) => i.id))
      const fresh = data.filter((d) => !seen.has(d.id))
      this.items.push(...fresh)               // append：只加新的
      this.cursor = nextCursor ?? this.items.at(-1)?.id ?? null
      this.ended = nextCursor == null
      return { added: fresh.length, ended: this.ended }
    }
    // 两次断裂：截断提示
    return { added: 0, ended: true, broken: true }
  }

  prepend(batch) {
    // WS 新内容置顶：去重 + 插入头部
    const seen = new Set(this.items.map((i) => i.id))
    const fresh = batch.filter((b) => !seen.has(b.id))
    this.items.unshift(...fresh)
    return fresh.length
  }

  refresh(firstPage) {
    // 刷新：与第一页 diff（旧数据保留位序，标记过时项）
    const newIds = new Set(firstPage.map((i) => i.id))
    const stale = this.items.filter((i) => !newIds.has(i.id))
    const seen = new Set()
    this.items = [...firstPage, ...this.items.filter((i) => !newIds.has(i.id))]
      .filter((i) => (seen.has(i.id) ? false : (seen.add(i.id), true)))
    this.cursor = this.items.at(-1)?.id ?? null
    return { removed: stale.length }
  }
}
```
