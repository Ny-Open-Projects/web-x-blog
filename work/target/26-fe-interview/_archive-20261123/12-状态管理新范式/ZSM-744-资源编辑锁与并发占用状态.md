## ZSM-744：资源编辑锁：并发占用的租约状态与抢锁 UX

**答**：
- 多人编辑同一资源（文档/配置/工单）用「编辑锁租约」防冲突：客户端 `acquire(resourceId)` 拿租约（服务端记录 holder + 过期时间 60s），持锁期间独占编辑；**租约自动续期**（每 30s heartbeat，编辑活动即续）；断线/关页未释放由服务端 TTL 兜底回收。
- 前端锁状态机：`unlocked → acquiring → held → contention(他人持锁) → stolen(被服务端回收)`。contention 的 UX 三选项：只读浏览、请求接管（向持锁者发协商，对方 60s 无操作自动转移）、强制抢占（管理员权限）——UX 决策要产品确认，不是技术自由裁断。
- 锁丢失的处置：heartbeat 失败（网络抖动）先重试 3 次；服务端判定超时回收后，编辑中的本地变更**不能静默丢弃**——转为「本地草稿 + 重新抢锁合并」，提示用户冲突。
- 乐观锁（版本号）与编辑锁的分工：编辑锁防「同时打字」（交互层互斥），乐观锁防「提交覆盖」（数据层校验）——两层都要，锁只解决体验问题不解决正确性。
- 追问钩子：编辑锁的「假死持锁者」——持锁方页面 freeze（后台 tab 被浏览器节流）导致 heartbeat 停：服务端 TTL 是最终裁决，前端 heartbeat 在 visibilitychange 恢复时立即补发。

```javascript
// 编辑锁租约管理器
class EditLock {
  state = 'unlocked'
  #heartbeat = null
  #resourceId = null
  #listeners = new Set()

  async acquire(resourceId) {
    this.#resourceId = resourceId
    this.state = 'acquiring'
    this.#notify()
    try {
      const res = await api.acquireLock(resourceId, { ttl: 60000 })
      if (res.holder === 'me') {
        this.state = 'held'
        this.#startHeartbeat()
      } else {
        this.state = 'contention'       // 他人持锁
        this.#holder = res.holder       // 展示持锁者信息
        this.#subscribeLockChanges(resourceId)   // 监听锁释放/转移
      }
    } catch {
      this.state = 'unlocked'
    }
    this.#notify()
    return this.state
  }

  #startHeartbeat() {
    this.#heartbeat = setInterval(async () => {
      try {
        await api.renewLock(this.#resourceId)      // 30s 续期（编辑活动时）
      } catch (e) {
        if (e.status === 409) {                     // 被服务端回收（超时/被抢占）
          this.state = 'stolen'
          this.#stopHeartbeat()
          this.#onStolen?.()                        // 本地变更转草稿 + 重新抢锁流程
        }
      }
    }, 30000)
  }

  // contention 下的接管监听
  async #subscribeLockChanges(resourceId) {
    ws.subscribe(`lock:${resourceId}`, (msg) => {
      if (msg.type === 'released') { this.state = 'unlocked'; this.#notify() }   // 可抢
      if (msg.type === 'transferred' && msg.to === 'me') {
        this.state = 'held'
        this.#startHeartbeat()
        this.#notify()
      }
    })
  }

  release() {
    this.#stopHeartbeat()
    api.releaseLock(this.#resourceId).catch(() => {})   // 尽力释放，TTL 兜底
    this.state = 'unlocked'
    this.#notify()
  }

  #notify() { this.#listeners.forEach((fn) => fn(this.state)) }
  subscribe(fn) { this.#listeners.add(fn); return () => this.#listeners.delete(fn) }
  onStolen(fn) { this.#onStolen = fn }
}
```
