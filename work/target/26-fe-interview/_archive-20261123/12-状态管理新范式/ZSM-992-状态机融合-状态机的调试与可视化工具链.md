## 992：状态机的调试工具链（inspector/时间旅行）

**答**：
- 工具三件：Stately 编辑器（图上改机器——可视建模）、Inspector（运行时状态实时可视化——当前状态高亮+事件流）、时间旅行（事件历史回放——从事件序列重建状态轨迹，复现 bug 就是回放事件列表）。
- 时间旅行的调试价值：复杂流程 bug（「点了 A 又点 B 就卡住」）——Inspector 记录事件序列，回放序列即可复现；把序列存成测试用例（bug -> 回归测试的直通路径）。
- 生产调试：事件日志上报（脱敏）——用户反馈「流程卡住」时按会话 ID 拉事件序列回放（远程复现）。
- 追问钩子：为什么状态机的「事件历史」比「状态快照」更利于调试？——快照只告诉你「在哪」，事件序列告诉你「怎么来的」——调试的本质是理解路径，事件序列是完整路径。

```ts
actor.subscribe(state => {
  if (import.meta.env.DEV) inspector.inspect(actor);   // 开发期 Inspector
  const history = actor.getPersistedSnapshot();        // 事件序列可回放
  bugReporter.attach('machine_history', history);      // 生产：附带事件历史
});
// bug 复现 = 用上报的事件序列重建 actor 并逐个 send
```
