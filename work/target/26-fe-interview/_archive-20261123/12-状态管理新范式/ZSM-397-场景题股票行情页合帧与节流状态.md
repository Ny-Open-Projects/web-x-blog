## ZSM-397：场景题示范：行情页高频数据状态（合帧/节流/精度）

**答**:
- 数据管道：WS tick → 原始缓冲（Map 按 symbol 覆盖，只留最新）→ rAF 合帧批量刷入展示层 → 图表增量更新（append 而非全量重绘）
- 展示节流分级：关注列表 500ms 级、详情盘口 100ms 级、K 线按聚合周期——不同区域不同节流频率
- 精度与格式：价格精度按交易所规则表驱动（step/小数位），格式化集中在展示层；红涨绿跌等样式是派生不存储
- 背压：订阅 symbol 数量上限、不可见列表降频或退订（IntersectionObserver），防订阅风暴

```javascript
const buf = new Map()                                  // symbol → 最新 tick
ws.on('tick', (t) => { buf.set(t.symbol, t); schedule() })
function schedule() {                                   // rAF 合帧
  if (scheduled) return
  scheduled = requestAnimationFrame(() => {
    scheduled = null
    buf.forEach((tick, sym) => quotes[sym] = tick)      // 批量刷入
    buf.clear()
    renderVisible()
  })
}
```
