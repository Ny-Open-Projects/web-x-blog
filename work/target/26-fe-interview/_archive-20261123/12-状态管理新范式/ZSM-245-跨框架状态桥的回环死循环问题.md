## ZSM-245：双向状态桥改一次两边都改，为什么会死循环

**答**：
- 回环：React 改 store → 桥通知 Vue → Vue 的 watch 回调又写回 store → 桥再通知 React → 循环
- 解法一（首选）：桥是单向管道——写入口只有 store.set，Vue 侧只订阅不回写（watch 回调去掉写入）；「双向」其实是两边都写 store，而不是互相同步彼此
- 解法二：版本号/来源标记，桥转发时带上 origin，收到「来自对方」的通知不再回写
- 解法三：比较值相等则短路（浅比较或深度相等），让重复写入幂等
- 调试手段：在桥的转发函数打印来源与调用栈，一眼看到回环链路

```javascript
function bridge(store, reactSetter, vueSetter) {
  let from = null
  store.sub((s) => {
    if (from === 'vue') return            // 来源短路防回环
    from = 'store'; reactSetter(s); vueSetter(s); from = null
  })
  // 双方写入都走 store.set —— 桥只有一条通路
}
```
