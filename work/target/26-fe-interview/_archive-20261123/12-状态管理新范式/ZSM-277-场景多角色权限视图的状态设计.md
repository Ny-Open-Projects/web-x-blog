## ZSM-277：后台系统多角色权限的状态与视图控制怎么做

**答**:
- 权限数据单点化：登录后权限集（codes/resources）进全局 store + Query 缓存，视图层派生消费（can(code) 函数/Selector），不各组件自判
- 控制三级：路由级（loader/中间件判权再渲染）、菜单级（派生过滤）、操作级（按钮禁用/隐藏）；数据安全永远靠服务端校验，前端权限只是体验
- 权限变更响应：权限失效广播（websocket/轮询版本号）→ invalidate 权限缓存 → 派生自动重算 → 视图自动收敛
- 性能：权限派生用 Set/memo 化，避免每次渲染遍历大权限数组

```javascript
const permsAtom = atom((g) => new Set(g(userAtom)?.permissions ?? []))
const can = (code) => permsAtom.value.has(code)     // O(1) 派生

function AdminButton() {
  const ok = useAtomValue(canAtom('order:export'))
  return ok ? <Button onClick={exportOrder} /> : null
}
```
