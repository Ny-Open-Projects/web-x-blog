## ZSM-689：键盘快捷键与焦点的全局状态：作用域栈与事件优先级

**答**：
- 快捷键冲突的本质是**作用域嵌套**：全局快捷键（Ctrl+K 搜索）> 页面级（表格 N 新建）> 组件级（弹窗内 Enter 提交）。建模为「作用域栈」：弹窗打开 push 一个作用域，栈顶作用域优先消费按键，未消费向下冒泡——与 DOM 事件冒泡不同，这是**语义层冒泡**（弹窗内的 Delete 不能触发表格的删除）。
- 实现要点：1) 全局一个 keydown 监听器（统一入口），按键规范化（`e.key + modifier mask`），从栈顶遍历 handler 集合，`handled = true` 停止；2) 作用域内 handler 用 Map（`'ctrl+k': fn`）+ 通配；3) 作用域销毁（弹窗关）pop——泄漏检查：栈深度回到 0。
- 焦点状态与快捷键的交叉：输入框聚焦时字符键不应触发快捷键（`e.target.tagName === 'INPUT'` 排除或作用域标记 `ignoreWhenTyping`）；焦点陷阱（modal 内 Tab 循环）与快捷键栈配合——modal 作用域接管 Tab。
- 可观测：快捷键系统本身要有「按键回声」调试模式（dev 面板显示当前栈与命中的 handler）——快捷键 bug 的排查全靠它。
- 追问钩子：快捷键与 React 渲染的解耦——handler 里拿到的是「事件时的最新 store」（getState 直接读），避免闭包旧值（ZSM-030 类问题在全局监听器里更常见）。

```javascript
class ShortcutManager {
  #stack = []       // [{ id, handlers: Map, ignoreWhenTyping }]
  #subs = new Set()

  constructor() {
    document.addEventListener('keydown', (e) => this.#onKey(e), { capture: true })
  }

  #normalize(e) {
    const mask = (e.ctrlKey ? 1 : 0) | (e.metaKey ? 2 : 0) | (e.shiftKey ? 4 : 0) | (e.altKey ? 8 : 0)
    return `${mask}:${e.key.toLowerCase()}`
  }

  push(id, handlers, { ignoreWhenTyping = true } = {}) {
    this.#stack.push({ id, handlers: new Map(Object.entries(handlers)), ignoreWhenTyping })
    return () => {
      this.#stack = this.#stack.filter((s) => s.id !== id)
    }
  }

  #onKey(e) {
    const isTyping = /INPUT|TEXTAREA/.test(e.target.tagName) || e.target.isContentEditable
    for (let i = this.#stack.length - 1; i >= 0; i--) {      // 栈顶优先
      const scope = this.#stack[i]
      if (scope.ignoreWhenTyping && isTyping && !e.ctrlKey && !e.metaKey) continue
      const fn = scope.handlers.get(this.#normalize(e))
      if (fn) {
        e.preventDefault()
        fn(e, store.getState())                              // 事件时最新状态
        this.#subs.forEach((s) => s({ scope: scope.id, key: e.key }))
        return true
      }
    }
    return false   // 无人消费：交给浏览器默认行为
  }

  onDispatch(fn) { this.#subs.add(fn); return () => this.#subs.delete(fn) }
  get depth() { return this.#stack.length }                  // 泄漏检查：回到 0
}

// 用法
const mgr = new ShortcutManager()
const popGlobal = mgr.push('global', { '2:k': openSearch })     // ctrl+k
// 弹窗打开时：
const popModal = mgr.push('modal', { '0:enter': submit, '0:escape': close })
// 弹窗内 Enter 被 modal 作用域消费，不会触发全局
```
