## ZSM-691：订单列表的批量操作状态：部分成功怎么展示与重试

**答**：
- 批量操作（批量发货/取消/退款）的结果不是单一 success/error，而是**逐条结果集**：`{ succeeded: id[], failed: {id, reason}[] }`。UI 三层呈现：成功项立即更新（乐观 UI + 服务端确认）、失败项保留原状态 + 行内标记失败原因、汇总条显示「成功 N / 失败 M，重试失败项」。
- 过程状态建模：`phase: 'idle' | 'confirming' | 'running' | 'settled'`，running 时逐条或并发提交（并发数限制防打爆）；**逐条独立**是关键——一条失败不中断其余（fire-and-per-item），全部完成后进 settled。取消语义：running 中点取消 = 停止发起新请求，在途的等待返回。
- 失败原因分级：可重试（网络/限流 429）vs 不可重试（订单状态已变 409、权限不足 403）——重试按钮只对可重试项开放，不可重试项引导用户逐条处理。
- 幂等要求：重试必须带同一批次 ID（batchId），服务端按 (batchId, orderId) 去重——部分成功的重试不会重复操作已成功项。
- 追问钩子：大批量（>500 条）不能一次发——分页批次 + 进度条（已完成/总数），中途刷新页面用 batchId 查询进度恢复（服务端记录批次任务）。

```javascript
const useBatchOp = create((set, get) => ({
  phase: 'idle',
  batchId: null,
  results: new Map(),        // orderId -> { status: 'pending'|'ok'|'failed', reason? }

  async run(orderIds, action) {
    const batchId = crypto.randomUUID()
    set({ phase: 'running', batchId, results: new Map(orderIds.map((id) => [id, { status: 'pending' }])) })

    const CONCURRENCY = 5
    const queue = [...orderIds]
    const retryable = new Set([429, 500, 503, 0])   // 0=网络错误

    async function worker() {
      while (queue.length && get().phase === 'running') {
        const id = queue.shift()
        try {
          await api.batchAction({ batchId, orderId: id, action })
          set((s) => { const m = new Map(s.results); m.set(id, { status: 'ok' }); return { results: m } })
        } catch (e) {
          const retry = retryable.has(e.status ?? 0)
          set((s) => { const m = new Map(s.results); m.set(id, { status: 'failed', reason: e.message, retry }); return { results: m } })
        }
      }
    }
    await Promise.all(Array.from({ length: CONCURRENCY }, worker))

    set((s) => ({ phase: 'settled' }))
  },

  cancel: () => set({ phase: 'settled' }),        // 停止发起新请求，在途等待

  async retryFailed() {
    const { batchId, results } = get()
    const failedIds = [...results.entries()].filter(([, r]) => r.status === 'failed' && r.retry).map(([id]) => id)
    return get().run(failedIds, 'retry')          // 同 batchId：服务端去重已成功项
  },

  summary: () => {
    const r = [...get().results.values()]
    return { ok: r.filter((x) => x.status === 'ok').length, failed: r.filter((x) => x.status === 'failed').length }
  },
}))
```
