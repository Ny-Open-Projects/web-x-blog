## ZSM-697：全局搜索的状态编排：输入防抖、多源合并与结果竞态

**答**：
- 搜索是「四路并发」的编排题：1) 输入态（本地高频，transient）；2) 防抖请求（300ms， AbortController）；3) 多源结果合并（文档/用户/工单各自接口，聚合展示，各自 loading）；4) 结果竞态防御（旧关键词的响应必须丢弃）。
- 竞态防御三线：AbortSignal 取消在途请求；**关键词版本号**（每 key 递增，响应回来自报版本，过期丢弃）；TanStack Query 方案 key 天然隔离 + cancelRefetch。三层任一漏掉都可能闪现旧结果。
- 多源合并的展示策略：`sources: { docs: {loading, items}, users: {...} }` 分组展示（各自 section 各自 loading 骨架）vs 扁平混排（全部完成后按 score 排）——分组型对体验友好（快的先出），混排需要等待全部或流式插入。高亮渲染（关键词标记）在合并后统一做，别在各源里重复。
- 空态与无结果区分：`phase: 'idle' | 'typing' | 'searching' | 'done'`——输入中不显示「无结果」，防抖期内空态闪烁是最常见的 UX bug。
- 追问钩子：搜索历史的持久化（最近 10 条关键词，去重、可删除）与「搜索态恢复」——从结果页返回搜索页要恢复关键词与结果（Query 缓存 key 含关键词就免费获得）。

```javascript
// 搜索编排引擎
class SearchOrchestrator {
  #version = 0
  #controller = null
  state = { phase: 'idle', kw: '', sources: {} }

  async search(kw) {
    this.state.kw = kw
    if (!kw.trim()) { this.state = { phase: 'idle', kw, sources: {} }; return }
    this.state.phase = 'typing'

    clearTimeout(this.#debounce)
    this.#debounce = setTimeout(() => this.#execute(kw), 300)
  }

  async #execute(kw) {
    const ver = ++this.#version
    this.#controller?.abort()
    this.#controller = new AbortController()
    this.state.phase = 'searching'

    // 多源并发：各源独立 loading
    const sources = { docs: null, users: null, tickets: null }
    this.state.sources = Object.fromEntries(Object.keys(sources).map((k) => [k, { loading: true, items: [] }]))
    this.notify()

    await Promise.all(Object.entries(API_SOURCES).map(async ([name, fn]) => {
      try {
        const items = await fn(kw, { signal: this.#controller.signal })
        if (ver !== this.#version) return            // 版本过期：丢弃
        this.state.sources[name] = { loading: false, items: highlight(items, kw) }
      } catch (e) {
        if (e.name === 'AbortError') return
        this.state.sources[name] = { loading: false, items: [], error: e.message }
      }
      this.notify()
    }))
    if (ver === this.#version) this.state.phase = 'done'
  }
}

// TanStack Query 版：key 隔离 + abort 内建
const useSearch = (kw) => useQuery({
  queryKey: ['search', kw],
  queryFn: ({ signal }) => Promise.all([
    api.searchDocs(kw, { signal }),
    api.searchUsers(kw, { signal }),
  ]),
  enabled: kw.trim().length > 0,
  placeholderData: keepPreviousData,   // 旧结果保留防闪烁
})
```
