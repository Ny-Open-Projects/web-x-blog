## ZSM-679：树形选择器的状态建模：半选态、懒加载与不可选节点

**答**：
- 树选择的状态核心是「选中集合 + 派生三态」：`checked: Set<nodeId>` 存事实（只存叶子或全选父节点取决于策略），`indeterminate` 是派生（部分子选中）——**不存半选**（派生错了就 UI 不一致）。三态判定：全选=all children in set、半选=some、未选=none。
- 父子联动两种策略：1) **级联**（父选中=子孙全选）：checked 存「叶子全集」，父节点的勾是派生——展开/懒加载时新叶子自动归入；2) **独立**（父与子各自勾选，互不影响）：checked 直接存勾过的节点。产品语义决定策略，半选语义在级联模式下才自然。
- 懒加载树：`childrenState: Map<nodeId, 'loaded'|'loading'|'error'>` 与选中集合分离——未加载的子树全选语义用「父节点本身入 checked + lazy 标记」，加载后把父从集合换成叶子集。
- 不可选节点（disabled/权限）：不可选且**不计入父节点的判定基数**（disabled 子不算入 some/all 计算）——否则一个不可勾的节点让父永远半选。
- 追问钩子：受控 vs 非受控——树选择器组件把 checked/expanded 都做成受控 props（状态归上层 store），内部只发 onChange；非受控模式下 expanded 可留内部（展开态不属于业务数据）。

```javascript
function treeSelectState(tree, checked) {
  function status(node) {
    if (node.disabled) return 'excluded'                 // 不可选：不计入基数
    const kids = node.children ?? []
    if (!kids.length) return checked.has(node.id) ? 'all' : 'none'
    let all = true, any = false, counted = 0
    for (const k of kids) {
      const s = status(k)
      if (s === 'excluded') continue
      counted++
      if (s === 'all') any = true
      else all = false
      if (s === 'some') any = true
      if (s !== 'all') all = false
    }
    if (!counted) return 'excluded'
    return all ? 'all' : any ? 'some' : 'none'
  }
  return status
}

// 懒加载全选：父入集合 + lazy 标记，加载后展开为叶子
const state = {
  checked: new Set(['node-3']),          // node-3 未加载但勾了
  lazyChecked: new Set(['node-3']),      // 懒加载集合
  childrenState: new Map(),              // nodeId → loaded|loading|error
}
function loadChildren(nodeId, children) {
  state.childrenState.set(nodeId, 'loaded')
  if (state.lazyChecked.has(nodeId)) {
    state.lazyChecked.delete(nodeId)
    children.forEach((c) => !c.disabled && state.checked.add(c.id))   // 全选语义落地
  }
}

// 受控组件接口
function Tree({ nodes, checked, onChange, expanded, onExpand }) {
  const toggle = (node) => {
    const s = treeSelectState(nodes, checked)(node)
    const next = new Set(checked)
    collectLeaves(node).forEach((leaf) => (s === 'all' ? next.delete(leaf.id) : next.add(leaf.id)))
    onChange(next)     // 状态归上层：组件是纯投影
  }
}
```
