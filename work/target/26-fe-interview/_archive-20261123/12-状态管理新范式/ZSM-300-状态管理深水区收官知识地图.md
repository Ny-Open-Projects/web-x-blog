## ZSM-300：状态管理进阶版收官：一页知识地图

**答**:
- 数据层：TanStack Query 边缘（retry 分类/离线队列/流式接入/精准失效/水合一致性）； Zustand 中间件源码（包装链/devtools 命名/persist 复水/顺序敏感/类型锚）
- 架构层：原子化调试（依赖图/记忆化/tearing）、跨框架桥接（vanilla 核心 + 薄适配/回环防护/DTO 边界）、微前端（共享边界/单点用户态/URL 真相源/契约版本化/订阅泄漏）
- 深水层：时间旅行（快照 vs 事件溯源/结构共享/协作 undo）、场景设计（表格/表单/画布/地图/直播/支付 FSM）、工程化（测试/初始化时序/迁移/可观测/债治理）
- 面试收束：一切题都回到「单一真相源 + 分层失效 + 边界明确」三原则；笔试题见 401~500 系列

```javascript
// 一页心智模型
// 服务端状态 → TanStack Query（失效与缓存生命周期）
// 全局客户端态 → Zustand（vanilla 可跨框架）
// 原子派生态 → Jotai（依赖图自动追踪）
// 可恢复态 → URL（唯一跨边界真相源）
// 跨应用 → 契约 + 广播 + 单点用户态
```
