## ZSM-274：地图应用（视图态+标记点）的状态怎么建模

**答**:
- 双层模型：视图态（center/zoom/bounds）由地图实例持有为真相源，React 侧镜像只读（同步事件→store 用于联动查询）；标记点/数据层进 store 与 Query 缓存
- 视口驱动的数据查询：bounds 变化 → debounce → queryKey 含 boundsHash，服务端按视口返回，避免全量加载
- 选中/详情流：点标记 → 选中 id 进 store → 详情走 Query 缓存（id key）——视图态、选中态、数据态各归其位
- 陷阱：双向同步地图中心与 React state 会形成回环（地图事件→setState→setCenter→事件），只允许「地图→React」单向镜像，React 想移动地图显式调 API

```javascript
map.on('moveend', () => viewStore.setState({ bounds: map.getBounds() }))   // 地图 → store 单向
const { data } = useQuery({
  queryKey: ['pois', hash(viewStore.getState().bounds)],   // 视口 → 查询
  queryFn: () => fetchPois(bounds), enabled: boundsChanged,
})
```
