## ZSM-367：setState 后立刻读 store 拿到新值还是旧值

**答**:
- 外部 store（zustand 等）：setState 同步改内存——同步读立即是新值；React 组件的 re-render 是异步批处理，render 里读到的才是「本次渲染快照」
- React useState：渲染闭包内读到的是本次渲染的旧值，下一渲染才是新值；同一事件内多次 setState 用函数式 `(s) => ...` 基于最新累计
- 事件批处理：React 18 自动批处理（包括 promise/timeout 内）——「多次 setState 一次渲染」是常态，同步读 React state 必旧
- 实践规则：链式更新一律函数式；需要「改完立刻基于新值做事」的逻辑放进 updater 或改用外部 store

```javascript
setCount((c) => c + 1)
console.log(count)          // 旧值（本次渲染闭包）
store.setState({ a: 1 })
console.log(store.getState().a)   // 新值：外部 store 同步生效
// 渲染差异：外部 store 变化经 useSyncExternalStore 触发的重渲染也批处理，但内存真相已新
```
