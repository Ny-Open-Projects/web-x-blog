## ZSM-297：状态管理开放题怎么答出框架感（面试方法论）

**答**:
- 先分类再选型：服务端状态（Query）、全局客户端态（Zustand/Context）、局部态（useState）、URL 态（router）、原子态（Jotai）——先问「这状态属于哪类」展示判断力
- 用决策三问作答：谁消费（作用域）？多常变（频率）？刷新后要还原吗（持久化）？——给出「为什么」而不是「我用了 X」
- 主动提边界：失效策略、并发竞态、多标签页、SSR 复水——面试官追问的高频点先自己说出来
- 落一个场景收尾：拿题目场景（商品列表/IM）走一遍分层，给 3 行伪代码锚定答案

```javascript
// 示例答题骨架
// 1) 分类：商品列表=服务端状态；主题=全局客户端态；筛选=URL 态
// 2) 三问：列表数据多组件消费+常变 → Query 缓存+key 化
// 3) 边界：失效走 WS 推送 invalidate；分页用 placeholderData 防跳闪
// 4) 代码锚：
useQuery({ queryKey: ['list', filters], queryFn: fetchList, placeholderData: keepPreviousData })
```
