## ZSM-348：客户端状态的「最终一致」怎么定义与验收

**答**:
- 定义：静默期（无新事件、无网络抖动）后，客户端状态与服务端真相收敛一致——需要明确「静默期上限」（SLA），如操作后 2s 内或重连后 5s 内
- 收敛机制组合：事件推送（实时）+ 主动失效（操作后 invalidate）+ 周期校准（低频快照对账）+ 校验错误纠偏（版本不符重拉）
- 验收方法：确定性测试（注入事件序列断言终态一致）+ 生产对账（周期抽样比客户端展示与服务端数据，不一致率进看板）
- 一致性成本分层：金额/库存类强校准（每次操作后对账）、列表类弱一致（失效即够）、纯展示类最终一致（低频轮询）

```javascript
// 三层收敛
onAction: () => invalidate(['order'])        // 主动失效（强）
ws.on('order.updated', apply)                // 推送（实时）
setInterval(reconcileSample, 300_000)        // 低频对账（纠偏）
// 对账：抽样 diff 本地缓存 vs 服务端，不一致 → invalidate + 计数上报
```
