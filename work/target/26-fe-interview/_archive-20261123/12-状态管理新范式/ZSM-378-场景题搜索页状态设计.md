## ZSM-378：场景题示范：搜索页状态（联想/结果/高亮/历史）

**答**:
- 状态分域：输入框值（IME 友好，见 ZSM-321）、联想词（独立 Query，防抖 + 取消旧请求）、结果集（queryKey=规范化 query+筛选+页码）、历史（本地持久化 LRU）
- 竞态治理：联想请求 AbortController 取消旧键控、响应带请求序号丢弃迟到者；结果页用 placeholderData 保住旧结果防跳闪
- 高亮与转义：联想词命中片段做安全高亮（转义后拼 span 或用受控组件），禁止 innerHTML 拼接用户输入
- 状态同步：query 进 URL（可分享/可返回），联想与历史不进 URL；「清空输入」与「清历史」是两个独立动作

```javascript
const [q, setQ] = useState('')
const debounced = useDebounce(q, 300)
const suggest = useQuery({ queryKey: ['sug', debounced], queryFn: (c) => fetchSug(debounced, c.signal),
  enabled: debounced.length > 0, placeholderData: keepPreviousData })
const results = useQuery({ queryKey: ['search', canonicalize(debounced), filters], queryFn: search })
// 历史：localStorage LRU 10 条，去重 + 时间戳
```
