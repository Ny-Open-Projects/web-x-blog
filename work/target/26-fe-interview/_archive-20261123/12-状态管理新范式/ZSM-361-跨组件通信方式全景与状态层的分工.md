## ZSM-361：React 里六种跨组件通信方式怎么分工到状态层

**答**:
- props/children：父子直传，无状态库参与；Context：低频全局注入（主题/语言），高频更新会炸全树；事件回调：子到父瞬时通知；全局 store：跨树共享可变状态；Query：服务端状态；事件总线/URL：跨页/跨应用
- 分工口诀：关系近用 props，范围小用 Context（低频），范围大且常变用 store，来自服务端用 Query，跨生命周期/跨页用 URL 与总线
- Context 高频陷阱：value 未 memo + 消费全树 → 每次更新全树重渲染；「只读注入 + store 管 mutable」是标准组合
- 反模式：用 Context 传 onChange 回调链做伪 store、用 store 存「只属于一个组件的局部态」

```javascript
// 低频 Context（主题） + 高频 store（业务）混合
const ThemeCtx = createContext(undefined)
export function App() {
  const [theme] = useTheme()                 // 低频，切换才变
  return <ThemeCtx.Provider value={theme}><Biz /></BizCtx.Provider>
}
// Biz 内部用 useStore()——不经过 Context
```
