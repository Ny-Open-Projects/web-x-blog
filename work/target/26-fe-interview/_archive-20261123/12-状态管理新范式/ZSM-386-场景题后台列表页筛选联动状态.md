## ZSM-386：场景题示范：后台列表页筛选联动状态（级联/互斥/默认值）

**答**:
- 筛选真相进 URL（可分享/可返回），派生查询 key；联动规则声明式（依赖图：城市依赖省份、时间范围互斥自定义区间），不写命令式 watch 链
- 级联失效：上游变化 → 依赖项重置为默认 + 选项重拉（选项也是 Query，key 含上游值）
- 互斥与归一：冲突组合在「规范化函数」里裁决（优先级/清空），保证进入查询的筛选集合永远合法
- 重置语义：「清空筛选」回到默认集（不是空集）；默认值也进 URL 保持一致性

```javascript
// 声明式联动规则
const rules = {
  city: { dependsOn: ['province'], reset: 'all' },
  range: { mutuallyExclusive: ['preset'] },
}
const filters = normalizeFilters(parseFilters(search), rules)   // 合法化
useQuery({ queryKey: ['list', filters], queryFn: fetchList })   // URL → key
```
