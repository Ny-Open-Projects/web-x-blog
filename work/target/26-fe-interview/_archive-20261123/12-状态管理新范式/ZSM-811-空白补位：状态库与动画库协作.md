## ZSM-811：空白补位：状态库与动画库（framer-motion）的状态协作接口

**答**：
- 动画库（framer-motion/react-spring）自带「动画值」内部状态——与状态库协作的边界：**动效参数进 store（声明式），逐帧插值不进 store（动画库内部）**。`animate={{ x: storeX }}`：storeX 变 → 动画库自动补间到新值——React 状态驱动「目标值」，动画库驱动「过程值」，两层各管一段。
- 弹簧物理与状态回写：`useSpring` 的值在动画中与 store 不同步——需要在 `onRest`（动画结束）回调里把最终值写回 store（milestone 语义，ZSM-763），否则「动画看起来到位了但状态没变」。
- 手势驱动（framer-motion 的 drag）：`onDrag` 高频回调里**不 setState**，用 motion value 或 ref；`onDragEnd` 才提交 store（ZSM-680 的拖拽混合模式在动画库下的落地）。
- 动画与列表状态的协作：列表项布局动画（AnimatePresence + layout）依赖 React diff——key 稳定性决定动画质量（key 抖动 = 动画乱跳）；删除项的 exit 动画期间**数据已从 store 移除但 DOM 还在**——「动画中的幽灵节点」要有独立的占用标记（防重复删除请求）。
- 追问钩子：动画库的「状态盲区」——动画中刷新/中断，恢复时 store 的值是目标值而视觉在中途——恢复策略：页面恢复时 `animate` 立即跳到 store 值（无补间），因为过程值不值得持久化。

```javascript
// framer-motion 与状态库的协作模式
import { motion, AnimatePresence, useMotionValue, useSpring } from 'framer-motion'

// 1) 声明式目标：store 驱动动画
function Panel() {
  const open = useDialog((s) => s.openIds.length > 0)
  return (
    <motion.div
      animate={{ x: open ? 0 : 300 }}       // store 状态 = 目标值
      transition={{ type: 'spring', stiffness: 300 }}
      onRest={() => useDialog.getState().markSettled()}   // 动画结束回写里程碑
    />
  )
}

// 2) 手势：onDrag 不 setState，onDragEnd 提交
function Draggable({ id }) {
  const x = useMotionValue(0)
  const sx = useSpring(x, { stiffness: 500 })
  return (
    <motion.div
      drag
      style={{ x: sx }}
      onDragEnd={(e, info) => {
        useBoard.getState().move(id, info.offset)   // drop 才进 store（680）
      }}
    />
  )
}

// 3) 列表 exit 动画的幽灵节点防护
function TaskList() {
  const tasks = useTasks((s) => s.items)
  const removing = useTasks((s) => s.removing)    // 动画中的占用标记
  return (
    <AnimatePresence>
      {tasks.map((t) => (
        <motion.li
          key={t.id}                                // key 稳定 = 动画质量
          exit={{ opacity: 0, height: 0 }}
          data-removing={removing.includes(t.id)}   // 幽灵节点标记：防重复删除请求
        >
          {t.title}
        </motion.li>
      ))}
    </AnimatePresence>
  )
}
// store.remove(id)：立即从 items 移除 + 加入 removing；exit 完成回调移出 removing
```
