## ZSM-382：场景题示范：监控仪表盘多图表高频刷新的状态设计

**答**:
- 数据通道：时序指标走「推送或轮询 → 环形缓冲（每指标 N 点）→ 图表消费」；不放 React state（每点重渲染全页），图表组件直接订阅数据层（自绘 canvas/图表库 setData）
- 合帧：高频点合并到 rAF/500ms 一批渲染；图表间共用时间轴对齐（同一时间窗版本），避免各图时间错位
- 窗口管理：可视图表才订阅（IntersectionObserver），离屏停更新；时间范围切换=新查询 key，切换动画用 placeholderData
- 告警联动：指标越过阈值在数据层产生事件（带去重），驱动角标/横幅，与图表渲染解耦

```javascript
const buf = new RingBuffer(600)                 // 10min × 1s
ws.on('metric', (p) => { buf.push(p); scheduleFlush() })
function scheduleFlush() {                      // rAF 合帧
  if (frame) return
  frame = requestAnimationFrame(() => { frame = null; chart.setData(buf.snapshot()) })
}
```
