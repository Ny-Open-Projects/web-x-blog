## ZSM-369：涉及状态层的改动怎么灰度与一键回滚

**答**:
- 灰度单位：按用户分桶（sticky）而非按请求——状态行为跨请求连续，分桶漂移会让同一用户体验两种实现
- 回滚硬要求：持久化结构向前兼容（新代码写的数据旧代码能读，或 migrate 可逆），否则回滚 = 数据损坏；迁移前自动备份旧结构
- 回滚开关分级：feature flag 关新逻辑（秒级）、版本回退（分钟级）、数据回迁（小时级）——能 flag 解决的不发版
- 观测先行：灰度期指标（错误率/转化/性能）双桶对比，显著劣化自动告警并支持一键关停

```javascript
// sticky 分桶 + 兼容写入
const bucket = getStickyBucket(userId)           // 1% → 10% → 50%
const useNew = bucket >= threshold
if (useNew) writeV2(data) else writeV1(data)     // 写入兼容：回滚后 v1 能读
// flag 关闭即回滚：flags.set('cart_v2', false)
```
