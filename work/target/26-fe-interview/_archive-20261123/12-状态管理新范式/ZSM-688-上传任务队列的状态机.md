## ZSM-688：文件上传队列的状态建模：并发数控制、分片续传与暂停恢复

**答**：
- 每个上传任务是一个小状态机：`pending → uploading(分片循环) → paused → merging → done / error`。调度器维护「全局并发数 ≤ N」：任务进入 uploading 前要拿并发槽，暂停/完成释放——并发控制本质是「槽位信号量」，不是每任务各自 setInterval。
- 分片续传：`uploadedChunks: Set<chunkIndex>` 持久化（localStorage，key 含文件 hash）——刷新后用 hash 询问服务端已有分片，跳过已完成部分（秒传/续传）。分片按序发（保序合并），失败分片重试而不重传整个文件。
- 暂停/恢复语义：暂停 = 取消在途分片请求（AbortController）+ 状态 paused，已传分片保留；恢复 = 从下一未完成分片继续。任务级优先级（VIP 插队）实现为调度器的「槽位抢占」——释放槽位时按优先级出队。
- 进度计算：`progress = Σ uploadedChunks.size / totalChunks`（分片不均匀时按字节加权）——进度是派生值（字节计数器），不要每次进度回调 setState 全量状态。
- 追问钩子：大文件的内存管理——分片用 `file.slice()` 惰性读取（不一次读入内存）；上传完成后 revoke ObjectURL；队列上限（如 50 任务）防止长列表无限堆积。

```javascript
class UploadScheduler {
  #slots = 3                  // 全局并发
  #queue = []                 // { task, priority }
  #running = new Set()

  enqueue(task, priority = 0) {
    this.#queue.push({ task, priority })
    this.#queue.sort((a, b) => b.priority - a.priority)   // VIP 插队
    this.#drain()
  }

  #drain() {
    while (this.#running.size < this.#slots && this.#queue.length) {
      const { task } = this.#queue.shift()
      this.#running.add(task)
      task.start().finally(() => {
        this.#running.delete(task)
        this.#drain()          // 槽位释放：继续调度
      })
    }
  }
}

class UploadTask {
  state = 'pending'
  uploaded = new Set()
  controller = null

  constructor(file, { chunkSize = 4 << 20 }) {
    this.file = file
    this.total = Math.ceil(file.size / chunkSize)
    this.chunkSize = chunkSize
  }

  async start() {
    this.state = 'uploading'
    // 续传：询问服务端已有分片
    const done = await api.checkUploaded(this.hash)
    done.forEach((i) => this.uploaded.add(i))
    try {
      for (let i = 0; i < this.total; i++) {
        if (this.uploaded.has(i)) continue
        if (this.state === 'paused') { this.state = 'paused'; return }
        this.controller = new AbortController()
        const blob = this.file.slice(i * this.chunkSize, (i + 1) * this.chunkSize)   // 惰性读取
        await api.uploadChunk(this.hash, i, blob, { signal: this.controller.signal })
        this.uploaded.add(i)      // 分片级进度
        this.notify()
      }
      await api.merge(this.hash, this.total)     // 合并
      this.state = 'done'
    } catch (e) {
      this.state = e.name === 'AbortError' ? 'paused' : 'error'
    }
    this.notify()
  }

  pause() { this.state = 'paused'; this.controller?.abort() }   // 取消在途分片
  resume() { if (this.state === 'paused') this.start() }

  get progress() {                       // 派生：字节加权
    const bytes = this.uploaded.size * this.chunkSize
    return Math.min(1, bytes / this.file.size)
  }
}
```
