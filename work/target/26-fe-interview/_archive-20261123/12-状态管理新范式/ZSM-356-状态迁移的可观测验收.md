## ZSM-356：状态重构上线后怎么确认没坏（验收指标）

**答**:
- 功能面指标：关键流程转化率（下单/提交流程完成率）环比、错误率（接口错误/前端异常）环比——重构最伤的是隐性流程断裂
- 状态健康指标：双写不一致率（迁移期）、缓存命中率（key 结构变了命中率可能暴跌）、失效次数分布（异常风暴检测）、复水失败率（持久化迁移）
- 性能面：关键交互 P95（重构后订阅扇出变化）、store 内存曲线、首屏 TTFB 变化
- 预案：验收期设置自动回滚条件（错误率/转化率阈值触发 flag 回退），不要靠人工盯盘

```javascript
// 验收看板指标（示例配置）
const dashboard = {
  funnel_completion: diff7d('checkout'),     // 流程完成率环比
  dual_write_mismatch: rate('mismatch'),     // 双写不一致率
  cache_hit: rate('query_hit'),              // 缓存命中率
  p95_interaction: p95('cart_submit'),       // 交互 P95
  rollback_if: 'funnel_completion < -2% || mismatch > 0.5%',
}
```
