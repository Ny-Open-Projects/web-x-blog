## ZSM-272：复杂表单（联动校验/分步）的状态管理怎么选型

**答**:
- 首选表单库（react-hook-form/zod）：表单状态高频变化且生命周期短，进全局 store 会造成全应用重渲染——表单是「局部性最强」的状态
- 联动/校验逻辑声明式化：schema 定义规则，联动用 watch + 条件校验，不写命令式 setState 链
- 需要跨组件/跨步共享时才上提：分步向导把「已完成步骤数据」放 Context/store，字段级状态仍在各步表单库内
- 草稿持久化：debounce 后写 storage（persist partialize），恢复时 merge 校验 schema，schema 变更走版本迁移

```javascript
const form = useForm({ resolver: zodResolver(schema) })
watch('country', (c) => {                     // 声明式联动
  if (c === 'CN') setFieldsValue({ taxId: '' })  // 清理失效字段
})
// 分步：完成后上提
onSubmit((data) => wizardStore.setState((s) => ({ steps: { ...s.steps, [stepIndex]: data } })))
```
