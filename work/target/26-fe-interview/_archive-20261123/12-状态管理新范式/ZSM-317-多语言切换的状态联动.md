## ZSM-317：多语言切换牵一发动全身的状态怎么联动

**答**:
- locale 是「准全局态」：进全局 store + URL（可分享指定语言）+ persist（记住偏好），三处真相要规定优先级（URL > storage > 默认）
- 联动面：翻译文本（即时切换）、服务端数据（含语言的字段要 invalidate 重拉）、格式化（日期/数字 Intl 对象重建）、布局（RTL 翻转）
- 缓存 key：含语言的服务端数据 queryKey 必须带 locale，否则切语言命中旧语言缓存——最常见的多语言 bug
- 切换体验：文本用 i18n 立即生效，数据类用 invalidate 异步刷新 + loading 态，避免半中半英

```javascript
function setLocale(l) {
  useAppStore.setState({ locale: l })
  document.documentElement.lang = l
  document.documentElement.dir = l === 'ar' ? 'rtl' : 'ltr'
  queryClient.invalidateQueries({ predicate: (q) => q.queryKey.includes('localized') })  // 语言相关数据重拉
}
```
