## ZSM-758：网络层状态的重试风暴防御：全站退避与熔断共享

**答**：
- 重试风暴的成因：服务端故障时，每个请求独立重试（TanStack 默认 3 次 × N 个组件同 key 去重失效时）——N 个请求 × 3 次重试在恢复瞬间形成脉冲。防御三层：1) **单请求退避**（retryer 的指数退避 + 抖动，ZSM-628）；2) **域名级熔断**——同一 host 连续失败 ≥5 次进入 open 态（30s 冷却内直接 fail-fast），半开探测恢复；3) **全局并发闸门**——在途请求 > 50 时新请求排队（防恢复瞬间脉冲打爆）。
- 熔断器与 Query 的协作：熔断 open 时 TanStack 的 queryFn 直接 throw CircuitOpenError（不占配额不重试），UI 显示「服务波动」态；half-open 放行 1 个探测请求成功后 closed——恢复期的流量爬坡由半开→closed 逐步放大。
- 指数退避的「全抖动」变体：`delay = random(0, min(cap, base * 2^attempt))`——避免同步重试（多个客户端同一时刻齐射）；TanStack 场景还需「重试预算」：同 query 1 分钟内重试总数上限（防 v5 组件反复 mount 触发的叠加）。
- 状态可见性：熔断状态进 store（`circuit: 'closed'|'open'|'half-open'`），顶栏全局横幅——服务故障的用户沟通靠它，而不是每个组件各自报错。
- 追问钩子：熔断的粒度选择——按 host（粗）vs 按 endpoint 类（细）；SLO 敏感的写操作与读操作分开熔断（写操作宁可失败快速返回，读可静默降级）。

```javascript
// 域名级熔断器
class CircuitBreaker {
  #failures = 0
  #state = 'closed'          // closed | open | half-open
  #cooldown = 30000
  #openedAt = 0
  #listeners = new Set()

  async exec(fn) {
    if (this.#state === 'open') {
      if (Date.now() - this.#openedAt > this.#cooldown) {
        this.#state = 'half-open'          // 冷却结束：半开探测
      } else {
        throw new CircuitOpenError()       // 直接失败：不打服务
      }
    }
    try {
      const result = await fn()
      if (this.#state === 'half-open') this.#close()   // 探测成功：闭合
      this.#failures = 0
      return result
    } catch (e) {
      this.#failures++
      if (this.#state === 'half-open' || this.#failures >= 5) this.#open()
      throw e
    }
  }

  #open() {
    this.#state = 'open'
    this.#openedAt = Date.now()
    this.#notify()                         // 全局横幅：「服务波动」
  }
  #close() { this.#state = 'closed'; this.#failures = 0; this.#notify() }
  #notify() { this.#listeners.forEach((fn) => fn(this.#state)) }
  subscribe(fn) { this.#listeners.add(fn); return () => this.#listeners.delete(fn) }
}

// 全局并发闸门
class ConcurrencyGate {
  #inFlight = 0
  #queue = []
  constructor(readonly max = 50) {}
  async run(fn) {
    if (this.#inFlight >= this.max) {
      await new Promise((r) => this.#queue.push(r))    // 排队：防恢复脉冲
    }
    this.#inFlight++
    try { return await fn() } finally {
      this.#inFlight--
      this.#queue.shift()?.()                          // 释放槽位
    }
  }
}

// 组装：TanStack queryFn 经熔断+闸门
const breaker = new CircuitBreaker()
const gate = new ConcurrencyGate(50)
queryFn: () => gate.run(() => breaker.exec(() => api.get(url)))
```
