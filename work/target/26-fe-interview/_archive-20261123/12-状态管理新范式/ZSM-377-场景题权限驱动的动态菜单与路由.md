## ZSM-377：场景题示范：动态菜单/动态路由的权限状态设计

**答**:
- 数据流：登录后拉权限集（codes + 菜单树配置）→ 派生菜单（过滤）与路由注册（懒加载 map 匹配）；权限数据进 Query 缓存单点
- 路由防线：动态注册的路由守卫仍校验（防直接输 URL）；未授权访问重定向 403 页并上报（越权探测信号）
- 派生纯函数：menuFromPermissions(perms, menuConfig) 可单测——权限→视图的映射逻辑零散在组件里是事故源
- 变更响应：权限更新（角色调整）→ 缓存失效 → 派生重算 → 菜单与路由即时收敛；正在访问的无权页面跳转处理

```javascript
const { data: perms } = useQuery({ queryKey: ['perms'], queryFn: fetchPerms })
const menu = useMemo(() => menuFromPermissions(perms, menuConfig), [perms])
// 路由守卫（统一入口）
function requirePerm(code) {
  if (!perms?.codes.includes(code)) { report('auth_probe', { code }); navigate('/403') }
}
```
