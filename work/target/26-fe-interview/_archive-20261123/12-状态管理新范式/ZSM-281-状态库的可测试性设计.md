## ZSM-281：怎么让状态层可测试（store 单测与组件集成）

**答**:
- 分层测试：store 纯逻辑（create 后直接 getState/setState 断言，零 DOM）→ hook 层（renderHook + wrapper Provider）→ 组件集成（MSW mock 接口，断言最终状态而非实现细节）
- 关键设计：store 创建函数参数化依赖（queryClient、storage 注入），测试里传 fake——单例化会导致测试互相污染，用 createXStore() 工厂每测新建
- 时间敏感逻辑用 fake timers（debounce/轮询）；异步中间件用 vi.fn 断言调用序
- 禁止测试「中间态」：只测公开行为（输入→状态），内部实现重构不破测试

```javascript
test('cart total', () => {
  const store = createCartStore({ mockApi })        // 依赖注入
  act(() => store.getState().addItem({ price: 10 }))
  expect(store.getState().total).toBe(10)
})
test('hook with provider', () => {
  const qc = new QueryClient()
  renderHook(() => useCart(), { wrapper: ({ children }) =>
    <QueryClientProvider client={qc}>{children}</QueryClientProvider> })
})
```
