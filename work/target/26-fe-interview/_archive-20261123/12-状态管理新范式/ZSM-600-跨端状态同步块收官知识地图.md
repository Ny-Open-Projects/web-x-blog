## ZSM-600：跨端状态同步收官知识地图：从通道到协议到收敛的完整分层

**答**：
- **通道层**（怎么传）：BroadcastChannel / storage 事件 / SharedWorker / postMessage（跨源）/ worker postMessage / IPC（Electron）/ 原生桥（RN/小程序）。选择依据：同源跨 tab、跨源窗口、跨进程、跨设备。
- **会话层**（谁说话）：Leader 选举（Web Locks/心跳）、可见性暂停恢复、加入握手（hello/welcome）、连接聚合（单 WS）。解决的问题：N 端只有 1 条连接、只渲染一次副作用。
- **协议层**（怎么不乱）：seq 序号去重、baseVersion 缺口检测 + 重同步、msgId 请求配对、乱序 hold-back 缓冲。解决的问题：重复、乱序、丢失。
- **收敛层**（冲突怎么办）：字段 LWW（同 ts 设备 id 决胜）、op 计数器（不丢增量）、游标 max（语义合并）、版本向量（识别并发）、CRDT（无中心收敛）、服务端权威 + 乐观对账。选型看「冲突后用户能否接受任意一方胜出」。
- **架构层**：全量镜像（离线优先）vs 投影模式（权威单一）。事实数据投影 + 交互态全量的混合分层是业务常态。
- 面试答题框架：先问同步半径（同 tab 群/跨设备）→ 定通道 → 说协议三防（重/乱/丢）→ 按数据性质选收敛策略 → 给出故障路径（leader 挂/断网恢复）。
