## ZSM-349：状态设计 code review 检查哪些点

**答**:
- 归属五问：这状态是服务端数据吗（该进 Query）？需要跨组件吗（该上提）？需要还原吗（该进 URL/持久化）？派生吗（不该存储）？生命周期（该随组件销毁吗）？
- 失效与竞态：key 是否含全部影响因子、写操作是否登记失效映射、并发写是否幂等、乐观更新是否有回滚
- 订阅与性能：selector 粒度、派生引用稳定性、通知扇出估算、大列表是否虚拟化
- 边界与健壮：多标签页、SSR 复水、会话过期清理、错误分级、持久化版本迁移——每项一句「这个场景你怎么处理」
- 用清单驱动而非经验驱动：清单进 PR 模板， reviewers 按项打勾，新人才不会漏

```javascript
// PR 模板节选
// [ ] 状态归属分类说明（服务端/客户端/URL/派生）
// [ ] queryKey 含全部影响因子；写操作已登记失效映射
// [ ] 并发/竞态处理说明（乐观回滚/幂等）
// [ ] 多标签页/SSR/过期清场考虑
```
