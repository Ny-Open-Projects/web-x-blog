## ZSM-291：跨标签页共享状态选什么通道（对比五种）

**答**:
- BroadcastChannel：首选——即时、结构化、双向、同源；不支持则降级 storage 事件
- storage 事件：兼容性兜底，仅「其他标签页」触发、JSON 字符串，写入本身也当广播用
- SharedWorker：真正的共享内存 + 消息，可做「中心化状态服务」，但 Safari/移动端支持与调试成本要评估
- Service Worker：离线场景顺带做状态中转；Cookie：仅服务端可达的会话态，性能差
- 决策口诀：要实时要对象用 BroadcastChannel，要兼容用 storage，要中心化计算用 SharedWorker，离线加 SW

```javascript
const ch = 'BroadcastChannel' in window ? new BroadcastChannel('app') : null
function emit(msg) {
  if (ch) ch.postMessage(msg)
  else localStorage.setItem('bus', JSON.stringify({ ...msg, _t: Date.now() }))  // storage 事件兜底
}
window.addEventListener('storage', (e) => { if (e.key === 'bus') handle(JSON.parse(e.newValue)) })
```
