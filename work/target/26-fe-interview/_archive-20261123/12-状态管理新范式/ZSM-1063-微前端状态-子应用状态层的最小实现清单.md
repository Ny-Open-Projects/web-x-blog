## 1063：子应用状态层的最小实现清单（新子应用脚手架）

**答**：
- 清单八项：接入 SDK（createAppSdk——总线/门/清理标准入口）、manifest 声明（requires/provides——契约）、私有 store（分桶命名空间）、事件发布（走 SDK 埋点钩子）、生命周期清理（onUnmount 全注册）、权限消费（gate 只读）、调试钩子（快照接口实现）、泄漏测试（mount/unmount 循环断言）。
- 脚手架化：清单做成模板（create-sub-app 脚手架生成——清单八项开箱即用）——新人不会漏项（漏项即 CI/探针拦截）。
- 清单的评审价值：新子应用上线前的 checklist（八项全过才放流量）——与 Query 层 CR 清单同构（机械项工具化）。
- 追问钩子：为什么「脚手架生成」优于「文档说明」？——文档说明靠人记忆执行（漏项率高）；脚手架把清单固化为代码起点（漏项在生成时就存在了概率为零）——清单的可执行化是治理从文档到代码的关键一步。

```md
## 新子应用状态层清单（脚手架生成）
- [x] SDK 接入（bus/gate/lifecycle）
- [x] manifest 声明（requires/provides）
- [x] 私有 store 分桶
- [x] 事件发布走 SDK（自动埋点）
- [x] onUnmount 全注册
- [x] 权限走 gate 只读
- [x] 快照调试接口
- [x] 泄漏循环测试
```
