## ZSM-686：秒杀倒计时与限时活动的状态设计：本地时钟不可信怎么办

**答**：
- 时钟三源：**服务端时间戳**（接口返回 serverTime）、**响应头 Date**（每次请求都带）、**本地 Date.now()**（漂移可达秒级甚至分钟级，用户改时钟更离谱）。倒计时的正确基线：`offset = serverTime - localNow`（接口对齐），活动状态判定用 `localNow + offset`，本地时钟只做「走秒」，不做「起点判定」。
- 倒计时的状态模型：`phase: 'upcoming' | 'active' | 'ended'` 派生自 `(now+offset)` 与活动窗口比较——派生而非存储（存储会在时钟对齐后不一致）。UI 显示秒数用 rAF/interval 驱动一个「本地 tick」，与 phase 分离（tick 高频不进 store，用 ref + 直接写 DOM 或节流到秒级进 store）。
- 边界语义：1) `active` 即将结束（<60s）加紧迫样式——时间阈值是展示层，不改状态语义；2) 结束瞬间（跨 phase 边界）的请求竞态——服务端以收到请求的时间为准，客户端在 phase 边界前后 1s 内发出的请求要容忍「请求被拒但 UI 显示 active」的不一致（提示「活动已结束」）。
- 多活动叠加：会场页多个活动倒计时共用一个 offset 与一个 tick——每个活动各自派生 phase，不要每活动一个 interval。
- 追问钩子：NTP 校时不可用的兜底——多次接口响应头 Date 的中位数估计 offset（单次网络延迟会引入 half-RTT 误差，取往返对称性修正）。

```javascript
// 时钟对齐 + 派生 phase
const useClock = create((set) => {
  let offset = 0        // serverTime - localNow
  let calibrated = false

  function calibrate(serverTs) {
    offset = serverTs - Date.now()
    calibrated = true
  }

  return {
    calibrated,
    now: () => Date.now() + offset,    // 服务端口径的当前时间
    sync: async () => {
      const res = await fetch('/api/time')             // 专用校时接口
      const rtt = performance.now()                    // half-RTT 修正
      const { serverTime } = await res.json()
      calibrate(serverTime + (performance.now() - rtt) / 2)   // 往返对称修正
    },
  }
})

// 活动状态派生
const activity = { startAt: ts1, endAt: ts2 }   // 服务端下发的时间戳
const phase = () => {
  const t = useClock.getState().now()
  return t < activity.startAt ? 'upcoming' : t < activity.endAt ? 'active' : 'ended'
}

// 倒计时组件：tick 不进 store
function Countdown() {
  const ref = useRef(null)
  useEffect(() => {
    const tick = () => {
      const remain = Math.max(0, activity.endAt - useClock.getState().now())
      ref.current.textContent = format(remain)      // 直接写 DOM：每秒一次
      if (remain <= 0) { queryClient.invalidateQueries({ queryKey: ['activity'] }); return }
      raf = requestAnimationFrame(() => setTimeout(tick, 1000 - (remain % 1000)))
    }
    let raf = requestAnimationFrame(tick)
    return () => cancelAnimationFrame(raf)
  }, [])
  return <div ref={ref} />
}

// 边界竞态：phase 边界的请求容忍
async function seckill(goodsId) {
  const res = await api.seckill(goodsId)
  if (res.code === 'ENDED') toast.info('手慢了，活动已结束')   // 服务端裁决
}
```
