## 983：并行状态与多个状态机之间的协调

**答**：
- 并行状态：一个流程的多条独立轨道同时进行（支付页：支付方式选择 + 优惠券选择并行——两个子状态互不干扰）——XState parallel 状态建模，避免「笛卡尔积爆炸」（两个布尔自由组合的 4 种状态扁平枚举）。
- 跨机器协调：机器 A 完成后触发机器 B（invoke + onDone）——父机器 invoke 子机器（审批流：资料审核机 -> 风控机 -> 终审机串行），子机失败父机进入异常分支。
- 协调的反模式：两个机器互相 send 事件（循环依赖）——协调方向单向（父调子/事件总线广播），双向协调说明建模边界错了（该合并成一个机器）。
- 追问钩子：什么时候拆多台机器什么时候并行状态？——同一实体的正交维度（支付+优惠券）用并行状态；不同实体的生命周期（订单机 vs 库存机）用独立机器 + 事件协调。

```ts
const payment = createMachine({
  type: 'parallel',
  states: {
    method: { initial: 'card', states: { card: {}, wallet: {} } },
    coupon: { initial: 'none', states: { none: {}, applied: {} } },
  },   // 2x2 组合由并行结构表达，不扁平枚举
});
// 父机器 invoke 子机器
const flow = createMachine({
  initial: 'audit',
  states: { audit: { invoke: { src: auditMachine, onDone: 'risk' } },
    risk: { invoke: { src: riskMachine, onDone: 'final', onError: 'rejected' } },
    final: {}, rejected: {} },
});
```
