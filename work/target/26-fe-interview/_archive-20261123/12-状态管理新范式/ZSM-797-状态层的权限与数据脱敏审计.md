## ZSM-797：状态层的安全审计：store 里的敏感数据清单与脱敏出口

**答**：
- store 是 XSS 的主要泄密面：任何 `__proto__` 污染、恶意扩展读取 window store、快照导出/日志都可能带出敏感数据。安全审计第一步是**敏感数据清单**：遍历所有 store 的字段，标注 `{ field, sensitivity: 'public'|'internal'|'pii'|'financial' }`——清单进 registry（ZSM-776），lint 检查「pii/financial 字段必须声明脱敏出口」。
- 脱敏出口三层：1) **持久化出口**——persist 的 partialize 白名单排除 pii（手机号/token 不落盘）；2) **日志/埋点出口**——统一 `sanitize()` 管道（字段名匹配敏感清单即 mask/hash），禁止直接 JSON.stringify 全量 store（ZSM-558/720 已内建）；3) **快照导出出口**——导出前脱敏管道 + 导出范围白名单（ZSM-561）。
- store 的访问控制：window 上暴露 store 只在 dev（ZSM-567）；生产如需远程调试走鉴权通道。**跨 iframe/postMessage 传 store 数据必须过脱敏管道**（消息可能被第三方 frame 接收）。
- 运行时防污染：外部输入进 store 前的 schema 校验（防 `__proto__/constructor` 键，ZSM-561 的 safeParse），不可信来源（URL 参数/第三方消息）进 store 必须走 sanitizer。
- 追问钩子：安全审计的「红队自查」——用 XSS 模拟脚本读 window store、读 localStorage persist、读 IndexedDB 队列，能拿到 pii 即不达标；这个自查进季度巡检（ZSM-784 的安全维度）。

```javascript
// 敏感数据清单与脱敏管道
const SENSITIVE_FIELDS = {
  userStore: { phone: 'pii', idCard: 'pii', balance: 'financial', token: 'pii', name: 'internal' },
  cartStore: { payAmount: 'financial' },
}
const MASK = { pii: (v) => v?.toString().replace(/.(?=.{2})/g, '*'), financial: (v) => '¥***', internal: (v) => v }

// 统一脱敏出口：所有日志/埋点/导出走这里
function sanitize(storeName, state, { level = 'log' } = {}) {
  const fields = SENSITIVE_FIELDS[storeName] ?? {}
  const out = {}
  for (const [k, v] of Object.entries(state)) {
    const s = fields[k]
    if (s && (level !== 'debug')) {
      out[k] = MASK[s](v)                    // mask/hash
    } else if (typeof v === 'object' && v) {
      out[k] = sanitize(storeName, v, { level })
    } else out[k] = v
  }
  return out
}

// persist 白名单（pii 不落盘）
persist((set) => ({...}), {
  name: 'user',
  partialize: (s) => {
    const { phone, idCard, token, ...safe } = s   // pii/financial 剔除
    return safe
  },
})

// 运行时防污染：外部输入 sanitizer
function safeAssign(store, input) {
  const clean = {}
  for (const [k, v] of Object.entries(input)) {
    if (['__proto__', 'constructor', 'prototype'].includes(k)) continue   // 原型污染拦截
    clean[k] = v
  }
  store.setState(clean)
}

// 红队自查（季度巡检项）
// simulateXSS: () => JSON.stringify(window.__stores.user.getState()) 含 phone 即不达标
```
