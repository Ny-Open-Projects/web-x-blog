## ZSM-389：场景题示范：多语言内容（富文本/UGC）的状态处理

**答**:
- 分类处理：UI 文案走 i18n 静态资源（构建期打包/按语言分包懒加载）；UGC 内容服务端存多语言版本，按 locale 参数请求（进 queryKey）；富文本嵌入翻译走占位符/段落映射而非拼 HTML
- 懒加载与回退：语言包按需加载（当前语言 + 回退链），切换时先加载完成再切换（loading 态防半译）；回退链（zh-TW→zh→en）在派生层实现
- 缓存联动：含语言的服务端数据 key 带 locale（ZSM-317）；富文本里的媒体路径与语言无关不重复缓存
- 展示一致性：数字/日期/复数规则用 Intl API（PluralRules/DateTimeFormat），不要手写 if else

```javascript
// 回退链派生
const t = (key) => {
  for (const l of [locale, ...fallbacks(locale)])
    if (bundles[l]?.[key]) return bundles[l][key]
  return key
}
// UGC 多语言
useQuery({ queryKey: ['article', id, locale], queryFn: fetchArticle })   // locale 进 key
```
