## ZSM-372：场景题示范：大促会场页（倒计时/秒杀/库存）状态设计

**答**:
- 时钟层：倒计时用「服务端时间基准 + 本地 rAF 推进」（offset 校准），不依赖本地钟；到期事件驱动按钮态转移
- 库存层：秒杀库存强一致域——点击时服务端裁决（预扣接口），前端按钮态由「预扣结果 + 低频轮询余量」驱动，不做本地乐观扣减的真相
- 状态收敛：活动阶段（预热/进行/结束）是 FSM，服务端时间驱动转移；阶段切换触发整页模块级失效
- 降级链：库存接口挂了 → 展示「最后已知 + 标记延迟」；推送断了 → 轮询兜底
- 面试结构：分层（时钟/库存/阶段）→ 每层真相源 → 竞态点（点击瞬间切换时刻）→ 降级

```javascript
// 服务端时间基准
const offset = serverTime - Date.now()
useEffect(() => { const id = setInterval(() => setNow(Date.now() + offset), 250); return () => clearInterval(id) }, [])
const stage = now < start ? 'PRE' : now < end ? 'LIVE' : 'END'    // FSM 阶段
// 秒杀：服务端裁决
const r = await api.preDeduct(skuId)
if (r.ok) navigate('/pay') else setSoldOut(true)
```
