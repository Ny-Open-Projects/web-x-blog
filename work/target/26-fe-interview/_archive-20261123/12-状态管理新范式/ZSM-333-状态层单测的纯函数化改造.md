## ZSM-333：状态层怎么改造成纯函数以便单测

**答**:
- 核心：把「变更逻辑」从「存储载体」剥离——reducer 式 `(state, action) => state` 纯函数，store 只做调度与通知；纯函数直接断言输入输出，无需实例化
- 依赖注入：时间（Date.now）、随机、storage 以参数传入或注入时钟，测试可控（fake timers 替代真等待）
- 表驱动测试：同域多个 action 用表格化用例（初始态/动作/期望态一行一条），覆盖率与可读性双高
- 集成层兜底：纯函数测试之外保留少量「store 实例 + hook」集成测试，验证订阅时序与通知行为

```javascript
// 纯 reducer
export function cartReducer(state, action) {
  switch (action.type) {
    case 'add': return { ...state, items: upsert(state.items, action.item) }
    case 'remove': return { ...state, items: state.items.filter((i) => i.id !== action.id) }
    default: return state
  }
}
// 表驱动
test.each([
  [{ items: [] }, { type: 'add', item: a }, { items: [a] }],
  [{ items: [a] }, { type: 'remove', id: a.id }, { items: [] }],
])('%#', (init, action, expect_) => expect(cartReducer(init, action)).toEqual(expect_))
```
