## ZSM-289：状态层要埋哪些可观测性指标

**答**:
- 健康类：Query 成功率/P95 耗时/重试率（queryCache 事件聚合）、mutation 失败率、乐观更新回滚率——直接反映接口与交互健康
- 性能类：store 高频 set 频次（疑似循环）、单次渲染订阅组件数（通知扇出）、persist 耗时——定位「状态引起卡顿」
- 行为类：undo/redo 使用频次、失效风暴计数（单位时间 invalidate 次数）、复水耗时（影响首屏）
- 落地：订阅 QueryCache/MutationCache 统一上报 + store 包装层埋点 + 采样率控制；关键指标进 SLO 看板

```javascript
queryCache.subscribe((e) => {
  if (e.type !== 'updated') return
  const a = e.action
  if (a?.type === 'success') perf('query_ok', { key: hashKey(e.query.queryKey), ms: Date.now() - a.ts })
  if (a?.type === 'error') report('query_fail', { key: hashKey(e.query.queryKey) })
})
```
