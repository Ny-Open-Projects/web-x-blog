## ZSM-285：多个状态源互相同步形成环怎么检测与打破

**答**:
- 症状：警告循环（Maximum update depth）、值闪跳、事件风暴；根因几乎都是「A watch B、B watch A」或「事件监听里又 emit 同一事件」
- 检测手段：同步写路径打点画依赖图（谁触发谁）、React 用 console.count 看更新次数、给关键 set 加环形告警（同一 tick 内 set 同一 store 超 N 次）
- 打破三板斧：确立单一真相源（其余变派生）、来源标记短路（广播带 origin）、值相等短路（幂等写入）
- 架构级预防：规定「数据只能从真相源流向派生方」的方向性规则，评审用工具扫描 watch-双向模式

```javascript
// 环形告警
let tickCount = 0
const origSet = store.setState
store.setState = (p) => {
  if (++tickCount > 10) throw new Error('possible sync loop')   // 同 tick 超 10 次
  queueMicrotask(() => (tickCount = 0))
  origSet(p)
}
```
