## ZSM-880：状态工程的三年技术雷达：采纳/试验/评估/暂缓

**答**:
- 把 900 张卡的技术按 ThoughtWorks 雷达四环归类（团队技术选型的制度化表达）：
- **采纳（Adopt，默认用）**：Zustand/Jotai 会话态、TanStack Query 缓存态、useSyncExternalStore 接线、幂等键/对账器模式、URL 事实源、乐观锁 baseVersion、预算门禁 CI、审计八问 PR 模板。
- **试验（Trial， Qualified 项目用）**：XState（流程复杂的模块）、Yjs（真并发编辑需求）、Valtio（高频 mutate 场景）、SharedWorker 中枢（多 tab 重度场景）、View Transition（视觉升级专项）、RRweb 双流回放（疑难 bug 排查）。
- **评估（Assess，关注别急用）**：React Compiler 全面启用的影响面、Signal 提案进 React 的可能、CRDT 服务端方案（Y-sweet 类）、AI 生成状态代码的一次通过率、原生 Navigation API 兼容面。
- **暂缓（Hold，别用）**：全局单一大 store（反模式 792）、渲染期写状态、Context 传高频状态、自研防撕裂 polyfill（用官方 API）、无淘汰策略的缓存 Map。
- 雷达的维护纪律：每季度巡检时同步评审「试验→采纳」「评估→试验」的晋升与降级，每次变动附一条实测证据（基准数据/事故复盘）——雷达没有证据不挪环。
- 追问钩子：雷达的「暂缓环」最有信息量——面试时主动讲「我们暂缓了 XX，理由是 YY，如果 ZZ 条件变化会重新评估」比罗列会用什么更显判断力。
