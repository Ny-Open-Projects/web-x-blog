## ZSM-251：微前端里哪些状态该共享哪些必须隔离

**答**：
- 共享层只放「平台级」状态：登录态/用户信息、主题/语言、全局路由、环境配置——由主应用单点持有并下发
- 隔离层放子应用自治状态：页面数据缓存、表单草稿、组件 state——隔离是防冲突与防泄漏（部署节奏不同、团队不同）
- 判断法：换个子应用这个状态还有意义吗？有 → 共享层；没有 → 隔离。灰色地带（如消息未读数）用事件推送而不是共享 store
- 红线：子应用之间不直连彼此的 store，一切跨应用交互经主应用的中转协议，否则形成网状依赖

```javascript
// 主应用持有共享层并下发
const shared = createGlobalState({ user, theme, locale })
qiankun.registerMicroApps(apps.map(a => ({ ...a, props: { shared, bus } })))
// 子应用：props.shared.sub(...) 订阅；自身业务状态用自己的 store
```
