## ZSM-741：多端通知的状态聚合：同源去重、优先级队列与已读联动

**答**：
- 通知的状态模型三层：**原始流**（WS 推送的通知事件，可能重复/乱序）、**聚合视图**（同类型合并：「3 人赞了你」）、**已读状态**（游标，ZSM-540 多端同步）。原始流按 `dedupeKey`（类型+目标 id）去重；聚合视图按规则折叠（同 key 5 分钟窗口内合并计数）。
- 优先级与展示策略：通知带 `priority: 'urgent'|'normal'|'low'`——urgent 立即 toast + 系统通知（Notification API，需授权状态管理），normal 进站内铃铛，low 只进列表。**展示决策**（要不要打断用户）也是状态：聚焦中/正在输入时降级为列表插入（不打断）。
- 已读联动：点击通知 → 本地标记已读 + 服务端游标上报（去抖）+ 其他端 BroadcastChannel/WS 同步；未读角标数是派生（`notifications.filter(n => n.seq > readCursor).length`），不单独存储。
- 过期与上限：通知列表环形上限（200 条，超出的持久化归档）、TTL（30 天自动归档）——聚合视图与原始流都要有上限，防长会话内存膨胀。
- 追问钩子：通知与 TanStack Query 的结合——通知中心列表走 useInfiniteQuery（分页加载），实时增量走 WS prepend（ZSM-646 推拉结合），已读游标变更 invalidate 未读数查询。

```javascript
// 通知聚合引擎
class NotificationHub {
  #raw = []                  // 原始流（环形）
  #aggregated = new Map()    // dedupeKey -> { count, latest, priority, seqs }
  #readCursor = 0
  #listeners = new Set()
  #MAX = 200

  receive(n) {
    // 去重：dedupeKey + seq
    const key = `${n.type}:${n.targetId}`
    if (this.#raw.some((x) => x.id === n.id)) return          // 重复推送
    this.#raw.push(n)
    if (this.#raw.length > this.#MAX) this.#raw.shift()

    // 聚合：同 key 5 分钟窗口合并
    const cur = this.#aggregated.get(key)
    if (cur && Date.now() - cur.latestAt < 5 * 60000) {
      cur.count++
      cur.latestAt = Date.now()
      cur.seq = Math.max(cur.seq, n.seq)
    } else {
      this.#aggregated.set(key, { count: 1, latest: n, latestAt: Date.now(), seq: n.seq, priority: n.priority })
    }
    this.#route(n)
    this.#notify()
  }

  // 展示路由：优先级 + 用户当前状态
  #route(n) {
    const busy = document.visibilityState === 'visible' && store.getState().typing
    if (n.priority === 'urgent' && !busy) {
      toast.urgent(n)
      systemNotify(n)          // Notification API（授权检查）
    } else if (n.priority === 'normal' && !busy) {
      toast.normal(n)
    }
    // busy / low：只进列表（不打断）
  }

  markRead(seq) {
    this.#readCursor = Math.max(this.#readCursor, seq)
    api.reportRead(this.#readCursor)                     // 多端游标上报
    channel.postMessage({ type: 'read', seq })           // 其他端同步
    this.#notify()
  }

  get unread() {
    return [...this.#aggregated.values()].filter((a) => a.seq > this.#readCursor).length   // 派生
  }

  #notify() { this.#listeners.forEach((fn) => fn({ list: this.list(), unread: this.unread })) }
  list() { return [...this.#aggregated.values()].sort((a, b) => b.seq - a.seq) }
}

// 系统通知的授权状态
async function systemNotify(n) {
  if (!('Notification' in window)) return
  let perm = Notification.permission
  if (perm === 'default') perm = await Notification.requestPermission()   // 需用户手势
  if (perm === 'granted') new Notification(n.title, { body: n.body, tag: n.dedupeKey })   // tag 防重复弹
}
```
