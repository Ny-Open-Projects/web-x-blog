## 1004：主应用向子应用注入权威数据的模式

**答**：
- 注入模式：主应用持有权威数据（用户/权限/字典），子应用通过「只读访问器」消费（inject({ getUser: () => authStore.user })——函数注入而非值拷贝，主应用数据更新子应用自动看到最新）。
- 值拷贝的坑：props 传对象值（子应用持有快照——主应用更新后子应用还是旧的=数据不一致）——快照仅在「明确冻结语义」时用（初始化配置）。
- 更新通知：权威数据变化时主应用广播（user.updated 事件）+ 子应用重新调用访问器——「访问器取最新 + 事件通知变化」双机制。
- 追问钩子：为什么用「函数注入」而不是「响应式对象共享」？——响应式共享把主应用的状态实现细节（用什么库/怎么组织）暴露给子应用（实现耦合）；函数注入只暴露「能力接口」（实现可自由演进）。

```ts
// 主应用注入访问器
mount(el, {
  getUser: () => authStore.getState().user,     // 函数注入：总是最新
  hasPerm: (p) => authStore.getState().perms.includes(p),
});
// 子应用消费：只读访问，禁止缓存快照（除非冻结语义）
const user = deps.getUser();
```
