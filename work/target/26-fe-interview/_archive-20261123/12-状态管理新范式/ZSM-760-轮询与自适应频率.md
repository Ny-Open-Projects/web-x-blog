## ZSM-760：轮询的自适应频率：按数据活跃度与页面状态动态调速

**答**：
- 固定频率轮询的浪费：数据不活跃时（无人协作/无变更）也全速拉。自适应策略三因子：1) **数据活跃度**——最近 N 次轮询数据无变化则降频（5s → 15s → 60s），有变化重置回基础频率；2) **页面状态**——隐藏页 10 倍降频或暂停（ZSM-585），聚焦时恢复；3) **服务端信号**——响应头带 `Retry-After` 或「服务端建议间隔」，尊重服务端负载意图。
- 实现：TanStack Query 的 `refetchInterval` 支持函数形式 `(query) => query.state.dataUpdatedAt 距今 < 活跃窗 ? 5000 : 60000`——按数据新鲜度调速；自定义轮询器则维护「频率档位表」+ 变更计数。
- 停止条件：轮询必须有**终止语义**——组件卸载停、会话过期停、资源关闭停（订单已完结不再轮询状态）。「永远在轮询」是最常见的隐形流量黑洞；配合「下次活跃时追平」（ZSM-727）替代持续轮询。
- 多轮询任务的协调：同页面多个轮询器各自 timer 会造成请求脉冲——统一调度器（单 timer 轮转各任务，间隔各自计算）或错峰（随机相位偏移）。
- 追问钩子：轮询 vs 长连接的成本分界——轮询成本 = 频率 × RTT × 服务器连接开销；当日均轮询请求 > 用户会话数的 100 倍时该上 WS/SSE。面试给出这个量化判断是加分点。

```javascript
// 自适应轮询调度器
class AdaptivePoller {
  #timer = null
  #idleCount = 0
  #paused = false
  constructor({ task, baseMs = 5000, ladder = [5000, 15000, 60000], idleThreshold = 3, hasChanged, isDone }) {
    this.task = task
    this.baseMs = baseMs
    this.ladder = ladder
    this.idleThreshold = idleThreshold
    this.hasChanged = hasChanged      // 判定数据是否有变化
    this.isDone = isDone              // 终止条件
  }

  start() {
    this.#schedule()
    document.addEventListener('visibilitychange', this.#onVisibility)
  }

  #onVisibility = () => {
    if (document.visibilityState === 'visible') {
      this.#paused = false
      this.#idleCount = 0             // 恢复聚焦：重置档位 + 追平
      this.#run(true)
    } else {
      this.#paused = true             // 隐藏：暂停（恢复时追平）
      clearTimeout(this.#timer)
    }
  }

  #schedule() {
    const ms = this.ladder[Math.min(this.#idleCount, this.ladder.length - 1)]
    this.#timer = setTimeout(() => this.#run(), ms)
  }

  async #run() {
    if (this.#paused || this.isDone()) return   // 终止语义
    try {
      const data = await this.task()
      if (this.hasChanged(data)) {
        this.#idleCount = 0                    // 有变化：回基础频率
      } else {
        this.#idleCount++                      // 无变化：降档
      }
    } catch {
      this.#idleCount = Math.max(0, this.#idleCount - 1)
    }
    this.#schedule()
  }

  stop() {
    clearTimeout(this.#timer)
    document.removeEventListener('visibilitychange', this.#onVisibility)
  }
}

// TanStack Query 版：refetchInterval 函数
useQuery({
  queryKey: ['order', id],
  queryFn: () => api.getOrder(id),
  refetchInterval: (query) => {
    const age = Date.now() - query.state.dataUpdatedAt
    return age < 30000 ? 5000 : age < 120000 ? 15000 : 60000    // 按新鲜度调速
  },
})
```
