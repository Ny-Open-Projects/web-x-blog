## ZSM-338：HTML 注入 / localStorage / 默认值三种初始化源的优先级设计

**答**:
- 优先级模型：本会话最新事实 > 本地缓存 > 静态默认。SSR 注入（HTML 内嵌 state）是「本会话最新」，优先于 localStorage；但要按域区分——会话性状态（用户信息）信注入，偏好性状态（主题/语言）信本地
- 冲突消解：同域数据带版本/时间戳，新者胜；注入与缓存数据 schema 不一致时缓存作废走默认
- 初始化时序：同步源（HTML 注入/localStorage）在 store 创建前完成，异步源（接口配置）通过 ready 门控（见 ZSM-282），禁止「创建后再偷偷补」
- 一致性验收：清缓存/带旧缓存/正常三种路径的启动状态快照回归

```javascript
// 优先级合成
const injected = window.__BOOTSTRAP__.user        // SSR 注入（会话态）
const stored = safeGet('user:v2')                 // 本地缓存
const user = injected?.v >= (stored?.v ?? 0) ? injected ?? DEFAULT : stored ?? DEFAULT
// 偏好态反转：主题信本地
const theme = stored('theme') ?? matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light'
```
