## ZSM-275：直播间（弹幕/礼物/在线人数）的状态流怎么设计

**答**:
- 分频分层：高频流（弹幕/礼物事件）走事件缓冲 + rAF 合帧渲染（每帧最多渲染一批），不进持久 store；低频态（房间信息/在线人数/主播状态）进 store 订阅
- 弹幕窗口用环形缓冲（固定长度 30 条），旧消息出队不保留——历史不该驻留内存
- WS 断线恢复：重连后先拉「房间当前快照」接口再续订阅事件流，避免事件流空洞；事件带 seq 号做连续性检测
- 观感一致性：礼物特效队列独立管理（优先级队列 + 播放上限），与数据流解耦

```javascript
let buffer = []
ws.onmessage = (e) => { buffer.push(JSON.parse(e.data)) }
function tick() {
  if (buffer.length) renderBatch(buffer.splice(0, 20))   // 每帧最多 20 条
  requestAnimationFrame(tick)
}
// 重连恢复
ws.onopen = async () => {
  const snap = await fetchRoomSnapshot(roomId)
  roomStore.setState(snap)          // 快照打底
  lastSeq = snap.seq                 // 事件流从 seq 续传
}
```
