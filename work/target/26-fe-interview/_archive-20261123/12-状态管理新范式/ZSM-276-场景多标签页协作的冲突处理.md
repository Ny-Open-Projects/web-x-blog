## ZSM-276：用户开了多个标签页改同一数据冲突怎么办

**答**:
- 先防再治：BroadcastChannel/storage 事件同步「谁在编辑 + 版本号」，后写覆盖前写前先比较版本，版本旧则提示合并/放弃
- 版本方案：乐观锁——客户端带 baseVersion 提交，服务端不等则 409，前端拉最新做三方合并或让用户决策
- 简单方案分级：低冲突域（设置项）「最后写入胜」+ 即时广播即可；高冲突域（文档编辑）上锁（编辑会话心跳 + 释放）或 CRDT
- 同步通道：BroadcastChannel 优先（结构化、即时），storage 事件兜底（跨兼容），IE 不在考虑范围

```javascript
const bc = new BroadcastChannel('doc-1')
bc.onmessage = ({ data }) => {
  if (data.version <= localVersion) return        // 旧版本忽略
  mergeRemote(data)
}
async function save(doc) {
  const res = await api.put(doc.id, { ...doc, baseVersion: localVersion })
  if (res.status === 409) promptConflict(await res.json())   // 拉最新三方合并
  else localVersion = (await res.json()).version
}
```
