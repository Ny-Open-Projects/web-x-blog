## ZSM-373：场景题示范：IM 消息列表的状态模型（幂等/已读/撤回）

**答**:
- 消息真相：客户端按会话缓存消息（Query 缓存 + 本地 pending 层）；服务端为真相；本地乐观消息带临时 id，确认后与真实 id 换绑
- 幂等与排序：消息带 seq/时间戳，渲染按 seq 排序；乱序到达按 seq 插入而不是追加；撤回是「标记 tombstone」更新不是物理删除
- 已读回执：会话维度 lastReadSeq（服务端真相），本地比较派生未读数——不要逐条消息存已读布尔
- 分页：向上拉历史（游标分页）+ 向下新消息（推送增量），两边在缓冲区汇合去重

```javascript
const pending = useStore((s) => s.pendingByConv[convId])    // 乐观层
const { data: msgs } = useQuery({ queryKey: ['conv', convId, cursor], queryFn: fetchMsgs })
const sorted = useMemo(() =>
  [...(msgs ?? []), ...pending].sort((a, b) => a.seq - b.seq), [msgs, pending])   // seq 排序
const unread = msgs.filter((m) => m.seq > lastReadSeq).length   // 派生
```
