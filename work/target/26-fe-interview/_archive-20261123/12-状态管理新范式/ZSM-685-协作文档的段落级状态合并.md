## ZSM-685：协作文档的段落级状态合并：块级 CRDT 何时够用、何时不够

**答**：
- 粒度选择是协同设计的第一决策：**块级**（段落/卡片为单元，LWW 或 op 合并）实现简单、性能好，适合「结构化文档」（笔记卡片、需求单、配置表）；**字符级**（Yjs/RGA）支持同段并发编辑，适合「富文本正文」。选块级的判据：同块内并发编辑的频率低（用户通常不编辑同一段落）。
- 块级合并的冲突语义：1) **新增**块——按创建时间戳/位置分数插入（无冲突）；2) **编辑**同块——LWW 丢一方的编辑（可接受的前提是编辑罕见冲突），或字段级 LWW（标题与正文分开判）；3) **删除** vs **编辑**——「删改冲突」需要提示用户（编辑后的内容被删了），不能静默裁决，这是块级方案唯一必须 UI 介入的点。
- 位置分数（fractional indexing）：块序用 rank 字符串（如 'a0','a1' 与中值 'a0V'）保证并发插入稳定排序，重排时 rebalance——比纯时间戳排序更符合「用户想要的顺序」。
- 服务端编排：块级方案常见架构是「服务端权威 + op 日志」：客户端发 block ops（upsert/delete/move），服务端按序应用并广播版本，客户端按版本 diff 对账（比完整 CRDT 简单一个量级）。
- 追问钩子：升级路径——块级方案遇到「同段落并发编辑变多」时，把单个块的内容替换为 Yjs Y.Text（块结构 LWW + 块内 CRDT 混合），这是石墨/语雀类产品的实际演进路线。

```javascript
// 块级文档引擎：op 日志 + 分数定位
class BlockDoc {
  blocks = new Map()          // blockId -> { content, rank, deleted, updatedAt }
  version = 0
  onOp = null                 // 服务端广播回调

  insert(content, prevId = null) {
    const prevRank = prevId ? this.blocks.get(prevId).rank : null
    const rank = fractionalBetween(prevRank, nextRankOf(prevId, this.blocks))
    const block = { content, rank, deleted: false, updatedAt: Date.now() }
    const id = crypto.randomUUID()
    this.blocks.set(id, block)
    this.commit({ op: 'insert', id, block, version: ++this.version })
    return id
  }

  edit(id, content, { force = false } = {}) {
    const b = this.blocks.get(id)
    if (!b) return
    if (b.updatedAt > Date.now() - 1000 && !force) {
      // 删改冲突标记：最近被编辑过且本端非最新 → 提示用户
      this.conflict = { id, local: content, remote: b.content }
      return
    }
    b.content = content
    b.updatedAt = Date.now()
    this.commit({ op: 'edit', id, content, version: ++this.version })
  }

  remove(id) { this.blocks.get(id).deleted = true; this.commit({ op: 'delete', id, version: ++this.version }) }

  commit(op) { this.onOp?.(op) }

  // 应用远端 op：LWW 按 updatedAt
  applyRemote(op) {
    if (op.op === 'edit') {
      const b = this.blocks.get(op.id)
      if (b && op.updatedAt > b.updatedAt) { b.content = op.content; b.updatedAt = op.updatedAt }
    }
    if (op.op === 'insert') this.blocks.set(op.id, op.block)
    if (op.op === 'delete') { const b = this.blocks.get(op.id); if (b) b.deleted = true }
    this.version = Math.max(this.version, op.version)
  }
}
```
