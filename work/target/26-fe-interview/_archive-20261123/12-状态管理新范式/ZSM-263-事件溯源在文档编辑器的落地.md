## ZSM-263：文档编辑器怎么做事件溯源式的时间旅行

**答**:
- 模型：文档 = 初始内容 + 操作流（insert/delete/format）的重放结果；撤销=回退到操作点，本质是逆操作或重建
- 落地：编辑器 op（ProseMirror Step/Quill Delta/ Slate Operation）即事件，历史栈存 op，undo 用库内置 invertStep/compose 生成逆 op
- 事件溯源的优势：op 流同时服务三个需求——撤销、协作同步（OT）、历史审计；一份事件三份价值
- 边界：离线编辑+网络插入会造成 op 交叉，需要 OT/CRDT 变换；纯客户端小协作量场景可用「服务端顺序号 + 前端变换」

```javascript
// Quill Delta 事件流与撤销
let doc = new Delta('hello')
const history = []
function apply(op) {
  history.push(op)
  doc = doc.compose(op)                       // 事件 → 状态
}
function undo() {
  const last = history.pop()
  doc = doc.compose(last.invert(doc))         // 逆 op（Quill/ProseMirror 均支持）
}
```
