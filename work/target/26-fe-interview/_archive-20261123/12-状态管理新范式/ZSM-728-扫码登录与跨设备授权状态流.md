## ZSM-728：扫码登录与跨设备授权的状态流：二维码轮询到确认的三段式

**答**：
- 扫码登录状态流：`qrcode_valid → scanned(手机端已扫，待确认) → confirmed → token_issued`，加上过期（180s 重新生成）与拒绝分支。三段式的关键是 **scanned 中间态**——「已扫待确认」给用户安全感（知道哪台设备扫的、设备名显示），防止「扫码即登录」被偷扫攻击。
- 轮询 vs 推送：桌面端轮询二维码状态（2s 间隔，带 qrcodeId）或 WS 订阅；二维码本身是「一次性授权票据」——内容为 `{ qrcodeId, nonce, expireAt }` 签名 payload，手机端扫码后调「确认接口」携带自身登录态，服务端把 qrcodeId 与用户会话绑定。
- 安全边界四条：1) 二维码与轮询接口绑定 IP/UA 弱校验（防止票据被猜）；2) 确认接口必须**手机端二次确认**（显示目标设备名/位置）而非扫码即通过；3) token 下发走一次性 code 交换（桌面端用 code 换 token，code 一次有效）；4) 过期二维码的轮询响应必须是明确的 `expired` 状态（前端刷新二维码），不返回用户信息。
- 前端状态机实现：轮询响应驱动迁移（`pending/scanned/expired/confirmed`），confirmed 后用 code 换 token（可能失败：code 已被用/过期——重试一次后回 valid 重新生成）。
- 追问钩子：跨设备授权与「设备管理」联动——confirmed 后新设备进设备列表（可远程下踢），下次该设备 token 被撤销时全端广播登出（ZSM-594）。

```javascript
import { setup, createActor } from 'xstate'

const qrLoginMachine = setup({
  actors: { poll: fromCallback(({ sendBack, input }) => {
    const timer = setInterval(async () => {
      const res = await api.qrStatus(input.qrcodeId)
      sendBack({ type: `POLL_${res.status.toUpperCase()}`, ...res })
    }, 2000)
    return () => clearInterval(timer)
  }) },
  delays: { qrExpire: 180000 },
}).createMachine({
  id: 'qrLogin',
  context: { qrcodeId: null, deviceInfo: null, code: null, retryCount: 0 },
  initial: 'generating',
  states: {
    generating: {
      invoke: { src: 'createQr', onDone: { target: 'valid', actions: assign({ qrcodeId: ({ event }) => event.output.id }) } },
    },
    valid: {
      invoke: { src: 'poll', input: ({ context }) => ({ qrcodeId: context.qrcodeId }) },
      after: { qrExpire: 'regenerating' },                        // 180s 过期兜底
      on: {
        POLL_SCANNED: { target: 'scanned', actions: assign({ deviceInfo: ({ event }) => event.device }) },
        POLL_EXPIRED: 'regenerating',
      },
    },
    scanned: {                                                    // 已扫待确认：显示设备名
      on: {
        POLL_CONFIRMED: 'exchanging',                             // 手机端二次确认后
        POLL_REJECTED: 'valid',                                   // 拒绝：回到待扫
        POLL_EXPIRED: 'regenerating',
      },
    },
    exchanging: {                                                 // code 换 token（可能失败）
      invoke: {
        src: 'exchangeToken',
        input: ({ context }) => context.code,
        onDone: 'done',
        onError: [
          { guard: ({ context }) => context.retryCount < 1, target: 'valid',
            actions: assign({ retryCount: ({ context }) => context.retryCount + 1 }) },
          { target: 'regenerating' },                             // code 失效：重新生成
        ],
      },
    },
    regenerating: { always: 'generating' },
    done: { type: 'final' },
  },
})
```
