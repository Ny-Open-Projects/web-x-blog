## ZSM-260：微前端状态共享方案怎么选（initGlobalState / 事件 / vanilla store）

**答**:
- 决策维度三问：需要回读最新值吗？需要精细粒度吗？需要持久化/中间件吗？——三问全否用事件总线；需要回读与粒度用 vanilla store 下发；仅一次性通知用事件
- initGlobalState 适合「主→子」简单下发；一旦子→主写入频繁，整树通知会放大渲染，应换带 selector 的 vanilla store
- vanilla store 下发是最通用形态：主应用创建实例，props 注入，各框架薄层适配；类型包版本化管契约
- 组合拳（推荐默认）：props 注入 vanilla store（状态）+ CustomEvent（事件）+ URL（跨应用上下文），三者各司其职

```javascript
// 选型速查
// 状态（回读+粒度）  → props 注入 vanilla store（zustand/vanilla）
// 事件（一次性通知） → bus.emit / CustomEvent
// 上下文（跨应用）   → URL search params
// 兜底兼容           → initGlobalState（简单下发）
```
