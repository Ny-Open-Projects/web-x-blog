## ZSM-682：表单联动的依赖图建模：字段间的显式依赖与环形依赖检测

**答**：
- 复杂表单联动（A 改变 B 的选项、B 改变 C 的校验规则、C 显隐 D）用手写 watch 链会失控——正确姿势是**依赖图**：每个字段声明 `dependsOn: string[]` + `compute(values)`，引擎按拓扑序重算受影响字段。
- 图的来源：声明式配置（schema 驱动表单的 `deps` 字段）比命令式 watch 好——可静态分析、可画图、可检测环。运行时也做兜底环检测（compute 内隐式依赖）。
- 联动重算规则：字段 A 变更 → 沿反向依赖边找下游 → 按拓扑序逐个跑 compute（上游新值可用）→ 下游 compute 可能返回 `{ value, options, disabled, visible }` 全量元数据——联动不只是值，还包括选项源与显隐。
- 值的清理：下游字段在上游变化后，旧值可能非法（「结束时间」依赖「开始时间」）——compute 返回 `reset: true` 时清空该字段并重跑校验；**清理要级联**（B 清了，依赖 B 的 C 也要清）。
- 环形依赖处理：静态检测报错（schema 期），运行时检测（compute 触发链超过 N 层）标记环并冻结参与字段，UI 提示配置错误——不能静默死循环。
- 追问钩子：这与 Jotai 的动态依赖 atom（ZSM-504）是同一模型——「表单引擎 = 特化的响应式依赖图」，理解一方就能理解另一方。

```javascript
function createFormGraph(fields) {
  // 环检测（DFS）
  function detectCycle() {
    const color = new Map(), stack = []
    const cycles = []
    function dfs(f) {
      color.set(f, 1); stack.push(f)
      for (const dep of fields[f].dependsOn ?? []) {
        if (color.get(dep) === 1) cycles.push([...stack.slice(stack.indexOf(dep)), dep])
        else if (!color.get(dep)) dfs(dep)
      }
      stack.pop(); color.set(f, 2)
    }
    Object.keys(fields).forEach((f) => { if (!color.get(f)) dfs(f) })
    return cycles
  }
  if (detectCycle().length) throw new Error('表单依赖成环: ' + detectCycle()[0].join('→'))

  function recompute(values, changedField) {
    const next = { ...values }
    const visited = new Set([changedField])
    // 拓扑序（Kahn）：按 dependsOn 分层
    const order = topoSort(Object.keys(fields))
    for (const f of order) {
      if (f === changedField) continue
      const conf = fields[f]
      if (!(conf.dependsOn ?? []).some((d) => visited.has(d))) continue
      const meta = conf.compute?.(next) ?? {}
      if (meta.reset) next[f] = conf.type === 'array' ? [] : ''
      if (meta.options) next[`${f}__options`] = meta.options
      if (meta.visible === false) next[f] = ''
      visited.add(f)
    }
    return next
  }

  function topoSort(keys) {
    const indeg = new Map(keys.map((k) => [k, 0]))
    keys.forEach((k) => (fields[k].dependsOn ?? []).forEach((d) => indeg.set(k, (indeg.get(k) ?? 0) + 1)))
    const q = keys.filter((k) => indeg.get(k) === 0)
    const out = []
    while (q.length) {
      const k = q.shift(); out.push(k)
      keys.forEach((f) => { if ((fields[f].dependsOn ?? []).includes(k) && --indeg.get(f) === 0) q.push(f) })
    }
    return out
  }

  return { recompute, detectCycle }
}

// 用例
const graph = createFormGraph({
  start: { type: 'date', dependsOn: [] },
  end: { type: 'date', dependsOn: ['start'], compute: (v) => v.start && v.end < v.start ? { reset: true } : {} },
  duration: { type: 'number', dependsOn: ['end'], compute: (v) => ({ value: diffDays(v.start, v.end) }) },
})
function diffDays(a, b) { return 2 }
const v = graph.recompute({ start: '2026-03-10', end: '2026-03-01', duration: 0 }, 'start')
console.log(v.end === '' && v.duration === 2)   // end 被级联清空后 duration 重算
```
