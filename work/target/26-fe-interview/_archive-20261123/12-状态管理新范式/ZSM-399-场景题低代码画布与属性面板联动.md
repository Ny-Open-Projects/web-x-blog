## ZSM-399：场景题示范：低代码平台画布与属性面板双向联动状态

**答**:
- 单一真相：组件树 schema 是唯一事实（归一化 Map + 树结构），画布渲染与属性面板都是它的投影——双向联动是两个消费者，不是双向同步
- 选中态：selectedId 单独存（轻量），画布点击与面板聚焦都只改它；hover 预览走 ephemeral（不进 undo 历史）
- 编辑协议：属性面板改 schema → 画布重渲染；画布拖拽 → 影子位置即时反馈 → drop 时 commit schema（进 undo 栈）
- 校验与锁：多人编辑时节点级锁（编辑中节点他人禁改提示）；schema 变更经过校验器（防坏数据进渲染）

```javascript
const schemaAtom = atom({ nodes: new Map(), root: 'root' })    // 唯一真相
const selectedId = atom(null)                                   // 轻量选中
onPropChange: (id, key, value) => {
  const next = validate(schemaWith(id, key, value))
  commitSchema(next)          // 进 undo 栈 → 画布自动重渲染（同一真相投影）
}
```
