## ZSM-748：多端文件协同：上传冲突的版本树与「快照点」语义

**答**：
- 文件（图片/文档附件）的多端并发上传冲突与文本不同：无法逐字合并，只能**版本分叉 + 用户裁决**。版本树模型：每次上传产生节点 `{ versionId, parentId, device, hash }`；两个端基于同一 parent 各自上传 → 服务端发现分叉，创建 merge-request 态（不是自动选一方）。
- 裁决策略三级：1) **内容 hash 相同**（两端传了完全一样的文件）→ 自动合并（去重，白得）；2) **一方是另一方的前缀/子集**（如追加型文件：日志/录音）→ 自动合并为「并集」（追加语义需文件类型声明）；3) **真分叉** → 用户选（保留哪版/两者都保留为 vA、vB）——设计文档类必须人工裁决。
- 「快照点」语义：客户端上传时带 `baseVersion`（基于哪个版本改的），服务端用 baseVersion 判断快进（fast-forward：base 是当前最新 → 直接追加）还是分叉——这是乐观锁思想在文件域的落地，与 ZSM-588 的 baseVersion 同构。
- 分片上传与冲突的交互：分片上传中途冲突（他人先完成）——继续传完自己的分片（带宽不浪费），最后在「提交合并」阶段裁决，而不是中途放弃。
- 追问钩子：文件冲突的 UX 表达——版本树可视化（时间轴上分叉标记）+ 预览对比（并排显示两版缩略图）比「冲突弹窗」体验好一个量级；冲突是常态（多人协作）不是异常，UI 不该用报错口吻。

```javascript
// 文件版本树与冲突裁决
class FileVersionTree {
  #nodes = new Map()        // versionId -> { parentId, device, hash, status }
  #head = null              // 当前最新版本
  #listeners = new Set()

  async upload(file, { baseVersion, device }) {
    const hash = await sha256(file)
    // 1) 内容相同：自动合并
    const dup = [...this.#nodes.values()].find((n) => n.hash === hash && n.status === 'committed')
    if (dup) return { merged: true, versionId: dup.id }

    // 2) 快进判定：base 是当前 head → 直接提交
    const isFastForward = !this.#head || baseVersion === this.#head
    if (isFastForward) {
      const id = this.#commit(file, baseVersion, device, hash)
      return { committed: true, versionId: id }
    }

    // 3) 分叉：创建 pending 节点等用户裁决
    const id = crypto.randomUUID()
    this.#nodes.set(id, { id, parentId: baseVersion, device, hash, status: 'pending', file })
    this.#notify({ type: 'conflict', pendingId: id, head: this.#head, base: baseVersion })
    return { conflicted: true, pendingId: id }
  }

  // 用户裁决：保留 A / 保留 B / 都保留
  resolve(pendingId, action) {
    const node = this.#nodes.get(pendingId)
    if (action === 'keep-mine') {
      node.status = 'committed'
      this.#head = pendingId                       // 我的版本成为新 head
    } else if (action === 'keep-theirs') {
      node.status = 'discarded'                    // 丢弃我的
    } else if (action === 'keep-both') {
      node.status = 'committed'
      this.#head = pendingId                       // 并行两个版本都保留
    }
    this.#notify({ type: 'resolved', id: pendingId, action })
  }

  #commit(file, parentId, device, hash) {
    const id = crypto.randomUUID()
    this.#nodes.set(id, { id, parentId, device, hash, status: 'committed' })
    this.#head = id
    return id
  }

  #notify(e) { this.#listeners.forEach((fn) => fn(e)) }
}
```
