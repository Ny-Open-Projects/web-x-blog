## XP-374：跨端滚动加载的触底判定与防重复

**答**：
- 判定：滚动接近底部（阈值 200px）触发加载；防重复：loading 状态锁 + 无更多标记。
- 跨端：小程序 onReachBottom/RN onEndReached/H5 scroll 监听（rAF）。
- 体验：加载中底部骨架、无更多提示、失败重试按钮。

```javascript
// 触底加载
function infiniteScroll(el, loadMore, { threshold = 200 } = {}) {
  let loading = false, hasMore = true;
  return onScrollThrottled(el, async () => {
    if (loading || !hasMore) return;
    const nearBottom = el.scrollHeight - el.scrollTop - el.clientHeight < threshold;
    if (!nearBottom) return;
    loading = true;
    try {
      const items = await loadMore();
      hasMore = items.length > 0;
    } finally { loading = false; }
  });
}
```
