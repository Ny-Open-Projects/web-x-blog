## XP-269：跨端容器专项：热更新差量包计算（笔试）

**答**：
- 题目：热更新差量包——新旧 bundle diff（模块级 hash 对比）→ 生成差量包（只含变更模块）→ 客户端合并。
- 思路：模块级 diff（模块 hash 对比，变更模块打包）→ 差量包 manifest → 客户端合并（旧包 + 差量 → 新包）；完整性校验。
- 评分点：模块级 diff；差量包结构；合并校验。

```javascript
function generateDiffPackage(oldBundle, newBundle) {         // 差量包生成
  const oldHashes = new Map(oldBundle.modules.map(m => [m.id, m.hash]));
  const changed = newBundle.modules.filter(m => oldHashes.get(m.id) !== m.hash);   // 变更模块
  const added = newBundle.modules.filter(m => !oldHashes.has(m.id));
  return {
    version: newBundle.version,
    base: oldBundle.version,                                    // 基础版本
    modules: [...changed, ...added],                             // 只含变更/新增
    removed: oldBundle.modules.filter(m => !newBundle.modules.find(n => n.id === m.id)).map(m => m.id),
    signature: sign(changed),                                     // 签名
  };
}
// 客户端合并：旧包 + 差量 → 新包（校验新包整体 hash）
// 体积：全量 5MB → 差量 200KB（只改 3 个模块）
```
