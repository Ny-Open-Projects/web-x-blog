## XP-329：跨端定位能力的性能与功耗

**答**：
- 策略：精度分档（高精 GPS/网络定位/城市级 IP），按需请求；连续定位用系统级（前台服务）。
- 缓存：上次位置短期复用（2 分钟内），避免重复请求。
- 降级：定位失败/超时（3s）用默认城市 + 手动选择提示。

```javascript
// 定位分档
async function locate({ accuracy = 'city', timeoutMs = 3000 } = {}) {
  const cached = lastLocation;
  if (cached && Date.now() - cached.at < 120_000) return cached;   // 2min 缓存
  const p = adapterLocate(accuracy);                 // gps/city
  const result = await Promise.race([p,
    sleep(timeoutMs).then(() => null)]);
  if (result) lastLocation = { ...result, at: Date.now() };
  else report({ type: 'locate-fallback', note: '超时用默认城市' });
  return result ?? DEFAULT_CITY;
}
```
