## XP-278：跨端容器专项：多端发布协调（Web/RN/小程序 同步发版）（笔试）

**答**：
- 题目：多端同步发版——同一业务功能在 Web/RN/小程序同步上线，各端发布节奏不同（Web 即时/RN 热更/小程序审核）——发布协调方案。
- 思路：功能 flag 统一控制（服务端下发）→ 各端独立发版但 flag 统一开——Web 即时生效/RN 热更/小程序过审后 flag 开。
- 评分点：flag 统一；节奏差异处理；灰度协调。

```javascript
class MultiPlatformRelease {
  async releaseFeature(featureName) {                          // 多端发版协调
    // 各端独立发版（代码到位），但 flag 统一控制
    await webDeploy(featureName);                                // Web：即时
    await rnCodePush(featureName);                                // RN：热更（1h 生效）
    await mpUpload(featureName);                                   // 小程序：提审（1~7 天）
    // flag 不开——等所有端就绪
    await waitForAllReady([webReady, rnReady, mpApproved]);       // 小程序过审
    await enableFlag(featureName);                                 // 统一开启
  }
  partialRelease(featureName, platforms) {                       // 部分端先行
    platforms.forEach(p => enableFlagForPlatform(featureName, p));   // 按端开 flag
    // 小程序后到 → 后开（不影响已上线端）
  }
}
```
