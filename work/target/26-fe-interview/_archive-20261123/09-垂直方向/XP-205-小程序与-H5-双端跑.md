## XP-205：小程序与 H5 双端跑：Taro/uni-app 编译差异

**答**：
- Taro/uni-app：一套代码编译到小程序/H5/RN——编译时适配（模板语法转换）vs 运行时适配（运行时适配层）。
- Taro 3：运行时方案（React 在小程序跑——模拟 DOM/BOM → setData 渲染）；uni-app：编译时为主（Vue 模板 → WXML）。
- 取舍：运行时灵活（完整 React 生态）但性能损耗（模拟层）；编译时性能好但框架受限。

```javascript
const taroVsUniapp = {
  taro3: { approach: '运行时（React reconciler → 小程序指令）',
    perf: '有模拟层损耗（VDOM diff → setData）',
    ecosystem: '完整 React 生态（hooks/状态库全兼容）',
    fit: 'React 团队 / 复杂交互' },
  uniapp: { approach: '编译时（Vue 模板 → WXML）',
    perf: '编译产物接近原生小程序（无模拟层）',
    ecosystem: 'Vue 生态（编译时转换，部分 API 不支持）',
    fit: 'Vue 团队 / 常规业务' },
  decision: 'React 生态 → Taro3；Vue + 性能敏感 → uni-app 编译时',
};
// Taro3 运行时原理：react-reconciler → Taro DOM（模拟树）→ diff → setData（HW-155 关联）
```
