## XP-174：跨端容器多主题：暗色模式跨端一致

**答**：
- 题目：跨端暗色主题——JS 侧主题 token 下发 → Native 侧样式应用；系统主题变化监听（跟随系统）→ 热切换。
- 思路：token 下发（CSS 变量思维：颜色/间距/圆角）→ Native 样式表应用；systemTheme 变化事件 → 热切换（不重启）；一致性：所有颜色经 token（无硬编码）。
- 评分点：token 下发；热切换；硬编码扫描。

```javascript
class ThemeManager {
  async apply(themeName) {                                   // 主题应用
    const tokens = await fetchTokens(themeName);              // token 集
    bridge.commit([{ op: 'set-theme', tokens }]);              // Native 侧批量应用
    this.current = themeName;
  }
  followSystem() {                                            // 跟随系统
    nativeBridge.onSystemThemeChange((system) => {
      this.apply(system === 'dark' ? 'dark' : 'light');
    });
  }
}
// 一致性保障：lint 扫描业务代码——不允许硬编码颜色（必须用 token 引用）
// CI 规则：grep '#[0-9a-f]{6}' 业务代码 → 报错（强制走 token）
```
