## XP-172：跨端容器与原生混合动画：共享元素过渡

**答**：
- 共享元素过渡：列表页点击图片 → 详情页同一图片放大过渡——Native 侧共享元素 API（Android SharedElement/iOS Hero）。
- 容器场景：JS 侧声明共享元素（相同 transitionId）→ Native 侧执行过渡动画（JS 不参与动画帧）。
- 关键：过渡期间 Native 渲染，JS 只发「进入过渡」指令与目标页数据。

```javascript
// JS 侧声明共享元素
class SharedElementTransition {
  push(route, sharedElements) {                              // sharedElements: [{id, nodeId}]
    bridge.commit([
      { op: 'setTransition', route, sharedElements: sharedElements.map(se => ({
        transitionId: se.id, nodeId: se.nodeId })) },         // Native 记录共享元素
      { op: 'push', route },                                   // Native push（动画由 Native 执行）
    ]);
  }
}
// Native 侧：路由切换时检测 transitionId 匹配 → 执行位移动画（图片从列表位置飞到详情位置）
// JS 不参与动画帧——性能好且流畅（Native 动画不受 JS 阻塞影响）
```
