## XP-267：跨端容器专项：容器与小程序页面栈差异（笔试）

**答**：
- 题目：小程序页面栈上限（10 层）与容器差异——写「栈深管理」方案（页面栈满时提示/替换/回退）。
- 思路：栈满检测（getCurrentPages().length >= 10）→ 策略：redirectTo 替换当前页（栈不增）/ 回退 N 页再 push；用户提示。
- 评分点：栈满检测；三种策略；用户体验。

```javascript
function navigateWithStackLimit(url) {                       // 栈深管理
  const pages = getCurrentPages();
  if (pages.length >= 10) {                                     // 栈满（10 层上限）
    const depth = pages.length - pages.findIndex(p => p.isTabBar ?? false);
    if (depth >= 8) {                                            // 深层：替换当前页
      wx.redirectTo({ url });                                    // 栈不增长
      showToast('页面层级过深，已替换当前页');
      return;
    }
    wx.navigateBack({ delta: 5 });                               // 回退 5 层再 push
  }
  wx.navigateTo({ url });
}
// 体验：redirectTo 快但丢返回路径——交互链路用 navigateBack + navigateTo
```
