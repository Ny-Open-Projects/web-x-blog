## XP-175：跨端容器离线能力：离线包与请求拦截

**答**：
- 容器离线：静态资源离线包（HW-788 复用）+ API 请求拦截（离线缓存/队列）——离线包拦截由 Native 侧执行（URL → 本地文件）。
- API 离线：读接口缓存（最后响应）；写接口队列（HW-336 离线同步复用）；恢复后重放。
- 架构：Native 拦截层（URL 请求 → 离线包/缓存判断）→ 命中直接返回本地，未命中走网络。

```javascript
class OfflineInterceptor {                                   // Native 侧拦截
  intercept(url, method, body) {
    if (method === 'GET') {
      const cached = this.apiCache.get(url);                   // 读缓存
      if (cached && !this.isExpired(cached)) return cached;     // 命中：离线返回
    }
    if (method === 'POST' && !this.isOnline()) {
      this.writeQueue.push({ url, body, ts: Date.now() });      // 写接口离线队列
      return { queued: true };                                   // 立即返回排队状态
    }
    return null;                                                 // 未命中：走网络
  }
  onRecover() {                                                  // 恢复：重放写队列
    this.writeQueue.forEach(item => this.replay(item));
    this.writeQueue = [];
  }
}
```
