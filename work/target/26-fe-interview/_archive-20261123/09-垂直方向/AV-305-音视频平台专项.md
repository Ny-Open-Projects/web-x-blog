## AV-305：音视频平台专项：媒体文件安全扫描

**答**：
- 题目：用户上传视频/音频安全扫描——格式校验（魔数）、恶意构造防御（解码炸弹）、内容审核（NSFW/版权）。
- 思路：魔数校验（文件头字节）；解码炸弹防御（分辨率/时长上限预检 metadata）；内容审核异步（转码管线内嵌审核节点）。
- 评分点：魔数校验；资源限制预检；异步审核。

```javascript
async function scanMediaFile(file) {
  // 1. 魔数校验（防伪装扩展名）
  const header = await file.slice(0, 16).arrayBuffer();
  const magic = new Uint8Array(header).slice(4, 8);
  if (String.fromCharCode(...magic) !== 'ftyp') throw new Error('not-mp4');
  // 2. metadata 预检（防解码炸弹：超大分辨率/超长时长）
  const meta = await probeMetadata(file);                    // ffprobe 类
  if (meta.width * meta.height > 8294400) throw new Error('resolution-too-high');   // >4K
  if (meta.duration > 7200) throw new Error('duration-too-long');
  // 3. 异步内容审核（不阻塞上传，审核不通过下架）
  enqueueReview({ fileId: file.id, nsfw: true, copyright: true });
  return { accepted: true, reviewId: taskId };
}
```
