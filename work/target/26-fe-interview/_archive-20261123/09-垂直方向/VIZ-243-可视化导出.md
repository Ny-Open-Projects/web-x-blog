## VIZ-243：可视化导出：静态图导出（PNG/SVG）与分辨率

**答**：
- 导出 PNG：Canvas.toBlob（DPI 缩放重绘）；SVG 导出：序列化 SVG DOM（内嵌字体处理）。
- DPI 导出：离屏 canvas 2x/3x 重绘 → 下载（报告场景）。
- WebGPU 场景导出：canvas.toBlob 直接取当前帧（preserveDrawingBuffer 类问题——WebGPU 需在渲染后立即导出或重渲）。

```javascript
async function exportChartPNG(chart, { dpi = 2 } = {}) {
  const off = document.createElement('canvas');
  off.width = chart.width * dpi; off.height = chart.height * dpi;   // DPI 缩放
  chart.renderTo(off.getContext('2d'), { scale: dpi });     // 离屏重绘（非截图）
  return new Promise(r => off.toBlob(r, 'image/png'));
}
async function exportWebGPUFrame(canvas) {
  // WebGPU：canvas 内容在提交后有效——渲染后立即导出，或加专门导出 pass
  return new Promise(r => canvas.toBlob(r, 'image/png'));
}
// SVG 导出坑：字体不内嵌 → 接收方缺字；嵌入 font-face base64 或转曲线路径
```
