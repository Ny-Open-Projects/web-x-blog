## XP-340：跨端性能预算的端维度设定

**答**：
- 预算：每端独立预算（小程序主包 2MB/RN bundle 3MB/H5 首屏 JS 300KB）。
- 指标预算：启动 P75/滚动掉帧/内存峰值分端阈值。
- 执行：CI 门禁 + 运行时采样告警双轨。

```javascript
// 端预算表
const END_BUDGETS = {
  h5: { jsKB: 300, ttiMs: 2500, memMB: 200 },
  miniprogram: { mainPkgKB: 2048, ttiMs: 2000, memMB: 150 },
  rn: { bundleKB: 3000, ttiMs: 2200, memMB: 250 },
  flutter: { appSizeKB: 8000, ttiMs: 1800, memMB: 200 },
};
function budgetCheck(end, actual) {
  const b = END_BUDGETS[end];
  return Object.entries(b).filter(([k, v]) => actual[k] > v)
    .map(([k]) => ({ metric: k, over: actual[k] - v }));
}
```
