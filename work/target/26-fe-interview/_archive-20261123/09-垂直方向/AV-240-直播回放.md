## AV-240：直播回放：录制切片与点播转码

**答**：
- 直播结束 → 录制文件（SFU/CDN 录制）→ 转码多清晰度（1080p/720p/480p）→ 切片 HLS → 点播上线。
- 前端关注：回放进度条（含精彩时刻标记）、倍速播放、seek 到任意时间（分片索引）。
- 精彩时刻：AI 剪辑（高弹幕时段/礼物高峰）→ 前端进度条章节标记。

```javascript
class ReplayViewer {
  constructor(recording) {
    this.player = attachHLS(recording.hlsUrl);               // 点播 HLS
    this.chapters = recording.highlights;                    // 精彩时刻 [{ts, label}]
  }
  renderProgress() {                                         // 进度条 + 章节标记
    this.chapters.forEach(c => this.progress.mark(c.ts, c.label));
  }
  seekTo(ts) { this.player.currentTime = ts; }               // HLS 分片自动定位
  setSpeed(v) { this.player.playbackRate = v; }               // 倍速（音调不变：preservesPitch）
}
// 精彩时刻来源：弹幕密度峰值（滑动窗口计数 TopN）+ 礼物事件聚簇
```
