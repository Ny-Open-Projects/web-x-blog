## AV-279：音视频场景专项：在线教育连麦课堂

**答**：
- 在线教育连麦：老师推流（大屏课件+人像画中画）→ 学生举手连麦（申请-批准-上线）→ 学生发言时全班可见。
- 实现：课件层（白板/ PPT）与人像层分离渲染；学生连麦走 SFU（老师订阅学生上行）；课堂纪律（静音全体/单个）。
- 延迟容忍：课件延迟可 1~2s（非互动），人像音频需 300ms——分层延迟策略。

```javascript
class ClassroomSession {
  async raiseHand() { this.signaling.send('raise-hand', { peerId: this.peerId }); }
  async approveStudent(studentId) {                          // 老师批准连麦
    await this.signaling.send('approve', { studentId });
    // SFU 开始转发学生流 → 老师订阅 → 全班订阅
  }
  muteAllStudents() { this.signaling.broadcast('mute-all'); }   // 全员静音
  layout() {                                                  // 分层渲染
    return { whiteboard: '底层（SVG/Canvas 课件）',
      teacher: '画中画（右上角 20% 区域）',
      student: '连麦学生（发言时中央切换）',
      latency: { whiteboard: '1~2s 可容忍', audio: '300ms 必须' } };
  }
}
```
