## XP-361：跨端通知权限的前置引导策略

**答**：
- 时机：价值场景后请求（订阅成功后问通知权限），而非启动即弹（拒绝率高）。
- 状态：拒绝后引导到系统设置（深度链接），记录引导次数（防骚扰）。
- 度量：授权率分端统计 + 引导路径转化。

```javascript
// 通知权限引导
async function notificationFlow(trigger) {
  const state = await adapter.query('notification');
  if (state === 'granted') return { ok: true };
  if (state === 'denied') {
    if (this.guideCount < 1) showSystemSettingGuide();
    return { ok: false };
  }
  if (trigger === 'subscribe-success') return adapter.request('notification');  // 价值后请求
  return { ok: false, note: '等待价值场景' };
}
```
