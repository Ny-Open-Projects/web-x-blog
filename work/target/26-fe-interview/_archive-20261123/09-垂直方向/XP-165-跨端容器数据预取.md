## XP-165：跨端容器数据预取：路由级预取与缓存

**答**：
- 路由级数据预取：路由注册时声明数据依赖 → 手势/点击前兆触发预取（HW-862 三层预加载复用）→ 页面到达时数据就绪。
- 缓存：页面数据按路由参数缓存（LRU+TTL）；返回时命中缓存秒显（SWR，HW-836 复用）。
- 收益：页面首帧数据等待从 500ms → 0。

```javascript
class RoutePrefetch {
  register(route, { fetchData, prefetchTrigger = 'hover' }) {   // 路由注册
    this.routes.set(route, { fetchData, prefetchTrigger });
  }
  onPrefetchTrigger(route, params) {                          // 前兆触发
    const r = this.routes.get(route);
    const key = route + JSON.stringify(params);
    if (!this.cache.has(key)) {
      this.cache.set(key, r.fetchData(params));                // 异步预取（Promise 缓存）
    }
  }
  async navigate(route, params) {                              // 到达时取缓存
    const key = route + JSON.stringify(params);
    const cached = this.cache.get(key);
    if (cached) {
      const data = await cached;                               // 预取已完成：秒显
      this.cache.delete(key);                                   // 用后即弃
      return { data, fromCache: true };
    }
    return { data: await this.routes.get(route).fetchData(params), fromCache: false };
  }
}
```
