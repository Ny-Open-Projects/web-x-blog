## VIZ-382：着色器中的常用数学内置函数速查与等价实现

**答**：
- mix/smoothstep/clamp/step 是 shader 数学四件套；smoothstep(edge0, edge1, x) = 3t²-2t³ 的 Hermite 平滑。
- 长度/距离/归一化在 JS 侧对应 hypot；fract/mod 用于网格 UV 与循环动画。
- 自实现要点：JS 版本与 GLSL 行为一致（如 smoothstep 在 edge0==edge1 时除零需防护）。

```javascript
// GLSL 数学的 JS 对应
const mix = (a, b, t) => a + (b - a) * t;
const clamp = (x, a, b) => Math.min(b, Math.max(a, x));
const step = (e, x) => x < e ? 0 : 1;
function smoothstep(e0, e1, x) {
  if (e0 === e1) return x < e0 ? 0 : 1;
  const t = clamp((x - e0) / (e1 - e0), 0, 1);
  return t * t * (3 - 2 * t);
}
const fract = (x) => x - Math.floor(x);
// 应用：网格线
// grid = smoothstep(0.98, 1.0, Math.max(fract(uv.x * 10), fract(uv.y * 10)))
```
