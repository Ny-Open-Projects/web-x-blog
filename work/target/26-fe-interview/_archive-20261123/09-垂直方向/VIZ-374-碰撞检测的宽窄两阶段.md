## VIZ-374：碰撞检测的宽窄两阶段

**答**：
- 宽阶段：AABB/球粗判（空间剖分加速），筛出候选对；窄阶段：精确几何（GJK/三角形相交）。
- 成本分布：宽阶段决定 O(n²)→O(n) 的量级；窄阶段精度决定穿透感。
- 连续碰撞检测（CCD）：高速物体用扫掠 AABB 防隧穿。

```javascript
// 两阶段碰撞
function broadPhase(items, grid) {                 // 358 网格
  const pairs = new Set();
  for (const it of items)
    for (const o of grid.query(it.x, it.y, it.r))
      if (o !== it && it.id < o.id)
        pairs.add(`${it.id}|${o.id}`);
  return [...pairs];
}
function narrowPhase(a, b) {                       // 圆-圆精确
  const d = Math.hypot(a.x - b.x, a.y - b.y);
  return d < a.r + b.r ? { depth: a.r + b.r - d, nx: (a.x-b.x)/(d||1), ny: (a.y-b.y)/(d||1) } : null;
}
// CCD：对高速物体在 t 与 t+dt 间扫掠 AABB 参与宽阶段
```
