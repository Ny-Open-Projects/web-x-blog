## XP-272：跨端容器专项：容器 JS 与 Native 双向通信竞态（笔试）

**答**：
- 题目：JS ↔ Native 双向通信竞态——JS 调 Native（异步回调）期间 Native 主动推事件 → 状态不一致。解决：操作序列号 + 状态版本。
- 思路：JS 调用带 seq → Native 回调带 seq（配对）；Native 主动推事件带 state version → JS 按版本应用（旧版本丢弃）。
- 评分点：seq 配对；版本化状态；竞态场景枚举。

```javascript
class RaceConditionFreeBridge {
  constructor() { this.seq = 0; this.pending = new Map(); this.stateVersion = 0; }
  call(method, args) {                                           // JS 调 Native
    const seq = ++this.seq;
    return new Promise((res, rej) => this.pending.set(seq, { res, rej }));
    // Native 回调带 seq → 配对 resolve（HW-250 复用）
  }
  onNativeEvent(event) {                                          // Native 主动推
    if (event.version < this.stateVersion) return;               // 旧版本：丢弃
    this.stateVersion = event.version;                            // 新版本：应用
    this.applyState(event.state);
  }
}
// 竞态场景：JS 调 native.setItem → 期间 Native 推 storage-change（旧值）→ JS 按版本丢弃旧推
```
