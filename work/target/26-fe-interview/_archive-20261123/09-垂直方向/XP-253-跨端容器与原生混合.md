## XP-253：跨端容器与原生混合：容器预渲染与 Native 导航（笔试）

**答**：
- 题目：容器页面预渲染——导航前预执行 JS + 预渲染 View（离屏），push 时直接展示（预渲染好的 View 树）。
- 思路：路由前兆（点击/hover）触发预渲染（离屏 View 树构建 + 数据预取）→ push 时直接挂载（无需等待）。
- 评分点：预渲染时机；离屏构建；挂载切换。

```javascript
class PreRenderedNavigation {
  onPrefetchSignal(route, params) {                              // 前兆触发
    const key = route + JSON.stringify(params);
    if (this.preRendered.has(key)) return;
    this.preRendered.set(key, (async () => {
      const data = await this.prefetchData(route, params);        // 数据预取
      const viewTree = await this.buildViewTree(route, data);      // 离屏 View 构建
      return viewTree;
    })());
  }
  async push(route, params) {                                     // 真正导航
    const key = route + JSON.stringify(params);
    const viewTree = await (this.preRendered.get(key) ?? this.buildFresh(route, params));
    bridge.commit([{ op: 'push-prebuilt', route, tree: viewTree }]);   // 直接挂载预渲染树
    this.preRendered.delete(key);
  }
}
// 收益：页面首帧 500ms → 50ms（预渲染已完成）
```
