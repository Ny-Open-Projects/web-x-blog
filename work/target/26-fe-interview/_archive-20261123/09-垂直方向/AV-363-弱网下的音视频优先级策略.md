## AV-363：弱网下的音视频优先级策略

**答**：
- 原则：音频优先（断续最伤体验），视频可降可停——WebRTC 编码器带宽分配音频保底。
- 策略：带宽 < 100kbps 只保音频（视频暂停/黑屏）；< 50kbps 切纯语音模式 UI 提示。
- 实现：sender.setParameters 降视频 maxBitrate，接收端 UI 状态机切换。

```javascript
// 弱网分档
function weakNetPolicy(kbps, current) {
  if (kbps >= 500) return { video: 'normal', audio: 'normal' };
  if (kbps >= 150) return { video: 'low', audio: 'normal',
    note: '视频降档' };
  if (kbps >= 60) return { video: 'paused', audio: 'normal',
    note: '停视频保语音' };
  return { video: 'paused', audio: 'reconnect',
    note: '极端弱网：提示切换网络' };
}
```
