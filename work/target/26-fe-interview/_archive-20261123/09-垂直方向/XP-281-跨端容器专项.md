## XP-281：跨端容器专项：容器灰度发布指标哨兵自动回退（笔试）

**答**：
- 题目：容器灰度发布自动回退——灰度组指标（崩溃/白屏/首帧）对比基线，劣化超阈值 → 自动暂停灰度 + 回退 + 告警。
- 思路：哨兵定时（5 分钟）对比灰度组 vs 基线组 → 劣化判定（崩溃率 ×1.5 / 首帧 ×1.2）→ 自动回退（flag 关闭）+ 告警。
- 评分点：哨兵指标；自动回退；告警通知。

```javascript
class GrayReleaseSentinel {
  constructor(releaseId, { checkInterval = 5 * 60000 } = {}) {
    this.releaseId = releaseId;
    this.timer = setInterval(() => this.check(), checkInterval);   // 5 分钟检查
  }
  async check() {                                                  // 哨兵检查
    const { gray, base } = await metrics.compare(this.releaseId,
      { metrics: ['crashRate', 'whiteScreenRate', 'firstFrameP75'], minSample: 500 });
    const degraded = gray.crashRate > base.crashRate * 1.5
      || gray.whiteScreenRate > base.whiteScreenRate * 1.3
      || gray.firstFrameP75 > base.firstFrameP75 * 1.2;
    if (degraded) {                                                  // 劣化
      clearInterval(this.timer);                                      // 停哨兵
      await this.rollback();                                           // 自动回退
      fire('gray-rollback', { releaseId: this.releaseId,
        gray, base, reason: 'metric-degradation' });                    // 告警
    }
  }
}
```
