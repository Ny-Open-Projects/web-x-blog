## VIZ-244：可视化无障碍：图表的屏幕阅读器与键盘导航

**答**：
- 图表 a11y：canvas 内容对 SR 不可见——提供 aria-label 摘要（图表类型+核心结论）+ 数据表格隐藏副本（SR 可读）。
- 键盘导航：Tab 进入图表 → 方向键在数据点间移动（焦点环）→ Enter 查看 tooltip。
- 色盲友好：色板避免红绿对撞；关键信息不只靠颜色（形状/标签冗余）。

```javascript
function chartA11y(chartEl, summary, data) {
  chartEl.setAttribute('role', 'img');
  chartEl.setAttribute('aria-label',
    `${summary.type}：${summary.title}。${summary.conclusion}`);   // 摘要（SR 朗读）
  // 数据表格隐藏副本
  const table = document.createElement('table');
  table.className = 'sr-only';                            // 视觉隐藏
  table.innerHTML = `<caption>${summary.title}</caption>` +
    data.map(d => `<tr><td>${d.x}</td><td>${d.v}</td></tr>`).join('');
  chartEl.appendChild(table);
}
// 键盘：chartEl.tabIndex = 0；keydown 方向键移动 focusPoint → 显示 tooltip
// 色板：deuteranopia 模拟校验（工具 chroma.js），红绿系列改蓝橙
```
