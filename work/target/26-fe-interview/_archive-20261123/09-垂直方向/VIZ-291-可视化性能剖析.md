## VIZ-291：可视化性能剖析：Chrome Performance 面板定位图表卡顿

**答**：
- 图表卡顿定位三步：① Performance 录制交互 → 找长任务（红色三角）；② 看火焰图定位函数（paint/composite/JS 数据处理）；③ Main 线程 vs GPU 轨道判断瓶颈侧。
- 常见根因：全量重绘（无脏区）、SVG 节点过多（DOM 回流）、数据处理在主线程（应 Worker）。
- 优化映射：全量重绘→分层脏区（VIZ-262）；SVG 多→Canvas；数据处理→Worker。

```javascript
function diagnoseChartJank(profile) {
  const longTasks = profile.filter(e => e.duration > 50);
  return longTasks.map(t => ({
    duration: t.duration,
    attribution: t.stack?.includes('paint') ? '渲染：考虑脏区/分层'
      : t.stack?.includes('recalculate') ? 'DOM 回流：SVG 节点过多→Canvas'
      : t.stack?.includes('parse') ? '数据处理：下沉 Worker'
      : '未知：看火焰图具体函数',
  }));
}
// 实战案例：万点折线 hover 卡 120ms → 根因拾取函数线性扫 → 二分 + 邻域精查（VIZ-241）→ 5ms
```
