## AV-384：编解码专项收口：一张编码参数决策表

**答**：
- 参数表：场景 × { codec, GOP, 码率模式, 帧率, B 帧, 编码 preset }。
- 直播：H.264 CBR GOP1s 无 B 帧 preset veryfast；点播：H.265/AV1 CRF18 GOP5s B 帧开 preset slow。
- 变更管控：参数变更走 A/B（VMAF+卡顿率双指标验收），禁止直接全量。

```javascript
// 参数决策表
function encodingProfile(scene) {
  const table = {
    live: { codec: 'h264', mode: 'cbr', gop: 1, bframes: 0,
      fps: 30, preset: 'veryfast', note: '低延迟优先' },
    vod: { codec: 'h265', mode: 'crf', crf: 18, gop: 5, bframes: 3,
      fps: 30, preset: 'slow', note: '质量优先' },
    screen: { codec: 'h264', mode: 'vbr', gop: 3, bframes: 0,
      fps: 15, contentHint: 'detail', note: '屏幕内容' },
  };
  return table[scene] ?? table.vod;
}
```
