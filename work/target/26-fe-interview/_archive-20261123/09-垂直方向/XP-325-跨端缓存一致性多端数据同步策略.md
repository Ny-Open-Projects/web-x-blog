## XP-325：跨端缓存一致性：多端数据同步策略

**答**：
- 问题：Web/小程序/App 各自缓存同一数据，更新后不一致。
- 策略：版本号协商（端缓存带 version，接口返回最新版本，旧则失效重拉）、写后广播（IM/推送通知失效）。
- 体验：失效后台刷新（先展示旧值），非阻塞。

```javascript
// 版本协商缓存
async function cachedGet(key, fetcher) {
  const local = await cache.get(key);                // { v, data }
  const meta = await apiHead(key);                   // 只拉版本
  if (local && local.v === meta.v) return local.data;
  const fresh = await fetcher();
  await cache.set(key, { v: meta.v, data: fresh });
  return fresh;
}
```
