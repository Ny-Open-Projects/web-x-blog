## XP-257：跨端容器与原生混合：JS 异常与 Native 崩溃桥接上报（笔试）

**答**：
- 题目：JS 异常与 Native 崩溃统一上报——JS 异常（uncaught）+ Native 崩溃（信号/exception）→ 统一错误平台（会话关联）。
- 思路：JS 异常（uncaught handler）+ Native 崩溃（crash handler）→ 统一上报（带 sessionId/设备/版本）；会话关联（同 session 的 JS + Native 错误聚合）。
- 评分点：双端采集；会话关联；符号化。

```javascript
class UnifiedCrashReporter {
  constructor(sessionId) { this.sessionId = sessionId; }
  init() {                                                       // 双端采集
    globalThis.onuncaughtException = (error) => {                  // JS 异常
      this.report({ kind: 'js', message: error.message, stack: error.stack });
    };
    nativeBridge.onCrash = (crash) => {                             // Native 崩溃回调
      this.report({ kind: 'native', signal: crash.signal,
        stack: crash.backtrace });
    };
  }
  report({ kind, ...data }) {                                     // 统一上报
    send({ kind, sessionId: this.sessionId,                        // 会话关联
      device: getDeviceInfo(), appVersion: getAppVersion(),
      ts: Date.now(), ...data });
  }
}
// 会话关联：同一 session 的 JS + Native 错误聚合——排查「JS 异常导致 Native 崩溃」链路
```
