## XP-164：跨端容器与原生混合导航：手势返回透传

**答**：
- 题目：iOS 侧滑返回手势——容器页内部有横向滑动列表，手势冲突（侧滑返回 vs 列表滑动）。实现手势仲裁。
- 思路：列表到达边缘（x=0 或 x=max）时手势透传给 Native（侧滑返回）；否则列表消费手势。Native 提供「手势透传」接口。
- 评分点：边缘判定；透传时机；防误触。

```javascript
class GesturePassthrough {
  onPan(dx, dy, listState) {                                  // 列表滑动
    const atLeftEdge = listState.scrollLeft <= 0 && dx > 0;   // 到左边缘且继续右滑
    if (atLeftEdge && Math.abs(dx) > 20) {
      this.native.beginBackGesture();                          // 透传给 Native 侧滑
      this.consumedByNative = true;
      return;
    }
    if (this.consumedByNative) return;                        // 已透传：列表不再消费
    listState.scrollBy(-dx);                                   // 正常滑动
  }
}
// 防误触：透传需位移 > 20px（阈值）——轻微滑动仍归列表
```
