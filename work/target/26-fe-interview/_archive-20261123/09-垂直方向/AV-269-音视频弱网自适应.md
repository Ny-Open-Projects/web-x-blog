## AV-269：音视频弱网自适应：WebRTC vs 流媒体协议的降级差异

**答**：
- WebRTC 降级：编码参数实时可调（setParameters）+ BWE 自动——延迟不变质量降；流媒体降级：切清晰度档位（转码预设）——需缓冲重建。
- WebRTC 优势：亚秒级自适应；劣势：码率波动大（BWE 振荡）；流媒体平滑但滞后。
- 前端实现差异：WebRTC 监听 getStats 调参；流媒体监听 hls.levelSwitched 告知用户。

```javascript
const degradationDiff = {
  webrtc: { mechanism: 'BWE + setParameters 实时调参',
    latency: '不变（300ms）', quality: '连续下降', oscillation: '码率振荡（需平滑）' },
  streaming: { mechanism: 'ABR 切换转码档位',
    latency: '切换时重建缓冲（+1~2s）', quality: '阶梯下降', smoothness: '平滑但滞后' },
  hybrid: '直播互动层 WebRTC（实时调参）+ 观看层 HLS（档位切换）——双链路独立降级',
};
// WebRTC 振荡平滑：目标码率变化 < 20% 不动，连续 3 次超阈值才调
```
