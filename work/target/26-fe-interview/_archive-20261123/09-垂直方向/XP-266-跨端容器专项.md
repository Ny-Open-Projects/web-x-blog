## XP-266：跨端容器专项：容器与原生混排列表（Native 头部 + JS 列表）（笔试）

**答**：
- 题目：混合列表——Native 原生头图（视频/轮播）+ JS 渲染列表（内容区），滚动联动（头部随滚动缩小）。
- 思路：Native ScrollView 包含原生头部 + JS 列表容器；滚动事件桥传（缩放系数计算）→ JS 列表滚动偏移同步。
- 评分点：混合结构；滚动联动；性能控制。

```javascript
class HybridScrollView {
  constructor(nativeHeader, jsList) {                             // 混合结构
    this.native = nativeScrollView({ header: nativeHeader, children: [jsList] });
    nativeHeader.height = HEADER_MAX;
  }
  onScroll(offset) {                                              // 滚动联动
    const headerScale = clamp(1 - offset / HEADER_MAX, 0.5, 1);    // 头部缩放
    bridge.commit([{ op: 'update-header', height: HEADER_MAX - offset,
      scale: headerScale }]);                                       // Native 头部更新
    jsList.setOffset(Math.max(0, offset - HEADER_MAX));              // JS 列表偏移
  }
}
```
