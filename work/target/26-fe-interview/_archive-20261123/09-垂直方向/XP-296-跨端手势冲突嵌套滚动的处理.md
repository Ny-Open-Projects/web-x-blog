## XP-296：跨端手势冲突：嵌套滚动的处理

**答**：
- 问题：外层横滑 + 内层竖滑（或嵌套滚动）事件竞争——抢手势导致卡顿或误触。
- 方案：手势仲裁（方向判定后锁定）、原生嵌套滚动协议（RN nestedScrollEnabled/小程序 page-meta）。
- 调试：手势日志（down/move/up 时间线）定位抢手势方。

```javascript
// 手势仲裁
function gestureArbiter(events) {
  // events: [{ type: 'move', dx, dy }]
  let locked = null;
  for (const e of events) {
    if (!locked && (Math.abs(e.dx) > 10 || Math.abs(e.dy) > 10))
      locked = Math.abs(e.dx) > Math.abs(e.dy) ? 'horizontal' : 'vertical';
    if (locked === 'horizontal') return 'outer-scroll';   // 外层接管
    if (locked === 'vertical') return 'inner-scroll';
  }
  return 'pending';
}
```
