## VIZ-335：向量点积在图形学中的三个核心用途

**答**：
- 夹角判断：a·b = |a||b|cosθ，用于法线朝向判定（背面剔除）与光照（Lambert 漫反射 = N·L）。
- 投影长度：b 在 a 上的投影 = (a·b/|a|²)a，用于分解速度/力向量与 shadow 投影。
- 同向性测试：点积 > 0 同向、< 0 反向、= 0 垂直——视锥剔除里"面是否朝向相机"就用 (faceNormal - camPos)·n 判断。

```javascript
// 点积三用途
const dot = (a, b) => a[0]*b[0] + a[1]*b[1] + a[2]*b[2];
function backface(normal, viewDir) {
  return dot(normal, viewDir) > 0;         // 与视线同向 = 背面
}
function lambert(normal, lightDir) {
  return Math.max(0, dot(normal, lightDir));   // 漫反射强度
}
function project(a, b) {                    // b 在 a 上投影
  const d = dot(a, a);
  const k = dot(a, b) / d;
  return [a[0]*k, a[1]*k, a[2]*k];
}
```
