## XP-302：跨端降级矩阵：低端机的体验分层

**答**：
- 档位判定：设备分（内存/CPU 核数/屏幕）+ 实测帧率 → L0~L3。
- 降级项：动效数量/图片质量/列表虚拟化/预加载距离/动画帧率。
- 原则：核心功能全档可用，装饰性特性按档位递减。

```javascript
// 设备分档
function deviceTier({ memGB, cores, fpsProbe }) {
  let score = 0;
  score += memGB >= 6 ? 3 : memGB >= 4 ? 2 : 1;
  score += cores >= 8 ? 3 : cores >= 4 ? 2 : 1;
  score += fpsProbe >= 55 ? 3 : fpsProbe >= 40 ? 2 : 1;
  return { score, tier: score >= 8 ? 'L3' : score >= 6 ? 'L2'
    : score >= 4 ? 'L1' : 'L0' };
}
```
