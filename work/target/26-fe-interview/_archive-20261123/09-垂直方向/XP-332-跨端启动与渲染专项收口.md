## XP-332：跨端启动与渲染专项收口

**答**：
- 启动：预热（284）/预取（285）/预加载（303）/闪屏（321）——预字诀。
- 渲染：列表（293）/图片（294）/动画（295）/手势（316）——合成层与原生驱动。
- 度量：全链路分段打点 + 分端对比看板（312），劣化自动开单。

```javascript
// 专项检查清单
const LAUNCH_CHECK = [
  { id: 'warmup', test: s => s.webviewWarmupMs < 50 },
  { id: 'prefetch', test: s => s.prefetchHitRate > 0.6 },
  { id: 'listFps', test: s => s.scrollDropRate < 0.01 },
  { id: 'bridgeBatch', test: s => s.bridgeCallsPerSec < 50 },
  { id: 'coldStart', test: s => s.coldStartP75 < 2000 },
];
function launchAudit(signals) {
  return LAUNCH_CHECK.filter(c => !c.test(signals))
    .map(c => ({ id: c.id }));
}
```
