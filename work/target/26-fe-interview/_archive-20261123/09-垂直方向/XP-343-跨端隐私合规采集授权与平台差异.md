## XP-343：跨端隐私合规：采集授权与平台差异

**答**：
- 差异：iOS ATT（IDFA 弹窗）、Android 权限组、小程序隐私协议接口。
- 统一：权限状态机（未询问/授予/拒绝）+ 拒绝后的降级体验（手动输入替代定位）。
- 审计：各端采集项与隐私政策一致性（1162）。

```javascript
// 权限状态机
async function ensurePermission(kind, adapter) {
  const state = await adapter.query(kind);           // granted/denied/undetermined
  if (state === 'granted') return { ok: true };
  if (state === 'denied')
    return { ok: false, fallback: adapter.fallback(kind) };   // 手动输入等
  const r = await adapter.request(kind);             // 弹窗
  report({ type: 'perm-request', kind, granted: r });
  return { ok: r };
}
```
