## AV-356：帧率与码率的联合优化（高帧率场景）

**答**：
- 60fps 不一定值得：码率 ×1.5，感知提升依赖内容运动量（游戏/体育值得，PPT 不值）。
- 动态帧率：WebRTC 可降帧保分辨率（优先空间分辨率）或反之，按内容判定。
- 指标：用运动向量密度/帧间差分自动判定内容运动等级。

```javascript
// 动态帧率决策
function frameratePolicy(frameDiff, { kbps } = {}) {
  // frameDiff: 0~1 帧间差异（运动量）
  if (frameDiff > 0.3 && kbps >= 4000)
    return { fps: 60, note: '高运动+带宽足，60fps' };
  if (frameDiff > 0.3)
    return { fps: 30, dropResolution: true, note: '高运动低带宽，保分辨率' };
  return { fps: 24, note: '低运动降帧省码率' };
}
```
