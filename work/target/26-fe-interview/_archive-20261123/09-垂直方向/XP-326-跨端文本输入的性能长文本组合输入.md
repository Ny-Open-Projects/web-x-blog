## XP-326：跨端文本输入的性能（长文本/组合输入）

**答**：
- 问题：受控输入每键触发 setState/setData 重渲——长文本输入卡。
- 方案：非受控 + onblur 提交、输入中节流同步、IME 组合期间不更新（compositionstart/end）。
- 跨端：小程序 input 防抖、RN TextInput defaultValue。

```javascript
// IME 安全输入
function imeSafeInput(onChange) {
  let composing = false;
  return {
    onCompositionStart: () => composing = true,
    onCompositionEnd: e => { composing = false; onChange(e.target.value); },
    onInput: e => { if (!composing) onChange(e.target.value); },
  };
}
// 组合输入（中文拼音）期间 setState 会导致候选框闪烁——必须跳过
```
