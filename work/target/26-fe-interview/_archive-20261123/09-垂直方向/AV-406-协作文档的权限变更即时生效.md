## AV-406：协作文档的权限变更即时生效

**答**：
- 问题：权限收回（editor -> viewer）后该用户已打开的编辑界面仍可操作。
- 方案：权限版本号广播，客户端收到变更立即切只读模式；服务端拒绝后续 update 双保险。
- 体验：编辑中内容自动保存草稿，提示"权限已变更"。

```javascript
// 权限热更新
function onPermissionChange(doc, user, newRole) {
  user.role = newRole;
  const editable = ROLE_CAPS[newRole]?.includes('edit');
  editor.setReadonly(!editable);                       // UI 即时切
  if (!editable && editor.hasPendingChanges())
    editor.saveDraft(user.id);                         // 草稿保护
  report({ type: 'perm-change', uid: user.id, role: newRole });
}
```
