## AV-234：直播首帧优化：秒开策略全景

**答**：
- 秒开手段：GOP 缓存（边缘缓存最近 I 帧，拉流立即发）、预加载（进房间前拉流）、首帧 I 帧对齐（推流端 1s GOP）、解码器预热。
- 指标：首帧时间（进入直播间 → 画面出现）P75 < 1s 为秒开。
- 手段组合：GOP 缓存（服务端）是最大头（省 1~4s），预加载省 200~500ms。

```javascript
const firstFrameOptimization = {
  gopCache: '边缘缓存最近 GOP——观众拉流从最近 I 帧立即发（省等下个 I 帧 1~4s）',
  preload: '进房前预连接 CDN + 预创建播放器（省 200~500ms）',
  gopShort: '推流端 GOP 1s——切片快速对齐',
  decoderPrewarm: '首帧解码预热（软解场景）',
  measure: 'joinTs → firstFramePaintTs 分段上报（CDN/解码/渲染）',
};
// 实测分布：无优化 P75 4s → GOP 缓存后 P75 1.2s → 预加载后 P75 0.8s
```
