## AV-402：协作服务端的水平扩展（房间分片）

**答**：
- 问题：单节点 WS 连接数与房间内广播瓶颈。
- 方案：房间粘性路由（一致性哈希到节点）、跨节点广播走 Redis PubSub/Kafka。
- 迁移：节点下线时房间平滑迁移（新节点接管 + 客户端透明重连）。

```javascript
// 房间分片路由
function roomNode(roomId, nodes) {
  const h = hashRoom(roomId);
  return nodes[h % nodes.length];                      // 一致性哈希简化版
}
class CrossNodeBus {
  constructor(pub, sub) { this.pub = pub; this.sub = sub; }
  broadcast(roomId, update, sourceNode) {
    this.pub.publish(`room:${roomId}`, update);
  }
  subscribe(roomId, handler) {
    this.sub.subscribe(`room:${roomId}`, msg => handler(msg));
  }
}
```
