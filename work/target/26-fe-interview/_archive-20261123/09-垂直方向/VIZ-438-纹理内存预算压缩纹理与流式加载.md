## VIZ-438：纹理内存预算：压缩纹理与流式加载

**答**：
- 账目：4K RGBA8 = 64MB；压缩纹理（BC7/ETC2/ASTC）≈ 1/4~1/8 且硬件解码。
- 流式：按 mip 流式加载（低 mip 先到先渲，高 mip 后台补），requestVideoFrameCallback 式调度。
- 策略：按重要性分级（首屏资产 < 10MB 预算），超预算走降质或懒加载。

```javascript
// 纹理预算管理
function texBudget(assets, budgetMB = 100) {
  let used = 0; const loaded = [], deferred = [];
  for (const a of assets.sort((x, y) => y.priority - x.priority)) {
    const mb = a.width * a.height * a.bytesPerPixel / 1024 / 1024;
    if (used + mb <= budgetMB) { used += mb; loaded.push(a); }
    else deferred.push({ ...a, reason: '超预算' });
  }
  return { usedMB: +used.toFixed(1), loaded, deferred,
    advice: deferred.length ? '延迟加载或转压缩格式（KTX2）' : 'ok' };
}
```
