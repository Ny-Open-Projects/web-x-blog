## XP-314：跨端手势库的性能：触控事件节流与合并

**答**：
- 问题：pointermove 事件高频（120Hz 屏 120 次/s）——JS 每次处理必卡。
- 方案：rAF 合帧（只取最新位置）、被动监听、原生手势模块（动画直接原生驱动）。
- 度量：手势处理耗时/帧（< 2ms）与掉帧率。

```javascript
// 手势 rAF 合帧
function gestureThrottle(onMove) {
  let pending = null, scheduled = false;
  return function handler(e) {
    pending = { x: e.clientX, y: e.clientY };
    if (scheduled) return;
    scheduled = true;
    requestAnimationFrame(() => {
      scheduled = false;
      onMove(pending);                               // 每帧最多一次
    });
  };
}
el.addEventListener('pointermove', gestureThrottle(updateDrag), { passive: true });
```
