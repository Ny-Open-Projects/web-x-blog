## AV-395：多人编辑选区/合并单元格（表格协作）的冲突

**答**：
- 表格特有冲突：合并单元格重叠、行列插入导致引用漂移。
- 方案：行列操作用 CRDT 序列（YArray），单元格内容 YText；合并冲突后取最新操作，其余端收到回滚通知。
- 体验：冲突时 toast 提示 + 数据自动收敛（不丢数据）。

```javascript
// 表格冲突处理
function onCellConflict(op, remoteOp) {
  if (op.row === remoteOp.row && op.col === remoteOp.col) {
    // LWW：时间戳新者胜（CRDT 已处理），前端提示
    report({ type: 'cell-conflict', cell: `${op.row},${op.col}`,
      winner: op.ts > remoteOp.ts ? op.userId : remoteOp.userId });
    toast('他人同时编辑了此单元格，已显示最新内容');
  }
}
```
