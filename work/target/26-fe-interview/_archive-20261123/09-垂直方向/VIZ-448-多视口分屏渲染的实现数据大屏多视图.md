## VIZ-448：多视口/分屏渲染的实现（数据大屏多视图）

**答**：
- 需求：一个 canvas 多个视图（主视图 + 小地图 + 侧视口）——viewport/ scissors 分区渲染。
- 实现：每视图独立相机与 VP 矩阵，依次设置 viewport 渲染；scissor 限制清屏范围。
- 优化：小视图低分辨率 FBO + 上采样；共享场景一次遍历多相机剔除（视锥并集）。

```javascript
// 多视口渲染
function renderMultiView(gl, views, scene) {
  for (const v of views) {
    gl.viewport(v.x, v.y, v.w, v.h);
    gl.scissor(v.x, v.y, v.w, v.h);
    gl.enable(gl.SCISSOR_TEST);
    gl.clear(gl.COLOR_BUFFER_BIT | gl.DEPTH_BUFFER_BIT);
    renderScene(scene, v.camera);                   // 各自 VP
    gl.disable(gl.SCISSOR_TEST);
  }
}
```
