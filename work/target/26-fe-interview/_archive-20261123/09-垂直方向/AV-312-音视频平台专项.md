## AV-312：音视频平台专项：多平台推流规格统一（抖音/快手/B站）

**答**：
- 题目：多平台分发推流——各平台推流规格差异（分辨率上限/码率上限/编码要求/帧率），统一推流配置生成器。
- 思路：平台规格表（抖音 1080p/6M/30fps、B站 1080p/8M/60fps）→ 取交集生成主推流 → 各平台按规格转推。
- 评分点：规格表维护；交集计算；转推配置。

```javascript
const PLATFORM_SPECS = {
  douyin: { maxRes: '1080p', maxBitrate: 6000000, fps: 30, codec: 'h264' },
  kuaishou: { maxRes: '1080p', maxBitrate: 8000000, fps: 30, codec: 'h264' },
  bilibili: { maxRes: '1080p60', maxBitrate: 8000000, fps: 60, codec: 'h264' },
};
function unifiedPushSpec(platforms) {                       // 多平台规格交集
  const specs = platforms.map(p => PLATFORM_SPECS[p]);
  const fps = Math.min(...specs.map(s => s.fps));
  const bitrate = Math.min(...specs.map(s => s.maxBitrate));
  return { resolution: '1080p', fps, bitrate, codec: 'h264',   // 交集：最低公共规格
    note: '主推流取交集，各平台差异由转推服务端适配' };
}
// 主推流 → RTMP 源站 → 各平台转推（规格适配在转推端）
```
