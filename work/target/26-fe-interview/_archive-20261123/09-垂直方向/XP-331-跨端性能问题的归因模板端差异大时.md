## XP-331：跨端性能问题的归因模板（端差异大时）

**答**：
- 模板：现象 → 各端复现 → 差异点（框架/引擎/资源）→ 端专属修复 → 跨端回归。
- 常见根因：某端资源未压缩（图片原图直出）、某端桥实现低效、某端引擎版本旧。
- 沉淀：归因结论进跨端 checklists（345），防止重复踩坑。

```javascript
// 端差异归因
function endDiffAnalysis(metrics) {
  const worst = metrics.sort((a, b) => b.value - a.value)[0];
  return {
    worstEnd: worst.end, worstValue: worst.value,
    gap: +(worst.value / metrics[metrics.length - 1].value).toFixed(2),
    suspects: [`${worst.end} 资源体积`, `${worst.end} 桥实现`, `${worst.end} 引擎版本`],
    next: '逐项排除，先查资源体积（最低成本）',
  };
}
```
