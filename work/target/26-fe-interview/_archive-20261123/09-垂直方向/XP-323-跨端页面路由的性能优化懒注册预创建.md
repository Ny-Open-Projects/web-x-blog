## XP-323：跨端页面路由的性能优化（懒注册/预创建）

**答**：
- 懒注册：路由组件动态 import（首屏只注册核心路由）。
- 预创建：高频页面预创建实例（小程序 preloadRule/RN 预渲染）。
- 度量：路由跳转耗时 P75（< 300ms 无感）。

```javascript
// 路由懒注册
const routeMap = {
  home: () => import('./pages/Home'),
  detail: () => import('./pages/Detail'),            // 懒注册
};
async function navigate(name, params) {
  const mod = await routeMap[name]();
  render(mod.default, params);
  perfMark({ route: name, ms: performance.now() - t0 });
}
// 预创建：requestIdleCallback(() => routeMap.detail());
```
