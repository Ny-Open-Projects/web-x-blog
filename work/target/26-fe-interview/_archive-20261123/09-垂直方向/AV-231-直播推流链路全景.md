## AV-231：直播推流链路全景：采集到观众端的每一跳

**答**：
- 推流链路：采集（Camera/Mic）→ 前处理（美颜/滤镜）→ 编码（H264/H265）→ 封装（FLV/RTMP）→ 推流（RTMP/SRT）→ 源站 → CDN 分发 → 观众拉流播放。
- 每跳延迟预算：编码 ~50ms、推流传输 RTT、CDN 分发（HLS 切片 2~6s / FLV 1~3s）、解码渲染 ~30ms。
- 端到端延迟：RTMP+FLV 约 3s；低延迟直播（WebRTC）300ms；选型看互动需求。

```javascript
const pushPipeline = {
  capture: 'Camera/Mic → MediaStreamTrack（采集 ~10ms）',
  preprocess: '美颜/滤镜 → WebGL/VideoFrame 管线（~20ms）',
  encode: 'VideoEncoder（WebCodecs）硬件编码 ~30ms',
  transport: 'RTMP over TCP（可能有队头阻塞）或 SRT over UDP（抗抖动）',
  cdn: 'FLV 1~3s / HLS 2~6s（切片长度决定）/ WebRTC 300ms',
  render: '观众端解码渲染 ~30ms + jitter buffer',
  total: { webrtc: '300ms~1s', httpFlv: '2~4s', hls: '4~10s' },
};
// 优化优先级：切片长度（HLS LL-HLS 降到 2s）> 编码 GOP > 传输协议
```
