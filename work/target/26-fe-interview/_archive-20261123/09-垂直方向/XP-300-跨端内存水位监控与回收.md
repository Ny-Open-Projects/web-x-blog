## XP-300：跨端内存水位监控与回收

**答**：
- 监控：JS heap（RN/Flutter resident）、WebView 内存、原生总量——分端采样。
- 治理：页面卸载彻底释放（监听器/定时器/图片缓存清理）、大图及时回收、列表滑动缓存上限。
- 告警：低端机内存 > 70% 时触发降级（关动效/减缓存）。

```javascript
// 内存水位
function memoryWatermark({ jsHeapMB, nativeMB, limitMB = 500 }) {
  const total = jsHeapMB + nativeMB;
  const ratio = total / limitMB;
  const policy = ratio > 0.85 ? 'aggressive'   // 清缓存/关动效
    : ratio > 0.7 ? 'moderate'                  // 清图片缓存
    : 'normal';
  return { total, ratio: +ratio.toFixed(2), policy };
}
```
