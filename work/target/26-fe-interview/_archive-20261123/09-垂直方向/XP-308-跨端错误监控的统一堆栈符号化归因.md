## XP-308：跨端错误监控的统一（堆栈符号化/归因）

**答**：
- 统一：各端错误（JS 异常/原生崩溃/Flutter 异常）映射到统一 schema（type/message/stack/page）。
- 符号化：RN sourcemap、小程序 sourcemap、Flutter symbolicate——平台侧还原。
- 归因：错误关联页面/版本/设备档位，按端分桶。

```javascript
// 错误统一 schema
function normalizeError(raw, platform) {
  return {
    platform, type: raw.type ?? 'js-error',
    message: redact(String(raw.message ?? raw)).slice(0, 200),
    stack: raw.stack?.split('\n').slice(0, 5).join('\n'),
    page: raw.route ?? currentRoute(),
    tier: deviceTierCache,
  };
}
// 各端接入点：RN ErrorUtils.setGlobalHandler / 小程序 App.onError / Flutter FlutterError.onError
```
