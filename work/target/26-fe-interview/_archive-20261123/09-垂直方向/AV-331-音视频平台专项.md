## AV-331：音视频平台专项：直播推流端性能监控（主播端）（笔试）

**答**：
- 题目：主播端推流监控——采集帧率/编码耗时/上行带宽/丢帧率，实时显示给主播（网络状态条）+ 劣化自动降参。
- 思路：VideoEncoder 统计（encodeTime/queueSize）+ 上行带宽估计 → 网络状态条（绿黄红）+ 自动降参（AV-212 复用）。
- 评分点：编码统计采集；网络状态条；自动降参联动。

```javascript
class PushStreamMonitor {
  constructor(encoder, sender) { this.encoder = encoder; this.sender = sender; }
  async tick() {                                                 // 每秒采样
    const encoderStats = this.encoder.status;                    // queueSize（编码积压）
    const params = this.sender.getParameters();
    const bitrate = params.encodings[0].maxBitrate;
    const stats = await this.sender.getStats();                   // 上行 RTT
    const rtt = [...stats.values()].find(r => r.type === 'outbound-rtp')?.roundTripTime;
    const health = encoderStats.queueSize > 10 || rtt > 0.3 ? 'bad'
      : encoderStats.queueSize > 3 ? 'mid' : 'good';
    this.indicator.update(health);                                // 网络状态条
    if (health === 'bad') this.degrader.downgrade();              // 自动降参（AV-212）
  }
}
```
