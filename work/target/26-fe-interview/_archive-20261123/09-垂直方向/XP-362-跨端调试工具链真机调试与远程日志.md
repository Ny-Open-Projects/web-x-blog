## XP-362：跨端调试工具链：真机调试与远程日志

**答**：
- 能力：vConsole/Flipper/Flutter DevTools 各端调试；远程日志（生产问题还原）。
- 安全：调试开关生产关闭（防信息泄露），按用户白名单临时开启。
- 流程：用户反馈 -> 拉 session 日志 -> 远程符号化 -> 复现。

```javascript
// 远程日志拉取
async function pullUserSession(uid, window) {
  const logs = await api(`/logs/session/${hash(uid)}`, { window });
  return logs.map(l => ({
    ...l, stack: symbolicate(l.stack, l.buildId),     // 远程符号化
  }));
}
// 生产调试开关：白名单 uid 才注入 vConsole
```
