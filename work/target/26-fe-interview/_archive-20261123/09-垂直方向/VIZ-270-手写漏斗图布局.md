## VIZ-270：手写漏斗图布局：转化率与梯形渲染

**答**：
- 题目：漏斗图——各阶段宽度按转化值比例递减，梯形（上宽=本阶段，下宽=下一阶段）；转化率标注（相邻阶段比）。
- 思路：宽度 = value/maxValue × 最大宽；梯形 path（上边=本阶段宽，下边=下阶段宽，居中对齐）；转化率 = next.value/value。
- 评分点：宽度比例映射；梯形 path；转化率标注位置。

```javascript
function funnelLayout(stages, { maxWidth = 400, stageH = 60, gap = 8 } = {}) {
  const max = Math.max(...stages.map(s => s.value));
  return stages.map((s, i) => {
    const topW = s.value / max * maxWidth;
    const next = stages[i + 1];
    const bottomW = next ? next.value / max * maxWidth : topW * 0.6;   // 末段收尾
    const y = i * (stageH + gap);
    return { stage: s.name, value: s.value,
      path: `M${(maxWidth - topW) / 2},${y} L${(maxWidth + topW) / 2},${y} ` +
        `L${(maxWidth + bottomW) / 2},${y + stageH} L${(maxWidth - bottomW) / 2},${y + stageH} Z`,
      conversion: next ? +(next.value / s.value * 100).toFixed(1) + '%' : null };   // 转化率
  });
}
```
