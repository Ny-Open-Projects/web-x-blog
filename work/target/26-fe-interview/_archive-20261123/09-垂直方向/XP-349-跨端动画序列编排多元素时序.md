## XP-349：跨端动画序列编排（多元素时序）

**答**：
- 需求：入场动画多元素依次/交错（stagger）——统一编排 API。
- 实现：delay 递增（每元素 +50ms）、GSAP 类库或各端动画 API 映射。
- 性能：元素多时用合成层动画（transform），避免逐元素布局动画。

```javascript
// stagger 编排
function stagger(count, { base = 0, step = 50, duration = 300 } = {}) {
  return Array.from({ length: count }, (_, i) => ({
    delay: base + i * step, duration,
    css: `animation-delay: ${base + i * step}ms; animation-duration: ${duration}ms`,
  }));
}
// RN 映射：Animated.stagger(step, animations)
```
