## XP-173：跨端容器与原生混合动画：容器页面与 Native 页过渡

**答**：
- 容器页面 ↔ Native 页过渡：切换动画期间容器预加载（HW-865 复用）——动画与加载并行，动画结束数据就绪。
- 实现：Native push 动画启动时同步通知 JS 开始预加载（数据+渲染）；动画 300ms 内完成预加载即无缝。
- 兜底：预加载未完成（弱网）→ 显示骨架屏（用户可感知）。

```javascript
class HybridTransition {
  async pushWithTransition(route) {
    const animPromise = this.native.pushAnimated(route);      // Native 动画 300ms
    const dataPromise = this.prefetchData(route);              // JS 并行预取
    const [_, data] = await Promise.all([animPromise, dataPromise]);
    if (data) {                                                // 数据就绪：直接渲染
      this.render(data);
    } else {
      this.renderSkeleton();                                    // 兜底骨架
      const late = await dataPromise;                            // 后到再渲染
      this.render(late);
    }
  }
}
```
