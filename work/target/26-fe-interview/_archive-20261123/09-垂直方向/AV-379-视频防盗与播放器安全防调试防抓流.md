## AV-379：视频防盗与播放器安全（防调试/防抓流）

**答**：
- 现实：前端无法绝对防盗——提高门槛（签名短时效 URL、token 绑会话、动态密钥）。
- 手段：MSE 内容加密（AES-128）、播放器混淆、异常行为检测（多设备同 token 上报）。
- 定位：盗录溯源（水印 361）比防御更有效——法律+溯源组合。

```javascript
// 短时效签名播放
async function playProtected(videoId) {
  const { url, token } = await api(`/media/${videoId}/play-url`);
  const player = new PlayerKernel();
  player.on('error', e => {
    if (e.category === 'auth') return player.reload(url, { freshToken: true });
  });
  await player.load(url);
  setInterval(async () => {                            // token 续期
    const { token: fresh } = await api(`/media/${videoId}/refresh`, { token });
    player.setToken(fresh);
  }, 10 * 60_000);
}
```
