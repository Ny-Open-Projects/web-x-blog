## VIZ-408：着色器中的条件纹理采样与依赖纹理读取

**答**：
- 依赖读取：UV 由前一采样结果计算——打断 GPU 纹理预取流水线，延迟敏感。
- 优化：atlas 固定布局（UV 由顶点算好）、避免链式采样；确需链式时把分支提升到顶点级。
- 替代：材质分组 draw，每 draw 单纹理，无依赖。

```javascript
// 依赖读取消除
// 反模式：
// vec4 mask = texture(maskTex, uv);
// vec4 c = texture(albedoAtlas, uv * mask.r + offset);   // 依赖
// 改进：UV 由顶点/attribute 提供（CPU 侧按 mask 分块）
// 或用 textureGrad 明确导数辅助 mipmap 选择
```
