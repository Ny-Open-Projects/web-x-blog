## XP-312：跨端性能看板的分端对比设计

**答**：
- 维度：端（H5/RN/小程序/Flutter）× 页面 × 指标（启动/滚动帧率/内存）。
- 口径对齐：各端指标定义映射表（首帧定义分端不同需注明）。
- 告警：同页面跨端指标差 > 50% 说明某端实现有问题（专项排查）。

```javascript
// 跨端对比
function crossEndCompare(metrics, page) {
  const rows = metrics.filter(m => m.page === page);
  const ends = [...new Set(rows.map(r => r.end))];
  return ends.map(e => {
    const vals = rows.filter(r => r.end === e).map(r => r.tti);
    return { end: e, ttiP75: quantile(vals, 0.75) };
  }).sort((a, b) => a.ttiP75 - b.ttiP75);
}
function quantile(a, q) { const s = [...a].sort((x, y) => x - y);
  return s[Math.floor(s.length * q)] ?? 0; }
```
