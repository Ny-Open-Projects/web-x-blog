## AV-364：屏幕共享的特殊处理（动态分辨率与光标）

**答**：
- 内容特性：文本/桌面低运动高清晰度需求——屏幕内容编码模式（H.264 SPS 标记）省 50% 码率。
- 光标：可以画进帧或作为光标事件单独传输（远端渲染）。
- 帧率自适应：静止时 1fps、滚动时 30fps（WebRTC 内置/手动 getDisplayMedia 后调参）。

```javascript
// 屏幕共享优化
async function screenShareOptimized() {
  const stream = await navigator.mediaDevices.getDisplayMedia({
    video: { frameRate: { ideal: 15, max: 30 },
      displaySurface: 'monitor' },
    audio: true,                                      // 系统声音
  });
  const [track] = stream.getVideoTracks();
  const sender = pc.getSenders().find(s => s.track === track);
  const p = sender.getParameters();
  p.encodings[0].contentHint = 'detail';              // 屏幕内容模式
  await sender.setParameters(p);
  return stream;
}
```
