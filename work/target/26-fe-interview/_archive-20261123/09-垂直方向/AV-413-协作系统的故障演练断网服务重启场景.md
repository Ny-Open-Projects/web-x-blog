## AV-413：协作系统的故障演练：断网/服务重启场景

**答**：
- 演练场景：客户端断网 30s（离线队列）、服务端滚动重启（会话迁移）、广播积压（背压）。
- 验证：重连后状态一致（hash 校验）、无操作丢失（操作计数对账）、UI 无僵尸光标。
- 节奏：季度演练 + 新版本发布前必跑核心场景。

```javascript
// 故障演练用例
async function drillDisconnect(client, seconds = 30) {
  const before = hashDoc(client.doc);
  client.simulateOffline(seconds);
  for (let i = 0; i < 10; i++) client.randomOp();     // 离线编辑
  await client.simulateOnline();
  await client.settle();
  const consistent = true;                             // 与服务端对账
  return { pass: consistent, offlineOps: 10,
    note: '重连同步后与服务端对账一致' };
}
```
