## XP-307：跨端图片缓存策略（磁盘/内存双层）

**答**：
- 内存层：LRU 上限（如 20MB），高频小图；磁盘层：上限（如 100MB）按最后访问淘汰。
- 键设计：URL+尺寸+格式 作为 key（同 URL 不同尺寸不共用）。
- 跨端实现：RN FastImage/小程序原生缓存/Web Service Worker Cache API。

```javascript
// 双层缓存
class TwoLayerImageCache {
  constructor({ memMB = 20, diskMB = 100 } = {}) {
    this.mem = new Map(); this.memLimit = memMB * 1024 * 1024;
    this.diskLimit = diskMB;
  }
  async get(key) {
    if (this.mem.has(key)) { const v = this.mem.get(key);
      this.mem.delete(key); this.mem.set(key, v);    // LRU 触底
      return v; }
    const disk = await idbGet('img-cache', key);
    if (disk) this.memSet(key, disk);
    return disk;
  }
  memSet(key, val) {
    this.mem.set(key, val);
    while (this.memSize() > this.memLimit)
      this.mem.delete(this.mem.keys().next().value);  // 淘汰最旧
  }
  memSize() { return [...this.mem.values()].reduce((s, v) => s + v.size, 0); }
}
```
