## XP-360：跨端指纹/设备信息的合规采集

**答**：
- 采集项：设备型号/OS 版本/屏幕/语言——功能必需项；广告 ID（IDFA/OAID）需授权。
- 统一：deviceInfo schema 各端 adapter 采集，敏感项授权门控。
- 留存：设备信息随会话上报不落库（隐私最小化）。

```javascript
// 设备信息采集
const DEVICE_FIELDS = {
  required: ['model', 'os', 'screen'],
  gated: ['idfa', 'oaid'],                           // 需授权
};
function deviceInfo(adapter, consents) {
  const out = {};
  for (const f of DEVICE_FIELDS.required)
    out[f] = adapter.get(f);
  for (const f of DEVICE_FIELDS.gated)
    if (consents[f]) out[f] = adapter.get(f);
  return out;                                        // 未授权字段不出现在上报中
```
