## AV-399：协作消息的压缩与批量传输

**答**：
- Update 压缩：Yjs update 是二进制，多端高频下可打包（每 50ms 合并多个 update）+ deflate。
- 批量：服务端聚合同一作者连续 update 再广播（减少消息头开销）。
- 监控：消息数/s 与字节数/s，超阈值自动加大批量窗口。

```javascript
// update 打包压缩
class UpdateBatcher {
  constructor(ws, { windowMs = 50 } = {}) { this.ws = ws; this.buf = []; }
  push(update) {
    this.buf.push(update);
    if (!this.timer) this.timer = setTimeout(() => this.flush(), this.windowMs ?? 50);
  }
  flush() {
    this.timer = null;
    if (!this.buf.length) return;
    const merged = Y.mergeUpdates(this.buf);           // 合并二进制
    const packed = pako.deflate(merged);
    this.ws.sendBinary(packed);
    this.buf = [];
  }
}
```
