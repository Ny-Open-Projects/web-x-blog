## AV-388：协作光标与选区的低延迟广播

**答**：
- 光标：高频小消息（位置/选区/颜色），走不可达通道（丢帧无妨），节流 50~100ms。
- 结构：{ userId, anchor, head, ts }；远端渲染时按文档位置映射屏幕坐标。
- 抖动处理：远端光标动画过渡（lerp）而非瞬移。

```javascript
// 光标广播
function cursorBroadcaster(doc, ws, { hz = 10 } = {}) {
  let pending = null;
  setInterval(() => {
    if (pending) { ws.send(JSON.stringify({ type: 'cursor', ...pending }));
      pending = null; }
  }, 1000 / hz);
  doc.on('selection', (anchor, head) => pending = { anchor, head });
}
// 远端渲染插值：
function renderRemoteCursor(prev, next, alpha) {
  return { x: prev.x + (next.x - prev.x) * alpha,
    y: prev.y + (next.y - prev.y) * alpha };          // 平滑移动
```
