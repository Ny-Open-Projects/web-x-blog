## VIZ-296：可视化色彩科学：色彩空间与色盲友好色板

**答**：
- 色彩空间：sRGB（屏幕）vs OKLCH（感知均匀）——色板生成用 OKLCH 等亮度插值（视觉平衡）。
- 色盲友好：8% 男性红绿色盲——色板用蓝橙/蓝黄对；模拟校验（deuteranopia 滤镜矩阵）。
- 对比度：WCAG 对比度 ≥ 3:1（图形元素）——文字色与背景的亮度差计算。

```javascript
function oklchPalette(n, { l = 0.65, c = 0.12 } = {}) {    // OKLCH 等亮度色板
  const hues = Array.from({ length: n }, (_, i) => i / n * 360);
  return hues.map(h => `oklch(${l} ${c} ${h.toFixed(1)})`);   // 等亮度等彩度，只转色相
}
function simulateDeuteranopia(rgb) {                       // 红绿色盲模拟
  const [r, g, b] = rgb;
  return [0.625 * r + 0.375 * g, 0.7 * r + 0.3 * g, b];    // 简化模拟矩阵
}
function contrastRatio(fg, bg) {                           // WCAG 对比度
  const lum = (c) => 0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2];
  const l1 = lum(fg), l2 = lum(bg);
  return (Math.max(l1, l2) + 0.05) / (Math.min(l1, l2) + 0.05);
}
// 校验：色板两两对比度 ≥ 3 且色盲模拟后可区分（色相差 > 阈值）
```
