## VIZ-428：双面渲染与背面剔除的显式控制

**答**：
- 默认剔除背面（gl.CULL_FACE BACK）；透明/布料/带状几何需双面（剔除关或法线翻转）。
- 双面光照：片元里翻转法线（dot(N, V) < 0 时 N = -N）保证两面光照正确。
- 轮廓渲染：先背面放大（沿法线外扩）纯色 pass，再正面渲染——经典描边。

```javascript
// 双面光照与描边
`// fs 双面：
vec3 N = normalize(vNormal);
if (!gl_FrontFacing) N = -N;
// 描边 vs（顶点沿法线外扩）：
vec3 inflated = aPos + aNormal * uOutlineWidth;
gl_Position = uVP * vec4(inflated, 1.0);
// 两 pass：pass1 剔正面画背面纯色 -> pass2 正常渲染正面`),
// GLSL 注意外闭合——实际生成时由脚本拼装
```
