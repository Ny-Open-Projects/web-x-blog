## XP-379：跨端滚动到指定元素的精准定位

**答**：
- 需求：锚点定位（目录跳转）精准且平滑；动态内容高度变化后定位偏移。
- 方案：定位重试（渲染后二次校准 scrollIntoView）、offset 修正（吸顶高度补偿）。
- 跨端：小程序 scroll-into-view 属性、RN scrollTo。

```javascript
// 锚点重试定位
async function scrollToAnchor(el, { retries = 3, offset = 60 } = {}) {
  for (let i = 0; i < retries; i++) {
    el.scrollIntoView({ behavior: 'smooth' });
    await sleep(100);
    const r = el.getBoundingClientRect();
    if (Math.abs(r.top - offset) < 4) return true;    // 已精准
    window.scrollBy(0, r.top - offset);               // 修正偏移
  }
  return false;
}
```
