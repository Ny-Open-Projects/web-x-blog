## VIZ-378：视差滚动与相机的数学建模

**答**：
- 多层视差：每层相机偏移 = 主相机位置 × 深度系数（0~1，1 为同速），z 序分层。
- 无限滚动：背景按 mod 平铺（偏移 % 图宽）；性能上用 CSS transform 合成层最优。
- 数据大屏慎用：装饰性视差在信息密度高的仪表盘会分散注意力——只用于营销页。

```javascript
// 视差层
function parallaxLayers(cameraX, layers) {
  // layers: [{ src, depth, width }]  depth: 0 远(慢) ~ 1 近(同速)
  return layers.map(l => ({
    ...l, offset: -(cameraX * l.depth) % l.width }));
}
// CSS 实现：transform: translate3d(calc(var(--camX) * -0.3), 0, 0)
// 合成器动画不触发重排，60fps 稳
```
