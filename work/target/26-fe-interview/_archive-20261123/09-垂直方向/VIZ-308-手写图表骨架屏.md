## VIZ-308：手写图表骨架屏：数据加载期的占位渲染（笔试）

**答**：
- 题目：图表数据异步加载——骨架屏占位（形状与最终图一致的微光动画），数据到达后无缝替换（布局不跳）。
- 思路：骨架形状按图表类型生成（折线=波浪 path，柱=柱形灰块）；shimmer 动画（渐变位移）；数据到达交叉淡入。
- 评分点：按类型生成骨架；shimmer 实现；无缝替换（布局一致）。

```javascript
function chartSkeleton(type, { w, h }) {                   // 类型化骨架
  if (type === 'line')
    return `<path d="M0,${h * 0.6} Q${w * 0.25},${h * 0.3} ${w * 0.5},${h * 0.5} T${w},${h * 0.4}"
      fill="none" stroke="#e8e8e8" stroke-width="3" class="shimmer"/>`;
  if (type === 'bar')
    return Array.from({ length: 8 }, (_, i) =>
      `<rect x="${i * w / 8 + 4}" y="${h * (0.3 + Math.sin(i) * 0.2)}" width="${w / 8 - 8}"
        height="${h * 0.5}" rx="2" fill="#e8e8e8" class="shimmer"/>`).join('');
  return `<rect width="${w}" height="${h}" fill="#f0f0f0" class="shimmer"/>`;
}
// shimmer CSS：.shimmer { animation: shimmer 1.5s infinite;
//   background: linear-gradient(90deg, transparent, rgba(255,255,255,0.6), transparent); }
// 无缝替换：骨架与真实图共用容器尺寸 → 数据到达后 opacity 交叉淡入
```
