## VIZ-336：叉积的几何意义与手性注意点

**答**：
- a×b 得到垂直于两者的向量，长度 = |a||b|sinθ = 平行四边形面积——三角形面积/法线计算的基础。
- 手性：右手系（WebGL 默认）与左手系（DirectX 常见）叉积方向相反，移植代码最容易踩。
- 二维叉积（标量）符号判断点在向量左侧/右侧，用于多边形填充与点在三角形内测试。

```javascript
// 叉积：法线 + 面积 + 2D 侧向
function cross(a, b) {
  return [a[1]*b[2] - a[2]*b[1], a[2]*b[0] - a[0]*b[2], a[0]*b[1] - a[1]*b[0]];
}
function triNormal(p0, p1, p2) {
  const u = [p1[0]-p0[0], p1[1]-p0[1], p1[2]-p0[2]];
  const v = [p2[0]-p0[0], p2[1]-p0[1], p2[2]-p0[2]];
  const n = cross(u, v);
  const len = Math.hypot(...n) || 1;
  return n.map(x => x / len);              // 单位法线
}
function cross2(o, a, b) {                 // 2D：>0 左侧
  return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0]);
}
```
