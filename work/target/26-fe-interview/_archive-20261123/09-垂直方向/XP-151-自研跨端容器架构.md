## XP-151：自研跨端容器架构：渲染层抽象与桥协议设计

**答**：
- 自研容器分层：JS 逻辑层（框架无关）→ 渲染描述层（VDOM/指令集）→ 原生渲染层（Native View 树）——桥协议传递「渲染指令」而非 DOM。
- 桥协议设计：序列化指令集（create/update/remove 节点 + 属性 diff），批量提交（避免高频跨桥）。
- 对标：React Native（旧 Bridge JSON）/新架构 JSI（同步直调）——自研的取舍在性能与生态间平衡。

```javascript
// 渲染指令集（桥协议）
const ops = [
  { op: 'create', nodeId: 1, type: 'View', props: { style: { flex: 1 } } },
  { op: 'update', nodeId: 1, props: { style: { backgroundColor: 'red' } } },
  { op: 'insertChild', parentId: 0, nodeId: 1, index: 0 },
  { op: 'remove', nodeId: 2 },
];
class RenderBridge {
  commit(ops) {                                            // 批量提交
    nativeBridge.send(JSON.stringify(ops));                // 旧架构：JSON 序列化
    // 新架构（JSI）：nativeBridge.commitDirect(ops)——零拷贝同步调用
  }
}
// JS 侧 VDOM diff → 指令集 → 桥 → Native 侧解析执行构建 View 树
```
