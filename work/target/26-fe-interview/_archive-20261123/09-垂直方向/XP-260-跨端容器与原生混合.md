## XP-260：跨端容器与原生混合：Web 与 Native 渲染切换策略（笔试）

**答**：
- 题目：容器内页面渲染策略——部分页面用 WebView 渲染（快速迭代/复杂 CSS）+ 部页面用 Native 渲染（性能/一致）→ 路由级渲染策略声明。
- 思路：路由表声明渲染类型（web/native）；web 页面走 WebView（URL 路由）；native 页面走指令集渲染；切换时统一导航栈。
- 评分点：路由声明；渲染切换；导航栈统一。

```javascript
const routeRenderStrategy = {
  '/home': { render: 'native', reason: '首屏性能/高频访问' },
  '/activity': { render: 'web', reason: '运营页面快速迭代（H5 动态下发）' },
  '/detail/:id': { render: 'native', reason: '核心转化路径' },
  '/help': { render: 'web', reason: '内容页（无需性能）' },
};
class RouteRenderDispatcher {
  navigate(path) {                                              // 路由分发
    const strategy = routeRenderStrategy[path];
    if (strategy.render === 'native') {
      this.nativeNavigator.push(path);                           // Native 渲染
    } else {
      this.webviewNavigator.push(buildH5Url(path));               // WebView 渲染
    }
  }
}
// 优势：运营页面 H5 秒发（不发版）+ 核心页面 Native 性能——混合最优
```
