## XP-157：跨端容器性能剖析：桥开销定位与优化

**答**：
- 桥开销三源：序列化（JSON 大 payload）、频率（高频事件）、阻塞（同步调用占 JS 线程）。
- 定位：桥调用日志（次数/payload 大小/耗时）→ TopN 优化；Payload 审计（HW-809 RN 版本复用）。
- 优化路径：批量提交、payload 瘦身（只传 diff）、高频合帧、大数据走共享内存。

```javascript
class BridgeProfiler {
  wrap(bridge) {                                             // 包装桥调用
    return new Proxy(bridge, { get(t, method) {
      return (...args) => {
        const t0 = performance.now();
        const payload = JSON.stringify(args);
        const result = t[method](...args);
        this.record({ method, size: payload.length, ms: performance.now() - t0 });
        return result;
      };
    } });
  }
  record(call) {                                             // 采样记录
    this.calls.push(call);
    if (call.size > 256 * 1024) warn('bridge-payload-oversize', call);
    if (this.calls.length > 1000) this.report();
  }
  report() {                                                  // TopN 报告
    const byMethod = groupBy(this.calls, 'method');
    return Object.entries(byMethod).map(([m, calls]) => ({
      method: m, count: calls.length,
      totalKB: +(calls.reduce((s, c) => s + c.size, 0) / 1024).toFixed(1),
      p75Ms: percentile(calls.map(c => c.ms), 0.75),
    })).sort((a, b) => b.totalKB - a.totalKB);
  }
}
```
