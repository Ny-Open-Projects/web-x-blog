## AV-362：音视频同步的机制与漂移处理

**答**：
- 基准：音频时钟为 master（人耳敏感），视频帧按 audioTime 对齐呈现。
- 漂移来源：音视频采集时钟不同晶振（ ppm 级漂移）、网络抖动导致缓冲不齐。
- 处理：播放器 jitter buffer 动态调整（音频主时钟），视频晚/早丢帧或重复帧追赶。

```javascript
// 音视频同步
function syncAV(video, audio, { maxDriftMs = 40 } = {}) {
  const drift = video.currentTime - audio.currentTime;
  if (Math.abs(drift * 1000) > maxDriftMs) {
    if (drift > 0) video.currentTime = audio.currentTime;   // 视频超前，跳帧
    else video.playbackRate = 1.02;                         // 视频落后，微加速追
  } else video.playbackRate = 1;
  return { driftMs: +(drift * 1000).toFixed(1) };
}
setInterval(() => syncAV(videoEl, audioEl), 1000);
```
