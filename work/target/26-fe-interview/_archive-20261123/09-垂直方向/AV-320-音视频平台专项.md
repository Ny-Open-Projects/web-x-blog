## AV-320：音视频平台专项：直播间数据实时看板（主播端）

**答**：
- 题目：主播端实时看板——在线人数曲线/礼物收益/弹幕热度/观众来源，低延迟（1s 刷新）+ 低开销（移动端）。
- 思路：服务端 1s 聚合推送（增量数据）→ 前端 Sparkline 渲染（VIZ-278 复用）；移动端省电：后台暂停刷新。
- 评分点：增量推送协议；移动端渲染开销；后台暂停。

```javascript
class StreamerDashboard {
  onDataTick(metrics) {                                        // 1s 增量推送
    if (document.hidden) return;                              // 后台暂停渲染
    this.onlineCurve.push(metrics.onlineCount);                // 在线人数曲线
    this.renderSparklines();                                    // Sparkline（轻量）
  }
  renderSparklines() {
    // Sparkline：单 path + 涨跌色（VIZ-278）——移动端 GPU 占用极低
    this.onlineChart.update(sparkline(this.onlineCurve.slice(-60)));   // 最近 60s
    this.incomeChart.update(sparkline(this.incomeCurve.slice(-60)));
  }
}
// 服务端聚合：每秒 diff（新增/退出人数）推送增量——非全量（省带宽）
```
