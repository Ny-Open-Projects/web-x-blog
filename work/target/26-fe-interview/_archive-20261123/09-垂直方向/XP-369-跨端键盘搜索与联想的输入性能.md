## XP-369：跨端键盘搜索与联想的输入性能

**答**：
- 链路：输入 -> 防抖 -> 联想请求 -> 渲染下拉；IME 中文需 composition 保护（326）。
- 性能：联想结果缓存（同前缀命中）、预取热词、下拉虚拟滚动。
- 竞态：旧请求响应覆盖新结果——seq 竞态防护。

```javascript
// 联想竞态防护
let seq = 0;
async function suggest(q) {
  const my = ++seq;
  const r = await api('/suggest', { q });
  if (my !== seq) return null;                       // 过期响应丢弃
  return r;
}
// 防抖 150ms + IME 保护 + seq 竞态 = 完整方案
```
