## XP-356：跨端支付流程的性能与体验

**答**：
- 性能：支付 SDK 懒加载（进入收银台才加载）、预下单提前（确认订单时）。
- 体验：支付结果轮询/回调（订单状态机），失败重试路径清晰。
- 安全：金额服务端裁决（1087）、防重放（幂等键）。

```javascript
// 支付编排
async function pay(orderId) {
  const { prepayId, sign } = await prefetchOrder(orderId);   // 提前预下单
  const result = await adapter.pay(prepayId, sign);  // 拉起支付
  const status = await pollOrderStatus(orderId, { maxWaitMs: 10_000 });
  if (status === 'paid') navigate('/success');
  else if (status === 'pending') showPendingUI();     // 轮询中提示
  else retryFlow();
}
```
