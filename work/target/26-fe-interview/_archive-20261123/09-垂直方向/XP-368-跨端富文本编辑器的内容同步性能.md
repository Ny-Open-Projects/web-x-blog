## XP-368：跨端富文本编辑器的内容同步性能

**答**：
- 问题：富文本操作流高频（输入/格式化）——全量序列化同步卡。
- 方案：操作级同步（插入/删除/格式命令）+ 协作库（Yjs YText）增量、节流 100ms。
- 大小限制：超长文档分页加载（虚拟滚动 + 分段同步）。

```javascript
// 富文本增量同步
function richTextSync(editor, doc) {
  const ytext = doc.getText('content');
  editor.on('ops', ops => {                          // 编辑器操作流
    for (const op of ops) {
      if (op.type === 'insert') ytext.insert(op.index, op.text);
      if (op.type === 'delete') ytext.delete(op.index, op.len);
    }
  });
  ytext.observe(() => editor.applyRemote(ytext.toString()));
}
```
