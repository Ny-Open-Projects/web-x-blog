## AV-381：直播录制与回放的时间轴对齐

**答**：
- 录制：SFU/边缘录制各流（独立时间轴），回放时按 NTP 时间戳对齐混合。
- 回放交互：多流时间轴同步 seek（拖一条全部跟），信号事件（打赏/连麦）叠加时间轴。
- 格式：fMP4 分段 + 元数据轨（事件）——支持增量上传与断点录制。

```javascript
// 回放时间轴对齐
function alignReplay(streams, masterId) {
  const master = streams.find(s => s.id === masterId);
  const offset = streams.map(s => ({
    id: s.id, delta: s.startNtp - master.startNtp }));
  return {
    seekAll(t) { return offset.map(o =>
      ({ id: o.id, t: Math.max(0, t + o.delta / 1000) })); },
    events: streams.flatMap(s => s.events.map(e =>
      ({ ...e, t: e.t + offset.find(o => o.id === s.id).delta / 1000 })))
      .sort((a, b) => a.t - b.t),
  };
}
```
