## XP-274：跨端容器专项：容器与小程序互跳（笔试）

**答**：
- 题目：App 容器跳小程序（微信开放 SDK）——跳转小程序（携带参数/登录态）、小程序跳回 App（deepLink）；参数传递安全。
- 思路：App → 小程序（微信 SDK launchMiniProgram 带参数）；小程序 → App（scheme deepLink）；参数安全（签名防篡改/敏感信息不透传）。
- 评分点：双向跳转；参数签名；安全考量。

```javascript
class MiniProgramJump {
  async openMiniProgram(appId, path, params) {                   // App → 小程序
    const signature = await serverSign({ appId, path, params });   // 服务端签名（防篡改）
    wx.openMiniProgram?({                                          // 微信 SDK
      appId, path: `${path}?data=${encodeURIComponent(serialize(params))}&sign=${signature}`,
    });
  }
  onReturnFromMiniProgram(result) {                              // 小程序 → App
    // 小程序通过 scheme/broadcast 回传结果
    const { data, sign } = result;
    if (!verifySign(data, sign)) throw new Error('signature-invalid');   // 验签
    this.handleResult(data);
  }
}
// 安全：参数签名（防中间篡改）、敏感信息不透传（token 通过服务端换取）
```
