## XP-336：跨端日志体系：分端采集与统一检索

**答**：
- 采集：各端日志 adapter（级别/traceId/上下文）统一 schema 上报。
- 检索：traceId 贯穿前端-网关-服务端，问题会话一键还原。
- 成本：日志分级采样（debug 10%/info 50%/error 100%）。

```javascript
// 日志统一
function createLogger(adapter, { traceId } = {}) {
  const LEVELS = { debug: 0.1, info: 0.5, warn: 1, error: 1 };
  return function log(level, msg, ctx = {}) {
    if (Math.random() > LEVELS[level]) return;       // 采样
    adapter.send({ level, msg: redact(msg), traceId,
      page: currentRoute(), ...ctx, ts: Date.now() });
  };
}
```
