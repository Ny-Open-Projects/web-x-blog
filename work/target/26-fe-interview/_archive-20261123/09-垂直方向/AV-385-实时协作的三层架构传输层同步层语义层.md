## AV-385：实时协作的三层架构：传输层/同步层/语义层

**答**：
- 传输层：WebSocket/WebRTC DataChannel，解决"消息到达"；可靠有序 vs 不可达低延迟可选。
- 同步层：状态收敛（OT/CRDT/快照+增量），解决"多端一致"。
- 语义层：操作模型（文档/画板/表格的领域操作），解决"业务正确"——冲突在该层定义。

```javascript
// 三层职责划分
const LAYERS = {
  transport: { concern: '到达/顺序/重连', tech: 'WS + 心跳 + 序号' },
  sync: { concern: '收敛/合并/版本', tech: 'CRDT (Yjs) 或 OT' },
  semantic: { concern: '领域操作合法性', tech: '业务 schema 校验' },
};
// 典型画板：传输 WS 不可达模式（丢帧可容忍）
// 同步 Yjs updates + 周期快照；语义：图形对象 schema
```
