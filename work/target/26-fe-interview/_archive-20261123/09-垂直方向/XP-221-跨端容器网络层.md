## XP-221：跨端容器网络层：统一请求库与拦截器

**答**：
- 跨端网络层：统一请求接口（fetch/wx.request/RN fetch 适配）+ 拦截器链（鉴权/重试/缓存/埋点）。
- 拦截器链：request 拦截（token 注入）→ 发送 → response 拦截（错误分类/重试）——洋葱模型。
- 实现：适配层注入（XP-166 复用）+ 洋葱模型中间件。

```javascript
class UnifiedHttpClient {
  constructor(adapter) { this.adapter = adapter; this.interceptors = []; }
  use(interceptor) { this.interceptors.push(interceptor); return this; }   // 洋葱模型
  async request(options) {
    let ctx = { options, response: null, error: null };
    for (const interceptor of this.interceptors)                 // 前置拦截
      ctx = await interceptor.before(ctx) ?? ctx;
    try {
      ctx.response = await this.adapter.request(ctx.options);     // 发送（平台适配）
    } catch (e) {
      ctx.error = e;
      for (const interceptor of [...this.interceptors].reverse())  // 错误拦截（逆序）
        ctx = await interceptor.onError?.(ctx) ?? ctx;
    }
    for (const interceptor of [...this.interceptors].reverse())   // 后置拦截
      ctx = await interceptor.after?.(ctx) ?? ctx;
    return ctx.response;
  }
}
// 用法：client.use(authInterceptor).use(retryInterceptor).use(trackingInterceptor)
```
