## XP-279：跨端容器专项：容器渲染帧率监控与掉帧归因（笔试）

**答**：
- 题目：容器帧率监控——rAF 采样帧间隔（HW-679 复用）→ 掉帧归因（桥调用/重渲染/图片解码）→ 归因上报。
- 思路：rAF 采样帧间隔 → 掉帧（间隔 > 32ms）时记录当时桥调用/渲染操作 → 归因（桥频次高/渲染耗时高/图片解码）。
- 评分点：帧率采样；掉帧归因；上报格式。

```javascript
class FrameDropAttribution {
  startMonitoring() {                                            // 帧率监控
    let lastFrame = performance.now();
    const tick = (now) => {
      const interval = now - lastFrame; lastFrame = now;
      if (interval > 32) {                                        // 掉帧（< 30fps）
        this.attribute(interval);                                  // 归因
      }
      requestAnimationFrame(tick);
    };
    requestAnimationFrame(tick);
  }
  attribute(interval) {                                            // 掉帧归因
    const bridgeCalls = this.bridgeLog.lastWindow();                // 窗口内桥调用
    const renders = this.renderLog.lastWindow();                    // 渲染操作
    const cause = bridgeCalls.length > 3 ? 'bridge-flood'
      : renders.some(r => r.ms > 16) ? 'heavy-render'
      : 'image-decode';
    report('frame-drop', { interval, cause, bridgeCalls: bridgeCalls.length });
  }
}
```
