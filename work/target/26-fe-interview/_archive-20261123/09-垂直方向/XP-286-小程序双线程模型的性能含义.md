## XP-286：小程序双线程模型的性能含义

**答**：
- 逻辑层（JS）与渲染层（WebView）分离，setData 是唯一桥梁——频繁/大批量 setData 是性能头号杀手。
- 通信成本：序列化 + 跨线程消息，10KB 数据 ~5-20ms。
- 优化：setData 只传变化字段、合并高频更新（100ms 合帧）、避免大对象全量传。

```javascript
// setData 优化
function smartSetData(page, patch) {
  // 只传变化字段：diff 上一份数据
  const diff = {};
  for (const [k, v] of Object.entries(patch))
    if (JSON.stringify(page.data[k]) !== JSON.stringify(v)) diff[k] = v;
  if (Object.keys(diff).length) page.setData(diff);
}
// 高频合并：
let pending = null;
function batchSet(page, patch) {
  pending = { ...pending, ...patch };
  if (pendingTimer) return;
  pendingTimer = setTimeout(() => {
    smartSetData(page, pending); pending = null; pendingTimer = null;
  }, 100);
}
```
