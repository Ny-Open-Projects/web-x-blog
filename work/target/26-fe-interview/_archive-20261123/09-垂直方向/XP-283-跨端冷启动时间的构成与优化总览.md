## XP-283：跨端冷启动时间的构成与优化总览

**答**：
- 构成：进程创建 → 引擎初始化（JS 引擎/渲染引擎）→ 框架加载 → 首屏数据请求 → 首帧渲染。
- 优化杠杆：引擎预热（常驻进程）、包体瘦身、首屏数据预取、懒加载非关键模块。
- 度量口径：冷启动 P75 分端统计（iOS/Android/低端机），目标 < 2s。

```javascript
// 冷启动分段打点
const STAGES = ['proc', 'engine', 'framework', 'data', 'first-paint'];
function coldStartTrace() {
  const marks = {};
  STAGES.forEach(s => performance.mark(s));
  return STAGES.map((s, i) => ({
    stage: s, ms: i === 0 ? 0
      : Math.round(performance.now() - marks[STAGES[i-1]] ?? 0) }));
}
// 各段超标对应优化：proc 长->进程常驻；framework 长->包拆分；data 长->预取
```
