## AV-301：音视频场景专项：音视频会议中的屏幕标注延迟优化

**答**：
- 题目：屏幕共享标注（HW-AV-265）延迟优化——标注事件走 DataChannel（不可靠模式够用，丢帧补全）+ 本地预测渲染（发送前先画）。
- 思路：本地先画（预测性渲染）→ 异步广播；接收端增量应用；丢帧时下一帧含全量路径起点（自愈）。
- 评分点：预测渲染；丢帧自愈；通道选型。

```javascript
class LowLatencyAnnotation {
  onLocalDraw(point) {
    this.canvas.drawPoint(point);                            // ① 本地即时画（预测）
    this.dc.send(JSON.stringify({ type: 'point', point }));   // ② 异步广播
  }
  onRemotePoint({ point, strokeId }) {                        // 接收端
    this.canvas.drawPoint(point, strokeId);
    if (!this.strokes.has(strokeId))                          // 丢了起点：请求快照自愈
      this.requestSnapshot();
  }
}
// DataChannel 配置：{ ordered: false, maxRetransmits: 1 }——低延迟优先，丢 1 点可容忍
// 自愈：每笔画前发「起点绝对坐标」——丢中间点画线仍大致正确
```
