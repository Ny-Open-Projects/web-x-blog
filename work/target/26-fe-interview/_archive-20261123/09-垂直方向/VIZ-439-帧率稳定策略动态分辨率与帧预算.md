## VIZ-439：帧率稳定策略：动态分辨率与帧预算

**答**：
- 动态分辨率：监控帧时间 > 预算（如 15ms）时降渲染分辨率（0.7×），反之恢复——FPS 平滑优于固定低分辨率。
- 实现：EMA 平滑帧时间 + 迟滞（降后至少 30 帧才升），避免分辨率抖动。
- 配合：降分辨率 + 提升后处理质量不可兼得时，优先保分辨率（感知更明显）。

```javascript
// 动态分辨率控制器
function dynamicRes({ budgetMs = 15, step = 0.1, min = 0.5, max = 1 } = {}) {
  let scale = 1, ema = budgetMs, hold = 0;
  return function onFrame(frameMs) {
    ema = ema * 0.9 + frameMs * 0.1;
    if (hold > 0) { hold--; return scale; }
    if (ema > budgetMs * 1.15 && scale > min) {
      scale = Math.max(min, scale - step); hold = 30;      // 降后保持
    } else if (ema < budgetMs * 0.85 && scale < max) {
      scale = Math.min(max, scale + step); hold = 60;
    }
    return scale;
  };
}
```
