## AV-383：音视频监控大盘的核心指标设计

**答**：
- 维度：成功率（join 成功率）、延迟（首帧/E2E）、质量（卡顿率/码率/分辨率分布）、稳定（错误率/断连率）。
- 聚合：按房间/地区/运营商/设备分桶，P75 口径（RUM 一致）。
- 告警：join 成功率 < 95% 或首帧 P75 > 2s 页值班。

```javascript
// 大盘聚合
function avDashboard(samples, slo = { firstFrame: 2000, joinRate: 0.95 }) {
  const first = samples.map(s => s.firstFrameMs).filter(Boolean).sort((a, b) => a - b);
  const p75 = first[Math.floor(first.length * 0.75)] ?? 0;
  const joinOk = samples.filter(s => s.joined).length / (samples.length || 1);
  return { samples: samples.length, firstFrameP75: p75,
    joinRate: +joinOk.toFixed(3),
    violations: [
      p75 > slo.firstFrame && `首帧 P75 ${p75}ms 超标`,
      joinOk < slo.joinRate && `join 成功率 ${(joinOk * 100).toFixed(1)}% 低于线`,
    ].filter(Boolean) };
}
```
