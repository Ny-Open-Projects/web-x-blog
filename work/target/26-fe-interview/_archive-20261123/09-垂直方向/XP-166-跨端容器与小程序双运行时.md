## XP-166：跨端容器与小程序双运行时：同一业务两端跑

**答**：
- 业务双端跑：同一份业务逻辑（数据层/状态层）跑在自研容器和小程序——平台适配层隔离差异（路由/存储/请求）。
- 适配层：PlatformAdapter 接口（navigate/setStorage/request）——容器实现与小程序实现各自封装；业务层只调接口。
- 构建分流：构建时按平台注入适配器实现（条件编译/运行时探测）。

```javascript
// platform-adapter.js（平台适配层）
class ContainerAdapter {                                     // 自研容器实现
  navigate(route) { nativeNavigator.push(route); }
  setStorage(k, v) { NativeStorage.set(k, v); }
  request(options) { return nativeFetch(options); }
}
class MiniProgramAdapter {                                   // 小程序实现
  navigate(route) { wx.navigateTo({ url: route }); }
  setStorage(k, v) { wx.setStorageSync(k, v); }
  request(options) { return new Promise((res, rej) =>
    wx.request({ ...options, success: res, fail: rej })); }
}
// 业务层：import adapter from './platform-adapter'（构建时注入对应实现）
// adapter.navigate('/detail?id=1')——业务代码零平台判断
```
