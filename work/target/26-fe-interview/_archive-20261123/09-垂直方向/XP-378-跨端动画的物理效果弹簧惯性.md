## XP-378：跨端动画的物理效果（弹簧/惯性）

**答**：
- 弹簧动画：spring 参数（stiffness/damping）跨端数学一致（积分实现）。
- 实现：原生侧弹簧（iOS UIDynamicAnimator/RN Reanimated/Flutter SpringSimulation）。
- 性能：弹簧逐帧积分在原生线程，JS 只设定参数。

```javascript
// 弹簧参数统一
const SPRING = {
  gentle: { stiffness: 120, damping: 14 },
  bouncy: { stiffness: 180, damping: 12 },
};
function springConfig(name) {
  const s = SPRING[name] ?? SPRING.gentle;
  return { ...s,
    rn: { useNativeDriver: true, ...s },               // Reanimated
    flutter: { stiffness: s.stiffness, damping: s.damping } };
}
```
