## XP-345：跨端工程收口：踩坑清单沉淀

**答**：
- 清单来源：历史事故（白屏/崩溃/卡顿）逐条沉淀"症状-根因-修复-预防"。
- 落地：checklist 进 MR 模板 + lint 规则自动化可检项。
- 机制：季度评审清单有效性，删除过时项。

```javascript
// 踩坑清单
const PITFALLS = [
  { symptom: 'iOS 键盘弹起遮挡输入', fix: 'resize 监听滚动到位',
    prevent: '输入组件统一封装' },
  { symptom: '小程序 setData 大数组卡顿', fix: '路径更新+分页',
    prevent: 'setData 体积 lint' },
  { symptom: 'RN 列表图片内存暴涨', fix: 'FastImage+缓存上限',
    prevent: '图片组件准入' },
];
function pitfallIndex(keyword) {
  return PITFALLS.filter(p => p.symptom.includes(keyword));
}
```
