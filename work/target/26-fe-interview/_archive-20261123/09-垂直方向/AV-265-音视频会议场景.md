## AV-265：音视频会议场景：屏幕共享标注协作

**答**：
- 屏幕共享协作：共享者共享屏幕，观看者可在共享画面上标注（箭头/文字）——标注层独立 canvas，标注事件广播给全员。
- 实现：观看者标注 → 信令广播标注数据 → 共享者端渲染标注 overlay（叠加在共享画面上）。
- 权限：只有「演示者指定的协作者」可标注。

```javascript
class ScreenAnnotation {
  constructor(signaling) { this.signaling = signaling; }
  onRemoteAnnotation(annotation) {                           // 远端标注渲染
    this.overlayCanvas.draw(annotation);                     // 箭头/文字叠加
  }
  sendAnnotation(annotation) {                               // 本地标注广播
    this.signaling.send('annotation', { ...annotation, ts: Date.now() });
  }
  clearAll() { this.overlayCanvas.clear(); this.signaling.send('annotation-clear'); }
}
// 标注坐标：归一化（0~1 相对共享画面）——接收端分辨率无关渲染
// 权限：signaling 校验 annotation 权限（演示者授权列表）
```
