## XP-156：跨端容器事件系统：触摸事件与手势桥接

**答**：
- Native 触摸事件 → 桥 → JS 侧手势识别（HW-832 复用）——事件流：touchstart/move/up 序列带 nodeId。
- 手势冲突：Native 手势（系统返回手势）与 JS 手势冲突 → Native 侧优先级声明（手势竞争仲裁）。
- 优化：连续 move 事件 Native 侧合帧（16ms）再桥传——避免高频桥调用。

```javascript
// Native → JS 事件流
class TouchEventBridge {
  onTouch(nodeId, eventType, touches) {                     // Native 回调
    if (eventType === 'move' && !this.pendingMove) {
      // 合帧：16ms 内只发一次 move
      this.pendingMove = setTimeout(() => {
        bridge.send({ type: 'touch', nodeId, event: 'move', touches: this.latestTouches });
        this.pendingMove = null;
      }, 16);
      this.latestTouches = touches;
    } else bridge.send({ type: 'touch', nodeId, event: eventType, touches });
  }
}
// JS 侧手势识别：tap/pan/pinch（复用 HW-832 GestureEngine）
// 手势竞争：Native 声明「本 View 处理左滑」→ JS 手势在该方向让位
```
