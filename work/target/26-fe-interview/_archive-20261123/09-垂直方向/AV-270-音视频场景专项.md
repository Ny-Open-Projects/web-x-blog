## AV-270：音视频场景专项：虚拟背景与背景分割

**答**：
- 虚拟背景：人体分割（MediaPipe/SelfieSegmentation）→ 前景贴新背景；模糊背景 = 背景区高斯模糊。
- 实现：MediaPipe SelfieSegmentation（WebAssembly/WebGL）→ segmentation mask → WebGL 合成（前景原样 + 背景替换）。
- 性能：720p30 分割 GPU ~10ms/帧；低端机降帧（15fps 分割 + 帧复用）。

```javascript
class VirtualBackground {
  async init(video, background) {
    const selfie = await selfieSegmentation.create();        // MediaPipe
    selfie.onResults((results) => {
      this.mask = results.segmentationMask;                  // 分割 mask
      this.composite(video, this.mask, background);          // WebGL 合成
    });
    setInterval(() => selfie.send({ image: video }), 66);     // 15fps 分割（帧复用 30fps 输出）
```
