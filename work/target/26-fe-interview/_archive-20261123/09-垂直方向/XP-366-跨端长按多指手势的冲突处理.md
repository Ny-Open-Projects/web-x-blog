## XP-366：跨端长按/多指手势的冲突处理

**答**：
- 冲突：长按（上下文菜单）与拖拽、双指缩放与滚动——手势优先级表。
- 实现：手势状态机（等待阈值时间/指数量后锁定），锁定后独占。
- 跨端：原生手势模块统一仲裁逻辑（bridge 分发）。

```javascript
// 手势优先级
const GESTURE_PRIORITY = [
  { name: 'pinch', minPointers: 2 },                 // 多指优先
  { name: 'longpress', minMs: 500 },
  { name: 'drag', minMove: 8 },
  { name: 'tap', minMove: 0 },
];
function arbiter(state) {
  for (const g of GESTURE_PRIORITY)
    if (matchGesture(g, state)) return g.name;       // 首个匹配锁定
  return null;
}
```
