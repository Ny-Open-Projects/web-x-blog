## XP-270：跨端容器专项：容器与原生混合——视频播放器页面（笔试）

**答**：
- 题目：视频播放器页面——容器渲染控制层（按钮/进度条）+ Native 渲染视频层（Surface），控制层随播放状态更新。
- 思路：Native 层：视频渲染（SurfaceView/TextureView）；JS 层：控制层（进度条/按钮）；桥通信（播放状态/进度 → JS 更新控制层）。
- 评分点：分层渲染；状态桥接；控制层更新节流。

```javascript
class VideoPlayerPage {
  constructor(nativePlayer) {                                   // 分层
    this.nativePlayer = nativePlayer;                             // Native 视频层
    this.controls = createControls();                              // JS 控制层
    nativePlayer.onProgress = throttle((position, duration) => {   // 进度节流
      bridge.commit([{ op: 'update-controls',
        progress: position / duration, buffered: nativePlayer.buffered }]);   // 控制层更新
    }, 500);                                                       // 500ms 节流（进度条）
  }
  onPlayPause() { bridge.commit([{ op: 'toggle-play' }]); }        // 播放/暂停（Native 执行）
}
```
