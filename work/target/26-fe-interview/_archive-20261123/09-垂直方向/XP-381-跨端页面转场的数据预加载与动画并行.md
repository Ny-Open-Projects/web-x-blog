## XP-381：跨端页面转场的数据预加载与动画并行

**答**：
- 并行：转场动画进行中同时拉数据（动画 300ms 掩盖请求）。
- 实现：转场启动即发请求（Promise 并行），页面就绪后渲染；数据慢时骨架兜底。
- 度量：转场到内容就绪总时长（而非分开考核）。

```javascript
// 转场并行
async function transitionWithFetch(route, fetcher) {
  const anim = startTransition(route, 300);          // 动画启动
  const data = fetcher();                            // 并行请求
  await Promise.all([anim, data.catch(() => null)]);
  render(await data);                                // 数据就绪渲染
}
```
