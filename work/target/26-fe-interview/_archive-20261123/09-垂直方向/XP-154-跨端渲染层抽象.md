## XP-154：跨端渲染层抽象：React/Vue/自研 DSL 多框架适配

**答**：
- 渲染层抽象：核心渲染指令集不变，上层框架可替换（React/Vue/自研 DSL）——通过「渲染器接口」（类 React Reconciler）适配。
- 适配器：每个框架实现 {createInstance/updateInstance/appendChild/removeChild} → 映射到指令集。
- 价值：业务团队可选用熟悉框架，容器层统一维护。

```javascript
// React 适配器（类 react-reconciler）
const ReactAdapter = {
  createInstance(type, props) {                             // 创建元素
    return { nodeId: genId(), type, props };
  },
  appendChild(parent, child) { bridge.commit([{ op: 'insertChild',
    parentId: parent.nodeId, nodeId: child.nodeId, index: parent.children.length }]); },
  removeChild(parent, child) { bridge.commit([{ op: 'remove', nodeId: child.nodeId }]); },
  commitUpdate(instance, props) {                            // 属性更新
    bridge.commit([{ op: 'update', nodeId: instance.nodeId, props }]);
  },
};
// Vue 适配器：customRenderer（Vue3 createRenderer API）——同一指令集
// DSL 适配器：自研模板编译 → 直接生成指令集（无 VDOM diff）
```
