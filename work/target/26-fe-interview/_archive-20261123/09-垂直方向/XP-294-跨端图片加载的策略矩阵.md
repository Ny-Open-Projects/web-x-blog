## XP-294：跨端图片加载的策略矩阵

**答**：
- 策略：尺寸适配（按容器 DPR 请求）、格式协商（AVIF/WebP/JPEG 探测）、懒加载 + 预热半径、占位（模糊缩略/骨架）。
- 跨端差异：小程序 image lazy-load、RN FastImage（原生缓存）、Flutter cached_network_image。
- 度量：图片加载失败率/平均耗时/内存（大图解码爆内存）。

```javascript
// 图片策略统一
function imageStrategy({ containerW, dpr, supports }) {
  return {
    width: Math.round(containerW * dpr),
    format: supports.avif ? 'avif' : supports.webp ? 'webp' : 'jpeg',
    lazy: true, rootMargin: '200px',
    placeholder: 'blur',                             // 模糊占位
  };
}
// 探测缓存一次：
const supports = { avif: checkAvif(), webp: checkWebp() };
```
