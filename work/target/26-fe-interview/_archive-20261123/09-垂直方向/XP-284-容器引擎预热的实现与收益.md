## XP-284：容器引擎预热的实现与收益

**答**：
- 预热：App 启动后 idle 时预创建 WebView/JS 引擎实例，打开页面时直接复用。
- 收益：WebView 创建 ~200-400ms，预热后首开省 30-50%。
- 细节：预热实例要加载 about:blank + 注入 JSBridge，避免白屏闪烁（预置骨架）。

```javascript
// WebView 池预热（简化）
class WebViewPool {
  constructor(size = 3) { this.pool = []; this.size = size; }
  warmup(createFn) {
    while (this.pool.length < this.size) {
      const wv = createFn();
      wv.loadUrl('about:blank');                    // 占位
      wv.__ready = true;
      this.pool.push(wv);
    }
  }
  acquire(createFn) {
    const wv = this.pool.pop() ?? createFn();
    wv.__ready = false;
    return wv;
  }
  release(wv) {
    if (this.pool.length < this.size) { wv.loadUrl('about:blank'); this.pool.push(wv); }
    else wv.destroy();                               // 超量销毁
  }
}
```
