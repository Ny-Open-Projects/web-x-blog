## XP-351：跨端离线包的版本管理与更新策略

**答**：
- 版本：离线包带版本号，服务端差量下发（bsdiff/自定义 diff）。
- 时机：启动时后台检查（不阻塞）、WiFi 优先下载、备用整包兜底。
- 校验：包签名+版本回滚能力（保留上一版本可切回）。

```javascript
// 离线包更新
async function offlinePackageUpdate(pkg) {
  const local = await getLocalVersion(pkg.id);
  if (local === pkg.version) return { updated: false };
  const diffUrl = pkg.diffs?.[local];                // 差量优先
  try {
    const data = diffUrl
      ? await applyDiff(await download(diffUrl), local)
      : await download(pkg.fullUrl);
    await verifySig(data, pkg.sig);                  // 签名校验
    await apply(data);
    keepPreviousVersion(local);                       // 回滚能力
    return { updated: true, from: local, to: pkg.version };
  } catch (e) {
    report({ type: 'pkg-update-fail', msg: e.message });
    return { updated: false, fallback: '用本地版本' };
  }
}
```
