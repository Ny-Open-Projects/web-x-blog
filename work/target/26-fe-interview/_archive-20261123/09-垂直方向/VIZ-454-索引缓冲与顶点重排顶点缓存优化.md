## VIZ-454：索引缓冲与顶点重排（顶点缓存优化）

**答**：
- 索引复用：共享顶点（三角形条带化顶点缓存命中率）——GPU 顶点缓存 32~64 顶点窗口。
- 优化工具：meshoptimizer（vertex cache/vertex fetch 优化重排索引）。
- 收益：顶点着色器重复执行减少 20~40%（复杂顶点着色器时明显）。

```javascript
// 顶点缓存命中率估算
function vertexCacheScore(indices, cacheSize = 32) {
  const cache = []; let hits = 0, miss = 0;
  for (const i of indices) {
    const idx = cache.indexOf(i);
    if (idx >= 0) { hits++; cache.splice(idx, 1); }
    else miss++;
    cache.unshift(i);
    if (cache.length > cacheSize) cache.pop();
  }
  return { hitRate: +(hits / (hits + miss) * 100).toFixed(1) + '%' };
}
```
