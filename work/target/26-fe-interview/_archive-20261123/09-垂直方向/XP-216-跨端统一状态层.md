## XP-216：跨端统一状态层：业务逻辑与渲染分离

**答**：
- 跨端统一状态：业务逻辑/状态层平台无关（纯 TS）→ 各端渲染层消费（React/RN/小程序/Flutter 桥接）。
- 实现：核心状态库（Zustand/自研 store，纯 TS 无 DOM）→ 各端绑定层（React hooks/小程序 mobx 绑定/Flutter stream）。
- 收益：业务逻辑一次编写多端复用；渲染层各端最优化。

```javascript
// core/store.ts（平台无关，纯 TS）
import { createStore } from 'zustand/vanilla';                  // vanilla：无 React 依赖
export const useCartStore = createStore((set) => ({
  items: [],
  addItem: (item) => set((s) => ({ items: [...s.items, item] })),
}));
// React 绑定（Web/RN）
import { useStore } from 'zustand';
const items = useStore(useCartStore, (s) => s.items);            // hook 绑定
// 小程序绑定（手动订阅）
useCartStore.subscribe((state) => {
  this.setData({ items: state.items });                          // setData 同步
});
// Flutter 绑定（Stream）
useCartStore.subscribe((state) => streamController.add(state));   // Stream 驱动 rebuild
// 业务逻辑 100% 复用——各端只写绑定层
```
