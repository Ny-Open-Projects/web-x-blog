## XP-299：跨端包体优化：按端拆包与条件编译

**答**：
- 条件编译：UNI_PLATFORM/Taro 平台常量裁剪平台专属代码——产物只含当前端代码。
- 度量：各端 bundle 体积对比 + 重复依赖检查（跨端库重复打包）。
- 策略：公共代码抽包，端差异用 adapter 模式（编译期选择实现）。

```javascript
// 条件编译（uni-app 风格）
// #ifdef MP-WEIXIN
wx.login({ success: res => useWxAuth(res.code) });
// #endif
// #ifdef H5
useWebAuth();
// #endif
// 构建产物体积对比：
function bundleReport(bundles) {
  return Object.entries(bundles).map(([end, kb]) =>
    ({ end, kb, over: kb > 2000 }));                 // 2MB 门禁
}
```
