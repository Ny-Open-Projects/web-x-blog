## AV-272：音视频录制质量：码率/帧率/分辨率的最佳实践矩阵

**答**：
- 录制参数矩阵：屏幕录制（5fps 2M 文档 / 30fps 4M 游戏）、摄像头（30fps 2M 会议）、音频（128k Opus）。
- MediaRecorder 参数：videoBitsPerSecond/audioBitsPerSecond/framerate——高码率不等于好（存储/上传成本）。
- 存储估算：720p 2Mbps 1 小时 ≈ 900MB——录制时长与存储策略（分片上传）。

```javascript
const recordingPresets = {
  screenDoc: { video: { fps: 5, bitrate: 2000000 }, note: '文档：低帧高细节' },
  screenGame: { video: { fps: 30, bitrate: 4000000 }, note: '游戏：高帧高码' },
  camera: { video: { fps: 30, bitrate: 2000000 }, audio: { bitrate: 128000 } },
  storageEstimate: (bitrateMbps, hours) => `${(bitrateMbps * 3600 * hours / 8 / 1024).toFixed(0)}GB`,
};
// 分片上传：timeslice 5s 分片 → 逐片上传（断点续传）→ 服务端拼接（HW-381 管线）
```
