## AV-311：音视频场景专项：连麦间回声排查（远端混音回流）

**答**：
- 题目：连麦中「对方听到自己的回声」但本地无感——远端混音回流排查：B 端外放 → A 端声音被 B 麦克风拾取 → 回传给 A。检测与自救。
- 思路：A 端检测：播放参考音 → B 端回传流中出现同频能量 → 判定回流。自救：A 端提示 B 戴耳机；或 A 端自动降音量。
- 评分点：回流路径理解；检测方法；自救动作。

```javascript
class EchoLoopDetector {
  async detect(peerConnection) {                              // 检测回流
    const stats = await peerConnection.getStats();
    const audio = [...stats.values()].find(r => r.kind === 'audio' && r.type === 'inbound-rtp');
    // 对端 audioLevel 持续 > 0 但对端处于静音状态 → 回声回流（对方麦克风拾取了我们的外放）
    const remoteMuted = this.remoteState.mic === false;
    const remoteSpeaking = (audio?.audioLevel ?? 0) > 0.05;
    if (remoteMuted && remoteSpeaking) {
      fire('echo-loop-detected', { peerId: this.remotePeerId });
      return { echo: true, advice: '对方设备外放拾音，请对方戴耳机或降低音量' };
    }
    return { echo: false };
  }
}
```
