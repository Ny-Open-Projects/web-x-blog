## AV-403：协作消息的幂等与去重（重发安全）

**答**：
- 问题：网络重试导致重复投递——CRDT 幂等天然容忍，但非 CRDT 操作（如外部 API 调用）需去重。
- 手段：消息带唯一 opId，服务端 seen set（窗口化）去重；客户端重发同一 opId。
- 审计：去重事件上报（量大会暴露网络质量问题）。

```javascript
// 消息去重
class DedupeWindow {
  constructor(size = 10_000) { this.seen = new Set(); this.order = []; this.size = size; }
  check(opId) {
    if (this.seen.has(opId)) return false;             // 重复
    this.seen.add(opId); this.order.push(opId);
    if (this.order.length > this.size)
      this.seen.delete(this.order.shift());            // 窗口淘汰
    return true;
  }
}
```
