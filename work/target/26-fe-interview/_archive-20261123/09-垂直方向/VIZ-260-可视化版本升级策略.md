## VIZ-260：可视化版本升级策略：渲染引擎切换灰度

**答**：
- 图表库引擎切换（SVG→Canvas→WebGPU）灰度：按流量/场景灰度，双跑对比（截图 diff + 性能指标）。
- 灰度开关：引擎选择器（feature flag）；回退：性能劣化/渲染错误自动回退旧引擎。
- 双跑验收：同一数据双引擎渲染 → 像素 diff < 阈值 + 性能不劣化 → 扩量。

```javascript
class EngineGrayscale {
  async shouldUseGPU(userId) {
    return await flag('viz-gpu-engine', { uid: userId });   // 灰度开关
  }
  async dualRun(chart, data) {                             // 双跑验证
    const [svgShot, gpuShot] = await Promise.all([
      renderWith('svg', chart, data), renderWith('gpu', chart, data)]);
    const diff = pixelDiff(svgShot, gpuShot, { threshold: 0.05 });
    report('engine-dualrun', { diffRatio: diff.ratio,
      svgMs: svgShot.ms, gpuMs: gpuShot.ms });
    return diff.ratio < 0.05 && gpuShot.ms <= svgShot.ms;   // 视觉一致且不劣化
  }
}
```
