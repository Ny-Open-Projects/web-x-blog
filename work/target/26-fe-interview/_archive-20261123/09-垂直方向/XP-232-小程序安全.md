## XP-232：小程序安全：用户输入与支付安全（笔试）

**答**：
- 题目：小程序支付安全——支付参数服务端签名（前端不碰密钥）、金额校验（服务端二次确认）、防重放（out_trade_no 幂等）。
- 思路：前端只传业务参数 → 服务端生成预支付单（签名）→ 前端调起支付 → 服务端回调验签；金额：服务端按业务计算（不信前端传值）。
- 评分点：签名流程；金额服务端计算；幂等。

```javascript
// 小程序支付安全流程
async function createOrder(itemId) {                              // 前端：只传业务参数
  const { prepayId, paySign } = await api.createOrder({ itemId });   // 服务端签名
  // 前端不传金额（服务端按 itemId 查价计算）
  await wx.requestPayment({ timeStamp: paySign.timeStamp,
    nonceStr: paySign.nonceStr, package: `prepay_id=${prepayId}`,
    sign: paySign.paySign });                                      // 调起支付
}
// 服务端：金额计算 + 验签 + 幂等
// out_trade_no 幂等：同订单号重复回调只处理一次（HW-AV-317 复用）
// 坑：前端传金额 → 被抓包改价 0.01 元 → 损失（必须服务端算价）
```
