## AV-392：协作编辑的权限模型

**答**：
- 层级：房间权限（owner/editor/viewer）+ 对象级锁（编辑中）+ 字段级（如金额只读）。
- 传输执行：服务端按权限过滤 update（未授权操作拒绝并回执），前端只是体验层。
- 审计：所有权限变更与敏感操作留痕（who/what/when）。

```javascript
// 协作权限
const ROLE_CAPS = {
  owner: ['edit', 'delete', 'share', 'manage'],
  editor: ['edit', 'comment'],
  viewer: ['comment'],
};
function canOperate(user, op, doc) {
  const caps = ROLE_CAPS[user.role] ?? [];
  if (!caps.includes(op.kind)) return { ok: false, reason: '角色无权限' };
  if (op.kind === 'delete' && doc.createdBy !== user.id && user.role !== 'owner')
    return { ok: false, reason: '仅创建者可删除' };
  return { ok: true };
}
```
