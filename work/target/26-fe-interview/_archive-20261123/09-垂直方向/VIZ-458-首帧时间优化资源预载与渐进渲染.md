## VIZ-458：首帧时间优化：资源预载与渐进渲染

**答**：
- 3D 首帧贵（模型/纹理/编译）——拆分：骨架场景先渲（低模+纯色），资产流式补齐。
- 度量：FirstRenderTime（首次有画面）与 FullLoadTime 分开考核。
- 手段：模型二进制格式（GLB）+ 预转译（Draco 解码 Worker）+ 纹理低 mip 先行。

```javascript
// 渐进渲染编排
async function progressiveRender(scene, assets) {
  renderPlaceholder(scene);                          // 纯色占位立即出画面
  const low = await loadLowLOD(assets.model);        // 低模 ~200KB
  swapGeometry(low);
  const full = await loadFullLOD(assets.model);      // 后台完整版
  swapGeometry(full);
  for (const tex of assets.textures) await streamTexture(tex);  // 451 分帧
}
```
