## XP-305：跨端骨架屏与占位的统一方案

**答**：
- 统一：占位组件 API（shape/dims）各端实现；骨架样式（灰块/微光动画）由 CSS/原生实现。
- 防 CLS：占位尺寸必须与内容一致（设计稿标注）。
- 时序：骨架显示 < 300ms 避免闪烁（数据快时直接渲染）。

```javascript
// 骨架防闪烁
function SkeletonGate({ data, minShowMs = 300 } = {}) {
  const [show, setShow] = useState(!data);
  useEffect(() => {
    if (data) {
      const elapsed = performance.now() - startRef.current;
      setTimeout(() => setShow(false),
        Math.max(0, minShowMs - elapsed));            // 数据快也保 300ms
    }
  }, [data]);
  return show ? <Skeleton /> : <Content data={data} />;
}
```
