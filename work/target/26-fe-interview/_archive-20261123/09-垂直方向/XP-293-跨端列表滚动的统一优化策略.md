## XP-293：跨端列表滚动的统一优化策略

**答**：
- 策略集：虚拟列表（窗口渲染）、行高固定（跳过测量）、图片懒加载 + 尺寸预占、行组件 memo。
- 各端映射：Web 虚拟滚动 / 小程序 recycle-view / RN FlatList 参数 / Flutter ListView.builder。
- 度量：滚动帧率（掉帧率 < 1%）、滚动内存稳定（无持续增长）。

```javascript
// 虚拟列表统一抽象
function createVirtualList({ total, rowH, viewportH }) {
  const visibleCount = Math.ceil(viewportH / rowH) + 4;   // overscan
  return {
    rangeFor(scrollTop) {
      const start = Math.max(0, Math.floor(scrollTop / rowH) - 2);
      return { start, end: Math.min(total, start + visibleCount),
        offsetY: start * rowH };
    },
  };
}
// 各端适配层各自实现渲染，计算逻辑复用
```
