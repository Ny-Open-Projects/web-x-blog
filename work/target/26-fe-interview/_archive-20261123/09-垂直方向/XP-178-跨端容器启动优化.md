## XP-178：跨端容器启动优化：JS 引擎预热与代码预解析

**答**：
- 容器冷启动优化：JS 引擎预热（进程预创建）、代码预解析（字节码缓存）、首屏指令集预生成。
- 预热：App 启动时预创建 JS 引擎实例 + 加载核心 chunk（不执行业务代码）→ 进页面时引擎已热。
- 量化：冷启动 1.2s → 预热后 400ms（引擎创建 500ms 被消除）。

```javascript
class EnginePrewarm {
  onAppLaunch() {                                              // App 启动即预热
    requestIdleCallback(async () => {
      this.engine = await createJSEngine();                    // 引擎创建（500ms）
      await this.engine.loadCoreChunk();                        // 核心 chunk 预加载
      this.prewarmed = true;
    });
  }
  async openPage(route) {                                      // 进页面
    if (!this.prewarmed) await this.waitForPrewarm();          // 未热：等待（兜底）
    await this.engine.executePage(route);                       // 页面执行（引擎已热）
  }
}
// 字节码缓存：首次加载编译后缓存字节码（下次启动免解析）——V8 code cache 思想
```
