## XP-219：跨端包体积优化：多端 bundle 分析与瘦身

**答**：
- 题目：跨端应用包体积——RN bundle 分析（metro-bundle-analyzer）、小程序分包分析、Flutter AAB 分析；体积预算门禁。
- 思路：各端体积分析工具 → 找大头（依赖/资源/死代码）→ 瘦身（按需加载/资源压缩/依赖替换）；CI 预算门禁（HW-843 复用）。
- 评分点：分析工具；瘦身手段；门禁。

```javascript
const bundleOptimization = {
  rn: { tool: 'react-native-bundle-visualizer', opts: ['Hermes 字节码（体积减 30%）',
    '依赖按需 import', '资源压缩（图片 webp）'] },
  mp: { tool: '微信开发者工具代码依赖分析', opts: ['分包（HW-203）', '按需注入（XP-204）',
    '清除未用组件'] },
  flutter: { tool: 'flutter build apk --analyze-size',
    opts: ['tree-shake icons', '延迟加载模块', '资源压缩'] },
  gate: 'CI 体积门禁：bundle > 预算 → 阻断合并（HW-843/398 复用）',
  example: 'RN bundle 8M → Hermes + 按需 + 资源压缩 → 4.2M',
};
```
