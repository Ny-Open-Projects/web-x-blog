## XP-335：跨端网络诊断：弱网模拟与真实分布

**答**：
- 模拟：各端弱网工具（Chrome throttling/Charles/小程序真机调试代理）统一参数（3G 400kbps 500ms）。
- 真实分布：RUM 按网络类型/地区分桶，弱网占比驱动优化优先级。
- 验收：弱网档位下核心路径可用（降级生效）。

```javascript
// 弱网验收
function weakNetAcceptance(results, { lcpTarget = 5000, stallTarget = 0.05 } = {}) {
  return {
    lcp: results.lcpP75, pass1: results.lcpP75 <= lcpTarget,
    stall: results.stallRatio, pass2: results.stallRatio <= stallTarget,
    verdict: results.lcpP75 <= lcpTarget && results.stallRatio <= stallTarget
      ? '弱网达标' : '需降级策略加强',
  };
}
```
