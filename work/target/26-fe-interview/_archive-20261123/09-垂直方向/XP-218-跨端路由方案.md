## XP-218：跨端路由方案：声明式路由与深链统一

**答**：
- 跨端路由：声明式路由表（路径 → 页面映射）→ 各端路由实现映射（Web history/RN Navigation/小程序 navigateTo/Flutter Navigator）。
- 深链统一：scheme/deepLink 解析到路由表 → 各端跳转（Web pushState/RN Linking/小程序扫码进入）。
- 实现：路由中间层（route table → platform router adapter）。

```javascript
// 统一路由表
const routes = {
  '/home': { component: HomePage, mp: 'pages/home/index' },
  '/detail/:id': { component: DetailPage, mp: 'pages/detail/index' },
};
// 路由适配器
class UnifiedRouter {
  push(path, params) {                                          // 统一入口
    const route = this.match(path);                              // 匹配路由表
    if (this.platform === 'web') history.pushState(null, '', this.buildUrl(path, params));
    if (this.platform === 'rn') this.navigator.navigate(route.component, params);
    if (this.platform === 'mp') wx.navigateTo({ url: route.mp + this.buildQuery(params) });
  }
  handleDeepLink(url) {                                          // 深链统一解析
    const { path, params } = this.parseDeepLink(url);             // scheme → 路由
    this.push(path, params);
  }
}
```
