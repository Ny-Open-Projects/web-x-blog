## XP-327：跨端视频播放的统一样式与控制条

**答**：
- 统一：播放器 UI 组件（控制条/手势/清晰度菜单）各端实现，逻辑层复用（状态机共享）。
- 性能：控制条动画走合成层；全屏切换用原生（避免布局重算）。
- 适配：iOS/Android 系统播放器差异（自动全屏行为）通过配置对齐。

```javascript
// 播放器状态机复用
const playerFSM = createMachine({
  idle: { play: 'buffering' },
  buffering: { ready: 'playing', error: 'error' },
  playing: { pause: 'paused', ended: 'ended' },
  paused: { play: 'buffering' },
});
// 各端 UI 订阅状态渲染控制条，逻辑零重复
```
