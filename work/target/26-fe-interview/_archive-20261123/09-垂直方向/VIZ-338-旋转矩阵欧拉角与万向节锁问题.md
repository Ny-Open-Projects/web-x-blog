## VIZ-338：旋转矩阵、欧拉角与万向节锁问题

**答**：
- 欧拉角（yaw/pitch/roll）直观但三个旋转的复合顺序敏感（ZYX vs XYZ 结果不同）。
- 万向节锁：pitch 到 ±90° 时 yaw 与 roll 轴共线，丢失一个自由度——相机俯仰到顶时左右转变成滚转。
- 解法：用四元数或旋转矩阵插值；欧拉角只做输入 UI，内部转换成四元数。

```javascript
// 欧拉角 -> 旋转矩阵（ZYX 序）
function eulerToMat(rx, ry, rz) {
  const cx = Math.cos(rx), sx = Math.sin(rx);
  const cy = Math.cos(ry), sy = Math.sin(ry);
  const cz = Math.cos(rz), sz = Math.sin(rz);
  // R = Rz * Ry * Rx
  return [
    cz*cy, cz*sy*sx - sz*cx, cz*sy*cx + sz*sx, 0,
    sz*cy, sz*sy*sx + cz*cx, sz*sy*cx - cz*sx, 0,
    -sy,   cy*sx,            cy*cx,            0,
    0, 0, 0, 1];
}
// 万向节锁复现：ry = PI/2 时第一列全 0 或 ±1，yaw/roll 等效
```
