## VIZ-365：运动模糊与快门角的数学

**答**：
- 运动模糊 = 在快门开启时间内积分多次采样（时间维度超采样）；快门角 180° 对应曝光 = 1/(2×帧率)。
- 实现：渲染 N 个时间子样本（N=4~8）或后处理方向模糊（motion vector 驱动）。
- 游戏/可视化慎用：数据大屏要"看得清"，模糊降低可读性——常只用于过场动画。

```javascript
// 时间子样本运动模糊
function motionBlurSample(renderAt, shutterDeg = 180, fps = 60, N = 4) {
  const dt = (shutterDeg / 360) / fps;      // 曝光时长
  const out = [];
  for (let i = 0; i < N; i++) {
    const t = -dt/2 + dt * i / (N - 1);
    out.push(renderAt(t));                  // 渲染 t 时刻场景
  }
  return out;                               // 混合即得模糊帧
}
// 后处理替代：用 motion vector 做方向模糊，成本低一个量级
```
