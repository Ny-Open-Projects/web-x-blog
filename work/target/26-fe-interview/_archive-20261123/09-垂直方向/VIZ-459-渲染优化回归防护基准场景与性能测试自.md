## VIZ-459：渲染优化回归防护：基准场景与性能测试自动化

**答**：
- 基准场景：固定场景（固定相机/固定数据）每次发版跑帧时间/内存/draw 数，与基线对比。
- 阈值：帧时间劣化 > 8% 阻断；环境差异用同机 CI runner（无头 GPU 或固定云机）。
- 报告：基准报告附在 MR，趋势图长期跟踪。

```javascript
// 性能回归测试
async function perfRegression(bench = runBenchScene) {
  const cur = await bench({ frames: 300 });
  const base = await loadBaseline();
  const items = ['frameMs', 'drawCalls', 'memMB'].map(k => ({
    metric: k, base: base[k], cur: cur[k],
    delta: +((cur[k] / base[k] - 1) * 100).toFixed(1) + '%' }));
  return { pass: items.every(i => parseFloat(i.delta) < 8), items };
}
```
