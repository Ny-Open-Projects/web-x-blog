## VIZ-256：可视化国际化：多语言图表的布局适配

**答**：
- 图表 i18n 三层：文案翻译（轴标签/图例/tooltip 模板）、数字格式（Intl.NumberFormat 千分位/货币）、布局适配（德语长词换行、RTL 翻转）。
- RTL：坐标轴方向翻转（x 轴从右到左）、tooltip 位置镜像。
- 格式化统一走 Intl（HW-312 联动）。

```javascript
function localizedChart(data, locale) {
  const fmt = new Intl.NumberFormat(locale, { notation: 'compact' });   // 1.2万/1.2K
  const dateFmt = new Intl.DateTimeFormat(locale, { dateStyle: 'short' });
  const rtl = ['ar', 'he'].includes(locale.slice(0, 2));
  return {
    formatValue: v => fmt.format(v),
    formatX: v => dateFmt.format(v),
    direction: rtl ? 'rtl' : 'ltr',
    axis: rtl ? { xReverse: true } : {},                   // RTL 轴翻转
    legendWidth: measureMaxLabel(data.legend, locale),      // 德语长词预留
  };
}
```
