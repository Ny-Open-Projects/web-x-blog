## XP-315：跨端滚动位置恢复（返回列表页）

**答**：
- 需求：列表 -> 详情 -> 返回，滚动位置与筛选条件恢复。
- 实现：离开时保存 scrollTop+状态（路由 state/内存 store），返回时恢复 + 数据不重拉（缓存）。
- 跨端：小程序页面栈天然保留（onShow 恢复）、RN 返回导航参数传递。

```javascript
// 滚动恢复
function scrollMemory() {
  const store = new Map();
  return {
    save(key, { scrollTop, filters }) {
      store.set(key, { scrollTop, filters, at: Date.now() });
    },
    restore(key, { maxAgeMs = 5 * 60_000 } = {}) {
      const s = store.get(key);
      if (!s || Date.now() - s.at > maxAgeMs) return null;
      return s;
    },
  };
}
```
