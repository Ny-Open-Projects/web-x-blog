## XP-240：跨端容器版本发布：CI/CD 流水线（笔试）

**答**：
- 题目：容器版本发布流水线——构建（bundle+签名）→ 测试（单测+E2E+真机）→ 灰度发布（flag）→ 全量 → 回滚。
- 思路：CI 阶段：lint → 单测 → 构建+签名 → E2E 真机 → 性能门禁 → 灰度 5% → 哨兵 → 扩量；回滚：flag 关闭（分钟级）。
- 评分点：流水线阶段；门禁；回滚。

```javascript
const releasePipeline = {
  stages: [
    'lint + 单测（jest）',
    'build bundle + ECDSA 签名（XP-171）',
    'E2E 真机跑（HW-898 真机池）',
    '性能门禁（XP-170 基准对比）',
    '灰度 5%（flag 按用户分桶，XP-160）',
    '哨兵监控（崩溃率/白屏率/首帧，24h 观察）',
    '逐步扩量 5% → 20% → 50% → 100%',
  ],
  rollback: 'flag 关闭 → 回退旧版本（分钟级生效，运行中实例下次启动回退）',
  trigger: '哨兵劣化（崩溃率 ×1.5 / 白屏 ×1.3）→ 自动暂停灰度 + 告警',
};
```
