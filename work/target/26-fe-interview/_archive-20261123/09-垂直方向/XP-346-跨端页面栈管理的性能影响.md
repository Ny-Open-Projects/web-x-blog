## XP-346：跨端页面栈管理的性能影响

**答**：
- 问题：页面栈过深（> 10 层）内存暴涨、返回慢（栈重建）。
- 策略：栈深度限制（替换式导航）、重页面销毁策略、路由快照（状态序列化）。
- 度量：栈深度分布 + 高深度会话的内存/崩溃相关性。

```javascript
// 页面栈治理
function stackPolicy(depth, memRatio) {
  if (depth > 10 || memRatio > 0.85)
    return { action: 'replace-oldest',
      note: '最深页面替换而非压栈，状态序列化保留' };
  return { action: 'push' };
}
```
