## XP-372：跨端视频首帧优化的移动端专项

**答**：
- 专项：预加载首帧（详情页进入前预拉）、硬解探测（353）、封面图占位（视频未就绪先显示封面）。
- 参数：起播缓冲最小化（0.5s）、HLS 部分 segment（LL-HLS）。
- 度量：点击到画面 P75 分端对比。

```javascript
// 视频秒开
async function fastVideoStart(video, url, poster) {
  video.poster = poster;                             // 封面先显示
  video.preload = 'auto';
  const p = video.play();                            // muted 自动播
  video.muted = true;
  await p.catch(() => {});
  video.muted = false;                               // 用户手势后开声
  report({ type: 'video-start', ms: performance.now() - t0 });
}
```
