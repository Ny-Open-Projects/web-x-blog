## XP-352：跨端网络切换与弱网的重连体验

**答**：
- 场景：WiFi->蜂窝切换（连接中断）、弱网降速（请求超时）。
- 处理：监听切换事件 -> 暂停非核心请求 -> 重连恢复 -> 增量同步。
- 体验：切换期间 UI 明确状态（重连中），核心操作排队不丢失。

```javascript
// 切换处理
function netSwitchHandler(ws) {
  const onSwitch = () => {
    pauseNonCritical();
    ws.reconnect({ priority: 'core-only' });          // 只恢复核心
    report({ type: 'net-switch', type: navigator.connection?.effectiveType });
  };
  window.addEventListener('online', onSwitch);
  navigator.connection?.addEventListener('change', onSwitch);
}
```
