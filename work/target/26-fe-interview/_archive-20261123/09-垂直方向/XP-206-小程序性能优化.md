## XP-206：小程序性能优化：启动到首屏的全链路

**答**：
- 题目：小程序启动优化全链路——代码包下载/注入/逻辑执行/渲染首屏，每段优化手段与指标。
- 思路：① 代码包：分包+按需注入+预下载；② 注入：lazyCodeLoading；③ 逻辑：首屏数据预拉（getLaunchOptionsSync 前兆）；④ 渲染：骨架屏+初始渲染精简。
- 评分点：链路分段；每段手段；指标量化。

```javascript
const mpStartupOptimization = {
  stages: [
    { stage: '代码包下载', budget: '500ms',
      opts: ['分包（主包 ≤ 2M）', '预下载（WiFi 预拉分包）', 'CDN 加速'] },
    { stage: '代码注入', budget: '300ms',
      opts: ['lazyCodeLoading: requiredComponents', '减少全局代码'] },
    { stage: '逻辑执行', budget: '200ms',
      opts: ['app.onLaunch 精简（异步化非关键逻辑）', '首屏数据预拉'] },
    { stage: '首屏渲染', budget: '400ms',
      opts: ['骨架屏', '初始渲染精简（首屏只渲染可视区）', '避免复杂 WXML 嵌套'] },
  ],
  metrics: { coldStartP75: '< 2s（全链路）', firstScreenP75: '< 1.5s' },
  measurement: 'wx.getPerformance() → 启动分段耗时上报（ALG-470 关联）',
};
```
