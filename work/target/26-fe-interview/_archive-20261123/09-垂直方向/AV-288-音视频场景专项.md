## AV-288：音视频场景专项：多语言会议实时翻译架构

**答**：
- 多语言会议：说话人 A 中文 → ASR → 翻译 → TTS/字幕给 B（英文）——链路延迟 2~3s（ASR+MT+TTS）；字幕实时（1s 内）优先于语音。
- 实现：音频分段上传（VAD 切句）→ ASR 流式 → MT 流式 → 字幕即时渲染（TTS 可选延迟播）。
- 体验分层：字幕（1s）→ 语音播报（3s）——字幕先行。

```javascript
class MeetingTranslation {
  constructor(audioTrack, { source = 'zh', target = 'en' } = {}) {
    this.vad = new VAD(audioTrack);                          // 语音活动检测切句
    this.vad.onSegment = (segment) => this.processSegment(segment);
  }
  async processSegment(segment) {                            // 一句话处理
    const asr = await asrService.transcribe(segment, this.source);   // ASR
    this.caption(asr.text, 'source');                        // 原文字幕（即时）
    const mt = await mtService.translate(asr.text, this.target);   // 翻译
    this.caption(mt.text, 'target');                         // 译文字幕
    if (this.ttsEnabled) this.ttsPlay(mt.text, this.target);   // TTS 语音（可选延迟）
  }
}
```
