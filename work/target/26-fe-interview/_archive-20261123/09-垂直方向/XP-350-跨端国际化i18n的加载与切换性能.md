## XP-350：跨端国际化(i18n)的加载与切换性能

**答**：
- 按需加载：语言包按命名空间拆分（首屏只拉当前语言核心包），切换懒加载其余。
- 切换：不重载页面（React context/全局状态热替换），缓存已加载语言。
- 度量：语言包体积/切换耗时（< 100ms 无感）。

```javascript
// i18n 懒加载
const loaded = new Map();
async function loadLocale(ns, lang) {
  const key = `${lang}:${ns}`;
  if (loaded.has(key)) return loaded.get(key);
  const dict = await import(`./locales/${lang}/${ns}.json`);
  loaded.set(key, dict.default);
  return dict.default;
}
// 首屏：loadLocale('common', 'zh')，切语言时增量加载其余 ns
```
