## VIZ-385：着色器渲染管线：顶点/片元着色器各负责什么

**答**：
- 顶点着色器：每顶点一次——变换（MVP）、传 varying（颜色/UV/法线）给片元。
- 片元着色器：每片元一次——插值属性 + 纹理采样 + 光照 + 输出颜色；是性能热点（像素量 >> 顶点量）。
- 中间阶段：几何着色器（WebGL 原生不支持）、计算着色器（WebGPU）用于通用并行。

```javascript
// WebGL2 最小着色器对
// vertex
`#version 300 es
in vec3 aPos; in vec2 aUV;
uniform mat4 uMVP;
out vec2 vUV;
void main() { vUV = aUV; gl_Position = uMVP * vec4(aPos, 1.0); }`
// fragment
`#version 300 es
precision highp float;
in vec2 vUV; uniform sampler2D uTex;
out vec4 outColor;
void main() { outColor = texture(uTex, vUV); }`
```
