## XP-204：小程序代码质量控制：按需注入与懒加载

**答**：
- lazyCodeLoading: requiredComponents——启动只注入当前页面需要的组件代码（默认注入全部组件代码，启动慢）。
- 按需注入收益：启动时 JS 注入量从全量 → 当前页所需，启动时间降 30%+。
- 配合：分包 + 按需注入 + 预下载 = 小程序启动优化三板斧。

```javascript
// app.json
const appJson = {
  lazyCodeLoading: 'requiredComponents',                     // 按需注入
  preloadRule: { ... },                                       // 分包预下载
};
// 原理：默认启动注入全部组件/页面 JS（不管是否用到）
// requiredComponents：只注入当前页声明的组件——启动 JS 注入量从 5M → 800K
// 收益：启动时间降 30%+（注入是大头）
// 注意：动态引用组件（如 this.selectComponent）需确保组件已注入
```
