## VIZ-259：可视化数据安全：敏感数据的脱敏渲染

**答**：
- 敏感数据图表（薪酬/医疗）：渲染层脱敏——聚合展示（不显示个体）、数值模糊化（区间而非精确值）、权限联动（无权者看聚合）。
- 实现：渲染管线注入脱敏钩子（数据进图前过 transform）；导出时强制脱敏（防导出绕过）。
- 与 HW-878 合规过滤协同：图表导出走同一脱敏过滤器。

```javascript
function sanitizedRender(data, viewerRole) {
  if (viewerRole === 'viewer') {                           // 无权者：聚合
    return {
      type: 'aggregate',                                   // 柱状聚合代替明细散点
      data: groupAggregate(data, { by: 'dept', agg: 'avg', minGroupSize: 5 }),   // 小组隐藏（防反推）
      rangeOnly: true,                                     // 显示区间
    };
  }
  return { type: 'detail', data };
}
// 防反推：聚合组最少 5 人（k-匿名）；导出走 sanitizeExport（强制同规则）
```
