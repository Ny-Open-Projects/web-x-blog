## XP-285：首屏数据预取（进入页面前拉数据）

**答**：
- 策略：列表页点击详情前预取详情接口（点击即拉，进页直接渲染）；路由预注册预取。
- 实现：预取结果带过期（3s 内有效），命中直接注水，未命中走正常请求。
- 收益：详情首屏数据等待 -300~800ms。

```javascript
// 点击预取
const prefetchCache = new Map();
function prefetchDetail(id) {
  if (prefetchCache.has(id)) return prefetchCache.get(id);
  const p = api(`/detail/${id}`).then(d => d);
  prefetchCache.set(id, p);
  setTimeout(() => prefetchCache.delete(id), 3000);  // 3s 过期
  return p;
}
listItem.onclick = () => { prefetchDetail(id); router.push(`/detail/${id}`); };
// 详情页：
const data = await prefetchDetail(id).catch(() => api(`/detail/${id}`));
```
