## XP-311：跨端埋点的统一事件模型

**答**：
- 模型：事件名/属性 schema 全端一致（跨端数据可比）；平台特有属性（端类型/容器版本）扩展字段。
- 发送：统一 track(event, props) 入口，各端 adapter 处理上报通道。
- 校验：CI 校验事件 schema（未注册事件告警）。

```javascript
// 统一埋点
const SCHEMA = {
  'page_view': ['page', 'ref'],
  'click': ['target', 'page'],
};
function track(event, props, platform) {
  const required = SCHEMA[event];
  if (!required) return report({ type: 'event-unregistered', event });
  const missing = required.filter(k => props[k] == null);
  if (missing.length) return report({ type: 'props-missing', event, missing });
  adapter(platform).send({ event, ...props,
    _platform: platform, _tier: deviceTierCache, _ts: Date.now() });
}
```
