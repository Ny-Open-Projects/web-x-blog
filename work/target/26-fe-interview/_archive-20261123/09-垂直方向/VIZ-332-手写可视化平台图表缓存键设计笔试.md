## VIZ-332：手写可视化平台图表缓存键设计（笔试）

**答**：
- 题目：多层缓存的键设计——图表配置 hash + 数据集版本 + 用户权限范围 + 时间窗口对齐（分钟级对齐防缓存抖动）。
- 思路：cacheKey = hash(configHash + datasetVersion + rowScope + timeBucket)；时间窗口按分钟对齐（防秒级变化导致缓存永不命中）。
- 评分点：键组成要素；时间桶对齐；版本失效。

```javascript
function chartCacheKey(config, datasetVersion, rowScope, now = Date.now()) {
  const configHash = hashStr(JSON.stringify(config));       // 配置
  const bucket = Math.floor(now / 60000) * 60000;           // 分钟对齐（防抖动）
  return `viz:${configHash}:${datasetVersion}:${hashStr(JSON.stringify(rowScope))}:${bucket}`;
}
// 键要素：配置（图变了换键）、数据版本（数据变了失效）、权限（不同人不同缓存）、时间桶（窗口对齐）
// 实测：不对齐时间桶 → 每次请求键都不同 → 缓存命中率 0%；分钟对齐 → 命中率 > 80%
```
