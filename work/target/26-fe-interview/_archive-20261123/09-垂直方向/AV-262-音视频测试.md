## AV-262：音视频测试：自动化通话质量回归

**答**：
- 通话质量回归测试：两端 headless 通话（fake 设备/预录视频源）→ 采集两端 getStats → 断言（RTT < 阈值/无冻结/音频连续）。
- fake 设备：Chrome --use-fake-device-for-media-stream（合成源）+ --use-fake-ui-for-media-stream（免权限弹窗）。
- CI 集成：每次发版跑核心链路（P2P/SFU）回归。

```javascript
async function e2eCallTest() {                             // 两端自动通话
  const args = ['--use-fake-device-for-media-stream',      // 合成视频源（绿色转盘）
    '--use-fake-ui-for-media-stream'];                      // 自动允许权限
  const a = await launchChrome(args), b = await launchChrome(args);
  await a.goto('/call?room=test'); await b.goto('/call?room=test');
  await sleep(5000);                                        // 通话 5 秒
  const statsA = await a.evaluate(() => collectStats());
  const statsB = await b.evaluate(() => collectStats());
  assert(statsA.video.framesPerSecond > 20, '帧率过低');
  assert(statsA.audio.jitterBufferDelay / statsA.audio.jitterBufferEmittedCount < 0.1, '音频缓冲过大');
  assert(!statsA.video.freezeCount, '出现冻结');
}
```
