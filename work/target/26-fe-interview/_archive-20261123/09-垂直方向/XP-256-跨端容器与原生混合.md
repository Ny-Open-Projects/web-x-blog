## XP-256：跨端容器与原生混合：多容器页面间数据共享（笔试）

**答**：
- 题目：多容器页面数据共享——全局状态（用户信息/购物车）跨页面同步：共享存储 + 变更通知（观察者模式）。
- 思路：共享数据层（Native 侧统一存储）+ 变更通知（pub/sub）；页面订阅关心的 key；页面销毁取消订阅（防泄漏）。
- 评分点：共享存储；订阅通知；防泄漏。

```javascript
class SharedDataManager {
  constructor() { this.data = new Map(); this.subscribers = new Map(); }   // key → Set<callback>
  get(key) { return this.data.get(key); }
  set(key, value) {                                              // 设置 + 通知
    this.data.set(key, value);
    this.subscribers.get(key)?.forEach(cb => cb(value));          // 通知订阅者
    persist(key, value);                                           // 持久化（跨启动）
  }
  subscribe(key, cb) {                                            // 订阅
    (this.subscribers.get(key) ?? this.subscribers.set(key, new Set()).get(key)).add(cb);
    return () => this.subscribers.get(key)?.delete(cb);            // 退订函数（防泄漏）
  }
}
// 页面：const unsub = sharedData.subscribe('cart', (cart) => this.updateBadge(cart));
// 页面销毁：unsub()——必须退订（否则内存泄漏+幽灵回调）
```
