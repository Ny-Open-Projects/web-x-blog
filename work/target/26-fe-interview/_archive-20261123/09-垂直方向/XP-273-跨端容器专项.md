## XP-273：跨端容器专项：容器启动路径优化——懒加载依赖图分析（笔试）

**答**：
- 题目：容器启动慢——分析依赖图找出启动关键路径（首屏页面 → 依赖模块 → 第三方库），非关键路径延迟加载。
- 思路：构建期生成依赖图（模块依赖 DAG）→ 标记启动必需（首屏页面依赖链）→ 非关键路径拆分（动态 import）；量化：启动加载量从 5M → 1.2M。
- 评分点：依赖图分析；关键路径标记；拆分量化。

```javascript
function analyzeStartupPath(bundle) {                       // 依赖图分析
  const graph = buildDependencyGraph(bundle.modules);            // DAG
  const entryPage = bundle.pages['/home'];                       // 首屏页面
  const critical = reachableFrom(graph, entryPage);               // 启动关键路径
  const lazy = bundle.modules.filter(m =>
    !critical.has(m.id) && !isVendorCritical(m));                 // 非关键路径
  return {
    criticalSize: sumSize(critical),                              // 关键路径体积
    lazySize: sumSize(lazy),                                       // 可延迟体积
    lazyModules: lazy.map(m => m.id),
    suggestion: `非关键模块 ${lazy.length} 个（${formatSize(lazySize)}）→ 动态 import 拆分`,
  };
}
// 实测：启动加载 5M → 关键路径 1.2M + 懒加载 3.8M → 启动 1.2s → 400ms
```
