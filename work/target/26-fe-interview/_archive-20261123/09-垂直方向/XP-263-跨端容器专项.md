## XP-263：跨端容器专项：容器页面导航转场动画实现（笔试）

**答**：
- 题目：容器页面转场动画——push 从右滑入/pop 向右滑出（Native 驱动），JS 侧只声明动画类型；自定义转场（共享元素）。
- 思路：标准转场（Native 内置 push/pop 动画）；自定义转场（transition config 下发：类型/时长/曲线）；共享元素（XP-172 复用）。
- 评分点：标准转场；自定义配置；共享元素。

```javascript
class TransitionConfig {
  push(route, { transition = { type: 'slide', duration: 300, curve: 'easeOut' } } = {}) {
    bridge.commit([
      { op: 'set-transition', route, transition },               // 动画配置下发
      { op: 'push', route },                                      // Native 执行动画
    ]);
  }
  customSharedElement(from, to, sharedElements) {                 // 自定义：共享元素
    bridge.commit([
      { op: 'set-transition', route: to,
        transition: { type: 'sharedElement', elements: sharedElements,
          duration: 400, curve: 'spring' } },                     // 弹簧曲线
      { op: 'push', route: to },
    ]);
  }
}
// Native 驱动动画（不受 JS 阻塞影响）——JS 只声明，Native 执行
```
