## AV-289：音视频场景专项：视频会议带宽预告与入会建议

**答**：
- 题目：入会前带宽评估与建议——测速（ICE 探测/下载测速）→ 建议入会模式（视频会议/纯音频/建议换网络）。
- 思路：ICE 探测候选对 RTT（快且准）；下载测速（fetch 1MB 计时）；综合评估 → 建议模式。
- 评分点：测速方法；建议逻辑；结果缓存。

```javascript
async function assessJoinReadiness() {
  const pc = new RTCPeerConnection({ iceServers });           // ICE 探测（不进会）
  pc.createDataChannel('probe');
  await pc.setLocalDescription(await pc.createOffer());
  const rtt = await probeICERTT(pc);                         // 候选对 RTT
  const bandwidth = await measureDownload();                  // 下载测速（1MB 计时）
  const advice = bandwidth > 2e6 && rtt < 0.15
    ? { mode: 'video', quality: '高清视频会议' }
    : bandwidth > 5e5 ? { mode: 'audio+lowVideo', quality: '建议标清或纯音频' }
    : { mode: 'audio', quality: '建议纯音频通话', warning: '当前网络不适合视频' };
  cacheResult(advice, 60000);                                  // 缓存 1 分钟
  return advice;
}
```
