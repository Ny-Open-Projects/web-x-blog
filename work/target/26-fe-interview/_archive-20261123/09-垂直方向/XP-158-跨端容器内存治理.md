## XP-158：跨端容器内存治理：页面栈与视图回收

**答**：
- 页面栈内存：每页面一个 View 树 + JS 上下文——栈深超限（Android 16/38 线性布局）→ 视图回收（非活跃页面释放 View 保留状态）。
- 回收策略：LRU 页面栈（保留最近 N 页），被回收页保留「状态快照」（数据+滚动位置）——返回时重建。
- 与 HW-747（Web 页面栈）同构：View 层释放 + JS 状态保留。

```javascript
class PageStackManager {
  constructor({ maxAlive = 5 } = {}) { this.max = max; this.stack = []; }
  push(page) {
    this.stack.push(page);
    while (this.stack.length > this.max) {                   // LRU 回收
      const oldest = this.stack.shift();
      if (oldest.dirty) oldest.saveState();                  // 脏页先存状态
      oldest.releaseView();                                   // 释放 View（JS 状态保留）
      oldest.released = true;
    }
  }
  restore(page) {                                            // 返回时重建
    if (page.released) {
      page.rebuildView();                                     // View 重建
      page.restoreState();                                    // 数据/滚动恢复
      page.released = false;
    }
  }
}
```
