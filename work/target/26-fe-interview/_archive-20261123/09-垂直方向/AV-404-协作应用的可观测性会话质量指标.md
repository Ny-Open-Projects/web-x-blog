## AV-404：协作应用的可观测性：会话质量指标

**答**：
- 指标：同步延迟（本地操作到远端可见 P75）、掉线率、冲突率、消息吞吐。
- 埋点：操作打点（send/apply/ack 三时刻），端到端延迟 = ack - send。
- 大盘：按房间规模/文档大小/网络分桶，定位性能 cliff。

```javascript
// 同步延迟埋点
class SyncMetrics {
  constructor() { this.pending = new Map(); }
  sent(opId) { this.pending.set(opId, performance.now()); }
  applied(opId) {
    const t0 = this.pending.get(opId);
    if (!t0) return;
    this.pending.delete(opId);
    report({ type: 'sync-latency', ms: Math.round(performance.now() - t0) });
  }
  report() {
    const lat = this.samples.sort((a, b) => a - b);
    return { p50: lat[lat.length >> 1], p75: lat[Math.floor(lat.length * 0.75)] };
  }
}
```
