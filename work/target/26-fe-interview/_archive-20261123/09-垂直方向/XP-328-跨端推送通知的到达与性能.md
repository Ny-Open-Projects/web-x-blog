## XP-328：跨端推送通知的到达与性能

**答**：
- 链路：厂商通道（APNs/华为/小米）+ 长连接兜底；到达率分通道统计。
- 前端：通知点击深链解析（297）、前台通知处理（应用内横幅 vs 系统通知）。
- 度量：到达率 P75、点击到页面就绪时长。

```javascript
// 推送深链
function onNotificationTap(payload) {
  const route = resolveDeepLink(payload.target);     // 297
  navigate(route.page, route.params);
  report({ type: 'push-open', id: payload.msgId,
    toReadyMs: performance.now() - t0 });
}
// 到达率 = 到达数/发送数，分通道（厂商）统计低到达通道换兜底长连接
```
