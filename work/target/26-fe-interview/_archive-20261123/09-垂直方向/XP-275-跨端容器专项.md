## XP-275：跨端容器专项：容器崩溃后的用户数据保护（笔试）

**答**：
- 题目：容器崩溃（JS 引擎 OOM）时用户数据保护——定期快照（HW-391 复用）+ 崩溃检测 → 恢复后数据还原提示。
- 思路：关键数据定期快照（表单/草稿/滚动位置，10s 或关键操作后）→ 持久化 → 崩溃恢复启动 → 检测快照 → 还原提示。
- 评分点：快照策略；崩溃检测；还原 UX。

```javascript
class CrashDataProtection {
  startProtection(page) {                                        // 启动保护
    this.snapshotTimer = setInterval(() => this.snapshot(page), 10000);   // 10s 快照
    page.onCriticalAction = () => this.snapshot(page);             // 关键操作后立即快照
  }
  snapshot(page) {                                                 // 快照
    persist(`page-${page.id}`, { formData: page.formData,
      scrollPos: page.scrollPos, ts: Date.now() });
  }
  async onRecover(pageId) {                                        // 崩溃恢复
    const snap = await readSnapshot(`page-${pageId}`);
    if (snap && Date.now() - snap.ts < 3600e3) {                    // 1h 内有效
      page.formData = snap.formData;                                 // 数据还原
      showModal('检测到异常退出，已恢复您的编辑内容');                   // 提示
    }
  }
}
```
