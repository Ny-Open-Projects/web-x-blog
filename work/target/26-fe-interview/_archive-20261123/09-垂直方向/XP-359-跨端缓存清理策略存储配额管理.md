## XP-359：跨端缓存清理策略（存储配额管理）

**答**：
- 配额：各端存储上限不同（localStorage 5MB/小程序 10MB/IndexedDB 大）——按端策略。
- 清理：LRU + 重要级（用户数据 > 配置 > 缓存），水位 80% 触发清理。
- 上报：清理事件与清空量，异常清理（用户数据被清）必须告警。

```javascript
// 配额清理
async function storageGC({ watermark = 0.8 } = {}) {
  const { used, quota } = await navigator.storage.estimate();
  if (used / quota < watermark) return { cleaned: 0 };
  const order = ['cache', 'config', 'userdata'];     // 低价值先清
  let cleaned = 0;
  for (const kind of order) {
    const freed = await clearKind(kind);
    cleaned += freed;
    if (used - cleaned < quota * watermark * 0.9) break;
  }
  report({ type: 'storage-gc', cleaned });
  return { cleaned };
}
```
