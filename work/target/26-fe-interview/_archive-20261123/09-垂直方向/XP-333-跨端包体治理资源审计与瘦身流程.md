## XP-333：跨端包体治理：资源审计与瘦身流程

**答**：
- 审计：bundle 分析（体积构成：JS/图片/字体/三方库）、Top 贡献者列表。
- 瘦身：图片压缩/WebP、字体子集化、依赖替换（moment->dayjs）、Tree-shaking 校验。
- 流程：体积预算门禁（CI）+ 季度专项治理，新增超预算需评审。

```javascript
// 包体审计
function bundleAudit(files, { budgetKB = 2000 } = {}) {
  const total = files.reduce((s, f) => s + f.kb, 0);
  const top = [...files].sort((a, b) => b.kb - a.kb).slice(0, 5);
  return { totalKB: total, top,
    over: total > budgetKB,
    suggestions: top.filter(f => /moment|lodash|images/.test(f.name))
      .map(f => `替换或压缩 ${f.name}`) };
}
```
