## AV-380：多码率转码梯度的设计

**答**：
- 梯度：1080p 5M / 720p 2.5M / 480p 1M / 360p 600k——覆盖带宽分布（弱网到 Wi-Fi）。
- ABR 切换边界：相邻档位码率比 < 2（否则切换感知强）。
- 内容感知转码：静态内容低档即可高 VMAF——按复杂度省 20% 转码成本。

```javascript
// 转码梯度
function transcodingLadder(sourceH, complexity = 1) {
  const ladder = [
    { h: 1080, kbps: 5000 }, { h: 720, kbps: 2500 },
    { h: 480, kbps: 1000 }, { h: 360, kbps: 600 },
  ].filter(l => l.h <= sourceH)
   .map(l => ({ ...l, kbps: Math.round(l.kbps * complexity) }));
  return ladder;
}
// 复杂度：帧间差分判定 0.5(静态)~1.5(高运动)
```
