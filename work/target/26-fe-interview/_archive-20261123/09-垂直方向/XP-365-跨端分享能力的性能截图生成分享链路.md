## XP-365：跨端分享能力的性能（截图生成/分享链路）

**答**：
- 截图：Canvas 合成（html2canvas 慢 -> dom-to-image/原生截图桥）。
- 分享链路：预生成分享图（异步缓存），点击分享时直接用（避免点击后等待）。
- 降级：截图失败 -> 纯文本分享兜底。

```javascript
// 分享图预生成
async function preGenerateShareImage(pageId) {
  const cached = await cache.get(`share-${pageId}`);
  if (cached) return cached;
  const img = await renderToImage(pageEl);           // Canvas 合成
  const blob = await img.convertToBlob();
  await cache.set(`share-${pageId}`, blob, { ttl: 600_000 });
  return blob;
}
// 触发时机：进入页面 idle 时预生成
```
