## XP-262：跨端容器专项：容器与 Web 的渲染差异对照（笔试）

**答**：
- 题目：容器渲染 vs Web 渲染差异清单——布局引擎（Yoga vs 浏览器）、事件模型、样式能力、滚动机制——写对照表。
- 思路：布局（Yoga flex-only vs 浏览器完整 CSS）；事件（触摸为主 vs 鼠标+触摸）；样式（子集）；滚动（Native 滚动 vs DOM scroll）。
- 评分点：四维对照表；Web 开发者适配要点；坑点清单。

```javascript
const containerVsWeb = {
  layout: { container: 'Yoga（flex-only，无 grid/float）',
    web: '完整 CSS（grid/float/position）',
    migration: 'grid 布局改 flex 嵌套；fixed 改 absolute + 容器级' },
  events: { container: '触摸事件为主（合成 mouse 兼容）',
    web: '鼠标+触摸+键盘', migration: 'hover 交互改为 active/longpress' },
  styles: { container: 'CSS 子集（无伪类/后代选择器限制）',
    web: '完整 CSS', migration: '伪类改状态 prop（hovered={true}）' },
  scrolling: { container: 'Native 滚动（ScrollView 组件）',
    web: 'DOM overflow scroll', migration: '滚动容器必须用 ScrollView 组件（非 CSS overflow）' },
  pitfalls: ['position: fixed 不支持（用 absolute + 容器根）', 'z-index 依赖插入顺序',
    '百分比尺寸基于父容器', '动画用 Native 动画 API（非 CSS animation）'],
};
```
