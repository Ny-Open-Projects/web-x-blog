## AV-339：分辨率/帧率/码率的推荐组合（工程经验表）

**答**：
- 720p30：1.5~2.5Mbps（H.264）；1080p30：3~5Mbps；1080p60：5~8Mbps。
- H.265/AV1 打 7 折；屏幕内容（低运动）打 5 折；高运动（体育）打 1.3 倍。
- 经验来源：YouTube/Netflix 推荐码率表 + 自测 VMAF 分数校准。

```javascript
// 码率推荐表
function bitrateFor({ h, fps, codec = 'h264', content = 'normal' } = {}) {
  const base = { 720: 2, 1080: 4, 1440: 8, 2160: 16 }[h] ?? 4;
  const fpsK = fps >= 50 ? 1.5 : 1;
  const codecK = { h264: 1, h265: 0.6, av1: 0.55, vp9: 0.7 }[codec];
  const contentK = { static: 0.5, normal: 1, sports: 1.3 }[content];
  return +(base * fpsK * codecK * contentK).toFixed(1) + 'Mbps';
}
console.log(bitrateFor({ h: 1080, fps: 30, codec: 'av1', content: 'static' }));
```
