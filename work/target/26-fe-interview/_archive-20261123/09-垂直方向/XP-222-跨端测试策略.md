## XP-222：跨端测试策略：单元/组件/E2E 多端覆盖

**答**：
- 跨端测试金字塔：单元（核心逻辑，平台无关——jest）→ 组件（各端渲染快照）→ E2E（各端真机/模拟器）。
- 核心逻辑平台无关（XP-166 状态层）→ 单测一次全端收益；组件层各端快照（渲染差异）；E2E 关键路径。
- CI 矩阵：Web（headless Chrome）/RN（模拟器）/小程序（miniprogram-simulate）/Flutter（flutter test）。

```javascript
const crossPlatformTesting = {
  unit: { target: '核心逻辑（纯 TS 状态层）', tool: 'jest',
    coverage: '一次编写全端收益（XP-166 状态层平台无关）' },
  component: { target: '各端组件渲染', tool: {
    web: '@testing-library/react + snapshot', rn: 'react-test-renderer + snapshot',
    mp: 'miniprogram-simulate', flutter: 'flutter test golden' } },
  e2e: { target: '关键路径（登录/下单/支付）', tool: {
    web: 'playwright', rn: 'detox', mp: 'miniprogram-automator', flutter: 'integration_test' } },
  ci: '测试矩阵：PR 触发 unit+component；合并触发 E2E 真机跑（HW-898 复用）',
};
```
