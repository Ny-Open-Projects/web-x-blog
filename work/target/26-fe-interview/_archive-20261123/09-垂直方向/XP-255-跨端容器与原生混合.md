## XP-255：跨端容器与原生混合：视频/相机原生组件覆盖层级（笔试）

**答**：
- 题目：原生组件覆盖层级问题——视频/相机是原生组件（层级最高），JS 渲染的弹幕/按钮被覆盖。解决方案（同层渲染/插入原生层）。
- 思路：方案① 同层渲染（容器支持时：原生组件融入 View 树层级）；方案② 原生层插入（弹幕/按钮也走原生渲染插到视频上）；方案③ 截图合成（视频帧画到 canvas，全部 JS 渲染——性能差但灵活）。
- 评分点：三种方案取舍；同层渲染条件；性能差异。

```javascript
const nativeOverlaySolutions = {
  sameLayer: { desc: '同层渲染——原生组件融入 View 树（支持时最优）',
    condition: '容器/小程序支持 same-layer 渲染（新版微信/自研容器）',
    perf: '最优（统一渲染管线）' },
  nativeInsert: { desc: 'JS 层组件也用原生渲染插到视频上方',
    condition: '容器支持原生层插入（Native View 插入排序）',
    perf: '好（Native 渲染弹幕）', note: '弹幕需 Native 渲染（不能用 JS Canvas）' },
  screenshot: { desc: '视频帧画到 canvas → 全 JS 渲染',
    perf: '差（每帧绘制 + CPU 编码）', fit: '不支持同层的老容器兜底' },
};
// 决策：支持同层 → sameLayer；不支持 → nativeInsert（弹幕原生化）
```
