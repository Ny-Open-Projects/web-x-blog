## AV-369：直播延迟的分段度量与端到端优化

**答**：
- 链路：采集编码（<100ms）→ 推流传输（CDN 1~3s）→ 拉流缓冲（2~5s）→ 解码渲染（<100ms）。
- 度量：SEI 时间戳插入（采集端），播放端解析差值 = 端到端延迟。
- 优化优先级：缓冲策略（起播缓冲 1s vs 5s）> GOP 长度 > 协议（LL-HLS）。

```javascript
// 延迟测量
function measureLatency(player, seiExtractor) {
  player.on('segment-loaded', seg => {
    const seiTs = seiExtractor(seg);                   // 采集时间戳
    const now = Date.now();
    report({ type: 'e2e-latency', ms: now - seiTs });
  });
}
// 延迟构成通常：CDN 排队 40%、起播缓冲 40%、编解码 10%、网络 10%
```
