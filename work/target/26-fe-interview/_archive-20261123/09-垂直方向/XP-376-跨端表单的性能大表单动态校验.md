## XP-376：跨端表单的性能（大表单/动态校验）

**答**：
- 问题：大表单每键全量校验/重渲卡顿。
- 方案：字段级校验（blur 触发）、校验规则按依赖分组、提交时全量兜底校验。
- 跨端：统一表单 schema（字段/规则/联动）各端渲染引擎复用。

```javascript
// 字段级校验
function fieldValidation(schema, values) {
  const errors = {};
  for (const [field, rules] of Object.entries(schema)) {
    for (const rule of rules) {
      const ok = rule.validate(values[field], values);
      if (!ok) { errors[field] = rule.message; break; }   // 首个错误即止
    }
  }
  return errors;
}
// blur 时只校验单字段：validateField(field, value)
```
