## VIZ-226：3D 后处理链：Bloom、SSAO、色调映射

**答**：
- 后处理顺序：场景 HDR 渲染 → SSAO（环境光遮蔽）→ Bloom（提亮泛光）→ 色调映射（HDR→LDR）→ 输出。
- 色调映射：ACES/Reinhard——HDR 值域压缩，图表场景用于高亮数据点的泛光效果。
- 成本：每 pass 全屏 fillrate；可视化场景建议只开 Bloom + MSAA（SSAO 成本高收益低）。

```javascript
function postProcessChain(renderer) {
  return [
    { name: 'ssao', optional: true, cost: 'high', gain: '低（可视化弱光照）' },
    { name: 'bloom', optional: false, cost: 'mid', gain: '高亮数据点泛光——可读性提升' },
    { name: 'tonemap', optional: false, cost: 'low',
      shader: `fn tonemap(hdr: vec3f) -> vec3f {           // ACES 近似
        return clamp((hdr * (2.51 * hdr + 0.03)) / (hdr * (2.43 * hdr + 0.59) + 0.14), vec3f(0), vec3f(1)); }` },
  ].filter(p => p.optional !== true || renderer.quality === 'high');
}
// 可视化建议链：scene(HDR) → bloom → tonemap，3 pass 内
```
