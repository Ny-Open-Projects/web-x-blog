## VIZ-387：着色器编译错误的调试流程

**答**：
- WebGL 编译错误静默（getShaderParameter 返回 false）——必须主动 getShaderInfoLog 打印。
- 常见错误：版本指令缺失（#version 300 es 必须第一行）、precision 缺失（片元必须声明）、int/float 混算。
- 工具链：glslangValidator 本地预校验 CI 集成、Spector.js 运行时查看。

```javascript
// 编译封装（错误必出）
function compile(gl, type, src) {
  const s = gl.createShader(type);
  gl.shaderSource(s, src.trim());   // trim 保证 #version 在第一行
  gl.compileShader(s);
  if (!gl.getShaderParameter(s, gl.COMPILE_STATUS)) {
    const log = gl.getShaderInfoLog(s);
    const line = /\d+:(\d+):/.exec(log)?.[1];
    console.error('shader 编译失败:\n', log,
      '\n出错行:', line && src.split('\n')[line - 1]);
    throw new Error(log);
  }
  return s;
}
```
