## XP-347：跨端输入法适配：键盘弹起的布局处理

**答**：
- 问题：软键盘遮挡输入框/布局跳动（iOS WebView resize 行为差异）。
- 方案：监听键盘高度（原生/visualViewport），滚动到焦点、resize 模式配置（adjustPan/Resize）。
- 统一：输入组件内置键盘适配逻辑（345 沉淀）。

```javascript
// 键盘适配
function keyboardAdapt(inputEl, visualViewport) {
  const handler = () => {
    const kbTop = visualViewport.height + visualViewport.offsetTop;
    const r = inputEl.getBoundingClientRect();
    if (r.bottom > kbTop)
      window.scrollBy(0, r.bottom - kbTop + 8);      // 滚到可见
  };
  visualViewport.addEventListener('resize', handler);
  return () => visualViewport.removeEventListener('resize', handler);
}
```
