## XP-310：跨端灰度发布与回滚（端内热更）

**答**：
- 热更：RN bundle/小程序整包更新走灰度（按设备分桶百分比）。
- 回滚：版本清单下发切换（秒级），旧版本资源保留期 2 版本。
- 安全：bundle 签名校验（1099），失败拒绝加载回退内置版本。

```javascript
// 热更灰度
async function hotUpdate(channel) {
  const manifest = await api(`/hotfix/${channel}/manifest`);
  if (hash(uid) % 100 >= manifest.grayPct) return { updated: false, note: '不在灰度' };
  const ok = await verifySignature(manifest.bundleUrl, manifest.sig);
  if (!ok) return { updated: false, note: '签名校验失败，回退内置版本' };
  await downloadAndApply(manifest);
  report({ type: 'hotfix-applied', version: manifest.version });
}
// 回滚：服务端 manifest.version 回退，客户端下次启动生效；紧急走强更
```
