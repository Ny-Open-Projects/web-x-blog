## XP-258：跨端容器与原生混合：容器页返回时数据回传（笔试）

**答**：
- 题目：页面 A push 页面 B → B 操作完返回 → A 需要拿到 B 的结果（选择器/表单回填）。
- 思路：回调模式（push 带 callback）或结果模式（B setResult → A onResult）；栈式管理（多级返回逐层回传）。
- 评分点：回调/结果两种模式；栈式回传；类型安全。

```javascript
class PageResultPassing {                                   // 结果回传
  pushForResult(route, params) {                             // A：push 等结果
    return new Promise((res) => {
      this.navigator.push(route, { ...params,
        __resultCallback: res });                              // 回调入栈
    });
  }
  setResult(result) {                                          // B：设置结果返回
    const callback = this.routeParams.__resultCallback;
    callback?.(result);                                         // 回传给 A
    this.navigator.pop();                                       // 返回
  }
}
// A：const selected = await pushForResult('/picker', { multi: true });
// B：setResult({ items: [1, 2] }); → A 拿到结果
// 类型安全：TS 泛型 pushForResult<T>(route): Promise<T>
```
