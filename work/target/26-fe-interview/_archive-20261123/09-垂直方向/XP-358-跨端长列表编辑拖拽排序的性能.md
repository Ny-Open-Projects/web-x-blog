## XP-358：跨端长列表编辑（拖拽排序）的性能

**答**：
- 实现：拖拽用 transform 位移（合成层）+ 松手归位动画 + 数据重排一次提交。
- 性能：拖拽中不触发重排（只 transform），排序计算节流；大数据量用原生拖拽模块（桥）。
- 同步：排序结果批量同步（协作场景 394 模式）。

```javascript
// 拖拽排序
function dragSort(list, onReorder) {
  let dragging = null;
  return {
    onDragStart(i) { dragging = { i, y: 0 }; },
    onDragMove(dy) {
      dragging.y = dy;
      // 只 transform 当前项 + 计算目标 index
      const target = Math.round(dy / 56);
    },
    onDragEnd() {
      const { i } = dragging;
      const target = i + Math.round(dragging.y / 56);
      if (target !== i) {
        const [item] = list.splice(i, 1);
        list.splice(target, 0, item);
        onReorder(list);                             // 一次提交
      }
    },
  };
}
```
