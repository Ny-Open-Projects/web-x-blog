## VIZ-230：3D 大场景内存治理：几何合并与实例化的选择

**答**：
- 同几何大量实例（1 万个立方体）→ InstancedMesh（一几何多实例，内存 = 几何 × 1 + 实例属性）；异几何 → BufferGeometryUtils.mergeGeometries（合并成一个 draw）。
- 选择：实例化支持逐实例变换但不能逐实例改几何；合并后整体一个 draw 但改单个需重建。
- 内存量化：1 万 Mesh 各自几何 ≈ 1 万 × 顶点开销；实例化 ≈ 1 × 几何 + 1 万 × 16B 矩阵。

```javascript
// Three.js 两种方案
// 1. InstancedMesh：同几何多实例
const inst = new THREE.InstancedMesh(boxGeo, material, 10000);
for (let i = 0; i < 10000; i++)
  inst.setMatrixAt(i, composeMatrix(positions[i], scales[i]));
// 2. mergeGeometries：异几何合并
const merged = BufferGeometryUtils.mergeGeometries(
  geometries.map(g => g.toNonIndexed()));
// 选择表：
// 同几何 + 动态增删实例 → InstancedMesh（count 增删方便）
// 异几何 + 静态展示 → mergeGeometries（一次 draw，最快）
// 异几何 + 需单独交互 → 保持独立 Mesh + 视锥剔除（merge 后无法单独拾取）
```
