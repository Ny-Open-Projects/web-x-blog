## VIZ-435：渲染优化的方法论：先测哪一层

**答**：
- 三层定位：CPU 提交层（JS/驱动开销）、GPU 几何层（顶点吞吐）、GPU 像素层（片元吞吐）。
- 测法：降分辨率（像素层瓶颈则帧率上升）/减顶点（几何层）/减 draw（CPU 层）三实验二分定位。
- 顺序纪律：先量化基线（帧时间分解）再优化，禁止凭直觉改。

```javascript
// 瓶颈二分实验
function diagnose(renderFn, { scale = 0.5 } = {}) {
  const t0 = bench(renderFn);                          // 全量帧时间
  const tLow = bench(renderFn, { resolutionScale: scale });  // 降分辨率
  const tLowVert = bench(renderFn, { resolutionScale: scale, lodMin: 2 }); // 也减顶点
  if (tLow < t0 * 0.7) return { layer: '像素/带宽', note: '降分辨率显著改善' };
  if (tLowVert < tLow * 0.7) return { layer: '几何', note: '减顶点改善' };
  return { layer: 'CPU 提交', note: '减 draw call 试验' };
}
function bench(fn, opts = {}, frames = 60) { /* 计时 */ return 16; }
```
