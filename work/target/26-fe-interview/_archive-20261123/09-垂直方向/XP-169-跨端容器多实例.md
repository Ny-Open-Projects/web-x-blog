## XP-169：跨端容器多实例：多容器页面的 JS 上下文管理

**答**：
- 多容器实例：多个容器页并发（如多 tab）——每实例独立 JS 上下文（隔离）或共享上下文（省内存）。
- 隔离 vs 共享：隔离（崩溃隔离/状态独立，内存 ×N）；共享（省内存，但全局变量污染/崩溃传染）。
- 折衷：同业务域共享，跨业务隔离——共享池 + 命名空间隔离（全局变量按实例命名空间）。

```javascript
class ContextPool {
  constructor({ maxContexts = 3 } = {}) { this.max = max; this.pool = []; }
  acquire(businessDomain) {                                   // 获取上下文
    const existing = this.pool.find(c => c.domain === businessDomain && !c.busy);
    if (existing) { existing.busy = true; return existing; }   // 复用同域
    if (this.pool.length < this.max) {
      const ctx = this.createContext(businessDomain);           // 新建（带命名空间）
      ctx.busy = true; this.pool.push(ctx);
      return ctx;
    }
    const oldest = this.pool.shift();                            // 淘汰最旧
    oldest.destroy();
    const ctx = this.createContext(businessDomain);
    ctx.busy = true; this.pool.push(ctx);
    return ctx;
  }
  createContext(domain) {                                      // 命名空间隔离
    const ctx = new JSContext();
    ctx.global = new Proxy(ctx.global, {                        // 全局变量按域隔离
      set(t, k, v) { t[`__${domain}__${k}`] = v; return true; },
      get(t, k) { return t[`__${domain}__${k}`]; },
    });
    return ctx;
  }
}
```
