## VIZ-460：渲染优化的降级矩阵设计（设备档位 × 特性）

**答**：
- 矩阵：每特性（阴影/反射/粒子/后处理）定义 L0~L3 行为，设备档位查表。
- 原则：核心信息（数据/交互）任何档位保留，装饰性特性先砍。
- 运行时切换：档位变化热切换（重建管线/FBO），过程一帧内完成。

```javascript
// 降级矩阵
const DEGRADE = {
  shadows:   { L0: 'off', L1: '1024 basic', L2: '2048 PCF', L3: '4096 PCF+CSM' },
  ssr:       { L0: 'off', L1: 'off', L2: 'half-res', L3: 'full-res' },
  particles: { L0: 500, L1: 2000, L2: 5000, L3: 10000 },
  bloom:     { L0: 'off', L1: 'half', L2: 'full', L3: 'full+dirty lens' },
};
function featureFor(level, feature) { return DEGRADE[feature]?.[level] ?? 'off'; }
```
