## VIZ-449：渲染排序：不透明从前到后、透明从后到前的原因

**答**：
- 不透明 early-z：近处先画挡住远处片元（深度测试剔除），片元成本大降。
- 透明不能写深度（否则后面的透明物被错误剔除）——只能排序后从远到近混合。
- 实现：渲染队列两个列表分别排序（441 sortKey 前缀区分）。

```javascript
// 双列表排序
function splitQueue(draws) {
  const opaque = draws.filter(d => !d.transparent)
    .sort((a, b) => a.zNear - b.zNear);             // 近->远
  const trans = draws.filter(d => d.transparent)
    .sort((a, b) => b.zNear - a.zNear);             // 远->近
  return { opaque, trans };
}
```
