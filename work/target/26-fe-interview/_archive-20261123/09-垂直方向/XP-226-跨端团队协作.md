## XP-226：跨端团队协作：容器团队与业务团队分工

**答**：
- 容器团队与业务团队分工：容器团队（渲染引擎/桥/基础组件/性能）与业务团队（页面/业务逻辑/埋点）——接口契约（API 文档/版本协商）。
- 协作机制：容器 API 版本化（semver）+ 变更通知（changelog 自动推送）+ 业务反馈通道（issue 分级）。
- 反模式：容器团队包揽业务页面（瓶颈）/业务团队绕过容器直接调 Native（失控）。

```javascript
const teamCollaboration = {
  containerTeam: '渲染引擎/桥协议/基础组件（Button/List）/性能优化/安全加固',
  businessTeam: '页面开发/业务逻辑/埋点/A/B 实验',
  contract: {
    apiVersion: 'semver（破坏性变更提前一个大版本通知，HW-AV-303 复用）',
    changelog: '版本发布自动推送变更文档到业务群',
    sla: '容器 bug P0 2h 响应 / P1 24h',
  },
  antiPatterns: [
    '容器团队写业务页面 → 成瓶颈',
    '业务绕过容器 API 直接 Native 调用 → 安全失控/升级困难',
  ],
  governance: '代码评审：跨层调用必须走适配层——lint 规则强制（import 限制）',
};
```
