## XP-201：小程序双线程模型：逻辑层与渲染层分离

**答**：
- 小程序双线程：逻辑层（JSCore 跑业务 JS）与渲染层（WebView 渲染 WXML）分离——安全（无 DOM/BOM）+ 管控（JS 不能直接操作页面）。
- 通信成本：setData 跨线程序列化传输（HW-670/671 已详述）——性能瓶颈核心。
- 分层收益：渲染层多 WebView（每页一个）互不影响；逻辑层单线程管所有页面。

```javascript
const mpArch = {
  logicLayer: { runtime: 'JSCore（无 DOM/BOM）',
    pages: '单线程管理所有页面实例',
    api: 'wx.xxx（Native 能力桥接）' },
  renderLayer: { runtime: 'WebView（每页一个）',
    render: 'WXML/WXSS 渲染', comm: 'setData → 序列化 → 渲染层 diff' },
  bridge: 'Native 层中转（逻辑层 ⇄ Native ⇄ 渲染层）——两次序列化',
  perf: 'setData 数据量/频率是性能核心（ALG-470 setData 审计）',
};
// 对比：Taro/uni-app 编译到小程序语法——框架层抹平但双线程成本不变
```
