## XP-338：跨端组件库的版本协同与破坏性变更管理

**答**：
- 版本：semver + 变更日志自动化（conventional commits）；破坏性变更带迁移指南与 codemod。
- 协同：组件库多端实现（web/rn/mini）同步发版（monorepo 变更集）。
- 灰度：组件库新版本先内部应用灰度，崩溃率指标验收后全量。

```javascript
// 变更集发版
function releasePlan(changes) {
  const breaking = changes.filter(c => c.type === 'breaking');
  return {
    version: bumpVersion(changes),
    requiresMigration: breaking.length > 0,
    codemods: breaking.map(b => b.codemodPath),
    rollout: breaking.length ? '内部灰度 2 周' : '直接发布',
  };
}
```
