## XP-382：跨端性能专项（工程层）收口

**答**：
- 工程：包体（333/339）、CI（339/363）、预算（340）、兼容（337）——流程保证。
- 体验：秒开（371）/视频（372）/手势（366）/导航（375）——端到端体验。
- 稳定：白屏（341）/崩溃（342）/日志（336）——可观测闭环。

```javascript
// 专项总检查
const XP_CHECK = [
  { id: 'bundle', test: s => s.bundleKB <= END_BUDGETS[s.end].jsKB ?? 3000 },
  { id: 'miaopen', test: s => s.miaopenRate > 80 },
  { id: 'crash', test: s => s.crashRate < 0.001 },
  { id: 'whiteScreen', test: s => s.whiteScreenRate < 0.001 },
  { id: 'scrollFps', test: s => s.scrollDropRate < 0.01 },
];
function xpAudit(signals) {
  return XP_CHECK.filter(c => !c.test(signals))
    .map(c => ({ id: c.id, sev: 'P1' }));
}
```
