## AV-304：音视频场景专项：连麦中断的快速恢复与状态同步

**答**：
- 题目：连麦中断恢复——SFU 切换/网络闪断后，两端状态（麦克风/摄像头开关）同步恢复，避免「对方以为我静音了」。
- 思路：状态消息带版本（每次切换 +1）；重连后交换最新状态版本，低版本应用高版本的变更。
- 评分点：状态版本化；重连同步；冲突仲裁（最新胜）。

```javascript
class StateSyncOnReconnect {
  constructor() { this.stateVersion = 0;
    this.state = { mic: true, camera: true, screen: false }; }
  toggleMic() { this.state.mic = !this.state.mic;
    this.signaling.send('state', { ...this.state, ver: ++this.stateVersion }); }
  async onReconnect(peerState) {                              // 重连后同步
    if (peerState.ver > this.stateVersion) {                   // 对方版本更新：采纳
      this.state = peerState; this.stateVersion = peerState.ver;
      applyRemoteState(peerState);                             // UI 同步（麦克风图标等）
    } else if (this.stateVersion > peerState.ver) {
      this.signaling.send('state', { ...this.state, ver: this.stateVersion });   // 推我的
    }
  }
}
```
