## VIZ-440：场景图遍历优化：脏标记与缓存变换

**答**：
- 问题：每帧全场景遍历更新变换 O(n)——静态子树无需更新。
- 手段：脏标记（transform 改变才重算子树）、世界矩阵缓存、静态节点与动态节点分表。
- 收益：10 万节点场景，动态 < 1k 时遍历成本降 99%。

```javascript
// 脏标记场景图
class Node {
  constructor() { this.children = []; this.dirty = true; this.world = null; }
  setDirty() { this.dirty = true;
    for (const c of this.children) c.setDirty(); }     // 向下传播
  updateWorld(parentWorld) {
    if (this.dirty) {
      this.world = parentWorld
        ? mul4(parentWorld, this.local) : this.local;
      this.dirty = false;
    }
    for (const c of this.children) c.updateWorld(this.world);
  }
}
```
