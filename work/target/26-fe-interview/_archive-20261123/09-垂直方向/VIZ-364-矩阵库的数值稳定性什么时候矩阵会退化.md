## VIZ-364：矩阵库的数值稳定性：什么时候矩阵会"退化"

**答**：
- 退化原因：非均匀缩放到 0（行列式 0）、精度累积（千次小旋转浮点漂移导致行列式偏离 1）。
- 防护：旋转矩阵定期正交化（Gram-Schmidt）、行列式监控（偏离 1 超 5% 告警）、避免连续小步长旋转累积。
- 测试：随机 1000 次级联后验证 M·M⁻¹ ≈ I 的误差上界。

```javascript
// 矩阵正交化（Gram-Schmidt 3x3）
function orthonormalize(m) {   // 列向量
  const col = (i) => [m[i*4], m[i*4+1], m[i*4+2]];
  const norm = v => { const l = Math.hypot(...v) || 1; return v.map(x => x/l); };
  const sub = (a, b) => a.map((x, i) => x - b[i]);
  const dot3 = (a, b) => a[0]*b[0]+a[1]*b[1]+a[2]*b[2];
  let x = norm(col(0));
  let y = norm(sub(col(1), x.map(v => v * dot3(col(1), x))));
  let z = [
    x[1]*y[2] - x[2]*y[1], x[2]*y[0] - x[0]*y[2], x[0]*y[1] - x[1]*y[0]];
  return [x[0],x[1],x[2],0, y[0],y[1],y[2],0, z[0],z[1],z[2],0, m[12],m[13],m[14],m[15]];
}
```
