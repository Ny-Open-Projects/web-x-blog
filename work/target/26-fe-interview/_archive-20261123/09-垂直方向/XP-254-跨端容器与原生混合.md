## XP-254：跨端容器与原生混合：Tab 切换保活策略（笔试）

**答**：
- 题目：多 Tab 页切换保活——活跃 tab 完整渲染、非活跃 tab 冻结（View 保留但不重绘/JS 暂停）——内存与恢复速度平衡。
- 思路：活跃 tab 完整运行；非活跃 tab：View 树保留（不销毁）+ JS 暂停（定时器冻结）+ 内存超限回收（LRU）。
- 评分点：冻结策略；内存回收；恢复速度。

```javascript
class TabKeepAlive {
  constructor({ maxAlive = 3 } = {}) { this.max = max; this.tabs = new Map(); }
  switchTo(tabId) {                                              // 切换
    for (const [id, tab] of this.tabs) {
      if (id === tabId) { tab.resume(); continue; }               // 活跃：恢复
      tab.freeze();                                               // 非活跃：冻结
    }
    while (this.tabs.size > this.max) {                            // LRU 回收
      const oldest = [...this.tabs.entries()]
        .sort((a, b) => a[1].lastActive - b[1].lastActive)[0];
      if (oldest[0] === tabId) break;
      oldest[1].release(); this.tabs.delete(oldest[0]);            // 释放（状态保留）
    }
    this.tabs.get(tabId).lastActive = Date.now();
  }
}
```
