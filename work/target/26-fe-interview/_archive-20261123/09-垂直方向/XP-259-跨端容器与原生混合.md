## XP-259：跨端容器与原生混合：多语言容器内嵌 H5 桥接安全（笔试）

**答**：
- 题目：容器内嵌 H5 页面 JSBridge 安全——H5 页面不可信（可能被注入）→ JSBridge 调用需校验来源（URL 白名单/签名）。
- 思路：URL 白名单（只允许自家域 H5 调 Bridge）；Bridge 调用签名（H5 每次调用带 token，服务端下发）；HTTPS 强制（防中间人注入）。
- 评分点：URL 白名单；调用签名；HTTPS。

```javascript
class SecureWebBridge {
  WHITELIST = ['https://h5.example.com', 'https://partner.example.com'];
  onBridgeCall(call, sourceUrl) {                              // 桥调用校验
    const url = new URL(sourceUrl);
    if (!this.WHITELIST.some(w => url.origin === w)) {
      fire('bridge-unauthorized', { sourceUrl, method: call.method });   // 审计
      return { error: 'origin-not-allowed' };                     // 拒绝
    }
    if (!this.verifyCallSignature(call)) {                       // 调用签名校验
      return { error: 'signature-invalid' };
    }
    return this.dispatch(call);                                  // 放行
  }
}
```
