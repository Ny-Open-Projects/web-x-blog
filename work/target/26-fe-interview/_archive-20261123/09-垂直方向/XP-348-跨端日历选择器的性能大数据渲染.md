## XP-348：跨端日历/选择器的性能（大数据渲染）

**答**：
- 问题：无限日历/年月选择器渲染全部日期节点（几十万节点）。
- 方案：虚拟滚动（月窗口 ±6）、日期矩阵按需生成、禁用日期区间用数据驱动样式。
- 交互：滑动加载相邻月（预渲染 1 月缓冲）。

```javascript
// 日历窗口渲染
function calendarWindow(currentMonth, offset = 6) {
  const months = [];
  for (let i = -offset; i <= offset; i++) {
    const d = new Date(currentMonth);
    d.setMonth(d.getMonth() + i);
    months.push({ year: d.getFullYear(), month: d.getMonth() + 1,
      days: daysInMonth(d) });
  }
  return months;                                     // 13 月窗口，滑动时平移
}
function daysInMonth(d) {
  return new Date(d.getFullYear(), d.getMonth() + 1, 0).getDate();
}
```
