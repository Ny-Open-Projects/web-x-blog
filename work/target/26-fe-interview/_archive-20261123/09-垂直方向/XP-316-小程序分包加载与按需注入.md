## XP-316：小程序分包加载与按需注入

**答**：
- 分包：主包 < 2MB（微信），业务分包按 tab/路径拆；独立分包可脱离主包启动。
- 按需注入：lazyCodeLoading "requiredComponents" 只注入用到的组件代码。
- 度量：主包体积/启动注入耗时，分包预下载（preloadRule）按路径触发。

```javascript
// 分包配置
const APP_JSON = {
  subpackages: [
    { root: 'pages/shop', pages: ['list', 'detail'] },
    { root: 'pages/order', pages: ['list'] },
  ],
  preloadRule: { 'pages/index': { network: 'all', packages: ['pages/shop'] } },
  lazyCodeLoading: 'requiredComponents',
};
// 主包体积检查：
function checkMainPkg(sizeKB) {
  return { sizeKB, over: sizeKB > 2048,
    advice: sizeKB > 2048 ? '拆分包或压缩资源' : 'ok' };
}
```
