## XP-301：跨端电量与发热优化

**答**：
- 热源：高频动画（60fps GPU 满载）、高频定位/GPS、持续网络轮询、蓝牙常连。
- 策略：后台降帧（30fps）、定位按需（前台才 GPS）、长连接心跳拉长（30s→60s 后台）。
- 度量：发热反馈率（用户举报）+ 电量消耗监控（iOS MetricKit/Android Battery Historian）。

```javascript
// 发热降档
function thermalPolicy(level) {                      // nominal/fair/serious/critical
  return {
    nominal: { fps: 60, gpsHz: 1 },
    fair:    { fps: 45, gpsHz: 0.5 },
    serious: { fps: 30, gpsHz: 0.2, animOff: true },
    critical:{ fps: 15, gpsHz: 0, netPause: true },  // 极限省电
  }[level] ?? { fps: 60 };
}
```
