## XP-363：跨端性能专项的回归体系（自动化）

**答**：
- 基准：各端基准场景（启动/列表/动画）自动跑，指标入库对比。
- 触发：每日定时 + 发版前必跑；劣化 > 8% 阻断发布。
- 环境：真机云测（固定机型池）保证可比性。

```javascript
// 跨端回归
async function crossEndRegression(ends) {
  const results = {};
  for (const end of ends) {
    const r = await runBench(end, { device: 'fixed-pool', frames: 300 });
    results[end] = { tti: r.tti, fps: r.fps, mem: r.memMB };
  }
  const baseline = await loadBaseline();
  const regressions = Object.entries(results)
    .filter(([end, r]) => r.tti > baseline[end].tti * 1.08);
  return { pass: !regressions.length, regressions };
}
```
