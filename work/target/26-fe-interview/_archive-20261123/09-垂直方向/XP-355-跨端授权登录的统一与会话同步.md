## XP-355：跨端授权登录的统一与会话同步

**答**：
- 统一：各端登录（微信/Apple/手机号）映射统一账号体系，token 标准化。
- 会话同步：多端登录互踢策略（可配置）或共存（分设备管理）。
- 性能：静默续期（refresh token 自动刷新，无感）。

```javascript
// 登录会话管理
class SessionManager {
  async refresh() {
    const r = await api('/auth/refresh', { credentials: 'include' });
    if (r.kicked) { clearLocal(); navigate('/login'); return; }
    setToken(r.token);
    scheduleNextRefresh(r.expiresIn - 60_000);        // 提前 1 分钟
  }
}
// 多端策略：token 绑 deviceId，同账号多设备并存，敏感操作 step-up 认证
```
