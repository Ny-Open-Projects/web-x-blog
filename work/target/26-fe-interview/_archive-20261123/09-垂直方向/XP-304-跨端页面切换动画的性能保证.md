## XP-304：跨端页面切换动画的性能保证

**答**：
- 原则：切换动画只用 transform/opacity（合成层），布局属性动画必卡。
- 实现：新页面预渲染（转场前 prepare）+ 共享元素过渡（各端 API 差异大）。
- 降级：低端机淡入淡出替代复杂转场。

```javascript
// 共享元素过渡抽象
function sharedElement(fromEl, toEl, { duration = 300 } = {}) {
  const a = fromEl.getBoundingClientRect();
  const b = toEl.getBoundingClientRect();
  return { transform:
    `translate(${a.left - b.left}px, ${a.top - b.top}px) scale(${a.width / b.width})`,
    duration, easing: 'ease',
    note: '从 from 位置动画到 to 位置（FLIP）' };
}
```
