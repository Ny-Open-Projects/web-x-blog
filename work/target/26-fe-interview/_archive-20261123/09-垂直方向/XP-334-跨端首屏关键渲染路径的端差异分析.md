## XP-334：跨端首屏关键渲染路径的端差异分析

**答**：
- H5：CSS/JS 阻塞 + 字体；小程序：注入+setData；RN：bundle 加载+首帧组件树；Flutter：引擎+着色器。
- 各端关键路径单独诊断（工具不同：DevTools/小程序助手/Flutter DevTools）。
- 统一产出：各端首屏 checklist 与耗时构成表（对比定位端专属短板）。

```javascript
// 首屏构成表
function firstScreenBreakup(end, stages) {
  const TABLE = {
    h5: ['dns', 'tls', 'html', 'css', 'js', 'render'],
    miniprogram: ['inject', 'firstSetData', 'render'],
    rn: ['bundleLoad', 'jsInit', 'firstRender'],
    flutter: ['engine', 'shader', 'firstFrame'],
  };
  return { end, stages: TABLE[end].map(s => ({ stage: s, ms: stages[s] ?? null })) };
}
```
