## XP-280：跨端容器专项：容器多主题切换性能（免重绘策略）（笔试）

**答**：
- 题目：容器主题切换性能——逐元素重绘慢（1000 节点 200ms）→ token 批量切换（一次桥调用全量换色）+ Native 侧批量属性更新。
- 思路：主题 token 批量下发（一次桥调用）→ Native 侧遍历 View 树批量更新颜色属性（Native 遍历比 N 次桥调用快）。
- 评分点：批量下发；Native 侧批量更新；耗时对比。

```javascript
class FastThemeSwitch {
  async switchTheme(themeName) {                              // 快速主题切换
    const tokens = await getTokens(themeName);                  // token 集
    const t0 = performance.now();
    bridge.commit([{ op: 'set-theme-batch', tokens }]);          // 一次桥调用（批量）
    // Native 侧：遍历 View 树按 token 批量更新——C++ 层快（1000 节点 ~10ms）
    report('theme-switch', { ms: performance.now() - t0, nodes: 1000 });
  }
}
// 反模式：JS 侧逐节点 commit([{ op: 'update', color }]) × 1000 → 1000 次桥调用 → 200ms+
// 批量化：一次桥调用 + Native C++ 遍历 → 10ms（20x）
```
