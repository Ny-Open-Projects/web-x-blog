## XP-371：跨端页面秒开指标的统一采集

**答**：
- 定义：从点击（或冷启动）到首屏内容可交互的时长，各端起点/终点映射表。
- 采集：起点（点击时间戳/路由事件）、终点（首帧渲染+数据就绪）。
- 口径：分端 P75 看板，秒开率（< 1s 占比）北极星。

```javascript
// 秒开率统计
function miaopenRate(samples, threshold = 1000) {
  const per = {};
  for (const s of samples)
    (per[s.end] ??= { fast: 0, total: 0 });
  per[s.end].total++;
  if (s.duration < threshold) per[s.end].fast++;
  return Object.fromEntries(Object.entries(per)
    .map(([e, v]) => [e, +(v.fast / v.total * 100).toFixed(1) + '%']));
}
```
