## VIZ-360：球面插值：大圆距离与地理坐标换算

**答**：
- 地图场景常用：两经纬点距离用 Haversine（球面大圆），小范围用 equirectangular 近似（快 10 倍）。
- 坐标换算：经纬度 → 墨卡托（Web 地图标准）：y = ln(tan(π/4 + φ/2))，纬度 ±85 之外的裁剪是规范。
- 注意：Web Mercator 面积失真（高纬膨胀），做面积/密度统计要换等积投影或按纬度修正。

```javascript
// Haversine + Mercator
function haversine([lat1, lon1], [lat2, lon2], R = 6371) {
  const d = Math.PI / 180;
  const a = Math.sin((lat2-lat1)*d/2)**2 +
    Math.cos(lat1*d) * Math.cos(lat2*d) * Math.sin((lon2-lon1)*d/2)**2;
  return 2 * R * Math.asin(Math.sqrt(a));      // km
}
function mercator([lat, lon]) {
  const x = lon / 180;
  const y = Math.log(Math.tan(Math.PI/4 + (lat*Math.PI/180)/2)) / Math.PI;
  return [x, -Math.min(1, Math.max(-1, y))];   // [-1,1] 区间
}
console.log(haversine([39.9, 116.4], [31.2, 121.5]).toFixed(0), 'km');
```
