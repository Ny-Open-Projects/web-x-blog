## VIZ-455：渲染管线级缓存：场景状态快照与增量更新

**答**：
- 场景大数据（几十万对象）：每帧全量更新 instance buffer 太贵——增量：只提交变化的实例区间。
- 实现：实例按 chunk 分块（每块 4k 实例），脏块才重传；排序结果缓存（visibility mask 变化才重排）。
- 复杂度管理：脏追踪粒度（实例级 -> 块级）权衡 CPU 与传输量。

```javascript
// 增量 instance 提交
class InstanceStore {
  constructor(chunk = 4096) { this.chunk = chunk;
    this.dirty = new Set(); }
  markDirty(i) { this.dirty.add(Math.floor(i / this.chunk)); }
  flushUpload(buffer, data) {
    for (const c of this.dirty) {
      const start = c * this.chunk;
      gl.bufferSubData(gl.ARRAY_BUFFER, start * stride,
        data.subarray(start * stride, (start + this.chunk) * stride));
    }
    this.dirty.clear();
  }
}
```
