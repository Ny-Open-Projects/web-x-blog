## XP-268：跨端容器专项：小程序 setData 与容器指令集对比（笔试）

**答**：
- 题目：对比小程序 setData 与自研容器指令集——通信次数/数据量/更新粒度，写对比表与选型建议。
- 思路：setData（页面级全量 diff → 渲染层）vs 指令集（最小操作序列）；粒度：页面 vs 节点；通信：双线程 vs JSI 直调。
- 评分点：四维对比表；选型建议；量化差异。

```javascript
const setDataVsOps = {
  granularity: { setData: '页面级（整页 diff）', ops: '节点级（最小操作序列）' },
  dataVolume: { setData: '变化字段全量传（路径优化后仍传值）',
    ops: '只传 diff（update 节点 + 变化 props）' },
  commCount: { setData: '每次调用一次跨线程', ops: '批量合并（16ms 窗口）一次' },
  sync: { setData: '异步（跨线程）', ops: 'JSI 可同步直调（Fabric 类）' },
  selection: '性能敏感 → 指令集（自研容器）；生态优先 → 小程序（setData 优化到位也可用）',
  quantified: '万节点更新：setData 80ms vs 指令集 5ms（16x）',
};
```
