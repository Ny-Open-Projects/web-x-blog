## VIZ-380：流场可视化：向量场的箭头/流线绘制

**答**：
- 箭头场：网格采样向量，画箭头（位置+方向+长度按模长缩放，颜色映射模长）。
- 流线：从种子点沿场积分（RK2/RK4），终止条件（出界/到达已有流线过近）。
- 性能：流线积分在 Worker 预计算，Canvas/WebGL 只画折线。

```javascript
// 流线积分（RK2）
function streamline(field, seed, { step = 0.5, maxLen = 200 } = {}) {
  const pts = [seed];
  let p = seed;
  for (let i = 0; i < maxLen; i++) {
    const v1 = field(p);
    const mid = [p[0] + v1[0]*step/2, p[1] + v1[1]*step/2];
    const v2 = field(mid);
    p = [p[0] + v2[0]*step, p[1] + v2[1]*step];
    if (!isFinite(p[0])) break;
    pts.push([...p]);
  }
  return pts;
}
// field(x,y) 返回 [vx, vy]；箭头绘制：
// angle = atan2(vy, vx)，len = clamp(|v|, 4, 20)
```
