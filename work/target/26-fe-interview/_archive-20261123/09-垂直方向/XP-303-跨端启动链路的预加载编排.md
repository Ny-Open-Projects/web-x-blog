## XP-303：跨端启动链路的预加载编排

**答**：
- 编排：启动 → 主框架就绪 → 预加载核心路由 bundle → 预取用户数据 → 预热下一页。
- 原则：预加载不阻塞首帧（idle 队列）、按用户路径概率排序（埋点驱动）。
- 度量：预加载命中率（预取资源被实际使用比例）> 60% 才有价值。

```javascript
// 预加载编排
function preloadOrchestrator(routes, usageStats) {
  const sorted = routes.sort((a, b) =>
    (usageStats[b.path] ?? 0) - (usageStats[a.path] ?? 0));
  const queue = [...sorted];
  function step(idle) {
    while (queue.length && performance.now() - idle < 12) {
      const r = queue.shift();
      import(r.bundle);                               // 预加载 bundle
    }
    if (queue.length) requestIdleCallback(step);
  }
  requestIdleCallback(step);
}
```
