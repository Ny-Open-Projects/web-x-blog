## XP-160：跨端容器灰度发布：新容器版本按流量切换

**答**：
- 容器灰度：新渲染引擎版本按用户流量灰度（flag 分桶），指标哨兵（崩溃率/白屏率/首帧）劣化自动暂停（HW-846 复用）。
- 回退：flag 关闭 → 回退旧引擎；已加载新引擎页面 → 下次启动回退（运行中不强切）。
- 双跑对比：新旧引擎同场景渲染截图 diff + 性能对比（VIZ-260 思想）。

```javascript
class ContainerGrayscale {
  async getEngineVersion(userId) {
    const bucket = hashStr(userId) % 100;
    const gray = await getFlag('container-v2', { default: 0 });
    return bucket < gray ? 'v2' : 'v1';
  }
  async sentinel(releaseId) {                                 // 指标哨兵
    const { gray, base } = await metrics.compare(releaseId,
      { metrics: ['crashRate', 'whiteScreenRate', 'firstFrameP75'], minSample: 500 });
    const degraded = gray.crashRate > base.crashRate * 1.5
      || gray.whiteScreenRate > base.whiteScreenRate * 1.3;
    if (degraded) {
      await pauseGray(releaseId);                              // 自动暂停灰度
      notifyOnCall(releaseId, '容器灰度劣化');
    }
  }
}
```
