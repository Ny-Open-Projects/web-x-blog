## AV-374：视频打点与章节导航的数据结构

**答**：
- 章节：[{ start, end, title }]，播放器按 currentTime 查当前章节（二分）。
- 打点热图：观看热力（每 5s 粒度回放/跳过统计）叠加进度条。
- 交互：点击章节跳转（seek 到 start），章节切换事件用于埋点。

```javascript
// 章节查找
function chapterAt(chapters, t) {
  let lo = 0, hi = chapters.length - 1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    if (t < chapters[mid].start) hi = mid - 1;
    else if (t >= chapters[mid].end) lo = mid + 1;
    else return chapters[mid];
  }
  return null;
}
function heatSegments(heat, granularity = 5) {
  return heat.map((v, i) => ({ start: i * granularity,
    ratio: v, hot: v > 0.8 }));
}
```
