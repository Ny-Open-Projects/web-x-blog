## AV-409：协作会话的进入与退出协议

**答**：
- 进入：auth -> join（携 lastSeq/clientId）-> 快照/增量 -> presence 广播（其他人看到新成员）。
- 退出：leave 广播 -> 光标移除 -> 锁释放 -> 会话注册表清理；异常断开走超时清理（397）。
- 全量校验：进入时服务端校验权限/容量（房间人数上限）。

```javascript
// 进入退出协议
class Session {
  async join({ roomId, lastSeq }) {
    await assertCapacity(roomId);                      // 容量校验
    const snap = await getSnapshotSince(roomId, lastSeq);
    broadcastPresence({ event: 'join', user: this.user });
    return { snapshot: snap, members: currentMembers(roomId) };
  }
  leave() {
    releaseAllLocks(this.user.id);
    broadcastPresence({ event: 'leave', user: this.user });
  }
}
```
