## XP-163：跨端容器与原生混合导航：路由同步

**答**：
- 混合导航：Native 页与容器页混排（HW-865 复用）——路由栈同步（Native 栈与 JS 路由栈一致）；返回手势透传。
- 实现：Native 侧管理栈（push/pop），JS 路由事件与 Native 栈事件双向同步；冲突（JS 内跳转 vs Native 返回）以 Native 栈为准。
- 坑：JS push 但 Native 未入栈 → 返回手势错乱——单向数据流：Native 栈为真源。

```javascript
class HybridNavigator {
  constructor(native) { this.native = native; this.jsRoutes = []; }
  push(route) {                                              // JS push → Native 入栈
    this.native.push(route);                                  // Native 先入栈
    this.jsRoutes.push(route);
  }
  onNativePop() {                                             // Native 返回 → JS 同步
    const popped = this.jsRoutes.pop();
    popped?.onLeave?.();                                      // 触发页面离开钩子
  }
  // 铁律：Native 栈为真源——JS 只发指令，Native 栈事件回调同步 JS 状态
  // 冲突：JS 快速 push 多次 → Native 去重/排队——保证栈一致
```
