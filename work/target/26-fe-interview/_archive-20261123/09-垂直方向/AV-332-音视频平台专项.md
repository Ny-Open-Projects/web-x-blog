## AV-332：音视频平台专项：直播间多端数据一致性（观看数/点赞数）（笔试）

**答**：
- 题目：直播间计数一致性——多端显示的观看数/点赞数可能不一致（缓存/推送延迟），定期对齐 + 展示层模糊化（约 x 万）。
- 思路：服务端权威计数 → 增量推送 → 客户端本地累加可能漂移 → 周期性全量对齐（30s 快照）；展示层大数模糊（1.2万）。
- 评分点：增量+对齐；漂移修正；展示模糊。

```javascript
class LiveCounterSync {
  constructor(ws) { this.local = 0; this.lastSync = 0; }
  onIncrement(delta) { this.local += delta; }                   // 增量累加
  onSync(authoritative) {                                        // 30s 全量对齐
    if (Math.abs(this.local - authoritative) > authoritative * 0.05) {   // 漂移 > 5%
      report('counter-drift', { local: this.local, server: authoritative,
        drift: +(Math.abs(this.local - authoritative) / authoritative * 100).toFixed(1) + '%' });
    }
    this.local = authoritative;                                   // 对齐
  }
  display() {                                                     // 模糊化展示
    return this.local > 10000 ? `${(this.local / 10000).toFixed(1)}万` : String(this.local);
  }
}
```
