## TST-496：笔试：相似用例检测（断言集合重叠）。
**答**：用例 `[{name, asserts: string[]}]`。Jaccard 相似度 > 0.8 的对输出合并建议（保留断言更多的）。

```javascript
function dupCandidates(cases, { threshold = 0.8 } = {}) {
  const out = [];
  for (let i = 0; i < cases.length; i++)
    for (let j = i + 1; j < cases.length; j++) {
      const a = new Set(cases[i].asserts), b = new Set(cases[j].asserts);
      const inter = [...a].filter(x => b.has(x)).length;
      const jac = inter / (a.size + b.size - inter || 1);
      if (jac > threshold) out.push({
        keep: cases[i].asserts.length >= cases[j].asserts.length ? cases[i].name : cases[j].name,
        drop: cases[i].asserts.length >= cases[j].asserts.length ? cases[j].name : cases[i].name,
        jaccard: +jac.toFixed(2) });
    }
  return out;
}
console.log(dupCandidates([
  { name: 'a', asserts: ['x', 'y', 'z'] },
  { name: 'b', asserts: ['x', 'y', 'z', 'w'] },
])[0].keep); // b

```

**评分点**：
- Jaccard = 交/并（集合运算正确）。
- 两两比对（去重对称）。
- 保留建议（断言数多者）。
- 阈值可配。
