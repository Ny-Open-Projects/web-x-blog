## TST-403：笔试：实现 toMatchObject（部分深匹配）。
**答**：`expect(obj).toMatchObject(sub)`：sub 中的每个键递归存在于 obj 且值匹配（对象递归、数组按位、正则可作期望）。输出失败路径（如 `user.addr.city`）。

```javascript
function match(obj, sub, path = '') {
  for (const [k, v] of Object.entries(sub)) {
    const p = path ? `${path}.${k}` : k;
    if (!(k in obj)) throw new Error(`路径 ${p} 缺失`);
    if (v instanceof RegExp) { if (!v.test(obj[k])) throw new Error(`路径 ${p} 不匹配正则`); }
    else if (v && typeof v === 'object') match(obj[k], v, p);
    else if (obj[k] !== v) throw new Error(`路径 ${p}：期望 ${v} 实得 ${obj[k]}`);
  }
}
export const toMatchObject = (obj) => (sub) => match(obj, sub);
expect({ user: { addr: { city: 'bj' } } }).toMatchObject({ user: { addr: { city: /^b/ } } }); // 通过

```

**评分点**：
- 递归匹配 + 失败路径回传（可定位）是核心。
- 正则期望值支持（toMatch 语义）。
- 数组按位比较（长度可比 sub 长）。
- 键缺失与值不匹配区分报错。
