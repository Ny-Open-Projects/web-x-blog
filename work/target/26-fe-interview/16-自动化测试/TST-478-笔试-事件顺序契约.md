## TST-478：笔试：WebSocket/消息流的「事件序列契约」校验。
**答**：契约：握手后期望序列 `['connected', 'snapshot', 'delta*']`（* 表重复）。实现 `verifySequence(received, expected)`：逐 token 匹配，`x*` 允许 0 次或多次；输出首个违约位置。

```javascript
function verifySequence(received, expected) {
  let ei = 0;
  for (let ri = 0; ri < received.length; ri++) {
    const tok = expected[ei];
    if (!tok) return { ok: false, at: ri, why: `多余事件 ${received[ri]}` };
    if (tok.endsWith('*')) {
      if (received[ri] !== tok.slice(0, -1)) ei++;   // 结束重复段
      if (received[ri] !== tok.slice(0, -1) && received[ri] !== expected[ei]) {
        // 前进后再比较
        if (received[ri] !== (expected[ei] || '')) return { ok: false, at: ri, why: `期望 ${expected[ei]} 得 ${received[ri]}` };
      }
    } else {
      if (received[ri] !== tok) return { ok: false, at: ri, why: `期望 ${tok} 得 ${received[ri]}` };
      ei++;
    }
  }
  const rest = expected.slice(ei).filter(t => !t.endsWith('*'));
  return rest.length ? { ok: false, at: received.length, why: `缺失: ${rest}` } : { ok: true };
}
console.log(verifySequence(['connected', 'snapshot', 'delta', 'delta', 'close'], ['connected', 'snapshot', 'delta*']).ok); // true

```

**评分点**：
- 星号重复语义解析（x* 贪婪匹配）。
- 顺序违约输出位置与期望（可诊断）。
- 空流（只匹配到 0 个）判定。
- 多余事件（未在契约中）告警。
