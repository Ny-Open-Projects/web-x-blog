## TST-495：笔试：测试指标周环比表（含异常标记）。
**题目**：本周/上周指标 `{flakyRate, avgMs, passRate}`。每指标环比变化；异常 = 恶化超 15%。输出表格行（只列恶化项为告警，其余正常）。

```javascript
const DIRECTION = { flakyRate: 'up-bad', avgMs: 'up-bad', passRate: 'down-bad' };
function weekOverWeek(cur, prev, { threshold = 0.15 } = {}) {
  const alerts = [];
  for (const k of Object.keys(DIRECTION)) {
    if (prev[k] === undefined || cur[k] === undefined) continue;
    const d = (cur[k] - prev[k]) / prev[k];
    const bad = DIRECTION[k] === 'up-bad' ? d > threshold : d < -threshold;
    if (bad) alerts.push(`${k}: ${prev[k]} → ${cur[k]}（${(d * 100).toFixed(1)}% 恶化）`);
  }
  return { alerts, healthy: alerts.length === 0 };
}
console.log(weekOverWeek(
  { flakyRate: 0.06, avgMs: 100, passRate: 0.98 },
  { flakyRate: 0.04, avgMs: 100, passRate: 0.98 }).alerts); // flakyRate 恶化 50%

```

**评分点**：
- 环比计算（方向语义：flaky 升=恶化，passRate 降=恶化）。
- 方向映射表（每指标恶化方向）。
- 阈值 15% 判定。
- 只输出恶化告警（降噪）。
