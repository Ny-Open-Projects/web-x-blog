## TST-369：同一业务多端实现（H5/小程序/RN）的行为一致性测试？
**答**：
- 核心断言共享：业务断言（金额计算/状态流转）抽成平台无关断言集。
- 多端驱动适配层：同一测试逻辑通过 adapter 驱动 Playwright/小程序模拟器/RN。
- 一致性基线：同一输入在多端的输出 JSON 对比（截图次要，行为数据优先）。
- 差异白名单：平台固有差异（导航栏样式）显式登记豁免。

```javascript
for (const drv of [h5Driver, miniProgramDriver, rnDriver]) {
  const out = await drv.runFlow('addToCartAndCheckout');
  expect(normalize(out)).toEqual(baseline.checkout);   // 行为一致
}
```
