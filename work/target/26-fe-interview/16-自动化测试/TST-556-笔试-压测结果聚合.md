## TST-556：笔试：笔试：压测结果聚合（P50/P90/P99）

**题目**：实现 aggregateLatency(samples)。samples=[{name, latency, status, ts}] 为压测采样。要求：① 忽略 status !== 'ok' 的样本，但统计 errorCount；② 对成功样本的 latency 计算 P50/P90/P99（线性插值）、min、max、avg、count；③ QPS 估算 = count / 覆盖秒数（按 ts 的 max-min，至少 1 秒）；④ 边界：无成功样本时返回各分位为 0、qps 0、errorCount 正常。

**答**：
- 结论：过滤失败样本 → 排序算分位 → 用时间跨度估算 QPS。
- 实现要点：percentile 线性插值；ts 按秒计（注意单位），跨度至少 1 秒避免除零；无成功样本时各分位 0 但 errorCount 保留。
- 追问钩子：为什么压测看 P99 而非均值？——均值被大量快请求拉低，P99 反映长尾用户体验；SLO 通常按 P99/P95 定义。

```javascript
function percentile(sorted, p) {
  if (!sorted.length) return 0;
  const i = (sorted.length - 1) * p, lo = Math.floor(i), hi = Math.ceil(i);
  return sorted[lo] + (sorted[hi] - sorted[lo]) * (i - lo);
}
function aggregateLatency(samples = []) {
  const ok = samples.filter(s => s.status === 'ok').map(s => s.latency).sort((a, b) => a - b);
  const errorCount = samples.length - ok.length;
  if (!ok.length) return { P50: 0, P90: 0, P99: 0, min: 0, max: 0, avg: 0, count: 0, qps: 0, errorCount };
  const ts = samples.map(s => s.ts);
  const seconds = Math.max(1, (Math.max(...ts) - Math.min(...ts)) / 1000);
  return { P50: +percentile(ok, 0.5).toFixed(2), P90: +percentile(ok, 0.9).toFixed(2),
    P99: +percentile(ok, 0.99).toFixed(2), min: ok[0], max: ok[ok.length - 1],
    avg: +(ok.reduce((a, b) => a + b, 0) / ok.length).toFixed(2),
    count: ok.length, qps: +(ok.length / seconds).toFixed(2), errorCount };
}
```

**评分点**：
- 正确过滤非 ok 样本并统计 errorCount。
- P50/P90/P99 用线性插值计算。
- QPS 按时间跨度估算且至少 1 秒，避免除零。
- 无成功样本时返回全 0 分位但保留 errorCount，边界完整。
