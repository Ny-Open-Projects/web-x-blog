## TST-600：笔试：笔试：整合题——韧性评分卡聚合器

**题目**：整合题：实现 resilienceReport(experiments, weights)。experiments=[{id, scenario, steadyHeld:boolean, degradeCorrect:boolean, recoveryMs, alerted:boolean, findings:[string]}]。weights={steady:number, degrade:number, recovery:number, alert:number}（默认各 0.25）。要求：① 每个实验算分：steadyHeld?1:0、degradeCorrect?1:0、recovery 分=max(0,1-recoveryMs/60000)、alerted?1:0，按 weights 加权；② 总分=所有实验分的均值×100；③ 输出 {score, perExperiment:[{id, score}], weakScenarios:得分最低的2个scenario, totalFindings:findings总数, grade:'A'|'B'|'C'|'D'}（grade: >=90 A, >=75 B, >=60 C, else D）；④ 边界：空 experiments 返回 score=0 grade='D'。

**答**：
- 结论：单实验加权得分 → 全局均值×100 → 找最弱场景 + 汇总发现 + 分级。
- 实现要点：weights 归一化或直接按给定权重（题目默认和为1）；recovery 分 clamp 0~1；weakScenarios 按分升序取前2；findings 用 flat 计数。
- 追问钩子：为什么按场景维度找「最弱」而非只看总分？——总分掩盖单点薄弱；弱场景才是改进方向，复盘要落到具体实验。

```javascript
function resilienceReport(experiments = [], weights = {}) {
  const w = { steady: 0.25, degrade: 0.25, recovery: 0.25, alert: 0.25, ...weights };
  if (!experiments.length) return { score: 0, perExperiment: [], weakScenarios: [], totalFindings: 0, grade: 'D' };
  const per = experiments.map(e => {
    const s = (e.steadyHeld ? 1 : 0) * w.steady + (e.degradeCorrect ? 1 : 0) * w.degrade
      + Math.max(0, 1 - e.recoveryMs / 60000) * w.recovery + (e.alerted ? 1 : 0) * w.alert;
    return { id: e.id, scenario: e.scenario, score: +s.toFixed(3) };
  });
  const score = +(per.reduce((a, x) => a + x.score, 0) / per.length * 100).toFixed(1);
  const weak = [...per].sort((a, b) => a.score - b.score).slice(0, 2).map(x => x.scenario);
  const totalFindings = experiments.reduce((n, e) => n + (e.findings?.length || 0), 0);
  const grade = score >= 90 ? 'A' : score >= 75 ? 'B' : score >= 60 ? 'C' : 'D';
  return { score, perExperiment: per, weakScenarios: weak, totalFindings, grade };
}
```

**评分点**：
- 单实验四维度按 weights 加权，recovery 分 clamp 0~1。
- 总分 = 均值×100，grade 按 90/75/60 正确分级。
- weakScenarios 取得分最低 2 个场景，totalFindings 汇总正确。
- 空 experiments 返回 score=0/grade='D'，边界与输出结构完整。
