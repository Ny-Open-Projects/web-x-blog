## TST-542：如何做前端性能回归测试（性能预算）

**答**：
- 结论：把性能指标当作「可失败的测试」——在 CI 中设定预算阈值，超预算即 fail，而不是只出报告没人看。
- 做法：固定测试环境（设备/网络/缓存状态，多次取中位数）；对 LCP/包体积/长任务数设预算；用基线对比（相对劣化 >10% 也告警），并把结果写进 PR。
- 追问钩子：性能数据天然抖动，怎么避免误报？——多轮取 P50/P75、设置容差带、只用同机型同网络对比；对抖动大的指标先看分布再定阈值。

```javascript
// 性能回归判定：绝对值 + 相对基线双重门槛
function perfRegression(current, baseline, { absLimit, degradeLimit = 0.1 }) {
  const res = {};
  for (const k of Object.keys(absLimit)) {
    const absOk = current[k] <= absLimit[k];
    const relOk = current[k] <= baseline[k] * (1 + degradeLimit);
    res[k] = { absOk, relOk, pass: absOk && relOk };
  }
  return res;
}
console.log(perfRegression({ LCP: 2600 }, { LCP: 2200 },
  { absLimit: { LCP: 2500 } }).LCP); // { absOk:false, relOk:false, pass:false }
```
