## TST-519：测试架构师的核心能力模型是什么

**答**：
- 结论：T 型能力——纵深是测试技术（框架/分层/度量），横向是工程架构（CI/CD、可观测、分布式）与软技能（影响力、权衡沟通）。
- 具体：① 能设计分层策略与门禁体系；② 懂研发架构以精准定位风险点；③ 能用数据讲清质量与 ROI；④ 能推动落地而非只出方案。
- 追问钩子：和 QA 负责人/测试开发的区别？——更偏「体系设计与技术决策」，对质量结果负责但不局限执行，需跨团队建立共识并沉淀平台能力。

```javascript
// 能力雷达：架构师 vs 测试开发的侧重差异
const competency = {
  architect: { strategy: 5, framework: 4, engineering: 5, metrics: 5, influence: 5, coding: 3 },
  sdet:      { strategy: 3, framework: 5, engineering: 5, metrics: 3, influence: 3, coding: 5 },
};
function gap(a, b) {
  return Object.fromEntries(Object.keys(a).map(k => [k, +(a[k] - b[k]).toFixed(1)]));
}
// 架构师相对 SDET：战略/度量/影响力更高，编码深度略低
console.log(gap(competency.architect, competency.sdet));
```
