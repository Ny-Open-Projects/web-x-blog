## TST-548：笔试：笔试：性能指标去噪（中位数与百分位）

**题目**：实现 summarizePerf(samples, { trim=0.1 })。samples 为一轮性能测试的多次耗时数组（ms）。要求：① 去掉首尾各 trim 比例的极端值（先排序再切）；② 计算 min、max、median(P50)、P90、P95、mean；③ 检测离群点：超出 [Q1-1.5*IQR, Q3+1.5*IQR] 的样本索引列表（数组下标）；④ 边界：空数组返回 null；trim 在 0~0.4；百分位用线性插值。

**答**：
- 结论：先排序裁剪极端值 → 再算分位数与统计量 → 用 IQR 法则找离群点（基于原始下标）。
- 实现要点：percentile 用线性插值；trim 用 floor(n*trim) 切两端；IQR 用四分位 Q1/Q3，离群返回原始下标（需在排序时保留 index）。
- 追问钩子：为什么要去首尾而不是用均值？——性能测量常有偶发尖刺（GC、系统抖动），裁剪 + 分位数比均值更稳健，P95 更能代表用户体感。

```javascript
function percentile(sorted, p) {
  if (!sorted.length) return 0;
  const idx = (sorted.length - 1) * p, lo = Math.floor(idx), hi = Math.ceil(idx);
  return sorted[lo] + (sorted[hi] - sorted[lo]) * (idx - lo);
}
function summarizePerf(samples, { trim = 0.1 } = {}) {
  if (!samples.length) return null;
  const indexed = samples.map((v, i) => ({ v, i })).sort((a, b) => a.v - b.v);
  const k = Math.floor(indexed.length * Math.min(0.4, Math.max(0, trim)));
  const trimmed = indexed.slice(k, indexed.length - k).map(x => x.v);
  const sorted = trimmed.slice().sort((a, b) => a - b);
  const values = indexed.map(x => x.v).sort((a, b) => a - b);
  const q1 = percentile(values, 0.25), q3 = percentile(values, 0.75), iqr = q3 - q1;
  const low = q1 - 1.5 * iqr, high = q3 + 1.5 * iqr;
  const outliers = indexed.filter(x => x.v < low || x.v > high).map(x => x.i);
  return { min: sorted[0], max: sorted[sorted.length - 1],
    median: percentile(sorted, 0.5), P90: percentile(sorted, 0.9), P95: percentile(sorted, 0.95),
    mean: +(sorted.reduce((a, b) => a + b, 0) / sorted.length).toFixed(2), outliers };
}
```

**评分点**：
- 裁剪首尾 trim 比例，边界 trim 限制在 0~0.4。
- 百分位用线性插值，P50/P90/P95 正确。
- IQR 离群检测基于原始下标返回，不丢失索引。
- 空数组返回 null，sorted 不破坏原数组，边界完整。
