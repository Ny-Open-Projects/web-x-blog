## TST-835：笔试：手写一个「测试覆盖率聚合器」，合并多分片的覆盖率数据
**答**：
- 需求：实现 mergeCoverage(shards) —— 每个 shard 是 { file: { coveredLines:number[] } }，合并为全局覆盖率。
- 规则：同一文件的 coveredLines 取并集；覆盖率 = 已覆盖行数 / 总行数(totalLines 参数)。
- 边界：无分片返回 0；文件缺失时按 0 计；去重复盖行。

```javascript
function mergeCoverage(shards, totalLines) {
  const merged = new Map(); // file -> Set of covered line numbers
  for (const shard of shards) {
    for (const [file, data] of Object.entries(shard)) {
      if (!merged.has(file)) merged.set(file, new Set());
      for (const line of data.coveredLines || []) merged.get(file).add(line);
    }
  }
  let covered = 0;
  for (const lines of merged.values()) covered += lines.size;
  return {
    perFile: Object.fromEntries([...merged].map(([f, s]) => [f, s.size])),
    covered,
    total: totalLines,
    coverage: totalLines > 0 ? Number((covered / totalLines).toFixed(3)) : 0,
  };
}
console.log(mergeCoverage([
  { 'a.js': { coveredLines: [1,2,3] } },
  { 'a.js': { coveredLines: [3,4] }, 'b.js': { coveredLines: [1] } },
], 10)); // a=4行, b=1行, covered=5, coverage=0.5
```
**评分点**：
- 同一文件覆盖行取并集（Set 去重），正确合并分片。
- 覆盖率按 covered/totalLines 计算，无分片/除零返回 0。
- perFile 拆分便于定位低覆盖文件。
- 能说出「分片执行后必须聚合覆盖率，否则单看分片会漏算」这一平台化要点。
