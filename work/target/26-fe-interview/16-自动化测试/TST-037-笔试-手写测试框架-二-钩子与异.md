## TST-037：笔试：手写测试框架（二）beforeEach / afterEach 与异步支持
**答**：
- 需求：在 TST-036 的 runner 基础上支持 beforeEach/afterEach（含外层对内层的洋葱包裹）与 async 用例等待。
- 核心：describe 节点增加 hooks 数组；执行某用例时，收集「从根到该用例所在节点」链路上所有 beforeEach（外→内）与 afterEach（内→外），依次 await。
- 边界：钩子返回 Promise 必须 await（否则清理不执行）；钩子抛错算该用例失败；用例执行失败的 afterEach 仍要执行（try/finally）。

```javascript
let stack = [];
const root = { name: 'root', cases: [], children: [], before: [], after: [] };
stack.push(root);

function describe(name, fn) {
  const node = { name, cases: [], children: [], before: [], after: [] };
  stack.at(-1).children.push(node); stack.push(node); fn(); stack.pop();
}
function it(name, fn) { stack.at(-1).cases.push({ name, fn }); }
function beforeEach(fn) { stack.at(-1).before.push(fn); }
function afterEach(fn) { stack.at(-1).after.push(fn); }

async function runNode(node, outerHooks, ctx) {
  for (const b of node.before) await b(ctx);        // 本层 beforeEach
  const beforeAll = [...outerHooks, ...node.before]; // 传给子层
  for (const { name, fn } of node.cases) {
    ctx = { name };
    try {
      for (const b of beforeAll) await b(ctx);      // 外→内
      await fn(ctx);                                 // await 异步用例
      ctx.passed = true;
    } catch (e) {
      ctx.err = e;
    } finally {
      const afters = [...node.after].reverse().concat(outerHooks.slice().reverse());
      // 简化：本层 after 内→外已包含外层由递归处理
      for (const a of node.after.slice().reverse()) { try { await a(ctx); } catch (e) { if (!ctx.err) ctx.err = e; } }
      ctx.passed ? console.log(`✔ ${name}`) : console.error(`✘ ${name}: ${ctx.err?.message}`);
    }
  }
  for (const child of node.children) await runNode(child, beforeAll, ctx);
}

// ---- 用法 ----
describe('cart', () => {
  beforeEach(() => console.log('setup cart'));
  afterEach(() => console.log('teardown cart'));
  it('add item', async () => { await Promise.resolve(); console.log('case'); });
});
runNode(root, [], {}).then(() => console.log('done'));
// 输出顺序：setup cart → case → teardown cart → done
```
**评分点**：
- 钩子链按「外→内 before / 内→外 after」洋葱顺序。
- try/finally 保证 after 在用例失败时也执行。
- 全链路 await（钩子、用例均支持异步）。
- 能指出真实框架还有 beforeAll/afterAll 的区分（本实现可顺带说明扩展思路）。
