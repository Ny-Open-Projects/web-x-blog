## TST-521：万级测试用例的套件如何组织与分片

**答**：
- 结论：按「域/层级/稳定性」三维切分套件，分片执行以「文件为最小单位 + 历史时长均衡装箱」，避免跨文件拆分带来的隔离成本。
- 做法：目录按业务域组织，标记 @smoke/@critical；分片用 LPT（最长处理时间优先）贪心把文件均衡到 N 个 worker；每片独立环境、独立数据命名空间。
- 追问钩子：单个巨型测试文件比一片还慢怎么办？——先按 beforeAll 开销做拆分决策，把重资源 setup 抽成共享 fixture，或允许该文件独占一片。

```javascript
// LPT 装箱：按历史时长降序，依次放入当前最轻的分片
function shardByDuration(files, shards) {
  const sorted = [...files].sort((a, b) => b.ms - a.ms);
  const bins = Array.from({ length: shards }, () => ({ ms: 0, files: [] }));
  for (const f of sorted) {
    const target = bins.reduce((a, b) => a.ms <= b.ms ? a : b);
    target.files.push(f.name); target.ms += f.ms;
  }
  return bins.map(b => ({ count: b.files.length, ms: b.ms, files: b.files }));
}
console.log(shardByDuration([
  { name: 'a.spec', ms: 10 }, { name: 'b.spec', ms: 5 }, { name: 'c.spec', ms: 8 },
], 2));
```
