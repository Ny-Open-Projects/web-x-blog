## TST-782：笔试：实现稳定性治理的「韧性成熟度」评估器（多维度打分）

**题目**：输入维度评分数组 dims [{name, score(0~5), weight}]。成熟度 = 加权平均分（0~5）。等级：>=4 为 'optimized'，>=3 为 'managed'，>=2 为 'defined'，>=1 为 'initial'，否则 'none'。返回 {score, level, weak:最低分维度名}。权重和不一定为 1，需归一化。

**答**：
- 加权平均需按权重和归一化。
- 等级阈值边界正确。
- weak 取最低分维度，并列取先出现者。

```javascript
function maturity(dims) {
  const wsum = dims.reduce((s, d) => s + d.weight, 0) || 1;
  const score = dims.reduce((s, d) => s + d.score * d.weight, 0) / wsum;
  const level = score >= 4 ? 'optimized' : score >= 3 ? 'managed'
    : score >= 2 ? 'defined' : score >= 1 ? 'initial' : 'none';
  const weak = dims.reduce((a, b) => b.score < a.score ? b : a, dims[0] || { name: null }).name;
  return { score: +score.toFixed(2), level, weak };
}
console.log(maturity([
  { name: '监控', score: 5, weight: 2 },
  { name: '演练', score: 2, weight: 1 },
  { name: '复盘', score: 4, weight: 1 },
])); // weak:'演练'
```

**评分点**：
- 权重归一化正确
- 等级阈值边界正确
- weak 维度识别正确
- 空数组兜底
