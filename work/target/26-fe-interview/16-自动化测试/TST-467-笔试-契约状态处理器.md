## TST-467：笔试：Pact provider states 的映射执行器。
**答**：状态定义 `{stateName: setupFn}`。验证请求带 providerStates 列表：逐个执行 setup（失败即中止）；执行后调用真实 verifier；未定义状态报错（契约与实现脱节）。

```javascript
async function verifyPact(states, verifierFn, requestedStates) {
  for (const s of requestedStates) {
    if (!(s in states)) throw new Error(`契约状态未实现: ${s}（provider 与契约脱节）`);
    try { await states[s](); }
    catch (e) { throw new Error(`状态 setup 失败 [${s}]: ${e.message}`); }
  }
  return verifierFn();
}
console.log(await verifyPact(
  { 'order 1 exists': async () => { await seedOrder('1'); } },
  async () => 'verified', ['order 1 exists'])); // 'verified'

```

**评分点**：
- 状态查找与执行（未定义即报错——契约漂移信号）。
- setup 失败中止并报告哪个状态失败。
- 多状态按序执行。
- 执行后清理（可选 teardown 注册）。
