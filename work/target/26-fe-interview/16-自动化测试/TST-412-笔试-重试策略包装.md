## TST-412：笔试：实现测试用例的重试包装（指数退避+上限+最终失败上报）。
**题目**：`retryCase(fn, {tries:3, base:100})`：失败重试（退避 base*2^n），全部失败抛聚合错误（含每次失败原因）。

```javascript
async function retryCase(fn, { tries = 3, base = 100, cap = 5000 } = {}) {
  const errs = [];
  for (let i = 0; i < tries; i++) {
    try { return { ok: true, attempts: i + 1, value: await fn() }; }
    catch (e) {
      errs.push(e.message);
      if (i < tries - 1) await new Promise(r => setTimeout(r, Math.min(cap, base * 2 ** i)));
    }
  }
  throw new Error(`重试 ${tries} 次全败：\n${errs.map((m, i) => `#${i + 1} ${m}`).join('\n')}`);
}

```

**评分点**：
- 退避公式与 cap。
- 聚合错误保留全部尝试信息（诊断友好）。
- 成功即返回不重试（幂等假设说明）。
- 重试计数暴露（可观测）。
