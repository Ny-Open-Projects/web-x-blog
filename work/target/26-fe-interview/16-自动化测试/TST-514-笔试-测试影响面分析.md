## TST-514：笔试：笔试：测试影响面分析（依赖关系传播）

**题目**：给定有向依赖图 graph（key=模块，value=它依赖的模块数组，即 A:[B] 表示 A 依赖 B）与本次变更模块 changed。要求实现 affected(changed, graph)：返回因变更而需要回归的模块集合（直接依赖者 + 传递依赖者，即反向可达）。再实现 selectors(affected, testMap)：从「模块→测试用例数组」映射中挑出需运行的用例（去重）。边界：图可能为空、changed 可能不在图中、需处理循环依赖不能死循环。

**答**：
- 结论：影响面 = 变更节点的「反向传递闭包」；用反向图 + BFS/DFS + visited 集合，天然防环。
- 实现要点：先构建反向邻接表（依赖者指向依赖它的模块），BFS 收集所有可达节点；用例选择时对 affected 集合做 flatMap + Set 去重。
- 追问钩子：如何进一步缩小范围？——给依赖边加「变更类型权重」（如仅改注释不触发），并用例级记录覆盖模块，做更精确的 selection。

```javascript
function affected(changed, graph = {}) {
  const reverse = {};
  for (const [m, deps] of Object.entries(graph))
    for (const d of deps) (reverse[d] ||= []).push(m); // d 被 m 依赖
  const seen = new Set(changed), q = [...changed];
  while (q.length) {
    const cur = q.shift();
    for (const depender of reverse[cur] || []) {
      if (!seen.has(depender)) { seen.add(depender); q.push(depender); }
    }
  }
  return [...seen];
}
function selectors(mods, testMap = {}) {
  const out = new Set();
  for (const m of mods) for (const t of (testMap[m] || [])) out.add(t);
  return [...out];
}
const graph = { A: ['B'], B: ['C'], C: [] };
const mods = affected(['C'], graph);            // ['C','B','A']
console.log(mods, selectors(mods, { A: ['a.spec'], B: ['b.spec'] }));
```

**评分点**：
- 正确构建反向邻接表，找出传递依赖者（不只是直接依赖）。
- BFS/DFS 配合 visited，循环依赖不死循环。
- changed 不在图中、空图等边界不报错。
- 用例选择去重，输出可执行的运行列表。
