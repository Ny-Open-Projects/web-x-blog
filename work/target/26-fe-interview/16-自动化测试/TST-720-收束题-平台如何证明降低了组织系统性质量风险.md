## TST-720：收束题：平台化后，如何证明它真的降低了组织的系统性质量风险

**答**：
- 结论：不能只看「用例数/通过率」，要用反事实指标：逃逸缺陷率、回滚率、故障平均发现时长（MTTD）在平台化前后的变化。
- 建立对照组：未接入平台的业务线作为基线，证明差异来自平台而非业务变简单。
- 平台自身要可审计：每次发布都能追溯「哪些风险被门禁拦下」，形成风险拦截台账。
- 追问钩子：指标都变好了但线上事故没减少，说明什么问题？

```javascript
// 平台价值：反事实对比
function platformImpact(withPlatform, baseline) {
  const rate = (arr) => arr.reduce((s, x) => s + x, 0) / (arr.length || 1);
  const escapeImprovement =
    (rate(baseline.escapedBugs) - rate(withPlatform.escapedBugs)) /
    (rate(baseline.escapedBugs) || 1);
  return {
    escapedBugDrop: +(escapeImprovement * 100).toFixed(1) + '%',
    mttdDrop: +(rate(baseline.mttd) - rate(withPlatform.mttd)).toFixed(1) + 'min',
    effective: escapeImprovement > 0,
  };
}
console.log(platformImpact(
  { escapedBugs: [1, 2], mttd: [30, 40] },
  { escapedBugs: [4, 5], mttd: [90, 100] }
));
```
