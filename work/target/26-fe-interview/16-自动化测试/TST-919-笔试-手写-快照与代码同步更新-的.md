## TST-919：笔试：手写「快照与代码同步更新」的 CI 检查器：代码改了但快照没更新则拦截
**答**：
- 需求：实现 checkSync({ changedSourceFiles, changedSnapshotFiles, importGraph })，importGraph 为 { sourceFile: [snapshotFile] }。
- 规则：对每个改动的源文件，若其导入图关联的快照文件未在本次改动中，且源文件含 toMatchSnapshot 调用，则判为不同步。
- 边界：新增源文件无对应快照不算异常；快照变更但源文件没变属于「可疑更新」需警告。

```javascript
function checkSync({ changedSourceFiles, changedSnapshotFiles, importGraph }) {
  const changedSnap = new Set(changedSnapshotFiles);
  const issues = [];
  for (const src of changedSourceFiles) {
    const snaps = importGraph[src] || [];
    // 简化：假设调用方已确认 src 含 toMatchSnapshot（真实场景可 grep 源码）
    if (snaps.length && !snaps.some(s => changedSnap.has(s)))
      issues.push({ type: 'unsynced', src, expectSnap: snaps });
  }
  for (const snap of changedSnapshotFiles) {
    const owners = Object.entries(importGraph)
      .filter(([, snaps]) => snaps.includes(snap)).map(([s]) => s);
    if (!owners.some(o => changedSourceFiles.includes(o)))
      issues.push({ type: 'suspicious', snap, reason: '快照变更但无对应源文件变更' });
  }
  return issues;
}
const g = { 'Price.js': ['Price.snap'] };
console.log(checkSync({
  changedSourceFiles: ['Price.js'], changedSnapshotFiles: [], importGraph: g,
})); // [{ type:'unsynced', src:'Price.js', expectSnap:['Price.snap'] }]
```
**评分点**：
- 能识别「源码改了快照没改」的 unsynced 问题。
- 能识别「快照改了源码没改」的 suspicious 可疑更新。
- 新增源文件无快照不误报，边界正确。
- 利用 importGraph 建立源码到快照的映射，不依赖硬编码。
