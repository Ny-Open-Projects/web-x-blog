## TST-779：笔试：实现线上故障到混沌场景的「脱敏转换器」

**题目**：输入事故对象 incident {id, type, description, payload}。转换规则：description 中的手机号与邮箱替换为 '[PII]'；payload 对象递归删除键名含 'token'/'secret'/'password' 的字段（大小写不敏感）；保留 id 与 type。返回新对象，不修改原对象。

**答**：
- 正则脱敏 description 中的手机号/邮箱。
- 递归清洗 payload，按敏感键名过滤。
- 不修改原对象，保留 id/type 用于追溯。

```javascript
function sanitizeIncident(incident) {
  const desc = incident.description
    .replace(/1\d{10}/g, '[PII]')
    .replace(/[\w.+-]+@[\w-]+\.[\w.]+/g, '[PII]');
  const clean = (obj) => {
    if (Array.isArray(obj)) return obj.map(clean);
    if (obj && typeof obj === 'object') {
      const out = {};
      for (const [k, v] of Object.entries(obj)) {
        if (/token|secret|password/i.test(k)) continue;
        out[k] = clean(v);
      }
      return out;
    }
    return obj;
  };
  return { id: incident.id, type: incident.type, description: desc, payload: clean(incident.payload) };
}
console.log(sanitizeIncident({
  id: 'I1', type: 'api', description: '用户 13800138000 报错',
  payload: { accessToken: 'x', data: { password: 'p', code: 200 } },
}));
```

**评分点**：
- 手机号/邮箱脱敏正确
- 敏感键名递归删除
- 不修改原对象
- 保留 id/type 可追溯
