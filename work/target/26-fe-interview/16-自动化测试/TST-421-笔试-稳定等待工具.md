## TST-421：笔试：实现「稳定等待」工具（条件轮询 + 超时 + 干净失败信息）。
**题目**：`waitFor(fn, {timeout=5000, interval=100})`：轮询执行 fn 直到真值；超时抛错并附「最后一次执行的错误/返回值」；fn 抛错也计入轮询（瞬时异常容忍）。

```javascript
async function waitFor(fn, { timeout = 5000, interval = 100 } = {}) {
  const t0 = Date.now();
  let last;
  while (Date.now() - t0 < timeout) {
    try {
      const v = await fn();
      if (v) return v;
      last = { value: v };
    } catch (e) { last = { error: e.message }; }   // 瞬时异常容忍
    await new Promise(r => setTimeout(r, interval));
  }
  throw new Error(`waitFor 超时 ${timeout}ms；最后一次：${JSON.stringify(last)}`);
}

```

**评分点**：
- 轮询间隔与总超时控制。
- 瞬时异常容忍（不立即失败）但记录最后一次。
- 超时错误附诊断信息（最后一次错误/值）——定位效率关键。
- fn 返回真值即返回该值（不只是 true）。
