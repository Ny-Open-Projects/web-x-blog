## TST-942：笔试：手写「视觉误报根因分类器」，根据 diff 特征判断是字体/动画/数据还是真回归
**答**：
- 需求：实现 classifyFalsePositive(diff)，diff = { changedPixels, bbox, textChanged, regions, timingStable, fontStable }。
- 规则：textChanged 且 fontStable=false → 字体渲染；timingStable=false 且 bbox 面积大 → 动画/异步；regions 全在宽容区 → 环境噪声；其余 → 疑似真回归。
- 边界：多个特征命中时按优先级 字体 > 动画 > 环境 > 真回归 取首个；返回 { category, confidence, action }。

```javascript
function classifyFalsePositive(diff) {
  const { textChanged, fontStable, timingStable, regions = [], bboxArea = 0 } = diff;
  const rules = [
    [textChanged && !fontStable, 'font-render', 0.9, '统一字体环境后重跑'],
    [!timingStable && bboxArea > 10000, 'animation-async', 0.8, '禁用动画/冻结时间后重跑'],
    [regions.length && regions.every(r => r.tolerant), 'environment', 0.7, '按区域容差忽略'],
  ];
  for (const [hit, category, confidence, action] of rules)
    if (hit) return { category, confidence, action };
  return { category: 'real-regression', confidence: 0.6, action: '转人工 review' };
}
console.log(classifyFalsePositive({
  textChanged: true, fontStable: false, timingStable: true, regions: [],
}));
// { category:'font-render', confidence:0.9, action:'统一字体环境后重跑' }
```
**评分点**：
- 按优先级 字体>动画>环境>真回归 命中首个规则，逻辑正确。
- 每条规则给出 category/confidence/action 三要素。
- 用 bbox 面积区分大面积动画与小范围真实变化。
- 兜底返回 real-regression 并转人工，边界完整。
