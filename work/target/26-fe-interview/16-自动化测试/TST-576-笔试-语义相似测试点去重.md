## TST-576：笔试：笔试：语义相似测试点去重

**题目**：实现 semanticDedupe(points, threshold)。points=[{id, text, embedding:number[]}]。要求：① 余弦相似度 sim(a,b)=dot/(|a||b|)；② 用聚类去重：遍历点，若与某已保留代表点相似度 >= threshold 则归入该簇（不新增），否则作为新代表；③ 输出 {clusters:[{rep, members:[]}], kept:number}；④ 边界：embedding 为零向量时相似度记 0，空数组返回空结构，threshold 0~1。

**答**：
- 结论：单遍聚类——维护代表点列表，新点与代表算余弦相似度，超阈值归入否则新建簇。
- 实现要点：dot 与模长计算，零向量保护；阈值比较；输出簇与成员；复杂度 O(n·k)，k 为簇数。
- 追问钩子：单遍聚类对顺序敏感怎么办？——可改用层次聚类或先按相似度排序再聚类；实际中用 embedding 相似度 + 阈值通常足够，关键是阈值要经过标注数据校准。

```javascript
function cosine(a = [], b = []) {
  const dot = a.reduce((s, v, i) => s + v * (b[i] || 0), 0);
  const na = Math.hypot(...a), nb = Math.hypot(...b);
  return (na === 0 || nb === 0) ? 0 : dot / (na * nb);
}
function semanticDedupe(points = [], threshold = 0.9) {
  const clusters = [];
  for (const p of points) {
    let target = null;
    for (const c of clusters) if (cosine(p.embedding, c.rep.embedding) >= threshold) { target = c; break; }
    if (target) target.members.push(p);
    else clusters.push({ rep: p, members: [p] });
  }
  return { clusters, kept: clusters.length };
}
```

**评分点**：
- 余弦相似度计算正确，零向量保护避免 NaN。
- 单遍聚类逻辑：超阈值归入、否则新建代表。
- threshold 0~1 边界与空数组处理到位。
- 输出簇结构含 rep/members 与 kept，可断言。
