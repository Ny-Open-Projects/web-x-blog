## TST-855：端到端加密/鉴权流程如何测试（登录态/会话过期/越权）？
**答**：
- 结论：鉴权测试要覆盖「认证（你是谁）+ 授权（你能干什么）+ 会话生命周期（何时失效）」三条线，且前端不能信任任何客户端状态。
- 认证测试：错误密码、锁定策略、验证码绕过、Token 篡改与重放；登录后 Cookie 属性（HttpOnly/Secure/SameSite）正确。
- 授权测试：低权限账号直接访问高权限路由/接口（水平/垂直越权），前端路由守卫只是体验，真正的鉴权在服务端。
- 会话测试：Token 过期、主动登出后 Token 失效、并发会话踢下线；前端正确处理 401 并跳登录。
- 追问钩子：前端路由守卫做了权限判断，是否还需要服务端鉴权测试？为什么？

```javascript
// 鉴权测试：篡改 Token / 越权访问
async function authTests(request) {
  const results = {};
  // 1. 无 Token 访问受保护接口应 401
  results.noToken = (await request.get('/api/order')).status() === 401;
  // 2. 越权：普通用户访问管理员接口应 403
  results.escalation = (await request.get('/api/admin', {
    headers: { Authorization: `Bearer ${normalUserToken}` }
  })).status() === 403;
  // 3. 篡改 Token 应拒绝
  results.tampered = (await request.get('/api/order', {
    headers: { Authorization: 'Bearer ' + tamper(token) }
  })).status() === 401;
  return results; // 全 true 才通过
}
function tamper(t) { return t.slice(0, -2) + 'xx'; }
```
