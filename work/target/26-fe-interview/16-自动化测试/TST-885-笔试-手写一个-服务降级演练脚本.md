## TST-885：笔试：手写一个「服务降级演练脚本」（按故障等级切换降级 UI）
**答**：
- 需求：实现 degrade(faultLevel, renderers) —— 根据故障等级 L0(正常)/L1(部分降级)/L2(全降级) 选择对应 UI 渲染函数。
- 规则：按等级升序查找「<= 当前等级」的最高可用 renderer；无可用 renderer 用 fallback；返回渲染结果。
- 边界：非法等级抛错；renderers 为空用默认兜底；渲染函数抛错时降级到更保守等级。

```javascript
function degrade(faultLevel, renderers = {}) {
  if (![0, 1, 2].includes(faultLevel)) throw new RangeError('非法故障等级');
  const order = [0, 1, 2];
  // 从高到低找 <= faultLevel 的可用 renderer
  for (let i = faultLevel; i >= 0; i--) {
    const r = renderers[`L${i}`];
    if (!r) continue;
    try { return { level: i, html: r() }; }
    catch { continue; } // 渲染失败，降级到更低等级
  }
  return { level: 'fallback', html: renderers.fallback?.() ?? '系统繁忙，请稍后再试' };
}
console.log(degrade(2, {
  L0: () => '完整页面', L1: () => '骨架屏+缓存数据',
  fallback: () => '友好错误页',
})); // L1 骨架屏（L2 无 renderer 则降级到 L1）

// 正常态渲染完整页面
console.log(degrade(0, { L0: () => '完整页面' })); // L0
// 渲染函数抛错时自动退到保守等级
console.log(degrade(2, { L2: () => { throw new Error('boom'); }, L1: () => '兜底' })); // L1
```
**评分点**：
- 按故障等级选择「<= 当前等级」的最高可用 renderer，降级逻辑正确。
- 渲染函数抛错时自动降级到更保守等级，健壮性核心考点。
- 非法等级抛错、无 renderer 用 fallback，边界完整。
- 能点出「降级演练要验证每级 UI 真的可用，而非只切个开关」。
