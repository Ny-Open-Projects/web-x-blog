## TST-540：大规模测试该监控哪些指标、如何告警

**答**：
- 结论：四类指标——稳定性（通过率/flaky/重试率）、速度（时长P95/反馈时长）、覆盖（增量覆盖/契约覆盖）、成本（CI分钟/资源利用率）。
- 告警原则：对「趋势恶化」告警而非单点波动（如 flaky 连续 3 天上升），且告警必须可行动（指向具体负责人/用例）；避免告警疲劳。
- 追问钩子：告警太多没人理怎么办？——分级：P0 电话（核心链路全挂），P3 汇总日报（趋势类），并用「告警有效率」指标反向治理无效告警。

```javascript
// 趋势告警：连续 N 天恶化才触发，避免单点噪声
function trendAlert(series, { days = 3, direction = 'up', threshold }) {
  if (series.length < days) return false;
  const tail = series.slice(-days);
  const bad = tail.every((v, i) => i === 0 ||
    (direction === 'up' ? v > tail[i-1] : v < tail[i-1]));
  return bad && tail[tail.length - 1] > threshold;
}
console.log(trendAlert([0.1, 0.2, 0.3, 0.4], { threshold: 0.3 })); // true
console.log(trendAlert([0.4, 0.3, 0.2], { threshold: 0.3, direction: 'down' })); // true
```
