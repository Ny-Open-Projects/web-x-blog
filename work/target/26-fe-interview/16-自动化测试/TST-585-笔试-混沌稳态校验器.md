## TST-585：笔试：笔试：混沌实验稳态校验器

**题目**：实现 verifySteady(baseline, during, config)。baseline/during 为指标对象 {errorRate, p95Ms, whiteScreen, degraded}。config={ tolerance:{errorRate:0.01, p95Ms:0.2}, mustNotWhiteScreen:true, allowDegrade:false }。要求：① 对 errorRate/p95Ms 这类数值指标，during <= baseline*(1+tolerance) 才算保持；② whiteScreen 若为 true 且 mustNotWhiteScreen 则直接失败；③ degraded 若为 true 且 !allowDegrade 则失败；④ 输出 {pass, failures:[{metric, baseline, during, reason}]}；⑤ 边界：baseline 缺失字段按 0，during 缺失按 0。

**答**：
- 结论：数值指标用容差带比较，布尔指标用规则判断，聚合所有失败原因。
- 实现要点：遍历 tolerance 的数值指标做带容差比较；单独处理 whiteScreen/degraded 的规则；缺失字段默认 0。
- 追问钩子：为什么用相对容差而非绝对？——不同页面基线差异大，相对容差（如 p95 不超过基线 20%）更通用，避免一刀切阈值。

```javascript
function verifySteady(baseline = {}, during = {}, config = {}) {
  const { tolerance = {}, mustNotWhiteScreen = true, allowDegrade = false } = config;
  const failures = [];
  for (const [metric, tol] of Object.entries(tolerance)) {
    const b = baseline[metric] ?? 0, d = during[metric] ?? 0;
    if (d > b * (1 + tol)) failures.push({ metric, baseline: b, during: d, reason: '超出容差带' });
  }
  if (mustNotWhiteScreen && during.whiteScreen)
    failures.push({ metric: 'whiteScreen', during: true, reason: '出现白屏' });
  if (!allowDegrade && during.degraded)
    failures.push({ metric: 'degraded', during: true, reason: '未允许降级' });
  return { pass: failures.length === 0, failures };
}
```

**评分点**：
- 数值指标按 baseline*(1+tol) 带容差比较正确。
- whiteScreen / degraded 布尔规则判断正确。
- 缺失字段默认 0，边界安全。
- failures 含 metric/reason 可读，pass 聚合正确。
