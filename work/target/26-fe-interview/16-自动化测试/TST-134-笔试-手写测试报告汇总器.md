## TST-134：笔试：手写测试报告汇总器（多 suite JSON → Markdown PR 评论）
**答**：
- 需求：实现 `summarize(junitOrJsonReports)`——聚合多个项目的测试结果（单测/组件测试/E2E 三个 suite），输出 Markdown 表格：各 suite 通过率/耗时/flaky 数、失败用例清单（前 5 条带错误首行）、与上一次运行对比（新增失败标红）。用 GitHub Actions `actions/github-script` 贴到 PR 评论。
- 核心：统一中间格式 `{ suite, total, passed, failed, skipped, durationMs, failures: [{ name, message }] }`；对比逻辑按用例名 diff 出「新失败」（本轮挂、上轮过）——比全量失败列表更有行动价值。
- 边界：上轮数据缺失（首次运行）跳过对比；失败 message 取第一行（堆栈太长）；总数为 0 的 suite 显示 skipped。

```javascript
function summarize(current, previous = null) {
  const line = (s) =>
    `| ${s.suite} | ${s.passed}/${s.total} | ${s.failed} | ${s.skipped} | ${(s.durationMs / 1000).toFixed(1)}s |`;

  const table = [
    '| Suite | Passed | Failed | Skipped | Time |',
    '|---|---|---|---|---|',
    ...current.map(line),
  ].join('\n');

  const prevByName = new Map((previous ?? []).flatMap((s) => s.failures.map((f) => [f.name, s.suite])));
  // 新失败：本轮失败 && 上轮通过/不存在
  const newFailures = current.flatMap((s) =>
    s.failures
      .filter((f) => !prevByName.has(f.name))
      .slice(0, 5)
      .map((f) => `- **${s.suite}** ${f.name}\n  \`${(f.message || '').split('\n')[0]}\``));

  const totalFailed = current.reduce((n, s) => n + s.failed, 0);
  return [
    `## 🧪 Test Report — ${totalFailed === 0 ? '✅ all passed' : `❌ ${totalFailed} failed`}`,
    table,
    newFailures.length ? `### New failures\n${newFailures.join('\n')}` : '',
    previous ? '_compared with last run_' : '_first run, no comparison_',
  ].filter(Boolean).join('\n\n');
}
```

**评分点**：
1. 中间格式统一 + 表格聚合（多 suite 一屏读完）。
2. 「新增失败」对比逻辑正确（相对上轮的 diff，不是全量列表）。
3. 失败信息截断到首行，PR 评论可读。
4. 首次运行/空 suite 等边界不崩。
