## TST-566：笔试：笔试：AI 失败归因的置信门槛路由

**题目**：实现 attributionRouter(results, config)。results=[{failureId, category, confidence:0~1, hasEvidence:boolean, isKnownFingerprint:boolean, severity}]。config={ autoThreshold:0.85, reviewThreshold:0.6 }。路由规则：① 已知指纹（isKnownFingerprint）且 confidence>=autoThreshold → 'auto'（自动套用已知修复建议）；② 非已知但 confidence>=autoThreshold 且 hasEvidence → 'auto'；③ confidence>=reviewThreshold → 'review'（人工复核）；④ 其余 → 'escalate'（转专家）；⑤ 严重度 critical 无论置信度至少 'review'。输出每条的 route 与 reason，以及按 route 分组的统计。

**答**：
- 结论：按「已知指纹 + 置信度 + 证据 + 严重度」分级路由，先判特殊规则（critical/已知），再按阈值分档。
- 实现要点：critical 提升下限到 review；已知指纹走快速自动；有证据的高置信可自动；统计按 route 聚合。
- 追问钩子：自动采纳错了怎么兜底？——自动动作也要可回滚并留审计；对 auto 结果抽样复核，发现错判则降低对应类别的信任度。

```javascript
function attributionRouter(results = [], config = { autoThreshold: 0.85, reviewThreshold: 0.6 }) {
  const groups = {};
  const routed = results.map(r => {
    let route, reason;
    const { autoThreshold: A, reviewThreshold: R } = config;
    if (r.isKnownFingerprint && r.confidence >= A) { route = 'auto'; reason = '已知指纹高置信'; }
    else if (!r.isKnownFingerprint && r.confidence >= A && r.hasEvidence) { route = 'auto'; reason = '新类但有证据'; }
    else if (r.confidence >= R) { route = 'review'; reason = '中等置信'; }
    else { route = 'escalate'; reason = '低置信'; }
    if (r.severity === 'critical' && route === 'auto') { route = 'review'; reason = 'critical 强制复核'; }
    groups[route] = (groups[route] || 0) + 1;
    return { failureId: r.failureId, route, reason };
  });
  return { routed, stats: groups };
}
```

**评分点**：
- 已知指纹 + 高置信走 auto，新类需额外 hasEvidence。
- 阈值分档 auto/review/escalate 正确。
- critical 强制至少 review 的覆盖规则正确。
- 按 route 分组统计，输出可审计的 reason。
