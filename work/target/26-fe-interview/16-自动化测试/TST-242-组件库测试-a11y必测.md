## TST-242：组件库为什么必须内置无障碍测试？如何落地？
**答**：
- 组件库是 a11y 的「批发层」：一处修复全公司受益，一处缺陷全公司继承。
- 每个组件测试文件内置 axe 扫描 + 键盘导航断言（Tab/Enter/Escape 路径）。
- 交互组件（Dialog/Dropdown/Tab）必须有 WAI-ARIA 模式对照用例（role/aria-* 属性齐全）。
- 发布门禁：a11y 违规阻断组件版本发布，不做「下版本再说」。

```javascript
test('Dialog a11y', async () => {
  render(<Dialog open title="确认" />);
  const results = await axe();                 // axe 扫描
  expect(results.violations).toEqual([]);
  expect(screen.getByRole('dialog')).toHaveAttribute('aria-modal', 'true');
  userEvent.tab();                             // 焦点困在对话框内
  expect(screen.getByRole('button', { name: '取消' })).toBeFocused();
});
```
