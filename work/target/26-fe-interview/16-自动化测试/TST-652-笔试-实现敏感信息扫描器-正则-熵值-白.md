## TST-652：笔试：实现敏感信息扫描器（正则 + 熵值 + 白名单）

**题目**：实现 scan(text,{whitelist})。用正则识别手机号与密钥格式，用香农熵 >4.5 识别高熵疑似密钥，命中白名单的行跳过。输出 [{line,match,reason,severity}]。

**答**：
- 三类规则：已知格式正则（手机号/身份证/token）、高熵字符串（疑似密钥）、关键字上下文。
- 白名单命中即跳过，避免误报（如测试固定值）。
- 输出 {file,line,match,reason,severity}。

```javascript
function entropy(s) {
  const freq = {};
  [...s].forEach(c => freq[c] = (freq[c] || 0) + 1);
  return -Object.values(freq).reduce((h, n) => {
    const p = n / s.length; return h + p * Math.log2(p);
  }, 0);
}
function scan(text, { whitelist = [] } = {}) {
  const rules = [
    { re: /1[3-9]\d{9}/g, why: 'phone', sev: 'medium' },
    { re: /(?:sk|pk)_live_[A-Za-z0-9]{16,}/g, why: 'secret', sev: 'high' },
  ];
  const out = [];
  text.split('\n').forEach((line, i) => {
    if (whitelist.some(w => line.includes(w))) return;
    rules.forEach(r => {
      for (const m of line.matchAll(r.re))
        out.push({ line: i + 1, match: m[0], reason: r.why, severity: r.sev });
    });
    const long = line.match(/[A-Za-z0-9+/]{32,}/g) || [];
    long.forEach(s => { if (entropy(s) > 4.5)
      out.push({ line: i + 1, match: s.slice(0, 12),
        reason: 'high-entropy', severity: 'medium' }); });
  });
  return out;
}
```

**评分点**：
- 正则规则与熵值双通道
- 熵计算正确
- 白名单跳过逻辑
- 输出含定位与严重度
