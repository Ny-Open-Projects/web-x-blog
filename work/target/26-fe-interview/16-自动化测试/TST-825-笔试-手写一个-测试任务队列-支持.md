## TST-825：笔试：手写一个「测试任务队列」，支持并发上限、优先级与超时
**答**：
- 需求：实现 TaskQueue(concurrency) —— enqueue(task, priority) 入队，run() 按优先级（高优先先执行）调度，并发不超过上限。
- 规则：task 是返回 Promise 的函数；超时(duration)的任务标记为 timeout 并释放槽位。
- 边界：队列空时 resolve；所有任务完成后返回各任务结果数组（按入队顺序）。

```javascript
class TaskQueue {
  constructor(concurrency = 2) { this.concurrency = concurrency; this.q = []; this.active = 0; }
  enqueue(task, priority = 0, duration = 1000, timeout = 800) {
    return new Promise((resolve, reject) => {
      this.q.push({ task, priority, duration, timeout, resolve, reject });
      this.q.sort((a, b) => b.priority - a.priority);
      this._pump();
    });
  }
  async _pump() {
    while (this.active < this.concurrency && this.q.length) {
      const item = this.q.shift(); this.active++;
      const timer = new Promise((_, rej) => setTimeout(() => rej(new Error('timeout')), item.timeout));
      try {
        const res = await Promise.race([item.task(), timer]);
        item.resolve(res);
      } catch (e) { item.reject(e); }
      finally { this.active--; this._pump(); }
    }
  }
}
const q = new TaskQueue(2);
q.enqueue(async () => 'low', 0, 1000, 500).then(console.log).catch(e => console.log(e.message));
q.enqueue(async () => 'high', 9, 100).then(console.log);
// 高优先先跑；低优先因 500ms 超时被 reject
```
**评分点**：
- 并发上限控制（active < concurrency）正确。
- 优先级调度（高优先先出队）。
- 超时用 Promise.race 实现并释放槽位，避免「僵尸任务」占坑。
- 边界：结果按入队返回、pump 递归驱动，体现队列工程化能力。
