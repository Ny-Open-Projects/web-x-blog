## TST-751：测试用例的执行成本如何在平台层估算与优化

**答**：
- 结论：成本可优化的前提是可估算——平台记录每条用例的历史时长与资源曲线，建立成本模型，再按边际价值决定保留/拆分/降级。
- 估算用滑动窗口均值并标记趋势，新用例无历史则用同模块同类用例的基线。
- 优化手段：长用例拆短并行、慢用例降级为定时跑、高成本低价值用例下线。
- 追问钩子：估算模型显示某用例很贵，但它是唯一覆盖核心链路的用例，怎么办？

```javascript
// 成本估算：历史滑动均值 + 同类基线兜底
function estimateCost(history, moduleBaseline) {
  if (!history.length) return moduleBaseline || 0;
  const recent = history.slice(-5);
  return +(recent.reduce((s, x) => s + x, 0) / recent.length).toFixed(1);
}
function optimize(queue, costOf, budget) {
  const sorted = [...queue].sort((a, b) => costOf(b) - costOf(a));
  const keep = [], defer = [];
  let used = 0;
  for (const t of sorted) {
    const c = costOf(t);
    if (used + c <= budget) { keep.push(t); used += c; } else defer.push(t);
  }
  return { keep, defer };
}
console.log(optimize(['a', 'b', 'c'], id => ({ a: 100, b: 200, c: 300 })[id], 300));
```
