## TST-524：笔试：笔试：一致性哈希分片调度器

**题目**：实现一致性哈希分片 ConsistentShard。要求：① 构造时接受节点列表 nodes 与虚拟节点数 vnode（每个物理节点映射 vnode 个环上位置）；② get(key) 返回 key 应落到的节点（顺时针找第一个 >= hash(key) 的虚拟节点）；③ addNode(node)/removeNode(node) 后，尽量只影响相邻 key 的映射（体现一致性哈希优势）；④ 用简单的字符串 hash（如 djb2）。边界：空节点返回 null，hash 需为无符号整数。

**答**：
- 结论：哈希环 = 虚拟节点位置排序数组 + 位置到物理节点的映射；key 顺时针找到第一个虚拟节点即其归属。
- 实现要点：djb2 生成无符号 hash；add/remove 只增删对应虚拟节点并重排数组，不影响其他节点映射；get 用二分查找第一个 >= hash 的位置。
- 追问钩子：为什么需要虚拟节点？——让节点在环上分布更均匀，避免数据倾斜；节点增删时只迁移相邻区间，减少雪崩式重分配。

```javascript
function djb2(str) {
  let h = 5381;
  for (let i = 0; i < str.length; i++) h = ((h << 5) + h + str.charCodeAt(i)) >>> 0;
  return h;
}
class ConsistentShard {
  constructor(nodes = [], vnode = 100) {
    this.vnode = vnode; this.ring = []; this.nodes = new Set();
    nodes.forEach(n => this.addNode(n));
  }
  addNode(node) {
    if (this.nodes.has(node)) return;
    this.nodes.add(node);
    for (let i = 0; i < this.vnode; i++) {
      this.ring.push({ pos: djb2(`${node}#${i}`), node });
    }
    this.ring.sort((a, b) => a.pos - b.pos);
  }
  removeNode(node) {
    this.nodes.delete(node);
    this.ring = this.ring.filter(v => v.node !== node);
  }
  get(key) {
    if (!this.ring.length) return null;
    const h = djb2(key);
    const idx = this.ring.findIndex(v => v.pos >= h);
    return (idx === -1 ? this.ring[0] : this.ring[idx]).node;
  }
}
const s = new ConsistentShard(['w1', 'w2', 'w3'], 50);
console.log(s.get('test-file-a.spec'));
```

**评分点**：
- 正确构建哈希环：虚拟节点位置排序 + 物理节点映射。
- get 顺时针查找（含回环到第一个节点）逻辑正确。
- add/remove 只增删本节点虚拟节点，体现一致性（其他映射稳定）。
- hash 无符号、空节点返回 null 等边界处理到位。
