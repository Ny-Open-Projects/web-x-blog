## TST-321：测试左移在 AI/需求阶段的落点有哪些？
**答**：
- 需求阶段：验收标准（Given/When/Then）在 PRD 中结构化，直接生成测试大纲。
- 设计阶段：接口契约先写测试（契约优先），组件 API 设计用例先行。
- 开发阶段：AI 生成测试 + 开发自测清单（lint/test 本地全绿才提测）。
- 左移度量：缺陷发现阶段分布左移（需求/开发期发现占比上升）。

// PRD 结构化验收标准 → 测试大纲
