## TST-616：笔试：实现测试架构健康度雷达（5 维评分 + 趋势）

**题目**：输入 current/previous 两期指标对象（五维各 0~10 分），归一化到 0~100，计算每维趋势（±5 分为阈值），返回最弱两维作为改进重点。

**答**：
- 五维：覆盖有效性、反馈速度、稳定性、可维护性、成本效率，各归一到 0~100。
- 趋势用相邻两期差值判定上升/下降/持平，阈值 5 分。
- 输出最弱两维作为改进重点。

```javascript
const DIMS = ['effectiveness', 'speed', 'stability', 'maintain', 'cost'];
function radar(current, previous) {
  const norm = o => DIMS.map(k => Math.max(0, Math.min(100,
    Math.round((o[k] || 0) * 10))));
  const cur = norm(current), prev = norm(previous);
  const trend = cur.map((v, i) => {
    const d = v - prev[i];
    return d > 5 ? 'up' : d < -5 ? 'down' : 'flat';
  });
  const weakest = cur.map((v, i) => ({ dim: DIMS[i], v }))
    .sort((a, b) => a.v - b.v).slice(0, 2).map(x => x.dim);
  return { dims: DIMS, current: cur, trend, weakest };
}
```

**评分点**：
- 五维归一化与边界钳制正确
- 趋势判定阈值处理准确
- 最弱维度排序输出
- 结构可直接用于可视化
