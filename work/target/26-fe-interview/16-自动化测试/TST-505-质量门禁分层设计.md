## TST-505：质量门禁应该设在哪几层，如何避免形同虚设

**答**：
- 结论：门禁分三层——提交前（lint/类型/单测，快反馈）、合入前（契约/组件/受影响 E2E + 增量覆盖率）、发布前（全量回归 + 性能/安全基线 + 人工验收）。
- 避免形同虚设：① 门禁规则版本化、写进仓库；② 只允许「白名单 + 有效期」豁免，过期自动失效；③ 门禁结果可追溯到具体提交和人。
- 追问钩子：门禁太严拖慢交付被要求放宽怎么办？——用「分层分级」替代一刀切：核心链路严格、边缘模块宽松，并用数据证明严格层的缺陷逃逸确实更低。

```javascript
// 质量门禁规则：分层 + 可审计的豁免
function evaluateGate(stage, metrics, exemptions = []) {
  const RULES = {
    precommit: { lint: 0, typeError: 0 },
    premerge:  { unitPass: 1, incCoverage: 0.7, contractPass: 1 },
    prerelease:{ e2ePass: 0.99, perfBudget: 1, securityP0: 0 },
  };
  const fails = [];
  for (const [k, min] of Object.entries(RULES[stage])) {
    const v = metrics[k];
    const ok = k.endsWith('Error') || k === 'securityP0' ? v <= min : v >= min;
    if (!ok && !exemptions.some(e => e.metric === k && e.expire > Date.now()))
      fails.push(k);
  }
  return { pass: fails.length === 0, fails };
}
```
