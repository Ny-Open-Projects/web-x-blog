## TST-422：笔试：实现「关键节点快照」（从大 DOM 提取语义摘要做快照）。
**题目**：输入 DOM 树（简化：嵌套对象 {tag, attrs, text, children}），提取摘要：tag + 关键 attrs（role/data-testid）+ 文本（截断 20 字），输出规范化 JSON 做快照对比。

```javascript
function summarize(node, depth = 0) {
  if (depth > 8) return '…(deep)';
  const keep = Object.fromEntries(
    Object.entries(node.attrs || {}).filter(([k]) =>
      /^(role|data-testid|aria-[a-z]+|href)$/.test(k)).sort());
  return {
    tag: node.tag, ...keep,
    text: node.text ? node.text.trim().replace(/\s+/g, ' ').slice(0, 20) : undefined,
    children: (node.children || []).map(c => summarize(c, depth + 1)),
  };
}
const snap = summarize(dom);
// 快照对比用 JSON.stringify(snap, null, 1)

```

**评分点**：
- 只保留语义属性（role/data-testid/aria-*），丢弃样式类（防脆弱）。
- 文本截断与空白归一。
- 子树深度限制（防超大快照）。
- 输出稳定排序（attrs 字典序）。
