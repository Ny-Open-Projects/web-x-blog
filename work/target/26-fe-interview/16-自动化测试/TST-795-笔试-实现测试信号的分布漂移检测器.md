## TST-795：笔试：实现测试信号的「分布漂移」检测器（PSI 简化版）

**题目**：输入基线区间计数 base 与当前区间计数 cur（等长数组，非负整数）。计算总体稳定性指数 PSI = Σ (curPct - basePct) * ln(curPct / basePct)，其中 pct = count / total。为避免除零，count 为 0 时用 0.0001 替代。PSI < 0.1 为无漂移，< 0.2 为轻度，否则显著漂移。返回 {psi, level}。空数组返回 {psi:0, level:'none'}。

**答**：
- 各自先算总量与占比，零值用小epsilon替代。
- 逐区间累加 (curPct-basePct)*ln(curPct/basePct)。
- 阈值分级正确。

```javascript
function detectDrift(base, cur) {
  if (!base.length) return { psi: 0, level: 'none' };
  const eps = 0.0001;
  const baseTotal = base.reduce((s, x) => s + x, 0) || 1;
  const curTotal = cur.reduce((s, x) => s + x, 0) || 1;
  let psi = 0;
  for (let i = 0; i < base.length; i++) {
    const b = (base[i] || eps) / baseTotal;
    const c = (cur[i] || eps) / curTotal;
    psi += (c - b) * Math.log(c / b);
  }
  const level = psi < 0.1 ? 'none' : psi < 0.2 ? 'mild' : 'significant';
  return { psi: +psi.toFixed(4), level };
}
console.log(detectDrift([90, 10], [50, 50])); // 显著漂移
console.log(detectDrift([90, 10], [91, 9]));   // 无漂移
```

**评分点**：
- 占比计算与零值替换正确
- PSI 公式实现正确
- 阈值分级正确
- 空数组兜底
