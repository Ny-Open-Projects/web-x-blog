## TST-656：安全测试左移：代码评审阶段怎么自动发现前端安全问题？

**答**：
- 结论：把安全规则做成 AST 检查器接入 PR——比正则准，能识别别名与复杂调用链。
- 规则集：危险 sink（innerHTML/dangerouslySetInnerHTML/eval）、不安全随机（Math.random 用于 token）、缺失 rel=noopener。
- 结果分级：block（高危必改）、warn（需确认）、info（建议）。
- 追问钩子：AST 检查误报率高，团队开始无视告警，你怎么救？

```javascript
const SINKS = ['innerHTML', 'outerHTML', 'dangerouslySetInnerHTML', 'eval'];
function lintSecurity(ast, visit) {
  const hits = [];
  visit(ast, node => {
    if (node.type === 'MemberExpression' &&
        SINKS.includes(node.property?.name))
      hits.push({ line: node.loc?.start.line, rule: 'dangerous-sink',
        sev: 'block' });
    if (node.type === 'CallExpression' &&
        node.callee?.name === 'Math.random' &&
        /token|secret|nonce/i.test(node.parent?.id?.name || ''))
      hits.push({ line: node.loc?.start.line, rule: 'insecure-random',
        sev: 'block' });
  });
  return hits;
}
```
