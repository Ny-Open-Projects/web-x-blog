## TST-609：笔试：实现可测试性静态检查器

**题目**：输入源码字符串与文件名，扫描三类不可测试写法：new Date()、Math.random()、直接 localStorage。输出 [{file,line,code,msg,fix}]；含 // testability-ignore 注释的行跳过。

**答**：
- 用正则/简单词法扫描源码文本，命中规则即产出问题，不做完整 AST。
- 规则要给出行号与修复建议，便于开发者定位。
- 白名单机制：注释标记 // testability-ignore 的行跳过。

```javascript
function checkTestability(src, file) {
  const rules = [
    { re: /new Date\(/, msg: '直接 new Date，建议注入 Clock', fix: 'constructor(clock)' },
    { re: /Math\.random\(/, msg: '直接 Math.random，建议注入随机源', fix: 'constructor(random)' },
    { re: /localStorage\./, msg: '直接访问 localStorage，建议封装存储接口', fix: 'inject storage' },
  ];
  const issues = [];
  src.split('\n').forEach((line, i) => {
    if (line.includes('testability-ignore')) return;
    rules.forEach(r => {
      if (r.re.test(line)) issues.push({
        file, line: i + 1, code: line.trim(), msg: r.msg, fix: r.fix,
      });
    });
  });
  return issues;
}
```

**评分点**：
- 三类规则全部覆盖
- 行号与修复建议准确
- 白名单忽略机制生效
- 输出结构统一便于集成 CI
