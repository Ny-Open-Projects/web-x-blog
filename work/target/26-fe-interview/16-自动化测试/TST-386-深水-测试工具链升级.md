## TST-386：测试工具链（框架/断言库）升级的方法论？
**答**：
- 升级影响面：API 变更清单（框架 changelog 对照自仓用法扫描）。
- codemod 优先：官方 codemod（如 Playwright 升级脚本）批量处理机械变更。
- 并行期：新旧双依赖共存过渡（测试双跑对照），稳定后删旧。
- 升级窗口：季度固定窗口，禁止长期拖尾（双轨成本高）。

```javascript
# Playwright 升级流程
npx playwright install --with-deps   # 版本对齐
npx codemod playwright/test migration
# 双跑对照一轮 → 删旧配置
r
```
