## TST-793：面试官追问：你如何为「测试架构的终极形态」辩护

**答**：
- 结论：不存在放之四海皆准的终极形态，只有「适配业务风险与组织阶段」的当前最优解；辩护要回到约束与目标。
- 框架：用「质量目标 → 风险画像 → 架构决策 → 度量验证」四段论证，每个决策都有取舍依据与反例。
- 要承认局限：说明在什么条件下当前架构会失效以及演进方向，体现架构判断力而非教条。
- 追问钩子：如果我给你无限资源，你的架构会和现在有什么不同？

```javascript
// 架构决策辩护：目标-约束-取舍
function defend(decision) {
  return {
    goal: decision.goal,
    constraints: decision.constraints,
    tradeoff: decision.tradeoff,
    invalidation: decision.invalidationCondition, // 什么条件下失效
    evidence: decision.metrics,                   // 验证数据
  };
}
console.log(defend({
  goal: '分钟级反馈', constraints: ['人力有限'],
  tradeoff: '牺牲部分 E2E 覆盖', invalidation: '业务复杂度超阈值',
  metrics: { p95: 120 },
}));
```
