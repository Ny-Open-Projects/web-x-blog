## TST-541：前端性能指标体系（LCP/INP/CLS）如何落地到测试

**答**：
- 结论：以 Core Web Vitals 为核心——LCP（加载）、INP（交互）、CLS（视觉稳定）作为北极星，辅以 TTFB/FCP/长任务等诊断指标。
- 落地：实验室内用 Lighthouse/Playwright 在固定网络与设备下采集，做性能预算断言；线上用 RUM 采集真实用户 P75 分布，两者互补——实验室可复现、线上反映真实。
- 追问钩子：实验室数据好但线上差怎么办？——典型是设备/网络差异或长尾机型；按机型分位看 RUM 数据，针对低端机优化，并用实验室模拟对应档位。

```javascript
// 采集 Core Web Vitals 并按预算判定（示意：PerformanceObserver）
function collectVitals(observerEntries) {
  const vitals = {};
  for (const e of observerEntries) {
    if (e.name === 'largest-contentful-paint') vitals.LCP = e.startTime;
    if (e.name === 'layout-shift' && !e.hadRecentInput)
      vitals.CLS = (vitals.CLS || 0) + e.value;
    if (e.name === 'event') vitals.INP = Math.max(vitals.INP || 0, e.duration);
  }
  return vitals;
}
const budget = { LCP: 2500, CLS: 0.1, INP: 200 };
function checkBudget(v, b) {
  return Object.fromEntries(Object.entries(b).map(([k, lim]) => [k, (v[k] ?? 0) <= lim]));
}
```
