## TST-312：性能回归测试的环境要求与「环境差异导致的假回归」治理？
**答**：
- 专用 runner（独占 CPU/内存），禁与其他 job 抢占；软件版本（Node/浏览器）锁定。
- 被测服务同机或同网段，网络 RTT 稳定（内网）。
- 数据规模固定：种子数据集版本化（data-v3），数据变化即基线重测。
- 环境变更登记：任何 runner/服务配置变更后重跑基线校准。

```javascript
# 性能 job 环境锁定
perf-gate:
  runs-on: perf-runner   # 专用独占
  container: node:20.11-pinned
  env: { DATASET: 'data-v3' }
  before: '校验 runner 基线分（cinebench-like）偏差 < 3%'
r
```
