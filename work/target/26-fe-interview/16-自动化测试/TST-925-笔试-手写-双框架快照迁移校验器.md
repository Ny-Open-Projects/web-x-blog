## TST-925：笔试：手写「双框架快照迁移校验器」——对比 Jest 与 Vitest 对同一输入的序列化输出
**答**：
- 需求：实现 compareSnapshots(jestResult, vitestResult)，入参为 { key: serializedString } 映射。
- 规则：逐 key 比对，输出 { matched:[], mismatched:[{key,jest,vitest,reason}], missingInJest, missingInVitest }；reason 区分「换行差异」「转义差异」「真实值差异」。
- 边界：序列化字符串先做 trim 再比；Unicode 归一化（NFC）后比较避免编码差异假报。

```javascript
function compareSnapshots(jestResult, vitestResult) {
  const norm = s => (s || '').trim().normalize('NFC');
  const keys = new Set([...Object.keys(jestResult), ...Object.keys(vitestResult)]);
  const out = { matched: [], mismatched: [], missingInJest: [], missingInVitest: [] };
  for (const k of keys) {
    if (!(k in jestResult)) { out.missingInJest.push(k); continue; }
    if (!(k in vitestResult)) { out.missingInVitest.push(k); continue; }
    const j = norm(jestResult[k]), v = norm(vitestResult[k]);
    if (j === v) { out.matched.push(k); continue; }
    let reason = '真实值差异';
    if (j.replace(/\r\n/g, '\n') === v.replace(/\r\n/g, '\n')) reason = '换行差异';
    else if (j.replace(/\\"/g, '"') === v.replace(/\\"/g, '"')) reason = '转义差异';
    out.mismatched.push({ key: k, jest: j, vitest: v, reason });
  }
  return out;
}
console.log(compareSnapshots({ 'a 1': '3\r\n' }, { 'a 1': '3\n' }).mismatched[0].reason);
// '换行差异'
```
**评分点**：
- 逐 key 比对并正确归类 matched/mismatched/两侧缺失。
- reason 能区分换行/转义/真实值差异，帮助判断是否需要修配置。
- 比较前 trim 与 NFC 归一化，避免假报。
- 正确处理只在一侧存在的 key。
