## TST-491：笔试：从 OpenAPI 生成最小契约测试骨架。
**题目**：输入契约 `[{method, path, status, schema}]`。生成测试代码行：每契约一条 it（请求 + 断言 schema 字段存在）。输出代码字符串数组（可直接写入文件）。

```javascript
function genContractTests(contracts) {
  return contracts.map(c => {
    const path = c.path.replace(/:([a-z]+)/g, '{$1}');
    const asserts = Object.keys(c.schema).map(f =>
      `  expect(body).toHaveProperty('${f}')`).join('\n');
    return `it('${c.method} ${path} → ${c.status}', async () => {
  const res = await request.${c.method.toLowerCase()}('${path.replace(/:\w+/g, '1')}');
  expect(res.status()).toBe(${c.status});
  const body = await res.json();
${asserts}
});`;
  });
}
console.log(genContractTests([
  { method: 'GET', path: '/goods/:id', status: 200, schema: { id: 's', price: 'n' } },
])[0].split('\n').length); // 7 行骨架

```

**评分点**：
- 代码生成（模板字符串拼接）。
- 每契约一条测试（路径参数占位）。
- 断言生成基于 schema 字段（逐字段 expect）。
- 特殊字符转义（路径参数）。
