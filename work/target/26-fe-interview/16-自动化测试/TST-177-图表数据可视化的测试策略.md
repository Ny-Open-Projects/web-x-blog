## TST-177：图表/数据可视化组件怎么测试？canvas 里的内容怎么断言？
**答**：
- 核心思路：图表组件分层测——数据加工层（纯函数：原始数据 → 图表配置）、交互层（tooltip/图例点击）、渲染层（canvas 内容只能靠视觉回归或 ECharts 实例状态）。
- canvas 不可查 DOM：三类替代手段——① 实例 API 断言（`chart.getOption()` 校验 series/数据映射，ECharts 实例是可查询的）；② 视觉回归截图（基线 diff，动画冻结）；③ mock 渲染引擎，断言 setOption 收到的配置正确（层间解耦时最实用）。
- SVG 图表（D3/ECharts SVG 渲染）可以查 DOM：`getByRole('img', { name })` + aria-label、`path` 的 d 属性、文本标签 `getByText`——优先让图表库输出可访问的文本（ECharts 的 aria 配置）。
- 数据到视觉的映射测试（最有业务价值）：同环比涨跌 → 颜色映射（红涨绿跌）、负值 → Y 轴翻转、空数据 → 空态。这些用数据加工纯函数 + 实例 API 断言组合覆盖。
- 追问钩子：tooltip 内容怎么测？——E2E 里 hover 后等 tooltip 出现断言文本；单测里直接调用 `dispatchAction({ type: 'showTip' })` 后断言 getOption 或 DOM。

```javascript
// ECharts 组件测试：实例 API + 空态 + 交互
import { render, screen } from '@testing-library/react';
import TrendChart from './TrendChart';

test('数据映射正确：涨跌颜色与 series', async () => {
  const { container } = render(
    <TrendChart data={[
      { day: '周一', value: 100, delta: +10 },
      { day: '周二', value: 90, delta: -10 },
    ]} />,
  );
  const chart = TrendChart.getInstance(container);   // 组件暴露实例引用
  const option = chart.getOption();
  expect(option.series[0].data).toEqual([
    { value: 100, itemStyle: { color: '#e02020' } },  // 涨：红
    { value: 90, itemStyle: { color: '#00b578' } },   // 跌：绿
  ]);
});

test('空数据显示空态而非空白', () => {
  render(<TrendChart data={[]} />);
  expect(screen.getByText('暂无数据')).toBeInTheDocument();
});
```
