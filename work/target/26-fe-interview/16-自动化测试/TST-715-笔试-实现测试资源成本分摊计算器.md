## TST-715：笔试：实现测试资源成本分摊计算器

**题目**：输入 usage [{team, ms, storageMB}] 与单价 {msPrice, mbPrice}，以及共享成本 sharedCost。按各团队直接成本占比分摊 sharedCost（直接成本 = ms*msPrice + storageMB*mbPrice）。输出每个团队的总成本（保留 2 位小数），需处理 usage 为空时 sharedCost 归属 'platform'。

**答**：
- 先算直接成本，再按占比分摊共享成本，注意总量守恒（分摊之和 == sharedCost）。
- 浮点误差用按比例分摊后对最后一项做差额校正，保证总和精确。
- 空输入要有兜底，不能除以 0。

```javascript
function allocate(usage, price, sharedCost) {
  if (!usage.length) return { platform: +sharedCost.toFixed(2) };
  const direct = usage.map(u => ({
    team: u.team,
    cost: u.ms * price.msPrice + u.storageMB * price.mbPrice,
  }));
  const total = direct.reduce((s, d) => s + d.cost, 0) || 1;
  let allocated = 0;
  const result = {};
  direct.forEach((d, i) => {
    let share = i === direct.length - 1
      ? sharedCost - allocated
      : +(sharedCost * d.cost / total).toFixed(2);
    allocated += share;
    result[d.team] = +(d.cost + share).toFixed(2);
  });
  return result;
}
console.log(allocate(
  [{ team: 'A', ms: 1000, storageMB: 10 }, { team: 'B', ms: 1000, storageMB: 10 }],
  { msPrice: 0.001, mbPrice: 0.01 }, 10
)); // A、B 各 11
```

**评分点**：
- 直接成本计算正确
- 共享成本按比例分摊且总量守恒
- 浮点差额校正
- 空输入兜底
