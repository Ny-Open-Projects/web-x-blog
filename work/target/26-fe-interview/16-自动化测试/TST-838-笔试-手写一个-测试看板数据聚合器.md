## TST-838：笔试：手写一个「测试看板数据聚合器」，产出趋势/通过率/耗时
**答**：
- 需求：实现 aggregateDashboard(runs) —— runs 是按日期的执行记录数组，输出近 N 天的通过率趋势、平均耗时与总用例数。
- 规则：按 day 分组，通过率 = 通过用例 / 总用例；平均耗时取各次执行时长均值；按日期升序。
- 边界：某天无执行记录跳过；days 限制返回天数；结果保留合适精度。

```javascript
function aggregateDashboard(runs, days = 7) {
  const byDay = new Map();
  for (const r of runs) {
    if (!byDay.has(r.day)) byDay.set(r.day, { passed: 0, total: 0, durations: [] });
    const d = byDay.get(r.day);
    d.passed += r.passed; d.total += r.total; d.durations.push(r.durationMs);
  }
  return [...byDay.entries()]
    .sort((a, b) => a[0].localeCompare(b[0]))
    .slice(-days)
    .map(([day, d]) => ({
      day,
      passRate: d.total ? Number((d.passed / d.total).toFixed(3)) : 0,
      avgDurationMs: Math.round(d.durations.reduce((s, x) => s + x, 0) / d.durations.length),
      totalCases: d.total,
    }));
}
console.log(aggregateDashboard([
  { day: '2026-11-22', passed: 95, total: 100, durationMs: 120000 },
  { day: '2026-11-21', passed: 80, total: 100, durationMs: 110000 },
])); // 按日期升序，含通过率/平均耗时
```
**评分点**：
- 按天分组并按日期升序，slice 限制天数。
- 通过率与平均耗时计算正确，精度处理得当。
- 无记录的天跳过，边界健壮。
- 输出结构可直接驱动看板，体现「数据聚合→可视化」的工程落地。
