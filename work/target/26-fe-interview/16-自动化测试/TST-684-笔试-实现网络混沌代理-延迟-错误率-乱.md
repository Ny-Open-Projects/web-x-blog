## TST-684：笔试：实现网络混沌代理（延迟 / 错误率 / 乱序 / 断连）

**题目**：实现 createProxy(handler,rules)。返回 {request(req)}。规则含 {match,delayMs,errorRate,code,disconnect,jitter}。按顺序处理断连>错误>延迟+抖动；错误抛带 code 的 Error。

**答**：
- 规则按 URL 匹配，支持延迟、错误率、断连三类。
- 乱序用延迟抖动实现：给每个请求随机额外延迟，使响应顺序变化。
- 返回 Promise，错误用带 code 的 Error 对象，便于测试断言。

```javascript
function createProxy(handler, rules = []) {
  const find = url => rules.find(r => r.match(url));
  return {
    async request(req) {
      const r = find(req.url);
      if (!r) return handler(req);
      if (r.disconnect) throw Object.assign(new Error('offline'), { code: 'OFFLINE' });
      if (Math.random() < (r.errorRate || 0))
        throw Object.assign(new Error('chaos'), { code: r.code || 503 });
      const jitter = r.jitter ? Math.random() * r.jitter : 0;
      if (r.delayMs || jitter)
        await new Promise(res => setTimeout(res, (r.delayMs || 0) + jitter));
      return handler(req);
    },
  };
}
const p = createProxy(r => Promise.resolve(r), [
  { match: u => u.includes('/list'), delayMs: 100, jitter: 500 },
]);
```

**评分点**：
- 规则匹配与优先级正确
- 乱序通过 jitter 实现
- 错误带 code 便于断言
- 无规则时透传
