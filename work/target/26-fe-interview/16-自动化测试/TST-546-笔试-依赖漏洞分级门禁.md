## TST-546：笔试：笔试：依赖漏洞分级与门禁判定

**题目**：实现 dependencyGate(vulns, policy)。vulns=[{pkg, severity:'critical'|'high'|'medium'|'low', fixAvailable:boolean, direct:boolean}]。policy 定义各 severity 的处置：'block'（阻塞）/'warn'/'ignore'，以及 directOnly（是否只卡直接依赖）。要求：① 按 severity 查策略决定动作；② 若 fixAvailable=false 且动作为 block，降级为 warn（无法修复不硬阻塞但需记录）；③ 输出 {verdict:'block'|'warn'|'pass', items:[{pkg, action, reason}]}；④ 同包多漏洞取最严动作。

**答**：
- 结论：漏洞按严重度映射动作，结合「可修复性」与「是否直接依赖」做降级，最后聚合成整体判定。
- 实现要点：用 rank 表比较动作严格度（block>warn>ignore）；directOnly 时忽略间接依赖；fixAvailable=false 的 block 降级 warn 并注明 reason。
- 追问钩子：无法修复的漏洞一直 warn 会钝化，怎么办？——引入「风险接受」流程：owner 签署豁免并设到期日，到期必须复评或升级。

```javascript
function dependencyGate(vulns, policy) {
  const RANK = { block: 3, warn: 2, ignore: 1, pass: 0 };
  const byPkg = new Map();
  for (const v of vulns) {
    if (policy.directOnly && !v.direct) continue;
    let action = policy.severity?.[v.severity] ?? 'warn';
    let reason = `${v.severity} 依赖漏洞`;
    if (action === 'block' && !v.fixAvailable) { action = 'warn'; reason += '（暂无修复，降级警告）'; }
    const prev = byPkg.get(v.pkg);
    if (!prev || RANK[action] > RANK[prev.action]) byPkg.set(v.pkg, { pkg: v.pkg, action, reason });
  }
  const items = [...byPkg.values()];
  const worst = items.reduce((m, x) => RANK[x.action] > RANK[m] ? x.action : m, 'pass');
  return { verdict: worst, items };
}
```

**评分点**：
- 严重度→动作映射正确，directOnly 过滤间接依赖。
- fixAvailable=false 时 block 降级 warn 并记录 reason。
- 同包多漏洞取最严动作（rank 比较）。
- 整体 verdict 聚合正确，输出 items 可追溯。
