## TST-489：笔试：单次回归的执行成本核算（CI 分钟 × 单价 + 资源系数）。
**题目**：输入 `[{suite, minutes, memGB}]` 与定价 `{perMin, perGBExtra}`（超 4GB 部分加价）。输出各套件成本与总价。

```javascript
function execCost(suites, { perMin = 0.02, perGBExtra = 0.005, baseGB = 4 } = {}) {
  const rows = suites.map(s => {
    const extra = Math.max(0, s.memGB - baseGB);
    return { suite: s.suite,
      cost: +(s.minutes * (perMin + extra * perGBExtra)).toFixed(2) };
  });
  return { rows, total: +rows.reduce((s, r) => s + r.cost, 0).toFixed(2) };
}
console.log(execCost([
  { suite: 'e2e', minutes: 40, memGB: 8 },   // 40*(0.02+4*0.005)=1.6
]).total); // 1.6

```

**评分点**：
- 分段计价（基础内存内 perMin，超量加价）。
- 公式透明（可审计）。
- 总价汇总。
- 保留两位小数。
