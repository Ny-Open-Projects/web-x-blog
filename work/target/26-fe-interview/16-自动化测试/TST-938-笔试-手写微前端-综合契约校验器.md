## TST-938：笔试：手写微前端「综合契约校验器」——同时校验 props、生命周期、共享依赖三类契约
**答**：
- 需求：实现 validateMicroFrontend({ props, schema, lifecycleCalls, modules })，返回 { propsOK, lifecycleOK, depsOK, issues }。
- 规则：props 用 json-schema 风格校验 required/type；lifecycleCalls 必须含恰好一次 bootstrap 且 mount/unmount 交替；modules 中同名依赖版本数须为 1。
- 边界：任一类别失败不影响其他类别判定；issues 按类别聚合描述。

```javascript
function validateMicroFrontend({ props, schema, lifecycleCalls, modules }) {
  const issues = [];
  let propsOK = true, lifecycleOK = true, depsOK = true;
  // props
  for (const k of schema.required || []) if (!(k in props)) {
    propsOK = false; issues.push(`[props] 缺失 ${k}`);
  }
  for (const [k, t] of Object.entries(schema.properties || {}))
    if (props[k] !== undefined && typeof props[k] !== t.type) {
      propsOK = false; issues.push(`[props] ${k} 类型错`);
    }
  // lifecycle
  const boot = lifecycleCalls.filter(c => c === 'bootstrap').length;
  if (boot !== 1 || lifecycleCalls[0] !== 'bootstrap') {
    lifecycleOK = false; issues.push('[lifecycle] bootstrap 须恰好一次且在最前');
  }
  // deps
  const versions = new Map();
  for (const m of modules) {
    if (!versions.has(m.name)) versions.set(m.name, new Set());
    versions.get(m.name).add(m.version);
  }
  for (const [name, vs] of versions) if (vs.size > 1) {
    depsOK = false; issues.push(`[deps] ${name} 多版本: ${[...vs]}`);
  }
  return { propsOK, lifecycleOK, depsOK, issues };
}
console.log(validateMicroFrontend({
  props: { userId: 'u1' }, schema: { required: ['userId'], properties: { userId: { type: 'string' } } },
  lifecycleCalls: ['bootstrap', 'mount', 'unmount'],
  modules: [{ name: 'react', version: '18' }, { name: 'react', version: '17' }],
}).issues); // ['[deps] react 多版本: 18,17']
```
**评分点**：
- props/lifecycle/deps 三类契约独立判定，互不干扰。
- lifecycle 校验 bootstrap 恰好一次且在最前。
- deps 正确检测同名多版本。
- issues 按类别聚合，可直接输出 CI 报告。
