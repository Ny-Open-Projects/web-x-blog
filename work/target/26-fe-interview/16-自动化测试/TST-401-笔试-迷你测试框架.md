## TST-401：笔试：手写一个迷你测试框架（describe/it/expect + 失败收集）。
**题目**：实现 `describe/it`（支持嵌套分组）与 `expect(x).toBe/toEqual`，执行后输出每组通过/失败统计与失败详情，进程退出码非 0 当有失败。

```javascript
const results = { pass: 0, fail: 0, failures: [] };
const stack = [];
export function describe(name, fn) { stack.push(name); fn(); stack.pop(); }
export function it(name, fn) {
  try { fn(); results.pass++; console.log(`✓ ${[...stack, name].join(' > ')}`); }
  catch (e) {
    results.fail++;
    results.failures.push({ title: [...stack, name].join(' > '), msg: e.message });
    console.log(`✗ ${[...stack, name].join(' > ')}：${e.message}`);
  }
}
export function expect(actual) {
  return {
    toBe(exp) { if (actual !== exp) throw new Error(`期望 ${exp} 实得 ${actual}`); },
    toEqual(exp) { if (JSON.stringify(actual) !== JSON.stringify(exp))
      throw new Error(`深比较失败：期望 ${JSON.stringify(exp)} 实得 ${JSON.stringify(actual)}`); },
  };
}
process.on('exit', () => { if (results.fail) process.exitCode = 1; });

```

**评分点**：
- 嵌套 describe 用栈式上下文（路径拼接标题）。
- 失败不中断（收集继续跑完），失败详情含期望/实际。
- toEqual 深比较（JSON 或递归）。
- 退出码语义正确（CI 集成关键）。
