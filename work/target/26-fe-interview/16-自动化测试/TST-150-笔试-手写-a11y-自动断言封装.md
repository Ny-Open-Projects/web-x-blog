## TST-150：笔试：手写 a11y 自动断言封装（axe-core 集成 + 级别过滤）
**答**：
- 需求：实现 `expectNoA11yViolations(container, options)`——跑 axe-core 扫描，按严重级别（critical/serious 阻断，moderate 告警）过滤，输出可读的违规报告（规则 id、影响元素、修复建议链接），并支持豁免清单（存量问题渐进治理）。
- 设计要点：① axe 在 jsdom 可跑但部分规则需要样式（`color-contrast` 在 jsdom 不可靠，通常禁用）；② 豁免按「规则 id + 选择器」维度，全局豁免会被滥用，要打日志；③ 错误信息包含每条违规的节点 selector，否则报错没法修。
- 与 E2E 结合：axe 也可在 Playwright 里跑（@axe-core/playwright），封装同一个 options 结构复用。

```jsx
// test-utils/a11y.ts
import { axe } from 'jest-axe';

const EXEMPT = [
  { rule: 'color-contrast' },                    // jsdom 不可靠，全局禁用
  { rule: 'aria-required-parent', selector: '.legacy-grid' }, // 存量豁免
];

export async function expectNoA11yViolations(container, { level = ['critical', 'serious'] } = {}) {
  const { violations } = await axe(container, {
    rules: { 'color-contrast': { enabled: false } },
  });

  const blocking = violations.filter((v) =>
    level.includes(v.impact) &&
    !EXEMPT.some((e) => e.rule === v.id &&
      (!e.selector || v.nodes.every((n) => n.target.some((t) => String(t).includes(e.selector))))
    ));

  if (blocking.length) {
    const detail = blocking.map((v) =>
      `[${v.impact}] ${v.id}: ${v.help}\n  nodes: ${v.nodes.map((n) => n.target.join(' ')).join(', ')}\n  fix: ${v.helpUrl}`
    ).join('\n');
    throw new Error(`a11y violations (${blocking.length}):\n${detail}`);
  }
  // 被豁免的打日志，防止豁免清单无限膨胀
  const waived = violations.filter((v) => !blocking.includes(v) && level.includes(v.impact));
  if (waived.length) console.warn('[a11y] waived:', waived.map((v) => v.id));
}

// ---- 用法 ----
test('表单无 critical 级 a11y 问题', async () => {
  const { container } = render(<LoginForm />);
  await expectNoA11yViolations(container);
  // 输出示例：
  // [serious] label: Form elements must have labels
  //   nodes: input[name="phone"]
});
```

**评分点**：
1. 按影响级别分级阻断（critical/serious fail，moderate 告警）——a11y 治理的正确姿势。
2. 豁免是「规则+选择器」粒度且有日志，不是一刀切。
3. 违规报告含节点 selector 与修复链接（可行动）。
4. jsdom 下禁用 color-contrast 等不可靠规则的常识。
