## TST-350：移动端 H5 的专项测试（触控/键盘/分享）有哪些？
**答**：
- 触控：点击热区（≥44px）、滑动惯性、双击缩放禁用。
- 软键盘：输入框聚焦时页面滚动/遮挡处理（键盘弹起视口变化）。
- 分享卡片：分享链接 schema（openid 通道）与落地页还原。
- 弱网/离线：骨架屏与缓存页行为（专项用例 + CDP 节流）。

```javascript
test('软键盘不遮挡输入框', async ({ page }) => {
  await page.goto('/login');
  await page.getByRole('textbox').tap();
  await page.evaluate(() => window.scrollTo(0, document.body.scrollHeight)); // 模拟键盘推起
  await expect(page.getByRole('button', { name: '登录' })).toBeInViewport();
});
```
