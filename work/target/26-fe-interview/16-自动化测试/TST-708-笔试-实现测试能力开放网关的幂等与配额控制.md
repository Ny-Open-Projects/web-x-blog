## TST-708：笔试：实现测试能力开放网关的幂等与配额控制

**题目**：实现 TokenBucket 类，支持 `allow(key, now)` 与 `acquire(key, idempotencyKey, now)`。令牌桶容量 capacity、补充速率 rate（个/秒）。acquire 需保证同一 idempotencyKey 在窗口内只扣一次令牌（返回首次结果），配额不足返回 false。now 为毫秒时间戳。

**答**：
- 幂等用 Map 记录 idempotencyKey → 首次结果，避免重试重复扣费。
- 令牌按时间差补充，上限封顶 capacity，用懒计算而非定时器。
- 多 key 相互隔离，避免一个业务打满影响其他业务。

```javascript
class TokenBucket {
  constructor(capacity, rate) {
    this.capacity = capacity; this.rate = rate;
    this.buckets = new Map(); this.idem = new Map();
  }
  _bucket(key, now) {
    if (!this.buckets.has(key)) this.buckets.set(key, { tokens: this.capacity, ts: now });
    const b = this.buckets.get(key);
    b.tokens = Math.min(this.capacity, b.tokens + (now - b.ts) / 1000 * this.rate);
    b.ts = now;
    return b;
  }
  allow(key, now) { return this._bucket(key, now).tokens >= 1; }
  acquire(key, idemKey, now) {
    if (this.idem.has(idemKey)) return this.idem.get(idemKey);
    const b = this._bucket(key, now);
    const ok = b.tokens >= 1;
    if (ok) b.tokens -= 1;
    this.idem.set(idemKey, ok);
    return ok;
  }
}
const gw = new TokenBucket(2, 0.1);
console.log(gw.acquire('teamA', 'req-1', 0));  // true
console.log(gw.acquire('teamA', 'req-1', 10)); // true（幂等，不重复扣）
```

**评分点**：
- 令牌按时间懒补充且封顶
- 幂等键保证只扣一次
- 多 key 隔离
- now 以毫秒正确换算速率
