## TST-985：笔试：手写「测试资源弹性调度器」——按任务优先级与资源配额动态分配 worker
**答**：
- 需求：实现 schedule(tasks, totalWorkers)，task = { id, priority, duration, workersNeeded }。
- 规则：按 priority 降序、duration 升序排队；逐个分配 worker，workersNeeded 超过剩余则跳过（进入等待队列）；返回 { running, waiting, utilization }。
- 边界：workersNeeded<=0 视为 1；同优先级短任务优先（SJF）；utilization = 已分配/总数。

```javascript
function schedule(tasks, totalWorkers) {
  const sorted = [...tasks].sort((a, b) =>
    b.priority - a.priority || a.duration - b.duration);
  let remaining = totalWorkers, used = 0;
  const running = [], waiting = [];
  for (const t of sorted) {
    const need = Math.max(1, t.workersNeeded || 1);
    if (need <= remaining) {
      remaining -= need; used += need; running.push({ ...t, assigned: need });
    } else waiting.push(t.id);
  }
  return { running, waiting, utilization: +(used / totalWorkers).toFixed(2) };
}
console.log(schedule([
  { id: 'a', priority: 1, duration: 10, workersNeeded: 2 },
  { id: 'b', priority: 2, duration: 5, workersNeeded: 3 },
  { id: 'c', priority: 1, duration: 2, workersNeeded: 2 },
], 5)); // running:['b','c']（优先级高的先）、a 等待
```
**评分点**：
- 按 priority 降序、duration 升序（SJF）排序正确。
- workersNeeded 超剩余则进入 waiting，不强行分配。
- workersNeeded<=0 归一化为 1。
- utilization 计算正确，返回 running/waiting 可编排。
