## TST-527：海量测试结果如何存储与查询

**答**：
- 结论：冷热分层——近期/明细结果进时序库或 OLAP（ClickHouse/ES），聚合报表进关系库；原始产物（trace/视频）进对象存储，只存指针。
- 做法：结果结构化为「运行维度 + 用例维度」两张表，按 runId/time 分区；查询走预聚合（通过率、flaky 趋势）避免全表扫描；设置 TTL 归档冷数据。
- 追问钩子：要查「某用例近 30 天的失败趋势」怎么高效？——按用例名 + 时间建索引/物化视图，预先按天聚合，查询 O(30) 而非扫描百万行。

```javascript
// 明细结果按天预聚合，供趋势查询
function dailyAggregate(results) { // results: [{name, status, ts}]
  const days = {};
  for (const r of results) {
    const d = new Date(r.ts).toISOString().slice(0, 10);
    const a = (days[r.name] ||= {})[d] ||= { total: 0, fail: 0 };
    a.total++; if (r.status === 'fail') a.fail++;
  }
  return Object.fromEntries(Object.entries(days).map(([name, byDay]) =>
    [name, Object.fromEntries(Object.entries(byDay).map(([d, v]) =>
      [d, +(v.fail / v.total).toFixed(3)]))]));
}
```
