## TST-413：笔试：实现 diff 输出器（对象差异的可读呈现）。
**题目**：`diffOutput(expected, actual)`：顶层不同 → 逐键比较输出 `- key: expected / + key: actual`；嵌套递归；数组按位。输出行数上限 10（防刷屏）。

```javascript
function diff(expected, actual, path = '', out = []) {
  if (out.length >= 10) return out;
  if (JSON.stringify(expected) === JSON.stringify(actual)) return out;
  if (typeof expected !== 'object' || typeof actual !== 'object' || !expected || !actual) {
    out.push(`~ ${path || '(root)'}: -${JSON.stringify(expected)} +${JSON.stringify(actual)}`);
    return out;
  }
  const keys = new Set([...Object.keys(expected), ...Object.keys(actual)]);
  for (const k of keys) {
    if (out.length >= 10) { out.push('…(截断)'); break; }
    const p = `${path}.${k}`;
    if (!(k in expected)) out.push(`+ ${p}: ${JSON.stringify(actual[k])}`);
    else if (!(k in actual)) out.push(`- ${p}: ${JSON.stringify(expected[k])}`);
    else diff(expected[k], actual[k], p, out);
  }
  return out;
}
console.log(diff({ a: { b: 1 }, c: 2, d: 3 }, { a: { b: 2 }, c: 3 }));
// ~ a.b: -1 +2；~ c: -2 +3；- d: 3

```

**评分点**：
- 递归 diff，路径前缀（a.b[0].c）。
- 只有 expected 有 → `-`；只有 actual 有 → `+`；都有的值不同 → `~`。
- 输出限流（前 10 条 + 提示）。
- 原始值用 JSON 展示。
