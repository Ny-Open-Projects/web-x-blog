## TST-829：笔试：手写一个「用例检索/标签过滤」引擎，支持多维组合条件
**答**：
- 需求：实现 filterTests(tests, query) —— query 含 tags(全部匹配)、layer、keyword(名称模糊)、owner。
- 规则：多条件为 AND；tags 内为「全部包含」；keyword 大小写不敏感的子串匹配。
- 边界：query 为空返回全部；无匹配返回空数组；不修改原数组。

```javascript
function filterTests(tests, query = {}) {
  const { tags = [], layer, keyword, owner } = query;
  const kw = keyword ? keyword.toLowerCase() : null;
  return tests.filter(t => {
    if (tags.length && !tags.every(tag => t.tags.includes(tag))) return false;
    if (layer && t.layer !== layer) return false;
    if (owner && t.owner !== owner) return false;
    if (kw && !t.name.toLowerCase().includes(kw)) return false;
    return true;
  });
}
const tests = [
  { name: '支付下单', tags: ['core','smoke'], layer: 'e2e', owner: 'a' },
  { name: '头像上传', tags: ['ui'], layer: 'unit', owner: 'b' },
];
console.log(filterTests(tests, { tags: ['core'], layer: 'e2e', keyword: '支付' }));
console.log(filterTests(tests, {}).length); // 2

// 无匹配返回空数组
console.log(filterTests(tests, { owner: 'none' }).length); // 0
// 组合条件为 AND：core + unit 同时满足才命中
console.log(filterTests(tests, { tags: ['core'], layer: 'unit' }).length); // 0
```
**评分点**：
- 多条件 AND 组合正确，tags 内「全部包含」语义正确。
- keyword 大小写不敏感子串匹配。
- 空 query 返回全部，无匹配返回空数组。
- 不修改原数组（纯函数），体现可复用资产的设计。
