## TST-420：笔试：测试套件间依赖的拓扑执行（含环检测）。
**题目**：套件 `[{name, deps[]}]`。输出执行层级（同层可并行）；环依赖报环路径；孤套件（无依赖）在第一层。

```javascript
function layerOrder(suites) {
  const indeg = new Map(suites.map(s => [s.name, (s.deps || []).length]));
  const dependents = new Map();
  for (const s of suites) for (const d of s.deps || []) {
    if (!dependents.has(d)) dependents.set(d, []);
    dependents.get(d).push(s.name);
  }
  let cur = [...indeg].filter(([, v]) => v === 0).map(([k]) => k);
  const layers = [];
  while (cur.length) {
    layers.push(cur);
    const next = [];
    for (const n of cur) for (const d of dependents.get(n) || []) {
      indeg.set(d, indeg.get(d) - 1);
      if (indeg.get(d) === 0) next.push(d);
    }
    cur = next;
  }
  if (layers.flat().length !== suites.length)
    throw new Error(`环依赖：${suites.filter(s => indeg.get(s.name) > 0).map(s => s.name)}`);
  return layers;
}
console.log(layerOrder([
  { name: 'auth', deps: [] }, { name: 'cart', deps: ['auth'] }, { name: 'pay', deps: ['cart', 'auth'] },
])); // [['auth'], ['cart'], ['pay']]

```

**评分点**：
- 分层拓扑（Kahn 分层版本）。
- 环检测输出环成员。
- 同层并行语义说明。
- 空套件列表返回空层级。
