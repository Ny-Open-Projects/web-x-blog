## TST-891：笔试：手写一个「故障注入的开关与回滚控制器」（feature flag + kill switch）
**答**：
- 需求：实现 ChaosController() —— 提供 enable/disable/getState/inject 方法，控制故障注入的开关与状态，支持自动过期回滚。
- 规则：enable(ttlMs) 开启并设置到期时间；到期后 inject 自动返回 false（回滚）；disable 立即停止；inject 受开关控制。
- 边界：重复 enable 重置 ttl；ttlMs<=0 表示永不过期；inject 返回是否应注入故障。

```javascript
function ChaosController() {
  let enabled = false, expiresAt = 0;
  return {
    enable(ttlMs = 0) {
      enabled = true;
      expiresAt = ttlMs > 0 ? Date.now() + ttlMs : Infinity;
      return this;
    },
    disable() { enabled = false; expiresAt = 0; return this; },
    getState() {
      return { enabled, expired: Date.now() > expiresAt,
        remainingMs: expiresAt === Infinity ? -1 : Math.max(0, expiresAt - Date.now()) };
    },
    inject() {
      if (!enabled) return false;
      if (Date.now() > expiresAt) { enabled = false; return false; } // 自动回滚
      return true;
    },
  };
}
const c = ChaosController().enable(1000);
console.log(c.inject(), c.getState());
// ttl 到期后 c.inject() -> false，自动回滚，防止演练失控
```
**评分点**：
- enable/disable/inject/getState 接口完整，开关控制清晰。
- TTL 到期自动回滚（inject 返回 false），防止演练失控是核心考点。
- 重复 enable 重置 ttl、ttl<=0 永不过期，边界正确。
- 能点出「kill switch 是故障演练的安全底线」。
