## TST-819：笔试：手写一个「质量门禁决策引擎」，把多维信号收敛成 go/no-go
**答**：
- 需求：实现 qualityGate(signals, policy) —— signals 含 coverage、flakyRate、e2ePass、perfDelta，输出是否可发布。
- 规则：任一 blocker 不达标即 no-go；warner 不达标给 warning 但仍可发布；policy 定义各阈值与等级。
- 边界：缺失信号视为不达标（fail-closed）；紧急模式(bypass)下 blocker 降级为 warning 但记录 bypass 原因。

```javascript
function qualityGate(signals, policy, opts = {}) {
  const violations = [];
  for (const [key, rule] of Object.entries(policy)) {
    const v = signals[key];
    if (v === undefined) { violations.push({ key, level: rule.level, reason: '信号缺失' }); continue; }
    const passed = rule.compare === '>=' ? v >= rule.value : v <= rule.value;
    if (!passed) violations.push({ key, level: rule.level, reason: `实际 ${v}` });
  }
  const blockers = violations.filter(v => v.level === 'blocker');
  const warnings = violations.filter(v => v.level === 'warner');
  if (opts.bypass && blockers.length) {
    return { go: true, warnings: [...warnings, ...blockers],
      bypass: true, reason: opts.reason || '未说明' };
  }
  return { go: blockers.length === 0, warnings, bypass: false };
}
const policy = {
  coverage: { level: 'blocker', compare: '>=', value: 0.7 },
  e2ePass: { level: 'blocker', compare: '>=', value: 1 },
  flakyRate: { level: 'warner', compare: '<=', value: 0.01 },
  perfDelta: { level: 'warner', compare: '<=', value: 0.05 },
};
console.log(qualityGate({ coverage: 0.68, e2ePass: 1, flakyRate: 0.02 }, policy));
// { go:false, warnings:[flakyRate], bypass:false }
```
**评分点**：
- fail-closed：缺失信号视为不达标，不用默认值蒙混过关。
- blocker 与 warner 分级处理，任一 blocker 失败即 no-go。
- bypass 机制：紧急模式降级并记录原因，可审计。
- 比较方向（>= / <=）由 policy 驱动，而非硬编码，体现可扩展性。
