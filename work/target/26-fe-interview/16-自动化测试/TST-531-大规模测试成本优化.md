## TST-531：大规模测试的成本优化有哪些抓手

**答**：
- 结论：成本 = 计算资源 × 时长 + 人力。优化从「少跑、快跑、错峰跑、按价值跑」四方向入手。
- 抓手：① 影响面选择 + 冒烟子集减少用例数；② 分片并行 + 缓存缩短时长；③ 夜间/闲置资源错峰；④ 按风险分级——低风险降频/ Sampling；⑤ 失败早停（fail-fast）减少无效执行。
- 追问钩子：省钱会不会降低质量？——用「每元拦截的缺陷数」做效率指标，证明优化后单位成本的质量产出反而提升，而非单纯砍覆盖。

```javascript
// 成本模拟：对比全量 vs 影响面选择的成本与拦截率
function costCompare({ total, perCaseMs, machineCostPerMs, fullRate, selectedRate, selectedPct }) {
  const full = { cases: total, ms: total * perCaseMs, cost: total * perCaseMs * machineCostPerMs, caught: total * fullRate };
  const selN = Math.round(total * selectedPct);
  const sel = { cases: selN, ms: selN * perCaseMs, cost: selN * perCaseMs * machineCostPerMs, caught: selN * selectedRate };
  return {
    savedCost: +(full.cost - sel.cost).toFixed(2),
    efficiency: +(sel.caught / sel.cost / (full.caught / full.cost)).toFixed(2), // 单位成本拦截效率比
  };
}
```
