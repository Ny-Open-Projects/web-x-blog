## TST-245：组件库的「类型契约」与「文档示例」如何纳入测试？
**答**：
- 类型测试：@ts-expect-error 断言错误用法编译失败（props 类型契约）。
- 文档示例可执行化：README/文档站示例代码直接作为测试源（doc tests），过期即红。
- Props 表格自动校验：文档中 props 表与实际 TS 类型比对（脚本生成 diff）。
- 变更 API 必须同步文档——CI 检查变更文件关联文档更新。

```javascript
// 类型契约测试
import { expectTypeOf } from 'expect-type';
expectTypeOf(<Button type="primary" />).toBeCallable();
// @ts-expect-error: 不存在 size="huge"
<Button size="huge" />;
r
```
