## TST-632：笔试：实现测试数据血缘图（生产 / 消费 / 影响面查询）

**题目**：实现 Lineage：link(from,to) 建有向边；impact(dataId) 返回该数据可到达的所有节点（BFS、防环）；upstream(caseId) 返回所有直接指向该用例的数据集。

**答**：
- 用邻接表存有向图，produce 建数据集→用例边，consume 建用例→数据集边。
- 影响面用 BFS 从数据集出发遍历可达节点，防止环导致死循环。
- 提供反向查询：某用例依赖哪些数据集。

```javascript
class Lineage {
  constructor() { this.g = new Map(); }
  link(from, to) {
    if (!this.g.has(from)) this.g.set(from, new Set());
    this.g.get(from).add(to);
  }
  impact(dataId) {
    const seen = new Set(), q = [dataId];
    while (q.length) {
      const n = q.shift();
      for (const m of this.g.get(n) || []) {
        if (!seen.has(m)) { seen.add(m); q.push(m); }
      }
    }
    return [...seen];
  }
  upstream(caseId) {
    return [...this.g].filter(([, tos]) => tos.has(caseId)).map(([k]) => k);
  }
}
const l = new Lineage(); l.link('users', 'case-login');
console.log(l.upstream('case-login')); // ['users']
```

**评分点**：
- 邻接表结构正确
- BFS 影响面遍历且防环
- 反向查询实现
- API 语义清晰可组合
