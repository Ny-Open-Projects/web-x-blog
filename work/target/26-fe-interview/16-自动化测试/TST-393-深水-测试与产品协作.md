## TST-393：产品经理在测试体系中的角色（不只是提需求）？
**答**：
- AC 共写：产品写验收标准（结构化），技术转化为自动化。
- 风险输入：产品标注业务风险等级（影响测试投入分配）。
- 验收执行：低风险 AC 由产品在预发自助验证（平台化触发）。
- 反馈闭环：产品参与缺陷逃逸复盘（需求歧义归因）。

```javascript
const pmRole = {
  ac: '结构化验收标准（Gherkin）',
  risk: 'bizImpact 标注 → 驱动测试分层',
  verify: '预发自助验证低风险 AC',
  retro: '逃逸缺陷的需求侧归因',
};
```
