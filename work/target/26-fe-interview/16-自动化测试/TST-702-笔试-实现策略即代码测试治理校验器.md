## TST-702：笔试：实现「策略即代码」的测试治理校验器

**题目**：输入用例数组 [{name, tags, assertions, coverage}] 与策略规则 [{id, when, assert}]，其中 when/assert 为安全字符串表达式（如 `tags.includes('P0')`、`coverage >= 0.8`）。逐条评估用例并返回违反项。禁止使用 eval/new Function。

**答**：
- 策略必须是声明式、可审计的，禁止任意代码执行，用受限表达式解析器而非 eval。
- 每条用例收集所有违规而非遇到第一条就停，便于一次修复。
- 输出保留违规规则 id 与用例名，可追溯到团队。

```javascript
// 极简受限表达式求值器：只支持 field op value 形式
function evalRule(rule, ctx) {
  const m = rule.when.match(/^(\w+)\s*(>=|<=|===|includes)\s*(.+)$/);
  if (!m) return false;
  const [, field, op, raw] = m;
  const left = ctx[field];
  const right = raw.startsWith("'") ? raw.slice(1, -1) : Number(raw);
  if (op === 'includes') return Array.isArray(left) && left.includes(right);
  if (op === '>=') return left >= right;
  if (op === '<=') return left <= right;
  return left === right;
}
function lint(cases, rules) {
  const violations = [];
  for (const c of cases) for (const r of rules) {
    if (!evalRule(r.when, c)) violations.push({ case: c.name, rule: r.id });
  }
  return violations;
}
console.log(lint(
  [{ name: 't1', tags: [], coverage: 0.7 }],
  [{ id: 'TAG', when: "tags.includes('P0')" }]
)); // [{case:'t1',rule:'TAG'}]
```

**评分点**：
- 禁止 eval/new Function，使用受限解析
- 收集全部违规而非短路
- 表达式字段/操作符解析正确
- 输出可追溯到用例与规则
