## TST-990：笔试：手写「基于多维信号的门禁动态分级器」，输出等级与对应放行策略
**答**：
- 需求：实现 gradeGate(signals, policy)，signals = { changeScope, criticalPath, passRate, flakeRate, diffCoverage, promoFreeze }，policy 定义各阈值。
- 规则：按加权风险分分级（high/medium/low）；high 必须人工审批+全量回归，medium 需增量覆盖达标，low 自动放行；promoFreeze=true 强制至少 medium。
- 边界：信号缺失按保守值处理（passRate 缺失记 0）；返回 { level, actions, score }。

```javascript
function gradeGate(s, p = {}) {
  const th = { high: 0.6, medium: 0.3, ...p };
  const score =
    (s.changeScope ?? 0.5) * 0.2 +
    (s.criticalPath ? 0.3 : 0) +
    (1 - (s.passRate ?? 0)) * 0.2 +
    (s.flakeRate ?? 0) * 0.1 +
    (1 - (s.diffCoverage ?? 0)) * 0.1 +
    (s.promoFreeze ? 0.3 : 0);
  let level = score >= th.high ? 'high' : score >= th.medium ? 'medium' : 'low';
  if (s.promoFreeze && level === 'low') level = 'medium'; // 封版期强制升级
  const actions = {
    high: ['人工审批', '全量回归', '安全扫描'],
    medium: ['增量覆盖率达标校验'],
    low: ['自动放行'],
  }[level];
  return { level, actions, score: +score.toFixed(2) };
}
console.log(gradeGate({ changeScope: 0.9, criticalPath: true, passRate: 1,
  flakeRate: 0, diffCoverage: 0.9, promoFreeze: true }).level); // 'high'
```
**评分点**：
- 加权风险分分级正确，criticalPath/promoFreeze 权重体现。
- high/medium/low 对应放行策略准确。
- promoFreeze 强制至少 medium，边界规则正确。
- 信号缺失按保守值（passRate 缺失记 0），返回 score 可解释。
