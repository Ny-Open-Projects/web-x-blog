## TST-896：混沌测试文化：如何在团队推动「主动找茬」而不引发恐慌？
**答**：
- 结论：推动混沌文化要靠「机制化 + 心理安全 + 小步试探」——把演练变成常规、可控、无指责的活动，而不是「搞破坏」的英雄主义。
- 机制化：固定演练日、明确范围与回滚、提前通知，让它成为流程而非个人行为。
- 心理安全：无指责复盘（blameless），强调「发现问题的是英雄，不是制造问题的人」。
- 小步试探：从测试环境、低流量、内部用户开始，积累成功案例后再扩大。
- 追问钩子：一次演练误影响真实用户引发投诉，你如何修复信任并继续推进？

```javascript
// 混沌文化健康度：无指责 + 机制化
const culture = {
  blameless: true,              // 无指责复盘
  regularDrill: '每两周一次',    // 机制化
  scope: '测试环境 -> 内部灰度 -> 小流量', // 小步试探
  heroMetric: '发现隐患数',      // 奖励发现而非"没出事"
};
function launchDrill() {
  return {
    notify: '提前 1 天通知相关方',
    killSwitch: '可秒级停止',
    review: 'blameless 复盘，产出改进项',
  };
}
console.log(culture.heroMetric, launchDrill().killSwitch);
```
