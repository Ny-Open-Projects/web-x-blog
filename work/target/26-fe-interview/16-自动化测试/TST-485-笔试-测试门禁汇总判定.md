## TST-485：笔试：多门禁结果的汇总判定（任一阻塞即 fail）。
**题目**：门禁 `[{name, level: 'blocking'|'advisory', passed}]`。汇总：blocking 有未过 → fail（列出）；否则 pass（advisory 未过列警告）。输出 `{verdict, blockers, warnings}`。

```javascript
function gateSummary(gates) {
  const blockers = gates.filter(g => g.level === 'blocking' && !g.passed).map(g => g.name);
  const warnings = gates.filter(g => g.level === 'advisory' && !g.passed).map(g => g.name);
  return { verdict: blockers.length ? 'fail' : 'pass',
    blockers, warnings };
}
console.log(gateSummary([
  { name: 'unit', level: 'blocking', passed: true },
  { name: 'visual', level: 'advisory', passed: false },
])); // pass + warning visual

```

**评分点**：
- 分级语义（blocking 决定成败）。
- blockers/warnings 分别收集。
- verdict 二值（CI 退出码对接）。
- 空门禁返回 pass（说明语义）。
