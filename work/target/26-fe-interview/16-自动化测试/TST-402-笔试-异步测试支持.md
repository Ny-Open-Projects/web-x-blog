## TST-402：笔试：给迷你测试框架加异步支持（await it + 超时）。
**答**：it 支持返回 promise：等待完成，超时（默认 5s）判失败并继续后续用例（不能卡死）。describe 改为异步遍历。

```javascript
async function runIt(name, fn) {
  const timeout = (ms) => new Promise((_, rej) => setTimeout(() => rej(new Error(`超时 ${ms}ms`)), ms));
  const t0 = Date.now();
  try {
    await Promise.race([fn(), timeout(5000)]);
    results.pass++;
  } catch (e) {
    results.fail++;
    results.failures.push({ title: name, kind: e.message.startsWith('超时') ? 'timeout' : 'assert', msg: e.message });
  }
  console.log(`${name} (${Date.now() - t0}ms)`);
}
export const itAsync = (name, fn) => queue.push(() => runIt(name, fn));
export async function run() { for (const t of queue) await t(); }  // 串行

```

**评分点**：
- 超时用 Promise.race，超时后框架继续（不 unhandled rejection）。
- 失败区分「断言失败」与「超时失败」。
- 串行执行保证顺序与输出可读。
- 清理：超时用例的资源泄漏提示（加分讨论）。
