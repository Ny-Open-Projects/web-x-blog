## TST-484：笔试：重构对账（新旧实现同输入输出对比）工具。
**题目**：输入输入集 inputs 与两实现 fn。逐输入对比输出（深度相等），输出 `{matched, mismatched}`；mismatched 带输入与两输出摘要（截断）。

```javascript
async function shadowCompare(inputs, oldFn, newFn, { maxShow = 200 } = {}) {
  const mismatched = [];
  let matched = 0;
  for (const input of inputs) {
    const [a, b] = await Promise.all([oldFn(input), newFn(input)]);
    if (JSON.stringify(a) === JSON.stringify(b)) matched++;
    else mismatched.push({ input: JSON.stringify(input).slice(0, maxShow),
      old: JSON.stringify(a).slice(0, maxShow), neo: JSON.stringify(b).slice(0, maxShow) });
  }
  return { matched, mismatched, passRate: +(matched / inputs.length).toFixed(2) };
}

```

**评分点**：
- 逐输入对账（深度比较）。
- 摘要截断（防报告爆炸）。
- matched 计数（对账通过率）。
- 输入顺序保持（可复现）。
