## TST-455：笔试：测试执行前的环境健康预检器。
**答**：检查项 `[{name, check: async () => {ok, ms}}]`。实现 `preflight(checks, {parallel: true})`：全过输出各耗时；失败快速汇总（不跑后续套件）；并行可选。

```javascript
function withTimeout(p, ms, name) {
  return Promise.race([p, new Promise((_, rej) =>
    setTimeout(() => rej(new Error(`${name} 预检超时 ${ms}ms`)), ms))]);
}
async function preflight(checks, { parallel = true, perCheckMs = 3000 } = {}) {
  const run = async (c) => {
    const t0 = Date.now();
    try { const r = await withTimeout(c.check(), perCheckMs, c.name);
      return { name: c.name, ...r, ms: Date.now() - t0 }; }
    catch (e) { return { name: c.name, ok: false, error: String(e), ms: Date.now() - t0 }; }
  };
  const results = parallel ? await Promise.all(checks.map(run)) : [];
  if (!parallel) for (const c of checks) results.push(await run(c));
  const failed = results.filter(r => !r.ok);
  return { ok: failed.length === 0, results, failed: failed.map(f => `${f.name}: ${f.error}`) };
}

```

**评分点**：
- 并行/串行双模式（Promise.all vs 循环）。
- 失败聚合（全部失败项清单，不只第一个）。
- 每项耗时记录（环境性能基线）。
- 超时保护（单检查项超时算失败）。
