## TST-444：笔试：用例的 covers 声明与实际断言模块的一致性校验。
**答**：用例声明 `covers: [module]` 与实际断言涉及的模块（从断言对象来源提取，输入提供）。校验：声明未覆盖（漏报）/覆盖未声明（漂移）。输出两类清单。

```javascript
function checkCovers(cases) {
  const undeclared = [], drifted = [];
  for (const c of cases) {
    if (!c.actualModules) continue;               // 数据不全跳过
    const decl = new Set(c.covers || []);
    for (const m of c.actualModules)
      if (!decl.has(m)) drifted.push({ case: c.name, module: m });
    for (const m of decl)
      if (!c.actualModules.includes(m)) undeclared.push({ case: c.name, module: m });
  }
  return { undeclared, drifted };
}
console.log(checkCovers([
  { name: 'a', covers: ['cart'], actualModules: ['cart', 'coupon'] },
])); // drifted: coupon

```

**评分点**：
- 双向比对（声明 vs 实际）。
- 漏报与漂移语义区分。
- 输出带用例名（可定位）。
- 实际来源缺失的用例跳过（数据不全容错）。
