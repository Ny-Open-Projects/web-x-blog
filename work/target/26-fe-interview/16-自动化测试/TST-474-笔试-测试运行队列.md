## TST-474：笔试：测试运行的优先级队列（发布优先/抢占语义简化）。
**答**：任务 `[{suite, priority: 1-3, enqueuedAt}]`。出队规则：priority 小者先；同优先级 FIFO。实现 `Queue.push/pop`；队列长度暴露（积压告警用）。

```javascript
export class RunQueue {
  #q = [];
  push(task) {
    const key = `${task.suite}|${task.ref}`;
    if (this.#q.some(t => `${t.suite}|${t.ref}` === key)) return false;  // 去重
    this.#q.push(task);
    return true;
  }
  pop() {
    if (!this.#q.length) return null;
    this.#q.sort((a, b) => a.priority - b.priority || a.enqueuedAt - b.enqueuedAt);
    return this.#q.shift();
  }
  get length() { return this.#q.length; }
}

```

**评分点**：
- 优先级比较 + FIFO 稳定。
- pop 空队列返回 null（不抛错）。
- length/积压统计暴露。
- 同任务去重（同 suite+ref 防重复入队）。
