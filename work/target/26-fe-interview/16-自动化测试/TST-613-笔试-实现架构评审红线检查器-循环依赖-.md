## TST-613：笔试：实现架构评审红线检查器（循环依赖 / 禁用 API）

**题目**：输入 files=[{name,imports:[依赖文件名],content:源码}] 与 banned=[正则]。实现 buildGraph + findCycles（DFS 三色标记，输出所有环）与 findBanned（禁用 API 命中），汇总为报告。

**答**：
- 循环依赖用 DFS 三色标记检测，遇到回边即记录环。
- 禁用 API 用正则扫描源码并输出文件 + 行号。
- 两类问题汇总成统一报告，便于 CI 消费。

```javascript
function buildGraph(files) {
  const g = new Map(files.map(f => [f.name, []]));
  files.forEach(f => (f.imports || []).forEach(dep => {
    if (g.has(dep)) g.get(f.name).push(dep);
  }));
  return g;
}
function findCycles(g) {
  const color = new Map(), stack = [], cycles = [];
  const dfs = n => {
    color.set(n, 1); stack.push(n);
    for (const m of g.get(n) || []) {
      if (color.get(m) === 1)
        cycles.push([...stack.slice(stack.indexOf(m)), m]);
      else if (!color.get(m)) dfs(m);
    }
    stack.pop(); color.set(n, 2);
  };
  g.forEach((_, n) => { if (!color.get(n)) dfs(n); });
  return cycles;
}
function findBanned(files, banned) {
  return files.flatMap(f => banned.filter(b => b.test(f.content))
    .map(b => ({ file: f.name, api: b.source })));
}
```

**评分点**：
- 循环依赖检测正确且不重复报环
- DFS 三色标记避免死循环
- 禁用 API 输出文件与 API 名
- 两类结果汇总结构统一
