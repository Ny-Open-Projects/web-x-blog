## TST-248：国际化组件（多语言文案/RTL）测试要点？
**答**：
- 文案 key 断言而非具体语言断言（用测试 locale 固定字符串）。
- RTL（阿拉伯语）布局：direction: rtl 下视觉快照 + 逻辑属性断言（margin-inline）。
- 插值与复数：ICU 语法多分支用例（单数/复数/零）。
- 缺 key 行为断言（显示 key 名或 fallback），不允许渲染空白。

```javascript
test('RTL 布局', () => {
  render(<LocaleProvider dir="rtl"><Card /></LocaleProvider>);
  expect(screen.getByTestId('card')).toHaveStyle({ direction: 'rtl' });
  expect(screen.getByRole('button')).toBeVisible();
});
```
