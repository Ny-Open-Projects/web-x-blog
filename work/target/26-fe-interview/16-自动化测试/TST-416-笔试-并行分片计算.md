## TST-416：笔试：实现测试分片计算（按文件时长均衡）。
**题目**：输入用例 `[{name, ms, file}]` 与 shard 数：按文件聚合时长，贪心装箱到分片，输出每分片的文件清单与预估时长、最大分片时长（makespan）。

```javascript
function shardByFile(cases, n) {
  const files = new Map();
  for (const c of cases) files.set(c.file, (files.get(c.file) || 0) + c.ms);
  const bins = Array.from({ length: n }, () => ({ total: 0, files: [] }));
  for (const [file, ms] of [...files].sort((a, b) => b[1] - a[1])) {
    const b = bins.reduce((m, x) => x.total < m.total ? x : m);
    b.total += ms; b.files.push(file);
  }
  const makespan = Math.max(...bins.map(b => b.total));
  const avg = cases.reduce((s, c) => s + c.ms, 0) / n;
  return { bins, makespan, warn: [...files].some(([, ms]) => ms > avg) ? '存在大文件建议拆分' : null };
}

```

**评分点**：
- 按文件粒度分片（同文件不拆——共享 setup）。
- 贪心：最长文件优先给最轻分片。
- makespan 输出（均衡质量指标）。
- 单文件超单分片均值时告警（大文件建议拆分）。
