## TST-547：长列表/虚拟滚动的性能与正确性怎么测

**答**：
- 结论：正确性看「可视区渲染 + 滚动到对应区间数据正确 + 复用无错位」；性能看「滚动帧率/长任务数/DOM 节点数恒定」。
- 做法：用大数据集（万级）渲染，断言 DOM 节点数远小于总数；滚动到中部断言可见项内容正确；用 requestAnimationFrame 采样帧间隔评估流畅度。
- 追问钩子：虚拟列表最容易被忽略的 bug 是什么？——滚动后快速反向滚动导致占位高度错位、或筛选后索引未重置显示旧数据；要专门设计「跳转+反向滚+筛选」组合用例。

```javascript
// 虚拟列表正确性断言：DOM 节点数恒定 + 可见项数据正确
function assertVirtualList(visibleItems, total, viewportHeight, rowHeight) {
  const maxNodes = Math.ceil(viewportHeight / rowHeight) + 4; // 缓冲
  const domOk = visibleItems.length <= maxNodes;
  const dataOk = visibleItems.every(it => it.index >= 0 && it.index < total && it.text);
  return { domOk, dataOk, rendered: visibleItems.length, maxNodes };
}
// 性能侧：采样滚动帧间隔，统计掉帧
function droppedFrames(frameMs) { return frameMs.filter(ms => ms > 32).length; }
console.log(assertVirtualList([{ index: 5, text: '商品' }], 10000, 800, 40));
console.log(droppedFrames([16, 40, 16])); // 1 帧掉帧
```
