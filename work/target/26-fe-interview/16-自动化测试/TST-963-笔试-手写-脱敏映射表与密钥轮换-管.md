## TST-963：笔试：手写「脱敏映射表与密钥轮换」管理器，支持可逆脱敏的平滑升级
**答**：
- 需求：实现 TokenVault()，提供 tokenize(v)/detokenize(t)/rotateKey() 方法。
- 规则：tokenize 用当前密钥生成 TK_<keyVersion>_<hash>，同一 v 同一版本返回同一 token；rotateKey 生成新版本密钥，旧 token 仍能 detokenize（保留旧密钥），新 tokenize 用新版本。
- 边界：v 为空抛错；detokenize 未知 token 抛错；支持 retireOlderThan(version) 清理过期密钥。

```javascript
function TokenVault() {
  let version = 1;
  const keys = new Map([[1, 'k1']]);
  const map = new Map(); // token -> value
  const tokenize = (v) => {
    if (v == null) throw new Error('value 不能为空');
    // 按当前版本生成确定 token
    const token = `TK_${version}_${hash(v + keys.get(version))}`;
    map.set(token, v);
    return token;
  };
  const detokenize = (t) => {
    if (!map.has(t)) throw new Error(`未知 token ${t}`);
    return map.get(t);
  };
  const rotateKey = () => {
    version++; keys.set(version, `k${version}`); return version;
  };
  const retireOlderThan = (v) => {
    for (const k of keys.keys()) if (k < v) keys.delete(k);
  };
  return { tokenize, detokenize, rotateKey, retireOlderThan, get version() { return version; } };
}
function hash() { return 'a1b2c3'; }
const v = TokenVault();
const old = v.tokenize('13800000000');
v.rotateKey();
const fresh = v.tokenize('13800000000');
console.log(old !== fresh, v.detokenize(old), v.detokenize(fresh));
// true, '13800000000', '13800000000' — 平滑升级
```
**评分点**：
- tokenize 用当前密钥版本生成确定 token，同值同版本结果一致。
- rotateKey 后旧 token 仍可 detokenize（保留旧密钥），新 token 用新版本。
- 空值/未知 token 正确抛错。
- retireOlderThan 清理过期密钥，边界完整。
