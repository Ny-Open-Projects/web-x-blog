## TST-724：平台化下性能数据的高基数时序存储与查询建模

**答**：
- 结论：性能指标是典型时序数据，标签（页面/机型/版本/地域）高基数，建模要「指标 + 标签 + 时间戳」并做降采样，避免直接存全量明细。
- 存储用时序库或列存，按时间分区 + 标签建索引；高基数标签做字典编码降低存储。
- 查询分层：原始明细（短保留期）+ 预聚合（长保留期），看板默认查聚合。
- 追问钩子：某个标签组合突然产生爆炸式时间序列，如何防止打爆存储？

```javascript
// 时序降采样：按时间桶聚合
function downsample(points, bucketMs) {
  const buckets = new Map();
  for (const p of points) {
    const key = Math.floor(p.ts / bucketMs) * bucketMs;
    if (!buckets.has(key)) buckets.set(key, []);
    buckets.get(key).push(p.value);
  }
  return [...buckets.entries()].map(([ts, vals]) => ({
    ts,
    p95: vals.sort((a, b) => a - b)[Math.floor(vals.length * 0.95)] || vals[0],
    count: vals.length,
  }));
}
console.log(downsample([
  { ts: 100, value: 10 }, { ts: 200, value: 20 }, { ts: 1100, value: 30 },
], 1000));
```
