## TST-634：笔试：实现多分支测试资源分配器（权重 + 截止时间优先）

**题目**：实现 allocate(branches, capacity)。branches=[{name,risk,daysLeft}]。按 risk/daysLeft 计算权重，最大余数法分配整数槽位，保证总和=capacity 且每分支至少 1 个槽位。

**答**：
- 权重 = 风险系数 / 剩余天数，越紧急权重越高。
- 按比例分配槽位后用最大余数法修正，保证总和等于容量。
- 每分支至少保留 1 个槽位，避免饿死。

```javascript
function allocate(branches, capacity) {
  const w = branches.map(b => ({ name: b.name,
    weight: b.risk / Math.max(1, b.daysLeft) }));
  const sum = w.reduce((s, x) => s + x.weight, 0) || 1;
  const raw = w.map(x => ({ name: x.name, exact: x.weight / sum * capacity }));
  const out = raw.map(x => ({ name: x.name, slots: Math.max(1, Math.floor(x.exact)) }));
  let used = out.reduce((s, x) => s + x.slots, 0);
  const byFrac = [...raw].sort((a, b) =>
    (b.exact % 1) - (a.exact % 1));
  let i = 0;
  while (used < capacity && byFrac.length) {
    out.find(x => x.name === byFrac[i % byFrac.length].name).slots++;
    used++; i++;
  }
  return out;
}
```

**评分点**：
- 权重公式体现截止时间优先
- 最大余数法保证总和守恒
- 最小槽位防止饿死
- 边界（capacity 小于分支数）处理
