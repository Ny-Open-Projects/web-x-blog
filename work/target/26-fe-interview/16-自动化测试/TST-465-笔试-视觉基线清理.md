## TST-465：笔试：视觉基线孤儿检测（基线无对应用例引用）。
**答**：基线文件列表（名称编码：`{test}-{viewport}-{platform}.png`）与用例引用列表。输出孤儿基线（无引用）与失效引用（引用无基线）；同 test 多平台合并计数。

```javascript
function orphanBaselines(baselineFiles, refs) {
  const parse = f => { const m = f.match(/^(.+)-(\w+)-(\w+)\.png$/);
    return m && { test: m[1], viewport: m[2], platform: m[3] }; };
  const refSet = new Set(refs.map(r => `${r.test}|${r.viewport}|${r.platform}`));
  const baseSet = new Set(), orphans = new Map();
  for (const f of baselineFiles) {
    const p = parse(f);
    if (!p) { console.warn(`非法基线命名: ${f}`); continue; }
    const k = `${p.test}|${p.viewport}|${p.platform}`;
    baseSet.add(k);
    if (!refSet.has(k)) orphans.set(p.test, (orphans.get(p.test) || 0) + 1);
  }
  const missing = [...refSet].filter(k => !baseSet.has(k));
  return { orphans: Object.fromEntries(orphans), missing };
}

```

**评分点**：
- 名称解析 → (test, viewport, platform) 三元组。
- 双向比对（孤儿/失效）。
- 按 test 聚合孤儿计数（清理 PR 粒度）。
- 名称解析容错（非法命名告警）。
