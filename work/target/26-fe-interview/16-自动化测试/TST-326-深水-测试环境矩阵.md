## TST-326：多环境（dev/staging/prod-like）下测试如何分配？
**答**：
- 单测/组件测试：无环境依赖（CI 任意 runner）。
- API/集成：专用测试环境（独立数据、可重置）。
- E2E 核心旅程：staging（接近真实配置但数据隔离）。
- 线上巡检：prod 探针账号（只读或标记数据）。
- 环境矩阵与用例层绑定声明（用例标注 allowed envs），防止误跑生产。

```javascript
const envMatrix = {
  unit: ['*'], api: ['test-env'], e2e: ['staging'], probe: ['prod'],
};
// runner 校验：if (!envMatrix[case.level].includes(env)) skip with warn
r
```
