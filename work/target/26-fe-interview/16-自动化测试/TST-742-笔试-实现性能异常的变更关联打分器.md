## TST-742：笔试：实现性能异常的「变更关联」打分器（时间相关性）

**题目**：输入变更数组 [{id, at}] 与性能拐点序列 points [{at, value}]。拐点定义为相邻两点 value 变化超过 20% 的点，取其 at。对每个拐点，找出其前 2 小时内最近的变更，计算关联分 = 1 - 时间差/2小时（时间差越小分越高）。按拐点时间升序返回 [{changeAt, changeId, score}]，无变更则 changeId=null、score=0。

**答**：
- 先按 20% 阈值识别拐点，再对每个拐点向前找 2h 内最近变更。
- 关联分随时间差线性衰减，边界 2h 处为 0。
- 输出按拐点时间排序，无匹配变更有兜底。

```javascript
function correlate(changes, points) {
  const twoHours = 2 * 3600000;
  const turns = points.filter((p, i) => i > 0 &&
    Math.abs(p.value - points[i - 1].value) / (points[i - 1].value || 1) > 0.2
  ).map(p => p.at).sort((a, b) => a - b);
  return turns.map(at => {
    const before = changes.filter(c => c.at <= at && at - c.at <= twoHours)
      .sort((a, b) => b.at - a.at)[0];
    if (!before) return { changeAt: at, changeId: null, score: 0 };
    return {
      changeAt: at, changeId: before.id,
      score: +(1 - (at - before.at) / twoHours).toFixed(3),
    };
  });
}
console.log(correlate(
  [{ id: 'c1', at: 1000 }],
  [{ at: 0, value: 100 }, { at: 3000, value: 200 }]
)); // score≈1
```

**评分点**：
- 20% 拐点识别正确
- 2 小时窗口内最近变更查找正确
- 关联分线性衰减公式正确
- 无变更兜底与排序
