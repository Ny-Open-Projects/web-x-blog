## TST-418：笔试：实现「请求是否符合 OpenAPI 契约」的简化校验。
**答**：契约 `[{method, path(含:param), requiredQuery?, bodySchema}]`。实现 `matchAndValidate(req)`：路径模板匹配（:param 提取）、必填 query、body 字段类型校验，输出匹配契约与错误清单。

```javascript
const contracts = [
  { method: 'GET', path: '/goods/:id', requiredQuery: ['lang'],
    bodySchema: {} },
  { method: 'POST', path: '/orders', bodySchema: { sku: 'string', count: 'number' } },
];
function validateRequest(req) {
  for (const c of contracts) {
    if (c.method !== req.method) continue;
    const segs = c.path.split('/');
    const rsegs = req.path.split('/');
    if (segs.length !== rsegs.length) continue;
    const params = {};
    const ok = segs.every((s, i) => s.startsWith(':') ? (params[s.slice(1)] = rsegs[i], true) : s === rsegs[i]);
    if (!ok) continue;
    const errors = [];
    (c.requiredQuery || []).forEach(q => { if (!(q in (req.query || {}))) errors.push(`缺 query: ${q}`); });
    Object.entries(c.bodySchema).forEach(([k, t]) => {
      if (typeof req.body?.[k] !== t) errors.push(`body.${k} 应为 ${t}`);
    });
    return { matched: c.path, params, errors };
  }
  return { matched: null, errors: ['无匹配契约'] };
}

```

**评分点**：
- 路径模板匹配 + 参数提取（:id 段）。
- query 必填校验。
- body schema 逐字段类型校验（简化 JSON schema）。
- 无匹配契约输出 404 语义（契约缺口）。
