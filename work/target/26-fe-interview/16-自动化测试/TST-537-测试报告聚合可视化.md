## TST-537：测试报告如何聚合与可视化才有用

**答**：
- 结论：报告分层——总览（通过率/趋势/门禁结论）→ 域视图 → 失败明细（证据链）→ 趋势与洞察（flaky/慢用例/逃逸）。让不同角色各取所需。
- 做法：总览用红绿灯 + 环比；失败按错误指纹聚类避免刷屏；提供下钻到单用例的 trace/截图；自动写一段「本次质量摘要」文字。
- 追问钩子：报告没人看怎么办？——把报告推到 IM/看板并绑定门禁结论（红即阻塞），同时生成一句话摘要，降低阅读门槛。

```javascript
// 失败按错误指纹聚类，避免报告刷屏
function clusterFailures(failures) {
  const groups = {};
  for (const f of failures) {
    const fp = fingerprint(f.message);
    (groups[fp] ||= { count: 0, names: [], sample: f.message }).count++;
    groups[fp].names.push(f.name);
  }
  return Object.entries(groups).map(([fp, g]) => ({ fp, ...g }))
    .sort((a, b) => b.count - a.count);
}
function fingerprint(msg = '') {
  return msg.replace(/\d+/g, '#').replace(/"[^"]*"/g, '"*"').slice(0, 80);
}
```
