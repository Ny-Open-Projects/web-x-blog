## TST-287：性能测试中的竞态问题（缓存/预热污染结果）如何处理？
**答**：
- 冷热分离：明确测冷启动（清缓存）与热态（预热后），分别设阈值。
- 同一 CI 机器上并行跑性能测试互相干扰——性能 job 独占 runner。
- 网络波动：全部用本地服务 + CDP 节流（模拟而非真网络）。
- 样本策略：每指标 ≥ 5 次取中位数，删除离群值（±2σ）。

```javascript
// 独占 runner + 节流

await page.route('**/*', route => {
  // CDP 节流模拟 Fast 3G
  cdp.send('Network.emulateNetworkConditions', { latency: 150, downloadThroughput: 180000 });
});
```
