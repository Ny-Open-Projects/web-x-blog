## TST-449：笔试：测试结果入库的 schema 与幂等写入。
**题目**：记录 `{runId, suite, name, status, ms, attempt, shard}`。实现 `upsert(store, record)`：同 (runId, name, attempt) 幂等覆盖；唯一键校验；批量写入去重。

```javascript
const KEY = r => `${r.runId}|${r.name}|${r.attempt ?? 0}`;
function upsert(store, records) {
  for (const r of records) {
    if (!r.runId || !r.name) throw new Error('缺 runId/name');
  }
  const batch = new Map(records.map(r => [KEY(r), r]));   // 批内去重取最后
  for (const [k, r] of batch) store.set(k, r);            // store 为 Map，天然幂等
  return store.size;
}

```

**评分点**：
- 唯一键定义（runId+name+attempt）。
- 幂等 upsert（重复写入覆盖不报错）。
- 批量去重（批内同键取最后）。
- 非法字段（缺 runId）快速失败。
