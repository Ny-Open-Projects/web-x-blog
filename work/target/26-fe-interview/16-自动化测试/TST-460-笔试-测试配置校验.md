## TST-460：笔试：测试配置（playwright.config 风格）静态校验器。
**题目**：规则：workers ≥ 1；retries 在 CI ≥ 1；use.baseURL 必填（e2e 项目）；timeout ≥ 5s；禁止 video: 'on'（成本）。实现 `lintConfig(cfg)` 输出违规清单（含建议）。

```javascript
const RULES = [
  { test: c => (c.workers ?? 0) >= 1, msg: 'workers ≥ 1', fix: '显式设置 workers' },
  { test: c => !c.ci || (c.retries ?? 0) >= 1, msg: 'CI 下 retries ≥ 1', fix: 'retries: process.env.CI ? 2 : 0' },
  { test: c => c.type !== 'e2e' || !!c.use?.baseURL, msg: 'e2e 必须配置 baseURL', fix: 'use: { baseURL }' },
  { test: c => (c.timeout ?? Infinity) >= 5000, msg: 'timeout ≥ 5s', fix: '提高全局 timeout' },
  { test: c => c.use?.video !== 'on', msg: '禁止 video: on（成本）', fix: "video: 'retain-on-failure'" },
];
function lintConfig(cfg) {
  return RULES.filter(r => !r.test(cfg)).map(r => ({ msg: r.msg, fix: r.fix }));
}
console.log(lintConfig({ workers: 0, ci: true, type: 'e2e', timeout: 2000 })); // 4 条违规

```

**评分点**：
- 规则表驱动（每条规则函数 + 建议）。
- 条件规则（CI 环境相关）。
- 违规输出带建议（可执行修复）。
- 未知字段告警（配置漂移）。
