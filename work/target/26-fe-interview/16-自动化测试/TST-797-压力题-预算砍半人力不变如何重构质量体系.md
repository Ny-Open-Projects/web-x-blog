## TST-797：压力题：预算砍半、人力不变，如何重构质量体系

**答**：
- 结论：先保「高风险覆盖」再砍「低价值成本」——用风险画像重新分配预算，把资源集中到核心链路而非平均用力。
- 具体手段：降低昂贵 E2E 频率改按需触发、用测试选择减量、闲时错峰跑资源、下线长期无价值的用例。
- 引入 AI 批量生成/自愈降低维护成本，但设成本上限防止反噬。
- 追问钩子：砍完预算后覆盖率数字下降但逃逸率上升，如何向管理层解释？

```javascript
// 预算削减：按风险价值排序保核心
function restructureWithHalfBudget(tests, budget) {
  const scored = tests.map(t => ({
    ...t, value: t.risk * t.bizImpact, cost: t.runCostMs,
  })).sort((a, b) => (b.value / b.cost) - (a.value / a.cost));
  let used = 0;
  const kept = [];
  for (const t of scored) {
    if (used + t.cost <= budget) { kept.push(t.id); used += t.cost; }
  }
  return { kept, used, dropped: tests.length - kept.length };
}
console.log(restructureWithHalfBudget([
  { id: 'a', risk: 5, bizImpact: 2, runCostMs: 1000 },
  { id: 'b', risk: 1, bizImpact: 1, runCostMs: 5000 },
], 6000));
```
