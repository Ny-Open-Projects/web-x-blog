## TST-335：CI 时间预算化（每个测试层有明确时长预算）如何管理？
**答**：
- 预算表：单测 < 3min / API < 8min / E2E 冒烟 < 5min / 全量 E2E < 40min。
- 超预算处理：先并行扩容（分片），再分析慢用例 top10 定向优化。
- 慢用例治理：超时用例自动标记 + 每迭代优化 N 条（常态化）。
- 预算回顾：季度根据代码增长调整预算（要论证不是放宽）。

```javascript
const timeBudget = { unit: 180, api: 480, e2eSmoke: 300, e2eFull: 2400 };
// CI job 结束输出 vs 预算，超支标红并附慢用例 top10
r
```
