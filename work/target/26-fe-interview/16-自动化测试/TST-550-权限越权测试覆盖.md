## TST-550：前端权限与越权测试怎么覆盖

**答**：
- 结论：三类越权——水平（改 ID 看他人数据）、垂直（普通用户访问管理员功能）、未授权（未登录访问受保护资源），前端都要有对应用例。
- 做法：准备多角色账号矩阵（游客/普通/管理员），对每个受保护操作断言：UI 隐藏/禁用 + 直接调接口/改路由也被后端拒绝；前端隐藏不能当安全，必须后端兜底。
- 追问钩子：前端路由守卫生效就够了吗？——不够，守卫只防 UI 进入；必须断言「绕过前端直接请求」仍被拒，且前端不缓存/渲染越权数据。

```javascript
// 越权测试矩阵：角色 × 资源 × 期望
const MATRIX = [
  { role: 'guest',  resource: '/admin', expect: 401 },
  { role: 'user',   resource: '/admin', expect: 403 },
  { role: 'user',   resource: '/order/other', expect: 403 }, // 水平越权
  { role: 'admin',  resource: '/admin', expect: 200 },
];
function checkAccess(results) {
  return results.map(r => ({ ...r,
    passed: r.status === r.expect,
    // 前端即便拿到数据也不应渲染他人信息
    noLeak: r.role !== 'user' || !r.body?.includes('他人私钥字段'),
  }));
}
```
