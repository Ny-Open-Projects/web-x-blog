## TST-956：脱敏后数据「不像真的」导致测试失真，如何验证脱敏的保真度？
**答**：
- 结论：保真度 = 脱敏前后数据的「统计特征与业务规则」一致程度——格式、分布、唯一性、关联关系要保持，仅敏感值改变。
- 验证：对比脱敏前后的字段格式正则、值域分布（直方图）、唯一键冲突率、外键关联完整性。
- 红线：手机号脱敏后必须仍是 11 位数字格式，否则下游正则校验测试全部假失败。
- 追问钩子：把身份证号哈希后变成 8 位十六进制，导致「校验身份证」的测试用例全挂，保真度怎么衡量这种破坏？

```javascript
function fidelityCheck(original, masked, rules) {
  const results = {};
  for (const r of rules) {
    const fmt = v => String(v).replace(/\d/g, 'N').replace(/[a-f]/gi, 'H');
    const oFmt = fmt(original[r.field]), mFmt = fmt(masked[r.field]);
    results[r.field] = {
      formatPreserved: oFmt === mFmt,
      note: oFmt === mFmt ? '格式保真' : `格式漂移: ${oFmt} -> ${mFmt}`,
    };
  }
  return results;
}
console.log(fidelityCheck(
  { phone: '13800000000' }, { phone: '138****0000' },
  [{ field: 'phone' }]
).phone); // 格式漂移: NNNNNNNNNNN -> NNN****NNNN（需按业务判断可接受性）
```
