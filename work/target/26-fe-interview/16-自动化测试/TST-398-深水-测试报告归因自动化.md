## TST-398：测试失败的「自动归因」（区分产品/环境/测试代码）的完整方案？
**答**：
- 特征提取：错误类型/失败分布（单用例 vs 多用例）/环境健康信号/变更关联。
- 规则层：多域同时失败 → 环境问题（先修环境）；单用例 + 断言差异 → 产品嫌疑。
- AI 层：规则不确定时 LLM 综合 trace 与变更归因（带置信度）。
- 准确率追踪：归因结果与人工最终判定对比，驱动规则/AI 优化。

```javascript
function autoAttribute(failures, envHealth, recentChanges) {
  if (failures.length > 10 && envHealth.degraded) return { cause: 'env', conf: 0.9 };
  const r = llmAttribute(failures, recentChanges);   // AI 层
  return r.conf > 0.7 ? r : { cause: 'unknown', escalate: true };
}
```
