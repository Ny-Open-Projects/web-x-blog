## TST-951：笔试：手写「误报反馈闭环器」——把人工确认的误报沉淀为可复用的抑制规则
**答**：
- 需求：实现 learnRules(feedbacks)，feedbacks = [{ cause, region, real }]，输出按 cause/region 聚合的抑制规则列表。
- 规则：某 (cause,region) 组合误报次数 >=3 且真回归次数为 0，生成 suppress 规则；若出现过真回归则生成 review 规则（不自动抑制）。
- 边界：新组合默认 review；规则可关闭（disabled）；输出按误报数降序。

```javascript
function learnRules(feedbacks) {
  const groups = new Map();
  for (const f of feedbacks) {
    const k = `${f.cause}@${f.region}`;
    const g = groups.get(k) || { cause: f.cause, region: f.region, false: 0, real: 0 };
    g[f.real ? 'real' : 'false']++;
    groups.set(k, g);
  }
  return [...groups.values()].map(g => ({
    ...g,
    action: g.false >= 3 && g.real === 0 ? 'suppress' : 'review',
    disabled: false,
  })).sort((a, b) => b.false - a.false);
}
const rules = learnRules([
  { cause: 'font', region: 'title', real: false },
  { cause: 'font', region: 'title', real: false },
  { cause: 'font', region: 'title', real: false },
  { cause: 'banner', region: 'ad', real: true },
]);
console.log(rules[0].action, rules[1].action); // 'suppress' 'review'
```
**评分点**：
- 按 (cause,region) 正确聚合误报/真回归次数。
- 误报>=3 且零真回归才生成 suppress，否则 review——安全兜底。
- 输出按误报数降序，便于优先治理高频误报。
- 规则带 disabled 开关，边界完整。
