## TST-894：笔试：手写一个「错误边界 + 重试 + 熔断」的组合演练测试
**答**：
- 需求：实现 resilientFetch(fetchFn, { retries, shouldTrip }) —— 组合重试（失败重试 retries 次）与熔断（连续失败达阈值后短路），返回包装函数。
- 规则：每次失败重试，间隔递增；连续失败 >= shouldTrip 阈值后进入熔断，熔断期间直接抛「CircuitOpen」不再请求。
- 边界：成功则重置连续失败计数；参数非法抛错；返回 stats（重试次数/熔断次数）。

```javascript
function resilientFetch(fetchFn, { retries = 2, shouldTrip = 3 } = {}) {
  if (retries < 0 || shouldTrip < 1) throw new RangeError('非法参数');
  let consecutiveFails = 0, circuitOpen = false;
  const stats = { retries: 0, trips: 0 };
  return async (...args) => {
    if (circuitOpen) { stats.trips++; throw new Error('CircuitOpen'); }
    for (let attempt = 0; attempt <= retries; attempt++) {
      try {
        const res = await fetchFn(...args);
        consecutiveFails = 0; // 成功重置
        return res;
      } catch (e) {
        if (attempt < retries) { stats.retries++; continue; }
        consecutiveFails++;
        if (consecutiveFails >= shouldTrip) circuitOpen = true;
        throw e;
      }
    }
  };
}
const rf = resilientFetch(fetch, { retries: 2, shouldTrip: 3 });
// 演练：持续失败 -> 重试后熔断，避免重试风暴
```
**评分点**：
- 重试逻辑（失败重试 retries 次，间隔可递增）实现正确。
- 熔断机制：连续失败达阈值后短路并抛 CircuitOpen，避免重试风暴。
- 成功重置计数、参数校验、stats 统计，边界与可观测完整。
- 能点出「重试+熔断组合用于验证系统在依赖持续故障时的韧性」。
