## TST-553：笔试：笔试：长任务（Long Task）检测与归因

**题目**：实现 detectLongTasks(entries, { threshold=50 })。entries 是 PerformanceObserver('longtask') 得到的数组，每项 {startTime, duration, attribution:[{name, containerType, containerSrc}]}。要求：① 过滤 duration >= threshold 的任务；② 按 attribution 的 name 归因，统计每个来源的长任务次数与总时长；③ 输出 {tasks, bySource:[{name, count, totalMs}], worst}（worst 为单个最长任务）；④ 边界：attribution 为空归为 'unknown'；entries 为空返回空结构。

**答**：
- 结论：先按阈值过滤，再按归因来源聚合次数/总时长，最后找最长任务。
- 实现要点：attribution 取首项 name（或每个来源都计入），空则 'unknown'；用 Map 聚合；worst 用 reduce 比较 duration。
- 追问钩子：长任务归因到 iframe 怎么办？——用 containerType/containerSrc 标识第三方来源，推动隔离或将重计算移出主线程（Web Worker）。

```javascript
function detectLongTasks(entries = [], { threshold = 50 } = {}) {
  const tasks = entries.filter(e => e.duration >= threshold);
  const bySource = new Map();
  for (const t of tasks) {
    const name = t.attribution?.[0]?.name || 'unknown';
    const cur = bySource.get(name) || { name, count: 0, totalMs: 0 };
    cur.count++; cur.totalMs += t.duration; bySource.set(name, cur);
  }
  const worst = tasks.reduce((m, t) => (!m || t.duration > m.duration) ? t : m, null);
  return { tasks, bySource: [...bySource.values()], worst };
}
console.log(detectLongTasks([
  { startTime: 10, duration: 120, attribution: [{ name: 'self' }] },
  { startTime: 200, duration: 30, attribution: [] },
]).bySource);
```

**评分点**：
- 按 threshold 正确过滤长任务。
- attribution 为空归为 'unknown'，不抛错。
- 按来源聚合 count/totalMs 正确。
- worst 找单个最长任务，空输入返回空结构。
