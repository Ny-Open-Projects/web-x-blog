## TST-506：笔试：分层测试预算分配算法

**题目**：给定模块列表 [{name, risk, cases}] 与每层单测成本（unit=1/contract=4/component=2/e2e=10 分钟），要求在总预算 budget 内分配每层用例数，目标是「风险加权覆盖最多」。规则：高风险模块优先保证 contract 与 e2e 覆盖；输出每个模块各层用例数，总成本不得超过 budget。

**答**：
- 结论：这是带约束的整数规划；用贪心 + 风险权重近似——按风险排序，先满足高风险模块的契约/E2E 底线，再用剩余预算按边际收益填充。
- 实现要点：每层设最小覆盖（底线），再按 risk 权重 × 边际覆盖率/成本 排序增量分配；最终若超预算则回退低优先级增量。
- 追问钩子：如何证明分配合理？——用「风险覆盖率」= Σ(已覆盖风险点权重 × 该层发现概率) 做目标函数，可对比不同策略的得分。

```javascript
function allocateBudget(modules, budget) {
  const COST = { unit: 1, contract: 4, component: 2, e2e: 10 };
  const RISK_W = { low: 1, mid: 2, high: 3 };
  const plan = modules.map(m => ({ name: m.name, unit: 0, contract: 0, component: 0, e2e: 0 }));
  let left = budget;
  // 1) 高风险模块优先兜底：每个至少 1 条 e2e + 1 条 contract
  modules.forEach((m, i) => {
    if (m.risk === 'high' && left >= COST.e2e + COST.contract) {
      plan[i].e2e = 1; plan[i].contract = 1; left -= COST.e2e + COST.contract;
    }
  });
  // 2) 生成候选增量：(收益/成本) 排序，收益 = 风险权重 × 层发现概率
  const FIND = { unit: 0.3, contract: 0.7, component: 0.5, e2e: 0.9 };
  const cand = [];
  modules.forEach((m, i) => Object.keys(COST).forEach(layer => {
    if (plan[i][layer] < m.cases) cand.push({ i, layer,
      ratio: RISK_W[m.risk] * FIND[layer] / COST[layer], cost: COST[layer] });
  }));
  cand.sort((a, b) => b.ratio - a.ratio);
  for (const c of cand) {
    if (c.cost <= left && plan[c.i][c.layer] < modules[c.i].cases) {
      plan[c.i][c.layer]++; left -= c.cost;
    }
  }
  return { plan, left };
}
```

**评分点**：
- 高风险模块优先获得契约/E2E 覆盖（兜底逻辑）。
- 候选增量按「风险权重×发现概率/成本」边际收益排序。
- 严格遵守 budget 约束，不超支并记录剩余。
- 不超过模块各自 cases 上限，输出结构清晰可断言。
