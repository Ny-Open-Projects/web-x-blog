## TST-723：安全测试如何平台化为自助扫描服务与持续安全门禁

**答**：
- 结论：安全平台化=「扫描能力服务化 + 结果分级门禁」，让业务在 MR 阶段自助触发，平台统一维护规则库与基线。
- 能力服务化：提供统一 API/CLI，屏蔽底层扫描器差异；规则库集中升级，业务无需感知。
- 结果分级：阻断级（XSS/越权）卡发布，提示级（低危）只告警，避免误报淹没。
- 追问钩子：扫描器误报率高导致业务绕过门禁，平台侧如何治理？

```javascript
// 安全扫描结果分级门禁
function securityGate(findings) {
  const BLOCK = new Set(['XSS', 'IDOR', 'RCE']);
  const blockers = findings.filter(f => BLOCK.has(f.type) && f.confidence >= 0.8);
  const warnings = findings.filter(f => !BLOCK.has(f.type) || f.confidence < 0.8);
  return {
    pass: blockers.length === 0,
    blockers: blockers.map(f => f.type),
    warnings: warnings.length,
  };
}
console.log(securityGate([
  { type: 'XSS', confidence: 0.9 },
  { type: 'INFO', confidence: 0.5 },
])); // pass:false
```
