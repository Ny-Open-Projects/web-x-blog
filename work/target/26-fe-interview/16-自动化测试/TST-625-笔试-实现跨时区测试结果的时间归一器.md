## TST-625：笔试：实现跨时区测试结果的时间归一器

**题目**：实现 normalizeResults(rows,{drift,tz})。rows=[{runId,caseId,region,ts,seq}]。按 drift+tz 校正得到 utcTs，按 runId:caseId 去重（seq 大者优先），按 utcTs 升序输出。

**答**：
- 用 drift 表校正机器时钟偏差，用 tzOffset 校正时区展示差异。
- 归一后按 (runId, caseId) 去重，保留 seq 最大的记录。
- 输出带 utcTs 的标准结果，便于下游聚合。

```javascript
function normalizeResults(rows, { drift = {}, tz = {} } = {}) {
  const utc = r => r.ts + (drift[r.region] || 0) + (tz[r.region] || 0);
  const map = new Map();
  rows.forEach(r => {
    const key = `${r.runId}:${r.caseId}`;
    const prev = map.get(key);
    const t = utc(r);
    if (!prev || (r.seq || 0) > (prev.seq || 0) || t > prev.utcTs)
      map.set(key, { ...r, utcTs: t });
  });
  return [...map.values()].sort((a, b) => a.utcTs - b.utcTs);
}
console.log(normalizeResults([{ runId: 'r1', caseId: 'c1',
  region: 'cn', ts: 100, seq: 1 }]));
```

**评分点**：
- 时钟与时区双重校正方向正确
- 去重键与 seq 优先规则
- 排序输出可聚合
- 边界（缺 region/ts）处理
