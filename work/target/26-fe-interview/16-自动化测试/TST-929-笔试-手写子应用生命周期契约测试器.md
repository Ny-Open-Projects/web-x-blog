## TST-929：笔试：手写子应用生命周期契约测试器，验证顺序/幂等/卸载清理
**答**：
- 需求：实现 testLifecycle(app, container, cycles)，app 含 bootstrap/mount/unmount，cycles 为挂载卸载循环次数。
- 规则：断言 bootstrap 恰好 1 次且在最前；mount/unmount 交替各 cycles 次；每次 mount 后 container 有内容、unmount 后清空；返回调用轨迹。
- 边界：任一钩子抛错则记录失败点并终止；mount 不产生内容视为违约。

```javascript
async function testLifecycle(app, container, cycles = 5) {
  const calls = [], failures = [];
  const step = async (name, fn) => { try { await fn(); calls.push(name); } catch (e) {
    failures.push({ at: name, error: e.message }); throw e; } };
  try {
    await step('bootstrap', () => app.bootstrap({ container }));
    for (let i = 0; i < cycles; i++) {
      await step('mount', () => app.mount({ container }));
      if (container.childElementCount === 0) failures.push({ at: 'mount', error: '挂载后无内容' });
      await step('unmount', () => app.unmount({ container }));
      if (container.childElementCount !== 0) failures.push({ at: 'unmount', error: '卸载后残留 DOM' });
    }
  } catch { /* 已记录失败点 */ }
  const bootCount = calls.filter(c => c === 'bootstrap').length;
  if (bootCount !== 1) failures.push({ at: 'bootstrap', error: `调用 ${bootCount} 次，应为 1` });
  if (calls[0] !== 'bootstrap') failures.push({ at: 'order', error: 'bootstrap 未在最前' });
  return { calls, failures, passed: failures.length === 0 };
}
const c = document.createElement('div');
const app = { bootstrap: async()=>{}, mount: async(p)=>{p.container.innerHTML='<i/>';},
  unmount: async(p)=>{p.container.innerHTML='';} };
console.log((await testLifecycle(app, c)).passed); // true
```
**评分点**：
- bootstrap 恰好一次且在最前，顺序断言完整。
- mount/unmount 交替 cycles 次，且验证挂载有内容/卸载清空。
- 钩子抛错记录失败点并终止，不掩盖错误。
- 返回调用轨迹与 failures，便于定位违约环节。
