## TST-518：笔试：笔试：发布准入加权评分卡

**题目**：实现 releaseScore(input, policy)。input={unitPass, e2ePass, incCoverage, perfPass, securityP0, flakyRate, escapedP0}。policy 定义各指标的权重 weight、达标值 target、方向 dir（'higher'/'lower'）和红线 redline。要求：① 每个指标按达标程度打 0~1 分（达 target 得 1，线性，方向区分）；② 触发任一红线的指标该项记 0 且整体直接 fail；③ 总分 = Σ(score×weight)，>=0.85 为 'go'，>=0.7 为 'conditional'（需审批），否则 'no-go'；④ 输出 {score, verdict, blockers}。

**答**：
- 结论：评分卡 = 指标归一化打分 + 红线一票否决 + 加权总分 + 分级判定。
- 实现要点：higher 方向 score=min(1, value/target)，lower 方向 score=min(1, target/value)（注意除零）；红线用集合判断，命中即 blocker 并强制 no-go。
- 追问钩子：conditional 谁来批？——把审批流做成可配置的审批人矩阵（按域/严重度），并留审计记录。

```javascript
function releaseScore(input, policy) {
  const blockers = [];
  let total = 0, wSum = 0;
  for (const [metric, rule] of Object.entries(policy)) {
    const v = input[metric];
    if (rule.redline !== undefined &&
        (rule.dir === 'lower' ? v > rule.redline : v < rule.redline)) {
      blockers.push(metric); total += 0; wSum += rule.weight; continue;
    }
    let s;
    if (rule.dir === 'lower') s = v <= 0 ? 1 : Math.min(1, rule.target / v);
    else s = rule.target <= 0 ? 1 : Math.min(1, v / rule.target);
    total += s * rule.weight; wSum += rule.weight;
  }
  const score = +(total / wSum).toFixed(3);
  const verdict = blockers.length ? 'no-go'
    : score >= 0.85 ? 'go' : score >= 0.7 ? 'conditional' : 'no-go';
  return { score, verdict, blockers };
}
const policy = {
  unitPass: { weight: 0.2, target: 1, dir: 'higher', redline: 0.9 },
  incCoverage: { weight: 0.2, target: 0.7, dir: 'higher' },
  securityP0: { weight: 0.3, target: 0, dir: 'lower', redline: 0 },
  flakyRate: { weight: 0.1, target: 0.01, dir: 'lower' },
  e2ePass: { weight: 0.2, target: 0.99, dir: 'higher' },
};
```

**评分点**：
- 按 dir 正确做 higher/lower 归一化，处理 target=0 的除零边界。
- 红线命中记 0 分且加入 blockers，整体强制 no-go。
- 加权总分并按 0.85/0.7 阈值分级 go/conditional/no-go。
- blocker 列表明确列出阻塞指标，便于排查。
