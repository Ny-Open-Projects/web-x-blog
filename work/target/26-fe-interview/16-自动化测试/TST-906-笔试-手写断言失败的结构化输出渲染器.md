## TST-906：笔试：手写断言失败的结构化输出渲染器，把 Error 转成含 diff/paths/suggestion 的可解析对象
**答**：
- 需求：实现 renderFailure(err, { expected, actual })，返回 { summary, paths, diff, suggestion }。
- 规则：paths 列出所有实际与期望不同的字段路径（支持一层嵌套）；diff 用 [-期望/+实际] 标记；suggestion 对值为 null/undefined 给出「是否漏了可选链」提示。
- 边界：expected/actual 非对象时退化为单值比较；路径超过 20 条截断并标注 truncated。

```javascript
function renderFailure(err, { expected, actual }) {
  const paths = [];
  if (expected && actual && typeof expected === 'object' && typeof actual === 'object') {
    for (const k of new Set([...Object.keys(expected), ...Object.keys(actual)])) {
      const e = expected[k], a = actual[k];
      if (e && typeof e === 'object') {
        for (const kk of Object.keys(e)) {
          if (e[kk] !== a?.[kk]) paths.push(`${k}.${kk}`);
        }
      } else if (e !== a) paths.push(k);
    }
  } else if (expected !== actual) paths.push('$');
  const truncated = paths.length > 20;
  const shown = truncated ? paths.slice(0, 20) : paths;
  const diff = shown.map(p => `- ${p}: ${JSON.stringify(expected?.[p] ?? expected)}` +
    `\n+ ${p}: ${JSON.stringify(actual?.[p] ?? actual)}`).join('\n');
  const hasNil = shown.some(p => actual?.[p] == null);
  return {
    summary: `${err.message} (${paths.length} 处差异)`,
    paths: shown, diff,
    suggestion: hasNil ? '检测到 null/undefined：检查是否漏写可选链或接口未返回该字段' : '核对字段映射与单位',
    ...(truncated ? { truncated: true } : {}),
  };
}
console.log(renderFailure(new Error('订单断言'), {
  expected: { price: 9900, coupon: 500 }, actual: { price: 9901, coupon: null },
}).paths); // ['price','coupon']
```
**评分点**：
- paths 能递归一层嵌套列出差异路径，超过 20 条截断并标 truncated。
- diff 用 -/+ 双行标记期望与实际，summary 含差异数量。
- 对 null/undefined 给出可选链/接口漏字段的可执行建议。
- 非对象输入退化为 $ 单值比较，边界处理完整。
