## TST-815：笔试：手写一个「测试用例质量评分器」，基于行为覆盖与断言强度
**答**：
- 需求：实现 scoreTest(test) —— test 含 assertions 数组与 mocks 数量，输出 0-100 质量分与改进建议。
- 评分：每个「行为断言」+20 分（断言 expect 真实输出），「快照断言」+5 分，「恒真断言」-20 分，mock 超过 5 个每个 -2 分。
- 边界：无断言返回 0 分；分数钳制在 0-100；给出至少一条改进建议。

```javascript
function scoreTest(test) {
  const assertions = test.assertions || [];
  if (assertions.length === 0) return { score: 0, advice: ['无任何断言'] };
  const kindScore = { behavior: 20, snapshot: 5, truthy: -20 };
  let score = assertions.reduce((s, a) => s + (kindScore[a] ?? 0), 0);
  const extraMocks = Math.max(0, (test.mocks || 0) - 5);
  score -= extraMocks * 2;
  score = Math.max(0, Math.min(100, score));
  const advice = [];
  if (assertions.includes('truthy')) advice.push('删除 expect(true) 类恒真断言');
  if (extraMocks > 0) advice.push('mock 过多，考虑依赖注入');
  if (score < 40) advice.push('断言强度不足，补充行为断言');
  return { score, advice: advice.length ? advice : ['质量良好'] };
}
console.log(scoreTest({ assertions: ['behavior', 'behavior', 'truthy'], mocks: 7 }));
// { score: 100-20-4=76? -> 20+20-20-4=16, advice:[...] }

// 对照：全是行为断言、无多余 mock -> 满分
console.log(scoreTest({ assertions: ['behavior','behavior','behavior','behavior','behavior'], mocks: 2 }));
// { score: 100, advice: ['质量良好'] }
```
**评分点**：
- 按断言类型差异化计分（行为/快照/恒真），恒真断言扣分是核心考点。
- 分数钳制在 0-100，无断言返回 0，边界处理到位。
- mock 超量惩罚体现「过度 mock 是坏味道」。
- 输出可执行的改进建议，而不只是数字。
