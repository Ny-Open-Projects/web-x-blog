## TST-331：回归范围如何智能选择（全量跑不起，该怎么选）？
**答**：
- 变更影响图：代码 diff → 组件依赖图 → 受影响测试集（单测精确到模块，E2E 粗粒度）。
- 置信分层：影响图命中的必跑 + 抽样对照组（防漏）+ 夜间全量兜底。
- 历史加持：失败关联学习（历史上 X 变更常伴随 Y 测试失败）增强影响图。
- 度量漏检：线上缺陷回溯「本应命中的测试」，校准影响图。

```javascript
const impacted = impactGraph(diffFiles, depGraph)     // 精确集
  .concat(sample(allTests, 0.05));                     // 5% 随机对照
// 夜间全量兜底，影响图漏检回溯校准
r
```
