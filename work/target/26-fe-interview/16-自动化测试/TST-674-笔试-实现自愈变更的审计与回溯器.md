## TST-674：笔试：实现自愈变更的审计与回溯器

**题目**：实现 HealingAudit(limit)：record(e) 记录 {from,to,reason,ts} 并返回该 from 是否超限；trace(from) 按时间升序返回自愈历史 [{to,ts,reason}]。

**答**：
- 每次自愈记录 {from,to,ts,reason}，写入不可变日志。
- 提供 trace(selector) 返回该选择器的完整自愈历史。
- 同一 from 被改超过阈值时标记需人工确认。

```javascript
class HealingAudit {
  constructor(limit = 3) { this.log = []; this.limit = limit; }
  record(e) {
    this.log.push({ ...e, ts: e.ts || Date.now() });
    return this.needsReview(e.from);
  }
  needsReview(from) {
    return this.log.filter(e => e.from === from).length > this.limit;
  }
  trace(from) {
    return this.log.filter(e => e.from === from)
      .sort((a, b) => a.ts - b.ts)
      .map(e => ({ to: e.to, ts: e.ts, reason: e.reason }));
  }
}
```

**评分点**：
- 审计日志不可变（只追加）
- 超限判定准确
- 历史按时间排序
- 回溯信息完整
