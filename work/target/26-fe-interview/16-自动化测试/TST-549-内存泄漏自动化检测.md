## TST-549：前端内存泄漏如何自动化检测

**答**：
- 结论：核心方法是「重复操作 → 强制 GC → 比较堆快照」：若关键对象数量/堆大小随操作次数单调增长且不回落，则疑似泄漏。
- 做法：用 Playwright + CDP 采集 JS heap usedSize 与 DOM 节点数；执行 N 次打开/关闭弹窗等场景，每次后 GC；断言堆增长在阈值内；监听器/定时器泄漏用计数包装器检测。
- 追问钩子：GC 不稳定导致堆大小跳动怎么办？——看趋势而非单次差值（多次采样线性回归斜率），并固定环境、关闭无关扩展。

```javascript
// 内存泄漏趋势检测：多次操作后采样堆大小，看是否单调增长
function leakTrend(heapSamples, { growthLimit = 0.2 } = {}) {
  const first = heapSamples[0], last = heapSamples[heapSamples.length - 1];
  const growth = (last - first) / first;
  let monotonic = true;
  for (let i = 1; i < heapSamples.length; i++)
    if (heapSamples[i] < heapSamples[i - 1]) monotonic = false;
  return { growth: +growth.toFixed(3), monotonic,
    leaked: growth > growthLimit && monotonic };
}
console.log(leakTrend([100, 110, 125, 150])); // 疑似泄漏
```
