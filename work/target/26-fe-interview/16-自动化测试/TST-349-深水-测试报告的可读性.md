## TST-349：让测试报告「人人能看懂」的设计要点？
**答**：
- 失败摘要先行：一句话归因（「环境超时，非产品问题」）+ 证据链接。
- 归因分类标签：env/product/test 三色标记，看报告先看分布。
- 截图/trace/数据快照随条目内嵌（不用翻 artifact）。
- 面向角色：开发看技术细节，PM 看验收项状态——同一数据多视图。

const reportUX = {
  summary: 'one-line 归因 + evidence links',
  tags: { env: 'blue', product: 'red', test: 'yellow' },

  views: { dev: 'technical', pm: 'AC status' },
