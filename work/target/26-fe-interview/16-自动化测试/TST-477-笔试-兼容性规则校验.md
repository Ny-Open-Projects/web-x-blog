## TST-477：笔试：JSON Schema 演进的兼容性规则校验。
**答**：规则：新增字段必须非 required；删除 required 字段 = breaking；类型变化 = breaking。输入新旧 schema `{required: [], props: {}}`。实现 `schemaCompat(oldS, nextS)` 输出分类清单。

```javascript
function schemaCompat(oldS, nextS) {
  const out = [];
  for (const f of nextS.required || [])
    if (!(oldS.required || []).includes(f)) out.push({ kind: 'breaking', why: `新增必填字段 ${f}` });
  for (const f of oldS.required || [])
    if (!(nextS.required || []).includes(f) && nextS.props?.[f])
      out.push({ kind: 'breaking', why: `required 字段 ${f} 从必填列表移除但仍存在（语义模糊）` });
    else if (!nextS.props?.[f]) out.push({ kind: 'breaking', why: `字段 ${f} 被删除` });
  for (const [f, t] of Object.entries(nextS.props || {})) {
    const ot = oldS.props?.[f]?.type;
    if (ot && ot !== t) out.push({ kind: 'breaking', why: `字段 ${f} 类型 ${ot}→${t}` });
  }
  for (const [f, t] of Object.entries(nextS.props || {}))
    if (!oldS.props?.[f] && !(nextS.required || []).includes(f))
      out.push({ kind: 'compatible', why: `新增可选字段 ${f}:${t}` });
  return out;
}

```

**评分点**：
- 三规则逐一判定（证据带字段名）。
- required 交集差集计算。
- 类型变更检测（props[k].type）。
- 输出 breaking/compatible 两组。
