## TST-372：按风险驱动测试投入（不是平均用力）的具体方法？
**答**：
- 风险评分：业务影响（资金/体验）× 变更频率 × 历史缺陷密度。
- 资源映射：高风险域高覆盖 + 高频回归；低风险域抽测。
- 动态调整：风险评分季度重算（业务变化驱动投入变化）。
- 传达方式：风险热力图评审（业务/技术共同确认优先级）。

```javascript
const risk = (m) => m.bizImpact * 0.4 + m.churn * 0.3 + m.defectDensity * 0.3;
// risk > 0.7 → 深覆盖+每 PR 回归；< 0.3 → 季度抽测
r
```
