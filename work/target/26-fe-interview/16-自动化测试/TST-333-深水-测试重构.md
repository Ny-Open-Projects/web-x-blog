## TST-333：测试代码重构（不改变验证意图下提升可维护性）的路径？
**答**：
- 先锁行为：重构前全量跑绿（基线），重构后必须同样绿。
- 提取公共：重复 setup/断言抽 helper（按「验证意图」而非代码相似度抽）。
- 降级迁移：脆弱 E2E 内的断言下沉为 API/组件测试（原 E2E 简化）。
- 小步：每 PR 只重构一个域（登录相关），全绿合入。

```javascript
// 重构前基线锁定
git stash && npx playwright test --reporter=json > baseline.json
git stash pop && ...重构...
npx playwright test --reporter=json > after.json
// diff(baseline, after) 必须为空
r
```
