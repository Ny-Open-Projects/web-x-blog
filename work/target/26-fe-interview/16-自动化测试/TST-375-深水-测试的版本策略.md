## TST-375：测试代码与产品代码的版本/分支策略（同仓/分仓）？
**答**：
- 同仓同 PR：测试与代码同变更同评审（防测试过期）——默认推荐。
- monorepo 中测试随包走，共享测试工具独立包版本化。
- 分仓（仅测试）的坑：与代码版本对齐困难、联调成本高——仅在安全测试等特殊场景。
- 基线（快照）也随代码走同仓，更新即 PR。

```javascript
const branching = {
  default: 'same-repo same-PR（测试与实现同评审）',
  shared: '@org/test-kit 独立版本（semver）',
  anti: 'test-only repo（版本对齐地狱，除非特殊安全需求）',
};
```
