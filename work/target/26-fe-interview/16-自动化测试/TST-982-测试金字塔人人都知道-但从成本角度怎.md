## TST-982：测试金字塔人人都知道，但从成本角度怎么算出「最优分层比例」？
**答**：
- 结论：最优比例取决于各层的「单位成本」与「单位缺陷发现能力」——用 成本/发现缺陷数 的比值决定投入，而非照搬 70/20/10。
- 计算：单测便宜快但发现集成问题弱，E2E 贵慢但抓端到端问题；对每类历史缺陷算「在哪一层最早、最便宜被发现」。
- 动态调整：核心支付链路提高 E2E 比例，后台管理提高单测比例。
- 追问钩子：你们团队 80% 的线上缺陷是「接口字段对不上」，按成本最优该怎么调分层？

```javascript
function optimalLayerMix(bugs) {
  const layers = ['unit', 'integration', 'e2e'];
  const cost = { unit: 1, integration: 8, e2e: 40 }; // 相对成本
  const score = {};
  for (const l of layers) {
    const caught = bugs.filter(b => b.earliestDetectableLayer === l).length;
    score[l] = caught / cost[l]; // 每单位成本发现缺陷数
  }
  const total = Object.values(score).reduce((a, b) => a + b, 0);
  return Object.fromEntries(layers.map(l =>
    [l, +(score[l] / total * 100).toFixed(1)]));
}
const bugs = [
  { earliestDetectableLayer: 'integration' }, { earliestDetectableLayer: 'integration' },
  { earliestDetectableLayer: 'e2e' }, { earliestDetectableLayer: 'unit' },
];
console.log(optimalLayerMix(bugs));
// { unit:12.5, integration:50, e2e:37.5 } → 接口类缺陷多，重投集成层
```
