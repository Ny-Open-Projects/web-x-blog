## TST-637：笔试：实现测试可观测性指标采集器（分层聚合）

**题目**：实现 collect(records)。records=[{level:'platform'|'suite'|'case',ms,status}]。按 level 分组，统计 count/fail，耗时算 p50/p95（升序数组取分位），删除中间数组后输出。

**答**：
- 三层指标分别聚合：platform/suite/case，用命名空间前缀区分。
- 耗时类指标算 P50/P95，计数类算总和。
- 输出结构化对象，便于直接推监控系统。

```javascript
function collect(records) {
  const out = {};
  records.forEach(r => {
    const ns = r.level;
    out[ns] = out[ns] || { count: 0, durations: [], fail: 0 };
    out[ns].count++;
    out[ns].durations.push(r.ms || 0);
    if (r.status === 'fail') out[ns].fail++;
  });
  Object.values(out).forEach(x => {
    const s = x.durations.sort((a, b) => a - b);
    x.p50 = s[Math.floor(s.length * 0.5)] || 0;
    x.p95 = s[Math.floor(s.length * 0.95)] || 0;
    delete x.durations;
  });
  return out;
}
console.log(collect([{ level: 'suite', ms: 10, status: 'pass' }]));
```

**评分点**：
- 三层命名空间分组正确
- 分位数计算边界处理
- 计数与耗时分别聚合
- 输出无中间态可直接上报
