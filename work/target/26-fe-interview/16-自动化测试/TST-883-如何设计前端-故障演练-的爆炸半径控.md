## TST-883：如何设计前端「故障演练」的爆炸半径控制（不影响真实用户）？
**答**：
- 结论：爆炸半径控制的核心是「环境隔离 + 开关可控 + 快速回滚」——故障只在测试/灰度环境注入，且有一键停止的 kill switch。
- 环境隔离：只在测试环境或内部账号灰度注入，绝不对全量用户；用 feature flag 精确圈定注入范围。
- 开关可控：注入开关可秒级关闭；设自动熔断（错误率超阈值自动停止演练）。
- 时间窗口：限定演练时长，避开业务高峰；提前通知相关方。
- 追问钩子：演练时注入开关失效关不掉，你如何设计「第二道防线」？

```javascript
// 爆炸半径控制：feature flag + 自动熔断 + kill switch
class BlastRadius {
  constructor() { this.enabled = false; this.errorCount = 0; this.maxErrors = 5; }
  shouldInject(userId) {
    if (!this.enabled) return false;             // 总开关
    if (!this.internalUsers.has(userId)) return false; // 仅内部用户
    if (this.errorCount >= this.maxErrors) { this.enabled = false; return false; } // 自动熔断
    return true;
  }
  kill() { this.enabled = false; } // 一键停止（第二道防线可独立触发）
  internalUsers = new Set(['u_internal_1', 'u_internal_2']);
}
const blast = new BlastRadius();
blast.enabled = true;
console.log(blast.shouldInject('u_internal_1'), blast.shouldInject('u_normal'));
```
