## TST-536：笔试：笔试：多租户资源配额与公平调度

**题目**：实现 FairScheduler，管理多租户共享的测试执行槽位（capacity）。接口：request(tenant) 尝试分配一个槽位（成功 true/失败 false）；release(tenant) 释放；stats() 返回各租户使用量。规则：① 每个租户配额 quota（可不同）；② 总容量 capacity 上限；③ 公平性：任一租户使用量不得超过 min(自身配额, 总容量 - 其他租户最小保障)，防止饥饿；④ 用加权公平队列思想：超额时优先给「已用/配额比」最低的租户。给出可运行实现与边界处理。

**答**：
- 结论：按「已用/配额比」最小者优先分配，保证比例公平（max-min fairness 的近似）。
- 实现要点：统计各租户 usage 与总量；request 时若总量未满，选 ratio 最小且未超配额的租户分配；release 递减；stats 输出快照。
- 追问钩子：突发大租户会饿死小租户吗？——比例公平保证小租户总能在轮到自己时拿到份额；可再加「最小保障配额」进一步兜底。

```javascript
class FairScheduler {
  constructor(capacity, quotas) { this.capacity = capacity; this.quotas = quotas; this.usage = {}; }
  get total() { return Object.values(this.usage).reduce((a, b) => a + b, 0); }
  request(tenant) {
    const quota = this.quotas[tenant] ?? 0;
    if (quota <= 0 || this.total >= this.capacity) return false;
    const used = this.usage[tenant] || 0;
    if (used >= quota) return false;
    // 比例公平：确认该租户当前 ratio 是否为候选中最低
    const ratio = used / quota;
    const othersHaveRoom = Object.keys(this.quotas).some(t => {
      const u = this.usage[t] || 0, q = this.quotas[t];
      return q > 0 && u < q && u / q < ratio;
    });
    if (othersHaveRoom) return false;            // 让 ratio 更低的先拿
    this.usage[tenant] = used + 1; return true;
  }
  release(tenant) { if (this.usage[tenant] > 0) this.usage[tenant]--; }
  stats() { return { ...this.usage, total: this.total }; }
}
```

**评分点**：
- 按已用/配额比最小者优先，体现比例公平。
- 总量不超过 capacity，单租户不超自身配额。
- request/release/stats 状态一致，边界（未知租户/配额0）安全。
- 能说明公平性设计（防饥饿/最小保障）的理由。
