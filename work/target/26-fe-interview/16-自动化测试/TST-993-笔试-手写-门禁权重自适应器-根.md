## TST-993：笔试：手写「门禁权重自适应器」——根据历史误报率动态调整各信号权重
**答**：
- 需求：实现 adaptWeights(signalStats, baseWeights)，signalStats = { signal: { falseAlarmRate, hitRate } }。
- 规则：误报率高（>0.3）的信号降权 50%，命中率高（>0.7）且误报低的升权 20%；归一化权重和为 1；返回 { weights, changes }。
- 边界：新信号无统计数据时用基础权重；所有信号都被降权时重新归一化不崩溃。

```javascript
function adaptWeights(stats, base) {
  const weights = { ...base }, changes = [];
  for (const [sig, s] of Object.entries(stats)) {
    if (s.falseAlarmRate == null || s.hitRate == null) continue;
    let w = base[sig] ?? 0;
    if (s.falseAlarmRate > 0.3) { w *= 0.5; changes.push(`${sig} 降权(误报高)`); }
    else if (s.hitRate > 0.7 && s.falseAlarmRate <= 0.1) {
      w *= 1.2; changes.push(`${sig} 升权(命中高误报低)`);
    }
    weights[sig] = w;
  }
  const sum = Object.values(weights).reduce((a, b) => a + b, 0) || 1;
  for (const k of Object.keys(weights)) weights[k] = +(weights[k] / sum).toFixed(3);
  return { weights, changes };
}
console.log(adaptWeights(
  { coverage: { falseAlarmRate: 0.5, hitRate: 0.8 }, flake: { falseAlarmRate: 0.05, hitRate: 0.9 } },
  { coverage: 0.5, flake: 0.5 }
).weights); // coverage 降权、flake 升权后归一化
```
**评分点**：
- 误报率>0.3 降权 50%，命中率高且误报低升权 20%。
- 权重归一化和为 1，全降权也不崩溃。
- 新信号无统计数据保留基础权重。
- changes 记录每次调整原因，可解释。
