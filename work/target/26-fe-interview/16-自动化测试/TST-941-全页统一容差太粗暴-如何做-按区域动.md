## TST-941：全页统一容差太粗暴，如何做「按区域动态容差」的视觉 diff？
**答**：
- 结论：不同区域对视觉变化的敏感度不同——文字/图标区用低容差（像素级），图片/广告位/渐变背景用高容差，按区域分别设定。
- 实现：给截图划分「敏感区/宽容区」坐标框，diff 时对不同区域应用不同 threshold，敏感区变化直接告警。
- 收益：既抓住按钮文字错位这类真回归，又不被广告轮播的像素抖动淹没。
- 追问钩子：大促主图是动态运营配置的，今天换成明天换，你怎么让它的变化不进告警但主图上的「立即抢购」按钮错位仍能抓住？

```javascript
const REGIONS = [
  { name: 'buy-button', box: [100, 200, 220, 260], threshold: 0.01 },  // 敏感
  { name: 'banner',     box: [0, 0, 750, 180],      threshold: 0.15 },  // 宽容
];
function diffWithRegions(base, current, regions = REGIONS) {
  const hits = [];
  for (const r of regions) {
    const [x1, y1, x2, y2] = r.box;
    const changed = countChangedPixels(base, current, x1, y1, x2, y2);
    const area = (x2 - x1) * (y2 - y1);
    const ratio = changed / area;
    if (ratio > r.threshold) hits.push({ region: r.name, ratio: +ratio.toFixed(3) });
  }
  return hits;
}
function countChangedPixels() { return 0; } // 实际接 pixelmatch
// 主图变化落在 banner 区、ratio<0.15 → 不告警；按钮错位落在 buy-button 区 → 告警
```
