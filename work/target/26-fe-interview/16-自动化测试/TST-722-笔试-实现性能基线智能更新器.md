## TST-722：笔试：实现性能基线「智能更新」器（区分真实优化与环境噪声）

**题目**：输入历史样本 history（数值数组，毫秒）与新样本 newVal。若 newVal 相对历史中位数下降超过 15%（真实优化），或历史样本数 < 5（样本不足），则更新基线为 newVal 与中位数的加权平均（权重 0.5）；否则基线保持中位数。返回 { baseline, updated, reason }。

**答**：
- 用中位数抗离群，避免单次抖动污染基线。
- 只认可「下降」为优化，上升不算；先判样本不足再判优化。
- 加权平均保留历史信息，避免基线被单次极值带偏。

```javascript
function median(arr) {
  const s = [...arr].sort((a, b) => a - b);
  const m = Math.floor(s.length / 2);
  return s.length % 2 ? s[m] : (s[m - 1] + s[m]) / 2;
}
function updateBaseline(history, newVal) {
  const base = median(history);
  if (history.length < 5) {
    return { baseline: +(base * 0.5 + newVal * 0.5).toFixed(1), updated: true, reason: '样本不足' };
  }
  if (newVal < base * 0.85) {
    return { baseline: +(base * 0.5 + newVal * 0.5).toFixed(1), updated: true, reason: '真实优化' };
  }
  return { baseline: +base.toFixed(1), updated: false, reason: '噪声或回归' };
}
console.log(updateBaseline([1000, 1050, 980, 1020, 1010], 700));
console.log(updateBaseline([1000, 1050, 980, 1020, 1010], 1300));
```

**评分点**：
- 中位数计算正确且抗离群
- 优化判定只认下降且阈值 15%
- 样本不足边界处理
- 加权平均实现正确
