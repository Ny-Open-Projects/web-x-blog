## TST-443：笔试：失败用例的「自动重开 issue」逻辑（去重/冷却）。
**题目**：规则：同一用例 24h 内不重复建 issue（冷却）；已 open 的复用（评论追加）。实现 `maybeCreateIssue(records, name)` 返回 `{action: 'create'|'comment'|'skip'}`。

```javascript
function maybeCreateIssue(openIssues, recentCreations, name, now = Date.now()) {
  const open = openIssues.find(i => i.test === name);
  const last = recentCreations.filter(i => i.test === name)
    .sort((a, b) => b.at - a.at)[0];
  if (open && last && now - last.at < 86_400_000) return { action: 'skip', issue: open.id };
  if (open) return { action: 'comment', issue: open.id };
  return { action: 'create', test: name };
}
console.log(maybeCreateIssue([{ id: 'I-1', test: 'pay.spec' }], [
  { test: 'pay.spec', at: Date.now() - 3_600_000 }], 'pay.spec').action); // skip（冷却中）

```

**评分点**：
- 冷却窗口判定（24h）。
- 复用已 open issue（评论而非新建）。
- skip 分支（冷却中且已 open）。
- 动作语义清晰可对接 issue API。
