## TST-792：笔试：实现质量事故的「多因归因」关联分析器（跨四类信号）

**题目**：输入信号数组 signals [{id, domain, at, strength}]（domain 为 'platform'|'perf'|'ai'|'chaos'），事故时间 incidentAt 与窗口 windowMs。找出窗口内（incidentAt-windowMs <= at <= incidentAt）的信号，按 domain 分组，计算每组总强度（strength 之和），返回按总强度降序的 [{domain, total, ids}]。空结果返回 []。

**答**：
- 先按窗口过滤信号，再按 domain 分组求和。
- 按 total 降序，相同按 domain 字典序。
- 窗口边界含等号。

```javascript
function analyzeSignals(signals, incidentAt, windowMs) {
  const inWindow = signals.filter(s =>
    s.at >= incidentAt - windowMs && s.at <= incidentAt);
  const groups = new Map();
  for (const s of inWindow) {
    if (!groups.has(s.domain)) groups.set(s.domain, { total: 0, ids: [] });
    const g = groups.get(s.domain);
    g.total += s.strength;
    g.ids.push(s.id);
  }
  return [...groups.entries()]
    .map(([domain, g]) => ({ domain, total: +g.total.toFixed(2), ids: g.ids }))
    .sort((a, b) => b.total - a.total || a.domain.localeCompare(b.domain));
}
console.log(analyzeSignals([
  { id: 's1', domain: 'perf', at: 900, strength: 3 },
  { id: 's2', domain: 'ai', at: 950, strength: 5 },
  { id: 's3', domain: 'perf', at: 1100, strength: 2 },
], 1000, 200));
```

**评分点**：
- 窗口过滤含边界正确
- 按 domain 分组求和正确
- 降序与稳定排序
- 空结果返回 []
