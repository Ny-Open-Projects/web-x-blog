## TST-917：笔试：手写「快照漂移检测器」——识别期望没变但快照被无意改写的提交
**答**：
- 需求：实现 detectDrift({ gitDiff, testFiles })，gitDiff 为 { file, added:[行], removed:[行] } 列表，testFiles 为当前用例对同一快照的期望序列化结果。
- 规则：若快照 removed/added 的差异可由 testFiles 重新序列化得到，则判为「合法更新」；若期望未变而快照变了，判为 drift 并列出文件。
- 边界：忽略仅注释变化；多用例共享同一快照文件时逐键比对。

```javascript
function detectDrift({ gitDiff, testFiles }) {
  const drifts = [];
  // testFiles: { 'sum 1': '3', 'tax 1': '0.06' } 期望键值
  const expectedKeys = new Set(Object.keys(testFiles));
  for (const d of gitDiff) {
    const changed = [...d.added, ...d.removed].join('\n');
    if (/^\s*\/\//m.test(changed) && !/exports\[/.test(changed)) continue;
    const keysInDiff = [...changed.matchAll(/exports\[`([^`]+)`\]/g)].map(m => m[1]);
    for (const k of keysInDiff) {
      if (!expectedKeys.has(k)) drifts.push({ file: d.file, key: k, reason: '用例已删除但快照残留' });
      else if (testFiles[k] !== extractValue(changed, k))
        drifts.push({ file: d.file, key: k, reason: '期望未变但快照值被改写' });
    }
  }
  return drifts;
}
function extractValue(text, key) {
  const m = text.match(new RegExp(`exports\[\`${key}\`\]\s*=\s*\`([\s\S]*?)\`;`));
  return m?.[1];
}
console.log(detectDrift({
  gitDiff: [{ file: 'a.snap', added: ['exports[`sum 1`] = `999`;'], removed: [] }],
  testFiles: { 'sum 1': '3' },
})); // [{ file:'a.snap', key:'sum 1', reason:'期望未变但快照值被改写' }]
```
**评分点**：
- 能区分「合法更新」（期望随代码变）与「drift」（期望没变快照却变）。
- 逐键比对共享快照文件，键提取用正则准确。
- 忽略纯注释变化，边界处理到位。
- 输出 drift 文件与键名、原因，可直接接入 CI 拦截。
