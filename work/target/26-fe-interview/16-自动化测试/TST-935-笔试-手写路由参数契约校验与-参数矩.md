## TST-935：笔试：手写路由参数契约校验与「参数矩阵」生成器，覆盖合法/非法/缺失三类输入
**答**：
- 需求：实现 genRouteCases(contract) 生成测试用例矩阵，contract = { required:[], types:{}, enums:{} }。
- 规则：为每个 required 字段生成「缺失」「类型错误」用例；为每个 enum 字段生成「合法值」「非法值」用例；返回 [{name, params, expectPass}]。
- 边界：types 中的 number 类型要把字符串数字视为类型错误；无字段时返回单条全合法用例。

```javascript
function genRouteCases(contract) {
  const { required = [], types = {}, enums = {} } = contract;
  const valid = {};
  for (const k of required) valid[k] = types[k] === 'number' ? 1 : 'ok';
  for (const k of Object.keys(enums)) valid[k] = enums[k][0];
  const cases = [{ name: '全合法', params: { ...valid }, expectPass: true }];
  for (const k of required) {
    const missing = { ...valid }; delete missing[k];
    cases.push({ name: `缺失-${k}`, params: missing, expectPass: false });
    const wrong = { ...valid, [k]: types[k] === 'number' ? 'not-num' : 123 };
    cases.push({ name: `类型错-${k}`, params: wrong, expectPass: false });
  }
  for (const [k, values] of Object.entries(enums))
    cases.push({ name: `枚举非法-${k}`, params: { ...valid, [k]: '__bad__' }, expectPass: false });
  return cases;
}
console.log(genRouteCases({ required: ['skuId'], types: { skuId: 'string' } }).length); // 3
```
**评分点**：
- 为 required 字段生成缺失与类型错误两类负向用例。
- 为 enum 字段生成合法与非法值用例。
- number 类型把字符串数字判为类型错误，符合契约语义。
- 空字段边界返回单条合法用例，不报错。
