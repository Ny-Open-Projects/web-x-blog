## TST-438：笔试：线上探针（定时冒烟）结果的可用性统计。
**答**：探针记录 `[{ts, ok, ms}]`。输出：成功率（窗口内）、P95 耗时、连续失败段（当前是否告警中）、可用性 SLA 达标（99%）。

```javascript
function probeStats(records, { windowMs = 3_600_000, sla = 0.99 } = {}) {
  const now = records[records.length - 1].ts;
  const win = records.filter(r => r.ts >= now - windowMs);
  const ok = win.filter(r => r.ok).length;
  const sorted = win.map(r => r.ms).sort((a, b) => a - b);
  const p95 = sorted[Math.floor(sorted.length * 0.95)] ?? 0;
  let streak = 0;
  for (let i = win.length - 1; i >= 0 && !win[i].ok; i--) streak++;
  return { successRate: win.length ? +(ok / win.length).toFixed(3) : 1,
           p95Ms: p95, failingStreak: streak,
           slaMet: (ok / Math.max(1, win.length)) >= sla, alerting: streak >= 3 };
}

```

**评分点**：
- 窗口统计（成功率/分位耗时）。
- 连续失败段检测（当前 streak）。
- SLA 判定（阈值可配）。
- P95 计算正确（排序取位）。
