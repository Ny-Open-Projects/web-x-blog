## TST-313：同质化测试数据掩盖 bug（全是标准中文名），如何保证多样性？
**答**：
- 数据剖面（profile）：多组配置（长文本/emoji/特殊字符/多语言）轮流应用。
- 组合遍历：关键字段的取值域做 pairwise 组合覆盖（性别×地区×会员等级）。
- 变异注入：随机加长/截断/空格/零宽字符——防校验漏洞。
- 多样性审计：定期检查测试库字段熵（多样性过低告警）。

```javascript
const profiles = [longText, emojiName, zeroWidth, i18nName];
test.each(profiles)('用户名剖面 %s 可正常注册', async (p) => {
  const u = UserBuilder.aUser().withProfile(p).build();
  await expect(register(u)).resolves.toBeTruthy();
});
```
