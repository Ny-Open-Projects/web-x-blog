## TST-859：笔试：手写一个「弱网模拟器」，模拟带宽/延迟/丢包对 fetch 的影响
**答**：
- 需求：实现 simulateWeakNetwork(fetchFn, { bandwidthKBps, latencyMs, lossRate }) —— 包装 fetchFn 注入延迟与丢包，返回新的 fetch。
- 规则：每次请求前等待 latencyMs；按 lossRate 概率随机抛「网络错误」；带宽限制通过延迟模拟（数据量/bandwidth）。
- 边界：参数非法（负数/lossRate>1）抛错；保留原 fetch 的入参与返回值语义。

```javascript
function simulateWeakNetwork(fetchFn, { bandwidthKBps = 100, latencyMs = 200, lossRate = 0 } = {}) {
  if (bandwidthKBps <= 0 || latencyMs < 0 || lossRate < 0 || lossRate > 1)
    throw new RangeError('非法弱网参数');
  return async (...args) => {
    await new Promise(r => setTimeout(r, latencyMs));
    if (Math.random() < lossRate) throw new Error('NetworkError: 模拟丢包');
    const res = await fetchFn(...args);
    // 按响应大小与带宽估算额外传输延迟（示意）
    const sizeKB = Number(res.headers?.get?.('content-length')) / 1024 || 10;
    const transferMs = (sizeKB / bandwidthKBps) * 1000;
    await new Promise(r => setTimeout(r, transferMs));
    return res;
  };
}
const weakFetch = simulateWeakNetwork(fetch, { bandwidthKBps: 50, latencyMs: 300, lossRate: 0.2 });
// weakFetch('/api') 可能抛错或显著变慢，用于测试前端弱网表现

// 用法：在测试里注入弱网后断言加载时长与降级提示
async function testWeakNet() {
  try { await weakFetch('/api/product'); }
  catch (e) { console.log('弱网下的错误提示应友好:', e.message); }
}
testWeakNet();
```
**评分点**：
- 包装 fetch 注入延迟/丢包，保留原语义，设计正确。
- 按带宽与响应大小估算传输延迟，模拟真实弱网。
- 参数非法抛错，边界健壮。
- 能点出「弱网模拟用于验证前端降级/重试/超时表现」这一测试目的。
