## TST-436：笔试：两次回归运行的「新增失败/已修复」diff。
**答**：两次运行失败集合 A（上次）与 B（本次）。输出 `{newFailures: B-A, fixed: A-B, persistent: A∩B}`；persistent 按失败次数持续轮数加权（输入 runs 历史可选）。

```javascript
function regressionDelta(prev, curr, runCounts = {}) {
  const p = new Set(prev), c = new Set(curr);
  return {
    newFailures: [...c].filter(x => !p.has(x)),
    fixed: [...p].filter(x => !c.has(x)),
    persistent: [...c].filter(x => p.has(x))
      .map(x => ({ test: x, rounds: (runCounts[x] || 2) })),
    summary: `新增失败 ${c.size - [...c].filter(x => p.has(x)).length}，修复 ${p.size - [...p].filter(x => c.has(x)).length}`,
  };
}

```

**评分点**：
- 集合差与交集（语义命名正确）。
- persistent 轮数统计（连续失败轮次）。
- newFailures 最紧急（新引入）。
- 输出 Markdown 摘要行。
