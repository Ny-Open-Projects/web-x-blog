## TST-244：受控/非受控双模式的组件如何测覆盖？
**答**：
- 两套用例：非受控验证「内部状态+onChange 回调」，受控验证「外部 value 驱动+onChange 上报」。
- 关键边界：受控下内部不持有状态（value 变化跟随 props），值变更被外部拒绝时 UI 保持。
- 混合用法（defaultValue+value）行为要有明确断言（以 value 为准）。
- 用例表驱动：模式 × 操作（输入/清空/重置）矩阵生成。

```javascript
test.each([
  ['uncontrolled', { defaultValue: 'a' }],
  ['controlled', { value: 'a' }],
])('%s 输入触发 onChange', (_mode, props) => {
  const onChange = vi.fn();
  render(<Input {...props} onChange={onChange} />);
  fireEvent.change(screen.getByRole('textbox'), { target: { value: 'ab' } });
  expect(onChange).toHaveBeenCalledWith('ab');
});
```
