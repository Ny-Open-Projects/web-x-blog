## TST-545：前端安全测试需要覆盖哪些方面

**答**：
- 结论：四层——注入（XSS）、请求伪造（CSRF）、依赖供应链（漏洞包）、数据与权限（敏感信息泄露/越权），再加上点击劫持、开放重定向等。
- 做法：XSS 用恶意输入断言不执行；CSRF 校验 token/Cookie SameSite；依赖用 SCA 工具（npm audit/OSV）扫描并做门禁；敏感数据检查 localStorage/日志/源码 map 是否泄露。
- 追问钩子：前端做这么多安全测试，和后端安全测试边界在哪？——前端负责「输入净化/输出编码/凭据保管/依赖安全」，后端负责「鉴权/数据校验/权限」，两边用契约测试对齐。

```javascript
// XSS 防护测试：注入 payload 后断言未产生可执行脚本
const xssPayloads = ['<img src=x onerror=alert(1)>', '<script>alert(1)</script>', 'javascript:alert(1)'];
function testXssSanitizer(render, sanitize) {
  return xssPayloads.map(payload => {
    const html = sanitize(payload);
    const safe = !/<script|onerror\s*=|javascript:/i.test(html);
    return { payload, html, safe, passed: safe && !html.includes('<img') };
  });
}
// 期望：sanitize 后不含可执行标签/属性
```
