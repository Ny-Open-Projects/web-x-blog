## TST-725：笔试：实现性能指标「降噪与异常检测」器（滑动窗口 + 3σ）

**题目**：给定指标序列 values 与窗口大小 window。对每个位置 i，用其前 window 个值计算均值 μ 与标准差 σ，若当前值 |v - μ| > 3σ 则标记为异常点。σ 为 0 时只有 v !== μ 才算异常。返回异常点索引数组。

**答**：
- 滑动窗口逐点计算，注意窗口不足时不判定。
- 标准差用总体标准差（除以 n），3σ 阈值。
- σ=0 的边界要单独处理，避免除零或误判。

```javascript
function detectAnomalies(values, window) {
  const out = [];
  for (let i = window; i < values.length; i++) {
    const w = values.slice(i - window, i);
    const mu = w.reduce((s, x) => s + x, 0) / window;
    const variance = w.reduce((s, x) => s + (x - mu) ** 2, 0) / window;
    const sigma = Math.sqrt(variance);
    const v = values[i];
    if (sigma === 0 ? v !== mu : Math.abs(v - mu) > 3 * sigma) out.push(i);
  }
  return out;
}
console.log(detectAnomalies([10, 11, 10, 11, 10, 500, 10, 11], 4)); // 含 5
```

**评分点**：
- 滑动窗口边界（i 从 window 开始）正确
- 均值与标准差计算正确
- 3σ 判定与 σ=0 边界处理
- 返回索引而非值
