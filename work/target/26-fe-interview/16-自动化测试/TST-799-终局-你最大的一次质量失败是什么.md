## TST-799：终局：面试官问「你最大的一次质量失败是什么」

**答**：
- 结论：要讲「真实的失败 + 清晰的归因 + 体系的改进」，避免甩锅或说「我没什么失败」；体现复盘能力与成长。
- 结构：背景与后果（坦诚）→ 根因（承认自己的判断失误）→ 改进（可量化的体系变化）→ 影响（后来如何避免同类问题）。
- 失败的「价值」在于催生了更好的机制，比如因一次漏测而建立了风险驱动选测门禁。
- 追问钩子：同样的失败如果现在再发生，你的体系能挡住吗？

```javascript
// STAR-L 复盘表达：情境-任务-行动-结果-教训
function failureStory(s) {
  return {
    situation: s.context,
    task: s.goal,
    action: s.myMistake,       // 坦诚自己的判断
    result: s.impact,
    lesson: s.systemFix,      // 落到体系改进
    measurable: s.metricAfter, // 量化改进
  };
}
console.log(failureStory({
  context: '大促前漏测支付链路', goal: '零故障发布',
  myMistake: '门禁只看覆盖率未看风险', impact: '资损 2 小时',
  systemFix: '建立风险驱动选测门禁', metricAfter: '逃逸率下降 60%',
}));
```
