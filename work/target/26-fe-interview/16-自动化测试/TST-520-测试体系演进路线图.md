## TST-520：如何从 0 规划测试体系的演进路线图

**答**：
- 结论：按「先止血、再基建、后优化」三阶段推进——先补核心链路的自动化与门禁止血，再建平台/数据/度量基建，最后做 AI/混沌/性能安全等优化。
- 每阶段要有可交付物与衡量指标：阶段一（逃逸 P0 归零、核心链路自动化覆盖），阶段二（CI 时长、flaky 率、自助率），阶段三（ROI、韧性分）。
- 追问钩子：老板只给一个季度怎么办？——聚焦阶段一 + 一个高价值专项（如契约测试），用单点突破的数据证明价值，再争取后续投入。

```javascript
// 演进路线图：阶段 -> 关键举措 -> 验收指标
const roadmap = [
  { phase: '止血', init: ['核心链路 E2E 自动化', '提测门禁'], kpi: '逃逸P0=0' },
  { phase: '基建', init: ['测试平台', '数据工厂', '度量看板'], kpi: 'CI时长-40%' },
  { phase: '优化', init: ['AI 归因', '混沌演练', '性能安全门禁'], kpi: 'ROI>1.5' },
];
function milestone(roadmap, phase) {
  const p = roadmap.find(x => x.phase === phase);
  return p ? `${p.phase}: ${p.init.join(' / ')} → ${p.kpi}` : '未知阶段';
}
console.log(roadmap.map(p => milestone(roadmap, p.phase)));
```
