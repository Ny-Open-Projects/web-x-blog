## TST-705：笔试：实现测试资产「孤儿用例」检测器

**题目**：输入用例数组 [{id, owner, assertions, lastRunAt, flakyCount}] 与当前时间戳 now（毫秒）。孤儿用例定义：无 owner、或断言数为 0、或超过 90 天未运行、或 flakyCount ≥ 10。输出按「危险分」降序的孤儿列表，危险分 = 命中条件数，需给出命中原因数组。

**答**：
- 四类信号独立判定，命中几个记几分，输出必须带原因便于治理。
- 时间阈值用天数换算成毫秒，注意边界。
- 排序稳定：相同分数按 id 字典序，便于复现。

```javascript
function findOrphans(cases, now) {
  const DAY = 86400000;
  const out = [];
  for (const c of cases) {
    const reasons = [];
    if (!c.owner) reasons.push('NO_OWNER');
    if (!c.assertions || c.assertions.length === 0) reasons.push('NO_ASSERT');
    if (now - c.lastRunAt > 90 * DAY) reasons.push('STALE');
    if (c.flakyCount >= 10) reasons.push('FLAKY');
    if (reasons.length) out.push({ id: c.id, score: reasons.length, reasons });
  }
  return out.sort((a, b) => b.score - a.score || a.id.localeCompare(b.id));
}
const now = Date.now();
console.log(findOrphans([
  { id: 'c1', owner: null, assertions: [], lastRunAt: now - 100 * 86400000, flakyCount: 12 },
  { id: 'c2', owner: 't', assertions: [1], lastRunAt: now, flakyCount: 0 },
], now)); // c1 score 4
```

**评分点**：
- 四类孤儿条件判定齐全
- 危险分与命中原因正确
- 时间阈值换算正确
- 排序稳定可复现
