## TST-913：笔试：手写一个「按依赖分组的软断言聚合器」，前一组失败则跳过依赖它的后续组
**答**：
- 需求：实现 groupSoftAssert(groups)，groups = [{ name, deps:[组名], run:()=>void }]，按依赖顺序执行。
- 规则：组内用软断言收集全部失败；若某组失败，所有 direct/间接依赖它的组标记 skipped 不再执行；最终返回 { passed, failed, skipped, failures }。
- 边界：检测循环依赖并抛错；deps 引用不存在的组视为配置错误。

```javascript
function groupSoftAssert(groups) {
  const byName = new Map(groups.map(g => [g.name, g]));
  for (const g of groups) for (const d of g.deps)
    if (!byName.has(d)) throw new Error(`未知依赖组 ${d}`);
  // 拓扑排序 + 环检测
  const order = [], state = new Map();
  const visit = (g, stack = []) => {
    if (state.get(g.name) === 'done') return;
    if (stack.includes(g.name)) throw new Error(`循环依赖: ${[...stack, g.name].join('->')}`);
    state.set(g.name, 'visiting');
    for (const d of g.deps) visit(byName.get(d), [...stack, g.name]);
    state.set(g.name, 'done'); order.push(g);
  };
  groups.forEach(g => visit(g));
  const failed = new Set(), results = { passed: [], failed: [], skipped: [], failures: [] };
  for (const g of order) {
    if (g.deps.some(d => failed.has(d))) { results.skipped.push(g.name); continue; }
    const errs = [];
    try { g.run((cond, msg) => { if (!cond) errs.push({ group: g.name, msg }); }); }
    catch (e) { errs.push({ group: g.name, msg: e.message }); }
    if (errs.length) { results.failures.push(...errs); results.failed.push(g.name); failed.add(g.name); }
    else results.passed.push(g.name);
  }
  return results;
}
const r = groupSoftAssert([
  { name: 'login', deps: [], run: soft => soft(false, '登录失败') },
  { name: 'cart', deps: ['login'], run: soft => soft(true, '') },
]);
console.log(r.skipped); // ['cart']
```
**评分点**：
- 拓扑排序保证依赖顺序，visit 中的 stack 能检测循环依赖并抛错。
- 失败组的 direct/间接依赖组被标记 skipped，不再执行。
- 返回 passed/failed/skipped/failures 四段结果，failures 带组名。
- deps 引用未知组视为配置错误，边界处理完整。
