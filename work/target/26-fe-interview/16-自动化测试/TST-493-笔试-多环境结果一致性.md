## TST-493：笔试：同一套件在多环境的结果一致性对比（staging vs prod-like）。
**题目**：两次运行结果 `[{name, status}]`。不一致用例 = 状态不同；输出环境差异嫌疑清单（staging 过 prod 挂 → 配置差异嫌疑最大）。

```javascript
function envDiff(staging, prodLike) {
  const s = new Map(staging.map(r => [r.name, r.status]));
  const out = [];
  for (const r of prodLike) {
    const st = s.get(r.name);
    if (st && st !== r.status)
      out.push({ name: r.name, staging: st, prod: r.status,
        suspect: r.status === 'fail' ? '高（prod-like 挂）：配置/数据差异嫌疑' : '中（仅 staging 挂）：环境噪声嫌疑' });
  }
  return out.sort((a, b) => (a.suspect.startsWith('高') ? 0 : 1) - (b.suspect.startsWith('高') ? 0 : 1));
}

```

**评分点**：
- 状态差异比对。
- 方向语义（staging 过/挂 × prod 挂/过 → 不同嫌疑）。
- 嫌疑排序（prod 挂优先——最严重）。
- 输出带两个环境的实际状态。
