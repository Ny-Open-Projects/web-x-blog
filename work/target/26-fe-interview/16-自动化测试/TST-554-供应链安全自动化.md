## TST-554：前端依赖供应链安全如何自动化

**答**：
- 结论：把 SCA（软件成分分析）做成流水线门禁：锁文件精确锁定版本、CI 扫描漏洞与许可证、关键包校验完整性（lockfile + hash）、限制新增依赖审批。
- 做法：用 osv-scanner/npm audit 定期扫描；区分直接/间接依赖与可修复性；对高危漏洞设 block；配合 dependabot/renovate 自动升级 PR；构建产物生成 SBOM。
- 追问钩子：传递依赖被污染（如事件型投毒）怎么防？——锁文件 + 完整性校验 + 安装脚本审计（npm 的 --ignore-scripts 审查），并对新版本引入做自动化行为检测。

```javascript
// 依赖变更门禁：新增/升级高风险依赖需审批
function dependencyReview(before, after, policy = { allowed: [], needReview: ['high', 'critical'] }) {
  const added = Object.keys(after).filter(p => !before[p]);
  const changed = Object.keys(after).filter(p => before[p] && before[p] !== after[p]);
  const flagged = [...added, ...changed].filter(p =>
    (after[p].severity && policy.needReview.includes(after[p].severity)) ||
    !policy.allowed.includes(p));
  return { flagged, needApproval: flagged.length > 0 };
}
console.log(dependencyReview({ lodash: '4.0' }, { lodash: '4.1', 'bad-pkg': '1.0' },
  { allowed: ['lodash'], needReview: ['high'] })); // flagged:['bad-pkg']
```
