## TST-346：「验收标准即可执行测试」的完整闭环如何搭？
**答**：
- 需求验收标准结构化（Gherkin）→ 关联到自动化用例（traceability）。
- PR 门禁按验收标准执行：变更影响的 AC 对应用例必须绿。
- 验收追溯：发布清单可列出「本版本 AC 全覆盖且全绿」。
- 缺口管理：无自动化覆盖的 AC 显式标记（手工验证项清单）。

```javascript
// AC → 用例追踪
const acMap = { 'AC-101': 'e2e/checkout.spec.ts#结算金额汇总' };
// 发布清单
```
