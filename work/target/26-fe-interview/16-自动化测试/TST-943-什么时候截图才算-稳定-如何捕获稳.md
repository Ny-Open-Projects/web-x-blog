## TST-943：什么时候截图才算「稳定」？如何捕获稳定帧而不是固定 sleep？
**答**：
- 结论：用「连续 N 帧像素一致」判定稳定，而非固定 sleep(N ms)——固定等待既不充分又浪费时间。
- 实现：间隔采样截图，比较相邻两帧差异，连续 2~3 帧 diff 低于阈值即认为稳定，超时则记录「始终不稳定」诊断。
- 配合：先等 document.fonts.ready、图片 decode、网络空闲，再进入稳定帧检测。
- 追问钩子：一个页面有无限循环的走马灯动画，你的稳定帧检测永远等不到一致，怎么办？

```javascript
async function waitStableFrame(page, { tries = 20, gap = 100 } = {}) {
  await page.evaluate(() => document.fonts.ready);
  let prev = null, stableCount = 0;
  for (let i = 0; i < tries; i++) {
    const buf = await page.screenshot(); // 返回 Buffer
    if (prev && pixelDiff(prev, buf) < 0.001) stableCount++;
    else stableCount = 0;
    if (stableCount >= 2) return { stable: true, frame: i };
    prev = buf;
    await page.waitForTimeout(gap);
  }
  return { stable: false, reason: '始终不稳定：检查无限动画/轮询接口' };
}
function pixelDiff(a, b) { return 0; } // 接 pixelmatch
// 无限走马灯 → 返回 stable:false 并给出诊断，而不是无限等待
```
