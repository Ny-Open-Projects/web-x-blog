## TST-282：如何用测试手段防止「长任务」（>50ms）回归？
**答**：
- Playwright + PerformanceObserver（longtask）统计页面内长任务数与总时长，超预算 fail。
- 典型长任务源：大 JSON 解析/同步排序/图片同步处理——专项用例注入大数据断言不超时。
- 调度改造验证：任务切片（scheduler.yield）后长任务指标改善的对照断言。
- 门禁分级：主交互路径长任务 0 容忍，边缘页面告警级。

```javascript
test('无长任务', async ({ page }) => {
  await page.goto('/list');
  const longTasks = await page.evaluate(() => new Promise<number>(res => {
    const obs = new PerformanceObserver(list => res(list.getEntries().length));
    obs.observe({ type: 'longtask', buffered: true });
    setTimeout(() => res(performance.getEntriesByType('longtask').length), 3000);
  }));
  expect(longTasks).toBe(0);
});
```
