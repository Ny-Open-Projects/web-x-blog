## TST-667：测试知识库的切块与新鲜度治理怎么做？

**答**：
- 结论：RAG 效果的上限由知识质量决定——切块保留「问题→根因→修法」三元组，过期条目降权。
- 按语义段落切而非固定字数，块头带标题路径与模块名作为上下文。
- 每条知识带 lastVerified 与 helpful 计数，超期未验证的降低召回权重。
- 追问钩子：知识库里两条互相矛盾的修法，检索到哪条？

```javascript
function chunkDocs(docs, { maxLen = 300 } = {}) {
  const out = [];
  docs.forEach(d => {
    const paras = d.body.split(/\n\s*\n/);
    paras.forEach((p, i) => out.push({
      id: `${d.id}-${i}`,
      text: `[${d.path}] ${p.slice(0, maxLen)}`,
      lastVerified: d.lastVerified,
      weight: freshness(d.lastVerified) * (d.helpful || 1),
    }));
  });
  return out;
}
function freshness(date) {
  const days = (Date.now() - new Date(date)) / 86400000;
  return Math.max(0.1, 1 - days / 365);
}
```
