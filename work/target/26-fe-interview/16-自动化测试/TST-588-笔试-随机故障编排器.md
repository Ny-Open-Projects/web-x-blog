## TST-588：笔试：笔试：随机故障编排器（故障预算 + 爆炸半径）

**题目**：实现 chaosOrchestrator(faults, config)。faults=[{id, severity:1~5, maxBlast:0~1}]。config={ budget:number（总严重度预算）, maxBlast:number（允许的最大爆炸半径）, rand:()=>number }。要求：① 随机打乱 faults（用注入 rand 做可测试的洗牌）；② 依次选取，若累计 severity<=budget 且该故障 maxBlast<=config.maxBlast 则纳入，否则跳过；③ 输出 {selected:[ids], usedBudget, totalBlast}（totalBlast 取所选故障 maxBlast 之和）；④ 边界：budget=0 返回空，faults 为空返回空结构。

**答**：
- 结论：先可复现洗牌，再按预算与爆炸半径约束贪心选取。
- 实现要点：Fisher-Yates 洗牌用注入 rand；累计 severity 不超 budget；单故障 maxBlast 不超全局 maxBlast；统计 usedBudget/totalBlast。
- 追问钩子：为什么要设爆炸半径？——限制单次实验影响范围（如只影响 1% 流量/单用户），把风险控制在可接受边界，是混沌安全的核心原则。

```javascript
function chaosOrchestrator(faults = [], config = {}) {
  const { budget = 0, maxBlast = 1, rand = Math.random } = config;
  const arr = [...faults];
  for (let i = arr.length - 1; i > 0; i--) {         // Fisher-Yates（可复现）
    const j = Math.floor(rand() * (i + 1));
    [arr[i], arr[j]] = [arr[j], arr[i]];
  }
  const selected = []; let usedBudget = 0, totalBlast = 0;
  for (const f of arr) {
    if (f.maxBlast <= maxBlast && usedBudget + f.severity <= budget) {
      selected.push(f.id); usedBudget += f.severity; totalBlast += f.maxBlast;
    }
  }
  return { selected, usedBudget, totalBlast: +totalBlast.toFixed(3) };
}
```

**评分点**：
- Fisher-Yates 洗牌使用注入 rand，可复现。
- 严重度预算与单故障 maxBlast<=全局上限双重约束正确。
- usedBudget/totalBlast 统计准确。
- budget=0 / faults 空等边界返回空结构。
