## TST-492：笔试：测试债（TODO 测试/skip）的登记与到期跟踪。
**题目**：债 `[{file, kind: 'skip'|'todo'|'weak-assert', addedAt, dueAt}]`。实现 `debts(due)`：逾期清单（dueAt < due）+ 即将到期（7 天内）；逾期按时间排序输出催办。

```javascript
function debts(items, due) {
  const over = items.filter(i => i.dueAt < due)
    .sort((a, b) => a.dueAt - b.dueAt)
    .map(i => ({ ...i, overdueDays: Math.floor((due - i.dueAt) / 86_400_000) }));
  const soon = items.filter(i => i.dueAt >= due && i.dueAt - due <= 7 * 86_400_000);
  const byKind = {};
  for (const i of items) byKind[i.kind] = (byKind[i.kind] || 0) + 1;
  return { over, soon, byKind };
}

```

**评分点**：
- 逾期/临期双清单。
- 排序（最早逾期优先）。
- kind 分布统计。
- 催办信息带逾期天数。
