## TST-499：笔试：五维成熟度评分（0-5）。
**答**：维度评分规则（各维度给判据函数）：分层/门禁/数据/稳定性/度量。总分 = 均值；输出雷达图数据与最弱维度。

```javascript
const DIMS = {
  layering: (s) => (s.hasUnit && s.hasE2E ? 3 : 1) + (s.hasComponent ? 1 : 0) + (s.hasContract ? 1 : 0),
  gates: (s) => (s.blockingUnit ? 3 : 1) + (s.gateDocs ? 1 : 0) + (s.gateMetrics ? 1 : 0),
  data: (s) => (s.hasFactory ? 3 : 1) + (s.nsIsolation ? 1 : 0) + (s.schemaLinked ? 1 : 0),
  stability: (s) => (s.flaky < 0.05 ? 3 : 1) + (s.rootCauseKB ? 1 : 0) + (s.quarantine ? 1 : 0),
  metrics: (s) => (s.hasBoard ? 3 : 1) + (s.roiReported ? 1 : 0) + (s.trendAlerts ? 1 : 0),
};
const ADVICE = { 1: '从标准模板起步', 3: '补专项与自动化', 5: '沉淀为平台能力' };
function maturity(signals) {
  const scores = Object.fromEntries(Object.entries(DIMS).map(([k, fn]) => [k, Math.min(5, fn(signals))]));
  const total = Object.values(scores).reduce((a, b) => a + b, 0) / Object.keys(scores).length;
  const weakest = Object.entries(scores).sort((a, b) => a[1] - b[1])[0];
  return { scores, total: +total.toFixed(1),
    next: `${weakest[0]}（${weakest[1]} 分）：${ADVICE[Math.ceil(weakest[1])] ?? '持续精进'}` };
}

```

**评分点**：
- 判据函数布尔→分数映射清晰。
- 总分均值 + 最弱维度诊断。
- 每维度给一句改进建议（对应分数段）。
- 输出可直接渲染雷达图。
