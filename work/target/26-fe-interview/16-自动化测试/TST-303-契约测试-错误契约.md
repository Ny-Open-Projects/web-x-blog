## TST-303：错误响应（4xx/5xx）也要进契约吗？怎么定义？
**答**：
- 必须：错误结构（code/message/retryable）是消费者处理逻辑的依赖——不契约化消费者只能瞎猜。
- 错误契约模式：统一 ErrorSchema（code 枚举/字段级错误明细）+ 状态码语义。
- 消费者测试覆盖错误路径：422 驱动表单错误展示、429 驱动退避重试。
- 提供者测试：每种业务错误都断言符合 ErrorSchema。

```javascript
const ErrorSchema = z.object({ code: z.string(), message: z.string(),
  retryable: z.boolean(), details: z.array(z.object({ field: z.string(), msg: z.string() })).optional() });
test('校验失败契约', async () => {
  const res = await provider.submitOrder({});
  expect(ErrorSchema.safeParse(await res.json()).success).toBe(true); // 错误结构契约
});
```
