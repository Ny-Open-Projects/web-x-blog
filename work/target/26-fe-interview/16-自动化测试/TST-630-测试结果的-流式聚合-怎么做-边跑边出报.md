## TST-630：测试结果的「流式聚合」怎么做（边跑边出报告）？

**答**：
- 结论：把报告从「结束后生成」改成「事件流驱动」——每个用例完成即发事件，聚合器增量更新。
- 乱序到达用时间戳 + 序号去重；进度用已完成/总数实时计算。
- 前端订阅 SSE/WebSocket 展示实时大盘，失败即刻推送。
- 追问钩子：分片重试导致同一用例上报两次，聚合层怎么保证幂等？

```javascript
function streamAggregate() {
  const seen = new Map();
  return {
    push(e) {
      const key = `${e.runId}:${e.caseId}:${e.seq}`;
      if (seen.has(key)) return;            // 幂等
      seen.set(key, e);
    },
    snapshot(runId, total) {
      const rows = [...seen.values()].filter(e => e.runId === runId);
      return { done: rows.length, total,
        progress: +(rows.length / total).toFixed(2),
        failed: rows.filter(e => e.status === 'fail').map(e => e.caseId) };
    },
  };
}
```
