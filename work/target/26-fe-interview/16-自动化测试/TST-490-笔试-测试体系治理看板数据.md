## TST-490：笔试：治理看板的四象限数据准备（稳定性/速度/覆盖/成本）。
**题目**：输入原始指标集。产出四象限各自的关键值与红黄绿状态（阈值表驱动）。

```javascript
const THRESH = {
  flaky: { red: 0.05, yellow: 0.02 },       // > 5% 红
  durationRatio: { red: 1.2, yellow: 1.0 }, // 超预算 20% 红
  covPassRate: { red: 0.7, yellow: 0.9 },
  costPerRun: { red: 5, yellow: 3 },
};
function statusOf(v, t) {
  if (v === undefined) return 'gray';
  return v >= t.red ? 'red' : v >= t.yellow ? 'yellow' : 'green';
}
function governanceBoard(m) {
  return {
    stability: { value: m.flakyRate, status: statusOf(m.flakyRate, THRESH.flaky) },
    speed: { value: m.durationRatio, status: statusOf(m.durationRatio, THRESH.durationRatio) },
    coverage: { value: m.covPassRate, status: m.covPassRate === undefined ? 'gray'
      : m.covPassRate < THRESH.covPassRate.red ? 'red' : m.covPassRate < THRESH.covPassRate.yellow ? 'yellow' : 'green' },
    cost: { value: m.costPerRun, status: statusOf(m.costPerRun, THRESH.costPerRun) },
  };
}

```

**评分点**：
- 四象限指标映射（每象限 ≥ 1 指标）。
- 阈值表驱动状态判定。
- 红/黄/绿输出（看板直接渲染）。
- 缺失指标标灰（数据缺口提示）。
