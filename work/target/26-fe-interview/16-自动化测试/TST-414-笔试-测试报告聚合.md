## TST-414：笔试：合并多分片测试结果为总报告（含分片归因）。
**答**：分片结果 `[{shard, results: [{name, status, ms}]}]`。聚合：同名用例多次出现（重跑）取最终状态；统计总数/通过率/总时长（并行取 max 分片时长而非求和）；失败清单带 shard。

```javascript
function mergeReports(shards) {
  const by = new Map();
  let wall = 0;
  for (const s of shards) {
    let shardMs = 0;
    for (const r of s.results) {
      shardMs += r.ms;
      by.set(r.name, { ...r, shard: s.shard });   // 重跑取最后
    }
    wall = Math.max(wall, shardMs);
  }
  const all = [...by.values()];
  const failed = all.filter(r => r.status !== 'pass');
  return { total: all.length, passRate: +(all.filter(r => r.status === 'pass').length / all.length).toFixed(2),
           wallMs: wall, failed: failed.map(f => `${f.name} (${f.shard})`) };
}

```

**评分点**：
- 重跑合并语义：按 name 保留最后一次结果。
- 总时长 = max(分片时长)（并行墙钟）而非总和——概念正确性。
- 失败清单带 shard 归因。
- 输出 Markdown 表格行。
