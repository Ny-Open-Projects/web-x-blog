## TST-336：无头浏览器测试的成本优化（CPU/内存/时长）？
**答**：
- 复用浏览器实例：同 worker 内 context 复用浏览器（Playwright 默认已做，避免自建多层）。
- 按需启动重功能：trace/video 只失败时开（retain-on-failure）。
- 资源画像：单用例 CPU 时间排行，优化重渲染页面（测试专用轻量模式）。
- 容器密度：单机容器数按内存预算（1-2GB/浏览器）不超卖。

```javascript
export default defineConfig({
  use: { trace: 'retain-on-failure', video: 'off' },  // video 默认关（最贵）
  workers: 4,
});
```
