## TST-798：笔试：实现质量体系「投入产出」的动态仿真器（蒙特卡洛简化版）

**题目**：输入每年投入 cost、每次事故损失 loss、事故年发生次数泊松近似参数 lambda(随投入下降：lambda = baseLambda * exp(-cost/scale))，仿真次数 trials。用固定种子的伪随机（LCG：seed=(seed*1664525+1013904223)>>>0，r=seed/2^32）生成泊松样本（简化：用 -ln(1-r) 累计直到超过 lambda 计数），计算平均年损失，返回 {avgLoss, netBenefit=avgLoss减少量-cost}。baseLambda 为无投入时的事故次数基准。

**答**：
- LCG 伪随机保证可复现。
- 泊松简化采样：累加指数分布样本直到超过 lambda。
- netBenefit = (baseLambda*loss) - avgLoss - cost。

```javascript
function simulateROI(cost, loss, baseLambda, scale, trials) {
  let seed = 42;
  const rand = () => { seed = (seed * 1664525 + 1013904223) >>> 0; return seed / 4294967296; };
  const lambda = baseLambda * Math.exp(-cost / scale);
  const poisson = (l) => {
    let n = 0, t = 0;
    while (true) { t += -Math.log(1 - rand()); if (t > l) break; n++; }
    return n;
  };
  let totalLoss = 0;
  for (let i = 0; i < trials; i++) totalLoss += poisson(lambda) * loss;
  const avgLoss = totalLoss / trials;
  return {
    avgLoss: +avgLoss.toFixed(1),
    netBenefit: +(baseLambda * loss - avgLoss - cost).toFixed(1),
  };
}
console.log(simulateROI(50, 100, 4, 100, 1000));
```

**评分点**：
- LCG 伪随机可复现
- 泊松简化采样正确
- lambda 随投入指数下降
- netBenefit 计算正确
