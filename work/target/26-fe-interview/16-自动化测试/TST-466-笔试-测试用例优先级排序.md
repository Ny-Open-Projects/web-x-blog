## TST-466：笔试：失败后的「修复优先级」排序（影响面×风险×时长）。
**题目**：失败用例 `[{name, coversUsers: number, risk, estMin}]`。优先级分 = coversUsers × riskWeight / estMin（性价比）。riskWeight: high=3/mid=2/low=1。输出排序与「预计总修复时长」。

```javascript
const RW = { high: 3, mid: 2, low: 1 };
function fixPriority(failures) {
  return failures.map(f => ({ ...f,
    score: +(f.coversUsers * (RW[f.risk] ?? 1) / Math.max(1, f.estMin)).toFixed(1) }))
    .sort((a, b) => b.score - a.score || b.coversUsers - a.coversUsers)
    .reduce((acc, f, i) => { acc.order.push(f.name); acc.totalMin = (acc.totalMin || 0) + f.estMin;
      return i === failures.length - 1 ? acc : acc; }, { order: [], totalMin: 0 });
}

```

**评分点**：
- 性价比公式（覆盖人数 × 风险 ÷ 修复时长）。
- riskWeight 映射与缺省处理。
- 排序 + 总时长汇总（排期参考）。
- 并列按 coversUsers 降序。
