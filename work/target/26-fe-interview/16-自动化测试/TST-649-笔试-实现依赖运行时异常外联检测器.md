## TST-649：笔试：实现依赖运行时异常外联检测器

**题目**：实现 detectEgress(calls,{whitelist,strict})。calls=[{pkg,host}]。域名在 whitelist[pkg] 内则放行；否则每个 (pkg,host) 只报一次，strict 包 severity=block，其余 warn。

**答**：
- 记录每个包的出网域名集合，与白名单比对。
- 新出现的域名视为异常；支持按包设置宽松/严格模式。
- 输出 {pkg,host,severity}，严格模式直接阻断。

```javascript
function detectEgress(calls, { whitelist = {}, strict = [] } = {}) {
  const seen = new Map();
  const out = [];
  calls.forEach(c => {
    const allow = whitelist[c.pkg] || [];
    if (allow.includes(c.host)) return;
    const key = `${c.pkg}|${c.host}`;
    if (seen.has(key)) return;
    seen.set(key, true);
    out.push({ pkg: c.pkg, host: c.host,
      severity: strict.includes(c.pkg) ? 'block' : 'warn' });
  });
  return out;
}
console.log(detectEgress([{ pkg: 'ui-kit', host: 'evil.test' }],
  { whitelist: { 'ui-kit': ['cdn.ok.test'] } }));
```

**评分点**：
- 白名单匹配准确
- 同名同域名去重
- 严格模式阻断语义
- 输出可解释
