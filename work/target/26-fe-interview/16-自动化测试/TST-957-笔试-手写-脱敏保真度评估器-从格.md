## TST-957：笔试：手写「脱敏保真度评估器」，从格式/值域/唯一性/关联四维打分
**答**：
- 需求：实现 evaluateFidelity(orig, masked, opts)，返回 { score, dims }，dims 含 format/domain/unique/relation 四项 0~1 分。
- 规则：format 按正则形态一致率；domain 按值域（min/max）偏差；unique 按唯一值数量比；relation 按外键关联保留率。score 为四项均值。
- 边界：任一数组为空该项记 1（无可比数据不扣分）；orig/masked 字段缺失记 0。

```javascript
function evaluateFidelity(orig, masked, opts = {}) {
  const shape = v => typeof v === 'number' ? 'N' : String(v ?? '').replace(/\d/g, 'N');
  const oFmt = orig.map(shape), mFmt = masked.map(shape);
  const format = oFmt.length && mFmt.length
    ? oFmt.filter((v, i) => v === mFmt[i]).length / Math.max(oFmt.length, mFmt.length) : 1;
  const oNums = orig.filter(v => typeof v === 'number'), mNums = masked.filter(v => typeof v === 'number');
  const domain = oNums.length && mNums.length
    ? 1 - Math.min(1, Math.abs(Math.max(...oNums) - Math.max(...mNums)) / (Math.max(...oNums) || 1)) : 1;
  const uo = new Set(orig).size, um = new Set(masked).size;
  const unique = uo ? Math.min(1, um / uo) : 1;
  const relation = opts.relations ? opts.relations.filter(r => r(orig, masked)).length / opts.relations.length : 1;
  const dims = { format: +format.toFixed(2), domain: +domain.toFixed(2),
    unique: +unique.toFixed(2), relation: +relation.toFixed(2) };
  return { dims, score: +(Object.values(dims).reduce((a, b) => a + b, 0) / 4).toFixed(2) };
}
console.log(evaluateFidelity([13800000000], [138****0000].map(String)).dims.format > 0); // true
```
**评分点**：
- 从 format/domain/unique/relation 四维独立打分，score 为均值。
- format 用正则形态一致率，能识别格式漂移。
- unique 用唯一值数量比，防止脱敏把数据压成同一个值。
- 空数组/字段缺失边界处理正确，不误扣分。
