## TST-497：笔试：失败通知的路由规则（域 owner + 严重度通道）。
**答**：失败 `[{name, domain, critical}]` 与 owner 映射。路由：critical → IM 即时 + owner；普通 → 日报聚合。未映射域 → 平台组兜底（并告警映射缺口）。

```javascript
function routeFailures(failures, owners, platform = 'fe-platform') {
  const im = [], digest = [], unmapped = new Set();
  for (const f of failures) {
    const owner = owners[f.domain];
    if (!owner) unmapped.add(f.domain);
    if (f.critical) im.push({ to: owner ?? platform, name: f.name });
    else digest.push({ to: owner ?? platform, name: f.name });
  }
  return { im, digest,
    mappingGaps: [...unmapped] };
}
console.log(routeFailures([
  { name: 'pay.spec', domain: 'pay', critical: true },
  { name: 'ui.spec', domain: 'unknown', critical: false },
], { pay: 'team-pay' }).mappingGaps); // ['unknown']

```

**评分点**：
- owner 查找 + 兜底分支。
- critical 决定通道。
- 映射缺口告警（治理信号）。
- 输出路由结果聚合。
