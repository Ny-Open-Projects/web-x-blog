## TST-1000：笔试：终局综合题——手写一个「动态分级 + 弹性豁免 + 事后验证」的发布门禁闭环
**答**：
- 需求：实现 ReleaseGate()，提供 evaluate(signals)、bypass(releaseId, reason)、verify(releaseId, outcome) 三个方法。
- 规则：evaluate 按多维信号算风险分并定级（high→阻塞+全量回归，medium→增量校验，low→放行）；bypass 仅允许降级一档且记录审批与 24h 补测任务；verify 用实际结果回填漏放/误拦统计并给出调整建议。
- 边界：同一 releaseId 重复 evaluate 幂等；bypass 过期自动失效；verify 未知 releaseId 抛错。

```javascript
function ReleaseGate() {
  const decisions = new Map(), bypasses = new Map();
  const levelOf = s => {
    const score = (s.changeScope || 0) * 0.3 + (s.criticalPath ? 0.3 : 0) +
      (1 - (s.passRate ?? 0)) * 0.2 + (s.promoFreeze ? 0.2 : 0);
    return score >= 0.6 ? 'high' : score >= 0.3 ? 'medium' : 'low';
  };
  return {
    evaluate(id, signals) {
      if (decisions.has(id)) return decisions.get(id); // 幂等
      let level = levelOf(signals);
      const bp = bypasses.get(id);
      if (bp && bp.active && new Date(bp.expiresAt) > new Date())
        level = level === 'high' ? 'medium' : 'low'; // 仅降一级
      const d = { id, level, signals,
        actions: { high: ['阻塞','全量回归'], medium: ['增量校验'], low: ['放行'] }[level] };
      decisions.set(id, d); return d;
    },
    bypass(id, reason, approver) {
      if (!approver) throw new Error('豁免需审批人');
      bypasses.set(id, { reason, approver, active: true,
        expiresAt: new Date(Date.now() + 24 * 3600e3).toISOString(),
        compensation: `补测-${id}` });
      return true;
    },
    verify(id, outcome) {
      if (!decisions.has(id)) throw new Error(`未知发布 ${id}`);
      const d = decisions.get(id);
      const bad = outcome.defect || outcome.rollback;
      return { id, wasPassed: d.level === 'low',
        verdict: d.level === 'low' && bad ? '漏放' : d.level !== 'low' && !bad ? '误拦' : '正确' };
    },
  };
}
const gate = ReleaseGate();
console.log(gate.evaluate('r1', { changeScope: 1, criticalPath: true }).level); // 'high'
console.log(gate.verify('r1', { defect: false }).verdict); // '误拦'
```
**评分点**：
- evaluate 多维信号定级正确，同一 id 幂等返回。
- bypass 仅降一级、记录审批人与 24h 补测任务、过期失效。
- verify 用实际结果回填漏放/误拦/正确判定。
- 未知 releaseId 与无审批人豁免正确抛错，边界完整。
- 综合体现门禁「分级-豁免-事后验证」的闭环设计思想。
