## TST-135：笔试：为搜索联想框写完整测试（防抖 + 竞态 + MSW + 键盘）
**答**：
- 场景：输入关键词 300ms 防抖后请求 `/api/suggest`，展示联想列表；快速连续输入只发最后一次；响应乱序时丢弃过期结果；上下键选择 + Enter 上报。
- 考点组合：fake timers 控防抖、MSW 造响应与延迟、竞态丢弃验证（让旧请求更慢）、键盘交互。是组件测试里区分度最高的一类题。
- 竞态测试技巧：给「旧关键词」的 handler 加更长 delay——后发的请求先返回，验证 UI 最终显示的是最后输入关键词的结果。

```jsx
import { render, screen, waitFor } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { vi } from 'vitest';
import { http, HttpResponse, delay } from 'msw';
import { server } from '@/mocks/server';
import SearchBox from './SearchBox';

beforeEach(() => vi.useFakeTimers());
afterEach(() => { vi.useRealTimers(); server.resetHandlers(); });

test('防抖：300ms 内连续输入只发一次请求', async () => {
  const requests = [];
  server.use(http.get('/api/suggest', ({ request }) => {
    requests.push(new URL(request.url).searchParams.get('q'));
    return HttpResponse.json({ list: [] });
  }));
  render(<SearchBox />);
  const user = userEvent.setup({ advanceTimers: vi.advanceTimersByTime });

  await user.type(screen.getByRole('combobox'), 'ip'); // 三次按键
  expect(requests).toHaveLength(0);                    // 防抖期内未发
  await vi.advanceTimersByTimeAsync(300);              // 快进防抖
  expect(requests).toEqual(['ip']);                    // 只发最后一次
});

test('竞态：旧请求后返回时丢弃过期结果', async () => {
  server.use(
    http.get('/api/suggest', ({ request }) => {
      const q = new URL(request.url).searchParams.get('q');
      return delay(q === 'i' ? 500 : 50).then(() =>
        HttpResponse.json({ list: [{ text: `结果-${q}` }] }));
    }),
  );
  render(<SearchBox />);
  const user = userEvent.setup({ advanceTimers: vi.advanceTimersByTime });

  await user.type(screen.getByRole('combobox'), 'i');
  await vi.advanceTimersByTimeAsync(300);
  await user.clear(screen.getByRole('combobox'));
  await user.type(screen.getByRole('combobox'), 'iphone');
  await vi.advanceTimersByTimeAsync(300);

  await screen.findByText('结果-iphone');              // 新结果先到并渲染
  await vi.advanceTimersByTimeAsync(500);              // 旧结果迟到
  expect(screen.queryByText('结果-i')).toBeNull();     // 必须被丢弃
});

test('键盘：Enter 选中联想词', async () => {
  server.use(http.get('/api/suggest', () =>
    HttpResponse.json({ list: [{ text: 'iPhone 15' }] })));
  render(<SearchBox />);
  const user = userEvent.setup({ advanceTimers: vi.advanceTimersByTime });
  await user.type(screen.getByRole('combobox'), 'iphone');
  await vi.advanceTimersByTimeAsync(300);
  await screen.findByRole('listbox');
  await user.keyboard('{ArrowDown}{Enter}');
  expect(screen.getByRole('combobox')).toHaveValue('iPhone 15');
});
```

**评分点**：
1. fake timers 与 userEvent 的 advanceTimers 正确联动（不联动必挂）。
2. 竞态测试用「旧慢新快」的 delay 设计，断言过期结果被丢弃。
3. 请求次数断言验证防抖而非只验证 UI。
4. 覆盖键盘可访问性交互（加分项）。
