## TST-507：笔试：可配置的质量门禁规则引擎

**题目**：实现一个门禁规则引擎 evaluateGates(results, rules)。results 是指标集合；rules 为 [{metric, op, threshold, stage, enabled}]，op 支持 '>=' '<=' '=='。要求：① 只评估 stage 匹配且 enabled 的规则；② 任一失败则该 stage 阻塞；③ 输出每个 stage 的 pass 与失败原因；④ 支持白名单豁免（exemptions: [{metric, stage, expire}]），过期豁免无效。

**答**：
- 结论：引擎 = 规则过滤 + 算子求值 + 豁免判定 + 按 stage 聚合。把算子做成查表函数，便于扩展。
- 实现要点：先按 stage 过滤规则；对每条规则用 OPS[op] 求值；失败时查豁免（metric+stage 匹配且未过期）；聚合出每个 stage 的 pass 与 fails。
- 追问钩子：规则之间若互斥/冲突如何检测？——加一层规则静态校验（同 metric 同 stage 不允许阈值区间矛盾），在加载时报错。

```javascript
const OPS = {
  '>=': (v, t) => v >= t, '<=': (v, t) => v <= t, '==': (v, t) => v === t,
};
function evaluateGates(results, rules, stage, exemptions = []) {
  const now = Date.now();
  const applicable = rules.filter(r => r.stage === stage && r.enabled !== false);
  const fails = [];
  for (const r of applicable) {
    const ok = OPS[r.op](results[r.metric], r.threshold);
    if (ok) continue;
    const exempt = exemptions.some(e => e.metric === r.metric && e.stage === stage && e.expire > now);
    if (!exempt) fails.push(`${r.metric} ${r.op} ${r.threshold} 未满足(实际=${results[r.metric]})`);
  }
  return { stage, pass: fails.length === 0, fails };
}
const rules = [
  { metric: 'incCoverage', op: '>=', threshold: 0.7, stage: 'merge', enabled: true },
  { metric: 'securityP0', op: '<=', threshold: 0, stage: 'release', enabled: true },
];
console.log(evaluateGates({ incCoverage: 0.6 }, rules, 'merge'));
```

**评分点**：
- 算子查表实现，支持新增 op 易扩展。
- 按 stage + enabled 正确过滤规则。
- 豁免按 metric+stage 匹配且校验 expire，过期无效。
- 按 stage 聚合 pass/fails，失败原因可读。
