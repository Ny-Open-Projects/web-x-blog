## TST-482：笔试：浏览器环境池的预热与借用归还。
**答**：池 `{warm: number}`。`borrow()` 从池取（池空则现场冷启动，标记 cold）；`return(ctx)` 归还（池满销毁）；`stats()` 输出 warm/cold 比率（冷启动过多告警）。

```javascript
export function ctxPool(size) {
  const free = Array.from({ length: size }, (_, i) => ({ id: i }));
  let cold = 0, total = 0;
  return {
    borrow() {
      total++;
      const ctx = free.pop();
      if (!ctx) { cold++; return { id: `cold-${total}`, cold: true }; }
      return { ...ctx, cold: false };
    },
    ret(ctx) {
      if (ctx.cold) return;                       // 冷启动会话不回收（一次性）
      if (free.length < size) free.push(ctx);
    },
    stats() { return { warm: free.length, coldRatio: +(cold / Math.max(1, total)).toFixed(2),
      warn: cold / Math.max(1, total) > 0.3 ? '冷启动过多，考虑加大池容量' : null }; },
  };
}

```

**评分点**：
- 借用/归还状态管理。
- 冷启动计数（池容量规划依据）。
- 归还时池满销毁（防泄漏）。
- stats 暴露冷比率（阈值告警）。
