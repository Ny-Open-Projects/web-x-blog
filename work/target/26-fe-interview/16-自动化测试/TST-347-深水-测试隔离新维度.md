## TST-347：除并行隔离外，测试隔离还有哪些维度（时区/语言/权限）？
**答**：
- 时间：冻结时钟（时区固定 UTC+8 测试 + 时区专项用例）。
- 语言/locale：locale 固定 + i18n 矩阵抽测。
- 权限：测试账号角色固定，权限差异用例用角色矩阵。
- 网络：mock 层统一（禁真网），CDP 节流标准化。
- 原则：所有「环境随机性」显式固定，未知随机性（如内存地址）不进断言。

```javascript
test.use({ locale: 'zh-CN', timezoneId: 'Asia/Shanghai' });
// 随机性原则：Date.now/random → page.clock / faker.seed

```
