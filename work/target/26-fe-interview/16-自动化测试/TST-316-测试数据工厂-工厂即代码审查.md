## TST-316：数据工厂本身也需要测试与审查吗？
**答**：
- 需要：工厂 bug（默认值非法/关系错误）会污染全部用例——工厂自己要有单测（build 合法性 schema 校验）。
- 工厂变更评审：默认值变更影响面大，PR 必须全量冒烟。
- 工厂文档：每个变体一句话用途说明，防止重复造轮子。
- 反模式检测：lint 用例内手写大对象字面量（应走工厂）。

```javascript
test.each([GoodsBuilder.aGoods, OrderBuilder.anOrder])('%s 默认值合法', (f) => {
  const entity = f().build();
  expect(EntitySchema[entity.type].safeParse(entity).success).toBe(true);
});
```
