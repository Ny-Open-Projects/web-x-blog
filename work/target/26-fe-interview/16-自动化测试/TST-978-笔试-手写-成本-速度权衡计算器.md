## TST-978：笔试：手写「成本-速度权衡计算器」——在多个候选方案里选性价比最优解
**答**：
- 需求：实现 choosePlan(plans, cfg)，plans = [{ name, durationMs, costPerRun, flakeRisk }]，cfg = { maxBudget, maxDurationMs }。
- 规则：先过滤超预算/超时方案；在可行方案中按「性价比 = 1/(durationMs × (1+flakeRisk) × costPerRun)」取最高；无可行方案返回 null 与原因。
- 边界：flakeRisk 缺省 0；参数为 0 时避免除零。

```javascript
function choosePlan(plans, cfg = {}) {
  const { maxBudget = Infinity, maxDurationMs = Infinity } = cfg;
  const feasible = plans.filter(p => p.costPerRun <= maxBudget && p.durationMs <= maxDurationMs);
  if (!feasible.length) return { chosen: null, reason: '无方案满足预算/时长约束' };
  const scored = feasible.map(p => {
    const risk = p.flakeRisk ?? 0;
    const denom = (p.durationMs || 1) * (1 + risk) * (p.costPerRun || 1);
    return { ...p, score: +(1 / denom).toFixed(8) };
  }).sort((a, b) => b.score - a.score);
  return { chosen: scored[0].name, score: scored[0].score,
    candidates: scored.map(s => s.name) };
}
console.log(choosePlan([
  { name: '全量并行', durationMs: 60000, costPerRun: 2, flakeRisk: 0.1 },
  { name: '预热复用', durationMs: 90000, costPerRun: 0.5, flakeRisk: 0.02 },
], { maxBudget: 1, maxDurationMs: 120000 }).chosen); // '预热复用'
```
**评分点**：
- 正确过滤超预算/超时方案。
- 性价比公式含时长、风险、成本三因子，flakeRisk 缺省 0。
- 无可行方案返回 null 与原因，边界完整。
- 避免除零，按 score 降序返回全部候选。
