## TST-330：测试对「基础设施」的依赖（DB/缓存/第三方）如何治理？
**答**：
- 依赖显式声明（用例 needs: [postgres, redis-stub]），runner 按需起容器（testcontainers）。
- 第三方一律 stub：真实第三方的不稳定是测试不稳定的最大外部源。
- DB 用嵌入式/临时实例（每 run 独立），禁共享 DB 手工状态。
- 依赖健康预检：runner 起跑前检查依赖就绪，失败快速报错（不是跑到一半崩）。

```javascript
const { container } = await new PostgreSqlContainer().start();  // testcontainers
process.env.DATABASE_URL = container.getConnectionUri();
// 用例隔离：每 run 全新 DB，无共享状态

```
