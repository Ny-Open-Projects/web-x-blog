## TST-931：笔试：手写共享依赖「单实例检测」工具，扫描构建产物与运行时引用一致性
**答**：
- 需求：实现 checkSingleInstance({ modules, runtimeRefs })，modules 为 [{name,version}]，runtimeRefs 为 { key: ref }。
- 规则：同名依赖出现多个 version 判为多版本违约；runtimeRefs 中主子应用对同一 key 的引用不相等判为多实例违约。
- 边界：忽略 @types/* 与仅 dev 依赖；返回 { valid, multiVersion:[], multiInstance:[] }。

```javascript
function checkSingleInstance({ modules, runtimeRefs = {} }) {
  const multiVersion = [], multiInstance = [];
  const byName = new Map();
  for (const m of modules) {
    if (/^@types\//.test(m.name)) continue;
    if (!byName.has(m.name)) byName.set(m.name, new Set());
    byName.get(m.name).add(m.version);
  }
  for (const [name, versions] of byName)
    if (versions.size > 1) multiVersion.push({ name, versions: [...versions] });
  for (const [key, refs] of Object.entries(runtimeRefs)) {
    // refs: [mainRef, subRef, ...]
    if (refs.some(r => r !== refs[0])) multiInstance.push({ key, count: refs.length });
  }
  return { valid: !multiVersion.length && !multiInstance.length, multiVersion, multiInstance };
}
console.log(checkSingleInstance({
  modules: [{ name: 'react', version: '18.2.0' }, { name: 'react', version: '17.0.2' }],
  runtimeRefs: { react: ['mainRef', 'subRef'] },
}).multiVersion); // [{ name:'react', versions:['18.2.0','17.0.2'] }]
```
**评分点**：
- 能检测同名依赖多版本，忽略 @types/*。
- 能检测主子应用运行时引用不一致（多实例）。
- 输出结构化 multiVersion/multiInstance 便于 CI 拦截。
- valid 综合两类违约，边界完整。
