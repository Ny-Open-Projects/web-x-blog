## TST-765：笔试：实现故障注入脚本的「安全沙箱」校验器

**题目**：输入操作数组 ops [{type, target, magnitude}] 与策略 policy {allowedTargets:[...], maxMagnitude, forbiddenTypes:[...]}。校验：type 不在 forbiddenTypes、target 在 allowedTargets、magnitude <= maxMagnitude。返回 {allowed:[...], rejected:[{op, reasons:[...]}]}，reasons 取 'FORBIDDEN_TYPE'/'BAD_TARGET'/'OVER_MAGNITUDE'。

**答**：
- 三条规则逐条检查，收集全部原因。
- target 严格匹配白名单。
- 不修改原数组。

```javascript
function sandboxCheck(ops, policy) {
  const allowed = [], rejected = [];
  for (const op of ops) {
    const reasons = [];
    if (policy.forbiddenTypes.includes(op.type)) reasons.push('FORBIDDEN_TYPE');
    if (!policy.allowedTargets.includes(op.target)) reasons.push('BAD_TARGET');
    if (op.magnitude > policy.maxMagnitude) reasons.push('OVER_MAGNITUDE');
    if (reasons.length) rejected.push({ op, reasons });
    else allowed.push(op);
  }
  return { allowed, rejected };
}
console.log(sandboxCheck(
  [{ type: 'delay', target: 'api', magnitude: 500 }, { type: 'drop', target: 'db', magnitude: 9999 }],
  { allowedTargets: ['api'], maxMagnitude: 1000, forbiddenTypes: ['drop'] }
));
```

**评分点**：
- 三条规则检查齐全
- 原因枚举正确
- 不修改原数组
- 分组返回正确
