## TST-362：测试执行结果的缓存与增量（只跑受影响的）落地细节？
**答**：
- 键设计：测试文件 hash + 依赖（被测模块/配置）hash ——任一变更即失效。
- 失败重跑语义：失败结果不缓存（每次重跑），通过才缓存。
- 依赖图精度：文件级依赖粗（误失效多）、模块级精确（构建依赖图）。
- 缓存存储：CI 共享缓存（S3/Actions cache），命中即跳过执行。

```javascript
const cacheKey = hash(testFile + deps(testFile) + configHash);
if (cacheHit(cacheKey) && lastResult === 'pass') skip();
// 失败永不缓存
r
```
