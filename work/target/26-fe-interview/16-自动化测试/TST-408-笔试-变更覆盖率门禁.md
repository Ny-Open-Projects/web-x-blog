## TST-408：笔试：实现增量覆盖率门禁（只看 diff 行）。
**答**：输入 diff 行号（新文件视角）与执行记录。门禁：diff 中可执行行的覆盖率 ≥ 80% 通过；纯注释/空行不计。输出 `{ratio, uncovered, pass}`。

```javascript
function diffGate({ executableDiffLines, executedLines }, { threshold = 0.8 } = {}) {
  const exec = new Set(executedLines);
  const uncovered = executableDiffLines.filter(l => !exec.has(l));
  const ratio = executableDiffLines.length
    ? (executableDiffLines.length - uncovered.length) / executableDiffLines.length : 1;
  return { ratio: +ratio.toFixed(2), uncovered,
           pass: ratio >= threshold };
}
console.log(diffGate({ executableDiffLines: [10, 11, 12, 13, 14], executedLines: [10, 11, 12, 13] }));
// ratio 0.8 pass true

```

**评分点**：
- diff 行与执行记录对齐（新文件行号）。
- 不可执行行过滤（由调用方传入 executable diff 行）。
- 阈值可配置，边界（恰好 80%）算通过。
- 输出未覆盖行号（可执行）。
