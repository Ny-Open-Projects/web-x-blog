## TST-596：笔试：笔试：消息乱序/重复混沌生成器的结果校验

**题目**：承接消息混沌：实现 validateDelivery(input, output)。input=[{id, seq}] 原始有序消息；output=[{id, seq, duplicate?}] 经混沌（乱序/重复/丢弃）后的消息序列。要求：① 无重复：按 id 去重后输出应含唯一 id；② 顺序正确：去重后按 seq 升序应等于原始 seq 升序（丢弃的消息不算，即只校验「保留的消息相对顺序正确」）；③ 统计丢失数 lost = 原始 id 数 - 输出唯一 id 数；④ 输出 {noDup, ordered, lost, valid}（valid=noDup&&ordered）；⑤ 边界：input/output 空。

**答**：
- 结论：先按 id 去重得到唯一消息集，再检查相对顺序（seq 升序），最后统计丢失。
- 实现要点：去重用 Map（保留首次）；ordered 检查去重序列的 seq 是否非递减（相对顺序，不要求连续，因为可能有丢弃）；lost = 原始唯一数 - 输出唯一数。
- 追问钩子：为什么校验「相对顺序」而非「seq 连续」？——因为混沌允许丢弃消息，seq 会有空洞；客户端正确行为是按到达消息的 seq 排序展示，而非要求连续。

```javascript
function validateDelivery(input = [], output = []) {
  const uniq = new Map();
  for (const m of output) if (!uniq.has(m.id)) uniq.set(m.id, m);
  const msgs = [...uniq.values()];
  const noDup = msgs.length === new Set(output.map(m => m.id)).size;
  let ordered = true;
  for (let i = 1; i < msgs.length; i++) if (msgs[i].seq < msgs[i-1].seq) ordered = false;
  const origIds = new Set(input.map(m => m.id));
  const lost = origIds.size - new Set(msgs.map(m => m.id)).size;
  return { noDup, ordered, lost, valid: noDup && ordered };
}
```

**评分点**：
- 按 id 去重正确（保留首次），noDup 判定准确。
- ordered 检查去重后 seq 相对顺序（非递减），理解丢弃导致的空洞。
- lost 按原始唯一 id 与输出唯一 id 之差计算。
- valid 聚合正确，空输入边界安全。
