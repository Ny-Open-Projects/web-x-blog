## TST-529：大促回归如何在有限时间窗内跑完

**答**：
- 结论：「分层 + 分级 + 分片 + 错峰」组合拳——核心链路全量/高频，非核心按风险抽样；把回归拆成多批，提前几天滚动执行，发布窗口只跑增量与冒烟。
- 做法：基于变更影响面选用例（affected）；历史时长预测每片耗时并动态扩容 worker；设置回归「截止时间」倒排，超时自动降级为非关键跳过并告警。
- 追问钩子：最后一刻改了代码怎么办？——触发「增量回归」：只跑受影响模块的用例 + 核心冒烟，并对改动做风险评审决定是否延后发布。

```javascript
// 回归时间窗规划：按截止时间倒排，超预算时降级非关键用例
function planRegression(cases, { deadline, now = Date.now(), workerMs }) {
  const budget = deadline - now;
  const sorted = [...cases].sort((a, b) => (b.critical - a.critical) || (a.ms - b.ms));
  const keep = [], dropped = [];
  let used = 0;
  for (const c of sorted) {
    if (used + c.ms / workerMs <= budget) { keep.push(c); used += c.ms / workerMs; }
    else dropped.push(c);                    // 非关键/耗时过长被降级
  }
  return { keep: keep.map(c => c.name), dropped: dropped.map(c => c.name), used };
}
```
