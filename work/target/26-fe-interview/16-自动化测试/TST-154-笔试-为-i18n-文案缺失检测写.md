## TST-154：笔试：为 i18n 做文案完整性测试（key 缺失/占位符校验/伪本地化）
**答**：
- 需求：三道静态校验测试：① 所有语言包的 key 集合与基准语言（zh-CN）一致（缺 key = 上线显示 raw key）；② 占位符一致（`{name}` 在 en/ja 里数量与名称相同，缺失会渲染错乱）；③ t() 调用的 key 都存在于语言包（防手写错 key）。
- 附加：伪本地化（pseudo-localization）测试——把文案替换成「加长 + 特殊字符」版本渲染，验证 UI 不溢出、不截断（Intl 场景高频翻车点）。
- 技巧：语言包是 JSON 模块，直接 import 遍历；t() 调用扫描用 glob 读源码 + 正则提取（含嵌套路径 `t('user.profile.name')`）。

```javascript
import { readFileSync } from 'node:fs';
import { globSync } from 'glob';
import zh from '@/locales/zh-CN.json';
import en from '@/locales/en.json';
import ja from '@/locales/ja.json';

const flatten = (obj, prefix = '') =>
  Object.entries(obj).flatMap(([k, v]) =>
    typeof v === 'object' ? flatten(v, `${prefix}${k}.`) : [`${prefix}${k}`]);
const keys = (o) => new Set(flatten(o));

test('所有语言 key 与基准一致', () => {
  const base = keys(zh);
  for (const [name, pack] of [['en', en], ['ja', ja]]) {
    const missing = [...base].filter((k) => !keys(pack).has(k));
    const extra = [...keys(pack)].filter((k) => !base.has(k));
    expect(missing, `${name} 缺少 key`).toEqual([]);
    expect(extra, `${name} 多出 key`).toEqual([]);
  }
});

test('占位符在所有语言中一致', () => {
  const PH = /\{(\w+)\}/g;
  const base = keys(zh);
  for (const k of base) {
    const names = (s) => [...String(s).matchAll(PH)].map((m) => m[1]).sort();
    expect(names(zh[k]), `zh placeholder @${k}`).toEqual(names(en[k]));
    expect(names(zh[k]), `ja placeholder @${k}`).toEqual(names(ja[k]));
  }
});

test('源码中 t() 的 key 都存在', () => {
  const all = keys(zh);
  const files = globSync('src/**/*.{ts,tsx}');
  const bad = [];
  for (const f of files) {
    for (const m of readFileSync(f, 'utf8').matchAll(/\bt\(\s*['"]([^'"]+)['"]/g)) {
      if (!all.has(m[1])) bad.push(`${f}: ${m[1]}`);
    }
  }
  expect(bad).toEqual([]);
});
```

**评分点**：
1. 三个维度齐全：key 集合、占位符、t() 引用扫描。
2. 嵌套 key 的扁平化处理正确。
3. 断言消息标注语言与文件（失败可定位）。
4. 能提到伪本地化测 UI 溢出（国际业务加分项）。
