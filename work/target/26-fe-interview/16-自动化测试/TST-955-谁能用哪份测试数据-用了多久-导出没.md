## TST-955：谁能用哪份测试数据、用了多久、导出没导出——如何做全链路审计追踪？
**答**：
- 结论：给每份脱敏数据打「数据身份证」（datasetId + 脱敏规则版本），所有访问（查询/导出/下载）记审计日志且不可篡改。
- 要点：日志含 who/when/what/用途/审批单号；敏感数据导出需二次审批；日志写入只读存储并定期归档。
- 价值：出事可追溯、平时可发现异常访问（如某账号短时间批量导出）。
- 追问钩子：审计日志发现有人半夜导出了 10 万条脱敏后仍含明文手机号的数据，你怎么定位是脱敏规则漏了还是人为绕过？

```javascript
function accessLog({ user, action, datasetId, purpose, approvalId }) {
  const entry = {
    ts: new Date().toISOString(), user, action, datasetId, purpose, approvalId,
    hash: null,
  };
  entry.hash = hashChain(entry, LAST_HASH); // 链式哈希防篡改
  LAST_HASH = entry.hash;
  AUDIT_LOG.push(entry);
  return entry;
}
function detectAnomaly(logs) {
  const byUser = {};
  for (const l of logs) (byUser[l.user] ||= []).push(l);
  return Object.entries(byUser).filter(([, ls]) =>
    ls.filter(l => l.action === 'export').length > 5); // 短时间多次导出
}
let LAST_HASH = '0', AUDIT_LOG = [];
function hashChain() { return 'h_' + Math.random().toString(16).slice(2); }
accessLog({ user: 'alice', action: 'export', datasetId: 'D1', purpose: '联调', approvalId: 'A1' });
```
