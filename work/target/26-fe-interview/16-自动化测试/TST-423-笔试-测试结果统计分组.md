## TST-423：笔试：测试结果按「功能域」聚合统计（从用例名解析域）。
**题目**：用例名约定 `domain: scenario > case`。统计每域：总数/通过率/平均时长/最慢用例；域解析失败的归 other。

```javascript
function byDomain(results) {
  const g = new Map();
  for (const r of results) {
    const domain = r.name.includes(':') ? r.name.split(':')[0] : 'other';
    const s = g.get(domain) ?? { n: 0, pass: 0, ms: 0, slowest: { name: '', ms: 0 } };
    s.n++; s.pass += r.status === 'pass' ? 1 : 0; s.ms += r.ms;
    if (r.ms > s.slowest.ms) s.slowest = { name: r.name, ms: r.ms };
    g.set(domain, s);
  }
  return [...g].map(([d, s]) => ({ domain: d, n: s.n,
    passRate: +(s.pass / s.n).toFixed(2), avgMs: Math.round(s.ms / s.n),
    slowest: s.slowest }))
    .sort((a, b) => a.passRate - b.passRate);
}

```

**评分点**：
- 名称解析（冒号分割域）容错。
- 聚合指标（数/率/均值/最慢）。
- other 兜底组。
- 输出按通过率升序（差域在前）。
