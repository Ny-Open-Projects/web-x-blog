## TST-409：笔试：实现迷你变异引擎（算子/执行/存活判定）。
**答**：算子：`+→-`、`===→!==`、`&&→||`。对源码按位置生成变异体，逐个跑测试，测试失败 = 杀死（变异被捕获），通过 = 存活。输出 `{mutants, killed, score}`。

```javascript
const OPS = [[/\+/g, '-'], [/===/g, '!=='], [/&&/g, '||']];
function* mutants(src) {
  for (const [re, to] of OPS)
    for (const m of src.matchAll(re)) {
      yield src.slice(0, m.index) + to + src.slice(m.index + m[0].length);
    }
}
function mutationScore(src, runTests) {
  const all = [...mutants(src)];
  const survivors = all.filter(m => runTests(m).passed);
  return { mutants: all.length, killed: all.length - survivors.length,
           score: all.length ? +((all.length - survivors.length) / all.length).toFixed(2) : 0,
           survivors };
}
console.log(mutationScore('a + b === c && d', () => ({ passed: false })).score); // 1（全杀）

```

**评分点**：
- 算子逐位置生成（每个匹配点一个变异体），总数统计。
- score = killed / mutants（除零保护）。
- 存活变异体输出位置与算子（定位弱测试）。
- 性能说明：真实引擎并行 + 只跑相关测试（加分讨论）。
