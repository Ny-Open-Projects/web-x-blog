## TST-732：笔试：实现分层质量门禁的决策流水线（性能/安全/功能联合判定）

**题目**：输入 layers [{name, results:[{ok, severity}]}]，按层顺序执行，遇到第一个 severity='block' 且 ok=false 就短路返回 {pass:false, blockedAt:name}；若某层结果里有 ok=false 但 severity='warn'，记录警告但继续；全部通过返回 {pass:true, warnings:[...]}。

**答**：
- 分层顺序执行，阻断性失败立即短路。
- 警告累积不短路，最终随结果返回。
- 空结果层视为通过。

```javascript
function runPipeline(layers) {
  const warnings = [];
  for (const layer of layers) {
    for (const r of layer.results) {
      if (r.ok) continue;
      if (r.severity === 'block') return { pass: false, blockedAt: layer.name, warnings };
      warnings.push(`${layer.name}: 警告`);
    }
  }
  return { pass: true, warnings };
}
console.log(runPipeline([
  { name: '功能', results: [{ ok: true }] },
  { name: '性能', results: [{ ok: false, severity: 'warn' }] },
  { name: '安全', results: [{ ok: false, severity: 'block' }] },
]));
// {pass:false, blockedAt:'安全', warnings:['性能: 警告']}
```

**评分点**：
- 阻断失败短路正确
- 警告累积不短路
- 层顺序保持
- 返回结果结构完整
