## TST-517：多团队共用测试平台如何做质量治理

**答**：
- 结论：平台提供「统一基座 + 团队自治」——统一执行引擎、数据模型与门禁框架，各团队自定义用例与阈值；通过租户隔离与配额保证公平。
- 治理抓手：① 质量数据按团队/域打标，出团队看板与横向对比；② 门禁规则版本化，变更需评审；③ 设平台 SLO 与 oncall，平台本身也被测。
- 追问钩子：A 团队刷指标把 flaky 用例 skip 掉怎么管？——把 skip/豁免纳入审计与有效期，并在看板暴露「跳过率」作为反向指标。

```javascript
// 多租户质量看板：按团队聚合，暴露反向指标防刷分
function teamDashboard(runs, exemptions) {
  const byTeam = {};
  for (const r of runs) {
    const t = (byTeam[r.team] ||= { total: 0, pass: 0, skipped: 0 });
    t.total++; if (r.status === 'pass') t.pass++; if (r.status === 'skip') t.skipped++;
  }
  return Object.entries(byTeam).map(([team, v]) => ({
    team, passRate: +(v.pass / v.total).toFixed(3),
    skipRate: +(v.skipped / v.total).toFixed(3),   // 反向指标
    activeExemptions: exemptions.filter(e => e.team === team && e.expire > Date.now()).length,
  }));
}
```
