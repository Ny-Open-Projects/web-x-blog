## TST-425：笔试：失败产物（截图/trace）的命名与清理策略实现。
**题目**：命名规则：`{date}/{suite}/{test-slug}-{shard}-{attempt}.{ext}`。实现 `artifactName(test, meta)` 与 `cleanup(dir, {keepDays: 14})`（按日期目录删除过期）。

```javascript
function artifactName(test, { suite, shard, attempt, ext = 'png' }) {
  const date = new Date().toISOString().slice(0, 10);
  const slug = test.replace(/[^\w\u4e00-\u9fa5]+/g, '-').slice(0, 40);
  return `${date}/${suite}/${slug}-s${shard}-a${attempt}.${ext}`;
}
function cleanup(dir, { keepDays = 14, now = Date.now() } = {}) {
  const removed = [];
  for (const d of listDirs(dir)) {
    const ts = Date.parse(d);
    if (now - ts > keepDays * 86_400_000) { rm(dir + d); removed.push(d); }
  }
  return removed;
}

```

**评分点**：
- 命名各字段齐全（可归因 shard/attempt）。
- slug 归一（非法字符替换）。
- 清理按目录名日期解析（早于阈值删除）。
- 保留最近 N 次运行可选策略说明。
