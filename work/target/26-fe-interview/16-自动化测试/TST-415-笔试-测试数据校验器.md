## TST-415：笔试：数据工厂产出的实体合法性校验（防止坏数据进测试）。
**题目**：实体 schema（简化：`{field: {type, required, validate?}}`）。实现 `validate(entity, schema)`：类型检查/必填/自定义校验，返回错误清单（路径化）。

```javascript
function validate(entity, schema, path = '') {
  const errors = [];
  for (const [k, rule] of Object.entries(schema)) {
    const p = path ? `${path}.${k}` : k;
    const v = entity?.[k];
    if (v === undefined || v === null) {
      if (rule.required) errors.push(`${p} 必填缺失`);
      continue;
    }
    if (rule.type === 'array' && !Array.isArray(v)) errors.push(`${p} 应为 array`);
    else if (rule.type !== 'array' && typeof v !== rule.type) errors.push(`${p} 应为 ${rule.type}`);
    if (rule.validate && typeof v !== 'undefined' && v !== null) {
      const msg = rule.validate(v);
      if (msg) errors.push(`${p} ${msg}`);
    }
  }
  return errors;
}
const S = { price: { type: 'number', required: true, validate: v => v >= 0 || '价格非负' } };
console.log(validate({ price: -1 }, S)); // ['price 价格非负']

```

**评分点**：
- 类型检查（string/number/boolean/数组元素类型）。
- required 与缺省区分（null/undefined 都算缺）。
- 自定义 validate 函数错误信息透传。
- 路径化错误输出（field.sub）。
