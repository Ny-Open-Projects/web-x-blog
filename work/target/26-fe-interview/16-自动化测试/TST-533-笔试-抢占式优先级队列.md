## TST-533：笔试：笔试：测试任务抢占式优先级队列

**题目**：实现 PriorityQueue，支持：push(task)（task 含 id、priority 数值越小越高、enqueueAt）、pop()（取最高优先级，相同则先入先出）、promote(id, newPriority)（提升优先级，可能插队）、toArray()。要求底层用堆或有序数组实现，pop/push 复杂度优于 O(n)（若用有序数组插入为 O(n) 需说明）；边界：空队列 pop 返回 null，promote 不存在的 id 不报错。

**答**：
- 结论：用最小堆维护优先级，堆节点带序号戳实现 FIFO 稳定性；promote 时下沉/上浮调整。
- 实现要点：比较函数先比 priority 再比 seq；push 上浮、pop 下沉交换尾元素；promote 修改后按新优先级上浮（提升场景）。若用有序数组，插入 O(n) 需在答案中说明权衡。
- 追问钩子：为什么要 FIFO 稳定性？——相同优先级下保证先提交先执行，避免任务饥饿与结果不可预测。

```javascript
class PriorityQueue {
  constructor() { this.a = []; this.seq = 0; }
  #less(x, y) { return x.priority !== y.priority ? x.priority < y.priority : x.seq < y.seq; }
  #up(i) { while (i > 0) { const p = (i - 1) >> 1; if (!this.#less(this.a[i], this.a[p])) break;
    [this.a[i], this.a[p]] = [this.a[p], this.a[i]]; i = p; } }
  #down(i) { const n = this.a.length; while (true) { let s = i, l = 2*i+1, r = 2*i+2;
    if (l < n && this.#less(this.a[l], this.a[s])) s = l;
    if (r < n && this.#less(this.a[r], this.a[s])) s = r;
    if (s === i) break; [this.a[i], this.a[s]] = [this.a[s], this.a[i]]; i = s; } }
  push(task) { this.a.push({ ...task, seq: this.seq++ }); this.#up(this.a.length - 1); }
  pop() { if (!this.a.length) return null; const top = this.a[0], last = this.a.pop();
    if (this.a.length) { this.a[0] = last; this.#down(0); } return top; }
  promote(id, newPriority) { const i = this.a.findIndex(t => t.id === id); if (i < 0) return;
    this.a[i].priority = newPriority; this.#up(i); }
  toArray() { return [...this.a]; }
}
```

**评分点**：
- 最小堆实现，pop/push 复杂度 O(log n)。
- 比较函数含 seq，保证相同优先级 FIFO 稳定。
- promote 正确上浮调整且对不存在 id 安全。
- 空队列 pop 返回 null，边界处理完整。
