## TST-995：门禁等级和「发布频段」怎么联动？一天发 1 次和发 50 次能用同一套门禁吗？
**答**：
- 结论：不能一刀切——高频发布（一天多次）靠「小步快跑 + 强增量门禁 + 快速回滚」，低频发布（一周一次）可加全量回归与人工评审。
- 做法：门禁强度 ∝ 发布风险 × 发布间隔；高频发布必须配套自动回滚与灰度，否则一次坏发布影响面被放大。
- 指标：变更失败率与 MTTR 作为联动效果的验收指标。
- 追问钩子：团队从周发布改成日均 20 次，但门禁没变导致发布排队，你怎么调整？

```javascript
function gateForFrequency({ releasesPerDay, hasAutoRollback, canary }) {
  if (releasesPerDay <= 1) return {
    mode: 'full', gate: '人工评审 + 全量回归', rollback: '手动',
  };
  if (!hasAutoRollback) return {
    mode: 'blocked', reason: '高频发布必须先具备自动回滚能力',
  };
  return {
    mode: 'incremental',
    gate: '增量覆盖率 + 受影响用例 + 核心冒烟',
    canary: canary ? '灰度 5% → 全量' : '需接入灰度',
    rollback: '自动（基于 SLO 异常）',
  };
}
console.log(gateForFrequency({ releasesPerDay: 20, hasAutoRollback: true, canary: true }).mode);
// 'incremental'
```
