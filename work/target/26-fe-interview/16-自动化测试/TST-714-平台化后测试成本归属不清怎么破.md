## TST-714：平台化后测试「成本归属」不清怎么破：架构师的可观测性设计

**答**：
- 结论：成本要可归因，前提是所有测试请求都带「调用方标签」（团队/业务/用例），平台在入口处强制打标。
- 成本拆三类：计算资源时长、存储与产物、平台人力摊销，按比例分摊到团队账单。
- 账单要可下钻到用例级，让团队看到「哪条用例最贵」，才有优化动力。
- 追问钩子：共享的公共用例集该算在谁头上？

```javascript
// 测试成本归因
function attributeCost(events, pricePerMs) {
  const byTeam = {};
  for (const e of events) {
    const team = e.team || 'unattributed';
    byTeam[team] = (byTeam[team] || 0) + e.durationMs * pricePerMs;
  }
  const shared = (byTeam['unattributed'] || 0);
  return {
    teams: Object.fromEntries(Object.entries(byTeam).filter(([k]) => k !== 'unattributed')),
    shared: +shared.toFixed(2),
  };
}
console.log(attributeCost([
  { team: 'A', durationMs: 1000 }, { durationMs: 500 },
], 0.001));
```
