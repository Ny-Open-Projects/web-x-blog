## TST-953：笔试：手写一个可配置的「测试数据脱敏规则引擎」，支持字段级策略与顺序执行
**答**：
- 需求：实现 maskData(data, rules)，rules = [{ field, type, enabled, priority }]，type 支持 hash/mask/token。
- 规则：按 priority 升序执行；hash 截断 8 位、mask 保留后 4 位、token 生成 `TK_<hash>`；嵌套对象用点路径（user.phone）。
- 边界：字段不存在跳过；enabled=false 跳过；不修改原对象（深拷贝后处理）。

```javascript
function maskData(data, rules) {
  const out = structuredClone(data);
  const get = (o, p) => p.split('.').reduce((x, k) => x?.[k], o);
  const set = (o, p, v) => {
    const ks = p.split('.'), last = ks.pop();
    ks.reduce((x, k) => x[k], o)[last] = v;
  };
  const sorted = [...rules].filter(r => r.enabled !== false).sort((a, b) => a.priority - b.priority);
  for (const r of sorted) {
    const v = get(out, r.field);
    if (v == null) continue;
    let nv;
    if (r.type === 'hash') nv = hash(String(v)).slice(0, 8);
    else if (r.type === 'mask') nv = String(v).replace(/.(?=.{4})/g, '*');
    else if (r.type === 'token') nv = `TK_${hash(String(v)).slice(0, 8)}`;
    else continue;
    set(out, r.field, nv);
  }
  return out;
}
function hash(s) { let h = 0; for (const c of s) h = (h * 31 + c.charCodeAt(0)) >>> 0; return h.toString(16); }
const src = { user: { phone: '13800000000' } };
console.log(maskData(src, [{ field: 'user.phone', type: 'mask', priority: 1 }]).user.phone);
// '*******0000'（且 src 未被修改）
```
**评分点**：
- 按 priority 升序执行，enabled=false 跳过。
- hash/mask/token 三种策略实现正确，token 格式为 TK_<hash>。
- 支持点路径处理嵌套对象，字段不存在跳过。
- 深拷贝后处理，不修改原对象——关键边界。
