## TST-292：需要特定状态的数据（已支付订单/已发货）工厂如何表达？
**答**：
- 状态迁移封装：builder 内部按状态机调用业务操作（pay→ship），生成「真实到达该状态」的数据而非直接改 DB 状态。
- 直接改库的快捷档（速度优先）与业务路径档（真实优先）两档可选，默认业务路径。
- 状态不可达验证：非法状态组合在工厂层即报错（防测试数据本身就是错的）。
- 状态+时间：时间敏感状态（已过期券）配合冻结时钟生成。

```javascript
const paidOrder = await OrderBuilder.anOrder().withItems([g])
  .toState('paid');        // 内部走 create→pay 真实路径
const expiredCoupon = await CouponBuilder.aCoupon()
  .withClock(frozenTime).expired();            // 时间敏感
r
```
