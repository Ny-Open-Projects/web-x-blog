## TST-900：笔试：终局综合题——手写一个「前端混沌测试平台」最小核心（注入/编排/观测/回滚）
**答**：
- 需求：实现 ChaosPlatform() —— 提供 registerFault/enable/run/rollback 方法，先注册故障注入器，再开启演练，run 编排「注入→观测→判定」，异常自动回滚。
- 规则：run 先检查 enable 状态；执行故障注入并采集观测指标；按 policy 判定稳态；finally 中自动回滚所有已注入故障。
- 边界：未注册故障抛错；未 enable 时 run 返回 skipped；回滚失败记录但不掩盖主结果。

```javascript
function ChaosPlatform() {
  const faults = new Map();
  let enabled = false, active = [];
  return {
    registerFault(name, injector) { faults.set(name, injector); return this; },
    enable() { enabled = true; return this; },
    disable() { enabled = false; return this; },
    async run(faultName, { observe, steadyCheck }) {
      if (!faults.has(faultName)) throw new Error(`未注册故障 ${faultName}`);
      if (!enabled) return { status: 'skipped' };
      const result = { status: 'running', fault: faultName };
      try {
        const rollback = await faults.get(faultName)(); // 注入
        active.push(rollback);
        result.before = await observe();
        result.during = await observe();
        result.steady = steadyCheck(result.before, result.during);
        result.status = result.steady ? 'passed' : 'vulnerability-found';
      } catch (e) {
        result.status = 'aborted'; result.error = e.message;
      } finally {
        for (const rb of active.reverse()) {
          try { await rb(); } catch (e) { (result.rollbackErrors ||= []).push(e.message); }
        }
        active = [];
      }
      return result;
    },
  };
}
const cp = ChaosPlatform().registerFault('api-fail', () => { /* 注入 */ return async () => {}; }).enable();
```
**评分点**：
- 平台最小核心：注册/开关/编排/回滚四能力齐全，run 编排流程正确。
- finally 中自动回滚所有已注入故障，且回滚失败被记录不掩盖主结果——核心安全考点。
- 未注册抛错、未 enable 返回 skipped，边界完整。
- 综合体现混沌测试「可控、可观测、可回滚」的终局设计思想。
