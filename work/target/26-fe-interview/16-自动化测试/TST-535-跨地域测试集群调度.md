## TST-535：跨地域测试集群如何调度与降本

**答**：
- 结论：按「数据就近 + 错峰电价 + 故障域分散」调度。测试任务调度到目标用户所在地域以贴近真实网络，同时利用各地空闲/低价时段。
- 做法：地域标签路由（国内/海外用例分开跑）；多地域互为备份，单地域故障可转移；产物与结果汇总到中心；注意跨地域数据合规。
- 追问钩子：跨地域执行结果不一致（时区/语言/网络）怎么办？——统一测试时钟（UTC）、语言环境变量与网络基线，差异作为「地域专项」单独断言。

```javascript
// 地域调度：按用例标签选择执行区域，故障域分散
function scheduleRegion(cases, regions, health = {}) {
  const alive = regions.filter(r => health[r] !== 'down');
  const groups = {};
  for (const c of cases) {
    const region = c.region && alive.includes(c.region) ? c.region
      : alive[Math.abs(hashStr(c.id)) % alive.length];
    (groups[region] ||= []).push(c.id);
  }
  return groups;
}
function hashStr(s) { let h = 0; for (const ch of s) h = (h*31 + ch.charCodeAt(0)) | 0; return h; }
```
