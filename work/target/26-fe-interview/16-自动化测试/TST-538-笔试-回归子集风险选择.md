## TST-538：笔试：笔试：基于风险模型的回归子集动态选择

**题目**：实现 selectRegression(candidates, budget, history)。每个候选用例 {id, module, ms, baseRisk}；history 记录每个 module 近期的 {changeFreq, escapedDefects, passRate}。目标：在总时长 <= budget 内选出用例，使「风险覆盖」最大。风险分 = baseRisk × (1 + changeFreq×0.1 + escapedDefects×0.5) × (1 - passRate)。要求：① 按风险分/时长比贪心选择；② 必须包含所有 critical（baseRisk>=0.9）用例（即使超预算也要选并标记超额）；③ 输出 {selected, totalMs, overBudget}。

**答**：
- 结论：加权风险模型打分 + 性价比（风险/时长）贪心 + critical 强制纳入。
- 实现要点：先按 history 计算每用例风险分；critical 单独拎出；其余按 risk/ms 降序在剩余预算内选；最后合并并计算是否超额。
- 追问钩子：history 数据不全时怎么办？——缺失字段给保守默认值（如 changeFreq=1, escapedDefects=0, passRate=0.9），并对缺数据模块降权或告警。

```javascript
function selectRegression(candidates, budget, history = {}) {
  const scored = candidates.map(c => {
    const h = history[c.module] || { changeFreq: 1, escapedDefects: 0, passRate: 0.9 };
    const risk = c.baseRisk * (1 + h.changeFreq * 0.1 + h.escapedDefects * 0.5) * (1 - h.passRate);
    return { ...c, risk };
  });
  const critical = scored.filter(c => c.baseRisk >= 0.9);
  const rest = scored.filter(c => c.baseRisk < 0.9)
    .sort((a, b) => (b.risk / b.ms) - (a.risk / a.ms));
  const selected = [...critical];
  let totalMs = critical.reduce((s, c) => s + c.ms, 0);
  for (const c of rest) {
    if (totalMs + c.ms <= budget) { selected.push(c); totalMs += c.ms; }
  }
  return { selected: selected.map(c => c.id), totalMs, overBudget: totalMs > budget };
}
```

**评分点**：
- 风险分按 history 三因子正确计算，缺数据有默认兜底。
- critical 用例强制纳入并正确计算 overBudget。
- 非 critical 按 risk/ms 性价比贪心选，预算约束正确。
- 输出结构清晰（selected/totalMs/overBudget），可直接断言。
