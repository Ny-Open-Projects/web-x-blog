## TST-430：笔试：实现子应用 mount/unmount 的 window 键污染 diff。
**题目**：快照 window 自有键集合（mount 前/卸载后）。新增键 = 污染；卸载后仍存在（mount 期间新增未清理）= 残留。输出 `{addedDuring, residual}`。

```javascript
function pollutionDiff(before, during, after, whitelist = ['__POWERED_BY_QIANKUN__']) {
  const wl = new Set(whitelist);
  const addedDuring = [...during].filter(k => !before.has(k) && !wl.has(k));
  const residual = [...after].filter(k => !before.has(k) && !wl.has(k));
  return { addedDuring, residual,
    clean: residual.length === 0 };
}
// 用法：mount 前 snapshot → mount 后 snapshot → unmount 后 snapshot

```

**评分点**：
- 两次快照差集计算。
- addedDuring（mount 后新增）与 residual（卸载后残留）区分。
- 白名单豁免（框架固有键如 __POWERED_BY_QIANKUN__）。
- 输出键名清单（可定位）。
