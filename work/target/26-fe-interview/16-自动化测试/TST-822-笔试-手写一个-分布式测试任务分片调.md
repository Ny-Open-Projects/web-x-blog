## TST-822：笔试：手写一个「分布式测试任务分片调度器」，按文件哈希分片 + 失败重跑
**答**：
- 需求：实现 shardTests(files, shardCount, shardIndex) —— 用一致性哈希把测试文件分配到指定分片。
- 规则：hash(fileName) % shardCount === shardIndex 的文件归入本片；保证同一文件稳定落在同一片。
- 边界：支持 failedOnly 模式，仅返回上次失败的文件（传入 failedSet）；空文件列表返回空数组。

```javascript
function hashString(s) {
  let h = 0;
  for (let i = 0; i < s.length; i++) h = (h * 31 + s.charCodeAt(i)) >>> 0;
  return h;
}
function shardTests(files, shardCount, shardIndex, failedSet = null) {
  if (shardCount < 1 || shardIndex < 0 || shardIndex >= shardCount)
    throw new RangeError('非法分片参数');
  const pool = failedSet ? files.filter(f => failedSet.has(f)) : files;
  return pool.filter(f => hashString(f) % shardCount === shardIndex);
}
const files = ['a.test.ts','b.test.ts','c.test.ts','d.test.ts','e.test.ts'];
console.log('shard0:', shardTests(files, 3, 0));
console.log('重跑:', shardTests(files, 3, 0, new Set(['b.test.ts','d.test.ts'])));
// 同一文件总落在同一片；失败重跑只取失败文件

// 校验：全部分片并集应等于原集合（不重不漏）
const all = [0,1,2].flatMap(i => shardTests(files, 3, i));
console.log('覆盖完整:', new Set(all).size === files.length);
console.log('无重复:', all.length === files.length); // true
// 哈希取模用 >>> 0 保证无符号，避免负数取模导致分配错位
```
**评分点**：
- 用稳定哈希取模分片，保证同一文件始终落在同一分片（一致性）。
- failedOnly 模式仅重跑失败文件，支持「失败重跑」提效。
- 分片参数越界抛错，边界健壮。
- 能点出分片用于「多机并行 + 失败重跑」的平台化价值。
