## TST-419：笔试：探索性测试的会话记录器（操作流/发现/回放）。
**题目**：记录 `[{type, detail, ts}]`（navigate/click/find-bug）。实现 `session()` 返回：操作时间线、发现清单（find-bug 条目）、可回放步骤（navigate+click 序列化为脚本行）。

```javascript
function session() {
  const log = [];
  return {
    record(type, detail) { log.push({ type, detail, ts: Date.now() }); },
    report() {
      const sorted = [...log].sort((a, b) => a.ts - b.ts);
      const bugs = sorted.filter(e => e.type === 'find-bug')
        .map(b => ({ ...b, context: sorted.slice(0, sorted.indexOf(b))
          .filter(e => e.type !== 'find-bug').slice(-3) }));   // 前置 3 步
      const replay = sorted.filter(e => e.type !== 'find-bug')
        .map(e => e.type === 'navigate' ? `await page.goto('${e.detail}')`
          : `await page.click('${e.detail}')`);
      return { bugs, replay };
    },
  };
}

```

**评分点**：
- 时间线按 ts 排序输出。
- 发现条目关联到触发前的操作序列（归因上下文）。
- 回放序列化：每操作一行可执行伪代码。
- 清理：未关联发现的操作仍完整保留（审计）。
