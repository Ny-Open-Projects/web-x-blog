## TST-144：笔试：为倒计时秒杀按钮写测试（fake timers + 边界时刻 + 时区）
**答**：
- 场景：秒杀商品有开抢时间，倒计时到 0 时按钮从「未开始」变「立即抢购」。测试三件事：倒计时逐秒更新、到点按钮状态翻转（含边界 0/负数）、跨时区用户看到的截止时刻一致。
- 手段：`vi.useFakeTimers()` + `vi.setSystemTime` 设定「现在」，倒计时组件内部用 setInterval 或 rAF；到点翻转用 `advanceTimersByTimeAsync` 精确推进到临界值；时区场景组件用 UTC 时间戳计算，测试传相对时间（Date.now()+offset）而非字符串解析（规避时区陷阱）。
- 边界：到 0 后不能再减为负、服务端时间偏差校正接口（可选断言 clock offset 应用）。

```jsx
import { render, screen } from '@testing-library/react';
import { vi } from 'vitest';
import SeckillButton from './SeckillButton';

beforeEach(() => { vi.useFakeTimers(); });
afterEach(() => vi.useRealTimers());

test('倒计时逐秒更新，到点按钮翻转', async () => {
  vi.setSystemTime(new Date('2026-11-11T10:59:58'));   // 开抢前 2 秒
  const startAt = Date.now() + 2000;                    // 相对时间，无时区陷阱

  render(<SeckillButton startAt={startAt} />);
  expect(screen.getByRole('button')).toBeDisabled();
  expect(screen.getByText('00:02')).toBeInTheDocument();

  await vi.advanceTimersByTimeAsync(1000);              // 走 1 秒
  expect(screen.getByText('00:01')).toBeInTheDocument();
  await vi.advanceTimersByTimeAsync(1000);              // 到点
  const btn = screen.getByRole('button', { name: '立即抢购' });
  expect(btn).toBeEnabled();
});

test('到点后不会出现负数倒计时', async () => {
  vi.setSystemTime(new Date('2026-11-11T11:00:00'));
  render(<SeckillButton startAt={Date.now() - 5000} />); // 已经开抢
  expect(screen.getByRole('button', { name: '立即抢购' })).toBeEnabled();
  await vi.advanceTimersByTimeAsync(60000);              // 时间继续走
  expect(screen.queryByText(/^-/)).toBeNull();           // 无负数显示
  expect(screen.getByRole('button', { name: '立即抢购' })).toBeEnabled();
});
```

**评分点**：
1. fake timers + setSystemTime 组合，且开抢时间用相对偏移构造（时区安全）。
2. 精确推进到临界时刻验证翻转（不是粗略等 3 秒）。
3. 负数倒计时/已开抢边界覆盖。
4. 断言按钮可用性翻转 + 文案两处（状态机两态齐全）。
