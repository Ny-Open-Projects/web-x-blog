## TST-446：笔试：单个测试文件的断言强度评分（模式加权）。
**答**：模式分值：业务值断言（toBe/textContent 含具体值）3 分；存在性（toBeVisible）1 分；弱断言（toBeDefined）0 分。score = Σ分值 / 断言数 × 100 归一。

```javascript
const PATTERNS = [
  { re: /toBe\(|toHaveTextContent\(['"`][^'"`]+/, w: 3, kind: 'value' },
  { re: /toBeVisible\(\)|toBeInTheDocument\(\)/, w: 1, kind: 'exist' },
  { re: /toBeDefined\(\)/, w: 0, kind: 'weak' },
];
function assertionStrength(code) {
  let total = 0, sum = 0;
  const byKind = {};
  for (const line of code.split('\n')) {
    if (!/expect\(/.test(line)) continue;
    total++;
    for (const p of PATTERNS) if (p.re.test(line)) { sum += p.w; byKind[p.kind] = (byKind[p.kind] || 0) + 1; break; }
  }
  return { total, score: total ? Math.round(sum / total / 3 * 100) : 0, byKind };
}
console.log(assertionStrength(`
expect(x.price).toBe(100);
expect(y).toBeDefined();
`).score); // 50

```

**评分点**：
- 模式正则识别 + 分值表。
- 归一公式（0-100）。
- 弱断言清零贡献（拉低均分）。
- 输出分项计数（可诊断）。
