## TST-357：测试结果如何驱动发布决策（自动拦截/自动放行）？
**答**：
- 发布门禁矩阵：L1+L2core 全绿 → 自动放行灰度；高危域失败 → 拦截 + 通知 owner。
- 灰度期自动化验证：错误率/转化/性能指标达标自动放量（人可随时叫停）。
- 回滚触发：探针冒烟失败 + 错误率超阈值 → 自动回滚预案执行（预授权范围）。
- 审计：每次自动决策留证据链（指标快照）。

```javascript
const releaseGate = {
  promote: () => l1Green && coreGreen && rumOK,
  block: (f) => criticalDomainFail(f) && notifyOwner(f),
  rollback: { trigger: 'probe-fail + errRate>2%', authorized: 'pre-approved plan' },
};
```
