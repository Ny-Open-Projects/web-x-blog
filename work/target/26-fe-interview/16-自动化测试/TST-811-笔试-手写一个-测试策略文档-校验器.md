## TST-811：笔试：手写一个「测试策略文档」校验器，检查策略是否具备关键要素
**答**：
- 需求：实现 validateStrategy(doc) —— doc 是字符串对象，校验测试策略是否包含必备章节与可执行门禁。
- 必备要素：测试分层、工具选型、覆盖率目标、门禁规则、flaky 治理、发布准入；缺失项汇总返回。
- 边界：doc 非对象返回错误；章节内容空字符串视为缺失；大小写不敏感。

```javascript
const REQUIRED = ['测试分层', '工具选型', '覆盖率目标', '门禁规则', 'flaky', '发布准入'];
function validateStrategy(doc) {
  if (!doc || typeof doc !== 'object') throw new TypeError('doc 必须是对象');
  const keys = Object.keys(doc).map(k => k.toLowerCase());
  const missing = REQUIRED.filter(r =>
    !keys.includes(r.toLowerCase()) ||
    String(doc[r] ?? '').trim() === ''
  );
  return {
    valid: missing.length === 0,
    missing,
    score: Math.round(((REQUIRED.length - missing.length) / REQUIRED.length) * 100),
  };
}
console.log(validateStrategy({
  测试分层: '单测/集成/E2E', 工具选型: 'Vitest',
  覆盖率目标: '70%', 门禁规则: '覆盖率+flaky',
  // flaky 治理与发布准入缺失
})); // { valid:false, missing:['flaky','发布准入'], score:67 }

// 补齐后应为 valid:true、score:100
console.log(validateStrategy({
  测试分层: '单测/集成/E2E', 工具选型: 'Vitest', 覆盖率目标: '70%',
  门禁规则: '覆盖率+flaky', flaky: '治理机制', 发布准入: 'go/no-go',
}));
```
**评分点**：
- 必备要素清单覆盖测试策略核心章节，缺失检测正确（含空串判定）。
- 大小写不敏感处理。
- 对非对象输入抛错，边界健壮。
- 返回可执行的 score 与 missing，能体现「策略文档要可校验」的工程化思维。
