## TST-789：笔试：实现跨团队混沌实验的「资源冲突」调度器

**题目**：输入实验请求数组 reqs [{id, team, target, start, end}]（时间用毫秒），同一 target 的实验不能时间重叠。按 start 升序调度，冲突时优先级：team 为 'core' 优先，其次 start 早的优先。返回 {scheduled:[被调度的id], rejected:[被拒的id]}。已调度实验占据其 [start,end) 区间。

**答**：
- 按优先级排序（core 优先、start 早优先）。
- 逐个检查与已调度实验在时间上是否重叠且同 target。
- 冲突则拒绝，否则加入调度。

```javascript
function schedule(reqs) {
  const sorted = [...reqs].sort((a, b) =>
    (a.team === 'core' ? 0 : 1) - (b.team === 'core' ? 0 : 1) || a.start - b.start);
  const accepted = [];
  const scheduled = [], rejected = [];
  for (const r of sorted) {
    const conflict = accepted.some(a => a.target === r.target &&
      r.start < a.end && a.start < r.end);
    if (conflict) rejected.push(r.id);
    else { accepted.push(r); scheduled.push(r.id); }
  }
  return { scheduled, rejected };
}
console.log(schedule([
  { id: 'a', team: 'biz', target: 'api', start: 0, end: 100 },
  { id: 'b', team: 'core', target: 'api', start: 50, end: 150 },
]));
// core 先调度，biz 冲突被拒
```

**评分点**：
- 优先级排序正确
- 时间重叠判定正确（半开区间）
- 同 target 才冲突
- 调度/拒绝分组正确
