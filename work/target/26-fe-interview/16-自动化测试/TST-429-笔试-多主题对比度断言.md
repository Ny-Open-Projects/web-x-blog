## TST-429：笔试：实现 WCAG 对比度计算与批量断言。
**题目**：`contrastRatio(fg, bg)`：线性化 RGB → 相对亮度 → 比值（(L1+0.05)/(L2+0.05)）。批量断言 token 组合（AA ≥ 4.5 正文 / 3.0 大字）。

```javascript
function lum(hex) {
  const c = [1, 3, 5].map(i => parseInt(hex.slice(i, i + 2), 16) / 255)
    .map(v => v <= 0.03928 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4);
  return 0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2];
}
export function contrastRatio(fg, bg) {
  const [a, b] = [lum(fg), lum(bg)].sort((x, y) => y - x);
  return +(((a + 0.05) / (b + 0.05))).toFixed(2);
}
test.each([
  ['#FFFFFF', '#000000', 21], ['#777777', '#FFFFFF', 4.48],
])('%s/%s 对比度 %s', (f, b, e) => expect(contrastRatio(f, b)).toBe(e));
const assertAA = (fg, bg, large = false) =>
  contrastRatio(fg, bg) >= (large ? 3 : 4.5);

```

**评分点**：
- sRGB 线性化公式正确（≤0.03928 分支）。
- 相对亮度加权（0.2126/0.7152/0.0722）。
- 比值方向（亮者当 L1）。
- 分级阈值（正文/大字）应用。
