## TST-719：笔试：实现测试资产「厂商锁定风险」评估器

**题目**：输入用例数组 [{id, usesPrivateApi, format, runner}]。锁定风险判定：使用私有 API 记 3 分，格式为非开放格式（非 json/yaml/md）记 2 分，runner 为专有运行时记 2 分。总分 ≥ 5 为高风险，3~4 为中风险，其余低风险。输出按风险分降序，含每个用例的风险分与等级。

**答**：
- 三类信号加权求和，阈值分级。
- 输出必须含命中原因，便于针对性去锁定。
- 排序稳定，相同分按 id 排序。

```javascript
function assessLockIn(cases) {
  return cases.map(c => {
    let score = 0;
    const reasons = [];
    if (c.usesPrivateApi) { score += 3; reasons.push('PRIVATE_API'); }
    if (!['json', 'yaml', 'md'].includes(c.format)) { score += 2; reasons.push('CLOSED_FORMAT'); }
    if (c.runner === 'proprietary') { score += 2; reasons.push('PROP_RUNNER'); }
    const level = score >= 5 ? 'high' : score >= 3 ? 'medium' : 'low';
    return { id: c.id, score, level, reasons };
  }).sort((a, b) => b.score - a.score || a.id.localeCompare(b.id));
}
console.log(assessLockIn([
  { id: 'a', usesPrivateApi: true, format: 'json', runner: 'open' },
  { id: 'b', usesPrivateApi: true, format: 'bin', runner: 'proprietary' },
]));
```

**评分点**：
- 三类权重与阈值分级正确
- 命中原因完整
- 排序稳定
- 边界分（3、5）归属正确
