## TST-944：笔试：手写「动画稳定帧捕获器」，支持禁用动画与例外保留、连续帧一致性判定
**答**：
- 需求：实现 captureStable(page, opts)，先注入禁用 CSS 动画样式（保留 [data-keep-animation]），再连续截图判定稳定。
- 规则：连续 stableFrames 帧像素一致即返回成功；超时返回 { stable:false, samples }；须 await document.fonts.ready 与图片 decode。
- 边界：动画禁用样式必须在截图后清理（恢复原页面），不能污染后续测试；page 为 mock 对象，提供 screenshot/evaluate/waitForTimeout。

```javascript
async function captureStable(page, { stableFrames = 2, maxTries = 15 } = {}) {
  const CSS_ID = '__stable_css__';
  await page.evaluate((id) => {
    const style = document.createElement('style');
    style.id = id;
    style.textContent = `*,*::before,*::after{animation:none!important;transition:none!important}
      [data-keep-animation],[data-keep-animation]*{animation:revert!important}`;
    document.head.appendChild(style);
    return Promise.all([document.fonts.ready,
      Promise.all([...document.images].map(i => i.decode().catch(()=>{})))]);
  }, CSS_ID);
  let prev = null, count = 0; const samples = [];
  try {
    for (let i = 0; i < maxTries; i++) {
      const buf = await page.screenshot();
      samples.push(buf.length);
      if (prev && diff(prev, buf) === 0) count++; else count = 0;
      if (count >= stableFrames) return { stable: true, tries: i + 1 };
      prev = buf;
      await page.waitForTimeout(80);
    }
    return { stable: false, samples };
  } finally {
    await page.evaluate(id => document.getElementById(id)?.remove(), CSS_ID); // 清理
  }
}
function diff(a, b) { return a === b ? 0 : 1; }
```
**评分点**：
- 注入禁用动画 CSS 并保留 [data-keep-animation] 例外。
- 等待 document.fonts.ready 与图片 decode 后才采样。
- 连续 stableFrames 帧一致判定稳定，超时返回 samples 诊断。
- finally 中清理注入样式，不污染后续测试——关键边界。
