## TST-940：笔试：手写「截图稳定化处理器」——在 diff 前消除字体/动画/滚动条/时间带来的噪声
**答**：
- 需求：实现 stabilizeScreenshot({ html, css, now })，返回处理后的 { html, css } 用于截图。
- 规则：注入 CSS 禁用所有动画/过渡（animation:none;transition:none）；隐藏滚动条；把含 data-testid=time 的文本替换为固定时间；字体等待 document.fonts.ready。
- 边界：保留 data-keep-animation 的元素动画；不修改业务 DOM 结构；now 为 ISO 字符串用于替换时间。

```javascript
function stabilizeScreenshot({ html, css, now = '2026-01-01T00:00:00Z' }) {
  const stableCss = css + `
    *, *::before, *::after { animation: none !important; transition: none !important; }
    [data-keep-animation], [data-keep-animation] * { animation: revert !important; }
    ::-webkit-scrollbar { display: none !important; }
    html { scrollbar-width: none !important; }
  `;
  const stableHtml = html.replace(
    /(<[^>]*data-testid="time"[^>]*>)([^<]*)(<\/[^>]+>)/g,
    `$1${now}$3`
  );
  return { html: stableHtml, css: stableCss, waitFor: 'document.fonts.ready' };
}
// 使用：等待字体就绪后再截图
// await page.evaluate(() => document.fonts.ready);
const out = stabilizeScreenshot({
  html: '<span data-testid="time">14:32:01</span>',
  css: '.a{transition:all .3s}',
});
console.log(out.html); // <span data-testid="time">2026-01-01T00:00:00Z</span>
```
**评分点**：
- 注入 CSS 禁用动画/过渡/滚动条，并保留 data-keep-animation 例外。
- 把 data-testid=time 的文本替换为固定时间，消除时间噪声。
- 返回 waitFor=document.fonts.ready 要求等待字体就绪。
- 不修改业务 DOM 结构，边界处理完整。
