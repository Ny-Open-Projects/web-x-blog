## TST-700：笔试：整合题——实现一个前端混沌实验平台核心（注入 / 观测 / 止损 / 报告）

**题目**：实现 ChaosPlatform({injectors,hypothesis,killSwitch})。run({type,opts,metrics,durationMs})：killSwitch 拒绝则 blocked；调用注入器并记录 undo；校验 metrics 是否越界，越界则回滚所有注入并记 aborted；返回 {verdict,recovered,timeline}。

**答**：
- 四模块：Registry 管理注入器、SteadyMonitor 校验稳态、Breaker 负责止损、Reporter 汇总。
- 实验流程：check 稳态 → enable 注入 → 周期观测 → 越界止损 → 回滚 → 出报告。
- 每模块可单测，依赖通过参数注入。
- 报告含五件事：稳态结论、注入项、发现弱点、恢复耗时、是否可复现。

```javascript
class ChaosPlatform {
  constructor({ injectors, hypothesis, killSwitch = () => true }) {
    this.injectors = injectors; this.hypothesis = hypothesis;
    this.kill = killSwitch; this.active = []; this.timeline = [];
  }
  async run({ type, opts, metrics, durationMs = 5000 }) {
    const mod = this.injectors[type];
    if (!this.kill()) return { verdict: 'blocked' };
    const undo = mod.inject(opts);
    this.active.push({ undo });
    this.timeline.push({ type: 'injected', ts: Date.now() });
    const bad = Object.entries(this.hypothesis)
      .some(([k, r]) => metrics[k] < r.min || metrics[k] > r.max);
    if (bad) {
      this.active.forEach(a => a.undo()); this.active = [];
      this.timeline.push({ type: 'aborted', ts: Date.now() });
    }
    return {
      verdict: bad ? 'stopped' : 'stable',
      recovered: this.active.length === 0,
      timeline: this.timeline,
    };
  }
}
```

**评分点**：
- 四模块职责边界清晰
- 稳态越界自动止损与回滚
- killSwitch 熔断生效
- 时间线可复盘、每模块可单测
