## TST-149：笔试：为剪贴板复制功能写测试（权限降级 + execCommand 兜底）
**答**：
- 场景：分享链接复制按钮——优先 `navigator.clipboard.writeText`（需 HTTPS + 权限），不可用时降级 `document.execCommand('copy')`（非安全上下文），都失败提示手动复制。测试要覆盖三条路径。
- 手段：stub `navigator.clipboard`（jsdom 无）；writeText 抛 NotAllowedError 模拟权限拒绝；execCommand stub 返回 false 模拟不支持。成功路径还要断言「已复制」toast 与 clipboard 内容。
- 边界：clipboard.writeText 是异步的——断言前要 await；降级路径中 execCommand 需要选中文本（document.createRange），stub 环境里组件代码要有 try/catch 保护。

```jsx
import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import ShareButton from './ShareButton';

function stubClipboard({ writeResult = 'resolve' } = {}) {
  const writeText = vi.fn(() =>
    writeResult === 'reject'
      ? Promise.reject(new DOMException('NotAllowedError'))
      : Promise.resolve());
  Object.defineProperty(navigator, 'clipboard', {
    value: { writeText }, configurable: true,
  });
  return writeText;
}

afterEach(() => vi.unstubAllGlobals());

test('现代 API 可用：写入剪贴板并提示成功', async () => {
  const writeText = stubClipboard();
  render(<ShareButton link="https://shop.com/g/1" />);
  await userEvent.click(screen.getByRole('button', { name: '复制链接' }));

  expect(writeText).toHaveBeenCalledWith('https://shop.com/g/1');
  await screen.findByText('已复制');                    // await 异步 toast
});

test('clipboard 不可用：降级 execCommand 并成功', async () => {
  stubClipboard({ writeResult: 'reject' });            // 权限拒绝
  const exec = vi.fn().mockReturnValue(true);
  document.execCommand = exec;

  render(<ShareButton link="https://shop.com/g/1" />);
  await userEvent.click(screen.getByRole('button', { name: '复制链接' }));

  expect(exec).toHaveBeenCalledWith('copy');           // 走降级
  await screen.findByText('已复制');
});

test('两者都失败：提示手动复制', async () => {
  stubClipboard({ writeResult: 'reject' });
  document.execCommand = vi.fn().mockReturnValue(false);

  render(<ShareButton link="https://shop.com/g/1" />);
  await userEvent.click(screen.getByRole('button', { name: '复制链接' }));
  await screen.findByText(/请手动复制/);
  expect(screen.getByTestId('share-link')).toHaveTextContent('https://shop.com/g/1');
});
```

**评分点**：
1. 三条路径全覆盖：现代 API 成功 / 降级 / 全失败。
2. writeText 是异步的，断言 toast 前 await（findByText 而非 getByText）。
3. stub 用 configurable defineProperty 并在 afterEach 还原（隔离）。
4. 模拟权限拒绝用 DOMException（贴近真实错误类型）。
