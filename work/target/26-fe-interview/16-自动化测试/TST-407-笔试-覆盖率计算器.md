## TST-407：笔试：实现语句覆盖率计算（插桩 + 汇总）。
**题目**：输入执行记录 `[{file, executedLines: number[]}]` 与各文件总行数（可执行行集）。输出每文件覆盖率与全局覆盖率（可执行行加权），未覆盖行清单 topN。

```javascript
function coverage(files, records) {
  const rec = new Map(records.map(r => [r.file, new Set(r.executedLines)]));
  let total = 0, hit = 0; const missed = [];
  for (const f of files) {
    const s = rec.get(f.path) ?? new Set();
    total += f.executable.length;
    const miss = f.executable.filter(l => !s.has(l));
    hit += f.executable.length - miss.length;
    if (miss.length) missed.push({ file: f.path, lines: miss });
  }
  return { global: total ? +(hit / total).toFixed(3) : 0,
           missedTop: missed.sort((a, b) => b.lines.length - a.lines.length).slice(0, 5) };
}
console.log(coverage(
  [{ path: 'a.ts', executable: [1, 2, 3, 4] }],
  [{ file: 'a.ts', executedLines: [1, 2] }])); // 0.5

```

**评分点**：
- 覆盖率分母是「可执行行数」而非物理行数（注释/空行不算）。
- 全局覆盖率按行加权（不是文件平均）。
- 未覆盖行清单排序输出（便于补测）。
- 除零保护（空文件）。
