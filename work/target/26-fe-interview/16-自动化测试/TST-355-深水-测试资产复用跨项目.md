## TST-355：测试资产（工厂/工具/用例）跨项目复用的模式？
**答**：
- 共享包：数据工厂/测试工具抽成 npm 包（版本化，breaking 同语义化）。
- 用例模板：新项目脚手架内置标准分层模板（含门禁配置）。
- 案例库：失败案例与标准修法跨项目共享（组织级知识）。
- 复用度量：共享包被引项目数，驱动持续投入。

```javascript
// @org/test-kit（跨项目共享）
{ "exports": { "./factory": "./dist/factory.js",
               "./stable": "./dist/stable-shot.js", "./gates": "./dist/gates.json" } }
r
```
