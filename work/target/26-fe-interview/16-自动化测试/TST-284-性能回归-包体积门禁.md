## TST-284：构建产物体积门禁的实践细节？
**答**：
- size-limit / bundlesize 按入口（首屏/vendor/单组件）设上限，CI 阻塞。
- 新增依赖强制展示体积影响（PR 评论 gzip 增量），大依赖需审批。
- tree-shaking 验证：只 import 一个组件时产物不含其他组件代码（副作用标记正确性）。
- 趋势看板：体积随版本曲线，异常增长（> 5%/版本）需要解释。

```javascript
// package.json size-limit 配置
"size-limit": [
  { "path": "dist/index.js", "limit": "45 kB" },
  { "path": "dist/button.js", "import": "{ Button }", "limit": "8 kB" }
]

```
