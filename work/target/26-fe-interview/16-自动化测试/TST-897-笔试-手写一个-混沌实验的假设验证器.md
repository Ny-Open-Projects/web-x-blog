## TST-897：笔试：手写一个「混沌实验的假设验证器」（定义稳态→注入→观测→判定）
**答**：
- 需求：实现 runChaosExperiment({ hypothesis, inject, observe, steadyCheck }) —— 编排完整的混沌实验四步并返回结论。
- 规则：先观测基线稳态 → 注入故障 → 观测故障期间指标 → 用 steadyCheck 判定假设是否成立；不成立返回脆弱点。
- 边界：任一步抛错记录 step 错误并返回 aborted；必须保证故障可回滚（inject 返回 rollback 函数并调用）。

```javascript
async function runChaosExperiment({ hypothesis, inject, observe, steadyCheck }) {
  const result = { hypothesis, status: 'running', steps: [] };
  try {
    result.baseline = await observe();           // 1. 基线
    result.steps.push('observe-baseline');
    const rollback = await inject();             // 2. 注入
    result.steps.push('inject');
    try {
      result.during = await observe();           // 3. 观测
      result.steps.push('observe-during');
      result.steady = steadyCheck(result.baseline, result.during); // 4. 判定
      result.status = result.steady ? 'passed' : 'vulnerability-found';
    } finally {
      if (typeof rollback === 'function') await rollback(); // 必须回滚
      result.steps.push('rollback');
    }
  } catch (e) {
    result.status = 'aborted'; result.error = e.message;
  }
  return result;
}
// steadyCheck 比较注入前后稳态指标，false 即发现脆弱点
```
**评分点**：
- 四步编排（基线→注入→观测→判定）完整，结论可解释。
- 用 finally 保证故障回滚，即使观测/判定抛错也不遗留故障——核心安全考点。
- 任一步抛错记录 status:aborted，不静默失败。
- 能点出「混沌实验必须可回滚、可观测、可证伪」三大原则。
