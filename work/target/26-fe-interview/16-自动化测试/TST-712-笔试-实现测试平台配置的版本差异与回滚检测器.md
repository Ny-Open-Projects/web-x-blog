## TST-712：笔试：实现测试平台配置的版本差异与回滚检测器

**题目**：输入配置版本历史 [{version, config, at}]（按时间升序）与当前版本 current。实现 diffVersions(a, b) 返回字段级差异 {added, removed, changed}；实现 canRollback(history, current, target) 判断能否安全回滚：目标版本必须存在、且不能回滚到比当前更新的版本，且回滚后不得丢失当前有而目标无的必填字段（required 集合）。

**答**：
- diff 要区分新增/删除/修改三类，值比较用严格相等。
- 回滚校验三条件：目标存在、非未来版本、必填字段不丢失。
- 输出要能解释「为什么不能回滚」。

```javascript
function diffVersions(a, b) {
  const added = Object.keys(b).filter(k => !(k in a));
  const removed = Object.keys(a).filter(k => !(k in b));
  const changed = Object.keys(a).filter(k => k in b && a[k] !== b[k])
    .map(k => ({ key: k, from: a[k], to: b[k] }));
  return { added, removed, changed };
}
function canRollback(history, current, target, required) {
  const idxC = history.findIndex(h => h.version === current);
  const t = history.find(h => h.version === target);
  if (!t) return { ok: false, why: '目标版本不存在' };
  if (history.indexOf(t) > idxC) return { ok: false, why: '不能回滚到更新的版本' };
  const missing = required.filter(k => !(k in t.config));
  if (missing.length) return { ok: false, why: '丢失必填字段: ' + missing.join(',') };
  return { ok: true };
}
const h = [{version:1, config:{a:1,req:2}, at:1}, {version:2, config:{a:3}, at:2}];
console.log(diffVersions(h[0].config, h[1].config));
console.log(canRollback(h, 2, 1, ['req'])); // ok:true
```

**评分点**：
- 字段级 diff 三类完整
- 回滚三条件判定齐全
- 不能回滚时给出原因
- 必填字段保护正确
