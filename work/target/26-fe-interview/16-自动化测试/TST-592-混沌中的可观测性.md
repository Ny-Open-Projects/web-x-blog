## TST-592：前端可观测性在混沌实验中的作用

**答**：
- 结论：可观测性是混沌实验的「仪表盘」——没有指标就无法定义稳态、无法判断熔断、无法量化韧性。
- 做法：采集用户侧指标（LCP/错误率/白屏/API 成功率）与系统侧（主线程/内存）；实验全程打点并关联实验 ID；实验报告附带指标曲线，便于复盘。
- 追问钩子：前端指标采集本身影响性能怎么办？——轻量采样 + 低频上报，采样率可配；实验期间临时提高采样，平时保持低开销。

```javascript
// 实验期间按实验 ID 关联指标打点
function taggedMetrics(expId, collector) {
  return (name, value) => collector.push({ expId, name, value, ts: Date.now() });
}
// 生成实验指标报告：关联稳态假设
function reportFor(expId, samples, steady) {
  const mine = samples.filter(s => s.expId === expId);
  const latest = name => mine.filter(s => s.name === name).slice(-1)[0]?.value;
  return { expId,
    errorRate: latest('errorRate'), whiteScreen: latest('whiteScreen'),
    // 稳态是否保持：错误率低 + 无白屏
    steadyHeld: (latest('errorRate') ?? 1) <= steady.maxErrorRate && !latest('whiteScreen'),
    samples: mine.length };
}
const samples = [];
const emit = taggedMetrics('EXP-1', samples);
emit('errorRate', 0.02); emit('whiteScreen', false);
console.log(reportFor('EXP-1', samples, { maxErrorRate: 0.05 }));
```
