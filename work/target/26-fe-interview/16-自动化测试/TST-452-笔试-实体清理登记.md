## TST-452：笔试：工厂创建实体的清理登记与级联删除。
**答**：登记 `[{type, id, deps: id[]}]`（deps = 依赖的实体 id）。实现 `teardown(registry)`：拓扑逆序删除（先删被依赖者引用的下游），环依赖报错，返回删除顺序。

```javascript
function teardown(registry) {
  const seen = new Set(), order = [];
  const byId = new Map(registry.map(r => [r.id, r]));
  const visit = (r, path = []) => {
    if (seen.has(r.id)) return;
    if (path.includes(r.id)) throw new Error(`清理环依赖：${[...path, r.id].join('→')}`);
    // 先递归删除「依赖 r 的」（即谁引用 r，谁先删）
    for (const other of registry) if (other.deps.includes(r.id)) visit(other, [...path, r.id]);
    seen.add(r.id); order.push(r.id);
  };
  registry.forEach(r => visit(r));
  return order; // 依赖他人的先删
}
console.log(teardown([
  { type: 'goods', id: 'g1', deps: [] },
  { type: 'order', id: 'o1', deps: ['g1'] },
])); // ['o1', 'g1']

```

**评分点**：
- 依赖图拓扑逆序（叶子即被依赖者先删？——语义：删除依赖方才能删被依赖方，即先删「依赖别人多」的）。
- 明确方向：订单依赖商品 → 先删订单。
- 环依赖报错。
- 重复登记去重。
