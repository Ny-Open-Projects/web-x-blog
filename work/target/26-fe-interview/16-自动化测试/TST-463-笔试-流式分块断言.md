## TST-463：笔试：流式响应的分块断言工具（壳先到/块后到/顺序）。
**答**：输入分块记录 `[{ts, content}]`。断言：指定关键词在指定时间窗内到达；块顺序符合期望序列；输出到达时间表。

```javascript
function streamAssert(chunks, { order, deadlineMs }) {
  const arrival = new Map();
  for (const c of chunks) {
    if (!arrival.has(c.content)) arrival.set(c.content, c.ts);
  }
  const errors = [];
  for (const kw of order) {
    if (!arrival.has(kw)) errors.push(`未到达: ${kw}`);
    else if (arrival.get(kw) > deadlineMs) errors.push(`${kw} 超时（${arrival.get(kw)}ms > ${deadlineMs}ms）`);
  }
  for (let i = 1; i < order.length; i++) {
    const a = arrival.get(order[i - 1]), b = arrival.get(order[i]);
    if (a !== undefined && b !== undefined && b < a) errors.push(`顺序颠倒: ${order[i - 1]} 晚于 ${order[i]}`);
  }
  return { errors, arrival: Object.fromEntries(arrival) };
}
console.log(streamAssert([
  { ts: 50, content: 'shell' }, { ts: 800, content: 'goods' },
], { order: ['shell', 'goods'], deadlineMs: 2000 }).errors); // []

```

**评分点**：
- 关键词到达时间检索（首现）。
- 顺序断言（按期望序列比较到达时间戳递增）。
- 时间窗断言（deadline 前到达）。
- 失败输出具体哪个关键词/顺序颠倒。
