## TST-888：笔试：手写一个「网络分区模拟器」（部分 API 成功部分失败）
**答**：
- 需求：实现 partitionNetwork(fetchFn, { failedPrefixes }) —— 让匹配 failedPrefixes 的请求失败，其他正常，模拟部分网络分区。
- 规则：按 URL 前缀匹配失败列表；失败请求抛「PartitionError」；返回包装 fetch 与 stats 统计。
- 边界：failedPrefixes 为空则全部正常（不注入）；stats 记录各前缀的失败次数；保留原语义。

```javascript
function partitionNetwork(fetchFn, { failedPrefixes = [] } = {}) {
  const stats = { failed: {}, total: 0 };
  const wrapped = async (url, ...rest) => {
    stats.total++;
    const hit = failedPrefixes.find(p => String(url).startsWith(p));
    if (hit) {
      stats.failed[hit] = (stats.failed[hit] || 0) + 1;
      throw new Error(`PartitionError: ${hit} 不可达`);
    }
    return fetchFn(url, ...rest);
  };
  wrapped.stats = stats;
  return wrapped;
}
const fetch2 = partitionNetwork(fetch, {
  failedPrefixes: ['/api/pay', '/api/ad'],
});
// /api/pay 失败，/api/product 正常 —— 验证「部分依赖挂了主流程是否可控」

fetch2('/api/product').then(() => console.log('商品接口正常'));
fetch2('/api/pay').catch(e => console.log(e.message)); // PartitionError
console.log('注入统计:', fetch2.stats); // { failed:{'/api/pay':1}, total:2 }
```
**评分点**：
- 按 URL 前缀匹配失败请求，实现部分网络分区，逻辑正确。
- stats 记录各前缀失败次数，便于观测演练效果。
- 空前缀列表不注入，边界正确。
- 能点出「部分分区比全断更真实——验证局部依赖故障的隔离能力」。
