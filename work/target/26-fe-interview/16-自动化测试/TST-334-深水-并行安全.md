## TST-334：用例并行的「安全」前提清单（哪些写法并行必炸）？
**答**：
- 共享可变全局（模块级变量累加）——并行下竞态。
- 固定文件路径写临时文件（并行覆盖）——用 tmpdir per worker。
- 依赖执行顺序（前用例种的数据后用例用）——数据自备。
- 端口/定时器冲突——动态端口、时钟隔离。
- 清单 lint 化：并行模式下扫禁区模式进 CI。

```javascript
// 反例：模块级计数器（并行竞态）
let calls = 0;                    // ✗ worker 间不共享且异步竞态
// 正例：per-test 独立状态
test('x', ({ }) => { let calls = 0; ... });   // ✓ 局部

```
