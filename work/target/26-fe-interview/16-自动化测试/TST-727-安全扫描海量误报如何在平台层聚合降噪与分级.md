## TST-727：安全扫描海量误报如何在平台层聚合降噪与分级

**答**：
- 结论：误报治理靠「多源交叉验证 + 指纹去重 + 上下文分级」，单一扫描器的结论不直接进门禁。
- 同一个漏洞用指纹（文件+规则+位置）去重，多扫描器都报的置信度高，单源低置信度降级为提示。
- 引入上下文：是否在测试环境、是否有豁免标记、是否命中已知误报库，综合定级。
- 追问钩子：业务给大量漏洞打了「误报」标签，平台上报数骤降，如何识别这是在刷数据？

```javascript
// 多源交叉验证降噪
function triage(findings) {
  const groups = new Map();
  for (const f of findings) {
    const fp = `${f.file}:${f.rule}:${f.line}`;
    if (!groups.has(fp)) groups.set(fp, new Set());
    groups.get(fp).add(f.scanner);
  }
  return [...groups.entries()].map(([fp, scanners]) => ({
    fp,
    scanners: [...scanners],
    confidence: scanners.size >= 2 ? 'high' : 'low',
  }));
}
console.log(triage([
  { file: 'a.js', rule: 'XSS', line: 1, scanner: 's1' },
  { file: 'a.js', rule: 'XSS', line: 1, scanner: 's2' },
]));
```
