## TST-768：笔试：实现故障演练计划的「风险叠加」检测器（避免多重故障）

**题目**：输入步骤数组 steps [{id, scope, severity}] 与规则：同一 scope 内 severity='high' 的步骤最多允许 1 个；整个计划 high 步骤总数最多 2 个。返回 {ok, violations:[{type, ids}]}，type 为 'SCOPE_OVERLOAD' 或 'GLOBAL_OVERLOAD'。

**答**：
- 按 scope 分组统计 high 数量，超过 1 记违规。
- 全局 high 总数超过 2 记违规。
- violations 含涉及的 id 便于定位。

```javascript
function detectRiskStacking(steps) {
  const violations = [];
  const high = steps.filter(s => s.severity === 'high');
  const byScope = {};
  for (const s of high) (byScope[s.scope] ||= []).push(s.id);
  for (const [scope, ids] of Object.entries(byScope)) {
    if (ids.length > 1) violations.push({ type: 'SCOPE_OVERLOAD', ids });
  }
  if (high.length > 2) violations.push({ type: 'GLOBAL_OVERLOAD', ids: high.map(s => s.id) });
  return { ok: violations.length === 0, violations };
}
console.log(detectRiskStacking([
  { id: 'a', scope: 'api', severity: 'high' },
  { id: 'b', scope: 'api', severity: 'high' },
  { id: 'c', scope: 'db', severity: 'high' },
]));
```

**评分点**：
- scope 内 high 限制判定正确
- 全局 high 限制判定正确
- 违规含 id 便于定位
- 返回结构正确
