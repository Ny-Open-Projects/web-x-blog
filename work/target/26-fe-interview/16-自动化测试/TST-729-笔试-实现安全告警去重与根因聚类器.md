## TST-729：笔试：实现安全告警「去重与根因聚类」器

**题目**：输入告警数组 [{id, rule, resource, cause}]。先按 (rule, resource, cause) 三元组去重（保留首次出现的 id），再把去重后的告警按 cause 聚类，输出每个 cause 的告警数量与 id 列表，按数量降序。

**答**：
- 去重与聚类分两步，先指纹去重再按根因归组。
- 保留首次 id 保证可追溯，聚类按数量降序。
- 相同数量按 cause 字典序保证稳定。

```javascript
function clusterAlerts(alerts) {
  const seen = new Set();
  const deduped = [];
  for (const a of alerts) {
    const fp = `${a.rule}|${a.resource}|${a.cause}`;
    if (seen.has(fp)) continue;
    seen.add(fp);
    deduped.push(a);
  }
  const groups = new Map();
  for (const a of deduped) {
    if (!groups.has(a.cause)) groups.set(a.cause, []);
    groups.get(a.cause).push(a.id);
  }
  return [...groups.entries()]
    .map(([cause, ids]) => ({ cause, count: ids.length, ids }))
    .sort((a, b) => b.count - a.count || a.cause.localeCompare(b.cause));
}
console.log(clusterAlerts([
  { id: 'a1', rule: 'XSS', resource: '/p', cause: '未转义' },
  { id: 'a2', rule: 'XSS', resource: '/p', cause: '未转义' },
  { id: 'a3', rule: 'SQLI', resource: '/u', cause: '未转义' },
])); // 未转义:2
```

**评分点**：
- 三元组指纹去重正确
- 按 cause 聚类且计数正确
- 降序与稳定排序
- 保留首次 id 可追溯
