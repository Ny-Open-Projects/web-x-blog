## TST-464：笔试：并行测试的命名空间工具（ID 前缀 + 随机种子隔离）。
**题目**：`ns(worker, shard)` 生成命名空间：`{prefix, id(name), fakerSeed}`。id 形如 `s{shard}-w{worker}-{name}-{seq}`，seq 每次递增；fakerSeed 由 shard/worker 派生（确定性）。

```javascript
export function createNS(worker, shard) {
  let seq = 0;
  return {
    prefix: `s${shard}-w${worker}`,
    id(name) { return `${this.prefix}-${name}-${++seq}`.slice(0, 64); },
    fakerSeed: (worker + 1) * 7919 + shard * 104729,   // 确定性派生
  };
}
const ns = createNS(0, 2);
console.log(ns.id('user'), ns.fakerSeed); // s2-w0-user-1

```

**评分点**：
- 前缀组装完整（shard/worker 可归因）。
- seq 递增（同 namespace 内唯一）。
- fakerSeed 确定性派生（同配置同种子）。
- id 长度限制（DB 字段约束）。
