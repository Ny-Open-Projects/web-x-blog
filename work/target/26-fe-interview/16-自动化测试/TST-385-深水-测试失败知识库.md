## TST-385：测试失败的知识库（错误 → 已知原因 → 修法）如何建设？
**答**：
- 每次失败自动检索知识库（错误指纹匹配），命中直接给已知解法。
- 指纹：错误类型 + 关键栈帧 + 触发条件归一化。
- 知识条目生命周期：重复命中 ≥ 5 次的固化，无命中半年清理。
- 人审校准：知识库建议的采纳率追踪，低采纳条目修正。

```javascript
const fingerprint = `${err.name}|${err.stack.split('\n')[1]}|${norm(err.message)}`;
const known = kb.find(f => f.fingerprint === fingerprint);
if (known) annotate(known.fix);   // 报告直接附已知修法
r
```
