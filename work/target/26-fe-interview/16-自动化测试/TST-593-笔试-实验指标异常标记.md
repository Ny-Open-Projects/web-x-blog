## TST-593：笔试：笔试：混沌实验指标采集与异常标记

**题目**：实现 markAnomalies(series, rules)。series=[{ts, metric, value}]；rules={ metric: { baseline:number, tolerance:number } }。要求：① 对每个采样点，若其 metric 在 rules 中且 value > baseline*(1+tolerance) 则标记 anomaly:true；② 输出带 anomaly 标记的新数组（不改原数组）；③ 统计每个 metric 的异常数 {metric:count}；④ 边界：未知 metric 不标记、series 空返回 {series:[], counts:{}}。

**答**：
- 结论：映射采样点，按规则判断是否越界打标，并聚合各指标异常数。
- 实现要点：用 map 生成新对象（不改原数组）；查 rules[metric]，存在且 value>baseline*(1+tol) 才标记；counts 累加。
- 追问钩子：为什么用相对 baseline？——不同指标量纲不同，相对阈值通用；baseline 应来自实验前稳态采集，而非硬编码。

```javascript
function markAnomalies(series = [], rules = {}) {
  const counts = {};
  const out = series.map(p => {
    const r = rules[p.metric];
    const anomaly = !!r && (p.value ?? 0) > r.baseline * (1 + r.tolerance);
    if (anomaly) counts[p.metric] = (counts[p.metric] || 0) + 1;
    return { ...p, anomaly };
  });
  return { series: out, counts };
}
```

**评分点**：
- 按 rules 的 baseline*(1+tolerance) 正确判定异常。
- 不修改原数组，返回带 anomaly 的新数组。
- counts 按 metric 聚合异常数准确。
- 未知 metric 不标记、空输入返回空结构，边界完整。
