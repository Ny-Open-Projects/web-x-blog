## TST-922：笔试：手写「快照过期自动巡检器」——找出长期未使用/对应用例已删的基线
**答**：
- 需求：实现 auditSnapshots({ snapshotFiles, usageRecords })，usageRecords 为 { key, lastUsedAt, testExists }[]。
- 规则：分三类输出——active（testExists 且 30 天内用过）、stale（testExists 但 90 天未用）、orphan（!testExists）；按类返回 key 列表与建议动作。
- 边界：snapshotFiles 中存在但 usageRecords 无记录的 key 视为 orphan；时间字符串需转时间戳比较。

```javascript
function auditSnapshots({ snapshotFiles, usageRecords }) {
  const now = Date.now(), DAY = 864e5;
  const byKey = new Map(usageRecords.map(r => [r.key, r]));
  const result = { active: [], stale: [], orphan: [] };
  for (const key of snapshotFiles) {
    const r = byKey.get(key);
    if (!r || !r.testExists) { result.orphan.push(key); continue; }
    const age = now - new Date(r.lastUsedAt).getTime();
    if (age > 90 * DAY) result.stale.push({ key, days: Math.floor(age / DAY) });
    else result.active.push(key);
  }
  result.actions = {
    orphan: '直接删除（无用例引用）',
    stale: '人工确认后删除或补充用例重新激活',
    active: '保留',
  };
  return result;
}
const r = auditSnapshots({
  snapshotFiles: ['a 1', 'b 1', 'c 1'],
  usageRecords: [
    { key: 'a 1', lastUsedAt: '2026-11-20', testExists: true },
    { key: 'b 1', lastUsedAt: '2026-01-01', testExists: true },
  ],
});
console.log(r.orphan, r.stale.map(x => x.key)); // ['c 1'] , ['b 1']
```
**评分点**：
- 正确三分类 active/stale/orphan，阈值 30/90 天判断准确。
- snapshotFiles 中无使用记录的 key 归为 orphan。
- 输出 actions 建议动作，可直接生成清理 PR。
- 时间字符串正确转时间戳，边界完整。
