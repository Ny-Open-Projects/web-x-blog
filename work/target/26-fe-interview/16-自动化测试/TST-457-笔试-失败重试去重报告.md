## TST-457：笔试：重试后的失败报告去重（同用例多次失败合并）。
**答**：运行记录 `[{name, attempt, error}]`（重试多次）。合并：同 name 聚合，输出 `{name, attempts, firstError, lastError, recovered: bool}`（最后一次成功即 recovered——此时无记录则按运行成功表判断）。

```javascript
function mergeRetries(failRecords, passedNames) {
  const by = new Map();
  for (const f of failRecords) {
    const s = by.get(f.name) ?? { name: f.name, attempts: 0,
      firstError: f.error.slice(0, 80), lastError: '' };
    s.attempts++; s.lastError = f.error.slice(0, 80);
    by.set(f.name, s);
  }
  return [...by.values()].map(s => ({ ...s, recovered: passedNames.has(s.name) }))
    .sort((a, b) => Number(a.recovered) - Number(b.recovered));
}
console.log(mergeRetries([
  { name: 'a', attempt: 1, error: 'timeout' }, { name: 'a', attempt: 2, error: 'assert' },
], new Set(['a']))); // recovered: true

```

**评分点**：
- 重试聚合（attempts/首错/末错）。
- recovered 判定：重试记录存在但最终在 pass 集合。
- 输出按未恢复优先排序。
- 错误信息截断（防报告爆炸）。
