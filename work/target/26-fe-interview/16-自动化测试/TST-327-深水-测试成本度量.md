## TST-327：如何度量「测试成本」并优化投入结构？
**答**：
- 成本 = 执行时长（CI 时间）× 频率 + 维护人力（用例修复工时）。
- ROI = 缺陷发现率（按层）÷ 成本——找出低 ROI 用例群。
- 优化杠杆：下沉（E2E→单测）、合并（冗余断言）、提速（数据预置替代 UI）。
- 汇报口径：同等缺陷发现下执行成本环比下降 = 测试体系健康度。

```javascript
const roi = (layer) => ({
  cost: layer.ciMinutes + layer.maintainHours * 60,
  defects: layer.defectsPerMonth,
  roi: layer.defectsPerMonth / (layer.ciMinutes + layer.maintainHours * 60),
});
```
