## TST-041：笔试：手写快照序列化器（稳定键序 + 脱敏）
**答**：
- 需求：实现 `serialize(value)`，输出确定性的字符串快照：对象键按字典序排列（不受插入顺序影响）、动态字段（时间戳/id）替换为占位符、循环引用不爆栈。
- 核心：递归遍历时 ① 键排序；② 命中敏感键名（createdAt/updatedAt/id/random）输出 `<{key}:dynamic>`；③ 用 WeakSet 记录已访问对象，命中循环输出 `[Circular]`。
- 边界：数组保持顺序（数组顺序通常有语义）；函数输出 `[Function name]`；undefined/null 明确区分；负零、NaN 也要有稳定表示。

```javascript
const DYNAMIC_KEYS = new Set(['createdAt', 'updatedAt', 'id', 'random']);

function serialize(value, seen = new WeakSet(), path = '') {
  if (value === null) return 'null';
  if (value === undefined) return 'undefined';
  const t = typeof value;
  if (t === 'number') return Object.is(value, -0) ? '-0' : (Number.isNaN(value) ? 'NaN' : String(value));
  if (t === 'string') return JSON.stringify(value);
  if (t === 'boolean') return String(value);
  if (t === 'function') return `[Function ${(value.name || 'anonymous')}]`;
  if (t !== 'object') return `[${t}]`;

  if (seen.has(value)) return `[Circular at ${path}]`;   // 循环引用
  if (value instanceof Date) return `<Date ${value.toISOString()}>`;
  seen.add(value);

  if (Array.isArray(value)) {
    return `[${value.map((v, i) => serialize(v, seen, `${path}[${i}]`)).join(', ')}]`;
  }
  const keys = Object.keys(value).sort();                // 键序稳定化
  return `{ ${keys.map((k) =>
    DYNAMIC_KEYS.has(k) ? `${k}: <dynamic>` : `${k}: ${serialize(value[k], seen, `${path}.${k}`)}`
  ).join(', ')} }`;
}

// ---- 用法 ----
const a = { id: 'ORD-99', name: '键盘', tags: ['x', 'y'], meta: { updatedAt: 1720000000, z: 1, a: 2 } };
a.self = a; // 循环引用
console.log(serialize(a));
// { id: <dynamic>, meta: { a: 2, updatedAt: <dynamic>, z: 1 }, name: "键盘", self: [Circular at .], tags: ["x", "y"] }
// 两次运行、两次键插入顺序不同，输出完全一致 —— 这正是快照可比对的前提。
```
**评分点**：
- 键排序（字典序）是「快照确定性」的核心得分点。
- 动态字段占位 + 循环引用检测（WeakSet）。
- 边界类型有稳定表示：NaN/-0/Date/Function/undefined。
- 能说出真实实现（pretty-format）还处理 Map/Set/Symbol/缩进排版。
