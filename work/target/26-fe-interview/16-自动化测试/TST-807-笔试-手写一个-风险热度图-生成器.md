## TST-807：笔试：手写一个「风险热度图」生成器，把测试优先级量化
**答**：
- 需求：实现 buildRiskHeatmap(features) —— 每个 feature 有 likelihood(1-5) 与 impact(1-5)，输出风险分与测试优先级。
- 规则：风险分 = likelihood × impact；>=20 为 P0 必测、10-19 为 P1 重点、<10 为 P2 常规；按风险分降序排序。
- 边界：非法分值（非 1-5 整数）跳过并记录到 invalid 列表，不中断整体生成。

```javascript
function buildRiskHeatmap(features) {
  const invalid = [];
  const scored = features.reduce((acc, f) => {
    const ok = [f.likelihood, f.impact].every(v => Number.isInteger(v) && v >= 1 && v <= 5);
    if (!ok) { invalid.push(f.name); return acc; }
    const score = f.likelihood * f.impact;
    const priority = score >= 20 ? 'P0' : score >= 10 ? 'P1' : 'P2';
    acc.push({ name: f.name, score, priority });
    return acc;
  }, []);
  scored.sort((a, b) => b.score - a.score);
  return { heatmap: scored, invalid };
}
const input = [
  { name: '支付', likelihood: 4, impact: 5 },
  { name: '头像上传', likelihood: 2, impact: 1 },
  { name: '脏数据', likelihood: 9, impact: 3 },
];
console.log(buildRiskHeatmap(input));
// 支付 P0(20)，头像上传 P2(2)，脏数据进 invalid
```
**评分点**：
- 风险分 = 可能性 × 影响，优先级分档边界（20/10）正确。
- 按风险分降序排序，输出结构清晰。
- 非法分值跳过并汇总到 invalid，不中断——体现健壮性。
- 能点出「风险热度图用于决定测试资源投在哪里」这一架构意图。
