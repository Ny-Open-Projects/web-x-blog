## TST-470：笔试：从功能变更描述生成「测试清单」（域 × 变化类型）。
**题目**：变更 `[{domain, kind}]`（kind: new/modify/delete）。生成清单规则：new → 正向+边界+异常；modify → 回归旧行为+新行为；delete → 确认移除+引用清理。按域分组输出 checklist。

```javascript
const KIND_TESTS = {
  new: ['正向路径', '边界值', '异常输入'],
  modify: ['旧行为回归', '新行为验证', '关联方影响'],
  delete: ['功能移除确认', '引用清理检查', '旧入口 404/降级'],
};
function genChecklist(changes) {
  const by = new Map();
  for (const c of changes) {
    const kinds = KIND_TESTS[c.kind];
    if (!kinds) { console.warn(`未知 kind: ${c.kind}`); continue; }
    if (!by.has(c.domain)) by.set(c.domain, []);
    by.get(c.domain).push(...kinds.map(k => `[ ] ${c.domain}: ${k}`));
  }
  return Object.fromEntries(by);
}
console.log(genChecklist([{ domain: 'cart', kind: 'modify' }]));

```

**评分点**：
- kind→测试类型映射表驱动。
- 按域分组输出。
- 每项 checklist 可勾选格式（[ ]）。
- 未知 kind 告警（映射缺口）。
