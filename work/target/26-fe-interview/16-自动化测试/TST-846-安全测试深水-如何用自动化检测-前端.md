## TST-846：安全测试深水：如何用自动化检测「前端敏感信息泄漏」（token/密钥硬编码）？
**答**：
- 结论：前端不能有真正的秘密——自动化检测要做到「提交前扫描 + CI 正则/熵检测 + 历史提交兜底」，发现硬编码立即阻断。
- 技术手段：gitleaks/trufflehog 类工具扫 git 历史与 diff；正则匹配常见密钥格式（AWS AK、私钥头）；高熵字符串启发式识别。
- 前端特有关注：环境变量误打进 bundle（process.env 泄漏）、源码里写死 API token、source map 暴露内部逻辑。
- 纵深防御：即便扫出也按「已泄漏」处理——轮换密钥、审计访问日志，而非只删代码。
- 追问钩子：扫描工具报了一堆误报（如测试 mock 的假 key），你如何在不漏报的前提下降噪？

```javascript
// 前端敏感信息扫描：正则 + 熵启发式
const PATTERNS = [
  /AKIA[0-9A-Z]{16}/,                    // AWS Access Key
  /-----BEGIN (RSA |EC )?PRIVATE KEY-----/, // 私钥
  /sk-[A-Za-z0-9]{20,}/,                  // OpenAI 类密钥
];
function shannonEntropy(s) {
  const freq = {};
  for (const c of s) freq[c] = (freq[c] || 0) + 1;
  return -Object.values(freq).reduce((h, n) => {
    const p = n / s.length; return h + p * Math.log2(p);
  }, 0);
}
function scan(code) {
  const hits = PATTERNS.filter(p => p.test(code)).map(() => 'pattern');
  if (/[A-Za-z0-9+/]{32,}/.test(code) && shannonEntropy(code) > 4.5) hits.push('high-entropy');
  return hits;
}
console.log(scan('const key = "AKIAIOSFODNN7EXAMPLE";')); // ['pattern']
```
