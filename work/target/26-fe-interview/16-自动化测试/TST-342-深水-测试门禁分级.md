## TST-342：测试门禁的分级设计（不是一刀切全阻塞）？
**答**：
- L1 阻塞：单测/lint/类型（快、准）。
- L2 阻塞（core）+ 建议（edge）：集成测试按模块关键度分级。
- L3 非阻塞：E2E 全量/视觉/AI 评审（评论式），主干合并后跑。
- 分级原则：误报率高/时长长的层降级为建议，用数据逐步升级。

```javascript
const gateLevels = {
  L1: { type: 'blocking', suites: ['unit', 'lint', 'type'] },
  L2: { type: 'block-core', suites: ['api:core'], comment: ['api:edge'] },
  L3: { type: 'post-merge', suites: ['e2e-full', 'visual', 'ai-review'] },
};
```
