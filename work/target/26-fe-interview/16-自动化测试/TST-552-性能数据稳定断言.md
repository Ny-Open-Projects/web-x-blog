## TST-552：性能数据波动大，如何做稳定断言

**答**：
- 结论：用「多次采样 + 稳健统计 + 容差带 + 同环境对比」对抗噪声，而不是单次绝对值比较。
- 做法：至少跑 5~10 次取 P50（或裁剪均值）；设相对容差（±10%）与绝对上限双门槛；固定机型/网络/缓存，必要时用专用裸机；只与同环境基线比，不跨环境。
- 追问钩子：CI 共享机器噪声大，根本压不住怎么办？——把性能回归放到隔离的专属 runner 或夜间定时执行，与功能 CI 解耦，换取环境稳定。

```javascript
// 稳健断言：多次采样取中位数 + 容差带
function stableAssert(samples, baseline, { tol = 0.1, absLimit = Infinity } = {}) {
  const sorted = [...samples].sort((a, b) => a - b);
  const med = sorted[Math.floor(sorted.length / 2)];
  return { median: med,
    pass: med <= Math.min(absLimit, baseline * (1 + tol)),
    spread: +(sorted[sorted.length - 1] - sorted[0]).toFixed(1) };
}
console.log(stableAssert([210, 250, 230, 900, 220], 240, { tol: 0.1 })); // 中位数抗住 900 尖刺
console.log(stableAssert([210, 250, 230, 220], 240)); // pass=true，无尖刺
```
