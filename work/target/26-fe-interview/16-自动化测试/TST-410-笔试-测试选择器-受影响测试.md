## TST-410：笔试：实现「变更 → 受影响测试」选择器（依赖图）。
**答**：输入 `deps: {module: string[]}`（模块→其依赖的模块）与 `tests: {test: covers[]}`。变更模块集合 → 受影响测试 = 覆盖了该模块或其传递依赖者的测试。

```javascript
function impactedTests(changed, deps, tests) {
  const affected = new Set(changed);
  let grow = true;
  while (grow) {                       // 闭包：依赖受影响模块的模块也受影响
    grow = false;
    for (const [mod, ds] of Object.entries(deps))
      if (!affected.has(mod) && ds.some(d => affected.has(d))) { affected.add(mod); grow = true; }
  }
  return [...new Set(tests.filter(t => t.covers.some(c => affected.has(c))).map(t => t.name))]
    .sort();
}
console.log(impactedTests(['price'],
  { cart: ['price'], checkout: ['cart'] },
  [{ name: 'cart.spec', covers: ['cart'] }, { name: 'pay.spec', covers: ['pay'] }]));
// ['cart.spec']

```

**评分点**：
- 传递闭包（反向依赖传播）：被变更模块影响的模块集合。
- 测试覆盖声明（covers）与影响集求交。
- 输出去重排序。
- 无覆盖声明的测试 → 保守全跑（可选策略说明）。
