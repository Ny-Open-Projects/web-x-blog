## TST-471：笔试：失败用例按错误指纹聚类（批量归因）。
**题目**：失败 `[{name, error}]`。指纹 = 错误类型 + 首个栈帧函数名。聚类输出组（组内用例列表 + 代表错误 + 建议归因：组大小 ≥ 3 → 疑环境/共享依赖问题）。

```javascript
function clusterFailures(failures) {
  const norm = m => m.replace(/\d+/g, 'N');
  const groups = new Map();
  for (const f of failures) {
    const [head] = f.error.split('\n');
    const fp = `${head.split(':')[0]}|${norm(head)}`;
    if (!groups.has(fp)) groups.set(fp, []);
    groups.get(fp).push(f.name);
  }
  return [...groups].map(([fp, names]) => ({ fingerprint: fp, size: names.length, names,
    suggest: names.length >= 3 ? '疑环境/共享依赖问题，优先查环境' : '个案排查' }))
    .sort((a, b) => b.size - a.size);
}

```

**评分点**：
- 指纹归一化（错误消息去数字/ID 变体）。
- 聚类分组 + 代表错误。
- 组大小驱动的归因建议（大组=系统性）。
- 单例组汇总（零散问题）。
