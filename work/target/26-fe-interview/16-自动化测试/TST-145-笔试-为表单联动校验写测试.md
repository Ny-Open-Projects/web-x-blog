## TST-145：笔试：为表单联动校验写测试（密码强度/二次确认/提交门禁）
**答**：
- 场景：注册表单——密码强度实时评分（弱/中/强文案与颜色）、确认密码一致性校验、所有校验通过才允许提交、提交中禁用按钮。联动校验是组件测试最能区分「测实现 vs 测行为」的题。
- 测试策略：逐字段触发（type → blur）断言提示文案；门禁断言用「按钮 disabled 状态」+「提交请求次数」双保险；只断言用户可见的反馈，不断言内部 state。
- 边界：修改密码后一致性提示要消失/更新；blur 前不报错（首次输入不骚扰）；提交飞行中再改字段的行为约定。

```jsx
import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { http, HttpResponse } from 'msw';
import { server } from '@/mocks/server';
import RegisterForm from './RegisterForm';

const typeInto = async (user, label, text) => {
  const field = screen.getByLabelText(label);
  await user.type(field, text);
  await user.tab();                                   // blur 触发校验
  return field;
};

test('强度提示与一致性校验联动', async () => {
  render(<RegisterForm />);
  const user = userEvent.setup();

  await typeInto(user, '密码', 'abc');                // 弱
  expect(screen.getByText('强度：弱')).toBeInTheDocument();

  await user.clear(screen.getByLabelText('密码'));
  await typeInto(user, '密码', 'Abc123!@#');          // 强
  expect(screen.getByText('强度：强')).toBeInTheDocument();

  await typeInto(user, '确认密码', 'Abc123!@');       // 不一致
  expect(screen.getByText('两次密码不一致')).toBeInTheDocument();
  expect(screen.getByRole('button', { name: '注册' })).toBeDisabled();

  await user.clear(screen.getByLabelText('确认密码'));
  await typeInto(user, '确认密码', 'Abc123!@#');      // 修正
  expect(screen.queryByText('两次密码不一致')).toBeNull();
  expect(screen.getByRole('button', { name: '注册' })).toBeEnabled();
});

test('提交成功后不可重复提交，失败回滚可重试', async () => {
  let n = 0;
  server.use(http.post('/api/register', () => {
    n++;
    return n === 1 ? HttpResponse.json({ ok: true }) : HttpResponse.error();
  }));
  render(<RegisterForm />);
  const user = userEvent.setup();
  await user.type(screen.getByLabelText('手机号'), '13800000000');
  await typeInto(user, '密码', 'Abc123!@#');
  await typeInto(user, '确认密码', 'Abc123!@#');

  const btn = screen.getByRole('button', { name: '注册' });
  await user.click(btn);
  await screen.findByText('注册成功');
  expect(n).toBe(1);
});
```

**评分点**：
1. 通过 blur + type 触发校验而非直接改 state（测行为不测实现）。
2. 门禁断言双保险：disabled + 请求次数。
3. 联动更新覆盖：修正后提示消失（不是只测出错路径）。
4. 无内部 state 断言（保持黑盒）。
