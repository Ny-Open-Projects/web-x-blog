## TST-749：笔试：实现性能预算的「自适应阈值」器（基于历史分布）

**题目**：输入历史耗时数组 history 与分位参数 q（0~1，如 0.9）。用线性插值法计算第 q 分位数作为预算阈值。若 history 为空返回 0。线性插值规则：位置 pos=(n-1)*q，取 floor 与 ceil 位置的值按小数部分插值。返回保留 1 位小数的阈值。

**答**：
- 先升序排序，按 (n-1)*q 定位。
- floor 与 ceil 相同则直接返回，否则线性插值。
- 空数组返回 0，q 边界 0/1 正确。

```javascript
function percentileBudget(history, q) {
  if (!history.length) return 0;
  const s = [...history].sort((a, b) => a - b);
  const pos = (s.length - 1) * q;
  const lo = Math.floor(pos), hi = Math.ceil(pos);
  if (lo === hi) return +s[lo].toFixed(1);
  return +(s[lo] + (s[hi] - s[lo]) * (pos - lo)).toFixed(1);
}
console.log(percentileBudget([1000, 2000, 3000, 4000], 0.5)); // 2500
console.log(percentileBudget([1000, 2000, 3000, 4000], 0));    // 1000
console.log(percentileBudget([], 0.9));                        // 0
```

**评分点**：
- 排序与分位位置计算正确
- 线性插值实现正确
- 空数组兜底
- q=0/1 边界正确
