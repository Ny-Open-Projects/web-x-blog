## TST-439：笔试：测试环境「运行租户」的 ID 分配与回收。
**题目**：租户池 `{free: string[], inUse: Map}`。`acquire(runId)` 分配空闲租户；`release(runId)` 回收；池耗尽返回 null（排队提示）；泄漏检测（租用超时未还列出）。

```javascript
export function tenantPool(pool, { leaseMs = 3_600_000 } = {}) {
  const free = [...pool], inUse = new Map();
  return {
    acquire(runId, now = Date.now()) {
      if (!free.length) return null;
      const t = free.pop();
      inUse.set(t, { runId, at: now });
      return t;
    },
    release(t, runId) {
      const rec = inUse.get(t);
      if (!rec) throw new Error(`租户 ${t} 未被借用`);
      if (rec.runId !== runId) throw new Error(`租户 ${t} 借用人不匹配`);
      inUse.delete(t); free.push(t);
    },
    leaked(now = Date.now()) {
      return [...inUse].filter(([, r]) => now - r.at > leaseMs).map(([t]) => t);
    },
  };
}

```

**评分点**：
- acquire/release 状态机（防重复借/还）。
- 池耗尽显式返回（排队而非报错）。
- 泄漏检测（租用时间戳超时）。
- 回收时校验借用人（防还错）。
