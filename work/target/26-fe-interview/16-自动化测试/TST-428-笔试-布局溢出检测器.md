## TST-428：笔试：实现「元素溢出视口」检测（几何规则）。
**答**：输入元素几何 `[{sel, rect:{x,y,w,h}, visible}]` 与视口 {w, h}。溢出 = visible 且超出视口边界（容差 2px）。输出溢出清单（超了多少 px）；横向溢出优先（移动端致命）。

```javascript
function overflowCheck(els, viewport, tol = 2) {
  const out = [];
  for (const el of els) {
    if (!el.visible) continue;
    const r = el.rect;
    const over = { right: r.x + r.w - viewport.w, bottom: r.y + r.h - viewport.h,
                   left: -r.x, top: -r.y };
    for (const [dir, v] of Object.entries(over))
      if (v > tol) out.push({ sel: el.sel, dir, overPx: Math.round(v), axis: dir === 'right' || dir === 'left' ? 'x' : 'y' });
  }
  return out.sort((a, b) => (a.axis === 'x' ? 0 : 1) - (b.axis === 'x' ? 0 : 1));
}
console.log(overflowCheck([
  { sel: '.banner', visible: true, rect: { x: 0, y: 0, w: 400, h: 50 } },
], { w: 375, h: 667 })); // right 25px 溢出

```

**评分点**：
- 四向边界检测（right/bottom/left/top）。
- 容差（2px）处理亚像素。
- 横向溢出排序优先。
- 不可见元素跳过。
