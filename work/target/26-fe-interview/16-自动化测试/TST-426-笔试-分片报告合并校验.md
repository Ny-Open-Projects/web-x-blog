## TST-426：笔试：合并分片报告时的完整性校验。
**题目**：输入各分片声明的用例集与结果。校验：① 全量用例都被某分片认领 ② 无用例被多分片重复认领 ③ 认领了但无结果的分片缺口。输出 `{unassigned, duplicated, missingResults}`。

```javascript
function verifySharding(allTests, shards) {
  const claimed = new Map();
  const unassigned = [], duplicated = [], missingResults = [];
  for (const s of shards) {
    for (const t of s.claimed) {
      if (claimed.has(t)) duplicated.push({ test: t, shards: [claimed.get(t), s.id] });
      else claimed.set(t, s.id);
    }
    for (const t of s.claimed)
      if (!(s.results || []).some(r => r.name === t)) missingResults.push({ test: t, shard: s.id });
  }
  for (const t of allTests) if (!claimed.has(t)) unassigned.push(t);
  return { unassigned, duplicated, missingResults };
}

```

**评分点**：
- 集合运算（认领并集 vs 全量；交集找重复）。
- 认领但缺结果（分片中途崩）单独识别。
- 输出带具体用例名（可定位）。
- 空报告分片也算 missing。
