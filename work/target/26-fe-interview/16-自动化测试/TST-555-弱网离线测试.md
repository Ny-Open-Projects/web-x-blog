## TST-555：弱网/离线场景的性能与体验怎么测

**答**：
- 结论：用网络模拟（Chrome DevTools/CDP Network.emulateNetworkConditions）设定 2G/3G/高延迟/丢包/离线，验证加载、超时、重试、降级与离线提示。
- 做法：断言弱网下首屏可用时间、进度/骨架屏是否正确展示；断网重连后请求恢复；超时重试有上限和退避；离线时给出明确提示而非白屏。
- 追问钩子：弱网下测试容易 flaky 怎么办？——固定网络参数、用确定性时钟控制超时、避免依赖真实网络抖动，把「弱网」作为可重复的测试配置而非临时手动模拟。

```javascript
// 用 CDP 模拟弱网配置（Playwright 示例）
const NETWORK_PRESETS = {
  '3g': { download: 1.6e6/8, upload: 750e3/8, latency: 150 },
  '2g': { download: 250e3/8, upload: 50e3/8, latency: 400 },
  offline: { offline: true },
};
async function applyNetwork(page, preset) {
  const cdp = await page.context().newCDPSession(page);
  await cdp.send('Network.enable');
  await cdp.send('Network.emulateNetworkConditions', {
    offline: !!preset.offline, latency: preset.latency || 0,
    downloadThroughput: preset.download || -1, uploadThroughput: preset.upload || -1,
  });
}
```
