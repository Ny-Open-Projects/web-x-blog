## TST-692：笔试：实现时钟跳变注入器（前进 / 回退 / 夏令时）

**题目**：实现 installFakeClock({offsetMs,tz})：替换全局 Date 为FakeDate，now() 与无参构造返回偏移后时间，toLocaleString 支持 timeZone；返回 restore 还原。另实现 dstOffset(dateStr) 返回时区偏移毫秒。

**答**：
- 用 Date 子类替换全局 Date，支持 now() 偏移与构造偏移。
- 时区跳变用 toLocaleString 的 timeZone 参数模拟；夏令时用特定日期偏移。
- 返回 restore 精确还原全局 Date。

```javascript
function installFakeClock({ offsetMs = 0, tz } = {}) {
  const RealDate = Date;
  class FakeDate extends RealDate {
    constructor(...args) {
      if (!args.length) super(RealDate.now() + offsetMs);
      else super(...args);
    }
    static now() { return RealDate.now() + offsetMs; }
    toLocaleString(...a) {
      return super.toLocaleString(...(tz ? [{ timeZone: tz }] : a));
    }
  }
  window.Date = FakeDate;
  return () => { window.Date = RealDate; };
}
function dstOffset(dateStr) {
  const d = new Date(dateStr);
  return d.getTimezoneOffset() * 60000;
}
```

**评分点**：
- Date 子类替换正确
- now 与构造函数偏移一致
- restore 精确还原
- 时区/夏令时处理
