## TST-462：笔试：实现服务端 HTML 与客户端 DOM 的「语义差异」检测。
**题目**：输入两棵简化树（tag+attrs+text）。忽略属性白名单（如随机 id/data-reactroot）后深度对比，输出差异路径；文本空白归一比较。

```javascript
const IGNORE = new Set(['id', 'data-reactroot']);
function treeDiff(a, b, path = '', out = []) {
  if (a.tag !== b.tag) { out.push(`结构差异 ${path||'(root)'}: ${a.tag} vs ${b.tag}`); return out; }
  for (const k of new Set([...Object.keys(a.attrs || {}), ...Object.keys(b.attrs || {})])) {
    if (IGNORE.has(k)) continue;
    if ((a.attrs || {})[k] !== (b.attrs || {})[k]) out.push(`属性 ${path}.${k}: ${a.attrs?.[k]} vs ${b.attrs?.[k]}`);
  }
  const na = (a.text || '').trim().replace(/\s+/g, ' ');
  const nb = (b.text || '').trim().replace(/\s+/g, ' ');
  if (na !== nb) out.push(`文本 ${path}: "${na}" vs "${nb}"`);
  const n = Math.max((a.children || []).length, (b.children || []).length);
  for (let i = 0; i < n; i++)
    treeDiff((a.children || [])[i] ?? { tag: '∅' }, (b.children || [])[i] ?? { tag: '∅' }, `${path}>${i}`, out);
  return out;
}

```

**评分点**：
- 忽略白名单属性（SSR 随机 id 是噪声源）。
- 文本归一（空白/截断）。
- 递归 diff 路径化输出。
- 结构不同（tag 变化）优先报告（比属性差异严重）。
