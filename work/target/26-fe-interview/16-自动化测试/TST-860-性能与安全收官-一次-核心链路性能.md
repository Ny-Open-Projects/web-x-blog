## TST-860：性能与安全收官：一次「核心链路性能+安全」双达标如何设计测试方案？
**答**：
- 结论：双达标方案 = 分层门禁（构建期静态扫描 + CI 性能预算 + 运行时安全探测）+ 核心链路 focused 验证 + 上线后 RUM/监控兜底。
- 构建期：SAST/依赖扫描/CSP 检查（安全）+ bundle 体积预算（性能）作为 PR 门禁。
- CI 期：核心链路（登录→下单→支付）跑 Lighthouse CI 性能预算 + 越权/注入安全用例，双维度都过才准入。
- 上线后：RUM 监控真实性能指标，WAF/日志监控安全事件，形成「左移门禁 + 右移监控」闭环。
- 追问钩子：性能门禁和安全门禁冲突（如加了安全检查拖慢首屏）时，架构师如何权衡？

```javascript
// 双达标门禁：性能 + 安全同时判定
function dualGate(perf, security) {
  const perfPass = perf.lcp < 2500 && perf.jsKB < 300;
  const secPass = security.noHardcodedSecret && security.noIDOR && security.cspValid;
  return {
    go: perfPass && secPass,
    perf: { pass: perfPass, lcp: perf.lcp },
    security: { pass: secPass, findings: security.findings || [] },
    verdict: perfPass && secPass ? '双达标，准入' : '存在阻断项',
  };
}
console.log(dualGate(
  { lcp: 2100, jsKB: 280 },
  { noHardcodedSecret: true, noIDOR: true, cspValid: true }));
// go:true
```
