## TST-046：笔试：为金额格式化函数设计一组完整单测（含边界表）
**答**：
- 需求：`formatMoney(n)` —— 正数带千分位两位小数（¥1,234.50）、负数带 -、0 输出 ¥0.00、非法输入（NaN/Infinity/字符串）返回 ¥0.00 并 console.warn 一次、超大数不失真。
- 设计方法：等价类划分（正常/负数/零/非法）+ 边界值（0.005 舍入、999999.999、极大值）+ 副作用断言（warn 恰好一次）。
- 结构：用 it.each 表驱动主映射，单独用例测副作用与舍入边界；命名写完整行为句子。

```javascript
import { describe, it, expect, vi, afterEach } from 'vitest';
import { formatMoney } from './money';

afterEach(() => vi.restoreAllMocks());

describe('formatMoney', () => {
  // 主映射：表驱动
  it.each([
    ['零', 0, '¥0.00'],
    ['普通', 1234.5, '¥1,234.50'],
    ['千分位+舍入', 1234567.891, '¥1,234,567.89'],
    ['负数', -20, '-¥20.00'],
    ['两舍入边界 0.005 进位', 1.005, '¥1.01'],
  ])('%s: %f -> %s', (name, input, expected) => {
    expect(formatMoney(input)).toBe(expected);
  });

  // 非法输入：返回值 + 副作用都要断言
  it.each([NaN, Infinity, 'abc', null])('非法输入 %p 返回 ¥0.00 且 warn 一次', (input) => {
    const warn = vi.spyOn(console, 'warn').mockImplementation(() => {});
    expect(formatMoney(input)).toBe('¥0.00');
    expect(warn).toHaveBeenCalledTimes(1);
  });

  // 舍入边界说明：0.005 因浮点表示实际是 0.00499…，期望值以实现约定为准
  // 若实现用 toFixed，此处应写 ¥1.00 并在注释里点破浮点坑 —— 这本身就是加分项。
});
```
**评分点**：
- 等价类 + 边界值方法论可见（0/负数/极大/非法而非只测快乐路径）。
- 非法输入同时断言返回值与 console.warn 副作用。
- 浮点舍入坑（0.005 实为 0.00499…）能点破是高分项。
- it.each 表驱动 + 用例命名完整。
