## TST-543：笔试：笔试：多指标性能预算校验器

**题目**：实现 checkPerformanceBudget(metrics, budget)。metrics={LCP, CLS, INP, bundleKB, longTasks}；budget={LCP:ms, CLS:number, INP:ms, bundleKB:KB, longTasks:count}。要求：① 每个指标若超过预算则记为违规（越小越好）；② 容忍度 tolerance（0~1）：实际值 <= 预算*(1+tolerance) 算「警告」而非失败；③ 输出 {pass, violations:[{metric, value, budget, level:'fail'|'warn'}], score}（score = 未违规指标占比）；④ 边界：metrics 缺失某指标按 0 处理。

**答**：
- 结论：逐指标比较，按 tolerance 区分 fail/warn，聚合通过率得分。
- 实现要点：value 缺省 0；if value<=budget 正常，<=budget*(1+tol) 记 warn，否则 fail；pass = 无 fail；score = 非 fail 数 / 总数。
- 追问钩子：为什么允许 tolerance？——性能测量有噪声，容忍度避免微小波动导致构建失败；但容忍度需按指标特性设定（CLS 几乎不容忍）。

```javascript
function checkPerformanceBudget(metrics, budget, tolerance = 0) {
  const violations = [];
  let okCount = 0;
  const keys = Object.keys(budget);
  for (const k of keys) {
    const v = metrics[k] ?? 0, lim = budget[k];
    if (v <= lim) { okCount++; continue; }
    if (v <= lim * (1 + tolerance)) violations.push({ metric: k, value: v, budget: lim, level: 'warn' });
    else violations.push({ metric: k, value: v, budget: lim, level: 'fail' });
  }
  const pass = !violations.some(x => x.level === 'fail');
  return { pass, violations, score: +(okCount / keys.length).toFixed(2) };
}
console.log(checkPerformanceBudget({ LCP: 2600, CLS: 0.05 },
  { LCP: 2500, CLS: 0.1, INP: 200 }, 0.1));
```

**评分点**：
- 逐指标比较，tolerance 正确区分 fail/warn 两档。
- metrics 缺失按 0 处理，不抛错也不误判违规。
- pass 仅取决于是否有 fail（warn 不阻塞）。
- score 按未违规占比计算，输出结构可断言。
