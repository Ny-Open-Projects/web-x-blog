## TST-458：笔试：测试矩阵裁剪（浏览器×用例层）。
**题目**：规则：smoke 层全浏览器；api 层只 chromium；visual 只 chromium；e2e 核心双浏览器（chromium+webkit）。输入用例 `[{name, layer}]` 与浏览器池，输出每浏览器要跑的用例数与总执行次数（对比未裁剪）。

```javascript
const LAYER_BROWSERS = {
  smoke: ['chromium', 'firefox', 'webkit'],
  api: ['chromium'], visual: ['chromium'],
  e2e: ['chromium', 'webkit'],
};
function matrixCost(cases) {
  const per = {}; let total = 0;
  for (const c of cases) {
    const bs = LAYER_BROWSERS[c.layer];
    if (!bs) throw new Error(`未知层: ${c.layer}`);
    total += bs.length;
    for (const b of bs) per[b] = (per[b] || 0) + 1;
  }
  return { per, total, untrimmed: cases.length * 3 };
}
console.log(matrixCost([
  { name: 'a', layer: 'smoke' }, { name: 'b', layer: 'api' }, { name: 'c', layer: 'visual' },
])); // total 5 vs untrimmed 9

```

**评分点**：
- 层→浏览器映射规则表驱动。
- 总执行次数计算（裁剪前后对比，量化收益）。
- 未识别 layer 报错（规则缺口）。
- 输出每浏览器清单计数。
