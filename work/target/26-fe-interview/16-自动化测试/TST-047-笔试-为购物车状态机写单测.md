## TST-047：笔试：为购物车状态机写一组行为级单测
**答**：
- 需求：`createCart()` 支持 addItem（重复商品合并数量）、removeItem、updateQty（数量 0 等价删除）、total（金额合计）与 discount 互斥规则（满减与折扣券不可叠加，抛 COUPON_CONFLICT）。
- 设计要点：每条 it 测一个可观察行为（状态变化/返回值/抛错），不测内部数组结构；用构造 helper 造夹具避免重复代码；非法输入分支（负数量）单独覆盖。

```javascript
import { describe, it, expect } from 'vitest';
import { createCart } from './cart';

const item = (id, price, qty = 1) => ({ id, price, qty });

describe('createCart', () => {
  it('空车 total 为 0', () => {
    expect(createCart().total()).toBe(0);
  });

  it('同商品重复 add 合并数量而不是新增条目', () => {
    const cart = createCart();
    cart.add(item('k1', 100)); cart.add(item('k1', 100, 2));
    expect(cart.items().length).toBe(1);          // 行为：条目数
    expect(cart.total()).toBe(300);               // 行为：金额
  });

  it('updateQty 到 0 等价于移除', () => {
    const cart = createCart();
    cart.add(item('k1', 100, 1));
    cart.updateQty('k1', 0);
    expect(cart.total()).toBe(0);
    expect(cart.items().length).toBe(0);
  });

  it('负数量抛 INVALID_QTY', () => {
    const cart = createCart();
    expect(() => cart.add(item('k1', 100, -1))).toThrow('INVALID_QTY');
  });

  it('满减与折扣券不可叠加，抛 COUPON_CONFLICT', () => {
    const cart = createCart();
    cart.add(item('k1', 300));
    cart.applyCoupon('FULLCUT');
    expect(() => cart.applyCoupon('DISCOUNT')).toThrow('COUPON_CONFLICT');
    expect(cart.total()).toBe(300);               // 失败时不产生副作用
  });
});
```
**评分点**：
- 行为级断言（total/items/抛错码）而非戳内部实现。
- 每条 it 一个行为；失败路径断言「无副作用」（回滚语义）。
- 夹具 helper 消除重复。
- 错误码用字符串常量断言 toThrow，与业务错误体系一致。
