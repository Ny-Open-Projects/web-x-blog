## TST-604：笔试：实现测试工具选型的加权评分器（含敏感性分析）

**题目**：输入候选 [{name,scores:{维度:分}}] 与权重 {维度:权重}。输出归一化加权总分排序，并对每个维度做 ±20% 扰动，标记会导致冠军翻转的敏感维度。

**答**：
- 先做量纲归一化（不同维度分值范围不同），再乘权重求和。
- 敏感性分析：把某维度权重 ±20% 后重排，若排名翻转则该维度是决策关键，需要重点复核评分依据。
- 输出必须可审计：保留每个候选的分项分。

```javascript
function evaluate(cands, weights) {
  const keys = Object.keys(weights);
  const max = Object.fromEntries(keys.map(k =>
    [k, Math.max(...cands.map(c => c.scores[k] || 0), 1)]));
  const rank = (ws) => cands.map(c => ({
    name: c.name,
    total: +keys.reduce((s, k) =>
      s + (c.scores[k] || 0) / max[k] * ws[k], 0).toFixed(3),
  })).sort((a, b) => b.total - a.total).map(x => x.name);
  const base = rank(weights);
  const sensitive = {};
  keys.forEach(k => {
    const up = { ...weights, [k]: weights[k] * 1.2 };
    const down = { ...weights, [k]: weights[k] * 0.8 };
    sensitive[k] = rank(up)[0] !== base[0] || rank(down)[0] !== base[0];
  });
  return { base, sensitive };
}
```

**评分点**：
- 归一化处理量纲差异
- 加权求和与排序正确
- 敏感性分析覆盖 ±20% 双向
- 输出含分项分可审计
