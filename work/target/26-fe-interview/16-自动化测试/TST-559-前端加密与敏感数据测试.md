## TST-559：前端加密与敏感数据存储怎么测

**答**：
- 结论：前端「加密」不能当安全边界（密钥会在客户端泄露），重点是「不存敏感数据、不明文传输、不进日志」，加密仅作纵深防御。
- 做法：检查 localStorage/Cookie 是否存 token/身份证等（应 HttpOnly Cookie + 短时内存）；断言 HTTPS、敏感字段脱敏展示；源码/source map 不泄露密钥；日志与报错不含敏感信息。
- 追问钩子：必须在前端临时存 token 怎么办？——放内存变量而非持久化存储，配合短过期与 CSP；并明确这是缓解而非根治，核心鉴权放后端。

```javascript
// 敏感数据泄露扫描：检查存储与日志中是否出现敏感模式
const SENSITIVE = [/(?:id|identity).{0,4}\d{15,}/i, /1[3-9]\d{9}/, /[a-z0-9_-]{32,}/i];
function scanLeak(storageDump, logDump = '') {
  const hits = [];
  for (const [k, v] of Object.entries(storageDump))
    if (SENSITIVE.some(re => re.test(String(v)))) hits.push(`storage.${k}`);
  if (SENSITIVE.some(re => re.test(logDump))) hits.push('logs');
  return { leaked: hits.length > 0, hits };
}
console.log(scanLeak({ token: 'sk-abcdefghijklmnopqrstuv', phone: '13800138000' }));
```
