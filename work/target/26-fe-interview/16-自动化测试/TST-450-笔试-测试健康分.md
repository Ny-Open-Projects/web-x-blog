## TST-450：笔试：给整个测试套件打「健康分」（多因子）。
**题目**：因子：flaky 率（0-1）、时长预算达成、覆盖门槛达成率、失败归因环境占比。健康分 = 加权（各因子归一 0-1），< 0.6 判「需要治理」并列出最差因子。

```javascript
function healthScore({ flakyRate = 0.5, budgetRatio = 0.5, covPassRate = 0.5, envFailRatio = 0.5 },
  w = { flaky: 0.3, budget: 0.2, cov: 0.3, env: 0.2 }) {
  const f = { flaky: 1 - flakyRate, budget: Math.min(1, budgetRatio), cov: covPassRate, env: 1 - envFailRatio };
  const score = f.flaky * w.flaky + f.budget * w.budget + f.cov * w.cov + f.env * w.env;
  const worst = Object.entries(f).sort((a, b) => a[1] - b[1])[0];
  return { score: +score.toFixed(2),
    verdict: score < 0.6 ? '需要治理' : '健康',
    worstFactor: worst[0] };
}
console.log(healthScore({ flakyRate: 0.02, budgetRatio: 0.9, covPassRate: 0.95, envFailRatio: 0.1 }));
// score 0.95 健康

```

**评分点**：
- 四因子归一与权重配置。
- 最差因子诊断输出（治理切入点）。
- 分值趋势可比（同口径）。
- 因子缺失容错（按 0.5 中性值）。
