## TST-367：大规模重构（状态库迁移）中测试如何护航？
**答**：
- 行为基线先行：重构前用特征测试锁定外部可观测行为。
- 双轨并行：新旧实现共存，同输入对账输出一致（影子对比）。
- 分批切换：按模块批次切换，每批全量回归 + 灰度验证。
- 回滚点：每批次独立可回滚（feature flag），出问题批次回退。

```javascript
// 影子对比：新旧实现对账
const results = await Promise.all([oldStore.getState(input), newStore.getState(input)]);
expect(deepEqual(normalize(results[0]), normalize(results[1]))).toBe(true);
```
