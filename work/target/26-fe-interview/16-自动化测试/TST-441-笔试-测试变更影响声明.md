## TST-441：笔试：测试文件变更的影响声明校验（改测试必须说明动机）。
**题目**：PR 中测试文件 diff：删除用例/放宽断言（期望值变更）必须带 `Test-Reason:` trailer。实现 `checkTestDiff(diffText, trailers)`：违规输出缺失 trailer 的文件清单。

```javascript
function checkTestDiff(diffText, trailers) {
  const violations = new Set();
  let curFile = null;
  for (const line of diffText.split('\n')) {
    if (line.startsWith('+++ b/')) curFile = line.slice(6);
    if (curFile?.endsWith('.test.ts')) {
      if (/^-\s*(it|test)\(/.test(line) || (/^[+-].*toBe\(/.test(line) && /^-/.test(line)))
        violations.add(curFile);
    }
  }
  return [...violations].filter(f => !(trailers[f] || '').includes('Test-Reason'))
    .map(f => `${f} 缺 Test-Reason 声明`);
}

```

**评分点**：
- diff 解析（删除用例行/期望值变更行识别）。
- trailer 匹配（每违规文件需要声明）。
- 删除与放宽两类违规。
- 输出文件清单（可定位）。
