## TST-578：笔试：笔试：AI 自愈定位器稳定性评分

**题目**：实现 locatorStability(history)。history=[{locator, healedAt, reason, confirmedByHuman}] 为某元素的定位器变更历史。要求评估某定位器是否「稳定可采纳」：① 近 30 天 healing 次数 <= 2 得分高；② 每次 healing 有 confirmedByHuman 加分；③ reason 属于 'attr-change'（属性变更）比 'structure-change'（结构变更）更可信；④ 输出 {score:0~100, verdict:'adopt'|'review'|'reject'}。规则：score>=80 adopt，>=50 review，否则 reject。边界：history 为空视为稳定（score=100, adopt）。

**答**：
- 结论：按「healing 频率 + 人工确认 + 变更类型可信度」加权打分，分档给采纳建议。
- 实现要点：频率分 = 100 - 超限次数×惩罚；人工确认比例加权；reason 权重 attr-change>structure-change；clamp 0~100。
- 追问钩子：为什么结构变更更不可信？——结构变化常意味着 UI 语义或功能变化，healing 到新元素可能掩盖 bug；属性变更多是无关 class/id 调整，更安全。

```javascript
function locatorStability(history = [], now = Date.now()) {
  if (!history.length) return { score: 100, verdict: 'adopt' };
  const recent = history.filter(h => now - h.healedAt <= 30 * 86400000);
  let score = 100 - Math.max(0, recent.length - 2) * 20;      // 频率惩罚
  const confirmed = recent.filter(h => h.confirmedByHuman).length;
  score += recent.length ? (confirmed / recent.length) * 10 : 0;
  const attrRatio = recent.filter(h => h.reason === 'attr-change').length / recent.length;
  score += attrRatio * 10 - (1 - attrRatio) * 15;              // 类型可信度
  score = Math.max(0, Math.min(100, Math.round(score)));
  return { score, verdict: score >= 80 ? 'adopt' : score >= 50 ? 'review' : 'reject' };
}
```

**评分点**：
- 30 天窗口与 healing 次数惩罚正确。
- 人工确认比例、attr/structure 变更类型加权正确。
- score clamp 0~100 且按 80/50 阈值分档。
- 空 history 返回稳定(100, adopt) 的边界处理。
