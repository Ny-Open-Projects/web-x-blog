## TST-733：性能结果波动大时，平台如何给出「可信度」而非简单 pass/fail

**答**：
- 结论：单次性能值不可信，平台要输出「置信区间 + 稳定性评分」，把结论从布尔值升级为带置信度的判断。
- 多次采样计算方差/变异系数（CV），CV 越高可信度越低，高波动结果标记为「需复测」而非直接判失败。
- 决策分级：高置信度才 pass/fail，低置信度触发自动重跑或人工介入。
- 追问钩子：连续复测仍高波动，此时平台应该卡发布还是放行？

```javascript
// 变异系数衡量性能结果可信度
function confidence(samples) {
  const n = samples.length || 1;
  const mu = samples.reduce((s, x) => s + x, 0) / n;
  const sd = Math.sqrt(samples.reduce((s, x) => s + (x - mu) ** 2, 0) / n);
  const cv = mu ? sd / mu : 0;
  return {
    mean: +mu.toFixed(1),
    cv: +cv.toFixed(3),
    reliable: cv < 0.1,          // 变异系数 < 10% 才可信
    verdict: cv < 0.1 ? 'decide' : 'retest',
  };
}
console.log(confidence([1000, 1010, 995, 1005]));
console.log(confidence([800, 1400, 950, 1600]));
```
