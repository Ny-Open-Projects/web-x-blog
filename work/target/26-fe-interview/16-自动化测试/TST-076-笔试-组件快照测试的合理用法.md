## TST-076：笔试：为卡片组件写「小快照 + 行为断言」组合测试
**答**：
- 需求：商品卡片（图 + 标题 + 价格 + 按钮三个状态 default/disabled/sold-out）——行为用显式断言，整体视觉结构用小粒度快照兜底； sold-out 态隐藏价格。
- 设计：三个状态各一条用例；关键内容（价格、按钮可用性）显式断言；序列化摘要（只含关键字段的 toMatchInlineSnapshot）防意外结构变化。
- 边界：快照内容控制在 10 行内；动态字段（促销标签列表顺序）先 sort 再快照。

```jsx
import { render, screen } from '@testing-library/react';
import { describe, it, expect } from 'vitest';
import ProductCard from './ProductCard';

const product = { id: 'p1', name: '键盘', price: 399, tags: ['新品', '包邮'] };

describe('ProductCard', () => {
  it('默认态：价格与可点击的购买按钮', () => {
    render(<ProductCard product={product} />);
    expect(screen.getByText('¥399.00')).toBeInTheDocument();
    expect(screen.getByRole('button', { name: '加入购物车' })).toBeEnabled();
    // 小快照兜底：只序列化关键字段
    expect(summarize(product)).toMatchInlineSnapshot(`
      "{ name: "键盘", price: 399, tags: ["新品", "包邮"] }"
    `);
  });

  it('sold-out 态：按钮禁用且隐藏价格', () => {
    render(<ProductCard product={{ ...product, stock: 0 }} />);
    expect(screen.getByRole('button', { name: '加入购物车' })).toBeDisabled();
    expect(screen.queryByText('¥399.00')).not.toBeInTheDocument();
  });
});

function summarize(p) {
  const { name, price, tags } = p;
  return JSON.stringify({ name, price, tags: [...tags].sort() });
}
```
**评分点**：
- 行为断言优先（价格、按钮态），快照只做小粒度兜底。
- sold-out 分支覆盖「隐藏」语义（queryBy + not.toBeInTheDocument）。
- 动态字段排序后再快照（tags 顺序无关化）。
- 能说清为什么不用整树快照（review 不可读、-u 滥用风险）。
