## TST-516：笔试：笔试：风险热力图计算（模块 × 变更频率 × 缺陷密度）

**题目**：实现 buildHeatmap(modules)：每个模块 {name, changeFreq（近30天变更次数）, defectCount, loc, coverage}。风险分 = 变更频率分(0-5) × 0.4 + 缺陷密度分(0-5) × 0.4 + 覆盖不足分(0-5) × 0.2。其中：变更频率分 = min(5, changeFreq/2)；缺陷密度 = defectCount/(loc/1000)，密度分 = min(5, 密度)；覆盖不足分 = min(5, (1-coverage)*10)。输出按风险分降序的 [{name, score, level}]，level: >=4 高 / >=2.5 中 / 否则低。

**答**：
- 结论：热力图是多维归一化加权求和；关键是先把各维度映射到统一 0-5 量纲，再加权。
- 实现要点：分别计算三个 0-5 的分值并 clamp，再按 0.4/0.4/0.2 权重求和，最后按阈值分级并排序。
- 追问钩子：权重怎么定？——用历史逃逸缺陷做回归拟合，让「高风险」模块确实对应更多线上问题，而非拍脑袋。

```javascript
const clamp5 = n => Math.min(5, Math.max(0, n));
function buildHeatmap(modules) {
  return modules.map(m => {
    const freqScore  = clamp5(m.changeFreq / 2);
    const density    = m.defectCount / (m.loc / 1000);
    const defectScore= clamp5(density);
    const coverageScore = clamp5((1 - m.coverage) * 10);
    const score = +(freqScore * 0.4 + defectScore * 0.4 + coverageScore * 0.2).toFixed(2);
    const level = score >= 4 ? '高' : score >= 2.5 ? '中' : '低';
    return { name: m.name, score, level };
  }).sort((a, b) => b.score - a.score);
}
console.log(buildHeatmap([
  { name: '支付', changeFreq: 10, defectCount: 12, loc: 1000, coverage: 0.5 },
  { name: '关于页', changeFreq: 0, defectCount: 0, loc: 200, coverage: 0.9 },
]));
```

**评分点**：
- 各维度正确归一化到 0-5 并 clamp 上下界。
- 缺陷密度按每千行代码计算，避免规模偏差。
- 按 0.4/0.4/0.2 加权求和并按阈值分级。
- 输出降序排列，可直接渲染热力图。
