## TST-662：笔试：实现生成测试的变异存活率评估器

**题目**：实现 mutate(src) 生成变异体（>, <, ===, + 互换），survival(testFn,mutants) 统计存活率：对每个变异体执行 testFn，不抛错记为存活。返回 {total,killed,survived,score}。

**答**：
- 变异存活率 = 存活变异体 / 总变异体；存活表示该测试没发现 bug，质量差。
- 用简单算子（>、<、== 互换常数）生成变异体。
- 对每个变异体跑测试，失败即被杀死。

```javascript
const MUTANTS = [
  { from: '>', to: '<' }, { from: '<', to: '>' },
  { from: '===', to: '!==' }, { from: '+', to: '-' },
];
function mutate(src) {
  return MUTANTS.filter(m => src.includes(m.from))
    .map(m => src.replace(m.from, m.to));
}
function survival(testFn, mutants) {
  let killed = 0;
  for (const m of mutants) {
    try { testFn(m); } catch (_) { killed++; }
  }
  return {
    total: mutants.length, killed,
    survived: mutants.length - killed,
    score: mutants.length ? +((mutants.length - killed) / mutants.length)
      .toFixed(3) : 0,
  };
}
const ms = mutate('if (a > 0) return a + 1;');
console.log(survival(code => { if (eval(code)) throw 0; }, ms));
```

**评分点**：
- 变异算子覆盖四类
- 存活率公式正确
- 异常捕获即杀死判定
- 边界（无变异体）处理
