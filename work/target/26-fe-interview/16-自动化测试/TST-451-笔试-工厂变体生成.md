## TST-451：笔试：数据工厂的「变体矩阵」批量生成。
**答**：变体定义 `{name, patch}` 列表。实现 `variants(base, defs)`：每个变体 = base + patch 深合并（对象递归、数组整体替换），输出带 name 的实体列表；同名 patch 键冲突以后者为准并告警。

```javascript
function deepMerge(a, b, warns = [], path = '') {
  const out = { ...a };
  for (const [k, v] of Object.entries(b)) {
    const p = path ? `${path}.${k}` : k;
    if (v && typeof v === 'object' && !Array.isArray(v) && typeof out[k] === 'object')
      out[k] = deepMerge(out[k], v, warns, p);
    else {
      if (k in out) warns.push(`覆盖已有键: ${p}`);
      out[k] = v;
    }
  }
  return out;
}
function variants(base, defs) {
  return defs.map(d => { const warns = [];
    return { name: d.name, entity: deepMerge(base, d.patch, warns), warns }; });
}
console.log(variants({ price: 100, promo: { type: 'none' } }, [
  { name: 'seckill', patch: { promo: { type: 'seckill' }, price: 9 } },
])[0].entity); // { price: 9, promo: { type: 'seckill' } }

```

**评分点**：
- 深合并语义（对象递归/数组替换）明确。
- 冲突告警（同名变体键被覆盖）。
- 基础实体不被修改（不可变合并）。
- 输出顺序与 defs 一致。
