## TST-310：把「故障注入」也工厂化（失败的数据/服务）？
**答**：
- FaultFactory：aSlowAPI(delay)/aFailingAPI(500)/aFlakyAPI(failRate) 生成路由 mock 配置。
- 场景组合：慢接口 × 大数据量 = 极端场景矩阵，工程化生成而非手写。
- 故障注入登记：用例声明的注入在 teardown 统一撤销（route.unroute）。
- 故障注入也过门禁：注入配置须符合「错误契约」（返回 ErrorSchema）。

```javascript
const slow = FaultFactory.aSlowAPI('/api/recommend', 3000);
await slow.install(page);          // page.route 注入
// ...断言骨架/降级 UI
await slow.uninstall();            // teardown 统一撤销
r
```
