## TST-762：笔试：实现混沌实验假设的「可证伪性」检查器

**题目**：输入假设数组 [{id, metric, threshold, windowMs, observable}]。可证伪要求：有 metric、threshold 为有限数、windowMs > 0、observable 为 true。返回 {valid:[...], invalid:[{id, reasons:[...]}]}，reasons 取值为 'NO_METRIC'/'BAD_THRESHOLD'/'BAD_WINDOW'/'NOT_OBSERVABLE'。

**答**：
- 四项检查逐条收集原因，不短路。
- threshold 用 Number.isFinite 判定，排除 NaN/Infinity。
- valid 保留原始假设对象。

```javascript
function checkFalsifiability(hypotheses) {
  const valid = [], invalid = [];
  for (const h of hypotheses) {
    const reasons = [];
    if (!h.metric) reasons.push('NO_METRIC');
    if (!Number.isFinite(h.threshold)) reasons.push('BAD_THRESHOLD');
    if (!(h.windowMs > 0)) reasons.push('BAD_WINDOW');
    if (h.observable !== true) reasons.push('NOT_OBSERVABLE');
    if (reasons.length) invalid.push({ id: h.id, reasons });
    else valid.push(h);
  }
  return { valid, invalid };
}
console.log(checkFalsifiability([
  { id: 'h1', metric: 'err', threshold: 0.01, windowMs: 1000, observable: true },
  { id: 'h2', metric: '', threshold: NaN, windowMs: 0, observable: false },
]));
```

**评分点**：
- 四项检查齐全且不短路
- Number.isFinite 判定阈值
- 原因枚举正确
- valid/invalid 分组正确
