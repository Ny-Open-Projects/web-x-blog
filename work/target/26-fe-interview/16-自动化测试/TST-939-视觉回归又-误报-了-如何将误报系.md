## TST-939：视觉回归又「误报」了——如何将误报系统化分类而不是每次凭感觉调阈值？
**答**：
- 结论：先建「误报分类学」——按根因分静态类（字体/抗锯齿/滚动条/亚像素）与动态类（时间/动画/异步数据/随机内容），分类后再定策略。
- 静态类：统一渲染环境（字体、DPR、浏览器版本）或从 diff 中排除；动态类：冻结时间、禁用动画、稳定化选择器。
- 度量：统计每类误报占比，优先治理占比最高的一类，而不是无差别调容差。
- 追问钩子：一个月 50 次视觉告警里 45 次是误报，你怎么用数据说服团队先治「字体加载」而不是继续调阈值？

```javascript
const FALSE_POSITIVE_TAXONOMY = {
  static: ['字体渲染', '抗锯齿', '滚动条', 'DPR/亚像素', '浏览器版本'],
  dynamic: ['时间/日期', 'CSS 动画', '异步数据', '随机 ID/广告位'],
};
function classify(cause) {
  if (FALSE_POSITIVE_TAXONOMY.static.includes(cause)) return 'static';
  if (FALSE_POSITIVE_TAXONOMY.dynamic.includes(cause)) return 'dynamic';
  return 'unknown';
}
// 统计占比，驱动治理优先级
const reports = [
  { cause: '字体渲染', real: false }, { cause: '字体渲染', real: false },
  { cause: '异步数据', real: false }, { cause: '真实样式回归', real: true },
];
const fpByCause = reports.filter(r => !r.real).reduce((m, r) => {
  m[r.cause] = (m[r.cause] || 0) + 1; return m;
}, {});
console.log(fpByCause); // { 字体渲染:2, 异步数据:1 } → 先治字体
```
