## TST-606：笔试：实现测试插件注册中心（能力声明 + 版本兼容校验）

**题目**：实现 Registry.register(plugin) 与 resolve(capability)。plugin 含 {name,version,capabilities[],minPlatform,exclusive}。注册时校验版本与平台兼容、检测同能力互斥插件，resolve 返回可用插件名列表。

**答**：
- 用 Map<capability, plugin[]> 建索引，注册时校验必需字段。
- 语义化版本兼容：主版本相同且插件版本不小于平台要求的最低版本。
- 同一能力的多个插件要检测能力冲突并给出明确错误。

```javascript
function parseVer(v) { return String(v).split('.').map(Number); }
function compatible(have, min) {
  const a = parseVer(have), b = parseVer(min);
  return a[0] === b[0] && (a[1] > b[1] || (a[1] === b[1] && a[2] >= b[2]));
}
class Registry {
  constructor(platformVersion) { this.pv = platformVersion; this.cap = new Map(); }
  register(p) {
    if (!p.name || !p.version || !p.capabilities?.length)
      throw new Error('name/version/capabilities 必填');
    if (!compatible(p.version, p.minPlatform || '0.0.0'))
      throw new Error(`${p.name} 与平台 ${this.pv} 不兼容`);
    for (const c of p.capabilities) {
      const arr = this.cap.get(c) || [];
      if (arr.some(x => x.exclusive && p.exclusive))
        throw new Error(`${c} 存在互斥插件`);
      arr.push(p); this.cap.set(c, arr);
    }
  }
  resolve(cap) { return (this.cap.get(cap) || []).map(p => p.name); }
}
```

**评分点**：
- 版本兼容判断正确（主版本一致 + 向后兼容）
- capability 索引结构合理
- 互斥冲突检测并抛出可读错误
- 缺少必填字段时有校验
