## TST-139：笔试：为暗色模式切换写测试（matchMedia + localStorage + 优先级）
**答**：
- 场景：主题切换三态逻辑——用户手动选择存 localStorage；未选择时跟随系统 `prefers-color-scheme`；切换时更新 `document.documentElement.dataset.theme` 并持久化。测试难点是 matchMedia 在 jsdom 里不存在，必须 stub 且**返回值可动态控制**。
- stub 设计：返回带 `matches` 属性 + `addEventListener` 的对象，测试里写一个 `setSystemTheme('dark')` 助手改内部状态并触发监听器——这样才能测「系统主题变化实时跟随」这条最难的路。
- 优先级验证是本题灵魂：手动选择 > 系统偏好 > 默认浅色，三条路径各一用例。

```jsx
// 可控的 matchMedia stub
let listeners = [];
function stubMatchMedia(initial = false) {
  const mql = { matches: initial,
    addEventListener: (_t, cb) => listeners.push(cb),
    removeEventListener: (_t, cb) => (listeners = listeners.filter((l) => l !== cb)),
    addListener(cb) { listeners.push(cb); },           // 旧 API 兼容
  };
  window.matchMedia = vi.fn().mockReturnValue(mql);
  return { set(matches) { mql.matches = matches; listeners.forEach((cb) => cb()); } };
}

import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import ThemeToggle from './ThemeToggle';

afterEach(() => { localStorage.clear(); vi.unstubAllGlobals(); });

test('无手动选择时跟随系统主题，且响应系统变化', async () => {
  const sys = stubMatchMedia(true);                    // 系统暗色
  render(<ThemeToggle />);
  expect(document.documentElement.dataset.theme).toBe('dark');

  sys.set(false);                                      // 用户系统切成浅色
  expect(document.documentElement.dataset.theme).toBe('light'); // 实时跟随
});

test('手动选择优先于系统，并持久化', async () => {
  stubMatchMedia(false);                               // 系统浅色
  render(<ThemeToggle />);
  await userEvent.click(screen.getByRole('button', { name: '切换主题' }));

  expect(document.documentElement.dataset.theme).toBe('dark');     // 覆盖系统
  expect(localStorage.getItem('theme')).toBe('dark');              // 持久化
});

test('已有持久化选择时忽略系统', () => {
  localStorage.setItem('theme', 'light');
  stubMatchMedia(true);                                // 系统暗色
  render(<ThemeToggle />);
  expect(document.documentElement.dataset.theme).toBe('light');    // 手动 > 系统
});
```

**评分点**：
1. matchMedia stub 必须支持动态改 matches + 触发 change 监听（静态 stub 测不了跟随）。
2. 三条优先级路径各覆盖：手动 > 系统 > 默认。
3. localStorage 持久化断言 + 用例间清理（隔离意识）。
4. addListener 旧 API 兼容（真实组件库常踩）。
