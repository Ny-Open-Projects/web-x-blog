## TST-437：笔试：季度测试资产盘点报告计算。
**题目**：资产 `[{kind: 'case'|'baseline'|'factory', lastTouched, defectsFound, maintainHours}]`。输出：老化资产（半年未动零发现）计数/维护工时分布/按 kind 汇总；给出处置建议（rewrite/archive/delete 启发式）。

```javascript
function auditAssets(assets, now, { agingDays = 182 } = {}) {
  const aging = assets.filter(a =>
    now - a.lastTouched > agingDays * 86_400_000 && a.defectsFound === 0);
  const hours = assets.map(a => a.maintainHours).sort((x, y) => x - y);
  const byKind = {};
  for (const a of assets)
    byKind[a.kind] = (byKind[a.kind] || 0) + 1;
  return {
    agingCount: aging.length,
    aging: aging.map(a => ({ id: a.id,
      suggest: a.maintainHours > hours[hours.length - 1] ? 'rewrite' : 'archive' })),
    maintain: { avg: hours.reduce((s, x) => s + x, 0) / hours.length, max: hours[hours.length - 1] },
    byKind,
  };
}

```

**评分点**：
- 老化判定（时间 + 零发现双条件）。
- 工时分布（均值/最大值）。
- 启发式处置建议规则明确。
- 按 kind 分组汇总。
