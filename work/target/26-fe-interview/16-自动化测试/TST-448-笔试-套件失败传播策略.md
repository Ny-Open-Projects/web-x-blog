## TST-448：笔试：套件失败的传播策略配置（谁阻塞谁）。
**答**：套件依赖图 + 策略 `{onFail: 'skip-dependents'|'continue'}`。实现 `propagate(results, deps, policy)`：失败套件的直接与传递依赖者标记 skipped（skip 模式），返回最终状态表。

```javascript
function propagate(results, deps, policy) {
  const failed = new Set(Object.entries(results).filter(([, s]) => s === 'fail').map(([k]) => k));
  const final = { ...results };
  if (policy === 'skip-dependents') {
    let grow = true;
    while (grow) {
      grow = false;
      for (const [suite, ds] of Object.entries(deps))
        if (final[suite] === undefined && ds.some(d => failed.has(d))) {
          final[suite] = 'skipped'; failed.add(suite); grow = true;
        }
    }
  }
  return Object.fromEntries(Object.entries(final).map(([k, v]) =>
    [k, v === 'skipped' ? `${v}(上游失败)` : v]));
}

```

**评分点**：
- 传递性 skip（依赖链传播）。
- continue 模式全跑（对照）。
- 状态三值（pass/fail/skipped）。
- 输出带 skip 原因（哪个上游失败）。
