## TST-853：笔试：手写一个「资源瀑布图关键路径分析器」，识别阻塞渲染资源
**答**：
- 需求：实现 analyzeCriticalPath(resources) —— resources 含 {name, startTime, duration, type, renderBlocking}，找出关键路径总时长与阻塞资源。
- 规则：关键路径 = 从 0 开始、renderBlocking 为 true 的资源按 startTime→endTime 串起来的最长链；输出阻塞资源列表。
- 边界：无资源返回 0；重叠资源取并集时长；按 startTime 升序处理。

```javascript
function analyzeCriticalPath(resources) {
  if (!resources.length) return { criticalTime: 0, blocking: [] };
  const blocking = resources.filter(r => r.renderBlocking)
    .sort((a, b) => a.startTime - b.startTime);
  // 计算阻塞资源覆盖的时间区间并集
  let total = 0, curStart = -1, curEnd = -1;
  for (const r of blocking) {
    const end = r.startTime + r.duration;
    if (curStart === -1) { curStart = r.startTime; curEnd = end; }
    else if (r.startTime <= curEnd) curEnd = Math.max(curEnd, end);
    else { total += curEnd - curStart; curStart = r.startTime; curEnd = end; }
  }
  if (curStart !== -1) total += curEnd - curStart;
  return {
    criticalTime: Math.round(total),
    blocking: blocking.map(r => r.name),
  };
}
console.log(analyzeCriticalPath([
  { name: 'app.css', startTime: 0, duration: 200, renderBlocking: true },
  { name: 'app.js', startTime: 150, duration: 300, renderBlocking: true },
  { name: 'img.png', startTime: 100, duration: 400, renderBlocking: false },
])); // criticalTime 450（CSS+JS 并集），不含图片
```
**评分点**：
- 正确筛选 renderBlocking 资源并计算时间并集（避免重叠重复计）。
- 按 startTime 排序，处理重叠区间。
- 无资源/边界返回 0。
- 能点出「关键路径上的阻塞资源是优化首屏的首要目标」这一性能分析核心。
