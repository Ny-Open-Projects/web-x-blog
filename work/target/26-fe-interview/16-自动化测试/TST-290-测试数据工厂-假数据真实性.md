## TST-290：测试数据（faker 生成）如何保证「真实感」与「确定性」的平衡？
**答**：
- 确定性：faker 用固定 seed——同一用例每次跑数据一致，失败可复现。
- 真实感：地址/姓名/手机号用本地化中文包，格式合规（能过业务校验）。
- 边界数据显式化：工厂出「合法随机」数据，边界用例（超长/空/特殊字符）用专用 builder 显式构造。
- 禁用真 PII：全假数据 + 明显测试标记，防止与生产数据混淆。

```javascript
faker.seed(42);                        // 确定性
export const aUser = () => ({
  name: faker.person.fullName(),       // 本地化假名
  phone: `138${faker.string.numeric(8)}`,  // 格式合规
  marker: 'E2E-TEST',
});
```
