## ALG-225：表格多列排序：按分类升序再金额降序再日期升序（比较器链 + 稳定排序语义）
**答**：表格多列排序（ALG-004 单列的进阶）：用户先点分类再点金额，排序规则是"组合键"（第一列主键，同值看第二列……）。要点：比较器链、null 值统一置尾、稳定语义（同键保持原顺序）、降序反转。

**思路**：维护 sortSpec = [{key, dir}]，比较器链逐键比较；ES2019 Array.sort 已稳定（引擎保证），但显式幂等比较器仍是好习惯。

```javascript
function multiSort(rows, spec) {                      // spec: [{ key, dir: 'asc'|'desc' }]
  const cmp = (a, b) => {
    for (const { key, dir } of spec) {
      const av = a[key], bv = b[key];
      if (av == null && bv == null) continue;         // 双 null：看下一键
      if (av == null) return 1;                       // null 统一置尾（不随 dir 反转）
      if (bv == null) return -1;
      let c = 0;
      if (typeof av === 'string' && typeof bv === 'string') c = av.localeCompare(bv);
      else c = av < bv ? -1 : av > bv ? 1 : 0;
      if (c !== 0) return dir === 'desc' ? -c : c;    // 降序只反转值比较，null 不反转
    }
    return 0;
  };
  return [...rows].sort(cmp);                         // 浅拷贝；ES2019+ sort 稳定
}
const orders = [
  { city: '上海', amount: 80,  createdAt: '2026-01-02' },
  { city: '北京', amount: 100, createdAt: '2026-01-03' },
  { city: '北京', amount: 120, createdAt: '2026-01-01' },
  { city: null,   amount: 50,  createdAt: '2026-01-04' },   // null 城市应置尾
];
console.log(multiSort(orders, [
  { key: 'city', dir: 'asc' },
  { key: 'amount', dir: 'desc' },
  { key: 'createdAt', dir: 'asc' },
]).map(r => `${r.city ?? '(null)'}:${r.amount}`));
// 输出：同城市内金额降序（120→100）、null 城市置尾；城市列先后由 locale collation 决定（拼音序/码点序）
// 注意：null 置尾不随 dir 反转（降序时 null 仍在最后）——用户预期一致
// 数字列性能：大表用预计算索引（按组合键排序后缓存），排序触发节流
```

**评分点**：
- 比较器链逐键短路正确；desc 只反转值比较（null 保持置尾）。
- null 处理策略一致且有意识（localeCompare 用于字符串）。
- 稳定排序认知（ES2019+ 保证）+ 浅拷贝不改原数据。
- 多列 spec 数据驱动（可持久化用户排序偏好）。
