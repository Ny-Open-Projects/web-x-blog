## HW-265：手写一个协作文档快照：定期快照与增量日志混合存储

**答**：
- 需求：实现 SnapshotStore：每 N 次操作或每 5 分钟生成快照（异步，不阻塞编辑）；存储 {snapshot, opsAfter: [...], rev}；加载流程：取最近快照 + 重放其后 ops；提供 compact（快照吃掉旧日志，释放存储）。
- 边界：快照生成期间新 op 归入 opsAfter（序号衔接）；存储配额（快照保留最近 3 个）；加载时日志空洞回退到更早快照。
- 评分点：序号衔接；compact 释放；空洞回退。

```javascript
class SnapshotStore {
  constructor(storage, { everyN = 500 } = {}) { this.store = storage; this.n = everyN; this.opsSince = 0; }
  async maybeSnapshot(doc, rev) {
    if (++this.opsSince < this.n) return;
    this.opsSince = 0;
    const snap = { rev, doc: serialize(doc), ts: Date.now(), opsAfter: [] };
    await this.store.put('snap-latest', snap);
    await this.trim();
  }
  onOp(op) { this.opsSince++; this.latest?.opsAfter.push(op); }   // 快照期间 op 衔接
  async load() {                                            // 快照+重放
    for (const k of ['snap-latest', 'snap-2', 'snap-3']) {  // 空洞回退链
      const snap = await this.store.get(k);
      if (!snap) continue;
      const doc = deserialize(snap.doc);
      let ok = true;
      for (const op of snap.opsAfter) { try { applyOpToDoc(doc, op); } catch { ok = false; break; } }
      if (ok) return { doc, rev: snap.rev + snap.opsAfter.length };
    }
    return null;
  }
  async trim() {                                            // 保留 3 个快照
    const all = await this.store.keys('snap-');
    for (const k of all.sort().slice(0, -3)) await this.store.del(k);
  }
}
```
