## HW-236：手写一个拖拽排序列表编辑器：拖拽预览与插入位置计算

**答**：
- 需求：实现 DragSort：onDragStart(item) 记录；onDragOver(e) 计算目标索引（按指针 y 与各项中点比较），渲染占位符（原位置隐藏 + 目标处插入占位）；onDrop 提交 reorder（splice 移动）；提供预览（跟随指针的半透明克隆）。
- 边界：自拖自放（索引未变）不触发 reorder；快速拖动防抖（索引变化才更新占位）；触摸设备用 pointer 事件统一。
- 评分点：中点比较算法；占位符与原项分离；索引不变短路。

```javascript
class DragSort {
  constructor(container, items) {
    this.el = container; this.items = items; this.ghost = null; this.lastIdx = -1;
    container.addEventListener('pointerdown', e => this.start(e));
  }
  start(e) {
    const itemEl = e.target.closest('[data-item]');
    if (!itemEl) return;
    this.dragItem = itemEl.dataset.item;
    itemEl.classList.add('dragging-src');                      // 原位隐藏
    this.ghost = itemEl.cloneNode(true);
    Object.assign(this.ghost.style, { position: 'fixed', opacity: '.5', pointerEvents: 'none',
      left: e.clientX + 'px', top: e.clientY + 'px' });
    document.body.appendChild(this.ghost);
    addEventListener('pointermove', this.over = ev => this.overFn(ev));
    addEventListener('pointerup', () => this.drop(), { once: true });
  }
  overFn(e) {
    this.ghost.style.left = e.clientX + 'px'; this.ghost.style.top = e.clientY + 'px';
    const idx = this.calcIndex(e.clientY);
    if (idx !== this.lastIdx) {                                // 索引变化才更新
      this.lastIdx = idx;
      this.renderPlaceholder(idx);
    }
  }
  calcIndex(y) {                                               // 中点比较
    const els = [...this.el.querySelectorAll('[data-item]:not(.dragging-src)')];
    let idx = els.length;
    for (let i = 0; i < els.length; i++)
      if (y < els[i].getBoundingClientRect().top + els[i].offsetHeight / 2) { idx = i; break; }
    return idx;
  }
  drop() {
    removeEventListener('pointermove', this.over);
    this.ghost?.remove();
    const from = this.items.indexOf(this.dragItem);
    const to = this.lastIdx;
    if (from >= 0 && to >= 0 && from !== to) {                 // 索引不变短路
      const [it] = this.items.splice(from, 1);
      this.items.splice(from < to ? to - 1 : to, 0, it);
      this.onChange?.(this.items);
    }
    this.el.querySelector('.drag-placeholder')?.remove();
  }
  renderPlaceholder(idx) {
    this.el.querySelector('.drag-placeholder')?.remove();
    const ph = document.createElement('div');
    ph.className = 'drag-placeholder';
    const els = [...this.el.children].filter(c => !c.classList.contains('dragging-src'));
    els[idx] ? this.el.insertBefore(ph, els[idx]) : this.el.appendChild(ph);
  }
}
```
