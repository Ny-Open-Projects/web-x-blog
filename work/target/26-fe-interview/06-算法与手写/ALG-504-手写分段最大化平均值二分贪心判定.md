## ALG-504：手写分段最大化平均值（二分+贪心判定）：绩效分组

**答**：
- 题目：员工按序分组（连续段），每组人数 ≥ m，最大化「平均分最低组」的平均分。二分答案 + 贪心判定（判定有精度陷阱——平均值不满足单调贪心的简单判定，需前缀和+DP 或容许近似）。
- 思路：标准做法：二分 mid（假设阈值），判定 = DP：dp[i] = 是否能分组使每组均值 >= mid。均值不可加——用「和与个数」二元组 DP 或参数搜索。
- 评分点：均值不可加的陷阱；二分答案的判定设计；连续段 DP O(n²) 与优化。

```javascript
function maxMinAverage(scores, m) {                        // scores 有序（按序分组）
  const n = scores.length;
  const feasible = (mid) => {                              // 判定：每组均值 >= mid
    // dp[i] = 前 i 人分组后每组均值 >= mid 是否可行（记录最少组数）
    const dp = new Array(n + 1).fill(Infinity);
    dp[0] = 0;
    const prefix = [0];
    scores.forEach((v, i) => prefix.push(prefix[i] + v));
    for (let i = 1; i <= n; i++)
      for (let j = 0; j < i; j++) {                        // 组 [j+1, i]
        if (i - j < m) continue;
        const avg = (prefix[i] - prefix[j]) / (i - j);
        if (avg >= mid && dp[j] + 1 <= Math.floor(n / m))
          dp[i] = Math.min(dp[i], dp[j] + 1);
      }
    return dp[n] !== Infinity;
  };
  let lo = Math.min(...scores), hi = Math.max(...scores);
  while (hi - lo > 1e-6) {                                 // 实数二分
    const mid = (lo + hi) / 2;
    feasible(mid) ? lo = mid : hi = mid;
  }
  return lo;
}
```
