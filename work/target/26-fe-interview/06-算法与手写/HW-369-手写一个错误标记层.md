## HW-369：手写一个错误标记层：诊断信息定位与悬停提示

**答**：
- 需求：实现 DiagnosticLayer：诊断 {line, col, len, severity, message}（LSP 风格）；渲染波浪线装饰（按 severity 颜色）；hover 提示（延迟 300ms，定位到诊断区间）；点击跳转（下一处/上一处循环）。
- 边界：诊断随文档编辑重映射（位置漂移用 delta 平移，同 CommentAnchor 思路）；多个诊断同区间取最高严重级；hover 防抖与快速移动取消。
- 评分点：位置重映射；严重级排序；hover 延迟取消。

```javascript
class DiagnosticLayer {
  constructor() { this.items = []; this.hoverTimer = null; }
  setDiagnostics(items) { this.items = items.sort((a, b) =>
    SEV[b.severity] - SEV[a.severity]); }                    // 严重级排序
  remap(line, col, delta, len) {                             // 编辑后位置重映射
    for (const d of this.items) {
      if (d.line !== line) continue;
      if (col + len <= d.col) d.col += delta;                // 编辑在诊断前：平移
      else if (col < d.col + d.len) { d.len += delta; if (d.len <= 0) d.len = 1; }   // 区间内：扩展
    }
  }
  render(ctx, lineHeight) {                                  // 波浪线装饰
    for (const d of this.items) {
      ctx.strokeStyle = { error: 'red', warning: 'orange', info: 'blue' }[d.severity];
      ctx.setLineDash([2, 2]);
      const x = this.text.posAt(d.line, d.col);
      const y = d.line * lineHeight + lineHeight - 2;
      ctx.beginPath();
      ctx.moveTo(x, y);
      ctx.lineTo(x + this.text.posAt(d.line, d.col + d.len) - x, y);
      ctx.stroke();
    }
  }
  onHover(px, py, showTip) {                                 // hover 延迟提示
    clearTimeout(this.hoverTimer);
    this.hoverTimer = setTimeout(() => {
      const d = this.at(px, py);
      if (d) showTip(d.message, { severity: d.severity });
    }, 300);                                                 // 快速移动自动取消
  }
  at(px, py) {
    const line = Math.floor(py / this.lineH);
    const col = this.text.offsetAt(line, px);
    return this.items.find(d => d.line === line && col >= d.col && col <= d.col + d.len);
  }
  next(fromLine) {                                           // 循环跳转
    const sorted = [...this.items].sort((a, b) => a.line - b.line);
    return sorted.find(d => d.line > fromLine) ?? sorted[0];
  }
}
const SEV = { error: 3, warning: 2, info: 1 };
```

## 补充：评分点与变体

**评分点**：

- 位置重映射只平移编辑点之后的诊断，编辑点之前的位置不动；全量平移会让前面的标记越错越远
- 同区间多诊断取最高 severity 合并渲染，叠多层波浪线既看不清也浪费 DOM
- hover 300ms 延迟与移出即 clearTimeout 必须成对，缺一个就会出现提示滞后弹在别的行上
- 上一处/下一处循环用取模，索引要先规范到 [0, n)，否则 -1 与 n 会越界

**变体与延伸**：

1. 编辑后诊断已完全失效 → 标 stale 并在下次语义分析返回后替换，不能拿旧位置硬画
2. 上千条诊断同时渲染卡顿 → 只渲染视口内的，按行号建索引按需取
3. 跨行诊断怎么画波浪线 → 按行拆成多段，末段长度按剩余字符数算，首段从起始列开始
