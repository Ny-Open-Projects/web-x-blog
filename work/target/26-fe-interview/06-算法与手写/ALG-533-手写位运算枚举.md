## ALG-533：手写位运算+枚举：权限组合

**答**：
- 题目：权限 bitmask 组合校验（权限 8 种，掩码判断），枚举「所有有效权限组合」且组合数可控（≤ 2^8）。子集枚举：位掩码遍历或 Gray 码。
- 思路：掩码判定 (mask & PERM) === PERM；全组合枚举 mask 0..2^8-1；子集枚举 sub = (sub - 1) & mask 技巧。
- 评分点：位运算判定；全子集枚举技巧；枚举上限控制。

```javascript
const PERMS = { READ: 1, WRITE: 2, DELETE: 4, ADMIN: 8, EXPORT: 16, SHARE: 32 };
function hasPerms(userMask, required) {
  return (userMask & required) === required;               // 全含判定
}
function enumerateSubsets(mask) {                          // 枚举 mask 的所有子集
  const out = [];
  let sub = mask;
  do {
    out.push(sub);
    sub = (sub - 1) & mask;                                // 子集枚举技巧
  } while (sub !== mask);
  return out;                                              // O(2^popcount)
}
function effectivePerms(roleMasks) {                       // 多角色并集
  return roleMasks.reduce((m, r) => m | r, 0);             // 位或合并
}
// 例：enumerateSubsets(PERMS.READ | PERMS.WRITE) → [3, 2, 1, 0]
// 子集枚举复杂度 = 2^有效位数——8 权限仅 256 组合可控
```
