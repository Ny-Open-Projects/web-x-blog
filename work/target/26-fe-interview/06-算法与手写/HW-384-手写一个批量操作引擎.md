## HW-384：手写一个批量操作引擎：事务化批量编辑与失败回滚清单

**答**：
- 需求：实现 BatchEditor：批量操作 [{target, action, params}]；事务执行：单条失败不中断（记录失败清单），成功项可整体回滚（逆操作栈）；进度回调；断点续批（中断后从上次成功位置续跑）。
- 边界：逆操作自动生成（action 注册表含 inverse）；部分失败的上报口径（成功 N / 失败 M）；续批游标持久化；并发限制（批量内串行或限并发）。
- 评分点：逆操作栈；失败清单口径；续批游标。

```javascript
class BatchEditor {
  constructor(actionRegistry) { this.regs = actionRegistry; }   // action -> {run, inverse}
  async run(ops, { concurrency = 1, checkpoint = 'batch-cursor' } = {}) {
    const cursor = +(localStorage.getItem(checkpoint) ?? 0);   // 断点续批
    const results = { done: [], failed: [], inverseStack: [] };
    const queue = ops.slice(cursor);
    let i = cursor;
    const worker = async () => {
      while (queue.length) {
        const op = queue.shift();
        const reg = this.regs[op.action];
        try {
          const result = await reg.run(op.params);
          results.done.push({ i, result });
          results.inverseStack.push(() => reg.inverse(op.params, result));   // 逆操作栈
        } catch (e) {
          results.failed.push({ i, op, error: String(e) });   // 单条失败不中断
        }
        i++;
        localStorage.setItem(checkpoint, String(i));          // 游标持久化
        this.onProgress?.(i / ops.length, results.failed.length);
      }
    };
    await Promise.all(Array(concurrency).fill(worker));
    localStorage.removeItem(checkpoint);                      // 完成清游标
    return { ...results, summary: `成功 ${results.done.length} / 失败 ${results.failed.length}` };
  }
  rollback() {                                               // 整体回滚
    while (this._inverseStack?.length) this._inverseStack.pop()();
  }
}
```
