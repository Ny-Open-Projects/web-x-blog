## ALG-490：手写划分字母区间：分片上传边界

**答**：
- 题目：文件按内容特征分片——每个特征出现在若干位置，切片必须「包含完整特征」（特征的所有出现位置在同一片），求最少切片数及各片边界。
- 思路：记录每个字符（特征）最后出现位置 last[c]；扫描 i 时当前片边界 = max(last[c])；i 到达边界即切一片。
- 评分点：last 数组；边界扩展；片数 = 切点数。

```javascript
function partitionLabels(features) {                       // features: 特征序列
  const last = new Map();
  features.forEach((c, i) => last.set(c, i));              // 每特征最后位置
  const parts = [];
  let start = 0, end = 0;
  for (let i = 0; i < features.length; i++) {
    end = Math.max(end, last.get(features[i]));            // 扩展片边界
    if (i === end) {                                       // 到达边界：切片
      parts.push({ start, end, size: end - start + 1 });
      start = i + 1;
    }
  }
  return parts;
}
// 例：ababcbacadefegde → 片 "ababcbaca" | "defegde" —— 每特征完整在同一片
```
