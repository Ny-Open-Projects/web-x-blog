## HW-345：手写一个图形拖拽与对齐吸附：网格吸附与对齐参考线

**答**：
- 需求：实现 SnapDrag：拖拽时对齐吸附——网格（snap 到 grid 步长）、其他节点边缘/中心对齐（阈值内吸附并显示参考线）；参考线渲染（红色对齐线）；吸附开关与阈值配置；松手提交最终位置。
- 边界：x/y 独立吸附（可只吸 x）；多候选吸附取最近；参考线在松手后消失；拖拽中用 transform 而非重绘全场景。
- 评分点：两类吸附（网格/对齐）；最近候选；参考线生命周期。

```javascript
class SnapDrag {
  constructor(scene, { grid = 10, alignTh = 6 } = {}) { this.scene = scene; this.grid = grid;
    this.th = alignTh; this.guides = []; }
  snap(x, y, dragNode) {
    let sx = Math.round(x / this.grid) * this.grid;          // 网格吸附
    let sy = Math.round(y / this.grid) * this.grid;
    this.guides = [];
    const others = this.scene.nodes.filter(n => n !== dragNode);
    for (const [val, axis] of [[sx, 'x'], [sy, 'y']]) {
      const targets = [];
      for (const n of others) {                              // 边缘/中心对齐候选
        const b = bounds(n);
        if (axis === 'x') targets.push(b.x, b.x + b.w / 2, b.x + b.w);
        else targets.push(b.y, b.y + b.h / 2, b.y + b.h);
      }
      let best = null;
      for (const t of targets) {
        const d = Math.abs(val - t);
        if (d <= this.th && (!best || d < best.d)) best = { t, d };
      }
      if (best) {                                            // 最近候选吸附
        if (axis === 'x') { sx = best.t; this.guides.push({ axis: 'v', pos: best.t }); }
        else { sy = best.t; this.guides.push({ axis: 'h', pos: best.t }); }
      }
    }
    return { x: sx, y: sy };
  }
  renderGuides(ctx) {                                        // 参考线（松手后清空）
    ctx.strokeStyle = 'red';
    for (const g of this.guides) {
      ctx.beginPath();
      if (g.axis === 'v') { ctx.moveTo(g.pos, 0); ctx.lineTo(g.pos, ctx.canvas.height); }
      else { ctx.moveTo(0, g.pos); ctx.lineTo(ctx.canvas.width, g.pos); }
      ctx.stroke();
    }
  }
}
```
