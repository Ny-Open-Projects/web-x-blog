## ALG-386：滑动窗口最值的两种实现对比：动态区间最值

**答**：
- 题目：窗口最值（最近 W 秒峰值）两种实现：① 单调队列（窗口严格固定、数据流式，O(1) 摊还）；② 线段树（窗口任意、支持历史修改，O(log n)）。对比给出代码与选型。
- 思路：单调队列维护递减下标队列，队首即窗口最大；线段树通用但更重。窗口固定+流式 → 队列；区间任意+修改 → 线段树。
- 评分点：单调队列出窗条件；两方案复杂度与适用边界。

```javascript
class MonoQueueWindow {
  constructor(W) { this.W = W; this.dq = []; this.vals = []; }
  push(i, v) {                                             // 数据流式
    while (this.dq.length && this.vals[this.dq.at(-1)] <= v) this.dq.pop();   // 维护递减
    this.dq.push(i); this.vals[i] = v;
    while (this.dq[0] <= i - this.W) this.dq.shift();      // 出窗
    return this.vals[this.dq[0]];                          // O(1) 摊还
  }
}
class SegWindow {
  constructor(n) { this.t = new Array(4 * n).fill(-Infinity); this.n = n; }
  set(i, v, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.t[node] = v;
    const m = (l + r) >> 1;
    i <= m ? this.set(i, v, node * 2, l, m) : this.set(i, v, node * 2 + 1, m + 1, r);
    this.t[node] = Math.max(this.t[node * 2], this.t[node * 2 + 1]);
  }
  query(ql, qr, node = 1, l = 0, r = this.n - 1) {         // 任意窗口 O(log n)
    if (qr < l || r < ql) return -Infinity;
    if (ql <= l && r <= qr) return this.t[node];
    const m = (l + r) >> 1;
    return Math.max(this.query(ql, qr, node * 2, l, m),
      this.query(ql, qr, node * 2 + 1, m + 1, r));
  }
}
// 选型：固定窗口流式→MonoQueueWindow O(1)；任意区间+修改→SegWindow O(log n)
```

## 补充：评分点与变体

**评分点**：

- 单调队列维护递减时用 `this.vals[this.dq.at(-1)] <= v` 弹尾，等号必须取到，否则同值下标会在队列里堆积、放大内存
- 出窗判断比较的是下标 `dq[0] <= i - this.W`，不是比较值；比值会在重复值场景下把仍在窗内的下标误删
- 线段树要说清三件事：空间开 4n、越界返回 -Infinity、全覆盖直接返回节点值，三者缺一查询会错
- 选型必须绑定条件：窗口固定且只追加走队列 O(1) 摊还；窗口端点可移动或要改历史值走线段树 O(log n)

**变体与延伸**：

1. 每次查询的窗口宽度 W 都不同 → 单调队列的出窗条件与 W 绑定，失效；改用线段树或稀疏表按区间查
2. 同时要窗口最大值与最小值 → 两套单调队列并行维护，或线段树节点存 `{max, min}` 二元组
3. 元素会乱序过期（不是 FIFO 出窗）→ 队列只能头部删，改用堆加懒删除，弹出时校验是否已过期
