## HW-235：手写一个编辑器大文档优化：分块持久化与惰性解析

**答**：
- 需求：实现 LazyDoc：文档按 block 分块存储（每 100 block 一 chunk），打开时只加载首 chunk；访问越界 chunk 时惰性加载（异步，加载中显示占位）；编辑只写回脏 chunk；提供 flushAll。
- 边界：chunk 加载并发去重（同 chunk 只加载一次）；跨 chunk 编辑触发双 chunk 加载；内存上限（LRU 释放远端 chunk，仅未脏的）。
- 评分点：惰性加载去重；脏 chunk 追踪；LRU 释放条件。

```javascript
class LazyDoc {
  constructor(loader, { chunkSize = 100, memChunks = 20 } = {}) {
    this.loader = loader; this.size = chunkSize; this.mem = memChunks;
    this.chunks = new Map(); this.dirty = new Set(); this.pending = new Map();
  }
  chunkOf(blockIdx) { return Math.floor(blockIdx / this.size); }
  async get(blockIdx) {
    const k = this.chunkOf(blockIdx);
    if (this.chunks.has(k)) return this.chunks.get(k)[blockIdx % this.size];
    if (!this.pending.has(k)) {                                // 并发去重
      const p = this.loader(k).then(data => {
        this.chunks.set(k, data); this.pending.delete(k); this.evict();
        return data[blockIdx % this.size];
      });
      this.pending.set(k, p);
    }
    return this.pending.get(k);
  }
  edit(blockIdx, block) {
    const k = this.chunkOf(blockIdx);
    const c = this.chunks.get(k);
    c[blockIdx % this.size] = block;
    this.dirty.add(k);                                         // 脏 chunk 追踪
  }
  evict() {                                                    // LRU 释放未脏远端
    while (this.chunks.size > this.mem) {
      const k = this.chunks.keys().next().value;
      if (this.dirty.has(k)) { this.dirty.delete(k); this.saveChunk(k); }
      this.chunks.delete(k);
    }
  }
  async flushAll() { for (const k of this.dirty) await this.saveChunk(k); this.dirty.clear(); }
  saveChunk(k) { return this.store?.put?.(k, this.chunks.get(k)); }
}
```
