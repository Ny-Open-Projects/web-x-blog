## HW-291：手写一个日期范围选择器：区间选择状态机与快捷项

**答**：
- 需求：实现 DateRangePicker：点击第一天为起点，第二次点击为终点（起点在终点后自动交换）；第三次点击重开区间（状态机：empty→picking→done）；hover 预览区间；快捷项（今天/近7天/本月）直接设置区间；禁用日期（过去/超过最大跨度）不可选。
- 边界：起点==终点（同日区间合法）；maxSpan 约束（hover 时超范围预览截断）；跨月面板预览。
- 评分点：三态状态机；hover 预览；maxSpan。

```javascript
class DateRangePicker {
  constructor({ maxSpanDays = 90 } = {}) { this.state = 'empty'; this.maxSpan = maxSpanDays; }
  click(date, isDisabled) {
    if (isDisabled) return this.state;
    if (this.state === 'empty' || this.state === 'done') {
      this.start = date; this.end = null; this.state = 'picking';    // 新区间
    } else {                                                 // picking：第二击
      if (date < this.start) [this.start, this.end] = [date, this.start];   // 自动交换
      else this.end = date;
      this.state = 'done';
    }
    return this.state;
  }
  hover(date) {                                              // 预览区间
    if (this.state !== 'picking') return null;
    const end = date < this.start ? this.start : date;
    if (diffDays(end, this.start) > this.maxSpan)            // maxSpan 截断
      return { start: this.start, end: addDays(this.start, this.maxSpan), truncated: true };
    return { start: this.start, end, truncated: false };
  }
  preset(name) {                                             // 快捷项
    const today = new Date();
    const map = {
      today: [today, today],
      last7: [addDays(today, -6), today],
      month: [new Date(today.getFullYear(), today.getMonth(), 1), today],
    };
    const [s, e] = map[name] ?? [];
    if (s && diffDays(e, s) <= this.maxSpan) { this.start = s; this.end = e; this.state = 'done'; }
    return [this.start, this.end];
  }
}
const diffDays = (a, b) => Math.round((new Date(b) - new Date(a)) / 86400000);
const addDays = (d, n) => new Date(new Date(d).getTime() + n * 86400000);
```
