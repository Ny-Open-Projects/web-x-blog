## ALG-356：手写线段树上二分：区间内第一个大于 x 的位置（投放首次超预算日期）

**答**：
- 题目：广告投放按天记录消耗，查「本周内第一次日消耗超过预算 X 的日期」。区间最大值线段树 + 树上二分。
- 思路：先查整段最大值是否 > x（否直接返回-1）；是则递归：左子树最大 > x 走左，否则走右——本质是带着「约束」的二分。复杂度 O(log n)。
- 评分点：先剪枝再递归；递归方向判定（左子树满足走左）；与普通二分的区别（在树结构上走）。

```javascript
class FirstGreater {
  constructor(arr) {
    this.n = arr.length; this.t = new Array(4 * this.n);
    this.build(arr);
  }
  build(a, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.t[node] = a[l];
    const m = (l + r) >> 1;
    this.build(a, node * 2, l, m); this.build(a, node * 2 + 1, m + 1, r);
    this.t[node] = Math.max(this.t[node * 2], this.t[node * 2 + 1]);
  }
  firstGreater(ql, qr, x, node = 1, l = 0, r = this.n - 1) {
    if (qr < l || r < ql || this.t[node] <= x) return -1;   // 剪枝：区间最大值都不超
    if (l === r) return l;                                  // 叶子：命中
    const m = (l + r) >> 1;
    const left = this.firstGreater(ql, qr, x, node * 2, l, m);
    if (left >= 0) return left;                             // 左子树满足：优先左（最左）
    return this.firstGreater(ql, qr, x, node * 2 + 1, m + 1, r);
  }
}
// firstGreater(monIdx, sunIdx, budget) → 本周首个超预算天索引
```
