## ALG-366：手写懒标记下传顺序与标记合并：先后批量操作正确性

**答**：
- 题目：对同一区间先「加 10」再「赋值为 5」，最终值必须为 5；先「赋值 5」再「加 10」结果 15。设计标记结构使任意顺序正确。
- 思路：标记二元组 (assign, add)，语义 = 先赋值后加：下推时子节点新标记 = 合并(子标记, 父标记)。合并规则：父 assign != null → 子标记重置为 (assign, add)；否则子 add += 父 add。应用顺序 (assign, add) 保证结合性。
- 评分点：标记二元组设计；合并的结合律验证；赋值清空子 add 标记。

```javascript
class CompositeLazy {
  constructor(n) { this.n = n;
    this.t = new Array(4 * n).fill(0);
    this.lazy = new Array(4 * n).fill(null);               // null 或 {assign, add}
  }
  compose(child, parent) {                                 // 父标记下推合并
    if (!parent) return child;
    if (parent.assign != null)                             // 父有赋值：覆盖子全部历史
      return { assign: parent.assign, add: parent.add };
    return { assign: child?.assign ?? null,
      add: (child?.add ?? 0) + parent.add };               // 父纯加：叠加
  }
  apply(node, mark, len) {
    const { assign, add } = mark;
    this.t[node] = (assign != null ? assign * len : this.t[node]) + add * len;
    this.lazy[node] = this.compose(this.lazy[node], mark);
  }
  pushdown(node, l, r) {
    if (!this.lazy[node]) return;
    const m = (l + r) >> 1;
    this.apply(node * 2, this.lazy[node], m - l + 1);
    this.apply(node * 2 + 1, this.lazy[node], r - m);
    this.lazy[node] = null;
  }
  // add(ql,qr,v) → apply({assign:null, add:v})；assign(ql,qr,v) → apply({assign:v, add:0})
```
