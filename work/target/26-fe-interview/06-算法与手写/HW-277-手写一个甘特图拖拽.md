## HW-277：手写一个甘特图拖拽：任务拖动、缩放与冲突提示

**答**：
- 需求：实现 GanttDrag：任务条拖动（整体平移，按天吸附）、左/右缘拖拽缩放（改 start/end）；拖拽中显示冲突提示（与依赖前置的 FS 约束冲突、与同时段资源重叠）；松手提交（带约束校验：end >= start，不早于前置完成）。
- 边界：按天吸附（round 到天）；缩放最小 1 天；约束冲突只提示不阻断（可配置 strict 模式阻断）。
- 评分点：天吸附；三类约束校验；strict 开关。

```javascript
class GanttDrag {
  constructor(layout, { strict = false, snap = 'day' } = {}) { this.l = layout; this.strict = strict; }
  start(task, mode /* move|left|right */, e) {
    const x0 = e.clientX;
    const orig = { start: new Date(task.start), end: new Date(task.end) };
    const move = ev => {
      const days = Math.round((ev.clientX - x0) / this.l.dw);   // 天吸附
      const t = { ...orig };
      if (mode === 'move') { t.start = addDays(orig.start, days); t.end = addDays(orig.end, days); }
      if (mode === 'left') t.start = addDays(orig.start, Math.min(days, (diffDays(t.end, orig.start) - 1) * -1 + days));
      if (mode === 'right') t.end = addDays(orig.end, days);
      t.end = t.end < t.start ? t.start : t.end;              // end >= start
      this.preview = t;
      this.conflicts = this.checkConflicts(task.id, t);
    };
    const up = () => { removeEventListener('pointermove', move);
      if (this.strict && this.conflicts.length) { this.preview = orig; }   // strict 阻断
      else this.commit(task.id, this.preview);
    };
    addEventListener('pointermove', move);
    addEventListener('pointerup', up, { once: true });
  }
  checkConflicts(id, t) {                                     // 三类约束
    const out = [];
    const task = this.l.tasks.find(x => x.id === id);
    for (const d of task.deps) {                              // FS 约束
      const pre = this.l.tasks.find(x => x.id === d);
      if (t.start < pre.end) out.push({ type: 'fs-violation', with: d });
    }
    for (const other of this.l.tasks)                         // 资源重叠
      if (other.id !== id && overlapDays(t, other) > 0 && sameResource(task, other))
        out.push({ type: 'resource-overlap', with: other.id });
    return out;
  }
}
const addDays = (d, n) => new Date(d.getTime() + n * 86400000);
const diffDays = (a, b) => Math.round((a - b) / 86400000);
const overlapDays = (a, b) => Math.max(0, diffDays(a.end < b.end ? a.end : b.end, a.start > b.start ? a.start : b.start));
```
