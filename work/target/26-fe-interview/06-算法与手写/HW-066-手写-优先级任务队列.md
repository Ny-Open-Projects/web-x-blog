**答**：在 HW-007 p-limit 基础上给队列加优先级：并发槽空出时，**从队列取优先级最高的任务**（同优先级保 FIFO，用 Map<priority, array> 分桶）。附带按 key 去重：同一 key 的任务只排队一份，结果共享。

```javascript
class PriorityQueue {
  constructor(concurrency = 4) {
    this.limit = concurrency; this.active = 0;
    this.buckets = new Map();        // priority -> [job]
    this.keys = new Map();           // dedupeKey -> Promise
  }
  push(task, { priority = 0, dedupeKey } = {}) {
    if (dedupeKey && this.keys.has(dedupeKey)) return this.keys.get(dedupeKey);  // 去重共享
    const p = new Promise((resolve, reject) => {
      const arr = this.buckets.get(priority) ?? [];
      this.buckets.set(priority, arr);
      arr.push({ task, resolve, reject });
    });
    if (dedupeKey) this.keys.set(dedupeKey, p);
    p.finally?.(() => dedupeKey && this.keys.delete(dedupeKey));
    this.#drain();
    return p;
  }
  #next() {                                     // 取最高优先级桶的队头（FIFO 同级）
    const levels = [...this.buckets.keys()].sort((a, b) => b - a);
    for (const lv of levels) {
      const arr = this.buckets.get(lv);
      if (arr.length) return arr.shift();
    }
    return null;
  }
  #drain() {
    while (this.active < this.limit) {
      const job = this.#next();
      if (!job) return;
      this.active++;
      Promise.resolve().then(job.task)
        .then(job.resolve, job.reject)
        .finally(() => { this.active--; this.#drain(); });
    }
  }
}
// 用法：预取任务可随时被交互任务插队
const q = new PriorityQueue(4);
q.push(() => prefetchRecommend(), { priority: 0 });
q.push(() => loadUserCart(), { priority: 10, dedupeKey: 'cart' });   // 高优先级先跑
```

**评分点**：
- 优先级取任务正确：按桶降序找第一个非空桶，桶内 FIFO。
- 并发上限语义正确（active < limit 才启动）。
- 去重键共享同一个 Promise（重复 push 返回同一结果），并在结算后清理键。
- 插队语义清楚：正在跑的任务不中断，"抢占"只发生在槽位分配时。
