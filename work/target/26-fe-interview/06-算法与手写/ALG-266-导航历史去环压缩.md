## ALG-266：导航历史去环：路径序列中 A→B→A 循环的压缩（保留首次/最后到达，固定窗口内检测）？
**答**：面包屑/历史栈去环：`home → list → detail → list → detail2` 中 list 重复——压缩重复中间节点（保留首次或最后出现），但连续 detail→list→detail2 是合法回溯（不能误压）。

**思路**：只压缩"相同节点相邻重复段"（list…list 之间全是已访问节点且回到 list）——用最近 K 次访问集合检测：当前节点出现在最近 K 窗口内且窗口内无新增 → 环，弹出窗口段。

```javascript
function compressHistory(path, window = 4) {
  const out = [];
  for (const node of path) {
    // 检测最近 window 段内是否已出现过当前节点（环）
    const start = Math.max(0, out.length - window);
    const idx = out.slice(start).lastIndexOf(node) + start;
    if (idx >= start && idx < out.length && out.length - idx >= 2) {
      // 环：A → ... → A（中间 ≥ 2 节点）—— 截断到首次出现位置
      out.length = idx + 1;
    } else {
      out.push(node);
    }
  }
  return out;
}
// compressHistory(['home','list','detail','list','detail2'])
// => ['home','list','detail','detail2']（第二个 list 触发环压缩，回到 list 首次位置）
// 反例保护：['home','list','detail','list'] 尾部 list 是"返回列表"合法操作？
// —— 业务语义决定：面包屑场景压缩（环=浪费）；操作历史场景不压缩（用户真实操作序列）
// window 限制：只在最近 4 段内检测环（长程重复是合法回访，不能全量去重）
```

**评分点**：
- 固定窗口环检测（最近 K 段内的重复）——本题核心。
- 压缩语义（截断到首次出现）与"合法回访"的边界（窗口限制的理由）。
- 业务语义分岔（面包屑 vs 操作历史）的取舍。
- out.length = idx + 1 的截断实现。
