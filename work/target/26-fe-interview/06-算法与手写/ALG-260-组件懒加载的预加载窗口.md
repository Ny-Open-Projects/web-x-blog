**场景**：长页分段懒加载（每屏一个懒加载 chunk）：用户滚动到某段，预加载前后 ±2 屏的 chunk（IDLE 触发）——方向感知（向下滚多预下方）。与 ALG-250 画廊预载同构，组件 chunk 版本。

**思路**：滚动到段 i → 计算 [i-2, i+3] 窗口（方向偏移）→ 未加载的 chunk 进 idle 队列预取（import()，去重 Map）→ 命中率统计。

```javascript
class SectionPrefetcher {
  #loaded = new Set();                                    // 段 idx -> Promise 去重
  constructor(sections, { before = 1, after = 2 } = {}) { Object.assign(this, { sections, before, after }); }
  onVisible(idx, direction = 'down') {                    // IO 回调：段可见
    const f = direction === 'down' ? this.after : this.before;   // 方向感知窗口偏移
    const b = direction === 'down' ? this.before : this.after;
    for (let d = -Math.max(b, f); d <= Math.max(b, f); d++) {
      const target = idx + d;
      if (target < 0 || target >= this.sections.length || this.#loaded.has(target)) continue;
      if (d < 0 && Math.abs(d) > b) continue;
      if (d > 0 && d > f) continue;
      this.#prefetch(target);
    }
  }
  #prefetch(idx) {
    const p = import(this.sections[idx]).catch(() => {});  // 预取失败静默（真用时正常加载）
    this.#loaded.set(idx, p);
  }
  async get(idx) { return (await this.#loaded.get(idx)) ?? import(this.sections[idx]); }
}
// idle 预取（requestIdleCallback 包裹 import）—— 预取不抢渲染主线程（PER-090 Warmer 模式）
// 方向感知：向下滚动 forward 窗口 2、back 1（带宽投给用户去的方向）
// 去重 Map（Promise 缓存）：同段重复触发只 import 一次（chunk 请求浏览器级去重 + 应用级确认）
```

**评分点**：
- 方向感知窗口（f/b 随滚动方向对调）——本题核心。
- idle 队列预取（不抢主线程，PER-090）。
- Promise 缓存去重（应用级 + 浏览器级双保险）。
- 预取失败静默。
