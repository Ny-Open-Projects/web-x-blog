## ALG-485：手写贪心+堆：任务分配机器（构建机分配）

**答**：
- 题目：n 个任务（时长），m 台构建机并行，求「最长机器的完工时间」最短（最小化 makespan）。近似贪心：任务按时长降序，每次派给当前负载最小的机器（LPT）。
- 思路：LPT（Longest Processing Time first）——降序 + 小顶堆（机器负载），保证 4/3 - 1/(3m) 近似比。
- 评分点：LPT 策略；近似比 4/3；最优解是 NP-hard（提及，划分问题）。

```javascript
function assignMachines(jobs, m) {                         // LPT 近似
  const sorted = [...jobs].sort((a, b) => b - a);           // 时长降序
  const loads = new MinHeap();                              // 机器负载小顶堆
  const assign = new Map();                                 // load -> jobs
  for (let i = 0; i < m; i++) { loads.push(0); assign.set(0, []); }
  for (const j of sorted) {
    const min = loads.pop();                                // 当前最闲机器
    assign.get(min).push(j);
    loads.push(min + j);
  }
  return { makespan: Math.max(...loads.toArray()), assign };
}
// LPT 近似比 4/3 - 1/(3m)；精确解是 NP-hard（partition 问题）
// 面试表达：先给近似贪心，说明 NP-hard 背景与近似比，展现完整认知
```
