## HW-234：手写一个评论锚点系统：基于文本位置稳定锚定与漂移跟随

**答**：
- 需求：实现 CommentAnchor：锚定 {blockId, start, end}，评论关联该区间；onEdit(pos, delta) 编辑发生在锚点前 → start/end 平移 delta；编辑发生在锚点内 → 扩展（插入）或收缩（删除截断，区间空则标记 lost）；输出每个评论的当前位置。
- 边界：多评论重叠锚定各自独立平移；block 删除 → 评论标 orphan；平移量按码点。
- 评分点：前/内/后三类编辑处理；orphan 状态。

```javascript
class CommentAnchor {
  constructor() { this.anchors = []; }
  attach(commentId, blockId, start, end) {
    this.anchors.push({ commentId, blockId, start, end, state: 'active' });
  }
  onEdit(blockId, pos, delta, removedBlockIds = []) {
    for (const a of this.anchors) {
      if (removedBlockIds.includes(a.blockId)) { a.state = 'orphan'; continue; }   // block 删除
      if (a.blockId !== blockId) continue;
      if (pos + delta <= a.start) {                            // 编辑在锚点前：整体平移
        a.start += delta; a.end += delta;
      } else if (pos <= a.end) {                               // 编辑在锚点内
        if (delta > 0) a.end += delta;                         // 插入：扩展
        else {                                                 // 删除：收缩截断
          const delS = Math.max(pos, a.start), delE = Math.min(pos - delta, a.end);
          a.start -= Math.max(0, a.start - pos); a.end -= (delE - delS);
          a.start = Math.max(a.start, pos); a.end = Math.max(a.end, a.start);
          if (a.end === a.start) a.state = 'lost';             // 区间空：锚丢失
        }
      }                                                        // 锚点后：不动
      if (a.state === 'active' && a.end < a.start) a.state = 'lost';
    }
  }
  locate(commentId) {
    const a = this.anchors.find(x => x.commentId === commentId);
    return a && { pos: { blockId: a.blockId, start: a.start, end: a.end }, state: a.state };
  }
}
```
