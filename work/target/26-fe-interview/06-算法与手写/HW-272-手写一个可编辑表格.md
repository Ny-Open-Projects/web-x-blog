## HW-272：手写一个可编辑表格：单元格编辑态与键盘导航

**答**：
- 需求：实现 EditableTable：双击进入编辑态（单例，同一时刻只有一个 cell 在编辑）；Enter 提交并下移、Tab 提交并右移、Esc 取消；编辑中禁用其他导航；提交走校验（失败保持编辑态并标记错误）。
- 边界：编辑态切走（点其他 cell）自动提交；只读 cell 跳过（导航时连续跳过只读列）；提交失败聚焦原 cell。
- 评分点：编辑态单例；导航跳过只读；失败保持。

```javascript
class EditableTable {
  constructor(grid) { this.grid = grid; this.editing = null; }
  dblClick(cell) { this.beginEdit(cell); }
  beginEdit(cell) {
    if (this.editing) this.commit();                         // 单例：先提交旧
    if (this.grid.isReadonly(cell)) return this.skipReadonly(cell);
    this.editing = { cell, original: this.grid.value(cell) };
    this.grid.renderInput(cell);
  }
  commit() {
    const { cell } = this.editing ?? {};
    if (!cell) return true;
    const v = this.grid.inputValue(cell);
    const err = this.grid.validate(cell, v);
    if (err) { this.grid.markError(cell, err); return false; }   // 失败保持编辑态
    this.grid.set(cell, v); this.endEdit(); return true;
  }
  onKey(e) {
    if (!this.editing) return this.navigate(e);
    if (e.key === 'Enter') { if (this.commit()) this.move(1, 0); }
    else if (e.key === 'Tab') { if (this.commit()) this.move(0, 1); e.preventDefault(); }
    else if (e.key === 'Escape') { this.grid.set(this.editing.cell, this.editing.original); this.endEdit(); }
    return 'handled';
  }
  navigate(e) {
    const dir = { ArrowUp: [-1, 0], ArrowDown: [1, 0], ArrowLeft: [0, -1], ArrowRight: [0, 1] }[e.key];
    if (dir) { this.move(...dir); return 'handled'; }
    return 'none';
  }
  move(dr, dc) {                                             // 连续跳过只读
    let c = this.grid.cursor;
    do { c = { r: c.r + dr, c: c.c + dc }; } while (this.grid.isReadonly(c) && this.grid.inBounds(c));
    if (this.grid.inBounds(c)) { this.grid.focus(c); }
  }
  endEdit() { this.editing = null; this.grid.removeInput(); }
}
```
