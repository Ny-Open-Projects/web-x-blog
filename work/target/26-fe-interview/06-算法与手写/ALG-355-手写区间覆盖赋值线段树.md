## ALG-355：手写区间覆盖赋值线段树：广告位时段批量改价

**答**：
- 题目：广告位按天分 96 个时段（15 分钟一格），运营批量把 [10:00, 14:00] 价格设为 500（覆盖式赋值，非增量），并随时查询某时段价格。
- 思路：懒标记改为赋值标记（assign: value 或 null 表示无标记）；下推时子节点值 = 标记值（区间内全部相同，和值 = v * len）。注意赋值标记会覆盖之前的加标记——下推顺序：先赋值标记再叠加标记（若同时存在需标记优先级）。
- 评分点：赋值 vs 增量标记区分；下推覆盖旧标记；标记优先级意识。

```javascript
class AssignTree {
  constructor(n) { this.n = n; this.t = new Array(4 * n).fill(0); this.assign = new Array(4 * n).fill(null); }
  pushdown(node, l, r) {
    if (this.assign[node] == null) return;
    const v = this.assign[node], m = (l + r) >> 1;
    for (const [child, len] of [[node * 2, m - l + 1], [node * 2 + 1, r - m]]) {
      this.t[child] = v * len;                             // 赋值：和 = v * len
      this.assign[child] = v;                              // 覆盖旧标记（赋值优先）
    }
    this.assign[node] = null;
  }
  assignRange(ql, qr, v, node = 1, l = 0, r = this.n - 1) {
    if (qr < l || r < ql) return;
    if (ql <= l && r <= qr) { this.t[node] = v * (r - l + 1); this.assign[node] = v; return; }
    this.pushdown(node, l, r);
    const m = (l + r) >> 1;
    this.assignRange(ql, qr, v, node * 2, l, m);
    this.assignRange(ql, qr, v, node * 2 + 1, m + 1, r);
    this.t[node] = this.t[node * 2] + this.t[node * 2 + 1];
  }
  query(i, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.t[node];
    this.pushdown(node, l, r);
    const m = (l + r) >> 1;
    return i <= m ? this.query(i, node * 2, l, m) : this.query(i, node * 2 + 1, m + 1, r);
  }
}
```
