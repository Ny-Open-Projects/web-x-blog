## HW-087：手写带缓存的异步函数——Promise 级缓存 + SWR 策略 + 失效参数
**答**：三个能力叠加：① Promise 级缓存——缓存"在途 Promise"实现并发去重（多个调用共享一次请求）；② SWR（stale-while-revalidate）——立即返回旧值同时后台刷新，刷新完静默更新缓存；③ TTL/手动失效。关键：错误不缓存（失败后立即可重试）。

```javascript
function swrFetch(loader, { ttl = 30000, onStale } = {}) {
  const cache = new Map();       // key -> { data, at, promise }
  return function cached(key, { swr = true } = {}) {
    const item = cache.get(key);
    const fresh = item && Date.now() - item.at < ttl;
    if (item?.promise) return item.promise;               // 在途请求共享
    if (item && fresh) return Promise.resolve(item.data); // 命中新鲜数据

    const refresh = (force = false) => {
      const promise = loader(key)
        .then((data) => { cache.set(key, { data, at: Date.now() }); return data; })
        .catch((e) => { cache.delete(key); throw e; });   // 错误不缓存
      cache.set(key, { ...(cache.get(key) || { data: item?.data }), at: item?.at ?? 0, promise });
      return promise;
    };
    if (item && !fresh && swr) {                          // 旧值 + 后台刷新
      refresh();
      onStale?.(key);
      return Promise.resolve(item.data);                  // 先返回旧值
    }
    return refresh();
  };
}
// 用法
const getGoods = swrFetch((id) => fetch(`/api/goods/${id}`).then((r) => r.json()), { ttl: 30000 });
getGoods(1).then(render);        // 首次请求
getGoods(1).then(render);        // 命中缓存，不发请求
// 31 秒后再调：立即拿到旧数据渲染（SWR），后台刷新完成后下次调用拿新值
getGoods(1);
// 并发去重：请求在途时第 100 个调用共享同一个 Promise
```

**评分点**：
- Promise 级缓存实现并发去重（缓存的是 promise 不是 data）。
- SWR 语义正确：旧值立即返回 + 后台刷新；新鲜判定用 ttl。
- 错误不缓存（catch 里 delete），失败可立即重试。
- 能说出 SWR 与 TTL 缓存的差别（SWR 优先感知速度，允许短暂时旧数据）。
