## HW-284：手写一个树节点拖拽移动：非法移动校验与环检测

**答**：
- 需求：实现 TreeDrag：拖拽节点到目标节点（into/before/after 三种落点）；校验：不能移动到自己子树内（环）、不能移动到自身、只读节点不可作为目标；合法移动生成 ops（remove+insert）；撤销支持。
- 边界：环检测沿目标向上找祖先是否包含被拖节点；into 与 before/after 的父节点计算不同；拖拽预览显示合法/非法（红/绿）。
- 评分点：子树环检测；三种落点语义；预览合法性。

```javascript
class TreeDrag {
  constructor(tree) { this.tree = tree; }
  validate(dragId, targetId, mode) {
    if (dragId === targetId) return { ok: false, reason: 'self' };
    if (mode === 'into' && this.isDescendant(targetId, dragId))
      return { ok: false, reason: 'cycle' };                 // 移入自己子树=环
    if (this.tree.isLocked(targetId)) return { ok: false, reason: 'locked' };
    return { ok: true };
  }
  isDescendant(ancestorId, nodeId) {                         // ancestor 是否包含 node
    let p = this.tree.parentOf(nodeId);
    while (p) { if (p === ancestorId) return true; p = this.tree.parentOf(p); }
    return false;
  }
  move(dragId, targetId, mode) {
    const v = this.validate(dragId, targetId, mode);
    if (!v.ok) return v;
    const parentId = mode === 'into' ? targetId : this.tree.parentOf(targetId);
    const siblings = this.tree.childrenOf(parentId);
    const idx = mode === 'into' ? siblings.length            // into：追加
      : siblings.indexOf(targetId) + (mode === 'after' ? 1 : 0);
    const ops = [
      { type: 'remove', id: dragId },
      { type: 'insert', id: dragId, parentId, idx },
    ];
    ops.forEach(o => this.tree.apply(o));
    this.undoStack?.push({ ops, inverse: [
      { type: 'remove', id: dragId },
      { type: 'insert', id: dragId, parentId: this.tree.parentOf(dragId), idx: -1 },
    ] });
    return { ok: true };
  }
}
```
