**场景**：画廊翻页体验：当前位置前后 ±2 张预加载；用户连续往右翻时右侧窗口加大（方向感知）、左侧收缩——带宽花在"用户要去的方向"。

**思路**：窗口大小按翻页方向偏移（forward: [back 1, forward 4]）；新位置与旧位置的方向判断；已加载缓存 Map 防重复；离窗图片不 revoke（画廊小，保留内存换回翻速度）。

```javascript
class GalleryPreloader {
  #cache = new Map();                                // index -> Promise<Image>
  constructor(urls, { back = 1, forward = 2 } = {}) { Object.assign(this, { urls, back, forward }); }
  async goto(idx) {
    this.#load(idx);                                  // 当前：立即
    const lastIdx = this.lastIdx ?? idx;
    const going = idx > lastIdx ? 'fwd' : 'back';
    // 方向感知窗口：往右翻 forward 窗口 +1，back 窗口 -1（对调）
    const f = going === 'fwd' ? this.forward : this.back;
    const b = going === 'fwd' ? this.back : this.forward;
    for (let d = 1; d <= Math.max(f, b); d++) {
      if (d <= f) this.#load(idx + d);
      if (d <= b) this.#load(idx - d);
    }
    this.lastIdx = idx;
  }
  #load(i) {
    if (i < 0 || i >= this.urls.length || this.#cache.has(i)) return;
    this.#cache.set(i, new Promise((res, rej) => {
      const img = new Image(); img.onload = () => res(img); img.onerror = rej;
      img.src = this.urls[i];
    }));
  }
  get(index) { return this.#cache.get(index); }      // 命中秒切，未命中现场加载
}
// 方向感知：连续右翻时 forward 窗口大于 back —— 带宽投给用户要去的方向
// 缓存 Map 防重复加载；get(index) 未命中现场加载兜底（预加载是尽力而为）
```

**评分点**：
- 方向感知窗口偏移（forward/back 随翻页方向对调）——本题核心。
- 缓存 Map 防重复 + get 未命中兜底（预加载尽力而为）。
- 边界 clamp（idx ± 窗口不越界）。
- 与弱网/Save-Data 的降级联动意识（PER-326）。
