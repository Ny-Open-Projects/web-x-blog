## HW-297：手写一个上传组件：多文件队列、分片与并发控制

**答**：
- 需求：实现 Uploader：add(files) 入队（去重按 name+size）；队列并发上传（默认 3，可配）；大文件分片（5MB/片，并行上传分片，全部成功后 merge 请求）；进度（文件级=已传分片/总分片，总进度=字节加权）；失败重试（单分片 3 次）与暂停恢复。
- 边界：重复文件秒传（服务端 hash 命中直接完成）；暂停=停止派发新分片（进行中的不中断）；文件从队列移除时中止其分片请求。
- 评分点：分片并行与 merge；进度口径；暂停语义。

```javascript
class Uploader {
  constructor({ conc = 3, chunkMB = 5 } = {}) { this.q = []; this.conc = conc;
    this.chunk = chunkMB * 1048576; this.active = new Set(); this.paused = false; }
  add(file) {
    if (this.q.some(f => f.name === file.name && f.size === file.size)) return 'dup';
    const item = { file, chunks: Math.ceil(file.size / this.chunk), done: 0, status: 'pending', ctrl: null };
    this.q.push(item); this.pump(); return 'added';
  }
  async pump() {
    while (!this.paused && this.active.size < this.conc) {
      const item = this.q.find(f => f.status === 'pending' || f.status === 'retrying');
      if (!item) break;
      item.status = 'uploading'; this.active.add(item);
      this.uploadFile(item).finally(() => { this.active.delete(item); this.pump(); });
    }
  }
  async uploadFile(item) {
    const tasks = [];
    for (let i = 0; i < item.chunks; i++) tasks.push(i);
    const worker = async () => {
      while (tasks.length && !this.paused) {
        const idx = tasks.shift();
        for (let t = 0; t < 3; t++) {                        // 单分片 3 次重试
          try {
            const blob = item.file.slice(idx * this.chunk, (idx + 1) * this.chunk);
            item.ctrl = new AbortController();
            await fetch(`/upload?i=${idx}`, { method: 'PUT', body: blob, signal: item.ctrl.signal });
            item.done++; this.onProgress?.(item);
            break;
          } catch (e) { if (t === 2) { item.status = 'failed'; return; } }
        }
      }
      if (item.done === item.chunks && !this.paused) {
        await fetch('/merge', { method: 'POST', body: JSON.stringify({ name: item.file.name }) });
        item.status = 'done'; this.onDone?.(item);
      }
    };
    await Promise.all(Array(this.conc).fill(worker));        // 分片并行
  }
  pause() { this.paused = true; }
  resume() { this.paused = false; this.pump(); }
  remove(item) { item.ctrl?.abort(); this.q = this.q.filter(f => f !== item); }
}
```
