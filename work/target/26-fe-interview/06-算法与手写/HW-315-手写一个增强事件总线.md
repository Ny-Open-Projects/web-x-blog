## HW-315：手写一个增强事件总线：命名空间、通配订阅与异步监听

**答**：
- 需求：实现 Emitter：on(event, fn)（支持通配 user.* 与命名空间 user.login#auth）；off 按命名空间批量移除；emit 支持异步监听（返回 Promise.allSettled 聚合）；emit 时通配匹配（前缀匹配 * 结尾）。
- 边界：通配只支持末段（user.* 不匹配 user.a.b 简化）；异步监听失败不阻断其他监听；同一 fn 重复 on 去重。
- 评分点：通配匹配；命名空间移除；allSettled 聚合。

```javascript
class Emitter {
  constructor() { this.handlers = new Map(); }               // event -> Set<{fn, ns}>
  on(event, fn, { ns = '' } = {}) {
    const set = this.handlers.get(event) ?? new Set();
    if ([...set].some(h => h.fn === fn)) return () => {};    // 去重
    set.add({ fn, ns });
    this.handlers.set(event, set);
    return () => this.off(event, fn);
  }
  off(event, { ns } = {}) {                                  // 按命名空间批量移除
    const set = this.handlers.get(event);
    if (!set) return;
    if (ns == null && typeof ns === 'undefined') { this.handlers.delete(event); return; }
    this.handlers.set(event, new Set([...set].filter(h => h.ns !== ns)));
  }
  async emit(event, payload) {
    const matched = [...this.handlers.entries()]
      .flatMap(([e, set]) => (e === event || wildMatch(e, event))
        ? [...set].map(h => h.fn) : []);
    const results = await Promise.allSettled(matched.map(fn => fn(payload)));   // 异步聚合
    return results.map(r => r.status === 'fulfilled' ? r.value : r.reason);
  }
}
function wildMatch(pattern, event) {                        // 末段通配
  if (!pattern.endsWith('.*')) return false;
  return event.startsWith(pattern.slice(0, -1));
}
```
