## HW-393：手写一个编辑器无障碍适配：aria 与键盘全操作

**答**：
- 需求：实现 A11yAdapter：编辑器容器 role=textbox + aria-multiline + aria-label；光标位置播报（aria-live polite 通知"第 x 行，内容摘要"）；全键盘操作（Tab 进入/退出编辑区不陷入）；选区变化播报（选中 N 个字符）；块类型变化播报。
- 边界：aria-live 防抖（快速操作合并播报）；聚焦管理（工具栏按钮操作后焦点回编辑器）；屏幕阅读器兼容（不用仅视觉的反馈）。
- 评分点：aria-live 防抖播报；焦点归还；role 语义。

```javascript
class A11yAdapter {
  constructor(editorEl) {
    this.el = editorEl;
    Object.assign(editorEl, { role: 'textbox', 'aria-multiline': 'true', tabIndex: 0 });
    editorEl.setAttribute('aria-label', '富文本编辑器');
    this.live = document.createElement('div');               // 播报区
    this.live.setAttribute('aria-live', 'polite');
    this.live.className = 'sr-only';                         // 视觉隐藏
    document.body.appendChild(this.live);
    this.timer = null;
  }
  announce(msg) {                                            // 防抖播报
    clearTimeout(this.timer);
    this.timer = setTimeout(() => { this.live.textContent = msg; }, 150);
  }
  onCursorMove(pos, lineText) {
    this.announce(`第 ${pos.line + 1} 行，${lineText.slice(0, 20) || '空行'}`);
  }
  onSelectionChange(len) { if (len > 0) this.announce(`已选中 ${len} 个字符`); }
  onBlockTypeChange(type) { this.announce(`已切换为${TYPE_NAME[type] ?? type}`); }
  trapFocus(e) {                                             // Tab 不陷入
    if (e.key !== 'Tab') return false;
    const focusables = [...this.el.querySelectorAll('button,[tabindex="0"]')];
    const i = focusables.indexOf(document.activeElement);
    if (e.shiftKey && i === 0) { focusables.at(-1)?.focus(); return true; }
    if (!e.shiftKey && i === focusables.length - 1) { this.el.focus(); return true; }   // 回编辑器
    return false;
  }
  afterToolbarAction() { this.el.focus(); }                  // 工具栏操作后焦点归还
}
const TYPE_NAME = { h1: '一级标题', li: '列表项', quote: '引用', code: '代码块' };
```
