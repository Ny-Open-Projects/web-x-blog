## ALG-233：菜单树懒加载：两次懒加载结果合并去重（增量树合并，id 幂等）
**答**：菜单树逐层懒加载（点开节点拉子级），同一节点可能被多次展开（结果重复返回），要把增量结果合并进本地树且不产生重复节点。

**思路**：合并函数 mergeInto(tree, subtree)：按 id 定位目标节点 → children 数组按 id 幂等合并（Map 去重）→ 已加载标记（childrenLoaded 防重复请求）；合并保持原顺序（按服务端 order 字段排序）。

```javascript
function mergeInto(tree, patch) {                    // patch: { id, children: [...] }
  const target = findById(tree, patch.id);
  if (!target) return false;                         // 树结构变化：目标已不在（重新同步全量）
  const existing = new Map((target.children ?? []).map((c) => [c.id, c]));
  for (const c of patch.children ?? []) {
    if (existing.has(c.id)) Object.assign(existing.get(c.id), c);   // 幂等更新（不重复插入）
    else existing.set(c.id, c);
  }
  target.children = [...existing.values()].sort((a, b) => a.order - b.order);   // 稳定顺序
  target.childrenLoaded = true;                      // 标记：防重复懒加载请求
  return true;
}
function findById(tree, id) {
  if (tree.id === id) return tree;
  for (const c of tree.children ?? []) {
    const hit = findById(c, id);
    if (hit) return hit;
  }
  return null;
}
// 幂等性验证：同一 patch 合并两次 → children 数量不变（Map 按 id 去重）
// 局部更新 Object.assign：服务端字段更新（如改名）同步，不重建整个子树（保引用稳定，React.memo 友好）
```

**评分点**：
- id 幂等合并（Map 去重），重复懒加载不产生重复节点——本题核心。
- 局部 Object.assign 更新（引用稳定）与 order 排序保持。
- childrenLoaded 标记防重复请求。
- 目标节点不存在时的降级（重新同步全量）。
