## ALG-432：手写最小表示法：循环日志归一化

**答**：
- 题目：服务按固定顺序轮转输出日志段（abc / bca / cab 同源），判断两段日志是否「循环同构」。最小表示法：O(n) 求循环串的最小字典序表示。
- 思路：双指针 i, j 表示两个候选起点，k 为已匹配长度；比较 s[i+k] vs s[j+k]，败者跳 k+1 位；最终较小起点即最小表示。
- 评分点：双指针跳跃；O(n) 复杂度；与「排序所有旋转」O(n² log n) 的对比。

```javascript
function minRepresentation(s) {                            // 循环串最小表示
  const t = s + s;                                         // 破环成链
  let i = 0, j = 1, k = 0;
  while (i < s.length && j < s.length && k < s.length) {
    const cmp = t[i + k].localeCompare(t[j + k]);
    if (cmp === 0) { k++; continue; }
    if (cmp > 0) i = i + k + 1; else j = j + k + 1;        // 败者跳过 k+1
    if (i === j) j++;
    k = 0;
  }
  const start = Math.min(i, j);
  return t.slice(start, start + s.length);
}
function isRotation(a, b) {                                // 循环同构判定
  if (a.length !== b.length) return false;
  return minRepresentation(a) === minRepresentation(b);
}
```
