**答**：令牌桶 = 容量 capacity + 每秒补 rate 个令牌。请求先"惰性补桶"（按距上次的间隔计算应补数量，不依赖定时器），桶里有令牌则立即执行，否则排队等待"下一个令牌可用时刻"。相比固定窗口（HW-193 已涉）平滑、支持突发。

```javascript
class TokenBucket {
  constructor(rate, capacity = rate) {           // rate: 每秒令牌数
    this.rate = rate; this.capacity = capacity;
    this.tokens = capacity; this.last = performance.now();
    this.queue = [];                             // 等待队列：[{resolve}]
  }
  #refill(now) {                                 // 惰性补桶：不靠 setInterval
    const elapsed = (now - this.last) / 1000;
    this.tokens = Math.min(this.capacity, this.tokens + elapsed * this.rate);
    this.last = now;
  }
  acquire() {
    return new Promise((resolve) => {
      const now = performance.now();
      this.#refill(now);
      if (this.tokens >= 1) {                    // 立即发放
        this.tokens -= 1; resolve();
        this.#drain();
      } else {
        this.queue.push(resolve);                // 排队等补桶
        if (this.queue.length === 1) this.#scheduleNext();
      }
    });
  }
  #nextAt() {                                    // 下一个令牌时刻（ms）
    const need = 1 - this.tokens;
    return performance.now() + (need / this.rate) * 1000;
  }
  #scheduleNext() {
    const wait = Math.max(0, this.#nextAt() - performance.now());
    setTimeout(() => { this.#refill(performance.now()); this.#drain(); }, wait);
  }
  #drain() {
    while (this.queue.length && this.tokens >= 1) {
      this.tokens -= 1;
      this.queue.shift()();                      // 按序发放
      if (this.queue.length) this.#scheduleNext();
    }
  }
}
// 用法：埋点上报每秒最多 10 条，允许瞬时突发 10 条
const limiter = new TokenBucket(10, 10);
async function report(ev) { await limiter.acquire(); return send(ev); }
```

**评分点**：
- 惰性补桶（按时间差计算）而非定时器轮询——正确且无定时器泄漏。
- 突发语义正确：初始满桶允许 capacity 个瞬时请求。
- 排队队列 + 单定时器调度（不每请求一个 timer）。
- 能说明令牌桶 vs 固定窗口 vs 漏桶的区别（突发容忍 vs 边界突刺 vs 恒定速率）。
