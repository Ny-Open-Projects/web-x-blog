## ALG-493：手写分发糖果（双向扫描）：积分梯度

**答**：
- 题目：用户按贡献排序站一排，每人至少 1 积分，贡献更高者积分必须多于相邻贡献低者，求最少总积分。经典双扫描贪心。
- 思路：先全 1；左→右：比左邻高则 +1；右→左：比右邻高且当前 <= 右邻则 = 右邻+1。取两方向最大。
- 评分点：双向扫描必要性（单向只满足一侧）；取 max 合并；反例（单向解不满足另一侧）。

```javascript
function candy(ratings) {                                  // 最少积分
  const n = ratings.length;
  const left = new Array(n).fill(1);
  for (let i = 1; i < n; i++)                              // 左→右
    if (ratings[i] > ratings[i - 1]) left[i] = left[i - 1] + 1;
  let total = 0;
  let right = 1;
  for (let i = n - 1; i >= 0; i--) {                       // 右→左
    if (i < n - 1 && ratings[i] > ratings[i + 1]) right = right + 1;
    else right = 1;
    total += Math.max(left[i], right);                     // 双向取 max
  }
  return total;
}
// 例：[1,2,87,87,87,2,1] → 总 13（87 间并列不需更多）
// 单向扫描反例：[1,3,2,2,1] 右侧约束无法由左扫保证
```
