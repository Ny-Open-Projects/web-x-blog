## ALG-369：手写线段树剪枝与提前终止：区间命中即停的投放检测

**答**：
- 题目：检测「区间内是否存在任一秒的投放量超阈值」——存在即返回 true 停止扫描，不要扫完整棵树。
- 思路：max 线段树 + 查询时若节点 max <= 阈值直接返回 false（剪枝）；命中即一路 return true 向上冒泡。
- 评分点：max 剪枝条件；命中短路（不再遍历右子树）；与全量统计查询的差异。

```javascript
class AnyOverTree {
  constructor(a, threshold) {
    this.n = a.length; this.th = threshold;
    this.t = new Array(4 * this.n);
    this.build(a);
  }
  build(a, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.t[node] = a[l];
    const m = (l + r) >> 1;
    this.build(a, node * 2, l, m); this.build(a, node * 2 + 1, m + 1, r);
    this.t[node] = Math.max(this.t[node * 2], this.t[node * 2 + 1]);
  }
  anyOver(ql, qr, node = 1, l = 0, r = this.n - 1) {
    if (qr < l || r < ql || this.t[node] <= this.th) return false;   // 剪枝
    if (l === r) return true;                              // 命中
    const m = (l + r) >> 1;
    return this.anyOver(ql, qr, node * 2, l, m)            // 左命中即停
      || this.anyOver(ql, qr, node * 2 + 1, m + 1, r);
  }
}
```
