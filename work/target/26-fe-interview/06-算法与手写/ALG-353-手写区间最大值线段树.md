## ALG-353：手写区间最大值线段树：滑动窗口内峰值 QPS 监控

**答**：
- 题目：网关 QPS 按秒记录，监控要查任意时间段（如最近 5 分钟）的峰值，且支持修正历史数据。区间最大值查询。
- 思路：与求和线段树同构，合并操作 max 替换 +；单点改用赋值（不是加）。区间最值也可用稀疏表（ST 表）离线 O(1) 查询，但在线单点改场景线段树更优。
- 评分点：合并函数可替换（和/max/min/gcd 统一抽象）；赋值式单点改；能对比 ST 表取舍。

```javascript
class MaxSegTree {
  constructor(n) { this.n = n; this.t = new Array(4 * n).fill(-Infinity); }
  merge = (a, b) => Math.max(a, b);                        // 合并函数可替换
  set(i, v, node = 1, l = 0, r = this.n - 1) {             // 单点赋值
    if (l === r) return this.t[node] = v;
    const m = (l + r) >> 1;
    i <= m ? this.set(i, v, node * 2, l, m) : this.set(i, v, node * 2 + 1, m + 1, r);
    this.t[node] = this.merge(this.t[node * 2], this.t[node * 2 + 1]);
  }
  query(ql, qr, node = 1, l = 0, r = this.n - 1) {
    if (qr < l || r < ql) return -Infinity;
    if (ql <= l && r <= qr) return this.t[node];
    const m = (l + r) >> 1;
    return this.merge(this.query(ql, qr, node * 2, l, m),
      this.query(ql, qr, node * 2 + 1, m + 1, r));
  }
}
// 通用化：把 merge 传入构造函数即可支持 sum/min/max/gcd——面试加分点
```
