## HW-218：手写一个粘贴净化管线：HTML 粘贴转换为内部 blocks 并清洗

**答**：
- 需求：实现 pastePipeline：onPaste(html, text)——优先 text/html 走 DOM 解析，按块级元素切 blocks（p/h1/li），行内元素转 marks（b/strong→bold，i→italic），清洗危险内容（script/style 剥离、未知属性丢弃），无 html 用纯文本按换行拆 blocks。
- 边界：嵌套列表降级为平铺；图片占位（data-uri 剥离，保留占位标记）；超大粘贴（> 1MB）截断并提示。
- 评分点：白名单转换；script 剥离；降级链。

```javascript
const BLOCK_TAGS = new Set(['P', 'H1', 'H2', 'H3', 'LI', 'DIV', 'BR']);
const INLINE_MARKS = { B: 'bold', STRONG: 'bold', I: 'italic', EM: 'italic', U: 'underline' };
function pastePipeline(html, text, { maxSize = 1048576 } = {}) {
  if (!html) return textToBlocks(text);                        // 纯文本降级
  if (html.length > maxSize) return [{ type: 'p', text: '[内容过大已截断]', marks: [] }];
  const root = new DOMParser().parseFromString(html, 'text/html').body;
  root.querySelectorAll('script,style,iframe,object').forEach(el => el.remove());   // 危险剥离
  const blocks = [];
  for (const node of root.children) {
    if (!BLOCK_TAGS.has(node.tagName)) continue;
    const { text: t, marks } = walkInline(node, 0, []);
    blocks.push({ id: genId(), type: tagToType(node.tagName), text: t, marks });
  }
  return blocks.length ? blocks : textToBlocks(text);
}
function walkInline(el, offset, marks) {
  let text = '';
  for (const n of el.childNodes) {
    if (n.nodeType === 3) { text += n.textContent; }
    else if (n.nodeType === 1 && INLINE_MARKS[n.tagName]) {
      const start = [...text].length;
      const sub = walkInline(n, 0, marks);
      marks.push({ type: INLINE_MARKS[n.tagName], start, end: start + [...sub.text].length });
      text += sub.text;
    }
  }
  return { text, marks };
}
```
