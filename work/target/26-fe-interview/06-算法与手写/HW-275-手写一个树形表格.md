## HW-275：手写一个树形表格：层级展开状态与异步加载子节点

**答**：
- 需求：实现 TreeTable：数据树转扁平可见列表（根据 expanded 集合）；toggle(nodeId) 展开收起；子节点异步加载（展开时懒加载，加载中显示 spinner 行）；缩进层级由 depth 计算；勾选联动（父选全选子，子全选勾父，半选态）。
- 边界：加载失败显示重试行；收起父节点时保留子节点已加载数据（仅隐藏）；半选（indeterminate）状态由子勾选比例决定。
- 评分点：扁平化展开列表；懒加载态行；半选计算。

```javascript
class TreeTable {
  constructor(loadChildren) { this.expanded = new Set(); this.checked = new Set();
    this.childrenCache = new Map(); this.loading = new Set(); this.load = loadChildren; }
  flatten(nodes, depth = 0) {                                // 数据树 → 可见列表
    const out = [];
    for (const n of nodes) {
      out.push({ node: n, depth, hasChildren: n.children?.length || this.childrenCache.has(n.id) || n.hasChildren });
      if (this.expanded.has(n.id)) {
        if (this.loading.has(n.id)) out.push({ loading: n.id, depth: depth + 1 });
        else if (n.children) out.push(...this.flatten(n.children, depth + 1));
        else if (this.childrenCache.has(n.id))
          out.push(...this.flatten(this.childrenCache.get(n.id), depth + 1));
      }
    }
    return out;
  }
  async toggle(id) {
    if (this.expanded.has(id)) { this.expanded.delete(id); return; }
    if (!this.childrenCache.has(id)) {
      this.loading.add(id);
      try { this.childrenCache.set(id, await this.load(id)); }
      catch { this.loadError = id; }                          // 失败重试行
      finally { this.loading.delete(id); }
    }
    this.expanded.add(id);
  }
  toggleCheck(id, nodes) {                                    // 勾选联动
    if (this.checked.has(id)) this.uncheckSubtree(id, nodes);
    else this.checkSubtree(id, nodes);
    syncParents(this.checked, nodes);
  }
  checkState(id, nodes) {                                     // 三态
    const n = findNode(nodes, id);
    const all = subtreeIds(n);
    const cnt = all.filter(x => this.checked.has(x)).length;
    return cnt === 0 ? 'none' : cnt === all.length ? 'all' : 'indeterminate';
  }
}
```
