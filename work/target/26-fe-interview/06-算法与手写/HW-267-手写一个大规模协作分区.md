## HW-267：手写一个大规模协作分区：文档分片与跨片操作

**答**：
- 需求：实现 DocSharding：超长文档按章节分片（每片独立 CRDT/OT 实例，独立 rev）；片内操作路由到对应片；跨片操作（跨章节拖动段落）拆为 delete(片A) + insert(片B) 两阶段（先 B 插入成功再 A 删除，防丢失）；提供片注册表与路由查询。
- 边界：两阶段跨片操作的中断恢复（B 已插 A 未删 → 幂等重试只补 A 删除）；片上限（> 50 万字自动再分）；片 rev 独立递增。
- 评分点：两阶段顺序（先插后删）；幂等恢复；分片路由。

```javascript
class DocSharding {
  constructor() { this.shards = new Map(); }                // shardId -> {crdt, rev, range}
  route(pos) { return [...this.shards.values()].find(s => pos >= s.range[0] && pos < s.range[1]); }
  localOp(pos, op) {
    const s = this.route(pos);
    s.crdt.apply(op); s.rev++;
    return { shard: s.id, rev: s.rev };
  }
  crossShardMove(text, fromShard, toShard) {                // 两阶段：先插后删
    const step1 = toShard.crddt ?? toShard.crdt;
    step1.localInsert(0, text);                             // 阶段1：目标片插入
    return { phase: 'inserted', cleanup: () => {            // 阶段2：源片删除（幂等）
      if (!fromShard.deletedOnce?.has(text)) {
        fromShard.crdt.deleteText(text);
        fromShard.deletedOnce ??= new Set();
        fromShard.deletedOnce.add(text);
      }
    } };
  }
  maybeSplit(shard, maxLen = 500000) {                      // 超长自动再分
    if (shard.crdt.text().length <= maxLen) return null;
    const half = Math.floor(maxLen / 2);
    const [a, b] = splitCRDT(shard.crdt, half);
    this.shards.set(shard.id + '-b', { crdt: b, rev: 0, range: [shard.range[0] + half, shard.range[1]] });
    shard.range[1] = shard.range[0] + half;
    return b;
  }
}
```
