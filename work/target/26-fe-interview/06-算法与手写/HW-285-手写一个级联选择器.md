## HW-285：手写一个级联选择器：多级数据加载与回显路径

**答**：
- 需求：实现 Cascader：层级数据（或异步 loadOptions(path)）；select(path) 逐级选择；回显（根据叶子值反查完整路径——深度优先搜索或索引表）；搜索模式（跨层级过滤，命中节点展开路径）。
- 边界：异步加载中显示 loading；反查路径建索引（Map<leafId, path>，数据变更重建）；搜索命中在多级时按路径深度排序。
- 评分点：反查索引表；异步 loading 态；搜索路径展开。

```javascript
class Cascader {
  constructor(loadOptions) { this.load = loadOptions; this.cache = new Map(); this.index = new Map(); }
  async loadLevel(path) {                                    // 逐级异步加载
    const key = path.join('/');
    if (this.cache.has(key)) return this.cache.get(key);
    const opts = await this.load(path);
    this.cache.set(key, opts);
    opts.forEach(o => { if (!o.children) this.index.set(o.value, [...path, o.value]); });   // 叶子索引
    return opts;
  }
  async echo(leafValue) {                                    // 回显：反查路径
    if (this.index.has(leafValue)) return this.index.get(leafValue);
    const path = await this.dfsPath([], leafValue);          // 索引未命中：DFS
    if (path) this.index.set(leafValue, path);
    return path;
  }
  async dfsPath(prefix, target) {
    const opts = await this.loadLevel(prefix);
    for (const o of opts) {
      const p = [...prefix, o.value];
      if (o.value === target) return p;
      if (o.hasChildren) { const r = await this.dfsPath(p, target); if (r) return r; }
    }
    return null;
  }
  search(kw, roots) {                                        // 跨层级搜索
    const hits = [];
    const walk = (n, path) => {
      if (n.label.includes(kw)) hits.push({ node: n, path });
      n.children?.forEach(c => walk(c, [...path, n.id]));
    };
    roots.forEach(r => walk(r, []));
    return hits.sort((a, b) => a.path.length - b.path.length);   // 浅路径优先
  }
}
```
