## HW-263：手写一个白板协作数据同步：图形对象增删改合并

**答**：
- 需求：实现 WhiteboardSync：对象 {id, type, props(x/y/w/h/...), ver, site}；属性变更为 prop 级 LWW（x 与 w 可独立合并，减少覆盖）；创建/删除为对象级；增量同步（按 ver 向量）；提供 hit 合并测试。
- 边界：属性级 LWW 需 per-prop 时间戳（props 内每个键 {v, ts}）；并发创建同 id（双端本地生成撞 id）按 site 定胜者；删除后属性变更忽略。
- 评分点：prop 级 LWW；撞 id 处理；ver 向量增量。

```javascript
class WhiteboardSync {
  constructor(siteId) { this.site = siteId; this.objects = new Map(); this.versions = new Map(); }
  create(obj) {
    const id = this.site + '-' + (++this.seq);              // site 前缀防撞 id
    this.objects.set(id, { id, ...obj, site: this.site, deleted: false,
      props: mapProps(obj.props, ts()) });
    return id;
  }
  updateProp(id, key, value) {                              // prop 级 LWW
    const o = this.objects.get(id);
    if (!o || o.deleted) return;
    o.props[key] = { v: value, ts: ts(), site: this.site };
  }
  remove(id) { const o = this.objects.get(id); if (o) { o.deleted = true; o.delTs = ts(); } }
  merge(remoteObjects) {
    for (const r of remoteObjects) {
      const cur = this.objects.get(r.id);
      if (!cur) { this.objects.set(r.id, r); continue; }
      if (r.deleted && (!cur.delTs || r.delTs > cur.delTs)) Object.assign(cur, r);   // 删除优先级按 ts
      for (const [k, pv] of Object.entries(r.props))        // prop 级合并
        if (!cur.props[k] || pv.ts > cur.props[k].ts || (pv.ts === cur.props[k].ts && pv.site > cur.props[k].site))
          cur.props[k] = pv;
    }
  }
  render() { return [...this.objects.values()].filter(o => !o.deleted)
    .map(o => ({ id: o.id, type: o.type,
      props: Object.fromEntries(Object.entries(o.props).map(([k, p]) => [k, p.v])) })); }
}
const mapProps = (p, t) => Object.fromEntries(Object.entries(p).map(([k, v]) => [k, { v, ts: t, site: 0 }]));
const ts = () => Date.now();
```
