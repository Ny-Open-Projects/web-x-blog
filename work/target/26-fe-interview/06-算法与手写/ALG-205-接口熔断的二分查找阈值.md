**场景**：压测数据：请求并发量 `1..n` 对应的 P99 耗时随并发量**单调不减**（数组按并发升序给耗时）。找"耗时首次超过 SLO（如 800ms）的最小并发量"，用于设置熔断阈值。

**思路**：单调性满足二分：找第一个 > SLO 的位置（lower_bound 变体）。O(logn)。

```javascript
function breakThreshold(costs, slo) {
  // costs 按并发量升序且单调不减；找第一个 costs[i] > slo 的 i（并发量 = i+1）
  let lo = 0, hi = costs.length;              // 左闭右开
  while (lo < hi) {
    const mid = (lo + hi) >> 1;
    if (costs[mid] > slo) hi = mid;           // mid 已超标：答案在左半（含 mid）
    else lo = mid + 1;                        // 未超标：右半
  }
  return lo < costs.length ? lo + 1 : -1;     // 并发量（1-based）；全不超标返回 -1
}
breakThreshold([120, 300, 480, 790, 950, 1400], 800);  // => 5（第 5 并发 950ms 超标）
// 边界：所有值 <= slo => -1；第一个就超标 => 1
// 为什么能二分：单调性（并发升 → 耗时不减）是前提，无单调性只能线性扫
```

**评分点**：
- lower_bound 模板正确（左闭右开、hi=mid 不跳过候选）。
- 返回值换算成"并发量"（1-based）与无解 -1。
- 明确指出单调性是二分前提，否则答案错误。
- 能对应场景：压测数据找熔断阈值。
