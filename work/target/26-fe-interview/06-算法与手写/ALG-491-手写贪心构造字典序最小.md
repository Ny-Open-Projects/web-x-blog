## ALG-491：手写贪心构造字典序最小：ID 生成

**答**：
- 题目：从数字串中删除 k 个字符使剩余字典序最小。贪心：栈——当前字符 < 栈顶则弹栈（消耗一次删除）。
- 思路：单调栈：遍历字符，while (k>0 && stack.top > c) pop；剩余 k 从尾部删。结果即最小。
- 评分点：单调栈贪心；尾部剩余删除；与「删最大值」错误直觉的对比。

```javascript
function removeKDigits(num, k) {                           // 删 k 个字符最小
  const stack = [];
  for (const c of num) {
    while (k > 0 && stack.length && stack.at(-1) > c) {    // 栈顶更大：弹
      stack.pop(); k--;
    }
    stack.push(c);
  }
  while (k > 0) { stack.pop(); k--; }                      // 剩余从尾部删
  return stack.join('').replace(/^0+(?=.)|^0+$/, '$&')     // 去前导零
    .replace(/^0+$/, '0') || '0';
}
// 例：'1432219', k=3 → '1219'；例：'10200', k=1 → '200'
// 贪心正确性：高位权重最大，尽量让高位小——单调栈恰是最优删除序
```
