## ALG-498：手写贪心+二分：最大化最小值（分片均衡）

**答**：
- 题目：把 n 个连续分片切成 m 份（每份是连续段），最大化「最小份的总大小」。二分答案 + 贪心判定（每份 >= mid 能否切出 m 份）。
- 思路：二分 mid：扫描贪心累加至 >= mid 切一段；能切出 >= m 段则 mid 可行。答案单调 → 二分成立。
- 评分点：二分答案+贪心判定的模板；单调性论证；复杂度 O(n log sum)。

```javascript
function maximizeMinChunk(shards, m) {                     // 最大化最小份
  let lo = Math.min(...shards), hi = shards.reduce((s, x) => s + x, 0);
  const feasible = (mid) => {                              // 贪心判定
    let count = 1, sum = 0;
    for (const x of shards) {
      if (sum + x > mid) { count++; sum = x; }             // 切一段
      else sum += x;
    }
    return count >= m;                                     // 能切出 m 份
  };
  while (lo < hi) {                                        // 二分答案
    const mid = Math.ceil((lo + hi) / 2);                  // 上取整防死循环
    feasible(mid) ? lo = mid : hi = mid - 1;
  }
  return lo;
}
// 例：shards [7,2,5,10,8] m=2 → 最优 max min = 18（[7,2,5,10,8]→[7,2,5]+[10,8] 18/18? 实为 [7,2,5,10]=24? 需按题算）
// 贪心判定正确性：每份尽量少装 → 留更多给后续份
```
