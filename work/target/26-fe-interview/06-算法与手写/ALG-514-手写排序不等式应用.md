## ALG-514：手写排序不等式应用：批量任务成本

**答**：
- 题目：n 个任务（处理时长 a[i]）与 m 台机器（速度 b[j]），任务 i 在机器 j 的成本 = a[i] × b[j]（b 是单位耗时系数），配对最小化总成本。排序不等式：同序配对最小（归并排序合并）。
- 思路：a 升序配 b 升序 → Σ 最小；a 升序配 b 降序 → 最大。证明：交换论证同 ALG-484。
- 评分点：排序不等式（同序最小、反序最大）；交换论证；归并 O(n+m) 实现。

```javascript
function optimalPairing(tasks, machines) {                 // 最小成本配对
  const a = [...tasks].sort((x, y) => x - y);
  const b = [...machines].sort((x, y) => x - y);
  let minCost = 0, maxCost = 0;
  for (let i = 0; i < Math.min(a.length, b.length); i++) {
    minCost += a[i] * b[i];                                // 同序配对：最小
    maxCost += a[i] * b[b.length - 1 - i];                 // 反序配对：最大
  }
  return { minCost, maxCost,
    plan: a.map((t, i) => ({ task: t, machine: b[i] })) };
}
// 排序不等式（Rearrangement Inequality）：
// Σa[i]b[σ(i)] 在 σ 同序时最小、反序时最大——交换论证两行即可证
```
