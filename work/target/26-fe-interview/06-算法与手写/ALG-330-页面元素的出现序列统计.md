## ALG-330：首屏元素出现序列：关键元素的出现顺序统计（页面模板的"元素出现基线"，回归检测）？
**答**：页面模板回归：关键元素（标题/价格/按钮）的出现顺序应稳定——基线序列（[title, price, buyBtn]）vs 实际序列（MutationObserver + IO 记录出现序）——顺序漂移（按钮先于价格出现）= 模板回归。

**思路**：基线固化（构建期或首采）→ 运行时记录关键元素首现序 → 序列对比（LCS 或简单序号 diff）→ 偏差告警。

```javascript
function trackAppearance(selectorList, { baseline, report } = {}) {
  const seen = new Set(); const order = [];
  const io = new IntersectionObserver((es) => {
    for (const e of es) {
      if (!e.isIntersecting) continue;
      const key = e.target.dataset.appearance;
      if (key && !seen.has(key)) { seen.add(key); order.push(key); }
      if (seen.size === selectorList.length) {            // 全部出现：对比基线
        io.disconnect();
        const drift = baseline.filter((k, i) => order[i] !== k);   // 顺序对比（同集合异序 = 漂移）
        if (order.length !== baseline.length || drift.length) {
          report?.({ type: 'appearance-drift', expected: baseline, actual: order });
        }
      }
    }
  }, { threshold: 0.1 });
  document.querySelectorAll(selectorList.join(',')).forEach((el) => io.observe(el));
}
// 基线：['title', 'price', 'buyBtn']；实际 ['title', 'buyBtn', 'price'] → drift 告警
// 价值：顺序漂移 = 渲染依赖变化（异步接口顺序变）→ LCP 元素变化的前兆（price 是 LCP 候选但晚出现）
// 集合校验优先（缺失元素 = 更严重回归）；顺序校验其次（漂移提示）
// 基线固化：构建期从模板生成（不是首采——首采可能本身就是异常）
```

**评分点**：
- 关键元素首现序与基线的顺序对比——本题核心。
- 集合校验（缺失）优先于顺序校验（漂移）。
- 与 LCP 元素变化的关联（出现序漂移是前兆信号）。
- 基线构建期固化（不是首采）。
