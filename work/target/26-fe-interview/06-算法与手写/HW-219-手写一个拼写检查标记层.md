## HW-219：手写一个拼写检查标记层：分词、词典查询与装饰定位

**答**：
- 需求：实现 SpellCheckLayer：check(doc) 对每个 block 分词（正则 \w+ / 中文按字），逐词查词典（Set），未命中的生成 decoration（blockId + start/end）；批量查词典用异步（分批 500 词/批避免卡顿）；提供 onDecorations 回调供渲染层定位。
- 边界：专有名词白名单（用户词典）；重复词只标一次实例（每处都标但统计去重）；全角/半角统一。
- 评分点：分批异步避免主线程拥塞；decoration 与 marks 解耦。

```javascript
class SpellCheckLayer {
  constructor(dict, userDict = new Set()) { this.dict = dict; this.user = userDict; }
  async check(doc, onDecorations, { batch = 500 } = {}) {
    const found = [];
    for (const b of doc.blocks) {
      const tokens = tokenize(b.text);
      for (const t of tokens)
        if (!this.dict.has(t.w) && !this.user.has(t.w))
          found.push({ blockId: b.id, start: t.start, end: t.end });
    }
    for (let i = 0; i < found.length; i += batch) {            // 分批回调防卡顿
      await new Promise(r => setTimeout(r));
      onDecorations(found.slice(i, i + batch), { progress: (i + batch) / found.length });
    }
    return { count: new Set(found.map(f => found.length)).size, items: found };
  }
}
function tokenize(text) {
  const out = [];
  const re = /[A-Za-z]+|[\u4e00-\u9fff]/g;                    // 英文按词，中文按字
  let m;
  while ((m = re.exec(text))) out.push({ w: m[0].toLowerCase(), start: m.index, end: m.index + m[0].length });
  return out;
}
```
