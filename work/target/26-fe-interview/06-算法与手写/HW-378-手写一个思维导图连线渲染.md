## HW-378：手写一个思维导图连线渲染：贝塞尔连线与样式

**答**：
- 需求：实现 MapLinks：连线渲染（三次贝塞尔：控制点水平延伸）；样式分支（depth 决定粗细/颜色）；选中高亮（祖先链高亮）；连线命中（点击连线选中边——用透明加宽的 hit path）。
- 边界：控制点水平距离按节点间距自适应（近节点控制点短）；命中 path 用 stroke 宽 12 的透明线；祖先链计算（向上遍历 parent）。
- 评分点：控制点自适应；hit path 加宽；祖先链高亮。

```javascript
class MapLinks {
  constructor(svg) { this.svg = svg; }
  renderLinks(positions, tree, selectedId) {
    const ancestors = new Set();                             // 祖先链
    let p = selectedId;
    while (p) { ancestors.add(p); p = tree.parentOf(p); }
    const paths = [];
    const walk = node => {
      for (const c of node.children ?? []) {
        const a = positions.get(node.id), b = positions.get(c.id);
        const gap = Math.abs(b.x - a.x);
        const mx = a.x + (b.x - a.x) * 0.5 * Math.min(1, gap / 200);   // 控制点自适应
        const d = `M${a.x},${a.y} C${mx},${a.y} ${mx},${b.y} ${b.x},${b.y}`;
        const hi = ancestors.has(c.id) || c.id === selectedId;
        paths.push({ d, depth: a.depth, hi });
        walk(c);
      }
    };
    walk(tree.root);
    this.svg.innerHTML = paths.map(p => `
      <g>
        <path d="${p.d}" stroke="transparent" stroke-width="12" fill="none"
          class="hit" data-depth="${p.depth}"/>              <!-- hit path 加宽 -->
        <path d="${p.d}" stroke="${p.hi ? 'orange' : colorOf(p.depth)}"
          stroke-width="${Math.max(1.5, 3 - p.depth * 0.5)}" fill="none"/>   <!-- depth 样式 -->
      </g>`).join('');
    this.svg.querySelectorAll('.hit').forEach(el =>
      el.addEventListener('click', e => this.onEdgeClick?.(e.target.dataset.depth)));
  }
}
const colorOf = d => ['#5af', '#5c5', '#c6c', '#fa0'][d % 4];
```
