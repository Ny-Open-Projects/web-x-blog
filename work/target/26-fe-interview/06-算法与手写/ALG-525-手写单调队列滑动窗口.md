## ALG-525：手写单调队列+滑动窗口：限流窗口峰值

**答**：
- 题目：限流器按秒记录通过数，滑动窗口 W 秒内峰值超限告警。单调递减队列 O(1) 摊还查窗口 max（复用 ALG-386）。
- 思路：递减队列存下标；入队时弹更小者；出窗弹队首；队首即窗口最大。
- 评分点：双端队列两端操作语义；出窗条件；与线段树选型对照。

```javascript
class SlidingMaxLimit {
  constructor(W, threshold) { this.W = W; this.th = threshold; this.dq = []; this.vals = []; }
  push(i, v) {                                             // 每秒调用
    while (this.dq.length && this.vals[this.dq.at(-1)] <= v) this.dq.pop();
    this.dq.push(i); this.vals[i] = v;
    while (this.dq[0] <= i - this.W) this.dq.shift();      // 出窗
    const peak = this.vals[this.dq[0]];
    if (peak > this.th) this.alert?.(i, peak);
    return peak;                                           // O(1) 摊还
  }
}
```
