## ALG-543：手写桶排序应用：评分分桶

**答**：
- 题目：接口延迟样本（0~10s 浮点）按分桶统计直方图（每 500ms 一桶），桶排序思想 + 桶内计数。值域大但分布集中——动态桶边界（分位数桶）更好。
- 思路：固定宽桶（简单）；分位数桶（每桶样本数均匀——先排序取分位边界）。展示固定桶 + P99 定位。
- 评分点：固定宽 vs 分位数桶；桶边界计算；直方图数据结构输出。

```javascript
function latencyHistogram(samples, { bucketMs = 500, maxMs = 10000 } = {}) {
  const bucketCount = Math.ceil(maxMs / bucketMs);
  const counts = new Array(bucketCount).fill(0);
  for (const s of samples) {
    const idx = Math.min(bucketCount - 1, Math.floor(s / bucketMs));   // 溢出归末桶
    counts[idx]++;
  }
  return {
    buckets: counts.map((c, i) => ({
      range: [i * bucketMs, (i + 1) * bucketMs], label: `${i * bucketMs}-${(i + 1) * bucketMs}ms`,
      count: c })),
    total: samples.length,
  };
}
function percentileFromHistogram(hist, p) {                // 从直方图估分位数
  const target = Math.ceil(hist.total * p);
  let acc = 0;
  for (const b of hist.buckets) {
    acc += b.count;
    if (acc >= target) return b.range[1];                  // 桶上界近似
  }
  return hist.buckets.at(-1).range[1];
}
// 精确分位数：t-digest / HdrHistogram；直方图版适合看板粗估
```
