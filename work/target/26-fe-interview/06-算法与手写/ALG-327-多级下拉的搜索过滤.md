## ALG-327：级联搜索：多级树按关键词过滤（命中节点+祖先链保留+兄弟折叠，ALG-198 的工程化）？
**答**：ALG-198 通讯录树过滤的工程化：命中节点 + 祖先链保留 + 未命中兄弟折叠 + 命中数统计（每分组"3 个匹配"）；模糊匹配（拼音首字母——zhcn→张成，Intl 简拼表）。

**思路**：DFS 过滤（返回过滤后树或 null）+ 命中计数上卷 + 拼音索引（预建 name→pinyin 映射，搜索时查表）。

```javascript
function filterTree(node, matcher, { withCount = true } = {}) {
  const selfMatch = matcher(node.name);
  const matchedChildren = [];
  let count = selfMatch ? 1 : 0;
  for (const child of node.children ?? []) {
    const filtered = filterTree(child, matcher, { withCount });
    if (filtered) { matchedChildren.push(filtered); count += filtered.count; }   // 命中子树：保留
  }
  if (!selfMatch && !matchedChildren.length) return null;   // 自身与子树都不命中：剪枝
  return { ...node, children: matchedChildren, count };     // 祖先链保留（count 上卷）
}
// 拼音搜索：预建映射（构建期从拼音库生成 name → { full: 'zhangsan', abbr: 'zs' }）
const pinyinIndex = new Map();                            // 构建期填充（不是搜索时逐字转换）
function pinyinMatcher(keyword) {
  const kw = keyword.toLowerCase();
  return (name) => name.includes(keyword)
    || pinyinIndex.get(name)?.full.includes(kw)
    || pinyinIndex.get(name)?.abbr.startsWith(kw);        // 全拼包含 + 首字母前缀
}
// 命中计数：每组节点 count（"华东区 (3)"）—— 分组感知的过滤结果
// 拼音索引构建期预建（运行时逐字转拼音性能不可接受——中文转拼音是重计算）
```

**评分点**：
- DFS 过滤（命中+祖先保留+未命中剪枝）与 count 上卷——本题核心（ALG-198 工程化）。
- 拼音索引构建期预建（运行时转换性能不可接受）。
- 全拼包含 + 首字母前缀两级匹配。
- 命中计数的分组展示价值。
