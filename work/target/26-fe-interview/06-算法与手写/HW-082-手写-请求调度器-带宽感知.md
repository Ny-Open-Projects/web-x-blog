## HW-082：手写带宽感知的请求调度器——按连接数与优先级调度 + 优先级抢占
**答**：HTTP/1.1 浏览器同域并发上限 6，HTTP/2 虽多路复用但服务端/客户端仍有流控。调度器：维护活跃请求计数，空闲槽按优先级取任务；高优先级请求到来时，可 abort 最低优先级的在途请求腾槽（抢占）；失败/abort 的请求 reject 并释放槽。

```javascript
class BandwidthScheduler {
  constructor({ maxConcurrent = 6, preempt = false } = {}) {
    this.max = maxConcurrent; this.active = new Map(); // id -> {abort, priority, resolve, reject}
    this.queue = []; this.seq = 0; this.preempt = preempt;
  }
  request(url, { priority = 0, signal } = {}) {
    return new Promise((resolve, reject) => {
      this.queue.push({ url, priority, resolve, reject, signal, id: ++this.seq });
      this.#dispatch();
    });
  }
  #dispatch() {
    while (this.active.size < this.max && this.queue.length) {
      this.queue.sort((a, b) => b.priority - a.priority);       // 取最高优
      const job = this.queue.shift();
      const ctrl = new AbortController();
      const entry = { abort: ctrl.abort.bind(ctrl), priority: job.priority, resolve: job.resolve, reject: job.reject, id: job.id };
      this.active.set(job.id, entry);
      fetch(job.url, { signal: ctrl.signal, ...(job.signal && { signal: job.signal }) })
        .then((r) => { this.active.delete(job.id); job.resolve(r); })
        .catch((e) => { this.active.delete(job.id); job.reject(e); })
        .finally(() => this.#dispatch());
    }
  }
  preemptLowest() {                                             // 抢占：abort 最低优在途
    if (!this.preempt) return false;
    const entries = [...this.active.values()];
    if (!entries.length) return false;
    const victim = entries.reduce((a, b) => (a.priority <= b.priority ? a : b));
    victim.abort();                                            // catch 路径释放槽
    return true;
  }
}
// 用法：6 并发槽内，用户点击"立即购买"可抢占低优预取
const sched = new BandwidthScheduler({ maxConcurrent: 6, preempt: true });
sched.request('/api/recs', { priority: 0 });
sched.request('/api/pay',   { priority: 10 }).catch(() => {});
// 若 6 槽全满，pay 可先 sched.preemptLowest() 腾槽再请求
```

**评分点**：
- 并发上限维护（active Map 计数，finally 释放槽后再 dispatch）。
- 优先级排序取任务；抢占通过 AbortController abort 在途低优请求实现。
- abort 后槽位释放（catch 路径 delete + dispatch）。
- 能说明 HTTP/1.1 6 连接上限与 HTTP/2 多路复用下调度的意义变化。
