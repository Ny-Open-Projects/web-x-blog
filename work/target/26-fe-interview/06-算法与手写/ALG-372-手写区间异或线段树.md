## ALG-372：手写区间异或线段树：开关状态区间翻转

**答**：
- 题目：一批开关（0/1），运营批量翻转某区间的所有开关，查某开关当前状态或区间内开启数。异或懒标记。
- 思路：节点存「开启数」；区间翻转标记 xor=1 → 和变 len - 和；下推时子标记 xor ^= 父标记（翻转两次抵消）。查单点：沿路径累计 xor 标记即可（也可 pushdown 到叶子）。
- 评分点：len - sum 的翻转公式；xor 标记自反合并；单点查沿路径累计标记的优化。

```javascript
class XorTree {
  constructor(bits) {
    this.n = bits.length;
    this.t = new Array(4 * this.n).fill(0);
    this.lazy = new Array(4 * this.n).fill(0);
    this.build(bits);
  }
  build(a, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.t[node] = a[l];
    const m = (l + r) >> 1;
    this.build(a, node * 2, l, m); this.build(a, node * 2 + 1, m + 1, r);
    this.t[node] = this.t[node * 2] + this.t[node * 2 + 1];
  }
  flip(ql, qr, node = 1, l = 0, r = this.n - 1) {
    if (qr < l || r < ql) return;
    if (ql <= l && r <= qr) {
      this.t[node] = (r - l + 1) - this.t[node];           // 翻转：和 = len - 和
      this.lazy[node] ^= 1;                                // 自反合并
      return;
    }
    const m = (l + r) >> 1;
    if (this.lazy[node]) {                                 // 下推
      for (const [c, cl] of [[node * 2, m - l + 1], [node * 2 + 1, r - m]]) {
        this.t[c] = cl - this.t[c]; this.lazy[c] ^= 1;
      }
      this.lazy[node] = 0;
    }
    this.flip(ql, qr, node * 2, l, m); this.flip(ql, qr, node * 2 + 1, m + 1, r);
    this.t[node] = this.t[node * 2] + this.t[node * 2 + 1];
  }
  get(i) { return this.queryOne(i); }
  queryOne(i, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.t[node];
    const m = (l + r) >> 1;
    if (this.lazy[node]) {                                 // 沿路径累计（此处简化 pushdown）
      for (const [c, cl] of [[node * 2, m - l + 1], [node * 2 + 1, r - m]]) {
        this.t[c] = cl - this.t[c]; this.lazy[c] ^= 1;
      }
      this.lazy[node] = 0;
    }
    return i <= m ? this.queryOne(i, node * 2, l, m) : this.queryOne(i, node * 2 + 1, m + 1, r);
  }
}
```
