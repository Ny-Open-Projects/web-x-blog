## HW-311：手写一个权限引擎：角色、资源与操作判定及缓存

**答**：
- 需求：实现 AuthzEngine：规则 [{role, resource, action, allow}]；can(role, resource, action) 判定（deny 优先于 allow）；通配（resource: * / action: *）；判定结果缓存（规则版本号失效）；多角色合并（任一 allow 且无 deny）。
- 边界：deny 优先；通配匹配（前缀 *）；规则变更 bump 版本清缓存；多角色 deny 优先（任一角色 deny 即拒绝）。
- 评分点：deny 优先；通配；版本失效缓存。

```javascript
class AuthzEngine {
  constructor(rules) { this.rules = rules; this.version = 0; this.cache = new Map(); }
  setRules(rules) { this.rules = rules; this.version++; this.cache.clear(); }   // 版本失效
  can(roles, resource, action) {
    const key = roles.slice().sort().join(',') + '|' + resource + '|' + action;
    const c = this.cache.get(key);
    if (c && c.v === this.version) return c.r;               // 缓存命中
    const r = this.compute(roles, resource, action);
    this.cache.set(key, { v: this.version, r });
    return r;
  }
  compute(roles, resource, action) {
    let deny = false, allow = false;
    for (const rule of this.rules) {
      if (!roles.includes(rule.role)) continue;
      if (!matchPattern(rule.resource, resource)) continue;
      if (!(rule.action === '*' || rule.action === action)) continue;
      if (rule.allow === false) deny = true;                 // deny 优先
      else allow = true;
    }
    return allow && !deny;
  }
}
function matchPattern(pattern, resource) {
  if (pattern === '*') return true;
  if (pattern.endsWith('*')) return resource.startsWith(pattern.slice(0, -1));
  return pattern === resource;
}
```
