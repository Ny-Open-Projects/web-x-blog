**场景**：销量榜：同销量的商品要并列（第 1、2、2、3 密集排名或 1、2、2、4 标准排名），榜单要稳定（同销量按上架时间早优先）且刷新不跳动。

**思路**：排序（多键：销量 desc + 上架时间 asc）→ 遍历赋名次（dense：值变才 +1；standard：跳位）。稳定化：同键用次级键（createdAt）保证顺序确定。

```javascript
function rankList(items, { mode = 'dense' } = {}) {
  const sorted = [...items].sort((a, b) =>
    b.sales - a.sales || a.createdAt - b.createdAt);   // 多键：同销量按上架时间（稳定次序）
  let rank = 0, prev = null, realIndex = 0;
  return sorted.map((item) => {
    realIndex++;
    if (item.sales !== prev) {
      rank = mode === 'dense' ? rank + 1 : realIndex;  // dense: 1,2,2,3 / standard: 1,2,2,4
      prev = item.sales;
    }
    return { ...item, rank };
  });
}
// [sales:100, 100, 80]
// dense   => rank 1, 1, 2
// standard=> rank 1, 1, 3
// 展示补充：并列名次显示"并列第 2"；同 rank 内按 createdAt 排序固定展示顺序（刷新不跳动）
// 防跳动：服务端快照榜单（每 N 分钟生成）—— 实时计算的榜单每秒变会让用户混乱
```

**评分点**：
- dense vs standard 两种并列语义（1223 vs 1234）实现正确——本题核心。
- 稳定次级键（同销量按上架时间）保证刷新不跳动。
- 并列展示语义（并列第 N）。
- 榜单快照防实时抖动的产品意识。
