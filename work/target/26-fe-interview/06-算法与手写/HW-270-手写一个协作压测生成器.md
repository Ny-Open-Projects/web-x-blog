## HW-270：手写一个协作压测生成器：模拟 N 用户随机操作验证收敛

**答**：
- 需求：实现 CollabStress：生成 N 个虚拟站点，每个按随机节奏产生 insert/delete ops；模拟网络（随机延迟+乱序+5% 丢包）；所有 op 交换完成后断言各站点文本收敛；输出报告（收敛成功率、平均收敛轮次、丢包重传量）。
- 边界：丢包由可靠层重传补齐（模拟层直接补投）；操作长度与位置合法；报告按 seed 可复现。
- 评分点：网络模拟三要素（延迟/乱序/丢包）；收敛判定；可复现报告。

```javascript
function collabStress({ sites = 4, opsPer = 30, seed = 7 } = {}) {
  const rng = mulberry32(seed);
  const docs = Array.from({ length: sites }, (_, i) => new CRDTDoc('site-' + i));
  const allOps = [];                                        // 全体 op 池
  for (let s = 0; s < sites; s++)
    for (let k = 0; k < opsPer; k++) {
      const doc = docs[s];
      const op = rng() < 0.7
        ? doc.localInsert(Math.floor(rng() * (doc.items.length + 1)), String.fromCharCode(97 + Math.floor(rng() * 26)))
        : (() => { const live = doc.items.filter(i => !i.deleted);
          const it = live[Math.floor(rng() * live.length)];
          if (it) { it.deleted = true; return it; } return null; })();
      if (op) allOps.push({ from: s, op });
    }
  // 模拟网络：乱序 + 丢包（由"全量补投"模拟可靠层重传）
  const shuffled = [...allOps].sort(() => rng() - 0.5);
  const dropped = shuffled.filter(() => rng() < 0.05);
  for (const { from, op } of shuffled)                     // 全网状交换
    for (let s = 0; s < sites; s++) if (s !== from) docs[s].remoteApply(op);
  for (const { from, op } of dropped)                      // 重传补投
    for (let s = 0; s < sites; s++) if (s !== from) docs[s].remoteApply(op);
  const texts = docs.map(d => d.text());
  return { converged: texts.every(t => t === texts[0]),
    rounds: 1, retrans: dropped.length,
    report: { seed, sites, opsPer } };                     // seed 可复现
}
```
