## HW-339：手写一个采样引擎：头采样、尾采样与一致性采样

**答**：
- 需求：implement Sampler：trace 级采样（一条请求链路统一采样决策）：head（入口随机决定，全链路继承）—由 traceparent 传播采样标志；tail（出口按耗时/错误决定是否上报，慢/错全保留）；一致性（同 uid 恒定采样——哈希）；组合策略可配。
- 边界：head 采样标志透传（下游不重复决策）；tail 采样需全链路缓冲（内存约束，环形）；一致性采样保证同用户体验完整追踪。
- 评分点：head 标志透传；tail 全保慢错；一致性哈希。

```javascript
class TraceSampler {
  constructor({ headRate = 0.1, slowMs = 1000 } = {}) { this.headRate = headRate; this.slowMs = slowMs; }
  head(uid) {                                                // 入口决策
    if (uid && hashStr(uid) % 100 < this.headRate * 100) return true;   // 一致性采样
    return Math.random() < this.headRate;                    // 随机兜底
  }
  inherit(parentFlag) { return parentFlag; }                 // 下游继承（不重复决策）
  tail(trace, { keepSlow = true, keepError = true, cap = 1000 } = {}) {   // 出口决策
    const isSlow = trace.duration > this.slowMs;
    const hasError = trace.spans.some(s => s.error);
    if ((keepSlow && isSlow) || (keepError && hasError)) return true;   // 慢/错全保
    this.buffer ??= [];
    this.buffer.push(trace);                                 // 正常样本进缓冲
    if (this.buffer.length > cap) this.buffer.shift();       // 环形约束
    return Math.random() < this.headRate;                    // 其余按率采样
  }
  traceparent(uid) {                                         // W3C traceparent 传播
    const flag = this.head(uid) ? '01' : '00';
    return `00-${crypto.randomUUID().replaceAll('-', '')}-${randomHex(8)}-${flag}`;
  }
}
const randomHex = n => [...crypto.getRandomValues(new Uint8Array(n))]
  .map(b => b.toString(16).padStart(2, '0')).join('');
```
