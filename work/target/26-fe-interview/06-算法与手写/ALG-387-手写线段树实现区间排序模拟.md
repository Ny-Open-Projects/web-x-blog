## ALG-387：手写线段树实现区间排序模拟：榜单区间重排

**答**：
- 题目：榜单序列，操作「把区间 [l, r] 的分数升序/降序重排」，查询某位置分数。真做需 「区间排序线段树（Segment tree beats 变体）」，面试给出可讲清的近似：分块 + 每块有序副本（懒重排）。
- 思路：分块维护每块「有序副本」+ 原始数组；重排标记 = 对整块生效的排序方向；查询时块在标记态直接二查副本，散块先下放标记。完整 beats 解复杂度均摊 O((n+q) log n)——提及即可。
- 评分点：分块懒排序标记；下放时机；提及 Segment tree beats 的存在与均摊复杂度。

```javascript
class SortBlocks {
  constructor(a) {
    this.a = a; this.bs = Math.ceil(Math.sqrt(a.length));
    this.mark = new Map();                                  // 块号 → 'asc'/'desc'（懒标记）
    this.rebuild();
  }
  rebuild() { this.sorted = this.chunk(this.a).map(c => [...c].sort((x, y) => x - y)); }
  chunk(a) { const out = [];
    for (let i = 0; i < a.length; i += this.bs) out.push(a.slice(i, i + this.bs)); return out; }
  sortRange(l, r, dir) {                                    // 区间重排（近似实现）
    const seg = this.a.slice(l, r + 1).sort((x, y) => dir === 'asc' ? x - y : y - x);
    for (let i = l; i <= r; i++) this.a[i] = seg[i - l];    // 简化：直接重写
    this.rebuild();                                         // 生产用懒标记+局部重建
  }
  at(i) { return this.a[i]; }
}
// 完整解 Segment tree beats：max/min 段剪枝均摊 O((n+q) log² n)——面试提及思想
```
