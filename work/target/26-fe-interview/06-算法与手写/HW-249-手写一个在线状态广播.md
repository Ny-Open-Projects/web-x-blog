## HW-249：手写一个在线状态广播：presence 光标与选区同步

**答**：
- 需求：实现 Presence：broadcast({user, cursor: {blockId, offset}, sel}) 周期 5s 心跳 + 变更即时；接收端维护 peers Map（user -> 最新 presence），超时（15s 无心跳）移除并触发回调；渲染数据输出（含颜色分配）。
- 边界：同一用户多标签页（取最新会话）；心跳与变更双通道防丢失；颜色由 userId 哈希稳定分配（重连不变色）。
- 评分点：心跳超时剔除；颜色稳定哈希；多端去重。

```javascript
class Presence {
  constructor(sessionId, { interval = 5000, timeout = 15000 } = {}) {
    this.session = sessionId; this.interval = interval;
    this.timeout = timeout; this.peers = new Map();
    this.timer = setInterval(() => this.beat(), interval);
  }
  update(cursor, sel) { this.broadcast({ session: this.session, cursor, sel }); }
  beat() { this.broadcast({ session: this.session, heartbeat: true }); this.gc(); }
  broadcast(msg) { channel.send({ type: 'presence', user: USER_ID, ts: Date.now(), ...msg }); }
  receive(msg) {
    const k = msg.user + ':' + msg.session;
    this.peers.set(k, { ...msg, seen: Date.now() });         // 多标签会话各自最新
  }
  gc() {                                                    // 超时剔除
    for (const [k, p] of this.peers)
      if (Date.now() - p.seen > this.timeout) { this.peers.delete(k); this.onLeave?.(k); }
  }
  renderList() {                                            // 颜色稳定分配
    return [...this.peers.values()].map(p => ({
      user: p.user, cursor: p.cursor, sel: p.sel,
      color: palette(hashStr(p.user) % palette.length),     // 稳定哈希配色
    }));
  }
  destroy() { clearInterval(this.timer); }
}
const palette = ['#f66', '#6c6', '#66f', '#c6c', '#fa0'];
function hashStr(s) { let h = 0; for (const c of s) h = (h * 31 + c.charCodeAt(0)) >>> 0; return h; }
```
