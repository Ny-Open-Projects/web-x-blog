## HW-142：手写表格列宽拖拽——pointer 事件调整列宽、最小宽度约束与布局位移最小化（table-fixed）
**答**：列宽拖拽三要点：① pointerdown/move/up（Pointer Events 统一鼠标触摸）+ setPointerCapture（拖出元素也持续跟踪）；② table-layout: fixed + colgroup 显式列宽——调整一列不动其他列（否则浏览器自动分配引起全表重排抖动）；③ 最小宽度约束 + 宽度持久化（localStorage 按表格 id 存偏好）。

```javascript
function makeResizable(table, { minWidth = 80 } = {}) {
  table.style.tableLayout = 'fixed';                  // 关键：fixed 布局拖一列不动其他列
  const cols = table.querySelectorAll('col');
  table.querySelectorAll('th').forEach((th, i) => {
    const handle = th.querySelector('.col-resizer') ?? addHandle(th);
    handle.addEventListener('pointerdown', (e) => {
      e.preventDefault();
      handle.setPointerCapture(e.pointerId);          // 拖出 handle 也持续跟踪
      const startX = e.clientX, startW = cols[i].offsetWidth ?? cols[i].style.width.slice(0, -2);
      const move = (ev) => {
        const w = Math.max(minWidth, startW + ev.clientX - startX);
        cols[i].style.width = w + 'px';               // 直接改 col 宽度（一次 layout）
      };
      const up = (ev) => {
        handle.releasePointerCapture(e.pointerId);
        handle.removeEventListener('pointermove', move);
        handle.removeEventListener('pointerup', up);
        persistWidths(table.id, [...cols].map((c) => c.style.width));   // 偏好持久化
      };
      handle.addEventListener('pointermove', move);
      handle.addEventListener('pointerup', up);
    });
  });
}
// table-layout:fixed 是核心——auto 布局拖一列会重排全表（其他列跟着抖）
// setPointerCapture：快速拖动鼠标出窗口也能持续跟踪（不丢 pointerup）
// 触摸支持：Pointer Events 天然统一（touch-action: none 防滚动冲突）
```

**评分点**：
- table-layout: fixed + colgroup 的布局位移最小化——本题核心。
- setPointerCapture 的跟踪语义；Pointer Events 统一鼠标触摸。
- minWidth 约束；宽度偏好持久化。
- touch-action: none 防触摸滚动冲突的意识。
