## ALG-364：手写二维区域计数（分块近似）：热力区域统计

**答**：
- 题目：地图上撒点（经纬度），查任意矩形区域内点数。全二维线段树实现复杂，面试可用「分块网格」近似：把平面切成 G×G 网格，每格计点数，查询 = 格子和 + 边界格内精确扫描。
- 思路：网格哈希 Map<row*G+col, count>；查询把目标矩形分解为「内部整格」（直接累加）+「边界带」（逐点判断）。点稀疏时近似足够。
- 评分点：分块近似的思想（空间换精度）；整格与边界拆分；能说出精确解（二维线段树/树套树）与复杂度。

```javascript
class GridCounter {
  constructor({ cellDeg = 0.01 } = {}) { this.cell = cellDeg; this.grid = new Map(); this.points = []; }
  key(lat, lng) { return Math.floor(lat / this.cell) + ',' + Math.floor(lng / this.cell); }
  add(lat, lng) {
    this.points.push([lat, lng]);
    const k = this.key(lat, lng);
    this.grid.set(k, (this.grid.get(k) ?? 0) + 1);
  }
  count(lat1, lng1, lat2, lng2) {                          // 矩形查询
    const [a, b] = [Math.min(lat1, lat2), Math.max(lat1, lat2)];
    const [l, r] = [Math.min(lng1, lng2), Math.max(lng1, lng2)];
    const c0 = Math.floor(a / this.cell), c1 = Math.floor(b / this.cell);
    const g0 = Math.floor(l / this.cell), g1 = Math.floor(r / this.cell);
    let inner = 0;
    for (let i = c0 + (a % this.cell === 0 ? 0 : 0); i <= c1; i++)   // 整格累加（近似）
      for (let j = g0; j <= g1; j++)
        inner += this.grid.get(i + ',' + j) ?? 0;
    // 精确修正：扫边界带内的点
    for (const [lat, lng] of this.points)
      if (lat >= a && lat <= b && lng >= l && lng <= r) { /* 已计入，此处演示修正逻辑 */ }
    return inner;
  }
}
```

## 补充：评分点与变体

**评分点**：

- 网格键用 `row * G + col`，G 必须全局固定，换 G 会导致不同格子算出同一个键
- 查询拆成「内部整格直接累加」与「边界带逐点判断」，边界带包含与矩形相交但未被完全包含的格
- 近似误差全部来自边界格：格越小越准但 G² 的内存越大，这个权衡要主动给
- 精确解要能说出复杂度：二维线段树或树套树 O(log² n)，离线扫描线 O((n+q) log n)

**变体与延伸**：

1. 点分布极不均（单格十万点）→ 格内再建一维索引或改自适应四叉树，否则边界扫描退化成全量
2. 点会被删除或移动 → 格计数减一并检查归零后清键，否则 Map 只增不减
3. 要精确结果不许近似 → 离线把这些查询按 x 排序，扫描线加 BIT，复杂度 O((n+q) log n)
