## ALG-303：筛选互斥：选择 A 档价格后某些品牌失效（组合可行性检测——可行性集动态计算）？
**答**：筛选联动互斥：选了"价格 < 100"后某些品牌在该价格段无商品——这些品牌选项置灰（不可选）。联动可行性 = 各维度候选值基于"其他维度当前筛选"的商品集存在性判定（ALG-247 facet 计数的选通版）。

**思路**：复用 ALG-247 facet 计数——计数 > 0 的选项可选，= 0 置灰（并显示"0 件"）。

```javascript
function optionAvailability(goods, active) {
  const dims = ['brand', 'price', 'color'];
  const availability = {};
  for (const dim of dims) {
    const others = dims.filter((d) => d !== dim);
    const pass = goods.filter((g) => others.every((d) => !active[d]?.size || active[d].has(g[d])));
    const counts = new Map();
    for (const g of pass) counts.set(g[dim], (counts.get(g[dim]) ?? 0) + 1);
    availability[dim] = counts;                           // 每选项的可用计数
  }
  return availability;                                    // counts.get(option) === 0 → 置灰
}
// UI：disabled={count === 0}，标签"品牌X (0)" —— 置灰可感知（比"点了没反应"体验好 10 倍）
// 语义：置灰选项不可点（不是可点后空结果）—— 避免用户进入"0 结果"死胡同
// 复用 ALG-247：同一 facet 计数既驱动侧栏数字也驱动置灰状态（一次计算两用）
```

**评分点**：
- facet 计数复用为置灰判定（计数 0 → 置灰）——本题核心。
- "排除自身维度"语义（ALG-247）保证互斥联动正确。
- 置灰可感知 vs 点了空结果的体验对比。
- 一次计算双用途（计数 + 可用性）。
