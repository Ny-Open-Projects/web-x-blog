## HW-407：手写一个代码片段库：分类存储、模糊搜索与一键插入

**答**：
- 需求：实现 SnippetLib：片段 CRUD（{id, title, code, lang, tags}，存 IndexedDB）；分类与标签过滤；模糊搜索（title/tags/code 全文，复用 LocalSearch 思路）；一键插入（复制到剪贴板或直接插入编辑器光标处）；导入导出（JSON 批量）。
- 边界：代码原文存储（不做转义）；搜索打分（title 命中权重 > tags > code）；导入去重（同 title+lang 判重）。
- 评分点：多字段加权搜索；导入去重；剪贴板兜底。

```javascript
class SnippetLib {
  constructor(store) { this.store = store; this.cache = []; }
  async add(snippet) {
    const dup = this.cache.find(s => s.title === snippet.title && s.lang === snippet.lang);
    if (dup) return { ok: false, reason: 'duplicate' };      // 去重
    const rec = { ...snippet, id: crypto.randomUUID(), ts: Date.now() };
    await this.store.put('snippets', rec);
    this.cache.push(rec);
    return { ok: true, id: rec.id };
  }
  async remove(id) { await this.store.del('snippets', id);
    this.cache = this.cache.filter(s => s.id !== id); }
  search(query) {                                            // 多字段加权
    if (!query) return this.cache;
    return this.cache.map(s => ({ s,
      score: fuzzyScore(query, s.title) * 3                 // title 权重最高
        + (s.tags ?? []).reduce((sum, t) => sum + fuzzyScore(query, t), 0) * 2
        + fuzzyScore(query, s.code) }))
      .filter(x => x.score > 0)
      .sort((a, b) => b.score - a.score).map(x => x.s);
  }
  async insert(snippetId, editor) {                          // 一键插入
    const s = this.cache.find(x => x.id === snippetId);
    if (!s) return false;
    try { await navigator.clipboard.writeText(s.code);       // 剪贴板优先
      toast('已复制到剪贴板');
    } catch { editor.insertAtCursor(s.code); }               // 兜底直接插入
    return true;
  }
  export() { return JSON.stringify(this.cache, null, 2); }
  async import(json) {
    const items = JSON.parse(json);
    let added = 0;
    for (const it of items) { const r = await this.add(it); if (r.ok) added++; }   // 导入去重
    return { added, skipped: items.length - added };
  }
}
```
