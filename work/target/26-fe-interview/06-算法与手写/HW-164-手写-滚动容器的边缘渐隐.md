## HW-164：手写滚动边缘渐隐——CSS mask 为主 + IO 哨兵切换 class（零主线程成本）
**答**：滚动容器边缘渐隐（提示可滚动）：① 首选 CSS mask-image 渐变 + IO 哨兵元素切换 class（顶部/底部哨兵是否可见决定 mask 状态——零 scroll 监听零主线程）；② mask 的渐变方向随状态切换（transition 平滑）；③ 降级：不支持 mask 的浏览器用覆盖渐变层。

```css
.scroller { mask-image: linear-gradient(#000, #000); transition: mask-image .3s; }
.scroller.has-top { mask-image: linear-gradient(transparent, #000 24px, #000); }
.scroller.has-bottom { mask-image: linear-gradient(#000, #000 calc(100% - 24px), transparent); }
.scroller.has-top.has-bottom {
  mask-image: linear-gradient(transparent, #000 24px, #000 calc(100% - 24px), transparent);
}
```
```javascript
function edgeFade(container) {
  const top = document.createElement('div'), bottom = document.createElement('div');
  top.style.cssText = bottom.style.cssText = 'position:absolute;height:1px;width:100%;pointer-events:none';
  container.prepend(top); container.append(bottom);       // 哨兵：位置固定在容器首尾
  const io = new IntersectionObserver(() => {
    const hasTop = container.scrollTop > 0;               // 也可用哨兵可见性：top 哨兵不可见 = 有内容被卷走
    const hasBottom = container.scrollTop + container.clientHeight < container.scrollHeight;
    container.classList.toggle('has-top', hasTop);
    container.classList.toggle('has-bottom', hasBottom);
  }, { root: container, threshold: 0 });
  io.observe(top); io.observe(bottom);
  return () => io.disconnect();
}
// mask 方案 vs 渐变覆盖层：mask 真正"淡出内容"（渐变层只是盖住，露出背景色）——视觉更高级
// IO 哨兵方案零 scroll 监听（PER-402）；scroll 事件变化仅在 IO 回调（滚动本身零成本）
```

**评分点**：
- CSS mask-image 渐变 + IO 哨兵切换（零主线程滚动成本）——本题核心。
- 四种状态组合的 mask 渐变正确（top/bottom/both/none）。
- mask 与覆盖渐变层的视觉差异说明。
- 哨兵元素方案与 scrollTop 计算的取舍。
