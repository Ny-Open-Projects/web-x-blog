## ALG-545：手写跳表思想：有序集合实现

**答**：
- 题目：实现有序集合（按分数排序，支持范围查询与排名）——跳表：多层链表，查找 O(log n) 期望。Redis ZSET 同款结构。
- 思路：每节点随机层高（抛硬币）；查找从顶层走到底层；插入随机层高并接链；范围查询定位起点后沿底层走。
- 评分点：随机层高（p=1/2）；期望 O(log n)；与平衡树对比（实现简单，无旋转）。

```javascript
class SkipList {
  constructor({ maxLevel = 16, p = 0.5 } = {}) {
    this.head = { score: -Infinity, children: new Array(maxLevel).fill(null) };
    this.p = p; this.maxLevel = maxLevel; this.level = 1;
  }
  randomLevel() { let l = 1;
    while (Math.random() < this.p && l < this.maxLevel) l++;
    return l; }
  insert(score, value) {
    const update = new Array(this.maxLevel).fill(this.head);
    let node = this.head;
    for (let l = this.level - 1; l >= 0; l--) {            // 从顶层查找
      while (node.children[l] && node.children[l].score < score)
        node = node.children[l];
      update[l] = node;
    }
    const level = this.randomLevel();
    if (level > this.level) { this.level = level; }
    const nn = { score, value, children: new Array(level).fill(null) };
    for (let l = 0; l < level; l++) {                      // 接链
      nn.children[l] = update[l].children[l];
      update[l].children[l] = nn;
    }
  }
  range(lo, hi) {                                          // 范围查询
    let node = this.head;
    for (let l = this.level - 1; l >= 0; l--)
      while (node.children[l] && node.children[l].score < lo)
        node = node.children[l];
    node = node.children[0];
    const out = [];
    while (node && node.score <= hi) { out.push({ score: node.score, value: node.value });
      node = node.children[0]; }
    return out;
  }
}
```
