## ALG-371：手写区间加+区间求和综合线段树：进度条区间贡献

**答**：
- 题目：任务进度按天记录增量，要查「第 10~20 天区间的进度总和」且支持对某区间统一补录增量（如补数据）。区间加 + 区间和（带懒标记）。
- 思路：懒标记线段树标准实现（同 ALG-352 但查询也是区间而非单点）——查询路径同样要先 pushdown。
- 评分点：查询路径也要 pushdown；区间贡献聚合；len 参与和值计算。

```javascript
class RangeAddSumTree {
  constructor(n) { this.n = n;
    this.t = new Array(4 * n).fill(0); this.lazy = new Array(4 * n).fill(0); }
  apply(node, v, len) { this.t[node] += v * len; this.lazy[node] += v; }
  pushdown(node, l, r) {
    if (!this.lazy[node]) return;
    const m = (l + r) >> 1;
    this.apply(node * 2, this.lazy[node], m - l + 1);
    this.apply(node * 2 + 1, this.lazy[node], r - m);
    this.lazy[node] = 0;
  }
  add(ql, qr, v, node = 1, l = 0, r = this.n - 1) {
    if (qr < l || r < ql) return;
    if (ql <= l && r <= qr) return this.apply(node, v, r - l + 1);
    this.pushdown(node, l, r);
    const m = (l + r) >> 1;
    this.add(ql, qr, v, node * 2, l, m); this.add(ql, qr, v, node * 2 + 1, m + 1, r);
    this.t[node] = this.t[node * 2] + this.t[node * 2 + 1];
  }
  query(ql, qr, node = 1, l = 0, r = this.n - 1) {         // 查询也 pushdown
    if (qr < l || r < ql) return 0;
    if (ql <= l && r <= qr) return this.t[node];
    this.pushdown(node, l, r);
    const m = (l + r) >> 1;
    return this.query(ql, qr, node * 2, l, m) + this.query(ql, qr, node * 2 + 1, m + 1, r);
  }
}
```
