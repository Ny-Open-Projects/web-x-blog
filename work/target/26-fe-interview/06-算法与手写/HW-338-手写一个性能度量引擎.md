## HW-338：手写一个性能度量引擎：marker、measure 封装与预算判定

**答**：
- 需求：实现 PerfMark：mark(name) 打点（user timing API）；measure(from, to) 产出耗时；budget(name, ms) 预算登记——measure 超预算自动告警；report 汇总所有 measures（p50/p75）+ 预算达成率。
- 边界：mark 去重（同名覆盖）；预算按路由独立；PerformanceObserver 监听 longtask 归入报告。
- 评分点：User Timing API；预算自动判定；p 分位聚合。

```javascript
class PerfMark {
  constructor(budgets = {}) { this.budgets = budgets; this.measures = []; this.violations = []; }
  mark(name) { performance.mark(name); return name; }
  measure(name, from, to, { budget } = {}) {
    const m = performance.measure(name, from, to ?? 'now');
    const ms = m.duration;
    this.measures.push({ name, ms: +ms.toFixed(1), route: location.pathname });
    const b = budget ?? this.budgets[name];
    if (b && ms > b) {                                       // 预算自动判定
      this.violations.push({ name, ms: +ms.toFixed(1), budget: b, route: location.pathname });
      report('perf-budget-violation', { name, ms: +ms.toFixed(1), budget: b });
    }
    return ms;
  }
  async collectLongTasks() {                                 // longtask 归入报告
    return new Promise(resolve => {
      const tasks = [];
      new PerformanceObserver(list => {
        list.getEntries().forEach(e => tasks.push({ dur: +e.duration.toFixed(1),
          start: +e.startTime.toFixed(0) }));
      }).observe({ entryTypes: ['longtask'] });
      setTimeout(() => resolve(tasks), 10000);               // 采样 10s
    });
  }
  report() {
    const byName = {};
    for (const m of this.measures) (byName[m.name] ??= []).push(m.ms);
    const pct = (a, p) => { const s = [...a].sort((x, y) => x - y);
      return +(s[Math.floor(s.length * p)] ?? 0).toFixed(1); };
    return {
      metrics: Object.fromEntries(Object.entries(byName).map(([k, v]) =>
        [k, { p50: pct(v, 0.5), p75: pct(v, 0.75), n: v.length }])),
      budgetRate: this.measures.length
        ? +(1 - this.violations.length / this.measures.length).toFixed(3) : 1,   // 预算达成率
      violations: this.violations.slice(-20),
    };
  }
}
```
