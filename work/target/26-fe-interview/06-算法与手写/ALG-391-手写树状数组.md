## ALG-391：手写树状数组：单点更新+前缀和（累计投票数）

**答**：
- 题目：投票系统，候选人得票实时变化，查「前 k 名投票站的累计票数」。树状数组（BIT）：lowbit 跳跃，O(log n) 单点加与前缀和。
- 思路：BIT[i] 管 [i-lowbit+1, i]；单点加沿 i += lowbit 更新；前缀和沿 i -= lowbit 累加。区间和 = 前缀差。
- 评分点：lowbit 定义 i & -i；两个方向的循环；区间和用两次前缀差。

```javascript
class BIT {
  constructor(n) { this.n = n; this.t = new Array(n + 1).fill(0); }   // 1-based
  static lowbit(i) { return i & -i; }                       // 核心：i & -i
  add(i, v) {                                               // 单点加（1-based）
    for (; i <= this.n; i += BIT.lowbit(i)) this.t[i] += v;
  }
  sum(i) {                                                  // 前缀 [1..i]
    let s = 0;
    for (; i > 0; i -= BIT.lowbit(i)) s += this.t[i];
    return s;
  }
  range(l, r) { return this.sum(r) - this.sum(l - 1); }     // 区间 = 前缀差
}
// 投票：votes.add(stationId, count)；查前 k 站累计 = votes.sum(k)
```
