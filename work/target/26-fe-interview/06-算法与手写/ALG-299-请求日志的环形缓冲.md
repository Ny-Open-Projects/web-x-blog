## ALG-299：请求日志环形缓冲：固定容量 RingBuffer（最近 N 条请求日志，调试面板数据源）？
**答**：调试面板要"最近 100 条请求日志"——数组 unshift + splice 是 O(n) 移动；环形缓冲 O(1) 写（指针推进覆盖旧数据），读时按序展开。

**思路**：定长数组 + head 指针 → 写：arr[head] = item, head=(head+1)%n → 读：从 head 起绕圈展开（最新的在前）。

```javascript
class RingBuffer {
  #buf; #head = 0; #count = 0;
  constructor(capacity = 100) { this.#buf = new Array(capacity); this.capacity = capacity; }
  push(item) {
    this.#buf[this.#head] = item;                         // 覆盖最旧（O(1) 写）
    this.#head = (this.#head + 1) % this.capacity;
    this.#count = Math.min(this.#count + 1, this.capacity);
  }
  toArray() {                                             // 读：按新旧顺序展开
    const out = [];
    for (let i = this.#count - 1; i >= 0; i--) {
      out.push(this.#buf[(this.#head - 1 - i + this.capacity * 2) % this.capacity]);
    }
    return out;                                           // 最新在前（调试面板习惯）
  }
  get size() { return this.#count; }
}
// O(1) 写 vs 数组 unshift+splice 的 O(n) 移动——高频写入场景（每秒 50 请求）差异显著
// 定长内存：恒定 100 条（自动淘汰最旧——内存有界，长会话不涨）
// 调试面板消费：toArray 展开渲染（低频读），写路径保持 O(1)
```

**评分点**：
- 环形写 O(1)（head 推进覆盖）——本题核心。
- toArray 的新旧序展开（取模绕圈正确）。
- 内存有界（定长自动淘汰——长会话不涨）。
- 与 EventStreamBuffer（HW-350 场景）的同构关系。
