## ALG-242：i18n 插值完整性校验：多语言文案的 {var} 占位符集合一致性检查（遍历 + 差集）
**答**：i18n 文案 `您好 {username}，您有 {count} 条消息`，各语言版本的占位符必须一致（漏一个运行时显示 {username} 原文）。构建期校验：提取每条文案的占位符集合，跨语言 diff。

**思路**：正则提取占位符 → 按 key 分组比较集合（差集）；输出缺失清单。

```javascript
const PLACEHOLDER = /\{(\w+)\}/g;
function placeholders(text) {
  return new Set([...text.matchAll(PLACEHOLDER)].map((m) => m[1]));
}
function auditI18n(bundles) {
  // bundles: { 'zh': { 'greeting': '您好 {username}，{count} 条' },
  //            'en': { 'greeting': 'Hi {username}, {count} messages' },
  //            'ar': { 'greeting': 'مرحبا {username}' } }   ← 缺 {count}
  const issues = [];
  const keys = new Set(Object.values(bundles).flatMap((b) => Object.keys(b)));
  for (const key of keys) {
    const ref = placeholders(bundles.zh?.[key] ?? '');       // 以 zh 为基准
    for (const [lang, bundle] of Object.entries(bundles)) {
      if (!bundle[key]) { issues.push({ key, lang, issue: 'missing' }); continue; }
      const set = placeholders(bundle[key]);
      const missing = [...ref].filter((p) => !set.has(p));
      const extra = [...set].filter((p) => !ref.has(p));
      if (missing.length || extra.length) issues.push({ key, lang, missing, extra });
    }
  }
  return issues;
}
// 输出：[{ key: 'greeting', lang: 'ar', missing: ['count'], extra: [] }]
// CI 集成：构建期跑 auditI18n，issues 非空拦发布（漏占位符 = 线上显示原文）
// RTL 语言（ar）额外校验：纯占位文案不含 BOM/方向字符混入
```

**评分点**：
- 正则提取占位符集合 + 跨语言差集校验的完整实现。
- missing/extra 双向 diff（多占位也报）。
- CI 集成拦发布的工程意识。
- 基准语言选择与 missing key 的单独类型。
