## HW-408：手写一个编辑器协同回放器：操作流时间轴播放

**答**：
- 需求：实现 ReplayPlayer：输入回放包（HW-389 产出：快照 + 事件流）；播放控制（play/pause/seek(倍速 1x/4x/16x)）；渲染（seek 到快照起点，重放其后事件；无快照从头重放）；时间轴 UI 数据（事件密度直方图 + 关键事件标记）；多人操作区分色显示。
- 边界：seek 策略（就近快照 + 部分重放 vs 从头重放，取耗时小者）；倍速通过事件时间压缩实现；暂停时状态冻结；回放性能（大事件量用 rAF 分帧处理）。
- 评分点：seek 快照加速；倍速时间压缩；分帧处理。

```javascript
class ReplayPlayer {
  constructor(pack) {
    this.snapshots = pack.snapshots; this.events = pack.events;
    this.pos = 0; this.speed = 1; this.timer = null;
  }
  play() {
    if (this.timer) return;
    let last = performance.now();
    const tick = (now) => {
      const elapsed = (now - last) * this.speed;             // 倍速=时间压缩
      last = now;
      this.advance(elapsed);
      if (this.pos < this.events.at(-1).t) this.timer = requestAnimationFrame(tick);
      else this.pause();
    };
    this.timer = requestAnimationFrame(tick);
  }
  advance(ms) {
    const target = this.virtualTime + ms;
    while (this.idx < this.events.length && this.events[this.idx].t <= target) {
      applyEvent(this.events[this.idx++]);                   // 逐事件重放
    }
    this.virtualTime = target;
  }
  pause() { cancelAnimationFrame(this.timer); this.timer = null; }
  seek(t) {                                                  // seek：快照加速
    const snap = this.snapshots.filter(s => s.t <= t).at(-1);
    const replayFrom = snap ? snap.t : this.events[0].t;
    const replayCost = t - replayFrom;
    const fullCost = t - this.events[0].t;
    if (snap && replayCost < fullCost * 0.3) {               // 快照+部分重放更快
      restoreDoc(snap.doc); this.idx = this.events.findIndex(e => e.t > snap.t);
    } else { restoreDoc(this.snapshots[0]?.doc ?? emptyDoc()); this.idx = 0; }
    this.virtualTime = replayFrom;
    this.advance(t - replayFrom);
  }
  timeline() {                                               // 直方图 UI 数据
    const buckets = new Array(50).fill(0);
    for (const e of this.events) {
      const i = Math.floor((e.t - this.events[0].t)
        / (this.events.at(-1).t - this.events[0].t) * 50);
      buckets[i]++;
    }
    return { buckets, marks: this.events.filter(e => e.type === 'conflict').map(e => e.t) };   // 关键事件标记
  }
}
```
