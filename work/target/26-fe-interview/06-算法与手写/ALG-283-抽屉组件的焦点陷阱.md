## ALG-283：模态焦点陷阱：Tab 循环限制在抽屉内 + Esc 关闭 + 关闭后焦点还原（a11y 完整实现）？
**答**：抽屉/模态的 a11y 三件套：Tab 焦点循环限制（focus trap——Tab 在容器内循环不逃逸）；Esc 关闭；关闭后焦点还原到触发元素（用户不迷路）。实现：keydown Tab 拦截 + 可聚焦元素查询 + 触发元素记录。

**思路**：open 时记录 document.activeElement（还原点）→ 聚焦容器内第一个可聚焦元素 → keydown 拦截 Tab（到尾跳头、到头跳尾）→ 关闭时还原焦点。

```javascript
class FocusTrap {
  #prevFocus = null;
  #handler = null;
  open(container) {
    this.#prevFocus = document.activeElement;             // 还原点
    const focusables = () => [...container.querySelectorAll(
      'a[href],button:not([disabled]),input:not([disabled]),select,textarea,[tabindex]:not([tabindex="-1"])'
    )].filter((el) => el.offsetParent !== null);          // 可见性过滤
    const first = focusables()[0];
    first?.focus();
    this.#handler = (e) => {
      if (e.key === 'Escape') return this.close(container);   // Esc 关闭
      if (e.key !== 'Tab') return;
      const list = focusables();
      const i = list.indexOf(document.activeElement);
      if (e.shiftKey && (i <= 0)) { e.preventDefault(); list.at(-1)?.focus(); }       // 头部反向：跳尾
      else if (!e.shiftKey && (i === list.length - 1 || i === -1)) {
        e.preventDefault(); list[0]?.focus();             // 尾部正向：跳头（循环）
      }
    };
    container.addEventListener('keydown', this.#handler);
  }
  close(container) {
    container.removeEventListener('keydown', this.#handler);
    this.#prevFocus?.focus();                             // 焦点还原：用户不迷路
    this.#prevFocus = null; this.#handler = null;
  }
}
// 焦点还原是最高频遗漏点：关闭抽屉后焦点落 body → 键盘用户"丢失位置"
// offsetParent 过滤：display:none 的元素不可聚焦
// focusables 每次重查（动态内容：抽屉内条件渲染的按钮）
```

**评分点**：
- focus trap 三件套（循环/Esc/还原）——本题核心。
- 还原到触发元素（焦点不迷路）——最高频遗漏。
- 可聚焦元素查询与可见性过滤（offsetParent）。
- focusables 每次重查（动态内容的支持）。
