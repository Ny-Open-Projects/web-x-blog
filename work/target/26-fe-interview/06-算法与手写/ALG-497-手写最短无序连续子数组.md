## ALG-497：手写最短无序连续子数组：排序异常段定位

**答**：
- 题目：数据序列被「局部污染」，找出「仅排序该连续子段就能使全序列有序」的最短子段 [l, r]。
- 思路：从左扫找最后一个比前缀最大值小的位置（右边界 r）；从右扫找最左一个比后缀最小值大的位置（左边界 l）。
- 评分点：双向扫描找边界；前后缀极值；若已有序返回 [-1,-1]。

```javascript
function findUnsortedSubarray(arr) {
  const n = arr.length;
  let maxSeen = -Infinity, r = -1;
  for (let i = 0; i < n; i++) {                            // 从左找右边界
    if (arr[i] < maxSeen) r = i;
    maxSeen = Math.max(maxSeen, arr[i]);
  }
  if (r === -1) return [-1, -1];                           // 已有序
  let minSeen = Infinity, l = -1;
  for (let i = n - 1; i >= 0; i--) {                       // 从右找左边界
    if (arr[i] > minSeen) l = i;
    minSeen = Math.min(minSeen, arr[i]);
  }
  return [l, r];
}
// 例：[1,3,5,4,2,6] → [1,4]（排序 3,5,4,2 即全序）
// 正确性：r = 最后一个「小于其左侧最大值」的位置——其右侧都已有序
```

## 追问（补充）

**追问**：

1. 为什么左右各扫一遍就够了？ → 右边界 r 定义为「最后一个小于其左侧最大值的位置」，r 右边必然有序；对称地 l 是「第一个大于其右侧最小值的位置」，中间段恰好是唯一需要重排的区间。
2. 全是相同元素会怎样？ → `arr[i] < maxSeen` 永远为假，返回 [-1,-1]，符合「已有序」语义；但若把判断写成 `<=`，就会把一个完全相等的数组判成需要排序。
3. 存在重复元素时答案还唯一吗？ → 最短长度唯一，边界可能不唯一（等于两侧极值的等值元素可以纳入也可以排除），答题时要说明按「最小长度」取值，避免与面试官争边界。
4. O(n) 空间的做法是什么？ → 复制一份排序后与原文逐位比对，第一个不同的位置到最后一个不同的位置即答案；时间 O(n log n) 但更不容易写错，适合先写这个再优化。
