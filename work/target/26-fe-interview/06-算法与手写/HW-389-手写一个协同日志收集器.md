## HW-389：手写一个协同日志收集器：编辑行为漏斗与回放数据

**答**：
- 需求：实现 CollabLogger：记录编辑行为事件（open/edit/commit/conflict/undo/close）含时间戳与会话 id；漏斗统计（打开→首次编辑→首次提交 的转化率与中位耗时）；回放数据导出（事件流 + 定期文档快照，供回放器）；采样与脱敏。
- 边界：漏斗按会话聚合（跨会话合并）；回放数据体积控制（快照间隔 + 事件压缩）；文本内容脱敏选项。
- 评分点：会话漏斗聚合；快照+事件回放包；脱敏。

```javascript
class CollabLogger {
  constructor({ snapshotEvery = 200 } = {}) {
    this.events = []; this.snapshots = []; this.n = 0; this.snapshotEvery = snapshotEvery;
  }
  log(type, data = {}) {                                     // 事件记录
    this.events.push({ t: Date.now(), session: SESSION_ID, type, ...data });
  }
  onEdit() { if (++this.n % this.snapshotEvery === 0)        // 定期快照
    this.snapshots.push({ t: Date.now(), doc: serializeDoc(currentDoc()) }); }
  funnel() {                                                 // 会话漏斗聚合
    const bySession = new Map();
    for (const e of this.events) {
      let s = bySession.get(e.session);
      if (!s) bySession.set(e.session, s = { opened: null, edited: null, committed: null, conflicts: 0 });
      if (e.type === 'open' && !s.opened) s.opened = e.t;
      if (e.type === 'edit' && !s.edited) s.edited = e.t;
      if (e.type === 'commit' && !s.committed) s.committed = e.t;
      if (e.type === 'conflict') s.conflicts++;
    }
    const sessions = [...bySession.values()].filter(s => s.opened);
    const med = a => { const s = a.sort((x, y) => x - y);
      return s[Math.floor(s.length / 2)] ?? null; };
    return {
      opened: sessions.length,
      editRate: sessions.filter(s => s.edited).length / sessions.length,      // 打开→编辑
      commitRate: sessions.filter(s => s.committed).length / sessions.length,  // →提交
      medianTimeToEdit: med(sessions.filter(s => s.edited).map(s => s.edited - s.opened)),
      conflictRate: sessions.filter(s => s.conflicts).length / sessions.length,
    };
  }
  exportReplay({ redact = true } = {}) {                     // 回放包
    return JSON.stringify({
      snapshots: this.snapshots,
      events: this.events.map(e => redact ? { ...e, text: e.text ? '***' : undefined } : e),
    });
  }
}
```
