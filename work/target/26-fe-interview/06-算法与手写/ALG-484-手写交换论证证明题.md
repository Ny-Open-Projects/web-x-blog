## ALG-484：手写交换论证证明题：排队最小化等待（窗口叫号）

**答**：
- 题目：n 个客户各有服务时长 t[i]，单窗口排队，总等待时间 = Σ 前面所有人的时长。证明「按时长升序排队」最小化总等待（交换论证白板题）。
- 思路：交换论证——设最优解存在相邻逆序对（t[i] > t[i+1]），交换两者总等待变化 = t[i] - t[i+1] > 0，交换后更优，矛盾。故最优解必为升序。
- 评分点：相邻交换的标准论证格式；总等待的数学表达；SJF（短作业优先）结论。

```javascript
function shortestJobFirst(jobs) {                          // 最小化总等待
  const sorted = [...jobs].sort((a, b) => a - b);           // 升序排队
  let wait = 0, cur = 0;
  for (const t of sorted) {
    wait += cur;                                           // 累计前面人的时长
    cur += t;
  }
  return wait;
}
// 交换论证模板（白板写法）：
// 1. 设最优解 S 中存在相邻 i, i+1 使 t[i] > t[i+1]
// 2. 交换后总等待变化 Δ = t[i] - t[i+1] > 0 → 更优，与最优矛盾
// 3. 逆序冒泡至全序 → 最优解 = 升序排列
// 4. 结论：SJF 是最优（单窗口、无抢占）
```
