## HW-352：手写一个图形对齐分布工具：多选对齐与等距计算

**答**：
- 需求：实现 AlignTool：多选节点对齐（左/右/上/下/水平居中/垂直居中——以选择集包围盒为基准）；等距分布（水平/垂直：按位置排序后均匀间距）；变换应用到各节点（各自位移量）。
- 边界：两点分布无等距意义（跳过）；分布按中心而非边缘（可配）；对齐基准可选（画布/选择集）。
- 评分点：包围盒基准；等距排序计算；位移分发。

```javascript
class AlignTool {
  align(nodes, mode) {
    const b = selectionBounds(nodes);
    const dx = n => { const nb = bounds(n);
      return { left: b.x - nb.x, right: b.x + b.w - (nb.x + nb.w),
        cx: b.x + b.w / 2 - (nb.x + nb.w / 2) }[mode]; };
    const dy = n => { const nb = bounds(n);
      return { top: b.y - nb.y, bottom: b.y + b.h - (nb.y + nb.h),
        cy: b.y + b.h / 2 - (nb.y + nb.h / 2) }[mode]; };
    for (const n of nodes) {                                 // 位移分发
      if (['left', 'right', 'cx'].includes(mode)) n.x += dx(n);
      else n.y += dy(n);
      invalidate(n);
    }
  }
  distribute(nodes, axis) {                                  // 等距分布
    if (nodes.length < 3) return;                            // 两点无意义
    const key = axis === 'h' ? 'x' : 'y';
    const sorted = [...nodes].sort((a, b) => a[key] - b[key]);
    const first = bounds(sorted[0]), last = bounds(sorted.at(-1));
    const span = axis === 'h'
      ? (last.x + last.w) - first.x : (last.y + last.h) - first.y;
    const totalSize = sorted.reduce((s, n) => s + (axis === 'h' ? bounds(n).w : bounds(n).h), 0);
    const gap = (span - totalSize) / (sorted.length - 1);    // 均匀间距
    let acc = axis === 'h' ? first.x : first.y;
    for (const n of sorted) {
      const nb = bounds(n);
      if (axis === 'h') n.x = acc; else n.y = acc;
      acc += (axis === 'h' ? nb.w : nb.h) + gap;
      invalidate(n);
    }
  }
}
```
