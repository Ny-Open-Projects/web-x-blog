## ALG-511：手写反悔贪心进阶：K 次替换（配额重分配）

**答**：
- 题目：配额分配：每天有收益，可「反悔」——把之前某天的收益换成当天（每资源只能占一天），最多利用 k 次资源。反悔堆变体：按收益小顶堆，容量动态。
- 思路：同 ALG-483（任务调度反悔），扩展：替换时记录「换出项」审计。
- 评分点：反悔堆通用框架；换出审计；与普通堆贪心的区别。

```javascript
function quotaReallocation(days) {                         // days: [{day, profit, capacity}]
  const sorted = [...days].sort((a, b) => a.day - b.day);
  const heap = new MinHeap();                              // 已占收益
  let total = 0; const swaps = [];
  for (const d of sorted) {
    for (let i = 0; i < d.capacity; i++) {                  // 当天可放 capacity 个
      heap.push(d.profit); total += d.profit;
      if (heap.size > d.day) {                              // 超容量：反悔换出最小
        const removed = heap.pop();
        total -= removed;
        swaps.push({ day: d.day, removed });
      }
    }
  }
  return { total, swaps };
}
// 复用 ALG-483 的 MinHeap 类
// 反悔贪心框架：决策可逆化（入堆）+ 容量约束触发换出 + 换出审计
```
