## HW-211：手写一个富文本编辑器的数据模型：扁平 blocks 加行内 marks 表示文档

**答**：
- 需求：设计文档数据结构：blocks 数组（每个 block 有 id/type/文本与行内 marks 区间列表），支持读取纯文本、定位（blockId+offset）、行内样式区间重叠合并。
- 边界：marks 区间须归一化（相邻同样式合并、嵌套展开为并列区间）；offset 按码点计（emoji 不截断）。
- 评分点：扁平模型优于树模型的原因（位置计算简单）；marks 归一化；码点安全。

```javascript
function createDoc(blocks = []) {
  return {
    blocks,
    textOf(b) { return b.text; },
    insert(bid, offset, str, marks = []) {        // 码点安全偏移
      const b = blocks.find(x => x.id === bid);
      const i = [...b.text.slice(0, offset)].length;   // 按码点计
      b.text = [...b.text.slice(0, offset), ...str, ...b.text.slice(offset)].join('');
      b.marks.push(...marks.map(m => ({ ...m, start: offset, end: offset + [...str].length })));
      normalizeMarks(b);
    },
  };
}
function normalizeMarks(b) {                      // 区间归一化：合并相邻同样式
  b.marks.sort((a, x) => a.start - x.start);
  const out = [];
  for (const m of b.marks) {
    const p = out.at(-1);
    if (p && p.end === m.start && eqSet(p.type, m.type)) p.end = m.end;
    else out.push({ ...m });
  }
  b.marks = out;
}
const eqSet = (a, b) => JSON.stringify([...a].sort()) === JSON.stringify([...b].sort());
```
