## HW-225：手写一个查找替换引擎：正则支持、大小写与全词匹配、批量替换事务

**答**：
- 需求：实现 FindReplace：find(query, {regex, caseSensitive, wholeWord}) 返回所有匹配区间；replaceAll(replacement, opts) 单事务完成（一次 undo 回退全部）；正则替换支持 $1 捕获组引用。
- 边界：全词匹配用 \b 包裹；正则异常（无效模式）返回错误不崩溃；替换文本中的 $ 字符转义（非捕获引用时按字面处理）。
- 评分点：事务化批量；正则异常处理；$1 引用。

```javascript
class FindReplace {
  constructor(text) { this.text = text; }
  pattern(q, { regex, caseSensitive, wholeWord } = {}) {
    let p = regex ? q : q.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');   // 非正则转义
    if (wholeWord) p = '\\b' + p + '\\b';
    try { return new RegExp(p, caseSensitive ? 'g' : 'gi'); }
    catch (e) { throw new Error('invalid-pattern: ' + e.message); }
  }
  find(q, opts = {}) {
    const re = this.pattern(q, opts);
    const out = []; let m;
    while ((m = re.exec(this.text))) {
      out.push({ start: m.index, end: m.index + m[0].length });
      if (m[0] === '') re.lastIndex++;                         // 空匹配防死循环
    }
    return out;
  }
  replaceAll(q, rep, opts = {}) {
    const re = this.pattern(q, opts);
    const matches = this.find(q, opts);
    let t = this.text;
    for (let i = matches.length - 1; i >= 0; i--) {            // 倒序：位置不失效
      const m = re.exec(t);                                    // 取对应捕获组
      const real = opts.regex ? t.slice(matches[i].start, matches[i].end).replace(re, rep) : rep;
      t = t.slice(0, matches[i].start) + real + t.slice(matches[i].end);
    }
    const before = this.text;
    this.text = t;
    return { before, after: t, count: matches.length };        // 单事务（一次 undo 回退全部）
  }
}
```
