## HW-266：手写一个协作权限位图：字段级读写权限表达与判定

**答**：
- 需求：实现 FieldPerm：权限位图（每字段 2 位：read=1, write=2），按角色组合；can(role, field, action) 判定；批量判定 canBatch；提供 merge（角色叠加取并集）与 revoke；输出 UI 可用的字段可用性矩阵。
- 边界：位运算判定；未知字段默认无权限（fail-closed）；矩阵输出供前端批量渲染（隐藏/禁用/可编辑三态）。
- 评分点：位运算；fail-closed；三态矩阵。

```javascript
const READ = 1, WRITE = 2;
class FieldPerm {
  constructor() { this.defs = new Map(); }                  // role -> Map(field -> bits)
  grant(role, field, bits) {
    const m = this.defs.get(role) ?? new Map();
    m.set(field, (m.get(field) ?? 0) | bits);               // 叠加并集
    this.defs.set(role, m);
  }
  revoke(role, field, bits) {
    const m = this.defs.get(role);
    if (m) m.set(field, (m.get(field) ?? 0) & ~bits);
  }
  can(role, field, action) {
    const bits = this.defs.get(role)?.get(field) ?? 0;      // fail-closed：未知=0
    return (bits & (action === 'read' ? READ : WRITE)) !== 0;
  }
  canBatch(role, fields) {
    return Object.fromEntries(fields.map(f => [f, this.can(role, f, 'read')]));
  }
  matrix(fields) {                                          // 三态 UI 矩阵
    const out = {};
    for (const role of this.defs.keys()) {
      out[role] = {};
      for (const f of fields) {
        const r = this.can(role, f, 'read'), w = this.can(role, f, 'write');
        out[role][f] = w ? 'editable' : r ? 'readonly' : 'hidden';
      }
    }
    return out;
  }
}
```
