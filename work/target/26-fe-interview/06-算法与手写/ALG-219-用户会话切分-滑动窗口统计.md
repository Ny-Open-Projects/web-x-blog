## ALG-219：埋点分析：把事件流切分成会话（间隔 > 30 分钟算新会话），统计各会话深度（线性扫描）
**答**：埋点事件流（按时间升序），切分会话：相邻事件间隔 > 30 分钟即新会话。统计：会话总数、每会话事件数分布（深度直方图）、平均时长。

**思路**：线性扫描，比较相邻事件时间差；O(n) 单次遍历，流式友好（generator）。

```javascript
function* splitSessions(events, gapMs = 30 * 60000) {
  let cur = [];
  for (const e of events) {
    if (cur.length && e.ts - cur.at(-1).ts > gapMs) {   // 间隔超限：切会话
      yield cur; cur = [];
    }
    cur.push(e);
  }
  if (cur.length) yield cur;
}
function sessionStats(events) {
  const sessions = [...splitSessions(events)];
  const depths = sessions.map((s) => s.length);
  const hist = { '1-3': 0, '4-10': 0, '10+': 0 };
  for (const d of depths) hist[d <= 3 ? '1-3' : d <= 10 ? '4-10' : '10+']++;
  const durations = sessions.map((s) => s.at(-1).ts - s[0].ts);
  return {
    count: sessions.length,
    hist,
    avgDurationMin: +(durations.reduce((a, b) => a + b, 0) / sessions.length / 60000).toFixed(1),
  };
}
// 流式版本（generator）不占整块内存：事件流边到边切，适合实时管道
// 边界：事件乱序（迟到数据）→ 缓冲窗口重排或按会话 id 修正
```

**评分点**：
- 切分逻辑正确（相邻差 > gap 即断开），单遍 O(n)。
- generator 流式版本（内存友好、可接管道）是加分项。
- 统计输出结构完整（总数/直方图/平均时长）。
- 迟到/乱序事件的边界意识。
