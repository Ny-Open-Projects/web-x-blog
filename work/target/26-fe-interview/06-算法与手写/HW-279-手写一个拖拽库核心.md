## HW-279：手写一个拖拽库核心：drag 生命周期与 drop 目标命中测试

**答**：
- 需求：实现 DragCore：draggable 注册（元素 + 数据 + drop 规则）；生命周期事件 dragstart/drag/dragend；drop 目标注册（accept 校验：数据类型匹配）；命中测试（指针位置遍历 drop 目标的包围盒，取最内层）；auto-scroll（拖到视口边缘自动滚动容器）。
- 边界：命中测试用 elementFromPoint 或包围盒遍历（本题为包围盒，取面积最小命中者）；auto-scroll 节流（rAF）；accept 按类型白名单。
- 评分点：最内层命中；accept 校验；边缘自动滚动。

```javascript
class DragCore {
  constructor() { this.drags = new Map(); this.drops = new Map(); }
  draggable(el, { type, data, onDrop }) { this.drags.set(el, { type, data, onDrop }); }
  droppable(el, { accepts }) { this.drops.set(el, { accepts }); }
  start(e, el) {
    const d = this.drags.get(el);
    this.ctx = { ...d, source: el };
    addEventListener('pointermove', this.move = ev => this.onMove(ev));
    addEventListener('pointerup', () => this.end(), { once: true });
  }
  onMove(e) {
    this.target = this.hitTest(e.clientX, e.clientY);
    autoScroll(e.clientY);                                   // rAF 节流的边缘滚动
  }
  hitTest(x, y) {                                            // 最内层（面积最小）命中
    let best = null;
    for (const [el, rule] of this.drops) {
      const r = el.getBoundingClientRect();
      if (x >= r.left && x <= r.right && y >= r.top && y <= r.bottom
        && rule.accepts.includes(this.ctx.type)) {
        const area = r.width * r.height;
        if (!best || area < best.area) best = { el, rule, area };
      }
    }
    return best;
  }
  end() {
    removeEventListener('pointermove', this.move);
    if (this.target) this.ctx.onDrop?.(this.ctx.data, this.target.el);
    this.target = null;
  }
}
function autoScroll(y) { requestAnimationFrame(() => {
  if (y < 60) scrollBy(0, -12); else if (innerHeight - y < 60) scrollBy(0, 12); }); }
```
