## ALG-351：手写线段树（单点更新+区间求和）：直播间礼物实时累计统计

**答**：
- 题目：直播间每秒收到礼物，主播榜单需要任意时间段（如 20:00~20:30）的礼物总额实时查询，礼物随时到账。用线段树按秒建树（稀疏时段离散化）。
- 思路：线段树每个节点管一个时间区间之和；到账即单点加，查询区间和 O(log n)。对比前缀和数组：查询 O(1) 但单点改 O(n)，高频到账场景线段树双 O(log n) 更优。
- 评分点：build/update/query 三函数完整；区间拆分左右递归正确；能说清与前缀和的取舍。

```javascript
class SegTree {
  constructor(n) { this.n = n; this.t = new Array(4 * n).fill(0); }
  build(a, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.t[node] = a?.[l] ?? 0;
    const m = (l + r) >> 1;
    this.build(a, node * 2, l, m); this.build(a, node * 2 + 1, m + 1, r);
    this.t[node] = this.t[node * 2] + this.t[node * 2 + 1];
  }
  update(i, v, node = 1, l = 0, r = this.n - 1) {          // 单点加 v
    if (l === r) return this.t[node] += v;
    const m = (l + r) >> 1;
    i <= m ? this.update(i, v, node * 2, l, m) : this.update(i, v, node * 2 + 1, m + 1, r);
    this.t[node] = this.t[node * 2] + this.t[node * 2 + 1];   // 回溯合并
  }
  query(ql, qr, node = 1, l = 0, r = this.n - 1) {         // [ql, qr] 区间和
    if (qr < l || r < ql) return 0;                        // 不相交
    if (ql <= l && r <= qr) return this.t[node];           // 全包含
    const m = (l + r) >> 1;
    return this.query(ql, qr, node * 2, l, m) + this.query(ql, qr, node * 2 + 1, m + 1, r);
  }
}
// 场景：到账 gifts.update(second, amount)；查询 sum = gifts.query(start, end)
```
