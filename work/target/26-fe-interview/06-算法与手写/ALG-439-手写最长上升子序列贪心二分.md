## ALG-439：手写最长上升子序列（贪心+二分）：渐进加载序列

**答**：
- 题目：瀑布流图片按「加载完成时间」记录，要找「最长的按尺寸递增排列的子集」用于渐进策略（尺寸单调的批次加载）。LIS 贪心+二分 O(n log n)。
- 思路：tails[i] = 长度 i+1 的递增子序列的最小尾值；新元素二分找插入位（替换或追加）。
- 评分点：贪心正确性（尾值越小越容易延伸）；二分位置；与 DP O(n²) 对比；严格递增用 lowerBound、非递减用 upperBound。

```javascript
function lengthOfLIS(nums, { strict = true } = {}) {
  const tails = [];                                        // tails[i] = 长度 i+1 最小尾值
  for (const x of nums) {
    let lo = 0, hi = tails.length;
    while (lo < hi) {                                      // 二分找插入位
      const m = (lo + hi) >> 1;
      const cmp = strict ? tails[m] < x : tails[m] <= x;
      cmp ? lo = m + 1 : hi = m;
    }
    tails[lo] = x;                                         // 替换或追加
  }
  return tails.length;                                     // O(n log n)
}
// 还原序列本身：记录每个元素所在长度，从后往前回填
// 场景：加载批次 = 按时间排序的图片中取尺寸递增的最长子序列
```
