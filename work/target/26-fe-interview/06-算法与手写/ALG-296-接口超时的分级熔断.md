## ALG-296：接口熔断器：closed/open/half-open 状态机（滑动窗口失败率 + 半开探测恢复）？
**答**：熔断器三态：closed（正常，滑动窗口统计失败率）→ open（失败率超阈值，快速失败 N 秒）→ half-open（放少量探测请求，成功则 closed）。防止"持续打已挂服务"（客户端侧保护 + 快速失败体验）。

**思路**：滑动窗口（最近 20 次）→ 失败率 > 50% → open（60s）→ 半开放 3 个探测 → 全成功 closed / 有失败重回 open。

```javascript
class CircuitBreaker {
  #window = []; #state = 'closed'; #openedAt = 0; #probes = 0;
  constructor({ windowSize = 20, threshold = 0.5, openMs = 60000, probeCount = 3 } = {}) {
    Object.assign(this, { windowSize, threshold, openMs, probeCount });
  }
  async exec(fn) {
    if (this.#state === 'open') {
      if (Date.now() - this.#openedAt < this.openMs) throw new Error('circuit-open');   // 快速失败
      this.#state = 'half-open'; this.#probes = 0;        // 冷却结束：半开探测
    }
    if (this.#state === 'half-open' && this.#probes >= this.probeCount) {
      throw new Error('circuit-open');                    // 半开期：探测名额已满，排队等结果
    }
    this.#probes++;
    try {
      const result = await fn();
      this.#record(true);
      if (this.#state === 'half-open') { this.#state = 'closed'; this.#window = []; }   // 探测成功：闭合
      return result;
    } catch (e) {
      this.#record(false);
      if (this.#state === 'half-open') { this.#trip(); }  // 探测失败：重回 open
      else if (this.#failureRate() > this.threshold) this.#trip();
      throw e;
    }
  }
  #record(ok) { this.#window.push(ok); if (this.#window.length > this.windowSize) this.#window.shift(); }
  #failureRate() { return this.#window.length >= 5
    ? this.#window.filter((x) => !x).length / this.#window.length : 0; }
  #trip() { this.#state = 'open'; this.#openedAt = Date.now(); this.#window = []; }
}
// 状态机闭环：closed(统计) → open(快速失败) → half-open(限量探测) → closed/open
// 快速失败的体验价值：open 期 0ms 返回（不用户等 15s 超时）→ UI 直接走降级
// 半开限量探测（3 个）：防止恢复瞬间全量流量打回（二次压垮）—— 探测成功才放量
```

**评分点**：
- 三态状态机闭环（closed→open→half-open）——本题核心。
- 滑动窗口失败率 + 最小样本（<5 不触发防抖动）。
- 半开限量探测（防恢复瞬间二次压垮）。
- 快速失败的体验价值（0ms 降级 vs 等 15s 超时）。
