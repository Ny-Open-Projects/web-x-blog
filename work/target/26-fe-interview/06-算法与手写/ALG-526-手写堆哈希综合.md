## ALG-526：手写堆+哈希综合：任务去重调度

**答**：
- 题目：任务流含重复任务（同 key 只需执行最新版），按优先级调度去重后的任务。堆 + Map（key → 最新条目），惰性删除（出堆时校验版本）。
- 思路：堆中存旧条目，出堆时比对 Map 中版本号——过期则丢弃继续出堆。
- 评分点：惰性删除模式；版本校验；堆外 Map 为准源。

```javascript
class DedupScheduler {
  constructor() { this.heap = new MinHeap(); this.latest = new Map(); }   // key -> {ver, task}
  submit(key, priority, task) {
    const ver = (this.latest.get(key)?.ver ?? 0) + 1;
    this.latest.set(key, { ver, priority, task });
    this.heap.push({ key, ver, priority });                // 旧条目留堆内（惰性删）
  }
  pop() {
    while (this.heap.size) {
      const item = this.heap.pop();
      const cur = this.latest.get(item.key);
      if (cur && cur.ver === item.ver) {                   // 版本匹配：有效
        this.latest.delete(item.key);
        return cur.task;
      }                                                    // 过期：跳过继续出堆
    }
    return null;
  }
}
```
