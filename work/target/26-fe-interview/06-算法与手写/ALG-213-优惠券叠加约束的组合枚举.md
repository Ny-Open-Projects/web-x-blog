## ALG-213：结算页：多张优惠券可叠加但有互斥约束，求最大抵扣组合（回溯剪枝）
**答**：购物车有券 `[{id, amount, excludes: ['b']}]`，券之间有互斥（用了 a 不能用 b），求最大总抵扣。带互斥约束的子集最大化 = 回溯 + 剪枝（当前和 + 剩余全加 <= 已知最优则剪）。

**思路**：按金额降序排列提高剪枝效率；回溯每个"选/不选"；用互斥集合排除冲突券。n 通常 < 15，回溯可行。

```javascript
function bestCouponCombo(coupons) {
  const sorted = [...coupons].sort((a, b) => b.amount - a.amount);   // 大券先试，剪枝更早
  const suffix = sorted.map((_, i) => sorted.slice(i).reduce((s, c) => s + c.amount, 0)); // 后缀和
  let best = 0, bestIds = [];

  function dfs(i, sum, used, banned) {
    if (sum + suffix[i] <= best) return;             // 剪枝：全拿也超不过当前最优
    if (i >= sorted.length) { best = sum; bestIds = [...used]; return; }
    const c = sorted[i];
    if (!banned.has(c.id)) {                          // 选：加入互斥
      dfs(i + 1, sum + c.amount, [...used, c.id], new Set([...banned, ...c.excludes]));
    }
    dfs(i + 1, sum, used, banned);                    // 不选
  }
  dfs(0, 0, [], new Set());
  return { total: best, ids: bestIds };
}
bestCouponCombo([
  { id: 'a', amount: 30, excludes: ['b'] },
  { id: 'b', amount: 25, excludes: ['a'] },
  { id: 'c', amount: 10, excludes: [] },
]); // => { total: 40, ids: ['a','c'] }（a 与 b 互斥，选 a+c=40 > b+c=35）
// 复杂度 O(2^n)，n≤15 可行；n 大时转最大权独立集（NP-hard，工程上贪心+局部搜索）
```

**评分点**：
- 回溯结构正确（选/不选两分支），互斥约束传递（banned 集合）。
- 双重剪枝：后缀和上界 + 金额降序排列（提高剪枝效率）。
- 复杂度 O(2^n) 且能说清适用规模与 n 大时的替代思路。
- 场景对应：互斥券组合最大化。
