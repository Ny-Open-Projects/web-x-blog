## HW-395：手写一个本地加密草稿库：WebCrypto 加密存储

**答**：
- 需求：实现 EncryptedDrafts：密钥派生（PBKDF2 从口令派生 AES-GCM 密钥，盐随机）；加密存储（AES-GCM 加密草稿 JSON，IV 随机，密文+IV 存 IndexedDB）；解密读取（口令错误 → 解密失败返回 null）；换口令（重新派生密钥重加密全部草稿）。
- 边界：盐与 IV 每次随机（不重用）；口令强度校验（长度+复杂度提示）；解密失败区分（认证失败=口令错）；自动锁定（闲置 5 分钟清内存密钥）。
- 评分点：PBKDF2 参数；IV 唯一性；自动锁定。

```javascript
class EncryptedDrafts {
  constructor({ idleMs = 300000 } = {}) {
    this.idleTimer = setTimeout(() => this.lock(), idleMs);  // 自动锁定
  }
  async deriveKey(password, salt) {                          // PBKDF2 派生
    const base = await crypto.subtle.importKey('raw',
      new TextEncoder().encode(password), 'PBKDF2', false, ['deriveKey']);
    return crypto.subtle.deriveKey(
      { name: 'PBKDF2', salt, iterations: 310000, hash: 'SHA-256' },   // OWASP 建议
      base, { name: 'AES-GCM', length: 256 }, false, ['encrypt', 'decrypt']);
  }
  async init(password) {
    this.salt = crypto.getRandomValues(new Uint8Array(16));  // 盐随机
    this.key = await this.deriveKey(password, this.salt);
  }
  async save(id, doc) {
    const iv = crypto.getRandomValues(new Uint8Array(12));   // IV 每次随机
    const ct = await crypto.subtle.encrypt({ name: 'AES-GCM', iv },
      this.key, new TextEncoder().encode(JSON.stringify(doc)));
    await idbPut('drafts', { id, salt: b64(this.salt), iv: b64(iv), ct: b64(new Uint8Array(ct)), ts: Date.now() });
  }
  async load(id, password) {
    const rec = await idbGet('drafts', id);
    if (!rec) return null;
    try {
      const key = await this.deriveKey(password, fromB64(rec.salt));
      const pt = await crypto.subtle.decrypt({ name: 'AES-GCM', iv: fromB64(rec.iv) },
        key, fromB64(rec.ct).buffer);
      return JSON.parse(new TextDecoder().decode(pt));
    } catch { return null; }                                 // 认证失败=口令错
  }
  async changePassword(oldPw, newPw) {                       // 换口令重加密
    const all = await idbAll('drafts');
    for (const rec of all) {
      const doc = await this.load(rec.id, oldPw);
      if (doc) { this.salt = crypto.getRandomValues(new Uint8Array(16));
        this.key = await this.deriveKey(newPw, this.salt);
        await this.save(rec.id, doc); }
    }
  }
  lock() { this.key = null; }                                // 清内存密钥
}
const b64 = a => btoa(String.fromCharCode(...a));
const fromB64 = s => Uint8Array.from(atob(s), c => c.charCodeAt(0));
```
