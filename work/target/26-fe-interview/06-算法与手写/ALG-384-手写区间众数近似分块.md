## ALG-384：手写区间众数近似（分块）：投票区间统计

**答**：
- 题目：投票记录（候选人 ID），查「区间内得票最多的候选人」。众数无区间可加性（不能合并），标准解法是分块：预处理块间众数 + 暴力扫边界候选。
- 思路：① 分块（块长 √n）；② 预处理 f[i][j] = 第 i 到 j 块的众数（O(n√n)）；③ 查询：整块部分直接查表，边界散块候选逐一用「出现次数前缀数组」统计取最大。
- 评分点：众数不满足区间可加性（不能用线段树合并）；分块预处理；散块候选扫描。

```javascript
class ModeBlock {
  constructor(a) {
    this.a = a; this.n = a.length;
    this.blockSize = Math.ceil(Math.sqrt(this.n));
    this.blockCount = Math.ceil(this.n / this.blockSize);
    this.prefix = new Map();                                // 值 → 前缀出现次数
    this.build();
  }
  build() {
    const per = new Map();                                  // 值 → 各前缀计数
    const cnt = new Map();
    const arr = [];
    for (let i = 0; i < this.n; i++) {
      cnt.set(this.a[i], (cnt.get(this.a[i]) ?? 0) + 1);
      arr.push(new Map(cnt));
    }
    this.preAt = arr;
    // f[b1][b2]: 块 b1..b2 的众数（O(n√n) 预处理）
    this.f = Array.from({ length: this.blockCount }, () => new Array(this.blockCount));
    for (let b1 = 0; b1 < this.blockCount; b1++) {
      const cnt2 = new Map();
      for (let b2 = b1; b2 < this.blockCount; b2++) {
        for (let i = b2 * this.blockSize; i < Math.min((b2 + 1) * this.blockSize, this.n); i++)
          cnt2.set(this.a[i], (cnt2.get(this.a[i]) ?? 0) + 1);
        let best = null, bn = 0;
        for (const [v, c] of cnt2) if (c > bn) { best = v; bn = c; }
        this.f[b1][b2] = best;
      }
    }
  }
  query(l, r) {                                            // 候选：整块众数 + 散块值
    const b1 = Math.floor(l / this.blockSize), b2 = Math.floor(r / this.blockSize);
    const cands = new Set([this.f[b1][b2]]);
    for (let i = l; i < Math.min((b1 + 1) * this.blockSize, r + 1); i++) cands.add(this.a[i]);   // 左散块
    for (let i = b2 * this.blockSize; i <= r; i++) cands.add(this.a[i]);   // 右散块
    let best = null, bn = 0;
    for (const v of cands) {
      const cnt = this.cntIn(v, l, r);
      if (cnt > bn) { best = v; bn = cnt; }
    }
    return { value: best, count: bn };
  }
  cntIn(v, l, r) { return (this.preAt[r].get(v) ?? 0) - (this.preAt[l - 1]?.get(v) ?? 0); }
}
```
