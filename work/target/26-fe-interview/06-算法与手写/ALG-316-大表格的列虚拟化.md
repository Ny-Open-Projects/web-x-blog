**场景**：报表 500 列（行级虚拟化 HW-068 之外）列也虚拟化：列宽不均（数字列 120px/文本列 240px）——前缀和二分定位可视列（ALG-222 横向模式），与行级虚拟化正交叠加（行列双虚拟，渲染矩阵 = 可视行 × 可视列）。

**思路**：列前缀和 + scrollLeft 二分 → 可视列区间 [startCol, endCol]（左右缓冲）→ 与行区间叉乘 → 只渲染矩阵交集。

```javascript
class ColumnVirtualizer {
  #prefix = [0];
  constructor(widths) {
    widths.reduce((acc, w, i) => { this.#prefix.push(acc + w); return acc + w; }, 0);
    this.total = this.#prefix.at(-1);
  }
  visibleRange(scrollLeft, clientWidth, buffer = 2) {
    let lo = 0, hi = this.#prefix.length - 1;             // 二分定位列
    while (lo < hi) { const mid = (lo + hi) >> 1;
      if (this.#prefix[mid] < scrollLeft) lo = mid + 1; else hi = mid; }
    const start = Math.max(0, lo - buffer);
    let end = lo, acc = 0;
    while (end < this.#prefix.length - 1 && acc < clientWidth) { acc += this.#prefix[end + 1] - this.#prefix[end]; end++; }
    return { start, end: Math.min(this.#prefix.length - 1, end + buffer) };
  }
}
// 行列双虚拟：可视矩阵 = 行区间（HW-068）× 列区间（本类）—— 500×10000 表格只渲染 ~40×40 = 1600 单元格
// 列宽不均：前缀和二分 O(logC)（等宽可 O(1) 除法——不均则必须前缀和）
// 左右缓冲（buffer 2 列）：横向滚动不闪白（HW-067 同款）
// 定位：绝对定位 left = prefix[col]（列坐标）—— 与行的 translateY 正交组合
```

**评分点**：
- 列前缀和 + 二分定位（列宽不均场景）——本题核心。
- 行列双虚拟正交（渲染矩阵叉乘）的完整叙事。
- 等宽 O(1) vs 不均 O(logC) 的退化说明。
- 缓冲列防闪白。
