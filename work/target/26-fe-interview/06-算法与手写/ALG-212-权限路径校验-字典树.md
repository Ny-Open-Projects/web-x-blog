## ALG-212：路由权限：海量权限路径 `a/b/c` 的前缀匹配查询（字典树 Trie，批量查询 O(L)）
**答**：权限系统存了 5000 条权限路径（`/admin/user/*`、`/api/goods/:id/edit`），每次路由跳转要判断"当前路径是否被授权"。逐条 includes 匹配 O(n·L) 慢，用字典树一次构建、每查 O(L)。

**思路**：按 `/` 分段建树，节点含 isEnd 与通配 `*` 分支；查询沿段走，遇 `*` 段匹配任意后续。

```javascript
class PermissionTrie {
  constructor(paths) { this.root = {}; for (const p of paths) this.insert(p); }
  insert(path) {
    let node = this.root;
    for (const seg of path.split('/').filter(Boolean)) {
      node = node[seg] ??= {};
    }
    node.__end = true;
  }
  match(path) {                                       // 支持 '*' 通配一段
    const segs = path.split('/').filter(Boolean);
    const dfs = (node, i) => {
      if (node.__end && i >= segs.length) return true;    // 精确到末段
      if (i >= segs.length) return !!node.__end;
      const seg = segs[i];
      if (node[seg] && dfs(node[seg], i + 1)) return true;
      return node['*'] ? dfs(node['*'], i + 1) : false;   // 通配符分支
    };
    return dfs(this.root, 0);
  }
}
const trie = new PermissionTrie(['/admin', '/admin/*', '/goods/:id/edit']);
trie.match('/admin/user/list');   // true（/admin/* 命中）
trie.match('/goods/42/edit');     // true
trie.match('/goods/42');          // false
// 构建一次 O(总路径长)，查询 O(路径段数)；5000 条权限路径逐条比对需要 5000 次，Trie 只需段数次
// :id 参数段可把 ':id' 也当字面段插入并查询时做参数归一（数字段 → ':id'）后匹配
```

**评分点**：
- Trie 结构与 `__end` 标记正确；通配 `*` 分支的 DFS 匹配。
- 参数段归一（数字段 → `:id`）的意识。
- 复杂度对比：Trie 查询 O(段数) vs 逐条匹配 O(路径数 × 段数)。
- 构建一次多次查询的场景适配（权限表启动时载入）。
