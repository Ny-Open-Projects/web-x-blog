## ALG-438：手写最长公共子序列：diff 算法核心

**答**：
- 题目：版本 diff（HW-233）的行级 LCS——两版本行序列的最长公共子序列。DP O(n×m)，大文件用 Myers O(ND) 或先哈希行去重。
- 思路：dp[i][j] = LCS 长度；相等取左上 +1，否则 max(上/左)；回溯构造 diff 序列。
- 评分点：转移方程；回溯构造；大文本的工程优化（行哈希压缩 + Myers 提及）。

```javascript
function lcsDiff(a, b) {
  const n = a.length, m = b.length;
  const dp = Array.from({ length: n + 1 }, () => new Uint16Array(m + 1));
  for (let i = 1; i <= n; i++)
    for (let j = 1; j <= m; j++)
      dp[i][j] = a[i - 1] === b[j - 1] ? dp[i - 1][j - 1] + 1
        : Math.max(dp[i - 1][j], dp[i][j - 1]);
  const ops = [];                                          // 回溯构造
  let i = n, j = m;
  while (i > 0 && j > 0) {
    if (a[i - 1] === b[j - 1]) { ops.push({ type: 'same', line: a[i - 1] }); i--; j--; }
    else if (dp[i - 1][j] >= dp[i][j - 1]) { ops.push({ type: 'del', line: a[i - 1] }); i--; }
    else { ops.push({ type: 'add', line: b[j - 1] }); j--; }
  }
  while (i > 0) ops.push({ type: 'del', line: a[--i] });
  while (j > 0) ops.push({ type: 'add', line: b[--j] });
  return ops.reverse();
}
// 大文本优化：先按行哈希把相同行折叠成唯一 token（缩坐标），再跑 LCS
// 更大文本：Myers O(ND)（D = 编辑距离，文本相似时远小于 n×m）
```
