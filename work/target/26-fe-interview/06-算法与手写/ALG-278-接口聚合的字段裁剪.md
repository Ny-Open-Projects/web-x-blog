**场景**：列表页只要 id/name/thumbnail，详情页要全量——BFF 按视图投影（字段白名单）裁剪：带宽省 60%+，且敏感字段（成本价/供应商）不出现在列表响应（安全隔离）。

**思路**：投影函数（白名单递归）+ 嵌套深度控制 + 敏感字段黑名单双保险（白名单漏了黑名单兜底）。

```javascript
function project(data, whitelist, { blacklist = ['costPrice', 'supplierId'], depth = 2 } = {}) {
  if (depth <= 0) return null;                            // 深度控制：列表嵌套不展开
  if (Array.isArray(data)) return data.map((x) => project(x, whitelist, { blacklist, depth: depth - 1 }));
  if (data === null || typeof data !== 'object') return data;
  const out = {};
  for (const [k, v] of Object.entries(data)) {
    if (blacklist.includes(k)) continue;                  // 黑名单兜底（白名单配漏的敏感字段）
    if (whitelist && !whitelist.includes(k) && typeof v === 'object') continue;   // 非白名单对象丢弃
    out[k] = typeof v === 'object' && v !== null
      ? project(v, whitelist, { blacklist, depth: depth - 1 })
      : v;                                                // 标量字段保留（id/name 等白名单或标量）
  }
  return out;
}
// project(goodsList, ['id', 'name', 'thumbnail', 'price'])
// => 列表视图：带宽 -60%，成本价/供应商绝不出现
// 投影的价值双面：性能（带宽/解析）+ 安全（字段级数据隔离——列表响应不含详情专属敏感字段）
// 白名单 + 黑名单双保险：白名单是业务声明，黑名单是安全底线（PER-411 脱敏的同源思想）
```

**评分点**：
- 白名单投影 + 黑名单兜底双保险——本题核心。
- 深度控制（列表不展开嵌套）。
- 投影的双面价值（带宽 + 字段级安全隔离）。
- 递归实现与标量保留语义。
