## ALG-481：手写区间调度（无重叠区间）：会议排期

**答**：
- 题目：一批会议（start, end），求最多能安排多少场不冲突的会议。经典贪心：按结束时间排序，每次选结束最早的。
- 思路：按 end 升序排序；扫描时 end <= 下一个 start 则选入。贪心正确性（交换论证）：最优解中最早结束的会议可换成结束最早的而保持可行。
- 评分点：按结束时间而非开始时间排序；交换论证表述；边界（end 相等视为可衔接）。

```javascript
function maxMeetings(intervals) {
  const sorted = [...intervals].sort((a, b) => a.end - b.end);   // 按结束时间排序
  let count = 0, lastEnd = -Infinity;
  for (const m of sorted) {
    if (m.start >= lastEnd) {                              // 可衔接（end==start 允许）
      count++;
      lastEnd = m.end;
    }
  }
  return count;
}
// 反例警示：按开始时间排序会错——[1,100],[2,3],[4,5] 按开始排选 [1,100] 只得 1 场
// 交换论证：设最优解第一个会议为 M，若有会议 end 更早，替换 M 后后续全部仍可行
```
