## ALG-512：手写贪心+图：最小生成树思想（Kruskal）：机房布线

**答**：
- 题目：机房节点间布线成本矩阵，求连通所有节点的最小总成本（MST）。Kruskal：边排序 + 并查集。
- 思路：边按权排序；逐边加入（不成环——并查集判）；n-1 条边停止。
- 评分点：并查集判环；边排序贪心；Prim 对比（稠密图用 Prim）。

```javascript
function kruskal(n, edges) {                               // edges: [{u, v, w}]
  const sorted = [...edges].sort((a, b) => a.w - b.w);
  const parent = Array.from({ length: n }, (_, i) => i);
  const find = (x) => parent[x] === x ? x : parent[x] = find(parent[x]);   // 路径压缩
  const mst = [];
  let total = 0;
  for (const e of sorted) {
    const ru = find(e.u), rv = find(e.v);
    if (ru !== rv) {                                       // 不成环
      parent[ru] = rv;
      mst.push(e); total += e.w;
      if (mst.length === n - 1) break;                     // 完成
    }
  }
  return { mst, total, connected: mst.length === n - 1 };
}
// Prim 对比：稠密图（边多）Prim O(V²) 更好；Kruskal O(E log E) 稀疏图友好
```
