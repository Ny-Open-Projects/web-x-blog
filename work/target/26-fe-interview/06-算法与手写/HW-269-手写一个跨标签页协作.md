## HW-269：手写一个跨标签页协作：BroadcastChannel 本地多开同步

**答**：
- 需求：实现 TabSync：同源多标签页通过 BroadcastChannel 同步文档（每 tab 本地编辑广播 op，其他 tab apply）；leader 选举（最老 tab 为 leader，负责与服务端同步，其他 tab 只本地应用）；leader 失联（心跳超时）重新选举。
- 边界：选举按启动时间戳最小者；leader 切换时的未确认 op 移交；channel 消息与网络消息的双源去重。
- 评分点：leader 选举与移交；双源去重；心跳重选。

```javascript
class TabSync {
  constructor() {
    this.chan = new BroadcastChannel('doc-sync');
    this.bornAt = Date.now() + Math.random();                // 随机扰动防同 ms 平局
    this.tabId = 'tab-' + Math.random().toString(36).slice(2);
    this.leader = null; this.leaderSeen = 0;
    this.chan.onmessage = e => this.receive(e.data);
    setInterval(() => this.hello(), 3000);                   // 心跳+选举
    this.hello();
  }
  hello() { this.chan.postMessage({ type: 'hello', tabId: this.tabId, bornAt: this.bornAt }); this.elect(); }
  receive(m) {
    if (m.tabId === this.tabId) return;
    if (m.type === 'hello') {
      if (!this.leader || m.bornAt < this.leader.bornAt) {   // 最老者为 leader
        const wasLeader = this.leader?.tabId === this.tabId;
        this.leader = m;
        if (wasLeader) this.handover(m);                     // leader 移交未确认 op
      }
      this.leaderSeen = Date.now();
    }
    if (m.type === 'op') this.applyRemote(m.op);             // 本地直接应用（免网络）
  }
  elect() {                                                  // leader 失联重选
    if (this.leader && Date.now() - this.leaderSeen > 9000) this.leader = null;
    if (!this.leader && this.isOldest()) this.leader = { tabId: this.tabId, bornAt: this.bornAt };
  }
  isOldest() { return this.leader?.tabId === this.tabId; }
  localOp(op) {
    applyLocal(op);
    this.chan.postMessage({ type: 'op', tabId: this.tabId, op });
    if (this.isOldest()) serverSubmit(op);                   // 仅 leader 走网络
  }
  handover(newLeader) { newLeader && this.chan.postMessage({ type: 'handover', pending: this.pendingOps }); }
}
```
