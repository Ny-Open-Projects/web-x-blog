## ALG-380：手写线段树测试生成器：暴力对拍

**答**：
- 题目：为线段树实现对拍工具——随机生成操作序列（update/query），线段树结果与暴力 O(n) 结果逐条比对，输出首个不一致的操作序列（可复现 seed）。
- 思路：seedable 随机；每步操作后双实现结果比对；失败时 dump 操作日志。这是上线前自测的标配。
- 评分点：可复现随机 seed；双实现对拍；失败信息含完整操作序列。

```javascript
function segTreeStress({ rounds = 1000, n = 100, seed = 42 } = {}) {
  const rng = mulberry32(seed);
  const arr = Array.from({ length: n }, () => Math.floor(rng() * 100));
  const tree = new SegTree(n); tree.build(arr);
  for (let r = 0; r < rounds; r++) {
    if (rng() < 0.5) {                                     // update
      const i = Math.floor(rng() * n), v = Math.floor(rng() * 100);
      arr[i] = v;
      tree.setSingle(i, v);
    } else {                                               // query 对拍
      const l = Math.floor(rng() * n), rr = Math.min(n - 1, l + Math.floor(rng() * 20));
      const fast = tree.query(l, rr);
      const brute = arr.slice(l, rr + 1).reduce((s, x) => s + x, 0);
      if (fast !== brute)
        return { pass: false, seed, round: r, op: { type: 'query', l, r: rr },
          fast, brute };                                   // 失败可复现
    }
  }
  return { pass: true, seed, rounds };
}
function mulberry32(seed) { return () => { seed |= 0; seed = seed + 0x6D2B79F5 | 0;
  let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
  t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t; return ((t ^ t >>> 14) >>> 0) / 4294967296; }; }
```
