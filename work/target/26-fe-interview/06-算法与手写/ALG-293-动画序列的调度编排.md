## ALG-293：入场动画编排：多元素序列动画（delay 阶梯 + 并行组 + 完成回调）的调度器？
**答**：页面入场编排：标题先入（0ms）→ 副标题（100ms）→ 三卡片并行（200ms 起、每个 +80ms 阶梯）→ 按钮最后（依赖卡片完成）。声明式时间轴 + WAAPI 执行（合成器路径）。

**思路**：编排 DSL（sequence/parallel/stagger）→ 展开为绝对时间轴 → WAAPI 带 delay 执行 → Promise.all 等待完成。

```javascript
function orchestrate(spec) {
  // spec: { sequence: [
  //   { el, frames, duration },
  //   { parallel: [
  //     { el: cards[0], frames, duration }, { el: cards[1], frames, duration, delay: 80 },
  //   ] },
  //   { el: btn, frames, duration },
  // ] }
  let offset = 0;
  const promises = [];
  function walk(node, base) {
    if (node.parallel) return Promise.all(node.parallel.map((c) => walk(c, base)));   // 并行组
    const delay = base + (node.delay ?? offset);
    const anim = node.el.animate(node.frames, { duration: node.duration, delay, fill: 'both', easing: 'ease-out' });
    promises.push(anim.finished);
    return anim.finished;
  }
  for (const node of spec.sequence) {                     // sequence：顺序累加 offset
    walk(node, offset);
    offset += (node.duration ?? 300) + (node.delay ?? 0);
  }
  return Promise.all(promises);
}
// stagger 语义：parallel 内各卡片 delay 递增（80ms 阶梯）—— 瀑布入场
// WAAPI：delay/fill both 由合成器调度（主线程零逐帧 JS，PER-347）
// reduced-motion：整体跳过直接落终态（HW-157 纪律）
```

**评分点**：
- 声明式编排 DSL（sequence/parallel/stagger）展开为时间轴——本题核心。
- WAAPI delay 执行（合成器路径）。
- Promise 编排（完成回调供后续逻辑）。
- reduced-motion 整体降级。
