## ALG-361：手写线段树合并：多用户标签集合合并统计

**答**：
- 题目：每个用户有一个标签计数线段树（标签 ID → 出现次数），要合并两个用户的树（对应位置相加），并查询合并后某标签区间的总次数。
- 思路：两棵树的合并——递归双指针：某方为空返回另一方（引用共享）；都有则合并子节点后回溯更新。合并复杂度 O(两树重叠节点数)。
- 评分点：空树直接返回（共享引用省空间）；递归合并子节点；动态开点配合使用。

```javascript
class MergeableSegTree {
  static merge(a, b) {                                     // 两棵树合并
    if (!a) return b;
    if (!b) return a;                                      // 空树返回另一方（引用共享）
    const node = { sum: a.sum + b.sum, l: null, r: null };
    node.l = MergeableSegTree.merge(a.l, b.l);
    node.r = MergeableSegTree.merge(a.r, b.r);
    return node;
  }
  static update(node, pos, v, l = 1, r = 1e6) {
    node ??= { sum: 0, l: null, r: null };
    if (l === r) return void (node.sum += v);
    const m = (l + r) >> 1;
    if (pos <= m) node.l = MergeableSegTree.update(node.l, pos, v, l, m);
    else node.r = MergeableSegTree.update(node.r, pos, v, m + 1, r);
    node.sum = (node.l?.sum ?? 0) + (node.r?.sum ?? 0);
    return node;
  }
  static query(node, ql, qr, l = 1, r = 1e6) {
    if (!node || qr < l || r < ql) return 0;
    if (ql <= l && r <= qr) return node.sum;
    const m = (l + r) >> 1;
    return MergeableSegTree.query(node.l, ql, qr, l, m)
      + MergeableSegTree.query(node.r, ql, qr, m + 1, r);
  }
}
// userTree = merge(userATree, userBTree)；查询合并后标签 [100, 200] 的总次数
```
