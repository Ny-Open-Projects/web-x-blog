## HW-113：手写可控并发的图片预加载池——进度回调、失败跳过与首帧优先
**答**：画廊/电商详情的图片预加载池：并发上限（带宽保护）、优先级（首帧大图先加载）、进度回调（已加载/总数）、失败跳过不阻塞后续、结果缓存（重复调用命中 Promise）。

```javascript
class ImagePreloader {
  constructor(concurrency = 4) {
    this.concurrency = concurrency;
    this.cache = new Map();                           // url -> Promise
  }
  preload(urls, { onProgress, priority = () => 0 } = {}) {
    const sorted = [...urls].sort((a, b) => priority(b) - priority(a));   // 高优先级先入队
    let done = 0, failed = 0;
    return new Promise((resolve) => {
      let next = 0, active = 0;
      const drain = () => {
        while (active < this.concurrency && next < sorted.length) {
          const url = sorted[next++];
          active++;
          this.#load(url).then(() => done++).catch(() => failed++)
            .finally(() => {
              active--;
              onProgress?.({ done, failed, total: sorted.length });
              if (done + failed === sorted.length) resolve({ done, failed });
              else drain();
            });
        }
      };
      drain();
    });
  }
  #load(url) {
    if (this.cache.has(url)) return this.cache.get(url);  // 重复 url：共享 Promise
    const p = new Promise((resolve, reject) => {
      const img = new Image();
      img.onload = () => resolve(url);
      img.onerror = reject;                              // 失败跳过，不阻塞整体
      img.src = url;
    });
    this.cache.set(url, p);
    return p;
  }
}
// 用法：详情页首帧大图优先
const pl = new ImagePreloader(4);
pl.preload(imageUrls, {
  priority: (url) => (url === heroUrl ? 10 : 0),
  onProgress: ({ done, total }) => progressBar.style.width = (done / total * 100) + '%',
}).then(({ done, failed }) => toast(`预加载完成 ${done} 张，失败 ${failed} 张`));
```

**评分点**：
- 并发池 drain 循环正确（active < concurrency 且队列非空时补充）。
- 优先级排序（首帧高优先入队）；进度回调含失败计数。
- 失败跳过不阻塞整体（catch 计数继续）；结果缓存 Map 共享 Promise。
- resolve 条件 = done + failed === total（失败也算完成）。
