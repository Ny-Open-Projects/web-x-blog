## ALG-443：手写大数加法与乘法：金额精度处理

**答**：
- 题目：账单聚合金额超 Number.MAX_SAFE_INTEGER（分单位聚合 9 千万笔），字符串大数运算保证精度。
- 思路：加法：对齐竖式逐位加进位；乘法：逐位乘累加（O(n×m)），或 Karatsuba（面试提及）。JS 里 BigInt 覆盖多数场景，但「字符串输入直接算」仍是面试高频。
- 评分点：竖式进位；BigInt 的边界（不支持小数、序列化 JSON 需字符串）；避免浮点累加误差的意识。

```javascript
function bigAdd(a, b) {                                    // 字符串大数加法
  let i = a.length - 1, j = b.length - 1, carry = 0;
  const out = [];
  while (i >= 0 || j >= 0 || carry) {
    const sum = (i >= 0 ? +a[i--] : 0) + (j >= 0 ? +b[j--] : 0) + carry;
    out.push(sum % 10); carry = Math.floor(sum / 10);
  }
  return out.reverse().join('');
}
function bigMul(a, b) {                                    // 大数乘法
  const res = new Array(a.length + b.length).fill(0);
  for (let i = a.length - 1; i >= 0; i--)
    for (let j = b.length - 1; j >= 0; j--) {
      const mul = +a[i] * +b[j] + res[i + j + 1];
      res[i + j + 1] = mul % 10;
      res[i + j] += Math.floor(mul / 10);                  // 进位累加
    }
  let s = res.join('').replace(/^0+(?!$)/, '');
  return s;
}
// 场景：金额一律用「分」的 BigInt/字符串运算，展示层才除 100 格式化
// 坑：0.1+0.2 !== 0.3 → 永远不在浮点上做账
```
