## HW-362：手写一个连线锚点高亮与类型校验

**答**：
- 需求：实现 PortHighlight：拖线时高亮兼容端口（类型/方向匹配的端口发亮，不兼容的置灰）；落点吸附（光标距端口 < 12px 吸附）；松手校验（不兼容时回弹取消 + 提示）；连线预览（虚线跟随光标）。
- 边界：兼容性判定复用 typeCompat；吸附半径与缩放联动（世界坐标换算）；拖线中滚动画布预览跟随。
- 评分点：兼容端口高亮；吸附半径；回弹反馈。

```javascript
class PortHighlight {
  constructor(model, viewport, { snapR = 12 } = {}) { this.m = model; this.vp = viewport; this.snapR = snapR; }
  startDrag(fromNode, fromPort) {
    this.drag = { fromNode, fromPort };
    this.refreshCandidates();
  }
  refreshCandidates() {                                      // 兼容端口高亮
    const fp = this.m.nodes.get(this.drag.fromNode)?.ports.find(p => p.id === this.drag.fromPort);
    for (const [nid, node] of this.m.nodes) {
      for (const port of node.ports) {
        const compatible = port.dir === 'in' && typeCompat(fp.type, port.type)
          && nid !== this.drag.fromNode;
        port.state = compatible ? 'highlight' : 'dimmed';   // 高亮/置灰
      }
    }
  }
  findSnap(worldX, worldY) {                                 // 吸附查找
    let best = null;
    for (const node of this.m.nodes.values()) {
      for (const port of node.ports) {
        if (port.state !== 'highlight') continue;
        const d = Math.hypot(worldX - port.x, worldY - port.y);
        if (d <= this.snapR / this.vp.scale && (!best || d < best.d))   // 缩放联动半径
          best = { node: node.id, port, d };
      }
    }
    return best;
  }
  onMove(worldX, worldY) {
    this.snapTarget = this.findSnap(worldX, worldY);
    this.previewLine = this.snapTarget                       // 虚线预览
      ? null : [[this.drag.fromNode, worldX, worldY]];
    return this.snapTarget;
  }
  onDrop() {
    const t = this.snapTarget;
    this.clearHighlight();
    if (!t) return { ok: false, reason: 'no-target' };
    const res = this.m.addEdge(this.drag.fromNode, this.drag.fromPort, t.node, t.port.id);
    if (!res.ok) this.onReject?.(res.reason);                // 回弹提示
    return res;
  }
  clearHighlight() { for (const n of this.m.nodes.values())
    n.ports.forEach(p => p.state = null); }
}
```
