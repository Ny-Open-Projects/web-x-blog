## HW-283：手写一个树控件：懒加载展开、勾选联动与搜索高亮

**答**：
- 需求：实现 Tree：数据树 + 状态（expanded/checked/keyword）；search(kw) 返回匹配节点并自动展开其祖先路径，渲染时关键词高亮（分段）；勾选联动（选中父自动选中子，子全选联动父，半选）；懒加载子节点（hasChildren 标记）。
- 边界：搜索时禁用懒加载（全量匹配已知数据）；高亮分段含多关键词；祖先路径展开不改变用户原 expanded 集合（搜索态与浏览态分离）。
- 评分点：祖先路径展开；双状态分离；半选联动。

```javascript
class Tree {
  constructor(data, { lazy = true } = {}) { this.data = data; this.expanded = new Set();
    this.searchExpanded = new Set(); this.checked = new Set(); this.kw = ''; this.lazy = lazy; }
  search(kw) {
    this.kw = kw;
    this.searchExpanded = new Set();
    const hits = [];
    const walk = (n, path) => {
      if (kw && n.label.includes(kw)) {
        hits.push(n.id);
        path.forEach(p => this.searchExpanded.add(p));       // 自动展开祖先
      }
      n.children?.forEach(c => walk(c, [...path, n.id]));
    };
    walk(this.data, []);
    return hits;
  }
  visibleNodes() {                                           // 双状态展开合并
    const exp = this.kw ? this.searchExpanded : this.expanded;
    const out = [];
    const walk = (n, depth) => {
      out.push({ node: n, depth, hit: this.kw && n.label.includes(this.kw) });
      if (exp.has(n.id)) n.children?.forEach(c => walk(c, depth + 1));
    };
    walk(this.data, 0);
    return out;
  }
  highlight(label) {                                         // 关键词分段高亮
    if (!this.kw) return [{ t: label, hit: false }];
    const segs = []; let i = 0;
    while (i < label.length) {
      const idx = label.indexOf(this.kw, i);
      if (idx < 0) { segs.push({ t: label.slice(i), hit: false }); break; }
      if (idx > i) segs.push({ t: label.slice(i, idx), hit: false });
      segs.push({ t: this.kw, hit: true }); i = idx + this.kw.length;
    }
    return segs;
  }
  toggleCheck(id) { checkSync(this.data, this.checked, id); }
}
```
