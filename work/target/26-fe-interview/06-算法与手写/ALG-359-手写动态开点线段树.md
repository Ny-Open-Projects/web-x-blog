## ALG-359：手写动态开点线段树：超稀疏 ID 区间统计

**答**：
- 题目：用户 ID 范围 [1, 1e9]，要统计任意 ID 区间内的活跃用户数，但实际活跃 ID 极稀疏（几千个）。不能建 4e9 大小的数组——动态开点：节点按需创建。
- 思路：节点对象 {left, right, sum, lazy}，update/query 时越界子节点按需 new；空间 O(操作数 × log 值域)。
- 评分点：按需创建节点；引用式结构（非数组下标）；lazy 下推在动态结构中的处理。

```javascript
class DynamicSegTree {
  constructor(lo = 1, hi = 1e9) { this.lo = lo; this.hi = hi; this.root = this.node(); }
  node() { return { l: null, r: null, sum: 0 }; }
  update(pos, v, node = this.root, l = this.lo, r = this.hi) {
    if (l === r) return node.sum += v;
    const m = (l + r) >> 1;
    if (pos <= m) {
      node.l ??= this.node();
      this.update(pos, v, node.l, l, m);
    } else {
      node.r ??= this.node();
      this.update(pos, v, node.r, m + 1, r);
    }
    node.sum = (node.l?.sum ?? 0) + (node.r?.sum ?? 0);    // 回溯合并
  }
  query(ql, qr, node = this.root, l = this.lo, r = this.hi) {
    if (!node || qr < l || r < ql) return 0;               // 空节点视为 0
    if (ql <= l && r <= qr) return node.sum;
    const m = (l + r) >> 1;
    return this.query(ql, qr, node.l, l, m) + this.query(ql, qr, node.r, m + 1, r);
  }
}
// 空间 = O(活跃 ID 数 × 30)，与值域 1e9 无关——稀疏场景核心优势
```
