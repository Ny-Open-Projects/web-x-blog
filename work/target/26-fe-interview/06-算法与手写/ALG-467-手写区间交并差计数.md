## ALG-467：手写区间交并差计数：号段集合运算

**答**：
- 题目：多个号段区间集合（已分配/已冻结/黑名单），求「可分配区间」= 总区间 - 分配 - 冻结 - 黑名单 的交并差计数。区间集合运算：排序 + 扫描合并。
- 思路：差集 = 合并所有「占用」区间（排序后合并重叠），再扫描空隙求总长。
- 评分点：区间合并（排序+扫）；差集计算；与数位 DP 的分工（区间是显式集合时不必数位 DP）。

```javascript
function availableRanges(occupied, universe) {             // [total] - occupied
  const sorted = [...occupied].sort((a, b) => a[0] - b[0]);
  const merged = [];                                       // 区间合并
  for (const [l, r] of sorted) {
    const last = merged.at(-1);
    if (last && l <= last[1] + 1) last[1] = Math.max(last[1], r);   // 相邻也算重叠
    else merged.push([l, r]);
  }
  const out = [];                                          // 扫描空隙 = 可分配
  let cur = 1;
  for (const [l, r] of merged) {
    if (cur < l) out.push([cur, l - 1]);
    cur = Math.max(cur, r + 1);
  }
  if (cur <= universe) out.push([cur, universe]);
  return out;
}
const totalLen = (ranges) => ranges.reduce((s, [l, r]) => s + r - l + 1, 0);

```
