## ALG-517：手写贪心+前缀和：分割数组最大和最小化（分包均衡）

**答**：
- 题目：数组切成 k 个连续子数组，最小化「最大子数组和」（分包给 k 个 worker，均衡负载）。与 ALG-498 同构：二分答案 + 贪心判定（此处要求恰好 k 段，判定条件 count <= k 且可行）。
- 思路：二分 mid；贪心扫描段数 <= k 且每段 <= mid 可行；注意「恰好 k 段」时多段可拆分（段长可 1）保证可行性。
- 评分点：二分+贪心判定；段数上界语义；与 DP 解（O(n²k)）对比。

```javascript
function splitArrayMinMax(nums, k) {                       // 最小化最大段和
  let lo = Math.max(...nums), hi = nums.reduce((s, x) => s + x, 0);
  const feasible = (mid) => {
    let count = 1, sum = 0;
    for (const x of nums) {
      if (sum + x > mid) { count++; sum = x; }
      else sum += x;
    }
    return count <= k;                                     // k 段内可行（段可拆分调）
  };
  while (lo < hi) {                                        // 二分
    const mid = (lo + hi) >> 1;
    feasible(mid) ? hi = mid : lo = mid + 1;
  }
  return lo;
}
// 例：[7,2,5,10,8] k=2 → 18（[7,2,5] 和 [10,8]）
// DP 解：dp[i][j] = 前 i 个分 j 段的最小最大值，O(n²k)——n 大时二分+贪心 O(n log sum) 优
```
