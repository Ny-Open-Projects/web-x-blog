## HW-319：手写一个多级缓存引擎：内存、IndexedDB 与网络分层一致性

**答**：
- 需求：实现 CacheEngine：三层（memory Map / idb / network fetch）；get(k, loader)——逐层查找，命中低层回填高层；TTL 各层独立（memory 短、idb 长）；失效 invalidate(k) 三层同步清；写穿透 put(k, v) 同时写两层。
- 边界：并发 get 去重（同 key in-flight 共享 loader Promise）；TTL 过期判定在读取时惰性校验；序列化体积上限（超限不进 memory）。
- 评分点：回填；并发去重；惰性 TTL。

```javascript
class CacheEngine {
  constructor(idb, { memTTL = 60000, idbTTL = 86400000, maxMemBytes = 102400 } = {}) {
    this.mem = new Map(); this.idb = idb;
    this.memTTL = memTTL; this.idbTTL = idbTTL; this.max = maxMemBytes;
    this.inflight = new Map();
  }
  async get(key, loader) {
    const m = this.mem.get(key);
    if (m && Date.now() - m.ts < this.memTTL) return m.v;    // L1 惰性 TTL
    const d = await this.idb.get(key);
    if (d && Date.now() - d.ts < this.idbTTL) {              // L2 命中回填 L1
      this.setMem(key, d.v);
      return d.v;
    }
    if (this.inflight.has(key)) return this.inflight.get(key);   // 并发去重
    const p = loader().then(async v => {
      this.inflight.delete(key);
      this.setMem(key, v);
      await this.idb.put(key, { v, ts: Date.now() });        // 回源回填两层
      return v;
    });
    this.inflight.set(key, p);
    return p;
  }
  setMem(key, v) {
    if (JSON.stringify(v).length > this.max) return;         // 超限不进 memory
    this.mem.set(key, { v, ts: Date.now() });
  }
  async put(key, v) { this.setMem(key, v); await this.idb.put(key, { v, ts: Date.now() }); }
  async invalidate(key) { this.mem.delete(key); await this.idb.del(key); }   // 三层同步清
}
```
