## ALG-502：手写重叠区间染色：并发占用统计

**答**：
- 题目：资源租用区间（start, end），同一时刻最多 k 个租用者，超出拒绝。求「每个时刻的并发数峰值」判断容量是否够。差分数组 / 排序事件扫描。
- 思路：事件法：start +1、end -1 事件排序（同点先减后加——end 不含），扫出峰值。或差分数组。
- 评分点：开闭区间语义（同刻先出后进）；峰值扫描；与 ALG-385 的对照（动态用线段树）。

```javascript
function peakConcurrency(intervals, capacity) {
  const events = [];
  for (const [s, e] of intervals) {
    events.push([s, 1], [e, -1]);                          // e 时刻已释放（先减）
  }
  events.sort((a, b) => a[0] - b[0] || a[1] - b[1]);       // 同点：-1 先于 +1
  let cur = 0, peak = 0, rejected = 0;
  for (const [, d] of events) {
    cur += d;
    peak = Math.max(peak, cur);
    if (cur > capacity) rejected++;
  }
  return { peak, ok: peak <= capacity, rejected };
}
// 例：[[1,4],[2,5],[3,6]] capacity 2 → peak 3 → 需拒绝 1 个
// 动态频繁增删 → 线段树区间加+max（ALG-385）
```
