## ALG-549：手写布隆过滤器+计数器：去重与计数协同

**答**：
- 题目：事件去重（布隆判定可能存在才查计数器精确确认）——布隆粗筛 + 精确计数双层。误判率与位数/哈希函数数的关系公式。
- 思路：布隆（k 个哈希置位）；可能存在 → 计数器精确判；计数器用 Map（或分片计数器防热点）。
- 评分点：双层过滤流程；误判率公式 m/n 与 k；布隆不支持删除的局限（计数布隆提及）。

```javascript
class BloomCounter {
  constructor({ expected = 100000, fpRate = 0.01 } = {}) {
    // 最优位数 m = -n×ln(p)/(ln2)²；哈希函数 k = m/n×ln2
    const m = Math.ceil(-expected * Math.log(fpRate) / (Math.LN2 ** 2));
    const k = Math.max(1, Math.round(m / expected * Math.LN2));
    this.bits = new Uint8Array(m);
    this.k = k; this.exact = new Map();                     // 精确计数层
  }
  hashes(item) {
    const out = [];
    for (let i = 0; i < this.k; i++) {
      let h = 0;
      const s = item + ':' + i;
      for (const c of s) h = (h * 31 + c.charCodeAt(0)) >>> 0;
      out.push(h % this.bits.length);
    }
    return out;
  }
  add(item) {
    for (const h of this.hashes(item)) this.bits[h] = 1;
    this.exact.set(item, (this.exact.get(item) ?? 0) + 1);
  }
  mightContain(item) {
    return this.hashes(item).every(h => this.bits[h] === 1);   // 粗筛
  }
  exactCount(item) { return this.mightContain(item) ? this.exact.get(item) ?? 0 : 0; }   // 双层
}
// 误判率公式：p ≈ (1 - e^{-kn/m})^k；1 万条 1% 误判约需 m=95850 位 ≈ 12KB
// 局限：标准布隆不支持删除——计数布隆（每槽计数器）可删但内存×8
```
