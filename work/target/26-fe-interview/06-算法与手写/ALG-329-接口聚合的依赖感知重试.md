## ALG-329：依赖感知重试：聚合请求部分失败，重试只拉失败项并保持依赖顺序（失败的下游依赖不重试）？
**答**：ALG-307 的依赖版：商品(id=1)成功、库存(id 依赖商品)失败——重试库存需要商品结果作为参数（依赖感知），不是独立重试全部。

**思路**：依赖图 + 部分结果缓存 → 重试轮次只调度"依赖已满足的失败项"（deps 全部有结果才可重试）。

```javascript
async function aggregateWithDeps(tasks, cache, { rounds = 2 } = {}) {
  // tasks: [{ key, run: (results) => Promise, deps: [key] }]
  const results = {}; let failed = [...tasks];
  for (let round = 0; round < rounds && failed.length; round++) {
    const settled = await Promise.allSettled(
      failed.filter((t) => t.deps?.every((d) => results[d] !== undefined))   // 依赖已满足才重试
        .map(async (t) => [t.key, await (cache.get(t.key) ?? t.run(results).then((v) => (cache.set(t.key, v), v)))])
    );
    failed = [];
    settled.forEach((s, i) => {
      // 注意：filter 后索引对应关系丢失——用 key 回查（工程实现用 Map 记任务）
    });
    // 清晰版：
    const retryable = failed.filter((t) => t.deps?.every((d) => results[d] !== undefined));
    const blocked = failed.filter((t) => !retryable.includes(t));
    const outcomes = await Promise.allSettled(retryable.map(async (t) => {
      const v = cache.get(t.key) ?? await t.run(results);
      cache.set(t.key, v); return [t.key, v];
    }));
    failed = blocked;
    outcomes.forEach((o, i) => o.status === 'fulfilled' ? (results[retryable[i].key] = o.value[1]) : failed.push(retryable[i]));
  }
  return { results, failedKeys: failed.map((t) => t.key) };   // 未满足依赖的失败项留待下轮
}
// 语义：
// 依赖感知：库存失败重试时商品已缓存（results.goods 可用）—— run(results) 拿依赖结果
// 阻塞失败项：依赖也失败的项本轮跳过（下轮依赖满足后再试）—— 无效重试不过载
// 轮次上限（2）：无限重试 = 无限等待 —— 有限轮次 + failedKeys 输出（UI 降级）
```

**评分点**：
- 依赖感知重试（deps 满足才调度，run(results) 传依赖结果）——本题核心。
- 阻塞项跳过（依赖失败的下游不无效重试）。
- 轮次上限 + failedKeys 降级输出（ALG-307 联动）。
- 缓存复用成功部分。
