## HW-250：手写一个协作消息可靠传输：序号确认与丢包重传

**答**：
- 需求：实现 ReliableChannel：发送侧为每条消息编号（按会话单调），收到 ack(n) 表示 n 及之前全部确认；未确认消息在重传定时器（1s 指数退避，上限 5 次）后重发；接收侧去重（已见序号丢弃）并按序回调（乱序缓存等待）；提供 stats（重传率）。
- 边界：乱序缓存按序释放；ack 消息自身丢失 → 发送侧重传 → 接收侧去重后重发 ack；连接重建时从最后确认序号请求补发。
- 评分点：累积确认；乱序按序释放；重建补发。

```javascript
class ReliableChannel {
  constructor(send) { this.send = send; this.nextId = 0; this.unacked = new Map();
    this.peerNext = 0; this.ooo = new Map(); this.seen = new Set(); this.stats = { sent: 0, retried: 0 }; }
  push(payload) {
    const id = this.nextId++;
    const msg = { id, payload };
    this.unacked.set(id, { msg, tries: 0 });
    this.stats.sent++;
    this.send(msg);
    this.scheduleRetry(id);
    return id;
  }
  scheduleRetry(id) {                                       // 指数退避重传
    const e = this.unacked.get(id);
    if (!e) return;
    setTimeout(() => {
      if (!this.unacked.has(id)) return;
      if (e.tries++ >= 5) { this.onFail?.(id); this.unacked.delete(id); return; }
      this.stats.retried++;
      this.send(e.msg);
      this.scheduleRetry(id);
    }, 1000 * 2 ** e.tries);
  }
  onAck(n) {                                                // 累积确认
    for (const id of [...this.unacked.keys()]) if (id <= n) { this.unacked.delete(id); }
  }
  receive(msg) {
    if (this.seen.has(msg.id)) { this.send({ ack: msg.id }); return; }   // 去重并重发 ack
    this.seen.add(msg.id);
    if (msg.id === this.peerNext) { this.deliver(msg.payload); this.peerNext++; this.flushOoo(); }
    else this.ooo.set(msg.id, msg);                          // 乱序缓存
    this.send({ ack: msg.id });
  }
  flushOoo() {                                              // 按序释放
    while (this.ooo.has(this.peerNext)) { this.deliver(this.ooo.get(this.peerNext++).payload); this.ooo.delete(this.peerNext - 1); }
  }
  deliver(p) { this.onMessage?.(p); }
  resume(fromId) { this.send({ resume: fromId }); }         // 重建补发请求
}
```
