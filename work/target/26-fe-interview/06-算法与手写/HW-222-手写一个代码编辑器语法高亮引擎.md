## HW-222：手写一个代码编辑器语法高亮引擎：逐行 tokenize 与增量重高亮

**答**：
- 需求：实现 Highlighter：highlight(line, state) 逐行 token 化（支持字符串/注释/关键字三态跨行状态），返回 tokens 与新 state；markDirty(line) 后只重高亮该行起至状态稳定的行为止（增量）；提供颜色 class 映射。
- 边界：跨行字符串/块注释（状态传播）；增量的终止条件（本行结束 state 与上次一致即可停）；正则转义防注入。
- 评分点：跨行状态；增量终止条件；token→span 渲染。

```javascript
const KEYWORDS = new Set(['const', 'let', 'function', 'return', 'if', 'else']);
class Highlighter {
  constructor() { this.lines = []; this.states = []; }
  highlight(line, state = 'normal') {                          // state: normal|str|comment
    const tokens = []; let cur = '', cs = state;
    let i = 0;
    while (i < line.length) {
      const ch = line[i], two = line.slice(i, i + 2);
      if (cs === 'comment') { cur += ch; i++; continue; }      // 块注释内
      if (cs === 'normal' && two === '/*') { this.flush(cur, 'plain', tokens); cur = two; cs = 'comment'; i += 2; continue; }
      if (cs === 'normal' && two === '//') { this.flush(cur, 'plain', tokens); tokens.push({ t: line.slice(i), c: 'comment' }); i = line.length; cs = 'normal'; break; }
      if (cs === 'str') { cur += ch; if (ch === '"' && line[i - 1] !== '\\') { this.flush(cur, 'str', tokens); cur = ''; cs = 'normal'; } i++; continue; }
      if (ch === '"') { this.flush(cur, 'plain', tokens); cur = ch; cs = 'str'; i++; continue; }
      cur += ch; i++;
    }
    this.flush(cur, cs === 'str' ? 'str' : cs === 'comment' ? 'comment' : 'plain', tokens);
    if (cs === 'normal') {                                    // 关键字再处理
      for (const t of tokens) if (t.c === 'plain')
        t.html = t.t.split(/\b/).map(w => KEYWORDS.has(w) ? `<span class="kw">${w}</span>` : w).join('');
    }
    return { tokens, state: cs };                             // str/comment 跨行传播
  }
  flush(t, c, tokens) { t && tokens.push({ t, c }); }
  markDirty(start) {                                          // 增量：重算至状态稳定
    let i = start, st = start === 0 ? 'normal' : this.states[start - 1];
    while (i < this.lines.length) {
      const r = this.highlight(this.lines[i], st);
      if (this.states[i] === r.state && i > start) break;     // 状态稳定即停
      this.states[i] = r.state; i++;
    }
  }
}
```
