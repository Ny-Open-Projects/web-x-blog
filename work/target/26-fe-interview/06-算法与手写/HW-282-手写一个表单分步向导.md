## HW-282：手写一个表单分步向导：步骤校验与草稿续填

**答**：
- 需求：实现 Wizard：steps（每步字段集 + 校验规则）；next() 校验当前步通过才前进（失败输出错误聚焦第一个错误字段）；prev() 保留值；草稿持久化（每步通过后存 localStorage）；恢复（进入时检测草稿，跳到最后完成步）。
- 边界：跳步（点击步骤条）只能到已到达过的最远步；最后一步提交做全量校验（跨步依赖字段）；草稿版本 schema 变更兼容（按字段名匹配）。
- 评分点：最远步限制；跨步全量校验；草稿版本兼容。

```javascript
class Wizard {
  constructor(steps) { this.steps = steps; this.cur = 0; this.maxReached = 0; this.draft = {}; }
  async next(engine) {
    const step = this.steps[this.cur];
    const res = await engine.validateFields(step.fields);    // 当前步校验
    if (!res.valid) { engine.focusFirstError(res.errors); return false; }
    this.draft = { ...this.draft, ...engine.pick(step.fields) };
    saveDraft(this.draft, this.cur + 1);                     // 草稿持久化
    this.cur++; this.maxReached = Math.max(this.maxReached, this.cur);
    return true;
  }
  jump(stepIdx) {                                            // 只能到已到达步
    if (stepIdx > this.maxReached) return false;
    this.cur = stepIdx; return true;
  }
  async submit(engine) {                                     // 全量校验
    const all = this.steps.flatMap(s => s.fields);
    const res = await engine.validateFields(all);
    return res.valid ? engine.values : { errors: res.errors };
  }
  restore(saved) {                                           // 草稿恢复（按字段名匹配）
    const validFields = new Set(this.steps.flatMap(s => s.fields));
    this.draft = Object.fromEntries(Object.entries(saved.values ?? {})
      .filter(([k]) => validFields.has(k)));                 // schema 变更兼容
    this.cur = Math.min(saved.step ?? 0, this.maxReached = saved.step ?? 0);
    return this.draft;
  }
}
function saveDraft(values, step) { localStorage.setItem('wizard-draft',
  JSON.stringify({ values, step, ts: Date.now() })); }
```
