## ALG-535：手写摩尔投票：多选主选项

**答**：
- 题目：投票流中找「出现次数 > n/3」的选项（可有多于一个）。扩展摩尔投票：维护两个候选及计数。
- 思路：两个候选 c1/c2；相同则 ++，不同则双减；减到 0 换候选；最后二次校验（真实计数）。
- 评分点：双候选维护；二次校验必要（候选可能无真实过半）；O(1) 空间。

```javascript
function majorityElements(nums) {                          // 出现 > n/3 的元素
  let c1 = null, c2 = null, v1 = 0, v2 = 0;
  for (const x of nums) {
    if (c1 === x) v1++;
    else if (c2 === x) v2++;
    else if (v1 === 0) { c1 = x; v1 = 1; }
    else if (v2 === 0) { c2 = x; v2 = 1; }
    else { v1--; v2--; }                                   // 双减抵消
  }
  // 二次校验：候选未必真过 n/3
  const count = (c) => nums.filter(x => x === c).length;
  const out = [];
  if (c1 !== null && count(c1) > nums.length / 3) out.push(c1);
  if (c2 !== null && count(c2) > nums.length / 3) out.push(c2);
  return out;
}
// 摩尔投票核心：不同元素互相抵消，主元素最终存活（>n/2 版本单候选）
```
