**场景**：虚拟列表选中（checkbox）：DOM 节点复用（HW-067）——选中状态不能存 DOM（复用节点会串）——选中集（Set<id>）为唯一真相，渲染时按 id 回读（ALG-291 同源，虚拟列表强化版）。

**思路**：selected: Set → 渲染时 row.checked = selected.has(id)（节点复用必须显式回写——不回写 = 复用节点残留上一个数据行的选中态）。

```javascript
function renderRows(container, rows, selected, expanded) {
  for (const row of rows) {                               // rows: 虚拟列表可视区数据
    const el = pool.acquire(row);                         // 节点复用（HW-067）
    // 关键：复用节点必须"全字段显式回写"——包括状态类（checked/expanded/active）
    el.querySelector('input').checked = selected.has(row.id);     // 选中态：按 id 回读
    el.classList.toggle('expanded', expanded.has(row.id));        // 展开态：同回读
    el.dataset.id = row.id;
    // 反例：只在"勾选事件"时改 DOM checked——节点复用后旧 checked 残留（视觉串行，最隐蔽的虚拟列表 bug）
  }
}
// 单一真相：selected Set 是唯一状态源——DOM checked 只是渲染投影（事件更新 Set → 重渲染回读）
// 节点复用的纪律：acquire 后必须全字段重置（HW-067 reset 契约）—— 状态类字段最容易漏（视觉 bug 无报错）
// 选中操作：input.onchange → selected.add/delete(row.id) → Set 是真相（不需要手动改 DOM——重渲染回写）
```

**评分点**：
- 选中集为唯一真相 + 渲染显式回读——本题核心（复用节点残留是最隐蔽 bug）。
- "全字段显式回写"契约（状态类字段 checked/expanded/active 都要）。
- 事件只更新 Set（不手动改 DOM——投影一致性）。
- 与 ALG-291 树形展开状态的同源设计。
