## HW-327：手写一个通用虚拟列表引擎：不定高与动态测量

**答**：
- 需求：实现 VirtualList：不定高行（预估高度 estimate，渲染后实测校正）；测量缓存 Map<index, height>；滚动定位（scrollTop → index：用缓存前缀和 + 预估段近似）；行卸载后高度缓存保留（重进不跳动）。
- 边界：首次渲染估高误差导致滚动条跳动（用已测高缓存收敛，跳变容忍阈值）；快速滚动时先按估算渲染再校正；位置恢复用缓存精确计算。
- 评分点：估高+实测校正；缓存前缀和；快速滚动降级。

```javascript
class VirtualList {
  constructor({ estimate = 60, viewport } = {}) {
    this.est = estimate; this.heights = new Map(); this.vp = viewport;
  }
  h(i) { return this.heights.get(i) ?? this.est; }           // 已测或估算
  prefix(i) { let s = 0; for (let k = 0; k < i; k++) s += this.h(k); return s; }   // 可用累加缓存优化
  locate(scrollTop) {                                        // scrollTop → index
    let acc = 0, i = 0;
    while (acc + this.h(i) < scrollTop) { acc += this.h(i); i++; }
    return { index: i, offset: acc };
  }
  measure(index, height) { this.heights.set(index, height); }   // 渲染后实测
  onScroll(scrollTop) {
    const { index, offset } = this.locate(scrollTop);
    const vh = this.vp.clientHeight;
    const end = [];
    let acc = offset, i = index;
    while (acc < scrollTop + vh && i < this.total) { end.push(i); acc += this.h(i); i++; }
    return { start: index, end: i, topPad: offset,
      bottomPad: Math.max(0, this.prefix(this.total) - acc) };
  }
  renderRow(index, el) { this.measure(index, el.offsetHeight); }   // 挂载后实测回填
}
```
