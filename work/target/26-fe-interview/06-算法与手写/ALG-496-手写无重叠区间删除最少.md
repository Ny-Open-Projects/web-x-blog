## ALG-496：手写无重叠区间删除最少：定时任务去冲突

**答**：
- 题目：定时任务区间重叠需删除部分，求最少删除数 = 总数 - 最大不重叠数（同 ALG-481）。
- 思路：保留最多 = 按结束排序选不重叠；删除 = n - 保留。
- 评分点：转化为最大不重叠；计数而非输出区间；与 ALG-495 的关系。

```javascript
function eraseOverlapIntervals(intervals) {
  const sorted = [...intervals].sort((a, b) => a[1] - b[1]);
  let keep = 0, lastEnd = -Infinity;
  for (const [s, e] of sorted) {
    if (s >= lastEnd) { keep++; lastEnd = e; }             // 保留不重叠
  }
  return intervals.length - keep;                          // 删除数
}
// 例：[[1,2],[2,3],[3,4],[1,3]] → 保留 3 删 1（删 [1,3]）
// 对偶关系：最少删除 = n - 最多保留（区间调度问题）
```
