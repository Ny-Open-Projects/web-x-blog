## HW-129：手写可配置表单布局引擎——schema 驱动栅格布局、条件显示与分组折叠
**答**：schema 驱动表单（低代码场景）：字段声明（组件类型/校验/栅格 span/条件显示 visibleWhen/分组 group collapsible）→ 布局引擎按 schema 渲染。要点：条件显示的字段值保留（隐藏不清值，恢复显示原值还在——除非声明 clearOnHide）；分组折叠状态独立于值。

```jsx
function SchemaForm({ schema, values, onChange }) {
  const [collapsed, setCollapsed] = useState(() =>
    new Set(schema.groups?.filter((g) => g.defaultCollapsed).map((g) => g.id)));
  return schema.groups?.map((group) => (
    <section key={group.id}>
      {group.collapsible && (
        <button aria-expanded={!collapsed.has(group.id)}
          onClick={() => setCollapsed((s) => { const n = new Set(s); n.has(group.id) ? n.delete(group.id) : n.add(group.id); return n; })}>
          {group.title}
        </button>
      )}
      {!collapsed.has(group.id) && (
        <div className="grid">
          {schema.fields.filter((f) => f.group === group.id).map((f) => {
            if (f.visibleWhen && !f.visibleWhen(values)) return null;   // 条件隐藏
            return (
              <div key={f.name} style={{ gridColumn: `span ${f.span ?? 2}` }}>
                <label htmlFor={f.name}>{f.label}</label>
                <Field config={f} value={values[f.name] ?? f.defaultValue}
                       onChange={(v) => onChange(f.name, v)} />
              </div>
            );
          })}
        </div>
      )}
    </section>
  ));
}
// schema: { fields: [{ name, label, type: 'input'|'select'|'date', span, visibleWhen, clearOnHide }],
//           groups: [{ id, title, collapsible, defaultCollapsed }] }
// 条件隐藏语义：默认保留值（恢复显示原值还在）；clearOnHide: true 才清（表单提交口径决定）
// 栅格 span：CSS grid gridColumn span —— 布局与校验解耦（schema 单一来源）
```

**评分点**：
- schema 驱动（布局/校验/条件单一来源）；栅格 span 用 CSS grid 实现。
- 条件隐藏的值语义分档（默认保留 vs clearOnHide 清值）——易漏的业务决策点。
- 分组折叠状态独立于表单值；aria-expanded。
- 引擎与 schema 分离（新增字段类型不改引擎）。
