## ALG-362：手写线段树上二分：预算分段扣减

**答**：
- 题目：账户按「天」存余额，扣款按天顺序扣（今天不够扣明天的），求扣完 X 元后停在哪天、各天扣多少。前缀和线段树 + 树上二分找「累计 >= X 的第一天」。
- 思路：树上找第一个前缀和 >= X 的位置（与 ALG-356 同构，把 max 换成 sum 累计）；找到后该天扣剩余部分。
- 评分点：前缀累计语义的二分方向；扣减边界（最后一天可能只扣部分）；剩余金额计算。

```javascript
class BudgetDeduct {
  constructor(balances) {
    this.n = balances.length;
    this.t = new Array(4 * this.n).fill(0);
    this.build(balances);
  }
  build(a, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.t[node] = a[l];
    const m = (l + r) >> 1;
    this.build(a, node * 2, l, m); this.build(a, node * 2 + 1, m + 1, r);
    this.t[node] = this.t[node * 2] + this.t[node * 2 + 1];
  }
  firstAtLeast(ql, qr, x, node = 1, l = 0, r = this.n - 1) {   // 首个累计 >= x
    if (qr < l || r < ql || this.t[node] < x) return -1;
    if (l === r) return l;
    const m = (l + r) >> 1;
    const left = this.firstAtLeast(ql, qr, x, node * 2, l, m);
    if (left >= 0) return left;
    // 左子树累计不足：扣掉左子树后继续在右找剩余 x
    const leftSum = this.query(Math.max(ql, l), m);
    return this.firstAtLeast(ql, qr, x - leftSum, node * 2 + 1, m + 1, r);
  }
  query(ql, qr, node = 1, l = 0, r = this.n - 1) {
    if (qr < l || r < ql) return 0;
    if (ql <= l && r <= qr) return this.t[node];
    const m = (l + r) >> 1;
    return this.query(ql, qr, node * 2, l, m) + this.query(ql, qr, node * 2 + 1, m + 1, r);
  }
}
```
