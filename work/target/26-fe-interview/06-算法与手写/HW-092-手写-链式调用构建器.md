**答**：链式 API 的两种实现：每步返回新实例（不可变，可复用中间对象）或 this 链（可变，性能好）。惰性求值：所有操作先记录到 ops 数组，end()/exec() 时才一次性求值。适用：查询构建、DOM 链、图片处理 pipeline。

```javascript
class Query {
  constructor(data, ops = []) { this.data = data; this.ops = ops; }   // ops: 惰性操作记录
  #chain(fn) { return new Query(this.data, [...this.ops, fn]); }      // 不可变：返回新实例
  where(predicate) { return this.#chain((rows) => rows.filter(predicate)); }
  select(...keys) { return this.#chain((rows) => rows.map((r) => Object.fromEntries(keys.map((k) => [k, r[k]])))); }
  orderBy(key, dir = 'asc') {
    return this.#chain((rows) => [...rows].sort((a, b) => (a[key] > b[key] ? 1 : a[key] < b[key] ? -1 : 0) * (dir === 'desc' ? -1 : 1)));
  }
  limit(n) { return this.#chain((rows) => rows.slice(0, n)); }
  exec() { return this.ops.reduce((rows, fn) => fn(rows), this.data); }  // 惰性求值点
  then(onFulfilled) { return Promise.resolve(this.exec()).then(onFulfilled); }  // 可 await
}
// 用法
const rows = new Query(goods)
  .where((g) => g.price < 1000)
  .orderBy('sales', 'desc')
  .select('id', 'name', 'sales')
  .limit(10)
  .exec();
// 惰性价值：exec 前可以任意调整 ops（如先 orderBy 再 limit 可优化为堆 top-K）；
// 不可变链：const base = new Query(goods).where(...); 可派生多个不同 select 的分支复用
```

**评分点**：
- 惰性求值：ops 只记录不执行，exec 才求值；能说出优化空间（sort+limit 可合并 top-K）。
- #chain 返回新实例（不可变），中间对象可复用分支。
- then 实现（可 await 直接等待 exec 结果）是加分项。
- 语义方法与 reduce 求值清晰。
