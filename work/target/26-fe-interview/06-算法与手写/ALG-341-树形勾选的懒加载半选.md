**场景**：懒加载权限树勾选父节点：子树未加载（服务端返回 totalCount=25, checkedCount=8）——半选判定用服务端聚合数（本地只知道 8/25 已知部分）——勾选父 = 全选（含未加载子级，服务端展开）；聚合数在子级加载后用本地实测替换（服务端数可能过期）。

**思路**：节点聚合数（totalCount/checkedCount 服务端预计算）→ 判定：checkedCount=0 未选 / =total 全选 / 中间半选；懒加载后本地重算替换（子级实测覆盖服务端估计）。

```javascript
function nodeState(node, checkedSet) {
  if (node.checkedCount != null && !node.childrenLoaded) {   // 未加载：用服务端聚合数
    return node.checkedCount === 0 ? 'none'
      : node.checkedCount === node.totalCount ? 'all' : 'half';
  }
  const kids = node.children ?? [];                       // 已加载：本地实测
  const checked = kids.filter((c) => checkedSet.has(c.id)).length;
  return checked === 0 ? 'none' : checked === kids.length ? 'all' : 'half';
}
function checkAll(node, checkedSet, newValue) {           // 勾选父：全选含未加载子级（服务端语义）
  checkedSet.add(node.id);
  node.__subtreeCheck = newValue;                         // 标记：子级懒加载后自动应用（服务端配合）
  // 服务端契约：加载子级接口返回 children 带 checked: true（父勾选已登记）
  // 客户端：子级到达后 checkedSet 批量加入（视觉一致）
}
// 聚合数语义：服务端预计算（totalCount/checkedCount）—— 客户端不做"未加载子树"的猜测
// 本地实测替换：子级加载后 checkedCount 改为本地计算（服务端数可能过期——以加载到的实测为准）
// 全选含未加载：勾选父 = 服务端登记全选（懒加载子级到达时带 checked 标记）—— 不要求"先加载完才能勾"
```

**评分点**：
- 未加载子树用服务端聚合数判定半选——本题核心（不做客户端猜测）。
- 本地实测替换服务端估计（子级加载后）。
- 全选含未加载子级的服务端登记契约。
- 与 ALG-223/ALG-324 的联动（半选状态机 + 异步超时）。
