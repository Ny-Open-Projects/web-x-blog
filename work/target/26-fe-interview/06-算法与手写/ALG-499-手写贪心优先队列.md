## ALG-499：手写贪心+优先队列：合并果子（批量请求合并成本）

**答**：
- 题目：n 个请求各有大小，合并两个请求的成本 = 两者大小之和，求把所有请求合成一个的最小总成本。经典哈夫曼：小顶堆每次取最小两个合并。
- 思路：小顶堆；每次 pop 两个最小、合并成本入堆并累加；合并次数 n-1。等价于哈夫曼编码总长。
- 评分点：哈夫曼贪心（最小两个先合并）；与排序贪心的区别（合并结果重新入堆）；复杂度 O(n log n)。

```javascript
function mergeFruitCosts(sizes) {                          // 最小合并成本
  const heap = new MinHeap(sizes);                          // 小顶堆
  let total = 0;
  while (heap.size > 1) {
    const a = heap.pop(), b = heap.pop();
    const cost = a + b;
    total += cost;                                         // 本次合并成本
    heap.push(cost);                                       // 合并结果入堆
  }
  return total;
}
// 例：[1,2,3,4] → (1+2)=3, (3+3)=6, (6+4)=10 → 总 3+6+10=19
// 正确性：贪心合并最小的两个 = 哈夫曼树构造，总成本 = Σ 权×深度
// 场景：网关批量请求合并——优先合并小请求减少总等待
```
