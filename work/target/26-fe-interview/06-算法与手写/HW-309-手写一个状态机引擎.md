## HW-309：手写一个状态机引擎：状态、事件、转移与守卫声明式执行

**答**：
- 需求：实现 StateMachine：定义 {states, events, transitions: [{from, event, to, guard, action}]}, initial；dispatch(event, payload)——查匹配转移（from=当前态），guard 通过才转移并执行 action；未匹配事件忽略（可配置抛错）；输出当前态与历史。
- 边界：guard 拿 payload 判定；action 异步（转移先完成，action 失败不回滚但记录）；同 from+event 多转移按声明序取第一个 guard 通过者。
- 评分点：转移表驱动；guard 短路；多转移仲裁。

```javascript
class StateMachine {
  constructor(def) {
    this.def = def; this.state = def.initial; this.history = [def.initial];
  }
  dispatch(event, payload = {}) {
    const cands = this.def.transitions.filter(t => t.from === this.state && t.event === event);
    if (!cands.length) {                                     // 未匹配
      if (this.def.strict) throw new Error(`no-transition: ${this.state}+${event}`);
      return false;
    }
    for (const t of cands) {                                 // 按序取第一个通过 guard
      if (t.guard && !t.guard(payload, this.state)) continue;
      this.state = t.to;
      this.history.push(this.state);
      t.action?.(payload)?.catch?.(e => this.onActionError?.(e, t));   // 异步 action 失败记录
      this.onChange?.(this.state);
      return true;
    }
    return false;
  }
  can(event, payload) {                                     // UI 可用性查询
    return this.def.transitions.some(t =>
      t.from === this.state && t.event === event
      && (!t.guard || t.guard(payload, this.state)));
  }
}
// 用法：订单状态机 idle --pay(guard: amount>0)--> paid --ship--> shipped
const orderSM = new StateMachine({
  initial: 'idle', strict: false,
  transitions: [
    { from: 'idle', event: 'pay', to: 'paid',
      guard: p => p.amount > 0,
      action: p => notify('paid', p) },
    { from: 'paid', event: 'ship', to: 'shipped' },
    { from: 'shipped', event: 'confirm', to: 'done' },
  ],
});
```
