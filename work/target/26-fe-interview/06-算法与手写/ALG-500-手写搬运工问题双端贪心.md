## ALG-500：手写搬运工问题（双端贪心）：文件传输配对

**答**：
- 题目：n 个文件各有大小，两个传输通道（快/慢），快通道一次只能传一个且比慢通道快——把文件分配使「总耗时 = max(快道总大小/速度, 慢道总大小/速度)」最小。双端贪心：降序后轮流分配。
- 思路：近似贪心——大文件优先给快道（大文件的传输时间差异影响大）；LPT 式轮流分配后调整。
- 评分点：排序降序直觉；两通道的makespan模型；与 ALG-485 的双机特例关系。

```javascript
function assignTransfer(files, { fast = 2, slow = 1 } = {}) {   // 速度比 2:1
  const sorted = [...files].sort((a, b) => b - a);           // 降序
  let fastLoad = 0, slowLoad = 0;
  for (const f of sorted) {
    // 决策：给谁使 makespan 增量最小
    const fastTime = fastLoad / fast, slowTime = slowLoad / slow;
    if (fastTime <= slowTime) fastLoad += f; else slowLoad += f;   // 给当前更快完成的通道
  }
  return { fastLoad, slowLoad, makespan: Math.max(fastLoad / fast, slowLoad / slow) };
}
// 贪心直觉：每次把文件给「预计先完成的通道」——两通道特例接近最优（NP-hard 一般情形）
```
