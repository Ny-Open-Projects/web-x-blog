## ALG-530：手写并查集+离线：账号合并

**答**：
- 题目：合并线索（同邮箱/同手机号视为同一人），把账号分组并统计「最大账号组」。并查集：线索合并，组大小维护。
- 思路：邮箱/手机号为节点，账号与线索 union；按根分组统计大小。
- 评分点：线索节点建模；路径压缩+按秩合并；组大小统计。

```javascript
function mergeAccounts(accounts) {                         // accounts: [{id, emails, phones}]
  const parent = new Map(), size = new Map();
  const find = (x) => {
    if (!parent.has(x)) { parent.set(x, x); size.set(x, 1); }
    return parent.get(x) === x ? x : parent.set(x, find(parent.get(x))).get(x);
  };
  const union = (a, b) => {
    const ra = find(a), rb = find(b);
    if (ra === rb) return;
    if (size.get(ra) < size.get(rb)) [ra, rb] = [rb, ra];   // 按秩
    parent.set(rb, ra); size.set(ra, size.get(ra) + size.get(rb));
  };
  for (const acc of accounts) {
    const key = 'id:' + acc.id;
    find(key);
    for (const e of acc.emails) union(key, 'mail:' + e);
    for (const p of acc.phones) union(key, 'tel:' + p);
  }
  const groups = new Map();
  for (const acc of accounts) {
    const root = find('id:' + acc.id);
    (groups.get(root) ?? groups.set(root, []).get(root)).push(acc.id);
  }
  const sizes = [...groups.values()].map(g => g.length);
  return { groups: [...groups.values()],
    largest: Math.max(...sizes) };
}
```
