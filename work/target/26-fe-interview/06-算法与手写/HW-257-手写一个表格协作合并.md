## HW-257：手写一个表格协作合并：单元格级并发写与 last-writer-wins

**答**：
- 需求：实现 SheetMerge：数据模型 Map<cellKey, {value, ts, site}>；并发写同一 cell 按 (ts, siteId) 全序取最大（LWW）；并发写不同 cell 独立合并；提供 merge(remoteCells) 与 dump（序列化含时钟）；行级结构变更（插入行）用行 ID 而非行号定位。
- 边界：时钟偏差容忍（ts 用服务器对时校准，偏差 > 5s 告警）；删除 vs 写并发（删除标记 tombstone 仍 LWW）；cellKey 稳定（行 ID+列 key）。
- 评分点：LWW 全序；稳定 cellKey；时钟偏差处理。

```javascript
class SheetMerge {
  constructor(siteId) { this.site = siteId; this.cells = new Map(); }
  set(rowId, colKey, value, serverTs) {
    const key = rowId + ':' + colKey;                       // 稳定 key（不用行号）
    const ts = serverTs ?? Date.now();
    if (Math.abs(ts - Date.now()) > 5000) warnClockSkew(ts);
    const cur = this.cells.get(key);
    if (!cur || ts > cur.ts || (ts === cur.ts && this.site > cur.site))
      this.cells.set(key, { value, ts, site: this.site });  // LWW：ts 大者胜，平局 site 大者胜
  }
  merge(remoteCells) {                                     // 并发合并
    for (const [key, r] of remoteCells) {
      const cur = this.cells.get(key);
      if (!cur || r.ts > cur.ts || (r.ts === cur.ts && r.site > cur.site))
        this.cells.set(key, r);
    }
  }
  deleteCell(rowId, colKey) {                              // 删除也是 LWW 写
    this.set(rowId, colKey, null, Date.now());
  }
  dump() { return [...this.cells].map(([k, v]) => ({ k, ...v })); }
  read(rowId, colKey) { return this.cells.get(rowId + ':' + colKey)?.value ?? ''; }
}
```
