## HW-287：手写一个标签输入框：去重、粘贴多值与校验

**答**：
- 需求：实现 TagInput：输入回车/逗号成标签；重复标签拒绝（提示已存在）；粘贴多值（换行/逗号/分号分隔）拆分为多个标签（过滤空与重复）；校验规则（格式/最大长度/最大数量）不合格拒绝并提示；Backspace 在空输入时删除最后一个标签。
- 边界：粘贴拆分 trim 与空过滤；数量上限达到后仍允许删除不允许新增；编辑已有标签（点击标签进入编辑态）。
- 评分点：粘贴拆分管线；上限语义；重复提示。

```javascript
class TagInput {
  constructor({ max = 10, maxLen = 20, pattern } = {}) {
    this.tags = []; this.max = max; this.maxLen = maxLen; this.pattern = pattern;
    this.error = null;
  }
  add(raw) {
    if (this.tags.length >= this.max)
      return this.fail(`最多 ${this.max} 个`);
    const v = raw.trim();
    if (!v) return null;
    if (v.length > this.maxLen) return this.fail(`单个标签最长 ${this.maxLen}`);
    if (this.pattern && !this.pattern.test(v)) return this.fail('格式不合法');
    if (this.tags.some(t => t.toLowerCase() === v.toLowerCase()))
      return this.fail('标签已存在');                        // 重复拒绝
    this.tags.push(v); this.error = null;
    return v;
  }
  paste(text) {                                              // 粘贴多值拆分
    const parts = text.split(/[\n,;；，]/).map(s => s.trim()).filter(Boolean);
    const added = [];
    for (const p of parts) { const r = this.add(p); if (r) added.push(r); }
    return { added, failed: parts.length - added.length };
  }
  onBackspace(inputValue) {
    if (inputValue === '') { this.tags.pop(); return 'removed-last'; }   // 空输入删末尾
    return 'normal';
  }
  edit(idx, newValue) {                                      // 编辑已有标签
    const dup = this.tags.some((t, i) => i !== idx && t === newValue.trim());
    if (dup || !newValue.trim()) return false;
    this.tags[idx] = newValue.trim(); return true;
  }
  fail(msg) { this.error = msg; return null; }
}
```
