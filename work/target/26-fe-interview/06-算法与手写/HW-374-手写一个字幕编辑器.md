## HW-374：手写一个字幕编辑器：时间对齐与文本同步滚动

**答**：
- 需求：实现 SubtitleEditor：字幕列表 [{start, end, text}]；时间轴与列表双向联动（播放头所在字幕高亮并滚动到可见）；编辑（双击文本进入编辑，改时间码格式校验 HH:MM:SS.mmm）；重叠检测与提示（相邻字幕时间重叠标红）。
- 边界：自动滚动不打断用户手动滚动（用户滚动后 3s 内暂停自动跟随）；时间码解析容错；重叠检测 O(n) 排序扫描。
- 评分点：自动跟随与手动滚动冲突；时间码校验；重叠扫描。

```javascript
class SubtitleEditor {
  constructor(subs) { this.subs = subs.sort((a, b) => a.start - b.start); this.userScrolled = 0; }
  parseTimecode(s) {                                         // HH:MM:SS.mmm 解析
    const m = /^(\d{1,2}):(\d{2}):(\d{2})\.(\d{1,3})$/.exec(s.trim());
    if (!m) throw new Error('bad-timecode');
    const [, h, mi, se, ms] = m.map(Number);
    return h * 3600 + mi * 60 + se + ms / 1000;
  }
  activeAt(t) { return this.subs.find(s => t >= s.start && t < s.end); }   // 播放头字幕
  syncScroll(t, listEl) {                                    // 联动滚动
    if (Date.now() - this.userScrolled < 3000) return;       // 手动滚动后暂停跟随
    const active = this.activeAt(t);
    if (!active) return;
    const el = listEl.querySelector(`[data-id="${active.id}"]`);
    if (el && !inViewport(el, listEl))
      el.scrollIntoView({ block: 'center', behavior: 'smooth' });
  }
  onUserScroll() { this.userScrolled = Date.now(); }         // 用户滚动标记
  checkOverlaps() {                                          // 重叠检测 O(n)
    const out = [];
    for (let i = 1; i < this.subs.length; i++)
      if (this.subs[i].start < this.subs[i - 1].end)
        out.push([this.subs[i - 1].id, this.subs[i].id]);   // 标红对
    return out;
  }
  validate(item) {
    if (item.end <= item.start) return 'end <= start';
    if (item.text.trim() === '') return 'empty-text';
    return null;
  }
}
function inViewport(el, container) {
  const r = el.getBoundingClientRect(), c = container.getBoundingClientRect();
  return r.top >= c.top && r.bottom <= c.bottom;
}
```
