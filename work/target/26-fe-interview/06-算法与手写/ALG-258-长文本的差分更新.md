**场景**：协作批注：旧文本 vs 新文本，输出"哪里插入/删除/替换"的最小编辑片段（行级 diff 更实用——按行 diff，O(n·m) 可控）。

**思路**：按行 split → Levenshtein DP → 回溯产出操作序列（equal/delete/insert）；行相似判定用包含关系近似（改写行 = delete+insert 而非 replace——展示更直观）。

```javascript
function lineDiff(oldLines, newLines) {
  const n = oldLines.length, m = newLines.length;
  const dp = Array.from({ length: n + 1 }, () => new Uint32Array(m + 1));
  for (let i = 0; i <= n; i++) dp[i][0] = i;
  for (let j = 0; j <= m; j++) dp[0][j] = j;
  for (let i = 1; i <= n; i++)
    for (let j = 1; j <= m; j++)
      dp[i][j] = oldLines[i - 1] === newLines[j - 1]
        ? dp[i - 1][j - 1]
        : 1 + Math.min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]);
  // 回溯产出操作
  const ops = [];
  let i = n, j = m;
  while (i > 0 || j > 0) {
    if (i > 0 && j > 0 && oldLines[i - 1] === newLines[j - 1]) {
      ops.unshift({ type: 'equal', oldIdx: i - 1, newIdx: j - 1 }); i--; j--;
    } else if (j > 0 && (i === 0 || dp[i][j - 1] <= dp[i - 1][j])) {
      ops.unshift({ type: 'insert', newIdx: j - 1, text: newLines[j - 1] }); j--;
    } else {
      ops.unshift({ type: 'delete', oldIdx: i - 1, text: oldLines[i - 1] }); i--;
    }
  }
  return { edits: dp[n][m], ops };
}
// old: [A,B,C] new: [A,X,C] => equal A / delete B / insert X / equal C（1 次编辑）
// 复杂度 O(n·m) 时间；行数大时先哈希分桶（相同行先匹配，缩小 DP 规模——Myers diff 的工程近似）
// 连续 insert/delete 片段可合并展示（"删除 B，插入 X"而不是逐行）
```

**评分点**：
- Levenshtein DP 与回溯操作序列（equal/insert/delete）正确——本题核心。
- 行级 diff 的粒度选择（比字符级 O(n·m) 可控）。
- 回溯方向判断（insert 优先还是 delete 优先影响展示——语义说明）。
- 大文本的分桶缩规模优化方向。
