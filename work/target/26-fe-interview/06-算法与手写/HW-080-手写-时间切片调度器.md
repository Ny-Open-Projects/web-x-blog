## HW-080：手写时间切片调度器——30ms 预算切片 + scheduler.yield + 优先级插队
**答**：React 时间切片思想：把任务列表按时间预算（如 30ms）切片，切片间让出主线程并允许高优先级任务插队。结构：双队列（urgent / normal），每轮取 urgent 优先；预算用尽 yield；urgent 到来时在下一个切片开头执行。

```javascript
class TimeSlicer {
  constructor(budget = 30) { this.budget = budget;
    this.urgent = []; this.normal = [];
    this.running = false; this.signal = null; }
  addTask(tasks, { urgent = false } = {}) {        // tasks: 函数数组
    (urgent ? this.urgent : this.normal).push(...tasks);
    if (!this.running) this.#run();
  }
  interrupt() { this.signal = 'urgent'; }          // 外部触发紧急插队
  async #run() {
    this.running = true;
    while (this.urgent.length || this.normal.length) {
      const q = this.urgent.length ? this.urgent : this.normal;
      const start = performance.now();
      while (q.length && performance.now() - start < this.budget) {
        q.shift()();
        if (this.signal === 'urgent' && q === this.normal) { this.signal = null; break; } // 让位 urgent
      }
      if (this.urgent.length || this.normal.length) await this.#yield();
    }
    this.running = false;
  }
  #yield() {                                       // 让出：原生 yield 优先
    if ('scheduler' in window && 'yield' in scheduler) return scheduler.yield();
    return new Promise(r => setTimeout(r, 0));
  }
}
// 用法：10000 行列表渲染切片化
const slicer = new TimeSlicer(30);
slicer.addTask(rows.map((row) => () => mountRow(row)));           // normal
// 用户点击"搜索"时：slicer.interrupt() + addTask(searchTasks, { urgent: true })
```

**评分点**：
- 时间预算切片（performance.now 差值）而非固定条数。
- urgent/normal 双队列插队：切片开头选 urgent 队列，interrupt 信号中断当前 normal 切片。
- 让出降级链（scheduler.yield → setTimeout）。
- running 标记防重入；队列空才结束。
