## ALG-427：手写字符串哈希：盗图指纹比对

**答**：
- 题目：图片文件名/描述文本判断是否「高度相似」（完全一致或仅小改动）。字符串哈希：多项式滚动哈希，O(1) 比较任意子串。
- 思路：hash(s) = Σ s[i] × p^i mod m（p=131, m=大质数/2^53 安全域）；子串哈希 = (h[r] - h[l-1]×p^{r-l+1})；比对哈希相等（可双哈希防碰撞）。
- 评分点：前缀哈希预计算；子串 O(1) 提取；碰撞概率与双哈希。

```javascript
class StringHash {
  constructor(s, { p = 131, mod = (1n << 61n) - 1n } = {}) {
    this.p = BigInt(p); this.mod = mod;
    this.h = [0n]; this.pw = [1n];
    for (let i = 0; i < s.length; i++) {
      this.h.push((this.h[i] * this.p + BigInt(s.charCodeAt(i)) % mod) % mod);
      this.pw.push(this.pw[i] * this.p % mod);
    }
  }
  substr(l, r) {                                           // 子串哈希 [l, r)
    return (this.h[r] - this.h[l] * this.pw[r - l] % this.mod + this.mod) % this.mod;
  }
}
function similarDesc(a, b) {
  if (a === b) return true;
  if (Math.abs(a.length - b.length) > 2) return false;     // 长度差过滤
  const ha = new StringHash(a), hb = new StringHash(b);
  // 找最长公共子串（二分长度 + 哈希集合）
  let lo = 0, hi = Math.min(a.length, b.length), best = 0;
  while (lo <= hi) {                                       // 二分公共子串长度
    const mid = (lo + hi) >> 1;
    const set = new Set();
    for (let i = 0; i + mid <= a.length; i++) set.add(ha.substr(i, i + mid).toString());
    let found = false;
    for (let i = 0; i + mid <= b.length; i++)
      if (set.has(hb.substr(i, i + mid).toString())) { found = true; break; }
    if (found) { best = mid; lo = mid + 1; } else hi = mid - 1;
  }
  return best >= Math.min(a.length, b.length) * 0.8;       // 80% 公共子串判相似
}
```
