## HW-256：手写一个文本同步增量协议：全文 hash 分块对比（rsync 思想简化）

**答**：
- 需求：实现 SyncDelta：本地文档按固定块（如 256 字符）计算弱 hash（滚动和）+ 强 hash；对端发送块 hash 列表，本端匹配命中块 → 复用，未命中块 → 按字符级 diff 生成增量 ops（insert/delete）；输出传输量估算（增量字节数 vs 全文字节数）。
- 边界：块边界漂移（插入导致错位）时命中率下降——用双档块长缓解（简化：报告命中率即可）；空文档对端全量下发。
- 评分点：双 hash 命中；增量 ops 生成；传输量估算。

```javascript
function blockHashes(text, size = 256) {                  // 滚动和 + 强 hash
  const out = [];
  for (let i = 0; i + size <= text.length; i += size) {
    const blk = text.slice(i, i + size);
    let weak = 0; for (const c of blk) weak = (weak * 31 + c.charCodeAt(0)) >>> 0;
    out.push({ offset: i, weak, strong: strongHash(blk) });
  }
  return out;
}
function syncDelta(local, remoteHashes, size = 256) {
  const localH = blockHashes(local, size);
  const remoteSet = new Map(remoteHashes.map(h => [h.weak + ':' + h.strong, h.offset]));
  const ops = []; let reused = 0;
  for (const h of localH) {
    if (remoteSet.has(h.weak + ':' + h.strong)) { reused += size; continue; }   // 命中复用
    const s = h.offset, e = Math.min(h.offset + size, local.length);
    ops.push({ type: 'insert', pos: s, text: local.slice(s, e) });
  }
  const remoteLen = remoteHashes.length * size;
  if (local.length > remoteLen) ops.push({ type: 'insert', pos: remoteLen, text: local.slice(remoteLen) });
  const deltaBytes = ops.reduce((s, o) => s + o.text.length, 0);
  return { ops, stats: { hitRate: localH.length ? reused / (localH.length * size) : 0,
    deltaBytes, fullBytes: local.length, ratio: +(deltaBytes / Math.max(1, local.length)).toFixed(2) } };
}
function strongHash(s) { let h = 5381; for (const c of s) h = (h * 33 + c.charCodeAt(0)) >>> 0; return h.toString(36); }
```
