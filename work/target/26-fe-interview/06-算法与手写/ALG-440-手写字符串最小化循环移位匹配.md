## ALG-440：手写字符串最小化循环移位匹配：轮播去重

**答**：
- 题目：轮播配置去重——同一素材不同起始帧算重复（ALG-432 已给最小表示法）。本题为「循环移位匹配」的另一写法：s 是 t 的旋转 ⟺ s 是 t+t 的子串。
- 思路：结论法：t + t 包含所有旋转；KMP 查 s in t+t（排除等长限定）。
- 评分点：t+t 包含全部旋转的证明；KMP 复用；长度限定防误判。

```javascript
function isRotationMatch(s, t) {
  if (s.length !== t.length) return false;                 // 长度限定
  return kmpSearch(t + t, s).length > 0;                   // t+t 包含所有旋转
  // 证明：t+t 的每个长度为 n 的窗口恰是 t 的一个旋转
}
// 场景：轮播配置 [a,b,c] 与 [b,c,a] 判重（同素材不同起始帧）
// 复杂度：O(n + m)，比生成全部旋转逐一比对的 O(n²) 快
```
