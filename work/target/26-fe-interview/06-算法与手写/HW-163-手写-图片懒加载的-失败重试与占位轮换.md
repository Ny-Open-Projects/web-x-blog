**答**：懒加载图片失败（弱网/CDN 抖动）的恢复链：重试 2 次（指数退避 500ms/1500ms）→ 降级占位（灰块 + 重试图标，点击手动重试）→ 布局稳定（占位与原图同尺寸 aspect-ratio，重试期间零位移）。重试用 Image 对象预载（失败不改 el.src，避免浏览器缓存失败结果）。

```javascript
async function lazyLoadWithRetry(img, { retries = 2 } = {}) {
  const src = img.dataset.src;
  const attempt = async (n) => new Promise((resolve, reject) => {
    const probe = new Image();                            // 预载探针：不直接改 el.src
    probe.onload = () => resolve();
    probe.onerror = () => reject(new Error(`attempt ${n} failed`));
    probe.src = `${src}${src.includes('?') ? '&' : '?'}r=${Date.now()}`;   // 绕失败缓存
  });
  img.style.opacity = '0.5';                              // 重试中视觉态
  for (let i = 0; i <= retries; i++) {
    try {
      await attempt(i);
      img.src = src;
      img.style.opacity = '1';
      img.classList.remove('img-failed');
      return true;
    } catch (e) {
      if (i < retries) await new Promise((r) => setTimeout(r, 500 * 2 ** i));  // 500ms/1500ms
    }
  }
  img.classList.add('img-failed');                        // 降级占位（CSS 同尺寸灰块+重试按钮）
  img.addEventListener('click', () => lazyLoadWithRetry(img, { retries }), { once: true });
  return false;
}
```
```css
.img-failed { background: var(--img-fallback, #eee); cursor: pointer; }
/* 占位与原图同 aspect-ratio（HW-106/220）：重试期间布局零位移 */
```
**评分点**：
- 探针预载（失败不改 el.src，绕浏览器失败缓存加 cache-buster）。
- 退避重试 2 次有限；降级占位 + 手动重试入口。
- 布局稳定（同 aspect-ratio 占位）——重试期间零 CLS。
- once: true 的点击重试监听清理。
