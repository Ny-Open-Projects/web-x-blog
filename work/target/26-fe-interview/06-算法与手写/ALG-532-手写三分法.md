## ALG-532：手写三分法：预算曲线峰值

**答**：
- 题目：投入预算 x 的收益曲线先升后降（单峰），求最优预算。三分法：比较 f(m1) 与 f(m2) 收缩区间。
- 思路：lo/hi 三等分点 m1/m2；f(m1) < f(m2) → 峰在右侧收缩 lo；否则收缩 hi。整数三分防死循环（差 2 特判）。
- 评分点：单峰前提；三分收缩方向；整数三分边界。

```javascript
function ternarySearch(f, lo, hi) {                       // f 单峰（先升后降）
  while (hi - lo > 2) {
    const m1 = lo + Math.floor((hi - lo) / 3);
    const m2 = hi - Math.floor((hi - lo) / 3);
    if (f(m1) < f(m2)) lo = m1 + 1;                        // 峰在右
    else hi = m2 - 1;                                      // 峰在左
  }
  let best = lo;
  for (let x = lo; x <= hi; x++)                           // 剩余小范围线性扫
    if (f(x) > f(best)) best = x;
  return best;
}
// 例：f(x) = -x² + 100x（单峰，峰在 50）→ ternarySearch(f, 0, 100) = 50
// 前提：f 必须单峰——非单峰先分段或用模拟退火（提及）
```
