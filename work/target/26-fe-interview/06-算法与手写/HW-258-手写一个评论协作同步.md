## HW-258：手写一个评论协作同步：评论锚点漂移的 OT 变换

**答**：
- 需求：实现 CommentSync：评论锚点 {pos, len} 随文档 op 漂移（insert 在锚点前 → pos += len；delete 重叠 → 收缩）；锚点状态随 op 广播同步（对端收到锚点 op 后先对本地 pending 变换再应用）；输出评论列表渲染数据（含 lost 状态）。
- 边界：两个评论锚点重叠时的独立漂移；锚点跨越删除区间中点时贴左；同步乱序按版本排序应用。
- 评分点：锚点漂移三类处理；乱序排序。

```javascript
function anchorDrift(anchor, op) {
  if (op.type === 'insert') {
    if (op.pos <= anchor.pos) { anchor.pos += op.text.length; return anchor; }
    if (op.pos < anchor.pos + anchor.len) anchor.len += op.text.length;   // 锚内插入：扩展
    return anchor;
  }
  const s = op.pos, e = op.pos + op.text.length;
  if (e <= anchor.pos) { anchor.pos -= op.text.length; return anchor; }  // 删除在锚前
  const overlapStart = Math.max(anchor.pos, s);
  const overlapEnd = Math.min(anchor.pos + anchor.len, e);
  if (overlapEnd > overlapStart) anchor.len -= (overlapEnd - overlapStart);  // 重叠收缩
  if (anchor.pos >= s) anchor.pos = Math.max(s, anchor.pos - (e - Math.min(e, anchor.pos)));
  if (anchor.len <= 0) anchor.state = 'lost';              // 收缩为空：丢失
  return anchor;
}
class CommentSync {
  constructor() { this.anchors = []; }
  onLocalOp(op) { this.anchors.forEach(a => anchorDrift(a, op)); }
  onRemoteOps(ops) {                                       // 乱序按版本排序
    ops.sort((a, b) => a.rev - b.rev).forEach(op => this.anchors.forEach(a => anchorDrift(a, op)));
  }
  render() {
    return this.anchors.map(a => ({ id: a.commentId, pos: a.pos, len: a.len, state: a.state ?? 'active' }));
  }
}
```
