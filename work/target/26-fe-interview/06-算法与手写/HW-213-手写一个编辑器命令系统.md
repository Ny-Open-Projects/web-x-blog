## HW-213：手写一个编辑器命令系统：命令注册、组合与快捷键绑定

**答**：
- 需求：实现 CommandRegistry：register(name, {run, when})，exec(name, args)（when 不满足返回 false 且不执行）；快捷键映射（combo 字符串如 Mod-B）注册到命令；支持命令组合（宏：一次执行多条命令并作为一个 undo 单元）。
- 边界：组合命令共享一个事务（undo 一次回退全部）；重复注册同名命令报错；when 在 exec 时实时求值。
- 评分点：宏与事务结合；快捷键解析（Mod 兼容 mac/win）。

```javascript
class CommandRegistry {
  constructor() { this.cmds = new Map(); this.keys = new Map(); this.onMacro = null; }
  register(name, { run, when = () => true }) {
    if (this.cmds.has(name)) throw new Error('dup: ' + name);
    this.cmds.set(name, { run, when });
  }
  bind(combo, name) { this.keys.set(parseCombo(combo), name); }
  exec(name, ...args) {
    const c = this.cmds.get(name);
    if (!c || !c.when(...args)) return false;
    return c.run(...args);
  }
  macro(names) {                                  // 组合：单事务
    return (...args) => this.onMacro(() => names.forEach(n => this.exec(n, ...args)));
  }
  onKey(e) {
    const combo = keyCombo(e);                    // e -> 'Mod-Shift-K'
    const name = this.keys.get(combo);
    if (name) { e.preventDefault(); return this.exec(name); }
    return false;
  }
}
const CANON = parts => [...parts.filter(p => ['mod', 'ctrl', 'alt', 'shift'].includes(p)).sort(), parts.at(-1)].join('-');
function parseCombo(c) { return CANON(c.toLowerCase().split('-')); }
function keyCombo(e) {
  const mac = /Mac|iPhone|iPad/.test(navigator.platform || '');
  const mods = [mac ? e.metaKey && 'mod' : e.ctrlKey && 'mod', mac && e.ctrlKey && 'ctrl',
    e.altKey && 'alt', e.shiftKey && 'shift'].filter(Boolean);
  return CANON([...mods, e.key.toLowerCase()]);
}
```

## 补充：评分点与变体

**评分点**：

- when 在 exec 时实时求值，注册时求值会让权限变更后旧状态一直生效
- 宏必须包进一个事务，undo 一次退全部；逐条执行会被拆成 N 个历史单元
- 同名命令重复注册必须报错或显式声明覆盖，静默覆盖会让两个插件互相踩而不报错
- parseCombo 要与 keymap 共用归一化逻辑：Mod 平台映射加修饰键排序，两处各写一套必然不一致

**变体与延伸**：

1. 命令需要异步（上传图片后插入）→ 事务支持异步并保证失败回滚，或先插占位节点再替换
2. 输入法组合期间敲快捷键 → 检查 isComposing，组合中一律不派发命令
3. 命令参数从哪来 → exec 时注入上下文（选区、当前 block、editor 句柄），命令本身不直接读全局
