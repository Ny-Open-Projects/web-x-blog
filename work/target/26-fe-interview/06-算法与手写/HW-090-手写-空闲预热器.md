**答**：预热器把"下一屏可能用到的东西"（路由 chunk、下一页数据、组件渲染）在浏览器空闲时批量准备，但必须给用户交互让路（isInputPending / 用户主动操作即暂停预热）。要点：优先级队列、预热去重、交互打断恢复。

```javascript
class Warmer {
  constructor() { this.tasks = []; this.done = new Set(); this.paused = false; }
  warm(key, task, { priority = 0 } = {}) {
    if (this.done.has(key)) return;                  // 去重
    this.tasks.push({ key, task, priority });
    this.tasks.sort((a, b) => b.priority - a.priority);
    this.#schedule();
  }
  pause() { this.paused = true; }
  resume() { this.paused = false; this.#schedule(); }
  #schedule() {
    if (this.paused || !this.tasks.length) return;
    const pending = () => navigator.isInputPending?.() ?? false;
    const ric = window.requestIdleCallback || ((f) => setTimeout(() => f({ timeRemaining: () => 10 }), 200));
    ric(async (deadline) => {
      while (this.tasks.length && !this.paused && !pending()) {   // 用户交互让路
        if (deadline.timeRemaining() <= 3) break;                  // 预算耗尽等下一轮
        const { key, task } = this.tasks.shift();
        try { await task(); this.done.add(key); }                  // 记完成防重复
        catch { /* 预热失败静默：真用时正常加载 */ }
      }
      if (this.tasks.length && !this.paused) this.#schedule();
    }, { timeout: 4000 });
  }
}
// 用法：列表页空闲预热详情数据与"下一页"
const warmer = new Warmer();
warmer.warm('detail-1', () => fetch('/api/goods/1').then(r => r.json()), { priority: 1 });
warmer.warm('page-2', () => fetch('/api/list?page=2').then(r => r.json()));
document.addEventListener('pointerdown', () => warmer.pause(), { capture: true }); // 交互优先
document.addEventListener('pointerup', () => warmer.resume());
```

**评分点**：
- 预热去重（done 集合）+ 优先级排序。
- 给交互让路：isInputPending 检查 + pointerdown 暂停（预热不能拖累 INP）。
- deadline 预算循环；任务失败静默（预热是尽力而为）。
- timeout 兜底防任务饿死。
