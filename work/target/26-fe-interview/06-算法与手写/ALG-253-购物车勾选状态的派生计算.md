**场景**：购物车勾选（分组 × 商品）：勾选合计金额/数量、分组全选半选、全选状态——一次遍历派生所有状态（不嵌套循环不重复遍历）。

**思路**：单次遍历累计：每分组 {checked, total, amount}；顶层汇总；全选 = 所有组 checked 且组内全选；半选 = 部分勾选。派生数据不存 state（每次渲染时从源头计算——单一真相）。

```javascript
function deriveCart(groups, checkedIds) {
  // groups: [{ id, items: [{ id, price, qty }] }], checkedIds: Set
  const result = { groups: [], totalAmount: 0, totalCount: 0, allChecked: true, someChecked: false };
  for (const g of groups) {
    let amount = 0, count = 0, checkedCount = 0;
    for (const item of g.items) {                     // 内层单遍：勾选且计入合计
      if (checkedIds.has(item.id)) {
        amount += Math.round(item.price * item.qty);  // 分单位（ALG-200）
        count += item.qty;
        checkedCount++;
      }
    }
    const groupAll = checkedCount === g.items.length;
    const groupSome = checkedCount > 0;
    result.groups.push({ id: g.id, amount, count, all: groupAll, some: groupSome && !groupAll });
    result.totalAmount += amount; result.totalCount += count;
    if (!groupAll) result.allChecked = false;
    if (groupSome) result.someChecked = true;
  }
  return result;
}
// 单遍 O(n)（n=商品总数）：分组状态、顶层合计、全选半选一次算完
// 派生不进 state：checkedIds 是唯一状态，其余每次渲染派生（单一真相，无同步 bug）
// 半选语义：some = 组内有勾选但未全勾（checkbox indeterminate 态）
```

**评分点**：
- 单遍派生 O(n)（拒绝嵌套循环/多次遍历）。
- 派生不进 state 的单一真相原则（避免状态同步 bug）——本题核心。
- 全选/半选判定正确（组级与顶层两层语义）。
- 分单位金额计算衔接 ALG-200。
