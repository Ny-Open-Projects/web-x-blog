## ALG-531：手写二分+前缀和：日志分段查询

**答**：
- 题目：日志按时间排序，查「时间段 [t1, t2] 的日志条数与首条位置」。时间戳前缀计数 + 二分定位（无重复时直接 lowerBound）。
- 思路： timestamps 有序——lowerBound(t1) 与 upperBound(t2) 即区间端点；计数 = 差。
- 评分点：lower/upper 语义；计数与首条定位；时间戳去重与重复处理（等值多次）。

```javascript
class LogSegmentQuery {
  constructor(logs) {                                      // logs: [{ts, msg}]
    this.ts = logs.map(l => l.ts);
    this.logs = logs;
  }
  queryRange(t1, t2) {                                     // 时间戳区间
    const lo = lowerBound(this.ts, t1);                    // 首个 >= t1
    const hi = upperBound(this.ts, t2);                    // 首个 > t2
    return { count: hi - lo, first: hi > lo ? this.logs[lo] : null };
  }
  countPerMinute() {                                       // 每分钟计数（前缀和预计算）
    const perMin = new Map();
    for (const ts of this.ts) {
      const key = Math.floor(ts / 60000);
      perMin.set(key, (perMin.get(key) ?? 0) + 1);
    }
    return perMin;
  }
}
const lowerBound = (a, x) => { let lo = 0, hi = a.length;
  while (lo < hi) { const m = (lo + hi) >> 1; a[m] < x ? lo = m + 1 : hi = m; } return lo; };
const upperBound = (a, x) => { let lo = 0, hi = a.length;
  while (lo < hi) { const m = (lo + hi) >> 1; a[m] <= x ? lo = m + 1 : hi = m; } return lo; };
```
