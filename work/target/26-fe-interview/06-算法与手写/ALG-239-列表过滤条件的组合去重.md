## ALG-239：筛选器组合去重：多维筛选条件（品牌×价格×颜色）的相同组合合并与可枚举性判断？
**答**：商品筛选项：品牌 50 个 × 价格档 5 个 × 颜色 8 个 = 2000 组合；埋点要统计"用户用过的筛选组合"，组合键规范化去重（顺序无关：品牌+颜色 与 颜色+品牌 同组合）。

**思路**：组合键 = 各维度排序后拼接（规范化）；Set 去重；组合爆炸判断——枚举总数 2000 可以全枚举，但维度动态（用户自定义价格）时不可枚举，只能按实际使用去重。

```javascript
function comboKey(facets) {                              // facets: [{ dim, value }]
  const norm = [...facets]
    .sort((a, b) => a.dim.localeCompare(b.dim))          // 维度排序：顺序无关
    .map((f) => `${f.dim}=${f.value}`)
    .sort().join('&');                                   // 值也排序（同维度多选）
  return norm;
}
const used = new Set();
function trackFilter(facets) {
  used.add(comboKey(facets));
  return used.size;
}
// 规范化验证：[{dim:'brand',value:'a'},{dim:'color',value:'red'}]
// 与 [{dim:'color',value:'red'},{dim:'brand',value:'a'}] → 同一 key ✔
// 可枚举性：维度封闭（固定选项）→ 组合数 = Π(选项数) 可全枚举（2000 可行）；
// 维度开放（自由价格输入）→ 组合空间无限，只能按使用记录去重
// 同维度多选：值排序后拼接（brand=a&brand=b），语义 = AND
```

**评分点**：
- 组合键规范化（维度排序 + 值排序）保证顺序无关去重——本题核心。
- 可枚举性判断：封闭维度可全枚举、开放维度只能使用驱动。
- 同维度多选的键语义（AND）。
- Set 去重 O(1)。
