## ALG-255：搜索结果排序快照：请求与渲染期间的排序稳定性（同分随机但单次会话固定）？
**答**：搜索结果同分商品要"打散"展示，但每次刷新顺序必须一致（用户来回翻页不跳动）——随机打散要"确定性随机"：以 query+页码为种子的伪随机（ALG-231 分桶同思路），同一会话内 seed 固定。

**思路**：seed = hash(query + sessionEpoch)；同分项用 seed 洗牌（HW-029 Fisher-Yates with seed）；排序键 = (score desc, seededOrder)；会话切换（新搜索）换 seed。

```javascript
function seededShuffle(arr, seed) {
  let s = seed;
  const rand = () => { s = (s * 1664525 + 1013904223) % 2 ** 32; return s / 2 ** 32; };  // LCG 确定性
  const out = [...arr];
  for (let i = out.length - 1; i > 0; i--) {
    const j = Math.floor(rand() * (i + 1));
    [out[i], out[j]] = [out[j], out[i]];                  // Fisher-Yates with seed（HW-029）
  }
  return out;
}
function stableSearchRank(items, query, page) {
  const seed = fnv(query + ':' + page);
  const tied = items.filter((x) => x.score === items[0].score);
  const shuffled = new Map(seededShuffle(tied, seed).map((x, i) => [x.id, i]));
  return [...items].sort((a, b) =>
    b.score - a.score || (shuffled.get(a.id) ?? 0) - (shuffled.get(b.id) ?? 0));
}
// 语义：同分打散但"每次搜索同 query 同结果序"（seed 确定性）—— 用户翻回来不跳
// 反例：Math.random 直接洗 —— 每次刷新顺序变，用户以为"商品在动"
// seed 生命周期：同 query 会话内固定；新搜索（query 变）重新洗（打散语义保留）
```

**评分点**：
- 确定性随机（seed = hash(query+page) 的 LCG/Fisher-Yates）——本题核心。
- 同分打散与"会话内稳定"的双语义达成。
- 反例对照（Math.random 导致刷新跳动）。
- seed 生命周期说明（query 变才换）。
