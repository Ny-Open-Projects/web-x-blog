## ALG-277：甘特图时间轴：工作日/节假日混合刻度宽度（节假日窄列 + 周末折叠）？
**答**：甘特图时间轴：工作日 96px、周末 48px、节假日 24px——任务条跨节假日时端点位置计算（不是天数×固定宽，而是"累计有效宽度"）。前缀和定位（ALG-222 横向模式 + 节假日变宽）。

**思路**：日期数组 → 每日宽度表 → 前缀和 → 日期→x 坐标 O(logn) 二分；任务条 [start,end] 的 x/width 由前缀和差值。

```javascript
class GanttScale {
  #days = []; #prefix = [0];
  constructor(days, widthOf) {                            // widthOf: (dayInfo) => 96|48|24
    this.#days = days;
    days.reduce((acc, d) => { const w = widthOf(d); this.#prefix.push(acc + w); return acc + w; }, 0);
  }
  xOf(dateIdx) { return this.#prefix[dateIdx]; }          // 起点坐标
  widthOfRange(startIdx, endIdx) { return this.#prefix[endIdx + 1] - this.#prefix[startIdx]; }  // 跨节假日任务条
  #find(dateStr) {                                        // 日期 → 索引（Map O(1) 更简单）
    return this.#days.findIndex((d) => d.date === dateStr);
  }
}
// 示例：周一~周五 96px，周六日 48px，法定假 24px
// 任务 3/6(一)~3/10(五)：width = 前缀和差 —— 自动跳过周末的窄列
// 周末折叠进阶：直接隐藏周末列（工作日历模式）—— 前缀和同样成立（数组里就没有周末）
// 与 ALG-222 的关系：横向虚拟列表的变宽列 + 节假日语义，同一前缀和机制
```

**评分点**：
- 前缀和跨节假日定位（widthOfRange 差值）——本题核心。
- widthOf 回调的节假日语义注入。
- 周末折叠变体的说明（数组移除即可）。
- 与横向虚拟列表（ALG-222）的同构关系。
