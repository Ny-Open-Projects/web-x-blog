## ALG-460：手写前缀匹配计数（字典树+数位）：号段分配

**答**：
- 题目：号段按前缀分配（138*、139*），统计「以某前缀开头的未分配号码数」。Trie 按位建 + 每节点记「子树中已分配数」。
- 思路：Trie 节点 {children, used}；分配号码时沿路径 used++；查前缀 prefix 的剩余 = 10^(len-prefix) - used(prefixNode)。
- 评分点：Trie 上的子树计数；剩余计算公式；与数位 DP 的关系（Trie 版是按已存在前缀查）。

```javascript
class PrefixPool {
  constructor(digits = 11) { this.digits = digits; this.root = { children: {}, used: 0 }; }
  assign(phone) {                                           // 分配一个号码
    let node = this.root;
    node.used++;
    for (const c of phone) {
      node = node.children[c] ??= { children: {}, used: 0 };
      node.used++;
    }
  }
  remaining(prefix) {                                       // 前缀下剩余可用
    let node = this.root;
    for (const c of prefix) {
      node = node.children[c];
      if (!node) return Math.pow(10, this.digits - prefix.length);   // 前缀未开：全剩
    }
    const total = Math.pow(10, this.digits - prefix.length);
    return total - node.used;                               // 总数 - 已分配
  }
}
```
