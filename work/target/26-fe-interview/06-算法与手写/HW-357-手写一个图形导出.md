## HW-357：手写一个图形导出：SVG 序列化与 PNG 栅格化

**答**：
- 需求：实现 GraphicExport：场景节点 → SVG 元素（rect/circle/path/text 映射，样式转属性）；SVG 字符串下载（Blob）；PNG 导出（离屏 canvas 按 DPI 缩放栅格化，透明背景可选）；选区导出（只导出选中节点，按其包围盒裁剪）。
- 边界：DPI 缩放（2x 导出清晰）；字体嵌入（text 节点用系统字体栈）；透明背景（PNG 不填白底）；SVG 坐标平移（选区导出原点对齐包围盒）。
- 评分点：SVG 映射完整性；DPI 栅格化；选区裁剪。

```javascript
class GraphicExport {
  toSVG(nodes, { selection = null } = {}) {
    const list = selection ?? nodes;
    const b = selectionBounds(list);
    const body = list.map(n => nodeToSVG(n, -b.x, -b.y)).join('\n');   // 原点平移
    return `<svg xmlns="http://www.w3.org/2000/svg" width="${b.w}" height="${b.h}" viewBox="0 0 ${b.w} ${b.h}">${body}</svg>`;
  }
  downloadSVG(nodes) {
    const svg = this.toSVG(nodes);
    const blob = new Blob([svg], { type: 'image/svg+xml' });
    const a = document.createElement('a');
    a.href = URL.createObjectURL(blob);
    a.download = 'scene.svg'; a.click();
    URL.revokeObjectURL(a.href);
  }
  async toPNG(nodes, { dpi = 2, transparent = true } = {}) { // DPI 栅格化
    const b = selectionBounds(nodes);
    const cv = document.createElement('canvas');
    cv.width = b.w * dpi; cv.height = b.h * dpi;
    const ctx = cv.getContext('2d');
    if (!transparent) { ctx.fillStyle = '#fff'; ctx.fillRect(0, 0, cv.width, cv.height); }
    ctx.scale(dpi, dpi);                                     // DPI 缩放
    ctx.translate(-b.x, -b.y);                               // 选区裁剪
    nodes.forEach(n => n.draw(ctx));
    return new Promise(r => cv.toBlob(r, 'image/png'));
  }
}
function nodeToSVG(n, dx, dy) {
  const attrs = (o) => Object.entries(o).map(([k, v]) => `${k}="${v}"`).join(' ');
  if (n.type === 'rect') return `<rect ${attrs({ x: n.x + dx, y: n.y + dy, width: n.w, height: n.h, fill: n.fill })}/>`;
  if (n.type === 'circle') return `<circle ${attrs({ cx: n.x + n.w / 2 + dx, cy: n.y + n.h / 2 + dy, r: n.w / 2, fill: n.fill })}/>`;
  if (n.type === 'text') return `<text ${attrs({ x: n.x + dx, y: n.y + dy, 'font-family': 'system-ui, sans-serif' })}>${esc(n.text)}</text>`;
  return '';
}
```

## 补充：评分点与变体

**评分点**：

- 节点到 SVG 的映射要覆盖 fill/stroke/opacity/transform 四类，漏 transform 会让带旋转缩放的节点导出错位
- DPI 缩放要同时放大 canvas 尺寸并 `ctx.scale(dpr, dpr)`，只改其一会得到模糊图或被裁掉一半
- 选区导出要同时调整 viewBox 与 translate，只改一个会让整体坐标偏移包围盒左上角
- 文本内容的 XML 转义（`& < > "`）必须做，否则一个 `&` 就能让 SVG 解析失败

**变体与延伸**：

1. 场景里有外链图片与自定义字体 → 图片转 dataURL 内联，字体要么 base64 内嵌要么明确退回系统字体栈
2. 大画布导出直接 OOM → 分块渲染后拼接，或限制最大像素数，超限自动降 DPI 并提示
3. PNG 要透明底但某些查看器显示黑 → 明确不填底色并确保 alpha 通道未被覆盖，不能默认铺白
