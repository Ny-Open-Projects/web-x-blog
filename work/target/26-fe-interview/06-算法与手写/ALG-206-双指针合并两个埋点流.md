## ALG-206：监控平台：合并两个按时间升序的埋点流并保持有序（双指针归并 + 去重相邻）
**答**：两个埋点 SDK 各自产出按 ts 升序的日志流，监控平台要合并成一条有序流，且同一毫秒的重复事件（相同 ts+type）只保留一条。 streams 可能很大，要求 O(n+m) 不全量排序。

**思路**：双指针归并（各自已是升序），归并时跳过与前一条相同的（ts+type 相同）。流式版可用 generator。

```javascript
function* mergeLogs(a, b) {
  let i = 0, j = 0, last = null;
  while (i < a.length || j < b.length) {
    const next = j >= b.length || (i < a.length && a[i].ts <= b[j].ts) ? a[i++] : b[j++];
    if (last && last.ts === next.ts && last.type === next.type) continue;  // 相邻去重
    yield next;
    last = next;
  }
}
// generator 版：流式消费不占整块内存
const merged = [...mergeLogs(
  [{ ts: 1, type: 'click' }, { ts: 3, type: 'view' }, { ts: 3, type: 'view' }],
  [{ ts: 2, type: 'click' }, { ts: 3, type: 'click' }],
)];
// => [{1,click},{2,click},{3,view},{3,click}]
// 复杂度：O(n+m) 时间、O(1) 额外（generator 惰性）
// 稳定性：ts 相同时 a 优先（<= 保证），两个 SDK 的同 ts 事件顺序可预期
```

**评分点**：
- 双指针归并正确（边界：一流耗尽走另一流）。
- 相邻去重只对"刚输出的上一条"比较（同毫秒重复判定 ts+type）。
- generator 流式版本是加分项（大流不爆内存）。
- O(n+m) 复杂度说明（不重新排序）。
