## HW-289：手写一个进度环组件：SVG 弧形计算与动画

**答**：
- 需求：实现 ProgressRing：SVG circle 描边（strokeDasharray=周长，strokeDashoffset 控制进度）；动画（offset 从当前值过渡到目标，CSS transition 或 rAF）；支持多段（分段颜色，各段弧长按占比分配）；中心文本显示百分比。
- 边界：0% 与 100% 边界（offset = 周长 / 0）；多段间隙（各段间留 1% 间隙）；半径与描边宽度联动（周长 = 2πr）。
- 评分点：dashoffset 原理；多段分配；边界处理。

```javascript
class ProgressRing {
  constructor(svg, { r = 45, stroke = 8, gapDeg = 3 } = {}) {
    this.r = r; this.c = 2 * Math.PI * r;                    // 周长
    this.gap = gapDeg / 360;                                 // 段间隙比例
    this.el = svg;
    svg.innerHTML = `<circle r="${r}" fill="none" stroke-width="${stroke}"
      stroke-dasharray="${this.c}" stroke-dashoffset="0"
      transform="rotate(-90)" class="ring-track"/>`;
  }
  render(segments) {                                         // 多段 [{value, color}]
    const total = segments.reduce((s, x) => s + x.value, 0) || 1;
    let acc = 0;
    const parts = segments.map((seg, i) => {
      const frac = seg.value / total;
      const len = Math.max(0, frac - this.gap) * this.c;     // 每段扣间隙
      const offset = -acc * this.c;                          // 起点偏移
      acc += frac;
      return `<circle r="${this.r}" fill="none" stroke="${seg.color}"
        stroke-width="8" stroke-dasharray="${len} ${this.c}"
        stroke-dashoffset="${offset}" transform="rotate(-90)"
        style="transition: stroke-dasharray .3s"><title>${(frac * 100).toFixed(1)}%</title></circle>`;
    });
    this.el.innerHTML += parts.join('');
    this.label(segments.reduce((s, x) => s + x.value, 0) / total);
  }
  label(p) {
    const pct = Math.round(Math.max(0, Math.min(1, p)) * 100);   // 钳制边界
    this.el.insertAdjacentHTML('beforeend',
      `<text text-anchor="middle" dy="6">${pct}%</text>`);
  }
}
```
