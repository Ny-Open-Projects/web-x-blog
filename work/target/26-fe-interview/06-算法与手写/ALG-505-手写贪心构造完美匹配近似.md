## ALG-505：手写贪心构造完美匹配近似：供需匹配

**答**：
- 题目：供给侧（承接量）与需求侧（需求量）匹配，最大化「成功匹配对数」（不要求量相等，能接即配）。二分图最大匹配精确解（匈牙利）O(V×E)，贪心近似：按需求紧迫度排序配当前可承接者。
- 思路：贪心近似：需求按紧迫度/量降序，逐个找可承接供给（剩余量 > 0 中挑最小的——避免大供给浪费在小需求）。
- 评分点：贪心近似策略（最小可承接供给）；精确解匈牙利算法的提及；匹配问题的建模。

```javascript
function greedyMatch(supplies, demands) {                  // 供给 [{id, cap}], 需求 [{id, need}]
  const sorted = [...demands].sort((a, b) => b.need - a.need);   // 大需求优先
  const remaining = new Map(supplies.map(s => [s.id, s.cap]));
  const matches = [];
  for (const d of sorted) {
    // 找「可承接且剩余量最小」的供给——最小合适（best-fit）
    let best = null;
    for (const [id, cap] of remaining)
      if (cap >= d.need && (best === null || cap < remaining.get(best)))
        best = id;
    if (best !== null) {
      matches.push({ demand: d.id, supply: best });
      remaining.set(best, remaining.get(best) - d.need);
    }
  }
  return { matches, matched: matches.length };
}
// best-fit vs first-fit：best-fit 减少大供给被小需求浪费
// 精确最大匹配：匈牙利算法 O(V×E)——面试提及即可
```
