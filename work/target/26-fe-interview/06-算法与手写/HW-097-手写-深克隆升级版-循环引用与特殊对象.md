## HW-097：手写深克隆（进阶版）——循环引用、Date/RegExp/Map/Set/File/Blob 与丢失类原型的兜底
**答**：基础深克隆（HW-016）之上的完整版：WeakMap 处理循环引用；类型分派（Date/RegExp/Map/Set/ArrayBuffer/TypedArray/File/Blob）；普通对象与数组递归；其余（函数/DOM/类实例）返回引用或按策略兜底。

```javascript
function deepClone(value, seen = new WeakMap()) {
  if (value === null || typeof value !== 'object') return value;          // 基本类型与函数：返回
  if (seen.has(value)) return seen.get(value);                            // 循环引用
  if (value instanceof Date) return new Date(value);
  if (value instanceof RegExp) return new RegExp(value.source, value.flags);
  if (value instanceof Map) {
    const m = new Map(); seen.set(value, m);
    value.forEach((v, k) => m.set(deepClone(k, seen), deepClone(v, seen)));
    return m;
  }
  if (value instanceof Set) {
    const s = new Set(); seen.set(value, s);
    value.forEach((v) => s.add(deepClone(v, seen)));
    return s;
  }
  if (value instanceof ArrayBuffer) return value.slice(0);                // 二进制：拷贝字节
  if (ArrayBuffer.isView(value)) return new value.constructor(value.slice().buffer); // TypedArray
  if (typeof Blob !== 'undefined' && value instanceof Blob) return value.slice(0, value.size, value.type);
  if (typeof File !== 'undefined' && value instanceof File) return new File([value], value.name, { type: value.type });

  const out = Array.isArray(value) ? [] : Object.create(Object.getPrototypeOf(value)); // 保留原型
  seen.set(value, out);
  for (const key of Reflect.ownKeys(value)) {                              // 含 symbol 键
    const desc = Object.getOwnPropertyDescriptor(value, key);
    if (desc.get || desc.set) Object.defineProperty(out, key, desc);        // getter：保留描述符
    else out[key] = deepClone(desc.value, seen);
  }
  return out;
}
// 循环引用：const a = {}; a.self = a; deepClone(a).self === 拷贝对象自身（非原对象）
// 类实例：new class P { constructor(){ this.x = 1 } } 的拷贝保留 P 原型（instanceof 成立）
```

**评分点**：
- WeakMap 循环引用（同一对象克隆一次，自引用闭环指向拷贝）。
- Map/Set 键值也走深克隆；Date/RegExp/二进制类型分派完整。
- Reflect.ownKeys 覆盖 symbol；getter/setter 保留描述符（不然 getter 会被"求值固化"）。
- 类实例保留原型（Object.create(getPrototypeOf)），能说出 structuredClone 的等价能力边界。
