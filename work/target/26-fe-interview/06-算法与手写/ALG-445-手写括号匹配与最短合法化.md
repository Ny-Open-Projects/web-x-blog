## ALG-445：手写括号匹配与最短合法化：公式输入校验

**答**：
- 题目：公式输入框实时校验——括号是否匹配，不匹配时给出「最少补几个括号在哪补」的提示。
- 思路：栈匹配；非法化：扫描中栈底不足的右括号需前补左括号，栈剩余左括号需后补；计数即最短补全数。
- 评分点：栈匹配基础；两类非法（多余右/未闭合左）；最短补全位置提示。

```javascript
function bracketValidate(s) {
  const stack = [];
  let needOpen = 0;                                        // 需前补 '(' 数
  for (let i = 0; i < s.length; i++) {
    if (s[i] === '(') stack.push(i);
    else if (s[i] === ')') {
      if (stack.length) stack.pop();
      else needOpen++;                                     // 多余右括号
    }
  }
  return {
    valid: needOpen === 0 && stack.length === 0,
    fixPrefix: needOpen,                                   // 前补 '(' 数
    fixSuffix: stack.length,                               // 后补 ')' 数
    unmatchedAt: stack,                                    // 未闭合 '(' 位置
    fixed: '('.repeat(needOpen) + s + ')'.repeat(stack.length),   // 最短合法化
  };
}
// 场景：公式输入 ((a+b)*c 实时提示「缺少 1 个右括号」
```
