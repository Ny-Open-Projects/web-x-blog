## ALG-441：手写正则简易匹配引擎（回溯+记忆化）：通配符匹配

**答**：
- 题目：实现「* 匹配任意序列、? 匹配单字符」的通配符匹配（如文件路径过滤）。回溯 + 记忆化（或 DP）。
- 思路：DP：dp[i][j] = s 前 i 与 p 前 j 匹配；* 转移 = dp[i-1][j]（吃一字符）或 dp[i][j-1]（空）；连续 * 折叠优化。
- 评分点：* 的两种转移；连续 * 折叠；回溯解的指数风险与记忆化修复。

```javascript
function wildcardMatch(s, p) {
  p = p.replace(/\*+/g, '*');                             // 连续 * 折叠
  const n = s.length, m = p.length;
  const dp = Array.from({ length: n + 1 }, () => new Array(m + 1).fill(false));
  dp[0][0] = true;
  for (let j = 1; j <= m && p[j - 1] === '*'; j++) dp[0][j] = true;   // 前缀 * 匹配空
  for (let i = 1; i <= n; i++)
    for (let j = 1; j <= m; j++) {
      if (p[j - 1] === '*')
        dp[i][j] = dp[i - 1][j] || dp[i][j - 1];           // 吃一字符 or 匹配空
      else if (p[j - 1] === '?' || p[j - 1] === s[i - 1])
        dp[i][j] = dp[i - 1][j - 1];
    }
  return dp[n][m];
}
// 场景：路径过滤 *.log、域名通配 *.example.com
// 回溯解最坏 O(n^m)（* 分支爆炸）——DP/记忆化是必须的
```
