## HW-278：手写一个看板引擎：列内排序与跨列拖拽

**答**：
- 需求：实现 KanbanEngine：数据 {columns: [{id, cards: [cardId]}]}；拖拽卡片：同列重排（splice）、跨列移动（源列删除+目标列插入指定位置）；拖拽中占位符指示目标位置；移动记录操作日志（undo 支持）。
- 边界：拖到列尾（无卡片中点命中）追加；列空时占位符居中显示；同一次拖拽只产生一条日志（原子）。
- 评分点：跨列原子移动；占位符定位；日志原子性。

```javascript
class KanbanEngine {
  constructor(data) { this.data = data; this.log = []; this.undolog = []; }
  move(cardId, fromCol, toCol, toIdx) {
    const from = this.data.columns.find(c => c.id === fromCol);
    const to = this.data.columns.find(c => c.id === toCol);
    const fi = from.cards.indexOf(cardId);
    if (fi < 0) return false;
    const adjTo = fromCol === toCol && fi < toIdx ? toIdx - 1 : toIdx;   // 同列先删后插补偿
    from.cards.splice(fi, 1);
    to.cards.splice(Math.min(adjTo, to.cards.length), 0, cardId);
    this.log.push({ type: 'move', cardId, fromCol, toCol, adjTo });
    return true;
  }
  calcDropIndex(colEl, y) {                                  // 列内落点计算
    const cards = [...colEl.querySelectorAll('[data-card]')];
    let idx = cards.length;
    for (let i = 0; i < cards.length; i++)
      if (y < cards[i].getBoundingClientRect().top + cards[i].offsetHeight / 2) { idx = i; break; }
    return idx;
  }
  undo() {
    const op = this.log.pop();
    if (!op) return;
    const to = this.data.columns.find(c => c.id === op.toCol);
    const from = this.data.columns.find(c => c.id === op.fromCol);
    const i = to.cards.indexOf(op.cardId);
    to.cards.splice(i, 1);
    const fi = from.cards.indexOf(op.cardId);
    from.cards.splice(op.fromCol === op.toCol && fi <= op.adjTo ? op.adjTo : op.adjTo, 0, op.cardId);
  }
}
```
