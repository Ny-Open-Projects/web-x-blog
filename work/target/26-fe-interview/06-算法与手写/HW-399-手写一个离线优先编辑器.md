## HW-399：手写一个离线优先编辑器：Service Worker 与本地队列整合

**答**：
- 需求：实现 OfflineFirstEditor：SW 缓存策略（app shell cache-first、文档数据 network-first + IDB 兜底）；本地写队列（离线操作入 IDB 队列，见 HW-336 复用）；恢复同步（online 事件触发 flush，冲突走合并策略）；状态指示（离线横幅 + 未同步计数）。
- 边界：SW 更新（新版本 skipWaiting + 提示刷新）；队列与 SW 缓存一致性（SW 不缓存 mutation 请求）；首次加载无 SW 的降级。
- 评分点：分资源策略；mutation 不缓存；SW 更新提示。

```javascript
const SW_CACHE_STRATEGY = `self.addEventListener('fetch', e => {
  const url = new URL(e.request.url);
  if (e.request.method !== 'GET') return;                    // mutation 不缓存（一致性）
  if (url.pathname.startsWith('/app/')) {                    // app shell：cache-first
    e.respondWith(caches.match(e.request).then(r => r
      || fetch(e.request).then(res => { caches.open('shell-v1').then(c => c.put(e.request, res.clone()));
        return res; })));
  } else if (url.pathname.startsWith('/doc/')) {             // 文档：network-first + IDB 兜底
    e.respondWith(fetch(e.request).then(res => {
      caches.open('doc-v1').then(c => c.put(e.request, res.clone()));
      return res;
    }).catch(() => caches.match(e.request).then(r => r || idbFallback(url))));
  }
});
self.addEventListener('install', e => self.skipWaiting());   // 新版本立即激活`;
class OfflineFirstEditor {
  constructor() {
    addEventListener('online', () => this.queue.flush());    // 恢复同步
    this.status = navigator.onLine ? 'online' : 'offline';
    addEventListener('offline', () => this.setStatus('offline', this.queue.pending()));
  }
  setStatus(status, pending) {
    banner(status === 'offline' ? `离线模式，${pending} 条变更待同步` : '已恢复同步');   // 状态指示
    this.status = status;
  }
  async onSwUpdate(reg) {                                    // SW 更新提示
    const sw = reg.waiting ?? reg.installing;
    if (!sw) return;
    sw.addEventListener('statechange', () => {
      if (sw.state === 'activated') showToast('新版本已就绪，刷新生效');
    });
  }
}
```
