## ALG-319：图片渐进加载：缩略图→模糊放大→原图的三级替换（感知速度最大化）？
**答**：图集加载：占位色（瞬时）→ 缩略图（50KB，快）→ 原图（2MB，慢）——三级替换，每级"先到先显示"（用户尽快看到内容），原图到达无缝替换（同位同尺寸零位移）。

**思路**：三级 src 依次尝试（并行发起，谁先到显示谁——低级不取消），容器 aspect-ratio 锁定（零 CLS），替换用 opacity 过渡。

```javascript
async function progressiveImage(img, { thumb, full }) {
  img.style.aspectRatio = '16 / 9';                     // 占位锁定（零 CLS，PER-220）
  const show = (src) => new Promise((res) => {
    const probe = new Image();
    probe.onload = () => {                              // 先到先显示（不取消低级请求）
      img.src = src;
      img.style.opacity = '0';
      requestAnimationFrame(() => { img.style.transition = 'opacity .3s'; img.style.opacity = '1'; });
      res(src);
    };
    probe.onerror = res;
    probe.src = src;
  });
  const thumbP = show(thumb);                           // 缩略图与原图并行发起（不等序列）
  const fullP = show(full);
  await Promise.race([thumbP, fullP]);                  // 第一个到达即有内容
  await fullP;                                          // 原图到达后替换完成
}
// 并行发起：缩略图/原图同时请求（缩略图先到先显示，原图到达覆盖）—— 序列式会浪费 1s 等缩略图
// 零 CLS：aspect-ratio 锁定 + object-fit cover —— 三级替换尺寸一致
// 感知速度：占位色(0ms) → 缩略图(~200ms) → 原图(~1.5s) —— 每一级都比"白屏等原图"好
```

**评分点**：
- 三级并行发起（先到先显示，不取消低级）——本题核心（序列式浪费等待）。
- aspect-ratio 锁定零 CLS。
- opacity 过渡替换（合成器）。
- 感知速度的分段量化。
