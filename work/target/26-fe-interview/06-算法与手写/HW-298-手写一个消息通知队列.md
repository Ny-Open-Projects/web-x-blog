## HW-298：手写一个消息通知队列：堆叠展示与自动消失

**答**：
- 需求：实现 Toast：show(msg, {type, duration}) 返回 id；堆叠渲染（最多 5 条，超出最旧先出）；自动消失（duration 到期淡出动画后移除）；hover 暂停该条倒计时；手动关闭；同文案去重（短时间重复合并计数）。
- 边界：倒计时暂停/恢复（hover 时长重算）；去重窗口内合并显示 ×N；关闭动画完成后再从 DOM 移除（防闪烁）。
- 评分点：倒计时暂停恢复；合并计数；动画后移除。

```javascript
class Toast {
  constructor(container, { max = 5, duration = 3000, dedupMs = 2000 } = {}) {
    this.box = container; this.max = max; this.dur = duration;
    this.dedup = dedupMs; this.items = new Map(); this.recent = new Map();
  }
  show(msg, { type = 'info', duration } = {}) {
    const last = this.recent.get(msg);
    if (last && Date.now() - last.t < this.dedup) {          // 去重合并计数
      last.count++; last.el.querySelector('.count').textContent = 'x' + last.count;
      return last.id;
    }
    if (this.items.size >= this.max) this.close(this.items.keys().next().value);   // 超出淘汰
    const id = 't' + Math.random().toString(36).slice(2);
    const el = document.createElement('div');
    el.className = `toast ${type}`;
    el.innerHTML = `<span>${esc(msg)}</span><span class="count"></span><button>×</button>`;
    el.querySelector('button').onclick = () => this.close(id);
    el.onmouseenter = () => this.pause(id);
    el.onmouseleave = () => this.resume(id);
    this.box.appendChild(el);
    const item = { el, timer: this.arm(id, duration ?? this.dur), count: 1 };
    this.items.set(id, item); this.recent.set(msg, { id, t: Date.now(), el });
    return id;
  }
  arm(id, ms) { return setTimeout(() => this.close(id), ms); }
  pause(id) { const it = this.items.get(id); if (!it) return;
    clearTimeout(it.timer); it.left = it.left ?? this.dur; }  // 暂停记录剩余
  resume(id) { const it = this.items.get(id); if (!it) return;
    it.timer = this.arm(id, it.left ?? this.dur); }
  close(id) { const it = this.items.get(id); if (!it) return;
    it.el.classList.add('closing');                          // 淡出动画
    setTimeout(() => { it.el.remove(); this.items.delete(id); }, 200); }
}
const esc = s => s.replace(/[<>&]/g, c => ({ '<': '&lt;', '>': '&gt;', '&': '&amp;' }[c]));
```
