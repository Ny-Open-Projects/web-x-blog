## HW-313：手写一个表单校验引擎：schema、异步规则与依赖校验

**答**：
- 需求：实现 Validator：schema {field: [rules]}，规则 {type, params, message}；validateField 异步支持（唯一性检查）；依赖校验（字段 A 校验依赖 B 当前值——传 context）；全量校验并发执行（Promise.all）聚合错误；validateOnBlur/input 分级触发。
- 边界：异步规则并发去重（同字段在途请求共享）；错误聚合按字段分组；首次错误即停可选（abortEarly）。
- 评分点：异步并发去重；依赖 context；abortEarly。

```javascript
class Validator {
  constructor(schema) { this.schema = schema; this.inflight = new Map(); }
  async validateField(field, value, ctx, { dedupe = true } = {}) {
    const rules = this.schema[field] ?? [];
    if (dedupe) {                                            // 异步去重
      const key = field + ':' + JSON.stringify(value);
      if (this.inflight.has(key)) return this.inflight.get(key);
      const p = this._run(rules, value, ctx).finally(() => this.inflight.delete(key));
      this.inflight.set(key, p);
      return p;
    }
    return this._run(rules, value, ctx);
  }
  async _run(rules, value, ctx) {
    for (const r of rules) {                                 // abortEarly：逐条执行
      const fn = RULES[r.type];
      const ok = await fn(value, r.params ?? {}, ctx);       // 异步规则支持
      if (!ok) return { valid: false, error: r.message };
    }
    return { valid: true };
  }
  async validateAll(values) {                                // 并发聚合
    const entries = Object.entries(values);
    const results = await Promise.all(entries.map(([f, v]) =>
      this.validateField(f, v, values)));
    const errors = {};
    entries.forEach(([f], i) => { if (!results[i].valid) errors[f] = results[i].error; });
    return { valid: !Object.keys(errors).length, errors };
  }
}
const RULES = {
  required: async v => v != null && v !== '',
  minLength: async (v, { n }) => String(v ?? '').length >= n,
  unique: async (v, {}, ctx) => (await api.checkUnique(v, ctx.scope)).available,   // 依赖 ctx
};
```
