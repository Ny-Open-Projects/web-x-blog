## HW-296：手写一个图片裁剪器：手势缩放平移与裁剪框约束

**答**：
- 需求：实现 Cropper：图片在裁剪框内可拖动/滚轮缩放（transform: translate+scale）；约束：图片始终覆盖裁剪框（无白边——缩放后边界钳制）；输出裁剪结果（canvas 绘制裁剪区域导出 blob）。
- 边界：钳制计算（scale 后图片尺寸 vs 框尺寸，translate 范围 [框-图, 0]）；缩放中心为鼠标点（保持光标下图像点不动）；导出用自然分辨率（非显示分辨率）。
- 评分点：覆盖约束钳制；中心缩放；导出分辨率。

```javascript
class Cropper {
  constructor(imgEl, frameEl) {
    this.img = imgEl; this.frame = frameEl;
    this.scale = 1; this.x = 0; this.y = 0;
    imgEl.addEventListener('wheel', e => this.zoom(e), { passive: false });
    frameEl.addEventListener('pointerdown', e => this.drag(e));
  }
  zoom(e) {                                                  // 中心缩放
    e.preventDefault();
    const r = this.frame.getBoundingClientRect();
    const cx = e.clientX - r.left, cy = e.clientY - r.top;   // 光标在框内坐标
    const k = e.deltaY < 0 ? 1.1 : 0.9;
    const next = Math.max(1, Math.min(4, this.scale * k));
    this.x = cx - (cx - this.x) * (next / this.scale);       // 光标点不动
    this.y = cy - (cy - this.y) * (next / this.scale);
    this.scale = next;
    this.clamp(); this.render();
  }
  clamp() {                                                  // 覆盖约束：无白边
    const fw = this.frame.clientWidth, fh = this.frame.clientHeight;
    const iw = this.img.naturalWidth * this.scale * (fw / this.img.naturalWidth);
    const ih = this.img.naturalHeight * this.scale * (fh / this.img.naturalHeight);
    const minX = Math.min(0, fw - iw), minY = Math.min(0, fh - ih);
    this.x = Math.max(minX, Math.min(0, this.x));
    this.y = Math.max(minY, Math.min(0, this.y));
  }
  render() { this.img.style.transform = `translate(${this.x}px,${this.y}px) scale(${this.scale})`; }
  async export(type = 'image/jpeg') {                        // 自然分辨率导出
    const cv = document.createElement('canvas');
    cv.width = this.frame.clientWidth; cv.height = this.frame.clientHeight;
    const ctx = cv.getContext('2d');
    ctx.drawImage(this.img, this.x / this.scale, this.y / this.scale,
      cv.width / this.scale, cv.height / this.scale, 0, 0, cv.width, cv.height);
    return new Promise(r => cv.toBlob(r, type, 0.9));
  }
}
```
