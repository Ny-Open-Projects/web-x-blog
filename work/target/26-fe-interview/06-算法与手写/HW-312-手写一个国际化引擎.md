## HW-312：手写一个国际化引擎：复数、占位符与嵌套翻译

**答**：
- 需求：实现 I18n：翻译表（嵌套 key）；t(key, params) 占位符替换 {name}；复数规则（Intl.PluralRules：zero/one/two/few/many/other，key_other/key_one 形式）；缺失 key 回退链（当前语言 → 默认语言 → key 本身并告警）；语言切换热更新（订阅）。
- 边界：复数按 locale 规则（中文只有 other）；嵌套 key 用点路径；插值缺失参数保留原样；回退告警上报（漏翻译监控）。
- 评分点：PluralRules；回退链+告警；热更新订阅。

```javascript
class I18n {
  constructor(messages, { fallback = 'en' } = {}) {
    this.messages = messages; this.locale = 'zh'; this.fallback = fallback;
    this.subs = new Set();
  }
  setLocale(l) { this.locale = l; this.subs.forEach(fn => fn(l)); }   // 热更新
  subscribe(fn) { this.subs.add(fn); return () => this.subs.delete(fn); }
  t(key, params = {}, n) {
    let str = this.lookup(this.locale, key, n)
      ?? this.lookup(this.fallback, key, n);
    if (!str) {                                              // 回退告警
      report('i18n-missing', { locale: this.locale, key });
      return key;                                            // 最终回退 key 本身
    }
    return str.replace(/\{(\w+)\}/g, (_, k) =>             // 占位符（缺失保留原样）
      params[k] !== undefined ? String(params[k]) : `{${k}}`);
  }
  lookup(locale, key, n) {
    const table = this.messages[locale];
    if (!table) return null;
    if (n != null) {                                         // 复数：Intl.PluralRules
      const cat = new Intl.PluralRules(locale).select(n);
      const v = getPath(table, `${key}_${cat}`) ?? getPath(table, key + '_other');
      if (v != null) return v.replace('{n}', n);
    }
    return getPath(table, key);
  }
}
const getPath = (o, p) => p.split('.').reduce((x, k) => x?.[k], o);
```
