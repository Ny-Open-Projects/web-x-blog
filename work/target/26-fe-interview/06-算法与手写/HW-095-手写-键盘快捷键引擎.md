## HW-095：手写键盘快捷键引擎——组合键解析、冲突裁决、输入框内禁用、作用域栈
**答**：快捷键引擎要点：① 组合键规范化（Ctrl/⌘、Shift、Alt 排序成标准串）；② 冲突裁决——后注册优先 / 最长匹配优先；③ 输入框内默认不触发（可覆盖 allowInInput）；④ 作用域栈（弹窗打开时 push 作用域，只有栈顶作用域生效）。

```javascript
class HotkeyManager {
  constructor() { this.scopes = [new Map()]; }   // 作用域栈：[{ 'mod+k': fn }]
  #norm(combo) {
    return combo.toLowerCase().split('+').map((s) => s.trim())
      .sort((a, b) => ({ ctrl: 0, meta: 0, alt: 1, shift: 2 }[a] ?? 3 - ({ ctrl: 0, meta: 0, alt: 1, shift: 2 }[b] ?? 3)))
      .join('+');
  }
  register(scope, combo, fn, { allowInInput = false } = {}) {
    this.scopes.at(-1).set(this.#norm(combo), { fn, allowInInput });
  }
  pushScope() { this.scopes.push(new Map()); }    // 弹窗打开：新作用域压栈
  popScope() { if (this.scopes.length > 1) this.scopes.pop(); }
  #inInput(e) {
    const t = e.target;
    return t.tagName === 'INPUT' || t.tagName === 'TEXTAREA' || t.isContentEditable;
  }
  handle(e) {
    const parts = [];
    if (e.ctrlKey) parts.push('ctrl'); if (e.metaKey) parts.push('meta');
    if (e.altKey) parts.push('alt'); if (e.shiftKey) parts.push('shift');
    parts.push(e.key.toLowerCase());
    const combo = this.#norm(parts.join('+'));
    const scope = this.scopes.at(-1).get(combo) ?? [...this.scopes.at(-1)].reverse().find(([k]) => k === combo)?.[1];
    if (!scope) return;
    if (this.#inInput(e) && !scope.allowInInput) return;      // 输入框内禁用
    e.preventDefault();
    scope.fn(e);
  }
}
// 用法
const hk = new HotkeyManager();
document.addEventListener('keydown', (e) => hk.handle(e));
hk.register('main', 'mod+k', openSearch);       // ⌘K / Ctrl+K
hk.register('main', 'ctrl+shift+s', saveAll);
hk.pushScope();                                  // 打开弹窗
hk.register('modal', 'esc', closeModal);         // esc 只在弹窗作用域生效
hk.popScope();                                   // 关弹窗恢复 main
```

**评分点**：
- 组合键规范化（统一小写 + 修饰键排序），跨平台 mod（⌘/Ctrl）处理。
- 作用域栈：只查栈顶，弹窗快捷键不穿透到主界面。
- 输入框内禁用 + allowInInput 覆盖。
- preventDefault 阻止浏览器默认行为（如 ⌘S 保存页面）。
