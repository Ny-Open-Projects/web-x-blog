## ALG-495：手写射气球（区间端点贪心）：告警合并

**答**：
- 题目：多条告警各有生效区间，一支「处理箭」（一次发布修复）覆盖所有与其区间相交的告警，求最少箭数。区间交贪心：按右端点排序，箭打在当前组最右端点。
- 思路：按 end 排序；当前箭位置 = 组内最小 end；后续区间 start <= 箭位则同组；否则新箭。
- 评分点：按 end 排序；箭位 = 组内最小 end（保证覆盖全组）；与 ALG-481 的对称关系。

```javascript
function minArrows(balloons) {                             // balloons: [[start, end]]
  const sorted = [...balloons].sort((a, b) => a[1] - b[1]);   // 按 end 排序
  let arrows = 0, arrowPos = -Infinity;
  for (const [s, e] of sorted) {
    if (s > arrowPos) {                                    // 新箭
      arrows++;
      arrowPos = e;                                        // 打在本组最右端点
    }
  }
  return arrows;
}
// 例：[[10,16],[2,8],[1,6],[7,12]] → 2 支（x=6 覆盖 3 条，x=12 覆盖 1 条）
// 与「无重叠区间」互为对偶：一支箭覆盖一组 = 相交区间合并
```
