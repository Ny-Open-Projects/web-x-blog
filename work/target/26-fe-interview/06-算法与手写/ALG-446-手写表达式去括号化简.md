## ALG-446：手写表达式去括号化简：规则展示优化

**答**：
- 题目：规则引擎条件展示「((a AND b) OR (c AND d))」嵌套括号冗长——在优先级保证语义不变前提下去掉冗余括号。
- 思路：AST 构建时按优先级（NOT > AND > OR）直接给每个节点记录「所需最小括号级别」；子节点优先级 ≥ 父级则不加括号。
- 评分点：优先级驱动的括号省略；结合性（同级左结合不加右括号）；语义保持验证（随机用例对拍）。

```javascript
const PREC = { OR: 1, AND: 2, NOT: 3 };
function stringify(node) {
  const wrap = (child, parentPrec, side) => {
    const s = stringify(child);
    const need = PREC[child.type] < parentPrec
      || (PREC[child.type] === parentPrec && side === 'right');   // 同级右孩子要括号
    return need ? `(${s})` : s;
  };
  switch (node.type) {
    case 'AND': return `${wrap(node.left, 2, 'left')} AND ${wrap(node.right, 2, 'right')}`;
    case 'OR': return `${wrap(node.left, 1, 'left')} OR ${wrap(node.right, 1, 'right')}`;
    case 'NOT': return `NOT ${wrap(node.child, 3, 'left')}`;
    default: return node.field;                            // 叶子
  }
}
// 验证：随机生成 AST → stringify → 重解析 → 与原 AST 等价（结构比对）
// 例：(a AND (b OR c)) OR d 中 (b OR c) 必须带括号（OR 优先级低于 AND 父级）
```
