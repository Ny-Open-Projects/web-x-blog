## ALG-519：手写贪心在 UI 中的应用合集：虚拟列表与缓存淘汰回顾

**答**：
- 题目：串联贪心在前端 UI 的已落地场景——虚拟列表窗口（贪心选可视区）、LRU 缓存淘汰（贪心逐出最旧）、骨架屏内容分级（贪心优先关键内容）。给出各场景的贪心决策点。
- 要点：虚拟列表 = 「只渲染可视区间」贪心（决策：剪掉不可见）；LRU = 「逐出最久未用」贪心（交换论证：最近使用的未来价值不低于更早的）；内容分级 = 「优先满足关键内容」贪心（同 SJF）。
- 评分点：三场景的贪心决策点表述；与经典贪心问题的对应；性能收益量化。

const greedyInUI = {
  virtualList: {
    decision: '只渲染可视区 ± buffer',
    classic: '区间选择贪心——剪掉的不可见部分不影响正确性',
    gain: '节点数从 1 万级降到几百级（ALG-357 关联）',
  },
  lru: {
    decision: '逐出最久未访问项',
    classic: '交换论证：最近使用的未来命中概率不低于更早项',

  },
  commonLesson: '贪心在 UI 的核心价值：局部决策即时执行，无需全局最优',
};
