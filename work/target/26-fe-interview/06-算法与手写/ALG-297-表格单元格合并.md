## ALG-297：表格单元格合并：连续相同值的 rowspan 合并（列方向扫描 + 范围标记）？
**答**：订单表格按"客户"列合并（同客户连续行 rowspan）：扫描列方向连续相同值 → 组起始行标 rowspan=n，后续行标记跳过渲染；多列合并（客户+订单）按层级嵌套判定。

**思路**：列扫描：连续相同值段 → {start, span}；渲染时该列只渲染段首（rowspan），后续行该列 skip；上游排序保证相同值相邻（合并的前提）。

```javascript
function mergeRanges(rows, key) {
  const ranges = [];                                      // [{start, span, value}]
  for (let i = 0; i < rows.length; ) {
    let span = 1;
    while (i + span < rows.length && rows[i + span][key] === rows[i][key]) span++;
    ranges.push({ start: i, span, value: rows[i][key] });  // 连续段
    i += span;
  }
  return ranges;
}
function renderWithMerge(rows, mergeKey) {
  const ranges = mergeRanges(rows, mergeKey);
  const skip = new Set();                                 // 被合并吞掉的行（该列不渲染）
  for (const r of ranges) for (let i = r.start + 1; i < r.start + r.span; i++) skip.add(`${i}:${mergeKey}`);
  return rows.map((row, i) => ({
    row,
    cell: skip.has(`${i}:${mergeKey}`) ? null                                  // skip：被 rowspan 吞
      : { rowspan: ranges.find((r) => r.start === i)?.span ?? 1, value: row[mergeKey] },
  }));
}
// 前提：rows 已按 mergeKey 排序（相同值相邻）—— 服务端排序或前端 group 后再排
// 多列嵌套合并：外列（客户）段内再扫内列（订单）—— 段范围作为内列扫描边界
// a11y：rowspan 合并的单元格加 scope="rowgroup" —— 读屏仍能理解分组关系
```

**评分点**：
- 连续段扫描（mergeRanges）与 skip 集合的渲染配合——本题核心。
- 排序前提（相同值相邻）的显式声明。
- 多列嵌套合并的扩展（段内递归）。
- a11y scope 属性意识。
