## ALG-374：手写珂朵莉树（区间推平思想）：染色区间合并场景

**答**：
- 题目：一段 ID 区间被反复「整段染成颜色 X」，查某 ID 的颜色。区间推平操作频繁且随机——珂朵莉树（Chtholly Tree）：用有序集合维护「段」（相同值的连续区间），推平 = 删除被覆盖段 + 插入一段。
- 思路：数据结构 = Map（按段起点有序）；assign(l, r, v) 删除起于 [l,r] 内的段、截断跨界段、插入新段。复杂度均摊 O((n+q) log n)——依赖「随机数据下段数少」。
- 评分点：段（interval）表示；推平操作删段逻辑；均摊复杂度前提（随机性）。

```javascript
class ChthollyTree {
  constructor(n) { this.segments = new Map([[1, { end: n, v: 0 }]]); }   // start -> {end, v}
  split(pos) {                                             // 在 pos 处切断
    if (pos > 1e9) return null;
    let key = null;
    for (const [s, seg] of this.segments) if (s <= pos && seg.end >= pos) { key = s; break; }
    if (!key || key === pos) return key;
    const seg = this.segments.get(key);
    this.segments.set(pos, { end: seg.end, v: seg.v });    // 后半段
    seg.end = pos - 1;                                     // 前半段截断
    return pos;
  }
  assign(l, r, v) {                                        // 区间推平
    this.split(r + 1); this.split(l);
    for (const [s, seg] of [...this.segments])
      if (s >= l && seg.end <= r) this.segments.delete(s); // 删被覆盖段
    this.segments.set(l, { end: r, v: v });                // 插入新段
  }
  color(id) {
    for (const [s, seg] of this.segments)
      if (s <= id && id <= seg.end) return seg.v;
    return 0;
  }
}
```
