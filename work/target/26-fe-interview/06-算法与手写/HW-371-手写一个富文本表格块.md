## HW-371：手写一个富文本表格块：块级表格的编辑与方向键逃逸

**答**：
- 需求：实现 TableBlock：表格作为一个 block（数据：rows×cells，cell 为内联内容）；编辑：单元格内输入、Tab/Shift+Tab 移动、方向键在单元格边界时"逃逸"到表格外 block（上下键在首行/末行）；行列增删（右键菜单操作）；表格与前后 block 的选区衔接。
- 边界：逃逸语义（首行上键 → 焦点到表格前 block 末尾；末行下键 → 后 block 开头）；单元格内换行（Shift+Enter 软换行 vs Enter 逃逸可配）；行列删除时选区钳制。
- 评分点：逃逸方向语义；软换行区分；选区衔接。

```javascript
class TableBlock {
  constructor(doc, blockId) { this.doc = doc; this.id = blockId; }
  get table() { return this.doc.byId(this.id).data; }
  moveCell(dr, dc) {                                        // 表格内导航
    const { r, c } = this.cursor;
    const nr = r + dr, nc = c + dc;
    if (nc < 0 || nc >= this.table.cols) return null;       // 左右到边界：交给外部（左右逃逸）
    if (nr < 0) return { escape: 'before' };                // 首行上键：逃逸到前 block
    if (nr >= this.table.rows) return { escape: 'after' };  // 末行下键：逃逸
    this.cursor = { r: nr, c: clamp(nc, 0, this.table.cols - 1) };
    return { pos: this.cellCursor(nr, nc) };
  }
  onKey(e) {
    if (e.key === 'Tab') { e.preventDefault(); return this.moveCell(0, e.shiftKey ? -1 : 1); }
    if (e.key === 'Enter' && !e.shiftKey)                   // Enter 逃逸 vs Shift+Enter 软换行
      return this.moveCell(1, 0);
    if (e.key === 'Enter' && e.shiftKey) { this.insertCellText('\n'); return 'soft-break'; }
    return 'normal';
  }
  insertRow(at, refRow) {                                    // 行列增删
    const t = this.table;
    t.rows++;
    t.cells.splice(at, 0, Array.from({ length: t.cols },
      () => ({ text: '', marks: [], style: refRow?.style })));   // 继承参考行样式
    this.cursor = { r: at, c: 0 };                           // 选区钳制到新行
  }
  removeRow(at) {
    const t = this.table;
    if (t.rows <= 1) return false;
    t.cells.splice(at, 1); t.rows--;
    this.cursor = { r: Math.min(at, t.rows - 1), c: this.cursor.c };
    return true;
  }
  cellCursor(r, c) { return { blockId: this.id, cell: { r, c }, offset: 0 }; }
}
const clamp = (v, lo, hi) => Math.max(lo, Math.min(hi, v));
```
