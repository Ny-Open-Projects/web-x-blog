**场景**：HW-063 单请求重试 + PER-328 全局并发限制之外，还需"周期预算"：页面生命周期内总重试次数上限（如 20 次）——超预算的失败转"显式人工重试"（按钮），防止重试风暴耗电+打服务端。

**思路**：预算计数器（页面级）→ 每次自动重试扣减 → 预算耗尽后 reject 带需要人工重试标记 → 用户点击重试重置小预算。

```javascript
class RetryBudget {
  #left; #periodStart = Date.now();
  constructor({ total = 20, refillPerMin = 5 } = {}) { this.total = total; this.#left = total; this.refillPerMin = refillPerMin; }
  canRetry() {
    // 时间桶回填：每分钟回 5 点（滚动恢复，不是一次性重置）
    const elapsedMin = (Date.now() - this.#periodStart) / 60000;
    this.#left = Math.min(this.total, this.#left + Math.floor(elapsedMin * this.refillPerMin));
    this.#periodStart = Date.now();
    return this.#left > 0;
  }
  spend() { this.#left--; return this.#left; }
}
async function fetchWithBudget(url, budget, opts) {
  for (let i = 0; ; i++) {
    try { return await fetch(url, opts).then(assertOk); }
    catch (e) {
      if (!budget.canRetry()) throw Object.assign(e, { manualRetry: true });   // 预算耗尽：转人工
      budget.spend();
      await sleep(500 * 2 ** i);
    }
  }
}
// 预算语义：
// 正常波动：预算够（20 次覆盖偶发失败）—— 用户无感
// 服务端故障：预算耗尽 → 停止自动重试（manualRetry 标记）→ UI 出重试按钮（人工节奏可控）
// 时间桶回填：恢复后预算自动回升（不需要刷新页面）—— 滚动恢复语义
// 与 HW-063/PER-328 的层级：单请求退避 → 全局并发 → 周期预算（三层防风暴）
```

**评分点**：
- 周期预算制（超预算转人工）——本题核心（三层防风暴的第三层）。
- 时间桶回填（滚动恢复）。
- manualRetry 标记驱动 UI（显式人工重试）。
- 三层防风暴体系（退避/并发/预算）的完整叙事。
