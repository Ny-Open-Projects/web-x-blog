**答**：三层防线：① Error Boundary 捕获渲染错误（class 组件 componentDidCatch/getDerivedStateFromError），展示降级 UI；② chunk 加载失败（动态 import reject，多是发版后旧 hash 404）→ 自动重载一次最新页面（location.reload 带 sessionStorage 标记防循环）；③ 重试计数——手动重试按钮 + 指数退避自动重试一次。注意 EB 不能捕获事件 handler/异步错误（那是 onerror/unhandledrejection 的职责）。

```jsx
import React from 'react';

class ErrorBoundary extends React.Component {
  state = { error: null, retries: 0 };
  static getDerivedStateFromError(error) { return { error }; }
  componentDidCatch(error, info) {
    report({ type: 'render-error', msg: String(error), stack: info.componentStack });
    // chunk 加载失败特征：Failed to fetch dynamically imported module / Loading chunk N failed
    if (/import|chunk/i.test(String(error)) && !sessionStorage.getItem('reloaded')) {
      sessionStorage.setItem('reloaded', '1');
      location.reload();                       // 发版后旧 chunk 404：整页刷新拿最新
    }
  }
  retry = () => {
    if (this.state.retries >= 2) return;       // 最多手动重试 2 次
    this.setState((s) => ({ error: null, retries: s.retries + 1 }));
  };
  render() {
    if (this.state.error) return (
      <div role="alert">
        <p>页面出错，请重试</p>
        <button onClick={this.retry}>重试{this.state.retries ? `（已 ${this.state.retries} 次）` : ''}</button>
      </div>
    );
    return this.props.children;
  }
}
// 全局兜底（EB 覆盖不到的异步错误）：
window.addEventListener('unhandledrejection', (e) => {
  report({ type: 'unhandled-rejection', msg: String(e.reason) });
});
// 用法：<ErrorBoundary><Suspense fallback={<Skeleton />}><LazyPage /></Suspense></ErrorBoundary>
```

**评分点**：
- EB 两个 API（getDerivedStateFromError 渲染降级 UI、componentDidCatch 副作用上报）职责分清。
- chunk 失败识别（正则）+ reload 防循环标记（sessionStorage）——发版 404 场景的关键。
- 手动重试上限；EB 覆盖边界明确说清（不捕异步/handler 错误）。
- 上报带 componentStack 便于定位组件树。
