## ALG-376：手写线段树区间等差数列赋值：刻度批量生成

**答**：
- 题目：坐标轴刻度批量设置：区间 [l, r] 设为等差数列（首项 a、公差 d），随后查任意点值。懒标记存 (first, d)。
- 思路：下推时左子 = (first, d)，右子 = (first + d * 左长, d)；和值可按等差求和公式 O(1) 算。查单点沿路径累计偏移。
- 评分点：右子首项偏移 = d × 左长；等差求和公式；标记 (first, d) 结构。

```javascript
class ArithTree {
  constructor(n) { this.n = n;
    this.val = new Array(4 * n).fill(0);
    this.lazy = new Array(4 * n).fill(null);               // {a, d}
  }
  pushdown(node, l, r) {
    const mk = this.lazy[node];
    if (!mk) return;
    const m = (l + r) >> 1;
    this.setLeaf(node * 2, mk.a, m - l + 1);               // 左子：首项 a
    this.setLeaf(node * 2 + 1, mk.a + mk.d * (m - l + 1), mk.d, r - m);   // 右子偏移
    this.lazy[node] = null;
  }
  setLeaf(node, a, d, len) {
    if (len === 1) this.val[node] = a;
    this.lazy[node] = { a, d };
  }
  assign(ql, qr, a, d, node = 1, l = 0, r = this.n - 1) {
    if (qr < l || r < ql) return;
    if (ql <= l && r <= qr) { this.setLeaf(node, a + d * (l - ql), d, r - l + 1); return; }   // 局部首项偏移
    this.pushdown(node, l, r);
    const m = (l + r) >> 1;
    this.assign(ql, qr, a, d, node * 2, l, m);
    this.assign(ql, qr, a, d, node * 2 + 1, m + 1, r);
  }
  get(i, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.lazy[node]?.a ?? this.val[node];   // 叶子取首项
    this.pushdown(node, l, r);
    const m = (l + r) >> 1;
    return i <= m ? this.get(i, node * 2, l, m) : this.get(i, node * 2 + 1, m + 1, r);
  }
}
```
