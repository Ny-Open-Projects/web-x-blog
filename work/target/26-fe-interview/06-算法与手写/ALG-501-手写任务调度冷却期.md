## ALG-501：手写任务调度冷却期：API 调用间隔

**答**：
- 题目：任务流（同类型任务不能连续执行，需间隔 cooldown），求完成所有任务的最短时间。经典「任务调度器」公式：max(任务数, (最大频次-1)×(cooldown+1) + 最大频次任务数)。
- 思路：频次统计；瓶颈 = 最高频任务的间隔框架；公式推导与执行序模拟两种给法。
- 评分点：公式记忆与推导；并列最高频的处理；空闲填充的直觉。

```javascript
function leastInterval(tasks, cooldown) {                  // 最短总时间
  const freq = new Map();
  for (const t of tasks) freq.set(t, (freq.get(t) ?? 0) + 1);
  const counts = [...freq.values()].sort((a, b) => b - a);
  const maxFreq = counts[0];
  const maxCount = counts.filter(c => c === maxFreq).length;   // 并列最高频任务数
  // 公式：框架 = (maxFreq-1)×(cooldown+1) + maxCount，任务多时任务数即答案
  return Math.max(tasks.length, (maxFreq - 1) * (cooldown + 1) + maxCount);
}
// 例：tasks=[A,A,A,B,B,B], cooldown=2 → (3-1)×3 + 2 = 8
// 模拟法：优先堆每轮取 cooldown+1 个不同任务——两者结果一致
```
