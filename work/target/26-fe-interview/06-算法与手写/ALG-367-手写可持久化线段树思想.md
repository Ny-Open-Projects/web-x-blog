## ALG-367：手写可持久化线段树思想：历史版本区间查询

**答**：
- 题目：配置变更历史（每次单点改一个键），要查「第 k 次变更后」某区间的值。可持久化：每个版本只新建修改路径上的节点（O(log n) 新节点），其余共享。
- 思路：update 返回新根（复用未改子树引用）；版本数组 roots[i]；查询第 k 版直接用 roots[k] 做普通区间查询。
- 评分点：路径复制（path copying）；共享子树引用；版本数组管理。

```javascript
class PersistentSegTree {
  constructor(base) { this.n = base.length;
    this.roots = [this.build(base)]; }                     // 版本 0
  build(a, l = 0, r = this.n - 1) {
    if (l === r) return { val: a[l], l: null, r: null };
    const m = (l + r) >> 1;
    return { l: this.build(a, l, m), r: this.build(a, m + 1, r),
      val: 0 };                                            // 可存区间和
  }
  update(version, i, v, node = this.roots[version], l = 0, r = this.n - 1) {
    if (l === r) return { val: v, l: null, r: null };      // 新叶子
    const m = (l + r) >> 1;
    const nn = { ...node };                                // 复制当前节点
    if (i <= m) nn.l = this.update(version, i, v, node.l, l, m);   // 只复制路径
    else nn.r = this.update(version, i, v, node.r, m + 1, r);
    return nn;
  }
  commit(version, i, v) { this.roots.push(this.update(version, i, v)); }
  query(version, ql, qr) {                                 // 任意历史版本查询
    return this._q(this.roots[version], ql, qr, 0, this.n - 1);
  }
  _q(node, ql, qr, l, r) {
    if (!node || qr < l || r < ql) return null;
    if (ql <= l && r <= qr) return node.val;
    const m = (l + r) >> 1;
    return this._q(node.l, ql, qr, l, m) ?? this._q(node.r, ql, qr, m + 1, r);
  }
}
```
