**场景**：头部阴影/进度条/埋点/懒加载都各自 addEventListener('scroll')——4 个 handler 各自读 scrollTop 触发 4 次布局读取。合并：单一 scroll 入口（rAF 合帧）+ 监听器注册表，一次读取状态分发给所有订阅者。

**思路**：ScrollHub 单监听 + rAF 合帧；订阅者按优先级执行；一次读取 scrollTop 传给所有订阅者（避免每个 handler 各读一次布局）。

```javascript
class ScrollHub {
  constructor(container) {
    Object.assign(this, { container, subs: new Map(), scheduled: false });
    container.addEventListener('scroll', () => this.#schedule(), { passive: true });
  }
  subscribe(key, fn, { priority = 0 } = {}) {         // 返回取消函数
    this.subs.set(key, { fn, priority });
    return () => this.subs.delete(key);
  }
  #schedule() {
    if (this.scheduled) return;
    this.scheduled = true;
    requestAnimationFrame(() => {
      this.scheduled = false;
      const scrollTop = this.container.scrollTop;     // 一次读取，全订阅者共享
      const subs = [...this.subs.values()].sort((a, b) => b.priority - a.priority);
      for (const { fn } of subs) {
        try { fn(scrollTop); } catch (e) { console.error('[scroll-hub]', e); }   // 单订阅者失败不炸其他
      }
    });
  }
}
// 用法：4 个功能共用一个 hub
const hub = new ScrollHub(container);
hub.subscribe('header', (st) => header.classList.toggle('compact', st > 60), { priority: 10 });
hub.subscribe('progress', (st) => bar.style.width = st / max * 100 + '%', { priority: 5 });
hub.subscribe('track', debounce((st) => track('scroll-depth', st), 1000), { priority: 0 });
// 收益：4 次 scroll 监听 + 4 次布局读取 → 1 次监听 + 1 次读取（rAF 合帧）
// 优先级：视觉反馈类（header/progress）先执行，埋点类最后且可被 idle 化
```

**评分点**：
- 单监听入口 + 注册表分发（N 个 handler 合 1）——本题核心。
- 一次读取 scrollTop 共享（避免多次布局读取，读写交错源头）。
- rAF 合帧 + passive + 优先级排序（视觉优先、埋点殿后）。
- 单订阅者失败隔离（try-catch）与取消函数 API。
