## HW-083：手写漏桶限流器——恒定速率漏出 + 溢出拒绝
**答**：漏桶：请求进桶排队/计数，以恒定速率"漏出"执行，桶满则拒绝（或等待）。与令牌桶相反：令牌桶允许突发、漏桶削峰整形（恒定输出速率）。实现要点：惰性计算水位（按时间差漏出）、桶满返回 false 或排队。

```javascript
class LeakyBucket {
  constructor({ rate = 10, capacity = 20 } = {}) {   // rate: 每秒漏出数
    Object.assign(this, { rate, capacity, water: 0, last: performance.now() });
  }
  #leak(now) {                                        // 惰性漏水
    const elapsed = (now - this.last) / 1000;
    this.water = Math.max(0, this.water - elapsed * this.rate);
    this.last = now;
  }
  tryAdd() {                                          // 尝试入桶：不排队版本
    const now = performance.now();
    this.#leak(now);
    if (this.water + 1 > this.capacity) return false; // 桶满拒绝（削峰）
    this.water += 1;
    return true;
  }
  async add({ queue = false } = {}) {                 // 排队版本：等漏出腾位
    for (;;) {
      if (this.tryAdd()) return;
      if (!queue) throw new Error('限流拒绝');
      await new Promise((r) => setTimeout(r, 1000 / this.rate));  // 一个漏出周期
    }
  }
}
// 对比：
// 令牌桶：桶里"空位"决定通过，允许 burst（瞬时多放）
// 漏桶：桶里"水位"决定拒绝，输出恒定 —— 适合保护脆弱下游（如第三方 API）
const bucket = new LeakyBucket({ rate: 5, capacity: 10 });
setInterval(() => { if (!bucket.tryAdd()) console.warn('dropped'); }, 50); // 20/s 输入，5/s 输出 => 会丢
```

**评分点**：
- 惰性漏水（时间差计算）而非定时器，正确且无泄漏。
- tryAdd 原子语义（检查+入桶一步完成）；排队版本给等待选项。
- 能对比漏桶（恒速整形）与令牌桶（允许突发）的适用场景。
- 容量满即拒绝，不无限堆积。
