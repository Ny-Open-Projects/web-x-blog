## HW-385：手写一个编辑器插件架构：扩展点设计与沙箱加载

**答**：
- 需求：实现 EditorPluginHost：扩展点（toolbar 按钮/快捷键/块类型/序列化器）；插件注册声明扩展点使用；沙箱：插件拿到的 API 是代理（可访问方法白名单，禁止访问 doc 原始引用）；版本与依赖；禁用/启用热切换。
- 边界：API 代理白名单（getOwnPropertyDescriptor 拦截）；块类型扩展（新 block type 注册渲染与序列化）；热禁用时注销快捷键与 UI。
- 评分点：代理白名单沙箱；扩展点注册表；热切换注销。

```javascript
class EditorPluginHost {
  constructor(editor) {
    this.ed = editor; this.plugins = new Map();
    this.extensions = { toolbar: [], keys: new Map(), blocks: new Map(), serializers: new Map() };
  }
  sandboxAPI(pluginName) {                                   // 沙箱代理
    const ALLOW = ['insertBlock', 'getSelection', 'onChange', 'registerCommand', 'getDocText'];
    return new Proxy(this.ed, {
      get(target, prop) {
        if (typeof prop === 'symbol' || !ALLOW.includes(prop))
          throw new Error(`plugin ${pluginName}: api "${String(prop)}" not allowed`);   // 白名单拦截
        const v = target[prop];
        return typeof v === 'function' ? v.bind(target) : v;
      },
    });
  }
  register(plugin) {
    const api = this.sandboxAPI(plugin.name);
    plugin.setup(api);                                       // 插件声明扩展点
    this.plugins.set(plugin.name, { plugin, disposers: plugin.__disposers ?? [] });
  }
  disable(name) {                                            // 热禁用：注销
    const entry = this.plugins.get(name);
    if (!entry) return;
    entry.disposers.forEach(d => d());                       // 注销快捷键/UI
    for (const [k, v] of this.extensions.keys) if (v === name) this.extensions.keys.delete(k);
    this.plugins.delete(name);
  }
  registerBlock(type, { render, serialize, parse }) {
    this.extensions.blocks.set(type, { render, serialize, parse, owner: this.current });
    this.ed.onSerialize?.(node => node.type === type
      ? serialize(node) : undefined);                        // 序列化扩展点
  }
}
```
