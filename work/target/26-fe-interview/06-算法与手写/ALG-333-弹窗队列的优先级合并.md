**场景**：登录后三个弹窗同时触发（升级提示/运营公告/客服邀请）——弹窗风暴体验灾难。队列：优先级排序（安全类 > 升级 > 运营）+ 同类合并（两个公告合并展示）+ 关闭后出队下一个（间隔 500ms 防闪）。

**思路**：入队（优先级 + 同类 key 合并）→ 当前无弹窗时出队展示 → 关闭事件出队下一个（防抖间隔）。

```javascript
class ModalQueue {
  #q = []; #current = null;
  #PRIORITY = { security: 10, upgrade: 5, announce: 3, chat: 2 };
  push(modal) {
    const existing = this.#q.find((m) => m.key === modal.key);
    if (existing) { existing.content = modal.content; return; }   // 同类合并（更新内容不重复入队）
    this.#q.push(modal);
    this.#q.sort((a, b) => (this.#PRIORITY[b.type] ?? 0) - (this.#PRIORITY[a.type] ?? 0));
    this.#next();
  }
  #next() {
    if (this.#current || !this.#q.length) return;
    setTimeout(() => {                                    // 500ms 间隔：关闭后不闪现下一个
      const modal = this.#q.shift();
      this.#current = modal;
      modal.show(() => { this.#current = null; this.#next(); });   // 关闭回调：出队下一个
    }, this.#current ? 500 : 0);
  }
}
// 同类合并：两个公告 key=announce → 内容更新为一个（用户只看到最新公告）
// 优先级语义：安全类（强制改密）> 升级 > 运营—— 打断权的分级
// 500ms 间隔：关闭→下一个的呼吸感（瞬间弹下一个像 bug）
// 队列可持久化（sessionStorage）—— 刷新后未展示的弹窗不丢（运营弹窗不因刷新消失）
```

**评分点**：
- 优先级排序 + 同类合并 + 关闭出队的队列机——本题核心。
- 打断权分级（安全 > 升级 > 运营）。
- 500ms 呼吸间隔。
- 会话持久化（刷新不丢未展示弹窗）。
