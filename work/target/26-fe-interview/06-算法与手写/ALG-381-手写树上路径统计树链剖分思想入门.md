## ALG-381：手写树上路径统计（树链剖分思想入门）：组织层级统计

**答**：
- 题目：组织架构树（每人一个绩效分），查「某人到 CEO 路径上的绩效和」。树链剖分入门：DFS 序 + 重链剖分，路径拆成 O(log n) 段区间用线段树/BIT 维护。
- 思路：① 求 DFS 序（子树连续）；② 重儿子/轻边分类；③ 路径查询 = 沿重链跳，每跳一段用区间查询。入门版可只讲思想 + 子树查询（DFS 序 + BIT 即可）。
- 评分点：DFS 序使子树连续；重链跳段；完整剖分复杂度 O(log^2 n)。

```javascript
class TreeQuery {                                          // 子树和：DFS 序 + BIT
  constructor(tree, vals, root = 0) {
    this.n = tree.length;
    this.tin = new Array(this.n); this.tout = new Array(this.n);
    this.timer = 0;
    this.dfs(tree, root, -1);
    this.bit = new Array(this.n + 1).fill(0);
    for (let v = 0; v < this.n; v++) this.bitAdd(this.tin[v], vals[v]);   // 按 DFS 序插入
  }
  dfs(tree, u, parent) {
    this.tin[u] = this.timer++;
    for (const v of tree[u]) if (v !== parent) this.dfs(tree, v, u);
    this.tout[u] = this.timer - 1;                         // 子树 = [tin, tout]
  }
  bitAdd(i, v) { for (i++; i <= this.n; i += i & -i) this.bit[i] += v; }
  bitSum(i) { let s = 0; for (i++; i > 0; i -= i & -i) s += this.bit[i]; return s; }
  updateNode(v, val) { this.bitAdd(this.tin[v], val); }     // 单点改
  subtreeSum(v) { return this.bitSum(this.tout[v]) - this.bitSum(this.tin[v] - 1); }   // 子树和
}
// 路径查询（u 到 root）：完整树链剖分将路径拆为重链段，每段做上述区间查询
```
