## HW-387：手写一个快捷键冲突检测与映射管理

**答**：
- 需求：实现 KeymapManager：快捷键注册（combo → handler，作用域：全局/编辑器/表格）；冲突检测（注册时同 combo 已被占用 → 报冲突并给出占用者，可强制覆盖或拒绝）；作用域优先级（越内层越优先，栈式）；导出/导入映射表（用户自定义持久化）。
- 边界：combo 归一化（Mod 兼容平台、排序修饰键）；作用域栈（focus 变化切换）；冲突检测含通配（如 Mod-K 前缀占用提示）。
- 评分点：冲突检测与仲裁；作用域栈；归一化。

```javascript
class KeymapManager {
  constructor() { this.scopes = new Map(); this.scopeStack = ['global']; }
  normalize(combo) {                                         // 归一化
    const parts = combo.toLowerCase().split('-');
    const mods = parts.filter(p => ['mod', 'ctrl', 'alt', 'shift'].includes(p)).sort();
    const key = parts.at(-1);
    return [...mods, key].join('-');
  }
  bind(combo, handler, { scope = 'global', force = false } = {}) {
    const norm = this.normalize(combo);
    const map = this.scopes.get(scope) ?? this.scopes.set(scope, new Map()).get(scope);
    const existing = [...this.scopes.entries()]
      .find(([, m]) => m.has(norm) && m.get(norm).scope !== scope);
    if (existing && !force)
      throw new Error(`keymap-conflict: ${norm} occupied by scope "${existing[0]}"`);   // 冲突检测
    map.set(norm, { handler, scope, raw: combo });
  }
  dispatch(e) {                                              // 作用域栈优先
    const combo = this.normalize(eventToCombo(e));
    for (let i = this.scopeStack.length - 1; i >= 0; i--) {  // 内层优先
      const map = this.scopes.get(this.scopeStack[i]);
      const entry = map?.get(combo);
      if (entry) { e.preventDefault(); entry.handler(e); return true; }
    }
    return false;
  }
  pushScope(name) { this.scopeStack.push(name); }            // focus 变化切换
  popScope() { if (this.scopeStack.length > 1) this.scopeStack.pop(); }
  export() {                                                 // 用户自定义持久化
    const out = {};
    for (const [scope, map] of this.scopes)
      for (const [norm, e] of map) out[`${scope}:${norm}`] = e.raw;
    return out;
  }
  import(data) { for (const [k, raw] of Object.entries(data)) {
    const [scope, norm] = k.split(':');
    this.scopes.get(scope)?.set(norm, { handler: null, scope, raw }); } }
}
function eventToCombo(e) {
  const mac = /Mac|iPhone|iPad/.test(navigator.platform || '');
  const mods = [mac ? e.metaKey && 'mod' : e.ctrlKey && 'mod', mac && e.ctrlKey && 'ctrl',
    e.altKey && 'alt', e.shiftKey && 'shift'].filter(Boolean);
  return [...mods, e.key.toLowerCase()].join('-');
}
```

## 补充：评分点与变体

**评分点**：

- normalize 要排序修饰键得到规范形式（Ctrl+Shift+K 与 Shift+Ctrl+K 等价），并把 Mod 解析为当前平台键
- 作用域用栈管理，focus 变化时 push/pop，dispatch 从栈顶向下找第一个命中，内层优先才成立
- 冲突检测在 bind 时做并返回占用者，只报「已存在」不给是谁占用，用户无法决策
- 前缀冲突（Mod-K 与 Mod-K-S）要单独提示，完全相等与前缀包含是两类冲突

**变体与延伸**：

1. 输入框里不该触发全局快捷键 → dispatch 前查 activeElement 是否 input 或 contenteditable，或在作用域上声明 ignoreInInput
2. 用户要覆盖内置映射 → 分三层 keymap（用户 > 插件 > 内置），查找自上而下，导出只导用户层
3. 撞上浏览器保留键（Ctrl+W）→ preventDefault 可能无效，注册时给出警示并建议换键而不是静默失败
