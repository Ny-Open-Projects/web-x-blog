**场景**：白板上有 1 万个图形元素，平移缩放时只渲染视口内的——O(n) 遍历判定每次移动都做也慢，需要空间索引（均匀网格）加速到 O(视口内元素数)。

**思路**：元素按包围盒注册进网格 cell（cellSize=256）；视口矩形 → 覆盖的 cell 集合 → 取 cell 内元素（Set 去重跨界元素）→ 渲染。移动/缩放只重算 cell 集合。

```javascript
class SpatialGrid {
  constructor(cellSize = 256) { Object.assign(this, { cellSize, cells: new Map() }); }
  #key(cx, cy) { return `${cx},${cy}`; }
  insert(item, { x, y, w, h }) {                      // item 包围盒注册到覆盖的所有 cell
    const c = this.cellSize;
    for (let cx = Math.floor(x / c); cx <= Math.floor((x + w) / c); cx++)
      for (let cy = Math.floor(y / c); cy <= Math.floor((y + h) / c); cy++) {
        const k = this.#key(cx, cy);
        (this.cells.get(k) ?? this.cells.set(k, new Set()).get(k)).add(item);
      }
    this.bounds = new Map();                          // item -> bounds（查询用）
    this.bounds.set(item, { x, y, w, h });
  }
  query({ x, y, w, h }) {                             // 视口查询：O(覆盖 cell 数 × 平均元素数)
    const c = this.cellSize, out = new Set();
    for (let cx = Math.floor(x / c); cx <= Math.floor((x + w) / c); cx++)
      for (let cy = Math.floor(y / c); cy <= Math.floor((y + h) / c); cy++)
        for (const item of this.cells.get(this.#key(cx, cy)) ?? []) out.add(item);
    // 跨界元素去重（Set）+ 精确包围盒相交判定过滤（cell 级粗筛后的细筛）
    return [...out].filter((it) => {
      const b = this.bounds.get(it);
      return b.x < x + w && b.x + b.w > x && b.y < y + h && b.y + b.h > y;
    });
  }
}
// 1 万元素 O(n) 逐个判定 → 网格索引 O(视口 cell 数 × 密度)，平移每帧 < 2ms
// 移动元素时：先从旧 cell 移除再插入新 cell（更新索引）；缩放只改视口查询参数不动索引
```

**评分点**：
- 空间网格索引（cellSize 均匀网格）与视口 cell 查询——本题核心。
- 跨界元素的 Set 去重 + 包围盒精确二次判定（粗筛+细筛两级）。
- 复杂度对比：O(n) 全扫 vs O(视口覆盖)。
- 元素移动时索引更新的意识。
