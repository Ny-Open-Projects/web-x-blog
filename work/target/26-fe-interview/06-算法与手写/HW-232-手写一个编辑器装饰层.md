## HW-232：手写一个编辑器装饰层：行内高亮与下划线的定位渲染

**答**：
- 需求：实现 DecorationLayer：add({blockId, start, end, className})（独立于文档数据，不参与 undo）；render(block) 依据 decorations + marks 计算分段 span（装饰与样式共存时叠加 class）；同一区间多个装饰合并渲染（class 拼接）。
- 边界：装饰随文档编辑自动失效（基于位置，编辑后需按 diff 平移——简化版：编辑发生时清空该 block 装饰）；class 名白名单防注入。
- 评分点：与数据 marks 解耦；分段合并渲染；失效策略。

```javascript
class DecorationLayer {
  constructor() { this.items = new Map(); }                    // blockId -> [deco]
  add(d) {
    if (!/^[\w-]+$/.test(d.className)) throw new Error('bad-class');   // 白名单
    const arr = this.items.get(d.blockId) ?? [];
    arr.push(d); this.items.set(d.blockId, arr);
  }
  clear(blockId) { this.items.delete(blockId); }
  clearAll() { this.items.clear(); }
  render(block) {                                              // 装饰 + marks 合并分段
    const decos = this.items.get(block.id) ?? [];
    const cuts = [...new Set(
      [...decos.flatMap(d => [d.start, d.end]),
       ...block.marks.flatMap(m => [m.start, m.end])])].sort((a, b) => a - b);
    let html = '', i = 0;
    for (const c of cuts) {
      if (c > i) {
        const seg = block.text.slice(i, c);
        const cls = [
          ...block.marks.filter(m => m.start <= i && c <= m.end).map(m => 'mk-' + m.type),
          ...decos.filter(d => d.start <= i && c <= d.end).map(d => d.className),
        ].join(' ');
        html += cls ? `<span class="${cls}">${esc(seg)}</span>` : esc(seg);
        i = c;
      }
    }
    return html + esc(block.text.slice(i));
  }
  onEdit(blockId) { this.clear(blockId); }                     // 编辑后失效（简化策略）
}
```
