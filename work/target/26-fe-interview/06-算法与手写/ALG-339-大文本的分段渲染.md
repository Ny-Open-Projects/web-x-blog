## ALG-339：长文分段渲染：按段落切块 + 视口附近渲染 + 段落锚点（content-visibility 的工程化补充）？
**答**：10 万字长文（小说/协议）：一次渲染 = 整段 Layout（整形成本 PER-436）——按段落切块渲染 + content-visibility（屏外跳过）+ 段落锚点（进度定位：60% 处 = 段落 N，前缀高度和）。

**思路**：分块（按段落 split）→ 每块独立容器（content-visibility: auto）→ 锚点定位（块索引 × 块高估算 + 微调）。

```javascript
function renderLongText(text, container) {
  const paragraphs = text.split(/\n{2,}/);                // 按段落切块（天然渲染单元）
  const frag = document.createDocumentFragment();
  paragraphs.forEach((p, i) => {
    const div = document.createElement('div');
    div.dataset.para = i;
    div.textContent = p;
    div.style.cssText = 'content-visibility:auto;contain-intrinsic-size:auto 200px;';   // 屏外跳过（PER-346）
    frag.append(div);
  });
  container.append(frag);
}
function jumpToRatio(container, ratio) {                  // 进度定位：60% → 段落锚点
  const blocks = container.children;
  const target = Math.floor(ratio * blocks.length);
  const el = blocks[target];
  el.scrollIntoView({ block: 'start' });
  el.style.containIntrinsicSize = 'auto 500px';           // 目标块提前给大高度（减少定位跳动）
}
// content-visibility：10 万字屏外 95% 跳过 Layout/整形（PER-436 整形成本的直接对策）
// contain-intrinsic-size：占位高度（块高估算——首块实测后校准均值）
// 段落锚点：进度条 60% → 块索引（前缀高度近似 + 渲染后微调——动态高度块的双阶段定位 HW-103 同源）
// 分块粒度：段落（天然语义边界）—— 按 fix 字节切会切断句子（搜索/复制体验破坏）
```

**评分点**：
- 按段落分块 + content-visibility 跳过屏外整形成本——本题核心（PER-436 对策）。
- contain-intrinsic-size 占位与校准。
- 进度锚点（ratio → 块索引 → 微调）双阶段。
- 段落语义边界的分块粒度选择。
