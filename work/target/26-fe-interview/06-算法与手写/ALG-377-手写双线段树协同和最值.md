## ALG-377：手写双线段树协同（和+最值）：流量洪峰峰值与总量

**答**：
- 题目：监控大盘同屏显示「窗口内总流量」与「峰值流量」——两棵线段树（sum/max）同步更新，或一棵树双字段。演示双字段版本与双树版本的取舍。
- 思路：双字段：节点 {sum, max}，合并各自算，一次遍历两得；双树：职责清晰、便于懒标记不同（sum 需 len、max 不需）但两次遍历。有复杂懒标记时拆双树更清晰。
- 评分点：双字段合并公式；双树拆分的标记差异（len 参与）；按标记复杂度取舍。

```javascript
class SumMaxTree {
  constructor(a) { this.n = a.length;
    this.t = new Array(4 * this.n); this.build(a); }
  build(a, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.t[node] = { sum: a[l], max: a[l] };
    const m = (l + r) >> 1;
    this.build(a, node * 2, l, m); this.build(a, node * 2 + 1, m + 1, r);
    this.pull(node);
  }
  pull(node) {
    this.t[node] = {
      sum: this.t[node * 2].sum + this.t[node * 2 + 1].sum,
      max: Math.max(this.t[node * 2].max, this.t[node * 2 + 1].max),
    };
  }
  set(i, v, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.t[node] = { sum: v, max: v };
    const m = (l + r) >> 1;
    i <= m ? this.set(i, v, node * 2, l, m) : this.set(i, v, node * 2 + 1, m + 1, r);
    this.pull(node);
  }
  stats(ql, qr, node = 1, l = 0, r = this.n - 1) {         // 一次查询双指标
    if (qr < l || r < ql) return { sum: 0, max: -Infinity };
    if (ql <= l && r <= qr) return this.t[node];
    const m = (l + r) >> 1;
    const a = this.stats(ql, qr, node * 2, l, m), b = this.stats(ql, qr, node * 2 + 1, m + 1, r);
    return { sum: a.sum + b.sum, max: Math.max(a.max, b.max) };
  }
}
```
