**场景**：树形数据缓存（每节点聚合值如"子树任务数"）：更新叶子节点 → 父链聚合失效——级联失效最小化：只失效受影响的祖先链（ALG-223 局部更新的缓存版），兄弟子树缓存保留。

**思路**：节点缓存 Map（id→聚合值）+ dirty 集 → 更新叶子：沿父链标 dirty → 惰性重算（读取时 dirty 才算，算完清除）——写 O(depth)、读摊销 O(1)。

```javascript
class TreeAggCache {
  #cache = new Map(); #dirty = new Set(); #parentOf = new Map();
  updateLeaf(leafId, value) {                             // 叶子更新：沿父链标脏（O(depth)）
    this.#cache.set(leafId, value);
    let p = this.#parentOf.get(leafId);
    while (p) { this.#dirty.add(p); p = this.#parentOf.get(p); }
  }
  aggregate(nodeId, { countChildren = (n) => n.children?.length ?? 0 } = {}) {   // 惰性重算
    if (!this.#dirty.has(nodeId) && this.#cache.has(nodeId)) return this.#cache.get(nodeId);   // 缓存命中
    const node = this.#nodes.get(nodeId);
    const value = countChildren(node) +
      (node.children ?? []).reduce((s, c) => s + this.aggregate(c), 0);   // 子递归（命中子树缓存）
    this.#cache.set(nodeId, value);
    this.#dirty.delete(nodeId);
    return value;
  }
  constructor(nodes, parentOf) { this.#nodes = nodes; this.#parentOf = parentOf; }
}
// 写 O(depth)（父链标脏）、读摊销 O(1)（命中缓存）—— 1000 节点树改 1 叶子只重算祖先链（~10 节点）
// 对比全树重算 O(n)：高频更新场景（任务看板实时协作）差 100 倍
// 惰性语义：标脏不立即算（写便宜），读取时才算（读时摊销）—— 写多读少场景最优
```

**评分点**：
- 父链标脏 + 惰性重算（写 O(depth)/读摊销 O(1)）——本题核心。
- 子树递归命中缓存（兄弟子树不重算）。
- 与 ALG-223 的关系（勾选局部更新 → 聚合缓存局部失效同构）。
- 写多读少的惰性取舍说明。
