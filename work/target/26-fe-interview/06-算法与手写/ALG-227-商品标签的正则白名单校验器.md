## ALG-227：用户自定义商品标签：敏感词与格式白名单校验（正则 + Trie 混合方案）
**答**：用户给商品打标签（2~10 字），要求：不命中敏感词库（2 万词）、只含中文/字母/数字。敏感词匹配用 Trie（AC 自动机思想）而不是逐词正则——2 万个正则逐一 test 是灾难。

**思路**：格式校验一个正则；敏感词用 Trie 前缀树扫描，O(文本长)。

```javascript
class SensitiveTrie {
  constructor(words) {
    this.root = {};
    for (const w of words) {
      let node = this.root;
      for (const ch of w) node = node[ch] ??= {};
      node.__end = true;
    }
  }
  find(text) {                                    // 返回命中的敏感词列表
    const hits = [];
    for (let i = 0; i < text.length; i++) {
      let node = this.root, j = i;
      let candidate = '';
      while (node && j < text.length) {
        candidate += text[j];
        node = node[text[j]];
        if (node?.__end) hits.push(candidate);
        j++;
      }
    }
    return hits;
  }
}
const FORMAT = /^[\u4e00-\u9fa5A-Za-z0-9]{2,10}$/;
function validateTag(text, trie) {
  if (!FORMAT.test(text)) return { ok: false, reason: '标签需 2~10 位中文/字母/数字' };
  const hits = trie.find(text);
  return hits.length ? { ok: false, reason: '包含敏感词' } : { ok: true };
}
// 2 万敏感词逐词 includes：O(词数 × 文本长)；Trie 扫描 O(文本长 × 平均词长)
// 生产补充：词库更新走下发；命中记录用于词库运营
```

**评分点**：
- 敏感词用 Trie 而不是逐词正则/includes（复杂度对比说清）。
- Trie 扫描实现正确（每个起点沿树走，__end 收集命中）。
- 格式正则与敏感词校验分层（格式先行短路）。
- 生产补充意识（词库下发/命中运营）。
