**场景**：订单优惠叠加：折扣券（85 折）与满减券（满 300 减 50）叠加，先后顺序结果不同——按业务规则（先折扣后满减，满减门槛按折后价）模拟计算每步金额，输出明细供用户理解。

**思路**：按规则序逐步应用：price → 折扣 → 满减判定（折后价是否达门槛）→ 减免 → 运费等；每步记录 before/after（透明化展示）。

```javascript
function applyPromotions(price, promotions) {
  // promotions: [{ type: 'discount', rate: 0.85 }, { type: 'fullcut', threshold: 300, cut: 50 }]
  let cur = price;
  const steps = [];
  for (const p of promotions) {
    const before = cur;
    if (p.type === 'discount') {
      cur = Math.round(cur * p.rate * 100) / 100;      // 分单位精度（ALG-200 语义）
      steps.push({ type: p.type, before, after: cur, cut: before - cur });
    } else if (p.type === 'fullcut') {
      if (cur >= p.threshold) {
        cur -= p.cut;
        steps.push({ type: p.type, before, after: cur, cut: p.cut });
      } else steps.push({ type: p.type, skipped: true, reason: `未达门槛 ¥${p.threshold}` });
    }
  }
  return { final: cur, steps };     // steps 明细透明化：用户看懂每一步（转化率关键）
}
applyPromotions(350, [{ type: 'discount', rate: 0.85 }, { type: 'fullcut', threshold: 300, cut: 50 }]);
// 350 → 折后 297.5 → 未达 300 门槛（跳过！）→ final 297.5
// 若先满减：350→300 达门槛减 50 → 250 → 折后 212.5 —— 顺序不同结果差 85
// 业务规则透明：顺序写死进配置（先折扣后满减），明细 steps 展示给用户
```

**评分点**：
- 顺序敏感的逐步模拟（每步 before/after 记录）——本题核心。
- 门槛判定按"当前已折扣价"（折后未达门槛跳过）的语义正确。
- 分单位精度（Math.round ×100/100，衔接 ALG-200）。
- skipped 明细透明化（用户理解为什么没用上满减）。
