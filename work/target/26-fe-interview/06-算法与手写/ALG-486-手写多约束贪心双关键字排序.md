## ALG-486：手写多约束贪心（双关键字排序）：投放排序

**答**：
- 题目：广告候选有 (预估收益, 消耗)，预算 B 内选收益最大的集合。经典：按「收益/消耗」比降序（分数背包贪心，可装整件时装满为止）。
- 思路：降序比值排序；逐个装，预算不够跳过（0-1 背包贪心不最优，但分数背包可拆时最优）——注意区分可拆/不可拆。
- 评分点：比值排序；可拆 vs 不可拆（0-1 背包贪心不最优需 DP）；反例构造（0-1 场景）。

```javascript
function greedySpend(candidates, budget) {                 // 可拆分数背包
  const sorted = [...candidates].sort((a, b) =>
    b.profit / b.cost - a.profit / a.cost);                 // 收益/消耗 比值降序
  let remain = budget, total = 0, chosen = [];
  for (const c of sorted) {
    if (c.cost <= remain) {                                 // 整件可装
      remain -= c.cost; total += c.profit; chosen.push(c);
    } else if (remain > 0 && c.fractional) {                // 可拆：装一部分
      total += c.profit * remain / c.cost;
      chosen.push({ ...c, cost: remain });
      remain = 0;
    }
  }
  return { total, chosen, unused: remain };
}
// 0-1 背包（不可拆）贪心反例：B=10, items [(6,60),(5,50),(5,50)]（cost,profit）
// 按比值同为 10：选第一个后剩 4 → 40 总收益 < DP 最优 100 → 必须用 DP
```
