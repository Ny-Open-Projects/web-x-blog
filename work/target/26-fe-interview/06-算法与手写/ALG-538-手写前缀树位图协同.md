## ALG-538：手写前缀树+位图协同：标签体系

**答**：
- 题目：标签体系（层级标签如「行业/电商/跨境」），支持「按前缀筛选 + 按位组合判定」——Trie 管层级、Bitmap 管标签集交集。
- 思路：每个资源一个标签 bitmap；筛选 = Trie 前缀命中标签集合 → bitmap AND 集合非空判定。
- 评分点：层级（Trie）与集合（bitmap）分工；AND 交集运算；位宽扩展（>32 用 BigInt/分段）。

```javascript
class TagSystem {
  constructor() { this.trie = { children: {}, tags: new Set() };
    this.bitmap = new Map(); }                             // tag → Set<resId>（简化位图语义）
  addTag(path, resId) {                                    // path: '行业/电商/跨境'
    let node = this.trie;
    node.tags.add(resId);
    for (const c of path.split('/')) {
      node = node.children[c] ??= { children: {}, tags: new Set() };
      node.tags.add(resId);                                // 沿途标记（前缀命中）
    }
    (this.bitmap.get(path) ?? this.bitmap.set(path, new Set()).get(path)).add(resId);
  }
  filterByPrefix(prefix) {                                 // 前缀筛选
    let node = this.trie;
    for (const c of prefix.split('/').filter(Boolean)) {
      node = node.children[c];
      if (!node) return [];
    }
    return [...node.tags];
  }
  intersect(tagPaths) {                                    // 多标签 AND
    const sets = tagPaths.map(p => this.bitmap.get(p) ?? new Set());
    if (!sets.length) return [];
    return [...sets.reduce((a, b) => new Set([...a].filter(x => b.has(x))))];
  }
}
```
