## ALG-378：手写线段树离线查询排序优化：批量报表按序计算

**答**：
- 题目：一次要算 1 万个「区间和」查询（只读），数据不变——离线处理：全部读入后排序（按右端点），用 BIT 从左到右扫一遍依次回答，O((n+q) log n)，避免每查询独立 O(n)。
- 思路：离线查询按右端点升序；扫描指针右移时 BIT.add(当前值)；到某查询右端点时 BIT.range(l, r) 即答案。
- 评分点：离线排序思想；扫描线+BIT 组合；与在线线段树的取舍（只读场景 BIT 更省）。

```javascript
function offlineRangeSum(arr, queries) {                   // queries: [{l, r, id}]
  const sorted = [...queries].sort((a, b) => a.r - b.r);   // 按右端点排序
  const bit = new Array(arr.length + 1).fill(0);
  const add = (i, v) => { for (i++; i <= arr.length; i += i & -i) bit[i] += v; };
  const sum = i => { let s = 0; for (i++; i > 0; i -= i & -i) s += bit[i]; return s; };
  const answers = new Array(queries.length);
  let ptr = 0;
  for (const q of sorted) {
    while (ptr <= q.r) add(ptr, arr[ptr++]);                // 扫描指针右移
    answers[q.id] = sum(q.r) - sum(q.l - 1);                // 前缀差
  }
  return answers;                                          // 按 id 回填原顺序
}
```
