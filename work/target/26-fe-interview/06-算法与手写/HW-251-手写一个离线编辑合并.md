## HW-251：手写一个离线编辑合并：本地操作队列与上线重放

**答**：
- 需求：实现 OfflineQueue：断网时 local op 入队（含本地版本号），联网后逐条提交（等待 ack 后提交下一条）；服务端拒绝（版本冲突）时对该 op 做变换后重试；提供 flushAll 与 pending 数量。
- 边界：队列操作间有依赖（后 op 基于前 op 的文档），拒绝时只需对服务端并发 op 变换队首；重试上限（5 次）后转人工冲突 UI；localStorage 持久化防刷新丢失。
- 评分点：串行重放保依赖；变换重试；持久化。

```javascript
class OfflineQueue {
  constructor(storage) { this.q = []; this.sending = false; this.storage = storage; }
  localOp(op) {                                             // 断网/未确认时入队
    this.q.push({ op, localRev: this.rev });
    this.storage.setItem('opq', JSON.stringify(this.q));    // 持久化
  }
  async flush() {                                           // 上线重放
    if (this.sending) return;
    this.sending = true;
    try {
      while (this.q.length) {
        const { op } = this.q[0];
        const res = await serverSubmit(op, this.rev);
        if (res.ok) { this.q.shift(); this.rev = res.rev; this.storage.setItem('opq', '[]'); }
        else if (res.conflict) {
          const { a1 } = transform(op, res.concurrentOp);   // 冲突变换重试
          this.q[0] = { op: a1, localRev: res.serverRev };
        } else break;                                       // 其他错误暂停
      }
    } finally { this.sending = false; }
  }
  pending() { return this.q.length; }
}
```
