## HW-295：手写一个轮播图组件：触摸滑动、循环与自动播放

**答**：
- 需求：实现 Carousel：触摸滑动跟手（translate 实时跟随，松手按位移+速度判定翻页或回弹）；循环（首尾无缝：克隆首尾帧或取模定位）；自动播放（可见时 4s 间隔，不可见暂停）；指示器同步。
- 边界：跟手位移用 translate3d（合成层）；快速连滑（翻页动画中再滑）排队或立即完成前一动画；页面隐藏暂停自动播放。
- 评分点：位移+速度判定；无缝循环实现；可见性暂停。

```javascript
class Carousel {
  constructor(track, { interval = 4000 } = {}) {
    this.track = track; this.n = track.children.length;
    this.idx = 0; this.timer = null;
    track.addEventListener('pointerdown', e => this.down(e));
    document.addEventListener('visibilitychange', () =>
      document.hidden ? this.stop() : this.play());          // 可见性暂停
    this.play();
  }
  down(e) {
    this.x0 = e.clientX; this.t0 = performance.now(); this.dragging = true;
    const move = ev => { if (!this.dragging) return;
      this.track.style.transition = 'none';
      this.track.style.transform = `translate3d(${-this.idx * 100}% + ${(ev.clientX - this.x0)}px,0,0)`; };
    const up = ev => { this.dragging = false;
      const dx = ev.clientX - this.x0, dt = performance.now() - this.t0;
      const v = dx / dt;                                     // 位移+速度判定
      if (dx < -50 || v < -0.5) this.go(this.idx + 1);
      else if (dx > 50 || v > 0.5) this.go(this.idx - 1);
      else this.go(this.idx);                                // 回弹
    };
    addEventListener('pointermove', move); addEventListener('pointerup', up, { once: true });
  }
  go(i) {                                                    // 取模循环
    this.idx = ((i % this.n) + this.n) % this.n;
    this.track.style.transition = 'transform .3s';
    this.track.style.transform = `translate3d(${-this.idx * 100}%,0,0)`;
    this.onSlide?.(this.idx);
  }
  play() { this.stop(); this.timer = setInterval(() => this.go(this.idx + 1), 4000); }
  stop() { clearInterval(this.timer); }
}
```
