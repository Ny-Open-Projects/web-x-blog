## ALG-208：浏览器历史面板：删除"含指定域名"的历史项（O(1) 删除：哨兵 + 前驱缓存）
**答**：历史记录用单向链表存储（ head -> node -> ...），要删除所有 `url` 含某域名的节点。单向链表删除需要前驱，经典做法：哨兵头结点统一边界，遍历时缓存前驱。

**思路**：哨兵 dummy + prev 指针遍历；O(n) 时间 O(1) 空间。

```javascript
function removeByDomain(head, domain) {
  const dummy = { url: '', next: head };             // 哨兵统一删头边界
  let prev = dummy;
  while (prev.next) {
    if (prev.next.url.includes(domain)) {
      prev.next = prev.next.next;                    // 摘除当前节点
      // 不前移 prev：next 可能也要删
    } else {
      prev = prev.next;
    }
  }
  return dummy.next;
}
// 链表: a.com -> evil.com -> b.com -> evil.com/x  删 'evil' => a.com -> b.com
const list = { url: 'a.com', next: { url: 'evil.com', next: { url: 'b.com', next: { url: 'evil.com/x', next: null } } } };
removeByDomain(list, 'evil');
// 复杂度 O(n)/O(1)
// 为什么不用递归：长历史可能几千条，递归栈深度风险（工程上迭代更稳）
```

**评分点**：
- 哨兵节点统一"删头"边界（无 dummy 时删第一个要特判）。
- 删除后 prev 不前移（连续待删节点不漏）。
- 返回 dummy.next（新头）；O(n)/O(1)。
- 能说明递归版的栈深风险。
