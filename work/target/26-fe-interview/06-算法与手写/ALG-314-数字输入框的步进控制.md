## ALG-314：数字步进器：步进边界/长按连续步进（pointerdown 长按加速）/输入直改校验三位一体？
**答**：数量步进器三合一：± 按钮步进（边界 clamp）、长按连续步进（pointerdown 启动，先慢后快加速）、手输直改（blur 校验 clamp 回合法值）——三种输入路径统一走 setValue（单一入口校验）。

**思路**：setValue 统一（clamp + onChange）→ 长按：pointerdown 启动延时 400ms 后连发（interval 从 200ms 加速到 50ms）→ pointerup/leave/cancel 全清理。

```javascript
function stepper(input, { min = 1, max = 99, step = 1 } = {}) {
  const setValue = (v) => {                               // 单一入口：clamp + 回写 + onChange
    const clamped = Math.max(min, Math.min(max, Math.round(v)));
    if (input.value !== String(clamped)) { input.value = clamped; input.dispatchEvent(new Event('change')); }
  };
  // 长按连续步进（加速）
  function holdBtn(btn, dir) {
    let timer = null, interval = null, speed = 200;
    const stepOnce = () => setValue((+input.value || min) + dir * step);
    const start = (e) => { e.preventDefault(); stepOnce();
      timer = setTimeout(() => {                          // 400ms 后连发
        interval = setInterval(() => { stepOnce(); speed = Math.max(50, speed - 30);   // 加速
          clearInterval(interval); interval = setInterval(stepOnce, speed);
        }, speed);
      }, 400);
    };
    const stop = () => { clearTimeout(timer); clearInterval(interval); speed = 200; };
    btn.addEventListener('pointerdown', start);
    for (const ev of ['pointerup', 'pointerleave', 'pointercancel']) btn.addEventListener(ev, stop);
  }
  holdBtn(btnUp, 1); holdBtn(btnDown, -1);
  input.addEventListener('blur', () => setValue(+input.value || min));   // 手输：blur 校验 clamp
  input.addEventListener('keydown', (e) => { if (e.key === 'Enter') setValue(+input.value || min); });
}
// 三路径统一 setValue（clamp 一处实现）—— 步进/长按/手输不可能出现不一致
// 长按加速：200ms → 50ms（先慢后快，大数量快速到达）
// 清理事件三元组（up/leave/cancel）—— pointer 离开按钮停止（漏 leave = 无限步进 bug）
```

**评分点**：
- 三输入路径统一 setValue（clamp 单一入口）——本题核心。
- 长按加速曲线（400ms 延迟 → 200→50ms 加速）。
- 清理事件三元组（up/leave/cancel 全清）。
- blur/Enter 的手输校验兜底。
