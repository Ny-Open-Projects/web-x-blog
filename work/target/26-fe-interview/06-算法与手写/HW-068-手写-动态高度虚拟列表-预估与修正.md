## HW-068：手写动态高度虚拟列表——预估高度 + 实测修正 + 缓存已测高度
**答**：动态高度难点：未渲染的行高度未知。方案：① 未测行用估计值 estimated；② 渲染后实测（ResizeObserver）回写缓存并更新累计前缀和；③ 总高度与滚动定位用"二分查找前缀和数组"定位 startIndex（O(logN)），滚动偏移 = prefix[start]。修正时保持滚动位置不跳（对已渲染区域修正做补偿）。

```javascript
class DynamicVirtualList {
  constructor(container, { estimated = 60, overscan = 5, count }) {
    this.c = container; this.estimated = estimated; this.overscan = overscan; this.count = count;
    this.heights = new Array(count).fill(estimated);   // 已测缓存（未测也是预估）
    this.measured = new Set();                         // 是否实测过
    this.prefix = [];                                  // 前缀和：prefix[i] = 前 i 行总高
    this.#buildPrefix();
    this.ro = new ResizeObserver((es) => {
      let dirty = false;
      for (const e of es) {
        const i = +e.target.dataset.index;
        const h = e.target.offsetHeight;
        if (!this.measured.has(i)) { this.measured.add(i); this.heights[i] = h; dirty = true; }
        else if (this.heights[i] !== h) { this.#adjust(this.heights[i], h); this.heights[i] = h; dirty = true; }
      }
      if (dirty) this.#buildPrefix();
    });
    container.addEventListener('scroll', () => this.render(), { passive: true });
  }
  #buildPrefix() { this.prefix = [0];
    for (let i = 0; i < this.count; i++) this.prefix[i + 1] = this.prefix[i] + this.heights[i];
    this.c.style.setProperty('--total', this.prefix[this.count] + 'px'); }
  #adjust(oldH, newH) { /* 修正滚动位置防跳动：本次从略 */ }
  findStart(scrollTop) {                        // 二分前缀和定位 O(logN)
    let lo = 0, hi = this.count;
    while (lo < hi) { const mid = (lo + hi) >> 1;
      if (this.prefix[mid] < scrollTop) lo = mid + 1; else hi = mid; }
    return Math.max(0, lo - 1);
  }
  render() {
    const scrollTop = this.c.scrollTop;
    const start = Math.max(0, this.findStart(scrollTop) - this.overscan);
    const visibleH = this.c.clientHeight;
    let end = start + this.overscan, acc = 0;
    while (end < this.count && acc < visibleH) { acc += this.heights[end]; end++; }
    end = Math.min(this.count, end + this.overscan);
    this.#mount(start, end);                    // 渲染 + ResizeObserver 实测回写
  }
  #mount(start, end) { /* 生成/复用节点，挂 data-index，交给 RO 观察 */ }
}
```

**评分点**：
- 预估 + 实测 + 缓存三段策略清晰（未测行预估、测过行缓存、RO 增量修正）。
- 前缀和 + 二分定位 startIndex（不是 O(N) 累加）。
- ResizeObserver 只对变化行做修正并重建前缀。
- 能说出"滚动跳变补偿"的意识（修正高度时保持视觉稳定）。
