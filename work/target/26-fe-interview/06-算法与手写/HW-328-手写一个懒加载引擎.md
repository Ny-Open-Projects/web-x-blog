## HW-328：手写一个懒加载引擎：资源优先级与预加载距离配置

**答**：
- 需求：实现 LazyLoader：注册资源 [{url, type, priority}]；可视区接近（rootMargin 可按优先级配置：高优 600px 提前、低优 200px）；队列并发控制（图片 6 个/脚本 2 个）；失败重试一次后降级占位；曝光即加载（IntersectionObserver）。
- 边界：优先级影响 rootMargin 与并发份额；重试用新 URL（加 cache-bust）；已加载去重（url 集合）。
- 评分点：按优先级差异化 margin；并发分组；降级占位。

```javascript
class LazyLoader {
  constructor() {
    this.seen = new Set();
    this.groups = { high: { io: this.makeIO('600px'), q: [], active: 0, max: 6 },
                    low: { io: this.makeIO('200px'), q: [], active: 0, max: 2 } };
  }
  makeIO(margin) {
    return new IntersectionObserver(es => es.forEach(e => {
      if (!e.isIntersecting) return;
      const item = this.items.get(e.target);
      item.io.unobserve(e.target);
      this.enqueue(item);
    }), { rootMargin: margin });
  }
  register(el, { url, type = 'img', priority = 'low' }) {
    if (this.seen.has(url)) return;                          // 去重
    this.seen.add(url);
    const item = { el, url, type, priority };
    (this.items ??= new Map()).set(el, item);
    this.groups[priority].io.observe(el);
  }
  enqueue(item) {                                            // 分组并发队列
    const g = this.groups[item.priority];
    g.q.push(item); this.pump(g);
  }
  pump(g) {
    while (g.active < g.max && g.q.length) {
      const it = g.q.shift(); g.active++;
      this.load(it).finally(() => { g.active--; this.pump(g); });
    }
  }
  async load(it, retried = false) {
    try {
      if (it.type === 'img') { it.el.src = it.url; await it.el.decode?.(); }
      else await fetch(it.url);
      this.onLoaded?.(it);
    } catch {
      if (!retried) return this.load({ ...it, url: it.url + (it.url.includes('?') ? '&' : '?') + '_r=1' }, true);   // cache-bust 重试
      it.el.src = PLACEHOLDER;                               // 降级占位
      this.onFail?.(it);
    }
  }
}
```
