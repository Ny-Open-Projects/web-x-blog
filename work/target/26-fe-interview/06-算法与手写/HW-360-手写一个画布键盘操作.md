## HW-360：手写一个画布键盘操作：方向键微移与复制粘贴序列化

**答**：
- 需求：实现 CanvasKeys：方向键微移（1px，Shift 10px 大步进）；复制（Ctrl+C 序列化选中节点含相对位置）；粘贴（Ctrl+V 反序列化 + 偏移 20px 防重叠 + 新 id）；剪切与撤销联动（粘贴为独立 undo 单元）。
- 边界：粘贴多次位置递增偏移（防完全重叠）；粘贴保留层归属；跨画布粘贴（序列化自包含）；粘贴后选中新粘贴节点。
- 评分点：微移步进；相对位置序列化；粘贴偏移与选中。

```javascript
class CanvasKeys {
  constructor(scene, history) { this.s = scene; this.h = history; this.clip = null; this.pasteN = 0; }
  onKey(e) {
    const sel = [...this.s.selection];
    const step = e.shiftKey ? 10 : 1;                        // 大步进
    const dirs = { ArrowLeft: [-step, 0], ArrowRight: [step, 0], ArrowUp: [0, -step], ArrowDown: [0, step] };
    if (dirs[e.key] && sel.length) {
      const [dx, dy] = dirs[e.key];
      const before = sel.map(n => ({ id: n.id, x: n.x, y: n.y }));
      sel.forEach(n => { n.x += dx; n.y += dy; invalidate(n); });
      this.h.pushTransform(sel[0].id, 'move', before,
        sel.map(n => ({ id: n.id, x: n.x, y: n.y })));       // 拖拽结束才入栈
      return 'moved';
    }
    if (ctrlKey(e) && e.key === 'c') return this.copy(sel);
    if (ctrlKey(e) && e.key === 'x') { this.copy(sel); sel.forEach(n => this.s.remove(n.id));
      this.h.pushSnapshot(sceneDoc(this.s)); return 'cut'; }
    if (ctrlKey(e) && e.key === 'v') return this.paste();
    return 'none';
  }
  copy(sel) {
    if (!sel.length) return;
    const b = selectionBounds(sel);                          // 相对位置序列化
    this.clip = sel.map(n => ({ ...serializeNode(n), dx: n.x - b.x, dy: n.y - b.y }));
    this.pasteN = 0;
    return 'copied';
  }
  paste() {
    if (!this.clip) return;
    this.pasteN++;
    const off = this.pasteN * 20;                            // 递增偏移防重叠
    const nodes = this.clip.map(c => ({ ...deserializeNode(c), id: genId(),
      x: c.x0 + c.dx + off, y: c.y0 + c.dy + off }));
    nodes.forEach(n => this.s.add(n));                       // 保留层归属
    this.s.selection = new Set(nodes);                       // 粘贴后选中
    this.h.pushSnapshot(sceneDoc(this.s));                   // 独立 undo 单元
    return 'pasted';
  }
}
```
