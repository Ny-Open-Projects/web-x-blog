## HW-336：手写一个离线同步引擎：变更日志与双向同步及冲突策略

**答**：
- 需求：实现 SyncEngine：本地写操作记录变更日志 [{entity, id, op, data, ts}]；sync() 推送日志到服务端（按实体批量），拉取服务端变更；冲突检测（本地与服务端都改了同实体）按策略（client-wins/server-wins/manual）合并；日志序号（游标断点续传）。
- 边界：幂等（变更日志带唯一 id，服务端去重）；断点续传（服务端返回 lastSeq，下次从 seq+1 推）；同步中新变更排队不打断当前批次。
- 评分点：幂等 id；游标续传；冲突策略注入。

```javascript
class SyncEngine {
  constructor(log, { conflict = 'client-wins' } = {}) {
    this.log = log; this.strategy = conflict; this.seq = 0; this.syncing = false;
  }
  record(entity, id, op, data) {
    this.log.push({ id: crypto.randomUUID(), entity, entityId: id, op, data, ts: Date.now() });
  }
  async sync() {
    if (this.syncing) { this.pendingSync = true; return; }   // 同步中新变更排队
    this.syncing = true;
    try {
      const pending = this.log.filter(e => e.seq == null);
      const res = await fetch('/sync', { method: 'POST', body: JSON.stringify({
        changes: pending, lastSeq: this.seq }) });
      const { serverChanges, lastSeq, conflicts } = await res.json();
      for (const c of conflicts ?? []) await this.resolveConflict(c);   // 冲突处理
      serverChanges.forEach(c => applyRemote(c));
      pending.forEach(e => e.seq = lastSeq);                 // 标记已同步
      this.seq = lastSeq;
      saveLog(this.log);
    } finally {
      this.syncing = false;
      if (this.pendingSync) { this.pendingSync = false; this.sync(); }   // 补跑
    }
  }
  async resolveConflict({ entityId, server, local }) {
    if (this.strategy === 'client-wins') return pushOverride(entityId, local);
    if (this.strategy === 'server-wins') return applyRemote(server);
    return queueManualConflict({ entityId, server, local });   // manual：进冲突 UI 队列
  }
}
```
