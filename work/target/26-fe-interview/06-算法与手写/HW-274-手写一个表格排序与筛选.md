## HW-274：手写一个表格排序与筛选：复合排序状态机与数据管道

**答**：
- 需求：实现 TablePipeline：sort 状态（多列复合：[{key, dir}]，dir 三态 none→asc→desc 循环）；filter 状态（每列 {op, value}）；pipeline(rows) 依次 filter→sort 输出；稳定排序（同键保持原序，多列按声明序比较）。
- 边界：filter op 注册表（eq/contains/range/in）；排序比较器支持 null 值排尾；状态变化时 pipeline 重算（记忆化：filter 结果缓存）。
- 评分点：三态循环；复合比较器；null 排尾。

```javascript
class TablePipeline {
  constructor() { this.sorts = []; this.filters = new Map(); this._fcache = null; }
  toggleSort(key) {                                          // 三态循环
    const i = this.sorts.findIndex(s => s.key === key);
    if (i < 0) this.sorts.push({ key, dir: 'asc' });
    else if (this.sorts[i].dir === 'asc') this.sorts[i].dir = 'desc';
    else this.sorts.splice(i, 1);                            // desc → 移除
    return this.sorts;
  }
  setFilter(key, f) { this.filters.set(key, f); this._fcache = null; }
  pipeline(rows) {
    let out = rows.filter(r => [...this.filters].every(([k, f]) =>
      OPS[f.op](r[k], f.value)));                            // filter
    const sorts = this.sorts;
    if (sorts.length) out = [...out].sort((a, b) => {        // 复合稳定排序
      for (const s of sorts) {
        const cmp = compareCell(a[s.key], b[s.key]);
        if (cmp) return s.dir === 'asc' ? cmp : -cmp;
      }
      return 0;                                              // 同键保序（稳定）
    });
    return out;
  }
}
function compareCell(a, b) {
  if (a == null && b == null) return 0;
  if (a == null) return 1;                                   // null 排尾
  if (b == null) return -1;
  return a < b ? -1 : a > b ? 1 : 0;
}
const OPS = {
  eq: (v, x) => v === x, contains: (v, x) => String(v ?? '').includes(x),
  range: (v, [lo, hi]) => v >= lo && v <= hi, in: (v, xs) => xs.includes(v),
};
```
