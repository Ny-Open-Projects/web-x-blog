## HW-317：手写一个重试引擎：固定、指数、抖动策略与预算

**答**：
- 需求：实现 Retry：run(fn, {strategy, maxAttempts, budgetMs})；策略：fixed(n)/exponential(base, cap)/jitter（指数+随机抖动防雪崩）；总预算（budgetMs 超时不再重试）；可重试错误判定（isRetryable 回调）。
- 边界：抖动 = 指数 × (0.5 + random)；预算耗尽返回最后错误并标注 exhausted；重试间隔从 0 开始计（首次失败后等待）。
- 评分点：抖动防雪崩；预算控制；可重试判定。

```javascript
async function retryRun(fn, opts = {}) {
  const { strategy = 'exponential', base = 500, cap = 30000,
    maxAttempts = 5, budgetMs = 30000, isRetryable = () => true } = opts;
  const t0 = Date.now();
  let lastErr = null;
  for (let i = 0; i < maxAttempts; i++) {
    try { return await fn(); }
    catch (e) {
      lastErr = e;
      if (!isRetryable(e)) throw e;                          // 不可重试错误直接抛
      const left = budgetMs - (Date.now() - t0);
      if (left <= 0) throw Object.assign(e, { exhausted: true });   // 预算耗尽
      let delay;
      if (strategy === 'fixed') delay = base;
      else if (strategy === 'exponential') delay = Math.min(base * 2 ** i, cap);
      else delay = Math.min(base * 2 ** i, cap) * (0.5 + Math.random());   // jitter
      delay = Math.min(delay, left);
      await new Promise(r => setTimeout(r, delay));
    }
  }
  throw Object.assign(lastErr, { attempts: maxAttempts });
}
// 用法：
// retryRun(fetchData, { strategy: 'jitter', maxAttempts: 4,
//   isRetryable: e => e.status >= 500 || e.name === 'NetworkError' })
```
