## HW-353：手写一个图层管理器：z 序调整、锁定与可见性

**答**：
- 需求：实现 LayerManager：图层列表（数组即 z 序，末尾在最上）；reorder（拖拽排序 + 置顶/置底/上移/下移）；锁定（locked 节点不参与命中/编辑）；可见性（visible 不渲染但保留）；分组图层（组节点递归管理子节点状态）。
- 边界：锁定组递归锁子节点；隐藏组不渲染子树；reorder 的 undo（记录原索引）；图层树与场景图同步。
- 评分点：数组即 z 序；递归锁/隐藏；undo 记录。

```javascript
class LayerManager {
  constructor() { this.layers = []; this.undoStack = []; }
  reorder(fromIdx, toIdx) {                                  // z 序调整
    this.undoStack.push({ from: [...this.layers] });
    const [layer] = this.layers.splice(fromIdx, 1);
    this.layers.splice(toIdx, 0, layer);
  }
  toTop(idx) { this.reorder(idx, this.layers.length - 1); }
  toBottom(idx) { this.reorder(idx, 0); }
  undo() { const op = this.undoStack.pop(); if (op) this.layers = op.from; }
  setLocked(layer, locked) {
    layer.locked = locked;
    if (layer.group) walk(layer, n => n.locked = locked);    // 递归锁子
  }
  setVisible(layer, visible) {
    layer.visible = visible;
    if (layer.group) walk(layer, n => n.visible = visible);  // 递归隐藏
  }
  renderAll(ctx) {                                           // 数组序渲染（末尾最上）
    for (const layer of this.layers) {
      if (!layer.visible) continue;                          // 隐藏不渲染
      walk(layer, n => n.visible && n.draw(ctx));
    }
  }
  hitTest(px, py) {                                          // 从顶层向下命中
    for (let i = this.layers.length - 1; i >= 0; i--) {
      const layer = this.layers[i];
      if (!layer.visible || layer.locked) continue;          // 锁定不参与命中
      const hit = layer.hit?.(px, py);
      if (hit) return hit;
    }
    return null;
  }
}
function walk(node, fn) { fn(node); node.children?.forEach(c => walk(c, fn)); }
```

## 补充：评分点与变体

**评分点**：

- 数组顺序即 z 序、末尾在最上，reorder 用 splice 原地移动；重建数组会让外部持有的节点引用全部失效
- setLocked 作用在组节点时必须递归到子节点，并保留子节点原有 locked 值，解锁时按原值还原而非一律置 false
- setVisible 为 false 只跳过渲染，节点仍留在数组里；hitTest 同样要跳过隐藏与锁定节点，否则点空白处会选中隐藏图层
- undo 要同时记录原索引 from 与目标索引 to，只记 to 无法还原移动前的顺序

**变体与延伸**：

1. 命中测试从哪一端开始 → 从数组末尾倒序（最上层优先），命中即返回，遇 locked 或 hidden 直接 continue
2. 组内坐标与父级变换怎么处理 → 递归累乘 transform 矩阵，把点击坐标变换到节点局部坐标再判边界
3. 把组拖进自己的子树怎么防 → 移动前做祖先链检查，目标父节点是自身后代时拒绝本次 reorder
