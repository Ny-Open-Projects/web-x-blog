## HW-392：手写一个输入性能探针：按键到渲染的耗时分解

**答**：
- 需求：实现 InputProbe：每次按键记录分解耗时——keydown → 命令执行（逻辑耗时）→ DOM 更新（渲染耗时）→ 浏览器绘制（rAF 对齐）；输出 p50/p95 与超预算（> 16ms）按键占比；归因到命令类型（insert/删除/格式化）。
- 边界：performance.now 分段测量；绘制完成时间用 requestAnimationFrame 后测量（近似）；采样上报（全量本地聚合，定期上报聚合值）。
- 评分点：分段测量口径；rAF 对齐绘制；聚合上报。

```javascript
class InputProbe {
  constructor() { this.samples = []; }
  wrapKeydown(handler) {                                     // 包装按键处理
    return e => {
      const t0 = performance.now();
      const result = handler(e);                             // 命令执行
      const t1 = performance.now();
      requestAnimationFrame(() => {                          // rAF 对齐绘制完成
        const t2 = performance.now();
        this.samples.push({ key: e.key, cmd: result?.cmd ?? 'unknown',
          logicMs: +(t1 - t0).toFixed(2),                    // 逻辑耗时
          paintMs: +(t2 - t1).toFixed(2),                    // 渲染耗时
          totalMs: +(t2 - t0).toFixed(2), over: t2 - t0 > 16 });
        if (this.samples.length >= 200) this.report();       // 定期聚合上报
      });
      return result;
    };
  }
  report() {
    const by = {};
    for (const s of this.samples) (by[s.cmd] ??= []).push(s.totalMs);
    const pct = (a, p) => { const s = [...a].sort((x, y) => x - y);
      return +(s[Math.floor(s.length * p)] ?? 0).toFixed(1); };
    const out = Object.fromEntries(Object.entries(by).map(([cmd, arr]) => [cmd, {
      p50: pct(arr, 0.5), p95: pct(arr, 0.95),
      overRate: +(arr.filter(v => v > 16).length / arr.length).toFixed(3),   // 超预算占比
    }]));
    track('input-perf', out);                                // 聚合上报
    this.samples = [];
    return out;
  }
}
```
