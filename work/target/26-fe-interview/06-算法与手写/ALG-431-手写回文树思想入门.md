## ALG-431：手写回文树思想入门：回文子串统计

**答**：
- 题目：统计字符串中「不同回文子串」的个数（回文树/EERTREE 是标准解，面试给思想 + 简化实现：Manacher 收集 + Set 去重，或中心扩展 Set）。
- 思路：回文树每个节点是一个不同回文串，fail 指向最长真回文后缀——本质是把所有回文串组织成两棵树（奇偶）。简化实现：中心扩展收集所有回文入 Set（O(n²) 最坏但实现简单），或 Manacher 每中心取最大 + 去重子回文（不完整，说明局限）。
- 评分点：回文树两棵树结构；简化解的复杂度局限；不同回文子串数 ≤ n 的性质。

```javascript
function countDistinctPalindromes(s) {                     // 简化：中心扩展 + Set
  const seen = new Set();
  const expand = (l, r) => {
    while (l >= 0 && r < s.length && s[l] === s[r]) {
      seen.add(s.slice(l, r + 1));                         // 收集回文
      l--; r++;
    }
  };
  for (let i = 0; i < s.length; i++) {
    expand(i, i);                                          // 奇数中心
    expand(i, i + 1);                                      // 偶数中心
  }
  return seen.size;                                        // O(n²) 最坏，n 小可用
}
// 回文树（EERTREE）：节点数 = 不同回文串数 + 2（两个根）
// 性质：长度 n 的串不同回文子串最多 n 个——回文树利用此性质做到 O(n)
// fail 指针 = 最长真回文后缀，用于统计每个回文出现次数
```
