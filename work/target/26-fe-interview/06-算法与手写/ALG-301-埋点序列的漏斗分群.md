## ALG-301：漏斗分群：按"到达哪一步"给用户分群（流失桶统计 + 分群交集分析）？
**答**：漏斗分析的分群维度：用户按"走到第几步"分桶（step0 只看 / step1 加购 / step2 下单 / step3 支付）——分群间可交叉（step1 且来自广告渠道的用户流失率）。

**思路**：单遍扫描分桶（ALG-215 的 lostAtStep 即桶号）→ 桶 × 维度（渠道/设备）交叉矩阵。

```javascript
function funnelCohorts(events, funnel, dims = ['channel', 'device']) {
  const cohorts = new Map();                              // "step2|ios|organic" -> count
  for (const session of events) {
    const { lostAtStep } = passedFunnel(session.events, funnel);   // ALG-215 复用
    const stepKey = lostAtStep === null ? 'converted' : `step${lostAtStep}`;
    const key = [stepKey, ...dims.map((d) => session[d] ?? 'unknown')].join('|');
    cohorts.set(key, (cohorts.get(key) ?? 0) + 1);
  }
  return cohorts;                                         // 交叉矩阵（可透视成漏斗 × 渠道表）
}
// 输出透视：
//          organic   paid    direct
// step0      300      800      100
// step1      200      400       80
// converted  100      200       60
// 洞察：paid 渠道 step0→step1 流失率 50%（高于 organic 33%）→ 落地页与广告承诺不匹配
// 内存：Map 键组合爆炸控制——dims 限定枚举（channel×device ≤ 50 组合），事件量级单遍无囤积
```

**评分点**：
- lostAtStep 直接作为分群桶号（ALG-215 复用）——本题核心。
- 交叉维度矩阵（漏斗 × 渠道/设备透视）。
- 单遍扫描无囤积（枚举维度控制组合爆炸）。
- 洞察输出（渠道间流失率对比）。
