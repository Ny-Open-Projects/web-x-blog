**场景**：分享链接直达树深层节点：`?path=1/5/23`——逐级展开（级联懒加载 ALG-288）+ 展开后滚动定位到目标节点 + 路径失效降级（节点被删 → 展开到最深有效层并提示）。

**思路**：path 数组逐级展开（复用级联加载）→ 展开完成 scrollIntoView 目标 → 失效节点 break（保留有效前缀展开）。

```javascript
async function expandPath(treeApi, pathIds, { container } = {}) {
  let lastValid = null;
  for (const id of pathIds) {
    try {
      await treeApi.expand(id);                         // 逐级展开（内部级联懒加载 + 缓存）
      lastValid = id;
    } catch { break; }                                  // 节点失效：停在最后有效层
  }
  if (lastValid) {
    await new Promise((r) => requestAnimationFrame(r)); // 渲染完成
    container.querySelector(`[data-id="${lastValid}"]`)
      ?.scrollIntoView({ block: 'center', behavior: 'smooth' });   // 滚动定位（居中）
    if (lastValid !== pathIds.at(-1)) toast('部分节点已不存在，已定位到最近有效节点');   // 失效提示
  }
}
// 分享链接直达：path 参数 + 逐级展开 + 滚动定位 —— 深层协作场景（树审批/目录）的刚需
// 失效降级：节点被删/无权限 → 停留在最深有效层 + 明示提示（不静默失败）
// 定位时序：展开是异步懒加载 → rAF 等渲染 → scrollIntoView（HW-103 同款纪律）
```

**评分点**：
- 逐级展开（级联懒加载复用）+ 滚动定位的时序——本题核心。
- 路径失效降级（最深有效层 + 提示）。
- 分享链接语义（URL path 参数可收藏可分享）。
- 与 ALG-288 级联加载/HW-103 定位的组合复用。
