## HW-158：手写图片主色提取——canvas 缩采样 + 颜色聚类简化版（LQIP 占位色，防 CLS）
**答**：图片加载前的占位主色（LQIP）：缩采样（drawImage 到 10×10——缩小后取像素成本极低）→ 简化聚类（按亮度分桶取中位色或 k-means k=3 简版）→ 作为背景色占位（图片加载前容器有"氛围色"，感知速度提升）。在 Worker/offscreen 中执行（解码成本不占主线程）。

```javascript
async function dominantColor(src) {
  const img = await loadImage(src);
  const c = new OffscreenCanvas(10, 10);                  // 缩到 10×10：100 像素足够代表主色
  const ctx = c.getContext('2d');
  ctx.drawImage(img, 0, 0, 10, 10);
  const data = ctx.getImageData(0, 0, 10, 10).data;
  // 简化聚类：按亮度分暗/中/亮三桶，取最大桶的平均色（避免边缘白/黑干扰）
  const buckets = [[], [], []];
  for (let i = 0; i < data.length; i += 4) {
    const [r, g, b, a] = [data[i], data[i + 1], data[i + 2], data[i + 3]];
    if (a < 128) continue;                                // 透明像素跳过
    const lum = 0.299 * r + 0.587 * g + 0.114 * b;
    buckets[lum < 85 ? 0 : lum < 170 ? 1 : 2].push([r, g, b]);
  }
  const main = buckets.reduce((a, b) => (b.length > a.length ? b : a), buckets[0]);
  const avg = main.reduce((acc, [r, g, b]) => [acc[0] + r, acc[1] + g, acc[2] + b],
    [0, 0, 0]).map((v) => Math.round(v / main.length));
  return `rgb(${avg.join(',')})`;
}
// 用法：容器 background = await dominantColor(url)，图片 onload 后覆盖
// 性能：10×10 采样 < 1ms；OffscreenCanvas 可挪 Worker（PER-290）
// 进阶：真 LQIP 用 20×20 高斯模糊位图（base64 存库）；本简化版主色已足够"氛围占位"
```

**评分点**：
- 缩采样到 10×10 的成本意识（100 像素足够，不逐像素全图处理）。
- 亮度分桶简化聚类（抗明暗边缘干扰）；透明像素跳过。
- OffscreenCanvas/Worker 执行（不占主线程）。
- 占位色防 CLS 的衔接（容器先有尺寸与颜色，PER-220）。
