## ALG-360：手写权值线段树：实时中位数与第 k 大

**答**：
- 题目：数据流实时到来的数字，随时查当前中位数或第 k 大（如直播礼物金额分位）。值域离散化后建权值线段树（下标=值，节点=个数）。
- 思路：插入即单点 +1；查第 k 小：左子树计数 >= k 走左，否则 k -= 左计数走右；中位数 = 第 ceil(n/2) 小。复杂度 O(log 值域)。
- 评分点：权值线段树下标是值；树上按计数二分；离散化处理大值域。

```javascript
class ValueSegTree {
  constructor(sortedVals) {                                 // 离散化值域
    this.vals = sortedVals; this.n = sortedVals.length;
    this.t = new Array(4 * this.n).fill(0);
  }
  insert(v) { this.update(this.vals.indexOf(v), 1); }
  update(i, v, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.t[node] += v;
    const m = (l + r) >> 1;
    i <= m ? this.update(i, v, node * 2, l, m) : this.update(i, v, node * 2 + 1, m + 1, r);
    this.t[node] = this.t[node * 2] + this.t[node * 2 + 1];
  }
  kth(k, node = 1, l = 0, r = this.n - 1) {                 // 第 k 小
    if (l === r) return this.vals[l];
    const leftCnt = this.t[node * 2];
    return k <= leftCnt ? this.kth(k, node * 2, l, m = (l + r) >> 1)
      : this.kth(k - leftCnt, node * 2 + 1, m + 1, r);
  }
  median() {
    const total = this.t[1];
    return total === 0 ? null
      : this.kth(Math.ceil(total / 2));                    // 中位数
  }
}
```
