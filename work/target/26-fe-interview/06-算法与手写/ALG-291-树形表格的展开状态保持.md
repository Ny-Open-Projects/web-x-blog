## ALG-291：树形表格展开状态：数据刷新后保持展开（expandedSet 按 id 独立于数据）+ 半选传递？
**答**：树形表格刷新数据（懒加载子级插入）后展开状态丢失——展开状态独立存储（Set<nodeId>）不随数据重建；懒加载插入子级后已展开节点继续展开；勾选半选沿树传递（ALG-223 联动）。

**思路**：expanded: Set（id 语义）——渲染时 has(id) 判定；刷新后新数据同 id 节点保持展开；半选计算（子树勾选比例）缓存到节点（避免每次渲染全树重算）。

```javascript
class TreeTableState {
  expanded = new Set();                                   // 展开状态：id 语义独立于数据
  checked = new Set(); half = new Set();
  toggle(id) { this.expanded.has(id) ? this.expanded.delete(id) : this.expanded.add(id); }
  refresh(newTree) {                                      // 数据刷新：展开集原样保留（id 匹配）
    // 新数据中不存在的 id 自动失效（Set 自然收缩——渲染时 has 判定不会命中不存在节点）
    return this.#render(newTree);
  }
  #render(node) {
    const rows = [];
    const walk = (n, depth) => {
      rows.push({ node: n, depth, expanded: this.expanded.has(n.id),
                  checked: this.checked.has(n.id), half: this.half.has(n.id) });
      if (this.expanded.has(n.id)) n.children?.forEach((c) => walk(c, depth + 1));
    };
    walk(node, 0);
    return rows;                                          // 渲染行序列（只含展开路径——懒加载语义）
  }
  #recomputeHalf(node) {                                  // 半选：子树勾选比例（ALG-223 联动）
    const kids = node.children ?? [];
    const all = kids.every((c) => this.checked.has(c.id));
    const any = kids.some((c) => this.checked.has(c.id) || this.half.has(c.id));
    all ? (this.checked.add(node.id), this.half.delete(node.id))
        : any ? (this.checked.delete(node.id), this.half.add(node.id))
              : (this.checked.delete(node.id), this.half.delete(node.id));
  }
}
// 展开状态 id 语义：数据刷新（懒加载子级插入）不丢展开 —— 独立 Set 是关键设计
// 半选缓存：#recomputeHalf 只在被勾选影响的祖先链上调用（ALG-223 局部更新）—— 不全树重算
```

**评分点**：
- 展开状态独立 Set（id 语义，刷新不丢）——本题核心。
- 展开路径渲染（只含展开子树——懒加载兼容）。
- 半选传递复用 ALG-223 局部更新。
- 新数据不存在的 id 自然失效（Set 收缩）。
