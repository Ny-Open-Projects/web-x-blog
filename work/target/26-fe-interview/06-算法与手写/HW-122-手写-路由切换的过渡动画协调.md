**答**：路由过渡的时序难点：新页面数据未就绪就播动画会闪白。双缓冲方案：旧页面保持渲染（离场动画期间）→ 新页面数据就绪后挂到缓冲层 → 同帧切换（旧 fade-out 与新 fade-in 并行，合成器路径）→ 动画完成卸载旧页。中断处理：过渡期间再次导航 → 取消当前动画立即切换（不能排队）。

```javascript
class RouteTransition {
  constructor(container) { this.container = container; this.current = null; this.animating = false; }
  async navigate(newPageRender, { duration = 240 } = {}) {
    if (this.animating) { this.#abort(); }                    // 中断：立即切换不排队
    const oldEl = this.current;
    // 1. 新页面数据就绪（渲染到缓冲层，不可见）
    const newEl = await newPageRender();
    newEl.style.cssText = 'position:absolute;inset:0;opacity:0;transform:translateX(24px)';
    this.container.append(newEl);
    // 2. 同帧启动双动画（合成器路径：transform + opacity）
    this.animating = true;
    const oldAnim = oldEl?.animate(
      [{ opacity: 1, transform: 'none' }, { opacity: 0, transform: 'translateX(-24px)' }],
      { duration, easing: 'ease-out', fill: 'forwards' });
    const newAnim = newEl.animate(
      [{ opacity: 0, transform: 'translateX(24px)' }, { opacity: 1, transform: 'none' }],
      { duration, easing: 'ease-out', fill: 'forwards' });
    this.#pending = Promise.all([oldAnim?.finished ?? null, newAnim.finished]);
    await this.#pending;
    // 3. 卸载旧页
    oldEl?.remove();
    this.current = newEl;
    this.animating = false;
  }
  #abort() { this.#pendingAbort = true; this.current?.remove?.(); this.animating = false; }
}
// 关键时序：数据就绪 → 缓冲层挂载 → 同帧双动画（不闪白）→ 完成卸载旧页
// 动画走 Web Animations API（合成器路径，主线程忙也流畅，PER-347）
// 中断语义：过渡中再导航 → 直接切新页（旧动画丢弃），绝不排队
```

**评分点**：
- 双缓冲时序正确（数据就绪 → 缓冲挂载 → 同帧切换，不闪白）——核心考点。
- Web Animations API 走合成器路径（transform/opacity）。
- 中断处理：过渡中再导航立即切换不排队。
- 旧页卸载时机（动画完成 remove，防内存滞留）。
