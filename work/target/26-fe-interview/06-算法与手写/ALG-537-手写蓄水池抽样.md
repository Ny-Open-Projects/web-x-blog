## ALG-537：手写蓄水池抽样：数据流采样

**答**：
- 题目：日志流（长度未知）中均匀抽 K 条——蓄水池抽样：第 i 条以 k/i 概率替换池中随机位。数学证明：每条最终入选概率 = k/n。
- 思路：前 k 条直接入池；第 i > k 条以 k/i 概率随机替换池中一条。
- 评分点：k/i 概率替换；均匀性归纳证明；单遍 O(1) 空间。

```javascript
function reservoirSample(stream, k) {                      // stream: 迭代器
  const pool = [];
  let i = 0;
  for (const item of stream) {
    if (i < k) pool.push(item);
    else {
      const j = Math.floor(Math.random() * (i + 1));       // [0, i] 均匀
      if (j < k) pool[j] = item;                           // 以 k/i 概率替换
    }
    i++;
  }
  return pool;                                             // 每条入选概率 k/n
}
// 证明（归纳）：第 i 条入选概率 = k/i；最终存活概率 = k/i × (1 - 1/(i+1)) × ... = k/n
```
