## HW-259：手写一个协作会话心跳与断线重连：版本对齐与追赶

**答**：
- 需求：实现 CollabSession：心跳 10s（携带当前 rev）；断线检测（3 次心跳未收到）；重连流程：发送 resume(rev) → 服务端返回 [missing ops] 或 [snapshot + ops]（落后太多走快照）→ 本地未确认 ops 对 missing ops 变换后重发；提供状态机输出（connected/reconnecting）。
- 边界：追赶期间缓冲新本地 op（不丢失）；快照对齐后本地 buffer 需基于新文档变换（简化：重放）；重连风暴退避（多次失败延长间隔）。
- 评分点：追赶双通道（ops/快照）；本地 buffer 变换重发；重连退避。

```javascript
class CollabSession {
  constructor({ hb = 10000, maxLag = 200 } = {}) { this.hbMs = hb; this.maxLag = maxLag;
    this.missed = 0; this.fails = 0; this.state = 'connected'; this.buf = []; }
  onHeartbeatAck(serverRev) {
    this.missed = 0;
    if (serverRev - this.rev > this.maxLag) return this.resync();   // 落后太多：快照
    const missing = server.fetchOps(this.rev, serverRev);   // 追赶 ops
    let pending = this.pending;
    missing.forEach(op => {                                 // 变换 pending 与 buffer
      if (pending) { const p = transform(pending, op); pending = p.a1; applyLocal(p.b1); }
      else applyLocal(op);
      this.buffer = this.buffer.map(b => { const q = transform(b, op); return q.a1; });
    });
    this.rev = serverRev;
    if (pending) resend(pending);
  }
  checkAlive() {                                            // 心跳检测
    if (++this.missed >= 3) this.reconnect();
  }
  async reconnect() {
    this.state = 'reconnecting';
    this.fails++;
    await sleep(Math.min(1000 * 2 ** this.fails, 30000));   // 风暴退避
    try {
      const snap = await server.resume(this.rev);
      if (snap.type === 'snapshot') restoreDoc(snap.doc), this.rev = snap.rev;
      this.onHeartbeatAck(snap.rev);
      this.fails = 0; this.state = 'connected';
    } catch { this.reconnect(); }
  }
}
```
