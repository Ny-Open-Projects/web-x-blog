## HW-363：手写一个流程图自动布局：分层布局（简化 DAG 排布）

**答**：
- 需求：实现 AutoLayout：拓扑分层（入度 0 为第 0 层，逐层递推）；层内排序（减少交叉：按上游节点平均位置排序，两轮迭代）；坐标输出（x = 层 × 层距，y = 层内序 × 行距）；连线重算。
- 边界：环存在时（强制布局模式）按 DFS 序分层；孤立节点层内居中；布局动画（从旧位置到新位置缓动过渡）。
- 评分点：拓扑分层；交叉减少迭代；过渡动画。

```javascript
function autoLayout(model, { layerGap = 200, rowGap = 80 } = {}) {
  const nodes = [...model.nodes.values()];
  const indeg = new Map(nodes.map(n => [n.id, 0]));
  for (const e of model.edges.values()) indeg.set(e.to.node, indeg.get(e.to.node) + 1);
  const level = new Map();
  const q = nodes.filter(n => !indeg.get(n.id));
  q.forEach(n => level.set(n.id, 0));
  while (q.length) {                                        // 拓扑分层
    const n = q.shift();
    for (const e of model.edges.values())
      if (e.from.node === n.id) {
        const t = model.nodes.get(e.to.node);
        indeg.set(t.id, indeg.get(t.id) - 1);
        if (indeg.get(t.id) === 0) {
          const lv = Math.max(...[...model.edges.values()]
            .filter(x => x.to.node === t.id).map(x => level.get(x.from.node) ?? 0)) + 1;
          level.set(t.id, lv); q.push(t);
        }
      }
  }
  const byLevel = new Map();
  nodes.forEach(n => {
    const lv = level.get(n.id) ?? 0;
    (byLevel.get(lv) ?? byLevel.set(lv, []).get(lv)).push(n);
  });
  const positions = new Map();
  for (const [lv, arr] of [...byLevel].sort((a, b) => a[0] - b[0])) {
    // 层内排序：按上游平均位置（减少交叉）
    arr.sort((a, b) => avgUpstreamPos(a) - avgUpstreamPos(b));
    arr.forEach((n, i) => positions.set(n.id, { x: lv * layerGap, y: i * rowGap }));
  }
  return { positions, animate: true };                      // 交由渲染层缓动过渡
}
function avgUpstreamPos(n) { return n.upstreamAvgY ?? 0; }   // 两轮迭代时更新该值
```

## 补充：评分点与变体

**评分点**：

- 拓扑分层用 Kahn 时要对边去重，重边会让目标节点入度永远降不到 0，整层节点卡在队列外
- 层内排序按上游平均位置计算，且必须基于上一轮的完整坐标，边算边改会让两轮迭代来回震荡不收敛
- 孤立节点（入度出度皆为 0）单独居中处理，塞进第 0 层会在图左侧堆一列
- 有环时先 DFS 标出回边并剔除再分层，直接 Kahn 会剩下环上节点永远不入层

**变体与延伸**：

1. 某一层节点数特别多（200 个）→ 层内再分列或限制单层宽度换行，纯按行距排会拉出超长画布
2. 用户手动拖过部分节点后再重算 → 记录 pinned 坐标，重算只移动未固定节点
3. 增量加一个节点要不要全量重算 → 只对受影响的下游做局部重排，全量 O(V+E) 在大图上会卡住交互
