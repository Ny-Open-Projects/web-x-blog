## HW-281：手写一个动态表单联动：字段依赖 DAG 与可见性/取值联动计算

**答**：
- 需求：实现 FormLinkage：字段联动声明 [{when: {field, op, value}, then: {show/hide/setValue/options}}]；构建字段依赖 DAG（联动源→目标），setValue 时只重算受影响字段（沿 DAG 下游传播）；环检测（联动声明成环报错）。
- 边界：下游传播到值稳定为止（联动链 A→B→C）；同字段多条规则按声明序执行，后者覆盖；options 联动（下拉选项随上级值变化）。
- 评分点：DAG 局部重算；传播收敛；环检测。

```javascript
class FormLinkage {
  constructor(rules, schema) {
    this.rules = rules; this.graph = buildDAG(rules, schema);
    if (hasCycle(this.graph)) throw new Error('linkage-cycle');   // 环检测
  }
  affected(field) {                                          // DAG 下游
    const out = new Set(); const q = [field];
    while (q.length) { const f = q.pop();
      for (const t of this.graph.get(f) ?? []) if (!out.has(t)) { out.add(t); q.push(t); } }
    return out;
  }
  setValue(name, v, engine) {
    engine.values[name] = v;
    for (const f of this.affected(name))                     // 只重算下游
      for (const rule of this.rules.filter(r => r.target === f)) {
        if (match(rule.when, engine.values)) {
          if (rule.then.action === 'show') engine.setVisible(f, true);
          if (rule.then.action === 'hide') engine.setVisible(f, false);
          if (rule.then.action === 'setValue') engine.setValueRaw(f, rule.then.value);
          if (rule.then.action === 'options') engine.setOptions(f, rule.then.options(engine.values));
        } else if (rule.else_) engine.setVisible(f, rule.else_ === 'show');
      }
  }
}
function buildDAG(rules, schema) {
  const g = new Map();
  for (const r of rules) {
    const src = Object.keys(r.when ?? {})[0];
    if (src) { g.set(src, [...(g.get(src) ?? []), r.target]); }
  }
  return g;
}
function match(when, values) { return Object.entries(when ?? {}).every(([k, v]) => values[k] === v); }
function hasCycle(g) { const state = new Map();
  const dfs = f => { if (state.get(f) === 1) return true; if (state.get(f) === 2) return false;
    state.set(f, 1);
    for (const t of g.get(f) ?? []) if (dfs(t)) return true;
    state.set(f, 2); return false; };
  return [...g.keys()].some(dfs); }
```
