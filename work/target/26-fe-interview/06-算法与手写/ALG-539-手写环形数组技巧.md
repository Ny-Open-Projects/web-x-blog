## ALG-539：手写环形数组技巧：轮播循环

**答**：
- 题目：轮播索引循环（前/后翻页、跳转），环形数组技巧：idx = (idx + n) % n 处理负数；无缝轮播用取模即可（无需克隆首尾的替代写法说明）。
- 思路：取模统一方向（负偏移安全：((idx % n) + n) % n）；克隆首尾的 transform 方案对照（动画连续性 vs 实现复杂度）。
- 评分点：负数取模防御；克隆方案的适用（过渡动画）；纯取模方案的局限。

```javascript
class CarouselIndex {
  constructor(total) { this.n = total; this.idx = 0; }
  next(step = 1) { this.idx = (this.idx + step) % this.n; return this.idx; }
  prev(step = 1) { this.idx = ((this.idx - step) % this.n + this.n) % this.n; return this.idx; }   // 负数防御
  jumpTo(i) { this.idx = ((i % this.n) + this.n) % this.n; return this.idx; }
}
// 方案 A（取模）：DOM 顺序固定，切换时 transform 跳转——最后一帧到第一帧会「倒放」
// 方案 B（克隆首尾）：DOM 首尾克隆，动画永远单向——过渡自然但需在动画结束瞬间重置 idx
// 选型：简单轮播 A；无缝体验 B（HW-295 已实现）
```
