**场景**：筛选侧栏每个选项显示"命中商品数"（品牌 X (123)）。当前筛选条件下重新计数——单次遍历商品列表，同时更新所有维度的计数桶，O(n) 出全部维度。

**思路**：对每个商品，在"当前筛选不含该维度时"把商品计入该维度桶（被筛掉的维度自身计数要保留——否则品牌计数只剩当前选中品牌的数）。经典细节：各维度计数要基于"排除自身维度、应用其他维度筛选"的商品集。

```javascript
function facetCounts(goods, activeFilters) {
  // activeFilters: { brand: Set, price: Set, color: Set }  空集合 = 该维度未筛选
  const dims = ['brand', 'price', 'color'];
  const counts = Object.fromEntries(dims.map((d) => [d, new Map()]));
  for (const g of goods) {
    for (const dim of dims) {
      // 该维度的计数 = 排除本维度、应用其他维度筛选后的商品
      const others = dims.filter((d) => d !== dim);
      const passOthers = others.every((d) => {
        const f = activeFilters[d];
        return !f?.size || f.has(g[d]);
      });
      if (passOthers) {
        const m = counts[dim];
        m.set(g[dim], (m.get(g[dim]) ?? 0) + 1);
      }
    }
  }
  return counts;
}
// 关键语义：brand 计数基于"只筛 price+color"的商品集 —— 用户点品牌 X 后仍能看到其他品牌的可选数
// 反例：全维度一起筛 → brand 计数只剩已选品牌（其他品牌全 0，无法跨选）
// 复杂度：O(n × dims)；大列表可按当前筛选先物化 passOthers 集（一次判定复用）
```

**评分点**：
- "排除自身维度"的计数语义（跨维度可选数保留）——本题核心考点。
- 单次遍历多维计数 O(n × dims)。
- 空集合 = 未筛选的语义处理。
- 能说出反例（全维度同筛导致其他选项计数归零）。
