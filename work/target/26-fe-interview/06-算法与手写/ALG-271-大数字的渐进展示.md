## ALG-271：大数字渐进展示：计数动画的 easing（先快后慢）与 1 万+ 数值的增量渲染节流？
**答**：GMV 大屏数字滚动动画：0→1234567 计数——线性匀速像"加载中"，easeOut（先快后慢）有"冲刺落地"感；渲染节流（每帧更新但数值变化 < 阈值时跳帧——大数字末段变化肉眼不可见）。

**思路**：easeOutCubic 时间映射 → 值插值 → rAF 渲染；数字格式化（HW-125 Intl compact）同步。

```javascript
function countUp(el, target, { duration = 1500, format = (v) => Math.round(v).toLocaleString() } = {}) {
  const t0 = performance.now();
  return new Promise((resolve) => {
    function tick(now) {
      const t = Math.min(1, (now - t0) / duration);
      const eased = 1 - Math.pow(1 - t, 3);               // easeOutCubic：先快后慢（冲刺感）
      const value = target * eased;
      el.textContent = format(value);
      if (t < 1) requestAnimationFrame(tick); else resolve(target);
    }
    requestAnimationFrame(tick);
  });
}
// countUp(el, 1234567) —— 1.5s 内从 0 滚到 1,234,567（前 0.3s 完成 60% 视觉冲刺）
// 实时递增场景（大屏每秒 +N）：增量动画——from 当前值 → 当前值 + delta（短 duration 300ms）
// 无障碍：aria-live off + 完成后 textContent 落最终值（读屏用户直接听最终数，不听 1.5s 滚动噪音）
// prefers-reduced-motion：直接设最终值（HW-157 同款纪律）
```

**评分点**：
- easeOutCubic 的时间-值映射（先快后慢的"冲刺落地"叙事）——本题核心。
- rAF 渲染 + Intl 格式化同步。
- 无障碍处理（aria-live off / reduced-motion 直接落值）。
- 实时递增场景的增量动画扩展。
