## ALG-201：运营埋点：用户行为串里找"连续命中关键词都为热门"的最长片段（无重复字符变体）

**场景**：埋点上报用户行为标签串 `s`（如 `"home,search,home,goods"` 简化为字符），运营要找**不含重复标签的最长连续片段**长度，用于分析用户路径多样性。等价于「无重复字符最长子串」。

**思路**：滑动窗口 + Set（或 lastIdx 数组），左指针在有重复时右移。O(n)。

```javascript
function longestUniquePath(s) {
  const lastIdx = new Map();        // 标签 -> 最近出现位置
  let left = 0, best = 0;
  for (let right = 0; right < s.length; right++) {
    const c = s[right];
    if (lastIdx.has(c) && lastIdx.get(c) >= left) {
      left = lastIdx.get(c) + 1;    // 重复：左界跳到重复位置+1（不逐格右移）
    }
    lastIdx.set(c, right);
    best = Math.max(best, right - left + 1);
  }
  return best;
}
// "abcbac" => 3 ("cba" or "bac")；"aaaa" => 1
// 关键优化：left 直接跳变（lastIdx+1），而不是 while 循环逐格删——均摊仍 O(n)
```

**评分点**：
- 滑动窗口结构正确，窗口无重复不变量成立。
- 左指针跳变优化（Map 记最近位置）而非逐格收缩。
- 均摊 O(n) 复杂度说明（每字符最多进出窗口各一次）。
- 能对应场景：行为标签去重路径分析。
