## ALG-352：手写区间更新+懒标记线段树（区间加）：弹幕限流配额批量调整

**答**：
- 题目：弹幕频道配额按小时段管理，运营会批量给 [10:00,12:00] 所有小时段增加 100 配额，同时要查询某小时段当前配额。区间改、单点查。
- 思路：懒标记（lazy propagation）——区间加时先给覆盖节点打 +v 标记并更新该节点和值，子节点延迟下推（pushdown），查询/更新经过时才下传。区间改从 O(n 个点) 降到 O(log n)。
- 评分点：pushdown 时机（先下推再递归）；标记叠加（多次区间加可合并）；区间全包含直接打标不递归。

```javascript
class LazySegTree {
  constructor(n) { this.n = n; this.t = new Array(4 * n).fill(0); this.lazy = new Array(4 * n).fill(0); }
  pushdown(node, l, r) {                                   // 下推标记
    if (!this.lazy[node]) return;
    const m = (l + r) >> 1;
    for (const child of [node * 2, node * 2 + 1]) {
      this.t[child] += this.lazy[node] * (child === node * 2 ? m - l + 1 : r - m);   // 和值同步
      this.lazy[child] += this.lazy[node];                 // 标记叠加
    }
    this.lazy[node] = 0;
  }
  add(ql, qr, v, node = 1, l = 0, r = this.n - 1) {
    if (qr < l || r < ql) return;
    if (ql <= l && r <= qr) {                              // 全包含：打标即返
      this.t[node] += v * (r - l + 1);
      this.lazy[node] += v;
      return;
    }
    this.pushdown(node, l, r);                             // 递归前先下推
    const m = (l + r) >> 1;
    this.add(ql, qr, v, node * 2, l, m);
    this.add(ql, qr, v, node * 2 + 1, m + 1, r);
    this.t[node] = this.t[node * 2] + this.t[node * 2 + 1];
  }
  query(i, node = 1, l = 0, r = this.n - 1) {              // 单点查
    if (l === r) return this.t[node];
    this.pushdown(node, l, r);
    const m = (l + r) >> 1;
    return i <= m ? this.query(i, node * 2, l, m) : this.query(i, node * 2 + 1, m + 1, r);
  }
}
```
