## HW-329：手写一个错误上报引擎：全局捕获、去重聚合与采样

**答**：
- 需求：实现 ErrorReporter：捕获 window.error / unhandledrejection / 资源加载错误三类；聚合去重（同 message+stack 指纹 5 分钟窗口内计数合并）；采样（错误率过高时降采样，单页最多 N 条）；上报带上下文（路由/用户/版本/release）。
- 边界：指纹算法（message 归一化：数字替换、行号可选）；降采样触发（1 分钟内 > 50 条后 10% 采样）；网络错误与 JS 错误分通道。
- 评分点：指纹归一化；自适应降采样；上下文完整。

```javascript
class ErrorReporter {
  constructor(endpoint, { windowMs = 300000, maxPerMin = 50 } = {}) {
    this.ep = endpoint; this.win = windowMs; this.max = maxPerMin;
    this.aggr = new Map(); this.minute = [];                 // 指纹 -> {count, sample}
    addEventListener('error', e => this.capture({ kind: 'js', message: e.message, stack: e.error?.stack }));
    addEventListener('unhandledrejection', e => this.capture({ kind: 'promise', message: String(e.reason) }));
    addEventListener('error', e => { if (e.target?.src) this.capture({ kind: 'resource', message: 'res:' + e.target.src }); }, true);
    setInterval(() => this.flush(), 10000);
  }
  fingerprint(e) {
    const msg = e.message.replace(/\d+/g, '*').slice(0, 100);
    const frame = e.stack?.split('\n')[1]?.replace(/:\d+:\d+/, '') ?? '';   // 去行号
    return msg + '|' + frame;
  }
  capture(e) {
    if (this.minute.length >= this.max) {                    // 自适应降采样
      if (Math.random() > 0.1) return;
    }
    const fp = this.fingerprint(e);
    const cur = this.aggr.get(fp);
    if (cur && Date.now() - cur.first < this.win) { cur.count++; return; }   // 聚合计数
    this.aggr.set(fp, { ...e, fp, count: 1, first: Date.now(),
      ctx: { route: location.pathname, release: window.__RELEASE__, uid: getUid() } });
    this.minute.push(Date.now());
  }
  async flush() {
    if (!this.aggr.size) return;
    const events = [...this.aggr.values()];
    this.aggr.clear();
    this.minute = this.minute.filter(t => Date.now() - t < 60000);
    try { await fetch(this.ep, { method: 'POST', keepalive: true,
      body: JSON.stringify({ errors: events }) }); }
    catch { this.aggr = new Map(events.map(e => [e.fp, e])); }   // 失败回滚待重试
  }
}
```
