## ALG-428：手写后缀数组思想与倍增：全文检索排序

**答**：
- 题目：知识库全文检索——所有文档拼接成大文本，查子串出现位置。后缀数组：所有后缀排序后，模式串二分定位。
- 思路：倍增构造——按长度 1/2/4/8... 排序（每轮用上轮 rank 双关键字），O(n log² n)（配基数排序 O(n log n)）；查询：模式串在后缀数组上二分（比较前缀），命中区间即所有出现位置。
- 评分点：倍增双关键字排序；二分查询定位；与后缀自动机/哈希的取舍。

```javascript
function suffixArray(s) {                                  // 倍增构造
  const n = s.length;
  let rank = [...s].map(c => c.charCodeAt(0));
  let sa = [...Array(n).keys()].sort((a, b) => rank[a] - rank[b]);
  for (let k = 1; k < n; k <<= 1) {                        // 长度倍增
    const key = i => [rank[i], i + k < n ? rank[i + k] : -1];
    sa.sort((a, b) => { const [x1, y1] = key(a), [x2, y2] = key(b);
      return x1 - x2 || y1 - y2; });
    const newRank = new Array(n);
    newRank[sa[0]] = 0;
    for (let i = 1; i < n; i++) {                          // 重新编号
      const [x1, y1] = key(sa[i - 1]), [x2, y2] = key(sa[i]);
      newRank[sa[i]] = newRank[sa[i - 1]] + (x1 !== x2 || y1 !== y2 ? 1 : 0);
    }
    rank = newRank;
    if (rank[sa[n - 1]] === n - 1) break;                  // 全部唯一：提前结束
  }
  return { sa, rank };
}
function searchSuffix(text, sa, pattern) {                 // 二分定位
  let lo = 0, hi = sa.length - 1;
  const hits = [];
  while (lo <= hi) {                                       // 找首个 >= pattern 的后缀
    const mid = (lo + hi) >> 1;
    text.slice(sa[mid], sa[mid] + pattern.length) < pattern ? lo = mid + 1 : hi = mid - 1;
  }
  for (let i = lo; i < sa.length && text.slice(sa[i], sa[i] + pattern.length) === pattern; i++)
    hits.push(sa[i]);
  return hits;                                             // 所有出现位置
}
```

## 补充：评分点与变体

**评分点**：

- 倍增每轮以「前半 rank + 后半 rank」双关键字排序，后半越界用 -1 补齐；越界处理写错会让短后缀排到长后缀之后
- 复杂度要分层说：比较排序实现是 O(n log² n)，只有把 rank 当整数键、配基数排序才降到 O(n log n)
- 查询要二分出左右边界，判等比较的是候选后缀与模式串的前 m 个字符，只比首字符会把大量候选误判为命中
- 空间是 sa 与 rank 两个 n 长数组，构造期的 tmp 要复用，每轮新建会让峰值翻倍

**变体与延伸**：

1. 要返回全部出现位置而不只是是否存在 → 二分出区间后遍历 `sa[l..r]`，总复杂度由输出量 z 决定，为 O(m log n + z)
2. 文本 1GB 装不进内存 → 外存后缀数组（分块构造再归并），或直接换倒排索引加哈希
3. 与后缀自动机怎么取舍 → 单文本建一次 SAM 是 O(n) 且答多模式很快，但要位置仍需 endpos；离线批量查用 SA + LCP 更省
