## HW-366：手写一个数据大屏适配器：等比缩放与坐标系换算

**答**：
- 需求：实现 ScreenAdapter：设计稿尺寸（如 1920×1080）→ 实际容器等比缩放（transform: scale，min(w/k, h/k) 取小保证完整显示）；居中定位；坐标系换算（事件坐标 → 设计稿坐标）；全屏切换重算。
- 边界：取 min 缩放比（留黑边）或 max（裁切）两种模式；resize 监听防抖；事件坐标换算（除以 scale + 容器偏移）。
- 评分点：min/max 两模式；事件坐标换算；防抖重算。

```javascript
class ScreenAdapter {
  constructor(el, design, { mode = 'contain' } = {}) {
    this.el = el; this.dw = design.width; this.dh = design.height; this.mode = mode;
    this.resize = debounce(() => this.fit(), 100);
    addEventListener('resize', this.resize);
    this.fit();
  }
  fit() {
    const { clientWidth: w, clientHeight: h } = this.el.parentElement;
    const kx = w / this.dw, ky = h / this.dh;
    this.scale = this.mode === 'contain' ? Math.min(kx, ky) : Math.max(kx, ky);   // 完整显示 or 裁切
    const sw = this.dw * this.scale, sh = this.dh * this.scale;
    this.offX = (w - sw) / 2; this.offY = (h - sh) / 2;      // 居中偏移
    Object.assign(this.el.style, {
      width: this.dw + 'px', height: this.dh + 'px',
      transform: `translate(${this.offX}px, ${this.offY}px) scale(${this.scale})`,
      transformOrigin: '0 0',
    });
  }
  toDesign(e) {                                              // 事件坐标 → 设计稿坐标
    const r = this.el.getBoundingClientRect();
    return { x: (e.clientX - r.left) / this.scale, y: (e.clientY - r.top) / this.scale };
  }
  destroy() { removeEventListener('resize', this.resize); }
}
function debounce(fn, ms) { let t; return (...a) => { clearTimeout(t); t = setTimeout(() => fn(...a), ms); }; }
```

## 补充：评分点与变体

**评分点**：

- scale 取 `min(w/k, h/k)` 保证完整显示、取 max 会裁切，两种模式要显式配置，不能在不同分支里悄悄换
- 事件坐标换算 `(clientX - rect.left) / scale`，漏掉容器 rect 偏移在非全屏嵌入时必然偏
- resize 监听必须防抖，拖拽窗口时每帧重排会让整个大屏掉帧
- transform-origin 设为左上角，默认 center 会让缩放后整体位置向中心漂移

**变体与延伸**：

1. 容器宽高比与设计稿差很远（超宽拼接屏）→ 用 min 留边并对左右区域做弹性拉伸的分区适配，而不是整体放大裁切
2. 缩放容器内要放 fixed 定位的弹窗 → fixed 相对视口不相对容器，改成 absolute 在容器内定位
3. 截图或打印时尺寸错乱 → 导出前按目标分辨率重算一次 scale，不依赖当前窗口尺寸
