**答**：字段间有依赖（B 的校验依赖 A 的值）时，校验要按拓扑序执行（HW-069 的联动版进阶）：依赖图 → Kahn 拓扑排序 → 按层校验（同层并行）；环（A 依赖 B 且 B 依赖 A）检测报错；异步校验字段等待依赖字段校验完成后才执行。

```javascript
function validateWithDAG(fields, values) {
  // fields: { name: { validate(v, values), dependsOn: [] } }
  const indeg = new Map(), dependents = new Map();
  for (const [f, cfg] of Object.entries(fields)) {
    indeg.set(f, cfg.dependsOn?.length ?? 0);
    for (const d of cfg.dependsOn ?? []) (dependents.get(d) ?? dependents.set(d, []).get(d)).push(f);
  }
  let layer = Object.keys(fields).filter((f) => indeg.get(f) === 0);
  const ordered = [];
  while (layer.length) {
    ordered.push(layer);
    const next = [];
    for (const f of layer) for (const d of dependents.get(f) ?? []) {
      indeg.set(d, indeg.get(d) - 1);
      if (indeg.get(d) === 0) next.push(d);
    }
    layer = next;
  }
  const total = Object.keys(fields).length;
  if (ordered.flat().length < total) {
    const cyclic = Object.keys(fields).filter((f) => !ordered.flat().includes(f));
    throw new Error(`校验依赖成环: ${cyclic.join(', ')}`);
  }
  // 按层校验：同层并行，依赖层完成后才校验（拿到依赖字段的最新值）
  const results = {};
  return (async () => {
    for (const layerFields of ordered) {
      await Promise.all(layerFields.map(async (f) => {
        results[f] = await fields[f].validate(values[f], values);   // 异步校验等待
      }));
    }
    return results;
  })();
}
// fields: { password: {...}, confirm: { dependsOn: ['password'], validate(v, all) => v === all.password || '不一致' } }
// 环：password 依赖 confirm 且 confirm 依赖 password → 启动即报错
```

**评分点**：
- 依赖图 + Kahn 拓扑排序分层校验（同层并行、跨层串行）。
- 环检测启动即报错并列出环内字段。
- 异步 validate 的层间等待语义（依赖字段最新值可用）。
- 与 HW-069 的差异：从"简单联动反查"升级为"拓扑序 + 环检测"。
