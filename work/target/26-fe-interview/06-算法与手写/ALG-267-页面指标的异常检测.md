**场景**：小时级 p75 INP 序列的自动异常检测（不需要人工设阈值）：滑动中位数 + MAD（中位绝对偏差）鲁棒 z-score——比均值/标准差抗长尾污染（性能数据天然长尾）。

**思路**：窗口 24 点 → 中位数 med 与 MAD = median(|x-med|) → z = |x-med|/MAD → z > 3.5 标异常；MAD=0 退化处理（常数序列）。

```javascript
function detectAnomalies(series, { window = 24, threshold = 3.5 } = {}) {
  const median = (arr) => { const s = [...arr].sort((a, b) => a - b);
    return s.length % 2 ? s[(s.length - 1) / 2] : (s[s.length / 2 - 1] + s[s.length / 2]) / 2; };
  const anomalies = [];
  for (let i = window; i < series.length; i++) {
    const hist = series.slice(i - window, i);             // 历史窗口（不含当前点）
    const med = median(hist);
    const mad = median(hist.map((x) => Math.abs(x - med)));
    if (mad === 0) continue;                              // 常数窗口：无偏差基线，跳过
    const z = Math.abs(series[i] - med) / (1.4826 * mad); // 1.4826 = MAD→σ 的正态校正系数
    if (z > threshold) anomalies.push({ idx: i, value: series[i], z: +z.toFixed(2), baseline: Math.round(med) });
  }
  return anomalies;
}
// 示例：INP 小时序列 [180,190,175,...,480] → 最后一点 z=4.2 → 异常（baseline 185）
// 鲁棒性：长尾分布下 mean/σ 会被极值拉偏 → median/MAD 稳定（异常点不影响基线）
// 阈值 3.5 = Iglewicz-Hoaglin 推荐值；窗口 24 点 = 一天周期（覆盖时段效应）
// 输出 baseline —— 告警附带"正常水位"（对比基准），比裸异常值可解释
```

**评分点**：
- MAD 鲁棒 z-score（1.4826 校正系数）——本题核心。
- 滑动窗口不含当前点（异常不影响基线）。
- MAD=0 退化处理。
- 输出 baseline 的可解释性（告警带正常水位）。
