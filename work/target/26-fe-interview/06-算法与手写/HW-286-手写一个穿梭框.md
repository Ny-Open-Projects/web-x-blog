## HW-286：手写一个穿梭框：批量移动与搜索过滤与序保持

**答**：
- 需求：实现 Transfer：左右两列数据与选中集合；move(dir, ids) 批量移动（保留两侧原相对顺序——移动后插入位置按目标列现有排序键）；search(kw) 过滤显示但移动操作作用于全量数据；全选（按过滤结果全选）。
- 边界：搜索态下移动选中项（隐藏项也可被移动）；排序键稳定（新增项按 key 插入正确位置）；重复移动幂等。
- 评分点：序保持合并；搜索与操作解耦；幂等。

```javascript
class Transfer {
  constructor(data, sortKey) {
    this.left = [...data]; this.right = []; this.sel = new Set(); this.kw = ''; this.sortKey = sortKey;
  }
  move(dir, ids) {                                           // 批量移动，序保持
    const [src, dst] = dir === 'right' ? [this.left, this.right] : [this.right, this.left];
    const moving = ids.filter(id => src.some(x => x.id === id));   // 幂等：忽略不存在
    if (!moving.length) return 0;
    const set = new Set(moving);
    const moved = src.filter(x => set.has(x.id));
    this[dir === 'right' ? 'left' : 'right'] = src.filter(x => !set.has(x.id));
    this[dir === 'right' ? 'right' : 'left'] = [...dst, ...moved]
      .sort((a, b) => (a[this.sortKey] > b[this.sortKey] ? 1 : -1));   // 按排序键稳定插入
    this.sel.clear();
    return moved.length;
  }
  moveAll(dir) { return this.move(dir, (dir === 'right' ? this.left : this.right).map(x => x.id)); }
  filtered(side) {                                           // 搜索过滤（仅显示）
    const list = side === 'left' ? this.left : this.right;
    return this.kw ? list.filter(x => x.label.includes(this.kw)) : list;
  }
  selectAllVisible(side) {                                   // 按过滤结果全选
    this.filtered(side).forEach(x => this.sel.add(x.id));
  }
}
```
