## HW-364：手写一个仪表盘布局引擎：网格拖拽布局与占位

**答**：
- 需求：实现 DashboardGrid：12 列网格（每卡片 {x, y, w, h} 单位为格）；拖拽卡片移动（碰撞检测：目标位置与其他卡片重叠则下推被压卡片）；缩放（右下角拖拽改 w/h，约束 min 格数）；占位预览（半透明目标位置）；布局序列化与恢复。
- 边界：下推算法（被压卡片向下找空位，无空位继续推下一张）；y 自增（行数动态增长）；重叠检测按格矩形相交。
- 评分点：碰撞下推；占位预览；格单位换算。

```javascript
class DashboardGrid {
  constructor({ cols = 12 } = {}) { this.cols = cols; this.items = []; }
  overlaps(a, b) { return a.x < b.x + b.w && b.x < a.x + a.w
    && a.y < b.y + b.h && b.y < a.y + a.h; }
  moveItem(id, to) {                                        // 拖拽移动 + 下推
    const it = this.items.find(x => x.id === id);
    const target = { ...it, x: clamp(to.x, 0, this.cols - it.w), y: Math.max(0, to.y) };
    const others = this.items.filter(x => x.id !== id);
    if (others.some(o => this.overlaps(target, o))) {       // 碰撞：下推被压卡片
      for (const o of others.filter(o => this.overlaps(target, o))) {
        let ny = target.y + target.h;
        while (others.some(x => x !== o && this.overlaps({ ...o, y: ny }, x)
          || this.overlaps({ ...o, y: ny }, target))) ny++;   // 向下找空位
        o.y = ny;
      }
    }
    Object.assign(it, target);
    this.compact();                                          // 压缩空行
    return target;
  }
  resizeItem(id, dw, dh) {                                   // 缩放约束
    const it = this.items.find(x => x.id === id);
    it.w = clamp(it.w + dw, it.minW ?? 2, this.cols);
    it.h = clamp(it.h + dh, it.minH ?? 1, 100);
    this.compact();
  }
  compact() {                                                // 空行压缩
    this.items.sort((a, b) => a.y - b.y);
    for (const it of this.items) {
      let y = 0;
      while (this.items.some(o => o !== it && this.overlaps({ ...it, y }, o))) y++;
      it.y = y;
    }
  }
  serialize() { return this.items.map(({ id, x, y, w, h }) => ({ id, x, y, w, h })); }
  restore(list) { this.items = list.map(x => ({ ...x })); this.compact(); }
}
const clamp = (v, lo, hi) => Math.max(lo, Math.min(hi, v));
```
