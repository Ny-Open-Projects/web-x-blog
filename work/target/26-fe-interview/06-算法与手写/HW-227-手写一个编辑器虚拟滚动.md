## HW-227：手写一个编辑器虚拟滚动：按行渲染可视行加缓冲区

**答**：
- 需求：实现 EditorVirtualizer：行高固定（lineH），总行数 N；onScroll(scrollTop) 输出 {start, end, translateY, topPad, bottomPad}（缓冲 10 行）；滚动时只渲染可视区间，DOM 复用（行节点池）。
- 边界：scrollTop 越界钳制；行高变化（换行折叠）时需重测（本题为定高版本，不定高进阶另题）；快速滚动时先渲染骨架行。
- 评分点：缓冲区计算；translateY 定位；行节点复用。

```javascript
class EditorVirtualizer {
  constructor(N, lineH, viewportH, { buffer = 10 } = {}) {
    this.N = N; this.lineH = lineH; this.vh = viewportH; this.buf = buffer;
    this.pool = [];                                            // 行节点池
  }
  onScroll(scrollTop) {
    const st = Math.max(0, Math.min(scrollTop, this.N * this.lineH - this.vh));
    const start = Math.max(0, Math.floor(st / this.lineH) - this.buf);
    const end = Math.min(this.N, Math.ceil((st + this.vh) / this.lineH) + this.buf);
    const need = end - start, reuse = this.pool.splice(0, need);   // 复用已有节点
    while (reuse.length < need) reuse.push(createLineEl());
    this.pool.push(...reuse);
    return { start, end, translateY: start * this.lineH,
      topPad: start * this.lineH,
      bottomPad: Math.max(0, (this.N - end) * this.lineH),
      nodes: reuse };
  }
}
function createLineEl() { const d = document.createElement('div');
  d.className = 'line'; return d; }
```
