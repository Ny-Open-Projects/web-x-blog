## ALG-279：埋点属性的自动脱敏：嵌套对象的敏感键递归清洗（性能埋点的 PII 防线工程化）？
**答**：PER-411 脱敏管道的嵌套版：埋点属性是任意嵌套对象（页面 state 快照）——递归清洗：敏感键黑名单删除、PII 模式值替换、深度截断（防大对象）、数组限长。

**思路**：递归清洗器（带深度/广度上限防 DoS）——每个分支独立 try 保护；输出统计（清洗了几处，供审计）。

```javascript
const SENSITIVE = /^(password|token|secret|card|idcard|phone|email|auth)/i;
const PII = [/1[3-9]\d{9}/, /\d{17}[\dXx]/, /[\w.+-]+@[\w-]+\.\w+/];

function scrub(value, { depth = 5, breadth = 50, stats = { redacted: 0 } } = {}) {
  if (depth <= 0) return '[depth-limit]';                 // 深度截断
  if (value === null || typeof value !== 'object') {
    if (typeof value === 'string' && PII.some((p) => p.test(value))) {
      stats.redacted++; return '[pii]';                   // 值级 PII 替换
    }
    return value;
  }
  if (Array.isArray(value)) return value.slice(0, 20).map((v) => scrub(v, { depth: depth - 1, stats }));
  const out = {};
  let i = 0;
  for (const [k, v] of Object.entries(value)) {
    if (++i > breadth) { out['[truncated]'] = true; break; }   // 广度截断
    if (SENSITIVE.test(k)) { stats.redacted++; continue; }     // 键级删除
    out[k] = scrub(v, { depth: depth - 1, breadth, stats });
  }
  return out;
}
// scrub({ user: { phone: '13812345678', name: 'x', addr: { deep: { deep2: 1 } } } })
// => { user: { name: 'x', addr: { deep: '[depth-limit]' } } }（phone 键删、深层截断）
// stats.redacted 上报（审计：这个埋点清洗了几处——清洗量大 = 上游就该不采）
// 防御边界：depth/breadth 上限防"恶意大对象"把 SDK 打爆（DoS 防线）
```

**评分点**：
- 递归清洗三规则（键黑名单/值 PII/深度广度截断）——本题核心。
- stats 统计上报（审计闭环：清洗量大 = 采集策略问题）。
- depth/breadth 的 DoS 防线。
- 与 PER-411 的关系（单层规则 → 嵌套工程化）。
