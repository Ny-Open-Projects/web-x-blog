## HW-108：手写断网请求队列——offline 入队、online 恢复重发、幂等键与超时清理
**答**：弱网/断网体验的关键组件：请求失败且判定为网络原因（TypeError: Failed to fetch / navigator.onLine=false）时入 IndexedDB 队列，online 事件或 SW sync 触发重放；幂等键防重复提交；TTL 清理过期请求（超过 24h 的操作提示用户手动处理，避免过期副作用）。

```javascript
class OfflineQueue {
  constructor(store) {
    this.store = store;                              // IDB 封装（HW-107）
    addEventListener('online', () => this.replay());
  }
  async send(url, { method = 'POST', body, idempotencyKey = crypto.randomUUID?.() ?? String(Math.random()), ttl = 24 * 3600e3 } = {}) {
    const item = { url, method, body, key: idempotencyKey, at: Date.now(), ttl };
    try {
      return await this.#fire(item);                 // 先直接发
    } catch (e) {
      if (!this.#isNetError(e) || !navigator.onLine === false && navigator.onLine) throw e;
      await this.store.put('outbox', item, item.key); // 网络原因：入队（持久化）
      return { queued: true, key: item.key };
    }
  }
  async replay() {
    const items = await this.store.page('outbox', 'byAt', null, 100).then((p) => p.items);
    for (const item of items) {
      if (Date.now() - item.at > item.ttl) {         // 过期：不再重放（副作用可能已失效）
        await this.store.delete('outbox', item.key);
        report?.({ type: 'outbox-expired', key: item.key });
        continue;
      }
      try {
        await this.#fire(item);
        await this.store.delete('outbox', item.key); // 成功出队
      } catch (e) {
        if (!this.#isNetError(e)) await this.store.delete('outbox', item.key);  // 业务错误：不重试
        break;                                       // 仍断网：停住等下次 online
      }
    }
  }
  #fire({ url, method, body, key }) {
    return fetch(url, { method, body: JSON.stringify(body),
      headers: { 'Content-Type': 'application/json', 'Idempotency-Key': key } })
      .then((r) => { if (!r.ok) throw new Error(String(r.status)); return r.json(); });
  }
  #isNetError(e) { return /fetch|network/i.test(String(e)); }
}
// 语义：网络错误入队重放；4xx 业务错误不重放（重放也不会变好）；5xx 且在线时可立即重试一次
// 幂等键服务端去重：重放成功后重复收到同键请求返回首次结果（409/200）
```

**评分点**：
- 网络错误 vs 业务错误分流（只重放会变好的请求）。
- 持久化队列（IDB）+ online 触发重放 + 仍断网 break 等待。
- 幂等键全链路（生成/头部/服务端去重）。
- TTL 过期清理与用户提示（避免过期副作用）。重放按时间序。
