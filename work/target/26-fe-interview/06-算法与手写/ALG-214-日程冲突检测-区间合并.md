**场景**：会议室预约列表（可能乱序、重叠），要合并已占用区间并输出"当日空闲时段"（工作时间 9:00-18:00 内）。

**思路**：按 start 排序 → 线性合并（重叠判定 cur.end >= next.start）→ 已占用区间的补集即空闲。O(n log n)。

```javascript
function freeSlots(bookings, workStart = 9 * 60, workEnd = 18 * 60) {  // 分钟制
  const sorted = bookings
    .map(({ start, end }) => [start, end])
    .sort((a, b) => a[0] - b[0]);
  const busy = [];
  for (const [s, e] of sorted) {
    const last = busy.at(-1);
    if (last && s <= last[1]) last[1] = Math.max(last[1], e);   // 重叠/相接：合并（s<=last.end）
    else busy.push([s, e]);
  }
  const free = [];
  let cursor = workStart;
  for (const [s, e] of busy) {
    if (s > cursor) free.push([cursor, s]);      // 空洞
    cursor = Math.max(cursor, e);
  }
  if (cursor < workEnd) free.push([cursor, workEnd]);
  return free;
}
freeSlots([{ start: 600, end: 690 }, { start: 660, end: 720 }, { start: 800, end: 840 }]);
// busy 合并 => [[600,720],[800,840]]；free => [[540,600],[720,800],[840,1080]]
// 即 9:00-10:00、12:00-13:20、14:00-18:00 空闲
// 边界：零长区间过滤；跨天预约截断到工作时间内
```

**评分点**：
- 排序后线性合并正确（`s <= last[1]` 包含"相接"的合并语义，边界处理讲清）。
- 空闲计算 = 工作时间与已占用区间的差集（cursor 推进逻辑）。
- O(n log n) 复杂度（排序主导）。
- 场景对应：会议室/预约日历的空闲计算。
