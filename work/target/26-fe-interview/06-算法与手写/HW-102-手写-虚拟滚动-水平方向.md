**答**：垂直虚拟列表（HW-037/067/068）的横向变体：时间轴/甘特图按"天"为列，列宽可不同（工作日/节假日）。实现：列宽前缀和 + 二分定位（同 HW-068 的动态高度思路横向化）+ transform 定位渲染窗口。

```javascript
class HorizontalVirtual {
  constructor(container, widths) {          // widths: 每列宽度数组
    Object.assign(this, { c: container, widths });
    this.prefix = [0];
    widths.reduce((acc, w, i) => { this.prefix.push(acc + w); return acc + w; }, 0);
    this.total = this.prefix.at(-1);
    container.addEventListener('scroll', () => this.render(), { passive: true });
  }
  #colAt(x) {                               // 二分：prefix[i] <= x 的最大 i
    let lo = 0, hi = this.widths.length - 1;
    while (lo < hi) { const mid = (lo + hi + 1) >> 1;
      if (this.prefix[mid] <= x) lo = mid; else hi = mid - 1; }
    return lo;
  }
  render() {
    const { scrollLeft, clientWidth } = this.c;
    const start = Math.max(0, this.#colAt(scrollLeft) - 3);              // 左缓冲 3 列
    let end = start, acc = 0;
    while (end < this.widths.length && acc < clientWidth) { acc += this.widths[end]; end++; }
    end = Math.min(this.widths.length, end + 3);                         // 右缓冲
    this.#mount(start, end);
    // 定位：left = prefix[start]（不用 padding——横向用 transform 或绝对定位）
    return { start, end };
  }
  #mount(start, end) {
    // 绝对定位挂载：colEl.style.left = this.prefix[i] + 'px'
    // 节点复用池同 HW-067；容器 position:relative，列 absolute
  }
}
// 甘特图场景：widths[i] = 节假日 48px / 工作日 96px
// 复杂度：定位 O(logN)，渲染 O(可视列数)，与总列数无关（1 万天时间轴流畅）
```

**评分点**：
- 前缀和 + 二分定位列（列宽不均是本题核心，均宽场景退化可 O(1)）。
- 左右缓冲列（-3/+3）防边缘闪烁；越界 clamp。
- 横向定位用 left/transform（不是垂直的 padding 技巧）。
- 节点复用意识；复杂度与总列数无关的说明。
