## HW-356：手写一个撤销栈的图形场景适配：变换合并与快照混合

**答**：
- 需求：实现 GraphicHistory：细粒度变换（move/resize 连续拖拽合并为一次——拖拽结束才入栈）；粗粒度快照（结构变更如删除组直接存快照）；undo/redo 统一入口（变换逆操作 or 快照恢复）；内存上限（快照限量）。
- 边界：拖拽过程不产生历史（dragEnd 才 push）；变换合并条件（同节点同类型且时间窗内）；快照与变换混合时 undo 顺序正确。
- 评分点：拖拽结束才入栈；合并窗口；混合模式顺序。

```javascript
class GraphicHistory {
  constructor({ mergeMs = 300, snapLimit = 20 } = {}) {
    this.undo = []; this.redo = []; this.mergeMs = mergeMs; this.snapLimit = snapLimit;
    this.last = null;
  }
  pushTransform(nodeId, type, before, after) {               // 细粒度：拖拽结束才调
    const top = this.undo.at(-1);
    if (top?.kind === 'transform' && top.nodeId === nodeId && top.type === type
      && Date.now() - top.t < this.mergeMs) {
      top.after = after; top.t = Date.now();                 // 合并：只更新终态
      return;
    }
    this.undo.push({ kind: 'transform', nodeId, type, before, after, t: Date.now() });
    this.redo = [];
  }
  pushSnapshot(doc) {                                        // 粗粒度：结构变更
    this.undo.push({ kind: 'snapshot', before: doc });
    if (this.undo.filter(x => x.kind === 'snapshot').length > this.snapLimit) {
      const i = this.undo.findIndex(x => x.kind === 'snapshot');
      this.undo.splice(i, 1);
    }
    this.redo = [];
  }
  undo() {
    const op = this.undo.pop();
    if (!op) return;
    if (op.kind === 'transform') applyProps(op.nodeId, op.before);
    else restoreDoc(op.before);
    this.redo.push(op);
  }
  redo() {
    const op = this.redo.pop();
    if (!op) return;
    if (op.kind === 'transform') applyProps(op.nodeId, op.after);
    else restoreDoc(op.after ?? op.before);
    this.undo.push(op);
  }
}
```
