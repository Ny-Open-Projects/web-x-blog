## ALG-509：手写双指针贪心：Container With Most Water 变体

**答**：
- 题目：AB 实验的两个对照组（用户量序列柱状），选两柱使「min(左,右) × 距离」最大（容量模型）。双指针经典：短柱移动。
- 思路：左右指针；面积 = min(h[l], h[r]) × (r-l)；移动较短一侧（移动长侧不可能更大——高度受短柱限制且距离变短）。
- 评分点：移动短柱的论证；O(n)；反证格式。

```javascript
function maxContainer(heights) {                           // 盛水容器
  let l = 0, r = heights.length - 1, best = 0;
  while (l < r) {
    const area = Math.min(heights[l], heights[r]) * (r - l);
    best = Math.max(best, area);
    if (heights[l] < heights[r]) l++;                      // 移短柱
    else r--;
  }
  return best;
}
// 论证：设 h[l] < h[r]，保持 l 移动 r 只会面积更小（min 受 h[l] 限且距离缩短）
// 故 l 侧所有与 r 的组合都被 (l, r) 支配——安全排除 l
```
