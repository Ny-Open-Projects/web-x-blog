## ALG-437：手写编辑距离受限版本：纠错预算限制

**答**：
- 题目：只允许最多 2 次编辑的快速判断（大量候选先粗筛）——带 early exit 的编辑距离：任意前缀最小值 > 预算即返回。
- 思路：DP 过程中若整行 min > k 提前返回 false（距离只会增不减）；或按对角线带状 DP（Ukkonen 思想：只算 |i-j|<=k 的带区）。
- 评分点：整行 min 剪枝；带状 DP 的正确性（超出带区的状态不可能 <= k）；先粗筛后精筛的管线。

```javascript
function editDistanceAtMost(a, b, k) {                     // 是否 <= k
  if (Math.abs(a.length - b.length) > k) return false;     // 长度差剪枝
  const m = a.length, n = b.length;
  const dp = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(Infinity));
  dp[0][0] = 0;
  for (let i = 0; i <= m; i++)
    for (let j = Math.max(0, i - k); j <= Math.min(n, i + k); j++) {   // 带状：|i-j|<=k
      if (i === 0) { dp[i][j] = j; continue; }
      if (j === 0) { dp[i][j] = i; continue; }
      dp[i][j] = a[i - 1] === b[j - 1] ? dp[i - 1][j - 1]
        : 1 + Math.min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]);
    }
  return dp[m][n] <= k;
}
// 带状 DP 复杂度 O(k × min(m,n))——k=2 时近似线性，适合海量候选粗筛
// 管线：editDistanceAtMost(≤2) 粗筛 → editDistance 精排
```
