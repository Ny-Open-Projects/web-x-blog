## ALG-542：手写计数排序应用：年龄段分布

**答**：
- 题目：用户年龄 0~120，统计分布且输出「按年龄段聚合（0-18/19-35/36-60/60+）」——计数排序思想：桶即年龄段，O(n+k)。
- 思路：计数数组 cnt[age]++；聚合段 = 桶区间求和；稳定性说明（计数排序对数值稳定，带负载需桶内有序）。
- 评分点：桶即下标；段聚合；计数排序适用（值域小且非负）。

```javascript
function ageDistribution(users) {                         // users: [{name, age}]
  const cnt = new Array(121).fill(0);
  for (const u of users) cnt[u.age]++;                     // 计数
  const bands = [[0, 18, '未成年'], [19, 35, '青年'], [36, 60, '中年'], [61, 120, '老年']];
  return bands.map(([lo, hi, label]) => ({
    label, count: cnt.slice(lo, hi + 1).reduce((s, x) => s + x, 0),   // 段聚合
    ratio: +(cnt.slice(lo, hi + 1).reduce((s, x) => s + x, 0) / users.length * 100).toFixed(1) + '%',
  }));
}
// 计数排序适用：值域 k 小且非负；复杂度 O(n + k)
// 带负载排序（按年龄排用户）：桶内保持插入序即可稳定
```
