**场景**：低代码页面里组件 A 依赖 B 的数据（`deps: ['B']`），初始化必须按依赖序：无依赖组件**同层可并行**初始化（省时）。Kahn 算法天然产出"分层"结构——每层内并行、层间串行。

**思路**：入度表 + 队列；每轮弹出当前入度 0 的集合（同层），全部并行执行后把它们的下游入度减 1，入度归零者进入下一层。成环检测：处理节点数 < 总数。

```javascript
async function topoInit(components) {                 // { id, deps: [id], init: async () => {} }
  const indeg = new Map(), dependents = new Map();
  for (const c of components) {
    indeg.set(c.id, c.deps?.length ?? 0);
    for (const d of c.deps ?? []) {
      if (!dependents.has(d)) dependents.set(d, []);
      dependents.get(d).push(c.id);
    }
  }
  let layer = [...components.filter((c) => indeg.get(c.id) === 0).map((c) => c.id)];
  const inited = new Set(), order = [];
  while (layer.length) {
    await Promise.all(layer.map(async (id) => {       // 同层并行初始化
      const c = components.find((x) => x.id === id);
      await c.init?.();
      inited.add(id);
    }));
    order.push(layer);
    const nextLayer = [];
    for (const id of layer) {
      for (const dep of dependents.get(id) ?? []) {
        indeg.set(dep, indeg.get(dep) - 1);
        if (indeg.get(dep) === 0) nextLayer.push(dep);
      }
    }
    layer = nextLayer;
  }
  if (inited.size < components.length) {
    throw new Error(`循环依赖: ${components.filter((c) => !inited.has(c.id)).map((c) => c.id)}`);
  }
  return order;    // [[无依赖层], [第二层], ...] —— 层内并行、层间串行
}
// 5 个组件、依赖深度 3：串行 5 次初始化 vs 分层并行 3 波（墙钟时间取决于最慢层）
```

**评分点**：
- Kahn 算法正确（入度表 + 归零入队）。
- **分层并行**调度（同层 Promise.all）是本题亮点——纯串行拓扑排序不算满分。
- 成环检测（处理数 < 总数）并报出环内节点。
- 复杂度 O(V+E)；墙钟时间 = 最慢层。
