## ALG-357：手写区间合并线段树（最长连续 1）：连续签到最长天数

**答**：
- 题目：用户签到表（0/1 按天），查任意区间内最长连续签到天数，支持补签（单点改 1）。经典区间合并线段树。
- 思路：每节点维护 prefix（前缀连续 1 长度）、suffix（后缀）、best（区间内最长）。合并：best = max(左 best, 右 best, 左 suffix + 右 prefix)；prefix = 左 prefix 满 + 右 prefix；查询返回根节点 best。
- 评分点：三字段定义清晰；合并公式（跨节点拼接）；补签即单点赋值。

```javascript
class MergeSegTree {
  constructor(bits) {
    this.n = bits.length; this.t = new Array(4 * this.n);
    this.build(bits);
  }
  leaf(v) { return { pre: v, suf: v, best: v }; }          // 叶子节点
  merge(L, R) {                                            // 跨节点拼接
    return {
      pre: L.pre === L.len ? L.len + R.pre : L.pre,        // 左全满才接右前缀
      suf: R.suf === R.len ? R.len + L.suf : R.suf,
      best: Math.max(L.best, R.best, L.suf + R.pre),       // 跨中点拼接
    };
  }
  build(a, node = 1, l = 0, r = this.n - 1) {
    this.t[node] = { len: r - l + 1 };
    if (l === r) return Object.assign(this.t[node], this.leaf(a[l]));
    const m = (l + r) >> 1;
    this.build(a, node * 2, l, m); this.build(a, node * 2 + 1, m + 1, r);
    this.t[node] = { len: r - l + 1, ...this.merge(this.t[node * 2], this.t[node * 2 + 1]) };
  }
  sign(i) { this.set(i, 1); }                              // 补签
  set(i, v, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return Object.assign(this.t[node], this.leaf(v));
    const m = (l + r) >> 1;
    i <= m ? this.set(i, v, node * 2, l, m) : this.set(i, v, node * 2 + 1, m + 1, r);
    Object.assign(this.t[node], this.merge(this.t[node * 2], this.t[node * 2 + 1]));
  }
  best(ql, qr) { return this.query(ql, qr).best; }
  query(ql, qr, node = 1, l = 0, r = this.n - 1) {
    if (ql <= l && r <= qr) return this.t[node];
    const m = (l + r) >> 1;
    if (qr <= m) return this.query(ql, qr, node * 2, l, m);
    if (ql > m) return this.query(ql, qr, node * 2 + 1, m + 1, r);
    return this.merge(this.query(ql, m, node * 2, l, m),
      this.query(m + 1, qr, node * 2 + 1, m + 1, r));
  }
}
```
