## HW-405：手写一个自动摘要生成器：句子打分与压缩

**答**：
- 需求：实现 ExtractSummary：抽取式摘要（非生成）——分句 → 句子打分（关键词 TF-IDF 加权 + 位置权重（首段加权）+ 长度惩罚（过长过短降分））→ 按 budget 句数取 Top；输出保持原文顺序。
- 边界：分句规则（。！? 边界 + 引号处理）；关键词权重（停用词过滤）；位置权重递减；输出句子数预算与字数预算双控。
- 评分点：TF-IDF 打分；位置权重；原文顺序输出。

```javascript
function extractSummary(text, { maxSentences = 3, maxChars = 200 } = {}) {
  const sents = splitSentences(text);                        // 分句
  const stop = new Set(['的', '了', '是', '在', '和', 'the', 'a', 'of']);
  const tf = new Map();                                      // 词频
  for (const s of sents)
    for (const w of tokenize(s)) if (!stop.has(w)) tf.set(w, (tf.get(w) ?? 0) + 1);
  const N = sents.length;
  const scored = sents.map((s, i) => {
    const words = tokenize(s).filter(w => !stop.has(w));
    const tfidf = words.reduce((sum, w) => sum + Math.log(1 + (tf.get(w) ?? 0)), 0)   // 简化 TF-IDF
      / Math.max(1, words.length);                           // 归一化防长句占优
    const posWeight = 1 + Math.max(0, (5 - i)) * 0.1;        // 首段位置加权
    const lenPenalty = s.length < 10 ? 0.5 : s.length > 100 ? 0.7 : 1;   // 长度惩罚
    return { s, i, score: tfidf * posWeight * lenPenalty };
  });
  const picked = scored.sort((a, b) => b.score - a.score)
    .filter((s, idx) => idx < maxSentences && s.s.length <= maxChars)
    .sort((a, b) => a.i - b.i)                               // 保持原文顺序
    .map(x => x.s);
  return picked.join('');
}
function splitSentences(text) {                              // 分句（含引号处理）
  return text.split(/(?<=[。！？!?])\s*/).filter(s => s.trim());
}
```
