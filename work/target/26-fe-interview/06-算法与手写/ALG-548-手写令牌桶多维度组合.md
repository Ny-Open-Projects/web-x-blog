## ALG-548：手写令牌桶多维度组合：接口多维限流

**答**：
- 题目：接口多维限流（按用户 + 按接口 + 全局三层），任一层拒绝即拒绝。多个令牌桶实例组合。
- 思路：桶组 = Map<dimension, TokenBucket>；acquire 时逐层 acquire（全过才放行）；部分成功的回滚（退回已扣令牌）。
- 评分点：多层桶组合；回滚语义；维度爆炸控制（组合键设计）。

```javascript
class MultiDimLimiter {
  constructor(limits) {                                    // limits: [{dim: 'user', rate, burst}, ...]
    this.limits = limits;
    this.buckets = new Map();                              // key -> TokenBucket
  }
  bucket(dim, key) {
    const k = dim + ':' + key;
    return this.buckets.get(k) ?? this.buckets.set(k,
      new TokenBucket(this.limits.find(l => l.dim === dim))).get(k);
  }
  async acquire(user, api) {
    const dims = [['user', user], ['api', api], ['global', '*']];
    const acquired = [];
    for (const [dim, key] of dims) {
      try {
        await this.bucket(dim, key).acquire(1);
        acquired.push([dim, key]);                          // 记录成功层
      } catch {
        for (const [d, k] of acquired) this.bucket(d, k).refund(1);   // 回滚已扣令牌
        throw new Error(`rate-limited@${dim}`);
      }
    }
  }
}
// TokenBucket 需补 refund(n)：this.tokens = Math.min(this.burst, this.tokens + n)
```
