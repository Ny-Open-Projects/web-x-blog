**场景**：表格横向滚动时表头同步位移、行虚拟化时侧标尺同步——多容器滚动联动：主从模式（只有一个源），从容器用 transform 跟随（不触发自己的 scroll 事件——防循环）。rAF 合帧统一派发。

**思路**：主容器 scroll（rAF 合帧）→ 从容器 transform: translateX（不设 overflow scroll，无自身滚动事件）→ 防循环天然成立（transform 不产生 scroll）。

```javascript
function syncScroll(master, followers) {
  let ticking = false;
  master.addEventListener('scroll', () => {
    if (ticking) return;
    ticking = true;
    requestAnimationFrame(() => {
      ticking = false;
      const x = master.scrollLeft, y = master.scrollTop;
      for (const f of followers) {
        f.el.style.transform = `translate(${-x}px, ${-y}px)`;   // transform 跟随（不产生 scroll 事件）
        f.el.style.width = master.scrollWidth + 'px';    // 从容器内容宽度 = 主滚动宽（对齐）
      }
    });
  }, { passive: true });
}
// 防循环的关键：从容器用 transform（不滚动）—— 两个真滚动容器互相监听 = 死循环（经典 bug）
// rAF 合帧：多次 scroll 一帧一次派发（PER-116 模式）
// 主从选择：用户操作的主容器是源（表头/标尺永远是从）—— 固定方向无歧义
// 精度：transform 用 -scrollLeft（负向移动内容 = 视觉同步）—— 与 master.scrollLeft 完全一致无累积误差
```

**评分点**：
- 主从模式 + transform 跟随（从容器无 scroll 事件防死循环）——本题核心（双滚动容器互监是经典 bug）。
- rAF 合帧派发。
- 主从方向固定（无循环歧义）。
- 从容器内容宽对齐（scrollWidth 同步）。
