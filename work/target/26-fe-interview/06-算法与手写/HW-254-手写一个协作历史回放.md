## HW-254：手写一个协作历史回放：按版本重放操作生成任意时刻文档

**答**：
- 需求：实现 HistoryReplay：ops 日志 + 初始快照；at(rev) 生成该版本文档（快照加速：找 rev 之前最近快照，重放其后 ops）；snapshotEvery(n) 每 n 版生成快照存储；provide timeline(min, max) 用于时间轴 UI（每版本变更摘要）。
- 边界：at(rev) 越界返回最新；快照存储内存上限（保留最近 10 个）；重放 op 缺失（日志空洞）报数据错误。
- 评分点：快照+重放加速；timeline 摘要；空洞检测。

```javascript
class HistoryReplay {
  constructor(baseDoc, ops) { this.base = baseDoc; this.ops = ops; this.snaps = new Map([[0, baseDoc]]); }
  snapshotEvery(n) {                                       // 每 n 版快照
    for (let rev = n; rev <= this.ops.length; rev += n)
      this.snaps.set(rev, this.at(rev));
    while (this.snaps.size > 10) this.snaps.delete(this.snaps.keys().next().value);   // 上限
  }
  at(rev) {
    rev = Math.min(rev, this.ops.length);
    let doc, start = 0;
    const snapRevs = [...this.snaps.keys()].filter(r => r <= rev).sort((a, b) => b - a);
    if (snapRevs.length) { doc = clone(this.snaps.get(snapRevs[0])); start = snapRevs[0]; }
    else doc = clone(this.base);
    for (let i = start; i < rev; i++) {                    // 重放区间 ops
      const op = this.ops[i];
      if (!op) throw new Error('log-hole at ' + i);        // 空洞检测
      applyOpToDoc(doc, op);
    }
    return doc;
  }
  timeline(min = 0, max = this.ops.length) {               // 时间轴摘要
    const out = [];
    for (let i = min; i < max; i++) {
      const op = this.ops[i];
      out.push({ rev: i + 1, type: op.type, pos: op.pos,
        digest: op.type === 'insert' ? op.text.slice(0, 10) : `-${op.text.length}` });
    }
    return out;
  }
}
```
