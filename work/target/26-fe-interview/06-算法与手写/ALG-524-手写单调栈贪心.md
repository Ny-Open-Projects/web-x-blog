## ALG-524：手写单调栈+贪心：柱状图最大矩形（仪表盘布局）

**答**：
- 题目：仪表盘网格各列可用高度，求「最大矩形布局」（连续列 × 最小高度）。经典单调栈 O(n)。
- 思路：递增栈；出栈时高度 = 栈顶，右边界 = 当前 i，左边界 = 新栈顶 + 1；面积 = h × 宽。
- 评分点：递增栈维护；出栈时结算；哨兵简化（首尾加 0）。

```javascript
function largestRectangle(heights) {
  const h = [0, ...heights, 0];                            // 哨兵
  const stack = [];
  let best = 0, bestRange = null;
  for (let i = 0; i < h.length; i++) {
    while (stack.length && h[stack.at(-1)] > h[i]) {
      const height = h[stack.pop()];
      const left = stack.at(-1) + 1;
      const width = i - left;
      if (height * width > best) { best = height * width; bestRange = [left, i - 1]; }
    }
    stack.push(i);
  }
  return { area: best, columns: bestRange };
}
// 例：[2,1,5,6,2,3] → 10（列 2-3 高 5）
// 场景：仪表盘相邻列等高区域最大化利用
```
