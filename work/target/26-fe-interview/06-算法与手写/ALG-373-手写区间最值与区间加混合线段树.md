## ALG-373：手写区间最值与区间加混合线段树：限流配额消耗与峰值

**答**：
- 题目：每时段有配额上限（会批量调整）与已用量（会区间累加），查「区间内剩余配额最小值」（最紧瓶颈）。节点存 max/maxLazy（赋值）+ addLazy（增量），下推按「先赋值后加」顺序（同 ALG-366 语义）。
- 思路：max 树的区间加懒标记（max 不需 len，直接加）；赋值与加标记复合；查询区间 min（另一棵树或同树存 min——此处演示同构 max/min 双字段）。
- 评分点：max 树区间加无 len 项；标记复合顺序；min/max 同步维护。

```javascript
class MinMaxTree {
  constructor(n) { this.n = n;
    this.min = new Array(4 * n).fill(0); this.max = new Array(4 * n).fill(0);
    this.lazy = new Array(4 * n).fill(0); }                // 增量标记（无赋值简化）
  pushdown(node) {
    if (!this.lazy[node]) return;
    for (const c of [node * 2, node * 2 + 1]) {
      this.min[c] += this.lazy[node]; this.max[c] += this.lazy[node];
      this.lazy[c] += this.lazy[node];
    }
    this.lazy[node] = 0;
  }
  add(ql, qr, v, node = 1, l = 0, r = this.n - 1) {
    if (qr < l || r < ql) return;
    if (ql <= l && r <= qr) {                              // max 树加标记无 len
      this.min[node] += v; this.max[node] += v; this.lazy[node] += v; return;
    }
    this.pushdown(node);
    const m = (l + r) >> 1;
    this.add(ql, qr, v, node * 2, l, m); this.add(ql, qr, v, node * 2 + 1, m + 1, r);
    this.min[node] = Math.min(this.min[node * 2], this.min[node * 2 + 1]);
    this.max[node] = Math.max(this.max[node * 2], this.max[node * 2 + 1]);
  }
  bottleneck(ql, qr, cap, node = 1, l = 0, r = this.n - 1) {   // 区间最小剩余配额
    if (qr < l || r < ql) return Infinity;
    if (ql <= l && r <= qr) return cap - this.min[node];
    this.pushdown(node);
    const m = (l + r) >> 1;
    return Math.min(this.bottleneck(ql, qr, cap, node * 2, l, m),
      this.bottleneck(ql, qr, cap, node * 2 + 1, m + 1, r));
  }
}
```
