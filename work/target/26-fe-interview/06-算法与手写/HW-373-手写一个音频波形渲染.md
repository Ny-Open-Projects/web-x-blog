## HW-373：手写一个音频波形渲染：解码与采样降精度

**答**：
- 需求：实现 WaveformRender：AudioContext.decodeAudioData 解码 → 取 channel 数据；峰值提取（每像素桶取 min/max，输出峰值数组——百万样本 → 数百像素级）；渲染（上下对称条形，min/max 区间）；缩放时按可视像素重采样（不全量重算）。
- 边界：多声道取最大峰值（或混合）；解码在 Worker 或分块（大文件解码秒级）；缩放平滑（缓存多档精度峰值）。
- 评分点：像素桶峰值；多档精度缓存；解码不阻塞。

```javascript
class WaveformRender {
  constructor(ctx) { this.ctx = ctx; this.peaks = new Map(); }   // 精度 → 峰值数组
  async decode(file) {
    const buf = await file.arrayBuffer();
    const audio = await this.ctx.decodeAudioData(buf);       // 主线程解码（大文件建议 Worker）
    this.samples = audio.getChannelData(0);                  // 取第一声道
    this.duration = audio.duration;
    this.buildPeaks(1000);                                   // 预建基础精度
  }
  buildPeaks(px) {                                           // 像素桶峰值提取
    if (this.peaks.has(px)) return this.peaks.get(px);
    const out = [];
    const bucket = Math.ceil(this.samples.length / px);
    for (let i = 0; i < px; i++) {
      let min = 0, max = 0;
      const s = i * bucket, e = Math.min(s + bucket, this.samples.length);
      for (let j = s; j < e; j += 4) {                       // 步进采样加速
        const v = this.samples[j];
        if (v < min) min = v; if (v > max) max = v;
      }
      out.push([min, max]);
    }
    this.peaks.set(px, out);
    return out;
  }
  render(canvas, { from = 0, to = 1 } = {}) {                // 缩放区间渲染
    const w = canvas.width, h = canvas.height;
    const px = Math.round(w * (to - from));                  // 可视像素数
    const peaks = this.buildPeaks(Math.max(px, 200));        // 按需精度
    const ctx = canvas.getContext('2d');
    ctx.clearRect(0, 0, w, h);
    ctx.fillStyle = '#4a90d9';
    const i0 = Math.floor(from * peaks.length);
    const i1 = Math.ceil(to * peaks.length);
    const visible = peaks.slice(i0, i1);
    visible.forEach(([min, max], i) => {
      const x = i / visible.length * w;
      ctx.fillRect(x, h / 2 * (1 - max), Math.max(1, w / visible.length),   // 上下对称
        h / 2 * (max - min));
    });
  }
}
```
