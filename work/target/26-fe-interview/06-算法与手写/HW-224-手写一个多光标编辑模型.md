## HW-224：手写一个多光标编辑模型：多选区独立编辑与操作合并

**答**：
- 需求：实现 MultiCursor：cursors 数组（每个含 text/pos），addCursorAt(occurrence) 按"下一个匹配词"加光标；applyEdit(str) 对每个光标独立插入（从后往前应用避免位置失效）；全部光标操作合并为单条 undo。
- 边界：光标重叠合并；删除时多光标各自删除前字符；从后往前应用保证前面插入不影响后面 offset。
- 评分点：倒序应用；重叠合并；单 undo 单元。

```javascript
class MultiCursor {
  constructor(text) { this.text = text; this.cursors = [0]; }
  addCursorNext(word) {                                        // 下一个匹配处加光标
    const starts = this.cursors.map(p => this.wordAt(p)).filter(Boolean);
    const last = starts.at(-1);
    let i = last ? last.end : 0;
    while (i < this.text.length) {
      const idx = this.text.indexOf(word, i);
      if (idx < 0) break;
      if (!this.cursors.some(p => Math.abs(p - idx) < word.length)) { this.cursors.push(idx); break; }
      i = idx + 1;
    }
    this.cursors.sort((a, b) => a - b);
    this.cursors = dedupe(this.cursors, word.length);          // 重叠合并
  }
  applyEdit(str) {                                             // 倒序应用
    const ops = [];
    [...this.cursors].sort((a, b) => b - a).forEach(p => {
      this.text = this.text.slice(0, p) + str + this.text.slice(p);
      ops.push({ p, len: str.length });
    });
    this.cursors = ops.map(o => o.p + o.len).sort((a, b) => a - b);   // 都在插入文本后
    return ops;                                                // 供单条 undo 合并
  }
  wordAt(p) { const m = /^[A-Za-z0-9_]+/.exec(this.text.slice(p)); return m && { end: p + m[0].length }; }
}
const dedupe = (arr, gap) => arr.filter((v, i) => i === 0 || v - arr[i - 1] >= gap);
```

## 补充：评分点与变体

**评分点**：

- 编辑一律从后往前应用，前面的插入会改变后面光标的 offset，正序应用会让后续光标全部错位
- 光标重叠或相邻必须先合并，否则同一位置会插入两遍同样的字符
- 全部光标操作合成一个 undo 单元，逐光标入栈会让用户按十次撤销
- addCursorNext 的搜索起点在当前光标之后且要处理「无更多匹配」，否则原地死循环

**变体与延伸**：

1. 多个光标的删除区间重叠 → 先归一化成互不相交的区间再执行，直接逐个删会删掉两倍长度
2. 列编辑每行输入内容不同 → 按列索引取对应字符，短行补空格或跳过该行
3. 输入法组合时多光标怎么响应 → 组合期间只作用于主光标，compositionend 后再分发到其余光标
