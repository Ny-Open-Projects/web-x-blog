## HW-260：手写一个操作去抖与合批：高频输入合并为一次同步

**答**：
- 需求：实现 OpBatcher：local op 到达时不立即发送，缓冲 80ms（或累积字节 > 4KB 提前发送）；发送时合并缓冲 ops 为单个复合 op（连续 insert 拼接、区间 delete 合并）；服务端 ack 作用于复合 op 整体；undo 粒度仍保持操作级（本地栈不变）。
- 边界：合批不能改变语义顺序（按到达序拼接）；类型交替（insert→delete→insert）不可合并为单 op 时打包为数组提交；flush 强制发送。
- 评分点：双触发条件；可合并判定；undo 粒度分离。

```javascript
class OpBatcher {
  constructor({ flushMs = 80, maxBytes = 4096 } = {}) {
    this.buf = []; this.bytes = 0; this.timer = null;
    this.flushMs = flushMs; this.max = maxBytes;
  }
  push(op) {
    this.buf.push(op);
    this.bytes += (op.text ?? '').length;
    if (this.bytes >= this.max) return this.flush();        // 字节提前触发
    if (!this.timer) this.timer = setTimeout(() => this.flush(), this.flushMs);
  }
  flush() {
    clearTimeout(this.timer); this.timer = null;
    if (!this.buf.length) return null;
    const n = this.buf.length;
    const merged = mergeOps(this.buf);
    this.buf = []; this.bytes = 0;
    send({ compound: merged, undoBase: n });                // undo 粒度本地保留
    return merged;
  }
}
function mergeOps(ops) {                                    // 相邻可合并则合并
  const out = [];
  for (const op of ops) {
    const last = out.at(-1);
    if (last && last.type === 'insert' && op.type === 'insert' && last.pos + last.text.length === op.pos)
      last.text += op.text;                                 // 连续插入拼接
    else out.push({ ...op });
  }
  return out.length === 1 ? out[0] : out;                   // 单条直接用，多条打包
}
```

## 补充：评分点与变体

**评分点**：

- 双触发条件要互斥收口：定时器到点或字节超 4KB 任一生效，触发后都要清定时器并把缓冲长度归零，否则重复 flush 会发两遍
- 可合并判定只看相邻同类型 op：`insert→delete→insert` 交替时必须打包成数组提交，强行拼接会改变语义
- 合批只改传输粒度不改语义顺序，按到达序拼接；本地 undo 栈仍按操作级入栈，不能跟着合批
- flush 要幂等，ack 回来前重复调用不能二次发送，需要 sending 标志位

**变体与延伸**：

1. 断网时缓冲持续增长怎么控 → 设字节上限，触顶强制落本地队列并切离线模式，不能无限堆在内存里
2. ack 丢失导致服务端重复应用 → 每个复合 op 带客户端 seq，服务端按 seq 幂等去重
3. 合批后 undo 粒度怎么保住 → 复合 op 内部保留原始 op 数组，undo 逐条回退而非整包回退
