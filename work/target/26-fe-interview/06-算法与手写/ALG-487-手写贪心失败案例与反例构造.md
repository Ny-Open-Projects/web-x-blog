## ALG-487：手写贪心失败案例与反例构造：警惕贪心直觉

**答**：
- 题目：给出三个「直觉贪心会错」的经典题与反例构造方法——训练「先想反例再写贪心」的习惯。
- 思路：① 硬币找零（标准币值贪心对，任意币值错：1,3,4 找 6 → 贪心 4+1+1=3 枚 vs 最优 3+3=2 枚）；② 区间覆盖选最长（局部最长可能错位）；③ 0-1 背包比值（ALG-486 反例）。反例构造法：小规模枚举最优解 vs 贪心解对比。
- 评分点：三个反例；反例构造方法论（小规模暴力对拍）；贪心适用判断（交换论证或反悔堆）。

```javascript
function coinChangeGreedyFail() {                          // 反例演示
  const coins = [1, 3, 4];                                  // 任意币值
  const target = 6;
  const greedy = [...coins].sort((a, b) => b - a);          // 贪心：大币优先
  let remain = target, count = 0;
  for (const c of greedy) while (remain >= c) { remain -= c; count++; }
  return { greedy: count, optimal: 2, optimalPlan: '3+3',
    lesson: '贪心对「标准币值」成立（1,5,10 体系），任意币值必须 DP' };
}
function greedyCounterexampleMethod() {                    // 反例构造方法论
  return {
    step1: '小规模枚举：n ≤ 10 全排列/子集暴力求最优',
    step2: '跑候选贪心策略',
    step3: '找首个不一致输入即为反例',
    tool: '对拍脚本（同 ALG-380 思想）',
  };
}
```
