## ALG-507：手写贪心与拍卖（保留最高出价）：广告竞价

**答**：
- 题目：竞价流：每个广告位由出价最高者得（二价拍卖：成交价 = 第二高价）。维护每位的最高出价者并计算二价成交价。
- 思路：维护 top2（最大两个出价）；新出价到来更新；成交价 = 第二高。堆/两个变量即可。
- 评分点：二价拍卖语义（激励真实报价）；top2 维护；流式更新的 O(1)。

```javascript
class SecondPriceAuction {                                 // 二价拍卖（Vickrey）
  constructor() { this.top1 = null; this.top2 = null; }    // top1: {bidder, price}
  bid(bidder, price) {
    if (!this.top1 || price > this.top1.price) {
      this.top2 = this.top1;
      this.top1 = { bidder, price };
    } else if (!this.top2 || price > this.top2.price) {
      this.top2 = { bidder, price };
    }
  }
  settle() {                                                // 结算
    if (!this.top1) return null;
    return { winner: this.top1.bidder,
      price: this.top2 ? this.top2.price : this.top1.price * 0.9 };   // 成交价 = 第二高
  }
}
// 二价拍卖激励真实报价：报低可能失去，报高不亏（只付第二高价）
```
