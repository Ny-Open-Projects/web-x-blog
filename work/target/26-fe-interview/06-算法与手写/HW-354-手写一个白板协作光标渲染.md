## HW-354：手写一个白板协作光标渲染：远端光标插值动画

**答**：
- 需求：实现 RemoteCursors：远端光标数据（user, x, y, ts）；渲染插值（每帧向目标位置缓动 0.25，收敛停帧）；标签（用户名+颜色，稳定哈希配色）；光标超时（2s 无更新淡出）；多条远端光标独立管理。
- 边界：网络抖动导致位置突变（插值平滑）；同一用户多设备（session 区分）；画布缩放/平移时光标坐标换算到视口。
- 评分点：插值停帧；稳定配色；坐标换算。

```javascript
class RemoteCursors {
  constructor() { this.peers = new Map(); this.raf = null; }
  update(sessionId, user, worldX, worldY, vp) {
    const cur = this.peers.get(sessionId) ?? {
      x: worldX, y: worldY, color: palette[hashStr(user) % palette.length], user };
    cur.targetX = worldX; cur.targetY = worldY;              // 目标位置
    cur.seen = Date.now();
    cur.vp = vp;                                             // 视口（坐标换算）
    this.peers.set(sessionId, cur);
    this.loop();
  }
  loop() {
    if (this.raf) return;
    const tick = () => {
      let moving = false;
      const now = Date.now();
      for (const [id, c] of this.peers) {
        if (now - c.seen > 2000) { this.peers.delete(id); continue; }   // 超时淡出
        const dx = c.targetX - c.x, dy = c.targetY - c.y;
        if (Math.hypot(dx, dy) > 1) {                        // 收敛停帧
          c.x += dx * 0.25; c.y += dy * 0.25; moving = true;
        }
        const s = c.vp.worldToScreen(c.x, c.y);              // 视口坐标换算
        renderCursorFlag(c.user, c.color, s.x, s.y);
      }
      if (moving) this.raf = requestAnimationFrame(tick);
      else this.raf = null;
    };
    this.raf = requestAnimationFrame(tick);
  }
}
const palette = ['#f66', '#6c6', '#66f', '#c6c', '#fa0', '#0aa'];
```
