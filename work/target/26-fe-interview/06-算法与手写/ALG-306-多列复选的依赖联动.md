## ALG-306：多列复选依赖：勾选"全选"时的联动豁免（disabled 项不参与全选/计数）？
**答**：列表全选：disabled 行（无权限操作）不参与全选勾选、不进合计、不计入"已选 N 项"——全选语义 = "选中所有可操作项"。

**思路**：过滤链：selectable = rows.filter(eligible) → 全选操作只作用于 selectable → 计数/合计同源（单一真相，ALG-253 联动）。

```javascript
function selectAll(rows, checkedIds, select) {
  const selectable = rows.filter((r) => !r.disabled);     // 只操作可操作项
  if (select) selectable.forEach((r) => checkedIds.add(r.id));
  else selectable.forEach((r) => checkedIds.delete(r.id));
}
function deriveSelection(rows, checkedIds) {              // ALG-253 单遍派生
  let count = 0, amount = 0, allChecked = true;
  for (const r of rows) {
    if (r.disabled) continue;                             // disabled：不参与任何统计
    if (checkedIds.has(r.id)) { count++; amount += r.price; }
    else allChecked = false;
  }
  return { count, amount, allChecked: allChecked && rows.some((r) => !r.disabled) };
}
// 语义：disabled 行的 checkbox 本身 disabled + 全选跳过 + 计数排除 —— 三处一致（单一真相）
// 半选：部分 selectable 被选 → indeterminate（全选框半选态）
// 全选的边界：全 disabled 列表 → allChecked 基于"存在可操作项"（空集不算全选成功）
```

**评分点**：
- selectable 过滤链贯穿全选/计数/合计（单一真相）——本题核心。
- disabled 三处一致（checkbox/全选/统计）。
- 空可操作集的 allChecked 边界。
- 与 ALG-253 单遍派生的联动。
