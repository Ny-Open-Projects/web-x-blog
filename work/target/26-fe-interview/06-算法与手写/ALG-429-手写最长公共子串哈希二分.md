## ALG-429：手写最长公共子串（哈希二分）：文本抄袭检测

**答**：
- 题目：两篇文档判「抄袭嫌疑」——最长公共子串长度（连续，区别于子序列 LCS）。哈希 + 二分长度。
- 思路：二分子串长度 mid：A 的所有 mid 长子串哈希入 Set，B 的 mid 子串逐个查命中。O((n+m) log n)。比 DP O(n×m) 快。
- 评分点：二分长度的单调性论证；哈希 Set 集合；与 LCS（不连续）的区别。

```javascript
function longestCommonSubstring(a, b) {
  const ha = new StringHash(a), hb = new StringHash(b);
  let lo = 1, hi = Math.min(a.length, b.length), best = 0, bestPos = -1;
  while (lo <= hi) {                                       // 二分：长度存在单调性
    const mid = (lo + hi) >> 1;
    const set = new Set();
    for (let i = 0; i + mid <= a.length; i++) set.add(ha.substr(i, i + mid).toString());
    let pos = -1;
    for (let i = 0; i + mid <= b.length; i++)
      if (set.has(hb.substr(i, i + mid).toString())) { pos = i; break; }
    if (pos >= 0) { best = mid; bestPos = pos; lo = mid + 1; }
    else hi = mid - 1;
  }
  return { length: best, sample: best >= 0 ? b.slice(bestPos, bestPos + best) : '' };
}
// 抄袭判定：LCS(连续)长度 / min(lenA, lenB) > 0.5 → 标记嫌疑
// 注意区分：子串（连续，本题）vs 子序列 LCS DP（不连续）
```
