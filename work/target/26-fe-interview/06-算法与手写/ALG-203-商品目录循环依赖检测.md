**场景**：低代码平台组件可引用其他组件（`{ A: ['B'], B: ['C'], C: ['A'] }`），发布前要检测循环依赖并给出环路径，否则构建死循环。

**思路**：DFS 三色标记（白灰黑）：灰=在当前递归栈中，遇到灰即成环，回溯栈拿环路径。或 Kahn 拓扑排序（入度归零的数量 < 节点数则成环）。DFS 版可定位具体环，这里给 DFS。

```javascript
function detectCycle(graph) {
  const WHITE = 0, GRAY = 1, BLACK = 2;
  const color = new Map(Object.keys(graph).map((k) => [k, WHITE]));
  const stack = [];
  let cycle = null;

  function dfs(node) {
    color.set(node, GRAY); stack.push(node);
    for (const dep of graph[node] || []) {
      const c = color.get(dep) ?? WHITE;
      if (c === GRAY) {                                  // 成环：从栈里 dep 开始截取
        const start = stack.indexOf(dep);
        cycle = stack.slice(start).concat(dep);
        return true;
      }
      if (c === WHITE && (color.has(dep) || graph[dep] !== undefined) && dfs(dep)) return true;
      if (c === WHITE && dfs(dep)) return true;
    }
    color.set(node, BLACK); stack.pop();
    return false;
  }
  for (const node of Object.keys(graph)) {
    if (color.get(node) === WHITE && dfs(node)) break;
  }
  return cycle;    // ['A','B','C','A'] 或 null
}
detectCycle({ A: ['B'], B: ['C'], C: ['A'] }); // => ['A','B','C','A']
// 复杂度：O(V+E)；拓扑排序替代方案：入度队列，处理完的节点数 < V => 成环
```

**评分点**：
- 三色标记语义正确（GRAY=递归栈中，回边即环）。
- 环路径定位（stack 截取）而不仅是布尔判定。
- 复杂度 O(V+E)；能提 Kahn 拓扑排序作为替代。
- 未声明的依赖节点不崩溃（默认白/容错）。
