## HW-372：手写一个视频时间轴编辑器：轨道渲染与裁剪手柄

**答**：
- 需求：实现 VideoTimeline：多轨道（视频/音频/字幕），每轨 clips [{start, end, src}]；渲染：clip 按时间映射为宽度（pxPerSec 可缩放）；裁剪手柄（clip 左右缘拖拽改 start/end，约束不与相邻 clip 重叠）；播放头（time → x 映射，拖拽 scrub）。
- 边界：裁剪最小时长（0.5s）；相邻 clip 重叠约束（拖拽时钳制到邻界）；轨道间拖拽移动 clip（跨轨）；时间轴缩放锚点（光标处时间不变）。
- 评分点：时间-像素双向映射；重叠钳制；跨轨移动。

```javascript
class VideoTimeline {
  constructor(tracks, { pxPerSec = 60, minClip = 0.5 } = {}) {
    this.tracks = tracks; this.pps = pxPerSec; this.minClip = minClip;
  }
  x(t) { return t * this.pps; }                              // 时间 → 像素
  t(x) { return x / this.pps; }                              // 像素 → 时间
  zoomAt(px, factor) {                                       // 缩放锚点
    const anchor = this.t(px);
    this.pps *= factor;
    this.scrollX = px - anchor * this.pps;                   // 锚点保持
  }
  trimClip(trackIdx, clipIdx, edge, newTime) {               // 裁剪手柄
    const track = this.tracks[trackIdx];
    const clip = track.clips[clipIdx];
    const prev = track.clips[clipIdx - 1], next = track.clips[clipIdx + 1];
    if (edge === 'left') {                                   // 左缘：改 start
      const min = prev ? prev.end : 0;
      const max = clip.end - this.minClip;                   // 最小时长约束
      clip.start = clamp(newTime, min, max);
    } else {
      const max = next ? next.start : Infinity;
      clip.start = clip.start;
      clip.end = clamp(newTime, clip.start + this.minClip, max);   // 重叠钳制
    }
    return clip;
  }
  moveToTrack(fromTrack, fromIdx, toTrack, newStart) {       // 跨轨移动
    const clip = this.tracks[fromTrack].clips.splice(fromIdx, 1)[0];
    const dur = clip.end - clip.start;
    clip.start = newStart; clip.end = newStart + dur;
    const others = this.tracks[toTrack].clips;
    const conflict = others.some(c => c.start < clip.end && clip.start < c.end);
    if (conflict) {                                          // 冲突：找最近空位
      let s = newStart;
      while (others.some(c => c.start < s + dur && s < c.end)) s = c.endOfNearest ?? s + 1;
      clip.start = s; clip.end = s + dur;
    }
    this.tracks[toTrack].clips.push(clip);
    this.tracks[toTrack].clips.sort((a, b) => a.start - b.start);
  }
  playheadX(time) { return this.x(time) - this.scrollX; }
}
const clamp = (v, lo, hi) => Math.max(lo, Math.min(hi, v));
```
