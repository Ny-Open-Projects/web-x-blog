## ALG-202：灰度系统：给定每日放量标记数组，求任意日期区间的累计放量数（前缀和 + 查询 O(1)）
**答**：灰度平台记录每日放量 0/1 数组 `marks`（长度 n），看板要频繁查询"第 i 天到第 j 天累计放量多少"。查询上千次，每次 O(n) 会慢，用前缀和预处理 O(n)，单查 O(1)。

**思路**：prefix[i] = 前 i 天累计。区间 [i, j] = prefix[j+1] - prefix[i]。增量更新场景（每天追加）天然友好；若中间修改多用树状数组（可提一句）。

```javascript
class DayPrefix {
  constructor(marks) {
    this.prefix = [0];
    for (let i = 0; i < marks.length; i++) this.prefix.push(this.prefix[i] + marks[i]);
  }
  query(i, j) {                        // 闭区间，0-based，含两端
    if (i > j) [i, j] = [j, i];
    return this.prefix[j + 1] - this.prefix[i];
  }
  append(v) { this.prefix.push(this.prefix.at(-1) + v); }   // 追加式更新 O(1)
}
const dp = new DayPrefix([1, 0, 1, 1, 0]);
dp.query(1, 3);   // => 2（第2~4天共放量2次）
// 复杂度：预处理 O(n)/O(n)，查询 O(1)
// 追问：若支持"修改某天放量"，改用树状数组（Binary Indexed Tree），单点更新 O(logn)、区间查询 O(logn)
```

**评分点**：
- 前缀和构造与区间公式正确（prefix[j+1]-prefix[i]，闭区间换算无 off-by-one）。
- 追加 O(1)、查询 O(1) 的复杂度标注。
- 能说出"频繁中间修改则换树状数组/线段树"的演进方向。
- 边界：i>j 交换、空数组。
