**场景**：编辑场景打开级联选择器：默认值是"浙江省/杭州市/西湖区"——三级都要懒加载并按序回填（父级加载完才能加载子级），竞态（快速打开关闭）与缓存（二级只加载一次）。

**思路**：按路径递归加载（父就绪 → 子）→ seq 竞态丢弃（HW-101 强化：整条路径一个 seq）→ 路径缓存（`province/330000` → children Map）。

```javascript
class CascadeLoader {
  #cache = new Map();                                     // "parentPath" -> children[]
  async loadPath(path, { signal, seq }) {                 // path: ['330000', '330100']
    let children = await this.#loadLevel(null, seq);      // 第一级
    const nodes = [];
    for (const code of path) {
      const node = children.find((c) => c.code === code);
      if (!node) break;                                   // 路径失效（数据变更）：停止回填
      nodes.push(node);
      children = await this.#loadLevel(node.code, seq);   // 父就绪再加载子（级联依赖）
    }
    return { nodes, siblings: children };                 // 回填路径 + 当前级选项
  }
  async #loadLevel(parentCode, seq) {
    const key = parentCode ?? 'root';
    if (this.#cache.has(key)) return this.#cache.get(key);
    const children = await fetchChildren(parentCode);
    if (seq !== this.#currentSeq) throw new DOMException('stale', 'AbortError');   // 竞态丢弃
    this.#cache.set(key, children);                       // 二级加载只发生一次
    return children;
  }
}
// 竞态粒度：整条路径一个 seq（打开→回填完成不可分割）——中途关闭（seq 变化）整链丢弃
// 缓存键：parentCode（同父只加载一次）—— 三级选择器 N 次打开只发 3+N 次请求 → 3 次
// 回填失败（路径失效）：stop 并停留在已加载层（数据变更防御，ALG-233 幂等合并同源）
```

**评分点**：
- 按路径递归级联（父就绪才加载子）——本题核心。
- 整路径一个 seq 的竞态粒度（中途关闭整链丢弃）。
- 路径缓存（同父一次）。
- 路径失效防御（break 停留已加载层）。
