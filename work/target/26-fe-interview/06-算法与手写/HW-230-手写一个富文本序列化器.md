## HW-230：手写一个富文本序列化器：blocks 与 HTML 及纯文本的双向转换

**答**：
- 需求：实现 Serializer：toHTML(blocks)（type→标签映射，marks→span/b/i 包裹，转义防 XSS）；toText(blocks)（纯文本拼接）；fromHTML(html) 复用粘贴净化逻辑（白名单）；toMarkdown(blocks)（标题/加粗/斜体映射）。
- 边界：HTML 转义 & < > 四字符；空 block 输出 <p><br></p>；marks 相邻合并后输出（避免冗余标签）；fromHTML 必须过滤 script/style/事件属性。
- 评分点：转义完整性；marks 合并输出；双向一致性（round-trip 测试）。

```javascript
const TAG = { p: 'p', h1: 'h1', h2: 'h2', li: 'li', quote: 'blockquote', code: 'pre' };
const MARK_TAG = { bold: 'strong', italic: 'em', underline: 'u' };
const esc = s => s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');
function toHTML(blocks) {
  return blocks.map(b => {
    let html = '';
    let i = 0;
    const cuts = [...new Set(b.marks.flatMap(m => [m.start, m.end]))].sort((a, x) => a - x);
    for (let k = 0; k < cuts.length; k++) {                   // 按切点分段包标签
      const seg = b.text.slice(i, cuts[k]);
      const active = b.marks.filter(m => m.start <= i && cuts[k] <= m.end).map(m => MARK_TAG[m.type]);
      const wrap = s => active.reduceRight((acc, tag) => `<${tag}>${acc}</${tag}>`, esc(s));
      html += wrap(seg); i = cuts[k];
    }
    html += esc(b.text.slice(i));
    return `<${TAG[b.type] ?? 'p'}>${html || '<br>'}</${TAG[b.type] ?? 'p'}>`;
  }).join('\n');
}
function toText(blocks) { return blocks.map(b => b.text).join('\n'); }
function roundtripTest(blocks) {                              // 双向一致性断言
  const html = toHTML(blocks);
  const back = fromHTML(html);
  return JSON.stringify(back) === JSON.stringify(blocks.map(b => ({ ...b, id: b.id })));
}
```
