**场景**：埋点有 N 条用户路径（`home → list → goods` 序列），统计高频路径 Top-K（产品要"典型用户路径"）。把每条路径插入前缀树并沿路径计数，树的"高频边序列"即典型路径。

**思路**：Trie 节点 {children, count, page}；插入路径逐层 count++；DFS 收集 count ≥ 阈值的路径，按 count 排序取 Top-K。路径长度上限 5（防爆炸）。

```javascript
function topPaths(sessions, { k = 10, maxDepth = 5, minCount = 10 } = {}) {
  const root = {};
  for (const pages of sessions) {                     // sessions: [['home','list','goods'], ...]
    let node = root;
    for (let i = 0; i < Math.min(pages.length, maxDepth); i++) {
      const p = pages[i];
      node = node[p] ??= { count: 0, children: {} };
      node.count++;
    }
  }
  const out = [];
  (function dfs(node, path) {
    if (path.length >= 2 && node.count >= minCount) out.push({ path: [...path], count: node.count });
    for (const [p, child] of Object.entries(node.children ?? {})) dfs(child, [...path, p]);
  })(root, []);
  return out.sort((a, b) => b.count - a.count).slice(0, k);
}
// topPaths([['home','list','goods'],['home','list'],['home','list','goods']], ...)
// => [{ path: ['home','list','goods'], count: 2 }, { path: ['home','list'], count: 3 }]
// 剪枝：count < minCount 的子树可提前剪（高频路径的祖先必高频——反证：低频祖先子树不可能高频）
// 输出含义：连续浏览路径（前缀序列）的频次 —— "典型路径"产品可视化数据源
```

**评分点**：
- Trie 路径计数（每路径前缀都计数）的正确实现。
- Top-K 收集 + minCount 剪枝（含"低频祖先子树不可能高频"的剪枝理由）。
- maxDepth 限制防路径爆炸。
- 场景对应：典型用户路径挖掘。
