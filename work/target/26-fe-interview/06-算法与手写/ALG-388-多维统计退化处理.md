## ALG-388：多维统计退化处理：多维筛选兜底方案

**答**：
- 题目：日志按 (机房, 服务, 级别) 三维筛选统计计数。全维组合爆炸——工程方案：预聚合常用维度组合 + 高维查询退化为扫描 + 布隆过滤器粗筛。
- 思路：① 高频组合预聚合 Map<comboKey, count>（增量维护）；② 长尾查询扫明细（配合时间窗限制）；③ 展示层接受近似。讲清「精确多维 = 无法全预聚合」的权衡。
- 评分点：维度组合爆炸认知；预聚合+扫描混合；近似与精度的业务权衡。

```javascript
class MultiDimCounter {
  constructor(dims) { this.dims = dims; this.agg = new Map(); this.total = 0; }
  add(record) {                                            // 增量维护常用组合
    this.total++;
    for (const combo of COMBOS) {                           // 预聚合指定组合（如 [机房,级别]）
      const key = combo.map(d => record[d]).join('|');
      this.agg.set(combo.join('+') + ':' + key, (this.agg.get(combo.join('+') + ':' + key) ?? 0) + 1);
    }
  }
  query(filters) {                                         // 查询：先查预聚合
    const combo = Object.keys(filters).sort().join('+');
    if (COMBOS.some(c => c.join('+') === combo)) {
      const key = combo + ':' + Object.keys(filters).sort().map(k => filters[k]).join('|');
      return this.agg.get(key) ?? 0;
    }
    return null;                                           // 高维：退化为扫描（调用方决定）
  }
}
const COMBOS = [['dc', 'level'], ['service', 'level'], ['dc']];   // 预聚合组合清单
```
