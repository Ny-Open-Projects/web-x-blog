## HW-268：手写一个协作调试工具：操作日志可视化与状态 diff

**答**：
- 需求：实现 CollabDebugger：记录所有本地/远端 op（环形 500 条）与每次应用后的文档 hash；stateDiff(revA, revB) 输出两版本文本 diff 摘要；explain(op) 解释某 op 的变换路径（原始 op → 经哪些并发 op 变换 → 最终应用形态）；导出会话日志（JSON）供 bug 上报。
- 边界：环形缓冲不丢最近关键 ops；explain 需要记录变换链（每步输入输出）；日志脱敏（文本内容可选脱敏）。
- 评分点：变换链记录；状态 diff；脱敏导出。

```javascript
class CollabDebugger {
  constructor({ cap = 500 } = {}) { this.log = []; this.cap = cap; this.hashes = []; }
  record(op, { remote = false, transformChain = [] } = {}) {
    this.log.push({ t: Date.now(), remote, op, chain: transformChain,
      docHash: hashStr(currentDocText()) });
    if (this.log.length > this.cap) this.log.shift();        // 环形
    this.hashes.push(this.log.at(-1).docHash);
  }
  explain(idx) {
    const e = this.log[idx];
    return { op: e.op, remote: e.remote,
      chain: e.chain.map(c => ({ by: c.by, before: c.before, after: c.after })),   // 变换路径
      finalText: e.op.text };
  }
  stateDiff(revA, revB) {                                   // 版本间 diff 摘要
    const ops = this.log.slice(revA, revB).filter(e => !e.remote);
    return { ops: ops.length,
      inserts: ops.filter(e => e.op.type === 'insert').reduce((s, e) => s + e.op.text.length, 0),
      deletes: ops.filter(e => e.op.type === 'delete').reduce((s, e) => s + e.op.text.length, 0) };
  }
  export({ redact = true } = {}) {                          // 脱敏导出
    return JSON.stringify(this.log.map(e => ({ ...e,
      op: redact ? { ...e.op, text: e.op.text ? '***' : '' } : e.op })));
  }
}
```
