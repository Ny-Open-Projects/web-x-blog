## HW-255：手写一个协作光标渲染数据：他人光标位置映射与插值动画

**答**：
- 需求：实现 RemoteCursor：远端光标（线性偏移）→ 本地渲染位置（DOM 坐标），文档编辑后旧偏移需通过 ops 映射到新偏移（逐 op 平移）；渲染层每帧向目标位置插值（缓动 0.2）实现平滑移动；标签显示用户名。
- 边界：远端选区（起点+终点）渲染高亮区间；映射时删除区间内的偏移钳制到删除点；插值收敛阈值（< 0.5px 停止）。
- 评分点：ops 偏移映射；钳制；插值渲染。

```javascript
class RemoteCursor {
  constructor(user) { this.user = user; this.offset = 0; this.target = 0; this.x = 0; this.y = 0; }
  mapByOps(ops) {                                          // 文档变更后映射偏移
    let o = this.offset;
    for (const op of ops) {
      if (op.type === 'insert' && op.pos <= o) o += op.text.length;
      if (op.type === 'delete') {
        const e = op.pos + op.text.length;
        if (o >= e) o -= op.text.length;
        else if (o > op.pos) o = op.pos;                   // 删除区间内：钳制
      }
    }
    this.offset = this.target = o;
  }
  setTarget(offset) { this.target = offset; }
  tick() {                                                 // 插值动画
    const dx = this.target - this.offset;
    if (Math.abs(dx) < 0.5) { this.offset = this.target; return false; }   // 收敛停帧
    this.offset += dx * 0.2;
    const { x, y } = posToXY(this.offset);
    this.x = x; this.y = y;
    renderFlag(this.user, this.x, this.y);
    return true;                                           // 需要下一帧
  }
  renderSelection(startOffset, endOffset) {                // 远端选区
    const a = posToXY(startOffset), b = posToXY(endOffset);
    return { top: a.y, left: a.x, width: b.x - a.x, height: lineHeight() };
  }
}
```
