## HW-221：手写一个输入法感知的编辑器输入处理：composition 事件与文本变更时序

**答**：
- 需求：实现 ImeAwareInput：组合期（compositionstart→end）不派发文档变更（暂存），compositionend 时一次性提交组合文本；非组合期 input 直接提交；提供 isComposing 状态给命令系统（组合期禁用快捷键）。
- 边界：组合中途中断（keydown Esc/失焦）要取消暂存；组合文本插在光标处，结束时再应用 pendingMark；Android 上 compositionend 后紧跟 input 事件去重。
- 评分点：组合期不写文档；中断取消；Android 双事件去重。

```javascript
class ImeAwareInput {
  constructor(apply) { this.apply = apply; this.composing = false; this.buf = ''; }
  onCompositionStart() { this.composing = true; this.buf = ''; }
  onCompositionUpdate(e) { this.buf = e.data ?? ''; }         // 暂存不提交
  onCompositionEnd(e) {
    this.composing = false;
    const data = e.data ?? this.buf;
    if (data) this.apply(data);                              // 一次性提交
    this.buf = '';
    this._lastCommit = Date.now();
  }
  onInput(e) {
    if (this.composing) return;                              // 组合期：不写文档
    if (Date.now() - (this._lastCommit ?? 0) < 30) return;   // Android 双事件去重
    this.apply(e.data ?? '');
  }
  onKeydown(e) {
    if (this.composing && (e.key === 'Escape' || e.key === 'Cancel')) {
      this.composing = false; this.buf = '';                 // 中断取消
      return 'cancel';
    }
    return this.composing ? 'blocked' : undefined;           // 组合期禁快捷键
  }
}
```
