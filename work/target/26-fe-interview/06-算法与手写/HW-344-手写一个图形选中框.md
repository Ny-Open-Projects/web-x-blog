## HW-344：手写一个图形选中框：包围盒计算与控制柄渲染与命中

**答**：
- 需求：实现 SelectionBox：多选节点合并包围盒（世界坐标）；渲染 8 个控制柄（四角缩放+四边）+ 旋转柄；控制柄命中测试（光标距柄中心 < 阈值）；光标样式映射（nwse/nesw/rotate）。
- 边界：旋转后包围盒取轴对齐包围（AABB of 4 corners）；缩放柄方向随旋转角换算；命中优先级高于画布（先测柄再测场景）。
- 评分点：AABB 四角合并；旋转柄方向映射；命中阈值。

```javascript
class SelectionBox {
  constructor() { this.selected = new Set(); }
  setSelection(nodes) { this.selected = new Set(nodes); }
  bounds() {                                                 // AABB（含旋转四角）
    let minX = Infinity, minY = Infinity, maxX = -Infinity, maxY = -Infinity;
    for (const n of this.selected) {
      const m = worldMatrix(n);
      const corners = [[0, 0], [n.w, 0], [0, n.h], [n.w, n.h]].map(([x, y]) => ({
        x: m.a * x + m.c * y + m.e, y: m.b * x + m.d * y + m.f }));   // 变换后四角
      corners.forEach(c => { minX = Math.min(minX, c.x); minY = Math.min(minY, c.y);
        maxX = Math.max(maxX, c.x); maxY = Math.max(maxY, c.y); });
    }
    return { x: minX, y: minY, w: maxX - minX, h: maxY - minY };
  }
  handles() {                                                // 8 柄 + 旋转柄
    const b = this.bounds();
    const pos = { nw: [b.x, b.y], n: [b.x + b.w / 2, b.y], ne: [b.x + b.w, b.y],
      e: [b.x + b.w, b.y + b.h / 2], se: [b.x + b.w, b.y + b.h],
      s: [b.x + b.w / 2, b.y + b.h], sw: [b.x, b.y + b.h], w: [b.x, b.y + b.h / 2],
      rotate: [b.x + b.w / 2, b.y - 20] };
    return Object.fromEntries(Object.entries(pos).map(([k, [x, y]]) => [k, { x, y }]));
  }
  hitHandle(px, py, threshold = 6) {                         // 柄命中（先于场景）
    const hs = this.handles();
    for (const [name, p] of Object.entries(hs))
      if (Math.hypot(px - p.x, py - p.y) <= threshold)
        return { name, cursor: name === 'rotate' ? 'grab'
          : { nw: 'nwse-resize', se: 'nwse-resize', ne: 'nesw-resize', sw: 'nesw-resize' }[name] ?? 'move' };
    return null;
  }
}
```
