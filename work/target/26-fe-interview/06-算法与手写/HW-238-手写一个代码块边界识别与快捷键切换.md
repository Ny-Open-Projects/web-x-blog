## HW-238：手写一个代码块边界识别与快捷键切换

**答**：
- 需求：实现 CodeBlockToggle：blocks 中 type=code 的连续 block 视为一个代码块（start/end 索引）；toggle(range) 把选区转成代码块（合并为一个 code block，保留换行）或从代码块拆回段落（按行拆）；快捷键 Ctrl+E 触发当前选区 toggle。
- 边界：选区跨代码块边界 → 先拆散再合并；空选区在代码块内 → 整块退出（拆回段落）；嵌套三反引号文本原样保留。
- 评分点：连续 block 归块；跨边界处理。

```javascript
class CodeBlockToggle {
  constructor(doc) { this.doc = doc; }
  findBlockEnclosing(blockId) {                                // 所在代码块范围
    const i = this.doc.indexOfId(blockId);
    let s = i, e = i;
    while (s > 0 && this.doc.blocks[s - 1].type === 'code') s--;
    while (e < this.doc.blocks.length - 1 && this.doc.blocks[e + 1].type === 'code') e++;
    return { s, e, inside: this.doc.blocks[i].type === 'code' };
  }
  toCode(range) {
    const { head, tail } = range.normalized();
    const hi = this.doc.indexOfId(head.blockId), ti = this.doc.indexOfId(tail.blockId);
    const seg = this.doc.blocks.slice(hi, ti + 1);
    // 跨代码块边界：先拆散已有 code
    seg.forEach(b => { if (b.type === 'code') this.splitCode(b); });
    const text = seg.filter(b => b.type !== 'code').map(b => b.text).join('\n');
    const nb = { id: genId(), type: 'code', text, marks: [] };
    this.doc.replaceRange(hi, ti + 1, [nb]);
    return nb.id;
  }
  splitCode(b) {                                               // code 拆回段落
    const paras = b.text.split('\n').map(t => ({ id: genId(), type: 'p', text: t, marks: [] }));
    this.doc.replaceById(b.id, paras);
    return paras;
  }
  toggle(range, selBlockId) {
    const enc = this.findBlockEnclosing(selBlockId);
    if (enc.inside && range.isEmpty())
      return this.splitCode(this.doc.blocks[enc.s]);           // 空选区整块退出
    return this.toCode(range);
  }
}
```
