## ALG-256：页面回归检测：两次渲染的 DOM 结构相似度哈希（结构指纹 + 汉明距离）？
**答**：低代码平台"页面快照回归"：改代码后对比渲染结构是否意外变化——DOM 结构指纹（标签序列哈希）+ 汉明距离判定相似度，文本内容变化不报警（结构变了才报警）。

**思路**：结构指纹 = 按 DOM 树生成"标签+层级"序列（忽略文本与属性），哈希为定长位串；相似度 = 异或后 1 的个数（汉明距离）/总位数。

```javascript
function structureHash(el, depth = 0) {
  let seq = '';
  (function walk(node, d) {
    seq += `${d}:${node.tagName ?? 'TXT'};`;
    for (const child of node.children ?? []) walk(child, d + 1);
  })(el, depth);
  // 定长位串哈希（FNV 多轮生成 64 位指纹）
  let h1 = 2166136261, h2 = 2166136261;
  for (let i = 0; i < seq.length; i++) {
    h1 = Math.imul(h1 ^ seq.charCodeAt(i), 16777619);
    h2 = Math.imul(h2 ^ seq.charCodeAt(seq.length - 1 - i), 16777619);   // 正反双哈希降低碰撞
  }
  return BigInt.asUintN(64, (BigInt(h1 >>> 0) << 32n) | BigInt(h2 >>> 0));
}
function similarity(a, b) {
  let diff = (a ^ b).toString(2).split('').filter((c) => c === '1').length;  // 汉明距离
  return 1 - diff / 64;                                   // 0~1，> 0.95 视为"结构未变"
}
// 判定阈值：> 0.95 结构未变（文本/属性变化不报警——业务允许）；< 0.8 结构大改（回归确认）
// 语义：只看结构不看内容 —— "改了文案不报警，改了嵌套层级报警"
// 误报控制：动态区块（轮播/时间）在指纹前剔除（data-snapshot-ignore 标注）
```

**评分点**：
- 结构指纹（标签+层级序列，忽略文本属性）——本题核心。
- 双向哈希降低碰撞 + 汉明距离相似度。
- 阈值语义（0.95 未变 / 0.8 大改）与文本变化不报警的取舍。
- 动态区块剔除的误报控制。
