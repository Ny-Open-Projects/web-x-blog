## HW-355：手写一个图形复用与图元库：模板拖入实例化

**答**：
- 需求：实现 ShapeLibrary：图元模板（矩形/箭头/便签等，含默认样式）；拖入画布实例化（深拷贝模板 + 新 id + 落点位置）；自定义模板保存（用户图形存为模板，样式快照）；模板面板渲染（缩略图）。
- 边界：模板与实例解耦（改模板不影响已放置实例）；实例化位置以拖入点为中心；模板 id 冲突（每次实例化重新生成）。
- 评分点：深拷贝解耦；实例化定位；id 重生成。

```javascript
class ShapeLibrary {
  constructor() { this.templates = new Map(); }
  register(name, shape) {
    this.templates.set(name, { name, shape: cloneShape(shape) });   // 模板快照
  }
  saveAsTemplate(node) {                                     // 用户图形存为模板
    const { id, x, y, ...style } = node;                     // 剥离 id 与位置
    this.register(node.type + '-' + Date.now(), { ...style, w: node.w, h: node.h });
  }
  instantiate(templateName, dropX, dropY) {                  // 拖入实例化
    const tpl = this.templates.get(templateName);
    if (!tpl) throw new Error('no-template');
    return {
      ...cloneShape(tpl.shape),
      id: genId(),                                           // 每次重新生成 id
      x: dropX - tpl.shape.w / 2,                            // 以拖入点为中心
      y: dropY - tpl.shape.h / 2,
    };
  }
  renderPanel(container) {                                   // 缩略图
    for (const [name, tpl] of this.templates) {
      const cv = document.createElement('canvas');
      cv.width = 60; cv.height = 60;
      const ctx = cv.getContext('2d');
      const scale = Math.min(60 / tpl.shape.w, 60 / tpl.shape.h);
      ctx.scale(scale, scale);
      tpl.shape.draw(ctx);
      cv.draggable = true;
      cv.ondragstart = e => e.dataTransfer.setData('shape', name);
      container.appendChild(cv);
    }
  }
}
function cloneShape(s) { return structuredClone(s); }
```
