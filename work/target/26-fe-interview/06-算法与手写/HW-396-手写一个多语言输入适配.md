## HW-396：手写一个多语言输入适配：RTL 布局与 IME 兼容层

**答**：
- 需求：实现 IntlInputAdapter：RTL 适配（dir=rtl 语言自动设置，光标/选区方向语义处理——left/right 逻辑方向 vs 物理方向）；IME 兼容（中日韩输入组合期处理，见 HW-221 复用）；数字/日期本地化格式（输入即格式化预览）；双向文本（bidi 隔离：混排片段用 unicode-bidi isolate）。
- 边界：RTL 下 ArrowLeft 语义（物理左 = 逻辑前进）；数字键盘适配（阿拉伯数字变体）；混排方向标记注入防显示错乱。
- 评分点：逻辑/物理方向；bidi 隔离；本地化格式。

```javascript
class IntlInputAdapter {
  constructor(editor) { this.ed = editor; }
  setLanguage(lang) {
    const rtl = ['ar', 'he', 'fa', 'ur'].includes(lang.slice(0, 2));
    this.rtl = rtl;
    this.ed.el.dir = rtl ? 'rtl' : 'ltr';                    // 自动方向
    this.ed.el.lang = lang;
    this.locale = lang;
  }
  onKey(e) {                                                 // 方向键语义适配
    if (!this.rtl) return 'ltr';
    if (e.key === 'ArrowLeft') return 'backward';            // RTL：物理左=逻辑后退
    if (e.key === 'ArrowRight') return 'forward';
    return 'normal';
  }
  formatNumber(n) { return new Intl.NumberFormat(this.locale).format(n); }   // 本地化数字
  formatDate(d) { return new Intl.DateTimeFormat(this.locale, { dateStyle: 'long' }).format(d); }
  isolate(text, dir) {                                       // bidi 隔离混排
    const mark = dir === 'rtl' ? '\u200F' : '\u200E';
    return `${mark}\u2066${text}\u2069${mark}`;            // LRI...PDI 隔离片段
  }
  onComposition(e) { return this.ed.ime.handle(e); }         // IME 兼容复用
}
```
