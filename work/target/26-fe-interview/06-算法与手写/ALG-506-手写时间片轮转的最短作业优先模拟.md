## ALG-506：手写时间片轮转的最短作业优先模拟：渲染任务队列

**答**：
- 题目：渲染任务池：任务随时到达（到达时间, 时长），CPU 时间片轮转 + SJF 选择（就绪队列中最短者优先，非抢占），求平均等待时间。事件驱动模拟。
- 思路：按到达时间排序；每个完成时刻从「已到达未完成」中选最短者执行；无就绪则跳到下一到达时刻。
- 评分点：事件驱动模拟框架；就绪队列选择策略；等待时间口径（完成-到达-时长）。

```javascript
function sjfSimulate(jobs) {                               // jobs: [{arrive, duration, id}]
  const sorted = [...jobs].sort((a, b) => a.arrive - b.arrive);
  let t = 0, i = 0;
  const ready = [], results = [];
  while (i < sorted.length || ready.length) {
    while (i < sorted.length && sorted[i].arrive <= t) ready.push(sorted[i++]);   // 入就绪
    if (!ready.length) { t = sorted[i].arrive; continue; }   // 空闲：跳到下一到达
    ready.sort((a, b) => a.duration - b.duration);         // SJF：最短优先
    const job = ready.shift();
    t += job.duration;
    results.push({ id: job.id,
      wait: t - job.arrive - job.duration, finish: t });   // 等待 = 完成-到达-时长
  }
  const avgWait = results.reduce((s, r) => s + r.wait, 0) / results.length;
  return { avgWait: +avgWait.toFixed(2), results };
}
```
