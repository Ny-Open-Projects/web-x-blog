## ALG-518：手写摊还分析：聚合法证明均摊 O(1)（动态数组扩容）

**答**：
- 题目：动态数组 push 的均摊复杂度分析——扩容翻倍策略下，n 次 push 总代价 O(n)，均摊 O(1)。聚合法（aggregate）：总代价/操作数。
- 思路：总代价 = n 次普通 push（n）+ 扩容拷贝（1+2+4+...+n ≈ 2n）= 3n → 均摊 O(1)。对比记账法（potential 法）：每次多存 2 个硬币支付未来拷贝。
- 评分点：聚合法求和；几何级数求和；记账法直观解释。

```javascript
class DynamicArray {
  constructor() { this.data = []; this.size = 0; this.capacity = 1;
    this.totalCost = 0; }                                  // 摊还分析用
  push(v) {
    if (this.size === this.capacity) {
      this.capacity *= 2;                                  // 翻倍扩容
      const next = new Array(this.capacity);
      for (let i = 0; i < this.size; i++) next[i] = this.data[i];   // 拷贝 O(n)
      this.totalCost += this.size;                         // 拷贝代价记账
      this.data = next;
    }
    this.data[this.size++] = v;
    this.totalCost += 1;                                   // 普通写入代价
    return this;
  }
  amortizedAnalysis(n) {                                   // n 次 push 均摊
    // 总拷贝 = 1 + 2 + 4 + ... ≤ 2n（几何级数）
    // 总代价 ≤ n + 2n = 3n → 均摊 O(1)
    return { totalCostUpperBound: 3 * n, amortizedPerOp: 'O(1)' };
  }
}
// 记账法：每次 push 收 3 元——1 元写入 + 2 元存「扩容基金」
// 扩容时基金恰好支付拷贝（每个老元素 2 元已预存）
```
