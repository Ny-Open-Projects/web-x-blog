## ALG-510：手写贪心证明技巧总结：交换论证模板

**答**：
- 题目：总结贪心证明的三大模板（交换论证/反证/归约），并各给一个白板演示题。
- 要点：① 交换论证（相邻交换消除逆序——SJF）；② 反证法（假设最优解与贪心不同，构造更优矛盾——区间调度）；③ 归约（问题映射到已知贪心可解问题）。
- 评分点：三大模板各配例题；表述格式（假设/交换/矛盾/结论）；面试白板可直接套用。

```javascript
const proofTemplates = {
  exchange: {                                               // 交换论证
    template: '设最优解存在相邻逆序 → 交换后 Δ = a-b > 0 更优 → 矛盾 → 最优即贪心序',
    example: 'SJF 最小化等待（ALG-484）',
    format: ['假设最优解 S', '找逆序对', '计算交换增量 Δ', '矛盾', '结论'],
  },
  contradiction: {                                          // 反证法
    template: '设最优解 T ≠ 贪心解 G 的首步 → 用贪心首步替换 T 首步 → 剩余子问题仍可行且不劣 → 归纳',
    example: '区间调度按 end 排序（ALG-481）',
    format: ['假设最优解首步不同', '替换为贪心首步', '证明可行+不劣', '归纳到整体'],
  },
  reduction: {                                              // 归约
    template: '把问题映射到已证贪心可解的经典问题（如哈夫曼/区间覆盖）',
    example: '合并果子 → 哈夫曼（ALG-499）',
    format: ['识别结构相似', '构造映射', '引用已知结论'],
  },
  antiExample: '无法证明时先构造反例（ALG-487）——贪心直觉常错',
};
```
