**答**：返回恢复滚动 = 三件事：① 离开时记录 scrollTop + 首屏首条数据的 id/offset（数据可能已变化，纯 scrollTop 不够）；② 返回时数据加载完成后再恢复（提前恢复会被渲染冲掉）；③ 数据更新后按锚点补偿（首条还在：用 anchor id 对齐；不在：按 offset 比例近似）。history.scrollRestoration = 'manual' 接管浏览器默认行为。

```javascript
class ScrollMemory {
  constructor(key) {
    this.key = key;
    if ('scrollRestoration' in history) history.scrollRestoration = 'manual';  // 关闭浏览器默认恢复
  }
  save(container, list) {
    const first = list[container.dataset.startIndex ?? 0];               // 可视区首条
    sessionStorage.setItem(this.key, JSON.stringify({
      scrollTop: container.scrollTop,
      anchorId: first?.id ?? null,
      anchorOffset: container.scrollTop - (container.dataset.startOffset ?? 0),
      savedAt: Date.now(),
    }));
  }
  async restore(container, fetchList) {
    const saved = JSON.parse(sessionStorage.getItem(this.key) || 'null');
    if (!saved) return;
    const list = await fetchList();                       // 数据就绪后再恢复（关键时序）
    requestAnimationFrame(() => {
      const anchorIdx = saved.anchorId != null
        ? list.findIndex((item) => item.id === saved.anchorId) : -1;
      if (anchorIdx >= 0) {                               // 锚点还在：按 id 对齐
        const el = container.querySelector(`[data-id="${saved.anchorId}"]`);
        if (el) { container.scrollTop = el.offsetTop + saved.anchorOffset; return; }
      }
      container.scrollTop = saved.scrollTop;              // 兜底：直接恢复 scrollTop
    });
  }
}
// 用法：列表页离开 → sm.save(container, list)；返回 → await sm.restore(container, fetchList)
// 关键时序坑：数据未渲染就 scrollTop=xxx 会被新内容顶回 0 —— 必须渲染完成（rAF）后再设
```

**评分点**：
- anchor（首条 id）+ scrollTop 双记录，数据更新后按锚点补偿而不是裸恢复。
- 时序正确：数据加载完成 + rAF 后才设置 scrollTop（最高频翻车点）。
- history.scrollRestoration = 'manual' 接管默认行为。
- sessionStorage 键隔离与过期（savedAt 可加 TTL）。
