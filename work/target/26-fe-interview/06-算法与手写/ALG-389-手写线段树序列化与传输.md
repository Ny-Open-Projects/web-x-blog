## ALG-389：手写线段树序列化与传输：服务端预计算下发

**答**：
- 题目：服务端预计算好线段树（区间聚合值），序列化成紧凑 JSON 下发到前端，前端只做查询不建树——省去前端 O(n) 建树。设计序列化格式与前端查询。
- 思路：按层序输出节点（数组即隐式树：node i 的子是 2i/2i+1）；前端查询沿数组下标走即可（无需显式 children）。
- 评分点：数组隐式树（2i/2i+1）；传输体积估算；前端零建树查询。

```javascript
// 服务端序列化：层序数组（隐式线段树）
function serializeTree(tree, n) {
  return JSON.stringify({ n, t: tree.slice(0, 4 * n) });   // 紧凑数组
}
// 前端零建树查询：直接沿数组下标递归
function queryCompact(t, n, ql, qr, node = 1, l = 0, r = n - 1) {
  if (qr < l || r < ql) return 0;
  if (ql <= l && r <= qr) return t[node];
  const m = (l + r) >> 1;
  return queryCompact(t, n, ql, qr, node * 2, l, m)
    + queryCompact(t, n, ql, qr, node * 2 + 1, m + 1, r);
}
// 传输体积：4n 个数（n=604800 秒 ≈ 2.4M 数字）——可改基底 64 或只传查询所需子树
// 优化：服务端只下发查询涉及的 O(log n) 条路径节点，体积从 4n 降到 O(q log n)
```
