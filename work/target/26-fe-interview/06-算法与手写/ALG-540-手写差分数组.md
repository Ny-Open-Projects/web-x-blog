## ALG-540：手写差分数组：区间批量变更

**答**：
- 题目：区间批量加（如批量调价 [l, r] +v），最后一次性求所有值。差分数组：O(1) 区间改，O(n) 还原。
- 思路：diff[l] += v, diff[r+1] -= v；前缀和还原原数组。与 BIT 的关系：一次性批量变更（无中途查询）用纯差分即可，BIT 用于「边改边查」。
- 评分点：差分构造与还原；一次性 vs 在线的选型；与 ALG-392 差分 BIT 对照。

```javascript
function diffUpdate(n, updates) {                          // updates: [{l, r, v}]
  const diff = new Array(n + 1).fill(0);
  for (const { l, r, v } of updates) {
    diff[l] += v;                                          // 区间起点
    diff[r + 1] -= v;                                      // 区间终点外
  }
  const result = new Array(n);
  let cur = 0;
  for (let i = 0; i < n; i++) {
    cur += diff[i];                                        // 前缀和还原
    result[i] = cur;
  }
  return result;
}
// 例：n=5, updates [{l:1,r:3,v:5},{l:2,r:4,v:2}] → [5,7,7,2,0]
// 选型：全部改完才查 → 差分数组 O(n+q)；边改边查 → BIT/线段树
```
