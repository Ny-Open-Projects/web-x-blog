## ALG-534：手写矩阵快速幂思想：周期性状态

**答**：
- 题目：系统状态按周期规律转移（如值班表每 3 天循环 + 递推），求第 N 天状态——转移矩阵快速幂 O(log N)。
- 思路：状态向量 × 转移矩阵；矩阵快速幂（反复平方）。展示 2×2 矩阵幂（斐波那契变体）。
- 评分点：线性递推→矩阵形式；快速幂反复平方；状态数=矩阵维度。

```javascript
function matMul(A, B, mod = 1e9 + 7) {
  const n = A.length, m = B[0].length, k = B.length;
  const C = Array.from({ length: n }, () => new Array(m).fill(0));
  for (let i = 0; i < n; i++)
    for (let p = 0; p < k; p++)
      for (let j = 0; j < m; j++)
        C[i][j] = (C[i][j] + A[i][p] * B[p][j]) % mod;
  return C;
}
function matPow(M, p, mod = 1e9 + 7) {                     // 矩阵快速幂
  const n = M.length;
  let R = Array.from({ length: n }, (_, i) =>
    Array.from({ length: n }, (_, j) => i === j ? 1 : 0));  // 单位阵
  while (p > 0) {
    if (p & 1) R = matMul(R, M, mod);
    M = matMul(M, M, mod);                                 // 反复平方
    p >>= 1;
  }
  return R;
}
function fibN(n) {                                         // 斐波那契第 n 项 O(log n)
  const M = [[1, 1], [1, 0]];
  const R = matPow(M, n);
  return R[0][1];
}
// 场景：周期 + 线性递推的系统状态直接跳算，不必逐天模拟
```
