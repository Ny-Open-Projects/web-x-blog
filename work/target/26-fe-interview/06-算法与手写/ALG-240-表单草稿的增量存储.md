## ALG-240：大表单草稿的增量存储：只存变更字段（diff patch），恢复时按序重放？
**答**：200 字段的配置表单草稿，全量存 localStorage 每次写 50KB（输入频繁，配额压力大）。增量方案：每次保存只存"与上次保存的 diff"（patch），恢复时按序重放 patches；定期压实（patches 超过 N 个合并为全量快照）。

**思路**：diff = {field: value}（浅层 diff 足够，字段扁平）；恢复 = 快照 + 按序应用 patches；压实 = patches 长度 > 20 时合并成一个快照。

```javascript
function diffPatch(base, next) {
  const patch = {};
  for (const k of Object.keys(next)) {
    if (base[k] !== next[k]) patch[k] = next[k];        // 只存变更字段
  }
  for (const k of Object.keys(base)) {
    if (!(k in next)) patch[k] = undefined;             // 删除的字段记 undefined
  }
  return patch;
}
class DraftStore {
  constructor(key) { this.key = key; }
  save(values) {
    const doc = JSON.parse(localStorage.getItem(this.key) || '{"base":{},"patches":[]}');
    const cur = this.#restore(doc);
    const patch = diffPatch(cur, values);
    if (!Object.keys(patch).length) return;              // 无变化不写
    doc.patches.push(patch);
    if (doc.patches.length > 20) {                       // 压实：合并为全量快照
      doc.base = this.#restore(doc); doc.patches = [];
    }
    localStorage.setItem(this.key, JSON.stringify(doc));
  }
  load() { return this.#restore(JSON.parse(localStorage.getItem(this.key) || '{"base":{},"patches":[]}')); }
  #restore(doc) {
    const out = { ...doc.base };
    for (const p of doc.patches) Object.assign(out, p);
    return out;
  }
}
// 存储体积：200 字段全量 50KB → diff 通常 < 500B（单字段修改）；配额压力降 99%
// 压实保证恢复性能（重放 20 个 patch 以内）；无变化不写（脏检查同 HW-104）
```

**评分点**：
- diff patch 增量语义（变更字段 + 删除字段记 undefined）。
- 恢复 = 快照 + 按序重放；压实机制（超 N 个 patch 合并快照）。
- 无变化不写的脏检查。
- 体积量化对比（50KB → 数百 B）说明方案价值。
