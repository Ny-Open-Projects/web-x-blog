## HW-388：手写一个主题引擎：CSS 变量注入与实时切换

**答**：
- 需求：实现 ThemeEngine：主题定义（token 表：颜色/间距/圆角/阴影）；apply(theme) 生成 CSS variables 注入 :root；实时切换（变量替换即时生效，无重载）；主题继承（dark 继承 light 覆盖部分 token）；导出/导入主题 JSON。
- 边界：颜色 token 支持引用（--primary 引用 --brand，切换时联动）；无效 token 校验（颜色格式）；动态注入 style 标签管理（单例）。
- 评分点：变量引用联动；继承覆盖；单例 style 管理。

```javascript
class ThemeEngine {
  constructor(themes) { this.themes = new Map(Object.entries(themes)); this.current = null; }
  apply(name) {
    const theme = this.themes.get(name);
    if (!theme) throw new Error('no-theme: ' + name);
    const resolved = this.resolve(theme);                    // 继承合并 + 引用解析
    let style = document.getElementById('theme-vars');
    if (!style) {
      style = document.createElement('style');               // 单例 style 标签
      style.id = 'theme-vars';
      document.head.appendChild(style);
    }
    style.textContent = `:root{${Object.entries(resolved)
      .map(([k, v]) => `${k}:${v}`).join(';')}}`;
    this.current = name;
    this.onchange?.(name, resolved);
  }
  resolve(theme, base = {}) {                                // 继承：extends 覆盖
    const inherited = theme.extends ? this.resolve(this.themes.get(theme.extends), base) : base;
    const merged = { ...inherited, ...theme.tokens };
    return this.linkVars(merged);                            // 引用联动
  }
  linkVars(tokens) {                                         // --primary: var(--brand) 引用
    const out = {};
    for (const [k, v] of Object.entries(tokens)) {
      const varName = '--' + k.replace(/[A-Z]/g, m => '-' + m.toLowerCase());
      out[varName] = typeof v === 'string' && tokens[v] != null
        ? `var(--${v.replace(/[A-Z]/g, m => '-' + m.toLowerCase())})` : v;
    }
    return out;
  }
  validate(theme) {                                          // 颜色格式校验
    for (const [k, v] of Object.entries(theme.tokens ?? {}))
      if (/color|bg/i.test(k) && !/^#([0-9a-f]{3,8})$|^rgb/i.test(v))
        return { ok: false, token: k, value: v };
    return { ok: true };
  }
  export(name) { return JSON.stringify(this.themes.get(name)); }
  import(json) { const t = JSON.parse(json); this.themes.set(t.name, t); }
}
```
