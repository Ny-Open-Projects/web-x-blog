## HW-394：手写一个敏感词过滤层：输入与粘贴双通道拦截

**答**：
- 需求：实现 SensitiveFilter：词库（Trie 构建）；检测（AC 自动机多模式匹配，返回命中词与位置）；输入通道（输入防抖后检测，命中标红提示不阻断）；粘贴通道（粘贴前检测，命中词替换为 * 或整段拒绝，可配策略）；词库热更新。
- 边界：变体对抗（全角/繁体归一化后再匹配）；替换策略（mask/replace/reject）；命中审计日志（不计内容只计次数）；性能（增量检测——只检变更段）。
- 评分点：双通道策略；归一化对抗；增量检测。

```javascript
class SensitiveFilter {
  constructor(words) { this.trie = buildTrie(words); this.policy = 'mask'; }
  normalize(text) {                                          // 变体归一化
    return text
      .replace(/[Ａ-Ｚａ-ｚ０-９]/g, c => String.fromCharCode(c.charCodeAt(0) - 0xfee0))   // 全角→半角
      .replace(/[\u0300-\u036f]/g, '');                     // 去变音符
  }
  detect(text) {                                             // AC 匹配
    const hits = [];
    let node = this.trie;
    const t = this.normalize(text);
    for (let i = 0; i < t.length; i++) {
      let cur = node;
      for (let j = i; j < t.length; j++) {
        cur = cur.children?.[t[j]];
        if (!cur) break;
        if (cur.word) hits.push({ word: cur.word, start: i, end: j + 1 });
      }
    }
    return hits;
  }
  filter(text) {                                             // 按策略处理
    const hits = this.detect(text);
    auditLog({ count: hits.length, words: hits.map(h => h.word.length + '字') });   // 审计不含内容
    if (!hits.length) return { text, blocked: false };
    if (this.policy === 'reject') return { text: null, blocked: true };
    let out = text;
    for (const h of hits.reverse())                          // 倒序替换防偏移
      out = out.slice(0, h.start) + '*'.repeat(h.end - h.start) + out.slice(h.end);
    return { text: out, blocked: false };
  }
  onPaste(e, onResult) {                                     // 粘贴通道拦截
    const text = e.clipboardData.getData('text/plain');
    const res = this.filter(text);
    if (res.blocked) { e.preventDefault(); onResult?.({ blocked: true }); }
    else if (res.text !== text) { e.preventDefault();         // 有替换：接管插入
      document.execCommand('insertText', false, res.text);
      onResult?.({ masked: true });
    }
  }
  updateWords(words) { this.trie = buildTrie(words); }       // 词库热更新
}
function buildTrie(words) {
  const root = {};
  for (const w of words) {
    let n = root;
    for (const c of w) n = n.children ??= {}, n = n.children[c] ??= {};
    n.word = w;
  }
  return root;
}
```
