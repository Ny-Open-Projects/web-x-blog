## HW-347：手写一个缩放平移视图：以光标为中心缩放

**答**：
- 需求：实现 Viewport：scale + offset（世界→屏幕：screen = world*scale + offset）；wheel 缩放（以光标为锚点：缩放前后光标下世界坐标不变）；拖拽平移（空格或中键）；坐标换算 screenToWorld / worldToScreen；缩放范围钳制。
- 边界：锚点公式推导（world = (screen - offset)/scale，offset2 = screen - world*scale2）；滚轮 deltaY 方向（deltaY < 0 放大）；resize 后视口自适应。
- 评分点：锚点缩放公式；双向坐标换算；范围钳制。

```javascript
class Viewport {
  constructor({ minScale = 0.1, maxScale = 8 } = {}) {
    this.scale = 1; this.ox = 0; this.oy = 0; this.min = minScale; this.max = maxScale;
  }
  screenToWorld(sx, sy) { return { x: (sx - this.ox) / this.scale, y: (sy - this.oy) / this.scale }; }
  worldToScreen(wx, wy) { return { x: wx * this.scale + this.ox, y: wy * this.scale + this.oy }; }
  wheel(e) {
    const k = e.deltaY < 0 ? 1.1 : 0.9;                      // deltaY 方向
    const next = Math.max(this.min, Math.min(this.max, this.scale * k));   // 钳制
    const w = this.screenToWorld(e.offsetX, e.offsetY);      // 光标下世界坐标（锚点）
    this.scale = next;
    this.ox = e.offsetX - w.x * next;                        // offset' = screen - world*scale'
    this.oy = e.offsetY - w.y * next;
  }
  pan(dx, dy) { this.ox += dx; this.oy += dy; }
  apply(ctx) { ctx.setTransform(this.scale, 0, 0, this.scale, this.ox, this.oy); }   // 渲染应用
}
```
