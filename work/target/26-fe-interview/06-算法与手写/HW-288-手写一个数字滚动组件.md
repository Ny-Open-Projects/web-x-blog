## HW-288：手写一个数字滚动组件：缓动插值与格式化

**答**：
- 需求：实现 NumberRoller：from→to 数值滚动（requestAnimationFrame + easeOutCubic），持续 800ms；滚动中每帧经 formatter（千分位/小数位）渲染；并发调用（滚动中新目标）从当前显示值续滚（不跳变）；支持 reduceMotion 时直接跳到终值。
- 边界：连续目标排队（取最新，取消中间）；格式化在渲染帧执行（不缓存中间）；精度（浮点累计误差用 from+t*(to-from) 插值避免累加）。
- 评分点：续滚不跳变；精度插值；reduceMotion。

```javascript
class NumberRoller {
  constructor(el, { duration = 800, format } = {}) {
    this.el = el; this.duration = duration;
    this.format = format ?? (n => n.toLocaleString('zh-CN'));
    this.display = 0; this.raf = null;
    this.reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
  }
  to(target) {
    cancelAnimationFrame(this.raf);                          // 取消中间目标
    if (this.reduce) { this.display = target; this.render(); return; }
    const from = this.display, t0 = performance.now();       // 从当前显示值续滚
    const tick = now => {
      const p = Math.min((now - t0) / this.duration, 1);
      const e = 1 - Math.pow(1 - p, 3);                      // easeOutCubic
      this.display = from + (target - from) * e;             // 插值式：无浮点累加误差
      this.render();
      if (p < 1) this.raf = requestAnimationFrame(tick);
    };
    this.raf = requestAnimationFrame(tick);
  }
  render() { this.el.textContent = this.format(this.display); }
}
```
