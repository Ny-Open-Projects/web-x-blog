## ALG-368：线段树与树状数组选型对比实现：统计需求选型

**答**：
- 题目：给出需求矩阵判断用什么：① 单点加+前缀和查询（BIT）；② 区间加+区间和（双 BIT 或线段树）；③ 区间最值（线段树，BIT 不便）；④ 带懒标记复杂标记（线段树）。实现两者核心并给出选型表。
- 思路：BIT 代码短/常数小/内存省（2n），只擅长前缀可减的运算；线段树通用但代码多/内存 4n。区间加+区间和可用双 BIT（维护差分数组的 Σd 和 Σi*d）实现，不必上线段树。
- 评分点：BIT 两套查询公式；双 BIT 推导；选型表按操作组合判断。

```javascript
class BIT {                                               // 单点加 + 前缀和
  constructor(n) { this.n = n; this.t = new Array(n + 1).fill(0); }
  add(i, v) { for (i++; i <= this.n; i += i & -i) this.t[i] += v; }   // lowbit 跳跃
  sum(i) { let s = 0; for (i++; i > 0; i -= i & -i) s += this.t[i]; return s; }
  range(l, r) { return this.sum(r) - this.sum(l - 1); }
}
class DoubleBIT {                                          // 区间加 + 区间和
  constructor(n) { this.n = n; this.b1 = new BIT(n); this.b2 = new BIT(n); }
  add(l, r, v) {                                           // [l,r] 区间加
    this.b1.add(l, v); this.b1.add(r + 1, -v);
    this.b2.add(l, v * (l - 1)); this.b2.add(r + 1, -v * r);
  }
  prefix(i) { return this.b1.sum(i) * i - this.b2.sum(i); }   // Σd×i 修正
  range(l, r) { return this.prefix(r) - this.prefix(l - 1); }
}
// 选型表：单点改前缀查→BIT；区间加区间和→DoubleBIT；区间最值/复杂标记→线段树
```
