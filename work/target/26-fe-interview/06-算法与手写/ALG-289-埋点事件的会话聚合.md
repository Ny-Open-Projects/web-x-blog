## ALG-289：埋点会话聚合：事件流的 session 窗口切分（间隔阈值 + 会话内指标聚合，流式单遍）？
**答**：ALG-219 会话切分的指标版：切分后聚合每会话（事件数/页面数/时长/转化标记），流式单遍（事件到达即处理，不囤全量）。

**思路**：滑动状态机（当前会话累积器）——间隔超阈值即结算当前会话（emit）并开新会话；内存 = 单会话状态（恒定）。

```javascript
function createSessionAggregator({ gapMs = 30 * 60000, emit } = {}) {
  let session = null;                                     // 单会话累积器（内存恒定）
  return function consume(event) {
    if (!session || event.ts - session.lastTs > gapMs) {
      if (session) emit(session);                         // 结算旧会话
      session = { start: event.ts, lastTs: event.ts, events: 0, pages: new Set(),
                  converted: false, firstPage: event.page };
    }
    session.lastTs = event.ts;
    session.events++;
    if (event.page) session.pages.add(event.page);
    if (event.type === 'pay') session.converted = true;   // 转化标记
    // 流式语义：事件到达即更新，不囤原始事件列表（pages 用 Set 去重）
  };
}
// 内存：单会话状态（events 计数 + pages Set）—— 恒定（对比 ALG-219 的切片存储，适合高吞吐管道）
// 转化归因：converted 标记挂在会话上 —— "该会话浏览 5 页后转化"（漏斗分析的会话粒度数据）
// flush 兜底：流结束/页面 hidden 时 emit 最后一个未结算会话
```

**评分点**：
- 流式状态机（单会话累积器，内存恒定）——本题核心（对比 ALG-219 存储版）。
- 聚合字段增量更新（计数/Set 去重/转化标记）。
- emit 结算时机（间隔切分 + flush 兜底）。
- 高吞吐管道的适用性。
