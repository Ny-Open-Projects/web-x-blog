## HW-231：手写一个表格数据模型与单元格选择：range 选择与方向键扩展

**答**：
- 需求：实现 TableSelection：rows×cols 数据矩阵；select({r1,c1},{r2,c2})（拖选归一化）；move(dir, {extend})——extend 时扩展选区边界，否则移动单选；selected() 输出选区内所有单元格（行列遍历）；shift+方向键扩展语义正确。
- 边界：单选 = 1×1 区间；越界钳制；反向拖选（起点大于终点）归一化。
- 评分点：extend 语义；归一化；越界钳制。

```javascript
class TableSelection {
  constructor(rows, cols) { this.rows = rows; this.cols = cols; this.r1 = 0; this.c1 = 0; this.r2 = 0; this.c2 = 0; }
  select(a, b) { Object.assign(this, { r1: a.r, c1: a.c, r2: b.r, c2: b.c }); this.norm(); }
  norm() { this.r1 = Math.min(this.r1, this.r2); this.r2 = Math.max(this.r1, this.r2);
    this.c1 = Math.min(this.c1, this.c2); this.c2 = Math.max(this.c1, this.c2); }
  move(dir, { extend = false } = {}) {
    const d = { ArrowUp: [-1, 0], ArrowDown: [1, 0], ArrowLeft: [0, -1], ArrowRight: [0, 1] }[dir];
    if (!d) return false;
    const [dr, dc] = d;
    if (extend) {                                             // 扩展边界
      this.r2 = clamp(this.r2 + dr, 0, this.rows - 1);
      this.c2 = clamp(this.c2 + dc, 0, this.cols - 1);
    } else {
      const r = clamp(this.r2 + dr, 0, this.rows - 1), c = clamp(this.c2 + dc, 0, this.cols - 1);
      this.r1 = this.r2 = r; this.c1 = this.c2 = c;           // 移动单选
    }
    this.norm(); return true;
  }
  *selected() {
    for (let r = this.r1; r <= this.r2; r++)
      for (let c = this.c1; c <= this.c2; c++) yield { r, c };
  }
}
const clamp = (v, lo, hi) => Math.max(lo, Math.min(hi, v));
```
