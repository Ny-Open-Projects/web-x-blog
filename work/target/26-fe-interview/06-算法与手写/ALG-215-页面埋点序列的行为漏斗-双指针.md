## ALG-215：增长分析：判断用户行为序列是否完整走过转化漏斗（有序子序列匹配，双指针 O(n)）
**答**：漏斗步骤 `['view', 'add_cart', 'pay']`，判断用户事件序列（时间序）是否**按序**完整经过这些步骤（中间可以有其他事件）。逐事件双指针匹配，O(n)。

**思路**：指针 j 指向漏斗当前步骤，扫事件序列，事件名等于漏斗[j] 则 j++，j 走完即完成。注意"按序"语义：乱序（pay 先于 add_cart）不算完成。

```javascript
function passedFunnel(events, funnel) {
  let j = 0;
  for (const e of events) {
    if (e.type === funnel[j]) j++;                 // 命中当前步骤：推进
    if (j === funnel.length) return { done: true, at: e.ts, steps: j };
  }
  return { done: false, steps: j };                // 卡在第几步（流失分析）
}
const events = [
  { type: 'view', ts: 1 }, { type: 'share', ts: 2 }, { type: 'view', ts: 3 },
  { type: 'add_cart', ts: 4 }, { type: 'pay', ts: 9 },
];
passedFunnel(events, ['view', 'add_cart', 'pay']);
// => { done: true, at: 9, steps: 3 }（第二次 view 才算漏斗第一步——按序匹配）
// 流失分析：steps=2 表示走到了 add_cart 但没 pay → 漏斗第 3 步流失
// 进阶：漏斗步骤带时间窗口（如 add_cart 后 10min 内 pay 才算）→ 记录每步命中时间做窗口校验
```

**评分点**：
- 双指针按序匹配正确（乱序不算完成，这是与"集合包含"的本质区别）。
- 返回流失步数（steps）支撑流失分析，不只是布尔。
- O(n) 单次扫描。
- 能说出时间窗口变体的扩展方式。
