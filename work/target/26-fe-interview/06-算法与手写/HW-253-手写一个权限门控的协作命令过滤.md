## HW-253：手写一个权限门控的协作命令过滤：只读、评论与编辑三级

**答**：
- 需求：实现 PermissionGate：roles = {viewer, commenter, editor}；filter(cmd) 按角色判定（viewer 全拒绝；commenter 允许 comment/anchor 类，拒绝文本编辑；editor 全通过）；敏感命令（删除文档/改权限）需要 editor+owner 双重判定；拒绝时输出原因供 UI 提示。
- 边界：角色变更即时生效（缓存失效）；命令类别注册表（可扩展）；批量命令部分通过时逐条返回结果。
- 评分点：角色-动作矩阵；即时生效；批量逐条结果。

```javascript
class PermissionGate {
  constructor() { this.matrix = new Map([                  // role -> 允许的命令类别
    ['viewer', new Set(['read'])],
    ['commenter', new Set(['read', 'comment', 'anchor'])],
    ['editor', new Set(['read', 'comment', 'anchor', 'edit', 'structural'])],
  ]);
  this.ownerOnly = new Set(['delete-doc', 'change-permission']); }
  check(cmd, role, { isOwner = false } = {}) {
    const cats = this.matrix.get(role);
    if (!cats?.has(cmd.category)) return { ok: false, reason: `role ${role} lacks ${cmd.category}` };
    if (this.ownerOnly.has(cmd.name) && !isOwner)
      return { ok: false, reason: 'owner-only command' };
    return { ok: true };
  }
  filterBatch(cmds, role, opts) {
    return cmds.map(c => ({ cmd: c, ...this.check(c, role, opts) }));   // 逐条结果
  }
  setRole(user, role) { roles.set(user, role); }           // 即时生效（无缓存）
}
// 用法：gate.check({name:'insert-text', category:'edit'}, 'commenter') → {ok:false, ...}
```
