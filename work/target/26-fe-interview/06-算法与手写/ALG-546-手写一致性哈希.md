## ALG-546：手写一致性哈希：分片路由

**答**：
- 题目：缓存分片路由——节点增减时只迁移少量数据。一致性哈希：哈希环 + 虚拟节点，找「顺时针第一个 ≥ key 的节点」。
- 思路：节点映射到环（hash(node)）；key 路由 = 排序后二分找第一个 >= hash(key)；虚拟节点（每物理节点 100 个 vnode）均衡负载。
- 评分点：环路由二分；虚拟节点均衡；迁移量 1/n（vs 取模全迁）。

```javascript
class ConsistentHash {
  constructor({ vnodes = 100 } = {}) { this.vnodes = vnodes; this.ring = new Map(); }
  hash(s) { let h = 0; for (const c of s) h = (h * 31 + c.charCodeAt(0)) >>> 0; return h; }
  addNode(node) {                                          // 加节点：虚拟节点上环
    for (let i = 0; i < this.vnodes; i++) {
      const h = this.hash(node + '#' + i);
      this.ring.set(h, node);
    }
    this.sorted = [...this.ring.keys()].sort((a, b) => a - b);
  }
  removeNode(node) {
    for (const [h, n] of [...this.ring]) if (n === node) this.ring.delete(h);
    this.sorted = [...this.ring.keys()].sort((a, b) => a - b);
  }
  route(key) {                                             // 顺时针第一个 ≥ hash(key)
    const h = this.hash(key);
    let lo = 0, hi = this.sorted.length - 1;
    while (lo <= hi) { const m = (lo + hi) >> 1;
      this.sorted[m] < h ? lo = m + 1 : hi = m - 1; }
    const ringH = this.sorted[lo] ?? this.sorted[0];        // 环绕
    return this.ring.get(ringH);
  }
}
```
