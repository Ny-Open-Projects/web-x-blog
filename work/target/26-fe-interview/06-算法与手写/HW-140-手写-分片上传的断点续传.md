## HW-140：手写分片上传断点续传——init/chunk/complete 三阶段、失败分片重试、秒传（hash 命中）
**答**：大文件上传三阶段：init（服务端返回 uploadId + 已有分片列表——断点续传与秒传）→ chunk（并发分片，失败重试单分片）→ complete（服务端合并校验）。秒传：文件 hash（Worker 算，主线程不卡）命中服务端已有文件直接完成。进度与断点持久化（localStorage 存 uploadId + 已传分片）。

```javascript
async function uploadLarge(file, { chunkSize = 4 * 1024 * 1024, concurrency = 3 } = {}) {
  const hash = await hashInWorker(file);                        // Worker 算 SHA-256（不卡主线程）
  const init = await api('/upload/init', { hash, size: file.size, name: file.name });
  if (init.exists) return { fastUpload: true, url: init.url };  // 秒传：hash 命中
  const uploaded = new Set(init.uploaded ?? []);                // 服务端告知已传分片（断点续传）
  const chunks = Math.ceil(file.size / chunkSize);
  let next = 0, active = 0;
  await new Promise((resolve, reject) => {
    const drain = () => {
      while (active < concurrency && next < chunks) {
        const i = next++;
        if (uploaded.has(i)) continue;                          // 跳过已传分片
        active++;
        const blob = file.slice(i * chunkSize, Math.min((i + 1) * chunkSize, file.size));
        api(`/upload/chunk?uploadId=${init.uploadId}&index=${i}`, blob, { method: 'PUT' })
          .then(() => uploaded.add(i))
          .catch(() => { next = i; })                           // 失败：该分片回队重试
          .finally(() => { active--; drain(); if (uploaded.size === chunks) resolve(); });
      }
      if (!active && next >= chunks && uploaded.size === chunks) resolve();
    };
    drain();
  });
  return api('/upload/complete', { uploadId: init.uploadId, hash });   // 服务端合并校验 hash
}
// 断点续传：uploadId + uploaded 列表持久化 → 刷新后重新 init 拿已传分片继续
// 秒传：hash 命中直接返回 URL（0 上传）；hash 在 Worker 算（50MB 文件 SHA-256 主线程卡 1s+）
```

**评分点**：
- 三阶段协议完整；init 返回已传分片列表实现断点续传与秒传。
- hash 在 Worker 计算（主线程不卡）；秒传语义（hash 命中 0 上传）。
- 分片失败单分片回队重试（不是整个文件重来）；并发上限。
- complete 阶段服务端合并 + hash 校验（防分片错序/损坏）。
