## ALG-489：手写加油站问题：电量续航站点

**答**：
- 题目：环形路线，站点 i 有油 gas[i]，站间耗油 cost[i]，求能否绕一圈及起点。经典 O(n) 贪心：总油 >= 总耗即可行，起点 = 最低谷的下一站。
- 思路：一趟扫描：cur 油量 < 0 时起点重置为 i+1（之前所有起点都不行）；最后总差 >= 0 保证可行。
- 评分点：局部失败全局重启的正确性证明；total >= 0 充要；起点唯一性。

```javascript
function canCompleteCircuit(gas, cost) {                   // 环形加油
  let total = 0, cur = 0, start = 0;
  for (let i = 0; i < gas.length; i++) {
    const diff = gas[i] - cost[i];
    total += diff; cur += diff;
    if (cur < 0) {                                         // 局部亏空：换起点
      start = i + 1;
      cur = 0;
    }
  }
  return total >= 0 ? start : -1;                          // 总量够才可行
}
// 正确性：若从 a 出发到 i 亏空，则 a..i 之间任意起点也到不了 i+1（油只少不多）
// 故下一个候选起点 = i + 1——每个站只访问一次 O(n)
```
