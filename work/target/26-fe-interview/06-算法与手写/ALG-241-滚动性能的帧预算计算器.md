## ALG-241：滚动性能预算：给定渲染回调耗时，计算每帧可渲染多少行（帧预算反推数量）？
**答**：滚动时每帧要渲染新增行，60fps 帧预算 16.7ms——减去样式/合成开销后给"行渲染"的预算有限。给定单行渲染耗时（实测），反推每帧最多渲染几行不丢帧；超出部分排队到后续帧。

**思路**：budget = 16.7 - overhead(测量)；perRow 实测；rowsPerFrame = floor(budget / perRow)；用环形单调队列/简单计数在 rAF 中按预算渲染。

```javascript
function frameBudgetCalculator({ overheadMs = 4, perRowMs, fps = 60 }) {
  const budget = 1000 / fps - overheadMs;
  const rowsPerFrame = Math.max(1, Math.floor(budget / perRowMs));
  return { budget, rowsPerFrame };          // perRowMs=1.2 → budget 12.7ms → 每帧 10 行
}
class BudgetedRenderer {
  constructor(queue, { rowsPerFrame = 10 } = {}) { Object.assign(this, { queue, rowsPerFrame }); this.running = false; }
  run() {
    if (this.running) return;
    this.running = true;
    const tick = () => {
      if (!this.queue.length) { this.running = false; return; }
      const batch = this.queue.splice(0, this.rowsPerFrame);      // 每帧按预算取
      batch.forEach((row) => mountRow(row));
      requestAnimationFrame(tick);
    };
    requestAnimationFrame(tick);
  }
}
// 每帧 10 行 × 60fps = 600 行/秒的渲染吞吐——快速滚动 1000 行需 ~1.7s 补齐
// 配合 overscan 缓冲（提前渲染）与骨架占位（PER-067），用户感知不到排队
// perRowMs 实测方法：Performance 面板单行 mount 的自耗时，或微基准（mount 100 行取均值）
```

**评分点**：
- 帧预算公式（16.7ms - overhead，除以单行耗时）正确。
- 每帧按预算取批（rAF 队列）的渲染调度。
- 能说明吞吐量推算（600 行/秒）与 overscan/骨架的配套。
- perRowMs 的实测来源意识。
