## ALG-308：数据变化后的滚动比例恢复：scrollTop 按内容高度比例映射（锚点不可用时的兜底）？
**答**：ALG-103 锚点不可用（数据全换无相同 id）——比例恢复：旧 scrollTop/旧高度 = 新 scrollTop/新高度（用户阅读位置的"比例语义"近似——看到 40% 处，新数据也到 40%）。

**思路**：离开时存 ratio + anchor（双保险）→ 恢复时锚点命中用锚点，未命中用 ratio × 新高度。

```javascript
function saveScroll(container) {
  const ratio = container.scrollTop / (container.scrollHeight - container.clientHeight || 1);
  return { ratio: +ratio.toFixed(4), scrollTop: container.scrollTop };
}
function restoreScroll(container, saved) {
  requestAnimationFrame(() => {
    const max = container.scrollHeight - container.clientHeight;
    if (Number.isFinite(saved.ratio) && max > 0) {
      container.scrollTop = Math.round(saved.ratio * max);   // 比例映射（锚点失效的兜底）
    }
  });
}
// 双保险优先级：锚点 id 命中（ALG-103）> 比例映射 > scrollTop 裸恢复
// 比例恢复的语义近似：用户在读 40% 处 → 新数据 40% 处大概率是同类内容（列表排序稳定的场景准确率高）
// 失效场景：数据量剧变（50 条 → 5000 条）比例失真 —— 此时降级为顶部（经验法则：ratio > 0.9 或数据量变化 > 10 倍时回顶部）
```

**评分点**：
- ratio 比例映射（scrollHeight 归一）——本题核心（锚点不可用的兜底）。
- 双保险优先级链（锚点 > 比例 > 裸值）。
- 数据量剧变的失效场景与降级（回顶部）。
- rAF 延迟（渲染完成后再设，HW-103 时序纪律）。
