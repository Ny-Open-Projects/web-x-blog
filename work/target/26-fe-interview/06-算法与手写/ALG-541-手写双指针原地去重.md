## ALG-541：手写双指针原地去重：列表清理

**答**：
- 题目：有序列表原地去重（不申请额外数组，返回新长度）——快慢指针：慢针写位置，快针扫描。
- 思路：快指针扫描，与前一保留值不同则写入慢针位置并前进。原数组前方即为去重结果。
- 评分点：原地语义（空间 O(1)）；快慢指针分工；稳定保序。

```javascript
function removeDuplicatesInPlace(arr) {
  let slow = 0;
  for (let fast = 1; fast < arr.length; fast++) {
    if (arr[fast] !== arr[slow]) {                         // 新值
      arr[++slow] = arr[fast];                             // 写入慢针位置
    }
  }
  const newLen = slow + 1;
  arr.length = newLen;                                     // 截断尾部
  return newLen;
}
// 例：[1,1,2,2,3] → [1,2,3] 长度 3
// 变体：保留至多 k 个重复——比较 arr[fast] !== arr[slow - k + 1]
```
