## HW-390：手写一个文档打印器：分页计算与分页预览

**答**：
- 需求：实现 PrintLayout：A4 尺寸（210mm×297mm，去边距后内容区）；分页算法：按块级元素高度累计（DOM 实测 offsetHeight → mm 换算），块不可分割则整体换页，长块允许内部断行（按行高整数分割）；页眉页脚与页码；预览渲染（分页容器预览）与 print() 触发。
- 边界：mm↔px 换算（96dpi：1mm = 3.7795px）；块跨越页边界时断开位置（避免行截断——按行盒边界）；表格跨页表头重复（简化：标记建议）。
- 评分点：mm 换算；不可分割块换页；断行边界。

```javascript
class PrintLayout {
  constructor({ margins = { top: 25, bottom: 20, left: 20, right: 20 } } = {}) {
    this.m = margins;
    this.PX_PER_MM = 96 / 25.4;                              // 96dpi 换算
  }
  contentSize() { return { w: 210 - this.m.left - this.m.right,
    h: 297 - this.m.top - this.m.bottom }; }                 // 内容区 mm
  paginate(rootEl) {
    const { h: contentHmm } = this.contentSize();
    const contentPx = contentHmm * this.PX_PER_MM;           // mm → px
    const pages = [];
    let cur = [], used = 0;
    for (const block of rootEl.children) {
      const bh = block.offsetHeight;
      if (used + bh <= contentPx) {
        cur.push(block); used += bh;                         // 放得下：当前页
      } else if (bh <= contentPx) {
        pages.push(cur); cur = [block]; used = bh;           // 不可分割：整体换页
      } else {                                               // 长块内部断行
        if (cur.length) { pages.push(cur); cur = []; used = 0; }
        const lineHeight = parseFloat(getComputedStyle(block).lineHeight);
        const perPage = Math.floor(contentPx / lineHeight);  // 按行盒整数分割
        const lines = Math.ceil(bh / lineHeight);
        for (let s = 0; s < lines; s += perPage) {
          pages.push([{ block, from: s, to: Math.min(s + perPage, lines) }]);   // 行区间
        }
        cur = []; used = 0;
      }
    }
    if (cur.length) pages.push(cur);
    return pages.map((p, i) => ({ index: i + 1, blocks: p,   // 页码
      header: `第 ${i + 1} / ${pages.length} 页` }));
  }
  print() {                                                  // 触发打印
    const css = `@page{size:A4;margin:${this.m.top}mm ${this.m.right}mm ${this.m.bottom}mm ${this.m.left}mm}`;
    const style = document.createElement('style');
    style.textContent = css;
    document.head.appendChild(style);
    window.print();
  }
}
```
