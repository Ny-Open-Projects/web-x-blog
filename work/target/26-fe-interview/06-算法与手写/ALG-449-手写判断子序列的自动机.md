## ALG-449：手写判断子序列的自动机：审计流匹配

**答**：
- 题目：大量查询「s 是否为 t 的子序列」——预处理 t 构建自动机：next[i][c] = 位置 i 后字符 c 的下一个位置，查询 O(len(s))。
- 思路：从右往左构建 next 表（O(n×26) 空间，或每字符位置列表 + 二分——空间 O(n)）；查询沿 next 跳。
- 评分点：自动机预处理 vs 每次双指针扫描的取舍；二分版的空间优势；多查询场景的均摊。

```javascript
class SubsequenceAutomaton {
  constructor(t) {                                          // 二分版：每字符位置列表
    this.positions = new Map();
    for (let i = 0; i < t.length; i++) {
      const c = t[i];
      (this.positions.get(c) ?? this.positions.set(c, []).get(c)).push(i);
    }
  }
  isSubsequence(s) {                                        // O(len(s) log n)
    let cur = -1;
    for (const c of s) {
      const list = this.positions.get(c);
      if (!list) return false;
      // 二分找 > cur 的最小位置
      let lo = 0, hi = list.length - 1, found = -1;
      while (lo <= hi) { const m = (lo + hi) >> 1;
        list[m] > cur ? (found = list[m], hi = m - 1) : lo = m + 1; }
      if (found < 0) return false;
      cur = found;
    }
    return true;
  }
}
// 对比：单次查询双指针 O(n)；多查询（q 次）自动机预处理 O(n×26 或 n) + 每次 O(m log n)
// 场景：合规审计流中批量校验事件序列模式
```
