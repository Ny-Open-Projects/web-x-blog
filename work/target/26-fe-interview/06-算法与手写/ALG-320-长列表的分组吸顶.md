**场景**：通讯录分组吸顶：滚动时当前组名固定在顶部（sticky）——当前组判定用 IO（每组首元素与吸顶栏的相交检测），切换时标题文字替换（单 sticky 元素复用，比每组 sticky 更省 DOM）。

**思路**：单 sticky 标题栏 + IO 观察各组首元素 → 视口顶部穿越的组 = 当前组 → 标题栏文字更新。

```javascript
function groupSticky(groups, headerEl) {
  const current = { name: '' };
  const io = new IntersectionObserver((entries) => {
    for (const e of entries) {
      if (!e.isIntersecting) continue;
      // 组首元素进入吸顶栏区域：更新当前组（取穿越吸顶线的组）
      const name = e.target.dataset.group;
      if (name && name !== current.name) {
        current.name = name;
        headerEl.textContent = name;                    // 单元素复用：文本替换（零 DOM 重建）
      }
    }
  }, { rootMargin: `-${headerEl.offsetHeight}px 0px 0px 0px`, threshold: 0 });   // 吸顶栏偏移：以栏底为参考线
  groups.forEach((g) => io.observe(g.header));
}
// rootMargin 负顶部：IO 参考线 = 吸顶栏下沿（组首穿越该线 = 当前组切换）
// 单 sticky 复用 vs 每组 sticky：单元素文本替换（DOM 恒定）vs N 个 sticky（DOM 随组数增长）
// 吸顶标题点击 = 跳组索引（通讯录右侧索引条的联动，ALG-272 分组序一致）
```

**评分点**：
- IO rootMargin 负偏移对齐吸顶栏参考线——本题核心（穿越判定）。
- 单 sticky 元素文本替换（DOM 恒定 vs N 组 sticky）。
- 与通讯录索引条（ALG-272 分组）联动。
- 组切换的视觉连续性（textContent 替换零重建）。
