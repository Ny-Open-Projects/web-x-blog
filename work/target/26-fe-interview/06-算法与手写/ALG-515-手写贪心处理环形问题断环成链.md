## ALG-515：手写贪心处理环形问题（断环成链）：轮班排班

**答**：
- 题目：n 人环形排班（相邻不能同班型），判断可行并给出排法。环形处理：断环成链（复制数组）或固定首人分类讨论。
- 思路：固定 person[0] 的班型 → 线性化后续贪心（每人选与前者不同的班型）；环形闭合检查首尾不同——不行则交换中间某对。
- 评分点：断环成链技巧；闭合约束检查；构造性贪心。

```javascript
function scheduleRing(staff, shifts) {                     // 环形排班
  const n = staff.length;
  const plan = new Array(n);
  plan[0] = shifts[0];                                     // 固定首人
  for (let i = 1; i < n; i++) {                            // 线性贪心
    plan[i] = shifts.find(s => s !== plan[i - 1]);
    if (!plan[i]) return null;                             // 只有一种班型：不可行
  }
  if (plan[n - 1] === plan[0] && n > 2) {                  // 闭合检查
    // 找中间位置换班型使首尾不同
    for (let i = 1; i < n - 1; i++) {
      const alt = shifts.find(s => s !== plan[i - 1] && s !== plan[i + 1 < n ? i + 1 : 0]);
      if (alt) { plan[i] = alt; break; }
    }
    if (plan[n - 1] === plan[0] && shifts.length < 3) {
      return shifts.length >= 2 && n % 2 === 0 ? plan : null;   // 两班型需偶数环
    }
  }
  return plan;
}
```
