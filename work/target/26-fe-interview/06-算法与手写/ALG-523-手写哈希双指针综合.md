## ALG-523：手写哈希+双指针综合：去重滑动窗口

**答**：
- 题目：找「不含重复元素的最长子数组」（如用户会话中最长无重复行为序列）。双指针 + Set/Map（记录上次出现位置）。
- 思路：滑动窗口：右指针扩展，遇重复则左指针跳到「上次出现 +1」；窗口长度 max。Map 记 last[c]。
- 评分点：左指针跳跃（不逐步）；Map 语义；O(n)。

```javascript
function longestDistinct(arr) {
  const last = new Map();
  let left = 0, best = 0, bestRange = [0, 0];
  for (let right = 0; right < arr.length; right++) {
    const v = arr[right];
    if (last.has(v) && last.get(v) >= left)
      left = last.get(v) + 1;                              // 左指针跳跃
    last.set(v, right);
    if (right - left + 1 > best) {
      best = right - left + 1;
      bestRange = [left, right];
    }
  }
  return { length: best, range: bestRange,
    sequence: arr.slice(bestRange[0], bestRange[1] + 1) };
}
```
