## ALG-482：手写区间覆盖最小数量：埋点覆盖

**答**：
- 题目：若干采集点区间，求「覆盖 [0, T] 全程所需的最少区间数」，不可行返回 -1。贪心：每次选能覆盖当前位置且延伸最远的区间。
- 思路：按 start 排序；cur = 已覆盖到的位置，在所有 start <= cur 的区间里选 end 最大者，cur 跳到该 end；cur >= T 停止。
- 评分点：跳跃式贪心（选延伸最远）；不可行判定（无区间可接）；排序+双指针实现。

```javascript
function minIntervalsToCover(intervals, T) {               // 覆盖 [0, T]
  const sorted = [...intervals].sort((a, b) => a.start - b.start);
  let count = 0, cur = 0, i = 0;
  while (cur < T) {
    let farthest = cur;
    while (i < sorted.length && sorted[i].start <= cur) {   // 所有可接区间
      farthest = Math.max(farthest, sorted[i].end);        // 选延伸最远
      i++;
    }
    if (farthest === cur) return -1;                       // 无区间可接：不可行
    cur = farthest;
    count++;
  }
  return count;
}
// 例：[[0,5],[4,10],[9,20]] T=15 → 3 个；缺 [0,x] 起始 → -1
```
