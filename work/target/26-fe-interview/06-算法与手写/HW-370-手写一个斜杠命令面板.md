## HW-370：手写一个斜杠命令面板：编辑器内嵌组件

**答**：
- 需求：实现 SlashMenu：输入 / 触发命令面板（浮层跟随光标）；命令注册（{name, desc, icon, run}）；输入过滤（前缀匹配 + 模糊排序）；键盘导航（上下选择、Enter 执行、Esc 关闭）；执行后删除 /cmd 文本并运行命令。
- 边界：嵌套输入框内（widget 场景）事件冒泡隔离；无匹配显示"无结果"；执行命令可返回插入内容（块级插入）。
- 评分点：触发与过滤；执行后清理输入；命令可插块。

```javascript
class SlashMenu {
  constructor(editor, commands) {
    this.ed = editor; this.cmds = commands; this.open = false;
  }
  onInput(text, cursorOffset) {
    const m = /\/([\w-]*)$/.exec(text.slice(0, cursorOffset));   // 光标前 /cmd
    if (!m) return this.close();
    this.query = m[1];
    this.cands = this.cmds
      .filter(c => c.name.startsWith(this.query) || fuzzyMatch(this.query, c.name))
      .sort((a, b) => (a.name.startsWith(this.query) ? -1 : 1));
    this.idx = 0;
    this.open = true;
    this.render();
  }
  onKey(e) {
    if (!this.open) return 'none';
    e.stopPropagation();                                     // 隔离冒泡（嵌套输入框）
    if (e.key === 'ArrowDown') { this.idx = (this.idx + 1) % this.cands.length; this.render(); return 'handled'; }
    if (e.key === 'ArrowUp') { this.idx = (this.idx - 1 + this.cands.length) % this.cands.length; this.render(); return 'handled'; }
    if (e.key === 'Escape') { this.close(); return 'handled'; }
    if (e.key === 'Enter') { this.exec(this.cands[this.idx]); return 'handled'; }
    return 'none';
  }
  async exec(cmd) {
    const text = this.ed.lineText();
    const slashStart = text.lastIndexOf('/' + this.query);   // 执行后删除 /cmd
    this.ed.deleteRange(slashStart, slashStart + this.query.length + 1);
    this.close();
    const result = await cmd.run(this.ed);
    if (result?.block) this.ed.insertBlock(result.block);    // 命令可插块
  }
  close() { this.open = false; this.el?.remove(); }
  render() { /* 浮层：光标位置定位 + 高亮 idx */ }
}
function fuzzyMatch(p, t) { let i = 0;
  for (const c of t) if (c === p[i]) i++;
  return i === p.length; }
```
