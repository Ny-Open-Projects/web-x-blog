## ALG-395：手写二维树状数组：热力区域累计

**答**：
- 题目：地图按格记录事件数，查任意矩形区域的事件总数。二维 BIT：两层 lowbit 循环。
- 思路：update(x, y, v)：双层 for（x 方向、y 方向各走 lowbit）；query(x, y)：前缀矩形和；矩形查询 = 容斥四角。
- 评分点：双层 lowbit；容斥 (r,b)-(l-1,b)-(r,t-1)+(l-1,t-1)；内存 n×m 与稀疏优化（Map 版）。

```javascript
class BIT2D {
  constructor(n, m) { this.n = n; this.m = m;
    this.t = Array.from({ length: n + 1 }, () => new Array(m + 1).fill(0)); }
  add(x, y, v) {                                            // 1-based
    for (let i = x; i <= this.n; i += i & -i)
      for (let j = y; j <= this.m; j += j & -j) this.t[i][j] += v;
  }
  sum(x, y) {                                               // 前缀 (1..x, 1..y)
    let s = 0;
    for (let i = x; i > 0; i -= i & -i)
      for (let j = y; j > 0; j -= j & -j) s += this.t[i][j];
    return s;
  }
  rect(x1, y1, x2, y2) {                                    // 矩形容斥
    return this.sum(x2, y2) - this.sum(x1 - 1, y2)
      - this.sum(x2, y1 - 1) + this.sum(x1 - 1, y1 - 1);
  }
}
```
