## HW-240：手写一个编辑器测试工具：模拟输入序列并断言文档状态

**答**：
- 需求：实现 EditorTestHarness：type(str) 逐字符模拟（insert + 光标推进）；key(combo) 模拟快捷键；run(steps) 按序执行并收集每步快照；expect(docMatcher) 断言最终文档结构（blocks 文本/类型/marks）；snapshot() 输出当前文档 JSON 用于回归对比（golden file 模式）。
- 边界：IME 场景模拟（composition 序列：start→update→end）；异步操作（粘贴净化）用 await 步骤；失败输出 diff 而非整个文档。
- 评分点：IME 序列模拟；golden file；失败 diff。

```javascript
class EditorTestHarness {
  constructor(editor) { this.ed = editor; this.steps = []; }
  type(str) { this.steps.push(async () => {
    for (const ch of str) this.ed.insert(ch); }); return this; }
  ime(str) { this.steps.push(async () => {                     // IME 序列
    this.ed.compositionStart();
    for (const ch of str) this.ed.compositionUpdate(ch);
    this.ed.compositionEnd(str); }); return this; }
  key(combo) { this.steps.push(async () => this.ed.key(combo)); return this; }
  paste(text, html) { this.steps.push(async () => this.ed.paste(text, html)); return this; }
  async run() { for (const s of this.steps) await s(); return this.ed.getDoc(); }
  async expectDoc(matcher) {
    const doc = await this.run();
    const actual = pick(doc, Object.keys(matcher));
    const diffs = diffJson(matcher, actual);
    if (diffs.length) throw new Error('doc mismatch:\n' + diffs.map(d =>
      `${d.path}: expected ${JSON.stringify(d.want)} got ${JSON.stringify(d.got)}`).join('\n'));
    return true;
  }
  golden() { return JSON.stringify(this.ed.getDoc()); }        // golden file 模式
}
function diffJson(want, got, path = '$', out = []) {
  if (JSON.stringify(want) === JSON.stringify(got)) return out;
  if (typeof want !== 'object' || typeof got !== 'object') { out.push({ path, want, got }); return out; }
  const keys = new Set([...Object.keys(want), ...Object.keys(got)]);
  for (const k of keys) diffJson(want[k], got[k], path + '.' + k, out);
  return out;
}
```
