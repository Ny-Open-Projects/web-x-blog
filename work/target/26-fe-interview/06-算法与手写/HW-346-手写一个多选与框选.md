## HW-346：手写一个多选与框选：橡皮筋选择与多选变换

**答**：
- 需求：实现 RubberSelect：按下拖出矩形（橡皮筋渲染虚线框）；命中判定：包围盒相交（可配 contains 模式：完全包含才选中）；与已有单选合并（shift 加选）；框选结束后多选节点支持整体拖动变换（公共包围盒锚点）。
- 边界：拖拽方向反向（起点>终点）归一化；框选与画布平移共存（框选时禁平移）；整体拖动的位移分发到每个节点。
- 评分点：相交/包含两模式；shift 加选；整体变换分发。

```javascript
class RubberSelect {
  constructor(canvas, scene) { this.c = canvas; this.scene = scene; this.multiSel = new Set(); }
  start(e) {
    this.startPt = { x: e.offsetX, y: e.offsetY };
    const move = ev => {
      this.rect = normRect(this.startPt, { x: ev.offsetX, y: ev.offsetY });   // 反向归一化
      this.render();
    };
    const up = () => {
      removeEventListener('pointermove', move);
      if (this.rect) {
        const mode = e.shiftKey ? 'add' : 'replace';
        const hits = this.scene.nodes.filter(n =>
          this.mode === 'contains'
            ? containsRect(this.rect, bounds(n))
            : intersects(bounds(n), this.rect));           // 相交/包含模式
        if (mode === 'replace') this.multiSel = new Set(hits);
        else hits.forEach(h => this.multiSel.add(h));      // shift 加选
        this.onSelect?.([...this.multiSel]);
      }
      this.rect = null;
    };
    addEventListener('pointermove', move);
    addEventListener('pointerup', up, { once: true });
  }
  dragSelection(dx, dy) {                                    // 整体变换分发
    for (const n of this.multiSel) { n.x += dx; n.y += dy; invalidate(n); }
  }
  render() { /* 虚线框渲染：setLineDash([4,4]) */ }
}
function normRect(a, b) { return { x: Math.min(a.x, b.x), y: Math.min(a.y, b.y),
  w: Math.abs(a.x - b.x), h: Math.abs(a.y - b.y) }; }
function containsRect(outer, inner) { return inner.x >= outer.x && inner.y >= outer.y
  && inner.x + inner.w <= outer.x + outer.w && inner.y + inner.h <= outer.y + outer.h; }
```
