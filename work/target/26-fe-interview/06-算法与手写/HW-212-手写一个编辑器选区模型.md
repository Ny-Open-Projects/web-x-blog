## HW-212：手写一个编辑器选区模型：anchor 与 focus 的归一化与方向处理

**答**：
- 需求：实现 Selection：{anchor, focus}（各含 blockId/offset），提供 normalized()（返回 head/tail：head 为起始端）、direction（forward/backward/collapsed）、isEmpty；提供跨 block 的文本提取。
- 边界：anchor==focus 时 collapsed；方向变化不影响 anchor/focus 原值（读时归一化）；同 block 内比较 offset，跨 block 比较 blocks 索引。
- 评分点：读写分离（不改原值）；跨 block 排序正确。

```javascript
function makeSelection(anchor, focus, blocksIndex) {
  const posRank = p => blocksIndex(p.blockId) * 1e6 + p.offset;
  return {
    get direction() {
      if (anchor.blockId === focus.blockId && anchor.offset === focus.offset) return 'collapsed';
      return posRank(anchor) <= posRank(focus) ? 'forward' : 'backward';
    },
    normalized() {
      return this.direction === 'backward'
        ? { head: focus, tail: anchor } : { head: anchor, tail: focus };
    },
    isEmpty() { return this.direction === 'collapsed'; },
    extract() {                                   // 跨 block 提取文本
      const { head, tail } = this.normalized();
      const hi = blocksIndex(head.blockId), ti = blocksIndex(tail.blockId);
      if (hi === ti)
        return blocksOf(head.blockId).text.slice(head.offset, tail.offset);
      const parts = [blocksOf(head.blockId).text.slice(head.offset)];
      for (let i = hi + 1; i < ti; i++) parts.push(blocksOf(idxToBlock(i)).text);
      parts.push(blocksOf(tail.blockId).text.slice(0, tail.offset));
      return parts.join('\n');
    },
  };
}
```

## 补充：评分点与变体

**评分点**：

- anchor/focus 存原值，normalized() 读时算，写入阶段绝不交换两者，交换后 shift 点击的方向信息就丢了
- 比较规则分两级：同 block 内比 offset，跨 block 比 block 索引，混用会让跨块选区排序错
- collapsed 判定必须是 blockId 与 offset 同时相等，只比 offset 会把不同块的首位当成折叠态
- 跨 block 提取文本要按 blocks 顺序拼接并补块分隔符，直接切片会串块

**变体与延伸**：

1. 选区端点所在的 block 被删除 → 端点吸附到相邻 block 的合法 offset，不能让 blockId 悬空
2. 要按词或按行扩展选区 → 对 normalized 后的 head/tail 各自扩展，不能对 anchor/focus 分别扩展
3. 双向选区怎么渲染 → 高亮用 head/tail，光标闪烁固定画在 focus 端
