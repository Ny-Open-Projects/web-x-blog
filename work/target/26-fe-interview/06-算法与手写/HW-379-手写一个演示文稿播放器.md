## HW-379：手写一个演示文稿播放器：全屏翻页与动画步骤

**答**：
- 需求：实现 SlidesPlayer：页面列表（每页含 build steps——动画分步出现）；翻页（左右键/触摸滑动，全屏 API 进入放映）；分步动画（Enter/右键先走当前页 steps，走完再翻页）；进度指示与页码；演讲者模式（当前页+下一页+备注，BroadcastChannel 同步翻页）。
- 边界：分步状态在翻回时重置（或保留可配）；全屏失败降级普通模式；双屏同步（演讲者控翻页，观众端跟随）。
- 评分点：分步先于翻页；全屏降级；双屏同步。

```javascript
class SlidesPlayer {
  constructor(slides, { keepStepOnBack = false } = {}) {
    this.slides = slides; this.page = 0; this.step = 0;
    this.chan = new BroadcastChannel('slides');              // 双屏同步
    this.chan.onmessage = e => e.data.type === 'nav' && this.nav(e.data.page, e.data.step, true);
  }
  async present() {
    try { await document.documentElement.requestFullscreen(); }   // 全屏
    catch { console.warn('fullscreen-denied, fallback'); }   // 降级
    this.render();
  }
  nav(page, step, fromRemote = false) {
    if (!fromRemote) this.chan.postMessage({ type: 'nav', page, step });
    if (page !== this.page && !keepStepOnBack) this.step = 0;   // 翻页重置分步
    this.page = clamp(page, 0, this.slides.length - 1);
    this.step = clamp(step, 0, this.slides[this.page].steps?.length ?? 0);
    this.render();
  }
  next() {
    const steps = this.slides[this.page].steps?.length ?? 0;
    if (this.step < steps) return this.nav(this.page, this.step + 1);   // 先走分步
    this.nav(this.page + 1, 0);                              // 走完翻页
  }
  prev() {
    if (this.step > 0) return this.nav(this.page, this.step - 1);
    const prevSteps = this.slides[this.page - 1]?.steps?.length ?? 0;
    this.nav(this.page - 1, keepStepOnBack ? prevSteps : 0);
  }
  onKey(e) {
    if (e.key === 'ArrowRight' || e.key === 'Enter' || e.key === ' ') { e.preventDefault(); this.next(); }
    if (e.key === 'ArrowLeft') this.prev();
    if (e.key === 'f') this.present();
  }
  render() { /* 当前页 + 已出现 steps 渲染 + 页码 */ }
}
const clamp = (v, lo, hi) => Math.max(lo, Math.min(hi, v));
```
