## ALG-285：图表数据桶化：万点折线按像素宽度分桶（min/max 保留降采样，形状保真）？
**答**：1 万点折线画在 800px 宽画布——每像素 12.5 点，全画浪费且抖动。按像素分桶：每桶保留 min/max（形状保真——峰值不被降采样抹掉），桶均值作连接点。LTTB 是同目标的高级算法（PER-466），min/max 分桶实现最简单且保峰。

**思路**：bucketSize = n/width → 每桶取 min/max 两点（按原始顺序）→ 输出 2×width 点。

```javascript
function minMaxDownsample(data, width = 800) {
  if (data.length <= width * 2) return data;              // 点少不降采样
  const bucketSize = data.length / width;
  const out = [];
  for (let b = 0; b < width; b++) {
    const start = Math.floor(b * bucketSize);
    const end = Math.min(data.length, Math.floor((b + 1) * bucketSize));
    let min = data[start], max = data[start];
    for (let i = start + 1; i < end; i++) {
      if (data[i].y < min.y) min = data[i];
      if (data[i].y > max.y) max = data[i];
    }
    // 按原始顺序输出（min/max 谁先出现谁在前）—— 保持时间语义
    if (min.x <= max.x) out.push(min, max); else out.push(max, min);
  }
  return out;
}
// 1 万点 → 1600 点（800 桶 × min/max）：渲染量 -84%，峰值保留（均值降采样会抹掉尖峰——监控告警场景致命）
// 对比均匀抽点（每 12 个取 1）：尖峰被抽掉的概率 92%——监控图"看起来平稳"但实际有尖刺，误判
// LTTB 更优（视觉相似度更高）但实现复杂；min/max 分桶是监控场景的性价比之王
```

**评分点**：
- min/max 分桶保峰——本题核心（均值/抽点抹尖峰的监控误判风险）。
- 原始顺序输出（min/max 时序语义）。
- 与 LTTB 的取舍（保峰 vs 视觉相似度）。
- 降采样量量化（-84%）。
