## ALG-223：权限树级联勾选的 O(n) 优化：一次 DFS 计算半选/全选状态（避免每次勾选全树重算）
**答**：权限树（1 万节点）勾选：勾父全选子、子决定父半选。朴素实现每次勾选遍历全树 O(n)，勾选频繁时卡顿。优化：**局部更新**——勾选影响只沿"该节点子树 + 祖先链"传播，其余节点状态不变。

**思路**：子树全量重算（勾选节点为根的子树，通常远小于全树）+ 祖先链冒泡重算（半选判定）。最坏 O(n)，典型远小于全树。

```javascript
function cascadeCheck(tree, checked, targetId, nextValue) {
  // checked: Set(已勾选 id)；返回新 checked 与半选 Set
  const byId = new Map();
  (function index(n, parent) {
    byId.set(n.id, { node: n, parent: parent?.id ?? null });
    n.children?.forEach((c) => index(c, n));
  })(tree);
  const entry = byId.get(targetId);

  // 1. 子树方向：整棵子树设为 nextValue
  const sub = [];
  (function collect(n) { sub.push(n.id); n.children?.forEach(collect); })(entry.node);
  for (const id of sub) nextValue ? checked.add(id) : checked.delete(id);

  // 2. 祖先方向：冒泡重算父节点全选/半选
  const half = new Set();
  let cur = entry.parent;
  while (cur) {
    const node = byId.get(cur).node;
    const children = node.children ?? [];
    const all = children.every((c) => checked.has(c.id));
    const any = children.some((c) => checked.has(c.id) || half.has(c.id));
    if (all) checked.add(cur);
    else { checked.delete(cur); if (any) half.add(cur); }
    cur = byId.get(cur).parent;
  }
  return { checked, half };
}
// 复杂度：子树 S + 祖先链 D；典型远小于全树 n —— 1 万节点树勾一个叶子只碰几十个节点
// 对比朴素：每次勾选全树 DFS O(n) —— 大树勾选卡顿的根因
```

**评分点**：
- 局部更新思想（子树 + 祖先链），复杂度远优于全树重算——本题核心。
- 半选传播正确：父节点半选状态会继续向上影响（any 含 half 检查）。
- Map 索引 byId 构建（O(n) 一次，勾选 O(S+D)）。
- 全选/半选边界：叶子无子节点直接 checked。
