## ALG-494：手写根据身高重建队列：座位排布

**答**：
- 题目：每人 (身高 h, 前面更高或等高的人数 k)，重建队列。经典贪心：按 h 降序、k 升序排序，逐个插入到索引 k 处。
- 思路：降序排序后，先放高的——矮的插入不影响已放高的 k 值；splice 到 k 位。
- 评分点：降序放置保证插入不影响前值；插入位置语义；复杂度 O(n²)（可 BIT 优化插入位置查找）。

```javascript
function reconstructQueue(people) {
  const sorted = [...people].sort((a, b) =>
    b.h - a.h || a.k - b.k);                               // h 降序，k 升序
  const out = [];
  for (const p of sorted) out.splice(p.k, 0, p);           // 插到第 k 位
  return out;
}
// 例：[[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]
// 排序后 [7,0],[7,1],[6,1],[5,0],[5,2],[4,4] 依次插入 → 正确队列
// BIT 优化：从高到低插入，用 BIT 查「第 k+1 个空位」O(n log n)
```
