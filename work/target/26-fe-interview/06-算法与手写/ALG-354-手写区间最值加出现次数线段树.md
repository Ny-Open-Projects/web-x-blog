## ALG-354：手写区间最值加出现次数线段树：峰值监控计数

**答**：
- 题目：监控要查区间峰值 QPS 以及峰值出现的秒数个数（峰值并列时输出次数，判断抖动程度）。节点维护 (max, count) 二元组。
- 思路：节点存 {max, cnt}，合并规则：左右 max 相等 → cnt 相加；不等 → 取大者的 cnt。单点更新时 cnt=1。
- 评分点：二元组合并规则完整；相等才累加 cnt 的细节；能推广到 top-k 思路。

```javascript
class MaxCountTree {
  constructor(n) { this.n = n; this.t = new Array(4 * n); }
  merge(a, b) {                                            // (max, cnt) 合并
    if (!a) return b; if (!b) return a;
    if (a.max === b.max) return { max: a.max, cnt: a.cnt + b.cnt };   // 相等累加
    return a.max > b.max ? a : b;
  }
  set(i, v, node = 1, l = 0, r = this.n - 1) {
    if (l === r) return this.t[node] = { max: v, cnt: 1 };
    const m = (l + r) >> 1;
    i <= m ? this.set(i, v, node * 2, l, m) : this.set(i, v, node * 2 + 1, m + 1, r);
    this.t[node] = this.merge(this.t[node * 2], this.t[node * 2 + 1]);
  }
  query(ql, qr, node = 1, l = 0, r = this.n - 1) {
    if (qr < l || r < ql) return null;
    if (ql <= l && r <= qr) return this.t[node];
    const m = (l + r) >> 1;
    return this.merge(this.query(ql, qr, node * 2, l, m),
      this.query(ql, qr, node * 2 + 1, m + 1, r));
  }
}
// 输出：query(lo, hi).cnt —— 峰值并列秒数，判断监控抖动
```
