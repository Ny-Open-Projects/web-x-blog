## HW-241：手写一个操作模型：编辑操作的序列化与重放

**答**：
- 需求：实现 Operation：{type: insert|delete, pos, text?, blockId?}；serialize()（紧凑 JSON）与 deserialize；apply(doc) 幂等执行；inverse() 生成逆操作（insert 的逆为删除同区间）；提供 opsApply(doc, ops) 按序重放生成目标文档。
- 边界：pos 按全局文本偏移（跨 block 线性化）；空字符串 insert 视为 no-op；逆操作序列与原操作互逆（round-trip 断言）。
- 评分点：线性化位置；inverse 正确性；重放一致性。

```javascript
class Operation {
  constructor(type, pos, text = '') { this.type = type; this.pos = pos; this.text = text; }
  apply(doc) {
    if (this.type === 'insert') doc.spliceText(this.pos, 0, this.text);
    else doc.spliceText(this.pos, this.text.length, '');
  }
  inverse() {
    return this.type === 'insert'
      ? new Operation('delete', this.pos, this.text)
      : null;                                              // delete 的逆需原文，由日志提供
  }
  serialize() { return { t: this.type === 'insert' ? 1 : 0, p: this.pos, s: this.text }; }
  static from(o) { return new Operation(o.t ? 'insert' : 'delete', o.p, o.s); }
}
function inverseOf(op, docBefore) {                        // delete 逆操作从日志取原文
  if (op.type === 'insert') return new Operation('delete', op.pos, op.text);
  const removed = docBefore.slice(op.pos, op.pos + op.text.length);
  return new Operation('insert', op.pos, removed);
}
function opsApply(doc, ops) { ops.forEach(o => o.apply(doc)); return doc; }
```
