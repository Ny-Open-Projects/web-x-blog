## ALG-379：手写线段树节点池化：高频创建销毁的内存控制

**答**：
- 题目：动态开点线段树频繁创建销毁（如每次请求建一棵用完即弃），GC 压力大——用节点池：销毁时节点归还池，创建时复用。
- 思路：池 = 数组栈；alloc() 从池弹或新建；free(node) 递归归还子节点（注意共享引用的树不能 free——池化树必须独占所有权）。
- 评分点：池化与所有权（独占才可回收）；递归归还；GC 压力优化场景。

```javascript
class PooledSegTree {
  constructor() { this.pool = []; }                        // 节点池
  alloc() { return this.pool.pop() ?? { sum: 0, l: null, r: null }; }
  update(node, pos, v, l = 0, r = 1e6) {
    node ??= this.alloc();                                 // 创建走池
    if (l === r) { node.sum += v; return node; }
    const m = (l + r) >> 1;
    if (pos <= m) node.l = this.update(node.l, pos, v, l, m);
    else node.r = this.update(node.r, pos, v, m + 1, r);
    node.sum = (node.l?.sum ?? 0) + (node.r?.sum ?? 0);
    return node;
  }
  destroy(node) {                                          // 独占树才可归还池
    if (!node) return;
    this.destroy(node.l); this.destroy(node.r);
    node.l = node.r = null; node.sum = 0;
    this.pool.push(node);                                  // 复用避免 GC
  }
}
```
