## ALG-516：手写贪心+栈：去除重复字母字典序最小（ID 压缩）

**答**：
- 题目：字符串去除重复字符（每字符保留一个），使结果字典序最小。单调栈 + 「后面还会出现」判断。
- 思路：遍历字符：栈顶 > 当前 且 栈顶后面还会出现 → 弹栈（该字符可稍后再放）；入栈时记录已用。与 ALG-491（删 k 个）同构但加「出现次数」约束。
- 评分点：remainCount 判断弹栈合法性；单调栈；inStack 防重复。

```javascript
function removeDuplicateLetters(s) {                       // 字典序最小的去重
  const remain = new Map();                                // 剩余出现次数
  for (const c of s) remain.set(c, (remain.get(c) ?? 0) + 1);
  const stack = [], inStack = new Set();
  for (const c of s) {
    remain.set(c, remain.get(c) - 1);                      // 消耗一个
    if (inStack.has(c)) continue;                          // 已在栈：跳过
    while (stack.length && stack.at(-1) > c                // 栈顶更大
      && remain.get(stack.at(-1)) > 0) {                   // 且后面还会出现
      inStack.delete(stack.pop());
    }
    stack.push(c); inStack.add(c);
  }
  return stack.join('');
}
// 例：bcabc → abc；cbacdcbc → acdb
// 弹栈合法性：被弹字符之后还会出现 → 以后再放不亏
```
