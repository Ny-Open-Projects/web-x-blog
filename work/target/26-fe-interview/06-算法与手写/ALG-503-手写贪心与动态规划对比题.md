## ALG-503：手写贪心与动态规划对比题：同一问题两解法

**答**：
- 题目：经典「打家劫舍」——相邻不能都选，求最大和。对比：贪心不可行（局部最优不保证全局），DP 可行。给出贪心反例与 DP 实现。
- 思路：贪心反例：[2,1,1,2]——贪心选 2 跳过 1 得 2+2=4？实际选 [2,2] 可行=4，构造 [3,2,2,3]：贪心选头尾 3+3=6 但 1,4 位冲突？给出反例并证 DP。
- 评分点：贪心失效原因（无最优子结构的局部性）；DP 转移 dp[i] = max(dp[i-1], dp[i-2]+v)；何时贪心仍可行。

```javascript
function houseRobberDP(nums) {                             // DP 解
  let prev = 0, cur = 0;
  for (const v of nums) {
    [prev, cur] = [cur, Math.max(cur, prev + v)];          // 选或不选
  }
  return cur;
}
function houseRobberGreedy(nums) {                         // 贪心（错误演示）
  let total = 0;
  for (let i = 0; i < nums.length; i++)
    if (nums[i] >= (nums[i - 1] ?? 0) && nums[i] >= (nums[i + 1] ?? 0))
      { total += nums[i]; i++; }                           // 取局部峰
  return total;
}
// 反例：[2,7,9,3,1] 贪心取 7+3=10（或 9+1）vs DP 最优 2+9+1=12
// 贪心可行的条件：问题有「贪心选择性质 + 最优子结构的局部形式」——打家劫舍没有
```
