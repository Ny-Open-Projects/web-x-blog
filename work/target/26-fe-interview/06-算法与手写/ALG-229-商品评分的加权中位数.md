## ALG-229：商品评分：按评价时间加权的"近期口碑分"（加权分位数与衰减因子）
**答**：商品有 1 万条评分（1~5 星），早期刷的分要衰减——"近期口碑分"：按时间衰减权重（指数衰减）加权平均，且要抗极端值（加权中位数备选）。

**思路**：weight = decay^(daysAgo / halfLife)，加权平均；抗刷用加权中位数（权排序 + 权累计过半处取值）。

```javascript
function recentScore(reviews, { halfLifeDays = 30, robust = false } = {}) {
  const now = Date.now();
  const weighted = reviews.map((r) => ({
    score: r.score,
    w: Math.pow(0.5, (now - r.ts) / (halfLifeDays * 86400e3)),   // 指数衰减：半衰期 30 天
  }));
  if (!robust) {                                    // 加权平均
    const sw = weighted.reduce((s, x) => s + x.w, 0);
    return +(weighted.reduce((s, x) => s + x.score * x.w, 0) / sw).toFixed(2);
  }
  weighted.sort((a, b) => a.score - b.score);       // 加权中位数（抗刷分）
  const total = weighted.reduce((s, x) => s + x.w, 0);
  let acc = 0;
  for (const x of weighted) { acc += x.w; if (acc >= total / 2) return x.score; }
}
// 30 天前的 5 星权重 = 0.5；60 天前 = 0.25 —— 刷的老分自然衰减
// robust=true 时取加权中位数：少量 5 星刷分被中位数吸收（比平均更抗操纵）
// 展示补充：评价数过少（< 5 条有效加权）显示"暂无口碑"而非裸分数
```

**评分点**：
- 指数衰减权重公式（半衰期参数化）正确。
- 加权平均与加权中位数两种口径，且能说清中位数抗操纵的价值。
- 时间衰减让"刷旧分"失效的机理说清。
- 小样本保护（评价数过少不显示）。
