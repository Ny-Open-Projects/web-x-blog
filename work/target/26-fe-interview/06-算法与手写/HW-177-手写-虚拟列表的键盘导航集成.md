## HW-177：手写虚拟列表键盘导航——↑↓ 移动聚焦行 + 窗口跟随滚动 + Home/End 跳边界（roving tabindex）
**答**：虚拟列表 + 键盘导航（HW-128 与 HW-068 结合）：↑↓ 移动 focusedIndex → 若超出渲染窗口，滚动使目标行进入视口（含 overscan 缓冲计算）→ 渲染后聚焦该行（rAF 等待挂载）；Home/End 跳到首尾行（滚动 + 聚焦同步）；aria-activedescendant 指向聚焦行（读屏可用）。

```javascript
function keyboardNav(vl, { onActivate } = {}) {
  let focused = 0;
  container.addEventListener('keydown', (e) => {
    const step = { ArrowDown: 1, ArrowUp: -1 }[e.key];
    if (step != null) { e.preventDefault(); move(focused + step); }
    if (e.key === 'Home') { e.preventDefault(); move(0); }
    if (e.key === 'End') { e.preventDefault(); move(vl.count - 1); }
    if (e.key === 'Enter') onActivate?.(focused);
  });
  function move(idx) {
    idx = Math.max(0, Math.min(vl.count - 1, idx));
    focused = idx;
    const { scrollTop, clientHeight, itemHeight } = vl;
    const visTop = Math.floor(scrollTop / itemHeight);
    const visBottom = visTop + Math.floor(clientHeight / itemHeight) - 1;
    if (idx < visTop) container.scrollTop = idx * itemHeight;              // 上方：滚到顶部对齐
    else if (idx > visBottom) container.scrollTop = (idx + 1) * itemHeight - clientHeight;  // 下方：滚到底对齐
    requestAnimationFrame(() => {                          // 渲染窗口更新后再聚焦（行可能刚挂载）
      const el = container.querySelector(`[data-index="${idx}"]`);
      if (el) { el.focus(); el.setAttribute('aria-selected', 'true'); }
    });
    announce(`第 ${idx + 1} 行，${vl.rows[idx].name}`);    // 读屏公告（aria-live 区域）
  }
}
// 虚拟列表键盘导航的坑：聚焦时行可能尚未渲染（窗口外）——必须"滚动触发重渲染 → rAF 后聚焦"
// aria-activedescendant vs roving tabindex：虚拟列表行频繁重建，activedescendant（引用 id 不依赖 DOM 生命周期）更稳
```

**评分点**：
- 虚拟列表下"滚动触发渲染 → rAF 后聚焦"的时序——本题核心（行未渲染直接 focus 失败）。
- 窗口越界时滚动对齐方向（上对齐顶/下对齐底）。
- aria-activedescendant vs roving tabindex 在虚拟列表场景的取舍（行重建友好）。
- 读屏公告（aria-live）。
