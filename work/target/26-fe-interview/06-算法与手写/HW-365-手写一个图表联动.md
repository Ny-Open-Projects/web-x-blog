## HW-365：手写一个图表联动：共享轴与刷选同步

**答**：
- 需求：实现 ChartSync：多图共享 x 轴（一图缩放/平移，其他图同步 viewport）；刷选（brush）联动——一图框选范围，其他图高亮对应区间并输出过滤数据；双向同步防环（标记来源，同源更新不回传）。
- 边界：防环（updating 标志）；刷选范围钳制在数据域；高亮非过滤（overlay 模式 vs filter 模式可配）。
- 评分点：viewport 广播；防环标志；overlay/filter 模式。

```javascript
class ChartSync {
  constructor(charts, { mode = 'overlay' } = {}) {
    this.charts = charts; this.mode = mode; this.updatingFrom = null;
    charts.forEach(c => {
      c.onViewportChange = vp => this.broadcast(c.id, { viewport: vp });
      c.onBrush = range => this.broadcast(c.id, { brush: range });
    });
  }
  broadcast(sourceId, patch) {
    if (this.updatingFrom === sourceId) return;              // 防环：同源不回传
    this.updatingFrom = sourceId;
    for (const c of this.charts) {
      if (c.id === sourceId) continue;
      if (patch.viewport) c.setViewport(patch.viewport);     // 共享轴
      if (patch.brush) {
        const clamped = clampRange(patch.brush, c.dataDomain());
        if (this.mode === 'overlay') c.highlight(clamped);   // 高亮模式
        else c.filter(clamped);                              // 过滤模式
      }
    }
    this.updatingFrom = null;
  }
}
function clampRange(range, domain) { return [Math.max(range[0], domain[0]),
  Math.min(range[1], domain[1])]; }
```
