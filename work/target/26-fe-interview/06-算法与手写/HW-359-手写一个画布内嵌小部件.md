## HW-359：手写一个画布内嵌小部件：DOM 覆盖层与画布同步

**答**：
- 需求：实现 WidgetLayer：画布上叠加 DOM 元素（输入框/按钮，如节点内编辑文本）；同步：视口变换（scale/offset）→ DOM 的 transform 同步；节点移动时 DOM 跟随；命中穿透（pointer-events 精细控制——覆盖层容器穿透，部件本体可交互）。
- 边界：缩放时 DOM 字号反向缩放（保持视觉大小）或随缩放（可配）；widget 生命周期（节点删除时移除）；键盘事件不被画布拦截。
- 评分点：transform 同步；pointer-events 穿透；反向缩放选项。

```javascript
class WidgetLayer {
  constructor(container, viewport) {
    this.layer = document.createElement('div');
    this.layer.className = 'widget-layer';
    this.layer.style.cssText = 'position:absolute;inset:0;pointer-events:none;';   // 容器穿透
    container.appendChild(this.layer);
    this.vp = viewport; this.widgets = new Map();
  }
  attach(nodeId, el, { fixedSize = true } = {}) {
    el.style.pointerEvents = 'auto';                         // 部件本体可交互
    el.addEventListener('keydown', e => e.stopPropagation());   // 键盘不被画布拦截
    this.widgets.set(nodeId, { el, fixedSize });
    this.layer.appendChild(el);
    return () => { el.remove(); this.widgets.delete(nodeId); };   // 生命周期
  }
  sync(node) {                                               // 视口+节点同步
    const w = this.widgets.get(node.id);
    if (!w) return;
    const s = this.vp.worldToScreen(node.x, node.y);
    const k = w.fixedSize ? 1 / this.vp.scale : 1;           // 反向缩放保持视觉大小
    w.el.style.transform = `translate(${s.x}px, ${s.y}px) scale(${k})`;
    w.el.style.transformOrigin = '0 0';
  }
  syncAll(nodes) { nodes.forEach(n => this.sync(n)); }
}
```
