## HW-121：手写可见性驱动轮询——前台轮询/后台暂停/恢复立即执行一次/退避递增
**答**：生产级轮询：仅前台运行（visibilitychange 暂停/恢复）、恢复时立即执行一次（用户切回来马上看到新数据）、连续失败指数退避（上限封顶）、成功后恢复正常间隔、destroy 清理。

```javascript
class VisibilityPoller {
  constructor(fn, { interval = 5000, backoff = 2, maxInterval = 60000 } = {}) {
    Object.assign(this, { fn, interval, backoff, maxInterval });
    this.current = interval; this.failures = 0;
    this.timer = null; this.destroyed = false;
    document.addEventListener('visibilitychange', this.onVis);
    this.onVis();
  }
  onVis = () => {
    if (this.destroyed) return;
    document.visibilityState === 'visible' ? this.start() : this.stop();
  };
  start() {
    this.stop();
    const tick = async () => {
      try {
        await this.fn();
        this.failures = 0; this.current = this.interval;         // 成功恢复正常间隔
      } catch {
        this.failures++;
        this.current = Math.min(this.current * this.backoff, this.maxInterval);  // 退避
      }
      if (!this.destroyed && document.visibilityState === 'visible') {
        this.timer = setTimeout(tick, this.current);
      }
    };
    tick();                                                       // 恢复/启动立即执行一次
  }
  stop() { clearTimeout(this.timer); this.timer = null; }
  destroy() { this.destroyed = true; this.stop(); document.removeEventListener('visibilitychange', this.onVis); }
}
// 语义：后台暂停省电；切回前台立即拉一次（用户感知"回来就是新的"）；
// 连续失败退避（5s→10s→20s...封顶 60s）防打死服务端
```

**评分点**：
- 可见性驱动：hidden 停、visible 恢复且立即执行一次（语义正确）。
- 失败退避 + 成功恢复 + 上限封顶。
- destroy 完整清理（定时器 + 事件监听）。
- 递归 setTimeout 而非 setInterval（上次未完成不叠加）。
