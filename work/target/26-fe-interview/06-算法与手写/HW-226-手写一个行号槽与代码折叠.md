## HW-226：手写一个行号槽与代码折叠：折叠区域计算与行号重映射

**答**：
- 需求：实现 CodeFolding：基于缩进或标记计算可折叠区间 [{start, end}]；fold(idx)/unfold(idx) 维护 folded 集合；renderLines() 输出可见行列表（被折叠的区间显示为单行折叠头）；行号重映射（显示行号 ↔ 真实行号双向转换）。
- 边界：嵌套折叠（区间包含校验，折叠外层时内层操作无效）；折叠区间包含光标时展开。
- 评分点：双向行号映射；嵌套包含校验。

```javascript
class CodeFolding {
  constructor(ranges) { this.ranges = ranges; this.folded = new Set(); }
  canFold(idx) { return this.ranges.some(r => r.start === idx); }
  fold(idx) {
    const r = this.ranges.find(r => r.start === idx);
    if (r && ![...this.folded].some(f => contains(this.ranges.find(x => x.start === f), r)))
      this.folded.add(idx);                                    // 外层包含内层校验
  }
  unfold(idx) { this.folded.delete(idx); }
  visibleLines(total) {                                        // 折叠头占一行
    const out = [];
    for (let i = 0; i < total; i++) {
      const f = [...this.folded].map(x => this.ranges.find(r => r.start === x))
        .find(r => i > r.start && i <= r.end);
      if (!f) out.push({ line: i });
      else if (i === f.start + 1) out.push({ line: i, folded: f });   // 折叠头
    }
    return out;
  }
  toReal(visibleIdx) {                                         // 显示行号 → 真实行号
    const vis = this.visibleLines(this.total ?? 1000);
    return vis[visibleIdx]?.line ?? null;
  }
  toVisible(realIdx) { return this.visibleLines(this.total ?? 1000).findIndex(v => v.line === realIdx); }
}
const contains = (a, b) => a && b && a.start <= b.start && b.end <= a.end;
```
