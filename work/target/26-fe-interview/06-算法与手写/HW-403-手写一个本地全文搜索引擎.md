## HW-403：手写一个本地全文搜索引擎：倒排索引构建与查询

**答**：
- 需求：实现 LocalSearch：索引构建（文档分词 → 倒排表 Map<term, Set<docId>>，中文按字+英文按词）；查询（多词 AND 交集 + 词频排序打分）；增量更新（文档增删改同步索引）；前缀补全（Trie 或前缀扫描）。
- 边界：分词器（中文字粒度 + 2-gram 提升召回）；打分（TF 简化版）；索引内存约束（文档多时分片）；空查询返回最近文档。
- 评分点：倒排结构；中文 2-gram；增量同步。

```javascript
class LocalSearch {
  constructor() { this.index = new Map(); this.docs = new Map(); this.docTerms = new Map(); }
  tokenize(text) {                                           // 中文字 + 2-gram / 英文词
    const out = [];
    const en = text.match(/[a-zA-Z]+/g) ?? [];
    out.push(...en.map(w => w.toLowerCase()));
    const zh = text.replace(/[^\u4e00-\u9fff]/g, '');
    for (let i = 0; i < zh.length; i++) {
      out.push(zh[i]);                                       // 单字
      if (i + 1 < zh.length) out.push(zh.slice(i, i + 2));   // 2-gram
    }
    return out;
  }
  addDoc(id, text) {
    this.removeDoc(id);                                      // 幂等：先删旧
    this.docs.set(id, text);
    const terms = this.tokenize(text);
    this.docTerms.set(id, new Set(terms));
    const tf = new Map();
    for (const t of terms) tf.set(t, (tf.get(t) ?? 0) + 1);
    for (const [t, n] of tf) {                               // 倒排表
      const posting = this.index.get(t) ?? this.index.set(t, new Map()).get(t);
      posting.set(id, n);                                    // docId -> 词频
    }
  }
  removeDoc(id) {
    for (const t of this.docTerms.get(id) ?? []) this.index.get(t)?.delete(id);
    this.docs.delete(id); this.docTerms.delete(id);
  }
  search(query, { limit = 20 } = {}) {                       // AND 交集 + TF 打分
    const terms = this.tokenize(query);
    if (!terms.length) return [...this.docs.keys()].slice(0, limit).map(id => ({ id }));
    const lists = terms.map(t => this.index.get(t) ?? new Map());
    const candidates = lists.reduce((acc, cur) => {          // 交集
      const out = new Map();
      for (const [id, tf] of acc) if (cur.has(id)) out.set(id, tf + cur.get(id));
      return out;
    });
    return [...candidates]
      .map(([id, score]) => ({ id, score, snippet: makeSnippet(this.docs.get(id), terms[0]) }))
      .sort((a, b) => b.score - a.score).slice(0, limit);
  }
  suggest(prefix) {                                          // 前缀补全
    const out = [];
    for (const term of this.index.keys())
      if (term.startsWith(prefix.toLowerCase())) out.push(term);
    return out.slice(0, 10);
  }
}
function makeSnippet(text, term) {
  const i = text.indexOf(term[0]);
  return i < 0 ? text.slice(0, 50) : '…' + text.slice(Math.max(0, i - 10), i + 40) + '…';
}
```
