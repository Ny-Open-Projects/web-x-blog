## ALG-287：接口失败自适应限流：连续失败的并发收缩（AIMD——成功加并发，失败减半）？
**答**：服务端过载时客户端仍全速并发 = 雪上加霜。AIMD 自适应：成功 → 并发 +1（缓慢恢复），超时/5xx → 并发减半（快速退让）——TCP 拥塞控制思想应用到前端请求调度。

**思路**：并发上限 c（初始 6）→ 每请求成功 c = min(max, c+1)；失败 c = max(1, c>>1) → 请求调度按当前 c 出队。

```javascript
class AdaptivePool {
  #c = 6; #max = 6; #q = []; #active = 0;
  constructor(privateMax = 6) { this.#max = privateMax; }
  submit(task) {
    return new Promise((resolve, reject) => {
      this.#q.push({ task, resolve, reject });
      this.#drain();
    });
  }
  #drain() {
    while (this.#active < this.#c && this.#q.length) {
      const job = this.#q.shift();
      this.#active++;
      job.task().then((v) => {
        this.#c = Math.min(this.#max, this.#c + 1);       // 成功：慢增（AIMD 的 AI）
        job.resolve(v);
      }).catch((e) => {
        this.#c = Math.max(1, this.#c >> 1);              // 失败：乘性减（MD）—— 快速退让
        report?.({ type: 'adaptive-backoff', concurrency: this.#c });
        job.reject(e);
      }).finally(() => { this.#active--; this.#drain(); });
    }
  }
  get concurrency() { return this.#c; }
}
// 行为：服务端过载 → 连续失败 c: 6→3→2→1（秒级收缩）；恢复 → 1→2→3（每成功 +1，慢恢复防震荡）
// 与固定限流（HW-064 令牌桶）的差异：AIMD 感知服务端状态自动调节——"限多少"由对端反馈决定
// 阈值配合：5xx/超时才算失败（4xx 业务错误不减并发——不是服务端过载）
```

**评分点**：
- AIMD（成功慢增/失败乘减）自适应并发——本题核心。
- 失败分类（5xx/超时减，4xx 不减）。
- 恢复的慢增防震荡。
- 与固定限流器的差异（对端反馈驱动）。
