## HW-293：手写一个热力图日历：格子布局与色阶映射

**答**：
- 需求：实现 HeatmapCalendar（GitHub 风格）：按周列布局（53 列 × 7 行），颜色按活跃度分 5 档（色阶映射：0 和四分位分档）；tooltip 数据（日期+次数）；月份标签按月首格定位；图例（色阶说明）。
- 边界：日期范围（最近一年）与周对齐（按 weekStart 补齐空格）；档位阈值自适应（数据分位数而非固定值）；无数据日期与未来日期区分（灰 vs 空白）。
- 评分点：分位数分档；周列对齐；tooltip 数据结构。

```javascript
function heatmapCalendar(dailyCounts, { weeks = 53 } = {}) {
  const today = new Date();
  const end = endOfWeek(today);
  const start = addDays(end, -weeks * 7 + 1);
  const values = Object.values(dailyCounts).filter(v => v > 0);
  const q = p => { const s = [...values].sort((a, b) => a - b);
    return s[Math.floor(s.length * p)] ?? 0; };              // 分位数分档
  const thresholds = [q(0.25), q(0.5), q(0.75), q(1)];
  const level = v => v === 0 ? 0 : 1 + thresholds.findIndex(t => v <= t);
  const grid = [];
  for (let w = 0; w < weeks; w++) {
    const col = [];
    for (let d = 0; d < 7; d++) {
      const date = addDays(start, w * 7 + d);
      const key = dateKey(date);
      const future = date > today;
      col.push({ date, key, future,
        count: dailyCounts[key] ?? 0,
        level: future ? null : level(dailyCounts[key] ?? 0),   // 未来日期空白
        monthLabel: date.getDate() === 1 ? date.toLocaleString('zh', { month: 'short' }) : null });
    }
    grid.push(col);
  }
  return { grid, legend: [0, 1, 2, 3, 4].map(l => ({ level: l,
    sample: l === 0 ? 0 : thresholds[l - 1] })) };           // 图例
}
const dateKey = d => d.toISOString().slice(0, 10);
const addDays = (d, n) => new Date(d.getTime() + n * 86400000);
const endOfWeek = d => { const x = new Date(d); x.setDate(x.getDate() + (7 - x.getDay()) % 7); return x; };
```
