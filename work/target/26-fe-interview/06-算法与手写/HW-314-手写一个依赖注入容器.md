## HW-314：手写一个依赖注入容器：注册、解析与单例作用域

**答**：
- 需求：实现 DIContainer：register(name, factory, {scope: singleton|transient, deps})；resolve(name) 自动解析依赖（按 deps 声明递归）；循环依赖检测（解析栈发现重复报错）；容器父子层级（子容器找不到时向上查，单例各自独立）。
- 边界：singleton 惰性创建（首次 resolve 实例化并缓存）；循环依赖在实例化前检测；transient 每次 resolve 新实例。
- 评分点：递归解析；循环检测（解析栈）；父子查找。

```javascript
class DIContainer {
  constructor(parent = null) { this.regs = new Map(); this.singletons = new Map(); this.parent = parent; }
  register(name, factory, { scope = 'transient', deps = [] } = {}) {
    this.regs.set(name, { factory, scope, deps });
  }
  resolve(name, stack = new Set()) {
    if (stack.has(name)) throw new Error('circular-dep: ' + [...stack, name].join('->'));   // 循环检测
    const reg = this.regs.get(name) ?? this.parent?.regs.get(name);
    if (!reg) throw new Error('not-registered: ' + name);
    if (reg.scope === 'singleton') {
      if (this.singletons.has(name)) return this.singletons.get(name);   // 单例缓存
      stack.add(name);
      const inst = reg.factory(...reg.deps.map(d => this.resolve(d, stack)));
      stack.delete(name);
      this.singletons.set(name, inst);
      return inst;
    }
    stack.add(name);                                         // transient：每次新实例
    const inst = reg.factory(...reg.deps.map(d => this.resolve(d, stack)));
    stack.delete(name);
    return inst;
  }
  createChild() { return new DIContainer(this); }            // 子容器向上查找
}
// 用法：register('db', () => new DB(), {scope:'singleton'});
//      register('svc', (db) => new Service(db), {deps:['db']});
```

## 补充：评分点与变体

**评分点**：

- 循环依赖在实例化之前用解析栈判断，等 new 出来再检查已经栈溢出，错误信息也拿不到环路径
- singleton 惰性创建且只缓存完成态实例，把「构造中」的占位当单例返回会让依赖拿到半初始化对象
- 子容器找不到时向上查注册项，但 singleton 实例在各自容器独立，不能复用父容器的实例
- transient 每次 resolve 新实例，同时不能被解析栈误判成循环而报错

**变体与延伸**：

1. 构造函数参数顺序与 deps 声明不一致 → 按 deps 名字顺序注入并断言个数，或统一改成具名参数对象
2. 测试要注入 mock 实现 → 子容器 override 同名注册并优先于父级，用例结束销毁子容器即可还原
3. 工厂是异步的（需 await 初始化）→ resolve 返回 Promise 并缓存这个 Promise 本身，并发 resolve 才不会重复初始化
