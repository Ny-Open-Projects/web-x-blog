## HW-326：手写一个手势引擎：统一 pointer 事件与手势识别管线

**答**：
- 需求：实现 GestureEngine：监听 pointer 统一事件（pointerdown/move/up 跨鼠标触摸）；识别管线：tap / longpress / pan（位移超阈值持续回调）/ pinch（双指距离比）；手势互斥（一次触摸序列只产一种手势）；每手势可注册回调。
- 边界：pan 用 rAF 合帧回调；pinch 锚点为两指中点；longpress 计时器在位移超标或第二指按下时取消。
- 评分点：统一 pointer；互斥管线；rAF 合帧。

```javascript
class GestureEngine {
  constructor(el) {
    this.el = el; this.h = new Map();
    el.addEventListener('pointerdown', e => this.down(e));
    el.addEventListener('pointermove', e => this.move(e));
    el.addEventListener('pointerup', e => this.up(e));
    el.addEventListener('pointercancel', () => this.reset());
  }
  on(g, fn) { this.h.set(g, fn); }
  down(e) {
    this.pts = new Map([[e.pointerId, { x: e.clientX, y: e.clientY }]]);
    this.t0 = Date.now(); this.fired = null;
    this.lpTimer = setTimeout(() => {                        // longpress 候选
      if (!this.fired && this.pts.size === 1) { this.fired = 'longpress'; this.h.get('longpress')?.(e); }
    }, 500);
  }
  move(e) {
    if (!this.pts?.has(e.pointerId)) return;
    this.pts.set(e.pointerId, { x: e.clientX, y: e.clientY });
    const [p0] = this.pts.values();
    if (this.pts.size === 2) {                               // pinch
      clearTimeout(this.lpTimer);
      const [a, b] = [...this.pts.values()];
      const dist = Math.hypot(a.x - b.x, a.y - b.y);
      if (!this.d0) this.d0 = dist;
      this.fired ??= 'pinch';
      if (this.fired === 'pinch')
        this.h.get('pinch')?.({ scale: dist / this.d0, cx: (a.x + b.x) / 2, cy: (a.y + b.y) / 2 });
      return;
    }
    const dx = e.clientX - p0.x, dy = e.clientY - p0.y;
    if (!this.fired && Math.hypot(dx, dy) > 10) {            // pan 触发：取消 longpress
      clearTimeout(this.lpTimer); this.fired = 'pan';
    }
    if (this.fired === 'pan' && !this.raf)                   // rAF 合帧
      this.raf = requestAnimationFrame(() => { this.raf = null; this.h.get('pan')?.({ dx, dy }); });
  }
  up(e) {
    clearTimeout(this.lpTimer);
    const dt = Date.now() - this.t0;
    if (!this.fired && dt < 250) this.h.get('tap')?.(e);     // tap
    this.reset();
  }
  reset() { this.pts?.clear(); this.pts = null; this.fired = null; this.d0 = null; }
}
```
