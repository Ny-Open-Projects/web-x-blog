## ALG-268：慢页面排行的降维：页面 × 指标 × 流量的复合评分（归一化加权，避免单指标排行失真）？
**答**：治理排行："哪个页面最该修"——单指标排行失真（INP 高但流量 0 的后台页排第一）。复合评分：各指标相对 SLO 的超标率归一化 × 流量权重 × 业务重要性加权。

**思路**：每指标 score = max(0, p75/SLO - 1)（超标率）；复合 = Σ(w_i × score_i × log(流量))；归一化到 0~100 排行。

```javascript
function priorityScore(pages, { weights = { lcp: 0.4, inp: 0.4, cls: 0.2 } } = {}) {
  const SLO = { lcp: 2500, inp: 200, cls: 0.1 };
  const scored = pages.map((p) => {
    const excess = (v, limit) => Math.max(0, v / limit - 1);          // 超标率（0 = 达标）
    const metricScore =
      weights.lcp * excess(p.lcp, SLO.lcp) +
      weights.inp * excess(p.inp, SLO.inp) +
      weights.cls * Math.max(0, p.cls / SLO.cls - 1);
    const traffic = Math.log10(Math.max(10, p.pv));       // log 流量：万级 PV 不会压倒性主导
    return { ...p, score: +(metricScore * traffic).toFixed(2) };
  });
  const max = Math.max(...scored.map((s) => s.score), 1);
  return scored.map((s) => ({ ...s, rank100: Math.round(s.score / max * 100) }))
    .sort((a, b) => b.rank100 - a.rank100);
}
// 排行对比：
// 单指标 INP 排行：后台页（INP 800ms、PV 10）第一 —— 失真
// 复合评分：详情页（INP 260ms、PV 50 万）第一 —— 修复价值排序正确
// log 流量的意义：PV 50 万 vs 10 万 差 0.7 倍（线性会差 5 倍）—— 大页面优先但不碾压
// weights 可配置（业务线自定义：交易页 INP 权重更高）
```

**评分点**：
- 复合评分公式（超标率 × 指标权重 × log 流量）——本题核心。
- log 流量的防碾压作用（对比线性）。
- 超标率定义（p75/SLO - 1，达标为 0）。
- 单指标排行失真的反例对照。
