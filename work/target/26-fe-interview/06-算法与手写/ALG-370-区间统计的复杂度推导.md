## ALG-370：区间统计的复杂度推导：万级 QPS 看板的方案论证

**答**：
- 题目：面试白板题——每秒 1 万条 QPS 记录，看板要实时显示任意时间窗口的 QPS 峰值/总和，论证方案与复杂度。
- 思路：数据按秒落桶，窗口查询 = 区间统计。方案 A 线段树：更新 O(log N)、查询 O(log N)，N = 保存秒数（如 7 天 = 604800）；方案 B 前缀和数组：更新 O(1) 追加、查询 O(1) 前缀差——但需修正（不支持历史修改）；方案 C 滑动窗口单调队列（只查最近 W 秒峰值，单次 O(W)）。按「是否修改历史+窗口形态」选。
- 评分点：三方案复杂度对比；按需求特征选型；数据保留期与内存估算（7 天 × 604800 × 8B ≈ 5MB）。

```javascript
class QPSDashboard {
  constructor({ keepDays = 7 } = {}) {
    this.keep = keepDays * 86400;
    this.buckets = new Float64Array(this.keep);              // 秒桶
    this.tree = null;                                        // 需要时懒建
  }
  record(ts, qps) { this.buckets[ts % this.keep] = qps; }    // O(1) 追加
  // 方案 A：窗口峰值查询（需要历史修正时懒建/增量维护线段树）
  peak(lo, hi) {
    this.tree ??= buildMaxTree(this.buckets);                // 懒初始化
    return this.tree.query(lo % this.keep, hi % this.keep);
  }
  // 方案 C：最近 W 秒峰值——单调队列 单次 O(W)
  recentPeak(W) {
    const q = new MonotonicQueue(this.buckets, W);
    return q.max();
  }
}
class MonotonicQueue {                                     // 单调递减队列
  constructor(arr, W) { this.arr = arr; this.W = W; this.dq = []; this.i = arr.length - 1;
    for (let j = Math.max(0, arr.length - W); j < arr.length; j++) this.push(j); }
  push(i) { while (this.dq.length && this.arr[this.dq.at(-1)] <= this.arr[i]) this.dq.pop();
    this.dq.push(i); }
  max() { while (this.dq[0] < this.i - this.W + 1) this.dq.shift();   // 出窗
    return this.arr[this.dq[0]]; }
}
```

## 补充：评分点与变体

**评分点**：

- 前缀和 O(1) 查询有前提：只追加不改历史；一旦要修正某一秒的值就退化成 O(N) 重建，这个前提必须讲出来
- 线段树的 N 取保留秒数（7 天 604800）而非 QPS 条数，内存估算 604800×8B≈5MB 要给得出量级
- 单调队列只能答「最近 W 秒峰值」，答不了任意窗口的 sum，两种查询不能混着说
- 选型要绑定读写比：写多读少用前缀和、读写均衡用线段树、只关心最近窗口用队列

**变体与延伸**：

1. 任意窗口要同时拿 sum 与 max → 线段树节点存 `{sum, max}` 二元组，一次查询两值都取
2. 保留 30 天且要按小时聚合 → 做秒桶/分桶/时桶三层，查询先吃整段粗粒度再补两端边界
3. 万级 QPS 写入打满主线程 → 聚合下沉到服务端，前端按 1s 批量合并后只更新展示
