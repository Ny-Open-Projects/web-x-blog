## HW-322：手写一个埋点引擎：事件队列、批量上报与失败重试

**答**：
- 需求：实现 Tracker：track(event, props) 入队（环形缓冲防丢）；批量上报（满 20 条或 5s 定时 flush）；sendBeacon 优先（页面卸载可靠）；失败重试（指数退避 3 次，失败降级 localStorage 落盘待下次启动补传）；采样（可配置全量/百分比/白名单事件全量）。
- 边界：页面卸载时 flush（visibilitychange + pagehide 双保险）；补传去重（落盘事件带 id，幂等）；props 深度限制与 PII 过滤。
- 评分点：sendBeacon 双保险；落盘补传幂等；采样策略。

```javascript
class Tracker {
  constructor(endpoint, { batch = 20, flushMs = 5000, sample = 1 } = {}) {
    this.ep = endpoint; this.batch = batch; this.sample = sample;
    this.q = []; this.timer = setInterval(() => this.flush(), flushMs);
    addEventListener('pagehide', () => this.flush(true));    // 卸载双保险
    addEventListener('visibilitychange', () => document.hidden && this.flush(true));
    this.recover();                                          // 启动补传
  }
  track(event, props = {}) {
    if (Math.random() > (WHITELIST.has(event) ? 1 : this.sample)) return;   // 采样（白名单全量）
    this.q.push({ id: crypto.randomUUID(), event, props: trimProps(props), ts: Date.now() });
    if (this.q.length >= this.batch) this.flush();
  }
  async flush(useBeacon = false) {
    if (!this.q.length) return;
    const batch = this.q.splice(0, this.batch);
    const body = JSON.stringify({ events: batch });
    if (useBeacon && navigator.sendBeacon?.(this.ep, body)) return;   // Beacon 优先
    try { await retryRun(() => fetch(this.ep, { method: 'POST', body, keepalive: true }), { maxAttempts: 3 }); }
    catch {                                                  // 落盘补传（幂等 id）
      const store = JSON.parse(localStorage.getItem('evt-backlog') ?? '[]');
      localStorage.setItem('evt-backlog', JSON.stringify([...store, ...batch].slice(-200)));
    }
  }
  async recover() {                                          // 补传去重（幂等 id）
    const backlog = JSON.parse(localStorage.getItem('evt-backlog') ?? '[]');
    localStorage.removeItem('evt-backlog');
    if (backlog.length) await fetch(this.ep, { method: 'POST',
      body: JSON.stringify({ events: backlog, replay: true }) });
  }
}
const WHITELIST = new Set(['error', 'purchase']);            // 关键事件不采样
function trimProps(p) { return JSON.parse(JSON.stringify(p, (k, v) =>
  typeof v === 'string' && v.length > 200 ? v.slice(0, 200) : v)); }
```
