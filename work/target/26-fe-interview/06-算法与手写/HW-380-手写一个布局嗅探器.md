## HW-380：手写一个布局嗅探器：从设计稿 DOM 推断布局参数

**答**：
- 需求：实现 LayoutSniffer：输入设计稿根 DOM，推断布局参数——栅格（统计元素宽度聚类出列宽与间距）、间距体系（margin/padding 值频次 → 间距 scale）、字号体系（font-size 频次 → 字号阶梯）、颜色体系（色值频次 → 主题色板）。
- 边界：频次阈值（出现 >= 3 次才纳入体系）；聚类容差（宽度差 < 2px 归同类）；输出 token 格式（可直接生成 CSS variables）。
- 评分点：频次聚类；容差归并；token 输出。

```javascript
class LayoutSniffer {
  sniff(root) {
    const widths = [], gaps = [], fonts = [], colors = [];
    const walk = el => {
      const cs = getComputedStyle(el);
      if (el.offsetWidth > 0) widths.push(el.offsetWidth);
      gaps.push(parseFloat(cs.marginLeft), parseFloat(cs.columnGap || cs.gap || 0));
      if (parseFloat(cs.fontSize)) fonts.push(parseFloat(cs.fontSize));
      if (cs.color && cs.color !== 'rgba(0, 0, 0, 0)') colors.push(cs.color);
      [...el.children].forEach(walk);
    };
    walk(root);
    return {
      grid: cluster(widths, 2).slice(0, 12),                 // 宽度聚类 → 栅格候选
      spacing: cluster(gaps.filter(g => g > 0), 2).slice(0, 8),   // 间距 scale
      fontSize: cluster(fonts, 1).slice(0, 8),               // 字号阶梯
      palette: cluster(colors, 0).slice(0, 10),              // 色板
      tokens: this.toTokens(cluster(gaps.filter(g => g > 0), 2)),
    };
  }
  toTokens(spacings) {                                       // token 输出
    const sorted = spacings.sort((a, b) => a - b);
    return Object.fromEntries(sorted.map((s, i) => [`--space-${i + 1}`, s + 'px']));
  }
}
function cluster(values, tol) {                             // 频次聚类（容差归并）
  const freq = new Map();
  for (const v of values) {
    const key = [...freq.keys()].find(k => Math.abs(k - v) <= tol);
    freq.set(key ?? v, (freq.get(key ?? v) ?? 0) + 1);
  }
  return [...freq].filter(([, n]) => n >= 3)                 // 频次阈值
    .sort((a, b) => b[1] - a[1]).map(([v]) => Math.round(v * 100) / 100);
}
```
