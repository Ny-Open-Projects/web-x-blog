## DP-338：笔试题：手写性能数据聚合（长任务分布）？
**题目**：实现 TaskAggregator：1) 长任务采集（PerformanceObserver longtask）；2) 按耗时分桶（50-100/100-200/200+ ms）；3) P50/P95 计算（分位数近似）；4) 归因（任务时段内的资源加载清单 top3）。
**评分点**：
- observer 配置正确（longtask buffered）。
- 分桶边界清晰。
- 分位数用排序取位（近似可）。
- 归因用时间窗匹配资源条目。
```javascript
class TaskAggregator {
  #tasks = [];
  #resources = performance.getEntriesByType('resource');
  constructor() {
    new PerformanceObserver(list => this.#tasks.push(...list.getEntries()))
      .observe({ type: 'longtask', buffered: true });       // 1)
  }
  buckets() {                                               // 2)
    const b = { '50-100': 0, '100-200': 0, '200+': 0 };
    this.#tasks.forEach(t => t.duration < 100 ? b['50-100']++
      : t.duration < 200 ? b['100-200']++ : b['200+']++);
    return b;
  }
  percentile(p) {                                           // 3)
    const sorted = this.#tasks.map(t => t.duration).sort((a, b) => a - b);
    return sorted.length ? sorted[Math.floor(sorted.length * p)] ?? sorted.at(-1) : 0;
  }
  attribute(t) {                                            // 4) 归因 top3
    return this.#resources.filter(r => r.startTime < t.startTime + t.duration
      && r.startTime + r.duration > t.startTime)
      .sort((a, b) => b.duration - a.duration).slice(0, 3).map(r => ({ name: r.name, ms: r.duration }));
  }
  report() { return { buckets: this.buckets(), p50: this.percentile(0.5), p95: this.percentile(0.95) }; }
}
```
