## ARC-649：搜索无结果优化
**答**:
- 无结果场景分级：拼写错误（纠错建议："您是不是要找 xx"——拼写纠错接口）、过窄条件（放宽建议：去掉某筛选试试——逐条件放宽预估）、真无货（相似商品推荐——语义相近）、敏感/禁搜词（合规提示——不解释具体规则）。
- 数据闭环：无结果率监控（按词聚类分析——运营补词/补货决策依据 ARC-383）、无结果后的行为追踪（用户改词/离开——优化效果衡量）、搜词日志（热词/新词——同义词词典运营）。
- 前端实现：无结果页组件化（建议/推荐/引导组合——按服务端返回的优化策略渲染）、改词链路（一键改词 → 重新搜索——保留筛选语义）、模糊搜索开关（结果过少自动放宽——服务端策略）。
- 联想与纠错协同：输入期纠错（联想列表带纠错提示——ARC-383 联想）、语音搜索（ASR 结果纠错——移动端）。
- 度量：无结果→有效点击转化（优化有效性）、纠错采纳率。
```javascript
// 无结果页策略
const r = await api.search(kw);
if (!r.items.length) {
  const s = await api.searchSuggest(kw);                         // {correction, relax, similar}
  renderNoResult({ correction: s.correction,                     // 一键改词
                   relax: s.relax,                               // 放宽建议（逐条件）
                   similar: s.similarGoods });                   // 相似推荐
}
```
