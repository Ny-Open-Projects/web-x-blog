## ARC-532：数据字典与枚举治理
**答**:
- 问题：订单状态/支付方式等枚举在前后端、多端各自定义 → 漂移（新增状态前端没渲染分支 → 白屏或"未知状态"）。治理：字典单源（服务端字典服务或共享 schema 包，ARC-448），多端生成消费。
- 字典服务：字典注册（code/name/描述/生效版本/图标等展示属性）、运行时拉取（启动拉取 + 版本更新推送 ARC-369）、类型生成（TS 枚举/常量自动生成，NODE-449 一致性）。
- 渲染兜底：未知枚举值的统一处理（"未知(11)"降级渲染——永不白屏，未识别枚举上报（监控发现前后端版本错配））。
- 展示语义分层：业务含义（代码→文案）在字典，视图层只消费；多语言走 i18n key 关联（ARC-241）。
- 治理机制：枚举变更走评审（破坏性变更——删除值/改值语义，通知消费方 ARC-447）、字典使用 lint（禁硬编码魔法数字，reselect/映射必须走字典）。
```javascript
// 字典服务 + 兜底渲染
export const ORDER_STATUS = await dictService.get('order.status'); // { 1:{label:'待支付',i18n:'order.s1'}, ... }
export const statusLabel = (code) =>
  ORDER_STATUS[code]?.label ?? `未知(${code})`;                  // 未知枚举兜底
if (!ORDER_STATUS[code]) reportUnknownEnum('order.status', code); // 版本错配监控
```
