## DP-505：笔试：手写轮询器

**答**：实现自适应轮询器 `AdaptivePoller`：① 基础间隔 + 变化率自适应（数据变化密集 → 3s；平静 → 30s——滑动窗口统计变化率）；② 失败退避（连续失败 ×2，成功重置——上限 60s）；③ jitter（±20% 随机——防多客户端同步）；④ 页面隐藏暂停 / 恢复立即拉取；⑤ 增量游标（lastId——服务端只回增量）。写出实现。

```javascript
class AdaptivePoller {
  #changes = []; #cursor = 0; #timer = null; #fails = 0; #stopped = false;
  constructor(fetcher, { min = 3000, max = 30_000 } = {}) { Object.assign(this, { fetcher, min, max }); }
  async tick() {
    if (this.#stopped) return;
    try {
      const { items, changed } = await this.fetcher(this.#cursor);
      if (changed) { this.#cursor = items.at(-1).id; this.#changes.push(Date.now()); this.#fails = 0; }
      this.#changes = this.#changes.filter((t) => Date.now() - t < 60_000);
      this.#fails = 0;
    } catch { this.#fails++; }
    const rate = this.#changes.length / 60;             // 变化/秒
    const base = rate > 0.2 ? this.min : this.min + (this.max - this.min) * (1 - Math.min(rate / 0.2, 1));
    const jittered = Math.min(base * 2 ** this.#fails * (0.9 + Math.random() * 0.2), this.max);
    this.#timer = setTimeout(() => this.tick(), jittered);
  }
  start() { this.tick(); }
  stop() { this.#stopped = true; clearTimeout(this.#timer); }
}
// 页面隐藏暂停: document.addEventListener('visibilitychange', () => document.hidden ? pause() : tick())
```

**评分点**：
- 变化率驱动的自适应间隔（滑动窗口统计）
- 失败退避 + 成功重置 + max 封顶
- jitter（±20% 防同步冲击）
- 增量游标（lastId——服务端配合）
