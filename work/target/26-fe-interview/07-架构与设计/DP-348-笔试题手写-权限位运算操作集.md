## DP-348：笔试题：手写权限位运算操作集？
**题目**：实现位权限集：1) 常量定义（READ=1<<0 等）；2) has/grant/revoke/toggle；3) 序列化为字符串（分号分隔十六进制）；4) 与角色集合并（多角色 or）。
**评分点**：
- 位运算正确（| 添加 & ~ 移除）。
- 集合运算（roles → or 合并）。
- 序列化往返一致。
- 32 位上限说明（BigInt 方案提及加分）。
```javascript
const P = { READ: 1 << 0, WRITE: 1 << 1, DELETE: 1 << 2, ADMIN: 1 << 3, EXPORT: 1 << 4 };
function permSet(bits = 0) {
  return {
    bits,
    has: (p) => (bits & p) === p,                    // 2) 掩码含组合权限
    hasAny: (ps) => ps.some(p => (bits & p) === p),
    grant: (p) => permSet(bits | p),
    revoke: (p) => permSet(bits & ~p),
    toggle: (p) => permSet(bits ^ p),
    serialize: () => bits.toString(16),              // 3) 十六进制串
  };
}
const mergeRoles = (...roles) => permSet(roles.reduce((acc, r) => acc | r.bits, 0));   // 4)
// 用：const editor = permSet(P.READ | P.WRITE);
// editor.has(P.READ)  → true
// const admin = mergeRoles(editor, permSet(P.ADMIN));
// > 32 位权限：BigInt(0b...) 位运算同款（JS 位运算 32 位限制）
```
