## DP-509：笔试：手写权限指令

**答**：实现 v-perm 指令（可恢复版）：① 无权限时用「注释占位」替换元素（不是删除——元素引用保留可恢复）；② 权限变更（updated 钩子）重新判定——有权限恢复显示；③ 恢复的位置精确（original nextSibling——不破坏元素顺序）；④ deny 优先的判定（auth.has 内部处理——指令只调 has）；⑤ 批量权限变更的性能（一次变更只触发一次全页判定——防抖权限 store 通知）。写出实现。

```javascript
const removed = new WeakMap();

export const vPerm = {
  mounted(el, { value }) { check(el, value); },
  updated(el, { value, oldValue }) { if (value !== oldValue) check(el, value); },
};
function check(el, perm) {
  const ok = authStore.has(perm);
  if (!ok && el.isConnected) {
    const anchor = document.createComment('v-perm');
    removed.set(el, { parent: el.parentElement, next: el.nextSibling, anchor });
    el.parentElement?.replaceChild(anchor, el);       // 注释占位
  } else if (ok && removed.has(el)) {
    const { parent, next, anchor } = removed.get(el);
    parent?.insertBefore(el, anchor);                 // 精确恢复位置
    anchor.remove();
    removed.delete(el);
  }
}
// authStore.setRoles 触发时: 用 MutationObserver 或手动遍历 registered elements 重新判定
// 性能: 权限 store 通知防抖 — 一次变更一轮判定
```

**评分点**：
- 注释占位（元素引用保留可恢复——vs 直接 remove 不可逆）
- 精确恢复位置（nextSibling——顺序不破坏）
- updated 钩子的重判定（value 变化触发）
- 权限变更通知的防抖（一轮判定）
