## ARC-512：连麦/语聊房前端架构
**答**:
- RTC 链路：采集（getUserMedia 降噪/回声消除配置）→ 发布（推流至 SFU）→ 订阅（按麦位动态订阅多路流）；订阅管理是核心（大房间只订阅麦上流，下麦即 unsubscrib 释放解码资源）。
- 麦位协议：麦位状态（上麦申请/邀请/抱麦/下麦）走信令通道（ARC-379 通道复用），状态变更广播全房；本地先渲染乐观状态再等信令确认。
- 音频治理：音量分级（说话人检测 audioLevel 回调驱动 UI 高亮与混流布局）、静音/闭麦状态同步、3A 问题（回声/噪声/自动增益）的设备兼容矩阵。
- 视频连麦额外项：大小窗口切换（拉流质量档位）、美颜/滤镜链路（WebGL 前处理）、弱网降级（先降分辨率再降帧）。
- 中断恢复：来电/切后台中断（audiointerrupt）自动暂停恢复；网络切换（WiFi→4G）ICE restart；断线重连后麦位状态对账。
```javascript
// 麦位订阅管理
room.on('seatChange', async (seats) => {
  const onSeat = new Set(seats.filter(s => s.uid).map(s => s.uid));
  for (const uid of subscribed) if (!onSeat.has(uid)) await rtc.unsub(uid);   // 下麦释放
  for (const uid of onSeat) if (!subscribed.has(uid)) await rtc.sub(uid, { quality: 'high' });
  subscribed = onSeat;
});
// 说话人高亮：rtc.on('audioLevel', ({ uid, level }) => ui.highlight(uid, level > 0.1))
```
