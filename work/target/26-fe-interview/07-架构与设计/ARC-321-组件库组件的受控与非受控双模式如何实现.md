## ARC-321：笔试题：实现组件库受控/非受控双模式组件？
**答**：实现一个 `Input` 组件同时支持受控（value+onChange）与非受控（defaultValue）模式，要求：1) 受控时外部不更新则值不变化；2) 非受控时内部维护状态且外部可通过 ref 读取/重置；3) 切换模式的行为有明确约定；4) TS 类型完备。
**评分点**：
- 受控/非受控判定正确（value !== undefined 为受控），且切换模式给出 console.warn。
- 非受控内部状态正确初始化（defaultValue），重置逻辑正确（ref.reset 回到 defaultValue）。
- onChange 时机正确（值真正变化才触发），受控模式下输入体验正常（受控回写）。
- 泛型/类型完备（ValueProps 泛型），JSDoc 说明约定。
```tsx
type ControlledProps<V> = { value: V; defaultValue?: never; onChange: (v: V) => void };
type UncontrolledProps<V> = { value?: never; defaultValue: V; onChange?: (v: V) => void };
type InputProps<V> = (ControlledProps<V> | UncontrolledProps<V>) & { placeholder?: string };

const Input = forwardRef(function Input<V extends string>(props: InputProps<V>, ref) {
  const controlled = props.value !== undefined;
  const [inner, setInner] = useState<V>(props.defaultValue as V);
  const value = controlled ? props.value : inner;
  useImperativeHandle(ref, () => ({
    get: () => value,
    reset: () => !controlled && setInner(props.defaultValue as V),   // 非受控重置
  }));
  if (process.env.NODE_ENV !== 'production') {
    const wasControlled = useRef(controlled);
    if (wasControlled.current !== controlled)
      console.warn('Input: 受控/非受控模式不可中途切换');            // 3) 约定告警
    wasControlled.current = controlled;
  }
  return <input value={value} placeholder={props.placeholder}
    onChange={e => { const v = e.target.value as V;
      if (!controlled) setInner(v);                                   // 非受控：内部更新
      props.onChange?.(v);                                            // 双模式都通知
    }}/>;
});
```
