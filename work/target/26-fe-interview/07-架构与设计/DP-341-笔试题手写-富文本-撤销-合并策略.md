## DP-341：笔试题：手写富文本撤销（连续输入合并）？
**题目**：实现 EditorHistory：1) 连续 insertText 合并为一条（时间窗 800ms + 相邻位置）；2) 格式化命令独立成条；3) undo/redo 完整；4) IME 合成期不提交。
**评分点**：
- 合并条件正确（时间窗 + 位置连续）。
- 格式化打断合并（不同 label）。
- IME compositionstart/end 门控。
- redo 分支清理。
```javascript
class EditorHistory {
  #stack = []; #redo = [];
  #lastAt = 0; #lastPos = -1;
  #composing = false;
  constructor(private editor) {
    editor.on('compositionstart', () => this.#composing = true);   // 4)
    editor.on('compositionend', () => { this.#composing = false; this.commit('type'); });
  }
  insertText(text, pos) {
    const now = Date.now();
    const merge = !this.#composing && this.#stack.at(-1)?.label === 'type'
      && now - this.#lastAt < 800 && pos === this.#lastPos;        // 1) 时间窗+连续
    this.#lastAt = now; this.#lastPos = pos + text.length;
    if (merge) { this.#stack.at(-1).len += text.length; return; }
    this.commit('type', { text, pos, len: text.length });
  }
  commit(label, payload) {                                         // 2) 格式化独立条
    const e = this.editor;
    const snap = e.getDoc();
    this.#stack.push({ label, payload, undo: () => e.setDoc(snap) });
    if (this.#stack.length > 100) this.#stack.shift();
    this.#redo = [];                                               // 4)
  }
  undo() { const c = this.#stack.pop(); if (!c) return;
    const cur = this.editor.getDoc(); c.undo(); this.#redo.push({ ...c, undo: () => this.editor.setDoc(cur) }); }
  redo() { const c = this.#redo.pop(); if (!c) return;
    const cur = this.editor.getDoc(); c.undo(); this.#stack.push({ ...c, undo: () => this.editor.setDoc(cur) }); }
}
```
