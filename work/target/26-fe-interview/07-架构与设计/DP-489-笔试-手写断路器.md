## DP-489：笔试：手写断路器

**答**：实现断路器 CircuitBreaker：① 三态：closed→(连续失败≥threshold)→open→(冷却期过)→half-open；② open 期快速失败（抛 CircuitOpenError——不发请求）；③ half-open 放行探测（并发 ≤1——防探测风暴）；④ 成功重置/失败重回 open（重置冷却期）；⑤ isRetryable 注入（只统计可重试错误）；⑥ 状态变化事件（onStateChange——监控告警）。写出实现与状态迁移测试要点。

```javascript
class CircuitOpenError extends Error { constructor() { super('circuit open'); this.name = 'CircuitOpenError'; } }

class CircuitBreaker {
  #state = 'closed'; #fails = 0; #halfOpen = 0; #openedAt = 0;
  constructor(fn, { threshold = 5, cooldown = 30_000, isRetryable = () => true, onStateChange } = {}) {
    Object.assign(this, { fn, threshold, cooldown, isRetryable, onStateChange });
  }
  async call(...args) {
    if (this.#state === 'open') {
      if (Date.now() - this.#openedAt < this.cooldown) throw new CircuitOpenError();
      this.#state = 'half-open';                       // 冷却结束 → 探测
    }
    if (this.#state === 'half-open') {
      if (this.#halfOpen >= 1) throw new CircuitOpenError();   // 探测并发 ≤1
      this.#halfOpen++;
      try { const r = await this.fn(...args); this.#reset(); return r; }
      catch (e) { this.#open(); throw e; }
      finally { this.#halfOpen--; }
    }
    try {
      const r = await this.fn(...args);
      this.#fails = 0; return r;                       // 成功重置
    } catch (e) {
      if (this.isRetryable(e) && ++this.#fails >= this.threshold) this.#open();
      throw e;
    }
  }
  #open() { this.#state = 'open'; this.#openedAt = Date.now(); this.onStateChange?.('open'); }
  #reset() { this.#state = 'closed'; this.#fails = 0; this.onStateChange?.('closed'); }
  get state() { return this.#state; }
}
// 测试: 5 连败 → open → 快速失败 → 冷却 → half-open → 成功 → closed
```

**评分点**：
- 三态转换完整（half-open 的探测并发 ≤1）
- 快速失败语义（open 期不发请求——保护用户等待时间）
- isRetryable 过滤（只统计可重试错误）
- onStateChange 告警钩子
