## DP-527：笔试：手写优先级事件总线

**答**：扩展事件总线支持优先级与同步语义：① handler 声明 priority——emit 按 priority 升序执行（高优先处理：鉴权 handler 先于日志）；② sync/async 语义：sync handler 顺序执行完才触发 async（关键逻辑先行）；③ emit 的返回值收集：handlers 的返回值聚合（管道语义——ctx 逐 handler 传递）；④ 拦截语义：handler 返回 false → 停止后续（可取消事件的实现）；⑤ 说明与普通 emit 的取舍（优先级总线的复杂度 vs 普通总线的简单性）。写出实现。

```javascript
class PriorityBus {
  #subs = new Map();   // type -> [{ fn, priority, sync }]
  on(type, fn, { priority = 10, sync = false } = {}) {
    (this.#subs.get(type) ?? this.#subs.set(type, []).get(type)).push({ fn, priority, sync });
    this.#subs.get(type).sort((a, b) => a.priority - b.priority);   // 注册时排序
  }
  async emit(type, ctx = {}) {
    const handlers = this.#subs.get(type) ?? [];
    // 同步先行
    for (const h of handlers.filter((h) => h.sync)) {
      const r = await h.fn(ctx);
      if (r === false) return { intercepted: true };   // 拦截语义
    }
    // 异步收集
    const results = [];
    for (const h of handlers.filter((h) => !h.sync)) {
      const r = await h.fn(ctx);
      if (r === false) return { intercepted: true };
      results.push(r);
    }
    return { intercepted: false, results };
  }
}
// 用法: bus.on('before-save', validate, { priority: 0, sync: true })   // 校验先
//       bus.on('before-save', log, { priority: 10 })                    // 日志后
// 拦截: validate 返回 false → 不保存
```

**评分点**：
- 优先级排序（注册时排序——emit 时有序）
- sync/async 语义分离（关键逻辑先行）
- ctx 管道传递（handlers 协作）
- 拦截语义（返回 false 停止——可取消事件）
