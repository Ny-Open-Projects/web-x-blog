## ARC-519：在线考试系统前端架构
**答**:
- 计时权威：服务端下发截止时间戳 + 本地钟差校正（ARC-481）；倒计时到期强制交卷（答案自动提交幂等）；断线恢复后时间以服务端为准（本地计时只做展示）。
- 答案保护：作答即存（防抖保存 + 本地双写 IndexedDB）；切屏/失焦事件埋点（防作弊信号：切屏次数/时长上报，服务端风控判定，前端只采集不裁决）。
- 试题安全：试卷按需下发（每题单独拉取或解密包，禁止整卷 HTML 可见）、复制/右键限制（软限制，防君子）、水印（用户 ID 隐写 ARC-340）。
- 交卷链路：交卷确认（未答题提示）→ 上传（幂等键 + 重试）→ 服务端校验完整性（缺失题补传窗口）→ 结果页（即时分/待判分状态区分）。
- 异常预案：刷新/崩溃恢复（答案与进度恢复 ARC-488）、长时间断网（离线继续作答，恢复后同步）。
```javascript
// 作答即存 + 切屏监控
answer.onChange(debounce(a => {
  localStorage.setItem(`ans:${examId}:${qId}`, JSON.stringify(a));
  api.saveAnswer({ examId, qId, a }, { idempotencyKey: hash({ examId, qId, a }) });
}, 800));
document.addEventListener('visibilitychange', () => {
  if (document.hidden) track('blur', { at: Date.now() });        // 防作弊信号采集
});
```
