## DP-488：笔试：手写重试装饰器

**答**：实现生产级重试装饰器：① 指数退避 + 抖动（base × 2^n + random(0, base)——防同步重试风暴）；② 总预算（budget ms——超预算停止，正在执行的请求 abort）；③ 可重试判定（注入 shouldRetry——5xx 重试 4xx 不重）；④ onRetry 钩子（第几次/等待多久/错误——埋点）；⑤ 返回元数据（attempts/elapsed——调用方可观测）。写出实现。

```javascript
async function withRetry(fn, {
  attempts = 5, base = 200, maxDelay = 5000, budget = 10_000,
  shouldRetry = (e) => !e.status || e.status >= 500 || e.status === 429,
  onRetry, signal,
} = {}) {
  const start = performance.now();
  const ctrl = new AbortController();
  signal?.addEventListener('abort', () => ctrl.abort(), { once: true });
  let lastErr;
  for (let i = 0; i < attempts; i++) {
    const remain = budget - (performance.now() - start);
    if (remain <= 0) break;
    try {
      const v = await fn(ctrl.signal);
      return { value: v, attempts: i + 1, elapsed: performance.now() - start };
    } catch (e) {
      lastErr = e;
      if (!shouldRetry(e)) break;
      const delay = Math.min(base * 2 ** i + Math.random() * base, maxDelay, remain);
      onRetry?.(i + 1, delay, e);
      await new Promise((r) => setTimeout(r, delay));
    }
  }
  const err = new Error('retry exhausted', { cause: lastErr });
  err.lastError = lastErr;
  throw err;
}
// budget 感知: 单次超时 = 剩余预算 (不是固定值)
```

**评分点**：
- 抖动的必要性（防多客户端同步重试风暴）
- 总预算感知（超时收缩 + abort 在途请求）
- shouldRetry 注入（错误分类决定重试）
- 元数据返回（attempts/elapsed——可观测）
