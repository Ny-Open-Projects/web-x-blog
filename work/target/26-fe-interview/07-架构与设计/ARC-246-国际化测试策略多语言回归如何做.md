## ARC-246：国际化测试策略：多语言回归如何做？
**答**：
- 分层：单测层——格式化函数（日期/货币/复数）表驱动跑全部支持语言；组件层——关键组件在"最极端语言"（德语长文案/阿语 RTL/日语无空格）下渲染快照；E2E 层——只跑默认语言 + 一个代表 RTL 语言的冒烟路径。
- 假语言技巧：伪本地化（pseudo-l10n）——生成"[!!! Ŝṕéçíàļ !!!]"式加长假文案，用于发现溢出与硬编码，不必等真翻译。
- 视觉回归矩阵：LTR×2 语言 + RTL×1 语言 + 最长语言（德）共 4 套基线截图，覆盖 90% 布局问题。
- 复数/日期专项：俄语复数（one/few/many）、阿拉伯语数字系统（Intl 默认 vs 强制 latn）单测必覆盖。

```typescript
// 伪本地化：构建期对源文案变形
function pseudo(s: string) {
  const map = { a: 'à', e: 'é', i: 'í', o: 'ó', u: 'ú' };
  return `[${'!'.repeat(Math.ceil(s.length * 0.3))} ${s.replace(/[aeiou]/g, c => map[c])}]`;
}
// 组件测试：跑伪语言快照 → 长文案溢出、漏翻（假文案没出现的英文就是硬编码）都现形
// 复数单测：
test.each([
  ['ru', 1, 'one'], ['ru', 3, 'few'], ['ru', 11, 'many'],
])('%s %d → %s', (locale, n, cat) => expect(pluralCat(locale, n)).toBe(cat));
```
