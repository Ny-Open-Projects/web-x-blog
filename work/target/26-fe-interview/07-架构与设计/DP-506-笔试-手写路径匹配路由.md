## DP-506：笔试：手写路由匹配器

**答**：实现路径匹配器 `matchPath(pattern, path)`：① 参数段：`/goods/:id` 提取 params；② 通配段：`/files/*`（剩余任意段）；③ 多段匹配长度必须一致（/:id 是一段）；④ 嵌套优先级：静态段 > 动态段 > 通配（同路径多路由命中时选静态）；⑤ decodeURIComponent 解码参数。写出实现与优先级测试。

```javascript
function matchPath(pattern, path) {
  const pp = pattern.split('/').filter(Boolean);
  const np = path.split('/').filter(Boolean);
  const params = {};
  let wildcard = false;
  let pi = 0;
  for (let i = 0; i < pp.length; i++) {
    const seg = pp[i];
    if (seg === '*') { params['*'] = np.slice(i).map(decodeURIComponent).join('/'); wildcard = true; break; }
    if (pi >= np.length) return null;                 // pattern 比 path 长
    if (seg.startsWith(':')) params[seg.slice(1)] = decodeURIComponent(np[pi++]);
    else if (seg !== np[pi++]) return null;
  }
  if (!wildcard && pi < np.length) return null;       // path 有剩余段
  return params;
}
// 优先级: ['/goods/list'(静态), '/goods/:id'(动态), '/goods/*'(通配)]
// matchPath('/goods/list', '/goods/list') → {} (静态优先)
// matchPath('/goods/:id', '/goods/42') → { id: '42' }
// matchPath('/goods/*', '/goods/a/b/c') → { '*': 'a/b/c' }
```

**评分点**：
- 参数段提取 + decodeURIComponent
- 通配段（* 的剩余路径聚合）
- 长度一致性校验（/a/:id 不匹配 /a）
- 优先级排序（静态 > 动态 > 通配）
