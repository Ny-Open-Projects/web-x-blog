## ARC-470：前端架构一页纸总览图怎么画
**答**:
- 用 C4 模型裁剪：Context（系统边界与外部依赖）→ Container（前端各应用/网关/BFF）→ Component（应用内模块分层）→ Code（关键机制示意）。一页纸只画前两层，后两层放链接。
- 画法纪律：每个框 = 有名字的部署单元（不是抽象概念）；每个箭头 = 具体协议（HTTP/WS/IPC，不是"调用"）；外部依赖标 owner 与 SLA；页面/路由到模块的映射放附录表。
- 常见错误：一张图塞下所有细节（变成装饰画）；只画期望架构不画现实（评审时被当场戳穿）；箭头无协议无数据语义。
- 维护机制：图由代码生成或半自动（结构扫描输出依赖图 + 人工标注协议），架构变更 MR 必须更新图（CI 检查 diff 是否触及架构文件）。
- 面试用法：白板画图题先画 Context 一层确认范围（跟面试官对齐），再按需下钻——顺序错了就会画成大杂烩。
```javascript
// 一页纸图的数据结构（可生成渲染）
const archPage = {
  context: [
    { node: 'Web App', type: 'spa', owner: 'fe-team' },
    { node: 'BFF', type: 'node', owner: 'fe-team', sla: '99.9%' },
    { node: '订单服务', type: 'external', owner: 'trade-team' }
  ],
  edges: [
    ['Web App', 'BFF', 'HTTPS/JSON, sse for feed'],
    ['BFF', '订单服务', 'gRPC']
  ]
};
```
