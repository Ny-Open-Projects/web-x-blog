## ARC-826：手写效能基线

**答**：实现平台化前后效能对比 `EfficiencyBaseline`：① 基线采集：平台接入前的指标（需求前置时间/构建时长/重复代码率/组件复用率）——「before 快照」；② after 采集：接入后同指标周期性采集；③ 对比分析：各指标的前后差值 + 显著性标注（样本量足够才下结论）；④ ROI 计算：效率提升折算人日节省（前置时间缩短 × 需求数）- 平台建设成本；⑤ 报告输出：管理层数据表（前后对比）+ 工程师细节（哪些环节改善最大）。写出实现。

```javascript
class EfficiencyBaseline {
  #before = []; #after = [];
  captureBefore(metrics) { this.#before.push({ t: Date.now(), ...metrics }); }
  captureAfter(metrics) { this.#after.push({ t: Date.now(), ...metrics }); }

  compare() {
    const keys = ['leadTimeDays', 'buildMinutes', 'dupCodeRate', 'reuseRate'];
    const out = {};
    for (const k of keys) {
      const b = median(this.#before.map((m) => m[k]));
      const a = median(this.#after.map((m) => m[k]));
      const n = Math.min(this.#before.length, this.#after.length);
      const significant = n >= 20;                     // 样本量门槛
      out[k] = { before: b, after: a, delta: +(a - b).toFixed(2),
        pctChange: +(((a - b) / b) * 100).toFixed(1), significant };
    }
    return out;
  }
  roi(platformCost, demandCount, costPerDay) {
    const c = this.compare();
    const leadTimeSaved = Math.max(0, c.leadTimeDays.before - c.leadTimeDays.after);
    const savedDays = leadTimeSaved * demandCount;
    const savedMoney = savedDays * costPerDay;
    return { savedDays: +savedDays.toFixed(1), savedMoney,
      roi: +(((savedMoney - platformCost) / platformCost) * 100).toFixed(0) + '%' };
  }
  report() {
    const c = this.compare();
    const best = Object.entries(c).sort((a, b) => Math.abs(b[1].pctChange) - Math.abs(a[1].pctChange))[0];
    return `效能对比: ${Object.entries(c).map(([k, v]) => `${k}: ${v.before}→${v.after} (${v.pctChange}%)${v.significant ? '' : ' [样本不足]'}`).join('\n')}\n改善最大: ${best[0]}`;
  }
}
function median(arr) { const s = [...arr].sort((a, b) => a - b); return s[Math.floor(s.length / 2)] ?? 0; }
```

**评分点**：
- before/after 双快照与中位数统计（非均值）
- 显著性标注（样本量门槛——不足不下结论）
- ROI 的量化折算（前置时间×需求数×人日成本）
- 报告分层（管理层数据 + 工程师细节）
