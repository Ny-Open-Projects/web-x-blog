## DP-497：笔试：手写懒加载代理

**答**：实现懒加载代理 `lazyProxy(factory)`：① 首次访问任意属性才执行 factory 初始化（重资源延迟创建——图表实例/SDK）；② 初始化后的访问直通（代理透明——后续零开销）；③ 初始化失败的处理（factory 抛错 → 后续访问重试——失败不缓存）；④ 并发初始化的防重（多个属性同时首次访问只初始化一次——Promise 复用）；⑤ 显式销毁（dispose 清实例——代理生命周期）。写出实现。

```javascript
function lazyProxy(factory) {
  let instance = null, initPromise = null;
  const ensure = () => {
    if (instance) return Promise.resolve(instance);
    initPromise ??= Promise.resolve()
      .then(factory)
      .then((inst) => { instance = inst; return inst; })
      .catch((e) => { initPromise = null; throw e; });   // 失败不缓存: 下次重试
    return initPromise;
  };
  return new Proxy({}, {
    get(_, prop) {
      if (prop === 'dispose') return () => { instance?.dispose?.(); instance = null; initPromise = null; };
      return async (...args) => {                       // 统一异步化: 初始化是异步的
        const inst = await ensure();
        return typeof inst[prop] === 'function' ? inst[prop](...args) : inst[prop];
      };
    },
  });
}
// 用法: const chart = lazyProxy(() => initHeavyChart());
// chart.render(data)   ← 首次调用才初始化
// chart.dispose()
```

**评分点**：
- 首次访问触发初始化（懒加载语义）
- 初始化失败不缓存（下次重试——失败不冻结）
- 并发初始化的 Promise 复用（防重复创建）
- dispose 的生命周期管理
