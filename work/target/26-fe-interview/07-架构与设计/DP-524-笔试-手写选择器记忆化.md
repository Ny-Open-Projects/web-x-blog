## DP-524：笔试：手写 selector 记忆化

**答**：实现 reselect 风格的 selector：① createSelector(deps, compute)：deps 是输入 selector 数组——依赖值不变直接返回缓存结果；② 级联：selector 依赖 selector（链式缓存）；③ 嵌套结构共享：输入引用不变短路（=== 命中占大多数）；④ 默认相等比较可注入（浅比较——输出对象字段级比较）；⑤ 说明与 useMemo 的区别（跨组件共享缓存 vs 组件级——selector 是 store 层记忆化）。写出实现。

```javascript
function createSelector(deps, compute, equalityFn = (a, b) => a === b) {
  let lastDeps, lastResult;
  return (state, ...rest) => {
    const depValues = deps.map((d) => d(state, ...rest));
    // 依赖值全部不变 → 返回缓存 (引用比较)
    if (lastDeps && depValues.every((v, i) => v === lastDeps[i])) return lastResult;
    lastDeps = depValues;
    lastResult = compute(...depValues);
    return lastResult;
  };
}
// 级联: 
const selectItems = (s) => s.cart.items;
const selectTotal = createSelector([selectItems], (items) => items.reduce((s, i) => s + i.price, 0));
const selectSummary = createSelector([selectTotal], (total) => ({ total, label: `¥${total}` }));
// items 引用不变 → total 不重算 → summary 不重算 (级联短路)
```

**评分点**：
- 依赖值引用比较短路（=== 命中占大多数——性能关键）
- 级联缓存（selector 依赖 selector）
- equalityFn 注入（浅比较——输出对象防失效）
- 与 useMemo 的区别（store 层跨组件 vs 组件级）
