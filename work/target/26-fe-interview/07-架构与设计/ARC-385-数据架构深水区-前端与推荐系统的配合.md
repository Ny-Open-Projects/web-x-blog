## ARC-385：信息流/推荐场景的前端架构如何设计？
**答**:
- 推荐流前端三职责：渲染（无限列表虚拟滚动 + 混排卡片）、曝光（精准曝光埋点：intersection + 时长阈值，是推荐闭环的数据基础）、刷新策略（下拉刷新/定时拉新/插入广告位协议）。
- 混排协议：服务端返回"槽位流"（内容 + 广告 + 运营位交错），前端按 slot 渲染；广告 SDK 异步加载不能阻塞信息流首屏。
- 无限列表的坑：虚拟滚动 + 动态高度测量（缓存实测高度）、图片渐进加载、列表内存上限（回收离屏节点但保滚动位置）、keep-alive 返回位置恢复。
- 曝光准确性：50% 可见 + 停留 > 500ms 才计曝光；滚动快速掠过不误报；页面隐藏时暂停计时；曝光去重（同一内容会话内只报一次或按策略）。
- 刷新与去重：拉新内容与已有内容去重（内容 ID 集合）；"看过了"折叠策略。
```javascript
const observer = new IntersectionObserver(onVisible, { threshold: 0.5 });
function onVisible(entries) {
  for (const e of entries) {
    if (e.isIntersecting) startDwell(e.target.dataset.id);
    else {
      const dwell = endDwell(e.target.dataset.id);
      if (dwell > 500) track('expose', { id: e.target.dataset.id, dwell }); // 有效曝光
    }
  }
}
```
