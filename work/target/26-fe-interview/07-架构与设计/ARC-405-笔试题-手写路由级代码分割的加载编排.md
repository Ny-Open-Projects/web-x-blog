## ARC-405：笔试题：手写路由级资源预加载编排
**答**：实现 Prefetcher：1) prefetch(route) 预取路由 chunk（去重、只一次）；2) hover 时延迟 100ms 预取（防误扫）；3) 空闲时按优先级队列预取 topN 路由；4) 预取失败静默，不影响真实导航。
**评分点**：
- 去重（inflight 与 done 集合）。
- hover 延迟 100ms + 离开取消（防抖语义正确）。
- requestIdleCallback 空闲预取，逐个串行防抢带宽。
- 失败静默 catch。
```javascript
class Prefetcher {
  #done = new Set(); #inflight = new Set(); #queue = [];
  prefetch(route) {
    if (this.#done.has(route) || this.#inflight.has(route)) return;
    this.#inflight.add(route);
    import(/* webpackChunkName: "route" */ `./pages/${route}.vue`)
      .then(() => this.#done.add(route))
      .catch(() => {})                                            // 静默：真实导航再加载
      .finally(() => this.#inflight.delete(route));
  }
  onHover(el, route) {
    const t = setTimeout(() => this.prefetch(route), 100);        // 防误扫
    el.addEventListener('mouseleave', () => clearTimeout(t), { once: true });
  }
  scheduleIdle(routes) {                                          // 空闲串行预取
    const next = () => {
      if (!routes.length) return;
      requestIdleCallback((dl) => {                               // 有剩余时间才取
        if (dl.timeRemaining() > 10) this.prefetch(routes.shift());
        next();
      });
    };
    next();
  }
}
```
