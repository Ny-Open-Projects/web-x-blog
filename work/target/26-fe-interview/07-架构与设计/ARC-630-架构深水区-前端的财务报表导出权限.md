## ARC-630：财务报表导出权限
**答**:
- 财务数据的导出敏感级最高：字段级权限（金额/账户信息分级——ARC-581 导出合规链路财务特化）、范围权限（只能导自己账户/自己店铺——行级权限在导出同样生效 ARC-420）。
- 流程设计：导出申请（财务报表 → 审批链（大额/全量需主管审批——ARC-509 工单）→ 异步生成 → 水印下载）、导出留痕（谁导出了什么范围什么时间——审计哈希链 NODE-442 配合）、时效限制（导出文件短期有效 + 下载记录）。
- 对账单专项：对账周期选择（月/日/自定义——切片边界时区 ARC-481 业务时区）、双方对账（渠道对账单 vs 平台流水——差异标注展示 ARC-382 结果呈现）、格式规范（财务导入格式：标准 CSV 列——财务系统兼容）。
- 前端配合：导出前预览（将导出的范围与字段预览——确认后执行）、导出历史（自己的导出记录可查——自证与再下载）。
- 安全：导出文件水印（用户标识——泄露溯源）、传输加密（签名 URL 短时效 ARC-340）。
```javascript
<FinanceExport report="settlement"
  scope={ownScope()}                                              // 行级权限：只导自己
  needsApproval={(q) => q.total > 10000}                          // 大额走审批
  watermark={{ uid, role }} onDone={downloadSigned} />            // 水印 + 签名下载
// 审计：export.audit({ uid, scope, rows, ts }) → hashChain
```
