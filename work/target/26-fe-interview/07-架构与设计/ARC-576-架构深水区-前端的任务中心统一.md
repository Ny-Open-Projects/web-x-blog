## ARC-576：异步任务中心前端架构
**答**:
- 收口：全站异步任务（导出/导入/报表/批量操作 ARC-486/490/575）统一任务中心——用户在一个地方看所有任务状态，不用在各功能里各找各的。
- 任务协议：统一任务模型（类型/状态机/进度/结果链接/失败原因/重试与撤销能力声明）——各业务的任务接入协议（注册任务类型：图标/文案/完成跳转）。
- 前端架构：任务中心 store（WS 推送更新 ARC-416 + 拉取兜底对账）、全局角标（进行中任务数，跨页面可见）、任务完成通知（ARC-394 联动：完成推送 + 点击跳结果）。
- 体验细节：进行中任务可取消（能力声明——服务端支持才展示）、失败任务一键重试（幂等安全时）、历史任务清理（完成 7 天归档）。
- 治理：任务类型注册审核（防任务类型泛滥——每种类型的取消/重试语义要明确）、长任务超时治理（超长任务拆分或提示预计时长）。
```javascript
// 任务中心 store
taskCenter.useSubscription();                                    // WS 推送
taskCenter.on('update', (t) => badge.update(t.active));
// 任务类型注册
registerTaskType('export', { icon: FileDown, done: '下载', retry: true, cancel: true });
registerTaskType('import', { icon: Upload, done: '查看结果', retry: false }); // 导入不可盲重试
```
