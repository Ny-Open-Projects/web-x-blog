## DP-526：笔试：手写审批链

**答**：实现审批责任链：① 链节点：{ approver, canApprove(ctx), approve, reject, escalate }——逐级审批；② 会签与或签：节点组语义（all 全同意/any 任一同意）——链节点的聚合参数化；③ 驳回语义：驳回上一节点（修改重提）vs 驳回发起人（重走）——两种驳回的策略；④ 金额路由：金额阈值动态构建链（>5w 加财务节点——策略构建链）；⑤ 超时升级：节点超 48h 未审 → 升级上级。写出实现。

```javascript
function buildApprovalChain(amount) {                   // 策略: 动态建链
  const chain = [{ approver: 'supervisor', mode: 'any' }];
  if (amount > 50000) chain.push({ approver: 'finance', mode: 'all' });   // 财务会签
  if (amount > 500000) chain.push({ approver: 'vp', mode: 'any' });
  return chain;
}
async function runChain(chain, ctx) {
  for (const node of chain) {
    const r = await collectApproval(node, ctx, { timeout: 48 * 3600e3 });
    if (r.action === 'reject')
      return r.target === 'prev' ? { ok: false, backTo: chain.indexOf(node) - 1 } : { ok: false, backTo: 0 };   // 驳回语义
    if (r.action === 'escalate') { /* 超时升级: 替换为上级审批人 */ }
    ctx.approvals.push(r);
  }
  return { ok: true, approvals: ctx.approvals };
}
// 会签: await Promise.all(group.map(n => n.approve(ctx))) — all 语义
```

**评分点**：
- 金额路由的动态建链（策略构建责任链）
- 会签/或签的聚合语义参数化
- 两种驳回策略（backTo 上节点 vs 发起人）
- 超时升级机制
