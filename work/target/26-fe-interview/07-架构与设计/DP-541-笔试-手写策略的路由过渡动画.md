## DP-541：笔试：手写路由过渡

**答**：实现路由切换的过渡策略：① meta 驱动：路由 meta.transition（slide/fade/none）——策略按 meta 选择过渡动画；② 方向感知：前进 slide-left / 后退 slide-right（导航方向 = depth 比较——策略的动态输入）；③ View Transitions API 优先：支持时用原生（document.startViewTransition——浏览器级过渡）、降级 CSS 类切换；④ 过渡期间的导航锁（动画中再点击——防抖/排队）；⑤ 减动效适配（prefers-reduced-motion → 全部瞬时切换）。写出实现。

```javascript
function getTransition(to, from, { prefersReducedMotion }) {
  if (prefersReducedMotion) return { name: 'none' };
  if (document.startViewTransition) return { type: 'view-transition' };
  const depth = (r) => r.path.split('/').filter(Boolean).length;
  const direction = depth(to) > depth(from) ? 'forward' : 'back';
  const name = to.meta?.transition ?? (direction === 'forward' ? 'slide-left' : 'slide-right');
  return { name, direction };
}
// 导航锁: transitioning 标记 — 动画中点击忽略 (或排队)
// Vue Router 集成: <RouterView v-slot="{ Component, route }">
//   <Transition :name="getTransition(route, from).name"><component :is="Component" /></Transition>
```

**评分点**：
- meta 驱动的过渡选择（声明式策略）
- 方向感知（depth 比较——前进/后退差异化）
- View Transitions 优先 + 降级链
- 减动效适配 + 导航锁
