## ARC-316：组件库的表单体系设计：统一校验与联动协议？
**答**:
- 表单体系三层：输入组件（受控协议统一 value/onChange）、字段包装（label/错误信息/布局）、表单容器（数据收集/校验编排/提交状态）。ARC-033 讲架构思路，这里讲组件库落地。
- 校验协议：统一校验器接口（`(value, formCtx) => Error | Promise<Error>`），内置规则 + async-validator 类适配；校验时机（blur/change/submit）可配置且全库默认一致。
- 联动协议：字段依赖声明（visible/disabled/校验联动由 schema 表达），容器统一求值；跨字段联动用信号量（字段 A change → 触发订阅列表）。
- 性能：大表单字段级订阅（每个 Field 只订阅自己的错误与值），避免整表单重渲染。

```typescript
// 字段级订阅的表单容器
class FormStore {
  fields = new Map<string, FieldState>();
  listeners = new Map<string, Set<() => void>>();
  setValue(name, v) { this.fields.get(name).value = v; this.emit(name); }
  subscribe(name, fn) { /* 精确订阅 */ }
}
function Field({ name, rules }) {
  const { value, error } = useFormStore(name);           // 只重渲染本字段
  const comp = <Input value={value} onChange={v => store.setValue(name, v)} />;
  return <FormItem label={label} error={error}>{comp}</FormItem>;
}
// 校验编排：validate() = Promise.all(fields.map(f => runRules(f))) → 汇总错误 map
```
