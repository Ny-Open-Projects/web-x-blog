## DP-330：笔试题：手写虚拟列表键盘导航？
**题目**：在虚拟列表上实现键盘导航：1) 上下键移动焦点项并自动滚入可视区；2) 焦点项渲染 aria-selected；3) 快速连按（键重复）不卡顿（rAF 合并滚动）；4) Enter 确认。
**评分点**：
- focus 状态与可视窗口联动（越界即滚动）。
- rAF 合并快速按键。
- aria 属性正确（listbox/option）。
- Enter 回调防重入。
```tsx
function VirtualKeyboardList({ items }) {
  const [focus, setFocus] = useState(0);
  const box = useRef();
  const raf = useRef(0);
  const move = (delta) => {
    setFocus(f => Math.min(Math.max(0, f + delta), items.length - 1));
    cancelAnimationFrame(raf.current);
    raf.current = requestAnimationFrame(() => {             // 3) 合并
      const el = box.current.querySelector(`[data-idx="${focus + delta}"]`);
      el?.scrollIntoView({ block: 'nearest' });             // 1) 自动滚入
    });
  };
  const onKey = (e) => {
    if (e.key === 'ArrowDown') { e.preventDefault(); move(1); }
    if (e.key === 'ArrowUp') { e.preventDefault(); move(-1); }
    if (e.key === 'Enter') { e.preventDefault(); items[focus] && confirm(items[focus]); }   // 4)
  };
  return <div ref={box} role="listbox" tabIndex={0} onKeyDown={onKey}>
    {visible.map(i => <div key={i} data-idx={i} role="option"
      aria-selected={i === focus}                           // 2)
      className={i === focus ? 'focused' : ''}>{render(items[i])}</div>)}
  </div>;
}
```
