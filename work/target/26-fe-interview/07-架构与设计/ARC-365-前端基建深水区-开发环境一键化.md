## ARC-365：前端基建：开发环境一键化如何设计？
**答**：
- 痛点量化：新人上手成本、跨仓库环境漂移、"只能在那台机器上跑"；解法是把环境声明为代码（devcontainer/Nix/asdf）。
- DevContainer：VS Code Remote 里容器即环境，.devcontainer 定义 Node 版本、扩展、端口、postStart 脚本；本地与 Codespaces 共用一份定义。
- 配套：本地 mock 服务 docker-compose 编排（DB/Redis/依赖服务），pnpm install 后一条 dev 命令起全链路。
- 分级策略：Monorepo 主仓库强制容器化；小工具仓库用 .nvmrc + make dev 降级方案——避免过度工程。
- 度量：新人首次跑通时间（目标 < 30 分钟）、环境相关问题工单数趋势。
```json
// .devcontainer/devcontainer.json
{
  "image": "ghcr.io/example/web-dev:node20",
  "postCreateCommand": "corepack enable && pnpm install && pnpm mock:up",
  "forwardPorts": [5173, 3000],
  "customizations": { "vscode": { "extensions": ["dbaeumer.vscode-eslint", "esbenp.prettier-vscode"] } }
}
```
