## ARC-388：宽表型配置界面（多行多列可编辑）的状态架构如何设计？
**答**:
- 场景：Excel 式批量配置（行 = 对象，列 = 字段），几百行 × 几十列，单元格间有依赖（B 列合法值取决于 A 列）。
- 状态设计：行列归一化 store（rows by id, cols by key），单元格引用 (rowId, colKey) 二元组；校验错误集独立于值集（dirty 分离）。
- 编辑协议：本地编辑态（cell draft）与提交态分离；失焦校验 → 行级批量保存（一行的多列原子提交）→ 失败行标红可重试；不逐格调接口。
- 依赖列：列依赖图（DAG）驱动级联刷新——改 A 列重算 B 列选项与校验；循环依赖在设计期拒绝。
- 性能：虚拟滚动 + 单元格组件 memo（按 (rowId,colKey,value) 精确比较）；粘贴批量导入走解析器 + 批量校验。
```javascript
const grid = createStore({
  rows: normalizedRows(), cols: colDefs(),
  drafts: {}, errors: {},                               // 编辑态与错误集分离
});
function setCell(rowId, key, value) {
  grid.setDraft(rowId, key, value);
  for (const dep of colsDependingOn(key))               // 依赖列级联
    grid.revalidate(rowId, dep);
}
async function saveRow(rowId) {                          // 行级原子提交
  const errs = await validateRow(rowId);
  if (errs) return grid.setErrors(rowId, errs);
  await api.saveRow(rowId, grid.commitDrafts(rowId));
}
```
