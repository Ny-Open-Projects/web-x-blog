## DP-303：笔试题：手写灰度发布决策器？
**答**：实现 ReleaseDecider：1) decide(uid) → v1|v2（白名单 > 回滚指纹 > 比例分桶）；2) 支持运行中调整比例（rampUp(r)）；3) autoStop(窗口指标) 自动回滚（错误率超对照 2 倍置 0）；4) 决策留痕（audit log）。
**评分点**：
- 决策优先级正确（白名单/回滚覆盖分桶）。
- 比例变更不破坏既有分桶稳定性（比例递增时老桶用户不动）。
- 自动回滚的条件判定（窗口+倍数+最小样本）。
- audit 记录完整（谁/何时/前后比例）。
```javascript
class ReleaseDecider {
  constructor(app, { build = 'v2', control = 'v1' } = {}) {
    this.app = app; this.build = build; this.control = control;
    this.ratio = 0; this.audit = [];
    this.whitelist = new Set();
  }
  rampUp(r) {                                          // 2) 递增式调整（分桶单调）
    if (r < this.ratio) throw new Error('放量只增不减，回滚请用 rollback');
    this.audit.push({ op: 'ramp', from: this.ratio, to: r, ts: Date.now() });
    this.ratio = r;
  }
  decide(uid) {
    if (this.whitelist.has(uid)) return this.build;
    const b = hash(`${this.app}:${uid}`) % 100;
    return b < this.ratio ? this.build : this.control;   // 1)
  }
  rollback(operator) {                                  // 3) 配合 autoStop
    this.audit.push({ op: 'rollback', by: operator, ts: Date.now() });
    this.ratio = 0;
  }
  autoStop(metrics) {                                   // 3) 止损引擎
    if (metrics.gray.sample < 300) return false;        // 最小样本
    if (metrics.gray.errRate > metrics.control.errRate * 2) { this.rollback('auto'); return true; }
    return false;
  }
}
```
