## ARC-562：设计规范一致性巡检
**答**:
- 问题：规范写在文档里没人看，实现漂移（间距随手 13px/颜色近似值）只有人眼走查能发现——走查贵且滞后。自动化巡检：从代码/渲染结果检测规范违反。
- 巡检层次：静态层（源码扫描：裸色值/魔法数/未用组件库——lint 层 ARC-561）、运行层（DOM 检查：实际渲染的样式与 token 比对——捕获运行时注入样式/内联样式违规）、视觉层（快照对比规范基准——ARC-319 视觉回归的规范特化：不是"有没有变化"而是"是否符合规范"）。
- 巡检产出：规范违规清单（按页面/组件归属 → owner 开单）、违规趋势（收敛还是扩散）、典型违规案例库（教育材料）。
- 与设计协作：巡检规则与设计规范同源（规范即数据：规范文档结构化 → 巡检规则生成——防"文档规范"与"巡检规则"两套口径漂移）。
- 尺度把控：巡检是引导不是审判——新页面严查、存量渐进收敛，误报率高的规则先降级为提示。
```javascript
// 运行层巡检：DOM 样式与 token 比对
function auditComputedStyles(page, tokens) {
  return page.evaluate((tokens) => {
    const violations = [];
    for (const el of document.querySelectorAll('*')) {
      const color = getComputedStyle(el).color;
      if (isRawHex(color) && !tokenMaps(color, tokens))
        violations.push({ el: el.tagName + '.' + el.className, style: color }); // 裸色值违规
    }
    return violations;
  }, tokens);
}
```
