## ARC-838：手写发布状态机

**答**：实现应用发布的完整状态机 `ReleaseStateMachine`：① 状态：draft → ci-passing → canary(灰度中) → full(全量) → done；旁路：canary → rolled-back；full → hotfixed(热修) → done；② 每次状态迁移需满足 guard 条件：ci-passing 需要「CI 全绿 + 门禁全过」、canary→full 需要「灰度指标达标 + 灰度时长 ≥ 最短观察」；③ 迁移的不可逆点：full 之后只能 hotfix 不能回滚（用户已消费新数据——数据兼容）；④ 状态持久化：状态机崩溃恢复（当前状态 + 审计日志从持久层恢复）；⑤ 并发发布防护：同一应用同时只允许一个活跃发布（活跃锁）。写出实现。

```javascript
const TRANSITIONS = {
  draft: { 'ci-pass': 'ci-passing' },
  'ci-passing': { 'start-canary': 'canary', abort: 'draft' },
  canary: { promote: 'full', rollback: 'rolled-back' },
  full: { hotfix: 'hotfixed', complete: 'done' },
  hotfixed: { complete: 'done' },
  'rolled-back': {},
  done: {},
};

class ReleaseStateMachine {
  #state = 'draft'; #audit = []; #persist;
  constructor(persistFn) { this.#persist = persistFn; this.#restore(); }
  async transition(event, context) {
    const targets = TRANSITIONS[this.#state];
    if (!targets?.[event]) throw new Error(`非法迁移: ${this.#state} + ${event}`);
    // guard 条件
    const guard = GUARDS[event];
    if (guard) {
      const ok = await guard(context);
      if (!ok.pass) throw new Error(`guard 失败: ${ok.reason}`);
    }
    const prev = this.#state;
    this.#state = targets[event];
    this.#audit.push({ from: prev, event, to: this.#state, t: Date.now(), ...context });
    await this.#persist(this.#state, this.#audit);     // 持久化(崩溃恢复)
    if (this.#state === 'full' || this.#state === 'canary') acquireLock(context.appId);  // 并发防护
    return this.#state;
  }
  #restore() { /* 从持久层恢复 state + audit */ }
}
const GUARDS = {
  'ci-pass': async (ctx) => ctx.ciGreen && ctx.gatesPass ? { pass: true } : { pass: false, reason: 'CI 或门禁未过' },
  promote: async (ctx) => ctx.grayMetricsOk && ctx.grayDuration >= 3600e3
    ? { pass: true } : { pass: false, reason: '灰度指标未达标或观察不足' },
};
```

**评分点**：
- 完整状态图（含旁路 rolled-back/hotfixed）
- guard 条件的可执行化（CI/灰度指标/时长——数据驱动迁移）
- full 后不可回滚的认知（数据兼容——只能 hotfix）
- 状态持久化恢复 + 并发发布锁
