## DP-217：源码识别：虚拟列表与无限滚动源码中的策略模式？
**答**:
- 策略模式：布局策略三选一——定高（乘法）、动态高（测量缓存+前缀和）、无限滚动（滚动接近尾部触发加载）。react-virtualized 的 cellSizeGetter/react-virtual 的 estimateSize 都是这个接口。
- 备忘录：动态高度的核心缓存——itemHeightMap（测量结果 memo），二次滚动命中缓存零测量。
- 代理：滚动容器被代理，消费者看到的是"完整列表 API"（scrollToIndex），内部换算成可视窗口渲染——react-virtual 的 useVirtualizer 返回 virtualItems 就是这层代理。
- 识别要点：能指出 overscan 的策略参数化与"测量-渲染"两阶段（先估算渲染 → IntersectionObserver/ResizeObserver 回填缓存）。

```javascript
// 虚拟列表布局策略
const fixedStrategy = {                       // 定高
  estimate: () => 40,
  offsetAt: (i, size) => i * size,
};
const dynamicStrategy = (measureCache) => ({  // 动态高（带缓存）
  estimate: (i) => measureCache.get(i) ?? 44, // 未测量的估算默认
  offsetAt: (i) => prefixSum(measureCache, i),// 前缀和 O(1) 查询偏移
});
function useVirtual({ count, overscan = 5, strategy }) {
  const [range, setRange] = useState({ start: 0, end: 0 });
  const onScroll = rAF(() => { const st = container.scrollTop;
    let start = 0; while (strategy.offsetAt(start) < st) start++;      // 二分优化点
    setRange({ start: Math.max(0, start - overscan), end: Math.min(count, start + viewportRows + overscan) });
  });
  return { range, items: slice(range), measure: (i, h) => measureCache.set(i, h) };  // 代理暴露
}
```
