## ARC-437：Hybrid 离线包与动态化架构
**答**:
- 离线包 = 业务资源（HTML/JS/CSS）打 zip 包，App 启动/空闲时预下载到本地，WebView 请求拦截器命中本地直返——秒开的核心手段。
- 包管理协议：包清单（版本/MD5/资源路径映射）+ 差量更新（bsdiff/基于文件哈希只下变更文件）+ 灰度发布（包版本按用户分桶下发）+ 强更/弱更策略。
- 动态化分级：纯 H5（发离线包即动态）、逻辑动态化（JS 沙箱动态下发脚本：JSCore/QuickJS）、配置动态化（服务端 JSON 驱动 UI）。风险与审批强度递增，禁止下发任意原生代码。
- 安全：包签名校验（防篡改与劫持）、HTTPS + 证书锁定、JS 沙箱无原生 API 白名单外权限。
- 兜底：离线包未就绪 → 在线加载；版本回滚保留上一版本可用（双版本共存窗口）。
```javascript
// WebView 离线包拦截（Android 伪码）
webview.webViewClient = object : WebViewClient() {
  override fun shouldInterceptRequest(view: WebView, req: WebResourceRequest): WebResourceResponse? {
    val local = pkgManager.resolve(pkgId, req.url)          // 清单映射：url → 本地文件
    return local?.let { streamResponse(it) }                // 命中返回本地
  }
}
// 清单：{ version: 42, files: { "/js/app.8f3a.js": "local://pkg42/app.js" } }
```
