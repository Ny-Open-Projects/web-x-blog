## ARC-631：分账与佣金展示
**答**:
- 分账模型：一笔交易多角色分钱（平台/商家/推广者/服务商——分账规则服务端计算，前端展示分账明细——ARC-460 涉账：金额与比例服务端权威，前端不推算）。
- 展示架构：分账明细组件（每角色一行：角色/金额/状态——分账状态机：待分账/分账中/已到账/失败）、佣金账单（推广者视角：佣金明细/提现入口 ARC-621）、规则透明化（分账规则说明——比例与计算口径展示，减少纠纷）。
- 状态联动：分账进度推送（到账通知 ARC-394）、失败处理（分账失败 → 补偿展示 + 客服入口——涉资失败不静默）、退款冲正（退款后佣金扣回——明细展示负向流水）。
- 一致性：多角色多端（商家端/推广者端各自视图——同一分账单多端口径一致，服务端单源）、时间口径（分账周期：T+1 结算——结算日历展示）。
- 合规：分账协议展示（电子协议签署 ARC-527）、税务提示（代扣代缴说明文案）。
```javascript
// 分账明细
const split = await api.settlementDetail(orderId);               // [{role, amount, state, ruleRef}]
<SplitTable rows={split} />                                      // 状态机渲染
bus.on('settlement.paid', ({ orderId }) => refreshBill());       // 到账刷新佣金账单
```
