## ARC-238：权限快照的调试与可视化工具如何做？
**答**：
- 痛点场景："这个按钮为什么我看得到/看不到"——排查要跨快照、路由表、组件注解三层，没工具全靠读代码。
- 工具形态：DevTools 面板（浏览器插件或 debug 页面）三视图——快照视图（当前生效权限码+版本+来源）、判定视图（输入任意 `resource:action` 实时看 can() 结果与命中规则）、页面视图（当前页每个 perm 点位的判定结果标注）。
- 模拟角色：测试不换账号直接"以角色 X 视角"模拟快照（仅 dev 环境），瞬间验证矩阵各格。
- 归因上报：每次 can() 判定可选埋点（采样），线上问题直接回放"当时快照+判定结果"。

```typescript
// dev 权限调试器
if (import.meta.env.DEV) {
  window.__permDebug = {
    snapshot: () => store.get('perm'),
    check: (resource, action) => ({ result: can(store.get('perm'), action, resource) }),
    asRole(role: string) {                 // 模拟角色（仅 dev）
      store.set('perm', buildSnapshotFixture(role));
      rebuildRoutes(store.get('perm'));
    },
  };
}
// 页面视图：PerfPanel 扫描当前渲染树里所有 WithPerm 节点，列出 perm 与判定结果，悬浮显示命中的权限码
```
