## ARC-406：笔试题：手写错误指纹算法与归并
**答**：实现 fingerprint(error)：对 JS 错误生成稳定指纹——堆栈取前 3 帧、剥离行号列号、变量值归一化（数字/字符串替换为占位符）；同指纹聚合计数。
**评分点**：
- 堆栈前 3 帧取函数名与文件（不含 line:col，防行号漂移聚不了类）。
- 动态值归一化（`Error: xxx id=123` → `id=?`）。
- 稳定哈希输出（简单 djb2 即可）。
- 同指纹计数与首末次时间记录。
```javascript
function normalize(frame) {
  return frame.replace(/:\d+:\d+/g, '')                    // 剥离行列号
              .replace(/https?:\/\/\S+?\/([\w.-]+)$/,'$1'); // 文件名化
}
function fingerprint(err) {
  const frames = (err.stack || err.message).split('\n').slice(0, 4)  // 消息+前3帧
    .map(normalize)
    .map(s => s.replace(/\b\d+\b/g, '?').replace(/(["']).*\1/g, '"?"')); // 归一化
  let h = 5381;
  for (const s of frames) for (const c of s) h = ((h << 5) + h + c.charCodeAt(0)) >>> 0;
  return { hash: h.toString(36), key: frames.join('|') };
}
// 归并存储
const groups = new Map();
function collect(err) {
  const fp = fingerprint(err);
  const g = groups.get(fp.hash) ?? { count: 0, first: Date.now(), sample: err, key: fp.key };
  g.count++; g.last = Date.now(); groups.set(fp.hash, g);
}
```
