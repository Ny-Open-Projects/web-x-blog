## ARC-835：手写协作健康度探针

**答**：实现跨团队协作健康度的自动化探针 `CollabProbes`：① 探针集：评审响应时长（跨团队 PR 的首响时间）、变更通知漏接率（破坏性变更后仍在用旧 API 的团队数）、依赖等待时长（跨团队需求的等待天数）、会议有效率（有决议的会议占比）——从系统数据自动采集；② 探针的阈值与恶化检测：连续 N 个周期恶化 → 协作健康告警（不是单点差而是趋势差）；③ 探针的归因辅助：恶化指标关联具体事件（某团队扩编/某平台变更）；④ 输出：协作健康度雷达（5 维度）+ 恶化趋势清单 + 建议。写出实现。

```javascript
class CollabProbes {
  #data = new Map();   // probe -> [{ period, value }]
  registerProbe(name, collector) { this.#collectors.set(name, collector); }
  async collect(period) {
    for (const [name, collector] of this.#collectors) {
      const value = await collector();
      (this.#data.get(name) ?? this.#data.set(name, []).get(name)).push({ period, value });
    }
  }
  analyze() {
    const report = {};
    for (const [name, series] of this.#data) {
      const values = series.map((s) => s.value);
      const trend = trendDirection(values.slice(-4));   // 最近4期趋势
      const worsening = trend === 'worsening';
      // 归因: 恶化期的事件关联
      const relatedEvents = worsening ? findEventsInRange(series.at(-2).period, series.at(-1).period) : [];
      report[name] = { current: values.at(-1), trend, worsening, relatedEvents };
    }
    const radar = { review: score(report['review-latency']), notice: score(report['notice-miss']),
      wait: score(report['dep-wait']), meeting: score(report['meeting-effective']),
      crossTeamDelivery: score(report['cross-team-leadtime']) };
    return { radar, degrading: Object.entries(report).filter(([, r]) => r.worsening).map(([k]) => k) };
  }
}
```

**评分点**：
- 探针的系统化采集（git/工单自动——非手工填报）
- 趋势恶化检测（连续 N 周期——非单点）
- 归因辅助（恶化期事件关联——数据定位访谈归因）
- 雷达可视化（5 维度健康度一目了然）
