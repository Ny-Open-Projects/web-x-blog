## DP-326：笔试题：手写白屏检测（采样判定）？
**答**：实现白屏检测：1) 关键容器检查（selector 列表：空/高度 0）；2) onload + 2s 判定窗口；3) 命中后追加二次确认（再等 1s 复查，防误报）；4) 附带资源加载上下文（失败的资源清单）。
**评分点**：
- 判定条件完备（DOM 空/高度/纯 loading）。
- 二次确认防误报。
- 资源失败上下文（performance entries 过滤）。
- 采样率控制（防上报洪峰）。
```javascript
function detectWhiteScreen(selectors, report) {
  const check = () => selectors.every(s => {
    const el = document.querySelector(s);
    return !el || el.offsetHeight < 5 || el.children.length === 0;   // 1) 判定
  });
  const scan = () => {
    if (!check()) return;
    setTimeout(() => {                                   // 3) 二次确认
      if (!check()) return;
      const failed = performance.getEntriesByType('resource')
        .filter(r => r.responseStatus === 0 || r.transferSize === 0 && r.decodedBodySize === 0)
        .map(r => r.name).slice(0, 10);                  // 4) 失败资源
      report({ type: 'white-screen', url: location.href, failed, ua: navigator.userAgent });
    }, 1000);
  };
  if (document.readyState === 'complete') scan();
  else addEventListener('load', () => setTimeout(scan, 2000), { once: true });   // 2) 窗口
}
// 上报采样：report = rate(0.1, fn) —— 白屏事件本身可全量（p0 级别），PV 级采样用于分母
```
