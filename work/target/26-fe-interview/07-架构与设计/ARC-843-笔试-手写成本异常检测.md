## ARC-843：手写成本异常检测

**答**：实现前端成本的异常检测器 `CostAnomalyDetector`：① 成本流：每日各应用成本数据（CDN/构建/监控——按应用分摊）；② 基线模型：每应用每成本项的「滚动 30 天基线」（中位数 + MAD 波动范围）——自适应基线（非固定阈值）；③ 异常判定：当日成本超出基线上界（中位数 + 3×MAD）→ 异常（涨幅 % 排序）；④ 异常归因提示：CDN 异常 → 检查新增大资源；构建异常 → 检查缓存失效；⑤ 异常报告：日异常清单 + 周趋势（成本治理的输入）。写出实现。

```javascript
class CostAnomalyDetector {
  #history = new Map();   // app+costType -> [{ date, amount }]
  ingest(app, costType, date, amount) {
    const key = `${app}:${costType}`;
    (this.#history.get(key) ?? this.#history.set(key, []).get(key)).push({ date, amount });
  }
  detect(day) {
    const anomalies = [];
    for (const [key, series] of this.#history) {
      const past = series.filter((s) => s.date < day).slice(-30).map((s) => s.amount);
      if (past.length < 14) continue;                  // 基线不足
      const med = median(past);
      const mad = median(past.map((v) => Math.abs(v - med)));
      const today = series.find((s) => sameDay(s.date, day))?.amount ?? 0;
      const upper = med + 3 * mad * 1.4826;            // MAD→σ 近似
      if (today > upper && med > 0) {
        anomalies.push({ key, today, baseline: Math.round(med),
          increase: +(((today - med) / med) * 100).toFixed(0) + '%',
          hint: hintFor(key.split(':')[1]) });
      }
    }
    return anomalies.sort((a, b) => b.increase.localeCompare(a.increase, undefined, { numeric: true }));
  }
}
function hintFor(costType) {
  return { cdn: '检查新增大资源/未压缩图片/爬虫流量',
    ci: '检查缓存失效导致的构建增量',
    monitor: '检查采样率变更/错误率暴涨' }[costType] ?? '人工排查';
}
// MAD 基线: 自适应(大促流量自然上涨不误报), 3×MAD 抗离群
```

**评分点**：
- 滚动中位数 + MAD 自适应基线（大促自然上涨不误报——比固定阈值优）
- 3×MAD 系数的抗离群选择
- 归因提示按成本类型分派（CDN/CI/监控各自排查看哪里）
- 基线不足期的保护（<14 天不判定）
