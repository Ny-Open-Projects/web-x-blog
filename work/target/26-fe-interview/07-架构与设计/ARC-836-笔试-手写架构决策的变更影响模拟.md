## ARC-836：手写变更影响模拟

**答**：实现架构变更的「影响面模拟器」`ImpactSimulator`：① 依赖图输入：模块依赖图（import 关系构建）；② 模拟变更：`simulate(modifyModule)`——计算直接受影响（直接 import 该模块的模块）与传递影响（递归下游）；③ 影响面分级：直接受影响（必须改）/间接受影响（可能要改）/不受影响——三级清单；④ 测试范围建议：受影响模块关联的测试文件清单（回归范围最小化）；⑤ 影响面报告：变更工作量估算（受影响模块数 × 平均改造人日）——变更成本的量化。写出实现。

```javascript
class ImpactSimulator {
  #graph;             // Map<module, Set<dependent>> (反向图: 谁依赖我)
  constructor(importGraph) {
    this.#graph = new Map();
    for (const [mod, deps] of importGraph)
      for (const d of deps)
        (this.#graph.get(d) ?? this.#graph.set(d, new Set()).get(d)).add(mod);
  }
  simulate(module) {
    const direct = [...(this.#graph.get(module) ?? [])];
    const transitive = new Set();
    const queue = [...direct];
    while (queue.length) {
      const m = queue.shift();
      for (const dep of this.#graph.get(m) ?? [])
        if (!transitive.has(dep) && !direct.includes(dep)) { transitive.add(dep); queue.push(dep); }
    }
    const tests = [...direct, ...transitive].flatMap((m) => testFilesFor(m));
    const effortDays = +(direct.length * 0.5 + transitive.size * 0.2).toFixed(1);
    return { direct, transitive: [...transitive], suggestedTests: [...new Set(tests)], effortDays };
  }
}
// 用法: importGraph = { 'store/cart': ['ui/CartList', 'ui/MiniCart'], 'ui/CartList': ['page/Checkout'] }
// simulate('store/cart') → { direct: ['ui/CartList','ui/MiniCart'],
//   transitive: ['page/Checkout'], suggestedTests: [...], effortDays: 1.4 }
```

**评分点**：
- 反向依赖图的构建（谁依赖我——影响面方向）
- BFS 传递影响（直接/间接分级清单）
- 测试范围建议（受影响模块 → 回归最小集）
- 工作量量化（影响面 → 人日估算——变更成本可视化）
