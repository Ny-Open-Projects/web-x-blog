## ARC-636：多店铺后台
**答**:
- 店切换 = 环境切换：店铺维度数据完全隔离（ARC-559/428 切换协议——内存清/WS 重建/缓存命名空间/URL 带 shopId）、店铺上下文贯穿（请求头 x-shop-id——NODE-395 服务端对应）。
- 权限差异：同账号不同店铺不同角色（店 A 管理员店 B 员工）——切换后权限快照重拉（ARC-550）、菜单/操作集按店铺权限渲染。
- 数据隔离细节：报表/导出/消息按店铺隔离（导出范围校验 ARC-630）、跨店功能显式（汇总视图：需要跨店权限才显示——汇总口径说明）。
- 体验设计：当前店铺标识常显（全局头：店铺名 + 切换器——防"在错的店操作"事故）、最近店铺快捷切换、切换中的加载态（重置宇宙的过渡——用户理解在切换）。
- 防呆：跨店操作拦截（A 店订单详情 URL 手输到 B 店会话 → 403 页面 + 切换引导——深链与店铺上下文校验 ARC-389）。
```javascript
async function switchShop(shopId) {
  await api.switchContext(shopId);                               // 服务端新会话上下文
  store.resetAll(); ws.reconnect(); idb.clearNamespace(prev);    // 重置宇宙
  const perms = await permStore.refresh();                       // 店铺权限重拉
  router.apply(perms); location.reload();                        // 重载兜底
}
// 深链校验：route guard 校验 route.shopId === currentShop，否则 403 + 切换引导
```
