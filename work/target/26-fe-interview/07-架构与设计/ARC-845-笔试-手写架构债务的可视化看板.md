## ARC-845：手写债务看板

**答**：实现架构债务的可视化看板数据层 `DebtBoard`：① 债务录入：{ type(框架/依赖/规范/性能/安全), desc, location, severity, interest(每迭代成本), payoff }；② 看板视图数据：按类型分组/按 severity 排序/按 owner 分组——三种切片；③ 趋势数据：债务总量趋势（新增 vs 偿还——净债务曲线）；④ 热点标注：利息最高的 Top5（优先偿还建议）；⑤ 与需求联动：债务项关联业务需求（该债阻塞哪些需求——债务的业务影响量化）。写出实现。

```javascript
class DebtBoard {
  #debts = []; #resolved = [];
  add(debt) { this.#debts.push({ ...debt, id: crypto.randomUUID(), addedAt: Date.now(), status: 'open' }); }
  resolve(id, how) {
    const idx = this.#debts.findIndex((d) => d.id === id);
    if (idx < 0) return;
    const [d] = this.#debts.splice(idx, 1);
    this.#resolved.push({ ...d, resolvedAt: Date.now(), how });
  }
  slices() {
    const byType = groupSum(this.#debts, 'type', (d) => d.interest);
    const byOwner = groupSum(this.#debts, 'owner', (d) => d.interest);
    const bySeverity = [...this.#debts].sort((a, b) => b.severity - a.severity);
    return { byType, byOwner, topInterest: bySeverity.slice(0, 5) };
  }
  trend() {
    // 净债务曲线: 新增(利息) - 偿还(利息) per sprint
    return { openInterest: this.#debts.reduce((s, d) => s + (d.interest ?? 0), 0),
      resolvedCount: this.#resolved.length,
      note: this.#resolved.length > this.#debts.length ? '净偿还中' : '净新增中' };
  }
  blockingRequirements(requirements) {                  // 债务的业务影响
    return requirements.map((r) => ({
      requirement: r.id,
      blockedBy: this.#debts.filter((d) => r.blockedBy?.includes(d.id)).map((d) => d.desc),
    })).filter((x) => x.blockedBy.length);
  }
}
```

**评分点**：
- 三种切片（类型/owner/severity——不同受众视图）
- 净债务趋势（新增 vs 偿还——治理方向判断）
- Top 利息热点（优先偿还建议）
- 债务的业务影响联动（阻塞需求——债务价值化）
