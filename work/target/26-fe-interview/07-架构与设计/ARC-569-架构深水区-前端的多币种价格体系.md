## ARC-569：多币种价格体系
**答**:
- 币种三态：定价币种（商品标价币种）、展示币种（用户偏好换算）、结算币种（支付通道实际币种）——三者可不同，协议要显式（每种价格带 currency 字段，永不含糊）。
- 换汇架构：汇率来源（服务端锁定成交汇率——下单时锁定，支付时用锁定汇率；展示用参考汇率实时换算，标注"仅供参考"）、精度（换算保留规则显式：支付金额向上取整防短收）。
- 展示格式：Intl.NumberFormat currency（ARC-482/481 收口）、双币展示（本地币 + 原价参考）、零小数币种（日元/韩币无分——精度按币种配置，不统一 ×100）。
- 一致性红线：订单金额换算后与支付金额一致（锁定汇率贯穿）、退款按原支付币种原额退（换汇损失规则业务显式）。
- 前端收口：价格组件统一（所有金额展示走 Price 组件：自动处理币种/精度/千分位/双币）——散写 format 是漂移温床。
```javascript
// 价格组件协议
<Price value={order.amount} currency={order.currency}           // 定价币种
  display={userCurrency} rate={order.lockedRate}                // 展示换算（锁定汇率）
  minorUnits={CURRENCY_SPEC[order.currency].minor} />           // 币种精度（JPY=0）
// 换算：Math.ceil(amount * lockedRate)  // 支付金额向上取整防短收
```
