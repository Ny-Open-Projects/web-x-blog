## DP-218：源码识别：d3 与图表库源码中的比例尺与观察者？
**答**：
- 策略/适配：d3-scale 是"数据域→像素域"的映射策略集（linear/log/time/band），同一 domain/range 接口不同实现——DP-175 图表库设计里比例尺就是核心策略。
- 观察者：d3-dispatch（dispatch.on）是显式事件系统；ECharts 的 setOption → chart.on('click') 同理；tooltip/legend 联动是 chart 级发布订阅。
- 组合模式：d3-selection 的 select/append/merge 链是"选择集"的组合操作；ECharts option 里 series/grid/axis 的树形配置也是组合。
- 识别要点：能说清"比例尺策略可替换 → 切换 log 轴不改上层代码"，这是策略模式价值的最小案例。

```javascript
// d3-scale 策略集
function linearScale(domain, range) {
  const [d0, d1] = domain, [r0, r1] = range;
  const k = (r1 - r0) / (d1 - d0);
  const scale = x => r0 + (x - d0) * k;
  scale.invert = y => d0 + (y - r0) / k;          // 双向映射（tooltip 反查数据用）
  return scale;
}
function logScale(domain, range) {                 // 同接口，替换策略
  const l = linearScale(domain.map(Math.log), range);
  const scale = x => l(Math.log(x));
  scale.invert = y => Math.exp(l.invert(y));
  return scale;
}
// 图表内部只依赖 scale 接口：xAxis(scale), bars(data.map(d => [scale(d.x), height - yScale(d.y)]))
// 切换 log 轴：chart.option({ xAxis: { scale: logScale } }) —— 上层零改动
```
