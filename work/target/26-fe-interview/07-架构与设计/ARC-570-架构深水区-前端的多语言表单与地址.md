## ARC-570：多语言表单（地址/姓名/电话）
**答**:
- 地址表单国际化：字段结构按国家差异（中国省市区三级/美国州+邮编/日本都道府县/中东无邮编）——地址 schema 注册表（每国家字段结构 + 校验规则），选择国家动态渲染字段。
- 数据规范：地址存储结构化（国家码 ISO3166 + 各字段独立存储）而非整串文本（不可解析不可国际化）；姓名分姓/名字段差异（部分文化无姓）、拉丁转写字段（跨语言展示）。
- 电话：国家区号 + 号码格式校验（libphonenumber 矩阵）、显示格式本地化、OTP 场景与手机号规范化（E.164 标准存储）。
- 邮编/证件：按国家规则校验（邮编格式/身份证类型注册表——证件类型按国家枚举）。
- 校验与提示：错误文案 locale 化（ARC-384 错误协议 + i18n）、输入辅助（邮编自动补城市、电话格式自动格式化）。
```javascript
// 地址 schema 注册表
const addressSchemas = {
  CN: { fields: ['province', 'city', 'district', 'detail'], postcode: { pattern: /^\d{6}$/, optional: false } },
  US: { fields: ['state', 'city', 'street', 'zip'], postcode: { pattern: /^\d{5}(-\d{4})?$/ } },
  JP: { fields: ['prefecture', 'city', 'detail'], postcode: { pattern: /^\d{3}-\d{4}$/ } }
};
function AddressForm({ country }) {
  const schema = addressSchemas[country];                        // 动态字段
  return schema.fields.map(f => <Field key={f} name={f} schema={schema[f]} />);
}
```
