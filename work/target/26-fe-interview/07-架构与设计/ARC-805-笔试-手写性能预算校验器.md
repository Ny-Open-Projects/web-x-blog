## ARC-805：手写性能预算校验器

**答**：实现性能预算校验 `checkBudget(buildOutput, budget, prev)`：① 预算配置：{ jsKB: 300, cssKB: 80, imgKB: 500, lcp: 2500, inp: 200 }——支持按页面粒度（每页面独立预算）；② 校验：构建产物体积分组统计（js/css/img）vs 预算 + Lighthouse 实测指标 vs 预算——两类校验；③ 增量模式：与上次构建 diff——新增超过预算的文件标注（谁引入的——git blame）；④ 豁免机制：白名单文件（legacy 模块——带期限）；⑤ 输出：pass/fail + 超预算清单 + 增量 blame + exit code。写出实现。

```javascript
function checkBudget(output, budget, prev, { whitelist = [], blameMap } = {}) {
  const results = { pass: true, violations: [], newFiles: [] };
  // 体积分组校验
  const groups = { js: 0, css: 0, img: 0 };
  for (const f of output.files) {
    if (whitelist.includes(f.path)) continue;         // 豁免
    const ext = f.path.match(/\.(js|css|png|jpe?g|webp)$/)?.[1];
    if (!ext) continue;
    groups[ext === 'png' || ext === 'webp' || ext.startsWith('jp') ? 'img' : ext] += f.size;
  }
  for (const [type, limit] of Object.entries(budget)) {
    if (type in groups && groups[type] > limit * 1024) {
      results.pass = false;
      results.violations.push({ type, actualKB: Math.round(groups[type] / 1024), budgetKB: limit });
    }
  }
  // 指标校验
  for (const [metric, limit] of Object.entries(budget).filter(([k]) => ['lcp', 'inp'].includes(k)))
    if (output.metrics?.[metric] > limit) {
      results.pass = false;
      results.violations.push({ metric, actual: output.metrics[metric], budget: limit });
    }
  // 增量 blame: 新增/增大文件 → 责任人
  if (prev) for (const f of output.files) {
    const old = prev.files.find((x) => x.path === f.path);
    if (!old || f.size - old.size > 10 * 1024) {
      const owner = blameMap?.[f.path] ?? 'unknown';
      results.newFiles.push({ path: f.path, deltaKB: Math.round((f.size - (old?.size ?? 0)) / 1024), owner });
    }
  }
  if (!results.pass) console.error('BUDGET FAIL', JSON.stringify(results.violations));
  process.exit(results.pass ? 0 : 1);
}
```

**评分点**：
- 体积分组校验 + 指标校验两类（构建期 + 运行期）
- 豁免白名单带期限的机制
- 增量 blame（超预算归因到人——可行动）
- 页面粒度预算的支持
