## DP-481：笔试：手写事件总线

**答**：实现 EventBus：① on/once/off/emit 基础四件套；② 命名空间订阅：on('user', fn, 'page-A') + offNamespace('page-A') 批量退订（组件卸载防泄漏）；③ once 的正确实现（触发后自动移除——不重复触发）；④ emit 的错误隔离（单 handler 异常不中断其他 handler——try/catch + 上报）；⑤ 通配订阅：on('user.*') 匹配 user.created/user.deleted；⑥ emit 时快照遍历（遍历中新增/删除 handler 的防御）。写出实现。

```javascript
class EventBus {
  #subs = new Map();       // type -> Set<{ fn, ns }>
  on(type, fn, ns) {
    const set = this.#subs.get(type) ?? this.#subs.set(type, new Set()).get(type);
    const entry = { fn, ns };
    set.add(entry);
    return () => set.delete(entry);                 // 返回退订
  }
  once(type, fn, ns) {
    const off = this.on(type, (...a) => { off(); fn(...a); }, ns);
    return off;
  }
  off(type, fn) { this.#subs.get(type)?.forEach((h) => { if (h.fn === fn) this.#subs.get(type).delete(h); }); }
  offNs(ns) { for (const set of this.#subs.values()) for (const h of [...set]) if (h.ns === ns) set.delete(h); }
  emit(type, payload) {
    for (const [pattern, set] of this.#subs) {
      const re = new RegExp(`^${pattern.replace(/\./g, '\\.').replace(/\*/g, '[^.]+')}$`);
      if (!re.test(type)) continue;
      for (const h of [...set]) {                   // 快照: 防遍历中修改
        try { h.fn(payload); }
        catch (e) { reportError(e); }               // 错误隔离
      }
    }
  }
}
// 组件卸载: onUnmounted(() => bus.offNs('page-A')) — 防泄漏
```

**评分点**：
- once 不重复触发（off 内嵌实现）
- 命名空间批量清理（订阅泄漏的工程解）
- emit 快照遍历 + 错误隔离（遍历中修改与 handler 崩溃的防御）
- 通配符的正则转义（. 转义、* 语义）
