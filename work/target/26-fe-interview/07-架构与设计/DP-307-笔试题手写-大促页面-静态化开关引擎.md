## DP-307：笔试题：手写大促页面静态化开关引擎？
**答**：实现 StaticEngine：1) 页面分块渲染（区块注册器：动态块/静态块）；2) 开关系统：动态块可降级为缓存快照；3) 快照过期检查（TTL+版本）；4) 全部降级时页面仍可渲染（静态壳兜底）。
**评分点**：
- 区块注册器接口清晰（render/getSnapshotId）。
- 降级路径完整（动态→缓存→骨架兜底）。
- 快照版本与 TTL 双校验。
- 降级原因上报。
```javascript
class StaticEngine {
  blocks = new Map();
  register(id, { render, ttl = 300_000, version = 'v1' }) {   // 1) 注册器
    this.blocks.set(id, { render, ttl, version });
  }
  async renderBlock(id, flags) {                              // 2) 开关系统
    const b = this.blocks.get(id);
    if (!flags[`block:${id}:static`]) {
      try { return { id, html: await b.render() }; }           // 动态
      catch (e) { report({ type: 'block-fallback', id, err: String(e) }); }  // 4) 上报
    }
    const snap = cache.get(`${id}:${b.version}`);
    if (snap && Date.now() - snap.ts < b.ttl) return { id, html: snap.html };  // 3) 双校验
    return { id, html: `<div data-skeleton="${id}"></div>` };  // 4) 骨架兜底
  }
  async renderPage(flags) {
    const out = await Promise.all([...this.blocks.keys()].map(id => this.renderBlock(id, flags)));
    return out.map(o => o.html).join('\n');
  }
}
// 大促预案：degrade.setFlag('block:home:feed:static', true) → feed 走缓存快照
```
