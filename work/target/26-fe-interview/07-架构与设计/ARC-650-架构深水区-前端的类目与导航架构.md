## ARC-650：类目与导航架构
**答**:
- 类目模型：多级类目树（类目懒加载 ARC-485 + 类目属性（筛选维度：品牌/价格区间——类目驱动的筛选 schema——服务端按类目下发筛选配置））。
- 导航架构：类目导航交互（侧边类目/顶部 Tab/面包屑——多级路径定位 ARC-508）、筛选面板（类目属性驱动动态渲染——属性联动 ARC-484）、当前路径状态（类目路径入 URL——可分享可回退）。
- 性能：类目树缓存（全量类目树版本化缓存——低频变更长缓存 + 版本失效）、类目切换预取（高频类目列表预取 ARC-405）。
- 一致性：类目与商品归属（类目调整（迁移/下线）→ 商品列表与筛选联动——类目版本一致性：筛选 schema 版本与列表接口版本对齐）、SEO（类目页 SSR/静态化——ARC-066 类目落地页）。
- 治理：类目树由服务端单源（前端不自建类目——运营配置驱动）、类目变更演练（大调整前灰度）。
```javascript
// 类目驱动的筛选
const cat = await categoryStore.ensure(catId);                   // 类目缓存
const filters = cat.filterSchema;                                // 类目属性下发
<FilterPanel schema={filters} value={urlFilters} />              // 动态筛选渲染
// 类目树：version 标注——服务端改类目 → 版本失效 → 端上重拉
```
