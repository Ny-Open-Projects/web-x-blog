## ARC-485：树形数据架构：懒加载、勾选与虚拟化协同
**答**:
- 数据模型：节点归一化（id → node Map + children 引用），树操作 O(1) 定位；懒加载协议（节点带 hasChildren + load(id)），展开即取子级。
- 勾选联动三态：勾选语义分"含子级"（父勾 = 子全勾，半选态推导）与"独立勾选"两种协议，架构上按业务显式选择；半选计算用计数缓存（每节点记 checkedCount/totalCount，O(1) 更新向上冒泡）。
- 懒加载与勾选冲突：未加载的子树勾选语义——"勾父含未加载子级"需要在提交时服务端展开校验（前端只知道路径不知道全量）；或懒加载树禁用"含子级"语义。
- 虚拟化与树：扁平化遍历（展开态 → 扁平数组含层级缩进），虚拟滚动复用（ARC-442）；展开/收起只改扁平数组，不重建 DOM。
- 大树性能：万级节点展开用 requestAnimationFrame 分批展开 + 过滤搜索（命中路径自动展开）。
```javascript
// 归一化树 + 半选冒泡
const tree = { nodes: new Map(), rootIds: [] };
function setChecked(id, v) {
  const n = tree.nodes.get(id);
  n.checked = v;
  applyDown(n, v);                                            // 向下传播
  let p = n.parentId;
  while (p) {                                                  // 向上重算半选
    const pn = tree.nodes.get(p);
    pn.checkedCount = countChecked(pn);
    pn.checked = pn.checkedCount === pn.total;
    pn.indeterminate = pn.checkedCount > 0 && pn.checkedCount < pn.total;
    p = pn.parentId;
  }
}
```
