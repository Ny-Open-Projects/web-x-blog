## DP-535：笔试：手写计价管道

**答**：实现订单价格计算的策略管道：① 管道阶段：基础价 → 满减 → 优惠券 → 会员折扣 → 运费——每阶段一个策略（顺序=业务规则）；② 策略签名：`({ price, cart, applied }) => { price, applied }`——每策略可追加 applied 明细（价格构成透明）；③ 管道的可配置：活动期间插队策略（大促管道插入限时折扣——配置驱动管道组装）；④ 边界守卫：每阶段校验非负（价格不为负——策略管道的防御）；⑤ 明细输出：每阶段的贡献（原价/满减省/券省/折扣省/运费——订单价格明细）。写出实现。

```javascript
const PIPELINE = [
  { name: 'full-reduction', apply: ({ price, cart }) => {
      const reduction = Math.floor(price / 300) * 50;  // 每300减50
      return { price: price - reduction, applied: { fullReduction: -reduction } };
    } },
  { name: 'coupon', apply: ({ price, cart, applied }) => {
      if (!cart.coupon) return { price, applied };
      return { price: price - cart.coupon.value, applied: { ...applied, coupon: -cart.coupon.value } };
    } },
  { name: 'guard', apply: ({ price, applied }) => {
      if (price < 0) throw new Error('价格计算异常: 负数');   // 边界守卫
      return { price, applied };
    } },
];
function calcPrice(cart, pipeline = PIPELINE) {
  return pipeline.reduce(({ price, applied }, stage) => stage.apply({ price, cart, applied }),
    { price: basePrice(cart), applied: {} });
}
// 大促: calcPrice(cart, [...BASE, ...PROMO_STAGES, ...PIPELINE]) — 配置驱动插队
```

**评分点**：
- 管道阶段顺序=业务规则（满减先于券——顺序显式）
- applied 明细（价格构成透明——可审计）
- 边界守卫（负价异常——策略管道的防御）
- 配置驱动插队（大促策略插入——管道可组装）
