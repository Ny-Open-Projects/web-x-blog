## DP-269：源码识别：文件预览源码中的适配器链与降级策略？
**答**:
- 适配器链（核心）：每种格式一个适配器（pdf/docx/xlsx/image/video），统一 canHandle + render 接口，按 MIME 路由——新增格式零侵入。
- 策略（降级）：原生渲染（iframe/img）→ 格式专用库（docx→html）→ 服务端转换（PDF 化）→ 兜底下载，逐级降级。
- 备忘录：转换结果缓存（文件 hash → 预览产物 URL），二次打开零转换。
- 识别要点：大文件适配器的流式处理（分页/分片渲染），以及"预览是只读的"安全边界（脚本剥离）。

```typescript
// 文件预览适配器链
interface PreviewAdapter {
  canHandle(mime: string, ext: string): boolean;
  render(file: FileMeta, host: HTMLElement): Promise<() => void>;  // 返回清理函数
}
const adapters: PreviewAdapter[] = [
  imageAdapter, pdfAdapter, officeAdapter,      // 顺序即优先级
];
function preview(file, host) {
  const ad = adapters.find(a => a.canHandle(file.mime, file.ext));
  const strategy = ad ?? fallbackDownload;      // 降级兜底
  const cached = previewCache.get(file.hash);   // 备忘录
  if (cached) return embed(host, cached);
  return strategy.render(file, host).then(clean => {
    previewCache.set(file.hash, host.innerHTML);
    return clean;
  });
}
// office 适配器内部再降级：try docx→html（mammoth）catch → 服务端转 PDF → catch → 提示下载
```
