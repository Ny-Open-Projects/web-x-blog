## ARC-839：手写架构可视化回归

**答**：实现「架构图的可视化回归」——架构图随代码演进的自动对比：① 基线架构图：从代码生成的模块依赖图快照（JSON 存储——git 版本化）；② 当前图生成：CI 时重新生成当前依赖图；③ diff 分析：新增边（新依赖——是否合规）/删除边（依赖移除）/节点变化（模块增删）——三类变化；④ 变化的语义标注：新边是否违反约束（适应度函数联动）/删除边是否预期（迁移计划中的）；⑤ 输出：架构 diff 报告 + 可视化图（Mermaid 渲染 diff 标注）。写出实现。

```javascript
function archDiff(baseline, current, { fitnessRules, migrationPlan } = {}) {
  const changes = [];
  // 边 diff
  const baseEdges = new Set(baseline.edges.map((e) => `${e.from}→${e.to}`));
  const curEdges = new Set(current.edges.map((e) => `${e.from}→${e.to}`));
  for (const e of current.edges) {
    const key = `${e.from}→${e.to}`;
    if (!baseEdges.has(key)) {
      const violation = fitnessRules?.find((r) => r.violates(e.from, e.to));
      changes.push({ type: 'edge-added', from: e.from, to: e.to,
        semantic: violation ? `违规: ${violation.name}` : migrationPlan?.includes(key) ? '预期(迁移)' : '未标注新依赖' });
    }
  }
  for (const e of baseline.edges)
    if (!curEdges.has(`${e.from}→${e.to}`))
      changes.push({ type: 'edge-removed', from: e.from, to: e.to,
        semantic: migrationPlan?.includes(`${e.from}→${e.to}`) ? '预期(迁移删除)' : '依赖意外移除?' });
  // 节点 diff
  for (const n of current.nodes)
    if (!baseline.nodes.find((x) => x.id === n.id)) changes.push({ type: 'node-added', id: n.id });
  for (const n of baseline.nodes)
    if (!current.nodes.find((x) => x.id === n.id)) changes.push({ type: 'node-removed', id: n.id });
  // mermaid 输出: 新边实线红 / 删边虚线灰 / 未标注新依赖加警告标记
  const mm = ['graph LR'];
  for (const c of changes.filter((x) => x.type === 'edge-added'))
    mm.push(`  ${c.from} -->|${c.semantic}| ${c.to}`);
  return { changes, mermaid: mm.join('\n') };
}
```

**评分点**：
- 基线图 git 版本化（架构图可 review）
- 三类变化 + 语义标注（违规/预期/未标注——语义化是核心）
- 与适应度函数联动（新边合规检查）
- Mermaid diff 输出（架构变化可视化进 PR）
