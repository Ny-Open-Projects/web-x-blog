## ARC-809：手写环境矩阵校验

**答**：实现多环境配置校验器 `envMatrixCheck(apps, envs)`：① 环境矩阵：apps × envs（dev/staging/prod）× 配置项（API 域名/开关/密钥引用）——配置项的完整性校验；② 必填校验：prod 环境的必需配置缺失 = fail（如支付密钥）；③ 一致性校验：dev 有而 prod 没有的配置项（可能遗漏）标注 warning；④ 敏感值检查：配置值含明文 secret（正则：key/sk-/password=）→ blocker；⑤ 差异报告：dev/staging/prod 的配置差异矩阵（输出 markdown 表格——配置漂移可视化）。写出实现。

```javascript
function envMatrixCheck(apps, envs) {
  const ENV_ORDER = ['dev', 'staging', 'prod'];
  const blockers = [], warnings = [];
  const matrix = {};

  for (const [app, config] of Object.entries(apps)) {
    matrix[app] = {};
    for (const env of ENV_ORDER) {
      const c = config[env] ?? {};
      matrix[app][env] = c;
      // prod 必填校验
      if (env === 'prod') {
        for (const required of ['apiUrl', 'paymentKeyRef']) {
          if (!c[required]) blockers.push(`${app}/${env}: 缺必需配置 ${required}`);
        }
      }
      // dev 有 prod 没有 → 可能遗漏
      for (const key of Object.keys(config.dev ?? {}))
        if (!(key in c) && !key.startsWith('_')) warnings.push(`${app}: ${key} dev 有 prod 无`);
      // 明文 secret 检测
      for (const [k, v] of Object.entries(c))
        if (typeof v === 'string' && /^(sk-|key=|password=)/i.test(v))
          blockers.push(`${app}/${env}/${k}: 疑似明文密钥`);
    }
  }
  // 差异矩阵 markdown
  const md = Object.entries(matrix).map(([app, envs]) => {
    const rows = Object.keys(apps[app].dev ?? {}).map((key) =>
      `| ${app}.${key} | ${envs.dev?.[key] ?? '-'} | ${envs.staging?.[key] ?? '-'} | ${envs.prod?.[key] ?? '-'} |`);
    return rows.join('\n');
  }).join('\n');
  console.log(`| config | dev | staging | prod |\n|---|---|---|---|\n${md}`);
  if (blockers.length) { console.error(blockers); process.exit(1); }
  return { blockers, warnings };
}
```

**评分点**：
- prod 必填配置校验（缺失 = fail）
- dev 有 prod 无的遗漏检测（warning）
- 明文密钥正则扫描（blocker）
- 差异矩阵 markdown 输出（配置漂移可视化）
