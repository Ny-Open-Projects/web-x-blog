## DP-334：笔试题：手写多标签页数据同步（BroadcastChannel + storage 兜底）？
**题目**：实现 TabsSync：1) BroadcastChannel 广播（登录态/权限变更）；2) 不支持 BC 时降级 storage 事件；3) 接收方按类型分发处理；4) 版本号防旧消息覆盖新状态。
**评分点**：
- BC + storage 双通道降级正确。
- 消息类型分发清晰。
- 版本号比较（乱序消息防护）。
- 清理（unmount 关闭 channel）。
```javascript
function createTabsSync(handlers) {
  let version = 0;
  const bc = 'BroadcastChannel' in window ? new BroadcastChannel('app-sync') : null;
  const dispatch = ({ type, payload, v }) => {
    if (v <= version && v !== 0) return;                  // 4) 旧消息丢弃
    version = Math.max(version, v);
    handlers[type]?.(payload);
  };
  bc?.onmessage = e => dispatch(e.data);                  // 1)
  const onStorage = (e) => {                              // 2) 降级
    if (e.key === '__sync' && e.newValue) dispatch(JSON.parse(e.newValue));
  };
  addEventListener('storage', onStorage);
  return {
    send(type, payload) {
      const msg = { type, payload, v: ++version };
      bc ? bc.postMessage(msg) : localStorage.setItem('__sync', JSON.stringify(msg));
    },
    close() { bc?.close(); removeEventListener('storage', onStorage); },   // 4)
  };
}
// 用：tabs.send('logout', {}) → handlers.logout = () => location.href = '/login'
```
