## ARC-513：直播带货间前端架构
**答**:
- 多通道并发：视频流（HLS/FLV）、信令流（WS：商品讲解切换/优惠券/弹幕）、业务流（商品列表/购物车）——三通道独立降级（视频挂了商品还能买）。
- 讲解商品协议：主播侧"讲解中"事件 → 全房间商品卡置顶切换（抢占式 UI：讲解位唯一）→ 点击进详情（直播间上下文保持：返回不重连）。
- 高频互动渲染：弹幕/点赞/进场的渲染节流（批量合并绘制，Canvas 弹幕层 ARC-178），点赞数字动画合帧（防 O(n) 动画爆炸）。
- 交易链路：直播间内下单（轻量下单浮层）与主站购物车打通；库存/价格以服务端实时为准（讲解价切换时效）。
- 稳定性：直播间崩溃监控独立（DAU 尖峰场景 ARC-256）、推流中断的观众侧降级（显示"信号恢复中" + 自动重连）、大促间预热（ARC-384 服务端配合）。
```javascript
// 讲解商品切换协议
signal.on('goods:live', ({ goodsId, price }) => {
  store.setLiveGoods(goodsId, { price, at: Date.now() });      // 讲解位抢占
  ui.pinGoodsCard(goodsId);                                    // 全房统一置顶
});
// 弹幕批量渲染：buffer 收集 200ms 内消息一次绘制（Canvas，dpr 适配）
setInterval(() => { if (buf.length) danmakuLayer.draw(buf.splice(0)); }, 200);
```
