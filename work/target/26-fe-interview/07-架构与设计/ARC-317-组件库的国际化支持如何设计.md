## ARC-317：组件库的国际化支持如何设计？
**答**：
- 组件库 i18n 范围：内置文案（Modal 确定按钮/分页文案/日期面板）+ 国际化能力组件（DatePicker 的 locale、NumberInput 的格式）。库内文案量小但要协议完整。
- 机制：ConfigProvider（locale 对象注入 context）——组件从 context 读文案，默认中文，用户可全量覆盖；locale 对象结构化（分组件命名空间），与 ARC-085 应用层 i18n 体系对接（应用把组件库 locale 并入全局字典）。
- RTL：组件布局用逻辑属性（ARC-244），方向敏感组件（分页箭头/抽屉方向）读 dir 上下文自动翻转。
- 细节能力：日期组件 Intl 化（周起始日/月份名按 locale）、数字输入千分位按 locale、复数场景（分页 total 用 ICU）。

```typescript
// locale 结构与注入
const zhCN = { modal: { ok: '确定', cancel: '取消' }, pagination: { total: '{n} 条' },
               datePicker: { weekStart: 1, months: ['一月', ...] } };
const LocaleContext = createContext(zhCN);
export function ConfigProvider({ locale = zhCN, children }) {
  return <LocaleContext.Provider value={{ ...zhCN, ...locale }}>{children}</LocaleContext.Provider>;
}
function useLocale() { return useContext(LocaleContext); }
// 组件内：const l = useLocale().modal; <Button>{l.ok}</Button>
// 应用层整合：<ConfigProvider locale={i18n.pickNamespace('ui')}> —— 组件库文案进全局字典统一管理
```
