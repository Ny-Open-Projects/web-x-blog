## ARC-529：剪贴板富交互架构
**答**:
- 多格式写入：clipboard.write 同时写 text/html + text/plain + 自定义 web 格式（application/x-app）——粘贴到外部应用退化纯文本、站内粘贴带富语义（ARC-497 协议延伸）。
- 粘贴分派：paste 事件按来源分级——站内自定义格式优先（结构化粘贴：跨文档复制组件保样式）、HTML 净化（外部来源白名单 ARC-472）、纯文本兜底。
- 权限与兼容：剪贴板读权限（clipboard.readText 需授权 + 用户手势，Safari 严格）、权限拒绝降级（提示手动 Ctrl+V 走 paste 事件）。
- 场景化策略：表格粘贴（TSV 解析批量写入 ARC-499）、富文本编辑器粘贴（图片提取上传 + 格式清洗）、代码块粘贴（语言探测高亮）。
- 大数据：超大粘贴内容限制（截断提示）、图片粘贴（clipboard items → 上传链路 ARC-377）。
```javascript
// 复制：双格式写入
async function copyNode(node) {
  const html = node.outerHTML, plain = node.textContent;
  const payload = JSON.stringify({ type: 'node', id: node.dataset.id });
  await navigator.clipboard.write([
    new ClipboardItem({ 'text/html': new Blob([html], { type: 'text/html' }),
      'text/plain': new Blob([plain], { type: 'text/plain' }),
      'application/x-app': new Blob([payload]) })]);             // 站内富语义
}
// 粘贴：格式分派
el.onpaste = (e) => {
  const items = e.clipboardData;
  if (items.types.includes('application/x-app')) return inAppPaste(items);
  if (items.files.length) return uploadPaste(items.files);       // 截图粘贴
  return sanitizePaste(items.getData('text/html') || items.getData('text/plain'));
};
```
