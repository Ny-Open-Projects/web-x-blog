## ARC-807：手写所有权地图

**答**：实现代码所有权分析器 `ownershipMap(gitLog, teamMap)`：① 基于 git 历史统计：每文件/目录的「实际维护者分布」（commit 作者按团队聚合）——登记 owner vs 实际维护者的对比；② 所有权漂移检测：登记 owner 近 3 月 0 commit 但他人高频维护 → 漂移告警（owner 失效）；③ Bus Factor 计算：每模块的维护者集中度（top1 作者占比 >70% → Bus Factor 1 警告）；④ 所有权建议：基于实际维护数据建议 owner 调整（实际维护者接管）；⑤ 输出：所有权地图（目录树 × 团队染色）+ 风险清单。写出实现。

```javascript
function ownershipMap(commits, teamMap) {
  // commits: [{ file, author, team, date }]
  const byFile = new Map();
  for (const c of commits) {
    const m = byFile.get(c.file) ?? byFile.set(c.file, { teams: {}, lastTouch: 0 }).get(c.file);
    m.teams[c.team] = (m.teams[c.team] ?? 0) + 1;
    m.lastTouch = Math.max(m.lastTouch, c.date);
  }
  const threeMonthsAgo = Date.now() - 90 * 86400e3;
  const report = [];
  for (const [file, data] of byFile) {
    const entries = Object.entries(data.teams).sort((a, b) => b[1] - a[1]);
    const total = entries.reduce((s, [, n]) => s + n, 0);
    const topTeam = entries[0][0], topRatio = entries[0][1] / total;
    const registered = registeredOwner(file);           // CODEOWNERS 查询
    const drift = registered && registered !== topTeam && data.lastTouch > threeMonthsAgo;
    const busFactor = topRatio > 0.7 && entries.length < 3 ? 1 : entries.length;
    report.push({ file, registered, actual: topTeam, drift, busFactor,
      suggestion: drift ? `建议 owner 由 ${registered} 调整为 ${topTeam}` : null });
  }
  return {
    map: report,
    risks: report.filter((r) => r.busFactor === 1 || r.drift),
  };
}
// 输出: { map: [{file:'src/cart/', registered:'cart-team', actual:'growth-team', drift:true, busFactor:1, suggestion:'...'}], risks: [...] }
```

**评分点**：
- git 历史驱动的实际维护者统计（登记 vs 实际对比）
- 所有权漂移检测（近 3 月无 commit + 他人维护）
- Bus Factor 集中度计算（top1 >70% 警告）
- owner 调整建议（数据驱动而非主观指定）
