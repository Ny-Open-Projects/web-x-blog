## ARC-359：可观测性深水区：前端健康分体系如何设计？
**答**：
- 健康分是多指标合成的单一分数（0~100），给非技术角色（老板/业务方）看；技术细节留在下钻视图。
- 指标域：稳定性（错误率/白屏率 40%）、性能（Web Vitals 达标率 30%）、可用性（核心接口成功率 20%）、体验（交互卡顿/投诉 10%），权重按业务类型调（C 端重性能，B 端重稳定）。
- 计分方式：每个指标映射到 0~100（SLO 达标法或分位数法），加权合成；用达标率而非均值，防极端值拉平。
- 防作弊与防钝化：指标口径版本化（改口径必须重新评审）、分数与发布流程挂钩（低于阈值冻结发布）、定期校准防"分数好看但体验差"。
- 落地：应用级健康分 + 团队级聚合，周报自动生成，环比劣化自动标注归因线索。
```javascript
const WEIGHTS = { stability: .4, performance: .3, availability: .2, experience: .1 };
function healthScore(metrics) {
  const s = {
    stability: 100 - metrics.errorRate * 1000,           // 1% 错误 = 90 分
    performance: metrics.lcpGoodRate * 100,              // 达标率直接映射
    availability: metrics.apiSuccessRate * 100,
    experience: 100 - metrics.longTaskRate * 500
  };
  return Math.round(Object.entries(WEIGHTS)
    .reduce((acc, [k, w]) => acc + clamp(s[k], 0, 100) * w, 0));
}
```
