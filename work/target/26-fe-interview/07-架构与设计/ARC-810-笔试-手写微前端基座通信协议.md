## ARC-810：手写基座通信协议

**答**：实现微前端基座与子应用的通信协议 `MicroProtocol`：① 协议消息：{ id, source, target, type, payload, version }——source/target 标识（基座=shell，子应用=appId）；② 路由分发：`send(msg)` 按 target 分发（基座处理或转发给目标子应用）；③ 请求响应模式：request(target, type, payload) → Promise（responseId 匹配 + 超时）；④ 广播与定向：broadcast(type) vs sendTo(appId, type)；⑤ 子应用生命周期协议：register/mount/unmount 的握手流程（版本协商——子应用要求基座最低版本）；⑥ 死锁防护：request 超时与循环请求检测（A 请求 B、B 请求 A 的环——深度计数 >3 拒绝）。写出实现。

```javascript
class MicroProtocol {
  #handlers = new Map();   // appId -> handler
  #apps = new Map();       // appId -> { version, mounted }
  #pending = new Map();
  #depth = 0;

  register(appId, { minShellVersion, handler }) {
    if (compareVersion(SHELL_VERSION, minShellVersion) < 0)
      throw new Error(`${appId} 需要基座 ≥${minShellVersion}`);
    this.#apps.set(appId, { version: minShellVersion, mounted: false });
    this.#handlers.set(appId, handler);
  }
  async send(msg) {
    if (this.#depth > 3) throw new Error('请求环检测: 深度超限');
    const full = { id: crypto.randomUUID(), source: 'shell', version: SHELL_VERSION, ...msg };
    if (msg.target === 'shell') return this.#handle(full);
    const handler = this.#handlers.get(msg.target);
    if (!handler) throw new Error(`unknown target: ${msg.target}`);
    this.#depth++;
    try { return await handler(full); } finally { this.#depth--; }
  }
  request(target, type, payload, { timeout = 5000 } = {}) {
    const id = crypto.randomUUID();
    return new Promise((resolve, reject) => {
      const timer = setTimeout(() => { this.#pending.delete(id); reject(new Error(`timeout: ${target}/${type}`)); }, timeout);
      this.#pending.set(id, { resolve, reject, timer });
      this.send({ target, type, payload: { ...payload, __reqId: id } }).catch(reject);
    });
  }
  async #handle(msg) { /* 基座处理逻辑: 路由/鉴权/全局态 */ }
  broadcast(type, payload) {
    for (const appId of this.#apps.keys())
      if (this.#apps.get(appId).mounted) this.send({ target: appId, type, payload }).catch(() => {});
  }
}
```

**评分点**：
- 消息协议字段完整（source/target/version——版本协商）
- 请求响应的 requestId 匹配 + 超时
- 请求环检测（深度计数 >3 拒绝——死锁防护）
- 生命周期握手（register 的最低版本校验）
