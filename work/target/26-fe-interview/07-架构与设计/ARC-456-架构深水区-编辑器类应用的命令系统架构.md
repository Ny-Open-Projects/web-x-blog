## ARC-456：编辑器类应用的命令系统架构
**答**:
- 核心抽象：所有用户操作都是命令（Command：do/undo/merge），UI（按钮/快捷键/菜单）只是命令的触发器——架构上命令系统与 UI 解耦，才能支持宏（命令序列）、撤销、协作重放。
- 命令设计要素：幂等参数化（"加粗选区"带选区范围而非全局状态）、可合并（连续输入合并为一笔撤销，merge 窗口 500ms）、可逆（undo 语义明确，复杂操作存 before/after 快照）。
- 数据模型分离：编辑器数据模型（文档树/场景图）与视图分离，命令操作模型，视图订阅模型渲染——协作与导出才可能实现。
- 扩展机制：命令注册表（插件贡献命令）、上下文可用性（命令在当前选区是否可用 → UI 自动置灰）、权限（只读模式禁写命令）。
- 测试策略：命令级单测（do/undo 往返不变性：undo(do(state)) === state）是编辑器质量的核心保障。
```javascript
class CommandSystem {
  #history = [];
  exec(cmd) {
    const before = model.snapshot();
    cmd.do(model);
    this.#history.push({ cmd, before, at: Date.now(), merged: false });
  }
  mergeableTail(cmd) {                                         // 连续输入合并
    const tail = this.#history.at(-1);
    if (tail?.cmd.type === cmd.type && Date.now() - tail.at < 500) { tail.cmd = cmd.merge(tail.cmd); return true; }
    return false;
  }
  undo() { const h = this.#history.pop(); if (h) model.restore(h.before); }
}
```
