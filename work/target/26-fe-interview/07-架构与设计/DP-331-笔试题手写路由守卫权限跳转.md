## DP-331：笔试题：手写路由守卫权限跳转？
**题目**：实现 Router 守卫：1) beforeEach 检查 meta.perm；2) 未登录 → 登录页带 redirect 回跳；3) 无权 → 403 页（保留来源）；4) 防死循环（登录页自身放行）。
**评分点**：
- 判定链顺序正确（登录 → 权限）。
- redirect 参数编码正确（encodeURIComponent + 恢复）。
- 白名单路径放行防循环。
- 403 保留来源供"申请权限后返回"。
```javascript
const whitelist = ['/login', '/403', '/public/*'];
function guard(to, from, next) {
  if (isPublic(to.path)) return next();                    // 4) 防循环
  const snap = permStore.snapshot;
  if (!snap?.user) {                                       // 2) 未登录
    return next({ path: '/login', query: { redirect: encodeURIComponent(to.fullPath) } });
  }
  const perm = to.meta?.perm;
  if (perm && !can(snap, perm.action, perm.resource)) {    // 3) 无权
    return next({ path: '/403', query: { from: to.fullPath, need: `${perm.resource}:${perm.action}` } });
  }
  next();
}
// 登录成功后：router.push(decodeURIComponent(route.query.redirect ?? '/')) —— 回跳
```
