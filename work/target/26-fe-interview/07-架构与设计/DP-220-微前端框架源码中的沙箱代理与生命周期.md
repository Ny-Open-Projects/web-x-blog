## DP-220：源码识别：微前端框架源码中的沙箱代理与生命周期？
**答**：
- 代理模式（JS 沙箱）：qiankun legacySandbox/proxySandbox 用 Proxy 包装 window——子应用写 window.x 记录到 fakeWindow，激活/失活时还原 diff；proxySandbox 每个子应用独立 fakeWindow（多实例）。
- 状态模式：子应用生命周期 bootstrap → mount → unmount（DP-186 设计过），框架是状态机调度者；activeRule 匹配是转移条件。
- 命令+发布订阅：initGlobalState 是主子应用共享事件总线（setGlobalState = 命令广播，onGlobalStateChange = 订阅）。
- 识别要点：能说出"qiankun 样式隔离 scopedCSS 是对 style 标签的代理改写（重写选择器加前缀）"——CSS 侧也是代理。

```javascript
// Proxy 沙箱（源码级简化）
class ProxySandbox {
  constructor() {
    const fakeWindow = Object.create(null);
    this.proxy = new Proxy(fakeWindow, {
      get: (t, k) => k in t ? t[k] : window[k],              // 读穿透到真 window
      set: (t, k, v) => { this.updated.add(k); t[k] = v; return true; },  // 写入记录
    });
    this.updated = new Set();                 // 改动集合（用于失活还原）
  }
  activate() { this.updated.forEach(k => { window[k] = this.proxy[k]; }); }   // 激活回放
  deactivate() { this.updated.forEach(k => { delete this.proxy[k]; }); }      // 失活还原
}
// 生命周期调度：app.mount 是命令，activeRule 命中 → loadApp → mount；路由离开 → unmount → 沙箱失活
// 全局状态：const { onGlobalStateChange, setGlobalState } = initGlobalState({ user: {} }) —— 主子通信发布订阅
```
