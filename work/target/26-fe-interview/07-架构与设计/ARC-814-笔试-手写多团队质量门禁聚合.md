## ARC-814：手写门禁聚合

**答**：实现多应用质量门禁的聚合看板 `GateAggregator`：① 门禁结果采集：各应用 CI 的门禁结果（pass/fail/waived + 各维度分数）——定时拉取或 webhook 推送；② 聚合视图：组织级通过率（按团队/应用维度下钻）、fail 应用的违规明细；③ 趋势追踪：通过率周趋势 + 劣化应用标注（连续 2 周下降 → 告警）；④ 豁免审计：waived 的申请记录（谁/原因/到期）——豁免到期未处理提醒；⑤ 输出：周报 markdown（发团队群）+ 仪表盘数据 JSON。写出实现。

```javascript
class GateAggregator {
  #results = new Map();   // appId -> [{ t, pass, dims: { perf, quality, security }, waived: [{rule, by, until}] }]
  ingest(appId, result) {
    const list = this.#results.get(appId) ?? this.#results.set(appId, []).get(appId);
    list.push({ t: Date.now(), ...result });
  }
  weeklyReport(teams) {
    const byTeam = {};
    for (const [appId, runs] of this.#results) {
      const team = teams[appId] ?? 'unknown';
      const latest = runs.at(-1);
      (byTeam[team] ??= { apps: 0, pass: 0, fails: [] }).apps++;
      latest.pass ? byTeam[team].pass++ : byTeam[team].fails.push({ appId, dims: latest.dims });
    }
    // 劣化检测: 连续 2 周下降
    const degrading = [];
    for (const [appId, runs] of this.#results) {
      if (runs.length < 3) continue;
      const last3 = runs.slice(-3);
      if (last3.every((r, i) => i === 0 || score(r) < score(last3[i - 1])))
        degrading.push(appId);
    }
    // 豁免到期提醒
    const expiring = [];
    for (const [appId, runs] of this.#results)
      for (const w of runs.at(-1)?.waived ?? [])
        if (new Date(w.until) < Date.now() + 7 * 86400e3)
          expiring.push({ appId, rule: w.rule, until: w.until });
    return { byTeam, degrading, expiring,
      markdown: renderReport({ byTeam, degrading, expiring }) };
  }
}
```

**评分点**：
- 多应用结果采集（拉取/推送双通道）
- 聚合下钻（组织通过率 → 团队 → 应用 → 维度）
- 连续劣化检测（趋势告警非单点）
- 豁免到期提醒（豁免生命周期管理）
