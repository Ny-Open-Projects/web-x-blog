## DP-319：笔试题：手写模态框队列（同屏限流+优先级）？
**题目**：实现 ModalQueue：1) enqueue(modal, { priority })：同屏最多 1 个模态，后续排队；2) 优先级插队（高优先级排在队首）；3) 当前模态关闭后自动弹下一个；4) 强制模式 force: true 跳过队列直接弹（叠层）。
**评分点**：
- 队列优先级排序正确（稳定：同优先级 FIFO）。
- 关闭联动（onClose 触发出队渲染下一个）。
- force 模式不打乱队列状态。
- 取消排队（clear / dequeue by id）。
```javascript
class ModalQueue {
  #current = null;
  #queue = [];        // { id, modal, priority }
  enqueue(modal, { priority = 0, force = false } = {}) {
    if (force) return this.#show(modal);                 // 4) 直接弹
    const item = { modal, priority, seq: ++ModalQueue.seq };
    const i = this.#queue.findIndex(m => m.priority < priority);   // 2) 插队（稳定）
    i === -1 ? this.#queue.push(item) : this.#queue.splice(i, 0, item);
    if (!this.#current) this.#next();
    return () => this.#remove(item);
  }
  #next() {
    const item = this.#queue.shift();
    if (!item) { this.#current = null; return; }
    this.#current = this.#show(item.modal);              // 3) 关闭后自动下一个
  }
  #show(modal) { return modal({ onClose: () => { this.#current = null; this.#next(); } }); }
  #remove(item) { this.#queue = this.#queue.filter(i => i !== item); }
}
ModalQueue.seq = 0;
```
