## ARC-407：笔试题：手写性能预算卡点脚本
**答**：实现 bundleBudget(files, budget)：1) 遍历 dist 统计各类型资源 gzip 体积；2) 与预算比较（js 总量、单 chunk 上限、图片总量）；3) 超预算项列出明细并以退出码 1 失败；4) 支持豁免清单（指定文件不计入）。
**评分点**：
- gzip 后计算（真实传输体积）而非原始体积。
- 预算三级（总量/单项/豁免）判断顺序正确。
- 输出超预算明细（差值）便于修复。
- CI 退出码语义正确（0 通过 / 1 阻断）。
```javascript
const fs = require('fs'), path = require('path'), zlib = require('zlib');
function gzipSize(f) { return zlib.gzipSync(fs.readFileSync(f)).length; }
function bundleBudget(dir, budget, exempt = []) {
  const files = walk(dir).filter(f => !exempt.some(e => f.includes(e)));
  const byType = groupBy(files, f => path.extname(f));       // js/css/图片分组
  const report = Object.entries(budget).map(([type, limit]) => {
    const total = (byType[type] ?? []).reduce((s, f) => s + gzipSize(f), 0);
    return { type, total, limit, over: total > limit };
  });
  const overs = report.filter(r => r.over);
  for (const r of overs)
    console.error(`[budget] ${r.type} 超预算 ${(r.total - r.limit)/1024|0}KB（${r.total/1024|0}/${r.limit/1024|0}KB）`);
  if (overs.length) process.exit(1);                          // CI 阻断
}
bundleBudget('./dist', { js: 300 * 1024, css: 60 * 1024 }, ['vendor-echarts.js']);
```
