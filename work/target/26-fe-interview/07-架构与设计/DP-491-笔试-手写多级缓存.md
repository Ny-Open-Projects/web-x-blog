## DP-491：笔试：手写多级缓存

**答**：实现多级缓存 `MultiCache`：① 三级：内存 LRU → IndexedDB（异步持久）→ fetcher（网络）；② 策略注入：cache-first / swr / network-first 可配；③ get 的逐级回退 + 命中提升（低级命中提升到高级——热点数据上浮）；④ 多级失效（写操作穿透所有层）；⑤ 命中统计（每级命中率——缓存收益分析）。写出实现。

```javascript
class MultiCache {
  #mem = new Map(); #stats = { l1: 0, l2: 0, net: 0 };
  constructor({ idb, strategy = 'swr', ttl = 60_000, maxMem = 100 } = {}) {
    Object.assign(this, { idb, strategy, ttl, maxMem });
  }
  async get(key, fetcher) {
    // L1: 内存
    const mem = this.#mem.get(key);
    if (mem && Date.now() - mem.at < this.ttl) { this.#stats.l1++; return mem.v; }
    // L2: IDB
    const disk = this.idb ? await this.idb.get(key) : null;
    if (disk && Date.now() - disk.at < this.ttl) {
      this.#stats.l2++;
      this.#mem.set(key, disk);                        // 命中提升
      return disk.v;
    }
    // L3: 网络
    this.#stats.net++;
    const fresh = { v: await fetcher(key), at: Date.now() };
    this.#mem.set(key, fresh);
    this.#enforceLimit();
    this.idb?.set(key, fresh);
    return fresh.v;
  }
  invalidate(key) { this.#mem.delete(key); this.idb?.del(key); }   // 穿透失效
  #enforceLimit() {
    while (this.#mem.size > this.maxMem) this.#mem.delete(this.#mem.keys().next().value);
  }
  get stats() { return { ...this.#stats }; }
}
// swr 变体: L1/L2 命中即返回 + 后台 fetcher 刷新 (旧值快回, 新值异步)
```

**评分点**：
- 逐级回退 + 命中提升（热点数据上浮）
- 穿透失效（多级同时清——防旧数据复活）
- 策略注入（swr 的后台刷新变体）
- 命中统计（每级命中率——收益分析）
