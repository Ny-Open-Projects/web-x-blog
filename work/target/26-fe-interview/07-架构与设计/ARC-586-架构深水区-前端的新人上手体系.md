## ARC-586：新人上手体系
**答**:
- 目标量化：新人从入职到首个 MR 合并的时间（目标 < 3 天）——上手体系围绕这个时间设计，每个阻塞点都是改进项。
- 体系组成：环境一键（DevContainer/脚本 ARC-365——第 1 天能跑起来）、入门任务清单（第一个真实小任务：bugfix/小功能——真实代码而非 toy）、导师制（buddy：每天 15 分钟答疑——答疑问题收集反哺文档）、代码导读（核心链路导读文档/视频：登录到渲染的数据流——按"新人最容易迷路的地方"写）。
- 知识地图：仓库地图（目录职责一页纸 ARC-470）、术语表（内部黑话/业务概念）、"去哪问"索引（问题类型 → 联系人/频道）。
- 反馈闭环：上手体验访谈（每个新人结束时 15 分钟）——上手时间曲线与阻塞点统计（环境问题占比 → 基建优先修）；文档热修机制（新人发现文档错误当场修——最好的文档审校者）。
- 文化：新人首周不排紧急任务（给上手留空间）、导师是荣誉任务不是负担（纳入绩效认可）。
```javascript
// 上手追踪
const onboarding = {
  day1: ['环境就绪', '跑通 dev', '代码导读'],
  day2: ['首个任务认领', '提 MR'],
  day3: ['MR 合并', '上手访谈'],
  metrics: { timeToFirstMR: '2.5d', blockers: ['node 版本安装慢 → 镜像预装修复'] }
};
```
