## ARC-846：手写技能矩阵

**答**：实现团队架构能力的技能矩阵 `SkillMatrix`：① 技能登记：{ skill(性能优化/安全/可视化/跨端...), level(1了解/2实践/3精通), member, evidence(证明: 项目/分享) }——证据必填；② 矩阵视图：技能 × 成员矩阵（每个技能的覆盖人数与深度）；③ 风险识别：level3（精通）只有 1 人的技能 → 单点风险（该技能的关键任务需 backup 计划）；④ 项目匹配：立项时 `match(projectNeeds)`——项目需要的技能 vs 团队覆盖（缺口 → 招聘/培训/借调建议）；⑤ 成长追踪：成员的技能升级记录（1→2→3——evidence 驱动）。写出实现。

```javascript
class SkillMatrix {
  #skills = new Map();   // `${skill}:${member}` -> { level, evidence }
  register(skill, member, level, evidence) {
    if (!evidence) throw new Error('技能登记必须带证据 (项目/分享)');
    this.#skills.set(`${skill}:${member}`, { skill, member, level, evidence, at: Date.now() });
  }
  matrix() {
    const skillNames = [...new Set([...this.#skills.values()].map((s) => s.skill))];
    const members = [...new Set([...this.#skills.values()].map((s) => s.member))];
    return {
      grid: skillNames.map((skill) => ({
        skill,
        coverage: members.map((m) => this.#skills.get(`${skill}:${m}`)?.level ?? 0),
        l3Count: members.filter((m) => this.#skills.get(`${skill}:${m}`)?.level === 3).length,
      })),
      risks: skillNames.filter((s) =>
        members.filter((m) => this.#skills.get(`${s}:${m}`)?.level === 3).length <= 1)
        .map((s) => ({ skill: s, risk: '单点 (l3≤1)', action: '指定 backup 培养计划' })),
    };
  }
  match(projectNeeds) {                                // 项目需求: [{ skill, minLevel }]
    const gaps = projectNeeds.filter(({ skill, minLevel }) => {
      const qualified = [...this.#skills.values()].filter((s) => s.skill === skill && s.level >= minLevel);
      return qualified.length === 0;
    });
    return { covered: projectNeeds.filter((n) => !gaps.some((g) => g.skill === n.skill)),
      gaps: gaps.map((g) => ({ ...g, advice: '招聘 / 培训 / 借调' })) };
  }
}
```

**评分点**：
- 证据必填（技能登记防自评注水）
- 单点风险识别（l3≤1 → backup 计划）
- 项目匹配的缺口分析（招聘/培训/借调建议）
- 成长追踪的 evidence 驱动（升级有据）
