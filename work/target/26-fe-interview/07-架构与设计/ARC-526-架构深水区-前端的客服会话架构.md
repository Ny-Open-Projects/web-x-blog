## ARC-526：客服会话前端架构
**答**:
- 双形态融合：机器人会话（FAQ/自助流程，快）与人工会话（IM 消息流 ARC-169）无缝转接——转接协议（机器人上下文打包给人工，用户无感换端）。
- 会话可靠性：消息 seq/ack/补拉（ARC-169 + NODE-392）、离线消息与通知（ARC-394）、会话列表未读同步（ARC-502）。
- 富消息类型：文本/图片/商品卡片/订单卡片/表单卡片——消息渲染注册表 + payload schema 校验（不可信消息体防注入 ARC-497 剪贴板净化思想）。
- 排队与状态：转人工排队（队列位置实时更新/预计等待）、客服在线状态、会话结束评价流程。
- 上下文联动：会话内直接引用业务对象（订单详情卡片可操作：查/催/退——操作走业务接口而非会话消息），操作结果回写消息流。
```javascript
// 消息类型注册表
const msgRenderers = {
  text: TextBubble, image: ImageBubble, goods: GoodsCard, order: OrderCard, form: FormCard
};
ws.on('message', m => {
  const T = msgRenderers[m.type];
  if (!T || !MsgSchema[m.type].safeParse(m.payload).success)     // 不可信 payload 校验
    return renderFallback(m);
  store.append(m);                                               // seq 去重后入列
});
// 转人工：api.transferToHuman({ context: robotCtx, lastSeq }) → 排队位推送
```
