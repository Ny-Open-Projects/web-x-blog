## DP-273：源码识别：播放器记忆播放源码中的状态持久化？
**答**:
- 观察者+防抖：timeupdate 节流采样（每 5s），position 变化写 Storage——"订阅即存档"（DP-254 持久化插件同款）。
- 策略：续播策略（差值 < 10s 视为看完不续播、超过片长 95% 归零）、跨端同步策略（服务端进度优先，本地兜底）。
- 状态机：恢复流程（加载 metadata → seek 保存位置 → 校验有效 → 播放），失败静默回退从头播。
- 识别要点：能说出"seek 时机"——loadedmetadata 后 seek 否则无效（duration 未知时 seek 会被 clamp）。

```typescript
// 记忆播放（源码级简化）
const KEY = (videoId: string) => `progress:${videoId}`;
video.addEventListener('timeupdate', throttle(() => {
  const { currentTime, duration } = video;
  if (currentTime < 10 || currentTime > duration * 0.95) return;   // 策略：开头/结尾不记
  localStorage.setItem(KEY(videoId), JSON.stringify({ t: currentTime, at: Date.now() }));
}, 5000));
// 恢复：
async function resume(videoId: string) {
  await new Promise(r => video.addEventListener('loadedmetadata', r, { once: true }));
  const saved = JSON.parse(localStorage.getItem(KEY(videoId)) ?? 'null');
  const server = await api.get(`/progress/${videoId}`).catch(() => null);   // 跨端同步
  const t = Math.max(saved?.t ?? 0, server?.position ?? 0);
  if (t > 10 && t < video.duration * 0.95) { video.currentTime = t; showResumeBar(t); }
}
```
