## DP-249：源码识别：ICU MessageFormat 引擎源码中的解释器与缓存？
**答**:
- 解释器（核心）：消息语法（{name}、{count, plural, one{...} other{...}}、select）是一棵消息 AST，format(params) 解释执行——语法节点递归求值。
- 备忘录：AST 解析贵（每条消息），按 (locale, key) 缓存解析结果，运行时只解释。
- 策略：复数类别计算按 locale 注入（Intl.PluralRules 适配）；子格式化器（date/number）也是策略注入。
- 识别要点：能说明"ICU 编译期预处理"路线（react-intl 的 babel 插件把消息编译成代码，运行零解析）与运行时解释的权衡。

```javascript
// ICU 解释器（源码级简化）
function parse(msg) {                          // {count, plural, one {1 item} other {# items}}
  return [...msg.matchAll(/\{(\w+)(?:, (\w+), (.+?))?\}/g)]
    .map(m => ({ type: m[2] ?? 'literal', arg: m[1], branches: m[3] && parseBranches(m[3]) }));
}
function format(nodes, params, locale) {
  return nodes.map(n => {
    if (n.type === 'literal') return n.value;
    if (n.type === 'plural') {
      const cat = new Intl.PluralRules(locale).select(params[n.arg]);   // 复数策略（Intl 适配）
      const branch = n.branches[cat] ?? n.branches.other;
      return format(branch, params, locale).replace('#', params[n.arg]); // # 引用数值
    }
    if (n.type === 'select') return format(n.branches[params[n.arg]] ?? n.branches.other, params, locale);
    return params[n.arg];                                            // 插值
  }).join('');
}
const astCache = new Map();                    // 备忘录：msg → AST
function t(key, params, locale) {
  astCache.get(key) ?? astCache.set(key, parse(dict[key]));
  return format(astCache.get(key), params, locale);
}
```
