## ARC-808：手写技术雷达

**答**：实现技术雷达生成器 `TechRadar`：① 雷达数据：{ name, quadrant(语言/框架/工具/平台), ring(采用/试用/评估/暂停), moved(↑新进/→持平/↓降级), notes, owner }；② 变更追踪：与上期雷达 diff——新增/环移动/移除的条目清单（本期变更日志）；③ ring 迁移规则校验：评估→试用→采用逐级（不允许跳级——评估直接采用需说明）；④ 输出：JSON 数据 + HTML 可视化（雷达图定位：四象限 × 四环的极坐标）+ 变更日志 markdown；⑤ 条目的「退役提醒」：暂停 ring 超一年的条目 → 建议移除。写出实现。

```javascript
const RINGS = ['评估', '试用', '采用', '暂停'];
const QUADRANTS = ['语言', '框架', '工具', '平台'];

class TechRadar {
  constructor(entries = []) { this.entries = entries; }
  diff(prev) {
    const prevMap = new Map(prev.entries.map((e) => [e.name, e]));
    const changes = [];
    for (const e of this.entries) {
      const old = prevMap.get(e.name);
      if (!old) changes.push({ name: e.name, change: '新增', ring: e.ring });
      else if (old.ring !== e.ring)
        changes.push({ name: e.name, change: `ring: ${old.ring} → ${e.ring}`, note: e.notes });
      prevMap.delete(e.name);
    }
    for (const removed of prevMap.values())
      changes.push({ name: removed.name, change: '移除' });
    return changes;
  }
  validate() {
    const errors = [];
    for (const e of this.entries) {
      if (!QUADRANTS.includes(e.quadrant)) errors.push(`${e.name}: quadrant 无效`);
      if (!RINGS.includes(e.ring)) errors.push(`${e.name}: ring 无效`);
      const prev = this.#prevRing(e.name);
      // 跳级校验: 评估 → 采用 必须经过试用 (除非 notes 说明)
      if (prev === '评估' && e.ring === '采用' && !e.notes?.includes('跳级说明'))
        errors.push(`${e.name}: 评估→采用跳级, 需 notes 说明`);
    }
    // 退役提醒
    const retired = this.entries.filter((e) => e.ring === '暂停' && e.pausedSince &&
      Date.now() - new Date(e.pausedSince).getTime() > 365 * 86400e3);
    return { errors, retireSuggestions: retired.map((e) => `${e.name} 暂停超一年, 建议移除`) };
  }
  #prevRing(name) { return null; }   // 与上期 diff 数据联动
  toChart() {
    // 极坐标: quadrant→角度扇区, ring→半径
    return this.entries.map((e) => ({
      ...e,
      angle: QUADRANTS.indexOf(e.quadrant) * 90 + 45,
      radius: (RINGS.indexOf(e.ring) + 1) * 25,
    }));
  }
}
```

**评分点**：
- 四象限四环模型 + moved 变更追踪
- ring 迁移规则校验（跳级需说明——防随意升级）
- 退役提醒（暂停超一年清理——雷达防膨胀）
- 极坐标输出（可视化数据结构）
