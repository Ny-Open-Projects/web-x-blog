## ARC-842：手写路由协调

**答**：实现微前端基座的路由协调器 `RouterCoordinator`：① 路由注册：子应用注册路由前缀（/order/** 归 order-app）——前缀匹配到子应用；② 跨应用导航：基座路由变化 → 卸载当前子应用 → 挂载目标子应用（带路由残留——目标子应用收到完整 path）；③ 子应用内部导航同步：子应用内部跳转 → 通知基座更新 URL（双向同步——history 拦截）；④ 嵌套路由的参数传递：基座路由参数透传子应用（/order/123 → order-app 收到 /123）；⑤ 悬空路由兜底：无子应用匹配 → 404 页面 + 上报。写出实现。

```javascript
class RouterCoordinator {
  #apps = new Map();   // prefix -> { mount, unmount, currentEl }
  #active = null;
  register(prefix, app) { this.#apps.set(prefix, app); }

  async handle(url) {
    const app = [...this.#apps.entries()].find(([prefix]) => url.startsWith(prefix));
    if (!app) {
      report404(url);
      return this.#render404();
    }
    const [prefix, impl] = app;
    if (this.#active?.prefix === prefix) {
      impl.onRouteChange?.(url);                       // 同应用: 内部导航
      return;
    }
    // 跨应用: 卸载 → 挂载
    await this.#active?.unmount();
    const el = document.createElement('div');
    el.id = `micro-${prefix}`;
    document.querySelector('#micro-root').appendChild(el);
    const unmount = await impl.mount(el, { path: url.slice(prefix.length) });   // 参数透传
    this.#active = { prefix, unmount, el };
    track({ type: 'app-switch', from: this.#prevPrefix, to: prefix });
  }
  // 子应用内部导航 → 通知基座
  bindChildNavigation(appId) {
    const origPush = history.pushState.bind(history);
    history.pushState = function (...args) {
      origPush(...args);
      dispatchEvent(new CustomEvent('micro:navigate', { detail: { url: location.pathname, appId } }));
    };
    addEventListener('micro:navigate', (e) => this.handle(e.detail.url));
  }
  #render404() { document.querySelector('#micro-root').innerHTML = '<div>404</div>'; }
}
```

**评分点**：
- 前缀匹配 + 路由残留透传（子应用收到完整 path）
- 卸载/挂载的生命周期协调（跨应用切换）
- 子应用内部导航的双向同步（history 拦截——URL 双写）
- 悬空路由兜底 + 上报（404 可观测）
