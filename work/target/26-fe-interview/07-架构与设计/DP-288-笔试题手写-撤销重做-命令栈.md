## DP-288：笔试题：手写撤销重做（命令栈+语义合并）？
**题目**：实现 HistoryManager：1) execute({do, undo, label})；2) undo/redo；3) 相邻同 label 命令合并（连续打字合为一条）；4) 上限 100 条；5) 新命令清空 redo 分支。
**评分点**：
- 命令双函数正确（do 执行+undo 可逆）。
- 合并策略正确（相邻同 label 且 do 返回可合并 payload）。
- redo 分支清理与栈上限裁剪。
- 时间复杂度 O(1) per 操作。
```javascript
class HistoryManager {
  #stack = []; #redo = [];
  constructor(private limit = 100) {}
  execute({ do: doFn, undo, label = 'op' }, prev) {
    const before = prev ?? capture();                   // 快照辅助
    doFn();
    const last = this.#stack.at(-1);
    if (last?.label === label && last.coalesce?.(label, before)) return;   // 3) 合并
    this.#stack.push({ label, undo: () => undo(before) });
    if (this.#stack.length > this.limit) this.#stack.shift();             // 4) 上限
    this.#redo = [];                                     // 5) 清 redo
  }
  undo() { const c = this.#stack.pop(); if (!c) return false;
    c.undo(); this.#redo.push(c); return true; }
  redo() { const c = this.#redo.pop(); if (!c) return false;
    c.undoInverse?.() ?? c.do?.(); this.#stack.push(c); return true; }
}
// 用法：history.execute({ do: () => editor.insert('a'), undo: () => editor.delete(1), label: 'type' });
// 连续 type 命令：last.coalesce 判定同 label → 合并为一条（undo 一次撤到最初 before 快照）
```
