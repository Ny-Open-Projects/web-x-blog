## ARC-583：前端指标到业务指标映射
**答**:
- 目标：LCP 提升对业务意味着什么（转化率提升 X% → GMV 增量）——建立"技术指标 → 业务结果"的量化映射，让性能工作获得业务语言支持（ARC-430/394 汇报的数据基础）。
- 映射方法：相关性分析（历史数据：LCP 分位与转化率的关系曲线——分桶对比：LCP<2.5s 用户 vs >4s 用户的转化差）、对照实验（性能优化的 AB 实验：优化版 vs 原版转化率——因果性证据）、行业基准补充（外部研究数据兜底——自身样本不足时）。
- 映射产出：指标业务价值表（LCP -1s ≈ 转化 +N% ≈ GMV +M 万——按页面类型分档）、优化 ROI 排序（哪些页面优化收益最大——指导投入优先级）。
- 使用纪律：映射是估算不是承诺（区间呈现、置信度标注）；实验证据优先于历史相关性（相关≠因果）。
- 维护：映射随业务变化更新（转化漏斗变了映射就变——季度校准）。
```javascript
// 指标业务价值表
const perfValue = {
  '/':      { lcp: { per1s: { conv: '+2.1%', gmv: '≈ 83万/月' }, confidence: 0.9, source: 'AB-2026-03' } },
  '/goods': { lcp: { per1s: { conv: '+1.4%', gmv: '≈ 55万/月' }, confidence: 0.8, source: '历史分桶' } }
};
// 汇报语言："首页 LCP 从 3.8s 到 2.4s，对应转化 +2.9%，月 GMV 增量约 110 万（AB 实验证据）"
```
