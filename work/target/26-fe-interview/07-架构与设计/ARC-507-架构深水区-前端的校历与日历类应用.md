## ARC-507：日历/日程类应用架构
**答**:
- 核心难题：跨天事件布局（同列多事件重叠的分区算法）、时区（跨时区参与者的显示与转换 ARC-481）、周期事件（RRULE 展开与例外）。
- 布局引擎：重叠事件分组（相交区间分组）→ 组内按开始时间排序 → 列分配（贪心：放到第一个不冲突的列）→ 宽度均分；月视图/周视图/日视图同一事件模型不同投影。
- 视口数据：按需加载可视范围事件（视图切换取数范围计算：周视图取该周 ± 缓冲）、跨月虚拟化。
- 周期事件：RRULE 展开（懒展开：只算可视窗口内的实例）+ 例外（本实例修改/删除 → 覆盖记录），实例 ID = 规则 ID + 偏移。
- 交互架构：拖拽改期（ARC-497 拖拽协议 + 时间吸附）、冲突检测（保存前重叠提示）、拖拽时预览布局实时重算。
```javascript
// 重叠事件布局（列分配）
function layout(events) {                                        // 同日事件
  const sorted = [...events].sort((a, b) => a.start - b.start || b.end - a.end);
  const groups = groupIntersecting(sorted);                      // 相交分组
  return groups.flatMap(g => {
    const cols = [];                                             // 贪心列分配
    for (const e of g) {
      const c = cols.find(col => col.at(-1).end <= e.start);
      c ? c.push(e) : cols.push([e]);
    }
    return g.map(e => ({ ...e, col: cols.findIndex(c => c.includes(e)), cols: cols.length }));
  });
}
```
