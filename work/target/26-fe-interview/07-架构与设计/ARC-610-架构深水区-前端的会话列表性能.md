## ARC-610：会话列表性能架构
**答**:
- 数据规模：千级会话 × 高频变更（新消息/未读/置顶/免打扰）——列表性能与更新风暴治理。
- 存储结构：会话索引（SQLite/IndexedDB 本地库 ARC-434：lastMsgTs 排序索引——排序查询 O(logn)）、列表分页加载（首屏 20 + 滚动加载）。
- 更新风暴治理：同一会话消息批量合并（500ms 内多消息一次更新）、排序变更节流（新消息 → 会话置顶——批量更新后一次重排）、增量 patch（单会话更新只 patch 该行——虚拟列表局部更新 ARC-442）。
- 排序与筛选：置顶/免打扰/折叠（群折叠策略——低频群折叠省视觉）、会话搜索（本地索引即时搜 ARC-383 + 服务端补）。
- 未读与总未读联动（ARC-502）：列表项未读数与总未读同源计算——本地库聚合，避免两处口径漂移。
- 恢复：会话列表冷启动加载（本地库秒开 + 增量同步拉新——离线优先架构 ARC-374）。
```javascript
// 本地库索引 + 批量更新
const sessions = db.table('sessions');                           // idx: pinned desc, lastTs desc
ws.on('messages', batch => {
  db.tx(() => batch.forEach(m => sessions.patch(m.convId, mergeMsg(m))));  // 批量合并
  rerenderThrottled();                                           // 一次重排渲染
});
```
