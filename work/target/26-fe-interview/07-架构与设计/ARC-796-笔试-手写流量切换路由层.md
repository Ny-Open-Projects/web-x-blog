## ARC-796：笔试：手写流量切换路由层

**答**：实现绞杀者模式的路由分流层：① 路由表：{ '/old/a': { new: '/new/a', strategy: 'percent' } }——老路由到新路由的映射；② 分流策略三种：percent（按用户哈希百分比——灰度切流）、whitelist（白名单用户先切）、full（全量已切）；③ 回退开关：切流后出问题 → 一键回退到老页面（路由表标记回退）；④ 分流决策的观测：每个请求记录 { path, strategy, chosen, userIdHash }（切流数据分析）；⑤ 路由表热更新（配置拉取 + 版本校验）。写出实现。

```javascript
class StranglerRouter {
  #routes = new Map(); #version = 0;
  constructor(configUrl) { this.#load(configUrl); }

  async #load(url) {
    const cfg = await fetchConfig(url);
    if (cfg.version <= this.#version) return;         // 版本校验防回退
    this.#version = cfg.version;
    this.#routes = new Map(Object.entries(cfg.routes));
  }

  resolve(path, userId) {
    const route = this.#routes.get(path);
    if (!route || route.strategy === 'full') return { target: route?.new ?? path, legacy: !route };
    if (route.rolledBack) return { target: path, legacy: true };    // 回退开关
    let useNew = false;
    if (route.strategy === 'percent')
      useNew = hash(`${path}:${userId}`) < route.percent / 100;
    if (route.strategy === 'whitelist')
      useNew = route.whitelist.includes(userId);
    track({ path, strategy: route.strategy, chosen: useNew ? 'new' : 'legacy' });
    return useNew ? { target: route.new, legacy: false } : { target: path, legacy: true };
  }
  rollback(path) {
    const r = this.#routes.get(path);
    if (r) { r.rolledBack = true; this.#persist(); }  // 一键回退标记
  }
}
function hash(s) { let h = 0; for (const c of s) h = (h * 31 + c.charCodeAt(0)) >>> 0; return (h % 1000) / 1000; }
// 用法: resolve('/old/a', 'user123') → { target: '/new/a', legacy: false }
//       出问题: rollback('/old/a') → 所有请求回老页面
```

**评分点**：
- 三种分流策略（percent/whitelist/full）+ 回退标记优先
- 一致性哈希（同用户稳定切流——体验一致）
- 观测记录（切流决策数据——分析切流效果）
- 热更新版本校验（配置回退防护）
