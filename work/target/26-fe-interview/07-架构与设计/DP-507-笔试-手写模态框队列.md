## DP-507：笔试：手写弹窗队列

**答**：实现模态框队列 `ModalQueue`：① push(modal)：{ id, priority, show: () => Promise }——按优先级排序入队；② 串行展示：一次只显示一个（前一个关闭 resolve 后出队下一个）；③ 去重：同 id 不重复入队（循环触发防护）；④ clearOnRoute：路由变化清队列（active 保留——按性质）；⑤ Promise 化：push 返回 Promise（弹窗关闭时的结果——调用方可 await）。写出实现。

```javascript
class ModalQueue {
  #queue = []; #active = null;
  push(modal) {
    if (this.#active?.id === modal.id || this.#queue.some((m) => m.id === modal.id)) return Promise.resolve(null);   // 去重
    return new Promise((resolve) => {
      this.#queue.push({ ...modal, resolve });
      this.#queue.sort((a, b) => a.priority - b.priority);
      this.#next();
    });
  }
  #next() {
    if (this.#active || !this.#queue.length) return;
    const m = this.#queue.shift();
    this.#active = m;
    Promise.resolve(m.show())                          // 展示 (内部 promise 在关闭时 resolve 结果)
      .then((result) => { m.resolve(result); this.#active = null; this.#next(); });
  }
  clearOnRoute() { this.#queue = []; }                 // active 保留 (跨路由弹窗按性质)
}
// 用法: const reason = await modalQueue.push({ id: 'login', priority: 0, show: () => loginModal() });
```

**评分点**：
- 优先级排序 + 串行展示（单活跃）
- 去重（同 id 防循环触发）
- push 的 Promise 化（结果回传——调用方可 await）
- 路由变化的清理策略（队列清 active 保留）
