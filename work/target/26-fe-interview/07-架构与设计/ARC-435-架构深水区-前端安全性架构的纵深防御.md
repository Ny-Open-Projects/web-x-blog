## ARC-435：前端安全的纵深防御体系
**答**:
- 纵深防御五层：输入层（不信任任何输入：富文本白名单净化 DOMPurify）、框架层（React/Vue 默认转义但警惕 dangerouslySetInnerHTML/v-html）、传输层（CSP 禁内联 + nonce，ARC-155）、运行时（Trusted Types 强制 sink 检查）、监测层（CSP report + 错误监控联动）。
- 信任链设计：第三方脚本是最薄弱环——白名单 + SRI 哈希锁定（ARC-363）+ 定期审计；动态 script 注入统一走受控 loader。
- 攻击面清单化：URL 参数回显（反射 XSS）、postMessage（origin 校验）、localStorage 敏感数据、JSONP 遗留、开放重定向。每项有 owner 与检测手段。
- 安全默认值：安全配置进脚手架模板（CSP/cookie 属性/referrer policy 默认就绪），新项目"出生即安全"。
- 度量：安全扫描通过率、CSP 违规报告趋势、漏洞修复时长；渗透测试季度化。
```javascript
// 纵深关键配置
const securityDefaults = {
  csp: "default-src 'self'; script-src 'self' 'nonce-{NONCE}'; report-uri /csp-report",
  cookies: { httpOnly: true, sameSite: 'Lax', secure: true },
  referrerPolicy: 'strict-origin-when-cross-origin',
  trustedTypes: 'require-trusted-types-for \'script\''
};
// 富文本净化：白名单标签+属性，剥离事件与 javascript: 协议
const clean = DOMPurify.sanitize(rawHtml, { ALLOWED_TAGS: ['p','b','img','a'], ALLOWED_ATTR: ['href','src'] });
```
