## ARC-508：通讯录/组织架构前端架构
**答**:
- 规模挑战：万人组织树全量渲染不可能——分层加载（部门懒加载 ARC-485）+ 搜索驱动（大组织主要靠搜，服务端搜索 ARC-383 + 拼音/别名词典）。
- 选择器架构：树选择（部门级）/人员多选（结果集扁平展示 + 回显）/跨域选择（外部联系人）；选择状态独立于树结构（selectedIds 集合，树只是导航）。
- 搜索与导航融合：搜索结果点击 → 定位树路径（懒加载树按路径逐层展开）；最近选择记忆。
- 性能：单部门千人扁平列表虚拟滚动、头像懒加载、搜索防抖 + 拼音首字母匹配本地缓存索引。
- 数据一致性：组织变更（调岗/离职）的失效（人员详情即查不缓存长 TTL）；已选人员失效态（离职标记，提交时服务端校验）。
```javascript
// 搜索定位展开
async function locate(nodeId) {
  const path = await api.nodePath(nodeId);                       // [{id,parentId},...]
  for (const n of path) await tree.ensureLoaded(n.id);           // 逐层懒加载
  tree.expandPath(path); tree.scrollTo(nodeId); tree.select(nodeId);
}
// 选择：selected = new Map(id => node)，树导航只是取数，选择状态独立存储
```
