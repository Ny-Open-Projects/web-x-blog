## ARC-522：文件预览统一层
**答**:
- 统一接口：preview(file) 返回预览描述（类型 + 渲染器 + 源 URL），调用方不关心实现——渲染器注册表（图片/PDF/视频/Office 转码预览/文本）按 MIME + 扩展名路由。
- 渲染器分派：图片（缩略图→原图渐进，ARC-341 处理链路）、PDF（pdf.js 流式渲染大文件分页）、Office（服务端转码为 PDF/HTML，转码异步任务 ARC-486）、视频（MSE 流式 ARC-378）、文本（分段加载 + 代码高亮）。
- 安全：预览源走签名 URL + 过期（ARC-340）、HTML 类预览沙箱（iframe sandbox + CSP，防注入）、大文件限制（超限给下载入口而非预览）。
- 体验细节：预览失败降级（转码失败 → 提示下载）、预览历史（最近预览快速回到上次页码）、移动端手势（捏合缩放/翻页）。
- 性能：预览实例销毁回收（大 PDF 内存控制）、并发预览限制（Worker/转码配额）。
```javascript
const renderers = new Map();
function registerPreview(type, impl) { renderers.set(type, impl); }
async function preview(file) {
  const r = pickRenderer(file, renderers);                       // MIME + 扩展路由
  if (!r) return offerDownload(file);                            // 未知类型降级下载
  const url = await signUrl(file, { disposition: 'inline', expires: 300 });
  return r.render(url, { file, sandbox: r.needsSandbox });       // 统一入口
}
```
