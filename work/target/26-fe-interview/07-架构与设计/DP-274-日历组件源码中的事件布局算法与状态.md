## DP-274：源码识别：日历周视图源码中的重叠布局算法？
**答**:
- 算法核心（区间重叠分组）：事件按开始时间排序 → 扫描线判定重叠簇（当前簇内事件的 maxEnd > 下一事件 start 则同簇）→ 簇内按列分配（贪心：找第一个不冲突的列）。
- 状态：事件拖拽改时间 → 布局重算（纯函数，输入事件集输出 { top, height, left, width }）。
- 策略：相等宽度（簇内均分）vs 嵌套宽度（按冲突深度缩进）两种呈现策略。
- 识别要点：能手写"重叠簇检测 + 列分配"——日历布局题是大厂手写高频。

```javascript
// 周视图布局算法（源码级简化）
function layout(events) {
  const sorted = [...events].sort((a, b) => a.start - b.start);
  const clusters = [];
  let cluster = [];
  let maxEnd = -Infinity;
  for (const ev of sorted) {
    if (cluster.length && ev.start >= maxEnd) { clusters.push(cluster); cluster = []; maxEnd = -Infinity; }
    cluster.push(ev);
    maxEnd = Math.max(maxEnd, ev.end);          // 扫描线：重叠簇
  }
  if (cluster.length) clusters.push(cluster);
  return clusters.flatMap(cluster => {
    const cols = [];
    for (const ev of cluster) {                  // 贪心列分配
      const col = cols.findIndex(colEnd => ev.start >= colEnd);
      if (col === -1) cols.push(ev.end); else cols[col] = ev.end;
      ev.col = col === -1 ? cols.length - 1 : col;
    }
    const n = cols.length;
    return cluster.map(ev => ({ ...ev, left: `${ev.col * 100 / n}%`, width: `${100 / n}%` }));  // 均分策略
  });
}
```
