## DP-350：笔试题：手写主题热切换（无闪变+SSR）？
**答**：实现 ThemeSwitcher：1) data-theme 切换 + CSS Variables；2) 切换时禁用 transition 防闪烁；3) SSR：首屏内联当前主题 style（读 Cookie）；4) 系统主题跟随（prefers-color-scheme）+ 用户覆盖优先。
**评分点**：
- 禁 transition 时机正确（切换前禁、rAF 后恢复）。
- SSR Cookie 读取与内联样式正确。
- 优先级正确（用户显式 > 系统）。
- storage 事件同步多标签页。
```javascript
function initTheme(serverCookie) {
  const user = serverCookie ?? localStorage.getItem('theme');   // 3) SSR Cookie
  const system = matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
  applyTheme(user ?? system);                                   // 4) 优先级
  matchMedia('(prefers-color-scheme: dark)').addEventListener('change', e => {
    if (!localStorage.getItem('theme')) applyTheme(e.matches ? 'dark' : 'light');   // 无用户覆盖才跟随
  });
  addEventListener('storage', e => e.key === 'theme' && applyTheme(e.newValue));   // 多标签同步
}
function applyTheme(theme) {
  const root = document.documentElement;
  root.style.setProperty('--theme-transitioning', '1');         // 2) 禁 transition
  root.classList.add('theme-transitioning');
  root.dataset.theme = theme;
  localStorage.setItem('theme', theme);                         // 3) 同步（SSR 下次读 Cookie 亦可）
  requestAnimationFrame(() => requestAnimationFrame(() =>
    root.classList.remove('theme-transitioning')));
}
// SSR 模板：<html data-theme="<%= theme %>"><style>[data-theme=dark]{...}</style>
```
