## ARC-472：富文本编辑器架构选型
**答**:
- 选型核心是数据模型：contenteditable + HTML（ProseMirror 系：schema 严格、插件生态）vs 自定义 Model（Slate/Lexical/Quill Delta：模型优先、协作友好）vs 文档级（块编辑器 Notion 风格：Block 粒度，协作简单）。
- 决策因素：内容复杂度（简单评论用 Quill；结构化文档 ProseMirror；Notion 类产品用块模型自研/Lexical）、协作需求（CRDT 集成：Yjs 与各模型适配层）、移动端 IME 兼容（国内安卓输入法是重灾区，选社区验证过的实现）。
- 架构分层：数据模型（文档树 + 事务）→ 命令系统（ARC-456）→ 视图渲染（受控 DOM 同步）→ 插件层（schema 扩展/快捷键/粘贴净化）。
- 粘贴是重灾区：从 Word/网页粘贴进来的是脏 HTML——粘贴管道（净化 → schema 过滤 → 资源转存）必须架构级设计，不能事后补。
- 服务端配合：文档存储用结构化 JSON（不做 HTML 反解析）、版本与快照、敏感词审核钩子。
```javascript
// 粘贴净化管道（ProseMirror 伪码）
editorProps.handlePaste = (view, event) => {
  const html = event.clipboardData.getData('text/html');
  if (fromWord(html)) {                                        // Word 粘贴特殊处理
    const doc = word2Prose(html);                              // 样式转语义
    view.dispatch(view.state.tr.replaceWith(0, view.state.doc.content.size, doc));
    return true;
  }
  const clean = DOMPurify.sanitize(html, { FORBID_TAGS: ['style', 'script'] });
  return false;                                                // 交给默认 schema 过滤
};
```
