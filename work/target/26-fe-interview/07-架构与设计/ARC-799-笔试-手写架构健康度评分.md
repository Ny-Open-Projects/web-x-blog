## ARC-799：手写健康度评分

**答**：实现应用架构健康度评分 `healthScore(app)`：① 五维度输入：性能（LCP P75/INP）、质量（错误率/覆盖率）、效率（构建 P50/发布频率）、安全（CSP 覆盖/漏洞存量）、体积（JS 大小/依赖健康）——各维度 0~100 分；② 评分规则引擎：每维度的指标→分数映射（阈值阶梯配置化——不同应用不同基线）；③ 加权总分：维度权重可配（核心应用性能权重高）；④ 等级映射：A(≥90)/B(≥75)/C(≥60)/D(<60) + Top 劣化维度标注；⑤ 趋势对比：与上月得分 diff（各维度升降标注）。写出实现。

```javascript
const DIMENSIONS = {
  performance: { weight: 0.3, metrics: [
    { key: 'lcp75', map: (v) => v < 2000 ? 100 : v < 2500 ? 80 : v < 4000 ? 50 : 20 } ],
  },
  quality: { weight: 0.25, metrics: [
    { key: 'errorRate', map: (v) => v < 0.001 ? 100 : v < 0.005 ? 80 : v < 0.01 ? 50 : 20 },
    { key: 'coverage', map: (v) => v * 100 } ] },
  // efficiency / security / size 同构...
};

function healthScore(app, prev) {
  const dims = {};
  let total = 0, totalW = 0;
  for (const [name, { weight, metrics }] of Object.entries(DIMENSIONS)) {
    const scores = metrics.map((m) => {
      const v = app.metrics[m.key];
      return v == null ? 0 : Math.min(100, m.map(v));
    });
    const score = scores.reduce((a, b) => a + b, 0) / scores.length;
    dims[name] = Math.round(score);
    total += score * weight; totalW += weight;
  }
  const overall = Math.round(total / totalW);
  const grade = overall >= 90 ? 'A' : overall >= 75 ? 'B' : overall >= 60 ? 'C' : 'D';
  // Top 劣化维度
  const worst = Object.entries(dims).sort((a, b) => a[1] - b[1]).slice(0, 2).map(([k]) => k);
  const trend = prev ? Object.fromEntries(Object.keys(dims).map((k) => [k, dims[k] - (prev.dims?.[k] ?? dims[k])])) : null;
  return { overall, grade, dims, worst, trend };
}
```

**评分点**：
- 阈值阶梯映射（配置化——不同应用不同基线）
- 加权总分 + 权重可配（核心应用侧重不同）
- Top 劣化维度标注（行动指向）
- 趋势 diff（升降标注——比单点分数有价值）
