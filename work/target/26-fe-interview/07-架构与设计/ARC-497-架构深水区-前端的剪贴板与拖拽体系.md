## ARC-497：剪贴板与拖拽体系架构
**答**:
- 拖拽架构分层：交互原语（pointer 事件 + capture）、语义层（draggable 数据模型：携带类型化 payload）、放置协议（drop 目标声明可接受类型）、反馈层（自动滚动/吸附/占位动画）。用成熟库（dnd-kit/Atlassian PRagmatic drag and drop）但要理解协议。
- 跨容器拖拽：payload 声明 MIME 式类型（'application/x.task'），目标按类型决定接受与否——类型系统防止"把节点拖进搜索框"类事故。
- 剪贴板集成：复制/剪切/粘贴与拖拽共享同一序列化协议（clipboardData 写 JSON payload + 纯文本 fallback）；粘贴净化（外部来源 payload 不可信，过 schema）。
- 无障碍：拖拽必须提供键盘替代（选中 → 剪切 → 粘贴；或 move-to 命令），屏幕阅读器可感知位置变化（aria-live）。
- 触屏与滚动：长按拖拽（区分滚动）、拖拽边缘自动滚动（AutoScroller）、iOS Safari 的 pointer 特性处理。
```javascript
// 类型化拖拽协议
const TASK = 'application/x.task';
item.onDragStart = (e) => e.dataTransfer.setData(TASK, JSON.stringify(task));
list.onDragOver = (e) => { if (e.dataTransfer.types.includes(TASK)) e.preventDefault(); };
list.onDrop = (e) => {
  const task = JSON.parse(e.dataTransfer.getData(TASK));      // 类型校验过的 payload
  store.move(task.id, list.id, dropIndex(e));
};
```
