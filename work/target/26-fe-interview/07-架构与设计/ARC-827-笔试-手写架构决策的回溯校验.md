## ARC-827：手写决策回溯

**答**：实现架构决策的回溯校验器 `DecisionAuditor`：① 输入：ADR 库 + 决策后的实际数据（性能/质量指标 + 实施完成度）；② 兑现校验：ADR 中承诺的 consequences（后果）逐条核对——「决策说会带来 X」实际 X 发生了吗；③ 偏差分类：未实施（决策没落地）/实施了但效果不符（决策错误）/实施了且符合（正确决策）——三类统计；④ 决策质量画像：按决策类型（选型/架构/流程）统计正确率——哪类决策容易错（未来更谨慎）；⑤ 输出：决策质量报告 + 需复审的 ADR 清单（偏差决策的复审日触发）。写出实现。

```javascript
class DecisionAuditor {
  audit(adr, actualData) {
    const results = [];
    for (const consequence of adr.expectedConsequences ?? []) {
      const check = consequence.verify(actualData);    // 每条后果有验证函数
      results.push({ consequence: consequence.desc, expected: consequence.expected,
        actual: check.actual, pass: check.pass });
    }
    const implemented = actualData.implemented ?? false;
    const allPass = results.every((r) => r.pass);
    const category = !implemented ? 'not-implemented'
      : allPass ? 'correct' : 'wrong-expectation';
    return { adrId: adr.id, category, results };
  }
  report(adrs, actualDataMap) {
    const audited = adrs.map((adr) => this.audit(adr, actualDataMap[adr.id] ?? {}));
    const byCategory = groupCount(audited, 'category');
    // 按决策类型统计正确率
    const byType = {};
    for (const a of audited) {
      const type = adrs.find((x) => x.id === a.adrId).type;
      (byType[type] ??= { total: 0, correct: 0 });
      byType[type].total++;
      if (a.category === 'correct') byType[type].correct++;
    }
    const needsReview = audited
      .filter((a) => a.category === 'wrong-expectation')
      .map((a) => adrs.find((x) => x.id === a.adrId));
    return { byCategory, byType: Object.fromEntries(Object.entries(byType).map(([k, v]) => [k, `${v.correct}/${v.total}`])),
      needsReview };
  }
}
// ADR 侧需支持: expectedConsequences: [{ desc, expected, verify: (data) => ({ pass, actual }) }]
// — 决策时写下「可验证的预期」是复盘的前提
```

**评分点**：
- consequences 逐条验证（决策时写「可验证预期」——复盘前提）
- 三类偏差分类（未实施/预期错误/正确）
- 决策类型画像（哪类决策容易错——选型 vs 流程）
- 复审清单输出（偏差决策的 ADR 复审日触发）
