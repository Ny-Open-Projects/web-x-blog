## DP-521：笔试：手写熔断感知重试

**答**：实现重试与熔断的感知集成：① 重试的每次失败计入熔断器（连续失败计数包含重试的失败——熔断感知）；② 熔断 open 后重试立即终止（不再发起——快速失败）；③ half-open 的重试：探测成功重置计数，探测失败立即 open（半开态不做多次重试）；④ 指标：重试产生的失败 vs 原生失败的分离统计（归因——重试是否放大了失败）；⑤ 半开的探测请求限定（每次冷却期只允许一次真实探测——其余快速失败）。写出实现。

```javascript
class RetryAwareBreaker {
  #fails = 0; #state = 'closed'; #probed = false;
  async call(fn) {
    if (this.#state === 'open') throw new CircuitOpenError();   // 重试立即终止
    if (this.#state === 'half-open') {
      if (this.#probed) throw new CircuitOpenError();  // 已有探测, 其余快速失败
      this.#probed = true;
      try { const r = await fn(); this.#reset(); return r; }
      catch (e) { this.#fail('probe'); throw e; }
    }
    try { const r = await fn(); this.#reset(); return r; }
    catch (e) { this.#fail('retry'); throw e; }        // 重试失败也计数
  }
  #fail(kind) {
    this.#fails++;
    metrics.incr(`breaker.fail.${kind}`);              // 归因: 重试失败 vs 原生失败
    if (this.#fails >= this.threshold) { this.#state = 'open'; this.#openedAt = Date.now(); }
  }
  #reset() { this.#fails = 0; this.#state = 'closed'; this.#probed = false; }
}
// 半开 + 重试: 探测成功 → closed → 后续重试正常; 探测失败 → open → 重试快速失败
```

**评分点**：
- 重试失败计入熔断计数（感知——否则熔断在重试下失效）
- half-open 探测唯一性（并发探测风暴防护）
- 重试失败 vs 原生失败的归因统计
- open 后重试立即终止（快速失败——不雪上加霜）
