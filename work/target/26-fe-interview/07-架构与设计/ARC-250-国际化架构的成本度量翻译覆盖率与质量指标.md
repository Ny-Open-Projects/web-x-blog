## ARC-250：国际化架构的成本度量：翻译覆盖率与质量指标？
**答**：
- 覆盖率定义要精确：不是"翻译了 N 条"，而是**用户路径覆盖**（Top 流量页面 × 语言的 key 覆盖率）与**展示覆盖**（实际渲染的文案里机翻/人工/缺失占比——missing 走 fallback 也算指标）。
- 质量指标：机翻后人工修改率（越低越好，反向衡量 AI 预翻质量）、线上文案反馈率（用户举报按钮）、术语一致性检查通过率。
- 成本指标：每语言翻译条数×单条成本、语言包体积、i18n 相关 bug 率（RTL/复数类 bug 单列）。
- 用数据驱动开放策略：新语言在"核心路径覆盖 > 98% 且质量达标"后才在语言入口开放（与 ARC-247 呼应）。

```typescript
// 覆盖率报表（CI 产出）
function coverage(lang: string, paths: string[]) {
  const keys = paths.flatMap(p => collectKeys(p));
  const translated = keys.filter(k => dict[lang][k] && !isMachineOnly(lang, k));
  return {
    pathCoverage: translated.length / keys.length,       // 目标 P0 路径 > 98%
    machineRatio: countMachine(lang) / keys.length,      // 机翻占比（越高质量风险越大）
    fallbackRate: runtimeMissingCounter.get(lang) ?? 0,  // 线上真实缺失次数（RUM）
  };
}
// RUM：t() 落入 fallback 时计数上报 → fallbackRate 是"真实缺失"的金标准
```
