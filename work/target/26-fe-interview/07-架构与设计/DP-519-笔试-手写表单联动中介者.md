## DP-519：笔试：手写联动中介者

**答**：实现表单联动中介者 `FormMediator`：① 联动规则声明：{ watch: ['country'], effect(ctx, api) }——多字段监听；② effect 的能力集：setRequired/setVisible/setValue/disable（受限 API——字段不能任意操作彼此）；③ 联动的循环防护：effect 修改字段 → 再次触发联动 → 环检测（单次变更的处理深度 ≤3）；④ 规则的优先级（数组顺序即执行序——显式化）；⑤ 与校验的联动：require 变化触发重校验。写出实现。

```javascript
class FormMediator {
  #rules = []; #values = {}; #depth = 0;
  #api = {
    setRequired: (f, v) => this.#emit('required', f, v),
    setVisible: (f, v) => this.#emit('visible', f, v),
    setValue: (f, v) => this.setField(f, v),           // setValue 触发联动 (递归)
    disable: (f, v) => this.#emit('disabled', f, v),
  };
  addRule(rule) { this.#rules.push(rule); }
  setField(name, value) {
    if (this.#depth > 3) throw new Error('联动循环: 深度超限');   // 环防护
    this.#values[name] = value;
    this.#depth++;
    try {
      for (const rule of this.#rules)                  // 顺序即优先级
        if (rule.watch.includes(name) && rule.when(this.#values))
          rule.effect(this.#values, this.#api);
    } finally { this.#depth--; }
    this.#emit('change', name, value);
  }
  #emit(...args) { /* 通知 UI */ }
}
// 规则: { watch: ['country'], when: (c) => c.country === 'CN',
//         effect: (c, api) => api.setRequired('taxId', false) }
```

**评分点**：
- 受限 API（字段不能任意操作彼此——能力集约束）
- 环检测（联动深度 ≤3——递归防护）
- 顺序即优先级（规则数组序）
- 联动触发重校验（require 变化 → 校验联动）
