## ARC-619：表单无障碍进阶
**答**:
- 动态校验的朗读：错误出现时机与朗读策略（失焦校验 → aria-describedby 关联错误 + role=alert 朗读——提交时错误汇总聚焦第一个错误 ARC-384 错误协议的 a11y 扩展）、错误清除也要可感知（修复后 aria-invalid 更新）。
- 复杂控件：自定义组件的完整语义（日期选择/滑块/级联——原生 input 失败时的 ARIA 模式：grid/listbox/combobox 角色 + 键盘 ARC-578）、表单关联（label for/aria-labelledby——视觉隐藏 label 的正确姿势（sr-only 而非 display:none））。
- 状态表达：必填（aria-required + 视觉*——两者都要）、加载中（提交按钮 aria-busy——防重复提交语义）、步骤表单（aria-current 步骤进度 ARC-489）。
- 提交流程：成功/失败结果的朗读（aria-live=polite 状态区——不要打断用户输入）、超时与自动保存提示（ARC-483 草稿的 a11y 通知）。
- 验证：屏幕阅读器表单走查（NVDA/VoiceOver 完整走一遍提交流程——含错误路径）、自动化（axe 表单规则 ARC-577）。
```html
<!-- 校验错误关联 -->
<input id="phone" aria-describedby="phone-err" aria-invalid="true">
<p id="phone-err" role="alert">手机号格式不正确</p>
<!-- 朗读：聚焦输入框时读 label + 错误；错误出现时 role=alert 主动朗读 -->
```
