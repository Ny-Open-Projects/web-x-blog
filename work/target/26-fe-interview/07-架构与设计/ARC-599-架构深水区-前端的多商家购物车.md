## ARC-599：多商家购物车架构
**答**:
- 数据模型：购物车 = 商家分组（店维度分组渲染与结算）× 商品行（sku + 数量 + 优惠标记）；跨店优惠（满减券跨店分摊——服务端分摊算法，前端只展示分摊结果不自己算 ARC-582 金额红线）。
- 状态架构：购物车 store 单源（ARC-467）+ 服务端权威（多端同步：Web 加购小程序可见——服务端购物车 + 本地乐观 ARC-386 回写）、失效商品处理（下架/改价：保留展示 + 置灰 + 结算拦截）。
- 交互一致性：选中状态（店级全选/商品勾选——勾选状态本地 UI 态，结算以提交选中集为准）、数量边界（库存上限实时校验——修改即校验防结算失败）。
- 结算链路：结算预检（价格/库存/优惠重算——提交前服务端确认，价格变了明确提示让用户确认新价）、分店结算限制（部分商家不支持跨店 → 结算分组）。
- 性能：百条商品渲染虚拟化（ARC-442）、数量修改防抖批量同步（ARC-483）。
```javascript
// 购物车 store（商家分组 + 服务端权威）
const cart = createStore({ groups: bySeller(serverCart), selected: new Set() });
async function checkout(sellerIds) {
  const pre = await api.checkoutPrecheck([...cart.selected]);    // 服务端重算
  if (pre.priceChanged) return confirmNewPrice(pre);             // 价格变化确认
  navigate('/checkout', { state: { items: pre.items, splitBy: 'seller' } });
}
```
