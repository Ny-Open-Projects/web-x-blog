## ARC-503：活动页快速生产架构
**答**:
- 定位：高频、强视觉、短生命周期页面。架构目标：运营自助 + 性能不崩 + 风险可控（ARC-173 低代码营销页的全链路）。
- 分层：物料层（轮播/倒计时/抽奖/表单等标准组件 + 模板）、搭建层（拖拽或模板参数化——二选一按运营能力定）、发布层（静态化 + CDN + 秒级发布，ARC-102）。
- 性能纪律：活动页是性能重灾区（大图/动画/第三方 SDK）——性能预算硬卡点（首屏 < 200KB）、图片走处理链路（ARC-441）、动画只 transform（ARC-471）、第三方 SDK 延迟加载。
- 风险控制：活动页与主站隔离部署（崩了不影响主站）、降级兜底页、大促演练（ARC-264）、二维码防刷与风控（ARC-107）。
- 治理：活动模板沉淀（同类活动复用模板参数化）、过期活动自动归档（CDN 清理）、搭建数据统计（自助率、平均耗时）。
```javascript
// 活动页 schema（模板参数化）
const activitySchema = {
  template: 'lottery-v3',
  tokens: { primaryColor: '#ff4d4f' },                           // 主题参数
  blocks: [
    { type: 'banner', src: '/act/spring/banner.avif' },
    { type: 'countdown', endAt: '2026-11-20T00:00:00Z' },
    { type: 'lottery', prizes: api.prizes, rules: '/act/spring/rules.html' }
  ],
  budget: { css: 30, js: 120, img: 100 }                         // KB 硬卡点
};
```
