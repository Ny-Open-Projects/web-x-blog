## DP-528：笔试：手写快照对比

**答**：实现文档快照的版本管理 `SnapshotStore`：① save(content)：快照入栈（带时间戳与作者）；② diff(v1, v2)：两版本的结构化差异（新增/删除/修改段落的列表——非全文 diff）；③ 相似度去重：连续快照内容相似度 >95% 不入栈（自动保存去重——相似度用编辑距离比例）；④ 恢复任意版本 + 当前与任意版本的 diff 预览；⑤ 容量管理：快照上限 50——溢出按「保留首尾+均匀采样」策略删中间（保留跨度）。写出实现。

```javascript
class SnapshotStore {
  #snaps = [];
  save(content, author) {
    // 相似度去重: 与上一版本比较
    if (this.#snaps.length) {
      const prev = this.#snaps.at(-1).content;
      if (similarity(prev, content) > 0.95) return null;   // 相似不入栈
    }
    const snap = { id: crypto.randomUUID(), content, author, at: Date.now() };
    this.#snaps.push(snap);
    if (this.#snaps.length > 50) this.#prune();
    return snap.id;
  }
  #prune() {                                           // 保首尾+均匀采样
    const keep = new Set([0, this.#snaps.length - 1]);
    for (let i = 1; i < this.#snaps.length - 1; i += 2) keep.add(i);
    this.#snaps = this.#snaps.filter((_, i) => keep.has(i));
  }
  diff(v1, v2) {
    const a = this.#snaps.find((s) => s.id === v1).content;
    const b = this.#snaps.find((s) => s.id === v2).content;
    return deepDiff(a, b);                             // 结构化差异清单
  }
}
function similarity(a, b) { const d = levenshtein(a, b); return 1 - d / Math.max(a.length, b.length); }
```

**评分点**：
- 相似度去重（>95% 不入栈——自动保存防膨胀）
- 结构化 diff（段落级差异非全文）
- 采样式裁剪（保首尾+均匀采样——保留时间跨度）
- 恢复任意版本 + diff 预览（回溯体验）
