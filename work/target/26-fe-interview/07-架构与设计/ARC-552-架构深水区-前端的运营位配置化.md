## ARC-552：运营位配置化架构
**答**:
- 运营位模型：位置注册（页面/锚点：首页顶部 Banner/退出挽留弹窗）、投放配置（素材/链接/排期/人群定向/频次控制）、渲染契约（各位置支持的能力 schema：尺寸/素材类型）。
- 配置化渲染：客户端拉运营位配置（配置中心 ARC-369）→ 按位置 + 定向过滤 → 渲染器分派（图片/视频/富文本/H5 模板类型）→ 展示频控（同素材每天最多 N 次，存储频控计数）。
- 定向能力：人群定向（标签/AB 分桶联动 ARC-390——运营位是实验天然载体）、地域/时段/设备定向；定向表达式 schema 化（运营可配）。
- 安全与体验：素材审核（文案合规 ARC-458）、弹窗频控上限（全局弹窗配额——防多模块弹窗轰炸用户体验）、兜底（配置拉取失败隐藏而非白屏）。
- 效果闭环：曝光/点击/转化埋点（ARC-535 标准事件）→ 运营位效果看板 → 低效位清理。
```javascript
// 运营位渲染管线
const slots = await cms.getSlots({ page: 'home', user: audienceCtx });
for (const slot of slots) {
  const hit = filterByAudience(slot, audienceCtx) && freqCtrl.allow(slot.id, uid);
  if (!hit) continue;
  const R = slotRenderers[slot.type];                            // banner/video/rich
  mount(slot.anchor, R(slot, { track: (e) => trackSlotEvent(slot, e) }));
}
```
