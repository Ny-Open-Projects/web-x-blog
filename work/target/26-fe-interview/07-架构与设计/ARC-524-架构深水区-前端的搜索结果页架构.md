## ARC-524：统一搜索结果页架构
**答**:
- 多类型聚合：一次搜索返回多类型结果（商品/文档/用户/话题）——聚合协议（分类型槽位展示 + "查看全部 X"入口）；搜索服务端聚合（NODE-387）或前端并发多源合并（ARC-383 混合搜索）。
- 状态与 URL：搜索词/类型 tab/过滤条件全入 URL（ARC-389 可分享可回退）；输入联想（ARC-383）与结果页解耦（联想高并发走轻接口）。
- 渲染分派：结果项渲染器按类型注册（每类型卡片组件 + 高亮策略）——统一搜索不知道具体业务类型。
- 竞态与体验：输入防抖 + 请求取消 + 只采纳最新（ARC-383）；空结果引导（放宽建议/热门推荐）；无结果类型的 tab 隐藏（动态 tab 集由响应决定）。
- 数据闭环：搜索点击埋点（结果位置/类型——相关性优化依据 ARC-385）。
```javascript
// 多类型聚合渲染
const typeRenderers = { goods: GoodsCard, doc: DocCard, user: UserCard };
function SearchResults({ data }) {
  return data.groups.map(g => (
    <section key={g.type}>
      <h3>{g.label}（{g.total}）<Link to={`/search/${g.type}`}>全部</Link></h3>
      {g.items.map(item => {
        const R = typeRenderers[g.type];
        return <R key={item.id} {...item} kw={data.kw} onExpose={trackExpose} />;  // 类型分派
      })}
    </section>
  ));
}
```
