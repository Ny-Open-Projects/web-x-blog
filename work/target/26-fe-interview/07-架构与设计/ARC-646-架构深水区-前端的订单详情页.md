## ARC-646：订单详情页架构
**答**:
- 数据结构：订单主单（状态/金额构成 ARC-644）+ 子单/包裹（拆单发货——每包裹物流独立 ARC-615）+ 状态时间线（全流程节点：下单/支付/发货/签收——时间轴组件）。
- 操作集：服务端下发（当前可做：支付/取消/催发货/确认收货/售后/评价——各状态操作不同，危险操作确认 ARC-509）、操作后局部刷新（状态变更 → 时间线/操作集/角标联动更新 ARC-641）。
- 资金联动：支付信息（支付方式/交易号）、退款进度（ARC-625 嵌入——售后单关联展示）、发票（开票入口与状态 ARC-626）。
- 一致性：多来源数据聚合（订单/物流/售后/发票——BFF 聚合一致性 NODE-492 口径映射）、实时性（关键状态变更推送 + 轮询兜底——查单事实源）。
- 性能：详情页重资源懒加载（商品大图/富文本详情）、子单包裹折叠展开。
```javascript
const order = await api.orderDetail(id);                         // BFF 聚合（订单+物流+售后+发票）
<OrderDetail {...order} actions={order.actions} />               // 操作集渲染
bus.on(`order:${id}:updated`, (patch) => orderStore.patch(patch));// 状态推送局部更新
```
