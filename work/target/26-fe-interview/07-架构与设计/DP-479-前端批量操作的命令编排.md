## DP-479：批量操作编排

**答**：
- 批量操作的模式组合：命令（批量操作 = 复合命令——每子项一个子命令）、策略（失败策略：遇错停止/跳过继续/回滚全部）、观察者（进度事件：done/total/failed）、备忘录（批量快照——整体回滚）
- 失败策略的语义：全成功才提交（事务性——服务端 batch 接口）vs 逐条提交部分成功（最终一致 UI 标注失败项）——策略按业务一致性要求
- 进度与取消：批量进行中可取消（已完成的保留——不回滚）——取消的语义边界
- 深水点：批量的「幂等与重试」——失败项重试只重试失败的（幂等键——成功的不会重复执行）

```javascript
async function batchProcess(items, { onFail = 'skip' } = {}) {
  const results = { ok: [], failed: [] };
  for (const item of items) {                         // 串行: 保序
    try { await op(item, { idempotencyKey: item.id }); results.ok.push(item); }
    catch (e) {
      if (onFail === 'stop') { /* 回滚已完成 */ throw e; }
      results.failed.push({ item, error: e });
    }
  }
  return results;                                     // 失败项 UI 标注 + 可重试
}
```
