## ARC-617：分享海报生成
**答**:
- 生成路线：Canvas 绘制（html2canvas/satori——DOM 转图：兼容性坑多（字体/阴影/跨域图）vs 模板化绘制（原生 Canvas API 按模板画——可控性高）vs 服务端生成（Puppeteer 模板渲染——复杂海报保真 ARC-496）。选型：简单二维码海报前端模板绘制；复杂排版/批量服务端。
- 前端模板绘制架构：海报模板协议（图层声明：背景/文字/图片/二维码——数据驱动绘制）、资源预加载（跨域图片 CORS + 转存代理——canvas 污染问题：图片必须同源或 CORS 头）、字体嵌入（base64 字体或已加载字体——绘制时字体可用性保证 ARC-495）。
- 分享链路：生成的图上传（ARC-377 短时效）→ 分享参数（小程序卡片/链接——分享配置服务端下发）、二维码参数签名（防伪造分享链接——带追踪参数）。
- 性能与体验：生成耗时控制（< 2s——预绘制模板缓存）、失败降级（生成失败 → 分享纯链接）、水印与合规（分享图防篡改标识、诱导分享红线）。
```javascript
// 模板化海报绘制
const tpl = await fetchPosterTemplate('invite');                  // 图层声明（服务端配置）
await preloadAssets(tpl.layers);                                  // CORS 图预载
const canvas = drawLayers(tpl.layers, { user: { avatar, nickname }, qrcode: signedQr });
const blob = await canvas.toBlob();
const { url } = await upload(blob);                               // 上传后分享
```
