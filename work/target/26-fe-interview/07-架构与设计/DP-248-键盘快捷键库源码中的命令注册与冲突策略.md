## DP-248：源码识别：快捷键库源码中的命令注册与冲突策略？
**答**:
- 命令注册表：bind('mod+k', handler) 把"按键序列 → 命令"存 Map；按键事件查表执行——命令模式的最小落地。
- 策略（冲突解决）：同快捷键多 handler 时的策略（后注册优先/作用域优先/全部执行），以及作用域（全局 vs 输入框聚焦内）判定。
- 状态机：组合键等待态（按下 mod 后等待下一个键，超时取消）——带超时的等待状态。
- 识别要点：能解释"preventDefault 时机：命中命令才拦截，未命中放行浏览器默认"。

```javascript
// 快捷键库（源码级简化）
class Shortcuts {
  registry = new Map();        // 'mod+k' → [{ handler, scope, priority }]
  waiting = null;              // 组合键等待态
  bind(combo, handler, { scope = 'global', priority = 0 } = {}) {
    this.registry.get(combo) ?? this.registry.set(combo, []);
    this.registry.get(combo).push({ handler, scope, priority });
  }
  onKeydown(e) {
    const combo = formatCombo(e);              // 'mod+shift+k' 规范化
    const cands = this.registry.get(combo) ?? [];
    const active = cands.filter(c => this.scopeActive(c.scope));   // 作用域过滤
    if (active.length) {
      active.sort((a, b) => b.priority - a.priority)[0].handler(e);  // 冲突策略：优先级最高
      e.preventDefault();                      // 命中才拦截
    }
  }
  // 组合键等待：'mod,shift,k' 序列 → 按下 mod 后进入 waiting，500ms 超时放弃
  // scopeActive：document.activeElement 在 input 内时 'input' 作用域命令才生效
}
```
