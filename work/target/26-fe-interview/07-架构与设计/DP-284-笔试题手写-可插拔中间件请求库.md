## DP-284：笔试题：手写可插拔中间件请求库？
**答**：实现 mini axios：1) `use(fn)` 注册中间件（async (ctx, next)），洋葱模型；2) 内置 dispatchRequest 为链尾；3) ctx 支持 { url, headers, data, response }；4) 错误处理中间件（链上任意环节抛错可被捕获）。
**评分点**：
- compose 实现正确（Koa 同款 dispatch 递归 + 防重复 next）。
- 洋葱后置逻辑可用（next 后改 response）。
- 错误传播：链顶 promise catch。
- 中间件顺序：先注册外层。
```javascript
class MiniAxios {
  #mws = [];
  #dispatch = null;
  use(fn) { this.#mws.push(fn); return this; }
  setDispatcher(fn) { this.#dispatch = fn; return this; }
  async request(config) {
    const chain = [...this.#mws, async (ctx, next) => {           // 链尾：真正请求
      ctx.response = await this.#dispatch(ctx);
    }];
    const dispatch = (i) => {                                     // 1) 洋葱 compose
      if (i >= chain.length) return Promise.resolve();
      return Promise.resolve(chain[i](config, () => dispatch(i + 1)));
    };
    return dispatch(0).then(() => config.response);               // 4) 错误沿 promise 冒泡
  }
}
// 用法：
const http = new MiniAxios().setDispatcher(fetchAdapter);
http.use(async (ctx, next) => { ctx.headers.Authorization = `Bearer ${token()}`; await next(); });     // 外层
http.use(async (ctx, next) => { await next(); if (ctx.response.status === 401) refreshToken(); }); // 后置
http.use(retryMiddleware(3));                                    // 任意环节可 throw
```
