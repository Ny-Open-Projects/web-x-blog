## ARC-828：手写巡检机器人

**答**：实现定时架构巡检机器人 `ArchBot`：① 巡检任务注册：{ name, cron, check: async () => ({ pass, issues }) }——巡检项可插拔（依赖健康/体积/规范/文档保鲜）；② 定时执行：cron 触发 + 失败重试（网络抖动）+ 超时保护（巡检卡死不阻塞）；③ 结果分级处理：pass（记录）→ warn（通知 owner）→ fail（建工单——按 severity 路由）；④ 周报聚合：一周巡检结果汇总（各检查项通过率趋势）；⑤ 静默期：巡检发现的已知问题（豁免清单）不重复告警。写出实现。

```javascript
class ArchBot {
  #checks = new Map(); #exemptions = new Set(); #weekly = [];
  registerCheck(name, cron, check) { this.#checks.set(name, { cron, check }); }
  exempt(issueFingerprint, until) { this.#exemptions.add(`${issueFingerprint}@${until}`); }

  async runAll(now = Date.now()) {
    const results = [];
    for (const [name, { check }] of this.#checks) {
      const result = await Promise.race([
        check().catch((e) => ({ pass: false, issues: [{ msg: `check error: ${e}` }], error: true })),
        new Promise((_, rej) => setTimeout(() => rej(new Error('check timeout')), 60_000)),
      ]).catch((e) => ({ pass: false, issues: [{ msg: String(e) }] }));
      const filtered = { ...result,
        issues: result.issues.filter((i) => !this.#isExempt(name, i)) };
      results.push({ name, ...filtered });
      // 分级路由
      for (const issue of filtered.issues) {
        if (issue.severity === 'fail') createTicket(name, issue);
        else if (issue.severity === 'warn') notifyOwner(issue.owner, issue);
      }
    }
    this.#weekly.push({ week: weekOf(now), results });
    return results;
  }
  #isExempt(checkName, issue) {
    const fp = hash(`${checkName}:${issue.msg}`);
    for (const key of this.#exemptions) {
      const [f, until] = key.split('@');
      if (f === fp && new Date(+until) > Date.now()) return true;
    }
    return false;
  }
  weeklyDigest() {
    const byCheck = {};
    for (const w of this.#weekly)
      for (const r of w.results)
        (byCheck[r.name] ??= { total: 0, pass: 0 }).total++,
        r.pass && byCheck[r.name].pass++;
    return Object.entries(byCheck).map(([name, s]) =>
      `${name}: ${s.pass}/${s.total} (${Math.round(s.pass / s.total * 100)}%)`);
  }
}
```

**评分点**：
- 巡检项可插拔（注册制——check 函数）
- 超时保护与失败兜底（巡检不阻塞不崩溃）
- 分级路由（fail 建单/warn 通知——不是全量告警）
- 豁免指纹机制（已知问题不重复告警——带到期）
- 周报聚合（通过率趋势）
