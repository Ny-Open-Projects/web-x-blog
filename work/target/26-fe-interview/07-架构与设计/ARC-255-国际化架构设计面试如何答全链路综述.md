## ARC-255：国际化架构设计面试如何答：全链路综述？
**答**：
- 综述题答题框架：按"语言协商 → 资源生产 → 分发加载 → 渲染格式化 → 质量保障"五段组织，每段给一个关键决策而不是罗列技术。
- 五段要点：协商（服务端定语言防闪变，ARC-241）；生产（文案平台+机翻人工混合流水线，ARC-242）；分发（独立语言包服务+immutable CDN，ARC-245）；渲染（响应式热切换+Intl 缓存，ARC-249/254）；质量（伪本地化+视觉回归矩阵+RUM fallback 率，ARC-246/250）。
- 加分点：主动说清"语言 ≠ 法域"（ARC-253 合规）、动态内容双链路（ARC-251）、多端统一产物（ARC-252）——体现架构广度。
- 收尾给度量：覆盖率/质量/成本三类指标闭环，说明国际化是持续运营的体系不是一次性工程。

```typescript
// 全链路一页纸架构（伪代码综述）
// ① 协商：negotiate(req) → lang（SSR 定，Cookie 传递）
// ② 生产：文案平台 → diff 任务 → MT+人工 → 质检 → 发布
// ③ 分发：manifest.json → /i18n/{lang}/{ns}.hash.json（immutable）
// ④ 渲染：reactive i18n store + t() memo + Intl cache + RTL dir 切换
// ⑤ 质量：pseudo-l10n CI、视觉回归 4 基线、RUM fallbackRate → 反哺②任务池
// 面试表达：先画五段箭头图，再逐段展开 1 个核心决策 + 1 个反模式（如 Cookie 决定 SSR 语言→SEO 灾难）
```
