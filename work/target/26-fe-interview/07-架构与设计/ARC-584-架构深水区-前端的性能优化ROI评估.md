## ARC-584：性能优化 ROI 评估
**答**:
- ROI 公式：收益（业务价值映射 ARC-583 量化）÷ 成本（人力 × 周期 + 维护成本）。评估防两个坑：只看技术指标不看业务收益（白干）/ 只看峰值收益不看持续性（一次性优化要折算）。
- 评估维度：收益侧（指标差距 × 业务映射 × 流量占比——低流量页面收益天然小）、成本侧（改动面/风险/回归测试量）、持续性（一次性收益 vs 结构性收益：SSR 是结构性、图片懒加载是一次性但覆盖面大）。
- 立项排序：收益/成本比矩阵 → 排期（高 ROI 先做——常见排序：图片与脚本治理 > 关键接口优化 > 渲染架构改造）；与稳定性/功能投入平衡（性能不是唯一优先级——季度容量内分配）。
- 验收闭环：立项时写明验收指标（目标值 + 验收方式 AB）→ 完成后实际收益 vs 预估复盘（校准下次估算——ROI 估算能力本身要成长）。
- 沟通材料：一页纸立项（ARC-440 结构：现状量化/方案/成本/收益/里程碑）——业务方能看懂并决策。
```javascript
// ROI 排序
function roi(projects) {
  return projects.map(p => ({
    ...p, score: p.valueEstimate.gmvPerMonth / (p.cost.personDays * dailyCost())
  })).sort((a, b) => b.score - a.score);
}
// 例：图片治理（成本 10 人日，收益 30 万/月）>> SSR 重构（成本 60 人日，收益 40 万/月）
```
