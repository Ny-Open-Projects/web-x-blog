## ARC-499：表格编辑器（Excel 式交互）架构
**答**:
- 与普通表格的区别：键盘导航（方向键/Tab/Enter 移动焦点）、单元格编辑态管理（同时只有一个编辑器实例——复用编辑组件移位而非每格一个）、粘贴批量解析、列宽行高交互、公式/依赖列（ARC-388）。
- 架构核心：虚拟滚动（ARC-442）+ 焦点模型分离（focus (row,col) 是独立状态，编辑器浮层跟随）+ 编辑器生命周期（进入编辑：校验守卫 → 实例化 → 提交/取消 → 焦点转移）。
- 粘贴协议：解析 TSV 多行多列 → 覆盖区域写入（越界自动扩展或拒绝）→ 批量校验标红 → 撤销为一笔（ARC-387 merge）。
- 选区语义：范围选区（Shift/框选）支持批量填充（拖柄填充公式/值——简化为复制填充）、批量清除；选区状态独立于滚动。
- 性能：编辑器单实例 + 值代理（滚动时编辑态保持但脱离 DOM 流）；万行 × 50 列渲染虚拟化后 < 200 DOM 节点。
```javascript
// 焦点模型与编辑器单实例
const grid = { focus: { r: 0, c: 0 }, editing: null };
function move(dr, dc) { commitIfEditing(); grid.focus = clamp(grid.focus + [dr, dc]); }
function startEdit() { grid.editing = { ...grid.focus }; editor.mountAt(grid.focus); }  // 复用实例
onPaste((text) => {
  const patch = parseTSV(text, grid.focus);                   // 从焦点起覆盖
  grid.applyPatch(patch, { asOneHistoryStep: true });         // 一笔撤销
});
```
