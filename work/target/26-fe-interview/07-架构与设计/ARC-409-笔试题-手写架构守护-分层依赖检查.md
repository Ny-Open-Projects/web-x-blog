## ARC-409：笔试题：手写分层依赖检查脚本
**题目**：实现 checkLayers(src)：1) 层级顺序 views → components → services → utils（高层可依赖低层，反向禁止）；2) 解析每个文件的 import 相对路径判断所属层；3) 输出违规列表（文件:行 → 依赖目标）；4) 有违规退出码 1。
**评分点**：
- 层级比较逻辑正确（index 顺序，高层 index 大，只能依赖更小 index？按题意 views(3)→components(2)→services(1)→utils(0)，允许依赖更低层）。
- 相对路径解析与层归类正确（含 alias 处理可选）。
- 同层依赖允许，向下违规拦截。
- CI 退出码与输出可定位（文件+行号）。
```javascript
const fs = require('fs'), path = require('path');
const LAYERS = ['utils', 'services', 'components', 'views']; // index = 层级
const levelOf = (p) => LAYERS.findIndex(l => p.split('/src/')[1]?.startsWith(l));
function checkLayers(src) {
  const violations = [];
  walk(src, (file, content) => {
    const from = levelOf(file); if (from < 0) return;
    content.split('\n').forEach((line, i) => {
      const m = line.match(/from\s+['"](\.\.?\/[^'"]+)['"]/);
      if (!m) return;
      const target = path.join(path.dirname(file), m[1]);
      const to = levelOf(target);
      if (to >= 0 && to > from)                              // 依赖了更高层 → 违规
        violations.push(`${file}:${i + 1} -> ${m[1]}（${LAYERS[from]} 依赖 ${LAYERS[to]}）`);
    });
  });
  violations.forEach(v => console.error('[layer] ' + v));
  if (violations.length) process.exit(1);
}
checkLayers('./src');
```
