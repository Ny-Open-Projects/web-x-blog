## ARC-494：响应式架构与 CLS 治理
**答**:
- 响应式架构分层：断点 token（设计系统定义档位：mobile/tablet/desktop/wide）→ 布局组件（Container/Grid 封装，页面不手写媒体查询）→ 组件响应式（容器查询 @container 替代视口查询——组件在不同容器内自适应）。
- CLS 治理清单：图片/视频显式宽高或 aspect-ratio；字体加载 font-display: optional/swap + 尺寸近似 fallback；动态内容（广告/推荐）预留固定高度占位；骨架屏与真实内容尺寸对齐（骨架屏高度不符反而加剧 CLS）。
- 治理机制：CLS 按会话采集归因（哪个元素位移）进监控；布局抖动 lint（禁止动画 width/height，ARC-471）；新页面上线前 Lighthouse CLS 门禁。
- 断点策略：内容优先（组件在窄容器怎么排布）优先于设备优先；少断点多适配（档位 4 个内），避免断点爆炸。
```css
/* 容器查询：组件级响应式 */
.card-list { container-type: inline-size; }
@container (min-width: 480px) { .card { flex-direction: row; } }
/* CLS 防护 */
img { aspect-ratio: attr(width) / attr(height); }  /* 或直接写 width/height 属性 */
.ad-slot { min-height: 250px; }                     /* 动态内容占位 */
```
