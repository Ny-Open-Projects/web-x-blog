## DP-533：笔试：手写页面联动

**答**：实现复杂页面的联动中介者：① 场景：筛选器变更 → 列表刷新 + 统计更新 + URL 更新 + 埋点——四个消费方；② 中介者协调：filterChanged 事件 → 中介者分发给各消费方（各消费方互不认识）；③ 消费方的注册与清理（页面卸载 off——防泄漏）；④ 联动的合并（筛选器高频变更 → 300ms 合并后统一分发——一次刷新而非四次）；⑤ 错误隔离（列表刷新失败不影响统计更新）。写出实现。

```javascript
class PageMediator {
  #consumers = new Map();   // topic -> Set<{ fn, ns }>
  register(topic, fn, ns) {
    (this.#consumers.get(topic) ?? this.#consumers.set(topic, new Set()).get(topic))
      .add({ fn, ns });
    return () => this.#remove(topic, fn);
  }
  #pendingFilters = null; #timer = null;
  filtersChanged(filters) {                            // 高频合并
    this.#pendingFilters = filters;
    this.#timer ??= setTimeout(() => {
      const filters = this.#pendingFilters;
      this.#pendingFilters = null;
      this.#dispatch('filters:applied', filters);
    }, 300);
  }
  #dispatch(topic, payload) {
    for (const { fn } of this.#consumers.get(topic) ?? []) {
      try { fn(payload); } catch (e) { console.error(`[mediator] ${topic} consumer failed`, e); }   // 隔离
    }
  }
}
// 消费方: mediator.register('filters:applied', refreshList, 'list-ns')
//           mediator.register('filters:applied', updateStats, 'stats-ns')
//           mediator.register('filters:applied', syncUrl, 'url-ns')     — 互不认识
```

**评分点**：
- 星型解耦（消费方互不认识——中介者协调）
- 高频合并（300ms 统一分发——一次刷新）
- 错误隔离（单消费方失败不影响他人）
- 注册清理（ns 批量退订——防泄漏）
