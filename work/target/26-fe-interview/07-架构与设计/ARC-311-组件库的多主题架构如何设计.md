## ARC-311：组件库的多主题架构如何设计？
**答**：
- 主题 = Design Token 的值集（ARC-029 三层 Token 的第 3 层落地）：组件层样式只引用语义 Token（color.primary），主题切换只替换语义 Token 的值，组件代码零改动。
- 实现路径：CSS Variables（运行时切换，`data-theme` 属性驱动，热切换零成本）vs 构建期多主题产物（compile 时按 Token 值生成主题 CSS 文件，体积小但要构建 N 份）。默认 CSS Variables，性能敏感场景（CDN 大量主题）才用构建期。
- 主题继承：主题不是并列集合而是继承链（base → brand → dark），dark 只覆盖必要的 Token 子集，避免每主题全量维护。
- 组件内样式适配：组件避免写死颜色/阴影/圆角，一律 `var(--token)`；对无法 Token 化的第三方样式提供覆写层。

```css
/* tokens/base.css */
:root { --color-primary: #1677ff; --radius-card: 8px; }
/* tokens/dark.css（继承+覆盖） */
[data-theme=dark] { --color-primary: #4a9eff; --bg-page: #111; }
```
```tsx
// 组件只消费语义 Token
const Btn = styled.button`
  background: var(--color-primary);
  border-radius: var(--radius-btn, 4px);
`;
// 切换：document.documentElement.dataset.theme = 'dark' → 全站即时生效，无重渲染
```
