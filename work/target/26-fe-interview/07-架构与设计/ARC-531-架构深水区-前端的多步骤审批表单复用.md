## ARC-531：跨业务复用的审批表单引擎
**答**:
- 抽象层次：审批引擎（流程 ARC-453 + 表单渲染 ARC-384 + 操作集 ARC-509 三件套通用化）与业务表单 schema（各业务声明自己的表单/校验/展示）分离——引擎不感知业务。
- schema 协议：表单 schema（字段/控件/校验）+ 审批流配置（节点/条件/角色）+ 展示模板（查看态只读渲染）——三份配置驱动一个业务审批上线（零代码或低代码）。
- 复用边界：通用能力进引擎（转办/加签/撤回/催办/SLA 倒计时/消息通知），业务特有交互（如合同签署 ARC-527）通过扩展点（自定义字段渲染器/自定义动作）注入。
- 版本兼容：审批中的实例按旧 schema 渲染（schema 版本快照存实例上——改 schema 不影响进行中流程）。
- 度量与治理：引擎接入业务数、schema 复用率（模板库）、扩展点使用率（高频扩展点考虑引擎化）。
```tsx
// 通用审批引擎消费
const config = { form: ExpenseFormSchema, flow: expenseFlow, display: expenseDisplay };
function ApprovalPage({ instanceId }) {
  const inst = useApprovalInstance(instanceId);                  // 引擎层
  const F = inst.schemaVersion === 1 ? config : registry.get(inst.schemaVersion); // 版本快照
  return inst.mode === 'view'
    ? <ReadOnlyForm schema={F.form} data={inst.data} />
    : <EditableForm schema={F.form} actions={inst.actions} onSubmit={submit} />;  // 操作集驱动
}
```
