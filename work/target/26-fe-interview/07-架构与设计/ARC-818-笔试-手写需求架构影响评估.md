## ARC-818：手写需求架构影响评估

**答**：实现需求的架构影响评估器 `assessRequirement(requirement)`：① 输入：{ newPages, modifiesShared: bool, newDeps: [包名], crossTeam: bool, perfSensitive: bool, touchesAuthOrPay: bool }；② 影响评分：每项加权（跨团队 3 分/共享修改 2 分/敏感链路 3 分/新依赖 1 分）→ 总分；③ 分级路由：<3 分 TL 自决、3~5 分架构师评审、>5 分委员会评审——分级决策；④ 输出评估报告：影响项清单 + 建议承载应用（按模块归属）+ 建议评审层级；⑤ 历史回归：同类需求的历史评估结果参考（曾批准/曾驳回）。写出实现。

```javascript
function assessRequirement(req, history) {
  const impact = [];
  let score = 0;
  if (req.crossTeam) { score += 3; impact.push({ item: '跨团队', weight: 3, note: '需接口人协调' }); }
  if (req.modifiesShared) { score += 2; impact.push({ item: '修改共享代码', weight: 2, note: '影响所有使用方' }); }
  if (req.touchesAuthOrPay) { score += 3; impact.push({ item: '敏感链路(鉴权/支付)', weight: 3, note: '安全评审必过' }); }
  if (req.newDeps?.length) { score += 1 * req.newDeps.length; impact.push({ item: `新增依赖 ${req.newDeps.join(',')}`, weight: 1 }); }
  if (req.perfSensitive) impact.push({ item: '性能敏感', note: '需性能预算评估' });

  const level = score < 3 ? 'tl-self' : score <= 5 ? 'arch-review' : 'committee';
  const suggestion = suggestApp(req);                 // 按模块归属建议承载应用
  const similar = history?.filter((h) =>
    h.newPages?.length === req.newPages?.length && h.modifiesShared === req.modifiesShared);
  return { score, level, impact, suggestion,
    verdict: level === 'tl-self' ? 'TL 自决, 无需架构评审' : `需 ${level === 'arch-review' ? '架构师' : '委员会'} 评审`,
    history: similar?.map((h) => ({ title: h.title, verdict: h.verdict })) };
}
function suggestApp(req) {
  // 按页面路径前缀归属微前端子应用
  return req.newPages?.map((p) => ({
    page: p, app: p.startsWith('/order') ? 'order-app' : p.startsWith('/marketing') ? 'mkt-app' : 'shell',
  }));
}
```

**评分点**：
- 加权评分（跨团队/共享/敏感链路的高权重）
- 分级路由（TL 自决/架构师/委员会——决策成本匹配）
- 建议承载应用（模块归属——架构左移）
- 历史回归（同类需求的既往决策参考）
