## ARC-445：前端内存架构总览
**答**:
- 内存架构三关注点：分配策略（大对象池化复用 vs 即用即弃）、驻留策略（什么该长驻缓存、什么必须可回收）、回收保障（引用链可断、监听器可卸载）。
- 高危驻留源清单：全局缓存无上限、事件监听/定时器未清、闭包捕获大对象、Detach DOM（已移除 DOM 仍被 JS 引用）、大数组切片引用（subarray 共享 buffer）。
- 架构约束：缓存必须带容量上限与淘汰策略（LFU/TTL）；订阅必须成对（subscribe/unsubscribe 强制配对，未配对在 dev 模式告警）；大数据流转用 Transferable 或视图，避免克隆驻留。
- 监控闭环：内存水位指标（performance.memory / performance.measureUserAgentSpecificMemory）+ 页面切换后内存不回落告警 + 堆快照对比工具链。
- 设计手段：分代缓存（页面级缓存随路由销毁、会话级缓存随标签页关闭、持久级显式管理）、弱引用场景（WeakMap 关联元数据不阻止回收）。
```javascript
// 有界缓存基类（架构约束落地）
class BoundedCache {
  #map = new Map();
  constructor(private max = 100, private ttl = 5 * 60e3) {}
  set(k, v) {
    if (this.#map.size >= this.max) this.#map.delete(this.#map.keys().next().value); // LRU 驱逐
    this.#map.set(k, { v, at: Date.now() });
  }
  get(k) { const e = this.#map.get(k); if (!e) return null;
    if (Date.now() - e.at > this.ttl) { this.#map.delete(k); return null; } return e.v; }
}
```
