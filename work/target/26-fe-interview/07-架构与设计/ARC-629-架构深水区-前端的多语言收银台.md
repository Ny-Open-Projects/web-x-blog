## ARC-629：跨境收银台
**答**:
- 差异维度：币种（展示币/结算币——ARC-569 双币展示 + 汇率标注）、渠道（海外渠道矩阵：卡组织/PayPal/本地钱包——渠道可用性按国家路由）、合规（本地合规要求：3DS 验证/账单地址/税务标识——按国家配置化表单 ARC-570）、语言与时区（ARC-241/481 全套国际化）。
- 渠道路由：可用渠道服务端按（国家+币种+金额）裁决下发——前端渲染可用列表（不可用渠道不显示——ARC-598 适配器注册表扩展）、渠道合规表单（3DS 跳转流程——挑战页处理与回跳 ARC-623 状态机）。
- 价格透明：汇率与手续费显式（换汇损失透明展示——合规要求）、税费明细（含税/不含税标注——税制差异配置）。
- 对账与凭证：多币种订单凭证（原币+结算币双记录——用户可查）、结算单据下载。
- 错误处理：渠道拒绝原因国际化（银行错误码映射——各渠道码表转译 ARC-491）、合规拦截提示（高风险地区/制裁名单——服务端拦截文案可懂）。
```javascript
// 跨境渠道路由
const channels = await api.availableChannels({ country, currency, amountCents });
// [{ id: '3ds-card', form: { billingAddress: true } }, { id: 'paypal', form: null }]
<ChannelList channels={channels} formSchemas={CHANNEL_FORMS} />   // 按渠道动态表单（3DS/账单地址）
```
