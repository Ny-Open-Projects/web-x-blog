## DP-389：路由层模式组合

**答**：
- 路由层的模式组合：责任链（守卫链：登录→权限→AB→埋点依次过）、策略（按路由元信息选择布局/过渡策略）、状态机（导航状态：idle→navigating→settled）
- 守卫链的语义：每个守卫返回 next/redirect/abort——链式短路（登录失败不进权限检查）
- 路由元信息驱动：meta: { auth, layout, keepAlive, perm }——策略按 meta 分派（布局组件选择/过渡动画选择——声明式路由）
- 导航状态机的价值：pending 状态驱动进度条、重复导航防抖（同目标导航短路）、导航取消（新导航打断旧导航）
- 深水点：守卫的「异步串行成本」——每个守卫一个 await（守卫链串行延迟）——轻守卫同步/重守卫并行（Promise.all 预取守卫数据）

```javascript
// 守卫链
const guards = [authGuard, permGuard, abGuard, trackGuard];
async function navigate(to) {
  for (const guard of guards) {
    const r = await guard(to);                        // 串行: 前一守卫结果影响后续
    if (r.redirect) return navigate(r.redirect);      // 重定向重启链
    if (r.abort) return;
  }
  commit(to);                                         // 全过才提交导航
}
```
