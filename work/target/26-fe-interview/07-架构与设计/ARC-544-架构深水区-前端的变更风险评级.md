## ARC-544：前端变更风险自动评级
**答**:
- 目标：不是所有变更同等对待——高风险变更强评审强灰度，低风险快速通道。评级自动化避免"人凭感觉"。
- 风险因子：代码范围（改动行数/文件数/是否触核心目录：支付/登录）、依赖变更（新增依赖/大版本升级）、影响面（页面 UV/是否 C 端主链路 ARC-428 调用方画像前端版）、历史（该模块近期事故/该作者新人文档）、发布窗口（临近大促冻结期 ARC-263）。
- 评级输出：风险分 + 分级动作（低：自动发布 / 中：1 人评审 + 常规灰度 / 高：架构评审 + 长灰度 + 监控加强）、证据链接（每因子可展开看数据）。
- 校准：评级 vs 实际事故的相关性复盘（评级高的没出事/评级低的出了事 → 调权重 ARC-428 闭环思想）。
- 例外通道：紧急修复（hotfix）评级豁免但事后补评与复盘留痕——紧急通道不可滥用（滥用率监控）。
```javascript
function riskScore(mr) {
  const factors = {
    corePath: touches(mr, ['pay', 'auth']) ? 3 : 0,              // 核心链路
    deps: majorDeps(mr) ? 2 : newDeps(mr) ? 1 : 0,
    impact: pageUv(mr) > 1e6 ? 2 : 0,                            // 高 UV 页面
    freezeWindow: inFreeze(mr.time) ? 2 : 0
  };
  const score = Object.values(factors).reduce((a, b) => a + b, 0);
  return { score, level: score >= 5 ? 'high' : score >= 2 ? 'mid' : 'low',
    action: { high: 'arch-review+long-canary', mid: 'review+canary', low: 'auto' }[score >= 5 ? 'high' : score >= 2 ? 'mid' : 'low'] };
}
```
