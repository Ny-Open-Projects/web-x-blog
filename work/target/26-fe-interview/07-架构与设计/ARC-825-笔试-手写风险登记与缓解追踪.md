## ARC-825：手写风险登记

**答**：实现架构风险登记与缓解追踪 `RiskRegister`：① 风险登记：{ id, category(依赖/人员/容量/合规/第三方), description, probability(1-5), impact(1-5), owner, mitigations: [{ action, status }] };② 风险评分：probability × impact → 分级（≥15 critical / ≥8 high / ≥4 medium）；③ 缓解追踪：mitigation 状态（planned/in-progress/done）——critical 风险的 mitigation 未完成 → 告警；④ 演练关联：风险项关联演练（该风险的缓解是否演练验证过——未演练标「未验证」）；⑤ 季度报告：风险变化趋势（新增/关闭/升级——风险表是动态的）。写出实现。

```javascript
class RiskRegister {
  #risks = new Map();
  add({ category, description, probability, impact, owner }) {
    const score = probability * impact;
    const level = score >= 15 ? 'critical' : score >= 8 ? 'high' : score >= 4 ? 'medium' : 'low';
    const risk = { id: crypto.randomUUID(), category, description, probability, impact,
      score, level, owner, mitigations: [], drilled: false, status: 'open',
      createdAt: Date.now() };
    this.#risks.set(risk.id, risk);
    return risk;
  }
  addMitigation(riskId, action) {
    const r = this.#risks.get(riskId);
    r.mitigations.push({ action, status: 'planned' });
  }
  updateMitigation(riskId, idx, status) {
    const r = this.#risks.get(riskId);
    r.mitigations[idx].status = status;
    // critical 风险全部 mitigation done 才能降级
    if (r.level === 'critical' && r.mitigations.every((m) => m.status === 'done')) {
      r.level = 'high'; r.score = Math.max(8, Math.floor(r.score / 2));
    }
  }
  markDrilled(riskId) { this.#risks.get(riskId).drilled = true; }
  quarterlyReport() {
    const all = [...this.#risks.values()];
    const alertItems = all.filter((r) =>
      r.level === 'critical' && (r.mitigations.some((m) => m.status !== 'done') || !r.drilled));
    return {
      trend: { total: all.length, byLevel: groupBy(all, 'level'),
        newThisQuarter: all.filter((r) => Date.now() - r.createdAt < 90 * 86400e3).length },
      alerts: alertItems.map((r) => ({ id: r.id, desc: r.description,
        issue: !r.drilled ? '未演练' : '缓解未完成', owner: r.owner })),
    };
  }
}
function groupBy(arr, key) { const o = {}; for (const x of arr) o[x[key]] = (o[x[key]] ?? 0) + 1; return o; }
```

**评分点**：
- 概率×影响评分分级（critical 阈值 15）
- mitigation 状态追踪（critical 全缓解才降级——降级逻辑）
- 演练关联（未演练的缓解 = 纸面缓解）
- 季度趋势（新增/关闭/升级——动态风险表）
