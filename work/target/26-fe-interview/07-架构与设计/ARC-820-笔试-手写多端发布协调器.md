## ARC-820：手写多端发布协调

**答**：实现同一业务多端（H5/小程序/App 内嵌）的发布协调器 `MultiPlatformRelease`：① 发布单元：{ feature, platforms: [{ platform, artifact, ready }] }——一功能多端工件；② 协调发布策略：all-ready（全部就绪才发——强一致）或 best-effort（就绪端先发，未就绪端 feature flag 关闭）；③ 功能可见性：`isFeatureVisible(feature, platform)`——未发布端不可见（flag 联动）；④ 发布日历冲突检测：多端发布时间重叠告警（故障归因混乱）；⑤ 版本兼容：H5 新版 + 小程序旧版共存期的接口兼容窗口（API 不 break 旧端）。写出实现。

```javascript
class MultiPlatformRelease {
  #features = new Map(); #calendar = [];
  register(feature, { strategy = 'best-effort', platforms }) {
    this.#features.set(feature, { strategy, platforms });
  }
  markReady(feature, platform, artifact) {
    const f = this.#features.get(feature);
    const p = f.platforms.find((x) => x.platform === platform);
    if (!p) throw new Error(`unknown platform: ${platform}`);
    p.ready = true; p.artifact = artifact;
    if (f.strategy === 'all-ready' && f.platforms.every((x) => x.ready))
      return this.#publish(feature);                  // 全就绪才发
    if (f.strategy === 'best-effort') this.#publish(feature);   // 就绪端先发(flag 关闭未就绪端)
    return null;
  }
  isFeatureVisible(feature, platform) {
    const f = this.#features.get(feature);
    if (!f || f.published !== true) return false;
    const p = f.platforms.find((x) => x.platform === platform);
    return f.strategy === 'all-ready' ? true : p.ready;   // best-effort: 未就绪端不可见
  }
  checkCalendar(feature, releaseTime) {
    const conflict = this.#calendar.find((c) =>
      Math.abs(c.time - releaseTime) < 24 * 3600e3 && c.feature !== feature);
    if (conflict) console.warn(`[calendar] ${feature} 与 ${conflict.feature} 发布时间重叠, 归因可能混乱`);
    this.#calendar.push({ feature, time: releaseTime });
  }
  #publish(feature) { const f = this.#features.get(feature); f.published = true; return f; }
}
// 接口兼容: API 带 minClientVersion → 旧端请求返回旧 schema (兼容窗口)
```

**评分点**：
- 两种策略（all-ready 强一致/best-effort flag 兜底）
- isFeatureVisible 的端级可见性（未就绪端不可见）
- 发布日历冲突检测（归因混乱预防）
- 多端版本兼容窗口的接口策略
