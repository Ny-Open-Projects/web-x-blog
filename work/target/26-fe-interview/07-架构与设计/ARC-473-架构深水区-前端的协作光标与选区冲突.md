## ARC-473：协作光标与选区同步、本地冲突处理
**答**:
- presence 同步（ARC-119 延伸）：光标位置锚定到文档位置（相对锚点）而非像素坐标——他人在前方插入文字时你的光标自动平移（CRDT 相对位置自动维护）；节流 80~100ms + 停止输入后发终值。
- 选区与输入法：IME 组合输入期间不广播中间态（只广播最终提交）；选区变化在 composition 中挂起。
- 本地冲突 UX：并发编辑同一位置时 CRDT 保证不丢但可能"穿插"——架构上提供实时跟随（跟随正在输入的人的视口）与冲突提示（同一单元格：显示"两人正在编辑"，后提交者需确认合并）。
- 表格/结构化冲突：单元格级锁定（软锁：提示但不强制，最后写入胜 + 双方历史可查）；文档级用段落所有权（正在编辑的段落高亮他人状态）。
- 离线回归：离线期间本地编辑与远端变更在重连时自动 merge，merge 后给用户"变更摘要"而非默默变化。
```javascript
// 相对锚点光标（Yjs 伪码）
const anchor = Y.createRelativePositionFromTypeIndex(doc.text, offset);
ws.on('presence', ({ user, anchor: remote }) => {
  const abs = Y.createAbsolutePositionFromRelativePosition(remote, doc);
  cursors.set(user.id, { pos: abs.index, color: user.color, ts: Date.now() });
  renderCursors();                                             // 远端插入自动平移
});
// 本地广播：throttle(() => send({ anchor }), 80)
```
