## DP-523：笔试：手写页面基座

**答**：实现页面基座 `createPageBase(hooks)`：① 骨架固定：鉴权检查 → 数据加载 → 渲染 → 埋点——顺序不可变；② 钩子可覆写：loadData/onReady/onError——业务填细节；③ 错误的骨架级处理：loadData 抛错 → 骨架统一错误态（业务钩子不写 try/catch）——错误处理内聚；④ 取消语义：页面卸载中断数据加载（AbortController 贯穿）；⑤ 埋点兜底：即使 loadData 抛错，PV 照常上报（骨架保证）。写出实现。

```javascript
function createPageBase(hooks) {
  return async function runPage(ctx) {
    const ctrl = new AbortController();
    ctx.onDispose(() => ctrl.abort());                // 取消贯穿
    try {
      await hooks.auth?.(ctx) ?? true;                // 步骤1: 鉴权(可选钩子)
      const data = await hooks.loadData(ctx, ctrl.signal);   // 步骤2: 数据(必填钩子)
      hooks.render?.(data);
      track('pageview', { ok: true });                // 步骤3: 埋点(骨架保证)
      hooks.onReady?.(data);
    } catch (e) {
      track('pageview', { ok: false });               // 错误也埋点
      hooks.onError?.(e) ?? renderErrorPage(e);       // 钩子处理 or 骨架兜底
    }
  };
}
// 业务: createPageBase({ loadData: (ctx) => api.detail(ctx.id, ctx.signal) })
// 骨架保证: 鉴权→数据→渲染→埋点顺序固定; 错误统一处理
```

**评分点**：
- 骨架顺序固定 + 钩子填细节（模板方法本质）
- 错误处理内聚（业务钩子不写 try/catch——骨架统一）
- AbortController 贯穿（取消语义）
- 错误也埋点（埋点骨架级保证）
