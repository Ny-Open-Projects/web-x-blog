## DP-349：笔试题：手写配置中心客户端（长轮询+回滚）？
**题目**：实现 ConfigClient：1) 初始拉取 + 长轮询（挂 30s，版本变化立即返回）；2) 版本号单调递增校验（乱序丢弃）；3) last-good 快照兜底（服务挂了用旧配置）；4) on('change') 订阅。
**评分点**：
- 长轮询循环正确（完成后立即发起下一轮）。
- 版本校验丢弃乱序。
- 快照兜底（fetch 失败用 lastGood）。
- 订阅清理（destroy）。
```javascript
class ConfigClient {
  #version = 0; #lastGood = null; #subs = new Set(); #alive = true;
  constructor(private url) {}
  async init() {
    try { await this.#fetchLatest(); }
    catch { if (this.#lastGood) this.#notify(this.#lastGood); }   // 3) 兜底
    this.#poll();
  }
  async #fetchLatest() {
    const r = await fetch(`${this.url}?version=${this.#version}`);
    const data = await r.json();
    if (data.version <= this.#version) return;                    // 2) 乱序丢弃
    this.#version = data.version;
    this.#lastGood = data;
    this.#notify(data);
  }
  async #poll() {                                                  // 1) 长轮询
    while (this.#alive) {
      try { await this.#fetchLatest(); }
      catch { await new Promise(r => setTimeout(r, 5000)); }       // 失败退避
    }
  }
  on(fn) { this.#subs.add(fn); return () => this.#subs.delete(fn); }
  #notify(data) { this.#subs.forEach(f => f(data)); }
  destroy() { this.#alive = false; this.#subs.clear(); }           // 4)
}
```
