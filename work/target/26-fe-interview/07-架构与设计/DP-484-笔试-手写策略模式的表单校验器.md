## DP-484：笔试：手写策略校验器

**答**：实现可扩展的表单校验器：① 策略注册表：register(name, validator)——validator 签名 (value, allValues) => error|null（支持跨字段）；② 参数化策略工厂：minLength(5) 返回闭包策略；③ 校验编排：字段规则数组按序执行——shortCircuit 选项（短路 vs 聚合）；④ 异步策略支持（远程唯一性校验——validateField 返回 Promise）；⑤ 未知规则抛错并提示已注册规则。写出实现与新增规则示例。

```javascript
class Validator {
  #strategies = new Map();
  register(name, fn) { this.#strategies.set(name, fn); }
  validateField(value, rules, allValues = {}, { shortCircuit = false } = {}) {
    const errors = [];
    const run = (rule) => {
      const [name, ...args] = Array.isArray(rule) ? rule : [rule];
      const strategy = this.#strategies.get(name);
      if (!strategy) throw new Error(`unknown rule: ${name}, available: ${[...this.#strategies.keys()].join(',')}`);
      const bound = args.length ? strategy(...args) : strategy;   // 参数化: 策略工厂
      return bound(value, allValues);
    };
    const results = rules.map((rule) => {
      const r = run(rule);
      if (r && shortCircuit) throw { errors: [r] };    // 短路: 抛出中断
      return r;
    });
    return Promise.all(results).then((errs) => errs.filter(Boolean));
  }
}
const v = new Validator();
v.register('required', (v) => (v == null || v === '' ? '必填' : null));
v.register('minLength', (n) => (v) => (v?.length < n ? `至少${n}字` : null));
v.register('match', (field) => (v, all) => (v === all[field] ? null : '两次输入不一致'));   // 跨字段
// 新增: v.register('idcard', fn) — 主流程零改动
```

**评分点**：
- 参数化策略工厂（minLength(5) 闭包——策略携带配置）
- 跨字段校验的 allValues 注入
- 短路 vs 聚合的选项
- 未知规则的错误提示（可用规则列出——可发现性）
