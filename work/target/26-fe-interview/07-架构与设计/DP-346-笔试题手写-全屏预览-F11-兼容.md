## DP-346：笔试题：手写全屏预览（Fullscreen 兼容与降级）？
**答**：实现 fullscreenPreview(el)：1) requestFullscreen 标准路径；2) Safari 旧版 webkit 前缀兼容；3) 不支持时降级 CSS 全屏（fixed inset 0）；4) Esc 退出监听与状态同步。
**评分点**：
- API 兼容链正确（标准 → webkit → CSS 降级）。
- 状态同步（fullscreenchange 事件 vs 手动标志）。
- 退出清理（降级模式移除 class）。
- Esc 语义一致（全屏 API 自带 + 降级手动监听）。
```javascript
function fullscreenPreview(el) {
  const api = el.requestFullscreen ?? el.webkitRequestFullscreen;
  if (api) {
    api.call(el);
    const sync = () => { if (!document.fullscreenElement && !document.webkitFullscreenElement) cleanup(); };  // 2) 状态同步
    document.addEventListener('fullscreenchange', sync);
    document.addEventListener('webkitfullscreenchange', sync);
    return cleanup;
  }
  // 3) CSS 降级
  el.classList.add('fullscreen-fallback');                    // .fullscreen-fallback { position: fixed; inset: 0; z-index: 9999; background: #000 }
  const esc = (e) => e.key === 'Escape' && cleanup();         // 4) Esc
  document.addEventListener('keydown', esc);
  function cleanup() {
    el.classList.remove('fullscreen-fallback');
    document.removeEventListener('keydown', esc);
    document.removeEventListener('fullscreenchange', sync);
    document.removeEventListener('webkitfullscreenchange', sync);
  }
  return cleanup;
}
```
