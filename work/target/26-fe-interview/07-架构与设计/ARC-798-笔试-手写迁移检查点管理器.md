## ARC-798：笔试：手写检查点管理器

**答**：实现迁移检查点管理器 `CheckpointManager`：① 检查点模型：{ id, name, scope(模块), completedAt, verification(验证证据: 回归链接/灰度数据), rollbackPlan }；② checkpoint(name, scope, evidence)：打点（要求证据齐全——无证据不接受）；③ rollbackTo(checkpointId)：生成回滚指令（回滚到该检查点的状态——含配置/流量比例快照）；④ 时间线视图：检查点列表（推进速度可视化）；⑤ 与发布系统联动：checkpoint 通过才允许下一阶段发布。写出实现。

```javascript
class CheckpointManager {
  #points = []; #snapshots = new Map();
  checkpoint({ name, scope, evidence, snapshot }) {
    if (!evidence?.regressionUrl && !evidence?.grayData)
      throw new Error('checkpoint 需要验证证据 (回归/灰度数据)');
    if (!snapshot) throw new Error('checkpoint 需要状态快照 (流量/配置)');
    const point = { id: crypto.randomUUID(), name, scope, evidence, completedAt: Date.now() };
    this.#points.push(point);
    this.#snapshots.set(point.id, snapshot);
    return point;
  }
  rollbackTo(pointId) {
    const idx = this.#points.findIndex((p) => p.id === pointId);
    if (idx < 0) throw new Error('unknown checkpoint');
    // 丢弃该检查点之后的所有迁移 + 恢复快照
    const snapshot = this.#snapshots.get(pointId);
    this.#points = this.#points.slice(0, idx + 1);
    return {
      action: 'rollback',
      restoreSnapshot: snapshot,     // 流量比例/配置/版本
      droppedAfter: this.#points.slice(idx + 1).length,
    };
  }
  timeline() {
    return this.#points.map((p, i) => ({
      name: p.name, scope: p.scope, at: p.completedAt,
      duration: i > 0 ? p.completedAt - this.#points[i - 1].completedAt : null,
    }));
  }
}
// 用法: checkpoint({ name: 'core-migrated', scope: 'core/',
//   evidence: { regressionUrl: 'ci.run/123', grayData: { errorRate: 0.002 } },
//   snapshot: { trafficPercent: 25, flags: { newCart: true } } })
```

**评分点**：
- 证据强校验（无回归/灰度证据不接受——防假检查点）
- 快照机制（回滚可恢复流量/配置状态）
- 时间线的推进速度可视化
- 与发布联动的检查点语义
