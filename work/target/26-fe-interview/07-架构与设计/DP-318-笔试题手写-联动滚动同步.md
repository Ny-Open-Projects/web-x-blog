## DP-318：笔试题：手写联动滚动同步（双向对比视图）？
**题目**：实现两面板滚动同步：1) 任意一方滚动，另一方按比例跟随（内容高不同）；2) 防回环（同步触发的滚动事件不再广播）；3) 比例映射正确（scrollTop / maxScroll）；4) 解绑清理。
**评分点**：
- 比例映射正确（避免绝对值同步导致不同内容高错位）。
- 锁标志防回环（互斥锁或 source 标记）。
- rAF 节流。
- 清理完整。
```javascript
function syncScroll(a, b) {
  let syncing = false;                                     // 2) 防回环
  let raf = 0;
  const bind = (from, to) => () => {
    if (syncing) return;
    cancelAnimationFrame(raf);
    raf = requestAnimationFrame(() => {
      syncing = true;
      const maxFrom = from.scrollHeight - from.clientHeight;
      const maxTo = to.scrollHeight - to.clientHeight;
      to.scrollTop = maxTo * (from.scrollTop / Math.max(maxFrom, 1));   // 3) 比例映射
      requestAnimationFrame(() => { syncing = false; });    // 下一帧解锁
    });
  };
  const h1 = () => bind(a, b)(), h2 = () => bind(b, a)();
  a.addEventListener('scroll', h1, { passive: true });
  b.addEventListener('scroll', h2, { passive: true });
  return () => { a.removeEventListener('scroll', h1); b.removeEventListener('scroll', h2);   // 4)
    cancelAnimationFrame(raf); };
}
```
