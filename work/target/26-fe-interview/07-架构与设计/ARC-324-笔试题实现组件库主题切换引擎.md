## ARC-324：笔试题：实现组件库主题切换引擎？
**答**：实现主题引擎 `ThemeProvider`：1) CSS Variables 注入（scope 可选挂在根或容器）；2) 主题继承（base → custom 覆盖合并）；3) 过渡动画期禁用防闪烁；4) 切换后派发事件供埋点；5) SSR 下首屏 style 内联。
**评分点**：
- Token 合并正确（浅合并，custom 只覆盖出现的 key）。
- CSS Variables 写入正确（scope 前缀选择器，容器级主题可行）。
- 过渡防闪烁处理（切换时临时禁 transition）。
- SSR：首屏 `<style>` 注入当前主题变量，客户端水合不闪变。
```tsx
function applyTheme(tokens, scope) {
  const vars = Object.entries(tokens).map(([k, v]) => `${k}:${v};`).join('');
  const css = `${scope}{${vars}}`;
  let el = document.getElementById('theme-vars');
  if (!el) { el = document.createElement('style'); el.id = 'theme-vars'; document.head.appendChild(el); }
  el.textContent = css;
}
function ThemeProvider({ base, custom, scope = ':root', children }) {
  const merged = useMemo(() => ({ ...base, ...custom }), [base, custom]);   // 2) 继承合并
  useEffect(() => {
    document.documentElement.style.setProperty('--theme-transition', 'none'); // 3) 防闪烁
    applyTheme(merged, scope);
    requestAnimationFrame(() => document.documentElement.style.removeProperty('--theme-transition'));
    window.dispatchEvent(new CustomEvent('themechange', { detail: Object.keys(custom ?? {}) })); // 4)
  }, [merged, scope]);
  return (
    <>
      {/* 5) SSR 内联 */}
      <style dangerouslySetInnerHTML={{ __html: `${scope}{${Object.entries(merged).map(([k, v]) => `${k}:${v}`).join(';')}}` }} />
      {children}
    </>
  );
}
```
