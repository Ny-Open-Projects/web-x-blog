## ARC-307：低代码引擎的可观测性如何设计？
**答**：
- 低代码的用户是"非专业开发者"，他们不会读堆栈——可观测性要做**翻译**：把技术错误翻译成搭建语言（"数据源 ds1 的 URL 拼写错误"而不是 TypeError: undefined）。
- 三类观测：搭建期（画布实时诊断面板：渲染报错/绑定失效/性能提示）、运行期（页面异常自动定位到 DSL 节点 ID 并展示给页面 owner）、平台期（引擎健康指标：渲染耗时分布/表达式执行错误率/物料版本分布）。
- 错误归因链：运行时错误携带 DSL 节点上下文（nodeId/数据源 ID），自动生成"可操作的修复建议"（绑定失效 → 列出正确的绑定候选）。
- 指标驱动引擎演进：哪些物料最常出错 → 优化其 setter 与校验；哪些表达式模式高频 → 做成内置函数。

```typescript
// 节点级错误包装
function renderWithError(node, ctx) {
  try { return renderNode(node, ctx); }
  catch (e) {
    const friendly = translateError(e, node);      // 技术错误 → 搭建语言
    report('lc-runtime-error', { nodeId: node.id, page: ctx.pageId, ...friendly });
    return <ErrorNode message={friendly.hint}/>;   // 画布内就显示修复提示
  }
}
// translateError: TypeError Cannot read items → { hint: '数据源 ds1 未返回 items 字段，检查接口响应或绑定路径' }
```
