## DP-342：笔试题：手写虚拟列表滚动锚定（顶部插入不跳动）？
**题目**：实现聊天列表的"新消息不跳动"：1) 顶部插入消息时保持用户当前视口（补偿 scrollTop）；2) 用户在底部时自动跟随（跟随模式）；3) 向上滚动触发加载历史（分页）；4) 历史插入补偿。
**评分点**：
- 插入补偿计算正确（插入高度 = 补 scrollTop）。
- 跟随模式判定（距底 < 阈值）。
- 历史加载补偿（插入 N 条后 scroll 位置不变）。
- 阈值常量合理。
```javascript
class ChatList {
  #following = true;
  constructor(private el, private loadHistory) {
    el.addEventListener('scroll', () => {                       // 2) 跟随判定
      this.#following = el.scrollHeight - el.scrollTop - el.clientHeight < 60;
      if (el.scrollTop < 100) this.#prependHistory();           // 3) 上滚加载
    });
  }
  append(msg) {
    this.el.insertAdjacentHTML('beforeend', msg);
    if (this.#following) this.el.scrollTop = this.el.scrollHeight;   // 底部跟随
  }
  async #prependHistory() {                                     // 4) 顶部补偿
    const prevHeight = this.el.scrollHeight;
    const prevTop = this.el.scrollTop;
    const older = await this.loadHistory();
    this.el.insertAdjacentHTML('afterbegin', older);
    this.el.scrollTop = prevTop + (this.el.scrollHeight - prevHeight);   // 1) 补偿保持视口
  }
}
```
