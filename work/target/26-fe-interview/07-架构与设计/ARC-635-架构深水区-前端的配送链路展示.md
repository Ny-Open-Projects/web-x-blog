## ARC-635：配送链路展示
**答**:
- 轨迹展示：物流节点时间线（揽收/转运/派送——节点数据服务端下发）、地图轨迹（骑手/快递实时位置——高频更新合帧 ARC-443/537、轨迹抽稀 ARC-455）。
- 位置更新策略：推送 vs 轮询（骑手位置高频：WS 推送 + 节流展示 3s/点；快递物流：轮询低频）、页面可见性（后台暂停订阅 ARC-537）、位置陈旧处理（超时未更新标注"信号最后更新 xx 前"）。
- ETA 展示：预计送达（服务端 ETA 下发——前端倒计时 + 更新；ETA 变化原因可懂化：天气/高峰——文案配置）、异常状态（配送延迟/异常件——状态文案与客服入口）。
- 轨迹回放：历史轨迹（已完成订单的轨迹回放——分段抽稀播放）、送达确认（收货码/拍照确认交互）。
- 性能与成本：地图 SDK 懒加载（ARC-086 重 SDK 编排——进详情页才加载地图模块）、多订单并发查看（订阅管理——切单 unsubscrib 旧单 ARC-566）。
```javascript
// 骑手位置订阅
const sub = ws.subscribe(`rider:${orderId}`, throttle(pos => map.moveMarker(pos), 3000));
document.visibilitychange(() => document.hidden ? sub.pause() : sub.resume()); // 可见性
// ETA：store.patch({ eta, reason: 'traffic' }) → 倒计时组件重算
```
