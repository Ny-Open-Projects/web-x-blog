## ARC-806：手写降级矩阵

**答**：实现大促降级开关矩阵 `DegradationMatrix`：① 开关声明：{ feature: { level(1核心不可降/2重要/3可降), fallback(降级后的替代实现), autoTriggers: ['errorRate>0.05', 'qps>threshold'] } }——按等级组织；② 手动降级：degrade(feature, reason)（大促指挥手动触发——审计记录）；③ 自动降级：监控指标触发 autoTriggers → 自动降级 + 通知（大促群播报）；④ 降级矩阵视图：当前各 feature 状态（正常/降级中/降级原因）——大促指挥室看板；⑤ 恢复：restore(feature)（需确认——防误恢复）；⑥ 全量降级预案：一键降级所有 level3（panic 按钮）。写出实现。

```javascript
class DegradationMatrix {
  #features = new Map();  // feature -> { level, fallback, triggers, state }
  #audit = [];
  constructor(features, { monitor, notify } = {}) {
    for (const [name, f] of Object.entries(features))
      this.#features.set(name, { ...f, state: 'normal' });
    this.#startAuto(monitor, notify);
  }
  degrade(feature, reason, operator) {
    const f = this.#features.get(feature);
    if (f.level === 1) throw new Error(`${feature} 是核心功能不可降级`);
    f.state = 'degraded';
    this.#audit.push({ feature, reason, operator, t: Date.now() });
    this.notify?.(`⬇️ 降级: ${feature} (${reason}) → fallback: ${f.fallback}`);
  }
  restore(feature, operator, confirm) {
    const f = this.#features.get(feature);
    if (f.state !== 'degraded') return;
    if (!confirm) throw new Error('恢复需二次确认 (防误操作)');
    f.state = 'normal';
    this.#audit.push({ feature, reason: 'restore', operator, t: Date.now() });
    this.notify?.(`⬆️ 恢复: ${feature}`);
  }
  panic(operator) {                                    // 一键全降 level3
    for (const [name, f] of this.#features)
      if (f.level === 3 && f.state === 'normal') this.degrade(name, 'panic', operator);
  }
  #startAuto(monitor, notify) {
    setInterval(() => {
      for (const [name, f] of this.#features) {
        if (f.state !== 'normal' || !f.autoTriggers) continue;
        for (const t of f.autoTriggers) {
          if (monitor.evaluate(t)) { this.degrade(name, `auto: ${t}`, 'auto-guard'); break; }
        }
      }
    }, 30_000);
  }
  matrix() { return [...this.#features.entries()].map(([n, f]) => ({ feature: n, level: f.level, state: f.state })); }
}
```

**评分点**：
- level 分级（核心不可降——level1 保护）
- 手动 + 自动双通道（autoTriggers 指标触发）
- panic 一键全降（大促预案）
- 恢复二次确认（防误恢复）+ 操作审计
