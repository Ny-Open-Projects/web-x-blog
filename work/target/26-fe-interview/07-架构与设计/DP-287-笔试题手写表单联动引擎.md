## DP-287：笔试题：手写表单联动引擎（schema→DAG 求值）？
**题目**：实现 FormEngine：1) schema 声明字段联动（visibleWhen/disabledWhen 为表达式函数）；2) setField 触发依赖字段重求值；3) 循环依赖检测（编译期报错）；4) computeValidations 并行校验。
**评分点**：
- 依赖图构建正确（表达式引用的字段集合）。
- 变更传播：只重求值下游节点（拓扑序/反向索引）。
- 循环依赖检测（DFS 找环）。
- 校验并行且聚合错误。
```javascript
class FormEngine {
  constructor(schema) {
    this.schema = schema;
    this.values = {};
    this.deps = new Map();                              // field → Set<依赖它的 field>
    this.buildDeps();
    this.checkCycle();                                  // 3) 编译期查环
  }
  buildDeps() {
    for (const [name, def] of Object.entries(this.schema)) {
      const used = collectFields(def.visibleWhen, def.disabledWhen);  // 提取表达式引用
      used.forEach(dep => { this.deps.get(dep) ?? this.deps.set(dep, new Set()).get(dep).add(name); });
    }
  }
  checkCycle() {                                        // DFS
    const visited = new Set(); const stack = new Set();
    const dfs = (n) => { if (stack.has(n)) throw new Error(`循环依赖: ${n}`);
      if (visited.has(n)) return; visited.add(n); stack.add(n);
      (this.deps.get(n) ?? []).forEach(dfs); stack.delete(n); };
    Object.keys(this.schema).forEach(dfs);
  }
  setField(name, value) {                               // 2) 下游传播
    this.values[name] = value;
    const downstream = [...topoFrom(name, this.deps)];
    downstream.forEach(f => this.evaluate(f));
  }
  async validateAll() {                                 // 4) 并行校验
    const results = await Promise.all(Object.entries(this.schema)
      .map(async ([n, d]) => [n, await d.validate?.(this.values[n]) ?? null]));
    return Object.fromEntries(results.filter(([, e]) => e));
  }
}
```
