## ARC-323：笔试题：实现虚拟滚动列表组件？
**答**：实现定高虚拟列表组件：1) 只渲染可视区 ± overscan 条；2) 支持 10 万条数据滚动流畅；3) 提供滚动到指定索引 API；4) 容器尺寸变化自适应（ResizeObserver）。
**评分点**：
- 可视区间计算正确（scrollTop/height/rowHeight → start/end，含 overscan）。
- 撑高容器正确（总高度 div），偏移用 transform 而非 paddingTop（避免回流抖动）。
- scroll 监听用 rAF 节流，ResizeObserver 更新视口高度。
- scrollToIndex 边界处理（clamp 到 [0, total-1]）。
```tsx
function VirtualList({ items, rowHeight = 40, overscan = 5, className }) {
  const boxRef = useRef<HTMLDivElement>(null);
  const [range, setRange] = useState({ start: 0, end: 0 });
  const [vh, setVh] = useState(600);
  useEffect(() => {
    const ro = new ResizeObserver(([e]) => setVh(e.contentRect.height));  // 4) 自适应
    ro.observe(boxRef.current!);
    return () => ro.disconnect();
  }, []);
  const onScroll = () => requestAnimationFrame(() => {                   // 3) rAF 节流
    const st = boxRef.current!.scrollTop;
    const start = Math.max(0, Math.floor(st / rowHeight) - overscan);
    const end = Math.min(items.length, Math.ceil((st + vh) / rowHeight) + overscan);
    setRange({ start, end });
  });
  const scrollToIndex = (i: number) => {
    const idx = Math.min(Math.max(0, i), items.length - 1);              // 边界 clamp
    boxRef.current!.scrollTop = idx * rowHeight;
  };
  const slice = items.slice(range.start, range.end);
  return (
    <div ref={boxRef} className={className} style={{ overflow: 'auto', height: '100%' }}
      onScroll={onScroll}>
      <div style={{ height: items.length * rowHeight, position: 'relative' }}>  {/* 2) 撑高 */}
        <div style={{ transform: `translateY(${range.start * rowHeight}px)` }}>
          {slice.map((it, i) => <div key={range.start + i} style={{ height: rowHeight }}>{render(it)}</div>)}
        </div>
      </div>
    </div>
  );
}
```

## 变体与延伸（补充）

**变体与延伸**：

1. 行高不固定怎么办？→ 估算行高加实测回填，维护偏移量索引，或改用动态高度加锚点校正，估算与实测之间设容差，避免滚动中反复校正。
2. 图片异步撑开高度怎么处理？→ 预留占位高度并在加载后校正偏移，配合 ResizeObserver 监听行内容变化，占位高度按宽高比预算，减少布局抖动。
3. 十万条还卡，先查什么？→ 先看是否每帧 setState 触发整表 diff，改成只更新可视区间并在 rAF 内合并更新，同时给列表项加 memo 防止整块重渲染。
