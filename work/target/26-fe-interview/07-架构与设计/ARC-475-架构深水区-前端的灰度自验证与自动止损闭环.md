## ARC-475：灰度自验证与自动止损闭环
**答**:
- 闭环模型：发布 → 自动观测（发布后 N 分钟指标对比基线）→ 判定（阈值内自动放量 / 异常自动暂停回滚）→ 通知（结果推送到发布群）。目标是不靠人盯。
- 判定指标：错误率、白屏率、LCP/P95 接口耗时，对比"同桶基线"（非灰度桶同期数据，消除大盘波动干扰）；小样本阶段用贝叶斯/最小样本量判定，避免抖动误判。
- 自动止损动作分级：暂停放量（等待人工）、自动回退（错误率超硬阈值，直接切回上一版本）、保留现场（回滚前抓取错误样本与指纹，供复盘）。
- 防误杀：发布瞬间的缓存混合期（新旧 HTML + 旧资源 404）会产生假错误——观测窗口跳过缓存过渡期（5~10 分钟）+ 新旧资源并存期双版本可达（ARC-368）。
- 闭环运营：每次自动止损事件入库（触发原因/耗时/误判标注），季度回看阈值合理性。
```javascript
// 自动止损判定器（平台侧）
function evaluate(release) {
  const m = metrics.compare(release, baselineBucket, { skipFirst: '10m' });
  if (m.errorRate > baseline.errorRate * 3) return autoRollback(release);   // 硬阈值
  if (m.lcpP75 > baseline.lcpP75 * 1.3) return pauseAndNotify(release);     // 软阈值
  return autoPromote(release);                                 // 全部达标自动放量
}
```
