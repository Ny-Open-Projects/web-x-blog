## DP-501：笔试：手写观察者泄漏检测

**答**：在事件总线上加「订阅泄漏检测层」：① 包装 subscribe——登记 { source(订阅方标识), stack, t }；② audit()：活跃订阅列表（按 source 聚合、存活时长）；③ 泄漏告警：同 source 存活 >10min 且数量增长 → 告警；④ sub/unsub 计数平衡监控；⑤ 定时快照对比（每分钟订阅数增速——增长速率告警非绝对值）。写出实现。

```javascript
function withLeakDetection(store, { growthThreshold = 20 } = {}) {
  const active = new Map();     // dispose -> { source, stack, t }
  let lastCount = 0;
  const origSub = store.subscribe;
  store.subscribe = (fn, source = 'anonymous') => {
    const dispose = origSub.call(store, fn);
    active.set(dispose, { source, stack: new Error().stack?.split('\n')[2], t: Date.now() });
    return () => { active.delete(dispose); dispose(); };
  };
  return {
    audit() {
      return [...active.values()].map((r) => ({
        source: r.source, ageMin: +((Date.now() - r.t) / 60000).toFixed(1), stack: r.stack,
      })).sort((a, b) => b.ageMin - a.ageMin);
    },
    startWatch(intervalMs = 60_000) {
      const timer = setInterval(() => {
        const n = active.size;
        if (n - lastCount > growthThreshold)
          console.warn('[leak]', this.audit().slice(0, 5));   // 增长最快的订阅源
        lastCount = n;
      }, intervalMs);
      return () => clearInterval(timer);
    },
  };
}
// 订阅时带 source='react:CartPage' — 泄漏可归因到组件
```

**评分点**：
- 订阅带身份（source + stack——泄漏归因）
- 增长速率告警（非绝对值——增长才可疑）
- audit 的按 source 聚合与排序
- watch 可停止（定时器清理）
