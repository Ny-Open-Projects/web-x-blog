## ARC-416：长连接网关的前端架构如何设计？
**答**:
- 单例连接 + 多路复用：一个页面只建一条 WebSocket，上跑多个逻辑通道（IM/通知/行情），按 topic 订阅分发；避免多 SDK 各自建连的连接数爆炸。
- 连接治理：心跳（ping/pong 30s，超时重连）、指数退避重连（带抖动防雪崩）、页面隐藏时降频心跳或断开（省电省服务端）、回前台立即恢复。
- 消息可靠性：客户端 seq + 服务端 ack；断线重连后按 lastSeq 拉增量（gap 检测）；去重（seq 已见丢弃）。
- 通道生命周期：topic 订阅引用计数（组件挂载 subscribe、卸载 unsubscribe），页面卸载统一清理防泄漏。
- 降级链：WS 不可用 → SSE → 轮询（间隔随负载调整）；通道切换对业务透明（统一 event emitter 接口）。
```javascript
class WsGateway {
  #topics = new Map(); // topic -> { handlers:Set, refCount }
  subscribe(topic, handler) {
    const t = this.#ensure(topic); t.refCount++;
    t.handlers.add(handler);
    return () => { if (--t.refCount <= 0) this.#send({ op: 'unsub', topic }); t.handlers.delete(handler); };
  }
  onMessage({ topic, seq, payload }) {
    if (seq <= this.#seen.get(topic)) return;                   // 去重
    this.#seen.set(topic, seq);
    this.#topics.get(topic)?.handlers.forEach(h => h(payload));
  }
  #heartbeat() { this.pingTimer = setInterval(() => {
    if (Date.now() - this.lastPong > 45000) this.reconnect();   // 1.5 倍周期未 pong → 重连
    this.#send({ op: 'ping' });
  }, 30000); }
}
```
