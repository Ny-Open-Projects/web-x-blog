## DP-511：笔试：手写画布命令

**答**：实现画布编辑器的命令系统：① MoveCommand：节点移动（from/to 坐标——undo 精确回移）；② MacroCommand：宏命令（组合多个子命令——原子撤销：拖拽 = 多步移动合为一条）；③ 连续拖拽的合并：拖拽过程中的多次 move 合并（开始/结束坐标——merge 协议）；④ 对齐吸附的原子性：移动+吸附是一组（吸附不产生独立撤销点）；⑤ 与 History 集成：宏命令入栈。写出实现。

```javascript
class MoveCommand {
  constructor(node, from, to) { Object.assign(this, { node, from, to, label: 'move' }); this.ts = Date.now(); }
  execute() { this.node.x = this.to.x; this.node.y = this.to.y; }
  undo() { this.node.x = this.from.x; this.node.y = this.from.y; }
  merge(next) {                                       // 拖拽过程合并
    if (next.label !== 'move' || next.node !== this.node) return null;
    this.to = next.to;                                // 只更新终点
    this.ts = next.ts;
    return this;
  }
}
class MacroCommand {
  constructor(commands, label) { this.commands = commands; this.label = label; }
  execute() { this.commands.forEach((c) => c.execute()); }
  undo() { [...this.commands].reverse().forEach((c) => c.undo()); }   // 逆序撤销
}
// 拖拽: pointermove 产生 N 个 MoveCommand → dragend 时 Macro([...]) — 原子撤销
```

**评分点**：
- merge 协议（拖拽过程合并——只更新终点）
- 宏命令的原子性（逆序撤销——组合命令）
- 拖拽的「一条撤销点」语义（move 过程不堆栈）
- undo 精确回移（from/to 而非快照）
