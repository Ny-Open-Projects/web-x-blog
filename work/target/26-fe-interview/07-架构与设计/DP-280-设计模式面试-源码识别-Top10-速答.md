## DP-280：源码识别面试 Top10 速答：一句话指认模式？
**答**:
- Vue3 reactive = 代理；effect 收集 = 观察者；computed = 备忘录。
- Koa compose = async 职责链（洋葱）；Express = 回调职责链。
- Axios adapter = 适配器；拦截器链 = 职责链+装饰。
- Redux action/reducer = 命令 + 状态转移；subscribe = 观察者；applyMiddleware = dispatch 装饰。
- React 双缓冲 fiber = 备忘录；Scheduler = 优先级队列 + 时间切片；Suspense throw promise = 信号控制流。
- immer draft = 代理 + 写时复制；patches = 命令记录。
- KeepAlive cache = 享元 + 对象池；LRU max = 淘汰策略。
- Zod schema = 组合 + 解释器；safeParse = 错误收集型解释。
- SW 策略（cache-first/swr）= 策略模式注册表；SW 版本切换 = 状态机。
- XState = 状态模式范式；Yjs = 状态向量 + 确定性合并。
- 收束：识别三问——"谁封装了变化（策略/适配）？谁在通知谁（观察者）？状态存在哪（备忘录/单例）？"

```javascript
// 速答背后的通用识别框架
// 1) 封装变化：接口不同（适配器）/行为可换（策略）/能力叠加（装饰）
// 2) 通知关系：单向订阅（观察者）/链式移交（职责链）/全局广播（发布订阅）
// 3) 状态归属：快照可回滚（备忘录）/全局唯一（单例）/复用共享（享元）/行为随状态变（状态模式）
// 面试话术："这段源码里 X 是被代理的 subject，Y 是 observer，Z 是策略注入点——所以是代理+观察者+策略的组合"
```
