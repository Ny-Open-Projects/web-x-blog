## ARC-547：页面级性能预算双体系
**答**:
- 双预算：资源预算（bundle 体积/图片/字体/第三方脚本——构建期可控 ARC-407）+ 体验预算（LCP/INP/CLS/TTFB——线上 RUM 实测）。两者联动：资源超标通常导致指标劣化，但指标劣化也可能来自数据/服务端——预算要分开归因。
- 预算设定：按页面类型分档（首页严、详情页中、活动页松）+ 基于当前真实值小步收紧（一次卡太严全被豁免 = 体系失效 ARC-396）。
- 运转机制：构建期卡资源预算（CI 阻断 + 豁免留痕）、线上 RUM 周报对比预算（劣化页面自动开单归因到版本/依赖，ARC-358 归因）、第三方脚本单独预算（第三方不可控——预注册白名单与体积上限，新增走评审）。
- 预算可视化：团队可见的预算看板（各页面预算 vs 实际、豁免清单、趋势）——预算不再是"文档里的数字"。
- 例外通道：临时超标豁免（大促功能）+ 到期自动回归检查（豁免过期提醒重新达标或继续豁免审批）。
```javascript
// 双预算配置
const budgets = {
  '/':            { js: 180, css: 30, img: 250, thirdParty: 30, lcp: 2.0 },
  '/goods/:id':   { js: 220, css: 35, img: 400, thirdParty: 40, lcp: 2.5 },
  '/activity/*':  { js: 250, css: 40, img: 500, thirdParty: 60, lcp: 2.5 }
};
// CI: bundle-budget(dist, budgets[route]) 阻断；RUM 周报：lcpP75 > budget.lcp → 开单
```
