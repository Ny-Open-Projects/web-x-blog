## DP-304：笔试题：手写权限快照（位图+增量同步）？
**答**：实现 PermBitmap：1) 权限码全平台有序表，快照编码为 Uint8Array 位图；2) has(code) O(1)；3) applyDiff（新增/移除的码列表）增量更新；4) serialize/deserialize（base64 传输）。
**评分点**：
- 位图索引计算正确（idx>>3 与 idx&7）。
- diff 应用只改受影响 bit。
- base64 编解码正确（byte 长度取整）。
- 版本号随快照维护。
```javascript
class PermBitmap {
  constructor(table /* 全平台有序权限码 */) {
    this.index = new Map(table.map((c, i) => [c, i]));
    this.bits = new Uint8Array(Math.ceil(table.length / 8));
    this.version = 0;
  }
  grant(codes) { for (const c of codes) { const i = this.index.get(c); if (i == null) continue;
    this.bits[i >> 3] |= 1 << (i & 7); } this.version++; }
  revoke(codes) { for (const c of codes) { const i = this.index.get(c); if (i == null) continue;
    this.bits[i >> 3] &= ~(1 << (i & 7)); } this.version++; }
  has(code) { const i = this.index.get(code);
    return i != null && (this.bits[i >> 3] & (1 << (i & 7))) !== 0; }   // 2) O(1)
  applyDiff({ grant = [], revoke = [] }) { this.grant(grant); this.revoke(revoke); }   // 3)
  serialize() {
    return btoa(String.fromCharCode(...this.bits));    // 4) base64
  }
  static deserialize(b64, table) {
    const bm = new PermBitmap(table);
    bm.bits = Uint8Array.from(atob(b64), c => c.charCodeAt(0));
    return bm;
  }
}
```
