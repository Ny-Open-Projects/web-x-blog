## DP-426：导航守卫深水

**答**：
- 守卫的模式深水：责任链（多守卫依次）、策略（守卫按路由元信息动态选择）、状态机（导航生命周期：idle→guarding→fetching→committing）、备忘录（导航历史——back 语义）
- 守卫的「取消语义」：导航进行中用户再点击（取消旧导航——AbortController + 状态机 cancel 迁移）——旧导航的回调不得执行（竞态）
- 重定向环检测：A→B→A 的守卫重定向环（深度计数 >5 断环——报配置错误）
- 异步守卫的数据预取：守卫里拉权限/AB 数据（守卫延迟导航）——「预取与导航并行」的优化（preload 与 guard 竞速）
- 深水点：守卫的「错误传播」——守卫抛错（网络失败）→ 降级策略（放行+默认值 or 中断+错误页）——每个守卫声明失败策略

```javascript
async function runGuards(to, from) {
  let depth = 0;
  for (const guard of activeGuards(to)) {
    if (++depth > 5) throw new Error('重定向环');
    const r = await guard(to, from, { signal: navController.signal });
    if (r?.redirect) return runGuards(r.redirect, to);
    if (r?.abort) return null;
  }
  commit(to);
}
// 守卫失败策略: authGuard 失败 → 中断; abGuard 失败 → 默认分组放行
```
