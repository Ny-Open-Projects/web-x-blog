## ARC-812：手写演练框架

**答**：实现故障演练框架 `ChaosFramework`：① 演练场景声明：{ name, steps: [{ inject: 'cdn-fail'|'api-latency'|'kill-sw', duration, scope }], assertions: ['fallback-active', 'errorRate<0.1'], rollback: 'auto' }；② 注入器：cdn-fail（阻断资源请求）、api-latency（接口延迟注入）、kill-sw（模拟 SW 失效）——注入器可扩展注册；③ 断言引擎：演练期间实时校验断言（降级生效/错误率可控）——断言失败即演练失败；④ 自动回滚：演练结束/异常中止 → 自动恢复注入（cleanup 保证）；⑤ 演练报告：注入时间线/断言结果/MTTR 测量——演练的产出物。写出实现。

```javascript
const INJECTORS = new Map();
INJECTORS.set('cdn-fail', (scope) => { /* 拦截 fetch 到 CDN 域名 → 返回失败 */ return () => restore(); });
INJECTORS.set('api-latency', (scope, ms = 3000) => { /* 包装 fetch 延迟 */ return () => restore(); });

class ChaosFramework {
  #injectors = INJECTORS; #cleanups = [];
  registerInjector(name, fn) { this.#injectors.set(name, fn); }

  async run(scenario, { onEvent } = {}) {
    const report = { name: scenario.name, timeline: [], assertions: [] };
    try {
      for (const step of scenario.steps) {
        const injector = this.#injectors.get(step.inject);
        if (!injector) throw new Error(`unknown injector: ${step.inject}`);
        const cleanup = injector(step.scope, step.duration);
        this.#cleanups.push(cleanup);
        report.timeline.push({ inject: step.inject, at: Date.now() });
        await sleep(step.duration);
        // 断言校验
        for (const a of scenario.assertions) {
          const ok = await evaluateAssertion(a);         // 实际查询监控/状态
          report.assertions.push({ assertion: a, pass: ok });
          if (!ok) throw new Error(`assertion failed: ${a}`);
        }
      }
      report.pass = true;
    } catch (e) {
      report.pass = false; report.error = String(e);
    } finally {
      this.#cleanups.forEach((c) => c()); this.#cleanups = [];   // 自动回滚
    }
    report.mttr = measureRecovery();
    return report;
  }
}
// 用法:
// chaos.run({ name: 'cdn 挂掉演练', steps: [{ inject: 'cdn-fail', scope: 'img.*', duration: 60000 }],
//   assertions: ['fallback-active', 'errorRate<0.1'] })
// → { pass: true, timeline: [...], assertions: [{pass:true}...], mttr: 42 }
```

**评分点**：
- 注入器可扩展注册（三种内置 + 注册机制）
- 断言实时校验（演练失败即中止——不硬撑）
- 自动回滚的 cleanup 保证（finally——演练不引入真故障）
- 演练报告含 MTTR 测量（演练的度量产出）
