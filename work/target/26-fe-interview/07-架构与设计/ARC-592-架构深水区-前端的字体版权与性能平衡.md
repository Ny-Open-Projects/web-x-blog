## ARC-592：字体版权与性能平衡
**答**:
- 字体治理三问题：版权（商用授权范围/嵌入方式合规——font 文件进仓库前过法务清单）、性能（ARC-495 子集化策略）、一致性（各处字体引用统一——禁散装 @font-face）。
- 管理机制：字体资产清单（每个字体：授权范围/用途/子集策略/负责人——新字体引入走审批）、子集流水线（原始字体入库 → 子集化生成 → 产物发布 CDN——原始字体不进前端产物）、引用收口（字体只有一处 @font-face 声明（字体模块），业务只能用字体名——多端产物同源 ARC-163）。
- 版权审计：字体使用范围巡检（授权只覆盖 Web 但被用于 App 内嵌 = 违约风险——按端清单核对）、续费与到期台账。
- 性能联动：新字体引入必须过性能预算（ARC-547 字体预算）——"想用就用的字体"没有预算空间。
- 替代策略：优先系统字体栈（零成本零版权）、品牌字仅标题（ARC-495 策略分级）——字体引入是例外不是默认。
```yaml
# 字体资产清单
fonts:
  brand-title:
    license: { type: 'commercial-web', expires: '2027-06', covers: ['web', 'h5'] },  # 不含 App 内嵌
    subsets: [ 'latin', 'cn-common' ], owner: design-system
  system: { license: 'system', note: '正文默认栈，零成本' }
# CI: fonts/ 之外出现 .woff2 → 违规（引用收口）；App 内嵌需扩展授权（法务确认）
```
