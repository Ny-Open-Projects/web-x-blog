## DP-498：笔试：手写 DI 容器

**答**：实现轻量 DI 容器 `Container`：① register(token, factory, { singleton })——factory 接收容器（可解析其他依赖）；② resolve(token)：单例缓存 / transient 每次新建；③ 循环依赖检测：A→B→A（解析栈——环报错）；④ 子容器：createScope()——scoped 实例（请求级/页面级生命周期）；⑤ 测试替换：override(token, fake) + resetOverrides()。写出实现。

```javascript
class Container {
  #registrations = new Map(); #singletons = new Map();
  #resolving = []; #overrides = new Map();
  register(token, factory, { singleton = true } = {}) { this.#registrations.set(token, { factory, singleton }); }
  override(token, fake) { this.#overrides.set(token, fake); }
  resetOverrides() { this.#overrides.clear(); }

  resolve(token) {
    if (this.#overrides.has(token)) return this.#overrides.get(token);
    const reg = this.#registrations.get(token);
    if (!reg) throw new Error(`未注册: ${String(token.description ?? token)}`);
    if (reg.singleton && this.#singletons.has(token)) return this.#singletons.get(token);
    if (this.#resolving.includes(token))
      throw new Error(`循环依赖: ${[...this.#resolving, token].map(String).join(' → ')}`);
    this.#resolving.push(token);
    try {
      const inst = reg.factory(this);                  // factory 拿容器 → 解析自己的依赖
      if (reg.singleton) this.#singletons.set(token, inst);
      return inst;
    } finally { this.#resolving.pop(); }
  }
  createScope() {                                      // 子容器: scoped 生命周期
    const scope = new Container();
    scope.#parent = this;
    return scope;
  }
}
// 测试: container.override(TOKENS.Api, () => fakeApi); ... container.resetOverrides();
```

**评分点**：
- 循环依赖检测（解析栈——环路径报错）
- 单例/transient 双生命周期 + 子容器 scope
- override 的测试替身注入（DI 的核心收益）
- factory 拿容器（依赖链解析）
