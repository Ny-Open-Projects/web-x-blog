## ARC-441：首屏编排的架构设计
**答**:
- 首屏是三线并行的流水线：资源线（HTML→CSS→JS chunk）、数据线（关键接口预取）、渲染线（骨架→内容→ hydration），架构目标是三条线重叠最大化。
- 编排点：服务端渲染时内联首屏数据（window.__INITIAL__，免二次请求）；关键 CSS 内联、非关键异步；路由 chunk 与接口请求在 HTML 解析期就发起（preload + service worker 缓存）。
- 交互优先：首屏先渲染"可交互骨架"（头部/导航/布局），重内容区流式补充；图片渐进（LQIP/模糊占位）。
- 编排配置化：首屏清单（哪些资源 high/哪些接口关键）做成 per-route 配置，构建工具消费生成 preload，运行时按网络状况调整（弱网砍非关键）。
- 度量：分段耗时瀑布（HTML/数据/hydration 各自 P75），编排优化的验收指标是 LCP + 局部 TTI 联合达标。
```javascript
// 路由级首屏编排配置
const homeOrchestration = {
  critical: { css: 'inline', data: ['goods.list', 'user.profile'] },   // 内联预取
  preload: ['/chunk-home.js', '/fonts/main.woff2'],
  defer: ['chat-widget', 'recommend-float'],                           // 交互后加载
  weakNet: { dropDefer: true, imageQuality: 'low' }                    // 弱网策略
};
// 构建期：生成 preload 标签；运行时：按 navigator.connection 调整
```
