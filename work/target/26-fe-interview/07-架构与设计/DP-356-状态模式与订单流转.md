## DP-356：状态模式：状态流转引擎

**答**：
- 状态模式核心：状态是对象（每个状态定义自己可响应的事件），而不是 if(currentStatus === 'xxx') 散落各处
- 实战结构：transitions 表（state → { event: { target, guard, action } }）+ send(event)——guard 拒绝非法迁移、action 处理副作用
- 前端价值：非法状态不可能出现（按钮按状态渲染——「当前状态能做什么」由状态机回答）；测试完备（迁移表即测试矩阵）
- 与策略模式的关系：策略是「平行可替换的算法」，状态是「随时间迁移的行为」——订单流程用状态机，排序算法用策略
- 深水点：UI 与状态机的对接——「每个状态允许的操作集合」直接驱动按钮渲染（disabled 逻辑自动化）

```javascript
function createMachine({ states, initial }) {
  let current = initial;
  return {
    get state() { return current; },
    can(event) { return !!states[current]?.on?.[event]; },     // UI 驱动
    send(event, payload) {
      const t = states[current]?.on?.[event];
      if (!t) return { ok: false, reason: 'illegal' };
      if (t.guard && !t.guard(payload)) return { ok: false, reason: 'guard' };
      t.action?.(payload);
      current = t.target;
      return { ok: true, state: current };
    },
  };
}
// 迁移表:
// { open: { on: { pay: { target: 'paid', guard: (p) => p.amount > 0 },
//                cancel: { target: 'closed' } } },
//   paid: { on: { ship: { target: 'shipped' } } } }
```
