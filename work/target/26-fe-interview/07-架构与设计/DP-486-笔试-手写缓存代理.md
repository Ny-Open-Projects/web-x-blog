## DP-486：笔试：手写缓存代理

**答**：用 Proxy 实现方法级缓存代理：① 对目标对象的所有异步方法自动缓存（key = 方法名+参数序列化）；② TTL 过期（命中但过期重新执行）；③ 失败不缓存（异常的调用下次重试）；④ 缓存命中统计（hit/miss——监控缓存收益）；⑤ invalidate(pattern)：按方法名/参数前缀失效；⑥ 说明与手写缓存包装的区别（Proxy 对全部方法统一生效 vs 逐个包装）。写出实现。

```javascript
function cachedProxy(target, { ttl = 60_000 } = {}) {
  const cache = new Map();
  const stats = { hit: 0, miss: 0 };
  return new Proxy(target, {
    get(t, prop) {
      const orig = t[prop];
      if (typeof orig !== 'function') return orig;
      return function (...args) {
        const key = `${String(prop)}:${JSON.stringify(args)}`;
        const hit = cache.get(key);
        if (hit && Date.now() - hit.at < ttl) { stats.hit++; return Promise.resolve(hit.value); }
        stats.miss++;
        return Promise.resolve(orig.apply(t, args)).then(
          (v) => { cache.set(key, { value: v, at: Date.now() }); return v; },
          (e) => { throw e; },                        // 失败不缓存
        );
      };
    },
  });
}
// invalidate: cache.clear() / 按前缀遍历删除
// 统计暴露: proxy.__stats → { hit, miss } — 缓存收益可观测
```

**评分点**：
- Proxy get 拦截对全部方法统一生效（vs 逐个包装）
- TTL 与失败不缓存的正确语义
- key 的参数序列化完整性
- 命中统计可观测（缓存收益）
