## ARC-458：前端合规审查自动化
**答**:
- 合规三类自动化：隐私（个人信息收集声明、SDK 隐私清单、敏感字段脱敏扫描）、无障碍（axe 自动扫描、对比度/焦点/语义化检查）、内容合规（文案敏感词、价格法术语扫描"最低价"类违规词）。
- 检查时机：CI 阶段静态扫描（代码里的敏感 API 调用：geolocation/camera 无授权流程声明）、E2E 阶段运行时扫描（axe-core 跑核心页面）、上线后巡检（CSP 报告/隐私 SDK 版本核查）。
- 隐私扫描器设计：bundle 扫描定位个人信息收集点（手机号正则命中上报、IDFA/IMEI API 调用），产出"收集清单"供合规声明对齐；清单与实际收集不一致即违规。
- 门禁集成：违规分级（阻断级：明文收集身份证号；警告级：缺 aria-label），豁免需合规侧审批留痕。
- 证据留存：每次发布的合规扫描报告存档（监管审计要追溯）。
```javascript
// E2E 阶段合规扫描
import { AxeBuilder } from '@axe-core/playwright';
test('核心页无障碍基线', async ({ page }) => {
  await page.goto('/goods/detail');
  const results = await new AxeBuilder({ page }).withTags(['wcag2a', 'wcag2aa']).analyze();
  const critical = results.violations.filter(v => v.impact === 'critical');
  expect(critical, JSON.stringify(critical.map(v => v.id))).toHaveLength(0);   // CI 卡口
});
// bundle 隐私扫描：正则定位手机号等收集点 → 生成收集清单
```
