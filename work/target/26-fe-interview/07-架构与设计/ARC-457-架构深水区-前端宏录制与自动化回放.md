## ARC-457：前端宏录制与自动化回放架构
**答**:
- 应用场景：用户操作录制生成教程回放、客服代操作（协同代操作）、自动化测试脚本生成、RPA 式批量处理。
- 架构：录制层（命令系统天然是录制源——ARC-456；无命令系统的用事件拦截：DOM 事件序列化）、存储层（操作序列 + 页面上下文）、回放层（逐步执行 + 可调速 + 中断恢复）。
- 关键设计：操作语义化（录制"点击了确认按钮"的命令而非"click at 300,200"坐标——回放才能抵抗布局变化）、上下文快照（回放前恢复录制时的文档状态）、回放校验（每步执行后校验前置条件，不符时暂停并提示人工接管）。
- 安全边界：回放涉及写操作必须用户确认与权限校验；代操作场景操作者身份与痕迹（审计日志记"由客服 X 代操作"）。
- 失败处理：元素找不到/状态不符的重试与降级策略（跳过可选项 vs 中止关键步骤）。
```javascript
class MacroRecorder {
  #steps = [];
  record(cmd) { this.#steps.push({ cmd, ctx: model.snapshot() }); }  // 命令级录制
  async replay({ speed = 1, onStep, onGuardFail }) {
    for (const step of this.#steps) {
      if (!guardOk(step)) { onGuardFail?.(step); return 'paused'; } // 前置校验失败人工接管
      await step.cmd.do(model);
      onStep?.(step);
      await delay(300 / speed);
    }
    return 'done';
  }
}
```
