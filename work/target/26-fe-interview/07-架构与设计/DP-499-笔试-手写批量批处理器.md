## DP-499：笔试：手写批处理器

**答**：实现批处理器 `Batcher`：① add(item) → 缓冲（满 maxSize / 定时 windowMs 双触发 flush）；② flush 的失败重入队（批不丢——失败批次放回缓冲头部）；③ 上限保护：缓冲超上限丢最旧 + 丢弃计数（防内存涨）；④ flush 的并发防护（flushing 标记——上一次 flush 未完成不重入）；⑤ pagehide 兜底（sendBeacon 紧急 flush）。写出实现。

```javascript
class Batcher {
  #buf = []; #dropped = 0; #flushing = false; #timer = null;
  constructor({ maxSize = 500, flushSize = 20, windowMs = 3000, send } = {}) {
    Object.assign(this, { maxSize, flushSize, windowMs, send });
    addEventListener('pagehide', () => this.#flush(true));
  }
  add(item) {
    if (this.#buf.length >= this.maxSize) { this.#buf.shift(); this.#dropped++; }   // 丢最旧
    this.#buf.push({ ...item, seq: ++this.seq, t: Date.now() });
    if (this.#buf.length >= this.flushSize) this.#flush();
    else this.#timer ??= setTimeout(() => this.#flush(), this.windowMs);
  }
  #flush(urgent = false) {
    clearTimeout(this.#timer); this.#timer = null;
    if (this.#flushing || !this.#buf.length) return;
    if (urgent) return navigator.sendBeacon(this.url, JSON.stringify({ events: this.#buf.splice(0), dropped: this.#dropped }));
    this.#flushing = true;
    const batch = this.#buf.splice(0);
    this.send(batch)
      .catch(() => { this.#buf.unshift(...batch); })   // 失败重入队头部 (保序)
      .finally(() => { this.#flushing = false; this.#dropped && this.#reportDrops(); });
  }
}
```

**评分点**：
- 双触发（满量/定时）+ pagehide 紧急通道
- 失败重入队头部（保序——批不丢）
- 并发防护（flushing 标记——防重入）
- 上限丢最旧 + 丢弃计数（背压与可观测）
