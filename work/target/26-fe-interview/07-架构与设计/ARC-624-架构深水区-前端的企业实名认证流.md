## ARC-624：企业实名认证流
**答**:
- 流程复杂度：多步骤（基本信息 → 证照上传 → 法人验证 → 对公打款/法人扫脸 → 审核）+ 长周期（对公打款 1~3 天）——向导架构（ARC-489）+ 异步状态（ARC-488 恢复）。
- 证照上传：多证照（营业执照/法人身份证——各自预检配置 ARC-605）、OCR 预填（上传后识别预填——用户确认修正）、证照有效性（服务端工商接口校验——前端展示校验结果与失败原因）。
- 对公打款流程：打款金额随机小额（用户回填验证——金额输入精确校验）、有效期（超时重发）、状态可查（认证进度时间线——每步状态与预计时长展示）。
- 状态与恢复：认证状态机服务端权威（每步完成即存——中断恢复从断点继续 ARC-521 分步提交）、审核被拒（原因结构化 + 对应步骤重新填写定位）。
- 合规与安全：证照信息安全（上传加密/展示脱敏/水印 ARC-341/346）、信息使用告知（合规文案 ARC-571）。
```javascript
// 认证向导 + 异步状态
const wizard = useWizard(verificationSchema, { resume: true });  // 断点续填
// 步骤：basic → licenses(OCR 预填) → legal-person → bank-transfer(异步) → review
poll(verifyId, { until: s => s.state !== 'processing' })          // 对公打款验证轮询
  .then(s => s.state === 'verified' ? wizard.next() : wizard.jumpTo('bank-transfer', s.reason));
```
