## ARC-626：发票开具流程
**答**:
- 抬头管理：抬头类型（个人/企业——企业需税号校验/专票额外字段）、抬头库（增删改查 + 默认抬头——表单 schema 按类型切换 ARC-570 动态字段）、税号校验（格式 + 合规提示）。
- 开票流程：选择范围（按订单/按月汇总——多订单合并开票的金额计算服务端）、开票申请（提交 → 异步开具——任务状态轮询/推送 ARC-576）、发票交付（PDF/OFD 下载 + 邮件发送——预览器统一 ARC-522）。
- 状态流：开票状态机（申请→开具中→已开具/失败——失败原因：税号错误/超额——可修正重开）、红冲（作废重开流程——原发票状态联动）。
- 一致性：可开票金额与订单状态联动（已全额开票订单不可重复开——服务端裁决）、退款后发票冲红提示（退款成功 → 已开发票提示冲红 ARC-625 联动）。
- 合规：发票要素展示（税率/金额大小写——格式化规范）、电子发票存档（端上缓存 + 重新下载）。
```javascript
// 抬头动态表单 + 开票任务
<InvoiceHeaderForm type={headerType} />                          // 个人/企业 schema 切换
const { taskId } = await api.issueInvoice({ orderIds, headerId });
taskCenter.watch(taskId, { done: r => download(r.fileUrl),       // 开票完成下载
  failed: r => showReason(r.code) });                            // 税号错误可修正重开
```
