## DP-522：笔试：手写粒子系统

**答**：实现 Canvas 粒子系统（烟花特效）：① 粒子数据与渲染分离：粒子状态数组（Float32Array——x/y/vx/vy/life）+ 单一渲染循环（享元——10000 粒子零对象分配）；② 对象池：粒子死亡后重用（生命周期循环——无 GC 压力）；③ 批量更新：物理更新与渲染分离（先全部 update 再统一 draw——减少 ctx 状态切换）；④ 死亡回收：life ≤0 → 回收索引入池；⑤ 容量上限：池满丢新粒子（性能保护——不崩溃）。写出实现。

```javascript
class ParticleSystem {
  #pool = []; #active = [];
  constructor(max = 5000) { this.max = max; }
  spawn(x, y, vx, vy) {
    if (this.#active.length >= this.max) return;       // 容量保护
    const p = this.#pool.pop() ?? { x: 0, y: 0, vx: 0, vy: 0, life: 1 };
    Object.assign(p, { x, y, vx, vy, life: 1 });
    this.#active.push(p);
  }
  update(dt) {
    this.#active = this.#active.filter((p) => {
      p.x += p.vx * dt; p.y += p.vy * dt; p.vy += 0.5; p.life -= dt;
      if (p.life <= 0) { this.#pool.push(p); return false; }   // 死亡回收
      return true;
    });
  }
  draw(ctx) {
    ctx.fillStyle = '#f66';
    for (const p of this.#active) ctx.fillRect(p.x, p.y, 2, 2);   // 单循环批量绘制
  }
}
// 10000 粒子: 零对象分配 (池复用) — 无 GC 抖动
```

**评分点**：
- 数据与渲染分离（状态池 + 单一绘制循环）
- 死亡回收（粒子生命周期循环——零 GC）
- 容量上限保护（池满丢新——不崩溃）
- 批量绘制的 ctx 状态切换优化
