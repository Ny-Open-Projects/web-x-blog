## ARC-804：手写依赖健康度评估

**答**：实现依赖健康度评估器 `auditDeps(lockfile, registryData)`：① 每个依赖的健康评分：维护活跃度（最后发布距今）、周下载量、issue 响应率、漏洞数（npm audit 数据）、替代方案存在性；② 评分分级：健康(≥80)/关注(60~80)/风险(<60)——风险依赖列出「行动计划」（升级/替代/隔离）；③ 传递依赖分析：深度 >3 的依赖（依赖的依赖的依赖——风险传导）；④ 废弃依赖检测（deprecated 标记——必须处理）；⑤ 输出报告：总分/风险清单/行动计划/趋势（与上月对比）。写出实现。

```javascript
function auditDeps(deps, registry) {
  const results = [];
  for (const [name, version] of Object.entries(deps)) {
    const info = registry[name];
    if (info.deprecated) {
      results.push({ name, version, score: 0, level: 'risk',
        action: '立即替代 (deprecated)', depth: info.depth });
      continue;
    }
    let score = 100;
    const monthsSince = (Date.now() - info.lastPublish) / 2.6e9;
    if (monthsSince > 12) score -= 40; else if (monthsSince > 6) score -= 20;
    if (info.weeklyDownloads < 1000) score -= 20;
    if (info.openIssues > 100) score -= 10;
    score -= info.vulnerabilities.critical * 30 + info.vulnerabilities.high * 15;
    const level = score >= 80 ? 'healthy' : score >= 60 ? 'watch' : 'risk';
    const action = level === 'risk'
      ? (info.alternatives ? `替代为 ${info.alternatives[0]}` : '评估自研/锁定+隔离')
      : level === 'watch' ? '纳入观察清单' : null;
    results.push({ name, version, score: Math.max(0, score), level, action, depth: info.depth });
  }
  const deep = results.filter((r) => r.depth > 3);
  const risks = results.filter((r) => r.level === 'risk');
  const overall = Math.round(results.reduce((s, r) => s + r.score, 0) / results.length);
  return { overall, risks, deepDeps: deep, report: { healthy: results.filter(r=>r.level==='healthy').length, watch: results.filter(r=>r.level==='watch').length, risk: risks.length } };
}
// 输出: { overall: 82, risks: [{name:'left-pad', action:'替代为内置'}], ... }
```

**评分点**：
- 五维健康评分（活跃度/下载/issue/漏洞/替代）
- deprecated 零容忍（直接 risk + 行动）
- 传递依赖深度分析（风险传导）
- 行动计划输出（风险依赖必须带行动建议）
