## DP-328：笔试题：手写请求取消管理器（竞态/卸载）？
**答**：实现 CancelManager：1) run(key, fn)：同 key 新请求自动取消旧请求（防竞态）；2) 组件卸载批量取消（scope）；3) 取消后 promise 以 AbortError 结束（不是静默）；4) 手动 cancel(key)。
**评分点**：
- 同 key 替换逻辑正确（旧 AbortController abort）。
- scope 生命周期管理（卸载清理）。
- AbortError 结构化抛出。
- 管理 Map 清理（完成后移除）。
```javascript
class CancelManager {
  #inflight = new Map();    // key → { ctrl, scope }
  run(key, fn, { scope = 'default' } = {}) {
    this.#inflight.get(key)?.ctrl.abort();                 // 1) 同 key 取消旧
    const ctrl = new AbortController();
    this.#inflight.set(key, { ctrl, scope });
    return fn(ctrl.signal).finally(() => this.#inflight.delete(key));   // 4)
  }
  cancel(key) { this.#inflight.get(key)?.ctrl.abort(); this.#inflight.delete(key); }
  cancelScope(scope) {                                     // 2) 卸载批量取消
    for (const [k, v] of this.#inflight)
      if (v.scope === scope) { v.ctrl.abort(); this.#inflight.delete(k); }
  }
}

```
