## ARC-254：国际化架构的性能影响与优化清单？
**答**：
- 国际化的性能代价点：语言包请求（首屏串行风险）、t() 运行时开销（高频调用）、ICU 格式化成本（日期/复数解析慢）、RTL 双产物体积。
- 清单：① 语言包 immutable 缓存 + manifest 预取（ARC-245）；② 首屏语言包**内联**到 HTML（SSR 场景消除一次请求）；③ 高频 t() 结果做 key 级 memo（同参数不重格式化）；④ 日期/数字 formatter 按 locale+options 缓存 Intl 实例（构造很贵）；⑤ 语言包裁剪（ARC-245 tree-shaking）。
- 度量：带 i18n 与不带的首屏差值、语言包字节占比、t() 在火焰图中的占比（>2% 就要 memo）。

```typescript
// Intl 实例缓存（构造器是重头）
const fmtCache = new Map();
function numFmt(locale: string, opts: Intl.NumberFormatOptions) {
  const k = locale + JSON.stringify(opts);
  return fmtCache.get(k) ?? fmtCache.set(k, new Intl.NumberFormat(locale, opts)).get(k)!;
}
// t() memo：key+params+langVersion → 字符串
const memo = new Map();
function t(key, params) {
  const k = `${i18n.version}|${key}|${JSON.stringify(params)}`;
  if (!memo.has(k)) memo.set(k, format(dict[key], params));   // 切语言 version 变化自动失效
  return memo.get(k);
}
// SSR 首屏内联：<script>window.__I18N__ = ${dictString}</script>，客户端零请求直接水合
```
