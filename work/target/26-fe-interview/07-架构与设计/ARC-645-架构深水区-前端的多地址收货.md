## ARC-645：多地址收货
**答**:
- 地址簿：地址 CRUD（ARC-570 国际地址 schema——按国家动态字段）、默认地址（默认切换语义）、地址上限（配额——引导删除）。
- 一单多址：拆单场景（多商品发不同地址——商品行 → 地址分配交互：行级选择地址）、运费拆分（每址运费——服务端计算展示）、库存校验（各址库存独立校验）。
- 结算联动：地址变更 → 运费/可达性重算（偏远地区不可达提示——服务端校验，配货方式变化）、地址与发票分离（收货地址与发票抬头独立）。
- 数据一致性：地址删除时的引用保护（被订单引用的地址删除语义——订单保留快照，地址簿可删）、地址编辑同步（编辑后历史订单不变——订单快照地址）。
- 隐私：地址信息脱敏展示（手机号/详细地址部分掩码——列表页）。
```javascript
// 一单多址分配
const assign = cart.items.map(i => ({ sku: i.skuId, addressId: defaultAddr }));
<AddressAssign items={cart.items} addresses={addressBook}
  onChange={assign => recalc(assign)} />                          // 行级分配 → 服务端重算运费
// recalc: POST /checkout/recalc { assign } → { shipping[], unavailable[] }
```
