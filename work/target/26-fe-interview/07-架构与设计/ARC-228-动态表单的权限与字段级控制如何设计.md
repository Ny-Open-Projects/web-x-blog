## ARC-228：动态表单的权限与字段级控制如何设计？
**答**：
- 字段级权限三种形态：hidden（不渲染）、readonly（可看不可改）、masked（脱敏渲染，如身份证中间打星）。语义不同不能混用。
- 实现路径：表单 schema 里每字段带 `perm` 描述，渲染引擎按用户快照解析为最终形态；提交前**按权限裁剪 payload**——readonly/masked/hidden 字段绝不进请求体（保持后端原值）。
- 编辑回显陷阱：masked 字段提交空值会覆盖真实数据，约定"掩码字段提交 undefined = 不修改"。
- 与动态表单引擎（低代码）结合：权限解析器作为引擎的中间件，输出"渲染指令集"，与校验规则同源维护。

```typescript
type FieldPerm = 'hidden' | 'readonly' | 'masked' | 'edit';
function resolveFieldPerm(field, snap) {
  if (!field.perm) return 'edit';
  return field.perm.levels.find(l => can(snap, l.action, l.resource)) ?? 'hidden';
}
function buildPayload(values, fields, snap) {
  return Object.fromEntries(Object.entries(values).filter(([k]) => {
    const p = resolveFieldPerm(fields[k], snap);
    return p === 'edit' || (p === 'masked' && values[k] === undefined); // 掩码空值=不修改
  }));
}
// masked 渲染：<Input value={mask(idNo)} disabled onChange={() => {}} /> 提交时该字段默认剔除
```
