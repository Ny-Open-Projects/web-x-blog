## ARC-490：导入导出双向架构
**答**:
- 导出（ARC-382）+ 导入构成双向协议：导出模板（表头/示例/下拉说明）与导入解析必须同一份字段定义生成——模板和解析脱节是脏数据主因。
- 导入管道：文件解析（前端 preview 前 100 行）→ 字段映射（表头 → 字段，支持用户手工映射）→ 行级校验（schema + 业务规则 + 服务端唯一性预检）→ 错误汇总（行号+原因，可下载错误标注版文件）→ 确认提交 → 异步入库（ARC-486）。
- 校验分层：格式错误前端立即拒；业务规则（重复 SKU/库存不足）批量预检接口异步查；入库时最终裁决。错误报告结构化（机器可读 + 人工可读双份）。
- 大文件：> 10 万行走服务端解析（前端只上传），进度与结果走任务中心。
- 体验细节：模板下载自动带当前筛选数据版本说明、解析预览允许修列映射后重解析（不重复上传）。
```javascript
async function importExcel(file, schema) {
  const rows = await parse(file);                              // 前端解析预览
  const mapped = await ui.columnMapping(rows.headers, schema); // 字段映射确认
  const check = await api.precheck(mapped.rows);               // 服务端批量预检
  if (check.errors.length) return downloadErrorReport(check);  // 错误标注文件
  const ok = await ui.confirmPreview(mapped.rows.slice(0, 100), check.warnings);
  if (ok) await api.importCommit({ taskId: check.taskId });    // 异步入库
}
```
