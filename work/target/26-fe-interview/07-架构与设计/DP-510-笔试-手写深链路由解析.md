## DP-510：笔试：手写深链解析

**答**：实现深链解析器 `parseDeepLink(url)`：① scheme 识别：myapp://goods/42?from=share → { path, params }；② 二维码 scene 压缩参数：「a=1&b=2」32 字符格式解析；③ 参数安全校验：id 参数必须数字、redirect 参数必须同域（防开放重定向）；④ 归因提取：inviter/act/sid 短码（服务端还原的 sid 单独处理）；⑤ 非法路由的兜底（未知 path → 首页 + 上报）。写出实现。

```javascript
const ROUTES = ['/goods/:id', '/activity/:slug'];
const SAFE_HOST = 'm.example.com';

function parseDeepLink(url) {
  try {
    const u = new URL(url, 'https://m.example.com');
    const path = u.pathname;
    const params = Object.fromEntries(u.searchParams);
    // 二维码 scene 参数
    if (params.scene) Object.assign(params, Object.fromEntries(
      decodeURIComponent(params.scene).split('&').map((kv) => kv.split('='))));
    // 安全校验
    if (/^id$|Id$/.test(Object.keys(params).find((k) => /id/i.test(k)) ?? ''))
      for (const [k, v] of Object.entries(params)) if (/id/i.test(k) && !/^\d+$/.test(v)) return fallback('bad-id');
    if (params.redirect && new URL(params.redirect, 'https://m.example.com').host !== SAFE_HOST)
      return fallback('open-redirect');
    // 路由匹配
    const route = ROUTES.find((r) => {
      const rp = r.split('/'), pp = path.split('/').filter(Boolean);
      return rp.length === pp.length && rp.every((s, i) => s.startsWith(':') ? !!pp[i] : s === pp[i]);
    });
    if (!route) return fallback('unknown-route');
    return { ok: true, path, params };
  } catch { return fallback('parse-error'); }
}
function fallback(reason) { track('deeplink-reject', { reason }); return { ok: false, redirect: '/home' }; }
```

**评分点**：
- scene 压缩参数解析（32 字符二维码格式）
- 参数安全校验（id 数字/redirect 同域——防开放重定向）
- 未知路由兜底 + 上报（拒绝可观测）
- try/catch 全包（URL 解析的异常防御）
