## ARC-484：复杂筛选面板的状态架构
**答**:
- 筛选状态模型：筛选条件集（field → 值/区间/多选）+ 联动规则（选了 A 类目，B 品牌选项随之变化）+ 依赖图（条件间 DAG）；状态机描述"哪些筛选在当前上下文可见/可选/被禁用"。
- 架构收口：筛选条件入 URL（ARC-389）为唯一事实源，面板组件是 URL 的受控视图；联动规则声明式配置（optionsProvider: (ctx) => Promise<options>），联动查询竞态保护（AbortController）。
- 交互细节：防抖触发查询（输入 300ms、下拉选择即时）、查询竞态只采纳最新、筛选摘要 chips（可单个撤销）、"筛选结果为空"的引导（放宽建议）。
- 性能：联动选项预取（常见组合缓存）、大数据量选项远程搜索 + 本地缓存；筛选结果页虚拟滚动（ARC-442）。
- 可测性：筛选逻辑纯函数化（输入条件集 → 输出 query + 面板状态），E2E 只测关键路径。
```javascript
// 筛选引擎（纯函数 + 联动）
const filterEngine = {
  fields: { category: { type: 'single', required: false }, brand: { dependsOn: 'category' } },
  async options(field, ctx) {
    if (field === 'brand') return api.brands(ctx.category, { signal: ctx.signal }); // 联动查询
    return staticOptions[field];
  },
  toQuery(sel) { return buildQuery(sel); }                    // sel → URL query
};
```
