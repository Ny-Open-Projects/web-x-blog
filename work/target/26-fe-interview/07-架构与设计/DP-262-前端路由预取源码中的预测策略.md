## DP-262：源码识别：路由预取源码中的预测与资源策略？
**答**:
- 观察者：hover/focus/视口进入触发 prefetch（Link 组件的 IntersectionObserver + mouseenter）——"意图信号"观察者。
- 策略：预取什么（route chunk / RSC payload / 数据）、何时（hover 立即 vs 视口立即 vs 空闲）、取消策略（hover 离开 abort）。
- 备忘录：已预取的路由缓存（router cache），重复触发零成本。
- 识别要点：能说出"视口预取的预算控制"（并发上限 + 流量节省模式 network saveData 检测）。

```tsx
// Next Link prefetch 策略（源码心智）
const [inViewport, ref] = useInView();
useEffect(() => {
  if (!prefetch || !inViewport) return;                       // 观察者触发
  if ((navigator as any).connection?.saveData) return;        // 省流策略
  const ac = new AbortController();
  prefetchRoute(href, { signal: ac.signal });                 // 预取 chunk+RSC payload
  return () => ac.abort();                                    // 卸载取消
}, [inViewport, href]);
// hover 立即预取（视口之外的兜底）：
onMouseEnter={() => prefetchRoute(href)}                     // 意图更强的信号
// router cache：prefetchRoute 先查 memo（hasRoute(href)）—— 备忘录去重
```
