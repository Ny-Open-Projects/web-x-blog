## DP-534：笔试：手写操作录制

**答**：实现编辑器的操作录制与回放 `Recorder`：① 录制：start → 拦截所有命令入录制列表（不执行 undo 语义——只记录）→ stop 产出宏；② 回放：宏命令按序 execute（可加速倍率——回放演示）；③ 导出/导入：宏序列化为 JSON（分享操作序列——宏的持久化）；④ 回放的容错：某步执行失败（跳过继续——回放不断）；⑤ 与撤销栈的关系：回放不入撤销栈（回放是演示不是编辑）。写出实现。

```javascript
class Recorder {
  #recording = null;
  start(label) { this.#recording = { label, commands: [], startedAt: Date.now() }; }
  record(cmd) {                                        // history.execute 时顺带录制
    if (this.#recording) this.#recording.commands.push(cmd);
  }
  stop() {
    const macro = new MacroCommand(this.#recording.commands, this.#recording.label);
    const serialized = JSON.stringify(this.#recording.commands.map((c) => c.serialize()));
    this.#recording = null;
    return { macro, serialized };
  }
  async replay(serialized, { speed = 1, onStep } = {}) {
    const commands = JSON.parse(serialized).map(deserializeCommand);
    for (const [i, cmd] of commands.entries()) {
      onStep?.(i, commands.length);
      try { await cmd.execute(); }
      catch (e) { console.warn(`replay skip step ${i}: ${e}`); }   // 容错跳过
      await sleep((cmd.delayMs ?? 300) / speed);
    }
  }
}
// history.execute 与 recorder.record 联动 — 所有编辑操作自动录制
```

**评分点**：
- 录制与 History 的联动（execute 时顺带——不重复实现）
- 宏的序列化/反序列化（分享与持久化）
- 回放容错（单步失败跳过——不断）
- 回放不入撤销栈（演示语义与编辑语义分离）
