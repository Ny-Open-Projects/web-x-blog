## ARC-516：在线表格公式引擎
**答**:
- 组成：公式解析器（tokenizer → parser → AST，支持函数/区间引用/运算优先级）→ 依赖图（单元格引用 DAG）→ 求值器（拓扑序批量重算，环检测循环引用报错）→ 格式化渲染。
- 性能核心：脏标记传播（改 A 只重算依赖链）+ 批量重算（一次编辑收集全部 dirty 一次拓扑求值，ARC-506 同构）；万级公式重算 < 100ms 预算（增量 + 可选 Worker 求值）。
- 语义细节：相对/绝对引用（$A$1，复制填充时引用平移 ARC-499）、跨表引用、函数注册表（可扩展 + 服务端一致性——关键计算服务端复核防端上结果漂移）。
- 协同叠加：公式结果不进协同数据（协同同步公式串，各端各自求值——避免结果不一致时互相覆盖 ARC-379）。
- 错误语义：#REF!/#DIV/0! 等错误值作为单元格值流转（不是异常），错误链传播标记。
```javascript
// 依赖图重算
class FormulaEngine {
  #graph = new DepGraph();                                       // cell -> deps
  setValue(addr, v) { this.#graph.setValue(addr, v); this.#schedule(); }
  #schedule() { queueMicrotask(() => {
    const dirty = this.#graph.collectDirty();                    // 依赖闭包
    for (const cell of topoSort(dirty)) this.#evalCell(cell);    // 一次批量
  }); }
  #evalCell(addr) {
    const ast = parse(this.#graph.formula(addr));
    this.#graph.setValue(addr, evalAst(ast, this.#graph), { isFormula: true, visited: new Set() }); // 环检测
  }
}
```
