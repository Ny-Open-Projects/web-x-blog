## ARC-540：低频高价值功能架构（年度报告类）
**答**:
- 特征：一年用一两次、爆发式流量（同时刻全员访问）、强传播（分享海报）。架构按"活动页"标准设计（ARC-503）而非常规功能。
- 生成链路：数据聚合（服务端预计算——报告数据提前离线算好存快照，访问时只读快照，不做实时聚合 NODE-437 编排预跑）、个人报告懒生成（首次访问触发生成 + 排队 + 生成完成通知，防瞬时算力风暴）。
- 传播设计：分享海报（Canvas 生成 + 个性化参数、防链接伪造签名 ARC-340）、分享回流（他人打开看"公共版"或需登录看个人版）。
- 性能与稳定性：静态化 + CDN（ARC-102）、重资产（视频/动画）按需加载、限流排队（超出容量进虚拟排队页 ARC-107）。
- 数据正确性：报告数字可复核（标注统计口径与时间范围；错数在年度报告场景是公关事故——灰度抽样人工复核 ARC-475）。
```javascript
// 报告懒生成
async function openReport(uid, year) {
  const cached = await api.getReport(uid, year);
  if (cached) return render(cached);
  const { taskId } = await api.requestReport({ uid, year });     // 排队生成
  await pollTask(taskId, { onDone: render, eta: true });         // 进度与预计时间
}
// 预热：大促/年初前对活跃用户预生成（NODE-437 夜间编排）
```
