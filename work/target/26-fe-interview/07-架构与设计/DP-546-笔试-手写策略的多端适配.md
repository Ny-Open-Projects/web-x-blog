## DP-546：笔试：手写多端适配

**答**：实现跨端能力适配层 `Capabilities`：① 抽象工厂：按平台创建服务集（storage/pay/share——Web 用 localStorage/微信用 wx.storage）；② 能力矩阵：每端声明支持的能力（can('subscribe-message') → weapp true / h5 false）——不支持的端「隐藏功能入口」；③ 降级链：某能力多端实现不同（分享：系统分享/Web Share API/复制链接）——降级链逐级尝试；④ 条件编译与运行时检测的双轨（构建期剔除 + 运行时兜底）。写出实现。

```javascript
const PLATFORMS = {
  web: { storage: localStorageAdapter, pay: stripePay, share: webShareOrCopy, caps: ['subscribe'] },
  weapp: { storage: wxStorage, pay: wxPay, share: wxShare, caps: ['subscribe', 'template-msg'] },
};
function createServices(platform) {
  const impls = PLATFORMS[platform];
  if (!impls) throw new Error(`unknown platform: ${platform}`);
  return {
    ...impls,
    can: (cap) => impls.caps.includes(cap),            // 能力矩阵
  };
}
// 降级链: share → navigator.share? webShare : clipboard   — 逐级尝试
// 条件编译: process.env.TARO_ENV === 'weapp' — 构建期剔除死代码
// 运行时兜底: CAPS.share || 隐藏分享按钮 (UI 联动)
```

**评分点**：
- 抽象工厂（平台 → 服务集——调用方不关心端）
- 能力矩阵（can() → UI 功能入口联动）
- 降级链（能力多端实现不同——逐级尝试）
- 条件编译与运行时检测的双轨
