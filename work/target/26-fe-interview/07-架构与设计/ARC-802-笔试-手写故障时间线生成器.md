## ARC-802：笔试：手写故障时间线

**答**：实现故障复盘时间线生成器 `IncidentTimeline`：① 事件记录：`at(time, actor, event, type)`——type: detection/action/impact/resolution；② 时间线生成：按时间排序 + 关键指标计算（MTTD=发现-发生、MTTR=恢复-发现、影响时长）；③ 影响面计算：impact 窗口内的受影响用户数（从监控数据接口拉取）；④ markdown 复盘报告生成：时间线表格 + 指标汇总 + action items 区；⑤ 与告警系统对接：告警事件自动注入时间线（去重）。写出实现。

```javascript
class IncidentTimeline {
  #events = []; #startAt;
  constructor(incidentStart) { this.#startAt = incidentStart; }
  at(time, actor, event, type = 'action') {
    this.#events.push({ time: new Date(time), actor, event, type });
    return this;
  }
  metrics(now = Date.now()) {
    const detected = this.#events.find((e) => e.type === 'detection');
    const resolved = this.#events.find((e) => e.type === 'resolution');
    const mttd = detected ? (detected.time - this.#startAt) / 1000 : null;
    const mttr = resolved ? (resolved.time - detected.time) / 1000 : null;
    const impactDuration = ((resolved?.time ?? now) - this.#startAt) / 1000;
    return { mttd, mttr, impactDuration: Math.round(impactDuration) };
  }
  toReport(affectedUsers) {
    const m = this.metrics();
    const rows = [...this.#events].sort((a, b) => a.time - b.time)
      .map((e) => `| ${e.time.toISOString()} | ${e.actor} | ${e.type} | ${e.event} |`).join('\n');
    return `# 故障复盘\n\n**MTTD**: ${m.mttd}s | **MTTR**: ${m.mttr}s | **影响时长**: ${m.impactDuration}s | **影响用户**: ${affectedUsers}\n\n| 时间 | 角色 | 类型 | 事件 |\n|---|---|---|---|\n${rows}\n\n## Action Items\n- [ ] ...`;
  }
}
```

**评分点**：
- 四类事件类型（detection/action/impact/resolution）
- MTTD/MTTR/影响时长的精确计算
- markdown 复盘报告（时间线表格 + action items）
- 告警自动注入的去重对接
