## ARC-850：手写架构周报

**答**：实现架构周报自动生成器 `ArchWeeklyReport`：① 数据源接入：CI 统计（发布次数/成功率）、监控（错误率趋势）、巡检（ArchBot 结果）、迁移进度、债务变化——五源聚合；② 周报结构：本周要点（Top3 变化）、指标速览（核心指标周环比）、风险与待办（未闭环项）、下周计划；③ 变化检测：与上周数据的显著变化检测（错误率突变/新债务登记——自动提取要点）；④ 收件人分级：全员版（要点）/架构版（完整数据）——两版生成；⑤ 生成器自身的可靠性：数据源缺失的降级（某源不可用标注「数据缺失」而非静默跳过）。写出实现。

```javascript
class ArchWeeklyReport {
  #sources = new Map();   // name -> fetcher
  registerSource(name, fetcher) { this.#sources.set(name, fetcher); }

  async generate(prevReport) {
    const data = {};
    const missing = [];
    for (const [name, fetcher] of this.#sources) {
      try { data[name] = await fetcher(); }
      catch { missing.push(name); data[name] = null; }   // 降级: 标注缺失
    }
    const highlights = [];
    // 显著变化检测: 错误率突变
    if (prevReport?.metrics && data.metrics) {
      const dr = data.metrics.errorRate - prevReport.metrics.errorRate;
      if (Math.abs(dr) > 0.002) highlights.push(`错误率${dr > 0 ? '上升' : '下降'} ${(Math.abs(dr) * 100).toFixed(2)}%`);
    }
    if (data.debts?.newCount) highlights.push(`新增技术债 ${data.debts.newCount} 笔`);
    if (data.releases?.failed) highlights.push(`发布失败 ${data.releases.failed} 次`);
    const openActions = data.migration?.pending ?? [];
    return {
      allHands: `本周要点:\n${highlights.map((h) => `- ${h}`).join('\n') || '- 平稳'}`,
      archVersion: { data, missing, openActions },
      markdown: this.#render({ highlights, data, missing, prevReport }),
    };
  }
  #render({ highlights, data, missing, prevReport }) {
    const sections = [`# 架构周报 ${new Date().toISOString().slice(0, 10)}`];
    sections.push(`## 要点\n${highlights.map((h) => `- ${h}`).join('\n')}`);
    sections.push(`## 指标环比\n${Object.entries(data.metrics ?? {}).map(([k, v]) => `${k}: ${v} (上周 ${prevReport?.metrics?.[k] ?? '-'})`).join('\n')}`);
    if (missing.length) sections.push(`## ⚠️ 数据缺失\n${missing.join(', ')} — 数据源不可用`);
    sections.push(`## 待办\n${(data.migration?.pending ?? []).map((t) => `- [ ] ${t}`).join('\n')}`);
    return sections.join('\n\n');
  }
}
```

**评分点**：
- 五源聚合的注册制（数据源可插拔）
- 显著变化检测（阈值提取要点——非流水账）
- 双版生成（全员要点 / 架构完整——受众分层）
- 数据缺失的诚实降级（标注而非静默——报告可信度）
