## ARC-795：笔试：手写迁移清单生成器

**答**：实现迁移点扫描器 `scanMigration(srcDir, patterns)`：① 扫描源码中所有「需要迁移的点」（老 API 调用/弃用模式）——正则 + AST 双模式；② 生成清单：{ file, line, snippet, category, owner(按目录归属映射), effort(估算人日: 简单0.5/中等1/复杂2) }；③ 工作量汇总：按 owner/按 category 统计——迁移排期的输入；④ 进度追踪：清单 JSON 持久化 + `markDone(file,line)` + 完成率报表；⑤ 增量模式：git diff 范围内只扫新变更（避免全量重扫）。写出实现。

```javascript
function scanMigration(srcDir, patterns, ownerMap) {
  const items = [];
  for (const file of collectFiles(srcDir, '.js', '.vue', '.ts')) {
    const lines = fs.readFileSync(file, 'utf8').split('\n');
    lines.forEach((line, i) => {
      for (const p of patterns) {
        if (p.regex.test(line)) {
          items.push({
            file, line: i + 1, snippet: line.trim().slice(0, 80),
            category: p.category,
            owner: ownerMap.find((m) => file.startsWith(m.dir))?.owner ?? 'unknown',
            effort: p.complexity(line) > 5 ? 2 : p.complexity(line) > 2 ? 1 : 0.5,
            done: false,
          });
        }
      }
    });
  }
  fs.writeFileSync('migration-plan.json', JSON.stringify(items, null, 2));
  return summarize(items);
}
function summarize(items) {
  const byOwner = {}, byCategory = {};
  for (const it of items) {
    byOwner[it.owner] = (byOwner[it.owner] ?? 0) + it.effort;
    byCategory[it.category] = (byCategory[it.category] ?? 0) + 1;
  }
  const totalEffort = Object.values(byOwner).reduce((a, b) => a + b, 0);
  return { total: items.length, totalEffort, byOwner, byCategory,
    eta: `${Math.ceil(totalEffort / 2)} 人周 (按 2 人日/人周吞吐)` };
}
// patterns 示例: [
//   { regex: /\$listeners/, category: 'vue2-listeners', complexity: (l) => l.length / 20 },
//   { regex: /new Vue\(/, category: 'global-api', complexity: () => 1 },
// ]
```

**评分点**：
- owner 映射（按目录归属——工作量到团队）
- effort 三档估算规则（复杂度函数可配）
- 持久化清单 + markDone 进度追踪（迁移看板数据源）
- 汇总的排期输出（人周 ETA）
