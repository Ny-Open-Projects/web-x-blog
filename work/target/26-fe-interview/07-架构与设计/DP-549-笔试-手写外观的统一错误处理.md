## DP-549：笔试：手写错误处理门面

**答**：实现统一错误处理门面 `ErrorHandler`：① 错误分类：网络错误/业务错误/权限错误/未知——分类驱动处置；② 分级处置：致命（全页错误屏）/可恢复（降级+重试）/可忽略（记录）；③ 用户语义翻译：技术错误到用户文案（错误码 → 文案映射表——「E1002」→「库存不足」）；④ 上报与展示的分离：全部上报（监控）+ 按级别展示（toast/错误页）；⑤ 重试的携带：可恢复错误带 retry 回调（错误对象可行动）。写出实现。

```javascript
class ErrorHandler {
  #translations = new Map([['E1002', '库存不足，请刷新后重试'], ['E1003', '请先登录']]);
  handle(err, { retry } = {}) {
    const kind = this.#classify(err);                  // 分类
    this.report(err, kind);                            // 全部上报
    const userMsg = this.#translations.get(err.code) ?? '出了点问题，请稍后重试';   // 语义翻译
    switch (kind) {
      case 'fatal': renderErrorPage(err); break;       // 致命: 错误屏
      case 'recoverable': toast(userMsg, { action: retry ? '重试' : null, onAction: retry }); break;
      case 'ignorable': /* 只记录不展示 */ break;
    }
    return { handled: true, kind, userMsg };
  }
  #classify(err) {
    if (err.network) return 'recoverable';
    if (err.status === 401 || err.status === 403) return 'fatal';
    if (err.code && err.recoverable) return 'recoverable';
    return 'fatal';
  }
}
```

**评分点**：
- 分类驱动处置（致命/可恢复/可忽略——分级）
- 语义翻译映射表（错误码 → 用户文案）
- 上报与展示分离（监控全量 + UI 按级别）
- retry 携带（错误对象可行动）
