## ARC-601：表格虚拟化键盘导航
**答**:
- 难点：虚拟化下 DOM 行按需存在（ARC-442），键盘焦点移动到未渲染行时——必须先确保该行渲染（滚动定位 → 渲染 → 焦点落位，三步时序）。
- 导航模型：焦点逻辑网格（(row,col) 逻辑坐标独立于 DOM——ARC-499 焦点模型），方向键改逻辑坐标 → 视口校正（目标行不可见 → scrollTo 行）→ 渲染完成后 focus 对应单元格（渲染是异步的——等渲染 commit 再 focus）。
- 滚动与焦点协同：方向键滚动幅度（每行精确高度——高度缓存 ARC-442）、PageUp/PageDown（按视口行数）、Home/End（行首行尾/表头跳转）、Ctrl+Home（表格顶部）。
- 可达性：表格语义（role=grid/row/gridcell）、当前单元格 aria 标注（行列坐标读出）、选中范围与焦点分离（Shift+方向扩展选区——焦点单格选区多格 ARC-499）。
- 与快捷键体系协同：表格内快捷键（复制/删除）注册在表格作用域（ARC-498 作用域栈）。
```javascript
function moveFocus(dr, dc) {
  const next = clamp(grid.focus + [dr, dc]);
  if (!virtual.isRendered(next.row)) {                            // 未渲染行
    virtual.scrollToRow(next.row);                                // 先滚动
    requestAnimationFrame(() => focusCell(next));                 // 渲染后落焦
  } else focusCell(next);
}
// roving tabindex：容器单 tab 进入，内部方向键移动（arc 元素 tabindex 动态 -1/0）
```
