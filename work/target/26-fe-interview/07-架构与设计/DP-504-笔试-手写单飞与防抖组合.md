## DP-504：笔试：手写 singleflight

**答**：实现 singleflight（并发去重）：① `singleflight(key, fn)`：同 key 并发调用共享同一 Promise（第一个执行，其余等待复用结果）；② 失败不共享（reject 后清除——可重试）；③ 完成后短 TTL 缓存（5s 内同 key 直接返回结果）；④ 统计（合并了多少调用——去重收益）；⑤ 与防抖的区别说明（singleflight 合并「在途」，防抖合并「到达」）。写出实现。

```javascript
const inflight = new Map();
const cache = new Map();
const stats = { merged: 0 };

function singleflight(key, fn, { ttl = 5000 } = {}) {
  const cached = cache.get(key);
  if (cached && Date.now() - cached.t < ttl) return Promise.resolve(cached.v);
  if (inflight.has(key)) { stats.merged++; return inflight.get(key); }   // 合并在途
  const p = Promise.resolve()
    .then(fn)
    .then((v) => { cache.set(key, { v, t: Date.now() }); return v; })
    .finally(() => inflight.delete(key));              // 失败/完成都清除 (可重试)
  inflight.set(key, p);
  return p;
}
// 并发: singleflight('user:1', loadUser) × N → 1 次执行
// 区别: 防抖 = 到达侧合并 (等停); singleflight = 在途侧合并 (执行中共享)
```

**评分点**：
- in-flight Map 复用（第一个执行共享结果）
- 失败清除（可重试——reject 不缓存）
- 短 TTL 结果缓存（二次去重）
- 与防抖的语义区别清晰（到达合并 vs 在途合并）
