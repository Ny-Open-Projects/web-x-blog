## DP-241：源码识别：视频播放器源码中的状态机与策略？
**答**:
- 状态模式（核心）：播放器是复杂状态机 idle → loading → ready → playing → paused → buffering → error，转移动作集中定义（DP-192 微内核插件的宿主状态）。
- 策略：码率切换策略（ABR：按带宽/缓冲水位选档）、清晰度切换、降级策略（HLS → MP4 直接播）都可注入。
- 观察者：媒体事件（timeupdate/ended/waiting）→ 播放器事件总线 → UI 组件订阅（进度条/控制条）。
- 识别要点：buffering 的进入/退出条件（buffer ahead < X 进入、> Y 退出）是状态机核心逻辑；自动播放被浏览器拦截（play() reject）是常见转移分支。

```javascript
// 播放器状态机（源码级简化）
const transitions = {
  idle:    { load: 'loading' },
  loading: { loaded: 'ready', error: 'error' },
  ready:   { play: 'playing' },
  playing: { pause: 'paused', waiting: 'buffering', ended: 'idle' },
  buffering: { canplay: 'playing', error: 'error' },
  error:   { retry: 'loading' },
};
class Player {
  state = 'idle';
  dispatch(event) {
    const next = transitions[this.state][event];
    if (!next) return warn(`事件 ${event} 在 ${this.state} 态非法`);
    const prev = this.state; this.state = next;
    this.emitter.emit('statechange', next, prev);   // 观察者广播
    if (next === 'buffering') this.abr.downgrade(); // 策略联动：缓冲不足降档
  }
}
// video.addEventListener('waiting', () => player.dispatch('waiting'));
// 自动播放拦截：video.play().catch(() => { player.dispatch('pause'); showUnmuteButton(); })
```
