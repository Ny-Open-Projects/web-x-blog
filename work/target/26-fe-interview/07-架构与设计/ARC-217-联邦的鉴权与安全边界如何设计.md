## ARC-217：联邦的鉴权与安全边界如何设计？
**答**：
- 信任模型：联邦是**强信任**集成（同运行时执行代码），只应用于同公司/同信任域应用；跨公司绝不用联邦（用 iframe 或独立站点）。
- 供应链安全：CDN 产物签名/SRI 校验、manifest 域名白名单、CSP script-src 收敛到联邦 CDN 域（ARC-071 安全清单）；产物构建流水线加依赖审计。
- 运行时鉴权：用户权限传给子应用走"最小上下文"——只传权限码集合（见 ARC-068/221），不传原始 token；子应用内部按钮级权限复用主应用的 RBAC 指令。
- 审计：expose 模块被哪些主应用/哪些页面加载，平台留痕（snapshot + runtime 上报），安全事件可回溯。

```javascript
// 主应用：给子应用注入权限上下文（最小化）
const permCtx = { perms: user.permCodes, locale: user.locale };  // 不传 token
const Header = await loadRemote('shop/Header', { permCtx });      // 经运行时透传
// 子应用 expose 侧：import { requirePerm } from '@mf/auth'; // 复用主应用单例
export default function Header({ permCtx }) {
  const canEdit = requirePerm(permCtx, 'order:edit');             // 按钮级权限判定
  return <div>{canEdit && <EditBtn/>}</div>;
}
// CSP 示例：script-src 'self' https://mf-cdn.example.com; manifest 域名走 connect-src 白名单
```
