## DP-514：笔试：手写预加载调度器

**答**：实现空闲期预加载调度器 `PrefetchScheduler`：① 任务注册：{ task, priority, expiresAt }——按优先级排序 + 过期丢弃；② 空闲驱动：requestIdleCallback 逐任务执行（每次 idle 只做一件事——不阻塞）；③ 并发与带宽预算：同时在途 ≤2（网络维度——空闲期也不抢带宽）；④ 用户交互让路：isInputPending 检测（输入待处理 → 立即让出）；⑤ 命中率度量：预取后实际访问统计（<30% = 纯浪费——策略调优依据）。写出实现。

```javascript
class PrefetchScheduler {
  #queue = []; #running = 0; #maxInFlight = 2;
  #hits = 0; #prefetched = 0;
  add(task, { priority = 0, expiresAt = Date.now() + 60_000 } = {}) {
    this.#queue.push({ task, priority, expiresAt });
    this.#queue.sort((a, b) => b.priority - a.priority);
    this.#pump();
  }
  async #pump() {
    while (this.#running < this.#maxInFlight && this.#queue.length) {
      const t = this.#queue.shift();
      if (t.expiresAt < Date.now()) continue;          // 过期丢弃
      if (navigator.scheduling?.isInputPending?.()) {   // 输入让路
        this.#queue.unshift(t); break;
      }
      this.#running++;
      requestIdleCallback(async (deadline) => {
        try { await t.task(); this.#prefetched++; }
        catch {}
        this.#running--;
        this.#pump();
      }, { timeout: 2000 });
    }
  }
  trackNavigation(key) {                                // 预取命中: 访问的是预取过的
    this.#hits++;
  }
  get hitRate() { return this.#prefetched ? +(this.#hits / this.#prefetched * 100).toFixed(0) + '%' : 'N/A'; }
}
```

**评分点**：
- 空闲驱动 + 输入让路（isInputPending——预取不抢交互）
- 带宽预算（在途 ≤2——空闲期也不抢网络）
- 过期丢弃（预取的时效性）
- 命中率度量（<30% 调优策略——数据驱动）
