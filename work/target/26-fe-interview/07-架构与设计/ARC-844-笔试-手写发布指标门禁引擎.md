## ARC-844：手写门禁引擎

**答**：实现发布指标门禁引擎 `GateEngine`：① 门禁声明：Declarative 规则（{ metric: 'errorRate', op: '<', threshold: 0.01, window: '5m', scope: 'canary' }——声明式可配）；② 引擎执行：灰度期间定时拉取指标 → 规则评估 → 全部 pass 才允许 promote；③ 条件组合：AND/OR 组合（errorRate<1% AND lcp<2.5s）；④ 指标源适配：多指标源（PromQL/Sentry/自建）——adapter 注册；⑤ 判定结果：pass/fail + 每规则明细（失败规则的原因——可读报告）；⑥ 规则热更新：门禁规则从配置中心加载（阈值调整不发版）。写出实现。

```javascript
class GateEngine {
  #rules = []; #adapters = new Map();
  loadRules(rules) { this.#rules = rules; }            // 热更新: 配置中心
  registerAdapter(source, fetcher) { this.#adapters.set(source, fetcher); }

  async evaluate(appId) {
    const results = [];
    let allPass = true;
    for (const rule of this.#rules) {
      const fetcher = this.#adapters.get(rule.source);
      if (!fetcher) throw new Error(`no adapter for ${rule.source}`);
      const value = await fetcher(rule.metric, rule.window, appId);
      const pass = rule.compose
        ? rule.compose(value)                          // 自定义组合
        : rule.op === '<' ? value < rule.threshold
        : rule.op === '<=' ? value <= rule.threshold : value > rule.threshold;
      results.push({ metric: rule.metric, value, threshold: rule.threshold, pass });
      if (!pass) allPass = false;
    }
    return {
      pass: allPass,
      report: results.map((r) => `${r.pass ? '✓' : '✗'} ${r.metric}: ${r.value} (阈值 ${r.threshold})`).join('\n'),
    };
  }
}
// 规则配置(配置中心):
// [
//   { metric: 'error_rate', op: '<', threshold: 0.01, window: '5m', source: 'prom' },
//   { metric: 'lcp_p75', op: '<', threshold: 2500, window: '1h', source: 'internal' },
//   { metric: 'crash_free', op: '>', threshold: 0.995, window: '24h', source: 'sentry' },
// ]
// 用法: const { pass, report } = await engine.evaluate('shop-app'); pass && promote();
```

**评分点**：
- 声明式规则（配置中心热更新——阈值调整不发版）
- 多指标源适配器注册
- 可读判定报告（每规则明细——人工可审计）
- AND 组合（全 pass 才 promote——语义正确）
