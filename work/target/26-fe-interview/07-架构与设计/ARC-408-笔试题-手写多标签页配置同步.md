## ARC-408：笔试题：手写多标签页配置同步
**答**：实现 ConfigSync：1) 配置变更通过 BroadcastChannel 广播到同源其它标签页；2) 各页按 version 判断新旧（只接受更高版本）；3) 断线（无 BC 支持）降级 storage 事件；4) 提供同步完成回调（用于 UI 提示刷新）。
**评分点**：
- BroadcastChannel 消息含 version，接收端版本比较防旧覆盖新。
- storage 事件降级路径正确（key 前缀监听）。
- 不直接覆盖本地未持久化状态（变更通知而非强刷）。
- 清理与重连（visibilitychange 时主动拉一次最新配置）。
```javascript
class ConfigSync {
  #bc = 'BroadcastChannel' in window ? new BroadcastChannel('cfg') : null;
  #version = 0;
  constructor(private store: Store, private onSynced: (v: number) => void) {
    if (this.#bc) this.#bc.onmessage = ({ data }) => this.#accept(data);
    addEventListener('storage', (e) => {
      if (e.key === 'cfg:latest' && e.newValue) this.#accept(JSON.parse(e.newValue));
    });
    document.addEventListener('visibilitychange', () => {     // 回前台对齐
      if (!document.hidden) this.store.refresh().then(c => this.#accept(c));
    });
  }
  publish(cfg) {
    this.#version = cfg.version;
    localStorage.setItem('cfg:latest', JSON.stringify(cfg));  // 降级通道写
    this.#bc?.postMessage(cfg);
  }
  #accept(cfg) {
    if (cfg.version <= this.#version) return;                 // 只接受更高版本
    this.#version = cfg.version;
    this.store.apply(cfg);
    this.onSynced(cfg.version);
  }
}
```
