## DP-502：笔试：手写互斥锁

**答**：实现前端互斥锁 `Mutex`：① acquire(key)：独占持有（同 key 可重入——嵌套调用计数）；② release(key)：计数归零才真释放；③ 超时释放（租约——持有者异常时 30s 自动放行，防死锁）；④ 队列：非持有者 FIFO 等待；⑤ finally 保证释放（示例展示正确的 acquire/release 配对）。写出实现。

```javascript
class Mutex {
  #owner = null; #count = 0; #queue = []; #lease = null;
  async acquire(key, { leaseMs = 30_000 } = {}) {
    if (this.#owner === key) { this.#count++; return; }   // 可重入
    while (this.#owner) await new Promise((r) => this.#queue.push(r));
    this.#owner = key; this.#count = 1;
    this.#lease = setTimeout(() => {                      // 租约: 防死锁
      this.#owner = null;
      const next = this.#queue.shift();
      next?.();
    }, leaseMs);
  }
  release(key) {
    if (this.#owner !== key) throw new Error('not owner');
    clearTimeout(this.#lease);
    if (--this.#count > 0) return;                        // 嵌套未退完
    this.#owner = null;
    this.#queue.shift()?.();
  }
  async run(key, fn, opts) {                              // 推荐用法: 自动配对
    await this.acquire(key, opts);
    try { return await fn(); } finally { this.release(key); }   // finally 保证释放
  }
}
// 正确: mutex.run('token', refreshToken)  — acquire/release 由 run 包裹
// 错误: await acquire(); 忘记 release → 死锁 (租约超时兜底)
```

**评分点**：
- 可重入计数语义（同 key 计数、归零释放）
- 租约超时释放（防持有者异常死锁）
- FIFO 等待队列
- run() 的 finally 自动配对（推荐用法优于裸 acquire/release）
