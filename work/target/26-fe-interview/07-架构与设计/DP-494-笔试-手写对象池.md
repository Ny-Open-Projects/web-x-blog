## DP-494：笔试：手写对象池

**答**：实现对象池 `ObjectPool`：① acquire：空闲池取（reset 清理）→ 容量内新建 → 满则排队等待归还；② release：归还并唤醒等待者（直接转交——不经过空闲池减少竞争）；③ reset 钩子：复用前清理状态（脏数据防护）；④ destroy 语义：归还时按条件销毁（超龄对象——不归还）；⑤ 统计：inUse/idle/queued。写出实现。

```javascript
class ObjectPool {
  #idle = []; #waiters = []; #inUse = 0;
  constructor(factory, { max = 10, reset, maxAge = Infinity } = {}) {
    Object.assign(this, { factory, max, reset, maxAge });
    this.stats = { inUse: 0, idle: 0, queued: 0 };
  }
  async acquire() {
    if (this.#idle.length) {
      const obj = this.#idle.pop();
      this.reset?.(obj);                               // 复用前清理
      this.#inUse++;
      return obj;
    }
    if (this.#inUse + this.#idle.length < this.max) { this.#inUse++; return this.factory(); }
    return new Promise((resolve) => this.#waiters.push(resolve));   // 排队
  }
  release(obj, age) {
    this.#inUse--;
    if (age > this.maxAge) return;                     // 超龄销毁
    const w = this.#waiters.shift();
    if (w) { this.reset?.(obj); w(obj); this.#inUse++; }   // 直转等待者
    else this.#idle.push(obj);
  }
}
// 用法: 大 ArrayBuffer / 图片解码实例 / Worker — 内存恒定的复用
```

**评分点**：
- acquire 三分支（复用 reset/新建/排队）
- release 直转等待者（绕过 idle——减少竞争）
- reset 清理（脏数据防护——复用的安全前提）
- 超龄销毁 + 统计可观测
