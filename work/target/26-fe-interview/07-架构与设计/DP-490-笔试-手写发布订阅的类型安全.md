## DP-490：笔试：类型安全事件总线

**答**：实现 TypeScript 类型安全的事件总线：① 事件 map 类型：{ 'cart:add': { sku: string }, 'cart:clear': void }——事件名 → payload 类型映射；② on/emit 的类型约束：on('cart:add', (p: { sku: string }) => ...)——事件名与 payload 类型联动（emit 传错类型编译报错）；③ 泛型实现：EventBus<T extends Record<string, any>>；④ off 的类型推导；⑤ 用 keyof 派发（事件名的自动补全）。写出实现。

```typescript
type EventMap = {
  'cart:add': { sku: string; qty: number };
  'cart:clear': undefined;
  'order:paid': { orderId: string };
};

class TypedBus<T extends Record<string, any>> {
  #subs = new Map<keyof T, Set<(p: any) => void>>();
  on<K extends keyof T>(type: K, fn: (payload: T[K]) => void) {
    const set = this.#subs.get(type) ?? this.#subs.set(type, new Set()).get(type)!;
    set.add(fn);
    return () => set.delete(fn);
  }
  emit<K extends keyof T>(type: K, payload: T[K]) {
    this.#subs.get(type)?.forEach((fn) => fn(payload));
  }
}
const bus = new TypedBus<EventMap>();
bus.on('cart:add', (p) => console.log(p.sku));       // p 自动推导 { sku, qty }
bus.emit('cart:add', { sku: 'a', qty: 1 });          // ✓
// bus.emit('cart:add', { sku: 123 });               // ✗ 编译报错: 类型不匹配
// bus.on('cart:add', (p) => p.unknown);             // ✗ 编译报错
```

**评分点**：
- 泛型映射（事件名 → payload 类型的编译期约束）
- keyof 约束（事件名自动补全 + 拼错编译报错）
- off 的退订与类型保持
- 运行时与类型层的双重安全说明
