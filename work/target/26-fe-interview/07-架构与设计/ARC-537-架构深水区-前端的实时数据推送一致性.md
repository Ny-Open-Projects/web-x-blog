## ARC-537：实时数据推送一致性
**答**:
- 一致性三问题：乱序（推送 seq + 版本号，旧版本丢弃）、丢包（WS gap 检测补拉 ARC-416）、闪烁（高频更新节流合帧 + 值变化动画缓冲——数字滚动而非跳变）。
- 快照与增量协议：连接建立先发快照（当前全量）→ 后续增量（diff 补丁）；重连 = 快照重置（比追增量简单可靠，数据量小时优先）。
- 展示一致性：同一数据多组件消费（行情价在列表和详情同时显示）——单一 store 订阅（ARC-467 owner 原则），时间戳标注（显示数据时间，陈旧数据明显标注而非静默旧值）。
- 性能：高频推送合帧（rAF 内合并渲染，ARC-443 帧调度）、不可见时暂停订阅（页面隐藏 unsubscrib，回前台重新快照）。
- 降级：推送链路挂 → 降级轮询（间隔自适应）+ 明确的"实时性降级"标识。
```javascript
class LiveFeed {
  #store = createStore({ data: null, ts: 0, seq: 0, stale: false });
  onMsg({ seq, patch }) {
    if (seq <= this.#store.get().seq) return;                    // 乱序丢弃
    this.#store.patch({ ...patch, seq, ts: Date.now() });
  }
  render = raf(() => {                                            // 合帧
    const s = this.#store.get();
    ui.update(s.data, { stale: Date.now() - s.ts > 5000 });       // 陈旧标注
  });
}
```
