## ARC-553：前端多环境矩阵管理
**答**:
- 环境矩阵：域名映射（dev/test/staging/prod 的前端域名与 API 网关对应）、数据源路由（各环境连接的数据/配置/推送通道）、开关差异（各环境默认开关不同——debug 工具仅非生产）。
- 架构收口：环境由"部署时注入"（构建/网关注入 ENV 标识）而非本地判断（window.location 猜环境是反模式——一个域名多环境共存时失效）；环境清单 schema 化（新环境加入走配置，不散写 if）。
- 跨环境工具：环境切换器（开发期 cookie/参数覆盖数据源指向——仅 dev 构建）、环境角标（页面显示当前环境 + 版本，防"测了半天在错环境" ARC-429）、链路对齐（前端环境 ↔ BFF 环境 ↔ 下游环境的映射表自动校验，ARC-415 多端一致性配合）。
- 防串环境：生产代码防御性校验（ENV=prod 时禁用调试接口/禁用测试域名请求——构建期删除 debug 代码 + 运行时兜底）。
- 演练：环境矩阵变更演练（加新环境/迁移域名的 checklist 与回归清单）。
```javascript
// 环境清单 schema
const envMatrix = {
  dev:    { api: 'https://gateway-dev.example.com', features: { debug: true } },
  prod:   { api: 'https://gateway.example.com', features: { debug: false } }
};
const env = window.__ENV__;                                      // 部署注入，非本地判断
export const apiBase = envMatrix[env].api;
if (env === 'prod') stripDebug();                                // 防串环境
```
