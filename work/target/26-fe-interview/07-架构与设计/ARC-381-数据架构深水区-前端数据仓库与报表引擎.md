## ARC-381：数据报表/BI 前端架构如何设计？
**答**：
- 分层：图表渲染层（ECharts/AntV 封装统一 API）→ 组件层（维度/指标选择器、筛选联动）→ 报表引擎（布局 schema、联动协议、下钻定义）→ 数据层（查询 DSL、缓存、分页）。
- 布局 schema：栅格 + 组件类型 + 数据绑定 + 联动规则，存 JSON；渲染器递归生成，与低代码引擎同构（ARC-091）。
- 联动协议：组件间通过"筛选上下文"通信（点击图表 A 的分类 → 更新全局 filter → 图表 B/C 重新查询），用全局 filter store 而不是组件间直连。
- 性能：大数据量图表降采样（LTTB）、服务端聚合代替前端算、图表实例懒创建与销毁（页面组件多时内存爆炸）；导出走服务端（前端截图大数据会崩）。
- 一致性：同指标多图表口径唯一（指标字典接口）、时间粒度与时区统一处理。
```javascript
// 报表联动：全局筛选上下文
const filterStore = createStore({ region: null, dateRange: defaultRange() });
chartA.onClick(params => filterStore.set({ region: params.name }));  // 点击联动
autorun(() => {
  const q = buildQuery(filterStore.get());          // 所有图表共享同一 filter
  chartB.query(q); chartC.query(q);
});
```
