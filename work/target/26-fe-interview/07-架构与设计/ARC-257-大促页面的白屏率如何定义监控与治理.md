## ARC-257：大促页面的白屏率如何定义、监控与治理？
**答**：
- 定义要可计算：白屏 = 首屏关键容器（约定 selector 列表）在 N 秒内"无有效内容"（DOM 为空/高度为 0/纯 loading）。采样上报判定结果与截图缩略图（低频采样控制成本）。
- 监控链路：SDK 在 onload+2s 检查 → 上报白屏事件（带资源加载明细）→ 实时聚合白屏率分桶（机型/地区/版本）→ 突增告警（阈值用大促基线，非日常基线）。
- 治理手段：根因分布治理——资源加载失败（CDN/网络）走重试+备用 CDN；JS 执行错误走错误边界；数据异常走骨架+局部重试；慢用户走更早的骨架与并行化。
- 大促专项：白屏率按小时环比告警 + 自动关联发布（最近变更白屏率对比），快速定位新版本引入。

```typescript
// 白屏探针（简化）
function checkWhiteScreen(selectors: string[], timeout = 2000) {
  setTimeout(() => {
    const empty = selectors.every(s => {
      const el = document.querySelector(s);
      return !el || el.offsetHeight < 5 || el.children.length === 0;
    });
    if (empty) report('white-screen', { url: location.href, resources: perf.resourceEntries() });
  }, timeout);
}
// 大盘 SQL 思路：white_rate = count(white-screen) / count(pv) group by hour, os, region
// 突增告警：rate > baseline * 3 && abs(count) > 50 → P0 呼叫值班
```
