## DP-343：笔试题：手写请求队列（并发上限+优先级）？
**题目**：实现 RequestPool：1) 并发上限 N；2) 任务带优先级（高优先先出队）；3) 超时（任务执行超时 reject）；4) 动态调整上限（弱网减半）。
**评分点**：
- 并发控制正确（running 计数 + 完成触发下一个）。
- 优先级出队稳定。
- 超时与任务竞速（Promise.race + 计时清理）。
- 上限调整即时生效（下次调度）。
```javascript
class RequestPool {
  #queue = []; #running = 0;
  constructor(private limit = 6) {}
  setLimit(n) { this.limit = n; this.#drain(); }               // 4)
  push(fn, { priority = 0, timeout = 10000 } = {}) {
    return new Promise((resolve, reject) => {
      this.#queue.push({ fn, priority, timeout, resolve, reject, seq: ++RequestPool.seq });
      this.#queue.sort((a, b) => b.priority - a.priority || a.seq - b.seq);   // 2) 稳定排序
      this.#drain();
    });
  }
  #drain() {                                                    // 1) 并发控制
    while (this.#running < this.limit && this.#queue.length) {
      const t = this.#queue.shift();
      this.#running++;
      const timer = setTimeout(() => t.reject(new TimeoutError()), t.timeout);   // 3) 超时竞速
      Promise.race([t.fn(), new Promise((_, rej) => timer)])  
        .then(t.resolve, t.reject)
        .finally(() => { clearTimeout(timer); this.#running--; this.#drain(); });
    }
  }
}
RequestPool.seq = 0;
```
