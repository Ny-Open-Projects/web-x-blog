## ARC-402：笔试题：手写插件系统
**答**：实现 PluginSystem：1) use(plugin) 注册插件，插件声明钩子函数；2) applyHook(name, ctx) 串行执行各插件该钩子，后插件可见前插件的 ctx 修改；3) tapParallel 并行版；4) 单插件抛错不阻断其它插件，收集错误返回。
**评分点**：
- 串行钩子用 await 顺序执行，ctx 引用传递保证可修改。
- 并行版 Promise.allSettled 而非 all。
- 错误隔离：单插件异常收集进 errors 数组。
- 钩子不存在时静默返回，注册顺序即执行顺序。
```javascript
class PluginSystem {
  #plugins = [];
  use(plugin) { this.#plugins.push(plugin); return this; }
  async applyHook(name, ctx) {
    const errors = [];
    for (const p of this.#plugins) {
      if (typeof p[name] !== 'function') continue;
      try { await p[name](ctx); }               // 串行：后插件可见前插件改动
      catch (e) { errors.push({ plugin: p.name, error: e }); }
    }
    return { ctx, errors };
  }
  async tapParallel(name, ctx) {
    const results = await Promise.allSettled(
      this.#plugins.filter(p => typeof p[name] === 'function').map(p => p[name](ctx)));
    return { ctx, errors: results.filter(r => r.status === 'rejected').map(r => r.reason) };
  }
}
const ps = new PluginSystem();
ps.use({ name: 'a', init: (c) => { c.step = 1; } });
ps.use({ name: 'b', init: (c) => { c.step++; }, fail: () => { throw new Error('boom'); } });
ps.applyHook('init', {}).then(({ ctx }) => console.log(ctx.step)); // 2
```
