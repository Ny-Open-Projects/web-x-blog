## ARC-832：手写演进时间线

**答**：实现架构演进的「时间线 + 影响分析」工具 `EvolutionTimeline`：① 事件记录：{ date, type(milestone/refactor/incident/decision), title, adrRef, metrics: { before, after } }——事件带指标对比；② 时间线视图：按时间排列 + 里程碑高亮；③ 指标趋势关联：事件时间线与核心指标曲线叠加（重构事件 → LCP 曲线变化——因果关系可视化）；④ 影响分析：某事件后的指标变化区间计算（事件前 30 天 vs 后 30 天的中位数对比）；⑤ 输出：演进叙事（时间线+指标变化→自动生成演进故事——用于晋升述职/团队回顾）。写出实现。

```javascript
class EvolutionTimeline {
  #events = [];
  add({ date, type, title, adrRef, metrics }) {
    this.#events.push({ date: new Date(date), type, title, adrRef, metrics });
    return this;
  }
  async impactAnalysis(eventId, metricsApi) {
    const e = this.#events.find((x) => x.id === eventId);
    if (!e) throw new Error('unknown event');
    const before = await metricsApi.query({ from: e.date - 30 * 86400e3, to: e.date, metric: e.metrics?.key });
    const after = await metricsApi.query({ from: e.date, to: e.date + 30 * 86400e3, metric: e.metrics?.key });
    const b = median(before.values), a = median(after.values);
    return { event: e.title, before: b, after: a,
      change: +(((a - b) / b) * 100).toFixed(1) + '%',
      improved: e.metrics?.lowerBetter ? a < b : a > b };
  }
  narrative() {
    const sorted = [...this.#events].sort((a, b) => a.date - b.date);
    const story = sorted.map((e) => {
      const m = e.metrics ? ` (指标: ${Object.entries(e.metrics).map(([k, v]) => `${k}: ${v.before}→${v.after}`).join(', ')})` : '';
      const adr = e.adrRef ? ` [ADR-${e.adrRef}]` : '';
      return `${e.date.toISOString().slice(0, 10)} [${e.type}] ${e.title}${m}${adr}`;
    });
    return `架构演进时间线:\n${story.join('\n')}`;
  }
}
```

**评分点**：
- 事件带指标对比（before/after——事件有价值证据）
- 影响分析（事件前后 30 天中位数对比——因果可视化）
- ADR 引用（时间线与决策记录联动）
- 演进叙事自动生成（述职/回顾的产出物）
