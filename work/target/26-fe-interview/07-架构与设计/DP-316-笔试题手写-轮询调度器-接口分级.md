## DP-316：笔试题：手写轮询调度器（接口分级+退避）？
**答**：实现 Poller：1) 注册多个轮询任务（不同间隔）；2) 页面隐藏暂停、恢复重启（visibilitychange）；3) 失败退避（连续失败间隔翻倍，成功复位）；4) 任务间互不阻塞（独立 timer）。
**评分点**：
- 隐藏暂停逻辑正确（clearInterval 与重启）。
- 退避正确（失败翻倍+成功复位，上限封顶）。
- 并发不阻塞（每任务独立循环而非共享队列）。
- stop 全量清理。
```javascript
class Poller {
  #tasks = new Map();   // id → { fn, interval, timer, fails }
  register(id, fn, interval = 5000) {
    const t = { fn, interval, fails: 0 };
    this.#tasks.set(id, t);
    this.#schedule(id);
    return () => this.unregister(id);
  }
  #schedule(id) {
    const t = this.#tasks.get(id);
    if (!t || document.visibilityState === 'hidden') return;        // 2) 隐藏暂停
    t.timer = setTimeout(async () => {
      try { await t.fn(); t.fails = 0; }                             // 3) 成功复位
      catch { t.fails++; }
      t.current = t.interval * Math.min(2 ** t.fails, 8);           // 退避封顶
      this.#schedule(id);
    }, t.current ?? t.interval);
  }
  start() { document.addEventListener('visibilitychange', () => {
    document.visibilityState === 'visible' ? [...this.#tasks.keys()].forEach(id => this.#schedule(id))   // 恢复
                                            : [...this.#tasks.values()].forEach(t => clearTimeout(t.timer)); }); }
  unregister(id) { clearTimeout(this.#tasks.get(id)?.timer); this.#tasks.delete(id); }
}
```
