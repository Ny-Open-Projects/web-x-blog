## ARC-474：前端后台任务与通知体系架构
**答**:
- Web Push 链路：订阅（service worker pushManager.subscribe，VAPID 公钥）→ 服务器发送（Web Push 协议）→ SW push 事件处理 → Notification 展示 → 点击聚焦/跳转。即使页面关闭也能触达（浏览器允许 SW 被唤醒）。
- 订阅治理：权限请求时机（用户上下文触发而非首屏弹窗，提升授权率）、订阅失效处理（推送 410 响应清订阅）、多端订阅去重。
- 后台任务分层：SW 后台同步（Background Sync：离线提交恢复网络后重放）、周期同步（Periodic Sync，Chrome 受限）、页面 idle 任务（requestIdleCallback，ARC-405）。
- 通知体验约束：通知去重与聚合（同类 5 分钟窗口合并）、用户偏好中心（分频道开关）、click 语义（跳转深链 + 未读状态同步）。
- 降级：不支持 Push 的环境（iOS Safari 旧版）降级为站内信 + 邮件；通知能力探测收口在能力层。
```javascript
// 订阅与推送处理
self.addEventListener('push', (e) => {
  const data = e.data.json();
  e.waitUntil(showDeduped(data));                              // 去重聚合后展示
});
async function subscribe(swReg) {
  const sub = await swReg.pushManager.subscribe({ userVisibleOnly: true,
    applicationServerKey: VAPID_PUBLIC });
  await api.saveSubscription(sub);                             // 服务端存端点
}
self.addEventListener('pushsubscriptionchange', () => resubscribe()); // 订阅自动续期
```
