## ARC-525：大促活动日历与状态联动
**答**:
- 活动状态机：未开始/预热/进行中/已结束/已暂停——状态由服务端日历驱动（配置中心下发 ARC-369），前端按状态渲染（按钮文案/倒计时/入口显隐），禁止前端硬编码活动时间判断。
- 状态切换的及时性：跨状态时刻（准点开抢）——本地倒计时到点触发轮询/推送确认（钟差校正 ARC-481），服务端为准；开抢瞬间的请求风暴用随机退避打散（ARC-446）。
- 配置驱动 UI：活动页各模块按状态显隐（预热期只展示预告）——模块声明"生效状态集"，渲染引擎过滤（ARC-503 活动页 schema 扩展）。
- 降级与兜底：日历服务不可用 → 缓存上次日历（保守状态：宁可显示未开始不可提前开抢——涉资状态宁严勿松）；活动暂停（熔断）全局生效通知。
- 多活动并行：活动日历冲突检测（同位资源抢排期，配置平台校验）。
```javascript
// 状态驱动渲染
function ActivityBlock({ activity, now }) {
  const st = activityState(activity, serverNow(now));            // 服务端时钟
  const visible = activity.schema.blocks.some(b => b.states.includes(st));
  if (!visible) return null;
  if (st === 'preheat') return <Countdown to={activity.startAt} onEnd={refreshState} />;
  if (st === 'running') return <SalePanel activity={activity} />; // 按 schema 渲染
  return <EndedPanel />;
}
// 倒计时到点：本地触发 + 服务端确认（防钟差提前开抢）
```
