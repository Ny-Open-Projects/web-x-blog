## ARC-410：笔试题：手写统一请求层
**答**：实现 request(config)：1) 请求/响应拦截器链；2) GET 幂等自动重试（网络错误最多 2 次退避）；3) 同一 key 的请求自动取消上一个（竞态防护）；4) 401 触发一次性刷新 token 重放。
**评分点**：
- 拦截器链顺序正确（请求先注册先执行，响应链可组合）。
- 重试只对网络错误/超时，4xx 不重试。
- 竞态取消用 AbortController 且 key 化管理。
- token 刷新并发去重（多个 401 只刷一次，共享刷新 Promise）。
```javascript
class Http {
  #interceptors = []; #pending = new Map(); #refreshing = null;
  use(fn) { this.#interceptors.push(fn); return this; }
  async request(config) {
    for (const i of this.#interceptors) config = await i(config);
    return this.#send(config);
  }
  async #send(config, attempt = 0) {
    const { key, signal } = config;
    if (key) { this.#pending.get(key)?.abort(); }             // 取消同类上一个
    const ac = new AbortController(); if (key) this.#pending.set(key, ac);
    try {
      const res = await fetch(config.url, { ...config, signal: signal ?? ac.signal });
      if (res.status === 401) return this.#reauth(config);    // 统一重放
      return res;
    } catch (e) {
      if (config.method === 'GET' && attempt < 2 && e.name === 'AbortError' === false)
        return new Promise(r => setTimeout(r, 2 ** attempt * 300))
          .then(() => this.#send(config, attempt + 1));
      throw e;
    } finally { if (key) this.#pending.delete(key); }
  }
  async #reauth(config) {
    this.#refreshing ??= api.refreshToken().finally(() => (this.#refreshing = null));
    await this.#refreshing;                                   // 并发 401 共享一次刷新
    return this.#send(config);
  }
}
```
