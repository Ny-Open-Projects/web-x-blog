## DP-333：笔试题：手写表单草稿自动保存？
**题目**：实现草稿自动保存：1) 表单变更防抖 2s 后写 localStorage（key 含用户+表单 id）；2) 恢复逻辑（进入时提示"恢复草稿？"）；3) 提交成功清除草稿；4) 草稿 schema 版本校验（结构变化时丢弃）。
**评分点**：
- 防抖正确（变更→2s→写）。
- 版本校验失败丢弃不崩溃。
- 恢复询问不自动覆盖（用户决定）。
- 提交后清除时机正确。
```typescript
const DRAFT_KEY = (uid: string, formId: string) => `draft:${uid}:${formId}`;
function useDraft(form, { uid, formId, schemaVersion }) {
  const key = DRAFT_KEY(uid, formId);
  const onFormChange = debounce(() => {                    // 1) 防抖保存
    const raw = localStorage.getItem(key);
    const saved = raw ? JSON.parse(raw) : null;
    if (saved && saved.schemaVersion !== schemaVersion) { localStorage.removeItem(key); return; }   // 4)
    localStorage.setItem(key, JSON.stringify({ values: form.values, schemaVersion, at: Date.now() }));
  }, 2000);
  useEffect(() => {
    const raw = localStorage.getItem(key);
    if (!raw) return;
    const saved = JSON.parse(raw);
    if (saved.schemaVersion !== schemaVersion) { localStorage.removeItem(key); return; }
    confirm(`检测到 ${new Date(saved.at).toLocaleString()} 的草稿，是否恢复？`)
      ? form.reset(saved.values)                            // 3) 询问后恢复
      : localStorage.removeItem(key);
  }, []);
  const submit = async () => { await form.submit(); localStorage.removeItem(key); };   // 清除
  return { onFormChange, submit };
}
```
