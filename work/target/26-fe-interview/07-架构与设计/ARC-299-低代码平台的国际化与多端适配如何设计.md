## ARC-299：低代码平台的国际化与多端适配如何设计？
**答**：
- 国际化进 DSL：文案字段用 i18n 类型值（`{ type: 'i18n', key: 'btn.submit' }`），引擎渲染时经运行时 t() 解析（ARC-249）；画布内可切换预览语言；文案缺失走 fallback 链。
- 平台侧管理：低代码平台的文案统一进文案平台（ARC-242），页面发布时校验"页面引用 key 覆盖率"，未达标语言禁止发布到对应站点。
- 多端适配两档：响应式（DSL 里用栅格/断点属性，一套 DSL 多端渲染）vs 多份 DSL（每端独立画布，导出时共享数据源与逻辑绑定）。前者成本低，后者还原度高——营销页用前者，复杂管理后台按端出码。
- 画布适配：编排器提供设备切换（375/768/1280 预览），断点属性在属性面板暴露（如"手机端隐藏"开关）。

```typescript
// i18n 类型值解析
function resolveValue(v, ctx) {
  if (v?.type === 'i18n') return ctx.t(v.key);            // 缺失走 i18n fallback 链
  if (v?.type === 'expression') return evalSandbox(v.value, ctx);
  return v;
}
// 多端断点属性
props: { visible: { desktop: true, mobile: false }, span: { desktop: 6, mobile: 12 } }
// 渲染：resolveProps 按 currentBreakpoint 取值 → CSS Grid span/条件渲染
// 发布校验：coverageOf(page.keys, 'en') < 0.98 → block publish to en-site
```
