## DP-495：笔试：手写任务调度器

**答**：实现带优先级与饿死防护的任务调度器：① push(task, priority)——多级队列（high/normal/low 数组）；② 高优先级先出队 + 同级 FIFO；③ 饿死防护：low 任务等待超 5s 自动升级为 normal（老化机制）；④ 惰性取消（cancelled 标记——出队时检查）；⑤ 深度告警（pending > 100 = 积压——产能不足信号）；⑥ 并发上限 + 同 key 去重。写出实现。

```javascript
class Scheduler {
  #lanes = { high: [], normal: [], low: [] };
  #flying = 0; #max = 4; #keyed = new Map();
  push(key, fn, lane = 'normal') {
    if (this.#keyed.has(key)) return this.#keyed.get(key);   // 同 key 去重
    const task = { key, fn, lane, cancelled: false, pushedAt: Date.now() };
    const promise = new Promise((res, rej) => Object.assign(task, { res, rej }));
    this.#keyed.set(key, promise);
    this.#lanes[lane].push(task);
    if (this.#pending() > 100) console.warn('[scheduler] 积压');
    setTimeout(() => {                                  // 老化: low 等 5s 升 normal
      if (this.#lanes.low.includes(task)) { this.#lanes.low.splice(this.#lanes.low.indexOf(task), 1); this.#lanes.normal.push(task); }
    }, 5000);
    this.#drain();
    return promise;
  }
  cancel(key) { for (const lane of Object.values(this.#lanes)) { const t = lane.find((x) => x.key === key); if (t) t.cancelled = true; } }
  #pending() { return Object.values(this.#lanes).reduce((s, l) => s + l.length, 0); }
  #drain() {
    while (this.#flying < this.#max) {
      const t = this.#lanes.high.shift() ?? this.#lanes.normal.shift() ?? this.#lanes.low.shift();
      if (!t) break;
      if (t.cancelled) { this.#keyed.delete(t.key); continue; }
      this.#flying++;
      t.fn().then(t.res, t.rej).finally(() => { this.#flying--; this.#keyed.delete(t.key); this.#drain(); });
    }
  }
}
```

**评分点**：
- 三级队列 + 老化升级（饿死防护）
- 同 key 去重（in-flight 复用）
- 惰性取消（出队时检查——简单正确）
- 积压告警（队列的可观测性）
