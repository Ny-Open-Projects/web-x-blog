## DP-329：笔试题：手写乐观更新与回滚？
**答**：实现 useOptimisticList：1) add 立即插入临时项（pending 态）；2) 服务器返回后用真数据替换；3) 失败回滚（移除临时项+提示）；4) 并发保护（列表版本号，过期响应不覆盖）。
**评分点**：
- 临时项标记与替换正确。
- 回滚清理完整。
- 版本号/序列号防过期响应覆盖。
- 提示与重试入口。
```tsx
function useOptimisticList(fetchList) {
  const [list, setList] = useState([]);
  const [version, setVersion] = useState(0);
  const add = async (item) => {
    const tempId = `tmp-${Date.now()}`;
    const v = version;
    setList(l => [...l, { ...item, id: tempId, pending: true }]);          // 1)
    try {
      const created = await api.create(item);
      setList(l => version === v ? l.map(i => i.id === tempId ? created : i) : l);   // 2) 版本保护
    } catch (e) {
      setList(l => version === v ? l.filter(i => i.id !== tempId) : l);    // 3) 回滚
      toast({ type: 'error', text: `${item.name} 添加失败`, action: () => add(item) });  // 4) 重试入口
    }
  };
  return { list, add };
}
```
