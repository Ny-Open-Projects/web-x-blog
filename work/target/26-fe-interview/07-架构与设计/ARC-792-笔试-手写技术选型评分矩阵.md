## ARC-792：笔试：手写选型评分矩阵

**答**：实现技术选型对比工具 `compareOptions(candidates, criteria, teamProfile)`：① 评分矩阵：候选方案 × 评估维度（维护活跃度/团队匹配/生态/迁移成本/性能/许可证）——每维度权重可配；② 团队画像加权：teamProfile（React 熟练度 0.8/TS 熟练度 0.9）——「团队匹配」维度按画像动态评分；③ 风险调整：低活跃度方案（半年无更新）扣 30% 分；④ 输出排序 + 敏感性分析（权重扰动 ±20% 结论是否稳定——不稳定则标注「结论脆弱」）；⑤ 输出决策表（含每项得分明细——可审计）。写出实现。

```javascript
function compareOptions(candidates, criteria, teamProfile) {
  const results = candidates.map((c) => {
    let total = 0;
    const detail = criteria.map(({ name, weight, score }) => {
      let s = typeof score === 'function' ? score(c, teamProfile) : score;
      // 风险调整: 维护活跃度低于阈值扣分
      if (name === '维护活跃度' && c.lastUpdateMonths > 6) s *= 0.7;
      total += s * weight;
      return { name, score: s, weight, weighted: +(s * weight).toFixed(2) };
    });
    return { name: c.name, total: +total.toFixed(2), detail };
  });
  results.sort((a, b) => b.total - a.total);
  // 敏感性分析: 每权重 ±20% 看排名是否翻转
```

**评分点**：
- 权重可配 + 团队画像动态评分（匹配度不是静态分）
- 风险调整（低活跃扣分）
- 敏感性分析（结论脆弱性标注——比结论本身更有价值）
- 得分明细可审计（决策可追溯）
