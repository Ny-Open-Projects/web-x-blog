## DP-210：源码识别：前端路由库源码中的状态机与命令模式？
**答**：
- 状态机：路由导航是显式状态机（idle → navigating → guards → committing → idle），vue-router 的导航解析流程就是文档化的状态机；中断（新导航覆盖旧导航）是转移边界。
- 命令模式：history.pushState 包装成 navigate(to) 命令对象，撤销/重做对应浏览器历史栈（原生备忘录）。
- 职责链：全局守卫 beforeEach → 路由守卫 → 组件内守卫是一条职责链，任一环节返回 false/redirect 即短路（跳转重派）。
- 识别要点：能解释"导航被重定向时递归走同一条链直到稳定"，以及 pending 导航如何被新导航打断（abort 控制）。

```javascript
// 路由导航状态机 + 守卫职责链
async function navigate(to) {
  if (state.phase !== 'idle') state.pending?.abort();        // 新导航打断旧导航
  const nav = { to, aborted: false, abort() { this.aborted = true; } };
  state.pending = nav; state.phase = 'navigating';
  for (const guard of [...globalGuards, ...resolveRouteGuards(to)]) {  // 职责链
    const res = await guard(to, from);
    if (nav.aborted) return;                                  // 被新导航覆盖
    if (res === false) return state.phase = 'idle';           // 短路：取消
    if (typeof res === 'string' || isRouteLocation(res)) return navigate(res);   // 重定向：递归命令
  }
  commit(to);                                                  // 命令提交：history.pushState
  state.phase = 'idle';
  listeners.forEach(l => l(currentRoute.value = to));          // 观察者通知视图
}
```
