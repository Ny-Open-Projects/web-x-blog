## DP-545：笔试：手写路由权限代理

**答**：实现路由的权限代理层：① 代理路由表：原始路由表 → 权限过滤代理（无权限路由不注册——而非注册后拦截）；② 动态代理：权限变更时路由表重建（addRoute/removeRoute——增量更新）；③ 深链防越权：直接 URL 访问无权限路由 → 404（不暴露存在）；④ 代理的可观测性：路由权限拦截统计（哪些路由被谁访问被拒——审计）；⑤ 防护边界说明（前端路由权限是 UX——服务端才是真权限）。写出实现。

```javascript
class RouteProxy {
  #registered = new Set();
  constructor(router, auth) { this.router = router; this.auth = auth; }
  sync(routes) {                                       // 权限变更 → 增量重建
    // 移除不再有权的老路由
    for (const name of this.#registered)
      if (!routes.some((r) => r.name === name && auth.has(r.meta.perm)))
        this.router.removeRoute(name), this.#registered.delete(name);
    // 注册新有权路由
    for (const r of routes)
      if (!this.#registered.has(r.name) && (!r.meta?.perm || auth.has(r.meta.perm))) {
        this.router.addRoute(r);
        this.#registered.add(r.name);
      }
  }
  guard(to) {                                          // 深链防越权
    if (this.#registered.size && !this.#registered.has(to.name)) {
      track('route-denied', { path: to.path, userId: auth.userId });   // 审计
      return { redirect: '/404' };                     // 404 不暴露存在
    }
  }
}
```

**评分点**：
- 代理过滤（无权限不注册——而非注册后拦截）
- 权限变更的增量重建（addRoute/removeRoute 差量）
- 深链 404（不暴露页面存在——安全语义）
- 审计统计 + 边界说明（前端是 UX 非安全）
