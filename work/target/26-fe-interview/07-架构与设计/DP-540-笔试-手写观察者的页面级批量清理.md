## DP-540：笔试：手写清理器

**答**：实现页面级的统一清理器 `PageScope`：① 资源注册：定时器/监听器/IO observer/AbortController——所有资源过 scope 登记；② disposeAll：逆序清理（后注册先释放——依赖顺序）；③ dispose 的幂等（重复调用不炸——资源清理的防御）；④ 单资源的错误隔离（一个清理失败不影响其他——逐个 try/catch）；⑤ 与框架生命周期绑定（React useEffect cleanup / Vue onScopeDispose 的对接——一处调用全清）。写出实现。

```javascript
export function createPageScope() {
  const disposers = [];
  let disposed = false;
  return {
    track(resource, dispose) {
      if (disposed) { dispose(); return resource; }    // 已销毁: 立即清理
      disposers.push(dispose);
      return resource;
    },
    listen(el, ev, fn, opts) { el.addEventListener(ev, fn, opts); disposers.push(() => el.removeEventListener(ev, fn, opts)); },
    interval(fn, ms) { const t = setInterval(fn, ms); disposers.push(() => clearInterval(t)); return t; },
    signal() { const c = new AbortController(); disposers.push(() => c.abort()); return c.signal; },
    disposeAll() {
      if (disposed) return;
      disposed = true;
      for (const d of disposers.reverse())             // 逆序: 后进先出
        try { d(); } catch (e) { console.error('dispose failed', e); }   // 隔离
    },
  };
}
// React: useEffect(() => { const scope = createPageScope(); ... return () => scope.disposeAll(); }, [])
```

**评分点**：
- 资源注册制（定时器/监听/IO/signal 统一）
- 逆序清理（依赖顺序——消费者先于生产者释放）
- 幂等 + 错误隔离（重复调用与单点失败的防御）
- 框架生命周期的一处绑定（全清）
