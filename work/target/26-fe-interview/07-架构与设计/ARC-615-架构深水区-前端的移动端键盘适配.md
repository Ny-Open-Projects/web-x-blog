## ARC-615：移动端软键盘适配
**答**:
- 三类问题：遮挡（键盘盖住输入框——滚动校正）、布局压缩（键盘顶起视口——fixed 元素/底部栏错位）、键盘类型（数字/搜索/回车语义——inputmode 与 enterkeyhint）。
- 适配架构：视口监听统一层（visualViewport API 监听键盘高度变化——iOS/Android 行为差异收口）、遮挡校正（焦点进入时 scrollIntoView 目标元素 + 键盘高度补偿——滚动策略按布局模式选择）、布局模式选择（resize vs overlay：键盘不压缩视口的浏览器（Android overlay）用 padding 补偿——检测行为差异自动适配）。
- 输入体验细节：inputmode（numeric/email/search——弹对应键盘）、enterkeyhint（go/search/done——回车键文案）、键盘收起时机（表单场景保持键盘连续输入 vs 提交场景自动收起——场景化配置）、安全区适配（键盘收起后 env(safe-area-inset) 布局）。
- 专项测试：iOS/Android 键盘矩阵（各机型行为差异大——真机矩阵 + 关键表单页面清单）。
```javascript
// 视口适配层
const vv = window.visualViewport;
vv?.addEventListener('resize', () => {
  const kb = window.innerHeight - vv.height;                     // 键盘高度估算
  if (kb > 100) { document.body.style.paddingBottom = kb + 'px'; // 布局补偿
                   ensureVisible(document.activeElement); }      // 焦点可见
  else document.body.style.paddingBottom = '';
});
<input inputmode="numeric" enterkeyhint="done">                   // 键盘类型语义
```
