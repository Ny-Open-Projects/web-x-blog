## DP-487：笔试：手写装饰器组合

**答**：实现三个函数装饰器并组合：① withRetry(n)：失败重试（指数退避）；② withThrottle(ms)：时间窗口限频；③ withLog(name)：前后日志；④ 组合语义测试：`withLog(withThrottle(withRetry(fn)))` 的执行顺序与日志条数（重试产生多次日志——装饰顺序影响行为）；⑤ 回答：为什么先限流再重试而不是先重试再限流（重试可能绕过限流——顺序即语义）。写出实现。

```javascript
const withRetry = (fn, n = 3, base = 200) => async (...a) => {
  for (let i = 0; i < n; i++) {
    try { return await fn(...a); }
    catch (e) { if (i === n - 1) throw e; await new Promise((r) => setTimeout(r, base * 2 ** i)); }
  }
};
const withThrottle = (fn, ms = 1000) => {
  let last = 0;
  return async (...a) => {
    const wait = ms - (Date.now() - last);
    if (wait > 0) await new Promise((r) => setTimeout(r, wait));
    last = Date.now();
    return fn(...a);
  };
};
const withLog = (fn, name) => async (...a) => {
  console.log(`[${name}] start`);
  try { const r = await fn(...a); console.log(`[${name}] ok`); return r; }
  catch (e) { console.log(`[${name}] fail: ${e}`); throw e; }
};
// 组合: withLog(withThrottle(withRetry(apiCall)))
// 顺序语义: throttle 在 retry 外层 → 重试的每次调用也受限流约束 (正确)
// 若 retry 在外层 throttle 在内层 → 重试绕过限流 (错误)
```

**评分点**：
- 三个装饰器独立实现（可组合）
- 顺序即语义的核心理解（限流必须在重试外层——否则重试绕过限流）
- 装饰顺序的日志条数分析
- 组合的「语义正确性」审查能力
