## AGT-288：跨多轮对话的注入攻击（多轮注入/会话劫持）有什么形态怎么防？

**答**:
- 多轮注入形态：铺垫式（前几轮正常对话建立语境，最后一轮注入）、碎片式（恶意指令拆在多轮中，每轮单独看无害）、上下文污染（通过诱导用户粘贴含注入的外部内容进对话——"帮我分析这个文件"而文件含指令）。
- 会话劫持风险：长会话中系统提示的影响力衰减（AGT-222 压缩后约束丢失），攻击者在后期提越权请求更易得手——压缩与摘要时必须保留安全约束（系统级红线不参与压缩）。
- 防御：约束固定锚（安全指令在每轮/每次压缩后重新注入，不依赖历史记忆）、意图一致性检查（突然请求与任务主线无关的高危操作→触发确认）、会话级权限不变（会话后期不得获得会话开始没有的能力——权限只降不升）。
- 评测纳入：多轮注入攻击样本进安全回归集（AGT-299 红队），每次 prompt/压缩策略变更后重跑——攻击在演化，防御要回归。

```javascript
function compactHistory(h) {
  const safety = extractSafetyBlocks(h);    // 安全约束不压缩
  return [{ role: 'system', content: SAFETY_ANCHOR + safety },
          ...summarize(h)];                 // 每次压缩重新锚定
}
// 意图检查：轮次突现高危请求 → 升级确认
// 权限：会话内只降不升（no privilege escalation）
```
