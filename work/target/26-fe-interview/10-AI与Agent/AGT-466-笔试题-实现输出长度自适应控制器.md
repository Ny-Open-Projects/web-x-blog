## AGT-466：手写长度控制：场景预算表、截断检测续写、要点+展开两级输出

**需求与边界**：
- 输入：query、场景类型；输出：带预算的 prompt 与后处理。
- 边界要求：① 场景预算表（闲聊短/分析中/报告长）；② max_tokens 截断检测（finish_reason=length）→ 续写或声明截断；③ 两级输出（要点先行+展开按钮）的预算拆分；④ 长度指令具体化（数字而非"简短"）。

**答**：
```javascript
const BUDGETS = { chat: 150, analysis: 400, report: 1200,
  code: 2000 };
async function lengthControl(query, scene, { llm }) {
  const budget = BUDGETS[scene] ?? 300;
  const prompt = `${query}
    要求：正文不超过 ${budget} 字；要点式；禁客套与重复；
    若内容超出预算，先给要点，结尾标注"[展开查看完整分析]"。`;
  const r = await llm(prompt, { max_tokens: budget * 3 });
  // 截断检测与处置
  if (r.finishReason === 'length') {
    if (scene === 'report' || scene === 'code')
      return { ...r, continued: await llm(`续写剩余部分`,
        { max_tokens: budget * 2 }), truncated: false };
    return { ...r, truncated: true,
      note: '因长度限制截断，可点击"继续生成"' };   // 短场景声明截断
  }
  // 两级输出拆分：要点（直接展示）+ 展开体（按需加载）
  const [brief, detail] = splitOnMarker(r.text, '[展开查看完整分析]');
  return { brief, detail: detail ?? null,
    budget, tokens: r.tokens,
    effective: tokens(r.text) <= budget * 1.2 };    // 超标率监控
}
// prompt 纪律：具体数字预算（模型对数字服从性好），
// 禁"简短一些"这类模糊指令。
```

**评分点**:
- 场景预算表 + 数字化长度指令（模糊词禁用）。
- 截断检测（finishReason）分场景处置：长场景续写、短场景声明截断。
- 两级输出（要点+展开标记）按需付费的交互设计。
- effective 超标率监控（预算执行质量可量化）。
