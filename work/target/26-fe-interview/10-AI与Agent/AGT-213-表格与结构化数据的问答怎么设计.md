## AGT-213：文档中的表格（财报/对账单）怎么支持精准问答？

**答**:
- 向量检索对表格天然失效：表格切块后行列关系断裂，embedding 无法表达"行=华东区，列=毛利率"的二维结构——表格必须走结构化路线而不是纯向量。
- 路线分层：小表格直接整表进上下文（保留 markdown/HTML 结构）；大表格走 Text2SQL/Text2DSL（LLM 把问题转成 SQL/查询 DSL，对数据库执行后返回精确结果）；混合路由由意图判断决定。
- 入库改造：表格抽取时保留"表格语义"——表头行/合并单元格/单位说明（"单位：万元"）要随表存元数据，否则"毛利率 32"到底是不是百分比都说不清。
- 防幻觉关键：数值型答案必须由查询引擎算出并返回原文引用（行号/单元格），LLM 只负责自然语言包装——绝不让 LLM 自己"算"表格数字。

```javascript
async function tableQA(question) {
  const plan = await llm(`判断问题类型：
    A) 单表小问题 B) 聚合计算 C) 语义问题`, question);
  if (plan === 'C') return ragAnswer(question);
  const { sql, table } = await llm2sql(question, tableSchema);
  const rows = await queryEngine.run(sql);       // 精确计算由引擎做
  return generate(question, formatRows(rows, table), {
    citation: `${table}#${rows.map(r => r.rowNo)}`  // 强制引用单元格
  });
}
```
