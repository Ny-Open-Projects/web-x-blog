## AGT-455：手写供应商路由：健康度滑动窗口、熔断半开、降级链与恢复探测

**需求与边界**：
- 输入：供应商列表 [{id, call, weight}]、健康策略；输出：可用供应商调用。
- 边界要求：① 错误率滑动窗口统计，超阈值熔断；② 熔断后半开探测（放行少量流量试探恢复）；③ 降级链顺序（主→备→缓存/静态）；④ 切换事件记录（可观测）。

**答**：
```javascript
class ProviderRouter {
  constructor({ providers, windowMs = 60000, errThreshold = 0.5,
    halfOpenQps = 2 }) {
    this.providers = providers;
    this.stats = new Map(providers.map(p => [p.id,
      { errors: [], opens: 0, state: 'closed', probes: 0 }]));
    this.cfg = { windowMs, errThreshold, halfOpenQps };
    this.order = providers.map(p => p.id);      // 降级链顺序
  }
  async call(req) {
    for (const id of this.order) {
      const s = this.stats.get(id);
      if (s.state === 'open') {
        // 半开：低频探测
        if (s.probes >= this.cfg.halfOpenQps) continue;
        s.probes++;
        try {
          const r = await this.doCall(id, req);
          s.state = 'closed'; s.probes = 0; s.errors = [];
          recordSwitch(id, 'half_open_recovered');
          return r;
        } catch { s.probes > 0 && s.probes--; continue; }
      }
      try {
        const r = await this.doCall(id, req);
        return r;
      } catch (e) {
        this.onError(id);                        // 记错误滑窗
      }
    }
    return fallbackCache(req);                   // 全挂：缓存/静态兜底
  }
  onError(id) {
    const s = this.stats.get(id);
    s.errors.push(Date.now());
    s.errors = s.errors.filter(t =>
      Date.now() - t < this.cfg.windowMs);
    if (s.errors.length >= 5 && s.state === 'closed') {
      s.state = 'open'; s.probes = 0;
      recordSwitch(id, 'circuit_open');
      setTimeout(() => { s.state = 'half_open';
        recordSwitch(id, 'half_open_probe'); }, 30e3);
    }
  }
  doCall(id, req) { return this.providers.find(p => p.id === id)
    .call(req); }
}
```

**评分点**:
- 滑动窗口错误率统计与熔断（closed→open→half_open 状态机完整）。
- 半开限频探测恢复（probes 上限），恢复成功清零重置。
- 降级链顺序执行+全挂缓存兜底。
- 切换事件全记录（可观测可归因）。
