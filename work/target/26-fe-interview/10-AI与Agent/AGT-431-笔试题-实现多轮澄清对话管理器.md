## AGT-431：手写澄清管理：歧义识别、选项生成、用户确认、超时默认

**需求与边界**：
- 输入：query、歧义检测函数、选项生成器；输出：澄清问题或直接处理。
- 边界要求：① 歧义可程序判定（多候选实体/缺时间范围）优先规则；② 选项 ≤3 个+其他（自由输入）；③ 用户确认结果写入会话约束（后续沿用不重复问）；④ 同一歧义只问一次（重复问=体验灾难）；⑤ 用户未答的超时默认取最常见解释并声明。

**答**：
```javascript
class ClarifyManager {
  constructor({ asked = new Set(), defaults = new Map() }) {
    this.asked = asked; this.defaults = defaults;   // 会话级
  }
  async process(query, { detect, genOptions }) {
    const amb = detect(query);                       // {dim, candidates}
    if (!amb) return { proceed: true };
    const sig = `${amb.dim}:${amb.candidates.join('|')}`;
    // 1. 已确认过的维度直接沿用
    const known = [...this.defaults.entries()]
      .find(([k]) => k.startsWith(amb.dim + ':'));
    if (known) return { proceed: true, resolved: known[1] };
    // 2. 同歧义只问一次
    if (this.asked.has(sig))
      return { proceed: true, resolved: this.defaults.get(sig) };
    // 3. 生成澄清问题（≤3 选项 + 其他）
    const options = amb.candidates.slice(0, 3);
    this.asked.add(sig);
    return { proceed: false, question:
      `您指的是${amb.dim}的哪一个？`, options, allowFree: true,
      onAnswer: (answer) => {                        // 确认闭环
        const resolved = options.find(o => o.id === answer)
          ?? { id: 'free', value: answer };
        this.defaults.set(sig, resolved);            // 写会话约束
        return resolved;
      },
      timeout: {                                      // 超时默认
        ms: 60e3, fallback: amb.candidates[0],        // 最常见解释
        note: '未选择时将按最常见情况处理' },
    };
  }
}
// detect 规则示例：{dim:'时间范围', candidates:[
//   {id:'m',label:'本月'},{id:'q',label:'本季度'},{id:'y',label:'本年'}]}
```

**评分点**:
- 歧义处理完整：检测→沿用已确认→单次提问→确认闭环写入约束。
- 同签名歧义不重复问（asked 集合），已确认维度跨轮沿用。
- 选项 ≤3 + 自由输入；超时走最常见解释且预先声明（默认不静默）。
- 程序可判定的歧义不调 LLM（成本与稳定性意识）。
