## AGT-234：黑板模式（Blackboard）的多 Agent 协作怎么实现？

**答**:
- 结构三件套：共享工作区（结构化的中间状态：事实/假设/待办）、各专长 Agent（自主决定何时"看板"并贡献）、控制策略（谁先上/冲突怎么解）——区别于流水线的强顺序，黑板是机会主义协作。
- 实现要点：工作区用结构化文档/状态库（不是自由聊天记录，否则噪音淹没状态）；每个贡献带类型标签（fact/hypothesis/draft）与作者；Agent 订阅自己关注的变化（事件驱动）而不是轮询。
- 收敛控制：黑板模式最大风险是"人人写没人收"——必须有收敛判据（目标完成度检查）与一个调度/终审角色（可以是规则或 LLM），判定"可以合成答案了"。
- 适用边界：适合答案路径不确定、需要多视角渐进构建的任务（调研/方案设计）；强流程任务用状态机更可控——黑板模式的自由度是双刃剑。

```javascript
// 黑板协作核心循环
const board = { facts: [], drafts: [], todos: [] };
for (const agent of specialists) {
  agent.subscribe(board);                  // 事件驱动
}
while (!converged(board)) {                // 收敛判据
  const ev = await board.nextEvent();      // 变化事件
  const contrib = await agentFor(ev).step(board);
  board.write(contrib);                    // 带类型+作者
}
return synthesize(board);                  // 终审合成
```
