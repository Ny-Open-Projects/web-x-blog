## AGT-424：手写人审卡逻辑：风险分级、记住选择、参数偏离重确认、超时兜底

**需求与边界**：
- 输入：操作 {tool, args, irreversible}、用户决策流；输出：决策 {approve/modify/reject}。
- 边界要求：① 读操作免确认；② 写操作单次确认；不可逆强确认；③ 同模式操作可"记住"（白名单），参数显著偏离白名单时重新确认；④ 超时走预定义策略（pause 默认）且决策留痕。

**答**：
```javascript
class ApprovalFlow {
  constructor({ whitelist = new Map(), onTimeout = 'pause' }) {
    this.whitelist = whitelist; this.onTimeout = onTimeout;
  }
  level(op) {
    if (op.kind === 'read') return 'none';
    if (op.irreversible || op.kind === 'destructive') return 'strong';
    return 'normal';
  }
  async decide(op, { confirm, clock = Date.now() }) {
    const lvl = this.level(op);
    if (lvl === 'none') return { action: 'auto', op };
    const sig = signature(op);                    // 工具+参数模式
    const remembered = this.whitelist.get(sig);
    if (remembered && deviation(op.args, remembered.args) < 0.15)
      return { action: 'auto', op, remembered: true };  // 白名单静默
    const decision = await confirm({
      level: lvl, op,
      options: ['approve', 'modify', 'reject', 'remember'],
    });
    if (decision.action === 'remember')           // 记住本次选择
      this.whitelist.set(sig, { args: op.args, ts: clock() });
    return { ...decision, logged: { ts: clock(), sig, op: brief(op) } };
  }
  // 超时：pending 审批的兜底
  onApprovalTimeout(pending) {
    switch (this.onTimeout) {
      case 'pause': return { action: 'pause', taskId: pending.taskId };
      case 'proceed': return { action: 'auto', op: pending.op,
        warning: '超时按预设继续' };
      default: return { action: 'pause' };
    }
  }
}
const signature = (op) => `${op.tool}:${Object.keys(op.args ?? {}).sort().join(',')}`;
// deviation：数值/枚举字段偏离比例。
```

**评分点**:
- 三级确认（读免/写单次/不可逆强确认）分级正确。
- 白名单静默执行 + 参数偏离检测（偏离超阈值重新确认）——防白名单被滥用。
- 超时策略可配置且有默认安全值（pause），决策全留痕。
- remember 选项记录签名与参数基线，供偏离比对。
