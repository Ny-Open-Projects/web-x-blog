## AGT-361：复杂 Agent 的系统 prompt 怎么组织——架构模式有哪些？

**答**:
- 分区模式：系统 prompt 按职能分区——身份与目标（我是谁/要达成什么）、行为准则（安全红线/拒答规则）、能力说明（工具使用纪律）、格式约定（输出规范）、上下文注入区（动态知识/用户画像）——分区让变更局部化，每区独立版本化（AGT-321）。
- 分层模式：全局规则（跨 Agent 一致的红线）+ 角色 prompt（每个 Agent 的职责）+ 任务 prompt（具体任务的模板）三层叠加——全局层短而稳定（利于缓存 AGT-224），变化多的放任务层。
- 纪律条款化：行为规则写成编号条款（"R1: 金额必须来自工具结果"），评测与监控按条款对齐（哪条规则被违反可归因）——条款化让 prompt 规则可测试。
- 长度治理：prompt 精简是持续工作（每季审计删除率）——过长的 prompt 稀释注意力（AGT-225），规则冲突也随长度增加；冲突检测（两条规则矛盾）纳入 prompt 评审清单。

```text
Prompt 架构分区：
① 身份目标 ② 行为准则（条款化 R1..Rn）
③ 工具纪律 ④ 格式约定 ⑤ 动态注入区
三层：全局红线（稳定/缓存友好）
  + 角色 prompt + 任务模板
治理：条款化可测试、季度审计、
  冲突检测清单、每区独立版本。
```
