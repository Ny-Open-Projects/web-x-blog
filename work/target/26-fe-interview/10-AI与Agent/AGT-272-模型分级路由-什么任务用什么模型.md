## AGT-272：模型分级路由（大模型/小模型混合）怎么设计降本？

**答**:
- 分级思路：任务难度差异巨大——意图分类/格式改写/简单摘要用小模型（成本 1/10~1/50），复杂推理/长文综合/关键生成用大模型；路由器按难度把请求分发到不同档位，整体成本可降 50%~80%。
- 路由实现：规则路由（类型可预测的任务：模板化改写→小模型，成本低零延迟）、分类器路由（小模型先判难度/类型再分发）、级联路由（先小模型试，置信度不够自动升级大模型——质量兜底）、Agent 内路由（同一任务的不同步骤用不同模型：规划用大模型，格式化用小模型）。
- 置信度判据：小模型输出的自一致性/结构校验通过率/judge 快评——级联的关键是"升级判据"要可靠，误升级浪费钱，漏升级伤质量。
- 护栏与评测：分级策略本身要评测（每档的失败率分布），关键链路（支付/医疗）禁止降级或只允许白名单降级；成本节省与质量损失一起看，形成分级策略的 ROI 表。

```javascript
async function routedLLM(task) {
  const { route, conf } = await classifier(task);
  if (route === 'small') {
    const out = await smallModel(task);
    if (await validate(out, task) && conf > 0.85) return out;
  }                                   // 级联升级
  return largeModel(task);
}
// Agent 内：规划/关键步骤→大模型；
// 格式化/简单工具传参→小模型。
```
