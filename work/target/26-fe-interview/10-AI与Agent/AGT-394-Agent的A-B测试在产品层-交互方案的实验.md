## AGT-394：Agent UI 的交互方案（呈现方式/确认流设计）怎么实验？

**答**:
- 两类实验区分：模型/质量实验（AGT-259：成功率为核心指标）vs 交互实验（呈现方式：步骤时间线 vs 简洁气泡——指标是理解度/信任/操作效率）——两类实验的指标体系完全不同，混在一个实验里无法归因。
- 交互实验的指标族：理解度（用户能否说清 Agent 在做什么——问卷+行为推断）、操作效率（审批耗时/误操作率/打断率）、信任代理指标（采纳率/后续使用留存）、满意度（微调研）——交互实验的目标是"掌控感与效率的平衡点"。
- 实验设计注意：交互习惯的形成期（新交互前 1~2 周有学习成本——剔除学习期或用长期留存判断）、新奇效应（新样式初期点击高）、分段呈现的测量（过程透明信息用户真的看吗——展开率数据）。
- 迭代路径：交互实验的结论进设计规范（AGT-340 范式选择的数据依据）——交互决策从"拍脑袋"变成"有实验依据"。

```text
交互实验要点：
与质量实验分开（指标体系不同）
指标：理解度 / 审批耗时与误操作 /
  采纳与留存 / 微调研满意度
注意：剔除学习期、防新奇效应、
  过程信息的展开率（真有人看吗）
结论 → 设计规范（范式选择的数据化）。
```
