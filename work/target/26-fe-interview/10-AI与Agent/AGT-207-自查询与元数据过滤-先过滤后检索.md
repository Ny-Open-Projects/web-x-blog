## AGT-207：带结构化条件的自然语言查询怎么实现——自查询与元数据过滤？

**答**:
- 问题本质：自然语言里混着语义部分（"关于退款"）与结构化条件（"2024 年""PDF 类型"）——只走向量检索会把所有年份所有类型的"退款"都召回，精度被无关数据稀释。
- 自查询（Self-Query）：让 LLM 把自然语言解析为 `{语义query, 过滤条件}` 结构——`{query:"退款", filter:{year:2024, type:"pdf"}}`，过滤条件下推到向量库的 metadata filter（先过滤后检索或预过滤），语义部分走 embedding。
- 工程要点：过滤字段要入库存好（year/type/dept/权限标签）；时间表达解析要处理相对时间（"最近三个月"→具体区间）；过滤后候选为空时做条件放松（去掉最低优先级条件重试）而不是空答。
- 安全联动：权限类过滤（部门/用户可见性）必须在查询前强制注入，不允许 LLM 决定——LLM 生成的过滤条件只允许收窄，权限条件由系统覆盖。

```javascript
async function selfQuery(nlQuery, user) {
  const { query, filter } = await llm(`
    解析为 JSON：{query: 语义, filter: {year?, type?, dept?}}
    问题：${nlQuery}`);
  // 权限强制注入，覆盖 LLM 输出（只允许收窄）
  const safeFilter = { ...filter, acl: user.acl };
  let docs = await vectorSearch(query, { filter: safeFilter, k: 20 });
  if (!docs.length && filter.year) {          // 条件放松重试
    docs = await vectorSearch(query, { filter: { acl: user.acl }, k: 20 });
  }
  return docs;
}
```
