## AGT-433：手写级联调用：小模型先试、质量验证、升级大模型、全链记账

**需求与边界**：
- 输入：任务、模型档位 [cheap, mid, premium]、验证函数；输出：结果+实际用的模型+成本。
- 边界要求：① 顺序级联，验证通过即停；② 验证含 schema 校验+语义抽检（可插拔）；③ 全部失败返回最高档结果并标注；④ 每档成本独立记账（级联总成本可见）。

**答**：
```javascript
async function cascadeCall({ task, models = ['cheap', 'mid', 'premium'],
  call, validate, pricing }) {
  const ledger = [];                                 // 成本记账
  let last = null;
  for (let i = 0; i < models.length; i++) {
    const model = models[i];
    const r = await call(model, task);
    ledger.push({ model, cost: pricing[model](r.tokens),
      ts: Date.now() });
    const v = await validate(r);                     // 可插拔验证
    if (v.pass)
      return { result: r, model, upgraded: i > 0,
        totalCost: ledger.reduce((s, x) => s + x.cost, 0),
        ledger };
    last = r;                                        // 记录最好/最后结果
  }
  // 全部验证失败：返回最高档结果并标注质量风险
  return { result: last, model: models.at(-1),
    totalCost: ledger.reduce((s, x) => s + x.cost, 0),
    ledger, warning: '所有档位验证未通过，取最高档结果' };
}
// validate 示例：
// const validate = async (r) => ({
//   pass: schemaCheck(r) && (await quickJudge(r)) >= 0.8, ... });
// 护栏：关键任务（白名单）跳过级联直接 premium。
```

**评分点**:
- 级联顺序正确（便宜→贵），验证通过即停（省下的每一档都记账）。
- validate 可插拔（schema+语义快评组合），失败有 warning 标注不静默。
- 关键任务跳过级联的白名单意识。
- ledger 全档成本可见——级联的真实成本（重试叠加）可审计。
