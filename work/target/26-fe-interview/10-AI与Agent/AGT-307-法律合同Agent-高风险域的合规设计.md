## AGT-307：合同审查/法律问答类 Agent 的合规设计要点？

**答**:
- 定位即合规：AI 定位为"辅助工具"而非"法律意见"——产品文案/免责声明/输出标注（"仅供参考，不构成法律意见"）三件套；重大决策必须人工律师终审（AGT-289 责任边界）。
- 能力设计：条款抽取与对比（程序化强项：找风险条款/缺失条款对照清单）、差异比对（新旧版本 diff+风险标注）、条款建议（引用条款库，每条建议带依据条款与适用条件）——AI 做检索对比类，人做判断类。
- 数据安全：合同是最高敏数据——自托管/私有化模型处理、脱敏代理（当事人信息脱敏后分析）、租户隔离（不同客户合同互不可见，AGT-217 权限）。
- 幻觉零容忍：条款编号/法条引用必须程序校验（引用的法条真实存在于法条库——AGT-267 数值治理同类）；错误引用法条的后果远比措辞错误严重。

```text
法律 Agent 合规设计：
定位：辅助工具，非法律意见；
  输出强制标注 + 律师终审
能力分工：AI 做条款抽取/对比/差异/
  引用建议；人做判断与签核
数据：私有化模型 / 脱敏代理 / 租户隔离
幻觉：条款与法条引用程序校验，
  引用不存在即拦截（零容忍）。
```
