## AGT-458：手写记忆注入：按任务相关性检索、冲突消解、结构化注入块

**需求与边界**：
- 输入：当前任务 query、用户记忆库；输出：注入上下文块。
- 边界要求：① 相关性阈值过滤（不相关记忆不注入——省注意力预算）；② 冲突记忆成对注入（新者标"当前"、旧者标"历史"）；③ 注入块结构化（来源/时间/置信度）；④ 注入 token 上限截断保最相关。

**答**：
```javascript
async function injectMemory(query, memory, { budget = 2000 } = {}) {
  const hits = await memory.search(query, { topK: 20 });
  const relevant = hits.filter(h => h.score > 0.4);
  // 冲突消解：同维度冲突 → 新者标当前，旧者标历史
  const resolved = new Map();
  for (const h of relevant.sort((a, b) => b.ts - a.ts)) {
    const key = h.dim ?? h.id;
    const cur = resolved.get(key);
    if (cur && contradicts(cur, h))
      cur.historyNote = { ...h, tag: '历史记录（可能与当前不一致）' };
    else if (!cur) resolved.set(key, { ...h, tag: '当前' });
  }
  // 结构化注入块 + 预算截断
  const items = [...resolved.values()].map(h => ({
    text: h.text, tag: h.tag,
    source: h.source ?? '对话提炼',
    confidence: h.score,
    history: h.historyNote?.text,
  }));
  let used = 0; const kept = [];
  for (const it of items.sort((a, b) => b.confidence - a.confidence)) {
    const t = tokens(JSON.stringify(it));
    if (used + t > budget) break;
    kept.push(it); used += t;
  }
  return {
    block: { type: 'memory', items: kept,
      note: '以下为用户历史偏好，与本次指令冲突时以指令为准' },
    used, dropped: items.length - kept.length,
  };
}
```

**评分点**:
- 相关性阈值过滤（省注意力预算）+ 置信度排序截断（预算内保最相关）。
- 冲突成对消解：新者标"当前"、旧者标"历史记录"（不静默覆盖）。
- 注入块结构化（来源/置信度/标签）且带使用说明（指令优先于记忆）。
- dropped 计数返回（可观测注入质量）。
