## AGT-227：一份 500 页的文档要整体理解，超过模型窗口怎么办？

**答**:
- 任务分型决定策略：抽取型（找特定信息）→ 检索定位后只读相关段（RAG）；总结型（全文理解）→ map-reduce 分段摘要再归并（层次摘要）；全文问答型 → 层次索引（RAPTOR）+ 检索。
- Map-Reduce 细节：map 阶段每段独立摘要（并行、便宜模型），reduce 阶段合并摘要生成最终答案——中间摘要会丢细节，reduce 提示中要声明"引用原始段落时回查原文"。
- 迭代精读（refine）：对顺序依赖的内容（合同条款前后引用）用 refine 链——逐段处理，每段带着前面累积的理解继续，保序但串行慢。
- 结构优先：超长文档先取目录/标题结构生成"文档地图"，让任务沿结构导航而不是盲扫——地图本身就是最省 token 的全局理解。

```javascript
async function longDocTask(doc, task) {
  const outline = await llm(`提取文档结构地图`, doc.toc);
  if (task.type === 'summary') {
    const parts = await Promise.all(
      doc.sections.map(s => cheapLLM(`摘要该节`, s)));   // map
    return llm(`基于各节摘要回答：${task.q}`, parts);    // reduce
  }
  if (task.type === 'ordered') {                          // refine 保序
    let acc = '';
    for (const s of doc.sections)
      acc = await llm(`已有理解:${acc}\n新章节:${s}\n更新理解`, task.q);
    return acc;
  }
  return ragAnswer(task.q, doc);                          // 抽取型
}
```
