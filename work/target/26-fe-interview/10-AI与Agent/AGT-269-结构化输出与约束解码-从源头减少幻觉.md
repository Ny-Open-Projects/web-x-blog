## AGT-269：结构化输出（JSON schema）与约束解码怎么降低幻觉与错误率？

**答**:
- 结构化输出的价值：输出被 schema 约束后，模型不能"自由发挥"（漏字段/加废话/改字段名）——下游程序解析可靠，幻觉空间被压缩；配合 function calling 的 schema 强校验，非法输出直接被拒并触发重试。
- 约束解码（受限生成）：在解码层面保证合法——枚举字段只允许从候选集中采样（logits 屏蔽）、正则约束（日期格式）、引用编号只能引用已提供的块——从机制上杜绝"编造枚举值"，比 prompt 恳求有效得多。
- 适用边界：结构化适合抽取/分类/路由/工具调用类任务；开放式生成（写作/解释）强套 schema 反而损伤质量——按任务类型选择，常用"结构外壳+自由正文"混合。
- 工程配合：schema 版本化（演进兼容）、重试策略（校验失败带错误信息重生成 ≤2 次）、枚举候选动态注入（候选来自检索结果而非硬编码，避免候选过时）。

```javascript
const schema = z.object({
  category: z.enum(['billing','tech','account']),  // 约束解码
  orderNo: z.string().regex(/^ORD\\d+$/),          // 正则约束
  citation: z.number().int().max(docs.length),     // 只能引已给块
  confidence: z.number().min(0).max(1),
});
let out = await llmJson(schema);
for (let i = 0; i < 2 && !schema.safeParse(out).success; i++) {
  out = await llmJson(schema, { fix: schema.safeParse(out).error });
}   // 失败带错误重试 ≤2 次，再失败走降级
```
