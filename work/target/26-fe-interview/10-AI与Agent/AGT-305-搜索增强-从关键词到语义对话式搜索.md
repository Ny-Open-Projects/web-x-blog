## AGT-305：传统搜索框升级为 AI 对话式搜索，架构怎么设计？

**答**:
- 意图分流：导航型/简单查询（"小米官网"）直接走传统搜索（快且准）；信息型/复杂问题走 AI 生成（检索+合成）；两者混合（搜索结果页+AI 摘要卡并存）——不是替代而是叠加，AI 摘要卡与传统结果并排。
- 生成质量：检索用站内索引（结构化+向量混合，AGT-203），AI 摘要强引用（每条信息带来源链接，点击可跳原文——搜索场景用户要的是"找到来源"不只是"得到答案"）。
- 会话式搜索：多轮细化（"再便宜点的"）依赖 query 改写（AGT-204）+ 会话上下文注入检索 filter——对话式搜索的体验核心是多轮不丢上下文。
- 指标：AI 卡片的点击率/采纳率 vs 传统结果点击、无点击率变化（AI 满足了需求则无点击是好的）、引用跳出率——对话式搜索的成败看"用户是否更快完成任务"。

```javascript
async function aiSearch(q, session) {
  const intent = await classify(q);        // nav / info / mixed
  const results = await hybridSearch(q, sessionCtx(session));
  if (intent === 'nav') return results;    // 传统结果直出
  const card = await generate(q, results, { cite: 'strict' });
  return { results, aiCard: card };        // 叠加呈现
}
// 指标：aiCard 采纳率 / 无点击率 / 引用跳出率
```
