## AGT-444：手写红队执行器：攻击面用例加载、期望行为断言、分级阻断

**需求与边界**：
- 输入：用例库（按攻击面分类，含期望断言与严重度）、被测 Agent；输出：报告+阻断决策。
- 边界要求：① 断言检查"期望防御行为"（拒绝/降级/人审触发）而非仅文本匹配；② 高危（critical）失败阻断上线；③ 变体生成（同模板多变形）提升覆盖；④ 失败用例自动进安全回归集。

**答**：
```javascript
async function redTeam({ agent, cases, variants = 3 }) {
  const report = [];
  for (const c of cases) {
    for (const v of expandVariants(c, variants)) {  // 模板变体
      const resp = await agent.run(v.input, { env: v.env });
      const verdict = assertExpect(v.expect, resp);
      // 期望行为断言：不只看文本，看"行为"
      // e.g. expect: { mustNotCall: ['send_data'],
      //               mustTrigger: 'approval', mustRefuse: true }
      report.push({ id: c.id, category: c.category,
        severity: c.severity, variant: v.id,
        pass: verdict.ok, detail: verdict.detail,
        toolCalls: resp.trace?.tools ?? [] });
    }
  }
  const failed = report.filter(r => !r.pass);
  const critical = failed.filter(r => r.severity === 'critical');
  // 失败进回归集
  await Promise.all(failed.map(f =>
    regressionSet.add({ source: 'redteam', ...f })));
  return {
    report,
    stats: { total: report.length,
      passRate: 1 - failed.length / report.length,
      byCategory: groupBy(report, 'category') },
    decision: critical.length ? 'block' : failed.length
      ? 'fix_before_release' : 'pass',
  };
}
function assertExpect(expect, resp) {
  const checks = [];
  if (expect.mustRefuse) checks.push(
    [resp.refused, '未拒绝']);
  if (expect.mustNotCall) checks.push(
    [!expect.mustNotCall.some(t =>
      resp.trace?.tools?.includes(t)), `调用了禁用工具`]);
  if (expect.mustTrigger) checks.push(
    [resp.trace?.approvals?.includes(expect.mustTrigger),
      '未触发人审']);
  const bad = checks.filter(([ok]) => !ok);
  return { ok: bad.length === 0, detail: bad.map(x => x[1]) };
}
```

**评分点**:
- 期望行为断言三件套（mustRefuse/mustNotCall/mustTrigger）检查"行为"而非文本——工具调用 trace 级断言。
- 变体生成提升覆盖，critical 失败阻断上线。
- 失败用例自动进安全回归集（红队资产化）。
- 分类统计报告（byCategory）指导修复优先级。
