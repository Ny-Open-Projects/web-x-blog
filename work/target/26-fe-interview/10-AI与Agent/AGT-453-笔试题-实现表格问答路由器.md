## AGT-453：手写表格问答路由：意图分类、数值走引擎、语义走 RAG、引用单元格

**需求与边界**：
- 输入：问题、表格元数据（schema/单位说明）；输出：答案+引用。
- 边界要求：① 意图三分类（查数值/聚合计算/语义理解）；② 数值与计算必须由查询引擎完成（模型只包装语言）；③ 结果带单元格引用（表名+行列号）；④ 查询失败降级为"展示相关表格区域"而非模型口算。

**答**：
```javascript
async function tableQA(question, { classify, genQuery, engine,
  ragTable }) {
  const intent = await classify(question);
  // 查数值 / 聚合 → 查询引擎（防模型口算）
  if (intent.type === 'lookup' || intent.type === 'aggregate') {
    const q = await genQuery(question, intent.type);
    try {
      const r = await engine.run(q, { timeout: 5000,
        readOnly: true });
      return {
        answer: formatAnswer(r, intent.type),
        citation: r.cells.map(c => `${q.table}[${c.row},${c.col}]`),
        unit: q.unitNote,                  // 单位说明（万元/元）
        computedBy: 'engine',              // 标注计算来源
      };
    } catch (e) {
      // 降级：展示相关区域而非让模型算
      const region = await ragTable(question);
      return { answer: '查询失败，以下是可能相关的表格区域：',
        region, error: e.message };
    }
  }
  // 语义理解 → RAG（表格结构保留）
  return ragTable(question);
}
const formatAnswer = (r, type) => type === 'aggregate'
  ? `${r.label}合计为 ${r.value}${r.unit}（${r.rows} 行记录）`
  : `${r.label}为 ${r.value}${r.unit}`;
```

**评分点**:
- 意图路由正确：数值/聚合走查询引擎、语义走 RAG。
- 计算来源标注（computedBy:'engine'）+ 单位说明（防万元/元错位）。
- 单元格级引用（表[行,列]）可溯源。
- 查询失败降级展示区域而非让模型口算——数值幻觉防线完整。
