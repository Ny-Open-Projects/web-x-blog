## AGT-382：AI 能为无障碍（a11y）做什么——双向的增强？

**答**:
- AI 增强无障碍（AI 帮残障用户）：图像自动描述（alt 文本生成——但要人工可修正，自动描述可能错）、复杂图表的语音解读、实时字幕与手语翻译辅助、语音操作界面（AGT-331 语音链路服务运动障碍用户）、读屏优化的内容摘要（长页面的结构化语音导航）。
- 无障碍增强 AI（a11y 帮 AI）：accessibility tree 是 GUI Agent 的核心接口（AGT-332）——语义化与 ARIA 良好的应用同时对 Agent 更友好，a11y 投入有双重回报（AGT-345 同源）。
- AI 的 a11y 风险：AI 生成 UI 忽略可访问性（生成代码的 a11y 校验进 AGT-341 管线）、AI 交互模式本身的不兼容（纯语音交互对听障用户、依赖视觉的确认卡对视障用户——多模态冗余呈现：确认卡同时可读屏/可语音）。
- 评测：a11y 指标纳入产品评测（WCAG 检查+辅助技术实测）——AI 功能的无障碍回归与功能回归同流程。

```text
AI × a11y 双向增强：
AI 帮人：图像描述 / 图表语音解读 /
  实时字幕 / 语音操作 / 读屏摘要
  （自动描述需人工可修正）
a11y 帮 AI：accessibility tree =
  GUI Agent 接口（双重回报）
风险：AI 生成 UI 的 a11y 校验；
  AI 交互的多模态冗余呈现。
评测：WCAG + 辅助技术实测回归。
```
