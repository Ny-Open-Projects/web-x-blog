## AGT-253：除了最终结果，Agent 的执行轨迹怎么评测？

**答**:
- 轨迹指标族：效率（步数/成本/时长 vs 基线）、健康度（循环检测——同工具同参数重复出现；冗余——重复搜索相同关键词）、安全度（危险操作计数：删除/外发/支付类调用次数）、决策质量（每步的工具选择是否在合理集合内——用专家标注的"参考轨迹"做对照）。
- 参考轨迹法：对标准任务人工写出理想轨迹（或由强模型+人工审核生成），评测时计算与参考轨迹的相似度（步骤集合重合度/顺序一致性）——偏差大的段位就是可疑点，但不要求完全一致（多条路径都可能对）。
- 异常模式库：常见失败模式做成检测器（死循环/空转搜索/过早放弃/暴力枚举/遗忘上下文重复提问）——模式库随 badcase 积累持续扩充，形成轨迹层的"静态检查"。
- 轨迹与结果的关系运用：结果对但轨迹差（侥幸成功）与结果错但轨迹好（环境突变）都要单独标记——分别指向"运气"与"能力"，优化方向不同。

```javascript
function evalTrajectory(trace, ref, patterns) {
  return {
    steps: trace.length,
    loop: patterns.loop.detect(trace),        // 同工具同参重复
    redundant: dupRate(trace.searchQueries),
    dangerous: trace.filter(t => RISKY.has(t.tool)).length,
    alignment: sim(trace, ref),               // 与参考轨迹相似度
    flags: patterns.all(trace),               // 异常模式标记
  };
  // 结果对+轨迹差 → 侥幸；结果错+轨迹好 → 环境问题。
}
```
