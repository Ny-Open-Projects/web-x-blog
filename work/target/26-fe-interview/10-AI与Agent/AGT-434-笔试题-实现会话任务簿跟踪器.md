## AGT-434：手写任务簿：从对话抽取待办（谁/做什么/何时）、状态流转、盘点

**需求与边界**：
- 输入：会话轮次 utterance、现有任务簿；输出：更新后的任务簿与提示。
- 边界要求：① 抽取三要素（负责人/事项/时间），缺要素标"待确认"；② 指代解析（"那个事"→匹配现有条目）；③ 状态机（open→done/cancelled）；④ 收尾盘点 API（未结事项清单+提醒）。

**答**：
```javascript
class TaskBook {
  constructor() { this.tasks = []; }
  async update(utterance, round, { extract, resolveRef }) {
    const events = await extract(utterance);   // [{type, who, what, when}]
    const updates = [];
    for (const e of events) {
      if (e.type === 'new_todo') {
        const missing = ['who', 'what', 'when']
          .filter(k => !e[k]);
        const t = { id: uid(), ...e, status: 'open',
          round, needConfirm: missing.length > 0,
          missing };                            // 缺要素待确认
        this.tasks.push(t);
        updates.push({ action: 'add', task: t });
      } else if (e.type === 'done' || e.type === 'cancelled') {
        // 指代解析：模糊引用 → 匹配现有条目
        const target = resolveRef(e, this.tasks);
        if (!target) return { ambiguous: e, updates };  // 解析失败反问
        target.status = e.type;
        target.closedRound = round;
        updates.push({ action: e.type, task: target });
      }
    }
    return { updates, book: this.tasks };
  }
  recap() {                                      // 收尾盘点
    const open = this.tasks.filter(t => t.status === 'open');
    return {
      open,
      needConfirm: open.filter(t => t.needConfirm),
      message: open.length
        ? `还有 ${open.length} 项未结：` +
          open.map(t => `${t.who ?? '?'} 的 ${t.what}`).join('；')
        : '所有事项已结清。',
      stale: open.filter(t =>
        Date.now() - new Date(t.when).getTime() > 0),  // 已过期未结
    };
  }
}
```

**评分点**:
- 三要素抽取与缺失标注（needConfirm+missing），不臆造信息。
- 指代解析失败返回 ambiguous 反问（不猜归属）。
- 状态机 open→done/cancelled 带关闭轮次（可回溯）。
- recap 盘点完整：未结/待确认/已过期三分类，主动提示体验。
