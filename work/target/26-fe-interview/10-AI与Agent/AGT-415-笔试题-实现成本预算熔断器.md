## AGT-415：手写预算熔断：四级检查、部分结果返回、全局降级

**需求与边界**：
- 输入：各级限额 {step, task, user, global}、当前用量；每步调用前检查；输出：允许/熔断+原因。
- 边界要求：① 检查顺序从细到粗；② 熔断返回结构化部分结果（已完成+原因+继续入口）；③ 全局水位 >80% 自动切便宜模型（降级而非拒绝）；④ 熔断事件记录归因。

**答**：
```javascript
class BudgetGuard {
  constructor({ limits, usage, pool }) {
    this.limits = limits; this.usage = usage; this.pool = pool;
    this.events = [];
  }
  // 每步前调用：返回 {allow, model, reason}
  async check(ctx) {
    // 1. 步骤级
    if (ctx.steps >= this.limits.maxSteps)
      return this.stop(ctx, 'max_steps', '达到最大步数');
    // 2. 任务级成本
    if (ctx.taskCost >= this.limits.taskCap)
      return this.stop(ctx, 'task_budget', '单任务成本超限');
    // 3. 用户级日配额
    const u = await this.usage.userDay(ctx.userId);
    if (u >= this.limits.userDaily)
      return this.stop(ctx, 'user_quota', '今日配额用尽');
    // 4. 全局水位：>80% 降级便宜模型，>100% 拒新任务
    const level = this.pool.usageRatio();
    if (level >= 1) return this.stop(ctx, 'global_cap', '平台预算耗尽');
    const model = level > 0.8 ? CHEAP_MODEL : DEFAULT_MODEL;
    if (level > 0.8) this.events.push({ ts: Date.now(),
      type: 'degrade', ratio: level });
    return { allow: true, model };
  }
  stop(ctx, type, reason) {
    this.events.push({ ts: Date.now(), type, reason,
      taskId: ctx.taskId });
    return { allow: false, type, reason,
      partial: {                       // 结构化部分结果
        done: ctx.completedSteps,
        output: ctx.partialOutput,
        resume: { taskId: ctx.taskId, nextStep: ctx.steps } } };
  }
}
// 前端消费 partial：展示已完成部分 + "继续任务"按钮。
```

**评分点**:
- 四级检查顺序正确（步骤→任务→用户→全局），逐级细到粗。
- 熔断返回结构化 partial（done/output/resume）而非裸错误，可续跑。
- 全局水位分级处置：80% 降级模型、100% 才拒绝——降级优先于拒绝。
- 熔断事件全记录（含类型与归因），供后续分析失控模式。
