## AGT-301：企业文档助手（读文档问答/总结/跨文档分析）怎么设计？

**答**:
- 分层架构：简单问答走固定 RAG 管线（快且便宜），复杂任务（跨文档对比/生成报告）升级为 Agent（多轮检索+分解+合成）——意图路由决定走哪层，两层共享同一知识库与引用体系。
- 引用体系是产品核心：每个答案块带可点击来源（文档/页码/高亮，AGT-262），跨文档任务输出"证据清单"——文档助手的信任完全建立在溯源上。
- 文档预处理决定上限：版面解析（标题层级/表格/图表，AGT-214 多模态）、父子块索引（AGT-201）、层级摘要（RAPTOR，AGT-208）——重投入在离线管线，在线层才简单。
- 交互设计：答案区分"事实引用"与"分析推断"两种样式；多文档对比用对照表组件；总结任务给"大纲可展开"的渐进输出——按任务类型定制呈现而非统一对话流。

```text
文档助手分层：
意图路由 → 简单QA：固定RAG（快/便宜）
        → 复杂任务：Agent（分解/多跳/报告）
共享：知识库 / 引用体系 / 评测集
核心：引用可点击溯源（块→页码→高亮）
离线重投入：版面解析 + 父子块 + 层次摘要
呈现：事实 vs 推断分样式、对比表、
  可展开大纲。
```
