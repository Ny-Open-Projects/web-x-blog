## AGT-432：手写增量索引：内容 hash 跳过、块级 diff、软删除与版本切换

**需求与边界**：
- 输入：新文档、当前版本记录 {hash, chunks}；输出：索引变更集。
- 边界要求：① 文档 hash 未变直接跳过；② 块级 diff（新分块与旧块 hash 对比，只嵌入变更块）；③ 删除走软删除（检索端过滤，异步物理清理）；④ 版本号原子发布（缓存联动）。

**答**：
```javascript
async function incrementalIndex(doc, { getVersion, upsert,
  softDelete, publish }) {
  const old = await getVersion(doc.id);
  const docHash = sha256(doc.text);
  if (old?.hash === docHash)
    return { skipped: true, version: old.version };  // 未变跳过
  // 1. 分块 + hash
  const newChunks = chunk(doc.text).map((c, i) => ({
    id: `${doc.id}:${i}`, docId: doc.id, text: c,
    hash: sha256(c), order: i }));
  // 2. 块级 diff
  const oldChunks = old?.chunks ?? [];
  const oldHashes = new Map(oldChunks.map(c => [c.hash, c]));
  const added = newChunks.filter(c => !oldHashes.has(c.hash));
  const keptOld = oldChunks.filter(c =>
    newChunks.some(n => n.hash === c.hash));         // 未变块保留原嵌入
  // 3. 删除：旧有新无 → 软删除（异步物理清理）
  const removed = oldChunks.filter(c =>
    !newChunks.some(n => n.hash === c.hash));
  // 4. 并行嵌入新增块（限并发）
  const embedded = await pool(added, 5, c => upsert({
    ...c, embedding: await embed(c.text),
    docVer: docHash }));                             // 块带文档版本
  await Promise.all(removed.map(c => softDelete(c.id)));
  // 5. 版本原子发布（新版本含 kept+added，检索端按版本过滤）
  const version = await publish(doc.id, docHash, [...keptOld, ...embedded]);
  return { skipped: false, version,
    added: added.length, removed: removed.length,
    reused: keptOld.length };                        // 复用统计
}
```

**评分点**:
- 两级跳过：文档 hash 未变全跳、块 hash 相同复用原嵌入（只嵌入变更块）。
- 删除走软删除+异步清理（检索一致性保障），块带文档版本号（缓存联动）。
- 统计输出（added/removed/reused）可监控管线效率。
- 分块并发限流（pool 模式）。
