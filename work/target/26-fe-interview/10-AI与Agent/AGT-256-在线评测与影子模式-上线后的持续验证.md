## AGT-256：Agent 上线后，线上质量怎么持续监控与验证？

**答**:
- 在线指标三层：用户层（采纳率/重试率/负反馈率/任务完成后的转化）、系统层（成功率/超时率/成本分布）、质量抽样（每天随机抽 N 条真实轨迹跑离线评测——线上没有金标，抽样评审是主要质量信号）。
- 影子模式（shadow）：新版本与线上版本并行跑相同流量（影子结果不返给用户只记录）——真实流量下的零风险对比，特别适合新 prompt/新模型上线前的最后验证；注意影子成本翻倍，按比例抽样影子即可。
- 反馈闭环：用户负反馈（点踩/改写/中断）自动进 badcase 队列，聚类归因后转入回归集——线上真实失败是最有价值的评测资产。
- 告警设计：指标带护栏阈值（采纳率跌破基线 X%、成本超预算 Y%）分级告警；上线当天自动回滚开关（指标异常即切回旧版）。

```javascript
// 影子对比 + 在线抽样评测
async function shadow(request) {
  const prod = await run(VERSIONS.prod, request);
  if (Math.random() < 0.1) {                     // 10% 影子
    const cand = await run(VERSIONS.candidate, request);
    await shadowLog({ request, prod, cand,
      verdict: await judgePair(prod, cand) });   // 只记录不返回
  }
  return prod;
}
// 每日抽 200 条真实轨迹 → 离线 rubric 评分
// 负反馈 → badcase 队列 → 周聚类归因 → 回归集
```
