## AGT-273：输入 token 的降本手段有哪些——优先级怎么排？

**答**:
- 第一杠杆：前缀缓存（AGT-224）——稳定内容前置，缓存价约 1/10，对长系统提示+长历史场景立竿见影，且零质量损失，优先级最高。
- 第二杠杆：历史与结果压缩（AGT-222/226）——滑动窗口+摘要、工具结果结论化，直接减少每轮重发的 token；有少量信息损失风险，需忠实性校验。
- 第三杠杆：检索精度（AGT-202 rerank）——召回 6 块精排比召回 30 块粗拼便宜且质量更高；rerank 成本远小于多余 token 的生成成本。
- 其他手段：prompt 瘦身（删冗余指令/示例，定期审计）、结构化压缩格式（表格/紧凑 JSON 代替自然语言罗列）、RAG 上下文压缩（AGT-212）——细节优化按收益排期，避免过度工程。

```javascript
async function cheapContext(query, history) {
  // 1. 前缀缓存：稳定部分在前
  const prefix = [SYS, ...stableKnowledge];
  // 2. 历史压缩：超预算才触发
  const hist = tokens(history) > HIST_BUDGET
    ? await compactHistory(history) : history;
  // 3. 精准检索：rerank 后只取 top6
  const docs = (await rerank(await retrieve(query, 30), query)).slice(0, 6);
  return [...prefix, ...hist, { role: 'user', content: query + ctx(docs) }];
}
```
