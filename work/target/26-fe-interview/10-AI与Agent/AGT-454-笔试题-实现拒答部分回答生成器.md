## AGT-454：手写"部分回答"生成：已知/未知/需补充三段结构，不裸拒也不编造

**需求与边界**：
- 输入：query、检索结果（含分数）、缺失分析；输出：结构化拒答/部分回答。
- 边界要求：① 分离已知（低分相关片段标注"未充分验证"）、未知（缺口具体描述）、需补充（用户可提供什么）；② 高危域（医疗/法律/资金）附加专业咨询引导；③ 前提错误的问题先纠正前提。

**答**：
```javascript
async function partialAnswer(query, docs, { riskDomain, analyzeGap }) {
  const relevant = docs.filter(d => d.score > 0.3).slice(0, 2);
  const gap = await analyzeGap(query, docs);   // 缺什么
  const parts = {
    known: relevant.length ? {
      note: '以下为相关片段（未经充分验证）：',
      items: relevant.map(d => ({ text: d.text.slice(0, 200),
        source: d.id })) } : null,
    unknown: gap.missing.length
      ? `无法回答：${gap.missing.join('、')} 相关信息不足`
      : null,
    ask: gap.needFromUser.length
      ? `您可以补充：${gap.needFromUser.join(' / ')}` : null,
  };
  // 高危域附加引导
  const disclaimer = riskDomain(query)
    ? '\n⚠ 该主题涉及专业判断，建议咨询专业人士。'
    : '';
  // 前提纠错：问题含错误预设
  if (gap.wrongPremise)
    return { type: 'premise_correction',
      message: `先说明：${gap.wrongPremise.correct}（您的提问假设了 ${gap.wrongPremise.wrong}）`,
      ...parts };
  if (!parts.known && !parts.unknown)
    return { type: 'answer', message: '正常回答流程' };
  return { type: 'partial', parts, disclaimer,
    principle: '部分可靠信息 + 明确缺口 + 补充引导，不编造' };
}
```

**评分点**:
- 三段结构（已知[标注未验证]/未知[具体化]/请补充）——既不裸拒也不编造。
- 高危域自动附加专业咨询声明。
- 前提纠错优先于回答（先纠正错误预设）。
- 缺口描述具体化（analyzeGap 输出 missing/needFromUser），拒答可操作。
