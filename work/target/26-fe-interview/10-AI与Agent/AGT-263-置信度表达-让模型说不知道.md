## AGT-263：模型总是一副很笃定的样子，怎么让它诚实表达不确定性？

**答**:
- 三层手段：行为层（prompt 明确"资料不足时必须说不确定，宁可拒答"——但 LLM 的自我声明可靠性有限）、结构层（强制输出 schema 带 confidence 字段+依据清单，程序读取决策）、信号层（用可观测信号估计置信度：检索命中分数低/多次采样答案分歧大/token 概率低→判低置信）。
- 自一致性采样：同一问题采样 N 次（不同温度），答案一致→置信高；分歧大→置信低——简单有效的置信度代理，成本是 N 倍调用（用小模型或抽样触发）。
- 校准问题：模型自报的 confidence 数值本身不可信（几乎总是 0.9）——必须用外部信号（检索分数/采样一致性/下游校验结果）构建置信度，并用历史数据校准阈值。
- 呈现策略：低置信答案不是不给，而是"带警告给"（"以下信息可能有误，建议核实：__"）+ 引导用户补充信息——把不确定性变成交互机会而不是静默错误。

```javascript
async function withConfidence(query) {
  const answers = await Promise.all(
    Array.from({ length: 3 }, () => llm(query, { temp: 0.7 })));
  const consistency = agreement(answers);          // 采样一致性
  const retScore = (await retrieve(query))[0]?.score ?? 0;
  const conf = 0.5 * consistency + 0.5 * retScore; // 外部信号合成
  if (conf < 0.5) return hedge(answers[0]);        // 带警告
  return answers[0];
}
// 阈值用历史标注数据校准，不信模型自报值。
```
