## AGT-408：手写双层缓存：精确命中、语义命中、权限隔离、失效联动

**需求与边界**：
- 输入：请求 {prompt, model, promptVer, userAcl}、embedding 函数、缓存后端；输出：缓存答案或 null（未命中）。
- 边界要求：① 精确 key 含全部影响因子（用户 ACL/版本）；② 语义命中要求相似度 ≥0.95 且 ACL 兼容（只命中"权限包含自己可见范围"的缓存项）；③ 数字敏感请求禁用语义缓存；④ 知识版本变更时批量失效。

**答**：
```javascript
class LLMCache {
  constructor({ embed, simThreshold = 0.95 }) {
    this.exact = new Map();          // key -> {answer, acl, ver}
    this.sems = [];                  // {vec, answer, acl, ver, numeric}
    this.embed = embed; this.simThreshold = simThreshold;
  }
  async get({ prompt, model, promptVer, userAcl, numericSensitive }) {
    const key = hash([prompt, model, promptVer, ...userAcl.sort()]);
    if (this.exact.has(key)) return { ...this.exact.get(key), type: 'exact' };
    // 语义层：数字敏感直接跳过
    if (!numericSensitive) {
      const vec = await this.embed(prompt);
      for (const it of this.sems) {
        if (it.ver !== promptVer) continue;                 // 版本失效
        if (!it.acl.every(t => userAcl.includes(t))) continue; // ACL 兼容
        if (cosine(vec, it.vec) >= this.simThreshold)
          return { ...it.answer, type: 'semantic' };
      }
    }
    return null;
  }
  async put({ prompt, model, promptVer, userAcl, numericSensitive }, answer) {
    const key = hash([prompt, model, promptVer, ...userAcl.sort()]);
    this.exact.set(key, answer);
    if (!numericSensitive)
      this.sems.push({ vec: await this.embed(prompt), answer,
        acl: userAcl, ver: promptVer });
  }
  invalidateByVersion(ver) {                     // 知识版本联动失效
    this.sems = this.sems.filter(s => s.ver !== ver);
    for (const [k, v] of this.exact)
      if (v.ver === ver) this.exact.delete(k);
  }
}
```

**评分点**:
- 精确 key 含 ACL 与版本全因子（防越权与脏缓存）。
- 语义命中三重校验：相似度阈值、版本一致、ACL 兼容（只复用权限不超过自己的缓存）。
- 数字敏感请求跳过语义层（数值错配风险规避）。
- 版本联动失效同时覆盖两层缓存。
