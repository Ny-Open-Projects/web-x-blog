## AGT-423：手写前端 delta 渲染缓冲：rAF 合帧、seq 重排、错误保留半成品

**需求与边界**：
- 输入：SSE 事件流回调；输出：按帧批量渲染 API。
- 边界要求：① delta 合帧（rAF 时机批量 flush，避免 token 级 setState）；② 乱序事件按 seq 重排（缺口等待或跳过标记）；③ error/cancelled 事件终止流但保留已渲染内容；④ 页面隐藏时暂停渲染积压（可见性联动）。

**答**：
```javascript
function createStreamRenderer({ onFrame, onError }) {
  const pending = new Map();      // seq -> ev（重排缓冲）
  let nextSeq = 0, rafId = null, dirty = false;
  function schedule() {
    if (rafId == null)
      rafId = requestAnimationFrame(flush);
  }
  function flush() {
    rafId = null;
    const batch = [];
    while (pending.has(nextSeq)) {
      batch.push(pending.get(nextSeq));
      pending.delete(nextSeq); nextSeq++;
    }
    if (batch.length) {
      const text = batch.filter(e => e.type === 'delta')
        .map(e => e.payload).join('');
      if (text) onFrame(text);                     // 批量渲染
      batch.filter(e => e.type !== 'delta')
        .forEach(e => handleEvent(e));
    }
    if (pending.size) schedule();                  // 还有缺口等下一帧
    dirty = false;
  }
  function handleEvent(e) {
    if (e.type === 'error' || e.type === 'cancelled') {
      onError(e);                                  // 保留已渲染内容
      pending.clear();
    }
  }
  return {
    push(ev) {
      if (ev.seq < nextSeq) return;                // 重复事件丢弃
      pending.set(ev.seq, ev); dirty = true;
      if (pending.has(nextSeq)) schedule();
      // 缺口等待：超 500ms 未补齐则跳号（服务端丢失兜底）
      clearTimeout(this._gapTimer);
      this._gapTimer = setTimeout(() => {
        if (pending.size && !pending.has(nextSeq)) {
          nextSeq = Math.min(...[...pending.keys()]);   // 跳号继续
          schedule();
        }
      }, 500);
    },
    pause() { if (rafId != null) { cancelAnimationFrame(rafId); rafId = null; } },
    resume() { if (dirty && rafId == null) schedule(); },
  };
}
// document.visibilitychange → pause/resume（后台标签页省电）。
```

**评分点**:
- rAF 合帧批量渲染（token 级 setState 防卡顿），空闲帧无任务不空转。
- seq 重排缓冲 + 缺口超时跳号兜底（服务端丢帧不永久卡住）。
- error/cancelled 保留已渲染内容并清缓冲（半成品不整块清除）。
- 页面可见性联动 pause/resume（后台标签页资源优化）。
