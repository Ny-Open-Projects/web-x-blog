## AGT-350：Agent 从 POC 到规模化生产的路线图怎么规划？

**答**:
- 五阶段路线：POC（2~4 周：验证可行性，低标准通过即可——重点是"值得做"的判断）→ Alpha（评测集建立+核心链路加固+内部试用，发现真实 badcase）→ Beta（影子/小流量灰度+护栏完善+反馈闭环，AGT-256）→ 生产（门禁/监控/SRE/成本归因全量化，AGT-326/328）→ 规模化（平台化/多场景复制/治理成熟，AGT-328）——每阶段有明确的退出标准（exit criteria），不达标不进下一阶段。
- 各阶段重心差异：POC 期唯一目标是验证价值假设（别过早优化工程质量）；Beta 期唯一目标是信任建立（可靠性/透明/渐进授权）；规模化期唯一目标是复用效率（平台化降低下一个场景的成本）。
- 时间预期管理：POC 到生产通常 3~6 个月（比传统功能慢——评测/安全/治理的必修课），向业务方管理预期（"AI 功能上线快"是最大的预期陷阱）。
- 回顾机制：每阶段末做 go/no-go 评审（价值验证了吗/指标达标吗/风险可控吗）——砍掉不值得的 Agent 比硬着头皮上线更专业。

```text
Agent 落地五阶段：
POC（2-4周）：验证价值假设
Alpha：评测集 + 加固 + 内部试用
Beta：影子灰度 + 护栏 + 反馈闭环
生产：门禁 / SRE / 成本归因
规模化：平台化 / 场景复制 / 治理成熟
每阶段有 exit criteria，
  阶段末 go/no-go 评审；
  POC→生产预期 3~6 个月。
```
