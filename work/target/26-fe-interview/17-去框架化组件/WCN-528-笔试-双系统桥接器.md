## WCN-528：笔试：实现两套 signal 系统之间的「桥接器」（A 写 → B effect 响应，带循环防护）。

**答**：
- 结论：桥接器订阅 A 的写，写入 B；用同步标记位防止 B 的 effect 再次触发 A 造成循环。
- 支持方向与转换器（transform），可映射值格式；提供 dispose 解除订阅。
- 批量：A 的多次写在微任务中合并为一次 B 写入，避免中间态。
- 追问：如何检测「桥接循环」并告警而非静默吞掉？

```javascript
function createBridge(sigA, sigB, { transform = v => v, batch = true } = {}) {
  let inFlight = false, pending, timer = null;
  function apply(v) {
    if (inFlight) { console.warn('[bridge] 检测到回环写入，已阻断'); return; }
    inFlight = true;
    sigB.set(transform(v));
    inFlight = false;
  }
  const unsub = sigA.subscribe(v => {
    if (!batch) return apply(v);
    pending = v;
    if (timer) return;
    timer = queueMicrotask(() => { const val = pending; timer = null; apply(val); });
  });
  return { dispose: unsub };
}
```

**评分点**：
- 单向订阅 + 循环防护标记
- transform 值映射
- 微任务批量合并
- dispose 解除订阅
