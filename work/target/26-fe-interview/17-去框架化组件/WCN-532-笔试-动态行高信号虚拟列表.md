## WCN-532：笔试：实现动态行高的信号化虚拟列表（每行 signal + 测量缓存 + 窗口重算）。

**答**：
- 结论：每行独立高度信号 + 测量缓存，滚动时二分定位可见窗口，高度变化增量更新前缀和。
- 测量缓存：同一行已测高度直接复用，避免重复 layout 读取。
- 窗口重算在 rAF 中合并，避免滚动高频触发多次。
- 追问：如何支持「展开/折叠」行导致高度剧变？（答：把展开态也做成信号，变化时触发该行重测）

```javascript
function signal(v) { const s = { v, subs: [] }; s.get = () => s.v;
  s.set = x => { if (x === s.v) return; s.v = x; s.subs.forEach(f => f()); }; return s; }
function createVirtualList(items, estimate = 40) {
  const heights = items.map(() => signal(estimate));
  const measured = new Map();
  const prefix = signal(() => heights.reduce((acc, h) => [...acc, acc.at(-1) + h.get()], [0]));
  let raf = 0;
  function remeasure(i, h) { measured.set(i, h); heights[i].set(h); if (!raf) raf = requestAnimationFrame(() => { prefix.set(); raf = 0; }); }
  function window_(top, vp) {
    const ps = prefix.get(); let lo = 0, hi = ps.length - 1;
    while (lo < hi) { const mid = (lo + hi) >> 1; ps[mid + 1] <= top ? lo = mid + 1 : hi = mid; }
    let end = lo; while (end < ps.length - 1 && ps[end] < top + vp) end++;
    return [lo, end];
  }
  return { remeasure, window: window_, measured };
}
```

**评分点**：
- 每行独立高度信号
- 测量缓存复用
- 前缀和二分定位窗口
- rAF 合帧重算
