## WCN-661：编译阶段如何做副作用分析（purity analysis）并输出摇树标记？

**答**：
- 结论：分析函数是否修改外部状态/抛错/依赖全局；纯函数可标 PURE，未使用的纯调用可安全删除。
- 做法：构建调用图，传播 purity（调用纯函数仍纯）；访问全局/参数对象属性的写操作视为副作用；输出 /*#__PURE__*/ 注释供打包器识别。
- 追问钩子：为什么递归调用需要不动点迭代？因为 purity 沿调用链传播——考察对静态分析算法的了解。

```javascript
function analyzePurity(functions) {
  const pure = new Set();
  let changed = true;
  while (changed) { // 不动点迭代：purity 沿调用链传播
    changed = false;
    for (const [name, fn] of Object.entries(functions)) {
      if (pure.has(name)) continue;
      const callsPure = (fn.calls || []).every(c => pure.has(c));
      const noSideEffect = !fn.writesGlobal && !fn.throws && callsPure;
      if (noSideEffect) { pure.add(name); changed = true; }
    }
  }
  return pure;
}
const fns = {
  add: { calls: [], writesGlobal: false },
  wrap: { calls: ['add'], writesGlobal: false },
  log: { calls: [], writesGlobal: true },
};
console.log([...analyzePurity(fns)]); // ['add','wrap']：可标 PURE
```
