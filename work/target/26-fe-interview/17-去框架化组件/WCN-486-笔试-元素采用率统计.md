## WCN-486：笔试：实现元素的采用率统计（每页面使用清单）。
**题目**：MutationObserver 监听元素插入：统计每页面各 tag 使用次数；输出 topN 与零使用元素（对照全量清单）——下线候选。

```javascript
const usage = new Map();
new MutationObserver((muts) => {
  for (const m of muts) for (const n of m.addedNodes)
    if (n.nodeType === 1 && n.tagName.includes('-'))
      usage.set(n.tagName.toLowerCase(), (usage.get(n.tagName.toLowerCase()) || 0) + 1);
}).observe(document.body, { childList: true, subtree: true });
function report(page) {
  const top = [...usage].sort((a, b) => b[1] - a[1]).slice(0, 10);
  const all = catalog.allTags();
  const unused = all.filter(t => !usage.has(t));   // 下线候选
  return { page, top, unused };
}

```

**评分点**：
- Observer 性能（只监听自定义元素插入——子树过滤简化说明）。
- 按页面路由打标（location.pathname）。
- topN + 零使用对照。
- 上报采样与聚合周期。
