## WCN-543：信号持久化工程：哪些信号该持久化、何时快照、版本迁移如何处理？

**答**：
- 结论：只持久化「用户意图态」（筛选条件/草稿/展开状态），不持久化派生值与临时 UI 态。
- 快照时机：变化节流（如 500ms）+ 页面隐藏时立即 flush，避免频繁写 localStorage。
- 版本迁移：存储带 schema 版本，读取时按版本链升级老数据；不兼容则丢弃并告警。
- 追问：多标签页同时写同一 key 怎么办？（答：storage 事件同步 + 最后写入胜出或 LWW 时间戳）

```javascript
function persist(sig, key, { version = 1, migrate = x => x, delay = 500 } = {}) {
  let timer;
  const raw = localStorage.getItem(key);
  if (raw) { const { v, data } = JSON.parse(raw); sig.set(v === version ? data : migrate(data)); }
  sig.subscribe(v => {
    clearTimeout(timer);
    timer = setTimeout(() => localStorage.setItem(key, JSON.stringify({ v: version, data: v })), delay);
  });
  window.addEventListener('pagehide', () => localStorage.setItem(key, JSON.stringify({ v: version, data: sig.get() })));
}
```
