## WCN-431：笔试：实现动态列表的焦点恢复（重渲染后焦点回位）。
**答**：元素列表重渲染前记录 document.activeElement（在列表内）；渲染后按「item id + 焦点在项内偏移」恢复焦点；找不到 → 回退到列表容器。

```javascript
function rerenderWithFocus(list, renderFn) {
  const active = document.activeElement;
  const item = active?.closest('[data-id]');
  const inner = item && active !== item
    ? [...item.querySelectorAll('*')].indexOf(active) : -1;
  renderFn();
  if (item) {
    const again = list.querySelector(`[data-id="${item.dataset.id}"]`);
    const target = inner >= 0 ? again?.querySelectorAll('*')[inner] : again;
    (target ?? list).focus({ preventScroll: true });   // 恢复或回退容器
  }
}

```

**评分点**：
- 焦点记录（id + 内部选择器）。
- 渲染后 querySelector 恢复。
- 恢复失败回退容器（focus({preventScroll})）。
- 键盘场景断言（Tab 流不因重渲染丢失）。
