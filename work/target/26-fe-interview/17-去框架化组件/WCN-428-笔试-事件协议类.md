## WCN-428：笔试：实现元素的事件协议辅助器（类型化 CustomEvent + 自动清理）。
**题目**：`emitter(el)`：`emit(name, detail)` 派发 composed CustomEvent；`on(name, h)` 记录监听，元素断开时自动移除全部（防泄漏）。

```javascript
function emitter(el) {
  const listeners = [];
  return {
    emit(name, detail) {
      el.dispatchEvent(new CustomEvent(name, { detail, bubbles: true, composed: true }));
    },
    on(name, h, { once = false } = {}) {
      el.addEventListener(name, h, { once });
      listeners.push([name, h]);
      return () => { el.removeEventListener(name, h); };
    },
    dispose() { listeners.forEach(([n, h]) => el.removeEventListener(n, h)); },
  };
}
class X extends HTMLElement {
  #bus = emitter(this);
  connectedCallback() { this.#bus.on('add-cart', () => this.#bus.emit('requested', { ok: true })); }
  disconnectedCallback() { this.#bus.dispose(); }   // 自动清理
}

```

**评分点**：
- emit：bubbles+composed 默认 true（跨 shadow 到宿主）。
- on 登记表：disconnectedCallback 统一 removeEventListener。
- detail 类型化文档（TS 层面）。
- once 选项支持。
