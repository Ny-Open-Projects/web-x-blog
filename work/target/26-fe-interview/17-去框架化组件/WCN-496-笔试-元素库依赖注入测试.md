## WCN-496：笔试：实现元素依赖注入（dataProvider/clock）的测试套件。
**题目**：测试：① 注入 fake 后元素行为（渲染 fake 数据）② 未注入走默认（真实通道在测试环境被拦截报错——防意外真请求）③ clock 注入时间敏感行为。

```javascript
test('fake 数据渲染', async () => {
  GoodsCard.dataProvider = async () => ({ title: 'FAKE', price: 1 });
  const { el } = await createFixture('goods-card', { sku: 'A1' });
  await expect(el.shadowRoot.textContent).toContain('FAKE');
});
test('测试环境禁真网', () => {
  delete GoodsCard.dataProvider;
  expect(() => new GoodsCard().load()).toThrow(/测试环境禁止默认通道/);
});
test('时钟注入', () => {
  DsClock.now = () => new Date('2026-01-01');
  const el = new DsCountdown({ until: '2026-01-02' });
  expect(el.remainingText).toBe('23h');   // 冻结时钟断言
});

```

**评分点**：
- 注入点声明与替换。
- 默认通道测试环境强制报错（防真网）。
- 时间敏感（过期态）冻结时钟断言。
- 套件结构（三用例模板）。
