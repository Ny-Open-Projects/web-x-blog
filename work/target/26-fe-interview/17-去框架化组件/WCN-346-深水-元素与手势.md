## WCN-346：复杂手势（拖拽排序/双指缩放）在元素中的实现与降级？
**答**：
- Pointer Events 统一（touch/mouse 一套），setPointerCapture 处理指针丢失。
- 触控增强：touch-action CSS 约定（防页面滚动劫持）。
- 降级：无 Pointer（老 WebView）→ touch/mouse 适配层；键盘可达（拖拽的键盘替代：上下移按钮）。
- 性能：move 事件 rAF 合帧（一帧最多处理一次）。

```javascript
onPointerDown(e) { this.setPointerCapture(e.pointerId); this._rafPending = false; }
onPointerMove(e) {
  if (this._rafPending) return;
  this._rafPending = true;
  requestAnimationFrame(() => { this._applyDrag(e); this._rafPending = false; });
}
```
