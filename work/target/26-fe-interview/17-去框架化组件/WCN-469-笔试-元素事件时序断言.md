## WCN-469：笔试：实现元素事件的时序断言（事件顺序确定）。
**题目**：录制元素派发的事件序列（tag+name+detail 摘要）；断言期望顺序（数组精确匹配或 contains 语义）；超时未到 → 失败附已收到序列。

```javascript
function eventRecorder(el, names) {
  const seq = [];
  const offs = names.map(n => el.addEventListener(n, (e) =>
    seq.push({ n, d: JSON.stringify(e.detail).slice(0, 40) })));
  return {
    seq: () => seq,
    expectOrder(expected, { contains = false } = {}) {
      const got = seq.map(x => x.n);
      const ok = contains
        ? expected.every(n => got.includes(n))
        : JSON.stringify(got) === JSON.stringify(expected);
      if (!ok) throw new Error(`事件顺序不符\n期望 ${expected}\n实得 ${got}`);
    },
    dispose: () => offs.forEach(f => f()),
  };
}

```

**评分点**：
- 录制器（事件监听收集）。
- 顺序断言（精确/包含两种语义）。
- 超时附已收序列（诊断）。
- detail 摘要截断。
