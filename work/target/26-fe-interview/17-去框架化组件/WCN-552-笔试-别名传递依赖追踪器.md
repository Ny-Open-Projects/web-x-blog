## WCN-552：编译期「别名/传递依赖」追踪器（含对象属性解构别名）怎么实现？

**答**：
- 结论：遍历 AST 建立作用域化绑定表，识别三种别名：直接赋值、解构、属性引用，统一解析到信号源。
- 作用域用栈管理，块结束弹出绑定，避免跨块误判。
- 解析失败（如动态属性 obj[key]）标记 unknown，交运行时兜底。
- 追问：如何输出「表达式依赖了哪些信号」供后续标记？

```javascript
function analyzeAliases(ast) {
  const stack = [{ bindings: new Map() }];       // 作用域栈
  function bind(name, target) { stack.at(-1).bindings.set(name, target); }
  function resolve(name) {
    for (let i = stack.length - 1; i >= 0; i--)
      if (stack[i].bindings.has(name)) return unwrap(stack[i].bindings.get(name), i);
    return { unknown: true, name };
  }
  function unwrap(t, i) {
    while (t?.kind === 'alias') t = stack[i].bindings.get(t.to) || { unknown: true, name: t.to };
    return t;
  }
  walk(ast, {
    VariableDeclarator(n) {
      if (n.id.type === 'Identifier') bind(n.id.name, { kind: 'alias', to: n.init.name });
      if (n.id.type === 'ObjectPattern') n.id.props.forEach(p => bind(p.value.name, { kind: 'alias', to: `${n.init.name}.${p.key.name}` }));
    },
    CallExpression(n) { n.deps = [resolve(n.callee.name)]; },
  });
  return ast;
}
```
