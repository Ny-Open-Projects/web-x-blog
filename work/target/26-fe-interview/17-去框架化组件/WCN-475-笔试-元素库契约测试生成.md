## WCN-475：笔试：实现「元素 API 契约」的运行时校验器（消费方声明依赖）。
**答**：消费方声明 `needs: {tag: {props: [], events: []}}`。运行时校验：元素存在 + property 可写（setter 存在）+ 事件可通过派发验证（构造测试事件）。输出契约缺口。

```javascript
function verifyContract(needs) {
  const gaps = [];
  for (const [tag, spec] of Object.entries(needs)) {
    const Impl = customElements.get(tag);
    if (!Impl) { gaps.push({ tag, why: '未注册' }); continue; }
    const proto = Impl.prototype;
    for (const p of spec.props || [])
      if (typeof Object.getOwnPropertyDescriptor(proto, p)?.set !== 'function')
        gaps.push({ tag, why: `property ${p} 无 setter` });
    const probe = document.createElement(tag);
    for (const ev of spec.events || []) {
      let got = false;
      probe.addEventListener(ev, () => got = true, { once: true });
      probe.dispatchEvent(new CustomEvent(ev));
      if (!got) gaps.push({ tag, why: `事件 ${ev} 无法派发验证` });
    }
  }
  return { ok: gaps.length === 0, gaps };
}

```

**评分点**：
- 契约声明结构（tag → props/events）。
- property setter 存在检测（原型链查找）。
- 事件契约验证（派发测试事件可被监听）。
- 缺口清单（升级守门依据）。
