## WCN-570：笔试：实现「常量表达式折叠器」（支持字面量运算 + 消除恒 false 的 if 分支）。

**答**：
- 结论：递归遍历 AST，对纯字面量二元表达式求值并替换为 Literal；对条件为字面量的 if 只保留命中分支。
- 折叠前检查子树无响应式引用与副作用，否则跳过。
- 消除分支时保留原始位置信息用于 sourcemap。
- 追问：如何避免 eval 安全问题？（答：用算子白名单表，只实现 + - * / > < == 等，不用 eval）

```javascript
const OPS = { '+': (a,b)=>a+b, '-': (a,b)=>a-b, '*': (a,b)=>a*b, '>': (a,b)=>a>b, '==': (a,b)=>a==b };
function hasReactive(n) { return n.type === 'CallExpression' && /signal|\$\w/.test(n.name || ''); }
function fold(node) {
  if (hasReactive(node)) return node;                    // 含响应式不折叠
  if (node.type === 'BinaryExpression' && node.left.type === 'Literal' && node.right.type === 'Literal' && OPS[node.op])
    return { type: 'Literal', value: OPS[node.op](node.left.value, node.right.value), src: node.src };
  if (node.type === 'IfStatement' && node.test.type === 'Literal')
    return fold(node.test.value ? node.consequent : node.alternate || { type: 'Empty', src: node.src });
  if (node.children) node.children = node.children.map(fold);
  return node;
}
```

**评分点**：
- 字面量二元运算白名单求值
- 恒 false 分支消除
- 响应式引用跳过折叠
- 位置信息保留给 sourcemap
