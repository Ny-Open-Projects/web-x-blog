## WCN-446：笔试：实现元素内图片懒加载（IntersectionObserver + 解码后淡入）。
**题目**：`lazyImg(el, src)`：进入视口前 200px 触发加载；load 后 decode() 再显示（防解码卡顿）；失败降级占位 + 重试一次。

```javascript
function lazyImg(container, src) {
  const img = new Image();
  let retried = false;
  img.loading = 'eager';
  const io = new IntersectionObserver((es) => {
    if (!es[0].isIntersecting) return;
    io.disconnect();
    img.src = src;
    img.decode().then(() => { img.style.opacity = '1'; container.append(img); })
      .catch(() => {
        if (!retried) { retried = true; img.src = src + '?retry=1'; }   // 重试一次
        else container.append(placeholder());
      });
  }, { rootMargin: '200px' });
  io.observe(container);
  return () => io.disconnect();
}

```

**评分点**：
- rootMargin 预加载（-200px 提前）。
- img.decode() 后再可见（防解码 jank）。
- 失败重试一次 + 降级占位（不无限重试）。
- 断开清理（observer disconnect）。
