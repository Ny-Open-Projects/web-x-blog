## WCN-607：为元素库自动生成 React/Vue 适配器（wrapper）时，需要解决哪些映射问题？

**答**：
- 结论：适配器要解决三类映射——属性/property 同步、事件监听、Slot/子节点，核心是「React 传复杂值走 property，事件走 ref.addEventListener」。
- React 痛点：React 对自定义元素属性只传字符串，对象/数组必须设 DOM property；布尔属性存在即 true 的语义要特判。
- 追问钩子：Vue 为何相对省心？Vue 3 对自定义元素原生支持 property 绑定与 v-model，但仍需声明 emits 以获得类型提示——考察对两个框架差异的理解。

```javascript
import React, { useRef, useEffect } from 'react';
export function wrap(tag) {
  return function Wrapper({ children, onEvent, ...props }) {
    const ref = useRef(null);
    useEffect(() => {
      const el = ref.current;
      // 复杂值写 property，避免被序列化成 [object Object]
      Object.keys(props).forEach(k => {
        if (typeof props[k] === 'object') el[k] = props[k];
      });
      const handler = e => onEvent?.(e.detail, e);
      el.addEventListener('ds-change', handler);
      return () => el.removeEventListener('ds-change', handler);
    }, [props, onEvent]);
    return React.createElement(tag, { ref }, children);
  };
}
export const DsButton = wrap('ds-button');
```
