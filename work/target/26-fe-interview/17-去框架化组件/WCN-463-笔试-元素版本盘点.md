## WCN-463：笔试：实现运行时元素版本盘点（页面全量 tagName+version）。
**题目**：遍历文档树（含 shadowRoot 递归）：收集所有自定义元素（tagName 含 '-'），输出版本分布 `{version: count}` 与未标版本的清单。

```javascript
function inventory(root = document) {
  const found = [];
  const walk = (node) => {
    for (const el of node.querySelectorAll('*')) {
      if (el.tagName.includes('-'))
        found.push({ tag: el.tagName.toLowerCase(), v: el.dataset?.version });
      el.shadowRoot && walk(el.shadowRoot);
    }
  };
  walk(root);
  const dist = {};
  for (const f of found) dist[f.v ?? 'unversioned'] = (dist[f.v ?? 'unversioned'] || 0) + 1;
  return { dist, unversioned: found.filter(f => !f.v).map(f => f.tag) };
}

```

**评分点**：
- 递归 shadowRoot 遍历。
- 自定义元素判定（'-' in tagName）。
- 版本来源 data-version。
- 分布统计 + 未标注清单（治理）。
