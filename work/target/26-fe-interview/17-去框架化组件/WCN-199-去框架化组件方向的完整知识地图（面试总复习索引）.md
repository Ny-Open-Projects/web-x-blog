## WCN-199：去框架化组件方向的完整知识地图：五大战场总复习索引

**答**：
- Web Components（001~060）：三大标准、生命周期时序、Shadow DOM（open/closed/样式穿透/::part/slot/事件重定向）、form-associated 与 ElementInternals、DSD/SSR、性能与 a11y、基类与组件手写（笔试 14）。
- Signals（061~100）：依赖追踪、computed 惰性、批处理、五框架对比、TC39 提案、SSR 水合、内存模型；手写 signal/computed/effect/store/绑定器等 23 题。
- 跨框架复用（101~120）：React/Vue/Svelte/Solid 桥接、微前端、token 样式策略、类型与文档契约、成本收益模型。
- 编译器方向（121~145）：Solid 细粒度、Vue Vapor、Svelte runes、Qwik resumability、React Compiler、编译产物与 DCE、SSR 双目标。
- 选型与工程落地（146~200）：决策树、路线图、SSR 坑、CI/监控、多品牌、SDUI、桌面/插件、安全基线、降级、性能基线。
- 复习法：每战场先走"概念 → 原理 → 手写 → 工程"四层；笔试题（61 张含评分点）按评分点自测；面试前重点看 176（双保险）、178（规则集）、199（本图）。

```text
            ┌─ Web Components 001-060（平台能力层）
            ├─ Signals 061-100（响应式层）
去框架化组件 ─┼─ 跨框架复用 101-120（桥接层）
            ├─ 编译器方向 121-145（优化层）
            └─ 选型与工程落地 146-200（工程层）
```
