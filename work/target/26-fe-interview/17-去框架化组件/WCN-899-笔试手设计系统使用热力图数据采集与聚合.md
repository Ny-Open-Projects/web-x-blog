## WCN-899：笔试：手写设计系统「使用热力图」数据采集与聚合器

**题目**：实现 `createHeatmapAggregator()`，返回 `{ record(event), snapshot(), top(n), levelOf(component) }`。事件形如 `{ component, variant, version, page, team, ts }`。要求：① `record` 采集事件并累积：每组件的 total、按 variant 的分布、按 team 的分布、去重后的 page 集合、版本集合；② `snapshot()` 返回所有组件的聚合数据（含 total、topVariant、teams、pages 数、versions）；③ `top(n)` 返回使用量前 n 的组件（按 total 降序）；④ `levelOf(component)` 按 total 分级：>1000 `核心`、>50 `常规`、其余 `长尾/弃用候选`；⑤ 支持 `batch(events)` 批量采集。边界：事件字段缺失按默认值处理（component 缺失丢弃）；同一 page 多次访问只算一次（Set 去重）；数值型 total 正确累加不溢出（普通 JS 数字即可）。

**答**：

```javascript
function createHeatmapAggregator() {
  const data = new Map();
  function record(e) {
    if (!e || !e.component) return;                       // 丢弃无效事件
    const c = data.get(e.component) || {
      total: 0, variants: {}, teams: {}, pages: new Set(), versions: new Set(),
    };
    c.total++;
    c.variants[e.variant || 'default'] = (c.variants[e.variant || 'default'] || 0) + 1;
    c.teams[e.team || 'unknown'] = (c.teams[e.team || 'unknown'] || 0) + 1;
    if (e.page) c.pages.add(e.page);                       // 去重
    if (e.version) c.versions.add(e.version);
    data.set(e.component, c);
  }
  function snapshot() {
    const out = {};
    for (const [name, c] of data) out[name] = {
      total: c.total,
      topVariant: Object.entries(c.variants).sort((a, b) => b[1] - a[1])[0]?.[0],
      teams: c.teams, pages: c.pages.size, versions: [...c.versions],
    };
    return out;
  }
  return {
    record,
    batch(events) { (events || []).forEach(record); },
    snapshot,
    top(n = 5) { return [...data].map(([component, c]) => ({ component, total: c.total }))
      .sort((a, b) => b.total - a.total).slice(0, n); },
    levelOf(component) {
      const t = data.get(component)?.total || 0;
      return t > 1000 ? '核心' : t > 50 ? '常规' : '长尾/弃用候选';
    },
  };
}
const hm = createHeatmapAggregator();
hm.batch([
  { component: 'ds-button', variant: 'primary', team: 'A', page: '/p1', version: '2.1' },
  { component: 'ds-button', variant: 'primary', team: 'A', page: '/p1', version: '2.1' },
  { component: 'ds-rare', variant: 'x', team: 'B', page: '/p2', version: '1.0' },
]);
console.log(hm.snapshot()['ds-button'].pages); // 1（同页去重）
console.log(hm.top(2));
```

**评分点**：
- record 多维累积（total/variant/team/page/version），page 用 Set 去重（数据正确）。
- snapshot/top/levelOf 三查询能力完整，分级阈值正确（业务价值）。
- batch 批量采集、缺失字段默认值、无效事件丢弃（健壮性）。
- top 排序与 slice(n) 正确，输出可视化友好（可用性）。
