## WCN-139：编译器方向有哪些可借鉴到自研工具链的核心技术点？

**答**：
- 可借鉴点清单：① 静态/动态节点分离（Vue block 树思路）→ 自研 lowcode 渲染器跳过静态区域；② 表达式级更新定位（Solid renderEffect）→ WCN 绑定层；③ 代码切片懒加载（Qwik qrl）→ 大型中台页面的交互代码分包；④ mutable range 分析（React Compiler）→ 自研 lint 自动 memo 建议。
- 实现基础：SWC/Oxc/Babel 插件能力 + 自定义 DSL 解析；评估点是团队对 AST 工具链的维护能力。
- 落地路径：从"模板 → 渲染函数"的预编译开始（收益立现），再逐步做静态提升、patchFlag、增量 helper。
- 度量：编译前后 bundle 体积、更新耗时（Long Task 数）、TBT/TBTp95 改善。
- 风险管理：编译器 bug 难查——保留"逃生舱"（手动 escape hatch，如 v-pre/raw 块）+ sourcemap 完整性测试。

```javascript
// 自研工具链示例：WC 组件模板预编译脚本（esbuild 插件）
export function wcPrecompile() {
  return {
    name: 'wc-precompile',
    setup(build) {
      build.onLoad({ filter: /\.wc\.html$/ }, async (args) => {
        const src = await fs.readFile(args.path, 'utf8');
        const code = compileWcTemplate(src);   // 静态骨架 + 动态点更新函数
        return { contents: code, loader: 'js' };
      });
    },
  };
}
```
