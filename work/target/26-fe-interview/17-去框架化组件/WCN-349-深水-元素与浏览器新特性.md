## WCN-349：利用新平台能力（View Transitions/Popover/Anchor Positioning）升级元素？
**答**：
- Popover API：菜单/弹层原生显示层（top layer）替代 z-index 管理——渐进增强（不支持回退旧实现）。
- Anchor Positioning：浮层定位原生（对比度定位逻辑删除）。
- View Transitions：路由/列表重排动画标准化。
- 模式：特性检测分支（原生优先 + 降级实现），构建产物共用。

```javascript
if ('popover' in HTMLElement.prototype) {
  this._menu.popover = 'auto';           // top layer 原生
} else {
  this._menu.classList.add('ds-portal'); // 降级：portal + z-index
}
```
