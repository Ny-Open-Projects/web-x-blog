## WCN-700：设计系统平台化的收官：如何用北极星指标与路线图证明平台价值并持续演进？

**答**：
- 结论：北极星指标选「设计一致性 × 交付效率」的复合指标（如 token 覆盖率 × 需求交付时长倒数）；路线图按「夯实底座→扩大采用→智能提效」三阶段演进。
- 价值证明：用采用率、裸值率下降、交付提速、故障减少的趋势数据说话；定期做 ROI 复盘争取持续投入。
- 追问钩子：平台何时算「成功」？不是组件最多，而是「业务方主动用它、少造轮子、体验一致」——考察对平台价值的本质判断。

```javascript
const NORTH_STAR = {
  formula: (m) => m.tokenCoverage * (1 / m.deliveryDays) * m.adoptionRate,
  stages: [
    { name: '夯实底座', focus: ['token', 'a11y', '质量门禁'] },
    { name: '扩大采用', focus: ['文档站', 'codemod', '多品牌'] },
    { name: '智能提效', focus: ['D2C', 'AI 辅助', '可视化搭建'] },
  ],
};
const metrics = { tokenCoverage: 0.9, deliveryDays: 5, adoptionRate: 0.8 };
console.log('北极星指标:', NORTH_STAR.formula(metrics).toFixed(3));
console.log('当前阶段:', NORTH_STAR.stages[1].name);
```
