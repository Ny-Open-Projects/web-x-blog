## WCN-363：WC 与微前端的双层治理（元素层统一 + 应用层自治）？
**答**：
- 元素层（平台治理）：统一注册/版本/token/质量门禁——集中化。
- 应用层（自治）：页面编排/业务组件/路由——各团队自主。
- 接口协议：子应用消费元素（whenDefined）+ 贡献元素（RFC 流程）。
- 冲突治理：标签命名空间/版本协商/样式边界三张表公开维护。

```javascript
const governance = {
  platform: '统一注册/版本/token/门禁',
  app: '页面编排自治',
  protocol: '消费协议 + 贡献 RFC',
  tables: ['命名空间表', '版本矩阵', '样式边界'],
};
```
