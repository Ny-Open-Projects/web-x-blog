## WCN-615：笔试：实现能力探测器驱动的渐进增强渲染器（按浏览器能力选择渲染路径并上报）

**答**：
- 需求：实现 render(host, capabilities)，根据 shadow/cssVar/adoptedSheet 能力选择「完整/降级/极简」三档渲染，并上报命中档位。
- 思路：能力位用布尔探测合成 level；三档渲染函数；用 try/catch 保证任一档失败自动降一档；上报用于兼容性看板。
- 边界：探测本身的异常（如 CSS.supports 不存在）要兜底为 false；上报不能阻塞渲染（fire-and-forget）。

```javascript
function probe() {
  const safe = fn => { try { return !!fn(); } catch { return false; } };
  return {
    shadow: safe(() => 'attachShadow' in HTMLElement.prototype),
    adopted: safe(() => 'adoptedStyleSheets' in ShadowRoot.prototype),
    cssVar: safe(() => CSS.supports('(--x:0)')),
  };
}
function render(host, c = probe()) {
  let level = c.shadow && c.cssVar ? 'full' : c.cssVar ? 'lite' : 'bare';
  try {
    if (level === 'full') {
      const r = host.attachShadow({ mode: 'open' });
      if (c.adopted) r.adoptedStyleSheets = [sharedSheet];
      r.innerHTML = '<slot></slot>';
    } else host.innerHTML = level === 'lite' ? '<div class="ds-lite"></div>' : '降级文本';
  } catch {
    level = 'bare'; host.textContent = '降级文本';
  }
  report(level); // 非阻塞上报
  return level;
}
const sharedSheet = new CSSStyleSheet();
```

**评分点**：
- 能力探测逐项 try/catch 兜底，单项失败不影响整体。
- 三档渲染路径清晰，且失败自动降档（try/catch 包裹渲染）。
- 上报非阻塞（fire-and-forget），不拖慢首屏。
- 返回命中档位，便于测试断言与看板统计。
