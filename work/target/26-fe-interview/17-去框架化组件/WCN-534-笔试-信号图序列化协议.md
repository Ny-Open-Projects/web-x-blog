## WCN-534：信号图的「序列化/反序列化」协议如何设计（含函数型 equals 降级）？

**答**：
- 结论：序列化只输出 signal 当前值与 computed 的声明（expr 枚举 + deps），函数用枚举名替代。
- 反序列化按「signal → computed → effect」三阶段恢复，保证依赖存在。
- 不可序列化值（Date/函数/DOM）标记降级为初值或忽略，并记录告警。
- 追问：如何校验下发数据未被篡改？（答：加签名 / schema 校验，拒绝未知 expr）

```javascript
const EXPR_REG = { gt: (a,b)=>a>b, concat: (...a)=>a.join('') };
function serialize(store) {
  const out = { signals: {}, computed: [] };
  for (const [k, s] of store.signals) out.signals[k] = toPlain(s.get());
  for (const c of store.computed) out.computed.push({ name: c.name, expr: c.expr, deps: c.deps });
  return JSON.stringify(out);
}
function toPlain(v) {
  if (v instanceof Date) return { __date: v.toISOString() };       // 可降级
  if (typeof v === 'function') return null;                       // 不可序列化降级
  return v;
}
function deserialize(json) {
  const d = JSON.parse(json), store = { signals: new Map(), computed: [] };
  for (const [k, v] of Object.entries(d.signals)) store.signals.set(k, signal(v));
  for (const c of d.computed) if (EXPR_REG[c.expr])
    store.computed.push({ name: c.name, get: () => EXPR_REG[c.expr](...c.deps.map(k => store.signals.get(k).get())) });
  return store;
}
```
