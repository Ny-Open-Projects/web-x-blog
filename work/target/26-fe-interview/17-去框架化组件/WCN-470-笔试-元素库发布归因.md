## WCN-470：笔试：实现「元素缺陷 → 引入版本」的二分定位。
**答**：输入版本列表（时间序）与「该版本是否复现」的判定函数（在线上快照环境跑）。二分找最早引入版本（首个复现的）。

```javascript
function bisectVersion(versions, reproduces) {
  let lo = 0, hi = versions.length - 1, ans = versions[0];
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    if (reproduces(versions[mid])) { ans = versions[mid]; hi = mid - 1; }
    else lo = mid + 1;
  }
  return { introduced: ans,
    changelogRange: `${ans} 的变更列表（嫌疑 commit）` };
}
console.log(bisectVersion(['3.0.0', '3.1.0', '3.2.0'], v => v >= '3.1.0').introduced); // 3.1.0

```

**评分点**：
- 二分（复现 → 左移，不现 → 右移）。
- 判定函数注入（可 mock）。
- 边界（首版即现 → 第一版）。
- 输出引入版本 + 对应 changelog 区间。
