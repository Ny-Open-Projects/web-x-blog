## WCN-688：组件/属性要弃用时，如何设计弃用与迁移策略才能不打断业务？

**答**：
- 结论：弃用 = 标记（deprecated 注释/文档）→ 软警告（dev 模式 console.warn）→ codemod 自动迁移 → 下个大版本移除；全程保留别名兼容。
- 做法：用 CSS 变量别名（var(--new, var(--old))）或属性兼容层过渡；统计旧 API 使用量决定何时移除。
- 追问钩子：为什么不能立即删除？因为业务方升级有滞后——考察对「生态兼容性」的工程同理心。

```javascript
function deprecated(oldName, newName, value) {
  if (process.env.NODE_ENV !== 'production') {
    console.warn(`[deprecated] ${oldName} 将在下个大版本移除，请改用 ${newName}`);
  }
  return value;
}
// 属性兼容层：新旧名都支持
function normalizeProps(props) {
  if ('type' in props && !('variant' in props)) {
    props.variant = deprecated('type', 'variant', props.type);
  }
  return props;
}
// CSS 变量别名过渡
// --ds-btn-bg: var(--ds-color-action, var(--ds-btn-bg-old));
console.log(normalizeProps({ type: 'primary' }).variant);
```
