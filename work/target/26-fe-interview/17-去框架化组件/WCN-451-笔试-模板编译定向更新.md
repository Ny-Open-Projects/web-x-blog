## WCN-451：笔试：实现迷你编译器：JSX 表达式 → 定向更新函数。
**答**：输入模板描述 `[{tag, static: {...}, dynamic: {prop: exprString}}]`，expr 中信号调用形如 `name()`。生成 `render()`：创建节点 + 对每个动态绑定生成 `effect(() => node.prop = evalExpr())`。

```javascript
function compileNode(node) {
  const lines = [`const n = document.createElement('${node.tag}');`];
  for (const [k, v] of Object.entries(node.static || {}))
    lines.push(`n.setAttribute('${k}', '${v}');`);
  for (const [k, expr] of Object.entries(node.dynamic || {})) {
    const val = k === 'text' ? 'textContent' : k;
    lines.push(`createEffect(() => n.${val} = (${expr}));`);
  }
  return lines.join('\n');
}
console.log(compileNode({
  tag: 'b', static: { class: 'price' },
  dynamic: { text: 'title()' },
}));

// n.setAttribute('class', 'price');
// createEffect(() => n.textContent = (title()));

```

**评分点**：
- 静态/动态分离（静态一次创建）。
- 动态绑定逐个 effect（定向更新）。
- 表达式求值作用域（信号名解析）。
- 输出代码可读（近似 Solid 产物）。
