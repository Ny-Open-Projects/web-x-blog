## WCN-681：设计系统的组件如何分级（基础/业务/区块）？分级对治理有何意义？

**答**：
- 结论：L1 基础组件（Button/Input，通用无业务语义）→ L2 业务组件（带领域语义的复合组件）→ L3 区块/模板（页面级拼装）；越往上复用度越低但业务贴合度越高。
- 意义：不同级别对应不同 owner、变更频率、审批成本——L1 严控（影响面大），L3 宽松（业务自治）。
- 追问钩子：业务组件何时该下沉为基础组件？看跨业务复用次数——超过阈值即提升为 L1 并纳入核心治理。

```javascript
const LEVELS = {
  L1: { owner: 'core', changeCost: 'high', examples: ['Button', 'Input'] },
  L2: { owner: 'domain', changeCost: 'medium', examples: ['SkuCard'] },
  L3: { owner: 'business', changeCost: 'low', examples: ['CheckoutBlock'] },
};
function approvalFor(level) {
  return { L1: ['core-review', 'a11y', 'visual'],
           L2: ['domain-review', 'a11y'],
           L3: ['business-review'] }[level];
}
console.log(approvalFor('L1')); // 最严：核心评审 + 无障碍 + 视觉
```
