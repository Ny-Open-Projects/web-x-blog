## WCN-356：元素库作为开源/内部开源（inner source）的协同机制？
**答**：
- 贡献流程：RFC（API 变更）→ 实现 → 全矩阵测试 → 设计评审 → 发布。
- 治理：API 变更需 design review（元素 API 是长期契约，比实现严格）。
- 文档化：贡献指南（含 a11y/token/测试要求清单）。
- 健康度：外部贡献占比/PR 响应时长——衡量 inner source 活性。
