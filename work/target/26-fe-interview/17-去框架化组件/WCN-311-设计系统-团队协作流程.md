## WCN-311：设计系统团队的协作流程（设计/工程/业务三向同步）？
**答**：
- 变更流程：需求 → 设计稿 + token 评审 → 工程实现 → 文档站发布 → 业务公告（迁移指引）。
- 同步机制：token/组件变更单向流（Figma → tokens → 实现），反向（实现中发现设计问题）走设计 bug 单。
- 服务模式：业务接入支持（oncall）+ 定期采纳调研（哪些组件没被用、缺什么）。
- 度量闭环：采纳率/缺陷率/需求响应时长进季度回顾。
