## WCN-491：笔试：实现文档新鲜度检测（API 变更 vs 文档更新）。
**题目**：输入：本 PR 变更的元素文件与文档目录。规则：元素 API 变更（types diff 非空）但文档未动 → stale；输出 stale 清单（阻断合并可选）。

```javascript
function docFreshness(changedFiles, { mapping = p => p.replace('elements/', 'docs/'), mode = 'block' } = {}) {
  const stale = changedFiles
    .filter(f => f.startsWith('elements/') && f.endsWith('.d.ts'))
    .filter(f => !changedFiles.includes(mapping(f)));
  return { stale, exitCode: mode === 'block' && stale.length ? 1 : 0 };
}

```

**评分点**：
- 文件→文档映射约定（elements/x → docs/x）。
- types diff 非空判定（简化：文件变更即判，说明粗粒度）。
- stale 清单输出。
- 阻断级别配置（warn/block）。
