## WCN-461：笔试：实现元素性能快照的版本对比（劣化告警）。
**题目**：两版本指标 `[{tag, mountP95, gzipKB}]`。劣化定义：mountP95 增 > 15% 或 gzip 增 > 20%。输出劣化清单与总体趋势。

```javascript
function perfDiff(prev, curr, { mountT = 0.15, gzipT = 0.2 } = {}) {
  const p = new Map(prev.map(x => [x.tag, x]));
  const out = [];
  for (const c of curr) {
    const o = p.get(c.tag);
    if (!o) { out.push({ tag: c.tag, kind: 'new' }); continue; }
    const m = c.mountP95 / o.mountP95 - 1, g = c.gzipKB / o.gzipKB - 1;
    if (m > mountT || g > gzipT)
      out.push({ tag: c.tag, kind: 'degraded', mount: `+${(m * 100).toFixed(0)}%`, gzip: `+${(g * 100).toFixed(0)}%` });
  }
  for (const o of prev) if (!curr.find(c => c.tag === o.tag)) out.push({ tag: o.tag, kind: 'removed' });
  return out.sort((a, b) => (b.kind === 'degraded') - (a.kind === 'degraded'));
}

```

**评分点**：
- 相对劣化阈值（两维独立）。
- 新增/删除元素标注。
- 劣化清单按幅度排序。
- 输出告警文案（可贴 PR）。
