## WCN-397：数字/日期/货币格式化在元素层的标准化？
**答**：
- 统一 formatter 协议：元素库内 Intl 封装（locale 经 context 注入）。
- 禁止散落 toFixed/手写格式——lint 拦截（格式化必须走 ds-format）。
- 本地化数据：货币/单位/日历按 locale 配置表（与 token 同源管理）。
- 验证：格式化快照矩阵（locale × 数据样本）。

```javascript
DsFormat.configure({ locale: context.locale });
// 元素内：DsFormat.currency(99.5, 'CNY') → ¥99.50
// lint：/\.toFixed\(/ 在元素目录 → fail
r
```
