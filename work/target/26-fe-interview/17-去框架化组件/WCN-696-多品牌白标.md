## WCN-696：设计系统要支持多品牌白标（White-label），架构上如何设计？

**答**：
- 结论：品牌差异收敛到「token 层 + 少量品牌组件插槽」；核心组件逻辑共享，品牌通过注入不同 token 集与覆盖组件实现定制。
- 做法：构建时按品牌产出独立产物（token 不同）；运行时按 data-brand 切换变量；品牌专属组件放 overlay 层按需加载。
- 追问钩子：白标与主题有何不同？主题是同一品牌的多套视觉，白标是不同品牌的身份证明（logo/文案/交互差异）——考察概念辨析。

```javascript
const BRANDS = {
  alpha: { token: { '--ds-primary': '#165DFF' }, logo: '/alpha.svg' },
  beta:  { token: { '--ds-primary': '#F53F3F' }, logo: '/beta.svg' },
};
function applyBrand(name, scope) {
  const b = BRANDS[name] || BRANDS.alpha;
  Object.entries(b.token).forEach(([k, v]) => scope.style.setProperty(k, v));
  scope.dataset.brand = name;
  return b;
}
// 一份组件代码，注入不同品牌 token 即得不同外观
const brand = applyBrand('beta', document.documentElement);
console.log(brand.logo); // /beta.svg
```
