## WCN-314：元素库的发布流程（含 breaking 管控）？
**答**：
- changesets 风格：变更 PR 附 changeset（patch/minor/major + 描述）。
- breaking 检测：API diff 自动判级（删 property/改事件签名 = major），major 需双 owner 审批。
- 发布产物：npm + 文档站版本 + 迁移指南（major 必附）。
- 下游灰度：canary 版本先发给试点宿主验证，再 stable。

```javascript
# 发布流水线
changeset publish --canary   # 试点
api-diff --from latest       # breaking 检测（major 拦截确认）
changeset publish --stable
r
```
