## WCN-237：元素文档站如何做到「框架无关展示 + 框架示例切换」？
**答**：
- 文档核心用原生 HTML 演示（元素真实运行），框架代码示例作为 tab 切换（静态代码块 + 可运行 demo 用适配包）。
- API 表从类型定义自动生成（docs 与代码同源）。
-  playground 支持 props 编辑实时预览（元素 property 直改）。
- 版本切换：文档站按元素库版本路由，deprecated API 标注。

```javascript
// 文档数据从类型生成
const api = generateApiTable('./goods-card.d.ts');
// → [{name: 'sku', type: 'string', attr: true, reflect: false, since: 'v1'}]
```
