## WCN-359：元素库支撑低代码平台（属性面板驱动的元素编排）？
**答**：
- 元素属性即低代码协议：每元素导出「属性 schema」（类型/枚举/分组）供属性面板自动生成。
- 约束校验：属性组合合法性 schema（如 variant 与 disabled 互斥）在元素层校验。
- 预览：低代码画布直接渲染真实元素（所见即所得）。
- 协议版本：schema 带版本，低代码平台按版本渲染（向后兼容）。

```javascript
DsButton.schema = {
  props: { variant: { type: 'enum', options: ['primary', 'ghost'] },
           disabled: { type: 'boolean' } },
  events: ['click'],
  version: 2,
};
```
