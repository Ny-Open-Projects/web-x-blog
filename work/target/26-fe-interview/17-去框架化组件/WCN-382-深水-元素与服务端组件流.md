## WCN-382：元素与 React Server Component 流式输出的嵌套兼容（RSC payload 内的元素）？
**答**：
- 元素作为 RSC 叶子：可序列化 props 进 flight payload，客户端渲染时实例化。
- 边界：元素的 children 若是 Server 组件输出——Client 边界内的元素只能消费已序列化内容。
- DSD 与 RSC 流：元素 DSD 片段在 RSC 流中作为原始 HTML 插槽下发（React 19 支持）。
- 验证：RSC 流断言（元素标签 + DSD 模板完整出现在流中）。

```javascript
// RSC
async function Page() {
  return <section><goods-card sku="A1" price={99} /></section>;  // 叶子元素
}
// 流断言：flight 数据含 'goods-card' 标签
```
