## WCN-296：设计系统去框架化迁移的度量看板？
**答**：
- 覆盖度：WC 版组件占设计系统组件总数比例（分阶段：新组件 100% 起步）。
- 消费面：各框架宿主的 WC 消费组件数（替代自研组件数）。
- 质量：WC 版缺陷率 vs 旧版（持平或更好才算成功）。
- 成本：迁移人力 vs 多框架维护节省（ROI 曲线）。

const board = {
  coverage: 'WC 45/120 组件',
  adoption: { react: 38, vue: 22, svelte: 12 },
  defect: { wc: 0.4, legacy: 0.5 },     // 千 PR 缺陷率
  roi: '月度人力差值曲线',
