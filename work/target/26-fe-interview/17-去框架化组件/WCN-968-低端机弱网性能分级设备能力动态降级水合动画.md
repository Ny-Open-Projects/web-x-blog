## WCN-968：低端机 / 弱网下性能分级：怎么按设备能力动态降级水合与动画

**答**：
- 结论先行：性能分级是「同一套组件、多档体验」——根据设备能力（硬件并发、内存、save-data、网络 RTT）把用户分档，低端档减少水合、关动画、降图片质量。
- 信号源：navigator.hardwareConcurrency、deviceMemory、navigator.connection.saveData/effectiveType、首屏 RTT；综合打分分档（高/中/低）。
- 降级策略：低档只水合核心岛、关闭非必要 WC 的 effect、动画改 CSS 静态、图片用低清占位；水合延后到交互时（按前文调度器）。
- 动态切换：网络/电量变化可重新评估，但降级易、升级难（已卸载的 chunk 不重载），升级要谨慎避免抖动。
- 追问钩子：面试官问「分级会不会造成测试矩阵爆炸」——答：用「档位」抽象而非设备型号枚举，测试只覆盖每档代表设备，线上按信号自动归类。

```javascript
// 设备能力打分 -> 档位 -> 降级策略
function deviceTier() {
  let score = 0;
  const n = navigator.hardwareConcurrency || 2;
  const mem = navigator.deviceMemory || 2;
  score += n >= 8 ? 2 : n >= 4 ? 1 : 0;
  score += mem >= 8 ? 2 : mem >= 4 ? 1 : 0;
  score += navigator.connection?.saveData ? -2 : 0;
  return score >= 3 ? 'high' : score >= 1 ? 'mid' : 'low';
}
const tier = deviceTier();
const policy = { high: { hydrateAll: true, anim: true, img: 'hd' },
                 mid:  { hydrateAll: false, anim: true, img: 'sd' },
                 low:  { hydrateAll: false, anim: false, img: 'lazy' } }[tier];
console.log('档位', tier, policy);
```
