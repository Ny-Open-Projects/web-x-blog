## WCN-641：Signal 状态如何持久化到 localStorage / URL，并避免频繁写入？

**答**：
- 结论：用 effect 监听 signal 变化写入存储，但必须节流（rAF/时间窗口）并只存纯数据；读取时做版本迁移与容错。
- 做法：persist(signal, key, {throttle})：初始化读存储 → signal.set；effect 里节流写；URL 同步用 history.replaceState。
- 追问钩子：多标签页同步怎么办？监听 storage 事件回写 signal——考察对「跨标签一致性」的工程经验。

```javascript
function persist(sig, key, delay = 300) {
  try {
    const raw = localStorage.getItem(key);
    if (raw) sig.set(JSON.parse(raw));
  } catch {}
  let timer = null;
  effect(() => {
    const value = sig.get();
    clearTimeout(timer);
    timer = setTimeout(() => {
      try { localStorage.setItem(key, JSON.stringify(value)); } catch {}
    }, delay);
  });
  window.addEventListener('storage', e => {
    if (e.key === key) { try { sig.set(JSON.parse(e.newValue)); } catch {} }
  });
}
const theme = signal('light');
persist(theme, 'ds-theme');
```
