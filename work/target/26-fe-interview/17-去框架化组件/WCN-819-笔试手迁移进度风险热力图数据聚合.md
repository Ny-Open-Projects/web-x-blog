## WCN-819：笔试：手写「迁移进度风险热力图」数据聚合器（组件 × 团队 × 阻塞依赖）

**题目**：企业 WC 迁移看板需要一张「风险热力图」：输入组件记录列表，每条含 `{ component, team, status, blockers: string[] }`（status 为 `done|doing|blocked|todo`）。要求：① 按 `team × component` 聚合成矩阵，值为该团队该组件的状态；② 计算每个团队的「风险分」=`blocked` 记 3 分、`doing` 记 1 分、`todo` 记 2 分、`done` 记 0 分，再叠加未解决 blocker 数 ×1；③ 输出 `{ matrix, riskByTeam, topRiskTeams }`（topRiskTeams 取风险分最高的前 N 个团队，N 由参数指定，默认 3）。边界：空数组返回空结构；同一 team+component 多条记录取「最差状态」（blocked>todo>doing>done）；blocker 去重。

**答**：

```javascript
const RANK = { done: 0, doing: 1, todo: 2, blocked: 3 };
const SCORE = { done: 0, doing: 1, todo: 2, blocked: 3 };

function riskHeatmap(records, topN = 3) {
  if (!Array.isArray(records) || !records.length) {
    return { matrix: {}, riskByTeam: {}, topRiskTeams: [] };
  }
  const matrix = {}, blockersByTeam = {};
  for (const r of records) {
    if (!r || !r.team || !r.component) continue;          // 边界：脏数据跳过
    matrix[r.team] ||= {};
    // 同一 team+component 取最差状态
    const prev = matrix[r.team][r.component];
    if (!prev || RANK[r.status] > RANK[prev]) matrix[r.team][r.component] = r.status;
    // blocker 去重并按团队归集
    blockersByTeam[r.team] ||= new Set();
    (Array.isArray(r.blockers) ? r.blockers : []).forEach(b => blockersByTeam[r.team].add(b));
  }
  const riskByTeam = {};
  for (const [team, comps] of Object.entries(matrix)) {
    let score = Object.values(comps).reduce((s, st) => s + (SCORE[st] ?? 0), 0);
    score += (blockersByTeam[team]?.size || 0);          // 未解决 blocker 加分
    riskByTeam[team] = score;
  }
  const topRiskTeams = Object.entries(riskByTeam)
    .sort((a, b) => b[1] - a[1]).slice(0, topN).map(([t]) => t);
  return { matrix, riskByTeam, topRiskTeams };
}

console.log(riskHeatmap([
  { component: 'ds-button', team: 'A', status: 'done', blockers: [] },
  { component: 'ds-table',  team: 'A', status: 'blocked', blockers: ['API 未定', 'API 未定'] },
  { component: 'ds-form',   team: 'B', status: 'doing', blockers: ['设计稿缺失'] },
]));
```

**评分点**：
- 状态取「最差」用显式的 RANK 映射比较，而非简单覆盖（边界意识）。
- blocker 用 Set 去重，避免重复计数（数据清洗）。
- 风险分叠加 blocker 数，且空数组/脏数据有防御（健壮性）。
- topRiskTeams 排序取前 N 且 N 可配置，输出结构清晰可消费（API 设计）。
