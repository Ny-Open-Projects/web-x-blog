## WCN-144：笔试：手写事件缓存提升器

**题目**：模板事件 `on:click="handle($event, id)"` 编译为稳定 handler：① 编译期把内联表达式包装成 `_$handler[i]` 缓存函数（只创建一次）；② 捕获变量（id）作为参数在调用时从 ctx 读取；③ 输出提升代码 + 使用代码；④ 重复表达式去重（同一表达式只生成一个缓存）；⑤ 事件绑定执行 `el.addEventListener(type, cached)`，组件重渲染不重新绑定。

**答**：

```javascript
const cache = new Map();

export function hoistEvent(expr, ctxKeys) {
  if (cache.has(expr)) return cache.get(expr);
  const i = cache.size;
  // 编译产物：handler 只在模块层创建一次；运行期数据从 ctx 动态取
  const code = `const _$h${i} = ($event, ctx) => { const { ${ctxKeys.join(', ')} } = ctx; ${expr.replace(/\$event/g, '$event')} };`;
  cache.set(expr, { index: i, code });
  return cache.get(expr);
}

// compile(template) 生成两段代码：
// 1) 提升段（render 函数外，只执行一次）
//   const _$h0 = ($event, ctx) => { const { id } = ctx; handle($event, id) };
// 2) 使用段（render 内，无闭包重建）
//   on(el, 'click', ($e) => _$h0($e, ctx));
//
// 对比手写：
// el.addEventListener('click', (e) => handle(e, id));  // 每次渲染重建闭包 → 需要 remove/re-add
// 编译后：handler 引用恒定 → 绑定一次即可；且被打包器识别为可 hoist

// 测试口径：
// 重渲染 10 次，el 上的 click listener 只注册一次（getEventListeners 验证）
```

**评分点**：
- 提升语义正确：handler 创建一次，运行期数据经 ctx 参数注入（闭包变量提升）。
- 去重（同表达式单实例）；render 内不重建闭包。
- 与 removeEventListener 的关系讲清楚（引用稳定可免重绑）。
- 编译产物分"提升段/使用段"两段输出。
