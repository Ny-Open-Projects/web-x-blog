## WCN-558：「可提升子树判定器」如何扫描动态/副作用引用并输出 hoist 结论？

**答**：
- 结论：递归遍历 AST，收集三类「污染标记」——动态绑定、slot/组件、副作用事件，任一命中则该子树及其祖先不可提升。
- 自底向上汇总子树的污染状态，父节点 OR 子节点。
- 输出每个节点的 hoistable 与拒绝原因，便于诊断。
- 追问：纯事件监听（静态 handler 引用）能否提升？（答：可以，只要 handler 本身是稳定引用）

```javascript
function analyze(node) {
  const childInfo = (node.children || []).map(analyze);
  const childDirty = childInfo.some(c => c.dirty);
  let reasons = childInfo.flatMap(c => c.reasons);
  if (node.dynamicBinding) reasons.push('动态绑定 ' + node.dynamicBinding);
  if (node.slot) reasons.push('slot 分发');
  if (node.component) reasons.push('组件实例');
  if (node.sideEffect && !node.stableHandler) reasons.push('副作用引用');
  return { dirty: reasons.length > 0 || childDirty, reasons: [...new Set(reasons)],
           hoistable: reasons.length === 0 && !childDirty };
}
function hoistReport(ast) {
  const r = analyze(ast);
  return { hoistable: r.hoistable, blockedBy: r.reasons };
}
```
