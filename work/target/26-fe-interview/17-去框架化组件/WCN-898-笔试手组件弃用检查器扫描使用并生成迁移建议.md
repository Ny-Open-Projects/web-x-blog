## WCN-898：笔试：手写组件「弃用检查器」（扫描使用 + 生成迁移建议）

**题目**：实现 `deprecationChecker(deprecated, codemods)`。输入 `deprecated` 是弃用 API 清单 `[{ pattern: RegExp 或字符串, name, replacement, removeIn }]`，`codemods` 是 `{ name: (code) => 迁移后代码 }`。返回 `{ scan(files), report(files), migrate(files) }`。要求：① `scan(files)`（files 为 `[{ path, code }]`）找出每处弃用 API 的使用，返回 `[{ path, api, line }]`（line 为出现行号，从 1 开始）；字符串 pattern 用 `includes`，RegExp 用全局匹配；② `report` 返回按 api 分组的统计 `{ [api]: { count, files: [], removeIn } }`；③ `migrate` 对每个文件依次应用对应 codemod（无 codemod 的跳过），返回 `[{ path, before, after, changed }]`；④ 支持 `dryRun`（migrate 时只返回建议不改代码——这里通过参数控制是否真应用）。边界：一个文件多处使用只扫一次；UTF-8 多行正确计行号。

**答**：

```javascript
function deprecationChecker(deprecated, codemods = {}) {
  function match(code, pattern) {
    if (pattern instanceof RegExp) { const m = code.match(new RegExp(pattern.source, pattern.flags.includes('g') ? pattern.flags : pattern.flags + 'g')); return m ? m.length : 0; }
    let n = 0, i = 0; while ((i = code.indexOf(pattern, i)) !== -1) { n++; i += pattern.length; } return n;
  }
  return {
    scan(files) {
      const hits = [];
      for (const f of files) {
        for (const api of deprecated) {
          const count = match(f.code, api.pattern);
          if (count) {
            const idx = f.code.split(String(api.pattern))[0];
            hits.push({ path: f.path, api: api.name, count, line: (idx || '').split('\n').length });
          }
        }
      }
      return hits;
    },
    report(files) {
      const hits = this.scan(files), out = {};
      for (const h of hits) {
        const api = deprecated.find(a => a.name === h.api);
        out[h.api] ||= { count: 0, files: [], removeIn: api.removeIn };
        out[h.api].count += h.count; out[h.api].files.push(h.path);
      }
      return out;
    },
    migrate(files, { dryRun = false } = {}) {
      return files.map(f => {
        let code = f.code;
        for (const api of deprecated) {
          if (match(code, api.pattern) && codemods[api.name] && !dryRun) code = codemods[api.name](code);
        }
        return { path: f.path, before: f.code, after: code, changed: code !== f.code };
      });
    },
  };
}
const checker = deprecationChecker(
  [{ pattern: 'oldType', name: 'ds-button.oldType', replacement: 'variant', removeIn: 'v4' }],
  { 'ds-button.oldType': (c) => c.replace(/oldType/g, 'variant') },
);
console.log(checker.scan([{ path: 'a.tsx', code: '<ds-button oldType="p"/>\n<ds-button oldType="s"/>' }]));
console.log(checker.migrate([{ path: 'a.tsx', code: '<ds-button oldType="p"/>' }]));
```

**评分点**：
- 字符串与 RegExp 两种 pattern 的匹配与计数（含全局）。
- scan/report/migrate 三能力完整，report 按 api 分组统计（业务闭环）。
- codemod 应用与 dryRun 控制，无 codemod 跳过（迁移灵活性）。
- 行号计算与边界（一处多次、多行 UTF-8）处理（细节）。
