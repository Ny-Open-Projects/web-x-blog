## WCN-438：笔试：实现元素的拖拽（Pointer Events + rAF 合帧 + capture）。
**题目**：pointerdown 开始（setPointerCapture）；move 合帧（rAF 一次 apply）；up 释放并派发 `drag-end` detail {dx, dy}。touch-action 防滚动。

```javascript
class DragEl extends HTMLElement {
  #dx = 0; #dy = 0; #raf = null; #last = null;
  connectedCallback() { this.style.touchAction = 'none';
    this.addEventListener('pointerdown', this);
    this.addEventListener('pointermove', this);
    this.addEventListener('pointerup', this); }
  handleEvent(e) {
    if (e.type === 'pointerdown') { this.setPointerCapture(e.pointerId); this.#last = e; }
    else if (e.type === 'pointermove') {
      if (this.#raf) return;
      this.#raf = requestAnimationFrame(() => {
        this.#raf = null;
        this.#dx += e.clientX - this.#last.clientX;   // 合帧 apply
        this.#dy += e.clientY - this.#last.clientY;
        this.style.transform = `translate(${this.#dx}px,${this.#dy}px)`;
        this.#last = e;
      });
    } else if (e.type === 'pointerup') {
      this.dispatchEvent(new CustomEvent('drag-end',
        { detail: { dx: this.#dx, dy: this.#dy }, bubbles: true, composed: true }));
    }
  }
}

```

**评分点**：
- capture（指针丢失不中断）。
- rAF 合帧（一帧最多 apply 一次）。
- touch-action: none 样式。
- end detail 汇总位移（语义事件）。
