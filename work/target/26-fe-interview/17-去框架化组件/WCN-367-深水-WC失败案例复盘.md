## WCN-367：WC 迁移失败的常见原因（复盘视角）？
**答**：
- 原因 1：为迁移而迁移（无跨框架需求）——记分卡缺失。
- 原因 2：基建先行不足（token/测试没好就铺组件）——质量失控。
- 原因 3：API 面照抄框架组件（React 风格 API 塞进 WC）——框架无关性破坏。
- 原因 4：SSR 没规划（后期补 DSD 成本指数级）。
- 对策：决策卡 + 基建门槛 + API 规范前置 + SSR 一等公民。
