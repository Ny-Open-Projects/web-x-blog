## WCN-033：笔试：手写一个迷你 Custom Element 基类，支持模板渲染、属性观察与事件自动清理

**题目**：实现 `BaseElement` 基类：① 子类声明静态 `tpl`（模板字符串）与 `observedAttrs`；② 基类在 constructor 中 attachShadow 并渲染模板；③ `attributeChangedCallback` 中自动调用子类 `onAttrChange`；④ 提供 `this.on(el, type, fn)` 绑定事件并在元素移除时自动解绑（含 window 级）；⑤ `connectedCallback`/`disconnectedCallback` 调用子类钩子。说明边界：重复 connected 不得重复渲染。

**答**：

```javascript
class BaseElement extends HTMLElement {
  static tpl = ''; static observedAttrs = [];
  static get observedAttributes() { return this.observedAttrs; }

  constructor() {
    super();
    this._rendered = false;
    this._cleanups = [];
    this._root = this.attachShadow({ mode: 'open' });
    if (this.constructor.tpl) this._root.innerHTML = this.constructor.tpl;
  }
  // 统一事件绑定：返回解绑函数，元素移除时全部执行
  on(target, type, fn, opts) {
    target.addEventListener(type, fn, opts);
    this._cleanups.push(() => target.removeEventListener(type, fn, opts));
  }
  connectedCallback() {
    if (!this._rendered) {           // 边界：元素被移动会再次 connected
      this._rendered = true;
      this.onMount?.();
    }
  }
  disconnectedCallback() {
    this._cleanups.forEach((fn) => fn());
    this._cleanups = [];
    this.onUnmount?.();
  }
  attributeChangedCallback(name, oldV, newV) {
    if (oldV !== newV) this.onAttrChange?.(name, oldV, newV);
  }
  $(sel) { return this._root.querySelector(sel); }
}

class CounterBtn extends BaseElement {
  static tpl = '<button id="b">0</button>';
  static observedAttrs = ['step'];
  onMount() {
    this.n = 0;
    this.on(this.$('#b'), 'click', () => {
      this.n += Number(this.getAttribute('step')) | 0 || 1;
      this.$('#b').textContent = String(this.n);
    });
    this.on(window, 'resize', () => console.log('resize 清理随元素销毁'));
  }
  onAttrChange(n) { if (n === 'step') console.log('step 变为', this.getAttribute('step')); }
}
customElements.define('counter-btn', CounterBtn);
```

**评分点**：
- attachShadow 放 constructor、渲染标志防重复 connected（时序意识）。
- 事件清理用 cleanup 数组统一回收，window/document 监听也覆盖（GC 意识）。
- `observedAttributes` 委托静态字段且守卫 `oldV !== newV`（API 细节）。
- 基类钩子用可选调用（`onMount?.()`），子类未实现不报错（健壮性）。
