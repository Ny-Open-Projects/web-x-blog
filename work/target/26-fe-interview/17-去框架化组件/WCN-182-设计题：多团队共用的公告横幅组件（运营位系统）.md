## WCN-182：设计题：多团队共用的公告横幅组件（运营位系统）怎么设计？

**答**：
- 需求特征：运营高频换内容（文案/图片/跳转）、多端投放（Web/App 内嵌/第三方）、曝光与点击要精确计量、样式可控可品牌化——典型 SDUI + WC 组合（WCN-160）。
- 架构：运营后台配置 → 服务端按页面/用户下发 banner 树（SDUI JSON）→ `<acme-banner>` WC 渲染器；运营位类型白名单（text/image/carousel/countdown）。
- 计量：组件内置曝光（IntersectionObserver 50% 可见 1s）与点击事件 → wc-track 适配器统一上报（归因 tag+version+页面）。
- 内容安全：服务端下发内容走清洗管道（富文本白名单、链接域白名单）；图片走对象存储 + 防盗链。
- 体验细节：倒计时横幅用 Signals（WCN-081）；关闭状态持久化（localStorage + 过期时间）；无障碍 aria-live polite。
- 降级：接口失败不渲染（或渲染兜底默认位）；组件加载失败静默（不影响页面主流程）。

```json
{ "tag": "acme-banner", "attrs": { "type": "countdown", "theme": "brand-a" },
  "children": [{ "tag": "acme-countdown", "attrs": { "end": 1732000000000 } }],
  "track": { "slot": "spring-sale" } }
```

```javascript
// 曝光计量（组件内置）
const io = new IntersectionObserver((ents) => {
  if (ents.some((e) => e.intersectionRatio >= 0.5)) {
    this.#track('banner-expose');       // 只报一次
    io.disconnect();
  }
}, { threshold: 0.5 });
```
