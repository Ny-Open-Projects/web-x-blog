## WCN-1000：笔试终局整合：组件平台「健康度 + 性能 + 成本 + 合规 + 一致性」五维仪表盘聚合

**题目**：实现 `platformScore(input)`，input 形如 `{ components:[{ name, health, hydrateMs, costKB, a11yViolations, apiDrift }], budgets:{ maxHydrateMs, maxCostKB } }`（health 为 0~100，其余见字段名）。要求聚合五维：① healthScore = health 均值；② perfScore = 各组件按 hydrateMs≤maxHydrateMs 得100、超出按 max(0,100-(超量/maxHydrateMs)*100) 后取均值；③ costScore = 各组件按 costKB≤maxCostKB 得100、超出按 max(0,100-(超量/maxCostKB)*100) 后取均值；④ complianceScore = 100 - a11yViolations总数*10（下限0）；⑤ consistencyScore = 100 - apiDrift总数*15（下限0）；⑥ overall = 五维加权 0.25/0.25/0.15/0.2/0.15；⑦ 输出 `{ healthScore, perfScore, costScore, complianceScore, consistencyScore, overall, alerts }`，alerts 含 a11y 违规、apiDrift、性能/成本超预算的组件名；⑧ 空 components 返回全0 + 相应告警；保留1位小数；不修改输入。请自足实现并给出可运行示例。

**答**：

```javascript
function platformScore(input = {}) {
  const { components = [], budgets = {} } = input || {};
  const { maxHydrateMs = 200, maxCostKB = 300 } = budgets;
  const r1 = n => +(+n).toFixed(1);
  const clamp = n => Math.max(0, Math.min(100, n));
  if (!components.length) return { healthScore:0, perfScore:0, costScore:0,
    complianceScore:0, consistencyScore:0, overall:0, alerts:['无组件数据'] };
  const decay = (v, max) => v <= max ? 100 : clamp(100 - (v-max)/max*100);
  const healthScore = components.reduce((s,c)=>s+clamp(c.health||0),0)/components.length;
  const perfScore = components.reduce((s,c)=>s+decay(c.hydrateMs||0,maxHydrateMs),0)/components.length;
  const costScore = components.reduce((s,c)=>s+decay(c.costKB||0,maxCostKB),0)/components.length;
  const violations = components.reduce((s,c)=>s+(c.a11yViolations||0),0);
  const drifts = components.reduce((s,c)=>s+(c.apiDrift||0),0);
  const complianceScore = clamp(100 - violations*10);
  const consistencyScore = clamp(100 - drifts*15);
  const overall = healthScore*0.25 + perfScore*0.25 + costScore*0.15
                + complianceScore*0.2 + consistencyScore*0.15;
  const alerts = [];
  components.forEach(c=>{
    if (c.a11yViolations>0) alerts.push(`${c.name}: a11y违规${c.a11yViolations}`);
    if (c.apiDrift>0) alerts.push(`${c.name}: API漂移${c.apiDrift}`);
    if (c.hydrateMs>maxHydrateMs) alerts.push(`${c.name}: 性能超预算`);
    if (c.costKB>maxCostKB) alerts.push(`${c.name}: 成本超预算`);
  });
  return { healthScore:r1(healthScore), perfScore:r1(perfScore), costScore:r1(costScore),
    complianceScore:r1(complianceScore), consistencyScore:r1(consistencyScore),
    overall:r1(overall), alerts };
}
console.log(platformScore({ components:[
  { name:'ds-button', health:90, hydrateMs:120, costKB:200, a11yViolations:0, apiDrift:0 },
  { name:'ds-table', health:70, hydrateMs:300, costKB:400, a11yViolations:2, apiDrift:1 },
], budgets:{ maxHydrateMs:200, maxCostKB:300 } }));
```

**评分点**：
- 五维分数计算正确（健康/性能/成本衰减/合规/一致性）。
- 加权综合分 overall 权重正确（0.25/0.25/0.15/0.2/0.15）。
- alerts 覆盖 a11y/漂移/性能/成本四类，含组件名。
- 空输入返回全0 + 告警，数值截断与1位小数精度正确。
- 不修改输入、示例可运行且输出结构正确。
