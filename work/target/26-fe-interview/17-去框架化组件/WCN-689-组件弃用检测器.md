## WCN-689：笔试：实现组件弃用检测器（扫描代码中的旧 API/旧标签，生成迁移清单 + codemod 建议）

**答**：
- 需求：实现 findDeprecated(sources, rules)：sources 是 {file, code}[]，rules 是 {pattern, name, replacement, codemod}；返回命中的 {file, name, line, suggestion} 列表，按文件分组。
- 思路：逐文件按行匹配 pattern（字符串或正则）；记录行号与命中片段；给出 replacement 建议与 codemod 名；空结果返回 []。
- 边界：正则全局匹配避免重复；跳过注释行（简单启发式）；按文件分组输出便于生成 PR。

```javascript
export function findDeprecated(sources, rules) {
  const result = [];
  for (const { file, code } of sources) {
    const hits = [];
    code.split('\n').forEach((line, i) => {
      if (/^\s*(\/\/|\/\*|\*)/.test(line)) return; // 跳过注释
      for (const r of rules) {
        const matched = typeof r.pattern === 'string'
          ? line.includes(r.pattern)
          : new RegExp(r.pattern.source, r.pattern.flags.includes('g') ? r.pattern.flags : r.pattern.flags + 'g').test(line);
        if (matched) hits.push({ line: i + 1, name: r.name,
          suggestion: r.replacement, codemod: r.codemod });
      }
    });
    if (hits.length) result.push({ file, hits });
  }
  return result;
}
console.log(findDeprecated(
  [{ file: 'a.js', code: '<ds-button type="primary" />\n// type 已弃用' }],
  [{ pattern: 'type=', name: 'type 属性', replacement: 'variant', codemod: 'type-to-variant' }]
));
```

**评分点**：
- 按行匹配并记录准确行号（便于人工定位）。
- 字符串与正则两种 pattern 都支持，正则正确处理 g 标志。
- 跳过注释行（减少误报）。
- 按文件分组输出，附带 replacement 与 codemod 建议。
