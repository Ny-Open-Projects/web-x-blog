## WCN-530：笔试：实现「表单依赖图」信号层（字段联动 + 循环依赖检测 + 拓扑求值）。

**答**：
- 结论：把联动规则建成有向图，字段变化只触发下游节点；拓扑排序保证求值顺序，DFS 检测环。
- 节点 = 字段，边 = 联动依赖；入度为 0 的节点先算，用队列做 Kahn 拓扑排序。
- 环检测：拓扑后若还有未处理节点即存在环，抛出具体字段链。
- 追问：如何处理「联动规则的优先级」？（答：边带 priority，拓扑序内按 priority 排）

```javascript
function buildGraph(rules) {
  const g = new Map();                          // field -> [{to, run}]
  for (const r of rules) for (const from of r.when) {
    if (!g.has(from)) g.set(from, []);
    g.get(from).push({ to: r.target, run: r.run });
  }
  return g;
}
function topoEval(graph, changed, values) {
  const indeg = new Map(), queue = [...changed];
  for (const [from, edges] of graph) for (const e of edges) indeg.set(e.to, (indeg.get(e.to) || 0) + 1);
  const seen = new Set(queue); let order = [];
  while (queue.length) {
    const f = queue.shift(); order.push(f);
    for (const e of graph.get(f) || []) {
      e.run(values);                            // 执行联动
      if (!seen.has(e.to)) { seen.add(e.to); queue.push(e.to); }
    }
  }
  if (order.length < graph.size) throw new Error('检测到循环依赖');
  return order;
}
```

**评分点**：
- 字段联动图建模
- Kahn 拓扑求值
- DFS/入度环检测
- 变更只触发下游
