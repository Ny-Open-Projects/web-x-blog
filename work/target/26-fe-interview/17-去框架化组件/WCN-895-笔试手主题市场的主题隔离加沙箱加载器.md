## WCN-895：笔试：手写主题市场的「主题隔离 + 沙箱加载」器

**题目**：实现 `createThemeSandbox({ allowedTokens, validate })`，返回 `{ publish(name, tokenData), activate(name), getActiveCSS(), list() }`。要求：① `publish` 时按 `allowedTokens` 白名单过滤 token（丢弃非白名单项），调用 `validate(name, filtered)` 校验（返回 `{ valid, errors }`），不合法则拒绝发布并抛出含 errors 的错误；② 每个主题存为「命名空间化的 CSS 变量」（如 `--theme-<name>-primary`），实现隔离；③ `activate(name)` 切换当前主题（只能切换到已发布且合法的）；④ `getActiveCSS()` 返回当前主题的 `:root{...}` CSS 文本；⑤ `list()` 返回已发布主题名。边界：重复 publish 同名覆盖但需重新校验；activate 未发布主题抛错；token 值含 `;`/`}` 要转义或拒绝（防 CSS 注入）。

**答**：

```javascript
function createThemeSandbox({ allowedTokens, validate }) {
  const themes = new Map(); let active = null;
  return {
    publish(name, tokenData = {}) {
      const filtered = {};
      for (const k of allowedTokens) if (k in tokenData) filtered[k] = tokenData[k];
      const check = validate(name, filtered);
      if (!check.valid) throw new Error(`主题 ${name} 校验失败: ${check.errors.join(', ')}`);
      themes.set(name, filtered);                 // 重复发布覆盖（已重新校验）
    },
    activate(name) {
      if (!themes.has(name)) throw new Error(`主题 ${name} 未发布`);
      active = name;
    },
    getActiveCSS() {
      if (!active) return '';
      const tokens = themes.get(active);
      const decls = Object.entries(tokens).map(([k, v]) => {
        if (/[;}{]/.test(String(v))) throw new Error(`非法 token 值: ${v}`); // 防 CSS 注入
        return `--theme-${active}-${k}: ${v};`;
      }).join('');
      return `:root { ${decls} }`;
    },
    list() { return [...themes.keys()]; },
  };
}
const sb = createThemeSandbox({
  allowedTokens: ['primary', 'bg'],
  validate: (n, t) => ({ valid: !!t.primary, errors: t.primary ? [] : ['缺 primary'] }),
});
sb.publish('dark', { primary: '#000', bg: '#111', evil: 'x; } body{display:none' });
sb.activate('dark');
console.log(sb.getActiveCSS()); // 只含白名单 token，隔离命名空间
```

**评分点**：
- 白名单过滤 + validate 校验后才发布，拒绝非法主题（安全门禁核心）。
- token 命名空间化（`--theme-<name>-`）实现多主题隔离。
- CSS 注入防护（值中 `;}{` 检测），安全边界意识。
- 重复发布重校验、activate 未发布抛错等边界处理（健壮性）。
