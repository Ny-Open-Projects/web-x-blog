## WCN-394：元素库总体积治理（50 元素 300KB 的预算分配）？
**答**：
- 预算分配：运行时内核（调度/绑定）≤ 8KB + 每元素均值 ≤ 6KB。
- 超支治理：元素内重复逻辑下沉内核（helper 复用）/字符串模板压缩。
- 审计工具：体积构成树（内核/共享/单元素），异常元素（> 2 倍均值）专项。
- 趋势：版本间总体积与单元素均值双曲线。

```javascript
const budget = { kernel: 8, perElement: 6, total: 300 };
// 审计：体积树 → 异常元素（>12KB）专项下沉
```
