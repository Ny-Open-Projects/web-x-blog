## WCN-292：元素库的版本治理（多宿主不同步版本的兼容）？
**答**：
- 元素自描述：data-version 属性 + window.DS_ELEMENTS_VERSION 全局快查。
- 兼容矩阵：宿主支持区间声明，注册时校验冲突（双版本同页告警）。
- 渐进升级：旧版元素保留注册名（-legacy），新版本并存灰度。
- 治理工具：页面元素版本盘点脚本（全量 tagName + version 汇总）。

```javascript
console.table([...document.querySelectorAll('*')]
  .filter(el => el.tagName.startsWith('DS-'))
  .map(el => ({ tag: el.tagName, v: el.dataset.version })));

```
