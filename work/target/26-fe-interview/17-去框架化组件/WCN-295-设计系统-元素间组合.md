## WCN-295：设计系统元素间的组合模式（表单组/卡片段落）？
**答**：
- 组合用「容器元素 + slot」：slot 语义化命名（header/content/footer）而非匿名插槽。
- 跨元素协调：容器元素内直接 API 调用子元素（同 shadow 域）或组合事件。
- 禁止跨 shadow 猜测内部结构（querySelector 深挖）——组合只走公共 API/slot。
- 文档：组合示例是文档一等公民（不只单元素 demo）。

```javascript
<ds-card>
  <template slot="header">标题</template>
  <ds-input label="邮箱" slot="content"></ds-input>
  <ds-button slot="footer">提交</ds-button>
</ds-card>

```
