## WCN-341：元素库的「多端输出」（Web/小程序/App WebView）适配策略？
**答**：
- Web：标准 WC；小程序：编译层映射（自研 renderer 或 Web-like 运行时）；App WebView：同 Web。
- 抽象点：元素实现尽量只依赖 Web 标准子集（小程序可支持的 DOM 能力）。
- 适配层：平台差异（事件模型/存储/网络）抽 adapter 接口，实现按端注入。
- 取舍：小程序适配成本高——评估「共享逻辑（无 DOM 层）抽包」折中方案。

```javascript
// 平台 adapter 接口
interface PlatformAdapter { request(): Promise<Response>; storage: Storage; events: 'dom' | 'mp'; }
// Web 用 DOM 实现；小程序 adapter 由编译层注入
r
```
