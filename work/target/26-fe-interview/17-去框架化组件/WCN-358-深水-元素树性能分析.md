## WCN-358：深层元素树（100+ 嵌套）的性能分析方法？
**答**：
- 渲染路径：composedPath 与 shadow 层数统计（层数过深 = 设计问题）。
- 事件延迟：委托链过长（每层都监听）→ 事件处理 P95。
- 内存：每层 shadow root 开销（强制减少不必要 shadow——纯展示可不用 shadow）。
- 工具：元素树可视化（层级/订阅数/mount 时长热力）。

```javascript
function analyzeTree(root) {
  const stats = { maxDepth: 0, shadowCount: 0, listeners: 0 };
  walk(root, (el, depth) => {
    stats.maxDepth = Math.max(stats.maxDepth, depth);
    if (el.shadowRoot) stats.shadowCount++;
  });
  return stats;   // maxDepth > 8 → 架构审查
}
```
