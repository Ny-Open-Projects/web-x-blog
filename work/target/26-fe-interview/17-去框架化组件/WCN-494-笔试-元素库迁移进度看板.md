## WCN-494：笔试：实现迁移进度看板数据（组件清单 × 状态 × 依赖阻塞）。
**题目**：组件 `[{name, status: wc|legacy|pending, blockedBy: [name]}]`。规则：pending 组件依赖未完成的 WC 组件 → 标 blocked。输出：完成率、blocked 清单（含阻塞链）、建议批次（无阻塞的可并行开工）。

```javascript
function migrationBoard(components) {
  const byName = new Map(components.map(c => [c.name, c]));
  const blocked = (c, seen = new Set()) => {
    if (seen.has(c.name)) return false;
    seen.add(c.name);
    return (c.blockedBy || []).some(b => {
      const dep = byName.get(b);
      return dep && dep.status !== 'wc' ? true : blocked(dep, seen);
    });
  };
  const wc = components.filter(c => c.status === 'wc').length;
  const blockedList = components.filter(c => c.status === 'pending' && blocked(c));
  return { rate: +(wc / components.length).toFixed(2),
    blocked: blockedList.map(c => c.name),
    readyBatch: components.filter(c => c.status === 'pending' && !blocked(c)).map(c => c.name) };
}

```

**评分点**：
- 依赖传播阻塞（blockedBy 的 blockedBy 也算）。
- 完成率（wc / 总数）。
- 建议批次 = 非 blocked 的 pending。
- 排序（阻塞链深度）。
