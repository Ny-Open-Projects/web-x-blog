## WCN-680：笔试：实现运行时主题切换引擎（CSS 变量 + 局部作用域 + 切换事件 + 防闪烁）

**答**：
- 需求：实现 ThemeEngine：set(theme, scope?) 应用主题变量并派发 ds-themechange；get(scope) 返回当前主题；支持局部主题覆盖（子元素可独立主题）；首屏防闪烁（同步读取偏好）。
- 思路：用 WeakMap 记录 scope→theme；变量写在 scope.style；局部覆盖用 CSS 变量继承；切换派发 composed 事件。
- 边界：未知主题回退默认；重复 set 同主题不派发事件；局部主题不影响兄弟节点。

```javascript
export class ThemeEngine {
  constructor(themes, defaultTheme = 'light') {
    this.themes = themes; this.defaultTheme = defaultTheme;
    this.scopes = new WeakMap();
  }
  set(name, scope = document.documentElement) {
    const theme = this.themes[name] ? name : this.defaultTheme;
    if (this.scopes.get(scope) === theme) return; // 幂等
    const vars = this.themes[theme];
    Object.entries(vars).forEach(([k, v]) => scope.style.setProperty(k, v));
    scope.dataset.theme = theme;
    this.scopes.set(scope, theme);
    scope.dispatchEvent(new CustomEvent('ds-themechange', {
      detail: { theme }, bubbles: true, composed: true,
    }));
  }
  get(scope = document.documentElement) {
    return this.scopes.get(scope) || this.defaultTheme;
  }
}
const engine = new ThemeEngine({
  light: { '--ds-bg': '#fff' }, dark: { '--ds-bg': '#000' },
});
engine.set('dark', document.querySelector('ds-card')); // 仅该卡片局部主题
```

**评分点**：
- CSS 变量按 scope 设置，支持局部主题覆盖（继承链正确）。
- 重复 set 同主题幂等（不重复派发事件）。
- ds-themechange 事件 bubbles+composed（穿透 Shadow DOM）。
- 未知主题回退默认；get 返回当前 scope 主题。
