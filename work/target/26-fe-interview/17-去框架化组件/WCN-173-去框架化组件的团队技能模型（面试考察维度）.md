## WCN-173：去框架化组件方向的团队技能模型：面试应该考察哪些维度？

**答**：
- 维度一（平台 API 深度）：生命周期/Shadow DOM/事件 retarget/form-associated 的准确记忆与边界条件（笔试可出 WCN-033/037 这类手写）。
- 维度二（响应式理解）：依赖追踪原理、computed 惰性、批处理——能手写迷你 signals（WCN-070/071 是标准考题）。
- 维度三（跨框架桥接）：React/Vue 与 WC 的属性/事件映射细节，回环防护意识（WCN-104/110）。
- 维度四（工程判断）：选型决策树、成本收益模型、迁移策略——用开放场景题（"多团队复用组件库怎么做"）考察，拒绝背题式回答。
- 维度五（质量与运营）：a11y 契约、监控归因、灰度回滚——高级候选人必备。
- 评估口径：初级重维度一二，中级加三，高级看四五与"主动暴露限制"的工程判断力。
