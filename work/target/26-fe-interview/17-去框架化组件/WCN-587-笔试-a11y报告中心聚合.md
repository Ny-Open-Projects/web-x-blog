## WCN-587：「a11y 报告中心」数据聚合器如何按规则 × 组件 × 严重级别生成整改看板？

**答**：
- 结论：把多次扫描的原始违规记录按「规则 + 组件 + 严重级别」三维聚合，统计数量与趋势。
- 严重级别映射权重，计算组件健康分；按权重降序生成整改优先级。
- 输出整改看板数据：每组件的违规清单、责任人、趋势。
- 追问：如何识别「反复出现的顽固问题」？（答：跨扫描按规则聚合，统计出现次数与持续周期）

```javascript
const WEIGHT = { critical: 10, serious: 5, moderate: 2, minor: 1 };
function aggregate(scans) {
  const board = new Map();
  for (const scan of scans) for (const v of scan.violations) {
    const key = `${v.component}::${v.rule}::${v.impact}`;
    if (!board.has(key)) board.set(key, { component: v.component, rule: v.rule, impact: v.impact, count: 0, weight: 0 });
    const row = board.get(key); row.count += v.nodes; row.weight += WEIGHT[v.impact] * v.nodes;
  }
  const byComp = {};
  for (const row of board.values()) {
    const c = byComp[row.component] ||= { issues: [], penalty: 0 };
    c.issues.push(row); c.penalty += row.weight;
  }
  for (const c of Object.values(byComp)) { c.issues.sort((a,b)=>b.weight-a.weight); c.health = Math.max(0, 100 - c.penalty); }
  return Object.entries(byComp).map(([name, v]) => ({ name, ...v })).sort((a,b)=>a.health-b.health);
}
```
