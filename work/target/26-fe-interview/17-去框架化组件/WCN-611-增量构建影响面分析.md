## WCN-611：笔试：实现元素库 monorepo 的增量构建影响面分析器（改一个文件算出需要重构建的包）

**答**：
- 需求：输入变更文件列表与包依赖图，输出受影响的包集合（直接修改的包 + 所有反向依赖包），按拓扑序排列。
- 思路：建反向依赖图 revDeps；对每个变更文件找到所属包入队；BFS 扩散；最后按依赖深度排序输出。
- 边界：循环依赖要去重防死循环；变更文件不在任何包时忽略但记录；输出稳定顺序便于 CI 缓存。

```javascript
function analyze(changes, packages) {
  const fileToPkg = new Map();
  for (const [pkg, files] of Object.entries(packages)) {
    files.forEach(f => fileToPkg.set(f, pkg));
  }
  const rev = new Map();
  for (const [pkg, deps] of Object.entries(packages)) {
    for (const d of deps || []) {
      if (!rev.has(d)) rev.set(d, []);
      rev.get(d).push(pkg);
    }
  }
  const affected = new Set();
  const queue = changes.map(f => fileToPkg.get(f)).filter(Boolean);
  while (queue.length) {
    const p = queue.shift();
    if (affected.has(p)) continue;
    affected.add(p);
    (rev.get(p) || []).forEach(x => queue.push(x));
  }
  return [...affected].sort();
}
console.log(analyze(['button/src/a.js'], {
  button: ['token'], form: ['button'], page: ['form'], token: [],
}));
```

**评分点**：
- 正确构建 fileToPkg 与反向依赖图（两向映射准确）。
- BFS 扩散包含传递依赖，不只直接依赖。
- Set 去重 + 循环依赖防死循环。
- 输出稳定排序，便于 CI 缓存命中。
