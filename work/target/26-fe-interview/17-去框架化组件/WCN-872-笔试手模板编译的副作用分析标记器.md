## WCN-872：笔试：手写模板编译的「副作用分析标记器」（指导 tree-shaking）

**题目**：模板编译产物是一个「语句数组」，每条语句形如 `{ id, kind, expr, deps?, used }`（kind 为 `Static|Expr|Effect|EventBind|Import|Assign|Call`）。实现 `analyzeSideEffects(stmts, pureCalls)` 返回 `{ keep, drop, reasons }`。规则：① `Static`、`Expr`（纯表达式，deps 仅读取）默认可删（若 used=false）；② `Effect`、`EventBind`、`Assign`、`Import` 永远保留（有副作用）；③ `Call` 若 callee 在 pureCalls 集合（默认含常见纯函数）且参数无副作用则可删，否则保留；④ 被保留语句 deps 中出现的可删语句也要保留（因为被依赖）——做「标记-清除」传递保留；⑤ `reasons` 记录每条语句保留/删除的简短原因。边界：未知 kind 保守保留；used=true 的语句保留。

**答**：

```javascript
function analyzeSideEffects(stmts, pureCalls = new Set(['Math.max', 'JSON.parse'])) {
  const byId = new Map(stmts.map(s => [s.id, s]));
  const keep = new Set(), reasons = {};
  // 初始标记：有副作用或 used 的保留
  for (const s of stmts) {
    const sideEffectKind = ['Effect', 'EventBind', 'Assign', 'Import'].includes(s.kind);
    const impureCall = s.kind === 'Call' && !pureCalls.has(s.expr?.callee);
    const unknown = !['Static', 'Expr', 'Call', 'Effect', 'EventBind', 'Assign', 'Import'].includes(s.kind);
    if (sideEffectKind || impureCall || unknown || s.used) {
      keep.add(s.id);
      reasons[s.id] = sideEffectKind ? `${s.kind} 有副作用` : impureCall ? '非纯调用' : unknown ? '未知类型保守保留' : '被使用';
    }
  }
  // 传递保留：被保留语句依赖的语句也保留
  const queue = [...keep];
  while (queue.length) {
    const cur = byId.get(queue.pop());
    for (const depId of (cur?.deps || [])) {
      if (byId.has(depId) && !keep.has(depId)) {
        keep.add(depId); reasons[depId] = '被保留语句依赖';
        queue.push(depId);
      }
    }
  }
  return {
    keep: stmts.filter(s => keep.has(s.id)),
    drop: stmts.filter(s => !keep.has(s.id)),
    reasons,
  };
}
const stmts = [
  { id: 'a', kind: 'Static', expr: '"hi"', used: false },
  { id: 'b', kind: 'Expr', expr: 'count', deps: ['a'], used: false },
  { id: 'c', kind: 'Effect', expr: 'render(b)', used: false },
  { id: 'd', kind: 'Call', expr: { callee: 'fetchData' }, used: false },
];
const r = analyzeSideEffects(stmts);
console.log('drop:', r.drop.map(s => s.id)); // a, b 可删（b 未被 c 依赖）
console.log('keep:', r.keep.map(s => s.id)); // c, d
```

**评分点**：
- 副作用分类规则正确（Effect/EventBind/Assign/Import/非纯调用保留）。
- 标记-清除的传递保留（被依赖的可删语句也保留）——tree-shaking 正确性关键。
- 保守原则：未知 kind 保留，避免误删（安全性）。
- reasons 输出便于调试审计（可观测性）。
