## WCN-604：企业元素库出现多个大版本共存时，如何做依赖治理与运行时协商？

**答**：
- 结论：大版本共存是常态（业务方升级有先后），治理目标是「同一页面不同版本互不干扰 + 可观测」。
- 做法：版本号写入 data-version 属性；注册中心记录 tag+version→构造器映射；跨版本组件通过自定义事件通信而非直接 DOM 耦合。
- 追问钩子：如何推动收敛？用采用率看板 + 升级 AB 对照 + 旧版本到期告警，而不是强制删除——考察治理手段的渐进性。

```javascript
// 注册中心：tag+version -> 构造器
const registry = new Map();
export function defineVersioned(tag, version, Impl) {
  const key = `${tag}@${version}`;
  if (registry.has(key)) return registry.get(key);
  class Versioned extends Impl {
    connectedCallback() {
      this.dataset.version = version;
      super.connectedCallback?.();
    }
  }
  customElements.define(key.replace('@', '-'), Versioned);
  registry.set(key, Versioned);
  return Versioned;
}
defineVersioned('ds-button', '2.4.0', class extends HTMLElement {});
defineVersioned('ds-button', '3.0.0', class extends HTMLElement {});
// 页面可同时存在 ds-button-2-4-0 与 ds-button-3-0-0
```
