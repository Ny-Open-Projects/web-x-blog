## WCN-471：笔试：实现元素库的灰度旗标系统（分级：全局/元素/实例）。
**题目**：`flags(scope)`：三级查找——实例 property > 元素默认 > 全局配置。返回布尔；解析顺序清晰（就近优先）。

```javascript
const KNOWN = new Set(['use-new-render', 'virtual-v2']);
function flags(el, global = window.DS_FLAGS || {}) {
  const meta = el.constructor.flagsMeta || {};
  return (name) => {
    if (!KNOWN.has(name)) console.warn(`未注册旗标: ${name}`);
    return el[name] ?? meta[name] ?? global[name] ?? false;   // 就近优先
  };
}
class X extends HTMLElement {
  static flagsMeta = { 'use-new-render': true };
}

```

**评分点**：
- 三级覆盖（实例 > 元素 > 全局）。
- 解析顺序实现（?? 链）。
- 旗标注册表（防止拼写漂移——未注册旗标告警）。
- 清理：全量后移除分支（版本化）。
