## WCN-874：笔试：手写一个轻量「错误恢复」解析器（恐慌模式 + 同步点）

**题目**：给定 token 数组（每个 token 为 `{ type, value }`），实现 `parseWithRecovery(tokens)`，用恐慌模式做错误恢复，返回 `{ ast, errors }`。文法：程序由若干语句组成，语句有两种——`let <ident> = <num> ;`（声明）与 `print <expr> ;`（打印），`<expr>` 为数字或标识符。要求：① 正常解析产出语句 AST 数组；② 遇到错误时记录 `{ message, tokenIndex }` 并进入恐慌模式——跳过 token 直到「同步点」（`;` 或语句起始关键字 `let`/`print`），从同步点继续；③ 若跳过过程中遇到 `;`，消费它作为恢复边界；④ 至少一个语句成功解析时 ast 保留已解析部分（不丢弃）；⑤ 错误抑制——连续两个错误的 tokenIndex 差距 < 2 时只保留第一个（避免连锁误报）。边界：空 tokens 返回空 ast；文件末尾错误要能收尾不越界。

**答**：

```javascript
function tokenize(src) {
  return src.match(/\w+|[=;]/g).map(value => ({
    type: /^\d+$/.test(value) ? 'NUM' : /^(let|print)$/.test(value) ? 'KW' : /^[A-Za-z_]/.test(value) ? 'IDENT' : value,
    value,
  }));
}
function parseWithRecovery(tokens) {
  const ast = [], errors = [];
  let i = 0;
  const at = () => tokens[i];
  const expect = (type) => { if (at()?.type === type) return tokens[i++]; throw new Error(`期望 ${type}，实际 ${at()?.value || 'EOF'}`); };
  function parseStmt() {
    if (at()?.value === 'let') {
      i++; const name = expect('IDENT'); expect('='); const num = expect('NUM'); expect(';');
      return { type: 'Decl', name: name.value, value: Number(num.value) };
    }
    if (at()?.value === 'print') {
      i++; const e = at(); if (!e || !['NUM', 'IDENT'].includes(e.type)) throw new Error('期望表达式'); i++; expect(';');
      return { type: 'Print', expr: e.value };
    }
    throw new Error(`未知语句起始 ${at()?.value}`);
  }
  function recover() {
    while (i < tokens.length && at().value !== ';' && !['let', 'print'].includes(at().value)) i++;
    if (at()?.value === ';') i++;                 // 消费同步点
  }
  const SYNC = new Set(['let', 'print', ';']);
  while (i < tokens.length) {
    if (SYNC.has(at().value) && at().value === ';') { i++; continue; }
    try { ast.push(parseStmt()); }
    catch (e) {
      const err = { message: e.message, tokenIndex: i };
      const last = errors[errors.length - 1];
      if (!last || err.tokenIndex - last.tokenIndex >= 2) errors.push(err); // 错误抑制
      recover();
    }
  }
  return { ast, errors };
}
console.log(JSON.stringify(parseWithRecovery(tokenize('let a = 1 ; print a ; let = 2 ; print b ;'))));
// 第三句 let = 2 报错恢复，其余成功解析
```

**评分点**：
- 恐慌模式：遇错跳到同步点（; / let / print）继续，一次报多个错（错误恢复核心）。
- 保留已成功解析的 ast，不因局部错误全盘失败（容错价值）。
- 错误抑制避免连锁误报（体验细节）。
- 末尾/空输入的边界收尾安全，不越界（健壮性）。
