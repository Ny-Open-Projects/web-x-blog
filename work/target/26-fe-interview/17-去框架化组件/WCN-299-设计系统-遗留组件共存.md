## WCN-299：元素库与遗留框架组件库的共存期治理？
**答**：
- 共存策略：按页面/域渐进替换（同域不混用同类组件），禁止同屏新旧混排（视觉不一致）。
- 过渡 API 层：旧组件内部实现换成 WC（对外 API 不变）——消费方无感迁移。
- 视觉回归双跑：替换前后同页面截图 diff（token 层面应一致）。
- 退场台账：旧组件清单 × 替换进度 × 计划版本，进季度评审。

```javascript
// 过渡：旧 API 组件内部渲染 WC
function OldButton(props) {
  return <ds-button variant={props.type} onClick={props.onClick}>{props.children}</ds-button>;
} // 消费方零改动，内部已 WC 化
```
