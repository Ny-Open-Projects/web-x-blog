## WCN-250：相等性跳过（equal:严格/浅/自定义）对调度的影响？
**答**：
- 写入时相等性检查：新值 === 旧值则不传播（最便宜的优化，必须默认开启原始值）。
- 浅比较：对象字段级比较，任一相同字段不触发对应订阅——粒度更细但成本上升。
- 深层成本陷阱：大对象每写一次做 deep equal 可能比重算还贵——阈值化（大小 > N 退回引用比较）。
- 语义风险：自定义 equal 导致「写了但视图没更新」的困惑——规范写文档。

```javascript
const sig = signal(bigObj, { equals: (a, b) =>
  bigObj.size > 10_000 ? a === b : deepEqual(a, b) });  // 大对象退回引用比较
r
```
