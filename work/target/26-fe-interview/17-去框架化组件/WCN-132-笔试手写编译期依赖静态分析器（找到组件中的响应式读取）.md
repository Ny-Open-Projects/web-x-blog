## WCN-132：笔试：手写编译期响应式标记器

**题目**：对 mini 模板（WCN-130 的 `{{expr}}` 语法）做编译期分析：① 区分"纯静态文本/属性"与"引用了 signal 的插值"；② signal 清单由外部提供（如 `['count','user.name']`），插值表达式引用其中任一即标记 reactive；③ 输出每个插值的标记结果与依赖路径；④ 属性值（`class="{{cls}}"`）同样分析；⑤ 未知变量视为静态并 dev 告警（可能漏标）。

**答**：

```javascript
export function analyze(tpl, signals, { warn = console.warn } = {}) {
  const signalRoots = new Set(signals.map((s) => s.split('.')[0]));
  const results = [];

  function checkExpr(expr, where) {
    // 提取标识符（简化词法：[A-Za-z_$][\w$]*，排除关键字）
    const ids = expr.match(/[A-Za-z_$][\w$]*/g) ?? [];
    const deps = ids.filter((id) => signalRoots.has(id));
    if (!deps.length && ids.length && !/^\d+$/.test(expr)) {
      warn(`possibly non-reactive expr "${expr}" at ${where}`);  // 漏标风险
    }
    const record = { expr, where, reactive: deps.length > 0, deps };
    results.push(record);
    return record.reactive;
  }

  // 插值扫描（文本与属性共用）
  for (const m of tpl.matchAll(/\{\{([^}]+)\}\}/g)) {
    checkExpr(m[1].trim(), `interp@${m.index}`);
  }
  for (const m of tpl.matchAll(/([\w-]+)="([^"]*\{\{[^}]+\}\}[^"]*)"/g)) {
    for (const inner of m[2].matchAll(/\{\{([^}]+)\}\}/g)) {
      checkExpr(inner[1].trim(), `attr:${m[1]}@${m.index}`);
    }
  }

  return {
    marks: results,
    summary: { total: results.length, reactive: results.filter((r) => r.reactive).length },
  };
}

// 口径：
// analyze('<b>{{count}}</b><i class="{{cls}}">{{a+b}}</i>', ['count', 'user.name']);
// → marks: [
//   { expr:'count', where:'interp@3', reactive:true, deps:['count'] },
//   { expr:'cls',   where:'attr:class@…', reactive:false },  // 告警
//   { expr:'a+b',   where:'interp@…', reactive:false },
// ]
```

**评分点**：
- 插值与属性插值两条扫描路径都覆盖。
- 依赖判定基于根标识符集合（`user.name` 按根 `user` 匹配）。
- 未知标识符告警（编译期保守性意识）。
- 输出结构可供后续编译器消费（expr/where/deps 三元信息）。
