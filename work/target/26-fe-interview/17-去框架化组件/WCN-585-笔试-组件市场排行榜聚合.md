## WCN-585：笔试：实现「组件市场」排行榜数据聚合器（采用率 × 健康分 × 引用趋势）。

**答**：
- 结论：聚合元数据、采用数据、健康分与趋势，按加权公式计算排名，并标记 badge。
- 采用率用 log 缩放避免头部垄断；趋势用近 N 期增量。
- deprecated 元素强制排末尾并列替代方案。
- 追问：如何处理数据缺失？（答：默认零值 + 标记「数据不足」，不参与推荐）

```javascript
function aggregate(assets, usageMap, history) {
  const trend = id => {
    const h = history[id] || []; if (h.length < 2) return 0;
    return (h.at(-1) - h.at(-2)) / Math.max(1, h.at(-2));
  };
  return assets.map(a => {
    const u = usageMap[a.id] || {};
    const hasData = u.repos != null && a.health != null;
    const score = hasData ? a.health * 0.4 + Math.log1p(u.repos) * 12 + trend(a.id) * 8 : 0;
    return { ...a, score: +score.toFixed(1),
      badge: !hasData ? 'insufficient' : a.deprecated ? 'deprecated' : a.health >= 80 ? 'recommended' : 'normal',
      replacement: a.deprecated ? a.replacedBy : undefined };
  }).sort((a,b) => (a.badge==='deprecated') - (b.badge==='deprecated') || b.score - a.score);
}
```

**评分点**：
- 多源数据聚合加权
- 采用率 log 缩放
- 趋势增量计算
- 缺失数据不推荐
