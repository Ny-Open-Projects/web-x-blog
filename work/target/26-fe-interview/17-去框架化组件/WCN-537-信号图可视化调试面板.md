## WCN-537：信号依赖图的「可视化调试面板」设计：如何实时展示订阅关系与触发热度？

**答**：
- 结论：在每个 signal/computed/effect 上挂元数据（name、deps、subs、触发计数），panel 订阅这些数据渲染力导向图。
- 触发热度：记录每次写/重算的时间戳与耗时，用颜色深浅表示热点。
- 数据从「调试探针」采集，生产构建通过开关 tree-shake 掉，零线上开销。
- 追问：如何定位「为什么这个 effect 又跑了」？（答：记录触发链——写信号 → 脏标记 → effect，点击节点展示链路）

```javascript
const NODES = new Map();
function trackSignal(name, s) {
  const meta = { name, deps: [], subs: new Set(), hits: 0, lastAt: 0 };
  NODES.set(s, meta);
  const orig = s.set;
  s.set = v => { meta.hits++; meta.lastAt = performance.now(); return orig(v); };
  return s;
}
function dumpGraph() {
  return [...NODES.values()].map(m => ({
    name: m.name, deps: m.deps.map(d => NODES.get(d)?.name),
    subs: [...m.subs].map(s => NODES.get(s)?.name), hits: m.hits,
  }));
}
```
