## WCN-900：笔试：终局整合——设计系统平台化「健康度 + 成本 + 采纳」三维仪表盘数据聚合

**题目**：作为收官整合题，实现 `platformDashboard(input)`。输入 `{ components: [{ name, health, usage, a11yPass, docFresh, cost, deprecated }], budgets: { maxCost, targetAdoption } }`（health/a11yPass/docFresh 为 0~100 分，usage 为使用次数，cost 为年度成本，deprecated 为布尔）。要求：① 采纳维度 adoptionScore = 各组件 usage 的归一化均值（以 usage 最大值为 100 分基准，无组件时为 0）；② 健康维度 healthScore = 各组件 health/a11yPass/docFresh 的加权平均（权重 0.4/0.35/0.25），弃用组件额外扣 10 分/个（总分下限 0）；③ 成本维度 costScore = cost ≤ maxCost 时 100，超出按 `Math.max(0, 100 - (cost-maxCost)/maxCost*100)`；④ 综合分 = adoption×0.3 + health×0.4 + cost×0.3；⑤ 输出 `{ adoptionScore, healthScore, costScore, overall, alerts }`，alerts 包含：a11yPass<80 的组件、成本超预算、采纳未达标。边界：空 components 返回全 0 + 相应告警；数值越界按 0~100 截断；保留 1 位小数。

**答**：

```javascript
function platformDashboard(input) {
  const { components = [], budgets = {} } = input || {};
  const { maxCost = Infinity, targetAdoption = 60 } = budgets;
  const clamp = v => Math.max(0, Math.min(100, Number(v) || 0));
  const r1 = (n) => +n.toFixed(1);
  if (!components.length) {
    return { adoptionScore: 0, healthScore: 0, costScore: 0, overall: 0,
      alerts: ['无组件数据', '采纳未达标'] };
  }
  // 采纳：usage 归一化
  const maxUsage = Math.max(...components.map(c => c.usage || 0), 1);
  const adoptionScore = r1(components.reduce((s, c) => s + ((c.usage || 0) / maxUsage) * 100, 0) / components.length);
  // 健康：加权 + 弃用扣分
  let healthRaw = components.reduce((s, c) =>
    s + clamp(c.health) * 0.4 + clamp(c.a11yPass) * 0.35 + clamp(c.docFresh) * 0.25, 0) / components.length;
  const deprecatedCount = components.filter(c => c.deprecated).length;
  const healthScore = r1(Math.max(0, healthRaw - deprecatedCount * 10));
  // 成本
  const totalCost = components.reduce((s, c) => s + (c.cost || 0), 0);
  const costScore = r1(totalCost <= maxCost ? 100 : Math.max(0, 100 - (totalCost - maxCost) / maxCost * 100));
  const overall = r1(adoptionScore * 0.3 + healthScore * 0.4 + costScore * 0.3);
  // 告警
  const alerts = [];
  components.forEach(c => { if (clamp(c.a11yPass) < 80) alerts.push(`${c.name}: a11y 不达标(${c.a11yPass})`); });
  if (totalCost > maxCost) alerts.push(`成本超预算(${totalCost}>${maxCost})`);
  if (adoptionScore < targetAdoption) alerts.push(`采纳未达标(${adoptionScore}<${targetAdoption})`);
  return { adoptionScore, healthScore, costScore, overall, alerts };
}
console.log(platformDashboard({
  components: [
    { name: 'ds-button', health: 90, a11yPass: 95, docFresh: 88, usage: 5000, cost: 30000, deprecated: false },
    { name: 'ds-old', health: 60, a11yPass: 70, docFresh: 50, usage: 100, cost: 20000, deprecated: true },
  ],
  budgets: { maxCost: 40000, targetAdoption: 60 },
}));
```

**评分点**：
- 三维指标（采纳/健康/成本）计算逻辑正确，加权综合分（核心整合能力）。
- 归一化、弃用扣分、成本超支衰减等细节处理到位。
- alerts 覆盖 a11y/预算/采纳三类告警，可驱动治理（业务闭环）。
- 空输入/越界截断/精度控制的边界处理（健壮性），体现平台化收官的工程严谨度。
