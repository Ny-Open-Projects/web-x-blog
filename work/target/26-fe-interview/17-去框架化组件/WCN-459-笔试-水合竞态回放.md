## WCN-459：笔试：实现「注册前交互」的意图暂存与回放。
**答**：根级 capture 监听：目标元素未注册 → 记录 {el, type, ts}；元素注册后回放最近一次同类意图（点击→模拟 click；输入→派发 input）。上限（队列 10 条）防堆积。

```javascript
const pending = new Map();
document.addEventListener('click', (e) => {
  const el = e.target.closest('ds-x');
  if (el && !customElements.get('ds-x')) {
    pending.set(el, { type: 'click', ts: Date.now() });     // 同元素只留最新
    if (pending.size > 10) pending.delete(pending.keys().next().value);
  }
}, true);
customElements.whenDefined('ds-x').then(() => {
  for (const [el] of pending) el.click();   // 意图回放（一次）
  pending.clear();
});

```

**评分点**：
- capture 阶段捕获（注册前也能收）。
- 回放语义（意图转换而非事件伪造——点击重放 vs 直接调 API 的取舍）。
- 队列上限与去重（同元素同类只留最新）。
- 注册完成钩子（whenDefined.then 回放）。
