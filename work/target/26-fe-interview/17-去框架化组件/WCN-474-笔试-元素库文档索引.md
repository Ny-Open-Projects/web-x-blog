## WCN-474：笔试：实现文档站的全文索引（组件/prop/事件/token）。
**题目**：输入结构化文档数据：生成倒排索引（词 → [{kind, ref}]）；`search(q)` 返回按类型分组的命中（token 优先）。

```javascript
function buildIndex(entries) {   // entries: [{kind, ref, text}]
  const idx = new Map();
  for (const e of entries)
    for (const w of e.text.toLowerCase().split(/\s+/))
      idx.set(w, [...(idx.get(w) || []), e]);
  return {
    search(q) {
      const words = q.toLowerCase().split(/\s+/);
      const hits = words.map(w => idx.get(w) || [])
        .reduce((a, b) => a.filter(x => b.includes(x)));   // AND
      const rank = { token: 0, component: 1, prop: 2, event: 3 };
      return [...new Set(hits)].sort((a, b) => rank[a.kind] - rank[b.kind]);
    },
  };
}

```

**评分点**：
- 倒排索引构建（分词 + 引用登记）。
- 四类引用（component/prop/event/token）。
- token 优先排序。
- 查询词组匹配（多词 AND）。
