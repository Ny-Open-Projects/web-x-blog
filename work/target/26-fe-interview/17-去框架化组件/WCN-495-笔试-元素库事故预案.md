## WCN-495：笔试：实现元素库事故的「自动降级注册」预案执行器。
**答**：事故场景：新版元素错误率超阈值。执行器：`degrade(tag, legacyImpl)` → 取消注册（无法取消——设计：页面刷新走旧版本 URL 参数，或平台网关切流）输出预案步骤清单与验证检查点。

```javascript
function degradePlan(tag, { errRate, threshold = 0.05 }) {
  if (errRate <= threshold) return { action: 'none' };
  return { action: 'switch-asset', steps: [
    `1. 网关把 ${tag} chunk 切回 v_prev（URL 参数 ?dsver=prev）`,
    '2. 观察 5 分钟错误率回落（检查点）',
    '3. 通知平台组 + 冻结该版本发布',
    '4. 复盘矩阵缺口',
  ], note: 'customElements 无法注销：降级只能走产物/网关层' };
}

```

**评分点**：
- customElements 无法注销的平台限制（关键认知）——降级走「构建产物切换/网关切流」。
- 预案步骤化（每步可验证）。
- 检查点：错误率回落确认。
- 演练：预案季度演练。
