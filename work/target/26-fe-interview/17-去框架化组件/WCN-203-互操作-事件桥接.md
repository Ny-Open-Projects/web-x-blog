## WCN-203：框架不原生支持自定义事件时，事件桥接层的标准写法与陷阱？
**答**：
- 标准桥接：ref 拿到元素 → addEventListener('add-cart', handler) → 卸载时 removeEventListener。
- 陷阱 1：匿名函数重复绑定（每次渲染叠加监听）——必须稳定引用或 effect 清理。
- 陷阱 2：事件 detail 里的对象引用在框架异步处理时已变更——detail 应传快照。
- React 19 可用 `onAddCart` prop 约定让框架自动桥接（元素定义时声明事件名）。

```javascript
function CartButton({ onAdd }: { onAdd: (sku: string) => void }) {
  const ref = useRef<HTMLElement>(null);
  useEffect(() => {
    const el = ref.current!;
    const h = (e: Event) => onAdd((e as CustomEvent).detail.sku);   // 快照化
    el.addEventListener('add-cart', h);
    return () => el.removeEventListener('add-cart', h);             // 必须清理
  }, [onAdd]);
  return <add-button ref={ref as any} />;
}
```
