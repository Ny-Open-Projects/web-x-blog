## WCN-345：元素库的动画体系（token 化 motion + FLIP）？
**答**：
- motion token：时长/缓动/距离曲线统一（--ds-motion-fast 等），reduced-motion 全局禁用。
- 列表重排动画：FLIP 模式（First-Last-Invert-Play）封装为容器元素能力。
- 入场动画：connectedCallback + animationend 清理（防动画残留状态）。
- 性能：动画只动 transform/opacity（合成层），layout 动画 lint 拦截。

```javascript
// FLIP 封装
flip(this.shadowRoot.querySelectorAll('.item'), () => { reorder(items); });
// token: animation: slide var(--ds-motion-fast) var(--ds-ease-out);
r
```
