## WCN-467：笔试：实现元素库的浏览器能力探测（特性矩阵 + 降级开关）。
**题目**：探测清单：customElements/DSD/adoptedStyleSheets/popover/anchor。输出 capability 对象与每元素的降级路径选择（如无 DSD → 客户端渲染模式）。

```javascript
function detect() {
  const c = {
    ce: 'customElements' in window,
    dsd: 'shadowRootMode' in HTMLTemplateElement.prototype,
    adopt: 'adoptedStyleSheets' in Document.prototype,
    popover: 'popover' in HTMLElement.prototype,
    anchor: CSS.supports?.('anchor-name: --x') ?? false,
  };
  c.mode = c.dsd && c.adopt ? 'full' : c.ce ? 'legacy' : 'polyfill';
  return c;   // legacy → 元素客户端渲染 + 样式内联降级
}

```

**评分点**：
- 特性检测标准写法（prototype 属性）。
- 能力 → 降级映射表。
- 探测结果缓存（一次会话）。
- 产物分支（加载对应 polyfill 或降级实现）。
