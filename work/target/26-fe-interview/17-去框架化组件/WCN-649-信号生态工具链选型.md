## WCN-649：团队要引入 Signals，@preact/signals、Solid、Vue  Isle 等方案如何选型？

**答**：
- 结论：按「框架绑定程度」选——已用 React 选 @preact/signals（桥接成本低）；新项目追求极致性能选 Solid；Vue 项目直接用 ref/shallowRef 无需外挂。
- 维度：包体积、DevTools 支持、SSR 成熟度、团队学习曲线、与现有构建链兼容。
- 追问钩子：为什么要考虑「退出成本」？考察对「引入新范式后若不合适如何回退」的工程理性。

```javascript
const OPTIONS = {
  '@preact/signals': { sizeKB: 2, reactIntegration: 'good', ssr: 'mature' },
  'solid-js': { sizeKB: 7, reactIntegration: 'bridge', ssr: 'mature' },
  'vue-ref': { sizeKB: 0, reactIntegration: 'none', ssr: 'native' },
};
function pick(stack) {
  return Object.entries(OPTIONS)
    .map(([name, o]) => ({ name, score: scoreFor(stack, o) }))
    .sort((a, b) => b.score - a.score)[0].name;
}
function scoreFor(stack, o) {
  if (stack === 'react') return o.reactIntegration === 'good' ? 10 : 3;
  if (stack === 'vue') return name_o(o); // vue-ref 最优
  return 6;
}
function name_o(o) { return o.reactIntegration === 'none' ? 10 : 5; }
console.log(pick('react')); // @preact/signals
```
