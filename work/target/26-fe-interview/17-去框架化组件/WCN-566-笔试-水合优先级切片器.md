## WCN-566：组件树的「水合优先级切片器」如何按交互评分分组与排序？

**答**：
- 结论：递归遍历组件树计算交互评分，按阈值分到 eager/idle/interaction 三组，输出各组加载顺序与 chunk 名。
- 评分考虑：事件数、是否首屏、业务权重、子树可交互面积。
- 加载顺序：eager 立即 → idle 用 requestIdleCallback → interaction 由事件触发。
- 追问：切片过碎导致请求过多如何控制？（答：合并小 chunk 到相邻优先级，设最小体积阈值）

```javascript
function score(c) {
  return c.events * 3 + (c.aboveFold ? 5 : 0) + (c.weight || 0) + (c.interactiveArea || 0) * 0.1;
}
function slice(tree, { idle = true } = {}) {
  const groups = { eager: [], idle: [], interaction: [] };
  (function visit(n) {
    const s = score(n);
    groups[s >= 10 ? 'eager' : s >= 5 ? 'idle' : 'interaction'].push(n.id);
    (n.children || []).forEach(visit);
  })(tree);
  return {
    groups,
    loadOrder: ['eager', idle ? 'idle' : null, 'interaction'].filter(Boolean),
  };
}
```
