## WCN-597：「性能预算门禁 + 趋势预测」服务如何用线性回归预测超预算？

**答**：
- 结论：服务做两件事——当期门禁（超阈值阻断）与趋势预测（线性回归预测下期是否超预算）。
- 线性回归用最小二乘拟合历史序列，预测下一期值。
- 预测超预算提前告警（软阻断），当期实际超预算硬阻断。
- 追问：历史数据波动大怎么办？（答：用滑动窗口 + 中位数平滑，降低异常点影响）

```javascript
function linearPredict(series) {
  const n = series.length; if (n < 2) return series.at(-1) || 0;
  const xs = series.map((_, i) => i), ys = series;
  const mx = xs.reduce((a,b)=>a+b,0)/n, my = ys.reduce((a,b)=>a+b,0)/n;
  const num = xs.reduce((s,x,i)=>s+(x-mx)*(ys[i]-my),0);
  const den = xs.reduce((s,x)=>s+(x-mx)**2,0) || 1;
  const b = num/den, a = my - b*mx;
  return a + b*n;                                          // 预测下一期
}
function gate(current, history, budget, { hard = 0.2, soft = 0.05 } = {}) {
  const over = current / budget - 1;
  const prediction = linearPredict([...history, current]);
  return { blocked: over > hard, warned: over > soft || prediction > budget,
    prediction: +prediction.toFixed(1), current, budget };
}
```
