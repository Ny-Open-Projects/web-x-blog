## WCN-426：笔试：手写一个自定义元素基类（生命周期/属性反射/渲染节流）。
**答**：`BaseElement`：observedAttributes 声明驱动 attributeChangedCallback；render() 渲染到 shadowRoot；同一帧多次属性变更合并为一次 render（微任务节流）。

```javascript
class BaseElement extends HTMLElement {
  static observedAttributes = [];
  static attrTypes = {};        // { count: 'number' }
  #dirty = false;
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
  }
  attributeChangedCallback(name, _old, value) {
    const t = this.constructor.attrTypes[name];
    this[name] = t === 'number' ? Number(value) : value;
    this.#schedule();
  }
  #schedule() {
    if (this.#dirty) return;
    this.#dirty = true;
    queueMicrotask(() => { this.#dirty = false; this.render(); });   // 同帧合并
  }
  render() { /* 子类实现 */ }
}
class GoodsCard extends BaseElement {
  static observedAttributes = ['sku', 'count'];
  static attrTypes = { count: 'number' };
  render() { this.shadowRoot.innerHTML = `<b>${this.sku} ×${this.count ?? 0}</b>`; }
}
customElements.define('goods-card', GoodsCard);

```

**评分点**：
- 属性变更 → 标脏 → 微任务统一 render（节流合并）。
- connected/disconnected 钩子暴露子类实现。
- attribute 字符串 → 类型化（数字自动转换可配置）。
- render 幂等（重复调用结果一致）。
