## WCN-508：笔试：实现元素「曝光可见性」批处理器（IO 单例 + 曝光去重 + 上报节流）。

**答**：
- 结论：单例 IO 收集可见元素，微任务批量去重后节流上报，避免高频触发打爆 SDK。
- 去重：同一元素只上报一次（Set 记录），移出再进入按「会话内只报首次」策略。
- 节流：固定窗口聚合，窗口结束统一 flush；页面隐藏时立即 flush 兜底。
- 追问：如何支持 0.5/1 多阈值分别上报不同事件？

```javascript
class ExposureBatcher {
  constructor(report, window = 500) {
    this.report = report; this.seen = new Set(); this.buf = []; this.window = window;
    this.io = new IntersectionObserver(es => this.onVisible(es), { threshold: [0.5, 1] });
    this.timer = null;
    document.addEventListener('visibilitychange', () => document.hidden && this.flush());
  }
  onVisible(entries) {
    for (const e of entries) {
      const id = e.target.dataset.trackId;
      const key = `${id}:${e.intersectionRatio >= 1 ? 'full' : 'half'}`;
      if (e.isIntersecting && !this.seen.has(key)) { this.seen.add(key); this.buf.push(key); }
    }
    this.schedule();
  }
  schedule() { if (this.timer) return; this.timer = setTimeout(() => this.flush(), this.window); }
  flush() { if (this.buf.length) this.report(this.buf.splice(0)); this.timer = null; }
  observe(el) { this.io.observe(el); }
}
```

**评分点**：
- IO 单例 + 多阈值
- 曝光去重（会话唯一）
- 窗口节流 + 隐藏兜底 flush
- 批量上报出口清晰
