## WCN-449：笔试：实现元素内的简单虚拟列表（定高滚动窗口）。
**题目**：scroll 容器内：可视范围计算 [start, end]，只渲染该窗口元素（上下缓冲 3 项）；spacer 撑总高；滚动 rAF 节流。

```javascript
class VList extends HTMLElement {
  connectedCallback() {
    this._itemH = 48; this._buf = 3;
    this.addEventListener('scroll', () => {
      if (this._raf) return;
      this._raf = requestAnimationFrame(() => { this._raf = null; this._render(); });
    });
  }
  _render() {
    const start = Math.max(0, Math.floor(this.scrollTop / this._itemH) - this._buf);
    const end = Math.min(this._count, Math.ceil((this.scrollTop + this.clientHeight) / this._itemH) + this._buf);
    this._spacer.style.height = this._count * this._itemH + 'px';
    this._window.style.transform = `translateY(${start * this._itemH}px)`;
    this._paint(this._items.slice(start, end));   // 只画窗口
  }
}

```

**评分点**：
- 窗口计算（scrollTop/height/itemH）。
- 缓冲区（上下 3 项）。
- spacer 高度 = total × itemH（滚动条稳定）。
- rAF 节流（滚动事件一帧一次）。
