## WCN-623：笔试：实现安全的属性渲染器（防 attribute 注入 + 文本转义 + URL 协议白名单）

**答**：
- 需求：实现 safeRender(el, {text, href, style})：text 用文本节点写入；href 仅允许 http/https/mailto；style 过滤 url()/expression()/javascript:。
- 思路：分层处理——文本走 textContent；URL 用 new URL 解析校验 protocol；样式用正则去危险函数（生产用 CSS 解析器）。
- 边界：相对路径允许；大小写混淆（JaVaScRiPt:）要归一化；空值不写属性。

```javascript
function safeRender(el, { text, href, style } = {}) {
  if (text != null) el.textContent = String(text);
  if (href != null) {
    try {
      const u = new URL(href, location.href);
      if (['http:', 'https:', 'mailto:'].includes(u.protocol)) {
        el.setAttribute('href', u.href);
      } else el.removeAttribute('href');
    } catch { el.removeAttribute('href'); }
  }
  if (style != null) {
    const cleaned = String(style)
      .replace(/url\s*\([^)]*\)/gi, '')
      .replace(/expression\s*\([^)]*\)/gi, '')
      .replace(/javascript\s*:/gi, '');
    if (cleaned) el.setAttribute('style', cleaned);
  }
  return el;
}
const a = document.createElement('a');
safeRender(a, { text: '<img onerror=alert(1)>', href: 'javascript:alert(1)' });
console.log(a.textContent, a.getAttribute('href')); // 安全：文本转义，href 被移除
```

**评分点**：
- 文本用 textContent（不解析 HTML），杜绝注入。
- URL 用 URL 解析 + protocol 白名单，大小写混淆归一化。
- 样式过滤 url()/expression()/javascript: 等危险构造。
- 非法值移除属性（而非留空字符串），边界完整。
