## WCN-435：笔试：实现「元素卸载清理」审计工具（监听/定时器/observer 泄漏检测）。
**题目**：开发模式包装 addEventListener/setInterval/observe：登记来源元素；元素断开后仍存活的登记项 → 泄漏清单。

```javascript
const reg = new WeakMap();
function auditRegister(el, kind, ref) {
  const set = reg.get(el) ?? new Set();
  set.add({ kind, ref, stack: new Error().stack.split('\n')[2] });
  reg.set(el, set);
}
function auditLeaks(el) {
  return [...(reg.get(el) ?? [])].filter(x => !x.cleaned)
    .map(x => ({ kind: x.kind, stack: x.stack }));
}
// disconnectedCallback：逐项清理（removeEventListener/clearInterval/disconnect）并标记 cleaned

```

**评分点**：
- 三种资源登记表（listener/timer/observer）。
- disconnectedCallback 自动核销（元素显式清理）。
- 审计：断开后残留项输出（含注册栈）。
- 仅 dev 生效（生产零开销）。
