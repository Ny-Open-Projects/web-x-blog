## WCN-320：编译器响应式与设计系统落地收束（面试答法）。
**答**：
- 编译器系（Solid/Vapor/Svelte5/Qwik/React Compiler）：产物审计验证细粒度，双目标编译保证 SSR 一致，产物缓存控构建成本。
- 设计系统去框架化：token 管线单源多主题、元素 API 规范、文档驱动、共存迁移治理、监控闭环。
- 两线交汇：编译器产物审计 = 设计系统质量门禁的一部分（性能预算）。
- 收束句：去框架化不是技术炫技，是「多框架 + 长寿命 + 统一体验」的工程决策。
