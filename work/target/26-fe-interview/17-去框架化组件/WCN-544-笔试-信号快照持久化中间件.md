## WCN-544：笔试：实现「信号快照持久化中间件」（变化节流 + schema 版本迁移 + localStorage 配额处理）。

**答**：
- 结论：中间件包装 signal，订阅变化做节流快照；读取时按版本迁移；写入捕获 QuotaExceededError 降级。
- 迁移用版本链函数数组逐级升级，缺链则丢弃旧数据并告警。
- 配额满时：淘汰最旧 key 或退化为内存态，保证不抛错中断业务。
- 追问：如何支持自定义存储后端（IndexedDB）？（答：抽象 storage 接口 {get,set,remove}）

```javascript
function persistent(sig, key, storage, { version = 1, migrations = {}, delay = 500 } = {}) {
  let timer;
  const raw = storage.get(key);
  if (raw) {
    try { let { v, data } = JSON.parse(raw);
      while (v < version) { if (!migrations[v]) throw new Error('缺迁移'); data = migrations[v](data); v++; }
      sig.set(data);
    } catch { storage.remove(key); console.warn('[persist] 丢弃不兼容数据', key); }
  }
  sig.subscribe(v => {
    clearTimeout(timer);
    timer = setTimeout(() => {
      try { storage.set(key, JSON.stringify({ v: version, data: v })); }
      catch (e) { if (e.name === 'QuotaExceededError') { storage.remove(key); storage.set(key, JSON.stringify({ v: version, data: v })); } }
    }, delay);
  });
  return sig;
}
```

**评分点**：
- 变化节流快照 + pagehide 兜底
- 版本链迁移
- 配额异常降级不中断
- storage 接口可替换
