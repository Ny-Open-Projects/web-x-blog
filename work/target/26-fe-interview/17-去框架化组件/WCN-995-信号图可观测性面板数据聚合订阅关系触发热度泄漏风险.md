## WCN-995：信号图可观测性面板的数据怎么聚合：订阅关系 / 触发热度 / 泄漏风险

**答**：
- 结论先行：面板数据来自三处埋点——依赖图（谁订阅谁）、触发计数（每个 effect 被唤起几次及耗时）、生命周期（订阅创建/释放时间），聚合成「热点 + 泄漏 + 环」三类视图。
- 订阅关系：effect 执行时记录它读到的 signal，构建 signal→effect 有向图，可视化展示依赖链。
- 触发热度：每次 effect 被调度 +1 并记录耗时，按「触发次数 × 平均耗时」排序找热点（前文自触发检测可复用）。
- 泄漏风险：统计订阅创建后未释放的存活时长、无 effect 订阅但仍被写入的 signal，超阈值标红。
- 追问钩子：面试官问「埋点本身会不会影响性能」——答：用采样 + 环境开关，生产默认关；只在诊断会话按白名单开启，避免全量开销。

```javascript
// 聚合信号图面板数据
function aggregate(events) {
  const graph = {}, heat = {}, created = {};
  for (const e of events) {
    if (e.type === 'read') (graph[e.signal] ||= new Set()).add(e.effect);
    if (e.type === 'run') heat[e.effect] = (heat[e.effect] || 0) + 1;
    if (e.type === 'sub') created[e.effect] = e.at;
  }
  const hotspots = Object.entries(heat).sort((a,b)=>b[1]-a[1]).slice(0,3);
  const leaks = Object.entries(created).filter(([eff])=>!heat[eff]).map(([eff])=>eff);
  return { graph: Object.fromEntries(Object.entries(graph).map(([k,v])=>[k,[...v]])),
    hotspots, leaks };
}
console.log(aggregate([
  { type:'read', signal:'price', effect:'cart' },
  { type:'run', effect:'cart' }, { type:'run', effect:'cart' },
  { type:'sub', effect:'ghost' },
]));
```
