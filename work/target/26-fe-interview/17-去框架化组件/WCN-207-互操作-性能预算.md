## WCN-207：混合渲染（框架页面 + 大量自定义元素）的性能预算如何管理？
**答**：
- 元素定义代码按需加载（customElements.define 前置成本：每元素 ~1-3KB + 注册开销）。
- 关键预算：首屏元素注册完成时间（影响 FCP）、批量元素挂载时长（列表场景）。
- 批量优化：列表元素用「轻量内部渲染」（innerHTML 模板）而非每元素 Shadow 构造。
- 监控：元素级 mount 耗时打点，超出预算（>5ms/元素）告警。

```javascript
customElements.whenDefined('goods-card').then(() => {
  performance.mark('goods-card-defined');
});
// 列表：100 个元素 mount 总时长 < 300ms 预算
const t0 = performance.now();
renderList(100);
performance.measure('list-mount', t0);
```
