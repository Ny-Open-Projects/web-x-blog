## WCN-209：框架侧主题（CSS 变量/类切换）如何可靠穿透 Shadow DOM？
**答**：
- CSS 自定义属性天然继承进 shadow——token 走变量通道（--ds-color-*）。
- ::part 暴露内部结构给外部选择器——元素方声明稳定的 part 清单。
- 主题切换时序：变量在 :root 级切换即全局生效，无需逐元素更新。
- 坑：元素内部用固定值而非 var() 的「遗漏扫描」进 CI（正则查内部样式硬编码颜色）。

```javascript
/* 宿主 */
:root { --ds-color-primary: #165DFF; }
.dark { --ds-color-primary: #4C9AFF; }
/* 元素 shadow 内 */
.button { background: var(--ds-color-primary, #165DFF); }   /* 必须走 var */
```
