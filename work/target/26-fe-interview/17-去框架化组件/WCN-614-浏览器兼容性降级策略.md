## WCN-614：面向低端机与旧浏览器，Web Components 的兼容性降级策略如何设计？

**答**：
- 结论：分层降级——有 Custom Elements/Shadow DOM 用完整能力；缺失时退回「无 Shadow 的 light DOM + 属性协议」；CSS 变量用 @supports 兜底常量值。
- 做法：能力探测 decide mode；polyfill 仅在缺失时动态加载；降级模式用 data-fallback 标记，样式用属性选择器约束。
- 追问钩子：降级会不会让契约不一致？需用契约测试在两种模式下跑同一套断言——考察对「一致性验证」的重视。

```javascript
function detectMode() {
  const ce = 'customElements' in window;
  const sd = 'ShadowRoot' in window && 'attachShadow' in HTMLElement.prototype;
  const cssVar = window.CSS?.supports?.('(--x: 1)');
  return { ce, sd, cssVar, mode: ce && sd ? 'full' : 'fallback' };
}
const env = detectMode();
if (!env.ce) await import('@webcomponents/custom-elements');
class DsCard extends HTMLElement {
  connectedCallback() {
    if (env.sd) {
      const r = this.attachShadow({ mode: 'open' });
      r.innerHTML = '<slot></slot>';
    } else {
      this.classList.add('ds-card--fallback');
    }
  }
}
customElements.define('ds-card', DsCard);
```
