## WCN-210：自定义表单控件（formAssociated）与 React 状态库（react-hook-form）的集成？
**答**：
- formAssociated 元素参与原生表单校验与 FormData 序列化——react-hook-form 走 HTML 表单模式（应模式）即可消费。
- value 属性双向：RHF 注册 ref → setValue 设元素 property，元素 input 事件回报。
- 校验状态：元素内部 setValidity() 与 RHF 的 rules 同步（重复校验二选一）。
- 建议：元素只管「原生语义」（value/validity），校验策略留给宿主框架——职责分离。

```javascript
const { register } = useForm();
<form>
  <rating-input ref={register('score').ref} name="score" required />
  {/* 元素 formAssociated: true → FormData 自动包含 score 与原生校验 */}
</form>

```
