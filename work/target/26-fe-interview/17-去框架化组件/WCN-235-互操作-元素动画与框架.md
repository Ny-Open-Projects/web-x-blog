## WCN-235：元素入场/离场动画与框架卸载时序（React/Vue transition）的协调？
**答**：
- 元素自身实现入场动画（connectedCallback 后 CSS animation）——框架无需参与。
- 离场动画：元素提供 hide() Promise API；React 无原生卸载动画——适配包实现「延迟卸载」包装。
- Vue 用 Transition 包裹（WC 是普通 DOM 节点，Vue transition 兼容）。
- 规范：动画时长 token 化（--ds-motion-duration），reduced-motion 尊重。

```javascript
// React 适配：延迟卸载
function useDelayedUnmount(show: boolean, hide: () => Promise<void>) {
  const [mounted, setMounted] = useState(show);
  useEffect(() => { if (show) setMounted(true); }, [show]);
  // show→false 时调用 hide() 等 Promise 再 setMounted(false)
}
```
