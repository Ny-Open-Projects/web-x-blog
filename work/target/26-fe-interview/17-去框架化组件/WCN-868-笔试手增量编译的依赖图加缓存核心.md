## WCN-868：笔试：手写增量编译的「依赖图 + 缓存」核心（文件变更 → 最小重编）

**题目**：实现 `createIncrementalCompiler()`，返回 `{ setSource(file, code), addDependency(from, to), build(entry), getStats() }`。要求：① `addDependency(from,to)` 表示 from 依赖 to（to 变化时 from 需重编）；② `setSource` 更新源码并记录内容哈希；③ `build(entry)` 只重新编译「entry 及其传递依赖中，源码哈希自上次编译后变化」的文件，未变且缓存有效则复用；④ 缓存 key 含源码哈希；⑤ `getStats()` 返回 `{ compiled, reused, total }`（本次编译数、复用数、总文件数）。边界：循环依赖要能处理不死循环；从未编译过的文件必编译；依赖不存在不报错。

**答**：

```javascript
function createIncrementalCompiler() {
  const sources = new Map(), hashes = new Map(), cache = new Map();
  const deps = new Map();   // file -> Set<依赖的文件>
  const hash = s => [...s].reduce((h, c) => (h * 31 + c.charCodeAt(0)) | 0, 0);
  return {
    setSource(file, code) { sources.set(file, code); hashes.set(file, hash(code)); },
    addDependency(from, to) {
      if (!deps.has(from)) deps.set(from, new Set());
      deps.get(from).add(to);
    },
    build(entry) {
      const compiled = [], visited = new Set();
      const walk = (file) => {
        if (visited.has(file)) return;            // 防循环依赖死循环
        visited.add(file);
        for (const d of (deps.get(file) || [])) if (sources.has(d)) walk(d);
        const h = hashes.get(file);
        const cached = cache.get(file);
        if (cached && cached.hash === h) return;  // 复用
        cache.set(file, { hash: h, code: `/*build*/${sources.get(file) || ''}` });
        compiled.push(file);
      };
      if (sources.has(entry)) walk(entry);
      const reused = visited.size - compiled.length;
      return { compiled, reused, total: visited.size };
    },
    getStats() {
      return { compiled: cache.size, cachedFiles: [...cache.keys()] };
    },
  };
}
// 用法
const c = createIncrementalCompiler();
c.setSource('main.js', 'import"./a"'); c.setSource('a.js', 'const a=1');
c.addDependency('main.js', 'a.js');
console.log(c.build('main.js')); // 首次：全部编译
console.log(c.build('main.js')); // 再次：全部复用
c.setSource('a.js', 'const a=2');
console.log(c.build('main.js')); // 只重编 a.js（main 复用）
```

**评分点**：
- 内容哈希作缓存 key，未变复用（增量核心）。
- 传递依赖遍历 + visited 防循环（正确性）。
- 复用与重编统计准确，区分首次与后续（可观测）。
- 依赖不存在/循环依赖的边界处理（健壮性）。
