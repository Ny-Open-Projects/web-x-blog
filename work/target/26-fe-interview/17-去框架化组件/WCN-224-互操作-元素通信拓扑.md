## WCN-224：嵌套自定义元素（父元素内含子元素）的通信拓扑设计？
**答**：
- 父子：父元素内部直接引用子元素实例（同 shadow 内，property 直调），不走全局事件。
- 跨 shadow 的公共 API：父元素暴露方法（part of public API 文档化）。
- 事件冒泡：composed: true 才能穿 shadow——明确哪些事件对外（API 事件）哪些内部。
- 避免「事件总线直通根」：层级深时用「容器元素」集中协调而非逐级冒泡。

```javascript
class GoodsList extends HTMLElement {
  async refresh() {
    const items = this.shadowRoot.querySelectorAll('goods-card');
    await Promise.all([...items].map(el => el.refresh()));   // 直接 API 调用
  }
}
```
