## WCN-443：笔试：实现 Menu 元素的键盘导航（上下/回车/ESC，ARIA activedescendant）。
**题目**：列表项不聚焦（aria-activedescendant 指向 activeId）；ArrowDown/Up 移动 active；Enter 派发 select；Escape 关闭并 focus 回触发器。

```javascript
class DsMenu extends HTMLElement {
  #active = -1;
  #onKey(e) {
    const items = this.#itemIds();
    if (e.key === 'ArrowDown') { this.#active = (this.#active + 1) % items.length; e.preventDefault(); }
    else if (e.key === 'ArrowUp') { this.#active = (this.#active - 1 + items.length) % items.length; e.preventDefault(); }
    else if (e.key === 'Enter') {
      const id = items[this.#active];
      this.dispatchEvent(new CustomEvent('select', { detail: { id }, bubbles: true, composed: true }));
    } else if (e.key === 'Escape') {
      this.#close();
      this._trigger.focus();   // 焦点还原
    }
    this.#internals.root.querySelector('[role=menubox]')
      ?.setAttribute('aria-activedescendant', items[this.#active] ?? '');
  }
}

```

**评分点**：
- activedescendant 模式（焦点保持容器）。
- 循环边界（末项下移回首项）。
- ESC 关闭 + 焦点还原。
- select detail 类型化。
