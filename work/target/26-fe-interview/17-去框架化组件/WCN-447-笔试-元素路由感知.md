## WCN-447：笔试：实现元素的「路由状态协议」注入与导航请求。
**题目**：宿主传 route property（{path, params}）；元素派发 nav-request 事件；适配层映射到框架路由。断言：元素源码无 location/history 引用（lint）。

```javascript
// 元素侧
set route(r) { this._route = r; this._render(); }
goto(to) { this.dispatchEvent(new CustomEvent('nav-request',
  { detail: { to }, bubbles: true, composed: true })); }
// React 适配
<ds-breadcrumb route={{ path: location.pathname }}
  on-nav-request={(e) => navigate(e.detail.to)} />

```

**评分点**：
- route property 快照注入（path/params）。
- 导航只发意图事件（元素不碰 location）。
- lint 规则（location|history 在元素目录 → fail）。
- 路由变化 → property 更新 → 元素重渲染。
