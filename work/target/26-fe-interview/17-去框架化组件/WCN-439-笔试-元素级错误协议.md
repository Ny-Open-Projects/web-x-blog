## WCN-439：笔试：实现元素的统一错误协议（内部 try/catch + ds-error 事件）。
**题目**：`safe(el, phase, fn)`：包裹生命周期/渲染函数，异常捕获 → 派发 `ds-error`（detail {phase, code, message, recoverable}）→ 元素进入降级态。

```javascript
function safe(el, phase, fn) {
  try { return fn(); }
  catch (e) {
    el.dispatchEvent(new CustomEvent('ds-error', {
      detail: { phase, code: e.name, message: String(e).slice(0, 120),
                recoverable: phase !== 'connected' },
      bubbles: true, composed: true }));
    el.dataset.error = phase;   // 降级标记（客户端可重试）
    return null;
  }
}
class X extends HTMLElement {
  connectedCallback() { safe(this, 'connected', () => this._init()); }
  render() { safe(this, 'render', () => { this.shadowRoot.innerHTML = this._html(); }); }
}

```

**评分点**：
- phase 标注（connected/render/attributeChanged）。
- 错误分级（recoverable 判断）。
- 降级态渲染（skeleton + data-error）。
- 全局收集器配合（宿主单点监听归因）。
