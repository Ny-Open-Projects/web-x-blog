## WCN-652：笔试：实现模板编译器的依赖收集与渲染函数生成（插值 → 更新函数）

**答**：
- 需求：给定模板字符串含插值 {{ expr }}，实现 compile(template) 返回 { render, deps }：render(state) 输出 HTML；deps 列出表达式引用的变量名，用于生成精准更新。
- 思路：正则提取插值表达式；解析标识符作为依赖；生成拼接字符串函数；deps 去重。
- 边界：表达式含成员访问 obj.a 取根标识符 obj；重复插值去重；无插值返回静态函数。

```javascript
function compile(tpl) {
  const deps = new Set();
  const parts = [];
  const re = /\{\{([^}]+)\}\}/g;
  let last = 0, m;
  while ((m = re.exec(tpl))) {
    parts.push(JSON.stringify(tpl.slice(last, m.index)));
    const expr = m[1].trim();
    (expr.match(/[A-Za-z_$][\w$]*/g) || []).forEach(id => deps.add(id));
    parts.push(`String(state.${expr} ?? '')`);
    last = re.lastIndex;
  }
  parts.push(JSON.stringify(tpl.slice(last)));
  const body = `return ${parts.join(' + ')};`;
  const render = new Function('state', body);
  return { render, deps: [...deps] };
}
const { render, deps } = compile('<p>你好 {{ name }}，{{ count }}</p>');
console.log(render({ name: '张三', count: 3 }));
console.log(deps); // ['name', 'count']
```

**评分点**：
- 正确提取所有 {{ }} 插值并生成拼接渲染函数。
- 依赖变量名（含成员访问取根）收集准确且去重。
- 用 new Function 生成可执行的 render（或等价 AST 方案）。
- 边界处理：无插值/重复插值/末尾文本不丢失。
