## WCN-820：笔试：手写「利益相关方影响力矩阵」分析工具（推动 WC 标准落地）

**题目**：标准推广前需分析干系人。输入人员数组 `{ name, power: 1~5, interest: 1~5, stance: 'support|neutral|oppose' }`。要求：① 按 power/interest 是否 ≥4 划分为四象限：`key(重点管理)/keep(令其满意)/inform(随时告知)/monitor(监督)`；② 计算「支持度指数」= support +1、neutral 0、oppose −1，按象限汇总求平均；③ 找出「高权力且反对」的高危干系人（power≥4 且 stance=oppose），他们最可能否决标准；④ 返回 `{ quadrants, supportIndex, blockers }`。边界：空数组返回空结构；分值越界按 1~5 截断；同一象限内按 power 降序。

**答**：

```javascript
function stakeholderMatrix(people) {
  if (!Array.isArray(people) || !people.length) {
    return { quadrants: {}, supportIndex: {}, blockers: [] };
  }
  const clamp = n => Math.max(1, Math.min(5, Number(n) || 1));
  const STANCE = { support: 1, neutral: 0, oppose: -1 };
  const quadrants = {}, sums = {}, counts = {}, blockers = [];

  for (const p of people) {
    const power = clamp(p.power), interest = clamp(p.interest);
    const q = power >= 4 && interest >= 4 ? 'key'
            : power >= 4 ? 'keep'
            : interest >= 4 ? 'inform' : 'monitor';
    (quadrants[q] ||= []).push({ name: p.name, power });
    sums[q] = (sums[q] || 0) + (STANCE[p.stance] ?? 0);
    counts[q] = (counts[q] || 0) + 1;
    if (power >= 4 && p.stance === 'oppose') blockers.push(p.name);
  }
  // 象限内按权力降序，便于先看最有权的人
  for (const q of Object.keys(quadrants)) {
    quadrants[q].sort((a, b) => b.power - a.power);
  }
  const supportIndex = {};
  for (const q of Object.keys(sums)) {
    supportIndex[q] = +(sums[q] / counts[q]).toFixed(2);
  }
  return { quadrants, supportIndex, blockers };
}

console.log(stakeholderMatrix([
  { name: '架构委主席', power: 5, interest: 5, stance: 'oppose' },
  { name: '业务VP',     power: 5, interest: 2, stance: 'support' },
  { name: '一线开发',   power: 2, interest: 5, stance: 'neutral' },
]));
```

**评分点**：
- 象限判定用 power/interest ≥4 的明确阈值，四分支互斥且完整（逻辑正确）。
- 越界分值 clamp 到 1~5，脏输入不污染结果（边界处理）。
- 支持度按象限加权汇总而非全局平均，能定位「哪个圈层不支持」（分析深度）。
- 高危 blockers 单独检出（高权力+反对），直接服务「先搞定谁」的决策（业务价值）。
