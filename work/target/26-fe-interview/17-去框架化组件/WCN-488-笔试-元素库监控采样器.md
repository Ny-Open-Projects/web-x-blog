## WCN-488：笔试：实现监控上报的采样器（错误全量 + 性能按率 + 布隆去重）。
**答**：规则：error 类型全量；perf 类型按 sampleRate 采样；同 fingerprint 5 分钟内去重（WeakSet/时间窗）。

```javascript
function sampler({ perfRate = 0.1, dedupMs = 300_000 } = {}) {
  const seen = new Map();
  return {
    should(e, now = Date.now()) {
      if (e.type === 'error') {
        const k = e.fingerprint;
        if (now - (seen.get(k) || 0) < dedupMs) return false;  // 错误也去重风暴
        seen.set(k, now); return true;
      }
      return (e.fingerprintHash % 100) / 100 < perfRate;       // 稳定分桶采样
    },
  };
}

```

**评分点**：
- 类型分级策略。
- 采样判定（rate + hash 分桶稳定性——同 key 同决策）。
- 时间窗去重（fingerprint → lastTs）。
- 统计（真实量估算 = 采样量 / rate）。
