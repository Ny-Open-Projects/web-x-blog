## WCN-591：笔试：实现「视觉差异归因器」（像素 diff → 定位到具体元素 + token 差异）。

**答**：
- 结论：接收 diff 区域坐标，用 elementFromPoint 定位元素，读取其计算样式与 token 值，与设计基准比对输出差异。
- 对 diff 区域聚类（多个 bbox 合并），避免同一问题重复报告。
- token 差异对比设计基准值，输出「期望 token 值 vs 实际值」。
- 追问：元素在 iframe/shadow 中如何定位？（答：递归穿透 shadowRoot.elementFromPoint 与 frame 坐标换算）

```javascript
function attributeDiff(diffBoxes, pageEval, baselineTokens) {
  const merged = mergeBoxes(diffBoxes);                  // 聚类相邻区域
  return merged.map(box => {
    const hit = pageEval(b => {
      let el = document.elementFromPoint(b.x, b.y);
      const chain = [];
      while (el) { chain.push(el); el = el.shadowRoot?.elementFromPoint(b.x, b.y) || null; }
      const el2 = chain.at(-1);
      const cs = getComputedStyle(el2);
      return { tag: el2.tagName, vars: Object.fromEntries(['--ds-color','--ds-space','--ds-radius'].map(k => [k, cs.getPropertyValue(k).trim()])) };
    }, box);
    const tokenDiff = Object.entries(hit.vars).filter(([k, v]) => baselineTokens[k] && v !== baselineTokens[k])
      .map(([k, v]) => ({ token: k, expected: baselineTokens[k], actual: v }));
    return { box, element: hit.tag, tokenDiff };
  });
}
function mergeBoxes(boxes, gap = 10) { return boxes.reduce((acc, b) => { const last = acc.at(-1); if (last && b.x - last.x < gap) { last.w = Math.max(last.w, b.w); } else acc.push({ ...b }); return acc; }, []); }
```

**评分点**：
- diff 区域聚类去重
- 穿透 shadow/iframe 定位
- token 期望 vs 实际比对
- 输出可整改归因
