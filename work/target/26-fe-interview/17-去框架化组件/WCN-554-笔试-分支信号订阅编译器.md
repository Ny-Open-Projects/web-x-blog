## WCN-554：笔试：实现「分支信号订阅」编译器（每个分支独立 effect + 切换时 dispose 旧订阅）。

**答**：
- 结论：把 if 节点编译成「选择函数 + 分支工厂」，运行时按条件选分支，切换时清理旧 effect 并重建。
- 每个分支的 effect 独立收集依赖，条件信号变化时只重建被激活的分支。
- 提供分支缓存开关，权衡「重建开销」与「内存占用」。
- 追问：嵌套 if 如何正确传递清理？（答：父分支 dispose 时递归 dispose 其子分支）

```javascript
function compileConditional(node) {
  const branches = node.branches.map(b => ({ test: b.test, build: b.build }));
  return function mount(host) {
    let active = null, activeTest = null;
    function select() {
      const hit = branches.find(b => !b.test || b.test());
      if (hit === activeTest) return;
      if (active) { active.dispose(); active = null; }     // 递归清理子分支
      activeTest = hit;
      active = createEffect(() => hit.build(host));
    }
    const cond = createEffect(select);                    // 条件信号驱动
    return { dispose() { cond.dispose(); active?.dispose(); } };
  };
}
```

**评分点**：
- 分支独立 effect 隔离依赖
- 切换 dispose 旧订阅
- 嵌套分支递归清理
- 分支缓存权衡
