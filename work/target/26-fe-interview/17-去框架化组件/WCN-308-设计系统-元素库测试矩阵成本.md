## WCN-308：元素库测试矩阵（浏览器×主题×视口）的成本控制？
**答**：
- 分层：行为测试（单浏览器全量）→ 视觉（全浏览器抽样组件）→ a11y（单浏览器全量 axe + 键盘）。
- 主题矩阵只在 token 层测对比度 + 抽样视觉——不在全组件全主题爆炸。
- 视口：组件级 3 视口抽样。
- 预算：全矩阵时长预算 + 用例元数据声明矩阵需求（按需扩）。

```javascript
const matrixPolicy = {
  behavior: 'chromium × 全量',
  visual: '全浏览器 × top20 组件 × 3 视口',
  a11y: 'chromium 全量 axe + 键盘',
  theme: 'token 对比度全量 + 视觉抽样',
};
```
