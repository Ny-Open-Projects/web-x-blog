## WCN-236：元素测试基建（fixture 加载/属性注入/事件断言）的标准化？
**答**：
- 统一 fixture 工具：createFixture(tag, props, children) 返回挂载好的元素 + 清理函数。
- 属性注入断言：waitForProperty(el, 'value', v) 轮询 property（异步渲染场景）。
- 事件断言：oneEvent(el, 'add-cart') Promise 化（超时失败）。
- 基建独立包（@ds/test-kit），所有元素测试同构（vitest browser mode 或 Playwright）。

```javascript
const { el, cleanup } = await createFixture('goods-card', { sku: 'A1' });
const ev = oneEvent(el, 'add-cart');
el.shadowRoot.querySelector('button')!.click();
const { detail } = await ev;
expect(detail.sku).toBe('A1');
await cleanup();
```
