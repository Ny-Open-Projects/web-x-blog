## WCN-665：编译期常量折叠与表达式优化能带来什么收益？实现上有哪些注意点？

**答**：
- 结论：把编译期可确定的常量表达式（1+2、'a'+'b'）提前算好，减小运行时体积与计算；同时可消除死代码。
- 注意：只在语义等价前提下折叠（浮点/大数需谨慎）；副作用表达式不可折叠；折叠后可能触发新的折叠（迭代到不动点）。
- 追问钩子：为什么要小心 JS 的 + 运算？因为 1+'2' 是字符串拼接，需按 JS 语义精确模拟——考察对「编译正确性优先于优化」的认知。

```javascript
function fold(node) {
  if (node.type === 'binary') {
    const l = fold(node.left), r = fold(node.right);
    if (l.type === 'lit' && r.type === 'lit') {
      if (node.op === '+' && typeof l.v === 'number' && typeof r.v === 'number')
        return { type: 'lit', v: l.v + r.v }; // 纯数字才折叠
      if (node.op === '*' && typeof l.v === 'number' && typeof r.v === 'number')
        return { type: 'lit', v: l.v * r.v };
    }
    return { ...node, left: l, right: r };
  }
  return node;
}
const ast = { type: 'binary', op: '+',
  left: { type: 'lit', v: 1 }, right: { type: 'lit', v: 2 } };
console.log(fold(ast)); // { type:'lit', v:3 }：编译期算出
```
