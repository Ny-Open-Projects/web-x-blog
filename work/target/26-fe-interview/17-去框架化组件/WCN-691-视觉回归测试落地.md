## WCN-691：视觉回归测试（截图 diff）在设计系统落地时有哪些坑？如何降低误报？

**答**：
- 结论：坑在「环境差异导致误报」——字体/渲染引擎/DPR/动画时序不同都会产生差异；关键是固定环境 + 只比对稳定状态 + 合理阈值。
- 做法：用容器固定浏览器版本与字体；禁用动画/等待字体加载；设像素容差与忽略区域；基线更新需人工审核。
- 追问钩子：为什么不能只看 diff 百分比？因为一个像素位移在关键区域（按钮文字）比大片背景差异更严重——考察对「差异权重」的理解。

```javascript
function compareScreens(base, current, options = {}) {
  const { tolerance = 0.01, ignoreRegions = [] } = options;
  let changed = 0, total = base.length;
  for (let i = 0; i < total; i++) {
    if (ignoreRegions.some(r => i >= r.start && i < r.end)) continue;
    const diff = Math.abs(base[i] - current[i]) / 255;
    if (diff > tolerance) changed++;
  }
  return { ratio: changed / total, pass: changed / total <= tolerance };
}
// 固定环境：同一浏览器版本 + 禁用动画 + 等待字体
console.log(compareScreens(
  [100, 100, 100, 100], [100, 100, 105, 100], { tolerance: 0.01 }
));
```
