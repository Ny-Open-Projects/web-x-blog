## WCN-540：「信号图分片」隔离器如何让模块 A 的脏标记不扩散到模块 B？

**答**：
- 结论：每个分片维护独立的脏集合与依赖边，flush 只遍历本分片；跨分片依赖需注册为 external 边界。
- 脏标记传播遇 external 边即停，改为通知目标分片调度，而非直接并入脏集。
- 分片可独立 dispose，清空本片所有订阅与信号。
- 追问：如何审计「非法跨域直连」？（答：依赖建立时校验 from/to 分片，跨域未声明则告警）

```javascript
class Shard {
  constructor(id) { this.id = id; this.dirty = new Set(); this.external = new Map(); }
  add(s, deps) { s.shard = this; s.deps = deps; return s; }
  mark(s) {
    if (s.shard !== this) { this.external.get(s.shard)?.(s); return; }  // 跨域交边界
    if (this.dirty.has(s)) return;
    this.dirty.add(s);
    (s.deps || []).forEach(d => this.mark(d));
  }
  flush() { const list = [...this.dirty]; this.dirty.clear(); list.forEach(s => s.run?.()); }
  link(other, cb) { this.external.set(other, cb); }
  dispose() { this.dirty.clear(); this.external.clear(); }
}
```
