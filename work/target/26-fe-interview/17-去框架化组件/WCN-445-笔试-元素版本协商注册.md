## WCN-445：笔试：实现元素的防御式注册（同名检测/版本对比/复用）。
**题目**：`defineOnce(tag, Impl, version)`：已注册 → 版本对比（同版本复用静默；低版本注册高版本 → 告警复用；高版本注册低版本 → 允许升级？简化：报错建议宿主统一）；未注册 → 注册。

```javascript
function cmpVer(a, b) {
  const [x, y] = a.split('.').map(Number), [p, q] = b.split('.').map(Number);
  return x !== p ? x - p : y - q;
}
function defineOnce(tag, Impl, version = '1.0.0') {
  const existing = customElements.get(tag);
  if (existing) {
    const regVer = document.querySelector(tag)?.dataset.version ?? '0.0.0';
    if (cmpVer(regVer, version) > 0)
      console.warn(`[${tag}] 已注册更高版本 ${regVer}，复用现有定义（请统一版本）`);
    return existing;
  }
  customElements.define(tag, Impl);
  return Impl;
}

```

**评分点**：
- customElements.get 前置检查。
- 版本比较（semver 主次）。
- 冲突输出协商建议（平台层统一）。
- 注册时间与版本写 data-version。
