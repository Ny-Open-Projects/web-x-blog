## WCN-213：自定义元素的多框架宿主测试矩阵如何设计？
**答**：
- 元素本体测试：纯浏览器环境（无框架）验证行为/样式/a11y——单一事实层。
- 桥接层测试：每框架适配包的最小用例（property 传递/事件回调/卸载清理）。
- 集成冒烟：每框架一个「元素组合页面」E2E（覆盖典型业务场景）。
- 矩阵成本控制：元素测试全量，桥接冒烟每框架 10 条内，集成 3-5 条。

```javascript
const matrix = {
  element: 'playwright + 无框架（全量行为）',
  bridge: { react: 10, vue: 10, svelte: 8 },   // property/事件/卸载
  integration: '每框架 3-5 条核心旅程',
};
```
