## WCN-200：收官自测：10 道高频快问快答（电梯陈述版）

**答**：
- Q1 WC 三大标准缺什么？——缺状态层，用 Signals 补齐（001/032/061）。
- Q2 Shadow DOM 是安全边界吗？——不是，只是封装边界；不可信代码用 iframe sandbox（006/028）。
- Q3 attribute 变化回调为什么没触发？——没进 observedAttributes，或时序在升级前（004/016）。
- Q4 组件样式被外部污染/污染外部？——影子树隔离 + 可继承属性显式重置 + token 穿透（007/014）。
- Q5 Signals 比 VDOM 快在哪？——免重跑/免 diff/精确更新，push-pull 脏标记（068/063）。
- Q6 effect 泄漏怎么防？——connected/disconnected 配对 + dispose 清依赖（078/090）。
- Q7 React 里 WC 的对象 props 丢失？——React18 序列化限制，19 原生支持或包装器 property 分流（102/110）。
- Q8 什么情况不要上 WCN？——单栈消费方、高频迭代、强依赖宿主生态（120/146）。
- Q9 编译器路线怎么选？——看更新粒度诉求（Solid/Vapor）vs 启动成本（Qwik）vs 兼容性（React Compiler）（140/145）。
- Q10 线上组件事故怎么兜底？——加载器熔断回滚 + SafeElement 降级 + tag/version 归因监控（176/186/149）。
