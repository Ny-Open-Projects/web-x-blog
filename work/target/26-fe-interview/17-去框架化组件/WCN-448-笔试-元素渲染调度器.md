## WCN-448：笔试：实现元素的渲染调度（写合并 + 优先级）。
**题目**：`scheduleRender(el, fn, {priority})`：高优（交互反馈）同步/微任务；低优（数据刷新）idle。同优先级合并（一帧一次）。

```javascript
function scheduleRender(el, fn, { priority = 'low' } = {}) {
  if (el.__pending) return;
  el.__pending = true;
  const run = () => { el.__pending = false; if (el.isConnected) fn(); };
  if (priority === 'high') queueMicrotask(run);
  else (window.requestIdleCallback || (cb => setTimeout(cb, 50)))(run);
}
// disconnectedCallback: el.__pending = false（取消）

```

**评分点**：
- 两档调度（microtask/idle）。
- 合并去重（pending 标志）。
- idle 不可用时回退 setTimeout（兼容）。
- 卸载取消（pending 不执行）。
