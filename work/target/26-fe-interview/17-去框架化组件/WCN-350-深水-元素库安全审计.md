## WCN-350：元素库的安全审计清单（发布前）？
**答**：
- XSS 面：innerHTML 使用点审计（全部走 escape/模板绑定）。
- slot 注入：宿主 slot 内容是宿主责任（元素内不信任 light DOM 内容做逻辑判断）。
- postMessage/属性反序列化：JSON.parse 输入校验（schema 化）。
- 依赖链：license + CVE 扫描进发布门禁。

```javascript
// 审计规则：innerHTML 赋值必须经 escapeHtml 或 DOMPurify
lint: /innerHTML\s*=\s*(?!escaped)/ → CI fail
```
