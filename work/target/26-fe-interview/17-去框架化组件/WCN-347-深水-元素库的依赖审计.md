## WCN-347：元素库依赖审计（第三方依赖最小化）？
**答**：
- 原则：运行时零依赖为理想（浏览器标准能力足够）——图表/复杂逻辑才引依赖。
- 审计：bundle 内依赖清单 + 许可证扫描 + 体积占比。
- 依赖隔离：第三方库包在内部模块（不暴露给元素 API 面）。
- 升级：依赖升级走全量矩阵回归（元素行为不变验证）。

```javascript
# 依赖审计
knip + license-checker → dist 依赖清单
预算：运行时依赖 ≤ 3 个，单依赖 ≤ 30KB gzip
r
```
