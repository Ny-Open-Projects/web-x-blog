## WCN-489：笔试：实现元素库健康分（五维加权）。
**题目**：维度：预算达成率/错误率（每 mount）/采纳增长/flaky 率/文档新鲜度。健康分加权 0-100；< 60 输出最差维度治理建议。

```javascript
const W = { budget: 0.2, error: 0.25, adoption: 0.15, flaky: 0.2, docs: 0.2 };
function health({ budgetRate, errPerMount, adoptionGrowth, flakyRate, docsFreshRate }) {
  const f = { budget: budgetRate, error: 1 - Math.min(1, errPerMount * 100),
    adoption: Math.min(1, Math.max(0, adoptionGrowth)), flaky: 1 - flakyRate, docs: docsFreshRate };
  const score = Math.round(Object.entries(f).reduce((s, [k, v]) => s + v * W[k], 0) * 100);
  const worst = Object.entries(f).sort((a, b) => a[1] - b[1])[0][0];
  return { score, worst,
    advice: score < 60 ? `优先治理 ${worst}` : '健康' };
}
console.log(health({ budgetRate: 0.95, errPerMount: 0.002, adoptionGrowth: 0.1,
  flakyRate: 0.01, docsFreshRate: 0.9 }).score); // 高分

```

**评分点**：
- 五维归一（各 0-1）。
- 权重表可配。
- 最差维度诊断（治理切入点）。
- 趋势对比（环比）。
