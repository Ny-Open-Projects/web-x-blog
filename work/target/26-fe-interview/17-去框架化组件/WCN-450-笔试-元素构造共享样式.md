## WCN-450：笔试：实现元素库的全局 constructable stylesheet 管理（共享/版本）。
**答**：`sharedSheet(id, css)`：同 id 复用（缓存 Map），否则 new CSSStyleSheet().replaceSync；`adopt(el, ids)`：按序 adopt 到元素 shadow。

```javascript
const sheets = new Map();
function sharedSheet(id, css) {
  if (sheets.has(id)) return sheets.get(id);
  const s = new CSSStyleSheet();
  try { s.replaceSync(css); } catch (e) { console.warn(`[sheet ${id}] CSS 错误`, e); }
  sheets.set(id, s);
  return s;
}
function adopt(el, ids) {
  el.shadowRoot.adoptedStyleSheets = ids.map(id => sheets.get(id)).filter(Boolean);
}
// 100 个 ds-button → 一份 button 样式实例

```

**评分点**：
- 缓存复用（同 id 一份 StyleSheet 实例）。
- adopt 顺序（base → 组件 → 主题覆盖）。
- replaceSync 失败容错（CSS 语法错不崩）。
- 体积收益说明（N 元素一份样式）。
