## WCN-462：笔试：实现页面元素注册的冲突预检（CI 扫描 define 调用）。
**题目**：扫描代码库全部 `customElements.define('tag', ...)`：同 tag 多定义（跨仓/跨版本）→ 冲突清单；未按命名空间（无前缀域）→ 告警。

```javascript
function conflictScan(defines) {
  const by = new Map();
  for (const d of defines) {
    if (!by.has(d.tag)) by.set(d.tag, []);
    by.get(d.tag).push(d);
  }
  const conflicts = [...by].filter(([, list]) => list.length > 1)
    .map(([tag, list]) => ({ tag, files: list.map(d => d.file) }));
  const noNs = [...by.keys()].filter(t => t.split('-').length < 2);
  return { conflicts, noNamespace: noNs };
}
console.log(conflictScan([
  { tag: 'goods-card', file: 'repoA/x.js' }, { tag: 'goods-card', file: 'repoB/y.js' },
]).conflicts.length); // 1

```

**评分点**：
- 正则扫描 define 调用（tag 提取）。
- 冲突分组（同 tag 多处定义）。
- 命名空间规范检查（域前缀 - 分隔）。
- 输出治理清单（归属仓/文件）。
