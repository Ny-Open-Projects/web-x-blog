## WCN-219：自定义元素的懒注册（ intersection/路由触发 define）实现要点？
**答**：
- 占位策略：注册前 DOM 上放骨架（或 DSD 静态内容），避免布局跳动（CLS）。
- 触发器：IntersectionObserver（进入视口再 define+加载实现 chunk）。
- whenDefined Promise 化封装给宿主等待；竞态保护（重复触发只加载一次）。
- 代价：首交互延迟——只对非关键元素启用（页脚图表/重组件）。

```javascript
const lazyDefine = (tag, loader) => {
  const io = new IntersectionObserver(async (es) => {
    for (const e of es) if (e.isIntersecting) {
      io.disconnect();
      await loader();   // chunk 内 customElements.define(tag, Impl)
    }
  });
  io.observe(document.querySelector(tag));
};
```
