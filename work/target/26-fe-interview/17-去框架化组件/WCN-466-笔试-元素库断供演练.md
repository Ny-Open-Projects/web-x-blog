## WCN-466：笔试：实现「元素实现 chunk 加载失败」的降级演练判定。
**题目**：模拟 chunk 404：页面行为评估——静态内容（DSD）可读/交互缺失有提示/无白屏。判定函数：输入页面快照指标（可读节点数/交互失败提示数），输出 pass/fail。

```javascript
function degradeJudge({ readableNodes, totalDsdElements, hintCount, failedHydrate }) {
  const readableOk = readableNodes >= totalDsdElements * 0.9;    // 90% 可读
  const hintOk = hintCount >= failedHydrate;                     // 每个失败水合有提示
  const noBlank = readableNodes > 0;
  return { pass: readableOk && hintOk && noBlank,
    detail: { readableOk, hintOk, noBlank } };
}
console.log(degradeJudge({ readableNodes: 9, totalDsdElements: 10,
  hintCount: 2, failedHydrate: 2 }).pass); // true

```

**评分点**：
- 降级三判据（可读/提示/无白屏）。
- 可读节点 = DSD 内容存在的元素数。
- 交互缺失提示覆盖（每未水合元素有提示）。
- 演练自动化（注入 404 后断言）。
