## WCN-427：笔试：实现元素属性的 attr/prop 双通道适配器（框架无关）。
**题目**：`defineProps(Class, spec)`：spec `{name: {attr: true, type, reflect}}`。生成：attribute 解析（类型转换/JSON 容错）、property setter（触发渲染）、reflect 回写（原始值 only）。

```javascript
function defineProps(Class, spec) {
  for (const [name, o] of Object.entries(spec)) {
    Object.defineProperty(Class.prototype, name, {
      set(v) { this[`_${name}`] = v;
        if (o.reflect && (typeof v !== 'object' || v === null))
          this.setAttribute(name, String(v));
        this.#scheduleRender(); },
      get() { return this[`_${name}`]; },
    });
    if (o.attr) {
      Class.observedAttributes.push(name);
      const orig = Class.prototype.attributeChangedCallback;
      // attributeChangedCallback 内统一处理类型转换（number/boolean/json）
    }
  }
}

```

**评分点**：
- attribute 通道：类型转换 + JSON parse 容错（非法告警不崩）。
- property 主通道：setter 直存 + schedule render。
- reflect：只反射原始值（对象不回写字符串）。
- 双通道一致性（attribute 变更与 property 写等价）。
