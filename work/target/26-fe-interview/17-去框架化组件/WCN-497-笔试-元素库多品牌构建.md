## WCN-497：笔试：实现多品牌构建（品牌 × 主题产物矩阵）与体积审计。
**题目**：输入品牌列表与主题列表：产物 = 元素代码（共享）+ 品牌主题 CSS。审计：各产物体积、共享率（元素代码不重复打包）。

```javascript
function buildMatrix(brands, themes, elementChunkKB) {
  const themeFiles = brands.flatMap(b => themes.map(t => ({
    file: `${b}-${t}.css`, kb: 4 })));                     // 主题各自一份
  const sharedKB = elementChunkKB;
  const total = sharedKB + themeFiles.reduce((s, f) => s + f.kb, 0);
  const shareRate = +(sharedKB / total).toFixed(2);
  return { files: themeFiles, total, shareRate,
    warn: shareRate < 0.5 ? '元素代码疑似被品牌产物重复打包' : 'ok' };
}
console.log(buildMatrix(['brandA', 'brandB'], ['light', 'dark'], 30).files.length); // 4

```

**评分点**：
- 产物矩阵：元素 chunk 共享一份 + 品牌主题各自一份。
- 共享率计算（共享字节 / 总字节）。
- 重复打包检测（品牌产物含元素代码 → 告警）。
- 输出构建清单。
