## WCN-483：笔试：实现元素持久化的命名空间存储（隔离/版本迁移/上限）。
**答**：`storage(tag, instanceId)`：key = tag:id；schema 版本迁移（v1 → v2 字段映射）；配额上限（超限 LRU 逐出最旧实例）。

```javascript
function nsStorage(tag, instanceId, { limit = 50 } = {}) {
  const key = `${tag}:${instanceId}`;
  const touch = () => meta.set(key, Date.now());
  const meta = new Map();
  return {
    load(schemaV, migrate = {}) {
      const raw = localStorage.getItem(key);
      if (!raw) return null;
      const { v, data } = JSON.parse(raw);
      let d = data;
      for (let x = v; x < schemaV; x++) d = migrate[x]?.(d) ?? d;   // 逐版迁移
      touch();
      return d;
    },
    save(data, v) {
      touch();
      if (meta.size > limit) {  // LRU 逐出最旧
        const oldest = [...meta].sort((a, b) => a[1] - b[1])[0][0];
        localStorage.removeItem(oldest); meta.delete(oldest);
      }
      localStorage.setItem(key, JSON.stringify({ v, data }));
    },
  };
}

```

**评分点**：
- key 组装 + 前缀隔离。
- 迁移函数注册（migrate: {1: fn}）。
- LRU 逐出（lastAccess 时间戳）。
- 敏感字段白名单外不持久化（安全）。
