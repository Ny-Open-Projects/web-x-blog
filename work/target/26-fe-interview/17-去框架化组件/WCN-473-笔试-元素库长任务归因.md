## WCN-473：笔试：实现长任务归因到元素（LongTask attribution）。
**题目**：PerformanceObserver longtask：attribution 中容器匹配自定义元素 → 记录 {tag, duration}；聚合 topN 输出治理清单。

```javascript
const byTag = new Map();
new PerformanceObserver((list) => {
  for (const e of list.getEntries()) {
    for (const a of e.attribution || []) {
      const tag = a.containerName?.match(/^([\w-]+-[\w-]+)/)?.[0];
      if (tag && tag.includes('-')) {
        const s = byTag.get(tag) ?? { n: 0, total: 0 };
        s.n++; s.total += e.duration;
        byTag.set(tag, s);
      }
    }
  }
}).observe({ type: 'longtask', buffered: true });
function report() {
  return [...byTag].map(([t, s]) => ({ tag: t, n: s.n, avg: Math.round(s.total / s.n) }))
    .sort((a, b) => b.n - a.n).slice(0, 5);   // 治理 top5
}

```

**评分点**：
- longtask attribution 容器匹配。
- 任务时长分级（>50ms 计）。
- 按 tag 聚合 topN。
- 采样（避免采集开销）。
