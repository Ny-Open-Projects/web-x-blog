## WCN-522：元素加载故障注入器（延迟/失败/损坏三模式）如何用于混沌演练？

**答**：
- 结论：包装 import 函数，按配置对指定 URL 注入延迟、网络失败或返回损坏内容三种故障。
- 按 URL 匹配 + 比例开关控制影响面，未命中则透传真实加载。
- 损坏模式返回语法错误脚本，验证兜底组件与错误上报是否被触发。
- 追问：如何保证演练结束故障自动关闭？（答：配置带 TTL，过期自动降级为透传）

```javascript
function createFaultyLoader(conf /* {targets:[{url, mode, ratio, ttl}]} */) {
  const started = Date.now();
  return async function load(url) {
    if (Date.now() - started > Math.min(...conf.targets.map(t => t.ttl || Infinity))) return import(url);
    const hit = conf.targets.find(t => url.includes(t.url) && Math.random() < (t.ratio || 1));
    if (!hit) return import(url);
    switch (hit.mode) {
      case 'delay': await new Promise(r => setTimeout(r, hit.ms || 2000)); return import(url);
      case 'fail': throw new Error('net::ERR_INJECTED');
      case 'corrupt': return import('data:text/javascript,' + encodeURIComponent('syntax @@@error'));
      default: return import(url);
    }
  };
}
```
