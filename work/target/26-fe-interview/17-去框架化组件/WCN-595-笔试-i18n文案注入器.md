## WCN-595：笔试：实现「i18n 文案注入器」（locale 切换 → 组件内文本信号更新 + RTL 属性同步）。

**答**：
- 结论：注入器监听 locale 信号，切换时更新组件内所有文案节点（按 key）并同步 dir 属性。
- 文案按 key 映射到多语言字典，缺失 key 回退到默认语言并记录告警。
- RTL 同步：设置宿主 dir 属性，组件内用逻辑属性无需改样式。
- 追问：动态插入的组件如何自动注入？（答：MutationObserver 监听新增元素，注册文案绑定）

```javascript
function createI18n(dict, defaultLocale = 'zh-CN') {
  const locale = signal(defaultLocale);
  const bindings = new Set();                              // { el, key }
  function t(key) {
    const l = locale.get();
    if (dict[l]?.[key] != null) return dict[l][key];
    console.warn('[i18n] 缺失', l, key); return dict[defaultLocale]?.[key] ?? key;
  }
  effect(() => {
    const l = locale.get();
    document.documentElement.dir = ['ar','he'].includes(l.split('-')[0]) ? 'rtl' : 'ltr';
    for (const b of bindings) b.el.textContent = t(b.key);
  });
  function bind(el, key) { bindings.add({ el, key }); el.textContent = t(key); return () => bindings.delete(el); }
  return { locale, t, bind };
}
```

**评分点**：
- locale 信号驱动更新
- 缺失 key 回退告警
- RTL dir 属性同步
- 动态绑定注册
