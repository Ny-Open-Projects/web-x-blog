## WCN-479：笔试：实现元素 chunk 的预取调度（预算 + 优先级 + 去重）。
**题目**：`prefetch(url, priority)`：队列按优先级；并发上限 3；同 URL 去重；预算上限（每页面 ≤ 5 个）后拒绝并计数。

```javascript
function prefetcher({ concurrency = 3, budget = 5 } = {}) {
  const seen = new Set(), queue = []; let active = 0, rejected = 0;
  function pump() {
    while (active < concurrency && queue.length) {
      const { url, priority } = queue.sort((a, b) => a.priority - b.priority).shift();
      active++;
      fetch(url).finally(() => { active--; pump(); });
    }
  }
  return {
    add(url, priority = 2) {
      if (seen.has(url)) return 'dup';
      if (seen.size >= budget) { rejected++; return 'budget-exceeded'; }
      seen.add(url); queue.push({ url, priority }); pump();
      return 'queued';
    },
    stats: () => ({ total: seen.size, rejected }),
  };
}

```

**评分点**：
- 优先级队列 + 并发限制。
- 去重（in-flight/已完成的 Set）。
- 预算计数（拒绝后记录原因）。
- 统计输出（命中/拒绝）。
