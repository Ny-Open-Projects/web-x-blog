## WCN-480：笔试：实现 ds-error 事件的聚合看板数据（tag × version × code）。
**题目**：事件流 `[{tag, version, code, ts}]`。输出：错误率分布（按 tag 汇总）、异常版本（同 tag 某 version 错误率显著高于均值）、Top 错误码。

```javascript
function errorBoard(events, { totalMounts }) {
  const by = new Map();
  for (const e of events) {
    const k = `${e.tag}@${e.version}`;
    const s = by.get(k) ?? { n: 0, codes: {} };
    s.n++; s.codes[e.code] = (s.codes[e.code] || 0) + 1;
    by.set(k, s);
  }
  const rows = [...by].map(([k, s]) => ({ k, n: s.n,
    rate: +(s.n / totalMounts[k.split('@')[0]] ?? 0).toFixed(4), codes: s.codes }));
  const avg = rows.reduce((s, r) => s + r.rate, 0) / (rows.length || 1);
  return { rows: rows.sort((a, b) => b.n - a.n),
    abnormal: rows.filter(r => r.rate > avg * 3).map(r => r.k) };
}

```

**评分点**：
- 三维聚合（tag/version/code）。
- 异常版本检测（错误率 > 均值 × 3）。
- 排序输出（错误数降序）。
- 采样说明（上报采样率换算真实率）。
