## WCN-550：笔试：实现「异步派生信号」的版本戳 + AbortController 综合竞态防护。

**答**：
- 结论：结合版本戳（丢弃过期结果）与 AbortController（取消在途请求），并保留旧值避免 loading 闪烁。
- 每次源变化递增版本、abort 上一次；只在版本匹配且未 abort 时落库。
- 提供 retry 与 dispose，dispose 时取消所有在途请求。
- 追问：如何处理「请求永不返回」？（答：加超时 AbortSignal.timeout，超时按错误态处理）

```javascript
function guardedAsync(source, fetcher, { timeout = 8000 } = {}) {
  const out = signal({ status: 'idle', value: null, error: null });
  let epoch = 0, ctrl = null;
  function run(params) {
    const my = ++epoch; ctrl?.abort(); ctrl = new AbortController();
    const timer = setTimeout(() => ctrl.abort(), timeout);
    out.set(s => ({ ...s, status: 'loading' }));             // 保留旧 value
    fetcher(params, ctrl.signal).then(v => {
      if (my === epoch) out.set({ status: 'success', value: v, error: null });
    }).catch(e => {
      if (my === epoch) out.set({ status: 'error', value: out.get().value, error: e });
    }).finally(() => clearTimeout(timer));
  }
  source.subscribe(run);
  return { out, retry: () => run(source.get()), dispose: () => ctrl?.abort() };
}
```

**评分点**：
- 版本戳丢弃过期结果
- AbortController 取消在途
- 保留旧值避免闪烁
- 超时与 dispose 兜底
