## WCN-560：笔试：实现编译产物「指令选择器」（根据表达式是否含动态依赖选择 straight-DOM 还是 signal-bind）。

**答**：
- 结论：分析表达式的引用集合与复杂度，按规则选择 straight-DOM 直写或 signal-bind 订阅更新两种产物。
- 规则：单信号 + 简单成员访问 → straight-DOM；多引用 / 派生运算 / 跨节点共享 → signal-bind。
- 输出统一产物结构 { mode, code }，供后续代码生成使用。
- 追问：如何验证选择器没选错？（答：生成产物做行为快照对比，两种模式输出应一致）

```javascript
function collectRefs(expr) { return expr.match(/\b[a-zA-Z_$][\w$]*\b/g) || []; }
function selectInstruction(expr, shared) {
  const refs = [...new Set(collectRefs(expr))];
  const isSimple = /^\w+$/.test(expr.trim()) || /^\w+\.\w+$/.test(expr.trim());
  if (refs.length === 1 && isSimple && !shared.has(refs[0]))
    return { mode: 'straight-dom', code: `node.textContent = String(${expr})` };
  return { mode: 'signal-bind', code: `bind(node, () => ${expr})` };
}
const shared = new Set(['user']);
selectInstruction('count', shared);          // straight-dom
selectInstruction('user.name + "!"', shared); // signal-bind
```

**评分点**：
- 引用集合与复杂度分析
- straight-dom 与 signal-bind 规则
- 统一产物结构
- 快照对比验证选择
