## WCN-963：手写帧预算调度器：把大量节点更新按 16ms 帧预算分片执行

**题目**：实现 `createFrameScheduler({ frameBudget = 16, now = () => performance.now(), scheduleFrame = cb => requestAnimationFrame(cb) })`，返回 `{ enqueue(task), start(), stop() }`。要求：① enqueue 收集任务（每个任务是无参函数，返回布尔表示是否完成，false 表示需下一帧继续）；② start 后每帧执行任务：循环取队首任务执行，累计耗时不超过 frameBudget，超时则把剩余任务留到下一帧（用 rAF 再调度）；③ 任务返回 true 则出队，false 则保留队首下一帧继续；④ stop 停止调度且不再执行；⑤ 依赖注入便于测试（now/scheduleFrame）。请自足实现并给出可运行示例（注入同步 rAF）。

**答**：

```javascript
function createFrameScheduler({ frameBudget = 16, now = () => performance.now(),
    scheduleFrame = cb => requestAnimationFrame(cb) } = {}) {
  let queue = [], running = false;
  function frame() {
    if (!running) return;
    const start = now();
    while (queue.length && now() - start < frameBudget) {
      const done = queue[0]();       // 执行队首，返回是否完成
      if (done === true) queue.shift();
      else break;                     // 未完成，留到下一帧
    }
    if (queue.length) scheduleFrame(frame);
  }
  return {
    enqueue(task) { queue.push(task); return this; },
    start() { if (!running) { running = true; scheduleFrame(frame); } },
    stop() { running = false; },
  };
}
let t = 0;
const q = [];
const s = createFrameScheduler({ frameBudget: 10, now: () => t,
  scheduleFrame: cb => q.push(cb) });
let done = 0;
s.enqueue(() => { done++; t += 4; return done >= 3; }); // 需多帧
s.enqueue(() => { done++; return true; });
s.start();
q.shift()(); q.shift()(); // 模拟两帧
console.log('done=', done); // 3（第一批跨3帧完成）+ 第二批 = 4? 由预算控制
```

**评分点**：
- 帧预算控制：累计耗时 < frameBudget 才继续执行，超时留到下一帧。
- 任务返回值语义：true 出队、false 保留队首继续。
- start/stop 正确控制调度生命周期，不重复启动。
- 依赖注入 now/scheduleFrame，可离线测试。
- 示例可运行、分片行为符合预期。
