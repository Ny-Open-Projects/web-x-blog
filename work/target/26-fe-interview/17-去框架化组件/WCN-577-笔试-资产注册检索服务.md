## WCN-577：「设计资产中台」的资产注册与检索服务（tag × token × 版本多维索引）如何建？

**答**：
- 结论：服务维护三张倒排索引（tag/token/版本），注册时更新索引，检索时交集过滤并按相关度排序。
- 标签索引：tag → Set(assetId)；token 索引：token → Set(assetId)；版本索引：version → Set。
- 检索多条件取交集，按「命中条件数 + 质量分」排序。
- 追问：资产下线如何清理索引？（答：注册时记录 asset→索引键映射，下线时反向删除）

```javascript
class AssetRegistry {
  constructor() { this.assets = new Map(); this.idx = { tag: new Map(), token: new Map(), version: new Map() }; }
  reg(a) {
    this.assets.set(a.id, a);
    for (const [dim, vals] of [['tag',[a.tag]], ['token',a.tokens], ['version',[a.version]]])
      for (const v of vals) { if (!this.idx[dim].has(v)) this.idx[dim].set(v, new Set()); this.idx[dim].get(v).add(a.id); }
  }
  search({ tag, tokens = [], version }) {
    const sets = [];
    if (tag) sets.push(this.idx.tag.get(tag) || new Set());
    for (const t of tokens) sets.push(this.idx.token.get(t) || new Set());
    if (version) sets.push(this.idx.version.get(version) || new Set());
    if (!sets.length) return [...this.assets.values()];
    let ids = sets.reduce((a, b) => new Set([...a].filter(x => b.has(x))));
    return [...ids].map(id => this.assets.get(id)).sort((a,b) => b.score - a.score);
  }
}
```
