## WCN-588：设计 token 的「使用治理」：如何防止业务方硬编码裸值绕过 token 体系？

**答**：
- 结论：靠「检测 + 门禁 + 引导」三管齐下——lint 扫裸值、CI 阻断新增、codemod 提供一键替换。
- 检测扫描颜色/间距/圆角/字号的 CSS 字面量，白名单豁免（如 0、1px、currentColor）。
- CI 只对新代码阻断（baseline 机制），存量逐步清理不一次性卡死。
- 追问：业务说「设计就是要特殊值」怎么办？（答：走显式 override 变量并登记，纳入设计评审）

```javascript
const TOKEN_PATTERN = {
  color: /#(?:[0-9a-f]{3,8})|rgba?\(/i,
  spacing: /\b\d+(?:\.\d+)?px\b/,
};
function scanRawValues(css, baseline = new Set()) {
  const hits = [];
  css.split('\n').forEach((line, i) => {
    for (const [kind, re] of Object.entries(TOKEN_PATTERN)) {
      const m = line.match(re);
      if (m && m[0] !== '0' && m[0] !== '1px' && !baseline.has(m[0]))
        hits.push({ line: i + 1, kind, value: m[0] });
    }
  });
  return hits;
}
```
