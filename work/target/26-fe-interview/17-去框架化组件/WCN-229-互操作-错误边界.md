## WCN-229：自定义元素内部抛错，框架错误边界能捕获吗？
**答**：
- React Error Boundary 捕获不到 shadow 内部异步错误（不在 React 渲染路径上）。
- 元素必须自行兜底：生命周期/渲染函数 try-catch → 错误事件（error 事件派发）→ 宿主决定降级。
- 规范：元素库统一 error 事件协议（detail: {code, message, recoverable}）。
- 宿主适配包把元素错误事件映射到框架错误处理（React Boundary 可捕获同步渲染期错误）。

```javascript
class GoodsCard extends HTMLElement {
  #safe(fn) { try { fn(); } catch (e) {
    this.dispatchEvent(new CustomEvent('ds-error', {
      detail: { code: 'render', message: String(e), recoverable: true }, bubbles: true, composed: true }));
  } }
}
```
