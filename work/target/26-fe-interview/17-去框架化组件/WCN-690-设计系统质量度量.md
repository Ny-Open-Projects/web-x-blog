## WCN-690：设计系统的质量如何量化度量？有哪些关键指标？

**答**：
- 结论：从四维度度量——一致性（token 覆盖率/裸值率）、健康度（A11Y 通过率/视觉回归通过率）、效率（接入耗时/采用率）、稳定性（故障数/升级耗时）。
- 做法：CI 采集裸值率与 A11Y 分数；文档站埋点采集采用率；定期开发者满意度调研；用看板持续追踪趋势。
- 追问钩子：指标会被「刷」怎么办？比如裸值率可通过拆分规避——需结合 code review 与抽样审计——考察对「指标治理」的清醒认知。

```javascript
const METRICS = {
  consistency: { tokenCoverage: 0.92, rawValueRate: 0.08 },
  health: { a11yPassRate: 0.98, visualPassRate: 0.95 },
  efficiency: { adoptionRate: 0.75, onboardingHours: 2 },
  stability: { incidents: 1, upgradeDays: 3 },
};
function healthScore(m) {
  const w = { tokenCoverage: 0.2, a11yPassRate: 0.3,
              visualPassRate: 0.2, adoptionRate: 0.2,
              stability: -0.1 };
  return (
    m.consistency.tokenCoverage * w.tokenCoverage +
    m.health.a11yPassRate * w.a11yPassRate +
    m.health.visualPassRate * w.visualPassRate +
    m.efficiency.adoptionRate * w.adoptionRate -
    m.stability.incidents * w.stability
  ).toFixed(3);
}
console.log('设计系统健康分:', healthScore(METRICS));
```
