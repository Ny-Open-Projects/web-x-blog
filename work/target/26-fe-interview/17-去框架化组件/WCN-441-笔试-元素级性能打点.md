## WCN-441：笔试：实现元素 mount/interactive 的性能打点与上报。
**答**：connectedCallback 记 t0；首次事件响应（委托监听）标记 interactive；report 上报 {tag, mountMs, interactiveMs}（带采样）。

```javascript
class Heavy extends HTMLElement {
  connectedCallback() {
    this._t0 = performance.now();
    performance.mark(`ds:${this.tagName}:start`);
    this.addEventListener('pointerdown', () => {
      if (!this._reported) {
        this._reported = true;
        performance.mark(`ds:${this.tagName}:interactive`);
        performance.measure(`ds:${this.tagName}`, `ds:${this.tagName}:start`, `ds:${this.tagName}:interactive`);
        Math.random() < 0.1 && report({ tag: this.tagName.toLowerCase(),
          ms: performance.getEntriesByName(`ds:${this.tagName}`).pop().duration });
      }
    }, { once: true });
  }
}

```

**评分点**：
- mount：连接到首渲染完成。
- interactive：首事件响应时刻。
- performance.mark/measure 标准化（可进 DevTools）。
- 采样上报（10%）+ 错误全量。
