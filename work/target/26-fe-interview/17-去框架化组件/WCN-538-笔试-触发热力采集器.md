## WCN-538：笔试：实现信号图的「触发热力采集器」（每信号触发次数/耗时 + 导出可视化数据）。

**答**：
- 结论：包装 signal 的 get/set 与 computed 的重算，采集触发次数与耗时，按窗口导出热力数据。
- 耗时用 performance.now() 包裹，热路径采样（按比例）避免探针本身成为瓶颈。
- 导出结构：nodes（id/name/type）+ edges（from/to）+ heat（hits/cost），可直接喂给力导向图。
- 追问：如何在生产环境零成本？（答：编译期 __DEV__ 分支 + 空实现替换）

```javascript
function profilable(s, name, registry) {
  const meta = { name, hits: 0, cost: 0, subs: new Set() };
  registry.set(s, meta);
  const origSet = s.set;
  s.set = v => { const t = performance.now(); origSet(v); meta.cost += performance.now() - t; meta.hits++; };
  return s;
}
function exportHeat(registry) {
  return {
    nodes: [...registry].map(([s, m]) => ({ id: m.name, type: s.isComputed ? 'computed' : 'signal' })),
    heat: [...registry].map(([, m]) => ({ id: m.name, hits: m.hits, cost: +m.cost.toFixed(2) })),
  };
}
```

**评分点**：
- 包装 get/set 采集次数与耗时
- 采样降低探针开销
- nodes/edges/heat 可 viz 结构
- __DEV__ 分支生产零成本
