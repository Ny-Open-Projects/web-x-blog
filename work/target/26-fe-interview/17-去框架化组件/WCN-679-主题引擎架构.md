## WCN-679：支持多主题与深色模式的主题引擎，架构上如何设计？

**答**：
- 结论：主题 = token 集合 + 切换策略；引擎按 scope（全局/局部）注入 CSS 变量，深色模式用 prefers-color-scheme + 手动覆盖双通道。
- 做法：token 分层生成变量；主题切换只改根元素 data-theme 属性（变量级联自动生效）；局部主题用元素级 CSS 变量覆盖。
- 追问钩子：如何处理「用户手动选择」与「跟随系统」的冲突？用优先级：手动 > 系统，且持久化用户选择——考察对状态优先级的设计能力。

```javascript
const THEMES = {
  light: { '--ds-bg': '#fff', '--ds-text': '#1d2129' },
  dark:  { '--ds-bg': '#17171a', '--ds-text': '#f2f3f5' },
};
function applyTheme(name, scope = document.documentElement) {
  const vars = THEMES[name];
  if (!vars) throw new Error(`未知主题 ${name}`);
  Object.entries(vars).forEach(([k, v]) => scope.style.setProperty(k, v));
  scope.dataset.theme = name;
}
function preferredTheme() {
  const saved = localStorage.getItem('ds-theme');
  return saved || (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
}
applyTheme(preferredTheme());
```
