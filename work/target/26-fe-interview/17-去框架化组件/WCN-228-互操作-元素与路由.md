## WCN-228：自定义元素感知路由变化（框架路由）的注入方式？
**答**：
- 路由状态作为 property 传入（params/query 片段），元素不感知路由库。
- 需要主动导航时元素派发「请求导航」事件（nav-request），宿主监听并调用路由 API——元素永不直接操作 location。
- 面包屑/锚点类元素由宿主传当前路由快照。
- 理由：路由库五花八门，元素层只认「路由状态协议」。

```javascript
// 元素派发导航意图
this.dispatchEvent(new CustomEvent('nav-request', {
  detail: { to: `/goods/${sku}` }, bubbles: true, composed: true }));
// React 适配：onNavRequest={(e) => navigate(e.detail.to)}

```
