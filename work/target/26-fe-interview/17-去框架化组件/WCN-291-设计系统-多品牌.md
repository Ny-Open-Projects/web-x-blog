## WCN-291：多品牌（白标）场景下的元素库策略？
**答**：
- 元素实现零品牌差异——差异全部在 token 层（品牌主题包：tokens-brandX.css）。
- 品牌包按需加载（宿主引对应主题文件），元素无感。
- 品牌特有结构差异：slot/变体属性（variant="brandA"）而非分支代码。
- 验证：同一元素矩阵跑全品牌视觉快照（品牌间 diff 应只在 token 值）。

```javascript
<!-- 品牌 A -->
<link rel="stylesheet" href="/tokens-brandA.css">
<ds-button>Buy</ds-button>
<!-- 品牌 B 只换 token 文件，元素标签不变 -->
r
```
