## WCN-536：笔试：实现「乐观信号 + 回滚栈」的 CRDT 适配层（本地先更新，ack 后确认，冲突回滚）。

**答**：
- 结论：维护「确认值 + 乐观补丁栈」，本地写压栈即时生效；ack 把补丁并入确认值，冲突则弹栈回滚。
- 每个操作带唯一 id 与前置版本，冲突检测用版本戳比较。
- 回滚按栈逆序恢复，保证中间态不残留。
- 追问：远端先到、本地 ack 后到如何处理？（答：以服务端版本戳为准，本地补丁若已包含在远端则直接丢弃）

```javascript
function optimisticLayer(initial) {
  let confirmed = initial;
  const patches = [];                            // { id, base, apply }
  const view = signal(initial);
  function recompute() { view.set(patches.reduce((v, p) => p.apply(v), confirmed)); }
  function local(id, apply) { patches.push({ id, base: confirmedVersion, apply }); recompute(); }
  function ack(id) {
    const i = patches.findIndex(p => p.id === id);
    if (i < 0) return;
    confirmed = patches[i].apply(confirmed); patches.splice(i, 1); recompute();
  }
  function remote(serverValue, includedIds) {
    confirmed = serverValue;
    for (const id of includedIds) { const i = patches.findIndex(p => p.id === id); if (i >= 0) patches.splice(i, 1); }
    recompute();
  }
  return { view, local, ack, remote };
}
```

**评分点**：
- 确认值 + 乐观补丁栈分离
- 版本戳冲突检测
- ack 合并与冲突回滚
- 远端先到幂等处理
