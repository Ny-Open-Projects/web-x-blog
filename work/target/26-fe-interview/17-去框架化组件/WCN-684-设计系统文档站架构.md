## WCN-684：交互式组件文档站（DocSite）如何设计？如何保证示例与代码同步？

**答**：
- 结论：文档站 = 组件元信息（props/events/slot）+ 可交互示例（Playground）+ API 表格，三者由同一份 source 生成，避免手写不同步。
- 做法：从组件 JSDoc/类型定义自动生成 API 表；示例用真实代码嵌入（live code）；文档随组件一起发布并在 CI 校验链接与示例可运行。
- 追问钩子：为什么不用独立维护文档？因为「代码改了文档没改」是文档腐烂的根源——考察对「单一数据源」的坚持。

```javascript
// 从组件元数据生成 API 表（单一数据源）
const ButtonMeta = {
  name: 'ds-button',
  props: { variant: 'enum: primary|secondary', disabled: 'boolean=false' },
};
function genApiTable(meta) {
  const rows = Object.entries(meta.props).map(([k, v]) => `| ${k} | ${v} |`);
  return `| 属性 | 说明 |\n|---|---|\n${rows.join('\n')}`;
}
// 示例即代码：Playground 直接渲染并支持编辑
const example = `<ds-button variant="primary">提交</ds-button>`;
console.log(genApiTable(ButtonMeta));
// 文档与组件同源 → 发布时自动更新，杜绝腐烂
```
