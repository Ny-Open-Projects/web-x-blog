## WCN-487：笔试：实现元素库发版前的自动化检查清单（五项）。
**答**：检查：① API diff（breaking 标记）② 全矩阵测试通过 ③ 文档 demo 全绿 ④ 体积预算 ⑤ changelog 存在。输出 `{ready, blockers}`（changelog 缺失对 major 是 blocker）。

```javascript
function releaseCheck({ apiDiff, matrix, docs, budget, changelog }, version) {
  const isMajor = version.startsWith('0.') ? false : version.split('.')[0] !== lastMajor(version);
  const blockers = [];
  if (apiDiff.breaking.length && !isMajor) blockers.push('breaking 变更但非 major');
  if (isMajor && !changelog) blockers.push('major 缺迁移指南 changelog');
  if (!matrix.allGreen) blockers.push('矩阵未全绿: ' + matrix.failed);
  if (!docs.allGreen) blockers.push('文档 demo 未全绿');
  if (budget.violations.length) blockers.push(`体积超预算: ${budget.violations.length}`);
  return { ready: blockers.length === 0, blockers };
}

```

**评分点**：
- 五项检查各自可执行（输入 mock）。
- major 特殊规则（changelog 必需）。
- blockers 汇总（不短路）。
- 退出码对接发布流水线。
