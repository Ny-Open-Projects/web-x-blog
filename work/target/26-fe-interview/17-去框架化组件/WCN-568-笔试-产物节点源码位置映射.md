## WCN-568：笔试：实现「产物节点 → 源码位置」的映射表生成器（含插入锚点的位置还原）。

**答**：
- 结论：遍历编译产物节点，收集每个节点及其锚点的源码位置，生成 id → 位置的映射表。
- 锚点（注释节点/空文本）继承其父模板节点的位置，保证文本区域也可定位。
- 提供 compress 参数，支持对压缩后偏移做二次映射（简化版：加 offset 修正）。
- 追问：如何导出为标准 sourcemap？（答：按 sources/mappings VLQ 编码生成 .map 文件）

```javascript
function generateMap(ast, { offset = 0 } = {}) {
  const map = {};
  (function visit(n) {
    if (n.generatedId) map[n.generatedId] = {
      file: n.src?.file || 'template.html',
      line: (n.src?.line || 1) + offset,
      col: n.src?.col || 0,
    };
    for (const c of n.children || []) {
      if (c.isAnchor && !c.src) c.src = n.src;          // 锚点继承父位置
      visit(c);
    }
  })(ast);
  return map;
}
function locate(id, map) { const p = map[id]; return p && `${p.file}:${p.line}:${p.col}`; }
```

**评分点**：
- id→源码位置映射表
- 锚点继承父节点位置
- 压缩偏移修正
- 可扩展标准 sourcemap
