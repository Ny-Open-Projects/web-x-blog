## WCN-564：笔试：实现「渲染间不变性分析器」（基于写操作集合推断值是否稳定）。

**答**：
- 结论：遍历渲染函数 AST 收集所有写操作目标，对每个候选值检查其依赖引用是否落在写集合中。
- 来源分类：字面量/props/state/memo 调用，未知函数调用视为不稳定（保守）。
- 输出：每个候选值的 stable 布尔与原因，供编译器决定是否插入缓存。
- 追问：如何处理闭包内的写？（答：递归收集嵌套函数体的写操作，纳入同一集合）

```javascript
function analyze(ast) {
  const writes = new Set();
  function collect(n) {
    if (n.type === 'AssignmentExpression' || n.type === 'UpdateExpression') writes.add(unwrap(n.argument || n.left));
    if (n.type === 'CallExpression' && /ref\.current|\.push/.test(n.calleeText || '')) writes.add('escape');
    (n.body ? [].concat(n.body) : []).forEach(collect);
    Object.values(n).forEach(v => v && typeof v === 'object' && v.type && collect(v));
  }
  collect(ast);
  function stable(value) {
    const refs = collectRefs(value);
    if (value.origin === 'unknown-call' || writes.has('escape')) return { stable: false, why: 'escape/unknown' };
    const hit = refs.find(r => writes.has(r));
    return hit ? { stable: false, why: '写入 ' + hit } : { stable: true, why: '无写入' };
  }
  return { writes, stable };
}
```

**评分点**：
- 写操作集合收集（含嵌套函数）
- escape hatch 保守降级
- 来源分类判定
- stable 结论可解释
