## WCN-490：笔试：实现元素库 CI 容量规划（矩阵 job 数与时长预测）。
**题目**：输入：元素数 N × 浏览器数 B × 分片数 S，单 job 时长历史均值。输出：总 job 数、墙钟预估（并行 runner 数限制）、成本估算。

```javascript
function capacity({ elements, browsers, shards, avgMin, runners, pricePerMin }) {
  const jobs = elements * browsers * shards;
  const totalMin = jobs * avgMin;
  const wall = Math.ceil(totalMin / runners);
  return { jobs, wallMin: wall,
    cost: +(totalMin * pricePerMin).toFixed(0),
    suggest: wall > 60 ? `墙钟 ${wall}min 超预算，加 runner 至 ${Math.ceil(totalMin / 60)}` : 'ok' };
}
console.log(capacity({ elements: 50, browsers: 3, shards: 4, avgMin: 2, runners: 20, pricePerMin: 0.02 }));
// jobs 600，wall 60min

```

**评分点**：
- job 数 = N×B×S（组合）。
- 墙钟 = 总时长 / runner 数（排队）。
- 成本 = CI 分钟 × 单价。
- 扩容决策（预算内时长 vs 加 runner）。
