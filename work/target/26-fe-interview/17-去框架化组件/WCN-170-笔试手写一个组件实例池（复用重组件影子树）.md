## WCN-170：笔试：手写一个组件实例池

**题目**：实现 `ElementPool(tag, { max })`：① `acquire()` 从池取空闲实例（无则新建并 `customElements.whenDefined` 等待 define）；② `release(el)` 归还：重置 attribute、清空影子树动态内容（保留骨架）、断开到 DOM 外容器；③ 池满（>max）直接销毁；④ `stats()` 返回 { created, reused, destroyed, idle }；⑤ 归还时执行组件上的 `poolReset?.()` 钩子；⑥ 防止同一实例被双重 acquire。

**答**：

```javascript
const detachedRoot = document.createElement('div'); // 池容器：脱离主 DOM 树
detachedRoot.style.display = 'none';

export class ElementPool {
  #idle = []; #busy = new Set();
  #created = 0; #reused = 0; #destroyed = 0;
  constructor(tag, { max = 20 } = {}) {
    this.tag = tag; this.max = max;
    this.ready = customElements.whenDefined(tag);
  }
  async acquire() {
    await this.ready;
    let el = this.#idle.pop();
    if (el) { this.#reused++; }
    else { el = document.createElement(this.tag); this.#created++; }
    if (this.#busy.has(el)) throw new Error('pool double-acquire');
    this.#busy.add(el);
    return el;
  }
  release(el) {
    if (!this.#busy.delete(el)) return;      // 未借出/重复归还忽略
    el.poolReset?.();                        // 组件自定义重置钩子
    while (el.attributes.length) el.removeAttribute(el.attributes[0].name);
    if (this.#idle.length >= this.max) {     // 池满销毁
      el.remove(); this.#destroyed++;
      return;
    }
    detachedRoot.append(el);                 // 移出主树保活影子树
    this.#idle.push(el);
  }
  stats() {
    return { created: this.#created, reused: this.#reused,
             destroyed: this.#destroyed, idle: this.#idle.length };
  }
}
// 组件侧实现 poolReset：清除动态行/定时器/内部 signal 引用，保留静态骨架
```

**评分点**：
- 池容器脱离主 DOM（保活影子树不参与布局）；release 清 attribute + 调 poolReset 钩子。
- 双重 acquire/归还防护（#busy Set）。
- 池满销毁与 stats 统计（复用率可观测）。
- whenDefined 等待 define（懒加载组件可直接入池）。
