## WCN-599：笔试：实现「元素准入评分离线器」（API 规范 / a11y / 测试覆盖 / 文档四维加权评分）。

**答**：
- 结论：按四维加权计算准入分，低于门槛拒绝；输出每维得分与整改建议。
- 维度：API 规范（命名/事件/slot）、a11y（基线项）、测试覆盖（行/分支）、文档（说明/demo/类型）。
- 权重可配置，输出逐项扣分点便于贡献者改进。
- 追问：如何处理「某项优秀但另一项极低」？（答：设单项最低线，任一维低于线直接不通过，防偏科）

```javascript
const WEIGHTS = { api: 0.25, a11y: 0.3, coverage: 0.25, docs: 0.2 };
const MIN = { api: 60, a11y: 80, coverage: 60, docs: 50 };
function scoreSubmission(s, weights = WEIGHTS) {
  const dims = {
    api: s.apiNaming * 0.5 + s.eventSpec * 0.5,
    a11y: s.a11yChecks,
    coverage: s.lineCov * 0.6 + s.branchCov * 0.4,
    docs: (s.hasDocs ? 50 : 0) + (s.hasDemo ? 30 : 0) + (s.hasTypes ? 20 : 0),
  };
  const total = Math.round(Object.keys(weights).reduce((sum, k) => sum + dims[k] * weights[k], 0));
  const failed = Object.keys(MIN).filter(k => dims[k] < MIN[k]);
  return { total, passed: total >= 75 && failed.length === 0, dims: Object.fromEntries(
    Object.entries(dims).map(([k,v]) => [k, Math.round(v)])), failed,
    advice: failed.map(k => `维度 ${k} 低于最低线 ${MIN[k]}`) };
}
```

**评分点**：
- 四维加权评分
- 单项最低线防偏科
- 逐项扣分可解释
- 阈值判定准入
