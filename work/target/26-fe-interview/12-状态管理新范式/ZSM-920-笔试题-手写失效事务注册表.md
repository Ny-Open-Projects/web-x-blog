## 920：笔试手写：实现事件驱动的缓存失效注册表

**答**：实现 createInvalidator()：on(event, fn) 注册（返回退订）、emit(event, payload) 异步触发全部 fn（任一抛错不影响其他，错误收集返回）；支持 once(event, fn)（触发一次后自动退订）。

```js
function createInvalidator() {
  const reg = new Map();                        // event -> Set<fn>
  return {
    on(event, fn) {
      if (!reg.has(event)) reg.set(event, new Set());
      reg.get(event).add(fn);
      return () => reg.get(event)?.delete(fn);  // 退订防泄漏
    },
    once(event, fn) {
      const off = this.on(event, payload => { off(); fn(payload); });
      return off;
    },
    async emit(event, payload) {
      const errors = [];
      const fns = [...(reg.get(event) || [])];  // 快照：防执行中退订迭代异常
      const rs = await Promise.allSettled(fns.map(f => f(payload)));
      rs.forEach((r, i) => { if (r.status === 'rejected') errors.push({
        fn: fns[i], reason: r.reason }); });
      return errors;
    },
  };
}
const inv = createInvalidator();
inv.on('order.updated', () => { throw new Error('boom'); });
inv.once('order.updated', p => console.log('hit', p.id));
inv.emit('order.updated', { id: 1 }).then(errs => console.log(errs.length)); // 1
```

**评分点**：
- 快照迭代（执行中退订不崩）——[...set] 是关键细节
- allSettled 隔离错误并收集
- once 的自退订实现（off 引用顺序正确）
- on 返回退订函数；能讨论真实失效中心化的事件总线设计
