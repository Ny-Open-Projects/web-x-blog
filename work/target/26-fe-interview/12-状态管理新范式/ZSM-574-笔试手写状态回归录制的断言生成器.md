## ZSM-574：手写状态回归录制的断言生成器
**答**：实现 `createAssertionGen()`：从操作录制自动生成回归测试代码：1) `record(action, stateBefore, stateAfter)`：记录一次变更的前后状态对；2) `generate()`：输出测试代码字符串——每个 action 生成「构造 before 状态 → 执行 → expect(after)」的用例；3) 去噪：合并同一 action 的连续调用（只测最后一次）；4) 快照裁剪：状态对象只保留与变更相关的字段（diff 到的前后状态），减少测试脆弱性；5) 附用例：录制 3 次操作输出可读测试代码。

```javascript
function createAssertionGen() {
  const recorded = []

  function record(action, before, after) {
    // 裁剪：只保留有差异的字段
    const diffKeys = new Set(Object.keys(before).filter((k) => !Object.is(before[k], after[k])))
    recorded.push({
      action,
      before: Object.fromEntries([...diffKeys].map((k) => [k, before[k]])),
      after: Object.fromEntries([...diffKeys].map((k) => [k, after[k]])),
    })
  }

  function generate() {
    // 去噪：同 action 连续调用只保留最后一次
    const merged = []
    for (const r of recorded) {
      if (merged.at(-1)?.action === r.action) merged[merged.length - 1] = r
      else merged.push(r)
    }
    const lines = []
    lines.push("import { describe, it, expect, beforeEach } from 'vitest'")
    lines.push("import { useCartApi } from './store'")
    lines.push('')
    lines.push("describe('回归：录制于真实操作', () => {")
    lines.push("  beforeEach(() => { useCartApi.setState(useCartApi.getInitialState()) })")
    merged.forEach((r, i) => {
      lines.push(`  it('用例 ${i + 1}: ${r.action} 后状态符合录制', () => {`)
      lines.push(`    useCartApi.setState(${JSON.stringify(r.before)})   // before`)
      lines.push(`    useCartApi.getState().${r.action}()`)
      lines.push(`    const s = useCartApi.getState()`)
      for (const [k, v] of Object.entries(r.after)) {
        lines.push(`    expect(s.${k}).toEqual(${JSON.stringify(v)})`)
      }
      lines.push('  })')
    })
    lines.push('})')
    return lines.join('\n')
  }

  return { record, generate }
}

// 用例
const gen = createAssertionGen()
const s0 = { items: [], total: 0 }
const s1 = { items: ['g1'], total: 100 }
const s2 = { items: ['g1', 'g2'], total: 300 }
const s3 = { items: ['g1', 'g2'], total: 300, mode: 'global' }
gen.record('addItem', s0, s1)
gen.record('addItem', s1, s2)         // 连续 addItem：去噪后只保留最后一次
gen.record('setMode', s2, s3)
console.log(gen.generate())

```
**评分点**：
- 状态裁剪只保留 diff 字段（测试不因无关字段变动而脆弱）
- 同 action 连续调用去噪（用例数量可控）
- 生成代码包含 beforeEach 重置（幂等可重复跑）
- 输出可读的 expect 逐字段断言（失败时直接定位字段）
