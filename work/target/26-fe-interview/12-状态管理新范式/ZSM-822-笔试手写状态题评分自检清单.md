## ZSM-822：手写答题自评分卡（面试官视角的五维评分）
**答**：模拟面试官评分——实现 `scoreAnswer(recorded, type)`：对自己答题录音/转写做五维评分：1) 结构分（是否按题型骨架走，段锚点命中数/应有数）；2) 深度分（L1/L2/L3 触达：变量名证据/边界反例出现即计分）；3) 数字分（实测数字个数 + 口径声明）；4) 交互分（画图/留钩子/承认边界）；5) 冗余扣分（营销话术/重复/超时）。输出总分与改进建议。附用例：对一段转写文本评分。

```javascript
const MARKERS = {
  structure: { 原理: ['先说结论', '内部实现', '边界/反例'], 设计: ['澄清', '分层', '冲突', '闭环'], 排查: ['复现', '归因', '根因', '验证'] },
  depth: { l2Evidence: /useSyncExternalStore|inst\.|hasValue|版本号|seq|hold-back|幂等键/g, l3Counter: /失效|边界|反例|不会|限制|坑/g },
  rhetoric: ['轻量', '很简单', '一目了然', '很方便', '完美'],   // 营销话术扣分
}

function scoreAnswer(transcript, type = '原理') {
  const text = transcript
  const scores = {}

  // 1) 结构分：段锚点命中
  const anchors = MARKERS.structure[type] ?? MARKERS.structure.原理
  const hitAnchors = anchors.filter((a) => text.includes(a))
  scores.structure = +(hitAnchors.length / anchors.length * 10).toFixed(1)

  // 2) 深度分：L2 证据 + L3 反例
  const l2 = (text.match(MARKERS.depth.l2Evidence) ?? []).length
  const l3 = (text.match(MARKERS.depth.l3Counter) ?? []).length
  scores.depth = +Math.min(10, l2 * 1.5 + l3 * 2).toFixed(1)

  // 3) 数字分：实测数字 + 口径
  const numbers = (text.match(/\d+(\.\d+)?(ms|次|条|%|s|KB)/g) ?? []).length
  const hasScope = /口径|实测|基准/.test(text)
  scores.numbers = +Math.min(10, numbers * 1.2 + (hasScope ? 3 : 0)).toFixed(1)

  // 4) 交互分
  const interaction = ['画图|画个图|白板', '留钩|感兴趣可以展开', '边界我没追|没有继续追|不确定']
  const interHits = interaction.filter((p) => new RegExp(p).test(text)).length
  scores.interaction = +(interHits / 3 * 10).toFixed(1)

  // 5) 冗余扣分：营销话术 + 超长
  const rhetoric = MARKERS.rhetoric.filter((r) => text.includes(r)).length
  const overLen = text.length > 1400 ? Math.floor((text.length - 1400) / 200) : 0   // 90s ≈ 350字×4
  scores.penalized = rhetoric + overLen
  const total = +Object.entries(scores).filter(([k]) => k !== 'penalized')
    .reduce((a, [, v]) => a + v, 0).toFixed(1)
  const final = Math.max(0, +(total - scores.penalized * 0.5).toFixed(1))

  const suggestions = []
  if (scores.structure < 7) suggestions.push('补齐段锚点：按骨架四段走')
  if (scores.depth < 6) suggestions.push('加 L2 证据（变量名/机制名）或 L3 反例')
  if (scores.numbers < 5) suggestions.push('加实测数字与口径声明')
  if (rhetoric) suggestions.push(`删除营销话术：${MARKERS.rhetoric.filter((r) => text.includes(r)).join('/')}`)

  return { scores, rhetoricCount: rhetoric, final, suggestions }
}

// 用例
const transcript = `这个性能问题我先按四段走：先定性分段归因，实测渲染层 commit 45ms 主导；建模上订单列表是 Map 归一化加行级订阅；方案上 selector 拆标量加 useShallow，复测 renders 87 到 23，blocking 310 到 46ms；闭环上 BudgetGate 进 CI，INP 生产观察一周。这里有个边界我没继续追：扇出监控的采样率调优。`
const r = scoreAnswer(transcript, '排查')
console.log(r.scores)
console.log(r.final)          // 结构/深度/数字/交互 四维高分
console.log(r.suggestions)    // 空或轻微建议
```
**评分点**：
- 五维评分（结构锚点命中/深度证据正则/数字+口径/交互行为/冗余扣分）
- 营销话术黑名单扣分
- 字数超限扣分（90s ≈ 350 字×4 转写）
- 改进建议分级输出
