## ZSM-383：场景题示范：问卷引擎状态（逻辑跳转/必填校验/草稿）

**答**:
- 数据模型：题目 schema（只读）与答案 map（qId → value）分离；可见性是派生（依赖图求值：题目被跳转逻辑隐藏则其答案标记 invalid 保留但不提交）
- 跳转引擎：条件表达式求值（声明式 DSL/JSON Logic），跳转目标确定性（避免环路检测提示）；答案修改触发受影响题目重算可见性
- 校验分层：实时必填提示（松）与提交全量校验（严）两档；错误定位到首个未完成题并滚动定位
- 草稿与恢复：答案 debounce 落盘带 schema 版本，版本不符提示重新开始（题目变了旧答案可能语义错位）

```javascript
const visible = useMemo(() => evalLogic(schema.logic, answers), [answers])    // 可见性派生
const invalid = Object.keys(answers).filter((q) => !visible.has(q))           // 隐藏题答案不提交
function submit() {
  const missing = schema.required.filter((q) => visible.has(q) && isEmpty(answers[q]))
  if (missing.length) scrollTo(missing[0])
  else api.submit({ ...answers, dropped: invalid })                            // 透明记录被跳过题
}
```
