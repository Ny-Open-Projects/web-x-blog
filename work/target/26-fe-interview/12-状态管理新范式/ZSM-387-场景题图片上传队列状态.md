## ZSM-387：场景题示范：多文件上传队列状态（分片/并发/失败重试）

**答**:
- 队列模型：文件级状态机（queued/uploading/done/failed/paused）+ 分片级进度（已传分片集合）；并发上限（3 个文件 × 各自分片串行），页面卸载暂停保存进度
- 断点续传：分片哈希/文件指纹 + 服务端已收分片查询——重传只补缺口；秒传（指纹命中直接完成）
- 进度派生：总进度 = Σ 文件进度加权（按字节数），UI 只读派生；失败聚合展示「N 个失败」入口而非逐条打断
- 重试策略：分片级指数退避（网络抖动）与文件级手动重试（配额/类型错误）分离——可自动修复的自动修，需决策的交用户

```javascript
const uploadFile = async (file) => {
  const fp = await fingerprint(file)
  const done = new Set(await api.listChunks(fp))         // 断点续传
  for (let i = 0; i < chunks.length; i++) {
    if (done.has(i)) continue
    await withRetry(() => api.putChunk(fp, i, chunks[i]), { retries: 3, backoff: true })
    markProgress(file.id, i)
  }
  await api.complete(fp)                                  // 秒传/合体
}
```
