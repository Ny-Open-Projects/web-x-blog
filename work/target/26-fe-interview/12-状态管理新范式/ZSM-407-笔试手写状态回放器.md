## ZSM-407：手写状态回放器（快照 + 动作流，支持倍速与暂停）
**需求**：实现 `createReplayer(store)`：1) `record()` 开始录制：存初始快照 + 每个 action（带相对时间戳）；2) `stop()` 结束；3) `play({ speed = 1 })` 回放：先恢复初始快照，再按时间轴（speed 倍速）依次 apply action；4) `pause()`/`resume()`；5) 回放期间用户的实时写入被忽略（或标记为回放态）；6) `seek(ratio)` 跳到时间轴比例处（从最近快照重放）。

```javascript
export function createReplayer(store) {
  let rec = null
  let play = null

  return {
    record() {
      rec = { t0: Date.now(), snapshot: structuredClone(store.getState()), actions: [] }
      store.subscribe((s, _p, patch) => rec.actions.push({ t: Date.now() - rec.t0, patch }))
    },
    stop() { const out = rec; rec = null; return out },

    play(track, { speed = 1 } = {}) {
      play = { track, speed, startAt: Date.now(), idx: 0, paused: false }
      store.setState(track.snapshot)                        // 初始快照
      this._tick()
    },
    _tick() {
      if (!play || play.paused) return
      const elapsed = (Date.now() - play.startAt) * play.speed
      const { actions } = play.track
      while (play.idx < actions.length && actions[play.idx].t <= elapsed) {
        store.setState(actions[play.idx].patch)             // 回放期间实时写入需被锁
        play.idx++
      }
      if (play.idx < actions.length) setTimeout(() => this._tick(), 16)   // rAF 步进
      else play = null
    },
    pause() { if (play) play.paused = true },
    resume() { if (play) { play.paused = false; this._tick() } },
  }
}
```
**评分点**：
- 录制=初始快照+带时间戳动作流；回放先快照后按时间轴 apply
- 倍速实现为「虚拟时间轴」缩放，不是逐条 setTimeout 累积误差
- 暂停/恢复保持时间轴一致性（恢复后 startAt 重新校准为可加分项，至少要点出）
- 回放期间写锁/回放态标记（防止实时事件污染回放）
