## ZSM-418：手写状态迁移双写对比器（灰度验证期）
**答**：实现 `createDualWriter(oldStore, newStore, transform)`：1) `write(patch)`：同时写两库（old 直写，new 经 transform 归一后写）；2) 写后对比两库同一视图（viewFn）结果，不一致计数并上报（采样上报，1/10）；3) `read()` 读路径：灰度开关开→读 new（missing 回退 old）；关→读 old；4) `stats()` 返回 { writes, mismatch, mismatchRate }；5) mismatch 率超阈值自动回退读 old（保护）。

```javascript
export function createDualWriter(oldStore, newStore, transform, viewFn, { sampleRate = 0.1 } = {}) {
  let writes = 0, mismatch = 0, fallback = false
  const MISMATCH_LIMIT = 0.02

  function write(patch) {
    writes++
    oldStore.setState(patch)
    newStore.setState(transform(patch))
    const a = viewFn(oldStore.getState())
    const b = viewFn(newStore.getState())
    if (JSON.stringify(a) !== JSON.stringify(b)) {
      mismatch++
      if (Math.random() < sampleRate) report('dual_write_mismatch', { a, b })
      if (mismatch / writes > MISMATCH_LIMIT) fallback = true     // 自动回退保护
    }
  }

  return {
    write,
    read: () => {
      if (!fallback) {
        const n = newStore.getState()
        if (Object.keys(n).length) return viewFn(n)               // new 优先
      }
      return viewFn(oldStore.getState())                          // 回退 old
    },
    stats: () => ({ writes, mismatch, mismatchRate: writes ? mismatch / writes : 0, fallback }),
  }
}
```
**评分点**：
- 双写必须先 old 后 new（回滚安全：old 永远可用）
- 对比用同一 viewFn（视图级对比，不比内部结构）
- 采样上报（量控）；mismatch 超阈值自动回退读 old（保护优先）
- stats 可观测驱动灰度推进决策
