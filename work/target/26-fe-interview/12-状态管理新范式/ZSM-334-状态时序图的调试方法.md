## ZSM-334：「值什么时候被谁改的」这类问题怎么调试

**答**:
- 时间线方法：给可疑字段加 setter 探针（包装 setState 拦截该字段变化），打印调用栈 + 时间戳，一屏看清谁在什么时刻写入了什么
- Chrome DevTools 配合：对对象属性用 `debug(obj, 'field')` 设置属性断点，变更时自动断住拿到完整栈
- 归因分组：探针输出按「来源」分类（用户操作/接口回调/定时器/推送），杂音过滤后异常写入一目了然
- 长期化：可疑域的写入探针做成 dev 开关（devtools 面板一键启用），变成团队调试基建而非临时 hack

```javascript
function probe(store, field) {
  let value = store.getState()[field]
  store.subscribe((s) => {
    if (!Object.is(s[field], value)) {
      console.trace(`[${field}] ${value} → ${s[field]}`)   // 完整调用栈
      value = s[field]
    }
  })
}
// 或：console DOM 断点 debug(store.__rawState, 'status')
```
