## ZSM-825：笔试终章收官：12 目录全笔试清单与一周复习计划

**答**：终章交付两张清单——①扩量 400 张的笔试卡全清单（编号+主题+核心评分点关键词）；②按天分配的一周复习计划。此卡本身是笔试卡的「索引笔试题」：实现 `buildReviewPlan(cards, { days })`：按「评分点关键词聚类」分组，每天复习一组（当天组 = 关键词最相近的卡），输出按天清单。附用例。

```javascript

}

function buildReviewPlan(cards, { days = 7 } = {}) {
  // 按评分点关键词聚类（伪码：取每卡第一个评分点关键词为签名）
  const all = Object.entries(cards).flatMap(([cat, list]) => list.map((c) => ({ cat, card: c })))
  const groups = new Map()
  for (const item of all) {
    const sig = item.card.split(' ')[0]       // 简化：按主题首词聚类
    ;(groups.get(sig) ?? groups.set(sig, []).get(sig)).push(item)
  }
  const clusters = [...groups.values()].sort((a, b) => b.length - a.length)
  const perDay = Math.ceil(clusters.length / days)
  return Array.from({ length: days }, (_, d) => ({
    day: d + 1,
    clusters: clusters.slice(d * perDay, (d + 1) * perDay).flat().map((c) => c.card),
  }))
}

// 用例
const plan = buildReviewPlan(WRITTEN_CARDS, { days: 7 })
console.log(plan.map((p) => `Day${p.day}: ${p.clusters.length} 张`))
// Day1~7 每天约 18-19 张：相近评分点聚组，一周覆盖全笔试
// 复习动作：Day N = 默写评分点 → 重写 2 张代表卡 → 错卡进 Day7 复测
```
**评分点**：
- 评分点关键词聚类分组（相近主题同天复习）
- 天数均衡分配（ceil 分片）
- 复习动作模板（默写→重写→错卡复测闭环）
- 全清单结构（按考点五类索引笔试 130 张）
