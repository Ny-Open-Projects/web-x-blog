## ZSM-323：本地撤销操作要不要广播给协作者怎么设计

**答**:
- 原则：协作场景撤销是「数据事件」不是「私人行为」——你 undo 删除的内容必须同步到他人，否则状态分裂；广播的是 undo 产生的逆 op，而非「undo 信号」
- 协议设计：undo 时从本地历史栈取 op，生成 inverse op 走与普通编辑相同的提交/广播通道（同 seq 协议），他人收到后按普通变更应用
- 不广播 undo 信号的另一层原因：他人没有你的历史栈，无法解释「undo」；广播 op 才是唯一通用语言
- 边界：他人正在编辑同一区域时，逆 op 需要变换（OT）或被 CRDT 合并；客户端只管发出，冲突交给协作算法

```javascript
function undo() {
  const op = history.pop()
  if (!op) return
  const inverse = invert(op)
  applyLocal(inverse)
  broadcast({ type: 'op', op: inverse, seq: nextSeq() })   // 与普通编辑同通道同协议
}
```
