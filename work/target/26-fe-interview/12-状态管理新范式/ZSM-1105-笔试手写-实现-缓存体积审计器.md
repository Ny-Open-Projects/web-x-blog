## 1105：笔试手写：实现 缓存体积审计器

**答**：实现 auditCache(cache)：cache 为 Map<key, { data, ts }>。估算每条目的序列化体积（JSON.stringify 长度近似字节）；输出总体积、Top-N 大对象（key + size + data 的顶层字段类型分布）、以及体积超阈值（如 100KB）的告警清单。注意循环引用与 undefined 的序列化兜底。

```js
function auditCache(cache, threshold = 100 * 1024, topN = 5) {
  const safeSize = v => {
    try {
      const seen = new WeakSet();
      return JSON.stringify(v, (k, x) => {
        if (typeof x === 'object' && x !== null) {
          if (seen.has(x)) return '[Circular]';
          seen.add(x);
        }
        return x === undefined ? null : x;
      })?.length ?? 0;
    } catch { return -1; } // 不可序列化（函数/BigInt）标 -1
  };
  const entries = [...cache.entries()]
    .map(([key, { data }]) => ({ key, size: safeSize(data) }));
  const total = entries.reduce((s, e) => s + Math.max(e.size, 0), 0);
  const over = entries.filter(e => e.size > threshold);
  const top = [...entries].sort((a, b) => b.size - a.size).slice(0, topN);
  return { total, top, alerts: over };
}
```

**评分点**：
- 序列化体积近似（缓存内存占用的可操作代理指标）
- replacer 处理循环引用与 undefined（stringify 的两个经典坑）
- 不可序列化条目标 -1 不计入总量
- 能讨论：审计驱动的治理——大对象改 select 裁剪或 gcTime 缩短
