## ZSM-848：手写事故率验收计算器（沙盘推演的 ROI 量化）
**答**：实现 `computeIncidentROI(prevQuarter, currQuarter, investment)`：1) 事故分类计数对比（P0/P1/P2 各类下降率）；2) 总事故率降幅 vs 目标（-50%）判定；3) ROI：事故处置人时成本节省 / 投入人日 × 8h；4) 加权计分：P0 权重 ×3、P1 ×2（P0 减少价值更高）；5) 附用例：目标达成判定与 ROI 为负的场景。

```javascript
const COST_PER_EVENT_HOURS = { P0: 12, P1: 4, P2: 1 }   // 处置人时
const WEIGHTS = { P0: 3, P1: 2, P2: 1 }

function computeIncidentROI(prev, curr, { investPersonDays = 25, targetReduction = 0.5 } = {}) {
  // 加权事故率对比
  const weighted = (q) => Object.keys(WEIGHTS).reduce((a, k) => a + (q[k] ?? 0) * WEIGHTS[k], 0)
  const prevW = weighted(prev)
  const currW = weighted(curr)
  const reduction = prevW ? +((prevW - currW) / prevW).toFixed(2) : 0
  const targetMet = reduction >= targetReduction

  // ROI：处置人时节省 / 投入
  const costHours = (q) => Object.keys(COST_PER_EVENT_HOURS)
    .reduce((a, k) => a + (q[k] ?? 0) * COST_PER_EVENT_HOURS[k], 0)
  const savedHours = Math.max(0, costHours(prev) - costHours(curr))
  const investedHours = investPersonDays * 8
  const roi = investedHours ? +(savedHours / investedHours).toFixed(2) : 0

  // 分级明细
  const detail = Object.keys(WEIGHTS).map((k) => ({
    level: k,
    prev: prev[k] ?? 0,
    curr: curr[k] ?? 0,
    reduction: prev[k] ? +(((prev[k] - (curr[k] ?? 0)) / prev[k]) * 100).toFixed(0) + '%' : 'n/a',
  }))

  return {
    weightedReduction: reduction,
    targetMet,
    detail,
    savedHours,
    investedHours,
    roi,                     // >1 = 回本
    verdict: targetMet && roi >= 1 ? '达标且回本'
      : targetMet ? '达标但 ROI 需观察（事故减少但处置成本结构变化）'
      : '未达标——健康分整改加码',
  }
}

// 用例
const r1 = computeIncidentROI(
  { P0: 2, P1: 14, P2: 30 },
  { P0: 1, P1: 6, P2: 18 },
  { investPersonDays: 25 },
)
console.log(r1.weightedReduction)   // 0.55（加权降 55%）
console.log(r1.targetMet)           // true（≥0.5）
console.log(r1.savedHours, r1.investedHours)   // P0:12+P1:32+P2:12=56h 节省 / 200h 投入
console.log(r1.roi, r1.verdict)     // 0.28 '达标但 ROI 需观察'——当季回本不足，次季延续收益

const r2 = computeIncidentROI(
  { P0: 5, P1: 20, P2: 10 },
  { P0: 0, P1: 8, P2: 5 },
  { investPersonDays: 10 },
)
console.log(r2.roi, r2.verdict)     // 高 ROI + 达标：'达标且回本'
```
**评分点**：
- 加权事故率（P0×3/P1×2——P0 减少价值更高）
- 目标判定与分级明细（reduction 百分比）
- ROI 双口径（处置人时节省 / 投入人日×8）
- verdict 三态（达标回本/达标观察/未达标加码）
