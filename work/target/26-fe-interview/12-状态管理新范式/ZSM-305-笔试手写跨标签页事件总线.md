## ZSM-305：手写跨标签页事件总线（BroadcastChannel + storage 降级）
**答**：实现 `createCrossTabBus(name)`：1) 优先用 BroadcastChannel，不可用降级 storage 事件；2) `emit(type, payload)`；3) `on(type, handler)` 返回退订；4) storage 降级时用时间戳 + 随机 id 去重（避免自己触发自己或重复消费）；5) 收发均做 JSON 安全校验。

```javascript
export function createCrossTabBus(name) {
  const handlers = new Map()   // type → Set<handler>
  const selfId = Math.random().toString(36).slice(2)
  let bc = null
  try { bc = new BroadcastChannel(name) } catch { /* 降级 */ }

  function dispatch(msg) {
    if (msg._id === selfId) return                        // 不消费自己
    handlers.get(msg.type)?.forEach((h) => h(msg.payload, msg))
  }

  if (bc) {
    bc.onmessage = (e) => dispatch(e.data)
  } else {
    window.addEventListener('storage', (e) => {
      if (e.key !== name || !e.newValue) return
      try { dispatch(JSON.parse(e.newValue)) } catch { /* 校验失败忽略 */ }
    })
  }

  return {
    emit(type, payload) {
      const msg = { type, payload, _id: selfId, _t: Date.now() }
      if (bc) bc.postMessage(msg)
      else try { localStorage.setItem(name, JSON.stringify(msg)) } catch { /* 配额 */ }
    },
    on(type, handler) {
      if (!handlers.has(type)) handlers.set(type, new Set())
      handlers.get(type).add(handler)
      return () => handlers.get(type).delete(handler)
    },
  }
}
```
**评分点**：
- 自己 id 过滤（storage 方案里自己 setItem 会触发其他页但自己也收不到，id 主要防重复消费场景）
- JSON.parse try-catch，恶意/损坏消息不炸总线
- on 返回退订；handler 集合用 Set 去重
- BroadcastChannel 与 storage 分支的消息结构保持一致
