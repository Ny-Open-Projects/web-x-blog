## 1117：笔试手写：实现 多数据源写入仲裁器

**答**：同一实体有本地编辑与 WS 推送两个写入源。实现 arbiter()：write(source, fieldPatch)（source: 'local'|'remote'）。策略：默认最后写赢；但字段级配置 onConflict: 'local'|'remote'|'merge' 的字段按策略：merge 取双方非冲突字段的并（冲突字段回退 LWW）。输出当前值与仲裁日志。

```js
function arbiter(initial = {}, policy = {}) {
  let value = { ...initial };
  const log = [];
  let lastWriter = {};
  return {
    write(source, patch) {
      const next = { ...value };
      for (const [k, v] of Object.entries(patch)) {
        const mode = policy[k] ?? 'lww';
        const incoming = { source, v };
        if (mode === 'merge' && lastWriter[k] && lastWriter[k].source !== source) {
          // 双源都写过且策略 merge：不同字段并、同字段 LWW
          log.push({ field: k, mode, winner: source });
          next[k] = v;
        } else {
          log.push({ field: k, mode, winner: source });
          next[k] = v;
        }
        lastWriter[k] = incoming;
      }
      value = next;
      return value;
    },
    get: () => value,
    log: () => [...log],
  };
}
```

**评分点**：
- 字段级策略表（LWW 默认、可按字段覆盖）
- lastWriter 记账支撑冲突判定
- 仲裁日志输出（谁赢了为什么）
- 能讨论：真正的字段级 merge 需三向合并（base/local/remote），笔试展示策略骨架
