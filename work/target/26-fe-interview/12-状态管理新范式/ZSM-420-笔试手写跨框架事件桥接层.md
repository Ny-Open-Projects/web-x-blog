## ZSM-420：手写跨框架事件桥接层（vanilla 总线 + React/Vue 适配）
**需求**：实现三层：1) vanilla 总线 `bus.on/emit/off`（带通配符 `user:*` 支持）；2) React 适配 `useBusEvent(type, handler)`：挂载订阅、卸载退订、handler 用 ref 保持最新（不重订阅）；3) Vue 适配 `useBusEvent(type, handler)`：onMounted 订阅 onUnmounted 退订；4) emit 时 payload 深冻结（防消费方篡改广播数据）；5) 同步 emit（可预测时序），异常 handler 隔离不炸总线。

```javascript
// 1) vanilla 总线
export function createBus() {
  const subs = new Map()      // pattern → Set<handler>
  const match = (pat, type) => pat === type || (pat.endsWith('*') && type.startsWith(pat.slice(0, -1)))

  function emit(type, payload) {
    const frozen = deepFreeze(payload)
    subs.forEach((hs, pat) => match(pat, type) && hs.forEach((h) => {
      try { h(frozen, type) } catch (e) { report('bus_handler_error', e) }   // 隔离
    }))
  }
  const on = (pat, h) => { if (!subs.has(pat)) subs.set(pat, new Set()); subs.get(pat).add(h)
    return () => off(pat, h) }
  const off = (pat, h) => subs.get(pat)?.delete(h)
  return { emit, on, off }
}

function deepFreeze(o) {
  if (o && typeof o === 'object') Object.values(o).forEach(deepFreeze)
  return Object.freeze(o)
}

// 2) React 适配
export function useBusEvent(bus, type, handler) {
  const ref = useRef(handler); ref.current = handler          // ref 保持最新
  useEffect(() => bus.on(type, (...args) => ref.current(...args)), [type])   // type 变才重订阅
}

// 3) Vue 适配
export function useBusEventV(bus, type, handler) {
  onMounted(() => { const off = bus.on(type, handler); onUnmounted(off) })
}
```
**评分点**：
- 通配符匹配正确（前缀 + *）；退订函数契约统一
- React ref 技巧避免 handler 变化导致重订阅（性能与正确性双收）
- payload 深冻结防篡改广播（广播数据不可变的契约）
- handler 异常隔离（一个消费者炸不掉总线与广播给其他消费者）
