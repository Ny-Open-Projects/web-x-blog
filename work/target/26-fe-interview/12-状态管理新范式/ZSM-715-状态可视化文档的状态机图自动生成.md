## ZSM-715：状态可视化文档：从 reducer/atom 代码自动生成状态图

**答**：
- XState 有 Stately 自动成图（ZSM-566），但 Zustand/Jotai 项目没有现成图——自研「状态图生成器」的两条路：1) **约定式**：action 命名规范（`feature/event`）+ slice 结构，脚本扫描 createSlice/atom 定义生成 Mermaid 图（节点 = 状态字段分组，边 = extraReducers 里监听的 action 流向）；2) **运行时录制**：跑一轮测试用例录 action 流，生成实际可达路径图（真实使用视角）。
- Mermaid 输出的价值：PR 里贴图 review 状态变更影响面；docs 与代码同源（CI 生成，不手绘不过期）——「文档腐烂」的正解是生成而非维护。
- 生成器实现要点：AST 扫描（jscodeshift/babel parser）找 `createSlice({ reducers, extraReducers })` 与 `atom(...)` 的 read 依赖（get 调用）；图边语义：action → slice、atom → atom（派生依赖）；布局按域分组（feature 目录）。
- 补充「时序图」：关键业务流（下单）的 action 序列从录制数据生成 sequenceDiagram——状态图答「结构」，时序图答「过程」，两者互补。
- 追问钩子：可视化的最终形态是「状态图 + ADR（ZSM-712）+ 状态清单表（ZSM-550）」三件套入 onboarding 文档——新人一天理解状态架构。

```javascript
// Mermaid 状态图生成器（扫描 slice 定义）
import { parse } from '@babel/parser'
import traverse from '@babel/traverse'

function generateMermaid(sources) {
  const nodes = new Map()     // sliceName -> [stateFields]
  const edges = []            // { from: actionType, to: sliceName }

  for (const src of sources) {
    const ast = parse(src, { sourceType: 'module', plugins: ['typescript'] })
    traverse(ast, {
      CallExpression(path) {
        if (path.node.callee.name !== 'createSlice') return
        const [config] = path.node.arguments
        const name = getObjectProp(config, 'name')?.value
        const reducers = getObjectProp(config, 'reducers')
        const fields = extractStateFields(getObjectProp(config, 'initialState'))
        nodes.set(name, fields)
        // reducers → 自环
        getObjectProps(reducers).forEach((r) => edges.push({ from: `${name}/${r}`, to: name }))
        // extraReducers → 跨 slice 边
        const extra = getObjectProp(config, 'extraReducers')
        scanExtraActions(extra).forEach((a) => edges.push({ from: a, to: name }))
      },
    })
  }

  let mermaid = 'graph TD\n'
  nodes.forEach((fields, name) => {
    mermaid += `  subgraph ${name}\n${fields.map((f) => `    ${name}__${f}["${f}"]`).join('\n')}\n  end\n`
  })
  edges.forEach(({ from, to }) => { mermaid += `  ${from.replace(/\W/g, '_')} --> ${to}\n` })
  return mermaid
}

// CI 集成：PR 时生成并 comment
// pnpm stategraph > docs/state-graph.mmd
// mermaid 渲染：slice 节点组 + action 流向边，review 一眼看懂数据流
```
