## 1106：笔试手写：实现 脱敏持久化管道

**答**：persist 前需脱敏。实现 sanitizePipeline()：返回 { outbound(state), inbound(raw) }。outbound 按 SENSITIVE 字段名单（支持 'a.b.c' 路径）把值替换为 '[REDACTED]' 并把 token 类字段加密（笔试用 base64 模拟）；inbound 还原加密字段、跳过 REDACTED（保留 store 默认值）。名单外字段原样通过。

```js
const SENSITIVE = ['user.token', 'profile.idCard'];
function sanitizePipeline() {
  const setPath = (obj, path, val) => {
    const keys = path.split('.');
    let o = obj;
    for (let i = 0; i < keys.length - 1; i++) o = o[keys[i]] ??= {};
    o[keys.at(-1)] = val;
  };
  const getPath = (obj, path) =>
    path.split('.').reduce((o, k) => o?.[k], obj);
  return {
    outbound(state) {
      const out = structuredClone(state);
      for (const p of SENSITIVE) {
        const v = getPath(out, p);
        if (v === undefined) continue;
        if (/token/i.test(p)) setPath(out, p, btoa(String(v))); // 加密（模拟）
        else setPath(out, p, '[REDACTED]');
      }
      return out;
    },
    inbound(raw) {
      const out = structuredClone(raw);
      for (const p of SENSITIVE) {
        const v = getPath(out, p);
        if (v === '[REDACTED]') setPath(out, p, undefined); // 回落默认值
        else if (/token/i.test(p) && v) setPath(out, p, atob(v));
      }
      return out;
    },
  };
}
```

**评分点**：
- 路径名单驱动（'a.b.c' 嵌套字段可命中）
- token 类走可逆加密、其余走 REDACTED（两类策略）
- inbound 对 REDACTED 置 undefined 让 store 回落默认
- 能讨论：REDACTED 持久化后 refresh 体验 vs 安全的权衡
