## ZSM-315：会话过期时全应用状态怎么收敛

**答**:
- 收敛目标：过期后应用回到「干净未登录基线」——清服务端缓存（queryClient.clear/removeQueries）、清持久化 storage（防下一用户读到残留）、清客户端态中的用户数据、UI 回登录页
- 触发源统一：401 拦截、刷新 token 失败、心跳断开——都汇聚到同一个 `onSessionEnd(reason)`，不在各组件散落处理
- 安全红线：账号切换必须物理清除（clear 而非 invalidate，invalidate 只是重拉）；storage 里的 token/草稿按含用户 id 的 key 清理
- 恢复友好：收敛前保存「当前路由 + 未提交草稿」，重登后恢复到原位置

```javascript
function onSessionEnd(reason) {
  queryClient.clear()                                  // 服务端缓存物理清除
  Object.keys(localStorage)
    .filter((k) => k.startsWith('user:'))              // 用户态 storage 清理
    .forEach((k) => localStorage.removeItem(k))
  appStore.setState({ user: null, routeBefore: location.pathname })
  navigate('/login?reason=' + reason)
}
```
