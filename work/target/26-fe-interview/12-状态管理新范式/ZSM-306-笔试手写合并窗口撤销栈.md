## ZSM-306：手写带合并窗口与上限的撤销栈
**需求**：实现 `createHistory()`：1) `push(state, tag?)`：记录状态，相同 tag 在 300ms 内合并为一步；2) `undo()`/`redo()` 返回对应状态；3) 上限 50 步 FIFO 淘汰；4) push 新状态时清空 redo 栈；5) undo/redo 在边界时返回当前状态并返回 `{ state, changed: false }`。

```javascript
export function createHistory({ limit = 50, mergeMs = 300 } = {}) {
  let past = [], future = [], cur = null
  let lastTag = null, lastTime = 0

  return {
    push(state, tag = null) {
      const now = Date.now()
      const merged = tag !== null && tag === lastTag && now - lastTime < mergeMs
      if (cur !== null && !merged) past = [...past.slice(-(limit - 1)), cur]  // FIFO 淘汰
      if (!merged) future = []                                                 // 分叉清 redo
      cur = state
      lastTag = tag; lastTime = now
      return { state, changed: true }
    },
    undo() {
      if (!past.length) return { state: cur, changed: false }
      future.push(cur)
      cur = past.pop()
      return { state: cur, changed: true }
    },
    redo() {
      if (!future.length) return { state: cur, changed: false }
      past.push(cur)
      cur = future.pop()
      return { state: cur, changed: true }
    },
  }
}
```
**评分点**：
- 合并窗口三条件：tag 相同 + 时间窗内 + 不清 redo（连续输入只算一步）
- push 时 redo 栈清空（时间线分叉语义）
- slice(-(limit-1)) 的 FIFO 淘汰边界（limit=1 时不越界）
- undo/redo 边界返回 changed:false，调用方无需判空
