## 1101：笔试手写：实现 分页游标缓存合并器

**答**：实现 mergePages(cached, incoming)：cached/incoming 为 { items, cursor }[] 页。合并时按 items 的 id 去重（保留先到的），按 id 升序重排；incoming 与 cached 的重叠页标记 dirty: true（服务端数据可能已变，需静默刷新）；输出合并后的页列表与去重统计。

```js
function mergePages(cached, incoming) {
  const seen = new Set();
  let dup = 0;
  const all = [...cached, ...incoming].flatMap(p => p.items)
    .filter(item => {
      if (seen.has(item.id)) { dup++; return false; }
      seen.add(item.id);
      return true;
    })
    .sort((a, b) => a.id - b.id);
  const cachedIds = new Set(cached.flatMap(p => p.items.map(i => i.id)));
  const dirty = incoming.map(p => ({
    cursor: p.cursor,
    dirty: p.items.some(i => cachedIds.has(i.id)), // 重叠页需刷新
  }));
  return { items: all, dedupCount: dup, pageMeta: dirty };
}
```

**评分点**：
- flatMap 摊平 + id 去重 + 重排三步走
- 重叠页的 dirty 标记（静默刷新的依据）
- 去重计数输出（对账信号）
- 能讨论：游标分页下乱序到达的排序依据必须是稳定 id 而非索引
