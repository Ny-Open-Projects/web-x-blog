## ZSM-335：状态写入的幂等性怎么保证（重复事件/重放安全）

**答**:
- 幂等是回放/重试安全的前提：同一事件应用两次结果不变，时间旅行、WS 重连补发、录制回放才可靠
- 手段一：事件带唯一 id，写入侧维护已处理集合（带过期）去重；手段二：upsert 语义（按 id 覆盖）天然幂等；手段三：增量运算改为绝对值赋值（count=5 而非 count++）
- 计数类陷阱：在线人数 +1/-1 事件流不可靠时幂等失效——改为定期快照校准（绝对值事件周期覆盖）
- 写入协议约定：所有推送/回放路径的 reducer 必须「无自增依赖、无时间依赖（除事件自带时间戳）」

```javascript
// ❌ 非幂等
applyEvent('view', () => store.setState((s) => ({ count: s.count + 1 })))
// ✅ 幂等三式
const seen = new Set()
applyEvent('view', (e) => {
  if (seen.has(e.id)) return; seen.add(e.id)                       // 去重
  store.setState((s) => ({ viewers: upsert(s.viewers, e.user) }))  // upsert
})
// 计数：快照校准
setInterval(() => fetchCount().then((n) => store.setState({ count: n })), 60_000)
```
