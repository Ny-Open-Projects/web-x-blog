## ZSM-395：场景题示范：目录树懒加载/拖拽/展开态持久化

**答**:
- 数据形态：已加载子树进 store（Map<id, node>），未加载节点标记 lazy；展开是「按需触发子级查询」（key 含父 id），兄弟展开互不影响
- 展开态持久化：expandedSet（Set<id>）单独持久化（用户偏好），与数据层分离——数据刷新后展开态重放
- 拖拽移动：乐观移动（本地父子关系改）→ 提交 → 服务端确认（环检测在提交前本地预判：不能移到自己子孙下）
- 重命名/删除：单节点 mutation + 受影响路径失效；删除文件夹级联——服务端权威，前端乐观删除 + 失败恢复

```javascript
const expanded = useStore((s) => s.expandedSet)          // 持久化偏好
function toggle(id) {
  const next = new Set(expanded); next.has(id) ? next.delete(id) : next.add(id)
  useStore.setState({ expandedSet: next })
}
function move(nodeId, targetId) {
  if (isDescendant(targetId, nodeId)) return toast('不能移动到子目录')   // 本地环预判
  optimisticMove(nodeId, targetId)
  api.move({ nodeId, targetId }).catch(() => rollbackMove(nodeId))
}
```
