## ZSM-379：场景题示范：商品详情页多数据源聚合的状态设计

**答**:
- 多源分缓存：商品主数据（staleTime 长，prefetch 已命中）、实时价格/库存（短 staleTime + 视口激活）、推荐流（无限分页）、评价（分页懒加载）——各自独立 key 独立失败，不搞一个大聚合接口缓存
- 聚合展示派生：页面级「可买状态」由多源派生（主数据上架 × 库存 > 0 × 限购规则），派生函数集中可测
- 依赖与时序：推荐不阻塞主内容（idle/视口加载）；价格失效触发可买状态重算——依赖用 derived atom / useMemo 显式声明
- 失败降级：价格接口失败 → 按钮置灰「价格获取中」而不是展示旧价误导下单（资金安全优先）

```javascript
const sku = useQuery({ queryKey: ['sku', id], queryFn: fetchSku, staleTime: 3600_000 })
const price = useQuery({ queryKey: ['price', id], queryFn: fetchPrice, staleTime: 10_000 })
const stock = useQuery({ queryKey: ['stock', id], queryFn: fetchStock, refetchInterval: 15_000 })
const buyable = useMemo(() =>
  sku.data?.onSale && price.isSuccess && (stock.data?.qty ?? 0) > 0, [sku, price, stock])
if (price.isError) return <Button disabled>价格获取中…</Button>   // 降级不误导
```
