## ZSM-805：大厂真题拆解：状态题的四种题型与考点矩阵

**答**：
- 大厂状态题的四种题型与本块知识的映射矩阵（备考用）：
- **题型 A「原理题」**（字节风格）：「React 18 并发下状态库怎么防撕裂」「Jotai 和 Zustand 内部区别」——答 L2/L3 层（ZSM-803 三层法），对应 501/513/615/504/626。
- **题型 B「手写题」**（阿里笔试风格）：「实现一个 useShallow」「手写 undo/redo」——本库 30+ 张笔试卡直备，评分点就是监考官的落点（ZSM-521/531）。
- **题型 C「场景设计题」**（腾讯系统设计风格）：「设计一个 IM 前端状态层」「设计协同表格」——分层骨架（ZSM-802），重点考「边界与取舍」（什么不做比做了什么更被关注）。
- **题型 D「排查题」**（美团工程化风格）：「线上反馈列表卡顿给你排查」（给录屏+监控数据）——九步法+工具地图（ZSM-625/717），重点考「证据链」。
- 矩阵用途：备考时按题型分配复习权重——A 题重源码块、B 题重笔试卡默写、C 题重设计骨架、D 题重度量叙事；每题型的「高分特征」与「低分特征」要能脱口而出。
- 追问钩子：四题型的识别信号——面试官问「为什么」是 A、给纸笔是 B、给业务场景是 C、给线上现象是 D；识别错题型会导致答非所问。

```javascript
// 题型×考点矩阵（备考地图）
const EXAM_MATRIX = {
  A_原理题: {
    signal: '面试官问「为什么/内部怎么做」',
    sources: ['ZSM-501 useStore校验', '513 双快照', '615 并发要求', '504 依赖图', '626 Query生命周期'],
    method: '三层法(803)：L1结论→L2实现证据→L3边界反例',
    highScore: '变量名级源码证据 + 真实踩坑案例',
    lowScore: '营销话术（轻量/简洁）',
  },
  B_手写题: {
    signal: '给纸笔/共享屏幕',
    sources: ['笔试卡 30+ 张（各块8张节奏）'],
    method: '先复述需求边界 → 写代码带注释 → 末尾主动报评分点',
    highScore: '边界处理 + 主动说评分点',
    lowScore: '直接写主流程不管边界',
  },
  C_场景设计: {
    signal: '给业务场景（IM/协同表格/购物车）',
    sources: ['设计骨架 802 + 建模五句式 700'],
    method: '澄清三问 → 协议栈分层 → 一致性分层 → 故障路径',
    highScore: '主动说不做什么（边界取舍）',
    lowScore: '一上来堆技术名词',
  },
  D_排查题: {
    signal: '给线上现象/录屏/监控截图',
    sources: ['九步法 625 + 工具地图 717'],
    method: '现象→复现脚本→基线→分层归因→根因→修复→门禁',
    highScore: '证据链（每步有数据）',
    lowScore: '猜原因直接改代码',
  },
}
```
