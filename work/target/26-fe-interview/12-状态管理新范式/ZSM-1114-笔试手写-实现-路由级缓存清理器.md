## 1114：笔试手写：实现 路由级缓存清理器

**答**：实现 createTagCleaner()：query 缓存条目注册 tag（register(key, tags[])）；离开路由时 purge(tags) 清理命中任一 tag 的条目；purge 支持 '*' 通配全部；提供 dryRun(tags) 只报将清理的 key 不真删。返回 { register, purge, dryRun, keys }。

```js
function createTagCleaner() {
  const reg = new Map(); // key -> Set(tags)
  const match = tags => {
    const hits = [];
    for (const [key, ts] of reg) {
      if (tags.includes('*') || tags.some(t => ts.has(t))) hits.push(key);
    }
    return hits;
  };
  return {
    register(key, tags) { reg.set(key, new Set(tags)); },
    purge(tags) {
      const hits = match(tags);
      hits.forEach(k => reg.delete(k)); // 真删（真实实现同步删 query 缓存）
      return hits;
    },
    dryRun(tags) { return match(tags); },
    keys: () => [...reg.keys()],
  };
}
```

**评分点**：
- tag 反查索引（Map<key, Set<tag>> 遍历匹配）
- purge 与 dryRun 分离（先预览后清理的操作习惯）
- '*' 通配与登出清场场景
- 能讨论：tag 设计粒度（实体级 tag 如 ['post', 'post:42'] 支持精准失效）
