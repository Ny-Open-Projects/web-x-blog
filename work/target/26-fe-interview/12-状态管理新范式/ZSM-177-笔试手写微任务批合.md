## ZSM-177：手写微任务批合并 store（同帧多次 set 只广播一次）
**需求**：实现 `createStore(initial)` 返回 `{ getState, setState, subscribe }`：1) setState 函数式或对象式更新并浅合并；2) 同一个微任务周期内多次 setState，订阅者只收到一次通知（读到的是最终合并结果）；3) subscribe 返回退订函数；4) 通知时抛错的监听器不影响其他监听器执行。边界：订阅回调里再 setState 不能死循环通知。

```javascript
export function createStore(initial) {
  let state = initial
  const listeners = new Set()
  let scheduled = false

  function flush() {
    scheduled = false
    for (const fn of [...listeners]) {
      try { fn(state) } catch (e) { console.error(e) }   // 隔离异常
    }
  }

  function schedule() {
    if (scheduled) return
    scheduled = true
    queueMicrotask(flush)                // 同微任务周期内合并为一次广播
  }

  return {
    getState: () => state,
    setState: (patch) => {
      const next = typeof patch === 'function' ? patch(state) : patch
      state = { ...state, ...next }      // 浅合并，引用必须换新
      schedule()
    },
    subscribe: (fn) => {
      listeners.add(fn)
      return () => listeners.delete(fn)
    },
  }
}

// 评分点：
// 1. 微任务级批合并：scheduled 标志保证一次周期只 flush 一次
// 2. setState 函数式/对象式双形态 + 浅合并语义
// 3. 监听器异常隔离（try/catch + 拷贝遍历防退订并发问题）
// 4. 回调内再 setState：只改 state 并再次 schedule，但已 scheduled 则合并，不死循环
// 5. subscribe 返回退订函数（Set 语义）
```
