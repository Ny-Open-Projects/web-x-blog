## ZSM-476：手写状态层错误边界钩子
**答**：实现 `safeSelector(selector, fallback)`：1) 包装 selector：执行异常时返回 fallback（而非让渲染崩溃）；2) 记录异常（path/错误/次数），同类异常连续 3 次 → 升级为「硬失败」（抛出让 ErrorBoundary 接住——持续性 bug 不该静默吞）；3) `health()` 返回各 selector 的异常统计；4) fallback 支持工厂（每次返回新默认值或共享常量由调用方决定）；5) 异常捕获后仍保持缓存语义（下次输入相同可重试计算而非永远 fallback）。

```javascript
export function safeSelector(selector, fallback, { hardFailAfter = 3 } = {}) {
  let errors = 0
  let lastErrorKey = ''

  return (state) => {
    try {
      const r = selector(state)
      errors = 0                                             // 成功重置计数
      lastErrorKey = ''
      return r
    } catch (e) {
      const key = String(e?.message ?? e)
      if (key === lastErrorKey) errors++; else { errors = 1; lastErrorKey = key }
      report('selector_error', { error: key, count: errors })
      if (errors >= hardFailAfter) throw e                   // 持续失败升级硬失败
      return typeof fallback === 'function' ? fallback(state) : fallback
    }
  }
}

// 用法：派生崩了给默认视图，但持续崩升级给 ErrorBoundary
const totalSafe = safeSelector(
  (s) => s.items.reduce((a, i) => a + i.price, 0),   // items undefined 时崩
  0,
)
```
**评分点**：
- 软降级 → 硬失败升级（连续同类异常 3 次）：静默吞掩盖 bug 与崩溃用户体验的平衡
- 同类判定（错误 message key）防止不同错误互相刷新计数
- 成功重置计数（间歇性异常不误升级）
- fallback 双形态（常量/工厂）+ health 统计（health 由 errors 计数体现，可扩展）
