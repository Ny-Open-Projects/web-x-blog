## ZSM-561：状态快照导出/导入功能的安全与版本设计

**答**：
- 快照导出/导入（客服让用户导出状态排查、QA 复现场景）三大风险：PII 泄漏（导出含 token/手机号）、注入（导入内容含 `__proto__` 污染原型链）、版本漂移（旧版本快照灌进新代码结构）。
- 导出侧：字段白名单（per-store 声明 `exportable: (s) => ({ items: s.items })`），敏感字段显式脱敏；导出文件带 `schemaVersion + exportedAt + appVersion`。
- 导入侧三道闸：1) **深解析防原型污染**——`JSON.parse` 后过滤 `__proto__/constructor/prototype` 键（或用 reviver 拒绝）；2) **schema 校验**——按 version 走 migrate 链，未知版本拒绝；3) **范围限权**——只写入声明了可导入的 store，且导入后必须经过业务校验（金额重新算，不信任快照里的 derived 字段）。
- derived 字段绝不导入：快照只含「事实」，派生值（小计、isDirty、权限结果）重建时重算——把 derived 灌回去等于把可能被篡改的数据当事实。
- 追问钩子：导入后触发一次全量 revalidate（invalidate 服务端缓存查询），保证快照里的服务端态与真实一致。

```javascript
const SNAPSHOT_SCHEMA_VERSION = 3

function exportSnapshot(stores) {
  return {
    schemaVersion: SNAPSHOT_SCHEMA_VERSION,
    appVersion: APP_VERSION,
    exportedAt: Date.now(),
    stores: stores.map((s) => ({
      name: s.name,
      state: s.exportable(useStore.getState()),   // 白名单导出，敏感字段已脱敏
    })),
  }
}

// 防原型污染解析
function safeParse(str) {
  return JSON.parse(str, (key, value) => {
    if (['__proto__', 'constructor', 'prototype'].includes(key)) {
      throw new Error(`illegal key: ${key}`)      // reviver 直接拒绝
    }
    return value
  })
}

function importSnapshot(json, stores) {
  const snap = safeParse(json)
  if (snap.schemaVersion !== SNAPSHOT_SCHEMA_VERSION) {
    return migrate(snap, stores)                 // 版本迁移链；未知版本抛错
  }
  for (const entry of snap.stores) {
    const store = stores.find((s) => s.name === entry.name)
    if (!store?.importable) continue             // 未声明可导入的 store 跳过
    store.setState((cur) => ({ ...cur, ...entry.state }))
    store.revalidate?.()                          // 全量对账：重算 derived + 刷新服务端数据
  }
}
```
