## ZSM-807：协同编辑器状态层系统设计（45 分钟白板演练）
**答**：设计题——设计一个协作白板/文档（多人光标 + 块编辑 + 历史 + 冲突）的状态层。
**① 澄清**：粒度（块级 vs 字符级——按同段并发编辑频率判，ZSM-685）、离线、规模。
**② 分层**：内容模型（块 Map+rank 分数定位）、presence（光标 TTL）、历史（命令栈+合并窗口 ZSM-531）、选区独立。
**③ 冲突语义**：块级 op 日志（upsert/move/delete）+ 服务端序、删改冲突用户裁决（不静默）、版本向量识别并发（ZSM-596）。
**④ 闭环**：undo 与协同的交互（undo 只撤自己的 op）、性能（块虚拟化+opacity 分层渲染）、可观测（op 日志回放）。

```javascript
const COEDITOR_DESIGN = {

// 评分落点：undo 与协同的交互（只撤自己）是本题最深的坑；rank 分数定位 vs 时间戳的取舍理由
```
**评分点**：
- undo 只撤自己 op 的协同约束（本题最深坑）
- rank 分数定位 vs 时间戳排序的取舍论证
- 删改冲突不静默裁决（UI 介入）
- 块级与字符级的演进路径（升级而非推翻）
