## 1109：笔试手写：实现 失败操作持久化重试队列

**答**：实现 createRetryQueue(storage)：enqueue(op)（op 为 { id, run: () => Promise, attempts }）；flush() 依次执行队列，失败的 op 按 attempts 指数退避计算下次可执行时间（backoff = 2^attempts * 1000，未到期跳过本次），attempts 达 5 移入 dead；每次队列变更调用 storage.save(JSON)。storage.load() 启动时恢复。

```js
function createRetryQueue(storage) {
  let queue = [];
  const persist = () => storage.save(JSON.stringify(queue));
  return {
    enqueue(op) { queue.push({ attempts: 0, nextAt: 0, ...op }); persist(); },
    async flush(now = Date.now()) {
      const dead = [];
      for (const op of queue) {
        if (now < op.nextAt) continue; // 退避期未到
        try { await op.run(); queue = queue.filter(o => o.id !== op.id); }
        catch {
          op.attempts++;
          if (op.attempts >= 5) { dead.push(op); queue = queue.filter(o => o.id !== op.id); }
          else op.nextAt = now + 2 ** op.attempts * 1000; // 指数退避
        }
      }
      persist();
      return { remaining: queue.length, dead: dead.map(o => o.id) };
    },
    restore: () => { const raw = storage.load(); if (raw) queue = JSON.parse(raw); },
    size: () => queue.length,
  };
}
```

**评分点**：
- 持久化到 storage（刷新/断网后队列存活）
- 指数退避 nextAt 与未到期跳过（而非 sleep 阻塞）
- attempts 上限进死信（dead）不再无限重试
- 能讨论：恢复时的幂等键校验（与 AGT 离线队列同构）
