## 1104：笔试手写：实现 权限位图计算器

**答**：权限用位图管理：bit0=read, bit1=write, bit2=admin, bit3=export。实现 permBitmap()：返回 { grant(mask), revoke(mask), has(mask), diff(other) }。diff 返回从当前到目标权限需要的 grant/revoke 位列表；has 用位与判定；位名与数值的映射常量表导出。

```js
const BITS = { read: 1 << 0, write: 1 << 1, admin: 1 << 2, export: 1 << 3 };
function permBitmap(initial = 0) {
  let mask = initial;
  const namesOf = m => Object.entries(BITS).filter(([, v]) => m & v).map(([n]) => n);
  return {
    grant: m => { mask |= m; },
    revoke: m => { mask &= ~m; },
    has: m => (mask & m) === m, // 请求位全集满足才算有
    get: () => mask,
    diff(target) {
      const add = target & ~mask, del = mask & ~target; // 目标有我无 / 我有目标无
      return { grantBits: namesOf(add), revokeBits: namesOf(del) };
    },
    names: () => namesOf(mask),
    BITS,
  };
}
```

**评分点**：
- 位运算 grant/revoke（|= 与 &= ~）
- has 判定用 (mask & m) === m（部分匹配不算有）
- diff 的集合差 translated 到位运算（add/del 对称差）
- 能讨论：位图 vs 权限数组的取舍（紧凑高效 vs 可读可扩展）
