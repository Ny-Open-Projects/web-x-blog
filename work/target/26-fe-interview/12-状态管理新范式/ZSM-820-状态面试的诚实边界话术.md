## ZSM-820：状态面试的诚实边界：不会答的题与划界话术

**答**:
- 诚实边界的三层话术（硬编是面试第一大减分项）：
- **L1 已知边界**：「这块我了解到 XX 层，再往下是 YY 的内部实现，我没有追」——给出已到深度 + 划界点，比含糊其辞专业。
- **L2 完全未知**：「这个我没实际用过/研究过，我的理解是…（给基于通用原理的推测并标注是推测）」——推测要标注，错误推测比沉默更糟。
- **L3 反问转化**：「这块你们团队是怎么做的？我也想学习」——把不会的题转化为交流，展示学习姿态（每场最多用一次，多了显得逃避）。
- 状态领域的高频「边界点」：React Flight 协议的序列化细节、CRDT 的完整数学证明、SSR 流式渲染的框架内部调度、Rust 工具链的 SWC 内部——这些答到「语义层」就该划界，别装懂实现层。
- 划界后的补救：转向相关已知领域（「CRDT 数学证明我没深究，但工程上我用过 Yjs 的 Y.Map，感知行为是…」）——从不会的点到会的点搭桥。
- 追问钩子：诚实边界的自信支撑——面试官问深是为了探边界，而不是要求全知；「知道边界在哪」本身就是能力证明，坦然划界的候选人反而更被信任。

```javascript
// 三层划界话术（状态领域高频边界点）
const HONESTY_PLAYBOOK = {
  L1_已知边界: {
    script: '这块我了解到 XX 层，再往下是 YY 的内部实现，我没有继续追',
    example: 'Zustand 的 useSyncExternalStoreWithSelector 的 inst 缓存我读过；再往下 React 内部 useSyncExternalStore 的调度我没追',
    applies: '源码追问到第三层',
  },
  L2_未知推测: {
    script: '这个我没实际用过。基于通用原理我的推测是…（标注：推测）',
    example: 'CRDT 的 RGA 数学收敛证明我没深究，但工程上 Yjs 的感知行为是——插入按 id 排序决胜，两端一致',
    trap: '错误推测比沉默更糟——推测必须标注',
  },
  L3_反问转化: {
    script: '这块你们团队是怎么做的？我也想学习',
    limit: '每场最多一次，多了=逃避',
    best_use: '面试官展示型的开放题',
  },
  状态领域边界点: [
    'Flight 协议序列化细节', 'CRDT 数学证明', 'SSR 流式调度内部', 'SWC 内部实现',
  ],
  补救: '搭桥：从不会的点到会的点（「数学没深究，工程感知是…」）',
  支撑: '知道边界在哪 = 能力证明；坦然划界 > 装懂',
}
```
