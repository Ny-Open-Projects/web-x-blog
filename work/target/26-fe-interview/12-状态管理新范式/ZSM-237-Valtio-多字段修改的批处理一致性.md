## ZSM-237：Valtio 连续改多个字段会不会触发多次渲染

**答**：
- 同一同步块内多次修改共享同一快照版本：Valtio 内部版本号 + 通知去重，React 并发渲染下只产生一次重渲染，快照是「批后」的一致状态
- 异步间隔的多次修改才会产生多次通知；跨宏任务要自己合并（收集后一次赋值）
- 一致性保证：订阅回调里拿到的 snapshot 不含「改到一半」的中间态，适合做不可视编辑器这类需要一致性回放的场景
- 但注意：proxy 内部嵌套对象修改是引用替换（immer 式 COW），读取旧快照安全，反向（在订阅里直接改 proxy）可能死循环——订阅回调只读不改

```javascript
state.a = 1; state.b = 2; state.c = 3   // 同步块 → 一个版本，一次渲染
// ❌ 反例
useSnapshot(state) // 订阅里
// someEffect: state.count++ → 又触发订阅 → 再改 → 死循环
```
