## ZSM-440：手写状态层性能采样器
**答**：实现 `createPerfSampler(store)`：1) 包装 setState 记录每次处理耗时（含订阅通知）；2) 滑动样本窗口 500 条；3) `p95()` 计算第 95 百分位耗时；4) 慢样本（>10ms）捕获完整上下文（action 名、调用栈、listener 数）最多存 10 条；5) 超长调用栈截断（前 5 帧 + 后 3 帧）；6) `report()` 返回 { count, p50, p95, max, slowSamples }；7) 采样率控制（全量计数但栈捕获仅 10% 采样）。

```javascript
export function createPerfSampler(store, { windowSize = 500, slowMs = 10 } = {}) {
  const samples = []       // 耗时
  const slow = []
  const origSet = store.setState

  store.setState = (patch, action = 'anon') => {
    const t0 = performance.now()
    const r = origSet(patch)
    const dt = performance.now() - t0
    samples.push(dt)
    if (samples.length > windowSize) samples.shift()
    if (dt > slowMs && slow.length < 10 && Math.random() < 0.1)   // 慢样本 + 采样率
      slow.push({ dt, action, stack: trimStack(new Error().stack), listeners: store.listenerCount?.() ?? -1 })
    return r
  }

  function pct(p) {
    if (!samples.length) return 0
    const sorted = [...samples].sort((a, b) => a - b)
    return sorted[Math.min(sorted.length - 1, Math.floor(sorted.length * p))] ?? sorted[sorted.length - 1]
  }

  function trimStack(stack) {
    const lines = (stack ?? '').split('\n')
    return [...lines.slice(0, 5), '...', ...lines.slice(-3)].join('\n')
  }

  return {
    p95: () => pct(0.95),
    report: () => ({ count: samples.length, p50: pct(0.5), p95: pct(0.95),
      max: samples.length ? Math.max(...samples) : 0, slowSamples: slow }),
  }
}
```
**评分点**：
- 滑动窗口（500 条）代表近期行为而非历史平均
- P95 计算边界正确（排序 + 索引钳制；空窗口返回 0）
- 慢样本上下文完整（action/栈/listener 数）且栈截断（上报体积控制）
- 采样率 10% 只影响「栈捕获」不影响耗时全量计数（准确性与成本分离）
