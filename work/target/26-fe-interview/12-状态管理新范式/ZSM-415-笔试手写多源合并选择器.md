## ZSM-415：手写多源合并选择器（主备数据源 + 新鲜度标记）
**答**：实现 `mergeSources(primary, fallback)`：1) 两源数据 `{ data, fetchedAt }`；2) 合并策略：primary 有数据且新鲜（maxAge 内）用 primary；primary 过期但存在 → 仍用 primary 但标 `stale: true`；primary 无数据用 fallback；两源都无 → null；3) 相同数据（深相等）时保持 primary 引用稳定；4) 输出 `{ data, source, stale, fetchedAt }`；5) maxAge 由调用方传入。

```javascript
function deepEqual(a, b) { return JSON.stringify(a) === JSON.stringify(b) }

export function mergeSources(primary, fallback, maxAge) {
  const now = Date.now()
  if (primary?.data) {
    const stale = now - primary.fetchedAt > maxAge
    return { data: primary.data, source: 'primary', stale, fetchedAt: primary.fetchedAt }
  }
  if (fallback?.data) {
    const p = primary                            // primary 过期无数据：待回填标记
    return { data: fallback.data, source: 'fallback', stale: true,
             fetchedAt: fallback.fetchedAt, pendingPrimary: !p?.data }
  }
  return null
}

// 使用：Query 两层 key
function useMerged(id) {
  const p = useQuery({ queryKey: ['detail', id], queryFn: () => fetchP(id), staleTime: 30_000 })
  const f = useQuery({ queryKey: ['detail-cache', id], queryFn: () => fetchCache(id), enabled: p.isError })
  return mergeSources(
    p.dataUpdatedAt ? { data: p.data, fetchedAt: p.dataUpdatedAt } : null,
    f.dataUpdatedAt ? { data: f.data, fetchedAt: f.dataUpdatedAt } : null,
    60_000,
  )
}
```
**评分点**：
- 三分支策略完整（新鲜 primary / 过期 primary 标 stale / fallback 兜底）
- stale 标记驱动 UI（旧数据展示 + 更新中提示），不静默混用
- source 标识可观测（排查「数据来自哪」）
- 引用稳定问题点出（深相等返回旧引用防下游抖动——实现可简化但要提及）
