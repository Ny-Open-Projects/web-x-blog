## ZSM-425：手写页面级状态管理器（生命周期感知 + 自动清理）
**答**：实现 `createPageState()`：1) `enter(pageId)` 进入页面：初始化页面命名空间（数据区 + 资源区）；2) `set(pageId, patch)` / `get(pageId)`；3) `registerCleanup(pageId, fn)` 注册页面清理钩子（订阅退订/定时器清理）；4) `leave(pageId)` 离开：执行全部清理钩子（逆序 LIFO）→ 删除命名空间 → 未执行的 cleanup 也清（防重复）；5) 同页重复 enter 重置命名空间（幂等）；6) `active()` 返回活跃页面列表。

```javascript
export function createPageState() {
  const pages = new Map()      // pageId → { data, cleanups: Set }

  function enter(pageId) {
    if (pages.has(pageId)) leave(pageId)                    // 幂等重置
    pages.set(pageId, { data: {}, cleanups: new Set() })
  }

  function leave(pageId) {
    const p = pages.get(pageId)
    if (!p) return
    const fns = [...p.cleanups]
    p.cleanups.clear()                                       // 先清防重入
    fns.reverse().forEach((fn) => { try { fn() } catch (e) { report('cleanup_error', e) } })
    pages.delete(pageId)                                     // 数据随命名空间消失
  }

  return {
    enter,
    leave,
    set: (pageId, patch) => { const p = pages.get(pageId); if (p) Object.assign(p.data, patch) },
    get: (pageId) => pages.get(pageId)?.data,
    registerCleanup(pageId, fn) {
      const p = pages.get(pageId)
      if (!p) throw new Error('page not entered')
      p.cleanups.add(fn)
      return () => p.cleanups.delete(fn)                     // 支持取消注册
    },
    active: () => [...pages.keys()],
  }
}
```
**评分点**：
- LIFO 清理顺序（资源依赖正确：后注册的先清理）
- leave 幂等 + cleanup 集合先清防重入（清理钩子里再触发 leave 不死循环）
- enter 幂等重置（重复进入重置命名空间）
- cleanup 异常隔离（一个清理失败不影响其余）
