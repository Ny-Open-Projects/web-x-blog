## 474：笔试手写：实现基于 BroadcastChannel 的跨页签状态同步

**答**：实现 CrossTabStore(key, initial)：多页签打开同一页面时共享状态。基于 BroadcastChannel + localStorage 兜底（BroadcastChannel 不可用时降级）。API：get()、set(val)（广播给其他页签并写入本地）、onChange(fn)。要求：自己 set 触发的广播不回调自己的 onChange（去自环）；storage 事件兜底时过滤非本 key 的新值写入。

```js
class CrossTabStore {
  constructor(key, initial) {
    this.key = key; this.value = initial; this.fns = new Set();
    this.tabId = Math.random().toString(36).slice(2);   // 页签唯一 id 防自环
    if ('BroadcastChannel' in window) {
      this.ch = new BroadcastChannel('crosstab:' + key);
      this.ch.onmessage = e => this._apply(e.data, e.data.from);
    } else {
      this._onStorage = e => {
        if (e.key !== 'crosstab:' + this.key || !e.newValue) return;
        const msg = JSON.parse(e.newValue);
        if (msg.from === this.tabId) return;           // storage 事件本页也会触发
        this._apply(msg, msg.from);
      };
      window.addEventListener('storage', this._onStorage);
    }
  }
  _apply(msg) {
    if (msg.tabId === this.tabId) return;              // 防自环
    this.value = msg.val;
    this.fns.forEach(fn => fn(this.value));
  }
  get() { return this.value; }
  set(val) {
    this.value = val;
    const msg = { tabId: this.tabId, val };
    if (this.ch) this.ch.postMessage(msg);
    else localStorage.setItem('crosstab:' + this.key, JSON.stringify(msg));
  }
  onChange(fn) { this.fns.add(fn); return () => this.fns.delete(fn); }
}
```

**评分点**：
- tabId 去自环（两处都要防：channel 的消息与 storage 事件——storage 事件本页也触发）
- BroadcastChannel -> localStorage 降级分支完整
- onChange 返回退订函数
- 能讨论：多页签竞写冲突（last-write-win 的局限与 CRDT 进阶）、storage 事件的 e.newValue 语义
