## ZSM-401：手写请求合并去重器（时间窗内同参数合并）
**需求**：实现 `createBatcher(fn, { delay })`：1) `add(item)` 返回 Promise，等待批量结果；2) delay 窗口内收集 item，到期一次性 `fn(items)`（返回数组按输入顺序对应）；3) 同窗口重复 item 去重——重复调用共享同一结果 Promise；4) fn 抛错时所有等待者 reject 同一错误；5) 支持并发多批（前一批执行中新一收集成下一批）。

```javascript
export function createBatcher(fn, { delay = 50 } = {}) {
  let pending = []      // { item, resolve, reject }
  let timer = null

  function flush() {
    const batch = pending
    pending = []
    timer = null
    const items = batch.map((b) => b.item)
    fn(items).then(
      (results) => batch.forEach((b, i) => b.resolve(results[i])),   // 按顺序回填
      (err) => batch.forEach((b) => b.reject(err)),
    ).catch(() => {})
  }

  return {
    add(item) {
      const dup = pending.find((p) => Object.is(p.item, item))       // 同窗去重
      if (dup) return dup.promise ?? dup.resolve // dup 存 promise
      const p = new Promise((resolve, reject) => pending.push({ item, resolve, reject, promise: undefined }))
      pending[pending.length - 1].promise = p
      if (!timer) timer = setTimeout(flush, delay)
      return p
    },
    flushNow: flush,
  }
}
```
**评分点**：
- 窗口内去重必须返回同一 Promise（重复 item 不重复进批）
- fn 结果按输入顺序映射回各 add 的 resolve（错位即数据事故）
- 错误广播给整批等待者；flush 先清 pending 再执行（并发批次隔离）
- timer 管理：flush 后置 null 允许新批
