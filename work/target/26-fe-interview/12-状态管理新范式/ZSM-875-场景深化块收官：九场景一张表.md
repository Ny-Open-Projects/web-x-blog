## ZSM-875：场景深化块收官：九场景状态策略一张表

**答**：
- 第二轮场景深化（851-875）九场景的核心策略一行表（面试遇同类场景直接迁移）：
- 1) **大促页面（851）**：phase 派生 + 库存乐观 + 推送节流 + 幂等令牌 + 降级链。
- 2) **后台管理（853）**：URL 事实源 + 租户隔离 + 两层门禁 + 批量结果集。
- 3) **信息流（855）**：cursor 幂等 + 冻结排序窗口 + 互动分离 + 内存红线。
- 4) **多维表格（857）**：公式依赖图 + 多视图零拷贝投影 + schema 运行时可变。
- 5) **直播课堂（859）**：窗口状态机 + 心跳权威 + 弱网三层信道。
- 6) **地图（861）**：视口指纹 + 粒度切换 + 帧避让。
- 7) **播放器（863）**：指针锁 + 随机历史栈 + 状态最小化五字段。
- 8) **低代码画布（865）**：树归一化 + 循环防护 + 撤销 patch。
- 9) **协作白板/OJ/工单/问卷（867-874）**：op 压缩/LWW、判题幂等流式、SLA 启停、版本化回收。
- 通用提炼升级版：在五句式（700）之上加三条场景句式——**「凡媒体高频 → transient+里程碑」、凡限时 → phase 派生+时钟对齐、凡海量数据 → 抽稀/物化/红线」**——八句式覆盖全部已知业务形态。
