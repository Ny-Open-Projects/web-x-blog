## ZSM-819：手写面试叙事装配器（STAR 变体 + 数字锚点注入）
**答**：实现 `createStoryAssembler()`：1) `register(story)`：登记素材（背景/动作/结果/数字锚点）；2) `compose(topic, { maxSeconds })`：按语速（4 字/秒）预算字数，装配「情境 20% → 冲突 15% → 动作 45% → 结果 20%」结构，动作段优先插入带数字的素材；3) 数字锚点注入：结果段强制含 ≥2 个实测数字（无数字素材标记 gap）；4) 附用例：装配一段「状态性能优化」叙事并检查数字缺口。

```javascript
function createStoryAssembler({ speechRate = 4 } = {}) {
  const stories = new Map()

  function register(topic, story) {
    stories.set(topic, story)     // { situation, conflict, actions: [{ text, numbers }], results: [{ text, numbers }] }
    return this
  }

  function compose(topic, { maxSeconds = 90, requireNumbers = 2 } = {}) {
    const s = stories.get(topic)
    if (!s) throw new Error(`no story for ${topic}`)
    const budget = maxSeconds * speechRate          // 总字数预算

    // 结构比例：情境20% 冲突15% 动作45% 结果20%
    const parts = [
      { name: '情境', text: s.situation, ratio: 0.2 },
      { name: '冲突', text: s.conflict, ratio: 0.15 },
      { name: '动作', text: s.actions.map((a) => a.text).join('；'), ratio: 0.45 },
      { name: '结果', text: s.results.map((r) => r.text).join('；'), ratio: 0.2 },
    ]
    const segments = parts.map((p) => {
      const charBudget = Math.round(budget * p.ratio)
      const text = p.text.length > charBudget ? p.text.slice(0, charBudget) + '…' : p.text
      return { name: p.name, chars: charBudget, text, truncated: p.text.length > charBudget }
    })

    // 数字锚点检查：结果段强制 ≥2 个实测数字
    const resultNumbers = s.results.flatMap((r) => r.numbers ?? [])
    const gaps = []
    if (resultNumbers.length < requireNumbers) {
      gaps.push(`结果段数字锚点不足（${resultNumbers.length}/${requireNumbers}）——补实测数据`)
    }
    // 动作段优先带数字的素材排序检查
    const actionWithoutNumber = s.actions.filter((a) => !(a.numbers?.length)).length
    if (actionWithoutNumber > 0) gaps.push(`${actionWithoutNumber} 个动作素材缺数字`)

    return { topic, segments, numbersUsed: resultNumbers, gaps, fitsBudget: !segments.some((x) => x.truncated) }
  }

  return { register, compose }
}

// 用例
const asm = createStoryAssembler()
asm.register('状态性能优化', {
  situation: '购物车页 INP p75 达 280ms，用户反馈加购卡顿，影响 10 万 DAU 主路径',
  conflict: '团队最初想直接重写组件，但没有基线数据无法证明收益，且结算链路有回归风险',
  actions: [
    { text: '先建复现脚本与基线：Profiler 实测单次加购 87 次重渲', numbers: ['87次'] },
    { text: '分段归因发现渲染层主导，selector 放大系数 3.2', numbers: ['3.2'] },
    { text: '按决策树拆标量 selector + useShallow + 聚合批算', numbers: [] },
    { text: '复测 renders 87→23，blocking 310→46ms，INP 降至 140ms', numbers: ['23', '46ms', '140ms'] },
  ],
  results: [
    { text: 'INP p75 从 280ms 降到 140ms，加购转化率提升 0.3%', numbers: ['280→140ms', '+0.3%'] },
    { text: '性能门禁进 CI，连续三个月零劣化', numbers: ['3个月'] },
  ],
})

const story = asm.compose('状态性能优化', { maxSeconds: 90 })
console.log(story.segments.map((s) => `${s.name}(${s.chars}字)`))
console.log(story.numbersUsed.length)     // 6：数字锚点充足
console.log(story.gaps)                   // [ '1 个动作素材缺数字' ]
console.log(story.fitsBudget)             // true（90 秒内）
```
**评分点**：
- 语速预算字数（4 字/秒 × 秒数）+ 段落比例裁剪
- 数字锚点注入（结果段强制 ≥2 实测数字，缺口标记 gap）
- 动作段数字排序提示（无数字素材警告）
- 结构四段（情境/冲突/动作/结果）与 truncation 标记
