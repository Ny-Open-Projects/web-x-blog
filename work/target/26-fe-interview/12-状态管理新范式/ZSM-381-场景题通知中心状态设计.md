## ZSM-381：场景题示范：通知中心（未读/免打扰/批量已读）状态

**答**:
- 计数派生：未读数从「通知缓存 + lastRead 游标」派生（一条事实），禁止独立存计数器再手动加减——两处真相必漂移
- 分组与折叠：按类型/日期分组是渲染派生（不在数据层分组存储）；折叠展开是组件态
- 批量已读：乐观标记（选中项立即灰）→ 批量提交 → 服务端确认后失效重拉校准；失败回滚并提示
- 实时接入：新通知推送 → 缓存 upsert（幂等）+ 未读游标推进；免打扰类型不触发角标但保留列表（规则集中一处可测）

```javascript
const { data: notices } = useQuery({ queryKey: ['notices'], queryFn: fetchNotices })
const lastRead = useStore((s) => s.lastReadAt)
const unreadCount = useMemo(() =>
  notices?.filter((n) => n.at > lastRead && !n.muted).length ?? 0, [notices, lastRead])
// 批量已读：乐观 → 提交 → 校准
const markAll = async () => {
  const prev = lastRead
  setLastRead(Date.now())
  try { await api.markAllRead() } catch { setLastRead(prev) }
}
```
