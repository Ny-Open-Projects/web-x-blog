## ZSM-878：状态工程的一页纸终版架构图（口述画法终稿）

**答**:
- 把 900 张卡浓缩成一页纸架构图（面试白板的终版模板，四区十二件）：
- **区 A 数据层**（左上）：RSC 直读 → TanStack 缓存（staleTime/gcTime 标注）→ Zustand 会话态小 store 群（registry 分层标注）。
- **区 B 流程层**（右上）：XState actor（invoke/after/actor 引用）——与 A 区用「事件 send」连接。
- **区 C 同步层**（下方横条）：WS 信封（seq/ack）→ hold-back buffer → 追平三策略 → leader 聚合——标注「幂等键/版本裁决」两个横切概念。
- **区 D 治理层**（右侧竖条）：探针→时间线→门禁→告警分级→健康分——标注「ADR/技术债」。
- 画图口诀：先四区框 → 再数据流箭头（单向）→ 标注横切概念 → 红笔圈三个故障点（断线追平/乐观回滚/熔断降级）——每区一句话讲透，全图 3 分钟讲完。
- 图的「三问自检」：面试官可能问的三个问题——「为什么缓存和会话态分开？」（失效语义 vs UI 语义）「XState 为什么独立？」（生命周期绑定）「治理层为什么是竖条？」（横切所有层）——每区都备一句「存在理由」。
- 追问钩子：一页纸图的「演进标注」——图上标三个箭头方向标（v1→v2 演进：全局 store→联邦、轮询→WS、无门禁→门禁），体现架构是演进出来的不是设计出来的。
