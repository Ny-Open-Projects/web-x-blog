## ZSM-421：手写派生缓存层（依赖失效 + 结果复用）
**答**：实现 `createComputed(store, depsFn, compute)`：1) depsFn(state) 返回依赖值数组；2) 缓存上次依赖与上次结果——依赖浅相等直接返回缓存结果（不重算）；3) 依赖变化重算，重算结果与上次深相等时仍返回旧引用（引用稳定）；4) `get()` 是唯一入口；5) store 订阅自动清缓存（失效），下次 get 惰性重算。

```javascript
function shallowArr(a, b) {
  return a.length === b.length && a.every((v, i) => Object.is(v, b[i]))
}

export function createComputed(store, depsFn, compute) {
  let cache = null                    // { deps, result }
  let dirty = true
  const unsub = store.subscribe(() => { dirty = true })   // 失效即标脏

  function get() {
    if (!dirty && cache) return cache.result          // 未失效直接复用
    const deps = depsFn(store.getState())
    if (cache && shallowArr(deps, cache.deps)) {      // 依赖没变（无效通知防御）
      dirty = false
      return cache.result
    }
    const result = compute(...deps)
    // 结果引用稳定：深相等复用旧引用
    if (cache && JSON.stringify(result) === JSON.stringify(cache.result)) {
      cache = { deps, result: cache.result }
    } else cache = { deps, result }
    dirty = false
    return cache.result
  }

  return { get, dispose: unsub }
}

// 用法
const totals = createComputed(cartStore,
  (s) => [s.items, s.taxRate],
  (items, rate) => items.reduce((s, i) => s + i.priceCents * rate, 0))
```
**评分点**：
- 双层短路：未失效直接返回 + 依赖浅比较防无效通知重算
- 结果引用稳定（深相等复用旧引用），下游订阅不抖动
- 惰性重算（订阅只标脏，get 时才算），失效即清缓存的语义正确
- dispose 提供退订（测试与热卸载防泄漏）
