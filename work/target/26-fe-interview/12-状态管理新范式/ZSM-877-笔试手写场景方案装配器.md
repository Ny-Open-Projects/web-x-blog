## ZSM-877：手写场景方案装配器（特征→概念→方案三步）
**答**：876 落地——实现 `assembleDesign(scenario)`：1) 输入场景特征集合（{ realtime, offline, conflict, undo, timeLimited, concurrentWrite }）；2) 按 CONCEPT_MATRIX 映射概念清单 + 生成方案段落（每概念一段：机制一句话 + 关键取舍）；3) 误用检查：场景特征与概念 misuse 信号冲突时剔除并说明；4) 附用例：IM 场景装配与误用剔除。

```javascript
const MATRIX = {
  对账器: { essence: '本地乐观+服务端权威', need: 'concurrentWrite', misuse: (f) => f.readOnly },
  seq协议: { essence: '多端实时流', need: 'realtime', misuse: (f) => !f.realtime },
  幂等键: { essence: '写操作重试', need: 'writes', misuse: () => false },
  命令栈: { essence: '可撤销编辑', need: 'undo', misuse: (f) => !f.undo },
  phase派生: { essence: '限时窗口', need: 'timeLimited', misuse: (f) => !f.timeLimited },
  版本裁决: { essence: '并发写', need: 'concurrentWrite', misuse: (f) => f.singleWriter },
  holdback: { essence: '乱序序号流', need: 'realtime', misuse: (f) => f.orderedChannel },
}

function assembleDesign(scenario, { timeLimit = 90 } = {}) {
  const concepts = []
  for (const [name, m] of Object.entries(MATRIX)) {
    const needed = scenario[m.need]
    if (!needed) continue
    if (m.misuse?.(scenario)) {
      concepts.push({ name, excluded: true, reason: `误用信号命中：场景不满足 ${m.need} 的前提` })
      continue
    }
    concepts.push({
      name,
      segment: `${m.essence}：用「${name}」机制承载（含关键取舍：过期数据/幂等窗口/压缩容差按场景配置）`,
    })
  }
  const used = concepts.filter((c) => !c.excluded)
  // 按时间预算分配段时长
  const per = Math.floor((timeLimit * 0.6) / Math.max(1, used.length))   // 60% 时间给方案段
  return {
    scenario,
    concepts,
    plan: used.map((c) => ({ concept: c.name, seconds: per, segment: c.segment })),
    clarity: `${timeLimit * 0.15}s 澄清 + ${timeLimit * 0.6}s 方案（${used.length} 概念）+ ${timeLimit * 0.25}s 闭环`,
  }
}

// 用例：IM 场景
const im = assembleDesign({
  realtime: true, offline: true, conflict: true,
  undo: false, timeLimited: false, concurrentWrite: true, writes: true,
  readOnly: false, singleWriter: false, orderedChannel: false,
})
console.log(im.concepts.filter((c) => c.excluded))
// [{ name: '命令栈', excluded: true, reason: '误用信号命中...' }]（IM 无撤销编辑）
console.log(im.plan.map((p) => `${p.concept}(${p.seconds}s)`))
// ['对账器(18s)', 'seq协议(18s)', '幂等键(18s)', '版本裁决(18s)']

// 误用剔除验证：有序通道场景剔除 holdback
const ordered = assembleDesign({ realtime: true, writes: true, orderedChannel: true, concurrentWrite: false })
console.log(ordered.concepts.find((c) => c.name === 'holdback')?.excluded)   // true
```
**评分点**：
- 特征→概念映射（need 匹配 + misuse 剔除并说明）
- 时间预算分配（60% 方案段均分 + 15/25 澄清闭环）
- 误用信号防过度设计（excluded 带理由）
- 段落生成含关键取舍提示
