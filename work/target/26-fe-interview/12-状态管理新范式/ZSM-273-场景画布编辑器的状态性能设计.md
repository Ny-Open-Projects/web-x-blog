## ZSM-273：白板/画布编辑器（千级节点）的状态设计怎么做

**答**:
- 数据形态：节点/连线归一化存储（Map<id, node> + 邻接表），渲染层派生（zIndex、可见性按视口裁剪），数据与视图严格分离
- 高频交互（拖拽）走「影子路径」：拖拽期间改轻量临时态（渲染跟随），mouseup 才 commit 进 store——避免每帧全量通知
- 订阅粒度：节点组件只订阅自身 id 的原子（Jotai atomFamily）或 selector，单节点移动不触发全画布重渲染
- 历史栈：操作级（创建/删除/移动 commit）进 undo 栈，帧级移动不进；快照用结构共享

```javascript
const nodeAtom = atomFamily((id) => atom((g) => g(nodesMapAtom).get(id)))
function Node({ id }) {
  const node = useAtomValue(nodeAtom(id))       // 精准订阅单节点
  return <rect x={node.x} y={node.y} />
}
// 拖拽：rAF 内只更新本地 transform；commit 时 store.set({ id, x, y })
```
