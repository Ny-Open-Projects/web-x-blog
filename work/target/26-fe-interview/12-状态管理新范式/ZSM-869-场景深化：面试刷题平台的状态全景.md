## ZSM-869：场景深化：在线编程判题（OJ）的状态全景（代码+执行+判题）

**答**：
- OJ（LeetCode 类）的状态特征是「编辑器态 + 异步判题 + 竞赛计时」，四域：
- 1) **代码域**：编辑器内容（Monaco 自管 undo）+ 草稿持久化（ZSM-529 脏检查+自动保存 + 乐观锁 If-Match）+ 语言切换的代码快照（每种语言独立草稿）。
- 2) **执行域**：提交状态机（idle→running→judging→accepted/wrong/tle）+ SSE 流式测试结果（ZSM-735 流式接收：逐用例结果推送）+ 取消（running 中取消 = AbortController + 服务端终止）。
- 3) **计时域**：竞赛倒计时（687 phase 派生）+ 本地计时与服务端对齐（时钟偏移）。
- 4) **结果域**：历史提交列表（分页）+ 失败用例 diff 展示（期望 vs 实际，独立于代码状态）。
- OJ 特有「判题幂等」：同一代码重复提交（双击/重试）——幂等键 + 服务端判题去重（相同 hash 短窗口返回上次结果）；判题结果的「流式与终局」两阶段（逐用例 SSE + 最终 verdict 确认）。
- 追问钩子：OJ 的「编辑器状态最小化」——Monaco 自己管理 undo/光标（ZSM-692 编辑器三层铁律），store 只镜像「需要跨组件的投影」（语言选择/提交状态/测试结果）。

```javascript
// OJ 状态全景
const OJ_STATE_MAP = {
  代码域: {
    core: 'Monaco 自管 undo（692 三层铁律）；store 只镜像跨组件投影',
    detail: '草稿脏检查+自动保存+If-Match（529）；多语言独立快照',
  },
  执行域: {
    core: '提交状态机 idle→running→judging→verdict + SSE 逐用例流式（735）',
    detail: '取消 = AbortController + 服务端终止',
  },
  计时域: {
    core: '竞赛倒计时 phase 派生（687）+ 时钟偏移对齐（686）',
  },
  结果域: {
    core: '历史提交分页 + 用例 diff 展示（独立于代码状态）',
  },
  判题幂等: '幂等键 + 相同代码 hash 短窗口去重（返回上次结果）',
  两阶段: '逐用例 SSE（流式）+ 最终 verdict（终局确认）',
}
```
