## ZSM-376：场景题示范：多步骤向导（分步表单）状态机设计

**答**:
- 流程建模为 FSM：步骤是状态、前进/后退/跳转是事件；「跳过可选步」「条件分支步骤」（A 用户走 1→2→4）在转移表里表达，避免布尔标志组合
- 数据策略：各步表单局部态自持，完成时提交进向导 store；已完成的步只读回看，修改触发「后续步骤重算/重置」（依赖级联）
- 恢复语义：当前步 + 已完成数据持久化（草稿），刷新后重建 FSM 到同一步
- 校验门控：前进条件 = 本步校验通过 + 依赖步骤有效；依赖步骤失效时锁定后续步并提示

```javascript
const wizard = createMachine({
  initial: 'step1',
  states: {
    step1: { on: { NEXT: 'step2', SKIP: 'step3' } },
    step2: { on: { NEXT: 'step3', BACK: 'step1' } },
    step3: { on: { SUBMIT: 'done', BACK: 'step2' } },
    done: { type: 'final' },
  },
})
// 依赖重置：修改 step1 数据 → step2 数据失效
onStep1Change: () => wizardStore.resetFrom('step2')
```
