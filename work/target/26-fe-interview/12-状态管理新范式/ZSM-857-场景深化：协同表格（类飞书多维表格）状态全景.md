## ZSM-857：场景深化：协同表格（类多维表格）的状态全景（行级协同+多视图）

**答**：
- 多维表格（飞书/Airtable 类）的状态全景，「行级协同 + 多视图 + 字段类型系统」三特性：
- 1) **数据域**：行级 CRDT/LWW（685 块级方案）+ 归一化 records/fields（535）+ 类型系统（每个 field 有 type + 配置，校验/格式化按 type 派生）。
- 2) **视图域**：多视图（表格/看板/甘特）= 同一数据的**不同投影**——视图配置（筛选/分组/排序）独立存储，视图切换零数据拷贝（派生重算）；「看板视图」= 按 select 字段分组的投影（ZSM-684 双结构的视图化）。
- 3) **协同域**：行编辑锁（744 租约）+ 单元格级光标 presence（694）+ 冲突裁决。
- 4) **性能域**：万行渲染（753 三层切片）+ 字段列虚拟化（横向也虚拟）+ 聚合行批算。
- 多维表格特有的「公式字段」：字段间引用形成依赖图（ZSM-682 表单联动同构）——公式循环引用检测 + 拓扑序求值；公式列的重算是写时算的典型场景（读多写少）。
- 追问钩子：多维表格 vs 普通后台表格的本质差异——「schema 是运行时可变的」（用户加字段/改类型）→ schema 版本化 + 值层迁移（ZSM-812 低代码建模的加强版）。
