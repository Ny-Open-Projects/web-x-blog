## 1113：笔试手写：实现 数据新鲜度徽章计算器

**答**：实现 freshnessBadge(fetchedAt, now)：输出 { label, level, color }。level 按年龄分级：<1min 'fresh'；<5min 'ok'；<30min 'stale'；否则 'cold'。label 为人类可读相对时间（'刚刚'/'3 分钟前'/'12 分钟前'，小时/天同理）；color 按级别映射绿/黄/橙/灰。处理未来时间（时钟偏移）按 fresh 处理。

```js
function freshnessBadge(fetchedAt, now = Date.now()) {
  const age = Math.max(0, now - fetchedAt); // 未来时间钳制为 0（时钟偏移兜底）
  const MIN = 60000;
  const rel = age < MIN ? '刚刚'
    : age < 60 * MIN ? `${Math.floor(age / MIN)} 分钟前`
    : age < 24 * 60 * MIN ? `${Math.floor(age / (60 * MIN))} 小时前`
    : `${Math.floor(age / (24 * 60 * MIN))} 天前`;
  const level = age < MIN ? 'fresh' : age < 5 * MIN ? 'ok'
    : age < 30 * MIN ? 'stale' : 'cold';
  const color = { fresh: 'green', ok: 'yellow', stale: 'orange', cold: 'gray' }[level];
  return { label: rel, level, color, ageMs: age };
}
```

**评分点**：
- 未来时间钳制（服务器时钟偏移的防御）
- 分级阈值与色阶映射表驱动
- 相对时间多级格式化
- 能讨论：徽章是「数据可信度」的低成本沟通——配合 stale-while-revalidate 的用户教育
