## ZSM-411：手写失效风暴熔断器
**答**：实现 `createInvalidateGuard({ limit, windowMs, cooldownMs })`：1) `invalidate(fn)` 包裹失效操作：滑动窗口内调用次数超 limit 则「熔断」；2) 熔断期内的失效调用改为「合并挂起」——cooldown 结束后执行一次全量失效（fn('ALL')）代替逐条；3) 窗口内正常调用直接执行；4) `state()` 返回 { calls, open, until }；5) 恢复后计数清零。

```javascript
export function createInvalidateGuard({ limit = 20, windowMs = 1000, cooldownMs = 5000 }) {
  const calls = []                 // 滑动窗口时间戳
  let openUntil = 0
  let pendingAll = null

  function invalidate(fn, scope) {
    const now = Date.now()
    if (now < openUntil) {                       // 熔断中：合并挂起
      pendingAll ??= setTimeout(() => {
        openUntil = 0; calls.length = 0          // 恢复清零
        fn('ALL')                                // 全量失效一次
        pendingAll = null
      }, openUntil - now)
      return { merged: true }
    }
    while (calls.length && now - calls[0] > windowMs) calls.shift()
    if (calls.length >= limit) {                 // 触发熔断
      openUntil = now + cooldownMs
      return invalidate(fn, scope)               // 本调用也进合并
    }
    calls.push(now)
    fn(scope)
    return { merged: false }
  }

  return { invalidate, state: () => ({ calls: calls.length, open: Date.now() < openUntil, until: openUntil }) }
}
```
**评分点**：
- 滑动窗口计数（过期时间戳出窗）而非固定桶
- 熔断语义：逐条失效改为 cooldown 后单次全量失效（合并挂起只挂一个 timer）
- 恢复时清空窗口计数（避免恢复后立即再熔断）
- state() 可观测（运维可查 open/until），挂起 timer 幂等（??= 保证一个）
