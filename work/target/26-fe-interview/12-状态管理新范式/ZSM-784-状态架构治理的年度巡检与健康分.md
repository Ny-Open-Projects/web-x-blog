## ZSM-784：状态架构的健康分：季度巡检的十项指标与评分

**答**：
- 状态架构健康分（季度巡检，十项加权）：1) **跨层违规数**（ZSM-776 lint，0 分满）；2) **store 注册率**（registry 覆盖比）；3) **ADR 覆盖率**（新 store 有决策记录比）；4) **竞态测试覆盖**（审计八问对应的用例存在比）；5) **性能门禁通过率**（CI BudgetGate）；6) **内存趋势**（heap 增长斜率）；7) **告警 runbook 完备度**（P0/P1 告警有 runbook 比）；8) **依赖图健康**（循环依赖数）；9) **persist migrate 完备性**（版本链无断档）；10) **降级链可用性**（WS→SSE→轮询演练通过）。
- 评分模型：每项 0-10 分加权（P0 相关权重高：竞态覆盖、跨层违规权重 2x），总分映射等级 A（≥85）/B（70-85）/C（<70，限期整改）。健康分的价值是把「架构好不好」从主观争论变成可追踪数字。
- 巡检执行：自动化部分（lint/CI/依赖图）脚本产出；人工部分（runbook 完备度/演练）季度走查会记录。巡检报告进 ADR（健康分历史曲线）。
- 整改闭环：C 级项生成「整改工单」限期（两周）+ 负责人，逾期升级到技术负责人——巡检不是打分表演，是治理驱动。
- 追问钩子：健康分的反博弈——指标不能只选「容易刷的」（注册率凑数），要混入「难以造假的实证指标」（竞态测试覆盖率靠真实用例、演练靠现场执行）。

```javascript
// 健康分计算器
const HEALTH_METRICS = [
  { key: 'crossLayerViolations', weight: 2, score: (n) => n === 0 ? 10 : Math.max(0, 10 - n * 2) },
  { key: 'registryCoverage',     weight: 1, score: (r) => Math.round(r * 10) },
  { key: 'adrCoverage',          weight: 1, score: (r) => Math.round(r * 10) },
  { key: 'concurrencyTestCoverage', weight: 2, score: (r) => Math.round(r * 10) },
  { key: 'ciGatePassRate',       weight: 1, score: (r) => Math.round(r * 10) },
  { key: 'heapGrowthSlope',      weight: 1, score: (mbPerDay) => mbPerDay < 0.5 ? 10 : Math.max(0, 10 - mbPerDay * 4) },
  { key: 'runbookCompleteness',  weight: 1, score: (r) => Math.round(r * 10) },
  { key: 'circularDeps',         weight: 1, score: (n) => n === 0 ? 10 : Math.max(0, 10 - n * 3) },
  { key: 'migrateChainIntegrity',weight: 1, score: (ok) => ok ? 10 : 0 },
  { key: 'fallbackDrillPass',    weight: 1, score: (ok) => ok ? 10 : 0 },
]

function computeHealthScore(metrics) {
  const totalWeight = HEALTH_METRICS.reduce((a, m) => a + m.weight, 0)
  const earned = HEALTH_METRICS.reduce((a, m) => a + m.weight * m.score(metrics[m.key]), 0)
  const total = +(earned / totalWeight * 10).toFixed(1)   // 0~100
  const grade = total >= 85 ? 'A' : total >= 70 ? 'B' : 'C'
  return { total, grade, deadline: grade === 'C' ? '两周整改' : null }
}

// 示例
console.log(computeHealthScore({
  crossLayerViolations: 1, registryCoverage: 0.9, adrCoverage: 0.8,
  concurrencyTestCoverage: 0.7, ciGatePassRate: 0.95, heapGrowthSlope: 0.3,
  runbookCompleteness: 1, circularDeps: 0, migrateChainIntegrity: true, fallbackDrillPass: true,
}))
// { total: 87.3, grade: 'A', deadline: null }
```
