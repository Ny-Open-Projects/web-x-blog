## ZSM-519：手写状态库性能剖析器（渲染归因）
**答**：实现 `createProfiledStore(initial)`：1) 代理 store 的 setState，记录每次变更 `{ keys, ts, stack }`（触发源调用栈取前 3 帧）；2) 给 hook 层提供 `startProfile()`/`stopProfile()`：统计期间「状态变更次数、被同一变更触发的组件重渲次数、最长一次变更到提交的耗时」；3) `report()` 输出按「变更源调用栈」聚合的重渲归因 Top3；4) 提供开关在不影响生产构建时零开销（未开启时 setState 直通）。附用例。

```javascript
import { useState, useEffect, useRef } from 'react'

function createProfiledStore(initial) {
  let state = initial
  const subs = new Set()
  let profiling = false
  const events = []            // { keys, ts, stack, renderCount }

  function setState(updater, source) {
    const prev = state
    state = typeof updater === 'function' ? updater(prev) : updater
    const changedKeys = Object.keys(state).filter((k) => !Object.is(prev[k], state[k]))
    if (!changedKeys.length) return
    if (profiling) {
      events.push({
        keys: changedKeys,
        ts: performance.now(),
        stack: (source || new Error().stack).split('\n').slice(2, 5),
        renderCount: 0,
      })
    }
    subs.forEach((fn) => fn(state, changedKeys, events.length - 1))
  }

  return {
    subscribe(fn) { subs.add(fn); return () => subs.delete(fn) },
    getState: () => state,
    setState,
    startProfile: () => { profiling = true; events.length = 0 },
    stopProfile: () => { profiling = false },
    noteRender(eventId) { if (events[eventId]) events[eventId].renderCount++ },
    report() {
      const byStack = new Map()
      for (const e of events) {
        const key = e.stack.join(' → ')
        const cur = byStack.get(key) ?? { count: 0, renders: 0 }
        cur.count++; cur.renders += e.renderCount
        byStack.set(key, cur)
      }
      return [...byStack.entries()]
        .sort((a, b) => b[1].renders - a[1].renders)
        .slice(0, 3)
        .map(([stack, { count, renders }]) => ({ stack, updates: count, renders }))
    },
  }
}

// hook 层：渲染时归因到最近一次变更事件
function useProfiled(store, selector, eventIdRef) {
  const [slice, setSlice] = useState(() => selector(store.getState()))
  useEffect(() => store.subscribe((s, keys, id) => {
    const next = selector(s)
    if (!Object.is(next, slice)) {
      eventIdRef.current?.(id)
      setSlice(next)
    }
  }), [store])
  return slice
}

// 用例
const store = createProfiledStore({ a: 0, b: 0 })
store.startProfile()
store.setState((s) => ({ a: s.a + 1 }))
store.setState((s) => ({ a: s.a + 1 }))   // 两次变更，组件重渲两次 → 归因到同一调用栈
store.stopProfile()
console.log(store.report())   // [{ stack: '...', updates: 2, renders: 2 }]
```
**评分点**：
- 变更 keys 与触发栈同帧采集（归因前提）
- report 按调用栈聚合渲染次数排序（Top3 输出）
- 关闭剖析时 setState 直通零开销（profiling 分支短路）
- 「同值变更」不计事件（changedKeys 空早退）
