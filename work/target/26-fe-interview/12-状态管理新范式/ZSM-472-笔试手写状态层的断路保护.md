## ZSM-472：手写状态层断路保护
**需求**：实现 `createCircuitBreaker(wrapFn, { threshold, cooldownMs })`：1) 状态机：closed（正常）→ open（连续 threshold 次失败）→ half-open（冷却后试一次）；2) open 期间直接 reject 'circuit-open'（不执行底层函数，快速失败）；3) half-open 试探成功 → closed 重置计数；失败 → 回 open 重新冷却；4) 成功会重置连续失败计数；5) `state()` 可观测 { state, failures, nextRetryAt }；6) onStateChange 可订阅（驱动 UI 提示「服务暂不可用」）。

```javascript
export function createCircuitBreaker(fn, { threshold = 5, cooldownMs = 30_000 } = {}) {
  let state = 'closed', failures = 0, nextRetryAt = 0
  const listeners = new Set()

  function setState(s) {
    if (state === s) return
    state = s
    listeners.forEach((fn) => fn({ state, failures, nextRetryAt }))
  }

  return {
    async call(...args) {
      if (state === 'open') {
        if (Date.now() < nextRetryAt)
          throw new Error('circuit-open')                    // 快速失败
        setState('half-open')                                // 冷却结束试探
      }
      try {
        const r = await fn(...args)
        failures = 0
        setState('closed')                                   // 成功重置
        return r
      } catch (e) {
        failures++
        if (state === 'half-open' || failures >= threshold) {
          nextRetryAt = Date.now() + cooldownMs
          setState('open')
        }
        throw e
      }
    },
    state: () => ({ state, failures, nextRetryAt }),
    onStateChange: (fn) => (listeners.add(fn), () => listeners.delete(fn)),
  }
}
```
**评分点**：
- 三态状态机转移完整（closed→open→half-open→closed/open）
- open 快速失败（不执行底层，保护下游与用户时间）；half-open 单次试探语义
- 成功重置计数；失败计数达阈值或 half-open 失败回 open 重新冷却
- onStateChange 驱动 UI（降级提示）+ state 可观测
