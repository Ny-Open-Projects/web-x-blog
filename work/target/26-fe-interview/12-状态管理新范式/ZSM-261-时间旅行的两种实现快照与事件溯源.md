## ZSM-261：时间旅行有哪两种实现思路（快照法与事件溯源法）

**答**:
- 快照法：每次变更存完整/结构共享的 state 快照，回退=恢复历史快照；实现简单，内存随快照数线性增长，靠结构共享（immer/immutable）压内存
- 事件溯源法：存的是 action/patch 流（undo 时存 patch，redo 存 inverse patch），回放=replay 动作；内存极小，但要保证 action 纯函数可重放
- 选择：低频大对象（文档）用事件溯源 patch 流；高频小状态（画布节点拖拽）用节流快照
- 两者都要处理边界：无界撤销栈截断（上限 N 步）、跨页签/网络写入不可撤销、时间旅行时副作用（请求）必须跳过

```javascript
// patch 流 undo/redo 核心
function makeHistory(apply, applyInverse) {
  const undoStack = [], redoStack = []
  return {
    do: (action) => { apply(action); undoStack.push(action); redoStack.length = 0 },
    undo: () => { const a = undoStack.pop(); if (a) { applyInverse(a); redoStack.push(a) } },
    redo: () => { const a = redoStack.pop(); if (a) { apply(a); undoStack.push(a) } },
  }
}
```
