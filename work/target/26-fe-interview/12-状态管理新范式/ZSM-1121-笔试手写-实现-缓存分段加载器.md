## 1121：笔试手写：实现 缓存分段加载器

**答**：十万行列表不整缓存。实现 createSlicedCache(loader, { slice })：get(range) 只取 [start, end) 段；段内命中（已缓存且完整）直接返回；部分命中时只补缺的子段；缓存记录已加载区间集合（合并相邻区间）。提供 loaded() 查看已加载区间，invalidate() 清空。

```js
function createSlicedCache(loader, { slice = 100 } = {}) {
  const data = new Map(); // index -> item
  let ranges = []; // 已加载 [start,end) 区间
  const merge = () => {
    ranges.sort((a, b) => a[0] - b[0]);
    const out = [];
    for (const r of ranges) {
      if (out.length && r[0] <= out.at(-1)[1]) out.at(-1)[1] = Math.max(out.at(-1)[1], r[1]);
      else out.push([...r]); // 相邻合并
    }
    ranges = out;
  };
  const has = (s, e) => ranges.some(([a, b]) => a <= s && e <= b);
  return {
    async get(start, end) {
      if (has(start, end)) return Array.from({ length: end - start }, (_, i) => data.get(start + i));
      // 补缺子段：与已加载区间求差集，按 slice 对齐
      const missing = [];
      for (let i = start; i < end; i += slice) {
        const s = i, e = Math.min(i + slice, end);
        if (!has(s, e)) missing.push([s, e]);
      }
      for (const [s, e] of missing) {
        const items = await loader(s, e);
        items.forEach((it, i) => data.set(s + i, it));
        ranges.push([s, e]); merge();
      }
      return Array.from({ length: end - start }, (_, i) => data.get(start + i));
    },
    loaded: () => ranges.map(([a, b]) => `${a}-${b}`).join(','),
    invalidate: () => { data.clear(); ranges = []; },
  };
}
```

**评分点**：
- 区间集合与合并算法（区间管理是分段缓存的核心）
- has 判完整覆盖才免请求（部分命中要补缺）
- 缺段按 slice 对齐（请求粒度可控）
- 能讨论：与窗口化虚拟列表的配合——只渲染 + 只缓存可见段
