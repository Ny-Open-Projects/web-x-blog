## 452：笔试手写：实现组件级脏检查与渲染调度（批处理）

**答**：实现 createReactive(store)：返回 { subscribe(key, fn), set(key, val) }。set 时：值浅比较不同才标记 key 为脏；同一微任务内的多次 set 合并（批处理），微任务统一通知订阅了脏 key 的 fn。值未变化不通知。要求不产生悬挂定时器（用 queueMicrotask）。

```js
function createReactive(store) {
  const subs = new Map();          // key -> Set<fn>
  let dirty = new Set(), flushing = false;
  function flush() {
    flushing = false;
    const keys = dirty; dirty = new Set();
    for (const k of keys) {
      for (const fn of subs.get(k) || []) fn(store[k]);
    }
  }
  function schedule() {
    if (!flushing) { flushing = true; queueMicrotask(flush); }  // 批处理合并
  }
  return {
    subscribe(key, fn) {
      if (!subs.has(key)) subs.set(key, new Set());
      subs.get(key).add(fn);
      return () => subs.get(key).delete(fn);      // 退订防泄漏
    },
    set(key, val) {
      if (store[key] === val) return;             // 浅比较，值相同不标脏
      store[key] = val;
      dirty.add(key);
      schedule();
    },
  };
}
const r = createReactive({ count: 0 });
r.subscribe('count', v => console.log('render', v));
r.set('count', 1); r.set('count', 2); r.set('count', 2); r.set('count', 3);
// 微任务统一：只 render 3（1/2 被合并，重复 2 被浅比较过滤）
```

**评分点**：
- 批处理：微任务合并同一 tick 的多次 set（flushing 标志防重复调度）
- 浅比较在 set 时过滤（同值不标脏）
- dirty 集合在 flush 时换新（防 flush 中的 set 丢失）
- 返回退订函数（防订阅泄漏）；queueMicrotask 无定时器泄漏
