## ZSM-400：场景题示范：电商工作台（微前端多模块）状态总设计

**答**:
- 三层收束：平台层（用户/租户/主题/权限，主应用单点下发 vanilla store）、共享业务层（商品/订单上下文，事件总线 + 失效广播协议）、模块私有层（各子应用自持 store/Query）
- 跨模块协同：订单模块改价 → 广播 invalidate → 商品模块相关缓存失效；不做「跨模块直接写对方 store」
- 一致性保障：URL 承载跨模块上下文（当前店铺/租户），挂载时从 URL 初始化——子应用独立部署/刷新都能对齐
- 收官要点：本答案覆盖 251~399 全部机制（单点用户态/契约版本化/失效广播/URL 真相源/订阅泄漏防护），面试按「层→机制→验收」组织即可

```javascript
// 工作台总装
platform.provide({ user, tenant, theme, perms })        // 平台层单点下发
bus.protocol({ 'cache:invalidate', 'theme:changed', 'auth:invalid' })   // 协议化广播
registerApp('order', { props: { request: authedFetch, shared, bus } })
registerApp('product', { props: { shared, bus } })      // 各模块私有状态自持
```
