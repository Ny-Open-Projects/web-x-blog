## ZSM-475：手写跨包状态单例注册表
**需求**：实现 `createStoreRegistry()`：解决「多包各自创建同名 store 导致状态分裂」：1) `register(name, factory)`：注册 store 工厂（名字冲突抛错——除非同 identity 校验通过）；2) `get(name)`：惰性创建（首次 get 才实例化），后续返回同一实例；3) `identityOf(name)`：factory 暴露 identity 字符串（包版本+实现指纹）——同名不同 identity 拒绝注册（双包检测）；4) `resetAll()`：测试用（全部销毁重建）；5) `instances()` 列出已实例化单例（内存审计）。

```javascript
export function createStoreRegistry() {
  const factories = new Map()   // name → { factory, identity }
  const instances = new Map()   // name → instance

  function register(name, factory) {
    const identity = factory.identity ?? 'unknown'
    const existing = factories.get(name)
    if (existing && existing.identity !== identity)
      throw new Error(`store ${name} 双包冲突: ${existing.identity} vs ${identity}`)   // 双包检测
    factories.set(name, { factory, identity })
  }

  function get(name) {
    if (instances.has(name)) return instances.get(name)
    const f = factories.get(name)
    if (!f) throw new Error(`store ${name} not registered`)
    const inst = f.factory()
    instances.set(name, inst)
    return inst
  }

  return {
    register, get,
    identityOf: (name) => factories.get(name)?.identity,
    resetAll: () => { instances.forEach((i) => i.__reset?.()); instances.clear() },
    instances: () => [...instances.keys()],
  }
}

// store 包侧：factory 带 identity
const factory = Object.assign(() => createStore(init), { identity: 'cart@2.1.0#abc123' })
registry.register('cart', factory)
```
**评分点**：
- 惰性单例（首次 get 创建，跨包共享同一实例）
- identity 指纹双包检测（同名不同版本/实现的冲突在注册期暴露——bundle 复制问题的根治）
- resetAll 测试隔离（实例销毁钩子可选）
- instances 内存审计（哪些单例已激活）
