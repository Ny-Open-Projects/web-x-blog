## ZSM-284：派生值放 store 还是 useMemo 还是 select 怎么判断

**答**:
- 三问决策：被多个组件/页面用吗？要跨渲染缓存吗？要参与失效链吗？——多消费者 → store 层派生（atom computed/selector）；单组件 → useMemo；服务端数据的裁剪变换 → Query 的 select
- store 层派生的优势：缓存随数据生命周期（不受组件卸载影响）、统一失效；useMemo 的优势：作用域最小、随组件销毁不占内存
- 反模式：把昂贵派生放渲染期函数体（每次渲染全算）；或把一次性派生塞进 store 占内存
- 结果稳定性：store 派生要返回稳定引用（结构共享/常量空数组），否则下游订阅全炸

```javascript
// 服务端数据裁剪 → select
const { data: names } = useQuery({ queryKey: ['users'], queryFn: fetchUsers,
  select: (d) => d.map((u) => u.name) })
// 跨组件派生 → store 层
const totalAtom = atom((g) => g(itemsAtom).reduce((s, i) => s + i.price, 0))
// 组件内一次性 → useMemo
const grouped = useMemo(() => group(items), [items])
```
