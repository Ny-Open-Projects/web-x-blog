## ZSM-458：手写状态时钟对齐器
**需求**：实现 `createAlignedClock()`：1) `sync(serverTime)`：用服务端时间计算 offset（多轮采样取中位数防抖动）；2) `now()` 返回对齐后的当前时间（serverTime + 本地流逝）；3) 本地钟跳变（NTP 校时/用户改时间）免疫：基于 performance.now 单调流逝量计算；4) `drift()` 返回当前本地钟与对齐钟的偏移（可观测）；5) sync 需要考虑网络延迟（round-trip 一半计入）；6) 未 sync 时 now() 退化为本地时间并标记 unsynced。

```javascript
export function createAlignedClock() {
  let offset = null                    // serverTime - localAtSync
  let basePerf = null                  // sync 时的 performance.now()
  let baseServer = null
  const samples = []

  function sync(serverTime) {
    const localNow = Date.now()
    const rttHalf = 0                  // 由调用方传入往返延迟的一半更准；简化取 0
    const sample = serverTime + rttHalf - localNow
    samples.push(sample)
    if (samples.length > 5) samples.shift()
    const sorted = [...samples].sort((a, b) => a - b)
    offset = sorted[Math.floor(sorted.length / 2)]              // 中位数防抖
    basePerf = performance.now()
    baseServer = localNow + offset
  }

  return {
    sync,
    now() {
      if (offset === null) return { t: Date.now(), unsynced: true }   // 退化
      const elapsed = performance.now() - basePerf             // 单调流逝（免疫跳变）
      return { t: baseServer + elapsed, unsynced: false }
    },
    drift() {
      if (offset === null) return null
      return Date.now() - (baseServer + (performance.now() - basePerf))   // 本地 vs 对齐钟
    },
  }
}

// 倒计时使用

```
**评分点**：
- 多轮采样中位数（单次网络抖动不污染 offset）
- performance.now 单调流逝（免疫本地钟跳变——核心考点：Date.now 会被改）
- RTT 校正意识（服务端时间是发出时刻，应加半个往返）
- unsynced 退化明确（未对齐时行为可预期且可标记）
