## ZSM-450：手写状态管理健康分评分器
**答**：实现 `scoreHealth(metrics)`：输入指标集，输出 0-100 健康分与扣分明细：1) 指标：{ cacheHitRate, optimisticRollbackRate, invalidateStorm7d, p95SetMs, invalidNotifyRate, dualTruthCount, leakCount }；2) 各指标独立打分（0-100）后加权：缓存 25 / 乐观回滚 15 / 失效风暴 20 / 性能 20 / 订阅质量 10 / 架构债 10；3) 每项给出扣分原因与修复建议；4) 分级：>=80 健康 / 60-80 观察 / <60 危险（危险列出 top3 修复项）；5) 评分函数纯函数可单测。

```javascript
const WEIGHTS = { cache: 25, rollback: 15, storm: 20, perf: 20, subscription: 10, debt: 10 }

function clamp(v) { return Math.max(0, Math.min(100, v)) }

export function scoreHealth(m) {
  const items = [
    { key: 'cache', w: WEIGHTS.cache, score: clamp((m.cacheHitRate ?? 0) * 125),            // 0.8 → 100
      tip: '缓存命中率低：检查 queryKey 规范化与 staleTime' },
    { key: 'rollback', w: WEIGHTS.rollback, score: clamp(100 - (m.optimisticRollbackRate ?? 0) * 500),  // 20% → 0
      tip: '乐观回滚率高：检查冲突合并与服务端幂等' },
    { key: 'storm', w: WEIGHTS.storm, score: clamp(100 - (m.invalidateStorm7d ?? 0) * 10),
      tip: '失效风暴：引入失效调度器合并（见 ZSM-307）' },
    { key: 'perf', w: WEIGHTS.perf, score: clamp(m.p95SetMs <= 2 ? 100 : 100 - (m.p95SetMs - 2) * 20),
      tip: 'setState P95 超预算：收窄订阅粒度' },
    { key: 'subscription', w: WEIGHTS.subscription, score: clamp(100 - (m.invalidNotifyRate ?? 0) * 100),
      tip: '无效通知率高：改用 path 订阅/selector' },
    { key: 'debt', w: WEIGHTS.debt, score: clamp(100 - ((m.dualTruthCount ?? 0) * 15 + (m.leakCount ?? 0) * 10)),
      tip: '双真相源/泄漏：登记架构债清单逐个清' },
  ]
  const total = Math.round(items.reduce((s, i) => s + i.score * i.w / 100, 0))
  const deductions = items.filter((i) => i.score < 80).map((i) => ({ key: i.key, score: Math.round(i.score), tip: i.tip }))
  return {
    total,
    grade: total >= 80 ? 'healthy' : total >= 60 ? 'watch' : 'danger',
    deductions,
    top3: deductions.sort((a, b) => a.score - b.score).slice(0, 3),
  }
}
```
**评分点**：
- 加权合成正确（各权重和 = 100）；每项打分曲线有明确物理意义（如命中率 0.8 满分）
- 扣分明细带修复建议（可行动，不是冷冰冰分数）
- top3 排序（危险级给出优先修复项）
- 纯函数可单测（指标→分的映射确定性）
