## ZSM-494：手写状态层巡检报告生成器
**答**：实现 `generatePatrolReport(data)`：1) 输入：`{ period, metrics: { name, value, target, unit }[], alerts: [...], fixes: [...] }`；2) 三段式结构：总览（健康分 + 一句话结论）→ 例外明细（未达标指标/告警/失败修复，按严重度排序）→ 下周期建议（top3 行动项）；3) 指标达标判定带方向（越高越好/越低越好）；4) Markdown 输出（可贴周报）+ JSON 输出（机器可读双格式）；5) 结论措辞分级（优秀/正常/需关注/危险）。

```javascript
function judge(m) {
  const ok = m.higherBetter ? m.value >= m.target : m.value <= m.target
  const severity = !ok ? (Math.abs(m.value - m.target) / (m.target || 1) > 0.3 ? 'critical' : 'warning') : 'ok'
  return { ok, severity }
}

export function generatePatrolReport(data) {
  const judged = data.metrics.map((m) => ({ ...m, ...judge(m) }))
  const score = Math.round(judged.reduce((s, m) => s + (m.ok ? 100 : m.severity === 'critical' ? 40 : 70), 0) / judged.length)
  const grade = score >= 90 ? '优秀' : score >= 75 ? '正常' : score >= 60 ? '需关注' : '危险'
  const exceptions = judged.filter((m) => !m.ok)
    .sort((a, b) => (a.severity === 'critical' ? 0 : 1) - (b.severity === 'critical' ? 0 : 1))
  const failedFixes = data.fixes.filter((f) => f.status !== 'applied')
  const top3 = exceptions.slice(0, 3).map((m) => `${m.name}: ${m.value}${m.unit} → 目标 ${m.target}${m.unit}`)

  const md = [
    `# 状态层巡检报告（${data.period}）`,
    `## 总览：${grade}（${score} 分）`,
    grade === '危险' ? '结论：多项指标严重偏离，需立即介入。' : '结论：整体可控。',
    `## 例外明细`,
    ...(exceptions.length ? exceptions.map((m) => `- [${m.severity}] ${m.name}: ${m.value}${m.unit}（目标 ${m.target}）`) : ['- 全部达标']),
    ...(failedFixes.length ? [`## 修复失败`, ...failedFixes.map((f) => `- ${f.cause}: ${f.status}`)] : []),
    `## 下周期建议`,
    ...(top3.length ? top3.map((t, i) => `${i + 1}. ${t}`) : ['1. 维持现状']),
  ].join('\n')

  return { md, json: { period: data.period, score, grade, exceptions, top3 } }
}
```
**评分点**：
- 三段式结构（总览/例外/建议）——报告的可读性工程
- 达判方向语义（higherBetter 处理 INP 类反向指标）
- 严重度分级排序（critical 优先）；双格式输出（Markdown 人读 + JSON 机器读）
- 措辞分级与数据一致（分数→等级→结论语气联动）
