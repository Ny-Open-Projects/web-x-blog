## ZSM-529：文档草稿的脏检查与自动保存状态怎么建模

**答**：
- 三个核心切片：`savedContent`（服务端已确认版本）、`dirtyContent`（本地编辑中）、`saveState: 'idle' | 'saving' | 'error' | 'saved'`。脏标志不是布尔而是「内容对比」——布尔脏标志在保存失败、并发编辑时会漂移。
- 脏判定：`dirty = !Object.is(savedContent, dirtyContent)`，编辑器里每次变更写 dirtyContent；自动保存只对 dirty 触发，保存成功后把 savedContent 对齐 dirtyContent。
- 防抖+合并：输入高频，保存请求 debounce 800ms，saving 期间继续编辑不阻塞（「保存中」只是 UI 状态）；若 saving 时又变脏，保存完成后发现 dirty 再排下一次。
- 竞态防护：保存请求带 `baseVersion`（savedContent 的版本号），返回 409 表示远端已更新，进入「冲突解决」状态（强制覆盖/合并提示），而不是悄悄覆盖。
- 追问钩子：beforeunload 拦截 dirty 页面关闭；离线时把草稿进 IndexedDB，恢复时与远端版本对比。

```javascript
const useDraft = create((set, get) => ({
  savedContent: '',
  savedVersion: 0,
  dirtyContent: '',
  saveState: 'idle',

  edit: (content) => set({ dirtyContent: content }),   // 高频，不触发保存

  save: async () => {
    const { savedVersion, dirtyContent, saveState } = get()
    if (saveState === 'saving' || dirtyContent === get().savedContent) return
    set({ saveState: 'saving' })
    try {
      const res = await fetch('/api/docs/1', {
        method: 'PUT',
        headers: { 'If-Match': `"v${savedVersion}"` },   // 乐观锁
        body: JSON.stringify({ content: dirtyContent }),
      })
      if (res.status === 409) return set({ saveState: 'conflict' })  // 冲突态
      const { version } = await res.json()
      set({ savedContent: dirtyContent, savedVersion: version, saveState: 'saved' })
      // 保存期间又改了：再排一次
      if (get().dirtyContent !== get().savedContent) get().save()
    } catch {
      set({ saveState: 'error' })
    }
  },
}))

const isDirty = (s) => s.dirtyContent !== s.savedContent   // 派生脏标志
```
