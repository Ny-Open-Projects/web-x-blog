## 1110：笔试手写：实现 分页缓存垃圾回收器

**答**：实现 gcPages(pages, cursor, keep)：pages 为 { id, items } 双向链页数组（含 prev/next cursor），cursor 为当前停留页 id。GC 规则：保留当前页及其前后各 1 页 + 最近浏览的 keep 页；其余页移除（释放内存），但链不断——移除页记为 tombstone { id, placeholder: true }，翻页经过时可按需重取。返回 { kept, tombstones, freed }。

```js
function gcPages(pages, cursor, keep = 3) {
  const idx = pages.findIndex(p => p.id === cursor);
  if (idx < 0) throw new Error('cursor 页不存在');
  const near = new Set([idx - 1, idx, idx + 1]);
  const kept = [], tombstones = [];
  pages.forEach((p, i) => {
    if (near.has(i)) { kept.push(p); tombstones.push({ id: p.id, placeholder: false }); }
    else tombstones.push({ id: p.id, placeholder: true }); // 链位保留、数据移除
  });
  // 最近浏览的 keep 页从 tombstone 救回（LRU 思想简化为尾部保留）
  const extra = tombstones.filter(t => t.placeholder).slice(-keep);
  extra.forEach(t => {
    const p = pages.find(x => x.id === t.id);
    if (p) { kept.push(p); t.placeholder = false; }
  });
  const freed = pages.length - kept.length;
  return { kept, tombstones, freed };
}
```

**评分点**：
- 游标锚点 + 邻页保底（双向滚动的最小工作集）
- tombstone 保链不断（翻页路径可达性）
- freed 统计（GC 有效性可度量）
- 能讨论：与 useInfiniteQuery maxPages 的关系——官方机制 vs 自建 GC 的边界
