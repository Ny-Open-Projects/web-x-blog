## ZSM-388：场景题示范：按钮级权限（细粒度）状态与性能

**答**:
- 数据结构：权限集合 Set<code>（O(1) 判定）+ 资源级覆盖（本单据 own 的特殊规则）；can(code, resource?) 统一入口
- 性能：千级按钮页面不逐个订阅 store——can 函数在渲染期纯计算（Set 查询极快），只有权限集本身订阅；权限变化一次重算全页
- 语义分级：可见（hidden）、可用（disabled+tooltip 原因）、审计（点击前再校验）——三层不要混用
- 服务端防线重申：按钮级权限只是体验，接口层必须独立鉴权；前端 can() 与后端鉴权用同一份权限源，避免口径分裂

```javascript
const can = (code, res) => {
  if (permSet.has(code)) return true
  if (res && res.ownerId === me.id && permSet.has(code + ':own')) return true   // 资源级
  return false
}
function ActionButton({ code, res, children }) {
  return can(code, res)
    ? <button onClick={() => can(code, res) && exec()}>{children}</button>       // 审计层再校验
    : null
}
```
