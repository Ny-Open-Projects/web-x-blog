## ZSM-497：手写状态层多活读一致性
**需求**：实现多数据源读一致性层 `createMultiSourceReader(sources)`：1) sources：`[{ name, fetch, lagMs? }]`（多活副本，各有延迟）；2) `read(key, { consistency })`：'eventual' 用最快源；'bounded' 用「延迟 ≤ bound 的源」集合中最新数据；'strong' 等全部源返回取时间戳最新；3) 数据带 `{ ts }`，比较用逻辑时钟（版本向量简化为 maxTs）；4) 读放大控制：strong 模式加结果缓存（同 key 1s 内复用）；5) 源健康探测：失败源暂时踢出（30s 后重试）。

```javascript
export function createMultiSourceReader(sources, { strongCacheMs = 1000 } = {}) {
  const unhealthy = new Map()   // name → until
  const strongCache = new Map() // key → { data, at }

  function healthy() { const now = Date.now()
    return sources.filter((s) => (unhealthy.get(s.name) ?? 0) < now) }

  async function read(key, { consistency = 'eventual', bound = 2000 } = {}) {
    if (consistency === 'strong') {
      const c = strongCache.get(key)
      if (c && Date.now() - c.at < strongCacheMs) return c.data     // 读放大控制
    }
    const pool = healthy()
    const chosen = consistency === 'eventual'
      ? [pool[0]]
      : consistency === 'bounded'
        ? pool.filter((s) => (s.lagMs ?? 0) <= bound)
        : pool
    if (!chosen.length) throw new Error('no healthy source')

    const results = await Promise.allSettled(chosen.map(async (s) => {
      try { return await s.fetch(key) }
      catch (e) { unhealthy.set(s.name, Date.now() + 30_000); throw e }   // 踢出 30s
    }))
    const ok = results.filter((r) => r.status === 'fulfilled').map((r) => r.value)
    if (!ok.length) throw new Error('all sources failed')
    const latest = ok.sort((a, b) => (b.ts ?? 0) - (a.ts ?? 0))[0]        // 逻辑时间戳最新
    if (consistency === 'strong') strongCache.set(key, { data: latest, at: Date.now() })
    return latest
  }

  return { read, health: () => healthy().map((s) => s.name) }
}
```
**评分点**：
- 三档一致性语义（eventual/bounded/strong）与读放大权衡（strong 加缓存）
- 逻辑时间戳取最新（不用本地时钟比较远端数据）
- 源健康探测 + 踢出重试（部分失败不拖垮读取）
- allSettled 部分成功原则（strong 模式等全部，bounded/eventual 容忍部分失败）
