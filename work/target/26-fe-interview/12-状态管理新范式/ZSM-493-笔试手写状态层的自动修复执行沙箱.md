## ZSM-493：手写自动修复执行沙箱
**需求**：实现 `createFixSandbox(store)`：1) `run(fixFn)`：在「影子副本」上执行修复（structuredClone 当前状态 → 执行 → 校验 schema）；2) 校验通过才落盘真 store（两阶段提交：影子验证 → 原子应用）；3) 影子执行异常/校验失败 → 拒绝落盘 + 返回原因（真状态零污染）；4) 修复函数只允许调用白名单 API（setStaleTime/invalidate/resize 等——拦截其他调用）；5) 超时 3s 强制终止（修复函数死循环保护）。

```javascript
export function createFixSandbox(store, { allowed = ['setStaleTime', 'invalidate', 'gc'], timeoutMs = 3000 } = {}) {
  async function run(fixFn, validate) {
    const shadow = structuredClone(store.snapshot?.() ?? store.getState())
    const calls = []
    const sandboxApi = new Proxy({}, {
      get(_t, prop) {
        if (!allowed.includes(prop)) throw new Error(`sandbox: ${String(prop)} not allowed`)   // 白名单
        return (...args) => { calls.push({ prop, args }); return store[prop]?.(...args) }
      },
    })

    const result = await Promise.race([
      Promise.resolve(fixFn(shadow, sandboxApi)),
      new Promise((_, rej) => setTimeout(() => rej(new Error('fix timeout')), timeoutMs)),
    ])

    if (validate && !validate(shadow))                        // 影子校验
      return { ok: false, reason: 'schema validation failed', calls }

    // 两阶段提交：影子验证通过 → 原子应用
    calls.forEach(({ prop, args }) => store[prop]?.(...args))
    return { ok: true, result, calls }
  }

  return { run }
}
```
**评分点**：
- 影子副本两阶段提交（先验证后落盘——真状态零污染）
- 白名单 API Proxy 拦截（修复函数权限受限，防越权操作）
- 超时强制终止（死循环保护）；calls 执行日志可审计
- 影子校验器接入（schema 检查——自动修复不能引入坏状态）
