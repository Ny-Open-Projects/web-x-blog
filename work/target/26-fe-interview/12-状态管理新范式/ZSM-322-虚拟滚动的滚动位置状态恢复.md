## ZSM-322：虚拟列表跳转/返回时滚动位置怎么恢复

**答**:
- 虚拟列表只渲染窗口，恢复 scrollTop 需要行高信息：动态高度列表要存「index + offset」对而不是裸 scrollTop，回来后 scrollToOffset 或 scrollToIndex 重建
- 数据未变的恢复：离开时记录 scrollTop，返回且数据 key 一致时在挂载后（首帧渲染完成）恢复；直接在 effect 里恢复会因布局未完成而失效
- 数据已变（刷新后）：按「锚点项 id + 行内偏移」恢复，找不到锚点降级到顶部/按比例
- 平滑性：恢复用 instant 而非 smooth；恢复后主动触发一次 range 重算防白屏

```javascript
// 离开时
const pos = listRef.current.getState()          // virtualizer: { scrollOffset, measurementsCache }
historyStore.setState({ scroll: { itemId: anchorId, offset: pos.scrollOffset } })
// 返回后（数据就绪、DOM 渲染完成）
useLayoutEffect(() => {
  if (saved) virtualizer.scrollToOffset(saved.offset)   // 或 scrollToIndex(anchorIndex)
}, [ready])
```
