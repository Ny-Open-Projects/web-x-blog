## ZSM-435：手写客户端缓存对账器
**答**：实现 `createReconciler(qc, serverApi)`：1) `reconcile(domain)`：从本地 Query 缓存取该域全部条目 → 抽样 N 条 → 服务端批量查最新 → 逐条深比较；2) 不一致条目：直接用服务端值回写缓存（纠偏）+ 计数上报；3) 全部一致的统计「对账通过」；4) 服务端查询单条失败跳过不炸（部分成功原则）；5) `metrics()` 返回 { checked, mismatch, rate }；6) rate 超 5% 触发全量失效（缓存可能系统性陈旧）。

```javascript
export function createReconciler(qc, serverApi, { sample = 20, threshold = 0.05 } = {}) {
  let checked = 0, mismatch = 0

  async function reconcile(domain, listKey = ['list', domain]) {
    const list = qc.getQueryData(listKey) ?? []
    const ids = pickSample(list.map((x) => x.id), sample)
    const results = await Promise.allSettled(ids.map((id) => serverApi.get(domain, id)))   // 部分成功
    let localMismatch = 0, valid = 0
    results.forEach((r, i) => {
      if (r.status === 'rejected') return                   // 单条失败跳过
      const id = ids[i], server = r.value
      valid++
      const local = list.find((x) => x.id === id)
      if (!eq(local, server)) {
        localMismatch++
        qc.setQueryData([domain, id], server)               // 纠偏回写
        qc.setQueryData(listKey, (old) => old?.map((x) => x.id === id ? server : x))
      }
    })
    checked += valid; mismatch += localMismatch
    const rate = valid ? localMismatch / valid : 0
    if (rate > threshold) qc.invalidateQueries({ queryKey: [domain] })   // 系统性陈旧 → 全量失效
    return { checked: valid, mismatch: localMismatch, rate }
  }

  return { reconcile, metrics: () => ({ checked, mismatch, rate: checked ? mismatch / checked : 0 }) }
}

function pickSample(arr, n) {
  const out = [...arr]
  for (let i = out.length - 1; i > 0; i--) { const j = Math.floor(Math.random() * (i + 1)); [out[i], out[j]] = [out[j], out[i]] }
  return out.slice(0, n)
}
const eq = (a, b) => JSON.stringify(a) === JSON.stringify(b)
```
**评分点**：
- 抽样对账（成本控制）+ 洗牌抽样正确性
- Promise.allSettled 部分成功原则（单条失败不炸对账）
- 纠偏回写双 key（详情 + 列表视图同步）
- rate 超阈值升级全量失效（系统性陈旧检测）+ metrics 可观测
