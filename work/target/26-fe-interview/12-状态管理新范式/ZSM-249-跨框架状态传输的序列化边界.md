## ZSM-249：状态跨框架或跨边界传递时哪些数据会丢

**答**:
- 三类会丢的边界：结构化克隆（postMessage/IndexedDB）丢函数/Symbol/原型链；JSON（storage/URL）丢 Date→字符串、Map/Set/undefined；组件 props 序列化（WC attribute）只能字符串
- 后果：传出去的 Map 变 {}、Date 变 ISO 字符串、类实例变普通对象（方法全丢）——桥接层要约定「跨边界 DTO 是纯 JSON 数据」
- 对策：边界处显式转换器（toJSON/fromJSON）；Map/Set 用 entries 数组，Date 用时间戳，函数不跨边界（传 ID 让对端查表）
- 微前端/iframe 场景同理，postMessage 的 detail 按 DTO 约定，不要直接传 proxy/React 元素这类不可克隆对象

```javascript
// DTO 转换器示例
const toDTO = (state) => ({
  ...state,
  createdAt: state.createdAt.getTime(),        // Date → number
  tags: state.tags instanceof Map ? [...state.tags] : state.tags,
})
const fromDTO = (dto) => ({
  ...dto,
  createdAt: new Date(dto.createdAt),
  tags: new Map(dto.tags),
})
```
