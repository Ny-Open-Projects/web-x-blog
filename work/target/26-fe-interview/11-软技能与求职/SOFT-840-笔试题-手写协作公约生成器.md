## SOFT-840：手写 teamCharter：团队协作公约的生成（表达规则/同步分级/决策机制/反馈制度）、签署与违背处理

**需求与边界**：
- 实现 teamCharter(teamSize, prefs)。
- 边界要求：① 公约四模块：表达规则（对事激烈对人温和 SOFT-809）/同步分级（SOFT-824 三档）/决策机制（小事团队内大事例会 SOFT-828）/反馈制度（轮值互评 SOFT-822）；② 每条公约带“违背处理”（轻：私下提醒/重：复盘会）；③ 全员签署确认结构（签署记录）；④ 生成季度复查提醒（公约适配性）。

**答**：
```javascript
function teamCharter(prefs = {}) {
  const modules = [
    { name: '表达规则', rules: ['对事激烈对人温和', '异议公开提，会后不翻案'],
      breach: { light: '私下提醒', heavy: '复盘会讨论' } },
    { name: '同步分级', rules: ['影响他人排期/接口的变更：即时+多通道',
      '进展：周报节奏', '细节：文档归档不推送'], breach: { light: '补同步', heavy: '摩擦复盘' } },
    { name: '决策机制', rules: ['小事团队内自决', '跨人/跨团队事例会', '僵局TL拍板'],
      breach: { light: '重走流程', heavy: 'TL介入' } },
    { name: '反馈制度', rules: ['季度轮值互评（具体化）', '横向反馈默认一对一', '负面反馈私下正面公开'],
      breach: { light: '私下提醒', heavy: '复盘会' } },
  ];
  return { modules,
    signoff: { required: true, note: '全员签署（邮件确认）——
      签署的公约才有约束力' },
    review: '季度复查适配性（团队变化后公约需迭代）',
    customization: prefs };                        // 团队自定义补充
}
```

**评分点**:
- 四模块公约结构（SOFT-809/824/828/822 的制度化集成）。
- 每条带分级违背处理（公约有牙齿）。
- 全员签署+季度复查（约束力与适配性）。
