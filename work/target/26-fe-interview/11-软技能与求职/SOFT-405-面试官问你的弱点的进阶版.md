## SOFT-405：弱点题进阶——不同岗位画像下的弱点选材？

**答**:
- 选材公式升级（SOFT-128 之上）：弱点必须"与岗位核心正交 + 与你的成长曲线吻合"——技术岗说管理经验少、管理岗说技术细节手感下降，都是"岗位核心正交"的真实选项。
- 三段式升级：承认（具体）→ 影响范围（受限场景）→ 弥补动作（有证据的进展）+ 新增第四段"互补声明"（团队里怎么配 SOFT-128）。
- 禁选升级：除假谦虚与核心能力外，新增"伪装成优点的弱点"（"我太关注细节"）——面试官听过一万遍，零信息。
- 追问预案：弱点题的固定追问"那你怎么弥补的，效果如何"——弥补动作必须带可验证证据（产出/数据），口头计划不算。

```text
弱点题选材公式：
岗位核心正交 + 成长曲线吻合：
  技术岗 → 管理经验少（带人证据在补）
  管理岗 → 技术细节手感下降（review 保持）
四段式：承认具体 → 影响范围 →
  弥补动作（带证据）→ 互补声明
禁选：假谦虚 / 核心能力 /
  伪装成优点的弱点（"太关注细节"）。
追问预案："弥补效果？"——
  必须有可验证证据。
```
