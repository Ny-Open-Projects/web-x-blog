## SOFT-417：JD 解码进阶——怎么从职责描述反推团队真实状态？

**答**:
- 缺人信号的解码："能承受压力/快节奏"→大概率救火期或赶项目；"从 0 到 1 搭建"→新团队或换血，风险与机会并存；"参与并推动 XX 体系建设"→基建薄弱，进来是填坑的。
- 层级信号：JD 写"与产品/后端紧密协作并推动落地"→前端在团队话语权不低；只写"完成页面开发"→大概率是执行型团队，成长受限。
- 加分项即真实栈：加分项往往是团队在用但没把握你一定会的东西（如加分项写 WebAssembly/音视频，说明团队真在做），面试大概率往这问。
- 验证动作：解码出的 3 个推断放进反问环节求证（如"这个岗位是从 0 到 1 还是接手存量？"），面试官的回答就是最准的 JD。

```text
JD 解码对照表：
"承受压力/快节奏"   → 救火期，问加班真实度
"从 0 到 1"        → 新团队/换血，问背景与存留
"推动 XX 体系"     → 基建薄弱，进来填坑
"参与技术选型"     → 话语权高，成长好信号
只写"完成页面开发"  → 执行型，成长受限
加分项             → 团队真实在用的栈
                     （面试会往这问，提前备）
验证：3 个推断 → 反问环节求证。
```
