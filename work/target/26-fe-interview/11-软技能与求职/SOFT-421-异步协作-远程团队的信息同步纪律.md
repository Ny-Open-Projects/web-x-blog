## SOFT-421：远程或分布式团队怎么做异步协作——信息同步纪律？

**答**:
- 异步优先三要素：任何协作请求自带上下文（背景/现状/期望产出/截止时间）、结论落文档不落聊天记录（聊天易丢失且不可检索）、关键决策有书面确认（口头共识要回执成文字）。
- 响应分级约定：P0 当天响、P1 24h 内响、P2 周内批处理——把响应预期写进团队 README，避免"已读不回"被解读成态度问题。
- 同步兜底：异步两轮没对齐立即转会（15 分钟同步解决异步 2 天拉扯），会后再把结论写回文档形成闭环。
- 日志习惯：每天下班前 3 行进展同步（今天做了什么/卡在哪/明天计划），远程环境下可见性即信任。

```text
异步请求模板：
背景：__（为什么找我）
现状：__（已有哪些结论/文档链接）
需要：__（明确产出，如"确认接口方案"）
DDL：__（+ 优先级 P0/P1/P2）
响应分级：P0 当天 / P1 24h / P2 周内
两轮不对齐 → 转 15min 会 → 结论回文档
每日 3 行：Done / Blocked / Next
```
