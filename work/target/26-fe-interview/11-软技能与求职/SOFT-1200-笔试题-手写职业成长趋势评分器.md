## 1200：笔试手写：实现年度走留决策的成长趋势评分

**答**：实现 growthTrend(years)：years 为 { year, skills: string[]（新增可迁移技能）, comp: 总包(万), influence: 0~10 }[]（按年升序，至少 2 年）。输出 { skillGrowth: 年均新增技能数(2 位), compCAGR: 总包年复合增长率(3 位，n=1 时 null), influenceDelta, verdict }；verdict：skillGrowth>=2 且 compCAGR>=0.1 -> 'healthy'；skillGrowth<1 且 influenceDelta<=0 -> 'stagnant'；其余 'watch'。

```js
function growthTrend(years) {
  const n = years.length;
  const skillGrowth = +(years.reduce((s, y) => s + y.skills.length, 0) / n).toFixed(2);
  const compCAGR = n > 1 && years[0].comp > 0
    ? +((years[n - 1].comp / years[0].comp) ** (1 / (n - 1)) - 1).toFixed(3) : null;
  const influenceDelta = years[n - 1].influence - years[0].influence;
  const verdict = skillGrowth >= 2 && (compCAGR ?? 0) >= 0.1 ? 'healthy'
    : skillGrowth < 1 && influenceDelta <= 0 ? 'stagnant' : 'watch';
  return { skillGrowth, compCAGR, influenceDelta, verdict };
}
const y = [
  { year: 2024, skills: ['react', 'node'], comp: 40, influence: 5 },
  { year: 2025, skills: ['k8s', 'rust', 'aigc'], comp: 46, influence: 6 },
];
console.log(growthTrend(y));
// skillGrowth 2.5, compCAGR 0.15, influenceDelta 1, verdict 'healthy'
```

**评分点**：
- CAGR 公式：(末/首)^(1/(n-1)) - 1；n=1 或首年为 0 时返回 null（保护）
- 三档 verdict 条件与优先级（healthy 优先判定）
- 精度统一
- 能讨论：用途（年度走留决策的数据支撑）、skills 的「可迁移」口径需先定义、influence 自评的主观性（配外部反馈校准）
