## SOFT-200：项目复盘总收束：复盘的复利逻辑——为什么复盘是唯一零成本的成长杠杆？

**答**:
- 复利的来源：每次复盘产出的不是"总结"而是"决策模型补丁"——错误变成 checklist 条目、成功变成可重复的方法论，下次同类决策直接调用，边际成本趋零。
- 复盘体系的四层沉淀（本章 181~199 的收束）：个人层（决策档案+brag doc）→ 团队层（checklist+卡点）→ 组织层（规范+培训资产）→ 求职层（STAR 卡+简历条目）——一次复盘四层受益。
- 复盘的频率纪律：项目级（结束后 1 周）+ 季度级（个人 OKR 对照）+ 事件级（事故 24h 内）——三级节奏保证不复利断流。
- 毕业标准：不看本章能自发执行"四步复盘→归因三检验→去个人化输出→三级落地→素材反哺"全链路，且最近一次项目复盘的 action 在两周内验收过。

```text
复盘复利全景（收束图）：
一次复盘（1~2 小时投入）
 ├ 个人层：决策档案 / brag doc 条目
 ├ 团队层：checklist 条目 / CI 卡点
 ├ 组织层：规范条目 / 培训材料
 └ 求职层：STAR 卡 / 简历结果行 / 述职素材

三级节奏：
事故 → 24h 内 | 项目 → 结束 1 周内
个人成长 → 每季度

毕业自检：
[ ] 四步复盘不查资料能走通
[ ] 归因做过运气/能力检验
[ ] 最近一条复盘 action 两周内验收过
[ ] brag doc 更新频率 ≥ 周级
[ ] 至少一条复盘产物在第二场景复用过
——全勾，复盘才算真的在复利。
```
