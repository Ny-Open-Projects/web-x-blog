## 1075：笔试手写：实现晋升材料对职级标准的覆盖评分

**答**：实现 coverageScore(evidence, standard)：standard 为 { dim: weight }[]（维度与权重，和为 1）；evidence 为 { dim, strength: 0~5 }[]（每条证据的强度）。评分 = Σ (维度内最强证据强度 / 5) × 维度权重，总分保留 2 位；输出 { score, perDim: { dim: { best, score } } }（维度无证据时 best 为 null，score 为 0），按 score 升序给出 weakest（最弱维度）建议补强列表（score < 0.6 的维度）。

```js
function coverageScore(evidence, standard) {
  const perDim = {};
  for (const [dim, w] of Object.entries(standard)) {
    const evs = evidence.filter(e => e.dim === dim);
    const best = evs.length ? Math.max(...evs.map(e => e.strength)) : null;
    const score = best === null ? 0 : +((best / 5) * w).toFixed(3);
    perDim[dim] = { best, score };
  }
  const total = Object.values(perDim).reduce((s, d) => s + d.score, 0);
  const weakest = Object.entries(perDim)
    .filter(([, d]) => d.score < 0.6)
    .sort((a, b) => a[1].score - b[1].score).map(([k]) => k);
  return { score: +total.toFixed(2), perDim, weakest };
}
const std = { tech: 0.4, influence: 0.4, people: 0.2 };
const ev = [{ dim: 'tech', strength: 5 }, { dim: 'tech', strength: 3 },
  { dim: 'influence', strength: 2 }];
console.log(coverageScore(ev, std));
// score: 0.4*1 + 0.4*0.4 = 0.56, weakest: ['influence','people']
```

**评分点**：
- 维度内取「最强证据」而非求和（一条硬证据顶三条弱的——符合评审直觉）
- 无证据维度 score=0 且 best=null；weakness 阈值 0.6 可讨论
- 权重归一假设（和为 1）应声明
- 能讨论：用途（材料自评+补强排序）、strength 的校准方法（用历史答辩结果回归）、求和 vs 取最强的适用差异
