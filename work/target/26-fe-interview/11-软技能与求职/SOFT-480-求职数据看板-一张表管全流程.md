## SOFT-480：把求职全流程装进一张数据看板——字段怎么设计？

**答**:
- 主表设计：机会表一行一机会，字段分五组——机会信息（公司/岗位/JD 链接/渠道/意愿把握分）、流程状态（当前轮次/下一步动作/日期）、复盘数据（爆题/挂因/反馈）、offer 数据（结构/期限/谈判状态）、关系数据（内推人/猎头/联系人）——一张表覆盖从投递到入职。
- 状态机思维：每个机会只有明确的下一步动作与日期（"等反馈"是非法状态，必须是"__ 日跟进 __"）——看板的核心是把模糊的等待变成可执行的动作队列。
- 视图复用：按状态切片（本周要面试的/该跟进的/等结果超期的）+ 按周汇总转化率（接 SOFT-411 漏斗）——一个表两个视图分别管执行和复盘。
- 收尾价值：求职结束后这张表是复盘与叙事资产（下轮求职的基线数据），也是 SOFT-400 全流程收束图的落地载体。

```text
求职看板主表（一行一机会）：
机会：公司/岗位/JD/渠道/意愿×把握
流程：当前轮次 / 下一步动作+日期
复盘：爆题 / 挂因 / 反馈
offer：结构 / 有效期 / 谈判状态
关系：内推人 / 猎头 / 联系人
纪律：每行必须有"下一步+日期"，
  "等反馈"是非法状态 → "__ 日跟进"。
视图：执行视图（本周面试/该跟进/
  超期）+ 复盘视图（周漏斗转化）。
收尾：全表 = 下轮基线 + 叙事资产。
```
