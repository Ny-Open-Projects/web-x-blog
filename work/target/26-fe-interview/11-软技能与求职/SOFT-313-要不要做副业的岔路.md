## SOFT-313：要不要做副业——成本收益与三条红线？

**答**:
- 收益清单：第二收入曲线、技能外溢（独立做产品倒逼全栈能力）、个人品牌资产、抗裁员心理垫——副业最大的价值常常是"心理层"（有 plan B 的人谈薪底气都不同，SOFT-250 的 BATNA）。
- 真实成本：每周 10~15 小时的持续投入（两三年才能见效）、精力对主业的挤占风险、情绪消耗（副业失败率极高）——副业是长跑不是快钱。
- 三条红线：不与主业竞争利益（竞业/保密，SOFT-109）、不占用主业时间与设备、不影响主业绩效（主业是 1，副业是后面的 0）。
- 起步建议：从"内容/工具"类低维护副业起步（技术博客/小工具/模板），验证持续投入的习惯后再上重项目——多数人死于高开低走。

```text
副业决策卡：
收益：第二曲线 / 技能外溢 /
  个人品牌 / 抗裁员心理垫（BATNA）
成本：每周 10~15h × 2~3 年见效 /
  挤占主业 / 高失败率
三红线：
[ ] 不与主业利益冲突（竞业/保密）
[ ] 不占主业时间设备
[ ] 主业绩效优先（1 与 0 的关系）
起步：内容/工具类低维护起步
  （博客/小工具/模板），
  验证投入习惯后再上重项目。
```
