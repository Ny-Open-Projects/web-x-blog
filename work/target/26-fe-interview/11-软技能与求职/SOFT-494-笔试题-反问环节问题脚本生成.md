## SOFT-494：手写反问环节的问题脚本——按面试轮次分层生成？

**需求与边界**：
- 输入：面试轮次（技术一面/二面/交叉面/HR 面）+ 已收集的团队情报；输出：每轮 2~3 个反问，含"为什么问这个"的意图说明。
- 边界要求：① 不问百度可得的基础问题（如"用什么技术栈"一面不能问）；② 不在早期问薪资福利；③ 每问必须有信息价值或价值展示意图。

**答**（分层反问脚本）:
```javascript
function buildAskQuestions(stage, intel) {
  const map = {
    tech1: [ // 一面：问技术深度与工程实践（展示技术热情）
      `团队目前最大的技术挑战是${intel.challenge || '什么'}？（意图：情报反哺+显得懂行）`,
      `团队的 Code Review 和测试流程是怎样的？（意图：判断工程文化）`,
    ],
    tech2: [ // 二面：问成长与业务（展示长期意愿）
      `这个岗位近半年最需要解决的一件事是什么？（意图：岗位预期对齐）`,
      `团队在${intel.domain}上的演进方向是什么？（意图：展示我研究过）`,
    ],
    cross: [ // 交叉面：问协作与定位
      `前端在这个业务里的话语权如何，技术决策怎么产生？（意图：判断成长空间）`,
    ],
    hr: [ // HR 面：问落地与节奏（此时可谈福利框架）
      `团队的节奏是怎样的，最近一次上线的项目周期多久？（意图：验证 JD 红灯词）`,
      `入职后前三个月的预期是什么？（意图：预期对齐）`,
    ],
  };
  return map[stage].map((q, i) => `${i + 1}. ${q}`);
}
// 自检：一面无薪资福利题；每问带意图注释；
// 无"百度可答"题（技术栈/加班多不多此类直接问被扣分）。
```

**评分点**:
- 四轮分层正确：一面技术、二面业务成长、交叉面协作定位、HR 面节奏预期，问题随轮次升维。
- 每个问题带意图说明，区分"信息价值"与"价值展示"两类目的。
- 无早期谈钱、无百度可答题，避雷意识到位。
- 有把已收集情报融入反问的动作（研究过团队才问得出深问题）。
