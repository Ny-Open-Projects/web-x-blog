## SOFT-358：职业倦怠期——识别信号、归因与恢复动作？

**答**:
- 信号识别：持续两周以上的"上班即消耗"（ Sunday scare 严重化）、产出质量下降但努力没减、对以前感兴趣的事麻木——三条中两条 = 倦怠确认。
- 归因三选一：能量型（长期高压无恢复——需要休息与边界）、意义型（工作失去意义感——需要新挑战或新叙事）、环境型（团队/业务有毒——需要换环境）——三种倦怠的解法完全不同。
- 恢复动作：能量型→强制休息+运动+睡眠（先修身体）；意义型→申请新方向/做 side project 找回掌控感；环境型→内转或外部机会（用 SOFT-299 流程）。
- 红线：倦怠期不做重大决策（裸辞/大额消费）——先恢复判断力再决策，顺序反了会雪上加霜。

```text
倦怠自救卡：
信号（2 条即确认）：持续消耗感 /
  产出降但努力没减 / 兴趣麻木
归因三选一：
  能量型 → 强制休息+运动+睡眠
  意义型 → 新方向/side project 找掌控感
  环境型 → 内转 or 外部机会（SOFT-299）
红线：倦怠期不裸辞不做大决策
  ——先恢复判断力再决策。
```
