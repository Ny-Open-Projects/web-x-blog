## 1025：笔试手写：实现求职漏斗的阶段转化率统计

**答**：实现 funnel(events)：events 为 { company, stage: 'applied'|'screen'|'interview'|'offer', ts }[]（可能乱序，按 ts 排序后每公司取「到达的最远阶段」）。输出各阶段到达数与转化率（相对上一阶段，保留 3 位，除零为 null）：applied->screen->interview->offer；另给 offerRate（offer/applied）。

```js
const ORDER = { applied: 0, screen: 1, interview: 2, offer: 3 };
function funnel(events) {
  const far = new Map();                    // 每公司最远阶段
  for (const e of [...events].sort((a, b) => a.ts - b.ts)) {
    const cur = far.get(e.company) ?? -1;
    if (ORDER[e.stage] > cur) far.set(e.company, ORDER[e.stage]);
  }
  const count = [0, 0, 0, 0];
  for (const v of far.values()) count[v]++;
  const reach = { applied: count[0], screen: count[1],
    interview: count[2], offer: count[3] };
  const keys = Object.keys(reach), conv = {};
  for (let i = 1; i < keys.length; i++) {
    conv[keys[i - 1] + '->' + keys[i]] =
      reach[keys[i - 1]] ? +(reach[keys[i]] / reach[keys[i - 1]]).toFixed(3) : null;
  }
  return { reach, conv,
    offerRate: reach.applied ? +(reach.offer / reach.applied).toFixed(3) : null };
}
console.log(funnel([
  { company: 'A', stage: 'applied', ts: 1 }, { company: 'A', stage: 'offer', ts: 9 },
  { company: 'B', stage: 'applied', ts: 2 }, { company: 'B', stage: 'screen', ts: 3 },
  { company: 'C', stage: 'applied', ts: 4 },
]));
// reach { applied:3, screen:1, interview:0, offer:1 }
```

**评分点**：
- 「最远阶段」语义正确（乱序按 ts 排序取最大；重复阶段不重复计数）
- 转化率除零返回 null
- 输出可看板化（reach + conv + offerRate）
- 能讨论：用途（定位卡点：简历->screen 低是简历问题，interview->offer 低是表达问题）、乱序与重复事件边界
