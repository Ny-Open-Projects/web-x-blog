## SOFT-500：手写晋升述职开场脚本——3 分钟内立住"下一级画像"？

**需求与边界**：
- 场景：晋升答辩开场 3 分钟，评委手上是等级能力模型。
- 边界要求：① 开场必须包含"下一级画像"定位句（我已具备 __ 能力的三个证据域）；② 每个证据域指向可验证的产出（项目/机制/影响面）；③ 不念简历，只立论点。

**答**（述职开场脚本）:
```javascript
function buildPromoOpening(me) {
  // 定位句：目标等级 + 三个证据域（对应能力模型维度）
  const claim = `我在 ${me.nextLevel} 要求的三个维度上都有完整证据：` +
    `技术深度、体系化建设、跨团队影响。`;
  // 证据地图：每个域 → 一个最强产出 + 量化 + 影响面
  const evidence = me.evidence.map(e =>
    `${e.domain}：${e.output}（${e.metric}，影响面 ${e.scope}）`);
  // 收尾：把 3 个域收束到"下一级在做什么"
  const close = `这三件事合起来，就是我理解的 ${me.nextLevel}` +
    `要解决的问题——接下来逐一展开。`;
  return [claim, ...evidence.map(s => `- ${s}`), close].join('\n');
}
// 示例：
// evidence: [
//  { domain: '技术深度', output: 'X 疑难性能治理', metric: 'LCP __→__',
//    scope: '核心链路 __ 流量' },
//  { domain: '体系化', output: '前端监控体系 0→1', metric: '拦截 __ 起/季',
//    scope: 'N 个团队接入' },
//  { domain: '跨团队', output: '契约联调机制', metric: '联调问题 __→__',
//    scope: '前后端 N 个团队' }]
// 自检：定位句先于细节；每证据=产出+量化+影响面三件套；
// 无简历流水账；3 分钟内可讲完（约 450 字）。
```

**评分点**:
- 开场先立"下一级画像"定位句（三证据域对应能力模型），而非从经历流水讲起。
- 每个证据域含产出+量化+影响面三件套，证据可验证且覆盖三个不同维度。
- 收束句把个人证据映射到"下一级职责"，答辩逻辑从"我做过"升维到"我已具备下一级能力"。
- 无简历复述、无形容词堆砌，3 分钟内可完成（评委注意力窗口内立住论点）。
