## SOFT-425：跨部门要资源或谈排期怎么谈——博弈话术怎么设计？

**答**:
- 立场换利益：谈判不摆立场（"我必须要 3 天"）而摆利益（"这个功能依赖后端接口提前 2 天，否则前端联调窗口不够，上线质量有风险"），把对抗变成共同解决问题。
- 选项式提案：给对方 2~3 个可选方案（A 全量支持但延后 / B 降级方案本周上 / C 借调人力），有选项的谈判更容易达成，对方拒绝的成本也更高。
- 数据即筹码：用历史数据说话（"上 3 次压缩联调各产生 __ 个线上问题，修复成本 __h"），情绪与抱怨不是筹码，量化损失才是。
- 底线管理：进场前定好底价与让步顺序（先让小项换大项），谈崩时的升级路径（拉双方 leader）提前想好，而不是现场意气用事。

```text
跨部门谈判框架：
利益句式："这件事对双方的影响是 __，
  我建议我们找都能接受的方案。"
选项式提案：
  A 全量支持，交付延 __ 天
  B 降级方案（砍 __），本周可上
  C 借调 __ 一人，成本 __
筹码数据：历史压缩联调 → 线上问题
  __ 个 / 修复 __h
底线：底价 __ / 让步顺序 小→大 /
  谈崩升级路径：双方 leader + 事实记录。
```
