## SOFT-386：怎么开口要内推——请求模板与感恩闭环？

**答**:
- 请求模板四要素：说明目标岗位（精确到 JD 链接）、为什么适合（2 条证据，让内推人好转发）、材料就绪（简历已定制，SOFT-136）、轻量承诺（"麻烦帮忙递一下，不合适也没关系"）——降低对方的动作成本与心理负担。
- 开口对象分层：强关系直说、弱关系先给价值再开口（帮过他/有共同话题）、陌生人从技术交流切入（评论区互动后私信）。
- 感恩闭环：拿到面试机会 → 同步进展 → 无论结果致谢 → 成功了请顿饭或送小礼物——内推人付出了信用，闭环质量决定下次还能不能开口。
- 反模式：群发式求内推（对方感到被批量对待）、开口就要"保过"、面崩了消失——三种行为烧掉的不只是这一个内推人，是他的圈子。

```text
内推请求模板：
"目标：{岗位 JD 链接}
适合：{2 条证据（方便他转发）}
材料：简历已按 JD 定制
姿态：麻烦递一下，不合适没关系"
对象分层：强关系直说 / 弱关系先给价值 /
  陌生人技术交流切入。
感恩闭环：同步进展 → 无论结果致谢 →
  成功请饭。
反模式：群发 / 要保过 / 面崩消失。
```
