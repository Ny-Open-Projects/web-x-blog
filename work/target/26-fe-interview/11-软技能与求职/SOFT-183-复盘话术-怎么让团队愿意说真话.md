## SOFT-183：主持复盘时怎么让大家说真话——安全氛围的具体营造技巧？

**答**:
- 真话缺席的根因是"说错话有代价"：营造安全的关键动作是主持人示范脆弱性——第一个讲自己的失误，且讲得具体不遮掩。
- 制度性保护：复盘文档默认不在绩效场景引用、"只对事不对人"开场白明确说出、发言顺序先新人后资深（新人先说避免被带偏）。
- 匿名通道兜底：会前收集匿名输入（表格），会上以"有人提到…"的方式转述——给不敢当面说的人一个出口。
- 语言技巧：把"你为什么没做"换成"什么阻碍了这个动作发生"——主语从人换到环境，防御性立刻下降。

```text
安全氛围营造清单：
[ ] 主持人第一个自我归因（具体到决策）
[ ] 开场声明："文档不进绩效，只对事不对人"
[ ] 发言顺序：新人 → 核心 → 资深 → leader
[ ] 会前匿名收集，会上转述
[ ] 语言换框："什么阻碍了 X" 替代 "你为什么没 X"

效果信号：会上出现了"其实当时我判断错了"
级别的发言 → 安全是真的；
全是"我们都尽力了" → 氛围是假的，下次先从
leader 自我归因开始重建。
```
