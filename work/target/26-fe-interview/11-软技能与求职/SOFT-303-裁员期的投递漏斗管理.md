## SOFT-303：裁员期的投递漏斗管理——用转化率数据驱动策略调整？

**答**:
- 漏斗四层与基准值：投递→简历通过（10%~20%）→一面通过（30%~40%）→offer（30%~50%）——每层都记数据，卡在哪层就修哪层的策略。
- 卡层诊断：简历通过率低 → 简历/JD 匹配问题（SOFT-136 定制）；一面挂 → 八股/手写手感（回归复习）；终面挂 → 叙事/动机问题（SOFT-107/280）。
- 投递量管理：收缩期投递基数上调（周 30~50 投），且按"漏斗前置放大"原则——简历通过率低的公司群（严筛大厂）多投，转化率高的（猎头优质岗）重点跟进。
- 心态功能：漏斗数据把"被拒"从情绪事件变成统计事件——通过率 15% 意味着 85% 的拒绝是预期内的，焦虑来自对拒绝的错误预期。

```text
投递漏斗表（每周更新）：
投递 40 → 简历过 6（15%）→ 一面过 2（33%）
  → 终面 1 → offer 0
诊断：卡在一面 → 下周侧重八股+手写复盘
策略调整规则：
  简历层低 → 定制化↑ / 渠道换内推
  面试层低 → 复盘答崩点（SOFT-179）
  终面层低 → 动机叙事修正
心态公式：拒绝是漏斗的数学，
  不是对我的判决。
```
