## 1100：笔试手写：校验职业履历的时间线完整性

**答**：实现 validateCareer(jobs)：jobs 为 { company, start: 'YYYY-MM', end: 'YYYY-MM'|null }[]（end=null 表示在职）。校验：① 无断档（相邻两份工作空隙 >2 月记录为 gap）；② 无重叠；③ start < end；④ 在职记录必须唯一。返回 { ok, gaps, overlaps, errors }。

```js
function toM(s) { return s ? +s.slice(0, 4) * 12 + +s.slice(5, 7) - 1 : Infinity; }
function validateCareer(jobs) {
  const errs = [], gaps = [], overlaps = [];
  const sorted = [...jobs].sort((a, b) => toM(a.start) - toM(b.start));
  if (sorted.filter(j => j.end === null).length > 1) errs.push('multiple active jobs');
  for (const j of sorted) {
    if (j.end && toM(j.start) >= toM(j.end)) errs.push('start>=end: ' + j.company);
  }
  for (let i = 0; i < sorted.length - 1; i++) {
    const a = sorted[i], b = sorted[i + 1];
    if (a.end && toM(b.start) < toM(a.end)) overlaps.push([a.company, b.company]);
    else if (a.end) {
      const g = toM(b.start) - toM(a.end);
      if (g > 2) gaps.push({ from: a.end, to: b.start, months: g });
    }
  }
  return { ok: !errs.length && !overlaps.length, gaps, overlaps, errors: errs };
}
const jobs = [
  { company: 'A', start: '2020-01', end: '2021-06' },
  { company: 'B', start: '2021-10', end: '2022-03' },   // gap 3 月
  { company: 'C', start: '2021-12', end: '2022-05' },   // overlap
];
console.log(validateCareer(jobs));
// overlaps [['B','C']], ok false
```

**评分点**：
- 月份换算函数正确；排序后相邻比较的 gap/overlap 判定
- gap 阈值 <=2 月宽容（投递准备期合理）
- 多个在职记录的校验；start>=end 校验
- 能讨论：用途（简历自检防背调翻车）、实习重叠的处理、自由职业期的合并口径
