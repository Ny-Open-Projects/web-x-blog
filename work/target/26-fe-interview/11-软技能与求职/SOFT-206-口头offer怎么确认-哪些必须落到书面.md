## SOFT-206：收到口头 offer 怎么确认——哪些条款必须落到书面才算数？

**答**:
- 必落书面的六项：base 数额、职级与 title、年终奖口径（月数基数 + 绩效系数说明）、股票/期权（数量、行权价、vesting 计划、回购条款）、签字费与发放条件、试用期时长与薪资折扣。
- 口头 offer 的合法用途：确认意向与到岗时间——谈条件阶段它不算数；"HR 说过了但邮件没有"的承诺，写消息确认（"刚才电话里确认的 {X}，麻烦邮件补充下"）即可留痕。
- 拒绝陷阱：口头承诺"年终平均 4 个月"要问清是承诺基数还是历史均值；"股票价值 X 万"要问清按什么价、几股、何时 vest。
- 收到书面 offer 前不要提离职：口头 offer 消失的真实案例太多，书面 = 唯一安全线。

```text
书面化确认消息模板：
"感谢确认！刚才电话里几项我复述一下：
 base {X}、职级 {Y}、年终按 {N} 月基数、
 股票 {数量/vesting}、签字费 {Z} 条件 {…}。
 麻烦正式 offer 里都体现下，我收到后会
 尽快走内部流程。"

必须书面六项核对：
[ ] base [ ] 职级title [ ] 年终口径
[ ] 股票细节 [ ] 签字费条件 [ ] 试用期折扣
口径追问："4 个月"是承诺基数还是历史均值？
"股票价值 X 万"按什么价？几股？vest 节奏？
```
