## SOFT-491：手写一份 90 秒自我介绍逐字稿模板——支持按 JD 一键切换重点？

**需求与边界**：
- 输入：JD 关键词（如"基建/性能/团队协作"）；输出：90 秒（约 260 字）逐字稿，含四段结构。
- 边界要求：① 稿内所有数字必须可被追问（不写无法佐证的数据）；② 不得出现贬低前司/前同事的表述；③ 结尾必须有一句"与该岗位的连接"。

**答**（逐字稿模板脚本）:
```javascript
/**
 * 自我介绍逐字稿生成器
 * @param {Object} me  个人事实档案（全部可佐证）
 * @param {string[]} jdKeywords  JD 高频关键词
 * @returns {string} 260 字左右的逐字稿
 */
function buildIntro(me, jdKeywords = []) {
  // 段 1：身份定位（15s）——一句话说清我是谁
  const P1 = `面试官您好，我是${me.name}，${me.years}年前端，` +
    `当前在${me.company}负责${me.domain}。`;
  // 段 2：主线递进（30s）——三段经历一条能力主线
  const P2 = `我的经历是一条主线：从${me.stage1}，` +
    `到${me.stage2}，再到${me.stage3}。` +
    `最近做的是${me.flagship}，结果是${me.metric}。`; // metric 必须可佐证
  // 段 3：按 JD 切换重点（30s）——关键词匹配最高权重素材
  const pick = jdKeywords.find(k => me.assets[k]); // 单一最高权重素材
  const P3 = pick
    ? `看到岗位强调${pick}——我正好${me.assets[pick]}。`
    : `我的技术积累主要在${me.defaultAsset}。`;
  // 段 4：连接与收尾（15s）——为什么是这里
  const P4 = `希望在贵司把${pick || me.defaultAsset}继续做深，这也是我今天来的原因。`;
  return [P1, P2, P3, P4].join('');
}
// 自检：总字数 <= 280；每句 ≤ 40 字可一口气说完；
// 数字全部来自事实档案；无形容词堆砌、无贬低性表述。
```

**评分点**:
- 四段结构完整且时长分配正确（15/30/30/15，结尾有岗位连接句）。
- 所有量化数据可佐证、无堆砌形容词，符合"每个词经得起三层追问"的纪律。
- 有按 JD 关键词切换重点的机制，而非一份稿子打天下。
- 无贬低前司表述，稿子口语化可念（短句，无书面长定语）。
