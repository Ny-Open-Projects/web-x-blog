## SOFT-454：JD 里哪些是红灯词——岗位风险的信号识别？

**答**:
- 高危信号组："抗压能力强+快节奏+弹性工作"组合 → 大概率长期加班；"迅猛发展+融资" → 未盈利公司稳定性风险；"接受 996/大小周"明示 → 直接按加班预期评估；"负责 XX 从 0 到 1"出现多次 → 可能频繁换血。
- 结构性红灯：JD 长期挂着（半年以上反复发布）→ 留不住人；薪资范围极宽（如 15-40k）→ 岗位定位混乱或压价空间大；"全栈""一专多能"要求过多 → 一人多岗的风险。
- 需要面试验证的红灯：红灯不是一票否决而是"进面试必须求证"——把疑点转为反问（"团队目前的节奏是怎样的""这个岗位为什么开放"），面试官的微表情与回答方式比 JD 本身信息量大。
- 对照组：绿灯词（"技术驱动""重视工程质量""有技术博客/开源"）——红灯躲坑，绿灯加分，两者一起构成岗位风险画像。

```text
JD 红灯词对照表：
"抗压+快节奏+弹性"   → 长期加班概率高
"迅猛发展+融资中"    → 稳定性风险
"接受 996/大小周"    → 明示加班预期
"从 0 到 1"多次出现  → 频繁换血嫌疑
挂半年反复发 / 薪资带极宽（15-40k）
/ "全栈+一专多能"    → 定位混乱或压价
处理：红灯 ≠ 拒投 → 转为面试验证：
  "团队节奏是怎样的？"
  "这个岗位为什么开放？"
绿灯词：技术驱动 / 工程质量 / 有博客。
```
