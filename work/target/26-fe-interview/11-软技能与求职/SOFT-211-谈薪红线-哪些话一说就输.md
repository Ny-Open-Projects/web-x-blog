## SOFT-211：谈薪红线清单——哪些话一说就输？

**答**:
- 红线一"我急"：任何暴露时间压力的表达（"下个月必须入职""房贷压力大"）都会被拿来压价——需求方劣势一旦暴露，谈判转入对方节奏。
- 红线二"我只有你们"：暗示没有其他选择 = 放弃 BATNA；哪怕真没有，也表述为"在推进几个流程，贵司优先级最高"。
- 红线三情绪化对抗："你们这预算是打发叫花子吗"式表达烧掉关系——谈判是合作博弈，保持"我很想来，只是条件要对齐"的框架。
- 红线四不诚实筹码：编造 offer、虚报现薪、虚构竞争对手——背调与入职流程会连环暴露，一次造假毁掉所有谈判成果。

```text
红线自检表（谈薪前过一遍）：
[ ] 全程未暴露时间压力（急入职/经济压力）
[ ] 未说"只有你们一个机会"类话
[ ] 无情绪化贬损表达，框架始终是
    "想来 + 条件对齐"
[ ] 所有筹码真实可查（offer/薪资/竞对）

危险话术替换：
差："我必须下月入职" → 好："到岗时间可以谈，
   我的期望是 {X 周内}，如果有签字费可以配合。"
差："你们预算太低了" → 好："和我的预期有差距，
   差距部分在 {结构/职级} 上有没有空间？"
```
