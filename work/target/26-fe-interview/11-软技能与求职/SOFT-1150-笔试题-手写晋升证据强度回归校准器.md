## 1150：笔试手写：用历史答辩结果校准证据强度权重

**答**：实现 calibrate(historical)：historical 为 { dims: { [dim]: strength(0~5) }, passed: bool }[]（历史答辩的维度强度与结果）。训练简化逻辑回归：score = Σ w_d × dim_d（w 初始 0.2），用梯度下降（lr=0.05，20 轮）最小化交叉熵，w 限制在 [0.05, 0.6]。返回权重表（保留 3 位）与训练集准确率。

```js
function sigmoid(z) { return 1 / (1 + Math.exp(-z)); }
function calibrate(historical, { lr = 0.05, epochs = 20 } = {}) {
  const dims = Object.keys(historical[0].dims);
  const w = Object.fromEntries(dims.map(d => [d, 0.2]));
  for (let e = 0; e < epochs; e++) {
    for (const h of historical) {
      const z = dims.reduce((s, d) => s + w[d] * h.dims[d], 0);
      const err = sigmoid(z) - (h.passed ? 1 : 0);
      for (const d of dims) {
        w[d] = Math.min(0.6, Math.max(0.05, w[d] - lr * err * h.dims[d]));
      }
    }
  }
  let hit = 0;
  for (const h of historical) {
    const z = dims.reduce((s, d) => s + w[d] * h.dims[d], 0);
    if ((sigmoid(z) > 0.5) === h.passed) hit++;
  }
  return { w: Object.fromEntries(dims.map(d => [d, +w[d].toFixed(3)])),
    acc: +(hit / historical.length).toFixed(3) };
}
const hist = [
  { dims: { tech: 5, influence: 2 }, passed: false },
  { dims: { tech: 4, influence: 4 }, passed: true },
  { dims: { tech: 3, influence: 1 }, passed: false },
  { dims: { tech: 4, influence: 5 }, passed: true },
];
console.log(calibrate(hist));
```

**评分点**：
- 梯度更新方向正确（err = p - y，权重减 lr×err×x）
- 权重裁剪在更新内执行（clamp 后仍收敛）
- sigmoid 数值稳定（可讨论大 z 溢出）
- 能讨论：用途（用历史答辩数据校准「哪些维度真正决定通过」，指导材料精力分配）、样本量小的过拟合风险、可加正则
