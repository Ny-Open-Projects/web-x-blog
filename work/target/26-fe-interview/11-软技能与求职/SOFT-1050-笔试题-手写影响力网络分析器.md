## 1050：笔试手写：实现协作网络的影响力分计算

**答**：实现 influenceScore(nodes, edges)：nodes 为 { id, team }[]，edges 为 [from, to][]（from 帮助/支持过 to，影响方向）。计算每个节点的影响力分：直接影响 = 出边数；二度影响 = 其直接影响的节点再影响的去重节点数（不含自己与直接节点）。输出每个节点 { id, direct, second }，按 (direct+second) 降序，并列按 id 字典序。

```js
function influenceScore(nodes, edges) {
  const out = new Map(nodes.map(n => [n.id, []]));
  for (const [a, b] of edges) if (out.has(a)) out.get(a).push(b);
  const ids = nodes.map(n => n.id);
  const rows = ids.map(id => {
    const d1 = new Set(out.get(id));
    const d2 = new Set();
    for (const t of d1) for (const x of out.get(t) || []) {
      if (x !== id && !d1.has(x)) d2.add(x);    // 去重排除直接与自身
    }
    return { id, direct: d1.size, second: d2.size };
  });
  return rows.sort((a, b) => (b.direct + b.second) - (a.direct + a.second)
    || (a.id < b.id ? -1 : 1));
}
const nodes = [{ id: 'A', team: 'fe' }, { id: 'B', team: 'be' }, { id: 'C', team: 'qa' }, { id: 'D', team: 'fe' }];
const edges = [['A','B'],['A','C'],['B','D']];
console.log(influenceScore(nodes, edges));
// A: direct 2, second 1；B: direct 1, second 0
```

**评分点**：
- 二度影响的去重语义（排除自身与直接节点）正确
- 出边方向 = 影响方向（方向搞反全错，高频错误）
- 排序含并列字典序稳定
- 能讨论：用途（识别协作网络中的关键节点/孤岛）、权重化扩展（帮助的强度/双向关系）、与团队维度的交叉分析（跨团队影响更值钱）
