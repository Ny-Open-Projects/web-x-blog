## SOFT-305：被裁后要不要立刻签离职协议——签字前的核对与缓冲？

**答**:
- 不立刻签原则：离职协议签字即生效，你有权要求"带走看/咨询后再签"（合理且常见）——公司催签的急迫感是它的需求，不是你的义务。
- 签前核对七项：补偿金额与支付时间、竞业是否启动（启动则补偿金条款要写明）、年假折算、奖金按比例、社保公积金截止月、离职证明的表述（"协商一致解除"，不是"个人原因"）、股票期权处置条款。
- 谈判杠杆：签字前是筹码最大时刻——"我可以今天签，但 X 条项需要调整"（一次性打包换签），签完就没得谈了。
- 红线复盘：任何条款模糊（"补偿面议""竞业另行通知"）一律要求写清楚——书面化纪律（SOFT-249）同样适用于离职场景。

```text
离职协议签字前七查：
[ ] 补偿金额 + 支付时间
[ ] 竞业是否启动 + 补偿金条款
[ ] 年假折算
[ ] 奖金按比例
[ ] 社保公积金截止月
[ ] 离职证明表述（"协商一致解除"）
[ ] 股票期权处置
策略："今天可以签，但 X 需要先改"——
  打包换签，签后无谈判筹码。
红线：模糊条款（面议/另行通知）必须写清。
```
