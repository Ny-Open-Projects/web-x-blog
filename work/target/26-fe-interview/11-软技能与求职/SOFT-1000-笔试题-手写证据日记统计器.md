## 1000：笔试手写：实现晋升证据的维度覆盖统计与缺口提示

**答**：实现 evidence(records, required)：records 为 { dim: string, date: string }[]（按时间升序），required 为维度数组（目标职级的标准维度）。输出 { coverage: { dim: count }（全部 required 维度都给 key，缺的计 0）, missing: 缺证据维度数组, freshness: 最近一条证据距今超过 180 天的维度（staleness） }。

```js
const DAY = 86400000;
function evidence(records, required) {
  const cov = {}, last = {};
  for (const r of records) {
    cov[r.dim] = (cov[r.dim] || 0) + 1;
    last[r.dim] = r.date;
  }
  const coverage = {}, missing = [], staleness = [];
  const now = Date.now();
  for (const dim of required) {
    coverage[dim] = cov[dim] || 0;
    if (!cov[dim]) { missing.push(dim); continue; }
    if (now - new Date(last[dim]).getTime() > 180 * DAY) staleness.push(dim);
  }
  return { coverage, missing, staleness };
}
const recs = [
  { dim: 'tech', date: '2026-06-01' },
  { dim: 'tech', date: '2026-10-01' },
  { dim: 'influence', date: '2026-01-01' },
];
console.log(evidence(recs, ['tech', 'influence', 'people']));
// { coverage: { tech: 2, influence: 1, people: 0 },
//   missing: ['people'],
//   staleness: ['influence'] }
```

**评分点**：
- required 全维度给 key（缺的计 0），missing 与 coverage 一致
- freshness 用「该维度最近一条」判断超 180 天
- 日期解析与毫秒换算正确
- 能讨论：用途——季度自查看证据覆盖与新鲜度，避免年终才发现某维度全年空白
