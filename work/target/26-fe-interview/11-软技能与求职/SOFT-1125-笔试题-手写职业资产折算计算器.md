## 1125：笔试手写：实现多 offer 总包的税后与折算比较

**答**：实现 compare(offers)：offers 为 { name, base, bonus, equity: { type: 'rsu'|'option', annual, vestYears, discount } }[]。RSU 按annual×discount 折算，期权按 annual×discount²（双重折扣）；统一按 4 年总包 = (base+bonus)×4 + equity 年均×min(vestYears,4)；结果按总包降序，保留整数。

```js
function compare(offers) {
  return offers.map(o => {
    const eq = o.equity;
    const eff = eq.type === 'rsu'
      ? eq.annual * eq.discount
      : eq.annual * eq.discount * eq.discount;   // 期权双重折扣
    const total = (o.base + o.bonus) * 4 + eff * Math.min(eq.vestYears, 4) / 4;
    return { name: o.name, total: Math.round(total) };
  }).sort((a, b) => b.total - a.total);
}
console.log(compare([
  { name: 'A', base: 40, bonus: 10, equity: { type: 'rsu', annual: 30, vestYears: 4, discount: 0.8 } },
  { name: 'B', base: 45, bonus: 10, equity: { type: 'option', annual: 40, vestYears: 4, discount: 0.5 } },
]));
// A: 200 + 30*0.8*1 = 224；B: 220 + 40*0.25*1 = 230
```

**评分点**：
- RSU 单折扣 vs 期权双折扣的模型区分（风险折价叠加）
- 4 年总包公式中 equity 年均 × min(vestYears,4)/4（vestYears<4 时按实际摊入）
- 排序与取整统一
- 能讨论：模型假设的局限（discount 应随公司阶段调整）、税后口径的进阶（RSU 即时税负 vs 期权递延）、vestYears<4 的处理合理性
