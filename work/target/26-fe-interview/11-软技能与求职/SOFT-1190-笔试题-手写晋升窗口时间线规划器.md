## 1190：笔试手写：实现晋升准备的倒排时间线生成器

**答**：实现 planTimeline(defenseDate)：defenseDate 为 'YYYY-MM-DD'。生成倒排计划：W-6~5 材料写作（10 个工作日）、W-4 弹药包（3 个工作日）、W-3~2 彩排（4 个工作日）、W-1 轻维护（2 个工作日）、W0 答辩。输出 [{ phase, start, end, days }]（按开始时间升序），日期用工作日推进（跳过周末，简化：所有日期按自然日减 7 的倍数推算即可——按周粒度）。周粒度输出即可：每阶段 { phase, weeksBefore: [6,5], days }。

```js
const PLAN = [
  { phase: '材料写作', weeks: [6, 5], days: 10 },
  { phase: '弹药包',   weeks: [4],    days: 3 },
  { phase: '彩排',     weeks: [3, 2], days: 4 },
  { phase: '轻维护',   weeks: [1],    days: 2 },
];
function planTimeline(defenseDate) {
  const d = new Date(defenseDate);
  const items = PLAN.map(p => {
    const end = new Date(d); end.setDate(end.getDate() - p.weeks[0] * 7);
    const start = new Date(d); start.setDate(start.getDate() - (p.weeks.at(-1) + 1) * 7 + 1);
    return { phase: p.phase, start: start.toISOString().slice(0, 10),
      end: end.toISOString().slice(0, 10), days: p.days };
  });
  items.push({ phase: '答辩', start: defenseDate, end: defenseDate, days: 1 });
  return items;
}
console.log(planTimeline('2026-12-15'));
// 各阶段含 W-6..W0，升序，答辩最后
```

**评分点**：
- 倒排计算正确：阶段结束 = 答辩日 - 起始周×7；起点 = 更远周推算
- 答辩日作为最后一项、整体按时间升序
- ISO 日期格式化统一
- 能讨论：工作日粒度的进阶（跳过周末与节假日需工作日历）、计划与实际偏差的周度回顾机制
