## SOFT-493：手写一份谈薪攻防脚本——覆盖锚定、压价、僵局三个场景？

**需求与边界**：
- 场景：① HR 问期望薪资（锚定）；② HR 说"预算有限"（压价）；③ 双方各执一词（僵局）。
- 边界要求：① 不报"当前薪资底数"但可报结构；② 每个场景给出话术 + 底线条件（低于 __ 走人）；③ 语气克制，全程无威胁性表述。

**答**（三场景攻防脚本）:
```javascript
const scripts = {
  anchor: { // 锚定：报期望区间，下沿=自己可接受值
    say: '我的期望总包在 X 到 Y（X=可接受下沿），结构上 base 与股票并重。' +
         '可先了解贵司这个职级的 band 是多少？', // 反问取情报
    rule: '先让对方出价；对方坚持先报 → 报区间且 X=真实底线',
  },
  squeeze: { // 压价："预算有限"
    say: '理解预算约束。我有另一家书面 offer 在 __（同级），' +
         '如果 base 差距大，能否用签字费/年终系数/职级来平衡？' +
         '如果整体差 __% 以上，我可能只能遗憾选择。',
    rule: '用书面 offer 做杠杆（不吹牛）；谈结构不谈单一数字；底线明说但不威胁',
  },
  deadlock: { // 僵局：各执一词
    say: '我们差距在 __，我的依据是 __（市场 band/offer 对照）。' +
         '建议这样：我接受 __（让步顺序：先让小项），' +
         '同时希望 __（换大项：职级/股票）。',
    rule: '让小换大；僵持超过两轮 → 感谢+保留窗口（"条件变化随时联系我"）',
  },
};
// 自检：三场景齐；每场景有话术+规则+底线；
// 无"你们不给我就去别家"式威胁；书面 offer 未到手不引用具体数字。
```

**评分点**:
- 三场景脚本完整，锚定用"区间+下沿=底线+反问"的正确技术而非裸报数字。
- 压价场景用书面 offer 做杠杆、谈结构组合而非单点 base，姿态专业无威胁性。
- 僵局场景有让步顺序设计（让小换大）与退出机制，脚本可执行。
- 底线明确（低于 __ 走人），且全程未泄露当前薪资底数。
