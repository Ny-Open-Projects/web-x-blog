## SOFT-495：手写离职原因话术脚本——标准版 30 秒 + 追问防御版？

**需求与边界**：
- 场景：被问"为什么离职"，需覆盖三种追问：① 追问真实原因细节；② 追问"是不是和领导有矛盾"；③ 追问"来了我们这会不会也待不住"。
- 边界要求：① 全程不抱怨前司/领导；② 事实可裁剪但不可虚构（背调一致性）；③ 标准版与追问版方向必须一致（口径统一）。

**答**（话术脚本）:
```javascript
const exitScript = {
  standard: // 30s 标准版：正向动机 + 客观事实佐证
    '我在前司三年，从业务开发做到了前端基建（事实佐证）。' +
    '下一步想在 __ 方向做深，贵司的业务正好是 __，' +
    '所以这次选择是主动的方向调整。',
  defense: {
    q1_detail: // 追问细节：补事实不加情绪
      '更具体说：前司的业务重心转向 __，而我积累的方向是 __，' +
      '继续做下去和我的方向会有偏差——这是主要考量。',
    q2_conflict: // 追问矛盾：承认摩擦但不人格化
      '合作中观点碰撞很正常，我们对方案有过分歧但流程上都解决了，' +
      '离开的原因是方向不是关系。',
    q3_stability: // 追问稳定性：用"决策依据"证明不是冲动型
      '我的每次选择都是看方向匹配度，这次来之前我研究了贵司 __，' +
      '判断长期做这个方向——正因为慎重，所以才站得住。',
  },
  rules: // 纪律
    ['三不：不抱怨/不虚构/不矛盾',
     '事实层（时间/职级）全流程一字不差',
     '叙事层可按 JD 调取景，方向不变'],
};
// 自检：三问防御齐备；标准版含事实佐证；
// 无一处指责前司；方向在所有版本中恒定。
```

**评分点**:
- 标准版含事实佐证（做了什么），不是空谈"想成长"。
- 三个追问方向防御齐全，其中"矛盾题"用"对事不对人"的措辞化解。
- 有口径一致性纪律（时间/职级/方向全网统一），意识到背调交叉验证。
- 全程零抱怨零贬低，"主动选择"叙事成立且不显心虚。
