## SOFT-455：站在面试官视角——他们手里的评分表长什么样？

**答**:
- 评分维度拆解：多数大厂面试官按四维打分（基础深度/工程与项目质量/解题思维/沟通协作），每维 1~4 分——答题是在四个格子里填分，只强一格（如算法）不会通关，明显弱一格（沟通混乱）会一票否决。
- 信号采集逻辑：面试官不会问你简历没写的东西（怕偏题），你的每个项目描述都是在"喂"下一题——简历上的每个词都要经得起 3 层追问，写"性能优化"就要备好指标/手段/结果。
- 潜台词解码："回去等通知"= 挂；"你有什么想问的"= 最后一维加分题；"我们这边节奏快"= 在筛加班意愿；追问"还有吗"= 答案不够深或不够全——听懂潜台词才能及时补救。
- 自我审视练习：把自己的简历交给同行模拟面试官 20 分钟，记录他的评分与顾虑——顾虑清单就是下次面试的改进清单。

```text
面试官评分表（四维 1~4 分）：
基础深度 __ / 工程质量 __ /
解题思维 __ / 沟通协作 __
信号采集：简历每个词 = 下一题的引子
  → 每个词备好 3 层追问
  （是什么 / 怎么做 / 量化结果）
潜台词："还有吗"→ 答深答全；
  "节奏快"→ 筛加班意愿；
  反问环节 = 最后一维加分题。
练习：同行模拟面试官 20min，
  记录顾虑清单 = 改进清单。
```
