## 1086：「没做成的项目」在答辩里怎么讲（否决案例）

**答**：
- 区分两种「非重点」：未达预期但学到了（讲——失败-根因-复用三段）、被砍掉/没做成的（选择讲「立项判断」——「当时我判断 X 不该做，后来业务变化验证了」——「没做」也可以是判断力证据）。
- 「不做」的证据价值：工程资源有限，「决定不做什么」的判断在高职级答辩权重高——准备 1 个「否决案例」（你论证砍掉了某项目，避免了 N 损失）。
- 呈现格式：否决案例用「反事实」讲——「如果做了会消耗 [N 人月]，实际我们把这些资源投向了 [Y]，Y 成功了」——资源再分配的决策链是最高级的工程师叙事。
- 诚实前提：否决必须是你真实参与的判断（挂名否决会被追问穿帮）——证据链原则适用于所有叙事。

```text
「没做成」的两种讲法：
失败但有学 -> 失败-根因-复用三段
被砍掉 -> 立项判断：「不做」的反事实验证
格式：否决 -> 避免损失 N -> 资源转投 Y -> Y 成功
前提：真实参与的判断（证据链）
```
