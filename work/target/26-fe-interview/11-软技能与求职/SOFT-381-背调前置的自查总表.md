## SOFT-381：背调自查总表——投递前把背调先在脑子里跑一遍？

**答**:
- 五项预演：时间线（与社保/合同一致，空窗如实）、公司名（主体名+品牌名双写）、职级（换算成对方体系表述）、离职原因（中性口径 SOFT-290）、联系人（质量经营 SOFT-289）——五项全绿投递。
- 预演方法：假装自己是背调员，拿着自己的简历给每个信息点问"怎么核实"——核实路径清晰的信息才放行。
- 红线再确认：薪资/学历/年限/竞业四个硬项零包装空间——SOFT-238 的判断准则（可验证+大损失=如实）。
- 动态维护：换公司/换城市后重跑预演（社保记录变化会让旧口径失效）。

```text
背调五项预演表：
[ ] 时间线 = 社保/合同（空窗如实）
[ ] 公司名 = 主体名+品牌名
[ ] 职级 = 对方体系表述
[ ] 离职原因 = 中性口径（SOFT-290）
[ ] 联系人 = 已打招呼（SOFT-289）
方法：假装自己是背调员，
  每个信息点问"怎么核实"。
硬项零包装：薪资/学历/年限/竞业。
维护：换公司/城市后重跑。
```
