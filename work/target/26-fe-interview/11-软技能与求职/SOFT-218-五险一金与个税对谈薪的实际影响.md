## SOFT-218：五险一金与个税怎么影响谈薪——base 的隐性价值怎么算？

**答**:
- base 的隐性价值三块：公积金（单位同比例缴纳，直接进你账户，等于 5%~12% 的免税加薪）、社保基数（影响养老与医疗待遇）、贷款与签证证明（流水和纳税记录以 base 为准）——所以"低 base 高补贴"的结构实际吃亏。
- 补贴类（餐补/房补/打车）多数计入个税且不进公积金基数——名义总包相同的情况下，"高 base 低补贴"的 offer 真实价值更高。
- 年终奖单独计税政策影响到手：大额年终按单独计税更划算，问清公司是否支持选择单独计税（影响实际到手几个点）。
- 谈判应用：结构优先级 base > 现金奖金 > 补贴 > 期权；当对方以"补贴高"替代 base 时，用公积金与社保基数的差额算给他看。

```text
base 隐性价值速算：
base 40k vs base 35k+补贴 5k（名义同 45k 池）：
公积金差：40k×12% − 35k×12% = 600/月（单位缴，
  免税进个人账户）→ 年 7200
社保基数 / 流水证明 / 贷款额度 全部受益于高 base
补贴部分：多数计税、不进公积金基数

年终计税：问"是否支持单独计税"，
大额年终单独计税通常省 1~3 个点到手。

结构优先级：base > 现金奖金 > 补贴 > 期权。
```
