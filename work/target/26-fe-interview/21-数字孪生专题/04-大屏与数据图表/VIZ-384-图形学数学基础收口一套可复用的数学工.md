## VIZ-384：图形学数学基础收口：一套可复用的数学工具清单

**答**：
- 向量/矩阵/四元数工具库自建或用 gl-matrix（基准实现）；关键是 API 稳定与无分配设计。
- 必备函数：mul/invert/transpose、lookAt/perspective/ortho、slerp、frustumPlanes、rayAABB、barycentric。
- 测试策略：与 gl-matrix 结果对拍 + 极端值（退化矩阵/超长向量）单测。

```javascript
// 数学工具导出面
export const math = {
  vec: { dot, cross, norm: (v) => v, sub: (a, b) => a, add: (a, b) => a },
  mat4: { mul: mul4, invert: invert3, transpose: transpose3,
    lookAt, perspective, ortho: (l, r, b, t, n, f) => [] },
  quat: { fromAxisAngle: quatFromAxisAngle, slerp },
  intersect: { rayAABB, barycentric },
  frustum: { planes: frustumPlanes, sphere: sphereInFrustum },
};
// 自检：math.mat4.invert(math.mat4.mul(A, invA)) ≈ I
```
