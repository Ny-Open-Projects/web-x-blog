## VIZ-288：手写图表交互指引：空状态与首次使用引导

**答**：
- 图表空状态：无数据/数据不足 → 引导性空态（插画 + 说明 + 操作按钮），非空白。
- 首次使用引导：新用户首次见复杂图表 → 气泡引导（缩放/刷选怎么用），localStorage 标记已读。
- 实现：emptyState 检测（数据长度/全空）→ 渲染空态层；coach-mark 浮层。

```javascript
function chartEmptyState(data, cfg) {
  if (!data?.length)
    return { empty: true, reason: 'no-data',
      title: '暂无数据', hint: '数据将在采集后展示', action: '刷新' };
  if (data.every(d => d.v == null))
    return { empty: true, reason: 'all-null',
      title: '数据尚未就绪', hint: '计算中，预计 2 分钟', action: null };
  return { empty: false };
}
function coachMarks(container, steps) {                    // 首次引导
  if (localStorage.getItem('chart-coach-done')) return;
  let i = 0;
  const show = () => {
    const step = steps[i];
    const bubble = createBubble(container, step.target, step.text);   // 定位气泡
    bubble.onclick = () => { i++ < steps.length ? show() : (bubble.remove(),
      localStorage.setItem('chart-coach-done', '1')); };
  };
  show();
}
```
