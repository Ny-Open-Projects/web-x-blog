## VIZ-297：可视化数据血缘：图表数据来源追踪与刷新链

**答**：
- 数据血缘：图表 → 数据集 → 查询 → 源表——血缘链用于「数据变更影响面」（源表变更通知相关图表失效）。
- 实现：图表注册数据依赖（dataset id + 查询指纹）；数据层变更事件沿血缘传播 → 相关图表 markDirty。
- 价值：数据更新及时性（图表自动刷新）与排查（数字不对时溯源）。

```javascript
class DataLineage {
  constructor() { this.graph = new Map(); }                 // datasetId → Set<chartId>
  register(chartId, datasetId, queryFingerprint) {
    (this.graph.get(datasetId) ?? this.graph.set(datasetId, new Set()).get(datasetId))
      .add({ chartId, fingerprint: queryFingerprint });
  }
  invalidate(datasetId) {                                   // 数据变更传播
    for (const { chartId, fingerprint } of this.graph.get(datasetId) ?? []) {
      const chart = charts.get(chartId);
      if (chart.queryFingerprint !== fingerprint) continue;   // 查询仍匹配才失效
      chart.markDirty();
      report('lineage-invalidate', { datasetId, chartId });
    }
  }
  trace(chartId) {                                          // 溯源：图表 → 源表
    return [...this.graph].filter(([, charts]) =>
      [...charts].some(c => c.chartId === chartId)).map(([ds]) => ds);
  }
}
```
