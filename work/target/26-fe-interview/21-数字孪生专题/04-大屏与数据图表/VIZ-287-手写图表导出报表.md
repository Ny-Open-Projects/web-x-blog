## VIZ-287：手写图表导出报表：多图合成一页 PDF 排版

**答**：
- 题目：仪表盘导出 PDF——多图表排版到 A4（网格布局）+ 标题页脚 + 分页。jsPDF + 离屏渲染图表。
- 思路：A4 尺寸网格（2 列×N 行）；逐图离屏渲染 → toDataURL → jsPDF addImage；超出页高分页；页眉页脚统一。
- 评分点：网格排版计算；分页逻辑；离屏渲染 DPI。

```javascript
async function exportDashboardPDF(charts, { title = '数据报告' } = {}) {
  const { jsPDF } = await import('jspdf');
  const pdf = new jsPDF('p', 'mm', 'a4');                  // A4
  const pageW = 210, pageH = 297, margin = 10;
  const cols = 2, cellW = (pageW - margin * 2) / cols;
  const cellH = 70;
  let page = 0, row = 0, col = 0;
  pdf.text(title, pageW / 2, 15, { align: 'center' });
  for (const chart of charts) {
    const y = 25 + row * (cellH + 5);
    if (y + cellH > pageH - 15) { pdf.addPage(); page++; row = 0; }   // 分页
    const img = await renderChartOffscreen(chart, { dpi: 2 });   // 离屏渲染
    pdf.addImage(img, 'PNG', margin + col * cellW, 25 + row * (cellH + 5), cellW - 5, cellH);
    col = (col + 1) % cols;
    if (col === 0) row++;
  }
  pdf.save('dashboard.pdf');
}
```
