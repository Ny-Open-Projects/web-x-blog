## VIZ-267：手写词云布局：螺旋放置与碰撞检测

**答**：
- 题目：词云——词语按权重从大到小，沿螺旋找不碰撞位置放置。碰撞检测：包围盒重叠（或像素级 mask）。
- 思路：阿基米德螺旋 (t·cos t, t·sin t)；包围盒碰撞（快速）或位图 mask（精确）；放不下降字号重试。
- 评分点：螺旋参数化；碰撞检测两级（包围盒粗筛+像素精查）；降级重试。

```javascript
function wordCloudLayout(words, { width = 600, height = 400 } = {}) {
  const sorted = [...words].sort((a, b) => b.weight - a.weight);
  const placed = [];
  for (const w of sorted) {
    const size = Math.max(12, Math.min(48, w.weight * 4));  // 权重→字号
    const box = measureWord(w.text, size);
    let placed_ok = false;
    for (let t = 0; t < 500 && !placed_ok; t += 0.35) {     // 螺旋搜索
      const x = width / 2 + t * 6 * Math.cos(t);
      const y = height / 2 + t * 6 * Math.sin(t);
      const rect = { x: x - box.w / 2, y: y - box.h / 2, w: box.w, h: box.h };
      if (rect.x < 0 || rect.y < 0 || rect.x + rect.w > width || rect.y + rect.h > height)
        continue;
      if (!placed.some(p => rectsOverlap(rect, p.rect))) {   // 包围盒碰撞
        placed.push({ text: w.text, size, rect, rotate: t % 2 < 1 ? 0 : 90 });   // 交替横竖
        placed_ok = true;
      }
    }
    // 放不下：降字号重试或跳过（省略）
  }
  return placed;
}
```
