## VIZ-294：可视化错误上报：图表级错误聚合与归因

**答**：
- 图表错误分类：数据错误（schema 不符）、渲染错误（GPU/Canvas 异常）、交互错误（事件处理异常）——分型聚合（同 HW-329 指纹）。
- 归因字段：图表类型/数据量级/浏览器/引擎版本——定位是「数据问题」还是「渲染兼容问题」。
- 告警：错误率突增（发版回归）自动阻断（HW-846 哨兵）。

```javascript
class VizErrorReporter {
  capture(error, ctx) {
    const kind = /schema|field/.test(error.message) ? 'data'
      : /WebGL|WebGPU|context/.test(error.message) ? 'render'
      : 'interaction';
    this.aggr ??= new Map();
    const fp = kind + '|' + ctx.chartType + '|' + normalize(error.message);
    const cur = this.aggr.get(fp) ?? { count: 0, first: Date.now() };
    cur.count++;
    this.aggr.set(fp, cur);
    if (cur.count === 1) send({ kind, fp, ctx: {            // 首次上报带全量上下文
      chartType: ctx.chartType, dataRows: ctx.rows,
      engine: ctx.engine, ua: navigator.userAgent } });
  }
  alertThreshold({ baseline, current }) {
    return current > baseline * 2;                          // 发版回归哨兵
  }
}
```
