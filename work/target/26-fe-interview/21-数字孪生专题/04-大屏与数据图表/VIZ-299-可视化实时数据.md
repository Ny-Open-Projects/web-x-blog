## VIZ-299：可视化实时数据：WebSocket 推送与图表增量更新

**答**：
- 题目：实时图表（秒级推送）——WS 推送新点 → 图表增量更新（追加尾部 + 滑出头部），不整图重算。洪泛缓冲（HW-767 思想）。
- 思路：环形数据窗口（固定 N 点）；新点 append，旧点 shift（环形缓冲）；增量渲染（只画新段）；推送洪泛合帧。
- 评分点：环形窗口；增量渲染 vs 全量；洪泛合帧节流。

```javascript
class RealtimeChart {
  constructor(capacity = 300) {
    this.buffer = new Array(capacity); this.head = 0; this.count = 0;
    this.pending = null;
  }
  push(point) {                                            // WS 推送到达
    this.buffer[this.head] = point;
    this.head = (this.head + 1) % this.buffer.length;
    this.count = Math.min(this.count + 1, this.buffer.length);
    if (!this.pending) this.pending = requestAnimationFrame(() => this.flush());   // 合帧
  }
  flush() {                                                // rAF 合帧渲染
    this.pending = null;
    const ordered = [];
    for (let i = 0; i < this.count; i++)
      ordered.push(this.buffer[(this.head - this.count + i + this.buffer.length) % this.buffer.length]);
    this.renderer.paintIncremental(ordered);               // 增量：只画新段 + 移出旧段
  }
}
// 全量重绘 300 点 ≈ 2ms 可接受；万点实时 → 增量渲染 + 降采样窗口
```
