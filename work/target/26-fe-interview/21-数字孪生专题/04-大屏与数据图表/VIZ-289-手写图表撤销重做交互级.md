## VIZ-289：手写图表撤销重做（交互级）：视图状态历史

**答**：
- 题目：图表交互撤销（Ctrl+Z 恢复上个缩放/刷选状态）——视图状态（domain/brush/series 可见性）历史栈。
- 思路：状态快照（轻量对象）入栈（上限 20）；undo/redo 出栈恢复；与数据变更区分（数据变清空视图历史）。
- 评分点：视图状态可序列化；栈上限；数据变更清历史。

```javascript
class ViewStateHistory {
  constructor(chart, { limit = 20 } = {}) {
    this.chart = chart; this.undoStack = []; this.redoStack = []; this.limit = limit;
    chart.on('view-change', (state) => {                     // 缩放/刷选时入栈
      this.undoStack.push(state);
      if (this.undoStack.length > this.limit) this.undoStack.shift();
      this.redoStack = [];
    });
  }
  undo() {
    if (this.undoStack.length < 2) return;                   // 当前态占一格
    this.redoStack.push(this.undoStack.pop());
    this.chart.restoreView(this.undoStack.at(-1));           // 恢复上一视图
  }
  redo() {
    const s = this.redoStack.pop();
    if (!s) return;
    this.undoStack.push(s);
    this.chart.restoreView(s);
  }
  onDataChange() { this.undoStack = []; this.redoStack = []; }   // 数据变清历史
}
```
