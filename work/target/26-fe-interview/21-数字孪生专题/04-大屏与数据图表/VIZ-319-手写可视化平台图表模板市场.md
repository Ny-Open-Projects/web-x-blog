## VIZ-319：手写可视化平台图表模板市场：模板发现与实例化（笔试）

**答**：
- 题目：BI 平台图表模板市场——模板（option+数据契约+缩略图）注册/搜索/实例化（用户数据套模板）。模板与数据契约校验。
- 思路：模板 {id, option, contract: {requiredFields, types}, thumbnail}；实例化：用户数据过 contract 校验 → 映射字段 → 渲染；搜索：标签/名称模糊（复用 ALG-403）。
- 评分点：模板结构；契约校验；字段映射。

```javascript
class TemplateMarket {
  register(template) {                                     // 模板注册
    this.templates.set(template.id, template);
    searchIndex.addDoc({ id: template.id, text: template.name + ' ' + template.tags.join(' ') });
  }
  instantiate(templateId, userDataset, fieldMapping) {     // 实例化
    const tpl = this.templates.get(templateId);
    const check = validateDataContract(userDataset, tpl.contract);   // 契约校验
    if (!check.valid) return { ok: false, errors: check.errors };   // 缺字段/类型不符
    const option = instantiateOption(tpl.option, fieldMapping);   // 字段映射注入
    return { ok: true, option, preview: tpl.thumbnail };
  }
  search(query) { return localSearch(query, this.templates, { limit: 10 }); }
}
// 契约示例：{ requiredFields: ['category', 'value'], types: { value: 'number' } }
// 实例化：用户「月份/销售额」映射到模板「category/value」
```
