## VIZ-469：手写一个渲染队列排序器（不透明/透明双序）

**答**：
- 需求：implement sortQueue(draws, cameraPos)。draws 含 { transparent, program, texture, pos }；不透明按 (program, texture, 与相机距离升序)；透明按距离降序（混合正确）；program/texture 优先于距离（状态切换最少）；输出 { opaque, transparent }。
- 边界：无 program/texture 字段按 -1；距离用 pos 与 cameraPos；draws 为空返回空列表。
- 评分点：双列表；排序键优先级；距离平方；透明反序

```javascript
function sortQueue(draws, cameraPos) {
  const dist2 = d => {
    if (!d.pos) return 0;
    return d.pos.reduce((s, v, i) => s + (v - cameraPos[i]) ** 2, 0);
  };
  const opaque = draws.filter(d => !d.transparent).sort((a, b) =>
    (a.program ?? -1) - (b.program ?? -1) ||
    (a.texture ?? -1) - (b.texture ?? -1) ||
    dist2(a) - dist2(b));
  const transparent = draws.filter(d => d.transparent)
    .sort((a, b) => dist2(b) - dist2(a));            // 远->近
  return { opaque, transparent };
}
// 不透明近->远：early-z 剔除；透明远->近：混合顺序正确；
```
