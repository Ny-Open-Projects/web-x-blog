## VIZ-277：手写饼图与环形图：标签避让

**答**：
- 题目：饼图——扇区角度分配 + 标签避让（标签外置，重叠时上下错开）。引导线（label line）绘制。
- 思路：扇区 = 值占比 × 2π；标签位置 = 扇区中角方向外推；同侧标签重叠时按 y 排序错开（最小间距）；引导线 = 节点→拐点→标签。
- 评分点：角度分配；标签重叠错开算法；引导线折线。

```javascript
function pieLabels(slices, { radius = 100, labelDist = 30 } = {}) {
  let angle = -Math.PI / 2;
  const items = slices.map(s => {
    const span = s.value / s.total * 2 * Math.PI;
    const mid = angle + span / 2;
    const lx = Math.cos(mid) * (radius + labelDist);
    const ly = Math.sin(mid) * (radius + labelDist);
    angle += span;
    return { ...s, mid, lx, ly, side: Math.cos(mid) > 0 ? 'right' : 'left' };
  });
  // 同侧标签按 y 排序，重叠时错开
  for (const side of ['right', 'left']) {
    const group = items.filter(i => i.side === side)
      .sort((a, b) => a.ly - b.ly);
    for (let i = 1; i < group.length; i++)
      if (group[i].ly - group[i - 1].ly < 20)              // 最小间距
        group[i].ly = group[i - 1].ly + 20;                // 下推错开
  }
  return items;
}
```
