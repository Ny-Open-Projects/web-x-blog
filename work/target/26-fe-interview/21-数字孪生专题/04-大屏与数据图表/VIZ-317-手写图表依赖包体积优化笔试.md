## VIZ-317：手写图表依赖包体积优化（笔试）

**答**：
- 题目：图表库按需加载（bundle 拆分）——核心渲染 / 各图表类型 / 图标语言包按需 import；体积预算 CI 门禁。
- 思路：动态 import 各 chart type（用户只用折线不装热力）；sideEffects 标注 tree-shaking；体积分析报告（HW-844 复用）。
- 评分点：按需拆分策略；tree-shaking 标注；预算门禁。

```javascript
// 按需加载注册表
const chartLoaders = {
  line: () => import('./charts/line'),                     // 动态 import
  bar: () => import('./charts/bar'),
  sankey: () => import('./charts/sankey'),
  map: () => import('./charts/map'),                       // 地图最重（瓦片引擎）
};
class ChartFactory {
  static async create(type, el, option) {
    const loader = chartLoaders[type];
    if (!loader) throw new Error(`unknown-type: ${type}`);
    const { Chart } = await loader();
    return new Chart(el, option);
  }
}
// package.json："sideEffects": ["*.css"] —— 非 CSS 可 tree-shake
// 预算门禁：core < 40KB gzip，单图表 < 15KB——超限阻断（HW-843）
```
