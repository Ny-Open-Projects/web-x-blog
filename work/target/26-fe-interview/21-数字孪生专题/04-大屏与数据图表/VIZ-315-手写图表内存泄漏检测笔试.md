## VIZ-315：手写图表内存泄漏检测（笔试）

**答**：
- 题目：图表频繁创建销毁（路由切换）内存泄漏——泄漏检测：实例注册表 + 事件监听计数 + Heap Snapshot 对账。
- 思路：基类维护 static 实例集合；destroy 必须清事件/定时器/Worker；路由切换后对比存活实例数；heap snapshot 中按 constructor 分组计数。
- 评分点：实例对账；destroy 完整性清单；snapshot 分析方法。

```javascript
class ChartBase {
  static instances = new Set();
  constructor(el) {
    this.el = el;
    ChartBase.instances.add(this);
    this.disposers = [];                                    // 资源释放登记
    this._ro = new ResizeObserver(() => this.resize());
    this._ro.observe(el);
    this.disposers.push(() => this._ro.disconnect());
  }
  destroy() {
    this.disposers.forEach(d => d());                       // 完整释放
    ChartBase.instances.delete(this);
    this.el.innerHTML = '';
  }
  static leakCheck() {                                     // 路由切换后对账
    return { alive: ChartBase.instances.size,
      details: [...ChartBase.instances].map(c => c.el.dataset.chartId) };
  }
}
// Heap Snapshot 分析：Memory 面板 → 按 constructor 过滤 ChartBase → 数量应回归基线
// 常见泄漏源：全局事件未移除 / 定时器未清 / 闭包持有大数据
```
