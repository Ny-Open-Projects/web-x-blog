## VIZ-298：可视化大屏适配：等比缩放与滚动策略

**答**：
- 题目：大屏（1920×1080 设计稿）在多种屏幕投放——等比缩放（contain 模式留黑边）或流式布局（栅格自适应）；拼接屏（超宽）特殊处理。
- 思路：contain：scale = min(w/1920, h/1080) 居中（HW-366 复用）；流式：栅格布局（列数随宽度变化）；拼接屏：分区块独立适配。
- 评分点：两种模式取舍；拼接屏分块；缩放后文字清晰度（transform 缩放 vs 重排）。

```javascript
class BigScreenAdapter {
  fit(el, design, mode = 'contain') {
    const { clientWidth: w, clientHeight: h } = el.parentElement;
    const kx = w / design.w, ky = h / design.h;
    const scale = mode === 'contain' ? Math.min(kx, ky) : Math.max(kx, ky);
    Object.assign(el.style, {
      width: design.w + 'px', height: design.h + 'px',
      transform: `scale(${scale})`,
      transformOrigin: mode === 'contain' ? 'center' : '0 0',
    });
    if (mode === 'contain') {                              // 居中留黑边
      el.style.marginLeft = (w - design.w * scale) / 2 + 'px';
      el.style.marginTop = (h - design.h * scale) / 2 + 'px';
    }
    return scale;
  }
}
// 拼接屏（超宽 7680×1080）：分 4 个 1920 区块，各区块独立 contain 适配——避免整体拉伸变形
// 文字清晰度：transform 缩放在高分屏会有重采样模糊——关键文字用 rem+媒体查询流式布局
```
