## VIZ-320：手写可视化平台权限：图表行级权限与可见性

**答**：
- 题目：BI 图表权限——图表可见性（菜单级）+ 数据行级权限（不同人看不同行）+ 字段级脱敏。服务端裁决（HW-253 复用）。
- 思路：图表权限矩阵（role × chart）；行级：查询带用户上下文（服务端过滤）；字段级：返回数据按角色裁剪列。
- 评分点：三层权限；服务端裁决；脱敏联动（VIZ-259）。

```javascript
class VizPermission {
  async resolveChart(chartId, user) {
    const perm = await authz.can(user.roles, `chart:${chartId}`, 'read');
    if (!perm) return { visible: false };                  // 图表级
    const rowFilter = await authz.getRowScope(user, chartId);   // 行级（服务端裁决）
    const fieldMask = await authz.getFieldMask(user, chartId);   // 字段级
    return { visible: true, rowFilter, fieldMask,
      note: '行级过滤在服务端查询时生效，前端只做展示' };
  }
  applyFieldMask(data, mask) {
    return data.map(row => Object.fromEntries(
      Object.entries(row).filter(([k]) => !mask.includes(k))));   // 裁剪列
  }
}
// 铁律：行级权限必须服务端裁决——前端过滤可被绕过（网络层可见全量数据）
```
