## VIZ-246：大屏可视化性能：多图表同屏的合成优化

**答**：
- 大屏 20+ 图表：合成层爆炸（每 canvas 一层）→ 合并渲染（单 canvas 多 viewport，VIZ-219）或分帧渲染（每帧只更新变化的图表）。
- 分帧渲染：脏图表优先（数据变更的），静止图表跳过；每帧最多重绘 3 个。
- 数据刷新节流：大屏数据 5s 轮询 → 各图表错峰更新（防同帧全部重算）。

```javascript
class DashboardScheduler {
  constructor(charts) { this.charts = charts; this.dirty = new Set(); this.budget = 3; }
  markDirty(id) { this.dirty.add(id); }
  frame() {                                                // 每帧：预算内重绘
    let drawn = 0;
    for (const id of this.dirty) {
      if (drawn >= this.budget) break;                     // 帧预算
      this.charts.get(id).render();
      this.dirty.delete(id); drawn++;
    }
  }
  staggerRefresh(data) {                                   // 错峰刷新
    const charts = [...this.dirty];
    charts.forEach((id, i) => setTimeout(() => {
      this.charts.get(id).setData(data[id]); this.markDirty(id);
    }, i * 100));                                          // 每图错 100ms
  }
}
```
