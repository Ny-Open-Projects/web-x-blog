## VIZ-257：可视化埋点：图表交互行为漏斗

**答**：
- 图表埋点：渲染完成（render_done）、首次交互（first_hover）、缩放/刷选行为、导出行为——漏斗「渲染→看懂→交互→导出」。
- 实现：图表 SDK 内置埋点钩子（onRender/onInteract），业务方注入上报通道。
- 指标用途：衡量图表可读性（交互率低 = 用户看不懂）。

```javascript
class ChartTelemetry {
  constructor(chart, report) {
    this.report = report; this.fired = new Set();
    chart.on('render-done', () => this.fire('render_done'));
    chart.on('first-interact', () => this.fire('first_hover'));
    chart.on('zoom', () => this.fire('zoom'));
    chart.on('export', () => this.fire('export'));
  }
  fire(event) {
    if (this.fired.has(event)) return;                     // 每图一次
    this.fired.add(event);
    this.report('chart-funnel', { event, chartType: this.chart.type });
  }
  funnel() {                                               // 漏斗分析
    const stages = ['render_done', 'first_hover', 'zoom', 'export'];
    return stages.map(s => ({ stage: s, count: this.counts[s] ?? 0 }));
  }
}
// 洞察：first_hover 率 < 30% → 图表信息密度或配色有问题
```
