## VIZ-326：手写可视化平台分享链接：只读快照与权限（笔试）

**答**：
- 题目：图表分享——生成只读链接（带 token 与快照版本），接收者无需登录即可看（受限数据快照），过期与撤销。
- 思路：分享 token（随机串 + 过期时间）服务端校验；快照（生成时刻的数据 + 配置冻结）避免实时权限穿透；撤销 = token 黑名单。
- 评分点：token 校验；快照语义（不穿透实时权限）；撤销机制。

```javascript
class ShareLink {
  async create(chartId, user, { expiresInDays = 7 } = {}) {
    const perm = await authz.can(user.roles, `chart:${chartId}`, 'share');
    if (!perm) throw new Error('share-denied');
    const snapshot = await freezeSnapshot(chartId, user);    // 当前权限下的数据快照
    const token = crypto.randomUUID();
    await store.put('share:' + token, { snapshot, expires: Date.now() + expiresInDays * 86400e3,
      owner: user.id, revoked: false });
    return { url: `${origin}/share/${token}`, expiresInDays };
  }
  async view(token) {
    const rec = await store.get('share:' + token);
    if (!rec || rec.revoked || Date.now() > rec.expires)
      throw new Error('link-invalid-or-expired');
    return renderReadOnly(rec.snapshot);                     // 只读渲染（无交互钻取）
  }
  revoke(token, user) {                                      // 撤销
    return store.update('share:' + token, { revoked: true, revokedBy: user.id });
  }
}
```
