## VIZ-468：手写一个纹理流式加载调度器

**答**：
- 需求：实现 TextureStreamer(maxPerFrame=2MB)。enqueue(tex) 按优先级排队；tick() 处理预算内任务（模拟分块上传：任务分 chunk，chunk 完成释放预算）；输出 { loaded, remaining, budgetUsed }；同任务重复 enqueue 去重。
- 边界：单 chunk > 预算时占用全部预算；任务 progress 属性跟踪；队列为空 tick 返回空。
- 评分点：预算调度；分块进度；去重；预算占用

```javascript
class TextureStreamer {
  constructor(maxPerFrame = 2 * 1024 * 1024) {
    this.budget = maxPerFrame; this.queue = []; this.seen = new Set();
  }
  enqueue(tex) {   // tex: { id, chunks: [size...], uploadChunk(i) }
    if (this.seen.has(tex.id)) return;
    this.seen.add(tex.id);
    this.queue.push({ ...tex, progress: 0 });
  }
  tick() {
    let budget = this.budget; const loaded = [];
    while (this.queue.length && budget > 0) {
      const t = this.queue[0];
      const size = t.chunks[t.progress] ?? 0;
      if (size > budget && t.progress < t.chunks.length) break;   // 预算不够
      const used = Math.min(size, budget);
      t.uploadChunk(t.progress); t.progress++;
      budget -= used;
      if (t.progress >= t.chunks.length) {
        this.queue.shift(); loaded.push(t.id);
      }
    }
    return { loaded, remaining: this.queue.length,
      budgetUsed: this.budget - budget };
  }
}
```
