## VIZ-330：手写图表下钻链路：维度切换与数据联动（笔试）

**答**：
- 题目：BI 下钻——点击柱状图某月 → 下钻到该月的日明细 → 再下钻到明细行。下钻路径栈（可返回上级）、每级查询参数继承。
- 思路：drillStack [{level, filters}]；下钻 push filter，返回 pop；每级查询 = 父级 filters + 本级维度切换。
- 评分点：下钻栈；过滤参数继承；面包屑 UI 数据。

```javascript
class DrillDown {
  constructor(baseConfig) { this.stack = [{ level: 0, filters: [], dim: baseConfig.dim }]; }
  drill(value) {                                            // 点击某值下钻
    const top = this.stack.at(-1);
    this.stack.push({
      level: top.level + 1,
      filters: [...top.filters, { field: top.dim, value }],
      dim: nextLevelDim(top.level),                        // 月 → 日 → 明细
    });
    return this.query();
  }
  back() { this.stack.pop(); return this.query(); }
  async query() {
    const top = this.stack.at(-1);
    return fetchChartData({ ...this.baseConfig, dim: top.dim, filters: top.filters });
  }
  breadcrumbs() {                                           // 面包屑数据
    return this.stack.map((s, i) => ({
      level: s.level, dim: s.dim,
      value: i > 0 ? s.filters.at(-1).value : '总览',
      clickable: i < this.stack.length - 1,
    }));
  }
}
```
