## VIZ-313：手写大屏图表自适应重排（笔试）

**答**：
- 题目：大屏图表栅格布局随屏幕宽度重排——断点（≥1920 三列 / ≥1280 两列 / 其余单列）+ 图表 resize 监听重绘（ResizeObserver）。
- 思路：CSS Grid 断点 + ResizeObserver 监听每图容器尺寸 → 图表 resize() 重绘（防抖）；跨断点时布局重排动画可选。
- 评分点：断点栅格；ResizeObserver 防抖；重绘联动。

```javascript
function adaptiveDashboard(container, charts) {
  const layout = () => {
    const w = container.clientWidth;
    const cols = w >= 1920 ? 3 : w >= 1280 ? 2 : 1;
    container.style.gridTemplateColumns = `repeat(${cols}, 1fr)`;
  };
  const ro = new ResizeObserver(debounce((entries) => {
    for (const entry of entries) {
      const chart = charts.get(entry.target.dataset.chartId);
      chart?.resize(entry.contentRect.width, entry.contentRect.height);   // 重绘
    }
  }, 150));
  charts.forEach((_, el) => ro.observe(el));
  layout();
  addEventListener('resize', debounce(layout, 150));
  return () => ro.disconnect();
}
```
