## VIZ-311：手写图表数据窗口滑窗聚合（笔试）

**答**：
- 题目：大时序图「缩放到小时级」时需拉取细粒度数据——设计多粒度数据源（分钟/小时/天三级）+ 窗口切换时选粒度 + 补间平滑。
- 思路：粒度选择：窗口 < 1 天用分钟级，< 30 天小时级，否则天级；切换时新旧数据交叉淡入；边界对齐。
- 评分点：粒度选择规则；切换平滑；边界请求对齐。

```javascript
class MultiGranularitySource {
  pickGranularity(windowSpan) {                            // 窗口 → 粒度
    if (windowSpan < 86400e3) return '1min';               // < 1 天
    if (windowSpan < 30 * 86400e3) return '1hour';
    return '1day';
  }
  async load(window, { fade = true } = {}) {
    const gran = this.pickGranularity(window[1] - window[0]);
    if (gran === this.currentGran) return this.slice(window);   // 同粒度：本地切
    const fresh = await fetchSeries(this.metric, window, gran);
    this.currentGran = gran;
    this.onData(fresh, { fade });                           // 交叉淡入（VIZ-310 模式）
    return fresh;
  }
  asyncGranularity(points) {                               // 降采样到目标点数
    return points.length > 2000 ? m4Aggregate(points, 2000) : points;
  }
}
```
