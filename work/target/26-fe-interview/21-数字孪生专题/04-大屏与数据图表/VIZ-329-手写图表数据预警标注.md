## VIZ-329：手写图表数据预警标注：阈值线与异常标记

**答**：
- 题目：时序图上的预警标注——阈值线（横线+区间着色）、异常点标记（圆点+悬停详情）、预测带（置信区间阴影）。
- 思路：阈值线 mark（y = threshold 虚线 + 超限区域着色）；异常点 = 规则判定（3σ/MAD）散点；预测带 = 上下界 path 填充。
- 评分点：阈值渲染；异常判定注入；置信区间填充。

```javascript
function annotateAlerts(chart, { thresholds, anomalies, forecast }) {
  const marks = [];
  for (const th of thresholds ?? []) {                      // 阈值线
    marks.push({ type: 'hline', y: chart.scaleY(th.value), style: { dash: [4, 4], color: th.color },
      band: th.band ? { from: chart.scaleY(th.value), to: chart.scaleY(th.band) } : null });
  }
  for (const a of anomalies ?? []) {                        // 异常点
    marks.push({ type: 'scatter', x: chart.scaleX(a.t), y: chart.scaleY(a.v),
      color: a.severity === 'high' ? 'red' : 'orange',
      tooltip: `${a.rule}：实际 ${a.v}，预期 ${a.expected}±${a.tolerance}` });
  }
  if (forecast) {                                           // 预测带
    const upper = forecast.map(f => [chart.scaleX(f.t), chart.scaleY(f.upper)]);
    const lower = forecast.map(f => [chart.scaleX(f.t), chart.scaleY(f.lower)]).reverse();
    marks.push({ type: 'band', path: [...upper, ...lower], fill: 'rgba(91,143,249,0.15)' });
  }
  return marks;
}
```
