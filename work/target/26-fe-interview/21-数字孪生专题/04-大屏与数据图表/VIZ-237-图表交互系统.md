## VIZ-237：图表交互系统：缩放平移与数据窗口过滤

**答**：
- dataZoom 缩放平移：改变比例尺 domain（数据窗口）——不是缩放画布，而是过滤数据窗口重新映射。
- 实现：滚轮缩放（以光标为锚点，同 HW-347）；拖拽平移（domain 平移）；双击还原。
- 联动：多个图表共享 x 域（ALG-365 的刷选同步）。

```javascript
class DataZoom {
  constructor(scale, domain) { this.scale = scale; this.full = domain; this.window = [...domain]; }
  zoomAt(px, factor) {                                   // 以光标为锚
    const anchor = this.scale.invert(px);
    const [d0, d1] = this.window;
    const half = (d1 - d0) / 2 / factor;
    this.window = [anchor - half * (2 * (px / this.size) - 1) * (d1 - d0) / (d1 - d0) + (d0 + d1) / 2 - half,
      0];                                                // 简化为对称缩放 + 锚点修正
    this.window = [anchor - (anchor - d0) / factor, anchor + (d1 - anchor) / factor];   // 锚点不动
    this.onChange(this.window);
  }
  pan(dxPx) {
    const dv = this.scale.invert(dxPx) - this.scale.invert(0);
    this.window = this.window.map(v => v - dv);            // 平移
    this.onChange(this.window);
  }
}
// 缩放本质：window 变 → 比例尺 domain 重设 → 数据重映射——分辨率随窗口大小自适应
```
