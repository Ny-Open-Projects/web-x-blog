## VIZ-373：物理引擎接入：固定时间步与插值

**答**：
- 物理步长固定（1/60s 或 1/120s）保证确定性；渲染帧率波动时用累加器执行 0~N 步。
- 渲染插值：物理在 t 与 t+dt 两状态间按 alpha 插值，消除物理步与渲染帧不同步的抖动。
- 上限：每帧最多跑 5 步（防螺旋死亡——物理跟不上时越跑越多）。

```javascript
// 固定步长 + 插值
function gameLoop(render, physics, { dt = 1/60, maxSteps = 5 } = {}) {
  let acc = 0, last = performance.now();
  function frame(now) {
    acc += (now - last) / 1000; last = now;
    let steps = 0;
    while (acc >= dt && steps < maxSteps) {
      physics(dt); acc -= dt; steps++;
    }
    if (steps === maxSteps) acc = 0;               // 防螺旋
    const alpha = acc / dt;
    render(alpha);                                 // 插值渲染
    requestAnimationFrame(frame);
  }
  requestAnimationFrame(frame);
}
```
