## VIZ-307：手写图表无障碍焦点环（笔试）

**答**：
- 题目：键盘在数据点间导航——焦点环（当前点高亮描边）+ aria-live 播报 + Tab 进入/退出。完整实现。
- 思路：chart tabIndex=0；方向键移动 focusIndex；焦点点画描边环 + 播报；Escape 退出。
- 评分点：焦点环渲染；aria-live 节流播报；进出编辑态。

```javascript
class KeyboardNav {
  constructor(chart, data, series) {
    this.chart = chart; this.data = data; this.idx = -1;
    chart.el.tabIndex = 0;
    chart.el.addEventListener('keydown', (e) => this.onKey(e));
    this.live = createLiveRegion();                          // aria-live polite
  }
  onKey(e) {
    const dirs = { ArrowRight: 1, ArrowLeft: -1 };
    if (dirs[e.key]) {
      e.preventDefault();
      this.idx = clamp(this.idx + dirs[e.key], 0, this.data.length - 1);
      this.chart.drawFocusRing(this.data[this.idx]);        // 焦点环
      this.announce();                                      // 节流播报
    } else if (e.key === 'Escape') {
      this.chart.clearFocusRing(); this.idx = -1;
    }
  }
  announce() {
    clearTimeout(this.timer);
    this.timer = setTimeout(() => {                          // 150ms 节流
      const d = this.data[this.idx];
      this.live.textContent = `${d.x}，${this.series.map(s => `${s.name} ${d[s.field]}`).join('，')}`;
    }, 150);
  }
}
```
