## VIZ-295：可视化无障碍进阶：数据表格自动生成与导航

**答**：
- 题目：为复杂图表（多系列折线）生成「等价数据表格」（SR 可读）——按系列×时间点矩阵，并支持键盘在数据点间导航。
- 思路：表格结构 thead（时间）/tbody（系列行）；焦点环：方向键移动 focusPoint → aria-live 播报值；表格视觉隐藏但 SR 可读。
- 评分点：矩阵表格生成；焦点导航实现；aria-live 播报节流。

```javascript
function buildAccessibleTable(chart, data, series) {
  const table = document.createElement('table');
  table.className = 'sr-only';
  table.setAttribute('role', 'grid');
  table.innerHTML = `<caption>${chart.title}</caption>
    <thead><tr><th>时间</th>${series.map(s => `<th>${s.name}</th>`).join('')}</tr></thead>
    <tbody>${data.map(row => `<tr><th scope="row">${row.x}</th>${
      series.map(s => `<td>${row[s.field] ?? '—'}</td>`).join('')}</tr>`).join('')}</tbody>`;
  chart.el.appendChild(table);
  // 键盘导航：方向键移动数据点
  chart.el.addEventListener('keydown', (e) => {
    const dirs = { ArrowRight: 1, ArrowLeft: -1 };
    if (dirs[e.key]) {
      chart.focusIndex = clamp((chart.focusIndex ?? 0) + dirs[e.key], 0, data.length - 1);
      const row = data[chart.focusIndex];
      announce(`${row.x}，${series.map(s => `${s.name} ${row[s.field]}`).join('，')}`);   // aria-live
    }
  });
}
```
