## VIZ-239：图表数据契约：schema 校验与缺值处理

**答**：
- 题目：图表接收的数据格式不保证可靠——设计数据契约层：schema 校验（字段/类型/缺失）+ 缺值处理策略（跳过/插值/置零）+ 降级渲染。
- 思路：schema {xField, yFields[], types}；validate 返回错误清单；缺值策略 per-series 配置；校验失败降级为「错误占位图表」而非白屏。
- 评分点：schema 校验完整；缺值三策略；降级渲染。

```javascript
class DataContract {
  validate(data, schema) {
    const errors = [];
    if (!Array.isArray(data)) errors.push('data-not-array');
    data.forEach((row, i) => {
      if (row[schema.xField] == null) errors.push(`row ${i}: x 缺失`);
      for (const y of schema.yFields) {
        if (row[y] == null) continue;                     // 缺值允许（走策略）
        if (typeof row[y] !== 'number') errors.push(`row ${i}: ${y} 非数值`);
      }
    });
    return { valid: errors.length === 0, errors: errors.slice(0, 5) };
  }
  applyMissingPolicy(series, policy) {                     // 缺值策略
    if (policy === 'skip') return series.filter(d => d.v != null);           // 跳过
    if (policy === 'zero') return series.map(d => ({ ...d, v: d.v ?? 0 }));  // 置零
    if (policy === 'interpolate') return interpolateMissing(series);          // 线性插值
    return series;
  }
}
// 降级：校验失败 → 渲染错误占位（图标 + 错误摘要 + 重试按钮），不白屏
```
