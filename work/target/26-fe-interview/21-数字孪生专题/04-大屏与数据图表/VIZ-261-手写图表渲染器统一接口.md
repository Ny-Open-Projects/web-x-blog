## VIZ-261：手写图表渲染器统一接口：SVG/Canvas/WebGPU 可替换

**答**：
- 题目：实现渲染器抽象：IRenderer {begin, drawRect, drawPath, drawText, end}，三实现（SVG 生成/Canvas2D/WebGPU），图表逻辑只调接口。
- 思路：接口方法映射——drawRect → SVG rect 元素 / ctx.fillRect / GPU 实例；命令模式收集绘制指令再回放（便于 diff 与快照）。
- 评分点：接口完备性；命令缓冲设计（记录+回放）；各后端成本特征。

```javascript
class IRenderer {                                        // 统一接口约定
  begin(viewport) {} rect(x, y, w, h, style) {} path(points, style) {}
  text(x, y, str, style) {} end() {}
}
class SVGRenderer extends IRenderer {
  constructor() { super(); this.ops = []; }                 // 命令缓冲
  rect(x, y, w, h, style) { this.ops.push({ t: 'rect', x, y, w, h, ...style }); }
  path(points, style) { this.ops.push({ t: 'path',
    d: points.map((p, i) => `${i ? 'L' : 'M'}${p[0]},${p[1]}`).join(''), ...style }); }
  text(x, y, str, style) { this.ops.push({ t: 'text', x, y, str, ...style }); }
  end() {                                                   // 回放生成 SVG
    return this.ops.map(op => op.t === 'rect'
      ? `<rect x="${op.x}" y="${op.y}" width="${op.w}" height="${op.h}" fill="${op.fill}"/>`
      : op.t === 'path' ? `<path d="${op.d}" stroke="${op.stroke}" fill="none"/>`
      : `<text x="${op.x}" y="${op.y}">${op.str}</text>`).join('');
  }
}
class CanvasRenderer extends IRenderer {
  begin(viewport) { this.ctx = viewport.getContext('2d'); }
  rect(x, y, w, h, s) { this.ctx.fillStyle = s.fill; this.ctx.fillRect(x, y, w, h); }
  path(points, s) { this.ctx.beginPath();
    points.forEach((p, i) => i ? this.ctx.lineTo(p[0], p[1]) : this.ctx.moveTo(p[0], p[1]));
    this.ctx.strokeStyle = s.stroke; this.ctx.stroke(); }
  text(x, y, str, s) { this.ctx.fillText(str, x, y); }
  end() {}
}
// 图表逻辑只调接口——引擎切换零业务改动（VIZ-260 灰度的基础）
```
