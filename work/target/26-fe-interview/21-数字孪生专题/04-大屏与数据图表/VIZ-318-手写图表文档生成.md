## VIZ-318：手写图表文档生成：从 Schema 生成 API 文档（笔试）

**答**：
- 题目：图表库 API 文档自动化——从 TS 类型/Schema 生成文档（属性表/示例代码/默认值），与代码同步（CI 校验文档时效）。
- 思路：类型提取（ts-morph 解析 props 类型）→ 模板渲染 Markdown；CI 比对文档 hash（类型变了文档没更新则阻断）。
- 评分点：类型提取；模板渲染；时效校验。

```javascript
import { Project } from 'ts-morph';
function generateDocs(entryFile) {
  const project = new Project({ tsConfigFilePath: 'tsconfig.json' });
  const source = project.addSourceFileAtPath(entryFile);
  const props = source.getInterface('ChartProps');
  const rows = props.getProperties().map(p => ({
    name: p.getName(),
    type: p.getTypeNode()?.getText(),
    required: !p.hasQuestionToken(),
    default: p.getInitializer()?.getText() ?? '—',
    doc: p.getJsDocs()[0]?.getDescription().trim() ?? '',
  }));
  return `## ChartProps

| 属性 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
` +
    rows.map(r => `| ${r.name} | \`${r.type}\` | ${r.required ? '✓' : ''} | ${r.default} | ${r.doc} |`).join('\n');
}
// CI 时效校验：hash(extractTypes) vs docs 里记录的 hash——不一致阻断（提醒更新文档）
```
