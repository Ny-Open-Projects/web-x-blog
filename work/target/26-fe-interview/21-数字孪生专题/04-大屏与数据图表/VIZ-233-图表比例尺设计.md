## VIZ-233：图表比例尺设计：线性/对数/时间/序数比例尺统一接口

**答**：
- 题目：实现比例尺抽象——linear（线性映射）、log（对数）、time（时间分桶）、band（序数分带），统一 domain→range 接口与 invert。
- 思路：接口 {scale(v), invert(px), domain, range}；linear: (v-d0)/(d1-d0)*(r1-r0)+r0；log: 先 log 变换；band: 均分步长。
- 评分点：统一接口抽象；invert（交互反查数据）；band 的 padding 处理。

```javascript
class LinearScale {
  constructor(domain, range) { this.d = domain; this.r = range; }
  scale(v) {
    const [d0, d1] = this.d, [r0, r1] = this.r;
    return r0 + (v - d0) / (d1 - d0) * (r1 - r0);
  }
  invert(px) {
    const [d0, d1] = this.d, [r0, r1] = this.r;
    return d0 + (px - r0) / (r1 - r0) * (d1 - d0);
  }
}
class LogScale extends LinearScale {
  scale(v) { return super.scale(Math.log10(v)); }
  invert(px) { return Math.pow(10, super.invert(px)); }
  static niceDomain(min, max) {                          // 对数轴取整十域
    return [Math.pow(10, Math.floor(Math.log10(min))),
            Math.pow(10, Math.ceil(Math.log10(max)))];
  }
}
class BandScale {
  constructor(domain, range, { padding = 0.1 } = {}) {
    this.step = (range[1] - range[0]) / domain.length;
    this.inner = this.step * (1 - padding);
  }
  scale(v) { const i = this.domain.indexOf(v); return this.range[0] + i * this.step; }   // 返回带起点
  bandwidth() { return this.inner; }
}
```
