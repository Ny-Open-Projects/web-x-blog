## VIZ-325：手写可视化平台图表收藏与个人工作台（笔试）

**答**：
- 题目：BI 工作台——图表收藏夹（个人排序）、最近访问、快捷筛选预设。本地 + 服务端双存储同步。
- 思路：收藏 {chartId, order, presetFilters}；本地 localStorage 即时反馈 + 服务端持久化（冲突按时间戳合并）；LRU 最近访问（ALG-544 复用）。
- 评分点：双存储同步；冲突合并；LRU 最近访问。

```javascript
class WorkspaceStore {
  constructor() { this.local = JSON.parse(localStorage.getItem('ws-favs') ?? '[]'); }
  async toggleFav(chartId, presetFilters) {
    const i = this.local.findIndex(f => f.chartId === chartId);
    if (i >= 0) this.local.splice(i, 1);
    else this.local.push({ chartId, presetFilters, ts: Date.now() });
    localStorage.setItem('ws-favs', JSON.stringify(this.local));   // 本地即时
    const remote = await syncToServer(this.local);           // 服务端持久化
    return mergeByTimestamp(this.local, remote);             // 冲突按 ts 合并
  }
  mergeByTimestamp(local, remote) {
    const merged = new Map([...local, ...remote].map(f => [f.chartId, f]));
    return [...merged.values()].sort((a, b) => b.ts - a.ts);   // 后写胜
  }
  recentAccess(chartId) {                                    // 最近访问 LRU
    const recents = JSON.parse(localStorage.getItem('ws-recent') ?? '[]');
    const next = [chartId, ...recents.filter(id => id !== chartId)].slice(0, 10);
    localStorage.setItem('ws-recent', JSON.stringify(next));
  }
}
```
