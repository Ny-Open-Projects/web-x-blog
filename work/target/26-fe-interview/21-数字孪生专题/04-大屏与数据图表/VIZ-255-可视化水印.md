## VIZ-255：可视化水印：图表防截图溯源水印

**答**：
- 水印两层：可见水印（品牌/用户标识，半透明平铺）与盲水印（频域/LSB 隐写，截图溯源）。
- 实现：可见水印 canvas overlay（旋转平铺、pointer-events none）；盲水印简化版：像素 LSB 嵌入用户 ID hash。
- 局限声明：前端水印防「君子」不防专业截取——服务端渲染水印更可靠。

```javascript
function visibleWatermark(ctx, text, w, h) {
  ctx.save();
  ctx.globalAlpha = 0.06;
  ctx.rotate(-Math.PI / 12);
  ctx.font = '14px sans-serif';
  const stepX = 180, stepY = 100;
  for (let x = -h; x < w + h; x += stepX)                 // 平铺
    for (let y = 0; y < h + w; y += stepY)
      ctx.fillText(text, x + y * 0.2, y);
  ctx.restore();
}
function blindWatermark(imageData, userId) {              // LSB 盲水印（简化）
  const tag = strToBits(userId.padEnd(8, '0'));            // 64 位
  for (let i = 0; i < tag.length; i++)
    imageData.data[i * 4] = (imageData.data[i * 4] & 0xFE) | tag[i];   // 最低位嵌入
  return imageData;
}
// 溯源：截图 → 提取 LSB → 还原 userId（对压缩鲁棒性差——声明局限）
```
