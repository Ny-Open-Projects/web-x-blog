## VIZ-402：着色器热更新（开发期）如何安全实现

**答**：
- 流程：文件 watch -> 编译校验（compile 387 失败不上线）-> swap program -> uniform 状态恢复。
- 坑：hot swap 后 attribute location 变化需重新绑定 VAO；纹理句柄保留复用。
- 收益：着色器调参免刷新（保存即生效），调参效率 ×5。

```javascript
// 热更新封装
function hotSwap(gl, progCache, name, vsSrc, fsSrc, uniformsSnapshot) {
  try {
    const prog = linkProgram(gl, compile(gl, gl.VERTEX_SHADER, vsSrc),
      compile(gl, gl.FRAGMENT_SHADER, fsSrc));
    const old = progCache.get(name);
    progCache.set(name, prog);
    restoreUniforms(gl, prog, uniformsSnapshot);   // 恢复 uniform
    if (old) gl.deleteProgram(old);
    return { ok: true };
  } catch (e) {
    return { ok: false, log: e.message };          // 保留旧 program
  }
}
```
