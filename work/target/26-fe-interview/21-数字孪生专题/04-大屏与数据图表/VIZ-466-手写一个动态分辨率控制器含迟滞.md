## VIZ-466：手写一个动态分辨率控制器（含迟滞）

**答**：
- 需求：实现 DynamicResolution。onFrame(frameMs) 返回当前 scale（0.5~1.0）；EMA 平滑（α=0.1）；> budget*1.15 连续 3 帧降 0.1；< budget*0.85 连续 60 帧升 0.1；每次调整后 30 帧冻结。
- 边界：budget 可配置（默认 15ms）；scale clamp；连续计数在调整后重置；输出变化事件（回调）。
- 评分点：EMA 平滑；双向迟滞；冻结窗口；变化回调

```javascript
class DynamicResolution {
  constructor({ budget = 15, min = 0.5, max = 1.0, onChange } = {}) {
    this.budget = budget; this.min = min; this.max = max;
    this.scale = 1; this.ema = budget;
    this.bad = 0; this.good = 0; this.freeze = 0;
    this.onChange = onChange;
  }
  onFrame(frameMs) {
    this.ema = this.ema * 0.9 + frameMs * 0.1;
    if (this.freeze > 0) { this.freeze--; return this.scale; }
    if (this.ema > this.budget * 1.15) {
      this.bad++; this.good = 0;
      if (this.bad >= 3) this.adjust(-0.1);
    } else if (this.ema < this.budget * 0.85) {
      this.good++; this.bad = 0;
      if (this.good >= 60) this.adjust(0.1);
    } else { this.bad = 0; this.good = 0; }
    return this.scale;
  }
  adjust(d) {
    const next = Math.min(this.max, Math.max(this.min, this.scale + d));
    if (next !== this.scale) {
      this.onChange?.(this.scale, next);
      this.scale = next;
    }
    this.bad = 0; this.good = 0; this.freeze = 30;
  }
}
```
