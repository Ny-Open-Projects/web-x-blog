## VIZ-293：可视化数据压缩传输：列式编码与 delta 编码

**答**：
- 题目：时序数据传输体积大——列式 + delta 编码：时间戳单调 → delta 编码（差值小，varint 更省）；值列按类型分列。
- 思路：timestamp 列 delta+varint；value 列按精度定长或 zigzag varint；JSON vs 二进制体积对比（10 万点：JSON 2MB → 二进制 400KB）。
- 评分点：delta 编码适用（单调时间戳）；varint 变长编码；列式布局。

```javascript
function encodeTimeSeries(points) {                        // 列式 + delta
  const tsDelta = points.map((p, i) =>
    i === 0 ? p.t : p.t - points[i - 1].t);                // 时间差分（单调→小值）
  const tsBytes = tsDelta.flatMap(v => varintEncode(v));   // varint 变长
  const valueBytes = points.map(p => zigzagEncode(p.v)).flatMap(varintEncode);   // zigzag 处理负数
  return { ts: tsBytes, value: valueBytes, count: points.length };
}
function varintEncode(n) {                                 // 变长整数
  const out = [];
  let v = n < 0 ? ((-n) << 1) | 1 : n << 1;                // zigzag 内嵌
  do { out.push((v & 0x7f) | (v > 0x7f ? 0x80 : 0)); v >>>= 7; } while (v);
  return out;
}
// 体积估算：10 万点 JSON（{t,v} 全量）≈ 2.4MB；列式 delta ≈ 350KB（7x）
// 解压成本 O(n) 极低——浏览器端 decode 后直接渲染
```
