## VIZ-241：图表拾取系统：最近点与区域命中

**答**：
- 题目：折线图拾取——光标附近找「最近的采样点」（含 x 距离与 y 距离的加权判定）；柱状图拾取——矩形包含判定。统一拾取接口。
- 思路：折线：按 x 二分找候选 → 计算屏幕距离取最近（阈值判定）；柱状：几何包含；接口 {hit(px, py) → {series, index, dist}}。
- 评分点：折线最近点算法（二分 + 距离）；阈值判定（超过阈值算未命中）；统一接口抽象。

```javascript
function nearestPointOnLine(data, scaleX, scaleY, px, py, { maxDist = 30 } = {}) {
  const xVal = scaleX.invert(px);
  // 二分找 x 最近候选（数据按 x 有序）
  let lo = 0, hi = data.length - 1;
  while (lo < hi) { const m = (lo + hi) >> 1;
    scaleX(data[m].x) < px ? lo = m + 1 : hi = m; }
  let best = null, bestDist = Infinity;
  for (let i = Math.max(0, lo - 2); i <= Math.min(data.length - 1, lo + 2); i++) {   // 邻域精查
    const dx = scaleX(data[i].x) - px, dy = scaleY(data[i].v) - py;
    const dist = Math.hypot(dx, dy);
    if (dist < bestDist) { bestDist = dist; best = { index: i, data: data[i] }; }
  }
  return bestDist <= maxDist ? { ...best, dist: bestDist } : null;   // 阈值判定
}
function hitBar(bars, px, py) {                            // 柱状：矩形包含
  return bars.find(b => px >= b.x && px <= b.x + b.w && py >= b.y && py <= b.y + b.h) ?? null;
}
// 统一接口：chart.hit(px, py) → {series, index} 或 null——交互层不关心图表类型
```
