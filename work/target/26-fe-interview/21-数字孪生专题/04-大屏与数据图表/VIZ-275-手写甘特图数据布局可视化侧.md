## VIZ-275：手写甘特图数据布局（可视化侧）：时间轴映射与依赖连线

**答**：
- 题目：甘特图前端布局——任务时间→像素映射（时间比例尺）、行分配（并行任务分行）、依赖连线（FS 箭头）。
- 思路：时间比例尺（domain=项目起止）；行分配：按 start 排序贪心装行（不重叠同行）；连线：前驱 end → 后继 start 折线。
- 评分点：时间比例尺；行分配贪心（与 ALG-481 同构）；依赖连线正交折线。

```javascript
function ganttLayout(tasks, { rowH = 32, pxPerDay = 10 } = {}) {
  const minDay = Math.min(...tasks.map(t => t.start));
  const scale = d => (d - minDay) * pxPerDay;              // 时间→x
  const rows = [];                                          // 行池：各行最后 end
  const placed = [...tasks].sort((a, b) => a.start - b.start)
    .map(t => {
      let row = rows.findIndex(lastEnd => lastEnd <= t.start);   // 贪心找可用行
      if (row < 0) { row = rows.length; rows.push(0); }
      rows[row] = t.end;
      return { ...t, row, x: scale(t.start), w: scale(t.end) - scale(t.start) };
    });
  const deps = tasks.flatMap(t => (t.deps ?? []).map(d => ({
    from: tasks.find(x => x.id === d), to: t }))).map(({ from, to }) => ({
    path: `M${scale(from.end)},${from.row * rowH + rowH / 2}
      L${scale(to.start) - 8},${from.row * rowH + rowH / 2}
      L${scale(to.start) - 8},${to.row * rowH + rowH / 2}
      L${scale(to.start)},${to.row * rowH + rowH / 2}`,      // 正交折线
  }));
  return { placed, deps, rowH };
}
```
