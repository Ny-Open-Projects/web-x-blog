## VIZ-302：手写时序图 M4 降采样完整实现（笔试）

**答**：
- 题目：实现 M4 降采样（保 min/max/first/last）+ 像素桶边界处理 + 增量更新（新数据到达只更新尾桶）。
- 思路：桶边界按时间域均分；每桶四点；增量：新数据进尾桶（时间单调），尾桶满则开新桶。
- 评分点：桶边界正确；四点保留；增量尾桶更新。

```javascript
class M4Series {
  constructor(pixelWidth, domain) {
    this.pw = pixelWidth; this.domain = [...domain];
    this.buckets = Array.from({ length: pixelWidth }, () => null);
  }
  bucketOf(t) {                                            // 时间 → 桶号
    return clamp(Math.floor((t - this.domain[0])
      / (this.domain[1] - this.domain[0]) * this.pw), 0, this.pw - 1);
  }
  append(t, v) {                                           // 增量追加（时间单调）
    const idx = this.bucketOf(t);
    const b = this.buckets[idx] ??= { min: { t, v }, max: { t, v }, first: { t, v }, last: { t, v } };
    if (v < b.min.v) b.min = { t, v };
    if (v > b.max.v) b.max = { t, v };
    b.last = { t, v };                                     // first 不变（桶内最早）
    if (idx === this.pw - 1 && t > this.domain[1]) {       // 溢出：窗口滑动
      const span = this.domain[1] - this.domain[0];
      this.domain = [this.domain[0] + span, this.domain[1] + span];
      this.buckets.shift(); this.buckets.push(null);       // 环形滑动
    }
  }
  toPoints() {                                             // 渲染点（≤ 4×像素）
    return this.buckets.filter(Boolean)
      .flatMap(b => [b.first, b.min, b.max, b.last])
      .sort((a, b) => a.t - b.t);                          // 时间排序供折线
  }
}
```
