## VIZ-232：图表引擎自研架构：数据流水线分层

**答**：
- 自研图表引擎分层：数据层（原始数据 → 归一化模型）→ 比例尺层（数据域 → 像素域映射）→ 布局层（坐标系统/分面）→ 渲染层（SVG/Canvas/WebGPU）→ 交互层（拾取/联动）。
- 单向数据流：数据变更 → 全管线失效（脏标记）→ 分层重算——各层独立缓存（比例尺不变则跳过重映射）。
- 与 ECharts 对照：ECharts 的 option→model→view 即同构分层。

```javascript
class ChartPipeline {
  setData(raw) {
    this.raw = raw;
    this.invalidate('data');                               // 数据脏：全链重算
  }
  render() {
    if (this.dirty.has('data')) {
      this.model = normalize(this.raw, this.schema);       // 数据层
      this.dirty.add('scale');
    }
    if (this.dirty.has('scale') || this.dirty.has('size')) {
      this.scale = buildScales(this.model, this.size);      // 比例尺层
      this.dirty.add('layout');
    }
    if (this.dirty.has('layout')) {
      this.layout = computeLayout(this.model, this.scale);  // 布局层
      this.dirty.add('paint');
    }
    if (this.dirty.has('paint')) paint(this.renderer, this.layout);   // 渲染层
    this.dirty.clear();
  }
}
// 增量收益：仅数据变（尺寸不变）→ 跳过布局重算；hover 交互 → 只走交互层
```
