## VIZ-238：图表主题系统：token 驱动的样式变量

**答**：
- 图表主题 = token 集（颜色序列/轴样式/字体/间距）；series 默认色按序取色板；暗色主题 = token 覆盖。
- 与组件主题（HW-388）的区别：图表主题核心是「颜色序列分配」（series 色不能撞）与「数据色映射」（连续色标）。
- 实现：theme.tokens + seriesColor(index) 分配器 + continuousScale(v) 数据色标。

```javascript
class ChartTheme {
  constructor(tokens) { this.t = tokens; this.colorIdx = 0; }
  nextColor() {                                          // series 顺序取色
    return this.t.palette[this.colorIdx++ % this.t.palette.length];
  }
  resetColors() { this.colorIdx = 0; }
  continuous(v, domain) {                                // 数据色标（热力）
    const t = (v - domain[0]) / (domain[1] - domain[0]);
    return interpolate(this.t.heatScale, t);              // 色标插值
  }
  static dark = { palette: ['#5b8ff9', '#5ad8a6', '#f6bd16'], axisLine: '#3a3f4b',
    textColor: '#c2c7ce', grid: '#2a2e37' };
  static light = { palette: ['#1890ff', '#52c41a', '#faad14'], axisLine: '#d9d9d9',
    textColor: '#333', grid: '#eee' };
}
// 色板选择原则：色相均匀分布（色盲友好）、亮度相近（视觉平衡）
```
