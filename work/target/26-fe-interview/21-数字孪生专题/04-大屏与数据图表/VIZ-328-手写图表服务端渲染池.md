## VIZ-328：手写图表服务端渲染池：并发渲染管理（笔试）

**答**：
- 题目：BI 服务端渲染（导出 PDF 批量）——渲染池（headless browser 实例池）、队列、超时与失败重试。复用 HW-334 Worker 池思想。
- 思路：浏览器实例池（内存隔离、上限）；任务队列（优先级）；单任务超时 kill 重启实例；结果回传（PDF/截图）。
- 评分点：池化与上限；超时重启；优先级队列。

```javascript
class SSRRenderPool {
  constructor(size = 3, { taskTimeout = 30000 } = {}) {
    this.size = size; this.timeout = taskTimeout;
    this.pool = []; this.q = []; this.active = 0;
  }
  async acquire() {                                         // 浏览器实例
    if (this.pool.length) return this.pool.pop();
    return launchHeadless({ args: ['--disable-gpu'] });     // 软渲染
  }
  async render(task) {                                      // task: {chartId, format, priority}
    return new Promise((res, rej) => { this.q.push({ ...task, res, rej }); this.pump(); });
  }
  async pump() {
    while (this.active < this.size && this.q.length) {
      this.q.sort((a, b) => b.priority - a.priority);
      const task = this.q.shift();
      this.active++;
      const browser = await this.acquire();
      const timer = setTimeout(() => {                      // 超时：重启实例
        browser.close(); this.pool.push(await this.acquire());
        task.rej(new Error('render-timeout'));
      }, this.timeout);
      try {
        const result = await renderInBrowser(browser, task);
        clearTimeout(timer);
        task.res(result);
        this.pool.push(browser);
      } catch (e) { clearTimeout(timer); browser.close(); task.rej(e); }
      finally { this.active--; this.pump(); }
    }
  }
}
```
