## VIZ-262：手写命令缓冲与脏区重绘：Canvas 图表局部更新

**答**：
- 题目：Canvas 图表 hover 时只重绘受影响区域（不整图重绘）——实现命令缓冲 + 脏区（dirty rect）重绘。
- 思路：绘制指令记录为命令列表（带包围盒）；hover 只影响 tooltip 区域 → 只回放包围盒相交的命令；底图分层（静态层独立）。
- 评分点：命令带包围盒；脏区相交判定；分层（静态/动态）。

```javascript
class DirtyRectRenderer {
  constructor(canvas) { this.ctx = canvas.getContext('2d');
    this.commands = []; }                                   // [{bbox, exec}]
  rect(x, y, w, h, style) {
    this.commands.push({ bbox: { x, y, w, h },
      exec: () => { this.ctx.fillStyle = style; this.ctx.fillRect(x, y, w, h); } });
  }
  repaint(dirty) {                                         // 只重绘脏区相交命令
    this.ctx.clearRect(dirty.x, dirty.y, dirty.w, dirty.h);
    for (const cmd of this.commands)
      if (intersects(cmd.bbox, dirty)) cmd.exec();          // 相交才执行
  }
  hover(dx, dy) {                                          // hover：只重绘 tooltip 区
    this.repaint({ x: dx - 100, y: dy - 60, w: 200, h: 100 });
  }
}
// 全图 10 万命令 → hover 只回放几十条 → 5ms → 0.3ms
```
