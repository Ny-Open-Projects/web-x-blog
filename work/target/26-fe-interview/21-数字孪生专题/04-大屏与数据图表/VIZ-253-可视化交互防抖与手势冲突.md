## VIZ-253：可视化交互防抖与手势冲突：图表手势仲裁

**答**：
- 图表手势冲突：捏合缩放 vs 双指平移、单指平移 vs 点选——仲裁：双指 → 缩放（捏合距离变化主导）、单指位移 > 6px → 平移、否则点选。
- 实现：pointer 事件统一；手势状态机（possible → began）；仲裁后锁定手势类型（本次触摸序列不再切换）。
- 移动端图表必备：touch-action: none 配合。

```javascript
class ChartGesture {
  constructor(el, handlers) {
    el.style.touchAction = 'none';
    this.state = 'idle'; this.handlers = handlers;
    el.addEventListener('pointerdown', e => this.down(e));
    el.addEventListener('pointermove', e => this.move(e));
    el.addEventListener('pointerup', () => this.reset());
  }
  down(e) { this.pts = new Map([[e.pointerId, e]]); this.state = 'possible'; this.start = e; }
  move(e) {
    if (this.state === 'idle') return;
    this.pts.set(e.pointerId, e);
    if (this.pts.size === 2 && this.state === 'possible') {
      this.state = 'pinch';                                // 双指锁定缩放
    } else if (this.pts.size === 1 && this.state === 'possible') {
      const dx = e.clientX - this.start.clientX;
      if (Math.hypot(dx, e.clientY - this.start.clientY) > 6)
        this.state = 'pan';                                // 位移超阈值：平移
    }
    if (this.state === 'pinch') this.handlers.pinch(this.pinchDelta());
    if (this.state === 'pan') this.handlers.pan(e.movementX, e.movementY);
  }
  reset() { if (this.state === 'possible') this.handlers.tap(this.start);   // 未位移 = 点选
    this.state = 'idle'; this.pts = null; }
}
```
