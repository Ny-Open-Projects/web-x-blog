## VIZ-251：可视化错误兜底：渲染失败的四级降级

**答**：
- 题目：图表渲染失败（数据异常/GPU 上下文丢失/库崩溃）——设计四级降级：重试 → 简化渲染 → Canvas2D 静态版 → 错误占位。
- 思路：L1 重试（瞬态错误）；L2 降参（减数据量/关动画）；L3 后端渲染兜底（Canvas2D 简版折线）；L4 错误占位（图标+摘要+重试按钮）。每级上报原因。
- 评分点：四级链完整；各级触发条件；占位内容不白屏。

```javascript
class RenderFallback {
  async render(chart, data) {
    const levels = [
      { name: 'full', fn: () => chart.render(data) },
      { name: 'lite', fn: () => chart.render(sample(data, 1000), { animation: false }) },
      { name: 'canvas2d', fn: () => simpleCanvas2D(data) },   // 简版静态折线
      { name: 'placeholder', fn: () => renderErrorCard(data.meta) },
    ];
    for (const level of levels) {
      try { return await level.fn(); }
      catch (e) {
        report('chart-fallback', { level: level.name, error: String(e).slice(0, 100) });
        if (level.name === 'placeholder') throw e;         // 最后一级也失败才抛
      }
    }
  }
}
function renderErrorCard(meta) {                           // L4 占位
  return `<div class="chart-error">
    <span class="icon">📉</span>
    <p>图表加载失败：${meta.title}</p>
    <button onclick="location.reload()">重试</button>
  </div>`;
}
```
