## VIZ-235：图表图例布局器：空间约束下的图例排布

**答**：
- 题目：图表图例项数不定（1~50 项），空间约束（顶部预留高度有限）——设计图例布局：放不下折行，折行超限收缩为「可滚动/折叠更多」。
- 思路：测量每项宽（文本+swatch），贪心装行（当前行放不下换行）；总高超限 → 截断显示 + "更多"入口。
- 评分点：测量与贪心装行；高度约束截断；更多入口交互。

```javascript
function layoutLegend(items, { maxWidth, maxHeight, itemH = 24 } = {}) {
  const rows = [];
  let cur = [], curW = 0;
  for (const item of items) {
    const w = measureText(item.label) + 20;                // 文本 + swatch
    if (curW + w > maxWidth && cur.length) {               // 换行
      rows.push(cur); cur = []; curW = 0;
    }
    cur.push({ item, w }); curW += w + 8;
  }
  if (cur.length) rows.push(cur);
  const totalH = rows.length * itemH;
  if (totalH <= maxHeight) return { rows, truncated: false };
  // 超高：截断 + 更多
  const fitRows = Math.floor(maxHeight / itemH) - 1;      // 留一行给"更多"
  const hiddenCount = items.length -
    rows.slice(0, fitRows).reduce((s, r) => s + r.length, 0);
  return { rows: rows.slice(0, fitRows), truncated: true, hiddenCount,
    moreEntry: { label: `+${hiddenCount} 更多` } };
}
```
