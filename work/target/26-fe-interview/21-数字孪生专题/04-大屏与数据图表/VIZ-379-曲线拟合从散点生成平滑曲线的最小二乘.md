## VIZ-379：曲线拟合：从散点生成平滑曲线的最小二乘

**答**：
- 可视化场景：传感器散点拟合趋势线——多项式最小二乘（2~3 次足够，高次震荡）。
- 移动端实时：滑动窗口内的局部回归（稳健）或指数平滑（更轻）。
- 展示：拟合线与散点分层渲染，注明拟合度 R²。

```javascript
// 多项式最小二乘（2 次）
function polyfit(pts, deg = 2) {
  const n = pts.length;
  const A = [], b = [];
  for (const [x, y] of pts) {
    const row = Array.from({ length: deg + 1 }, (_, i) => x ** i);
    A.push(row); b.push(y);
  }
  // 正规方程 (AᵀA)c = Aᵀb（小规模直接解）
  const at = transpose(A);
  const ata = matmul(at, A), atb = matvec(at, b);
  const c = solve(ata, atb);
  return x => c.reduce((s, ci, i) => s + ci * x ** i, 0);
}
const transpose = A => A[0].map((_, i) => A.map(r => r[i]));
const matmul = (a, b) => a.map(r => b[0].map((_, j) => r.reduce((s, v, k) => s + v * b[k][j], 0)));
const matvec = (a, v) => a.map(r => r.reduce((s, x, i) => s + x * v[i], 0));
function solve(A, b) { /* 高斯消元，略 */ return b; }
```
