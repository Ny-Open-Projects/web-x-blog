## VIZ-250：可视化数据降级：大数据的抽样与聚合策略选型

**答**：
- 数据 > 渲染能力时降级三策略：LTTB 抽样（保形状——折线）、M4 聚合（保极值——时序）、网格聚合（保密度——散点/热力）。
- 选型：折线趋势 → LTTB；监控告警（极值不能丢）→ M4；密度分布 → 网格聚合；业务汇总 → 服务端预聚合。
- M4：每个像素列取 min/max/first/last 四点——极值不丢且数据量 = 像素宽 × 4。

```javascript
function m4Aggregate(data, pixelWidth, scaleX) {          // M4 聚合（保极值）
  const domain = scaleX.domain;
  const perPixel = (domain[1] - domain[0]) / pixelWidth;
  const buckets = Array.from({ length: pixelWidth }, () => ({
    min: Infinity, max: -Infinity, first: null, last: null }));
  for (const d of data) {
    const idx = clamp(Math.floor((d.x - domain[0]) / perPixel), 0, pixelWidth - 1);
    const b = buckets[idx];
    if (b.first === null) b.first = d;
    b.last = d;
    if (d.v < b.min.v) b.min = d;
    if (d.v > b.max.v) b.max = d;
  }
  return buckets.flatMap(b => [b.first, b.min, b.max, b.last].filter(Boolean));   // ≤ 4×像素点
}
// 10 万点 → 像素级 4000 点，min/max 保留（监控告警不失真）
// LTTB 对比：保视觉形状但可能丢极值——监控场景禁用
```
