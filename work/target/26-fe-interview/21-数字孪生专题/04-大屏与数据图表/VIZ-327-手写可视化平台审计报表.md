## VIZ-327：手写可视化平台审计报表：数据访问合规报告（笔试）

**答**：
- 题目：合规审计——「谁访问过敏感图表、访问频次、导出记录」的周期报表生成与留存策略。
- 思路：审计日志聚合（按用户/图表/周期）；报表模板（敏感度分层）；留存策略（热 90 天 → 冷存储 1 年）。
- 评分点：聚合维度；报表模板；留存分级。

```javascript
class ComplianceReport {
  async generate(period) {                                  // period: {from, to}
    const logs = await auditStore.query({ from: period.from, to: period.to,
      kinds: ['view', 'export', 'share'] });
    const byUser = groupBy(logs, 'user');
    const byChart = groupBy(logs, 'chartId');
    return {
      period,
      topUsers: topBy(byUser, 'count', 10),
      sensitiveExports: logs.filter(l => l.sensitivity === 'high').length,
      anomaly: detectAnomaly(byUser),                       // 频次异常（MAD，ALG-350 思想）
      retention: { hot: '90d online', cold: '1y archive', policy: 'GB 合规' },
    };
  }
  detectAnomaly(byUser) {                                   // 访问频次异常
    const counts = Object.values(byUser).map(l => l.length);
    const med = median(counts);
    const mad = median(counts.map(c => Math.abs(c - med)));
    return Object.entries(byUser)
      .filter(([, l]) => Math.abs(l.length - med) > 3 * mad * 1.4826)   // 3×MAD
      .map(([user]) => user);
  }
}
```
