## VIZ-322：手写图表查询缓存与失效（笔试）

**答**：
- 题目：BI 图表查询结果缓存——key（查询指纹）、TTL、主动失效（数据变更事件）；与 ALG-531/319 协同。
- 思路：指纹 = SQL + params + 用户行级权限范围（不同人不同缓存）；失效：数据集变更事件 → 按血缘清缓存（VIZ-297）。
- 评分点：指纹含权限维度；主动失效；被动 TTL 配合。

```javascript
class ChartQueryCache {
  constructor({ ttl = 300000 } = {}) { this.ttl = ttl; this.store = new Map(); }
  fingerprint(sql, params, rowScope) {                     // 指纹含权限
    return hashStr(sql + JSON.stringify(params) + JSON.stringify(rowScope));
  }
  async query(sql, params, rowScope) {
    const key = this.fingerprint(sql, params, rowScope);
    const hit = this.store.get(key);
    if (hit && Date.now() - hit.ts < this.ttl) return hit.data;   // 命中
    const data = await db.query(sql, params);
    this.store.set(key, { data, ts: Date.now() });
    return data;
  }
  invalidateDataset(datasetId) {                            // 数据变更 → 血缘清缓存
    for (const [key, entry] of this.store)
      if (entry.datasetId === datasetId) this.store.delete(key);
  }
}
// 行级权限入指纹：不同 userScope 各自缓存——防止权限串数据
```
