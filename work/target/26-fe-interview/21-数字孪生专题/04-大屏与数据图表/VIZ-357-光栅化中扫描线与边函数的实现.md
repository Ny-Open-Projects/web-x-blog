## VIZ-357：光栅化中"扫描线"与"边函数"的实现

**答**：
- 三角形光栅化：用边函数 E(x,y) = (y1-y2)(x-x2) + (x2-x1)(y-y2) 判定像素在边哪侧。
- 增量计算：相邻像素 E 值可增量更新（+a 或 +b），避免每像素全量乘法。
- 瓦片化（tile-based）：先算 8×8 瓦片覆盖再内部光栅化，GPU 硬件与软件光栅都这么做。

```javascript
// 软件光栅：边函数扫描
function edgeFn(ax, ay, bx, by, x, y) {
  return (by - ay) * (x - ax) - (bx - ax) * (y - ay);
}
function rasterizeTri(v0, v1, v2, putPixel) {
  const minX = Math.floor(Math.min(v0[0], v1[0], v2[0]));
  const maxX = Math.ceil(Math.max(v0[0], v1[0], v2[0]));
  const minY = Math.floor(Math.min(v0[1], v1[1], v2[1]));
  const maxY = Math.ceil(Math.max(v0[1], v1[1], v2[1]));
  const area = edgeFn(v0[0], v0[1], v1[0], v1[1], v2[0], v2[1]);
  for (let y = minY; y <= maxY; y++)
    for (let x = minX; x <= maxX; x++) {
      const w0 = edgeFn(v1[0], v1[1], v2[0], v2[1], x + 0.5, y + 0.5);
      const w1 = edgeFn(v2[0], v2[1], v0[0], v0[1], x + 0.5, y + 0.5);
      const w2 = edgeFn(v0[0], v0[1], v1[0], v1[1], x + 0.5, y + 0.5);
      if ((w0 >= 0 && w1 >= 0 && w2 >= 0) === (area >= 0))
        putPixel(x, y, [w0, w1, w2].map(w => w / area));
    }
}
```
