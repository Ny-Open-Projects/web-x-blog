## VIZ-309：手写图表性能探针（笔试）

**答**：
- 题目：图表库内置性能探针——渲染耗时/拾取耗时/内存/帧率采集，聚合上报与超预算告警。复用 HW-338 思想。
- 思路：performance.mark/measure 包装渲染函数；内存用 performance.memory 采样；帧率 rAF 计数；预算判定与告警。
- 评分点：分段度量；采样与聚合；预算告警。

```javascript
class ChartPerfProbe {
  constructor(budgets = { render: 16, pick: 5 }) { this.budgets = budgets; this.samples = new Map(); }
  wrapRender(chart) {
    const raw = chart.render.bind(chart);
    chart.render = (...args) => {
      const t0 = performance.now();
      const r = raw(...args);
      this.record('render', performance.now() - t0);
      return r;
    };
  }
  wrapPick(chart) {
    const raw = chart.pick.bind(chart);
    chart.pick = (...args) => {
      const t0 = performance.now();
      const r = raw(...args);
      this.record('pick', performance.now() - t0);
      return r;
    };
  }
  record(metric, ms) {
    const arr = this.samples.get(metric) ?? [];
    arr.push(+ms.toFixed(1));
    this.samples.set(metric, arr.slice(-100));               // 环形 100 条
    if (arr.length >= 50) this.checkBudget(metric);
  }
  checkBudget(metric) {
    const arr = this.samples.get(metric);
    const p95 = [...arr].sort((a, b) => a - b)[Math.floor(arr.length * 0.95)];
    if (p95 > this.budgets[metric])
      report('viz-perf-over', { metric, p95, budget: this.budgets[metric] });   // 告警
  }
}
```
