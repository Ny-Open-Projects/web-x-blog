## VIZ-272：手写关系图力导向布局：力模拟与迭代收敛

**答**：
- 题目：力导向布局（Force-Directed）——节点斥力（库仑）+ 连线引力（弹簧）+ 中心引力，迭代模拟收敛。防重叠与边界约束。
- 思路：每轮：斥力（两两 O(n²)，网格加速可选）+ 引力（连线）+ 中心力 → 速度积分 → 位置更新；阻尼防震荡。
- 评分点：三种力公式；阻尼与收敛判定；迭代次数上限。

```javascript
function forceLayout(nodes, links, { iterations = 300, repulsion = 2000, spring = 0.05 } = {}) {
  const pos = nodes.map((_, i) => ({ x: Math.cos(i) * 100, y: Math.sin(i) * 100, vx: 0, vy: 0 }));
  for (let iter = 0; iter < iterations; iter++) {
    for (let i = 0; i < nodes.length; i++)                  // 斥力
      for (let j = i + 1; j < nodes.length; j++) {
        const dx = pos[i].x - pos[j].x, dy = pos[i].y - pos[j].y;
        const dist2 = dx * dx + dy * dy + 0.01;
        const f = repulsion / dist2;
        const fx = dx / Math.sqrt(dist2) * f, fy = dy / Math.sqrt(dist2) * f;
        pos[i].vx += fx; pos[i].vy += fy;
        pos[j].vx -= fx; pos[j].vy -= fy;
      }
    for (const l of links) {                                // 引力（弹簧）
      const a = pos[l.source], b = pos[l.target];
      const dx = b.x - a.x, dy = b.y - a.y;
      const f = spring;
      a.vx += dx * f; a.vy += dy * f;
      b.vx -= dx * f; b.vy -= dy * f;
    }
    for (const p of pos) {                                  // 积分 + 阻尼
      p.vx *= 0.85; p.vy *= 0.85;
      p.x += p.vx; p.y += p.vy;
    }
  }
  return pos;
}
```
