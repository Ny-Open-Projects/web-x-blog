## VIZ-464：渲染优化深水收口：一张优化检查清单

**答**：
- CPU：draw 数、状态切换、GC（对象分配）、场景遍历、命令排序。
- GPU 几何：顶点量/实例化/LOD/剔除（视锥+遮挡）/索引优化。
- GPU 像素：分辨率/overdraw/纹理带宽/片元复杂度/后处理成本。
- 内存：纹理预算/GPU 资源池/泄漏审计/流式加载。
- 过程：先测后改/基准回归/降级矩阵/渐进加载。

```javascript
// 优化清单检查器
const CHECKLIST = [
  { id: 'draws', test: s => s.drawCalls < 1000, sev: 'P1' },
  { id: 'overdraw', test: s => s.overdraw < 2.5, sev: 'P1' },
  { id: 'texMB', test: s => s.texMB < 100, sev: 'P0' },
  { id: 'gcJitter', test: s => s.gcEventsPerMin < 2, sev: 'P0' },
  { id: 'firstRender', test: s => s.firstRenderMs < 1000, sev: 'P1' },
];
function renderAudit(signals) {
  return CHECKLIST.filter(c => !c.test(signals))
    .map(c => ({ id: c.id, sev: c.sev }));
}
```
