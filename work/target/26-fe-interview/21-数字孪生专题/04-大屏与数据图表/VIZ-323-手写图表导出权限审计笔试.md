## VIZ-323：手写图表导出权限审计（笔试）

**答**：
- 题目：BI 导出（PNG/数据 CSV）审计——谁在何时导出了什么（含行级范围与字段裁剪记录），敏感图表导出需二次确认与水印。
- 思路：导出前权限复核 + 审计日志（不含数据本体，含范围摘要）；敏感度分级（高敏需审批）。
- 评分点：审计字段设计；敏感度分级；水印溯源（VIZ-255）。

```javascript
class ExportAudit {
  async export(chartId, user, format) {
    const perm = await authz.can(user.roles, `chart:${chartId}`, 'export');
    if (!perm) throw new Error('export-denied');
    const sensitivity = await getChartSensitivity(chartId);
    if (sensitivity === 'high') {                           // 高敏：二次确认
      const approved = await requestApproval(chartId, user);
      if (!approved) throw new Error('approval-required');
    }
    const scope = await authz.getRowScope(user.roles, chartId);
    auditLog({                                              // 审计（不含数据本体）
      action: 'export', chartId, user: user.id, format,
      rowScopeSummary: scope.summary,                       // 范围摘要（非全量）
      ts: Date.now(), watermarked: true,
    });
    return generateExport(chartId, { watermark: user.id, rowScope: scope });
  }
}
```
