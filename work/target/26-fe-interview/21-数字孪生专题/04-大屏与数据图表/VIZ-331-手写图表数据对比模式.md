## VIZ-331：手写图表数据对比模式：同比环比计算（笔试）

**答**：
- 题目：图表对比模式——同比（去年同月）、环比（上月）计算与展示（值+涨跌色+百分比），空数据周期处理。
- 思路：同比 = 本期 vs 去年同期（日期 -1 年）；环比 = vs 上一周期；缺对比数据 → 显示占位符而非 0%；涨跌色与箭头。
- 评分点：同环比日期计算；缺失对比处理；展示格式。

```javascript
function periodComparison(current, sameTimeLastYear, previousPeriod) {
  const calc = (cur, base) => base == null || base === 0
    ? null                                                 // 缺对比：null 非 0
    : +(((cur - base) / Math.abs(base)) * 100).toFixed(1);
  return {
    value: current,
    yoy: calc(current, sameTimeLastYear),                  // 同比
    mom: calc(current, previousPeriod),                    // 环比
    display: (pct) => pct == null ? '—'
      : `${pct > 0 ? '↑' : pct < 0 ? '↓' : '→'} ${Math.abs(pct)}%`,
    color: (pct) => pct > 0 ? '#52c41a' : pct < 0 ? '#f5222d' : '#999',
  };
}
function lastYearSameMonth(dateStr) {                      // 同比日期（处理闰年）
  const d = new Date(dateStr);
  d.setFullYear(d.getFullYear() - 1);
  if (d.getMonth() !== new Date(dateStr).getMonth()) d.setDate(0);   // 2/29 → 2/28
  return d.toISOString().slice(0, 10);
}
```
