## VIZ-242：图表联动系统：多图共享轴与刷选

**答**：
- 多图联动两种：轴同步（x 域一致，一图缩放全部跟随）与刷选（brush 框选范围，其他图高亮/过滤）。
- 实现：事件总线广播 domain/brush 变更；防环标记（来源标识，ALG-365 已实现）。
- 应用：仪表盘上「时间轴刷选 → 所有图同步」。

```javascript
class ChartLinkage {
  constructor(charts) {
    this.charts = charts; this.source = null;
    charts.forEach(c => {
      c.onZoom = (domain) => this.broadcast(c.id, { type: 'zoom', domain });
      c.onBrush = (range) => this.broadcast(c.id, { type: 'brush', range });
    });
  }
  broadcast(sourceId, evt) {
    if (this.source === sourceId) return;                  // 防环
    this.source = sourceId;
    for (const c of this.charts) {
      if (c.id === sourceId) continue;
      evt.type === 'zoom' ? c.setDomain(evt.domain) : c.highlight(evt.range);
    }
    this.source = null;
  }
}
```
