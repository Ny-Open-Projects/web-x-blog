## VIZ-284：手写散点图密度渲染（百万点）：alpha 累积与热力融合

**答**：
- 题目：百万散点直接画点 GPU 也吃力（fillrate）——密度渲染：点画到低分辨率累积缓冲（alpha 累积），再色标映射放大。
- 思路：低分辨率 buffer（如 500×300）；每点 alpha 累积（globalAlpha 0.1 或直接 buffer 计数）；计数值 → 色标 → 放大绘制。
- 评分点：密度累积缓冲；色标映射；放大插值平滑。

```javascript
function densityScatter(points, { w = 500, h = 300, cell = 4 } = {}) {
  const gw = Math.ceil(w / cell), gh = Math.ceil(h / cell);
  const grid = new Float32Array(gw * gh);                  // 密度累积
  for (const p of points) {
    const gx = clamp(Math.floor(p.x / cell), 0, gw - 1);
    const gy = clamp(Math.floor(p.y / cell), 0, gh - 1);
    grid[gy * gw + gx] += 1;
  }
  const max = Math.max(...grid);
  const colorScale = multiStopScale([[0, [30, 30, 60]], [0.5, [255, 200, 0]], [1, [255, 60, 0]]]);
  const ctx = document.createElement('canvas').getContext('2d');
  const img = ctx.createImageData(gw, gh);
  for (let i = 0; i < grid.length; i++) {
    const [r, g, b] = colorScale(grid[i] / max);           // 密度→色
    img.data[i * 4] = r; img.data[i * 4 + 1] = g;
    img.data[i * 4 + 2] = b; img.data[i * 4 + 3] = grid[i] > 0 ? 255 : 0;
  }
  ctx.putImageData(img, 0, 0);
  // 主 canvas：imageSmoothingEnabled = true 放大 → 平滑密度云
  return ctx.canvas;
}
```
