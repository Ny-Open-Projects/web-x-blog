## VIZ-252：可视化数据契约的版本演进：图表配置兼容层

**答**：
- 图表配置（option schema）版本演进：老版本 option 在新库渲染——兼容层做字段迁移（v1→v2 映射表）。
- 迁移注册表：migrations[v1→v2] = (option) => transformed；链式执行到当前版本。
- 与 HW-321 schema 校验协同：迁移后校验，仍非法则降级。

```javascript
const optionMigrations = {
  1: (opt) => ({ ...opt, xAxis: opt.xAxis ?? opt.x,       // v1: x → v2: xAxis
    series: opt.series.map(s => ({ ...s, encode: s.mapping ?? s.encode })) }),
  2: (opt) => ({ ...opt, theme: opt.theme ?? 'light' }),   // v2 → v3
};
function migrateOption(option, fromVersion, currentVersion = 3) {
  let opt = { ...option }, v = fromVersion;
  while (v < currentVersion) {
    const migrate = optionMigrations[v];
    if (!migrate) throw new Error(`no-migration: v${v}`);
    opt = migrate(opt); v++;
  }
  const check = validateSchema(opt);                       // 迁移后校验
  if (!check.valid) return { option: fallbackOption(opt), warnings: check.errors };
  return { option: opt };
}
```
