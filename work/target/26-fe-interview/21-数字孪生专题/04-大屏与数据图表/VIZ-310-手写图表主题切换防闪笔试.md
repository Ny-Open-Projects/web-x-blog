## VIZ-310：手写图表主题切换防闪（笔试）

**答**：
- 题目：暗色主题切换时图表「先白后黑」闪烁——主题切换原子化：新主题渲染完成后一次性替换（双缓冲），不逐元素变色。
- 思路：双缓冲：离屏渲染新主题版本 → 完成后整幅替换（透明度交叉）；CSS 变量切换与重绘同帧完成。
- 评分点：双缓冲渲染；原子替换；交叉淡入时长。

```javascript
class ThemeSwapper {
  async switchTheme(chart, theme) {
    // 1. 离屏渲染新主题（不动当前显示）
    const off = await chart.renderOffscreen({ theme });
    // 2. 当前图与新图叠放，交叉淡入
    off.style.position = 'absolute'; off.style.opacity = '0';
    chart.el.parentElement.appendChild(off);
    off.style.transition = 'opacity 0.25s';
    requestAnimationFrame(() => { off.style.opacity = '1'; });
    // 3. 淡入完成后：正式替换 + 清理
    setTimeout(() => {
      chart.applyTheme(theme);                             // 内部状态切换
      off.remove();
    }, 260);
  }
}
// 对照反模式：直接 chart.setTheme(dark) 逐元素重绘 → 中间帧半白半黑闪烁
// CSS 变量切换 + 单帧重绘也可原子化（ HW-388 联动）
```
