## VIZ-333：手写可视化平台监控大盘（自监控）（笔试）

**答**：
- 题目：可视化平台自身监控——图表渲染成功率/P95 耗时/交互响应/引擎分布，自身大盘渲染（吃自己狗粮）。
- 思路：SDK 采集（VIZ-309 探针）→ 聚合（分位数）→ 大盘展示；告警（成功率 < 99% 或 p95 劣化）。
- 评分点：指标体系；聚合口径；告警条件。

```javascript
class VizPlatformMonitor {
  constructor() { this.samples = { render: [], pick: [], errors: 0, total: 0 }; }
  recordRender(ms, engine) { this.samples.render.push({ ms, engine }); this.samples.total++; }
  recordError(kind) { this.samples.errors++; }
  report() {
    const pct = (a, p) => [...a].sort((x, y) => x.ms - y.ms)[Math.floor(a.length * p)];
    const render = this.samples.render;
    return {
      successRate: +(1 - this.samples.errors / Math.max(1, this.samples.total)).toFixed(4),
      renderP50: pct(render, 0.5)?.ms, renderP95: pct(render, 0.95)?.ms,
      engineDist: countBy(render, 'engine'),                 // WebGPU/WebGL/Canvas 分布
      byChartType: groupBy(render, 'chartType'),             // 分图表类型下钻
    };
  }
  alert() {
    const r = this.report();
    if (r.successRate < 0.99) fire('viz-success-low', r);    // 成功率告警
    if (r.renderP95 > 100) fire('viz-render-slow', { p95: r.renderP95 });
  }
}
```
