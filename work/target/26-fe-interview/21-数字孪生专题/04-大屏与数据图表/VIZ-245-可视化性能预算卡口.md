## VIZ-245：可视化性能预算卡口：图表库的 CI 性能门禁

**答**：
- 图表库性能门禁指标：万点渲染 < 16ms、交互拾取 < 5ms、内存 < 100MB、动画帧率 > 50fps。
- CI 集成：headless 跑基准场景（固定数据集）→ 指标对比基线 → 超预算阻断合并（HW-398 复用）。
- 数据集版本化：基准数据固定（seed 随机），保证可比性。

```javascript
async function chartPerfGate() {
  const scenarios = [
    { name: 'line-10k-render', data: genLineData(10000), budget: { renderMs: 16 } },
    { name: 'bar-1k-pick', data: genBarData(1000), budget: { pickMs: 5 } },
    { name: 'scatter-100k-memory', data: genScatter(100000), budget: { memMB: 100 } },
  ];
  const results = [];
  for (const sc of scenarios) {
    const chart = await mount(sc);
    const r = await benchmark(chart, sc.data, 5);          // 5 轮取中位数
    results.push({ ...sc, actual: r, pass: compare(r, sc.budget) });
    chart.destroy();
  }
  const failed = results.filter(r => !r.pass);
  if (failed.length) { console.error(formatTable(results)); process.exit(1); }
}
```
