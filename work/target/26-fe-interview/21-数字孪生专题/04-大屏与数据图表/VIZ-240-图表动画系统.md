## VIZ-240：图表动画系统：数据过渡插值

**答**：
- 图表动画三类：出现动画（进入生长）、更新动画（数据变化过渡——柱高插值）、布局动画（series 切换形态过渡如柱→折线）。
- 核心：数据插值——旧值 → 新值 easing 过渡；增删点的 enter/exit 动画（生长/收缩）。
- 实现：rAF 循环 + 每帧插值重绘（脏区/局部重绘）；时长与缓动可配。

```javascript
class ChartAnimator {
  animate(oldData, newData, { duration = 300, ease = 'outCubic' } = {}) {
    const byId = new Map(oldData.map(d => [d.id, d]));
    const start = performance.now();
    const tick = (now) => {
      const t = Math.min((now - start) / duration, 1);
      const e = easeFn[ease](t);
      const frame = newData.map(d => {
        const old = byId.get(d.id);
        return { ...d, v: old ? old.v + (d.v - old.v) * e : d.v * e };   // 更新插值/进入生长
      });
      this.renderer.paint(frame);                         // 每帧重绘
      if (t < 1) requestAnimationFrame(tick);
    };
    requestAnimationFrame(tick);
  }
}
// exit 动画：旧数据中消失的点收缩到 0 后移除
// 性能：动画期间禁用 tooltip 拾取（或降频），动画结束恢复
```
