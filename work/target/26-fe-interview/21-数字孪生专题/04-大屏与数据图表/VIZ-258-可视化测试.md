## VIZ-258：可视化测试：图表快照测试与交互断言

**答**：
- 题目：图表回归测试——像素快照对比（渲染结果）+ 交互断言（hover/缩放行为）。设计测试框架。
- 思路：快照：headless 渲染固定数据 → canvas toDataURL → 与 golden 对比（允许 diff 阈值，字体渲染差异）；交互：模拟事件 → 断言 tooltip 内容/缩放后 domain。
- 评分点：快照 diff 阈值（像素级容差）；字体差异处理（CI 字体固定）；交互断言链。

```javascript
async function chartSnapshotTest(chart, golden) {
  chart.setData(FIXTURE);                                  // 固定数据
  await chart.renderDone();
  const shot = chart.canvas.toDataURL();
  const diff = pixelDiff(shot, golden, { threshold: 0.02 });   // 2% 容差
  if (diff.ratio > 0.02)
    throw new Error(`snapshot-diff ${(diff.ratio * 100).toFixed(1)}% → ${diff.diffPath}`);
  return 'pass';
}
async function chartInteractionTest(chart) {
  chart.dispatchHover({ x: 300, y: 150 });                 // 模拟 hover
  await settle(chart);
  assert(chart.tooltip.visible, 'tooltip 应显示');
  chart.dispatchWheel({ x: 300, deltaY: -100 });
  assert(chart.domain[1] - chart.domain[0] < chart.initialSpan, '滚轮应缩小 domain');
}
```
