## VIZ-231：3D 场景序列化：场景快照与恢复

**答**：
- 场景快照用途：撤销（HW-356 关联）、分享链接、服务端存档。序列化内容：节点树（类型/变换/样式）+ 相机 + 环境；排除 GPU 资源（纹理引用 URL）。
- 格式：JSON（可读）或二进制（体积）；版本号字段保证向后兼容。
- 恢复：反序列化 → 按类型重建节点 → 相机状态回放。

```javascript
function serializeScene(root) {
  const walk = (node) => ({
    type: node.type, id: node.id,
    transform: node.local.toArray(),                       // 16 位矩阵
    props: node.serializableProps(),                       // 颜色/大小等业务属性
    children: node.children.map(walk),
  });
  return JSON.stringify({
    version: 3,                                            // 格式版本号
    root: walk(root),
    camera: { position: camera.position.toArray(), target: controls.target.toArray() },
  });
}
function restoreScene(json) {
  const data = JSON.parse(json);
  if (data.version > SCHEMA_VERSION) warnNewerSchema();
  const build = (d) => {
    const node = NodeFactory.create(d.type, d.props);       // 按类型重建
    node.local.fromArray(d.transform);
    d.children?.forEach(c => node.add(build(c)));
    return node;
  };
  return { root: build(data.root), camera: data.camera };
}
```
