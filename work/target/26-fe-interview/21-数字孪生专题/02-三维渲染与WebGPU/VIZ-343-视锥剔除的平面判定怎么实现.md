## VIZ-343：视锥剔除的平面判定怎么实现

**答**：
- 视锥 6 个平面从投影矩阵行组合提取（Gribb-Hartmann 方法），每个平面 (n, d)，点在内当 n·p + d > 0。
- 物体级剔除用包围球：球心到平面距离 > -radius 即该平面外；全部平面通过才渲染。
- 八叉树/BVH 先粗筛再逐平面精判，把每帧剔除成本从 O(物体数×6) 降下来。

```javascript
// 从 VP 矩阵提取 6 平面
function frustumPlanes(m) {   // 列主序 m
  const row = (i) => [m[i], m[i+4], m[i+8], m[i+12]];
  const rows = [0,1,2,3].map(row);
  const planes = [];
  const signs = [[0,1],[0,-1],[1,1],[1,-1],[2,1],[2,-1]];
  for (const [r, s] of signs) {
    const a = rows[3].map((v, i) => v + s*rows[r][i]);
    const len = Math.hypot(a[0], a[1], a[2]) || 1;
    planes.push({ n: [a[0]/len, a[1]/len, a[2]/len], d: a[3]/len });
  }
  return planes;
}
function sphereInFrustum(c, radius, planes) {
  return planes.every(p =>
    p.n[0]*c[0] + p.n[1]*c[1] + p.n[2]*c[2] + p.d >= -radius);
}
```
