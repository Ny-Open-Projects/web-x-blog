## VIZ-225：3D 粒子系统：GPU 粒子与发射器抽象

**答**：
- 可视化粒子（数据流动画/散点动效）：GPU 粒子——位置存 GPU buffer，compute pass 每帧更新（物理/生命周期），渲染 pass 画点。
- 发射器抽象：emitter {rate, spread, lifetime, velocity}；粒子池（死亡粒子重用）。
- 与 CPU 粒子对比：1 万粒子 CPU 更新 3ms/帧，GPU compute < 0.5ms。

```javascript
// compute pass 更新粒子
const updateShader = `
struct Particle { pos: vec3f, vel: vec3f, life: f32 };
@group(0) @binding(0) var<storage, read_write> particles: array<Particle>;
@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) gid: vec3<u32>) {
  let i = gid.x;
  var p = particles[i];
  p.life -= dt;
  if (p.life <= 0) { p = spawn(particles, i); }          // 死亡重生（池化）
  p.vel.y -= 0.98 * dt;                                  // 重力
  p.pos += p.vel * dt;
  particles[i] = p;
};`;
// 渲染 pass 直接画 particles buffer（point sprites）——CPU 每帧 0 数据传输
```
