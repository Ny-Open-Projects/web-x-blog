## VIZ-473：手写一个实例剔除增量上传器

**答**：
- 需求：implement InstanceUploader(chunkSize=4096)。update(i, data) 标脏；flush(buffer, fullData) 只上传脏块（bufferSubData 按 chunk 区间）；输出 { uploadedChunks, bytes }；连续 flush 无脏返回 0。
- 边界：i 超界抛错；同块多次标脏只传一次；flush 后清脏；fullData 为 Float32Array。
- 评分点：块级标脏；区间上传；幂等；越界校验

```javascript
class InstanceUploader {
  constructor(chunkSize = 4096, stride = 32) {   // stride: 字节/实例
    this.chunk = chunkSize; this.stride = stride;
    this.dirty = new Set();
  }
  update(i) {
    const total = this.total ?? (this.total = 0);
    if (i < 0) throw new Error('index 越界');
    this.dirty.add(Math.floor(i / this.chunk));
  }
  flush(gl, buffer, fullData) {
    if (!this.dirty.size) return { uploadedChunks: 0, bytes: 0 };
    const bytesPerChunk = this.chunk * this.stride;
    let chunks = 0;
    gl.bindBuffer(gl.ARRAY_BUFFER, buffer);
    for (const c of this.dirty) {
      const start = c * bytesPerChunk;
      const end = Math.min(fullData.byteLength, start + bytesPerChunk);
      if (start >= end) continue;
      gl.bufferSubData(gl.ARRAY_BUFFER, start,
        fullData.subarray(start / 4, end / 4));     // Float32 视图
      chunks++;
    }
    this.dirty.clear();
    return { uploadedChunks: chunks, bytes: chunks * bytesPerChunk };
  }
}
```
