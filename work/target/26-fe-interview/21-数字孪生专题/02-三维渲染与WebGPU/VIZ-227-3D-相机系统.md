## VIZ-227：3D 相机系统：轨道控制器与惯性阻尼

**答**：
- 题目：实现 3D 轨道控制器（拖拽旋转、滚轮缩放、右键平移）带惯性阻尼——速度衰减到 0 而非瞬停。
- 思路：球坐标（theta/phi/radius）描述相机位；拖拽改目标角速度；每帧 angle += vel × damping；缩放改 radius（钳制 min/max）。
- 评分点：球坐标参数化；阻尼帧衰减；phi 钳制防翻转。

```javascript
class OrbitController {
  constructor(camera, dom) {
    this.theta = 0; this.phi = Math.PI / 3; this.radius = 10;
    this.vel = { theta: 0, phi: 0 }; this.damping = 0.9;
    dom.addEventListener('pointermove', e => {
      if (!this.dragging) return;
      this.vel.theta = -e.movementX * 0.01;              // 目标角速度
      this.vel.phi = -e.movementY * 0.01;
    });
    dom.addEventListener('wheel', e => {
      this.radius = clamp(this.radius * (e.deltaY > 0 ? 1.1 : 0.9), 2, 100);
    });
  }
  update(dt) {                                           // 每帧：惯性阻尼
    this.theta += this.vel.theta * dt * 60;
    this.phi = clamp(this.phi + this.vel.phi * dt * 60, 0.1, Math.PI / 2 - 0.1);   // 防翻转
    this.vel.theta *= this.damping; this.vel.phi *= this.damping;   // 衰减
    this.camera.position = spherical(this.theta, this.phi, this.radius);
    this.camera.lookAt(0, 0, 0);
  }
}
```
