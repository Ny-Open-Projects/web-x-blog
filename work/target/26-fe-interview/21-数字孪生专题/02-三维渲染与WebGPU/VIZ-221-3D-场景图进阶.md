## VIZ-221：3D 场景图进阶：变换矩阵缓存与脏标记传播

**答**：
- 题目：3D 场景图（千节点）每帧更新少数节点变换，但全树矩阵重算卡顿——实现「脏标记向上传播 + 向下失效」的增量矩阵更新。
- 思路：节点改 local matrix → 标记自身 dirty → 向上传播到祖先（父 world 依赖子？不对：子依赖父——子 dirty 时自身与后代 dirty，父无需重算）。正确传播：节点 dirty 时其 world 变 → 所有后代 world 变 → 标记后代。
- 评分点：dirty 传播方向（后代失效而非祖先）；缓存命中率高；world matrix = parent.world × local。

```javascript
class SceneNode3D {
  constructor() { this.children = []; this.local = mat4(); this.world = mat4();
    this.dirty = true; }
  setLocal(m) { this.local = m; this.markDirty(); }
  markDirty() {                                           // 自身 + 后代失效
    if (this.dirty) return;                                // 已脏：剪枝
    this.dirty = true;
    for (const c of this.children) c.markDirty();
  }
  updateWorld(parentWorld) {                              // 渲染前统一更新
    if (this.dirty) {
      this.world = mat4mul(parentWorld, this.local);
      for (const c of this.children) c.updateWorld(this.world);
      this.dirty = false;
    } else {
      for (const c of this.children) c.updateWorld(this.world);   // 缓存命中也要传 parent
    }
  }
}
// 千节点场景：改 1 个节点 → 只重算该子树（约 10 节点）而非全树 1000 次 matmul
```
