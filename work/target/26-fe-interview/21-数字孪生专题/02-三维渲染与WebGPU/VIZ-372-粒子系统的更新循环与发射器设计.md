## VIZ-372：粒子系统的更新循环与发射器设计

**答**：
- 更新循环：每帧对活粒子积分（位置 += 速度×dt，速度 += 加速度×dt），寿命到期回收——对象池避免 GC。
- 发射器：速率（个/秒，小数累积）、爆发（burst）、形状（点/球/锥体）参数化。
- 渲染：点精灵（gl.POINTS）或实例化 quad；纹理动画用 UV 偏移表；排序可选（加法混合免排序）。

```javascript
// 粒子池更新
function createPool(max = 5000) {
  return { pos: new Float32Array(max*3), vel: new Float32Array(max*3),
    life: new Float32Array(max), alive: 0, max };
}
function update(pool, dt, emit, gravity = [0, -9.8, 0]) {
  emit(pool, dt);                                   // 发射填充
  for (let i = 0; i < pool.alive; i++) {
    pool.life[i] -= dt;
    if (pool.life[i] <= 0) {                        // 回收：与末尾交换
      const last = --pool.alive;
      for (const arr of [pool.pos, pool.vel, pool.life])
        [arr[i], arr[last]] = [arr[last], arr[i]];
      i--; continue;
    }
    for (let j = 0; j < 3; j++) {
      pool.vel[i*3+j] += gravity[j] * dt;
      pool.pos[i*3+j] += pool.vel[i*3+j] * dt;
    }
  }
}
```
