## VIZ-358：空间剖分：四叉树/八叉树与均匀网格怎么选

**答**：
- 均匀网格：查询 O(1)、构建快，适合分布均匀的静态数据（瓦片地图/粒子网格）。
- 四叉树/八叉树：自适应密度（密集区细分），适合不均匀分布（POI 聚合、碰撞检测）。
- 更新成本：动态物体频繁移动时网格重建便宜（每帧清桶重插），树更新贵（节点合并/分裂）。

```javascript
// 均匀网格构建与查询
function buildGrid(items, cell) {
  const grid = new Map();
  for (const it of items) {
    const key = `${Math.floor(it.x / cell)},${Math.floor(it.y / cell)}`;
    if (!grid.has(key)) grid.set(key, []);
    grid.get(key).push(it);
  }
  return { grid, cell,
    query(x, y, r) {
      const out = [];
      const r0 = Math.floor((x - r) / cell), r1 = Math.floor((x + r) / cell);
      const c0 = Math.floor((y - r) / cell), c1 = Math.floor((y + r) / cell);
      for (let i = r0; i <= r1; i++)
        for (let j = c0; j <= c1; j++)
          out.push(...(grid.get(`${i},${j}`) ?? []));
      return out;
    } };
}
```
