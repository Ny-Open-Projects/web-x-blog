## VIZ-229：3D 数据绑定：场景图与数据模型的双向同步

**答**：
- 题目：3D 图表数据更新（新增/删除/修改数据点）同步到场景图——设计「数据模型 → 场景节点」的增量同步（不整体重建）。
- 思路：数据节点 id ↔ 场景节点映射表；diff 数据变更（增/删/改），增量操作场景节点（add/remove/update transform）。
- 评分点：映射表；diff 三类操作；整体重建的卡顿对照。

```javascript
class DataSceneSync {
  constructor(scene) { this.scene = scene; this.nodeMap = new Map(); }   // dataId → node
  sync(oldData, newData) {
    const oldIds = new Set(oldData.map(d => d.id));
    const newIds = new Set(newData.map(d => d.id));
    for (const d of newData) {
      if (!oldIds.has(d.id)) {                             // 增
        const node = createBarNode(d);
        this.scene.add(node); this.nodeMap.set(d.id, node);
      } else {
        const node = this.nodeMap.get(d.id);
        if (node.value !== d.value) node.setHeight(d.value);   // 改（动画过渡）
        node.setColor(d.color);
      }
    }
    for (const d of oldData)
      if (!newIds.has(d.id)) {                             // 删
        this.scene.remove(this.nodeMap.get(d.id));
        this.nodeMap.delete(d.id);
      }
  }
}
// 万点数据部分更新：重建 800ms → 增量同步 5ms（只动变化的几十个）
```
