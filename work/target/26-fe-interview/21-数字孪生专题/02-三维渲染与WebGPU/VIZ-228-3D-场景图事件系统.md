## VIZ-228：3D 场景图事件系统：冒泡与捕获

**答**：
- 场景图事件沿节点树冒泡（子→父）与捕获（父→子）——与 DOM 事件模型同构；命中节点先确定，再沿父链冒泡。
- 应用：数据点 hover → 系列高亮 → 图表联动（冒泡到图表层处理）。
- 实现：pick 得到叶子 → 事件对象带 target → dispatch 逐父传播（可 stopPropagation）。

```javascript
class SceneEventSystem {
  dispatch(type, target, payload) {
    const event = { type, target, ...payload, stopped: false,
      stopPropagation() { this.stopped = true; } };
    let node = target;                                     // 冒泡：叶子 → 根
    while (node && !event.stopped) {
      node.listeners?.[type]?.forEach(fn => fn(event));
      node = node.parent;
    }
  }
  onPointerDown(worldX, worldY) {
    const hit = pick(this.scene, rayFromScreen(worldX, worldY));
    if (hit) this.dispatch('pointerdown', hit.node, { worldX, worldY });
    else this.dispatch('pointerdown', this.scene, { worldX, worldY });   // 空白也派发
  }
}
// 应用：数据点监听 hover（叶子）；图表层监听任意点的 pointerdown 做框选（冒泡捕获空白）
```
