## VIZ-222：3D 空间索引：八叉树与 BVH 在场景查询中的选型

**答**：
- 空间查询（拾取/剔除/邻近）加速结构：八叉树（均匀空间划分，适合动态对象）vs BVH（按对象包围盒划分，适合静态三角网）。
- 动态对象频繁移动 → 八叉树增量更新便宜；静态网格射线求交 → BVH（Three.js 内置 BVH 扩展）。
- 构建成本：八叉树 O(n log)；BVH 构建 O(n log n) 但查询更快（SAH 划分）。

```javascript
class Octree {
  constructor(bounds, { depth = 8, maxPer = 8 } = {}) {
    this.bounds = bounds; this.depth = depth;
    this.maxPer = maxPer; this.objects = []; this.children = null;
  }
  insert(obj) {
    if (this.children) return this.childFor(obj.bounds).insert(obj);
    this.objects.push(obj);
    if (this.objects.length > this.maxPer && this.depth > 0) this.split();
  }
  split() {                                               // 八分
    const sub = subdivide(this.bounds);
    this.children = sub.map(b => new Octree(b, { depth: this.depth - 1, maxPer: this.maxPer }));
    for (const o of this.objects) this.childFor(o.bounds).insert(o);
    this.objects = [];                                     // 只存叶子（或跨界存当前层）
  }
  childFor(b) { return this.children.find(c => contains(c.bounds, b)) ?? this; }   // 跨界留上层
  query(frustum) {
    if (!intersects(this.bounds, frustum)) return [];       // 剪枝
    return [...this.objects, ...this.children?.flatMap(c => c.query(frustum)) ?? []];
  }
}
```
