## VIZ-304：手写地图聚合层完整实现（笔试）

**答**：
- 题目：地图 POI 聚合层——网格聚合 + zoom 切层 + 点击展开 + 增量更新（复用 ALG-539 环形技巧）。完整实现核心类。
- 思路：预计算金字塔（各 zoom 网格计数）；当前 zoom 取对应层；点击聚合格 → 请求下层细点；POI 变更增量改格子计数。
- 评分点：金字塔构建；展开交互；增量更新正确性（加/减同格）。

```javascript
class MapClusterLayer {
  constructor(points, maxZoom = 18) {                       // 复用 VIZ-247 金字塔
    this.layers = new Map();
    for (let z = 3; z <= maxZoom; z++) this.layers.set(z, this.buildLayer(points, z));
  }
  buildLayer(points, z) {
    const cells = new Map();
    for (const p of points) {
      const key = this.cellKey(p, z);
      cells.set(key, { count: (cells.get(key)?.count ?? 0) + 1,
        center: p, members: z >= 15 ? [p.id] : [] });      // 高 zoom 存成员
    }
    return cells;
  }
  cellKey(p, z) { const s = Math.pow(2, z);
    return `${Math.floor(p.lng * s)},${Math.floor(p.lat * s)}`; }
  render(zoom, viewport) {                                 // 视口内格子渲染
    const cells = this.layers.get(Math.round(zoom));
    return [...cells.values()].filter(c => inViewport(c.center, viewport));
  }
  onClusterClick(cellKey, zoom) {                          // 展开下钻
    const nextZoom = zoom + 2;
    const nextCells = this.layers.get(Math.min(nextZoom, 18));
    return [...nextCells].filter(([k]) => k.startsWith(cellKey.split(',').slice(0, -1).join(',')));   // 粗略子格
  }
  updateOne(point, removed = false) {                      // 增量
    for (const [z, cells] of this.layers) {
      const key = this.cellKey(point, z);
      const cell = cells.get(key);
      if (cell) cell.count += removed ? -1 : 1;
    }
  }
}
```
