## VIZ-247：地图可视化进阶：聚合金字塔与增量更新

**答**：
- 地图海量点（10 万 POI）：聚合金字塔——预计算各 zoom 级的网格聚合（服务端或 Worker），前端按 zoom 取对应层。
- 增量更新：POI 变更只重算受影响网格（空间索引定位），不重建整层。
- 渲染：WebGL 批量画聚合点（大小=权重）；点击聚合点 → 展开下层。

```javascript
class MapAggregationPyramid {
  constructor(points, { maxZoom = 18 } = {}) {
    this.layers = new Map();                               // zoom → Map<cellKey, count>
    for (let z = 3; z <= maxZoom; z++) this.buildLayer(z, points);
  }
  buildLayer(z, points) {
    const cells = new Map();
    const scale = Math.pow(2, z);
    for (const p of points) {
      const key = `${Math.floor(p.lng * scale)},${Math.floor(p.lat * scale)}`;
      cells.set(key, (cells.get(key) ?? 0) + 1);
    }
    this.layers.set(z, cells);
  }
  updateOne(point, oldPoint) {                             // 增量：只改受影响格
    for (let z = 3; z <= 18; z++) {
      const scale = Math.pow(2, z);
      for (const p of [point, oldPoint].filter(Boolean)) {
        const key = `${Math.floor(p.lng * scale)},${Math.floor(p.lat * scale)}`;
        const cells = this.layers.get(z);
        cells.set(key, (cells.get(key) ?? 0) + (p === point ? 1 : -1));
      }
    }
  }
}
```
