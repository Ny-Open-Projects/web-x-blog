## VIZ-350：三角形的重心坐标与点在三角形内测试

**答**：
- 重心坐标 (u, v, w)：p = u·A + v·B + w·C，u+v+w=1；用于插值（法线/UV/深度）与拾取命中点属性。
- 测试：三个子三角形面积比（叉积同号）即内部；2D 快速实现用边函数（edge function）。
- 光栅化本质：对像素中心算重心坐标，全正则覆盖，同时得到深度插值。

```javascript
// 重心坐标
function barycentric(p, a, b, c) {
  const v0 = [b[0]-a[0], b[1]-a[1]], v1 = [c[0]-a[0], c[1]-a[1]];
  const v2 = [p[0]-a[0], p[1]-a[1]];
  const d00 = v0[0]*v0[0]+v0[1]*v0[1];
  const d01 = v0[0]*v1[0]+v0[1]*v1[1];
  const d11 = v1[0]*v1[0]+v1[1]*v1[1];
  const d20 = v2[0]*v0[0]+v2[1]*v0[1];
  const d21 = v2[0]*v1[0]+v2[1]*v1[1];
  const den = d00*d11 - d01*d01 || 1e-9;
  const v = (d11*d20 - d01*d21) / den;
  const w = (d00*d21 - d01*d20) / den;
  return { u: 1 - v - w, v, w };       // 全 >=0 在内部
}
// 插值：depth = u*z0 + v*z1 + w*z2（注意透视校正：先除 w 再插）
```
