## SCN-654：3D 场景与 2D 面板怎么联动？
**答**：
- 联动桥：全局 TwinStore（deviceId → 状态），3D 拾取选中设备 → store.focus(deviceId) → 2D 面板切到该设备详情；反向：2D 列表点击 → 3D 相机飞到该设备点位。
- 相机动画：飞行用缓动插值（相机位置 + lookAt 目标同时 tween），期间禁用用户输入防止打架；多重点位排队时打断策略（最新优先）。
- 状态映射：3D 材质/颜色/告警脉冲由状态机驱动（state → material map），不散落在业务代码。
- 性能边界：联动触发的高频更新（万设备全量变色）走批量合帧，单设备变更立即渲染。
- 追问钩子：3D 和 2D 的数据一致怎么保证——同一 store 单源，谁都不自己拉数据，事件到达 → store → 两侧订阅者各自消费。

```javascript
const TwinStore = createStore({
  devices: new Map(), focusId: null,
  onFocus(id) {
    this.focusId = id;
    cameraFlyTo(points[id], { duration: 800, easing: easeInOutCubic });  // 3D 侧订阅
  },
  applyEvents(events) {
    for (const e of events) {
      this.devices.set(e.deviceId, { value: e.value, quality: e.quality });
      if (e.deviceId === this.focusId) this.emit('focus-update', e);     // 2D 侧订阅
    }
  },
});
// 2D 面板：TwinStore.subscribe('focus-update', e => detailChart.update(e));
// 3D 拾取：raycaster.onPick(id => TwinStore.onFocus(id));
```
