## SCN-667：仿真数据与真实数据融合怎么呈现？
**答**：
- 数据来源标注：每个数据点带 source（real/simulated/forecast），UI 上仿真数据统一虚线/半透明/「仿真」角标——大屏混着看时必须一眼可辨。
- 融合场景：能耗预测曲线叠加实测曲线（预测区间用带状），应急演练时仿真人流/温度场叠加在真实场景上（图层开关）。
- 时间轴区分：仿真数据是「未来时间」或「假设时间」，时间轴上用独立色段表示，与实时段拼接处明确分界线。
- 数字孪生的核心承诺：真实驱动仿真、仿真反哺决策——前端呈现上要保持「真实永远比仿真可信度高」的视觉层级。
- 追问钩子：预测数据和实测偏差大时怎么办——偏差可视化（残差带），并在图例标注模型置信度，不静默替换实测值。

```javascript
function fuseLayers(realSeries, simSeries) {
  return {
    real: { data: realSeries, style: { line: 'solid', opacity: 1 }, badge: '实测' },
    sim:  { data: simSeries,  style: { line: 'dashed', opacity: 0.5 }, badge: '仿真' },
    residual: simSeries.map((s, i) => ({       // 残差带：仿真可信度可视化
      t: s.t, r: Math.abs(s.v - (realSeries.find(x => x.t === s.t)?.v ?? s.v)),
    })),
  };
}
// 时间轴：<RealSegment/> | <div class="sim-divider">仿真段 →</div> | <SimSegment/>
```
