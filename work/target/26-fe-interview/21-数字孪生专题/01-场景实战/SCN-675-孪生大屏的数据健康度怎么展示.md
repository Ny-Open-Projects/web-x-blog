## SCN-675：数据健康度展示怎么设计？
**答**：
- 健康度分层：全局（网关连接/推送延迟）→ 数据源级（每个数据源的最近更新时间/断流时长）→ 指标级（单指标 quality 标注）。
- 呈现原则：正常时隐身（健康度不占注意力）；异常时按影响面升级——单指标陈旧灰显该卡片，数据源断流顶部横幅告警，全链路断网进入降级态（显示最后快照 + 「数据截至 xx:xx」大字标）。
- 陈旧定义：每指标配置 staleness 阈值（温度 1 分钟/电量 1 小时），超阈值即标 stale，不用统一标准。
- 管理层沟通价值：大屏显示「实时」但数据是死的，会误导决策——健康度可见是数字孪生的可信度基础。
- 追问钩子：降级态怎么设计——冻结最后快照 + 明确标注时间与影响范围，同时推送恢复后自动刷新，绝不假实时。

```javascript
function healthCheck(metrics, thresholds) {
  const now = Date.now();
  const report = { fresh: 0, stale: [], offline: [] };
  for (const m of metrics) {
    const age = now - m.lastUpdateTs;
    if (age > thresholds[m.type] * 3) report.offline.push(m.id);     // 3 倍阈值 = 断流
    else if (age > thresholds[m.type]) report.stale.push(m.id);      // 陈旧
    else report.fresh++;
  }
  return {
    ...report,
    banner: report.offline.length ? `数据源断流 ${report.offline.length} 个`
      : report.stale.length ? `${report.stale.length} 项数据延迟` : null,
    snapshotMode: report.offline.length / metrics.length > 0.5,      // 过半断流进快照模式
  };
}
```
