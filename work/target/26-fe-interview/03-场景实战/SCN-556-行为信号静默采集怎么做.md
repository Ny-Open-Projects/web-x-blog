## SCN-556：行为信号静默采集怎么做？
**答**：
- 采集内容：鼠标移动速度与转角分布、点击间隔节奏、键盘输入节奏（keystroke dynamics）、滚动惯性、触屏压力/面积——刻画「操作节奏」。
- 性能原则：采集器用被动监听 + 轻量聚合（只存统计量不存原始点，或环形缓冲 500 点），绝不每事件上报；合并批次在 idle 时发送。
- 数据瘦身：上报的是特征（均值/方差/熵）而非全量轨迹，服务端模型吃特征；调试模式可开全量采样。
- 时机：登录/支付等关键场景前采集窗口 3~10 秒即可，不必全程采集。
- 追问钩子：静默采集会不会违反隐私——最小化原则 + 政策声明 + 不含内容（只含节奏与轨迹形态，不记录输入了什么）。

```javascript
function behaviorCollector(windowMs = 8000) {
  const stats = { moves: 0, dist: 0, turns: 0, clickGaps: [], keyGaps: [] };
  let last = null, lastClick = 0, lastKey = 0;
  const onMove = e => {
    stats.moves++;
    if (last) {
      stats.dist += Math.hypot(e.clientX - last.x, e.clientY - last.y);
      if (last.p) {                              // 方向变化率（转角）
        const a1 = angle(last, last.p), a2 = angle(last, e);
        stats.turns += Math.abs(a1 - a2);
      }
    }
    last = { ...last, x: e.clientX, y: e.clientY, p: last };  // 环形摘要，不存全量
  };
  document.addEventListener('pointermove', onMove, { passive: true });
  document.addEventListener('click', () => {
    stats.clickGaps.push(performance.now() - lastClick); lastClick = performance.now();
  }, { passive: true });
  setTimeout(() => {                             // 窗口结束：出特征并卸载监听
    document.removeEventListener('pointermove', onMove);
    return features(stats);                      // { moveRate, turnEntropy, clickCV, ... }
  }, windowMs);
}
```
