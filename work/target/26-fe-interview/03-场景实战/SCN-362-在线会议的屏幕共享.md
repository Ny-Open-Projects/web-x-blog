## SCN-362：会议屏幕共享（选择源/推流/共享标注）怎么实现？

**答**:
- 共享源选择：getDisplayMedia（屏幕/窗口/标签页选择——浏览器原生选择器），音频共享（系统声音共享：标签页音频——Chrome 支持 tab audio），共享提示（共享中悬浮条：你在共享屏幕/停止按钮——防隐私泄露）。
- 推流实现：共享流发布（replaceTrack 切换摄像头→共享流——SCN-239 复用无感切换）、共享质量自适应（共享内容检测：静态画面降码率——内容感知编码）、共享中的摄像头画中画（共享+摄像头同推）。
- 观看端：共享视图切换（自动切大屏）、缩放与标注（观看者请求标注权限→在共享画面上画笔——SCN-231 白板复用）、清晰度选择。
- 边界处理：共享中断（窗口关闭/最小化→共享流结束信令）、共享黑屏（受版权保护内容 getDisplayMedia 拒绝——降级提示）、远程控制（可选：观看者控制共享者鼠标——高危需显式授权）。

```javascript
async function startShare() {
  const stream = await navigator.mediaDevices.getDisplayMedia({
    video: { frameRate: 15 }, audio: 'tab' });
  await sender.replaceTrack(stream.getVideoTracks()[0]); // 无感切换
  stream.getVideoTracks()[0].onended = stopShare;   // 用户停止
  showShareBar();                                   // 悬浮提示条
}
// 内容感知：frameDiffDetector → static → 降码率省带宽
// 观看标注：requestAnnotate() → owner.grant() →
//   白板层叠加（SCN-231 复用）。
```
