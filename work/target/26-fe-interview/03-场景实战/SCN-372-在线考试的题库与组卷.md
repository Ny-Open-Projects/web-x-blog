## SCN-372：在线考试的题库与组卷（智能组卷/AB 卷/随机序）怎么实现？

**答**:
- 题库管理：题目 schema（题型/题干/选项/答案/解析/知识点标签/难度——SCN-307 知识点体系联动）、题目生命周期（草稿→审核→入库→废弃）、批量导入（Excel/Word 解析导入——SCN-354 导入保真复用）。
- 智能组卷：组卷策略（按知识点覆盖/难度分布/总分约束——约束求解）、手动组卷+智能推荐（按策略推荐候选题——教师确认）、AB 卷（同知识不同题——打乱策略：题目随机序+选项随机序，选项顺序影响答案位置的服务端判分适配）。
- 防作弊配合：随机化与防抄（相邻考生不同卷/不同序——AB 卷意义）、题库轮换（每次考试从题库抽题——重复率控制）。
- 质量运营：题目质量分析（正确率/区分度——低区分度题目标记）、题目复用追踪（哪些考试用过）。

```javascript
// 组卷约束求解
function compose({ kps, difficulty, total, count }) {
  // 按知识点覆盖 + 难度分布 + 总分约束选题
  const pool = bank.byKps(kps);
  return solve(pool, { count, dist: difficulty,
    score: total });                        // 服务端求解
}
// AB 卷：paperA = compose(...), paperB = compose(...)
//   随机序：shuffle(questions) → 选项 shuffle →
//   答案判分按内容不按位置（服务端）。
// 质量：itemAnalysis(结果) → {correctRate, discrimination}
//   discrimination < 0.2 → 标记复核。
```
