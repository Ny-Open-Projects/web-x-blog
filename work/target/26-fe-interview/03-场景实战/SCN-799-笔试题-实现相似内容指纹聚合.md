## SCN-799：手写相似内容聚合

**需求与边界**：
- 需求：对封面图计算 8×8 pHash；按汉明距离 ≤ 6 聚合相似视频为批次；批次输出代表样本（最早投稿）与成员列表。
- 边界：① pHash：缩到 8×8 灰度 → 与均值比较得 64bit；② 聚类用并查集（距离链式传递）；③ 距离阈值参数化。

**答**：
```javascript
function pHash(imgData) {                            // imgData: 64×64 灰度
  const tiny = downsample8x8(imgData);               // 缩到 8×8
  const avg = tiny.reduce((s, v) => s + v, 0) / 64;
  let hash = 0n;
  tiny.forEach((v, i) => { if (v > avg) hash |= 1n << BigInt(i); });
  return hash;
}
const hamming = (a, b) => { let d = 0, x = a ^ b; while (x) { d += Number(x & 1n); x >>= 1n; } return d; };
function clusterBySimilarity(items, { threshold = 6 } = {}) {   // items: [{id, hash}]
  const parent = [...items.keys()];                   // 并查集
  const find = (x) => parent[x] === x ? x : (parent[x] = find(parent[x]));
  for (let i = 0; i < items.length; i++)
    for (let j = i + 1; j < items.length; j++)
      if (hamming(items[i].hash, items[j].hash) <= threshold) {
        const ri = find(i), rj = find(j);
        if (ri !== rj) parent[ri] = rj;               // 链式传递合并
      }
  const groups = new Map();
  items.forEach((it, i) => {
    const root = find(i);
    (groups.get(root) ?? groups.set(root, []).get(root)).push(it);
  });
  return [...groups.values()].map(members => ({
    representative: members.sort((a, b) => a.uploadTs - b.uploadTs)[0],  // 最早投稿为代表
    members,
    batch: members.length > 1,
  }));
}
```

**评分点**:
- pHash 计算正确（8×8 均值二值化 64bit）。
- 汉明距离 + 并查集聚类（链式传递 O(n²) 可接受规模）。
- 代表样本选最早投稿（可追溯源头）。
- 阈值参数化（模板批量场景可调）。

## 变体与延伸（补充）

**变体与延伸**：

1. 图片被裁剪或加边框后 pHash 还聚得上吗 → 聚不上，pHash 对裁剪敏感；要补中心区域多尺度哈希并下调阈值。
2. 十万条数据 O(n²) 两两比较跑不动怎么办 → 把 64bit 切 7 段，汉明距离 ≤ 6 必有一段完全相同，用分段哈希出候选集再精算。
3. 并查集链式传递会把相距很远的 A 和 C 聚在一起怎么处理 → 明确接受传递闭包语义（批次定义如此），若要严格控制簇内距离则改用 DBSCAN。
