## SCN-643：手写审批权限校验器

**需求与边界**：
- 需求：check(user, action, ctx) 综合角色矩阵、委托关系、数据范围（本部门）、金额上限后给出 allow/deny + 原因。
- 边界：① 委托链最多一层（禁链式）；② 超金额上限的委托拒绝；③ deny 必须带原因码（可展示）。

**答**：
```javascript
function check(user, action, ctx) {
  const role = user.roles.find(r => PERM_MATRIX[r]?.operate.includes(action) || PERM_MATRIX[r]?.operate.includes('*'));
  if (!role) return deny('NO_ROLE', `${user.id} 无 ${action} 角色`);
  const p = PERM_MATRIX[role];
  // 数据范围
  if (p.view === 'dept' && ctx.instanceDept !== user.deptId)
    return deny('OUT_OF_SCOPE', '该单不在你的部门范围');
  // 委托校验：user 是被委托人时
  if (user.actFor) {
    if (user.actFor.chain) return deny('CHAIN_DELEGATE', '禁止链式委托');
    if (ctx.amountFen > user.actFor.amountCap)
      return deny('DELEGATE_CAP', `超过委托金额上限 ${user.actFor.amountCap}`);
    if (Date.now() > user.actFor.endTs)
      return deny('DELEGATE_EXPIRED', '委托已过期');
  }
  // 操作特例
  if (action === 'skip' && ctx.amountFen > SKIP_LIMIT)
    return deny('SKIP_LIMIT', '大额禁止特批跳过');
  return { allow: true };
}
const deny = (code, msg) => ({ allow: false, code, msg });    // 原因码可直接渲染给用户
// 委托链检查：actFor = { from: '李四', chain: false, amountCap, endTs }
```

**评分点**:
- 角色→动作矩阵 + 通配符支持。
- 数据范围（部门）校验独立于角色。
- 委托三重校验（禁链式/金额上限/有效期）。
- deny 结构化（code+msg 可直接展示，不裸抛）。
