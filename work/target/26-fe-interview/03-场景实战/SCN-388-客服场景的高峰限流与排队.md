## SCN-388：客服高峰期（排队/优先级/溢出）怎么设计？

**答**:
- 排队策略：排队透明（位置/预计等待——SCN-334 排队复用）、优先级（VIP/紧急工单插队——SCN-457 复用）、多技能组排队（跨组排队——组间调度）。
- 溢出策略：机器人兜底（排队中机器人继续服务——等待不空转）、异步留言（超长队→留言工单：承诺回复时效）、回呼预约（电话渠道：预约回呼时段）。
- 客户侧体验：等待价值感（排队中自助解决推荐——可能不用排了）、取消与重排（取消排队随时/重排规则透明）、等待焦虑管理（进度可视+预期诚实——"当前排队较多"不说谎）。
- 运营联动：实时调度看板（排队积压/客服负载——主管实时调度：SCN-257 复用）、临时扩容（跨组支援信令）、高峰预案（大促客服高峰预案——SCN-212 时间线复用）。

```javascript
// 排队 + 机器人兜底
ws.on('queue', (q) => {
  ui.queue(q);                               // 位置/ETA 透明
  bot.serveWhileWaiting(q);                  // 排队不空转
  if (q.eta > 30e3) offerAsyncTicket();      // 溢出留言
});
// VIP 插队：priority(t) → frontOf(queue)（SCN-457）
// 主管看板：dashboard({ backlog, agentLoad }) →
//   crossAssign(groupA → groupB)。
// 大促预案：peakPlan.scaleAgents()（SCN-212 T-1 周）。
```
