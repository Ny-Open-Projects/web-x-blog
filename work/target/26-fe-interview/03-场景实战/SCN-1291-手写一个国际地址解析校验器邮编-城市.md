## SCN-1291：手写一个国际地址解析校验器（邮编-城市匹配）

**答**：
- 需求：implement AddrValidator(postalIndex)。validate(addr)：邮编正则（按国）+ 邮编-城市匹配（postalIndex 查询）；不匹配返回候选城市；normalize 输出标准化（大写邮编/去空格）。
- 边界：postalIndex 无该邮编返回 unknown（人工审核标记）；大小写不敏感匹配；多城市同邮编返回全部候选。
- 评分点：正则校验；邮编城市匹配；候选；归一化

```javascript
class AddrValidator {
  constructor(postalIndex) { this.index = postalIndex; }
  validate(addr) {
    const schema = SCHEMAS[addr.country] ?? SCHEMAS.US;
    if (!schema.zip.test(addr.postal ?? ''))
      return { ok: false, reason: '邮编格式错误' };
    const cities = this.index[addr.country]?.[addr.postal.toUpperCase()] ?? [];
    if (!cities.length)
      return { ok: false, reason: '邮编无法匹配城市', manual: true };
    if (!cities.includes(addr.city))
      return { ok: false, candidates: cities,
        reason: `邮编对应城市: ${cities.join('/')}` };
    return { ok: true, normalized: this.normalize(addr) };
  }
  normalize(addr) {
    return { ...addr, postal: addr.postal?.toUpperCase().replace(/\s+/g, ''),
      city: addr.city };
  }
}
const SCHEMAS = { DE: { zip: /^\d{5}$/ }, US: { zip: /^\d{5}(-\d{4})?$/ } };
```
