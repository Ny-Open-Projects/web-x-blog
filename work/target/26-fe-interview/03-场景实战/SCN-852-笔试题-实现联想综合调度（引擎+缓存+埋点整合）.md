## SCN-852：手写联想综合调度器

**需求与边界**：
- 需求：整合「输入守护（IME/最短长度）→ 缓存检查 → 请求（seq+abort）→ 降级（服务失败走本地历史）→ 曝光/采纳埋点」，单入口 `handleInput(q)`。
- 边界：① 缓存命中跳过网络（埋点标 cached）；② 服务失败 2 次进入降级模式（本次会话后续直接本地）；③ traceId 全链贯穿。

**答**：
```javascript
function createSuggestOrchestrator({ api, historyStore } = {}) {
  const engine = createSuggestEngine(api);             // SCN-837
  const cache = createSuggestCache();                  // SCN-842
  const profiler = latencyProfiler();                  // SCN-850
  let degraded = false, failCount = 0;
  async function handleInput(q, { incognito = false } = {}) {
    profiler.markInput();
    const guard = engine.onInput(q);
    if (guard.skipped || guard.items) return guard;    // IME/短前缀直接返回
    const persona = incognito ? 'anon' : currentUser.id;
    const hit = cache.get(q, { version: serverVer, persona });
    if (hit) { render(hit); track(q, hit, { cached: true }); return hit; }
    try {
      profiler.markFire();
      const res = await profiler.markResponse(engine.fire(q));
      failCount = 0;
      if (res?.items) { cache.set(q, res.items, { version: serverVer, persona }); render(res.items); }
      return res;
    } catch {
      if (++failCount >= 2) degraded = true;           // 连续失败进降级
      const local = await historyStore.list();         // 本地历史兜底
      render(filterByPrefix(local, q));
      return { items: local, degraded: true };
    }
  }
  function track(q, items, meta) {
    const traceId = newTrace();
    const tracker = createImpressionTracker(traceId);  // SCN-841
    bindTrackerToDOM(tracker);
    return { traceId, tracker };
  }
  return { handleInput, get degraded() { return degraded; } };
}
```

**评分点**:
- 全链整合顺序正确（守护→缓存→请求→降级）。
- 降级模式会话级（连续失败 2 次锁定，避免每输入都失败重试）。
- 缓存命中埋点标 cached（归因区分）。
- traceId 贯穿 + 降级路径也有输出（下拉永不空屏）。
