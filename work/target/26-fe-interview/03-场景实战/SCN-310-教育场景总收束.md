## SCN-310：在线教育场景（课堂/作业/考试/课程销售/多角色）怎么总收束？

**答**:
- 全景五块：实时课堂（SCN-231~240）、作业考试闭环（301 提交批改/302 回放/308 随堂测/236 防作弊）、学习驱动（303 自适应/307 错题本）、商业转化（304 详情/289 裂变）、组织与角色（305 双师/306 多角色/309 课程表）。
- 教育特有的工程约束：多角色合规（青少年防沉迷/家长知情权——服务端强制）、高可信数据（考试与成绩的完整性与审计）、课堂秩序（控制权中心化）——教育前端是"强规则"场景，规则先行于体验优化。
- 资产复用：实时课堂基建（RTC/信令/白板——SCN-231~240 全复用）、任务中心（转写/批改/导出异步任务）、掌握度与错题引擎（学习侧核心资产）、IM 与通知（家校沟通复用 IM 底座）。
- 收束心法：教育前端 = 实时互动（复用协作/直播基建）× 学习科学（掌握度/记忆曲线的产品化）× 合规秩序（多角色强规则）——技术多数可复用，教育逻辑（掌握度模型/防沉迷/教学法交互）是行业壁垒所在。

```text
教育全景：
课堂：直播+课件跟随+连麦+秩序（复用协作直播基建）
学习：作业闭环 / 随堂测洪峰 / 错题本 /
  自适应路径 / 回放增强
商业：详情转化 / 裂变 / 双师服务
组织：多角色分离 / 防沉迷 / 家校 IM
课程表：冲突检测 / 提醒路由。
心法：实时可复用，教育逻辑（掌握度/
  防沉迷/教学法）是壁垒。
```
