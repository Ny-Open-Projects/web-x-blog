## SCN-602：手写人机验证综合调度器（整合前几题的模块）

**需求与边界**：
- 需求：整合「评分→分级验证→结果缓存→降级链」，对外单入口 `guard(scene, user)`；低分用户走缓存复用，高分强验证；验证服务故障走降级。
- 边界：① 缓存命中直接返回 token（带 cached 标记）；② 大额操作绕过缓存；③ 全链失败返回 exhausted 由业务决定放行。

**答**：
```javascript
async function guard(scene, user, { amountFen = 0 } = {}) {
  const { score, level } = await withFallback(
    () => api.post('/risk/score', { scene, userId: user.id, signals: collector.snapshot() }),
    () => ({ score: 50, level: 1 }));               // 评分接口故障：默认中风险
  // 缓存复用：低风险 + 非大额
  if (level === 0 && amountFen < 500_0000) {
    const cached = verifyCache.get(user.id, scene);
    if (cached) return { pass: true, token: cached, cached: true };
  }
  // 分级验证链
  const chain = [['slider'], ['slider', 'sms'], ['puzzle', 'face']][level] || ['slider'];
  const scheduler = createDegradationScheduler(chain);
  const r = await scheduler.run(scene);
  if (r.pass) {
    verifyCache.put(user.id, scene, r.token);       // 通过后入缓存
    return { pass: true, token: r.token, verifier: scheduler.active[0] };
  }
  return { pass: false, reason: r.reason };         // exhausted 交业务决策
}
const withFallback = async (fn, fb) => fn().catch(e => {
  report({ type: 'SCORE_FALLBACK', err: e.message });
  return fb();
});
```

**评分点**:
- 模块整合正确：评分→分级→缓存→降级链全链路。
- 缓存命中条件（低风险+非大额）与 cached 标记。
- 评分接口故障回退中风险（fail-safe 不 fail-open）。
- exhausted 结果交业务层决策（权限边界清晰）。
