## SCN-278：直播间的播放质量监控（卡顿率/延迟/黑屏）与兜底怎么做？

**答**:
- 质量指标体系：卡顿率（stall 次数与时长/播放时长）、首帧时间、延迟（缓冲时长近似+RTT）、黑屏检测（视频帧采样：连续 N 帧无变化+音频无输出→疑似黑屏/卡死）、断流次数——指标分端汇聚（观众端体验指标）。
- 采集方式：播放器事件埋点（stall/waiting/error）、视频帧采样（定时截帧 diff 检测黑屏/冻结——低成本抽样 1 次/5s）、日志流水（轻量本地 ring buffer，异常时批量上报）。
- 异常兜底：卡顿→自动换线路（多线路测速选优）、黑屏/冻结→自动重连（播放器 reload 级）、长时间无流→降级提示（"主播网络异常"+封面图）——兜底动作自动执行+上报。
- 值班联动：实时大盘（卡顿率/在线数异常告警——直播间级维度）、问题定位（trace：房间号+线路+CDN 节点，快速定位是 CDN 还是端问题）。

```javascript
const monitor = createPlayMonitor(player, roomId);
player.on('stall', (e) => monitor.record('stall', e.dur));
player.on('error', (e) => { monitor.record('error', e);
  autoRecover(player); });                   // 换线重连
setInterval(async () => {                    // 黑屏抽样
  const frame = await grabFrame(player);
  if (isBlack(frame) && !audioPlaying())
    monitor.record('blackframe');            
    if (monitor.count('blackframe') >= 3) reload(player);
}, 5000);
// 兜底链：卡顿→换线；冻结→reload；无流→封面+提示；
// 全部自动执行并上报 trace（房间+线路+CDN 节点）。
```
