## SCN-1284：手写一个多语言评价翻译缓存器

**答**：
- 需求：implement ReviewTranslate(cache, translateFn)。display(review, userLang)：同语言直出；异语言先查缓存，miss 调 translateFn 并写缓存（TTL 7 天）；返回 { text, machine: true, fromCache }。
- 边界：翻译失败回退原文并标注 untranslated；同 review+lang 幂等；并发同 key 合并请求（单飞）。
- 评分点：缓存 TTL；单飞；失败回退；幂等

```javascript
class ReviewTranslate {
  constructor(cache, translateFn) { this.cache = cache; this.fn = translateFn;
    this.inflight = new Map(); }
  async display(review, userLang) {
    if (review.lang === userLang)
      return { text: review.text, machine: false };
    const key = `${review.id}:${userLang}`;
    const hit = await this.cache.get(key);
    if (hit) return { text: hit, machine: true, fromCache: true };
    if (this.inflight.has(key)) return this.inflight.get(key);
    const p = this.fn(review.text, userLang)
      .then(text => { this.cache.set(key, text, { ttl: 7 * 86400_000 });
        this.inflight.delete(key);
        return { text, machine: true, fromCache: false }; })
      .catch(() => { this.inflight.delete(key);
        return { text: review.text, machine: true, untranslated: true }; });
    this.inflight.set(key, p);
    return p;
  }
}
```
