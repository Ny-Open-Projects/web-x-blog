## SCN-1279：手写一个关税预估计算器

**答**：
- 需求：implement DutyCalc(country)。estimate(items) 按 HS 编码税率表计算关税+VAT：{ taxable = 申报价值, duty = taxable × dutyRate, vat = (taxable + duty) × vatRate }；免税额度以下返回零税；输出明细。
- 边界：HS 码未知按默认税率（标注估算）；免税额度（如 US $800 de minimis）；多件合计计算；税率表缺失抛错。
- 评分点：免税额度；HS 税率；VAT 计算；默认税率

```javascript
class DutyCalc {
  constructor(country, rates) {
    this.country = country; this.rates = rates;        // { hsCode: dutyRate }
    this.deMinimis = { US: 800, EU: 150 }[country] ?? 0;
    this.vatRate = { DE: 0.19, FR: 0.20, US: 0 }[country] ?? 0.2;
  }
  estimate(items) {
    const declared = items.reduce((s, i) => s + i.value, 0);
    if (declared <= this.deMinimis)
      return { duty: 0, vat: 0, note: `低于免税额度 $${this.deMinimis}` };
    const detail = items.map(i => {
      const rate = this.rates[i.hs] ?? 0.05;           // 未知 HS 默认税率
      const duty = i.value * rate;
      return { hs: i.hs, declared: i.value, rate,
        duty: +duty.toFixed(2),
        vat: +((i.value + duty) * this.vatRate).toFixed(2) };
    });
    return { detail,
      duty: +detail.reduce((s, d) => s + d.duty, 0).toFixed(2),
      vat: +detail.reduce((s, d) => s + d.vat, 0).toFixed(2),
      mode: this.deMinimis ? 'DDU 估算' : 'DDP' };
  }
}
```
