## SCN-760：审核效率度量怎么设计？
**答**：
- 核心指标：人均每小时审核量（分品类）、单条平均审核时长、队列积压深度与预估清空时间、SLA 达标率（进审后 N 分钟内完成）。
- 口径细节：时长 = 领取到提交（剔除锁定超时释放的）；吞吐按品类归一（长视频/短视频不可直接比）。
- 平衡指标：效率指标必须与质检准确率同屏呈现——「又快又准」才是真快，只快不准是灾难。
- 积压预警：积压超阈值（预估清空 > 2h）自动告警并建议加开人审资源或临时放宽直放比例。
- 追问钩子：怎么防止效率指标被博弈（秒审刷量）——最短审核时长下限 + 盲测抽检 + 时长分布异常检测（秒审占比高的账号自动质检加权）。

```javascript
const efficiency = {
  throughput: (logs, categoryNorm) => groupBy(logs, 'auditor')
    .map(([id, logs]) => ({ id, perHour: logs.length / hours(logs) * categoryNorm })),
  backlog: (queue) => ({ depth: queue.length, eta: queue.length / teamRate,
    alert: queue.length / teamRate > 2 }),         // 预估清空 > 2h 告警
  antiGame: (logs) => ({
    tooFast: logs.filter(l => l.duration < 3_000).length / logs.length,   // 秒审占比
    trigger: (ratio) => ratio > 0.2 && flagForQC(auditor),
  }),
};
```
