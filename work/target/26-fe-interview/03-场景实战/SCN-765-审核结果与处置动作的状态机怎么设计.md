## SCN-765：审核处置状态机怎么设计？
**答**：
- 状态链：待审 → 审核中（锁定）→ 已审（通过/驳回）→ 处置中（异步执行下架/通知）→ 已处置 → 可申诉 → 终局；驳回分支有「驳回待执行」中间态（处置可能失败需重试）。
- 处置可靠性：处置动作（下架/通知创作者/信誉分扣减）异步执行 + 重试 + 对账（SCN-对账模式），前端状态由推送更新。
- 前端动作映射：每个状态渲染可用动作（已审通过可申诉入口；处置中显示进度）。
- 幂等与防重：处置指令带幂等键，重试不重复扣分。
- 追问钩子：为什么处置不是同步的——下架涉及 CDN 刷新/搜索索引/推荐剔除多个下游，同步等待会超时；异步 + 状态机让每一步可追踪可重试。

```javascript
const REVIEW_FSM = {
  transitions: {
    PENDING: ['REVIEWING'],
    REVIEWING: ['PASSED', 'REJECTED'],
    REJECTED: ['EXECUTING', 'REVIEWING'],            // 处置失败可重审
    EXECUTING: ['EXECUTED', 'EXEC_FAILED'],
    EXEC_FAILED: ['EXECUTING'],                      // 重试
    PASSED: ['APPEALED'],
    APPEALED: ['FINAL'],
  },
};
function executePunish(videoId, action) {            // 幂等处置
  return api.post('/punish', { videoId, action,
    idempotencyKey: `${videoId}:${action}:${hash(videoId, action)}` });
}
```
