## SCN-245：低代码页面被运营改出问题，版本管理与快速恢复怎么设计？

**答**:
- 版本体系：schema 快照（每次发布自动存版本：内容+发布人+变更摘要）、草稿与发布分离（编辑区草稿/线上版本两套状态）、版本对比（schema diff 可视化：改了哪个节点哪个属性）。
- 发布流程：预览验证（真机预览+校验规则：必填/链接有效性/组件兼容性）→ 灰度发布（按比例/白名单）→ 全量——运营自助发布但走轻审核（关键页面强制审核）。
- 快速恢复：一键回滚（版本指针切回，秒级生效——SCN 配置热更新同源）、回滚通知（相关人员告警）、回滚后自动建修复草稿（基于回滚版本继续修）。
- 防御性设计：发布前自动检查（性能预算/Lighthouse 门槛/死链检测）、高危操作二次确认（删除大区块/清空页面）、操作日志（谁在何时改了什么——审计与追责）。

```javascript
async function publish(draftId, { gray = 1.0 }) {
  const check = await validateSchema(draft.schema);
  if (!check.ok) return { ok: false, issues: check.issues };
  const ver = await store.saveVersion(draft, {
    author: me, summary: draft.changeLog });
  await pointers.set(draft.pageId, ver.id, { gray });
  audit.log({ action: 'publish', pageId: draft.pageId, ver: ver.id });
  return { ok: true, version: ver.id,
    rollback: `回滚命令：pointer → ${await store.previous(draft.pageId)}` };
}
async function rollback(pageId) {
  const prev = await store.previous(pageId);
  await pointers.set(pageId, prev.id, { gray: 1 });
  await store.createDraft(pageId, prev.id);   // 自动建修复草稿
  notifyOwners(pageId, '已回滚至上一版本');
}
```
