## SCN-473：手写实验分流：hash 正交、互斥域、比例精确分桶

**需求与边界**：
- 输入：userId、实验配置列表；输出：各实验分组。
- 边界要求：① hash 种子含实验 id（正交——不同实验独立）；② 互斥域（同域实验只能进一个）；③ 比例精确（权重累加）；④ 同用户稳定同组。

**答**：
```javascript
function assign(userId, experiments) {
  const result = {}; const domainTaken = new Map();
  for (const exp of experiments) {
    if (exp.domain && domainTaken.has(exp.domain)) {
      result[exp.id] = 'domain_conflict'; continue;   // 互斥域占用
    }
    // 正交：种子 = 实验 id + userId
    const h = murmur3(`${exp.id}:${userId}`) % 10000;
    let acc = 0, group = 'control';
    for (const g of exp.groups) {              // [{id, weight}]
      acc += g.weight * 100;
      if (h < acc) { group = g.id; break; }    // 权重累加精确
    }
    result[exp.id] = group;
    if (exp.domain && group !== 'control')
      domainTaken.set(exp.domain, exp.id);     // 控制组不占域
  }
  return result;
}
// 正交原理：种子含实验 id → 各实验分桶独立不相关；
// 稳定性：同 userId+实验 id → 恒定同组（无状态分流）；
// 精度：10000 桶 → 0.01% 粒度。
```

**评分点**:
- 种子含实验 id 的正交原理阐述正确。
- 互斥域机制（控制组不占域）。
- 权重累加分桶（比例精确）+ 同用户稳定。
- murmur 类均匀 hash 的选型意识。
