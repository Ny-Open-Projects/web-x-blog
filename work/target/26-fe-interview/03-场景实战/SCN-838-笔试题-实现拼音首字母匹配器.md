## SCN-838：手写拼音/首字母匹配器

**需求与边界**：
- 输入：query（如 "jsq"/"jisuanqi"/"计算器"）、词库（词 + 拼音全拼 + 首字母）；输出匹配结果与匹配级别。
- 要求：① 精确前缀（中文对中文）> 拼音全拼前缀 > 首字母前缀 > 子串包含；② 打分排序；③ 大小写不敏感；④ 数字/英文段单独精确匹配。

**答**：
```javascript
function matchSuggest(q, dict) {
  const norm = q.trim().toLowerCase();
  const results = [];
  for (const item of dict) {
    const { word, pinyin, initials } = item;           // pinyin: 'jisuanqi', initials: 'jsq'
    let level = 0, score = 0;
    if (word.startsWith(q)) { level = 3; score = 100; }              // 中文前缀
    else if (/^[a-z]+$/.test(norm)) {                  // 字母输入走拼音
      if (pinyin.startsWith(norm)) { level = 2.5; score = 80; }
      else if (initials.startsWith(norm)) { level = 2; score = 60; }
      else if (word.toLowerCase().includes(norm)) { level = 1.5; score = 40; }
    } else if (word.includes(q)) { level = 1.5; score = 40; }        // 子串
    if (level) results.push({ word, level, score,
      bonus: item.hot ?? 0 });                         // 热度加成参与排序
  }
  return results
    .map(r => ({ ...r, total: r.score + r.bonus }))
    .sort((a, b) => b.total - a.total || a.word.length - b.word.length)
    .slice(0, 10);
}
// dict 预处理：多音字多读音都生成 pinyin/initials（'重庆' -> ['chongqing','zhongqing']）
```

**评分点**:
- 四级匹配层次清晰且打分单调递减。
- 字母输入才走拼音路径（中文输入不匹配拼音）。
- 多音字多读音入索引的意识。
- 排序融合热度 bonus + 长度 tiebreaker。
