## SCN-437：手写地址粘贴解析：字段抽取、置信度降级、配送范围校验

**需求与边界**：
- 输入：用户粘贴的长文本；输出：结构化地址（姓名/电话/省市区/详址）。
- 边界要求：① 手机号正则抽取；② 省市区匹配（词典匹配+置信度）；③ 低置信降级手动模式；④ 解析结果回填可编辑（用户确认）；⑤ 配送范围校验（解析后）。

**答**：
```javascript
async function parseAddress(text) {
  const phone = (text.match(/1[3-9]\d{9}/) ?? [])[0];
  let rest = text.replace(phone ?? '', ' ');
  // 省市区词典匹配（最长匹配优先）
  const region = matchRegion(rest);            // {province,city,district,conf,rest}
  const name = extractName(region.rest);       // 2-4 字中文（去重词）
  const conf = (region.conf + (phone ? 0.5 : 0)) / 1.5;
  if (conf < 0.7 || !region.district)
    return { ok: false, mode: 'manual',        // 低置信降级
      prefilled: { phone } };
  const fields = { name, phone, region, detail: region.rest.trim() };
  const delivery = await checkDelivery(region); // 配送范围
  return { ok: true, fields,
    warning: delivery.ok ? null : '该区域暂不支持配送',
    confirm: true };                           // 回填待用户确认
}
// 匹配失败 → 手动模式保留已识别部分预填；
// 回填后用户可改（解析是辅助不是终态）；
// 确认提交才入库。
```

**评分点**:
- 字段抽取分层：电话正则/省市区词典最长匹配/姓名启发式。
- 置信度评分与低置信降级手动模式（预填已识别部分）。
- 回填待确认（解析是辅助非终态）。
- 配送范围校验联动（解析后立即校验）。
