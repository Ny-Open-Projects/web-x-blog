## SCN-633：审批的国际化与多租户怎么设计？
**答**：
- 多租户隔离：流程定义/表单 schema/权限矩阵按租户隔离（数据层隔离），前端以租户上下文（URL/域名/切换器）加载对应配置；切换租户等同 SCN-525 账户隔离。
- 国际化：流程名/意见模板/通知文案多语言（用户语言偏好渲染）；审批单内容不翻译（业务原文），界面翻译；金额币种按租户主体（法人）展示。
- 时区与日历：跨时区审批的「到达时间」双时区展示（本地 + 发起方）；工作日历按租户/地区配置（节假日影响 SLA 计算）。
- 合规差异：不同国家审批留痕要求不同（如欧盟 GDPR 数据保留期），保留策略按租户配置。
- 追问钩子：多租户下流程定义同名冲突怎么办——流程定义带租户命名空间，模板市场共享时复制而非引用。

```javascript
function tenantContext(ctx) {
  return {
    flowNS: `${ctx.tenantId}:flows`,               // 命名空间隔离
    locale: ctx.userLocale,
    calendar: CALENDARS[ctx.region],               // 工作日历影响 SLA
    currency: LEGAL_ENTITIES[ctx.entityId].currency,
    retention: RETENTION_POLICY[ctx.tenantId],     // GDPR 等
  };
}
// 时间线双时区：<time data-tz={initiatorTz}>{fmt(ts, local)}</time>（悬浮显示发起方时区）
```
