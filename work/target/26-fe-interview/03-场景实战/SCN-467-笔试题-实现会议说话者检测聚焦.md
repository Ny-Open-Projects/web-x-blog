## SCN-467：手写说话者检测：音频电平检测、防抖聚焦切换、布局联动

**需求与边界**：
- 输入：各路音频流；输出：当前说话者与布局焦点。
- 边界要求：① 每路电平检测（AnalyserNode）；② 聚焦切换防抖（说话 1s 内不重排+持续发言才聚焦）；③ 多人同时说话取最大电平；④ 布局联动（focus 模式重算）。

**答**：
```javascript
class SpeakerDetector {
  constructor(streams, { threshold = -50, stableMs = 1000 }) {
    this.analysers = new Map(streams.map(([id, s]) =>
      [id, mkAnalyser(s)]));
    this.threshold = threshold; this.stableMs = stableMs;
    this.current = null; this.candidate = null;
    this.candidateSince = 0;
    setInterval(() => this.detect(), 200);
  }
  detect() {
    let loudest = null, max = this.threshold;
    for (const [id, an] of this.analysers) {
      const level = rms(an);                  // 电平 RMS
      if (level > max) { max = level; loudest = id; }
    }
    if (!loudest || loudest === this.current) return;
    // 防抖：候选持续 1s 才切换（防瞬间噪音闪烁）
    if (loudest !== this.candidate) {
      this.candidate = loudest;
      this.candidateSince = Date.now();
      return;
    }
    if (Date.now() - this.candidateSince >= this.stableMs) {
      this.current = loudest;
      layoutEngine.setSpeaker(loudest);       // 布局联动（SCN-442）
    }
  }
}
const rms = (an) => {                          // 电平 RMS 计算
  const buf = new Uint8Array(an.fftSize);
  an.getByteTimeDomainData(buf);
  let sum = 0;
  for (const v of buf) sum += (v - 128) ** 2;
  return 10 * Math.log10(sum / buf.length + 1e-10); // dB
};
```

**评分点**:
- RMS 电平计算正确（时域数据→dB）。
- 防抖切换（候选持续 1s 才聚焦，防噪音闪烁）。
- 多路并行检测取最大电平。
- 与布局引擎联动（SCN-442 复用）。
