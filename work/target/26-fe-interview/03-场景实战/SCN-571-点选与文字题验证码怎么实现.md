## SCN-571：点选/文字题验证码怎么实现？
**答**：
- 题型：图片点选（按语序点击图中文字/物体）、语序题（选词成句）、空间题（点击指定方位）——比滑块更难被通用模型破解。
- 采集：点击坐标序列（相对图片归一化 0~1）+ 每次点击间隔时间，一并上报；坐标在服务端与题图标准答案做区域容差匹配。
- 防猜：题库随机 + 答案区域随机扰动 + 单次 challenge 一次性；同一 IP 短时高频请求同一题型自动升级难度。
- 加载：题图为动态接口拉取（不在静态资源中），带防盗链与短时效签名。
- 追问钩子：容差多大合适——点击目标半径 5%~8% 图片宽度，过严误伤、过松机器可 brute force。

```javascript
function pickTracker(imgEl) {
  const picks = [];
  imgEl.addEventListener('click', e => {
    const r = imgEl.getBoundingClientRect();
    picks.push({
      x: (e.clientX - r.left) / r.width,          // 归一化坐标（适配不同尺寸）
      y: (e.clientY - r.top) / r.height,
      dt: performance.now() - (picks.at(-1)?.t ?? performance.now()),  // 点击间隔
      t: performance.now(),
    });
    drawMarker(e.clientX - r.left, e.clientY - r.top);        // 序号标记
  });
  async function submit(token) {
    const res = await api.post('/risk/pick/verify', { token, picks });
    return res.pass;                                            // 匹配/容差在服务端
  }
  return { picks, submit };
}
```
