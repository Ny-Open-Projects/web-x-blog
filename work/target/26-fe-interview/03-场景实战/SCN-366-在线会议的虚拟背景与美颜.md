## SCN-366：会议虚拟背景（抠像/背景替换/美颜）的端侧实现？

**答**:
- 抠像技术：人像分割（端侧分割模型：WebAssembly/WebGPU 推理——AGT-478 端侧分档：高端机实时分割、低端机降级纯色背景虚化）、虚拟背景（图片/模糊/视频背景——背景渲染与分割 mask 合成）。
- 渲染管线：视频帧处理管线（getUserMedia→帧处理（分割+合成+美颜）→canvas→captureStream→推流——处理链在端侧完成），性能管理（处理帧率自适应：CPU 高降处理帧率、处理分辨率低于推流分辨率）、设备发热降级。
- 美颜处理：磨皮/美白（滤镜参数化）、美颜强度调节（实时预览）、美颜与分割的合成顺序。
- 降级与边界：低端机降级链（分割关闭→纯色虚化→关闭），暗光场景分割质量差提示、GPU 不可用回退 WASM（慢但可用）。

```javascript
// 端侧处理管线
const pipeline = new VideoPipeline(camera, {
  segmenter: caps.webgpu ? gpuSegmenter : wasmSegmenter,
  background: 'blur' | image,
  beauty: { smooth: 0.3 },
});
const processed = pipeline.stream();         // 处理后流
await sender.replaceTrack(processed.getVideoTracks()[0]);
// 自适应：cpuMonitor.high → pipeline.fps = 15
//   → 仍高 → segmenter.off()（虚化降级）。
// 推流分辨率独立于处理分辨率（处理 480p，推流 720p 插值）。
```
