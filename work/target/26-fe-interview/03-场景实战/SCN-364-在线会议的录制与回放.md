## SCN-364：会议录制（录制告知/回放生成/权限）怎么实现？

**答**:
- 录制合规：录制告知与同意（开始录制全员强提示：指示灯+入会提示——合规底线）、录制权限（主持人开录——参会者不可录制的前端提示与法律边界）、录制范围声明（录制内容包含音视频/屏幕共享/聊天记录——明确告知）。
- 录制实现：服务端混流录制（推荐：服务端合成——含共享画面+人像布局稳定）、录制状态信令（录制中/暂停/停止全员同步）、录制中断处理（会议中断→录制文件保全+提示）。
- 回放生成：转码与处理（异步任务：AGT-449 任务中心复用——转码进度透明）、回放增强（说话人分离标注/转写字幕/章节标记——SCN-293 复用）、回放分享（权限控制：链接有效期/下载禁止）。
- 管理与删除：录制文件管理（存储位置/保留期策略——合规保留期）、删除权（删除后副本清理——含 CDN 缓存失效）、审计（谁看过回放——SCN-319 审计复用）。

```javascript
// 录制信令
ws.on('record_state', (s) => {
  recIndicator(s);                            // 全员指示灯
  if (s.started) banner('会议正在录制');
});
// 回放：record → asyncTask({ transcode, asr, chapters })
//   → taskCenter 跟踪 → 完成通知。
// 回放页：playback({ seek, speakerDiary, transcript,
//   access: { expire, noDownload } })。
// 删除：del → purge(origin + cdnCache) + audit。
```
