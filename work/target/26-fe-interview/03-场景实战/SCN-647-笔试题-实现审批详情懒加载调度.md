## SCN-647：手写详情页资源调度器

**需求与边界**：
- 需求：首屏并行加载「实例 + 权限 + 当前节点」；流程图布局/全量时间线/附件列表按优先级 idle 加载；失败的低优先资源不影响首屏。
- 边界：① 首屏任一失败进入错误态（重试入口）；② idle 任务可取消（实例刷新后过期）；③ 并发 idle 任务最多 2 个（防带宽争抢）。

**答**：
```javascript
async function loadDetail(instanceId) {
  const ctrl = new AbortController();
  // 首屏三请求并行
  const [instance, perm, node] = await Promise.all([
    api.get(`/instance/${instanceId}`, { signal: ctrl.signal }),
    api.get(`/perm/${instanceId}`, { signal: ctrl.signal }),
    api.get(`/instance/${instanceId}/node`, { signal: ctrl.signal }),
  ]).catch(e => { throw Object.assign(e, { fatal: true }); });
  // 次要资源 idle 队列（并发 2，可取消）
  const queue = [
    { key: 'flowGraph', load: () => api.get(`/instance/${instanceId}/graph`) },
    { key: 'timeline', load: () => api.get(`/instance/${instanceId}/timeline`) },
    { key: 'attachments', load: () => api.get(`/instance/${instanceId}/attachments`) },
  ];
  const results = {}; let running = 0, qi = 0, cancelled = false;
  function pump() {
    while (!cancelled && running < 2 && qi < queue.length) {
      const task = queue[qi++];
      running++;
      task.load().then(r => { results[task.key] = r; })
        .catch(e => { results[task.key] = { error: e }; })   // 失败不致命
        .finally(() => { running--; pump(); });
    }
  }
  const startIdle = () => requestIdleCallback(pump);
  startIdle();
  return {
    instance, perm, node,
    idle: { results, cancel: () => { cancelled = true; ctrl.abort(); } },
  };
}
// 实例刷新（如操作后 reload）时先 idle.cancel() 再重新 loadDetail
```

**评分点**:
- 首屏 3 请求并行 + 任一失败 fatal 区分。
- idle 队列并发 2 上限（带宽保护）。
- 低优先失败包装为 { error } 不影响首屏。
- cancel + abort 支持实例刷新时清理过期请求。
