## SCN-235：课堂连麦（学生上麦发言）的流管理怎么设计？

**答**:
- 连麦流程状态机：举手（SCN-233 队列）→ 老师邀请上台 → 学生接受 → 推流建立（采集权限请求→发布流→订阅混流）→ 发言中 → 下台（停止推流→释放资源）——每步有超时与失败回退（权限拒绝→提示引导开权限，不静默失败）。
- 流管理：上台人数上限（并发推流限 6~8 路，超过走申请排队）、学生端推流质量自适应（上行带宽检测自动降清晰度）、下台资源释放（localStream tracks stop、RTC 发布取消、采集设备释放——泄漏防护 AGT-499 同款）。
- 老师控制权：老师可静音/下台任意学生（控制信令优先）、学生突发噪音自动检测提示老师（音量突增事件上报）、全班静音开关（一键下台全部）。
- 容错：推流中断（网络切换）自动重连推流、上台瞬间失败回退（回观众席+提示）、切后台/锁屏的采集中断处理（回来恢复推流或提示重新上台）。

```javascript
async function goOnStage(invite) {
  const ok = await requestMedia();           // 权限请求
  if (!ok) return toast('需要麦克风权限，请在设置中开启');
  const stream = await rtc.publish({ audio: true, video: false });
  setState('onStage'); trackStream(stream);  // 登记，下台释放
}
async function leaveStage() {
  localStream.getTracks().forEach(t => t.stop());  // 释放设备
  await rtc.unpublish();
  setState('audience');
}

//   s === 'failed' && onStage && retryPublish(3));
// 全班静音：teacher.broadcast('force_leave_stage')。
```
