## SCN-1301：手写一个国际化合规拦截器（结算前校验链）

**答**：
- 需求：implement ComplianceGate(checks)。run(order) 按序执行校验链（禁运/合规标识/地址校验/税务配置），首个失败返回 { blocked, step, reason }；全过返回 pass；每步耗时记录（性能审计）。
- 边界：checks 空 pass；校验器抛错视为失败（step 名标记）；order 缺地址在地址步骤失败；耗时保留 1 位。
- 评分点：校验链；异常即失败；耗时审计；首个失败

```javascript
class ComplianceGate {
  constructor(checks) { this.checks = checks; }        // [{ name, run: async (order) => {ok, reason} }]
  async run(order) {
    const timings = [];
    for (const c of this.checks) {
      const t0 = performance.now();
      try {
        const r = await c.run(order);
        timings.push({ step: c.name, ms: +(performance.now() - t0).toFixed(1) });
        if (!r.ok)
          return { blocked: true, step: c.name, reason: r.reason, timings };
      } catch (e) {
        return { blocked: true, step: c.name, reason: '校验器异常: ' + e.message,
          timings };
      }
    }
    return { blocked: false, timings };
  }
}
```
