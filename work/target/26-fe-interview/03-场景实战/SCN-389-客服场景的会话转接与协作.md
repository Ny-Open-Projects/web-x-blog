## SCN-389：客服会话转接（转专家/多方会诊/交接质量）怎么设计？

**答**:
- 转接类型：技能转接（转专家坐席——SCN-219 衔接复用）、邀请协作（三方会诊：客服+专家+主管同会话——多方信令与权限）、静默旁观（求助时专家旁观会话——旁听指导不露给客户）。
- 交接质量：交接摘要自动生成（问题/已尝试/客户情绪——AGT 摘要复用）、交接确认（接收方确认接手——不空中转接）、交接客户告知（"为您转接专家 XX"——客户知情）。
- 协作细节：转接中的会话保持（转接期间客户可继续发消息——排队缓存）、转接失败兜底（专家忙→回原客服+排期）、多方会诊的发言控制（客户可见谁在说——身份标识）。
- 数据与考核：转接率监控（高转接率→技能组配置问题）、交接质量评分（接收方评价交接摘要质量——闭环）、跨组协作审计（SCN-319 复用）。

```javascript
async function transfer(session, target, { type }) {
  const digest = await genDigest(session);   // 自动摘要
  const ok = await target.confirm(digest);   // 接收确认
  if (!ok) return fallback(session, target);
  await session.migrate(target);             // 会话迁移
  notifyCustomer(`已转接专家 ${target.name}`);
}
// 三方会诊：invite(session, expert) → 3 方信令
//   expert.silentObserve()（旁观不露客户）→ 联合回复。
// 交接质量：target.rate(digest) → 闭环优化摘要模板。
```
