## SCN-606：审批催办与超时自动流转怎么做？
**答**：
- 超时规则可视化：每个节点显示 SLA 时限与剩余时间（倒计时按工作日历计算，不是自然时间）；剩余 < 25% 变黄、超时变红。
- 催办交互：发起人/管理员可催办，一次催办生成待办强提醒（IM + 站内 + 邮件由服务端做），前端展示催办历史与次数（防骚扰：每人每天限 N 次）。
- 自动升级：超时未处理按规则升级到上级（自动流转），时间线上体现「超时 → 自动升级至 X」节点。
- 待办优先级：待办列表按超时风险排序（快超时的置顶），而非单纯按到达时间。
- 追问钩子：倒计时为什么不能用 setInterval 累减——Tab 休眠节流会漂移，必须用 deadline 时间戳 + 绝对时间计算。

```javascript
function slaCountdown(node, workCalendar) {
  const deadline = workCalendar.addBusinessHours(node.arriveTs, node.slaHours);
  const render = () => {
    const left = deadline - Date.now();
    if (left <= 0) return { text: '已超时', level: 'danger' };
    if (left < node.slaHours * 3600_000 * 0.25) return { text: fmtDuration(left), level: 'warn' };
    return { text: fmtDuration(left), level: 'normal' };
  };
  // rAF/interval 只负责触发 render()，剩余时间永远由 deadline 绝对值计算
  return { deadline, render, canUrge: node.status === 'PENDING' && urgeCount(node) < 3 };
}
```
