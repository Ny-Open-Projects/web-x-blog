## SCN-630：审批列表筛选与个性化怎么设计？
**答**：
- 视图分层：内置视图（待我处理/我发起/抄送我/已处理）+ 用户自定义视图（筛选条件组合保存命名）；自定义视图存服务端（跨端一致），本地只缓存最近使用。
- 筛选模型：与 SCN-526 同构——单一 filter 对象 + URL 承载 + 服务端过滤；审批特有的是「金额区间」「流程类型」「超时状态」维度。
- 列个性化：列显隐/排序/宽度用户可调，配置随视图保存；默认列按角色不同（审批人看「剩余时间」，发起人看「当前节点」）。
- 快捷入口：按流程类型聚合的卡片入口（报销 N 条待办），点击进入该类型过滤后的列表。
- 追问钩子：筛选条件很多 UI 放不下怎么办——高频条件外露 + 「更多筛选」抽屉 + 已选条件以标签形式回显可单个移除。

```javascript
function FilterChips({ filter, onRemove }) {
  const chips = flattenFilter(filter);               // { type: ['报销','采购'], overdue: true }
  return chips.map(c => (
    <Tag closable key={c.key + c.value} onClose={() => onRemove(c)}>
      {FIELD_LABEL[c.key]}: {VALUE_LABEL(c.key, c.value)}
    </Tag>
  ));
}
```
