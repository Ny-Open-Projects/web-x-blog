## SCN-350：协作场景（文档/表格/白板/PPT/评论/提醒）怎么横向收束？

**答**:
- 横向能力地图：实时同步层（CRDT/增量/快照——SCN-221~222 全形态复用）、呈现层（多光标/冲突/批注——SCN-223/224/228）、内容层（文本/表格公式/白板笔迹/页面——各形态的 CRDT 数据模型）、协同周边（@引用/评论 AI/提醒/多窗口——341~349）、平台层（权限/离线/搜索/审计——SCN-297~319 复用）。
- 协同场景的通用解法清单：任何"多人改同一份数据"的需求 → CRDT 数据模型+awareness+权限三件套；任何"异步协作"需求 → 通知+提醒+实体引用；任何"内容生成"需求 → AI 助手嵌入模式（SCN-341 范式）。
- 形态差异只在数据模型：文档=文本 CRDT、表格=Map+单元格文本、白板=元素几何、PPT=页面序列——上层协议（同步/权限/光标/撤销）完全复用；"新协作形态"的工程量=新数据模型+新渲染器。
- 收束心法：协作产品的护城河是"协同基建的完备性"——把 CRDT 同步/权限/离线/引用/提醒做成平台资产，新协作形态（如图表协同/数据库协同）只需实现自己的数据模型与渲染层，即可继承全部协同能力。

```text
协同横向地图：
同步：CRDT + 增量 + 快照（全形态复用）
呈现：光标锚 / 冲突提示 / 批注
内容：文本 / 表格公式 / 笔迹 / 页面序列
  —— 差异只在数据模型 + 渲染器
周边：@引用 / 评论 AI / 提醒 / 多窗口
平台：权限 / 离线 / 搜索 / 审计
通用解法：多人改同一数据 →
  CRDT + awareness + 权限 三件套。
```
