## SCN-452：手写礼物连送：按住连发本地计数、结束统一结算、全屏动效队列

**需求与边界**：
- 输入：礼物选择、长按事件；输出：发送与动效控制。
- 边界要求：① 长按连送：本地计数动画（x2/x3...）+松手统一结算（省请求）；② 余额预校验（连送中余额不足中断）；③ 全屏动效队列（串行播放+可跳过）；④ 发送幂等。

**答**：
```javascript
class GiftSender {
  startCombo(gift) {                           // pointerdown
    this.count = 0; this.gift = gift;
    this.timer = setInterval(() => {
      this.count++;
      const cost = gift.price * this.count;
      if (cost > balance) { this.stopCombo(); return toast('余额不足'); }
      showComboBadge(this.count);              // x2 x3 本地动画
    }, 300);
  }
  async stopCombo() {                          // pointerup 结算
    clearInterval(this.timer);
    if (!this.count) return;
    const n = this.count; this.count = 0;
    const r = await giftApi.send({ giftId: this.gift.id, count: n,
      idempotencyKey: uid() });                // 一次请求结算
    if (r.ok) this.gift.luxury
      ? effectQueue.enqueue({ gift: this.gift, count: n })
      : danmakuZone.show(this.gift, n);        // 普通：弹幕区
  }
}
class EffectQueue {                            // 全屏动效队列
  enqueue(item) { this.q.push(item); this.play(); }
  async play() {
    if (this.playing || !this.q.length) return;
    this.playing = true;
    const item = this.q.shift();
    await playSVGA(item, { skippable: true }); // 可跳过
    this.playing = false;
    this.play();                               // 串行播放
  }
}
// 洪峰：队列>3 → 跳过中档礼物只播高档（降级）。
// SVGA 预载：开播时下载缓存（SCN-277 复用）。
```

**评分点**:
- 连送本地计数+松手统一结算（请求合并正确）。
- 余额预校验中断（连送中断网兜底）。
- 动效队列串行播放+可跳过+洪峰降级（跳过中档）。
- 普通/豪华礼物分流呈现。
