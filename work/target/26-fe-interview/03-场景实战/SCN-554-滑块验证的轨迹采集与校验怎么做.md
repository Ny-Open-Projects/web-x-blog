## SCN-554：滑块验证的轨迹采集与人机校验怎么做？
**答**：
- 采集内容：pointermove 轨迹点（x/y/t 三元组）、按下与松开时刻、途中加速度变化、缺口对齐精度；采样频率固定（如 60Hz 按帧）。
- 人机特征：真人轨迹有起手停顿、速度波动、过冲回修；机器拖动是匀速直线或贝塞尔完美曲线——「过于完美」本身就是机器信号。
- 校验在服务端：前端只采集上报，轨迹合法性（时长/速度分布/缺口匹配）由服务端模型判定，防止本地校验被绕过。
- 防重放：轨迹携带 challenge token + 时间戳 + 轨迹哈希，服务端校验 token 一次性。
- 追问钩子：为什么不用 setInterval 采样——事件驱动 + 时间戳更准确，setInterval 在后台被节流会产生假均匀轨迹。

```javascript
function trackSlider(el, { onDone }) {
  const points = [];
  let t0;
  el.addEventListener('pointerdown', e => {
    t0 = performance.now(); points.length = 0;
    el.setPointerCapture(e.pointerId);
  });
  el.addEventListener('pointermove', e => {
    if (!t0) return;
    points.push({ x: e.clientX, y: e.clientY, t: performance.now() - t0 });
  });
  el.addEventListener('pointerup', e => {
    if (!t0) return;
    const dur = performance.now() - t0;
    const speeds = points.slice(1).map((p, i) =>
      Math.hypot(p.x - points[i].x, p.y - points[i].y) / Math.max(1, p.t - points[i].t));
    onDone({ points, dur,
      stdSpeed: std(speeds),                     // 速度标准差：真人显著更高
      overShoot: maxExcursion(points),           // 过冲幅度
      token: challengeToken });
    t0 = null;
  });
}
```
