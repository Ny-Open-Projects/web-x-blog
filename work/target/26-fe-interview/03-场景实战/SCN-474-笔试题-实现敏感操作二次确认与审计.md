## SCN-474：手写敏感操作守卫：风险分级、影响面预览、二次确认、审计留痕

**需求与边界**：
- 输入：操作（删除/批量导出/权限变更）；输出：守卫流程。
- 边界要求：① 风险分级（高=二次确认+验证码，中=确认，低=直接）；② 影响面预览（删除前显示影响多少数据——AGT-478 预览复用）；③ 审计（谁何时做了什么——SCN-319 复用）；④ 批量操作限额与分批。

**答**：
```javascript
const RISK = {
  deleteSingle: 'mid', deleteBatch: 'high',
  exportAll: 'high', permissionChange: 'high',
};
async function guard(op) {
  const level = RISK[op.type];
  const impact = await previewImpact(op);      // 影响面预览
  if (level === 'high') {
    const ok = await confirm({
      title: op.title, impact,                 // "影响 3,421 条"
      verify: 'captcha',                       // 高危+验证码
    });
    if (!ok) return abort();
    if (op.type === 'exportAll') audit.notifyAdmin(op);  // 告警
  } else if (level === 'mid') {
    if (!await confirm({ title: op.title, impact })) return abort();
  }
  const r = await exec(op);                    // 分批执行
  audit.log({ op, by: me, impact, result: r }); // 审计留痕
  return r;
}
// 批量：>1000 条 → 分批+进度（SCN-255 复用）；
// 权限变更 → 生效前预览影响人数 → confirm → 生效。
```

**评分点**:
- 三级风险分级（低直做/中确认/高验证码）。
- 影响面预览前置（删除/策略变更先看影响）。
- 审计留痕完整（who/when/impact/result）。
- 批量操作限额分批+导出告警管理员。
