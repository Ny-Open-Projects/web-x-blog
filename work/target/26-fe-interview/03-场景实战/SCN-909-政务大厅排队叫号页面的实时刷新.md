## SCN-909：政务大厅排队叫号页面的实时刷新

**答**：
- 实时性：叫号状态（当前号/前面还有几人）走轮询（10s）或 SSE；大厅大屏走 WS。
- 体验：临近叫号（前 3 位）提醒；过号处理（重新排队规则展示）。
- 降级：实时通道失败降级轮询，页面显示最后更新时间。

```javascript
// 叫号轮询
function queuePolling(ticketNo) {
  let stopped = false;
  async function tick() {
    if (stopped) return;
    try {
      const s = await api(`/queue/${ticketNo}/status`);
      render(s);
      if (s.ahead <= 3) vibrate();                    // 临近提醒
    } catch { showStaleNotice(); }                    // 降级提示
    setTimeout(tick, 10_000);
  }
  tick();
  return () => stopped = true;
}
```
