## SCN-699：手写帧率守护降级器

**需求与边界**：
- 需求：P5 帧率持续 5 分钟 < 30 依次降级：关闭后处理 → 降低 pixelRatio（1.0→0.75）→ LOD 强制低模；帧率恢复持续 10 分钟逐级回升；降级动作上报且页面显示降级角标。
- 边界：① 帧率采样 5s 一桶取 P5（10 桶滑动）；② 降级/回升都带迟滞防震荡；③ 最低档不再下降但上报人工处理。

**答**：
```javascript
function createFpsGuard(renderer, { low = 30, recover = 45, window = 10 } = {}) {
  const hist = [];                                     // 每桶 { fps }
  let stage = 0;                                       // 0 正常 1 无后处理 2 降分辨率 3 低模
  const STAGES = [
    () => setPostProcessing(false),
    () => renderer.setPixelRatio(0.75),
    () => forceLOD(1),
  ];
  function onFpsBucket(fps) {
    hist.push({ fps, t: Date.now() });
    if (hist.length > window) hist.shift();
    const p5 = quantile(hist.map(h => h.fps).sort((a, b) => a - b), 0.05);
    const below = p5 < low, above = p5 > recover;
    if (below && stage < STAGES.length) {              // 降级（无迟滞门槛，帧率持续低才累计）
      STAGES[stage++]();
      report({ type: 'FPS_DEGRADE', stage, p5 });
      showBadge(`性能降级 L${stage}`);
    } else if (above && stage > 0) {                   // 回升逐级恢复
      stage--;
      report({ type: 'FPS_RECOVER', stage, p5 });
      hideBadge();
    }
  }
  // 采样循环
  let frames = 0, last = performance.now();
  requestAnimationFrame(function f(now) {
    frames++;
    if (now - last >= 5000) { onFpsBucket(frames / 5); frames = 0; last = now; }
    requestAnimationFrame(f);
  });
}
```

**评分点**:
- P5 分位帧率（比平均值敏感）+ 滑动窗口。
- 三级降级链（后处理→分辨率→LOD）顺序固定可解释。
- 降级与回升双阈值迟滞（30 降 / 45 升，防震荡）。
- 每次动作上报 + 用户可见角标（透明度）。
