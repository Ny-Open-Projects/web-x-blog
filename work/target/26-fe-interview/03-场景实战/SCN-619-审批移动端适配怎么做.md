## SCN-619：审批移动端适配怎么做？
**答**：
- 移动端信息重排：详情页不用桌面全流程图，改用「步骤条 + 当前节点卡片」纵向时间线——小屏看全图意义有限；需要全图时提供横屏/新页全屏图（可缩放）。
- 操作适配：底部固定操作栏（同意/驳回/转交），大拇指可达区；驳回必填意见弹层全屏；签名（手写板）用 canvas 触控。
- 待办轻量化：移动端优先「快速同意」场景（简单表单+意见框），复杂表单（大量字段/附件）引导到 PC 处理并一键发送链接到 PC。
- 离线与弱网：地铁场景查看已加载详情离线可用（缓存），操作必须在线（防重复提交）。
- 追问钩子：移动端审批的安全要求——生物识别（指纹/面容）替代密码确认，设备绑定防代批。

```javascript
function flowViewFor(device, def, instance) {
  if (device.type === 'mobile') {
    return {
      mode: 'stepper',                       // 纵向步骤条
      nodes: currentPathOnly(def, instance), // 只展示已走+当前路径
      fullMapLink: '/flow-full?instance=' + instance.id,   // 全图跳新页
    };
  }
  return { mode: 'dagre-svg', nodes: def.nodes };
}
function currentPathOnly(def, inst) {
  return def.nodes.filter(n => inst.statusMap[n.id] !== 'PENDING_BRANCH_UNTAKEN');  // 裁剪未走分支
}
```
