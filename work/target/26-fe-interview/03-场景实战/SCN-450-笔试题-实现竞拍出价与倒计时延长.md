## SCN-450：手写在线竞拍：出价校验、最后 N 秒出价延长倒计时、服务端定序

**需求与边界**：
- 输入：竞拍事件流（出价/倒计时）；输出：竞拍 UI 状态。
- 边界要求：① 出价必须高于当前价+最小步长（本地预校验+服务端裁决）；② 最后 10s 出价→倒计时延长（防狙击）；③ 并发出价服务端定序（价高者得）；④ 出价失败反馈（被超/已结束）。

**答**：
```javascript
class Auction {
  constructor({ step }) { this.step = step; }
  onState(s) {                                 // 服务端权威状态
    this.current = s.price; this.endAt = s.endAt;
    render(s);                                 // 当前价/倒计时
  }
  async bid(price) {
    // 1. 本地预校验（省请求）
    if (price < this.current + this.step)
      return toast(`至少出价 ${this.current + this.step}`);
    const r = await auctionApi.bid({ itemId: this.id,
      price, idempotencyKey: uid() });
    if (r.ok) return;                          // 信令会广播新价
    toast(r.reason === 'outbid' ? '已被他人出价'
      : r.reason === 'ended' ? '竞拍已结束' : '出价失败');
  }
  onBid(bid) {                                 // 服务端广播
    this.current = bid.price;
    if (bid.remainSec < 10)
      this.endAt = serverNow(bid.newEndAt);    // 最后 10s 延长
    highlight(bid.user);
  }
}
// 服务端定序：并发出价按到达序裁决（价高者得）——
//   前端预校验只是体验优化不是裁决；
// 延长：服务端判定（剩余<10s 收到出价 → endAt += 10s）。
```

**评分点**:
- 本地预校验（步长）+ 服务端裁决的双层正确。
- 最后 10s 出价延长倒计时（防狙击）由服务端判定。
- 失败原因分型反馈（被超/已结束）。
- 出价幂等键防重复。
