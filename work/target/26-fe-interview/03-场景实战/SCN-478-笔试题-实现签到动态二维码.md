## SCN-478：手写课堂动态签到码：30s 签名刷新、扫码校验、代签风控

**需求与边界**：
- 输入：课堂会话；输出：动态二维码与校验。
- 边界要求：① 码 30s 签名时间窗（截图转发无效——SCN-434 同源）；② 扫码校验（签名+时间窗+教室围栏可选）；③ 同设备多账号签到标记（代签风控）；④ 签到看板实时（已签/未签）。

**答**：
```javascript
// 教师端：动态码
class AttendanceQR {
  start(classId) {
    this.timer = setInterval(async () => {
      const code = await api.sign({ classId,
        win: Math.floor(Date.now() / 30e3) });   // 30s 窗
      renderQR(code);
    }, 28000);                                   // 提前刷新
  }
}
// 学生端：扫码 → verify({ sig, win, studentId })
//   服务端校验签名+窗口+围栏（可选）
//   → signed / late（窗口外）。
// 风控：fingerprintOf(device) → 同设备多 studentId
//   → flag 代签嫌疑（服务端裁决）。
// 看板：ws.on('signed', (s) => roster.patch(s));
```

**评分点**:
- 30s 签名时间窗（提前 28s 刷新避免空窗）。
- 校验三要素：签名+窗口+围栏（可选降级）。
- 同设备多账号代签风控（服务端裁决）。
- 看板实时更新（已签/未签+一键提醒）。
