## SCN-805：联想词高亮分词怎么做？
**答**：
- 服务端返回命中片段：词与命中位置由服务端标记（`<em>` 偏移或结构化 offset），前端不做模糊匹配高亮——服务端知道是前缀命中还是拼音命中，前端猜会错位。
- 前端渲染：结构化 offset 渲染 `<mark>`，禁止 innerHTML 直接插服务端串（XSS）；拼音命中（输入 iphone 命中「苹果手机」）高亮整词不高亮字符级。
- 混合输入：中文+英文+数字混合（"iphone17壳"）分词后分别匹配，高亮各段。
- 纠错命中：纠错词显示原输入（如输入「iphon」展示建议「iphone」），纠错过程透明化。
- 追问钩子：为什么高亮偏移要用码点而不是字符索引——中文 emoji 等是 surrogate pair，字符索引会错位；用 UTF-16 码点或Intl.Segmenter。

```javascript
// 服务端结构：{ q: '苹果手机', offsets: [[0, 2]] }  // 码点偏移
function highlight(item, { markClass = 'hl' } = {}) {
  const chars = [...item.q];                          // 码点级拆分
  const marks = new Set();
  for (const [s, e] of item.offsets)
    for (let i = s; i < e; i++) marks.add(i);
  const html = chars.map((c, i) =>
    marks.has(i) ? `<mark class="${markClass}">${escapeHtml(c)}</mark>` : escapeHtml(c)
  ).join('');
  return { __html: html };                            // escapeHtml 已消毒
}
```
