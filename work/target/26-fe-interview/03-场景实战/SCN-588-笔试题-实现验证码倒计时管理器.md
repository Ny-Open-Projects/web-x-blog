## SCN-588：手写验证码倒计时管理器

**需求与边界**：
- 需求：send 成功后以服务端返回 cooldown 为准起倒计时；多 Tab 同步；刷新页面恢复剩余时间；为 0 后允许发送。
- 边界：① 用绝对时间戳而非秒数（Tab 休眠不漂移）；② 其他 Tab 发送后本 Tab 同步；③ localStorage 不可用时静默降级。

**答**：
```javascript
function createCountdown(mobile) {
  const KEY = `sms_cd_${mobile}`;
  const deadline = () => Number(localStorage.getItem(KEY)) || 0;
  let timer = null;
  function remaining() { return Math.max(0, Math.ceil(deadline() - Date.now() / 1000)); }
  function startRender(onTick) {
    clearInterval(timer);
    const tick = () => {
      const r = remaining();
      onTick(r);
      if (r === 0) clearInterval(timer);
    };
    tick(); timer = setInterval(tick, 1000);
  }
  return {
    async send(doSend, onTick) {
      if (remaining() > 0) return { ok: false, left: remaining() };   // 本地冷却中
      const { cooldown, ok } = await doSend(mobile);                  // 服务端权威
      if (!ok) return { ok: false, left: remaining() };
      try { localStorage.setItem(KEY, Math.floor(Date.now() / 1000) + cooldown); } catch {}
      startRender(onTick);
      return { ok: true, cooldown };
    },
    restore(onTick) {                                                 // 刷新恢复
      if (remaining() > 0) startRender(onTick);
    },
    syncOtherTab(onTick) {                                            // storage 事件同步
      window.addEventListener('storage', e => {
        if (e.key === KEY) startRender(onTick);
      });
    },
    dispose() { clearInterval(timer); },
  };
}
```

**评分点**:
- 绝对时间戳存 deadline（Tab 节流/休眠不漂移）。
- 服务端 cooldown 为权威，本地仅 UX。
- storage 事件多 Tab 同步 + 刷新恢复。
- localStorage 异常 try-catch 静默降级。
