## SCN-683：大屏告警处置闭环怎么打通？
**答**：
- 状态机：告警 → 已确认（值班点选）→ 已派单（生成工单）→ 处理中 → 已销警（自动：指标恢复 N 分钟，或人工确认）；大屏展示当前态与累计时长。
- 大屏职责边界：大屏负责「看见」（状态/耗时/责任人），操作入口引导到值班终端（大屏不承载复杂表单），但支持快捷确认/派单两个高频动作。
- 联动呈现：告警卡片显示「已持续 2h13m / 处理人：王五」，超时未确认标红升级——闭环时效可视化倒逼处理。
- 数据回流：闭环时长（确认耗时/处理耗时）进驾驶舱，识别响应瓶颈。
- 追问钩子：销警的自动判定条件——指标连续 N 分钟回到阈值内 + 无重复告警窗口，避免抖动型指标反复销警/复发。

```javascript
const ALARM_FSM = {
  states: ['TRIGGERED', 'ACKED', 'DISPATCHED', 'RESOLVED'],
  transitions: {
    TRIGGERED: { ack: 'ACKED', autoResolve: 'RESOLVED' },
    ACKED: { dispatch: 'DISPATCHED' },
    DISPATCHED: { resolve: 'RESOLVED' },
  },
};
function autoResolve(alarm, { recoverMs = 300_000 } = {}) {
  if (alarm.valueInThreshold && Date.now() - alarm.recoverSince > recoverMs)
    return api.post(`/alarm/${alarm.id}/resolve`, { auto: true });
  if (!alarm.valueInThreshold) alarm.recoverSince = Date.now();   // 抖动重置计时
}
```
