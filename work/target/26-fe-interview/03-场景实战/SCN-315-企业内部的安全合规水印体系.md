## SCN-315：企业敏感系统防截图水印（动态水印/泄露溯源）怎么体系化？

**答**:
- 水印分层：明水印（平铺用户信息：工号+姓名+时间——视觉威慑）、暗水印（盲水印嵌图片/文档：肉眼不可见——泄露图片可溯源到人）、动态挑战水印（随机码+旋转角度随机——截图裁剪删除水印成本高）。
- 实现要点：水印层实现（canvas 生成 pattern 平铺/Overlay 层防删除：MutationObserver 监听水印节点删除自动重建——防开发者工具删除）、全局覆盖（iframe/弹窗/新窗口都要覆盖——全局挂载策略）、性能（一次性生成 pattern 背景，滚动不动）。
- 溯源体系：水印信息与审计关联（截图含水印→可追溯到人+时间——SCN-430 审计 trace 联动）、导出文件水印（导出 Excel/PDF 嵌入盲水印——服务端处理）、检测工具（泄露图片的盲水印解码工具）。
- 边界认知：前端水印防君子不防技术高手（内核级截图绕过）——价值在威慑+提高泄露成本+事后溯源；真正的防泄露靠数据分级+权限最小化+DLP（AGT-285 联动）。

```javascript
function watermarkLayer({ text, dense }) {
  const canvas = genPattern(text, { rotation: rand(-15, 15),
    opacity: 0.06 });                        // 随机角度防批量裁剪
  const el = overlay(canvas.toDataURL());
  document.body.appendChild(el);
  // 防删除：MutationObserver 重建
  new MutationObserver(() => {
    if (!document.body.contains(el)) document.body.appendChild(el);
  }).observe(document.body, { childList: true });
  // 全局覆盖：app-shell::before 统一注入（含弹窗层）
  return { destory: () => observer.disconnect() };
}
// 盲水印：导出时服务端嵌入（LSB/频域），
//   泄露图 → decode 工具 → 工号+时间戳溯源。
```
