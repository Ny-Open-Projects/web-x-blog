## SCN-744：手写分位数置信区间

**需求与边界**：
- 需求：对样本（<5000 可全量）计算 P95 及 95% 置信区间；bootstrap 重采样 B=1000 次；样本量 < 30 返回 insufficient。
- 边界：① bootstrap 用固定 seed 可复现；② 区间按百分位法取 2.5%/97.5%；③ 结果标注样本量。

**答**：
```javascript
function p95CI(samples, { B = 1000, seed = 42, level = 0.95 } = {}) {
  if (samples.length < 30) return { insufficient: true, n: samples.length };
  const rnd = mulberry32(seed);
  const estimates = [];
  for (let b = 0; b < B; b++) {
    const resample = Array.from({ length: samples.length },
      () => samples[Math.floor(rnd() * samples.length)]);   // 有放回重采样
    estimates.push(quantile(resample, 0.95));
  }
  estimates.sort((a, b) => a - b);
  return {
    point: quantile(samples, 0.95),
    ci: [estimates[Math.floor(B * (1 - level) / 2)],
         estimates[Math.floor(B * (1 + level) / 2)]],
    n: samples.length,
  };
}
const mulberry32 = (a) => () => {
  a |= 0; a = (a + 0x6D2B79F5) | 0;
  let t = Math.imul(a ^ (a >>> 15), 1 | a);
  t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
  return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
};
```

**评分点**:
- bootstrap 有放回重采样 + 百分位法区间。
- 固定 seed 可复现（看板数字稳定）。
- 样本量下限 insufficient 保护。
- 结果带 n 标注（置信度上下文）。
