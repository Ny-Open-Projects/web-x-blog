## SCN-464：手写入会预检：麦克风/摄像头/扬声器测试、网络测速、权限引导

**需求与边界**：
- 输入：入会请求；输出：预检清单与放行决策。
- 边界要求：① 三设备检测（麦克风电平/摄像头画面/扬声器回放）；② 网络测速（RTT/带宽估算→质量预估）；③ 权限缺失→引导文案（按浏览器差异化）；④ 预检结果缓存（短时免重复检）。

**答**：
```javascript
async function precheck() {
  const result = { mic: false, cam: false, speaker: false, net: null };
  try {                                        // 麦克风：电平检测
    const s = await getUserMedia({ audio: true });
    result.mic = await hasAudioLevel(s, 2000);  // 2s 电平>阈值
  } catch (e) { result.micGuide = permGuide(e, 'mic'); }
  try {                                        // 摄像头：帧变化
    const s = await getUserMedia({ video: true });
    result.cam = await hasFrameChange(s);
    s.getTracks().forEach(t => t.stop());
  } catch (e) { result.camGuide = permGuide(e, 'cam'); }
  result.speaker = await speakerTest();        // 播放测试音听回执
  result.net = await speedProbe();             // RTT/带宽估算
  cache(result, { ttl: 300e3 });               // 5min 免重复检
  return result;                               // 按结果引导或放行
}
const permGuide = (e, kind) => e.name === 'NotAllowedError'
  ? { text: `请在浏览器设置中允许${kind === 'mic' ? '麦克风' : '摄像头'}权限`,
      how: browserSpecificSteps() }            // 按浏览器差异文案
  : { text: '设备不可用或被占用' };
// speakerTest：播放测试音→用户确认"能听到吗"（主观回执）。
```

**评分点**:
- 三设备检测方法正确（电平检测/帧变化/主观回执）。
- 权限引导按浏览器差异文案（NotAllowedError 分流）。
- 网络测速→质量预估（入会预期管理）。
- 预检结果短时缓存（重复入会免检）。
