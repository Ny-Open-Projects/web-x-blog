## SCN-649：手写委托分流器

**需求与边界**：
- 需求：新待办到达时按委托单分流（场景匹配 + 金额上限 + 有效期）；委托到期/收回时未处理待办回流原人；操作记录 operator+principal 双字段。
- 边界：① 多张委托单重叠时取最先创建；② 被委托人处理后原委托人待办同步移除；③ 分流不可改变实例归属记录。

**答**：
```javascript
function routeTodo(instance, delegations) {
  const matched = delegations
    .filter(d => d.ownerId === instance.assigneeId
      && d.scenes.includes(instance.scene)                    // 场景匹配
      && instance.amountFen <= d.amountCap                    // 金额上限
      && Date.now() >= d.startTs && Date.now() <= d.endTs)    // 有效期
    .sort((a, b) => a.createdAt - b.createdAt)                // 重叠取最先创建
    [0];
  if (!matched) return { assignee: instance.assigneeId, principal: null };
  return { assignee: matched.agentId, principal: instance.assigneeId,
           delegationId: matched.id };                        // 双向记录
}
async function reclaim(delegation) {                            // 到期/收回回流
  const open = await api.get('/todos', { params: { delegationId: delegation.id, status: 'PENDING' } });
  for (const t of open.list) {
    await api.post(`/todos/${t.id}/reroute`, { assignee: delegation.ownerId, principal: null });
    notify(delegation.ownerId, 'returned', t.instanceId);
  }
  notify(delegation.agentId, 'delegation_ended', { returned: open.list.length });
  return open.list.length;
}
// 审计记录示例：{ operator: 'agentId', principal: 'ownerId', action: 'approve' }
```

**评分点**:
- 分流四条件（范围/场景/金额/有效期）+ 重叠取最先创建。
- 回流逻辑完整（未处理待办 + 双方通知）。
- operator/principal 双字段审计语义。
- 被委托处理不改变实例归属记录（assignee vs principal 分离）。
