## SCN-394：全平台统一通知触达（站内/推送/短信/邮件）的策略中枢怎么设计？

**答**:
- 通知中枢：统一通知 schema（SCN-258 复用）+触达编排（一个事件→多通道路由：按紧急度与用户偏好选通道），触达模板中心（各渠道模板管理+变量填充——SCN-321 资产复用）。
- 触达策略：通道选择矩阵（事件类型×紧急度×渠道可达性：推送失败→短信兜底——降级链 AGT-455 复用）、频控与合并（同人同时段多通知合并——SCN-388 合并复用）、免打扰时段（用户偏好+全局静默时段——紧急类豁免）。
- 用户偏好：订阅中心（用户自选接收哪些类通知/渠道——AGT-378 能力声明复用）、触达效果（各渠道到达率/点击率——策略调优数据）。
- 前端呈现：站内通知中心统一（SCN-258 复用）、未读数统一（多业务未读聚合——总角标）、触达历史可查（用户可见自己收到的通知）。

```javascript
// 触达编排（服务端中枢）
notifier.emit('order_shipped', { userId, order }) →
  route({ event, user: { pref, mute, tz } }) →
    channels = [push, inapp]                 // 偏好+矩阵
    push.fail → sms fallback                 // 降级链（AGT-455）
merge(同用户 5min 多事件) → 聚合推送
// 站内：统一通知中心（SCN-258）+ 总未读角标
// 效果：channelStats.deliver/click → 调优。
```
