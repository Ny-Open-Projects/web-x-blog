## SCN-492：手写弱网自适应：RTT 探测、策略矩阵切换、恢复升级

**需求与边界**：
- 输入：网络探测流；输出：当前网络档位与策略。
- 边界要求：① RTT 探测（定期采样——滑动窗口均值）；② 策略矩阵（档位→图片质量/自动播放/预载开关）；③ 防抖切换（连续 N 次才降档，恢复可升档）；④ 用户可见提示（弱网模式告知）。

**答**：
```javascript
class NetworkAdaptive {
  constructor({ strategy }) {
    this.strategy = strategy;                  // 策略矩阵
    this.samples = []; this.level = 2;         // 0 差~2 好
    setInterval(() => this.probe(), 30e3);
  }
  async probe() {
    const rtt = await measureRTT();            // 探测 RTT
    this.samples.push(rtt);
    const avg = avgLast(this.samples, 3);      // 滑动均值
    const target = avg > 1500 ? 0 : avg > 600 ? 1 : 2;
    if (target < this.level) {                 // 防抖：连续 2 次降档
      if (++this.badStreak >= 2) {
        this.level = target;
        applyStrategy(this.strategy[this.level]);
        toast('当前网络较弱，已优化加载');
      }
    } else if (target > this.level && ++this.goodStreak >= 3) {
      this.level = target;                     // 恢复升档（更保守）
      applyStrategy(this.strategy[this.level]);
      this.badStreak = 0;
    }
  }
}
// 策略矩阵：
// 0: { images: 'low', autoPlay: false, prefetch: false }
// 1: { images: 'mid', autoPlay: false, prefetch: false }
// 2: { images: 'auto', autoPlay: true, prefetch: true }
// 降档快（2 次）升档慢（3 次）——体验与流量平衡。
```

**评分点**:
- RTT 滑动均值探测（采样窗口）。
- 策略矩阵三档（图片/自动播放/预览）。
- 降档快升档慢的防抖不对称设计。
- 用户告知（弱网模式提示）。
