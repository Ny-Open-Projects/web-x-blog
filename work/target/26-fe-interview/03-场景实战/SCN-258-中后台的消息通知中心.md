## SCN-258：中后台消息通知中心（审批/告警/公告多源聚合）怎么设计？

**答**:
- 通知模型：统一通知 schema（type/level: info|warn|critical/title/body/link/时间/已读态），多源接入（审批流/监控告警/公告/评论@）映射到统一 schema——渠道差异在服务端聚合层抹平。
- 实时通道：WS 推送实时到达（未读数+1+顶部提示）、轮询兜底（WS 断开时降级轮询）、离线补齐（重连拉增量）。
- 呈现与交互：铃铛未读角标（分级：critical 数字+红、info 圆点）、通知面板（分类 tab/全部已读/逐条已读）、关键通知强提醒（critical 弹窗+声音，可配置免打扰时段）、点击跳转（link 到业务上下文：直接打开审批单）。
- 治理：通知风暴合并（同类告警聚合："CPU 告警 ×23 条"）、已读游标（批量已读按游标）、通知保留期与归档、免打扰与订阅偏好（用户可关某类通知）。

```javascript
ws.on('notify', (n) => {
  store.add(n);                              // 统一 schema
  if (n.level === 'critical' && !mute(n))
    strongAlert(n);                          // 弹窗+声音
});
// 风暴合并：同 groupKey 5min 内聚合
//   → "CPU 告警 ×23"
// 已读游标：readCursor → 全部已读 = cursor 推进，
//   服务端按游标算未读（不逐条标记）。
// 跳转：router.push(n.link) 且携带通知 id（已读联动）。
```
