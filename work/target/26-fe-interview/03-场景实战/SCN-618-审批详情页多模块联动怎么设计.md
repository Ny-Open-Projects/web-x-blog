## SCN-618：审批详情页多模块联动怎么设计？
**答**：
- 单一实例 store：流程图/表单/时间线/附件订阅同一实例 store（含 statusMap/version），操作后一次性更新，各模块独立渲染。
- 联动行为：时间线点击某节点 → 流程图定位该节点并高亮；流程图节点点击 → 时间线滚动锚点 + 弹出该节点意见；驳回节点两侧同步红色。
- 数据分块加载：详情首屏 = 表单 + 当前节点信息（关键），流程图布局与全量时间线异步加载；大附件列表懒加载缩略图。
- 操作入口收敛：所有操作按钮集中在底部操作栏，按 allowedOperations 渲染；操作后回到详情页并全量刷新。
- 追问钩子：模块间联动怎么避免循环更新——事件单向流动（store → 各视图），视图只发 action 不互相直接调用。

```javascript
// 实例 store：单向数据流
const detailStore = createStore({
  instance: null, focusNodeId: null,   // 联焦点
  actions: {
    focusNode(id) { this.focusNodeId = id; },     // 时间线/图都可触发
    afterOperate() { return this.reload(); },     // 全量刷新
  },
});
// 时间线点击 → detailStore.focusNode(id)；流程图订阅 focusNodeId 高亮并 scrollIntoView；
// 图节点点击 → focusNode(id) → 时间线滚动锚点。视图间零直接依赖。
```

## 追问（补充）

**边界与易错**：

- `focusNode(id)` 只改 `focusNodeId`，绝不能在 action 里顺手调 `reload()`，否则点一次节点整页闪一次。
- 时间线的 `scrollIntoView` 要放在 `requestAnimationFrame` 里执行，目标节点尚未渲染时会滚到错误位置。
- 操作后必须 `afterOperate()` 整页 `reload()`，不能本地 patch 状态——服务端可能改了流程节点与操作权限，本地猜会不一致。

**追问**：

1. 表单未保存时点时间线跳转，草稿丢了怎么办 → 表单值存到 store 的 draft 分区，切换视图不销毁组件；离开页面用路由守卫加 `beforeunload` 提示。
2. 多标签页同时打开同一审批单，一个提交了另一个还显示待办怎么办 → 接口返回 `version`，提交带 If-Match，冲突返回 409 并提示「已被处理」强制刷新。
3. 两百多个节点的流程图，联动高亮会不会卡 → 图按层级虚拟化，高亮只改 CSS class 不触发重排；时间线只渲染可视窗口，锚点用 id 直接查询而非遍历。
