## SCN-347：同一文档在多个窗口（多标签页/桌面端多窗）打开，状态怎么一致？

**答**:
- 连接策略：独立连接 vs 共享连接（每窗口独立 WS 连接（简单）vs BroadcastChannel 共享一个连接（省资源）——按场景选择：轻文档共享连接，重型编辑器独立连接），连接数配额（同文档连接数上限——服务端保护）。
- 状态一致：编辑内容一致（CRDT 天然一致——两窗口各自连接同文档）、本地 UI 状态不强制一致（滚动位置/选中各自独立——符合直觉）、跨窗口操作互斥（同窗口编辑的 awarenss 双光标呈现——两窗口像两个用户）。
- 同源窗口优化：BroadcastChannel 做窗口间协调（SCN-446 多端同步同源：同一 device 的窗口共享 awareness 身份——一个用户不是两个光标）、焦点跟随（主窗口概念：某些操作仅主窗口执行——避免重复弹窗/重复计时）。
- 关闭与归档：最后窗口关闭→释放连接与本地锁、窗口间数据落地竞争（IndexedDB 同文档并发写——事务性保障/单写者模式）。

```javascript
// 同用户多窗口：共享 awareness 身份
const bc = new BroadcastChannel(`doc:${docId}`);
bc.onmessage = (e) => {
  if (e.type === 'presence_claim' && e.tabId !== myTab)
    isPrimary = false;                       // 主窗口选举
};
// 主窗口职责：唯一 awareness 广播/自动保存
// 次窗口：镜像主窗口 presence（同用户一个光标）
// 连接：共享 WS（主窗口持有，次窗口 BC 转发）——
//   主窗口关闭 → 重新选举。
// 本地写竞争：IndexedDB 单写者（主窗口写）。
```
