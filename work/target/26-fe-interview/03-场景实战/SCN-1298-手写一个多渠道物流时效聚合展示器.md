## SCN-1298：手写一个多渠道物流时效聚合展示器

**答**：
- 需求：implement EtaAggregator(channels, addr)。matrix(item) 输出各渠道 { fee, etaMin, etaMax, dutyMode }；recommend(prefs) 按 prefs（fast/cheap）推荐；不可达渠道（无 eta）标 unavailable 并给原因。
- 边界：addr 缺国家用默认；eta 区间相同合并展示（"3-5 天"）；prefs 非法按 cheap；channels 空返回空矩阵。
- 评分点：时效矩阵；不可达标注；区间合并；偏好

```javascript
class EtaAggregator {
  constructor(channels, addr) {
    this.channels = channels; this.country = addr?.country ?? 'US';
  }
  matrix(item) {
    return this.channels.map(c => {
      const eta = c.eta[this.country];
      return { channel: c.name, fee: c.fee(item),
        etaText: eta ? (eta.min === eta.max ? `${eta.min} 天` : `${eta.min}-${eta.max} 天`)
          : '不可达',
        dutyMode: c.ddp ? 'DDP' : 'DDU',
        unavailable: !eta };
    });
  }
  recommend(item, prefs = {}) {
    const rows = this.matrix(item).filter(r => !r.unavailable);
    if (!rows.length) return null;
    return rows.sort((a, b) => prefs.fast
      ? parseInt(a.etaText) - parseInt(b.etaText)
      : a.fee - b.fee)[0];
  }
}
```
