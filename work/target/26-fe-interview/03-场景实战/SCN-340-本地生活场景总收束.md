## SCN-340：本地生活场景（到店+外卖+内容）怎么总收束？

**答**:
- 全景三线：到店线（333 券核销/334 排队/338 储值/339 打卡内容）、到家线（335 外卖配送/336 门店点单）、通用线（330 优惠钱包/331-332 打车出行的位置流复用）。
- 位置是本地生活的心脏：几乎所有场景（附近门店/配送范围/打卡核验/过号预警）都建立在定位质量上——定位采集分级（SCN-265）、围栏判定（SCN-263）、坐标统一是底座。
- 线下线上融合的交互纪律：核销码离线可用（弱网门店现实）、进度推送透明（排队/骑手/ETA 的预期管理）、虚拟号保护隐私（用户与商家双向）、截屏与泄露防护（券码）。
- 收束心法：本地生活 = 交易闭环（复用电商资产）× 位置工程（LBS 底座）× 线下履约的不确定性管理（ETA 区间/过号规则/异常透明）——线下场景的最大挑战是"现实世界的不可控"，前端的价值是把不可控转化为可感知的预期管理。

```text
本地生活全景：
到店：券核销（离线签名码）/ 排队过号 /
  储值分账 / 打卡围栏
到家：配送状态机 / ETA 区间 / 异常透明
通用：优惠钱包 / 多店购物车 / 内容挂 POI
底座：定位分级 + 围栏 + 坐标统一
  + 虚拟号隐私。
心法：把线下不可控转化为可感知的预期管理。
```
