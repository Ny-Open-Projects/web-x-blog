## SCN-323：创作者发布（图文/视频/草稿/定时发布）怎么实现？

**答**:
- 发布表单：正文编辑（富文本/话题标签/表情——SCN-218 分段模型复用）、媒体上传（图片压缩多图排序、视频上传大文件分片+转码进度——SCN 断点续传复用）、发布设置（可见范围/定时发布/同步平台）。
- 草稿体系：自动保存（编辑中草稿本地+服务端双存——SCN 草稿篇复用）、草稿列表恢复、定时发布（定时队列：到时服务端自动发——客户端只是配置）。
- 提交后链路：发布审核（先发后审 vs 先审后发：粉丝可见策略——内容安全分级）、发布状态跟踪（审核中→已发布/驳回原因）、发布后编辑窗口。
- 体验细节：发布中离开提示、发布成功动画与跳转、失败保留草稿（上传失败不清空——内容是创作者资产）、多图预览编辑（拖拽排序/封面选择）。

```javascript
async function publish(draft) {
  await saveDraft(draft);                    // 先落草稿
  const media = await uploadAll(draft.media, {
    onProgress: setProgress,                 // 视频转码进度
    resumable: true });                      // 断点续传
  const r = await postApi.create({ ...draft, media,
    scheduleAt: draft.scheduledAt,           // 定时：服务端队列
    idempotencyKey: draft.id });
  if (r.status === 'reviewing') showState('审核中（粉丝可见策略）');
}
// 草稿：debounce 1s → idb + server draft
// 上传失败 → 保留草稿+重试入口（不清空）。
// 审核：fanVisibleStrategy === 'followersFirst' → 粉丝先见。
```
