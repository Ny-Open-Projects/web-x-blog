## SCN-229：协作文档中的表格（多人同时编辑单元格），协同怎么设计？

**答**:
- 表格数据模型：CRDT Map（单元格 key=row:col → Y.Text），单元格内容独立 CRDT 文本（同单元格并发编辑字符级合并），行列操作（插入/删除行列）为结构操作进同文档流水。
- 单元格冲突：同单元格并发编辑自动字符合并（CRDT）；单元格公式/结构化内容冲突→最后写入+覆盖提示（表格语义上字符合并没有意义，如 "=SUM(A1)" 合并两版公式会坏）；锁定单元格（有人编辑中显示锁定徽标，软锁不改硬限制）。
- 性能：大表格只同步视口单元格（按需加载行/列窗口，虚拟滚动+分区同步），单元格编辑态的 awareness（他人正在编辑哪个单元格的提示条）。
- 与文本协同的一致性：表格操作与文本操作同一 seq 流水（撤销栈统一——撤销跨文本与表格操作按提交序撤销）。

```javascript
// Yjs 表格模型
const table = ydoc.getMap('table');         // 'r:c' → Y.Text
function editCell(r, c, newText) {
  ydoc.transact(() => {
    const key = `${r}:${c}`;
    const cell = table.get(key) ?? table.set(key, new Y.Text());
    cell.delete(0, cell.length);
    cell.insert(0, newText);
  });
}
// awareness：编辑中单元格（软锁提示）
awareness.setLocalStateField('editingCell', 'r3:c2');
// 视口同步：只订阅可视行列窗口的单元格 observe。
// 撤销栈：ydoc.transact 包裹 → UndoManager 统一撤销文本与表格。
```
