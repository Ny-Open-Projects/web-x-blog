## SCN-330：社交信息流场景怎么总收束？

**答**:
- 全景五域：消费流（321 沉浸视频/325 多源排序/322 互动）、创作发布（323 发布器/326 审核可见性）、关系与互动（324 私信/328 关注推送/327 评论区/329 主页）、内容安全（审核流转/举报拉黑/青少年）、底层复用（IM 基座/播放器池/曝光计费/隐私矩阵）。
- 社交场景的核心张力：即时性与审核的平衡（先发后审 vs 先审后发按内容分级）、个性化与隐私的平衡（推荐依赖数据 vs 隐私设置）、洪峰与体验的平衡（互动洪峰乐观+洪峰降级）——每条张力都需要服务端策略+前端呈现的配合。
- 资产复用地图：IM 全套（SCN-213~220）、直播全套（SCN-271~280：直播是社交的子场景）、播放器池与预载矩阵（消费流）、审核可见性矩阵（发布侧）——社交产品是这些资产的最大消费者。
- 收束心法：社交前端的核心是"状态的即时性与真实性管理"——互动的乐观更新、关系的即时生效、审核的可见性矩阵，本质都是"本地体验优先+服务端事实源+分端可见性"三件套在不同实体上的应用。

```text
社交全景：
消费：沉浸视频池 / 多源流插入 / 乐观互动
创作：发布器草稿 / 审核可见性矩阵 / 申诉
关系：关注状态机 / 推送分级 / 隐私矩阵
安全：先发后审分级 / 举报拉黑 / 青少年
复用：IM 基座 / 直播全套 / 播放器池。
心法：本地体验优先 + 服务端事实源
  + 分端可见性。
```
