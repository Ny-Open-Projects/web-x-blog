## SCN-446：手写虚拟背景：人像分割、背景合成、CPU 自适应降级链

**需求与边界**：
- 输入：摄像头流、背景配置；输出：处理后流（推流用）。
- 边界要求：① 分割 mask+背景合成（canvas 管线）；② CPU 监控自适应（处理帧率降→分割关→功能下线三级降级）；③ 处理分辨率与推流分辨率分离；④ GPU 不可用回退 WASM。

**答**：
```javascript
class VBgPipeline {
  constructor(video, { bg = 'blur', fps = 30 }) {
    this.fps = fps; this.bg = bg;
    this.segmenter = pickSegmenter();          // GPU 优先，WASM 回退
    this.canvas = new OffscreenCanvas(480, 360); // 处理分辨率低
    this.loop();
  }
  async frame() {
    const mask = await this.segmenter.segment(this.video); // 人像 mask
    const ctx = this.canvas.getContext('2d');
    if (this.bg === 'blur') blurLayer(ctx, this.video);    // 背景模糊
    else ctx.drawImage(this.bg, 0, 0);         // 图片背景
    ctx.drawImageMasked(this.video, mask);     // 人像叠加
    return this.canvas;                        // captureStream 推流
  }
  loop() {
    setTimeout(async () => {                   // 处理帧率独立
      await this.frame();
      this.adapt();
      this.loop();
    }, 1000 / this.fps);
  }
  adapt() {                                    // CPU 自适应降级链
    const load = cpuMonitor.load();
    if (load > 0.8 && this.fps > 15) this.fps = 15;      // 1 降帧率
    else if (load > 0.9 && this.segmenter.on) this.segmenter.off();
                                              // 2 关分割（纯虚化）
    else if (load > 0.95) this.disable();      // 3 功能下线
  }
}
// 推流分辨率（720p）≠ 处理分辨率（360p 插值）——省算力。
// 处理流：canvas.captureStream(fps) → replaceTrack。
```

**评分点**:
- 分割 mask+背景合成的管线顺序正确。
- 三级降级链（降帧率→关分割→下线）+ CPU 监控驱动。
- 处理分辨率与推流分辨率分离（省算力）。
- GPU→WASM 回退路径。
