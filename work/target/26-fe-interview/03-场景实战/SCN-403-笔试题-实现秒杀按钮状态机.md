## SCN-403：手写秒杀按钮状态机：idle/countdown/ready/processing/done/soldout

**需求与边界**：
- 输入：活动配置 {startAt(服务器时间), endAt, token}；输出：状态与渲染回调。
- 边界要求：① 倒计时以服务器时间校准（本地偏移修正）；② 到点切换 ready 精度 <1s；③ processing 期防重复点击；④ 结束/售罄由服务端事件驱动而非本地推断。

**答**：
```javascript
class SeckillButton {
  constructor({ startAt, endAt, clock, onChange }) {
    this.startAt = clock.serverNow(startAt);   // 服务器时间校准
    this.endAt = clock.serverNow(endAt);
    this.state = 'idle'; this.onChange = onChange;
    this.tick();
  }
  tick() {
    const now = Date.now() + this.clock.offset;
    if (now < this.startAt)
      return this.set('countdown',
        { remain: this.startAt - now });       // 倒计时展示
    if (now >= this.endAt) return this.set('ended');
    if (this.state === 'idle' || this.state === 'countdown')
      this.set('ready');                       // 到点开抢
  }
  async click(userId) {
    if (this.state !== 'ready') return;        // 状态守卫
    this.set('processing');                    // 防重复点击
    try {
      const r = await seckillApi.grab({
        activityId: this.id, userId, token: this.token,
        idempotencyKey: `${this.id}:${userId}` });   // 幂等
      if (r.status === 'success') this.set('done', r);
      else if (r.status === 'queue') this.set('processing',
        { queue: r.queueId });                 // 排队保持处理态
      else this.set('soldout');
    } catch (e) { this.set('ready', { retry: true }); } // 可重试
  }
  set(s, payload) { this.state = s; this.onChange(s, payload); }
}
// 服务端事件驱动：ws.on('seckill_end') → set('soldout')
//   （本地推断可能误判，以服务端为准）。
```

**评分点**:
- 六态状态机完整且迁移有守卫（processing/ended 不可点击）。
- 倒计时服务器校准（clock.offset），到点切换精度 <1s。
- 抢购请求幂等键 + 排队态保持处理中（防重复提交）。
- 结束/售罄以服务端信令为准的兜底意识。
