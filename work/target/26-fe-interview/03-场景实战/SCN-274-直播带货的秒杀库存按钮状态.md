## SCN-274：直播间内的秒杀（限量优惠限时开抢），状态同步怎么做？

**答**:
- 状态机广播：秒杀活动状态（预告→进行中→售罄/结束）由服务端广播（时间以服务端为准），观众端倒计时本地跑+定期校正（SCN-020 原则）；按钮三态随广播切换（预约提醒/立即抢购/已售罄）。
- 抢购交互：点击抢购→进入处理态（防重复）→排队轮询（SCN-203 机制复用）→结果（成功→弹下单浮层；售罄→遗憾提示+订阅到货通知入口）。
- 洪峰协调：抢购瞬间直播间万人点击——前端请求限流（点击合并+随机抖动 0~500ms 分散请求）、按钮点击后立即视觉反馈（进度动画稳住用户——体感等待）、失败重试限次。
- 附加体验：库存进度条（"已抢 80%"实时更新，营造氛围但服务端下发）、抢购结果不影响直播观看（弹层可关闭，直播继续）。

```javascript
ws.on('seckill_state', (s) => {
  seckillState.set(s.status, { endAt: s.endAt,
    stock: s.stockPercent });                // 服务端为准
});
// 倒计时：本地跑 + 每 30s 校正 endAt
async function grab() {
  if (state !== 'ready') return;
  setState('processing');
  await jitter(0, 500);                     // 随机抖动分散请求
  const r = await withRetry(() => seckillApi.grab(id), 2);
  r.status === 'queued' ? pollResult(r.queueId)
    : r.status === 'success' ? showOrder(r)
    : setState('soldout');
}
// 库存进度条：ws.on('seckill_stock', p => progress(p))。
```
