## SCN-758：违规片段定位怎么实现？
**答**：
- 标注数据结构：机审与人审统一 marks 模型 `{ startTs, endTs, type, confidence, source }`，时间轴渲染条带，颜色按类型。
- 片段循环：审核员点击标记进入「片段循环模式」（start↔end 循环播放 + 0.5 倍速），快速确认违规内容；键盘 n/p 在标记间跳转。
- 手动标注：人审发现机器漏标时可手动框选时间段标注类型（补充训练数据）。
- 导出证据：违规片段可裁剪导出短片段（服务端 ffmpeg）作为处置证据。
- 追问钩子：循环播放怎么实现——监听 timeupdate 越过 endTs 时 seek 回 startTs；注意与用户主动拖动互斥（拖动即退出循环模式）。

```javascript
function useClipLoop(video, mark, { speed = 0.5 } = {}) {
  const [looping, setLooping] = useState(false);
  useEffect(() => {
    if (!looping || !mark) return;
    video.playbackRate = speed;
    video.currentTime = mark.startTs;
    const onTime = () => {
      if (video.currentTime >= mark.endTs) video.currentTime = mark.startTs;   // 循环
    };
    const onSeek = () => setLooping(false);          // 用户拖动退出循环
    video.addEventListener('timeupdate', onTime);
    video.addEventListener('seeking', onSeek);
    return () => { video.removeEventListener('timeupdate', onTime);
                   video.removeEventListener('seeking', onSeek); video.playbackRate = 1; };
  }, [looping, mark]);
  return { looping, toggle: () => setLooping(v => !v) };
}
```
