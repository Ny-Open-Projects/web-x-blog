## SCN-428：手写轨迹回放：按时间轴插值、倍速、拖拽定位、增量绘制

**需求与边界**：
- 输入：轨迹点（带时间戳）、倍速；输出：播放控制器（play/pause/seek/speed）。
- 边界要求：① 位置=时间插值（不按点序匀速——速度真实）；② 倍速=时间倍率；③ 拖拽→二分定位时间戳+重绘已走轨迹；④ 已走轨迹增量绘制（位图缓存）；⑤ 暂停续播状态保持。

**答**：
```javascript
class TrackPlayer {
  constructor(points, map) {
    this.track = points.sort((a, b) => a.ts - b.ts)
      .map(simplify);                          // 抽稀预处理
    this.times = this.track.map(p => p.ts);
    this.idx = 0; this.speed = 1; this.playing = false;
  }
  play() { this.playing = true; this.last = performance.now();
    this.loop(); }
  loop() {
    if (!this.playing) return;
    const now = performance.now();
    const dt = (now - this.last) * this.speed; // 倍速=时间倍率
    this.simTime += dt;
    this.last = now;
    const pos = this.interpolate(this.simTime);
    this.drawTrail(pos.idx);                   // 增量绘制已走
    this.marker.setPosition(pos.coord);        // 插值位置
    if (this.simTime < endAt) requestAnimationFrame(() => this.loop());
    else this.onEnd?.();
  }
  interpolate(t) {                             // 时间插值
    let i = this.binarySearch(t);              // 二分定位时间段
    const a = this.track[i], b = this.track[i + 1];
    const k = (t - a.ts) / (b.ts - a.ts);
    return { coord: lerpLngLat(a, b, k), idx: i };
  }
  seek(ts) {                                   // 拖拽定位
    this.simTime = clamp(ts, startAt, endAt);
    const { idx } = this.interpolate(this.simTime);
    this.redrawTrailBitmap(idx);               // 位图缓存重绘
    this.idx = idx;
  }
  setSpeed(s) { this.speed = s; }
}
```

**评分点**:
- 按时间戳插值（真实速度）而非按点序匀速——正确模型。
- 倍速=模拟时间倍率；seek 二分定位+位图重绘。
- 增量绘制已走轨迹（性能）；抽稀预处理。
- pause/resume 状态保持（simTime 独立于真实时间）。
