## SCN-660：时间轴回放怎么实现？
**答**：
- 数据组织：历史事件按时间窗口分片（如 5 分钟一片）预取，回放时按播放头seek 加载；快照 + 事件重放双模式（快照准、重放省流量，混合：起点快照 + 增量事件）。
- 播放控制：倍速（1x/4x/16x）、拖拽 seek（跳片加载）、暂停；播放头位置与数据时间戳对齐而非 wall clock。
- 渲染一致性：回放态与实时态互斥（回放时断开实时推送，退出回放时快进到当前并恢复推送），防止两套时间叠加错乱。
- 轻量化：回放只推「状态差异事件」，位置/数值没变的设备不发数据。
- 追问钩子：seek 到任意时间点怎么快——按片索引二分定位 + 目标片首帧快照直达，不做全量重放。

```javascript
function createReplayer(timeline) {
  let playing = false, speed = 1, cursor = 0;
  const slices = timeline.slices;                  // [{start, end, snapshotUrl, events}]
  async function seek(ts) {
    const idx = bisect(slices, s => s.start <= ts);           // 二分定位片
    const slice = slices[idx];
    if (cursor !== slice.start) {
      await applySnapshot(slice.snapshotUrl);                 // 片首快照直达
      cursor = slice.start;
    }
    for (const e of slice.events.filter(e => e.ts <= ts)) applyEvent(e);
    cursor = ts;
  }
  function play() {
    playing = true;
    const step = () => {
      if (!playing) return;
      cursor += 1000 * speed;                                 // 每步推进 speed 秒
      if (needNextSlice(cursor)) preloadSlice(nextSlice);
      applyEventsUpto(cursor);
      setTimeout(step, 1000 / speed);
    };
    step();
  }
  return { seek, play, pause: () => { playing = false; } };
}
```
