## SCN-206：满减+优惠券+跨店合单的优惠计算，前端引擎怎么设计？

**答**:
- 计算职责划分：前端做"展示性试算"（帮用户理解优惠结构），服务端做"结算裁决"（下单时以服务端算价为准）——前端试算与服务端差额超阈值（如 1 分钱以上）时提示刷新，绝不前端直出下单价格。
- 计算引擎设计：规则集抽象（满减/折扣/立减/跨店券统一为 calculator 插件，按作用域分组：单品级→店铺级→跨店级，逐层应用），分摊逻辑（优惠金额按比例分摊到商品行——退款时按行退的关键，分摊精度用分为单位+尾差挂到最后一行）。
- 最优组合推荐：券组合枚举（券少时全排列，券多时启发式：优先大额券+凑单提示），凑单引擎（差 X 元可用券→推荐凑单商品列表，按加购转化率排序）。
- 边界与一致性：互斥规则表（券与券/券与活动的互斥关系配置化）、价格快照（下单时的优惠明细快照留存，售后按快照退）。

```javascript
const calculators = [itemDiscount, shopFull, crossShopCoupon]; // 逐层
function calcOrder(items, coupons) {
  let lines = items.map(i => ({ ...i, pay: i.price }));
  let remaining = coupons.slice();
  const trail = [];                        // 明细快照
  for (const calc of calculators) {
    const r = calc(lines, remaining);      // 每层返回 {lines, used}
    lines = r.lines;
    remaining = remaining.filter(c => !r.used.includes(c.id));
    trail.push({ calc: calc.name, used: r.used,
      saved: r.saved, lines: snapshot(lines) });
  }
  return { lines: apportion(lines, trail), trail };  // 分摊到行
}
function apportion(lines, trail) {
  const total = sum(trail.map(t => t.saved));       // 总优惠
  let assigned = 0;
  return lines.map((l, i) => {
    if (i === lines.length - 1)                     // 尾差挂最后一行
      return { ...l, discount: toFen(l.price * total / sumPrices(lines)) - assigned + total };
    const d = Math.round(l.price * total / sumPrices(lines));
    assigned += d;
    return { ...l, discount: d };
  });
}
```
