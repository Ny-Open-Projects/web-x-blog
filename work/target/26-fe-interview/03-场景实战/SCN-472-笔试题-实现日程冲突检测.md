## SCN-472：手写日程冲突检测：区间重叠计算、UTC 换算、空闲时段推荐

**需求与边界**：
- 输入：参会者日程（各自时区）、候选时段；输出：冲突检测结果与推荐。
- 边界要求：① 统一 UTC 轴后判重叠（跨时区正确）；② 重叠类型（完全/部分/边界贴邻不算冲突）；③ 空闲交集推荐（所有人空闲∩工作时间）；④ DST 切换周警示。

**答**：
```javascript
function overlaps(a, b) {                       // 区间重叠
  return a.start < b.end && b.start < a.end;    // 贴邻不算
}
function detectConflicts(newEvent, calendars) { // calendars: UTC 轴
  const conflicts = calendars
    .flatMap(c => c.events.map(e => ({ owner: c.owner, e })))
    .filter(x => overlaps(newEvent, x.e));
  return conflicts;                             // 冲突人清单
}
function suggestSlots(participants, range) {
  const busy = participants.map(p =>
    p.events.map(toUTC(p.tz)));                 // 各自时区→UTC
  const work = participants.map(p => workWindow(p.tz));
  const slots = [];
  for (let t = range.start; t < range.end; t += 30e3) {
    const ev = { start: t, end: t + 3600e3 };
    const free = busy.every(b =>
      !b.some(e => overlaps(ev, e)));
    const inWork = work.every(w => t >= w.start && t < w.end);
    if (free && inWork) slots.push({
      utc: t,
      locals: participants.map(p => fmt(t, p.tz)),   // 各自本地
      warn: isEarly(t, p.tz) && '太早' });
  }
  return slots.slice(0, 5);                    // 推荐 Top5
}
// DST：range 覆盖切换日 → warn('本周含夏令时切换')。
```

**评分点**:
- 区间重叠判定（贴邻不算）正确。
- UTC 轴统一换算（跨时区正确性）+ 各自本地时区显示。
- 空闲交集∩工作时间推荐 + Top N。
- DST 切换警示。
