## SCN-435：手写排队进度：推送更新、过号预警（前方少+距离远）、取消重排

**需求与边界**：
- 输入：排队推送事件、定位；输出：进度 UI 与预警。
- 边界要求：① 进度实时更新（WS 推送+轮询兜底）；② 过号预警（前方 ≤2 桌且距离 >1km）；③ 过号后的顺延规则展示；④ 取消排队确认。

**答**：
```javascript
class QueueTracker {
  constructor({ storeId, locate, distTo }) {
    this.storeId = storeId; this.locate = locate;
    this.distTo = distTo;
  }
  subscribe(queueId) {
    ws.on(`queue:${queueId}`, (s) => this.update(s));
    pollFallback(`queue:${queueId}`, 30e3);    // 轮询兜底
  }
  update(s) {                                  // s: {ahead, nowNo}
    render({ ahead: s.ahead, now: s.nowNo,
      progress: 1 - s.ahead / s.total });      // 进度条
    // 过号预警：前方少 + 距离远
    const d = this.distTo(this.locate(), this.storeId);
    if (s.ahead <= 2 && d > 1000)
      push(`前方仅 ${s.ahead} 桌，您距门店 ${fmtKm(d)}，请尽快到店`);
    if (s.ahead === 0 && d > 500)
      this.missWarn(s);                        // 即将叫号
  }
  missWarn(s) {                                // 过号规则透明
    banner('即将到您的号，过号将顺延 3 桌',
      { actions: ['立即到店', '取消排队'] });
  }
  cancel() {
    confirm('确认取消排队？') && api.cancel(this.queueId);
  }
}
// 过号：ws.on('missed') → 顺延说明（规则透明）+ 重排按钮。
// 进度：WS 优先 + 30s 轮询兜底（断网恢复数据一致）。
```

**评分点**:
- 推送+轮询兜底双通道（进度可靠）。
- 过号预警双条件（前方少×距离远）——定位联动。
- 过号规则透明化（顺延说明+取消/重排动作）。
- 进度条与可视化（1-ahead/total）。
