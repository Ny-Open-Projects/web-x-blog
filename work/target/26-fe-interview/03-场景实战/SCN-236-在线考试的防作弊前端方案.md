## SCN-236：在线考试的防作弊，前端能做什么、边界在哪？

**答**:
- 前端可做的检测：切屏/失焦检测（visibilitychange/blur 记录次数与时长）、粘贴拦截（考试模式禁粘贴或记录粘贴行为）、全屏强制（退出全屏记录）、多标签检测（localStorage 广播同考号多开）、摄像头抓拍（定时/切屏触发抓拍上传）——所有行为记录上报服务端裁决，前端只采集不判决。
- 数据可信度：本地答案加密暂存+定时快照上传（断电断网可恢复，SCN-227 离线思路）、防篡改（答案提交带完整性 hash，服务端校验）、时间以服务端为准（本地改时钟无效，SCN-020 同源）。
- 边界认知：前端防作弊全部可被技术用户绕过（DevTools/虚拟机/第二台设备）——前端手段的价值是"提高作弊成本+采集行为证据"，真正的防作弊靠考试设计（题库随机/限时/面试化）+ 监考（AI 视频监考）+ 服务端行为分析。
- 体验平衡：误伤控制（切屏误触不直接判负分，累积阈值+人工复核）、可访问性例外（无障碍工具的误报白名单）、考前明确告知监考范围（合规与知情同意）。

```javascript
const monitor = {
  blurCount: 0, fullScreenExit: 0, pastes: [],
};
document.addEventListener('visibilitychange', () => {
  if (document.hidden) {
    monitor.blurCount++;
    snapshotCamera();                        // 切屏抓拍
    report({ type: 'blur', at: serverNow() });
  }
});
document.addEventListener('paste', (e) => {
  monitor.pastes.push({ len: e.clipboardData
    .getData('text').length, at: serverNow() });
  report({ type: 'paste', ...last(monitor.pastes) });
  // 记录但可配置是否阻止
});
```
