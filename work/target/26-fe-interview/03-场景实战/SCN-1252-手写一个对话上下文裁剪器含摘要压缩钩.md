## SCN-1252：手写一个对话上下文裁剪器（含摘要压缩钩子）

**答**：
- 需求：implement ContextManager(maxTokens, tokenizer)。push(msg) 追加；build() 输出裁剪后上下文（system 保留 + 最近消息 + 被裁部分摘要钩子 onTrim 回调生成摘要注入）；token 计数用注入 tokenizer。
- 边界：单条消息超 maxTokens 直接报错；摘要消息也计入 token；build 幂等（不重复裁剪）。
- 评分点：裁剪策略；摘要钩子；单条超限；幂等

```javascript
class ContextManager {
  constructor(maxTokens, tokenizer, onTrim) {
    this.max = maxTokens; this.tk = tokenizer;
    this.onTrim = onTrim; this.msgs = [];
  }
  push(msg) {
    const t = this.tk(msg.content);
    if (t > this.max) throw new Error('单条消息超上下文上限');
    this.msgs.push({ ...msg, tokens: t });
  }
  build() {
    let total = this.msgs.reduce((s, m) => s + m.tokens, 0);
    if (total <= this.max) return this.msgs;
    const sys = this.msgs.filter(m => m.role === 'system');
    const rest = this.msgs.filter(m => m.role !== 'system');
    const trimmed = [];
    while (total > this.max && rest.length > 2) {
      const cut = rest.splice(0, Math.ceil(rest.length / 3));
      const summary = this.onTrim(cut);                // 摘要压缩钩子
      const sMsg = { role: 'system', content: `[历史摘要] ${summary}` };
      total -= cut.reduce((s, m) => s + m.tokens, 0);
      total += this.tk(sMsg.content);
      trimmed.push(sMsg);
    }
    return [...sys, ...trimmed, ...rest];
  }
}
```
