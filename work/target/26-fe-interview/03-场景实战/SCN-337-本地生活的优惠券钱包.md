## SCN-337：用户优惠券钱包（多类型券/有效期/最优推荐）怎么设计？

**答**:
- 券类型模型：券 schema（满减/折扣/兑换/配送券，使用范围：门店/品类/商品，门槛与限额，叠加规则——SCN-206 引擎数据源），券状态（待用/已用/过期/冻结——退款中冻结态）。
- 钱包呈现：分组 tab（可用/已用/过期），有效期排序（临期优先——"3 天后过期"紧迫标注）、券详情（适用范围可视化：哪些门店/商品可用——跳转筛选）、券组合推荐（结算时最优组合——SCN-206 引擎）。
- 领券与发放：领券中心（可领券列表+库存实时）、批量发券（活动发券的到账通知）、券码兑换（兑换码输入）。
- 边界处理：叠加互斥提示（互斥券同时选择→提示冲突）、退款券返还（订单退款→冻结券解冻/过期券补偿策略）、券与凑单联动（SCN-286 凑单复用）。

```javascript
function Wallet({ coupons }) {
  const groups = groupBy(coupons, 'status');  // 待用/已用/过期
  return <>
    <Tabs data={groups}>
      {groups.usable.sort(byExpireFirst).map(c =>
        <CouponCard key={c.id} {...c}
          warn={expireSoon(c)}                // 3天过期标注
          scopeHint={scopeOf(c)} />)}         {/* 可用范围 */}
    </Tabs>
  </>;
}
// 最优推荐：bestCombo(cart, usableCoupons)（SCN-206 引擎）
// 冲突：互斥券同选 → toast('两张券不可叠加')。
// 退款返还：refund.done → unfreeze(coupons)。
```
