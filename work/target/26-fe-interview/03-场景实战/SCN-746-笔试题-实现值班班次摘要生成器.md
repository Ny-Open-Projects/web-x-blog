## SCN-746：手写班次摘要生成器

**需求与边界**：
- 输入：班次时间范围 + 事件流（告警/发布/故障/操作）；输出结构化摘要：触发/处理/遗留/发布清单 + 一段叙述文本。
- 边界：① 遗留（班次结束仍 FIRING）必须单列；② 叙述按严重度排序；③ 空班次输出「无事发生」而非空对象。

**答**：
```javascript
async function shiftSummary({ start, end }) {
  const [alerts, deploys, incidents] = await Promise.all([
    alertsStore.in(start, end), deploysStore.in(start, end), incidentsStore.in(start, end),
  ]);
  const fired = alerts.filter(a => a.firedIn(start, end));
  const resolved = fired.filter(a => a.resolvedTs && a.resolvedTs <= end);
  const carry = fired.filter(a => !a.resolvedTs || a.resolvedTs > end);   // 遗留
  const summary = {
    fired: fired.length, resolved: resolved.length, carryOver: carry.map(a => a.id),
    deploys: deploys.map(d => `${d.service}@${d.version} ${fmtTime(d.ts)}`),
    incidents: incidents.map(i => ({ id: i.id, sev: i.sev })),
  };
  summary.narrative = carry.length
    ? `班次内触发 ${fired.length} 条告警，已处理 ${resolved.length}；遗留 ${carry.length} 条需交接：${carry.map(a => `${a.metricKey}(${a.severity})`).join('、')}`
    : fired.length ? `班次内触发 ${fired.length} 条告警全部闭环`
    : '本班次无事发生';
  return summary;                                     // 空班次也有 narrative
}
```

**评分点**:
- 触发/处理/遗留三类口径清晰（遗留 = 结束时仍 FIRING）。
- 发布与事故清单便于交接上下文。
- 空班次「无事发生」兜底。
- narrative 遗留明细可直接粘贴到交接文档。
