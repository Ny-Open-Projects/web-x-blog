## SCN-503：金融账户的资金流水组件怎么设计？
**答**：
- 数据分层：流水列表按「日聚合头 + 明细行」两级渲染，接口按游标分页（时间 + 流水号双游标，避免同一秒多笔丢数据），前端不做全量拉取。
- 精度红线：金额一律用字符串/分（整数）传输，前端用整数运算或 decimal 库，禁止浮点直接加减展示。
- 高频更新：新流水从 WS 推送进来时插入列表头并带「新」标记，不整表刷新；余额与流水分开通道，避免联动闪烁。
- 审计要求：每笔流水展示可溯源字段（流水号/渠道/操作端），点击可看回执；前端埋点不落敏感字段（卡号/手机号脱敏后再上报）。
- 追问钩子：分页到中途来了新数据，如何保证「插入头部不打断当前浏览位置」——用滚动锚定而不是简单 prepend。

```javascript
// 双游标分页 + 插入头部锚定
async function loadFlows(cursor) {
  // cursor: { ts, id }，服务端按 (ts, id) 排序保证同秒多笔不丢
  const { list, next } = await api.get('/flows', {
    params: { before_ts: cursor.ts, before_id: cursor.id, size: 20 },
  });
  return { list: list.map(decorate), next };
}
function decorate(f) {
  return { ...f,
    amountText: fenToYuan(f.amount),          // 分 -> 元，整数运算
    masked: f.account ? mask(f.account, 4) : '', // 尾号展示
    isNew: Date.now() - f.ts < 60_000,
  };
}
// 新流水到达：若用户在顶部（scrollTop < 40）直接插入；
// 否则插入缓冲区并显示「有 N 笔新流水」气泡，点击后插入并复位锚点
```
