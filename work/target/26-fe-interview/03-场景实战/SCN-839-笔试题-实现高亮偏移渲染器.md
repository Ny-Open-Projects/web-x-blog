## SCN-839：手写高亮渲染器

**需求与边界**：
- 输入：`{ q, offsets: [[start, end]] }`（码点偏移）；输出安全的 HTML（<mark> 包裹命中段）。
- 边界：① 偏移用码点（surrogate pair 安全）；② 全文 HTML 转义后再标记（防 XSS）；③ 偏移越界/乱序容错（clamp + 合并重叠）；④ offsets 为空整串无高亮。

**答**：
```javascript
function escapeHtml(s) {
  return s.replace(/[&<>"']/g, (c) =>
    ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' }[c]));
}
function renderHighlight(item) {
  const chars = [...item.q];                          // 码点级（emoji 安全）
  const n = chars.length;
  // 合并重叠 + clamp
  const ranges = (item.offsets || [])
    .map(([s, e]) => [Math.max(0, Math.min(s, n)), Math.max(0, Math.min(e, n))])
    .filter(([s, e]) => e > s)
    .sort((a, b) => a[0] - b[0]);
  const merged = [];
  for (const [s, e] of ranges) {
    const last = merged.at(-1);
    if (last && s <= last[1]) last[1] = Math.max(last[1], e);
    else merged.push([s, e]);
  }
  const markSet = new Set();
  merged.forEach(([s, e]) => { for (let i = s; i < e; i++) markSet.add(i); });
  return chars.map((c, i) =>
    markSet.has(i) ? `<mark>${escapeHtml(c)}</mark>` : escapeHtml(c)
  ).join('');
}
// renderHighlight({ q: '苹果<手机>', offsets: [[0,2]] })
// => '<mark>苹</mark><mark>果</mark>&lt;手机&gt;'   （输入含 HTML 也安全）
```

**评分点**:
- escapeHtml 在标记前对每个字符转义（XSS 防线）。
- 码点级拆分（surrogate pair 不错位）。
- 偏移 clamp + 重叠合并容错。
- 输出片段可直接 innerHTML（已消毒声明）。
