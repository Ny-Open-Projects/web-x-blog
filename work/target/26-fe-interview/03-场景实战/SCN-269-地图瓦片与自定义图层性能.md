## SCN-269：地图上叠加热力图/海量轨迹等自定义图层，性能怎么实现？

**答**:
- 图层技术选型：热力图（厂商内置热力插件——优先复用）、自定义 canvas 图层（地图 API 的 custom layer 钩子：每帧拿到投影矩阵自己画）、WebGL 图层（10 万级轨迹/粒子：regl/three 叠加，GPU 渲染）、栅格瓦片（预渲染热力图成瓦片图——服务端/离线渲染，性能最好）。
- 渲染优化：视野裁剪（只渲染可视区数据）、分级细节（LOD：低 zoom 渲染简化版数据）、重绘节流（地图缩放动画期间节流重绘）、数据分块（按瓦片网格预组织数据，移动视野增量加载）。
- 交互拾取：canvas 图层的点击拾取（颜色编码拾取帧：渲染时把 id 编码进颜色，readPixels 拾取）、空间索引（网格索引 O(1) 粗筛）。
- 数据管线：大数据传输（二进制/扁平数组而非 JSON 对象数组——10 万点 JSON 10MB vs 二进制 2MB）、Worker 解码（解码不占主线程）。

```javascript
// 自定义 canvas 图层
class HeatLayer {
  constructor(map) { this.map = map; map.on('frame', () => this.draw()); }
  draw() {
    const { projection, bounds } = this.map.getView();
    const visible = this.grid.query(bounds);   // 空间索引粗筛
    const ctx = this.canvas.getContext('2d');
    ctx.clearRect(0, 0, w, h);
    for (const p of visible) {
      const [x, y] = projection(p.lnglat);     // 经纬度→屏幕
      drawGradient(ctx, x, y, p.weight);
    }
  }
}
// 10 万轨迹 → WebGL（regl）批量 draw call；
// 热力预渲染瓦片：服务端按 zoom/xyz 生成热力瓦片 PNG。
```
