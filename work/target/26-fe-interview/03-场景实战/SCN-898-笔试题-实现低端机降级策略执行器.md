## SCN-898：手写低端机降级执行器

**需求与边界**：
- 需求：设备分档（内存/核数/基准跑分）；按档位应用降级（动画关/图降质/请求合并）；降级不得影响抢购请求时机（点击即发请求）；分档结果缓存（会话内不变）。
- 边界：① 分档规则可配置下发（新机型适配）；② 分档检测一次执行缓存结果；③ 请求优先级与档位解耦（公平性）。

**答**：
```javascript
function deviceTier({ rules = DEFAULT_TIERS } = {}) {
  const cached = sessionStorage.getItem('tier');
  if (cached) return cached;
  const signals = {
    mem: navigator.deviceMemory ?? 4,
    cores: navigator.hardwareConcurrency ?? 4,
    bench: quickBenchmark(),                           // 微基准（500ms 内）
  };
  const tier = rules.find(r => matchRule(r, signals))?.tier ?? 'MID';
  sessionStorage.setItem('tier', tier);                // 会话内缓存
  report({ type: 'DEVICE_TIER', tier, ...signals });
  return tier;
}
function applyDegrade(tier, policies) {                // 降级只影响渲染
  const p = policies[tier] ?? policies.MID;
  if (p.animationOff) disableAnimations();
  if (p.imageQuality) setImageQuality(p.imageQuality);
  if (p.mergeRequests) enableRequestMerge();
  return {
    note: '抢购请求时机与档位无关',                    // 公平性：点击即发
    onRequest: (fn) => fn(),                           // 不排队不延迟
  };
}
```

**评分点**:
- 分档信号三维（内存/核数/微基准）+ 规则可配置。
- 会话缓存（检测一次不重复跑基准）。
- 公平性显式保障（降级不碰请求时机——点击先行）。
- 分档结果上报（分层复盘的数据基础）。
