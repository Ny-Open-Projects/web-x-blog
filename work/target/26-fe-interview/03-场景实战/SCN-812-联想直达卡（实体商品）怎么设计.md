## SCN-812：直达卡怎么设计？
**答**：
- 卡片类型：实体（人物/品牌）卡与商品卡（图+价+券）——点击跳详情而非搜索；普通建议词点击发起新搜索，两类行为必须区分埋点。
- 图片策略：卡片图小尺寸专用缩略图（64px），懒加载 + 失败占位；禁止加载原图（流量浪费）。
- 数据预算：直达卡数据（价格/库存）时效敏感——卡片展示时校验数据新鲜度，过期标灰「查看最新价格」。
- 布局兼容：卡片高度与纯文本建议混排，键盘导航跨类型一致（卡片是一个整体选项）。
- 追问钩子：为什么直达卡价格要新鲜度校验——搜索页到详情页价格不一致是高客诉场景；展示时校验 + 过期置灰是最低成本的预期管理。

```javascript
function EntityCard({ item }) {
  const stale = Date.now() - item.priceTs > 5 * 60_000;   // 5 分钟新鲜度
  return (
    <div className="entity-card" onClick={() => goto(item.url)}>
      <img src={item.thumb64} loading="lazy" onError={showPlaceholder} />
      <div>
        <b>{item.title}</b>
        <Price value={item.price} stale={stale} />    {/* 过期置灰 */}
      </div>
    </div>
  );
}
// 埋点：点击直达卡 type=card_click，点击建议词 type=sug_adopt —— 行为分开归因
```
