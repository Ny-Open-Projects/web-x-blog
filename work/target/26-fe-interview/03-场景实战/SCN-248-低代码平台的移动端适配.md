## SCN-248：低代码页面要同时出 H5 和小程序，多端适配怎么实现？

**答**:
- 逻辑与渲染分离：schema 是平台无关的（节点树/数据绑定/逻辑编排与端无关），渲染层分端实现（H5 渲染器/小程序渲染器各有一套组件注册表）——一套 schema 两端渲染。
- 端差异处理：组件映射差异（H5 div↔小程序 view——注册表屏蔽）、能力差异声明（组件标注端支持矩阵：webcam 组件 H5 only，小程序端自动降级或隐藏）、样式适配（rpx/vw 统一由样式编译层处理）。
- 编译与预览：schema 编译为目标端产物（H5 运行时渲染 / 小程序 WXML+AJS 代码生成或运行时渲染——小程序运行时渲染用 template 递归受限，代码生成更可控）、分端预览（编辑器内切换端预览）。
- 一致性保障：跨端 E2E（同 schema 两端快照对比）、端差异显式化（组件能力矩阵文档化，运营可见——防"为什么小程序没有这个功能"的困惑）。

```javascript
// 分端注册表
const H5Registry = { button: ButtonH5, video: VideoH5 };
const MPRegistry = { button: ButtonMP, video: null };  // 小程序无
function render(schema, platform) {
  const reg = platform === 'h5' ? H5Registry : MPRegistry;
  return walk(schema, (node) => {
    const comp = reg[node.type];
    if (!comp) return platformFallback(node);  // 端降级/隐藏
    return h(comp, resolveProps(node.props));
  });
}
// 能力矩阵：{ video: { h5: true, mp: false } }
// 小程序方案：运行时渲染（template 递归 20 层限制）
// vs 代码生成（schema → WXML），复杂页面选代码生成。
```
