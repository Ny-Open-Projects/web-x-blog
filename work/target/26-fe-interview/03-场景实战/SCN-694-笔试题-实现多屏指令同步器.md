## SCN-694：手写多屏同步器（从屏端）

**需求与边界**：
- 需求：接收主屏指令流（seq 单调）；乱序/重复丢弃；每 30s 上报状态 hash 与主屏对账；不一致或断连 60s 后请求快照重建；指令执行去抖（同类指令 200ms 合并执行最后一条）。
- 边界：① 断连重连后带 lastSeq 补增量；② 快照与增量竞争时快照优先（版本号大者）；③ 非法指令忽略并上报。

**答**：
```javascript
function createSlaveSync(channel, exec, { heartbeat = 30_000, snapshotTimeout = 60_000 } = {}) {
  let lastSeq = 0, lastCmdTime = 0, healthy = true;
  const pending = new Map();                           // opType -> 最后一条指令
  channel.subscribe('cmd', ({ op, payload, seq }) => {
    if (seq <= lastSeq) return;                        // 乱序/重复丢弃
    lastSeq = seq;
    lastCmdTime = Date.now();
    if (!OPS.has(op)) { report({ type: 'BAD_OP', op }); return; }
    pending.set(op, payload);                          // 合并同类
    setTimeout(() => {                                 // 200ms 合并窗口
      const p = pending.get(op);
      if (p !== undefined) { pending.delete(op); exec(op, p); }
    }, 200);
  });
  channel.subscribe('snapshot', ({ version, state }) => {
    if (version <= stateVersion()) return;             // 快照旧于当前则忽略
    exec('applySnapshot', state);
    lastSeq = version;
  });
  setInterval(() => {                                  // 心跳对账
    channel.publish('state', { hash: stateHash(), seq: lastSeq });
    if (Date.now() - lastCmdTime > snapshotTimeout && healthy) {
      healthy = false;
      channel.publish('needSnapshot', { seq: lastSeq });   // 请求快照重建
    }
  }, heartbeat);
  channel.subscribe('cmd', ({ seq }) => { if (seq > lastSeq) healthy = true; });
  channel.onReconnect(() => channel.publish('resume', { lastSeq }));   // 补增量
  return { get lastSeq() { return lastSeq; } };
}
```

**评分点**:
- seq 单调去重 + 重连 resume 补增量。
- 同类指令 200ms 合并执行（相机拖拽流畅）。
- 心跳 hash 对账 + 超时请求快照重建（最终一致）。
- 快照版本守卫（旧快照不覆盖新状态）。
