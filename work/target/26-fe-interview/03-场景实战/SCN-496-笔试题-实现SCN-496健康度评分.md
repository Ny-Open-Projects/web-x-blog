## SCN-496：手写业务健康度评分：多维指标加权、一票否决、趋势告警

**需求与边界**：
- 输入：可用性/质量/成本/安全指标；输出：健康分与告警。
- 边界要求：① 归一化（不同量纲→0~100）；② 加权（安全/质量权重高）；③ 一票否决（安全严重违规直接红）；④ 趋势告警（连续下滑才告警——AGT-480 复用）。

**答**：
```javascript
function healthScore({ availability, quality, cost, security },
                     history) {
  const norm = {
    availability: availability.successRate * 100,
    quality: quality.acceptRate * 100,
    cost: Math.max(0, 100 - cost.perTask / cost.budget * 100),
    security: 100 - security.violations * 20,
  };
  const WEIGHTS = { security: 0.3, quality: 0.3,
    availability: 0.25, cost: 0.15 };
  const total = Object.entries(WEIGHTS)
    .reduce((s, [k, w]) => s + norm[k] * w, 0);
  const veto = security.criticalViolations > 0;   // 一票否决
  const level = veto ? 'red' : total > 80 ? 'green'
    : total > 60 ? 'yellow' : 'red';
  const trend = lastN(history, 3).every((v, i, a) =>
    i === 0 || v < a[i - 1]) ? 'declining' : 'stable';
  return { score: Math.round(total), level, veto, norm,
    alerts: [veto && { type: 'critical', msg: '安全违规' },
      trend === 'declining' && { type: 'warning', msg: '连续下滑' }]
      .filter(Boolean) };
}
```

**评分点**:
- 归一化处理量纲差异；加权安全/质量优先。
- 一票否决（加权不掩盖硬伤）。
- 连续 3 点下滑才告警（防单点波动）。
- 告警明细可执行。
