## SCN-755：审核队列分发与锁定怎么设计？
**答**：
- 抢占式领取：审核员主动「领取下一条」（服务端原子操作：锁定 + 返回内容），优于服务端强推（审核员节奏不同）；锁定带 TTL（如 10 分钟），超时自动释放回队列。
- 防重复：锁定态原子性（乐观锁/队列原子弹出）；同一视频多人同时领取被拒绝。
- 断线恢复：审核中页面崩溃，锁定超时释放后视频回到队列（半成品意见丢弃或进草稿）。
- 优先级调度：违规风险高（机审分数低）优先 + 等待时长加权（防饿死）。
- 追问钩子：锁定超时怎么定——按品类平均审核时长 P95 的 1.5 倍动态配置，过长压吞吐、过短频繁中断审核。

```javascript
async function claimNext(userId, category) {
  return db.transaction(async (tx) => {
    const item = await tx.queryOne(
      `SELECT id FROM review_queue WHERE category=? AND status='PENDING'
       ORDER BY risk_score DESC, wait_ts ASC LIMIT 1 FOR UPDATE SKIP LOCKED`);
    if (!item) return null;
    await tx.update(`UPDATE review_queue SET status='LOCKED', locked_by=?, lock_until=? WHERE id=?`,
      [userId, Date.now() + LOCK_TTL, item.id]);
    return item;
  });
}
// 超时释放（服务端定时任务）
// UPDATE review_queue SET status='PENDING', locked_by=NULL WHERE status='LOCKED' AND lock_until < NOW()
```
