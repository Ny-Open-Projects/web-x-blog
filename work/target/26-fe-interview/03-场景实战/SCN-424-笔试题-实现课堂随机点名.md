## SCN-424：手写课堂随机点名：公平随机、已点过滤、全员同步高亮

**需求与边界**：
- 输入：班级成员、点名历史；输出：被点者与全员同步效果。
- 边界要求：① 公平随机（服务端随机——前端不预知结果）；② 本节课已答过滤（可配置）；③ 全员同步高亮动画；④ 结果与应答流程衔接（SCN-235 上台）。

**答**：
```javascript
// 服务端（公平源）
function rollCall(roster, { history, avoidAnswered = true }) {
  const pool = roster.filter(m =>
    !avoidAnswered || !history.includes(m.id));
  if (!pool.length) return null;               // 全点过
  const picked = pool[Math.floor(Math.random() * pool.length)];
  history.push(picked.id);
  broadcast('rollcall', { studentId: picked.id,
    round: history.length });                 // 全员信令
  return picked;
}
// 学生端
ws.on('rollcall', ({ studentId }) => {
  highlightAvatar(studentId);                  // 全员高亮动画
  if (studentId === me.id)
    showAnswerPanel();                         // 应答面板（上台/文字）
});
// 教师端：看板 roster.map(s => history.includes(s.id))
//   → 已答 ✓ / 未答；一键提醒未答者。
// 重复点保护：history 由服务端维护（多教师不冲突）。
```

**评分点**:
- 随机源在服务端（公平+前端不可预知）。
- avoidAnswered 过滤与全点完空值处理。
- 全员同步高亮+被点者应答面板联动（流程衔接）。
- history 服务端维护（多端一致性）。
