## SCN-862：订单超时回流怎么设计？
**答**：
- 回流链路：秒杀订单支付倒计时（15 分钟）→ 超时自动关闭 → 库存回流 → 二次开抢（「回流库存」小批量瞬时放行，前端用「回血」提示承接）。
- 前端呈现：用户侧支付倒计时强提醒（剩余 3 分钟推送/弹窗），超时关闭后清晰告知「订单已关闭，库存将回流」；回流开抢时原排队用户有优先权提示。
- 二次开抢防抖：回流库存量小（几十件），前端按钮状态机复用（SCN-857）+ 回流专用令牌防脚本（原排队 token 优先）。
- 对账闭环：回流库存 = 超时关闭订单数，对账差异说明有丢单或库存泄漏——回流也是资损监控点。
- 追问钩子：为什么回流开抢要原排队用户优先——回流库存本质是「未兑现的排队承诺」，给原排队者优先是公平性设计，也抑制外挂抢单回流库存。

```javascript
function payCountdown(order, { remindAt = 3 * 60_000 } = {}) {
  const deadline = order.createdTs + 15 * 60_000;
  const timer = setInterval(() => {
    const left = deadline - Date.now();
    if (left <= remindAt && !reminded) {
      reminded = true;
      notify('订单即将超时，库存将回流');              // 强提醒
    }
    if (left <= 0) {
      clearInterval(timer);
      render('ORDER_CLOSED', { note: '库存将回流二次开抢', requeueToken: order.queueToken });
    }
  }, 1000);
}
```
