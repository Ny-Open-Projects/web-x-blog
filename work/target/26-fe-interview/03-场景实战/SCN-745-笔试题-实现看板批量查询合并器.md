## SCN-745：手写看板查询合并器

**需求与边界**：
- 需求：同时间范围的多指标查询合并为一次批量请求；并发中相同查询去重（共享 Promise）；快照一致性（同一 revision）。
- 边界：① 50ms 合并窗口收集请求；② 去重键 = metric+range+granularity；③ 单个指标失败不影响批内其他。

**答**：
```javascript
function createQueryCoalescer(api) {
  let timer = null, pending = new Map();               // key -> [resolve, reject]
  function query(metric, range, g) {
    const key = `${metric}|${range}|${g}`;
    return new Promise((resolve, reject) => {
      const entry = pending.get(key);
      if (entry) { entry.push({ resolve, reject }); return; }   // 去重共享
      pending.set(key, [{ resolve, reject }]);
      if (!timer) {
        timer = setTimeout(() => { timer = null; flush(); }, 50);   // 合并窗口
      }
    });
  }
  async function flush() {
    const batch = [...pending.entries()];
    pending = new Map();
    const keys = batch.map(([k]) => k);
    const rev = await api.revision(keys);              // 同一快照修订
    await Promise.allSettled(batch.map(async ([key, waiters]) => {
      const [metric, range, g] = key.split('|');
      try {
        const data = await api.query({ metric, range, g, rev });   // 快照一致
        waiters.forEach(w => w.resolve(data));
      } catch (e) {
        waiters.forEach(w => w.reject(e));             // 单指标失败不影响批内其他
      }
    }));
  }
  return { query };
}
```

**评分点**:
- 50ms 合并窗口批量请求（N 次变 1 次）。
- 相同查询 Promise 共享去重。
- revision 快照一致（面板间数字不打架）。
- Promise.allSettled 部分失败隔离。
