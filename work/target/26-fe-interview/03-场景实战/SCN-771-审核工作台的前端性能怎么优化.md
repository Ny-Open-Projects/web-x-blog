## SCN-771：审核工作台前端性能怎么优化？
**答**：
- 长会话稳定性：审核员一坐 8 小时——内存治理（视频实例切换时完整释放、雪碧图缓存上限、历史审核记录虚拟化），每 100 条自动软刷新提示。
- 切换流畅：审核切换（下一条）预加载——提交当前结果时预取下一条的视频首屏与元数据（预测性加载），切换 < 500ms。
- 多面板并发：播放器/时间轴/表单独立组件，提交后局部更新（不整页刷新）。
- 弱网可用：审核动作（提交）支持离线暂存重试，视频播放失败给明确的网络诊断提示（不是无限转圈）。
- 追问钩子：为什么「下一条预取」值得做——审核 80% 时间在切换与等待，预取把切换等待从 1~2s 压到 500ms 内，人均吞吐提升立竿见影，这是审核台特有的优化方向。

```javascript
async function submitAndNext(current, verdict) {
  const nextPromise = prefetchNext(current.id);      // 预取下一条（视频首屏+元数据）
  await api.post(`/review/${current.id}`, verdict);
  const next = await nextPromise;
  mountWorkbench(next);                              // 切换 < 500ms
  if (++sessionCount % 100 === 0) softRefreshHint(); // 长会话软刷新提示
}
function prefetchNext(currentId) {
  return api.get(`/queue/peek`, { params: { after: currentId } })
    .then(item => Promise.all([loadVideoMeta(item.id), loadSpriteSheet(item.id)]));
}
```
