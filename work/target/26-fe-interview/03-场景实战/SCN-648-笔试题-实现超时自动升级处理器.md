## SCN-648：手写超时自动升级处理器

**需求与边界**：
- 需求：节点超时按策略升级（最长 N 层），每层通知双方并写时间线；超过上限进人工池；同一节点升级操作幂等（重复触发只执行一次）。
- 边界：① 升级目标解析失败（无人）直接进兜底；② 原审批人补处理后升级链终止（先到先得）；③ 时间线事件带 traceId 关联。

**答**：
```javascript
async function escalate(instanceId, nodeId, policy) {
  const lockKey = `esc:${instanceId}:${nodeId}`;
  if (!(await acquireLock(lockKey))) return { skipped: true };   // 幂等锁
  try {
    const node = await getNode(nodeId);
    if (node.status !== 'PENDING') return { skipped: true, reason: 'ALREADY_DONE' };  // 先到先得
    for (let level = 1; level <= policy.maxLevel; level++) {
      let approver;
      try { approver = resolveApprover(node.assignee, level); }
      catch { approver = null; }
      if (!approver) break;                                     // 解析失败 → 兜底
      timeline.push({ instanceId, nodeId, type: 'ESCALATE', level, approver,
                      from: node.assignee, traceId: currentTrace() });
      await Promise.all([ notify(approver, 'escalated_to_you'),
                          notify(node.assignee, 'your_task_escalated') ]);
      node.assignee = approver;                                 // 指派给上级
      node.status = 'PENDING';                                  // 重新计时
      return { escalated: true, level, approver };
    }
    await manualPool(instanceId, nodeId, 'MAX_LEVEL_OR_RESOLVE_FAIL');   // 兜底池
    timeline.push({ instanceId, nodeId, type: 'MANUAL_POOL', traceId: currentTrace() });
    return { pooled: true };
  } finally { releaseLock(lockKey); }
}
```

**评分点**:
- 分布式/单飞锁保证升级幂等（重复触发 skip）。
- ALREADY_DONE 先到先得（原审批人补处理优先）。
- 解析失败直接兜底池，不空转升级链。
- 每层升级双通知 + 时间线 traceId。
