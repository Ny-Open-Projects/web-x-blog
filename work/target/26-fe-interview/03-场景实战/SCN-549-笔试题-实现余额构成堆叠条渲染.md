## SCN-549：手写余额构成堆叠条（Canvas）

**需求与边界**：
- 需求：横条堆叠渲染可用/冻结/在途，宽度按占比，占比 < 2% 的项合并到「其他」，标签防重叠（放不下移到图例）。
- 边界：① 总额为 0 显示空态；② DPR 缩放清晰；③ hover 命中检测返回原始项。

**答**：
```javascript
function drawBreakdown(canvas, parts, dpr = devicePixelRatio) {
  const w = canvas.clientWidth, h = canvas.clientHeight;
  canvas.width = w * dpr; canvas.height = h * dpr;
  const ctx = canvas.getContext('2d');
  ctx.scale(dpr, dpr);
  const total = parts.reduce((s, p) => s + p.amountFen, 0);
  if (total === 0n) { ctx.fillText('暂无资金', w / 2, h / 2); return { hit: () => null }; }
  const MIN = 0.02;
  const merged = [];
  let other = 0;
  for (const p of parts)
    Number(p.amountFen) / Number(total) < MIN ? (other += Number(p.amountFen)) : merged.push(p);
  if (other > 0) merged.push({ type: 'OTHER', amountFen: BigInt(Math.round(other)) });
  const COLORS = { AVAILABLE: '#34c77b', FROZEN: '#ff9f43', PENDING: '#7f8fa6', OTHER: '#dfe6e9' };
  const rects = []; let x = 0;
  const barH = 24, y = (h - barH) / 2;
  for (const p of merged) {
    const pw = Math.max(2, Number(p.amountFen) / Number(total) * w);   // 最小可见宽度 2px
    ctx.fillStyle = COLORS[p.type];
    ctx.fillRect(x, y, pw, barH);
    if (pw > 64) ctx.fillText(p.type, x + 4, y + barH / 2 + 4);        // 放得下才画标签
    rects.push({ x, w: pw, part: p });
    x += pw;
  }
  return {
    hit: (mx) => rects.find(r => mx >= r.x && mx <= r.x + r.w)?.part || null,  // hover 命中
  };
}
```

**评分点**:
- DPR 缩放（清晰度）与空态防御（total=0 不除零）。
- 小占比合并 + 最小 2px 可见宽。
- 标签空间阈值防重叠（<64px 移除内联标签）。
- 命中检测返回原始 part（交互闭环）。
