## SCN-589：手写设备指纹合成器

**需求与边界**：
- 需求：收集稳定信号（屏幕/时区/硬件/Canvas 哈希）按权重合成指纹 ID；与历史指纹列表做相似度匹配（容忍部分信号漂移）。
- 边界：① 信号缺失（null）不参与哈希但降低置信度；② 相似度 = 匹配信号权重 / 总权重；③ 输出置信度分级。

**答**：
```javascript
const SIGNAL_WEIGHTS = {
  screen: 0.2, tz: 0.1, lang: 0.05, hw: 0.15, canvas: 0.3, webgl: 0.2,
};
async function buildFingerprint(collectors) {
  const signals = {}; let totalW = 0;
  for (const [k, fn] of Object.entries(collectors)) {
    const v = await fn().catch(() => null);        // 单信号失败不影响整体
    signals[k] = v;
    if (v !== null) totalW += SIGNAL_WEIGHTS[k];
  }
  const parts = Object.entries(signals).filter(([, v]) => v !== null)
    .map(([k, v]) => `${k}=${v}`).sort().join('|');
  const fp = await sha256(parts);
  return { fp, signals, confidence: totalW };      // 置信度 = 有效信号权重和
}
function similarity(fa, fb) {                      // 容忍漂移的相似度
  let matched = 0, total = 0;
  for (const k of Object.keys(SIGNAL_WEIGHTS)) {
    total += SIGNAL_WEIGHTS[k];
    if (fa.signals[k] === fb.signals[k]) matched += SIGNAL_WEIGHTS[k];
  }
  return total ? matched / total : 0;
}
function matchHistory(fp, history) {               // history: [{fp, signals}]
  const best = history.map(h => ({ fp: h.fp, sim: similarity(fp, h) }))
    .sort((a, b) => b.sim - a.sim)[0];
  return best.sim > 0.8 ? { same: best.fp, sim: best.sim }   // 高相似视为同设备
       : best.sim > 0.5 ? { maybe: best.fp, sim: best.sim } // 漂移疑似
       : { new: true };
}
```

**评分点**:
- 加权合成 + 单信号失败不崩（catch null）。
- 置信度 = 有效权重和（缺失信号降置信）。
- 相似度双阈值分级（same/maybe/new）容忍浏览器升级漂移。
- 排序拼接保证信号顺序无关哈希稳定。
