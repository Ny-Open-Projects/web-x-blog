## SCN-356：长文档的导航体系（目录/书签/搜索定位/大纲联动）怎么实现？

**答**:
- 目录体系：标题树提取（H1~H6 层级树实时更新——编辑中目录跟随）、目录导航（点击跳转+当前位置高亮——scroll spy 联动）、目录折叠（层级折叠长目录）。
- 书签与锚点：用户书签（自定义位置标记+命名——书签列表跳转）、内部锚点（@引用跳转 SCN-346 复用）、外部深链（带段落位置的链接分享——SCN-291 深链复用）。
- 搜索定位：文档内搜索（查找替换：全部命中列表+逐个跳转+高亮）、搜索与目录联动（命中所在章节标记数量）。
- 协同与性能：目录状态协同（标题编辑进 CRDT——目录树自动同步）、超长文档性能（目录树增量更新——只更新变更标题、scroll spy 节流、视口渲染 SCN-345 复用）。

```javascript
// 目录树实时
outline.observe(() => renderTree(headings()));  // 标题进 CRDT
// scroll spy：可视标题 → 目录高亮
editor.viewport.onChange((range) =>
  highlightToc(headingsInRange(range)));      // 节流
// 书签：bookmark.add({ pos, label }) → 列表跳转
// 文内搜索：matches = findAll(q) → 列表 + 逐个 jump
//   + 高亮 + replaceAll（批量事务 SCN-344）。
// 深链：/doc/1?pos=anchorId → 定位 + 高亮闪烁。
```
