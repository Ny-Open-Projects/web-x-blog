## SCN-669：大屏多屏联动怎么实现？
**答**：
- 主从模型：主屏（操控台）产生视角/页面/下钻指令，从屏订阅执行；指令模型统一（{ op: 'flyTo'|'setPage'|'drill', payload, seq }）。
- 通道选择：同机房局域网 WS 广播（低延迟）；跨网走消息服务；指令带 seq 幂等去重，乱序丢弃。
- 一致性：从屏状态与指令流对账（每 30s 心跳上报当前 hash，与主屏比对不一致则全量同步快照）。
- 权限分离：从屏是纯渲染端（禁交互），主屏才可操作——避免双人操作冲突。
- 追问钩子：3D 相机指令怎么同步——同步「相机参数」而非「鼠标轨迹」；高频操作（拖拽）合并 100ms 发送，松手发终值。

```javascript
const master = {
  send(op, payload) {
    channel.publish('twin-cmd', { op, payload, seq: ++this.seq });
  },
  onCameraDrag(cam) {                              // 拖拽节流同步
    throttle(() => this.send('flyTo', camParams(cam)), 100);
  },
  onDragEnd(cam) { this.send('flyTo', camParams(cam), { final: true }); },
};
const slave = channel => {
  let lastSeq = 0;
  channel.subscribe('twin-cmd', ({ op, payload, seq }) => {
    if (seq <= lastSeq) return;                    // 乱序丢弃
    lastSeq = seq;
    execOp(op, payload);                           // flyTo/setPage/drill
  });
  setInterval(() => channel.publish('twin-state', { hash: sceneStateHash() }), 30_000);
};
```
