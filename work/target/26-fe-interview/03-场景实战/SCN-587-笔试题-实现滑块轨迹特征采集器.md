## SCN-587：手写滑块轨迹特征采集器

**需求与边界**：
- 输入：pointer 事件轨迹（x/y/t）；输出：特征对象 `{ duration, avgSpeed, speedStd, overShoot, points, valid }`。
- 边界：① 速度标准差区分匀速机器；② 过冲检测（超出目标后回修）；③ 轨迹点数 < 5 或时长 < 200ms 直接 invalid；④ 坐标归一化到 0~1。

**答**：
```javascript
function sliderFeatures(points, targetX, width) {
  if (points.length < 5) return { valid: false, reason: 'TOO_FEW_POINTS' };
  const dur = points.at(-1).t - points[0].t;
  if (dur < 200) return { valid: false, reason: 'TOO_FAST' };
  const norm = points.map(p => ({ x: p.x / width, y: p.y / width, t: p.t }));  // 归一化
  const speeds = norm.slice(1).map((p, i) => {
    const dx = p.x - norm[i].x, dy = p.y - norm[i].y;
    return Math.hypot(dx, dy) / Math.max(1, p.t - norm[i].t);  // 每段速度
  });
  const avg = speeds.reduce((s, v) => s + v, 0) / speeds.length;
  const std = Math.sqrt(speeds.reduce((s, v) => s + (v - avg) ** 2, 0) / speeds.length);
  // 过冲：最大 x 超过 targetX 后回落
  const maxX = Math.max(...norm.map(p => p.x));
  const overShoot = Math.max(0, maxX - targetX);
  const monotonic = norm.every((p, i) => i === 0 || p.x >= norm[i - 1].x);  // 无回修=机器特征
  return {
    valid: true, points: norm, duration: dur,
    avgSpeed: avg, speedStd: std,
    overShoot, monotonic,
    machineHint: std < 0.002 && monotonic && overShoot < 0.005,  // 初筛信号（决策在服务端）
  };
}
```

**评分点**:
- 最少点数/最短时长双重 invalid 兜底。
- 速度标准差 + 单调性 + 过冲三特征组合判机器。
- 坐标归一化（适配不同宽度）。
- 明确「初筛信号，决策在服务端」的意识。
