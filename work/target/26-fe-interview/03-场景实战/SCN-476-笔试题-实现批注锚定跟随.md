## SCN-476：手写批注锚定：相对锚跟随文本编辑、锚丢失降级、解决态流转

**需求与边界**：
- 输入：批注（锚区间）、文本编辑流；输出：批注渲染。
- 边界要求：① 锚用相对位置（编辑后自动跟随伸缩——SCN-223 同源）；② 锚区间收缩为 0（原文全删）→"锚丢失"态；③ 解决态→正文去高亮+边栏折叠、可重开；④ 批注数据进 CRDT（多端一致）。

**答**：
```javascript
class CommentAnchor {
  constructor(comments, ytext) {
    this.comments = comments;                  // CRDT Map
    ytext.observe(() => this.refresh());       // 文本变更重算
  }
  resolve(comment) {                           // 相对锚→绝对区间
    const start = absPos(comment.anchor.start);
    const end = absPos(comment.anchor.end);
    if (start == null || end == null)
      return { ...comment, lost: true,        // 锚丢失（原文已删）
        hint: '原文已删除' };
    if (start === end)
      return { ...comment, lost: true };      // 收缩为 0
    return { ...comment, start, end, lost: false };
  }
  resolveComment(id) {                         // 解决态流转
    const c = this.comments.get(id);
    c.status = c.status === 'open' ? 'resolved' : 'open';
    // resolved：正文去高亮+边栏折叠；重开恢复
  }
}
// CRDT 相对锚：插入/删除自动跟随（不存绝对偏移）；
// 批注 thread 多轮回复（comments → {thread: [...]}）；
// resolved 可重开（open/resolved 双态切换）。
```

**评分点**:
- 相对锚自动跟随（不存绝对偏移）——跟随正确性核心。
- 锚丢失双态检测（区间收缩/锚删除）+降级提示。
- 解决/重开双态流转与呈现联动。
- 批注进 CRDT（多端一致）。
