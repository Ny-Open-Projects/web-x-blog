## SCN-232：协作产品（文档/白板/会议）的成员在线状态怎么设计？

**答**:
- 状态机：active（有交互 5min 内）→ idle（5min 无交互）→ offline（连接断开/关闭）——交互事件驱动（键盘/鼠标/触摸重置 idle 计时），idle 不等于离线（开着页面没动）。
- 感知通道：awareness 心跳（10s 一次在线心跳，30s 超时判离线——SCN-223 协议复用），多标签页合并（同用户多端取最高活跃态），进入/离开事件（系统消息流"XX 进入了文档"可配置）。
- 呈现规范：头像堆栈（当前活跃成员头像+上限 N 个+计数）、状态色点（绿活跃/黄空闲/灰离线）、状态用途分离（活跃成员影响协作预期——"3 人正在编辑"，空闲成员只是存在感）。
- 隐私边界：精确位置不暴露（只显示"正在编辑第 3 节"级别的模糊信息可配置）、隐身模式（VIP 可隐身——awareness 不广播但可写）、企业审计需求与个人隐私的平衡（管理员可见性>成员可见性）。

```javascript
// 活跃检测：交互重置 idle
['keydown','pointerdown','wheel'].forEach(ev =>
  document.addEventListener(ev, () => resetIdle(), { passive: true }));
function resetIdle() {
  clearTimeout(idleTimer);
  awareness.setLocalStateField('presence',
    { status: 'active', user: me });
  idleTimer = setTimeout(() => {
    awareness.setLocalStateField('presence',
      { status: 'idle', user: me });
  }, 5 * 60e3);
}
// 心跳：awareness 自动 10s 心跳，30s 超时 → offline。
// 多端合并：presence 按 userId 聚合取 active > idle > offline。
```
