## SCN-387：客服机器人（独立解决场景的能力分层）怎么设计？

**答**:
- 能力分层（SCN-303 客服分层复用深化）：L1 问答（FAQ 检索回答）、L2 查询（订单/物流查询工具调用——AGT-303 只读自动）、L3 办理（退款/改址——写操作确认流：AGT-286 人机确认复用）、L4 复杂转人工。
- 机器人对话策略：多轮澄清（模糊问题澄清——AGT-431 复用）、上下文维持（任务簿 SCN-434：办理中的多步任务跟踪）、打断处理（用户换话题→上下文切换确认）、失败兜底（两次没解决→主动转人工+摘要——SCN-219 衔接）。
- 自助工具集成：会话内自助操作（查物流卡片/自助退款表单——SCN-281 卡片复用），自助完成率（机器人独立解决率——核心指标）、转人工原因分析（哪类问题机器人接不住——AGT-353 归因）。
- 体验边界：机器人身份透明（明确标识——SCN-219 复用）、等待体验（查询中进度态）、人工入口常驻（不困住用户）。

```javascript
async function botTurn(msg) {
  const intent = await classify(msg);
  if (intent.level === 'L3') {
    const ok = await confirmFlow(intent.action);   // 写操作确认
    if (!ok) return offerHuman();
    const r = await tools.exec(intent.action, {
      idempotencyKey: intent.id });
    return cardResult(r);                          // 卡片结果
  }
  if (failedTwice(intent)) return toHuman(withDigest);
  return answer(intent);
}
// 独立解决率：solvedByBot / total（北极星）
// 转人工归因：cluster(reasons) → 补能力 backlog。
```
