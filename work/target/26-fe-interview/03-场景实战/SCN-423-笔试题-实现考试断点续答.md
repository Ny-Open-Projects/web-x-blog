## SCN-423：手写断点续答：本地即时落盘、服务端快照、恢复合并与剩余时间

**需求与边界**：
- 输入：作答事件、恢复入口；输出：恢复后的完整作答状态。
- 边界要求：① 每次作答本地立即落盘（IndexedDB）+服务端增量；② 恢复时服务端快照与本地按时间戳合并；③ 剩余时间按服务端起止计算（本地时钟不可信）；④ 恢复后摘要确认（防止静默丢答案）。

**答**：
```javascript
class ExamPersistence {
  constructor(examId) { this.examId = examId; }
  async save(qid, value) {
    const rec = { examId: this.examId, qid, value,
      ts: Date.now(), hash: sha256(qid + value) };
    await idb.put('answers', rec);             // 本地即时落盘
    queueUpload(rec);                          // 服务端增量（失败重试）
  }
  async recover() {
    const [server, local] = await Promise.all([
      api.snapshot(this.examId),               // 服务端快照
      idb.all('answers', this.examId)]);       // 本地记录
    const merged = mergeByTs(server.answers ?? [], local);
    // 时间戳新者胜；hash 校验完整（篡改丢弃）
    const valid = merged.filter(a =>
      a.hash === sha256(a.qid + a.value));
    const remain = server.endTime - serverNow();   // 服务端时间
    return { answers: valid, remain,
      restoredCount: countAnswered(valid) };
  }
}
// 恢复流程：recover() → render(answers, remain)
//   → toast(`已恢复 ${restoredCount} 题`)      // 摘要确认
// 考试已结束（remain<=0）→ "以服务器最后快照为准"
// 定时快照：30s 全量上传 + 切题增量（双保险）。
```

**评分点**:
- 三层持久：本地 IDB 即时+服务端增量+定时快照。
- 合并策略明确：时间戳新者胜+hash 完整性过滤（篡改丢弃）。
- 剩余时间用服务端 endTime-serverNow()（本地时钟不可信）。
- 恢复摘要确认（restoredCount 提示）防静默丢答案。
