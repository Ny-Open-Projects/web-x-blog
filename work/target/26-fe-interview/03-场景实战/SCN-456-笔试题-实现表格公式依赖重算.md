## SCN-456：手写公式引擎：公式解析、依赖图维护、增量重算、循环检测

**需求与边界**：
- 输入：单元格公式（=SUM(A1:B2)）、单元格变更；输出：重算结果。
- 边界要求：① 公式 AST 解析（函数/区间/引用）；② 依赖图（变更传播链）；③ 增量重算（只算依赖链——非全表）；④ 循环引用检测报错。

**答**：
```javascript
class FormulaEngine {
  constructor() { this.graph = new Map(); }    // addr → Set<依赖addr>
  setFormula(addr, formula) {
    const refs = parseRefs(formula);           // AST 提取引用
    if (this.wouldCycle(addr, refs))
      throw new Error(`#CYCLE! ${addr}`);
    this.graph.set(addr, refs);                // 更新依赖图
    this.recalc(addr);
  }
  wouldCycle(addr, refs) {                     // 环检测（DFS）
    const visit = (n) => n === addr ||
      [...(this.graph.get(n) ?? [])].some(visit);
    return refs.some(visit);
  }
  onChange(addr) {
    const dirty = dependents(addr);            // 依赖链（拓扑序）
    worker.recalc(dirty);                      // Worker 重算
  }
  dependents(addr) {                           // 反向依赖遍历
    const out = [], seen = new Set([addr]);
    const walk = (a) => {
      for (const [cell, refs] of this.graph)
        if (refs.has(a) && !seen.has(cell)) {
          seen.add(cell); out.push(cell); walk(cell);
        }
    };
    walk(addr);
    return out;                                // 拓扑序重算
  }
}
// parseRefs：SUM(A1:B2) → [A1,A2,B1,B2]（区间展开）；
// Worker 重算（万级公式不卡 UI）；
// 错误呈现：#CYCLE!/#REF! 标注定位。
```

**评分点**:
- AST 提取引用（区间展开）+ 依赖图维护。
- wouldCycle 前置环检测（DFS）+ #CYCLE! 报错。
- dependents 反向遍历得拓扑序增量重算（非全表）。
- Worker 重算的性能意识。
