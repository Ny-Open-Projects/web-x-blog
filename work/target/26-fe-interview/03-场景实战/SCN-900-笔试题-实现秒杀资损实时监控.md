## SCN-900：手写资损实时监控

**需求与边界**：
- 需求：下单金额流实时监控——① 金额分布突变检测（某价位占比突增 = 价格展示错误嫌疑）；② 单价低于成本价的订单计数（直损）；③ 触发阈值自动建议熔断（值班确认执行）。
- 边界：① 分布基线用活动前 10 分钟建立；② 突变检测用卡方偏离或占比阈值；③ 全量步数据（支付流）不允许采样。

**答**：
```javascript
function lossMonitor({ chiThreshold = 50, lowPriceCount = 10 } = {}) {
  const buckets = new Map();                           // 价位桶 -> count
  let baseline = null;
  function establishBaseline(ms) {                     // 活动前 10 分钟建基线
    baseline = normalize(buckets); buckets.clear();
  }
  function onOrder(order) {                            // 全量支付流
    const bucket = priceBucket(order.amount);
    buckets.set(bucket, (buckets.get(bucket) || 0) + 1);
    if (order.amount < order.costPrice) {
      lowPriceHits++;
      if (lowPriceHits >= lowPriceCount)               // 直损：低于成本价订单
        return suggestCircuitBreaker('BELOW_COST', lowPriceHits);
    }
    if (baseline) {
      const current = normalize(buckets);
      const chi = chiSquare(baseline, current);
      if (chi > chiThreshold)                          // 分布突变：价格展示错误嫌疑
        suggestCircuitBreaker('DISTRIBUTION_SHIFT', { chi, topShift: biggestShift(baseline, current) });
    }
  }
  function suggestCircuitBreaker(reason, detail) {
    report({ type: 'LOSS_ALERT', reason, detail, level: 'P0' });
    return { suggest: 'SECKILL_BREAK', confirmedBy: 'oncall' };   // 值班确认执行
  }
  return { onOrder, establishBaseline };
}
```

**评分点**:
- 双检测：分布突变（卡方）+ 直损计数（低于成本价）。
- 基线活动前建立（对比基准可信）。
- 全量步不采样（资损数据必须完整）。
- 熔断建议由值班确认（自动化建议 + 人工执行，防误熔断）。
