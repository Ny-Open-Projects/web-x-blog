## SCN-432：手写撤销重做栈：Command 模式、连续操作合并、栈深度上限

**需求与边界**：
- 输入：编辑命令流（移动/改属性/增删节点）；输出：undo/redo 能力。
- 边界要求：① Command 可逆（undo 精确还原）；② 连续同类操作合并（连续拖动=一次撤销）；③ 栈深度上限（内存控制，丢弃最旧）；④ redo 遇新命令清空。

**答**：
```javascript
class UndoStack {
  constructor({ limit = 100, mergeMs = 500 }) {
    this.undoStack = []; this.redoStack = [];
    this.limit = limit; this.mergeMs = mergeMs;
    this.lastCmd = null;
  }
  dispatch(cmd) {                              // cmd: {apply, revert, mergeKey}
    const now = Date.now();
    const top = this.undoStack.at(-1);
    // 合并：同 mergeKey 且时间近 → 合并为一条
    if (top && top.mergeKey && top.mergeKey === cmd.mergeKey &&
        now - top.ts < this.mergeMs) {
      top.revert = cmd.revert;                 // 保留最初 revert
      top.ts = now;
    } else {
      this.undoStack.push({ ...cmd, ts: now,
        mergeKey: cmd.mergeKey });
      if (this.undoStack.length > this.limit)
        this.undoStack.shift();                // 上限丢弃最旧
    }
    this.redoStack = [];                       // 新命令清空 redo
    cmd.apply();
  }
  undo() {
    const cmd = this.undoStack.pop();
    if (!cmd) return;
    cmd.revert();
    this.redoStack.push(cmd);
  }
  redo() {
    const cmd = this.redoStack.pop();
    if (!cmd) return;
    cmd.apply();
    this.undoStack.push(cmd);
  }
}
// 示例：MoveCmd { mergeKey: 'move:node1',
//   apply: () => setPos(final), revert: () => setPos(orig) }
//   连续拖动 mergeKey 相同 → 合并为一次撤销。
// 深拷贝替代方案：快照式（schema clone）——大 schema 用 Command 省内存。
```

**评分点**:
- Command 双方法（apply/revert）精确可逆。
- mergeKey+时间窗合并连续同类操作（拖动体验关键）。
- 栈深度上限 shift 丢弃 + 新命令清空 redo 栈。
- 快照式与 Command 式的内存取舍意识。
