## SCN-1297：手写一个国际订单的税费明细行生成器

**答**：
- 需求：implement TaxLines(calc)。lines(items, country, mode) 生成订单税费明细行：VAT 行/DDU 关税预估行/免税行；每行 { label, amount, note }；合计校验（各行和 = 税总额）。
- 边界：mode vat-included 不再叠加关税行；items 空 tax 全零；金额负数（优惠分摊）按比例分摊；输出行序固定。
- 评分点：含税/价外模式；DDU 行；空 items；行序

```javascript
class TaxLines {
  constructor(calc) { this.calc = calc; }              // 1257 的税计算
  lines(items, country, mode) {
    const total = items.reduce((s, i) => s + i.price * i.qty, 0);
    if (!items.length) return [{ label: 'tax', amount: 0 }];
    if (mode === 'vat-included') {
      const vat = total - total / (1 + (VAT_RATE[country] ?? 0.2));
      return [{ label: 'VAT（含税价内）', amount: +vat.toFixed(2) }];
    }
    const duty = total * (DUTY_RATE[country] ?? 0);
    return [
      { label: '关税预估（DDU）', amount: +duty.toFixed(2),
        note: '以清关实际为准' },
      { label: '销售税', amount: +((total + duty) * (US_TAX[country] ?? 0)).toFixed(2) },
    ];
  }
}
const VAT_RATE = { DE: 0.19, JP: 0.10 };
const DUTY_RATE = { DE: 0, JP: 0 };
const US_TAX = { CA: 0.0725, NY: 0.04, DE: 0 };
```
