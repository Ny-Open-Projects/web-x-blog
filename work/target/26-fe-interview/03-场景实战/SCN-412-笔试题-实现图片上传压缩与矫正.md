## SCN-412：手写图片上传管线：压缩、长边限制、EXIF 方向矫正、格式降级

**需求与边界**：
- 输入：图片 File、配置 {maxSide, quality, maxBytes}；输出：处理后的 Blob。
- 边界要求：① EXIF 方向矫正（手机照片旋转问题）；② 长边超限等比缩放；③ 压缩循环（quality 递减直到 <maxBytes 或最低）；④ HEIC 等不支持格式降级（canvas 转 jpeg）；⑤ 小图不放大。

**答**：
```javascript
async function processImage(file, { maxSide = 4096,
  quality = 0.85, maxBytes = 2 * 1024 * 1024 } = {}) {
  // 1. EXIF 方向矫正（通过 createImageBitmap options 或手绘旋转）
  let bmp = await createImageBitmap(file,
    { imageOrientation: 'from-image' });       // 读 EXIF 方向
  // 2. 长边限制（只缩不放）
  let { width, height } = bmp;
  const long = Math.max(width, height);
  if (long > maxSide) {
    const k = maxSide / long;
    width = Math.round(width * k);
    height = Math.round(height * k);
  }
  // 3. 压缩循环：quality 递减至达标
  const canvas = new OffscreenCanvas(width, height);
  canvas.getContext('2d').drawImage(bmp, 0, 0, width, height);
  let q = quality, blob;
  do {
    blob = await canvas.convertToBlob({ type: 'image/jpeg',
      quality: q });
    q -= 0.1;
  } while (blob.size > maxBytes && q > 0.3);
  // 4. 兜底：仍超 → 缩尺寸再来一轮
  if (blob.size > maxBytes) {
    return processImage(await blobToFile(blob),
      { maxSide: maxSide * 0.8, quality, maxBytes });
  }
  return blob;                                 // { blob, width, height }
}
// 格式降级：HEIC 等 createImageBitmap 失败 →
//   尝试 fetch 解码失败 → 提示格式不支持或服务端转码。
// PNG 透明图：保 PNG（type 判断），不用 jpeg（丢透明）。
```

**评分点**:
- EXIF 方向矫正（imageOrientation from-image）——手机照片旋转的经典坑。
- 长边等比缩放且"只缩不放"（小图不放大）。
- 压缩循环双维度（quality 递减 → 尺寸递减）兜底。
- 格式细节意识：透明图保 PNG、不支持格式降级路径。
