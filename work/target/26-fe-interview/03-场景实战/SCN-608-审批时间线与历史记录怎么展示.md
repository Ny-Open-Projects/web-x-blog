## SCN-608：审批时间线怎么展示？
**答**：
- 事件模型：统一 auditEvent（节点/操作人/动作/意见/时间/附件），服务端事件流下发，前端排序渲染；系统事件（自动流转/超时升级）与人工事件用图标区分。
- 聚合规则：同节点同操作人的连续多次操作（提交→撤回→重新提交）合并为一组，组头显示最终状态，展开看全部——保审计完整性同时避免时间线爆炸。
- 关键锚点：流程的里程碑（提交/通过/归档）固定锚点高亮；驳回发生的节点红色标记并在图与时间线联动。
- 长流程分页：事件流游标分页，跳转锚点（定位某节点）直接拉取该节点前后事件。
- 追问钩子：时间线里意见修改（审批人先同意后改意见）怎么展示——保留修改记录（原意见划线+新意见），审计不允许覆盖历史。

```javascript
function mergeTimeline(events) {
  const sorted = [...events].sort((a, b) => a.ts - b.ts);
  const groups = [];
  for (const e of sorted) {
    const last = groups.at(-1);
    // 同节点+同操作人+连续人工事件 → 合并为一组
    if (last && last.nodeId === e.nodeId && last.operator === e.operator
        && !e.system && last.items.at(-1).ts > e.ts - 60_000) {
      last.items.push(e);
      last.finalStatus = e.action;               // 组头显示最终动作
    } else {
      groups.push({ nodeId: e.nodeId, operator: e.operator,
                    system: !!e.system, items: [e], finalStatus: e.action });
    }
  }
  return groups;
}
```
