## SCN-383：客服会话质检（规则+AI 预检+人工复核）怎么实现？

**答**:
- 质检维度：服务规范（开场白/禁语/回复时效——规则可查）、业务准确（解答正确性——AI 预判+人审）、情绪与合规（辱骂/敏感承诺——SCN-436 审核复用）、流程完整（该升级未升级/该登记未登记）。
- 质检架构：全量 AI 预检（每会话跑规则+AI 打分——AGT-260 评测复用），抽检策略（AI 低分强制人审+随机抽样——SCN-314 三级分流复用），复核工作台（质检员看会话回放+评分项勾选+扣分原因）。
- 结果应用：质检报告（个人/团队维度——SCN-374 看板复用）、申诉流程（客服申诉→复核）、改进闭环（高频扣分项→培训/知识库更新——AGT-353 badcase 流水线复用）。
- 实时与事后：实时质检（会话中违规即时提醒客服——事前干预）、事后质检（全量回溯——报告与考核）。

```javascript
// 全量 AI 预检
qc.onSessionEnd(async (session) => {
  const score = await qcAI.grade(session.transcript, {

  score.low ? toHumanReview(session, score)   // 低分人审
    : archive(score);                          // 高分归档
});
```
