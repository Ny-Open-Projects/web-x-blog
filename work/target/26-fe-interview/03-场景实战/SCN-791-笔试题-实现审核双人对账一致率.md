## SCN-791：手写审核交叉复审对账

**需求与边界**：
- 输入：双审结果对 `[{videoId, a: verdict, b: verdict, truth?}]`；输出一致率、分歧分类（标准模糊/个人偏差）、误判矩阵（truth 可用时）。
- 边界：① verdict 三值（PASS/REJECT/ESCALATE）；② ESCALATE 与任何判罚的分歧算「流程正常」不算不一致；③ truth 缺失时不计算误判只算一致率。

**答**：
```javascript
function crossCheck(pairs) {
  const valid = pairs.filter(p => p.a !== 'ESCALATE' && p.b !== 'ESCALATE');
  const agree = valid.filter(p => p.a === p.b);
  const disagree = valid.filter(p => p.a !== p.b);
  const confusion = { tp: 0, fp: 0, fn: 0, tn: 0 };
  for (const p of pairs) {
    if (!p.truth) continue;
    const key = { PASS: p.truth === 'PASS', REJECT: p.truth === 'REJECT' };
    // 以 A 审为对象统计（B 为对照）；truth 为金标准
    if (p.a === 'REJECT' && p.truth === 'REJECT') confusion.tp++;
    if (p.a === 'REJECT' && p.truth === 'PASS') confusion.fp++;     // 误杀
    if (p.a === 'PASS' && p.truth === 'REJECT') confusion.fn++;     // 漏杀
    if (p.a === 'PASS' && p.truth === 'PASS') confusion.tn++;
  }
  const byAuditor = groupBy(disagree, 'a');          // 分歧按审核员聚合（个人偏差信号）
  return {
    agreementRate: valid.length ? agree.length / valid.length : null,
    disagreements: disagree,
    biasHint: Object.entries(byAuditor).map(([aud, ds]) =>
      ({ aud, n: ds.length, skewed: ds.filter(d => d.a === 'REJECT').length / ds.length })), // 从严/从宽倾向
    confusion: pairs.some(p => p.truth) ? confusion : null,
  };
}
```

**评分点**:
- ESCALATE 不算分歧（流程语义正确）。
- 一致率分母剔除 ESCALATE 样本。
- 误判矩阵区分误杀（fp）与漏杀（fn）。
- 分歧按审核员聚合给出从严/从宽倾向（个人偏差可行动）。
