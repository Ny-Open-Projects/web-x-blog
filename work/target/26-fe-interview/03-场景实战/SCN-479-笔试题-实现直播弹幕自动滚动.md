## SCN-479：手写聊天流自动滚动：新消息自动滚底、用户上滑暂停、回到底部按钮

**需求与边界**：
- 输入：新消息事件、滚动位置；输出：滚动控制。
- 边界要求：① 距底部 <50px 视为"在底部"（自动滚）；② 用户上滑→暂停自动滚+显示回到底部按钮（含新消息数）；③ 点击回到底部→恢复自动滚；④ 虚拟列表兼容（锚定不跳——SCN-408 复用）。

**答**：
```javascript
class AutoScroller {
  constructor(container) {
    this.container = container;
    this.stick = true; this.unread = 0;
    container.onscroll = () => {
      const { scrollTop, scrollHeight, clientHeight } = container;
      const atBottom = scrollHeight - scrollTop - clientHeight < 50;
      if (!atBottom && this.stick) {           // 用户上滑
        this.stick = false; showJumpBtn();
      }
      if (atBottom && !this.stick) this.resume();
    };
  }
  onNewMessage(msg) {
    append(msg);                               // 始终追加（不丢）
    if (this.stick) this.scrollToBottom();
    else {                                     // 上滑中：计数
      this.unread++;
      updateJumpBtn(this.unread);              // "回到底部 (12)"
    }
  }
  resume() {
    this.stick = true; this.unread = 0;
    hideJumpBtn(); this.scrollToBottom();
  }
  scrollToBottom() {
    this.container.scrollTop = this.container.scrollHeight;
  }
}
// 虚拟列表兼容：append 用锚定（保持视口行不跳——SCN-408）。
// 洪峰：append 批量（SCN-216 聚合复用）。
```

**评分点**:
- 距底部阈值判定"在底部"（50px 容差）。
- 上滑暂停自动滚+未读计数按钮（不丢消息）。
- 回到底部恢复 stick+清计数。
- 虚拟列表锚定兼容（append 不跳）。
