## SCN-743：手写旅程漏斗归因

**需求与边界**：
- 输入：各步到达人数（会话维度）与每步历史基线掉落率；输出漏斗转化、步间掉落率、异常掉落步（超基线 1.5 倍）。
- 边界：① 掉落率 = 1 - (下一步人数/本步人数)；② 基线比较需样本量下限（<1000 标注）；③ 多步异常按掉落增量排序。

**答**：
```javascript
function funnelAttribution(steps) {                  // steps: [{key, users, baselineDrop}]
  const drops = steps.slice(0, -1).map((s, i) => {
    const next = steps[i + 1].users;
    const dropRate = 1 - next / s.users;
    const abnormal = dropRate > s.baselineDrop * 1.5;
    return { from: s.key, to: steps[i + 1].key,
      dropRate, baseline: s.baselineDrop,
      excess: dropRate - s.baselineDrop,             // 掉落增量（可排序）
      abnormal,
      lowSample: s.users < 1000 };
  });
  return {
    overall: steps.at(-1).users / steps[0].users,    // 端到端转化
    drops: drops.sort((a, b) => b.excess - a.excess),// 增量排序：最大元凶在前
    bottleneck: drops.find(d => d.abnormal && !d.lowSample)?.from ?? null,
  };
}
```

**评分点**:
- 步间掉落率与端到端转化双指标。
- 异常判据（1.5× 基线）+ 掉落增量排序。
- 小样本保护（<1000 不判 bottleneck）。
- bottleneck 返回第一步 key（可行动定位）。
