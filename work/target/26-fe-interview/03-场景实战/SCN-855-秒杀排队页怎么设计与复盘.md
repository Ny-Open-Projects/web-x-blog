## SCN-855：秒杀排队页怎么设计？
**答**：
- 排队本质：把瞬时洪峰削成可控速率——用户点击秒杀进入排队页（令牌桶服务端放行），排队页展示位置/预计等待，放行后跳购买页。
- 排队交互：进度条/排队位置动态展示（服务端推送），等待期间轮播商品/规则（把等待变成逛）；超长排队给「离开再回」的诚意提示（估算时间可信）。
- 退出与重入：排队态可退出（页面关闭保留排队资格 N 分钟），重入恢复位置（token 持有）。
- 复盘指标：排队进入率/放弃率/平均等待/放行速率 vs 系统容量匹配度——排队时长过长说明容量规划失误。
- 追问钩子：为什么排队页要展示「预计等待」——不确定性是放弃主因；可信的估算（宁可高估）让用户选择等待或离开，双方体验都好于黑盒。

```javascript
function QueuePage({ activityId }) {
  const { position, etaMs, token } = useQueue(activityId);   // WS 推送位置
  useKeepAlive({ token, ttlMs: 10 * 60_000 });               // 离开保留资格
  if (position === 0) return <Redirect to={`/buy?token=${token}`} />;
  return (
    <div>
      <Progress value={1 - position / totalUsers} />
      <p>前方还有 {position} 人，预计等待 {fmtEta(etaMs)}</p>
      <IdleCarousel items={relatedGoods} />                  {/* 等待变逛 */}
    </div>
  );
}
```
