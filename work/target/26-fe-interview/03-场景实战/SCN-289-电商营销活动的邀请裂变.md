## SCN-289：邀请助力裂变活动（砍价/拼团/助力）的前端实现？

**答**:
- 活动流程状态机：发起（生成活动单+分享物料）→ 分享传播（分享卡片：小程序码/链接，带活动参数）→ 助力（新用户进入→助力确认页→助力成功）→ 达成/超时失败——每态界面与可操作动作对应。
- 分享物料与回链：分享卡片配置（标题/图/参数），多渠道分享（微信/海报图保存），新用户识别（设备/账号维度——新客条件服务端判定），落地页参数解析（活动 id+发起人 id，防伪造签名校验）。
- 助力交互：助力进度条（还差 N 人）、助力人列表（头像墙）、自助催促（一键提醒）、失败兜底（超时退款/自动延长）。
- 防刷：前端辅助（行为采集：设备指纹/操作序列上报）、服务端风控为主（同设备/同 IP/虚拟号判定）、进度不实时精确（服务端定序，防脚本探测进度逻辑）。

```javascript
async function joinBargain(activityId, initiatorId, sig) {
  verifySig(sig);                            // 防伪造参数
  const r = await actApi.join({ activityId, initiatorId,
    device: fingerprint() });                // 行为采集
  if (r.ok) showHelpSuccess(r.progress);     // {cut, remain}
  else showBlock(r.reason);                  // 风控拦截提示
}
// 进度条：ws.on('bargain_progress', p => update(p))
// 超时：actApi.status → expired → 自动退款提示
// 分享：buildShareCard({ title, img, path: `${activityId}?inv=${me}&sig=${sig}` })
```
