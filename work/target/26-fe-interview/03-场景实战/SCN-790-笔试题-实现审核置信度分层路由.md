## SCN-790：手写置信度分层路由

**需求与边界**：
- 需求：按机审分数路由 DIRECT/HUMAN/OBSERVE；直放样本按比例混入盲测抽检（打标进质检队列，审核员不可见）；高危品类强制人审不直放。
- 边界：① 阈值按（品类，模型版本）查表；② 抽检用确定性采样（样本 id 哈希，保证可复现与可统计）；③ 观察区到期自动重审。

**答**：
```javascript
function routeReview(item, { rand = hashSample } = {}) {
  const th = THRESHOLDS[`${item.category}:${item.modelVersion}`];   // 阈值版本绑定
  if (!th) return { lane: 'HUMAN', reason: 'NO_THRESHOLD' };         // 无配置兜底人审
  if (HIGH_RISK_CATEGORIES.includes(item.category))                  // 高危强制人审
    return { lane: 'HUMAN', forced: true };
  if (item.score >= th.direct) {
    const sampled = rand(item.id) < th.sampleRate;                   // 确定性抽检
    return { lane: 'DIRECT', qc: sampled ? { type: 'BLIND', queue: 'qc' } : null };
  }
  if (item.score >= th.human) return { lane: 'HUMAN', marks: item.marks };
  return { lane: 'OBSERVE', recheckAt: Date.now() + 24 * 3600_000 }; // 到期重审
}
const hashSample = (id) => {                          // 确定性采样（可复现可统计）
  let h = 0;
  for (const c of String(id)) h = (h * 31 + c.charCodeAt(0)) >>> 0;
  return (h % 1000) / 1000;
};
```

**评分点**:
- 阈值按（品类×模型版本）查表 + 无配置兜底。
- 高危品类强制人审（安全红线）。
- 确定性抽检（可复现统计，比 Math.random 专业）。
- 观察区到期重审闭环。
