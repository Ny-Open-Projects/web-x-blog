## SCN-499：手写业务流程断点续跑：步骤幂等键、checkpoint 落库、恢复自检

**需求与边界**：
- 输入：业务流程步骤（如开票流程）、持久化存储；输出：可恢复执行器。
- 边界要求：① 步骤幂等键（重试去重）；② 预执行记录（崩溃时"可能已执行"识别）；③ checkpoint 每步落库；④ 恢复自检（关键状态校验）。

**答**：
```javascript
async function resumableFlow(flowId, steps, store) {
  const cp = await store.checkpoint(flowId) ??
    { next: 0, results: {}, ctx: {} };
  for (let i = cp.next; i < steps.length; i++) {
    const key = `${flowId}:${i}`;
    if (await store.isDone(key)) continue;     // 已完成跳过
    await store.markIntent(key);               // 预执行记录
    try {
      const r = await steps[i].run({
        idempotencyKey: key,                   // 服务端幂等
        ctx: cp.ctx,
        priorAttempt: (await store.intent(key))?.ts,  // 上次尝试
      });
      cp.results[i] = r;
      cp.ctx = steps[i].merge?.(cp.ctx, r) ?? cp.ctx;
      cp.next = i + 1;
      await store.checkpoint(flowId, cp);      // 每步 checkpoint
    } catch (e) {
      if (steps[i].critical) {
        await store.checkpoint(flowId, cp);    // 关键失败停（可恢复）
        throw e;
      }
      cp.results[i] = { skipped: true, error: e.message };
    }
  }
  await store.complete(flowId, cp.results);
  return cp.results;
}
// 自检：恢复后校验关键状态（如"订单是否已创建"），
//   priorAttempt 存在 → 先查服务端实际状态再决定重试/跳过。
```

**评分点**:
- 幂等键全链路传递 + 预执行记录（"可能已执行"识别）。
- checkpoint 每步落库（next/results/ctx 完整快照）。
- 关键/非关键步骤失败分级（critical 停可恢复，普通跳过）。
- 恢复自检（先查服务端实际状态——防重复执行）。
