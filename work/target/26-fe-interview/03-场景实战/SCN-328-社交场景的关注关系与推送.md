## SCN-328：关注关系（关注/互关/特别关注）变更的即时性与推送怎么设计？

**答**:
- 关系状态模型：关注状态机（无→已关注→互关，特别关注标记），状态即时生效（关注后对方主页/消息权限立即变化——互关解锁图片发送 SCN-324 联动），双向同步（对方端收到"新粉丝"通知+粉丝列表实时更新）。
- 推送链路：关注事件通知（被关注推送：实时信令+离线推送兜底）、特别关注推送强化（特别关注的新内容强推送——推送分级）、推送频率治理（防打扰：同人合并推送）。
- 内容联动：关注流即时性（关注后新内容进关注流——SCN-325 流合并联动）、特别关注优先级（关注流排序加权）。
- 边界处理：取关的涟漪（互关解除→消息权限回收提示）、关注上限（数量上限提示）、批量关注的风控（机器人关注检测——服务端）。

```javascript
async function follow(userId) {
  const r = await relApi.follow(userId,
    { idempotencyKey: `f:${me}:${userId}` });
  updateLocalRelation(r);                    // {mutual: true} 即时生效
  if (r.mutual) unlockMediaChat(userId);     // 解锁图视发送
}
```
