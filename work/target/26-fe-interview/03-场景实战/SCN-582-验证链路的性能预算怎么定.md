## SCN-582：验证链路性能预算怎么定？
**答**：
- 预算拆分：决策接口 800ms、无感通过总耗时 1.2s、滑块 chunk 加载 1s（首次）/0.3s（缓存）、验证器渲染 200ms、轨迹上传与判定 600ms——每段有 budget 并监控 P95。
- 最易超标环节：决策接口（风控计算重，需服务端缓存/预热）、人脸 SDK 体积（首载 2MB+，必须按需+预检后加载）、弱网下轨迹上传（压缩 + 降采样）。
- 弱网策略：信号上报压缩（字段名缩写/整型化）、轨迹采样率按网络自适应、验证过程允许「先提交后补信号」。
- 预算守护：CI 集成 bundle size 检查（SDK 超 15KB 失败）+ 线上 RUM 按段统计超预算告警。
- 追问钩子：验证在支付主路径上，怎么和支付页 TTI 兼容——验证器挂载延后到用户点击支付时才加载，决策接口在页面加载时预热。

```javascript
const VERIFY_BUDGET = {
  decision: 800, silent: 1200, chunkLoad: 1000, render: 200, judge: 600,
};
function withBudget(name, fn) {
  const t0 = performance.now();
  return fn().finally(() => {
    const cost = performance.now() - t0;
    if (cost > VERIFY_BUDGET[name]) report({ type: 'BUDGET_EXCEED', stage: name, cost });
  });
}
// 弱网：轨迹降采样（0.5x 采样率）+ 字段压缩
const sampleRate = netInfo.effectiveType === '4g' ? 1 : 0.5;
const trajectory = points.filter((_, i) => i % (2 / sampleRate) < 1);
```
