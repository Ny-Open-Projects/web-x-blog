## SCN-679：大屏首屏加载怎么优化？
**答**：
- 并行化：模型加载、数据首拉、图表库初始化三路并行（Promise.all），不互相等待；模型加载自带进度反馈到加载动画。
- 分级呈现：先出「园区外壳 + 核心指标面板」（最小可看），楼宇细节/次级图表后台继续加载渐进浮现——首屏可用不等全量。
- 资源预算：首屏模型 < 5MB（LOD0 低模）、首屏数据 < 200KB（聚合接口）；次级资源 idle 拉取。
- 缓存策略：模型用 Service Worker 缓存（大屏固定设备，二次启动秒开）；数据短 TTL 缓存 + WS 增量。
- 追问钩子：为什么大屏首屏体验不用 Lighthouse 标准衡量——大屏是固定设备长时运行，关键指标是「启动完成时间」与「稳态帧率」，用自定义 RUM。

```javascript
async function bootScreen() {
  showLoader('场景加载中…');
  const [model, initData] = await Promise.all([   // 并行
    loadModelLOD0(),                              // < 5MB 低模
    fetchInitData(),                              // 聚合首屏数据
  ]);
  renderShell(model, initData);                   // 最小可看：外壳+核心面板
  requestIdleCallback(() => {
    loadModelLOD1(); loadSecondaryPanels();       // 渐进增强
  });
}
// SW 缓存模型
self.addEventListener('fetch', (e) => {
  if (e.request.url.endsWith('.glb'))
    e.respondWith(caches.match(e.request).then(hit =>
      hit ?? fetch(e.request).then(res => {
        const clone = res.clone();
        caches.open('models').then(c => c.put(e.request, clone));
        return res;
      })));
});
```
