## SCN-335：外卖订单的骑手轨迹、ETA 动态更新与异常呈现怎么设计？

**答**:
- 配送阶段视图：商家接单→骑手取餐→配送中→已送达，每阶段卡片与地图内容切换（SCN-331 状态机复用），骑手轨迹平滑移动（SCN-265 滤波+动画）、路线绘制（骑行路线规划线）。
- ETA 动态更新：ETA 多因子（服务端融合路况/骑手状态/商家出餐——服务端权威），ETA 变化提示（延迟超阈值→主动告知+补偿券引导——预期管理）、ETA 展示区间（"30~40 分钟"比精确分更诚实）。
- 异常呈现：骑手联系（虚拟号 SCN-287 复用）、异常状态透明（商家出餐慢/骑手延误/恶劣天气——原因+新的预计时间，不说模糊的"稍晚"）、催单（有频率限制的催单按钮+效果反馈）。
- 弱网与后台：后台刷新策略（切后台轻量轮询保活状态——回来立即同步）、送达确认（拍照/确认码——送达凭证）。

```javascript
ws.on('delivery_state', (s) => stageView(s));  // 阶段切换
ws.on('rider_pos', (p) => {
  riderMarker.moveTo(filter.feed(p));         // 平滑动画
});
ws.on('eta_change', ({ eta, reason }) => {
  if (eta > prevEta + 10)                    // 延迟>10min
    banner(`${reason}，预计延迟至 ${eta} 分钟`,
      { coupon: 'delay_compensation' });      // 补偿引导
});
// 联系骑手：tel: 虚拟号；
// 催单：urgeBtn → 频控（1 次/10min）→ 效果反馈 toast。
```
