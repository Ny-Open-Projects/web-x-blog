## SCN-555：设备指纹采集怎么做？
**答**：
- 稳定信号：屏幕参数/时区/语言/平台/硬件并发数/内存分级/Canvas 与 WebGL 渲染差异哈希/AudioContext 指纹——变化周期长，是指纹主体。
- 易变信号：UA（可伪造但作为一致性校验）、字体列表（新版浏览器被收窄）、电池/网络 API（已被部分浏览器移除）——只作辅助。
- 稳定性分层：信号按稳定性加权合成指纹 ID；每次会话重算并与历史指纹做相似度匹配（而非严格相等），容忍浏览器升级带来的漂移。
- 合规与对抗：指纹用于风控需在隐私政策声明；新浏览器 API（如 WebGL 抗指纹）会削弱信号，方案要可插拔降级。
- 追问钩子：指纹为什么不能存 localStorage 当唯一标识——黑产清缓存即失效，且跨浏览器不共享，服务端聚类才是正解。

```javascript
async function fingerprint() {
  const signals = {
    screen: `${screen.width}x${screen.height}@${devicePixelRatio}`,
    tz: Intl.DateTimeFormat().resolvedOptions().timeZone,
    lang: navigator.languages.join(','),
    hw: `${navigator.hardwareConcurrency}:${navigator.deviceMemory ?? ''}`,
    canvas: canvasHash(),                       // 绘制文本+图形取像素哈希
    webgl: webglHash(),                         // 渲染器/扩展列表哈希
  };
  const fp = await sha256(JSON.stringify(signals));
  return { fp, signals, sim: await matchHistory(fp) };  // 与历史指纹相似度
}
```
