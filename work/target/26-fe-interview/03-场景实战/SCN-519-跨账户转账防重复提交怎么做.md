## SCN-519：转账防重复提交怎么做到无死角？
**答**：
- 三层防重：按钮级（提交即 disable + loading）、请求级（in-flight Map 按业务键去重）、业务级（客户端生成幂等键 idempotencyKey 随请求提交，服务端兜底）。
- 幂等键生命周期：进入确认页时生成 UUID，整个确认流程复用；失败重试复用同一 key（服务端返回上次结果），换金额才重新生成。
- 网络异常处理：超时/断网不自动重试 POST，展示「结果确认中」页并引导查询，防止双击重试造成双扣。
- 全局兜底：路由离开/页面卸载时提交中的请求不取消（keepalive），结果落地后通过推送/轮询对账刷新。
- 追问钩子：为什么不能只靠按钮 disable——刷新页、双端操作、请求重发都会绕过 UI 层。

```javascript
const inflight = new Map();
function submitOnce(bizKey, fn) {
  if (inflight.has(bizKey)) return inflight.get(bizKey);   // 请求级去重
  const p = fn().finally(() => inflight.delete(bizKey));
  inflight.set(bizKey, p);
  return p;
}
// 确认页生成幂等键，重试复用
const idemKey = useRef(crypto.randomUUID());
const pay = () => submitOnce('pay:' + idemKey.current, () =>
  api.post('/transfer', { ...form, idempotencyKey: idemKey.current, timeout: 10_000 })
);
```
