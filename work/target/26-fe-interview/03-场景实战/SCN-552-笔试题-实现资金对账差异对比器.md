## SCN-552：手写对账差异对比器

**需求与边界**：
- 输入：我方流水 mine[] 与渠道流水 theirs[]（均有 orderId + amountFen + status）。
- 要求：① 按 orderId 匹配，分类：长款（我有他无）/短款/金额不一致/状态不一致；② 输出按风险排序（金额不一致 > 短款 > 长款 > 状态）；③ 相同 orderId 多笔时按 (orderId, amountFen) 多重匹配。

**答**：
```javascript
function reconcile(mine, theirs) {
  const theirsIdx = new Map();                    // orderId -> [rows]（多重）
  for (const t of theirs)
    (theirsIdx.get(t.orderId) || theirsIdx.set(t.orderId, []).get(t.orderId)).push(t);
  const used = new Set(), result = { amount: [], short: [], long: [], status: [] };
  for (const m of mine) {
    const cand = (theirsIdx.get(m.orderId) || []).filter(t => !used.has(t.id));
    if (!cand.length) { result.long.push(m); continue; }        // 长款
    let best = cand.find(t => t.amountFen === m.amountFen);     // 金额一致优先
    if (best) {
      used.add(best.id);
      if (best.status !== m.status) result.status.push({ m, t: best }); // 状态不一致
      continue;
    }
    best = cand[0]; used.add(best.id);
    result.amount.push({ m, t: best, diff: m.amountFen - best.amountFen }); // 金额不一致
  }
  for (const t of theirs) if (!used.has(t.id)) result.short.push(t);        // 短款
  const risk = { amount: 0, short: 1, long: 2, status: 3 };                 // 风险权重
  return Object.entries(result)
    .sort(([a], [b]) => risk[a] - risk[b])
    .map(([kind, rows]) => ({
      kind, rows: rows.sort((x, y) =>
        Math.abs(getFen(y)) - Math.abs(getFen(x))),         // 组内按金额降序
    }));
}
const getFen = (r) => r.amountFen ?? r.diff ?? 0;
```

**评分点**:
- 多重匹配（同 orderId 多笔，used 集合防重复消费）。
- 四类差异完整覆盖，金额优先匹配再判状态不一致。
- 风险权重排序 + 组内金额降序（财务处理优先级）。
- 长款/短款方向定义正确（我有他无=长款）。
