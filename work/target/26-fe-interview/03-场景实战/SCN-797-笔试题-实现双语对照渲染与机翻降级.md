## SCN-797：手写双语对照渲染器

**需求与边界**：
- 需求：原文段落与机翻段落逐段对齐渲染；机翻失败（超时/限流）降级为原文 + 「翻译暂不可用」标注；机翻置信度低（<0.7）段落高亮提示「以原文为准」。
- 边界：① 段落对齐按段落索引（长度差异不破坏对齐）；② 翻译请求批量化（一次请求全文）；③ 失败重试一次后降级。

**答**：
```javascript
async function bilingualRender(text, targetLang) {
  const paragraphs = text.split(/\n+/);
  let translated;
  try {
    translated = await withRetry(() => mt(paragraphs, targetLang), 1);   // 批量 + 重试一次
  } catch {
    return paragraphs.map(p => ({ original: p, translated: null,
      degraded: true, note: '翻译暂不可用，以原文为准' }));             // 整体降级
  }
  return paragraphs.map((p, i) => ({
    original: p,
    translated: translated[i]?.text ?? null,           // 段落对齐
    lowConfidence: (translated[i]?.score ?? 1) < 0.7,  // 低置信提示
    note: lowConfidence ? '机翻置信度低，判罚以原文为准' : null,
  }));
}
const withRetry = (fn, times) => fn().catch(e =>
  times > 0 ? withRetry(fn, times - 1) : Promise.reject(e));
```

**评分点**:
- 段落索引对齐（不因长度差异错位）。
- 批量翻译一次请求 + 失败重试一次降级。
- 低置信段落显式提示（原文为准的合规意识）。
- 整体降级时原文完整可审（功能不中断）。
