## SCN-421：手写课件跟随：老师信令驱动、学生自由浏览超时回跟、双缓冲切换

**需求与边界**：
- 输入：老师翻页信令、学生交互事件；输出：页面切换控制。
- 边界要求：① 学生自由浏览期间暂缓跟随；② 10s 无操作自动回跟老师位置（含滞留期间的页变更补齐）；③ 双缓冲（新页渲染完成才切换——无半渲染）；④ 重复信令幂等。

**答**：
```javascript
class CourseFollow {
  constructor({ onSwitch, prefetch }) {
    this.teacherPage = 0; this.current = 0;
    this.freeBrowsing = false; this.lastUserAction = 0;
    this.onSwitch = onSwitch; this.prefetch = prefetch;
    this.buffered = null;
  }
  onTeacherPage(page) {                        // 老师信令（幂等）
    if (page === this.teacherPage) return;
    this.teacherPage = page;
    prefetch(page + 1);                        // 预载下一页
    if (this.freeBrowsing && Date.now() - this.lastUserAction < 10e3)
      return;                                  // 自由浏览暂缓
    this.switchTo(page);
  }
  onUserInteract() {                           // 学生自由浏览
    this.freeBrowsing = true;
    this.lastUserAction = Date.now();
    clearTimeout(this.backTimer);
    this.backTimer = setTimeout(() => this.backToTeacher(), 10e3);
  }
  backToTeacher() {                            // 超时回跟
    this.freeBrowsing = false;
    this.switchTo(this.teacherPage);           // 补齐滞留变更
  }
  async switchTo(page) {
    if (page === this.current) return;
    await this.bufferReady(page);              // 双缓冲：新页就绪
    const prev = this.current;
    this.current = page;
    this.onSwitch(page, prev);                 // 原子切换
  }
  bufferReady(page) {
    return pageCache.has(page) ? Promise.resolve()
      : renderToBuffer(page);                  // 渲染到缓冲层
  }
}
// 重复信令幂等：teacherPage 相同直接 return。
// 滞留补齐：回跟直接切 teacherPage（不重放历史信令）。
```

**评分点**:
- 自由浏览三态（暂缓/滞留/回跟）+10s 超时回跟直接切老师页（不重放）。
- 双缓冲（bufferReady 原子切换）防半渲染。
- 信令幂等 + 预载下一页。
- 用户交互重置回跟计时器。
