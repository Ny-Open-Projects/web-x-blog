## SCN-227：断网期间继续编辑文档，恢复联网后怎么合并？

**答**:
- 离线能力架构：CRDT 本地优先（所有编辑进本地 Y.Doc，离线不阻塞——本地操作立即可见），本地持久化（IndexedDB 存 doc update，离线不丢），联网后同步（provider 自动把离线期间的 update 包发给服务端，CRDT 自动合并）。
- 离线状态呈现：连接状态徽标（离线中/同步中/已同步）、离线期间编辑计数、其他人的陈旧光标清理（离线时他人光标隐藏或标注"最后状态"）。
- 上线合并的体验：合并是自动无感的（CRDT 收敛），但要处理语义冲突提示（SCN-224 的并发检测在合并后运行）；同步进度呈现（正在同步 X 条编辑）；合并失败兜底（update 包校验失败→文档完整性检查+从快照恢复路径）。
- 长期离线的边界：超过 N 天的离线（文档结构大改/权限变更）→ 合并前检查（文档版本代差过大提示"文档已大幅更新，建议逐段确认"）；权限被收回→离线内容转本地副本（保留但不自动合并）。

```javascript
// Yjs + IndexedDB 离线优先
const doc = new Y.Doc();
const idb = new IndexeddbPersistence('doc-123', doc);   // 离线持久化
const provider = new WebsocketProvider(url, 'doc-123', doc);
provider.on('status', ({ status }) => {
  ui.badge = status;                        // connected/disconnected
  if (status === 'connected') {
    // 离线 update 会被 provider 自动补发（Yjs update 队列）
    ui.syncing = true;
  }
});
doc.on('afterTransaction', () => {
  ui.offlineEdits = provider.synced ? 0 : countLocal(txn);
});
// 合并后语义冲突检测：detectConflicts(recentOps)
// → 行内提示（SCN-224）。
```
