## SCN-279：直播中控台（主播端推流+商品/优惠操控）怎么设计？

**答**:
- 推流管理：推流状态监控（码率/帧率/丢帧率实时显示）、网络自适应提示（上行不足建议降清晰度）、OBS/移动端 SDK 双形态（中控台 Web 版走服务端控制信令——主播不一定在 Web 端推流）。
- 商品操控：商品列表（讲解中/讲解顺序调整）、一键切换讲解（信令广播 SCN-273）、改价/发券（操作二次确认——误操作代价高）、库存监控（实时销量/剩余，售罄预警）。
- 互动操控：发起抽奖/红包（参数配置→信令）、置顶评论/禁言、公告（滚动条配置）。
- 可靠性：操作信令幂等+失败重试（商品切换失败重发——主播看不到观众端效果的风险）、双端预演（重要操作先小流量验证或预览）、断网缓冲（操作本地队列，恢复后补发——推流端网络波动时中控不失控）。

```javascript
// 商品切换（幂等+确认）
async function switchGoods(goodsId) {
  confirm(`切换讲解至：${goods.title}？`);
  const r = await withRetry(() =>
    controlApi.switchGoods({ room, goodsId,
      idempotencyKey: uid() }), 2);
  ui.currentGoods = goodsId;                 // 主播端即时反馈
}
// 推流监控：statsLoop → { bitrate, fps, droppedFrames }
//   droppedFrames > 5% → toast('上行不足，建议降低清晰度')
// 断网缓冲：offline → opsQueue.push(op)；online → flush。
```
