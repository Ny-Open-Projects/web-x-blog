## SCN-211：大促期间埋点量暴涨数十倍，上报风暴怎么治理？

**答**:
- 上报管道改造：批量合并（队列聚合，1s 或 20 条阈值 flush）、sendBeacon 兜底（页面卸载时不丢）、独立埋点域名（与业务接口隔离，洪峰不互相影响）——管道能力先扩，再谈采样。
- 分级采样策略：P0 事件（下单/支付转化）全量、P1（浏览/点击）大促期间降采样 50%、P2（曝光细粒度）采样 10%——分级白名单配置化，运营可按大促节奏调整。
- 端上节流：高频事件聚合（滚动曝光合并为一批）、重复去重（同 SKU 同位曝光 5 分钟内去重）、本地压缩（gzip/字段缩写）——端上先减量再上报。
- 洪峰自保护：队列上限（超过丢弃 P2 保 P0）、失败退避（埋点服务 5xx 时指数退避，不重试风暴）、降级开关（埋点服务故障时 P1/P2 全停，保业务接口）。

```javascript
const tracker = createTracker({
  flush: { maxBatch: 20, intervalMs: 1000 },
  sample: { p0: 1, p1: 0.5, p2: 0.1 },     // 大促采样配置
  queueCap: 500,                            // 上限：超丢 P2
});
function track(event) {
  const level = LEVELS[event.type] ?? 'p2';
  if (Math.random() > tracker.sample[level]) return;  // 采样
  if (tracker.queue.length >= tracker.queueCap
      && level === 'p2') return;            // 队列满丢 P2
  tracker.queue.push(compact(event));       // 字段压缩
}
setInterval(() => tracker.flush(), 1000);
window.addEventListener('pagehide',
  () => navigator.sendBeacon('/t', pack(tracker.queue)));
// 失败退避：连续 3 次 5xx → 停 P1/P2 上报 30s。
```
