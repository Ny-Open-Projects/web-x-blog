## SCN-603：审批流程图怎么可视化渲染？
**答**：
- 布局分层：审批流是 DAG（条件分支/并行/汇聚），用分层布局（dagre/ELK）自动排布，SVG 渲染节点与连线；节点状态（待处理/通过/驳回/跳过）用色区分。
- 数据驱动：前端只消费流程定义 JSON（nodes/edges + 实例状态），不解析业务规则；条件分支展示「走了哪条边」。
- 大图优化：超过阈值（如 200 节点）虚拟化或聚合折叠（同类型连续节点折叠为一条泳道）；缩放用 transform 而非重排。
- 交互：节点 hover 显示处理人与时间，点击看审批意见与附件；当前节点高亮脉冲。
- 追问钩子：流程定义与流程实例为什么要分开渲染——定义是模板（可复用），实例是运行态（带状态），混在一起无法做模板预览。

```javascript
import dagre from 'dagre';
function layoutFlow(def, instance) {           // def: {nodes, edges}; instance: {statusMap}
  const g = new dagre.graphlib.Graph();
  g.setGraph({ rankdir: 'LR', nodesep: 40, ranksep: 80 });
  g.setDefaultEdgeLabel(() => ({}));
  for (const n of def.nodes)
    g.setNode(n.id, { width: 180, height: 56,
      label: n.name,
      state: instance.statusMap[n.id] || 'pending' });   // 定义+实例合并
  for (const e of def.edges)
    g.setEdge(e.from, e.to, { label: e.condition, taken: instance.takenEdges?.includes(e.id) });
  dagre.layout(g);
  return g.nodes().map(id => {
    const { x, y, width, height, label, state } = g.node(id);
    return { id, x: x - width / 2, y: y - height / 2, label, state };  // dagre 给中心点
  });
}
```
