## SCN-527：交易确认页的防爬与动态水印怎么设计？
**答**：
- 动态水印：全屏覆盖层绘制工号/手机尾号 + 时间戳，pointer-events 穿透、定时刷新防删除（MutationObserver 监听水印节点被移除则重建并上报风控）。
- 防爬接口侧：确认页数据接口要求带页面加载时下发的 challenge token（与请求序号绑定），脚本直连接口拿不到有效 token。
- 防截图（App 内）：桥接 Native 禁截屏；Web 端检测到 DevTools/无头特征时降级展示（敏感字段不渲染）。
- 水印合规：水印不得遮挡关键信息影响可读性，透明度与密度可配置。
- 追问钩子：MutationObserver 防删水印的边界——对抗只是提高成本，证据链（服务端日志）才是最终威慑。

```javascript
function Watermark({ text }) {
  const ref = useRef(null);
  useEffect(() => {
    const draw = () => { /* canvas 平铺水印到固定定位层 */ ref.current.appendChild(makeLayer(text)); };
    draw();
    const mo = new MutationObserver(() => {
      if (!ref.current.hasChildNodes()) { draw(); report('WATERMARK_REMOVED'); } // 防删重建
      else if (ref.current.childElementCount > 1) ref.current.lastChild.remove();
    });
    mo.observe(ref.current, { childList: true });
    const iv = setInterval(draw, 60_000);          // 时间戳定期刷新
    return () => { mo.disconnect(); clearInterval(iv); };
  }, [text]);
  return <div ref={ref} className="wm-layer" style={{ pointerEvents: 'none' }} />;
}
```
