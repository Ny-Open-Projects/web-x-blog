## SCN-470：手写长会话内存巡检：内存水位检测、泄漏源定位、兜底重启

**需求与边界**：
- 输入：长时直播/会议会话；输出：内存守护。
- 边界要求：① 内存水位检测（performance.memory+趋势）；② 泄漏源定位（资源注册表对照——AGT-499 泄漏扫描复用）；③ 趋势告警（增长斜率异常）与兜底（低峰 reload——SCN-314 挂屏复用）；④ 巡检不卡主线程。

**答**：
```javascript
class MemoryGuard {
  constructor({ resources, running }) {
    this.resources = resources;               // 资源注册表
    this.running = running;
    this.samples = [];
    setInterval(() => this.check(), 60e3);    // 1min 巡检
  }
  check() {
    const mem = performance.memory?.usedJSHeapSize;
    if (!mem) return;
    this.samples.push({ mem, ts: Date.now() });
    const trend = slope(this.samples.slice(-10));   // 增长斜率
    if (trend > LEAK_RATE) {                   // 持续线性增长
      const suspects = this.resources.leakScan(this.running);
      // 未释放资源清单（定时器/监听/流）
      alert({ type: 'memory_leak', trend, suspects });
      if (mem > HARD_LIMIT) {
        flushCriticalState();                  // 状态落库
        location.reload();                     // 兜底重启（低峰）
      }
    }
  }
}
// 兜底：reload 前状态落库（断点恢复 SCN-229 复用）；
// 泄漏定位：资源注册表对照（任务结束未释放清单）；
// 低峰 reload：22:00-07:00 执行（值班场景惯例）。
```

**评分点**:
- 水位+趋势斜率检测（持续增长才告警，非单点）。
- 泄漏源定位（资源注册表对照清单）。
- 兜底 reload 前状态落库（恢复能力）。
- 巡检低频不卡主线程。
