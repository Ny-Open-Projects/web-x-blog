## SCN-283：收货地址簿（增删改/默认地址/地址校验）怎么设计？

**答**:
- 地址表单：四级联动选择器（省市区街道：级联数据懒加载+搜索式选择）、详细地址校验（智能解析：粘贴长文本自动拆分省市区+姓名电话——识别失败的降级手动）、地图选点辅助（定位到小区级别——配送范围校验）。
- 校验与纠错：地址规范性校验（缺省市区/关键字冲突提示）、超配送范围提示（地址解析后服务端判定）、敏感信息（地址簿本地缓存脱敏——手机号部分掩码展示）。
- 默认地址与快捷选择：默认地址置顶+结算页一键选、最近使用地址排序（按订单频率）、地址删除防护（默认地址删除需先设新默认）。
- 拆单收货：多包裹不同地址（一单多址——拆单场景按商品分组选地址）、地址簿数量上限（超限提示删除）。

// 智能解析
async function parsePasted(text) {
  const r = await addrApi.parse(text);       // 服务端 NLP 解析

}
// 级联懒加载：RegionCascader 按级 fetch 下级

//   超范围 toast('该区域暂不支持配送')
