## SCN-560：异地登录验证流程前端怎么做？
**答**：
- 流程态：正常登录 → 风控判定「新设备/异地」→ 进入增强验证页（已有设备扫码确认 / 手机验证码 / 邮箱确认多选）；用户选哪种由服务端给 allowedMethods。
- 扫码确认双向态：本机展示二维码等待确认，被确认端收到推送后展示「是否允许新设备 XX 登录」——两个端的 UI 与状态同步（长轮询/WS）都要做。
- 安全细节：确认二维码 2 分钟过期自动刷新；确认结果携带设备信息摘要（地点/机型），让用户能识别异常。
- 失败处理：验证失败次数限 3 次，之后锁定并引导申诉；登录页展示「为什么需要验证」教育文案减少客诉。
- 追问钩子：扫码确认的两端状态机是什么——PENDING → APPROVED/DENIED/EXPIRED，本机轮询状态 + 被扫端操作推送。

```javascript
function useCrossDeviceConfirm(sessionId) {
  const [status, setStatus] = useState('PENDING');
  useEffect(() => {
    const poll = setInterval(async () => {
      const { status: s, device } = await api.get(`/auth/cross/${sessionId}`);
      setStatus(s);
      if (s === 'APPROVED') { clearInterval(poll); login(device); }
      if (s === 'DENIED') { clearInterval(poll); toast('对方已拒绝本次登录'); }
    }, 2000);
    const expire = setTimeout(() => { clearInterval(poll); setStatus('EXPIRED'); }, 120_000);
    return () => { clearInterval(poll); clearTimeout(expire); };
  }, [sessionId]);
  const refreshQr = () => newSession();            // 过期重生成
}
```
