## SCN-355：在线表格/文档的打印（分页控制/页眉页脚/打印预览）怎么实现？

**答**:
- 打印适配层：打印样式分离（@media print 专用样式：隐藏交互元素/白底黑字/分页规则），表格分页（列分页（宽表横向拆页）+行分页（行跨页时重复表头——thead 重复）、冻结窗格打印处理（冻结列每页重复））。
- 分页控制：手动分页符（用户插入分页符——打印分页模型独立于屏幕渲染）、页眉页脚（每页页码/标题/日期）、缩放（缩放到一页宽——缩放比例计算）、打印区域选择（选区打印）。
- 打印预览：所见即所得预览（分页效果预渲染——分页计算引擎与实际打印一致），预览性能（分页计算 Worker 化）。
- 实现路径：浏览器打印（window.print + print CSS——简单场景）vs 服务端渲染 PDF（高保真需求：服务端排版引擎生成 PDF——SCN-255 导出复用，保真度最高）。

```javascript
// 打印分页模型
function paginate(sheet, { pageW, pageH, repeatHeader }) {
  const colPages = splitCols(sheet.cols, pageW);   // 列拆页
  const rowPages = splitRows(sheet.rows, pageH);
  return cross(colPages, rowPages).map(p => ({
    cols: p[0], rows: p[1],
    header: repeatHeader ? sheet.header : null,    // 每页表头
    footer: { page: i, total },
  }));
}
// CSS 路线：@media print { .toolbar{display:none} }
//   tr { break-inside: avoid } thead { display: table-header-group }
// 高保真：serverRenderPDF(sheet, printModel)。
// 手动分页符：userBreaks 插入分页计算。
```
