## SCN-1286：手写一个国际物流渠道选择器

**答**：
- 需求：implement ChannelSelector(channels)。pick(pkg, country, prefs) 过滤：禁运（国家品类）/重量限制/时效偏好（prefs.fast 最快优先）；输出 { channel, fee, etaDays } 与备选；全不满足返回 null + 原因。
- 边界：channels 空 null；prefs 缺省 cheapest；fee 缺失按 0；禁运优先于其他校验。
- 评分点：禁运过滤；重量限制；偏好排序；原因返回

```javascript
class ChannelSelector {
  constructor(channels) { this.channels = channels; }
  pick(pkg, country, prefs = {}) {
    const ok = this.channels.filter(c => {
      if (BANNED[country]?.some(b => pkg.categories.includes(b))) return false;
      if (c.maxWeight && pkg.weight > c.maxWeight) return false;
      return true;
    });
    if (!ok.length) return { channel: null, reason: '无可用渠道（禁运或超限）' };
    const sorted = ok.sort((a, b) => prefs.fast
      ? (a.etaDays[country] ?? 99) - (b.etaDays[country] ?? 99)
      : a.fee - b.fee);
    return { channel: sorted[0], fee: sorted[0].fee,
      etaDays: sorted[0].etaDays?.[country] ?? null,
      alternatives: sorted.slice(1, 3) };
  }
}
const BANNED = { DE: ['电池'] };
```
