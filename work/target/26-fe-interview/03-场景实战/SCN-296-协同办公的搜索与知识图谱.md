## SCN-296：办公套件统一搜索（文档/消息/任务/日历跨应用）怎么设计？

**答**:
- 统一索引架构：服务端统一搜索服务（各应用数据源接入索引管线：文档全文/消息/任务标题——权限裁剪在索引侧：只索引用户可见内容），前端聚合展示（分组 tab：文档/消息/任务/人员）。
- 前端体验：即时搜索（防抖+缓存+取消，SCN-285 搜索联想同源）、搜索语法（高级过滤：from:张三 in:文档）、历史与热门（搜索历史本地保存）。
- 权限与安全：搜索结果权限过滤（无权文档不出现在结果——服务端过滤不可前端隐藏了事）、搜索审计（敏感内容搜索行为记录——企业合规）、摘录权限（有文档权限才能看内容摘录，否则只有标题）。
- 跳转深度：结果直达上下文（消息搜索→跳到会话并定位消息；文档→定位到片段高亮）——深链协议统一（type:id+position）。

```javascript
async function unifiedSearch(q) {
  const r = await searchApi.query(q, { scope: currentTab });
  // 服务端已按用户权限过滤
  return r.groups;   // {docs, msgs, tasks, people}
}
// 分组 tab 渲染 + 各类型跳转：
// msgs → `/chat/${convId}?msgId=${id}`（定位到消息）
// docs → `/doc/${id}?hl=${pos}`（片段高亮）
// 权限：摘录 = index 按可见性裁剪，
//   无权 → 只显示标题与存在性。
```
