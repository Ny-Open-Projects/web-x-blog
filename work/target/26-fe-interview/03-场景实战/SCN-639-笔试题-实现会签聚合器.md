## SCN-639：手写会签聚合器

**需求与边界**：
- 模式：ALL（全同意）、ANY（一人同意）、MAJORITY（比例≥阈值）、VETO（一票否决，其他可同意）；缺席（超时未签）按配置算弃权/否决。
- 输出：节点状态 + 未签人列表 + 决议说明；所有模式必须处理「无人签署」边界。

**答**：
```javascript
function aggregateSign(signers, mode, { ratio = 0.5, absentAs = 'abstain' } = {}) {
  const signed = signers.filter(s => s.opinion);     // 有明确意见
  const absent = signers.filter(s => !s.opinion);
  const agree = signed.filter(s => s.opinion === 'agree').length;
  const reject = signed.filter(s => s.opinion === 'reject').length;
  const validN = signers.length;                     // 总人数
  const effAgree = absentAs === 'abstain' ? agree : (absentAs === 'reject' ? reject += absent.length, agree : agree);
  switch (mode) {
    case 'ALL':                                      // 全签：任何否决即失败
      if (reject > 0) return { status: 'REJECTED', detail: `${reject} 人否决` };
      if (agree === validN) return { status: 'PASSED', detail: '全员同意' };
      return { status: 'PENDING', pending: absent.map(s => s.userId) };
    case 'ANY':
      return agree > 0 ? { status: 'PASSED', winner: signed.find(s => s.opinion === 'agree').userId }
        : reject === validN ? { status: 'REJECTED' }
        : { status: 'PENDING', pending: absent.map(s => s.userId) };
    case 'MAJORITY': {
      if (validN === 0) return { status: 'REJECTED', detail: '无审批人' };  // 边界
      if (agree / validN >= ratio) return { status: 'PASSED', detail: `${agree}/${validN} 达到 ${(ratio*100)}%` };
      if ((validN - agree) / validN > 1 - ratio && reject + (absentAs === 'reject' ? absent.length : 0) > 0)
        return { status: 'REJECTED' };               // 数学上已不可能通过，提前终止
      return { status: 'PENDING' };
    }
    case 'VETO':                                     // 一票否决：无否决且有人同意即过
      if (reject > 0) return { status: 'REJECTED', vetoBy: signed.find(s => s.opinion === 'reject').userId };
      return agree > 0 ? { status: 'PASSED' } : { status: 'PENDING' };
    default:
      throw new Error(`未知会签模式 ${mode}`);
  }
}
```

**评分点**:
- 四种模式语义正确（ALL/ANY/MAJORITY/VETO）。
- 缺席人处理参数化（abstain/reject）。
- MAJORITY 提前终止判定（不可能通过即 REJECT）。
- 空审批人/无人签署边界处理。
