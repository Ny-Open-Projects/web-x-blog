## SCN-857：秒杀按钮防连点怎么设计？
**答**：
- 按钮状态机：NOT_STARTED → COUNTDOWN → OPEN(可点) → SUBMITTING → SUCCESS/FAILED → SOLD_OUT；每态只允许迁移动作，非法点击静默（不弹错误）。
- 防连点三层：视觉（点击即 loading 态）、逻辑（状态机 SUBMITTING 拒绝）、网络（幂等键，SCN-519）——三层缺一不可。
- 失败重试策略：网络类失败给重试按钮（人工触发），业务失败（售罄）直接终态；不做自动重试（秒杀失败重试 = 雪上加霜）。
- 触感反馈：点击有即时反馈（100ms 内按钮态变化或震动），否则用户会再点。
- 追问钩子：为什么失败不自动重试——秒杀场景重试风暴会打垮本已脆弱的系统；且「抢不到」的失败重试也无意义，只有网络类异常才值得人工重试。

```javascript
const BTN_FSM = {
  NOT_STARTED: ['COUNTDOWN'], COUNTDOWN: ['OPEN'],
  OPEN: ['SUBMITTING'], SUBMITTING: ['SUCCESS', 'FAILED', 'SOLD_OUT'],
  FAILED: ['OPEN'], SOLD_OUT: [], SUCCESS: [],
};
function onSeckillClick() {
  if (state !== 'OPEN') return;                        // 非法态静默
  setState('SUBMITTING');                              // 即时反馈 < 100ms
  navigator.vibrate?.(10);
  submitOnce('seckill', () =>                          // 幂等去重
    api.post('/seckill', { skuId, token, idempotencyKey }, { timeout: 5000 })
  ).then(res => setState(res.stock === 0 ? 'SOLD_OUT' : 'SUCCESS'))
   .catch(e => setState(e.type === 'NETWORK' ? 'FAILED' : 'SOLD_OUT'));
}
```
