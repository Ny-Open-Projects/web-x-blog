## SCN-447：手写分组讨论：自动均分、手动拖拽调整、倒计时回收

**需求与边界**：
- 输入：成员列表、组数、时长；输出：分组编排与回收控制。
- 边界要求：① 自动均分（人数尽量均衡）；② 手动拖拽调整（互斥锁防并发编辑冲突）；③ 倒计时同步（服务器时钟）+到期预警回收；④ 被分组者确认跳转。

**答**：
```javascript
function autoAssign(members, n) {              // 均分
  const groups = Array.from({ length: n }, () => []);
  members.forEach((m, i) => groups[i % n].push(m));
  return groups;
}
function rebalance(groups, from, to, member) { // 手动调整
  if (groupLocks.has(to)) return toast('正在被调整');
  groupLocks.add(to);
  groups[from] = groups[from].filter(m => m !== member);
  groups[to].push(member);
  broadcast({ groups });                       // 全员同步
  groupLocks.delete(to);
}
// 倒计时：serverClock 同步 → 剩余 1min 预警
//   → 到期 confirm 延长 or auto join(main)。
// 确认跳转：ws.on('assigned', ({room}) =>
//   confirm(`进入分组${room}?`) ? switchRoom(room) : stay())
// 拒绝者留在主会（信令记录）。
```

**评分点**:
- 均分算法（轮转分配）+ 手动调整带互斥锁（并发编辑冲突）。
- 服务器时钟倒计时 + 到期预警与自动回收。
- 被分组者确认跳转（拒绝留主会）。
- 分组结果全员广播同步。
