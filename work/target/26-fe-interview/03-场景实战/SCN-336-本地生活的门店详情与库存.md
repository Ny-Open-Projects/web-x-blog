## SCN-336：门店详情页（商品库存/营业状态/门店切换）怎么设计？

**答**:
- 门店信息层：营业状态（营业中/已打烊/休市——打烊态可预点单：次日配送）、配送信息（起送价/配送费/预计送达——按定位动态计算）、门店动态（公告/临时歇业）。
- 商品库存呈现：售罄置灰+到货提醒（订阅）、少货提示（仅剩 N 份）、规格售罄联动（SCN-008 SKU 联动复用）、库存实时性（下单前最终校验 SCN-205 复用）。
- 多门店切换：附近门店切换器（距离排序 SCN-266 联动——切换门店购物车跨店处理：购物车按门店分组）、切换确认（换店清空购物车提示）。
- 性能与体验：门店页预载（列表点击预载 SCN-210）、商品分组锚点导航（左侧分类+右侧商品锚点联动）、门店收藏与到店提醒。

```javascript
function StorePage({ storeId }) {
  const s = useStore(storeId);               // 预载命中
  return <>
    <Header open={s.open} notice={s.notice}
      delivery={{ min: s.minOrder, fee: s.fee(locate), eta: s.eta }} />
    <GoodsList groups={s.groups}
      onStockChange={markSoldOut}            // 仅剩N/售罄
      anchorNav />                            {/* 分类锚点联动 */}
    <StoreSwitcher near={nearStores}         // 距离排序
      onSwitch={(ns) => confirmCartClear(ns)} />
  </>;
}
// 打烊预点：s.open === false && s.preOrder → banner('可预点明日')
// 库存：ws.on('stock', m => patchGoods(m))。
```
