## SCN-444：手写实时字幕：ASR 增量修正渲染、双行翻译、说话人归属

**需求与边界**：
- 输入：字幕事件流（partial/final/翻译）；输出：字幕渲染。
- 边界要求：① partial 增量修正（同段更新不闪烁）；② final 定格滚动；③ 双行（原文+译文——译文晚于原文的错位容忍）；④ 说话人头像绑定；⑤ 字幕配置（字号/位置）。

**答**：
```javascript
class SubtitleRenderer {
  constructor({ style }) { this.style = style; this.current = null; }
  onPartial(seg) {                             // 增量修正（同段）
    if (this.current?.segId !== seg.segId) {
      this.current = { segId: seg.segId, text: seg.text };
    } else this.current.text = seg.text;       // 原地更新不闪烁
    this.paint();
  }
  onFinal(seg) {
    this.current = null;
    this.history.push(seg);                    // final 进滚动历史
    this.paint();
  }
  onTranslation(seg) {                         // 双行翻译
    const orig = this.current?.segId === seg.segId
      ? this.current : this.history.at(-1);
    orig.trans = seg.text;                     // 译文挂原段（错位容忍）
    this.paint();
  }
  paint() {
    const seg = this.current ?? this.history.at(-1);
    if (!seg) return this.clear();
    render({ speaker: avatarOf(seg.uid),      // 说话人头像
      text: seg.text, trans: seg.trans,
      style: this.style });                    // 字号/位置可配
  }
}
// 增量修正：partial 同 segId 原地更新（ASR 修正机制）；
// 译文晚于原文：挂到最新段（错位容忍呈现）。
```

**评分点**:
- partial 同段原地更新（不闪烁）与 final 滚动定格的区分。
- 双行翻译挂最新段（译文延迟的错位容忍）。
- 说话人头像绑定（voice print/uid 映射）。
- 字幕样式可配置（无障碍价值）。
