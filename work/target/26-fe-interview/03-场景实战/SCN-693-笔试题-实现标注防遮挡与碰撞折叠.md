## SCN-693：手写标注碰撞折叠

**需求与边界**：
- 需求：标注投影到屏幕后有矩形包围盒；重叠时按优先级（告警 > 焦点 > 普通）保留，低优先级折叠到聚合点（显示 +N）；视口外标注隐藏。
- 边界：① 投影在相机后（z > 1）剔除；② 聚合点本身也要防重叠（递归一层即可）；③ 每帧 O(n²) 检测在 n > 500 时降频。

**答**：
```javascript
function resolveLabels(labels, viewport) {           // labels: [{x,y,w,h,level,id,el}]
  const visible = [];
  const clusters = new Map();                        // 被折叠的标注按格聚类
  const sorted = labels
    .filter(l => l.z < 1 && l.x > -l.w && l.x < viewport.w && l.y > -l.h && l.y < viewport.h)
    .sort((a, b) => LEVEL[b.level] - LEVEL[a.level]);  // 高优先级先占位
  const placed = [];
  for (const l of sorted) {
    const box = { x: l.x, y: l.y, w: l.w, h: l.h };
    const hit = placed.find(p => intersect(p, box));
    if (!hit) { placed.push(box); visible.push(l); }
    else {
      const cellKey = `${Math.floor(l.x / 100)},${Math.floor(l.y / 100)}`;   // 100px 网格聚类
      const c = clusters.get(cellKey) ?? { x: l.x, y: l.y, items: [], el: null };
      c.items.push(l); clusters.set(cellKey, c);
    }
  }
  // 聚合点渲染（折叠一层）
  for (const c of clusters.values()) placeAggregate(c);
  return { visible, aggregated: [...clusters.values()] };
}
const LEVEL = { critical: 4, focus: 3, normal: 1 };
const intersect = (a, b) => a.x < b.x + b.w && a.x + a.w > b.x && a.y < b.y + b.h && a.y + a.h > b.y;
```

**评分点**:
- 优先级排序贪心占位（高优先级保留）。
- 相机后剔除与视口过滤。
- 网格聚类折叠 + 聚合点显示 +N。
- O(n²) 降频意识（n 大时分帧检测）。
