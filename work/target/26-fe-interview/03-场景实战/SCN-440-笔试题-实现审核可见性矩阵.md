## SCN-440：手写内容可见性矩阵：审核态×观众关系决定可见性与呈现

**需求与边界**：
- 输入：内容状态（审核中/限流/下架）、观众（作者/粉丝/路人）；输出：可见性与呈现方式。
- 边界要求：① 矩阵由服务端下发（策略可调前端不硬编码）；② 作者端状态透明（原因+申诉入口）；③ 观众端下架内容占位；④ 引用失效处理（转发已下架内容）。

**答**：
```javascript
// 服务端下发矩阵（策略可调）
const MATRIX = {
  reviewing: { author: 'review_badge',
    follower: fanFirst ? 'normal' : 'hidden', public: 'hidden' },
  limited: { author: 'limited_badge', follower: 'normal',
    public: 'normal_no_rec' },
  removed: { author: 'removed_reason', follower: 'gone',
    public: 'gone' },
};
function renderPost(post, viewer) {
  const rel = viewer.id === post.authorId ? 'author'
    : viewer.follows ? 'follower' : 'public';
  const mode = MATRIX[post.status]?.[rel];
  switch (mode) {
    case 'hidden': return null;               // 不渲染
    case 'gone': return <GoneCard note="内容已删除" />;
    case 'review_badge': return <Post {...post}
      badge="审核中" appeal={<AppealBtn id={post.id} />} />;
    case 'limited_badge': return <Post {...post}
      badge="限流：建议优化封面标题" />;
    case 'removed_reason': return <Removed reason={post.reason}
      appeal={<AppealBtn id={post.id} />} />;
    default: return <Post {...post} />;
  }
}
// 申诉：appealApi.create(postId) → 进度跟踪（待受理/复审/结果）。
// 引用失效：repost → removed → GoneCard 占位（SCN-217 同源）。
```

**评分点**:
- 矩阵服务端下发（策略可调，前端不硬编码）。
- 作者端状态透明（原因+申诉入口）；观众端 gone 占位。
- 关系分档（author/follower/public）取值正确。
- 引用失效联动（转发已下架内容占位）。
