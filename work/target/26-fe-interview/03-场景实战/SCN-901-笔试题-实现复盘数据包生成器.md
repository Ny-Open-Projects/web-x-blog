## SCN-901：手写复盘数据包生成器

**需求与边界**：
- 需求：聚合活动数据生成复盘包：业务（漏斗/GMV）、技术（事故/P95）、资金（对账差异/资损）、用户（客诉聚类）；改进项校验（owner/期限/验证指标齐全才收录）。
- 边界：① 数据缺失标注（不静默留空）；② 事故时间线按事实排序（不带归因）；③ 输出一页版（结论+Top3）+ 明细版。

**答**：
```javascript
async function reviewPack(activity, { window } = {}) {
  const [funnel, perf, recon, complaints, incidents] = await Promise.all([
    funnelStats(activity), perfSummary(activity, window),
    reconciliation(activity), clusterComplaints(activity), incidentTimeline(activity),
  ]);
  const missing = [['funnel', funnel], ['perf', perf], ['recon', recon], ['complaints', complaints]]
    .filter(([k, v]) => v == null).map(([k]) => k);    // 缺失显式标注
  const improvements = collectImprovements(incidents).filter(i =>
    i.owner && i.due && i.verifyMetric
      ? true : (rejected.push(i), false));             // 不可验证改进项拒绝收录
  return {
    headline: {
      achieved: funnel.conversion >= activity.target,
      incidents: incidents.length,
      topRisk: recon.diffs[0] ?? null,
    },
    timeline: incidents.sort((a, b) => a.ts - b.ts),   // 事实排序，无归因
    improvements, rejected,
    missing,                                           // 数据缺失标注
    onePager: true,
  };
}
```

**评分点**:
- 五问数据聚合完整且并行拉取。
- 改进项质量门禁（owner/due/verify 齐全，不合格进 rejected）。
- 时间线事实排序无归因（无责纪律）。
- 数据缺失显式标注（复盘数据可信度）。
