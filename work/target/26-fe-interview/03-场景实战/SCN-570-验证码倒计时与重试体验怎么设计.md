## SCN-570：验证失败重试与超时体验怎么设计？
**答**：
- 重试友好：答错不惩罚（可无限重试但服务端记账），给具体提示（「滑块未对齐」vs「轨迹异常，请手动拖动」）；连续失败 3 次自动换一种验证方式或降低难度。
- 超时提前预警：剩 10 秒提示 + 可一键续期（不重做验证，延长当前 challenge）；直接失效且不解释是最大流失点。
- 中途恢复：验证进行中切后台回来，进度保留（滑块位置、已输入位数）；页面刷新后 challenge 未过期可继续。
- 网络失败区分：加载失败（重试按钮）与判定失败（原因提示）分开，不让网络抖动表现为「验证错误」。
- 追问钩子：续期会不会被黑产利用无限续——续期次数与总时长有限制，且续期需带原 challenge 签名。

```javascript
function challengeTimer(seconds, { onWarn, onExpire }) {
  let left = seconds, warned = false;
  const t = setInterval(() => {
    left--;
    if (left === 10 && !warned) { warned = true; onWarn(); }   // 提前预警
    if (left <= 0) { clearInterval(t); onExpire(); }
  }, 1000);
  return {
    renew: async () => {                          // 续期（服务端校验原 challenge）
      const { extra } = await api.post('/risk/renew', { challengeId, renewals: ++renewCount });
      if (renewCount <= 2) left += extra;         // 最多续 2 次
      else onExpire();
    },
    get left() { return left; },
    stop: () => clearInterval(t),
  };
}
```
