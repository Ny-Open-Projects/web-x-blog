## SCN-477：手写增量重算：依赖反向索引、变更影响面计算、局部刷新

**需求与边界**：
- 输入：数据变更流、依赖注册表；输出：受影响集合与刷新计划。
- 边界要求：① 反向索引（数据 key → 依赖它的视图/计算单元）；② 影响面计算（变更 key 匹配）；③ 去重合并（同批变更合并一次刷新）；④ 刷新计划可观测（saved 统计）。

**答**：
```javascript
class IncrementalRecalc {
  constructor() {
    this.deps = new Map();                     // dataKey → Set<consumer>
    this.batch = new Set(); this.scheduled = false;
  }
  register(consumer, dataKeys) {               // 注册依赖
    for (const k of dataKeys)
      this.deps.set(k, (this.deps.get(k) ?? new Set()).add(consumer));
  }
  onDataChanged(keys) {
    keys.forEach(k => this.batch.add(k));
    if (!this.scheduled) {                     // 批合并：一帧一次
      this.scheduled = true;
      requestAnimationFrame(() => this.flush());
    }
  }
  flush() {
    this.scheduled = false;
    const consumers = new Set();
    for (const k of this.batch)
      for (const c of this.deps.get(k) ?? []) consumers.add(c);
    const all = this.deps.size;                // 全量规模
    consumers.forEach(c => c.recalc());
    this.batch.clear();
    audit({ affected: consumers.size,
      saved: all - consumers.size });          // 节省统计
  }
}
// 用途：公式链（SCN-456）/透视（SCN-353）/答案增量（SCN-477 前文）
// 通用化：任何"数据→派生"关系的增量更新。
```

**评分点**:
- 反向索引（dataKey→consumers）结构正确。
- 变更批合并（rAF 一帧一次）防高频变更风暴。
- 影响面计算+节省统计（可观测收益）。
- 通用化意识（公式/透视/图表统一模式）。
