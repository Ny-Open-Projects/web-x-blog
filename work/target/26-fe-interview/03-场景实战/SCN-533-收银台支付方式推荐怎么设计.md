## SCN-533：收银台支付方式怎么设计与推荐？
**答**：
- 服务端编排：可用支付方式（含可用性/额度/手续费/优惠）由收银台接口下发渲染清单，前端不本地枚举渠道——渠道上下线、限额策略随时变化。
- 排序即产品：默认选中与排序由服务端策略（成功率×优惠金额×用户历史）下发，前端展示「已为你优选」及优惠角标；用户手动切换则尊重选择并在会话内记忆。
- 可用性降级：渠道标记 SLOW/DISABLED 时置灰并给原因（「当前繁忙，预计等待 2 分钟」）；主渠道故障自动把备用渠道提到默认。
- 金额联动：选择分期/组合支付时实时重算金额拆分，任何一项不可用回退到单渠道。
- 追问钩子：收银台轮询策略失败重试怎么防重复支付——与 SCN-519 幂等键同源。

```javascript
function PayMethodList({ order }) {
  const { methods, recommended } = usePayMethods(order.id); // 服务端编排
  const [selected, setSelected] = useState(recommended);
  return methods.map(m => (
    <Row key={m.channel}
      disabled={m.state !== 'OK'}
      reason={m.state === 'DISABLED' ? m.reason : null}
      badge={m.discount ? `省${fenToYuan(m.discount)}` : null}
      selected={selected === m.channel}
      onClick={() => setSelected(m.channel)} />
  ));
}
```
