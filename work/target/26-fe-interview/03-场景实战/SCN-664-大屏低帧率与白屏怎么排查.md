## SCN-664：大屏线上问题排查怎么搭？
**答**：
- 内建诊断面板：值班用「隐藏快捷键呼出」的诊断层——实时帧率/GPU 内存/WS 状态/事件缓冲长度/最近错误，不用远程连接现场机器。
- 内存泄漏排查：大屏 7×24 运行必须防泄漏——监听器/定时器生命周期、three.js 资源 dispose（geometry/material/texture）、快照对比（Heap Snapshot 每 6h 自动采一次 diff）。
- 白屏恢复：watchdog（主线程心跳检测 + rAF 停滞检测）超时自动 reload 页面并上报；reload 次数异常告警（防止 reload 循环）。
- 远程支持：诊断快照（FPS 曲线/错误日志/资源占用）一键导出发回，替代现场摄像头看屏幕。
- 追问钩子：为什么不能只靠 reload 兜底——reload 丢失当前下钻状态且掩盖根因；watchdog 必须 + 上报 + 根因归档。

```javascript
function watchdog() {
  let lastBeat = performance.now();
  requestAnimationFrame(function beat() {
    lastBeat = performance.now();
    requestAnimationFrame(beat);
  });
  setInterval(() => {
    if (performance.now() - lastBeat > 10_000) {   // rAF 停滞 10s
      report({ type: 'WATCHDOG_RELOAD', lastBeat });
      if (reloadCount++ < 3) location.reload();    // 限 3 次防循环
      else report({ type: 'RELOAD_LOOP', reloadCount });
    }
  }, 10_000);
  // 内存巡检
  setInterval(() => {
    const mem = performance.memory;
    if (mem && mem.usedJSHeapSize > 1.5e9) report({ type: 'HEAP_HIGH', ...pick(mem) });
  }, 300_000);
}
```
