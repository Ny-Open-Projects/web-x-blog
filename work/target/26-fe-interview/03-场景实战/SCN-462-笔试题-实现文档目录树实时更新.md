## SCN-462：手写文档目录树：标题层级提取、协同实时更新、scrollspy 高亮

**需求与边界**：
- 输入：文档内容变更、滚动事件；输出：目录树与高亮。
- 边界要求：① H1~H6 层级树提取；② 协同编辑下实时更新（标题变更→目录 diff 更新）；③ scrollspy 高亮当前章节（节流）；④ 目录点击跳转（锚点定位）。

**答**：
```javascript
class Outline {
  constructor(doc) {
    this.tree = extractTree(doc.text());
    doc.observe(() => this.refresh());        // 协同实时更新
  }
  extractTree(text) {                          // 标题→层级树
    const items = [];
    for (const line of text.split('\n')) {
      const m = line.match(/^(#{1,6})\s+(.*)/);
      if (m) items.push({ level: m[1].length,
        title: m[2], line: lineOffset(text, line) });
    }
    return nest(items);                        // level 嵌套成树
  }
  refresh() {                                  // diff 更新（非全量）
    const next = this.extractTree(doc.text());
    render(diffTree(this.tree, next));        // 只更新变更节点
    this.tree = next;
  }
  spy(scrollTop) {                             // 节流高亮
    throttle(() => {
      const cur = lastItemBefore(this.tree.flat(), scrollTop);
      highlightToc(cur);                       // 当前章节高亮
    }, 200);
  }
  goto(item) { editor.scrollTo(item.line); }   // 锚点跳转
}
// 标题也进 CRDT → 多人编辑目录自动同步（SCN-222 复用）。
```

**评分点**:
- 层级树提取（level 嵌套）+ 行偏移锚点（跳转定位）。
- 协同实时更新用 diffTree 增量（非全量重渲）。
- scrollspy 节流高亮（200ms）。
- 目录进 CRDT（多人一致）。
