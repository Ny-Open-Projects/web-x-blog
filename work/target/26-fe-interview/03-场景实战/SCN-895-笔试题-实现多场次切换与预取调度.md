## SCN-895：手写多场次调度

**需求与边界**：
- 需求：多场秒杀按时间轴展示（未开始/进行中/已结束）；切换场次只换数据不重建骨架；两场间隙（上一场结束到下一场开始）预取下一场数据。
- 边界：① 场次状态由统一时钟驱动（SCN-888）；② 预取在主线程 idle 时执行；③ 切换进行中场次需要确认（放弃当前抢购上下文）。

**答**：
```javascript
function createSessionScheduler(sessions, ticker) {
  let current = sessions.find(s => s.state === 'LIVE')?.id ?? sessions[0].id;
  const states = new Map(sessions.map(s => [s.id, s.state]));
  ticker.subscribe((now) => {
    for (const s of sessions) {
      const st = s.endTs > now ? (s.startTs <= now ? 'LIVE' : 'UPCOMING') : 'ENDED';
      if (states.get(s.id) !== st) {
        states.set(s.id, st);
        if (s.id === current) renderSessionState(s, st);
        if (st === 'ENDED' && nextOf(s)) schedulePrefetch(nextOf(s));   // 结束即预取下一场
      }
    }
  });
  async function switchTo(id) {
    if (states.get(current) === 'LIVE' && hasActiveContext(current))
      await confirmLeave(current);                     // 放弃抢购上下文需确认
    current = id;
    const data = prefetched.get(id) ?? await fetchSession(id);   // 预取命中零等待
    renderSessionData(data, { reuseSkeleton: true }); // 骨架复用只换数据
  }
  function schedulePrefetch(s) { requestIdleCallback(() => prefetchSession(s)); }
  return { switchTo, get current() { return current; } };
}
```

**评分点**:
- 统一时钟驱动状态机（UPCOMING/LIVE/ENDED）。
- 结束即触发下一场 idle 预取（间隙利用）。
- 切换进行中场次确认（防误放弃抢购）。
- 骨架复用只换数据（不整页重建）。
