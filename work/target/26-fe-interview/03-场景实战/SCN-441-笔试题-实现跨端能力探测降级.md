## SCN-441：手写跨端能力探测：功能×端支持矩阵、探测缓存、降级链

**需求与边界**：
- 输入：运行环境（浏览器/小程序/TV）；输出：能力集与降级方案。
- 边界要求：① 能力探测（特性检测而非 UA 硬编码）；② 功能×端支持矩阵配置化；③ 每功能降级链（不可用→降级→提示）；④ 探测结果缓存（会话级）。

**答**：
```javascript
const MATRIX = {                               // 功能×端支持矩阵
  screenShare: { web: true, mp: false, tv: false,
    fallback: { mp: '主播端共享', tv: '提示扫码观看' } },
  virtualBg: { web: true, mp: false, tv: false,
    fallback: { mp: 'disabled', tv: 'disabled' } },
  chat: { web: true, mp: true, tv: true },
};
function detectPlatform() {
  if (typeof wx !== 'undefined') return 'mp';
  if (navigator.userAgent.includes('TV')) return 'tv';
  return 'web';
}
function capability(feature) {
  const p = this.platform ??= detectPlatform();  // 会话缓存
  const m = MATRIX[feature];
  const supported = m?.[p];
  return { supported,
    fallback: supported ? null : m?.fallback?.[p]
      ?? `${feature} 当前端不可用` };
}
// 特性检测优先：supportsSimulcast() 等运行时探测
//   （同一端不同浏览器能力不同）——UA 只做平台分流。
// 使用：const c = capability('screenShare');
//   c.supported ? show() : toast(c.fallback)。
// 矩阵文档化给产品（功能×端支持可视化）。
```

**评分点**:
- 特性检测优先于 UA 硬编码（同端浏览器差异）+ UA 仅平台分流。
- 矩阵配置化含 fallback（每功能降级方案）。
- 会话级探测缓存。
- 矩阵文档化给产品（跨端能力可见性）。
