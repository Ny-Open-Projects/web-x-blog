## SCN-1277：手写一个时区感知的倒计时组件逻辑

**答**：
- 需求：implement Countdown(targetUtc, tz)。remaining() 返回 { d, h, m, s }（按 UTC 差值计算，展示无关时区）；display() 按 tz 格式化目标时间；isLive() 判断活动是否开始；tick(cb) 每秒回调（自动清理）。
- 边界：target 已过返回全 0；DST 切换不影响（全 UTC 计算）；tz 缺省用户本地。
- 评分点：UTC 差值；时区展示；已过处理；tick 清理

```javascript
class Countdown {
  constructor(targetUtc, tz) {
    this.target = targetUtc; this.tz = tz; this.timer = null;
  }
  remaining(now = Date.now()) {
    const diff = Math.max(0, this.target - now);
    return { d: Math.floor(diff / 86400_000),
      h: Math.floor(diff / 3600_000) % 24,
      m: Math.floor(diff / 60_000) % 60,
      s: Math.floor(diff / 1000) % 60, total: diff };
  }
  display() {
    return new Intl.DateTimeFormat(undefined, { timeZone: this.tz,
      dateStyle: 'full', timeStyle: 'short' }).format(new Date(this.target));
  }
  isLive(now = Date.now()) { return now >= this.target; }
  tick(cb) {
    this.timer = setInterval(() => cb(this.remaining()), 1000);
    return () => clearInterval(this.timer);
  }
}
```
