## SCN-493：手写多租户隔离：租户 id 强制注入、缓存 key 隔离、交叉测试

**需求与边界**：
- 输入：请求（含租户身份）、存储访问；输出：隔离校验。
- 边界要求：① 所有存储访问强制带 tenantId（默认拒绝——AGT-386 复用）；② 缓存 key 含租户因子；③ 交叉测试（A 写 B 查的自动化测试）；④ 隔离违规即最高级告警。

**答**：
```javascript
function tenantGuard(ctx) {                    // 统一数据访问层
  const { tenantId, userId } = ctx;
  return {
    async get(key) {
      return store.get(tKey(tenantId, key));   // 强制租户前缀
    },
    async set(key, val) {
      await store.set(tKey(tenantId, key), val);
    },
    cacheKey(key, extra) {                     // 缓存 key 隔离
      return hash([tenantId, key, ...extra]);
    },
  };
}
const tKey = (t, k) => `t:${t}:${k}`;          // 租户前缀
// 交叉测试（回归必跑）：
async function isolationTest() {
  await a.set('doc:1', secretOfA);             // A 租户写
  const b = await b.get('doc:1');              // B 租户查
  if (b === secretOfA) fatal('ISOLATION_BREACH');  // 泄露即致命
}
// 告警：isolation breach → immediate page（最高级）。
// 默认拒绝：无 tenantId 的存储访问直接抛错。
```

**评分点**:
- 租户前缀强制注入（统一数据访问层收口）。
- 缓存 key 含租户因子（缓存越权防护）。
- 交叉测试自动化（A 写 B 查回归必跑）。
- 隔离违规最高级告警（fatal page）。
