## SCN-448：手写问卷跳题引擎：选项路由、显隐条件、环检测与答案清理

**需求与边界**：
- 输入：问卷 schema（题目+logic）、用户答案；输出：下一题/显隐状态。
- 边界要求：① 跳题规则匹配（选 A→Q5）；② 显隐条件（前题含某答案）；③ 环检测（设计器校验）；④ 跳过的题答案清理（提交不含死路答案）。

**答**：
```javascript
function nextQuestion(questions, logic, cur, answers, visible) {
  const rules = logic.filter(l => l.when === cur);
  for (const r of rules) {
    if (matchCondition(r.cond, answers[cur])) {
      if (r.goto === cur) throw new Error('自环');
      return r.goto;                          // 跳题
    }
  }
  const idx = visible.indexOf(cur);           // 默认顺序下一题
  return visible[idx + 1] ?? null;
}
function refreshVisible(questions, logic, answers) {
  const visible = questions.filter(q => q.id === 'q1' ||
    (logic.find(l => l.show === q.id)
      ? evalCond(logic.find(l => l.show === q.id).if, answers)
      : !logic.some(l => l.goto === q.id && l.condHit)));
  return visible;
}
function cleanAnswers(answers, visible) {      // 死路答案清理
  return Object.fromEntries(Object.entries(answers)
    .filter(([k]) => visible.includes(k)));
}
// 环检测（设计器）：跳题图 DFS——SCN-407 环检测复用；
// 提交：cleanAnswers 后校验必答全在 visible 中。
```

**评分点**:
- 跳题匹配+默认顺序回退；自环检测。
- 显隐条件求值与可见序列维护。
- 死路答案清理（提交不含不可见题答案）。
- 环检测在设计器侧前置（DFS 复用）。
