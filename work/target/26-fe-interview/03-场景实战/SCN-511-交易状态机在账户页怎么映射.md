## SCN-511：交易状态机在账户页怎么映射？
**答**：
- 状态收敛：服务端下发原始状态（INIT/PROCESSING/SUCCESS/FAIL/CLOSED/REFUND），前端用映射表渲染文案、颜色、可用动作，不散落 if-else。
- 中间态兜底：PROCESSING 超过阈值（如 5 分钟）不显示失败，转为「处理时间较长，结果以最终通知为准」+ 手动刷新入口，避免误判引发重复交易。
- 终态确认：SUCCESS/FAIL 由服务端通知/轮询确认后才改 UI；FAIL 给出原因码映射的文案与下一步动作（重试/换卡/联系客服）。
- 非法迁移防御：组件层动作表（如 CLOSED 不允许取消），防止用户在旧页面对已终态交易发起操作。
- 追问钩子：轮询与推送并存时以谁为准——以单调递增的 version/ts 判重，旧状态不得覆盖新状态。

```javascript
const TX_VIEW = {
  INIT:      { text: '已创建',  color: 'gray',  actions: ['cancel'] },
  PROCESSING:{ text: '处理中',  color: 'blue',  actions: [] },
  SUCCESS:   { text: '成功',    color: 'green', actions: ['receipt', 'refund'] },
  FAIL:      { text: '失败',    color: 'red',   actions: ['retry'] },
  CLOSED:    { text: '已关闭',  color: 'gray',  actions: [] },
};
function applyTx(tx, prev) {
  if (prev && tx.version <= prev.version) return prev;   // 乱序/旧推送丢弃
  const view = TX_VIEW[tx.status] || TX_VIEW.PROCESSING;  // 未知态按处理中兜底
  return { ...tx, view };
}
```
