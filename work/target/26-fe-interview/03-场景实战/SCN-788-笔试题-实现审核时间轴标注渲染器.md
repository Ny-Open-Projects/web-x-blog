## SCN-788：手写审核时间轴标注渲染器

**需求与边界**：
- 输入：marks `[{startTs, endTs, type, confidence}]` + 视频时长 + 时间轴像素宽度；输出渲染条带（重叠合并）与点击命中。
- 边界：① 重叠或紧邻（<0.5s）的同类标注合并渲染；② 条带最小可见宽度 2px；③ 点击/拖动命中返回 mark（优先置信度高的）；④ 不同 type 用色条分层。

**答**：
```javascript
function renderMarks(marks, duration, width) {
  const px = (ts) => ts / duration * width;
  // 同类合并：排序后重叠或 <0.5s 间隙合并
  const byType = groupBy(marks, 'type');
  const bands = Object.entries(byType).map(([type, list]) => {
    const sorted = list.sort((a, b) => a.startTs - b.startTs);
    const merged = [];
    for (const m of sorted) {
      const last = merged.at(-1);
      if (last && m.startTs - last.endTs < 0.5) last.endTs = Math.max(last.endTs, m.endTs);
      else merged.push({ ...m });
    }
    return { type, merged };
  });
  const rects = [];
  for (const { type, merged } of bands)
    for (const m of merged) {
      const x = px(m.startTs), w = Math.max(2, px(m.endTs - m.startTs));   // 最小 2px
      rects.push({ x, w, y: typeRow(type), type, mark: m });
    }
  return {
    rects,
    hitTest: (mx) => rects.filter(r => mx >= r.x && mx <= r.x + r.w)
      .sort((a, b) => b.mark.confidence - a.mark.confidence)[0]?.mark ?? null,  // 高置信优先
  };
}
const typeRow = (type) => MARK_TYPE_ORDER.indexOf(type);   // 类型分层行
```

**评分点**:
- 同类重叠/近邻合并（0.5s 阈值），减少碎片渲染。
- 最小 2px 可见宽 + 分类型分层。
- 命中按置信度优先（重叠时取最相关）。
- px 映射与时长解耦（宽度变化自适应）。
