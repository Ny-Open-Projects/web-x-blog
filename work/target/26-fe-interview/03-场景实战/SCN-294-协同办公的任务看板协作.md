## SCN-294：敏捷看板多人同时拖拽卡片（SCN 已有基础上的协同深化）怎么处理并发？

**答**:
- 并发拖拽冲突：两人同时拖同一张卡→服务端定序（乐观锁 version 或 CRDT），败者的拖拽回弹+提示"已被 XX 移动"；同一列两人排序→序列操作合并（move 操作 CRDT 化：insert index 冲突由 CRDT 定序）。
- 实时同步：他人拖拽的实时预览（卡片跟随移动动画——拖拽中的 live position 广播，SCN-231 白板同源）、列计数实时更新（每列数量徽标）。
- 字段并发：两人同时编辑卡片详情（描述/负责人）→ 字段级 last-write+冲突提示（关键字段如负责人变更通知双方）、看板与详情页双端状态同步。
- 撤销与历史：个人撤销栈（只撤自己的操作——操作带 author，undo 按 author 过滤）、操作历史流（卡片时间线：谁何时移动/编辑）。

```javascript
// 拖拽 CRDT 化：卡片顺序存为 CRDT 序列
function onDrop(cardId, toCol, index) {
  const cur = cardLocks.get(cardId);
  if (cur && cur !== me) return bounceBack(cardId);  // 他人持有
  seqList.move(cardId, toCol, index);          // CRDT move
}
seqList.observe((ev) => renderColumns());      // 全员同步
ws.on('card_drag', ({ cardId, pos }) => {      // 拖拽预览
  floatCard(cardId, pos);                      // 跟随动画
});
// 详情字段：lastWrite + 双方通知：
//   onConflict(field) → toast(`字段被 ${other} 修改`)
// 个人撤销：undoStack.filter(op => op.author === me)。
```
