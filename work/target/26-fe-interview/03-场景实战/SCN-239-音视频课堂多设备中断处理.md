## SCN-239：上课中来电话/切后台/插拔耳机，音视频怎么优雅处理？

**答**:
- 中断事件体系：监听系统中断（来电：移动端音频中断事件/WebRTC 连接状态变化）、切后台（visibilitychange+隐藏时采集策略）、设备切换（devicechange 事件：耳机插拔/摄像头切换）——每类中断有标准处理动作。
- 来电处理：音频采集中断→推流暂停（不结束课程状态）、通话结束→自动恢复采集与推流（重协商）、中断期间老师端看到"网络波动"状态（学生没有消失）。
- 设备切换：耳机插拔→track 替换（replaceTrack 无感切换，不重发布），前后摄切换同理；权限被系统回收（iOS 切后台麦克风）→恢复时重新请求。
- 恢复校验：中断恢复后做电平检测（3s 采集电平，静音假活检测）、频繁中断降级提示（建议换网络/设备）、中断期间课程状态保持（不上台不退出）。

```javascript
// 设备切换：无感 replaceTrack
navigator.mediaDevices.addEventListener('devicechange',
  async () => {
    const devs = await navigator.mediaDevices.enumerateDevices();
    const mic = devs.find(d => d.kind === 'audioinput'
      && d.deviceId !== currentMic);
    if (mic) {
      const s = await navigator.mediaDevices
        .getUserMedia({ audio: true });
      await sender.replaceTrack(s.getAudioTracks()[0]); // 无感替换
      currentMic = mic.deviceId;
    }
  });
rtc.on('connectionstate', (s) => {
  if (s === 'interrupted') showBadge('网络波动');
  if (s === 'failed') autoRecover();          // 重协商恢复
});
// 恢复校验：3s 采集电平检测，
// 无电平 → 提示"麦克风未采集，请检查"。
```
