## SCN-878：倒计时渲染怎么优化？
**答**：
- 统一驱动：全局一个 rAF 或 setInterval（1s）时钟，多个倒计时订阅（一个 ticker 驱动 N 个显示），不每组件一个 timer。
- 只更新变化的 DOM：倒计时数字 diff（秒变化才写 DOM），数字翻牌动画只在进位时播（CSS）。
- 页面不可见暂停：后台 Tab 停止渲染（visibilitychange），回前台立即校准（基于 deadline 绝对时间无漂移）。
- 长列表倒计时：列表每行倒计时用同 ticker + 虚拟滚动配合，视口外不更新。
- 追问钩子：为什么用 deadline 绝对时间而非累减——累减在 Tab 休眠/setInterval 漂移下必然越走越慢；绝对时间计算天然抗漂移，这是所有倒计时的标准答案。

```javascript
const ticker = (() => {                                // 全局单例时钟
  const subs = new Set();
  setInterval(() => { const now = Date.now(); subs.forEach(fn => fn(now)); }, 1000);
  document.addEventListener('visibilitychange', () => {
    if (!document.hidden) subs.forEach(fn => fn(Date.now()));   // 回前台立即校准
  });
  return { subscribe: fn => (subs.add(fn), () => subs.delete(fn)) };
})();
function Countdown({ deadline }) {
  const [left, setLeft] = useState();
  useEffect(() => ticker.subscribe(now => {
    const next = Math.max(0, deadline - now);          // 绝对时间计算
    setLeft(prev => prev === next ? prev : next);      // 秒不变不渲染
  }), [deadline]);
}
```
