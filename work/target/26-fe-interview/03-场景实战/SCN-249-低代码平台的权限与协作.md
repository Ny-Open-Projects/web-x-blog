## SCN-249：低代码编辑器多人协作（同时拖拽搭建）怎么设计？

**答**:
- 权限模型：页面级角色（owner/editor/viewer）+ 操作级权限（改结构/改样式/改逻辑/发布——精细到动作）、空间级管理（空间 owner 管理成员与模板）。
- 协作模式分级：轻协作（编辑锁：页面级/节点级乐观锁——他人正在编辑的节点锁定提示，SCN-229 软锁同源）、强协作（同文档 CRDT——低代码 schema 也可进 Yjs，节点树天然适配 CRDT Map）、按平台成熟度选型（初期锁模式够用）。
- 冲突处理：并发发布（A B 同时发布→版本序定，后发布者提示有新版本需 rebase）、编辑冲突（同节点并发修改→last write+提示，或 CRDT 自动合并属性）。
- 协作呈现：协作者头像与选中态（SCN-223 多光标同源）、操作历史流（时间线：谁改了什么）、评论（页面上打评论锚点——SCN-228 批注同源）。

```javascript
// 轻协作：节点级软锁
const locks = new Map();                     // nodeId → {user, ts}
ws.on('node_lock', ({ nodeId, user }) => {
  locks.set(nodeId, { user, ts: Date.now() });
  if (user.id !== me.id) markLocked(nodeId);  // 灰显+锁定徽标
});
function tryEdit(nodeId) {
  const l = locks.get(nodeId);
  if (l && l.user.id !== me.id &&
      Date.now() - l.ts < 30e3)
    return toast(`${l.user.name} 正在编辑该节点`);
  ws.send('node_lock', { nodeId, user: me });
  return true;
}
// 强协作：schema → Y.Map（节点 id → 节点对象），
// 属性级 CRDT 合并——参考 SCN-222/229。
```
