## SCN-288：会员体系（等级/成长值/权益）的前端呈现怎么设计？

**答**:
- 成长体系呈现：等级页（当前等级/成长值进度条/下一等级差距/升级条件明细）、成长值动画（SCN 会员结算动画复用：旧值到新值数字滚动）、成长值获取途径清单（可跳转执行）。
- 权益联动：权益矩阵（各等级权益对比表——升级动机）、权益使用入口（优惠券包按等级发放/专属客服标识/免邮标签在商品页实时显示）、权益生效状态（会员过期倒计时+续费引导）。
- 价格与标签：会员价展示（商品页价格区双价：会员价+普通价，登录会员态实时）、价格解释合规（会员价与原价对比的规范——避免虚构原价）。
- 状态一致性：会员身份缓存与失效（会员过期→权益标签同步消失）、多端会员状态同步（购买会员后其他端即时生效——事件推送）。

```javascript
function MemberBadge({ user, product }) {
  const vip = user.member?.active;
  return vip && product.memberPrice
    ? <Price vip={product.memberPrice}
        original={product.price}
        note={`会员立省 ¥${diff}`} />
    : <UpgradeHint target={product.memberPrice} />;  // 非会员引导
}
// 成长值动画：animateNumber(old, new) 滚动
// 会员过期：ws.on('member_expired') → 刷新权益态
// 价格合规：原价须为真实成交价（服务端下发依据）。
```
