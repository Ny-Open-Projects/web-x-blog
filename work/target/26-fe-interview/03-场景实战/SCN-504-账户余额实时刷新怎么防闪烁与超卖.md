## SCN-504：账户余额实时刷新怎么防闪烁与「超卖错觉」？
**答**：
- 单向更新：余额以服务端推送为唯一可信源，本地 optimistic 更新只在「本人发起交易」时临时叠加 pending 金额，推送到达后对账收敛。
- 合并节流：余额推送做 200ms 合并窗口（只保留最新值），配合数字滚动动画过渡，避免 1 秒内跳变多次造成闪烁。
- 状态显式化：余额旁标注「处理中 ¥xx」，冻结/在途金额单独展示，避免「余额没减但钱扣了」的超卖错觉投诉。
- 一致性兜底：页面 visibility 恢复、WS 重连、交易返回三个时机强制拉一次权威余额，diff 后才更新 UI。
- 追问钩子：pending 叠加与推送到达乱序怎么办——给每笔 pending 带幂等号，推送里携带「已确认流水号集合」做对账。

```javascript
class BalanceStore {
  confirmed = '1000000';   // 分
  pending = new Map();     // id -> amount(分)，本人未确认交易
  pushAmount(v) {          // WS 推送（200ms 合并后的权威值）
    if (v === this.confirmed) return;
    this.confirmed = v;
    this.pending.forEach((amt, id) => { /* 推送含 confirmedIds 时删除已确认项 */ });
    this.emit({ confirmed: v, display: v + sum(this.pending.values()) });
  }
  addPending(id, amount) {
    this.pending.set(id, amount);
    this.emit({ display: this.confirmed + amount, pendingHint: fenToYuan(amount) });
  }
}
```
