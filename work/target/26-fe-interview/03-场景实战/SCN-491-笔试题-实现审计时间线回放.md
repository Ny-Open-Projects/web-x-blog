## SCN-491：手写审计时间线回放：字段级 diff 渲染、快照查看、过滤导出

**需求与边界**：
- 输入：实体审计日志（含 diff/快照）；输出：时间线回放。
- 边界要求：① 字段级 diff 渲染（before→after 高亮——SCN-319 服务端预计算复用）；② 快照查看（变更时完整状态）；③ 过滤（操作人/类型/时间范围）；④ 导出（异步任务 SCN-426 复用）；⑤ 密集操作聚合。

**答**：
```javascript
function AuditTimeline({ entityId, logs }) {
  const [filter, setFilter] = useState({});
  const shown = logs
    .filter(l => matchFilter(l, filter))
    .map(l => ({ ...l, diff: l.diffs ?? diffOf(l) }));
  return <>
    <Filters value={filter} onChange={setFilter} />  {/* 人/类型/时间 */}
    <TimeAxis events={shown}
      aggregate={{ window: 60e3,           // 1min 密集聚合
        groupBy: 'operator' }} />
    {shown.map(l => (
      <Entry key={l.id} who={l.operator} at={l.ts}
        diffs={l.diff}                     // [{field, before, after}]
        onSnapshot={() => openSnapshot(l.snapshotId)} />))}
    <ExportAsync filters={filter} rows={shown.length} />
  </>;
}
// diff 渲染：字段名+before(删除线)→after(高亮)；
// 快照：变更时完整数据快照（查看当时状态）；
// 聚合：同人连续操作 1min 内折叠（"张三 执行 12 项变更"展开）。
```

**评分点**:
- 字段级 diff 渲染（before→after 可视化）。
- 快照查看（变更时完整状态可回放）。
- 过滤（人/类型/时间）+ 异步导出（SCN-426 复用）。
- 密集操作聚合（1min 窗口按操作人折叠）。
