## SCN-666：大屏主题换肤与值守模式怎么设计？
**答**：
- 主题体系：设计 token（颜色/字号/发光强度）CSS 变量化，深色科技风/浅色办公风两套；3D 场景的主题（环境光/背景/材质色）走配置对象同步切换。
- 值守轮播：多页面/多视角定时轮播（每页停留 N 分钟），轮播顺序可配置；数据刷新在页面切换时触发，避免后台页空耗资源（非可见页暂停渲染）。
- 无人值守健壮性：交互入口隐藏或锁定（防误触改配置）、自动全屏（Fullscreen API + 定期检测退出自动恢复）、异常自恢复（watchdog + reload）。
- 切页过渡：页面切换用交叉淡入淡出（避免白屏闪烁），切换期间数据预取。
- 追问钩子：后台页暂停渲染怎么实现——document.visibilityState + IntersectionObserver，配合按需渲染（SCN-658）一起省 GPU。

```javascript
function patrol(pages, { dwell = 5 * 60_000 } = {}) {
  let idx = 0, timer;
  function next() {
    idx = (idx + 1) % pages.length;
    router.push(pages[idx]);
    prefetch(pages[(idx + 1) % pages.length]);      // 预取下一页
    timer = setTimeout(next, dwell);
  }
  // 可见性：非可见页暂停渲染
  document.addEventListener('visibilitychange', () => {
    rendererPaused = document.hidden;
  });
  // 全屏守护
  setInterval(() => {
    if (!document.fullscreenElement &&值守Enabled)
      document.documentElement.requestFullscreen().catch(() => {});
  }, 30_000);
  return { start: next, stop: () => clearTimeout(timer) };
}
```
