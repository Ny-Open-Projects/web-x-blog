## SCN-817：联想下拉渲染性能怎么优化？
**答**：
- 高频更新：每次输入都渲染下拉——用列表复用（keyed diff 只更新变化项）+ 渲染节流（数据到达即渲染但同帧合并）。
- DOM 预算：下拉 ≤ 10 条 + 分组头 ≤ 20 个 DOM 节点/帧；图片卡片懒加载。
- 动画克制：下拉展开/收起用 CSS transition（transform/opacity），列表项不加动画（更新频率太高）。
- 输入法配合：composing 期间不渲染新数据（避免候选闪烁），上屏后再更新（SCN-811）。
- 追问钩子：为什么列表项不加进场动画——联想数据每次击键都变，动画会让列表持续闪烁；动画只留给下拉容器整体。

```javascript
function suggestListRenderer(container, items) {      // keyed 复用
  const byId = new Map([...container.children].map(el => [el.dataset.id, el]));
  items.forEach((item, i) => {
    let el = byId.get(item.id);
    if (!el) { el = buildRow(item); container.appendChild(el); }
    else byId.delete(item.id);
    el.style.order = i;                               // 只更新位置
    updateRow(el, item);                              // diff 更新文本
  });
  byId.forEach(el => el.remove());                    // 移除消失项
}
```
