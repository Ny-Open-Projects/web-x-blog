## SCN-316：跨国/跨区团队用内部系统，弱网与延迟的体验怎么优化？

**答**:
- 延迟感知优化：乐观更新（写操作本地立即生效+后台同步——审批/勾选/状态切换类全乐观）、预取（列表页预取详情——SCN-210 矩阵复用）、接口合并（弱网下请求合并批量化）、重试与断点（弱网请求超时放宽+断点续传文件）。
- 数据就近：边缘接入（全球加速接入点：CDN 动态加速/就近网关——成本与收益平衡）、读写分离（读走就近副本，写走主区——最终一致提示）、大文件就近上传（分片中转到就近边缘再汇聚）。
- 弱网体验：网络状态感知（RTT 探测→UI 自适应：弱网降图片质量/关自动播放）、离线优先能力（SCN-297 离线分级——弱网接近离线模式）、操作反馈强度（弱网下更明显的 pending 态——等待焦虑管理）。
- 协作时区配合：跨时区协作提醒（异步协作优先——SCN-422 跨时区协议复用到产品）、在线状态时区上下文（显示对方本地时间——避免深夜打扰）。

```javascript
// 弱网自适应
const net = probeRTT();                       // 定期探测
adaptive(net.rtt, {
  slow3g: { images: 'low', autoPlay: false, prefetch: false },
  good:   { images: 'auto', autoPlay: true, prefetch: true },
});
// 乐观更新：toggle 审批按钮 → 本地置位 → sync 队列
// 大文件：chunkUpload({ edge: nearestEdge(region) })  // 就缘中转
// 显示对方本地时间：<Presence tz label/>。
```
