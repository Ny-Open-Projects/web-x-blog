## SCN-700：手写 3D 标注投影跟随器

**需求与边界**：
- 需求：标注锚定世界坐标，每帧更新 DOM transform 跟随；相机后方/视锥外隐藏；距离衰减透明度（远淡）；批量更新上限。
- 边界：① project 后 z > 1 为相机后方；② 只写 transform 与 opacity（合成层友好）；③ 标签数量 > 300 时每帧分两批更新（隔帧轮替）。

**答**：
```javascript
function createLabelFollower(container, camera, renderer, { maxPerFrame = 300 } = {}) {
  const labels = new Map();                            // id -> { anchor: Vector3, el }
  let frame = 0;
  function tick() {
    frame++;
    const w = renderer.domElement.clientWidth, h = renderer.domElement.clientHeight;
    let count = 0;
    const v = new THREE.Vector3();
    for (const [id, l] of labels) {
      if (count >= maxPerFrame && frame % 2 === 0) continue;   // 超限隔帧轮替
      v.copy(l.anchor).project(camera);
      if (v.z > 1 || v.x < -1.1 || v.x > 1.1 || v.y < -1.1 || v.y > 1.1) {  // 后方/视锥外
        l.el.style.display = 'none';
        continue;
      }
      const x = (v.x + 1) / 2 * w, y = (-v.y + 1) / 2 * h;
      const dist = camera.position.distanceTo(l.anchor);
      const opacity = Math.max(0.2, 1 - dist / 800);   // 距离衰减
      l.el.style.display = 'block';
      l.el.style.transform = `translate(${x}px,${y}px)`;
      l.el.style.opacity = opacity.toFixed(2);
      count++;
    }
    requestAnimationFrame(tick);
  }
  requestAnimationFrame(tick);
  return {
    add: (id, anchor, el) => labels.set(id, { anchor, el }),
    remove: (id) => { labels.get(id)?.el.remove(); labels.delete(id); },
  };
}
```

**评分点**:
- project 投影 + z>1 相机后方剔除 + 视锥外隐藏。
- 只写 transform/opacity（合成层，无 reflow）。
- 距离衰减透明度（远近层次感）。
- 数量超限隔帧轮替（帧预算控制）。
