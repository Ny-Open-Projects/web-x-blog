## SCN-696：手写数据健康度巡检器

**需求与边界**：
- 需求：每指标配置 staleness 阈值；巡检输出 fresh/stale/offline 分类与全局健康分；过半 offline 触发快照模式（冻结 UI + 标注时间）；恢复自动退出快照模式。
- 边界：① 巡检频率 30s（可注入时钟测试）；② 连续 2 次异常才判 offline（防抖）；③ 健康分 = fresh 占比加权。

**答**：
```javascript
function createHealthInspector(metrics, thresholds, { interval = 30_000, now = () => Date.now() } = {}) {
  let abnormalStreak = new Map(), snapshotMode = false;
  const listeners = new Set();
  function inspect() {
    const t = now();
    const result = { fresh: [], stale: [], offline: [] };
    for (const m of metrics) {
      const age = t - m.lastUpdateTs, th = thresholds[m.type];
      if (age > th * 3) {
        const n = (abnormalStreak.get(m.id) || 0) + 1;
        abnormalStreak.set(m.id, n);
        n >= 2 ? result.offline.push(m.id) : result.stale.push(m.id);   // 连续 2 次才 offline
      } else if (age > th) result.stale.push(m.id);
      else { result.fresh.push(m.id); abnormalStreak.delete(m.id); }
    }
    const score = result.fresh.length / metrics.length;
    const shouldSnapshot = result.offline.length / metrics.length > 0.5;
    if (shouldSnapshot !== snapshotMode) {
      snapshotMode = shouldSnapshot;
      listeners.forEach(fn => fn({ type: snapshotMode ? 'ENTER_SNAPSHOT' : 'EXIT_SNAPSHOT',
                                   frozenAt: snapshotMode ? t : null }));
    }
    return { ...result, score, snapshotMode };
  }
  const timer = setInterval(inspect, interval);
  return { inspect, subscribe: fn => (listeners.add(fn), () => listeners.delete(fn)),
           stop: () => clearInterval(timer) };
}
```

**评分点**:
- 阈值三档（fresh/stale/offline = 1x/3x staleness）。
- 连续 2 次异常才判 offline（防抖，可注入时钟测试）。
- 快照模式进出双向切换（ENTER/EXIT 事件 + frozenAt 时间标注）。
- 健康分 = fresh 占比（可加权扩展）。
