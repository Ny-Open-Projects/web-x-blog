## SCN-657：大屏告警可视化怎么设计？
**答**：
- 视觉分层：告警四级色（提示/一般/严重/紧急）+ 紧急告警空间脉冲（3D 点位放大光环 + 2D 列表置顶）；同点位多告警合并为聚合标记（数字角标）。
- 告警风暴防御：同源告警限频聚合（10s 窗口同类合并计数）；地图侧聚合到区域层（钻取展开）；列表虚拟滚动。
- 联动定位：告警触发自动飞行到点位（可配置开关，风暴期关闭自动飞行）；人工点击定位。
- 确认闭环：值班人员点击确认 → 告警状态变灰 → 处理完成消失；全程留痕（谁确认的/耗时）。
- 追问钩子：自动飞行在告警风暴时反而干扰值班——用「告警密度」判断：风暴期关闭自动联动只保留声音提示。

```javascript
function alarmAggregator({ window = 10_000, autoFly = true } = {}) {
  const buckets = new Map();                       // sourceKey -> count
  let storm = false;
  function onAlarm(alarm) {
    const key = `${alarm.deviceGroup}:${alarm.level}`;
    const b = buckets.get(key) ?? { count: 0, first: alarm };
    b.count++; buckets.set(key, b);
    flushSoon();
  }
  function flushSoon() {
    setTimeout(() => {
      for (const [key, b] of buckets) renderMarker(b.first, b.count);   // 聚合渲染
      buckets.clear();
    }, window);
  }
  function onStorm(density) {
    storm = density > 50;                          // 每分钟告警数
    if (storm) { autoFly = false; toast('告警风暴模式：已暂停自动定位'); }
  }
  return { onAlarm, onStorm };
}
```
