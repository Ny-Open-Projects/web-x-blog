## SCN-565：无感验证与分级策略怎么设计？
**答**：
- 分级策略：服务端按风险评分分级——低风险无感通过（0 骚扰）、中风险滑块、高风险答题/人脸；阈值动态调整（大促/被攻击期自动收紧）。
- 信号组合：无感验证靠设备指纹 + 行为特征 + 账号信誉 + 环境一致性（IP/时区/语言匹配）综合评分。
- 误伤防御：白名单（老设备 + 高信誉 + 稳定环境）兜底；分级每次升级给用户原因提示（「网络环境异常」），并提供人工申诉出口。
- 灰度上线：新评分模型先 shadow 模式（只记分不拦截）跑两周，比对误伤率后再放量。
- 追问钩子：无感通过后还要二次验证吗——高危金额操作（转账）即使低分也强制一种显式验证，安全等级与金额挂钩。

```javascript
async function silentOrChallenge(scene, amountFen = 0) {
  const { score, level, reason } = await api.post('/risk/score', {
    scene, signals: collector.snapshot(),
  });
  // level: 0 无感 / 1 滑块 / 2 答题 / 3 人脸
  const forced = scene === 'pay' && amountFen > 500_0000;   // 大额强制显式
  const chosen = forced ? Math.max(level, 1) : level;
  if (chosen === 0) return { token: score.token };
  const v = registry.get(['slider', 'puzzle', 'face'][chosen - 1]);
  return v.run({ ...scene, hintReason: reason });           // 告知原因减少困惑
}
```
