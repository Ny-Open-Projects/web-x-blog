## SCN-807：联想埋点怎么设计？
**答**：
- 曝光定义：建议可见 ≥ 300ms 且 ≥ 50% 面积算有效曝光（IntersectionObserver），同一次下拉每条只计一次（曝光去重）。
- 归因链路：suggest 请求 traceId → 每条建议 sid → 点击/采纳事件携带 sid + 位置（rank）→ 搜索结果页延续同一 traceId——完整评估「联想质量对搜索转化的贡献」。
- 位置偏差校正：排名越靠前点击越多是位置效应，离线分析用 position-bias 模型校正后评估词质量。
- 埋点分级：点击/采纳全量，曝光采样 10%（量大价值密度低）。
- 追问钩子：为什么曝光去重要按「一次下拉会话」——连续输入（a→ap→app）每帧都触发下拉，不去重会把曝光量放大百倍，CTR 计算全部失真。

```javascript
const sugTracking = {
  expose: new IntersectionObserver(entries =>
    entries.forEach(e => {
      if (e.isIntersecting && e.intersectionRatio >= 0.5)
        reporter.push({ type: 'sug_expose', sid: e.target.dataset.sid,
                        rank: e.target.dataset.rank, traceId }, { sample: 0.1 });
    }), { threshold: 0.5 }),
  sessionScope: 'per-dropdown-open',                   // 曝光去重粒度
  adopt: (sid, rank) => reporter.push({ type: 'sug_adopt', sid, rank, traceId }, { urgent: true }),
};
```
