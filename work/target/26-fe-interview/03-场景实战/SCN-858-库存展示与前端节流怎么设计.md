## SCN-858：库存展示怎么设计？
**答**：
- 展示语义降维：秒杀库存精确数字无意义且高频跳变——展示区间档位（充足/紧张/售罄）或「仅剩少量」，既真实又稳定。
- 推送节流：库存变更合并窗口 500ms（只渲染最新档位），变化方向标记（↓ 减少时短暂高亮增强紧迫感但不闪烁）。
- 一致性红线：展示档位永远 ≤ 服务端真实库存（宁少报不多报）——展示「充足」但实际没了是最差体验。
- 售罄终态：售罄推送到达后立即锁定全购买入口（按钮/购物车/下单接口预检三处），售罄后到点前清理排队队列。
- 追问钩子：为什么展示档位而不是精确数——精确数（剩余 3 件）每秒变化引发 UI 抖动+用户刷新风暴；档位信息量足够决策且渲染稳定。

function stockLevel(real) {                            // 服务端下发的真实库存
  if (real <= 0) return { label: '已售罄', level: 'SOLD_OUT' };
