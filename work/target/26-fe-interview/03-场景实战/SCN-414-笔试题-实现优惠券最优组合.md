## SCN-414：手写优惠计算：券组合枚举、互斥校验、最优推荐与凑单差额

**需求与边界**：
- 输入：商品行、券列表（门槛/面额/互斥组）；输出：最优组合与凑单建议。
- 边界要求：① 券组合枚举（券少全排列、券多启发式截断）；② 互斥组不可同用；③ 满足门槛才可用；④ 差额凑单建议（差 X 元可达下一档）。

**答**：
```javascript
function bestCombination(items, coupons) {
  const subtotal = sum(items, 'price');
  let best = null, gapInfo = null;
  for (const combo of combinations(coupons)) {  // 子集枚举
    if (!valid(combo)) continue;                // 互斥组冲突→跳过
    const total = sum(combo, 'threshold');
    if (total > subtotal) {                     // 门槛不足→记差额
      const gap = total - subtotal;
      if (!gapInfo || gap < gapInfo.gap)
        gapInfo = { combo, gap };
      continue;
    }
    const saved = sum(combo, 'amount');
    if (!best || saved > best.saved)
      best = { combo, saved };
  }
  return {
    best,                                       // 最优组合
    suggest: !best && gapInfo ? {               // 凑单建议
      gap: gapInfo.gap,
      coupon: gapInfo.combo,
    } : null,
  };
}
function combinations(arr) {                    // 子集枚举
  const res = [[]];
  for (const x of arr)
    res.push(...res.map(r => [...r, x]));
  return res;
}
function valid(combo) {                         // 互斥校验
  const groups = combo.map(c => c.mutexGroup)
    .filter(Boolean);
  return new Set(groups).size === groups.length; // 同互斥组≤1
}
// 启发式：coupons > 8 时按面额降序贪心（避免 2^n 爆炸）；
// 门槛按"组合总门槛 vs 小计"判定；
// 尾差：分摊用分单位（SCN-206 引擎联动）。
```

**评分点**:
- 子集枚举正确（含空集）；互斥组校验（同组唯一）。
- 门槛判定与差额凑单建议（最优可达档）。
- 大券量启发式降级意识（2^n 爆炸防护）。
- saved 最优比较逻辑正确。
