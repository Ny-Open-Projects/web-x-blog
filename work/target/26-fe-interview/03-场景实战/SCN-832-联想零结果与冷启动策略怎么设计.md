## SCN-832：零结果与冷启动策略怎么设计？
**答**：
- 冷启动分层：新用户无历史 → 纯热词+品类入口；有品类偏好 → 品类热词加权；老用户 → 完整个人——冷启动不影响可用性只影响个性化深度。
- 零结果防御：输入命中无候选时降级为「字符级模糊匹配」（放宽到子串/纠错），仍无则展示「相关品类」引导——下拉永远不空屏（空屏 = 交互死路）。
- 新品类冷启：新上线品类词少——用同类目词迁移（相机→镜头）+ 运营补词，避免「新品类联想永远空」。
- 采集引导：零结果输入本身是宝贵信号（用户要什么没有），记录进词库缺口分析。
- 追问钩子：为什么零结果要「降级匹配」而不是直接空——空下拉让用户以为产品坏了；降级链保证任意输入都有响应，同时零结果信号被记录用于补词库。

```javascript
function zeroResultFallback(q) {
  const chain = [
    () => fuzzyMatch(q, { editDistance: 2 }),         // 纠错放宽
    () => substringMatch(q),                          // 子串匹配
    () => categoryHints(inferCategory(q)),            // 品类引导
  ];
  for (const step of chain) {
    const r = step();
    if (r.length) return r;
  }
  logGap(q);                                          // 词库缺口记录
  return categoryTopQueries();                        // 最终兜底：品类热词
}
```
