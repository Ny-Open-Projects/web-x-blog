## SCN-544：手写敏感字段脱敏器

**需求与边界**：
- 支持字段：手机号（保留前 3 后 4）、银行卡号（保留后 4）、姓名（中文保姓、英文保首字母）、证件号（保前 3 后 4）、邮箱（保首字符与域名）。
- 策略：场景可配置 `full`（全显）/`partial`/`hidden`；未知字段默认 hidden；输入非法（长度不足）原样返回但标记。

**答**：
```javascript
const MASK_RULES = {
  phone:   v => v.replace(/^(\d{3})\d{4}(\d{4})$/, '$1****$2'),
  bank:    v => v.length < 8 ? null : '**** **** **** ' + v.slice(-4),
  name:    v => /[\u4e00-\u9fa5]/.test(v)
              ? v[0] + '*'.repeat(v.length - 1)
              : v[0] + '*'.repeat(v.length - 1),           // 英文同样保首字母
  idcard:  v => v.length < 8 ? null : v.slice(0, 3) + '*'.repeat(v.length - 7) + v.slice(-4),
  email:   v => v.replace(/^(.).*(@.*)$/, '$1***$2'),
};
function maskObject(obj, { scene = 'partial', fields = {} } = {}) {
  const out = { ...obj }, warnings = [];
  for (const [key, value] of Object.entries(obj)) {
    const strategy = fields[key] ?? scene;                  // 字段级覆盖 > 场景默认
    if (strategy === 'full') continue;
    if (strategy === 'hidden') { out[key] = '******'; continue; }
    const rule = MASK_RULES[guessType(key)] || (() => '******');
    const masked = rule(String(value));
    if (masked === null) warnings.push(key);                // 长度不足：hidden 兜底并上报
    out[key] = masked ?? '******';
  }
  return { masked: out, warnings };
}
function guessType(key) {
  if (/mobile|phone/i.test(key)) return 'phone';
  if (/bank|card/i.test(key)) return 'bank';
  if (/name/i.test(key)) return 'name';
  if (/idcard|identity/i.test(key)) return 'idcard';
  if (/email/i.test(key)) return 'email';
  return 'unknown';                                         // unknown 默认 hidden
}
// maskObject({ phone: '13812345678', name: '王小明' }, { scene: 'partial' })
// => { masked: { phone: '138****5678', name: '王**' }, warnings: [] }
```

**评分点**:
- 规则表驱动 + 场景/字段双层策略覆盖。
- 未知字段默认 hidden（安全默认值，fail-closed）。
- 长度不足等非法输入 warning + 兜底而非抛错中断渲染。
- 正则脱敏考虑中文姓名/邮箱结构。
