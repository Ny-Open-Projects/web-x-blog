## SCN-425：手写审批流条件路由：条件表达式求值、实际路径展开、环检测

**需求与边界**：
- 输入：流程定义（节点+条件）、表单值；输出：实际审批路径。
- 边界要求：① 条件表达式求值（沙箱：字段比较，不 eval）；② 并行会签节点（所有审批人通过才过）；③ 环检测（路由形成环拒绝）；④ 时间线只渲染实际路径。

**答**：
```javascript
const FLOW = {
  start: 'n1',
  nodes: {
    n1: { type: 'approval', next: { n2: 'amount > 5000', n3: 'default' } },
    n2: { type: 'countersign', assignees: ['总监A','总监B'],
      next: { n3: 'default' } },
    n3: { type: 'finance', next: { end: 'default' } },
  },
};
function evalCond(expr, form) {                // 沙箱求值
  const m = expr.match(/^(\w+)\s*(>|<|==)\s*(\S+)$/);
  if (!m) return expr === 'default';
  const [, field, op, val] = m;
  const left = form[field];
  const right = isNaN(+val) ? val.replace(/['"]/g, '') : +val;
  return op === '>' ? left > right
    : op === '<' ? left < right : left == right;
}
function resolvePath(flow, form) {
  const path = []; const seen = new Set();
  let cur = flow.start;
  while (cur !== 'end') {
    if (seen.has(cur)) throw new Error('流程环');
    seen.add(cur);
    const node = flow.nodes[cur];
    path.push({ id: cur, ...node });
    const nextKey = Object.keys(node.next)
      .find(k => evalCond(node.next[k], form));
    if (!nextKey) throw new Error('无可用路由');
    cur = nextKey;
  }
  return path;                                 // 实际路径（时间线渲染）
}
// countersign：全部通过才前进（任一驳回→驳回处理）。
```

**评分点**:
- 条件求值沙箱化（受限解析不 eval）+ default 兜底分支。
- 路径解析含环检测与无路由异常。
- countersign 会签语义（全员通过）。
- 时间线只渲染实际路径（动态展开）。
