## SCN-557：短信验证码防轰炸前端怎么做？
**答**：
- 发送前校验：图形/滑块验证前置（人机校验先行），手机号格式校验，风控接口判断「当前手机号 + IP + 设备」是否可发。
- 倒计时权威在服务端：发送成功后服务端返回剩余冷却秒数，前端按它起倒计时——防止换设备/刷新绕过本地计时；多 Tab 同步用 localStorage 事件。
- 展示策略：剩余次数显示、超限提示与解封时间；语音验证码作为备用通道。
- 防绕过意识：前端倒计时只是 UX，服务端才是频控本体；接口层再限流兜底。
- 追问钩子：多标签页同时倒计时怎么同步——storage 事件广播剩余秒数，以最新写入为准。

```javascript
function useSmsCountdown(mobile) {
  const [left, setLeft] = useState(() =>
    Math.max(0, Number(localStorage.getItem(`sms_cd_${mobile}`)) - Date.now() / 1000 | 0));
  useEffect(() => {
    const sync = (e) => e.key === `sms_cd_${mobile}` && setLeft(Math.max(0, Math.ceil(+e.newValue - Date.now() / 1000)));
    window.addEventListener('storage', sync);     // 多 Tab 同步
    const t = setInterval(() => setLeft(l => Math.max(0, l - 1)), 1000);
    return () => { window.removeEventListener('storage', sync); clearInterval(t); };
  }, [mobile]);
  const send = async () => {
    const { cooldown, remain } = await api.post('/sms/send', { mobile, captcha: await slider() });
    localStorage.setItem(`sms_cd_${mobile}`, Math.ceil(Date.now() / 1000) + cooldown);
    setLeft(cooldown);
    toast(`今日还可发送 ${remain} 次`);
  };
}
```
