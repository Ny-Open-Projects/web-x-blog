## SCN-952：手写一个政务事项搜索联想器（同义词+拼音）

**答**：
- 需求：implement ItemSuggest(items, synonyms)。input(q) 返回 Top10：名称命中 2 分/关键词 1 分/同义词命中 1.5 分/拼音前缀 1 分；按分排序；空输入返回热门事项。
- 边界：q 去空格转小写；拼音匹配用全拼与首字母；重复结果去重；items 空返回空。
- 评分点：多源打分；同义词扩展；拼音匹配；热门兜底

```javascript
class ItemSuggest {
  constructor(items, synonyms = {}) {
    this.items = items; this.syn = synonyms;
    this.index = items.map(it => ({ ...it,
      py: toPinyin(it.name), pyInitial: pinyinInitial(it.name) }));
  }
  suggest(q, { hot = [] } = {}) {
    const norm = q.trim().toLowerCase();
    if (!norm) return hot.slice(0, 10);
    const exp = new Set([norm, ...(this.syn[norm] ?? [])]);
    return this.index.map(it => {
      let score = 0;
      for (const k of exp) {
        if (it.name.includes(k)) score += 2;
        else if (it.keywords?.some(x => x.includes(k))) score += 1;
        else if (it.py.includes(k)) score += 1;
        else if (it.pyInitial.startsWith(k)) score += 1;
        if (this.syn[norm]?.some(s => it.name.includes(s))) score = Math.max(score, 1.5);
      }
      return { item: it, score };
    }).filter(r => r.score > 0)
      .sort((a, b) => b.score - a.score).slice(0, 10)
      .map(r => r.item);
  }
}
function toPinyin(s) { /* 拼音库实现 */ return s; }
function pinyinInitial(s) { return s; }
```
