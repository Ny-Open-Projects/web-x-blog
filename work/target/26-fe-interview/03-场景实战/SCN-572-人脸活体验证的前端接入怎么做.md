## SCN-572：人脸/活体验证前端接入怎么做？
**答**：
- 接入形态：优先官方 H5/小程序 SDK（合规与算法一体），不自研识别；前端负责调起、结果回传与体验包装（前置说明、光线检测引导）。
- 环境预检：调用前检测摄像头权限、HTTPS 环境、设备性能；低配机给「换设备」或替代验证路径。
- 隐私合规：采集前显式告知并单独授权（人脸是敏感个人信息），录框提示仅本地处理不上传原始帧（由 SDK 保证），失败不保留留底。
- 失败率优化：失败原因结构化（光线暗/遮挡/角度偏）实时引导重试；连续失败 2 次提供替代验证。
- 追问钩子：人脸 SDK 加载失败怎么办——降级到短信+人工审核通道，并在日志中标记走降级的比例。

```javascript
async function faceVerify(bizToken) {
  const pre = await precheck();                   // { camera: true, https: true, perf: 'ok' }
  if (!pre.ok) return fallback(pre.missing);      // 引导换设备/替代验证
  const consent = await askConsent('face');       // 敏感个人信息单独授权
  if (!consent) return { pass: false, reason: 'USER_DENY' };
  const result = await FaceSDK.verify({           // 官方 SDK
    token: bizToken,
    onGuide: (g) => showGuide(g),                 // “请正对屏幕”“光线不足”实时引导
  });
  return { pass: result.pass, failReason: result.reason };   // 原始帧不上前端
}
```
