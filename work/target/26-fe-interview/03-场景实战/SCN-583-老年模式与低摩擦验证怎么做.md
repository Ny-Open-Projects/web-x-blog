## SCN-583：老年模式与低摩擦验证怎么做？
**答**：
- 适老通道：老年模式用户优先无感验证与短信验证，默认跳过滑块；字号/命中区放大，倒计时延长 50%。
- 低摩擦策略池：图形点选替代拖拽滑块（单次点击 vs 精细拖动）、语音验证、亲属协助验证（授权家庭成员辅助确认）。
- 安全不放松：低摩擦通道的额度上限更低（如老年模式单笔转账限额下调），安全强度用额度补偿摩擦。
- 引导文案：步骤拆解（一次一件事）、避免术语（「滑动滑块到最右侧」而非「完成人机校验」）。
- 追问钩子：怎么识别用户需要适老模式——显式开关 + 行为特征（误触率/操作时长）自动建议，不靠年龄字段硬猜。

```javascript
function adaptVerifier(user, scene) {
  if (user.elderMode) {
    return {
      verifiers: ['sms', 'voice'],                 // 跳过滑块
      quotaLimit: Math.min(scene.maxFen, 50_0000), // 额度补偿摩擦
      ui: { fontSize: 'large', hitArea: 56, countdownScale: 1.5 },
      copy: SIMPLE_COPY,                           // 拆解步骤文案
    };
  }
  return scene.defaultVerifiers;
}
```
