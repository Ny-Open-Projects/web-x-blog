## SCN-438：手写视频发布：上传后转码轮询、封面选择、失败草稿保全

**需求与边界**：
- 输入：视频 File、发布表单；输出：发布控制器。
- 边界要求：① 大视频分片上传（SCN-411 复用）；② 转码任务轮询（异步任务中心）；③ 封面抽帧选择（前端 canvas 抽帧）；④ 失败保留草稿（内容是创作者资产——不清空）。

**答**：
```javascript
async function publishVideo(form, file) {
  await saveDraft(form);                       // 先保全草稿
  const up = await chunkUpload(file, { onProgress: setBar });
  const task = await api.transcode(up.url);    // 转码任务
  const done = await pollTask(task.id, {
    onProgress: (p) => setBar(p * 0.5 + 0.5) });
  // 封面：前端抽帧
  const frames = await grabFrames(done.playUrl, [1, 5, 10], 3);
  form.cover = form.cover ?? frames[0];        // 默认首帧
  showCoverPicker(frames);                     // 创作者选封面
  const r = await postApi.create({ ...form,
    videoId: done.videoId, idempotencyKey: form.draftId });
  if (!r.ok) {                                 // 失败保全草稿
    toast('发布失败，草稿已保留');
    return { retry: () => publishVideo(form, file) };
  }
  clearDraft(form.draftId);
  return r;
}
const grabFrames = (url, secs, n) => Promise.all(
  secs.slice(0, n).map(t => frameAt(url, t)));  // canvas 抽帧
// 转码：taskCenter 模式（进度/失败原因/重试）。
// 审核状态：r.status === 'reviewing' → 粉丝可见策略提示。
```

**评分点**:
- 草稿先行保全（失败不清空——创作者资产意识）。
- 转码异步任务轮询（进度合并展示：上传 50%+转码 50%）。
- 前端 canvas 抽帧封面选择。
- 幂等键（draftId）防重复发布。
