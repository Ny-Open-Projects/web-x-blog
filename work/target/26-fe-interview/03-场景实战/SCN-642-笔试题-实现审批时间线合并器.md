## SCN-642：手写审批时间线合并器

**需求与边界**：
- 输入：事件流 `[{nodeId, operator, action, opinion, system, ts}]`。
- 要求：① 按 ts 排序；② 同节点同操作人 60 秒内的连续人工事件合并为一组（组头取最终 action）；③ 系统事件不合并、独立展示；④ 里程碑（SUBMIT/PASSED/ARCHIVED）单列锚点。

**答**：
```javascript
const MILESTONES = new Set(['SUBMIT', 'PASSED', 'REJECTED', 'ARCHIVED']);
function mergeTimeline(events) {
  const sorted = [...events].sort((a, b) => a.ts - b.ts);
  const out = [];
  for (const e of sorted) {
    if (MILESTONES.has(e.action)) { out.push({ type: 'milestone', event: e }); continue; }
    if (e.system) { out.push({ type: 'system', event: e }); continue; }
    const last = out.at(-1);
    if (last?.type === 'group' && last.nodeId === e.nodeId && last.operator === e.operator
        && e.ts - last.items.at(-1).ts < 60_000) {
      last.items.push(e);
      last.finalAction = e.action;                   // 组头最终动作
      last.opinion = e.opinion ?? last.opinion;      // 意见以最新非空为准
    } else {
      out.push({ type: 'group', nodeId: e.nodeId, operator: e.operator,
                 items: [e], finalAction: e.action, opinion: e.opinion });
    }
  }
  return out.map(g => g.type === 'group' ? {
    ...g, count: g.items.length,
    // 保留修改痕迹：同操作人同节点先 agree 后改意见 → items 全保留
  } : g);
}
```

**评分点**:
- 三类输出（milestone/system/group）分层。
- 合并条件三重校验（同节点+同人+60s 内），系统事件永不合并。
- 组头 finalAction 与最新意见语义。
- items 全保留（审计不丢细节）。
