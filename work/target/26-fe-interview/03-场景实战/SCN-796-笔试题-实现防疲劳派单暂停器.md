## SCN-796：手写防疲劳暂停器

**需求与边界**：
- 需求：连续审核计数（按品类区分阈值）；达到上限通知服务端暂停派单并显示休息倒计时；休息结束重置计数；高危品类连续时长单独累计。
- 边界：① 计数持久化（刷新页面不丢）；② 服务端为准（本地计数仅提示）；③ 休息期间领取请求被拒显示剩余时间。

**答**：
```javascript
function createFatigueGuard(auditorId, policy) {
  const KEY = `fatigue_${auditorId}`;
  const state = JSON.parse(localStorage.getItem(KEY) || '{"count":0,"highRiskMin":0}');
  let timer = null;
  function onSubmitted(item) {
    state.count++;
    if (item.category === 'HIGH_RISK')
      state.highRiskMin += (item.durationMs ?? 0) / 60_000;
    persist();
    const limit = policy.normal.maxContinuous;
    if (state.count >= limit || state.highRiskMin >= policy.highRisk.maxMinutes)
      return triggerBreak(item.category === 'HIGH_RISK'
        ? policy.highRisk.breakMin : policy.normal.breakMin);
    return null;
  }
  function triggerBreak(minutes) {
    return api.post('/dispatch/pause', { auditorId, minutes }).then(() => {
      countdown(minutes, () => {                       // 倒计时结束重置
        state.count = 0; state.highRiskMin = 0; persist();
      });
      return { breakMin: minutes };
    });
  }
  async function claim() {
    const res = await api.post('/queue/claim', { auditorId });
    if (res.code === 'PAUSED') return { paused: true, left: res.breakLeft };   // 服务端为准
    return { item: res.data };
  }
  const persist = () => localStorage.setItem(KEY, JSON.stringify(state));
  return { onSubmitted, claim };
}
```

**评分点**:
- 双阈值（普通条数 + 高危分钟数）独立累计。
- 服务端暂停派单为准，本地计数仅提示。
- localStorage 持久化（刷新不丢）。
- 休息结束重置 + PAUSED 响应显示剩余时间。
