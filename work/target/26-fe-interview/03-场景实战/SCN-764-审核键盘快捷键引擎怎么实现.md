## SCN-764：审核快捷键引擎怎么实现？
**答**：
- 统一注册：快捷键表 `{ combo → action }`，全局监听 + 上下文感知（播放器聚焦时 space 是播放，表单聚焦时是输入）——用「目标元素是否可编辑」分流。
- 防冲突：注册时检测重复 combo 报错；组合键（Shift+R）优先于单键；输入框内不做全局拦截。
- 可配置与可发现：快捷键用户可改（偏好持久化），界面提供快捷键浮层（? 键唤起）——新审核员学习成本。
- 高频路径零鼠标：通过/驳回/标注/提交全键盘，实测单条审核时长可降 30%+。
- 追问钩子：为什么不用 keydown 直接 switch——需要处理 combo 顺序、长按去重（e.repeat）、目标可编辑检测、用户自定义覆盖，统一引擎才能维护。

```javascript
function createHotkeys({ isEditable = (t) => /INPUT|TEXTAREA/.test(t.tagName) } = {}) {
  const map = new Map();                             // combo -> handler
  function normalize(e) {
    return [e.ctrlKey && 'ctrl', e.shiftKey && 'shift', e.key.toLowerCase()]
      .filter(Boolean).join('+');
  }
  window.addEventListener('keydown', (e) => {
    if (e.repeat || isEditable(e.target)) return;    // 长按去重 + 可编辑跳过
    const h = map.get(normalize(e));
    if (h) { e.preventDefault(); h(e); }
  });
  return {
    register: (combo, handler) => {
      if (map.has(combo)) throw new Error(`快捷键冲突: ${combo}`);
      map.set(combo, handler);
    },
    list: () => [...map.keys()],                     // 浮层展示
  };
}
```
