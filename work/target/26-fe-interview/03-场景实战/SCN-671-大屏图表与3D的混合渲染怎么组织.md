## SCN-671：2D 图表与 3D 场景混合渲染怎么组织？
**答**：
- 分层结构：底层 3D WebGL canvas（全屏）→ 中层 3D 标注 DOM 层 → 上层 2D 图表面板（DOM/SVG），z-index 分层各管各的渲染循环，互不干扰。
- 事件穿透：图表面板区域拦截鼠标事件，其余区域事件穿透到 3D canvas（pointer-events 控制）；面板半透明区域可配置「点击穿透」。
- 数据桥：3D 与图表共享 TwinStore 单源；面板位置跟随 3D 的「贴地布局」需求用投影坐标（SCN-662 同源）。
- 合成性能：3D 层用独立 canvas + preserveDrawingBuffer: false；DOM 层 will-change 提升合成层，避免每帧重绘。
- 追问钩子：图表想「嵌在 3D 空间里」（ billboard）怎么办——用 CSS2DRenderer 把 DOM 标签投影到 3D 坐标，本质还是分层投影，不是真的在 WebGL 里画 DOM。

```javascript
// 分层渲染循环
function hybridLoop() {
  let raf;
  function frame(t) {
    if (twinStore.dirty3D) {                          // 3D 脏才渲染
      renderer.render(scene, camera);
      updateLabels(camera);                           // 标注投影（DOM 层）
      twinStore.dirty3D = false;
    }
    if (twinStore.dirtyCharts.has('energy')) {        // 图表脏标记
      energyChart.setOption(buildOption(twinStore.get('energy')));
      twinStore.dirtyCharts.delete('energy');
    }
    raf = requestAnimationFrame(frame);
  }
  raf = requestAnimationFrame(frame);
  return () => cancelAnimationFrame(raf);
}
```
