## SCN-688：手写万级设备状态着色更新器

**需求与边界**：
- 需求：万设备 InstancedMesh，状态事件到达后按状态改实例颜色；rAF 合帧批量应用；颜色变化用短过渡（可选）。
- 边界：① setColorAt 后必须标记 instanceColor.needsUpdate；② 同帧重复状态取最新；③ 帧内应用数量上限（超限留到下帧）。

**答**：
```javascript
function createStateColorizer(mesh, stateColors) {    // stateColors: { normal: 0x2ecc71, alarm: 0xe74c3c, ... }
  const pending = new Map();                           // instanceId -> state（同帧取最新）
  const dummy = new THREE.Color();
  function onEvents(events) {
    for (const e of events) pending.set(e.instanceId, e.state);
    scheduleFlush();
  }
  let scheduled = false;
  function scheduleFlush() {
    if (scheduled) return;
    scheduled = true;
    requestAnimationFrame(flush);
  }
  function flush() {
    scheduled = false;
    const BATCH = 2000;                                // 帧内上限，防止单帧过长
    let done = 0;
    for (const [id, state] of pending) {
      if (done >= BATCH) { scheduleFlush(); return; }  // 剩余留到下帧
      dummy.set(stateColors[state] ?? stateColors.normal);
      mesh.setColorAt(id, dummy);
      pending.delete(id);
      done++;
    }
    if (mesh.instanceColor) mesh.instanceColor.needsUpdate = true;   // 关键：标记重传
  }
  return { onEvents, get pending() { return pending.size; } };
}
```

**评分点**:
- rAF 合帧 + 同帧状态去重（Map 覆盖）。
- 帧内批量上限（大更新分帧，不掉帧）。
- instanceColor.needsUpdate 标记（漏写是不生效的头号原因）。
- 未知状态 fallback 到 normal。
