## SCN-1299：手写一个国际化站点健康度日报（分国家）

**答**：
- 需求：implement I18nDaily(samples)。samples 为 [{ country, lang, cvr, payFailRate, noResultRate }]；report() 分国家输出 { country, cvr, payFail, noResult, grade }（三项阈值：cvr > 1%、payFail < 5%、noResult < 10%）；低样本标注。
- 边界：样本 < 50 标 low-sample；缺失指标按达标；grade 按超标项数（0 优 1 良 2+ 差）；按 grade 升序排序。
- 评分点：分国聚合；三指标；分级；低样本

```javascript
class I18nDaily {
  constructor(samples, th = { cvr: 1, payFail: 5, noResult: 10 }) {
    this.samples = samples; this.th = th;
  }
  report() {
    const by = {};
    this.samples.forEach(s => (by[s.country] ??= []).push(s));
    return Object.entries(by).map(([country, rows]) => {
      const rate = sel => rows.filter(sel).length / rows.length * 100;
      const cvr = rate(s => s.cvr > 1);
      const payOk = rate(s => s.payFailRate < 5);
      const searchOk = rate(s => s.noResultRate < 10);
      const bad = [cvr < 100, payOk < 100, searchOk < 100].filter(Boolean).length;
      return { country, cvr: +cvr.toFixed(1), payOk: +payOk.toFixed(1),
        searchOk: +searchOk.toFixed(1),
        grade: bad === 0 ? '优' : bad === 1 ? '良' : '差',
        lowSample: rows.length < 50 };
    }).sort((a, b) => (a.grade === '差' ? -1 : 1) - (b.grade === '差' ? -1 : 1));
  }
}
```
