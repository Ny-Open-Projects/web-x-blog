## SCN-1302：手写一个国际电商场景收束检查器

**答**：
- 需求：implement GlobalAudit(signals)。signals 为各子域结果 { i18n, payment, logistics, tax, compliance }（各含 pass/failItems）；输出总分与发布建议；i18n/payment 为核心域（未过阻塞）。
- 边界：域缺失按未通过；score 保留 1 位；verdict 三态（可发布/有条件/阻塞）；红项按域排序。
- 评分点：五域聚合；核心域阻塞；三态 verdict；缺失处理

```javascript
function GlobalAudit(signals) {
  const DOMAINS = ['i18n', 'payment', 'logistics', 'tax', 'compliance'];
  const rows = DOMAINS.map(d => ({
    domain: d, pass: signals[d]?.pass ?? false,
    failItems: signals[d]?.failItems ?? ['missing'],
  }));
  const passed = rows.filter(r => r.pass).length;
  const red = rows.filter(r => !r.pass);
  return {
    score: +(passed / DOMAINS.length * 100).toFixed(1),
    red,
    verdict: red.length === 0 ? '可发布'
      : red.some(r => ['i18n', 'payment'].includes(r.domain))
        ? '阻塞发布（核心域未过）' : '有条件发布（限期修复）',
  };
}
```
