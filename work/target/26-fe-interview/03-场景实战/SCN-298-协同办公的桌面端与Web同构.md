## SCN-298：办公套件要出桌面端（Electron）与 Web 同构，怎么设计？

**答**:
- 同构分层：业务核心层复用（同一套业务代码：编辑器/IM/状态管理——平台无关），平台适配层（文件系统/剪贴板/通知/协议注册：Electron API vs Web API 的适配器接口），壳层差异（窗口管理/托盘/自动更新 Electron 专属）。
- 平台增强：桌面端独有能力（全局快捷键/系统通知原生/文件关联/离线更强的本地存储/多窗口）、Web 端能力兜底（适配层降级实现——同一业务代码两平台行为一致但能力不同）。
- 更新与部署：自动更新（增量更新/灰度发布/版本回滚）、双端发布节奏（Web 随时发，桌面端发版节奏慢——兼容期：旧桌面端连新服务端的 API 兼容窗口）。
- 深度集成：系统集成（文件双击打开/系统分享菜单/开机自启）、与 Web 的会话连续（同一账号状态同步/剪贴板互通）。

```text
桌面同构分层：
业务核心：复用（编辑器/IM/状态）
适配层：fs/clipboard/notify →
  ElectronAdapter | WebAdapter（降级实现）
壳层：窗口/托盘/自动更新（Electron 专属）
增强：全局快捷键/文件关联/多窗口
发布：Web 随时发 / 桌面慢节奏 + API
  兼容窗口（旧客户端连新服务端）。
```
