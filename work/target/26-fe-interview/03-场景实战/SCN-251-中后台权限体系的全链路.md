## SCN-251：中后台 RBAC 权限（路由/菜单/按钮/接口）怎么全链路落地？

**答**:
- 权限模型：RBAC（用户→角色→权限点），权限点粒度三级（页面/操作按钮/数据字段），数据来源（登录后拉权限码集合 permissions: string[]，前端本地判断+服务端强制）。
- 路由层：动态路由（按权限码过滤路由表→生成菜单+注册路由），直接 URL 访问拦截（无权限路由→403 页），懒加载路由的守卫顺序（先权限后加载组件——不下载无权组件）。
- 按钮级：权限指令/组件（`v-perm="'order:delete'"` 无权限不渲染或禁用），批量判断的性能（权限码 Set 查找 O(1)）、混淆注意（隐藏按钮≠接口安全，服务端必须同校验）。
- 数据权限：行级/字段级权限（同一列表不同人看不同行/字段——服务端裁剪数据，前端不做数据裁剪只呈现）、字段脱敏展示（手机号/金额按权限掩码）。

```javascript
// 动态路由
const routes = allRoutes.filter(r => hasPerm(r.meta.perm));
router.setRoutes([...common, ...routes]);    // 生成菜单同源
function hasPerm(code) { return permSet.has(code); }
// 按钮指令
app.directive('perm', {
  mounted(el, { value }) {
    if (!hasPerm(value)) el.parentNode?.removeChild(el);
  },
});
// <Button v-perm="'order:delete'">删除</Button>
// 数据权限：服务端裁剪 rows/fields，
// 前端按字段掩码配置渲染（sc.phone → 138****5678）。
// 直接访问无权路由 → 全局守卫 → 403 页。
```
