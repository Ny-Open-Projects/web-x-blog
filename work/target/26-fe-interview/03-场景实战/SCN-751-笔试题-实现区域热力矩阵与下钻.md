## SCN-751：手写区域热力矩阵

**需求与边界**：
- 输入：`[{region, isp, p95, n}]`；输出矩阵格子（region×isp）的 z 偏离度、分级（1~5）、小样本标注、点击下钻过滤条件。
- 边界：① 全局基准用加权中位数（低样本区域不影响基准）；② 样本 < 1000 标 LOW_SAMPLE 不判异常；③ 分级按分位数自适应。

**答**：
```javascript
function regionHeatmap(rows) {
  const total = rows.reduce((s, r) => s + r.n, 0);
  const weighted = rows.flatMap(r => Array(Math.ceil(r.n / total * 1000)).fill(r.p95));   // 加权展开
  const base = median(weighted);
  const zs = rows.map(r => r.n >= 1000 ? (r.p95 - base) / base : null).filter(v => v !== null);
  const th = [0.2, 0.4, 0.6, 0.8].map(q => quantile(zs.sort((a, b) => a - b), q));   // 自适应阈值
  return rows.map(r => {
    const z = r.n >= 1000 ? (r.p95 - base) / base : null;
    const level = z === null ? 0 : th.findIndex(t => z <= t) + 1;      // 0=小样本 1~5 级
    return {
      region: r.region, isp: r.isp, p95: r.p95, z,
      level, lowSample: r.n < 1000,
      drill: { filters: { region: r.region, isp: r.isp, status: 'PENDING' } },
    };
  });
}
```

**评分点**:
- 加权中位数基准（大流量区域主导）。
- 小样本保护（<1000 不参与分级、level=0）。
- 分级阈值自适应（分位数而非固定值）。
- 每格携带下钻过滤条件。
