## SCN-865：容灾演练怎么组织？
**答**：
- 演练矩阵：压测（1.5× 预估峰值，验证容量）、故障注入（WS 断连/接口超时/CDN 故障，验证降级链）、用户体验演练（真实终端走全流程，验证交互细节）。
- 演练判据：每项演练有预期行为（「WS 断连应在 5s 内切轮询」）与实际结果差距——差距就是改进项。
- 演练复盘：演练发现的问题分级（阻断活动级/降级体验级/记录级），阻断级问题修复后回归演练。
- 演练资产沉淀：演练脚本与用例库复用（下一场活动增量更新），演练报告归档。
- 追问钩子：为什么压测要 1.5× 而不是 1× 预估峰值——预估本身有误差（爆款超预期很常见），1.5× 是对估算误差的工程冗余；压到崩再修复好过活动崩。

```javascript
const drillMatrix = [
  { type: 'load', target: '1.5x', judge: (m) => m.p95 < 3000 ? 'PASS' : 'FAIL' },
  { type: 'chaos', inject: ['ws-down', 'api-timeout', 'cdn-fail'],
    judge: (behavior) => behavior.fallbackIn <= 5_000 ? 'PASS' : 'FAIL' },
  { type: 'ux-walkthrough', judge: '人工 checklist' },
];
const review = (results) => ({
  blockers: results.filter(r => r.judge === 'FAIL' && r.level === 'blocker'),
  note: '阻断级修复后回归演练',
});
```
