## SCN-518：余额构成可视化怎么设计？
**答**：
- 恒等式优先：可用 + 冻结 + 在途 = 总额，UI 按堆叠条/环形图渲染并显示合计校验行，两端数对不上时提示数据异常而非静默渲染。
- 语义配色：可用（绿）/冻结（橙，hover 显示冻结原因与预计解冻时间）/在途（灰蓝），金额标签支持点击下钻到明细流水。
- 动效克制：金额变化用差值动画；占比变化用过渡，但大屏展示关闭动画节省渲染。
- 空态与异常态：总额为 0、单构成 100%、服务端部分字段缺失三种态分别设计，不出现 NaN。
- 追问钩子：占比极小项怎么画——小于阈值合并为「其他」，防止 0.3% 的扇区文字重叠。

```javascript
function balanceBreakdown(parts) {           // parts: [{ type, amountFen, reason? }]
  const total = parts.reduce((s, p) => s + p.amountFen, 0);
  const MIN = 0.005;                         // 0.5% 以下并入其他
  const shown = [], other = { type: 'OTHER', amountFen: 0 };
  for (const p of parts)
    p.amountFen / total < MIN ? (other.amountFen += p.amountFen) : shown.push(p);
  if (other.amountFen) shown.push(other);
  return shown.map(p => ({
    ...p, pct: p.amountFen / total,
    text: fenToYuan(p.amountFen),            // NaN 防御：total=0 时返回空态而非除零
    drill: p.type === 'FROZEN' ? `/flows?status=frozen&reason=${p.reasonId}` : null,
  }));
}
```
