## SCN-331：打车场景（叫车→接驾→行程→支付）的地图与状态联动怎么设计？

**答**:
- 订单状态机：等待应答（地图扩散找车动画）→已接单（司机信息卡+接驾路线）→到达上车点→行程中（实时轨迹+ETA）→待支付（费用明细）→完成——每态的地图呈现与卡片内容不同（状态驱动视图），状态信令推送+轮询兜底。
- 地图联动：接驾阶段（司机位置实时更新+预计到达倒计时）、行程中（轨迹实时绘制+ETA 动态更新——路况重算）、视野自动适配（状态切换时视野平移到相关实体：司机/终点），路径规划结果缓存（路线变更才重绘）。
- 司机位置流：高频位置推送节流渲染（3s 一次平滑移动动画——SCN-265 滤波复用）、信号弱降级（位置冻结+最后更新时间标注）。
- 关键交互：改目的地（行程中改终点→重新规划确认）、紧急功能（一键报警/行程分享实时位置给家人）、支付前置（行程结束前预授权展示预估价）。

```javascript
ws.on('order_state', (s) => {
  orderStore.set(s.status);
  mapAdapter.byState(s);          // 状态驱动地图视图
  // 等待：扩散动画；接单：fit司机+上车点；行程：fit全程
});
ws.on('driver_pos', throttleRender((p) => {
  const loc = filter.feed(p);     // 滤波平滑（SCN-265）
  driverMarker.moveTo(loc);       // 动画移动非瞬跳
}));
// ETA：ws.on('eta', e => card.setEta(e.min))；
// 改终点：confirm → replan → routeLayer.update()。
```
