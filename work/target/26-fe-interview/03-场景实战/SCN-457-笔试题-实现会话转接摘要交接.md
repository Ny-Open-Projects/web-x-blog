## SCN-457：手写客服会话转接：自动摘要、接收方确认、失败兜底

**需求与边界**：
- 输入：会话、目标坐席；输出：转接结果。
- 边界要求：① 交接摘要（问题/已尝试/情绪）；② 接收方确认接手（不空中转）；③ 转接中客户消息缓存（不丢）；④ 转接失败回退原客服；⑤ 客户知情提示。

**答**：
```javascript
async function transfer(session, target) {
  const digest = {
    issue: await summarize(session.messages, { schema: '问题' }),
    tried: session.actionsTaken,             // 已尝试方案
    mood: detectMood(session),               // 客户情绪
    order: session.ctx.order,                // 上下文
  };
  const ok = await target.confirmHandover(digest);  // 接收确认
  if (!ok) return fallback(session, target);  // 回退原客服
  session.hold();                            // 转接期间消息缓存
  await session.migrate(target);
  flushHeldMessages(session);                // 缓存消息补发
  notifyCustomer(session, `已为您转接专家 ${target.name}`);
  session.rateHandover(target);              // 交接质量评分闭环
}
// 失败兜底：target 拒绝/超时 → 原客服继续+排期转接
// 摘要质量闭环：接收方对 digest 打分 → 模板优化。
```

**评分点**:
- 摘要四要素（问题/已尝试/情绪/上下文）+质量评分闭环。
- 接收方确认（不空中转）+失败回退原客服。
- 转接期间消息缓存与补发（不丢）。
- 客户知情提示。
