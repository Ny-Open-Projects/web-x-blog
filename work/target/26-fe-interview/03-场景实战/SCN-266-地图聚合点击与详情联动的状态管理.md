## SCN-266：地图页的列表-地图双向联动（点列表定位地图、拖地图刷列表），状态怎么管理？

**答**:
- 联动模型：单一事实源（selectedId + viewport + dataSource），列表与地图都是视图（点列表项→selectedId 变更→地图 panTo+marker 高亮；点 marker→列表滚动到对应项+详情卡弹出）。
- 视野变化与列表刷新：地图拖动→视野变化→防抖 500ms 按新 bbox 拉列表数据（"在此区域搜索"模式避免拖动即刷——用户拖动观察时不想列表乱跳，显式按钮或停止拖动后自动）。
- 状态一致性：selectedId 的双向高亮（列表项滚动 intoView 用 scrollIntoView({block:'nearest'}) 不跳动）、视野变化时选中项可能出视野（保持选中+指示"已移出视野，点击回位"）。
- 性能：联动更新最小化（只更新高亮 marker 与列表滚动位置，不整列表重渲）、防循环（地图事件触发列表更新又触发地图事件——事件来源标记 guard）。

```javascript
const store = createStore({ selectedId: null, bbox: null });
function selectItem(id, { from }) {
  store.set({ selectedId: id });
  if (from !== 'map') map.panTo(posOf(id), { markerHighlight: true });
  if (from !== 'list') scrollToItem(id);     // nearest 不跳动
}
map.on('moveend', debounce(async () => {
  const bbox = map.getBounds();
  if (sameArea(store.bbox, bbox)) return;    // 防循环 guard
  store.set({ bbox });
  const items = await fetchByBbox(bbox);
  listStore.set(items);                      // "在此区域搜索"按钮
}, 500));
```
