## SCN-379：协作模板中心（模板库/变量填充/自定义模板）怎么实现？

**答**:
- 模板体系：模板类型（文档模板：周报/PRD/复盘；表格模板：排期/预算——模板=骨架+占位变量+示例内容），模板 schema（占位变量协议：{{owner}}/{{date}}——使用时填充），模板分类与搜索（SCN-296 搜索复用）。
- 使用流程：选模板→创建副本（模板只读+副本可编辑——模板与实例分离）→变量填充向导（占位变量逐个填写——必填校验）→进入编辑；模板更新不影响已创建实例（实例锁定模板版本）。
- 自定义模板：从现有文档沉淀模板（文档→存为模板：清空内容保留结构+设置占位）、部门模板管理（模板审核/部门可见范围——SCN-225 权限复用）、模板版本（模板迭代——老实例不受影响）。
- 智能填充：上下文自动填充（周报模板自动填本周任务/姓名日期——SCN-376 数据联动）、AI 生成初稿（模板+要点→AI 填充初稿——AGT-341 复用）。

```javascript
async function useTemplate(tplId, vars) {
  const tpl = await template.get(tplId);    // 只读模板
  const missing = tpl.vars.filter(v => !vars[v.name]);
  if (missing.length) return fillWizard(missing); // 变量向导
  const doc = await createFrom(tpl, vars);  // 副本实例
  autoFill(doc, { owner: me, date: today(),
    tasks: thisWeekTasks() });              // 上下文填充
  return doc;
}
```
