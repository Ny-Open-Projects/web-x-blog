## SCN-576：验证组件安全自测怎么做？
**答**：
- 攻击面清单：跳过验证直调业务接口（服务端必须校验 token）、token 重放、challenge 复用、伪造判定响应（防前端信任本地结果）、轨迹重放、低频慢速绕过频控。
- 自动化测试：安全用例进 CI——「不带 token 请求业务接口必须 403」「同一 token 消费两次必须第二次失败」。
- 红队演练：每季度模拟黑产路径（脚本 + 无头浏览器）实测拦截率，输出报告驱动改进。
- 依赖安全：SDK 依赖审计（SCN-依赖治理联动）、CDN 资源 SRI 校验、配置下发签名校验。
- 追问钩子：前端能测出来的核心结论是什么——凡是「前端判断决定放行」的设计都是漏洞，测试要证明服务端闭环。

```javascript
// 安全用例（CI 执行）
test('业务接口拒绝无 token 请求', async () => {
  const res = await api.post('/pay', { orderId: 'o1' });      // 不带 riskToken
  expect(res.status).toBe(403);
});
test('token 一次性', async () => {
  const { token } = await passVerify('pay');
  await expect(api.post('/pay', { riskToken: token })).resolves.toBeTruthy();
  await expect(api.post('/pay', { riskToken: token }))
    .rejects.toMatchObject({ code: 'TOKEN_USED' });            // 重放被拒
});
test('challenge 不可复用', async () => {
  const c = await api.post('/risk/challenge', { scene: 'pay' });
  await expect(api.post('/risk/challenge', { scene: 'pay', nonce: c.nonce }))
    .rejects.toMatchObject({ code: 'NONCE_DUP' });
});
```
