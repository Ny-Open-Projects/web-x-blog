## SCN-516：账户冻结/限制状态的前端呈现怎么做？
**答**：
- 限制分级：账户可能部分受限（只收不付/只付不收/禁止提现），用服务端下发的 restrictList 精确控制对应入口按钮 disable + 说明文案，不做「一刀切封页」。
- 全局拦截：受限状态下所有交易入口统一走守卫（路由级 + 按钮级双层），点击被拦截时弹出原因与解除指引（如「完成实名认证」）。
- 客服通道：冻结页固定挂载申诉/客服入口与工单进度，减少用户焦虑与重复来电。
- 状态时效：限制状态带生效时间戳与复核时间；每次进入页面拉取最新状态，本地不缓存旧结论。
- 追问钩子：部分受限时余额还能看吗——看资产不看交易是常见产品决策，由 restrictList 细分控制。

```javascript
const RESTRICT_BLOCK = {
  NO_PAY:   ['transfer', 'consume'],
  NO_IN:    ['recharge'],
  NO_WITHDRAW: ['withdraw'],
};
function useAccountGuard(account) {
  const blocked = useMemo(() =>
    new Set(account.restrictList.flatMap(r => RESTRICT_BLOCK[r] || [])), [account]);
  return {
    can: (action) => !blocked.has(action),
    guard: (action, fn) => (...args) =>
      blocked.has(action) ? showRestrictReason(account) : fn(...args),
  };
}
```
