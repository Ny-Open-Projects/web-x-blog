## SCN-825：跨端历史同步怎么做？
**答**：
- 同步模型：搜索历史写入服务端历史服务（带设备与时间戳），各端拉取合并（本地缓存 + 服务端权威，冲突按时间戳合并去重）。
- 增量同步：每端持 lastSyncId，拉增量不拉全量；删除操作双向传播（PC 删了一条，手机也要消失）。
- 隐私一致性：无痕模式的搜索不进历史服务（全端一致）；敏感类目历史全端折叠。
- 冲突策略：同词多端重复去重取最新时间；删除与新增并发时删除胜（用户意图优先）。
- 追问钩子：为什么删除要胜过新增——用户明确删除表达「不想再看到」的意图，跨端同步把它弄回来会严重伤害信任；冲突规则要符合用户心理预期。

```javascript
async function syncHistory(lastSyncId) {
  const delta = await api.get('/history/sync', { params: { since: lastSyncId } });
  const local = await historyStore.all();
  const merged = mergeDelta(local, delta, {
    dedupe: (a, b) => sameQuery(a, b), keep: 'latest-ts',
    deleteWins: true,                                  // 删除胜过新增
  });
  await historyStore.replaceAll(merged);
  return delta.nextSyncId;
}
```
