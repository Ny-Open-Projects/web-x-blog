## SCN-454：手写看板协同拖拽：乐观移动、冲突回弹、他人拖拽实时预览

**需求与边界**：
- 输入：拖拽事件、远端移动事件；输出：看板状态一致。
- 边界要求：① 本地拖拽乐观移动（立即生效）；② 服务端冲突（他人已移动）→回弹+提示；③ 他人拖拽的实时跟随动画（拖拽中 live position）；④ 列计数实时更新。

**答**：
```javascript
class KanbanSync {
  async onDrop(cardId, toCol, index) {
    const prev = snapshotBoard();              // 回滚快照
    optimisticMove(cardId, toCol, index);      // 乐观移动
    try {
      await api.move({ cardId, toCol, index,
        version: cardVersion(cardId) });       // 乐观锁
    } catch (e) {
      if (e.code === 'CONFLICT') {             // 他人已移动
        restore(prev);                         // 回弹
        toast(`卡片已被 ${e.by} 移动`);
        resyncCard(cardId);
      }
    }
  }
  onRemoteDrag({ cardId, pos }) {              // 他人拖拽预览
    floatCard(cardId, pos);                    // 跟随动画
  }
  onRemoteDrop({ cardId, toCol, index }) {
    clearFloat(cardId);
    commitMove(cardId, toCol, index);          // 落定
    updateCounts();                            // 列计数徽标
  }
}
// 乐观锁 version：服务端 CAS 失败→CONFLICT。
// 拖拽中信令 30ms 节流（SCN-445 白板同源）。
// 字段并发：详情字段 last-write+双方通知（SCN-294）。
```

**评分点**:
- 乐观移动+快照回弹（CONFLICT 时恢复原状+提示）。
- 乐观锁 version（服务端 CAS）防并发覆盖。
- 他人拖拽实时预览（float+落定两阶段信令）。
- 列计数联动更新。
