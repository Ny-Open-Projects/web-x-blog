## SCN-1290：手写一个合规价签生成器（各国划线价法规）

**答**：
- 需求：implement PriceTag(country, lowest30d)。render(current) 按法规生成价签：欧盟划线价必须为 30 天最低价（不合规标 warning）；美国可自由标注划线价（标 MRP）；日本需标"参考价格"。
- 边界：lowest30d 缺失欧盟标无法验证；current > 划线价（涨价）不显示划线；输出含合规字段。
- 评分点：欧盟 Omnibus；缺数据预警；日本参考价；涨价

```javascript
class PriceTag {
  constructor(country, lowest30d) {
    this.country = country; this.low = lowest30d;
  }
  render(current) {
    if (this.country in EU) {
      if (this.low == null)
        return { strike: null, warning: '缺 30 天最低价数据，无法合规展示' };
      if (current >= this.low) return { strike: null };
      return { current, strike: this.low, legal: true,
        basis: '30 天最低价（Omnibus）' };
    }
    if (this.country === 'JP' && this.low)
      return { current, strike: this.low, label: '参考价格' };
    return { current, strike: this.low, label: 'MRP' };
  }
}
const EU = { DE: 1, FR: 1, NL: 1 };
```
