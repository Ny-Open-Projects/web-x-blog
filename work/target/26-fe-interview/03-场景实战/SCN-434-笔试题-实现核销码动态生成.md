## SCN-434：手写核销码：短时有效签名码、离线缓存兜底、截屏提醒

**需求与边界**：
- 输入：voucherId；输出：动态核销二维码。
- 边界要求：① 码短时有效（60s 签名时间窗——截图盗用失效）；② 弱网门店离线兜底（缓存码+时效窗口）；③ 到期自动刷新；④ 截屏检测提示。

**答**：
```javascript
class VoucherCode {
  constructor(voucherId) { this.id = voucherId; }
  async current() {                            // 动态码（60s 窗）
    const payload = { vid: this.id,
      win: Math.floor(Date.now() / 60000) };   // 时间窗签名
    const signed = await api.sign(payload)     // 服务端签名
      .catch(() => this.cached?.());           // 离线兜底：缓存码
    this.cache(signed);
    return renderQR(signed);                   // 二维码含 sig+win
  }
  cache(signed) {                              // 离线缓存
    this.cached = () => signed;                // 窗口内可用
    setTimeout(() => this.cached = null, 60000);
  }
  autoRefresh() {                              // 到期自动刷新
    this.timer = setInterval(() => this.current(), 55000);
    return () => clearInterval(this.timer);
  }
}
// 校验（商家端）：验签 + 时间窗校验
//   → 通过核销 → 状态流转推送用户端。
// 离线语义：缓存码窗口内有效（服务端对账容忍窗口）；
// 截屏：screenshotDetect() && toast('请勿泄露核销码')。
```

**评分点**:
- 短时签名时间窗（60s）+ 自动刷新，截图盗用失效。
- 离线兜底：缓存签名码（窗口内可用，服务端对账容忍）。
- 到期自动刷新与清理接口（定时器不泄漏）。
- 商家端验签+时间窗校验的闭环意识。
