## SCN-442：手写会议布局引擎：按人数/发言/共享自动切换布局模板

**需求与边界**：
- 输入：参会者列表（音量/视频开关）、共享状态、手动 pin；输出：布局方案。
- 边界要求：① 模板选择规则（人数→宫格行列数、共享→大屏+小条、发言→聚焦）；② 手动 pin 优先于自动；③ 切换过渡动画；④ TV 端宫格上限降级。

**答**：
```javascript
function layoutEngine({ members, sharing, pin, speaking, platform }) {
  if (pin) return template('focus', [pin]);    // 手动 pin 最优先
  if (sharing) return template('share',        // 共享大屏+人像条
    { sharee: sharing.owner, strip: members });
  const active = members.filter(m => m.videoOn);
  if (speaking && active.length > 4)
    return template('focus', [speaking]);      // 说话者聚焦
  // 宫格：按人数选行列
  const grid = platform === 'tv'
    ? gridFor(Math.min(active.length, 9))      // TV 上限 9
    : gridFor(active.length);
  return template('grid', { cells: active, grid });
}
const gridFor = (n) => n <= 1 ? [1, 1]
  : n <= 4 ? [2, 2] : n <= 9 ? [3, 3] : [4, 4];
// 切换过渡：layout 变化 → FLIP 动画（位置过渡不跳变）。
// 音量驱动：audioLevel > threshold → speaking 变更 →
//   自动 focus 模式重算（防抖：说话切换 1s 内不重排）。
```

**评分点**:
- 模板优先级正确：pin > 共享 > 说话聚焦 > 宫格。
- 说话驱动聚焦带防抖（1s 内不重排防闪烁）。
- TV 端宫格上限降级（平台约束）。
- FLIP 过渡动画（布局切换不跳变）。
