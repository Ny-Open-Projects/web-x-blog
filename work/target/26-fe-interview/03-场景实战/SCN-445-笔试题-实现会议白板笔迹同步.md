## SCN-445：手写白板笔迹同步：30ms 打包、坐标量化压缩、三层渲染分离

**需求与边界**：
- 输入：本地笔迹事件、远端笔迹包；输出：白板渲染。
- 边界要求：① 本地笔迹立即渲染（零延迟）+30ms 打包广播；② 坐标量化整数+差分编码（包体压缩）；③ 三层分离（完成层缓存/远端预览层/本地层）；④ 视口裁剪与脏矩形重绘。

**答**：
```javascript
class Whiteboard {
  constructor(canvas) {
    this.layers = { done: cacheLayer, preview: liveLayer,
      local: myLayer };
    this.buf = [];
    pen.on('move', (p) => {                    // 本地零延迟
      this.local.draw(p);
      this.buf.push(quantize(p));              // 量化取整
    });
    pen.on('move', throttle(() => {            // 30ms 打包
      ws.send('stroke', diff(this.buf));       // 差分编码压缩
      this.buf = [];
    }, 30));
  }
  onRemote(pkg) {                              // 远端预览层
    const pts = unquantize(diffReverse(pkg));
    this.preview.draw(pts);
  }
  onStrokeEnd(stroke) {                        // 完成→正式层
    this.preview.clear();
    this.done.addElement(stroke);              // CRDT 元素
    this.invalidate(bbox(stroke));             // 脏矩形重绘
  }
  invalidate(rect) {                           // 脏矩形重绘
    this.done.repaint(rect);                   // 只重绘变化区
  }
}
const quantize = (p) => ({ x: Math.round(p.x), y: Math.round(p.y) });
const diff = (pts) => pts.map((p, i) => i === 0 ? p
  : { dx: p.x - pts[i - 1].x, dy: p.y - pts[i - 1].y }); // 差分
```

**评分点**:
- 本地零延迟渲染 + 30ms 打包节流（双节奏正确）。
- 量化取整+差分编码（包体压缩）。
- 三层分离（完成层缓存/远端预览/本地）各独立刷新。
- 脏矩形重绘与完成层缓存（性能）。
