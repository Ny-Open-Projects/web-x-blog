## SCN-766：防疲劳机制怎么设计？
**答**：
- 强制休息：连续审核 N 条或 M 分钟强制休息提示（服务端配合暂停派单 5 分钟），尤其高危品类（暴恐/血腥）轮换频率更高。
- 品类轮换：高危品类审核任务与普通任务按比例穿插（心理健康保护），排班系统控制单人高危暴露时长。
- 前端呈现：疲劳计数器（今日已审 X 条）+ 休息倒计时；休息期间队列锁定不派单。
- 效率联动：疲劳时段质检加权（疲劳期准确率下降是规律），质检抽检比例按时段动态调整。
- 追问钩子：为什么防疲劳是审核质量的一部分——疲劳直接导致漏杀与误杀率上升，且涉及员工身心健康合规；技术上暂停派单是唯一可强制执行的手段。

```javascript
const fatiguePolicy = {
  highRiskCategory: { maxContinuous: 50, breakMin: 10, rotateEvery: '2h' },
  normal: { maxContinuous: 120, breakMin: 5 },
  enforce: async (auditor) => {
    const stats = await workload.today(auditor);
    if (stats.continuous >= policy.maxContinuous) {
      pauseDispatch(auditor, policy.breakMin);       // 服务端暂停派单（可强制）
      client.showBreakCountdown(policy.breakMin);
    }
  },
};
```
