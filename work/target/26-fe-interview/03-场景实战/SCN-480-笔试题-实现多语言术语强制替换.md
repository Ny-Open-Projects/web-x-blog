## SCN-480：手写翻译术语控制：术语表注入翻译、译文一致性校验、违规标红

**需求与边界**：
- 输入：术语表（源语→译语）、译文；输出：校验结果。
- 边界要求：① 翻译时术语表注入（prompt/MT 参数——AGT-381 复用）；② 译后校验（术语在译文中是否正确出现）；③ 违规标红+建议替换；④ 术语版本化（术语表更新→旧译文复查清单）。

**答**：
```javascript
class GlossaryGuard {
  constructor(glossary) { this.glossary = glossary; } // [{src, dst}]
  inject(text) {                               // 翻译前注入
    return { text,
      terms: this.glossary.filter(g => text.includes(g.src)) };
  }
  validate(srcText, translated) {              // 译后校验
    const issues = [];
    for (const g of this.inject(srcText).terms) {
      if (!translated.includes(g.dst))
        issues.push({ src: g.src, expected: g.dst,
          found: findSimilar(translated, g.dst),
          suggestion: `请使用术语「${g.dst}」` });
    }
    return { pass: issues.length === 0, issues };   // 违规标红
  }
  onGlossaryUpdate(diff) {                     // 术语表更新
    return affectedParagraphs(diff.srcs)       // 影响面
      .map(p => ({ p, action: 'revalidate' }));  // 复查清单
  }
}
// 术语表版本化：v2 更新 → 旧译文按 diff.srcs 复查
//   （增量复查非全量——SCN-477 影响面复用）。
// MT 注入：术语表进翻译参数（AGT-381 术语本地化复用）。
```

**评分点**:
- 术语注入（翻译前筛选命中术语）+译后校验闭环。
- 违规标红带建议替换（可操作）。
- 术语表版本化更新→增量复查清单（影响面复用）。
- findSimilar 模糊匹配（译法变体检测）。
