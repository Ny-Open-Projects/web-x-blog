## SCN-597：手写自动化环境检测器

**需求与边界**：
- 需求：检测 webdriver/无头/CDP 等特征，输出「弱证据分」而非布尔判断（避免误伤）；每个检测项独立 try-catch；输出分数与明细供服务端参考。
- 边界：① 任何单检测异常不影响其他；② 分数 = 命中信号权重和；③ 阈值判断只做日志提示，不做拦截。

**答**：
```javascript
const DETECTORS = [
  { name: 'webdriver', weight: 0.4,
    run: () => navigator.webdriver === true ? 1 : 0 },               // 显式标志，强信号
  { name: 'plugins-empty', weight: 0.15,
    run: () => navigator.plugins.length === 0 ? 1 : 0 },             // 无头常见，弱信号
  { name: 'langs-missing', weight: 0.15,
    run: () => !navigator.languages || navigator.languages.length === 0 ? 1 : 0 },
  { name: 'permissions-inconsistent', weight: 0.2,
    run: async () => {
      const p = await navigator.permissions.query({ name: 'notifications' });
      return p.state === 'denied' && Notification.permission === 'default' ? 1 : 0;  // CDP 痕迹
    } },
  { name: 'ua-headless', weight: 0.3,
    run: () => /HeadlessChrome/i.test(navigator.userAgent) ? 1 : 0 },
];
async function automationScore() {
  const details = [];
  let score = 0, total = 0;
  for (const d of DETECTORS) {
    let hit = 0;
    try { hit = await d.run(); } catch { hit = 0; }   // 单项异常不影响整体
    details.push({ name: d.name, hit });
    total += d.weight;
    if (hit) score += d.weight;
  }
  const normalized = total ? score / total : 0;
  if (normalized > 0.5) report({ type: 'AUTOMATION_SUSPECT', score: normalized, details }); // 仅上报
  return { score: normalized, details };              // 不做拦截，交给服务端决策
}
```

**评分点**:
- 弱证据加权分数而非布尔判断（防误伤意识）。
- 每项独立 try-catch（检测自身异常安全）。
- 只上报不拦截（决策权在服务端）。
- 信号强弱分级（webdriver 0.4 vs plugins 0.15）。
