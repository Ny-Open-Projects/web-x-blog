## SCN-277：直播礼物（发送/全屏动效/打赏榜）的实现要点？

**答**:
- 礼物发送：礼物面板（余额/充值入口/礼物分类），发送流程（选择数量→余额校验→支付确认（余额不足引导充值）→发送请求→信令广播动效），连送（按住连发：客户端本地计数+结束统一结算——减少请求）。
- 动效体系：小礼物（弹幕区滚动+图标动画）、豪华礼物（全屏 SVGA/Lottie 动效——动效文件预载：开播时下载缓存）、动效队列（多个全屏礼物排队播放，可跳过）、 SVGA 优先（比 Lottie 兼容好体积小）。
- 打赏榜单：贡献榜实时更新（信令聚合：增量更新榜单）、榜单动画（排名变化过渡）、礼物值聚合（PK 场景双方礼物值实时对比条）。
- 洪峰与降级：豪华礼物洪峰排队（同时 5 个全屏动效→队列串行+可设置"仅看最高档"）、低端机关闭全屏动效（保留消息）、动效资源按需下载+本地缓存版本管理。

```javascript
async function sendGift(gift, count) {
  const r = await giftApi.send({ giftId: gift.id, count,
    idempotencyKey: uid() });
  if (r.ok) localEcho(gift, count);          // 本端立即动效
}
ws.on('gift', (g) => {
  g.luxury ? effectQueue.push(g)             // 豪华：队列播放
    : danmakuZone.show(g);                   // 普通：弹幕区
});
effectQueue.onPlay = (g) => playSVGA(g.animUrl);  // 预载缓存
// 连送：pointerdown 计数 + pointerup 统一 sendGift(count)。
// 洪峰：队列长度>3 → 跳过中档礼物只播高档。
```
