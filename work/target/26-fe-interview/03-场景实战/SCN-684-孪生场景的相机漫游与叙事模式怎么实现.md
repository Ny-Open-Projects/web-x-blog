## SCN-684：相机漫游与导览叙事怎么实现？
**答**：
- 叙事编排：导览 = 关键帧序列（相机位置/朝向/时长/旁白/高亮目标），JSON 编排可配置；播放时相机沿 CatmullRom 曲线插值，同步高亮对应设备与字幕。
- 手动接管：用户交互（拖拽/点击）立即中断漫游进入自由模式，闲置 N 分钟恢复自动漫游——参观与操作两种模式平滑切换。
- 帧率友好：相机插值在渲染循环内做（每帧算位置），关键帧切换用 ease；旁白与字幕数据预载。
- 多导览脚本：不同访客（领导参观/日常值守）不同脚本，入口切换。
- 追问钩子：漫游时数据更新还继续吗——继续（漫游只是视角），但漫游目标设备的高亮优先级最高，避免告警飞行打断导览。

```javascript
const tourScript = [
  { cam: { from: p1, to: p2, lookAt: b1 }, duration: 8,
    highlight: 'building-A', caption: 'A 楼能耗看板' },
  { cam: { from: p2, to: p3, lookAt: dev1 }, duration: 6,
    highlight: 'device-101', caption: '重点设备实时温度' },
];
function createTour(script, camera) {
  const curve = new THREE.CatmullRomCurve3(script.map(s => s.cam.to));
  let i = 0, t0 = 0, manual = false;
  function step(now) {
    if (manual) return;                            // 用户接管暂停
    const seg = script[i], p = (now - t0) / (seg.duration * 1000);
    camera.position.lerpVectors(seg.cam.from, seg.cam.to, easeInOut(Math.min(1, p)));
    camera.lookAt(seg.cam.lookAt);
    if (p >= 1) { i = (i + 1) % script.length; t0 = now; }
    requestAnimationFrame(step);
  }
  const takeOver = () => { manual = true; scheduleIdleResume(); };
}
```
