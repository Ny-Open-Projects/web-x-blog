## SCN-762：批量审核怎么设计？
**答**：
- 批量场景：同一创作者连续投稿/同模板批量生成的相似内容——聚合成批次展示（缩略图墙 + 抽样播放），审核员判定代表样本后批量套用。
- 批量风险控制：批量套用前展示影响清单（将处置 N 条，列出关键样本）；单条可剔除（批量决策中例外）；批量操作幂等键防重复提交。
- 误杀恢复：批量处置支持「批量申诉」入口；发现批量误杀（标准误判）可一键撤销该批次并通知创作者。
- 相似度辅助：按内容指纹（感知哈希）聚合相似视频，而非按时间——模板批量生产的内容天然聚合。
- 追问钩子：为什么批量不能直接全选套用——相似 ≠ 相同（模板中插一帧违规），批量决策必须抽样确认 + 例外剔除，否则批量误杀是灾难级。

```javascript
async function batchReview(batchId, verdict, { excludeIds = [], sampleIds } = {}) {
  const impact = await api.get(`/batch/${batchId}/impact`, { params: { excludeIds } });
  confirmDialog({ content: `将处置 ${impact.count} 条，样本 ${sampleIds.map(s => s.thumb)}`,
    onOk: () => api.post(`/batch/${batchId}/apply`, {
      verdict, excludeIds,
      idempotencyKey: `batch-${batchId}-${Date.now()}`,     // 幂等
      samples: sampleIds,                                   // 抽样确认记录
    }) });
}
async function revertBatch(batchId, reason) {          // 批量误杀撤销
  const r = await api.post(`/batch/${batchId}/revert`, { reason });
  await notifyCreators(r.affected, 'reverted+compensation');
}
```
