## SCN-613：审批草稿与自动保存怎么设计？
**答**：
- 自动保存：输入停顿 3s 或失焦触发保存（防抖 + 变脏检测，未变化不保存）；保存显示时间戳「已自动保存 12:30:45」；离线时本地暂存，恢复后合并。
- 冲突策略：草稿级冲突用「后写覆盖 + 前值快照提示」（草稿阶段可接受简单策略，不必上 CRDT）；审批提交阶段才需要强一致（version 乐观锁）。
- 数据分离：草稿（未提交数据，可丢）与审批记录（已提交，不可变）严格分开存储；提交成功即删草稿。
- 附件与富文本：草稿含附件引用（上传即存，不随草稿删除物理文件，保留期后清理）。
- 追问钩子：自动保存会不会把半成品提交上去——草稿保存与提交是两个接口两种语义，schema 校验只在提交时强制。

```javascript
function useAutoSave(form, saveApi, { delay = 3000 } = {}) {
  const dirty = useRef(false), timer = useRef();
  const onChange = () => { dirty.current = true; debounceSave(); };
  const debounceSave = () => {
    clearTimeout(timer.current);
    timer.current = setTimeout(async () => {
      if (!dirty.current) return;
      const { savedAt, conflict } = await saveApi(form.snapshot());
      if (conflict) showDraftConflict(conflict);   // 前值快照提示
      else setSavedAt(savedAt);
      dirty.current = false;
    }, delay);
  };
  useEffect(() => () => clearTimeout(timer.current), []);   // 卸载清定时器
  return { onChange, savedAt };
}
```
