## SCN-384：坐席辅助（回复推荐/SOP 推送/话术库）怎么实现？

**答**:
- 回复推荐：意图识别→推荐回复（客户问题→知识库检索→推荐答案草稿——AGT-384 坐席辅助复用），推荐呈现（输入框上方推荐卡：一键插入可编辑——AI 是助手 SCN-348 同款边界）、采纳率埋点（低采纳推荐下线——SCN-483 闭环）。
- SOP 推送：上下文 SOP（工单类型→相关 SOP 自动推送——AGT-310 知识库复用）、SOP 内嵌操作（SOP 步骤可执行：跳转退款页/发起补偿——流程化 SOP）。
- 话术库：常用话术（个人+团队两级话术库，快捷短语/宏：带变量填充——订单号自动代入）、快捷键触发、话术治理（团队话术审核——SCN-321 资产复用）。
- 边界：推荐不代发（客服确认发送——责任在人）、推荐的学习（采纳的推荐成为高频话术——数据回流）。

```javascript
// 意图→推荐
ws.on('customer_msg', async (m) => {
  const intent = await classify(m.text);
  const rec = await kbSuggest(intent, { order: ctx.order });
  showSuggestion(rec.map(r => ({
    ...r, insert: () => compose(r.text
      .replace('{{orderNo}}', ctx.order.id)) })));  // 宏变量
});
// SOP：intent → sopOf(intent) → 侧栏 SOP 卡（可执行步骤）
// 话术宏：'/refund' → 话术模板 + 订单号代入。
// 采纳率 → track → 低频推荐下线。
```
