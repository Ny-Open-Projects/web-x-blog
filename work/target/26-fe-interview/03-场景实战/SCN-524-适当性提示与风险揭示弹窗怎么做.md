## SCN-524：适当性提示与风险揭示弹窗怎么设计？
**答**：
- 合规不可绕过：风险揭示必须真实阅读——滚动到底 + 停留时长校验 + 勾选确认 + 记录阅读时长，四要素齐全才能继续；不做「点 X 关闭即同意」。
- 适当性分级：用户风险等级与产品等级不匹配时，展示匹配度警告并要求二次确认，超限购买直接阻断并引导重新测评。
- 版本与证据：协议文本带版本号，同意记录（版本/时间/端）由服务端落库；前端只上报，不自行判断合规性。
- 频控：同类揭示有展示频次策略（如每日一次），频控由服务端下发，前端记录已读状态。
- 追问钩子：用户跳过 15 秒倒计时怎么办——倒计时结束前确认按钮 disable，且脚本滚动检测到未滚动到底则重置。

```javascript
function RiskDisclose({ doc, onAccept }) {
  const [readDone, setReadDone] = useState(false);
  const [seconds, setSeconds] = useState(15);
  useEffect(() => { const t = setInterval(() => setSeconds(s => Math.max(0, s - 1)), 1000); return () => clearInterval(t); }, []);
  const onScroll = e => {
    const el = e.target;
    if (el.scrollTop + el.clientHeight >= el.scrollHeight - 4) setReadDone(true); // 阅读到底
  };
  const canAccept = readDone && seconds === 0;   // 滚到底 + 停留时长
  return (
    <Modal>
      <div className="doc" onScroll={onScroll}>{doc.text}</div>
      <Checkbox disabled={!canAccept}>我已阅读并理解风险</Checkbox>
      <Button disabled={!canAccept} onClick={() => onAccept(doc.version, Date.now() - t0)}>继续</Button>
    </Modal>
  );
}
```
