## SCN-856：倒计时同步怎么做？
**答**：
- 服务器时间为准：页面加载时获取服务器时间并计算偏移量（本地时间 + offset），倒计时基于偏移后时间推算——本地时钟不可信（用户可改）。
- 开抢瞬间判定：到达 startTime 不立即解锁——「预备态」提前 5s 预加载资源（购买接口预热/资源加载），到点切换按钮态；服务端才是开抢权威（前端提前点击会被拒绝）。
- 倒计时 UI：分钟级精度够用（毫秒跳动引发焦虑+无意义刷新），到点前 3s 停止毫秒显示只保留「即将开始」。
- 多活动并发：多场秒杀倒计时统一时钟管理器（一个 rAF 驱动多个 deadline），避免多个 setInterval。
- 追问钩子：为什么前端提前 5 秒预备——开抢瞬间是资源峰值（图片/接口/JS 全部同时请求），预备态把资源加载前置到峰值前，抢购点击瞬间只剩一个接口请求。

```javascript
function createCountdowns(serverOffsetMs) {
  const items = new Map();                             // id -> {start, onReady}
  let prepared = false;
  function register(id, startTs, onReady) { items.set(id, { startTs, onReady }); }
  function tick() {
    const now = Date.now() + serverOffsetMs;           // 服务器时间推算
    for (const [id, it] of items) {
      const left = it.startTs - now;
      render(id, left <= 0 ? 'OPEN' : left < 3000 ? 'IMMINENT' : fmt(left));
      if (left <= 5000 && left > 0 && !prepared) {     // 预备态：前置加载
        prepared = true;
        prefetchBuyResources(id);
      }
      if (left <= 0) { it.onReady(); items.delete(id); }
    }
    requestAnimationFrame(tick);
  }
  tick();
}
```
