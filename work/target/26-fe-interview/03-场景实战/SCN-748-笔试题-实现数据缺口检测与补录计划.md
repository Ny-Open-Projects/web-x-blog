## SCN-748：手写数据缺口检测器

**需求与边界**：
- 需求：给定期望粒度的时间序列与管道健康记录；检测缺口（连续缺失时段），缺口按「管道故障（排除）」与「可补录」分类；输出补录任务列表。
- 边界：① 缺口合并相邻缺失点（不逐点报）；② 管道故障时段（上报 QPS 归零）内的缺口排除；③ 输出保留缺口时长的统计。

**答**：
```javascript
function detectGaps(series, pipelineHealth, { expectedMs = 60_000 } = {}) {
  const gaps = [];
  let missing = null;
  for (let t = series.start; t < series.end; t += expectedMs) {
    const has = series.points.some(p => p.t === t);
    if (!has && missing === null) missing = t;
    if (has && missing !== null) { gaps.push({ start: missing, end: t }); missing = null; }
  }
  if (missing !== null) gaps.push({ start: missing, end: series.end });   // 尾部缺口
  const tasks = [], excluded = [];
  for (const g of gaps) {
    if (pipelineHealth.downAt(g.start, g.end)) excluded.push(g);   // 管道故障：排除不计入 SLA
    else tasks.push({ ...g, action: 'backfill', reason: 'collector-gap' });
  }
  return {
    tasks, excluded,
    stats: { gapCount: gaps.length,
             totalMs: gaps.reduce((s, g) => s + g.end - g.start, 0) },
  };
}
```

**评分点**:
- 缺口检测合并连续缺失点（非逐点噪音）。
- 管道故障时段排除（SLA 不背采集锅）。
- 尾部缺口兜底。
- 统计输出（缺口数/总时长）供容量评估。
