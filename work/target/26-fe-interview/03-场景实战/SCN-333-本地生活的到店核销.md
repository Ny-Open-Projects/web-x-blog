## SCN-333：到店团购（买券→出示核销→退款）的闭环怎么设计？

**答**:
- 购买与券管理：团购券购买（SCN-209 支付复用）、券包管理（待使用/已使用/已过期——有效期提醒推送）、券详情（核销码动态刷新——防截图盗用：二维码带时间戳签名短时有效）。
- 到店核销：出示核销码（离线可用：本地缓存的签名码——弱网门店场景）、离线核销码有效性（时效签名：离线生成的码带时间窗，服务端事后对账）、商家扫码核销→券状态流转实时回推。
- 退款流程：未使用随时退（自助退款 SCN-282 状态机复用）、已过期自动退（策略配置）、部分核销（多券套餐部分使用）。
- 体验细节：附近核销门店（地图 SCN-261 复用）、核销码亮度与截屏提醒（截屏检测提示"请勿泄露核销码"）、过期前提醒（提前 3 天推送）。

```javascript
// 核销码：短时签名
async function showVoucher(voucherId) {
  const code = await voucherApi.qr(voucherId);  // 带时间窗签名
  renderQR(code, { refresh: 60e3 });            // 60s 自动刷新
}
// 离线兜底：lastSignedCode 缓存（有效期窗口内可出示），
//   恢复网络后对账。
// 过期：schedule(expireAt - 3d) → push 提醒；
// 未用随时退：refundFlow(voucher)（SCN-282 状态机）。
// 截屏：screenshotDetect() && toast('请勿泄露核销码')。
```
