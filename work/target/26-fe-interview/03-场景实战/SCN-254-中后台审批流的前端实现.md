## SCN-254：审批流（多级/会签/驳回重提）的前端怎么实现？

**答**:
- 审批流数据模型：流程实例（当前节点/历史轨迹/状态），节点类型（审批/会签/或签/抄送），前端渲染审批进度条（节点时间线：已完成/当前/待达，含每节点处理人与意见）。
- 操作与状态：同意/驳回/转交/加签/撤回，驳回模式（驳回到发起人/驳回到上一节点/驳回任一节点——影响重提路径）、重提后流程恢复到驳回点（不从头走）。
- 待办中心：我的待办聚合（多流程类型统一列表）、代办催办（超时未处理提醒）、代理审批（请假期间委托）。
- 前端实现要点：流程图渲染（节点图可视化：状态着色）、表单只读态（流程中表单不可改，驳回重提才解锁）、操作幂等（并发点同意——服务端状态机裁决，前端按钮防重复）。

```javascript
// 审批时间线
const FlowTimeline = ({ instance }) => (
  <Steps>
    {instance.nodes.map(n => (
      <Step key={n.id} status={stepStatus(n, instance.current)}
        title={`${n.name}·${n.assignee}`}
        description={n.opinion} />))}
  </Steps>);
// 状态着色：done=finish / current=process / pending=wait
// 驳回重提：resubmit → 服务端恢复到 rejectAt 节点
// 操作按钮按权限+节点能力渲染：
//   canApprove(current, me) && <Button onClick={approve}/>
// 并发防护：按钮 loading + 服务端状态机幂等。
```
