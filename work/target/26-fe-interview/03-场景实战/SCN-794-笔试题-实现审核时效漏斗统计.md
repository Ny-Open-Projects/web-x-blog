## SCN-794：手写审核时效漏斗统计

**需求与边界**：
- 输入：事件流 `[{videoId, stage, ts}]`（upload/queued/claimed/verdict/effective）；输出各段 P50/P95 耗时、超 SLA 占比、瓶颈段。
- 边界：① 按视频分组排序事件；② 事件缺失（未领取就取消）标记 dropped 不计入；③ 瓶颈 = 超时占比最大的段。

**答**：
```javascript
const STAGES = ['upload', 'queued', 'claimed', 'verdict', 'effective'];
function latencyFunnel(events, slas) {
  const byVideo = groupBy(events, 'videoId');
  const segs = { 'upload→queued': [], 'queued→claimed': [], 'claimed→verdict': [],
                 'verdict→effective': [] };
  let dropped = 0;
  for (const [id, list] of byVideo) {
    const sorted = list.sort((a, b) => a.ts - b.ts);
    const stages = STAGES.map(s => sorted.find(e => e.stage === s)?.ts);
    if (!stages[STAGES.indexOf('verdict')]) { dropped++; continue; }   // 未完成判定不计入
    for (let i = 0; i < STAGES.length - 1; i++) {
      if (stages[i] != null && stages[i + 1] != null)
        segs[`${STAGES[i]}→${STAGES[i + 1]}`].push(stages[i + 1] - stages[i]);
    }
  }
  const stats = Object.entries(segs).map(([seg, arr]) => ({
    seg,
    p50: quantile([...arr].sort((a, b) => a - b), 0.5),
    p95: quantile([...arr].sort((a, b) => a - b), 0.95),
    overRatio: arr.filter(t => t > slas[seg]).length / (arr.length || 1),
  }));
  return {
    stats, dropped,
    bottleneck: [...stats].sort((a, b) => b.overRatio - a.overRatio)[0]?.seg ?? null,
  };
}
```

**评分点**:
- 按视频分组 + 阶段定位（乱序事件排序修正）。
- 未完成流程 dropped 单独统计（不污染耗时）。
- 分段 P50/P95 + 超 SLA 占比。
- 瓶颈段 = 超时占比最大（可行动定位）。
