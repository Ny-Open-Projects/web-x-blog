## SCN-329：社交个人主页（资料/作品橱窗/隐私控制）怎么整合设计？

**答**:
- 主页信息架构：头区（头像/昵称/简介/关注粉丝赞数/操作按钮：关注或聊天——按关系态变化）、内容区（作品 tab：图文/视频/收藏/喜欢分 tab——隐私态分端可见性）、橱窗区（创作者商品橱窗——SCN-273 商品卡复用）。
- 隐私控制：可见性设置（作品/关注列表/粉丝列表的可见范围：公开/粉丝/仅自己——设置项矩阵），对访客的呈现（受限主页：不可见区块不渲染而非"404"——保留存在感），黑名单屏蔽（被拉黑者视角：不可互动+内容按设置）。
- 编辑体验：资料编辑（头像裁剪上传/背景图/简介字数与敏感词预检——SCN-326 审核联动）、认证标识（认证状态与申请入口）。
- 性能与个性化：主页预载（信息流点击头像——进主页预载，SCN-210 矩阵复用）、资料卡轻弹层（IM 内点头像出资料卡不跳页）。

```javascript
function Profile({ user, viewer }) {
  const vis = privacyOf(user.settings, viewer.relation); // 服务端规则
  return <>
    <Header {...user} action={actionByRelation(viewer.relation)} />
    <Tabs>
      <Works list={filterVisible(user.works, vis)} />
      {vis.fans && <Fans id={user.id} />}    {/* 不可见不渲染 */}
      {user.shop && <Showcase goods={user.goods} />}
    </Tabs>
  </>;
}
// 隐私矩阵：{works: 'public', fans: 'followers'}
// 黑名单视角：blocked → 不可互动按钮隐藏 + 内容按设置
// 预载：feed.on('avatarTap') → prefetchProfile(id)。
```
