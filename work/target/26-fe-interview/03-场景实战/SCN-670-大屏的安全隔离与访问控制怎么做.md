## SCN-670：大屏安全隔离怎么设计？
**答**：
- 大屏特殊性：无人值守、无键盘鼠标、可能物理暴露——不能走交互式登录，用「设备凭证」：每块屏注册 deviceToken（服务端绑定设备指纹/IP/位置），定时轮换。
- 数据最小化：大屏 token 只能订阅其被授权的主题（只读 + 范围限定），不能调用任何写接口；敏感字段在网关层脱敏后下发。
- 网络隔离：大屏设备进 VLAN 隔离区，只开放数据网关端口；页面禁开发者工具提示 + 禁右键（提高成本，非真防线）。
- 离线防泄露：页面缓存不含敏感数据的骨架；断网时显示「数据暂不可用」而非本地缓存明文。
- 追问钩子：deviceToken 泄露怎么办——绑定 IP/MAC 指纹 + 短时效轮换 + 异常订阅模式告警（异地使用立即吊销）。

```javascript
// 大屏设备认证流程
async function bootScreen(deviceId) {
  const { token, expiresIn } = await api.post('/screen/token', {
    deviceId, fingerprint: await deviceFingerprint(),     // 服务端校验设备绑定
  });
  scheduleRenew(token, expiresIn * 0.8);                 // 提前轮换
  gateway.connect({ token, topics: allowedTopics(deviceId) });  // 只读授权主题
}
function allowedTopics(deviceId) {
  return SCREEN_ACL[deviceId].topics;                    // 网关二次校验，前端只声明
}
```
