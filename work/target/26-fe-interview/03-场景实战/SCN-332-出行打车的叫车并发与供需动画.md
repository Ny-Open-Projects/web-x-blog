## SCN-332：叫车等待期（排队/加价引导/找车动画）的供需呈现怎么设计？

**答**:
- 等待期状态：找车动画（雷达扩散/周边车辆游走——动画缓解焦虑但标注"示意"避免误导真实车辆位置）、排队信息（排队第 N 位/预计等待）、超时升级引导（等待超 N 分钟→提示加价/换车型——服务端供需策略下发，前端呈现不编造）。
- 加价交互：加价面板（档位选择/自定义）、加价效果说明（"加价后预计等待 X 分钟"——数据说话）、取消呼叫（随时可取消+已等待时长显示）。
- 应答瞬间的过渡：应答动画（司机信息卡翻出+地图视野切换），双通道冗余（应答信令+轮询兜底——应答是关键时刻不能丢）。
- 洪峰场景：极端天气/高峰的全局排队（排队透明化：真实位置与预计时长、可随时取消）、页面保持唤醒（等待期防息屏——Wake Lock API）。

```javascript
// 等待期
ws.on('queue', (q) => ui.queue(q.position, q.eta));
// 超时升级：after(120e3) → suggestPanel({
//   addPrice: tiers, switchType: options })   // 服务端策略
// 应答双通道：
ws.on('matched', onMatched);
poll(orderId, { until: 'matched', fallback: onMatched });
// 防息屏：navigator.wakeLock.request('screen')
//   （等待期持锁，应答后 10s 释放）。
// 动画标注："周边车辆为示意图"。
```
