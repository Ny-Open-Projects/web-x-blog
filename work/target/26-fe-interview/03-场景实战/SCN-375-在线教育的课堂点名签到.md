## SCN-375：课堂签到（位置签到/口令签到/手势签到）怎么实现？

**答**:
- 签到形态：位置签到（教室定位围栏判定——SCN-263 复用：GPS 精度兜底：位置不可信降级）、口令签到（教师随机口令——输入口令签到防代签）、手势/二维码签到（动态二维码——短时刷新防转发截图 SCN-333 同源）、人脸签到（合规授权下）。
- 防代签：动态码（30s 刷新——转发无效）、位置校验（与教室距离）、行为风控（同设备多账号签到——服务端判定）、随机口令（口头传达不可截图）。
- 教师端：签到看板（实时已签/未签名单——未签一键提醒）、补签管理（手动补签+审计）、签到统计（学期出勤率）。
- 体验：签到倒计时（签到窗口期）、迟到标记（窗口外签到标迟到——策略配置）、断网兜底（离线签到暂存 SCN-297 复用）。

```javascript
// 动态二维码签到
const qr = dynamicQR({ session: classId, ttl: 30e3 });  // 30s 刷新
student.scan(qr) → verify({ session, sig }) → signed
// 口令：teacher.setPasscode('AX3K') → student.input 匹配
// 位置：fenceCheck(locate(), classroom) ||
//   fallback（GPS 不可信 → 口令兜底提示）
// 防代签：sameDevice(multiAccounts) → flag。
// 看板：roster.map(s => s.signed ? '✓' : remind(s))。
```
