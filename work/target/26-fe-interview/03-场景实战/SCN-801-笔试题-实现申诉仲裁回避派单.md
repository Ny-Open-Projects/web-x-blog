## SCN-801：手写申诉仲裁派单

**需求与边界**：
- 需求：申诉进仲裁队列，派单规则：① 原审核员及其同团队回避；② 按当前负载（在审数）最小优先；③ 超时（48h）未派单自动升级资深组。
- 边界：① 回避无可用仲裁员时放宽到跨团队（记录放宽原因）；② 负载数据带时间衰减（5 分钟前的负载按 0.9 折算）；③ 派单幂等（同申诉不重复派）。

**答**：
```javascript
function assignArbitration(appeal, arbitrators, { staleFactor = 0.9 } = {}) {
  if (appeal.assignedTo) return { skip: true };       // 幂等
  const recused = new Set([appeal.originalAuditor, ...teamOf(appeal.originalAuditor)]);
  let pool = arbitrators.filter(a => !recused.has(a.id) && a.online);
  let relaxed = false;
  if (!pool.length) {                                 // 回避后无人：放宽跨团队
    pool = arbitrators.filter(a => a.online);
    relaxed = true;
  }
  const now = Date.now();
  const pick = pool
    .map(a => ({ a, load: a.active * (now - a.loadTs < 300_000 ? 1 : staleFactor) }))
    .sort((x, y) => x.load - y.load)[0]?.a;
  if (!pick) return { queued: true, reason: 'NO_ARBITRATOR' };
  return {
    assignedTo: pick.id,
    relaxed,                                          // 放宽原因记录（审计）
    escalateAt: appeal.submitTs + 48 * 3600_000,      // SLA 升级点
  };
}
// 定时任务：escalateAt 到期未完成 → 转资深组
```

**评分点**:
- 回避规则（本人+同团队）+ 无可用时放宽并记录。
- 负载均衡带时间衰减（陈旧负载折算）。
- 派单幂等（assignedTo 判重）。
- SLA 升级时间点明确（48h）。
