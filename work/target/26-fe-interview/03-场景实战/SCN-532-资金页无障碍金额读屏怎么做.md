## SCN-532：资金页无障碍怎么做？
**答**：
- 金额读屏：读屏把 "¥1,234.56" 读成货币全称（人民币一千二百三十四元五角六分）需要 aria-label 显式提供；小数点读法易错（读成点五六 vs 五角六分）由文案层解决。
- 数字滚动动画：读屏用户禁用装饰动画（prefers-reduced-motion），aria-live=\"polite\" 播报余额变化但不刷屏（限频）。
- 焦点管理：弹窗（风险揭示/认证）焦点困住 + 关闭归还焦点；错误提示与出错字段 aria-describedby 关联并自动聚焦。
- 对比度与操作：金额红色/绿色不能只靠颜色区分涨跌（色盲），必须带箭头/正负号；按钮命中区 ≥44px。
- 追问钩子：aria-live 播报余额每秒变化怎么办——播报节流（合并 5 秒内变化，只播最终值）。

```javascript
function BalanceLive({ fen, prevFen }) {
  const label = moneyToSpeech(fen);              // “人民币 1234 元 5 角 6 分”
  const dir = fen > prevFen ? '增加' : fen < prevFen ? '减少' : '';
  return (
    <div aria-label={`余额${dir ? dir + '为' : ''}${label}`}
         aria-live="polite" aria-atomic="true">
      <span aria-hidden="true">{fenToYuan(fen)}</span>  {/* 视觉值，读屏走 label */}
      {dir && <ArrowIcon up={fen > prevFen} />}          {/* 颜色+箭头双通道 */}
    </div>
  );
}
```
