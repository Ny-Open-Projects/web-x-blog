## SCN-737：手写错误预算燃尽计算器

**需求与边界**：
- 输入：SLO（compliance 0.999）、窗口（30d）、事件列表 `[{ts, downtimeMs, weight}]`；输出逐日剩余预算序列与当前行动级别（OK/LIMIT/FREEZE）。
- 边界：① 预算 = (1-compliance) × 窗口总时长；② 消耗按天聚合（跨天事件分摊）；③ 超支后 remaining 为负继续累计；④ 行动线 25%/0%。

**答**：
```javascript
function budgetBurn(slo, events, { windowDays = 30 } = {}) {
  const windowMs = windowDays * 24 * 3600_000;
  const budget = (1 - slo.compliance) * windowMs;
  // 按天分摊消耗
  const daily = new Map();
  for (const e of events) {
    let rest = e.downtimeMs * (e.weight ?? 1);
    let cursor = e.ts;
    while (rest > 0) {                               // 跨天事件分摊
      const dayEnd = endOfDay(cursor);
      const span = Math.min(dayEnd - cursor, rest);
      const key = dayKey(cursor);
      daily.set(key, (daily.get(key) || 0) + span);
      rest -= span;
      cursor = dayEnd;
    }
  }
  let consumed = 0;
  const series = [];
  for (let d = 0; d < windowDays; d++) {
    const key = dayKey(slo.windowStart + d * 24 * 3600_000);
    consumed += daily.get(key) || 0;
    const remaining = budget - consumed;
    series.push({ day: d + 1, remaining,
      level: remaining <= 0 ? 'FREEZE' : remaining < budget * 0.25 ? 'LIMIT' : 'OK' });
  }
  return { budget, series,
    action: series.at(-1).level,
    burnRate: consumed / (elapsedMs(slo) || 1) / (budget / windowMs) };
}
const dayKey = (ts) => new Date(ts).toISOString().slice(0, 10);
const endOfDay = (ts) => { const d = new Date(ts); d.setHours(24, 0, 0, 0); return d.getTime(); };
```

**评分点**:
- 预算公式正确（(1-SLO)×窗口）。
- 跨天事件分摊（不整笔计入首日）。
- 超支持续累计（负数）与行动线三级判定。
- burn rate 归一化（消耗速率 vs 匀速预算）。
