## SCN-1283：手写一个多语言搜索建议器（拼音/罗马字/同义词）

**答**：
- 需求：implement I18nSuggest(index, syn)。suggest(q, lang)：标题命中 2 分/同义词（按语言词典）1.5 分/罗马字前缀 1 分；Top10；空输入返回该语言热门。
- 边界：q 全小写化；同义词递归一层；index 空返回空；语言不支持用默认词典。
- 评分点：多语言命中；同义词递归；罗马字；热门

```javascript
class I18nSuggest {
  constructor(index, syn = {}) { this.index = index; this.syn = syn; }
  suggest(q, lang = 'en', { hot = [] } = {}) {
    const norm = q.trim().toLowerCase();
    if (!norm) return hot.slice(0, 10);
    const syns = this.syn[lang]?.[norm] ?? [];
    const expanded = new Set([norm, ...syns,
      ...(this.syn[lang]?.[syns[0]] ?? [])]);           // 递归一层
    return this.index.map(it => {
      let score = 0;
      for (const k of expanded) {
        if (it.title?.toLowerCase().includes(k)) score += 2;
        if (it.romaji?.startsWith(k)) score += 1;
        if (it.keywords?.some(x => x.includes(k))) score += 1.5;
      }
      return { item: it, score };
    }).filter(r => r.score > 0)
      .sort((a, b) => b.score - a.score).slice(0, 10)
      .map(r => r.item);
  }
}
```
