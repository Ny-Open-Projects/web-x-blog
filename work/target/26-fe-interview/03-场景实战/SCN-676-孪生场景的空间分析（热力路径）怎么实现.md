## SCN-676：空间分析可视化怎么实现？
**答**：
- 热力图：传感器密度 → 高斯核映射到地面平面网格，用自定义 shader 或半透明贴图渲染在 3D 地面上；数据更新用纹理增量更新不重建。
- 路径模拟：人流/物流路径用曲线（CatmullRom）+ 沿曲线移动的实例化模型；大规模（千人）用 InstancedMesh + GPU 动画。
- 密度分级：人数少逐个画实体模型，超过阈值转热力/粒子抽象表达——「看得见个体」与「看得见趋势」两种模式切换。
- 分析数据口径：热力图数据来自传感器采样插值还是摄像头识别计数，来源与置信度标注（避免把插值当实测展示）。
- 追问钩子：千人级路径动画怎么不卡——位置计算放 GPU（shader 内按时间函数插值），CPU 只发一次起始/终点缓冲。

```javascript
// 千人路径：GPU 插值
const shaderMat = new THREE.ShaderMaterial({
  uniforms: { uTime: { value: 0 }, uPaths: { value: pathTexture } },
  vertexShader: `
    attribute vec2 uvPath;              // (路径id, 进度0~1)
    uniform sampler2D uPaths; uniform float uTime;
    void main() {
      float prog = fract(uvPath.y + uTime * speed(uvPath.x));   // GPU 内插值
      vec3 pos = texture2D(uPaths, vec2(uvPath.x, prog)).xyz;   // 路径纹理采样
      gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
    }`,
});
// CPU 侧每帧只更新 uTime 一个 uniform
```
