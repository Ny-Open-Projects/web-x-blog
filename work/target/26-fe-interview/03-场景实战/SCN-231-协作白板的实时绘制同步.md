## SCN-231：协作白板（画笔/图形/便签）的实时同步怎么设计？

**答**:
- 双通道分离：笔迹流（高频原始点，节流 30ms 打包广播——绘制中的实时预览）与元素流（完成的图形对象，结构化数据进 CRDT 文档——最终状态事实源）；绘制中的他人笔迹只是"预览层"，完成后转正式元素。
- 数据模型：元素 CRDT（白板文档 = Y.Map：元素 id → {type, geometry, style, zOrder}），笔迹点序列压缩（量化坐标到整数+差分编码，笔迹点数 ×10 压缩）。
- 渲染分层：canvas 分层（已完成元素层-静态缓存 / 他人笔迹预览层 / 自己绘制层——不同频率分层渲染），脏矩形重绘（只重绘变化区域），视口裁剪（视口外元素不绘制，海量元素场景）。
- 竞态处理：同元素并发拖拽→最后写入+位置插值动画（拖拽中的 live position 广播，放手后 CRDT 定位）、zOrder 冲突（时间戳序）。

```javascript
// 笔迹流：绘制中预览
pen.on('move', throttle((pts) => {
  ws.send('stroke', quantize(pts));        // 30ms 打包
}, 30));
// 完成后：结构化元素进 CRDT
pen.on('end', (stroke) => {
  ymap.set(uid(), { type: 'stroke',
    points: compress(stroke.points),       // 差分编码
    style: pen.style });
});
ymap.observe(() => renderLayer.dirty());   // 元素层脏矩形重绘
// 渲染三层：staticLayer(缓存) / previewLayer(他人笔迹)
// / localLayer(自己) —— 各自独立刷新频率。
```
