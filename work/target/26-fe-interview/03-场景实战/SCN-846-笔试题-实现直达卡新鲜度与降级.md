## SCN-846：手写直达卡新鲜度管理

**需求与边界**：
- 需求：卡片价格/库存带时间戳，展示时校验新鲜度（5 分钟）；过期卡片置灰 + 「查看最新」按钮（点击重新拉取）；卡片图加载失败降级占位；批量卡片的过期检查用统一时钟。
- 边界：① 新鲜度阈值按卡片类型配置（价格 5min/库存 1min）；② 重新拉取后局部更新（不重建列表）；③ 下拉关闭时停止过期轮询。

**答**：
```javascript
function cardFreshness(cards, { now = () => Date.now() } = {}) {
  const THRESHOLD = { price: 300_000, stock: 60_000 };
  const timer = setInterval(() => {                    // 统一时钟批量检查
    for (const card of cards) {
      const stale = now() - card.dataTs > THRESHOLD[card.type];
      if (stale !== card.stale) patchCard(card.id, { stale });   // 局部更新
    }
  }, 5000);
  return {
    refresh: async (cardId) => {
      const fresh = await api.get(`/card/${cardId}`);
      patchCard(cardId, { ...fresh, dataTs: now(), stale: false });
    },
    stop: () => clearInterval(timer),                  // 下拉关闭调用
  };
}
function CardImage({ src }) {
  const [failed, setFailed] = useState(false);
  return failed
    ? <Placeholder w={64} h={64} />                    // 失败占位
    : <img src={src} onError={() => setFailed(true)} loading="lazy" width={64} height={64} />;
}
```

**评分点**:
- 按类型差异化新鲜度阈值。
- 统一时钟批量检查 + 变化才 patch（防全量重渲染）。
- stop 生命周期（下拉关闭停轮询）。
- 图片失败占位降级 + lazy 加载。
