## SCN-659：孪生体层级模型怎么组织？
**答**：
- 树形层级：园区 → 楼宇 → 楼层 → 房间 → 设备，每级节点带聚合状态（子节点最差状态上传）；数据模型与 3D 场景树同构映射。
- 聚合状态计算：父节点状态 = 子节点按严重度取最差（一台告警整楼标黄），但视觉上区分「自身状态」与「包含异常」两种色。
- 下钻交互：点击楼宇 → 相机进入 + 楼宇外壳半透明/隐藏 → 展示内部设备；面包屑记录路径可逐级返回。
- 数据按需：设备级明细只在下钻到该层时拉取（上层只拿聚合数），避免首屏拉全量设备。
- 追问钩子：聚合状态会不会有延迟歧义——子状态变化沿树自底向上传播（事件驱动），传播延迟标注 quality，避免「楼是绿的但设备在告警」的矛盾呈现。

```javascript
function aggregateUp(node) {                       // 自底向上传播
  if (!node.children.length) return node.status;
  const worst = node.children
    .map(aggregateUp)
    .sort((a, b) => SEVERITY[b] - SEVERITY[a])[0];
  node.rollup = worst;                             // 包含异常（与自身状态分开）
  node.hasAbnormal = worst && SEVERITY[worst] > SEVERITY.normal;
  return worst || node.status;
}
function drillTo(node, camera) {
  camera.flyTo(node.center, { fit: node.bbox });   // 相机进入
  node.shell.opacity = 0.15;                       // 外壳半透明
  breadcrumb.push(node);
  if (node.level === 'device') loadDeviceDetail(node.id);   // 按需拉明细
}
```
