## SCN-352：在线表格的 Excel 式行内编辑（双击编辑/方向键移动/粘贴多行）怎么实现？

**答**:
- 编辑态状态机：浏览态→编辑态（双击/直接输入覆盖/F2 编辑）→提交（回车确认/ESC 取消/TAB 确认右移），编辑控件分型（文本/数字/日期/下拉——按列类型渲染编辑器），单元格内多行编辑（Alt+Enter 换行）。
- 键盘流：方向键移动选区（含跨冻结区）、Shift 选区扩展、回车下移（Excel 习惯）、Ctrl+方向跳边界（跳到数据边界——数据感知导航）、Ctrl+C/V 复制粘贴（多行粘贴解析 TSV → 批量写入+越界处理：粘贴区域超表格→扩展或截断确认）。
- 与协同的结合：编辑锁提示（他人编辑中单元格软锁 SCN-229）、粘贴批量写入为批量事务（一次撤销全撤——SCN-344 批量事务复用）、公式列自动填充（拖拽填充柄公式引用相对调整——SCN-342 公式引擎联动）。
- 数据校验：单元格类型校验（数字列输入文本→即时报错）、粘贴值校验（批量粘贴校验失败行标红）、必填约束（清空必填单元格→离开时提示）。

```javascript
grid.on('keydown', (e) => {
  const { r, c } = selection;
  switch (e.key) {
    case 'ArrowDown': move(r + 1, c); break;
    case 'Enter': commit(); move(r + 1, c); break;  // Excel 习惯
    case 'Tab': commit(); move(r, c + 1); break;
    case 'F2': enterEdit(r, c); break;
  }
});
grid.on('paste', (e) => {
  const rows = parseTSV(e.clipboardData);     // 多行解析
  const fit = clampToSheet(rows, selection);  // 越界处理
  ydoc.transact(() => writeBatch(fit), origin); // 批量事务
  markInvalid(fit);                           // 校验失败行标红
});
// 编辑锁：lockOf(r,c) → 他人持有 → 只读态+徽标。
```
