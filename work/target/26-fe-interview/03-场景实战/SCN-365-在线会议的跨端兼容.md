## SCN-365：会议产品跨端（浏览器差异/小程序/电视大屏）怎么适配？

**答**:
- 浏览器差异矩阵：WebRTC 能力差异（Safari 的 H265/双流支持差异、Firefox 的 getDisplayMedia 限制——能力探测降级矩阵 AGT-478 复用：按端能力选编解码与功能），MSE 差异（FLV 支持范围）、移动浏览器限制（iOS 静默自动播放限制/后台行为）。
- 小程序端：小程序 RTC（live-pusher/live-player 组件——能力与原生 SDK 差异）、组件化差异（WXML 渲染层限制）、包体与分包（RTC SDK 分包加载）。
- 电视大屏端：交互重塑（遥控器导航：焦点系统替代触摸——focus 管理是核心）、性能约束（低端 TV 芯片：最多 9 宫格/硬解限制）、输入简化（无键盘——数字键搜索/语音输入）。
- 统一策略：核心协议统一（信令/媒体协议全端一致——互通的基础），端能力矩阵文档化（功能×端支持矩阵——产品可见），端差异降级链（每功能的不支持降级方案预定义）。

```javascript
// 能力探测降级
const caps = await detect({
  h265: supportsH265(), tabAudio: supportsTabAudio(),
  simulcast: supportsSimulcast(),
});
publish({ codec: caps.h265 ? 'h265' : 'vp8',
  simulcast: caps.simulcast });
// TV 端：focusManager（遥控器焦点环）
//   + gridLimit(9) + voiceSearch()。
// 小程序：live-player 组件适配层，
//   能力矩阵 { screenShare: { web: true, mp: false } }。
```
