## SCN-628：审批意见与附件规范怎么设计？
**答**：
- 意见结构化：操作（同意/驳回/退回）+ 意见文本 + 分类标签（预算问题/凭证不全/金额错误）；驳回意见必填且要求「具体到字段」，提供快捷模板（引用具体字段名）。
- 可执行性：驳回时表单字段级标注（点击意见里的字段引用，详情页对应字段高亮闪烁）——意见变成可导航的，发起人不用猜改哪里。
- 附件规范：类型白名单/大小限制/病毒扫描提示；审批意见中引用附件（截图证据）作为锚点；附件版本（重新上传不覆盖旧版）。
- 富文本边界：意见支持 @人 与字段引用，不支持自由 HTML（防 XSS）；长度上限与字数提示。
- 追问钩子：意见里的字段引用怎么实现——@字段语法解析为 fieldRef，渲染时绑定锚点 id，点击 scrollIntoView。

```javascript
function parseOpinion(text, fields) {
  // 语法：{amount} 引用字段，@张三 提人
  return text.split(/(\{[\w.]+\}|@[\u4e00-\u9fa5\w]+)/).map(part => {
    const fieldMatch = part.match(/^\{([\w.]+)\}$/);
    if (fieldMatch) {
      const f = fields.find(x => x.name === fieldMatch[1]);
      return { type: 'fieldRef', name: f?.name, label: f?.label ?? part };
    }
    if (part.startsWith('@')) return { type: 'mention', name: part.slice(1) };
    return { type: 'text', value: part };
  });
}
// 渲染：<a onClick={() => document.getElementById(`field-${name}`).classList.add('flash')}>
```
