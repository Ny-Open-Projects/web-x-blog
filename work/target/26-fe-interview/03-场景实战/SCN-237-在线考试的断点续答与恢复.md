## SCN-237：考试中断电/断网/浏览器崩溃，答案恢复怎么设计？

**答**:
- 三层持久：内存（当前作答）、本地（localStorage/IndexedDB 每次作答即时落盘，带考试 id+时间戳+hash）、服务端（每 30s 定时快照+切题时增量上传）——恢复优先级：服务端快照 vs 本地 diff 取最新。
- 恢复流程：重新进入考试→拉服务端最新快照+本地存储比对（时间戳+hash 判定谁新）→合并（答案逐题比对，冲突取时间戳新者）→恢复剩余时间（服务端考试开始时间计算，本地时钟不可信）→提示"已恢复 N 题作答"。
- 端到端校验：恢复后展示作答摘要（已答 X 题/标记 Y 题）供考生确认（防止恢复错乱静默丢答案）、每题答案 hash 链（防篡改，SCN-236 完整性延续）。
- 边界：考试已结束期间断网恢复（服务端已收卷）→ 明确"考试已结束，以服务器最后快照为准"；本地与服务端都无数据→从空白开始+事件记录（审计可查断点时段）。

```javascript
// 本地持久：每次作答
function saveAnswer(qid, value) {
  const rec = { qid, value, ts: Date.now(),
    hash: sha256(qid + value + examId) };
  idb.put('answers', rec);
  queueUpload(rec);                          // 增量上传（失败重试）
}
setInterval(() => snapshotUpload(allAnswers()), 30e3);
// 恢复
async function recover() {
  const server = await api.getSnapshot(examId);
  const local = await idb.all('answers');
  const merged = mergeByTs(server.answers, local);  // 时间戳新者胜
  const remain = server.endTime - serverNow();
  render(merged, remain);
  toast(`已恢复 ${countAnswered(merged)} 题作答`);
}
```
