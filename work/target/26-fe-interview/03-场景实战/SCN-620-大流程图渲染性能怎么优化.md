## SCN-620：大流程图渲染性能怎么优化？
**答**：
- 渲染分层：静态结构（布局结果）一次计算缓存；状态变化只更新受影响节点的 class/填充色，不整体重建 SVG DOM。
- 视口裁剪：节点数 > 150 时按视口渲染（滚动/缩放时计算可见节点集）；缩放层级低时聚合显示（节点缩为圆点）。
- 布局缓存：流程定义不变时布局结果（节点坐标）缓存，实例状态变更不触发重新布局。
- 动画克制：当前节点脉冲动画用 CSS animation（GPU 合成）不用 JS 逐帧；连线流向动画仅当前活跃边。
- 追问钩子：SVG 还是 Canvas——交互密集（hover/点击/拖拽）用 SVG（DOM 事件），节点过千转 Canvas 自绘事件拾取，审批场景一般 SVG 够用。

```javascript
function updateStatuses(graph, statusMap) {        // 只 patch 状态，不重建
  for (const [id, state] of Object.entries(statusMap)) {
    const el = document.getElementById(`node-${id}`);
    if (el && el.dataset.state !== state) {        // 变化才写 DOM
      el.dataset.state = state;
      el.classList.toggle('pulse', state === 'CURRENT');
    }
  }
}
function visibleNodes(layout, viewport, zoom) {
  if (zoom < 0.4) return layout.nodes.map(n => ({ ...n, aggregate: true }));  // 聚合态
  return layout.nodes.filter(n =>
    n.x + n.w > viewport.x && n.x < viewport.x + viewport.w &&
    n.y + n.h > viewport.y && n.y < viewport.y + viewport.h);
}
```
