## SCN-353：在线表格的数据透视表（分组聚合/拖拽维度/联动刷新）怎么实现？

**答**:
- 透视模型：透视配置（行维度/列维度/值聚合方式/筛选），聚合计算（源数据按配置分组聚合——Worker 计算，SCN-342 引擎联动），透视结果只读（透视表是源数据的投影——不可直接编辑，编辑跳源单元格）。
- 交互设计：维度拖拽（字段拖入行/列/值区域——配置即重算）、下钻（透视单元格点击→筛选源数据显示明细——联动钻取）、刷新联动（源数据变更→透视自动重算——SCN-477 增量影响面复用）。
- 性能：聚合增量（源数据局部变更→只重算受影响的分组——分组影响面计算）、大数据透视（服务端聚合/Worker 分块聚合）、透视缓存（配置不变缓存结果——源变更才失效）。
- 协同：透视配置进 CRDT（共享视图的透视配置——SCN-292 视图配置复用）、透视结果与源数据版本一致（源变更传播到透视的时序——事件驱动重算）。

```javascript
function pivot(config, source) {
  const groups = groupBy(source, [config.rowDim, config.colDim]);
  const cells = map(groups, (g) =>
    aggregate(g, config.valueDim, config.agg));   // sum/count/avg
  return { cells, meta: { groups } };
}
// 源变更：sourceChange(addr) → affectedGroups(addr) →
//   recalc(groups)（增量，非全量）。
// 下钻：cellClick(groupKey) → detailSheet(groupKey)
//   （筛选源显示明细行）。
// Worker：大源数据聚合放 Worker，主线程只渲染。
```
