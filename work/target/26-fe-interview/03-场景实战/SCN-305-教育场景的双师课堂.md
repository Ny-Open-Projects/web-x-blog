## SCN-305：双师课堂（主讲直播大班+辅导老师小班服务）前端怎么支撑？

**答**:
- 双通道信息流：主讲直播（大班直播流+课件跟随 SCN-234 复用）+ 辅导老师通道（辅导老师面向自己小班：答疑消息/学情提醒——两个角色两套界面，学生端合流呈现）。
- 学生端合流：直播画面+辅导老师互动区（侧边 IM：辅导老师发送讲义/提示做笔记），学生问题路由（内容问题→主讲公共答疑区/个人问题→辅导老师私聊——路由策略配置）。
- 辅导老师工作台：小班学情面板（自己学生的观看状态/随堂测验成绩/未到学生——点名触达）、快速回复库（常见问题话术）、课后跟进清单（未完成作业学生名单一键触达）。
- 协同纪律：主讲与辅导的信令互不干扰（通道分级）、课堂节奏控制权在主讲（辅导老师侧边不打断主流程——消息静默进入学生侧栏）。

```javascript
// 学生端双通道
ws.join([`live:${courseId}`, `tutor:${tutorId}`]);
ws.on('course_page', followTeacher);         // 主讲通道
ws.on('tutor_msg', (m) => tutorPanel.add(m)); // 辅导侧栏
// 问题路由：askBtn → routeQuestion(type) →

//   quickReplies: REPLY_LIB });
// 随堂测：主讲发题→学生作答→成绩实时推辅导老师。
```
