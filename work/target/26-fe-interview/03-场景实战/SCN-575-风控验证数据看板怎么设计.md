## SCN-575：风控验证数据看板怎么设计？
**答**：
- 核心指标区：验证请求量（分场景/验证器/版本）、通过率、拦截量、平均耗时、SDK 错误率——按小时趋势 + 同比昨日。
- 攻击态势区：可疑流量占比、封禁设备数、接码平台命中数、各验证器被绕过尝试数；攻击上升自动标红。
- 体验区：流失漏斗（SCN-561）、误伤申诉量、各机型通过率分布（找兼容性问题）。
- 下钻联动：任何指标异常点击即下钻到明细（样本轨迹回放/服务端判定理由），运营可自助排障。
- 追问钩子：看板数据延迟多少可接受——运营看 1~5 分钟级聚合即可，攻击应急才看分钟级实时。

```javascript
const boardSpec = {
  panels: [
    { id: 'volume',  metric: 'verify_requests', dims: ['scene', 'verifier', 'sdk_version'] },
    { id: 'pass',    metric: 'pass_rate',       compare: 'yesterday' },
    { id: 'block',   metric: 'blocked_count',   alert: { expr: 'rate > baseline*3' } },
    { id: 'attack',  metric: 'suspicious_ratio', markRed: 'attack_mode' },
    { id: 'funnel',  metric: 'conversion',      drill: 'sample-replay' },
  ],
  refresh: { default: 300, emergency: 60 },       // 秒；应急模式提高频率
};
```
