## SCN-351：在线表格冻结窗格（冻结行列）与筛选的视口计算怎么实现？

**答**:
- 冻结窗格模型：冻结行列切分视口（十字冻结：冻结行+列分四个区：左上角冻结区/右上/左下/滚动区），滚动同步（滚动区滚动时冻结区固定+行列头跟随），冻结线拖拽（调整冻结位置）。
- 视口计算：虚拟滚动的冻结扩展（可视范围计算需考虑冻结区偏移——滚动区的可视行列计算基于内容坐标而非视口坐标）、冻结区与滚动区独立渲染容器（transform 分离——滚动不重排冻结区）。
- 筛选联动：筛选状态与冻结共存（筛选后行索引重映射——冻结行基于筛选后序列）、筛选行数变化（冻结窗格位置不变、内容重算）。
- 协同一致：冻结/筛选状态是否协同（视图级配置：个人视图 vs 协同视图——SCN-292 视图配置复用，默认个人视图各看各的冻结）。

```javascript
// 四区渲染布局
<div class="grid">
  <CornerPane rows={frozenRows} cols={frozenCols} />   // 左上
  <ColHeaderPane cols={frozenCols} />                  // 右上(头)
  <RowHeaderPane rows={frozenRows} />                  // 左下
  <ScrollPane />                                       // 滚动区
</div>
// 视口计算：ScrollPane 的 scrollTop/Left 独立，
//   可视行 = rows.slice(floor(scrollTop / rowH),
//     ceil((scrollTop + viewH) / rowH))，
//   冻结区不参与滚动计算。
// 筛选：visibleRows = filtered（索引重映射），
//   冻结行取 filtered.slice(0, frozenRows)。
// 冻结状态默认个人视图（协同需显式共享）。
```
