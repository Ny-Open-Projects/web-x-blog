## SCN-615：审批统计分析报表怎么做？
**答**：
- 核心指标：平均审批时长（P50/P95，按节点/流程类型/审批人拆分）、驳回率（驳回原因分布）、审批人负载（待办数/日均处理量）、超时率。
- 口径先行：时长 = 通过时刻 - 到达时刻（不含撤回/终止的实例是否计入要明确）；工作日历口径 vs 自然时间口径可切换。
- 下钻联动：总览图点击异常指标下钻到实例明细列表（哪些单慢了）；慢审批 TopN 列表可一键催办。
- 归因辅助：驳回原因结构化（提交时必选原因枚举），报表自动出分布饼图；「被打回重来」的单重新计时口径要标注（区分首次时长与总时长）。
- 追问钩子：审批人负载均衡怎么用数据——识别单人积压超阈值，提示管理员调整审批规则或加签代理。

```javascript
function approvalStats(instances, { workHours = true } = {}) {
  const done = instances.filter(i => i.status === 'PASSED');
  const durations = done.map(i => {
    const ms = i.passTs - i.arriveTs;
    return workHours ? toWorkMs(ms, i.arriveTs) : ms;   // 工作日历口径
  });
  return {
    p50: quantile(durations, 0.5), p95: quantile(durations, 0.95),
    rejectRate: instances.filter(i => i.status === 'REJECTED').length / instances.length,
    rejectReasons: groupCount(instances.flatMap(i => i.rejectReasons || [])),
    loadByApprover: groupCount(done.map(i => i.approverId)),    // 处理量分布
  };
}
```
