## SCN-891：手写秒杀漏斗统计

**需求与边界**：
- 需求：漏斗事件按采样率加权还原（行为线 10%、交易线全量）；输出各步转化率与失败原因分布；样本量不足的步骤标注低置信。
- 边界：① 加权 = 事件数 / 采样率（还原真实量级）；② 混合采样率时分步还原（每步用自身 rate）；③ 转化率基于加权量计算。

**答**：
```javascript
function seckillFunnel(events) {                     // events: [{step, sid, rate, reason?}]
  const weighted = {};
  for (const e of events) {
    weighted[e.step] ??= { n: 0, reasons: {} };
    weighted[e.step].n += 1 / e.rate;                // 按采样率加权还原
    if (e.reason)
      weighted[e.step].reasons[e.reason] = (weighted[e.step].reasons[e.reason] || 0) + 1 / e.rate;
  }
  const ORDER = ['expose', 'detail', 'click', 'queue', 'admit', 'order', 'pay'];
  const steps = ORDER.filter(s => weighted[s]).map(s => ({ step: s, n: weighted[s].n }));
  const funnel = steps.map((s, i) => ({
    ...s,
    conv: i === 0 ? 1 : s.n / steps[i - 1].n,        // 步间转化（加权量）
    lowConfidence: s.rawN < 100,                     // 样本不足标注（需 raw 计数）
    failureTop: weighted[s.step].reasons &&
      Object.entries(weighted[s.step].reasons).sort(([, a], [, b]) => b - a).slice(0, 3),
  }));
  return funnel;
}
```

**评分点**:
- 采样率加权还原（1/rate），分步用各自 rate。
- 步间转化基于加权量（非原始计数）。
- 失败原因 Top3（限流/售罄/风控占比定位瓶颈）。
- 低置信标注（加权后样本量小的步骤）。
