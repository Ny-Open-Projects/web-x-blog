## SCN-377：文档中嵌入图表（数据表联动/数据更新图表刷新）怎么实现？

**答**:
- 嵌入模型：文档内嵌块（图表块：数据源（文档内表格/外部数据源）+图表配置），数据源绑定（文档内表格选区绑定——表格数据变更→图表自动刷新；外部数据源快照/实时模式）。
- 图表引擎：图表渲染（图表库注册——SCN-257 图表复用），配置交互（点选数据区→图表类型选择→配置面板——SCN-243 编排复用），图表协同（图表配置进 CRDT——多人协同编辑图表 SCN-292 视图配置复用）。
- 更新一致性：表格变更→图表增算（SCN-477 影响面复用：只重算引用区域）、外部数据定时刷新（AGT-449 调度复用）+刷新标注（数据截至时间）。
- 导出一致性：导出文档时图表转静态图（导出快照——所见即所得）、打印适配（SCN-355 复用）。

```javascript
// 图表块
const block = { type: 'chart',
  source: { kind: 'inline', range: 'A1:C10' },  // 文档内表格
  chart: { type: 'bar', config: {...} } };
tableCellChange(range) → chartBlock.refresh(affected); // 增量
// 外部源：{ kind: 'remote', url, refresh: '30m' }
//   → schedule(refresh)（AGT-449）→ 标注 asOf。
// 协同：block.chart.config → Y.Map（SCN-292 复用）。
// 导出：chart.toImage() 快照嵌入 PDF。
```
