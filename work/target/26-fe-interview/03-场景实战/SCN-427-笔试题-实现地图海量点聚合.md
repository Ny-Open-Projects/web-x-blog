## SCN-427：手写地图点聚合：网格聚合、zoom 变化重算、聚合点击展开

**需求与边界**：
- 输入：点位数组（万级）、zoom；输出：聚合结果集。
- 边界要求：① 网格聚合（屏幕像素网格——O(n) 而非 O(n²) 距离聚合）；② zoom 变化重算（防抖+增量）；③ 聚合数动画；④ 点击聚合→放大展开（或下级聚合）。

**答**：
```javascript
function gridCluster(points, zoom, { cellPx = 60, projection }) {
  const grid = new Map();                      // 网格 key → 点集
  for (const p of points) {
    const [x, y] = projection(p, zoom);        // 经纬度→屏幕
    const key = `${Math.floor(x / cellPx)}:${Math.floor(y / cellPx)}`;
    grid.set(key, (grid.get(key) ?? []).concat(p));
  }
  return [...grid.values()].map(g => g.length === 1
    ? { type: 'point', point: g[0] }           // 单点直显
    : { type: 'cluster', count: g.length,      // 聚合点
      center: avgPos(g), points: g });
}
// zoom 变化：map.on('zoomend', debounce(() =>
//   recalc(currentZoom), 200))；zoom 动画中不清除旧聚合。
// 点击聚合：clusterClick → map.zoomIn()
//   → zoom+1 重算 → 子聚合/单点出现（逐级展开）。
// 性能：O(n) 网格分桶；10 万点 → 服务端预聚合
//   （按 zoom 预生成瓦片聚合）。
// 聚合数字动画：count 变化 → 数字滚动过渡。
```

**评分点**:
- 网格聚合 O(n)（key 分桶），优于 O(n²) 距离聚合的正确选择。
- 单点/聚合分流输出结构清晰。
- zoom 变化防抖重算+点击放大逐级展开交互。
- 10 万级服务端预聚合的升级路径意识。
