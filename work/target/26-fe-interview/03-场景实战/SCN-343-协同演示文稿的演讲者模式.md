## SCN-343：协同演示文稿（演讲者模式/观众跟随/注释工具）怎么设计？

**答**:
- 双端模式：演讲者端（当前页+下一页预览+演讲备注+计时器——双屏信息），观众端（跟随页——SCN-234 课件跟随复用），观众自由浏览（翻看后自动回跟 SCN-234 同源）；播放态切换（编辑模式↔放映模式）。
- 页面协同：页面编辑进 CRDT（多人同时编辑不同页/同页元素——SCN-229 表格/231 白板思路：元素级 CRDT），页面顺序操作（拖拽调页序）、演讲者锁（放映中只有演讲者可翻页）。
- 注释工具：放映中的激光笔/画笔（观众可见的标注——白板通道 SCN-231 复用，放映结束清除）、弹幕提问（放映中观众提问侧栏——演讲者可见可回应）。
- 性能：页面资源预载（当前±1 页资源预热——SCN-210 矩阵复用）、动画编排（页面内动画序列在放映态按序播放）、大页面渲染（复杂图表页的离屏渲染优化）。

```javascript
// 演讲者端
presenter.on('next', () => {
  slides.go(1);                              // CRDT 页指针
  signaling.send({ type: 'slide_pointer', page: slides.current });
});
presenter.render({ current: slides.current,
  next: slides.peek(1), notes: page.notes,   // 备注双屏
  timer: elapsed });
// 观众端：SCN-234 跟随 + 自由浏览回跟。
// 标注：penStream → 白板通道（SCN-231）→ 放映层叠加。
// 页面元素：元素级 CRDT（SCN-231），页序：CRDT 序列。
```
