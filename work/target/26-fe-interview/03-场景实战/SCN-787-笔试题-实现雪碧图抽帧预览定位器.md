## SCN-787：手写雪碧图抽帧预览定位器

**需求与边界**：
- 需求：给定雪碧图元数据（每张 cols×rows 帧、帧间隔、URL 列表），实现 hoverTime(t) → { url, backgroundPosition }；跨分片只加载所在分片并缓存（LRU 上限 5 张）。
- 边界：① t 超出视频时长 clamp；② 最后一帧不满张的雪碧图越界坐标不显示（返回 null）；③ 分片预加载相邻一张。

**答**：
```javascript
function createSpriteLocator(meta, { cacheMax = 5 } = {}) {
  const cache = new Map();                             // sheetIdx -> Image (LRU)
  function locate(t) {
    const clamped = Math.max(0, Math.min(t, meta.duration - meta.interval));
    const frame = Math.floor(clamped / meta.interval);
    const perSheet = meta.cols * meta.rows;
    const sheet = Math.floor(frame / perSheet);
    if (sheet >= meta.urls.length) return null;        // 末张不满帧越界
    const idx = frame % perSheet;
    ensureLoaded(sheet);                               // 懒加载 + 相邻预载
    ensureLoaded(sheet + 1, { idle: true });
    return {
      url: meta.urls[sheet],
      x: -(idx % meta.cols) * meta.w,
      y: -Math.floor(idx / meta.cols) * meta.h,
    };
  }
  function ensureLoaded(i, { idle = false } = {}) {
    if (i >= meta.urls.length || cache.has(i)) { touch(i); return; }
    const img = new Image();
    img.src = meta.urls[i];
    cache.set(i, img); touch(i);
    if (cache.size > cacheMax) {                       // LRU 淘汰
      const oldest = [...cache.entries()].sort((a, b) => a[1]._t - b[1]._t)[0];
      cache.delete(oldest[0]);
    }
  }
  const touch = (i) => { cache.get(i)._t = Date.now(); };
  return { locate };
}
```

**评分点**:
- 时间→帧→分片→网格坐标映射正确。
- 末张不满帧的越界 null 防护 + 时长 clamp。
- LRU 缓存上限 + 相邻分片 idle 预载。
- 只加载所需分片（长视频不拉全集）。
