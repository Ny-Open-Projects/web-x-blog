## SCN-803：搜索联想的词源与排序怎么设计？
**答**：
- 词源分层：用户历史（个性化）、热门榜（时效性）、商品/内容库前缀匹配（召回）、纠错扩展（拼写）——四源合并去重后统一排序。
- 排序因子：匹配度（前缀/拼音/编辑距离）× 热度 × 个性化（用户点击历史加权）× 运营权重（活动词置顶）——服务端排序，前端只呈现与交互。
- 类型区分：建议词（query 补全）与直达对象（商品/人物卡）分容器展示，直达卡点击行为不同（跳详情 vs 发起搜索）。
- 时效控制：热词带 TTL（热点事件过期自动降权），历史词去敏感（避免展示敏感历史查询）。
- 追问钩子：为什么排序不能放前端——前端只有当前用户上下文，热度/运营权重/风控过滤都是全局数据；前端排序还会导致「同一输入不同端结果不一致」。

```javascript
// 服务端返回的联想结果结构（前端渲染契约）
const suggestion = {
  groups: [
    { type: 'history', items: [{ q: '前端面试', highlighted: '前端面试' }] },
    { type: 'hot', items: [{ q: '双十一', badge: '热' }] },
    { type: 'entity', items: [{ q: 'iPhone 17', card: { img, price } }] },
  ],
  traceId: 'sug-xxx',                                // 点击归因
};
function renderGroups(groups) {
  return groups.map(g => ({
    ...g,
    items: dedupeByQuery(g.items),                   // 跨源去重后仍需组内保险
  }));
}
```
