## SCN-591：手写验证状态机 + 降级链

**需求与边界**：
- 状态：idle → running(verifier) → passed / failed(user) / fallback → passed / exhausted。
- 边界：① 验证器执行超时自动切下一个；② 风控拒绝（RISK_REJECT）不降级直接终止；③ 全链用尽报 exhausted；④ 每次切换上报事件。

**答**：
```javascript
function createVerifyChain(chain, { perTimeout = 60_000 } = {}) {
  let state = 'idle', idx = -1;
  const events = [];
  async function run(scene) {
    state = 'running';
    for (idx = 0; idx < chain.length; idx++) {
      const name = chain[idx];
      const impl = registry.get(name);
      events.push({ type: 'start', name });
      if (!impl?.available()) {
        events.push({ type: 'unavailable', name });    // 组件不可用跳过
        continue;
      }
      try {
        const r = await withTimeout(impl.run(scene), perTimeout);
        if (r.pass) { state = 'passed'; events.push({ type: 'pass', name });
                      return { pass: true, token: r.token, verifier: name }; }
        events.push({ type: 'fail-user', name, reason: r.reason });   // 用户答错：可换下一种
        if (r.reason?.code === 'RISK_REJECT') {        // 风控拒绝：终止不降级
          state = 'rejected';
          return { pass: false, reason: 'RISK_REJECT' };
        }
      } catch (e) {
        events.push({ type: 'error', name, err: e.message });  // 超时/崩溃：降级
      }
    }
    state = 'exhausted';
    events.push({ type: 'exhausted' });
    return { pass: false, reason: 'EXHAUSTED' };       // 上层决定限流放行或阻断
  }
  return { run, get state() { return state; }, events };
}
const withTimeout = (p, ms) => Promise.race([
  p, new Promise((_, rej) => setTimeout(() => rej(new Error('VERIFY_TIMEOUT')), ms)),
]);
```

**评分点**:
- 状态机完整（idle/running/passed/failed/fallback/exhausted/rejected）。
- 三种退出路径区分：用户答错可降级、系统故障降级、风控拒绝终止。
- withTimeout 超时自动切换 + 事件全量记录（可观测）。
- exhausted 交上层决策，不在组件层放行。
