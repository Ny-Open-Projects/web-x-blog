## SCN-757：审核标准配置化怎么设计？
**答**：
- 标准结构化：违规类型树（涉政/色情/暴恐/侵权…子类）× 处置动作（下架/限流/封号/警告）× 判定依据（规则 id + 截图帧），表单从配置生成——标准更新不发版。
- 证据绑定：每个处置必须关联证据（违规帧截图 + 时间点 + 引用标准条目），无证据不能提交——审核质量与申诉仲裁的基础。
- 版本与生效：标准版本化，审核时记录所用版本；新版本生效给审核员「标准变更学习」提示（关键变更强制阅读）。
- 意见模板：常用驳回理由模板（可编辑），提升填写效率且表述一致。
- 追问钩子：为什么处置必须绑证据——申诉仲裁与质检都依赖证据链；没有证据的处置在争议中必然败诉（创作者权益）。

```javascript
const violationSchema = {
  categories: [{ id: 'politics', label: '涉政', children: ['flag', 'leader'] }],
  actions: { politics: ['takedown', 'ban'], copyright: ['takedown', 'warn'] },
  require: { evidence: ['frameTs', 'screenshotUrl', 'ruleRef'] },   // 证据强制
};
function ReviewForm({ schema, version }) {
  const [cat, setCat] = useState(null);
  return (
    <>
      <CategoryTree data={schema.categories} onChange={setCat} />
      <ActionPicker actions={schema.actions[cat]} />
      <EvidenceUploader required />                  {/* 无证据禁提交 */}
      <button disabled={!evidenceComplete}>提交</button>
      {versionChanged(version) && <StandardChangeNotice version={version} />}
    </>
  );
}
```
