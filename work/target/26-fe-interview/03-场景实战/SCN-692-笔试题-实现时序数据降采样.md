## SCN-692：手写 min-max 桶降采样

**需求与边界**：
- 需求：N 点压缩到 bucketCount 桶；每桶输出 {tMid, avg, min, max}；另输出「尖峰点」列表（桶内极值偏离 avg 超 3σ 或绝对超阈值）；无数据桶跳过。
- 边界：① NaN 值过滤；② 输入乱序按 t 排序；③ 单桶一点时 avg=min=max。

**答**：
```javascript
function minMaxDownsample(points, buckets, { spikeThreshold = Infinity } = {}) {
  const clean = points.filter(p => Number.isFinite(p.v))
    .sort((a, b) => a.t - b.t);                        // 乱序修正 + NaN 过滤
  if (!clean.length) return { buckets: [], spikes: [] };
  const size = Math.ceil(clean.length / buckets);
  const out = [], spikes = [];
  for (let i = 0; i < clean.length; i += size) {
    const slice = clean.slice(i, i + size);
    const vs = slice.map(p => p.v);
    const avg = vs.reduce((s, v) => s + v, 0) / slice.length;
    const variance = vs.reduce((s, v) => s + (v - avg) ** 2, 0) / slice.length;
    const std = Math.sqrt(variance);
    const bucket = {
      tMid: slice[Math.floor(slice.length / 2)].t,
      avg, min: Math.min(...vs), max: Math.max(...vs),
      count: slice.length,
    };
    out.push(bucket);
    // 尖峰保留：极值偏离均值 3σ 或绝对超阈值
    for (const p of slice)
      if (std > 0 && Math.abs(p.v - avg) > 3 * std || Math.abs(p.v) > spikeThreshold)
        spikes.push(p);
  }
  return { buckets: out, spikes };
}
// 绘制：band = min/max 带状图（保真）+ avg 线（轻量）+ spikes 散点标注
```

**评分点**:
- NaN 过滤与乱序排序（数据清洗先于聚合）。
- min/max/avg 三值输出（band 绘图不失真）。
- 尖峰双判据（3σ 统计 + 绝对阈值）。
- 单点桶边界正确。
