## SCN-802：手写审核综合调度器

**需求与边界**：
- 需求：整合「置信度路由 → 队列混入盲测样本 → 人审提交 → 反馈分流（回流训练/质检统计）」，单入口 `schedule(item)`。
- 边界：① 盲测样本按确定性比例混入人审队列（不可区分）；② 提交时自动判定是盲测样本并路由到质检统计；③ 全链路带 traceId。

**答**：
```javascript
async function schedule(item, { traceId = newTrace() } = {}) {
  // 1. 置信度路由（SCN-790）
  const route = routeReview(item);
  if (route.lane === 'DIRECT' && !route.qc) return { done: 'DIRECT', traceId };
  // 2. 人审队列 + 盲测混入（确定性采样，审核员不可见）
  const queue = route.lane === 'HUMAN' ? 'human' : 'qc-blind';
  const blindSample = isBlindSample(item.id);          // 确定性：金标准样本哈希混入
  const assigned = await claimQueue({ queue, traceId });
  // 3. 提交后反馈分流
  function onSubmitted(verdict) {
    if (blindSample) {
      qcStats.record({ itemId: item.id, verdict, truth: item.truth });   // 质检统计
      return { lane: 'QC' };
    }
    return feedbackSink.write({                       // 模型回流（SCN-769）
      videoId: item.id, verdict,
      machine: { score: item.score, agree: verdict.verdict === (item.score >= 0.5 ? 'REJECT' : 'PASS') },
      traceId, priority: item.appealReversed ? 'P0' : 'P2',
    });
  }
  return { lane: queue, assigned, blindSample, traceId, onSubmitted };
}
```

**评分点**:
- 模块整合完整：路由→混入→提交→分流四步链路。
- 盲测确定性混入（金标准样本审核员不可区分）。
- 提交后双分流（质检统计 vs 模型回流）。
- traceId 全链贯穿（SCN-564 可观测意识）。
