## SCN-887：手写秒杀按钮状态机

**需求与边界**：
- 状态：NOT_STARTED / COUNTDOWN / OPEN / SUBMITTING / SUCCESS / FAILED / SOLD_OUT。
- 边界：① 迁移白名单，非法迁移静默拒绝并计数；② SUBMITTING 期间所有点击忽略（防连点）；③ FAILED 仅网络类可回 OPEN 重试（限 1 次）；④ 状态变化发出渲染事件。

**答**：
```javascript
const SECKILL_FSM = {
  transitions: {
    NOT_STARTED: ['COUNTDOWN'], COUNTDOWN: ['OPEN'],
    OPEN: ['SUBMITTING'], SUBMITTING: ['SUCCESS', 'FAILED', 'SOLD_OUT'],
    FAILED: ['OPEN'], SUCCESS: [], SOLD_OUT: [],
  },
  views: {
    NOT_STARTED: { text: '未开始', disabled: true }, COUNTDOWN: { text: '即将开始', disabled: true },
    OPEN: { text: '立即抢购' }, SUBMITTING: { text: '抢购中…', disabled: true },
    SUCCESS: { text: '抢购成功' }, FAILED: { text: '网络异常，重试' }, SOLD_OUT: { text: '已售罄', disabled: true },
  },
};
function createSeckillButton() {
  let state = 'NOT_STARTED';
  const illegalCounts = {};
  function transition(to, { reason } = {}) {
    if (!(SECKILL_FSM.transitions[state] || []).includes(to)) {
      illegalCounts[`${state}->${to}`] = (illegalCounts[`${state}->${to}`] || 0) + 1;   // 静默计数
      return false;
    }
    if (state === 'SUBMITTING' && to === 'SUBMITTING') return false;   // 连点忽略
    state = to;
    listeners.forEach(fn => fn(state, SECKILL_FSM.views[state]));
    return true;
  }
  const listeners = new Set();
  return {
    transition, subscribe: fn => listeners.add(fn),
    click: () => transition('SUBMITTING'),
    result: (r) => transition(r.type === 'NETWORK' && !r.retried ? 'FAILED' : r.type),
    get state() { return state; },
  };
}
```

**评分点**:
- 迁移白名单 + 非法迁移静默计数（不弹错误不打断用户）。
- SUBMITTING 拒绝一切（防连点核心）。
- FAILED 仅网络类可重试且限次（FAILED→OPEN 唯一出口）。
- 状态与视图解耦（views 表渲染）。
