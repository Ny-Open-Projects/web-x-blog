## SCN-944：政务办件的电子签名接入（手写签名板）

**答**：
- 签名：触屏手写签名（Canvas 采集笔迹），签名图片 + 时间戳嵌入办件。
- 校验：签名完整性（笔迹采样率/非空白检测）、防抵赖（签名绑定办件号+身份）。
- 体验：签名失败重写（清除）、签名预览确认。

```javascript
// 签名板
class SignaturePad {
  constructor(canvas) {
    this.ctx = canvas.getContext('2d');
    this.ctx.lineWidth = 3; this.ctx.lineCap = 'round';
    this.points = 0;
    canvas.addEventListener('pointermove', e => {
      if (!e.buttons) return;
      this.ctx.lineTo(e.offsetX, e.offsetY); this.ctx.stroke();
      this.points++;
    }, { passive: true });
  }
  isValid() { return this.points > 20; }              // 防空白签名
  clear() { this.ctx.clearRect(0, 0, 9999, 9999); this.points = 0; }
  toBlob() { return this.ctx.canvas.toBlob(b => b, 'image/png'); }
}
```
