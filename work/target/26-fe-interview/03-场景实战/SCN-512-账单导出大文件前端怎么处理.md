## SCN-512：大账单导出怎么设计？
**答**：
- 异步任务化：超过阈值（如 1 万行）走服务端异步导出——前端创建任务 → 轮询/WS 拿进度 → 完成后拿签名直链下载；同步导出只留小数据量。
- 前端职责：任务中心入口（进度条/失败重试/过期提示）、下载文件名规范（账期+账户+时间戳）、导出权限与行数上限展示。
- 直链安全：下载 URL 用短时效签名（SCN-494 模式），过期前端引导重新生成；前端不缓存直链到 localStorage。
- 一致性：导出携带查询条件快照 ID，防止「导出时数据与筛选时不一致」；文件内附口径说明行。
- 追问钩子：为什么不让前端拼 10 万行 CSV——内存与主线程都扛不住，且拿不到服务端完整数据。

```javascript
async function exportBill(query) {
  const { taskId } = await api.post('/export', query);
  const timer = setInterval(async () => {
    const t = await api.get(`/export/${taskId}`);
    updateTaskUI(taskId, t.progress);                 // 进度条
    if (t.status === 'DONE') {
      clearInterval(timer);
      const a = document.createElement('a');
      a.href = t.url;                                  // 短时效签名直链
      a.download = `bill_${query.month}_${Date.now()}.csv`;
      a.click();
    } else if (t.status === 'FAILED') {
      clearInterval(timer); showRetry(taskId);
    }
  }, 1500);
}
```
