## SCN-800：手写下一条预取器

**需求与边界**：
- 需求：提交当前审核时预取队列下一条（元数据+雪碧图首张）；提交后立即命中使用；预取未命中（队列变化）丢弃并统计命中率；组件卸载取消进行中预取。
- 边界：① 预取请求 AbortController 管理；② 命中率进工作台体验指标；③ 预取失败静默（不影响主流程）。

**答**：
```javascript
function createPrefetcher() {
  let ctrl = null, prefetched = null;
  const stats = { attempts: 0, hits: 0 };
  function prefetchAfter(currentId) {
    cancel();                                         // 上一次预取作废
    stats.attempts++;
    ctrl = new AbortController();
    prefetched = Promise.all([
      api.get(`/queue/peek`, { params: { after: currentId }, signal: ctrl.signal }),
      api.get(`/queue/peek/sprite`, { params: { after: currentId }, signal: ctrl.signal }),
    ]).then(([meta, sprite]) => ({ meta, sprite }))
      .catch(() => (prefetched = null, null));        // 失败静默清空
    return prefetched;
  }
  function consume() {                                // 提交后使用预取
    if (prefetched) { stats.hits++; return prefetched; }
    return null;                                      // 未命中走正常领取
  }
  function cancel() { ctrl?.abort(); prefetched = null; }
  window.addEventListener('pagehide', cancel);
  return {
    prefetchAfter, consume, cancel,
    hitRate: () => stats.attempts ? stats.hits / stats.attempts : 0,
  };
}
```

**评分点**:
- AbortController 取消旧预取（队列变化防串数据）。
- 命中率统计（优化工作台切换体验的度量）。
- 预取失败静默降级（不影响领取主流程）。
- pagehide 清理。
