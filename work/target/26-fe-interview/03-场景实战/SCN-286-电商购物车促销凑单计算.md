## SCN-286：购物车"再凑 30 元可用券"的凑单功能怎么实现？

**答**:
- 差额计算：优惠门槛差额实时计算（SCN-206 优惠引擎复用：当前优惠结构→最优可用优惠的差额），多门槛提示（满 99 减 10 / 满 199 减 30——推荐最优档）。
- 凑单推荐：凑单商品列表（差额金额附近的商品：价格区间 [差额, 差额+20%]，按毛利率与转化排序——平台侧策略）、凑单商品一键加购→购物车重算差额闭环。
- 交互细节：凑单进度条（当前合计 vs 门槛）、凑单后自动取消凑单模式、不凑单的可忽略（凑单是引导不是拦截）。
- 边界：凑单商品库存校验（加购时确认）、凑单商品退货后优惠失效的提示（凑单达成优惠后删凑单品→优惠失效警示）。

```javascript
function calcGap(cart, coupons) {
  const best = bestReachableCoupon(cart, coupons);   // 最优可达优惠
  return best ? { coupon: best,
    gap: best.threshold - subtotal(cart),
    suggest: fetchSuggest(best.threshold - subtotal(cart)) } : null;
}
// UI：进度条 gap>0 → "再凑 ¥30 可用满 199-30 券"
//   + 推荐商品列表（差额区间）
// 加购凑单品 → recalc → gap ≤ 0 → 达成提示+退出凑单模式
// 删凑单品 → 若优惠失守 → confirm('移除后优惠失效')。
```
