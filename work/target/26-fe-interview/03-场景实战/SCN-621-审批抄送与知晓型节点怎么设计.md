## SCN-621：抄送/知晓型节点怎么设计？
**答**：
- 语义区分：抄送节点（CYCLIC，通知但无审批权）与审批节点视觉/交互区分——抄送卡片只有「已阅」与「评论」，无同意/驳回按钮。
- 已读回执：点击进入详情即记已读（服务端埋点），列表里「已读/未读」状态区分；是否强制「已阅确认」由流程定义声明（关键单需主动点已阅）。
- 静默规则：抄送人不在时间线参与者高亮区显示（弱化），但完整可见全部内容与意见；抄送列表可展开（大群抄送折叠头像 +N）。
- 评论协同：抄送人评论仅抄送圈可见（@人可提醒），评论不产生审批动作。
- 追问钩子：抄送范围动态变化（中途加抄送人）怎么通知——新增抄送事件进时间线（「X 被added to 抄送」），保证审计完整。

```javascript
function CcCard({ node, instance }) {
  const isRead = node.readers.includes(currentUser.id);
  return (
    <Card>
      <Tag>抄送 · {node.readers.length} 人</Tag>
      {!isRead && <Badge>未读</Badge>}
      <ReaderList users={node.readers} max={5} />   {/* 折叠 +N */}
      {node.requireAck && !isRead && (
        <Button onClick={() => ack(instance.id, node.id)}>确认已阅</Button>
      )}
      <CommentBox scope="cc" />                     {/* 评论无审批动作 */}
    </Card>
  );
}
```
