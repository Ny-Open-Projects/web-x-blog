## SCN-843：手写热词池管理

**需求与边界**：
- 需求：热词带来源（运营置顶/自动挖掘）与 TTL；自动热词按搜索量爆发检测进池，衰减期自动降权，TTL 到期淘汰；运营置顶词不受自动淘汰但到期提醒续期。
- 边界：① 爆发判定：搜索量 > 基线均值 3σ 且持续 2 个窗口；② 衰减：每过 TTL/2 权重 ×0.5；③ 池容量上限淘汰低权重。

**答**：
```javascript
function createHotwordPool({ cap = 50, baseTtl = 24 * 3600_000 } = {}) {
  const pool = new Map();                              // word -> {weight, ts, source, boosts}
  function detectBurst(series, baseline) {             // series: 窗口搜索量
    const mean = avg(baseline), std = stdOf(baseline);
    return series.filter(v => v > mean + 3 * std).length >= 2;   // 持续 2 窗口超 3σ
  }
  function tick(now) {
    for (const [word, e] of pool) {
      const age = now - e.ts;
      if (e.source === 'ops') {                        // 运营置顶：不淘汰但提醒续期
        if (age > e.ttl) notifyRenew(word);
        continue;
      }
      e.weight *= Math.pow(0.5, Math.floor(age / (e.ttl / 2)));   // 半衰期降权
      if (age > e.ttl || e.weight < 0.1) pool.delete(word);       // 淘汰
    }
    while (pool.size > cap) {                          // 容量淘汰最低权重
      const min = [...pool.entries()].sort((a, b) => a[1].weight - b[1].weight)[0];
      pool.delete(min[0]);
    }
  }
  return { add: (word, opts) => pool.set(word, { weight: 1, ts: Date.now(), ttl: baseTtl, ...opts }),
           detectBurst, tick, list: () => [...pool.entries()]
             .sort((a, b) => b[1].weight - a[1].weight).map(([w]) => w) };
}
```

**评分点**:
- 爆发检测双条件（3σ + 持续 2 窗口）。
- 半衰期降权（衰减平滑非突然失效）。
- 运营词与自动词差异化治理（置顶保护 + 续期提醒）。
- 容量上限淘汰最低权重。
