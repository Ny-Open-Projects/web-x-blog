## SCN-806：联想键盘导航与无障碍怎么实现？
**答**：
- 键盘流：↑↓ 在建议间移动（循环），Enter 采纳当前项，Esc 关闭，Tab 关闭并回到输入框；分组边界跳转（history→hot 组跳转体验顺滑）。
- ARIA 语义：input role="combobox" aria-expanded + listbox + option（aria-selected），读屏用户能完整操作。
- 状态一致：键盘移动时输入框显示「ghost 提示」（灰色补全预览）与实际选中项同步；鼠标 hover 与键盘选中互不覆盖（最后操作者胜）。
- 移动端适配：无 hover，点击即采纳；键盘弹起时下拉跟随视口（visualViewport 监听）。
- 追问钩子：为什么 hover 与键盘选中要合并为单一「activeIndex」——两个选中态并存会导致 Enter 采纳与视觉高亮不一致，单一状态源是交互一致性的根基。

```javascript
function useComboboxNav(items) {
  const [active, setActive] = useState(-1);
  const onKeyDown = (e) => {
    switch (e.key) {
      case 'ArrowDown': e.preventDefault(); setActive(a => (a + 1) % items.length); break;
      case 'ArrowUp':   e.preventDefault(); setActive(a => (a - 1 + items.length) % items.length); break;
      case 'Enter':     e.preventDefault(); active >= 0 && adopt(items[active]); break;
      case 'Escape':    close(); break;
    }
  };
  return {
    onKeyDown, active,
    a11y: { role: 'combobox', 'aria-expanded': items.length > 0,
            'aria-activedescendant': `opt-${active}` },   // 读屏跟随
  };
}
```
