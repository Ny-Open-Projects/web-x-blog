## SCN-469：手写共享画面感知编码：帧差检测、静态降码率、动态恢复

**需求与边界**：
- 输入：共享视频轨；输出：码率自适应控制。
- 边界要求：① 帧差检测（定时抽样 diff——静态/动态判定）；② 静态画面降帧率/码率（省带宽）、动态恢复；③ 判定防抖（连续 N 次才切）；④ 文字画面优先清晰度（文字场景保分辨率）。

**答**：
```javascript
class ContentAwareEncoder {
  constructor(track) {
    this.track = track;
    this.timer = setInterval(() => this.probe(), 2000);
    this.staticStreak = 0;
  }
  async probe() {
    const frame = await grabFrame(this.track);
    const diff = frameDiff(this.lastFrame, frame);  // 帧差
    this.lastFrame = frame;
    if (diff < 0.01) this.staticStreak++;        // 静态
    else this.staticStreak = 0;
    // 防抖：连续 2 次静态才降
    if (this.staticStreak >= 2 && this.mode !== 'static') {
      this.mode = 'static';
      setTrackConstraints(this.track, { frameRate: 5,   // 降帧
        bitrate: 300e3 });                     // 降码率
    } else if (this.staticStreak === 0 && this.mode === 'static') {
      this.mode = 'dynamic';                   // 动态恢复
      setTrackConstraints(this.track, { frameRate: 15,
        bitrate: 1500e3 });
    }
  }
}
// 文字画面：diff 小但文字需要清晰 → 静态模式保分辨率降帧率
//   （而非降分辨率——共享场景清晰度优先于流畅）。
```

**评分点**:
- 帧差检测（抽样 diff）判定静态/动态。
- 防抖（连续 2 次）防频繁切换。
- 静态降帧率+码率、动态恢复的双向切换。
- 共享场景"保清晰度降帧率"的价值排序意识。
