## SCN-210：商品详情页要"点击秒开"，预加载矩阵怎么设计？

**答**:
- 预载触发矩阵：列表曝光即预载（可视区商品的详情数据+首图，额度受控：并发 ≤3）、即将点击预载（手指按下/长按触发 mousedown 级预载——点击前 200ms 的抢跑）、意图预测（浏览速度/滑动方向预测下一个点击目标，仅 WiFi 下启用）。
- 预载内容分级：P0 详情骨架数据（标题/价格/主图——首屏必需）、P1 图集与规格、P2 评价与推荐——按点击概率分配预载深度，P0 全量、P1 高概率、P2 不预载。
- 秒开渲染：预载数据进内存缓存（LRU 限制 30 个商品），点击命中缓存→跳过 loading 直接渲染；未命中→骨架屏+流式接口（详情接口拆分：核心字段 50ms 级返回）。
- 成本控制：预载请求带预载标识（服务端可降级）、限流（每秒 ≤5 个预载请求）、弱网/WiFi 判断（蜂窝网只预载 P0）、预载命中率监控（命中率 <30% 说明预测策略该调）。

```javascript
const cache = new LRU(30);
listView.on('expose', throttle(async (item) => {
  if (!wifiLike()) return;                   // 蜂窝只预 P0
  prefetch(item.id, ['p0']);                 // 曝光预载 P0
}, { wait: 300, maxConcurrent: 3 }));
listView.on('touchstart', (item) =>
  prefetch(item.id, ['p0', 'p1']));          // 按下抢跑
async function prefetch(id, levels) {
  if (cache.has(id)) return;
  const r = await detailApi.get(id, { levels,
    prefetch: true });                       // 服务端可降级
  cache.set(id, r);
}
async function openDetail(id) {
  const cached = cache.get(id);
  if (cached) return render(cached);         // 秒开
  return renderWithSkeleton(await detailApi.get(id));
}
// 命中率监控：cacheHits / openClicks，目标 >60%。
```
