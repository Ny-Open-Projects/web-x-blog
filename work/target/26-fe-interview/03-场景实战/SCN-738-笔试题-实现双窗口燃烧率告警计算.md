## SCN-738：手写双窗口 burn rate 计算器

**需求与边界**：
- 输入：分钟级可用性序列 `[{ts, ok, total}]`；SLO 0.99；快窗 1h 阈值 14.4，慢窗 6h 阈值 6；输出每分钟告警状态与触发/恢复事件。
- 边界：① burnRate = (1 - 窗口实际可用率) / (1 - SLO)；② 双条件同时满足才告警，任一恢复即解除；③ 窗口数据不足（首小时）用已有样本计算并标注 partial。

**答**：
```javascript
function burnRateAlerts(minutes, slo = 0.99, { fast = 14.4, slow = 6 } = {}) {
  const FAST = 60, SLOW = 360;                       // 分钟数
  let firing = false; const events = [];
  return minutes.map((m, i) => {
    const win = (n) => {
      const slice = minutes.slice(Math.max(0, i - n + 1), i + 1);
      const ok = slice.reduce((s, x) => s + x.ok, 0);
      const total = slice.reduce((s, x) => s + x.total, 0);
      const avail = total ? ok / total : 1;
      return { rate: (1 - avail) / (1 - slo), partial: slice.length < n };
    };
    const f = win(FAST), s = win(SLOW);
    const shouldFire = f.rate > fast && s.rate > slow && !s.partial;   // 慢窗必须满样本
    if (shouldFire && !firing) { firing = true; events.push({ type: 'FIRE', ts: m.ts, fast: f.rate, slow: s.rate }); }
    if (!shouldFire && firing) { firing = false; events.push({ type: 'RESOLVE', ts: m.ts }); }
    return { ts: m.ts, burnFast: f.rate, burnSlow: s.rate, firing, partial: f.partial || s.partial };
  });
}
```

**评分点**:
- burn rate 归一化公式正确（相对错误预算的倍数）。
- 双窗口 AND 触发、任一恢复即解除。
- 慢窗不满样本不告警（防启动误报）+ partial 标注。
- 状态翻转只记边沿事件（FIRE/RESOLVE）。
