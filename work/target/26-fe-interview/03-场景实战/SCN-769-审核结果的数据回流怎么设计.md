## SCN-769：审核结果数据回流怎么设计？
**答**：
- 回流内容：人审结论 + 违规帧标注 + 机审对错（agree/disagree）+ 申诉仲裁结果——构成模型迭代的高质量标注集。
- 回流管线：审核提交时同步写「标注事件流」，离线任务聚合生成训练集；高分歧样本（机审错且申诉翻案）优先进训练。
- 前端配合：标注数据结构标准化（帧级/片段级/全片级），提交时自动附上下文（标准版本/品类/机审分数）。
- 回流质量门槛：进入训练集需通过质检（盲测/复审一致），脏标注污染模型是最大风险。
- 追问钩子：为什么申诉翻案样本最有价值——机审+人审都错、最终仲裁纠正的样本暴露系统性盲区，是模型迭代收益最高的数据；按价值分级回流。

```javascript
function feedbackPacket(review) {
  return {
    videoId: review.videoId, marks: review.marks,    // 帧级标注
    machine: { score: review.machineScore, agree: review.agree },
    standardVersion: review.standardVersion,
    qualityGate: { blindPassed: review.blindPassed, crossChecked: review.crossChecked },
    priority: review.appealReversed ? 'P0'           // 申诉翻案最高优先
            : !review.agree ? 'P1' : 'P2',
  };
}
```
