## SCN-393：多业务线（电商/本地生活/会员充值）的统一收银台怎么设计？

**答**:
- 收银台抽象：统一收银协议（业务方传订单信息→收银台渲染：金额/明细/支付方式），支付方式注册（渠道动态配置：按业务/地区/风控等级启用——微信/支付宝/ApplePay/储值余额），支付流程统一（SCN-209 三通道确认复用）。
- 场景差异配置：业务差异（电商支持组合支付、充值只支持单渠道——能力矩阵），收银台主题（业务品牌皮肤——SCN-241 楼层协议复用），营销集成（可用优惠券选择/支付立减——SCN-206 引擎注入）。
- 可靠性统一：支付结果三通道（SCN-209）、防重复支付（SCN-209 幂等）、支付失败分流（换渠道建议——渠道可用性探测）。
- 安全合规：收银台安全（域名白名单/防钓鱼提示——固定收银台域名+验证标识）、数据隔离（业务订单数据不互见——收银台只见必要支付信息）。

```javascript
// 统一收银协议
cashier.open({
  biz: 'mall', orderId,
  amount, detail: [...],
  allow: { combined: true, channels: auto },  // 能力矩阵
  theme: 'mall-dark',
});
// 渠道注册：channelRegistry（业务/地区/风控过滤）
// 确认：三通道（URL/查询/推送）SCN-209 复用
// 组合支付：balance + wechat 拆分支付。
// 安全：固定收银台域名 + 官方验证标识。
```
