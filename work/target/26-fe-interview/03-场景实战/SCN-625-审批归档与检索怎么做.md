## SCN-625：审批归档与检索怎么做？
**答**：
- 归档不可变：终态实例归档后只读（含时间线/意见/附件），任何「修改历史」操作都是合规事故；导出归档包（PDF + 附件清单）带防伪校验。
- 检索维度：按标题/发起人/时间范围/金额区间/状态/流程类型全文检索（服务端 ES），前端只做条件输入与结果展示；高频筛选条件做成预设。
- 保留策略：按合规等级保留期限（如财务 10 年/一般 3 年），到期进入「待销毁」清单需合规审批——前端展示保留倒计时，防止误删。
- 权限回顾：归档后查看权限仍走权限矩阵，离职人员的审批记录保留（审计不随人员变化丢失）。
- 追问钩子：为什么归档检索要走 ES 而不是数据库 like——全文匹配（标题+意见内容）+ 高亮 + 聚合统计，ES 才满足；前端不加载全量数据。

```javascript
async function searchArchive(q) {
  const { hits, aggs, total } = await api.post('/archive/search', {
    keyword: q.text, filters: q.filters, from: q.page * 20, size: 20,
  });
  return {
    total,
    list: hits.map(h => ({
      ...h._source, id: h._id,
      highlight: h.highlight,                    // ES 命中片段高亮
      retainLeft: retainDeadline(h._source.archiveTs),   // 保留期倒计时
    })),
    buckets: aggs.byType, aggs.byMonth,          // 聚合统计直出
  };
}
```
