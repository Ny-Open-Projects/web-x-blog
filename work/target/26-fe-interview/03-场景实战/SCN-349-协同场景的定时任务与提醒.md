## SCN-349：协作场景的定时提醒（评审提醒/任务截止/文档复审）怎么调度？

**答**:
- 提醒类型体系：任务截止提醒（DDL 前 1 天/当天两级）、文档评审提醒（SOP 复审周期——SCN-312 复审复用）、会议提醒（SCN-295 日历联动）、自定义提醒（用户设任意提醒）。
- 调度架构：服务端调度器（AGT-449 定时调度复用：cron/事件触发/状态触发），触发后多通道触达（站内通知+推送+邮件按用户偏好——SCN-258 通知中心路由），免打扰与合并（同时段多提醒合并推送）。
- 前端职责：提醒设置 UI（相对时间预设：截止前 1 天/绝对时间）、提醒状态呈现（到期任务高亮/过期标记）、 snooze（稍后提醒：10 分钟/明天—— snooze 队列）、多端同步（已读/已 snooze 状态多端一致——SCN-446 同步复用）。
- 依赖校准：提醒时间的时区语义（用户时区为准——SCN-259 复用）、服务端时钟权威（到期判定服务端算——客户端只呈现）。

```javascript
// 提醒设置
reminder.create({ ref: task.id, at: 'ddl-1d',
  channels: user.prefNotify });              // 偏好路由
// 服务端调度（AGT-449）：到期 → 便宜检查（任务是否已完）
//   → 未完才通知（无变化不打扰）→ 多通道路由。
// snooze：reminder.snooze(id, '+10min') → 重排队列
//   状态多端同步（SCN-446）。
// 到期呈现：task.dueAt < now && !done → 高亮 + 过期标记。
```
