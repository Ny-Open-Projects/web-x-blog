## SCN-543：手写月度账单聚合器

**需求与边界**：
- 输入：流水数组 `{ ts, type, direction: 'in'|'out', amountFen, channel }`；输出：月汇总。
- 要求：① 按月聚合收支总额与笔数；② 按类型子分组并求 Top3 支出类型；③ 与上月环比（防除零）；④ 大额单笔（> 阈值）单独列出。

**答**：
```javascript
function monthlyReport(flows, { topN = 3, bigFen = 100_0000 } = {}) {
  const byMonth = new Map();
  for (const f of flows) {
    const ym = new Date(f.ts).toISOString().slice(0, 7);      // UTC 月，注意业务时区校正
    if (!byMonth.has(ym)) byMonth.set(ym, {
      in: 0n, out: 0n, count: 0,
      byType: new Map(), big: [],
    });
    const m = byMonth.get(ym);
    m.count++;
    if (f.direction === 'in') m.in += BigInt(f.amountFen);
    else {
      m.out += BigInt(f.amountFen);
      m.byType.set(f.type, (m.byType.get(f.type) || 0n) + BigInt(f.amountFen));
    }
    if (f.amountFen > bigFen && f.direction === 'out')
      m.big.push({ ts: f.ts, amountFen: f.amountFen, type: f.type });
  }
  const months = [...byMonth.entries()].sort(([a], [b]) => a < b ? -1 : 1);
  return months.map(([ym, m], i) => {
    const prev = months[i - 1]?.[1];
    const growth = prev && prev.out > 0n
      ? Number((m.out - prev.out) * 10000n / prev.out) / 100   // 万分比转百分数，整数环环比
      : null;                                                  // 除零：null 表示无环比
    const topTypes = [...m.byType.entries()]
      .sort(([, a], [, b]) => b > a ? 1 : -1).slice(0, topN)
      .map(([type, v]) => ({ type, out: v.toString() }));
    return { ym, in: m.in.toString(), out: m.out.toString(), count: m.count,
             topTypes, big: m.big.slice(0, 10) };
  });
}
```

**评分点**:
- BigInt 累加金额（不用 float 求和）。
- 环比除零与首月 null 处理。
- TopN 排序稳定且从子分组 Map 聚合。
- 大额单笔独立列表（threshold 参数化）。
