## SCN-650：手写审批报表聚合器

**需求与边界**：
- 输入：终态实例数组 `{ flowType, arriveTs, doneTs, status, approverId, rejectReasons }`。
- 输出：① 按流程类型的时效 P50/P95；② 驳回原因分布（Top5）；③ 审批人处理量 Top10；④ 环比（传入上一周期数据可算）。

**答**：
```javascript
function quantile(sortedArr, q) {
  if (!sortedArr.length) return null;
  const pos = (sortedArr.length - 1) * q;
  const lo = Math.floor(pos), hi = Math.ceil(pos);
  return sortedArr[lo] + (sortedArr[hi] - sortedArr[lo]) * (pos - lo);   // 线性插值
}
function approvalReport(instances, prev = null) {
  const byType = groupBy(instances.filter(i => i.status === 'PASSED'), 'flowType');
  const latency = Object.fromEntries(Object.entries(byType).map(([t, list]) => {
    const durations = list.map(i => i.doneTs - i.arriveTs).sort((a, b) => a - b);
    return [t, { p50: quantile(durations, 0.5), p95: quantile(durations, 0.95), n: list.length }];
  }));
  const rejected = instances.filter(i => i.status === 'REJECTED');
  const reasonCount = {};
  for (const r of rejected) for (const reason of r.rejectReasons || [])
    reasonCount[reason] = (reasonCount[reason] || 0) + 1;
  const load = {};
  for (const i of instances.filter(i => i.status === 'PASSED'))
    load[i.approverId] = (load[i.approverId] || 0) + 1;
  const topLoad = Object.entries(load).sort(([, a], [, b]) => b - a).slice(0, 10)
    .map(([id, n]) => ({ id, n }));
  const wow = prev && {
    rejectRateDelta: rejected.length / instances.length - prev.rejectRate,
    p95Delta: latency && prev.p95ByType
      ? Object.fromEntries(Object.entries(latency).map(([t, v]) =>
          [t, v.p95 - (prev.p95ByType[t] ?? v.p95)]))
      : null,
  };
  return { latency, rejectTop: Object.entries(reasonCount).sort(([, a], [, b]) => b - a)
             .slice(0, 5), topLoad, wow };
}
```

**评分点**:
- 分位数线性插值实现正确。
- 多原因驳回（数组）聚合正确。
- 环比只对可比指标计算（null 防御）。
- 输出结构可直接渲染（TopN 已排序）。
