## SCN-627：特批通道（跳过节点）怎么设计？
**答**：
- 显式通道：跳过是流程定义内的合法能力（freeSkip 节点标记），不是绕过引擎的黑操作；时间线记录「跳过 X 节点，操作人 + 理由」，理由必填。
- 权限与限制：跳过权限仅限指定角色（总经理特批），单实例跳过次数有限；金额超阈值禁止跳过（硬规则，前端 disable + 后端校验）。
- 审计强化：跳过节点的时间线在归档报表中单列统计（跳过率监控）——高频跳过说明流程设计有问题，驱动流程优化。
- 前端呈现：流程图上被跳过节点显示虚线框 + 「已特批跳过」；跳过原因 tooltip 可见（有权限者）。
- 追问钩子：为什么不能悄悄跳过——审批的法律效力依赖完整记录，任何节点缺席都要留痕，否则审计不通过。

```javascript
function skipNode(instance, nodeId, reason, operator) {
  const node = instance.def.nodes.find(n => n.id === nodeId);
  if (node.amountLimit && instance.amountFen > node.amountLimit)
    return { ok: false, reason: 'AMOUNT_LIMIT' };  // 硬规则禁跳
  if (instance.skipCount >= 2)
    return { ok: false, reason: 'SKIP_LIMIT' };
  return api.post(`/instance/${instance.id}/skip`, {
    nodeId, reason, operator,                      // 理由必填 + 审计双字段
  });
}
// 报表：跳过率 = 有跳过记录的实例 / 全部实例，异常升高告警并评审流程定义
```
