## SCN-792：手写片段循环播放控制器

**需求与边界**：
- 需求：enableClip(mark) 进入 [startTs, endTs] 循环（0.5 倍速）；用户拖动/切换标记自动退出并恢复原速；loopCount 统计（审核行为埋点）。
- 边界：① timeupdate 越界 seek 回起点（容差 0.05s 防抖）；② seek 事件与循环内 seek 区分（循环内 seek 不退出）；③ 标记过短（<0.5s）最小播放 0.5s。

**答**：
```javascript
function createClipLoop(video, { speed = 0.5 } = {}) {
  let mark = null, looping = false, loopCount = 0, internalSeek = false;
  function enableClip(m) {
    mark = { startTs: m.startTs, endTs: Math.max(m.endTs, m.startTs + 0.5) };   // 最短 0.5s
    looping = true;
    video.playbackRate = speed;
    video.currentTime = mark.startTs;
    video.play();
  }
  function disable() {
    if (!looping) return;
    looping = false; video.playbackRate = 1;
    report({ loopCount });
    loopCount = 0;
  }
  video.addEventListener('timeupdate', () => {
    if (!looping) return;
    if (video.currentTime >= mark.endTs - 0.05) {     // 容差防边界抖动
      internalSeek = true;
      video.currentTime = mark.startTs;               // 循环回跳
    }
  });
  video.addEventListener('seeking', () => {
    if (!looping) return;
    if (!internalSeek) disable();                     // 用户拖动退出
    internalSeek = false;
  });
  return { enableClip, disable, get looping() { return looping; } };
}
```

**评分点**:
- 内部循环 seek 与用户 seek 区分（internalSeek 标志）。
- 边界容差（endTs-0.05）防抖。
- 最短片段 0.5s 保护。
- 退出时恢复倍速 + loopCount 埋点复位。
