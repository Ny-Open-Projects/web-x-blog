## SCN-526：流水多维筛选器怎么设计？
**答**：
- 筛选模型：单一 filter 对象（时间范围/类型/方向/金额区间/状态/关键词）作为唯一事实源，派生 URL query 与请求参数，三处同源转换。
- URL 承载：筛选态写进 URL（可分享/可回退），但敏感关键词与 token 不入 URL；深度链接恢复筛选后自动查询。
- 组合规则：互斥项（时间预设 vs 自定义范围）与依赖项（选「转账」才出现「对手方」）用规则表声明，防非法组合。
- 性能：筛选变更 debounce 300ms，滚动位置重置，分页回到第一页；计数接口与列表接口并行，计数用于显示「命中 N 条」。
- 追问钩子：为什么筛选逻辑放服务端——流水是海量数据，前端过滤既泄数据又不准（分页内过滤）。

```javascript
const RULES = {
  range:  { exclusive: ['preset'] },
  preset: { exclusive: ['range'], reset: ['range'] },
  type:   { require: { opponent: ['TRANSFER'] } },   // 依赖规则
};
function toQuery(f) {
  const q = {};
  if (f.preset) q.preset = f.preset;
  else if (f.range) { q.start = f.range[0]; q.end = f.range[1]; }
  for (const [k, v] of Object.entries(f)) if (v && k !== 'range' && k !== 'preset') q[k] = v;
  return q;                                          // 服务端执行过滤，前端只拼参数
}
```
