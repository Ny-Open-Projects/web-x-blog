## SCN-1289：手写一个汇率刷新与价格失效联动器

**答**：
- 需求：implement RateAwareCache(cache, rates)。onRateUpdate(currency, newRate) 更新汇率并失效该币种价格缓存（tag 失效）；getPrice(item, currency) 读缓存（miss 回源带新汇率）；输出 { price, rateAt }；汇率更新事件审计。
- 边界：同币种连续更新去抖（1s 内合并）；rates 缺币种抛错；失效操作幂等。
- 评分点：汇率联动；去抖失效；tag 失效；缺汇率

```javascript
class RateAwareCache {
  constructor(cache, rates) {
    this.cache = cache; this.rates = rates;
    this._pending = new Set(); this._timer = null;
  }
  onRateUpdate(currency, value, at = Date.now()) {
    this.rates[currency] = { value, ts: at };
    this._pending.add(currency);
    if (!this._timer) this._timer = setTimeout(() => this.flush(), 1000);
  }
  flush() {
    for (const c of this._pending)
      this.cache.invalidateByTag(`rate:${c}`);         // 失效价格缓存
    this._pending.clear(); this._timer = null;
  }
  async getPrice(item, currency, fetcher) {
    const rate = this.rates[currency];
    if (!rate) throw new Error('无汇率: ' + currency);
    const key = `price:${currency}:${item.id}`;
    const hit = await this.cache.get(key);
    if (hit) return hit;
    const p = await fetcher(item, rate);
    await this.cache.set(key, { ...p, rateAt: rate.ts }, { ttl: 60_000 });
    return p;
  }
}
```
