## SCN-242：低代码编辑器的画布（拖拽/选中/属性面板）交互怎么设计？

**答**:
- 三区数据流：组件面板（可拖拽组件清单）→ 画布（schema 树的可视化渲染+编辑态）→ 属性面板（选中节点的 schema 编辑）——单向数据流：所有编辑操作进命令队列（Command），画布是 schema 的纯渲染（不可直接改 DOM）。
- 拖拽实现：HTML5 DnD 或指针事件自研（跨容器排序/嵌套检测/插入位置指示线）、拖拽预览（ghost 影子）、非法位置拒绝（容器约束：表单组件只能进表单容器）。
- 选中与编辑：点选（画布元素→schema 节点映射，data-schema-id 桥接）、选中态覆盖层（outline+操作柄：复制/删除/层级）、属性面板双向绑定（改属性→Command→schema 变更→画布重渲）。
- 撤销重做：Command 模式（每个编辑操作可逆），撤销栈（合并连续同类操作：连续拖动合并为一次）、快捷键体系（Ctrl+Z/Ctrl+Shift+Z/Ctrl+D 复制）。

```javascript
class EditorStore {
  schema; undoStack = []; redoStack = [];
  dispatch(cmd) {                             // Command 模式
    this.undoStack.push({ cmd, prev: clone(this.schema) });
    this.redoStack = [];
    this.schema = cmd.apply(this.schema);
    notify();                                 // 画布+面板重渲
  }
  undo() {
    const e = this.undoStack.pop();
    if (!e) return;
    this.redoStack.push({ cmd: e.cmd, prev: clone(this.schema) });
    this.schema = e.prev; notify();
  }
}
// 拖拽：pointerdown → ghost → move 计算插入位（目标容器+index）
// → drop 时 dispatch(AddNodeCmd)；非法目标→无操作。
// 选中桥接：画布元素 data-schema-id → 选中节点 → 属性面板。
```
