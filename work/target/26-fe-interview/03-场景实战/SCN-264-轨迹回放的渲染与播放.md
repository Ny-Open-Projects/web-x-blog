## SCN-264：出行轨迹回放（10 万个点、倍速播放），怎么做到流畅？

**答**:
- 数据预处理：抽稀（Douglas-Peucker 或等距抽稀——10 万点抽到 1~2 万渲染点，视觉无损）、分段索引（按时间分桶，倍速跳转直接定位段）、精度裁剪（6 位小数）。
- 渲染方案：轨迹线 canvas 分层绘制（已走轨迹+未走轨迹两层，增量绘制——每帧只画新增段）、移动 marker 用 DOM（单个可交互）、动画驱动 requestAnimationFrame 按时间插值（播放时间轴独立于点密度：位置=时间戳插值）。
- 倍速与拖拽：倍速实现=时间轴倍率（1x/4x/16x——每帧推进的模拟时间倍增）、拖拽进度条→时间点定位（二分查找时间戳→对应段→重绘该段之前轨迹缓存位图）、暂停/续播状态保持。
- 大轨迹的性能兜底：已走轨迹渲染为位图缓存（拖动缩放时重绘位图而非重画点）、视野跟随模式（marker 居中，视野随移动平移——地图移动节流）。

```javascript
const track = simplify(points, 1e-5);       // 抽稀
let simTime = track[0].ts;
function frame(now) {
  simTime += (now - last) * speed;          // 倍速=时间倍率
  const seg = locateByTime(track, simTime); // 二分定位
  const pos = lerp(seg.p1, seg.p2, seg.t);  // 插值
  drawTrailTo(seg.index);                   // 增量画新增段
  marker.setPosition(pos);
  follow && map.setCenter(pos);             // 节流跟随
  last = now;
  playing && requestAnimationFrame(frame);
}
// 拖拽进度：seek(t) → simTime = t → 重绘 trailBitmap
// （已走轨迹位图缓存，增量绘制）。
```
