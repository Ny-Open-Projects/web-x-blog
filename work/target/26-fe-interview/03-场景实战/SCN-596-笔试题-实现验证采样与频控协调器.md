## SCN-596：手写验证采样与频控协调器

**需求与边界**：
- 需求：普通事件按采样率上报（默认 10%）；异常/风控事件全量；全量事件消耗令牌桶但优先级高（可抢占配额）；采样决策可注入（测试）。
- 边界：① 同 key 事件 5 秒内去重；② 令牌桶速率自适应（过载降速）；③ 决策可解释（返回 sample/skip/dedup/token 的原因）。

**答**：
```javascript
function createSampler({ rate = 0.1, bucketRate = 5, bucketCap = 20, rand = Math.random } = {}) {
  let tokens = bucketCap;
  setInterval(() => { tokens = Math.min(bucketCap, tokens + bucketRate); }, 1000);
  const dedup = new Map();                            // key -> lastTs
  function decide(event, now = Date.now()) {
    if (event.urgent) {                               // 异常/风控：全量 + 抢占
      if (tokens < 1) return { take: true, reason: 'urgent-no-token' };  // 仍上报，仅告警
      tokens--;
      return { take: true, reason: 'urgent' };
    }
    const last = dedup.get(event.key);
    if (last && now - last < 5000) return { take: false, reason: 'dedup' };
    dedup.set(event.key, now);
    if (tokens < 1 && rand() < rate) return { take: true, reason: 'sampled' };  // 令牌耗尽走采样
    if (tokens >= 1) { tokens--; return { take: true, reason: 'token' }; }
    return { take: false, reason: 'token-exhausted' };
  }
  function feed(event) {
    const d = decide(event);
    if (d.take) reporter.push(event, { urgent: event.urgent });
    return d;
  }
  return { feed, decide, get tokens() { return tokens; } };   // decide 暴露便于测试注入
}
```

**评分点**:
- 正常采样/异常全量双通道 + urgent 抢占语义。
- 5 秒去重（dedup 原因可解释）。
- 令牌桶限速与采样率兜底（token 耗尽时降为随机采样而非直接丢弃全部）。
- rand 注入保证测试确定性。
