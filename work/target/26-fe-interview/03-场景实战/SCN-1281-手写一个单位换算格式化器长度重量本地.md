## SCN-1281：手写一个单位换算格式化器（长度/重量本地化）

**答**：
- 需求：implement UnitFormatter(region)。length(cm) 返回本地单位值+单位串；weight(kg) 同理；both(sizeCm, weightKg) 组合输出；换算精度按地区（美制 1 位小数）。
- 边界：region 未知按 metric；负数支持；region 缺省 metric；美制分单位（lb/oz）选择按大小（>1lb 用 lb）。
- 评分点：单位换算；美制分单位；region 回退；精度

```javascript
class UnitFormatter {
  constructor(region = 'metric') {
    this.region = region; this.imperial = region === 'US';
  }
  length(cm) {
    if (!this.imperial) return `${cm} cm`;
    return cm * 2.54 < 12 ? `${+(cm / 2.54).toFixed(1)} in`
      : `${Math.floor(cm / 2.54 / 12)} ft ${+(cm / 2.54 % 12).toFixed(1)} in`;
  }
  weight(kg) {
    if (!this.imperial) return `${kg} kg`;
    const lb = kg * 2.20462;
    return lb >= 1 ? `${+lb.toFixed(1)} lb` : `${+lb.toFixed(1)} oz` / 16;
  }
  both(sizeCm, weightKg) {
    return { size: this.length(sizeCm), weight: this.weight(weightKg) };
  }
}
```
