## SCN-407：手写倒计时：服务器时间获取、本地偏移计算、周期校准

**需求与边界**：
- 输入：活动开始时间（服务器时间戳）；输出：精确倒计时。
- 边界要求：① 服务器时间获取含网络延迟补偿（RTT/2）；② 本地偏移定期重校准（时钟漂移）；③ 渲染节流（1s 粒度不逐帧刷）；④ 偏移异常（本地时钟被改）容错。

**答**：
```javascript
class ServerClock {
  async sync() {
    const t0 = Date.now();
    const server = await timeApi.now();        // 服务器时间
    const rtt = Date.now() - t0;
    this.offset = server + rtt / 2 - Date.now(); // 延迟补偿
    return this.offset;
  }
  now() { return Date.now() + this.offset; }   // 校准后时间
}
class Countdown {
  constructor(target, { clock, onTick, onEnd }) {
    this.clock = clock; this.target = clock.now(target);
    this.onTick = onTick; this.onEnd = onEnd;
    this.last = -1;
    this.loop();
  }
  loop() {
    const remain = Math.ceil((this.target - this.clock.now()) / 1000);
    if (remain !== this.last) {                // 1s 粒度渲染
      this.last = remain;
      remain > 0 ? this.onTick(remain) : this.onEnd();
    }
    if (remain > 0) setTimeout(() => this.loop(),
      1000 - (this.clock.now() % 1000));       // 对齐整秒
  }
}
// 校准：sync() 每 5min 一次（时钟漂移修正）；
// 异常：offset 突变 > 60s → 提示本地时钟异常（防改钟作弊）；
// onEnd 后以服务端信令最终确认开抢状态。
```

**评分点**:
- 服务器时间获取含 RTT/2 延迟补偿。
- 周期性重校准（漂移修正）+ offset 异常检测（本地改钟容错）。
- 渲染 1s 粒度节流且对齐整秒边界（不逐帧浪费）。
- onEnd 以服务端信令二次确认（本地推断不作裁决）。
