## SCN-459：手写坐席推荐闭环：意图推荐、采纳率统计、低效推荐下线

**需求与边界**：
- 输入：客户消息、知识库；输出：推荐与反馈闭环。
- 边界要求：① 意图→推荐（带一键插入+变量填充）；② 采纳/忽略埋点；③ 采纳率 <5% 且样本 >100 的推荐自动下线；④ 推荐不代发（客服编辑确认）。

**答**：
```javascript
class AgentAssist {
  async onMsg(msg) {
    const intent = await classify(msg.text);
    const recs = await kbSuggest(intent);
    showSuggestions(recs.map(r => ({
      ...r,
      text: r.template.replace('{{orderNo}}', ctx.order?.id ?? ''),
      insert() { editor.insert(this.text); track(intent, true); },
    })));
    trackShow(intent);                        // 曝光埋点
  }
  track(intent, accepted) {
    stats.inc(`assist.${intent}.${accepted ? 'used' : 'skip'}`);
    const n = stats.count(`assist.${intent}`);
    if (n > 100 && stats.rate(`assist.${intent}.used`) < 0.05)
      featureFlags.off(`assist.${intent}`);   // 低效下线
  }
}
// 推荐可编辑后发送（AI 草稿人拍板——责任边界）；
// 采纳数据回流：高频采纳推荐 → 沉淀话术库（SCN-384 复用）。
```

**评分点**:
- 推荐带变量宏填充（订单号代入）+一键插入。
- 曝光/采纳/忽略三类埋点齐全。
- 低效自动下线（5% 采纳率+100 样本阈值）。
- 推荐不代发的责任边界（可编辑确认）。
