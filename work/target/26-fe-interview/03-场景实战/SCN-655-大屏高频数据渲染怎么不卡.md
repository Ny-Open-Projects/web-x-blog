## SCN-655：大屏高频数据渲染怎么不卡？
**答**：
- 合帧渲染：数据事件进缓冲，rAF 每帧统一消费一次（1 帧 ≤ 16ms 内处理完），推送频率与渲染频率解耦。
- 分级更新：关键告警立即渲染，普通指标进合帧缓冲，图表类用脏标记（只重绘变化的图表）。
- 批量 API：three.js 用 InstancedMesh（万设备一个 draw call），ECharts 用 appendData/增量 setOption（不整图重建）。
- CPU/内存预算：事件缓冲设上限（如 5 万条），溢出丢旧并计数告警；Texture/几何体复用池化。
- 追问钩子：怎么证明优化有效——性能基线：主线程单帧 > 50ms 的帧占比 < 1%，用 Performance 面板 + RUM 帧率采样持续监控。

```javascript
function createFrameRenderer(apply) {
  const buffer = [];
  const MAX = 50_000;
  let scheduled = false, dropped = 0;
  function push(events) {
    buffer.push(...events);
    if (buffer.length > MAX) {                    // 溢出丢旧
      dropped += buffer.length - MAX;
      buffer.splice(0, buffer.length - MAX);
      if (dropped > 1000) report({ type: 'BUFFER_OVERFLOW', dropped });   // 触发推送侧降采样
    }
    if (!scheduled) {
      scheduled = true;
      requestAnimationFrame(() => {               // 合帧：每帧统一消费
        scheduled = false;
        const batch = buffer.splice(0);
        apply(batch);                             // 单次批量应用
      });
    }
  }
  return { push, get dropped() { return dropped; } };
}
```
