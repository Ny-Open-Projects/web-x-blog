## SCN-297：协同办公套件（文档/表格/IM）的离线能力怎么分级设计？

**答**:
- 离线分级矩阵：L1 完整离线（已缓存文档的查看+编辑——CRDT 本地优先 SCN-227）、L2 受限离线（IM 本地历史可读+可发待发队列）、L3 仅缓存（日历只读/任务只读）、L4 不可离线（权限变更/搜索/新建分享）——分级配置化按应用声明。
- 数据预载策略：常用文档自动缓存（最近打开的 N 篇/置顶文档）、手动预载（"标记为离线可用"用户自选）、缓存配额（本地空间上限，LRU 淘汰+用户可见的缓存管理页）。
- 离线交互规范：离线徽标（各页面连接状态全局指示）、离线动作的反馈（编辑可做/发送进队列/搜索不可用提示）、上线同步队列（离线操作按序回放+冲突处理 SCN-224）。
- 同步一致性：同步队列持久化（IndexedDB——崩溃不丢离线操作）、同步失败重试与降级（冲突文档转手动处理队列）、多端同步序（seq 保证跨端顺序）。

```text
离线分级矩阵：
L1 文档：缓存查看+CRDT 编辑（本地优先）
L2 IM：历史可读 + 发送进待发队列
L3 日历/任务：只读缓存
L4 权限/搜索/分享：需在线
预载：最近 N 篇 + 用户自选，配额 LRU
交互：全局离线徽标 + 动作分级反馈
同步：IndexedDB 队列 → 上线按序回放
  → 冲突 → 手动处理队列。
```
