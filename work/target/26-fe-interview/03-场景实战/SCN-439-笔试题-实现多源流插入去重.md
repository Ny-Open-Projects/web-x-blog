## SCN-439：手写多源信息流合并：插入规则、fingerprint 去重、新内容提示条

**需求与边界**：
- 输入：推荐流/关注流/插入项；输出：合并后的流。
- 边界要求：① 插入规则配置化（位置+来源+去重）；② fingerprint 去重（已读/重复内容）；③ 下拉刷新不重置位置（顶部提示条）；④ 曝光计费埋点（广告位可见性判定）。

**答**：
```javascript
class FeedMerger {
  constructor({ rules, seen }) {               // rules: [{pos, source}]
    this.rules = rules; this.seen = seen ?? new Set();
  }
  merge(recommend, following, inserts) {
    const out = []; let ri = 0, fi = 0;
    const used = new Set();
    while (out.length < 20) {
      const rule = this.rules.find(r =>
        out.length === r.pos && !used.has(r.id));
      if (rule) {                              // 插入规则命中
        const item = rule.source === 'ad' ? inserts.shift()
          : following[fi++];
        if (item && !this.dup(item)) {
          out.push(item); used.add(rule.id); continue;
        }
      }
      const next = out.length % 8 < 6
        ? recommend[ri++] : following[fi++];   // 8:2 交替
      if (!next) break;
      if (!this.dup(next)) out.push(next);
    }
    return out;
  }
  dup(item) {
    const fp = fingerprint(item);
    if (this.seen.has(fp)) return true;        // 已读/重复去重
    this.seen.add(fp);
    return false;
  }
}
// 曝光计费：IO threshold 0.5 + ≥1s → billable 埋点
//   （广告曝光标准，SCN-322 曝光口径复用）。
// 刷新：peekNew → 顶部提示条（不重置滚动）。
```

**评分点**:
- 插入规则配置化（位置/来源/used 去重）。
- fingerprint 去重覆盖已读与重复。
- 交替比例逻辑（8:2）清晰可配。
- 新内容提示条（不重置位置）+ 计费级曝光判定。
