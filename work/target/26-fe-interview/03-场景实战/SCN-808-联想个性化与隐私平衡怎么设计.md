## SCN-808：联想个性化与隐私怎么平衡？
**答**：
- 历史词治理：本地存历史（不上传全文），展示前过滤敏感词（服务端敏感词库标记）；支持单条删除与清空。
- 无痕模式：无痕开关开启后不写历史、不参与个性化（请求带 incognito 标记，服务端跳过个性化因子）。
- 共享设备：历史词在展示时默认部分场景脱敏（如健康/金融类目历史折叠为「你搜索过 N 条相关内容」需点击展开）。
- 个性化边界：个性化只影响排序不影响召回过滤（不能用个人画像把某些结果「消失」——信息茧房与合规问题）。
- 追问钩子：为什么历史词存本地而不是服务端——服务端存全文历史是隐私负债（泄露面大）；本地存储 + 服务端只收「匿名的个性化特征向量」是隐私最小化架构。

```javascript
const privacyPolicy = {
  history: { storage: 'local', sensitiveMask: true, perItemDelete: true },
  incognito: { noHistory: true, noPersonalization: true, flag: 'incognito=1' },
  personalization: { sortOnly: true, neverFilterRecall: true },   // 只影响排序
};
function maskIfSensitive(item) {
  return item.sensitive
    ? { folded: true, label: `你搜索过 ${item.count} 条相关内容`, revealOnClick: true }
    : item;
}
```
