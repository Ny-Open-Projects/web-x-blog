## SCN-460：手写客户 360 视图：多业务数据聚合、时效标注、权限裁剪

**需求与边界**：
- 输入：客户 id；输出：聚合视图（订单/工单/会话/会员/黑名单）。
- 边界要求：① 多源并行聚合（Promise.allSettled——单源失败不拖垮）；② 各源数据时效标注（数据截至时间）；③ 字段权限裁剪（客服等级决定可见字段）；④ 敏感数据水印+脱敏。

**答**：
```javascript
async function customer360(customerId, agent) {
  const [orders, tickets, sessions, member] =
    await Promise.allSettled([
      orderApi.byCustomer(customerId),
      ticketApi.byCustomer(customerId),
      sessionApi.history(customerId),
      memberApi.status(customerId),
    ]);
  const pick = (r) => r.status === 'fulfilled' ? r.value : null;
  return {
    orders: pick(orders),                     // 单源失败→null 不拖垮
    tickets: pick(tickets),
    sessions: pick(sessions),
    member: pick(member),
    asOf: Date.now(),                         // 时效标注
    fields: fieldCrop(agent.level),           // 字段权限裁剪
    watermark: true,                          // 敏感数据水印
  };
}
// 脱敏：手机号 138****5678（按 agent.level 决定是否全显）
// 失败源显示"暂时不可用"+重试按钮（不静默空）。
// 字段裁剪：普通客服不见身份证/住址全量。
```

**评分点**:
- allSettled 并行聚合（单源失败不拖垮+重试入口）。
- 字段权限裁剪（客服等级）+脱敏+水印（合规）。
- asOf 时效标注。
- 视图按场景组装（订单/工单/会话分 tab）。
