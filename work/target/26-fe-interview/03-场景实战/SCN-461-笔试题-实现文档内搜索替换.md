## SCN-461：手写文档搜索替换：全量命中列表、逐个跳转、批量替换为单事务

**需求与边界**：
- 输入：文档文本、关键词、替换词；输出：命中列表与替换控制。
- 边界要求：① 全量命中（含偏移列表）；② 逐个跳转高亮（当前命中定位）；③ 替换全部=单事务（一次撤销全撤 SCN-432 复用）；④ 替换后偏移重算（命中列表刷新）。

**答**：
```javascript
function findAll(text, q) {
  const hits = []; let i = 0;
  while ((i = text.indexOf(q, i)) !== -1) {
    hits.push({ start: i, end: i + q.length });
    i += q.length;
  }
  return hits;
}
class SearchReplace {
  constructor(doc) { this.doc = doc; this.hits = []; }
  search(q) { this.hits = findAll(doc.text(), q); return this.hits; }
  jump(idx) {                                 // 逐个跳转
    const h = this.hits[idx];
    editor.scrollTo(h.start);
    editor.highlight(h);                      // 当前命中高亮
    this.cursor = idx;
  }
  replaceAll(q, rep) {
    this.doc.transact(() => {                 // 单事务（一次撤销）
      // 从后往前替换（偏移不失效）
      for (let i = this.hits.length - 1; i >= 0; i--) {
        const h = this.hits[i];
        doc.replace(h.start, h.end, rep);
      }
    });
    this.search(q);                           // 替换后重算命中
  }
}
// 从后往前替换：避免前段替换使后段偏移失效；
// 高亮当前命中 + 命中列表（n/m 计数）。
// 协同：transact 单事务进 CRDT（SCN-344 批量撤销复用）。
```

**评分点**:
- 全量命中含偏移列表；从后往前替换避免偏移失效（关键技术点）。
- 逐个跳转+当前命中高亮+n/m 计数。
- replaceAll 单事务（一次撤销全撤）。
- 替换后命中列表刷新。
