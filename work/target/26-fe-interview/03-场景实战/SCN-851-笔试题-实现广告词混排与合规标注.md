## SCN-851：手写广告词混排

**需求与边界**：
- 需求：自然建议与广告建议混排——规则：① 广告 ≤ 1 条/屏；② 不占首位；③ 必须与输入相关（前缀匹配校验）；④ 必须带「广告」标识，缺标识的广告直接丢弃（合规红线）。
- 输出：混排后列表（含位置索引）+ 广告位统计（供 CTR 分离统计）。

**答**：
```javascript
function mixAds(natural, ads, prefix, { maxAds = 1, minRelatedScore = 0.3 } = {}) {
  const valid = ads.filter(a => {
    if (!a.labeled) { report({ type: 'AD_UNLABELED_DROPPED', id: a.id }); return false; }  // 无标识丢弃
    return relatedness(a.q, prefix) >= minRelatedScore;                // 相关性校验
  }).slice(0, maxAds);
  const INSERT_AFTER = 2;                              // 第 3 位插入（不占首位）
  const mixed = [];
  let adUsed = 0;
  natural.forEach((n, i) => {
    mixed.push(n);
    if (i === INSERT_AFTER - 1 && adUsed < valid.length) {
      mixed.push({ ...valid[adUsed++], ad: true, labeled: true });
    }
  });
  // 尾部兜底：自然条目少时广告放最后
  while (adUsed < valid.length && mixed.length < 10) mixed.push({ ...valid[adUsed++], ad: true });
  return {
    items: mixed,
    adSlots: mixed.map((it, i) => it.ad ? i : null).filter(v => v !== null),   // CTR 分离统计
  };
}
const relatedness = (ad, prefix) =>
  ad.startsWith(prefix) ? 1 : ad.includes(prefix) ? 0.5 : 0;
```

**评分点**:
- 合规红线：无「广告」标识直接丢弃并上报（不静默展示）。
- 位置规则：首位保护 + 单条限额。
- 相关性阈值校验（无关广告伤害体验）。
- 广告位索引输出（自然/广告 CTR 分离）。
