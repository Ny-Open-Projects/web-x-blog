## SCN-309：学生课程表（周课表/冲突检测/上课提醒）怎么实现？

**答**:
- 周课表渲染：时间网格（周视图：按星期×节次网格，课程块渲染——冲突重叠检测：同节次多课重叠标记）、多月/日视图切换、课表来源聚合（必修课表+自选课+直播课多源合并）。
- 冲突检测：选课冲突（选课时实时检测与现有课表冲突——服务端校验+前端即时提示）、调课通知（课程变动推送+课表自动更新）。
- 提醒体系：课前提醒（提前 15 分钟推送+端内提醒——多端触达 SC-306 家长端联动）、直播开播提醒（订阅开播——SCN-349 定时任务）、作业截止提醒（按受众路由 SCN-306）。
- 快捷入口：课程块点击直达（进直播间/查看作业/回放）、下一节课程置顶卡（"下节课 14:00 数学"首页卡片）、请假与调课申请入口。

```javascript
function WeeklyGrid({ courses, week }) {
  const conflicts = detectOverlap(courses);  // 同节次重叠
  return courses.map(c => (
    <CourseBlock key={c.id} {...c}
      conflict={conflicts.includes(c.id)}
      onClick={() => enterCourse(c)} />));
}

// 冲突：overlap = sameSlot(courses) → 标红+选课拦截
// 直播提醒：subscribe(c.liveId) → 开播信令提醒。
```
