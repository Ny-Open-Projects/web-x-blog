## SCN-287：物流详情页（快递时间线+实时位置地图）怎么融合展示？

**答**:
- 双形态融合：时间线为主（节点列表：揽收/运输/派送/签收——每节点时间地点）、地图为辅（车辆实时位置/轨迹线——有 GPS 数据才显示，快递员派送段地图化），折叠交互（地图可展开/收起——弱网/低端机默认收起省流量）。
- 数据聚合：多快递公司接口归一（不同物流商轨迹 schema 不同→统一物流事件模型：{time, status, location, desc}）、轨迹抽稀（回放轨迹 SCN-264 复用）、位置更新频率（派送中 5min 一次，运输中 30min）。
- 状态联动：预计送达时间（ETA 动态更新）、异常状态强调（延误/派送失败→醒目提示+联系快递入口）、签收确认（本人签收 vs 代收标注）。
- 边界：无轨迹数据（老物流商只有文字节点）→ 纯时间线优雅降级、虚拟单号/隐私号（快递员虚拟号拨打保护隐私）。

```javascript
function LogisticsView({ events, track, eta }) {
  return <>
    {track && <CollapsibleMap points={track}   // 抽稀轨迹
      live={last(track)} collapsed={weakNet()} />}
    <Timeline events={normalize(events)}       // 归一事件模型
      highlight={abnormal(events)} />           // 异常强调
    <ETA value={eta} />                        // 动态预计送达
  </>;
}
// 归一：normalize(物流商事件) → {time,status,location,desc}
// 隐私号：courier.phone 是虚拟号，直接 tel: 拨打。
```
