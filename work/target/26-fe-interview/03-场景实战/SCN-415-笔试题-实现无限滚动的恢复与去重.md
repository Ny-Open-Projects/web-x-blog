## SCN-415：手写无限滚动信息流：分页加载、内容去重、切走回来恢复位置

**需求与边界**：
- 输入：数据源（分页接口）、滚动容器；输出：加载控制器。
- 边界要求：① 触底预加载（提前 1 屏）+加载中防重复；② 内容去重（id fingerprint——重复内容不插入）；③ 切走再回恢复位置（位置+内容快照）；④ 新内容刷新不重置位置（顶部提示条）。

**答**：
```javascript
class InfiniteFeed {
  constructor({ fetch, container }) {
    this.fetch = fetch; this.container = container;
    this.items = []; this.page = 0;
    this.loading = false; this.seen = new Set();
  }
  async loadMore() {
    if (this.loading) return;
    this.loading = true;
    try {
      const r = await this.fetch({ page: this.page++ });
      const fresh = r.items.filter(i =>
        !this.seen.has(i.id));                // fingerprint 去重
      fresh.forEach(i => this.seen.add(i.id));
      this.items.push(...fresh);
      append(fresh);                           // 增量 append
    } finally { this.loading = false; }
  }
  checkScroll() {                              // 触底预载
    const { scrollTop, scrollHeight, clientHeight } = this.container;
    if (scrollHeight - scrollTop - clientHeight < clientHeight)
      this.loadMore();                         // 提前 1 屏
  }
  snapshot() {                                 // 切走快照
    return { items: this.items, page: this.page,
      pos: this.container.scrollTop, seen: [...this.seen] };
  }
  restore(snap) {                              // 回来恢复
    this.items = snap.items; this.page = snap.page;
    this.seen = new Set(snap.seen);
    renderAll(snap.items);
    this.container.scrollTop = snap.pos;       // 位置恢复
  }
  checkNew() {                                 // 新内容不重置
    const fresh = this.peekNew();
    if (fresh.length) showTopBar(`${fresh.length} 条新内容`,
      () => prepend(fresh));                  // 点击才插入
  }
}
```

**评分点**:
- 触底提前 1 屏预加载 + loading 防重复请求。
- fingerprint 去重（分页重叠/刷新重复内容过滤）。
- 快照恢复（items+page+seen+scrollTop 四要素）。
- 新内容提示条模式（不重置当前位置）。
