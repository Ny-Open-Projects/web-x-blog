## SCN-255：报表导出（几十万行 Excel）的前端链路怎么设计？

**答**:
- 量级分流：小量（<1 万行）前端直接生成（SheetJS 流式写，Web Worker 不卡 UI）、大量（>1 万行）服务端生成（异步任务：提交导出任务→轮询/通知→下载中心拿文件）——前端生成是体验优化，服务端生成是能力保障。
- 异步导出任务流：提交任务（带筛选条件快照）→ 任务中心（排队/生成中/完成/失败状态）→ 完成通知（站内信/轮询）→ 下载（OSS 签名直链，过期时间）——导出与页面解耦，用户可离开。
- 体验细节：导出进度（行数进度条：服务端分批生成时上报进度）、重复导出去重（同条件任务进行中提示）、失败重试（任务失败原因可见：数据超限/超时）。
- 安全与合规：导出权限点控制、敏感字段导出审批（或自动脱敏）、导出审计（谁导出了什么——数据外流追溯）。

```javascript
async function exportReport(filters) {
  const count = await api.count(filters);
  if (count <= 10000) return exportLocal(filters);   // 前端流式生成
  const task = await api.createExportTask(filters);  // 异步任务
  taskCenter.add(task);                              // 任务中心
  pollOrNotify(task.id);
}
// 任务中心轮询：taskApi.status → done → 下载 URL（签名，15min 有效）
// 进度：task.progress（0-100）→ 进度条
// 去重：进行中同条件任务 → 提示"导出生成中"
// Worker 前端生成（小量）：
// worker.postMessage({ rows, columns }) →
//   流式写 xlsx → Blob 下载，不卡 UI。
```
