## SCN-382：工单智能分配（技能组/负载/优先级）怎么实现？

**答**:
- 分配策略：技能组路由（按问题分类→技能组——意图分类服务端），负载均衡（组内最少在办工单优先/轮询——策略可配），优先级路由（VIP/紧急工单插队——SCN-457 优先级调度复用）。
- 前端呈现：分配透明度（工单详情显示分配原因："按技能组-支付问题分配"——可解释）、手动调整（管理员改派+原因）、分配看板（各技能组负载/积压热力——管理视角）。
- 客服端体验：我的待办队列（优先级排序——高优置顶）、认领模式（自动分配 vs 抢单池——两种模式）、工作负荷提示（个人在办上限——超限不再分配）。
- 数据回流：分配效果分析（各技能组解决率/时长——策略调优依据）、误分类反馈（客服纠正分类→路由模型优化——AGT-354 飞轮复用）。

```javascript
// 分配（服务端）
function assign(ticket) {
  const group = skillGroupOf(ticket.category);   // 意图分类
  const agent = minLoad(group.agents, { cap: 5 });  // 负载均衡
  return priority > 2 ? insertFront(agent, ticket)
    : agent.queue.push(ticket);                // 优先级插队
}
// 可解释：ticket.assignReason = '技能组:支付/负载最少'
// 抢单池：pool.take(ticket) → 原子认领（AGT-476 并发复用）
// 反馈：agent.reclassify(ticket, correctCat) →
//   路由训练数据（AGT-354）。
```
