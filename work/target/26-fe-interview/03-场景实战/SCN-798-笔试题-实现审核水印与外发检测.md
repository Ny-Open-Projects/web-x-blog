## SCN-798：手写审核水印与外发检测

**需求与边界**：
- 需求：全屏工号水印（平铺 canvas）；MutationObserver 防删除（被移除重建并上报）；copy 事件审计（大文本外发记录 + 阻断可配置）。
- 边界：① 水印 pointer-events 穿透；② 定期刷新时间戳；③ 阻断模式只对大文本（>200 字符）生效（不影响正常复制流水号）。

**答**：
```javascript
function auditWatermark(auditorId, { blockCopy = true } = {}) {
  const layer = document.createElement('div');
  layer.style.cssText = 'position:fixed;inset:0;pointer-events:none;z-index:9999';
  const draw = () => { layer.innerHTML = ''; layer.appendChild(makeTiledCanvas(`${auditorId} ${fmtTime(Date.now())}`)); };
  draw();
  document.body.appendChild(layer);
  const mo = new MutationObserver(() => {
    if (!document.body.contains(layer)) {             // 被删除：重建 + 上报
      document.body.appendChild(layer); draw();
      report({ type: 'WATERMARK_REMOVED', auditorId });
    }
  });
  mo.observe(document.body, { childList: true });
  const refresh = setInterval(draw, 60_000);          // 时间戳定期刷新
  document.addEventListener('copy', (e) => {
    const text = e.clipboardData?.getData('text') ?? '';
    report({ type: 'COPY', auditorId, len: text.length });
    if (blockCopy && text.length > 200) e.preventDefault();   // 大文本阻断
  });
  return { destroy: () => { mo.disconnect(); clearInterval(refresh); layer.remove(); } };
}
```

**评分点**:
- 防删重建 + 上报（MutationObserver 守护）。
- pointer-events 穿透不挡操作。
- 剪贴板审计全量 + 阻断只针对大文本（不影响正常工作流）。
- destroy 清理（组件卸载不泄漏）。
