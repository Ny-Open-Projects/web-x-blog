## SCN-463：手写版本对比：段→行→字三级 diff、移动检测、双栏连线

**需求与边界**：
- 输入：旧版/新版文本；输出：diff 可视化。
- 边界要求：① 三级 diff（段级先比对减少噪音→行级→字级细化）；② 移动识别（删除+新增配对为移动——非假变更）；③ 双栏对应连线（变更位置可视化）；④ 变更统计摘要（增/删/改计数）。

**答**：
```javascript
function hierarchicalDiff(oldText, newText) {
  const oldParas = splitParas(oldText);
  const newParas = splitParas(newText);
  const paraDiff = lcsDiff(oldParas, newParas); // 段级
  const changes = [];
  for (const d of paraDiff) {
    if (d.type === 'equal') continue;
    // 行级细化（仅变更段内部）
    const lineDiff = lcsDiff(d.old?.lines ?? [], d.new?.lines ?? []);
    for (const l of lineDiff)
      changes.push({ ...l,
        charDiff: l.type !== 'equal'
          ? charDiff(l.old, l.new) : null });  // 字级标注
  }
  return { changes, moves: detectMoves(changes),
    stats: countBy(changes, 'type') };        // 增/删/改统计
}
function detectMoves(changes) {               // 移动配对
  // 删除块与新增块文本相同（位置不同）→ 配对为 move
  const dels = changes.filter(c => c.type === 'del');
  const adds = changes.filter(c => c.type === 'add');
  const moves = [];
  for (const d of dels) {
    const m = adds.find(a => sameText(a, d));
    if (m) { moves.push({ from: d, to: m }); }
  }
  return moves;                               // → 渲染为移动连线
}
// 双栏渲染：左右文本 + 变更行着色 + SVG 连线（对应关系）。
// 统计条：+X -Y ~Z（变更摘要）。
```

**评分点**:
- 三级 diff 分层（段级降噪→行级→字级）策略正确。
- 移动检测（删除+新增同文本配对）避免假变更。
- 双栏连线可视化与变更统计条。
- LCS diff 的正确使用（段/行两层）。
