## SCN-535：余额不一致排查与时间旅行调试怎么做？
**答**：
- 快照留痕：BalanceStore 每次状态变更落 snapshot（version/来源/事件/pending 集），开发环境保留最近 100 条，可回放定位「用户截图与我方日志不一致」类客诉。
- 时间旅行：基于不可变状态 + 事件溯源，调试面板可逐步重放事件序列（推送/交易/失效），看到每一步 UI 应该是什么。
- 排查三问：哪端旧（version 对比）、事件丢了（seq 空洞）、还是展示错（快照 vs 渲染 props）。
- 生产可用：快照摘要（不含明文金额，仅版本与来源）随错误上报附带，快速还原现场。
- 追问钩子：为什么快照不上传完整金额——隐私最小化，版本号+来源已足够定位。

```javascript
function createTimeTravel(limit = 100) {
  const snaps = [];
  return {
    apply(state, event) {
      snaps.push({ state, event: { ...event, at: Date.now() } });
      if (snaps.length > limit) snaps.shift();
      return state;
    },
    replay(from = 0) {
      return snaps.slice(from).map(s => s.event);   // 事件重放 → 逐步恢复状态
    },
    report() {   // 生产：仅版本与来源摘要
      return snaps.slice(-5).map(s => ({ v: s.state.version, src: s.event.source, t: s.event.at }));
    },
  };
}
```
