## SCN-867：秒杀数据对账怎么做的？
**答**：
- 三方对账：下单数据 vs 支付数据（丢单/超时关闭口径）、库存扣减 vs 售出数量（超卖/泄漏）、优惠发放 vs 核销（优惠券滥用/未使用堆积）。
- 前端角色：提供对账辅助数据（前端埋点的点击/下单事件流）用于三方差异仲裁——「用户确实点了下单但服务端无单」是网络丢单的关键证据。
- 差异分级：金额级差异（资损嫌疑）立即排查；数量级小差异（正常损耗容差内）记录；系统性偏差（某渠道全偏）定向排查。
- 对账自动化：T+1 自动跑批，差异清单进复盘数据包——人工对账在秒杀数据量下不可行。
- 追问钩子：为什么前端埋点能做对账仲裁——客户端事件流是「用户视角的事实」，服务端丢单时客户端事件是唯一旁证；这就是埋点可靠性的深层价值。

```javascript
const reconciliation = {
  pairs: [['order', 'payment'], ['stock-deduct', 'sold'], ['coupon-grant', 'coupon-used']],
  clientEvidence: (orderId) => ({                     // 前端事件流旁证
    clicked: funnel.has('click', orderId), queued: funnel.has('queue', orderId),
    submitted: submitEvents.get(orderId),
  }),
  classify: (diff) => diff.amount > 0 ? 'P0-资损排查'
    : diff.ratio < 0.001 ? 'tolerated' : 'systematic-investigate',
  batch: 'T+1 自动跑批',
};
```
