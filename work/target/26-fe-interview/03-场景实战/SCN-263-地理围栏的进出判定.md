## SCN-263：外卖骑手 App 的地理围栏（进入/离开商圈），前端判定怎么设计？

**答**:
- 判定算法：点在多边形内（射线法 ray casting）或点在圆内（距离比较）——围栏数量少（<20）逐个判定即可；围栏多时空间索引（网格分桶先粗筛）。
- 节流与去抖：定位频率控制（移动中 5~10s 一次）、进出判定去抖（进入围栏需连续 2 次定位在区域内才触发——防 GPS 抖动导致的频繁进出触发）、事件上报服务端裁决（前端判定只是触发提示，业务状态以服务端为准）。
- 定位质量处理：精度半径（accuracy 大于围栏半径时降级判定/标注不确定）、漂移过滤（速度阈值过滤异常跳点：1 秒移动 200m 显然漂移）、缓存上次位置（与上次位置差值过小不上报）。
- 交互与合规：后台定位权限（iOS Always/Android 后台限制——申请理由与降级：前台时才判定）、围栏事件的用户可见反馈（进入商圈 toast"已接单商圈"）、电量考量（后台定位频率与电量平衡，系统级节流适配）。

```javascript
function inPolygon(pt, poly) {              // 射线法
  let inside = false;
  for (let i = 0, j = poly.length - 1;
       i < poly.length; j = i++) {
    const [xi, yi] = poly[i], [xj, yj] = poly[j];
    if ((yi > pt.lat) !== (yj > pt.lat) &&
      pt.lng < (xj - xi) * (pt.lat - yi) / (yj - yi) + xi)
      inside = !inside;
  }
  return inside;
}
let insidePrev = false, streak = 0;
onLocation(async (loc) => {
  if (loc.accuracy > 200) return;          // 精度不足跳过
  const inside = fences.some(f => inPolygon(loc, f.poly));
  streak = inside === insidePrev ? streak + 1 : 1;
  if (streak >= 2 && inside !== insidePrev) {  // 连续2次确认
    insidePrev = inside;
    report(inside ? 'enter' : 'leave', loc);   // 服务端裁决
  }
});
```
