## SCN-682：大屏组件库怎么建设？
**答**：
- 面板协议：每个面板组件实现统一接口（props: data/schema、生命周期 onResize/onThemeChange/onDispose、性能自述——需要的更新频率上限），渲染器按协议调度。
- 分层：基础层（图表封装/3D 基础组件）→ 业务面板（能耗/设备/告警面板）→ 项目层（拼装配置）。复用发生在中两层。
- 数据契约内聚：面板自带数据 schema 与默认降采样策略，接入新项目只需换数据源映射。
- 主题与适配内建：组件不感知具体分辨率（接收设计稿网格区域），主题 token 全走 CSS 变量——换肤不改组件。
- 追问钩子：组件库怎么防「性能劣化」——协议里声明 updateFrequency 上限，渲染器超过上限自动节流；组件性能基准测试进 CI。

```javascript
// 面板协议
export function definePanel(spec) {
  return {
    meta: { name: spec.name, updateHz: spec.updateHz ?? 1, heavy3D: spec.heavy3D ?? false },
    mount(el, { data, theme, grid }) { /* ... */ },
    onResize(grid) { /* 重排 */ },
    onThemeChange(theme) { /* 换肤 */ },
    dispose() { /* 清理监听/图表/3D 资源 */ },
  };
}
// 渲染器调度：updateHz 超限自动节流
const throttled = rateLimit(panel.update, panel.meta.updateHz);
```
