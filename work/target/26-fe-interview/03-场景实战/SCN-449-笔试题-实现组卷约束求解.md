## SCN-449：手写智能组卷：约束求解（覆盖/难度/总分）、AB 卷抽题

**需求与边界**：
- 输入：题库（知识点/难度/分值）、组卷约束；输出：试卷。
- 边界要求：① 知识点全覆盖；② 难度分布达标（易 30/中 50/难 20）；③ 总分等于目标分；④ AB 卷同知识点不同题；⑤ 无解时报告缺口。

**答**：
```javascript
function compose(pool, { count, dist, totalScore, kps }) {
  // 1. 按知识点分桶（保证覆盖）
  const byKp = groupBy(pool, 'kp');
  const missing = kps.filter(k => !byKp[k]?.length);
  if (missing.length)
    return { ok: false, missing };            // 缺口报告
  // 2. 贪心+回溯：按难度配额选题，凑总分
  const paper = [];
  let score = 0;
  for (const [level, ratio] of Object.entries(dist)) {
    const need = Math.round(count * ratio);
    const candidates = pool.filter(p => p.difficulty === level
      && !paper.includes(p))
      .sort(() => Math.random() - 0.5);
    paper.push(...candidates.slice(0, need));
  }
  // 3. 总分校正：替换分值最近的题微调
  adjustScore(paper, totalScore);
  return { ok: true, paper, total: sum(paper, 'score') };
}
function makeAB(bank, constraint) {
  const a = compose(bank, constraint);
  const rest = bank.filter(x => !a.paper.includes(x));
  const b = compose(rest, constraint);        // AB 不同题同知识点
  return { a, b };
}
// 随机序：题目/选项 shuffle（判分按内容不按位置）。
// 无解→缺口报告（哪个知识点/难度缺题）。
```

**评分点**:
- 三重约束建模（覆盖/难度分布/总分）+ 缺口报告。
- 贪心配额+总分微调校正的工程化求解。
- AB 卷从互斥题池各组（同知识点不同题）。
- shuffle 后判分按内容的意识。
