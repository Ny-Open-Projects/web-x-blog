## SCN-569：黑产对抗升级时验证策略怎么演进？
**答**：
- 对抗分层：脚本直调接口（看协议签名与参数混淆）、无头浏览器（看环境特征：webdriver/缺插件/字体异常）、真人农场（看行为与设备信誉）——不同层次不同手段。
- 环境检测：检测自动化特征（navigator.webdriver、CDP 痕迹、权限 API 异常、渲染一致性）作为信号之一，不做唯一依据（会误伤）。
- 动态混淆：验证 SDK 定期更换 JS 结构与采集字段名（自动化构建产出混淆版本），抬高逆向成本。
- 策略演进节奏：攻击上升期自动收紧阈值 + 紧急下发新验证器配置；平稳期放宽减少误伤。
- 追问钩子：永远无法根治怎么办——目标是抬高成本使攻击不划算（经济学），配合业务层手段（限购/实名）。

```javascript
function automationSignals() {
  return {
    webdriver: navigator.webdriver === true,               // 显式标志
    cdp: !!(window.chrome && !window.chrome.app),          // CDP 痕迹（弱信号）
    permMismatch: navigator.permissions && (() =>          // 权限 API 与 UA 不一致
      navigator.permissions.query({ name: 'notifications' })
        .then(p => p.state === 'denied' && Notification.permission === 'default'))(),
    plugins: navigator.plugins.length,                     // 无头常见 0
    langs: navigator.languages?.length || 0,
  };                                                       // 多信号弱证据，交给服务端模型
}
```
