## SCN-754：视频抽帧预览怎么实现？
**答**：
- 雪碧图方案：服务端转码时按固定间隔（如 1s/帧）抽帧生成雪碧图（sprite）+ 元数据（间隔/网格/URL），前端 hover 进度条按时间映射到雪碧图坐标显示——一个请求预览全程，比逐帧截图高效。
- 帧定位：previewTime(t) → spriteIndex + 网格内偏移 → background-position。
- 大视频分片雪碧图：长视频多张雪碧图按需加载（只加载 hover 到的时间段那张）。
- 与机审联动：机审标注帧直接在雪碧图方案上叠加标记点，点击跳转播放。
- 追问钩子：为什么不用 canvas 逐帧 seek 截图——视频 seek 精度与解码耗时不可控（关键帧问题），且主线程卡顿；预生成雪碧图是 O(1) 显示。

```javascript
function spritePosition(t, meta) {                   // meta: { interval, cols, rows, w, h, urls }
  const frameIndex = Math.floor(t / meta.interval);
  const perSheet = meta.cols * meta.rows;
  const sheetIdx = Math.floor(frameIndex / perSheet);
  const idx = frameIndex % perSheet;
  return {
    url: meta.urls[sheetIdx],                        // 按需加载所在雪碧图
    x: -(idx % meta.cols) * meta.w,
    y: -Math.floor(idx / meta.cols) * meta.h,
  };
}
// DOM: <div class="thumb" style={{ backgroundImage: url(p.url),
//        backgroundPosition: `${p.x}px ${p.y}px`, width: meta.w, height: meta.h }} />
```
