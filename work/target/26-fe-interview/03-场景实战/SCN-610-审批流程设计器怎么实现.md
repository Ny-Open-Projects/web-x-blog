## SCN-610：审批流程设计器怎么实现？
**答**：
- 双栏结构：左侧节点物料（审批人节点/条件分支/并行/汇聚/抄送），中间画布拖拽编排，右侧选中节点的属性面板（审批人规则/超时策略/表单权限）。
- 结构化数据：画布操作实时映射为流程定义 JSON（树形结构更易表达分支，序列化为 DAG）；每次操作生成撤销栈快照。
- 约束校验：保存前结构校验（必须单起点单终点、条件分支必须互斥完整、汇聚节点入边数匹配）+ 业务校验（审批人规则非空）；错误定位到具体节点高亮。
- 版本管理：流程定义版本化，发布新版不影响在途实例；设计器支持「复制为草稿」。
- 追问钩子：条件分支的完整性怎么提示用户——引擎要求条件覆盖所有可能（else 兜底分支），设计器在缺失时给出黄色警告而非静默保存。

```javascript
function validateFlow(tree) {
  const errors = [];
  function walk(node, path) {
    if (node.type === 'branch') {
      if (!node.branches.some(b => b.condition === 'else'))
        errors.push({ path, code: 'MISSING_ELSE', nodeId: node.id });   // 条件不完整警告
      for (const b of node.branches) walk(b.child, [...path, node.id]);
    } else if (node.type === 'approver') {
      if (!node.assignee?.rule) errors.push({ path, code: 'NO_ASSIGNEE', nodeId: node.id });
      walk(node.next, path);
    }
  }
  walk(tree, []);
  return { ok: errors.every(e => e.code !== 'NO_ASSIGNEE'), errors };  // else 缺失是警告
}
```
