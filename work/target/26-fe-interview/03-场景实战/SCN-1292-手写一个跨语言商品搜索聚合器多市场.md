## SCN-1292：手写一个跨语言商品搜索聚合器（多市场）

**答**：
- 需求：implement CrossMarketSearch(markets)。search(q) 并行查询多市场（各市场语言 analyzer 不同），合并结果去重（同商品 ID 优先主市场），按综合分排序；输出 { items, markets }。
- 边界：单市场失败不阻塞整体（部分结果返回，标注 failedMarkets）；同商品跨市场库存合并展示；q 空 null。
- 评分点：并行查询；部分失败；跨市场合并；评分排序

```javascript
class CrossMarketSearch {
  constructor(markets) { this.markets = markets; }
  async search(q) {
    if (!q) return null;
    const settled = await Promise.allSettled(
      this.markets.map(m => m.search(q)));
    const failed = settled.filter(s => s.status === 'rejected')
      .map((s, i) => this.markets[i].id);
    const merged = new Map();
    settled.forEach((s, i) => {
      if (s.status !== 'fulfilled') return;
      s.value.forEach(item => {
        const key = item.productId;
        const prev = merged.get(key);
        if (!prev) merged.set(key, { ...item, markets: [this.markets[i].id] });
        else { prev.stock += item.stock;
          prev.markets.push(this.markets[i].id);
          prev.score = Math.max(prev.score, item.score); }   // 跨市场合并
      });
    });
    return { items: [...merged.values()].sort((a, b) => b.score - a.score),
      failedMarkets: failed };
  }
}
```
