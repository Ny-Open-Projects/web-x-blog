## SCN-652：手写审批积压热力图数据聚合

**需求与边界**：
- 输入：在途实例 `{ nodeId, arriveTs }` 快照；输出「节点 × 小时段」积压矩阵，颜色分 5 级（按分位数）。
- 边界：① 时段按到达时间落到当天小时桶；② 每级阈值用分位数而非固定值（适应业务波动）；③ 点击格输出下钻过滤条件。

**答**：
```javascript
function backlogHeatmap(instances) {
  const matrix = {};                                 // nodeId -> [24 cells]
  for (const inst of instances) {
    const hour = new Date(inst.arriveTs).getHours();
    const row = matrix[inst.nodeId] ??= new Array(24).fill(0);
    row[hour]++;
  }
  // 全局分位分 5 级
  const all = Object.values(matrix).flat().sort((a, b) => a - b);
  const qs = [0.2, 0.4, 0.6, 0.8].map(q => quantile(all, q));
  const levelOf = v => qs.findIndex(t => v <= t) === -1 ? 4 : qs.findIndex(t => v <= t);
  const cells = [];
  for (const [nodeId, row] of Object.entries(matrix))
    row.forEach((v, hour) => cells.push({
      nodeId, hour, count: v, level: levelOf(v),
      drill: { filters: { nodeId, arriveHour: hour, status: 'PENDING' } },  // 下钻条件
    }));
  return { cells, thresholds: qs, maxNodes: Object.keys(matrix).length };
}
// 渲染：level 0~4 → 色阶 ['#e8f7ee','#b7e3c7','#7fc99a','#3f9e6e','#1c6b48']
```

**评分点**:
- 节点×24 小时矩阵聚合。
- 分位数自适应色阶（非硬编码阈值）。
- 每格携带下钻过滤条件（可行动）。
- 空桶（0 值）正确落在 level 0。
