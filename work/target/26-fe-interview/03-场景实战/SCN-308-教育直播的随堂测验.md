## SCN-308：直播随堂测验（主讲发题万人作答实时统计）怎么实现？

**答**:
- 发题与作答：主讲发题信令（题目+时限全员弹出——弹窗不遮挡播放可收起）、学生作答提交（轻量接口/信令通道——答题洪峰：万人 30s 内提交）、本地计时（服务端开始时间校准——SCN-020）。
- 实时统计：作答进度（已提交人数进度条）、正确率实时聚合（服务端聚合广播：选项分布条形图）、截止统计（正确率+逐题讲解模式：主讲端展示分布引导讲解）。
- 洪峰处理：提交请求削峰（客户端随机延迟提交 0~3s——统计粒度足够）、服务端聚合（窗口聚合广播统计而非每条广播）、答题通道与直播流分离（互不拖垮）。
- 结果沉淀：测验结果入掌握度（SCN-303/307 联动）、未作答学生标记（辅导老师跟进——SCN-305 工作台）、题目质量回流（正确率过低的题目进教研复核）。

```javascript
ws.on('quiz_start', ({ quiz, endAt }) => {
  showQuizOverlay(quiz, { timer: endAt - serverNow(),
    collapsible: true });                     // 可收起不挡直播
});
async function submitAnswer(choice) {
  await jitter(0, 3000);                      // 削峰分散
  await quizApi.submit({ quizId, choice,
    idempotencyKey: quizId + ':' + me.id });
}
ws.on('quiz_stats', (s) => renderBars(s.dist)); // 选项分布
```
