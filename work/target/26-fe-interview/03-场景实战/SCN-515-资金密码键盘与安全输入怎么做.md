## SCN-515：交易密码安全键盘怎么做？
**答**：
- 防记录：屏蔽物理键盘输入（防键盘钩子）、禁用 input 默认行为，用自绘按键（DOM 乱序布局防轨迹推断）；密码输入框使用 `autocomplete="off"` + 随机 name。
- 防截屏/防调试（App 混合场景）：与 Native 桥接开启 FLAG_SECURE 等截屏防护；Web 端叠加动态水印与检测开发者工具时的软提示（不做恶意对抗）。
- 加密上传：密码不在明文 DOM/内存长存，输入完成即用服务端下发的 RSA 公钥/国密加密，配合防重放 nonce。
- 乱序键盘：每次渲染按键位置随机，防肩窥与轨迹记录；点击区域足够大并有震动/声音反馈（可关）。
- 追问钩子：Web 端安全键盘的真实边界——只能提高成本，无法对抗 root/恶意输入法，核心信任仍在服务端风控。

```javascript
function SecureKeypad({ onConfirm }) {
  const [keys] = useState(() => shuffle([...Array(10).keys()])); // 每次随机布局
  const [buf, setBuf] = useState('');
  const encrypt = async (plain) => {
    const { keyId, pub } = await api.get('/key/latest');  // 服务端公钥 + nonce
    return { keyId, payload: rsaEncrypt(pub, plain + nonce()), plain: undefined };
  };
  return (
    <div className="keypad" onCopy={e => e.preventDefault()}>
      {keys.map(k => <button key={k} onClick={() => setBuf(b => (b + k).slice(0, 6))}>•</button>)}
      <button onClick={async () => onConfirm(await encrypt(buf))}>确认</button>
    </div>
  );
}
```
