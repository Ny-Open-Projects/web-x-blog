## SCN-354：Excel 导入在线表格（格式保真/公式转换/兼容差异）怎么处理？

**答**:
- 导入管线：解析（SheetJS 解析 xlsx：值/公式/样式/合并单元格），转换（Excel 公式→在线公式语法映射——函数子集映射表，不支持函数降级为值+标注），样式映射（字体/颜色/边框/对齐映射到在线样式模型——子集保真策略），合并单元格与冻结保持。
- 保真分级：完全支持（值/基础样式/常用函数）、降级支持（复杂样式/部分函数——值化+批注标注"原为 XX 公式"）、不支持（宏/图表——明确提示丢弃清单），导入报告（差异清单让用户知情）。
- 导出：在线→xlsx 导出（样式与公式反向映射——SCN-255 异步导出复用大数据量）、导出一致性校验（导出再导入 round-trip 抽检——保真度回归测试）。
- 流程体验：导入预览（解析后先预览映射效果再确认导入——所见即所得的导入）、冲突处理（导入到已有表格：覆盖/追加/新 sheet 选择）、大文件（异步导入任务+进度）。

```javascript
async function importExcel(file) {
  const wb = await parseXLSX(file);          // SheetJS
  const plan = wb.sheets.map(s => ({
    values: s.cells,
    formulas: mapFormulas(s.formulas),       // 函数映射表
    unsupported: s.unsupported,              // 宏/图表清单
  }));
  showPreview(plan);                         // 预览+差异报告
  await confirmAndImport(plan);              // 确认后写入 CRDT
}
// 映射：VLOOKUP → 支持；INDIRECT → 值化+批注。
// round-trip 测试：export(import(f)) ≈ f 的保真回归。
// 大文件：asyncImportTask（SCN-255 复用）。
```
