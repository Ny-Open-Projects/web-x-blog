## SCN-631：审批电子签名与合规留痕怎么设计？
**答**：
- 签名层次：账号级签名（登录密码/生物识别确认操作意图）+ 手写签名图（关键单如合同会签）；二者都绑定操作记录而非独立存在。
- 防篡改：签名时生成操作指纹（用户+时间+实例+操作+哈希），服务端签名链（每次操作哈希包含上一次哈希，形成区块链式证据链，SCN-491 时间线回放同源）。
- 留痕完整：谁/何时/在什么端/基于什么版本的内容做的操作，全部记录；截图取证用服务端渲染的快照（前端 DOM 截图可伪造）。
- 前端职责：手写签名 canvas 采集（笔迹采样点+时间，服务端生成签章图），不做任何本地存储；生物识别调系统能力。
- 追问钩子：手写签名图片能被复制盗用怎么办——签名图只在服务端合成到凭证快照里，前端从不下载原始签名文件。

```javascript
function signPad(canvas) {
  const pts = [];
  canvas.addEventListener('pointerdown', e => pts.push({ ...rel(e), t: performance.now(), p: 0 }));
  canvas.addEventListener('pointermove', e => pts.push({ ...rel(e), t: performance.now(), p: e.pressure }));
  return {
    async submit(instanceId) {                     // 只提交采样点，服务端生成签章
      return api.post('/sign', {
        instanceId, strokes: pts,                  // 笔迹+节奏（防临摹盗签的辅助证据）
        opHash: sha256([instanceId, Date.now(), currentUser.id].join('|')),
      });
    },
  };
}
```
