## SCN-466：手写会议成员管理：主持人控制信令、权限校验、被控端处理

**需求与边界**：
- 输入：控制动作（静音/移出/锁会）、角色；输出：信令与两端处理。
- 边界要求：① 信令携带操作者身份（服务端校验主持人权限——前端不可伪造）；② 被静音端 UI 反馈（原因+时长）；③ 移出处理（断开媒体+提示）；④ 锁会后加入被拒（等候室）；⑤ 控制信令最高 QoS。

**答**：
```javascript
// 服务端校验（前端只发请求）
function control(actor, action, target) {
  if (actor.role !== 'host' && actor.role !== 'cohost')
    return { ok: false, reason: 'NO_PERMISSION' };  // 权限服务端裁决
  broadcast('control', { action, target: target.id, by: actor.id },
    { qos: 'critical' });                      // 控制信令最高优先
}
// 被静音端
ws.on('control', (e) => {
  if (e.target !== me.id) return roster.update(e.target, e.action);
  switch (e.action) {
    case 'mute':
      localMute(); toast(`已被主持人静音`); break;
    case 'kick':
      leaveMeeting('您已被移出会议'); break;   // 断媒体+提示
    case 'lock':
      meeting.locked = true; break;
  }
});
// 锁会：join 请求 → locked → 转等候室（准入轮询）
// roster 全员视图同步（成员列表状态一致）。
```

**评分点**:
- 权限校验在服务端（角色裁决，前端请求不可伪造）。
- 控制信令 critical QoS（最高优先）。
- 被控端三类处理完整（静音反馈/移出断流/锁会等候室）。
- roster 视图全员同步一致。
