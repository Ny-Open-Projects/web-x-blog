## SCN-892：手写白屏守护

**需求与边界**：
- 需求：秒杀页核心容器 2s 内必须渲染内容（首屏数据或骨架）；超时判定白屏 → 上报 + 尝试恢复（重拉首屏接口 → 失败则静态兜底）；每用户单次会话最多恢复 2 次。
- 边界：① 骨架渲染不算白屏（判定目标是「核心容器有内容节点」）；② 恢复期间按钮保持不可抢（防半初始化下单）；③ 恢复成功后校验配置版本（快照一致性）。

**答**：
```javascript
function whiteScreenGuard(container, { timeout = 2000, maxRetry = 2 } = {}) {
  let retries = 0;
  const t = setTimeout(async () => {
    const hasContent = container.querySelector('[data-rendered="1"]');
    if (hasContent) return;
    report({ type: 'WHITE_SCREEN', path: location.pathname, retries });   // P0 上报
    if (retries++ >= maxRetry) return showStaticFallback();               // 静态兜底
    lockBuyButton();                                   // 恢复期间禁抢（防半初始化）
    const data = await fetchInitData().catch(() => null);
    if (data && snapshotVersionMatch(data)) {
      renderInit(data);                                // 骨架→真实内容
      unlockBuyButton();
    } else showStaticFallback();
  }, timeout);
  return { stop: () => clearTimeout(t) };
}
function showStaticFallback() {
  render('活动火爆，请稍后刷新重试', { cta: '刷新' });   // 静态兜底页
  report({ type: 'STATIC_FALLBACK' });
}
```

**评分点**:
- 内容判定用 data-rendered 标记（骨架不算白屏）。
- 恢复期间禁抢（半初始化下单 = 资损风险）。
- maxRetry 限次 + 最终静态兜底（死路防护）。
- 快照版本校验（SCN-882 一致性联动）。
