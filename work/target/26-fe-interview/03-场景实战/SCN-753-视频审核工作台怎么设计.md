## SCN-753：视频审核工作台怎么设计？
**答**：
- 三区布局：左侧审核队列（待审列表/优先级）、中间播放器（抽帧预览/片段定位）、右侧审核表单（结果/违规类型/意见）——一屏完成全流程，减少切换。
- 队列分发：审核员按技能组（不同内容品类）分配，服务端派单（抢占式领取 + 锁定超时释放），前端显示「当前审核中」与剩余队列数。
- 机器辅助：机审结果（置信度/违规帧标记）叠加在时间轴上，人审重点看机器标注片段——人机协同提效核心。
- 快捷操作：键盘快捷键（通过/驳回/跳转下一个违规点），审核效率直接决定 throughput。
- 追问钩子：为什么机审置信度 0.99 还要人审——高置信误杀率仍然存在且审核决策影响创作者收益，高风险内容（涉政/未成年人）必须人审兜底；低风险可配置直放。

```javascript
const Workbench = () => {
  const { current, queue } = useReviewQueue();       // 服务端派单+锁定
  return (
    <Layout>
      <QueuePanel items={queue} current={current} />
      <PlayerPanel videoId={current.id} marks={current.machineMarks} />  {/* 机审标注叠加 */}
      <FormPanel onSubmit={submitReview} shortcuts={SHORTCUTS} />
    </Layout>
  );
};
const SHORTCUTS = {
  'a': 'pass', 'r': 'reject', 'n': 'nextMark', 'p': 'prevMark',
  'space': 'playPause',
};   // 审核效率是核心指标：全键盘流
```
