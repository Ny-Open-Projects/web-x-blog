## SCN-1285：手写一个营销日历活动判定器（多国活动并行）

**答**：
- 需求：implement PromoCalendar(campaigns)。active(country, now) 返回该国家生效活动（时间窗+国家命中），优先级高的标 primary；display(campaign, tz) 输出本地化倒计时；冲突：同国多活动按优先级叠加（折扣叠加规则校验）。
- 边界：campaigns 空返回 null；时间窗全 UTC；时区展示按国家 tz；折扣超限（> 80%）标记审查。
- 评分点：国家过滤；优先级；UTC 窗口；折扣审查

```javascript
class PromoCalendar {
  constructor(campaigns) { this.campaigns = campaigns; }
  active(country, now = Date.now()) {
    const hit = this.campaigns.filter(c =>
      c.countries.includes(country) &&
      now >= c.startUtc && now < c.endUtc)
      .sort((a, b) => b.priority - a.priority);
    return { primary: hit[0] ?? null, others: hit.slice(1),
      stackWarning: hit.length > 1 ? '多活动叠加需校验折扣上限' : null };
  }
  display(c, tz) {
    return { endsAt: new Intl.DateTimeFormat(undefined,
        { timeZone: tz, timeStyle: 'short' }).format(new Date(c.endUtc)),
      discount: c.discountPct,
      review: c.discountPct > 80 ? '折扣超 80% 需审查' : null };
  }
}
```
