## SCN-369：会议中的白板协作（全员画笔/模板/会议关联）怎么实现？

**答**:
- 白板通道：会议内白板（SCN-231 白板全复用：笔迹流+元素 CRDT——与会议信令共享连接），权限模式（全员可画/仅主持人画/演示模式——画笔权限切换信令）、光标呈现（SCN-223 多光标复用）。
- 低延迟要求：笔迹延迟 <100ms（绘制中的预览流优先级最高——笔迹通道 QoS 高于其他消息）、洪峰（多人同时画——笔迹流合并渲染 SCN-231 聚合复用）。
- 会议集成：白板与会议布局（白板占屏布局切换——共享画面同级）、白板快照（会议录制时白板同步录制——混流包含白板层）、会后留存（白板内容导出/关联会议纪要——SCN-293 链路）。
- 模板与工具：白板模板（SWOT/流程图模板——教学与复盘场景）、图形工具集（形状/便利贴/连接线）、多页白板（分页——页面序列 SCN-343 复用）。

```javascript
// 会议白板初始化（复用白板基建）
const board = createBoard(roomId, {
  transport: meetingTransport,               // 共享会议连接
  permission: 'all' | 'hostOnly',
});
penStream.qos = 'high';                      // 笔迹高优先
// 布局：boardLayout() → 共享画面同级切换
// 录制：mixer.addLayer(board.canvas)          // 混流含白板
// 会后：board.export() → attach(minutes)。
// 权限切换：host.setPenMode('all') → 信令广播全员。
```
