## SCN-495：手写大屏布局：面板注册表、栅格布局配置、数据源绑定刷新

**需求与边界**：
- 输入：布局配置（面板类型/位置/数据源）；输出：大屏渲染。
- 边界要求：① 面板白名单注册（类型→组件——SCN-241 复用）；② 栅格布局（12 栅格配置位置大小——响应式缩放）；③ 数据源绑定（每面板独立源+刷新间隔）；④ 面板错误隔离（单面板挂不拖垮——SCN-207 复用）。

**答**：
```javascript
const PANELS = { line: LinePanel, map: MapPanel, stat: StatPanel };
function renderDashboard(config) {
  return config.panels.map(p => {
    const C = PANELS[p.type];
    if (!C) return null;                       // 白名单外跳过
    return (
      <PanelErrorBoundary key={p.id}
        fallback={<PanelDead title={p.title} />}>  {/* 错误隔离 */}
        <div style={gridStyle(p.grid)}>        {/* 栅格定位 */}
          <C {...p.props}
            dataSource={bindSource(p.source)} />  {/* 数据绑定 */}
        </div>
      </PanelErrorBoundary>);
  });
}
function bindSource({ type, url, interval }) {
  if (type === 'ws') return wsSubscribe(url);  // 推送
  if (type === 'poll') return poll(url, interval ?? 30e3);  // 轮询
  return staticData(url);                      // 静态
}
// 12 栅格：grid-col/row-span 配置；分辨率自适应
//   （scale 缩放——大屏分辨率适配 transform scale）。
// 数据：ws/poll/static 三种源类型（面板声明）。
```

**评分点**:
- 面板白名单注册+错误隔离（SCN-207/241 复用）。
- 12 栅格配置定位+分辨率 scale 缩放（大屏适配）。
- 数据源三类型绑定（ws/poll/static）+面板级刷新间隔。
- key 稳定渲染（面板独立更新）。
