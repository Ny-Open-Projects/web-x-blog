## SCN-307：错题本（自动收集/知识点聚合/间隔复习）怎么实现？

**答**:
- 错题收集：自动入本（考试/作业错题自动收集——SCN-301 闭环）、手动添加（拍照错题：OCR 题干还原+裁剪编辑）、错题信息结构化（题目/我的答案/正确答案/知识点标签/错因分类：粗心/知识缺口）。
- 知识点聚合：错题按知识点聚类（掌握度弱的知识点排序展示——SCN-303 掌握度联动）、同类错因统计（"计算错误 ×12"提示习惯问题）。
- 复习调度：间隔复习队列（1/3/7/15 天间隔——答对升级间隔答错重置）、到期提醒（今日待复习 N 题——首页入口）、复习模式（隐藏答案自测+标记掌握）。
- 变式练习：错题变式（同知识点换数字/换情境——题库变式服务）、变式答对才算掌握（掌握判定严格化）。

```javascript
function MistakeBook({ groups, due }) {
  return <>
    <KnowledgeGroups groups={groups}          // 按知识点聚类
      sort="weakFirst" />
    <ReviewDue count={due.length}             // 今日到期
      onStart={() => reviewMode(due)} />
    <CauseStats causes={groupCause(groups)} /> {/* 错因统计 */}
  </>;
}
```
