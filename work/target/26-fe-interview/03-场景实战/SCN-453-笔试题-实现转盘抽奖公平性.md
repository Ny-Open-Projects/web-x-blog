## SCN-453：手写转盘抽奖：结果服务端定、动画旋转对齐角度、抽奖幂等

**需求与边界**：
- 输入：抽奖请求；输出：动画与结果。
- 边界要求：① 中奖结果服务端定（前端不预知——防抓包）；② 动画旋转角度与结果扇区精确对齐；③ 抽奖幂等（次数扣减）；④ 动画结束才显示结果（悬念体验）。

**答**：
```javascript
async function draw(wheelId) {
  const r = await lotteryApi.draw(wheelId,
    { idempotencyKey: `${wheelId}:${me.id}:${today()}` }); // 服务端定结果
  if (!r.ok) return toast(r.reason);           // 次数不足等
  // 动画：旋转到结果扇区（角度对齐）
  const segAngle = 360 / r.totalSegments;
  const target = 360 * 6 +                      // 转 6 圈
    (r.segmentIndex * segAngle + segAngle / 2); // 指针指扇区中心
  await animateWheel(target, { duration: 4000,
    easing: 'easeOut' });                      // 减速停在扇区
  showPrize(r.prize);                          // 动画完展示结果
}
// 服务端：结果在请求时已定（扣次数+发奖），前端只拿
//   segmentIndex 做动画——抓包只能提前拿 index（可接受，
//   或分两步：先抽后取结果——进一步防预知）。
// 幂等：每日一次/次数扣减服务端裁决。
```

**评分点**:
- 结果服务端裁决+扣次数（前端不预知总奖池）。
- 动画角度对齐扇区中心的数学正确（totalSegments/segmentIndex）。
- 动画先于结果展示（悬念体验）。
- 幂等键含日期（每日限次）。
