## SCN-471：手写通知频控：同源合并窗口、免打扰时段、推送→站内降级

**需求与边界**：
- 输入：通知事件流；输出：触达决策。
- 边界要求：① 同源合并（同人 5min 内同类事件合并为一条计数）；② 免打扰时段（用户偏好+紧急豁免）；③ 推送失败→站内降级；④ 触达历史可查（用户可见）。

**答**：
```javascript
class NotifyThrottle {
  constructor({ mergeMs = 5 * 60e3 }) { this.mergeMs = mergeMs; }
  async deliver(n, user) {
    // 1. 免打扰（紧急豁免）
    if (inQuietHours(user) && n.level !== 'critical')
      return inAppOnly(n);                     // 只进站内不推
    // 2. 同源合并
    const key = `${user.id}:${n.groupKey}`;
    const pending = pendingOf(key);
    if (pending && Date.now() - pending.ts < this.mergeMs) {
      pending.count++;                         // 合并计数
      updatePending(pending);                  // "CPU告警 ×23"
      return { merged: true };
    }
    // 3. 通道尝试+降级
    try {
      await push.send(n, user);                // 推送
      await inApp(n);                          // 站内同时
    } catch (e) {
      await inApp(n);                          // 推送失败→站内
      await smsIfCritical(n, user);            // critical→短信
    }
    markPending(key, n);                       // 合并窗口记账
    return { delivered: true };
  }
}
// 历史：delivered log（用户可见自己收到的通知）；
// 合并展示："CPU 告警 ×23 条"点击展开明细。
```

**评分点**:
- 同源合并窗口（5min 计数聚合）+ 明细展开。
- 免打扰时段+critical 豁免的分级。
- 推送失败→站内→短信的降级链（critical 才短信）。
- 触达历史可查（透明）。
