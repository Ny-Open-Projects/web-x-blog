## SCN-482：手写甘特拖拽：任务移动/边缘拉长、依赖联动后移、冲突检测

**需求与边界**：
- 输入：拖拽事件（移动/拉伸）、依赖图；输出：排期更新与联动。
- 边界要求：① 移动任务（起点变→依赖它的任务联动后移）；② 拉长时长（ef 变→下游联动）；③ 资源冲突检测（同一人同时段多任务标红）；④ 调整结果持久化（乐观锁）。

**答**：
```javascript
function onGanttDrag(task, { type, deltaDays }) {
  if (type === 'move') task.start += deltaDays;
  if (type === 'resize') task.dur += deltaDays;
  cascade(task);                               // 依赖联动
  const conflicts = resourceConflict(task);    // 资源冲突
  renderSchedule(schedule(allTasks));          // 全图重排（SCN-481）
  highlightConflicts(conflicts);
  saveTask(task, { version: task.version });   // 乐观锁持久化
}
function cascade(task) {                       // 下游联动后移
  const ef = task.start + task.dur;
  for (const dep of tasksDependingOn(task.id)) {
    if (dep.start < ef) {
      dep.start = ef;                          // 依赖任务顺延
      cascade(dep);                            // 递归传播
    }
  }
}
// 资源冲突：同 assignee 同时间段 → 标红提示（不强制阻止）。
// 拖拽中实时预览 + 松手提交（乐观锁 CAS 失败提示刷新）。
```

**评分点**:
- move/resize 两类拖拽语义正确。
- cascade 递归联动（依赖任务顺延传播）。
- 资源冲突检测（同人同时段标红）。
- 乐观锁持久化+全图重排（SCN-481 复用）。
