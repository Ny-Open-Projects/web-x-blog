## SCN-416：手写点赞乐观更新：状态翻转、计数增减、失败回滚、连点合并

**需求与边界**：
- 输入：帖子对象、点赞接口；输出：更新控制器。
- 边界要求：① 乐观翻转立即生效+动画；② 失败回滚原状态+提示；③ 连点合并（300ms 窗口只发最终态）；④ 幂等键防重复计数。

**答**：
```javascript
class LikeControl {
  constructor(post) {
    this.post = post; this.timer = null;
    this.pending = false;
  }
  toggle() {
    // 1. 本地立即翻转（乐观）
    this.post.liked = !this.post.liked;
    this.post.likes += this.post.liked ? 1 : -1;
    animate(this.post.id);
    // 2. 连点合并：300ms 窗口只发最终态
    clearTimeout(this.timer);
    this.timer = setTimeout(() => this.sync(), 300);
  }
  async sync() {
    if (this.pending) return;                  // 上一次在途
    this.pending = true;
    const snapshot = { liked: this.post.liked,
      likes: this.post.likes };
    try {
      await api.like(this.post.id, snapshot.liked, {
        idempotencyKey: `like:${this.post.id}:${snapshot.liked}` });
    } catch (e) {
      // 3. 失败回滚到同步前状态
      this.post.liked = !snapshot.liked;
      this.post.likes = snapshot.likes - (snapshot.liked ? 1 : -1);
      revert(this.post.id);
      toast('操作失败，请重试');
    } finally { this.pending = false; }
  }
}
// 幂等键含目标状态：重试同状态不重复计数；
// 回滚公式：likes 回到 sync 前的本地原值。
```

**评分点**:
- 乐观翻转先行 + 失败精确回滚（snapshot 前状态）。
- 连点合并（300ms 只发最终态）+ pending 防在途并发。
- 幂等键带目标状态。
- 回滚伴随用户提示（失败可感知）。
