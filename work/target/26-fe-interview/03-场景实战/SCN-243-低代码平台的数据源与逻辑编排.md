## SCN-243：低代码的数据源绑定与事件逻辑编排（无代码写逻辑）怎么设计？

**答**:
- 数据源抽象：数据源类型（API 请求/静态 JSON/其他节点状态/全局状态），API 数据源配置（URL/参数映射/自动请求时机：挂载时/手动/依赖变化），数据源状态管理（loading/data/error 三态注入组件）。
- 逻辑编排两种范式：事件-动作流（触发器→动作序列：条件分支/请求/赋值/跳转/消息，可视化编排）、表达式（简单逻辑用表达式，复杂逻辑逃生舱写自定义代码——受控的自定义 JS 沙箱）。
- 组件间联动：状态中心（全局/页面/组件三级状态），联动协议（组件 A 状态变更→订阅者响应），跨页面参数传递（路由参数/临时存储）。
- 治理：逻辑复杂度度量（超过阈值提示该写代码而非拖拽——低代码的能力边界意识，SCN 低代码共存篇）、逻辑复用（自定义动作沉淀为平台动作库）。

```javascript
// 数据源配置示例
{
  type: 'api',
  url: '/api/goods/list',
  params: { kw: '{{state.search}}' },       // 表达式绑定
  trigger: 'onMount|onDepsChange',
}
// 事件-动作流
{
  event: 'onClick',
  actions: [
    { type: 'request', source: 'submitOrder' },
    { type: 'condition', if: '{{resp.code === 0}}',
      then: [{ type: 'navigate', to: '/success' }],
      else: [{ type: 'toast', msg: '{{resp.msg}}' }] },
  ],
}
// 沙箱执行：动作序列解释执行（不 eval 用户 JS）；
// 自定义代码逃生舱 → Web Worker 沙箱（无 DOM 访问）。
```
