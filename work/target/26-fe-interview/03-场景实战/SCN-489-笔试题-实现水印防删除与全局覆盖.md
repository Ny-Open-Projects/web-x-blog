## SCN-489：手写水印层：canvas pattern、MutationObserver 防删除、全局覆盖含弹窗

**需求与边界**：
- 输入：水印文本（用户+时间）、配置；输出：水印层。
- 边界要求：① canvas 生成 pattern（随机角度平铺——防批量裁剪）；② MutationObserver 防删除重建；③ 全局覆盖（弹窗/iframe/新内容之上——zIndex 策略）；④ 性能（一次性生成背景，滚动不重绘）；⑤ 防篡改样式（pointer-events none）。

**答**：
```javascript
function createWatermark({ text }) {
  const c = document.createElement('canvas');
  const ctx = c.getContext('2d');
  c.width = 300; c.height = 200;
  ctx.translate(150, 100);
  ctx.rotate((Math.random() * 30 - 15) * Math.PI / 180); // 随机角度
  ctx.font = '14px sans-serif';
  ctx.fillStyle = 'rgba(0,0,0,0.06)';
  ctx.fillText(text, -ctx.measureText(text).width / 2, 0);
  const el = document.createElement('div');
  el.style.cssText = `position:fixed;inset:0;z-index:2147483647;
    pointer-events:none;background:url(${c.toDataURL()}) repeat;`;
  document.body.appendChild(el);
  const mo = new MutationObserver(() => {      // 防删除/防改样式
    if (!document.body.contains(el) ||
        el.style.display === 'none')
      document.body.appendChild(el);
  });
  mo.observe(document.body, { childList: true,
    attributes: true, subtree: false });
  // 弹窗覆盖：水印层 z-index 最大 + fixed inset 0（覆盖一切浮层）
  return { destroy: () => { mo.disconnect(); el.remove(); } };
}
// 随机角度+用户信息+时间戳（溯源三要素）；
// 弱点认知：内核级截图可绕过——威慑+溯源定位（SCN-315 边界）。
```

**评分点**:
- canvas pattern 随机角度平铺（防批量裁剪删除水印）。
- MutationObserver 双重防（删除重建+display 修正）。
- z-index 最大+fixed inset+pointer-events none（覆盖一切交互不受影响）。
- 一次性生成背景（性能）+溯源三要素+绕过边界认知。
