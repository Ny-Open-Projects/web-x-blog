## SCN-520：金融页面错误兜底与资损提示怎么设计？
**答**：
- 错误分级渲染：网络类可重试、业务类给可行动文案（限额/余额不足）、系统类转客服；绝不把原始错误码/堆栈直接抛给用户。
- 资损敏感路径的「不确定态」：支付/转账结果未知（超时）时，UI 永远显示「处理中」，禁止渲染「失败」——失败文案可能引发二次支付造成资损。
- 防资损文案校验：金额、收款人等关键字段在确认 UI 由独立组件渲染并做双录校验（渲染值必须来自同一 source 对象），防止模板错位显示错金额。
- 兜底边界：ErrorBoundary 分区（表单区崩溃不影响余额展示），崩溃时交易入口自动禁用而非带病运行。
- 追问钩子：怎么验证文案不会引发资损——关键提示走评审 + 灰度文案实验（SCN-OPS 灰度体系）。

```javascript
class TxBoundary extends Component {
  state = { err: null };
  static getDerivedStateFromError(err) { return { err }; };
  componentDidCatch(err, info) { report({ err, info, zone: 'tx-form' }); }
  render() {
    if (this.state.err)
      return <FaultPane safe="交易入口已暂停，资产数据不受影响" cta="联系客服" />; // 不显示"支付失败"
    return this.props.children;
  }
}
function AmountView({ tx }) {                // 双源校验：渲染值与提交值必须同源
  useEffect(() => {
    if (tx.displayFen !== tx.submitFen) report({ type: 'AMOUNT_MISMATCH', tx });
  }, [tx]);
  return <b>{fenToYuan(tx.displayFen)}</b>;
}
```
