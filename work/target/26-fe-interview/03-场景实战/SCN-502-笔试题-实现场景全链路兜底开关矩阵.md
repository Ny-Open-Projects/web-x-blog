## SCN-502：手写兜底开关矩阵：分级开关注册、一键降级编排、演练验证

**需求与边界**：
- 输入：开关注册表（各降级动作）、应急等级；输出：一键降级编排。
- 边界要求：① 开关注册（动作/见效速度/影响面/依赖顺序——SCN-402 清单复用）；② 一键降级（按等级执行动作序列——有序不冲突）；③ 恢复路径（逐项恢复+验证）；④ 演练验证（开关真的可用——预发定期演练）。

**答**：
```javascript
const SWITCHES = [                               // 按见效速度排序
  { id: 'off-tracking', action: stopTracking, level: 1,
    impact: '丢失非核心埋点', speed: 'instant' },
  { id: 'slow-poll', action: slowDownPolling, level: 1,
    impact: '数据延迟', speed: 'instant' },
  { id: 'disable-rec', action: hideRecommend, level: 2,
    impact: '推荐楼层隐藏', speed: 'instant' },
  { id: 'static-fallback', action: staticPage, level: 3,
    impact: '整页静态兜底', speed: 'instant' },
];
async function degrade(level) {                  // 一键降级编排
  const ops = SWITCHES.filter(s => s.level <= level);
  const results = [];
  for (const s of ops) {                         // 顺序执行（依赖）
    try { await s.action(); results.push({ id: s.id, ok: true }); }
    catch (e) { results.push({ id: s.id, ok: false,
      error: e.message }); alert(s.id); }        // 失败告警不中断
  }
  audit.log({ type: 'degrade', level, results });
  return results;
}
async function recover() {                       // 逐项恢复+验证
  for (const s of SWITCHES.reverse()) {
    await s.restore?.();
    await verify(s.id);                        // 恢复后验证可用
  }
}
// 演练：weekly → prefireDegrade(2) → 全开关验证 → 恢复
//   （没演练过的降级是摆设——SCN-204 纪律）。
```

**评分点**:
- 开关注册表含四要素（动作/等级/影响面/见效速度）。
- 一键降级按等级顺序编排（不冲突）+单项失败告警不中断。
- 恢复路径逐项+验证。
- 演练验证纪律（预发定期跑降级链）——SCN-402 SOP 闭环。
