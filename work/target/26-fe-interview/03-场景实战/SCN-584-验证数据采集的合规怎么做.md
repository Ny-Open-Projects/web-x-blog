## SCN-584：验证数据采集合规怎么做？
**答**：
- 分级授权：一般信号（屏幕/UA）进隐私政策即可；敏感个人信息（人脸、精确位置、通讯录相关）必须单独授权且可撤回——架构上把敏感采集做成可选信号。
- 最小必要：每个采集字段声明用途（「Canvas 指纹用于设备风控」），隐私政策字段清单与代码白名单用 CI 对齐（代码采集了清单外字段即失败）。
- 存储与流转：指纹与行为数据留存期限明确（如 180 天）、脱敏存储、不出境合规（数据跨境评估）；用户可申请删除。
- 未成年人：识别未成年用户关闭人脸验证通道（法律限制），转短信验证。
- 追问钩子：合规怎么落地到工程——采集层字段白名单 schema + CI 校验 + 隐私字段打标（PII 标记自动传播到日志/埋点链路）。

```javascript
const COLLECT_SCHEMA = {                          // 采集白名单（CI 与隐私政策对齐）
  screen: { purpose: '设备风控', pii: false },
  canvasFp: { purpose: '设备指纹', pii: false },
  faceFrame: { purpose: '活体验证', pii: true, consent: 'face', retention: 0 },  // 不落盘
  geo: { purpose: '异地登录判定', pii: true, consent: 'geo', coarse: true },     // 只存粗粒度
};
function collect(key) {
  const f = COLLECT_SCHEMA[key];
  if (!f) throw new Error(`采集字段 ${key} 未登记（合规红线）`);
  if (f.pii && !consent.has(f.consent)) return null;          // 未授权不采集
  return f.pii ? anonymize(raw[key], f) : raw[key];
}
```
