## SCN-871：活动配置错误怎么防？
**答**：
- 配置即发布：活动配置（价格/库存/时间/规则文案）按发布流程管理——校验（价格上下限/库存与目标匹配/时间顺序）→ 预览（配置渲染成真实页面预览）→ 双人审批 → 定时生效。
- 预览必须真实：配置预览不是表格而是「渲染后的页面快照」——运营看到的是用户将看到的页面，配错一眼可见。
- 时间线校验：开始时间 < 结束时间、预热时间 < 开始时间、多场次不重叠（同 SKU）——机器校验 + 提示确认双重。
- 复盘归类：配置错误型事故在复盘单列（区别于代码缺陷），推动配置系统的校验规则迭代——同类错误重复出现说明校验缺失。
- 追问钩子：为什么配置预览要「渲染成页面」而不是表格核对——运营对表格不敏感（看着都对），对页面敏感（价格显示错了立刻发现）；把校验翻译成运营的语言。

```javascript
const configGuard = {
  validation: {
    price: (p) => p > 0 && p <= maxPrice,
    timeline: (c) => c.warmupTs < c.startTs < c.endTs && noOverlap(c.skus),
    stock: (s) => s >= target.salesEstimate * 0.8,     // 库存与目标合理性
  },
  preview: { mode: 'rendered-page-snapshot', not: 'table' },
  release: { dualApproval: true, scheduledEffect: true },
  review: { category: 'config-error', loop: '校验规则迭代' },
};
```
