## SCN-418：手写协作光标：相对位置锚定、他人插入自动跟随、超时移除

**需求与边界**：
- 输入：协作成员光标状态、文档编辑流；输出：光标渲染位置。
- 边界要求：① 光标存相对锚（不存绝对偏移——他人插入不串位）；② 本地编辑后他人光标自动跟随（锚点前后判断偏移）；③ 成员超时清理（30s 无心跳）；④ 重叠光标错开渲染。

**答**：
```javascript
class CursorTracker {
  constructor() { this.cursors = new Map(); }   // userId → {anchor, ts}
  setLocal(userId, offset, docLength) {
    // 简化锚：{offset, userId 排序优先级}
    // 协同插入跟随规则：他人插入在锚点之前 → 锚 +diff；
    //   之后 → 不变；同位置 → siteId 决胜（SCN-417）
    this.cursors.set(userId, { offset, ts: Date.now() });
  }
  onRemoteInsert(pos, len, byUser) {            // 他人插入
    for (const [uid, c] of this.cursors) {
      if (uid === byUser) continue;
      if (c.offset > pos || (c.offset === pos && uid > byUser))
        c.offset += len;                        // 锚点在其后 → 偏移跟随
    }
  }
  onRemoteDelete(pos, len) {
    for (const [uid, c] of this.cursors) {
      if (c.offset > pos)
        c.offset = Math.max(pos, c.offset - len); // 删除区间收缩
    }
  }
  render(docText) {                             // 渲染（含清理）
    const now = Date.now();
    const items = [];
    let overlap = 0;
    for (const [uid, c] of this.cursors) {
      if (now - c.ts > 30000) {                 // 30s 超时清理
        this.cursors.delete(uid); continue;
      }
      items.push({ uid, offset: c.offset,
        x: overlap++ % 3 });                    // 重叠错开 3 列
    }
    return items.map(i => ({ ...i,
      y: lineOf(docText, i.offset) }));         // 偏移→行列
  }
}
```

**评分点**:
- 锚点语义正确：插入在锚前→跟随偏移，之后不变，同位置 siteId 决胜。
- 删除区间收缩处理（锚点在删除区间内吸附到 pos）。
- 30s 超时清理（离线成员光标移除）。
- 重叠光标错开渲染（同位置多人不遮挡）。
