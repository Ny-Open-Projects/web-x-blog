## SCN-509：账户敏感信息脱敏展示怎么设计？
**答**：
- 默认脱敏：卡号/手机号/证件号默认只显示尾号，完整值不在首屏 HTML 里——点击「查看」才调接口取，且取回后 30 秒自动回脱敏态。
- 服务端脱敏优先：能脱敏的（资产总额可配置隐藏）由服务端返回 `****`，前端不做「拿到明文再打码」——防爬虫抓接口直接拿明文。
- 复制管控：完整卡号禁止复制或复制走剪贴板埋点 + 风控计数；截图场景叠加动态水印（工号 + 时间）。
- 生命周期：脱敏组件对 visibility/blur 事件响应，切后台立即回脱敏；定时器清理防内存泄漏。
- 追问钩子：如何防止用户 F12 改样式看明文——根本防线是服务端不下发明文，前端只是展示层。

```javascript
function useMaskedSecret(fetchFull, { revealMs = 30_000 } = {}) {
  const [full, setFull] = useState(null);
  const [revealing, setRevealing] = useState(false);
  const timer = useRef();
  const reveal = async () => {
    if (!full) setFull(await fetchFull());     // 点击才取明文
    setRevealing(true);
    clearTimeout(timer.current);
    timer.current = setTimeout(() => {
      setRevealing(false); setFull(null);      // 30s 后丢弃明文，回脱敏
    }, revealMs);
  };
  useEffect(() => () => clearTimeout(timer.current), []);
  useEffect(() => {                            // 切后台立即脱敏
    const onVis = () => document.hidden && setRevealing(false);
    document.addEventListener('visibilitychange', onVis);
    return () => document.removeEventListener('visibilitychange', onVis);
  }, []);
  return { reveal, revealing, text: revealing ? full : maskTail(full) };
}
```
