## SCN-275：直播连麦（观众上麦PK/嘉宾连线）的流管理与体验？

**答**:
- 连麦流程：申请/邀请→接受→推流发布（观众端从拉流者变推拉流者）→混流（服务端把多路流合成一路——观众端只需拉混流，简单端不处理多路）、结束→停止推流→回归纯拉流。
- 布局切换：连麦布局动画（主播大屏→连麦分屏布局过渡）、画面自适应（连麦人数变化布局：1v1/2v2/1+N 模板）、语音连麦（纯音频成本更低）。
- 质量保障：连麦者上行自适应（带宽检测自动降码率）、回声消除（连麦者需戴耳机提示——免提回声问题）、延迟匹配（连麦延迟 <500ms 要求 RTC，与主播拉流延迟差异导致的时间感错位提示）。
- 边界处理：连麦者网络差→卡顿显示（不黑屏）、连麦中断自动下麦、连麦权限与内容安全（连麦画面审核：截图审核异步）。

```javascript
async function acceptMicLink(invite) {
  await requestMedia();
  const stream = await rtc.publish({ audio: true, video: true });
  player.switchToMixed();                    // 切换拉混流
  setState('linked', { layout: '1v1' });
}
async function endLink() {
  await rtc.unpublish();
  localStream.getTracks().forEach(t => t.stop());
  player.switchToNormal();                   // 回纯拉流
}
// 布局：layoutEngine.apply('1v1') 带过渡动画；
// 回声：detectNoHeadset() && toast('建议佩戴耳机避免回声')。
```
