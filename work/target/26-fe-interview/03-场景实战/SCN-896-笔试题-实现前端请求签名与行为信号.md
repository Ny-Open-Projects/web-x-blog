## SCN-896：手写请求签名器

**需求与边界**：
- 需求：抢购请求签名 = HMAC(时序参数 + 设备指纹 + 行为摘要, 会话密钥)；签名算法版本随构建轮换；行为摘要 = 页面停留时长 + 交互计数哈希；无行为信号标记 report-only 上报。
- 边界：① 签名带时间戳窗口（±30s 有效，防重放）；② 行为摘要只含统计量（不存轨迹，隐私最小化）；③ 签名失败不重试（直接上报）。

**答**：
```javascript
function createSigner(sessionKey, { version = BUILD_SIGN_VER, window = 30_000 } = {}) {
  const behavior = { enterTs: Date.now(), interactions: 0 };
  document.addEventListener('pointerdown', () => behavior.interactions++, { passive: true });
  function sign(payload) {
    const ts = Date.now();
    const dwell = Date.now() - behavior.enterTs;
    const summary = `${dwell}:${behavior.interactions}`;   // 统计量摘要（隐私最小化）
    const sig = hmacSHA256(sessionKey,
      JSON.stringify([payload, ts, summary, version]));
    const suspicious = dwell < 1000 || behavior.interactions === 0;
    if (suspicious) report({ type: 'NO_DWELL', dwell, version });   // report-only
    return { ts, sig, ver: version, behaviorDigest: summary };
  }
  function verifyFreshness(ts) {
    return Math.abs(Date.now() - ts) <= window;        // 服务端也校验，双端一致
  }
  return { sign, verifyFreshness, get version() { return version; } };
}
```

**评分点**:
- 签名输入含版本号（算法随构建轮换）。
- 行为摘要只用统计量（停留+交互数，不存轨迹）。
- 时间窗口防重放（±30s）。
- 无停留行为 report-only 不本地拦截（判定权在服务端，SCN-553 原则）。
