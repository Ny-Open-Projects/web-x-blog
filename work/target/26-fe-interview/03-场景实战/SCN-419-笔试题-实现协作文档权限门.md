## SCN-419：手写文档权限门：角色能力对象、按权限订阅通道、被踢出处理

**需求与边界**：
- 输入：用户、文档 ACL；输出：能力对象与连接策略。
- 边界要求：① 角色能力矩阵（edit/comment/view——决定订阅哪些通道）；② 无权通道不订阅（连接即授权）；③ 编辑中被收回权限→切只读+本地未同步内容保留提示；④ 本地能力判断仅为体验，操作仍需服务端校验。

**答**：
```javascript
function capabilities(user, doc) {
  const role = doc.acl[user.id] ?? doc.public ?? 'none';
  return {
    canEdit: ['owner', 'editor'].includes(role),
    canComment: ['owner', 'editor', 'commenter'].includes(role),
    canRead: role !== 'none',
    canShare: role === 'owner',
    role,
  };
}
async function connectDoc(user, doc) {
  const caps = capabilities(user, doc);
  if (!caps.canRead) throw new Error('NO_ACCESS');   // 连接即授权
  const channels = ['content'];                       // 内容通道人人有
  if (caps.canEdit) channels.push('ops');             // 编辑操作通道
  if (caps.canComment) channels.push('comments');
  const conn = await ws.join(doc.id, { channels, token: user.t });
  conn.on('kicked', () => {                    // 权限被收回
    editor.toReadonly();
    const pending = editor.unsyncedEdits();
    if (pending.length)
      backupLocal(pending);                    // 未同步内容本地保留
    toast('您的编辑权限已被收回，未同步内容已本地保存');
  });
  // 操作仍带 token 由服务端校验（本地能力只是 UI 体验）
  conn.on('ops_reject', (e) =>
    toast(`操作被拒绝：${e.reason}`));
  return { caps, conn };
}
```

**评分点**:
- 能力矩阵驱动通道订阅（无权通道不订阅——连接即授权）。
- kicked 处理完整：切只读+未同步内容本地保留+用户告知。
- 本地能力仅 UI 层、服务端强制校验的双层意识。
- ops_reject 反馈路径（隐藏按钮绕过的兜底）。
