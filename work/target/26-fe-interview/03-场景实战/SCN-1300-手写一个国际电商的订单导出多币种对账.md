## SCN-1300：手写一个国际电商的订单导出（多币种对账）

**答**：
- 需求：implement OrderExport(orders)。export(currency) 导出订单（金额换算至统一币种+汇率快照），行含 { orderId, gross, fxRate, amountBase }；对账校验（各币种小计合计 = 总额）；输出 CSV 行与校验结果。
- 边界：无汇率币种跳过并记录 skipped；汇率缺失抛错；金额精度 2 位；orders 空返回空。
- 评分点：汇率换算；快照；跳过记录；对账校验

```javascript
class OrderExport {
  constructor(orders, rates) {
    this.orders = orders; this.rates = rates;          // { currency: { value, ts } }
  }
  export(target = 'USD') {
    const rows = [], skipped = [];
    let sum = 0;
    for (const o of this.orders) {
      const rate = this.rates[o.currency];
      if (!rate) { skipped.push(o.currency); continue; }
      const base = +(o.amount * rate.value).toFixed(2);
      sum += base;
      rows.push({ orderId: o.id, gross: o.amount,
        currency: o.currency, fxRate: rate.value, amountBase: base });
    }
    return { rows, total: +sum.toFixed(2), skipped,
      check: skipped.length ? '存在无汇率币种，需补汇率后重导' : '对账一致' };
  }
}
```
