## SCN-485：手写审批表单态：流程中只读、驳回解锁重提、路径恢复到驳回点

**需求与边界**：
- 输入：流程实例状态；输出：表单态控制。
- 边界要求：① 审批中表单只读（字段禁编辑——按节点能力）；② 驳回到发起人→表单解锁可改；③ 重提后流程恢复到驳回节点（不从头走——SCN-425 条件路由复用）；④ 重提需变更说明（改了什么留痕）。

**答**：
```javascript
function formMode(instance, userId) {
  if (instance.status === 'rejected' &&
      instance.rejectTo === 'start' &&
      instance.initiator === userId)
    return 'editable';                         // 驳回发起人→解锁
  if (instance.currentNode?.assignee === userId &&
      instance.currentNode.type === 'approval')
    return 'approvable';                       // 当前审批人→审批态
  return 'readonly';                           // 其他→只读
}
async function resubmit(instance, form, changeNote) {
  // 变更留痕：diff 原值 vs 新值
  const diff = diffForm(instance.formSnapshot, form);
  await api.resubmit(instance.id, { form, diff,
    changeNote });                             // 改动说明必填
  // 流程恢复到驳回节点（服务端按 rejectAt 恢复——不从头走）
}
// 审批态：当前审批人可同意/驳回/转交（按钮按节点能力渲染）；
// 只读态：字段禁用+审批时间线可见。
```

**评分点**:
- 三态判定（editable/approvable/readonly）逻辑正确。
- 驳回解锁+重提 diff 与改动说明留痕。
- 重提恢复到驳回节点（不从头走——SCN-425 复用）。
- 按节点能力渲染操作按钮（approvable 才有同意按钮）。
