## SCN-674：大屏动效设计怎么克制？
**答**：
- 动效分层级：状态型动效（告警脉冲/数值滚动，有语义必须保）、氛围型动效（背景粒子/光效，可关）、过场型动效（页面切换，短且快）。氛围型在数据密度高时降级或移除。
- 性能预算：动效只允许 transform/opacity（GPU 合成）；同屏同时运行的动效数量上限（如 8 个）；3D 场景动效（相机漫游/粒子）单独 GPU 预算。
- 数值动画规范：数字滚动时长 300~600ms，间隔刷新合并（防高频抖动）；图表动画只在首次加载与数据突变时播。
- 值守模式联动：长时间无人交互后动效自动降级（保电、保 GPU），有人操作恢复。
- 追问钩子：怎么量化动效是否「抢数据」——眼动/可用性测试 + 简单度量：告警确认耗时在动效版本 vs 静态版本对比，告警响应变慢即超标。

```javascript
const MOTION_BUDGET = { maxConcurrent: 8, ambient: false, dataDense: true };
function motionGate(kind) {
  if (kind === 'state') return true;                        // 语义动效必保
  if (kind === 'ambient') return MOTION_BUDGET.ambient && runningCount() < MOTION_BUDGET.maxConcurrent;
  return true;                                              // 过场动效默认放行
}
function rollingNumber(el, from, to, { duration = 500 } = {}) {
  if (motionGate('state')) animateValue(el, from, to, duration);
  else el.textContent = to;                                 // 降级直出
}
```
