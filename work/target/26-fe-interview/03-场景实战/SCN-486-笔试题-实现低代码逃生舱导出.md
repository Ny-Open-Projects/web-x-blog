## SCN-486：手写低代码逃生舱：schema→可维护代码生成、单向门标记

**需求与边界**：
- 输入：页面 schema；输出：可维护的组件代码。
- 边界要求：① 代码生成（schema→组件 JSX：结构/样式 token 化/事件绑定）；② 生成代码可编译可运行（lint+类型校验）；③ 单向门标记（导出后页面转手写维护——平台标记不再允许回低代码）；④ 生成物含来源注释。

**答**：
```javascript
function exportCode(schema, { tokens }) {
  const code = [`// 低代码导出 @${new Date().toISOString()} // 单向门：导出后转手写维护`];
  code.push(genComponent(schema, { tokens }));  // 递归生成 JSX
  const styles = genStyles(schema, { tokens }); // 样式 token 化
  return { files: [{ name: 'Page.jsx', code: code.join('\n') },
    { name: 'page.css', code: styles }],
    checks: { lint: runLint(code), types: runTsc(code) } };
}
function genComponent(node, ctx, depth = 0) {
  const comp = REGISTRY[node.type]?.jsx ?? 'div';
  const props = genProps(node.props, ctx);     // 表达式→JSX 表达式
  const children = (node.children ?? [])
    .map(c => genComponent(c, ctx, depth + 1)).join('\n');
  const events = genEvents(node.events, ctx);  // 动作→事件处理器
  return indent(depth) + `<${comp} ${props} ${events}>${children}${indent(depth)}</${comp}>`;
}
// 表达式转换：{{a.b}} → {ctx.a?.b}；
// 单向门：导出登记 → 平台该页面只读（防双轨漂移）；
// 校验：生成物过 lint/tsc 才交付。
```

**评分点**:
- 生成三件套：组件 JSX+token 化样式+事件处理器。
- 表达式转换语义正确（{{a.b}}→JSX 表达式）。
- 单向门：导出登记+平台只读（防双轨漂移）。
- 生成物 lint/tsc 校验（可编译才交付）+来源注释。
