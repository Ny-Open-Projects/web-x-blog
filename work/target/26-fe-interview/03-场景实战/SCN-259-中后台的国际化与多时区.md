## SCN-259：中后台多语言（i18n）与多时区怎么系统化落地？

**答**:
- 文案 i18n：key 化文案（t('order.status.paid')），缺失兜底（缺 key 显示 key 本身+上报）、复数/插值（ICU 规范）、文案翻译流程（提取→翻译平台→构建注入/运行时拉取）。
- 时区处理：存储与传输一律 UTC（ISO8601），展示按用户时区（配置的偏好时区而非浏览器时区——跨国团队用户自选），关键场景双时区显示（列表显示本地+悬浮显示源时区），服务端定时任务的时区语义明确（"每日 9 点"是哪个时区——配置化声明）。
- 本地化细节：数字/货币/日期格式（Intl API：Intl.NumberFormat/DateTimeFormat）、时区缩写歧义（显示 GMT+8 比 CST 更准确）、RTL 语言（阿语布局镜像——逻辑属性 margin-inline）。
- 工程化：切语言不刷新（locale 热切换+组件重渲）、语言包分包（按语言懒加载）、翻译完整性 CI 检查（key 覆盖率门禁）、伪本地化测试（pseudo-i18n 检查布局溢出）。

```javascript
// 时区统一：存 UTC，展示本地
const t = (iso) => new Intl.DateTimeFormat(locale, {
  timeZone: user.tz, dateStyle: 'medium',
  timeStyle: 'short' }).format(new Date(iso));
// 关键双时区：<Time utc={x}/> + hover 源时区
```
