## SCN-793：手写处置扇出聚合器

**需求与边界**：
- 需求：处置动作扇出到 4 路（推荐/搜索/CDN/外链），每路独立重试（指数退避，最多 3 次）；聚合状态输出（DONE/RETRYING/FAILED）；全部终态后触发对账确认。
- 边界：① 各路独立互不影响；② 重试用幂等键（同 key 重试不重复执行）；③ FAILED 路进人工对账队列。

**答**：
```javascript
async function fanoutTakedown(videoId, channels) {
  const idem = `td-${videoId}-${Date.now()}`;
  const results = await Promise.all(channels.map(async (ch) => {
    for (let i = 0; i <= 3; i++) {
      const r = await ch.exec({ videoId, idempotencyKey: `${idem}:${ch.name}` })
        .catch(() => null);
      if (r?.ok) return { channel: ch.name, status: 'DONE' };
      if (i < 3) await sleep(backoff(i, 1000));
    }
    return { channel: ch.name, status: 'FAILED' };
  }));
  const summary = {
    done: results.filter(r => r.status === 'DONE').length,
    failed: results.filter(r => r.status === 'FAILED'),
  };
  if (summary.failed.length) await manualReconcileQueue.push({ videoId, idem, failed: summary.failed });
  else await reconcile.confirm(videoId);             // 全部成功触发对账确认
  return { results, summary };                       // 前端聚合呈现
}
```

**评分点**:
- 每路独立重试 + 幂等键防重复执行。
- FAILED 进人工对账队列（最终一致兜底）。
- 全部成功才触发对账确认。
- 聚合输出可直接渲染（各路状态）。
