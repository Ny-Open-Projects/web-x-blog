## SCN-455：手写表格引用列：关联记录取值、源表变更增量刷新、失效标记

**需求与边界**：
- 输入：引用列配置（源表+字段）、源表变更流；输出：引用列值更新。
- 边界要求：① 取值：关联记录的指定字段；② 源变更只刷新受影响行（增量——非全表）；③ 关联记录删除→失效标记；④ 循环引用检测（A 引用 B、B 引用 A）。

**答**：
```javascript
class LookupColumn {
  constructor(config, sourceTable) {
    this.config = config; this.source = sourceTable;
    this.source.observeDeep((chg) => this.refresh(chg));
  }
  value(row) {                                 // 取关联值
    const rel = row[this.config.key];          // 关联记录 id
    const rec = this.source.get(rel);
    return rec ? rec[this.config.field]
      : { error: '已删除', stale: true };     // 失效标记
  }
  refresh(chg) {                               // 增量刷新
    // 只刷新引用了变更记录的行（影响面反向索引）
    const rows = rowsReferencing(chg.recordIds);
    rows.forEach(r => renderCell(r, this.value(r)));
  }
}
// 循环引用：建列时依赖图 DFS（SCN-407 复用）→ 拒绝成环。
// 源变更广播：CRDT observeDeep → 影响面反向索引
//   （recordId → 引用行集合）——SCN-477 复用。
```

**评分点**:
- 引用取值+删除失效标记（stale）正确。
- 增量刷新：反向索引定位受影响行（不全表刷）。
- 循环引用检测（建列时拒绝）。
- observeDeep 的 CRDT 深层监听使用正确。
