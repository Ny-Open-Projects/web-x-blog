## SCN-507：交易明细虚拟滚动 + 按月分组吸顶怎么做？
**答**：
- 扁平化渲染：分组头与明细混排成同一扁平数组（month header 是特殊 rowType），虚拟列表只看总行高，不嵌套滚动。
- 动态行高：明细行高固定、汇总头固定，用高度数组 + 前缀和做 offset 二分定位；不确定高度（多行备注）用 ResizeObserver 校正。
- 分组吸顶：当前视口首行所属 month 的 header 用 sticky 定位钉在容器顶部，滚动跨组时切换。
- 数据懒载：按月懒加载，滚动到相邻月边界时预取下一个月；跳月（日期选择器）直接定位 offset。
- 追问钩子：吸顶头与虚拟列表的结合点——header 不进虚拟池，单独渲染当前 month 变量。

```javascript
function buildFlatRows(months) {              // months: [{ key:'2026-11', items:[...] }]
  const rows = []; const offsets = [0];
  for (const m of months) {
    rows.push({ type: 'header', key: m.key });
    for (const it of m.items) rows.push({ type: 'item', data: it });
  }
  let h = 0;
  for (const r of rows) { h += r.type === 'header' ? 44 : 76; offsets.push(h); }
  return { rows, offsets };
}
function indexAt(offsets, y) {                // 二分找可视首行
  let lo = 0, hi = offsets.length - 1;
  while (lo < hi) { const mid = (lo + hi) >> 1; offsets[mid] < y ? lo = mid + 1 : hi = mid; }
  return lo - 1;
}
```
