## SCN-514：定投/代扣协议管理页怎么设计？
**答**：
- 协议生命周期：创建 → 生效 → 暂停/恢复 → 终止，前端动作按钮由服务端下发的 allowedActions 决定，不本地推断（涉及签约合规）。
- 扣款计划可视化：未来扣款日历（金额/扣款日/扣款卡），失败记录带原因与补扣安排；改期/改额要二次确认并提示生效周期（下期生效还是本期）。
- 风险提示：修改/终止协议时展示影响（如定投中断影响收益计划），合规文案不可关闭式强提示。
- 状态同步：扣款结果推送更新对应计划项状态；页面打开时强制校验协议最新状态（可能已在别端终止）。
- 追问钩子：扣款失败后自动补扣的展示——同一笔业务显示为一次失败 + 一次补扣，金额别重复计入。

```javascript
function ProtocolCard({ p, onChange }) {
  // p: { id, status, nextCharge: { date, amount, card }, allowedActions, fails: [...] }
  return (
    <div>
      <StatusTag status={p.status} />
      <Calendar plan={p.plan} fails={p.fails} />      {/* 失败日标红，hover 原因 */}
      {p.allowedActions.map(a => (
        <button key={a} onClick={() => confirmAndCall(a, p)}>{ACTION_TEXT[a]}</button>
      ))}
      {p.fails.length > 0 && (
        <Alert type="warning" text={`上期扣款失败：${FAIL_TEXT[p.fails[0].reason]}，将于 ${p.retryDate} 补扣`} />
      )}
    </div>
  );
}
```
