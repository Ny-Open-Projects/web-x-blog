## SCN-617：表单版本升级与在途审批兼容怎么做？
**答**：
- 快照原则：提交时锁定表单 schema 版本 + 数据快照，审批人在途看到的永远是提交时版本——审批结论针对提交时的内容。
- 新版本迁移：仅对「草稿/退回待修改」的实例提供迁移（diff 提示新增字段需补填、删除字段自动丢弃）；已提交不可迁移。
- 字段级映射：v1→v2 有字段改名/类型变化时提供映射表（迁移器执行），映射失败的实例人工处理列表。
- 审批人视角：审批页若发现实例版本 < 当前最新，提示「本单使用旧版表单（v1.2），字段定义可能与当前不同」。
- 追问钩子：为什么不允许审批中动态升级 schema——审批人已基于旧字段给出意见，换字段等于换题目，结论失效。

```javascript
function migrateDraft(instance, fromSchema, toSchema, mapping) {
  const patch = {};
  for (const [oldKey, rule] of Object.entries(mapping)) {
    if (rule.type === 'rename') patch[rule.to] = instance.data[oldKey];
    if (rule.type === 'transform') patch[rule.to] = rule.fn(instance.data[oldKey]);
  }
  const dropped = Object.keys(instance.data).filter(k => !mapping[k]);
  const missing = toSchema.required.filter(f => patch[f] === undefined);   // 新增必填待补
  return {
    ...instance, data: patch, schemaVersion: toSchema.version,
    warnings: { dropped, missing },               // 提示用户补填
  };
}
```
