## SCN-481：手写任务排期：依赖图拓扑、关键路径计算、环检测、甘特渲染

**需求与边界**：
- 输入：任务（时长+依赖）；输出：排期（最早开始/结束+关键路径）。
- 边界要求：① 环检测（先于排期）；② 最早开始=依赖最晚完成（ES/EF/LS/LF 计算）；③ 关键路径（总时差为 0 的链——延期影响整体的链）；④ 甘特渲染（时间轴刻度+任务条+依赖线）。

**答**：
```javascript
function schedule(tasks) {                     // tasks: [{id, dur, deps}]
  const cycle = detectCycle(tasks);            // 环检测（SCN-407 复用）
  if (cycle) throw new Error(`依赖环: ${cycle.join('->')}`);
  const es = {}, ef = {};
  for (const t of topoOrder(tasks)) {          // 拓扑序
    es[t.id] = Math.max(0, ...t.deps.map(d => ef[d] ?? 0));
    ef[t.id] = es[t.id] + t.dur;
  }
  const projectEnd = Math.max(...Object.values(ef));
  // 关键路径：反向计算最晚开始，总时差 = LS - ES = 0
  const critical = [];
  for (const t of tasks) {
    const lf = Math.min(projectEnd,
      ...(tasks.filter(x => x.deps.includes(t.id))
        .map(x => es[x.id]) ?? [projectEnd]));
    if (lf - t.dur - es[t.id] === 0) critical.push(t.id);
  }
  return { es, ef, critical, end: projectEnd };
}
// 甘特渲染：时间轴刻度（日/周自适应）+ 任务条位置
//   = (es, ef) + 依赖箭头连线 + 关键路径高亮红。
// 拖拽调整：改 dur → 重算 schedule → 布局动画过渡。
```

**评分点**:
- 环检测先于排期（DFS 复用）。
- ES/EF 正向计算正确（依赖最晚完成）。
- 关键路径判定（总时差=0 反向计算）。
- 甘特渲染映射（时间轴+任务条+依赖线+关键路径高亮）。
