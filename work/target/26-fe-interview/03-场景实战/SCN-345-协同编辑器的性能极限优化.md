## SCN-345：几十万字文档多人同时编辑，编辑器性能怎么优化？

**答**:
- 渲染层：视口渲染（只渲染可视区段落——长文档虚拟化）、增量渲染（只重绘变更段落——脏区标记，SCN-477 增量思想）、渲染分层（文本层/光标层/批注层/水印层分离——各层独立刷新频率 SCN-223 复用）。
- 数据层：文档分区加载（SCN-222 分章节分区——只加载编辑中的分区）、CRDT 元数据压缩（tombstone GC——删除标记定期压缩）、操作合并（连续 keystroke 合批事务）。
- 协同事件治理：远端操作批处理（远端 update 批量应用——10ms 窗口合并）、光标状态节流（awareness 50ms）、事件优先级（文本变更>光标>presence——主线程任务分级）。
- 输入延迟保障：本地输入优先路径（本地编辑零延迟——同步任务让路，远端应用放 rAF 空闲期）、输入法兼容（IME 组合输入期间不应用远端变更到光标区——组合态保护）、长任务拆分（重排段落拆帧处理）。

```javascript
// 视口 + 增量渲染
editor.viewport.onChange((range) =>
  renderRange(range));                       // 只渲染视口
ydoc.on('update', (u) => {
  batchBuffer.push(u);
  if (!scheduled) scheduleIdle(applyBatch);  // 远端批量空闲应用
});
function applyBatch(updates) {
  markDirty(affectedRanges(updates));        // 脏区标记
  requestAnimationFrame(() => repaint(dirtyRanges));
}
// IME 保护：composing 期间延迟非光标区远端应用。
// GC：定期 compressYDoc()（tombstone 压缩）。
```
