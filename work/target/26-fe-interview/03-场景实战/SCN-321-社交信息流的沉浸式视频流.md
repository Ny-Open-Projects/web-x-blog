## SCN-321：短视频信息流（上下滑切换）的预加载与秒切怎么实现？

**答**:
- 滑动切换模型：滑动吸附（scroll-snap 级吸附：一滑一屏）、切换三阶段（滑动中→松手判定（超过 1/2 或速度阈值切下一支）→切换动画与播放切换），切走即暂停（上一支暂停+释放部分资源——内存控制）。
- 预加载矩阵：当前±1 预载（下一支视频首帧+元数据，上滑概率 >下滑）、预载分级（元数据+首帧图 always、视频分段 WiFi 才预载）、连接复用（预建 CDN 连接）。
- 播放器池：2~3 个播放器实例循环复用（创建销毁开销大——池化，SCN-272 对象池同源）、实例迁移（切到下一支→池中另一实例已就绪直接播放）、自动播放策略（可见即播+静音起播合规）。
- 性能与稳定性：内存巡检（长刷会话的释放纪律：非可视 ±2 释放）、卡顿降级（连续卡顿→降低预载深度）、进度记忆（刷到几百条切走回来恢复位置——SCN 无限流恢复篇复用）。

```javascript
class FeedPlayerPool {
  constructor(size = 3) { this.pool = [...]; this.idx = 0; }
  async show(index) {
    const cur = this.pool.get(index);
    const item = feed.get(index);
    await cur.load(item.url, { seekStart: item.progress });
    cur.play();                                // 就绪实例直接播
    this.pool.get(index - 1)?.pause();
    this.pool.get(index + 2)?.release();       // 释放远端
  }
}
// 预载：scroll 事件 → next 索引 → warmup(next.url)
//   （首帧+元数据 always；分段 WiFi 才拉）。
// 滑动判定：dy > height/2 || velocity > 0.5 → snap next。
```
