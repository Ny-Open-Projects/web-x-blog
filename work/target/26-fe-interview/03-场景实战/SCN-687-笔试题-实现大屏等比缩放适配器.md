## SCN-687：手写大屏等比缩放适配器

**需求与边界**：
- 需求：设计稿 3840×2160，窗口任意尺寸居中等比缩放；输出实际 scale 与黑边尺寸；提供 onScaleChange 回钩（图表按 scale 重绘字号）。
- 边界：① resize 节流（100ms）；② 只在 scale 变化超过 0.01 才触发回调（防抖动）；③ 极小窗口（scale < 0.3）触发 minScale 保护。

**答**：
```javascript
function createFitStage(stageEl, { designW = 3840, designH = 2160, minScale = 0.3 } = {}) {
  const listeners = new Set();
  let currentScale = 0, timer = null;
  function fit() {
    const w = window.innerWidth, h = window.innerHeight;
    const scale = Math.max(minScale, Math.min(w / designW, h / designH));
    stageEl.style.width = designW + 'px';
    stageEl.style.height = designH + 'px';
    stageEl.style.position = 'absolute';
    stageEl.style.left = '50%';
    stageEl.style.top = '50%';
    stageEl.style.transform = `translate(-50%,-50%) scale(${scale})`;
    stageEl.style.transformOrigin = 'center';
    if (Math.abs(scale - currentScale) > 0.01) {          // 显著变化才回调
      currentScale = scale;
      listeners.forEach(fn => fn({
        scale,
        letterbox: { x: Math.max(0, w - designW * scale),   // 黑边尺寸
                     y: Math.max(0, h - designH * scale) },
      }));
    }
  }
  const onResize = () => {
    clearTimeout(timer);
    timer = setTimeout(fit, 100);                          // resize 节流
  };
  window.addEventListener('resize', onResize);
  fit();
  return {
    onScaleChange: (fn) => (listeners.add(fn), () => listeners.delete(fn)),
    get scale() { return currentScale; },
    destroy() { window.removeEventListener('resize', onResize); clearTimeout(timer); },
  };
}
```

**评分点**:
- 居中等比缩放（取 min 保完整构图）与黑边计算。
- minScale 保护与 scale 显著变化阈值（防抖回调）。
- resize 节流 + destroy 清理。
- onScaleChange 支持图表字号重绘（扩展钩子）。
