## SCN-673：大屏布局配置系统怎么设计？
**答**：
- 配置模型：布局 JSON（面板类型/网格区域/数据绑定/样式参数），渲染器按配置实例化面板——同一渲染器不同配置产出不同大屏。
- 编辑模式：设计模式（拖拽面板到网格/绑定数据源/调整样式）与展示模式（纯渲染）双态；设计态操作产生配置 diff 预览，保存前校验（网格重叠/数据源可达性）。
- 版本与灰度：布局配置版本化，发布可先推到测试屏验证；回滚一键切旧版。
- 校验清单：面板间数据依赖（联动源存在）、网格无重叠、适配目标分辨率下元素不溢出（用布局引擎预计算）。
- 追问钩子：配置驱动大屏的边界在哪——强定制视觉（独特动画/特殊 3D 交互）还是需要写代码，配置系统覆盖 80% 常规面板即可，逃生舱口留自定义组件注册。

```javascript
const layoutSchema = {
  panels: [{
    type: 'line-chart', grid: { x: 0, y: 0, w: 6, h: 4 },
    data: { source: 'metric.energy.trend', window: '24h', downsample: true },
    style: { theme: 'dark', fontSize: 24 },
  }],
  version: 3,
};
function validateLayout(cfg) {
  const occupied = new Set();
  for (const p of cfg.panels) {
    for (let x = p.grid.x; x < p.grid.x + p.grid.w; x++)
      for (let y = p.grid.y; y < p.grid.y + p.grid.h; y++)
        if (occupied.has(`${x},${y}`)) throw new Error(`面板重叠 @${x},${y}`);
        else occupied.add(`${x},${y}`);
    if (!dataSources.has(p.data.source)) throw new Error(`数据源不可达 ${p.data.source}`);
  }
  return true;
}
```
