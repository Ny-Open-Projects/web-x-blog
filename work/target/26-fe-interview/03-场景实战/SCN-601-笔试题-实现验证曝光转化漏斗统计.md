## SCN-601：手写验证曝光转化漏斗统计

**需求与边界**：
- 需求：埋点事件流 `[{scene, step, ts}]`（expose→interact→try→pass/fail），按 scene 输出漏斗转化率、每步流失人数、平均耗时（expose→pass）。
- 边界：① 事件乱序到达按时间排序；② 用户级去重（同用户每步只计一次，取首次）；③ 无 pass 的会话不计耗时。

**答**：
```javascript
function funnelStats(events, { steps = ['expose', 'interact', 'try', 'pass'] } = {}) {
  const sorted = [...events].sort((a, b) => a.ts - b.ts);         // 乱序修正
  const sessions = new Map();                       // userId -> { firstTs, steps: Map }
  for (const e of sorted) {
    const s = sessions.get(e.userId) ?? { firstTs: e.ts, scene: e.scene, steps: new Map() };
    if (e.ts - s.firstTs > 30 * 60_000) continue;   // 30 分钟窗口外的算新会话（简化：丢弃）
    if (!s.steps.has(e.step)) s.steps.set(e.step, e.ts);          // 每步取首次
    sessions.set(e.userId, s);
  }
  const byScene = {};
  for (const s of sessions.values()) {
    (byScene[s.scene] ??= { counts: {}, durations: [] });
    for (const step of steps)
      if (s.steps.has(step)) byScene[s.scene].counts[step] = (byScene[s.scene].counts[step] || 0) + 1;
    if (s.steps.has('pass'))
      byScene[s.scene].durations.push(s.steps.get('pass') - s.firstTs);
  }
  return Object.entries(byScene).map(([scene, d]) => {
    const base = d.counts.expose || 1;
    const funnel = steps.map(st => ({
      step: st, count: d.counts[st] || 0,
      rate: +(((d.counts[st] || 0) / base) * 100).toFixed(1),     // 相对曝光的转化率
      dropFromPrev: st === 'expose' ? 0
        : base - (d.counts[st] || 0) - steps.slice(0, steps.indexOf(st))
            .reduce((s2, x) => s2 + (d.counts[x] || 0) - base, 0),
    }));
    const avgCost = d.durations.length
      ? d.durations.reduce((s, v) => s + v, 0) / d.durations.length : null;   // 无 pass 不计
    return { scene, funnel, passRate: funnel.at(-1).rate, avgCostMs: avgCost };
  });
}
```

**评分点**:
- 乱序排序 + 用户级每步首次去重。
- 会话窗口边界（30 分钟）处理。
- 转化率相对曝光基准 + 平均耗时仅统计有 pass 的会话。
- 分 scene 聚合输出结构清晰。
