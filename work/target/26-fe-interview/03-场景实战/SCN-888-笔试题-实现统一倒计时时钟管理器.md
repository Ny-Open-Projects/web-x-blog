## SCN-888：手写统一倒计时时钟

**需求与边界**：
- 需求：全局单例 ticker（1s）驱动多倒计时；基于服务器偏移的绝对时间计算；页面不可见暂停分发、可见立即校准；倒计时到期回调一次性触发。
- 边界：① 订阅返回退订函数；② 同一 deadline 到期只触发一次；③ 偏移量定期重校准（每 5 分钟向服务端对时一次）。

**答**：
```javascript
function createTicker({ serverOffsetMs = 0 } = {}) {
  const subs = new Map();                              // id -> { deadline, fired, cb }
  let visible = true, timer = null;
  let offset = serverOffsetMs;
  function now() { return Date.now() + offset; }
  function loop() {
    if (!visible) return;                              // 不可见暂停分发
    const t = now();
    for (const [id, s] of subs)
      if (!s.fired && t >= s.deadline) { s.fired = true; s.cb(id); }  // 一次性触发
    notifyTick(t);
  }
  function start() { timer ??= setInterval(loop, 1000); }
  document.addEventListener('visibilitychange', () => {
    visible = !document.hidden;
    if (visible) loop();                               // 回前台立即校准
  });
  setInterval(async () => {                            // 定期重校准偏移
    const tSrv = await fetchServerTime();
    offset = tSrv - Date.now();
  }, 5 * 60_000);
  return {
    register: (id, deadline, cb) => { subs.set(id, { deadline, cb, fired: false }); start(); },
    unregister: (id) => subs.delete(id),
    now,
  };
}
```

**评分点**:
- 单例 ticker 驱动 N 倒计时（不每组件一个 timer）。
- 绝对时间 + 偏移重校准（抗本地时钟漂移与篡改）。
- 不可见暂停/可见立即校准（省资源且无漂移）。
- fired 标志保证到期回调一次性。
