## SCN-665：时序数据降采样怎么实现？
**答**：
- 降采样策略分用途：折线趋势用区间聚合（每桶 avg/min/max 保留极值防趋势失真），点位标记用 LTTB（保形状），告警类永不降采样（信息不能丢）。
- 桶聚合保真：每桶存 min/max/avg/count，绘制时 min-max 画带状（高保真）或 avg 画线（轻量）；峰值特征（尖刺）保留桶内最大值点。
- 分辨率联动：图表像素宽度决定桶数（每 2px 一桶），resize 时重新降采样而不是缩放变形。
- 服务端优先：大时间跨度（7 天×秒级）必须服务端预聚合（物化视图），前端只对视口内数据细看。
- 追问钩子：降采样会不会把「瞬时尖峰」抹掉——用 min/max 桶不会；这也是为什么监控场景禁用纯 avg 曲线。

```javascript
function downsample(points, bucketCount) {           // points: [{t, v}]
  if (points.length <= bucketCount) return points;
  const size = Math.ceil(points.length / bucketCount);
  const out = [];
  for (let i = 0; i < points.length; i += size) {
    const slice = points.slice(i, i + size);
    const vs = slice.map(p => p.v);
    out.push({
      t: slice[Math.floor(slice.length / 2)].t,     // 桶中点时间
      avg: vs.reduce((s, v) => s + v, 0) / slice.length,
      min: Math.min(...vs), max: Math.max(...vs),   // 极值保留：尖峰不失真
      count: slice.length,
    });
  }
  return out;
}
```
