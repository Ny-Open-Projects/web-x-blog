## SCN-1296：手写一个多语言站点的语言切换记忆器

**答**：
- 需求：implement LangPreference(storage)。get() 读取记忆；set(lang) 保存（带时间戳）；suggest(acceptLang) 结合记忆与检测建议；expireDays 过期重检测（30 天后重新询问）。
- 边界：storage 异常静默（隐私模式）；lang 不在支持列表忽略；suggest 用户选择优先；过期返回 null。
- 评分点：记忆过期；隐私模式；支持列表校验；建议链

```javascript
class LangPreference {
  constructor(storage, supported, { expireDays = 30 } = {}) {
    this.store = storage; this.supported = new Set(supported);
    this.expire = expireDays;
  }
  get(now = Date.now()) {
    try {
      const s = JSON.parse(this.store.get('lang') ?? 'null');
      if (!s || !this.supported.has(s.lang)) return null;
      if (now - s.at > this.expire * 86400_000) return null;   // 过期重检测
      return s.lang;
    } catch { return null; }
  }
  set(lang, at = Date.now()) {
    if (!this.supported.has(lang)) return false;
    try { this.store.set('lang', JSON.stringify({ lang, at })); } catch {}
    return true;
  }
  suggest(acceptLang, now = Date.now()) {
    return this.get(now) ?? detectFromHeader(acceptLang, this.supported);
  }
}
function detectFromHeader(h, supported) {
  const first = h?.split(',')[0]?.split('-')[0];
  return supported.has(first) ? first : [...supported][0];
}
```
