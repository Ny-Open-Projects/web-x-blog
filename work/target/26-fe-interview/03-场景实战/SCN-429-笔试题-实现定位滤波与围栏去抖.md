## SCN-429：手写定位处理：漂移识别、指数平滑、围栏进出去抖确认

**需求与边界**：
- 输入：定位流（含 accuracy）；输出：可信位置流与围栏事件。
- 边界要求：① 漂移识别（速度超限/精度差）；② 平滑（EMA 指数平滑——抖动消除）；③ 围栏进出需连续 2 次确认（防抖）；④ 低精度定位跳过判定。

**答**：
```javascript
class LocationProcessor {
  constructor({ maxSpeed = 15 / 3.6, smooth = 0.4, fences }) {
    this.maxSpeed = maxSpeed; this.alpha = smooth;
    this.fences = fences;
    this.last = null; this.inside = null; this.streak = 0;
  }
  feed(loc) {                                  // loc: {lat,lng,accuracy,ts}
    if (this.last) {
      const v = dist(this.last, loc) /
        ((loc.ts - this.last.ts) / 1000);
      if (v > this.maxSpeed || loc.accuracy > 100)
        return { ...this.last, drift: true, quality: 'low' };
    }
    // EMA 平滑
    const out = this.last
      ? lerpLoc(this.last, loc, this.alpha)
      : loc;
    out.quality = loc.accuracy < 50 ? 'high' : 'mid';
    // 围栏判定 + 去抖确认
    const inside = this.fences.some(f => inPolygon(out, f));
    this.streak = inside === this.inside ? this.streak + 1 : 1;
    let event = null;
    if (this.streak >= 2 && inside !== this.inside) {
      event = inside ? 'enter' : 'leave';      // 连续2次确认
      this.inside = inside;
    }
    this.last = out;
    return { ...out, fenceEvent: event };
  }
}
// 上报带 quality（服务端区分可信度）；
// drift 点沿用上次位置（marker 平滑动画不瞬跳）。
```

**评分点**:
- 漂移双信号（速度超限+精度差）识别，低质量沿用上次。
- EMA 平滑消除抖动；quality 分级上报（服务端可用）。
- 围栏进出连续 2 次确认（去抖防 GPS 抖动误触发）。
- marker 动画意识（不瞬跳）。
