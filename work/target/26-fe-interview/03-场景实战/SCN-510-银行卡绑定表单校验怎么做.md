## SCN-510：银行卡四要素绑定表单怎么设计校验与体验？
**答**：
- 前端初校 + 服务端权威校：卡号 Luhn 校验 + BIN 段识别（自动带出发卡行/卡类型），姓名/证件号格式校验；真实绑卡以四要素接口 + 短信验证为准。
- 输入体验：卡号 4 位分组、纯数字过滤、粘贴去空格；证件号自动转大写；错误就地提示并聚焦首个错误字段。
- 安全：要素不进 URL/日志/埋点；表单 autofill 控制敏感字段；提交防重（点击后 loading + 请求幂等键）。
- 失败分支：四要素不一致/已绑定/卡状态异常分别给可行动提示，连续失败计数触发风控升级（滑块/客服）。
- 追问钩子：Luhn 通过不代表卡有效，为什么还做——提前拦截明显手误，减少短信验证成本。

```javascript
function luhn(numStr) {
  const digits = numStr.replace(/\D/g, '');
  let sum = 0, dbl = false;
  for (let i = digits.length - 1; i >= 0; i--) {
    let d = +digits[i];
    if (dbl && (d *= 2) > 9) d -= 9;
    sum += d; dbl = !dbl;
  }
  return digits.length >= 12 && sum % 10 === 0;
}
function formatCard(v) { return v.replace(/\D/g, '').slice(0, 19).replace(/(\d{4})(?=\d)/g, '$1 '); }
function binInfo(v) {                        // BIN 段 → 发卡行（字典由服务端下发）
  const bin = v.replace(/\D/g, '').slice(0, 6);
  return BIN_TABLE[bin] || BIN_TABLE[bin.slice(0, 4)] || null;
}
```
