## SCN-741：手写贡献度分析

**需求与边界**：
- 输入：大盘 P95 与各维度（页面）的 P95 + 请求数；输出每个维度的贡献度（对大盘劣化的推动量）并排序。
- 定义：贡献 = 维度 P95 相对大盘的偏离 × 维度流量占比（劣化贡献可为负——拉低大盘）。

**答**：
```javascript
function contribution(overallP95, dims) {            // dims: [{page, p95, count}]
  const total = dims.reduce((s, d) => s + d.count, 0);
  return dims.map(d => ({
    page: d.page,
    share: d.count / total,
    contribution: (d.p95 - overallP95) * (d.count / total),   // 偏离×权重
    flag: d.p95 > overallP95 * 1.2 ? 'WORST' : null,          // 显著劣化标记
  }))
  .sort((a, b) => b.contribution - a.contribution);   // 正贡献（拖差大盘）在前
}
// 用法：大盘 P95 突增时，第一行就是最可能的元凶页面，直接下钻。
// 校验：Σcontribution ≈ 0（各维度偏离以流量加权和抵消），可用于自检
function sanityCheck(result) {
  const sum = result.reduce((s, r) => s + r.contribution, 0);
  return Math.abs(sum) < 1e-6;
}
```

**评分点**:
- 贡献定义清晰（偏离 × 流量权重）。
- 排序让元凶置顶，负贡献（拉低大盘）语义保留。
- 显著劣化阈值标记（1.2×）。
- 自我校验（贡献和 ≈ 0）。
