## SCN-534：收益曲线展示怎么做？
**答**：
- 口径显式化：七日年化/万份收益/累计净值是不同口径，切换 Tab 时重拉数据并标注口径说明；禁止用同一序列换算伪造另一口径。
- 断点处理：非交易日/停牌产生数据空洞——折线是否连线由业务语义决定（净值曲线连，交易量柱状断），配置在数据字段上而非硬编码。
- 轴与标注：Y 轴不从 0 起要明示（金融合规敏感）；回撤区间、分红除息事件打标注点。
- 降采样：按视口宽度抽点（LTTB 算法），缩放时按可见范围重新请求高精度数据。
- 追问钩子：曲线渲染用什么——网格量大用 Canvas（ECharts），交互标注用 SVG 层叠，别在一个混合模式里又画又拾取。

```javascript
function lttb(data, target) {                 // Largest-Triangle-Three-Buckets 降采样
  if (data.length <= target) return data;
  const step = (data.length - 2) / (target - 2);
  const out = [data[0]];
  let a = 0;
  for (let i = 1; i < target - 1; i++) {
    const rangeStart = Math.floor(1 + (i - 1) * step);
    const rangeEnd = Math.min(Math.floor(1 + i * step), data.length);
    let maxArea = -1, pick = rangeStart;
    for (let j = rangeStart; j < rangeEnd; j++) {
      const area = triArea(data[a], data[Math.floor(rangeStart + step / 2)], data[j]);
      if (area > maxArea) { maxArea = area; pick = j; }
    }
    out.push(data[pick]); a = pick;
  }
  out.push(data[data.length - 1]);
  return out;
}
```
