## SCN-663：大屏数据接入层怎么设计？
**答**：
- 订阅模型：按主题订阅（device.* / alarm.* / kpi.*）而非全量连接；订阅粒度支持区域/层级（只订当前下钻层级的数据）。
- 背压协同：前端渲染慢（缓冲堆积）时向网关发送降采样请求（100Hz→10Hz）；恢复后升回——前后端协同的流控。
- 断线补漏：重连带游标，网关发增量或「快照重建」指令；大屏宁可快照重建也不静默丢数据。
- 数据质量：事件带 quality 标注（good/stale/offline），陈旧数据视觉变灰——宁可显示「数据过期」不给假实时感。
- 追问钩子：为什么大屏不能容忍丢帧静默——大屏是管理层决策面，数据陈旧呈现为「实时」会误导决策，必须可视化数据健康度。

```javascript
class TwinGateway {
  connect(topics) {
    this.ws = new WebSocket(`wss://gw?topics=${topics.join(',')}&rate=${this.sampleRate}`);
    this.ws.onmessage = ({ data }) => {
      const { type, events, cursor } = JSON.parse(data);
      if (type === 'snapshot') store.rebuild(events);         // 快照重建
      else renderer.push(events);                             // 合帧渲染
      this.cursor = cursor;
    };
    this.ws.onclose = () => setTimeout(() =>
      this.connect(topics), backoff(this.retry++));           // 指数退避重连
  }
  applyBackpressure(bufferLen) {                              // 背压协同
    const newRate = bufferLen > 30_000 ? 10 : bufferLen < 5_000 ? 100 : this.sampleRate;
    if (newRate !== this.sampleRate) {
      this.sampleRate = newRate;
      this.ws.send(JSON.stringify({ op: 'rate', value: newRate }));
    }
  }
}
```
