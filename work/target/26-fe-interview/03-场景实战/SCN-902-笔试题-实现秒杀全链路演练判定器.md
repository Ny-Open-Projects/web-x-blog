## SCN-902：手写全链路演练判定器

**需求与边界**：
- 需求：汇总压测（P95 达标）、故障注入（降级切换时效）、UX 走查（checklist）三线结果；输出 PASS/FAIL 汇总与阻断项清单；阻断项修复后支持单项重跑。
- 边界：① 每线判据参数化（阈值配置下发）；② FAIL 项必须带证据（数据/截图引用）；③ 全部阻断项 PASS 才给活动准入。

**答**：
```javascript
function drillJudge(results, { thresholds } = {}) {
  const judged = results.map(r => {
    let verdict = 'FAIL', evidence = null;
    switch (r.type) {
      case 'load':                                     // 压测：P95 + 错误率
        verdict = r.p95 <= thresholds.p95 && r.errorRate <= thresholds.error ? 'PASS' : 'FAIL';
        evidence = { p95: r.p95, errorRate: r.errorRate };
        break;
      case 'chaos':                                    // 注入：降级时效
        verdict = r.fallbackMs <= thresholds.fallbackMs ? 'PASS' : 'FAIL';
        evidence = { inject: r.inject, fallbackMs: r.fallbackMs };
        break;
      case 'ux':                                       // 走查：checklist 全过
        const failed = r.checklist.filter(c => !c.pass);
        verdict = failed.length ? 'FAIL' : 'PASS';
        evidence = { failed: failed.map(f => f.item) };
        break;
    }
    const blocker = verdict === 'FAIL' && (r.level === 'blocker' || r.type !== 'ux');
    return { ...r, verdict, blocker, evidence };       // FAIL 必带证据
  });
  const blockers = judged.filter(j => j.blocker && j.verdict === 'FAIL');
  return {
    judged,
    admission: blockers.length === 0 ? 'GRANTED' : 'DENIED',   // 全阻断项 PASS 才准入
    rerun: (id) => rerunSingle(id),                    // 单项重跑（修复后）
  };
}
```

**评分点**:
- 三线判据参数化（阈值配置下发，随活动调整）。
- FAIL 必带证据（数据/清单引用，可追溯）。
- 阻断项定义明确（压测/注入 FAIL 即阻断）。
- 准入判定 + 单项重跑机制（修复后回归闭环）。
