## SCN-594：手写验证挑战轮换器

**需求与边界**：
- 需求：连续失败自动轮换验证方式（滑块→点选→答题），难度随失败次数递增（难度 1~3）；成功后重置；同一种方式最多连续 2 次。
- 边界：① 难度上限 3；② 轮换历史去重（不重复刚失败的方式）；③ 每次轮换记录事件。

**答**：
```javascript
function createChallengeRotator(pool) {              // pool: ['slider','puzzle','quiz']
  let fails = 0, difficulty = 1, history = [], events = [];
  function next() {
    const recent = history.slice(-2);
    // 排除最近连续使用过的方式，避免重复
    const candidates = pool.filter(p => !(recent.length === 2 && recent[0] === p && recent[1] === p));
    const pick = candidates[Math.floor(Math.random() * candidates.length)];
    history.push(pick);
    events.push({ type: 'rotate', to: pick, difficulty, fails });
    return { verifier: pick, difficulty, token: issueChallenge(pick, difficulty) };
  }
  function onFail() {
    fails++;
    if (fails % 2 === 0) difficulty = Math.min(3, difficulty + 1);   // 每 2 次失败升 1 难度
    events.push({ type: 'fail', fails, difficulty });
    return next();
  }
  function onPass() {
    events.push({ type: 'pass', fails });
    fails = 0; difficulty = 1; history = [];         // 成功全重置
  }
  return { next, onFail, onPass, events };
}
function issueChallenge(verifier, difficulty) {
  // 难度参数随 verifier 类型含义不同：滑块=轨迹精度要求，点选=干扰项数量
  const params = { slider: { tolerance: 0.08 / difficulty }, puzzle: { distractors: difficulty * 2 } };
  return { verifier, difficulty, params: params[verifier] };
}
```

**评分点**:
- 失败轮换 + 最近方式去重（history.slice(-2)）。
- 难度阶梯（每 2 次失败 +1，上限 3）。
- 成功全量重置（防难度只升不降）。
- 轮换事件记录（可观测）。
