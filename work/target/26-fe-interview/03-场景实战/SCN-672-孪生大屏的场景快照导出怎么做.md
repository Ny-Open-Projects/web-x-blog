## SCN-672：场景快照导出怎么实现？
**答**：
- 分层捕获：3D canvas 用 toDataURL（需 preserveDrawingBuffer: true 或导出前同步重渲染一次）；DOM 层（图表/标注）用 html2canvas 或逐图表导出（ECharts 自带 getDataURL 更精确）。
- 合成：把 3D 截图与 DOM 截图在离屏 canvas 按布局合成，叠加水印（时间/操作人/数据口径）。
- 服务端方案（可靠）：大屏状态序列化发服务端，用 headless 浏览器渲染导出 PDF/长图——绕开前端 canvas 限制，格式统一，适合定时报告。
- 数据一致性：导出快照附带数据时间戳与口径版本，报告可复现。
- 追问钩子：为什么定时报告用服务端渲染——无人值守的定时导出 + 分辨率不受现场机器限制 + 渲染失败可重试可监控。

```javascript
async function exportSnapshot() {
  renderer.render(scene, camera);                    // 同步重渲染（免 preserveDrawingBuffer）
  const scene3d = renderer.domElement.toDataURL('image/png');
  const charts = await Promise.all(
    visibleCharts.map(c => c.getDataURL({ pixelRatio: 2 })));   // ECharts 精确导出
  const merged = compose([scene3d, ...charts], layoutSpec);     // 离屏合成
  stampWatermark(merged, { ts: dataCursor(), by: operator, calVer: METRIC_VER });
  return merged.toDataURL('image/png');
}
// 定时报告走服务端：
// POST /report/schedule { screenId, cron: '0 8 * * 1', format: 'pdf' }
```
