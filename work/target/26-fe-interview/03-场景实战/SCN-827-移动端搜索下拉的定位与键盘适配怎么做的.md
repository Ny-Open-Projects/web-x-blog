## SCN-827：移动端下拉定位与键盘适配怎么做？
**答**：
- 键盘遮挡：下拉用 fixed 定位相对输入框，visualViewport resize 时重新计算可用高度（键盘弹起压缩视口），列表区域只在可视区间内滚动。
- 全屏接管：联想内容多时下拉转为「搜索中转页」（全屏列表页，历史+热词+直达卡），比小下拉体验好——移动端主流做法。
- 惯性滚动与输入焦点：列表滚动时 blur 输入框（收起键盘腾出空间），点击建议时再聚焦搜索——键盘收放有明确策略。
- 触控目标：建议项高度 ≥ 44px，删除历史按钮独立热区（与采纳区分）。
- 追问钩子：为什么移动端常用「中转页」而不是下拉——小屏下拉展示 3~5 条信息密度不足，且键盘遮挡后下拉只剩半屏；全屏中转页信息容量与操作空间都更优。

```javascript
function useViewportSafe(dropdownEl) {
  const update = () => {
    const vv = window.visualViewport;
    const avail = vv.height - inputTop();              // 键盘上方可用高度
    dropdownEl.style.maxHeight = `${Math.max(120, avail)}px`;
    dropdownEl.style.bottom = `${window.innerHeight - vv.height - vv.offsetTop}px`;
  };
  window.visualViewport?.addEventListener('resize', update);
  window.visualViewport?.addEventListener('scroll', update);
  return update;
}
```
