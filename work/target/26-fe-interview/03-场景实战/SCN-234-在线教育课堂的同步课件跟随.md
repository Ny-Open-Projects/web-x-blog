## SCN-234：在线课堂老师翻课件，学生端怎么同步跟随？

**答**:
- 同步模型：老师端是课件状态的唯一驱动者（page/scroll/标注状态变更广播），学生端只读跟随——"讲师跟随模式"默认开启，学生可临时自由浏览（拖动查看，N 秒无操作自动回跟老师位置）。
- 信令与容错：课件切换信令（带课件 id+页码+时间戳，幂等——重复信令跳过）、断线重连后对齐（重连拉取当前课件状态而非历史信令重放）、老师端卡顿（信令延迟 >1s 时学生端展示"网络延迟"提示避免误解）。
- 标注同步：老师在课件上的实时标注（笔迹/箭头）走白板通道（SCN-231 复用），标注与页绑定（翻页自动清层/按页保存）。
- 学生端性能：课件大图预载（当前页±1 页预加载）、双缓冲渲染（新页就绪后原子切换，避免半渲染）、低端设备降级（标注层关闭或降采样）。

```javascript
// 老师端驱动
teacher.on('pageChange', (page) =>
  signaling.send({ type: 'course_page', page, ts: now() }));
// 学生端跟随
signaling.on('course_page', (e) => {
  if (freeBrowsing && Date.now() - lastUserAction < 10e3)
    return queuePending(e);                  // 自由浏览暂缓
  goToPage(e.page);                          // 双缓冲切换
  prefetch(e.page + 1);
});
// 自由浏览超时回跟：10s 无操作 → applyPending + 回跟
// 重连对齐：signaling.on('resume', () =>
//   signaling.send({type:'course_state_query'}))
```
