## SCN-811：纠错与拼音匹配怎么设计？
**答**：
- 三层匹配：精确前缀 > 拼音全拼/首字母（jsq→计算器）> 纠错（编辑距离 ≤ 2 的词库词）；各层独立召回合并。
- 拼音索引：词库预生成拼音与首字母索引（多音字多读音都入索引），查询时输入转拼音前缀匹配——服务端离线构建，前端无感。
- 纠错呈现：显示「已为你纠正为 xxx」+ 保留原输入选项（用户可能就是要搜错拼）。
- 中文输入法 IME 适配： composing 状态（拼音未上屏）不请求联想（候选词频繁变化），compositionend 才触发。
- 追问钩子：为什么 composing 期间不请求——输入法候选切换会触发 input 事件高频抖动，请求全是噪声；这是中文搜索前端最常被忽略的细节。

```javascript
input.addEventListener('compositionstart', () => { composing = true; });
input.addEventListener('compositionend', () => {
  composing = false;
  suggest(input.value);                               // 上屏后才联想
});
input.addEventListener('input', () => {
  if (!composing) suggest(input.value);               // 非中文输入直接联想
});
// 匹配优先级
const matchRank = { exact: 3, pinyin: 2, initial: 1.5, fuzzy: 1 };
```
