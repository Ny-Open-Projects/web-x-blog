## SCN-465：手写录制合规：开始/停止信令、全员指示灯、中途入会告知

**需求与边界**：
- 输入：录制信令流、入会事件；输出：合规呈现。
- 边界要求：① 开始录制→全员强提示（横幅+指示灯）；② 中途入会者也要被告知（入会时查录制态）；③ 停止录制→提示解除；④ 录制范围声明（音视频/聊天是否含——透明告知）。

**答**：
```javascript
class RecordCompliance {
  constructor(meeting) {
    ws.on('record_state', (s) => this.sync(s));
    this.sync(meeting.recordState);            // 入会即查当前态
  }
  sync(s) {                                    // s: {on, scope}
    indicator.toggle(s.on);                    // 持续指示灯
    if (s.on && !this.notified) {
      banner(`会议正在录制（范围：${s.scope.join('/')}）`,
        { level: 'warning', sticky: true });   // 强提示不自动消失
      this.notified = true;
    }
    if (!s.on) { this.notified = false; banner.clear(); }
  }
  onJoinLate() {                               // 中途入会
    ws.send('record_state_query');             // 主动查询录制态
  }
}
// chatScope 明确：聊天记录是否入录制——透明告知合规底线；
// 录制停止 → 解除全部提示（状态完全同步）。
```

**评分点**:
- 全员强提示（sticky 横幅+持续指示灯）。
- 中途入会主动查询录制态（不遗漏告知）。
- 录制范围声明（音视频/聊天透明化）。
- 停止录制的状态完全解除。
