## SCN-224：协作文档的冲突，什么自动合并、什么必须人工解决？

**答**:
- 自动合并区：文本字符级操作（插入/删除不同位置）——CRDT/OT 天然收敛，无需人工；段落级原子替换（不同段落）也可自动。
- 必须人工区：语义冲突（两人同时改同一句子的不同改法——字符级合并后语义混乱）、结构冲突（同时删除同一章节/同一表格单元格编辑）、离线长 divergence（两天离线的两份编辑）——检测策略：同区域（相邻 50 字内）并发操作触发"冲突提示"供确认。
- 人工解决交互：行内冲突提示（两版本对比高亮，选保留哪个/合并）、表格单元格冲突（最后写入+提示被覆盖者）、离线合并摘要（"你有 3 处编辑与他人冲突"逐个确认）。
- 设计哲学：协作编辑的冲突解决目标是"合并不丢字"（CRDT 保证），但"语义正确"必须人审——把自动合并做到无损，把人工介入降到最少且精准提示。

```javascript
// 同区域并发检测（基于 CRDT 操作元数据）
function detectConflicts(ops) {
  const conflicts = [];
  for (const [i, a] of ops.entries())
    for (const b of ops.slice(i + 1)) {
      if (a.author === b.author) continue;
      const near = Math.abs(a.pos - b.pos) < 50 &&
        concurrent(a, b);                  // 时钟上并发
      if (near) conflicts.push({ a, b,
        kind: kindOf(a, b) });             // edit-edit / del-edit
    }
  return conflicts;
}
// UI：conflicts.forEach(c => markInline(c));
// 行内提示："此处有并发修改" → 对比浮层（选 A/B/都保留）。
// CRDT 仍会自动合并（不丢字），提示只是语义确认。
```
