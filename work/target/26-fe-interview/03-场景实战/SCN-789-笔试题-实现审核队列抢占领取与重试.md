## SCN-789：手写审核队列领取器

**需求与边界**：
- 需求：claim(userId) 抢占领取下一条；服务端 409（被抢）自动重试下一条（最多 3 次）；领取成功启动锁定 TTL 心跳续期（页面存活即续期，崩溃后超时释放）。
- 边界：① 重试间隔退避；② 页面卸载停止心跳；③ 心跳失败 2 次提示用户（锁可能被释放）。

**答**：
```javascript
function createClaimer(userId) {
  let current = null, heartbeat = null, alive = true;
  async function claim({ retries = 3 } = {}) {
    for (let i = 0; i <= retries; i++) {
      const res = await api.post('/queue/claim', { userId }).catch(e => ({ status: e.status }));
      if (res.status === 200) {
        current = res.data;
        startHeartbeat(current.id);
        return current;
      }
      if (res.status !== 409) throw new Error('CLAIM_FAILED');   // 非抢占失败不重试
      await sleep(backoff(i, 300));                    // 被抢：退避后领下一条
    }
    return null;
  }
  function startHeartbeat(itemId) {
    clearInterval(heartbeat);
    let failures = 0;
    heartbeat = setInterval(async () => {
      if (!alive) return clearInterval(heartbeat);
      const ok = await api.post(`/lock/${itemId}/renew`).catch(() => false);
      if (!ok && ++failures >= 2) {
        toast('审核锁定即将释放，请尽快提交', { persistent: true });
        failures = 0;
      }
    }, LOCK_TTL * 0.4);                                // TTL 40% 周期续期
  }
  window.addEventListener('pagehide', () => { alive = false; clearInterval(heartbeat); });
  return { claim, get current() { return current; } };
}
```

**评分点**:
- 409 抢占失败退避重试（只对抢占类错误重试）。
- 锁定 TTL 心跳续期（TTL 40% 周期，容错一次失败）。
- 心跳失败 2 次用户提示（锁可能丢失）。
- pagehide 停止心跳 + 崩溃靠服务端超时释放兜底。
