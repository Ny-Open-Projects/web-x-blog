## SCN-494：手写下载直链：签名 URL 短时效、过期续签、防盗链校验

**需求与边界**：
- 输入：文件 id、用户身份；输出：可下载直链。
- 边界要求：① 签名短时效（15min——防链接外传长期有效）；② 过期续签（用户点击时校验重签）；③ 防盗链（签名含用户+文件绑定——他人链接无效）；④ 下载审计（谁下载了什么）。

**答**：
```javascript
async function getDownloadUrl(fileId, user) {
  if (!acl.can(user, `file:${fileId}`))         // 权限校验
    throw new Error('NO_ACCESS');
  const sig = hmac({ fileId, uid: user.id,
    exp: Date.now() + 15 * 60e3 });             // 签名：文件+人+过期
  audit.log({ fileId, uid: user.id, action: 'download_url' });
  return `${CDN}/${fileId}?uid=${user.id}&exp=${...}&sig=${sig}`;
}
// 续签：下载时 403（过期）→ 重新 getDownloadUrl → retry
async function downloadWithRenew(fileId) {
  let url = await getDownloadUrl(fileId, me);
  let r = await fetch(url);
  if (r.status === 403) {                      // 过期→续签重试
    url = await getDownloadUrl(fileId, me);
    r = await fetch(url);
  }
  return r.blob();
}
// CDN 校验：sig 匹配（uid 绑定——转给他人无效）+ exp 未过期；
// 审计：下载行为留痕（数据外流追溯——SCN-285 联动）。
```

**评分点**:
- 签名三要素（文件+用户+过期）绑定，转链他人无效。
- 403 过期续签重试的用户无感处理。
- 下载审计留痕（追溯）。
- 权限前置校验（签名前 ACL）。
