## SCN-662：点位标注系统怎么设计？
**答**：
- 双坐标锚定：标注锚定 3D 世界坐标，每帧投影到屏幕坐标更新 DOM/Canvas 标签位置——标签用 DOM（排版/交互方便）+ transform 定位。
- 防遮挡：按深度/屏幕距离过滤（相机背后/过远的隐藏）；密集时按屏幕空间碰撞检测折叠为聚合点；重要标注（告警）永远优先显示。
- 层级策略：Zoom 越近显示越多（LOD of labels）：园区级只显示楼宇名，设备级才显示传感器值。
- 引线与避让：标签与点位之间画引线（Canvas overlay），标签位置用简单的偏移算法（上/下/左右候选位择优）。
- 追问钩子：DOM 标签每帧 reflow 会卡吗——只写 transform（合成层），且用 will-change 与 contain: strict 隔离；数量超阈值转 Canvas 绘制。

```javascript
function updateLabels(labels, camera, renderer) {
  const frustum = new THREE.Frustum();
  const mat = new THREE.Matrix4().multiplyMatrices(
    camera.projectionMatrix, camera.matrixWorldInverse);
  frustum.setFromProjectionMatrix(mat);
  for (const l of labels) {
    const v = l.anchor.clone().project(camera);       // 世界→NDC
    const visible = v.z < 1 && frustum.containsPoint(l.anchor)
      && camera.position.distanceTo(l.anchor) < l.maxDist;
    if (!visible) { l.el.style.display = 'none'; continue; }
    const x = (v.x + 1) / 2 * renderer.domElement.clientWidth;
    const y = (-v.y + 1) / 2 * renderer.domElement.clientHeight;
    l.el.style.transform = `translate(${x}px, ${y}px)`;   // 只写 transform
    l.el.style.display = l.screenPriority ? 'block' : collisionFold(l, labels);
  }
}
```
