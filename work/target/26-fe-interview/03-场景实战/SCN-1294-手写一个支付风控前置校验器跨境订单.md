## SCN-1294：手写一个支付风控前置校验器（跨境订单）

**答**：
- 需求：implement RiskGate(rules)。check(order, user) 输出 { pass, actions }：规则（新用户大额->3DS；高风险国家->人工审核；同卡高频->拒绝）；按序执行首个命中规则返回。
- 边界：rules 空 pass；订单金额缺失按 0；actions 为 { type, detail }；命中即返回（不叠加）。
- 评分点：规则链；首个命中；3DS；新用户

```javascript
class RiskGate {
  constructor(rules) { this.rules = rules; }           // [{ when: (o,u) => bool, action }]
  check(order, user) {
    for (const r of this.rules) {
      if (r.when(order, user))
        return { pass: r.action.type !== 'reject',
          actions: [r.action] };
    }
    return { pass: true, actions: [] };
  }
}
const rules = [
  { when: (o, u) => u.isNew && o.total > 1000,
    action: { type: '3ds', detail: '新用户大额需 3DS' } },
  { when: (o, u) => HIGH_RISK.has(o.shipCountry),
    action: { type: 'manual-review', detail: '高风险国家' } },
  { when: (o, u) => u.cardAttemptsToday > 5,
    action: { type: 'reject', detail: '同卡高频' } },
];
const HIGH_RISK = new Set();
```
