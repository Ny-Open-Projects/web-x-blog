## SCN-566：验证码 a11y 怎么做？
**答**：
- 替代通道：滑块/图像码提供语义替代——语音验证码、短信/邮箱验证、人工客服通道；替代入口不能藏在三级菜单。
- 组件无障碍：滑块用 slider role + aria-valuenow（进度）+ 键盘方向键操作；倒计时 aria-live polite 播报；答题验证图片带文字化题目。
- 焦点与提示：验证弹窗焦点管理（困住/归还），错误提示与控件 aria-describedby 关联。
- 认知无障碍：文案简明、重试无惩罚、超时提醒提前（剩 10 秒提醒而非直接失效）。
- 追问钩子：键盘可操作的滑块会不会被脚本滥用——服务端照样做轨迹校验，a11y 通道走单独特征模型。

```javascript
function AccessibleSlider({ value, onChange, onDone }) {
  return (
    <div role="slider" tabIndex={0}
      aria-valuemin={0} aria-valuemax={100} aria-valuenow={value}
      aria-label="按住滑块拖到最右侧完成验证"
      onKeyDown={e => {
        const step = { ArrowRight: 2, ArrowLeft: -2 }[e.key];
        if (!step) return;
        e.preventDefault();
        const v = Math.min(100, Math.max(0, value + step));
        onChange(v);
        if (v === 100) onDone('keyboard');          // 键盘通道单独上报特征
      }} />
  );
}
```
