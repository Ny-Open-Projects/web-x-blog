## SCN-1293：手写一个多国退货政策引擎

**答**：
- 需求：implement ReturnPolicyEngine(rules)。policy(country, category, daysSincePurchase) 返回 { allowed, daysLeft, reason }：规则匹配顺序：品类禁退 > 国家法定 > 平台默认；超期 allowed=false；订单状态校验（已签收才可退）。
- 边界：rules 无匹配国家用 default；daysSincePurchase 缺失按 0；规则优先级显式声明。
- 评分点：规则优先级；品类禁退；超期；状态校验

```javascript
class ReturnPolicyEngine {
  constructor(rules) { this.rules = rules; }           // [{ scope: { country?, category? }, windowDays, except: [] }]
  policy(country, category, daysSincePurchase = 0, status = 'delivered') {
    if (status !== 'delivered')
      return { allowed: false, reason: '订单未签收' };
    const matched = this.rules.filter(r =>
      (!r.scope.country || r.scope.country === country) &&
      (!r.scope.category || r.scope.category === category))
      .sort((a, b) => (b.scope.country ? 2 : 0) + (b.scope.category ? 1 : 0)
        - ((a.scope.country ? 2 : 0) + (a.scope.category ? 1 : 0)))[0]
      ?? this.rules.find(r => r.scope.default);
    if (!matched) return { allowed: false, reason: '无适用规则' };
    if (matched.except?.includes(category))
      return { allowed: false, reason: `${category} 不可退货` };
    const daysLeft = matched.windowDays - daysSincePurchase;
    return { allowed: daysLeft > 0, daysLeft,
      reason: daysLeft <= 0 ? '超出退货期' : null };
  }
}
```
