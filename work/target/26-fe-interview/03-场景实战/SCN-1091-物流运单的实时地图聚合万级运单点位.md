## SCN-1091：物流运单的实时地图聚合（万级运单点位）

**答**：
- 聚合：万级运单地图点位聚合（网格聚合，zoom 联动展开）。
- 性能：WebGL 点渲染（万点无卡）或服务端预聚合。
- 交互：点击聚合块展开明细列表（分页）。

```javascript
// 点位聚合
function aggregatePoints(points, zoom) {
  const cell = 256 / (2 ** zoom);                      // 网格大小
  const grid = new Map();
  points.forEach(p => {
    const key = `${Math.floor(p.lng / cell)},${Math.floor(p.lat / cell)}`;
    (grid.get(key) ??= []).push(p);
  });
  return [...grid.values()].map(group => group.length === 1
    ? { type: 'point', ...group[0] }
    : { type: 'cluster', count: group.length,
        center: avgPoint(group) });
}
function avgPoint(group) {
  return { lng: group.reduce((s, p) => s + p.lng, 0) / group.length,
    lat: group.reduce((s, p) => s + p.lat, 0) / group.length };
}
```
