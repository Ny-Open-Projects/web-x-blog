## SCN-342：协同表格（类 Excel）的公式依赖与实时重算怎么设计？

**答**:
- 公式引擎：公式解析（AST 解析=SUM(A1:B10)）、依赖图（单元格依赖关系 DAG：公式引用其他单元格）、重算调度（依赖图拓扑序增量重算——只重算受影响链路，SCN-477 增量思想同源）、循环引用检测（环检测报错）。
- 协同下的一致性：公式也是数据（进 CRDT 同步——多人同时改公式冲突）、重算的执行位置（前端本地重算（即时反馈）+服务端权威重算（最终一致——本地结果与服务端差异校正）、重算结果广播（未编辑公式的单元格因依赖变化也要更新——依赖图变更广播）。
- 性能：万级公式重算（Worker 重算不卡 UI）、脏标记传播（只传播变更依赖链）、批量编辑合并（粘贴大区域一次重算）。
- 交互：公式编辑器（引用高亮：编辑公式时引用区域着色——依赖可视化）、错误呈现（#REF!/#CYCLE 标注与定位）。

```javascript
class FormulaEngine {
  constructor(sheet) { this.graph = new DepGraph(); }
  onCellChange(addr) {
    const dirty = this.graph.dependents(addr);  // 依赖链
    worker.recalc(dirty);                       // Worker 增量重算
  }
  setFormula(addr, f) {
    const ast = parse(f);
    this.graph.update(addr, refs(ast));         // 更新依赖图
    if (this.graph.hasCycle(addr)) throw 'CYCLE';
  }
}
// 一致性：本地重算即时展示 → 服务端权威结果回推校正。
// 协同：公式单元格进 CRDT，多人改公式 last-write+提示。
// 引用高亮：editingFormula 时 refs→着色区域。
```
