## SCN-637：手写审批流程图渲染器（简化分层布局）

**需求与边界**：
- 输入：流程定义 `{ nodes: [{id,name}], edges: [{from,to,cond}] }` + 实例状态 `{ statusMap, takenEdges }`。
- 要求：① 按拓扑层级（最长路径分层）计算节点 x/y（层间距 120，层内垂直排布）；② 状态着色 class；③ 走过的边高亮；④ 检测环（异常定义报错）。

**答**：
```javascript
function renderFlow(def, instance) {
  // 1. 环检测
  const color = {}, hasCycle = (id, path = new Set()) => {
    if (path.has(id)) throw new Error(`流程存在环: ${[...path, id].join('->')}`);
    if (color[id] === 2) return false;                 // 已完成
    color[id] = 1; path.add(id);
    for (const e of def.edges.filter(e => e.from === id))
      if (hasCycle(e.to, path)) return true;
    color[id] = 2; path.delete(id);
    return false;
  };
  def.nodes.forEach(n => hasCycle(n.id));
  // 2. 最长路径分层
  const layer = new Map();
  const setLayer = (id, l) => {
    if ((layer.get(id) ?? -1) >= l) return;
    layer.set(id, l);
    for (const e of def.edges.filter(e => e.from === id)) setLayer(e.to, l + 1);
  };
  const roots = def.nodes.filter(n => !def.edges.some(e => e.to === n.id));
  roots.forEach(r => setLayer(r.id, 0));
  // 3. 坐标计算
  const nodes = def.nodes.map(n => {
    const l = layer.get(n.id), peers = def.nodes.filter(m => layer.get(m.id) === l);
    const idx = peers.findIndex(m => m.id === n.id);
    return { ...n, x: l * 220, y: idx * 96,
      cls: instance.statusMap[n.id] || 'pending' };    // 状态着色
  });
  // 4. 边：走过的高亮
  const edges = def.edges.map(e => ({
    ...e, x1: layer.get(e.from) * 220 + 180, x2: layer.get(e.to) * 220,
    taken: instance.takenEdges?.includes(`${e.from}->${e.to}`),
  }));
  return { nodes, edges, depth: Math.max(...layer.values()) };
}
```

**评分点**:
- DFS 染色环检测（异常定义 fail-fast）。
- 最长路径分层（分支汇合节点落在正确层）。
- 状态 class 与 taken 边高亮（定义+实例合并渲染）。
- 坐标计算层间距/层内排布清晰。
