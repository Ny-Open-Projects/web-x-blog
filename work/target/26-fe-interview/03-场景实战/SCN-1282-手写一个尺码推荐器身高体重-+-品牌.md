## SCN-1282：手写一个尺码推荐器（身高体重 + 品牌尺码表）

**答**：
- 需求：implement SizeRecommender(chart)。recommend({ heightCm, weightKg, fit }) 按 brand 尺码表（每个码的身高/体重区间）推荐，fit（slim/regular/loose）偏移一档；区间重叠取中间；输出 { size, confidence }。
- 边界：超出表范围返回 null（提示人工咨询）；区间缺失字段跳过该维匹配；confidence 按距离计算。
- 评分点：区间匹配；fit 偏移；范围外；置信度

```javascript
class SizeRecommender {
  constructor(chart) { this.chart = chart; }          // [{ size, height: [min,max], weight: [min,max] }]
  recommend({ heightCm, weightKg, fit = 'regular' }) {
    const offset = { slim: -1, regular: 0, loose: 1 }[fit] ?? 0;
    const scored = this.chart.map(c => {
      const hOk = !c.height || (heightCm >= c.height[0] && heightCm <= c.height[1]);
      const wOk = !c.weight || (weightKg >= c.weight[0] && weightKg <= c.weight[1]);
      const center = ((c.height?.[0] ?? 0) + (c.height?.[1] ?? 0)) / 2;
      return { size: c.size, ok: hOk && wOk,
        dist: hOk && wOk ? Math.abs(heightCm - center) : Infinity };
    }).filter(s => s.ok);
    if (!scored.length) return { size: null, note: '超出尺码表范围' };
    const idx = scored.sort((a, b) => a.dist - b.dist)[0];
    const finalIdx = this.chart.findIndex(c => c.size === idx.size) + offset;
    const final = this.chart[Math.max(0, Math.min(this.chart.length - 1, finalIdx))];
    return { size: final.size, confidence: +(1 - idx.dist / 100).toFixed(2) };
  }
}
```
