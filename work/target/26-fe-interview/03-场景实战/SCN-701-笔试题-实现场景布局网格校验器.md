## SCN-701：手写布局配置校验器

**需求与边界**：
- 需求：校验面板网格配置——① 网格重叠；② 超出画布（cols×rows）；③ 面板数据源可达与循环依赖（联动 A→B→A）；④ 输出全部错误而非首个。
- 边界：① 重叠用占用集合 O(总面积)；② 循环依赖 DFS 染色检测；③ 错误带面板 id 定位。

**答**：
```javascript
function validateLayout(config, { cols = 24, rows = 12, dataSources } = {}) {
  const errors = [];
  const occupied = new Map();                          // cell -> panelId
  for (const p of config.panels) {
    const { x, y, w, h } = p.grid;
    if (x + w > cols || y + h > rows || x < 0 || y < 0)
      errors.push({ panel: p.id, code: 'OUT_OF_CANVAS' });
    for (let cx = x; cx < Math.min(x + w, cols); cx++)
      for (let cy = y; cy < Math.min(y + h, rows); cy++) {
        const key = `${cx},${cy}`;
        if (occupied.has(key))
          errors.push({ panel: p.id, code: 'OVERLAP', with: occupied.get(key), at: key });
        else occupied.set(key, p.id);
      }
    if (!dataSources.has(p.data?.source))
      errors.push({ panel: p.id, code: 'SOURCE_UNREACHABLE', source: p.data?.source });
  }
  // 联动循环依赖
  const deps = new Map(config.panels.map(p => [p.id, p.data?.dependsOn ?? []]));
  const color = {};
  function dfs(id, path) {
    if (color[id] === 1) { errors.push({ code: 'DEP_CYCLE', cycle: [...path, id] }); return; }
    if (color[id] === 2) return;
    color[id] = 1; path.push(id);
    (deps.get(id) || []).forEach(d => dfs(d, path));
    color[id] = 2;
  }
  for (const id of deps.keys()) dfs(id, []);
  return { ok: errors.length === 0, errors };
}
```

**评分点**:
- 三类校验（重叠/溢出/数据源）+ 联动循环 DFS 染色。
- 输出全部错误（非短路），每条带 panel 定位。
- 占用集合 O(总面积) 高效重叠检测。
- 边界裁剪（超界坐标不越界统计）。
