## SCN-756：机审与人审协同怎么设计？
**答**：
- 置信度分层：高置信违规（>0.98）直接处置（可申诉）、中置信（0.6~0.98）进人审队列、低置信（<0.6）标记待观察——阈值按品类与误杀成本配置。
- 机审辅助呈现：违规帧/片段标注 + 机器理由（「画面出现疑似刀具 12s-15s」），人审复核后反馈「机器对/机器错」，反馈数据回流训练模型。
- 人审抽检：直放（高置信合规）内容按比例抽检（1%~5%）验证直放策略，抽检出问题回退直放比例。
- 仲裁机制：人审意见分歧（两次审核结论不一致）自动升级仲裁队列（资深审核员）。
- 追问钩子：为什么直放比例要动态——模型迭代后直放比例可提升，但抽检漏杀率是红线；直放率是效率指标，漏杀率是安全指标，安全优先。

```javascript
const COVERAGE = {
  direct: { min: 0.98, sample: 0.03 },             // 直放 + 3% 抽检
  human: { min: 0.6, max: 0.98 },                  // 人审
  observe: { max: 0.6 },                           // 观察
};
function route(item) {
  const c = item.machineScore;
  if (c >= COVERAGE.direct.min) return { lane: 'DIRECT', sample: Math.random() < COVERAGE.direct.sample };
  if (c >= COVERAGE.human.min) return { lane: 'HUMAN', marks: item.machineMarks };
  return { lane: 'OBSERVE', recheckAfter: 24 * 3600_000 };
}
function humanFeedback(review, machine) {           // 反馈回流
  return { agree: review.verdict === machine.suggested, reason: review.reason };
}
```
