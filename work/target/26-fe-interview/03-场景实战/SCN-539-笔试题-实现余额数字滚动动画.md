## SCN-539：手写余额数字滚动动画组件逻辑

**需求与边界**：
- 需求：余额从旧值滚动到新值（600ms ease-out），增加绿/减少红箭头，期间到达的新值要接管动画；prefers-reduced-motion 直接跳变。
- 边界：① 动画中值更新须从「当前显示值」继续，不跳变；② rAF 取消防泄漏；③ 值不变不触发动画；④ 金额格式化复用 fenToYuan。

**答**：
```javascript
function createRollingNumber({ duration = 600, reduced }) {
  let raf = null, shown = 0;
  const easeOut = t => 1 - Math.pow(1 - t, 3);
  function render(fen, el) {
    el.textContent = fenToYuan(fen);
    el.dataset.dir = '';                        // 方向色由 dir class 控制
  }
  function to(nextFen, el) {
    if (nextFen === shown) return;
    if (raf) cancelAnimationFrame(raf);
    el.dataset.dir = nextFen > shown ? 'up' : 'down';
    if (reduced()) return render(nextFen, el);  // 无障碍：直接跳变
    const from = shown, delta = nextFen - from, t0 = performance.now();
    const tick = (now) => {
      const p = Math.min(1, (now - t0) / duration);
      const cur = Math.round(from + delta * easeOut(p));
      shown = cur; render(cur, el);
      if (p < 1) raf = requestAnimationFrame(tick);
    };
    raf = requestAnimationFrame(tick);
  }
  return {
    to,
    destroy() { if (raf) cancelAnimationFrame(raf); },  // 组件卸载必须调用
    get shown() { return shown; },
  };
}

```

**评分点**:
- 动画中更新值从当前 shown 续播（先 cancel 再以 shown 为起点）。
- rAF 取消与 destroy 生命周期（内存泄漏扣分项）。
- reduced-motion 降级与同值不动画。
- 方向色用 dataset/class 而非内联样式，保证 CSS 可控。
