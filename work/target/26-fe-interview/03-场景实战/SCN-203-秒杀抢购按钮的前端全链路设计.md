## SCN-203：秒杀场景的抢购按钮全链路（预热/开抢/结果）前端怎么设计？

**答**:
- 预热阶段：按钮三态机（未开始→可抢→已抢完/已下单），倒计时服务器时间校准（SCN-020），活动页静态化+CDN，商品详情与库存标识提前下发——抢购前一切能预载的都预载。
- 开抢瞬间：点击后立即进入"处理中"态（防重复提交+视觉反馈），请求走独立秒杀接口（与普通接口隔离，避免拖垮主站），前端不判断库存（服务端裁决），响应三态（成功→下单页/排队中→轮询/已抢完→遗憾页）。
- 结果确认：排队模式（服务端削峰异步出结果，前端轮询或 WebSocket 推送），轮询间隔递增（1s→2s→4s）+ 最大时长兜底；成功页防回退重复下单（token 一次性）。
- 兜底：开抢瞬间按钮抖动检测（连点合并）、页面降级预案（秒杀接口挂→展示排队提示而非白屏）、风控前置（滑块验证在点击后抢购前触发）。

```javascript
async function seckillClick(activityId) {
  if (state !== 'ready') return;          // 三态守卫
  setState('processing');                 // 防重复
  try {
    const r = await seckillApi.post('/seckill',
      { activityId, token: userToken }, { timeout: 3000 });
    if (r.status === 'success') return router.push(`/order/${r.orderToken}`);
    if (r.status === 'queue') return pollResult(r.queueId);   // 排队轮询
    setState('soldout');                  // 已抢完
  } catch (e) {
    setState('error');                    // 保留重试入口
    toast('网络拥堵，请重试');
  }
}
function pollResult(queueId, delay = 1000) {
  setTimeout(async () => {
    const r = await seckillApi.get(`/seckill/result/${queueId}`);
    if (r.status === 'pending') return pollResult(queueId, Math.min(delay * 2, 5000));
    r.status === 'success' ? router.push(`/order/${r.orderToken}`)
      : setState('soldout');
  }, delay);
}
```
