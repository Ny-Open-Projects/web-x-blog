## SCN-312：企业内部知识库（搜索/权限/过期治理）怎么设计？

**答**:
- 知识组织：空间结构（部门空间/项目空间/个人知识库），文档类型（Wiki/FAQ/SOP/归档），知识地图（分类导航+标签体系+热门推荐）。
- 检索体系：全文搜索（AGT-310 研发知识库同源：标题+正文+附件文本）、权限过滤（检索结果按 ACL 剪枝——AGT-217 企业 RAG 复用）、搜索质量（同义词/缩写词典：OKR=目标管理——企业黑名词典可维护）。
- 新鲜度治理：知识 TTL（SOP 类文档强制复审周期：到期提醒 owner 复审——复审后刷新有效期）、过期标记（过期文档检索降权+显式"已过期"标注）、废弃归档流程。
- 贡献运营：贡献激励（编写量/被引用数——知识贡献者榜单）、缺失探测（高频搜索无结果→知识缺口清单推给领域 owner——AGT-310 闭环）、评审协作（SOP 发布走评审流——SCN-311 审批复用）。

```javascript
async function searchKB(q, user) {
  const r = await kbApi.search(q, { acl: user.acl });
  return {
    hits: r.hits.map(h => ({
      ...h,
      stale: h.reviewDueAt < now() && markStale(h),  // 过期降权标注
    })),
    gapHint: r.hits.length === 0 &&
      recordGap(q),   // 无结果 → 记缺口 → 推 owner
  };
}
// TTL：schedule(h.reviewDueAt) → 通知 owner 复审
//   → approve → reviewDueAt = +180d。
// 词典：synonyms 维护台（OKR → 目标管理）热更新。
```
