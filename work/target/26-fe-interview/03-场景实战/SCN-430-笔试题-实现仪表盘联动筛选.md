## SCN-430：手写仪表盘联动：全局筛选订阅、防抖、过期请求取消

**需求与边界**：
- 输入：筛选状态变更、图表注册；输出：图表数据刷新控制。
- 边界要求：① 筛选变更→订阅图表防抖刷新；② 过期请求取消（AbortController——快速切换不串数据）；③ 图表间联动（点选注入筛选）；④ 可见性暂停（后台不刷新）。

**答**：
```javascript
class Dashboard {
  constructor() {
    this.filters = { region: null, range: [0, 0] };
    this.subs = new Map();                     // chartId → {unsub, ac}
  }
  setFilters(patch) {
    Object.assign(this.filters, patch);
    this.notify();                             // 单向数据流
  }
  register(chartId, queryFn, render) {
    const run = debounce(async () => {
      if (document.hidden) return;             // 后台暂停
      this.subs.get(chartId)?.ac?.abort();     // 取消过期请求
      const ac = new AbortController();
      this.subs.set(chartId, { ac });
      try {
        const data = await queryFn(this.filters,
          { signal: ac.signal });
        render(data);                          // setOption 增量
      } catch (e) {
        if (e.name !== 'AbortError') chartError(chartId);
      }
    }, 300);
    this.notify = this.pipe(this.notify, run);
    run();
  }
  notify() { /* 触发所有注册图表 run */ }
  pipe(base, fn) {                             // 简单订阅编排
    const prev = base.bind(this);
    return () => { prev(); fn(); };
  }
}
// 图表 A 点选 → dashboard.setFilters({region: clicked})
//   → B/C 防抖刷新（单向数据流，无循环）。
// AbortController 取消：快速切换不串数据。
```

**评分点**:
- 单向数据流（筛选状态→订阅刷新），点选注入无循环。
- 防抖 300ms + AbortController 取消过期请求（防串数据）。
- document.hidden 暂停（可见性优化）。
- AbortError 与真实错误分流处理。
