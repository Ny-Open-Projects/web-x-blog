## SCN-1276：手写一个多语言文本回退解析器（缺翻译回退+标注）

**答**：
- 需求：implement I18nText(dict, fallbackLang)。t(key, lang) 取翻译：命中返回 { text, machine: false }；缺失回退 fallbackLang 并标 machine=true；嵌套 key（a.b.c）支持；完全缺失返回 key 本身。
- 边界：dict 缺失按空对象；key 含非法字符返回 null；回退语言也缺失返回 key 并标注 untranslated。
- 评分点：回退链；嵌套 key；机翻标注；非法 key

```javascript
class I18nText {
  constructor(dict = {}, fallbackLang = 'en') {
    this.dict = dict; this.fb = fallbackLang;
  }
  get(obj, path) {
    return path.split('.').reduce((o, k) => o?.[k], obj);
  }
  t(key, lang) {
    if (!/^[\w.]+$/.test(key)) return null;
    const hit = this.get(this.dict[lang], key);
    if (hit != null) return { text: hit, machine: false };
    const fb = this.get(this.dict[this.fb], key);
    if (fb != null) return { text: fb, machine: true, fallback: this.fb };
    return { text: key, machine: true, untranslated: true };
  }
}
```
