## SCN-581：验证组件错误监控怎么建？
**答**：
- 错误分类码：组件错误（chunk 加载失败/初始化异常/渲染崩溃）、协议错误（token 校验失败/配置签名错）、用户态（放弃/超时/答错）三类分开统计，混在一起会误导排查。
- 上下文丰富：每条错误带 sdkVersion/scene/端/机型/网络，聚合成维度可查；错误率按版本切片，灰度版本异常自动告警。
- 崩溃兜底：验证器渲染崩溃被 ErrorBoundary 捕获后自动走降级链（SCN-558），错误上报带边界快照。
- 版本对齐：上报时同时记录「业务页面版本」与「SDK 版本」，定位是集成问题还是 SDK 问题。
- 追问钩子：怎么发现「静默失败」——验证发起后无任何结果事件的「悬挂会话」单独计数，通常是 SDK 与页面消息不通。

```javascript
const ERR = { COMPONENT: 'component', PROTOCOL: 'protocol', USER: 'user', HANG: 'hang' };
function verifyMonitor(scene) {
  const t0 = Date.now();
  const hang = setTimeout(() =>                    // 悬挂检测：发起后 30s 无结果
    report({ type: ERR.HANG, scene, sdkVersion, cost: Date.now() - t0 }), 30_000);
  return {
    done(result) {
      clearTimeout(hang);
      if (result.error) report({
        type: result.error.source,                 // component/protocol/user 分类
        scene, sdkVersion, pageVersion,
        msg: result.error.message, stack: compactStack(result.error),
      });
    },
  };
}
```
