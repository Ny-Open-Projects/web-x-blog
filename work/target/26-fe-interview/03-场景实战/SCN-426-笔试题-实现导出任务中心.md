## SCN-426：手写异步导出任务中心：提交/进度/完成通知/签名下载/去重

**需求与边界**：
- 输入：导出条件；输出：任务管理器。
- 边界要求：① 同条件任务进行中→去重提示；② 进度推送（轮询/WS——生成中百分比）；③ 完成→签名下载 URL（过期时间）；④ 失败原因可见+重试；⑤ 任务历史列表。

**答**：
```javascript
class ExportCenter {
  constructor({ bus }) { this.tasks = new Map(); this.bus = bus; }
  async create(filters) {
    // 1. 去重：同条件进行中任务
    const dup = [...this.tasks.values()].find(t =>
      t.status === 'running' &&
      hash(t.filters) === hash(filters));
    if (dup) return { ok: false, reason: '相同导出生成中',
      taskId: dup.id };
    const t = await api.createExport(filters);
    const task = { id: t.id, filters, status: 'queued',
      progress: 0 };
    this.tasks.set(t.id, task);
    this.subscribe(t.id);
    return { ok: true, task };
  }
  subscribe(taskId) {                          // 进度订阅
    this.bus.on(`export:${taskId}`, (s) => {
      const t = this.tasks.get(taskId);
      t.status = s.status; t.progress = s.progress;
      if (s.status === 'done') {
        t.url = s.url;                         // 签名直链（15min）
        t.expireAt = Date.now() + 15 * 60e3;
        notifyDone(t);                         // 站内通知
      }
      if (s.status === 'failed') {
        t.reason = s.reason;                   // 失败原因可见
        t.canRetry = s.reason !== 'DATA_LIMIT';
      }
    });
    pollFallback(taskId);                      // WS 断开轮询兜底
  }
  async retry(taskId) {
    const t = this.tasks.get(taskId);
    if (!t.canRetry) return toast('该失败不可重试');
    return this.create(t.filters);
  }
  download(taskId) {
    const t = this.tasks.get(taskId);
    if (Date.now() > t.expireAt)
      return this.renewUrl(taskId);            // 签名过期→换新
    location.href = t.url;
  }
}
```

**评分点**:
- 同条件去重（hash 比对进行中任务）。
- 进度 WS 订阅+轮询兜底双通道。
- 签名 URL 带过期时间与过期续签处理。
- 失败原因可见+按原因分类的可重试判断。
