## SCN-523：账户主页首屏性能优化怎么做？
**答**：
- 首屏切分：余额卡（聚合接口）同步渲染，图表/流水列表懒加载；余额未返回前显示骨架而不是 0.00——显示假 0 会引发恐慌。
- 交互可用优先：TTI 重于 FCP——按钮在数据就绪前禁用并给 loading，防「点了没反应」重复点击；JS 拆包让「查看流水」路径最小化。
- 请求编排：聚合接口 + 关键依赖预取（HTML 里 preload 首屏接口），非关键（营销 banner）延迟到 idle。
- 缓存与预热：登录成功后后台预取账户首页数据，跳转时 SWR 秒出。
- 追问钩子：为什么金融页禁用「占位 0」——用户可能立刻做决策（以为没钱去充值），数字不确定就用不确定性表达。

```javascript
// 路由级 code split + 骨架 + 禁用门控
const Flows = lazy(() => import('./Flows'));
function AccountHome() {
  const { data, isLoading } = useOverview();     // SCN-513 SWR 快照
  return (
    <>
      <BalanceCard value={data?.balance} loading={isLoading} /> {/* null → “--” 而非 0 */}
      <Suspense fallback={<FlowsSkeleton />}>
        <Flows />
      </Suspense>
      <TransferButton disabled={isLoading} hint={isLoading ? '数据加载中' : null} />
    </>
  );
}
```
