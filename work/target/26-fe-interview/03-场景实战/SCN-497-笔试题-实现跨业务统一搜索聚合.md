## SCN-497：手写统一搜索聚合：多源分组结果、权限裁剪、深链定位

**需求与边界**：
- 输入：query、数据源注册表；输出：聚合结果。
- 边界要求：① 多源并行检索（allSettled——单源慢不拖垮）；② 权限过滤在服务端（结果含摘录需有权）；③ 分组 tab（文档/消息/任务/人）；④ 深链协议（type:id+position 定位上下文——SCN-296 复用）。

**答**：
```javascript
async function unifiedSearch(q, user, { sources }) {
  const results = await Promise.allSettled(
    sources.map(s => s.search(q, { user })));   // 并行
  const groups = {};
  sources.forEach((s, i) => {
    groups[s.name] = results[i].status === 'fulfilled'
      ? results[i].value : { items: [], degraded: true };  // 降级标注
  });
  return groups;
}
// 深链：hit → routeByType(hit)
//   doc → /doc/${id}?hl=${pos}（片段高亮）
//   msg → /chat/${convId}?msgId=${id}（定位消息）
// 权限：服务端检索时 ACL 裁剪（无权→仅标题无摘录）；
// 降级源显示"暂不可用"（不静默空）。
```

**评分点**:
- allSettled 并行多源（单源失败降级标注）。
- 权限裁剪在服务端检索侧（摘录分级）。
- 分组 tab + 深链定位上下文（doc 片段/消息定位）。
- 未注册源不接入（注册制）。
