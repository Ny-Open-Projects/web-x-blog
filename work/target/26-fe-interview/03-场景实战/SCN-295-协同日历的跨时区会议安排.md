## SCN-295：团队日历的跨时区会议安排（忙闲/最佳时段）怎么实现？

**答**:
- 忙闲视图：参与者忙闲栅格（每人一天的时间格：忙/闲/ tentative），跨时区换算（每人所在时区的本地时间显示——同一时刻多时区并列：北京 9 点=伦敦 1 点），推荐时段算法（所有人空闲的交集∩工作时间交集，取重叠最大时段）。
- 会议邀请流：选人→忙闲查询→推荐时段→创建会议（日历事件+视频会议链接自动挂载）→邀请响应（接受/拒绝/提议新时间——响应状态实时可见）。
- 跨时区细节：DST 切换边界（夏令时切换周的会议安排警示）、时区歧义避免（一律存 UTC+按人显示）、"对某人太早"标记（凌晨时段红色警示）。
- 与日程联动：会议冲突检测（受邀人已有日程）、日历订阅（iCal 导出）、提醒策略（开始前 15 分钟多端提醒）。

```javascript
function suggestSlots(participants, range) {
  // 参与者忙闲（各自时区）→ 统一 UTC 轴
  const busy = participants.map(p => toUTCAxis(p.events, p.tz));
  const workHours = participants.map(p => workWindow(p.tz));
  const slots = intersectFree(busy).filter(inAllWork(workHours));
  return slots.map(s => ({ utc: s,
    locals: participants.map(p => fmt(s, p.tz)),
    warning: tooEarly(s, p.tz) }));
}
// 栅格渲染：每列=参与者，行=UTC 时间轴，本地时间双标。
// DST：isDSTTransition(week) && warn('本周含夏令时切换').
```
