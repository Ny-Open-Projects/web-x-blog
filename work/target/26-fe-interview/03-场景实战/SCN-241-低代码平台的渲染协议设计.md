## SCN-241：低代码平台的页面 schema（JSON）怎么渲染成页面？

**答**:
- 协议设计：节点树 schema（{id, type, props, children, bindings, events}），组件注册表（type→组件实现，版本化——组件升级不破旧 schema），属性协议（静态值/表达式/数据绑定三类区分）。
- 渲染引擎：递归渲染器（schema→组件树，白名单组件映射）、数据绑定解析（表达式引擎：受限于安全沙箱的求值——new Function 白名单风险，用受限表达式解析器）、事件绑定（事件名→动作协议：跳转/请求/弹窗/自定义动作）。
- 性能：大页面渲染（长列表节点虚拟化、按需渲染视口节点）、增量更新（schema patch 更新局部节点而非整树重渲）、预编译（schema→渲染函数缓存，重复访问免解析）。
- 安全边界：schema 是不可信输入（运营配置）——组件白名单、表达式沙箱、props 深度校验（防原型污染）、样式白名单（防 CSS 注入影响宿主）。

```javascript
const registry = new Map();                  // type → {comp, schema 校验}
function renderNode(node, ctx) {
  const reg = registry.get(node.type);
  if (!reg) return dev ? <MissingNode type={node.type}/> : null;
  const props = resolveProps(node.props, ctx);   // 静态/表达式/绑定
  return createElement(reg.comp, {
    ...props,
    key: node.id,
    events: bindEvents(node.events, ctx),        // 动作协议分发
  }, node.children?.map(c => renderNode(c, ctx)));
}
// 表达式沙箱：受限解析器（仅支持 a.b + c ? x : y 语法），
// 禁 new Function/eval。
// 增量更新：schema diff → 局部 re-render。
```
