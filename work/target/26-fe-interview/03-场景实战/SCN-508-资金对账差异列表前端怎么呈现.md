## SCN-508：资金对账差异列表前端怎么呈现与处理？
**答**：
- 差异分类：长款（我方有对方无）/短款/金额不一致/状态不一致分 Tab，默认按金额降序（资损风险优先），红色标注金额差。
- 双列对比：差异明细展开后左右对照（我方流水 vs 渠道流水），字段级 diff 高亮，支持一键复制两侧流水号给财务。
- 处理动作：挂起/认领/标注原因/发起调账，每个动作需二次确认并写审计；同一差异用乐观锁（version）防止两人同时处理。
- 状态回流：调账结果异步返回，列表项从「处理中」态流转为「已关闭」，WS 推送刷新不整表重载。
- 追问钩子：差异几千条怎么查——服务端筛选（日期/渠道/金额区间）+ 前端只做展示，绝不前端过滤全量。

```javascript
async function handle(item, action, reason) {
  const res = await api.post(`/recon/${item.id}/${action}`, {
    reason, version: item.version,          // 乐观锁
  }).catch(e => {
    if (e.code === 'VERSION_CONFLICT') {     // 别人已处理
      toast('该差异已被他人处理，正在刷新');
      return refreshOne(item.id);
    }
    throw e;
  });
  patchRow(item.id, { status: res.status, handledBy: res.operator });
}
function fieldDiff(mine, theirs) {
  return Object.keys(mine).filter(k => mine[k] !== theirs[k]); // 字段级高亮
}
```
