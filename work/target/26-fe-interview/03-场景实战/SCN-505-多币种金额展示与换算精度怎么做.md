## SCN-505：多币种金额展示与换算精度怎么做？
**答**：
- 展示本地化：用 Intl.NumberFormat 按币种渲染（日元无小数、美元两位），币种符号与小数位由服务端币种字典下发，前端不硬编码。
- 换算在服务端：前端只展示折算结果与「汇率时间戳」，不做自行换算入账；仅展示性换算（估值）用服务端下发的 rate 字符串。
- 精度策略：折算金额用字符串定点数展示到币种小数位，多余位数截断并标注「估算值」，防止用户当成入账金额。
- 一致性：同屏多币种折算必须用同一份快照汇率（带 snapshotId），否则列表合计与明细对不上。
- 追问钩子：为什么不用 float——0.1 + 0.2 !== 0.3，金融展示错一位就是客诉。

```javascript
const fmtCache = new Map();
function moneyFmt(currency) {
  if (!fmtCache.has(currency)) {
    fmtCache.set(currency, new Intl.NumberFormat(
      navigator.language, { style: 'currency', currency }));
  }
  return fmtCache.get(currency);
}
// 展示：服务端返回 { amount: "123456", scale: 2, currency: "USD", rateSnapshot: "r1" }
function display(m) {
  const v = Number(m.amount) / 10 ** m.scale;   // 整数字符串 + scale，避免浮点传输
  return { text: moneyFmt(m.currency).format(v), snapshot: m.rateSnapshot };
}
// 合计校验：同 snapshotId 才允许求和，否则提示「汇率快照不一致」
```
