## AIC-434：笔试：生成依赖画像（活跃度/使用面/风险标签）。
**题目**：输入 `deps: {name: {lastCommitDays, openIssues, usedIn}}`。风险标签规则：lastCommitDays > 365 → 'stalled'；usedIn > 50 → 'core'；两者叠加 → 'critical'。输出按风险排序的画像列表。

```javascript
function profile(deps) {
  const rank = { critical: 0, core: 1, stalled: 2, ok: 3 };
  return Object.entries(deps).map(([name, d]) => {
    const stalled = d.lastCommitDays > 365, core = d.usedIn > 50;
    const risk = stalled && core ? 'critical' : stalled ? 'stalled' : core ? 'core' : 'ok';
    return { name, risk, lastCommitDays: d.lastCommitDays, usedIn: d.usedIn };
  }).sort((a, b) => rank[a.risk] - rank[b.risk]);
}
console.log(profile({
  lodash: { lastCommitDays: 400, openIssues: 10, usedIn: 60 },   // critical
  vite: { lastCommitDays: 2, openIssues: 200, usedIn: 1 },       // ok
})); // lodash 在前

```

**评分点**：
- 标签判定顺序（critical > stalled/core）。
- 排序：critical > core > stalled > ok。
- 数值条件边界（恰好 365/50）。
- 输出字段固定便于下游消费。
