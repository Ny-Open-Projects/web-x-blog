## AIC-187：笔试：实现一个变更影响分析器：从 diff 提取改动符号、沿调用图传播、输出受影响测试清单？
**需求**：实现 `impactAnalysis(diffText, callGraph, testMap)`：
- 从 diff 中提取被改文件与改动的导出符号（新增行的 `export const/fn` + 删除行中的导出名）；
- 沿调用图（reverse index: callee → callers）传播 2 层；
- 匹配测试映射（file → testFiles），输出受影响测试清单（去重）与风险等级；
- 改动含公共导出删除 → critical（调用方必炸）。

```javascript
function extractChanged(diffText) {
  const files = [...diffText.matchAll(/^diff --git a\/(.+?) b\//gm)].map(m => m[1]);
  const removedExports = [...diffText.matchAll(/^-.*export\s+(?:const|function|class)\s+(\w+)/gm)].map(m => m[1]);
  const addedExports = [...diffText.matchAll(/^\+.*export\s+(?:const|function|class)\s+(\w+)/gm)].map(m => m[1]);
  return { files, removedExports, addedExports };
}

function impactAnalysis(diffText, callGraph, testMap, { depth = 2 } = {}) {
  const { files, removedExports, addedExports } = extractChanged(diffText);
  const affected = new Set(files);
  let frontier = [...files];
  for (let d = 0; d < depth; d++) {
    const next = [];
    for (const f of frontier) {
      for (const caller of callGraph.reverse[f] ?? []) {
        if (!affected.has(caller)) { affected.add(caller); next.push(caller); }
      }
    }
    frontier = next;
  }
  const tests = [...affected].flatMap(f => testMap[f] ?? []);
  const critical = removedExports.length > 0;
  return {
    affectedFiles: [...affected],
    removedExports, addedExports,
    testsToRun: [...new Set(tests)],
    risk: critical ? 'critical' : affected.size > 10 ? 'high' : affected.size > 3 ? 'medium' : 'low',
    note: critical ? `删除公共导出 ${removedExports.join(', ')}：所有调用方必须同步修改` : '',
  };
}

// 测试
const diff = `diff --git a/src/calc.ts b/src/calc.ts
@@ -1,3 +1,3 @@
-export function calcTotal(items) { return 0; }
+export function calcTotal(items, coupon) { return items.length; }`;
const callGraph = { reverse: { 'src/calc.ts': ['src/cart.ts', 'src/report.ts'], 'src/cart.ts': ['src/page.tsx'] } };
const testMap = { 'src/calc.ts': ['calc.spec.ts'], 'src/page.tsx': ['page.spec.ts'] };
console.log(impactAnalysis(diff, callGraph, testMap));
// affected: calc/cart/report/page 4 个 → medium，tests: calc.spec + page.spec
```

**评分点**：
1. 删除的导出单独识别（critical 判定依据）——签名变更比实现变更风险高一档；
2. 调用图反向传播的层数控制与 visited 去重；
3. 测试清单去重且来自「受影响文件」而非只改动的文件；
4. 风险分级与受影响面（文件数）及导出删除双因素；
5. 追问：精确到符号级的传播需要 import 绑定分析（该文件只用了一个导出时可以缩小范围）。
