## AIC-402：笔试：实现上下文预算分配器，按优先级把多个上下文片段装入有限窗口。
**题目**：给定片段列表 `[{name, tokens, priority, must}]` 与窗口 `budget`，装入策略：must 片段必须全装；其余按 priority 降序装入直到放不下；返回 `{packed, dropped, used}`。

```javascript
function packContext(items, budget) {
  if (budget <= 0) throw new RangeError('budget must be positive');
  const must = items.filter(i => i.must);
  const mustSum = must.reduce((s, i) => s + i.tokens, 0);
  if (mustSum > budget) throw new Error(`must items exceed budget: ${mustSum}/${budget}`);
  const optional = items.filter(i => !i.must)
    .sort((a, b) => b.priority - a.priority || a.tokens - b.tokens);
  let used = mustSum;
  const packed = [...must], dropped = [];
  for (const i of optional) {
    if (used + i.tokens <= budget) { packed.push(i); used += i.tokens; }
    else dropped.push(i.name);
  }
  return { packed: packed.map(i => i.name), dropped, used };
}
console.log(packContext([
  { name: 'rules', tokens: 1000, priority: 5, must: true },
  { name: 'fileA', tokens: 2000, priority: 3 },
  { name: 'fileB', tokens: 6000, priority: 2 },
  { name: 'history', tokens: 1000, priority: 1 },
], 8000)); // packed: rules,fileA,history; dropped: fileB

```

**评分点**：
- must 项总和超过 budget 时应显式报错而不是静默截断。
- 排序稳定且 priority 相同时按 tokens 小的优先（装入更多项）。
- 返回 dropped 清单用于诊断——面试官看重「可观测性」意识。
- 边界：budget 为 0/负数、空列表、tokens 为 0 的片段。
