## AIC-273：不同模型代码风格不同导致混用后代码「拼凑感」，如何统一？
**答**：
- 格式层统一：所有模型产出过同一 formatter/lint --fix，表面风格机器归一。
- 模式层统一：rules 中固化「仓库模式示例」，各模型注入同一示例——模式从示例学而非从预训练来。
- 评审兜底：AI 评审检查模式一致性（是否复用既有组件/是否沿用错误处理范式）。
- 统计观测：按模型统计「评审模式类意见数」，异常高的模型补更具体示例。

```javascript
const unify = {
  format: 'prettier/eslint --fix → 表面归一',
  pattern: 'rules 内嵌黄金示例 → 模式归一',
  observe: 'by-model pattern-feedback count → 异常模型补示例',
};
```
