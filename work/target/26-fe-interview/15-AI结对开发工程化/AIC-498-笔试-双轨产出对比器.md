## AIC-498：笔试：保守版 vs 激进版产出的量化对比。
**题目**：两版指标 `{loc, dupBlocks, perfMs}`。激进版需满足：性能提升 ≥ 20% 或重复块减少 ≥ 2 才推荐，否则保守版。输出 `{pick, reasons}`，指标缺失按保守处理。

```javascript
function pickVersion(safe, bold) {
  const perfGain = safe.perfMs ? (safe.perfMs - (bold.perfMs ?? safe.perfMs)) / safe.perfMs : 0;
  const dupCut = (safe.dupBlocks ?? 0) - (bold.dupBlocks ?? safe.dupBlocks ?? 0);
  const reasons = [];
  if (perfGain >= 0.2) reasons.push(`性能提升 ${(perfGain * 100).toFixed(0)}%`);
  if (dupCut >= 2) reasons.push(`重复块减少 ${dupCut}`);
  return { pick: reasons.length ? 'bold' : 'safe', reasons: reasons.length ? reasons : ['激进版无可量化优势，默认保守'] };
}
console.log(pickVersion({ loc: 100, dupBlocks: 3, perfMs: 100 }, { loc: 120, dupBlocks: 1, perfMs: 95 }));
// pick bold：dup 减 2

```

**评分点**：
- 双达标条件（或关系）明确。
- 指标缺失 → 默认保守（安全默认）。
- reasons 带数字证据。
- 相等性能判保守（不激进）。
