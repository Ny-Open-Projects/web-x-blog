## AIC-430：笔试：检测 Agent 重复行为循环。
**题目**：输入动作序列 `[{action, target}]`。连续 3 次相同 (action,target) 即循环。实现 `detectLoop(actions)` 返回首个循环的起始索引与片段，无循环返回 null。

```javascript
function detectLoop(actions) {
  for (let i = 0; i + 2 < actions.length; i++) {
    const a = actions[i], b = actions[i + 1], c = actions[i + 2];
    const same = (x, y) => x.action === y.action && x.target === y.target;
    if (same(a, b) && same(b, c))
      return { start: i, loop: [a.action, a.target] };
  }
  return null;
}
console.log(detectLoop([
  { action: 'read', target: 'a.ts' }, { action: 'read', target: 'b.ts' },
  { action: 'retry', target: 'test' }, { action: 'retry', target: 'test' },
  { action: 'retry', target: 'test' },
])); // start 2

```

**评分点**：
- 滑窗比较（连续 3 条相同）而非全串重复。
- 返回起始索引 + 循环片段（可诊断）。
- 恰好 3 次即触发（>=）。
- 空/短序列返回 null。
