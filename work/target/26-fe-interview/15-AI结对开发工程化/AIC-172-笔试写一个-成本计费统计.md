## AIC-172：笔试：实现一个 LLM 用量计费统计器：按模型单价计费、按项目/日聚合与异常检测？
**需求**：实现 `Meter` 类：
- `record({project, model, input, output, at})` 记录一条用量；单价表 `PRICE = {model: {input, output}}`（$/1M tokens）；
- `billBy(project)` / `billByDay(date)` 返回费用与 token 明细；
- 异常检测：单条费用 > 单条阈值 或 项目当日费用环比 > 3×触发告警；
- 未知模型单价时报错（防漏计费）。

```javascript
const PRICE = {
  'glm-high': { input: 2, output: 8 },
  'glm-cheap': { input: 0.5, output: 2 },
};
const ALERT_PER_CALL = 0.5; // 单条 $0.5

class Meter {
  #records = [];
  record(r) {
    const p = PRICE[r.model];
    if (!p) throw new Error(`未知模型单价: ${r.model}`); // 防漏计费：fail-fast
    const cost = (r.input * p.input + r.output * p.output) / 1e6;
    const rec = { ...r, cost };
    this.#records.push(rec);
    if (cost > ALERT_PER_CALL) this.#alert('single', rec);
    const today = this.dayOf(rec);
    const prev = this.dayTotal(rec.project, this.prevDate(today));
    if (prev > 0 && today > prev * 3) this.#alert('spike', rec);
    return rec;
  }
  dayOf(r) { return new Date(r.at).toISOString().slice(0, 10); }
  prevDate(d) { return new Date(new Date(d).getTime() - 864e5).toISOString().slice(0, 10); }

  billBy(project) {
    const rs = this.#records.filter(r => r.project === project);
    return { cost: sum(rs.map(r => r.cost)), tokens: sum(rs.map(r => r.input + r.output)), calls: rs.length };
  }
  billByDay(date) {
    const rs = this.#records.filter(r => this.dayOf(r) === date);
    const byProject = {};
    for (const r of rs) byProject[r.project] = (byProject[r.project] ?? 0) + r.cost;
    return { date, byProject, total: sum(rs.map(r => r.cost)) };
  }
  dayTotal(project, date) {
    return sum(this.#records.filter(r => r.project === project && this.dayOf(r) === date).map(r => r.cost));
  }
  #alert(kind, rec) { console.warn(`[Meter:${kind}]`, rec.project, rec.model, rec.cost); }
}
const sum = a => a.reduce((x, y) => x + y, 0);

// 测试
const m = new Meter();
m.record({ project: 'goods', model: 'glm-high', input: 50000, output: 2000, at: '2026-11-19T10:00:00Z' });
m.record({ project: 'goods', model: 'glm-cheap', input: 100000, output: 5000, at: '2026-11-19T11:00:00Z' });
console.log(m.billBy('goods')); // cost ≈ 0.1 + 0.06
```

**评分点**：
1. 单价表外的模型 fail-fast——静默 0 计费是成本黑洞；
2. 计费公式明确（$/1M tokens 换算），input/output 分价计；
3. 两级异常检测（单条费用尖峰 + 日环比突增）；
4. 聚合维度（项目/日）与查询 API 设计合理；
5. 追问：环比基准含节假日效应需周同比；记录应 append-only 持久化。
