## AIC-291：选型时容易被忽视的「上下文引擎」能力指什么？为什么比模型本身更重要？
**答**：
- 指工具如何组装上下文：相关文件检索、规则选择、依赖图裁剪、历史对话管理。
- 同一个模型，上下文组装差会导致关键文件没被看到——产出质量差距主要在这里。
- 评估方法：故意问「需要跨文件理解」的问题，看工具是否主动检索了正确文件。
- 自建方案可对比各家的上下文策略（embedding 检索/规则注入/最近文件）做组合。

```javascript
// 上下文组装对比实验
async function probe(ctxEngine: CtxEngine, task: string) {
  const ctx = await ctxEngine.assemble(task);
  const needed = groundTruthFiles(task);   // 人工标注的必要文件
  return { recall: intersect(ctx.files, needed).length / needed.length,
           tokens: ctx.tokenCount };
}
```
