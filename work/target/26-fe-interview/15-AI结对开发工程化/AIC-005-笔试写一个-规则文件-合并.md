## AIC-005：笔试：实现一个 Cursor 规则文件合并器，按 glob 匹配出某文件应注入哪些规则？
**题目**：给定规则列表 `[{ name, globs: string[], alwaysApply, content }]` 与目标文件路径，返回应注入的规则名数组。匹配规则：`alwaysApply: true` 的永远注入；否则当任一 glob 匹配目标路径时注入。glob 支持 `*`（单段）与 `**`（多段）。要求 30 行左右，含边界处理。

```typescript
function globToRegExp(glob: string): RegExp {
  // '**/' → 任意层级；'*' → 单段任意字符（不含 /）
  const re = glob
    .replace(/[.+^${}()|[\]\\]/g, '\\$&')
    .replace(/\*\*\//g, '(?:.*/)?')
    .replace(/\*\*/g, '.*')
    .replace(/\*/g, '[^/]*');
  return new RegExp(`^${re}$`);
}

function matchRules(
  file: string,
  rules: Array<{ name: string; globs: string[]; alwaysApply?: boolean }>
): string[] {
  if (!file || !Array.isArray(rules)) return [];
  const matched = rules.filter(r => {
    if (r.alwaysApply) return true;
    return (r.globs ?? []).some(g => globToRegExp(g).test(file));
  });
  return matched.map(r => r.name);
}

// 测试
const rules = [
  { name: 'fe', globs: ['src/components/**/*.tsx'] },
  { name: 'api', globs: ['server/api/**/*.ts'] },
  { name: 'base', globs: [], alwaysApply: true },
];
console.log(matchRules('src/components/Goods/List.tsx', rules)); // ['fe','base']
console.log(matchRules('server/api/goods.ts', rules));           // ['api','base']
console.log(matchRules('README.md', rules));                     // ['base']
```
**评分点**：
- glob → 正则的转义是否正确（先把正则元字符转义再替换通配符）。
- `**/` 与 `*` 语义区分：`*` 不得跨目录（`[^/]*`），写出 `[^/]*` 是核心得分点。
- `alwaysApply` 优先短路，空 globs 不抛错。
- 输出保持规则定义顺序（用 filter 而非收集时乱序）。
- 能说出「等价实现可用 minimatch 库」体现工程意识。
