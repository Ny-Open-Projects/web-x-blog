## AIC-170：笔试：实现一个嵌入检索重排器：余弦相似度初排 + 规则重排（去冗余/多样性）？
**需求**：实现 `rerank(queryVec, docs, { topK, lambda })`：
- docs: `[{id, vec, path, text}]`；余弦相似度初排取候选 3×topK；
- MMR 式重排：`score = λ·rel − (1−λ)·maxSim(已选)`，λ 平衡相关性与多样性；
- 同 path 的文档天然冗余（maxSim 加 0.2 惩罚）；
- 输出 topK 及每条的 rel/diversity 值。

```javascript
function cosine(a, b) {
  let dot = 0, na = 0, nb = 0;
  for (let i = 0; i < a.length; i++) { dot += a[i] * b[i]; na += a[i] ** 2; nb += b[i] ** 2; }
  return dot / (Math.sqrt(na) * Math.sqrt(nb) || 1);
}

function rerank(queryVec, docs, { topK = 3, lambda = 0.7 } = {}) {
  const scored = docs.map(d => ({ ...d, rel: cosine(queryVec, d.vec) }))
    .sort((a, b) => b.rel - a.rel)
    .slice(0, topK * 3);                       // 候选池

  const selected = [];
  const rest = [...scored];
  while (selected.length < topK && rest.length) {
    let best = null, bestScore = -Infinity;
    for (const d of rest) {
      const maxSim = selected.length
        ? Math.max(...selected.map(s => {
            const sim = cosine(d.vec, s.vec);
            return d.path === s.path ? sim + 0.2 : sim;  // 同文件冗余惩罚
          }))
        : 0;
      const score = lambda * d.rel - (1 - lambda) * maxSim;
      if (score > bestScore) { bestScore = score; best = d; }
    }
    selected.push({ ...best, diversity: +(1 - (bestScore + (1 - lambda) * 0) ).toFixed(3), mmr: +bestScore.toFixed(3) });
    rest.splice(rest.indexOf(best), 1);
  }
  return selected.map(s => ({ id: s.id, path: s.path, rel: +s.rel.toFixed(3), mmr: s.mmr }));
}

// 测试（4 维玩具向量）
const q = [1, 0, 0, 0];
const docs = [
  { id: 'a', path: 'f1.ts', vec: [0.9, 0.1, 0, 0], text: '分页实现' },
  { id: 'b', path: 'f1.ts', vec: [0.85, 0.15, 0, 0], text: '分页实现（重复）' }, // 与 a 几乎一样且同文件
  { id: 'c', path: 'f2.ts', vec: [0.8, 0, 0.2, 0], text: '游标说明' },
];
console.log(rerank(q, docs, { topK: 2 }));
// [a, c]：b 因与 a 同文件高相似被多样性惩罚挤掉
```

**评分点**：
1. 余弦相似度正确实现（含零向量保护）；
2. MMR 公式方向正确：λ·rel − (1−λ)·maxSim，λ 偏高重相关、偏低重多样；
3. 同文件惩罚体现领域知识（同 path 文档冗余度高）；
4. 候选池 3×topK 再重排的工程习惯（全量重排成本高）；
5. 追问：真实场景向量来自 embedding 模型，本实现用玩具向量演示算法骨架。
