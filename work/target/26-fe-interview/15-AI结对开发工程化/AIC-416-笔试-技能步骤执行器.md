## AIC-416：笔试：实现技能（步骤清单）执行器，带失败即停与跳过标记。
**题目**：技能 `{steps: [{name, run}]}`。顺序执行：步骤抛错即停，返回 `{done, failedAt, log}`；支持 `resumeFrom(stepName)` 从指定步骤续跑（幂等由步骤自行保证，executor 只负责跳过）。

```javascript
async function runSkill(skill, { resumeFrom } = {}) {
  const names = skill.steps.map(s => s.name);
  let start = 0;
  if (resumeFrom) {
    start = names.indexOf(resumeFrom);
    if (start < 0) throw new Error(`unknown step: ${resumeFrom}`);
  }
  const log = [];
  for (const step of skill.steps.slice(start)) {
    const t0 = Date.now();
    try {
      await step.run();
      log.push({ step: step.name, ok: true, ms: Date.now() - t0 });
    } catch (e) {
      log.push({ step: step.name, ok: false, err: String(e), ms: Date.now() - t0 });
      return { done: false, failedAt: step.name, log };
    }
  }
  return { done: true, failedAt: null, log };
}
// 用法：失败后修复环境 → runSkill(skill, { resumeFrom: failedStep })

```

**评分点**：
- 失败即停且 log 完整记录每步耗时与结果。
- resumeFrom 校验步骤存在，不存在报错。
- 每步计时（performance.now 或 Date.now）——可观测性意识。
- 空步骤列表直接成功返回。
