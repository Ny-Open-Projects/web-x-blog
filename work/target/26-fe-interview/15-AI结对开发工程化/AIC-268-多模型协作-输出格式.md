## AIC-268：多模型混合使用时输出格式不稳定（JSON 解析常挂），如何工程化解决？
**答**：
- 强约束优先：用 API 的结构化输出/JSON mode 而非提示词里口头要求。
- 防御解析：宽松解析（截取首个 JSON 块/修复尾逗号）+ schema 校验失败自动重试一次。
- 格式中间件：解析层独立成模块统一处理各模型差异，上层无感知。
- 降级路径：重试仍失败 → 记录坏样本（用于提示词迭代）→ 降级为自由文本人读。

```javascript
function robustParse<T>(raw: string, schema: Schema<T>): T | null {
  const json = extractFirstJSON(raw);          // 截取 json 围栏块或首个 {...}
  const fixed = repairTrailingComma(json);
  const ok = schema.safeParse(fixed);
  if (ok.success) return ok.data;
  log('format-miss', raw.slice(0, 200));       // 坏样本留存
  return retryOnce(raw) ?? humanFallback(raw); // 人读降级
}
```
