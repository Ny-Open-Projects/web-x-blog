## AIC-468：笔试：生成模型对比评测报告（含显著性简化判定）。
**题目**：输入 `[{model, pass, total}]`。输出通过率排名表（降序）；两模型通过率差 ≥ 5 个百分点视为「显著差异」并列出差异对。

```javascript
function evalReport(results) {
  const ranked = results.map(r => ({ model: r.model,
    rate: r.total ? r.pass / r.total : 0 }))
    .sort((a, b) => b.rate - a.rate);
  const lines = ranked.map(r => `| ${r.model} | ${(r.rate * 100).toFixed(1)}% |`);
  const diffs = [];
  for (let i = 0; i < ranked.length; i++)
    for (let j = i + 1; j < ranked.length; j++) {
      const d = ranked[i].rate - ranked[j].rate;
      if (d >= 0.05) diffs.push({ better: ranked[i].model, worse: ranked[j].model,
        delta: +(d * 100).toFixed(1) });
    }
  return { table: ['| model | passRate |', '|---|---|', ...lines], significant: diffs };
}
console.log(evalReport([
  { model: 'A', pass: 90, total: 100 }, { model: 'B', pass: 82, total: 100 },
]).significant); // A 比 B 高 8pt → 显著

```

**评分点**：
- 率计算 + 排序 + 并列名次处理（同率同名次可选简化）。
- 显著差异 pairwise 对比列出（只比较相邻或全对均可，说明取舍）。
- 输出 Markdown 表格行可直接渲染。
- 除零保护（total=0）。
