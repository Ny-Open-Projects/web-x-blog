## AIC-180：笔试：实现一个评审抽样器：风险加权、周配额公平分配与重复抽样规避？
**需求**：实现 `weeklySample(prs, team)`：
- 每个 PR 风险分：AI 生成行数/500 + 目录权重（payment/auth ×5、core ×3、其他 ×1）+ 是否大 diff（>500 行 +2）；
- 抽样配额 = 团队人数（每人 1 个），加权随机抽样（权重大被抽概率高）；
- 同一 PR 一周内不被抽两次（历史记录排除）；
- 返回 `[{pr, reviewer}]`，reviewer 轮转分配（工作量均衡）。

```javascript
function riskScore(pr) {
  const dirW = (p) => p.files.some(f => /payment|auth/.test(f)) ? 5
    : pr.files.some(f => /\/core\//.test(f)) ? 3 : 1;
  return pr.aiLines / 500 + dirW(pr) + (pr.totalLines > 500 ? 2 : 0);
}

function weightedPick(items, exclude) {
  const pool = items.filter(i => !exclude.has(i.id));
  const total = pool.reduce((s, i) => s + i.w, 0);
  let r = Math.random() * total;
  for (const i of pool) { r -= i.w; if (r <= 0) return i; }
  return pool.at(-1); // 浮点兜底
}

function weeklySample(prs, team, history = new Set()) {
  const scored = prs.map(p => ({ id: p.id, pr: p, w: Math.max(riskScore(p), 0.01) }));
  const exclude = new Set(history);
  const picks = [];
  const queue = [...team]; // 轮转队列
  for (let i = 0; i < team.length; i++) {
    const picked = weightedPick(scored, exclude);
    exclude.add(picked.id);                       // 本周内不重复
    picks.push({ pr: picked.pr, reviewer: queue[i % team.length] });
  }
  return picks;
}

// 测试
const prs = [
  { id: 'P1', aiLines: 800, totalLines: 600, files: ['payment/export.ts'] },
  { id: 'P2', aiLines: 50, totalLines: 60, files: ['ui/button.tsx'] },
  { id: 'P3', aiLines: 100, totalLines: 200, files: ['core/log.ts'] },
];
console.log(weeklySample(prs, ['alice', 'bob']));
// P1 权重最高（800/500+5+2）几乎必中；reviewer 轮转不重叠
```

**评分点**：
1. 风险权重可解释（AI 量/目录风险/diff 规模三因子），且下限 0.01 防零权重永不被抽；
2. 加权随机而非纯 topN——保留抽查的不可预测性（可发现系统性问题而非固定靶）；
3. exclude 双层：历史周记录 + 本周内去重；
4. reviewer 轮转分配保证工作量均衡；
5. 追问：加权随机的公平性可用蓄水池抽样改造（流式 PR 场景）。
