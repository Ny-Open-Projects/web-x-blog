## AIC-279：监管/客户要求提供「AI 使用合规证据」，日常要提前留存哪些证据？
**答**：
- 使用记录：谁在什么范围使用什么工具（网关日志），数据分级隔离证明。
- 产出溯源：AI 代码标记（commit trailer）+ 门禁通过记录（测试/评审链）。
- 制度文件：数据分级制度/工具白名单/审计流程的版本化文档。
- 培训记录：员工 AI 使用规范培训签到与考核——证据链要能串起「制度-执行-监督」。

```javascript
const evidence = {
  usage: 'gateway logs（who/repo/tool/mode）',
  provenance: 'commit trailers + gate pass records',
  policy: 'versioned policy docs + 白名单',
  training: '培训签到 + 考核记录',
  chain: '制度 → 执行 → 监督 三段可追溯',
};
```
