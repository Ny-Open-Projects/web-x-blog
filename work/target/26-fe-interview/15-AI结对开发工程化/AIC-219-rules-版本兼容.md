## AIC-219：框架大版本升级（如 React 18→19）时，规则库如何同步迁移而不误导模型？
**答**：
- 升级前先冻结旧规则并标注版本：`适用 React 18`，避免新旧混用。
- 升级中：规则明确写「当前仓库处于 18→19 迁移期，src/migrated/ 用 19 写法，其余用 18」，给模型分区指引。
- 迁移完成后删除过渡规则，全量更新示例代码。
- 用评测集跑迁移前后的规则，确保新规则与新 lint 一致。

```javascript
# migration-period.mdc
# globs: ["src/**/*.tsx"]
# ---
# 仓库处于 React 18→19 迁移期：
# - src/migrated/**：使用 React 19（Actions、use）
# - 其余目录：维持 18 写法，禁止混用新 API
# 迁移完成后本规则废弃。
r
```
