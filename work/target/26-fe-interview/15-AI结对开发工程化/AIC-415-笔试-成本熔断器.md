## AIC-415：笔试：实现按仓库的 AI 成本日熔断器。
**题目**：`check(repo, usd)`：累计当日成本，超过 limit 时返回 `{allow:false, mode:'fallback'}` 并记录；超过 limit 的 80% 返回 `{allow:true, warn:true}`。支持 `reset(date)` 跨日重置。

```javascript
class BudgetGuard {
  constructor(limit) { this.limit = limit; this.today = ''; this.spent = new Map(); }
  roll(date) { if (date !== this.today) { this.today = date; this.spent.clear(); } }
  check(repo, usd, date) {
    this.roll(date);
    const cur = (this.spent.get(repo) || 0) + usd;
    this.spent.set(repo, cur);
    if (cur > this.limit) return { allow: false, mode: 'fallback', spent: cur };
    if (cur > this.limit * 0.8) return { allow: true, warn: true, spent: cur };
    return { allow: true, spent: cur };
  }
}
const g = new BudgetGuard(100);
console.log(g.check('web', 85, '2026-11-20')); // warn
console.log(g.check('web', 30, '2026-11-20')); // deny → fallback
console.log(g.check('web', 30, '2026-11-21')); // 跨日重置 → allow

```

**评分点**：
- 状态按仓库隔离（Map），跨日重置逻辑正确（用日期字符串比对）。
- warn 阈值（80%）与熔断阈值双层设计。
- 熔断后请求被拒但仍计入尝试（或明确不计，说明取舍）。
- 并发场景说明：单进程内顺序调用即可，多实例需集中存储（加分讨论）。
