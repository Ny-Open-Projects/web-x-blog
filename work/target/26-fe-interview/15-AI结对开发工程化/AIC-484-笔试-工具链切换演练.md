## AIC-484：笔试：切换 AI 工具前的「资产迁移校验」。
**题目**：资产清单 `[{kind, path, portable}]`。校验：portable=false 的资产（依赖私有特性）列出并给替代建议；portable 资产校验目标路径存在（迁移完成）。输出 `{ready, blockers, doneCount}`。

```javascript
function switchCheck(assets, targetExists) {
  const blockers = [], letDone = 0;
  let done = 0;
  for (const a of assets) {
    if (!a.portable) {
      blockers.push({ asset: a.path,
        suggest: `依赖私有特性，改用开放格式重写（${a.kind}）` });
      continue;
    }
    if (targetExists(a.targetPath)) done++;
    else blockers.push({ asset: a.path, suggest: `迁移到 ${a.targetPath}` });
  }
  return { ready: blockers.length === 0 && done === assets.length, blockers, doneCount: done };
}
console.log(switchCheck([
  { kind: 'rules', path: '.cursor/rules', portable: true, targetPath: 'docs/rules' },
  { kind: 'memory', path: 'cursor-memory', portable: false, targetPath: '' },
], p => p === 'docs/rules')); // ready:false，memory 是 blocker

```

**评分点**：
- portable=false 即 blocker（阻断切换）。
- portable 资产按目标路径存在性判定已迁移。
- ready = 无 blocker 且全部迁移完成。
- blockers 带替代建议（可执行）。
