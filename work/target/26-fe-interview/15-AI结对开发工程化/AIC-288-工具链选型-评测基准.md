## AIC-288：团队自建 AI 编码能力基准（internal benchmark），应该怎么设计？
**答**：
- 题源：从真实事故/历史任务中抽取，脱敏后固化环境（依赖版本/测试基线），保证可复现。
- 判定自动化：以「测试通过 + 类型检查 + 关键行为断言」为判据，少用 LLM 主观评分。
- 分层：补全级（30s 内任务）/ 功能级（30min 任务）/ 架构级（方案题人评）。
- 防过拟合：题目定期轮换 20%，禁止单一模型针对评测集调优。

```javascript
const bench = {
  levels: { completion: { count: 50, auto: true }, feature: { count: 20, auto: true },
            arch: { count: 5, judge: 'human-panel' } },
  auto: 'vitest pass && tsc --noEmit && behavior-assert',
  rotate: '每季度替换 20% 题目，旧题归档禁用',
};
```
