## AIC-443：笔试：迁移期按文件路由新旧规范。
**题目**：迁移地图 `{'src/migrated/**': 'v2', 'src/**': 'v1'}`。实现 `pickRules(path, map)`：最长 pattern 命中优先（更具体者胜）；无命中 → default。输出规范版本与命中 pattern。

```javascript
function pickRules(path, map, def = 'v1') {
  const hits = Object.entries(map).filter(([p]) => globMatch(p, path));
  if (!hits.length) return { version: def, pattern: 'default' };
  hits.sort((a, b) => b[0].length - a[0].length);
  return { version: hits[0][1], pattern: hits[0][0] };
}
function globMatch(p, s) {
  const re = p.replace(/\*\*\//g, '(?:.*/)?').replace(/\*/g, '[^/]*');
  return new RegExp(`^${re}$`).test(s);
}
console.log(pickRules('src/migrated/a.ts', { 'src/migrated/**': 'v2', 'src/**': 'v1' }));
// v2（更长 pattern 优先）

```

**评分点**：
- 最长匹配优先（具体度排序）——glob 语义正确性。
- 命中输出 pattern（可解释）。
- default 兜底不抛错。
- 多条同长命中取先声明（说明取舍）。
