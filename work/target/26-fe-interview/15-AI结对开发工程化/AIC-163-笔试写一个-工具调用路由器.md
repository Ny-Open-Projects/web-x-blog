## AIC-163：笔试：实现一个 Agent 工具调用路由器：schema 校验、权限检查、结果摘要回注？
**需求**：实现 `dispatch(toolCall, registry, policy)`：
- registry: `{name, schema, run, risky}`；按 schema 校验参数（required/type）；
- policy：白名单工具 + risky 工具需人工确认标记；
- 结果统一摘要（截断 200 字符）回注给模型（防大结果撑爆上下文）；
- 工具抛错时返回错误摘要而非中断 agent 循环。

```javascript
function validateArgs(args, schema) {
  const errors = [];
  for (const [k, rule] of Object.entries(schema)) {
    if (rule.required && args?.[k] === undefined) errors.push(`缺少参数 ${k}`);
    if (args?.[k] !== undefined && typeof args[k] !== rule.type
        && !(rule.type === 'array' && Array.isArray(args[k]))) {
      errors.push(`参数 ${k} 类型应为 ${rule.type}`);
    }
  }
  return errors;
}

async function dispatch(toolCall, registry, policy, { maxResultLen = 200 } = {}) {
  const tool = registry[toolCall.name];
  if (!tool) return { ok: false, error: `未知工具 ${toolCall.name}` };   // 防工具名幻觉

  if (!policy.allowed.includes(toolCall.name)) {
    return { ok: false, error: `工具 ${toolCall.name} 未授权` };
  }
  const argErrors = validateArgs(toolCall.args ?? {}, tool.schema);
  if (argErrors.length) return { ok: false, error: `参数错误：${argErrors.join('; ')}` };

  if (tool.risky && !toolCall.confirmed) {
    return { ok: false, needConfirm: true, error: `${toolCall.name} 是高危工具，需人工确认` };
  }

  try {
    const result = await tool.run(toolCall.args);
    const summary = typeof result === 'string' ? result : JSON.stringify(result);
    return {
      ok: true,
      result: summary.length > maxResultLen
        ? summary.slice(0, maxResultLen) + `...[共 ${summary.length} 字符，可分页读取]`
        : summary,
    };
  } catch (e) {
    return { ok: false, error: `工具执行失败：${String(e).slice(0, 200)}` };
  }
}

// 测试
const registry = {
  readFile: { schema: { path: { type: 'string', required: true } }, run: async a => '内容'.repeat(500), risky: false },
  deleteFile: { schema: { path: { type: 'string', required: true } }, run: async a => 'deleted', risky: true },
};
const policy = { allowed: ['readFile', 'deleteFile'] };
console.log((await dispatch({ name: 'readFile', args: { path: 'a.ts' } }, registry, policy)).result.length <= 210); // true 摘要截断
console.log((await dispatch({ name: 'deleteFile', args: { path: 'x' } }, registry, policy)).needConfirm); // true
```

**评分点**：
1. 未知工具返回错误而非崩溃——模型会编造工具名（工具幻觉），agent 循环必须容错；
2. risky 工具的确认闸（needConfirm）而非直接拒绝——「拦住但可继续」符合审批点设计；
3. 结果摘要截断并提示可分页——防工具结果撑爆上下文窗口；
4. 参数校验在权限校验之后顺序（先授权后验参，减少信息泄露面）可讨论；
5. 工具错误以摘要回注而非抛出中断——agent 循环的健壮性核心。
