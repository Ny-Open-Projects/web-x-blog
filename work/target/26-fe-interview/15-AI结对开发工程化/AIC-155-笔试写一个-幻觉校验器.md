## AIC-155：笔试：实现一个幻觉校验器，抽取 AI 代码中的 API 调用并与白名单/d.ts 比对输出可疑项？
**需求**：实现 `detectHallucination(code, knownApis)`：
- 抽取代码中的调用（`obj.method(...)` 与 `fn(...)` 两种形态）；
- 与白名单比对：成员调用按「对象.方法」查，自由函数直接查；对象名先解析 import 来源映射到其方法集；
- 输出可疑调用清单（白名单没有的），每条附「最相似的真实 API」建议（编辑距离最近）。

```javascript
function extractCalls(code) {
  const calls = new Set();
  for (const m of code.matchAll(/\b([A-Za-z_$][\w$]*)\.([A-Za-z_$][\w$]*)\s*\(/g)) {
    calls.add(`${m[1]}.${m[2]}`);
  }
  for (const m of code.matchAll(/(?<![.\w$])([A-Za-z_$][\w$]*)\s*\(/g)) {
    if (!['if', 'for', 'while', 'switch', 'catch', 'return', 'function'].includes(m[1])) {
      calls.add(m[1]);
    }
  }
  return [...calls];
}

function editDistance(a, b) {
  const dp = Array.from({ length: b.length + 1 }, (_, i) => [i, ...Array(a.length).fill(0)]);
  for (let j = 0; j <= a.length; j++) dp[0][j] = j;
  for (let i = 1; i <= b.length; i++)
    for (let j = 1; j <= a.length; j++)
      dp[i][j] = Math.min(dp[i - 1][j] + 1, dp[i][j - 1] + 1,
        dp[i - 1][j - 1] + (b[i - 1] === a[j - 1] ? 0 : 1));
  return dp[b.length][a.length];
}

function detectHallucination(code, knownApis, importMap = {}) {
  const suspects = [];
  for (const call of extractCalls(code)) {
    if (call.includes('.')) {
      const [obj, method] = call.split('.');
      const objSource = importMap[obj] ?? obj; // axios→'axios'
      const apis = knownApis.filter(k => k.startsWith(objSource + '.'));
      if (apis.length && !apis.some(k => k === `${objSource}.${method}`)) {
        suspects.push({ call, nearest: nearest(apis, method) });
      }
    } else if (!knownApis.includes(call)) {
      suspects.push({ call, nearest: nearest(knownApis, call) });
    }
  }
  return suspects;
}
function nearest(apis, name) {
  let best = apis[0], d = Infinity;
  for (const a of apis) { const dist = editDistance(a.split('.').pop(), name); if (dist < d) { d = dist; best = a; } }
  return d <= 2 ? best : null; // 距离 ≤2 才算「疑似拼错」
}

// 测试
const known = ['axios.get', 'axios.post', 'goodsApi.list', 'goodsApi.detail'];
const code = `import goodsApi from '@/api/goods';
const r = await axios.gett('/x');     // gett → 拼写幻觉，建议 axios.get
const l = await goodsApi.listAll();   // listAll → 建议 goodsApi.list`;
console.log(detectHallucination(code, known, { goodsApi: 'goodsApi' }));
```

**评分点**：
1. 两形态抽取（成员/自由函数）且排除关键字，漏 `fn(` 形态只能抓一半幻觉；
2. importMap 解析对象真实来源——不解析的话本地别名全是「幻觉」误报；
3. 近似建议用编辑距离且设阈值（≤2），无阈值会给出荒谬建议；
4. 已知对象的「方法级」白名单比对（该对象存在但方法编造）——只查对象名会漏这类；
5. 主动说明：静态抽取无法覆盖动态调用（`obj[k]()`），生产应叠加 tsc 校验。
