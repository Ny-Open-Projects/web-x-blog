## AIC-426：笔试：实现「风险分级 → 评审流程」的路由策略。
**题目**：输入风险 `{score, level}` 与策略表 `{low: 'auto-merge', mid: 'single-review', high: 'double-review+ai-deep'}`。实现 `routeReview(risk, policy)`：未知 level 抛错；返回流程字符串；策略表缺项用默认 single-review 并告警。

```javascript
function routeReview(risk, policy = {}, warn = () => {}) {
  const def = { low: 'auto-merge', mid: 'single-review', high: 'double-review+ai-deep' };
  const merged = { ...def, ...policy };
  for (const k of Object.keys(policy))
    if (!(k in def)) warn(`unknown policy key: ${k}`);
  const flow = merged[risk.level];
  if (!flow) throw new Error(`unknown risk level: ${risk.level}`);
  return `[${risk.level}] ${flow}`;
}
console.log(routeReview({ score: 8, level: 'high' }));                       // double-review
console.log(routeReview({ score: 1, level: 'low' }, { low: 'single-review' }));

```

**评分点**：
- 策略查表 + 缺项降级（default + warning）。
- 未知 level 显式报错而非静默。
- 输出可拼接说明（level + 流程）。
- 空策略表全部走默认并告警一次。
