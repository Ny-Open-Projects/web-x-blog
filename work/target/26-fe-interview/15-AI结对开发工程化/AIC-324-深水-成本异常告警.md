## AIC-324：某个 Agent 任务陷入循环重试烧钱，如何设计成本异常检测？
**答**：
- 任务级预算：每个任务预设 token 上限与耗时上限，超限熔断并汇报中间状态。
- 循环检测：相似请求（embedding 相似度 > 0.95）连续出现 N 次判定为循环。
- 全局看板：实时成本速率（$/分钟）分仓库/任务类型展示，速率异常告警。
- 熔断后处理：保存已完成的中间产物，人介入归因（任务模糊/环境问题/模型能力不足）。

```javascript
function costGuard(task: RunningTask) {
  if (task.tokens > task.budget || task.minutes > task.wall) return { action: 'halt', save: 'partial' };
  const loops = similarRequests(task.history, 0.95);
  if (loops.streak >= 3) return { action: 'halt', reason: 'loop-detected', detail: loops.top };
  return { action: 'continue' };
}
```
