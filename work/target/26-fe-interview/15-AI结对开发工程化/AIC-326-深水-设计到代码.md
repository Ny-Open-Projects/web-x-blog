## AIC-326：从设计稿（Figma）到代码的 AI 流水线，如何保证产出符合设计系统而不是「像素级复刻」的自由代码？
**答**：
- 中间表示：设计稿先转结构化描述（组件树+token 引用），不直接像素转代码。
- 强制走组件库：Agent 只能用既有组件组装 + token 变量，自定义样式需声明理由。
- 还原度与规范度双验收：视觉 diff（还原度）+ lint/规范检查（规范度），双达标才算完成。
- 边界处理：设计稿中的「设计错误」（与 token 体系冲突的颜色）报告给人裁决而非硬抄。

```javascript
async function designToCode(figma: FigmaNode) {
  const spec = await toStructuredSpec(figma);       // 组件树 + token
  const violations = spec.colors.filter(c => !isToken(c));
  if (violations.length) return { status: 'review-needed', violations }; // 设计稿自身异常
  return generate(spec, { components: designSystem, style: 'tokens-only' });
}
```
