## AIC-481：笔试：检测长会话中「约束漂移」（AI 复述的约束与原始不符）。
**题目**：原始约束列表 constraints 与 AI 复述文本 restated。逐条检测：复述中含该约束关键词即「保持」；缺失即「丢失」；出现「不/禁止 + 关键词」即「反转」（最危险）。输出三类清单。

```javascript
function driftCheck(constraints, restated) {
  const reversed = [], missing = [], kept = [];
  for (const c of constraints) {
    const kw = c.slice(0, 4);
    const re = new RegExp(`(不|禁止|never|don't)\\S{0,6}${kw}`);
    if (re.test(restated)) reversed.push(c);
    else if (restated.includes(kw)) kept.push(c);
    else missing.push(c);
  }
  return { reversed, missing, kept,
           clean: reversed.length === 0 && missing.length === 0 };
}
console.log(driftCheck(['使用 token 颜色', '禁止直接 fetch'],
  '记住：不要使用 token，直接 fetch 即可')); // reversed 2 条 → 最危险

```

**评分点**：
- 三类检测顺序：反转优先于丢失（一条只能归一类）。
- 关键词取约束首词（简化，说明局限）。
- 反转是最高危信号（置顶输出）。
- 全保持时输出 clean。
