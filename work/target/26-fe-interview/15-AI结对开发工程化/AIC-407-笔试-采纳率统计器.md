## AIC-407：笔试：实现 AI 评审采纳率统计（含「语义采纳」判断）。
**题目**：输入评审意见与后续 commit 列表。意见被采纳 = 存在 commit 的修改文件与意见位置匹配，且 diff 中出现意见关键词（简化为子串匹配）。输出 `{total, adopted, rate}`。

```javascript
function adoptionRate(reviews, commits) {
  const real = commits.filter(c => !c.message.startsWith('docs:'));
  let adopted = 0;
  for (const r of reviews) {
    const hit = real.some(c => c.files.includes(r.file)
      && c.changes.some(ch => ch.near(r.line) && ch.text.includes(r.keyword)));
    if (hit) adopted++;
  }
  return { total: reviews.length, adopted,
           rate: reviews.length ? +(adopted / reviews.length).toFixed(2) : 0 };
}
const commit = {
  message: 'fix: use tryParse', files: ['a.ts'],
  changes: [{ near: l => Math.abs(l - 10) <= 2, text: '- parse(x) -> tryParse(x)' }],
};
console.log(adoptionRate([{ file: 'a.ts', line: 10, keyword: 'tryParse' }], [commit]));
// { total: 1, adopted: 1, rate: 1 } 位置邻近 + 关键词命中

```

**评分点**：
- 位置匹配（文件+行附近）与内容匹配（关键词）双条件才算采纳——只按文件匹配会虚高。
- 同一 commit 匹配多条意见时各自独立计数。
- 排除 docs-only commit（自动化脚本改动不算语义采纳）。
- 率计算保留两位小数并处理除零。
