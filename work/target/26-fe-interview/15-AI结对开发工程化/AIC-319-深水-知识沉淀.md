## AIC-319：AI 结对开发中的经验（什么任务用什么提示词有效）如何沉淀为团队资产？
**答**：
- 提示词资产化：有效的提示词进 Prompt Library（带场景标签/版本/效果数据），禁止散落在个人收藏。
- 案例库：成功任务归档「任务卡+最终提示词+产出 diff」，失败任务归档根因，形成可检索案例集。
- 检索集成：Agent 执行任务时自动检索相似案例注入上下文——经验闭环。
- 维护机制：季度评审过时案例，高复用案例晋升为规则/技能。

```javascript
const promptLibrary = {
  entry: { scene: 'SSR 页面迁移', prompt: v3, metrics: { passRate: 0.86, n: 21 } },
  loop: '任务开始 → 检索相似案例（embedding）→ 注入 top3 → 结束回写效果数据',
};
```
