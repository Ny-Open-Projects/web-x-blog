## AIC-251：两个模型对同一代码给出相反结论（一个说有性能问题一个说没有），如何仲裁？
**答**：
- 仲裁靠证据不靠投票：用测量（基准测试/profile）判定，让两个模型基于同一测量数据再讨论。
- 要求双方给出可证伪的依据（代码行号、复杂度分析、基准数字），无依据结论直接丢弃。
- 分歧分类：事实分歧（可测量→测）、观点分歧（权衡→人）、定义分歧（语义不一致→澄清）。
- 沉淀仲裁记录：重复出现的分歧模式写进提示词，减少下次分歧。

```javascript
async function arbitrate(a: string, b: string) {
  if (isMeasurable(a) && isMeasurable(b)) {
    const bench = await microBench(targetCode);  // 测量是最终裁判
    return rejudge([a, b], bench);
  }
  return classify(a, b); // fact→measure / opinion→human / definition→clarify
}
```
