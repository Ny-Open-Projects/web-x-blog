## AIC-477：笔试：实现「静态工具 → AI 评审 → 人审」编排器。
**题目**：`pipeline(pr)`：静态工具全过才进 AI；AI 高危意见直接 block；低危输出 comment。每阶段记录耗时。输出 `{verdict, findings, timings}`。

```javascript
async function pipeline(pr, { staticCheck, aiReview }) {
  const timings = {};
  let t0 = Date.now();
  const det = await staticCheck(pr);
  timings.static = Date.now() - t0;
  if (det.length) return { verdict: 'block', findings: det, timings };
  t0 = Date.now();
  const findings = await aiReview(pr).catch(() => null);
  timings.ai = Date.now() - t0;
  if (findings === null)
    return { verdict: 'comment', findings: ['AI 评审不可用，已降级人工'], timings };
  const high = findings.filter(f => f.severity === 'high');
  return { verdict: high.length ? 'block' : 'comment',
           findings: high.length ? high : findings, timings };
}

```

**评分点**：
- 阶段短路：静态失败不跑 AI（省钱且标准清晰）。
- verdict 三态（pass/block/comment）。
- timings 每阶段耗时（可观测）。
- 异常阶段（AI 调用失败）降级为 comment 而非 block（可用性优先）。
