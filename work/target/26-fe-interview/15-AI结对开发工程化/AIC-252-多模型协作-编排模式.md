## AIC-252：多模型协作有哪些典型编排模式（流水线/辩论/分工/评审）？各适合什么任务？
**答**：
- 流水线：分析→实现→测试→评审按序接力，适合明确的多阶段任务。
- 辩论式：两模型互评对方方案再收敛，适合高风险设计决策。
- 分工式：按模块/层拆分并行，适合大规模机械迁移，需统一接口约定。
- 评审式：生成者与评审者角色分离（可同模型不同提示），适合一切产出——角色分离能显著提高质量。

```javascript
// 辩论式收敛
let [a, b] = await Promise.all([draft('modelA'), draft('modelB')]);
for (let i = 0; i < 2; i++) {           // 最多两轮，防无限互撕
  a = await critique('modelA', b, a);   // 吸收对方优点修改
  b = await critique('modelB', a, b);
}
return await judge(a, b);               // 人类或强模型裁决
```
