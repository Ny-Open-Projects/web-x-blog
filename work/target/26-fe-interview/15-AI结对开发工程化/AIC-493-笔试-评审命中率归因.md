## AIC-493：笔试：评审意见命中真实缺陷的归因统计。
**题目**：意见 `[{category, hit: boolean}]`（hit=后续被证实为真缺陷）。输出每类命中率与「最高性价比类别」（命中率 × 出现次数最高）。

```javascript
function hitAttribution(reviews) {
  const by = new Map();
  for (const r of reviews) {
    const s = by.get(r.category) ?? { n: 0, hit: 0 };
    s.n++; s.hit += r.hit ? 1 : 0;
    by.set(r.category, s);
  }
  return [...by].map(([cat, s]) => ({ cat, n: s.n,
    hitRate: +(s.hit / s.n).toFixed(2),
    value: +(s.hit / s.n * s.n).toFixed(1),
    lowConfidence: s.n < 5 }))
    .sort((a, b) => b.value - a.value);
}
console.log(hitAttribution([
  ...Array(10).fill({ category: 'null-check', hit: true }),
  ...Array(10).fill({ category: 'style', hit: false }),
])); // null-check 性价比 10 第一；style 0

```

**评分点**：
- 分类聚合双指标（出现数/命中数）。
- 性价比 = hitRate × count（引导优先保留高价值评审维度）。
- 样本小的类别标注 low-confidence。
- 排序输出性价比降序。
