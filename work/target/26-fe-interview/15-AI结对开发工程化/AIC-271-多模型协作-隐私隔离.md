## AIC-271：多模型路由下如何保证「敏感数据永远不流向云端模型」？
**答**：
- 数据分级前置：任务提交时打敏感级标签，路由器按标签过滤可选模型（L4 → 仅本地）。
- 内容级兜底：即使任务未标注，出站内容过敏感扫描（密钥/PII/内部域名），命中即强制本地模型。
- 架构性隔离：云端模型请求走独立出口网关，网关上做最终拦截——双保险不在同一层。
- 审计追溯：所有路由决策留痕（为什么走云端/本地），合规审计可回放。

```javascript
function routeWithPrivacy(task: Task) {
  const tier = task.sensitivity ?? classify(task.content);
  if (tier === 'L4' || outboundScan(task.content).hit) return 'local-only';
  return normalRoute(task);                    // 云端走独立出口网关二次拦截
}
```
