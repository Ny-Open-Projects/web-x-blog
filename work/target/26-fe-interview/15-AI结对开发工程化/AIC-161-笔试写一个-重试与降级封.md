## AIC-161：笔试：实现一个 LLM 调用的重试与降级封装：指数退避、可重试错误分类、超时与超限降级？
**需求**：实现 `callWithRetry(fn, opts)`：
- 可重试错误（429 限流/5xx/超时）指数退避重试（1s, 2s, 4s…带抖动）；不可重试（400 参数错/401 鉴权）直接抛；
- 每次调用有独立超时（用 Promise.race），超时计入可重试；
- 重试耗尽走降级函数 `fallback(input)`，降级结果带 `degraded: true` 标记；
- 全过程 emit 事件（attempt/fallback）供观测（AIC-085）。

```javascript
const RETRYABLE = [429, 500, 502, 503, 504];

function classify(err) {
  if (err.name === 'TimeoutError') return 'retryable';
  const code = err.status ?? err.code;
  return RETRYABLE.includes(code) ? 'retryable' : 'fatal';
}

function withTimeout(promise, ms) {
  return Promise.race([
    promise,
    new Promise((_, rej) => setTimeout(() => {
      const e = new Error(`timeout ${ms}ms`); e.name = 'TimeoutError'; rej(e);
    }, ms)),
  ]);
}

const sleep = (ms) => new Promise(r => setTimeout(r, ms));

async function callWithRetry(fn, input, {
  maxRetries = 3, timeoutMs = 30_000, fallback,
  onEvent = () => {},
} = {}) {
  let lastErr;
  for (let i = 0; i <= maxRetries; i++) {
    try {
      const res = await withTimeout(fn(input), timeoutMs);
      onEvent({ type: 'attempt', n: i, ok: true });
      return { res, degraded: false, attempts: i + 1 };
    } catch (err) {
      lastErr = err;
      onEvent({ type: 'attempt', n: i, ok: false, err: String(err) });
      if (classify(err) === 'fatal') break;           // 不可重试直接跳出
      if (i < maxRetries) {
        const backoff = 1000 * 2 ** i + Math.random() * 500; // 抖动防雪崩
        await sleep(backoff);
      }
    }
  }
  if (!fallback) throw lastErr;
  onEvent({ type: 'fallback', err: String(lastErr) });
  const res = await fallback(input);
  return { res, degraded: true, attempts: maxRetries + 1 };
}

// 测试
let n = 0;
const flaky = async (q) => {
  if (n++ < 2) { const e = new Error('rate'); e.status = 429; throw e; }
  return `answer:${q}`;
};
console.log(await callWithRetry(flaky, 'hi', {
  onEvent: e => console.log(e.type, e.n, e.ok),
  fallback: (q) => `cached:${q}`,
})); // degraded:false, attempts:3
```

**评分点**：
1. 错误分类先行：fatal（400/401）不重试——盲目重试参数错误只会浪费预算；
2. 指数退避 + 随机抖动（防多客户端同步重试雪崩），写死固定间隔是基础失分；
3. 超时用 Promise.race 且超时归类为可重试（TimeoutError 标记）；
4. 降级返回必须带 degraded 标记——调用方要知道结果来路，不能静默吞掉差异；
5. 事件回调贯穿全程（可观测性），及 maxRetries 含义的边界（0 = 不重试）。
