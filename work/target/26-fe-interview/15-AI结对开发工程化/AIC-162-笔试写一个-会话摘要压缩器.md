## AIC-162：笔试：实现一个会话摘要压缩器，把长对话历史压缩为「决策+待办+事实」三段结构？
**需求**：实现 `compressHistory(messages, budgetTokens)`：
- 保留最近 N 轮原文（保证细节），更早的压缩为结构化摘要；
- 压缩器用确定性规则：从 assistant 消息抽「决策句」（含"决定/选择/采用"）、从 user 消息抽「待办」（含"然后/接着/下一步/待办"）、从两者抽「事实」（代码块引用与 API 名）；
- 压缩后总 tokens ≤ budget；超预算则减少保留轮数再压；
- 返回 `{summary, keptRounds, tokens}`。

```javascript
function tokensOf(s) {
  const cjk = (s.match(/[\u4e00-\u9fa5]/g) || []).length;
  return Math.ceil(cjk / 1.5 + (s.length - cjk) / 4);
}
const DECISION_RE = /(决定|选择|采用|定为|confirm)/;
const TODO_RE = /(下一步|然后要|接着|待办|TODO)/;

function compressRound(round) {
  const decisions = [], todos = [], facts = new Set();
  for (const m of round) {
    const lines = m.content.split('\n');
    (m.role === 'assistant' ? DECISION_RE.test(m.content) ? decisions : [] : TODO_RE.test(m.content) ? todos : [])
      .push(...lines.filter(l => DECISION_RE.test(l) || TODO_RE.test(l)));
    for (const code of m.content.matchAll(/```(\w+)?\n([\s\S]*?)```/g)) facts.add(code[1] ?? 'code');
    for (const api of m.content.matchAll(/\b[A-Z][\w$]*(?:\.[\w$]+)+\b/g)) facts.add(api[0]);
  }
  return {
    decisions: [...new Set(decisions)].slice(0, 5),
    todos: [...new Set(todos)].slice(0, 5),
    facts: [...facts].slice(0, 10),
  };
}

function renderSummary(sum) {
  return `## 会话摘要（压缩）
决策：${sum.decisions.join('；') || '无'}
待办：${sum.todos.join('；') || '无'}
涉及代码：${sum.facts.join(', ') || '无'}`;
}

function compressHistory(messages, budgetTokens) {
  const ROUNDS = 2; // 每轮=一对 user/assistant
  let keptRounds = Math.min(ROUNDS, Math.floor(messages.length / 2));
  for (; keptRounds >= 0; keptRounds--) {
    const kept = messages.slice(messages.length - keptRounds * 2);
    const old = messages.slice(0, messages.length - keptRounds * 2);
    const summary = old.length ? renderSummary(compressRound(chunk(old, 2).flat()))
      : '';
    const total = tokensOf(summary) + kept.reduce((s, m) => s + tokensOf(m.content), 0);
    if (total <= budgetTokens) return { summary, kept, keptRounds, tokens: total };
  }
  return { summary: renderSummary(compressRound(messages)), kept: [], keptRounds: 0, tokens: budgetTokens };
}
function chunk(arr, n) { const out = []; for (let i = 0; i < arr.length; i += n) out.push(arr.slice(i, i + n)); return out; }

// 测试
const history = [
  { role: 'user', content: '实现分页，然后要支持跳页' },
  { role: 'assistant', content: '决定采用游标分页。\n```ts\nusePagination()\n```' },
  { role: 'user', content: 'orders 也接入' },
  { role: 'assistant', content: '已完成接入，下一步是删除旧逻辑' },
];
console.log(compressHistory(history, 150));
```

**评分点**：
1. 「保留最近原文 + 压缩早期」的两段策略：全压缩会丢实现细节，全保留会超预算；
2. 压缩结构三段（决策/待办/事实）语义清晰——决策防发散、待办防烂尾、事实防重复探索；
3. 去重与条数上限（防摘要本身膨胀）；
4. 预算不满足时迭代减少保留轮数的收敛逻辑；
5. 追问：确定性规则抽不准时可换成 LLM 摘要（成本换质量），但要保留本实现的「事实抽取」做兜底。
