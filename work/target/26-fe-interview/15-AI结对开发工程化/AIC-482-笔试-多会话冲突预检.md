## AIC-482：笔试：多会话并行前的文件冲突预检。
**题目**：会话任务 `[{session, files}]`。输出冲突矩阵（两两有交集的会话对）；冲突会话建议串行顺序（按文件数多者优先先行，多者改动大先合）。

```javascript
function precheck(sessions) {
  const pairs = [];
  for (let i = 0; i < sessions.length; i++)
    for (let j = i + 1; j < sessions.length; j++) {
      const a = sessions[i], b = sessions[j];
      const inter = a.files.filter(f => b.files.includes(f));
      if (inter.length) pairs.push({ a: a.session, b: b.session, inter });
    }
  const order = [...sessions].sort((x, y) => y.files.length - x.files.length ||
    x.session.localeCompare(y.session)).map(s => s.session);
  return { conflicts: pairs, serialOrder: pairs.length ? order : 'parallel-ok' };
}
console.log(precheck([
  { session: 's1', files: ['a.ts', 'b.ts', 'c.ts'] },
  { session: 's2', files: ['b.ts'] },
])); // conflicts [s1|s2 inter b.ts]；serialOrder [s1, s2]

```

**评分点**：
- 两两求交集（对称去重）。
- 串行建议排序规则明确（文件数降序，同数按 id）。
- 无冲突输出空矩阵且允许并行。
- 输出带交集文件清单（定位冲突点）。
