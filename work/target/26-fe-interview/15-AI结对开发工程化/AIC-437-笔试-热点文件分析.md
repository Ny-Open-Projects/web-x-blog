## AIC-437：笔试：按 git log 统计热点文件（churn 热力图）。
**题目**：输入 commits `[{files: string[]}]`。输出每文件被改次数，取 topN 并计算占比（占总变更人次），占比 > 40% 的前几名标记 hot。

```javascript
function hotspots(commits, topN = 5) {
  const cnt = new Map();
  let total = 0;
  for (const c of commits) for (const f of c.files) { cnt.set(f, (cnt.get(f) || 0) + 1); total++; }
  const ranked = [...cnt].sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0]));
  let acc = 0;
  return ranked.slice(0, topN).map(([file, n]) => {
    acc += n;
    return { file, n, share: +(n / total).toFixed(2), hot: acc / total <= 0.4 };
  });
}
console.log(hotspots([
  { files: ['a.ts', 'b.ts'] }, { files: ['a.ts'] }, { files: ['a.ts', 'c.ts'] },
])); // a.ts n=3 share=0.5 hot

```

**评分点**：
- 计数准确（同 commit 多文件各计 1）。
- topN 截取 + 占比计算（分母 = 总变更次数）。
- hot 阈值判定（累计占比）——用累计占比超 40% 的前缀标记。
- 并列次数排序稳定。
