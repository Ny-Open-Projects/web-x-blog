## AIC-494：笔试：Agent 任务失败的重试策略（带退避与上限）。
**题目**：失败类型：transient（网络/限流）指数退避重试最多 3 次；permanent（校验失败）不重试直接转人工。实现 `retry(task, attempt, errType)` 返回 `{action, delayMs}`。

```javascript
function retry(attempt, errType, { base = 1000, cap = 30_000 } = {}) {
  if (errType === 'permanent') return { action: 'human', delayMs: 0 };
  if (attempt >= 3) return { action: 'human', delayMs: 0 };
  const delay = Math.min(cap, base * 2 ** attempt); // 1s/2s/4s
  return { action: 'retry', delayMs: delay, attempt: attempt + 1 };
}
console.log(retry(0, 'transient'));   // retry 1000ms
console.log(retry(3, 'transient'));   // human（上限）
console.log(retry(0, 'permanent'));   // human

```

**评分点**：
- 分类驱动：transient 重试 permanent 转人工。
- 退避公式 2^n × base（含 jitter 可选说明）。
- 次数上限后也转人工（不无限重试）。
- delayMs 上限 cap（如 30s）。
