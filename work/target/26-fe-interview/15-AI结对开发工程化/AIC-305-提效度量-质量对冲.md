## AIC-305：提效数据很好但缺陷率上升，如何设计「质量对冲看板」防止提效幻觉？
**答**：
- 看板双列布局：提效列（周期/采纳/成本）与质量列（缺陷逃逸/返工/回滚次数），趋势必须同看。
- 定义「健康区间」：提效指标上升且质量指标劣化超阈值（如缺陷率 +20%）时看板标红冻结推广。
- 根因分流：质量下滑是 AI 产出的（按 AI 标记归因）还是流程变更的——用代码溯源标记区分。
- 汇报话术规范：只允许讲「在质量约束下的提效」，禁止剥离质量谈速度。

```javascript
function healthGate(eff: Metrics, qual: Metrics) {
  const qualityDrop = qual.bugEscape / qual.bugEscapeBaseline - 1;
  return { verdict: qualityDrop > 0.2 ? 'red-freeze' : eff.cycleDelta < 0 ? 'green' : 'yellow',
           splitBy: 'ai-authored vs human-authored 缺陷分流' };
}
```
