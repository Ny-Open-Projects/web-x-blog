## AIC-467：笔试：实现评审意见的反馈采集与提示词迭代建议。
**题目**：反馈 `[{rule, rating: 1|2|3}]`（1 差 3 好）。按规则聚合均分；均分 < 1.5 且样本 ≥ 3 的规则输出「重写建议」，> 2.5 输出「保持」，中间「观察」。

```javascript
function feedbackLoop(feedbacks) {
  const by = new Map();
  for (const f of feedbacks) {
    const g = by.get(f.rule) ?? { sum: 0, n: 0 };
    g.sum += f.rating; g.n++;
    by.set(f.rule, g);
  }
  const out = { rewrite: [], keep: [], watch: [] };
  for (const [rule, g] of by) {
    const avg = +(g.sum / g.n).toFixed(2);
    if (g.n < 3) continue;
    if (avg < 1.5) out.rewrite.push({ rule, avg, n: g.n });
    else if (avg > 2.5) out.keep.push({ rule, avg, n: g.n });
    else out.watch.push({ rule, avg, n: g.n });
  }
  return out;
}
console.log(feedbackLoop([
  { rule: 'sec', rating: 1 }, { rule: 'sec', rating: 1 }, { rule: 'sec', rating: 2 },
  { rule: 'perf', rating: 3 }, { rule: 'perf', rating: 3 }, { rule: 'perf', rating: 3 },
])); // sec → rewrite；perf → keep

```

**评分点**：
- 聚合：均分 + 样本数双指标。
- 判定阈值清晰且样本不足（< 3）不判定（avoid 小样本决策）。
- 输出三分类清单。
- 均分保留 2 位。
