## AIC-427：笔试：检测「测试被削弱」的 diff（删断言/加 skip）。
**题目**：输入新旧测试文件内容。输出 `{weakened, details}`：断言数减少、新增 skip（it.skip/test.skip）、期望值放宽（toBe 硬编码变化简化为检查 toBe 行变更）任一命中即 weakened:true。

```javascript
function testGuard(oldCode, newCode) {
  const cnt = s => (s.match(/expect\(/g) || []).length;
  const removedAssert = cnt(oldCode) - cnt(newCode);
  const oldLines = oldCode.split('\n'), newLines = newCode.split('\n');
  const addedSkip = newLines.filter(l => /(it|test)\.skip/.test(l) && !oldLines.includes(l));
  const details = [];
  if (removedAssert > 0) details.push(`断言减少 ${removedAssert} 处`);
  addedSkip.forEach(l => details.push(`新增 skip: ${l.trim()}`));
  return { weakened: details.length > 0, details };
}
console.log(testGuard(
  "it('a', () => { expect(x).toBe(1); expect(y).toBe(2); });",
  "it.skip('a', () => { expect(x).toBe(1); });"));
// weakened: true，details 2 条

```

**评分点**：
- 断言计数用 expect( 正则统计，删除数 = old-new。
- skip 检测 diff 行级别（新增行含 skip）。
- details 列出具体类别与行。
- 无变化返回 weakened:false。
