## AIC-167：笔试：实现一个上下文片段优先级评分器：相关度×新鲜度×关键性的多因子打分与排序？
**需求**：实现 `rankFragments(fragments, query)`：
- 片段：`{id, text, path, updatedAt, kind: 'code'|'doc'|'chat'}`；
- 相关度：query 关键词与片段的词重叠率（分词按非字母数字切分 + 中文单字 bigram 简化）；
- 新鲜度：按 updatedAt 距今天数指数衰减（半衰期 30 天）；
- 关键性：kind 权重 code 1.0 / doc 0.8 / chat 0.5；
- 综合分 = 0.5·相关度 + 0.3·新鲜度 + 0.2·关键性，降序输出。

```javascript
function tokenize(s) {
  const latin = (s.toLowerCase().match(/[a-z_$][\w$]*/g) ?? []);
  const cjkRuns = s.match(/[\u4e00-\u9fa5]+/g) ?? [];
  const bigrams = cjkRuns.flatMap(w => {
    const g = [];
    for (let i = 0; i < w.length - 1; i++) g.push(w.slice(i, i + 2));
    return g;
  });
  return [...new Set([...latin, ...bigrams])];
}
function relScore(query, text) {
  const q = tokenize(query), t = new Set(tokenize(text));
  if (!q.length) return 0;
  let hit = 0; for (const k of q) if (t.has(k)) hit++;
  return hit / q.length;
}
function freshScore(updatedAt, now = Date.now(), halfLifeDays = 30) {
  const days = (now - updatedAt) / 864e5;
  return Math.pow(0.5, days / halfLifeDays);
}
const KIND_W = { code: 1.0, doc: 0.8, chat: 0.5 };

function rankFragments(fragments, query, now = Date.now()) {
  return fragments.map(f => {
    const rel = relScore(query, `${f.path} ${f.text}`);
    const fresh = freshScore(f.updatedAt, now);
    const kind = KIND_W[f.kind] ?? 0.5;
    return { id: f.id, rel: +rel.toFixed(3), fresh: +fresh.toFixed(3), kind,
      score: +(0.5 * rel + 0.3 * fresh + 0.2 * kind).toFixed(3) };
  }).sort((a, b) => b.score - a.score);
}

// 测试
const now = Date.now();
const frags = [
  { id: 'a', path: 'goods/usePagination.ts', kind: 'code', text: '分页 hook cursor 逻辑', updatedAt: now - 3 * 864e5 },
  { id: 'b', path: 'docs/old.md', kind: 'doc', text: '分页 旧方案 分页', updatedAt: now - 120 * 864e5 },
  { id: 'c', path: 'chat/2026-01.log', kind: 'chat', text: '分页 讨论', updatedAt: now - 200 * 864e5 },
];
console.log(rankFragments(frags, '分页 hook'));
// a 最高（相关+新鲜+code）；c 相关度相同但新鲜度/关键性垫底
```

**评分点**：
1. 中文检索必须分词（latin 词 + CJK bigram），直接 includes 匹配是失分点；
2. 新鲜度用指数衰减（半衰期）而非线性——20 天前的知识还有价值，180 天的才是垃圾；
3. 三因子权重显式定义且归一（和为 1），因子可配置化意识；
4. path 参与相关度计算（文件名语义价值高）；
5. 追问：相关度可升级为 embedding 余弦相似度，本实现是其降级兜底。
