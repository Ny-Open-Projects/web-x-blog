## AIC-109：「AI 是结对者还是工具」——两种定位对团队流程的影响有什么不同？
**答**：
- 工具定位：AI 是放大器，一切流程照旧（人写人审），AI 只省打字时间。流程影响小、治理成本低，但收益也封顶。
- 结对者定位：AI 是有产出的协作者——它需要任务卡（输入规范）、它产出需要验收（review 变成对协作者产出的把关）、它需要记忆与规则（onboarding 流程同样适用）。
- 流程差异具体化：工具定位下不需要门禁/审计/成本核算；结对定位下这三样是必需基建（AIC-041/086/087）。
- 务实结论：按任务分级定位——核心业务流程里 AI 是「受监督的结对者」（全套治理），边缘任务里是「工具」（轻治理）。定位跟着风险走，不做哲学争论。
- 追问钩子：这题考察「会不会用治理成本换收益」的权衡思维——全公司一刀切任一极端都是失分答案。

```javascript
// 按任务分级定位 AI（风险驱动）
const positioning = (task) => task.risk === 'high'
  ? { mode: 'pair', needs: ['门禁', '审计', '成本账本'] }   // 受监督结对者
  : { mode: 'tool', needs: ['lint', '人工抽查'] };           // 普通工具
```
