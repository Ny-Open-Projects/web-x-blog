## AIC-358：把高频开发流程沉淀为「Agent 技能」（可复用流程包），设计要点是什么？
**答**：
- 单一职责：一个技能解决一类任务（如「新增数据面板」），不做大而全的万能技能。
- 步骤显式化：技能是步骤清单（每步的输入/动作/验证），而非一段模糊描述。
- 内置验收：技能末尾自带验收步骤（测试/规范检查），失败即停并汇报。
- 版本与效果数据：技能带版本号与使用效果统计（成功率），低效技能被淘汰或重写。

const skill = {
  name: 'add-dashboard-panel',
  steps: ['读数据源 schema', '生成查询层', '生成组件（token-only）',
          '生成测试', '跑门禁（失败即停）'],
  version: 'v3', stats: { successRate: 0.91, n: 45 },
};
