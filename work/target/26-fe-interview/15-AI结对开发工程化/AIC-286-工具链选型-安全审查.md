## AIC-286：引入 AI 编码工具前的安全审查应该查哪些点？
**答**：
- 数据流向：代码/遥测发到哪里、是否用于训练、能否关闭、有无 SOC2/ISO 认证与 DPA 条款。
- 访问控制：SSO 集成、权限粒度（谁能用/谁能看历史）、审计日志完整性。
-  Prompt 注入与数据外泄风险：仓库内恶意文件诱导模型外发数据的能力评估。
- 合规红线映射：公司数据分级制度 → 工具使用范围（如 secret 仓库禁用云端模式）。

const securityChecklist = [
  '代码是否被用于训练（合同层面可否禁止）',

  '仓库内 prompt 注入测试（恶意 README 诱导行为）',
  '数据分级映射：L4 仓库 → 仅本地模型模式',
