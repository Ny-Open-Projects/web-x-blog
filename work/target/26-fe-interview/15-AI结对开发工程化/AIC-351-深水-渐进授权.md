## AIC-351：新 Agent 能力（如自动执行命令）上线如何做渐进授权而非一步放开？
**答**：
- 授权阶梯：建议（人执行）→ 白名单自动执行 → 全自动（高危除外），每级观察 2-4 周。
- 授权数据：每级统计执行成功率/事故数/回滚次数，达标才升下一级。
- 可随时回退：授权级别是配置开关，出事故立即降级，降级事件复盘后才可回升。
- 按命令分级授权：低危命令（读/测试）先行，高危（写/删/网络）最后。

```javascript
const authorizationLadder = [
  { level: 1, mode: 'suggest-only', weeks: 2 },
  { level: 2, mode: 'allowlist-auto', allow: ['vitest', 'tsc'], weeks: 4 },
  { level: 3, mode: 'auto', except: ['delete', 'network', 'deploy'] },
]; // 每级出口判据：0 事故 && 成功率 > 95%
```
