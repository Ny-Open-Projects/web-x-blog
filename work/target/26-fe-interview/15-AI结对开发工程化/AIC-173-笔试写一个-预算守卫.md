## AIC-173：笔试：实现一个任务预算守卫：预估审批、执行中消耗追踪与超限熔断？
**需求**：实现 `BudgetGuard`：
- `start(taskId, estTokens, { hardLimit })`：预估超硬限时要求人工审批（`approve(taskId)` 才放行）；
- `spend(taskId, tokens)`：累计消耗；达到 80% 软限告警；超硬限抛 `BudgetExceeded`（agent 循环捕获后终止，AIC-165）；
- `stop(taskId)` 返回任务账单（预估 vs 实际偏差）；
- 防重复 start（同 taskId 未结束不可重开）。

```javascript
class BudgetExceeded extends Error {
  constructor(taskId, used, limit) {
    super(`任务 ${taskId} 预算超限：${used}/${limit}`);
    this.name = 'BudgetExceeded';
  }
}

class BudgetGuard {
  #tasks = new Map(); // taskId -> {est, used, hard, approved, closed}
  #WARN = 0.8;

  start(taskId, estTokens, { hardLimit, needsApproval = () => estTokens > hardLimit * 0.9 }) {
    if (this.#tasks.has(taskId) && !this.#tasks.get(taskId).closed) {
      throw new Error(`任务 ${taskId} 仍在进行`);
    }
    const t = { est: estTokens, used: 0, hard: hardLimit, approved: !needsApproval(), closed: false };
    this.#tasks.set(taskId, t);
    if (!t.approved) return { allowed: false, reason: '预估接近硬限，需人工审批' };
    return { allowed: true };
  }
  approve(taskId) {
    const t = this.#must(taskId); t.approved = true;
  }
  spend(taskId, tokens) {
    const t = this.#must(taskId);
    if (!t.approved) throw new Error('未审批不可消耗');
    t.used += tokens;
    if (t.used >= t.hard) throw new BudgetExceeded(taskId, t.used, t.hard);
    if (t.used >= t.hard * this.#WARN) console.warn(`[${taskId}] 已用 ${Math.round(t.used / t.hard * 100)}%`);
    return t.used;
  }
  stop(taskId) {
    const t = this.#must(taskId); t.closed = true;
    return { est: t.est, used: t.used, drift: +(t.used / t.est - 1).toFixed(2),
      verdict: t.used > t.est * 1.5 ? '预估严重偏低，检查任务拆分' : 'OK' };
  }
  #must(taskId) {
    const t = this.#tasks.get(taskId);
    if (!t) throw new Error(`未知任务 ${taskId}`);
    return t;
  }
}

// 测试：agent 循环接入守卫
const guard = new BudgetGuard();
const taskId = 'T-1';
console.log(guard.start(taskId, 9000, { hardLimit: 10000 })); // allowed（<90%）
try {
  for (let step = 0; step < 100; step++) guard.spend(taskId, 150);
} catch (e) {
  console.log(e instanceof BudgetExceeded); // true（15×100=15000 > 10000 在中途熔断）
}
console.log(guard.stop(taskId)); // drift > 0.5 → 检查任务拆分
```

**评分点**：
1. 审批闸方向正确：预估接近硬限才需要审批，别把审批点做成每任务必批；
2. 软限 80% 告警 + 硬限抛专用异常（类型化错误供 agent 循环 catch 终止）；
3. 防重复 start 与 stop 账单的预估偏差（drift）分析——预算数据要反哺任务拆分质量；
4. 未审批不可消耗的状态机完整性；
5. 追问：spend 应按 token 计费换算为金额（与 AIC-172 Meter 打通）。
