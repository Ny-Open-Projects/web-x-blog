## AIC-346：同一功能让 AI 出两版实现（保守版/激进版），如何利用双通道产出做决策？
**答**：
- 保守版：沿用既有模式最小改动；激进版：引入更优抽象。两者同时生成。
- 对比维度：代码量/性能/可维护性/风险，AI 出对比表附数据（复杂度/基准结果）。
- 决策规则：除非激进版有可量化的显著优势（性能 +20% 或减少 2 处重复），否则默认保守版——控制架构熵增。
- 双通道产出都保留在分支上，激进版作为未来演进参考。

```javascript
async function dualChannel(spec: Spec) {
  const [safe, bold] = await Promise.all([gen(spec, { mode: 'conservative' }),
                                          gen(spec, { mode: 'bold' })]);
  const cmp = await compare(safe, bold);   // 量化对比
  return { pick: cmp.boldAdvantage >= 0.2 ? 'bold' : 'safe', cmp };
}
```
