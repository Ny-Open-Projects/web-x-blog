## AIC-330：代码改了文档没同步是常态，如何让 AI 承担文档同步职责？
**答**：
- 挂钩点：PR 评审时 AI 检测「代码变更 vs 文档失效」（注释/API 文档/README/ADR）输出同步建议。
- 同步产物分级：注释与 API 文档自动生成提交；README/ADR 给草稿由人定稿。
- 文档可测试化：关键示例代码抽成可执行文档（doc tests），过期即红。
- 责任明确：文档同步进 DoD（完成的定义），AI 是执行者人是责任人。

```javascript
async function docSync(pr: PR) {
  const stale = await findStaleDocs(pr.diff); // 注释/README/ADR 对照
  const autoFix = stale.filter(s => s.kind === 'comment' || s.kind === 'api-doc');
  return { autoPR: await genDocPatch(autoFix), draft: stale.filter(s => s.kind === 'adr') };
}
```
