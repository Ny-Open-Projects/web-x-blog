## AIC-451：笔试：从违规样本自动提炼规则草稿（去重与归纳）。
**题目**：输入样本 `[{desc, pr}]`，实现 `distill(samples)`：按 desc 的关键词（提取中文动词短语）聚类，每类输出 `{topic, count, samplePRs}`（≥2 条才成类），并生成规则草案要点。

```javascript
function distill(samples) {
  const STOP = new Set(['的', '了', '在', '是']);
  const key = d => (d.match(/[\u4e00-\u9fa5A-Za-z]{2,6}/g) || [])
    .filter(w => !STOP.has(w)).slice(0, 2).join('|');
  const groups = new Map();
  for (const s of samples) {
    const k = key(s.desc);
    if (!k) continue;
    const g = groups.get(k) ?? { topic: k, count: 0, samplePRs: new Set() };
    g.count++; g.samplePRs.add(s.pr);
    groups.set(k, g);
  }
  return [...groups.values()]
    .filter(g => g.count >= 2)
    .sort((a, b) => b.count - a.count)
    .map(g => ({ topic: g.topic, count: g.count,
                 prs: [...g.samplePRs],
                 draft: `- 禁止「${g.topic.split('|')[0]}」类写法，参见 PR ${g.prs[0]}` }));
}
console.log(distill([
  { desc: '硬编码颜色导致暗色模式回归', pr: '#101' },
  { desc: '硬编码颜色未走 token', pr: '#102' },
  { desc: '偶发命名不规范', pr: '#103' },
])); // 只输出硬编码颜色类

```

**评分点**：
- 聚类键提取：正则取关键词（禁用词如「的/了」过滤）。
- ≥2 条才成规则（单条样本可能是偶发）——阈值意识。
- PR 编号去重收集，供规则引用证据。
- 输出按 count 降序。
