## AIC-151：笔试：实现一个规则文件解析器，解析 frontmatter、glob 匹配与规则优先级合并？
**需求**：实现 `resolveRules(ruleFiles, filePath)`：
- 规则文件形如 `{name, globs: ['packages/goods/**'], priority: 2, alwaysApply: false, content}`；
- 找出匹配 filePath 的规则 + alwaysApply 的全局规则；
- 按 priority 升序合并 content（低优先级在前，高优先级可覆盖——同 key 约定以 `禁止` 开头的条目高优先级为准）；
- 无匹配时返回全局规则；输出合并后的最终规则文本。

```javascript
// 极简 glob → 正则（** 跨段、* 单段）
function globToRe(glob) {
  const esc = glob.replace(/[.+^${}()|[\]\\]/g, '\\$&')
    .replace(/\*\*\//g, '(?:.+/)?').replace(/\*\*/g, '.*')
    .replace(/\*/g, '[^/]+');
  return new RegExp(`^${esc}$`);
}

function resolveRules(ruleFiles, filePath) {
  const matched = ruleFiles.filter(r =>
    r.alwaysApply || r.globs?.some(g => globToRe(g).test(filePath)));

  // priority 升序拼接；「禁止」条目在高优先级重复时去重保留高优版本
  const sorted = [...matched].sort((a, b) => a.priority - b.priority);
  const lines = [];
  const seenForbid = new Set();
  for (const r of sorted) {
    for (const line of r.content.split('\n')) {
      if (/^禁止/.test(line.trim())) {
        if (seenForbid.has(line.trim())) continue; // 高优先级已出现（后写入覆盖）
        seenForbid.add(line.trim());
      }
      lines.push(line);
    }
  }
  return {
    rules: sorted.map(r => r.name),
    merged: sorted.map(r => `<!-- ${r.name} -->\n${r.content}`).join('\n') + '\n' +
      lines.filter(l => /^禁止/.test(l.trim())).join('\n'),
  };
}

// 测试
const rules = [
  { name: 'global', globs: null, alwaysApply: true, priority: 0, content: '使用 pnpm\n禁止使用 any' },
  { name: 'goods', globs: ['packages/goods/**'], priority: 1, content: '商品域禁止直接 fetch' },
  { name: 'core', globs: ['packages/goods/core/**'], priority: 2, content: '禁止使用 any\n核心域需双人评审' },
];
console.log(resolveRules(rules, 'packages/goods/core/cart.ts').rules);
// ['global', 'goods', 'core']
console.log(resolveRules(rules, 'apps/admin/page.tsx').rules); // ['global']
```

**评分点**：
1. glob 转正则的 `**` 语义（跨段 vs 单段 `*`）必须区分，混淆是最常见错误；
2. alwaysApply 与 glob 匹配的并集逻辑，不是替换关系；
3. priority 升序拼接保证高优规则「后出现」——模型对尾部内容更敏感（可说明设计意图）；
4. 「禁止」类红线去重合并的冲突处理策略；
5. 返回值带上命中的规则名清单（可解释性，便于审计哪条规则生效）。
