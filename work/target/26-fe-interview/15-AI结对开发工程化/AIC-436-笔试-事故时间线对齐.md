## AIC-436：笔试：把日志/告警/commits 对齐成统一时间线。
**题目**：三类事件 `{ts, source, text}`。输出按 ts 排序的时间线；相邻同类事件（间隔 < 60s）合并为一条（text 拼接，保留首 ts）。

```javascript
function timeline(events, { mergeMs = 60_000 } = {}) {
  const sorted = [...events].sort((a, b) => a.ts - b.ts);
  const out = [];
  for (const e of sorted) {
    const last = out[out.length - 1];
    if (last && last.source === e.source && e.ts - last.ts < mergeMs) {
      last.text += `；${e.text}`;
    } else out.push({ ...e });
  }
  return out;
}
console.log(timeline([
  { ts: 100, source: 'log', text: 'err1' },
  { ts: 120, source: 'log', text: 'err2' },
  { ts: 200, source: 'alert', text: 'P1 告警' },
])); // log 合并为一条 ts=100

```

**评分点**：
- 排序稳定 + 合并只对相邻同类（不是全局同类）。
- 合并保留首个 ts（因果顺序不乱）。
- 间隔阈值可配置。
- 空输入返回空数组。
