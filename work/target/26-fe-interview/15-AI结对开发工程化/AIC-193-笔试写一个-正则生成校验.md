## AIC-193：笔试：实现一个 AI 生成正则的校验器：语法编译、样例双向验证（正例全过/反例全拒）与灾难回溯检测？
**需求**：实现 `verifyRegex(pattern, positives, negatives)`：
- 编译失败返回语法错误；正例必须全部 match、反例必须全部不 match（双向验证）；
- 灾难回溯检测：检测嵌套量词（如 `(a+)+`、`(.*)*`）与重叠分支，静态报警告；
- 锚定检查：用于全文校验的场景（如手机号）未加 ^$ 时警告「可能子串匹配」；
- 输出 `{ok, syntaxError, failures, warnings}`。

```javascript
function verifyRegex(pattern, positives = [], negatives = []) {
  let re;
  try { re = new RegExp(pattern); }
  catch (e) { return { ok: false, syntaxError: e.message, failures: [], warnings: [] }; }

  const failures = [];
  for (const s of positives) if (!re.test(s)) failures.push({ kind: 'should-match', s });
  for (const s of negatives) if (re.test(s)) failures.push({ kind: 'should-not-match', s });

  const warnings = [];
  // 灾难回溯：嵌套量词
  if (/\((?:[^()]+)[+*][^()]*\)[+*]/.test(pattern)) {
    warnings.push('嵌套量词存在灾难性回溯风险（ReDoS），建议改写或加长度限制');
  }
  if (/(\.\*|\.\+)[+*]\??/.test(pattern)) warnings.push('`.x*` 类双重贪婪');
  // 锚定检查
  if (!/[\^]/.test(pattern) && positives.length) {
    warnings.push('未锚定开头（^）：可能发生子串误匹配，全串校验场景建议 ^...$');
  }

  return { ok: !failures.length && !warnings.length, syntaxError: null,
    failures, warnings,
    advice: failures.some(f => f.kind === 'should-not-match')
      ? '反例被匹配：检查字符类边界与量词贪婪度' : '' };
}

// 测试
const r1 = verifyRegex(/^1[3-9]\d{9}$/.source, ['13812345678'], ['12812345678', '1381234567']);
console.log(r1.ok); // true
const r2 = verifyRegex('(a+)+b', ['aaaaaaaaaaaaaaaaaaaaaaaaaab'], ['x']);
console.log(r2.warnings.length > 0); // ReDoS 嵌套量词警告
const r3 = verifyRegex('1[3-9]\\d{9}', ['13812345678'], ['abc13812345678xyz']);
console.log(r3.failures.length > 0); // 未锚定 → 反例子串命中
```

**评分点**：
1. 双向验证（正例过 + 反例拒）缺一不可——只测正例的正则校验是半成品；
2. ReDoS 静态检测（嵌套量词模式）体现安全意识；能提「线性时间引擎/长度限制」加分；
3. 锚定警告针对「全串校验」语义——AI 生成的正则经常漏 ^$；
4. failures 给出分类（should-match/should-not-match）与修复建议方向；
5. 语法错误信息原样透传（可直接回喂 AI 修复，闭环）。
