## AIC-337：线上出了 bug 但测试全绿，如何让 AI 分析「为什么测试没抓住」？
**答**：
- 三类缺口分析：场景缺失（没写这个用例）/断言不足（写了但没断言该行为）/环境差异（测试环境不复现）。
- AI 对比「bug 触发条件 vs 既有用例覆盖范围」，输出缺口定位与补救用例。
- 补救用例进回归集并回填到「同类组件的测试生成提示词」——举一反三。
- 统计缺口类型分布，指导测试策略调整（如环境差异类缺口 → 补 E2E）。

```javascript
async function whyMissed(bug: Bug, suite: Tests) {
  const gap = await classify(bug, suite);
  // { kind: 'scenario-missing' | 'weak-assertion' | 'env-diff', patch: regressionCase }
  const fix = await genRegressionCase(gap);
  await addToPromptLibrary(gap.kind, fix);  // 同类组件提示词升级
  return fix;
}
```
