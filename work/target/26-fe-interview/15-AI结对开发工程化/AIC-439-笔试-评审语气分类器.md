## AIC-439：笔试：实现评审意见的语气校验（对事不对人）。
**题目**：禁用模式：指责人称（你怎么/你总是/又）、绝对化（永远/从来不）。命中即改写建议：去掉人称改描述式。实现 `toneCheck(messages)` 输出 `{msg, rewritten, flagged}`。

```javascript
const BAD = /你(怎么|总是|又)|永远|从来不|never|always\s+you/i;
function toneCheck(messages) {
  return messages.map(m => {
    if (!BAD.test(m)) return { msg: m, rewritten: m, flagged: false };
    return { msg: m,
      rewritten: m.replace(/你(怎么|总是|又)/g, '此处').replace(/永远|从来不/g, '当前'),
      flagged: true };
  });
}
console.log(toneCheck(['你怎么又没判空', '这里可能 NPE，建议 tryParse'])[0]);
// flagged true，rewritten: 此处又没判空（提示人工复核）

```

**评分点**：
- 禁用模式正则覆盖中英文常见指责式。
- 改写策略：删除人称片段保留问题描述（机械改写 + 提示人工复核）。
- flagged 标记便于统计语气违规率。
- 干净意见原样返回。
