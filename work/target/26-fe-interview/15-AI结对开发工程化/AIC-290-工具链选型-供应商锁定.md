## AIC-290：如何降低对单一 AI 工具/模型的锁定风险？
**答**：
- 资产标准化：规则/技能/评测集全部用开放格式（纯 markdown/JSON），不依赖私有特性。
- 抽象层：任务提交、上下文组装、结果校验走自建中间层，工具只做末端执行。
- 双供应商策略：主备模型定期互测，保证备胎随时可用。
- 锁定成本盘点：季度检查哪些能力已依赖私有特性（如 Cursor 的 rules 语义匹配），评估替代成本。

```javascript
const lockStrategy = {
  assets: 'rules/skills/evals 均为开放格式 + 迁移脚本',
  abstraction: '任务网关：统一 prompt 组装 → 可切换执行器（cursor cli / claude code / api）',
  dualVendor: '主备模型季度互测 passRate 差 < 10%',
};
```
