## AIC-453：笔试：实现 Agent 命令执行白名单校验器。
**题目**：三级分类：auto（白名单精确匹配命令首 token）、confirm（写操作前缀）、deny（高危模式）。输入命令字符串，返回 `{action, reason}`；deny 优先级最高。

```javascript
const DENY = [/rm\s+-rf/, /curl[^|]*\|\s*(ba)?sh/, /sudo\b/, /git\s+push\s+--force/];
const AUTO = new Set(['ls', 'cat', 'vitest', 'tsc', 'node', 'npm test']);
const CONFIRM = ['git commit', 'npm install'];
function checkCmd(cmd) {
  for (const p of DENY) if (p.test(cmd)) return { action: 'deny', reason: '高危模式' };
  const parts = cmd.split('|').map(s => s.trim());  // 管道每段都查
  for (const seg of parts) {
    const head = seg.split(/\s+/)[0];
    if (!AUTO.has(head)) {
      const hitC = CONFIRM.find(c => seg.startsWith(c));
      return { action: hitC ? 'confirm' : 'confirm', reason: hitC ? '写操作' : `未知命令 ${head}` };
    }
  }
  return { action: 'auto', reason: '白名单' };
}
console.log(checkCmd('vitest run'));            // auto
console.log(checkCmd('rm -rf /tmp/x'));         // deny
console.log(checkCmd('ls | sh'));               // deny? sh 未知 → confirm（说明：sh 未入白名单）
console.log(checkCmd('git commit -m x'));       // confirm

```

**评分点**：
- deny 用正则模式（rm -rf/curl|sh/sudo），先于白名单判断。
- 白名单匹配按首个 token（如 vitest/tsc），参数不影响分类。
- 命令解析要处理多空格/管道（管道右侧命令也需校验——亮点）。
- 未知命令默认 confirm（安全默认值）。
