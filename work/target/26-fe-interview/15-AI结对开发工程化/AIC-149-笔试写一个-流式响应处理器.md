## AIC-149：笔试：实现一个 LLM 流式响应处理器，解析 SSE 数据块、支持中断与增量提取代码块？
**需求**：实现 `streamHandler()` 返回处理器：
1. `push(chunk)` 接收 SSE 原始文本（可能一次含多个 `data:` 行、跨块拆行）；`data: [DONE]` 结束；
2. `onDelta(text)` 回调增量文本；`onDone(full)` 完成回调；
3. `abort()` 中断：立即停止并返回已接收内容；
4. 增量提取围栏代码块：流式过程中实时报告「当前是否在代码块内」，便于 UI 高亮。

```javascript
function streamHandler({ onDelta, onDone }) {
  let buf = '', full = '', aborted = false;
  function processLine(line) {
    if (!line.startsWith('data:')) return;
    const payload = line.slice(5).trim();
    if (payload === '[DONE]') { onDone(full); return 'DONE'; }
    try {
      const json = JSON.parse(payload);
      const delta = json.choices?.[0]?.delta?.content ?? '';
      if (delta) { full += delta; onDelta(delta, inCodeBlock(full)); }
    } catch { /* 部分行：忽略，等下一块拼全 */ }
  }
  function inCodeBlock(text) {
    const fences = text.match(/```/g);
    return fences ? fences.length % 2 === 1 : false; // 奇数个围栏 → 在块内
  }
  return {
    push(chunk) {
      if (aborted) return;
      buf += chunk;
      const lines = buf.split('\n');
      buf = lines.pop() ?? '';        // 最后一段可能不完整，留到下次
      for (const line of lines) {
        if (processLine(line) === 'DONE') { aborted = true; break; }
      }
    },
    abort() {
      aborted = true;
      return { partial: full, inCode: inCodeBlock(full) };
    },
    get full() { return full; },
  };
}

// 测试
const h = streamHandler({ onDelta: (d, inCode) => console.log(inCode ? '[代码]' : '[文本]', d),
  onDone: f => console.log('完成，共', f.length) });
h.push('data: {"choices":[{"delta":{"content":"以下是"}}]}\n\ndata: {"choices":[{"delta":{"content":"```js\\n"}}]}\n');
h.push('data: {"choices":[{"delta":{"content":"let a=1\\n```"}}]}\n\ndata: [DONE]\n');
// 流程：文本 → 进入代码块 → 完成
```

**评分点**：
1. 跨块残行缓冲（split 后 pop 留 buf）是 SSE 解析核心，漏掉会丢半行 JSON；
2. 一次 chunk 可能含多个 data 行，必须逐行处理而非整块 parse；
3. 中断状态要返回 partial 与代码块状态，供 UI 保留已生成内容；
4. 代码块内判定用围栏计数奇偶，能想到围栏本身可能跨块到达（buf 缓冲覆盖此场景）加分；
5. [DONE] 后停止处理剩余数据（防重复回调）。
