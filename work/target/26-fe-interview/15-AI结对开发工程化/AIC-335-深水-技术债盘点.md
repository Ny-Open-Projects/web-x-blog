## AIC-335：用 AI 做全仓技术债盘点，输出什么样的报告才有行动价值？
**答**：
- 量化分维度：重复代码/圈复杂度/过时依赖/缺测试区域/类型逃逸（any）分布热力图。
- 按「改动概率 × 修复收益」排序：债在热路径上才值得还，冷区债务挂账即可。
- 每项债给修复预估（人日）与分批计划，能直接排进迭代。
- 债的「归因标签」：历史决策/赶工/标准演进——帮助判断该修还是该接受。

```javascript
async function debtAudit(repo: Repo) {
  const hot = await churnHeatmap(repo);           // 改动频率
  const debt = await detectDebt(repo, ['duplication', 'complexity', 'outdated-dep', 'any-escape']);
  return debt.map(d => ({ ...d, priority: d.fixGain * hot[d.area] }))
             .sort((a, b) => b.priority - a.priority).slice(0, 20);
}
```
