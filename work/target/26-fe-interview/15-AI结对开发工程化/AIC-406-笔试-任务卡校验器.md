## AIC-406：笔试：实现 AI 任务卡的校验器，不合格的任务卡打回并给出原因。
**题目**：任务卡 `{goal, ctxFiles, acceptance, constraints, forbidFiles}`，校验：goal ≥ 10 字且含动词；ctxFiles ≥ 1；acceptance 每条必须可执行（含「测试/通过/编译/等于」等判据词）；forbidFiles 与 ctxFiles 不得重叠。返回 `{ok, errors[]}`。

```javascript
const EXEC_WORDS = /测试|test|编译|tsc|等于|toBe|通过|lint/;
function validateTaskCard(card = {}) {
  const errors = [];
  if (!card.goal || card.goal.length < 10 || !/\S+(实现|修复|重构|新增|迁移|优化)/.test(card.goal))
    errors.push('goal：≥10 字且含明确动词（实现/修复/…）');
  if (!Array.isArray(card.ctxFiles) || card.ctxFiles.length < 1)
    errors.push('ctxFiles：至少提供 1 个相关文件');
  (card.acceptance || []).forEach((a, i) => {
    if (!EXEC_WORDS.test(a)) errors.push(`acceptance[${i}] 不可执行：缺判据词`);
  });
  if (!card.acceptance?.length) errors.push('acceptance：不能为空');
  const conflict = (card.forbidFiles || []).filter(f => card.ctxFiles?.includes(f));
  if (conflict.length) errors.push(`forbid 与 ctx 重叠：${conflict}`);
  return { ok: errors.length === 0, errors };
}
console.log(validateTaskCard({
  goal: '实现购物车金额汇总函数',
  ctxFiles: ['src/cart/index.ts'], forbidFiles: ['src/cart/index.ts'],
  acceptance: ['单测通过：空车返回 0', '单测通过：多商品汇总'],
})); // ok:false, errors: forbid 与 ctx 重叠

```

**评分点**：
- acceptance「可执行判据」检测用关键词白名单近似实现，并说明这是启发式。
- ctxFiles 与 forbidFiles 重叠检测（矛盾指令）是亮点考点。
- 错误信息要能指导修改（指出具体哪条不合格），不是笼统「格式错误」。
- 所有字段缺省容错（undefined → 报缺字段而非抛异常）。
