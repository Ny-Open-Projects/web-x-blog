## AIC-329：AI 自动修复安全漏洞（依赖 CVE/代码注入点），如何保证修复不破坏业务？
**答**：
- 依赖类 CVE：AI 做版本兼容性分析（changelog + 测试回归），自动提 PR 并附风险评级。
- 代码级漏洞（XSS/注入）：AI 给出修复 + 利用复现测试（修复前 PoC 能打穿，修复后打不穿）。
- 修复范围最小化：只改安全相关代码，禁止顺手重构（扩大爆炸半径）。
- 双人门禁：安全团队 + 业务 owner 双审批后合入。

```javascript
async function fixXSS(sink: Sink) {
  const poc = await genPoC(sink);          // 修复前必须复现
  const fix = await aiFix(sink, { scope: 'minimal' });
  const retest = await runPoC(fix.patch);  // 修复后必须打不穿
  return retest.blocked ? pr(fix, { reviewers: ['sec-team', 'owner'] }) : reject(fix);
}
```
