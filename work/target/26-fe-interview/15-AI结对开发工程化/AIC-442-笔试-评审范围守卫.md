## AIC-442：笔试：检查 AI 修改是否越界（超出任务声明范围）。
**题目**：任务声明 `allowFiles[]` 与实际改动 `changedFiles[]`。越界文件 = changed - allow；公共文件（如 package.json/锁文件）允许例外（白名单例外清单可配置）。输出 `{violations, allowedExtras}`。

```javascript
function scopeGuard(allowFiles, changedFiles, extras = ['package.json', 'pnpm-lock.yaml']) {
  const allow = new Set(allowFiles);
  const violations = [], allowedExtras = [];
  for (const f of changedFiles) {
    if (allow.has(f)) continue;
    (extras.includes(f) ? allowedExtras : violations).push(f);
  }
  return { violations, allowedExtras };
}
console.log(scopeGuard(['src/a.ts'], ['src/a.ts', 'src/b.ts', 'pnpm-lock.yaml']));
// violations [src/b.ts]；allowedExtras [pnpm-lock.yaml]

```

**评分点**：
- 差集计算 + 例外白名单（构建产物/锁文件不算违规）。
- 违规仍要列出（即使有例外，透明输出）。
- 例外清单可配置（默认 package.json、lock 文件）。
- 空改动返回空。
