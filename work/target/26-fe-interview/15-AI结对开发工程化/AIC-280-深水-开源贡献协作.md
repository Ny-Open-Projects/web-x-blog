## AIC-280：团队向开源项目贡献代码时，AI 工具使用要注意什么？
**答**：
- 上游上下文：给 Agent 注入上游项目的贡献规范（CONTRIBUTING/代码风格），不能套内部规范。
- 许可证清洁：确保 AI 产出不含训练数据污染的整段复制（相似度扫描），避免许可证风险。
- 隐私边界：公开 PR 不能带内部信息（内部链接/域名/密钥），出站前扫描。
- 内部 Fork 策略：复杂贡献先在内部 fork 用 Agent 迭代，达标后再整理成上游 PR。

```javascript
const ossContribution = {
  ctx: '上游 CONTRIBUTING 优先于内部 rules',
  license: 'AI 产出相似度扫描（防训练数据复制）',
  privacy: '出站扫描：内部链接/域名/密钥零出现',
  flow: 'internal fork 迭代 → 整理 → upstream PR',
};
```
