## AIC-266：超长上下文任务（200+ 文件分析），强模型窗口也吃紧，如何分工？
**答**：
- 两阶段：检索模型（便宜长窗）先做全库粗筛输出相关文件清单，强模型只处理清单内内容。
- 多路并行：按模块拆分给多个实例并行分析，汇总阶段用强模型做合并与消歧。
- 摘要链：每模块输出结构化摘要，摘要的摘要给顶层模型——层级压缩保留骨架。
- 关键文件保真：入口文件/契约文件永远全文注入，不参与压缩。

```javascript
async function longCtx(task: Task, files: string[]) {
  const shortlist = await cheapModel('rank relevance', files, { topK: 20 });
  const partials = await Promise.all(group(shortlist, 5).map(g => strongModel(task, g)));
  return strongModel(task, { partials, contracts: fullText(contractFiles) });
}
```
