## AIC-413：笔试：实现测试文件弱断言扫描器并输出变异风险评分。
**题目**：弱断言模式：`toBeDefined/toBeTruthy/not.toThrow()/expect 无参`。评分 = 100 - 弱断言占比×100（向下取整），占比 = 弱断言数 / 总断言数（expect 出现次数）。输出 `{weak, total, score}`，score < 60 建议重写。

```javascript
const WEAK = [/\.toBeDefined\(\)/, /\.toBeTruthy\(\)/, /not\.toThrow\(\)$/, /expect\(\)\./];
function scanAssertions(code) {
  const lines = code.split('\n');
  let total = 0, weak = 0; const hits = [];
  lines.forEach((line, i) => {
    total += (line.match(/expect\(/g) || []).length;
    for (const p of WEAK) if (p.test(line)) { weak++; hits.push({ line: i + 1 }); }
  });
  const score = total === 0 ? 0 : Math.floor(100 - (weak / total) * 100);
  return { weak, total, score,
           action: score < 60 ? 'rewrite' : score < 80 ? 'review' : 'ok', hits };
}
console.log(scanAssertions(`
expect(x).toBeDefined();
expect(y.foo).toBe('bar');
expect(fn).not.toThrow();
`)); // weak 2, total 3, score 33 → rewrite

```

**评分点**：
- 弱断言模式清单准确（正则），总数统计用 expect 计数。
- 占比与分数公式明确，除零保护（无断言 → score 0）。
- 逐行输出弱断言位置便于修复。
- 阈值判定输出 action 建议。
