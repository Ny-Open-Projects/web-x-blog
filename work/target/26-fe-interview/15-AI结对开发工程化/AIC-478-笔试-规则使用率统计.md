## AIC-478：笔试：统计每条规则的实际命中率并给裁剪建议。
**题目**：请求日志 `[{rules: string[]}]`（每请求注入的规则）。输出每规则命中率；命中率 < 5% 且请求数 ≥ 100 的规则建议「移出 always 层改 glob/agent」。

```javascript
function ruleUsage(logs, { minSamples = 100 } = {}) {
  const hits = new Map();
  for (const l of logs) for (const r of l.rules) hits.set(r, (hits.get(r) || 0) + 1);
  const total = logs.length;
  return [...hits].map(([rule, n]) => ({ rule, hitRate: +(n / total).toFixed(3) }))
    .sort((a, b) => a.hitRate - b.hitRate)
    .map(x => ({ ...x, suggest: x.hitRate < 0.05 && total >= minSamples
      ? '移出 always，改 glob 或 agent 语义注入' : 'keep' }));
}
console.log(ruleUsage(
  [...Array(100).fill({ rules: ['base'] }), { rules: ['base', 'obscure-rule'] }]
).filter(x => x.rule === 'obscure-rule')[0].suggest); // 命中 1% → 移出建议

```

**评分点**：
- 命中率分母是总请求数。
- 最小样本门槛（≥ 100）防误杀新规则。
- 建议附带替代方案（不是简单删除）。
- 输出排序（命中率升序，最差在前）。
