## AIC-438：笔试：统计旧接口→新接口迁移进度。
**题目**：输入全仓调用点 `[{file, api}]`（api 形如 `old.getUser`）。映射表 `map: {getUser: 'user.get'}`。输出 `{migrated, remaining, progress}`（保留 2 位），remaining 按文件分组列出便于分批。

```javascript
function migrationProgress(calls, map) {
  const remaining = new Map();
  let migrated = 0;
  for (const c of calls) {
    const api = c.api.split('.')[1];
    const isNew = Object.values(map).some(v => c.api === v || c.api.endsWith(v));
    if (isNew) migrated++;
    else {
      if (!remaining.has(c.file)) remaining.set(c.file, []);
      remaining.get(c.file).push(map[api] ? `old.${api}(→${map[api]})` : `old.${api}(unmapped)`);
    }
  }
  return { migrated, remaining: Object.fromEntries(remaining),
           progress: calls.length ? +(migrated / calls.length).toFixed(2) : 1 };
}
console.log(migrationProgress([
  { file: 'a.ts', api: 'user.get' }, { file: 'b.ts', api: 'old.getUser' },
], { getUser: 'user.get' })); // progress 0.5，remaining b.ts

```

**评分点**：
- 映射表命中的为「已迁移」判定依据（调用新 api 名）。
- 未映射的 api 归入 remaining 并标注 unmapped（映射表缺口）。
- progress 除零保护。
- remaining 按 file 分组（可分批派发）。
