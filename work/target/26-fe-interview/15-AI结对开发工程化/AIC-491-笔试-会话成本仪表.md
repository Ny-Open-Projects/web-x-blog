## AIC-491：笔试：单会话成本仪表（实时聚合）。
**题目**：流式返回 `[{usd}]`。实现 `Meter`：`add(usd)` 累计；`pacePer10()` 返回最近 10 次请求的平均成本；超预算 `limit` 后 `add` 返回 false（拒收继续）。

```javascript
class Meter {
  constructor(limit) { this.limit = limit; this.spent = 0; this.win = []; this.attempted = 0; }
  add(usd) {
    this.attempted++;
    if (this.spent >= this.limit) return false;
    this.spent += usd;
    this.win.push(usd);
    if (this.win.length > 10) this.win.shift();
    return true;
  }
  pacePer10() { return this.win.length ? +(this.win.reduce((a, b) => a + b, 0) / this.win.length).toFixed(2) : 0; }
}
const m = new Meter(10);
for (let i = 0; i < 12; i++) m.add(1);
console.log(m.spent, m.attempted, m.pacePer10()); // 10 12 1（后 2 次拒收但计数）

```

**评分点**：
- 滑动窗口（最近 10 次）平均——队列截断实现。
- 超预算拒收但记录 attempted（可观测超支尝试）。
- avg 除零保护。
- 状态暴露（spent/limit/pace）。
