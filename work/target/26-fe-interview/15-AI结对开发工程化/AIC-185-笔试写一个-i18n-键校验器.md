## AIC-185：笔试：实现一个 i18n 键校验器：占位符一致、长度膨胀、术语表强制与孤儿键清理？
**需求**：实现 `validateI18n(base, translations, opts)`：
- base: `{key: 文案}`（源语言），translations: `{lang: {key: 译文}}`；
- 校验每条译文：占位符集合一致（`{{name}}`/`%s`）、长度膨胀系数（默认 3 倍，按语言表差异化）、术语表强制（术语必须按表翻译，出现禁用译法报错）；
- 找孤儿：翻译文件里有、base 里没有的键（建议清理）；
- 输出 `{errors: [{lang, key, reason}], orphans}`。

```javascript
const INFLATE = { en: 1.2, de: 3, ru: 3, ja: 0.8, zh: 1 }; // 相对中文源
const PLACEHOLDER = /\{\{(\w+)\}\}|%[sd]/g;

function placeholders(s) {
  return [...s.matchAll(PLACEHOLDER)].map(m => m[0]).sort().join(',');
}

function validateI18n(base, translations, { glossary = {}, termBan = {} } = {}) {
  const errors = [], orphans = [];
  for (const [lang, dict] of Object.entries(translations)) {
    for (const [key, text] of Object.entries(dict)) {
      if (!(key in base)) { orphans.push({ lang, key }); continue; }
      const src = base[key];
      // 1. 占位符一致
      const pSrc = placeholders(src), pDst = placeholders(text);
      if (pSrc !== pDst) { errors.push({ lang, key, reason: `占位符不一致: ${pSrc} vs ${pDst}` }); continue; }
      // 2. 长度膨胀（按语言）
      const limit = src.length * (INFLATE[lang] ?? 3);
      if (text.length > limit) errors.push({ lang, key, reason: `超长: ${text.length}/${limit}` });
      // 3. 术语强制：glossary[术语] = {de: 'Warenkorb', ...}
      for (const [term, mapping] of Object.entries(glossary)) {
        if (src.includes(term)) {
          const want = mapping[lang];
          if (want && !text.includes(want)) {
            errors.push({ lang, key, reason: `术语 "${term}" 应译为 "${want}"` });
          }
          for (const ban of termBan[term] ?? []) {
            if (text.includes(ban)) errors.push({ lang, key, reason: `禁用译法 "${ban}"` });
          }
        }
      }
    }
  }
  return { errors, orphans };
}

// 测试
const base = { 'cart.title': '购物车（{{count}}件）', 'buy': '购买' };
const translations = {
  en: { 'cart.title': 'Cart ({{count}} items)', 'buy': 'Purchase' },
  de: { 'cart.title': 'Warenkorb ({{count}} Artikel)', 'buy': 'Kaufen', 'old.key': 'deprecated' },
};
console.log(validateI18n(base, translations, {
  glossary: { '购物车': { en: 'Cart', de: 'Warenkorb' } },
  termBan: { '购物车': ['Basket'] },  // 团队统一用 Cart 不用 Basket
}));
// errors: []，orphans: [{lang:'de', key:'old.key'}]
```

**评分点**：
1. 占位符集合比较要先排序再拼接（顺序无关），漏排序会误报；
2. 长度膨胀按语言差异化（de/ru 膨胀大、ja 可能反向收缩）——全局常数是粗糙实现；
3. 术语双向检查：必须包含正确译法 + 禁用译法黑名单；
4. 孤儿键检测方向是「译文有、源没有」，且区分 lang 维度；
5. 追问：校验器可挂 CI，diff 翻译文件才触发（增量校验）。
