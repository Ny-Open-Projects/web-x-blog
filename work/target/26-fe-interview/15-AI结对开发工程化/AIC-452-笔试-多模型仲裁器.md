## AIC-452：笔试：实现双模型结论仲裁器（测量优先）。
**题目**：输入两结论 `[{model, claim, measurable: {metric, expect}}]`。若双方 claim 一致直接通过；不一致且均可测量 → 用基准结果 bench 裁决（与 bench 吻合者胜）；不可测量 → 转人工。输出 `{winner, needsHuman}`。

```javascript
function arbitrate(a, b, bench) {
  if (a.claim === b.claim) return { winner: 'both-agree', needsHuman: false };
  const close = (x, y) => Math.abs(x - y) / Math.max(1, Math.abs(y)) <= 0.05;
  const okA = a.measurable && close(a.measurable.expect, bench.value);
  const okB = b.measurable && close(b.measurable.expect, bench.value);
  if (okA && !okB) return { winner: 'a', needsHuman: false };
  if (okB && !okA) return { winner: 'b', needsHuman: false };
  return { winner: null, needsHuman: true, evidence: { bench, a: a.claim, b: b.claim } };
}
console.log(arbitrate(
  { model: 'A', claim: '快', measurable: { metric: 'ms', expect: 98 } },
  { model: 'B', claim: '慢', measurable: { metric: 'ms', expect: 300 } },
  { value: 100 })); // winner: a

```

**评分点**：
- 一致短路 → 可测量裁决 → 人工三级瀑布。
- 与 bench 比较用数值容差（相对误差 5%）而非严格相等。
- 双方都不吻合 bench → needsHuman（不盲判）。
- 输出保留双方结论供审计。
