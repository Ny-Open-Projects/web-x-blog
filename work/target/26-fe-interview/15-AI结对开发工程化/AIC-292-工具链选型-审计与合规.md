## AIC-292：AI 工具在企业内的审计合规要求有哪些？落成什么制度？
**答**：
- 事前：数据分级使用规范、工具白名单、供应商安全评估报告。
- 事中：使用审计日志（谁在哪个仓库用了什么模式）、敏感仓库的技术性隔离。
- 事后：AI 产出事故的归因报告制度、季度合规抽查。
- 制度落点：使用规范并入信息安全制度、白名单进采购流程、审计接 SIEM。

```javascript
# ai-tool-policy.yaml（制度的技术化表达）
tools:
  cursor: { repos: ['L1-L3'], modes: ['cloud'], audit: true }
  local-llm: { repos: ['L1-L4'], modes: ['self-hosted'] }
forbidden: { cloud-on: ['L4-*'] }
audit: { logs: 'siem', review: 'quarterly', incidentFlow: 'ai-incident.md' }
r
```
