## AIC-456：笔试：实现 Agent 操作审计日志的完整性校验。
**题目**：日志条目 `{seq, ts, action, prevHash, hash}`，hash = 简化 `seq+ts+action+prevHash` 的字符串长度混合（题目给定 mockHash 函数）。校验：seq 连续、prevHash 链接、hash 重算一致，返回首处破坏点。

```javascript
const mockHash = (seq, ts, action, prev) =>
  String(`${seq}:${ts}:${action}:${prev}`.length * 31 + seq);
function verifyAudit(log) {
  for (let i = 0; i < log.length; i++) {
    const e = log[i];
    if (i > 0 && e.seq !== log[i - 1].seq + 1)
      return { ok: false, at: e.seq, reason: 'seq 不连续' };
    if (i > 0 && e.prevHash !== log[i - 1].hash)
      return { ok: false, at: e.seq, reason: 'hash 链断裂' };
    if (e.hash !== mockHash(e.seq, e.ts, e.action, e.prevHash))
      return { ok: false, at: e.seq, reason: 'hash 重算不一致（内容被篡改）' };
  }
  return { ok: true };
}
console.log(verifyAudit([
  { seq: 1, ts: 1, action: 'read', prevHash: '0', hash: mockHash(1, 1, 'read', '0') },
  { seq: 2, ts: 2, action: 'write', prevHash: 'TAMPERED', hash: mockHash(2, 2, 'write', 'TAMPERED') },
])); // ok（链一致）；把 hash 改掉即报篡改

```

**评分点**：
- 链式校验顺序：先 seq 连续再 hash 链，破坏点只报第一个。
- mockHash 用给定函数（重点考察校验逻辑非哈希实现）。
- 空日志视为合法。
- 破坏点带 {seq, reason}。
