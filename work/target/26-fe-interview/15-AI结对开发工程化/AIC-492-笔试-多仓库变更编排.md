## AIC-492：笔试：跨仓变更的顺序编排与验证。
**题目**：变更 `[{repo, dependsOn: repo[]}]`。拓扑排序输出执行顺序；环依赖报错并给出环路径。每步完成需 `publish(repo)` 后下一步才可见（题目 mock 为顺序即可）。

```javascript
function orderChanges(changes) {
  const indeg = new Map(changes.map(c => [c.repo, 0]));
  const adj = new Map();
  for (const c of changes) for (const d of c.dependsOn || []) {
    if (!adj.has(d)) adj.set(d, []);
    adj.get(d).push(c.repo);
    indeg.set(c.repo, (indeg.get(c.repo) || 0) + 1);
  }
  const queue = [...indeg].filter(([, v]) => v === 0).map(([k]) => k);
  const out = [];
  while (queue.length) {
    const cur = queue.shift();
    out.push(cur);
    for (const n of adj.get(cur) || []) {
      indeg.set(n, indeg.get(n) - 1);
      if (indeg.get(n) === 0) queue.push(n);
    }
  }
  if (out.length !== changes.length) {
    const cyc = [...indeg].filter(([, v]) => v > 0).map(([k]) => k);
    throw new Error(`环依赖：${cyc}`);
  }
  return out;
}
console.log(orderChanges([
  { repo: 'protocol', dependsOn: [] },
  { repo: 'bff', dependsOn: ['protocol'] },
  { repo: 'fe', dependsOn: ['bff'] },
])); // [protocol, bff, fe]

```

**评分点**：
- 拓扑排序（Kahn）实现正确。
- 环检测输出环成员（不只报「有环」）。
- 输出带层级（可并行的同层任务归并）。
- 空依赖任务先行。
