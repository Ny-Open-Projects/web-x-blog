## AIC-274：设计一个「模型能力档案」，让任务分派有数据依据而不是拍脑袋。
**答**：
- 档案维度：按任务类型（补全/生成/重构/评审/debug）× 指标（通过率/耗时/成本/返工率）。
- 数据来源：真实使用数据持续回流（每次任务的结果与验收），定期更新档案。
- 分派策略：任务卡指定任务类型 → 查档案选最优模型（可加约束：预算内最快/最便宜）。
- 档案漂移监控：某模型指标连续两周下滑触发复测（模型服务端可能变更）。

```javascript
const profile = {
  dims: ['completion', 'codegen', 'refactor', 'review', 'debug'],
  metrics: ['passRate', 'latency', 'cost', 'reworkRatio'],
  dispatch: (t: Task) => bestModel(profile, t.type, { budget: t.budget }),
  drift: '两周指标连续下滑 → 复测 → 确认服务端变更',
};
```
