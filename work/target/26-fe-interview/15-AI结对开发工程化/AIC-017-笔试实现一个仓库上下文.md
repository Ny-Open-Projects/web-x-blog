## AIC-017：笔试：实现一个「仓库侦察报告」生成器，输入文件树与 package.json 输出技术栈摘要？
**题目**：实现 `reconReport(pkg, files)`：识别框架（react/vue/next/nuxt）、包管理器（lockfile 判断）、测试框架，并输出注入给 AI 的上下文摘要字符串。注意边界：package.json 可能缺字段、文件树是无层级字符串数组。

```typescript
interface Pkg {
  dependencies?: Record<string, string>;
  devDependencies?: Record<string, string>;
}

function reconReport(pkg: Pkg = {}, files: string[] = []): string {
  const deps = { ...(pkg.dependencies ?? {}), ...(pkg.devDependencies ?? {}) };
  const has = (n: string) => n in deps;
  const detect = (names: string[]) => names.find(has) ?? 'unknown';

  const framework =
    has('next') ? 'next' :
    has('nuxt') ? 'nuxt' :
    has('react') ? 'react' :
    has('vue') ? 'vue' : 'unknown';
  const pm = files.find(f => f.endsWith('pnpm-lock.yaml')) ? 'pnpm'
    : files.find(f => f.endsWith('yarn.lock')) ? 'yarn'
    : files.find(f => f.endsWith('package-lock.json')) ? 'npm' : 'unknown';
  const test = detect(['vitest', 'jest']);

  return [
    `framework: ${framework}`,
    `packageManager: ${pm}`,
    `testRunner: ${test}`,
    `entries: ${files.filter(f => /^(src\/)?(main|index|app)\.(ts|tsx|js|vue)$/.test(f)).join(', ') || 'unknown'}`,
  ].join('\n');
}

console.log(reconReport(
  { dependencies: { react: '^18', next: '^14' } },
  ['pnpm-lock.yaml', 'src/app/page.tsx', 'src/main.tsx', 'README.md']
));
// framework: next / packageManager: pnpm / testRunner: unknown / entries: src/main.tsx
```
**评分点**：
- 框架判定优先级正确：next/nuxt 这类元框架先于 react/vue 判断。
- lockfile 判包管理器要覆盖三种且互斥（find 短路即可）。
- 空入参不抛错（默认 `{}`/`[]` 或可选链），体现 fail-safe。
- 输出为结构化文本（每行 key: value），能说出「这就是给 LLM 的最小充分上下文」的意识。
