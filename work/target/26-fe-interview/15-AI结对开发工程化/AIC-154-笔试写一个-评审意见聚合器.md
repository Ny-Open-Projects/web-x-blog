## AIC-154：笔试：实现一个 AI 评审意见聚合器，去重相似意见、按风险排序、限制输出条数？
**需求**：实现 `aggregateFindings(findings, { max = 10, minConfidence = 0.7 })`：
- 过滤低置信度；同文件相邻行（±3）且 msg 相似的意见合并（保留置信度最高的一条，附 `alsoAt` 列表）；
- 相似判定：msg 归一化（去空白/大小写/标点）后 Jaccard ≥ 0.6；
- 排序：blocker > suggestion > nit，同级按 confidence 降序；截断到 max 条并返回被丢弃数。

```javascript
function normalize(s) {
  return s.toLowerCase().replace(/[\s\p{P}]+/gu, '');
}
function jaccard(a, b) {
  const A = new Set(normalize(a)), B = new Set(normalize(b));
  let inter = 0;
  for (const x of A) if (B.has(x)) inter++;
  return inter / (A.size + B.size - inter || 1);
}
const LEVEL_W = { blocker: 3, suggestion: 2, nit: 1 };

function aggregateFindings(findings, { max = 10, minConfidence = 0.7 } = {}) {
  const passed = findings.filter(f => f.confidence >= minConfidence)
    .sort((a, b) => LEVEL_W[b.level] - LEVEL_W[a.level] || b.confidence - a.confidence);
  const merged = [];
  for (const f of passed) {
    const dup = merged.find(m =>
      m.file === f.file && Math.abs(m.line - f.line) <= 3 && jaccard(m.msg, f.msg) >= 0.6);
    if (dup) {
      if (f.confidence > dup.confidence) Object.assign(dup, f, { alsoAt: dup.alsoAt });
      dup.alsoAt = [...(dup.alsoAt ?? []), f.line];
      continue;
    }
    merged.push({ ...f, alsoAt: [] });
  }
  const kept = merged.slice(0, max);
  return { findings: kept, dropped: merged.length - kept.length };
}

// 测试
const fs = [
  { file: 'a.ts', line: 10, level: 'blocker', msg: '可能存在空指针引用', confidence: 0.9 },
  { file: 'a.ts', line: 12, level: 'nit', msg: '可能存在空指针引用！', confidence: 0.6 },  // 低置信丢弃
  { file: 'a.ts', line: 11, level: 'blocker', msg: '可能存在空指针引用', confidence: 0.95 }, // 合并进 10 行那条
  { file: 'a.ts', line: 50, level: 'nit', msg: '建议添加注释', confidence: 0.8 },
];
console.log(aggregateFindings(fs));
// 2 条：line10(alsoAt:[11], conf 0.95)、line50
```

**评分点**：
1. 合并条件的三要素（同文件+行邻近+消息相似）缺一不可，只按 msg 去重会跨文件误合；
2. 合并时保留置信度更高的一条——信息合并策略影响采纳率统计；
3. alsoAt 保留重复位置，不能丢信息只减条数；
4. 排序权重 blocker 优先于 confidence（先看严重的再看确定的）；
5. dropped 计数返回，供「意见总量」度量。
