## AIC-499：笔试：事故后全仓扫描同类风险模式。
**题目**：事故模式 `[{pattern, desc}]`（正则）。扫描文件列表输出命中 `{file, line, pattern}`；同类命中 ≥ 3 的模式标 systemic:true 置顶。

```javascript
function sweep(files, patterns) {
  const hits = [];
  for (const [path, content] of Object.entries(files)) {
    const lines = content.split('\n');
    for (const p of patterns) {
      lines.forEach((l, i) => {
        if (p.pattern.test(l) && !hits.some(h => h.file === path && h.pattern === p.desc && h.line === i + 1))
          hits.push({ file: path, line: i + 1, pattern: p.desc });
      });
    }
  }
  const count = new Map();
  for (const h of hits) count.set(h.pattern, (count.get(h.pattern) || 0) + 1);
  return hits.sort((a, b) => (count.get(b.pattern) || 0) - (count.get(a.pattern) || 0))
    .map(h => ({ ...h, systemic: (count.get(h.pattern) || 0) >= 3 }));
}
console.log(sweep({ 'a.ts': 'fetch(x)\nfetch(y)' },
  [{ pattern: /fetch\(/, desc: '直接 fetch' }]));
// systemic:false（仅 2 处）；第 3 处起 true 置顶

```

**评分点**：
- 多模式 × 多文件扫描，逐行匹配。
- systemic 判定（同模式 ≥ 3 处命中）与置顶排序。
- 命中限制每文件每模式 1 条（防刷屏）。
- 输出带 pattern 描述（可读性）。
