## AIC-444：笔试：把原始事件流转为提效看板指标。
**题目**：事件 `[{type, ts, pr}]`（opened/merged/reverted）。计算：PR 周期 = merged - opened（中位数）、回滚率 = reverted/merged、吞吐 = merged 数。输入按 pr 分组后再算。

```javascript
function boardMetrics(events) {
  const by = new Map();
  for (const e of events) {
    const p = by.get(e.pr) ?? {};
    if (p[e.type] === undefined) p[e.type] = e.ts;
    by.set(e.pr, p);
  }
  const cycles = [...by.values()].filter(p => p.merged !== undefined && p.opened !== undefined)
    .map(p => p.merged - p.opened).sort((a, b) => a - b);
  const med = cycles.length
    ? cycles.length % 2 ? cycles[(cycles.length - 1) / 2]
      : (cycles[cycles.length / 2 - 1] + cycles[cycles.length / 2]) / 2 : 0;
  const merged = [...by.values()].filter(p => p.merged !== undefined).length;
  const reverted = [...by.values()].filter(p => p.reverted !== undefined).length;
  return { cycleMedian: med, throughput: merged,
           revertRate: merged ? +(reverted / merged).toFixed(2) : 0 };
}
console.log(boardMetrics([
  { type: 'opened', ts: 0, pr: 1 }, { type: 'merged', ts: 10, pr: 1 },
  { type: 'opened', ts: 0, pr: 2 }, { type: 'merged', ts: 20, pr: 2 },
  { type: 'reverted', ts: 30, pr: 2 },
])); // cycleMedian 15，revertRate 0.5

```

**评分点**：
- 按 pr 分组建生命周期（opened/merged/reverted 各取首个）。
- 中位数计算（偶数取均值）。
- 回滚率分母是 merged 数。
- 无 merged 时周期与回滚率输出 0/null 处理明确。
