## AIC-483：笔试：从 AI 报告提取「人类评审会」焦点议题。
**题目**：输入发现列表。焦点 = 高危项 + 「有分歧的项」+ 「需业务决策项」（标记字段）。去重后限 5 条，输出带优先理由。

```javascript
function focusTopics(findings) {
  const key = f => `${f.file}:${f.line}`;
  const seen = new Map();
  for (const f of findings) {
    if (f.severity === 'high' || f.disputed || f.needsDecision) {
      const k = key(f);
      if (!seen.has(k)) seen.set(k, { ...f, why: f.needsDecision ? '需业务决策'
        : f.disputed ? '评审分歧' : '高危' });
    }
  }
  const list = [...seen.values()].slice(0, 5);
  return { focus: list, folded: [...seen.values()].length - list.length,
           note: list.length ? '评审会按此清单讨论' : '无焦点，快速过会' };
}
console.log(focusTopics([
  { file: 'a', line: 1, severity: 'low', disputed: true },
  { file: 'b', line: 2, severity: 'high' },
])); // focus 2 条，why 各异

```

**评分点**：
- 三类来源合并去重（按 file+line）。
- 限 5 条（超出的折叠进附录统计）。
- 每条带来源标记（为什么进焦点）。
- 空焦点时输出「无焦点，快速过会」。
