## AIC-325：跨仓库任务（前端仓库 + BFF 仓库 + 协议仓库）如何给 Agent 提供跨库上下文？
**答**：
- 协议先行：把跨仓契约（API schema/类型定义）单独成仓并生成发布包，Agent 只依赖契约不读对方全库。
- 按需检索：Agent 通过 MCP 检索其他仓库的相关定义（如接口签名），而非整库注入。
- 变更编排：跨仓变更拆成有序任务序列（协议→BFF→前端），每步依赖上一步的发布产物。
- 一致性验证：集成级门禁跑「契约测试」验证三仓变更匹配。

```javascript
const crossRepo = {
  ctx: 'contract repo (openapi/types) → 各仓 Agent 只读契约',
  retrieve: 'mcp search: api.user.profile → 返回签名+示例，不注入全库',
  order: ['protocol v2', 'bff adapt', 'fe consume'],  // 序列化任务
  gate: 'pact verification 三方全绿',
};
```
