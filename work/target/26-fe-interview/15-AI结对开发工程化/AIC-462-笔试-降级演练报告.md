## AIC-462：笔试：对比降级演练期与正常期指标，量化 AI 依赖度。
**题目**：输入 `{normal: {cycleMs, defects}, degraded: {cycleMs, defects}}`。AI 依赖度 = (degraded.cycle - normal.cycle) / degraded.cycle（正数越大依赖越深），缺陷变化率单独输出，并给出结论文案（依赖度 > 40% 提示单点风险）。

```javascript
function drillReport(normal, degraded) {
  const n = normal.cycleMs || 0, d = degraded.cycleMs || 0;
  const dependency = d ? Math.max(0, (d - n) / d) : 0;
  const defectDelta = normal.defects ? (degraded.defects - normal.defects) / normal.defects : 0;
  const level = dependency > 0.4 ? 'high' : dependency > 0.2 ? 'mid' : 'low';
  return {
    dependency: +dependency.toFixed(2), defectDelta: +defectDelta.toFixed(2),
    conclusion: `AI 依赖度 ${level}${level === 'high' ? '：存在单点风险，需建设降级预案' : ''}`,
  };
}
console.log(drillReport({ cycleMs: 20, defects: 5 }, { cycleMs: 100, defects: 6 }));
// dependency 0.8 → high

```

**评分点**：
- 依赖度公式方向正确（用 degraded 做分母防除零与放大）。
- 缺陷率变化独立报告（不与速度混谈）。
- 阈值文案分级（>40% 高依赖 / 20-40% 中 / <20% 低）。
- 输入防御：字段缺失按 0 处理并标注。
