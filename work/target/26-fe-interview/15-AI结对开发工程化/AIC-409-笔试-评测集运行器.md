## AIC-409：笔试：实现一个规则评测集运行器，输出通过率与失败明细。
**题目**：评测项 `{id, task, checks: [{kind, arg}]}`，check 支持 `contains`（产出含关键词）、`notMatch`（不含模式）、`test`（跑指定测试文件，简化为随机布尔注入）。输出 `{passRate, failures: [{id, failedChecks}]}`。

```javascript
async function runEvalSet(items, output) {
  const results = await Promise.all(items.map(async item => {
    const failed = [];
    for (const c of item.checks) {
      if (c.kind === 'contains' && !output.includes(c.arg)) failed.push(c);
      if (c.kind === 'notMatch' && c.arg.test(output)) failed.push(c);
      if (c.kind === 'test' && !(await c.arg(output))) failed.push(c);
    }
    return { id: item.id, ok: failed.length === 0, failed };
  }));
  const failures = results.filter(r => !r.ok);
  return { passRate: +( (results.length - failures.length) / results.length).toFixed(2),
           failures };
}
const out = '使用 color.text.primary';
console.log(await runEvalSet([
  { id: 'E1', task: 'x', checks: [{ kind: 'contains', arg: 'color.' }] },
  { id: 'E2', task: 'y', checks: [{ kind: 'notMatch', arg: /#[0-9a-fA-F]{6}/ }] },
  { id: 'E3', task: 'z', checks: [{ kind: 'test', arg: async () => false }] },
], out)); // passRate 0.67, failures: [E3]

```

**评分点**：
- check 逐条执行且失败项全部收集（不只第一个）——便于归因。
- test 类 check 模拟为注入函数，重点考察 runner 结构而非真跑。
- 通过率分母是评测项数（不是 check 数）。
- 并发执行用 Promise.all + 结果顺序保持。
