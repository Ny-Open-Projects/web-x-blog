## AIC-178：笔试：实现一个 AI 行为遥测采集器：事件 schema 校验、批量上报、失败缓冲与丢弃策略？
**需求**：实现 `Telemetry`：
- `track(name, props)`：按事件 schema 校验（必填字段/类型/白名单事件名），非法事件静默丢弃并计数（遥测不能影响主流程）；
- 缓冲池满 `flushSize` 或定时到期即批量上报；上报失败重新入缓冲；
- 缓冲超过上限时丢弃最旧事件（保护内存）并记录丢弃数；
- `stats()` 返回已发送/丢弃/待发。

```javascript
const SCHEMAS = {
  completion_accept: { fields: { taskId: 'string', accepted: 'boolean', latencyMs: 'number' } },
  review_finding: { fields: { prId: 'string', level: 'string', accepted: 'boolean' } },
};
const ALLOWED = Object.keys(SCHEMAS);

class Telemetry {
  #buf = []; #stats = { sent: 0, dropped: 0, invalid: 0, pending: 0 };
  constructor({ flushSize = 10, maxBuf = 100, send }) {
    this.flushSize = flushSize; this.maxBuf = maxBuf; this.send = send;
  }
  track(name, props) {
    if (!ALLOWED.includes(name)) { this.#stats.invalid++; return false; }
    const schema = SCHEMAS[name].fields;
    for (const [k, t] of Object.entries(schema)) {
      const v = props?.[k];
      const ok = t === 'array' ? Array.isArray(v) : typeof v === t;
      if (v === undefined || !ok) { this.#stats.invalid++; return false; }
    }
    this.#buf.push({ name, props, at: Date.now() });
    if (this.#buf.length > this.maxBuf) {       // 保护内存：丢最旧
      this.#buf.shift(); this.#stats.dropped++;
    }
    if (this.#buf.length >= this.flushSize) this.flush();
    return true;
  }
  async flush() {
    const batch = this.#buf.splice(0, this.flushSize);
    try {
      await this.send(batch);
      this.#stats.sent += batch.length;
    } catch {
      this.#buf.unshift(...batch);              // 失败重回缓冲（头部，保序）
      this.#stats.pending = this.#buf.length;
    }
    this.#stats.pending = this.#buf.length;
  }
  stats() { return { ...this.#stats, pending: this.#buf.length }; }
}

// 测试
const sent = [];
const t = new Telemetry({
  flushSize: 2, maxBuf: 5,
  send: async (b) => { if (b.length === 1) throw new Error('net'); sent.push(b); },
});
t.track('completion_accept', { taskId: 'T1', accepted: true, latencyMs: 120 }); // true
console.log(t.track('unknown_event', {}));  // false 白名单拒绝
console.log(t.track('completion_accept', { taskId: 'T2' })); // false 缺字段
t.track('review_finding', { prId: '#1', level: 'blocker', accepted: true }); // 触发 flush
console.log(t.stats());
```

**评分点**：
1. 事件白名单 + schema 校验先行——脏数据进湖后不可修复；
2. 遥测绝不影响主流程：非法事件静默丢弃计数而非抛错；
3. 失败重入缓冲保序（unshift 回头部）与 maxBuf 丢最旧的内存保护；
4. 批量触发条件（数量阈值）与手动 flush 并存；
5. 追问：真正生产还要加采样率（高 QPS 事件按比例采样）与脱敏（AIC-076）。
