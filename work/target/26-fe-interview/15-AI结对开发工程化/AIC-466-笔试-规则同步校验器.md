## AIC-466：笔试：校验「单一事实源 → 双 IDE 产物」是否过期。
**题目**：源文件 `docs/standards/*.md` 与产物 `.cursor/rules/*.mdc`、`.github/instructions/*.instructions.md`。校验：每个源文件存在对应产物且产物 mtime ≥ 源 mtime（输入为 mtime map）。输出过期清单与退出码（CI 用）。

```javascript
function checkSync(sources, artifacts) {
  const stale = [];
  for (const [src, mSrc] of sources) {
    const base = src.replace(/\.md$/, '');
    const need = [`${base}.mdc`, `${base}.instructions.md`];
    for (const p of need) {
      const m = artifacts[p];
      if (!m) stale.push({ src, missing: p });
      else if (m < mSrc) stale.push({ src, outdated: p });
    }
  }
  return { stale, exitCode: stale.length ? 1 : 0 };
}
console.log(checkSync(
  new Map([['docs/standards/style.md', 100]]),
  { 'docs/standards/style.mdc': 50, 'docs/standards/style.instructions.md': 200 }));
// style.mdc 过期 → exitCode 1

```

**评分点**：
- 映射规则：源文件名（去 .md）对应两产物名。
- 过期判定：任一产物缺失或 mtime 早于源即过期。
- exitCode 1（过期）/0（新鲜）——CI 可直接用。
- 输出列出缺失的产物路径（可执行修复）。
