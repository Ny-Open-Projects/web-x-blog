## AIC-440：笔试：统计技能（流程包）使用效果并给淘汰建议。
**题目**：记录 `[{skill, ok}]`。成功率 < 60% 且 n ≥ 10 → 建议 rewrite；60-85% → tune；≥ 85% → keep。输出每技能 `{n, successRate, action}`。

```javascript
function skillStats(records) {
  const by = new Map();
  for (const r of records) {
    const s = by.get(r.skill) ?? { n: 0, ok: 0 };
    s.n++; s.ok += r.ok ? 1 : 0;
    by.set(r.skill, s);
  }
  const out = { rewrite: [], tune: [], keep: [], insufficient: [] };
  for (const [skill, s] of by) {
    const rate = +(s.ok / s.n).toFixed(2);
    if (s.n < 10) out.insufficient.push({ skill, n: s.n });
    else if (rate < 0.6) out.rewrite.push({ skill, rate });
    else if (rate < 0.85) out.tune.push({ skill, rate });
    else out.keep.push({ skill, rate });
  }
  return out;
}
console.log(skillStats([
  ...Array(12).fill({ skill: 'deploy', ok: true }),
  ...Array(12).fill({ skill: 'deploy', ok: false }),
])); // deploy rate 0.5 → rewrite

```

**评分点**：
- 样本门槛（n ≥ 10）不足标 insufficient（不凭 3 次失败杀技能）。
- 三档阈值清晰（60/85）。
- 成功率保留 2 位。
- 输出按 action 分组便于看板。
