## AIC-431：笔试：静态检查数据访问代码是否缺 tenant 过滤。
**题目**：输入查询语句列表。规则：含 `db.query`/`db.find` 且语句未出现 `tenant_id` → 违规。实现 `checkTenant(queries)` 输出违规项（行/语句摘要）；`where` 子句含 tenant_id 视为合规。

```javascript
function checkTenant(queries) {
  return queries.map((q, i) => ({ q, i }))
    .filter(({ q }) => !/--\s*no-tenant/.test(q))
    .filter(({ q }) => /db\.(query|find)/i.test(q) && !/tenant_id/i.test(q))
    .map(({ q, i }) => ({ line: i + 1, excerpt: q.trim().slice(0, 40) }));
}
console.log(checkTenant([
  'db.query("select * from orders where user_id=1")',
  'db.query("select * from orders where tenant_id=9")',
  'db.find("audit_log") // -- no-tenant（全局审计表）',
])); // 只第一条违规

```

**评分点**：
- 关键词检测在整条语句（含 where）范围内。
- 违规输出含语句摘要（截断 40 字）。
- 显式豁免注释（`-- no-tenant`）可跳过——例外机制。
- 大小写不敏感匹配。
