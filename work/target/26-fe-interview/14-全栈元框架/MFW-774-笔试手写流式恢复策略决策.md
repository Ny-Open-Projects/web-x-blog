## MFW-774：笔试：手写流式恢复决策

**答**：实现 `streamRecovery({ errorType, receivedTokens, totalEstimate, contentType })`。errorType: 'timeout'|'rate-limit'|'content-filter'|'network'. 规则：1) content-filter → 'stop'（不可重试——修改 prompt）；2) rate-limit → 'wait-retry'（退避 = retry-after header）；3) timeout → receivedTokens 比例 > 50% → 'continue'（续传）；≤ 50% → 'restart'（重做）；4) network → 'restart'（网络不可靠——重做更安全）；5) contentType 为 'code' → 强制 'restart'（一致性优先——续传可能不一致）；6) 返回 `{ strategy: 'continue'|'restart'|'wait-retry'|'stop', backoffMs?, reason }`。边界：receivedTokens=0（任何错误都 restart）；totalEstimate 缺失（默认 restart——不知比例）；contentType 缺失（默认 text——正常决策树）。

```javascript
function streamRecovery({ errorType, receivedTokens = 0, totalEstimate, contentType = 'text' } = {}) {
  if (errorType === 'content-filter')
    return { strategy: 'stop', reason: '内容审核拒绝——修改 prompt 后重试' };
  if (errorType === 'rate-limit')
    return { strategy: 'wait-retry', backoffMs: 30000, reason: '速率限制——30s 后重试' };
  if (contentType === 'code')
    return { strategy: 'restart', reason: '代码生成——续传可能不一致，重做保证一致性' };
  if (errorType === 'network')
    return { strategy: 'restart', reason: '网络不可靠——重做更安全' };
  if (errorType === 'timeout') {
    const ratio = totalEstimate ? receivedTokens / totalEstimate : null;
    if (ratio !== null && ratio > 0.5)
      return { strategy: 'continue', reason: `已生成 ${Math.round(ratio * 100)}%——续传节省 tokens` };
    return { strategy: 'restart', reason: ratio !== null
      ? `仅 ${Math.round(ratio * 100)}%——重做一致性更好` : '无法估算进度——重做' };
  }
  return { strategy: 'restart', reason: '未知错误——重做兜底' };
}

// 自测
// content-filter：停止
console.log(streamRecovery({ errorType: 'content-filter' }).strategy === 'stop');
// rate-limit：等待
r = streamRecovery({ errorType: 'rate-limit' });
console.log(r.strategy === 'wait-retry' && r.backoffMs === 30000);
// timeout 过半 → 续传
r = streamRecovery({ errorType: 'timeout', receivedTokens: 600, totalEstimate: 1000 });
console.log(r.strategy === 'continue' && r.reason.includes('60%'));
// timeout 不到半 → 重做
r = streamRecovery({ errorType: 'timeout', receivedTokens: 300, totalEstimate: 1000 });
console.log(r.strategy === 'restart' && r.reason.includes('30%'));
// code 强制 restart
r = streamRecovery({ errorType: 'timeout', receivedTokens: 900, totalEstimate: 1000,
  contentType: 'code' });
console.log(r.strategy === 'restart' && r.reason.includes('一致性'));
// network → restart
console.log(streamRecovery({ errorType: 'network' }).strategy === 'restart');
// 零 token → restart
r = streamRecovery({ errorType: 'timeout', receivedTokens: 0, totalEstimate: 1000 });
console.log(r.strategy === 'restart');
// 无 estimate
console.log(streamRecovery({ errorType: 'timeout' }).strategy === 'restart');
```

**评分点**：
- 决策树优先级：content-filter stop > rate-limit wait > code restart > timeout 比例 > network restart
- 续传条件（timeout + >50% + 非 code——比例与内容类型双约束）；backoffMs 传递
- 边界（零 token/无 estimate/contentType 强制）；策略的用户可理解 reason
- 能说清「LLM 流式的恢复策略由内容类型决定：code 强制 restart（一致性），text 可续传（节省 tokens）」属于加分
