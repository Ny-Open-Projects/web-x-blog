## MFW-627：笔试：手写类型逃逸扫描器

**答**：实现 `scanTypeEscapes(code)`。检测四类逃逸：1) 显式 any：`: any` / `as any` / `<any>`；2) 双重断言：`as unknown as`；3) 非空断言链：`!.` 或 `!` 后跟 `.`（连续调用——空值逃逸）；4) 索引签名绕过：`(obj as Record<string, unknown>).x`。按行扫描：返回 `{ escapes: Array<{ line, type, snippet }>, count, density }`（density = escapes/行数——文件级类型健康度）。注释/字符串内的同形文本跳过（简单判断：行 trim 以 // 或 * 开头跳过；字符串内的复杂场景标注局限）。边界：空代码；全注释文件。

```javascript
function scanTypeEscapes(code = '') {
  const escapes = [];
  const lines = code.split('\n');
  let inBlockComment = false;
  lines.forEach((line, i) => {
    const t = line.trim();
    if (inBlockComment) { if (t.includes('*/')) inBlockComment = false; return; }
    if (t.startsWith('//') || t.startsWith('*')) return;
    if (t.startsWith('/*')) { if (!t.includes('*/')) inBlockComment = true; return; }
    const add = (type, snippet) => escapes.push({ line: i + 1, type,
      snippet: t.slice(0, 60) });
    if (/:\s*any\b|\bas\s+any\b|<any>/.test(t)) add('explicit-any');
    if (/as\s+unknown\s+as/.test(t)) add('double-assert');
    if (/!\s*\.\s*\w/.test(t)) add('non-null-chain');
    if (/as\s+Record\s*<\s*string\s*,\s*unknown\s*>/.test(t)) add('index-bypass');
  });
  const density = lines.length ? +(escapes.length / lines.length).toFixed(4) : 0;
  return { escapes, count: escapes.length, density };
}

// 自测
const code = [
  'const a: any = getData();',                           // explicit-any
  'const b = x as unknown as Admin;',                    // double-assert
  'const c = user!.profile!.name;',                      // non-null-chain
  'const d = (obj as Record<string, unknown>).secret;',  // index-bypass
  '// : any 这是注释不算',
  'const ok: User = getData();',
].join('\n');
let r = scanTypeEscapes(code);
console.log(r.count === 4);
console.log(r.escapes.map(e => e.type).sort().join(','));
// double-assert,explicit-any,index-bypass,non-null-chain
console.log(r.escapes.find(e => e.type === 'non-null-chain').line === 3);
console.log(!r.escapes.some(e => e.line === 5));          // 注释跳过

// 块注释
r = scanTypeEscapes('/* const x: any */\nconst y: any = 1;');
console.log(r.count === 1);                              // 块注释内跳过

// 密度
console.log(scanTypeEscapes('const a: any = 1;').density === 1);
console.log(scanTypeEscapes('').count === 0);
```

**评分点**：
- 四类逃逸检测（any/双断言/非空链/索引绕过——推理链的薄弱点全谱）；注释状态机跳过
- density 指标（文件级类型健康度——可比较可排名）；snippet 定位
- 边界（空/全注释）；局限性标注（字符串内不检——诚实）
- 能说清「类型逃逸 = 推理链断点——审计让链的薄弱环节可见，any 是变更传播的天敌」属于加分
