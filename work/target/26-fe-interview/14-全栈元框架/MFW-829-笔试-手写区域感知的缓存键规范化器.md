## MFW-829：笔试：手写区域感知的缓存键规范化器

**答**：
- 结论：按路径语义决定键策略：静态资源全局键、区域数据加 region 前缀、个性化路由返回 null（不进共享缓存）；其余用规范化全局键。
- 关键：查询参数排序 + 去 utm 追踪参数控制键基数；个性化路由识别要准确，避免私有数据污染共享缓存。
- 追问钩子：为什么个性化路由不进共享缓存？——不同用户的私有数据混在公共键里会造成越权泄露。

```javascript
const REGION_SCOPED = new Set(['/api/price', '/api/stock']);
const PERSONAL = new Set(['/account', '/checkout']);
function cacheKey({ path, query = {}, region, hasSession }) {
  if (path.startsWith('/_next/static')) return 'static:' + path;
  if (PERSONAL.has(path)) return hasSession ? null : 'g:' + path; // 私有不共享
  const qs = new URLSearchParams(query);
  for (const k of [...qs.keys()]) if (k.startsWith('utm_')) qs.delete(k);
  const sorted = [...qs.entries()].sort((a, b) => a[0].localeCompare(b[0]))
    .map(([k, v]) => k + '=' + v).join('&');
  const base = path + (sorted ? '?' + sorted : '');
  return REGION_SCOPED.has(path) ? `r:${region}:${base}` : `g:${base}`;
}

// 自测
console.log(cacheKey({ path: '/api/price', query: { id: '1' }, region: 'cn-east' }));
// r:cn-east:/api/price?id=1
console.log(cacheKey({ path: '/account', hasSession: true }));   // null
console.log(cacheKey({ path: '/p', query: { b: '2', utm_source: 'x', a: '1' } }));
// g:/p?a=1&b=2
```

**评分点**：
- 区域数据加 region 前缀隔离，避免跨区缓存污染
- 个性化路由返回 null（不进共享缓存），防止私有数据越权
- 查询参数规范化：排序 + 去 utm 参数，控制键基数
- 静态资源用全局键；边界（hasSession / 路由白名单）处理正确
