## MFW-711：笔试：手写水合优先级调度

**答**：实现 `createHydrationScheduler(boundaries, { maxConcurrent })`。boundaries: `{ id, priority: number, hydrate: () => Promise<void>, interactiveCostMs }[]`。规则：1) 优先级排序（priority 越小越先——1 = 交互区高优先）；2) 用户交互触发：`onInteraction(boundaryId)` → 该边界跳到队首（立即水合——抢占当前）；3) 并发上限（maxConcurrent——同时水合的边界数——CPU 预算）；4) 返回 `{ schedule(), onInteraction(id), stats() }`（stats: hydrated/pending/reordered）。边界：boundaries 空；重复 interaction（已水合的忽略）；maxConcurrent 1（串行）。

```javascript
function createHydrationScheduler(boundaries = [], { maxConcurrent = 2 } = {}) {
  const queue = [...boundaries].sort((a, b) => a.priority - b.priority);
  const hydrated = new Set(); let active = 0; let reordered = 0;
  const pending = new Set(queue.map(b => b.id));
  function pump() {
    while (active < maxConcurrent && queue.length) {
      const next = queue.shift();
      if (hydrated.has(next.id)) continue;
      active++;
      next.hydrate().then(() => {
        active--; hydrated.add(next.id); pending.delete(next.id);
        pump();
      }).catch(() => { active--; pump(); });
    }
  }
  return {
    schedule() { pump(); },
    onInteraction(id) {
      if (hydrated.has(id)) return;
      const idx = queue.findIndex(b => b.id === id);
      if (idx === -1) return;
      const [item] = queue.splice(idx, 1);
      queue.unshift(item);                               // 抢占：跳到队首
      reordered++;
      pump();
    },
    stats: () => ({ hydrated: hydrated.size, pending: pending.size, reordered }),
  };
}

// 自测
const hydratedOrder = [];
const boundaries = [
  { id: 'sidebar', priority: 5, hydrate: async () => { await sleep(20); hydratedOrder.push('sidebar'); } },
  { id: 'main', priority: 2, hydrate: async () => { await sleep(10); hydratedOrder.push('main'); } },
  { id: 'widget', priority: 8, hydrate: async () => { hydratedOrder.push('widget'); } },
];
const sched = createHydrationScheduler(boundaries, { maxConcurrent: 2 });
sched.schedule();
await sleep(5);
sched.onInteraction('sidebar');                          // 用户点击 sidebar → 优先
await sleep(50);
console.log(hydratedOrder.indexOf('sidebar') < hydratedOrder.indexOf('main'));
// sidebar 被抢占优先水合（priority 5 > 2 但交互触发抢占）
console.log(sched.stats().hydrated === 3);

// 重复 interaction 忽略
sched.onInteraction('sidebar');
console.log(sched.stats().reordered === 1);              // 已水合：不再重排

// maxConcurrent=1 串行
const serial = createHydrationScheduler(boundaries, { maxConcurrent: 1 });
serial.schedule();
await sleep(60);
console.log(serial.stats().hydrated === 3);
```

**评分点**：
- 优先级排序 + 交互抢占（onInteraction 跳队首——用户意图驱动 RBL-710）
- 并发上限（CPU 预算——同时水合数限制）；重复 interaction 忽略
- 边界（空/串行/重复）；stats 可观测（reordered 次数——抢占频率）
- 能说清「水合顺序的分离：流序（server 数据调度）≠ 水合序（client 交互驱动）——选择性水合让交互优先于树序」属于加分
