## MFW-285：健康检查与优雅停机

**答**:
- 双探针语义：liveness（进程活着——失败即重启，检查要轻不碰依赖）vs readiness（能接流量——检查 DB/KV 可达 + 初始化完成 MFW-281 标志）；启动期 readiness=false 摘流预热
- 优雅停机五步：SIGTERM → 摘流（readiness=false）→ 等待在途请求完成（超时 30s）→ 关闭连接池 → exit 0——K8s preStop + terminationGracePeriod 配合
- 连接排水细节：长连接（WS/SSE）发 goaway 让客户端重连到其他实例——不等长连接自然结束
- 验证：滚动发布期间零 5xx（错误率曲线平滑）——停机处理不当的表现是发布瞬间错误尖刺

```javascript
process.on('SIGTERM', async () => {
  ready = false                                                  // 摘流
  await drainInflight(30_000)                                    // 在途排水
  wsServer.broadcastGoaway()                                     // 长连接迁移
  await pool.end()
  process.exit(0)
})
// readiness: /healthz → ready && dbPing()
```
