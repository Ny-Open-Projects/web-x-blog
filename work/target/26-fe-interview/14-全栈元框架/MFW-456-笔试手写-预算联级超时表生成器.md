## MFW-456：预算联级超时表
**答**：实现 `deriveTimeouts(tree, { root = 8000 } = {})`（MFW-383 执行器）：1) 树：{ name, cost: 预估自身ms, children: [] }；2) 后序遍历分配：子节点预算 = min(自身默认, 父剩余 × ownShare%)——叶子耗尽不透支兄弟；3) 输出每节点 { budget, leftAfter } 表（deadline 头的数据源）；4) 冲突检测：任意子链必要耗时之和 > 父预算 → 标 impossible（构建期断言——部署前发现预算幻觉）。
