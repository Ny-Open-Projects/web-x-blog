## MFW-754：笔试：手写数据流追踪

**答**：实现 `createDataFlowTracer()`。方法：`traceFetch(component, url, options)`（记录 fetch）、`traceRevalidate(tag, source)`（记录失效）、`getFlow()`（返回数据流图）。规则：1) fetch 记录：`{ component, url, tags, cacheHit, latencyMs }`——cacheHit 从响应头（x-nextjs-cache）或 options 推断；2) revalidate 记录：`{ tag, source, timestamp }`；3) getFlow：返回 `{ fetches, revalidations, slowest: 排序最慢的前 3, cacheHitRate }`——hitRate = hit/total 保留 1 位；4) 关联：revalidate 的 tag → 匹配 fetch 的 tags（哪些 fetch 会被该失效影响——关联分析）。边界：无 fetch（空 flow）；无 revalidate；cacheHit 无响应头（默认 miss）。

```javascript
function createDataFlowTracer() {
  const fetches = []; const revalidations = [];
  return {
    traceFetch(component, url, options = {}, res) {
      const cacheHit = res?.headers?.get('x-nextjs-cache') === 'HIT' ||
        options?.next?.revalidate != null;
      fetches.push({ component, url, tags: options?.next?.tags ?? [],
        cacheHit, latencyMs: res?._latency ?? 0, ts: Date.now() });
    },
    traceRevalidate(tag, source) {
      revalidations.push({ tag, source, ts: Date.now() });
    },
    getFlow() {
      const total = fetches.length;
      const hits = fetches.filter(f => f.cacheHit).length;
      const slowest = [...fetches].sort((a, b) => b.latencyMs - a.latencyMs).slice(0, 3);
      // 关联：revalidate tag → 影响 fetch
      const impacted = revalidations.map(r => ({
        tag: r.tag, source: r.source,
        affectedFetches: fetches.filter(f => f.tags.includes(r.tag)).map(f => f.component),
      }));
      return {
        fetches, revalidations: impacted,
        slowest,
        cacheHitRate: total ? +(hits / total * 100).toFixed(1) : null,
      };
    },
  };
}

// 自测
const tracer = createDataFlowTracer();
tracer.traceFetch('ProductView', '/api/product/1', { next: { tags: ['product:1'] } },
  { headers: { get: () => 'HIT' }, _latency: 5 });
tracer.traceFetch('Reviews', '/api/reviews/1', { next: { tags: ['reviews'] } },
  { headers: { get: () => 'MISS' }, _latency: 800 });
tracer.traceFetch('Header', '/api/nav', {}, { headers: { get: () => 'HIT' }, _latency: 2 });
tracer.traceRevalidate('product:1', 'admin-panel');

const flow = tracer.getFlow();
console.log(flow.fetches.length === 3);
console.log(flow.cacheHitRate === 66.7);                 // 2/3
console.log(flow.slowest[0].component === 'Reviews');    // 800ms 最慢
console.log(flow.slowest[0].latencyMs === 800);
// 关联：revalidate 'product:1' → ProductView 被影响
console.log(flow.revalidations[0].affectedFetches.join(',') === 'ProductView');
console.log(flow.revalidations[0].source === 'admin-panel');

// 空缓存命中率 null
console.log(createDataFlowTracer().getFlow().cacheHitRate === null);
```

**评分点**：
- fetch 记录四要素（component/url/tags/cacheHit）；revalidate 关联分析（tag → 影响的组件）
- cacheHitRate 计算（1 位小数）；slowest 排序（前 3——优化靶点）；空 flow null
- 边界（无 fetch/无 revalidate/无响应头默认 miss）
- 能说清「RSC 数据流的可观测 = 组件级 fetch 追踪 + 缓存层级标注 + 失效关联——数据流的树形分散需要精细观测」属于加分
