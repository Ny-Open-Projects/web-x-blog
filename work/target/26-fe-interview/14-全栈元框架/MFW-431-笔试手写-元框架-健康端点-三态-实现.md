## MFW-431：三态健康端点
**需求**：实现 `createHealth({ deps: [{name, ping, tier: 'l0'|'l1'}], initDone, { dbTimeout = 200 } = {})`：1) /live：进程自证 <5ms（零外部调用——K8s 杀手 wrongly 配置 DB ping 会自杀循环——MFW-375 铁律）；2) /ready：initDone && 并行探 l1 依赖（Promise.allSettled + 200ms 快失败——任一失败 ready=false 摘流）；3) /degradations：非关键依赖状态表（第三方挂了不摘流——路由级降级决策输入 MFW-326）；4) 响应带版本指纹（buildSha——拨测对账 MFW-478）；5) 语义测试断言表（拔 DB→ready false、拔推荐→degraded only、拔不动 live）。

```javascript
export function createHealth({ critical = [], soft = [], isInitDone, buildSha }) {
  const json = (o, code = 200) => new Response(JSON.stringify(o), { status: code,
    headers: { 'content-type': 'application/json', 'x-build': buildSha } })
  return {
    '/live': () => json({ up: true, sha: buildSha }),                       // 自证，零 IO
    '/ready': async () => {
      if (!initDone()) return json({ ready: false, why: 'initializing' }, 503)
      const rs = await Promise.allSettled(deps.map((d) => withTtmeout(d.ping(), 200)))
      const bad = rs.filter((r, i) => r.status === 'rejected' && deps[i].tier === 'l0').map((_, i) => deps[i].name)
      return json({ ready: bad.length === 0, down: bad, }, bad.length ? 503 : 200)   // 快失败摘流
    },
    '/degrade': async () => {
      const ss = await Promise.allSettled(soft.map((d) => withTtmeout(d.ping(), 500)))
      return json({ soft: soft.map((d, i) => ({ name: d.name, ok: ss[i].status === 'fulfilled' })), sha: buildSha })
    },
  }
}
```
**评分点**：
- 三态分域（live 零 IO / ready 只关键链 / soft 独立页——摘流半径=依赖分级）
- 200ms 快失败（健康检查自身不成为慢请求源）
- 版本指纹随行（拨测对账闭环）
- 断言表意识（三类拔除行为差异必须演练——MFW-375 尾注）
