## MFW-667：笔试：手写双包一致性验证器

**答**：实现 `verifyDualBundle(testCases, runners)`。testCases: `{ name, execute: (env) => Promise<any>, normalize? }[]`；runners: `{ modern: (tc) => Promise<any>, legacy: (tc) => Promise<any> }`. 规则：1) 每用例在双环境执行；2) 结果比对（normalize 可选——结果规范化（时间戳等抖动剔除）后 deepEq）；3) 不一致 → diff 记录 `{ case, modern, legacy }`；4) 汇总：一致率 + 不一致清单；5) **结果可比性**：normalize 缺失时原始比较（严格 deepEq——抖动数据会误报，提示 normalize）。返回 `{ cases: Array<{ name, consistent, modern?, legacy? }>, consistentRate, ok }`（ok = 全一致）。边界：testCases 空；runner 抛错（视为不一致——结果 undefined）；normalize 对 undefined。

```javascript
function deepEq(a, b) { return JSON.stringify(a) === JSON.stringify(b); }

async function verifyDualBundle(testCases = [], runners) {
  const cases = []; let consistent = 0;
  for (const tc of testCases) {
    let modern, legacy, modernErr, legacyErr;
    try { modern = await runners.modern(tc); } catch (e) { modernErr = e.message; }
    try { legacy = await runners.legacy(tc); } catch (e) { legacyErr = e.message; }
    // 错误也参与比对（双包都错且错误一致 = 一致）
    const norm = tc.normalize ?? ((v) => v);
    const m = modernErr ?? norm(modern), l = legacyErr ?? norm(legacy);
    const same = deepEq(m, l);
    if (!same && !tc.normalize)
      console.warn(`用例 ${tc.name} 不一致且无 normalize——若结果含时间戳等抖动请提供 normalize`);
    if (same) consistent++;
    cases.push({ name: tc.name, consistent: same,
      modern: modernErr ?? modern, legacy: legacyErr ?? legacy });
  }
  return { cases, consistentRate: testCases.length ? +(consistent / testCases.length * 100).toFixed(1) : 100,
    ok: consistent === testCases.length };
}

// 自测
const runners = {
  modern: async (tc) => tc.logic({ Array: global.Array, es: 2020 }),
  legacy: async (tc) => tc.logic({ Array: global.Array, es: 5 }),
};
const testCases = [
  { name: 'array-spread', logic: ({ es }) => es >= 2015 ? [1, 2] : Object.assign([], [1, 2]) },
  { name: 'optional-chaining', logic: ({ es }) => es >= 2020 ? ({}).x?.y ?? 'default' : 'default' },
  { name: 'time-based', logic: () => ({ now: Date.now() }),            // 抖动：需 normalize
    normalize: (v) => ({ now: 'ignored' }) },
];
let r = await verifyDualBundle(testCases, runners);
console.log(r.ok === true && r.consistentRate === 100);

// 双包行为不一致
const runners2 = {
  modern: async (tc) => tc.logic({ Array: global.Array, es: 2020 }),
  legacy: async (tc) => tc.logic({ Array: global.Array, es: 5 }),
};
const badCases = [
  { name: 'feature-missing', logic: ({ es }) => es >= 2020 ? 'new-behavior' : 'old-behavior' },
];
r = await verifyDualBundle(badCases, runners2);
console.log(r.ok === false && r.cases[0].modern === 'new-behavior');
console.log(r.cases[0].legacy === 'old-behavior');

// runner 抛错：双包都错且一致
r = await verifyDualBundle([{ name: 'err', logic: () => { throw new Error('same'); } }], {
  modern: async (tc) => { await tc.logic({}); },
  legacy: async (tc) => { await tc.logic({}); },
});
console.log(r.ok === true);                              // 两包错误一致 = 一致

console.log((await verifyDualBundle([], runners)).consistentRate === 100);
```

**评分点**：
- 双环境执行 + normalize（抖动剔除——时间戳类结果的比较语义）；错误也参与比对
- 无 normalize 的不严格告警（提示抖动误报风险）；一致率统计
- 边界（空 cases/runner 抛错的一致性语义）
- 能说清「双包的最大成本是行为等价验证——两编译器产出的语义差异只有跨环境测试才能发现」属于加分
