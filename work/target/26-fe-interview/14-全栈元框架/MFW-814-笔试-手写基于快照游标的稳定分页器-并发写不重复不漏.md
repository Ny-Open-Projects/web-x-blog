## MFW-814：笔试：手写基于快照游标的稳定分页器（并发写不重复不漏行）

**答**：
- 结论：游标编码 id + snapshotTs，不依赖可变 offset；始终从「不可变快照数组」读取，并发插入/删除不引起重复或漏行。
- 关键：首页/末页游标为 null；翻页时新数据不混入当前快照的结果集。
- 追问钩子：快照窗口与存储成本如何权衡？——保留窗口有限，过期快照回退到当前版本并提示。

```javascript
function encodeCursor(id, ts) {
  return Buffer.from(JSON.stringify({ id, ts })).toString('base64url');
}
function decodeCursor(c) {
  return JSON.parse(Buffer.from(c, 'base64url').toString());
}
function stablePage(snapshot, cursor, limit = 10) {
  // snapshot：按 createdAt 倒序、不可变的数组快照
  const cur = cursor ? decodeCursor(cursor) : { id: null, ts: Infinity };
  const start = cur.id ? snapshot.findIndex(x => x.id === cur.id) + 1 : 0;
  const items = snapshot.slice(start, start + limit);
  const next = start + limit < snapshot.length
    ? encodeCursor(items[items.length - 1].id, cur.ts) : null;
  return { items, nextCursor: next, snapshotTs: cur.ts };
}

// 自测
const snap = Array.from({ length: 25 }, (_, i) => ({ id: 'p' + i, ts: i }));
let r = stablePage(snap, null, 10);
console.log(r.items.length === 10 && r.nextCursor);   // true
snap.unshift({ id: 'new', ts: 99 });                 // 并发插入
r = stablePage(snap, r.nextCursor, 10);              // 用旧游标翻页
console.log(!r.items.some(x => x.id === 'new'));     // true：新数据不混入
```

**评分点**：
- 游标编码 id + snapshotTs，不依赖可变 offset，定位稳定
- 从不可变快照读取，并发写不引起重复/漏行；自测覆盖并发插入
- 边界处理：首页 nextCursor、末页返回 null
- 能讨论快照窗口的 GC / 回溯限制与成本权衡（加分）
