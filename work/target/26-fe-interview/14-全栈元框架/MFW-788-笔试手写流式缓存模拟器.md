## MFW-788：笔试：手写流式缓存模拟

**答**：实现 `createStreamingCache(origin, { maxAge })`。origin: `(url) => ReadableStream | string`（源站流式/静态）。get(url)：1) 缓存 miss → 调 origin → **边流边缓存**（每个 chunk 存入缓存——透传给 client）；2) 流完成 → 缓存条目完整（下次直接返回全量）；3) 缓存 hit → 一次性返回（非流式——RBL-787 行为）；4) 返回 `{ stream: ReadableStream, cached: boolean }`。实现 `cacheStats()`：`{ hits, misses, totalBytes }`。边界：origin 抛错（缓存不写入——下次重试）；origin 返回空流（缓存空条目——仍算 miss→hit 转换）；maxAge=0（不缓存——每次 origin）。

```javascript
function createStreamingCache(origin, { maxAge = 60000 } = {}) {
  const cache = new Map();                               // url -> { chunks, ts }
  const stats = { hits: 0, misses: 0, totalBytes: 0 };
  return {
    async get(url) {
      const cached = cache.get(url);
      if (cached && Date.now() - cached.ts < maxAge) {
        stats.hits++;
        // 缓存 hit：一次性返回（非流式）
        return { stream: singleStream(cached.chunks), cached: true };
      }
      stats.misses++;
      const chunks = [];
      const source = origin(url);
      // 处理流式 origin
      if (source.getReader) {
        const reader = source.getReader();
        const stream = new ReadableStream({
          async start(controller) {
            const enc = new TextEncoder();
            while (true) {
              const { done, value } = await reader.read();
              if (done) break;
              chunks.push(value);
              stats.totalBytes += value.byteLength ?? value.length;
              controller.enqueue(enc.encode(value));     // 透传给 client（流式）
            }
            // 流完成：写入缓存
            if (maxAge > 0) cache.set(url, { chunks: [...chunks], ts: Date.now() });
            controller.close();
          },
        });
        return { stream, cached: false };                // 流式透传
      }
      // 静态 origin
      const content = source;
      chunks.push(content);
      if (maxAge > 0) cache.set(url, { chunks: [content], ts: Date.now() });
      return { stream: singleStream(content), cached: false };
    },
    stats: () => ({ ...stats }),
  };
}
function singleStream(chunks) {
  const enc = new TextEncoder();
  return new ReadableStream({
    start(controller) {
      for (const chunk of chunks) controller.enqueue(enc.encode(chunk));
      controller.close();
    },
  });
}

// 自测
let callCount = 0;
const origin = (url) => {
  callCount++;
  return new ReadableStream({
    start(controller) {
      controller.enqueue('chunk1');
      setTimeout(() => { controller.enqueue('chunk2'); controller.close(); }, 10);
    },
  });
};
const cache = createStreamingCache(origin, { maxAge: 60000 });
// 首次：miss → 流式透传
let r1 = await cache.get('/page');
console.log(r1.cached === false);
const text = await readAll(r1.stream);
console.log(text === 'chunk1chunk2');
console.log(callCount === 1);
// 二次：hit → 全量（非流式）
let r2 = await cache.get('/page');
console.log(r2.cached === true);                         // 缓存命中
const text2 = await readAll(r2.stream);
console.log(text2 === 'chunk1chunk2');                   // 内容一致
console.log(callCount === 1);                            // origin 不再调用
console.log(cache.stats().hits === 1 && cache.stats().misses === 1);
async function readAll(stream) {
  const reader = stream.getReader(); let out = '';
  const dec = new TextDecoder();
  while (true) { const { done, value } = await reader.read(); if (done) break; out += dec.decode(value); }
  return out;
}
```

**评分点**：
- 边流边缓存（miss 时透传+缓存——流式特性保持）；缓存 hit 全量返回（非流式——RBL-787）
- origin 调用一次（缓存后不再调 origin——成本节省）；stats 可观测
- 边界（空流/origin 错误不缓存/maxAge=0）；流式与非流式的行为差异
- 能说清「CDN 缓存流式响应：miss 时流式透传、hit 时全量发送——缓存命中的流式特性丢失」属于加分
