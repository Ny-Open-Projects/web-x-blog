## MFW-677：笔试：手写乐观导航回滚器

**答**：实现 `createOptimisticNav({ router })`。router 注入：`{ pushState(url), back(), replaceState(url) }`. 方法：`navigate(href)`。规则：1) 乐观：保存快照（scrollY + snapshot tag）→ router.pushState(href) → 状态 'navigating'；2) `confirm(payload)`：成功 → 状态 'done'（渲染 payload 由调用方做）；3) `rollback()`：router.back() → 状态 'rolled-back' → 返回快照（scrollY——调用方恢复）；4) **并发导航**：navigate 中再次 navigate → 自动 rollback 前一个（前一个的 promise resolve { rolledBack: true }）再开始新导航（后导航优先——RBL-563 竞态）；5) 返回 Promise `{ ok, payload? , rolledBack? }`。边界：confirm 后 navigate（新导航正常）；rollback 无快照（首次失败——无回滚目标）。

```javascript
function createOptimisticNav({ router }) {
  let current = null;                                    // { snapshot, payloadPromise }
  function navigate(href, fetchPayload) {
    // 并发：前一个未完成 → 自动 rollback
    if (current && !current.settled) {
      router.back();
      current.settled = true;
      current.resolve({ ok: false, rolledBack: true, reason: 'superseded' });
    }
    const snapshot = { scrollY: window.scrollY ?? 0 };
    router.pushState(href);
    const promise = new Promise((resolve) => {
      current = { snapshot, href, resolve, settled: false,
        confirm(payload) { this.settled = true; this.resolve({ ok: true, payload }); },
        rollback(reason = 'error') { this.settled = true;
          router.back(); this.resolve({ ok: false, rolledBack: true,
            reason, scrollY: this.snapshot.scrollY }); } };
    });
    current.confirm = current.confirm.bind(current);
    current.rollback = current.rollback.bind(current);
    return { promise, confirm: current.confirm, rollback: current.rollback };
  }
  return { navigate };
}

// 自测
const routerLog = [];
const router = {
  pushState: (u) => routerLog.push(['push', u]),
  back: () => routerLog.push(['back']),
  replaceState: (u) => routerLog.push(['replace', u]),
};
global.window = { scrollY: 500 };
const nav = createOptimisticNav({ router });
// 正常流程
const op1 = nav.navigate('/a', async () => 'payload-a');
await sleep(10);
op1.confirm('payload-a');
const r1 = await op1.promise;
console.log(r1.ok === true && r1.payload === 'payload-a');
console.log(routerLog.filter(x => x[0] === 'push').length === 1);

// 失败回滚
routerLog.length = 0;
const op2 = nav.navigate('/b', async () => { throw new Error('404'); });
await sleep(10);
try { await op2.confirmPromise; } catch {}
op2.rollback('404');
const r2 = await op2.promise;
console.log(r2.ok === false && r2.rolledBack === true && r2.scrollY === 500);
console.log(routerLog.includes('back'));

// 并发导航：后者覆盖前者
routerLog.length = 0;
const opA = nav.navigate('/c', async () => { await sleep(50); return 'c'; });
const opB = nav.navigate('/d', async () => 'd');
const rA = await opA.promise;
console.log(rA.rolledBack === true && rA.reason === 'superseded');   // A 被取代
const rB = await opB.promise;
opB.confirm('payload-d');
// B 正常
```

**评分点**：
- 乐观 pushState + 失败 back 回滚（URL 与内容一致性）；快照（scrollY——RBL-936 恢复协议）
- 并发导航的取代语义（后者优先、前者 rolledBack——RBL-563 竞态）
- 回滚返回快照（调用方恢复——回滚的完整性）；边界
- 能说清「乐观导航的复杂度 = 回滚的完整性（URL+内容+滚动无损恢复）——确定性导航免回滚但慢」属于加分
