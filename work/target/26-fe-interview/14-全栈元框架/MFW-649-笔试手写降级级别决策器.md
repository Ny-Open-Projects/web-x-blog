## MFW-649：笔试：手写降级级别决策器

**答**：实现 `decideDegrade(metrics, levels)`。metrics: `{ dbP95, renderQps, errorRate }`；levels: 升序数组 `{ level, trigger: { metric, threshold }[], action }`。规则：1) 从最高 level 往下检查：levels 内所有 trigger 都超阈值 → 该 level 触发（取最高的满足级——多级都满足取最高）；2) 无满足 → level 0（全功能）；3) 返回 `{ level, action, triggersHit: string[] }`。边界：levels 空（0）；metrics 缺字段（该 trigger 视为未命中——不猜）；多指标 trigger（dbP95>200 AND renderQps>3000——AND 语义）。

```javascript
function decideDegrade(metrics = {}, levels = []) {
  const sorted = [...levels].sort((a, b) => b.level - a.level);   // 高级别优先
  for (const lv of sorted) {
    const hits = [];
    let allHit = true;
    for (const [metric, threshold] of Object.entries(lv.trigger ?? {})) {
      const v = metrics[metric];
      if (v === undefined) { allHit = false; break; }    // 缺数据不猜
      if (v >= threshold) hits.push(metric);
      else { allHit = false; break; }
    }
    if (allHit && Object.keys(lv.trigger ?? {}).length)
      return { level: lv.level, action: lv.action, triggersHit: hits };
  }
  return { level: 0, action: null, triggersHit: [] };
}

// 自测
const levels = [
  { level: 1, trigger: { dbP95: 200 }, action: { stockRealtime: false } },
  { level: 2, trigger: { dbP95: 1000, renderQps: 3000 }, action: { recommendations: 'popular' } },
  { level: 3, trigger: { errorRate: 0.1 }, action: { page: 'static-shell' } },
];
// 正常
console.log(decideDegrade({ dbP95: 50, renderQps: 100, errorRate: 0.01 }, levels).level === 0);
// L1
console.log(decideDegrade({ dbP95: 250, renderQps: 100 }, levels).level === 1);
// L2（AND：两指标都超）
console.log(decideDegrade({ dbP95: 1200, renderQps: 5000, errorRate: 0.01 }, levels).level === 2);
// L2 不满足（只有一个超）
console.log(decideDegrade({ dbP95: 1200, renderQps: 100 }, levels).level === 1);
// L3
console.log(decideDegrade({ dbP95: 50, renderQps: 10, errorRate: 0.15 }, levels).level === 3);
// 多级满足 → 取最高
console.log(decideDegrade({ dbP95: 1200, renderQps: 5000, errorRate: 0.2 }, levels).level === 3);
// 缺字段不猜
console.log(decideDegrade({ dbP95: 1200 }, levels).level === 1);   // 只有 dbP95：L1 命中 L2 不猜
// 空 levels
console.log(decideDegrade({ dbP95: 9999 }, []).level === 0);
```

**评分点**：
- 高级别优先（多级满足取最高——降级的最深程度）；AND 语义（多指标 trigger 全超才命中）
- 缺字段不猜（数据不足时不误降级——保守默认 RBL-925 容器协商同构）
- 边界（空 levels/全不满足 → level 0）；触发器命中的可观测（triggersHit）
- 能说清「降级决策的自动化：阈值驱动秒级响应优于人工判断的分钟级——误降级成本 < 全损」属于加分
