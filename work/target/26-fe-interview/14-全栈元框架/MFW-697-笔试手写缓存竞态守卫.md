## MFW-697：笔试：手写缓存竞态守卫

**答**：实现 `class CacheRaceGuard`。方法：`renderStart(key)`（返回 renderToken）、`renderDone(token, key, result)`、`revalidate(key)`、`get(key)`。规则：1) renderDone：比较 token 的 renderStart 与 lastInvalidate——renderStart < lastInvalidate → 丢弃（返回 { discarded: true }）；2) renderStart ≥ lastInvalidate → 写入缓存（{ discarded: false }）；3) revalidate：记录时间戳 + 清缓存；4) get：返回缓存值（revalidate 后 = null 直到新渲染写入）；5) **并发渲染保护**：同 key 的多个并发渲染——后完成的覆盖先完成的（最后写入胜——同一时间窗内的正常行为）；但都受 revalidate 守卫约束。边界：revalidate 后无新渲染（get null）；token 不存在的 renderDone（忽略）；并发渲染 + revalidate 交错。

```javascript
class CacheRaceGuard {
  constructor({ now = Date.now } = {}) { this.now = now;
    this.cache = new Map(); this.invalidations = new Map(); this.renderStarts = new Map(); }
  renderStart(key) {
    const token = `${key}:${this.now()}:${Math.random()}`;
    this.renderStarts.set(token, { key, ts: this.now() });
    return token;
  }
  renderDone(token, key, result) {
    const info = this.renderStarts.get(token);
    if (!info) return { discarded: true, reason: 'unknown-token' };
    this.renderStarts.delete(token);
    const lastInvalidate = this.invalidations.get(key) ?? 0;
    if (info.ts < lastInvalidate)
      return { discarded: true, reason: 'render-started-before-invalidate' };   // 旧数据丢弃
    this.cache.set(key, result);                         // 安全写入
    return { discarded: false };
  }
  revalidate(key) {
    this.invalidations.set(key, this.now());
    this.cache.delete(key);                              // 清缓存（直到新渲染写入）
  }
  get(key) { return this.cache.get(key) ?? null; }
}

// 自测
const guard = new CacheRaceGuard({ now: () => t });
let t = 1000;
// 正常渲染写入
const token = guard.renderStart('p:1');
t = 1100;
guard.renderDone(token, 'p:1', 'v1');
console.log(guard.get('p:1') === 'v1');

// revalidate 后旧渲染丢弃
t = 1200;
const staleToken = guard.renderStart('p:1');             // 渲染开始 t=1200
t = 1250;
guard.revalidate('p:1');                                 // t=1250 失效
console.log(guard.get('p:1') === null);                  // 缓存清空
t = 1300;
const result = guard.renderDone(staleToken, 'p:1', 'stale-data');
console.log(result.discarded === true);                  // 旧渲染丢弃
console.log(guard.get('p:1') === null);                  // 缓存仍空（不被污染）

// 新渲染写入
t = 1400;
const newToken = guard.renderStart('p:1');               // 渲染开始于 revalidate 之后
guard.renderDone(newToken, 'p:1', 'v2');
console.log(guard.get('p:1') === 'v2');                  // 安全写入

// 未知 token
r = guard.renderDone('fake', 'p:1', 'x');
console.log(r.discarded === true && r.reason === 'unknown-token');
```

**评分点**：
- 竞态守卫正确：renderStart < lastInvalidate → 丢弃（旧数据不覆盖 revalidate 语义）
- revalidate 清缓存（失效态等待新渲染——不被污染）；最后写入胜（并发渲染同窗）
- 未知 token 忽略（防御）；边界
- 能说清「revalidate 后在途渲染的写入 = 旧数据污染缓存——时间戳比较是标准竞态守卫」属于加分
