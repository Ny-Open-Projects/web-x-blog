## MFW→342：配置继承树

**答**:
- 四层树：base（全站默认）→ env（dev/stage/prod）→ region（合规差异：GDPR 去统计）→ tenant/variant（品牌与实验）——合并顺序固定（后者覆盖前者，深合并对象、数组 replace）
- 漂移防护：每层 schema 独立校验（层内合法）+ 合成后全量校验（组合合法——单独合法不代表组合合法：GDPR 层禁的 SDK 不能被 tenant 层加回）；非法组合 fail-fast 并打印合并路径
- 可解释性：`/api/whichcfg?key=x` 返回该值的来源层链（base→prod→eu→acme）——排查「这个值哪来的」秒级
- 变更纪律：base 层变更 = 全站 RFC（影响面最大）；tenant 层自助（租户管理员可改白名单字段——层即权限边界）

```text
树：base → env → region → tenant（固定序深合并）
双检：层内 schema + 合成后全量（防跨层复活）
可解释：/whichcfg 返回来源链；层即权限（base=RFC，tenant=自助）
```
