## MFW→386：回退语义测试

**答**:
- 语义矩阵（每路由声明）：Back 时数据应「命中缓存即时显」or「重验取新」；表单半成品保不保；滚动位置恢复精度——声明进路由卡（MFW-371 第五字段），测试即声明的执行器
- 自动化：Playwright 脚本生成器吃语义矩阵（遍历「进→改→出→Back」四步，按声明断言：DOM 值/请求计数（0=命中缓存）/scrollY 容差）——新路由自动获得语义回归网
- 高频翻车点：回退后 Query 缓存被失效逻辑误清（重拉闪空）、bfcache 被 unload 监听禁用（性能回退无感知恶化）、动态段参数变化复用旧组件 state（key 缺失）
- 门禁：语义矩阵变更 = PR 必审（行为契约变更与代码同权重）；CI 只跑受影响路由的语义用例（增量——MFW-425 思路）

```text
矩阵：每路由 { back数据策略/表单保持/滚动精度 } → Playwright 生成器自动断言
抓点：缓存误清 / bfcache 被 unload 禁 / 动态段 state 串页
门禁：矩阵变更=PR 必审；CI 增量跑受影响路由
```
