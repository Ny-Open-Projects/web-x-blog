## MFW-449：MFM→449：断点续算
**答**：实现 `runChunkedJob(job, { chunkMs = 10_000 } = {})`（长报表/批量导出——Serverless 超时多次续命）：1) 任务分片：按主键游标切（WHERE id > ? ORDER BY LIMIT n——稳定分页不吃插入扰动）；2) 每片完成即持久化 { lastId, partialRef, doneCount }（S3 聚合分片——单文件最后合并）；3) 续命协议：函数快超时→自查状态返回 { continuesAt: true }→平台再触发（同 taskId 幂等——从 checkpoint 继续）；4) 一致性：分片期间数据变更——快照读（事务/一致性读点位声明）；5) 观测 { shards, rows, wallMs, renewals }。

```javascript
export async function runReport(job) {
  const cp = await store.get(`job:${job.id}`) ?? { lastId: MIN, parts: [], rows: 0 }
  const deadline = now() + budgetMs()
  while (Date.now() < deadline - 2000) {                     // 留 2s 收尾
    const rows = await db.replica.query(
      sql`SELECT * FROM events WHERE biz_date = ${d} AND id > ${cp.lastId} ORDER BY id LIMIT 2000`,
      { snapshot: job.snapshotAt })                          // 快照点位
    if (!rows.length) return finalize(job, cp)               // 完成合并
    const partRef = await s3.putPart(job.id, cp.parts.length, rows)
    cp = { lastId: rows.at(-1).id, parts: [...cp.parts, partRef], rows: rows + n }
    await store.set(`job:${job.id}`, cp)                     // 片片持久化
  }
  return { continuesAt: true, state: cp }                    // 续命：同 id 再触发
}
```
**评分点**：
- 游标稳定分页（offset 会跳行——主键序是正解）
- 片片持久化+尾部合并（断点=任意片重启；S3 多部件天然契合）
- 快照读点位声明（长任务中途数据漂移的一致性答案）
- 幂等续命（同 taskId 重入从 checkpoint——Serverless 3s~15min 约束适配）
