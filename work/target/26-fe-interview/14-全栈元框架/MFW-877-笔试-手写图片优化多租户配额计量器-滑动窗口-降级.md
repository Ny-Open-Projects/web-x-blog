## MFW-877：笔试：手写图片优化多租户配额计量器（滑动窗口 + 降级）

**答**：
- 结论：按租户在滑动时间窗内累计优化成本，超限返回降级；用固定窗口分段近似滑动，避免无限增长。
- 关键：计量与降级返回要原子，避免并发下超额；提供 reset/查询接口便于运维。
- 追问钩子：为什么不存每一笔明细？——高频优化下明细存储成本高于计量本身，分桶聚合即可。

```javascript
function createQuota({ limit = 1000, windowMs = 60000, buckets = 4 } = {}) {
  const data = new Map();       // tenant -> [cost per bucket]
  const slot = (t) => Math.floor(Date.now() / (windowMs / buckets)) % buckets;
  function prune(t, now) {
    const s = data.get(t) || Array(buckets).fill(0);
    s[slot(t)] = 0;             // 简化：到新槽清零当前槽
    data.set(t, s); return s;
  }
  return {
    check(t, cost) {
      const s = prune(t);
      const used = s.reduce((a, b) => a + b, 0);
      if (used + cost > limit) return false;
      s[slot(t)] += cost;
      return true;
    },
    used(t) { return (data.get(t) || []).reduce((a, b) => a + b, 0); }
  };
}
// 自测
const q = createQuota({ limit: 10 });
console.log(q.check('tenantA', 6) && q.check('tenantA', 5) === false); // true
```

**评分点**：
- 按租户分桶计量，滑动窗口近似（固定分段）避免无限增长
- check 内完成计量与判定，超限返回 false 触发降级
- 提供 used 查询；边界：新租户、窗口切换
- 能讨论并发原子性与明细存储成本权衡（加分）
