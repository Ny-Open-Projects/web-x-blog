## MFW-405：蓝图提取器
**答**：实现 `extractBlueprint(src)`（正则近似 AST，真实生产用 oxc/babel）：1) 提取 `{ tagPatterns, hardWrites, dynamic }`：fetch 选项与 revalidateTag 里的 tag 字面量/模板串；2) 写库调用检测（prisma/db 的 create/update/delete → 渲染纯度违例，MFW-364）；3) cookies()/headers() 调用 → dynamic 标记；4) 模板 tag 归一为模式（`p:${id}` → `p:*`——蓝图是模式表）；5) 未知模式收集 unknowns（人工清单兜底）。

```javascript
export function extractBlueprint(src) {
  const tags = [], hardWrites = [], unknowns = []
  let dynamic = false

  for (const m of src.matchAll(/revalidateTag\(\s*[`'"]([^`'"]+)[`'"]\s*\)/g)) tags.push(m[1])
  for (const m of src.matchAll(/next:\s*\{\s*tags:\s*\[([^\]]+)\]/g))
    m[1].split(',')
      .map((x) => x.trim().replace(/^[`'"]|[`'"]$/g, ''))
      .filter(Boolean)
      .forEach((t) => tags.push(t))

  for (const m of src.matchAll(/\b(prisma\.\w+|db\.\w+)\.(create|update|delete|upsert)\(/g))
    hardWrites.push(m[0])

  if (/\b(cookies|headers)\(\)/.test(src)) dynamic = true

  const generalize = (t) => t.replace(/\$\{[^}]+\}/g, '*')     // 实例 → 模式
  return {
    tagPatterns: [...new Set(tags.map(generalize))],
    hardWrites: [...new Set(hardWrites)],
    dynamic,
    unknowns,                                                    // 解析不了的行号进人工清单
  }
}
```

**评分点**：
- tag 双源收集（revalidateTag 调用 + fetch 选项——两处声明必须一致，diff 即漂移）
- 模板 tag 模式化（实例→通配——蓝图是模式表不是枚举）
- 渲染纯度违例检出（写库进 RSC = 重试不安全 MFW-364）
- 未知模式收集（解析器诚实边界——漏报比误报危险，人工清单兜底）
