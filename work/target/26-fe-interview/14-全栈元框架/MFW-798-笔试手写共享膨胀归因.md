## MFW-798：笔试：手写共享膨胀归因

**答**：实现 `attributeBloat(before, after, gitLog)`。before/after: `Record<file, sizeKB>`（构建前后的文件体积）；gitLog: `{ sha, author, files, message }[]`（PR 变更的 git 记录）。规则：1) **体积 diff**：after − before > 0 → 膨胀文件（增长量排序）；2) **影响面计算**：膨胀文件的引用路由数（RBL-797 依赖图）；3) **归因**：膨胀文件的 git commit（谁引入的变更——PR 归因）；4) 返回 `{ bloated: Array<{ file, growthKB, affectedRoutes, commit }>, totalGrowth, worstRoute }`。边界：before/after 一致（无膨胀）；gitLog 空（归因未知）；文件只在 after 中（新增——growth = sizeKB）；文件只在 before 中（删除——负增长不报）。

```javascript
function attributeBloat(before = {}, after = {}, gitLog = [], fileToRoutes = new Map()) {
  const bloated = [];
  let totalGrowth = 0;
  for (const [file, size] of Object.entries(after)) {
    const prev = before[file] ?? 0;
    const growth = +(size - prev).toFixed(1);
    if (growth <= 0) continue;                           // 无增长/删除不报
    totalGrowth += growth;
    const affectedRoutes = [...(fileToRoutes.get(file) ?? [])].length;
    const commit = gitLog.find(g => g.files?.includes(file));
    bloated.push({ file, growthKB: growth, affectedRoutes,
      commit: commit ? `${commit.sha.slice(0, 7)} by ${commit.author}: ${commit.message}` : 'unknown' });
  }
  bloated.sort((a, b) => b.growthKB - a.growthKB);
  return {
    bloated,
    totalGrowth: +totalGrowth.toFixed(1),
    worstRoute: bloated[0]?.affectedRoutes
      ? `影响 ${bloated[0].affectedRoutes} 路由` : null,
  };
}

// 自测
const before = { 'common.js': 100, 'page-a.js': 50, 'page-b.js': 50 };
const after = { 'common.js': 130, 'page-a.js': 50, 'page-b.js': 60, 'page-c.js': 40 };
const gitLog = [
  { sha: 'abc1234', author: 'dev1', files: ['common.js'], message: 'add lodash' },
  { sha: 'def5678', author: 'dev2', files: ['page-b.js', 'page-c.js'], message: 'new feature' },
];
const fileToRoutes = new Map([
  ['common.js', new Set(['/a', '/b', '/c', '/d', '/e'])],
  ['page-b.js', new Set(['/b'])],
  ['page-c.js', new Set(['/c'])],
]);
let r = attributeBloat(before, after, gitLog, fileToRoutes);
console.log(r.bloated.length === 3);                     // common +30, page-b +10, page-c +40(新)
console.log(r.bloated[0].file === 'common.js');          // +30 最大增长
console.log(r.bloated[0].affectedRoutes === 5);          // 共享 chunk 影响 5 路由
console.log(r.bloated[0].commit.includes('abc1234'));    // 归因到 commit
console.log(r.totalGrowth === 80);
console.log(r.worstRoute === '影响 5 路由');              // common.js 影响面最大

// 一致
r = attributeBloat(before, before, gitLog, fileToRoutes);
console.log(r.bloated.length === 0 && r.totalGrowth === 0);
// 空
r = attributeBloat({}, after, gitLog, fileToRoutes);
console.log(r.bloated.length === 3);                     // 全部视为新增
```

**评分点**：
- 体积 diff（growth = after − before，删除不报——只关注膨胀）；归因到 commit（PR 粒度）
- 影响面计算（共享 chunk 的引用路由数——膨胀的传播面）；totalGrowth 汇总
- 边界（一致无膨胀/空 before 全新增/无 gitLog 归因未知）；增长排序（最大靶点）
- 能说清「共享 chunk 膨胀的影响面 = 引用路由数——路由级依赖图让膨胀归因精确到 PR 与文件」属于加分
