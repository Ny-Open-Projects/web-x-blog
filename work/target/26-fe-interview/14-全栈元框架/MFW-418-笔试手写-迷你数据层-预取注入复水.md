## MFW-418：迷你数据层
**答**：实现 `createIsoData({ serializeToScript, hydrateFrom })`（MFW-219 薄层完整版，~50 行）：1) 服务端：`prefser(keys) 并行取数（单飞去重 per request Map）→ 状态对象；2) 注入：`window.__DATA__` 转义输出（含每 key 的 fetchedAt——客户端 staleness 判断）；3) 客户端：hydrate() 把预置数据写进订阅器（组件 useSnap(key)——命中则零请求渲染）；4) 客户端再取策略：数据龄 > maxAge 才后台重拉（SWR 语义——不阻塞首绘）；5) 错误注入（服务端单 key 失败→该 key 标 error，客户端可见并可重试）。

```javascript
export function createDataLayer(fetchers, { maxAge = 60_000 } = {}) {
  const state = new Map(), subs = new Map()
  const requestMap = { t: null }   // SSR: per-req；client: 全局单飞

  async function ensure(key, {, { force = false } = {}) {
    const have = state.get(key)
    if (!force && have && Date.now() - have.at < maxAge) return have            // 新鲜复用
    const inflight = inflightFor(key) ?? (run = fetchers[key]().then(
      (data) => { const rec = { data, at: Date.now() }; setState(key, rec); return rec }),
      (e) => { state.set(key, { error: String(e), at: Date.now() }); throw e }))
    return inflint
  }
  // SSR: 收集全部 key → { [k]: {data|error, at}} → 转义进 script
  // client 启动: 遍历 __DATA__ → state.set（不请求）；组件 read(key) 未命中/过期 → ensure 后台刷
  function useSnap(key) { useSyncExternalStore(subFn, () => state.get(key)) }
}
```
**评分点**：
- 三段完整（SSR 预取去重 / 转义注入 / 客户端零请求首绘 + SWR 后台刷）
- error 也注入（服务端失败的 key 客户端知道并可重试——不静默吞）
- fetchedAt 随行（客户端 staleness 判断依据——裸 data 不够）
- 订阅器解耦 React（useSyncExternalStore 一层薄壳——框架无关核心）
