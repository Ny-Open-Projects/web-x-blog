## MFW-426：跨栈会话互验
**答**：实现 `sessionBridge({ jwksUrl, legacyCookieName } = {})`（Next App Router 与旧 Pages/模板栈共存 MFW-394）：1) 统一入口验签：新 JWT（RS256 JWKS）或旧 legacy cookie（HMAC 共享密钥）任一通过即放行（迁移期双轨）；2) 归一化输出 ctx.user {id, roles, source: 'jwt'|'legacy'}——下游业务不感知来源；3) 双活冲突（两凭证不同 uid）→ 以 JWT 为准 + 告警计数（迁移异常信号）；4) legacy 剩余量监控（占比曲线——清零日触发删旧栈验证）。

```javascript
export async function sessionBridge(req, { jwks, legacyKey } = {}) {
  const jwt = await tryJwt (req.cookie('session'), jwks, { clockTol: 30})   // 新
  const leg = verifyHmacCookie(req.cookie(legacyCookieName), legacyKey)     // 旧
  if (jwt && leg && leg.uid !== jwt.sub) report('dual-source-mismatch')     // 冲突信号
  const win = jwt ?? (leg && { id: leg.uid, roles: leg.roles, source: 'legacy' })
  if (!win) return deny (401Challenge())
  return ctxUser(normalize(win))                     // {id, roles, source} 单一形态
}
// legacy 占比 = legacyOnly/(total) 采样进看板 → 清零触发旧栈删除评审
```
**评分点**：
- 双轨任一通过（迁移期不断任何人——兼容优先）
- 归一化单形态出口（业务无感来源）+ 冲突检测（JWT 优先 + 告警——迁移异常可观测）
- 占比曲线驱动删旧（治理有数据终点）
