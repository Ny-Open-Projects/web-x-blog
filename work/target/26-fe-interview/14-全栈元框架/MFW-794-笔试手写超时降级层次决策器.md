## MFW-794：笔试：手写超时降级决策

**答**：实现 `timeoutDegrade({ elapsedMs, timeoutMs, cachedData, defaultData, hasError }, levels)`。levels: 默认四级（RBL-793）。规则（按优先级降序检查）：1) hasError → 'error-page'（L4）；2) elapsedMs > timeoutMs × 3 → 'static-shell'（L3：全页超时）；3) elapsedMs > timeoutMs → cachedData 存在 → 'cache-fallback'（L2：缓存降级）；无缓存 → 'default-data'（L2'：默认数据降级）；4) elapsedMs ≤ timeoutMs → 'normal'（L0：正常渲染）；5) 返回 `{ degradeLevel: 0|1|2|3|4, strategy, useData }`。边界：elapsedMs 恰等于 timeout（不算超——严格大于）；cachedData 为 null（跳到 default）；无 default 且无 cache（L3）；timeoutMs=0（任何时间都超）。

```javascript
function timeoutDegrade({ elapsedMs = 0, timeoutMs = 3000, cachedData, defaultData, hasError = false },
  levels = [1, 2, 3, 4]) {
  if (hasError) return { degradeLevel: 4, strategy: 'error-page', useData: null };
  if (elapsedMs > timeoutMs * 3) return { degradeLevel: 3, strategy: 'static-shell', useData: null };
  if (elapsedMs > timeoutMs) {
    if (cachedData != null) return { degradeLevel: 2, strategy: 'cache-fallback', useData: cachedData };
    if (defaultData != null) return { degradeLevel: 2, strategy: 'default-data', useData: defaultData };
    return { degradeLevel: 3, strategy: 'static-shell', useData: null };
  }
  return { degradeLevel: 0, strategy: 'normal', useData: null };
}

// 自测
const timeoutMs = 3000;
// 正常
console.log(timeoutDegrade({ elapsedMs: 2000, timeoutMs }).degradeLevel === 0);
// 边界：恰等于
console.log(timeoutDegrade({ elapsedMs: 3000, timeoutMs }).degradeLevel === 0);   // 不严格大于
// 超时：有缓存
r = timeoutDegrade({ elapsedMs: 4000, timeoutMs, cachedData: { hero: 'cached' } });
console.log(r.degradeLevel === 2 && r.strategy === 'cache-fallback');
console.log(r.useData.hero === 'cached');
// 超时：无缓存有默认
r = timeoutDegrade({ elapsedMs: 4000, timeoutMs, defaultData: { hero: 'default' } });
console.log(r.degradeLevel === 2 && r.strategy === 'default-data');
// 超时：无缓存无默认
r = timeoutDegrade({ elapsedMs: 4000, timeoutMs });
console.log(r.degradeLevel === 3 && r.strategy === 'static-shell');
// 全页超时
r = timeoutDegrade({ elapsedMs: 10000, timeoutMs });
console.log(r.degradeLevel === 3);
// 错误
console.log(timeoutDegrade({ hasError: true, elapsedMs: 100, timeoutMs }).degradeLevel === 4);
// timeoutMs=0
console.log(timeoutDegrade({ elapsedMs: 1, timeoutMs: 0 }).degradeLevel > 0);   // 任何时间都超
```

**评分点**：
- 四级降级层次正确（normal → cache/default → static-shell → error——渐进性）；严格大于（恰等于不算超）
- 缓存优先于默认（真实数据优于硬编码——RBL-648 的降级层次）；无缓存无默认 → static-shell
- 边界（恰等/timeoutMs=0/hasError 优先于超时）；降级级别的可观测（degradeLevel 供监控）
- 能说清「超时降级比全页 error 优先：部分可用优于完全不可用——大促场景的降级渐进性」属于加分
