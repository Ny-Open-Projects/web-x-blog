## MFW-461：缓存键规范化器
**答**：实现 `normalizeCacheKey(parts)`：1) parts 为任意混合（字符串/对象/数组/URL），对象键序无关（递归排序键后 JSON 化）；2) URL 参数序无关且去掉默认端口、hash、尾部斜杠（同语义 URL 必须同键——否则缓存击穿）；3) `undefined`/空字符串部分跳过，数组保持顺序（顺序敏感的参数不排序）；4) 输出定长 sha1 风格摘要（演示可用简易 hash 替代），冲突时加长度前缀防碰撞。

```javascript
function canonicalize(v) {
  if (v instanceof URL) v = v.toString()
  if (typeof v === 'string' && /^https?:\/\//.test(v)) {
    const u = new URL(v)
    const q = [...u.searchParams].sort(([a], [b]) => a.localeCompare(b))
    u.search = new URLSearchParams(q).toString()
    u.hash = ''
    if ((u.protocol === 'http:' && u.port === '80') ||
        (u.protocol === 'https:' && u.port === '443')) u.port = ''
    let s = u.toString().replace(/\/(\?.*)?$/, '$1')
    return s
  }
  if (Array.isArray(v)) return v.map(canonicalize) // 数组序敏感
  if (v && typeof v === 'object') {
    return Object.fromEntries(Object.keys(v).sort().map(k => [k, canonicalize(v[k])]))
  }
  return v ?? null
}

export function normalizeCacheKey(parts) {
  const canon = parts.filter(p => p !== undefined && p !== '').map(canonicalize)
  const s = JSON.stringify(canon)
  let h = 5381
  for (let i = 0; i < s.length; i++) h = ((h << 5) + h + s.charCodeAt(i)) >>> 0
  return `${s.length}-${h.toString(36)}` // 长度前缀降低碰撞面
}
```

**评分点**：
- 对象键排序递归（键序无关，避免伪 miss）
- URL 归一化四件套：参数排序/去默认端口/去 hash/去尾斜杠
- 数组保序（区分"键序无关"与"列表序敏感"是考点深处）
- 长度前缀防 hash 碰撞（cache key 冲突即数据串页）
