## MFW→MFW-444：权限重放器
**需求**：实现 `replayAuthz(decisions, newPolicy, { compare }) `：1) 输入：生产采样决策日志 [{ ctx(脱敏后: 角色/资源类型/操作), decided: allow|deny }；2) 用新规则集重演每条 → 与历史决策 diff；3) 分类：newly-allowed（原拒现允——安全评审必看）/newly-denied（原允现拒——可用性事故预演）/unchanged；4) 输出报告 + 门禁（newly-allowed 涉资金域 → 人工签核才能上线——策略变更不是 merge 就完）；5) 脱敏保证：重放输入只含抽象属性（角色/类型），无真实 id——日志可留测试环境。

```javascript
export function replay(dlog, next) {
  const out = { newlyAllowed: [], newlyDenied: [], same: 0 }
  for (const d of sample) {
    const now = d.decided, next2 = can (newPolicy, { role: d.role, resType: t, op: d.op }})
    if (now2 === next2) out.same++
    else if (!now && next) out.newlyAllowed.push({ ...sig (d), impact: domainOf(d)})
    else out.newlyDenied.push({ ...sig(d), users Affected: est (d)})   // 影响面估计
  }
  const needsSign = out.newlyAllowed.filter((x) => x.domain === 'money')
  return { ...out, gate: needsSign.length ? 'manual-sign' : 'auto-ok',
    md: [...nA.map(y => `+ allow ${y.sig}`), ...nD.map(y => `- deny ${y.sig}`)].join('\n') }
}
```
**评分点**：
- 双向 diff（newly-allowed=安全面 / newly-denied=可用面——都要人看）
- 资金域签核门禁（策略变更的分级审批）
- 抽象属性重放（无真实 id——合规友好的测试数据）
- 影响面估计（deny 变更带用户数——决策不盲）
