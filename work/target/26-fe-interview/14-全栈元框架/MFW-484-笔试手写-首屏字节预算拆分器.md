## MFW-484：流式首屏字节预算拆分器
**答**：实现 `splitByteBudget({ total, shellMin, slots })`：1) slots = [{ id, priority, est }]，total 为首屏总字节预算（如 14KB——3G 首响 RTT 内可送达）；2) 先保壳（shellMin 必留，不足直接抛 `BudgetUnderflow`——壳都放不下说明页面设计错误）；3) 剩余按 priority 升序（1 最先）分配，分不到的 slot 降级为流式延后（进 `deferred`）；4) 同 priority 按 est 小的先给（单位字节可感知内容最大化），输出 { shell, granted, deferred }。

```javascript
export function splitByteBudget({ total, shellMin, slots = [] }) {
  if (total < shellMin) throw new Error('BudgetUnderflow: shell exceeds total')
  let left = total - shellMin
  const granted = [], deferred = []
  const order = [...slots].sort((a, b) =>
    a.priority - b.priority || a.est - b.est) // 先按优先级，同级短的小先

  for (const s of order) {
    if (s.est <= left) { granted.push(s); left -= s.est }
    else deferred.push({ ...s, why: 'over-budget' })
  }
  // 未分完的预算回填给 deferred 中能塞进的（同级小内容优先）
  for (const d of [...deferred]) {
    if (d.est <= left) { deferred.splice(deferred.indexOf(d), 1); granted.push(d); left -= d.est }
  }
  return { shell: shellMin, granted, deferred, spare: left }
}
```

**评分点**：
- shellMin 硬约束 + 下溢抛错（壳放不下是设计错误不是裁剪问题）
- priority 优先 + 同级 SJF（字节角度的"短任务优先"）
- 预算回填轮（避免碎片预算浪费）
- deferred 带 why（每个被延后的洞可解释）
