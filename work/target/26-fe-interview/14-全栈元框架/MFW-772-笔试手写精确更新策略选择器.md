## MFW-772：笔试：手写精确更新策略

**答**：实现 `chooseUpdateStrategy({ hasTag, affectedRoutes, affectedComponents, isAction })`。规则：1) isAction && hasTag → 'revalidate-tag'（server 侧精确失效——最优）；2) isAction && !hasTag && affectedRoutes ≤ 3 → 'revalidate-path'（少量路由 path 失效）；3) !isAction（client 侧）&& affectedComponents 已知 → 'suspense-refresh'（刷新特定边界——精确但需实现）；4) 兜底 → 'router-refresh'（全页刷新 RBL-771）。5) 返回 `{ strategy, granularity: 'tag'|'path'|'component'|'page', reason }`。边界：affectedRoutes 空（tag 也无效——router-refresh）；affectedComponents 空（无法精确——降级）；isAction=false 且 hasTag=true（client 也可调 revalidate——'revalidate-tag' 仍可用但需 server route）。

```javascript
function chooseUpdateStrategy({ hasTag = false, affectedRoutes = [], affectedComponents = [],
  isAction = false } = {}) {
  if (isAction && hasTag && affectedRoutes.length > 0)
    return { strategy: 'revalidate-tag', granularity: 'tag',
      reason: 'server action + tag——精确失效关联路由' };
  if (isAction && affectedRoutes.length > 0 && affectedRoutes.length <= 3)
    return { strategy: 'revalidate-path', granularity: 'path',
      reason: `少量路由（${affectedRoutes.length}）——path 精确失效` };
  if (!isAction && affectedComponents.length > 0)
    return { strategy: 'suspense-refresh', granularity: 'component',
      reason: 'client 侧——刷新特定 Suspense 边界' };
  return { strategy: 'router-refresh', granularity: 'page',
    reason: '兜底——全页刷新（无精确失效手段）' };
}

// 自测
// 最优：action + tag
console.log(chooseUpdateStrategy({ isAction: true, hasTag: true,
  affectedRoutes: ['/p/1', '/products'] }).strategy === 'revalidate-tag');
console.log(chooseUpdateStrategy({ isAction: true, hasTag: true,
  affectedRoutes: ['/p/1'] }).granularity === 'tag');
// action 无 tag 少路由
console.log(chooseUpdateStrategy({ isAction: true, hasTag: false,
  affectedRoutes: ['/p/1'] }).strategy === 'revalidate-path');
// action 无 tag 多路由（>3 降级）
console.log(chooseUpdateStrategy({ isAction: true, hasTag: false,
  affectedRoutes: ['/a', '/b', '/c', '/d', '/e'] }).strategy === 'router-refresh');
// client + 组件
console.log(chooseUpdateStrategy({ isAction: false,
  affectedComponents: ['Reviews'] }).strategy === 'suspense-refresh');
// 兜底
console.log(chooseUpdateStrategy({ isAction: false, hasTag: true,
  affectedRoutes: [] }).strategy === 'router-refresh');
console.log(chooseUpdateStrategy({}).strategy === 'router-refresh');
```

**评分点**：
- 决策树优先级：tag > path > component > page（精确性递减——server 侧优于 client 侧）
- affectedRoutes ≤ 3 的 path 阈值（少量 path 精确、大量降级 tag 或 refresh）；affectedRoutes 空的兜底
- 边界（client 无组件/全部空/granularity 递减语义）；server 侧 > client 侧的架构原则
- 能说清「revalidateTag 在 action 内优于 router.refresh：server 侧精确失效（tag 粒度）优于 client 侧粗刷」属于加分
