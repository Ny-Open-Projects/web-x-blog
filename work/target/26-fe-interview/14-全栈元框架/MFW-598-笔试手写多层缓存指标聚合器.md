## MFW-598：笔试：手写多层缓存指标聚合器

**答**：实现 `aggregateCache(metrics, { minSamples })`。metrics: `{ layer, route, status: 'hit'|'miss'|'stale', latencyMs, tag? }[]`。规则：1) 双维分桶（layer:route 与 layer:tag）；2) 每桶：hitRate（hit/(total)）保留 1 位 + p50 延迟（排序中位）；3) 告警桶：hitRate < minSamples 相关阈值（hitRate < 50% 且样本 ≥ 10）→ flags `{ bucket, hitRate, suspicion: 'over-invalidation'|'low-ttl' }`（stale 比例 > 30% → over-invalidation——失效太频繁；否则 low-ttl）；4) 返回 `{ buckets: sorted by hitRate asc, flagged }`。边界：metrics 空；单样本桶（p50 = 该值；hitRate 不告警——样本不足）。

```javascript
function aggregateCache(metrics = [], { minSamples = 10 } = {}) {
  const buckets = new Map();
  for (const m of metrics) {
    for (const bucket of [`${m.layer}:${m.route}`, m.tag ? `${m.layer}:tag:${m.tag}` : null]) {
      if (!bucket) continue;
      const b = buckets.get(bucket) || buckets.set(bucket,
        { bucket, hit: 0, miss: 0, stale: 0, lats: [] }).get(bucket);
      b[m.status]++; b.lats.push(m.latencyMs);
    }
  }
  const out = [...buckets.values()].map(b => {
    const total = b.hit + b.miss + b.stale;
    const lats = [...b.lats].sort((a, c) => a - c);
    return { bucket: b.bucket, hitRate: +(b.hit / total * 100).toFixed(1),
      p50: lats[Math.floor(lats.length / 2)], total,
      staleRatio: +(b.stale / total).toFixed(2) };
  }).sort((a, c) => a.hitRate - c.hitRate);
  const flagged = out.filter(o => o.total >= minSamples && o.hitRate < 50)
    .map(o => ({ bucket: o.bucket, hitRate: o.hitRate,
      suspicion: o.staleRatio > 0.3 ? 'over-invalidation' : 'low-ttl' }));
  return { buckets: out, flagged };
}

// 自测
const metrics = [
  { layer: 'data', route: '/products', status: 'hit', latencyMs: 5, tag: 'products' },
  { layer: 'data', route: '/products', status: 'miss', latencyMs: 120, tag: 'products' },
  { layer: 'data', route: '/products', status: 'miss', latencyMs: 110, tag: 'products' },
  { layer: 'data', route: '/products', status: 'stale', latencyMs: 8, tag: 'products' },
  { layer: 'data', route: '/products', status: 'stale', latencyMs: 9, tag: 'products' },
  { layer: 'cdn', route: '/products', status: 'hit', latencyMs: 2 },
  { layer: 'cdn', route: '/products', status: 'hit', latencyMs: 3 },
  { layer: 'data', route: '/account', status: 'hit', latencyMs: 1, tag: 'account' },
];
let r = aggregateCache(metrics, { minSamples: 5 });
// data:/products: total=5 hit=1 miss=2 stale=2 → hitRate 20%, stale 0.4
console.log(r.buckets[0].bucket === 'data:tag:products');
console.log(r.buckets[0].hitRate === 20 && r.buckets[0].p50 === 110);
console.log(r.flagged[0].suspicion === 'over-invalidation');   // stale 0.4 > 0.3
console.log(r.buckets.find(b => b.bucket === 'cdn:/products').hitRate === 100);

// 样本不足不告警
r = aggregateCache([{ layer: 'data', route: '/x', status: 'miss', latencyMs: 5, tag: 'x' }]);
console.log(r.flagged.length === 0);                     // 1 < minSamples
console.log(aggregateCache([]).buckets.length === 0);
```

**评分点**：
- 双维分桶（route 与 tag——tag 维度定位失效问题 RBL-577）；p50 中位数（非均值——离群鲁棒 RBL-588）
- 告警归因二分（stale 比例 > 30% = 失效过频 vs TTL 太短——不同治理动作）
- 样本量门禁（minSamples 防噪声告警）；命中率升序（最差优先——RBL-851 看板）
- 能说清「CDN 命中率高 ≠ 缓存健康——命中率 + 新鲜度双指标才是完整画像」属于加分
