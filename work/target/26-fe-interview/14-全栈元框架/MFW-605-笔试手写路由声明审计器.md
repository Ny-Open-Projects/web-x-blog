## MFW-605：笔试：手写路由声明审计器

**答**：实现 `auditRoutes(audits, lastBuild, { warnImplicit })`。audits: `{ route, declared?: string, actual: string }[]`；lastBuild: 上次构建的 audits（漂移检测）。规则：1) 矛盾：force-static + actual dynamic → error 'contradiction'；2) 隐式动态：无声明 + actual dynamic → warn 'implicit-dynamic'（warnImplicit=false 则忽略）；3) 浪费：declared dynamic + actual static → warn 'wasted-dynamic'；4) 漂移：与 lastBuild 的 actual 类型变化 → info 'type-drift'（from→to）；5) 返回 `{ findings: Array<{ route, severity: 'error'|'warn'|'info', issue, detail? }>, ok }`（ok = 无 error）。边界：audits 空；lastBuild 空（无漂移检测）；force-static + actual isr 算矛盾吗（isr 有静态能力——不算矛盾但算漂移）。

```javascript
function auditRoutes(audits = [], lastBuild = [], { warnImplicit = true } = {}) {
  const findings = [];
  for (const a of audits) {
    const isStaticish = a.actual === 'static' || a.actual === 'isr';
    if (a.declared === 'force-static' && !isStaticish)
      findings.push({ route: a.route, severity: 'error', issue: 'contradiction',
        detail: '声明 force-static 但实际动态——动态 API 覆盖声明' });
    if (a.declared === undefined && a.actual === 'dynamic' && warnImplicit)
      findings.push({ route: a.route, severity: 'warn', issue: 'implicit-dynamic',
        detail: '隐式动态化——建议显式声明' });
    if (a.declared === 'dynamic' && isStaticish)
      findings.push({ route: a.route, severity: 'warn', issue: 'wasted-dynamic',
        detail: '声明 dynamic 但实际可静态——成本白付' });
    if (lastBuild.length) {
      const prev = lastBuild.find(l => l.route === a.route);
      if (prev && prev.actual !== a.actual)
        findings.push({ route: a.route, severity: 'info', issue: 'type-drift',
          detail: `类型漂移: ${prev.actual} → ${a.actual}` });
    }
  }
  return { findings, ok: !findings.some(f => f.severity === 'error') };
}

// 自测
const audits = [
  { route: '/home', declared: 'force-static', actual: 'dynamic' },     // 矛盾
  { route: '/shop', actual: 'dynamic' },                                // 隐式
  { route: '/blog', declared: 'dynamic', actual: 'static' },            // 浪费
  { route: '/about', declared: 'static', actual: 'static' },            // 正常
];
let r = auditRoutes(audits, [
  { route: '/home', declared: 'force-static', actual: 'static' },       // 漂移源
  { route: '/shop', actual: 'static' },                                 // 静→动
  { route: '/blog', actual: 'static' },
  { route: '/about', actual: 'static' },
]);
console.log(r.findings.filter(f => f.severity === 'error').map(f => f.route).join(',') === '/home');
console.log(r.findings.some(f => f.issue === 'implicit-dynamic' && f.route === '/shop'));
console.log(r.findings.some(f => f.issue === 'wasted-dynamic' && f.route === '/blog'));
console.log(r.findings.filter(f => f.issue === 'type-drift').length === 1);   // /shop 静→动
console.log(r.ok === false);                             // 有 error

// warnImplicit=false
r = auditRoutes(audits, [], { warnImplicit: false });
console.log(!r.findings.some(f => f.issue === 'implicit-dynamic'));
console.log(auditRoutes([], []).ok === true);
```

**评分点**：
- 三类发现分级（error 矛盾 / warn 隐式与浪费 / info 漂移——严重度语义清晰）
- force-static + isr 的边界判定（isr 有静态能力不算矛盾——静态性谱系而非二值）
- 漂移检测与上次构建对账（升级/变更的动态化归因 RBL-576）；边界
- 能说清「隐式动态化的静默成本变化与静默错误同级危险——审计让成本画像变化与代码变更关联」属于加分
