## MFW→356：混合渲染共存

**答**:
- 场景：老站服务端模板（Java FTL/Rust 页面）与新元框架路由共存于同域——渐进重写的标准困局
- 共存协议：路径族分治（网关按前缀分派到模板服务 or Next 集群）+ 会话互认（同一签发 cookie 双端本地验签——MFW-291 共享 JWKS）+ 导航无缝（跨栈跳转用整页导航不做软路由——两棵路由树别互水合）
- 视觉一致性合约：设计 token 双端同源（JSON token 生成两侧 CSS 变量——改色不出现「半新半旧」色差页）
- 收敛策略：按流量与改版频率排序逐路径族迁移（每月 2-3 族）+ 模板侧冻结（只修不加——新功能强制走新栈，倒计时收敛）
