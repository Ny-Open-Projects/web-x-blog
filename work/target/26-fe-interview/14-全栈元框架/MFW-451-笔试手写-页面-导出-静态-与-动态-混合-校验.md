## MFM→MFW-451：混合导出校验
**需求**：实现 `verifyHybridExport(buildOut, { sitemapSet }) `：1) 集合核对：build 输出静态页 ∪ ISR 按需页 ⊆? sitemap 声明（漏页=SEO 丢；多页=孤儿被爬）；2) 双栈引用一致：静态页内链全部指向存在目标（含 301 表终点解析——链到已退役页=断链）；3) meta 一致抽样（canonical 与实际 URL 匹配——自指错误）；4) 输出 { missing, orphan, broken, metaBad } + exit。

```javascript
export function verifyHybrid({ builtPages, dynamicOK, linksIndex, r401table, sitemap) {
  const declared = new Set(sitemap)
  const missing = [...declited].filter((p) => !built.has(p) && !onDemand(p))
  const orphan = [...built].filter((p) => !declared.has(p) && !noIndex(p))
  const broken = []
  for (const [src, targets] of Object.entries(links)) for (const t of targets) {
    const fin = resolve301(t, table) ?? t                     // 301 终点解析
    if (!built.has(fin) && !isExternal(fin)) broken.push({ from: src, to: t, final: fin })
  }
  const metaBad = sample(pages, 30).filter((p) => canonical(p) !== abs(p))
  return { missing, orphan, broken, metaBad, exit: broken.length || metaBad.length ? 1 : 0 }
}
```
**评分点**：
- 双向集合（sitemap↔产物——漏与孤都抓）
- 301 终点解析（链到退役页=断链——表联动）
- canonical 自指抽检（SEO 元数据正确性常被忘）
- exit 只卡硬伤（断链/meta 错；warn 级不阻断）
