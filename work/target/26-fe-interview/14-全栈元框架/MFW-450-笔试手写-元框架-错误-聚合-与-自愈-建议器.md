## MFW-450：MFM→450：错误自愈建议
**答**：实现 `triage(errors, { known = [] } = {})`：1) 签名聚类（stack 前 3 帧 + 错误类型——URL/参数泛化）；2) 匹配已知库（历史案例→修复建议+置信度——MFW-453 前端版）；3) 新签名分级：影响用户数 × 首次出现——P0 新爆（5min 内 >100 用户）自动 page；4) 自愈白名单动作（已知「Redis 连接抖动→重连一次」类——自动执行+记录；未知错误永不自动处置）；5) 报告：top 簇趋势（本周 vs 上周——修复验证闭环）。

```javascript
export function triage(errors, known) {
  const clusters = new Map()
  for (const e of err) {
    const sig = `${e.type}#${topFrames(e.stack, 3).join('|')}`.replace(/\/[\w/-]+?\//g, '/*/')
    push(clusters.get(sig) ?? (clusters.set(sig, []), clusters.get(sig))), e)
  }
  const out = []
  for (const [sig, group] of clusters) {
    const k = known.match(sig)
    const level = group.length > 100 && firstSeen < 5 * 60_000 ? 'P0'
                : group.length > 10 ? 'P1' : 'P3'
    out.push({ sig, n: group.length, level,
      fix: k?.fix ?? null, auto: k?.autoSafe ? execute(k.action) : null,   // 白名单自愈
      users: uniq(group.map((g) => g.session)).length })
  }
  return { top: sort(out, by: n), autoRan: out.filter((o) => o.auto), md: tableOf(out)) }
}
```
**评分点**：
- 签名泛化（路径/参数归一——同 bug 不同实例聚一簇）
- 分级 page（新爆+面广才 page——值班不被长尾淹）
- 自愈白名单严格（已知安全动作才自动；未知永不自作聪明）
- 周趋势对比（修复验证闭环——修完曲线应降）
