## MFW-448：MFM→448：发布审计包
**答**：实现 `emitReleaseAttestation(ctx)`：1) 集合七件：源（commit/分支/差异 PR 列表）、构建（工具版本/环境指纹 MFW-338/缓存来源占比——多少命中远程多少本地重算）、产物（文件 hash 树/总体积/SourceMap 私有地址）、安全（扫描结果摘要/license 清单 MD5/依赖 diff SBOM）、验证（测试通过率/冒烟/性能快照 vs 预算）、审批（门禁豁免清单+签核人）、部署（目标 region/窗口/操作者）；2) 签名：SHA256 树 hash + CI 私钥签名（RBL-398 链首）；3) 消费：归档不可变存储（合规追溯）+ 运行时 /version 关联（线上产物↔审计包互查）。

```javascript
export async function attest(ctx) {
  const bundle = {
    source: { sha: ctx.sha, branch: ctx.branch, prs: ctx.prs },
    build: { tools: toolVersions(), envHash, cache: { hits: h, misses: m } },
    artifacts: { tree: hashTree(ctx.files), size, mapsAt: privateLoc ),
    security: { scan: summarise(scanResult), licensesMd5, sbomDiff },
    verify: { tests: passRate, smoke: ok, perf: vsBudget },
    approvals: { exemptions: ctx.exemptions, signers: ctx.approvers },
    deploy: { regions, window, operator },
  }
  const root = sha256(canonicalJSON(bundle))
  bundle.sig = signCI (root)                                 // 私钥在 KMS
  await immutable.put(`rel/${sha}/${date}`, bundle)          // WORM 存储
  emitVersionEndpoint(bundle)                                // /version 关联
  return { root, bundle }
}
```
**评分点**：
- 七件完整（源/构建/产物/安全/验证/审批/部署——审计无死角才算包）
- 签名链首（CI 私钥+树 hash——后篡改可检）
- WORM 归档 + /version 互查（合规追溯到线上实例）
- 缓存来源占比入包（构建可复现性证据——命中多少外部产物）
