## MFW-482：RSC 分页游标编解码器
**需求**：实现 `encodeCursor/decodeCursor`：1) 游标 = Base64(JSON { sort, lastId, lastVal, dir, v })，v 是结构版本（游标结构演进不崩旧链接）；2) decode 校验：字段缺失/类型错/v 不支持 → 抛 `BadCursor`（返回 400 而不是当无游标处理——防伪造游标穿过滤条件）；3) sort 白名单（只允许 'id'|'createdAt'——直接拼 SQL 的排序字段是注入点）；4) encode 不含页码（游标分页语义：数据变动也不重/不漏页）。

```javascript
const SCHEMA = { v: 1, sorts: ['id', 'createdAt'] }

export function encodeCursor({ sort, lastId, lastVal, dir = 'asc' }) {
  if (!SCHEMA.sorts.includes(sort)) throw new Error(`sort not allowed: ${sort}`)
  const payload = { v: SCHEMA.v, sort, lastId: String(lastId), lastVal: String(lastVal), dir }
  return Buffer.from(JSON.stringify(payload)).toString('base64url')
}

export function decodeCursor(cur) {
  if (!cur) return null // 首页无游标
  try {
    const p = JSON.parse(Buffer.from(cur, 'base64url').toString())
    if (p.v !== SCHEMA.v) throw new Error('unsupported cursor version')
    if (typeof p.lastId !== 'string' || typeof p.lastVal !== 'string') throw new Error('bad fields')
    if (!SCHEMA.sorts.includes(p.sort)) throw new Error('sort not allowed')
    if (p.dir !== 'asc' && p.dir !== 'desc') throw new Error('bad dir')
    return { sort: p.sort, lastId: p.lastId, lastVal: p.lastVal, dir: p.dir }
  } catch (e) {
    throw Object.assign(new Error(`BadCursor: ${e.message}`), { status: 400 })
  }
}

// 用法：where(sortCol, op, lastVal) and (sortCol, id) != (lastVal, lastId) order by sortCol, id
```

**评分点**：
- 结构版本 v（游标演进兼容旧分页链接）
- 全字段类型校验 + 400 而非静默 null（伪造游标必须显式拒绝）
- sort 白名单（排序字段直拼 SQL 是注入口——安全硬分）
- (sortVal, id) 复合锚点（同值排序不稳定，id 做决胜列防重漏）
