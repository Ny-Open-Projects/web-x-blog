## MFW-156：笔试：手写一致性哈希实现边缘节点分流
**答**：边缘渲染集群要按用户（uid）稳定分流到渲染实例，保证同一用户总落同一实例（会话亲和）。实现 `ConsistentHash`：① `add/remove(node)` 动态上下线；② `getNode(uid)` 返回负责节点；③ 用虚拟节点（每物理节点 150 个）改善均匀性；④ 节点下线只迁移 1/N 的 key 而非全部重排；⑤ 节点列表为空返回 null。

```ts
import { createHash } from 'crypto';

export class ConsistentHash {
  private ring: Array<{ hash: number; node: string }> = [];
  private nodes = new Set<string>();
  private vnodes = 150;

  private hash(str: string): number {
    return parseInt(createHash('md5').update(str).digest('hex').slice(0, 8), 16);
  }

  add(node: string): void {
    if (this.nodes.has(node)) return;
    this.nodes.add(node);
    for (let i = 0; i < this.vnodes; i++) {
      // 虚拟节点：node#v0..node#v149 散列进环
      this.ring.push({ hash: this.hash(`${node}#v${i}`), node });
    }
    this.ring.sort((a, b) => a.hash - b.hash);
  }

  remove(node: string): void {
    if (!this.nodes.has(node)) return;
    this.nodes.delete(node);
    this.ring = this.ring.filter((e) => e.node !== node); // 只删该节点的虚拟点
  }

  getNode(key: string): string | null {
    if (!this.ring.length) return null;
    const h = this.hash(key);
    // 环上顺时针找第一个 >= h 的虚拟节点；绕回取第一个
    let lo = 0, hi = this.ring.length - 1;
    if (h > this.ring[hi].hash) return this.ring[0].node;
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      if (this.ring[mid].hash >= h) hi = mid; else lo = mid + 1;
    }
    return this.ring[lo].node;
  }
}

// —— 用例与迁移验证 ——
const ch = new ConsistentHash();
['edge-a', 'edge-b', 'edge-c'].forEach((n) => ch.add(n));
const before = ['u1', 'u2', 'u3'].map((u) => ch.getNode(u));

ch.remove('edge-b'); // 下线一个节点
const after = ['u1', 'u2', 'u3'].map((u) => ch.getNode(u));
// 期望：多数 u 仍落在原节点（迁移量 ≈ 1/3），只有原来落在 edge-b 的 key 重排
console.log({ before, after });
```

**评分点**：
1. 虚拟节点机制正确且数量够（150/节点），否则环不均匀。
2. 二分查找定位环上第一个 >= hash 的节点，越界回绕到环首。
3. remove 只过滤该节点的虚拟点，能解释「只迁移 1/N」的性质。
4. 空环返回 null 而不是抛错。
5. 能口头补充：一致性哈希 vs 简单取模的差别（扩容时全量重排 vs 局部迁移）。
