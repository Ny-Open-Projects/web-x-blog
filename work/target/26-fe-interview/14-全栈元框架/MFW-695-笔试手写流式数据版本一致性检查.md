## MFW-695：笔试：手写流式数据版本检查

**答**：实现 `checkConsistency(renderedChunks, { maxVersionGapMs })`。renderedChunks: `{ segment, dataVersion, renderedAt }[]`（同页面的各段渲染元数据）。规则：1) 版本差：max(renderedAt) − min(renderedAt) > maxVersionGapMs（默认 5000ms）→ warn 'version-gap'（段间时间差过大——数据不一致风险）；2) 版本号对比（数值 version：段间 version 差 > 1 → 'data-drift'——数据在渲染期间变更）；3) 一致性评级：无 gap 无 drift → 'consistent'；gap 或 drift → 'eventually-consistent'；返回 `{ consistent, warnings, timeSpan }`。边界：单 chunk（无 gap）；全同 version（consistent）；renderedAt 缺失（跳过时间检查）。

```javascript
function checkConsistency(renderedChunks = [], { maxVersionGapMs = 5000 } = {}) {
  if (renderedChunks.length <= 1)
    return { consistent: true, warnings: [], timeSpan: 0 };
  const warnings = [];
  const renderedAts = renderedChunks.map(c => c.renderedAt).filter(Boolean);
  const versions = renderedChunks.map(c => c.dataVersion).filter(v => v != null);
  const timeSpan = renderedAts.length
    ? Math.max(...renderedAts) - Math.min(...renderedAts) : 0;
  if (timeSpan > maxVersionGapMs)
    warnings.push({ type: 'version-gap',
      detail: `段间渲染时差 ${timeSpan}ms > ${maxVersionGapMs}ms——数据版本不一致风险` });
  if (versions.length > 1) {
    const minV = Math.min(...versions), maxV = Math.max(...versions);
    if (maxV - minV > 1)
      warnings.push({ type: 'data-drift',
        detail: `数据版本跨 ${maxV - minV} 次变更——前后段数据不一致` });
  }
  return {
    consistent: warnings.length === 0,
    warnings,
    timeSpan,
  };
}

// 自测
// 一致：同时渲染
let r = checkConsistency([
  { segment: 'info', dataVersion: 5, renderedAt: 1000 },
  { segment: 'reviews', dataVersion: 5, renderedAt: 1200 },
]);
console.log(r.consistent === true && r.warnings.length === 0);

// 版本差 > 1：data drift
r = checkConsistency([
  { segment: 'info', dataVersion: 5, renderedAt: 1000 },
  { segment: 'reviews', dataVersion: 8, renderedAt: 1200 },
]);
console.log(r.consistent === false);
console.log(r.warnings.some(w => w.type === 'data-drift'));

// 时间 gap
r = checkConsistency([
  { segment: 'info', dataVersion: 5, renderedAt: 1000 },
  { segment: 'reviews', dataVersion: 5, renderedAt: 8000 },
], { maxVersionGapMs: 5000 });
console.log(r.warnings.some(w => w.type === 'version-gap'));
console.log(r.timeSpan === 7000);

// 单 chunk
console.log(checkConsistency([{ segment: 'x', dataVersion: 1, renderedAt: 1 }]).consistent === true);

// 无 renderedAt
r = checkConsistency([{ segment: 'x', dataVersion: 5 }, { segment: 'y', dataVersion: 5 }]);
console.log(r.timeSpan === 0 && r.consistent === true);
```

**评分点**：
- 双维检测：时间 gap（渲染时差）与 version 差（数据变更——两种不一致形态）
- maxVersionGapMs 阈值（可接受的窗口——业务可调）；单 chunk 短路
- 边界（无 renderedAt 跳过/全同 version）；eventually-consistent 的评级语义
- 能说清「流式错误恢复的 reset 重渲染 = 数据版本差窗口——严格一致需整页刷新（成本权衡）」属于加分
