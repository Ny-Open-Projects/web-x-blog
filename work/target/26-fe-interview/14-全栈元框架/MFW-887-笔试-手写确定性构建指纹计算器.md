## MFW-887：笔试：手写确定性构建指纹计算器

**答**：
- 结论：把影响产物的所有输入（源码哈希集合、依赖锁、配置、环境变量白名单）规范化后计算稳定哈希，作为可复现构建的指纹。
- 关键：键排序 + 去时间戳 + 稳定序列化；遗漏任一输入都会导致指纹「假命中」。
- 追问钩子：为什么环境变量要白名单？——全量环境含时间戳/随机值会破坏确定性，只纳入真正影响产物的变量。

```javascript
function stableStringify(o) {
  if (Array.isArray(o)) return '[' + o.map(stableStringify).join(',') + ']';
  if (o && typeof o === 'object')
    return '{' + Object.keys(o).sort().map(k => JSON.stringify(k) + ':' + stableStringify(o[k])).join(',') + '}';
  return JSON.stringify(o);
}
function hash(s) { let h = 5381; for (const c of s) h = ((h << 5) + h + c.charCodeAt(0)) >>> 0; return h.toString(16); }

function buildFingerprint({ fileHashes, lockHash, config, env, envWhitelist }) {
  const pickedEnv = {};
  for (const k of envWhitelist.slice().sort()) pickedEnv[k] = env[k] ?? '';
  const input = { files: fileHashes, lock: lockHash, config, env: pickedEnv };
  return hash(stableStringify(input));
}
// 自测：输入顺序不同 → 指纹相同
const a = { fileHashes: { b: '2', a: '1' }, lockHash: 'L', config: {}, env: { TZ: 'UTC', X: 'noise' }, envWhitelist: ['TZ'] };
const b = { fileHashes: { a: '1', b: '2' }, lockHash: 'L', config: {}, env: { TZ: 'UTC' }, envWhitelist: ['TZ'] };
console.log(buildFingerprint(a) === buildFingerprint(b)); // true
```

**评分点**：
- 对输入做稳定序列化（键排序 + 去噪），顺序无关
- 覆盖全部影响产物的输入：文件哈希/锁/配置/白名单环境变量
- 环境变量白名单过滤非确定噪声
- 能讨论遗漏输入导致「假命中」的风险（加分）
