## MFW-471：流式响应晚到错误注入器
**需求**：流已 flush 壳之后洞才报错：实现 `LateErrorRouter`：1) `begin(res)` 记录 `headersSent` 状态：未发送 → 直接改写 500 错误页；已发送 → 不可改状态码，改为向流内注入可执行错误片段；2) `fail(slotId, err)`：已发送时写出 `<script>$RE(slotId, payload)</script>`，客户端脚本把洞替换为错误卡片 + 上报；3) payload 必须白名单化（只留 name/message/slotId，剥 stack——不泄露服务端路径）；4) 全部错误聚合到 `errors[]` 供 instrumentation 上报。

```javascript
const esc = s => s.replace(/<\/script/gi, '<\\/script')

export class LateErrorRouter {
  constructor() { this.sent = false; this.errors = [] }

  async begin(res, shell) {
    this.res = res
    await res.write(shell)
    this.sent = true
  }

  fail(slotId, err) {
    this.errors.push({ slotId, name: err.name })
    const payload = JSON.stringify({   // 白名单，剥 stack
      slotId, name: err.name, message: String(err.message).slice(0, 200),
    })
    if (!this.sent) {
      this.res.status = 500
      return this.res.end(`<h1>Server Error</h1>`)
    }
    return this.res.write(
      `<script>$RE(${JSON.stringify(slotId)},${esc(payload)})</script>`)
  }

  async end() {
    if (this.errors.length) {
      await this.res.write(
        `<script>window.__streamErrors=${esc(JSON.stringify(this.errors))}</script>`)
    }
    await this.res.end()
  }
}
```

**评分点**：
- headersSent 分叉：未发改状态码 / 已发只能流内注入（HTTP 语义硬约束）
- 错误 payload 白名单剥 stack（stack 含路径与内部信息）
- 错误聚合到 instrumentation 出口（散落的 fail 也要有全量视图）
- `</script` 转义贯穿（message 内容不可信）
