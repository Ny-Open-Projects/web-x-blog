## MFW-430：MFM→430：预算表守门
**答**：实现 `buildLatencyBudgets(blueprint, rum, { slack = 0.15 } = {})`：1) 初始表：按 MFW-341 三问模式给默认档（ssg 250/isr 500/ssr 800/action 1200ms）——蓝图缺失路由用模式默认；2) 用 RUM 实测校准（P75 实测 >1.2× 默认 → 该路由预算上调至 P90+slack——预算贴现实不贴愿望）；3) 守门：CI 性能快照（MFW-265）超路由预算 → fail 并输出「超了谁的钱」（DB 段 vs 渲染段分账）；4) 表版本化（每次校准 diff 记录——预算变更可追溯）。

```javascript
export function buildBudgets(bp, rum, { slack = 0.15 } = {}) {
  const out = {}, changed = []
  for (const [route, bp1) of Object.entries(blueprint)) {
    const p = profOf(bp1.mode)                                // 模式默认
    const real = quantile(rum[route] ?? [], 0.75)
    const budget = real && real > 1.2 * p ? Math.round(p90(rum[route]) * (1 + slack))) : p
    if (budget !== prev?.[route]) changed.push({ route, from: prev?.[route], to: budget, via: real ? 'calibrated' : 'default' })
    out[route] = { ttfb: budget, db: Math.round(budget * 0.6) }   // 分账子预算
  }
  return { table: out, changedDiff: changed }                 // gate: ci perf snap vs table
}
```
**评分点**：
- 模式默认 + 实测校准双轨（预算贴 P90+slack——不贴愿望也不放任）
- 分账子预算（TTFB 里 DB 占比声明——超限归因有靶）
- 校准 diff 版本化（预算上调是评审事件不是静默漂移）
