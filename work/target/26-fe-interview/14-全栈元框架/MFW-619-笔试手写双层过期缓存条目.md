## MFW-619：笔试：手写双层过期缓存

**答**：实现 `class TieredDataCache(cap, { defaultTtlMs, now })`。方法：`set(key, value, { revalidateSec?, tags? })`、`get(key)`、`revalidateTag(tag)`。规则：1) **LRU 物理层**：cap 上限，超出淘汰最久未访问条目；2) **逻辑层**：revalidateSec 过期——get 返回 `{ value, stale: true }`（逻辑过期但仍返回值——stale-while-revalidate：调用方决定重取）；3) revalidateTag：按 tags 反向索引删除（逻辑失效——下次 get miss）；4) get 命中即刷新 LRU 位；5) revalidateSec 缺省 defaultTtlMs。返回 get：`{ value, stale }` 或 null。边界：cap=0（set 即丢——不缓存）；同 key 覆盖（LRU 位刷新 + tags 重挂）；tag 交叉（一条目多 tag——任一 tag 失效即删）。

```javascript
class TieredDataCache {
  constructor(cap, { defaultTtlMs = 60000, now = Date.now } = {}) {
    this.cap = cap; this.defaultTtl = defaultTtlMs; this.now = now;
    this.store = new Map();                              // Map 迭代序 = 插入序（LRU）
    this.tagIndex = new Map();                           // tag -> Set<key>
  }
  set(key, value, { revalidateSec, tags = [] } = {}) {
    if (this.cap <= 0) return;
    if (this.store.has(key)) this.store.delete(key);     // 覆盖：先删后插（刷新 LRU 位）
    while (this.store.size >= this.cap) {                // LRU 淘汰
      const oldest = this.store.keys().next().value;
      this._delete(oldest);
    }
    this.store.set(key, { value, tags,
      expiresAt: this.now() + (revalidateSec ?? this.defaultTtl / 1000) * 1000 });
    for (const t of tags) {
      (this.tagIndex.get(t) || this.tagIndex.set(t, new Set()).get(t)).add(key);
    }
  }
  get(key) {
    const e = this.store.get(key);
    if (!e) return null;
    this.store.delete(key); this.store.set(key, e);      // LRU touch
    const stale = this.now() > e.expiresAt;
    return { value: e.value, stale };                    // 逻辑过期仍返回值
  }
  revalidateTag(tag) {
    for (const key of this.tagIndex.get(tag) ?? []) this._delete(key);
  }
  _delete(key) {
    const e = this.store.get(key);
    if (!e) return;
    this.store.delete(key);
    for (const t of e.tags) this.tagIndex.get(t)?.delete(key);
  }
}

// 自测
const nowState = { t: 1000 };
const c = new TieredDataCache(2, { defaultTtlMs: 60000, now: () => nowState.t });
c.set('a', 'A', { tags: ['x'] });
c.set('b', 'B');
console.log(c.get('a').value === 'A' && c.get('a').stale === false);
// LRU：cap=2，set c 淘汰最久未访问的 b（a 刚被 get touch）
c.set('c', 'C');
console.log(c.get('b') === null && c.get('a').value === 'A');   // b 被淘汰，a 保留

// 逻辑过期：stale 标记（值仍返回）
nowState.t += 70000;                                     // 过了 TTL
const r = c.get('a');
console.log(r.stale === true && r.value === 'A');        // stale-while-revalidate

// tag 失效
nowState.t = 1000;
c.set('p1', 'P1', { tags: ['product', 'list'] });
c.set('p2', 'P2', { tags: ['product'] });
c.revalidateTag('product');
console.log(c.get('p1') === null && c.get('p2') === null);   // 两 key 都被删
console.log(c.get('b') === null);                        // list tag 未动

// cap=0
const c0 = new TieredDataCache(0, { now: () => nowState.t });
c0.set('x', 'X');
console.log(c0.get('x') === null);
```

**评分点**：
- LRU 正确（Map 迭代序实现——touch 刷新 + cap 淘汰）；逻辑过期返回 stale 值（SWR 语义）
- tag 反向索引失效（多 tag 条目的交叉删除）；cap=0 的防御
- 双层过期分工：LRU 管容量、TTL/标签管新鲜度——两层缺一不可
- 能说清「只有 TTL = 冷门条目永驻占容量；只有 LRU = 热门条目被误删——逻辑与物理过期互补」属于加分
