## MFW-218：自建的文件路由与分割

**答**:
- 文件路由实现：构建期扫描 routes 目录（fs.readdir 递归）→ 生成路由表模块（虚拟模块——Vite 虚拟模块协议最顺手）→ 运行时匹配（radix tree 或简单正则表）
- 代码分割：路由级动态 import（路由表值是 () => import('./pages/home')）——构建器按入口自动分 chunk；SSR 侧同一路由表服务端加载（SSR import 不需要懒——直接 await）
- SSR/CSR 路由表同构：一份路由表两处消费（服务端匹配渲染、客户端导航懒加载）——同构的关键是「表结构一致、加载方式分环境」
- 布局嵌套：目录结构表达（app/posts/_layout.tsx）→ 构建期组装嵌套组件树——避免运行时递归查找的开销

```javascript
// 虚拟模块生成路由表（Vite）
export default function routesPlugin() {
  const load = () => scanRoutes('src/pages')        // 构建期扫描
  return {
    name: 'routes',
    resolveId: (s) => s === 'virtual:routes' ? '\0routes' : null,
    load: () => `export const routes = ${JSON.stringify(routesToModule(load())})`,
  }
}
// 产物形如：[{ path: '/', load: () => import('/src/pages/index') }]
```
