## MFW-742：笔试：手写乐观值生命周期

**答**：实现 `OptimisticValueSim`。规则：1) `add(delta)`：乐观值 += delta（累积）；2) `revalidate(serverValue)`：乐观值被 server 真值替换（重置）；3) `rollback()`：乐观值回到 revalidate 前的 server 值（失败回滚 RBL-513）；4) `getState()` 返回 `{ optimistic, server, isPending }`——isPending = 有乐观 delta 未被 revalidate；5) **连续 revalidate**：revalidate 更新 server 值 → isPending = false（乐观完成）；revalidate 后 add → 新一轮乐观。边界：add 0（isPending 仍 true——有 pending 意图）；revalidate 无 add（isPending false 不变）；连续 add 后 rollback（全部回滚到 server 值）。

```javascript
class OptimisticValueSim {
  constructor(initial) { this.server = initial; this.deltas = []; }
  add(delta) { this.deltas.push(delta); }
  revalidate(serverValue) {
    this.server = serverValue;                           // 真值更新
    this.deltas = [];                                    // 乐观完成
  }
  rollback() {
    this.deltas = [];                                    // 回滚：清 delta（回到 server 值）
  }
  get optimistic() {
    return this.server + this.deltas.reduce((s, d) => s + d, 0);
  }
  getState() {
    return { optimistic: this.optimistic, server: this.server,
      isPending: this.deltas.length > 0 };
  }
}

// 自测
const sim = new OptimisticValueSim(10);
// 初始
console.log(sim.getState().optimistic === 10 && sim.getState().isPending === false);
// 乐观 add
sim.add(1);
console.log(sim.getState().optimistic === 11 && sim.getState().isPending === true);
// 快速双击（两次 add）
sim.add(1);
console.log(sim.getState().optimistic === 12);
// revalidate：server 确认 +2
sim.revalidate(12);
console.log(sim.getState().optimistic === 12 && sim.getState().isPending === false);
console.log(sim.getState().server === 12);               // server 真值更新

// revalidate 后新一轮 add
sim.add(-1);                                             // unlike
console.log(sim.getState().optimistic === 11 && sim.getState().isPending === true);

// 失败回滚
sim.rollback();
console.log(sim.getState().optimistic === 12 && sim.getState().isPending === false);
console.log(sim.getState().server === 12);               // 回到 server 值

// revalidate 无 add（isPending 不变）
sim.revalidate(15);                                      // server 直接更新（他人操作）
console.log(sim.getState().optimistic === 15 && sim.getState().isPending === false);
// add 0
sim.add(0);
console.log(sim.getState().isPending === true);          // 有 pending 意图
```

**评分点**：
- 乐观生命周期三态：idle → pending(乐观累积) → revalidate(真值替换) 或 rollback(回滚)
- 连续 add 累积（双击 = +2——乐观值的数学语义）；revalidate 后 server 更新（乐观完成）
- 边界（add 0 的 pending 意图/revalidate 无 add/回滚）；isPending 的语义 = 有未确认 delta
- 能说清「乐观值是等待 server 确认的临时状态——revalidate 后被真值替换是 React 设计而非 bug」属于加分
