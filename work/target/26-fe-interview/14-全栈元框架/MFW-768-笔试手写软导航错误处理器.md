## MFW-768：笔试：手写软导航错误处理

**答**：实现 `createSoftNavErrorHandler({ onRetry, onBack })`。规则：1) 处理 payload fetch 失败：`handleNavError(url, error)` → 决策 `{ action: 'retry'|'back'|'error-page', keepUrl: boolean }`。2) 404 → error-page（URL 保持——not-found.tsx）；3) 网络错误（fetch TypeError/AbortError）→ retry（URL 保持——重试语义）；4) 500 → retry（server 临时错误）；5) **重试次数限制**：同 URL 连续失败 ≥3 → 'error-page'（熔断 RBL-672）；6) 重试计数重置（成功后清零；不同 URL 独立计数）。返回 `{ handleNavError, retryCount(url) }`。边界：无 error type（默认 retry）；URL 无失败记录（从 0 开始）；重试成功后计数归零。

```javascript
function createSoftNavErrorHandler({ onRetry = () => {}, onBack = () => {} } = {}) {
  const failCounts = new Map();                          // url -> count
  function handleNavError(url, error) {
    const type = error?.type ?? (error instanceof TypeError ? 'network' : 'unknown');
    const status = error?.status;
    // 404：error-page
    if (status === 404)
      return { action: 'error-page', keepUrl: true, detail: 'Not Found' };
    // 重试熔断
    const count = (failCounts.get(url) ?? 0) + 1;
    failCounts.set(url, count);
    if (count >= 3)
      return { action: 'error-page', keepUrl: true, detail: `连续 ${count} 次失败——熔断` };
    // 网络错误 / 500 → retry（URL 保持）
    if (type === 'network' || status === 500 || status === 503)
      return { action: 'retry', keepUrl: true, detail: `第 ${count} 次失败，重试中` };
    // 未知 → retry
    return { action: 'retry', keepUrl: true };
  }
  function markSuccess(url) { failCounts.delete(url); }  // 成功清零
  function retryCount(url) { return failCounts.get(url) ?? 0; }
  return { handleNavError, markSuccess, retryCount };
}

// 自测
const handler = createSoftNavErrorHandler({});
// 404 → error-page
let r = handler.handleNavError('/ghost', { status: 404 });
console.log(r.action === 'error-page' && r.keepUrl === true);
// 网络错误 → retry
r = handler.handleNavError('/a', { type: 'network' });
console.log(r.action === 'retry' && r.keepUrl === true);
// 连续失败熔断
handler.handleNavError('/b', { status: 500 });           // 1
handler.handleNavError('/b', { status: 500 });           // 2
r = handler.handleNavError('/b', { status: 500 });       // 3 → 熔断
console.log(r.action === 'error-page' && r.detail.includes('熔断'));
// 成功后清零
handler.markSuccess('/b');
console.log(handler.retryCount('/b') === 0);
r = handler.handleNavError('/b', { status: 500 });
console.log(r.action === 'retry');                       // 计数重置
// 不同 URL 独立
console.log(handler.retryCount('/c') === 0);             // /c 从 0 开始
// 未知错误
r = handler.handleNavError('/d', { type: 'unknown' });
console.log(r.action === 'retry');
```

**评分点**：
- 决策树完整：404 → error-page / network+500 → retry / 熔断 → error-page
- 熔断语义（同 URL ≥3 次 → 熔断——防无限重试 RBL-672）；成功清零（重置计数）
- 边界（404/网络/500/未知/不同 URL 独立）；keepUrl 策略（保持 URL 显示错误）
- 能说清「软导航错误比硬导航复杂：URL 已变 → 保持（重试）或回滚——Next 默认保持 + 重试按钮」属于加分
