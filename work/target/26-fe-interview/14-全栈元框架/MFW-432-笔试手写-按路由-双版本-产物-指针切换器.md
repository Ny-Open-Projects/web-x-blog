## MFW-432：MFM→432：路由指针切换
**答**：实现 `createRoutePin(kv, history)`（MFW-381 执行器）：1) 状态：`{ '/checkout': { active: 'v41', shadow: 'v40' } }`——发布写 shadow→验证→promote(active)；2) `promote(route, version)：校验该版本 manifest 完整（head 全文件——半发布禁切）→ 原子写指针（版本号 CAS 防并发发布互踩）→ 记录审计；3) rollback(route) = swap active/shadow（O(1) 秒级）；4) 自动回滚定时器（promote 时挂 15min 确认窗——错误率阈值超限自动 swap 回+告警）；5) 约束：数据迁移版本与渲染版本解耦声明（渲染回滚不禁用已迁移数据——MFW-381 红线落地）。

```javascript
export function createRouterPointer(kv, { verifyIn, autoMs = 900_000 } = {}) {
  async function promote (route, v, { by }) {
    const rec = await loadState(route)
    const ok = await verifyCompleteFull(v)                   // head 全清单
    if (!ok) throw new Error(`incomplete build ${v}`)
    const updated = await store.setC AS(`rt:${route}`, { active: v, shadow: rec.active },
      { expect: { v: rec.rev + 1 } })                        // CAS 防并发发布踩
    scheduleWatchdog(s, route, rec.active, autoMs)           // 错误率超限自动换回
    audit.push({ route, from: rec.active, to: v, by, at: now() })
  }
  const rollback = (route, by) => swap(route, by)            // O(1)
  return { promote, rollback, stateOf: (r) => kv.get(`rt:${r}`) }
}
```
**评分点**：
- shadow→验证→promote 三步（半发布禁切——用户永不见缺文件态）
- CAS 版本防并发发布互踩 + 自动回滚 watchdog（错误率联动）
- O(1) swap 回滚（秒级止血）
- 渲染/数据解耦声明（回滚不撤销迁移——红线成字段）
