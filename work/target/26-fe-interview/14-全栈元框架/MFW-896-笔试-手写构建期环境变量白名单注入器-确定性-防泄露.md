## MFW-896：笔试：手写构建期环境变量白名单注入器（确定性 + 防泄露）

**答**：
- 结论：只把白名单内的确定性变量注入产物，其余一律不注入；同时对值做校验，避免时间戳/随机值/secrets 破坏确定性或造成泄露。
- 关键：白名单按前缀匹配（如 NEXT_PUBLIC_），值需可序列化且非敏感；注入结果稳定排序。
- 追问钩子：用户误把 SECRET 放进白名单怎么办？——注入时扫描值特征（如密钥长度/前缀）告警并拒绝。

```javascript
const SENSITIVE = /(sk_|pk_|secret|password|token)/i;
function injectEnv(env, whitelistPrefix = 'NEXT_PUBLIC_') {
  const out = {};
  for (const key of Object.keys(env).sort()) {
    if (!key.startsWith(whitelistPrefix)) continue;  // 仅白名单前缀
    const val = env[key];
    if (SENSITIVE.test(key) || SENSITIVE.test(val))
      throw new Error('疑似敏感变量被注入: ' + key);   // 防泄露
    out[key] = val;
  }
  return out;                                        // 稳定排序的对象
}
// 自测
const env = { NEXT_PUBLIC_API: 'https://api', NEXT_PUBLIC_TS: '123', SECRET_KEY: 'sk_xxx' };
const injected = injectEnv(env);
console.log(Object.keys(injected).join(',') === 'NEXT_PUBLIC_API,NEXT_PUBLIC_TS'); // true
```

**评分点**：
- 仅白名单前缀注入，过滤非公开变量
- 敏感值检测（key/value 特征）并拒绝，防 secrets 泄露
- 稳定排序保证注入确定性
- 边界：非字符串值、空值、白名单前缀误配（加分）
