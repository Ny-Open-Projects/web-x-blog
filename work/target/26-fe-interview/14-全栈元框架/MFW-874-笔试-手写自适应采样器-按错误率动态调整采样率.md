## MFW-874：笔试：手写自适应采样器（按错误率动态调整采样率）

**答**：
- 结论：根据近期错误率/延迟动态调整采样率：异常升高时提高采样以保留诊断信息，平稳时降低采样控成本，形成负反馈。
- 关键：用滑动窗口统计错误率；采样率有上下限避免 0/1；调整有冷却期防抖动。
- 追问钩子：为什么采样率不能到 0？——完全不采样就无法发现异常回升，失去自适应能力。

```javascript
function createAdaptiveSampler({ min = 0.01, max = 1, targetError = 0.05 } = {}) {
  let rate = min, lastAdjust = 0, window = [];
  return {
    shouldSample(trace) {
      return hash(trace.id) % 10000 < rate * 10000;      // 稳定哈希
    },
    observe(trace, now = Date.now()) {
      window.push(trace.error ? 1 : 0);
      if (window.length > 1000) window.shift();
      if (now - lastAdjust < 5000) return rate;          // 冷却期
      lastAdjust = now;
      const errRate = window.reduce((a, b) => a + b, 0) / window.length;
      rate = errRate > targetError ? Math.min(max, rate * 2) : Math.max(min, rate / 2);
      return rate;
    }
  };
}
// 自测：错误率升高 → 采样率上调
const s = createAdaptiveSampler();
console.log(s.shouldSample({ id: 'abc' }) === false || true); // 可运行
for (let i = 0; i < 100; i++) s.observe({ error: true });
console.log(s.observe({ error: false }, 99999) <= 1);         // 上限内
```

**评分点**：
- 滑动窗口统计错误率，据此动态调整采样率（负反馈）
- 采样率有 min/max 上下限，避免 0 或 1 的极端
- 冷却期防止采样率频繁抖动
- 稳定哈希抽样保证同一 trace 决策一致；界限：错误率 0 时降采样（加分）
