## MFW-825：怎么发现并修复多区域之间的数据不一致（反熵对账）

**答**：
- 结论：对账 = 定期比较各区数据摘要（Merkle tree / 版本向量），差异定位到具体键；修复 = 以权威副本为准 read-repair 或后台同步（反熵）。
- 落地：维护 per-key 版本向量 + 周期交换摘要；摘要不同才逐 key 比对，避免全量传输。
- 追问钩子：对账频率如何定？——按一致性 SLA，越高频成本越高；关键数据近实时、普通数据分钟级。

```javascript
// 用哈希摘要比较两区数据，差异才逐 key 拉取
function merkleRoot(kv) {
  const hashes = Object.keys(kv).sort().map(k => hash(k + ':' + kv[k].version));
  return hashes.reduce((acc, h) => hash(acc + h), '');
}
function hash(s) { /* 简化：真实用 sha256 */ return '' + s.length + s.charCodeAt(0); }

async function antiEntropy(localKV, remote) {
  const remoteRoot = await remote.root();          // 远端摘要
  if (merkleRoot(localKV) === remoteRoot) return;  // 一致，零传输
  const diff = await remote.diffKeys(merkleRoot(localKV));
  for (const key of diff) {
    const theirs = await remote.get(key);
    if (theirs.version > (localKV[key]?.version ?? 0))
      localKV[key] = theirs;                       // 以新版本修复
  }
}
```
