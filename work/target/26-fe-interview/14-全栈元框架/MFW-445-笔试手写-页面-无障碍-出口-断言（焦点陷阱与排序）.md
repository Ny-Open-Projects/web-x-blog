## MFW-445：a11y 出口断言
**答**：实现 `a11yGate(page, { rules }) `（构建产物级而非运行时全量）：1) 静态规则：img 缺 alt / 表单无 label / heading 跳级（h2→h4）/ landmark 重复 main——SSG HTML 直接 DOM 解析断言；2) 焦点链：Tab 序模拟（可交互元素序 = DOM 序或显式 tabindex 合理）+ 弹窗 opened 后焦点入框（focus trap 存在性——data-attr 约定检测）；3) 对比度抽检（主题变量组合计算——暗色主题遗漏白字白底类错误）；4) 分级：critical（键盘不可达）fail / advisory（对比度边缘）warn；5) 与流式共存：断言跑在「最终 HTML」（流式完成态——不是首屏截断）。

```javascript
export async function a11y (html, { themePairs = [['light'], ['dark']] } = {}) {
  const dom = parse (html)
  const errs = [], warns = []
  dom('img:not([alt])').each(x => errs.push({ r: 'img-alt', at: pathOf(x) })))
  headingsSeq (dom).filter(j => j.jump > 1).forEach(h => warns.push({ r: 'h-skip', at: h }))
  if (dom('[role=dialog]').length && !dom('[data-focus-trap]').length)
    errs.push({ r: 'trap-missing' })
  for (const th of themePairs) {
    const bad = contrastScan(dom, cssVars(th))
    bad.critical ? errs.push(...bad.list) : warns.push(...bad.list)
  }
  return { pass: !errs.length, errs, warns, note: '跑在流式完成态 HTML' }
}
```
**评分点**：
- 五规则典型面（alt/label/跳级/trap/对比度——最高频 WCAG 违例）
- 双主题计算（暗色遗漏是主题化站点特有坑）
- 流式完成态（截断 HTML 误报——元框架特有注意点）
- 分级出口（键盘不可达=阻断；对比度=债务清单）
