## MFW-827：什么场景需要把用户粘到固定边缘区域，怎么实现且不牺牲容灾

**答**：
- 结论：长连接/有状态会话（IM、协同编辑、事务草稿）需要区域亲和；用一致性哈希把 sessionId 映射到主区，cookie 记录区域，故障时通过「接管者」重映射。
- 落地：session→region 映射写全球 KV，请求先查映射再路由；健康检查失败切备用区并更新映射（带 TTL + fencing 防脑裂）。
- 追问钩子：粘滞与负载均衡冲突怎么办？——只对有状态请求粘滞，无状态请求照常就近，分层路由。

```javascript
function hashRing(key, ring) {
  const h = fnv(key);
  return ring.find(n => h <= n.upper) || ring[0];   // 一致性哈希
}
async function route(req) {
  const sid = req.cookies.get('sid') || (req.cookies.set('sid', genId()), genId());
  if (!req.sessionBacked) return nearest(req);      // 无状态：就近
  let region = await globalKV.get('region:' + sid);
  if (!region || !(await healthy(region))) {        // 失效/不健康 → 接管
    region = hashRing(sid, RING);
    await globalKV.set('region:' + sid, region, { ttl: 3600 });
  }
  return region;
}
function fnv(s) { let h = 2166136261; for (const c of s) h = (h ^ c.charCodeAt(0)) * 16777619; return h >>> 0; }
```
