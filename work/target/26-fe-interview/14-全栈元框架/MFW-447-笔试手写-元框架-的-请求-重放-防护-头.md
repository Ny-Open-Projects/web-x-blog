## MFW-447：MFM→447：重放防护
**答**：实现 `nonceGuard(scope, { windowMs = 300_000 } = {})`：1) 客户端：动作准备时取一次性 nonce（GET /nonce?scope=pay——绑定会话+域，5min 有效）→ 提交携带；2) 服务端：原子消费（Redis SET NX——同 nonce 二次提交拒绝）+ 与会话绑定（token A 的 nonce 不能被会话 B 用——横向搬运防护）；3. 时钟与延迟容忍：nonce 过期给明确错误码（NONCE_EXPIRED 可重取——不是笼统 400）；4. 限速联动：nonce 获取端点本身限流（攻击者刷 nonce=消耗配额——防护资源化）。

```javascript
// server
const nonce = {
  issue: withAuth(async (user, domain) => {
    const n = crypto.randomBytes(16).toString('base64url')
    await redis.set(`n:${user.id}:${dom}:${n}`, 1, 'NX', 'PX', windowMs)   // 会话+域绑定
    return { nonce: n, expiresInMs: windowMs }
  }),
  consume: withAuth(async (user, domain, n) => {
    const ok = await redis.eval(`
      if redis.call('GET', KEYS[1]) then
        return redis.call('DEL', KEYS[1])                  // 原子消费：GET+DEL 一体
      else return 0 end`, 1, `n:${user.id}:${domain}:${n}`)
    if (!ok) throw new AppError('nonce_invalid_or_expired') // 明确码→前端自动重取重试
  }),
}
// 客户端 useSubmit: const { nonce } = await api.nonce('pay'); await api.pay({ ..., nonce })
```
**评分点**：
- 会话+域绑定（nonce 不可横向搬运——单维随机数不够）
- GET+DEL Lua 原子（检查与消费竞态消除——两步 Redis 会双花）
- 明确错误码（EXPIRED 自动重取重试——UX 与安全兼得）
- 获取端点限流（防护自身资源化）
