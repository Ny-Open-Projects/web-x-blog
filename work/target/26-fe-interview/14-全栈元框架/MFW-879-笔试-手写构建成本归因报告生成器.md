## MFW-879：笔试：手写构建成本归因报告生成器

**答**：
- 结论：把构建流水线的各阶段耗时与失败情况聚合成报告，按阶段归因瓶颈（依赖安装/编译/测试/上传），并计算缓存命中率。
- 关键：用稳定哈希做缓存键；报告含每阶段耗时、命中率、成本估算与优化建议。
- 追问钩子：为什么按阶段拆分归因？——全局时长只知道「慢」，拆分才能定位到具体阶段对症下药。

```javascript
function generateBuildReport(builds) {
  const stages = new Map();
  let hits = 0, total = 0;
  for (const b of builds) {
    total++;
    if (b.cacheHit) hits++;
    for (const [name, ms] of Object.entries(b.stages || {})) {
      const s = stages.get(name) || { name, totalMs: 0, n: 0 };
      s.totalMs += ms; s.n++; stages.set(name, s);
    }
  }
  const breakdown = [...stages.values()]
    .map(s => ({ ...s, avgMs: Math.round(s.totalMs / s.n) }))
    .sort((a, b) => b.totalMs - a.totalMs);
  return { builds: total, hitRate: +(hits / total).toFixed(2), bottleneck: breakdown[0]?.name, breakdown };
}
// 自测
const builds = [
  { cacheHit: false, stages: { install: 5000, compile: 20000, test: 8000 } },
  { cacheHit: true, stages: {} }
];
console.log(generateBuildReport(builds).bottleneck); // compile
```

**评分点**：
- 按阶段聚合耗时并排序，定位瓶颈阶段（compile 等）
- 计算缓存命中率，纳入报告
- 输出可执行的优化归因（bottleneck 字段）
- 边界：空 stages、cacheHit 统计、avgMs 计算正确
