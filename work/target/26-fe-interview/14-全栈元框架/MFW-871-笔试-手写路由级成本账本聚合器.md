## MFW-871：笔试：手写路由级成本账本聚合器

**答**：
- 结论：按路由维度聚合多次请求的消耗（DB ms、出站次数、边缘时长），输出可排序的成本排行，定位高成本低价值路由。
- 关键：用加权公式折算统一成本分；按路由分组累加并排序；异常负值/缺失字段做防御。
- 追问钩子：为什么成本要按路由而非全局？——全局均值会被大量廉价请求稀释，掩盖少数昂贵路由。

```javascript
function aggregateCost(records) {
  const byRoute = new Map();
  for (const r of records) {
    const key = r.route || '(unknown)';
    const acc = byRoute.get(key) || { route: key, dbMs: 0, outCalls: 0, edgeMs: 0, n: 0 };
    acc.dbMs += Math.max(0, r.dbMs || 0);
    acc.outCalls += Math.max(0, r.outCalls || 0);
    acc.edgeMs += Math.max(0, r.edgeMs || 0);
    acc.n++;
    byRoute.set(key, acc);
  }
  const PRICE = { db: 0.001, out: 0.5, edge: 0.0001 };
  return [...byRoute.values()].map(a => ({
    ...a,
    cost: +(a.dbMs * PRICE.db + a.outCalls * PRICE.out + a.edgeMs * PRICE.edge).toFixed(2)
  })).sort((x, y) => y.cost - x.cost);
}

// 自测
const recs = [
  { route: '/checkout', dbMs: 300, outCalls: 4, edgeMs: 120 },
  { route: '/home', dbMs: 20, outCalls: 0, edgeMs: 30 },
  { route: '/checkout', dbMs: 100, outCalls: 1, edgeMs: 50 }
];
console.log(aggregateCost(recs)[0].route); // checkout（成本最高）
```

**评分点**：
- 按路由分组累加消耗，而非全局平均（避免掩盖昂贵路由）
- 加权折算统一成本分并降序排序，输出可定位的热点排行
- 边界防御：unknown 路由、负值/缺失字段处理
- 能讨论成本指标应全采、trace 才抽样（加分）
