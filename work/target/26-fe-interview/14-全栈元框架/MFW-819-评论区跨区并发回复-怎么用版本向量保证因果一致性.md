## MFW-819：评论区跨区并发回复，怎么用版本向量保证因果一致性

**答**：
- 结论：分布式系统无全局时钟，用向量时钟表达「因果先后」：向量 A 支配 B 说明 A 在 B 之后；互不安支配即并发，保留分支供合并或按规则排序。
- 落地：每条回复带 vector clock，服务端检测支配关系决定排序/隐藏，客户端合并并发分支。
- 追问钩子：向量时钟和 HLC 的区别？——向量精确捕捉因果但随节点数膨胀；HLC 用单值近似且有界。

```javascript
// 向量时钟：a 支配 b 当且仅当 a 各分量 >= b 且至少一个 >
function dominates(a, b) {
  let strictlyGreater = false;
  for (const k of new Set([...Object.keys(a), ...Object.keys(b)])) {
    if ((a[k] || 0) < (b[k] || 0)) return false;
    if ((a[k] || 0) > (b[k] || 0)) strictlyGreater = true;
  }
  return strictlyGreater;
}
function relation(a, b) {
  if (dominates(a, b)) return 'a-after-b';
  if (dominates(b, a)) return 'b-after-a';
  return 'concurrent';                              // 并发：无因果
}
console.log(relation({ A: 2, B: 0 }, { A: 1, B: 0 })); // a-after-b
console.log(relation({ A: 1, B: 0 }, { A: 0, B: 1 })); // concurrent
```
