## MFW-681：笔试：手写内存泄漏斜率检测

**答**：实现 `detectMemoryLeak(samples, { slopeThresholdMB, windowSize })`。samples: `{ t, rss }[]`（MB，时间序）。规则：1) 滑动窗口线性回归（windowSize 个采样的斜率——最小二乘）；2) 斜率 > slopeThresholdMB（默认 0.5MB/采样）→ leak 信号；3) **噪声过滤**：GC 回落（RSS 骤降 = GC 而非泄漏——斜率计算用窗口内连续段（GC 断点后重算））；4) 返回 `{ leak, slope, confidence, windowStart }`（confidence = 斜率连续超标次数）。边界：samples < windowSize（no-data）；全零 RSS（无增长）；斜率恰好等于阈值（不报——严格大于）。

```javascript
function detectMemoryLeak(samples = [], { slopeThresholdMB = 0.5, windowSize = 20 } = {}) {
  if (samples.length < windowSize)
    return { noData: true, need: windowSize - samples.length };
  // GC 断点分段：RSS 骤降（< 前值的 70%）切段
  const segments = [];
  let seg = [samples[0]];
  for (let i = 1; i < samples.length; i++) {
    if (samples[i].rss < samples[i - 1].rss * 0.7) { segments.push(seg); seg = [samples[i]]; }
    else seg.push(samples[i]);
  }
  segments.push(seg);
  let leak = false, maxSlope = 0, confidence = 0;
  for (const seg of segments) {
    if (seg.length < windowSize) continue;
    for (let i = 0; i + windowSize <= seg.length; i++) {
      const w = seg.slice(i, i + windowSize);
      const slope = linearSlope(w);
      if (slope > slopeThresholdMB) {
        leak = true; maxSlope = Math.max(maxSlope, slope);
        confidence++;
      }
    }
  }
  return { leak, slope: +maxSlope.toFixed(2), confidence };
}
function linearSlope(w) {
  const n = w.length; const xs = w.map((_, i) => i);
  const ys = w.map(s => s.rss);
  const mx = xs.reduce((s, x) => s + x, 0) / n;
  const my = ys.reduce((s, y) => s + y, 0) / n;
  const num = xs.reduce((s, x, i) => s + (x - mx) * (ys[i] - my), 0);
  const den = xs.reduce((s, x) => s + (x - mx) ** 2, 0);
  return den ? num / den : 0;
}

// 自测
// 线性泄漏：0.8MB/采样
const leaking = Array.from({ length: 30 }, (_, i) => ({ t: i, rss: 100 + i * 0.8 }));
let r = detectMemoryLeak(leaking);
console.log(r.leak === true && r.slope >= 0.5 && r.confidence > 0);

// GC 回落分段
const withGC = [
  ...Array.from({ length: 15 }, (_, i) => ({ t: i, rss: 100 + i * 0.8 })),   // 增长
  { t: 15, rss: 80 },                                    // GC 回落（< 70%）
  ...Array.from({ length: 15 }, (_, i) => ({ t: 16 + i, rss: 80 + i * 0.1 })),   // 平稳
];
r = detectMemoryLeak(withGC);
console.log(r.leak === true);                            // 第一段检出泄漏
// GC 后段不误报
// 全平稳
const stable = Array.from({ length: 30 }, () => ({ t: 1, rss: 100 }));
console.log(detectMemoryLeak(stable).leak === false);
// no-data
r = detectMemoryLeak(Array.from({ length: 10 }, (_, i) => ({ t: i, rss: 100 + i })));
console.log(r.noData === true && r.need === 10);
```

**评分点**：
- 线性回归斜率（最小二乘——噪声鲁棒）；GC 断点分段（回落 70% 切段——平稳段不误报）
- confidence（连续超标次数——信号强度）；阈值严格大于
- 边界（no-data/平稳/GC 断点）；诚实标注（检测是信号不是诊断——heap diff 定位泄漏源）
- 能说清「内存检测是信号、heap snapshot diff 是诊断、LRU 是根治——三层各司其职」属于加分
