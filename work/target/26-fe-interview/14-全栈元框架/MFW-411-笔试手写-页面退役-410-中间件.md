## MFW-411：退役中间件
**答**：实现 `retireMiddleware(table)`（table 见 MFW-343 JSON）：1) 精确匹配 + 前缀通配（/old-campaign/*）；2) code 分派：301→Location=to（外链 SEO 权重转移）+`; 410→Gone 页（带替代建议链接）；3) until 过期自动摘除（外链自然衰减——表自清洁）；4) 命中计数（每条目 lastHit——90 天零命中提示清理）；5) 与 SSR 路由匹配顺序：退役表最先（旧路径永不进新渲染）。

```javascript
export function retire MW(table, now = Date.now()) {
  const exact = new Map(), prefixes = []
  for (const r of table) {
    if (new Date(r.until) < now) continue
    if (r.path.endsWith('/*')) prefixes.push({ re: globToRe(r.path), ...r })
    else exact.set(r.path, r)
  }
  return (req) => {
    const p = path(req)
    let hit = exact.get(p) ?? prefixes.find((x) => x.re.test(p))
    if (!hit) return passthrough()
    record.hit(hit.id)                                          // lastHit 审计
    if (hit.code === 301) return redirect(sefeUrl(hit.to), 301)
    return renderGone({ alt: hit.alt, sign: 410 })              // 410 + 替代建议
  }
}
// 注册序：退役表 → （其后才轮到）语言协商/鉴权/SSR
```
**评分点**：
- 301/410 语义分派正确（权重转移 vs 删档——SEO 信号准确）
- until 自清洁（表不无限增长）+ lastHit 审计（90 天清理依据）
- 前缀通配与精确共存（campaign 子页批量退）
- 注册序最先（死路径不进任何后置逻辑——安全与性能双收）
