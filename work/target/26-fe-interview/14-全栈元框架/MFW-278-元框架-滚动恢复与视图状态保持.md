## MFW-278：滚动恢复与状态保持

**答**:
- 框架默认语义：Back/Forward 恢复滚动（浏览器 API + 框架接管）、Push 导航回顶——列表→详情→返回应回到原位置（异步内容未就绪时恢复会失败——数据缓存命中是前提）
- 状态保持三工具：URL（筛选/页码——可分享最可靠）、客户端缓存（列表数据 Query 缓存——返回即命中不重拉）、模板级状态（SvelteKit snapshot / Vue keep-alive 等价物——表单半成品）
- 异步恢复次序：先恢复滚动锚点（记录 index+offset）→ 数据命中渲染等高行 → scrollTo 校准（ZSM-322 虚拟列表同款协议）
- 验收用例：进详情改数据→返回，列表该行更新且滚动位置保持——「数据新鲜」与「位置保持」要同时成立

```text
协议：URL 管可分享状态 / Query 管数据命中 / snapshot 管表单半成品
滚动：离开记 index+offset → 返回数据命中 → scrollToOffset 校准
验收：改详情回列表 = 新数据 + 原位置
```
