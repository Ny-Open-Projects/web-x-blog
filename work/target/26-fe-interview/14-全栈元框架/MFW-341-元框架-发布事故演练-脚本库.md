## MFW-341：演练脚本库八景

**答**:
- 元框架特有故障八景与断言：①半发布（html 新 chunk 缺）→ 断言拨测拦截②ISR 再生成风暴 → 队列限流生效③Middleware OTel 过载 → 10ms 预算熔断④Edge 数据面断连 → HTTP 驱动回退只读⑤双写窗口错位 → mismatch 告警触发⑥字体/CDN 域抖动 → 降级链切换⑦Action 幂等键冲突 → 去重生效⑧灰度比例误配 100% → 看板 SRM 秒级报警
- 脚本化结构：每景 { 注入器, 预期信号, 清理器, MTTR 目标 }——注入用平台 API（不 hack 生产配置）；预期信号 = 可观测指标阈值而非人工肉眼
- 运行节奏：发布流程变更后全量跑；每季度常态轮一个景（值班即训练）
- 演练产物：每景结果进 Runbook 更新 PR（发现的失效点=待修缺口清单——演练的输出是修复 backlog 不是报告归档）

```javascript
const SCENARIOS = {
  halfShip: { inject: () => cdn.dropPercent('chunks', 30),
    expect: (m) => m.probeBlocked === true && m.userVisible5xx === 0,
    cleanup: () => cdn.restore(), mttr: 60_000 },
  // ...8 景同构
}
async function drill(name) { const s = SCENARIOS[name]; await s.inject();
  const m = await observe(120_000); const ok = s.expect(m)
  await s.cleanup(); await fileRunbookPR({ name, ok, mttr: m.at - m.t0 })
  return { ok, mttr: m.at - m.t0 } }
```
