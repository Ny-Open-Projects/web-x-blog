## MFW→MFW-437：迁移 301 表
**需求**：实现 `migrationBundle(oldRoutes, newRoutes, { holdDays = 365 } = {})`：1) 生成：old 全集 → 相似度匹配新路由（同 slug 集合/参数形状——`/p/[id]` ↔ `/product/[pid']` 参数映射声明）→ 未匹配上 old → 410+替代建议页（不瞎 301 到首页——SEO 惩罚与用户迷惑双防）；2) 冲突检测：新路由被两个 old 映射（多对一允许但聚合警告）或成环（A→B 且 B→A——构建期压平）；3) 验收脚本：发布后抽样拨测 old 集合（断言 3xx Location 正确 + 终态 200 + 内容标记新栈——真到了新页面而非 404）；4) 到期清理：holdDays 后 301 保留（外链永续）但监控降频。

```javascript
export function makeMigration (olds, news, map) {
  const out = []
  for (const o of oldRoutes) {
    const t = bestMatch(o, newRoutes, by: (a,b) => slugOverlap(a,b)*2 + shapeEq (a,b)))
    if (!t) out.push({ from: o, code: 410, alt: nearestHub (o) })
    else out.push({ from: o.path, to: renderTo (t, o.paramsMap), code: 301 })
  }
  const cycle = findCycles (out)                              // A→B→A 压平
  const dupT = groupBy (target)  → multiSource warn
  return { entries: dedupeCicle (out), warnings: { multiTarget, cycles },
    probe: () => sample (out, 20).map (verify → { loc, final200, isNewStack })
}
```
**评分点**：
- 未匹配不瞎 301（410+建议——首页汇集是 SEO 反模式）
- 参数形状映射声明（动态段迁移核心——丢参数=内容丢失）
- 环压平+多对一聚合警告（表质量自检）
- 拨测验收含「终态 200 且新栈标记」（迁移成功=用户真到新页）
