## MFW-168：笔试：手写一个多级缓存（内存 + 模拟 Redis）与过期打散
**题目**：实现 `TwoTierCache`：① L1 进程内 Map（TTL 基础上 ±20% 抖动打散）；② L2 模拟 Redis（异步 get/set，本测试用 Map 实现）；③ 读取顺序 L1 → L2 → loader，L1 命中直接返回；④ L2 命中回填 L1；⑤ loader 失败时若 L2 有旧值返回旧值并记录警告；⑥ TTL=0 时不缓存。

```ts
class RedisSim {
  private store = new Map<string, { value: string; exp: number }>();
  async get(key: string): Promise<string | null> {
    const e = this.store.get(key);
    if (!e) return null;
    if (Date.now() > e.exp) { this.store.delete(key); return null; }
    return e.value;
  }
  async set(key: string, value: string, ttlMs: number): Promise<void> {
    this.store.set(key, { value, exp: Date.now() + ttlMs });
  }
}

interface Entry { value: unknown; exp: number }

export class TwoTierCache {
  private l1 = new Map<string, Entry>();
  constructor(
    private l2: RedisSim,
    private jitterRatio = 0.2, // ±20% 打散
  ) {}

  /** 基础 TTL 加抖动：base ± base*jitterRatio，防大量 key 同时过期 */
  private jitteredTtl(base: number): number {
    if (base <= 0) return 0;
    const delta = base * this.jitterRatio;
    return Math.round(base - delta + Math.random() * delta * 2);
  }

  async get<T>(key: string, loader: () => Promise<T>, ttlMs: number): Promise<T> {
    // L1 命中
    const hit = this.l1.get(key);
    if (hit && Date.now() < hit.exp) return hit.value as T;

    // L2 命中：回填 L1（L1 TTL 用更短值，防与 L2 同步过期）
    const raw = await this.l2.get(key);
    if (raw) {
      const value = JSON.parse(raw) as T;
      const l1Ttl = Math.max(1000, Math.floor(ttlMs / 4));
      this.l1.set(key, { value, exp: Date.now() + this.jitteredTtl(l1Ttl) });
      return value;
    }

    // miss -> loader
    try {
      const value = await loader();
      if (ttlMs > 0) {
        const ttl = this.jitteredTtl(ttlMs);
        await this.l2.set(key, JSON.stringify(value), ttl);        // L2 用原始序列化值
        this.l1.set(key, { value, exp: Date.now() + Math.max(1000, Math.floor(ttl / 4)) });
      }
      return value;
    } catch (err) {
      // ⑤ loader 失败：尝试 L2 旧值兜底（即使过期也不主动清掉的 stale 策略）
      // 此处模拟：RedisSim 已过期返回 null，若实现层保留 stale 副本则可用
      const stale = await this.l2.get('stale:' + key);
      if (stale) {
        console.warn(`[cache] ${key} loader 失败，返回 stale 值`);
        return JSON.parse(stale) as T;
      }
      throw err;
    }
  }

  async set<T>(key: string, value: T, ttlMs: number): Promise<void> {
    if (ttlMs <= 0) return; // ⑥ 不缓存
    const ttl = this.jitteredTtl(ttlMs);
    await this.l2.set(key, JSON.stringify(value), ttl);
    await this.l2.set('stale:' + key, JSON.stringify(value), ttl * 5); // stale 副本更长
    this.l1.set(key, { value, exp: Date.now() + Math.max(1000, Math.floor(ttl / 4)) });
  }
}
```

**评分点**：
1. TTL 抖动公式正确（base ± ratio，或对称区间），并说明防雪崩动机。
2. L1/L2 TTL 分层（L1 更短），能说出防同层齐过期。
3. 读取顺序正确且 L2 命中回填 L1。
4. stale 副本兜底：loader 失败返回旧值比抛错更可用（stale-while-error）。
5. ttlMs<=0 直接跳过缓存写入。
