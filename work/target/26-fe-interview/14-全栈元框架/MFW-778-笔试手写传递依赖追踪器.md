## MFW-778：笔试：手写传递依赖

**答**：实现 `traceAffected(changed, importGraph, { filter })`。changed: 变更文件数组；importGraph: `Map<file, Set<file>>`（file → 谁 import 了它）。filter: `(path) => boolean`（过滤——只保留 page/layout）。规则：1) **传递追踪**：changed 的所有传递 importers（A imports Header、B imports A——Header 变 → B 也受影响）；2) 环保护（visited 集合——环不爆栈 RBL-657）；3) 过滤：只返回 filter 为 true 的路径（页面文件）；4) 返回 affected 排序数组。边界：changed 空（空）；importGraph 无 changed 的 entry（只 changed 自身——如果 filter 通过）；环（去重）。

```javascript
function traceAffected(changed = [], importGraph = new Map(), { filter = () => true } = {}) {
  const affected = new Set();
  const queue = [...changed];
  const visited = new Set(changed);
  while (queue.length) {
    const file = queue.shift();
    const importers = importGraph.get(file) ?? new Set();
    for (const importer of importers) {
      if (visited.has(importer)) continue;
      visited.add(importer);
      affected.add(importer);
      queue.push(importer);
    }
  }
  return [...affected].filter(filter).sort();
}

// 自测
const graph = new Map([
  ['Header.tsx', new Set(['page-a.tsx', 'page-b.tsx', 'layout.tsx'])],
  ['layout.tsx', new Set(['page-c.tsx'])],
  ['page-a.tsx', new Set([])],
  ['Footer.tsx', new Set(['page-a.tsx'])],
  ['theme.ts', new Set(['Header.tsx', 'Footer.tsx'])],   // theme → Header → page-a
]);
// Header 变更：直接 importers
let r = traceAffected(['Header.tsx'], graph, { filter: f => f.startsWith('page') || f.startsWith('layout') });
console.log(r.join(','));                                // layout.tsx,page-a.tsx,page-b.tsx

// 传递：theme 变更 → Header → page-a/b + layout → page-c
r = traceAffected(['theme.ts'], graph, { filter: f => f.startsWith('page') });
console.log(r.join(','));                                // page-a.tsx,page-b.tsx,page-c.tsx（传递）

// 环保护
const cyclic = new Map([
  ['a.ts', new Set(['b.ts'])],
  ['b.ts', new Set(['a.ts', 'page-x.tsx'])],
]);
r = traceAffected(['a.ts'], cyclic, { filter: f => f.includes('page') });
console.log(r.join(',') === 'page-x.tsx');               // 环去重不死循环

// 空
console.log(traceAffected([], graph).length === 0);
```

**评分点**：
- 传递追踪正确（BFS 层层传播——Header→layout→page-c 的多级依赖）；环保护（visited 去重）
- filter 的语义（只保留 page/layout——非页面文件的变更不入结果但传递继续）
- 边界（空/环/无 importers）；排序输出
- 能说清「传递依赖追踪让 SSG 增量的精度从页面级提升到组件级：theme 变更 → 传递到所有引用组件的页面」属于加分
