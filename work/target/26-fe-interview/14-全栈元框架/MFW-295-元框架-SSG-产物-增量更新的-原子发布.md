## MFW-295：增量产物原子发布

**答**:
- 半发布事故：新 html 引用新 chunk，但部分 chunk 未传完（CDN 异步）→ 404 白屏——协议必须是「产物全量就绪 → 校验 → 才切引用」（RBL-335 同款搬进元框架语境）
- ISR 特有层：再生成写共享存储（S3）用临时 key + rename 原子替换（读方永远见到完整旧或完整新——RBL-344 原子写复用）
- 版本共存：保留 N 个历史产物版本（回滚指针切换秒级）+ 清理器只删「无指针引用且超 7 天」的版本（引用计数式 GC）
- 对账：发布后拨测（多 region 拉 manifest 比对 hash——RBL-318 指纹三方对账在元框架部署的落地）

```text
协议：全量上传(临时key) → head 校验清单 → 原子切指针 → 拨测比对 → GC(无引用+7d)
红线：html/manifest 引用切换是唯一可见原子操作
```
