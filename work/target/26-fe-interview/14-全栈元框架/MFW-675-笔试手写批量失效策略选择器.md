## MFW-675：笔试：手写批量失效策略选择器

**答**：实现 `chooseInvalidation(skus, { tagHierarchy, rumWeights, threshold })`。skus: `{ id, op: 'UPDATE'|'DELETE' }[]`。规则（RBL-674 的策略决策）：1) skus 数 ≤ threshold（默认 50）→ path 逐个失效（精确，少量开销可接受）；2) skus 数 > threshold → tag 失效（一次调用惰性——批量效率）；3) **热点预渲染**：tag 失效后，rumWeights Top N 的 sku 主动预渲染（首访无回源——用户无感）；4) 返回 `{ strategy: 'path'|'tag', invalidated: string[], preheated: string[] }`。边界：skus 空；rumWeights 空（tag 失效后不预热——长尾按需）；全部 DELETE（tag 失效同样适用）。

```javascript
function chooseInvalidation(skus = [], { tagHierarchy, rumWeights = {}, threshold = 50, preheatTop = 100 } = {}) {
  if (!skus.length) return { strategy: 'none', invalidated: [], preheated: [] };
  const ids = skus.map(s => s.id);
  if (skus.length <= threshold) {
    return { strategy: 'path', invalidated: ids.map(id => `/p/${id}`),
      preheated: [], note: '少量：逐个精确失效' };
  }
  // 批量：tag 失效（惰性）
  const invalidated = [`tag:products`, ...ids.map(id => `tag:product:${id}`)];
  // 热点预渲染
  const preheated = Object.entries(rumWeights)
    .sort((a, b) => b[1] - a[1]).slice(0, preheatTop)
    .map(([id]) => id).filter(id => ids.includes(id));
  return { strategy: 'tag', invalidated, preheated,
    note: '批量：tag 惰性失效 + 热点预渲染' };
}

// 自测
const rumWeights = { '1': 0.9, '2': 0.8, '3': 0.7, '4': 0.1, '5': 0.05 };
// 少量：path
let r = chooseInvalidation([{ id: '1', op: 'UPDATE' }, { id: '2', op: 'UPDATE' }], { rumWeights });
console.log(r.strategy === 'path' && r.invalidated.join(',') === '/p/1,/p/2');
// 批量：tag + 预热
r = chooseInvalidation(
  Array.from({ length: 100 }, (_, i) => ({ id: String(i + 1), op: 'UPDATE' })),
  { rumWeights, threshold: 50, preheatTop: 2 });
console.log(r.strategy === 'tag');
console.log(r.invalidated.includes('tag:products'));
console.log(r.preheated.join(',') === '1,2');            // 热点 Top2 预渲染

// rumWeights 空：不预热
r = chooseInvalidation(Array.from({ length: 100 }, (_, i) => ({ id: String(i), op: 'UPDATE' })), {});
console.log(r.preheated.length === 0);

// 空
console.log(chooseInvalidation([], {}).strategy === 'none');

// 全 DELETE 也走 tag
r = chooseInvalidation(Array.from({ length: 60 }, (_, i) => ({ id: String(i), op: 'DELETE' })),
  { rumWeights, threshold: 50 });
console.log(r.strategy === 'tag');
```

**评分点**：
- 阈值决策（少量 path 精确 / 批量 tag 惰性——RBL-674 的决策落地）
- 热点预渲染（rumWeights 加权 Top N——首访无回源 RBL-599）；rumWeights 空降级
- 边界（空/全 DELETE）；策略 + 预热 + 通知的三段输出
- 能说清「批量失效 tag 优于 path 循环：惰性语义（首访问才重渲染）+ 一次 API 调用」属于加分
