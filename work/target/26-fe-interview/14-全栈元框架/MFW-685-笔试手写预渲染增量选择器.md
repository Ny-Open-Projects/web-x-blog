## MFW-685：笔试：手写预渲染增量选择器

**答**：实现 `selectPrerender(skus, cached, { topN, renderMsPerSku, ciBudgetMin })`。skus: `{ id, popularity }[]`；cached: `{ rendered: string[], hash }`（上次构建清单）。规则：1) Top N 按 popularity 降序；2) **增量过滤**：上次已渲染且 popularity 未变的跳过（popularity hash 比对——或简化：上次 rendered 包含且热度不变）；3) **CI 预算约束**：topN × renderMs ≤ ciBudgetMin × 60000——超预算 → 自动降低 topN（预算内最大 N）；4) 返回 `{ params: string[], skipped: number, budgetMs, usedMs }`。边界：skus 空；topN > skus.length（取全部）；cached 为空（首次全渲染 Top N）；预算不足导致 topN=0（全部 on-demand——合法但警告）。

```javascript
function selectPrerender(skus = [], cached = { rendered: [] }, { topN = 1000, renderMsPerSku = 200, ciBudgetMin = 5 } = {}) {
  const prevSet = new Set(cached.rendered ?? []);
  const sorted = [...skus].sort((a, b) => b.popularity - a.popularity);
  // CI 预算内的最大 N
  const budgetMs = ciBudgetMin * 60000;
  const maxAffordable = Math.floor(budgetMs / renderMsPerSku);
  const effectiveTopN = Math.min(topN, skus.length, maxAffordable);
  const selected = sorted.slice(0, effectiveTopN);
  // 增量：上次已渲染且热度未变的跳过（用 popularity 简化——真实场景用 hash）
  const params = selected.filter(s => !prevSet.has(s.id) || s.popularityChanged)
    .map(s => ({ sku: s.id }));
  const skipped = selected.length - params.length;
  return {
    params: params.map(p => ({ sku: p.sku })),
    skipped,
    budgetMs,
    usedMs: selected.length * renderMsPerSku,
    warning: effectiveTopN === 0 ? '预算不足——全部 on-demand（首访问慢）' : undefined,
  };
}

// 自测
const skus = Array.from({ length: 5000 }, (_, i) => ({ id: `sku-${i}`, popularity: 5000 - i }));
const cached = { rendered: ['sku-0', 'sku-1', 'sku-2'] };
let r = selectPrerender(skus, cached, { topN: 100, renderMsPerSku: 10, ciBudgetMin: 1 });
// 预算 = 60000ms / 10ms = 6000 可渲染 → topN=100 生效
console.log(r.params.length === 97);                     // 100 - 3 cached = 97 新增
console.log(r.skipped === 3);
console.log(r.usedMs === 1000);

// 预算约束：自动降 N
r = selectPrerender(skus, cached, { topN: 1000, renderMsPerSku: 10, ciBudgetMin: 0.5 });
// 预算 = 30000ms / 10 = 3000 可渲染 → topN=1000 < 3000 → 1000 生效
console.log(r.params.length === 997);
// 预算更紧
r = selectPrerender(skus, cached, { topN: 1000, renderMsPerSku: 100, ciBudgetMin: 0.5 });
// 预算 = 30000ms / 100ms = 300 → topN 降到 300
console.log(r.params.length === 297);

// 空 skus
r = selectPrerender([], cached, {});
console.log(r.params.length === 0 && r.usedMs === 0);

// 预算不足警告
r = selectPrerender(skus, cached, { topN: 100, renderMsPerSku: 10000, ciBudgetMin: 0.1 });
console.log(r.warning?.includes('预算不足'));
```

**评分点**：
- 增量过滤（上次已渲染 + 热度不变跳过——RBL-535 diff）；CI 预算约束（自动降 N——预算内最大值）
- skipped 可观测（增量收益量化）；预算不足的诚实警告（全部 on-demand 的体验代价）
- 边界（空 skus/预算不足/topN 超量）；popularity 排序（RBL-599 加权）
- 能说清「预渲染的容量权衡：热点预渲染 + 长尾按需——构建成本与首访问成本的分配」属于加分
