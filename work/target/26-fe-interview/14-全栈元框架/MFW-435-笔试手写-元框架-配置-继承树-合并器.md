## MFW-435：配置继承树
**答**：实现 `mergeLayers([base, env, region, tenant], schemas)`（MFW-342 执行器）：1) 固定序深合并（对象递归/数组 replace/标量覆盖——语义显式，无隐式 concat 惊喜）；2) 双检：层内 schema 校验（各层单独合法）+ 合成后不变量断言（`requires: { gdpr: ['noTracker'] }`——tenant 加回 GDPR 禁的 SDK 被组合检捕获——跨层复活防御）；3) 来源链：合成时记录每键的 `__from['perf.mode']='tenant:acme'`——排查秒级；4) 冲突升级：同键多层类型不同 → TypeError（静默 last-win 是 bug 温床）。

```javascript
export function mergeLayers(layers, { perLayer, invariant } = {}) {
  const src = {}                                             // key -> 来源层
  const out = layers.reduce((acc, [name, cfg], i) => {
    const errs = validate (cfg, perLayer[name])              // 层内检
    if (errors.length) throw new ConfigError(`layer ${name}`, errors)
    return deepMergeTraced(acc, cfg, name, src)              // 记录 __from
  }, {})
  for (const [cond, mustNotHave] of Object.entries(invariant ?? {}))   // 组合检
    if (out[cond] && mustNotHave.some((k) => present(out, k)))
      throw new ConfigError(`cross-layer revive: ${mustNotHave} under ${cond}`)
  return withMeta(out, src)                                  // 读取时可查来源
}
// __from 用例：whichcfg('perf.mode') → 'tenant:acme (override of base:"ssg")'
```
**评分点**：
- 固定序+显式数组语义（无 concat 隐患）
- 双检缺一不可（层内合法+组合不变量——跨层复活是独有事故类）
- 来源链（__from 让「值哪来的」可查询——多租户排查刚需）
- 类型冲突升级（不静默 last-win）
