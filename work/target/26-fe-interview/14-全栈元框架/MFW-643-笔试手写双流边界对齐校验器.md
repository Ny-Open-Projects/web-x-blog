## MFW-643：笔试：手写双流边界对齐校验器

**答**：实现 `verifyBoundaryAlignment(html, flight)`。规则：1) 提取 HTML 边界占位 id（`template id="B:X"`）；2) 提取 Flight 的 Suspense 完成标记 id（`S(\d+):`）与 chunk id（`^(\d+):` 行首）；3) 对齐断言：HTML 的每个 B:id 应有对应 Flight chunk（id 数字对齐——B:0 ↔ chunk 0）；4) 多余 Flight chunk（HTML 无占位）→ warn 'extra-flight-chunk'（流式后补的 chunk——可能正常：多次导航的 payload 合并）；5) 多余 HTML 占位（Flight 无）→ error 'missing-flight-chunk'（内容永远不填充——白屏区域）。返回 `{ htmlBoundaries, flightChunks, missing, extra, ok }`（ok = 无 missing）。边界：无边界（纯静态页——通过）；HTML/flight 空。

```javascript
function verifyBoundaryAlignment(html = '', flight = '') {
  const htmlBoundaries = [...html.matchAll(/template id="B:([A-Za-z0-9]+)"/g)]
    .map(m => m[1]);
  const flightChunks = [...flight.matchAll(/^(\d+):/gm)].map(m => m[1]);
  const flightIds = new Set(flightChunks);
  const missing = htmlBoundaries.filter(id => !flightIds.has(id));
  const htmlSet = new Set(htmlBoundaries);
  const extra = flightChunks.filter(id => !htmlSet.has(id));
  return {
    htmlBoundaries: htmlBoundaries.length,
    flightChunks: flightChunks.length,
    missing,
    extra,
    ok: missing.length === 0,
  };
}

// 自测
// 对齐正常：HTML B:0/B:1 ↔ Flight chunk 0/1
const html = `<div><!--$?--><template id="B:0"></template><!--/$--></div>
<div><!--$?--><template id="B:1"></template><!--/$--></div>`;
const flight = `0:["$","div",null,{"children":"内容A"}]
1:["$","p",null,{"children":"内容B"}]
2:["$","footer",null,{}]`;                              // chunk 2：无占位的静态段
let r = verifyBoundaryAlignment(html, flight);
console.log(r.ok === true && r.missing.length === 0);
console.log(r.htmlBoundaries === 2 && r.flightChunks === 3);
console.log(r.extra.join(',') === '2');                  // chunk 2 额外——warn

// 缺失：HTML B:1 无 Flight chunk 1 → 内容永不填充
const badFlight = `0:["$","div",null,{"children":"A"}]`;
r = verifyBoundaryAlignment(html, badFlight);
console.log(r.ok === false && r.missing.join(',') === '1');   // error

// 无边界（纯静态）
r = verifyBoundaryAlignment('<div>静态</div>', `0:["$","div",null,{}]`);
console.log(r.ok === true && r.htmlBoundaries === 0);
console.log(verifyBoundaryAlignment('', '').ok === true);
```

**评分点**：
- 双流 ID 提取（HTML template B:id 与 Flight 行首 id）+ 对齐断言
- missing = error（内容永不填充——白屏区域）与 extra = warn（正常流式余量）分级
- 边界（纯静态页无边界——通过；空流）；ok 仅由 missing 决定
- 能说清「双流协议的 ID 契约错配是最难排查的静默错——只有 CI 对比两流才能验证」属于加分
