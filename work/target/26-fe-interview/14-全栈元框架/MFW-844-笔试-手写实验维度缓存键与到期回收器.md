## MFW-844：笔试：手写实验维度缓存键与到期回收器

**答**：
- 结论：实验变体进键避免互相污染；实验结束后按前缀批量清理所有变体键，并用 TTL 兜底自动过期，防止僵尸缓存。
- 关键：清理时实验名前缀匹配要精确（避免误删 btn-v2 之类相似名），retired 状态可被新请求读取以降级到默认变体。
- 追问钩子：为什么要 retired 状态而不直接删？——让进行中的实验请求知道该实验已结束，降级到默认变体。

```javascript
function createExpCache() {
  const store = new Map();
  const retired = new Map();       // exp -> expireAt
  return {
    makeKey(path, exp, variant) { return `${path}#${exp}:${variant}`; },
    set(key, val) { store.set(key, val); },
    get(key) { return store.get(key); },
    endExperiment(exp, now = Date.now(), ttl = 3600e3) {
      retired.set(exp, now + ttl);
      setTimeout(() => {
        const prefix = '#' + exp + ':';
        for (const k of store.keys()) if (k.includes(prefix)) store.delete(k);
        retired.delete(exp);
      }, ttl);
    },
    isRetired(exp, now = Date.now()) { return (retired.get(exp) ?? 0) > now; }
  };
}

// 自测
const c = createExpCache();
const k = c.makeKey('/home', 'btn', 'B');
c.set(k, '<B>');
console.log(c.get(k) === '<B>' && !c.isRetired('btn')); // true
c.endExperiment('btn', Date.now(), 20);
console.log(c.isRetired('btn'));                        // true
setTimeout(() => console.log(c.get(k)), 40);            // undefined（已回收）
```

**评分点**：
- 实验变体进入缓存键，避免两变体互相污染
- 实验结束按精确前缀批量清理所有变体键，TTL 兜底自动过期
- retired 状态可查询，供新请求降级到默认变体
- 边界：前缀匹配精确（避免误删相似实验名），清理后 retired 状态移除
