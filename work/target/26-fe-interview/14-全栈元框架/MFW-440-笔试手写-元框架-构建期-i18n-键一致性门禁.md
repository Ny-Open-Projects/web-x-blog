## MFW→MFW-440：i18n 门禁
**需求**：实现 `auditI18n(locales, usage)`：1) 三表对齐：各语言 key 集合 ⊇= 基准语言（漏译列单）；代码引用键（t('cart.add') 静态提取+动态键白名单）⊆ 基准语言（引用不存在的键=运行时裸 key）；反向：基准语言存在但零引用 → dead key（清理清单）；2) 占位符类型校验（{count} 复数/ICU 参数跨语言一致——德语多一个参数=运行时错）；3) 输出 exitCode（漏译 blocking？——按 namespace 分级：checkout 阻断/marketing 警告）；4) 增量模式（只查 PR 触及 namespace——全量扫描慢）。

```javascript
export function auditI18n(bundles /* {en:{...},de:{...}} */, codeRefs, { hardNamespaces = ['checkout'] } = {}) {
  const base = flatKeys (bundles.en), missing = [], dead = [], badIcu = []
  for (const [lang, b] of Object.entries(bundles)) {
    if (lang === 'en') continue
    const ks = new Set (flatKeys(b))
    missing.push(...[...base].filter(k => !ks.has(k)).map(k => ({ lang, key: k,
      hard: nsOf(k) ∈ hardNS }))))
    for (const k of ks) if (!base.has(k)) dead.push({ lang, key: k })     // 幽灵键
    for (const k of base ∩ ks) if (!icuParamsEq(b[k], bundles.en[k])) badIcu.push({lang,key:k})
  }
  const unknown = codeRefs.filter((k) => !base.has(k))      // 引用不存在的键
  const unused = [...base].filter((k) => !codeRefs.includes(k) && !allowlist(k))
  const exit = missing.some(m => m.block) || unknown.length ? 1 : 0   // 分级：资金/下单链阻断
  return { missing, deadKeys: dead, badIcu, unknownRefs: unknown, unused, exit }
}
```
**评分点**：
- 四向检查（漏译/幽灵键/ICU 参数/引用不存在——各对应一类运行时炸）
- 分级阻断（checkout 链 fail、marketing warn——门禁不一刀切）
- dead key 与 unused 双清（体积与心智同步瘦）
- 动态键白名单（模板串构造键的诚实豁免口）
