## MFW-824：边缘函数无共享内存，怎么做跨区域的全局限流配额

**答**：
- 结论：中心配额服务发放「本地租约」：边缘节点一次性领 N 个令牌，本地消费完再申领；用短租约 + 少量超额预留换低延迟与高可用。
- 对比：每请求问中心 = 延迟与单点瓶颈；纯本地 = 全局超限；租约是两者折中。
- 追问钩子：租约大小怎么定？——按 QPS × 租约有效期 × 容忍超额比例估算，突发流量用更小租约。

```javascript
// 中心发租约：返回本节点可本地消费的配额
async function acquireLease(key, nodeId, size = 100) {
  return fetch('/quota/lease', {
    method: 'POST',
    body: JSON.stringify({ key, nodeId, size })
  }).then(r => r.json());                          // { tokens, expiresAt }
}

let local = { tokens: 0, expiresAt: 0 };
async function rateLimit(key, nodeId) {
  if (local.tokens <= 0 || Date.now() > local.expiresAt) {
    local = await acquireLease(key, nodeId);        // 耗尽/过期才申领
  }
  if (local.tokens <= 0) return false;              // 中心也无配额
  local.tokens--;
  return true;
}
// 效果：N 个边缘节点各自消费租约，全局超限 ≈ 租约大小 × 节点数
```
