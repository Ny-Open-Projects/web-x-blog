## MFW-275：表单分层校验

**答**:
- 单一 schema 双端消费：zod schema 同时喂 client（react-hook-form resolver——即时体验）与 server Action validator（权威防线）——两套手写规则必漂移
- 分层语义：client 校验管「格式与必填」（省一次往返）；server 重复全部校验 + client 做不了的（唯一性/权限/库存）——server 永不信任 client 跳过
- 错误回显协议：server 字段级错误（{ fieldErrors: { email: '已被占用' } }）→ useActionState 回填到对应输入——服务端与客户端错误同一 UI 通道
- 提交防抖与锁：pending 态禁重复提交（useFormStatus）+ 幂等键（MFW-272）——校验之外的第二层防

```javascript
const schema = z.object({ email: z.string().email(), qty: z.number().int().min(1) })
// client：useForm({ resolver: zodResolver(schema) })
// server：.validator(schema) —— 同一 schema 双端
// server 附加：email 唯一性（DB 查——client 做不了）→ fieldErrors 回填
```
