## MFW-493：边缘日志头采样 + 尾采样器
**答**：实现 `LogSampler({ headRate = 0.01, tailKeep = 100 })`：1) 头采样：常规请求按 headRate 概率放行（确定性采样用 traceId 尾数取模，同 trace 全链路同决策——不能各跳各采）；2) 尾采样：错误请求（status >= 500 或 duration > p99 阈值）100% 保留，最近 tailKeep 条常驻（问题请求绝不丢）；3) 慢请求全保但按 traceId 去重（同 trace 多 span 只记一次入口）；4) `export()` 输出保留日志并重置窗口——采样器自身内存要恒定。

```javascript
export class LogSampler {
  constructor({ headRate = 0.01, tailKeep = 100, slowMs = 3000 } = {}) {
    Object.assign(this, { headRate, tailKeep, slowMs })
    this.tail = []        // 错误/慢请求环
    this.seen = new Set() // traceId 去重窗口
  }

  decide(log) {
    const isErr = log.status >= 500
    const isSlow = log.duration > this.slowMs
    if (isErr || isSlow) {
      if (this.seen.has(log.traceId)) return false // 同 trace 只收入口
      this.seen.add(log.traceId)
      this.tail.push(log)
      if (this.tail.length > this.tailKeep) this.tail.shift() // 环形截断
      return true
    }
    // 头采样：traceId 尾 hex 取模（同 trace 恒定决策）
    return parseInt(log.traceId.slice(-4), 16) % 100 < this.headRate * 100
  }

  export() {
    const out = [...this.tail]
    this.tail = []; this.seen.clear() // 重置窗口保持内存恒定
    return out
  }
}
```

**评分点**：
- 头采样基于 traceId（同链路各跳同决策，否则链路拼不全）
- 错误/慢请求尾采样 100% 保留（采样不采样问题请求是铁律）
- traceId 去重防 span 放大（一条慢请求带出 N 条重复）
- 环形缓冲 + export 重置（内存上限恒定——边缘环境红线）
