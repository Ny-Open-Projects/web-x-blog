## MFW-060：笔试：手写一个按优先级分层的流式商品详情页
**答**：商品详情页包含：头图（关键，LCP）、价格（关键）、评论列表（慢接口，可延后）、推荐列表（慢接口，可延后）。要求：① 页面 shell 立即返回；② 关键内容优先流式输出；③ 两个慢接口并行取数不互相阻塞；④ 每个区块有独立骨架屏。

```tsx
// app/products/[id]/page.tsx
import { Suspense } from 'react';

export default async function ProductPage({ params }: { params: Promise<{ id: string }> }) {
  const { id } = use(params);

  // 并行发起：只创建 Promise 不 await，避免评论接口拖慢头图接口
  const reviewsPromise = getReviews(id);
  const recosPromise = getRecommendations(id);

  return (
    <main>
      {/* 第一梯队：LCP 内容，同层尽早 flush */}
      <Suspense fallback={<GallerySkeleton />}>
        <Gallery id={id} />
      </Suspense>
      <Suspense fallback={<PriceSkeleton />}>
        <Price id={id} />
      </Suspense>

      {/* 第二梯队：慢接口互相独立，谁先完成谁先流出 */}
      <Suspense fallback={<ReviewsSkeleton />}>
        <Reviews promise={reviewsPromise} />
      </Suspense>
      <Suspense fallback={<RecoSkeleton />}>
        <Recommendations promise={recosPromise} />
      </Suspense>
    </main>
  );
}

async function Gallery({ id }: { id: string }) {
  const gallery = await getGallery(id);
  return <img src={gallery.main} alt="主图" fetchPriority="high" />;
}

function Reviews({ promise }: { promise: Promise<Review[]> }) {
  if (!promise) return null;
  return <ReviewList data={use(promise)} />; // use() 读外部传入的 promise
}
```

**评分点**：
1. 两个慢接口在服务端组件顶层就并行发起（promise 传递），而不是每个子组件里各自 await 造成瀑布。
2. `Suspense` 边界按业务优先级划分，LCP 区块单独一层，fallback 是骨架屏而非空白。
3. 能说清流式顺序：shell 先出，各边界的数据 ready 后按完成顺序 flush。
4. 关键图片有 fetchPriority/尺寸标注，体现 LCP 意识。
5. 知道传 Promise 给客户端组件会破坏序列化（需在服务端组件内 await/use 消化）。
