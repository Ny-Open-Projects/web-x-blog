## MFW-898：笔试：手写双构建产物对账器（定位非确定性差异）

**答**：
- 结论：对两次构建的产物按路径比对——文件集合差异、内容哈希差异；输出新增/删除/修改清单，定位非确定性来源。
- 关键：先按路径排序保证稳定；分别计算两侧哈希，分类差异；忽略可配置白名单（如纯时间戳文件）。
- 追问钩子：为什么要忽略白名单？——某些文件本就含版本时间，属预期变化，不应误报为缺陷。

```javascript
function hash(s) { let h = 5381; for (const c of s) h = ((h << 5) + h + c.charCodeAt(0)) >>> 0; return h.toString(16); }
function reconcile(buildA, buildB, ignore = []) {
  const paths = [...new Set([...Object.keys(buildA), ...Object.keys(buildB)])].sort();
  const diff = { added: [], removed: [], modified: [] };
  for (const p of paths) {
    if (ignore.some(rx => rx.test(p))) continue;
    const a = buildA[p], b = buildB[p];
    if (a === undefined) { diff.added.push(p); continue; }
    if (b === undefined) { diff.removed.push(p); continue; }
    if (hash(a) !== hash(b)) diff.modified.push(p);
  }
  return { deterministic: !diff.added.length && !diff.removed.length && !diff.modified.length, diff };
}
// 自测
const A = { 'a.js': 'v1', 'b.js': 'x' };
const B = { 'a.js': 'v2', 'c.js': 'y' };
const r = reconcile(A, B);
console.log(r.deterministic === false && r.diff.modified[0] === 'a.js'); // true
```

**评分点**：
- 按路径排序后比对，分类新增/删除/修改
- 用内容哈希判断修改，忽略白名单文件
- 输出 determinstic 结论 + 差异清单，可定位来源
- 边界：空产物、两侧路径完全不同、白名单正则误配（加分）
