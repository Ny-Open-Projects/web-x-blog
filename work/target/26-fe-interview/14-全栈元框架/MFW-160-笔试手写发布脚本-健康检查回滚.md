## MFW-160：笔试：手写一个带健康检查与自动回滚的发布脚本
**题目**：写一个 Node 发布脚本 `deploy({ image, replicas })`：① 滚动更新到新镜像；② 逐批（每批 1/3）等待 readiness（HTTP 探针通过才算成功）；③ 任一批失败 → 立即回滚到旧版本并退出非零；④ 全部就绪后输出发布报告；⑤ 脚本要有整体超时（如 5 分钟）防挂死。

```ts
import { execSync } from 'child_process';

type DeployOpts = { image: string; replicas: number; probeUrl?: string };
const PROBE = '/api/health';
const BATCH_TIMEOUT = 60_000;
const TOTAL_TIMEOUT = 300_000;

function sh(cmd: string): string { return execSync(cmd, { encoding: 'utf8' }).trim(); }

async function probeOnce(base: string): Promise<boolean> {
  try {
    const res = await fetch(base + PROBE, { signal: AbortSignal.timeout(2000) });
    return res.ok && (await res.json()).status === 'ok';
  } catch { return false; }
}

async function waitReady(base: string, deadline: number): Promise<boolean> {
  while (Date.now() < deadline) {
    if (await probeOnce(base)) return true;
    await new Promise((r) => setTimeout(r, 2000));
  }
  return false;
}

export async function deploy({ image, replicas }: DeployOpts): Promise<void> {
  const totalDeadline = Date.now() + TOTAL_TIMEOUT;
  const previous = sh('kubectl get deploy app -o jsonpath={.spec.template.spec.containers[0].image}');
  console.log(`发布 ${image}（当前 ${previous}）`);

  // 分批：每批副本数 = ceil(总副本 / 3)
  const batchSize = Math.ceil(replicas / 3);
  for (let i = 0; i < replicas; i += batchSize) {
    sh(`kubectl set image deploy/app app=${image}`);
    sh(`kubectl rollout restart deploy/app --rollout-index=${i}`); // 简化示意

    const podBase = sh(`kubectl get pods -l app=app -o jsonpath={.items[0].status.podIP}`);
    const batchDeadline = Math.min(Date.now() + BATCH_TIMEOUT, totalDeadline);
    const ok = await waitReady(`http://${podBase}:3000`, batchDeadline);

    if (!ok) {
      console.error(`第 ${i / batchSize + 1} 批未就绪，回滚到 ${previous}`);
      sh(`kubectl rollout undo deploy/app`);       // 回滚旧版本
      sh(`kubectl rollout status deploy/app --timeout=60s`);
      process.exit(1);                              // 非零退出：CI 感知失败
    }
    console.log(`第 ${i / batchSize + 1} 批就绪`);
  }

  sh(`kubectl rollout status deploy/app --timeout=120s`);
  console.log(`发布完成：${image}，副本 ${replicas}，探针 ${PROBE}`);
}

// 整体超时兜底（防 kubectl 挂死拖垮 CI）
process.on('SIGALRM', () => { console.error('发布整体超时'); process.exit(2); });
```

**评分点**：
1. 分批滚动 + 每批探针就绪才继续（不是一把梭 set image 就算发布成功）。
2. 失败即回滚（rollout undo）并退出非零——CI 能感知发布失败。
3. 探针有单次超时与批次超时双层控制，整体超时兜底。
4. 记录 previous 镜像作为回滚目标（而非依赖集群默认历史）。
5. 探针校验响应体 status 字段而不只是 200——健康检查更真实。
