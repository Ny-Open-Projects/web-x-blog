## MFW-464：边缘地域路由降级器
**需求**：实现 `pickRegion(req, config)`：1) 请求头带 `x-vercel-ip-country` / 自定义 `x-geo`；config = { rules: [{ match: 'CN', region: 'sh2' }, { match: ['SG','MY'], region: 'sg1' }], default: 'us1', health: { sh2: false } }；2) 命中规则但该 region 不健康 → 顺延到下一个匹配规则，都没有则 default；3) default 也标不健康时选择健康集合中延迟表最近的（config.latency = { sh2: 200, sg1: 80 }）；4) 输出 { region, via: 'rule'|'fallback'|'latency' } 并设置 `x-region-src` 便于归因。

```javascript
export function pickRegion(req, config) {
  const geo = req.headers.get('x-vercel-ip-country') || req.headers.get('x-geo') || ''
  const healthy = r => config.health?.[r] !== false
  for (const rule of config.rules) {
    const hit = Array.isArray(rule.match) ? rule.match.includes(geo) : rule.match === geo
    if (hit && healthy(rule.region)) {
      return withSrc(rule.region, 'rule')
    }
  }
  if (healthy(config.default)) return withSrc(config.default, 'fallback')
  const best = Object.entries(config.latency || {})
    .filter(([r]) => healthy(r))
    .sort(([, a], [, b]) => a - b)[0]
  if (!best) throw new Error('no healthy region')
  return withSrc(best[0], 'latency')

  function withSrc(region, via) {
    const h = new Headers()
    h.set('x-region-src', via)
    return { region, via, headers: h }
  }
}
```

**评分点**：
- 规则命中必须过健康检查（不健康即跳过——绕过故障区）
- 三级降级链：rule → default → latency 最近
- default 不健康不走（默认值也是节点，会挂）
- via/头归因（决策可观测，排障不用猜）
