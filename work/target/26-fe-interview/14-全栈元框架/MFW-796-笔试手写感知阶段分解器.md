## MFW-796：笔试：手写感知阶段分解

**答**：实现 `perceptionPhases(metrics)`。metrics: `{ ttfb, lcp, tti, fcp? }`。规则：1) 三阶段：Phase 1 (可见) = ttfb → fcp 或 ttfb；Phase 2 (完整) = fcp/lcp − ttfb；Phase 3 (可交互) = tti − lcp；2) **间隙问题检测**：tti − lcp > 1000ms → warn 'interaction-gap'（视觉就绪到可交互的间隙 > 1s——用户点击无响应 RBL-795）；3) 阶段的优化建议：Phase 1 → SSR 缓存；Phase 2 → 流式/数据优先级；Phase 3 → 水合调度/代码拆分；4) 返回 `{ phases: { visible, complete, interactive }, gapMs, warnings, suggestions }`。边界：无 tti（TTI 未测——Phase 3 不可知）；tti < lcp（异常——tti 不可能小于 lcp——数据问题 warn）；单阶段。

```javascript
function perceptionPhases(metrics = {}) {
  const { ttfb = 0, lcp = 0, tti, fcp } = metrics;
  if (!ttfb && !lcp) return { noData: true, phases: {}, gapMs: 0, warnings: [] };
  const visible = fcp ?? ttfb;                           // Phase 1: 首次内容可见
  const complete = Math.max(lcp - ttfb, 0);              // Phase 2: 流式填充时长
  const interactive = tti != null ? Math.max(tti - Math.max(lcp, visible), 0) : null;   // Phase 3
  const gapMs = tti != null && lcp ? Math.max(tti - lcp, 0) : null;
  const warnings = [];
  if (gapMs !== null && gapMs > 1000)
    warnings.push({ type: 'interaction-gap',
      detail: `视觉就绪到可交互的间隙 ${gapMs}ms > 1000ms——用户点击无响应` });
  if (tti != null && lcp && tti < lcp)
    warnings.push({ type: 'data-anomaly', detail: 'TTI < LCP——数据异常' });
  const suggestions = [
    { phase: 1, strategy: 'SSR 缓存/CDN（RBL-520）' },
    { phase: 2, strategy: '流式优先级/数据分层（RBL-655）' },
    { phase: 3, strategy: '水合调度/渐进增强/乐观 UI（RBL-710/512/580）' },
  ];
  return { phases: { visible, complete, interactive }, gapMs, warnings, suggestions };
}

// 自测
// 典型 RSC 页面
let r = perceptionPhases({ ttfb: 200, lcp: 1500, tti: 3000 });
console.log(r.phases.visible === 200);
console.log(r.phases.complete === 1300);                 // lcp-ttfb
console.log(r.phases.interactive === 1500);              // tti-lcp
console.log(r.gapMs === 1500);
console.log(r.warnings.some(w => w.type === 'interaction-gap'));   // 1500 > 1000

// 间隙小（优化后）
r = perceptionPhases({ ttfb: 200, lcp: 1500, tti: 2000 });
console.log(r.gapMs === 500);
console.log(!r.warnings.some(w => w.type === 'interaction-gap'));   // < 1000

// 无 TTI
r = perceptionPhases({ ttfb: 200, lcp: 1500 });
console.log(r.phases.interactive === null && r.gapMs === null);

// 数据异常：TTI < LCP
r = perceptionPhases({ ttfb: 200, lcp: 3000, tti: 2000 });
console.log(r.warnings.some(w => w.type === 'data-anomaly'));

// 空
console.log(perceptionPhases({}).noData === true);
```

**评分点**：
- 三阶段分解（visible/complete/interactive——RBL-795 的感知模型）；gap 检测（tti-lcp > 1000ms）
- 阶段优化建议（每阶段的策略映射——SSR/流式/水合分阶段优化）；数据异常检测
- 边界（无 TTI/TTI<LCP 异常/空 metrics）；三阶段的优化策略分离
- 能说清「RSC 的 UX 关键间隙：视觉就绪（LCP）到可交互（TTI）——选择性水合与渐进增强是缩小间隙的手段」属于加分
