## MFW-703：笔试：手写压缩策略选择器

**答**：实现 `compressionStrategy(contentType, { isInteractive })`。规则：1) HTML（text/html）→ level 6 + chunk 16KB（压缩率优先）；2) Flight（text/x-component）→ level 6 + chunk 16KB；3) SSE/token 流（text/event-stream）→ level 4 + chunk 1KB（延迟优先——小 chunk 逐 token）；4) API JSON（application/json）→ level 6 + chunk 32KB；5) isInteractive=true（用户正在等待——延迟优先覆盖：SSE 场景的交互）→ 强制小 chunk。返回 `{ level, chunkKB, reason }`。边界：未知 content-type（默认 level 6 chunk 16KB）；isInteractive 覆盖 HTML（用户等待中——HTML 也小 chunk？——不：HTML 首包不是交互（shell 整体——不覆盖））。

```javascript
const STRATEGIES = {
  'text/html': { level: 6, chunkKB: 16, reason: 'HTML 压缩率优先' },
  'text/x-component': { level: 6, chunkKB: 16, reason: 'Flight 结构化重复——压缩友好' },
  'text/event-stream': { level: 4, chunkKB: 1, reason: 'SSE 延迟优先——逐 token' },
  'application/json': { level: 6, chunkKB: 32, reason: 'JSON 一次性响应' },
};

function compressionStrategy(contentType, { isInteractive = false } = {}) {
  const base = STRATEGIES[contentType] ??
    { level: 6, chunkKB: 16, reason: '默认策略' };
  if (isInteractive && contentType === 'text/event-stream')
    return { ...base, reason: `${base.reason}（交互等待中——延迟优先）` };
  return base;
}

// 自测
console.log(compressionStrategy('text/html').chunkKB === 16);
console.log(compressionStrategy('text/x-component').level === 6);
console.log(compressionStrategy('text/event-stream').chunkKB === 1);     // SSE 小 chunk
console.log(compressionStrategy('application/json').chunkKB === 32);
console.log(compressionStrategy('application/json').reason.includes('JSON'));
// 未知类型
r = compressionStrategy('image/png');
console.log(r.chunkKB === 16 && r.reason.includes('默认'));
// isInteractive 覆盖 SSE
r = compressionStrategy('text/event-stream', { isInteractive: true });
console.log(r.reason.includes('交互等待'));
// isInteractive 不覆盖 HTML（shell 非交互）
r = compressionStrategy('text/html', { isInteractive: true });
console.log(r.chunkKB === 16);                           // HTML 不受影响
```

**评分点**：
- 内容类型策略表（HTML/Flight/SSE/JSON 的差异化——压缩级别与 chunk 大小权衡）
- SSE 小 chunk（延迟优先——LLM token 流的实时性）；HTML 大 chunk（压缩率优先）
- isInteractive 的覆盖范围（仅 SSE——HTML 首包非交互不受影响）；未知默认
- 能说清「压缩策略由内容类型决定：SSE 延迟优先小 chunk、HTML 压缩率优先大 chunk——延迟与传输量的权衡」属于加分
