## MFW→MFW-412：脱敏执行器
**需求**：实现 `runSanitization(branch, tables)`：1) 表级策略执行（users.email→fakeEmail()、tokens.value→NULL、orders.amount→扰动保分布 ±10%）——假名器确定化（同输入同输出——跨表 join 后仍一致）；2) 全量 PII 扫描门禁（手机/邮箱/身份证正则 + 高熵串采样——漏网 fail）；3) 断点续跑（按表+主键水位 checkpoint）；4) 报告 { tables, rowsTouched, scanFindings }。

```javascript
const FAKERS = { email: (v) => `u_${hmac(v)}@ex.test`, phone: () => fakePhone(), ... }

export async function runSanitization(db, branch, plan) {
  for (const { table, fields, pk } of plan.tables) {
    let cursor = loadCp(branch, table) ?? null
    while (true) {
      const rows = await bfetchRows(branch, table, pk, cursor, 500)
      if (!rows.length) break
      for (const r of rows) {
        for (const [f, rule] of Object.entries(fields)) {
          if (rule === 'null') r[f] = null
          else if (FAERS[rule]) r[f] = FAKERS[rule](r[f])      // 确定化：join 后仍对齐
          else if (rule.jitter) r[f] = jitter(r[f], 0.1)       // 保分布
        }
      }
      await bwriteRows(branch, table, rows)
      saveCp(branch, table, rows.at(-1)[pk])                   // 断点
      cursor = rows.at(-1)[pk]
    }
  }
  const findings = await scanPII(branch, PII_PATTERNS)         // 双保险扫描
  if (findings.length) throw new Error(`PII leak: ${findings.slice(0, 5)}`)   // 门禁
  return { ok: true }
}
```
**评分点**：
- 确定化假名（同输入同输出——脱敏后跨表关系不散架，测试仍可用）
- 三类规则（null/假名/保分布扰动——统计形状保留）
- checkpoint 续跑（大表中断不重来）+ 末尾 PII 扫描门禁（双保险）
- fail 而非 warn（漏脱敏=合规事故——预览环境不建为默认安全）
