## MFW-497：全站渲染模式审计报告生成器
**答**：实现 `auditRenderModes(routes)`：1) routes = [{ path, dynamic, revalidate, fetchCache, dynamicApis: ['cookies'], usesAction }]；2) 推断每条路由实际渲染模式：dynamicApis 非空或 dynamic='force-dynamic' → SSR；revalidate 存在 → ISR；否则 SSG；usesAction 且 SSR 冲突时标 `mixed`（页面既静态又含写动作要确认 Action 不依赖页面动态性）；3) 输出汇总 { ssr: n, isr: n, ssg: n, mixed: [...], suspect: [...] }；suspect 判定：SSG 页含 Action（构建期页面不含用户上下文，Action 参数来自渲染时会被裁剪——需人工确认）。

```javascript
export function auditRenderModes(routes) {
  const stats = { ssr: 0, isr: 0, ssg: 0, mixed: [], suspect: [] }
  for (const r of routes) {
    let mode
    if (r.dynamic === 'force-dynamic' || (r.dynamicApis?.length))
      mode = 'ssr'
    else if (r.revalidate !== undefined)
      mode = 'isr'
    else mode = 'ssg'
    stats[mode]++

    if (r.usesAction && mode === 'ssg') {
      stats.mixed.push(r.path)
      stats.suspect.push({
        path: r.path,
        why: 'static page hosts a Server Action; verify action inputs are not render-time-derived',
      })
    }
    if (mode === 'ssr' && r.revalidate !== undefined)
      stats.suspect.push({ path: r.path, why: 'force-dynamic with revalidate is contradictory' })
  }
  return {
    summary: { ssr: stats.ssr, isr: stats.isr, ssg: stats.ssg },
    mixed: stats.mixed, suspect: stats.suspect,
    advice: stats.suspect.length ? 'review before deploy' : 'clean',
  }
}
```

**评分点**：
- 推断优先级：dynamicApi/force-dynamic > revalidate > 默认 SSG（与框架实际判定一致）
- SSG × Action 的 mixed 标记（静态页承载写动作是真实事故源）
- force-dynamic 与 revalidate 矛盾进 suspect（配置自相矛盾要暴露）
- advice 字段接 CI 门禁（审计结果可阻断发布而非仅打印）
