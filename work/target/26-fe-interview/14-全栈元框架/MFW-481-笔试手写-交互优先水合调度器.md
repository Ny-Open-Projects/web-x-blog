## MFW-481：交互优先（选择性）水合调度器
**答**：实现 `createHydrationScheduler()`：1) `register(el, { weight, interactive })` 注册待水合 island：interactive 高（首屏可点）优先；2) `tick(budgetMs)`：每帧在水合预算内按优先级执行，单个 island 水合超预算也执行完（不可打断——半水合比晚水合更糟）；3) 全局事件委托：未水合 island 收到点击时立即提到最高优先级（用户正在等它——选择性好合的关键）；4) 输出 `state()` 供监控：{ hydrated, pending, boosted }。

```javascript
export function createHydrationScheduler() {
  const pending = new Map() // el -> { weight, interactive, boosted }
  const hydrated = new Set()
  let boosted = 0

  function register(el, { weight = 1, interactive = 0 } = {}) {
    pending.set(el, { weight, interactive, boosted: false })
  }

  function boost(el) { // 用户点击未水合 island → 立即置顶
    const e = pending.get(el)
    if (e && !e.boosted) { e.boosted = true; boosted++ }
  }

  function priority(el) {
    const e = pending.get(el)
    return (e.boosted ? 1000 : 0) + e.interactive * 10 + e.weight
  }

  function tick(budgetMs = 8) {
    const start = performance.now()
    const order = [...pending.keys()].sort((a, b) => priority(b) - priority(a))
    for (const el of order) {
      const t0 = performance.now()
      hydrate(el)                       // 不可打断，做完为止
      hydrated.add(el); pending.delete(el)
      if (performance.now() - start > budgetMs) break // 超预算让出主线程
      void t0
    }
  }

  function hydrate(el) { /* 假设框架注水 */ el.__hydrated = true }

  return { register, boost, tick, state: () => ({ hydrated: hydrated.size, pending: pending.size, boosted }) }
}
```

**评分点**：
- boost 通道（点击即置顶——选择性好合的灵魂，响应等待感最低）
- 单 island 不可打断（半水合状态比晚水合更危险）
- 帧预算让出（8ms 约束，超时 break 保输入响应）
- 优先级公式：boost > interactive > weight（层次分明）
