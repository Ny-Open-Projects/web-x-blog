## AGT-592：手写 DualStream：双流独立渲染、先完成定格、采纳交互、低端机降级

**需求与边界**：
- 实现 DualStreamController(prompt, modelA, modelB)：并行请求两模型，双栏渲染。
- 边界要求：① 两流状态独立（一端失败不影响另一端渲染）；② 先完成的一栏先定格显示完成态；③ adopt(side) 确立主回答（另一栏保留为对比），adopt 只能一次；④ 低端机降级为串行（先 A 完成才开始 B）。

**答**：
```javascript
class DualStreamController {
  constructor(prompt, a, b, { lowEnd = false } = {}) {
    this.sides = { a: this.mkSide(a, prompt), b: null };
    if (lowEnd) this.sides.a.done.then(() =>   // 串行降级
      { this.sides.b = this.mkSide(b, prompt); });
    else this.sides.b = this.mkSide(b, prompt);
    this.adopted = null;
  }
  mkSide(model, prompt) {
    const s = { model, buf: '', status: 'running', done: null };
    s.done = streamChat({ ...prompt, model }, {
      onDelta: d => { s.buf += d; if (!this.adopted) render(sideEl(s), s.buf); },
      onDone: f => { s.buf = f; s.status = 'done'; render(sideEl(s), f, true); },
      onError: e => { s.status = 'error'; renderError(sideEl(s), e); },
    });
    return s;
  }
  adopt(side) {
    if (this.adopted) throw new Error('已采纳，不可重复');
    if (this.sides[side].status !== 'done') throw new Error('该栏未完成');
    this.adopted = side;
    setMain(side);                              // 主回答确立
    markCompare(side === 'a' ? 'b' : 'a');      // 另一栏降级为对比参考
  }
}
```

**评分点**:
- 双流状态机独立（一端失败另一端照常），串行降级用 done.then 链。
- 先完成先定格；adopt 单次且要求该栏已完成，另一栏转对比态。

## 变体与延伸（补充）

**变体与延伸**：

1. 两栏都在流式输出，切换时怎么避免跳动？→ 每栏独立容器并预留高度，采纳只做一次布局切换，用过渡不用重排，流式期间两栏的滚动位置要各自独立保存。
2. 低端机串行降级等待太久怎么办？→ 先完成的一栏立即可用，另一栏显示进度并允许取消，避免用户误以为卡死。
3. 采纳后想改主意怎么处理？→ 允许撤销一次并恢复对比态，但不再允许重新采纳另一侧，避免状态来回翻转，撤销动作本身也要记一条审计。
