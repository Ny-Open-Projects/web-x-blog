## AIC-778：AI 效能度量中数据粒度（任务级/会话级/PR级）如何选择

**答**：
- 结论先行：粒度决定了能回答什么问题——任务级看「AI 对不同工作的适用性」，会话级看「prompt/上下文质量」，PR 级看「代码产出与审查」；选粒度就是选分析问题，不是越细越好。
- 各粒度用途：1) 任务级——战略层（哪类任务值得投 AI）；2) 会话级——战术层（哪里返工多、prompt 怎么改）；3) PR 级——执行层（质量、审查负担）。
- 选择原则：分析目标先行；粒度越细采集成本越高、噪声越大；多粒度要能对齐（会话→PR→任务的关联键）。
- 追问钩子：为什么多粒度之间必须有唯一关联键？——没有关联键就无法把「会话返工」下钻到「具体 PR/任务」，数据成为孤岛。

```javascript
// 多粒度通过唯一键对齐
function joinGrains(tasks, sessions, prs) {
  const idx = { sessions: {}, prs: {} };
  sessions.forEach(s => (idx.sessions[s.taskId] ??= []).push(s));
  prs.forEach(p => (idx.prs[p.taskId] ??= []).push(p));
  return tasks.map(t => ({
    task: t.id,
    sessions: idx.sessions[t.id]?.length ?? 0,
    prs: idx.prs[t.id]?.length ?? 0,
  }));
}
console.log(joinGrains(
  [{ id: 't1' }],
  [{ id: 's1', taskId: 't1' }, { id: 's2', taskId: 't1' }],
  [{ id: 'p1', taskId: 't1' }]
)); // [{ task:'t1', sessions:2, prs:1 }]
```
