## AIC-823：笔试：实现评测用例去重与分层抽样器
**答**：
- 核心需求：`dedupe(cases)` 去除 prompt 语义重复的用例（归一化后完全相同或 simplicial 相似度 > 0.9 视为重复，保留 source 优先级 bug > online > synthetic）；`stratifiedSample(cases, size)` 按 `tag` 分层，每层按占比分配名额，保证小众标签至少 1 条。
- 归一化：去首尾空格、压缩空白、转小写；相似度可用简单的 Jaccard（词集合交集/并集），避免引入外部依赖。
- 边界：空输入返回 `[]`；`size >= cases.length` 返回全部；某层只有 1 条时不足名额不重复抽样；随机抽样要可传入 seed 保证可复现（评测要可复现）。
- 追问钩子：追问「为什么评测抽样要可复现」——能答出「否则两次评测结果差异无法判断是模型变化还是抽样波动」的候选人懂实验设计。

```typescript
type Case = { id: string; prompt: string; tag: string; source: 'bug'|'online'|'synthetic' };

const norm = (s: string) => s.trim().toLowerCase().replace(/\s+/g, ' ');
const words = (s: string) => new Set(norm(s).split(' '));
const jaccard = (a: Set<string>, b: Set<string>) => {
  const inter = [...a].filter(x => b.has(x)).length;
  return inter / (a.size + b.size - inter || 1);
};
const priority = { bug: 0, online: 1, synthetic: 2 };

function dedupe(cases: Case[]): Case[] {
  const kept: Case[] = [];
  for (const c of [...cases].sort((a, b) => priority[a.source] - priority[b.source])) {
    const dup = kept.some(k => k.tag === c.tag && jaccard(words(k.prompt), words(c.prompt)) > 0.9);
    if (!dup) kept.push(c);
  }
  return kept;
}

function stratifiedSample(cases: Case[], size: number, seed = 1): Case[] {
  if (size >= cases.length) return [...cases];
  const groups = new Map<string, Case[]>();
  for (const c of cases) groups.set(c.tag, [...(groups.get(c.tag) ?? []), c]);
  // 可复现的伪随机
  let s = seed; const rnd = () => ((s = (s * 9301 + 49297) % 233280) / 233280);
  const out: Case[] = [];
  for (const [, g] of groups) {
    const quota = Math.max(1, Math.round(size * g.length / cases.length));
    out.push(...g.sort(() => rnd() - 0.5).slice(0, quota));
  }
  return out.slice(0, size);
}

const cases: Case[] = [
  { id:'1', prompt:'  How to sort a list? ', tag:'algorithm', source:'synthetic' },
  { id:'2', prompt:'how to sort a list', tag:'algorithm', source:'bug' },
  { id:'3', prompt:'解释 React hooks', tag:'frontend', source:'online' },
];
console.log(dedupe(cases).map(c => c.id));                 // ['2','3']（保留 bug 来源）
console.log(stratifiedSample(cases, 2).map(c => c.id));    // 可复现的两条
```
**评分点**：
- 去重前按 source 优先级排序，保证保留「最有价值」用例而非先到先得。
- Jaccard 基于词集合，分母加 `|| 1` 防止空集合除零。
- 分层按占比分配 + 小众标签保底 1 条，不能直接随机截断。
- 抽样提供 seed 保证可复现，这是评测实验设计的核心得分点。
- 输入边界（空数组、size 超总量）处理到位。
