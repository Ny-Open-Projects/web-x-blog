## AIC-421：笔试：实现 AI 门禁降级开关（故障时自动降级为静态检查）。
**答**：`GateSwitch` 维护连续失败计数：连续 ≥ 3 次失败自动降级（mode: ai→static），降级后每 10 次成功尝试半开探测一次 AI；成功则恢复。实现 `shouldUseAI()` 与 `record(ok)`。

```javascript
class GateSwitch {
  constructor() { this.mode = 'ai'; this.fails = 0; this.successes = 0; }
  shouldUseAI() {
    if (this.mode === 'static') {
      return this.successes % 10 === 0;  // 每 10 次静态成功探测一次
    }
    return true;
  }
  record(ok) {
    if (!ok && this.mode === 'ai') {
      if (++this.fails >= 3) { this.mode = 'static'; this.fails = 0; }
    } else if (ok) {
      this.successes++;
      if (this.mode === 'static') {
        // 探测成功（shouldUseAI 刚返回 true 且成功）恢复
        if ((this.successes - 1) % 10 === 0) { this.mode = 'ai'; this.fails = 0; }
      }
    }
  }
  get state() { return this.mode; }
}
const g = new GateSwitch();
[0,0,0].forEach(() => g.record(false));  // 3 连败
console.log(g.state); // static（降级）

```

**评分点**：
- 熔断器三态（closed/open/half-open）正确实现。
- 失败计数只在 AI 模式下累计。
- 半开探测失败回到 open 且计数重置。
- 状态可查询（暴露 mode 供日志）。
