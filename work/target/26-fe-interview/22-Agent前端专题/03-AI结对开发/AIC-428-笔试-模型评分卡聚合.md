## AIC-428：笔试：按任务类型聚合模型评分卡。
**答**：记录 `[{model, kind, pass}]`。输出 `{[kind]: {[model]: {n, passRate}}}`，并给每 kind 的最优模型（passRate 最高且 n ≥ 5，样本不足标 insufficient）。

```javascript
function scorecard(records, { minN = 5 } = {}) {
  const by = new Map();
  for (const r of records) {
    if (!by.has(r.kind)) by.set(r.kind, new Map());
    const m = by.get(r.kind);
    const s = m.get(r.model) ?? { n: 0, pass: 0 };
    s.n++; s.pass += r.pass ? 1 : 0;
    m.set(r.model, s);
  }
  const out = {};
  for (const [kind, m] of by) {
    const stats = {};
    let best = null;
    for (const [model, s] of m) {
      const rate = +(s.pass / s.n).toFixed(2);
      stats[model] = { n: s.n, passRate: rate };
      if (s.n >= minN && (!best || rate > best.passRate)) best = { model, passRate: rate };
    }
    out[kind] = { stats, best: best ?? 'insufficient' };
  }
  return out;
}
console.log(scorecard([
  ...Array(6).fill({ model: 'A', kind: 'review', pass: 1 }),
  ...Array(6).fill({ model: 'B', kind: 'review', pass: 0 }),
])); // review.best = A

```

**评分点**：
- 双层聚合正确（kind → model）。
- 最优模型需要最小样本量（n ≥ 5）门槛——小样本不排名。
- passRate 保留 2 位。
- 无记录的 kind 输出空对象。
