## AIC-605：笔试：手写测试缺口分析

**答**：实现 `analyzeTestGaps(sourceFns, testFns, coverage, { branchThreshold })`。sourceFns: `string[]`（源码导出函数名）；testFns: `string[]`（测试中覆盖的函数名）；coverage: `{ lines: number, branches: number }`. 规则：1) 函数缺口：sourceFns 中不在 testFns → 'uncovered-function'；2) 边界缺口：coverage.branches < branchThreshold（默认 80）→ 'missing-edge-cases'；3) 集成缺口：sourceFns.length ≥ 3 且 testCode 无 'integration' 关键字 → 'missing-integration'（需要 testCode 参数或用 testFns.length ≥ sourceFns.length 替代判断）；4) 返回 `{ gaps: Array<{ type, target, priority }>, score }`（score = 100 − gaps × 20，clamp 0）。边界：sourceFns 空（无缺口）；testFns 完全覆盖（函数级无缺口但可能边界缺口）；coverage 缺失（跳过边界检查）。

```javascript
function analyzeTestGaps(sourceFns = [], testFns = [], coverage,
  { branchThreshold = 80 } = {}) {
  const gaps: { type: string; target: string; priority: number }[] = [];
  const testSet = new Set(testFns);
  // 1) 函数缺口
  for (const fn of sourceFns) {
    if (!testSet.has(fn))
      gaps.push({ type: 'uncovered-function', target: fn, priority: 1 });
  }
  // 2) 边界缺口
  if (coverage?.branches != null && coverage.branches < branchThreshold)
    gaps.push({ type: 'missing-edge-cases', target: `${coverage.branches}% branches`, priority: 1 });
  // 3) 集成缺口
  if (sourceFns.length >= 3 && testFns.length < sourceFns.length * 0.5)
    gaps.push({ type: 'missing-integration', target: 'multi-function', priority: 2 });
  const score = Math.max(0, 100 - gaps.length * 20);
  return { gaps, score };
}

// 自测
const sourceFns = ['getUser', 'updateUser', 'deleteUser', 'listUsers'];
const testFns = ['getUser'];                            // 只测了一个
let r = analyzeTestGaps(sourceFns, testFns, { lines: 90, branches: 60 });
console.log(r.gaps.length === 3);                       // 3 uncovered + 1 edge + 1 integration = 5? 不对
// uncovered: updateUser, deleteUser, listUsers = 3
// edge: branches 60 < 80 = 1
// integration: 4 sourceFns ≥ 3 且 1 testFn < 4*0.5=2 = 1
console.log(r.gaps.length === 5);
console.log(r.gaps.filter(g => g.type === 'uncovered-function').length === 3);
console.log(r.gaps.some(g => g.type === 'missing-edge-cases'));
console.log(r.gaps.some(g => g.type === 'missing-integration'));
console.log(r.score === 0);                             // 100 - 5*20 = 0

// 完全覆盖
r = analyzeTestGaps(sourceFns, sourceFns, { lines: 100, branches: 90 });
console.log(r.gaps.length === 0 && r.score === 100);

// coverage 缺失：跳过边界检查
r = analyzeTestGaps(sourceFns, testFns, undefined);
console.log(!r.gaps.some(g => g.type === 'missing-edge-cases'));
// 空 source
console.log(analyzeTestGaps([], [], { lines: 0, branches: 0 }).score === 100);
```

**评分点**：
- 三类缺口：uncovered-function（函数级）/ missing-edge-cases（边界级）/ missing-integration（集成级）
- 分支覆盖率阈值（< 80% = 边界缺口——RBL-534 分支覆盖的代理指标）；integration 判定（testFns < sourceFns × 0.5）
- 边界（空 sourceFns/完全覆盖/coverage 缺失跳过边界检查）；score 的线性递减
- 能说清「AI 测试的缺口分析需要三级：函数级（漏测的函数）+ 边界级（分支覆盖不足）+ 集成级（组合未测）——函数覆盖 100% 不等于边界覆盖 100%」属于加分
