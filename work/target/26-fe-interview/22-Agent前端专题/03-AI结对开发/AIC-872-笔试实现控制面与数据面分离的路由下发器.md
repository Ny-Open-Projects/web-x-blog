## AIC-872：笔试：实现控制面/数据面分离的路由配置下发器
**答**：
- 核心需求：实现 `ConfigPlane`。控制面维护路由配置（版本化，`publish(config)` 生成新版本），数据面通过 `snapshot()` 获取当前生效快照（不可变），`select(snapshot, key)` 按配置选择模型。要求：发布不中断数据面读取（读写不阻塞），配置变更对进行中的请求透明（快照语义）。
- 边界：空配置返回默认路由；版本号单调递增；`rollback(version)` 切回历史版本；快照是深拷贝（数据面拿到的对象被篡改不影响控制面）。
- 一致性：数据面在「切换瞬间」要么看到旧配置要么看到新配置，不能看到半更新状态——通过整体替换不可变快照引用实现（类似 copy-on-write）。
- 追问钩子：追问「配置下发到所有节点有延迟怎么办」——能答出「带上版本号，节点上报当前版本，控制面确认全量收敛；期间允许新旧版本共存（灰度常态）」的候选人懂分布式配置治理。

```typescript
type Route = { capability: string; modelId: string; weight?: number };
type Snapshot = { version: number; routes: Route[] };

class ConfigPlane {
  private history = new Map<number, Snapshot>();
  private current: Snapshot = { version: 0, routes: [] };
  private seq = 0;

  publish(routes: Route[]) {
    const next: Snapshot = { version: ++this.seq, routes: structuredClone(routes) };
    this.history.set(next.version, next);
    this.current = next; // 原子替换引用：数据面看到完整新快照或旧快照
    return next.version;
  }
  rollback(version: number) {
    const s = this.history.get(version);
    if (!s) throw new Error('version not found');
    this.current = { version: ++this.seq, routes: structuredClone(s.routes) };
  }
  snapshot(): Snapshot { return structuredClone(this.current); } // 深拷贝，防数据面篡改

  select(snap: Snapshot, capability: string, hash = 0): string {
    const routes = snap.routes.filter(r => r.capability === capability);
    if (!routes.length) return 'default-model';
    const total = routes.reduce((s, r) => s + (r.weight ?? 1), 0);
    let x = hash % total;
    for (const r of routes) { x -= (r.weight ?? 1); if (x < 0) return r.modelId; }
    return routes[routes.length - 1].modelId;
  }
}
const cp = new ConfigPlane();
cp.publish([{ capability:'chat', modelId:'m1', weight:8 }, { capability:'chat', modelId:'m2', weight:2 }]);
const snap = cp.snapshot(); // 数据面拿到不可变快照，期间控制面可继续发布
console.log(cp.select(snap, 'chat', 5)); // 'm1'
```
**评分点**：
- 发布用整体替换快照引用（copy-on-write），保证数据面看到完整状态，无半更新。
- snapshot 返回深拷贝，数据面篡改不影响控制面。
- 版本号单调递增，rollback 生成新版本而非回退序号（可追溯）。
- select 支持加权选择与默认兜底，空配置安全。
- 能讨论「配置下发延迟下新旧版本共存」体现分布式经验。
