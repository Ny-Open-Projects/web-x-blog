## AIC-689：笔试：手写插件准入检查器

**答**：实现 `checkPluginAdmission(plugin, policy)`。plugin: `{ name:string, source:'verified'|'community', permissions:string[], vulns:number, lastUpdatedDays:number, signed:boolean }`；policy: `{ maxVulns:number, maxStaleDays:number, requireSignature:boolean, dangerPerms:string[] }`。规则：1) vulns > maxVulns → 'vulnerabilities'；2) lastUpdatedDays > maxStaleDays → 'stale'；3) requireSignature 且 !signed → 'unsigned'；4) permissions 含 dangerPerms 中任一项 → 'dangerous-permission'（记录具体项）；5) source='community' 且含危险权限 → 额外 'community-escalation'；6) 返回 `{ admitted:boolean, issues:Array<{type,detail}>, effectivePerms:string[] }`，effectivePerms = 去掉危险权限后的权限集。边界：plugin 字段缺失用安全默认值（vulns=Infinity, signed=false, source='community'——fail-safe）。

```javascript
function checkPluginAdmission(plugin = {}, policy = {}) {
  const { maxVulns = 0, maxStaleDays = 365, requireSignature = true, dangerPerms = ['exec:cmd', 'write:any', 'net:any'] } = policy;
  const {
    source = 'community', permissions = [],
    vulns = Infinity, lastUpdatedDays = Infinity, signed = false,
  } = plugin;
  const issues = [];
  if (vulns > maxVulns) issues.push({ type: 'vulnerabilities', detail: `${vulns} vulns` });
  if (lastUpdatedDays > maxStaleDays) issues.push({ type: 'stale', detail: `${lastUpdatedDays}d` });
  if (requireSignature && !signed) issues.push({ type: 'unsigned', detail: 'no-signature' });
  const dangerous = permissions.filter(p => dangerPerms.includes(p));
  if (dangerous.length) issues.push({ type: 'dangerous-permission', detail: dangerous.join(',') });
  if (source === 'community' && dangerous.length) issues.push({ type: 'community-escalation', detail: '社区插件申请危险权限' });
  const effectivePerms = permissions.filter(p => !dangerPerms.includes(p));
  return { admitted: issues.length === 0, issues, effectivePerms };
}

// 自测
const policy = { maxVulns: 0, maxStaleDays: 180, requireSignature: true, dangerPerms: ['exec:cmd', 'write:any'] };
const plugin = { name: 'tool', source: 'community', permissions: ['read:file', 'exec:cmd'],
  vulns: 0, lastUpdatedDays: 30, signed: true };
const r = checkPluginAdmission(plugin, policy);
console.log(r.admitted === false);
console.log(r.issues.some(i => i.type === 'dangerous-permission'));
console.log(r.issues.some(i => i.type === 'community-escalation'));
console.log(r.effectivePerms.join(',') === 'read:file');
console.log(checkPluginAdmission({}, policy).issues.some(i => i.type === 'unsigned')); // fail-safe
```

**评分点**：
- 五类准入检查（漏洞/陈旧/未签名/危险权限/社区提权）
- effectivePerms 剥离危险权限
- fail-safe 默认值（vulns=Infinity/signed=false/community）
- admitted 与 issues 一致性
- 能说清「插件准入是供应链安全：沙箱约束 + 最小权限 + 持续审计，信任声明不可靠」属于加分
