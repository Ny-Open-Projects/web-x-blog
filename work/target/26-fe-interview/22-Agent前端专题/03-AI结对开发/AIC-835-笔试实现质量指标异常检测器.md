## AIC-835：笔试：实现质量指标异常检测器（同比/环比/3σ）
**答**：
- 核心需求：实现 `detect(series, config)`。输入时序 `{ t, value }[]`，返回异常点 `{ t, value, reason, severity }[]`。三种检测策略可组合：`sigma`（偏离均值超过 k 倍标准差）、`wow`（周同比变化超过阈值）、`mom`（环比变化超过阈值）。
- 边界：序列长度 < `minSamples`（默认 7）不做 sigma 检测；分母为 0 的变化率不计算（返回 0 变化）避免除零；缺失点（value 为 null）跳过且不纳入统计。
- 误报控制：连续 N 个点异常才告警（防抖）；用中位数/MAD 替代均值/标准差增强对已有异常点的鲁棒性可作为加分项。
- 追问钩子：追问「为什么不用简单同比阈值」——能答出「业务有周期性（周末流量不同），同比要和同周期比，且要考虑趋势」的候选人对时序理解更深。

```typescript
type Point = { t: number; value: number | null };

function detect(series: Point[], cfg: { sigma?: number; wowPct?: number; momPct?: number; minSamples?: number } = {}) {
  const k = cfg.sigma ?? 3, min = cfg.minSamples ?? 7;
  const valid = series.filter(p => p.value != null) as Array<{ t: number; value: number }>;
  if (valid.length < 2) return [];
  const mean = valid.reduce((s, p) => s + p.value, 0) / valid.length;
  const std = Math.sqrt(valid.reduce((s, p) => s + (p.value - mean) ** 2, 0) / valid.length) || 1e-9;

  const out: Array<{ t: number; value: number; reason: string; severity: 'warn'|'critical' }> = [];
  for (let i = 0; i < series.length; i++) {
    const p = series[i];
    if (p.value == null) continue;
    const reasons: string[] = [];
    if (cfg.sigma != null && valid.length >= min &&
        Math.abs(p.value - mean) > k * std) reasons.push(`超出 ${k}σ`);
    const prev = series[i - 1]?.value, weekAgo = series[i - 7]?.value;
    const rate = (a: number, b: number) => b ? (a - b) / Math.abs(b) : 0;
    if (cfg.momPct != null && prev != null && Math.abs(rate(p.value, prev)) > cfg.momPct)
      reasons.push('环比突变');
    if (cfg.wowPct != null && weekAgo != null && Math.abs(rate(p.value, weekAgo)) > cfg.wowPct)
      reasons.push('同比突变');
    if (reasons.length) out.push({
      t: p.t, value: p.value, reason: reasons.join(' + '),
      severity: reasons.length > 1 ? 'critical' : 'warn',
    });
  }
  return out;
}

const series = Array.from({ length: 10 }, (_, i) => ({ t: i, value: 100 + (i % 3) }));
series[5].value = 300; // 注入异常
console.log(detect(series, { sigma: 2, momPct: 0.5 }));
```
**评分点**：
- `std` 加 `|| 1e-9` 防止常量序列除零导致全部误报。
- 样本不足时跳过 sigma 检测，不用小样本下不可靠的统计结论。
- 变化率分母为 0 时返回 0，避免 Infinity/NaN。
- null 缺失点跳过且不纳入统计，同时不做环比比较。
- 多策略组合与 severity 分级、reason 可解释是加分项。
