## AIC-898：笔试：实现多信号决策融合器（综合质量/成本/速度选策略）
**答**：
- 核心需求：实现 `chooseStrategy(options, signals, weights)`。`options: { name, quality, cost, latency }[]`（各维度 0~1，quality 越高越好，cost/latency 越低越好）；`signals: { quality, cost, latency }` 是当前任务对各维度的偏好强度（0~1）；输出按「加权效用」排序的 options。效用 = `wq*(1+sq)*quality − wc*(1+sc)*cost − wl*(1+sl)*latency`，权重归一化。
- 边界：所有输入缺失用默认权重（质量 0.5/成本 0.25/速度 0.25）；维度值裁剪 [0,1]；空 options 返回 []；效用相同按 name 字典序保证确定性。
- 语义：这是**帮助决策的信号融合**，不是替代决策——输出要带 each 的效用分解（quality/cost/latency 各自贡献），让人理解为什么选它；高风险场景人可覆盖（呼应 AIC-889 的 advisory）。
- 追问钩子：追问「权重怎么定」——能答出「权重反映任务上下文（如赶工时 latency 权重升高），应该可配置且随场景动态调整，而非拍死」的候选人理解决策系统的灵活性。

```typescript
const clamp = (v: number) => Number.isFinite(v) ? Math.max(0, Math.min(1, v)) : 0;

function chooseStrategy(options: any[] = [], signals: any = {}, weights: any = {}) {
  const w = { quality:clamp(weights.quality ?? 0.5), cost:clamp(weights.cost ?? 0.25),
    latency:clamp(weights.latency ?? 0.25) };
  const sw = { quality:clamp(signals.quality ?? 0.5), cost:clamp(signals.cost ?? 0.5),
    latency:clamp(signals.latency ?? 0.5) };
  return options.map(o => {
    const q = w.quality*(1+sw.quality)*clamp(o.quality);
    const c = w.cost*(1+sw.cost)*clamp(o.cost);
    const l = w.latency*(1+sw.latency)*clamp(o.latency);
    return { name:o.name, utility:+(q - c - l).toFixed(3),
      breakdown:{ quality:+q.toFixed(3), cost:-+c.toFixed(3), latency:-+l.toFixed(3) } };
  }).sort((a, b) => b.utility - a.utility || a.name.localeCompare(b.name));
}
console.log(chooseStrategy(
  [{ name:'强模型', quality:0.95, cost:0.8, latency:0.6 },
   { name:'快模型', quality:0.7, cost:0.2, latency:0.2 }],
  { quality:0.9, cost:0.3, latency:0.3 })); // 质量偏好高 → 强模型胜出
```
**评分点**：
- 效用公式方向正确：quality 正向加权，cost/latency 负向加权，signals 作为放大器 `(1+s)`。
- 所有维度 clamp [0,1]，缺失用默认权重，空 options 返回 []。
- 效用相同按 name 字典序 tie-break，结果确定性。
- 输出 breakdown 分解，可解释「为什么选它」，且是 advisory 非强制。
- 权重可配置、随场景动态调整的理解是加分项。
