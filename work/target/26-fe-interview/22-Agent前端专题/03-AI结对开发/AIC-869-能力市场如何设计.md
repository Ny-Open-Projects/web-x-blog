## AIC-869：工具平台的「能力市场」怎么设计，让团队像点外卖一样复用 AI 能力？
**答**：
- 能力市场 = 把平台能力（prompt 模板、评测集、Agent、工具插件）做成**可发现、可评估、可复用**的「商品」。核心三件事：目录（发现）、评分（信任）、接入（消费）。
- 目录要有**结构化元数据**：能力描述、适用场景、输入输出 schema、owner、版本、成本、SLA、依赖；支持按标签/场景搜索，让「不知道有这个能力」的人能找到。
- 信任机制：复用别人的 prompt 有风险（质量/安全），要有**评分 + 使用量 + 评测报告 + 审核状态**；热门不等于好用，要看评测数据；平台可对官方能力打认证标。
- 消费要极简：**一键接入**（复制一段 SDK 调用或开通权限即可），消费方无需了解内部实现；同时要有反馈通道（用得不好能评价/报问题），形成优胜劣汰。
- 避免变成「垃圾场」：上架要有门槛（最小文档 + 评测 + owner），长期无人用/评分低的能力下架。
- 追问钩子：能说出「能力市场的核心是降低发现成本和建立信任，而不是做一个花哨的列表页」的候选人，抓住平台的产品本质。

```typescript
type Listing = { id: string; name: string; tags: string[];
  rating: number; uses: number; evalScore: number; verified: boolean; owner: string };

function recommend(listings: Listing[], need: string[]) {
  return listings
    .filter(l => need.some(t => l.tags.includes(t)))
    .map(l => ({
      ...l,
      // 排序综合考虑评测质量、信任评分、使用量，而非单纯热度
      rank: l.evalScore * 0.5 + l.rating * 0.3 + Math.min(1, l.uses / 1000) * 0.2,
    }))
    .sort((a, b) => b.rank - a.rank)
    .slice(0, 5);
}
console.log(recommend([
  { id:'p1', name:'商品文案生成', tags:['文案','电商'], rating:4.8, uses:5000,
    evalScore:0.9, verified:true, owner:'growth' },
  { id:'p2', name:'随便写的提示词', tags:['文案'], rating:5, uses:3,
    evalScore:0.3, verified:false, owner:'intern' },
], ['文案']).map(l => l.id)); // ['p1'] 评测与验证更重要
```
