## AIC-472：笔试：实现依赖升级的受影响文件清单生成。
**答**：输入 breaking 变更 `[{api, since}]` 与全仓 import 图 `imports: {file: string[]}`（元素形如 `pkg@api`）。输出每个文件命中的 breaking API 清单与汇总 `{affectedFiles, byApi}`。

```javascript
function upgradeImpact(breaking, imports) {
  const bp = new Set(breaking.map(b => `${b.pkg}@${b.api}`));
  const byApi = new Map(), affected = [];
  for (const [file, uses] of Object.entries(imports)) {
    const hit = uses.filter(u => {
      const [pkg, api] = u.split('@');
      return bp.has(`${pkg}@${api}`) || bp.has(`${pkg}@*`);
    });
    if (hit.length) {
      affected.push(file);
      for (const h of hit) {
        if (!byApi.has(h)) byApi.set(h, []);
        byApi.get(h).push(file);
      }
    }
  }
  return { affectedFiles: affected.sort(), byApi: Object.fromEntries(byApi) };
}
console.log(upgradeImpact([{ pkg: 'react', api: 'useFormState' }], {
  'src/a.ts': ['react@useFormState', 'react@useState'],
  'src/b.ts': ['react@useState'],
})); // affected [a.ts]；byApi useFormState → [a.ts]

```

**评分点**：
- import 条目解析（pkg@api 或整包通配）。
- byApi 反向索引：每个 breaking API 被哪些文件使用。
- 排序稳定（文件字典序）。
- 无命中输出空（升级无破坏可直接执行）。
