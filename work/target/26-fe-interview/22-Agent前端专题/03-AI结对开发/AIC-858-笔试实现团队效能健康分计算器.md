## AIC-858：笔试：实现团队效能健康分计算器（多指标归一化）
**答**：
- 核心需求：实现 `healthScore(team, targets)`。输入团队多维度指标（正向：adoption、survival、deployFreq；负向：revertRate、escapedBugs、mttr）与目标值，输出 0~100 的健康分与逐维度贡献。
- 归一化：正向指标 `min(1, value/target)`；负向指标 `min(1, target/value)`（value 为 0 时得满分 1）；各维度等权或传入权重；最终分 = 加权平均 × 100。
- 边界：缺失指标跳过且重新归一化权重（不按 0 计）；target <= 0 抛错；分数裁剪到 [0,100]；输出要带每维度得分与短板维度（最低分），便于行动。
- 追问钩子：追问「把多个指标合成一个分数会不会掩盖问题」——能答出「分数用于趋势监控，短板维度用于定位，二者配合而非只报总分」的候选人理解合成的代价。

```typescript
type Targets = { adoption:number; survival:number; deployFreq:number;
  revertRate:number; escapedBugs:number; mttr:number };
const POSITIVE = ['adoption','survival','deployFreq'];

function healthScore(team: any, targets: Targets, weights: any = {}) {
  let weighted = 0, totalW = 0;
  const parts: Record<string, number> = {};
  for (const key of Object.keys(targets) as Array<keyof Targets>) {
    const target = targets[key], value = team[key];
    if (target <= 0) throw new Error(`bad target: ${String(key)}`);
    if (value == null) continue; // 缺失则跳过并重归一化
    const norm = POSITIVE.includes(key)
      ? Math.min(1, value / target)
      : value === 0 ? 1 : Math.min(1, target / value);
    const w = weights[key] ?? 1;
    parts[key] = +norm.toFixed(3);
    weighted += norm * w; totalW += w;
  }
  const score = totalW ? Math.max(0, Math.min(100, Math.round(weighted / totalW * 100))) : 0;
  const weakest = Object.entries(parts).sort((a, b) => a[1] - b[1])[0]?.[0] ?? null;
  return { score, parts, weakest };
}
console.log(healthScore(
  { adoption:0.9, survival:0.8, deployFreq:5, revertRate:0.1, escapedBugs:1, mttr:2 },
  { adoption:0.8, survival:0.9, deployFreq:4, revertRate:0.05, escapedBugs:0, mttr:4 }
)); // score，weakest 指出短板（如 escapedBugs）
```
**评分点**：
- 正向/负向指标归一化方向正确，负向 value=0 得满分。
- 缺失指标跳过并重归一化权重，不按 0 计（否则缺失=惩罚，不合理）。
- target <= 0 抛错，分数裁剪 [0,100]。
- 输出 parts 与 weakest，短板可定位（合成分数不掩盖问题）。
- 权重可配置且默认等权，设计合理。
