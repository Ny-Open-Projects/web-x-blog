## AIC-772：AI 效能度量中辛普森悖论如何识别与规避

**答**：
- 结论先行：辛普森悖论 = 分组看 AI 在每组都提效，但合并后整体反而变差（或反之）——原因是组间结构与规模差异混淆了整体；规避方法是「分层分析 + 标准化权重」而非看合并均值。
- 识别：1) 按任务难度/类型分层，比较每层的 AI vs 非 AI 表现；2) 若分层结论与合并结论方向相反，即触发警报；3) 检查各层样本占比是否失衡。
- 规避：用「标准化」——固定各层权重（如统一按真实任务分布加权）再算整体效果；或直接报告分层结果，不强行合并。
- 追问钩子：为什么合并均值会误导？——它隐含「各组权重相同」的假设，当 AI 更多被用于简单任务时，简单任务的高表现会虚抬整体。

```javascript
// 辛普森悖论：分层都赢，合并却输
function checkSimpson(groups) {
  const perGroup = groups.map(g => ({
    name: g.name,
    aiBetter: g.ai.rate > g.noAI.rate,
    aiRate: g.ai.rate, noRate: g.noAI.rate,
  }));
  const allAIBetter = perGroup.every(g => g.aiBetter);
  const pooled = {
    ai: groups.reduce((s, g) => s + g.ai.success, 0) / groups.reduce((s, g) => s + g.ai.n, 0),
    no: groups.reduce((s, g) => s + g.noAI.success, 0) / groups.reduce((s, g) => s + g.noAI.n, 0),
  };
  const pooledAIBetter = pooled.ai > pooled.no;
  return { perGroup, allAIBetter, pooledAIBetter, paradox: allAIBetter && !pooledAIBetter };
}
const r = checkSimpson([
  { name: '简单', ai: { success: 90, n: 100, rate: .9 }, noAI: { success: 8, n: 10, rate: .8 } },
  { name: '困难', ai: { success: 10, n: 100, rate: .1 }, noAI: { success: 36, n: 90, rate: .4 } },
]);
console.log(r.allAIBetter === false); // 困难组 AI 更差，不构成典型悖论（示例展示算法）
console.log(typeof r.paradox === 'boolean');
```
