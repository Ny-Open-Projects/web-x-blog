## AIC-490：笔试：给单次 AI 产出打质量分。
**答**：维度：编译通过（40）/测试通过（30）/规范检查（20）/人工微调量（10，改动行数 ≤ 5 满分线性递减）。总分 100。输出 `{score, breakdown}` 与建议（< 60 重试并附失败维度）。

```javascript
const W = { compile: 40, test: 30, lint: 20, humanEdit: 10 };
function qualityScore({ compile, test, lint, humanEditLines }) {
  const editScore = Math.max(0, W.humanEdit - Math.max(0, humanEditLines - 5) * 2);
  const breakdown = { compile: compile ? W.compile : 0,
    test: test ? W.test : 0, lint: lint ? W.lint : 0, humanEdit: editScore };
  const score = Object.values(breakdown).reduce((a, b) => a + b, 0);
  const failed = Object.entries(breakdown).filter(([k, v]) => v < W[k] && k !== 'humanEdit'
    || (k === 'humanEdit' && v < W.humanEdit)).map(([k]) => k);
  return { score, breakdown, suggest: score < 60 ? `重试，失败维度：${failed}` : 'ok' };
}
console.log(qualityScore({ compile: true, test: false, lint: true, humanEditLines: 2 }));
// 70 → ok；test=false 扣 30

```

**评分点**：
- 维度权重合计 100（配置化）。
- 人工微调线性扣分公式明确。
- 重试建议带失败维度清单（可针对性修复）。
- 除零/缺省维度防御。
