## AIC-410：笔试：实现会话历史压缩器，把超长对话压成结构化摘要。
**答**：输入消息数组 `[{role, text}]`，规则：保留最近 N 条原文；更早的按 role 分组拼接后截断到每角色 maxChars；输出 `{recent, summary}`，summary 是带角色前缀的压缩文本。

```javascript
function compress(messages, { keep = 4, maxChars = 200 } = {}) {
  const recent = messages.slice(-keep);
  const older = messages.slice(0, -keep);
  const truncate = (s) => {
    if (s.length <= maxChars) return s;
    const sentences = s.slice(0, maxChars).split(/(?<=[。.!?])/);
    return sentences.slice(0, -1).join('') + '…(截断)';
  };
  const grouped = new Map();
  for (const m of older) {
    grouped.set(m.role, (grouped.get(m.role) || '') + m.text + '\n');
  }
  const summary = [...grouped].map(([role, text]) => `[${role}] ${truncate(text)}`);
  return { recent, summary };
}
console.log(compress(
  Array.from({ length: 10 }, (_, i) => ({ role: i % 2 ? 'ai' : 'user', text: `第${i}轮约束。` })),
  { keep: 2 })); // recent 2 条；summary 每角色压缩段

```

**评分点**：
- 结构化压缩（按角色分组+截断）优于无脑截尾——保留多轮约束信息。
- 截断必须加省略标记且不切词（简化按句切分）。
- recent 与 summary 无重复（recent 内的消息从 summary 排除）。
- 边界：消息数 < N 时 summary 为空。
