## AIC-756：笔试：实现代码可维护性指数计算器

**需求**：实现 `maintainabilityIndex(metrics, opts)`。`metrics`: `{ loc, complexity, dupRatio, commentRatio, params }`；`opts.weights`（默认 `{ loc:0.25, complexity:0.25, dup:0.25, comment:0.15, params:0.1 }`）。规则：1) 各维度归一到 0-1（loc: min(loc/200,1)；complexity: min(complexity/20,1)；dupRatio: clamp；commentRatio: clamp；params: min(params/10,1)）；2) 加权求和得 `raw`；3) `MI = Math.round((1 - raw) * 100)`；4) 评级：>=80 'A'，>=60 'B'，>=40 'C'，否则 'D'。边界：metrics 缺字段按 0；权重和为 0 时 raw=0（MI=100）；commentRatio 是「加分项」——归一后从 raw 中减去其权重贡献。

**答**：
- 结论先行：MI 的关键是「归一化」——不同量纲（行数/复杂度/比例）必须映射到同一 0-1 区间才能加权；注释是加分项，方向与其他维度相反。
- 评级阈值要覆盖满分与零分边界，避免 MI=100 或 0 落入空档。
- 追问钩子：为什么注释比例是加分项？——适度注释提升可读性；但过多注释也可能是代码自解释性差的表现，所以权重应较低。

```javascript
function maintainabilityIndex(metrics = {}, opts = {}) {
  const wt = opts.weights ?? { loc: .25, complexity: .25, dup: .25, comment: .15, params: .1 };
  const clamp = v => Math.max(0, Math.min(1, Number(v) || 0));
  const n = {
    loc: clamp((metrics.loc ?? 0) / 200),
    complexity: clamp((metrics.complexity ?? 0) / 20),
    dup: clamp(metrics.dupRatio ?? 0),
    comment: clamp(metrics.commentRatio ?? 0),
    params: clamp((metrics.params ?? 0) / 10),
  };
  const wsum = Object.values(wt).reduce((s, x) => s + x, 0);
  const raw = wsum
    ? (n.loc * wt.loc + n.complexity * wt.complexity + n.dup * wt.dup + n.params * wt.params
       - n.comment * wt.comment) / wsum
    : 0;
  const MI = Math.round((1 - clamp(raw)) * 100);
  const grade = MI >= 80 ? 'A' : MI >= 60 ? 'B' : MI >= 40 ? 'C' : 'D';
  return { MI, grade };
}
console.log(maintainabilityIndex({ loc: 20, complexity: 1, commentRatio: 0.3 }));
console.log(maintainabilityIndex({}, { weights: { loc: 0, complexity: 0 } }).MI === 100); // 边界权重全 0
console.log(maintainabilityIndex().grade === 'A'); // 空指标→满分
```


**评分点**：
- 各维度归一化到 0-1（loc/complexity/params 有上限、比例 clamp）
- 注释为减项（从 raw 中扣除），方向正确
- MI = (1-raw)*100 与评级边界正确
- 边界（空指标 / 权重全 0 时 MI=100）
