## AIC-479：笔试：AI 产出代码指纹库（检测重复产出）。
**答**：对产出做归一化指纹（去空白/去注释后哈希）。实现 `fingerprint(code)` 与 `isDup(store, code)`：库中存在相同或仅变量名不同的指纹（归一化含「标识符统一」简化版——把连续字母序列替换为 X）判重复。

```javascript
function fingerprint(code) {
  const noComment = code.replace(/\/\/.*$/gm, '').replace(/\/\*[\s\S]*?\*\//g, '');
  const noSpace = noComment.replace(/\s+/g, '');
  return [...noSpace].reduce((h, c) => (h * 31 + c.charCodeAt(0)) | 0, 7);
}
const norm = code => code.replace(/\/\/.*$/gm, '').replace(/\s+/g, '')
  .replace(/[A-Za-z_$][\w$]*/g, 'X');
function isDup(store, code) {
  const k = norm(code);
  if (store.has(k)) return true;
  store.add(k);
  return false;
}
const store = new Set();
console.log(isDup(store, 'const a = 1; // init'));   // false 入库
console.log(isDup(store, 'let   b=2;'));             // 归一后同为 X=1 vs X=2？——注意常量不同

```

**评分点**：
- 归一化三步：去注释/去空白/标识符归一。
- 指纹用简单字符串哈希即可（重点在归一化）。
- 标识符归一过于激进会误判——题目简化并说明局限（加分点）。
- store 用 Set 保证 O(1)。
