## AIC-425：笔试：按「任务类型 × 仓库」生成成本交叉报表。
**答**：记录 `[{repo, taskType, usd}]`，输出矩阵 `{[repo]: {[taskType]: usd}}` 与行/列合计，金额保留 2 位。

```javascript
function costMatrix(records) {
  const m = new Map(), row = new Map(), col = new Map();
  for (const r of records) {
    if (!m.has(r.repo)) m.set(r.repo, new Map());
    const inner = m.get(r.repo);
    inner.set(r.taskType, +(((inner.get(r.taskType) || 0)) + r.usd).toFixed(2));
    row.set(r.repo, +((row.get(r.repo) || 0) + r.usd).toFixed(2));
    col.set(r.taskType, +((col.get(r.taskType) || 0) + r.usd).toFixed(2));
  }
  const matrix = {};
  for (const [repo, inner] of m) matrix[repo] = Object.fromEntries(inner);
  return { matrix, rowTotal: Object.fromEntries(row), colTotal: Object.fromEntries(col) };
}
console.log(costMatrix([
  { repo: 'web', taskType: 'review', usd: 1.111 },
  { repo: 'web', taskType: 'review', usd: 2.222 },
  { repo: 'app', taskType: 'codegen', usd: 0.5 },
])); // web.review = 3.33

```

**评分点**：
- 嵌套 Map/对象构建正确，缺项初始化为 0。
- 行列合计独立累计，浮点误差用累加后统一 toFixed。
- 空记录返回空结构不抛错。
- 列排序稳定（按总额降序）可选实现。
