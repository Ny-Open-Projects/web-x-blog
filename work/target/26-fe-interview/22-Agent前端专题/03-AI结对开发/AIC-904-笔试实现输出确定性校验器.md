## AIC-904：笔试：实现 AI 生成代码的「输出确定性校验器」（多次运行指纹对比 + 归一化）
**答**：
- 核心需求：实现 `verifyDeterminism(run, input, opts)`。`run(input, env)` 返回代码字符串；`opts.times` 默认 5、`opts.ignore` 为额外归一化正则数组。返回 `{ stable, distinct, fingerprints }`。
- 归一化规则：抹掉 ISO 时间戳、形如 8 位以上的十六进制 id、连续空白折叠为单空格；再叠加 `opts.ignore` 中的自定义正则。
- 边界：run 抛错要捕获并记为一次「失败指纹」（不中断整体）；times ≤ 1 时直接 stable=true；非字符串返回强制 String()；哈希用 32 位整数避免溢出。
- 语义：这是「检测」而非「修复」——只报告是否稳定，不擅自改代码；稳定不等于正确，仍需配合功能测试。
- 追问钩子：能指出「归一化要可配置，因为不同项目的时间/ID 格式不同；且必须说明本工具只判稳定性不判正确性」的候选人理解工具边界。

```typescript
const DEFAULT_IGNORE = [/\d{4}-\d{2}-\d{2}T[\d:.]+Z?/g, /\b[0-9a-f]{8,}\b/gi];
function fingerprint(code, extra = []) {
  let s = String(code ?? '');
  for (const re of [...DEFAULT_IGNORE, ...extra]) s = s.replace(re, '<X>');
  s = s.replace(/\s+/g, ' ').trim();
  let h = 0;
  for (const c of s) h = (Math.imul(h, 31) + c.charCodeAt(0)) | 0;
  return h >>> 0;
}
function verifyDeterminism(run, input, opts = {}) {
  const times = Math.max(1, opts.times ?? 5), extra = opts.ignore ?? [];
  const prints = new Set();
  for (let i = 0; i < times; i++) {
    try { prints.add(fingerprint(run(input, { temperature: 0, seed: i }), extra)); }
    catch { prints.add('ERROR'); }
  }
  return { stable: prints.size === 1, distinct: prints.size, fingerprints: [...prints] };
}
console.log(verifyDeterminism(inp => `const t=new Date(); return ${inp};`, 'ok').stable);
```
**评分点**：
- 归一化覆盖时间戳/长 id/空白折叠，且支持自定义 ignore 正则。
- run 抛错被捕获为失败指纹，不中断整体检测（鲁棒性）。
- 使用 Math.imul + >>> 0 保证 32 位哈希不溢出、结果确定。
- times ≤ 1 边界处理、非字符串强制转换、stable 由 Set.size 判定。
- 输出语义正确：只检测不修复，明确 stable≠correct（加分项）。
