## AIC-734：笔试：实现本地-云端模型的混合路由器

**需求**：实现 `hybridRoute(task, policy)`。`task`: `{ sensitive, difficulty, latencyMs, size }`（difficulty: 'low'|'mid'|'high'，size 为输入 token 数）；`policy`: `{ localMaxSize, offline, localConfidence }`。规则：1) `sensitive===true` 强制 local（数据不出域）；2) 否则若 `offline===true` 强制 local；3) 否则若 `size > localMaxSize` 或 `difficulty==='high'` 选 cloud；4) 若 `localConfidence < 0.7` 选 cloud 兜底；5) 其余 local。返回 `{ target, reason }`。边界：task 缺字段按默认（非敏感、difficulty='mid'、size=0）；policy 缺字段用默认（localMaxSize=4096、offline=false、localConfidence=1）。

**答**：
- 结论先行：安全红线（敏感/离线）优先级最高，直接锁定本地；能力兜底（长输入/高难度/低置信）才上云；顺序不能乱，否则会把敏感数据送出去。
- 默认值要保证「安全侧保守」——缺字段时按非敏感但走本地优先，避免意外上云。
- 追问钩子：为什么「低置信兜底」放最后？——它是能力判断，优先级低于安全约束；安全约束是一票否决式的。

```javascript
function hybridRoute(task = {}, policy = {}) {
  const maxSize = policy.localMaxSize ?? 4096;
  const offline = policy.offline ?? false;
  const conf = policy.localConfidence ?? 1;
  const size = task.size ?? 0;
  const difficulty = task.difficulty ?? 'mid';
  if (task.sensitive === true) return { target: 'local', reason: 'sensitive' };
  if (offline) return { target: 'local', reason: 'offline' };
  if (size > maxSize) return { target: 'cloud', reason: 'input-too-large' };
  if (difficulty === 'high') return { target: 'cloud', reason: 'high-difficulty' };
  if (conf < 0.7) return { target: 'cloud', reason: 'low-confidence' };
  return { target: 'local', reason: 'default' };
}
console.log(hybridRoute({ sensitive: true, difficulty: 'high' }).reason); // sensitive（安全优先）
console.log(hybridRoute({ size: 5000 }, { localMaxSize: 4096 }).target); // cloud
console.log(hybridRoute({}, { localConfidence: 0.5 }).reason);           // low-confidence
console.log(hybridRoute().target);                                       // local（默认）
```


**评分点**：
- 安全红线优先（sensitive/offline 强制 local）
- 能力兜底顺序（size / difficulty / confidence）正确
- 默认值保守（缺字段走本地）
- 能说明「安全约束优先于能力判断」属加分
