## AIC-883：笔试：实现代码归属判定器（基于 git blame + AI 标记）
**答**：
- 核心需求：实现 `attribute(lines, commits)`。`lines: { file, lineNo, content }[]` 是待判定代码行；`commits: { hash, author, aiGenerated, promptVersion?, changedLines: { file, from, to }[] }[]`。对每行返回 `{ humanOwner, aiSource, confidence }`。人负责（humanOwner = commit.author）；AI 来源信息（model/promptVersion）单独记录。
- 边界：某行找不到对应 commit → owner 为 'unknown'、confidence 0；一行被多个 commit 覆盖（冲突）→ 取行号范围最小者（最近改动）并记录歧义；AI 标记缺失但 commit 声明 aiGenerated → aiSource 仍记录但 confidence 降低。
- 语义：**责任永远归人**（commit.author），AI 信息只是归因元数据（呼应 AIC-882）；输出用于统计而非追责。
- 追问钩子：追问「为什么要单独记 AI 来源而不是混进 owner」——能答出「责任归属和贡献归因是两件事，混在一起会导致甩锅或数据失真」的候选人理解设计意图。

```typescript
type Line = { file: string; lineNo: number; content: string };
type Commit = { hash: string; author: string; aiGenerated: boolean;
  promptVersion?: string; changedLines: Array<{ file: string; from: number; to: number }> };

function attribute(lines: Line[], commits: Commit[]) {
  return lines.map(line => {
    const hits = commits.filter(c => c.changedLines.some(r =>
      r.file === line.file && line.lineNo >= r.from && line.lineNo <= r.to));
    if (!hits.length) return { ...line, humanOwner:'unknown', aiSource:null, confidence:0 };
    // 取改动范围最小的 commit（最接近该行的改动）
    const span = (c: Commit) => Math.min(...c.changedLines
      .filter(r => r.file === line.file)
      .map(r => r.to - r.from));
    const best = [...hits].sort((a, b) => span(a) - span(b))[0];
    return {
      ...line,
      humanOwner: best.author,                       // 责任永远归人
      aiSource: best.aiGenerated
        ? { commit:best.hash, promptVersion:best.promptVersion ?? 'unknown' } : null,
      confidence: best.aiGenerated && !best.promptVersion ? 0.6 : 1,
    };
  });
}
console.log(attribute(
  [{ file:'pay.ts', lineNo:5, content:'total = a + b;' }],
  [{ hash:'abc', author:'zhang', aiGenerated:true, promptVersion:'p7',
     changedLines:[{ file:'pay.ts', from:1, to:10 }] }]));
// humanOwner:'zhang', aiSource:{commit:'abc',promptVersion:'p7'}, confidence:1
```
**评分点**：
- 责任归属 humanOwner=commit.author，AI 信息独立记录，语义正确。
- 多 commit 覆盖时取改动范围最小者，处理歧义。
- 找不到 commit / AI 标记缺失的边界与 confidence 降级处理。
- 输出含行信息与归因元数据，可用于统计而非追责。
- 能解释「责任归属 vs 贡献归因分离」的设计意图是加分项。
