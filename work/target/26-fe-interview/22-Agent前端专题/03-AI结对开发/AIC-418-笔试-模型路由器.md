## AIC-418：笔试：实现基于任务特征与模型能力档案的路由器。
**答**：档案 `models: [{name, kinds:{codegen:0.9,debug:0.7}, costPerK}]`。路由：按 task.kind 取通过率最高者；同分取成本最低；sensitivity=secret 强制 local。实现 `route(task)` 返回模型名，无匹配抛错。

```javascript
function route(task, models) {
  if (task.sensitivity === 'secret') {
    const local = models.find(m => m.local);
    if (!local) throw new Error('no local model for secret task');
    return local.name;
  }
  const scored = models
    .map(m => ({ name: m.name, q: m.kinds[task.kind] ?? 0, cost: m.costPerK }))
    .sort((a, b) => b.q - a.q || a.cost - b.cost);
  if (!scored.length || scored[0].q === 0) return 'default';
  return scored[0].name;
}
const models = [
  { name: 'fast', kinds: { codegen: 0.85, debug: 0.6 }, costPerK: 0.5 },
  { name: 'strong', kinds: { codegen: 0.85, debug: 0.9 }, costPerK: 3 },
  { name: 'local', kinds: { codegen: 0.7 }, costPerK: 0.1, local: true },
];
console.log(route({ kind: 'codegen' }, models));                    // fast（同分成本低）
console.log(route({ kind: 'debug' }, models));                      // strong
console.log(route({ kind: 'debug', sensitivity: 'secret' }, models)); // local

```

**评分点**：
- 过滤 → 排序 → 选择的清晰分层。
- secret 硬约束优先于质量分（安全 > 最优）。
- 平局处理规则明确（成本最低）。
- 档案无该 kind 数据时按 0 处理并可用兜底模型。
