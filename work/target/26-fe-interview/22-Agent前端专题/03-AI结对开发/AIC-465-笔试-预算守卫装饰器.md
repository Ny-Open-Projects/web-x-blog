## AIC-465：笔试：实现 AI 调用的预算守卫高阶函数。
**答**：`withBudget(fn, budget)` 包装异步函数：执行前检查剩余预算，不足直接抛 `BudgetExceeded`；执行后按实际用量扣减。多次调用共享预算状态，`remaining()` 可查。

```javascript
class BudgetExceeded extends Error { constructor() { super('budget exceeded'); } }
function withBudget(fn, budget) {
  let left = budget;
  return {
    async call(...args) {
      if (left <= 0) throw new BudgetExceeded();
      const { result, usage } = await fn(...args);
      left -= usage;
      return result;
    },
    remaining: () => left,
  };
}
let calls = 0;
const g = withBudget(async () => { calls++; return { result: 'ok', usage: 40 }; }, 100);
(async () => {
  await g.call(); await g.call();
  console.log(g.remaining());       // 20
  try { await g.call(); } catch (e) { console.log(e instanceof BudgetExceeded); } // true
})();

```

**评分点**：
- 闭包持有状态（多次调用共享）。
- 不足即拒（不透支）且错误可识别（自定义错误类）。
- 扣减用实际用量（fn 返回 usage）而非估算。
- remaining 剩余计算含并发说明（单线程顺序无竞态）。
