## AIC-804：多模型 A/B「竞技场」如何避免投票偏差，得出可信排名？
**答**：
- 主要偏差有三类：**位置偏差**（人倾向选左边）、**长度偏差**（长答案显得更专业）、**模型身份偏差**（看到 GPT/Claude 标签就投票）。对策分别是随机左右顺序、限制答案长度或让评审只看要点、全程匿名（A/B 代号）。
- 排名别用「胜率」直接比：用 **Elo / Bradley-Terry** 这类成对比较模型，每场对战更新评分，能处理未两两比对的情况；同时报告置信区间（Bootstrap），样本不足时不下结论。
- 对战要分层：按任务类型（代码/解释/改写）和难度分别排名，避免一个「写诗强」的模型在代码榜虚高。
- 自动裁判与人工评审要分开统计，自动裁判本身有偏好（偏向自家模型），需定期用人审校准。
- 追问钩子：能说出「匿名 + 随机顺序 + Elo + 置信区间」四件套的候选人，说明真的跑过评测而不是凭感觉挑模型。

```typescript
// Elo 更新：K 为步长，score 为 A 的胜负（1 胜 / 0.5 平 / 0 负）
function eloUpdate(rA: number, rB: number, score: number, K = 32) {
  const expected = 1 / (1 + 10 ** ((rB - rA) / 400));
  const delta = K * (score - expected);
  return { a: rA + delta, b: rB - delta };
}

// 位置偏差消除：每场随机决定是否交换 A/B 展示顺序
function presentPair(a: string, b: string) {
  const swap = Math.random() < 0.5;
  return swap ? { left: b, right: a, swap } : { left: a, right: b, swap };
}
// 统计时若 swap，则投票结果要反转映射回真实模型
let rating: Record<string, number> = { A: 1500, B: 1500 };
const pair = presentPair('A', 'B');
const winnerIsLeft = true;                       // 模拟人工投票
const winner = pair.swap ? pair.right : pair.left;
const loser  = winner === 'A' ? 'B' : 'A';
({ a: rating[winner], b: rating[loser] } = eloUpdate(rating[winner], rating[loser], 1));
console.log(rating);
```
