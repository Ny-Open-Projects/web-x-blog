## AIC-448：笔试：校验多仓库共享规则版本一致性。
**答**：各仓 gate.yml 记录 `policyVersion`。中央配置当前版本 current。落后 ≥ 2 个 minor 视为过期（版本号 x.y 比较）。输出过期仓库与升级清单。

```javascript
function outdatedRepos(repos, current) {
  const [cmaj, cmin] = current.split('.').map(Number);
  return repos.map(r => {
    if (!/^\d+\.\d+$/.test(r.version)) throw new Error(`${r.repo} 版本格式非法: ${r.version}`);
    const [maj, min] = r.version.split('.').map(Number);
    const behind = cmaj - maj > 0 || (cmaj === maj && cmin - min >= 2);
    return behind ? { repo: r.repo, from: r.version, to: current } : null;
  }).filter(Boolean);
}
console.log(outdatedRepos([
  { repo: 'web', version: '3.1' }, { repo: 'app', version: '3.0' }, { repo: 'h5', version: '3.1' },
], '3.1')); // app 落后（3.0 vs 3.1 差 1 minor？——注意边界：>=2 才过期，故 app 合规）

```

**评分点**：
- 版本号解析（x.y）与比较（major 优先 minor 次之）。
- 落后判定（差值 ≥ 2 minor 或 major 更低）。
- 输出升级建议目标版本（即 current）。
- 格式非法版本报错定位到仓库。
