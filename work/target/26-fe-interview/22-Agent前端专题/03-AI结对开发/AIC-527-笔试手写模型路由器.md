## AIC-527：笔试：手写模型路由器

**答**：实现 `createModelRouter(models, { fallbackModel })`。models: `Record<tier, { name, costPerMTok, maxTokens }>`；tiers: 'cheap'|'expensive'。方法：`route(task)` → `{ model, cost, reason }`、`execute(task, prompt)` → `{ result, model, cost }`。规则：1) route：基于 task 属性选择 tier（RBL-526 决策树）；2) execute：路由后调模型（mock execute）；3) **fallback**：expensive 不可用（maxTokens 超限）→ fallback 到 cheap（降级 RBL-679）；4) 成本计算：`inputTokens × costPerMTok / 1M + outputTokens × costPerMTok / 1M`；5) 统计：`stats()` → `{ byModel: Record<tier, { count, totalCost }> }`。边界：models 空（抛错）；fallbackModel 缺失且 expensive 不可用（抛错）；task 无属性（默认 cheap）。

```javascript
function createModelRouter(models, { fallbackModel = 'cheap' } = {}) {
  if (!models || !Object.keys(models).length) throw new Error('No models configured');
  const stats = { cheap: { count: 0, totalCost: 0 }, expensive: { count: 0, totalCost: 0 } };
  function route(task = {}) {
    if (task.isSecurityCritical) return 'expensive';
    if (task.isInline) return 'cheap';
    const complex = (task.linesChanged ?? 0) > 100 || (task.filesInvolved ?? 0) > 3 ||
      task.complexityHint === 'complex';
    return complex ? 'expensive' : 'cheap';
  }
  return {
    route,
    async execute(task = {}, prompt) {
      let tier = route(task);
      const model = models[tier];
      if (!model) {
        if (models[fallbackModel]) tier = fallbackModel;
        else throw new Error(`模型 ${tier} 不可用且无 fallback`);
      }
      const m = models[tier];
      const inputTok = prompt?.length ? Math.ceil(prompt.length / 4) : 500;
      const outputTok = m.maxTokens ?? 1000;
      const cost = +((inputTok + outputTok) * m.costPerMTok / 1_000_000).toFixed(4);
      stats[tier].count++; stats[tier].totalCost += cost;
      const result = `generated by ${m.name}`;
      return { result, model: m.name, cost, tier };
    },
    stats: () => ({ byModel: { ...stats } }),
  };
}

// 自测
const models = {
  cheap: { name: 'gpt-4o-mini', costPerMTok: 0.5, maxTokens: 4000 },
  expensive: { name: 'gpt-4', costPerMTok: 10, maxTokens: 8000 },
};
const router = createModelRouter({ models });
// inline → cheap
let r = await router.execute({ isInline: true }, 'complete this function');
console.log(r.model === 'gpt-4o-mini' && r.tier === 'cheap');
// complex → expensive
r = await router.execute({ linesChanged: 300 }, 'refactor this');
console.log(r.model === 'gpt-4' && r.tier === 'expensive');
// cost 计算
console.log(r.cost > 0);
// stats
const s = router.stats();
console.log(s.byModel.cheap.count === 1 && s.byModel.expensive.count === 1);

// fallback：expensive 不可用
const noExp = createModelRouter({ models: { cheap: models.cheap } },
  { fallbackModel: 'cheap' });
r = await noExp.execute({ isSecurityCritical: true }, 'auth code');
console.log(r.tier === 'cheap');                        // fallback

// 空 models
e = null; try { createModelRouter({}); } catch (x) { e = x; }
console.log(/No models/.test(e.message));
```

**评分点**：
- 路由决策树：security → expensive / inline → cheap / complex → expensive / default cheap
- fallback 降级（expensive 不可用 → cheap——可用性优先 RBL-679）；成本计算
- 边界（空 models 抛错/fallback 缺失/stats 统计）；模型路由的 ROI
- 能说清「模型路由节省 60% 成本：80% 简单任务用便宜模型——ROI 比统一用最贵模型高一个量级」属于加分
