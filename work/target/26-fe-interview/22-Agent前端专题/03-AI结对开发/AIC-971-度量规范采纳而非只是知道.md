## AIC-971：如何度量团队 AI 规范的「采纳度」，而不是只看「大家知不知道有这份规范」？
**答**：
- 采纳度要看得见行为：统计「规范检查通过率」「违规后修复率」「AI 产出带合规 trailer 的比例」等行为指标，而非发个问卷问「你知道吗」——结论：行为数据是采纳的真实信号。
- 区分「被动遵守」与「主动使用」：CI 拦截后改了算被动，主动调用规范检查工具/引用规则 ID 算主动；两者比例反映规范内化程度。
- 指标要避免博弈（呼应 AIC-848）：通过率 100% 可能是大家学会了绕过检查，要看「绕过/豁免次数」「违规被静默忽略数」等反向指标。
- 追问钩子：能提出「采纳度指标要按团队/个人分布看，找出『知道但不用』的群体去针对性解决，而非用一个平均数掩盖问题」的候选人懂数据驱动推广。

```typescript
// 采纳度行为指标（而非问卷）
function adoptionMetrics(events) {
  const total = events.length || 1;
  const pass = events.filter(e=>e.type==='check' && e.passed).length;
  const active = events.filter(e=>e.type==='check' && e.initiatedBy==='human').length;
  const bypass = events.filter(e=>e.type==='bypass').length;
  return {
    passRate:+(pass/total).toFixed(2),
    activeRate:+(active/total).toFixed(2),        // 主动使用比例
    bypassRate:+(bypass/total).toFixed(2),        // 反向指标：绕过
  };
}
console.log(adoptionMetrics([
  {type:'check',passed:true,initiatedBy:'human'},
  {type:'check',passed:false,initiatedBy:'ci'},
  {type:'bypass'},
]));
```
