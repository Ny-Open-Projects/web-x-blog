## AIC-639：笔试：手写投票多样性度量器

**答**：实现 `measureVotingDiversity(votes, opts)`。votes: `{ model:string, answer:string, confidence:number }[]`（confidence 0-1）；opts: `{ similarityThreshold?:number }`（默认 0.8，答案相似度阈值）。规则：1) 答案去重后计算「答案一致性」= 最高票数/总票数；2) 置信度加权一致性 = Σ(同答案置信度)/Σ(所有置信度)；3) 答案两两相似度（用简单的 Jaccard：字符集合交集/并集），若所有对相似度 > similarityThreshold → 'homogeneous'（同质化，可疑）；4) 返回 `{ topAnswer, consistency, weightedConsistency, diversity:'healthy'|'homogeneous'|'polarized', minorityAnswers:string[] }`。diversity 判定：consistency>0.9 且 homogeneous → 'homogeneous'；consistency<0.5 → 'polarized'；否则 'healthy'。边界：votes 空返回默认安全值；单票 consistency=1 但 diversity='healthy'（样本不足不判同质）。

```javascript
function measureVotingDiversity(votes = [], opts = {}) {
  const { similarityThreshold = 0.8 } = opts;
  if (votes.length === 0) {
    return { topAnswer: null, consistency: 0, weightedConsistency: 0, diversity: 'healthy', minorityAnswers: [] };
  }
  const byAnswer = new Map();
  for (const v of votes) {
    if (!byAnswer.has(v.answer)) byAnswer.set(v.answer, []);
    byAnswer.get(v.answer).push(v);
  }
  const sorted = [...byAnswer.entries()].sort((a, b) => b[1].length - a[1].length);
  const [topAnswer, topVotes] = sorted[0];
  const consistency = topVotes.length / votes.length;
  const totalConf = votes.reduce((s, v) => s + (v.confidence || 0), 0);
  const topConf = topVotes.reduce((s, v) => s + (v.confidence || 0), 0);
  const weightedConsistency = totalConf ? topConf / totalConf : 0;
  // Jaccard 字符相似度
  const jaccard = (a, b) => {
    const A = new Set(a), B = new Set(b);
    const inter = [...A].filter(c => B.has(c)).length;
    const union = new Set([...A, ...B]).size;
    return union ? inter / union : 0;
  };
  const answers = [...byAnswer.keys()];
  let homogeneous = answers.length > 1;
  if (homogeneous) {
    for (let i = 0; i < answers.length && homogeneous; i++) {
      for (let j = i + 1; j < answers.length; j++) {
        if (jaccard(answers[i], answers[j]) <= similarityThreshold) { homogeneous = false; break; }
      }
    }
  }
  const diversity = votes.length > 1 && consistency > 0.9 && homogeneous
    ? 'homogeneous' : consistency < 0.5 ? 'polarized' : 'healthy';
  return { topAnswer, consistency, weightedConsistency, diversity,
    minorityAnswers: sorted.slice(1).map(([a]) => a) };
}

// 自测
const votes = [
  { model: 'A', answer: 'useMemo(v1)', confidence: 0.9 },
  { model: 'B', answer: 'useMemo(v2)', confidence: 0.8 }, // 与 A 高度相似
  { model: 'C', answer: 'useMemo(v3)', confidence: 0.7 },
];
const r = measureVotingDiversity(votes);
console.log(r.diversity === 'homogeneous'); // 全票且答案极像 → 可疑同质
console.log(r.consistency === 1);
console.log(measureVotingDiversity([]).topAnswer === null);
```

**评分点**：
- 答案一致性 + 置信度加权一致性计算正确
- Jaccard 字符相似度判定同质化（homogeneous）
- diversity 三态判定：homogeneous / polarized / healthy，单票不判同质
- minorityAnswers 正确提取（按票数排序去掉第一名）
- 能说清「全票一致 + 高度相似 = 共同盲点而非高可信，少数派答案要重点复核」属于加分
