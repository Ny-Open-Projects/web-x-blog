## AIC-473：笔试：实现发布就绪检查器（go / go-with-risk / no-go）。
**答**：输入 `{highRisks: string[], flakyRate: number, breakingApproved: boolean, rollbackPlan: boolean}`。判定：no-go（未批的 breaking 或无回滚预案）；go-with-risk（有高危但其余健康）；go（全绿）。输出 verdict + blockers。

```javascript
function releaseVerdict(input) {
  const blockers = [];
  if (!input.breakingApproved) blockers.push('breaking 变更未审批');
  if (!input.rollbackPlan) blockers.push('缺少回滚预案');
  if (input.flakyRate > 0.05) blockers.push(`flaky 率 ${(input.flakyRate * 100).toFixed(1)}% > 5%`);
  if (blockers.length) return { verdict: 'no-go', blockers };
  if (input.highRisks.length)
    return { verdict: 'go-with-risk', blockers: input.highRisks.map(h => `高危：${h}`) };
  return { verdict: 'go', blockers: [] };
}
console.log(releaseVerdict({ highRisks: ['支付链路重构'], flakyRate: 0.01,
  breakingApproved: true, rollbackPlan: true })); // go-with-risk

```

**评分点**：
- 判定顺序：先 no-go 条件（硬性）再风险分级。
- flakyRate > 5% 也进 blockers（质量红线）。
- blockers 汇总所有不满足项（不因第一个失败短路）。
- go-with-risk 必须列明风险项。
