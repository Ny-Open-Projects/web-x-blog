## AIC-803：笔试：实现模型能力匹配器，按能力/预算/延迟选出可用模型并排序
**答**：
- 核心需求：输入任务 `{ required: string[], maxCost, maxLatency, minContext }` 与模型数组（含 `capabilities`、`costPer1k`、`latencyP50`、`maxTokens`、`deprecated`），返回**满足全部硬条件**的模型 id 数组，按成本升序、成本相同按延迟升序。
- 边界：`deprecated: true` 直接淘汰；`required` 为空表示任意模型；任一数值上限为 `0`/`undefined` 视为不限；输入非法返回空数组而非抛错。
- 复杂度 O(n·m)，n 为模型数、m 为能力数；可用 Set 把能力查找降到 O(1)。
- 追问钩子：追问「如果软约束无解怎么办」——能答出「不淘汰、返回全集让上层降级」 Candidates 才算理解匹配器与协商器的分工。

```typescript
type Req = { required?: string[]; maxCost?: number; maxLatency?: number; minContext?: number };
type M = { id: string; capabilities: string[]; costPer1k: number; latencyP50: number; maxTokens: number; deprecated?: boolean };

function matchModels(req: Req, models: M[]): string[] {
  if (!Array.isArray(models) || !req) return [];
  const need = req.required ?? [];
  const ok = models.filter(m => {
    if (m.deprecated) return false;
    const caps = new Set(m.capabilities ?? []);
    if (!need.every(c => caps.has(c))) return false;
    if (req.maxCost && m.costPer1k > req.maxCost) return false;
    if (req.maxLatency && m.latencyP50 > req.maxLatency) return false;
    if (req.minContext && m.maxTokens < req.minContext) return false;
    return true;
  });
  return ok
    .sort((a, b) => a.costPer1k - b.costPer1k || a.latencyP50 - b.latencyP50)
    .map(m => m.id);
}

// 自测
const models: M[] = [
  { id: 'cheap', capabilities: ['code'], costPer1k: 1, latencyP50: 800, maxTokens: 8e3 },
  { id: 'fast',  capabilities: ['code', 'json'], costPer1k: 5, latencyP50: 200, maxTokens: 4e3 },
  { id: 'old',   capabilities: ['code'], costPer1k: 0.5, latencyP50: 100, maxTokens: 8e3, deprecated: true },
];
console.log(matchModels({ required: ['code'], maxCost: 3 }, models));            // ['cheap']
console.log(matchModels({ required: ['json'], minContext: 16000 }, models));     // []
console.log(matchModels({}, models));                                             // ['cheap','fast']
```
**评分点**：
- `deprecated` 优先淘汰，不受价格优势干扰。
- 用 `Set` 做能力查找，避免 `includes` 嵌套循环；`need.every` 而非 `some`（全部满足）。
- 上限为 falsy（0/undefined）时视为不限，不能误把 `0` 当严格预算。
- 排序是「成本升序 + 延迟升序」双关键字，不能用单层 `sort` 漏掉 tie-break。
- 非法输入返回 `[]` 不抛异常，体现边界意识。
