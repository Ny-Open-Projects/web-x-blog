## AIC-996：笔试：实现「迁移进度与风险看板数据聚合器」（多维度统计迁移状态并暴露风险）
**答**：
- 核心需求：实现 `buildDashboard(tasks, thresholds)`。`tasks: { id, module, status, verified:boolean, risk:number, owner, blocker? }[]`；返回 `{ overall:{total,doneRate,verifiedRate,avgRisk}, byOwner, atRisk, blockers }`。
- 计算：doneRate = status==="done" 的比例；verifiedRate = done 任务中 verified 的比例（未验证的完成不算真完成）；avgRisk 为平均风险分；byOwner 按人聚合 done 数；atRisk = risk≥thresholds.risk 或（done 但未 verified）的任务；blockers 为有 blocker 的任务。
- 边界：tasks 为空返回全 0 与空列表；比率保留 2 位小数；byOwner 按 owner 排序确定性；status 未知值按未完成处理。
- 语义：看板是「决策仪表盘」——关键洞察是「完成≠验证通过」，未验证的完成被单列为风险，避免虚假进度（呼应迁移纪律）。
- 追问钩子：能指出「看板要突出『假完成』（标记完成但未验证）和『阻塞项』，因为这两类才是真正需要管理者介入的」的候选人懂看板的价值在于暴露问题而非粉饰。

```typescript
function buildDashboard(tasks=[], thresholds={}) {
  const riskTh=thresholds.risk??7, total=tasks.length;
  const done=tasks.filter(t=>t.status==='done');
  const r=(n,d)=>+((d?n/d:0)).toFixed(2);
  const byOwner={};
  for(const t of tasks){ byOwner[t.owner]??=0; if(t.status==='done')byOwner[t.owner]++; }
  const atRisk=tasks.filter(t=>t.risk>=riskTh||(t.status==='done'&&!t.verified)).map(t=>t.id);
  const blockers=tasks.filter(t=>t.blocker).map(t=>({id:t.id,blocker:t.blocker}));
  return {
    overall:{ total, doneRate:r(done.length,total), verifiedRate:r(done.filter(t=>t.verified).length,done.length),
      avgRisk:r(tasks.reduce((s,t)=>s+t.risk,0),total) },
    byOwner:Object.fromEntries(Object.entries(byOwner).sort((a,b)=>a[0].localeCompare(b[0]))),
    atRisk, blockers,
  };
}
console.log(buildDashboard([
  {id:1,module:'a',status:'done',verified:false,risk:8,owner:'x'},
  {id:2,module:'b',status:'doing',verified:false,risk:3,owner:'y',blocker:'缺文档'},
]));
```
**评分点**：
- doneRate/verifiedRate/avgRisk 计算正确，未验证的完成不计入 verifiedRate。
- byOwner 按人聚合 done 数且排序确定性，atRisk/blockers 识别正确。
- 空 tasks 返回全 0 与空列表，比率保留 2 位小数，边界完整。
- 返回结构完整、代码可运行，突出「假完成」与阻塞项。
- 明确「看板价值在暴露问题而非粉饰进度」（加分项）。
