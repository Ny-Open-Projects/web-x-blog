## AIC-814：长文档任务里，长/短上下文模型如何协同分段而不丢信息？
**答**：
- 先按**语义边界**切分（章节/段落/函数），不要按固定字符数硬切——硬切会把一个完整论证劈成两半。用 token 计数而非字符数估算窗口占用。
- 分段后两种协同模式：**map-reduce**（每段独立提炼，再让长上下文模型汇总）适合摘要/抽取；**滑动窗口 + 重叠**（相邻段保留 10%~15% overlap）适合问答，避免跨段实体被切断。
- 每段要带**全局锚点**：文档 id、段序号、前后段摘要，让模型知道「我在全文的位置」，减少断章取义。
- 贵模型用在该用的地方：便宜短模型做逐段粗处理，只有需要全局推理的汇总/冲突仲裁步骤才调用长上下文模型，控制成本。
- 追问钩子：追问「跨段的指代消解怎么办」——能答出「overlap + 段间摘要传递 + 最终一致性校验」的候选人，说明处理过真实长文档链路。

```typescript
const approxTokens = (s: string) => Math.ceil(s.length / 2); // 粗估，真实用 tokenizer

// 按段落语义切分 + 重叠，返回带锚点的片段
function chunk(doc: string, maxTokens = 4000, overlap = 0.12) {
  const paras = doc.split(/\n\s*\n/);
  const chunks: Array<{ idx: number; text: string; tokens: number }> = [];
  let buf = '', tokens = 0;
  for (const p of paras) {
    const t = approxTokens(p);
    if (tokens + t > maxTokens && buf) {
      chunks.push({ idx: chunks.length, text: buf, tokens });
      const tail = buf.slice(-Math.floor(buf.length * overlap)); // 保留尾部重叠
      buf = tail + '\n' + p; tokens = approxTokens(buf);
    } else { buf += '\n' + p; tokens += t; }
  }
  if (buf) chunks.push({ idx: chunks.length, text: buf, tokens });
  return chunks;
}

async function summarize(doc: string, cheap: any, strong: any) {
  const parts = chunk(doc);
  const outlines = await Promise.all(        // map：便宜模型逐段提炼
    parts.map(p => cheap.chat(`[段${p.idx}/${parts.length}] 提炼要点：${p.text}`)));
  return strong.chat('结合以下分段要点，输出全文摘要：\n' + outlines.join('\n')); // reduce
}
```
