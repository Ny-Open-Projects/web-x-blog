## AIC-816：模型/提示词上线后「漂移」了，在线如何检测而不是等投诉？
**答**：
- 漂移分三种：**数据漂移**（输入分布变了，如用户开始问新产品）、**性能漂移**（质量指标下降）、**概念漂移**（同样的输入应该给不同答案了）。AI 系统还有特有的「**静默漂移**」：答案仍然流畅但事实错误率上升，最难发现。
- 在线检测手段：① 对输入/输出 embedding 做分布距离监测（PSI、KS 检验、MMD）；② 对质量代理指标（拒绝回答率、平均答案长度、用户重试率、复制率）做时序异常检测；③ 定期回放 golden 集做「定时体检」。
- 代理指标变化只是信号，不是结论：要自动触发**抽样人工复核**确认，再决定是否回滚。避免一有波动就回滚造成抖动。
- 要有基线：上线稳定期建立指标基线和控制限（如 ±3σ），告警分级（warn / page）；模型版本变更、流量结构变化都要重新校准基线。
- 追问钩子：能说出「静默漂移靠 golden 集定时回放 + 用户行为代理指标双保险」的候选人，说明理解 AI 质量不能只看工程指标。

```typescript
// PSI（群体稳定性指数）：衡量当前分布相对基线的偏移
function psi(base: number[], curr: number[], bins = 10): number {
  const min = Math.min(...base, ...curr), max = Math.max(...base, ...curr);
  const width = (max - min) / bins || 1;
  const hist = (arr: number[]) => {
    const h = new Array(bins).fill(0);
    for (const v of arr) h[Math.min(bins - 1, Math.floor((v - min) / width))]++;
    return h.map(x => (x + 0.5) / (arr.length + bins)); // 平滑，避免除零
  };
  const b = hist(base), c = hist(curr);
  return b.reduce((s, bi, i) => s + (c[i] - bi) * Math.log(c[i] / bi), 0);
}

const baseLen = [120, 130, 125, 140, 118, 132];       // 基线答案长度分布
const currLen = [130, 128, 140, 135, 300, 310];       // 当前分布（出现超长答案）
const score = psi(baseLen, currLen);
console.log('PSI =', score.toFixed(3), score > 0.2 ? 'WARN: 显著漂移，触发抽样复核' : '正常');
// 经验阈值：PSI < 0.1 稳定，0.1~0.2 关注，> 0.2 显著漂移
```
