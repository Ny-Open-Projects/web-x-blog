## AIC-863：笔试：实现工具注册表与能力发现器（按能力标签检索）
**答**：
- 核心需求：实现 `ToolRegistry`，支持 `register(tool)`、`discover(tags, mode)`、`invoke(name, args)`。tool 形状 `{ name, description, tags: string[], handler, enabled, timeoutMs }`。`discover` 按标签匹配（`mode:'all'` 需包含全部标签，`mode:'any'` 包含任一），返回按匹配度排序的启用工具；`invoke` 带超时控制并统计调用次数。
- 边界：重名注册抛错；`enabled:false` 不参与发现但可显式 invoke；标签大小写归一；未知工具抛清晰错误；handler 抛错向上透传但计数仍增加。
- 超时：用 `Promise.race` + `setTimeout`，超时后清理定时器避免内存泄漏；超时时间取工具的 timeoutMs 或默认 5000。
- 追问钩子：追问「工具描述要不要给 AI 看」——能答出「description 是给模型做工具选择的提示，要写得像给 AI 的 API 文档，这是 Tool Registry 区别于普通服务发现的关键」的候选人理解 AI 工具链特性。

```typescript
type Tool = { name: string; description: string; tags: string[];
  handler: (args: any) => Promise<any>; enabled?: boolean; timeoutMs?: number };

class ToolRegistry {
  private tools = new Map<string, Tool>();
  private calls = new Map<string, number>();

  register(t: Tool) {
    if (this.tools.has(t.name)) throw new Error(`duplicate tool: ${t.name}`);
    this.tools.set(t.name, { ...t, tags: t.tags.map(x => x.toLowerCase()) });
  }
  discover(tags: string[], mode: 'all' | 'any' = 'any'): Tool[] {
    const want = tags.map(x => x.toLowerCase());
    return [...this.tools.values()].filter(t => t.enabled !== false)
      .map(t => ({ t, hits: want.filter(w => t.tags.includes(w)).length }))
      .filter(({ hits }) => hits > 0 && (mode === 'any' || hits === want.length))
      .sort((a, b) => b.hits - a.hits)
      .map(({ t }) => t);
  }
  async invoke(name: string, args: any) {
    const t = this.tools.get(name);
    if (!t) throw new Error(`unknown tool: ${name}`);
    this.calls.set(name, (this.calls.get(name) ?? 0) + 1);
    let timer: any;
    try {
      return await Promise.race([
        t.handler(args),
        new Promise((_, rej) => { timer = setTimeout(() => rej(new Error('tool timeout')),
          t.timeoutMs ?? 5000); }),
      ]);
    } finally { clearTimeout(timer); } // 清理定时器，防泄漏
  }
}
const reg = new ToolRegistry();
reg.register({ name:'search', description:'按关键词搜索商品', tags:['search','goods'],
  handler: async (a: any) => a.q, enabled:true, timeoutMs:1000 });
console.log(reg.discover(['goods']).map(t => t.name)); // ['search']
```
**评分点**：
- discover 支持 all/any 两种模式，按 hits 排序（匹配度）。
- 标签大小写归一，enabled:false 不参与发现但可显式调用。
- Promise.race 超时控制 + finally 清理定时器，避免泄漏。
- 重名/未知工具有明确错误，调用计数不影响异常透传。
- description 面向 AI 工具选择的语义理解是加分项。
