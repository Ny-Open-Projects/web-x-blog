## AIC-563：笔试：手写多模型投票

**答**：实现 `multiModelVote(prompt, models, { mode })`。models: `((prompt) => Promise<string>)[]`。mode: 'pair'（前两个对比）| 'vote'（全部投票）。规则：1) pair：normalize 后比较——一致 → { consistent: true, verdict: 'high-confidence' }；不一致 → { consistent: false, verdict: 'needs-review' }；2) vote：normalize 后计数——全同 → 'unanimous'；多数 → 'majority' + winner + confidence%；3) normalize：去空白 + 排序语句（语义等价的不同实现 → normalize 后相同——宽松匹配）。返回统一结构 `{ results, verdict, winner?, confidence? }`。边界：models 空/1（无法对比——single）；全部不同（no majority——需人工）。

```javascript
function normalizeOutput(code = '') {
  return code.replace(/\s+/g, ' ').trim()
    .split(';').map(s => s.trim()).filter(Boolean).sort().join(';');
}
async function multiModelVote(prompt, models = [], { mode = 'pair' } = {}) {
  if (models.length === 0) return { verdict: 'no-models', results: [] };
  if (models.length === 1) {
    const r = await models[0](prompt);
    return { verdict: 'single', results: [r], winner: r, confidence: null };
  }
  const results = await Promise.all(models.map(m => m(prompt)));
  const normalized = results.map(normalizeOutput);
  if (mode === 'pair' && models.length === 2) {
    const consistent = normalized[0] === normalized[1];
    return { results, verdict: consistent ? 'high-confidence' : 'needs-review',
      consistent };
  }
  // vote
  const counts = new Map<string, number>();
  normalized.forEach(r => counts.set(r, (counts.get(r) ?? 0) + 1));
  const sorted = [...counts.entries()].sort((a, b) => b[1] - a[1]);
  const [winnerNorm, count] = sorted[0];
  const winnerIdx = normalized.indexOf(winnerNorm);
  const unanimous = count === results.length;
  return {
    results, verdict: unanimous ? 'unanimous' : sorted[0][1] > 1 ? 'majority' : 'no-majority',
    winner: results[winnerIdx], confidence: `${Math.round(count / results.length * 100)}%`,
  };
}

// 自测
const models = [
  async () => 'const x = 1; return x;',
  async () => 'return x; const x = 1;',                  // 语句序不同但语义同
  async () => 'const x = 1; return x;',
];
// vote 模式：normalize 后一致
let r = await multiModelVote('test', models, { mode: 'vote' });
console.log(r.verdict === 'unanimous' || r.verdict === 'majority');
console.log(r.confidence === '100%');                    // normalize 后全部一致

// pair 模式
r = await multiModelVote('test', models.slice(0, 2), { mode: 'pair' });
console.log(r.verdict === 'high-confidence');            // normalize 后一致

// 不一致
const disagree = [
  async () => 'result A',
  async () => 'result B',
];
r = await multiModelVote('test', disagree, { mode: 'pair' });
console.log(r.verdict === 'needs-review' && r.consistent === false);

// no majority
const allDiff = [async () => 'A', async () => 'B', async () => 'C'];
r = await multiModelVote('test', allDiff, { mode: 'vote' });
console.log(r.verdict === 'no-majority');                // 3 个全不同

// 单模型
r = await multiModelVote('test', [models[0]]);
console.log(r.verdict === 'single');
```

**评分点**：
- 双模式：pair（两个对比）/ vote（N 个投票）；normalize 语义等价（语句排序后比较——宽松匹配）
- 投票三级（unanimous/majority/no-majority）+ confidence 百分比；pair 的 high-confidence/needs-review
- 边界（空 models/单模型/全不同）；no-majority 需人工
- 能说清「多模型一致 = 独立验证高置信：两个独立生成器结论一致——不一致的 diff 区域 = 可能的 bug 区域」属于加分
