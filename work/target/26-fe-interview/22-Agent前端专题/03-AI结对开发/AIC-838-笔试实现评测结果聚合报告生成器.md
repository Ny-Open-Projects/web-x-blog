## AIC-838：笔试：实现评测结果聚合报告生成器（分维度 + 趋势 + 结论）
**答**：
- 核心需求：输入多轮评测记录 `{ runId, ts, results: { caseId, tag, score, passed }[] }`，生成报告：按 `tag` 维度聚合通过率、计算相对上轮的趋势（↑↓→）、标出退步超过 10% 的维度、给出整体结论（pass/warn/fail）。
- 边界：某轮无某维度数据时该维度不参与趋势比较；只有一轮时趋势全是 `→`；空数据返回结构完整但全为 0 的报告；分数越界（<0 或 >1）视为无效过滤。
- 结论规则：任一维度通过率 < 0.7 → fail；任一维度环比退步 > 0.1 → warn；否则 pass。报告要可读（带维度名与数值）。
- 追问钩子：追问「为什么要分维度看而不是只看总分」——能答出「总分会被大维度掩盖小维度崩塌（如 tool-call 从 90% 掉到 40% 但总量小）」的候选人理解辛普森悖论式的评测陷阱。

```typescript
type CaseResult = { caseId: string; tag: string; score: number; passed: boolean };
type Run = { runId: string; ts: number; results: CaseResult[] };

function generateReport(runs: Run[]) {
  const dim = (run: Run) => {
    const m = new Map<string, { total: number; pass: number }>();
    for (const r of run.results ?? []) {
      if (!Number.isFinite(r.score) || r.score < 0 || r.score > 1) continue;
      const x = m.get(r.tag) ?? { total: 0, pass: 0 };
      x.total++; if (r.passed) x.pass++;
      m.set(r.tag, x);
    }
    return new Map([...m].map(([k, v]) => [k, v.pass / v.total] as const));
  };
  const dims = new Set(runs.flatMap(r => [...dim(r).keys()]));
  const cur = runs.length ? dim(runs[runs.length - 1]) : new Map();
  const prev = runs.length > 1 ? dim(runs[runs.length - 2]) : new Map();

  const byTag: any = {};
  let fail = false, warn = false;
  for (const tag of dims) {
    const rate = cur.get(tag) ?? 0, before = prev.get(tag);
    const delta = before == null ? 0 : rate - before;
    const trend = before == null ? '→' : delta > 0.02 ? '↑' : delta < -0.02 ? '↓' : '→';
    if (rate < 0.7) fail = true;
    if (delta < -0.1) warn = true;
    byTag[tag] = { passRate: +rate.toFixed(2), trend, delta: +delta.toFixed(2) };
  }
  return { byTag, verdict: fail ? 'fail' : warn ? 'warn' : 'pass', runs: runs.length };
}

console.log(generateReport([
  { runId: 'r1', ts: 1, results: [{ caseId:'a', tag:'tool-call', score:0.9, passed:true }] },
  { runId: 'r2', ts: 2, results: [{ caseId:'a', tag:'tool-call', score:0.4, passed:false }] },
]));
// tool-call: passRate 0.4, trend ↓, verdict 'fail'
```
**评分点**：
- 按 tag 分维度聚合，不用全局平均分掩盖小维度崩塌。
- 无效分数过滤，空输入返回结构完整的报告而非抛错。
- 趋势相对上一轮、缺维度时不比较（trend=→），逻辑严谨。
- 结论规则 fail/warn/pass 优先级正确，且 with reasons（退步维度可定位）。
- 数值保留小数位、报告可读，体现工程可用性。
