## AIC-485：笔试：批量任务的错峰调度器（配额窗口内均匀分布）。
**答**：任务 n 个，配额每分钟 q 个。实现 `spread(n, q)`：输出每分钟执行数量数组，最后一分钟允许不满；q ≤ 0 抛错。

```javascript
function spread(n, q) {
  if (q <= 0) throw new RangeError('quota must be positive');
  const perMin = [];
  let left = n;
  while (left > 0) {
    const take = Math.min(q, left);
    perMin.push(take); left -= take;
  }
  return perMin;
}
console.log(spread(25, 10)); // [10, 10, 5]
console.log(spread(0, 10));  // []

```

**评分点**：
- 均匀分布：Math.ceil(n/q) 分钟数，每分钟 min(q, 剩余)。
- 边界：n=0 空数组；q<=0 显式报错。
- 总执行数守恒（sum = n）。
- 输出可执行（时长 = 数组长度）。
