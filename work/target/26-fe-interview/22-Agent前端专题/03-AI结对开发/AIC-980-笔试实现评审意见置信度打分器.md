## AIC-980：笔试：实现「评审意见置信度打分器」（综合证据强度/规则确定性/历史准确率）
**答**：
- 核心需求：实现 `scoreConfidence(comment, ctx)`。`comment: { rule, hasEvidence, hasSuggestion, line, severity }`；`ctx: { rulePrecision:number, fileHistory:{falsePositiveRate}, isTestFile }`。返回 `{ score(0~1), level, reasons }`。
- 打分因子：规则历史精确率（rulePrecision，权重 0.4）+ 是否有证据（0.2）+ 是否有建议（0.15）+ 文件历史误报率的反面（1-falsePositiveRate，权重 0.15）+ 严重级别合理性（10% 基础分）。
- level：score≥0.75 高（阻断/强提醒）、0.5~0.75 中（普通提示）、<0.5 低（折叠或仅记录）；测试文件对 certain 规则可降权。
- 边界：rulePrecision 缺失按 0.5；falsePositiveRate 缺失按 0；各因子裁剪 [0,1]；reasons 说明主要得分/扣分来源（可解释）。
- 语义：置信度用于「分级处置」——高置信阻断、低置信折叠，缓解误报骚扰；它排序的是「可信程度」不是「问题严重性」。
- 追问钩子：能区分「置信度（这个报告可信吗）」与「严重性（问题有多严重）」两个正交维度，并强调两者都要有才能决策处置方式的候选人，思路很清晰。

```typescript
const clamp=v=>Math.max(0,Math.min(1,Number.isFinite(v)?v:0.5));
function scoreConfidence(comment={}, ctx={}) {
  const precision=clamp(ctx.rulePrecision??0.5);
  const fpRate=clamp(ctx.fileHistory?.falsePositiveRate??0);
  const factors = {
    rule:precision*0.4,
    evidence:(comment.hasEvidence?1:0)*0.2,
    suggestion:(comment.hasSuggestion?1:0)*0.15,
    fileHistory:(1-fpRate)*0.15,
    base:0.10,
  };
  let score=Object.values(factors).reduce((s,v)=>s+v,0);
  if(ctx.isTestFile) score*=0.8; // 测试文件降权
  score=clamp(score);
  const level=score>=0.75?'高':score>=0.5?'中':'低';
  const reasons=Object.entries(factors).filter(([,v])=>v>0).map(([k])=>k);
  return { score:+score.toFixed(2), level, reasons };
}
console.log(scoreConfidence({hasEvidence:true,hasSuggestion:true},
  {rulePrecision:0.9,fileHistory:{falsePositiveRate:0.1}}));
```
**评分点**：
- 多因子加权打分（规则精确率/证据/建议/文件历史/基础分），权重与裁剪正确。
- level 三档分级（高/中/低）与测试文件降权逻辑正确。
- rulePrecision/falsePositiveRate 缺失默认值，各因子 clamp [0,1]。
- reasons 提供可解释的得分来源，代码可运行。
- 区分「置信度」与「严重性」两个正交维度（加分项）。
