## AIC-517：笔试：手写接受率分析

**答**：实现 `analyzeAcceptance(events, { minSamples })`。events: `CompletionEvent[]`。规则：1) 总接受率 + 逻辑接受率（排除 boilerplate）；2) **修改率告警**：modifyRate > 50% → 'high-modification'（AI 生成的代码被大改——质量差信号）；3) **保留率告警**：retainRate < 70% → 'low-retention'（用户 revert 多——质量差信号）；4) **总评**：acceptRate ≥ 50 && modifyRate ≤ 30 && retainRate ≥ 80 → 'good'；modifyRate > 50 || retainRate < 70 → 'poor'；其余 → 'moderate'。返回 `{ acceptRate, logicAcceptRate, modifyRate, retainRate, verdict }`。边界：events 空（no-data）；total < minSamples（insufficient）；全部 boilerplate（logicAcceptRate null）。

```javascript
function analyzeAcceptance(events = [], { minSamples = 20 } = {}) {
  if (!events.length) return { noData: true, verdict: null };
  const total = events.length;
  const accepted = events.filter(e => e.action === 'accepted' || e.action === 'partial');
  const totalAccepted = accepted.length;
  const logicAccepted = accepted.filter(e => !e.isBoilerplate);
  const acceptRate = +(totalAccepted / total * 100).toFixed(1);
  const logicAcceptRate = totalAccepted
    ? +(logicAccepted.length / totalAccepted * 100).toFixed(1) : null;
  const modifyRate = totalAccepted
    ? +(accepted.filter(e => e.modifiedAfterAccept > 0).length / totalAccepted * 100).toFixed(1) : 0;
  const retainRate = totalAccepted
    ? +(accepted.filter(e => !e.revertedWithin5min).length / totalAccepted * 100).toFixed(1) : 0;
  if (total < minSamples)
    return { acceptRate, logicAcceptRate, modifyRate, retainRate,
      verdict: null, insufficient: true };
  const verdict =
    modifyRate > 50 || retainRate < 70 ? 'poor'
    : acceptRate >= 50 && modifyRate <= 30 && retainRate >= 80 ? 'good'
    : 'moderate';
  return { acceptRate, logicAcceptRate, modifyRate, retainRate, verdict };
}

// 自测
const events = Array.from({ length: 30 }, (_, i) => ({
  ts: i * 60000, language: 'typescript', fileType: 'ts',
  action: i % 3 === 0 ? 'rejected' : 'accepted',        // 2/3 接受
  linesAccepted: 5,
  modifiedAfterAccept: i % 5 === 0 ? 3 : 0,              // 20% 修改
  revertedWithin5min: i % 10 === 0,                      // 10% revert
  isBoilerplate: i % 6 === 0,                            // 1/6 是 boilerplate
}));
let r = analyzeAcceptance(events, { minSamples: 20 });
console.log(r.acceptRate === 66.7);                      // 20/30
console.log(r.verdict === 'moderate' || r.verdict === 'good');

// 高修改率 → poor
const highMod = events.map(e => ({ ...e, modifiedAfterAccept: 10 }));
r = analyzeAcceptance(highMod, { minSamples: 20 });
console.log(r.modifyRate === 100 && r.verdict === 'poor');

// 空
console.log(analyzeAcceptance([]).noData === true);
// 不足
console.log(analyzeAcceptance(events.slice(0, 5), { minSamples: 20 }).insufficient === true);
```

**评分点**：
- 四指标：acceptRate / logicAcceptRate（排除 boilerplate）/ modifyRate / retainRate——层层深入
- 告警：high-modification（AI 代码被大改）与 low-retention（用户 revert）——质量差信号
- 边界（空 no-data/不足 insufficient/全 boilerplate logicAcceptRate null）；verdict 三级
- 能说清「接受率 80% 不等于 AI 好——修改率和保留率才是质量指标：接受后大改 = AI 不准」属于加分
