## AIC-934：笔试：实现审计日志的「防篡改哈希链」结构（含追加、校验、断点检测）
**答**：
- 核心需求：实现 `AuditChain` 类，方法 `append(payload)`、`verify()`、`findBreak()`。`append` 计算 `hash = H(stableStringify({...payload, prev:lastHash, seq}))` 并追加；`seq` 为递增序号。
- verify() 遍历整条链：校验每条记录的 hash 是否与重算一致、prev 是否等于前一条 hash、seq 是否连续——全部通过返回 true。
- findBreak() 返回第一个被篡改或断链的记录下标；若链完整返回 -1。要求对 payload 做稳定序列化（键排序）保证哈希可复现。
- 边界：空链 verify=true、findBreak=-1；payload 含循环引用要处理（可跳过或用占位）；append 返回本次记录的 hash。
- 语义：哈希链保证「Detecting tampering」（发现篡改）而非「Preventing tampering」（阻止篡改）——攻击者若同时改后续所有 hash 仍可伪造，需配合只追加存储/外部时间戳。
- 追问钩子：能指出「哈希链只能检测篡改不能阻止有根攻击者重写整条链，需外部存证增强」的候选人理解安全的相对性。

```typescript
function stable(o){ if(o===null||typeof o!=='object')return JSON.stringify(o);
  if(Array.isArray(o))return '['+o.map(stable).join(',')+']';
  return '{'+Object.keys(o).sort().map(k=>JSON.stringify(k)+':'+stable(o[k])).join(',')+'}'; }
function H(s){ let h=0; for(const c of s) h=(Math.imul(h,31)+c.charCodeAt(0))>>>0; return h; }
class AuditChain {
  constructor(){ this.items=[]; }
  append(payload){
    const seq=this.items.length, prev=seq?this.items[seq-1].hash:0;
    const body={...payload, prev, seq};
    const hash=H(stable(body));
    this.items.push({body,hash}); return hash;
  }
  findBreak(){
    for(let i=0;i<this.items.length;i++){
      const {body,hash}=this.items[i];
      if(H(stable(body))!==hash) return i;
      if(i>0 && body.prev!==this.items[i-1].hash) return i;
    }
    return -1;
  }
  verify(){ return this.findBreak()===-1; }
}
const c=new AuditChain(); c.append({actor:'a'}); c.append({actor:'b'});
c.items[0].body.actor='hacker';
console.log(c.verify(), c.findBreak()); // false, 0
```
**评分点**：
- append 用稳定序列化 + prev + seq 计算 hash，seq 递增。
- verify 重算 hash 并校验 prev 链与 seq 连续性，空链返回 true。
- findBreak 返回第一个篡改/断链下标，完整返回 -1。
- 稳定序列化键排序保证哈希可复现，边界处理完整。
- 明确「检测而非阻止篡改、需外部存证」（加分项）。
