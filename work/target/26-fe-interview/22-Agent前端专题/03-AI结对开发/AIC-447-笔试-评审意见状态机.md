## AIC-447：笔试：实现评审意见的生命周期状态机。
**答**：状态：open → acknowledged → fixed | wontfix → closed。非法迁移（如 fixed 直接 closed 之外的跳变、wontfix → fixed）报错。实现 `transition(review, action)` 纯函数。

```javascript
const TRANSITIONS = {
  open: { acknowledge: 'acknowledged', wontfix: 'wontfix', fix: 'fixed' },
  acknowledged: { fix: 'fixed', wontfix: 'wontfix' },
  fixed: { close: 'closed' },
  wontfix: { close: 'closed' },
  closed: {},
};
function transition(review, action) {
  const next = TRANSITIONS[review.status]?.[action];
  if (!next)
    throw new Error(`非法迁移 ${review.status} --${action}--> ?；合法 action: ${
      Object.keys(TRANSITIONS[review.status] || {})}`);
  return { ...review, status: next };
}
console.log(transition({ status: 'open' }, 'acknowledge')); // acknowledged
try { transition({ status: 'closed' }, 'fix'); } catch (e) { console.log('blocked'); }

```

**评分点**：
- 状态迁移表驱动（而非 if 链）。
- 非法迁移抛错并列出当前合法 action。
- wontfix 终态不可再改（除非 reopen 特例——题目不允许则报错）。
- closed 为终态。
