## AIC-708：笔试：实现结对会话的上下文腐烂检测器

**需求**：实现 `contextRot(messages, opts)`。`messages`: `Array<{ text, symbols? }>`（按时间顺序的对话；`symbols` 为本轮提到的符号名）；`opts.staleSet`: `Set<string>`（已被删除/改名的陈旧符号）；`opts.repeatThreshold`（默认 0.3）、`opts.staleThreshold`（默认 2）。规则：1) 重复率 = 重复文本轮数 / 总轮数（同一文本出现第 2 次及以后计为重复）；2) 陈旧引用数 = 文本中出现 staleSet 内符号的轮数；3) `score = repeatRate * 0.6 + min(staleCount/staleThreshold,1) * 0.4`；4) `shouldReset = repeatRate > repeatThreshold || staleCount > staleThreshold`。边界：messages 空（全 0、false）；文本为空字符串不计重复；符号匹配大小写敏感。

**答**：
- 结论先行：腐烂 = 重复率与陈旧引用共同上升；用加权 score 量化、用硬阈值触发重置，二者结合避免单一信号误报。
- 重复计数要注意「第 2 次起才计」，首轮正常不算重复；score 里陈旧项要 clamp 到 1，防止单信号霸权。
- 追问钩子：为什么陈旧符号引用是强信号？——它证明 AI 仍活在旧上下文里，已无法感知最新代码状态。

```javascript
function contextRot(messages = [], opts = {}) {
  const staleSet = opts.staleSet ?? new Set();
  const repeatThreshold = opts.repeatThreshold ?? 0.3;
  const staleThreshold = opts.staleThreshold ?? 2;
  const seen = new Map();
  let repeats = 0, staleCount = 0;
  for (const m of messages) {
    const text = m.text ?? '';
    if (text) {
      seen.set(text, (seen.get(text) ?? 0) + 1);
      if (seen.get(text) > 1) repeats++;
    }
    const symbols = m.symbols ?? [];
    if (symbols.some(s => staleSet.has(s))) staleCount++;
  }
  const repeatRate = messages.length ? repeats / messages.length : 0;
  const stalePart = staleThreshold ? Math.min(staleCount / staleThreshold, 1) : 0;
  const score = repeatRate * 0.6 + stalePart * 0.4;
  const shouldReset = repeatRate > repeatThreshold || staleCount > staleThreshold;
  return { repeatRate, staleCount, score, shouldReset };
}
const r = contextRot(
  [{ text: 'A?' }, { text: 'A?' }, { text: '用 store', symbols: ['store'] }, { text: 'store', symbols: ['store'] }],
  { staleSet: new Set(['store']), staleThreshold: 2 }
);
console.log(r.repeatRate === 0.25); // 1/4
console.log(r.staleCount === 2);
console.log(r.shouldReset === false); // staleCount 不「大于」阈值
console.log(contextRot([]).shouldReset === false); // 边界
```


**评分点**：
- 重复率统计（第 2 次起才计）与陈旧引用计数正确
- score 加权公式与 clamp（陈旧项封顶 1）
- shouldReset 硬阈值判定（repeatRate 或 staleCount 越界）
- 边界（空消息、符号大小写敏感）处理
