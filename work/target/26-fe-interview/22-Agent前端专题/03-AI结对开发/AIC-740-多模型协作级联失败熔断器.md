## AIC-740：笔试：实现多模型协作的级联失败熔断器

**需求**：实现 `circuit(events, opts)`。`events`: `Array<{ type:'success'|'fail', step:string }>`；`opts.threshold`（连续失败阈值，默认 3）、`cooldown`（冷却期事件数，默认 2）。规则：1) 统计连续失败数 `consecutive`；2) 达到 threshold 时状态置 `open`（熔断），此后 fail/success 事件在冷却期内只递减 `cooldownLeft` 不改变 `consecutive`；3) 冷却期结束（cooldownLeft 归零）状态转 `half-open`，下一个 success 转 `closed` 并清零 consecutive，下一个 fail 重新 open；4) 返回 `{ state, consecutive, cooldownLeft, trippedAtStep? }`。边界：events 空（closed/0/0）；threshold<=0 视为 1。

**答**：
- 结论先行：熔断器三态（closed→open→half-open）是防止级联失败的行业标准；关键是冷却期隔离——熔断后不能立刻恢复，要试探性放行一个请求验证。
- 冷却期事件只用于倒计时，不改变失败计数，否则熔断会反复震荡。
- 追问钩子：为什么需要 half-open 中间态？——直接从 open 回 closed 会在下游仍故障时立即雪崩；half-open 用单次试探安全验证恢复。

```javascript
function circuit(events = [], opts = {}) {
  const threshold = Math.max(1, opts.threshold ?? 3);
  const cooldown = opts.cooldown ?? 2;
  let st = { state: 'closed', consecutive: 0, cooldownLeft: 0 };
  for (const e of events) {
    if (st.state === 'open') {
      st.cooldownLeft--;
      if (st.cooldownLeft <= 0) st.state = 'half-open';
      continue;                                   // 冷却期内不改变计数
    }
    if (st.state === 'half-open') {
      if (e.type === 'success') st = { state: 'closed', consecutive: 0, cooldownLeft: 0 };
      else { st.state = 'open'; st.cooldownLeft = cooldown; st.trippedAtStep = e.step; }
      continue;
    }
    if (e.type === 'success') st.consecutive = 0;
    else {
      st.consecutive++;
      if (st.consecutive >= threshold) {
        st.state = 'open'; st.cooldownLeft = cooldown; st.trippedAtStep = e.step;
      }
    }
  }
  return st;
}
const r = circuit([
  { type: 'fail', step: 'A' }, { type: 'fail', step: 'B' }, { type: 'fail', step: 'C' },
  { type: 'success', step: 'D' }, { type: 'success', step: 'E' },
], { threshold: 3, cooldown: 2 });
console.log(r.state === 'half-open'); // 冷却 2 次后转半开
console.log(r.trippedAtStep === 'C');
console.log(circuit([]).state === 'closed'); // 边界
```


**评分点**：
- 三态流转（closed→open→half-open→closed）
- 冷却期只倒计时、不改变失败计数
- 阈值触发与 trippedAtStep 记录
- 边界（空 events / threshold<=0 按 1）
