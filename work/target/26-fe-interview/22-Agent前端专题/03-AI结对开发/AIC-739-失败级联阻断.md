## AIC-739：多模型协作中失败级联如何阻断

**答**：
- 结论先行：级联失败 = 上游模型出错后，下游模型基于错误输入继续生成，错误被逐层放大；阻断手段是「快速失败 + 结果校验 + 熔断」，不让错误向下游流动。
- 三道闸门：1) 每步输出做校验（schema/规则），失败立即返回而非继续；2) 上游失败时下游不启动（依赖短路）；3) 连续失败触发熔断，暂停整条流水线并告警。
- 关键：错误要「显式传播」而不是被下游当成正常输入——下游必须能区分「上游成功但结果差」和「上游根本失败」。
- 追问钩子：为什么「上游失败下游仍执行」很危险？——下游会把错误输出当事实继续推理，产出看似合理实则基于错误前提的结果，更难发现。

```javascript
// 级联阻断：上游失败则短路，不执行下游
function pipeline(steps) {
  let acc = { ok: true, value: null };
  for (const step of steps) {
    if (!acc.ok) return { ...acc, stoppedAt: step.name }; // 短路：错误不扩散
    const res = step.run(acc.value);
    if (!res.valid) return { ok: false, error: res.error, stoppedAt: step.name }; // 校验失败即停
    acc = { ok: true, value: res.value };
  }
  return acc;
}
console.log(pipeline([
  { name: 'A', run: () => ({ valid: false, error: 'bad' }) },
  { name: 'B', run: () => { throw new Error('不该执行'); } },
])); // { ok:false, error:'bad', stoppedAt:'A' }
```
