## AIC-246：多模型协作时如何设计「任务→模型」路由策略（强模型 vs 快模型 vs 本地模型）？
**答**：
- 按任务特征路由：补全/重命名/格式化走小快模型，架构评审/疑难 debug 走强模型。
- 按上下文长度路由：超长上下文（全仓分析）用长窗口模型，短任务用普通模型。
- 按敏感度路由：涉密代码只走自托管/本地模型，路由层做数据分类打标。
- 路由策略要可配置可回退：主模型配额耗尽或超时自动降级次选，记录降级事件。

```javascript
function route(task: Task): Model {
  if (task.sensitivity === 'secret') return 'local-private';
  if (task.kind === 'completion' || task.loc < 30) return 'fast-mini';
  if (task.kind === 'arch-review' || task.loc > 500) return 'strong-max';
  return 'default-balanced';
}
async function callWithFallback(task: Task) {
  const chain = [route(task), 'default-balanced', 'local-private'];
  for (const m of chain) {
    try { return await call(m, task); }
    catch (e) { log('fallback', { from: m, err: e.code }); }
  }
  throw new Error('all models failed');
}
```
