## AIC-975：笔试：实现「规范版本与生效范围管理器」（按路径/时间/团队解析生效的规则）
**答**：
- 核心需求：实现 `resolveRules(specs, ctx)`。`specs: { id, version, glob, teams?, from?, to?, content }[]`；`ctx: { path, team, date }`。返回当前上下文生效的规则列表（同一 id 多版本取 applicability 最高的一个）。
- 适用性判定：glob 匹配 ctx.path；teams 若存在需包含 ctx.team；from/to 时间窗包含 ctx.date；不满足者过滤掉。
- 版本选择：同一 id 多个候选时，取 from 最近（最新生效）的一条；结果按 id 排序保证确定性。
- 边界：specs 为空返回 []；glob 用简单 * / **；ctx 字段缺失时采用宽松匹配（不因缺失而误过滤）；content 原样返回。
- 语义：这是「规范解析引擎」——把「什么规则在什么范围生效」变成可计算的查询，是规则分层治理的基础设施。
- 追问钩子：能指出「规则解析要可解释——输出应能说明某规则为何生效/另一版本为何被覆盖，便于审计与排障」的候选人理解配置系统的可观测性。

```typescript
function globMatch(p,g){ return new RegExp('^'+String(g).replace(/\*\*/g,'.*').replace(/\*/g,'[^/]*')
  .replace(/[.+?^${}()|[\]\\]/g,'\\$&')+'$').test(p); }
function resolveRules(specs=[], ctx={}) {
  const ok = s =>
    (!s.glob || globMatch(ctx.path||'', s.glob)) &&
    (!s.teams || !ctx.team || s.teams.includes(ctx.team)) &&
    (!s.from || !ctx.date || s.from<=ctx.date) &&
    (!s.to || !ctx.date || s.to>=ctx.date);
  const groups = new Map();
  for (const s of specs.filter(ok)) {
    const cur = groups.get(s.id);
    if (!cur || (s.from||'') > (cur.from||'')) groups.set(s.id, s); // 取最新生效版本
  }
  return [...groups.values()].sort((a,b)=>a.id.localeCompare(b.id));
}
console.log(resolveRules([
  {id:'R1',version:1,glob:'src/**',from:'2026-01-01',content:'old'},
  {id:'R1',version:2,glob:'src/**',from:'2026-11-01',content:'new'},
], {path:'src/a.ts',team:'im',date:'2026-11-23'}).map(r=>r.content)); // ['new']
```
**评分点**：
- 适用性判定：glob/teams/from/to 四维过滤正确，ctx 缺失宽松匹配。
- 同 id 多版本取 from 最新（最近生效）的一条，逻辑正确。
- 结果按 id 排序确定性，content 原样返回。
- 空 specs 等边界处理，glob 转义正确，代码可运行。
- 能说明「解析结果应可解释为何某版本生效」（加分项）。
