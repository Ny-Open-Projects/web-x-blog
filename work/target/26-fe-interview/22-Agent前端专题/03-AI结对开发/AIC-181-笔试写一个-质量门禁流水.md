## AIC-181：笔试：实现一个 AI 质量门禁流水线编排器：串行阶段、条件跳过、超时与失败聚合报告？
**答**：实现 `runGate(stages, ctx)`：
- stages: `[{name, run, when?, timeoutMs?, blockOnFail}]`；when(ctx) 为 false 跳过；
- 每阶段独立超时（超时按失败处理）；blockOnFail=false 的阶段失败只记录不终止；
- 全部跑完后输出聚合报告 `{passed, durationMs, stageResults}`，而非首个失败即退出（信息最大化）；
- 阻断型阶段失败后，后续「依赖型」阶段（dependsOn）自动跳过。

```javascript
function withTimeout(promise, ms, name) {
  return Promise.race([promise, new Promise((_, rej) => setTimeout(
    () => rej(Object.assign(new Error(`${name} 超时 ${ms}ms`), { timeout: true })), ms))]);
}

async function runGate(stages, ctx) {
  const results = [];
  const failed = new Set();
  const t0 = Date.now();
  for (const s of stages) {
    if (s.when && !s.when(ctx)) {
      results.push({ name: s.name, status: 'skipped', reason: 'when=false' });
      continue;
    }
    const deps = s.dependsOn ?? [];
    if (deps.some(d => failed.has(d))) {
      results.push({ name: s.name, status: 'skipped', reason: `依赖失败: ${deps.filter(d => failed.has(d))}` });
      continue;
    }
    try {
      await withTimeout(s.run(ctx), s.timeoutMs ?? 60_000, s.name);
      results.push({ name: s.name, status: 'passed' });
    } catch (e) {
      failed.add(s.name);
      results.push({ name: s.name, status: s.blockOnFail === false ? 'warn' : 'failed',
        error: String(e) });
    }
  }
  const blocking = results.filter(r => r.status === 'failed');
  return { passed: !blocking.length, durationMs: Date.now() - t0, stageResults: results };
}

// 测试
const stages = [
  { name: 'lint', run: async () => {}, timeoutMs: 5000 },
  { name: 'typecheck', run: async () => { throw new Error('TS2322'); } },
  { name: 'unit-test', dependsOn: ['typecheck'], run: async () => {}, blockOnFail: false },
  { name: 'ai-review', when: (c) => c.hasAiCode, run: async () => {}, timeoutMs: 3000 },
];
runGate(stages, { hasAiCode: true }).then(r => console.log(JSON.stringify(r, null, 1)));
// typecheck failed → unit-test skipped（依赖失败）；ai-review 正常执行 → passed:false
```

**评分点**：
1. 「聚合报告」而非快速失败——门禁一次给全量反馈，减少开发者多轮等待；
2. 依赖跳过（dependsOn）与条件跳过（when）两种语义分开；
3. blockOnFail 分级：非阻断阶段失败记 warn 不终止流水线；
4. 每阶段独立超时，超时归类为失败（防挂死流水线）；
5. passed 判定只看阻断型失败。
