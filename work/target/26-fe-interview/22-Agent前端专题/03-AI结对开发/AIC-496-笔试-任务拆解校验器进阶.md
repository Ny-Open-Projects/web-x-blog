## AIC-496：笔试：校验任务拆解的依赖环与粒度。
**答**：拆解 `[{id, deps[], estMin}]`。校验：依赖环（DFS 检测）报环路径；单任务 estMin > 120 分钟标「粒度过粗」；总时长 > 单会话上限（480）提示分批。

```javascript
function validatePlan(tasks) {
  if (!tasks.length) return { ok: false, errors: ['空拆解'] };
  const errors = [];
  const map = new Map(tasks.map(t => [t.id, t]));
  const state = new Map(), path = [];
  const dfs = id => {
    if (state.get(id) === 2) return;
    if (state.get(id) === 1) { errors.push(`依赖环：${[...path, id].join('→')}`); return; }
    state.set(id, 1); path.push(id);
    for (const d of map.get(id)?.deps || []) {
      if (!map.has(d)) errors.push(`${id} 依赖不存在的 ${d}`);
      else dfs(d);
    }
    path.pop(); state.set(id, 2);
  };
  tasks.forEach(t => dfs(t.id));
  tasks.filter(t => t.estMin > 120).forEach(t => errors.push(`${t.id} 粒度过粗（${t.estMin}min）`));
  const total = tasks.reduce((s, t) => s + t.estMin, 0);
  if (total > 480) errors.push(`总时长 ${total}min 超单会话上限，建议分批`);
  return { ok: errors.length === 0, errors };
}
console.log(validatePlan([
  { id: 'a', deps: ['b'], estMin: 60 }, { id: 'b', deps: ['a'], estMin: 60 },
])); // 环 a→b→a

```

**评分点**：
- 环检测 DFS 带路径（不只布尔）。
- 粒度阈值与分批提示双输出。
- 依赖引用不存在的 id 报错定位。
- 空拆解返回 ok:false（没有任务无法执行）。
