## AIC-846：笔试：实现跨源事件关联器，按 session/commit 合并多源数据
**答**：
- 核心需求：实现 `correlate(events)`。事件有三类：`{ source:'ide', sessionId, type, ts }`、`{ source:'ci', commit, sessions: string[], result }`、`{ source:'review', commit, comments }`。输出按 `sessionId` 分组的视图：`{ sessionId, ideEvents, ciResults, reviewComments }`。
- 关联规则：CI 事件通过 `sessions[]` 反查属于哪些 session；review 事件通过 `commit` 找到对应 CI 事件，再间接归属到 session。一个 session 可能关联多个 commit，需合并。
- 边界：无 sessionId 的事件归入 `'unattributed'`；事件时间乱序不影响结果；同一事件重复输入需去重（用事件 id 或内容指纹）；空输入返回 `{}`。
- 追问钩子：追问「一个 commit 关联多个 session 时，质量结果算谁的」——能答出「不要强行归因到单一 session，保留多对多关系，分析时用并集/加权」的候选人避免了虚假精确。

```typescript
type Event =
  | { id: string; source: 'ide'; sessionId: string; type: string; ts: number }
  | { id: string; source: 'ci'; commit: string; sessions: string[]; result: any; ts: number }
  | { id: string; source: 'review'; commit: string; comments: any[]; ts: number };

function correlate(events: Event[]) {
  const seen = new Set<string>();
  const unique = (events ?? []).filter(e => e && !seen.has(e.id) && !!seen.add(e.id));
  const commitToSessions = new Map<string, string[]>();
  const out: Record<string, { ideEvents: any[]; ciResults: any[]; reviewComments: any[] }> = {};
  const ensure = (k: string) => (out[k] ??= { ideEvents: [], ciResults: [], reviewComments: [] });

  for (const e of unique) {
    if (e.source === 'ide') {
      ensure(e.sessionId || 'unattributed').ideEvents.push(e);
    } else if (e.source === 'ci') {
      commitToSessions.set(e.commit, e.sessions);
      for (const s of e.sessions) ensure(s).ciResults.push(e.result);
    }
  }
  for (const e of unique) {
    if (e.source === 'review') {
      const sessions = commitToSessions.get(e.commit) ?? [];
      if (!sessions.length) ensure('unattributed').reviewComments.push(...e.comments);
      for (const s of sessions) ensure(s).reviewComments.push(...e.comments);
    }
  }
  return out;
}
console.log(correlate([
  { id:'1', source:'ide', sessionId:'s1', type:'accept', ts:2 },
  { id:'2', source:'ci', commit:'c1', sessions:['s1'], result:{ passed:true }, ts:3 },
  { id:'3', source:'review', commit:'c1', comments:['LGTM'], ts:4 },
  { id:'1', source:'ide', sessionId:'s1', type:'accept', ts:2 }, // 重复，被去重
]));
// s1: 1 个 ide 事件 + 1 个 ci 结果 + 1 条 review 评论
```
**评分点**：
- 按事件 id 去重，`!seen.has(e.id) && !!seen.add(e.id)` 先判后加：新 id 保留并登记，重复 id 被短路过滤。
- review 通过 commit → sessions 间接关联，处理多对多关系而非强行一对一。
- 未归属事件统一进 `unattributed`，不丢弃数据。
- 两遍遍历解决依赖顺序（先建 commit→session 映射，再处理 review），乱序输入不受影响。
- 空输入与重复输入边界处理到位。
