## AIC-553：笔试：手写上下文权重排序

**答**：实现 `orderContext(context, cursorOffset)`。context: `{ before: string, after: string, imports: string[], related: Array<{ content, priority }> }`. 规则：1) 光标前文本截取最后 500 字符（weight 10）；2) 光标后文本截取前 200 字符（weight 5）；3) imports（weight 3）；4) related 按 priority 排序（weight = priority）；5) 全部按 weight 降序排列，返回 `Array<{ type, content, weight }>`。边界：before < 500 字符（全取）；after < 200（全取）；before 空（跳过）；related 空（跳过）；cursorOffset 忽略（用 before/after 切分好的）。

```javascript
function orderContext(context = {}, cursorOffset = 0) {
  const { before = '', after = '', imports = [], related = [] } = context;
  const items = [];
  if (before) items.push({ type: 'cursor-before', content: before.slice(-500), weight: 10 });
  if (after) items.push({ type: 'cursor-after', content: after.slice(0, 200), weight: 5 });
  if (imports.length) items.push({ type: 'imports', content: imports.join('\n'), weight: 3 });
  related.forEach(r => items.push({ type: 'related', content: r.content, weight: r.priority ?? 0 }));
  return items.sort((a, b) => b.weight - a.weight);
}

// 自测
const ctx = {
  before: 'x'.repeat(600),                              // > 500 → 截取
  after: 'y'.repeat(300),                               // > 200 → 截取
  imports: ['import React', 'import { z }'],
  related: [
    { content: 'related low', priority: 2 },
    { content: 'related high', priority: 8 },
  ],
};
let r = orderContext(ctx);
console.log(r[0].type === 'cursor-before' && r[0].weight === 10);
console.log(r[0].content.length === 500);                // 截取 500
console.log(r[1].type === 'related' && r[1].content === 'related high');   // priority 8 > 5
console.log(r[2].type === 'cursor-after' && r[2].content.length === 200);
console.log(r[3].type === 'imports');
console.log(r[4].type === 'related' && r[4].content === 'related low');

// before < 500 全取
r = orderContext({ before: 'short', after: '', imports: [], related: [] });
console.log(r[0].content === 'short');
// 空
console.log(orderContext({}).length === 0);
```

**评分点**：
- 截取正确（before 后 500 / after 前 200——LLM 的 attention locality bias 近处优先）
- 权重排序（cursor-before 10 > related-high 8 > cursor-after 5 > imports 3——权重可调）；空部分跳过
- 边界（before < 500 全取/空部分/related 排序）
- 能说清「上下文的排序 = LLM attention 的 locality bias：光标前 500 字符的权重 >> 文件开头——近处优先」属于加分
