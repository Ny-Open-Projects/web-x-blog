## AIC-469：笔试：实现评审任务分配（负载 + 领域匹配）。
**答**：评审者 `[{name, load, domains[]}]`，PR `[{id, domain}]`。分配：候选 = 懂该 domain 者，选 load 最小者；无人懂 → 池外 load 最小者并标记 fallback。分配后 load 增 1。

```javascript
function assign(prs, reviewers) {
  const rvs = reviewers.map(r => ({ ...r }));
  return prs.map(pr => {
    const know = rvs.filter(r => r.domains.includes(pr.domain));
    const pool = know.length ? know : rvs;
    pool.sort((a, b) => a.load - b.load);
    const pick = pool[0];
    pick.load++;
    return { prId: pr.id, assignee: pick.name, fallback: know.length === 0 };
  });
}
console.log(assign(
  [{ id: 1, domain: 'ssr' }, { id: 2, domain: 'ssr' }],
  [{ name: 'A', load: 0, domains: ['ssr'] }, { name: 'B', load: 1, domains: ['ssr'] },
   { name: 'C', load: 0, domains: ['perf'] }]));
// pr1→A；pr2 时 A.load=1 与 B.load=1 同分 → 取先者（说明稳定排序）

```

**评分点**：
- 领域匹配优先于负载——专家优先但避免压垮。
- fallback 分支必须有标记（不可静默派给不懂的人）。
- 分配后 load 更新（连续分配不会全压同一人）。
- 输出 {prId, assignee, fallback}。
