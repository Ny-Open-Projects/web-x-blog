## AIC-798：笔试题：实现平台工具的采用与留存分析器

**需求**：实现 `retentionAnalysis(events, opts)`。`events`: `Array<{ user, week, calls }>`；`opts.cohortWeek`（默认取最早周）、`activeMin`（默认 1，calls>=该值为活跃）。规则：1) 首周活跃用户为 cohort（首周 calls>=activeMin）；2) 计算第 0/1/2... 周留存：第 N 周仍活跃（calls>=activeMin）的 cohort 用户数 / cohort 总数；3) 计算每用户总 calls 与人均 calls；4) 返回 `{ cohortSize, byWeek: Record<week, count>, retention: Record<week, number>, avgCalls }`。边界：无 cohort（全 0/空）；某周无数据该周 count=0、retention=0；同一用户同周多条记录取 calls 之和。

**答**：
- 结论先行：留存分析用「同期群（cohort）」——固定首周用户看其后续行为，避免不同周用户混合导致的幸存者偏差。
- 同用户同周多条记录要聚合（求和），否则会重复计数；活跃阈值让「装了不用」的用户不计入。
- 追问钩子：为什么用同期群而非每周活跃总数？——总数可能靠不断拉新维持，掩盖老用户流失；同期群才反映真实留存。

```javascript
function retentionAnalysis(events = [], opts = {}) {
  const activeMin = opts.activeMin ?? 1;
  if (!events.length) return { cohortSize: 0, byWeek: {}, retention: {}, avgCalls: 0 };
  const weeks = [...new Set(events.map(e => e.week))].sort((a, b) => a - b);
  const cohortWeek = opts.cohortWeek ?? weeks[0];
  const callsBy = {}; // user|week -> total calls
  for (const e of events) { const k = e.user + '|' + e.week; callsBy[k] = (callsBy[k] ?? 0) + e.calls; }
  const cohort = [...new Set(events.filter(e => e.week === cohortWeek).map(e => e.user))]
    .filter(u => (callsBy[u + '|' + cohortWeek] ?? 0) >= activeMin);
  const byWeek = {}, retention = {};
  for (const w of weeks) {
    const active = cohort.filter(u => (callsBy[u + '|' + w] ?? 0) >= activeMin);
    byWeek[w] = active.length;
    retention[w] = cohort.length ? +(active.length / cohort.length).toFixed(2) : 0;
  }
  const totalCalls = Object.values(callsBy).reduce((s, c) => s + c, 0);
  return { cohortSize: cohort.length, byWeek, retention, avgCalls: +(totalCalls / (cohort.length || 1)).toFixed(1) };
}
const r = retentionAnalysis([
  { user: 'a', week: 1, calls: 5 }, { user: 'b', week: 1, calls: 0 },
  { user: 'a', week: 2, calls: 3 }, { user: 'b', week: 2, calls: 2 },
]);
console.log(r.cohortSize === 1);        // 仅 a 首周活跃
console.log(r.retention[2] === 1);      // a 第 2 周仍活跃
console.log(retentionAnalysis([]).cohortSize === 0); // 边界
```


**评分点**：
- 同期群（cohort）定义正确
- 同用户同周 calls 求和、第 N 周留存计算
- 活跃阈值 activeMin 与人均 calls
- 边界（空 events / 无 cohort）
