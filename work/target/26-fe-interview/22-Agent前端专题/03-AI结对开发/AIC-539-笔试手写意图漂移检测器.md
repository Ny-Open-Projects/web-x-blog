## AIC-539：笔试：手写意图漂移检测

**答**：实现 `detectIntentDrift(requirements, codePerTurn, { coverageThreshold, maxScopeCreep })`。requirements: `{ keyword, weight }[]`；codePerTurn: `string[]`（每轮生成的代码）。规则（RBL-538）：1) coverage：最终代码中需求关键词的覆盖比例；2) driftTrend：每轮覆盖度的变化趋势（最后一轮 − 第一轮）；3) scopeCreep：代码中的函数名不在需求关键词中的数量；4) drifted = coverage < 80 || driftTrend < -10 || scopeCreep > 3。返回 `{ coverage, driftTrend, scopeCreep, drifted, coveragePerTurn }`。边界：codePerTurn 空（coverage 0）；requirements 空（coverage 100——无需求即无漂移）；单轮（driftTrend 0）；coverage 恰好 80（不漂移——严格小于）。

```javascript
function detectIntentDrift(requirements = [], codePerTurn = [],
  { coverageThreshold = 80, maxScopeCreep = 3 } = {}) {
  if (!codePerTurn.length)
    return { coverage: 0, driftTrend: 0, scopeCreep: [], drifted: false, coveragePerTurn: [] };
  if (!requirements.length)
    return { coverage: 100, driftTrend: 0, scopeCreep: [], drifted: false,
      coveragePerTurn: codePerTurn.map(() => 100) };
  const check = (code) => requirements.filter(r =>
    code.toLowerCase().includes(r.keyword.toLowerCase())).length / requirements.length * 100;
  const coveragePerTurn = codePerTurn.map(check);
  const coverage = +coveragePerTurn.at(-1).toFixed(1);
  const driftTrend = coveragePerTurn.length >= 2
    ? +(coveragePerTurn.at(-1) - coveragePerTurn[0]).toFixed(1) : 0;
  const reqKeywords = new Set(requirements.map(r => r.keyword.toLowerCase()));
  const fnNames = [...codePerTurn.at(-1).matchAll(/(?:function|const)\s+(\w+)/g)]
    .map(m => m[1].toLowerCase());
  const scopeCreep = [...new Set(fnNames.filter(k => !reqKeywords.has(k)))];
  const drifted = coverage < coverageThreshold || driftTrend < -10 || scopeCreep.length > maxScopeCreep;
  return { coverage, driftTrend, scopeCreep, drifted, coveragePerTurn: coveragePerTurn.map(x => +x.toFixed(1)) };
}

// 自测
const reqs = [
  { keyword: 'search', weight: 3 }, { keyword: 'filter', weight: 2 }, { keyword: 'pagination', weight: 2 },
];
// 无漂移
let r = detectIntentDrift(reqs, [
  'function searchProducts() {} function filterProducts() {} function paginate() {}',
  'function searchProducts() {} function filterProducts() {} function paginate() {} function searchHelper() {}',
]);
console.log(r.coverage === 100 && r.drifted === false);
console.log(r.scopeCreep.length === 1);                  // searchHelper 不在需求中

// 漂移：轮次增加覆盖递减
r = detectIntentDrift(reqs, [
  'function searchProducts() {} function filterProducts() {} function paginate() {}',
  'function searchProducts() {} function filterProducts() {}',
  'function searchProducts() {}',                        // 只剩 search
]);
console.log(r.coverage === 33.3);                        // 1/3
console.log(r.driftTrend === -66.7);                     // 100 → 66.7 → 33.3
console.log(r.drifted === true);                         // 覆盖 < 80 且趋势 < -10

// 恰好 80：不漂移
r = detectIntentDrift(reqs, [
  'search filter',                                       // 2/3 = 66.7%
  'search filter pagination extra',                      // 3/3 = 100% + 1 scope
], {});
console.log(r.coverage === 100);                         // 第二轮恢复了

// 空
r = detectIntentDrift(reqs, []);
console.log(r.coverage === 0 && r.drifted === false);    // 空 code 不算漂移
```

**评分点**：
- 三维检测：覆盖率（需求关键词命中）/ driftTrend（轮次趋势）/ scopeCreep（超出需求的功能）
- coverage < 80 的阈值语义（严格小于——恰等不触发）；scopeCreep 的函数名提取
- 边界（空 codePerTurn/空 requirements/单轮/恰好 80）；coveragePerTurn 的趋势可视化
- 能说清「LLM 的注意力稀释导致多轮对话中原始需求权重递减——每轮覆盖度趋势是意图漂移的量化指标」属于加分
