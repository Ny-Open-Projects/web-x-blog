## AIC-807：笔试：实现多模型加权投票聚合器，输出答案/置信度/分歧度
**答**：
- 核心需求：输入 `votes: { modelId, answer, weight }[]`，返回 `{ answer, confidence, disagreement }`。权重先归一化为概率；`confidence = 赢家权重和 / 总权重`；`disagreement = 1 - 归一熵`（答案越分散分歧越大）。平票时按 `modelId` 字典序取前者保证确定性。
- 边界：空数组返回 `{ answer: null, confidence: 0, disagreement: 0 }`；`weight <= 0` 视为 1；答案需 trim，空答案剔除；权重全为 0 时回退等权。
- 歧义处理：分歧度高于 0.6 时建议仲裁，聚合器只给信号不擅自裁决。
- 追问钩子：追问「为什么用归一熵而不是票数差」——能答出「熵能反映多答案分散程度，票数差只看前两名」的候选人理解信息论在工程质量中的应用。

```typescript
type Vote = { modelId: string; answer: string; weight?: number };

function aggregate(votes: Vote[]) {
  const valid = (votes ?? [])
    .map(v => ({ ...v, answer: (v.answer ?? '').trim(), weight: v.weight ?? 1 }))
    .filter(v => v.answer && v.weight > 0);
  if (!valid.length) return { answer: null as string | null, confidence: 0, disagreement: 0 };

  const total = valid.reduce((s, v) => s + v.weight, 0);
  const groups = new Map<string, number>();
  for (const v of valid) groups.set(v.answer, (groups.get(v.answer) ?? 0) + v.weight / total);

  const ranked = [...groups.entries()].sort(
    (a, b) => b[1] - a[1] || a[0].localeCompare(b[0])); // 平票按字典序，确定性
  const [answer, confidence] = ranked[0];
  const entropy = -ranked.reduce((s, [, p]) => s + p * Math.log2(p), 0);
  const maxEnt = Math.log2(groups.size || 1);
  const disagreement = maxEnt === 0 ? 0 : +(entropy / maxEnt).toFixed(3);
  return { answer, confidence: +confidence.toFixed(3), disagreement };
}

console.log(aggregate([
  { modelId: 'm1', answer: 'A', weight: 3 },
  { modelId: 'm2', answer: 'A', weight: 2 },
  { modelId: 'm3', answer: 'B', weight: 1 },
])); // { answer:'A', confidence:0.833, disagreement:0.918 }
console.log(aggregate([])); // { answer:null, confidence:0, disagreement:0 }
```
**评分点**：
- 权重先归一化再统计，不能直接用原始 weight 算比例。
- 平票用 `localeCompare` 做确定性 tie-break，避免结果随输入顺序漂移。
- 空答案/非法权重过滤，空输入返回安全默认值而非 NaN。
- 熵按 `entropy / log2(n)` 归一化到 [0,1]，处理 `n=1` 时除零（maxEnt=0）。
- 能解释「分歧度是信号、不是裁决」体现边界意识。
