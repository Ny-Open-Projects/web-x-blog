## AIC-829：笔试：实现质量门禁规则引擎，多规则聚合决策
**答**：
- 核心需求：实现 `evaluate(ctx, rules)`。规则 `{ id, level: 'block'|'warn'|'inform', when(ctx): boolean, confidence?: number }`。聚合逻辑：任一 `block` 且 confidence ≥ 0.9 命中 → 整体 `block`；否则有 `warn` 命中 → `warn`；否则 `pass`。返回 `{ decision, hits, reasons }`。
- 边界：规则执行抛错不能让整个门禁崩溃——捕获后降级为 `inform` 并记录（fail-open 但要留痕）；`when` 不是函数则跳过；空规则返回 pass；`confidence` 非法视为 1。
- 可解释性：`reasons` 要说清「哪条规则、什么级别、为什么命中」，让开发能快速修复，而不是只给一个红灯。
- 追问钩子：追问「为什么规则执行失败要 fail-open 而不是 fail-close」——能答出「门禁自身故障不应阻塞全部交付，但必须告警并留痕」的候选人理解可用性权衡。

```typescript
type Level = 'block' | 'warn' | 'inform';
type Rule = { id: string; level: Level; when: (ctx: any) => boolean; confidence?: number };
type Hit = { rule: string; level: Level; reason: string };

function evaluate(ctx: any, rules: Rule[]) {
  const hits: Hit[] = [];
  for (const r of rules ?? []) {
    try {
      if (typeof r.when !== 'function') continue;
      if (!r.when(ctx)) continue;
      const conf = Number.isFinite(r.confidence) ? r.confidence! : 1;
      const level: Level = r.level === 'block' && conf < 0.9 ? 'warn' : r.level;
      hits.push({ rule: r.id, level, reason: `${r.id} matched (confidence=${conf})` });
    } catch (e) {
      // 规则自身异常：降级为 inform，不拖垮门禁，但留痕
      hits.push({ rule: r.id, level: 'inform', reason: `rule error: ${(e as Error).message}` });
    }
  }
  const decision: Level = hits.some(h => h.level === 'block') ? 'block'
    : hits.some(h => h.level === 'warn') ? 'warn' : 'pass';
  return { decision, hits, reasons: hits.map(h => h.reason) };
}

const rules: Rule[] = [
  { id: 'no-secret', level: 'block', when: c => /sk-[a-z0-9]{20}/.test(c.diff), confidence: 0.95 },
  { id: 'max-lines', level: 'warn', when: c => c.addedLines > 500 },
  { id: 'ai-ratio', level: 'inform', when: () => true },
];
console.log(evaluate({ diff: 'const key = "sk-xxxxxxxxxxxxxxxxxxxx"', addedLines: 10 }, rules).decision);
// 'block'
```
**评分点**：
- block 规则按 confidence 阈值（0.9）降级为 warn，不是无条件阻断。
- 规则执行异常被捕获降级为 inform + 留痕，fail-open 而非崩溃。
- 聚合优先级 block > warn > inform > pass 正确。
- `when` 非函数跳过、confidence 非法默认 1 的边界处理。
- 返回 reasons 可解释，便于开发定位（工程可用性）。
