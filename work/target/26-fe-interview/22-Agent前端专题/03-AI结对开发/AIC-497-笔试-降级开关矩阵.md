## AIC-497：笔试：AI 能力降级开关矩阵（按故障类型选降级）。
**答**：故障 `fault: 'quota'|'network'|'model-degraded'` 与能力集。矩阵：quota → 关批量任务保交互；network → 全降本地；model-degraded → 加严门禁不关功能。实现 `degradePlan(fault)` 输出动作清单。

```javascript
const MATRIX = {
  quota: ['pause-batch-tasks', 'keep-interactive', 'alert'],
  network: ['switch-local-model', 'queue-cloud-tasks', 'alert'],
  'model-degraded': ['tighten-gates', 'keep-features', 'canary-eval'],
};
function degradePlan(fault) {
  const actions = MATRIX[fault];
  if (!actions) return ['switch-local-model', 'tighten-gates', 'alert']; // 保守
  return actions;
}
console.log(degradePlan('quota'));        // 保交互关批量
console.log(degradePlan('unknown-x'));    // 保守降级

```

**评分点**：
- 矩阵查表（故障 → 动作集）。
- 动作可执行（带对象与参数）。
- 未知故障保守降级（全保本地 + 告警）。
- 输出排序：先保关键路径。
