## AIC-657：笔试：手写缺陷逃逸分析器

**答**：实现 `analyzeEscapes(defects, opts)`。defects: `{id:string, source:'ai'|'human', foundStage:'dev'|'review'|'test'|'canary'|'prod', cause:string, severity:'low'|'high'}[]`；opts: `{ escapeStages?:string[], alertRate?:number }`（默认 escapeStages=['canary','prod'], alertRate=0.2）。规则：1) 逃逸 = foundStage 在 escapeStages；2) 按 source 分组算逃逸率（逃逸数/组总数），无缺陷组记 0；3) 按 cause 统计逃逸缺陷分布（只统计逃逸的）；4) 高危逃逸数（severity=high 且逃逸）；5) 告警条件：ai 逃逸率 > alertRate 或 高危逃逸数 ≥ 3；6) 返回 `{ bySource:{ai:number,human:number}, causeDistribution:Record<string,number>, highSeverityEscapes:number, alert:boolean, suggestions:string[] }`，suggestions 按最高频 cause 给出对应建议（context-missing→补rules, intent-drift→强化任务卡, edge-case→加属性测试, review-miss→改审查清单）。边界：defects 空全 0 不告警。

```javascript
function analyzeEscapes(defects = [], opts = {}) {
  const { escapeStages = ['canary', 'prod'], alertRate = 0.2 } = opts;
  const isEscape = d => escapeStages.includes(d.foundStage);
  const escaped = defects.filter(isEscape);
  const rate = src => {
    const all = defects.filter(d => d.source === src);
    return all.length ? all.filter(isEscape).length / all.length : 0;
  };
  const bySource = { ai: rate('ai'), human: rate('human') };
  const causeDistribution = {};
  for (const d of escaped) causeDistribution[d.cause] = (causeDistribution[d.cause] || 0) + 1;
  const highSeverityEscapes = escaped.filter(d => d.severity === 'high').length;
  const alert = bySource.ai > alertRate || highSeverityEscapes >= 3;
  const suggestionMap = {
    'context-missing': '补充 rules/代码地图，让 AI 了解内部框架',
    'intent-drift': '强化任务卡与意图锚点',
    'edge-case': '增加属性测试覆盖边界',
    'review-miss': '改进 AI 代码审查清单',
  };
  const topCause = Object.entries(causeDistribution).sort((a, b) => b[1] - a[1])[0]?.[0];
  const suggestions = topCause && suggestionMap[topCause] ? [suggestionMap[topCause]] : [];
  return { bySource, causeDistribution, highSeverityEscapes, alert, suggestions };
}

// 自测
const defects = [
  { id: '1', source: 'ai', foundStage: 'prod', cause: 'context-missing', severity: 'high' },
  { id: '2', source: 'ai', foundStage: 'test', cause: 'edge-case', severity: 'low' },
  { id: '3', source: 'ai', foundStage: 'canary', cause: 'context-missing', severity: 'high' },
  { id: '4', source: 'human', foundStage: 'prod', cause: 'edge-case', severity: 'low' },
];
const r = analyzeEscapes(defects);
console.log(r.bySource.ai === 2 / 3);
console.log(r.causeDistribution['context-missing'] === 2);
console.log(r.alert === true);
console.log(r.suggestions[0].includes('rules'));
console.log(analyzeEscapes([]).alert === false);
```

**评分点**：
- 逃逸判定与按 source 分组逃逸率正确
- causeDistribution 只统计逃逸缺陷
- highSeverityEscapes 与告警条件（ai率>阈值 或 高危≥3）
- suggestions 按最高频 cause 映射对应改进建议
- 能说清「区分 AI/人工逃逸率是关键——AI 显著更高说明防线对 AI 新失效模式不适用」属于加分
