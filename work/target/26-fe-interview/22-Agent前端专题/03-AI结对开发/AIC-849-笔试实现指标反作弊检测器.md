## AIC-849：笔试：实现指标反作弊检测器，识别异常分布
**答**：
- 核心需求：实现 `detectGaming(records, baseline)`。`records: { dev, adoption, survival, revertRate, reviewSec, suggestions }[]`；返回 `{ dev, flags, score }[]`，只返回有异常的开发者。规则：① 采纳率 > 0.95 且存活率 < 0.4；② 采纳率 > 0.8 且 reviewSec < 3；③ revertRate > 0.5 且 adoption > 0.8。
- 统计增强：用 **z-score** 检测「建议数远超团队均值 +3σ」的异常高频采纳；分数 = 命中规则数 + z-score 超限加成；score ≥ 2 才标记，减少误报。
- 边界：样本数 < 5 的开发者跳过统计检测（数据量不足）；字段缺失按 0 处理但不误判；survival 等比率裁剪到 [0,1]。
- 追问钩子：追问「检测到作弊就处罚吗」——能答出「只作为复核信号，不自动处罚；且根因往往是指标设计问题（AIC-848）」的候选人有系统观。

```typescript
type Rec = { dev: string; adoption: number; survival: number; revertRate: number; reviewSec: number; suggestions: number };

function detectGaming(records: Rec[]) {
  const n = records.length;
  const mean = records.reduce((s, r) => s + r.suggestions, 0) / (n || 1);
  const std = Math.sqrt(records.reduce((s, r) => s + (r.suggestions - mean) ** 2, 0) / (n || 1)) || 1;
  const out: Array<{ dev: string; flags: string[]; score: number }> = [];
  for (const r of records ?? []) {
    const flags: string[] = [];
    if (r.adoption > 0.95 && r.survival < 0.4) flags.push('高采纳低存活');
    if (r.adoption > 0.8 && r.reviewSec < 3) flags.push('review 过短');
    if (r.revertRate > 0.5 && r.adoption > 0.8) flags.push('高回滚高采纳');
    let score = flags.length;
    if (n >= 5 && (r.suggestions - mean) / std > 3) { flags.push('建议数 3σ 异常'); score++; }
    if (score >= 2) out.push({ dev: r.dev, flags, score });
  }
  return out; // 仅返回疑似对象，供人工复核，不自动处罚
}
console.log(detectGaming([
  { dev:'normal', adoption:0.6, survival:0.7, revertRate:0.1, reviewSec:30, suggestions:100 },
  { dev:'gamer',  adoption:0.99, survival:0.1, revertRate:0.7, reviewSec:1, suggestions:5000 },
])); // [{ dev:'gamer', flags:[...], score:3 }]
```
**评分点**：
- 多规则组合判定，单规则不直接定罪，score ≥ 2 阈值降低误报。
- z-score 检测异常高频，样本 < 5 跳过统计判定（小样本不可靠）。
- std 加 `|| 1` 防常量序列除零；缺失字段不误判为作弊。
- 输出是「复核信号」而非自动处罚，体现制度层面的克制。
- 比率裁剪与边界处理严谨。
