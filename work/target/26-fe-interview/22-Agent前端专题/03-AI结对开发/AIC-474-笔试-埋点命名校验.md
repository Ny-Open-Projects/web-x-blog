## AIC-474：笔试：实现埋点命名规范校验器。
**答**：规范：`域.对象.动作`（三段，小写下划线）。校验事件名列表：格式错误/保留字（如 `test`）/重复名。输出 `{invalid, duplicates}`。

```javascript
function validateEvents(events, reserved = ['test', 'debug']) {
  const RE = /^[a-z][a-z0-9_]*(?:\.[a-z][a-z0-9_]*){2}$/;
  const invalid = [], seen = new Map(), duplicates = [];
  for (const e of events) {
    const head = e.split('.')[0];
    if (!RE.test(e)) invalid.push({ event: e, reason: '格式不符 域.对象.动作' });
    else if (reserved.includes(head)) invalid.push({ event: e, reason: '保留字' });
    const key = e.toLowerCase();
    if (seen.has(key)) duplicates.push(e);
    else seen.set(key, 1);
  }
  return { invalid, duplicates };
}
console.log(validateEvents(['cart.item.add', 'Cart.Item.Add', 'cart.add', 'test.page.view']));
// invalid: cart.add（两段）、test.page.view（保留字）；duplicates: Cart.Item.Add

```

**评分点**：
- 正则：`^[a-z][a-z0-9_]*(?:\.[a-z][a-z0-9_]*){2}$` 且三段。
- 重复检测（大小写归一后比较——大写变体也算重复）。
- invalid 带原因（格式/保留字）。
- 保留字集合可配置。
