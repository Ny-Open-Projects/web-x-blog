## AIC-752：AI 质量工程中黄金数据集如何建设

**答**：
- 结论先行：黄金数据集 = 一组「输入 + 标准答案 + 评分标准」的基准用例，用来客观评测模型/prompt/规则变更的优劣；没有它，所有「质量提升」都是主观感觉。
- 建设步骤：1) 从真实生产任务与历史 badcase 取样；2) 人工标注标准答案与评分点；3) 分层覆盖（简单/中等/困难、不同业务域）；4) 版本化并定期刷新，防止模型过拟合固定题。
- 关键原则：评测集要与训练集/日常 prompt 隔离；标注要有一致性校验（多人标注取共识），否则标准本身不可信。
- 追问钩子：为什么黄金数据集要定期刷新？——模型升级与业务变化会让旧题失去代表性，甚至被针对性优化过拟合。

```javascript
// 黄金数据集条目结构
const GOLDEN = [
  { id: 'g1', level: 'easy', domain: 'list', input: '空数组', expected: '显示空态', points: ['不崩溃', '有占位'] },
  { id: 'g2', level: 'hard', domain: 'pay', input: '并发支付', expected: '幂等', points: ['不重复扣款'] },
];
function evaluate(actualFn, ds) {
  return ds.map(g => {
    const out = actualFn(g.input);
    return { id: g.id, pass: g.points.every(p => out.includes(p)) };
  });
}
console.log(evaluate(i => i === '空数组' ? ['不崩溃', '有占位'] : [], GOLDEN)[0].pass); // true
```
