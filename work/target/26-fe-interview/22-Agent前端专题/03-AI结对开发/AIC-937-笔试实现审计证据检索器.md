## AIC-937：笔试：实现「审计证据检索器」（按时间/文件/任务多维过滤 + 血缘扩展 + 摘要）
**答**：
- 核心需求：实现 `queryEvidence(records, query)`。`records: { id, at, file, task, session, hash, parents }[]`；`query: { timeRange:[start,end], files?, tasks?, sessions?, expandBlood? }`。返回 `{ items, digest, total }`。
- 过滤：at 落在 timeRange 内；files/tasks/sessions 若提供则按包含匹配（任一命中即可，OR 关系）；所有条件 AND 组合。
- 血缘扩展：expandBlood=true 时，对命中项的 parents（父记录 id）递归纳入祖先记录（用 Set 去重防环），扩展项一并进入结果。
- 边界：空 records 返回 items=[]/total=0；timeRange 缺失表示不限时间；digest = 所有结果 hash 按 id 排序拼接后计算稳定哈希。
- 语义：结果按 id 排序保证确定性；摘要用于证明证据集完整性（呼应 AIC-936 裁剪）。
- 追问钩子：能指出「OR/AND 组合语义要明确、血缘递归要防环、摘要要绑定排序结果」的候选人，把检索做成了可信证据管道。

```typescript
function stableHash(s){ let h=0; for(const c of s) h=(Math.imul(h,31)+c.charCodeAt(0))>>>0; return h; }
function queryEvidence(records = [], query = {}) {
  const { timeRange, files, tasks, sessions, expandBlood } = query;
  const inArr = (v, arr) => !arr || arr.includes(v);
  let items = records.filter(r =>
    (!timeRange || (r.at >= timeRange[0] && r.at <= timeRange[1])) &&
    inArr(r.file, files) && inArr(r.task, tasks) && inArr(r.session, sessions));
  if (expandBlood) {
    const map = new Map(records.map(r => [r.id, r])), ids = new Set();
    const collect = id => { const r = map.get(id); if(!r||ids.has(id))return;
      ids.add(id); (r.parents||[]).forEach(collect); };
    items.forEach(r => collect(r.id));
    items = records.filter(r => ids.has(r.id));
  }
  items = items.slice().sort((a,b) => a.id - b.id);
  const digest = stableHash(items.map(r => r.hash).join('|'));
  return { items, digest, total:items.length };
}
console.log(queryEvidence([{id:1,at:5,file:'a',hash:'x',parents:[]}], {timeRange:[0,10]}).total);
```
**评分点**：
- 多维过滤：timeRange 区间 + files/tasks/sessions 的 OR 匹配 + 条件 AND 组合。
- 血缘扩展递归纳入祖先，用 Set 去重防环。
- 结果按 id 排序，digest 基于排序后 hash 拼接保证确定性。
- 空 records / 缺失 timeRange 等边界处理正确。
- 返回 items/digest/total 结构完整，可运行。
