## AIC-913：笔试：实现「多模型交叉验证投票器」（一致性门槛 + 分歧报告，用于高确定性要求场景）
**答**：
- 核心需求：实现 `crossValidate(responses, opts)`。`responses: { model, output }[]`；`opts.threshold` 默认 0.8（一致率门槛）。返回 `{ pass, agreement, clusters, disagreements }`。
- 按 output 归一化后聚类（去空白、统一引号），`agreement = 最大簇大小 / 总数`；`pass = agreement >= threshold`。
- 分歧报告 `disagreements` 要列出「少数派输出及其模型」，便于人工裁决；`clusters` 为 `{ output, models, count }` 按 count 降序。
- 边界：空 responses 返回 pass=false/agreement=0；单个响应 agreement=1；threshold 裁剪到 [0,1]；归一化要处理换行与多余空白。
- 语义：投票只提高「置信度」不保证「正确性」——三个模型都错时仍会通过，高风险场景需配合参考实现验证。
- 追问钩子：能指出「投票是有成本的一致性放大，不是真理判定；模型同质化会让投票失效」的候选人理解其局限。

```typescript
function crossValidate(responses = [], opts = {}) {
  const threshold = Math.max(0, Math.min(1, opts.threshold ?? 0.8));
  if (!responses.length) return { pass:false, agreement:0, clusters:[], disagreements:[] };
  const norm = s => String(s ?? '').replace(/\s+/g,' ').replace(/['"]/g,'"').trim();
  const map = new Map();
  for (const r of responses) {
    const k = norm(r.output);
    if (!map.has(k)) map.set(k, { output:k, models:[], count:0 });
    const c = map.get(k); c.models.push(r.model); c.count++;
  }
  const clusters = [...map.values()].sort((a,b)=>b.count-a.count);
  const agreement = clusters[0].count / responses.length;
  const disagreements = clusters.slice(1).flatMap(c => c.models.map(m => ({ model:m, output:c.output })));
  return { pass: agreement >= threshold, agreement:+agreement.toFixed(2), clusters, disagreements };
}
console.log(crossValidate([{model:'A',output:'x=1'},{model:'B',output:'x = 1'},{model:'C',output:'x=2'}]));
```
**评分点**：
- output 归一化（空白/引号）后聚类，agreement = 最大簇/总数。
- pass 由 threshold 判定且 threshold 裁剪 [0,1]，空输入边界正确。
- clusters 按 count 降序，disagreements 列出少数派模型与输出。
- 返回结构完整、代码可运行，分歧报告可用于人工裁决。
- 明确「一致性≠正确性、同质模型投票失效」（加分项）。
