## AIC-480：笔试：评审意见抽样复核流程（判定正确/错误采纳）。
**答**：输入意见与人工复核结果 `[{id, verdict: 'correct'|'wrong-adoption'|'false-positive'}]`。输出正确率与错误采纳率；false-positive 率 > 20% 时建议收紧评审提示词。

```javascript
function auditReviews(sampled) {
  const c = { correct: 0, wrongAdoption: 0, falsePositive: 0 };
  for (const s of sampled) {
    if (s.verdict === 'correct') c.correct++;
    else if (s.verdict === 'wrong-adoption') c.wrongAdoption++;
    else c.falsePositive++;
  }
  const n = sampled.length;
  const fpRate = n ? c.falsePositive / n : 0;
  return { n, correctRate: n ? +(c.correct / n).toFixed(2) : 0,
           fpRate: +fpRate.toFixed(2),
           suggest: fpRate > 0.2 ? '误报率过高：收紧评审提示词（限定评审范围）' : 'keep' };
}
console.log(auditReviews([
  { id: 1, verdict: 'correct' }, { id: 2, verdict: 'correct' },
  { id: 3, verdict: 'false-positive' }, { id: 4, verdict: 'wrong-adoption' },
])); // fpRate 0.25 → 收紧建议

```

**评分点**：
- 三分类互斥统计。
- 两个独立率指标（正确率/误报率）不要混淆。
- 阈值建议（> 20% 收紧）。
- 样本总数输出（判定可信度参考）。
