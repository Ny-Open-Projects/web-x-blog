## AIC-960：笔试：实现「重构影响面分析器」（调用图 + 契约边界，找出会被重构波及的范围）
**答**：
- 核心需求：实现 `analyzeImpact(graph, targets, opts)`。`graph: { file, imports:[], exports:[], contracts:[] }[]`；`targets` 为计划重构的文件。返回 `{ direct, transitive, boundaryContracts, risk }`。
- 计算：direct = 直接 import 了 targets 的文件；transitive = 沿 import 关系递归的传播集（直接+间接依赖方），用 Set 防环；boundaryContracts = targets 的 exports 中被外部引用的契约名。
- risk 评分：基于 transitive 数量 + boundaryContracts 数量（如 `risk = min(10, transitive.size + boundaryContracts.length)`），用于决策是否需要更谨慎的流程。
- 边界：targets 不存在于 graph 时忽略；空 targets 返回空影响面 risk=0；graph 的 imports 用文件路径字符串。
- 语义：影响面分析用于「重构范围评估」——它给的是静态依赖视角，动态调用/反射仍是盲区（呼应 AIC-959）。
- 追问钩子：能指出「调用图是静态的、会漏动态依赖，所以影响面分析给的是下界估计，实际范围可能更大」的候选人理解静态分析的局限。

```typescript
function analyzeImpact(graph=[], targets=[], opts={}) {
  const targetSet = new Set(targets.filter(t=>graph.some(g=>g.file===t)));
  const importers = new Map();
  for (const g of graph) for (const imp of g.imports||[])
    if (!importers.has(imp)) importers.set(imp, []), importers.get(imp).push(g.file);
  const direct = new Set(), transitive = new Set();
  const queue = [...targetSet];
  while(queue.length){
    const cur = queue.shift();
    for (const f of importers.get(cur)||[]) {
      if(!transitive.has(f)){ transitive.add(f); direct.add(f); queue.push(f); }
    }
  }
  const exportedNames = new Set(graph.filter(g=>targetSet.has(g.file)).flatMap(g=>g.exports||[]));
  const boundaryContracts = [...exportedNames].filter(n =>
    graph.some(g=>!targetSet.has(g.file) && (g.imports||[]).some(i=>String(i).includes(n))));
  const risk = Math.min(10, transitive.size + boundaryContracts.length);
  return { direct:[...direct], transitive:[...transitive], boundaryContracts, risk };
}
console.log(analyzeImpact([
  {file:'price.ts',imports:[],exports:['computePrice']},
  {file:'list.ts',imports:['price.ts'],exports:[]},
], ['price.ts']));
```
**评分点**：
- direct 为直接 import 方，transitive 沿 import 递归传播且用 Set 防环。
- boundaryContracts 找出被外部引用的导出契约，逻辑正确。
- risk 基于传播范围与契约数评分并封顶，决策价值明确。
- targets 不存在/空 targets 等边界处理正确。
- 明确「静态调用图是下界估计、漏动态依赖」（加分项）。
