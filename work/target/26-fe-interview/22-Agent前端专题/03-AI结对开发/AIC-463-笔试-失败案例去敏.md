## AIC-463：笔试：实现失败案例入库前的自动去敏。
**答**：案例文本中的敏感信息替换：内部域名 → `<INT-DOMAIN>`、密钥模式 → `<REDACTED>`、员工名（名单匹配）→ `<NAME>`。返回去敏文本与替换计数，命中密钥时额外标记 `critical:true`。

```javascript
function sanitize(text, names) {
  const counts = { key: 0, domain: 0, name: 0 };
  let out = text.replace(/(?:sk-|AKIA)[A-Za-z0-9]{16,}/g, () => { counts.key++; return '<REDACTED>'; });
  out = out.replace(/[a-z0-9-]+\.internal\.[a-z.]+/gi, () => { counts.domain++; return '<INT-DOMAIN>'; });
  for (const n of names) {
    out = out.split(n).join('<NAME>');
    counts.name += text.split(n).length - 1;
  }
  return { text: out, counts, critical: counts.key > 0 };
}
console.log(sanitize('王五在 api.internal.example 用 sk-abcdefghij1234567890 调试', ['王五']));
// critical: true，密钥与域名与姓名全部替换

```

**评分点**：
- 三类模式齐备且替换顺序：密钥最先（避免域名替换破坏密钥上下文）。
- 计数按类别统计。
- critical 判定：密钥类命中即 true（无论数量）。
- 替换不可逆（不留前缀后缀提示）。
