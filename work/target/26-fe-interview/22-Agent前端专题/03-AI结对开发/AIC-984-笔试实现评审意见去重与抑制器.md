## AIC-984：笔试：实现「评审意见去重与抑制器」（按位置归一化去重 + 带过期的抑制规则）
**答**：
- 核心需求：实现 `filterReviews(comments, suppressions)`。`comments: { id, rule, file, line, code, msg }[]`；`suppressions: { rule, file, fp, expires }[]`（fp 为代码指纹数字）。返回 `{ kept, deduped, suppressed }`（都是 comment id 列表）。
- 去重：同一 `rule + file + 归一化的 code`（去空白/小写）视为重复，只保留首次出现的 id，其余进 deduped——跨 PR 的同一问题也据此合并。
- 抑制：若 comment 的 rule+file 命中某条 suppression 且该条未过期（expires >= today，today 由 opts.today 传入）且指纹匹配，则进 suppressed；expired 的抑制规则忽略。
- 边界：comments 为空返回三空列表；expires 缺失视为永不过期；指纹计算用简单字符串哈希（去空白）；同一 comment 先去重再判抑制，不重复归类。
- 语义：去重降噪、抑制消除已知误报——两者都是「提升信噪比」的手段，但抑制必须有过期与理由，避免变成永久盲区。
- 追问钩子：能指出「抑制要记录创建人和理由以便审计；自动过期优于永久抑制，因为代码会演进」的候选人理解治理的可持续性。

```typescript
function fp(code){ let h=0; const s=String(code||'').replace(/\s+/g,'').toLowerCase();
  for(const c of s)h=(Math.imul(h,31)+c.charCodeAt(0))>>>0; return h; }
function filterReviews(comments=[], suppressions=[], opts={}) {
  const today=opts.today||'2026-11-23';
  const seen=new Set(), kept=[], deduped=[], suppressed=[];
  for(const c of comments){
    const key=`${c.rule}|${c.file}|${fp(c.code)}`;
    if(seen.has(key)){ deduped.push(c.id); continue; }
    seen.add(key);
    const hit=suppressions.some(s=>
      s.rule===c.rule && s.file===c.file && s.fp===fp(c.code) && (!s.expires||s.expires>=today));
    if(hit) suppressed.push(c.id); else kept.push(c.id);
  }
  return { kept, deduped, suppressed };
}
console.log(filterReviews(
  [{id:1,rule:'R',file:'a.ts',code:'x = 1',msg:'m'},{id:2,rule:'R',file:'a.ts',code:'x=1',msg:'m'}], []));
```
**评分点**：
- 去重：rule+file+归一化 code（去空白/小写）判重，保留首次、其余进 deduped。
- 抑制：rule+file+指纹匹配且未过期才抑制，expires 缺失视为永不过期。
- 先去重后抑制，同一 comment 不重复归类；空 comments 边界处理。
- 指纹计算稳定（去空白哈希），代码可运行，返回三列表结构完整。
- 明确「抑制需记录理由/创建人、自动过期优于永久」（加分项）。
