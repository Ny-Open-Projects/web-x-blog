## AIC-599：笔试：手写实现计划验证

**答**：实现 `validatePlan(plan)`。plan: `{ steps: Array<{ action, file, description, verify? }>, risks, testPlan }`. 规则：1) 步骤非空（至少 1 步）；2) **文件存在性**：modify/delete 的文件必须在文件系统中存在（create 的不应存在——防覆盖）；3) **验证步骤**：每个 modify 步骤有 verify 命令 → ok；无 verify → warn 'missing-verify'（步骤后如何验证？RBL-558）；4) **安全路径检查**：modify/delete 涉及 securityPaths（auth/payment）→ info 'security-sensitive'（需要 security reviewer RBL-505 T0）；5) **testPlan 非空**：计划包含测试计划 → ok；缺失 → warn 'missing-test-plan'。返回 `{ findings: Array<{ step?, type, severity }>, ok }`（ok = 无 error）。边界：steps 空 → error；create 的文件已存在 → error 'file-exists'；verify 命令为空字符串 → 视为无 verify。

```javascript
function validatePlan(plan = { steps: [], risks: [], testPlan: '' },
  { fsExists = () => true, securityPaths = [/auth\//, /payment\//] } = {}) {
  const findings = [];
  if (!plan.steps?.length)
    return { findings: [{ type: 'empty-plan', severity: 'error' }], ok: false };
  for (const step of plan.steps) {
    // 文件存在性
    if (step.action === 'modify' || step.action === 'delete') {
      if (!fsExists(step.file))
        findings.push({ step: step.order, type: 'file-not-found', severity: 'error',
          detail: `${step.action} 目标 ${step.file} 不存在` });
    }
    if (step.action === 'create') {
      if (fsExists(step.file))
        findings.push({ step: step.order, type: 'file-exists', severity: 'error',
          detail: `create 目标 ${step.file} 已存在——会覆盖` });
    }
    // 验证步骤
    if ((step.action === 'modify' || step.action === 'create') && !step.verify)
      findings.push({ step: step.order, type: 'missing-verify', severity: 'warn' });
    // 安全路径
    if (securityPaths.some(p => p.test(step.file)))
      findings.push({ step: step.order, type: 'security-sensitive', severity: 'info' });
  }
  if (!plan.testPlan)
    findings.push({ type: 'missing-test-plan', severity: 'warn' });
  return { findings, ok: !findings.some(f => f.severity === 'error') };
}

// 自测
const existingFiles = new Set(['src/auth/login.ts', 'src/utils.ts']);
const fsExists = (f) => existingFiles.has(f);
const plan = {
  steps: [
    { order: 1, action: 'modify', file: 'src/auth/login.ts', description: 'add rate limit', verify: 'pnpm test auth' },
    { order: 2, action: 'create', file: 'src/auth/rate-limit.ts', description: 'new file', verify: 'pnpm build' },
    { order: 3, action: 'delete', file: 'src/old.ts', description: 'cleanup' },
  ],
  risks: ['auth 变更——需 security review'],
  testPlan: 'pnpm test && pnpm build',
};
let r = validatePlan(plan, { fsExists });
console.log(r.ok === true);                             // 全通过
console.log(r.findings.some(f => f.type === 'security-sensitive'));   // auth 路径
// create 已存在的文件
const badPlan = { ...plan, steps: [
  { order: 1, action: 'create', file: 'src/auth/login.ts', description: 'override' } ] };
r = validatePlan(badPlan, { fsExists });
console.log(r.findings[0].type === 'file-exists' && r.ok === false);
// modify 不存在的文件
const ghostPlan = { ...plan, steps: [
  { order: 1, action: 'modify', file: 'src/ghost.ts', description: 'modify' } ] };
r = validatePlan(ghostPlan, { fsExists });
console.log(r.findings[0].type === 'file-not-found');
// 缺 testPlan
const noTestPlan = { steps: [{ order: 1, action: 'create', file: 'x.ts', verify: 't' }], risks: [], testPlan: '' };
r = validatePlan(noTestPlan, { fsExists });
console.log(r.findings.some(f => f.type === 'missing-test-plan'));
console.log(r.ok === true);                             // warn 不阻断
// 空 plan
console.log(validatePlan({ steps: [], risks: [], testPlan: '' }).ok === false);
```

**评分点**：
- 四类检查：空 plan / 文件存在性（create 不覆盖、modify 不 ghost）/ verify 步骤 / security 路径
- create 的文件已存在 = error（防覆盖）；modify 的文件不存在 = error（无效操作）
- 边界（正常 plan/create 已存在/ghost 文件/缺 testPlan/空 plan）；security-sensitive 为 info
- 能说清「先审计划再执行：计划的文件存在性检查防止 AI 覆盖已有文件或修改不存在的文件」属于加分
