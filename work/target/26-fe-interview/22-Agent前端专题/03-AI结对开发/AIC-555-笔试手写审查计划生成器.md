## AIC-555：笔试：手写审查计划

**答**：实现 `planReview(files, { maxChunkLines })`。files: `{ path, lines, riskLevel }[]`. 规则：1) riskLevel 降序排序（高优先先审）；2) chunking：累计 lines ≤ maxChunkLines 分入同一 chunk（超则新开 chunk——chunk 内文件连续审——避免注意力跨 chunk 分散）；3) chunk 的注释：第 1 个 chunk 标 'high-attention'（注意力最佳），后续标 'rested'；4) 单文件 > maxChunkLines → 独立 chunk（超量文件——即使超也单独一个 chunk）；5) 返回 `Array<{ order, files: string[], totalLines, note }>`。边界：files 空；单文件 chunk；riskLevel 全同（按原序 chunk）；maxChunkLines 极小（每个文件独立 chunk）。

```javascript
function planReview(files = [], { maxChunkLines = 100 } = {}) {
  const sorted = [...files].sort((a, b) => (b.riskLevel ?? 0) - (a.riskLevel ?? 0));
  const chunks = [];
  let current = []; let total = 0;
  for (const f of sorted) {
    if (total + f.lines > maxChunkLines && current.length) {
      chunks.push(current); current = []; total = 0;
    }
    current.push(f); total += f.lines;
  }
  if (current.length) chunks.push(current);
  return chunks.map((chunk, i) => ({
    order: i + 1,
    files: chunk.map(f => f.path),
    totalLines: chunk.reduce((s, f) => s + f.lines, 0),
    note: i === 0 ? 'high-attention: riskLevel 优先审' : 'rested: 休息后注意力恢复',
  }));
}

// 自测
const files = [
  { path: 'auth/login.ts', lines: 50, riskLevel: 3 },    // 最高优先
  { path: 'payment.ts', lines: 60, riskLevel: 3 },
  { path: 'utils.ts', lines: 30, riskLevel: 1 },
  { path: 'README.md', lines: 10, riskLevel: 0 },
];
let r = planReview(files, { maxChunkLines: 100 });
// 排序后：auth(50,r3) payment(60,r3) utils(30,r1) README(10,r0)
// chunk1: auth(50)+payment(60)=110>100 → auth 单独？50+60=110 > 100 → chunk1=[auth], chunk2=[payment+utils+README]=100
console.log(r.length === 2);
console.log(r[0].files.join(',') === 'auth/login.ts');
console.log(r[0].note.includes('high-attention'));
console.log(r[1].files.join(',') === 'payment.ts,utils.ts,README.md');
console.log(r[1].note.includes('rested'));

// maxChunkLines 极小 → 每文件独立
r = planReview(files, { maxChunkLines: 10 });
console.log(r.length === 4);                             // 每文件独立 chunk
// 空文件
console.log(planReview([]).length === 0);
```

**评分点**：
- 排序正确（riskLevel 降序——高优先先审 RBL-505）；chunking 正确（累计 ≤ maxChunkLines）
- chunk 注释：首 chunk high-attention、后续 rested（注意力管理 RBL-554）
- 边界（空/单文件/maxChunk 极小/全同 riskLevel）；超量文件独立 chunk
- 能说清「审查注意力管理：高优先级先审 + chunking 防衰减——同一时间发现更多 bug」属于加分
