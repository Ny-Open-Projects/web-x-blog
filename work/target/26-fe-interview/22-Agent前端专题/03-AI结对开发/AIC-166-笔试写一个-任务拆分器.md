## AIC-166：笔试：实现一个 Agent 任务拆分器：按依赖拓扑排序、并行分组与批次预算？
**答**：实现 `planTasks(tasks)`：
- tasks: `[{id, deps: [], estTokens}]`；检测循环依赖并报错；
- 拓扑排序，产出可并行的「批次」列表（同批任务无依赖关系）；
- 每批 token 预算限制（批次内 estTokens 总和 ≤ batchBudget，超出拆成多个批次）；
- 返回 `{waves: [[ids]], cycles?}`。

```javascript
function planTasks(tasks, batchBudget = 10000) {
  const byId = new Map(tasks.map(t => [t.id, t]));
  const depsLeft = new Map(tasks.map(t => [t.id, new Set(t.deps)]));
  const dependents = new Map(tasks.map(t => [t.id, []]));
  for (const t of tasks) for (const d of t.deps) dependents.get(d)?.push(t.id);

  // 环检测：拓扑推进不了剩余>0
  const waves = [];
  let done = new Set();
  while (done.size < tasks.length) {
    const ready = tasks.filter(t => !done.has(t.id) &&
      [...depsLeft.get(t.id)].every(d => done.has(d)));
    if (!ready.length) {
      const cycles = tasks.filter(t => !done.has(t.id)).map(t => t.id);
      return { cycles, waves };
    }
    // 同批内按预算装箱（简单顺序装箱）
    const wave = [];
    let acc = 0;
    for (const t of ready) {
      if (acc + t.estTokens > batchBudget && wave.length) break; // 留给下一波
      wave.push(t.id); acc += t.estTokens;
    }
    waves.push(wave);
    wave.forEach(id => {
      done.add(id);
      dependents.get(id).forEach(d => depsLeft.get(d).delete(id));
    });
  }
  return { waves, cycles: null };
}

// 测试
const tasks = [
  { id: 'types', deps: [], estTokens: 3000 },
  { id: 'service', deps: ['types'], estTokens: 5000 },
  { id: 'ui-a', deps: ['types'], estTokens: 4000 },
  { id: 'ui-b', deps: ['types'], estTokens: 4000 },
  { id: 'tests', deps: ['service', 'ui-a', 'ui-b'], estTokens: 3000 },
];
console.log(planTasks(tasks, 8000));
// wave1: [types]  wave2: [service]（ui-a 超预算推后）  wave3: [ui-a, ui-b]  wave4: [tests]
```

**评分点**：
1. 循环依赖必须显式检测（拓扑推不动即环）并返回环成员——直接死循环是硬伤；
2. 并行分组正确性：同波任务相互无依赖（由「deps 全部已完成」保证）；
3. 预算装箱的边界：波内留空至少一个任务（`wave.length` 判断）防止死循环；
4. estTokens 预算视角：每波是一次 LLM 调用的上下文上限，不只调度问题；
5. 追问：更优装箱可用首次适应递减（FFD）；环检测可用 DFS 三色标记。
