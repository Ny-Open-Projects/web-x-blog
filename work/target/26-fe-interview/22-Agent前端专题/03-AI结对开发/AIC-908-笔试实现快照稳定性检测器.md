## AIC-908：笔试：实现「快照稳定性检测器」，识别快照中易漂移的字段（时间戳/自增 ID/随机数）
**答**：
- 核心需求：实现 `findVolatile(snapshots)`，输入同一逻辑的 N 份快照对象数组，输出在样本间取值不一致的字段路径列表，如 `["meta.createdAt","id"]`。
- 要求递归遍历嵌套对象与数组，路径用点号拼接（数组用 `[i]`）；只输出「值不一致」的字段路径。
- 边界：样本为空或仅 1 份返回 []；对象是循环引用要用 WeakSet 防死循环；BigInt/Symbol 值跳过；差异比较用深度相等而非引用相等。
- 语义：结果用于提示「这些字段应从快照断言中排除或归一化」，本身不修改快照。
- 追问钩子：能提出「检测只是第一步，关键是推动团队把易漂移字段从断言里排除或注入固定值」的候选人理解工具服务于流程。

```typescript
function findVolatile(snapshots) {
  if (!Array.isArray(snapshots) || snapshots.length < 2) return [];
  const seen = new WeakSet();
  function flatten(obj, prefix, out) {
    if (obj === null || typeof obj !== 'object') { out.set(prefix, String(obj)); return; }
    if (seen.has(obj)) return; seen.add(obj);
    for (const k of Object.keys(obj)) {
      const v = obj[k], path = prefix ? `${prefix}.${k}` : k;
      if (v !== null && typeof v === 'object') flatten(v, path, out);
      else if (typeof v !== 'symbol' && typeof v !== 'bigint') out.set(path, String(v));
    }
  }
  const maps = snapshots.map(s => { const m = new Map(); flatten(s, '', m); return m; });
  const paths = new Set(maps.flatMap(m => [...m.keys()]));
  return [...paths].filter(p => new Set(maps.map(m => m.get(p))).size > 1);
}
console.log(findVolatile([{id:1,t:'2026-01-01'},{id:2,t:'2026-01-02'}])); // ['id','t']
```
**评分点**：
- 递归展平嵌套对象/数组，路径用点号（数组含下标）正确拼接。
- 用 WeakSet 处理循环引用防栈溢出，跳过 Symbol/BigInt。
- 跨样本字段值用深度/字符串化比较，正确识别不一致字段。
- 空数组/单样本返回 []，边界处理完整。
- 输出语义清晰：仅提示易漂移字段，不擅自修改快照（加分项）。
