## AIC-579：笔试：手写重渲染检测

**答**：实现 `detectRenderIssues(components)`。components: `{ name, hasMemo, hasUseCallback, hasUseMemo, props: Array<{ name, type: 'fn'|'obj'|'primitive' }>, childCount }[]`. 规则：1) 无 memo 且 childCount > 3 → 'no-memo'；2) 无 useCallback 且有 fn 类型 props → 'no-usecallback'；3) 无 useMemo 且有 obj 类型 props → 'no-usememo'；4) 组件有 hasMemo 但内部无 useCallback 且有 fn props → 'memo-ineffective'（memo 无效——props 引用不稳定）；5) 返回 `{ issues: Array<{ component, issue, fix }>, ok }`（ok = 无 issues）。边界：空 components；hasMemo 且无 fn props（pass）；props 空（无 fn/obj——无 issue）；全有 memo+callback（pass）。

```javascript
function detectRenderIssues(components = []) {
  const issues = [];
  for (const c of components) {
    const fnProps = (c.props ?? []).filter(p => p.type === 'fn');
    const objProps = (c.props ?? []).filter(p => p.type === 'obj');
    if (!c.hasMemo && (c.childCount ?? 0) > 3)
      issues.push({ component: c.name, issue: 'no-memo', fix: '添加 React.memo' });
    if (!c.hasUseCallback && fnProps.length > 0)
      issues.push({ component: c.name, issue: 'no-usecallback', fix: '用 useCallback 包裹函数 props' });
    if (!c.hasUseMemo && objProps.length > 0)
      issues.push({ component: c.name, issue: 'no-usememo', fix: '对象 props 用 useMemo' });
    if (c.hasMemo && !c.hasUseCallback && fnProps.length > 0)
      issues.push({ component: c.name, issue: 'memo-ineffective',
        fix: 'memo 无效——props 引用不稳定，需 useCallback' });
  }
  return { issues, ok: issues.length === 0 };
}

// 自测
const components = [
  { name: 'ProductList', hasMemo: false, hasUseCallback: false, hasUseMemo: false,
    props: [{ name: 'onClick', type: 'fn' }, { name: 'filter', type: 'obj' }],
    childCount: 10 },                                     // 全有问题
  { name: 'Button', hasMemo: true, hasUseCallback: true, hasUseMemo: false,
    props: [{ name: 'label', type: 'primitive' }], childCount: 0 },  // OK
  { name: 'Card', hasMemo: true, hasUseCallback: false, hasUseMemo: false,
    props: [{ name: 'onClick', type: 'fn' }], childCount: 1 },  // memo-ineffective
];
let r = detectRenderIssues(components);
console.log(r.issues.length === 4);                      // 3+0+1
console.log(r.issues.some(i => i.component === 'ProductList' && i.issue === 'no-memo'));
console.log(r.issues.some(i => i.component === 'Card' && i.issue === 'memo-ineffective'));
console.log(!r.issues.some(i => i.component === 'Button'));
console.log(r.ok === false);

// 全优化
r = detectRenderIssues(components.map(c => ({
  ...c, hasMemo: true, hasUseCallback: true, hasUseMemo: true })));
console.log(r.ok === true && r.issues.length === 0);
// 空
console.log(detectRenderIssues([]).ok === true);
```

**评分点**：
- 四类检测：no-memo/no-usecallback/no-usememo/memo-ineffective——层层深入（memo-ineffective = memo 加了但 props 引用不稳定使其无效）
- 每类有 fix 建议（可操作——添加 React.memo/useCallback/useMemo）；childCount > 3 的 memo 阈值
- 边界（空 components/全优化/props 空）；ok = 无 issues
- 能说清「AI 生成的 React 代码比人写的更容易有不必要 re-render——AI 一次性输出不做性能优化，需要检测器+自动修复」属于加分
