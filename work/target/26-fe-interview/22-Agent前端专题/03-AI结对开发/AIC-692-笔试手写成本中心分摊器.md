## AIC-692：笔试：手写成本中心分摊器

**答**：实现 `allocateCosts(usages, sharedCost, config)`。usages: `{ team:string, project:string, tokens:number, model:string }[]`；sharedCost: number（平台共享成本，如网关运维）；config: `{ prices:Record<string,number> (每千token单价), sharedMethod:'by-usage'|'equal', teams:string[] }`。规则：1) 直接成本 = Σ(tokens/1000 × prices[model])，按 team+project 聚合；2) 共享成本分摊：by-usage 按各 team 直接成本占比，equal 按 teams 数量均分；3) 每 team 总成本 = 直接成本 + 分摊的共享成本；4) 返回 `{ byTeam:Record<string,number>, byProject:Record<string,number>, sharedAllocated:Record<string,number>, total:number }`。边界：usages 空时 by-usage 无法分摊→均分；未知 model 单价按 0。

```javascript
function allocateCosts(usages = [], sharedCost = 0, config = {}) {
  const { prices = {}, sharedMethod = 'by-usage', teams = [] } = config;
  const byProject = {}, directByTeam = {}, directTotal = {};
  for (const u of usages) {
    const cost = u.tokens / 1000 * (prices[u.model] || 0);
    const pk = `${u.team}/${u.project}`;
    byProject[pk] = (byProject[pk] || 0) + cost;
    directByTeam[u.team] = (directByTeam[u.team] || 0) + cost;
  }
  for (const t of Object.values(directByTeam)) { /* noop, keep explicit */ }
  const sumDirect = Object.values(directByTeam).reduce((s, x) => s + x, 0);
  const allTeams = [...new Set([...teams, ...Object.keys(directByTeam)])];
  const sharedAllocated = {};
  for (const t of allTeams) {
    if (sharedMethod === 'equal' || sumDirect === 0) {
      sharedAllocated[t] = allTeams.length ? sharedCost / allTeams.length : 0;
    } else {
      sharedAllocated[t] = sharedCost * (directByTeam[t] || 0) / sumDirect;
    }
  }
  const byTeam = {};
  for (const t of allTeams) byTeam[t] = (directByTeam[t] || 0) + (sharedAllocated[t] || 0);
  return { byTeam, byProject, sharedAllocated, total: sumDirect + sharedCost };
}

// 自测
const usages = [
  { team: 'fe', project: 'shop', tokens: 1000, model: 'strong' }, // 10
  { team: 'fe', project: 'im', tokens: 1000, model: 'fast' },     // 1
  { team: 'be', project: 'api', tokens: 1000, model: 'fast' },    // 1
];
const r = allocateCosts(usages, 12, {
  prices: { strong: 10, fast: 1 }, sharedMethod: 'by-usage', teams: ['fe', 'be'],
});
console.log(Math.abs(r.byTeam.fe - (11 + 12*11/12)) < 0.001); // 11 + 11 = 22
console.log(Math.abs(r.byTeam.be - (1 + 12*1/12)) < 0.001);   // 1 + 1 = 2
console.log(r.byProject['fe/shop'] === 10);
console.log(Math.abs(r.total - 24) < 0.001); // 12直接 + 12共享
console.log(allocateCosts([], 10, { teams: ['a','b'], sharedMethod: 'by-usage' }).byTeam.a === 5); // 无用量→均分
```

**评分点**：
- 直接成本按 token×单价、按 team+project 聚合
- 共享成本 by-usage（按占比）与 equal（均分）两种分摊
- 边界：无用量时 by-usage 退化为均分、未知 model 单价 0
- byTeam = 直接 + 分摊，total 守恒
- 能说清「成本可见性会改变工程师行为——把 AI 消耗的外部性内部化，是成本治理的根本」属于加分
