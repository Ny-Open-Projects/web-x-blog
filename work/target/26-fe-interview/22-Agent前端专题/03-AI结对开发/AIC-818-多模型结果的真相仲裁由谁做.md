## AIC-818：多个模型答案互相矛盾时，「真相仲裁」该由谁来做？
**答**：
- 仲裁不是简单地「再找一个更强的模型问一遍」——裁判模型同样会幻觉、同样有偏好。要分层：**可验证的事实用工具验证**（跑测试、查文档、算数、查数据库），**不可验证的主观判断才用裁判模型或人工**。
- 裁判模型要做**去偏**：匿名候选、随机顺序、多个裁判交叉、去掉自身生成的答案（避免自评偏好）；裁判的准确率要定期用 golden 集校准。
- 仲裁要有**升级路径**：低置信度 / 高风险场景（医疗、金融、资金操作）必须升级到人工，不能让模型自己拍板——AI 仲裁的边界就是「不可自动化的决策」。
- 仲裁结果要**留痕**：记录候选答案、裁判理由、最终选择，作为后续评测与模型改进的标注数据（飞轮）。
- 追问钩子：能说出「能用工具验证的绝不让模型裁判」的候选人，体现了对「证据 > 意见」的工程判断，这是区分中级和高级的关键。

```typescript
type Candidate = { modelId: string; answer: string; evidence?: string };

async function arbitrate(candidates: Candidate[], ctx: any) {
  // 第一层：可验证任务用确定性工具，不靠模型
  if (ctx.verifier) {
    const verified = candidates.filter(c => ctx.verifier(c.answer));
    if (verified.length) return { answer: verified[0].answer, by: 'tool' };
  }
  // 第二层：裁判模型，匿名 + 随机顺序 + 多裁判
  const anonymized = candidates
    .map(c => ({ id: crypto.randomUUID(), answer: c.answer }))
    .sort(() => Math.random() - 0.5);           // 打乱顺序去位置偏差
  const judges = await Promise.all([
    judge.chat('选出最准确的答案并说明理由：' + JSON.stringify(anonymized)),
    judge.chat('独立复核：' + JSON.stringify(anonymized)),
  ]);
  if (judges[0].pick === judges[1].pick) {
    return { answer: judges[0].pick, by: 'judge-consensus' };
  }
  // 第三层：分歧未解 → 升级人工
  return { answer: null, by: 'human-escalation', candidates };
}

const result = await arbitrate([
  { modelId: 'a', answer: '42' },
  { modelId: 'b', answer: '43' },
], { verifier: (a: string) => a === '42' });
console.log(result); // { answer:'42', by:'tool' }
```
