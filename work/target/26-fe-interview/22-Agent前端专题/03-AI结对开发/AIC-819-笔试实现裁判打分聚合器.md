## AIC-819：笔试：实现裁判打分聚合器，去极值并做一致性检验
**答**：
- 核心需求：输入多个裁判对若干候选的打分 `scores: { judgeId, candidateId, score }[]`（score 0~10），返回每个候选的 `{ finalScore, consensus }`。流程：先对每个候选去掉一个最高分和一个最低分（样本 ≥ 4 时），再取均值；`consensus = 1 - 标准差/量程` 表示裁判一致性。
- 边界：裁判数 < 3 不去极值（只取均值）；分数越界视为无效过滤；某候选无有效分数返回 `finalScore: 0, consensus: 0`；consensus 低于 0.5 标记 `needsReview: true`。
- 可用性：聚合器不替换候选的真相性，只是「裁判意见的汇总」，结果低一致性时交人工（AIC-818 的升级路径）。
- 追问钩子：追问「去极值一定合理吗」——能答出「裁判本身有系统偏差时去极值反而丢信息，应配合裁判校准」的候选人有批判性思维。

```typescript
type Score = { judgeId: string; candidateId: string; score: number };
type Result = { finalScore: number; consensus: number; needsReview: boolean };

function aggregateScores(scores: Score[]): Record<string, Result> {
  const byCandidate = new Map<string, number[]>();
  for (const s of scores ?? []) {
    if (!Number.isFinite(s.score) || s.score < 0 || s.score > 10) continue;
    const arr = byCandidate.get(s.candidateId) ?? [];
    arr.push(s.score);
    byCandidate.set(s.candidateId, arr);
  }
  const out: Record<string, Result> = {};
  for (const [candidateId, raw] of byCandidate) {
    let values = raw;
    if (values.length >= 4) {
      const sorted = [...values].sort((a, b) => a - b);
      values = sorted.slice(1, -1);     // 去掉一个最高、一个最低
    }
    if (!values.length) {
      out[candidateId] = { finalScore: 0, consensus: 0, needsReview: true };
      continue;
    }
    const mean = values.reduce((s, v) => s + v, 0) / values.length;
    const variance = values.reduce((s, v) => s + (v - mean) ** 2, 0) / values.length;
    const std = Math.sqrt(variance);
    const consensus = +(1 - std / 10).toFixed(3);  // 量程 10
    out[candidateId] = {
      finalScore: +mean.toFixed(2),
      consensus,
      needsReview: consensus < 0.5,
    };
  }
  return out;
}

console.log(aggregateScores([
  { judgeId: 'j1', candidateId: 'A', score: 8 },
  { judgeId: 'j2', candidateId: 'A', score: 9 },
  { judgeId: 'j3', candidateId: 'A', score: 1 },  // 离群
  { judgeId: 'j4', candidateId: 'A', score: 8 },
])); // A 去掉 1 和 9 后 → finalScore 8, 高 consensus
```
**评分点**：
- 仅在裁判数 ≥ 4 时去极值，避免小样本误删有效信息。
- 越界/非有限分数过滤，防止 NaN 污染均值与标准差。
- consensus 用 `1 - std/量程` 归一化到 [0,1]，处理量程常量。
- 无有效分数返回安全默认并标记 needsReview，不抛异常。
- 能指出「去极值假设裁判无系统偏差」体现对统计前提的理解。
