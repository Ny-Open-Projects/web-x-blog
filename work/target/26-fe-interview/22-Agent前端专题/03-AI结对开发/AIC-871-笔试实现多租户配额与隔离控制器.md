## AIC-871：笔试：实现多租户配额与隔离控制器（并发/速率/预算三维）
**答**：
- 核心需求：实现 `QuotaController`，`configure(tenant, { maxConcurrent, qpm, dailyBudget })`，`acquire(tenant, cost)` 返回 `boolean`，`release(tenant)`，`getUsage(tenant)`。三个维度任一超限即拒绝：并发数 < maxConcurrent、每分钟请求数 < qpm、当日累计成本 + cost ≤ dailyBudget。
- 边界：未配置的租户使用默认配额（如并发 5、qpm 60、预算 100）；`release` 不能让并发数变负；成本累计按自然日（跨日自动清零，用日期 key 判断）；`acquire` 失败不产生任何副作用（不占并发、不计成本/速率）。
- 隔离：租户之间状态完全独立，一个租户超限不影响其他租户；要能返回「因哪个维度被拒」便于调用方决策（重试/降级）。
- 追问钩子：追问「配额用满时是排队还是拒绝」——能答出「交互式请求快速失败 + 提示，批处理可排队，且要带 Retry-After」的候选人理解不同场景的取舍。

```typescript
type Quota = { maxConcurrent: number; qpm: number; dailyBudget: number };
const DEFAULT: Quota = { maxConcurrent: 5, qpm: 60, dailyBudget: 100 };
const dayKey = () => new Date().toISOString().slice(0, 10);

class QuotaController {
  private quotas = new Map<string, Quota>();
  private state = new Map<string, { inFlight: number; minuteCount: number;
    minuteKey: number; day: string; spent: number }>();

  configure(tenant: string, q: Quota) { this.quotas.set(tenant, q); }
  private st(t: string) {
    const now = Date.now(), mk = Math.floor(now / 60000), dk = dayKey();
    let s = this.state.get(t);
    if (!s || s.minuteKey !== mk || s.day !== dk) { // 跨分钟/跨日自动重置计数
      s = { inFlight: s?.inFlight ?? 0, minuteCount: 0, minuteKey: mk,
        day: dk, spent: s?.day === dk ? s.spent : 0 };
      this.state.set(t, s);
    }
    return s;
  }
  acquire(tenant: string, cost = 1): { ok: boolean; reason?: string } {
    const q = this.quotas.get(tenant) ?? DEFAULT, s = this.st(tenant);
    if (s.inFlight >= q.maxConcurrent) return { ok:false, reason:'concurrency' };
    if (s.minuteCount >= q.qpm) return { ok:false, reason:'rate' };
    if (s.spent + cost > q.dailyBudget) return { ok:false, reason:'budget' };
    // 全部校验通过后才修改状态，失败零副作用
    s.inFlight++; s.minuteCount++; s.spent += cost;
    return { ok:true };
  }
  release(tenant: string) {
    const s = this.st(tenant);
    s.inFlight = Math.max(0, s.inFlight - 1); // 不能变负
  }
  getUsage(tenant: string) { return { ...this.st(tenant) }; }
}
const qc = new QuotaController();
qc.configure('team-a', { maxConcurrent:2, qpm:10, dailyBudget:50 });
console.log(qc.acquire('team-a', 10)); // { ok:true }
console.log(qc.getUsage('team-a'));    // inFlight:1, spent:10
```
**评分点**：
- 三维限制全部通过才修改状态，失败零副作用（原子性）。
- 跨分钟/跨日自动重置计数，预算按自然日清零。
- release 用 Math.max(0,...) 防止并发数变负。
- 拒绝时返回具体 reason，便于调用方重试/降级决策。
- 租户状态完全隔离，未配置租户走默认配额。
