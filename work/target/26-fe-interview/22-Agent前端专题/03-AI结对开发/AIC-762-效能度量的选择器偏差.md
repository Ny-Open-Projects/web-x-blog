## AIC-762：AI 效能度量中如何避免选择器偏差（只看乐观样本）

**答**：
- 结论先行：选择器偏差 = 只统计「成功使用 AI 的案例」而忽略「尝试后放弃」和「根本没用」的场景，导致效能被系统性高估；正确做法是「意向治疗分析」——把放弃者算进分母。
- 典型来源：1) 只统计采纳的建议，不统计被拒的；2) 只统计愿意填问卷的重度用户；3) 用「使用过 AI 的任务」而非「所有任务」做分母。
- 修正：定义清晰的分母（所有符合条件的人/任务），追踪从「决定使用」到「放弃/完成」的完整漏斗，报告各阶段流失。
- 追问钩子：为什么「被拒的建议」必须进分析？——它代表 AI 没帮上忙的场景；排除它会让采纳率虚高、问题被掩盖。

```javascript
// 意向治疗：所有任务进分母，含放弃者
function ittAnalysis(tasks) {
  const attempted = tasks.filter(t => t.triedAI);
  const completed = attempted.filter(t => t.completedWithAI);
  const abandoned = attempted.filter(t => t.abandonedAI);
  const never = tasks.filter(t => !t.triedAI);
  return {
    numerator: completed.length,
    denominator: tasks.length,           // 所有任务，不只是尝试者
    effect: completed.length / (tasks.length || 1),
    abandonedRate: abandoned.length / (attempted.length || 1),
    neverTried: never.length,
  };
}
console.log(ittAnalysis([
  { triedAI: true, completedWithAI: true }, { triedAI: true, abandonedAI: true }, { triedAI: false },
]).effect === 1 / 3); // 不是 1/2（只看尝试者）
```
