## AIC-713：笔试：实现 AI 多方案的加权决策评分器

**需求**：实现 `scorePlans(plans, weights, opts)`。`plans`: `Array<{ id, scores: Record<dim, number> }>`（0~1）；`weights`: `Record<dim, number>`；`opts.threshold`（默认 0.6）。规则：1) 缺失维度按 0 处理；2) 每个方案 `total = Σ scores[d]*weights[d] / Σ weights[d]`（归一化到 0~1）；3) 过滤掉任一关键维度（`criticalDims`，默认 `['correct']`）低于 threshold 的方案；4) 按 total 降序返回，平分时 id 字典序小的在前；5) 返回 `{ ranked, rejected: Array<{id, reason}> }`。边界：plans 空（ranked/rejected 空）；weights 全 0（total 记 0，不除零）；scores 值 clamp 到 [0,1]。

**答**：
- 结论先行：加权评分要把「归一化」做对——除以权重和而非维度数，否则不同权重集合无法横向比较；关键维度做一票否决，避免平均分掩盖致命缺陷。
- 平分排序要稳定：用 id 字典序兜底，保证结果可复现（AI 决策需可审计）。
- 追问钩子：为什么关键维度用「一票否决」而不是「加大权重」？——权重再大也可能被其他维度抵消，致命缺陷不能靠平均分洗白。

```javascript
function scorePlans(plans = [], weights = {}, opts = {}) {
  const threshold = opts.threshold ?? 0.6;
  const critical = opts.criticalDims ?? ['correct'];
  const dims = Object.keys(weights);
  const wsum = dims.reduce((s, d) => s + weights[d], 0);
  const clamp = v => Math.max(0, Math.min(1, Number(v) || 0));
  const ranked = [], rejected = [];
  for (const p of plans) {
    const badCritical = critical.find(d => clamp(p.scores?.[d]) < threshold);
    if (badCritical) { rejected.push({ id: p.id, reason: 'critical:' + badCritical }); continue; }
    const total = wsum ? dims.reduce((s, d) => s + clamp(p.scores?.[d]) * weights[d], 0) / wsum : 0;
    ranked.push({ id: p.id, total });
  }
  ranked.sort((a, b) => b.total - a.total || String(a.id).localeCompare(String(b.id)));
  return { ranked, rejected };
}
const r = scorePlans(
  [{ id: 'B', scores: { correct: .9, cost: .8 } }, { id: 'A', scores: { correct: .5, cost: 1 } }],
  { correct: 2, cost: 1 }
);
console.log(r.ranked[0].id === 'B');      // A 被一票否决
console.log(r.rejected[0].reason);        // critical:correct
console.log(scorePlans([], { correct: 1 }).ranked.length === 0); // 边界
```


**评分点**：
- total 归一化正确（除以权重和，非维度数）
- 关键维度一票否决（correct 低于阈值即过滤）
- 平分稳定排序（total 降序 + id 字典序兜底）
- 边界（plans 空 / weights 全 0 / scores clamp 到 0-1）
