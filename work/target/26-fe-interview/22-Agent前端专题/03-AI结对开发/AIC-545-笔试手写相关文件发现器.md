## AIC-545：笔试：手写相关文件发现

**答**：实现 `findRelated(currentFile, ctx, { maxFiles })`。ctx: `{ imports: string[], sameDir: string[], coChange: string[], semantic: { file, score }[] }`。规则：1) 四源合并去重；2) 优先级排序：import(1) > sameDir(2) > coChange(3) > semantic(4，score ≥ 0.7)；3) 同源内：import 按字母序、coChange 按共现次数降序、semantic 按 score 降序；4) maxFiles 截断。返回 `{ files: string[], sources: Record<file, source> }`。边界：ctx 全空（空）；maxFiles=0；所有源都发现同一文件（取最高优先级源）。

```javascript
function findRelated(currentFile, ctx = {}, { maxFiles = 10 } = {}) {
  const { imports = [], sameDir = [], coChange = [], semantic = [] } = ctx;
  const found = new Map();
  const add = (file, source, priority) => {
    if (!found.has(file)) found.set(file, { file, source, priority });
  };
  imports.forEach(f => add(f, 'import', 1));
  sameDir.filter(f => f !== currentFile).forEach(f => { if (!found.has(f)) add(f, 'same-dir', 2); });
  coChange.forEach(f => { if (!found.has(f)) add(f, 'co-change', 3); });
  semantic.filter(s => s.score >= 0.7).forEach(s => { if (!found.has(s.file)) add(s.file, 'semantic', 4); });
  const files = [...found.values()].sort((a, b) => a.priority - b.priority).slice(0, maxFiles);
  const sources = Object.fromEntries(files.map(f => [f.file, f.source]));
  return { files: files.map(f => f.file), sources };
}

// 自测
const ctx = {
  imports: ['utils.ts', 'types.ts'],
  sameDir: ['utils.ts', 'Button.tsx'],
  coChange: ['Button.test.tsx', 'utils.ts'],
  semantic: [{ file: 'API.ts', score: 0.85 }, { file: 'low.ts', score: 0.5 }],
};
let r = findRelated('Product.tsx', ctx, { maxFiles: 10 });
console.log(r.files.join(','));
// utils.ts,types.ts,Button.tsx,Button.test.tsx,API.ts（low.ts score 0.5 < 0.7 不含）
console.log(r.sources['utils.ts'] === 'import');
console.log(r.sources['Button.tsx'] === 'same-dir');
console.log(r.sources['Button.test.tsx'] === 'co-change');
console.log(r.sources['API.ts'] === 'semantic');
// maxFiles 截断
r = findRelated('Product.tsx', ctx, { maxFiles: 3 });
console.log(r.files.length === 3);
// 空
console.log(findRelated('x.ts', {}).files.length === 0);
```

**评分点**：
- 四源合并去重（同文件取最高优先级源）；优先级排序正确（import > sameDir > coChange > semantic）
- semantic 的 score 门槛（≥ 0.7——低于阈值不注入——节省 tokens RBL-502）；maxFiles 截断
- 边界（空 ctx/maxFiles=0/重复文件去重）；co-change 的隐式关联价值
- 能说清「相关文件的发现优先级：import 显式依赖 > 同目录 > git co-change > 语义检索——精确到模糊」属于加分
