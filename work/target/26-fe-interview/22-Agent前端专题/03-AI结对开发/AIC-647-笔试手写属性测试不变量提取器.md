## AIC-647：笔试：手写属性测试不变量提取器

**答**：实现 `extractInvariants(spec)`。spec: `{ fnName:string, inputType:string, outputType:string, hints:string[], bugs:{input:any, expected:any, actual:any}[] }`（函数签名 + 提示 + 历史 bug）。规则：从 hints 和 bugs 中识别可验证的不变量候选，按以下模式生成：1) hints 含「长度/数量不变/子集」→ 'preserve-length' 或 'subset'；2) hints 含「幂等」→ 'idempotent'（f(f(x))===f(x)）；3) hints 含「可逆/往返/反序列化」→ 'roundtrip'；4) bugs 中 expected 与 actual 不同的 → 'bug-regression' 不变量（输入 bug.input 应得 expected）；5) 返回 `Array<{type, description, check:(fn:Function)=>boolean, confidence:number}>`（check 用伪实现，描述验证逻辑）。边界：spec 无 hints 无 bugs 返回空数组；重复类型去重保留高 confidence 者。

```javascript
function extractInvariants(spec = {}) {
  const { hints = [], bugs = [] } = spec;
  const out = [];
  const has = re => hints.some(h => re.test(h));
  if (has(/长度|数量不变|length/)) {
    out.push({ type: 'preserve-length', description: '输出长度等于输入长度', confidence: 0.9 });
  }
  if (has(/子集|包含于|subset/)) {
    out.push({ type: 'subset', description: '输出是输入的子集', confidence: 0.85 });
  }
  if (has(/幂等|idempotent/)) {
    out.push({ type: 'idempotent', description: 'f(f(x)) === f(x)', confidence: 0.9 });
  }
  if (has(/可逆|往返|roundtrip|序列化/)) {
    out.push({ type: 'roundtrip', description: 'decode(encode(x)) === x', confidence: 0.8 });
  }
  for (const b of bugs) {
    if (JSON.stringify(b.expected) !== JSON.stringify(b.actual)) {
      out.push({
        type: 'bug-regression',
        description: `输入 ${JSON.stringify(b.input)} 应返回 ${JSON.stringify(b.expected)}`,
        confidence: 1.0,
      });
    }
  }
  // 同类去重保留高 confidence
  const best = new Map();
  for (const inv of out) {
    if (!best.has(inv.type) || inv.confidence > best.get(inv.type).confidence) {
      best.set(inv.type, inv);
    }
  }
  return [...best.values()];
}

// 自测
const spec = {
  fnName: 'filterList', inputType: 'Item[]', outputType: 'Item[]',
  hints: ['筛选后是原列表的子集', '长度可变'],
  bugs: [{ input: [], expected: [], actual: null }],
};
const invs = extractInvariants(spec);
console.log(invs.some(i => i.type === 'subset'));
console.log(invs.some(i => i.type === 'bug-regression' && i.confidence === 1));
console.log(!invs.some(i => i.type === 'preserve-length')); // 提示说长度可变，不该有
console.log(extractInvariants({}).length === 0);
```

**评分点**：
- 从 hints 按正则识别四类不变量（长度/子集/幂等/往返）
- bug 反推 bug-regression 不变量且 confidence 最高
- 同类去重保留高 confidence 者
- 「长度可变」等反向提示不应误触发 preserve-length
- 能说清「不变量不是 AI 凭空发明的，而是从类型语义、历史 bug、人给的规律中提取，AI 负责翻译成可运行断言」属于加分
