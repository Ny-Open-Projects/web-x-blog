## AIC-660：笔试：手写安全约束合规性检查器

**答**：实现 `checkSecurityCompliance(code)`。code: string。检查四类前端安全违规：1) `dangerouslySetInnerHTML` 且参数含 user/input/props → 'xss-risk'；2) `eval(` 或 `new Function(` → 'code-injection'；3) `localStorage.setItem` 且值含 token/password/secret → 'sensitive-storage'；4) `console.log` 且参数含 token/password/PII/phone → 'sensitive-log'。规则：每处违规记 `{type, line, snippet}`，返回 `{ violations, passed:boolean, score:number }`（score=100−violations×25，clamp 0）。边界：code 空返回 passed=true score=100；同一行多个违规都要记。

```javascript
function checkSecurityCompliance(code = '') {
  if (!code.trim()) return { violations: [], passed: true, score: 100 };
  const rules = [
    { re: /dangerouslySetInnerHTML\s*=\s*\{\s*\{\s*__html:\s*(user|input|props|\w*content)/i, type: 'xss-risk' },
    { re: /eval\s*\(|new Function\s*\(/, type: 'code-injection' },
    { re: /localStorage\.setItem\([^)]*(token|password|secret|key)/i, type: 'sensitive-storage' },
    { re: /console\.log\([^)]*(token|password|phone|pii|idcard)/i, type: 'sensitive-log' },
  ];
  const violations = [];
  code.split('
').forEach((line, i) => {
    for (const r of rules) {
      if (r.re.test(line)) {
        violations.push({ type: r.type, line: i + 1, snippet: line.trim() });
      }
    }
  });
  const score = Math.max(0, 100 - violations.length * 25);
  return { violations, passed: violations.length === 0, score };
}

// 自测
const code = `
const html = props.content;
return <div dangerouslySetInnerHTML={{__html: html}} />;
eval(userInput);
localStorage.setItem('auth_token', token);
console.log('user phone', phone);
`;
const r = checkSecurityCompliance(code);
console.log(r.violations.map(v => v.type).sort().join(','));
// code-injection, sensitive-log, sensitive-storage, xss-risk
console.log(r.passed === false && r.score === 0);
console.log(checkSecurityCompliance('const x = 1;').score === 100);
```

**评分点**：
- 四类安全违规正则识别（XSS/注入/敏感存储/敏感日志）
- 逐行扫描，同一行多违规都记录
- score=100−违规数×25 clamp 0，passed 与 violations 一致
- 边界：空代码安全、正常代码无误报
- 能说清「prompt 安全约束是概率的（左移），生成后静态扫描是确定的（兜底），两者缺一不可」属于加分
