## AIC-450：笔试：试用期（新奇效应）过滤统计。
**答**：用户 `[{user, startDate}]` 与记录 `[{user, ts, metric}]`。只统计「开始使用 4 周后」的记录（稳态窗口），输出每人稳态均值与全队均值。

```javascript
const RAMP = 28 * 86_400_000;
function steadyStats(users, records) {
  const start = new Map(users.map(u => [u.user, u.startDate]));
  const steady = new Map(), ramp = new Map();
  for (const r of records) {
    const s = start.get(r.user);
    if (s === undefined) continue;
    (r.ts - s >= RAMP ? steady : ramp).get(r.user)?.push?.(r.metric)
      ?? (r.ts - s >= RAMP ? steady.set(r.user, [r.metric]) : ramp.set(r.user, [r.metric]));
  }
  const avg = a => a.reduce((x, y) => x + y, 0) / a.length;
  const per = {};
  for (const [u, arr] of steady) per[u] = +avg(arr).toFixed(2);
  const all = [...steady.values()].flat();
  return { per, insufficient: users.filter(u => !steady.has(u.user)).map(u => u.user),
           teamAvg: all.length ? +avg(all).toFixed(2) : null };
}
console.log(steadyStats(
  [{ user: 'a', startDate: 0 }],
  [{ user: 'a', ts: 10, metric: 1 }, { user: 'a', ts: 30 * 86_400_000, metric: 8 }]));
// per.a = 8（ramp 期数据被过滤）

```

**评分点**：
- 窗口过滤：ts - startDate ≥ 28 天。
- 4 周内数据单列（ramp 期参考）不进稳态统计。
- 无稳态数据用户标记 insufficient。
- 全队均值用稳态数据计算。
