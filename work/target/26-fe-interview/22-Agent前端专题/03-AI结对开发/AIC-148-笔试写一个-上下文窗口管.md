## AIC-148：笔试：实现一个上下文窗口管理器，按预算裁剪多来源上下文并保证关键段不被丢弃？
**答**：实现 `fitContext(items, budget)`：
- 每项 `{key, content, priority, pinned}`；估算 token（按 1 token ≈ 4 字符，中文按 1.5 字符折算）；
- 裁剪顺序：pinned 永不裁 → priority 高的先保留 → 同级按后进先保（近期信息价值高）；
- 超预算时对非 pinned 项做「尾部截断」（保留前 70%，加 `...[截断]` 标记）再放不下则整项丢弃；
- 返回 `{kept, dropped, used}`。

```javascript
function estimateTokens(text) {
  const cjk = (text.match(/[\u4e00-\u9fa5]/g) || []).length;
  const other = text.length - cjk;
  return Math.ceil(cjk / 1.5 + other / 4);
}

function fitContext(items, budget) {
  const sorted = [...items].sort((a, b) =>
    (b.pinned - a.pinned) || (b.priority - a.priority));
  const kept = [], dropped = [];
  let used = 0;
  const overflowRe = /\n{3,}/g;
  for (const it of sorted) {
    let content = it.content.replace(overflowRe, '\n\n');
    let t = estimateTokens(content);
    if (used + t <= budget) { kept.push(it); used += t; continue; }
    if (it.pinned) { // pinned 超预算也必须放入，但允许截断到剩余空间
      const remain = Math.max(budget - used, 200);
      content = truncate(content, remain); t = estimateTokens(content);
      kept.push({ ...it, content }); used += t; continue;
    }
    // 非关键：先尝试截断保留 70%
    const cut = truncate(content, Math.floor(budget * 0.02)); // 预留缓冲
    const t70 = estimateTokens(truncate(content, Math.ceil(estimateTokens(content) * 0.7)));
    if (used + t70 <= budget) { kept.push({ ...it, content: truncate(content, Math.ceil(estimateTokens(content) * 0.7)) }); used += t70; }
    else dropped.push({ key: it.key, tokens: t });
  }
  return { kept: kept.reverse(), dropped, used, overBudget: used > budget };
}

function truncate(text, maxTokens) {
  let est = estimateTokens(text);
  if (est <= maxTokens) return text;
  let chars = Math.floor(text.length * (maxTokens / est));
  return text.slice(0, chars) + '\n...[截断]';
}

// 测试
const items = [
  { key: 'rules', content: '规则'.repeat(500), priority: 10, pinned: true },
  { key: 'target', content: '目标文件'.repeat(400), priority: 9, pinned: false },
  { key: 'old-chat', content: '历史'.repeat(2000), priority: 2, pinned: false },
  { key: 'docs', content: '文档'.repeat(800), priority: 5, pinned: false },
];
console.log(fitContext(items, 3000));
// old-chat 大概率被 drop 或截断；rules 完整保留
```

**评分点**：
1. token 估算要区分中英文（中文密度更高），只按字符数 ÷4 是常见失分点；
2. pinned 语义必须完整保留（最多允许带标记截断），裁掉 pinned 直接不合格；
3. 截断要保留头部（代码任务中文件头部的 import/类型信息价值最高）并打显式标记；
4. 返回值要含 dropped 清单——调用方需要知道丢了什么才能决定补什么；
5. 排序稳定性与 used 累计的正确性（追问：如何做成增量更新）。
