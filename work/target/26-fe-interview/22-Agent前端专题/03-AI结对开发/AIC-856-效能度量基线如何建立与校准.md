## AIC-856：效能度量的「基线」怎么建立？业务一变就失效怎么办？
**答**：
- 基线不是「历史平均值」这么简单：要先定义**同口径的分层基线**——按任务类型、团队、复杂度分别建基线，否则「简单需求变多」会让整体基线失真。
- 建立方法：取 AI 引入前稳定期的 4~8 周数据，剔除异常期（大促、放假、大重构），用中位数/分位数而非均值（抗离群），并标注当时的业务上下文。
- 基线要**带有效期和重校准触发器**：需求结构、团队构成、技术栈发生重大变化时强制重校准；平时按月滚动更新，但保留「冻结基线」用于长期趋势对比。
- 用**同比环比 + 同任务对照**代替绝对基线：当业务变化时，同一类任务的耗时对比比跨期总均值更可靠；基线失效要明确声明而非硬套。
- 追问钩子：能说出「基线要分层、要抗离群、要有重校准触发器，失效就诚实声明」的候选人，理解基线是工具不是教条。

```typescript
type Sample = { value: number; tag: string; ts: number };

function buildBaseline(samples: Sample[], excludeTags: string[] = []) {
  const valid = samples
    .filter(s => !excludeTags.includes(s.tag))
    .map(s => s.value).sort((a, b) => a - b);
  if (!valid.length) return null;
  const q = (p: number) => valid[Math.min(valid.length - 1, Math.floor(valid.length * p))];
  return {
    p50: q(0.5), p90: q(0.9), p10: q(0.1),
    sampleCount: valid.length,
    // 用分位数而非均值，抗离群；冻结后用于长期对比
  };
}
const baseline = buildBaseline([
  { value: 10, tag:'normal', ts:1 }, { value: 11, tag:'normal', ts:2 },
  { value: 90, tag:'outage', ts:3 },  // 异常期，建立时应排除
]);
console.log(baseline); // p50 10~11，不受 90 污染
// 业务变化时触发重校准：recalibrate() 用新窗口重建，但保留冻结基线
```
