## AIC-771：笔试：实现从效能指标到业务价值的归因器

**需求**：实现 `attributeValue(periods)`。`periods`: `Array<{ week, aiAdoption, cycleDays, throughput, incidents, reinvestRatio }>`。规则：1) 以第 1 周为基线，计算每周相对基线的相对变化率；2) `efficiencyGain = (baselineCycle - cycleDays) / baselineCycle`；3) `valueScore = efficiencyGain * reinvestRatio * 0.6 + throughputGain * 0.3 - incidentGain * 0.1`（各 gain 为相对基线的变化率，throughputGain 取正、incidentGain 取负向恶化）；4) `correlation` = aiAdoption 与 efficiencyGain 的皮尔逊相关（保留 2 位）；5) 返回 `{ weekly: Array<{week, efficiencyGain, valueScore}>, correlation }`。边界：periods<2（correlation=0）；基线 cycleDays=0（efficiencyGain=0 避免除零）；incidentGain 定义为 incidents 相对基线增长率（正=事故变多=扣分）。

**答**：
- 结论先行：归因要区分「相关性」与「贡献量」——valueScore 估算 AI 带来的可量化价值，correlation 衡量采纳与提效是否同步变化；两者结合避免把自然增长算成 AI 功劳。
- reinvestRatio（时间是否被再投入）是关键调节因子：省下时间若未 reinvest，价值应折算。
- 追问钩子：为什么相关不等于因果？——可能同时有流程改进等因素提升效率，需对照组或控制变量才能确认 AI 的净贡献。

```javascript
function attributeValue(periods = []) {
  if (!periods.length) return { weekly: [], correlation: 0 };
  const b = periods[0];
  const rate = (cur, base) => base ? (cur - base) / base : 0;
  const weekly = periods.map(p => {
    const efficiencyGain = rate(b.cycleDays - p.cycleDays, b.cycleDays); // 周期下降为正
    const throughputGain = rate(p.throughput, b.throughput);
    const incidentGain = rate(p.incidents, b.incidents);                 // 事故增加为正（坏）
    const valueScore = efficiencyGain * (p.reinvestRatio ?? 1) * 0.6 + throughputGain * 0.3 - incidentGain * 0.1;
    return { week: p.week, efficiencyGain: +efficiencyGain.toFixed(3), valueScore: +valueScore.toFixed(3) };
  });
  // 简相关系数：aiAdoption vs efficiencyGain
  let corr = 0;
  if (periods.length >= 2) {
    const xs = periods.map(p => p.aiAdoption), ys = weekly.map(w => w.efficiencyGain);
    const mx = xs.reduce((a, c) => a + c, 0) / xs.length, my = ys.reduce((a, c) => a + c, 0) / ys.length;
    const cov = xs.reduce((s, x, i) => s + (x - mx) * (ys[i] - my), 0);
    const vx = Math.sqrt(xs.reduce((s, x) => s + (x - mx) ** 2, 0));
    const vy = Math.sqrt(ys.reduce((s, y) => s + (y - my) ** 2, 0));
    corr = vx && vy ? +(cov / (vx * vy)).toFixed(2) : 0;
  }
  return { weekly, correlation: corr };
}
const r = attributeValue([
  { week: 1, aiAdoption: 0.2, cycleDays: 10, throughput: 10, incidents: 5, reinvestRatio: 0.5 },
  { week: 2, aiAdoption: 0.8, cycleDays: 8, throughput: 12, incidents: 4, reinvestRatio: 0.8 },
]);
console.log(r.weekly[1].efficiencyGain === 0.2);
console.log(typeof r.correlation === 'number');
console.log(attributeValue([]).correlation === 0); // 边界
```


**评分点**：
- 各指标相对基线变化率正确（周期下降为正）
- reinvestRatio 调节价值折算
- 皮尔逊相关计算与样本<2 保护
- 能区分「相关非因果」属加分
