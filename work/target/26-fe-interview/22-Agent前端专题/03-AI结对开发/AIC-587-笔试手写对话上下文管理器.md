## AIC-587：笔试：手写对话上下文管理

**答**：实现 `createConversationManager(requirements, { maxHistory, restateEvery })`。方法：`addTurn(role, content)`、`buildPrompt()`、`needsRestate()`。规则：1) `buildPrompt()` 返回 `{ system: string, history: Array }`——system 包含 requirements（固定位置）；2) **历史压缩**：history > maxHistory → 保留最近 5 条 + 早期压缩为 summary（`[Summary: N turns completed]`）；3) **需求重述提醒**：turns % restateEvery === 0 → needsRestate=true（提醒人重述需求——强化注意力 RBL-586）；4) `addTurn` 返回当前 turn 数。边界：requirements 空（system 无需求段）；history 空（buildPrompt 只有 system）；maxHistory=0（每轮都压缩——只剩最新一条）。

```javascript
function createConversationManager(requirements = [], { maxHistory = 10, restateEvery = 5 } = {}) {
  const history: { role: string; content: string }[] = [];
  function addTurn(role: string, content: string) {
    history.push({ role, content });
    // 压缩
    if (history.length > maxHistory) {
      const excess = history.length - maxHistory;
      const summary = { role: 'system',
        content: `[Summary: ${excess} earlier turns completed]` };
      history.splice(0, excess, summary);
    }
    return history.length;
  }
  function buildPrompt() {
    const system = requirements.length
      ? `Requirements:\n${requirements.map(r => `- ${r}`).join('\n')}` : '';
    return { system, history: [...history] };
  }
  function needsRestate() {
    return history.length > 0 && history.length % restateEvery === 0;
  }
  return { addTurn, buildPrompt, needsRestate,
    get turnCount() { return history.length; } };
}

// 自测
const mgr = createConversationManager(
  ['Use cursor-based pagination', 'TypeScript strict mode'],
  { maxHistory: 5, restateEvery: 3 },
);
mgr.addTurn('user', 'Write a pagination hook');
mgr.addTurn('assistant', 'Here is the hook...');
mgr.addTurn('user', 'Now add search');
// buildPrompt：system 有需求
let p = mgr.buildPrompt();
console.log(p.system.includes('cursor-based'));
console.log(p.history.length === 3);
// needsRestate：3 % 3 === 0
console.log(mgr.needsRestate() === true);
// 压缩：addTurn 超过 maxHistory=5
for (let i = 4; i <= 7; i++) mgr.addTurn('user', `turn ${i}`);
console.log(mgr.turnCount === 5);                        // 压缩到 maxHistory
console.log(mgr.buildPrompt().history[0].content.includes('Summary'));
// needsRestate：5 % 3 !== 0
console.log(mgr.needsRestate() === false);
// 空 requirements
const mgr2 = createConversationManager([], { maxHistory: 5 });
console.log(mgr2.buildPrompt().system === '');
```

**评分点**：
- 需求固定在 system prompt（不随对话轮次衰减 RBL-586）；历史压缩（超 maxHistory → summary 替换早期）
- needsRestate 的周期提醒（restateEvery 轮提醒重述——强化注意力）；压缩后的 history 含 summary
- 边界（空 requirements/空 history/maxHistory=0）；buildPrompt 的 system 与 history 分离
- 能说清「system prompt 的位置固定 = 每请求都有——对话中的需求会随轮次被注意力稀释或裁掉」属于加分
