## AIC-620：笔试：手写新旧行为兼容检查器

**答**：实现 `checkCompatibility(baseline, oldOut, newOut, opts)`。baseline: `{key:string, transform?:'identity'|'lower'|'num'}[]`（行为基线，key 为输出对象字段，可选变换）；oldOut/newOut: `Record<string, any>`；opts: `{ allowAdded?:boolean, ignoreKeys?:string[] }`（默认 allowAdded=true, ignoreKeys=[]）。规则：1) 对每个 baseline.key，比较 `pick(oldOut,key)` 与 `pick(newOut,key)`（经 transform 后）；相等 → 'preserved'，不等 → 'broken'；2) newOut 中多出的 key：allowAdded=true 视为 ok，否则 'unexpected-add'；3) ignoreKeys 中的 key 跳过；4) oldOut 有但 baseline 未列的 key：若 newOut 缺失 → 'silently-dropped'（旧字段被悄悄丢弃）。返回 `{ preserved:string[], broken:string[], dropped:string[], added:string[], compatible:boolean }`。边界：baseline 空但 oldOut/newOut 非空——仅检查 dropped/added。

```javascript
function checkCompatibility(baseline = [], oldOut = {}, newOut = {}, opts = {}) {
  const { allowAdded = true, ignoreKeys = [] } = opts;
  const ignored = new Set(ignoreKeys);
  const apply = (v, t) => t === 'lower' ? String(v).toLowerCase()
    : t === 'num' ? Number(v) : v;
  const preserved = [], broken = [], dropped = [], added = [];
  for (const b of baseline) {
    if (ignored.has(b.key)) continue;
    const o = apply(oldOut[b.key], b.transform);
    const n = apply(newOut[b.key], b.transform);
    (JSON.stringify(o) === JSON.stringify(n) ? preserved : broken).push(b.key);
  }
  // 旧字段被悄悄丢弃（baseline 未列但 old 有、new 无）
  for (const k of Object.keys(oldOut)) {
    if (ignored.has(k) || baseline.some(b => b.key === k)) continue;
    if (!(k in newOut)) dropped.push(k);
  }
  // new 多出的字段
  for (const k of Object.keys(newOut)) {
    if (!(k in oldOut) && !ignored.has(k) && !allowAdded) added.push(k);
  }
  return { preserved, broken, dropped, added,
    compatible: broken.length === 0 && dropped.length === 0 };
}

// 自测
const baseline = [{ key: 'price' }, { key: 'title', transform: 'lower' }];
const old = { price: 100, title: 'Phone', currency: 'CNY' };
const neu = { price: 90, title: 'phone' }; // price 变了, currency 丢了
const r = checkCompatibility(baseline, old, neu);
console.log(r.broken.join(',') === 'price');
console.log(r.dropped.join(',') === 'currency');
console.log(r.compatible === false);
console.log(checkCompatibility(baseline, old, { ...old }).compatible === true);
```

**评分点**：
- baseline 逐字段比较 + transform（identity/lower/num）正确应用
- 静默丢弃检测：old 有但 baseline 未列且 new 缺失 → dropped
- allowAdded 开关控制 unexpected-add，ignoreKeys 正确跳过
- compatible 综合 broken 与 dropped（不含 added）
- 能说清「兼容检查器把『保留旧行为』变成可自动验证的条件，是 feature flag 之外的第二道护栏」属于加分
