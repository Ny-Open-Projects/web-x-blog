## AIC-557：笔试：手写迭代收敛检测

**答**：实现 `checkConvergence(iterations, { convergeRatio, oscillateThreshold })`。iterations: `{ changedLines, feedback? }[]`。规则：1) ratios：相邻两轮的变化量比（本轮/上轮）；2) converging：最后 2 个 ratio 均 < convergeRatio（默认 0.5）；3) oscillating：最后 2 个 ratio 均 ≥ oscillateThreshold（默认 1.0）；4) 返回 `{ converging, oscillating, ratios, suggestion }`。边界：iterations 长度 < 3（两者都 null——无法判断趋势）；changes 有 0（ratio = 0——收敛极快）；monotonic 递减（ratio 递减——强收敛）。

```javascript
function checkConvergence(iterations = [], { convergeRatio = 0.5, oscillateThreshold = 1.0 } = {}) {
  if (iterations.length < 3)
    return { converging: null, oscillating: null, ratios: [], suggestion: '需要 ≥3 轮迭代判断趋势' };
  const changes = iterations.map(i => i.changedLines ?? 0);
  const ratios = [];
  for (let i = 1; i < changes.length; i++) {
    ratios.push(changes[i - 1] > 0 ? +(changes[i] / changes[i - 1]).toFixed(2) : 0);
  }
  const last2 = ratios.slice(-2);
  const converging = last2.every(r => r < convergeRatio);
  const oscillating = last2.every(r => r >= oscillateThreshold);
  let suggestion;
  if (oscillating) suggestion = '震荡——请提供包含原因的具体反馈';
  else if (converging) suggestion = '正在收敛——继续当前迭代';
  else suggestion = '变化量稳定——可能需要改变策略';
  return { converging, oscillating, ratios, suggestion };
}

// 自测
// 收敛：变化量递减
let r = checkConvergence([
  { changedLines: 50 }, { changedLines: 10 }, { changedLines: 2 },
]);
console.log(r.converging === true);                      // ratios [0.2, 0.2] 均 < 0.5
console.log(r.oscillating === false);

// 震荡：变化量不减
r = checkConvergence([
  { changedLines: 50 }, { changedLines: 60 }, { changedLines: 55 },
]);
console.log(r.oscillating === true && r.converging === false);
// ratios [1.2, 0.92] 均 ≥ 1.0

// 稳定
r = checkConvergence([
  { changedLines: 50 }, { changedLines: 50 }, { changedLines: 50 },
]);
console.log(r.ratios.every(x => x === 1));
console.log(r.suggestion.includes('改变策略'));          // 稳定不变——需要新策略

// 有 0 变化（极快收敛）
r = checkConvergence([
  { changedLines: 50 }, { changedLines: 10 }, { changedLines: 0 },
]);
console.log(r.converging === true);                      // ratio 0 < 0.5

// < 3 轮
console.log(checkConvergence([{ changedLines: 5 }]).converging === null);
console.log(checkConvergence([]).ratios.length === 0);
```

**评分点**：
- 双检测：converging（ratio < 0.5）与 oscillating（ratio ≥ 1.0）——独立判断不互斥
- 三轮最小样本（< 3 无法判断趋势——诚实标注）；ratio=0（极快收敛）
- 边界（稳定不变/有 0 变化/不足 3 轮）；suggestion 的可操作性
- 能说清「收敛检测 = 变化量比值的趋势分析：递减比 = 收敛、恒定比 = 震荡、需要不同策略」属于加分
