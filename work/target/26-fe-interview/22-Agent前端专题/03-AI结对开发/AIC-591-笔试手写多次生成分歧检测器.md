## AIC-591：笔试：手写分歧检测

**答**：实现 `detectDivergence(outputs, { normalize })`。outputs: string[]（多次生成的代码）。规则：1) normalize：去空白/排序语句（语义等价的不同实现 → normalize 后相同 RBL-667）；2) 两两比较：不一致的对数 = divergentPairs；3) confidence：一致 = 'high'；不一致对数 < runs-1 = 'medium'；≥ runs-1 = 'low'（全不一致）；4) 返回 `{ consistent, divergentPairs, confidence, consensus: string | null }`（consensus = 所有输出一致时的共同结果）。边界：outputs 空/1（无法比较——no-data）；全部一致（divergentPairs 空）；全部不同（全 divergent）。

```javascript
function detectDivergence(outputs = [], { normalize = (s) => s.replace(/\s+/g, ' ').trim() } = {}) {
  if (outputs.length <= 1)
    return { noData: true, consistent: null, divergentPairs: [], confidence: null, consensus: null };
  const normalized = outputs.map(normalize);
  const divergentPairs: [number, number][] = [];
  for (let i = 0; i < normalized.length; i++)
    for (let j = i + 1; j < normalized.length; j++)
      if (normalized[i] !== normalized[j]) divergentPairs.push([i, j]);
  const consistent = divergentPairs.length === 0;
  const total = outputs.length;
  const confidence = consistent ? 'high'
    : divergentPairs.length < total - 1 ? 'medium' : 'low';
  return {
    consistent, divergentPairs, confidence,
    consensus: consistent ? normalized[0] : null,
  };
}

// 自测
// 全一致（normalize 后）
let r = detectDivergence(['const x = 1;', 'const x = 1;  ', 'const  x  =  1;']);
console.log(r.consistent === true && r.confidence === 'high');
console.log(r.consensus === 'const x = 1;');

// 不一致
r = detectDivergence(['result A', 'result B', 'result C']);
console.log(r.consistent === false && r.confidence === 'low');
console.log(r.divergentPairs.length === 3);               // C(3,2)=3 对

// 部分一致
r = detectDivergence(['A', 'A', 'B']);
console.log(r.consistent === false && r.confidence === 'medium');   // 1 对不一致 < 2
console.log(r.divergentPairs.length === 2);              // (0,2) 和 (1,2) 不一致

// 单输出
console.log(detectDivergence(['only']).noData === true);
// 空
console.log(detectDivergence([]).noData === true);
```

**评分点**：
- 两两比较（C(n,2) 对——全部检测）；confidence 三级（high/medium/low 按不一致对数）
- normalize 的语义等价（去空白/排序——不同实现但语义相同视为一致）；consensus 提取
- 边界（空/单输出/全一致/全不同/部分一致）；no-data 的诚实标注
- 能说清「多次生成的分歧区域 = 审查的最高效靶点：一致部分可信、分歧部分需要人审——审查聚焦」属于加分
