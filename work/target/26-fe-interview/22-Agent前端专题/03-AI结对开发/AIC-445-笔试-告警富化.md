## AIC-445：笔试：告警触发时自动聚合上下文。
**答**：输入告警 `{service, signature}` 与数据源（recentChanges/similarIncidents/runbook 三个 mock 异步函数）。并行拉取，超时（mock 为立即返回）聚合输出 `{brief, steps, execute:'human-only'}`，任一源失败其余照常返回（部分降级）。

```javascript
async function enrich(alert, { recentChanges, similarIncidents, runbook }) {
  const [rc, si, rb] = await Promise.allSettled([
    recentChanges(alert.service), similarIncidents(alert.signature), runbook(alert.signature)]);
  const brief = [];
  if (rc.status === 'fulfilled') brief.push({ changes: rc.value });
  else brief.push({ changes: 'degraded（获取失败）' });
  if (si.status === 'fulfilled') brief.push({ similar: si.value });
  return { brief, steps: rb.status === 'fulfilled' ? rb.value : [],
           execute: 'human-only' };
}
// 用法：await enrich(alert, sources) → 值班者 10 秒拿到全部上下文

```

**评分点**：
- Promise.allSettled（部分失败不整体失败）——关键考点。
- 输出统一结构且执行权在人。
- 失败源在 brief 中标注 degraded。
- 并行拉取（不串行等待）。
