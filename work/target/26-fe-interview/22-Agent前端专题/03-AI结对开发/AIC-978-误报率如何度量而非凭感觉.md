## AIC-978：大家都说「AI Review 误报太多」，如何科学度量误报率而不是凭主观感觉？
**答**：
- 先定义「误报」的操作标准：报告的问题经人判断后「无需修改且合理」才算误报（不是「我不想改」）——结论：要有可操作的标注规范，否则数据不可信。
- 核心指标：精确率（Precision）= 真问题 / 报告总数，这就是「报出来的有多少是真的」；同时跟踪按规则/文件类型的误报分布，定位重灾区。
- 用「阳性预测值」作为北极星，配合「工程师处置率」（报告被点击处理的比例）作为信任代理指标；采样人工复核保证标注质量。
- 追问钩子：能区分「误报（假阳性）」与「漏报（假阴性）」并说明两者权衡——降误报常升漏报，要按场景（安全 vs 风格）分别设定容忍度——的候选人，度量观很成熟。

```typescript
// 误报率度量：精确率 + 处置率
const labels = [
  { rule:'R1', trueIssue:true }, { rule:'R1', trueIssue:false },
  { rule:'R2', trueIssue:true }, { rule:'R2', trueIssue:true },
];
function reviewMetrics(labels) {
  const byRule = {};
  for (const l of labels) {
    byRule[l.rule] ??= { reported:0, real:0 };
    byRule[l.rule].reported++;
    if (l.trueIssue) byRule[l.rule].real++;
  }
  return Object.entries(byRule).map(([rule,s])=>({
    rule, precision:+(s.real/s.reported).toFixed(2) // 误报率 = 1 - precision
  }));
}
console.log(reviewMetrics(labels)); // R1 precision=0.5 → 误报多，重点治理
```
