## AIC-768：笔试：实现 AI 任务队列的吞吐与瓶颈分析器

**需求**：实现 `analyzeQueue(records, opts)`。`records`: `Array<{ ts, enqueueMs, startMs, endMs, kind }>`（时间毫秒）；`opts.windowMs`（默认 3600000）、`saturation`（默认 0.85）。规则：1) 按 windowMs 分桶（ts 所在窗口），每桶统计到达数 `arrivals` 与总服务时长；2) 服务率 μ = 完成数 / 总服务时长（单位：任务/毫秒），到达率 λ = arrivals / windowMs；3) ρ = λ / μ；4) 找 ρ 最高的桶为 `bottleneckWindow`，并标记 `saturated: ρ > saturation`；5) 计算平均等待 = mean(startMs - enqueueMs)。边界：records 空（全 0/null）；μ=0 时 ρ=Infinity；无完成记录 μ=0。

**答**：
- 结论先行：瓶颈分析要把「到达率」和「服务能力」都换算到同一时间单位，ρ 才有意义；分桶能定位「哪个时段堵」，而不是看全局平均掩盖突刺。
- ρ=Infinity（无完成）是重要信号，表示服务完全停滞，必须显式处理而非静默取 0。
- 追问钩子：为什么分桶比全局 ρ 更重要？——全局平均会抹平高峰，而瓶颈恰恰发生在高峰时段；要按窗口看 ρ 峰值。

```javascript
function analyzeQueue(records = [], opts = {}) {
  const windowMs = opts.windowMs ?? 3600000;
  const saturation = opts.saturation ?? 0.85;
  const buckets = {};
  let totalWait = 0, completed = 0;
  for (const r of records) {
    const b = Math.floor(r.ts / windowMs) * windowMs;
    const o = (buckets[b] ??= { arrivals: 0, serviceMs: 0, done: 0 });
    o.arrivals++;
    totalWait += (r.startMs ?? r.ts) - r.enqueueMs;
    if (r.endMs != null) { o.serviceMs += r.endMs - r.startMs; o.done++; completed++; }
  }
  let worst = null;
  for (const [t, o] of Object.entries(buckets)) {
    const lambda = o.arrivals / windowMs;
    const mu = o.serviceMs ? o.done / o.serviceMs : 0;
    const rho = mu ? lambda / mu : Infinity;
    if (!worst || rho > worst.rho) worst = { window: +t, rho, saturated: rho > saturation };
  }
  return {
    bottleneckWindow: worst?.window ?? null,
    saturated: worst?.saturated ?? false,
    avgWaitMs: records.length ? totalWait / records.length : 0,
    completed,
  };
}
const now = 100000;
const r = analyzeQueue([
  { ts: now, enqueueMs: now, startMs: now + 100, endMs: now + 1100, kind: 'code' },
  { ts: now + 10, enqueueMs: now + 10, startMs: now + 200, endMs: now + 1200, kind: 'code' },
], { windowMs: 10000 });
console.log(r.completed === 2 && r.avgWaitMs > 0);
console.log(analyzeQueue([]).bottleneckWindow === null); // 边界
```


**评分点**：
- 按窗口分桶统计到达数与总服务时长
- λ/μ 与 ρ 换算正确、μ=0 时 ρ=Infinity
- 找 ρ 最高桶并标 saturated
- 平均等待累计与空记录边界
