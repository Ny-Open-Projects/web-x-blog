## AIC-551：笔试：手写动态信任校准

**答**：实现 `calibrateTrust(models, { targetBugRate, tightenStep, relaxStep, minSample })`。models: `{ domain, bugRate, sampleRate, sampleCount }[]`。规则：1) bugRate > targetBugRate × 2 且 sampleCount ≥ minSample → sampleRate + tightenStep（上限 1）；2) bugRate < targetBugRate / 2 且 sampleCount ≥ minSample → sampleRate − relaxStep（下限 0.1）；3) bugRate 在范围内 → 不变（hold）；4) sampleCount < minSample → 不调整（数据不足 RBL-517 minSamples 语义）；5) 返回 `{ domain, oldSampleRate, newSampleRate, action: 'tighten'|'relax'|'hold'|'insufficient-data' }[]`。边界：sampleRate 已 = 1（tighten 不超 1）；sampleRate 已 = 0.1（relax 不低于 0.1）；sampleCount=0（insufficient）；targetBugRate=0（除零——所有 > 0 的 bugRate 视为超）。

```javascript
function calibrateTrust(models = [], { targetBugRate = 0.02, tightenStep = 0.2,
  relaxStep = 0.1, minSample = 20 } = {}) {
  return models.map(m => {
    const old = m.sampleRate;
    if ((m.sampleCount ?? 0) < minSample)
      return { domain: m.domain, oldSampleRate: old, newSampleRate: old, action: 'insufficient-data' };
    const over = targetBugRate === 0 ? m.bugRate > 0 : m.bugRate > targetBugRate * 2;
    const under = m.bugRate < targetBugRate / 2;
    let action = 'hold'; let newRate = old;
    if (over) {
      newRate = Math.min(1, old + tightenStep);
      action = newRate > old ? 'tighten' : 'hold';
    } else if (under) {
      newRate = Math.max(0.1, old - relaxStep);
      action = newRate < old ? 'relax' : 'hold';
    }
    return { domain: m.domain, oldSampleRate: old, newSampleRate: +newRate.toFixed(2), action };
  });
}

// 自测
const models = [
  { domain: 'ts', bugRate: 0.08, sampleRate: 0.3, sampleCount: 50 },    // 0.08 > 0.04 → tighten
  { domain: 'css', bugRate: 0.001, sampleRate: 0.3, sampleCount: 50 },  // 0.001 < 0.01 → relax
  { domain: 'sql', bugRate: 0.02, sampleRate: 0.3, sampleCount: 50 },   // 0.02 在范围内 → hold
  { domain: 'new', bugRate: 0.1, sampleRate: 0.3, sampleCount: 5 },     // 数据不足
];
let r = calibrateTrust(models);
console.log(r[0].action === 'tighten' && r[0].newSampleRate === 0.5);
console.log(r[1].action === 'relax' && r[1].newSampleRate === 0.2);
console.log(r[2].action === 'hold');
console.log(r[3].action === 'insufficient-data');

// sampleRate 已 = 1 不超
r = calibrateTrust([{ domain: 'x', bugRate: 0.1, sampleRate: 1, sampleCount: 50 }]);
console.log(r[0].action === 'hold' && r[0].newSampleRate === 1);   // 已最高

// sampleRate 已 = 0.1 不降
r = calibrateTrust([{ domain: 'y', bugRate: 0.001, sampleRate: 0.1, sampleCount: 50 }]);
console.log(r[0].action === 'hold' && r[0].newSampleRate === 0.1);   // 已最低

// 空
console.log(calibrateTrust([]).length === 0);
```

**评分点**：
- 动态校准的双向（tighten 收紧 + relax 放宽——数据驱动 RBL-550）；上下限（1/0.1）
- sampleCount 门禁（数据不足不调整——防 noise 驱动 RBL-517）；targetBugRate=0 的除零防御
- 边界（已最高/已最低/数据不足/空）；action 的四种值
- 能说清「信任校准 = 数据驱动的动态调整：bug 率高收紧、bug 率低放宽——不是固定审查率而是自适应的」属于加分
