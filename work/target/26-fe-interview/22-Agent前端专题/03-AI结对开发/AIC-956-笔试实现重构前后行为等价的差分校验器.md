## AIC-956：笔试：实现「重构前后行为等价的差分校验器」（多输入对比输出 + 副作用）
**答**：
- 核心需求：实现 `diffBehavior(before, after, cases, opts)`。`before/after` 为函数；`cases: { input, expectSideEffects? }[]`。返回 `{ passed, failures }`。
- 对比内容：① 返回值深度相等；② 副作用序列相等（函数可通过 opts.capture 注入的 recorder 记录，如 recorder.log）；③ 抛错行为一致（都抛/都不抛，错误消息一致）。
- 边界：cases 为空返回 passed=true/failures=[]；函数抛错要捕获并归类比较（避免一个抛错中断整体）；深度比较要处理对象/数组/NaN（NaN 视为相等）。
- 语义：差分校验只能证明「给定用例集上等价」，不能证明全等价——failures 要带具体 input 与差异点便于定位；通过率要给评估者看覆盖盲区。
- 追问钩子：能指出「用例集的代表性决定结论可信度；要配合特征化测试覆盖历史 bug 场景」的候选人理解差分验证的相对性。

```typescript
function deepEqual(a,b){
  if(Object.is(a,b))return true;
  if(typeof a!=='object'||typeof b!=='object'||!a||!b)return false;
  const ka=Object.keys(a),kb=Object.keys(b);
  return ka.length===kb.length && ka.every(k=>deepEqual(a[k],b[k]));
}
function runCapture(fn, input){
  const recorder={ log:[] };
  try { return { ok:true, value:fn(input, recorder), effects:recorder.log.slice() }; }
  catch(e){ return { ok:false, error:String(e.message||e), effects:recorder.log.slice() }; }
}
function diffBehavior(before, after, cases=[], opts={}) {
  const failures=[];
  for(const c of cases){
    const a=runCapture(before,c.input), b=runCapture(after,c.input);
    const same = a.ok===b.ok && deepEqual(a.value,b.value) && a.error===b.error
      && deepEqual(a.effects,b.effects);
    if(!same) failures.push({ input:c.input, before:a, after:b });
  }
  return { passed:failures.length===0, failures };
}
console.log(diffBehavior(x=>x*2, x=>x+x, [{input:3}]).passed); // true
```
**评分点**：
- deepEqual 处理对象/数组/NaN（Object.is），递归比较正确。
- runCapture 记录副作用与抛错，异常不中断整体对比。
- diffBehavior 对比返回值/副作用/抛错行为三者，failures 带 input 与差异。
- 空 cases 返回 passed=true，边界处理完整。
- 明确「只在用例集上等价，代表性决定可信度」（加分项）。
