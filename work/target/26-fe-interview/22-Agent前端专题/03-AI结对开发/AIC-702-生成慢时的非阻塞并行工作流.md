## AIC-702：AI 生成耗时长时如何设计非阻塞的并行工作流

**答**：
- 结论先行：不要在 AI 生成时「干等」，而要把等待窗口变成人做高价值工作的并行槽——先让 AI 异步生成，人同步推进审查准备、测试用例设计、边界清单整理。
- 具体做法：1) 提交需求后立即让 AI 进入后台生成；2) 人并行写「验收清单」（期望行为、边界、反例）；3) 生成完成后用验收清单逐条核对，而不是重新读一遍代码。
- 关键：并行不等于分心——并行槽必须围绕「同一任务的验收」展开，否则切换成本会吃掉收益。
- 追问钩子：并行工作流如何避免「AI 生成完了人还没准备好验收」的错配？——用任务看板把「生成中 / 待验收 / 验收中」显式化。

```javascript
// 并行工作流：生成任务与验收准备同时进行
async function pairFlow(task) {
  const gen = generateAsync(task);          // 后台生成，不阻塞
  const checklist = buildChecklist(task);   // 人并行写验收清单
  const code = await gen;                   // 此刻清单已就绪
  return checklist.map(item => ({
    item,
    pass: verify(code, item),               // 用清单核对，而非重读代码
  }));
}
function generateAsync(t) { return new Promise(r => setTimeout(() => r('code:' + t.id), 10)); }
function buildChecklist(t) { return t.acceptance; }
function verify(code, item) { return code.includes(item); }
pairFlow({ id: 7, acceptance: ['code:7', 'token'] }).then(r => console.log(r));
// [ { item:'code:7', pass:true }, { item:'token', pass:false } ]
```
