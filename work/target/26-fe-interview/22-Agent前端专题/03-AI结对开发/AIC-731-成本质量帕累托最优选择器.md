## AIC-731：笔试：实现成本-质量帕累托最优配置选择器

**需求**：实现 `pickOptimal(configs, budget, opts)`。`configs`: `Array<{ name, cost, quality }>`；`budget`: number；`opts.minQuality`（默认 0.8）。规则：1) 过滤 `cost <= budget` 且 `quality >= minQuality` 的配置；2) 在候选里选质量最高者；3) 质量相同选成本最低者；4) 再相同选 name 字典序小者；5) 无候选返回 `{ name:null, reason:'no-candidate' }`。边界：configs 空；budget<=0；cost/quality 非数字视为 0。返回选中配置（附加字段 `chosenBy` 记录选择依据）。

**答**：
- 结论先行：先按硬约束（预算、最低质量）过滤，再在最优点里按「质量优先、成本次之、名称兜底」稳定排序——决策可复现是工程化的底线。
- 阈值要包含边界（>= / <=），避免恰好等于预算或质量线的配置被误排除。
- 追问钩子：为什么质量优先于成本？——在已满足预算的前提下，多花一点预算换更高价值通常是划算的；除非成本是硬上限。

```javascript
function pickOptimal(configs = [], budget, opts = {}) {
  const minQuality = opts.minQuality ?? 0.8;
  const num = v => (typeof v === 'number' && v >= 0 ? v : 0);
  const ok = configs.filter(c => num(c.cost) <= num(budget) && num(c.quality) >= minQuality);
  if (!ok.length) return { name: null, reason: 'no-candidate' };
  ok.sort((a, b) => num(b.quality) - num(a.quality) || num(a.cost) - num(b.cost)
                   || String(a.name).localeCompare(String(b.name)));
  return { ...ok[0], chosenBy: 'quality-first' };
}
const cfg = [
  { name: 'cheap', cost: 1, quality: 0.72 },
  { name: 'mid', cost: 3, quality: 0.85 },
  { name: 'top', cost: 9, quality: 0.95 },
  { name: 'mid2', cost: 2, quality: 0.85 },
];
console.log(pickOptimal(cfg, 5).name === 'mid2'); // mid/top 中质量相同取成本低的 mid2
console.log(pickOptimal(cfg, 0.5).reason);        // no-candidate
console.log(pickOptimal([], 10).reason);          // 边界
```


**评分点**：
- 硬约束过滤（cost<=budget 且 quality>=minQuality），含边界等号
- 质量优先→成本最低→名称字典序的稳定排序
- 无候选返回 no-candidate
- 边界（空 configs / budget<=0 / 非数字归 0）
