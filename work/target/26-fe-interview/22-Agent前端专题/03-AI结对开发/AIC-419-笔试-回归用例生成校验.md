## AIC-419：笔试：实现回归用例「先红后绿」校验器。
**答**：输入用例 `{id, runOn(ref)}` 与仓库 refs（pre-fix/post-fix）。校验：pre-fix 必须失败且失败信息含断言类错误；post-fix 必须通过。不满足即判无效并给原因。

```javascript
function validateRegression(tc, refs) {
  if (!refs['pre-fix'] || !refs['post-fix']) return { valid: false, reason: 'refs 缺失' };
  const pre = tc.runOn('pre-fix');
  const isRed = pre.failed && /Assertion/i.test(pre.error ?? '');
  if (!isRed) return { valid: false,
    reason: pre.failed ? 'pre-fix 失败但非断言错误（环境问题？）' : 'pre-fix 未失败：用例未捕获 bug' };
  const post = tc.runOn('post-fix');
  return post.passed ? { valid: true } : { valid: false, reason: 'post-fix 未通过：用例本身有错' };
}
console.log(validateRegression({
  id: 'R1',
  runOn: ref => ref === 'pre-fix'
    ? { failed: true, error: 'AssertionError: expected 0 got 5' }
    : { failed: false, passed: true },
}, { 'pre-fix': 1, 'post-fix': 1 })); // valid: true

```

**评分点**：
- 双态校验（pre 红 + post 绿）缺一即无效——只验证绿的用例可能是无效用例。
- 失败类型判定：断言错误（AssertionError）才算「红」，环境错误（找不到文件）不计为红。
- 原因输出指导修复（哪个状态不满足）。
- refs 缺失防御。
