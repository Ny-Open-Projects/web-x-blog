## AIC-489：笔试：从评审会焦点生成结构化纪要。
**答**：焦点 `[{topic, decision, owner, deadline}]`。纪要：决策区（有 decision 的）/待办区（owner+deadline）/遗留区（无 decision）。deadline 距今 < 3 天标 urgent。

```javascript
function minutes(focus, now) {
  const DAY = 86_400_000;
  const decided = [], todo = [], leftover = [];
  for (const f of focus) {
    if (f.decision) decided.push(`- ${f.topic}：${f.decision}`);
    else if (f.owner) todo.push(`- ${f.topic} @${f.owner}${f.deadline && f.deadline - now < 3 * DAY ? ' [URGENT]' : ''}`);
    else leftover.push(`- ${f.topic}（无决策无 owner）`);
  }
  return { decided, todo: todo.map(t => t.includes('URGENT') ? t : t),
           leftover };
}
console.log(minutes([
  { topic: '状态库选型', decision: 'Zustand', owner: 'li' },
  { topic: '灰度方案', owner: 'wang', deadline: 2 * 86_400_000 },
], 0)); // decided 1；todo 1 带 URGENT

```

**评分点**：
- 三区分类明确（decision 存在与否是分界）。
- owner 缺失的待办标 unassigned（不静默）。
- urgent 判定（< 3 天）。
- 输出 Markdown 区块可直接发频道。
