## AIC-630：笔试：手写草稿-精修成本优化器

**答**：实现 `optimizeDraftRefine(tasks, models, opts)`。tasks: `{id:string, tokens:number, risk:'low'|'high'}[]`；models: `{name:string, pricePerK:number, quality:number, canRefine:boolean}[]`（quality 0-1）；opts: `{ budget:number, reworkPenalty:number }`（总预算/返工惩罚成本）。为每任务选策略：'draft-refine'（便宜模型草稿+高质量模型精修）或 'direct'（直接用高质量模型）或 'cheap-only'（只用便宜模型）。规则：1) draft-refine 成本 = cheap.price×tokens/1000 + refine.price×tokens×0.3/1000（精修只处理 30% token），质量 = min(1, cheap.quality + refine.quality×0.3)，返工率 = (1−质量)×(risk==='high'?2:1)；2) direct 成本 = high.price×tokens/1000，质量 = high.quality，返工率 = (1−质量)；3) cheap-only 成本 = cheap.price×tokens/1000，返工率 = (1−cheap.quality)×(risk==='high'?3:1)；4) 总成本 = 模型成本 + 返工率×reworkPenalty；选总成本最低且质量 ≥ 0.8 的策略（都不达标选质量最高者）。返回 `{ plan:Array<{id,strategy,quality,cost}>, totalCost, withinBudget:boolean }`。边界：tasks 空返回空计划。

```javascript
function optimizeDraftRefine(tasks = [], models = [], opts = {}) {
  const { budget = Infinity, reworkPenalty = 10 } = opts;
  const cheap = [...models].sort((a, b) => a.pricePerK - b.pricePerK)[0];
  const high = [...models].sort((a, b) => b.quality - a.quality)[0];
  if (!cheap || !high || tasks.length === 0) return { plan: [], totalCost: 0, withinBudget: true };
  const k = t => t.tokens / 1000;
  const strategies = t => {
    const rf = (1 - Math.min(1, cheap.quality + high.quality * 0.3)) * (t.risk === 'high' ? 2 : 1);
    const drCost = cheap.pricePerK * k(t) + high.pricePerK * k(t) * 0.3 + rf * reworkPenalty;
    const drQ = Math.min(1, cheap.quality + high.quality * 0.3);
    const dirRf = 1 - high.quality;
    const dirCost = high.pricePerK * k(t) + dirRf * reworkPenalty;
    const coRf = (1 - cheap.quality) * (t.risk === 'high' ? 3 : 1);
    const coCost = cheap.pricePerK * k(t) + coRf * reworkPenalty;
    return [
      { strategy: 'draft-refine', quality: drQ, cost: drCost },
      { strategy: 'direct', quality: high.quality, cost: dirCost },
      { strategy: 'cheap-only', quality: cheap.quality, cost: coCost },
    ];
  };
  let total = 0;
  const plan = tasks.map(t => {
    const opts2 = strategies(t).sort((a, b) => b.quality - a.quality ? 0 : 0); // 先按质量筛
    const qualified = strategies(t).filter(s => s.quality >= 0.8).sort((a, b) => a.cost - b.cost);
    const pool = qualified.length ? qualified : strategies(t).sort((a, b) => b.quality - a.quality);
    const chosen = { id: t.id, ...pool[0] };
    total += chosen.cost;
    return chosen;
  });
  return { plan, totalCost: total, withinBudget: total <= budget };
}

// 自测
const models = [
  { name: 'cheap', pricePerK: 1, quality: 0.6, canRefine: false },
  { name: 'strong', pricePerK: 10, quality: 0.95, canRefine: true },
];
const r = optimizeDraftRefine([{ id: 'T1', tokens: 1000, risk: 'low' }], models, { budget: 20, reworkPenalty: 10 });
console.log(r.plan.length === 1 && ['draft-refine', 'direct', 'cheap-only'].includes(r.plan[0].strategy));
console.log(r.plan[0].quality >= 0.8);
console.log(optimizeDraftRefine([], models).plan.length === 0);
```

**评分点**：
- 三种策略成本与质量建模正确（draft-refine 精修只算 30% token）
- 返工率受 risk 放大（high 风险返工惩罚更高）
- 选择逻辑：质量≥0.8 中成本最低，都不达标选质量最高
- budget 判定 withinBudget 正确
- 能说清「分层是否划算取决于返工成本，便宜模型导致的高返工会吃掉 API 省下的钱」属于加分
