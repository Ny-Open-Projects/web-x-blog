## AIC-617：笔试：手写幻觉漂移检测器

**答**：实现 `detectDrift(turns, repo)`。turns: `{text:string, decisions:string[]}[]`（多轮对话，每轮的回复文本与声称的决策）；repo: `{ symbols:string[], files:string[] }`（真实仓库符号/文件）。规则：1) 幻觉符号：turn.text 中反引号包裹且形如标识符、不在 repo.symbols 中 → 'phantom-symbol'；2) 决策反复：某 decision 在连续 3 轮出现又被推翻（后一轮 decisions 不再含它，且出现语义相反的新决策——用 `!decision` 表示否定）→ 'decision-flip'；3) 路径幻觉：turn.text 中出现的 `xx/yy.ts` 形式路径不在 repo.files → 'phantom-path'；4) 漂移分 = 幻觉项数 / 总检查项数（0-1）。返回 `{ issues:Array<{turnIndex,type,detail}>, driftScore:number, alert:boolean }`，alert = driftScore > 0.3。边界：turns 为空安全；反引号内非标识符（如 `npm install`）不算符号。

```javascript
function detectDrift(turns = [], repo = {}) {
  const symbols = new Set(repo.symbols || []);
  const files = new Set(repo.files || []);
  const issues = [];
  let checks = 0;
  turns.forEach((t, i) => {
    // 1) 幻觉符号：反引号内的合法标识符
    const syms = [...(t.text.matchAll(/`([A-Za-z_$][\w$]{3,})`/g) || [])].map(m => m[1]);
    for (const s of syms) {
      checks++;
      if (!symbols.has(s)) issues.push({ turnIndex: i, type: 'phantom-symbol', detail: s });
    }
    // 3) 幻觉路径：xx/yy.ts
    const paths = [...(t.text.matchAll(/([\w-]+\/[\w/-]+\.tsx?)/g) || [])].map(m => m[1]);
    for (const p of paths) {
      checks++;
      if (!files.has(p)) issues.push({ turnIndex: i, type: 'phantom-path', detail: p });
    }
  });
  // 2) 决策反复：连续3轮出现又被 !否定
  for (let i = 2; i < turns.length; i++) {
    const d0 = turns[i - 2].decisions || [];
    const d1 = turns[i - 1].decisions || [];
    const d2 = turns[i].decisions || [];
    for (const d of d0) {
      if (d1.includes(d) && d2.includes('!' + d)) {
        checks++;
        issues.push({ turnIndex: i, type: 'decision-flip', detail: d });
      }
    }
  }
  const driftScore = checks ? issues.length / checks : 0;
  return { issues, driftScore, alert: driftScore > 0.3 };
}

// 自测
const repo = { symbols: ['fetchUser', 'useState'], files: ['src/api.ts'] };
const turns = [
  { text: '用 `useFetchCache` 和 `fetchUser`', decisions: ['use-cache'] },
  { text: '改 `src/missing.ts` 吧', decisions: ['use-cache'] },
  { text: '不用缓存了，直接请求', decisions: ['!use-cache'] },
];
const r = detectDrift(turns, repo);
console.log(r.issues.some(x => x.type === 'phantom-symbol'));
console.log(r.issues.some(x => x.type === 'phantom-path'));
console.log(r.issues.some(x => x.type === 'decision-flip'));
console.log(r.alert === true);
console.log(detectDrift([], repo).driftScore === 0);
```

**评分点**：
- 三类幻觉检测（phantom-symbol / phantom-path / decision-flip）判定正确
- 符号/路径抽取正则合理，排除非标识符（npm install）
- 决策否定用 `!decision` 语义，连续 3 轮模式识别
- driftScore 计算与 alert 阈值 0.3 正确
- 能说清「幻觉漂移的早期信号是可证伪的具体事实（路径/符号）编造，而非抽象的『不确定』」属于加分
