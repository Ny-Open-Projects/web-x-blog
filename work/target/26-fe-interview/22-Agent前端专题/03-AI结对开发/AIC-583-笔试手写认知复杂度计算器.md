## AIC-583：笔试：手写认知复杂度

**答**：实现 `cognitiveComplexity(code)`。规则：1) 基础分：`if/for/while/catch/switch` 每个 +1；2) **嵌套加成**：嵌套深度 d（缩进/2）中出现的控制流 +1+d（嵌套越深越复杂）；3) 逻辑运算符：`&&` +1、`||` +1（同层不递增——连续 && 不加Nested）；4) 三元运算符：`? :` +1；5) `else if` 视为 if +1（不额外加嵌套）。返回 `{ complexity, level: 'low'|'medium'|'high' }`（level：≤5 low、6~15 medium、>15 high——SonarSource 阈值）。边界：空代码（0）；纯声明无控制流（0）；深层嵌套（high）；每个 if 在同一行（多个 if 累计）。

```javascript
function cognitiveComplexity(code = '') {
  let complexity = 0;
  const lines = code.split('\n');
  for (const line of lines) {
    const indent = Math.floor((line.match(/^\s*/)?.[0].length ?? 0) / 2);
    // 基础控制流：+1 + nesting
    const controlMatches = line.match(/\b(?:if|for|while|catch)\b/g) ?? [];
    for (const _ of controlMatches) {
      complexity += 1 + indent;                        // 嵌套加成
    }
    // switch 每个 case +1
    complexity += (line.match(/\bcase\b/g) ?? []).length;
    // 逻辑运算符（不额外加嵌套）
    complexity += (line.match(/&&/g) ?? []).length;
    complexity += (line.match(/\|\|/g) ?? []).length;
    // 三元
    complexity += (line.match(/\?[^:]*:/g) ?? []).length;
  }
  const level = complexity <= 5 ? 'low' : complexity <= 15 ? 'medium' : 'high';
  return { complexity, level };
}

// 自测
// 简单：0 嵌套
let r = cognitiveComplexity('const x = 1;\nreturn x;');
console.log(r.complexity === 0 && r.level === 'low');
// 单层 if
r = cognitiveComplexity('if (x > 0) { return x; }');
console.log(r.complexity === 1);                        // 1 + 0(嵌套) = 1
// 嵌套 if
r = cognitiveComplexity(
  'if (a) {\n  if (b) {\n    if (c) { return; } }\n}');
// if(a): 1+0=1; if(b): 1+1=2; if(c): 1+2=3 → total=6
console.log(r.complexity === 6);
console.log(r.level === 'medium');
// 逻辑运算符
r = cognitiveComplexity('if (a && b || c) { }');
// if: 1+0=1; &&: 1; ||: 1 → 3
console.log(r.complexity === 3);
// 深层嵌套 → high
r = cognitiveComplexity(
  'if (a) {\n  if (b) {\n    if (c) {\n      if (d) {\n        if (e) { return; }\n      }\n    }\n  }\n}');
// if(a):1, if(b):1+1=2, if(c):1+2=3, if(d):1+3=4, if(e):1+4=5 → total=15
console.log(r.complexity === 15);
console.log(r.level === 'medium');
// 再加一个 → >15
r = cognitiveComplexity(r2 => r2); // 不会执行——此处仅示意
// 空
console.log(cognitiveComplexity('').complexity === 0);
```

**评分点**：
- 认知复杂度计算正确：基础分（if/for/while/catch）+ 嵌套加成（indent/2 作为嵌套深度）；逻辑运算符独立计（不加嵌套）
- level 三级（≤5 low / 6~15 medium / >15 high——SonarSource 阈值）；嵌套 if 的累加验证
- 边界（空/纯声明/深层嵌套/逻辑运算符）；&& 与 || 的独立计数
- 能说清「认知复杂度 ≠ 圈复杂度：计算的是『人理解有多难』（嵌套越深越难）——AI 代码需要与人写代码的复杂度匹配」属于加分
