## AIC-696：笔试：手写 AI 能力灰度发布分流器

**答**：实现 `grayRouter(user, config)`。user: `{ id:string, team:string, isInternal:boolean }`；config: `{ percent:number (0-100), internalFirst:boolean, allowTeams:string[], sticky:true }`。规则：1) 若 internalFirst 且 isInternal → 强制走新版本（内部 dogfood）；2) 白名单团队 allowTeams 强制新版本；3) 否则基于 user.id 的稳定哈希（如 hash(id)%100 < percent）决定是否新版本——保证 sticky（同一用户每次结果一致，不会一会儿新一会儿旧）；4) 返回 `{ version:'new'|'old', reason:string, bucket:number }`。边界：percent=0 全走旧（除非内部/白名单）；percent=100 全走新；id 为空用 team 作 hash 源。

```javascript
function stableHash(s = '') {
  let h = 0;
  for (let i = 0; i < s.length; i++) h = (h * 31 + s.charCodeAt(i)) >>> 0;
  return h;
}

function grayRouter(user = {}, config = {}) {
  const { percent = 0, internalFirst = false, allowTeams = [], sticky = true } = config;
  if (config.internalFirst && user.isInternal) {
    return { version: 'new', reason: 'internal-dogfood', bucket: 0 };
  }
  if (allowTeams.includes(user.team)) {
    return { version: 'new', reason: 'team-whitelist', bucket: 0 };
  }
  const key = user.id || user.team || 'anonymous';
  const bucket = stableHash(key) % 100;
  const version = bucket < percent ? 'new' : 'old';
  return { version, reason: sticky ? 'stable-hash' : 'random', bucket };
}

// 自测
const cfg = { percent: 10, internalFirst: true, allowTeams: ['canary-team'], sticky: true };
console.log(grayRouter({ id: 'u1', team: 'fe', isInternal: true }, cfg).reason === 'internal-dogfood');
console.log(grayRouter({ id: 'u2', team: 'canary-team', isInternal: false }, cfg).reason === 'team-whitelist');
const r1 = grayRouter({ id: 'user-42', team: 'fe', isInternal: false }, cfg);
const r2 = grayRouter({ id: 'user-42', team: 'fe', isInternal: false }, cfg);
console.log(r1.bucket === r2.bucket && r1.version === r2.version); // sticky 稳定
console.log(grayRouter({ id: 'x', team: 'fe' }, { percent: 0 }).version === 'old');
console.log(grayRouter({ id: 'x', team: 'fe' }, { percent: 100 }).version === 'new');
```

**评分点**：
- 内部优先与团队白名单强制走新版本
- 稳定哈希分桶保证 sticky（同一用户结果一致）
- percent 边界（0 全旧/100 全新）
- id 为空回退用 team 作 hash 源
- 能说清「灰度分流必须 sticky，否则用户每次请求在版本间跳变，体验和数据都不可信」属于加分
