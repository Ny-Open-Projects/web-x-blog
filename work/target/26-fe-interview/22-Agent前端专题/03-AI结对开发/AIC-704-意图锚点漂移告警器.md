## AIC-704：笔试：实现结对会话的意图锚点漂移告警器

**需求**：实现 `detectDrift(anchors, outputs)`。`anchors`: `string[]`（需求关键点）；`outputs`: `string[]`（AI 每轮输出文本）。规则：1) 逐轮计算锚点关键词命中率；2) 若某轮命中率相对上一轮下降超过阈值 `drop`（默认 0.3），判为「漂移告警」；3) 若某轮引入与锚点无关的新主题词（由 `topics` 集合判定）且命中率为 0，判为「主题偏离」；4) 返回 `{ alerts: Array<{round, type, hitRate}>, finalHitRate }`。边界：anchors 为空（无告警、finalHitRate=0）；outputs 为空（alerts 空）；命中率用 anchor 词是否在文本中出现（子串匹配）。

**答**：
- 结论先行：漂移 = 输出对初始需求关键点的覆盖率随时间下降；用「逐轮命中率 + 环比跌幅」双信号判断，比单次覆盖率更能识别渐进漂移。
- 命中统计用子串匹配即可，但要注意锚点去重与大小写归一，避免同一词重复计数。
- 追问钩子：为什么只看「最终命中率」不够？——渐进漂移每步跌幅小，最终才暴露；环比能提前告警。

```javascript
function detectDrift(anchors = [], outputs = [], opts = {}) {
  const drop = opts.drop ?? 0.3;
  const topics = new Set(opts.topics ?? []);
  const norm = s => String(s).toLowerCase();
  const keys = [...new Set(anchors.map(norm))].filter(Boolean);
  const rates = outputs.map(text => {
    const t = norm(text);
    return keys.length ? keys.filter(k => t.includes(k)).length / keys.length : 0;
  });
  const alerts = [];
  for (let i = 0; i < rates.length; i++) {
    const prev = i === 0 ? 1 : rates[i - 1];
    if (prev - rates[i] > drop) alerts.push({ round: i, type: 'drift', hitRate: rates[i] });
    const offTopic = [...topics].some(tp => norm(text = outputs[i]).includes(norm(tp)));
    if (rates[i] === 0 && offTopic) alerts.push({ round: i, type: 'off-topic', hitRate: 0 });
  }
  return { alerts, finalHitRate: rates.length ? rates[rates.length - 1] : 0 };
}
const r = detectDrift(['登录', '验证码'], ['登录 验证码 流程', '登录 流程', '重写样式 动画'], { topics: ['样式', '动画'] });
console.log(r.alerts.map(a => a.type)); // ['drift', 'off-topic']
console.log(r.finalHitRate === 0);      // true
console.log(detectDrift([], ['x']).alerts.length === 0); // 边界：无锚点
```


**评分点**：
- 逐轮命中率计算正确（锚点去重、大小写归一、子串匹配）
- 环比跌幅告警与「主题偏离」双信号判定
- 边界处理（无锚点 / 空输出 / topics 缺失）
- 能说清「只看最终命中率会漏掉渐进漂移」属加分
