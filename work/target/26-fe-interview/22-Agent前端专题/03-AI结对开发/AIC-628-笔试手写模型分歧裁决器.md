## AIC-628：笔试：手写模型分歧裁决器

**答**：实现 `arbitrateDisagreement(candidates, evidence, opts)`。candidates: `{ model:string, answer:string, metrics?:{correct:number,perf:number} }[]`；evidence: `{ test:string, pass:boolean }[]`（客观测试证据）；opts: `{ weights?:{correct:number,perf:number}, tieBreak?:'human'|'prefer-complexity-low' }`（默认 weights={correct:0.7,perf:0.3}, tieBreak='human'）。规则：1) 若某候选的 answer 在 evidence 中被对应 test 明确验证通过（约定 test 名含模型名前缀且 pass=true）→ 直接胜出；2) 否则按 metrics 加权打分（缺失 metrics 记 0）；3) 分数差 < 0.05 视为平局，按 tieBreak 处理：human → winner=null需人工, prefer-complexity-low → 选 answer 更短者；4) 返回 `{ winner:string|null, scores:{model,score}[], reason:'evidence'|'metrics'|'tie' }`。边界：candidates 空 winner=null reason='empty'；单候选直接胜出。

```javascript
function arbitrateDisagreement(candidates = [], evidence = [], opts = {}) {
  const { weights = { correct: 0.7, perf: 0.3 }, tieBreak = 'human' } = opts;
  if (candidates.length === 0) return { winner: null, scores: [], reason: 'empty' };
  if (candidates.length === 1) return { winner: candidates[0].model, scores: [{ model: candidates[0].model, score: 1 }], reason: 'metrics' };
  // 1) 客观证据优先
  const evidenceWinner = candidates.find(c =>
    evidence.some(e => e.pass && e.test.startsWith(c.model + ':')));
  if (evidenceWinner) {
    return { winner: evidenceWinner.model, scores: [], reason: 'evidence' };
  }
  // 2) 指标加权
  const scores = candidates.map(c => {
    const m = c.metrics || { correct: 0, perf: 0 };
    return { model: c.model, score: m.correct * weights.correct + m.perf * weights.perf };
  }).sort((a, b) => b.score - a.score);
  const [top, second] = scores;
  // 3) 平局处理
  if (top.score - (second?.score ?? 0) < 0.05) {
    if (tieBreak === 'human') return { winner: null, scores, reason: 'tie' };
    const shortest = [...candidates].sort((a, b) => a.answer.length - b.answer.length)[0];
    return { winner: shortest.model, scores, reason: 'tie' };
  }
  return { winner: top.model, scores, reason: 'metrics' };
}

// 自测
const cands = [
  { model: 'A', answer: '用虚拟滚动', metrics: { correct: 0.7, perf: 0.9 } },
  { model: 'B', answer: '用分页', metrics: { correct: 0.9, perf: 0.6 } },
];
console.log(arbitrateDisagreement(cands, []).reason === 'metrics');
console.log(arbitrateDisagreement(cands, [{ test: 'B:边界用例', pass: true }]).winner === 'B');
const tie = [{ model: 'A', answer: 'x', metrics: { correct: 0.5, perf: 0.5 } },
             { model: 'B', answer: 'y', metrics: { correct: 0.5, perf: 0.5 } }];
console.log(arbitrateDisagreement(tie).winner === null); // 平局交人工
```

**评分点**：
- 证据优先于指标（test 含模型名前缀且 pass）
- 指标加权打分正确，缺失 metrics 记 0
- 平局阈值 0.05 与两种 tieBreak（human=null / 选更短答案）
- 边界：空候选、单候选直接胜出
- 能说清「裁决的本质是把主观自信之争转成客观数据之争，证据 > 指标 > 人工」属于加分
