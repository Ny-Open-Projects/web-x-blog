## AIC-609：笔试：手写迭代回滚决策器

**答**：实现 `decideRollback(rounds, opts)`。rounds: `{ changedFiles:string[], linesAdded:number, linesRemoved:number, testsPassed:boolean, errorSignature:string }[]`（每轮迭代记录）；opts: `{ maxRounds?:number, stagnationWindow?:number }`（默认 maxRounds=5, stagnationWindow=3）。规则按优先级：1) 连续 `stagnationWindow` 轮 errorSignature 相同 → 'stagnation'；2) 某轮 linesAdded > linesRemoved × 3 且 testsPassed=false → 'diverging'；3) 迭代轮数 ≥ maxRounds 仍未通过 → 'exhausted'；4) changedFiles 在最近两轮完全相同且 errorSignature 相同 → 'no-progress'；5) 否则 'continue'。返回 `{ action:'rollback'|'continue', reason, rollbackTo:number }`，rollbackTo 为建议回退到的轮次索引（0 表示初始状态）。边界：rounds 为空返回 continue/0。

```javascript
function decideRollback(rounds = [], opts = {}) {
  const { maxRounds = 5, stagnationWindow = 3 } = opts;
  if (rounds.length === 0) return { action: 'continue', reason: 'empty', rollbackTo: 0 };
  let reason = null;
  // 规则1：连续 N 轮同一错误签名
  if (rounds.length >= stagnationWindow) {
    const tail = rounds.slice(-stagnationWindow);
    if (tail.every(r => r.errorSignature === tail[0].errorSignature)) reason = 'stagnation';
  }
  // 规则2：某轮大量新增且测试失败（发散）
  if (!reason && rounds.some(r => r.linesAdded > r.linesRemoved * 3 && !r.testsPassed)) {
    reason = 'diverging';
  }
  // 规则4：最近两轮文件与错误都相同（原地打转）
  if (!reason && rounds.length >= 2) {
    const [a, b] = rounds.slice(-2);
    const sameFiles = a.changedFiles.join('|') === b.changedFiles.join('|');
    if (sameFiles && a.errorSignature === b.errorSignature) reason = 'no-progress';
  }
  // 规则3：轮数耗尽
  if (!reason && rounds.length >= maxRounds && !rounds[rounds.length - 1].testsPassed) {
    reason = 'exhausted';
  }
  if (!reason) return { action: 'continue', reason: 'ok', rollbackTo: rounds.length - 1 };
  // 回退到最近一次测试通过的轮次，没有则回到 0
  let rollbackTo = 0;
  for (let i = rounds.length - 1; i >= 0; i--) {
    if (rounds[i].testsPassed) { rollbackTo = i + 1; break; }
  }
  return { action: 'rollback', reason, rollbackTo };
}

// 自测
const rounds = [
  { changedFiles: ['a.ts'], linesAdded: 10, linesRemoved: 2, testsPassed: false, errorSignature: 'E1' },
  { changedFiles: ['a.ts'], linesAdded: 12, linesRemoved: 1, testsPassed: false, errorSignature: 'E1' },
  { changedFiles: ['a.ts'], linesAdded: 11, linesRemoved: 2, testsPassed: false, errorSignature: 'E1' },
];
console.log(decideRollback(rounds).reason === 'stagnation'); // 连续3轮同签名
console.log(decideRollback(rounds).action === 'rollback');
console.log(decideRollback([]).action === 'continue');
```

**评分点**：
- 五条规则优先级正确处理（stagnation > diverging > no-progress > exhausted > continue）
- 发散判定 linesAdded > linesRemoved×3 且 testsPassed=false
- rollbackTo 回退到最近测试通过轮次 +1，无则回到 0
- 边界：空 rounds、窗口不足 maxRounds 的判定
- 能说清「回滚决策本质是检测发散与停滞，AI 的自我评估不可信，必须用客观信号（测试/行数/签名）」属于加分
