## AIC-476：笔试：把规则注入/上下文组装/输出校验整合成迷你结对流水线。
**答**：三步：① selectRules(file) 选规则（always+glob）② assemble(rules, files, budget) 装上下文 ③ validate(out) 校验产出（含规则关键词断言）。整合为 `pairProgram(task, file)` 返回 `{ctx, out, ok}`。

```javascript
function selectRules(file, rules) {
  return rules.filter(r => r.always || r.globs.some(g =>
    new RegExp('^' + g.replace(/\*/g, '[^/]*') + '$').test(file)));
}
function assemble(items, budget) {
  const out = []; let used = 0;
  for (const i of items.sort((a, b) => b.priority - a.priority)) {
    if (used + i.tokens > budget) continue;
    out.push(i.name); used += i.tokens;
  }
  return out;
}
function validate(out, checks) {
  const failed = checks.filter(c => !c(out));
  return { ok: failed.length === 0, failed };
}
async function pairProgram(task, file, deps) {
  const rules = selectRules(file, deps.rules);
  const ctx = assemble([
    ...rules.map(r => ({ name: `rule:${r.name}`, tokens: r.tokens, priority: 5 })),
    { name: `file:${file}`, tokens: 800, priority: 3 },
  ], 4000);
  const out = await deps.model(task, ctx);
  const v = validate(out, deps.checks);
  return { ctx, out, ...v };
}

```

**评分点**：
- 三步职责边界清晰（选规则/装上下文/验产出互不越界）。
- 预算用满不超（assemble 截断逻辑）。
- validate 失败应返回可重试信息（而非只 false）。
- 整合层不重复实现子功能（调用而非复制）。
