## AIC-645：笔试：手写变异测试目标计算器

**答**：实现 `computeMutationGoal(modules, opts)`。modules: `{name:string, risk:'high'|'medium'|'low', lines:number, aiGenerated:boolean, weakAssertRate:number}[]`（weakAssertRate 0-1）；opts: `{ maxScore?:number, minScore?:number }`（默认 max=90, min=40）。规则：1) 基础目标：high=80, medium=65, low=50；2) AI 生成测试且 weakAssertRate>0.3 → +15（弱断言多，需要更高变异分数兜底）；3) 大模块（lines>500）→ −10（成本高，适当放宽）；4) clamp 到 [minScore, maxScore]；5) 返回 `{ goals:Array<{name,target,rationale:string[]}>, avgTarget:number }`，rationale 记录每步调整原因。边界：modules 空返回空 goals、avgTarget=0；lines/weakAssertRate 缺失按 0 处理。

```javascript
function computeMutationGoal(modules = [], opts = {}) {
  const { maxScore = 90, minScore = 40 } = opts;
  const goals = modules.map(m => {
    const { name, risk = 'low', lines = 0, aiGenerated = false, weakAssertRate = 0 } = m;
    let target = risk === 'high' ? 80 : risk === 'medium' ? 65 : 50;
    const rationale = [`基础:${risk}=${target}`];
    if (aiGenerated && weakAssertRate > 0.3) {
      target += 15; rationale.push('AI弱断言多+15');
    }
    if (lines > 500) { target -= 10; rationale.push('大模块成本-10'); }
    target = Math.min(maxScore, Math.max(minScore, target));
    if (target !== (risk === 'high' ? 80 : risk === 'medium' ? 65 : 50) + (aiGenerated && weakAssertRate > 0.3 ? 15 : 0) - (lines > 500 ? 10 : 0)) {
      rationale.push(`clamp到${target}`);
    }
    return { name, target, rationale };
  });
  const avgTarget = goals.length ? goals.reduce((s, g) => s + g.target, 0) / goals.length : 0;
  return { goals, avgTarget };
}

// 自测
const modules = [
  { name: 'checkout', risk: 'high', lines: 300, aiGenerated: true, weakAssertRate: 0.5 },
  { name: 'list', risk: 'low', lines: 800, aiGenerated: false, weakAssertRate: 0 },
];
const r = computeMutationGoal(modules);
console.log(r.goals[0].target === 90); // 80+15=95, clamp 90
console.log(r.goals[1].target === 40); // 50-10=40
console.log(r.goals[0].rationale.some(x => x.includes('弱断言')));
console.log(computeMutationGoal([]).avgTarget === 0);
```

**评分点**：
- 基础目标按 risk 正确映射（high=80/medium=65/low=50）
- AI 弱断言加成条件正确（aiGenerated 且 weakAssertRate>0.3）
- 大模块惩罚（lines>500 −10）与 clamp [min,max]
- rationale 记录调整原因，avgTarget 计算正确
- 能说清「AI 测试弱断言多，行覆盖率虚高，必须用更高变异分数兜底，但等价变异体使 100% 不可达」属于加分
