## AIC-726：多模型协作中结果融合有哪些策略各适用什么场景

**答**：
- 结论先行：融合策略分三类——拼接（各模型负责不同部分，合并成完整结果）、投票（多模型对同一问题投票取多数）、加权（按模型画像权重融合）；选择依据是「任务是分工还是共识」。
- 拼接：适合长任务分工（A 写骨架、B 补边界），要求输出有明确可拼的接口；投票：适合有客观答案的判断（对错、分类），但会抹平少数派的真知灼见；加权：适合各模型能力不等的场景。
- 风险：投票制下「 correlated error（相关错误）」会集体投错——模型同源或上下文相同时，多样性丧失，投票失去意义。
- 追问钩子：为什么分工型任务不该用投票？——各模型答案针对的是不同子问题，投票等于把苹果和橘子放一起数。

```javascript
// 三种融合策略
const fuse = {
  concat: parts => parts.join('\n'),                       // 拼接：各管一段
  vote: results => {                                        // 投票：取多数
    const count = {};
    results.forEach(r => count[r] = (count[r] ?? 0) + 1);
    return Object.entries(count).sort((a, b) => b[1] - a[1])[0]?.[0];
  },
  weighted: (pairs) => {                                    // 加权：按权重融合数值
    const [ws, vs] = pairs.reduce(([sw, sv], [w, v]) => [sw + w, sv + w * v], [0, 0]);
    return ws ? vs / ws : 0;
  },
};
console.log(fuse.concat(['骨架', '边界']));                // 骨架
边界
console.log(fuse.vote(['A', 'A', 'B']));                   // A
console.log(fuse.weighted([[0.7, 0.9], [0.3, 0.4]]));     // 0.75
```
