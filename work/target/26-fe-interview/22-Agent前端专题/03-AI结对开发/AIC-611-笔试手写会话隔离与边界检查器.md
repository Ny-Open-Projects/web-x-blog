## AIC-611：笔试：手写会话隔离与边界检查器

**答**：实现 `checkSessionBoundaries(sessions, edits)`。sessions: `{id:string, owner:string, allowedFiles:string[], worktree:string}[]`；edits: `{sessionId:string, file:string, worktree:string}[]`。规则：1) 越权文件：edit.file 不在对应 session.allowedFiles → 'out-of-scope'；2) 跨 worktree：edit.worktree 与 session.worktree 不符 → 'worktree-mismatch'；3) 未知会话：sessionId 不存在 → 'unknown-session'；4) 文件冲突：两个不同 session 在同一次提交中编辑同一 file（即使用不同 worktree，合并时也会冲突）→ 'cross-session-conflict'（标记到相关 edits）。返回 `{ violations: Array<{ editIndex, type, detail }>, safe:boolean }`。边界：edits 为空安全；同一 session 多次编辑同一文件不算冲突。

```javascript
function checkSessionBoundaries(sessions = [], edits = []) {
  const byId = new Map(sessions.map(s => [s.id, s]));
  const violations = [];
  const fileToSessions = new Map();
  edits.forEach((e, i) => {
    const s = byId.get(e.sessionId);
    if (!s) {
      violations.push({ editIndex: i, type: 'unknown-session', detail: e.sessionId });
      return;
    }
    if (!s.allowedFiles.includes(e.file)) {
      violations.push({ editIndex: i, type: 'out-of-scope', detail: `${e.sessionId}:${e.file}` });
    }
    if (e.worktree !== s.worktree) {
      violations.push({ editIndex: i, type: 'worktree-mismatch', detail: `${e.worktree}!=${s.worktree}` });
    }
    if (!fileToSessions.has(e.file)) fileToSessions.set(e.file, new Set());
    fileToSessions.get(e.file).add(e.sessionId);
  });
  // 跨会话文件冲突
  for (const [file, owners] of fileToSessions) {
    if (owners.size > 1) {
      edits.forEach((e, i) => {
        if (e.file === file) {
          violations.push({ editIndex: i, type: 'cross-session-conflict', detail: file });
        }
      });
    }
  }
  return { violations, safe: violations.length === 0 };
}

// 自测
const sessions = [
  { id: 's1', owner: 'alice', allowedFiles: ['a.ts'], worktree: 'wt-alice' },
  { id: 's2', owner: 'bob', allowedFiles: ['b.ts'], worktree: 'wt-bob' },
];
const edits = [
  { sessionId: 's1', file: 'a.ts', worktree: 'wt-alice' }, // ok
  { sessionId: 's1', file: 'c.ts', worktree: 'wt-alice' }, // out-of-scope
  { sessionId: 's2', file: 'a.ts', worktree: 'wt-bob' },   // out-of-scope + cross-conflict
  { sessionId: 's1', file: 'a.ts', worktree: 'wt-bob' },   // worktree-mismatch
];
const r = checkSessionBoundaries(sessions, edits);
console.log(r.violations.some(v => v.type === 'out-of-scope'));
console.log(r.violations.some(v => v.type === 'worktree-mismatch'));
console.log(r.violations.some(v => v.type === 'cross-session-conflict'));
console.log(checkSessionBoundaries(sessions, []).safe === true);
```

**评分点**：
- 三类基础违规（out-of-scope / worktree-mismatch / unknown-session）判定准确
- 跨会话文件冲突检测（同一 file 被不同 session 编辑），即便 worktree 不同
- 同一 session 多次编辑同一文件不误判为冲突
- 返回结构含 editIndex 与 detail，safe 与 violations 一致
- 能说清「会话隔离的三层：上下文隔离、文件锁、worktree 物理隔离，缺一不可」属于加分
