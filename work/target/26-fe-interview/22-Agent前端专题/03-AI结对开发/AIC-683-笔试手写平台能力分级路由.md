## AIC-683：笔试：手写平台能力分级路由

**答**：实现 `routeCapability(request, caps)`。request: `{ capability:'complete'|'review'|'test-gen'|'agent', sensitivity:'L1'|'L2'|'L3', tokens:number, tenant:string }`；caps: `{ name:string, capabilities:string[], maxSensitivity:'L1'|'L2'|'L3', maxTokens:number, costPerK:number, healthy:boolean }[]`（能力/隐私等级/容量/成本/健康度）。规则（按优先级）：1) 过滤：capability 支持、maxSensitivity ≥ request.sensitivity（L3>L2>L1）、maxTokens ≥ tokens、healthy；2) 无候选 → 抛出 'no-capable-provider'（或返回 error）；3) 选 costPerK 最低者（成本优先）；4) 隐私 L3 强制选 maxSensitivity='L3'（即使有更便宜的 L2 也不选）；5) 返回 `{ provider:string|null, cost:number, reason:string }`。边界：caps 空返回 provider=null。

```javascript
function routeCapability(request = {}, caps = []) {
  const level = { L1: 1, L2: 2, L3: 3 };
  const { capability, sensitivity = 'L1', tokens = 0 } = request;
  if (!caps.length) return { provider: null, cost: 0, reason: 'no-caps' };
  const candidates = caps.filter(c =>
    c.capabilities.includes(capability)
    && level[c.maxSensitivity] >= level[sensitivity]
    && c.maxTokens >= tokens
    && c.healthy
  );
  if (!candidates.length) return { provider: null, cost: 0, reason: 'no-capable-provider' };
  // L3 强制最高隐私等级，不因便宜降级
  const pool = sensitivity === 'L3'
    ? candidates.filter(c => c.maxSensitivity === 'L3')
    : candidates;
  if (!pool.length) return { provider: null, cost: 0, reason: 'no-L3-provider' };
  pool.sort((a, b) => a.costPerK - b.costPerK);
  const chosen = pool[0];
  return { provider: chosen.name, cost: chosen.costPerK * tokens / 1000, reason: 'cost-optimized' };
}

// 自测
const caps = [
  { name: 'cheap-cloud', capabilities: ['complete', 'review'], maxSensitivity: 'L2', maxTokens: 8000, costPerK: 1, healthy: true },
  { name: 'local-secure', capabilities: ['complete', 'review'], maxSensitivity: 'L3', maxTokens: 4000, costPerK: 5, healthy: true },
];
console.log(routeCapability({ capability: 'complete', sensitivity: 'L1', tokens: 1000 }, caps).provider === 'cheap-cloud');
console.log(routeCapability({ capability: 'complete', sensitivity: 'L3', tokens: 1000 }, caps).provider === 'local-secure'); // L3 强制本地
console.log(routeCapability({ capability: 'test-gen', sensitivity: 'L1', tokens: 1000 }, caps).reason === 'no-capable-provider');
console.log(routeCapability({}, []).provider === null);
```

**评分点**：
- 多维过滤（能力/隐私等级/容量/健康度）正确
- 隐私等级比较用 L1<L2<L3 有序映射
- L3 强制选 L3 provider，不被更便宜的 L2 诱导（安全不降级）
- 成本最优选择 + 无候选的各种 reason
- 能说清「平台路由的优先级：安全 > 可用性 > 成本，绝不为了省钱违反隐私约束」属于加分
