## AIC-942：AI 结对长会话几十轮后上下文臃肿，如何用「滚动摘要」压缩历史而不丢关键决策？
**答**：
- 滚动摘要 = 每积累 N 轮，把更早的对话压缩成一段结构化摘要（做了什么决策、改了哪些文件、踩了什么坑），用摘要替代原始历史，只保留最近几轮原文。
- 摘要必须「结构化且可追溯」：记录决策点、变更文件、未解决问题，并附原始轮次引用，需要细节时能回溯——结论：摘要是有损压缩，引用保住可回溯性。
- 风险是「摘要漂移」：多轮摘要层层压缩会累积失真（传话游戏），要定期用原始关键信息「校准」摘要，关键决策（如安全约束）永不压缩、原样保留。
- 追问钩子：能指出「摘要要区分事实与推断、关键约束单独留存；压缩率与失真率要权衡」的候选人理解信息压缩的本质代价。

```typescript
// 滚动摘要：结构化压缩历史 + 关键项永不压缩
function rollingSummary(rounds, keepRecent = 3) {
  const recent = rounds.slice(-keepRecent);
  const older = rounds.slice(0, -keepRecent);
  const pinned = older.filter(r => r.pinned); // 关键决策永不压缩
  const compressed = older.filter(r => !r.pinned);
  const summary = {
    decisions: compressed.filter(r=>r.type==='decision').map(r=>r.id),
    files: [...new Set(compressed.flatMap(r=>r.files||[]))],
    range: [compressed[0]?.id, compressed[compressed.length-1]?.id],
  };
  return { pinned, summary, recent };
}
const rounds = [
  {id:1,type:'decision',files:['a.ts'],pinned:true},
  {id:2,type:'chat',files:[]}, {id:3,type:'code',files:['b.ts']},
  {id:4,type:'code',files:['c.ts']},
];
console.log(rollingSummary(rounds));
```
