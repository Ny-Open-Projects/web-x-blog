## AIC-761：团队效能度量中如何保证数据的可信度

**答**：
- 结论先行：效能指标一旦用于考核就会被「优化」，因此数据可信度机制要先于指标本身——埋点口径统一、口径版本化、异常可追溯，否则一切度量都是空中楼阁。
- 三个保障：1) 口径单一来源（同一指标只在一处定义，避免各端算法不一致）；2) 采集链路可追溯（原始事件留存，支持重算）；3) 异常检测（突增/突降先质疑数据故障，再归因业务变化）。
- 反模式：为拿好看数字改埋点、用抽样冒充全量、口径悄悄变更导致趋势断裂。
- 追问钩子：为什么口径变更必须版本化？——否则历史趋势与当前口径不可比，会出现「指标突然变好」的假象。

```javascript
// 数据可信度：口径版本化 + 异常检测
function metricSeries(events, definition, version) {
  const daily = {};
  for (const e of events) {
    const day = e.ts.slice(0, 10);
    daily[day] = (daily[day] ?? 0) + (definition.countIf(e) ? 1 : 0);
  }
  const days = Object.values(daily);
  const suspicious = days.some((v, i) => i > 0 && Math.abs(v - days[i - 1]) / (days[i - 1] || 1) > 0.8);
  return { version, daily, suspicious };
}
console.log(metricSeries(
  [{ ts: '2026-11-01T10:00', ok: true }, { ts: '2026-11-02T10:00', ok: true }, { ts: '2026-11-03T10:00', ok: true }],
  { countIf: e => e.ok }, 'v2'
).suspicious); // false
```
