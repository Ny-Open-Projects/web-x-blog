## AIC-789：笔试：实现 AI 工具链的语义版本兼容性检查器

**需求**：实现 `checkCompat(current, required, opts)`。两个版本字符串格式为 `major.minor.patch`（可带 prerelease `-alpha`）。规则：1) 解析出 major/minor/patch 与 prerelease；2) 若 major 不同 → `{ compatible:false, reason:'major-mismatch' }`；3) 若 current < required（按数值比较 major.minor.patch）→ reason 'older'；4) 若 required 带 prerelease 而 current 是 stable → 允许（stable 更可靠）；若 current 带 prerelease 而 required 是 stable → reason 'prerelease-below-stable'；5) 否则 compatible。opts.allowMajor（默认 false，true 时忽略 major 差异）。边界：格式非法（无法解析出數字）→ reason 'invalid'。

**答**：
- 结论先行：SemVer 检查要先做合法性校验，再按「主版本 → 数值大小 → 预发布状态」顺序判断；预发布版本（alpha/beta）稳定性低于正式版，方向不能错。
- 非法输入必须显式判 invalid，不能静默当作 0.0.0——否则会把错误配置误判为兼容。
- 追问钩子：为什么「stable 能满足 prerelease 要求」但反之不行？——正式版经过验证，比预发布版更可靠；用稳定版满足一个测试版要求是合理的。

```javascript
function checkCompat(current = '', required = '', opts = {}) {
  const parse = v => {
    const m = /^(\d+)\.(\d+)\.(\d+)(?:-([\w.]+))?$/.exec(String(v).trim());
    if (!m) return null;
    return { major: +m[1], minor: +m[2], patch: +m[3], pre: m[4] ?? null };
  };
  const c = parse(current), r = parse(required);
  if (!c || !r) return { compatible: false, reason: 'invalid' };
  if (!opts.allowMajor && c.major !== r.major) return { compatible: false, reason: 'major-mismatch' };
  const cmp = (a, b) => a.major - b.major || a.minor - b.minor || a.patch - b.patch;
  if (cmp(c, r) < 0) return { compatible: false, reason: 'older' };
  if (c.pre && !r.pre) return { compatible: false, reason: 'prerelease-below-stable' };
  return { compatible: true };
}
console.log(checkCompat('3.2.0', '3.1.0').compatible);        // true
console.log(checkCompat('4.0.0', '3.1.0').reason);            // major-mismatch
console.log(checkCompat('3.1.0-alpha', '3.1.0').reason);      // prerelease-below-stable
console.log(checkCompat('bad', '3.1.0').reason);              // invalid
console.log(checkCompat('4.0.0', '3.1.0', { allowMajor: true }).compatible); // true
```


**评分点**：
- 合法性校验（格式非法判 invalid）
- major 差异判定与数值大小比较
- 预发布方向（stable 满足 prerelease，反之不行）
- allowMajor 选项与边界处理
