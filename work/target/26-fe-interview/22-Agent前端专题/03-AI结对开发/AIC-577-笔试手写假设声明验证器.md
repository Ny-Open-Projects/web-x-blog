## AIC-577：笔试：手写假设声明验证

**答**：实现 `validateAssumptions(code, assumptions)`。code: AI 生成的代码；assumptions: `AIAssumption[]`（RBL-576 格式）。规则：1) **假设的实现验证**：每个 assumption 的关键词在 code 中存在（如 "LRU" → code 包含 'lru' 或 'LRU'）；2) **假设注释存在**：code 中有 `// ASSUMPTION:` 标记（假设的文档化 RBL-576）；3) 未声明的假设：code 中有实现但 assumptions 未覆盖（AI 做了假设但没声明——静默假设检测）；4) 返回 `{ verified: Array<{ assumption, verified }>, undeclared: string[], ok }`（ok = 全 verified 且无 undeclared）。边界：assumptions 空（跳过验证——但检查 undeclared）；code 空（全 false）；assumptions 与 code 完全匹配（全 verified）。

```javascript
function validateAssumptions(code = '', assumptions = []) {
  const codeLower = code.toLowerCase();
  const verified = assumptions.map(a => ({
    assumption: a.assumption,
    verified: codeLower.includes(a.assumption.toLowerCase().split(' ')[0]) ||
              codeLower.includes(a.assumption.toLowerCase()),
  }));
  const hasDeclaration = /\/\/\s*ASSUMPTION:/i.test(code);
  // 未声明的假设检测（简化：检查 code 中的 ASSUMPTION 标记是否覆盖所有声明的假设）
  const declaredInCode = [...code.matchAll(/\/\/\s*ASSUMPTION:\s*(.+)/g)].map(m => m[1].trim());
  const undeclared = assumptions
    .filter(a => !declaredInCode.some(d => d.toLowerCase().includes(a.assumption.toLowerCase().split(' ')[0])))
    .map(a => a.assumption);
  const ok = verified.every(v => v.verified) && undeclared.length === 0 && hasDeclaration;
  return { verified, undeclared, ok };
}

// 自测
const assumptions = [
  { assumption: 'LRU eviction policy', alternative: 'LFU', impact: 'hit rate' },
  { assumption: '100 entries max', alternative: 'unlimited', impact: 'memory' },
];
// 代码包含假设 + 注释声明
const goodCode = `// ASSUMPTION: LRU eviction policy
// ASSUMPTION: 100 entries max
class LRUCache {
  constructor(private max = 100) {}
}`;
let r = validateAssumptions(goodCode, assumptions);
console.log(r.verified.every(v => v.verified) === true);
console.log(r.ok === true);

// 缺少声明注释
const noDeclCode = `class LRUCache { constructor(private max = 100) {} }`;
r = validateAssumptions(noDeclCode, assumptions);
console.log(r.undeclared.length > 0);                    // 假设未声明
console.log(r.ok === false);

// 假设不匹配
r = validateAssumptions('class FIFOCache {}', assumptions);
console.log(r.verified.some(v => v.verified === false)); // LRU 不在 FIFOCache 中
console.log(r.ok === false);

// 空 assumptions
r = validateAssumptions('const x = 1;', []);
console.log(r.verified.length === 0);                    // 跳过验证
```

**评分点**：
- 双维验证：假设实现（关键词在 code 中）+ 假设声明（ASSUMPTION 注释存在）
- undeclared 检测（AI 做了假设但没声明——静默假设的反模式检测 RBL-956）
- 边界（空 assumptions/空 code/全匹配）；ok = verified 全通过 + 无 undeclared + 有声明
- 能说清「假设声明验证 = AI 的假设是否落实到代码且文档化——静默假设是意图漂移的源头（RBL-538）」属于加分
