## AIC-947：笔试：实现「上下文去重与片段索引器」（识别重复/高度相似的上下文片段并建立索引）
**答**：
- 核心需求：实现 `indexContexts(fragments)`。`fragments: { id, text, source }[]`。返回 `{ unique, duplicates, index }`：duplicates 为 `{ id, of }[]`（重复片段指向首次出现的 id）。
- 去重分两层：① 完全相同（text 规范化后哈希相等）；② 高度相似（用 Jaccard 相似度 = 词集交集/并集 ≥ opts.threshold 默认 0.9）。规范化 = 去空白、统一换行、转小写。
- index 为 Map-like 对象 `{ [hash]: string[] }`，键为规范化文本的哈希，值为片段 id 数组，便于 O(1) 查找同内容片段。
- 边界：空数组返回空结果；threshold 裁剪到 [0,1]；空文本片段归为同一重复组；source 相同不参与去重（只按 text）。
- 语义：这是「降本 + 降噪」工具——重复上下文既浪费 token 又干扰模型；去重后只喂唯一片段，但保留 duplicates 映射供追溯。
- 追问钩子：能指出「Jaccard 对短文本不稳定、可加长度门槛；语义相似（embedding）比词集更准但更贵」的候选人理解去重的精度-成本权衡。

```typescript
function normalize(t){ return String(t??'').replace(/\s+/g,' ').trim().toLowerCase(); }
function hash(s){ let h=0; for(const c of s)h=(Math.imul(h,31)+c.charCodeAt(0))>>>0; return h; }
function jaccard(a,b){ const A=new Set(a.split(' ')),B=new Set(b.split(' '));
  const inter=[...A].filter(x=>B.has(x)).length, uni=new Set([...A,...B]).size||1;
  return inter/uni; }
function indexContexts(fragments=[], opts={}) {
  const threshold=Math.max(0,Math.min(1,opts.threshold??0.9));
  const index={}, unique=[], duplicates=[];
  const reps=[]; // {id, text}
  for(const f of fragments){
    const t=normalize(f.text), h=hash(t);
    (index[h] ??= []).push(f.id);
    const similar=reps.find(r=>r.hash===h || (r.text && t && jaccard(r.text,t)>=threshold));
    if(similar) duplicates.push({id:f.id,of:similar.id});
    else { unique.push(f); reps.push({id:f.id,hash:h,text:t}); }
  }
  return { unique, duplicates, index };
}
console.log(indexContexts([{id:1,text:'const a = 1'},{id:2,text:'const a=1;'}]).duplicates);
```
**评分点**：
- 规范化（空白/换行/小写）后哈希去重完全相同片段，建 index 映射。
- Jaccard 相似度阈值判定高度相似，threshold 裁剪 [0,1]。
- duplicates 指向首次出现的 id，保留追溯关系。
- 空数组、空文本、source 不参与去重等边界处理正确。
- 能说明 Jaccard 短文本不稳定、语义去重更准更贵（加分项）。
