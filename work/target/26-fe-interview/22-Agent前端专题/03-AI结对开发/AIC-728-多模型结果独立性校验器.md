## AIC-728：笔试：实现多模型结果的独立性校验器

**需求**：实现 `checkIndependence(results, opts)`。`results`: `Array<{ model, claim, source? }>`；`opts.minSources`（默认 2）。规则：1) 按 `claim` 分组；2) 一个 claim 被认定为「可靠共识」需满足：不同 `model` 数 ≥ minSources **且** 至少有两个不同 `source`（source 缺失不计入多样性）；3) 若同 claim 的所有结果来自同一 model 或同一 source，标记为 `correlated`；4) 返回 `{ reliable, correlated, lone }`（lone=只出现一次的 claim）。边界：results 空（三组均空）；source 全缺失的 claim 即使多模型也算 correlated；claim 大小写敏感。

**答**：
- 结论先行：独立性 = 「模型多样 × 来源多样」双条件；只看模型数会被同源自欺骗蒙混，必须同时校验 source 的多样性。
- 同 claim 只有单一来源时，即便多个模型引用，也判为相关（高度疑似幻觉互相印证）。
- 追问钩子：为什么 lones（孤证）要单列？——孤证既不能证真也不能证伪，但可能是少数派真知，需人工关注而非直接丢弃。

```javascript
function checkIndependence(results = [], opts = {}) {
  const minSources = opts.minSources ?? 2;
  const groups = {};
  for (const r of results) (groups[r.claim] ??= []).push(r);
  const reliable = [], correlated = [], lone = [];
  for (const [claim, list] of Object.entries(groups)) {
    if (list.length === 1) { lone.push(claim); continue; }
    const models = new Set(list.map(r => r.model));
    const sources = new Set(list.filter(r => r.source).map(r => r.source));
    if (models.size >= minSources && sources.size >= minSources) reliable.push(claim);
    else correlated.push(claim);
  }
  return { reliable, correlated, lone };
}
const r = checkIndependence([
  { model: 'A', claim: 'X 已弃用', source: 'changelog' },
  { model: 'B', claim: 'X 已弃用', source: 'gh-issue' },   // 模型+来源都独立 → reliable
  { model: 'A', claim: 'Y 慢', source: null },
  { model: 'B', claim: 'Y 慢', source: null },             // 无来源 → correlated
  { model: 'A', claim: 'Z' },                              // 孤证
]);
console.log(r.reliable);    // ['X 已弃用']
console.log(r.correlated);  // ['Y 慢']
console.log(r.lone);        // ['Z']
```


**评分点**：
- 按 claim 分组、lone 单列
- 双条件判定（模型数 与 来源数 均达 minSources）
- 无来源判 correlated（防幻觉互相印证）
- 能解释「一致性须建立在独立来源之上」属加分
