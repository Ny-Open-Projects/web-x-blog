## AIC-777：笔试：实现带对照组的效能实验分析器

**需求**：实现 `analyzeExperiment(control, treatment, opts)`。`control`/`treatment`: `Array<{ metric, guardrail }>`（主指标与质量护栏）；`opts.minLift`（默认 0.05）。规则：1) 分别计算两组主指标均值 `meanC`、`meanT`；2) `lift = (meanT - meanC) / meanC`（meanC=0 时 lift=0）；3) 若任一组的 guardrail 均值低于 `opts.guardFloor`（默认 0.8），标记 `guardrailBreached: true`，结论 `inconclusive`；4) 否则 `lift >= minLift` 结论 `positive`，`lift <= -minLift` 结论 `negative`，其余 `neutral`；5) 返回 `{ meanC, meanT, lift, guardrailBreached, verdict }`。边界：组为空（对应均值=0，lift=0）；guardrail 缺字段按 0（触发 breach）。

**答**：
- 结论先行：实验结论要先看护栏（质量是否被损害），再提升幅；护栏破了即使主指标涨也应判「不确定/有害」，不能以质量换效率。
- lift 的分母用对照组均值，代表「相对基线的提升」；除零要保护。
- 追问钩子：为什么 guardrail 一票否决？——主指标提升可能来自牺牲质量（如跳过测试），这种「提升」是假象，长期有害。

```javascript
function analyzeExperiment(control = [], treatment = [], opts = {}) {
  const minLift = opts.minLift ?? 0.05;
  const guardFloor = opts.guardFloor ?? 0.8;
  const mean = (arr, k) => arr.length ? arr.reduce((s, x) => s + (x[k] ?? 0), 0) / arr.length : 0;
  const meanC = mean(control, 'metric'), meanT = mean(treatment, 'metric');
  const lift = meanC ? (meanT - meanC) / meanC : 0;
  const guardrailBreached = mean(control, 'guardrail') < guardFloor || mean(treatment, 'guardrail') < guardFloor;
  const verdict = guardrailBreached ? 'inconclusive'
    : lift >= minLift ? 'positive' : lift <= -minLift ? 'negative' : 'neutral';
  return { meanC, meanT, lift: +lift.toFixed(3), guardrailBreached, verdict };
}
console.log(analyzeExperiment(
  [{ metric: 10, guardrail: 0.9 }, { metric: 12, guardrail: 0.9 }],
  [{ metric: 14, guardrail: 0.85 }, { metric: 15, guardrail: 0.85 }]
).verdict); // positive
console.log(analyzeExperiment([{ metric: 10, guardrail: 0.9 }], [{ metric: 15, guardrail: 0.5 }]).verdict);
// inconclusive —— 质量护栏被破
console.log(analyzeExperiment([], []).verdict); // neutral（边界）
```


**评分点**：
- 两组均值与 lift 计算（分母为对照组、除零保护）
- guardrail 一票否决 → inconclusive
- positive/negative/neutral 阈值判定
- 边界（空组）处理
