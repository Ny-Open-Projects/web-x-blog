## AIC-889：笔试：实现任务复杂度评估与人机分配器
**答**：
- 核心需求：实现 `assignTasks(tasks)`。任务字段 `{ id, exploratory:0-1, risk:0-1, files:number, hasTests:boolean, dataSensitivity:boolean }`。先算复杂度 `complexity = 0.3*exploratory + 0.3*risk + 0.2*min(files/20,1) + 0.2*(hasTests?0:1)`；再分配：`risk>=0.7 || dataSensitivity → human-only`；`complexity>=0.6 → human-lead`（AI 辅助）；`complexity<0.3 && hasTests → ai-lead`；其余 `pair`。
- 边界：字段缺失按默认值（0 / false）；分值裁剪到 [0,1]；未知 risk 级别不崩溃；输出含 rationale（为什么这么分）便于人复核。
- 语义：即使是 ai-lead，责任归属仍是人（AIC-882）；分配只是建议，人可覆盖——输出要标注 `advisory:true`。
- 追问钩子：追问「算法分配会不会不信任人」——能答出「这是建议不是命令，要给理由让人复核，且高风险永远人工兜底」的候选人理解人机协作的边界。

```typescript
type Task = { id: string; exploratory?: number; risk?: number; files?: number;
  hasTests?: boolean; dataSensitivity?: boolean };
const clamp = (v: number) => Math.max(0, Math.min(1, Number.isFinite(v) ? v : 0));

function assignTasks(tasks: Task[]) {
  return (tasks ?? []).map(t => {
    const exp = clamp(t.exploratory ?? 0), risk = clamp(t.risk ?? 0);
    const files = clamp((t.files ?? 0) / 20), noTests = t.hasTests ? 0 : 1;
    const complexity = +(0.3*exp + 0.3*risk + 0.2*files + 0.2*noTests).toFixed(3);
    let decision: string, rationale: string;
    if (risk >= 0.7 || t.dataSensitivity) {
      decision = 'human-only'; rationale = '高风险/敏感数据，AI 不得主导';
    } else if (complexity >= 0.6) {
      decision = 'human-lead'; rationale = '复杂度高，人主导 AI 辅助';
    } else if (complexity < 0.3 && t.hasTests) {
      decision = 'ai-lead'; rationale = '低复杂度且有测试，AI 主导';
    } else {
      decision = 'pair'; rationale = '中等复杂度，人机结对';
    }
    return { id:t.id, complexity, decision, rationale, advisory:true, accountable:'human' };
  });
}
console.log(assignTasks([
  { id:'pay', risk:0.9, exploratory:0.2, files:3, hasTests:true },
  { id:'list', risk:0.1, exploratory:0.1, files:2, hasTests:true },
])); // pay:human-only, list:ai-lead
```
**评分点**：
- 复杂度加权公式按字段计算，clamp 处理缺失/越界值。
- 分配优先级：高风险/敏感数据 > 高复杂度 > 低复杂度有测试 > 结对，顺序正确。
- 输出 rationale 与 advisory/accountable，体现「建议非命令、责任归人」。
- 空输入、字段缺失不崩溃，分值裁剪 [0,1]。
- 能讨论算法分配的信任边界是加分项。
