## AIC-626：笔试：手写多模型接力流水线编排器

**答**：实现 `orchestrateRelay(task, stages, opts)`。stages: `{ name:string, model:string, timeoutMs:number, validate:(out:any)=>boolean }[]`；opts: `{ maxRetries?:number, onStageFail?:'abort'|'skip-optional' }`（默认 maxRetries=2, onStageFail='abort'）。规则：1) 顺序执行每个 stage，把上一阶段输出作为下一阶段输入；2) 阶段 validate 失败时重试最多 maxRetries 次，仍失败按 onStageFail 处理：abort 抛错，skip-optional 跳过（仅当 stage.optional=true，否则仍 abort）；3) 单阶段超时（用 mock 的 run 函数配合 timeoutMs 模拟）记失败；4) 返回 `{ output, trace:Array<{stage,status,attempts}>, success }`。边界：stages 空返回原 task；任意阶段 abort 时返回已完成 trace。

```javascript
function orchestrateRelay(task, stages = [], opts = {}) {
  const { maxRetries = 2, onStageFail = 'abort' } = opts;
  let output = task;
  const trace = [];
  for (const stage of stages) {
    let attempts = 0;
    let ok = false;
    while (attempts <= maxRetries && !ok) {
      attempts++;
      // 真实场景 await callModel(stage.model, output)；此处用注入的 run
      const out = (stage.run ? stage.run(output) : output);
      ok = stage.validate ? stage.validate(out) : true;
      if (ok) output = out;
    }
    if (!ok) {
      trace.push({ stage: stage.name, status: 'failed', attempts });
      const canSkip = onStageFail === 'skip-optional' && stage.optional;
      if (!canSkip) return { output, trace, success: false };
      trace.push({ stage: stage.name, status: 'skipped', attempts });
      continue;
    }
    trace.push({ stage: stage.name, status: 'ok', attempts });
  }
  return { output, trace, success: true };
}

// 自测
const stages = [
  { name: 'plan', model: 'strong', validate: o => o.includes('plan'), run: o => `${o}-plan` },
  { name: 'code', model: 'fast', validate: o => o.includes('code'), run: o => `${o}-code` },
  { name: 'review', model: 'strict', optional: true, validate: () => false, run: o => o },
];
let r = orchestrateRelay('task', stages.slice(0, 2));
console.log(r.success && r.output === 'task-plan-code');
console.log(r.trace.every(t => t.status === 'ok' && t.attempts === 1));
r = orchestrateRelay('task', stages, { onStageFail: 'skip-optional' });
console.log(r.success && r.trace.some(t => t.status === 'skipped'));
r = orchestrateRelay('task', stages); // 默认 abort
console.log(r.success === false);
console.log(orchestrateRelay('task', []).output === 'task');
```

**评分点**：
- 顺序执行且前阶段输出作为后阶段输入
- validate 失败重试 maxRetries 次，attempts 记录准确
- onStageFail 两种模式：abort 终止 / skip-optional 仅跳过 optional 阶段
- 边界：空 stages 返回原 task、abort 时保留已完成 trace
- 能说清「接力编排的工程要点是阶段间结构化传递 + 每阶段独立验收，失败不硬往下传」属于加分
