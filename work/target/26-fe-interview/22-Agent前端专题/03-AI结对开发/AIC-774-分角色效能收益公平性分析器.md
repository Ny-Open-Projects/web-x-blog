## AIC-774：笔试：实现分角色效能收益的公平性分析器

**需求**：实现 `fairness(records, opts)`。`records`: `Array<{ role, hoursSaved, reviewHours, quality }>`；`opts.gapThreshold`（默认 0.3）。规则：1) 按 role 聚合：`net = Σ(hoursSaved - reviewHours)`、`avgQuality = Σquality/n`；2) 计算所有角色 `net` 的极差比 `(max-min)/max`（max>0）；3) 若极差比 > gapThreshold 标记 `unfair: true`，并列出 `laggards`（net 低于均值*(1-gapThreshold) 的角色）；4) 返回 `{ byRole, spread, unfair, laggards }`。边界：records 空（全空/0/false）；max<=0 时 spread=0；缺字段按 0。

**答**：
- 结论先行：公平性用「极差比」衡量相对差距（而非绝对差），因为不同角色基规模不同；laggards 明确指出哪些角色需要额外支持。
- 用 net（净收益 = 节省 - 审查成本）而非毛节省，才能真实反映 senior 的隐形负担。
- 追问钩子：为什么不用绝对差值判断不公平？——绝对差受团队规模影响大；极差比是相对指标，更公平可比。

```javascript
function fairness(records = [], opts = {}) {
  const gapThreshold = opts.gapThreshold ?? 0.3;
  const byRole = {};
  for (const r of records) {
    const o = (byRole[r.role ?? 'unknown'] ??= { net: 0, qSum: 0, n: 0 });
    o.net += (r.hoursSaved ?? 0) - (r.reviewHours ?? 0);
    o.qSum += r.quality ?? 0;
    o.n++;
  }
  const rows = Object.entries(byRole).map(([role, o]) => ({
    role, net: +o.net.toFixed(2), avgQuality: o.n ? +(o.qSum / o.n).toFixed(2) : 0,
  }));
  const nets = rows.map(r => r.net);
  const max = Math.max(0, ...nets), min = Math.min(0, ...nets);
  const spread = max > 0 ? +((max - min) / max).toFixed(2) : 0;
  const mean = nets.length ? nets.reduce((a, b) => a + b, 0) / nets.length : 0;
  const laggards = rows.filter(r => r.net < mean * (1 - gapThreshold)).map(r => r.role);
  return { byRole: rows, spread, unfair: spread > gapThreshold, laggards };
}
const r = fairness([
  { role: 'junior', hoursSaved: 20, reviewHours: 2, quality: 0.8 },
  { role: 'senior', hoursSaved: 4, reviewHours: 12, quality: 0.9 },
]);
console.log(r.unfair === true && r.laggards.includes('senior'));
console.log(fairness([]).spread === 0); // 边界
```


**评分点**：
- 按角色聚合 net（节省 - 审查成本）
- 极差比衡量相对差距（非绝对差）
- laggards 判定与 max<=0 边界
- 能说明「净收益反映 senior 隐形负担」属加分
