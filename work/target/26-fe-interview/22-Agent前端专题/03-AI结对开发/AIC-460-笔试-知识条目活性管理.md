## AIC-460：笔试：实现知识条目的引用统计与过期清理。
**答**：条目 `{id, refs, updatedAt}`。`prune(entries, now, {halfLifeDays=90})`：refs=0 且 updatedAt 距今 > halfLife → 归档；refs>0 的保留并按 refs 降序输出 top。

```javascript
function prune(entries, now, { halfLifeDays = 90 } = {}) {
  const LIMIT = halfLifeDays * 86400_000;
  const keep = [], archived = [], stale = [];
  for (const e of entries) {
    const age = now - e.updatedAt;
    if (e.refs === 0 && age >= LIMIT) archived.push(e.id);
    else if (age >= LIMIT) { stale.push(e.id); keep.push(e); }
    else keep.push(e);
  }
  const top = keep.slice().sort((a, b) => b.refs - a.refs).slice(0, 3)
    .map(e => ({ id: e.id, refs: e.refs }));
  return { top, stale, archived };
}
const DAY = 86400_000;
console.log(prune([
  { id: 'a', refs: 5, updatedAt: 0 },
  { id: 'b', refs: 0, updatedAt: 0 },
  { id: 'c', refs: 2, updatedAt: 80 * DAY },
], 100 * DAY)); // top [a,c]；archived [b]

```

**评分点**：
- 双条件（零引用 + 过期）才归档——有引用但过期只标记 stale。
- 时间计算用天数差，边界（恰好 90 天）算过期。
- 归档不删除（保留 id 供恢复）。
- top 输出带 refs 数。
