## AIC-812：各家模型 token 计费口径不一致，平台如何统一成本视图？
**答**：
- 差异来源：输入/输出单价不同、是否有缓存折扣、是否按字符/token 计费、是否有最低消费、工具调用是否单独计费、batch 是否半价。直接拿「token 数 × 单价」会严重失真。
- 统一做法：建立**计费规则表**（按模型 + 时间生效的价格版本），适配器上报原始 usage，平台套用规则换算为「标准成本单位」；规则按生效时间版本化，历史请求用当时价格重算（账单可追溯）。
- 换算要区分 `inputTokens / outputTokens / cachedTokens`，各自乘对应单价再求和；输出通常更贵，不能合并成一个 token 数。
- 成本要**分摊到业务方**：请求带 `tenantId/appId` 标签，按标签聚合出各团队成本，这是成本治理（AIC-813 配额）和效能度量（AIC-843）的数据基础。
- 追问钩子：能答出「价格按生效时间版本化，历史账单用当时价格重算」的候选人，说明真处理过财务对账，而不是只做实时看板。

```typescript
type PriceRule = {
  input: number; output: number; cached: number;
  effectiveFrom: number; batchDiscount?: number;
};
type Usage = { input: number; output: number; cached: number };

// 价格规则按生效时间版本化
const priceBook: Record<string, PriceRule[]> = {
  'model-x': [
    { input: 0.001, output: 0.002, cached: 0.0002, effectiveFrom: 0 },
    { input: 0.0005, output: 0.001, cached: 0.0001, effectiveFrom: 1730000000000 },
  ],
};

function ruleAt(modelId: string, ts: number): PriceRule {
  const rules = priceBook[modelId];
  if (!rules) throw new Error('no price rule');
  return [...rules].reverse().find(r => r.effectiveFrom <= ts)!;
}

function costOf(modelId: string, usage: Usage, ts = Date.now(), batch = false): number {
  const r = ruleAt(modelId, ts);
  const raw = usage.input * r.input + usage.output * r.output + usage.cached * r.cached;
  return batch ? raw * (r.batchDiscount ?? 0.5) : raw;
}

console.log(costOf('model-x', { input: 1000, output: 500, cached: 200 }));
// 用 ts 可重算历史账单，保证对账可追溯
```
