## AIC-664：笔试：手写北极星指标计算器

**答**：实现 `computeNorthStar(deliveries, opts)`。deliveries: `{ id:string, points:number, quality:{tested:boolean, reviewPassed:boolean, survived7d:boolean, reverted:boolean}, aiAssisted:boolean, daysAgo:number }[]`；opts: `{ minAgeDays?:number, aiOnly?:boolean }`（默认 minAgeDays=7, aiOnly=false）。规则：1) 成熟度过滤：daysAgo < minAgeDays 的排除（未到 7 天无法判定存活）；2) aiOnly=true 时只算 aiAssisted；3) 有效交付 = tested && reviewPassed && survived7d && !reverted；4) 北极星 = 有效交付的 points 之和；5) 护栏指标：escapeRate = 被回滚数/总交付数；6) 返回 `{ northStar:number, effectiveCount:number, totalCount:number, escapeRate:number, trend:'up'|'down'|'flat' }`（trend 需对比上一周期，这里用 opts.prevNorthStar 参与，缺省 'flat'）。边界：无有效交付 northStar=0 escapeRate 按总数算。

```javascript
function computeNorthStar(deliveries = [], opts = {}) {
  const { minAgeDays = 7, aiOnly = false, prevNorthStar } = opts;
  const mature = deliveries.filter(d => d.daysAgo >= minAgeDays && (!aiOnly || d.aiAssisted));
  const isEffective = d => {
    const q = d.quality || {};
    return q.tested && q.reviewPassed && q.survived7d && !q.reverted;
  };
  const effective = mature.filter(isEffective);
  const northStar = effective.reduce((s, d) => s + d.points, 0);
  const reverted = mature.filter(d => d.quality?.reverted).length;
  const escapeRate = mature.length ? reverted / mature.length : 0;
  let trend = 'flat';
  if (typeof prevNorthStar === 'number') {
    trend = northStar > prevNorthStar ? 'up' : northStar < prevNorthStar ? 'down' : 'flat';
  }
  return { northStar, effectiveCount: effective.length, totalCount: mature.length, escapeRate, trend };
}

// 自测
const deliveries = [
  { id: 'a', points: 5, quality: { tested: true, reviewPassed: true, survived7d: true, reverted: false }, aiAssisted: true, daysAgo: 10 },
  { id: 'b', points: 8, quality: { tested: true, reviewPassed: true, survived7d: false, reverted: true }, aiAssisted: true, daysAgo: 9 },
  { id: 'c', points: 3, quality: { tested: true, reviewPassed: true, survived7d: true, reverted: false }, aiAssisted: false, daysAgo: 8 },
  { id: 'd', points: 2, quality: { tested: true, reviewPassed: true, survived7d: true, reverted: false }, aiAssisted: true, daysAgo: 2 }, // 未成熟
];
const r = computeNorthStar(deliveries, { aiOnly: true });
console.log(r.northStar === 5);          // 只有 a 有效（b回滚，d未成熟）
console.log(r.effectiveCount === 1 && r.totalCount === 2);
console.log(Math.abs(r.escapeRate - 0.5) < 0.001);
console.log(computeNorthStar(deliveries, { prevNorthStar: 3 }).trend === 'up');
```

**评分点**：
- 成熟度过滤（daysAgo < minAgeDays 排除）与 aiOnly 过滤正确
- 有效交付四条件（tested/reviewPassed/survived7d/!reverted）
- northStar 求和、escapeRate 计算（回滚数/总数）
- trend 基于 prevNorthStar 三态判定
- 能说清「北极星必须内嵌质量护栏（7天存活+未回滚），否则就是可被灌水的虚荣指标」属于加分
