## AIC-417：笔试：把结构化评审结果渲染为三层 Markdown 报告。
**答**：输入 findings 与 verdict，渲染：TL;DR 3 行（verdict + 最高危 1 条 + 统计）；明细按 severity 分组；附录低危统计行。severity 排序 high>medium>low。

```javascript
function renderReport(verdict, findings) {
  const rank = { high: 0, medium: 1, low: 2 };
  const sorted = [...findings].sort((a, b) => rank[a.severity] - rank[b.severity]);
  const high = sorted.filter(f => f.severity === 'high');
  const low = sorted.filter(f => f.severity === 'low');
  const lines = [];
  lines.push(`**TL;DR** ${verdict}；高危 ${high.length} 条；低危 ${low.length} 条`);
  if (high[0]) lines.push(`最大风险：${high[0].file}:${high[0].line} ${high[0].message}`);
  else lines.push('无高危项');
  lines.push(''); lines.push('## 明细');
  for (const f of sorted.filter(x => x.severity !== 'low'))
    lines.push(`- [${f.severity}] ${f.file}:${f.line} ${f.message}`);
  lines.push(''); lines.push(`## 附录（低危 ${low.length} 条已折叠）`);
  return lines.join('\n');
}
console.log(renderReport('go-with-risk', [
  { severity: 'low', file: 'a', line: 1, message: '命名' },
  { severity: 'high', file: 'b', line: 9, message: 'NPE' },
]));

```

**评分点**：
- 分组排序正确，空分组不输出标题。
- TL;DR 恰好 3 行内——考察对「信息密度」的克制。
- 附录只输出统计（计数），不逐条展开低危。
- 输出为合法 Markdown（缩进/列表符正确）。
