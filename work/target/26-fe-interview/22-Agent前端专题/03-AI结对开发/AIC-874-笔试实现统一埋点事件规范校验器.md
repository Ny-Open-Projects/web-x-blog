## AIC-874：笔试：实现统一埋点事件规范校验器（字段/类型/标签）
**答**：
- 核心需求：实现 `validateEvent(event, schema)`，按 schema 校验事件是否合规。schema 定义 `{ required: string[], fields: Record<string, { type, enum?, min?, max? }>, tags: string[] }`。返回 `{ valid, errors }`，errors 列出每个不合规点（字段缺失、类型错误、枚举越界、数值越界、缺失必填标签）。
- 规则：`type` 支持 `'string' | 'number' | 'boolean' | 'array'`；`tags` 要求 `event.tags` 中包含所有 schema.tags 指定的标签键；额外字段允许（宽松）；嵌套对象用点路径（如 `ctx.tenantId`）。
- 边界：event 非对象返回 invalid；schema 非法抛错；数值 NaN 视为非法；空字符串视为缺失。
- 追问钩子：追问「校验在哪个环节做」——能答出「客户端上报前做一次（快速反馈）+ 服务端接收再做一次（防绕过），失败事件进死信队列而非直接丢弃」的候选人有完整的数据质量观。

```typescript
type FieldRule = { type: string; enum?: any[]; min?: number; max?: number };
type Schema = { required: string[]; fields: Record<string, FieldRule>; tags: string[] };

function get(obj: any, path: string) { return path.split('.').reduce((o, k) => o?.[k], obj); }

function validateEvent(event: any, schema: Schema) {
  if (!schema || !Array.isArray(schema.required)) throw new Error('bad schema');
  if (!event || typeof event !== 'object') return { valid:false, errors:['event must be an object'] };
  const errors: string[] = [];
  for (const path of schema.required) {
    const v = get(event, path);
    if (v == null || v === '') errors.push(`missing required: ${path}`);
  }
  for (const [path, rule] of Object.entries(schema.fields ?? {})) {
    const v = get(event, path);
    if (v == null) continue; // 非必填缺失跳过
    if (typeof v !== rule.type) { errors.push(`${path}: expected ${rule.type}`); continue; }
    if (rule.enum && !rule.enum.includes(v)) errors.push(`${path}: not in enum`);
    if (rule.type === 'number' && (!Number.isFinite(v) ||
        (rule.min != null && v < rule.min) || (rule.max != null && v > rule.max)))
      errors.push(`${path}: out of range`);
  }
  const tags = event.tags ?? {};
  for (const t of schema.tags ?? []) if (tags[t] == null) errors.push(`missing tag: ${t}`);
  return { valid: errors.length === 0, errors };
}
const schema: Schema = { required:['event','ts'],
  fields:{ ts:{type:'number',min:0}, event:{type:'string',enum:['accept','reject']} },
  tags:['modelVersion','tenantId'] };
console.log(validateEvent({ event:'accept', ts:123, tags:{ modelVersion:'v2', tenantId:'a' } }, schema));
// { valid:true, errors:[] }
console.log(validateEvent({ event:'click', ts:-1, tags:{} }, schema).errors);
// ['event: not in enum', 'ts: out of range', 'missing tag: modelVersion', 'missing tag: tenantId']
```
**评分点**：
- 必填字段缺失（含空字符串）与类型错误分别校验，错误可定位到字段路径。
- enum 与数值范围（含 NaN）校验正确，NaN 用 Number.isFinite 拦截。
- 标签键校验（tags 中必须含指定键），符合可观测性语义约定。
- schema 非法抛错、event 非法返回 invalid，边界清晰。
- 错误列表完整（一次返回所有问题）而非遇错即停，便于批量修正。
