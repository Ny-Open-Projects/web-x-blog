## AIC-753：笔试：实现黄金数据集的用例去重与分层器

**需求**：实现 `curateDataset(cases, opts)`。`cases`: `Array<{ id, input, level, domain }>`；`opts.maxPerDomain`（默认 10）。规则：1) 按 `input` 去重（保留首次出现，大小写敏感）；2) 按 `level` 分层统计（easy/mid/hard，未知 level 归 'other'）；3) 每个 domain 最多保留 maxPerDomain 条，超出按 id 字典序截断；4) 返回 `{ kept, deduped: number, byLevel: Record, byDomain: Record }`。边界：cases 空（全空/0）；maxPerDomain<=0 视为 0（不保留任何）；input 缺失按空字符串处理。

**答**：
- 结论先行：去重保证数据集无冗余，分层保证覆盖均衡，限额防止某域独占——三者都是为了让有限评测资源覆盖尽可能多的真实场景。
- 截断要有确定性规则（id 字典序），否则每次运行保留的用例不同，评测结果不可复现。
- 追问钩子：为什么按 input 而非 id 去重？——id 是人为分配的，同一个输入可能被不同来源赋予不同 id；输入相同才是真正的重复。

```javascript
function curateDataset(cases = [], opts = {}) {
  const maxPerDomain = opts.maxPerDomain ?? 10;
  const seen = new Set(), unique = [];
  let deduped = 0;
  for (const c of cases) {
    const key = c.input ?? '';
    if (seen.has(key)) { deduped++; continue; }
    seen.add(key); unique.push(c);
  }
  const domainCount = {};
  const kept = unique.filter(c => {
    const d = c.domain ?? 'unknown';
    domainCount[d] = (domainCount[d] ?? 0) + 1;
    return domainCount[d] <= Math.max(0, maxPerDomain);
  });
  const byLevel = {}, byDomain = {};
  for (const c of kept) {
    byLevel[c.level ?? 'other'] = (byLevel[c.level ?? 'other'] ?? 0) + 1;
    byDomain[c.domain ?? 'unknown'] = (byDomain[c.domain ?? 'unknown'] ?? 0) + 1;
  }
  return { kept, deduped, byLevel, byDomain };
}
const r = curateDataset([
  { id: 'a', input: 'X', level: 'easy', domain: 'list' },
  { id: 'b', input: 'X', level: 'easy', domain: 'list' }, // 去重
  { id: 'c', input: 'Y', level: 'hard', domain: 'pay' },
], { maxPerDomain: 1 });
console.log(r.deduped === 1 && r.kept.length === 2); // true
console.log(r.byLevel); // { easy:1, hard:1 }
console.log(curateDataset([]).deduped === 0); // 边界
```


**评分点**：
- 按 input 去重（保留首次出现）
- 分层统计 level（未知归 other）
- 每域限额 + id 字典序确定性截断
- 边界（空 cases / maxPerDomain<=0）
