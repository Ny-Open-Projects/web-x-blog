## AIC-701：AI 结对中的探索-实施-收敛三段式协作节奏如何设计

**答**：
- 结论先行：把一次 AI 结对拆成「探索（发散、低成本试错）→ 实施（聚焦、生成主代码）→ 收敛（验证、清理、定稿）」三段，每段的目标、产出、退出条件都不同，避免一路聊到底导致上下文腐烂与返工。
- 探索段：用短 prompt 枚举多方案，允许 AI「想错」；产出是方案清单与取舍表，不写生产代码；退出条件是选定 1 个方案。
- 实施段：把选定方案转成结构化任务卡（涉及文件、接口、边界），让 AI 在受限上下文里生成；人只做关键决策；退出条件是代码可编译、核心路径跑通。
- 追问钩子：为什么探索与实施要尽量分会话？——避免探索期的错误假设污染实施期上下文（RBL-352）；追问：如何判断已经进入收敛段？

```javascript
// 三段式协作状态机：每段有明确的进入条件与退出条件
const STAGES = {
  explore: { goal: '枚举方案', exit: r => r.plans.length >= 2 },
  implement: { goal: '生成主代码', exit: r => r.buildOk && r.corePathOk },
  converge: { goal: '验证清理定稿', exit: r => r.reviewPassed && r.cleaned },
};
function advance(stage, result) {
  const next = { explore: 'implement', implement: 'converge', converge: 'done' }[stage];
  return STAGES[stage].exit(result) ? next : stage; // 未达退出条件则停留
}
let stage = 'explore';
stage = advance(stage, { plans: ['A', 'B'] });      // -> implement
stage = advance(stage, { buildOk: true, corePathOk: true }); // -> converge
stage = advance(stage, { reviewPassed: true, cleaned: true }); // -> done
console.log(stage); // done
```
