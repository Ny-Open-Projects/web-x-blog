## AIC-168：笔试：实现一个 AI 回复的代码块提取器：多语言块、嵌套围栏、语言标签与残块处理？
**答**：实现 `extractCodeBlocks(text)`：
- 提取 ```lang ... ``` 块，返回 `[{lang, code, startLine}]`；
- 支持 4 反引号外层包裹 3 反引号内层（嵌套围栏）；
- 无语言标签默认 'text'；流式场景允许「未闭合块」返回 `{incomplete: true}`；
- 提取后剩余文本可拼回（用于只保留说明文字）。

```javascript
function extractCodeBlocks(text) {
  const blocks = [];
  const lines = text.split('\n');
  let i = 0;
  while (i < lines.length) {
    const open = lines[i].match(/^(`{3,})\s*(\w*)\s*$/);
    if (!open) { i++; continue; }
    const fence = open[1];                    // 外层围栏长度（3 或 4）
    const lang = open[2] || 'text';
    const body = [];
    let closed = false;
    i++;
    for (; i < lines.length; i++) {
      const close = lines[i].match(/^(`{3,})\s*$/);
      if (close && close[1].length === fence.length) { closed = true; i++; break; }
      body.push(lines[i]);
    }
    blocks.push({
      lang, code: body.join('\n'), closed,
      startLine: text.split('\n').indexOf(lines[i - body.length - (closed ? 2 : 1)]) + 1,
    });
  }
  return { blocks, incomplete: blocks.some(b => !b.closed) };
}

function stripCodeBlocks(text) {
  return text.replace(/^`{3,}\s*\w*\s*$[\s\S]*?^`{3,}\s*$/gm, '').trim();
}

// 测试：嵌套围栏 + 未闭合（围栏用码点构造，避免源码内出现字面围栏）
const F = '\u0060'.repeat(3), F4 = '\u0060'.repeat(4);
const md = [
  '说明如下：',
  F4 + 'md',
  '示例：',
  F + 'js',
  'let a = 1;',
  F,
  F4,
  '以上是嵌套示例',
].join('\n');
console.log(extractCodeBlocks(md).blocks);
// [{lang:'md', code:'示例：\n' + F + 'js\nlet a = 1;\n' + F, closed:true}]

console.log(extractCodeBlocks(F + 'ts\nlet b = 2;'));  // incomplete: true（流式中间态）
```

**评分点**：
1. 嵌套围栏处理：外层用更长围栏（4 反引号）包裹内层 3 反引号，闭合判断必须「等长围栏」；
2. 残块（未闭合）识别是流式场景刚需，返回 incomplete 而非丢弃；
3. 语言标签缺省兜底 'text'；
4. startLine 计算允许简化，但要说清实现思路（逐行计数比 indexOf 更稳）；
5. 追问：stripCodeBlocks 的反向提取用 replace 时要防贪婪跨块（`[\s\S]*?` 惰性 + 行锚点）。
