## AIC-597：笔试：手写敏感数据泄露检测

**答**：实现 `detectSensitiveData(code)`。规则：1) API key 模式（`sk-xxx` / `api_key = "..."`，长度 ≥ 20）；2) DB 连接串（`postgres://user:pass@`）；3) JWT secret（`jwt.sign(data, "secret")`）；4) AWS key（`AKIA` + 16 位）；5) 私钥（`BEGIN PRIVATE KEY`）；6) PII（email/phone 字面量）；7) 注释中的敏感数据不算（跳过注释行）；8) 返回 `{ findings: Array<{ type, line }>, ok }`（ok = 无 findings）。边界：空 code（ok）；纯注释中的 API key（不算——跳过注释）；模式命中但为环境变量引用（`process.env.KEY` 不算——是引用不是硬编码）。

```javascript
const PATTERNS = [
  { type: 'api-key', re: /(?:sk-|pk-|api[_-]?key|apikey)\s*[:=]\s*['"][A-Za-z0-9_\-]{20,}['"]/i },
  { type: 'db-connection', re: /(?:postgres|mysql|mongodb):\/\/\w+:\w+@/i },
  { type: 'jwt-secret', re: /jwt\.sign\(\s*\w+\s*,\s*['"][^'"]{8,}['"]/i },
  { type: 'aws-key', re: /AKIA[0-9A-Z]{16}/ },
  { type: 'private-key', re: /-----BEGIN\s+(?:RSA\s+)?PRIVATE\s+KEY-----/ },
  { type: 'pii-email', re: /['"][\w.+-]+@[\w-]+\.\w{2,}['"]/ },
];
function detectSensitiveData(code = '') {
  const findings: { type: string; line: number }[] = [];
  code.split('\n').forEach((line, i) => {
    const t = line.trim();
    if (t.startsWith('//') || t.startsWith('*') || t.startsWith('/*')) return;   // 注释跳过
    // 环境变量引用不算
    if (/process\.env|import\.meta\.env|getenv/.test(line)) return;
    for (const p of PATTERNS) {
      if (p.re.test(line))
        findings.push({ type: p.type, line: i + 1 });
    }
  });
  return { findings, ok: findings.length === 0 };
}

// 自测
// API key 泄露
const code1 = `const key = "sk-proj-abc123def456ghi789jkl012";`;
let r = detectSensitiveData(code1);
console.log(r.findings[0].type === 'api-key' && r.ok === false);
// DB 连接串
r = detectSensitiveData(`const conn = "postgres://admin:pass123@db.host/mydb";`);
console.log(r.findings[0].type === 'db-connection');
// JWT secret
r = detectSensitiveData(`jwt.sign(data, "my-super-secret-key");`);
console.log(r.findings[0].type === 'jwt-secret');
// AWS key
r = detectSensitiveData(`const config = { accessKeyId: "AKIAIOSFODNN7EXAMPLE" };`);
console.log(r.findings[0].type === 'aws-key');
// 环境变量引用不算
r = detectSensitiveData(`const key = process.env.API_KEY;`);
console.log(r.ok === true);                             // 引用不是硬编码
// 注释跳过
r = detectSensitiveData(`// const key = "sk-example123456789012345";`);
console.log(r.ok === true);
// PII
r = detectSensitiveData(`const email = "user@example.com";`);
console.log(r.findings[0].type === 'pii-email');
// 空代码
console.log(detectSensitiveData('').ok === true);
```

**评分点**：
- 六类模式检测（api-key/db-connection/jwt-secret/aws-key/private-key/pii——AI 特有的泄露向量全覆盖）
- 环境变量引用排除（`process.env.KEY` 是引用不是硬编码——不误报）；注释跳过
- 边界（空 code/注释/环境变量引用/PII）；ok = 无 findings（安全零容忍）
- 能说清「AI 的密钥泄露比人写的更隐蔽：AI 写的看起来像真实 key 而非明显占位符——开发者和扫描器都可能漏过」属于加分
