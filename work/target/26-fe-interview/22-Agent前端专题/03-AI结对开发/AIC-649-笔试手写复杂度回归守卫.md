## AIC-649：笔试：手写复杂度回归守卫

**答**：实现 `guardComplexity(before, after, opts)`。before/after: `Record<string, number>`（文件名→该文件函数圈复杂度总和）；opts: `{ perFileMax?:number, totalDeltaMax?:number, exempt?:string[] }`（默认 perFileMax=15, totalDeltaMax=30, exempt=[]）。规则：1) 逐文件计算 delta = after[f] − before[f]；2) 新增文件（before 无）delta = after[f]，若 > perFileMax → 'file-complexity-exceeded'；3) 已有文件 delta > perFileMax → 同类违规；4) 所有文件 delta 之和 > totalDeltaMax → 'total-delta-exceeded'（整体复杂度膨胀）；5) exempt 列表中的文件跳过所有检查；6) 返回 `{ violations:Array<{file,type,delta}>, totalDelta, passed:boolean }`。边界：after 空返回无违规；复杂度下降（delta<0）不违规。

```javascript
function guardComplexity(before = {}, after = {}, opts = {}) {
  const { perFileMax = 15, totalDeltaMax = 30, exempt = [] } = opts;
  const exemptSet = new Set(exempt);
  const violations = [];
  let totalDelta = 0;
  for (const [file, afterVal] of Object.entries(after)) {
    if (exemptSet.has(file)) continue;
    const beforeVal = before[file] ?? 0;
    const delta = afterVal - beforeVal;
    totalDelta += delta;
    if (delta > perFileMax) {
      violations.push({ file, type: 'file-complexity-exceeded', delta });
    }
  }
  if (totalDelta > totalDeltaMax) {
    violations.push({ file: '*', type: 'total-delta-exceeded', delta: totalDelta });
  }
  return { violations, totalDelta, passed: violations.length === 0 };
}

// 自测
const before = { 'a.ts': 10, 'legacy.ts': 50 };
const after = { 'a.ts': 28, 'legacy.ts': 50, 'new.ts': 20 };
const r = guardComplexity(before, after, { perFileMax: 15, totalDeltaMax: 30 });
console.log(r.violations.some(v => v.file === 'a.ts' && v.type === 'file-complexity-exceeded')); // delta 18
console.log(r.violations.some(v => v.type === 'total-delta-exceeded')); // total 18+20=38
console.log(!r.violations.some(v => v.file === 'legacy.ts')); // 无增量
const r2 = guardComplexity(before, after, { exempt: ['a.ts', 'new.ts'] });
console.log(r2.passed); // 豁免后 totalDelta=0
console.log(guardComplexity(before, {}).passed);
```

**评分点**：
- 新增文件 delta = after 值，已有文件 delta = 差值
- 逐文件 perFileMax 与整体 totalDeltaMax 双重守卫
- exempt 豁免列表对逐文件与 total 都生效
- 复杂度下降不违规、after 空边界
- 能说清「增量守卫只卡新代码放过存量，是 AI 复杂度治理能落地的关键——先止血不清算历史」属于加分
