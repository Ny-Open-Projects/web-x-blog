## AIC-843：笔试：实现提效指标计算器（采纳率/存活率/返工率加权）
**答**：
- 核心需求：实现 `calcEfficiency(stats)`。输入 `{ suggestions, accepted, survived7d, reworked, reverted, manualBaselineMinutes, actualMinutes }`，输出 `{ adoption, survival, reworkRate, timeSavedPct, composite }`。权重默认采纳 0.2 / 存活 0.5 / 返工（反向）0.3。
- 公式：`adoption = accepted/suggestions`；`survival = survived7d/accepted`；`reworkRate = reworked/accepted`；`timeSavedPct = (baseline-actual)/baseline`；`composite = 0.2×adoption + 0.5×survival + 0.3×(1-reworkRate)`。
- 边界：分母为 0 时对应指标返回 0；输入非法（负数、非数字）过滤为 0；composite 裁剪到 [0,1]；`timeSavedPct` 可为负（AI 反而更慢，必须如实反映）。
- 追问钩子：追问「为什么存活率权重最高」——能答出「采纳只是用了，存活才说明真的有用且质量过关」的候选人理解指标背后的价值判断。

```typescript
type Stats = {
  suggestions: number; accepted: number; survived7d: number;
  reworked: number; reverted: number;
  manualBaselineMinutes: number; actualMinutes: number;
};
const safeDiv = (a: number, b: number) => b > 0 && Number.isFinite(a) && a >= 0 ? a / b : 0;

function calcEfficiency(s: Stats, w = { adoption: 0.2, survival: 0.5, rework: 0.3 }) {
  const adoption = safeDiv(s.accepted, s.suggestions);
  const survival = safeDiv(s.survived7d, s.accepted);
  const reworkRate = safeDiv(s.reworked, s.accepted);
  const timeSavedPct = s.manualBaselineMinutes > 0
    ? (s.manualBaselineMinutes - s.actualMinutes) / s.manualBaselineMinutes : 0;
  const raw = w.adoption * adoption + w.survival * survival + w.rework * (1 - reworkRate);
  return {
    adoption: +adoption.toFixed(3),
    survival: +survival.toFixed(3),
    reworkRate: +reworkRate.toFixed(3),
    timeSavedPct: +timeSavedPct.toFixed(3), // 可为负：如实呈现"AI 反而更慢"
    composite: +Math.max(0, Math.min(1, raw)).toFixed(3),
  };
}
console.log(calcEfficiency({
  suggestions: 1000, accepted: 600, survived7d: 450,
  reworked: 120, reverted: 30, manualBaselineMinutes: 500, actualMinutes: 320,
})); // { adoption:0.6, survival:0.75, reworkRate:0.2, timeSavedPct:0.36, composite:0.735 }
console.log(calcEfficiency({ suggestions:0, accepted:0, survived7d:0, reworked:0,
  reverted:0, manualBaselineMinutes:0, actualMinutes:0 })); // 全 0，不抛错
```
**评分点**：
- 统一的 `safeDiv` 处理所有分母为 0 / 非法输入，避免 NaN 扩散。
- 返工率是反向指标，加权时用 `(1 - reworkRate)`，方向不能反。
- `timeSavedPct` 允许为负（AI 更慢时如实反映），不强制裁剪到正数。
- composite 裁剪到 [0,1] 且权重可配置，便于团队校准。
- 存活率权重最高并有理由，体现对指标价值的理解。
