## AIC-595：笔试：手写跨文件一致性

**答**：实现 `checkCrossFileConsistency(exportedNames, importedNames)`。exportedNames: `Record<file, Set<string>>`（各文件的导出名集合——变更后）；importedNames: `Record<file, { from: string; names: Set<string> }[]>`（各文件的 import 清单）。规则：1) **引用检查**：import 的 name 不在 from 文件的 exportedNames 中 → 'missing-export'（编译错误——引用了不存在的导出）；2) **未使用导出**：exportedNames 中有但无人 import → 'unused-export'（可清理——不算 error）；3) **循环依赖检测**：A imports B、B imports A → 'circular'（RBL-592 的模块版）；4) 返回 `{ issues: Array<{ type, from?, to?, name? }>, ok }`（ok = 无 missing-export 和 circular）。边界：exportedNames 空（全部 missing）；importedNames 空（全部 unused——如果 exportedNames 非空）；自引用（A imports A——合法但可能是笔误）。

```javascript
function checkCrossFileConsistency(exportedNames = {}, importedNames = {}) {
  const issues = [];
  const exportSet = new Map(Object.entries(exportedNames).map(([f, s]) => [f, new Set(s as string[])]));
  // 1) 引用检查
  for (const [file, imports] of Object.entries(importedNames)) {
    for (const imp of imports) {
      const exports = exportSet.get(imp.from);
      if (!exports) { issues.push({ type: 'missing-module', to: file, from: imp.from }); continue; }
      for (const name of imp.names) {
        if (!exports.has(name))
          issues.push({ type: 'missing-export', from: imp.from, to: file, name,
            detail: `${file} imports '${name}' from '${imp.from}' but it's not exported` });
      }
    }
  }
  // 2) 未使用导出
  const importedAll = new Set<string>();
  for (const imports of Object.values(importedNames))
    for (const imp of imports)
      for (const name of imp.names) importedAll.add(name);
  for (const [file, names] of exportSet)
    for (const name of names)
      if (!importedAll.has(name))
        issues.push({ type: 'unused-export', from: file, name, severity: 'info' });
  // 3) 循环依赖
  const depGraph = new Map<string, Set<string>>();
  for (const [file, imports] of Object.entries(importedNames))
    for (const imp of imports)
      (depGraph.get(file) || depGraph.set(file, new Set()).get(file)).add(imp.from);
  const visited = new Set();
  function hasCycle(node, path = new Set<string>()): boolean {
    if (path.has(node)) return true;
    if (visited.has(node)) return false;
    visited.add(node); path.add(node);
    for (const dep of depGraph.get(node) ?? [])
      if (hasCycle(dep, new Set(path))) return true;
    return false;
  }
  for (const file of depGraph.keys())
    if (hasCycle(file)) { issues.push({ type: 'circular', from: file }); break; }
  return { issues, ok: !issues.some(i => i.type === 'missing-export' || i.type === 'circular') };
}

// 自测
const exportedNames = { 'utils.ts': new Set(['getUser', 'formatDate']), 'api.ts': new Set(['fetchData']) };
const importedNames = {
  'app.ts': [{ from: 'utils.ts', names: new Set(['getUser', 'formatDate']) }, { from: 'api.ts', names: new Set(['fetchData']) }],
};
// 全一致
let r = checkCrossFileConsistency(exportedNames, importedNames);
console.log(r.ok === true && r.issues.length === 0);

// missing-export：app.ts 引用了不存在的 getUserById
const badImports = { 'app.ts': [{ from: 'utils.ts', names: new Set(['getUserById']) }] };
r = checkCrossFileConsistency(exportedNames, badImports);
console.log(r.issues[0].type === 'missing-export' && r.ok === false);

// unused-export：formatDate 无人 import
const partialImports = { 'app.ts': [{ from: 'utils.ts', names: new Set(['getUser']) }] };
r = checkCrossFileConsistency(exportedNames, partialImports);
console.log(r.issues.some(i => i.type === 'unused-export' && i.name === 'formatDate'));
console.log(r.ok === true);                             // unused 是 info

// circular
const circularImports = { 'a.ts': [{ from: 'b.ts', names: new Set(['x']) }], 'b.ts': [{ from: 'a.ts', names: new Set(['y']) }] };
const circularExports = { 'a.ts': new Set(['y']), 'b.ts': new Set(['x']) };
r = checkCrossFileConsistency(circularExports, circularImports);
console.log(r.issues.some(i => i.type === 'circular'));
console.log(r.ok === false);
```

**评分点**：
- 三类检测：missing-export（编译错误阻断）/ unused-export（info 清理）/ circular（阻断）
- 循环依赖检测（DFS 环检测 RBL-592 模块版）；missing-export 的详细错误信息（谁引用了谁的什么）
- 边界（全一致/引用不存在/未使用导出/循环依赖/自引用）；ok 仅由 missing-export 和 circular 决定
- 能说清「AI Agent 模式的跨文件一致性优势：全局视角同步修改——Inline 模式逐文件修改会导致 export/import 不同步」属于加分
