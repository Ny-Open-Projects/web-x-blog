## AIC-652：笔试：手写性能回归风险扫描器

**答**：实现 `scanPerfRisks(diff, opts)`。diff: `{ file:string, added:string[] }[]`（每个文件新增的代码行）；opts: `{ maxAddedLines?:number, dataIntensive?:boolean }`（默认 maxAddedLines=100, dataIntensive=false）。规则：扫描 added 行中的性能反模式：1) 深拷贝 `JSON.parse(JSON.stringify` → 'deep-clone'（dataIntensive 时严重度 high）；2) `.map(...).filter(` 链式 → 'chained-iteration'；3) 渲染函数内 `new Date()/Math.random()` → 'impure-render'；4) 单文件新增行数 > maxAddedLines → 'large-addition'；5) `setInterval(` 无对应清理 → 'interval-leak'（简化：仅看是否出现 setInterval 且同段无 clearInterval）。返回 `{ risks:Array<{file,type,severity:'high'|'medium'|'low',line:string}>, score:number }`（score=100−high×20−medium×10−low×5，clamp 0）。边界：diff 空返回 score=100。

```javascript
function scanPerfRisks(diff = [], opts = {}) {
  const { maxAddedLines = 100, dataIntensive = false } = opts;
  const rules = [
    { re: /JSON\.parse\(JSON\.stringify/, type: 'deep-clone' },
    { re: /\.map\([^)]*\)\.filter\(/, type: 'chained-iteration' },
    { re: /new Date\(\)|Math\.random\(\)/, type: 'impure-render' },
    { re: /setInterval\(/, type: 'interval-leak' },
  ];
  const risks = [];
  for (const f of diff) {
    for (const line of f.added) {
      for (const r of rules) {
        if (r.re.test(line)) {
          const severity = r.type === 'deep-clone' && dataIntensive ? 'high'
            : r.type === 'deep-clone' || r.type === 'interval-leak' ? 'medium' : 'low';
          risks.push({ file: f.file, type: r.type, severity, line: line.trim() });
        }
      }
    }
    if (f.added.length > maxAddedLines) {
      risks.push({ file: f.file, type: 'large-addition', severity: 'low', line: `${f.added.length} lines` });
    }
    // interval-leak 简化：有 setInterval 但无 clearInterval
    const joined = f.added.join('
');
    if (/setInterval\(/.test(joined) && !/clearInterval\(/.test(joined)) {
      if (!risks.some(r => r.file === f.file && r.type === 'interval-leak-cleanup')) {
        risks.push({ file: f.file, type: 'interval-leak', severity: 'medium', line: 'no clearInterval' });
      }
    }
  }
  const weight = { high: 20, medium: 10, low: 5 };
  const score = Math.max(0, 100 - risks.reduce((s, r) => s + weight[r.severity], 0));
  return { risks, score };
}

// 自测
const diff = [{ file: 'list.tsx', added: [
  'const copy = JSON.parse(JSON.stringify(items));',
  'const x = items.map(f).filter(Boolean);',
  'const t = new Date();',
] }];
const r = scanPerfRisks(diff, { dataIntensive: true });
console.log(r.risks.some(x => x.type === 'deep-clone' && x.severity === 'high'));
console.log(r.risks.some(x => x.type === 'chained-iteration'));
console.log(scanPerfRisks([]).score === 100);
```

**评分点**：
- 四类反模式正则识别（深拷贝/链式迭代/非纯渲染/setInterval）
- dataIntensive 时 deep-clone 升级为 high
- interval 无清理检测与 large-addition 检测
- score 加权计算（high20/medium10/low5）clamp 0
- 能说清「性能是运行时特性，静态扫描只能抓高频反模式，真正确认要数据放大测试 + 火焰图」属于加分
