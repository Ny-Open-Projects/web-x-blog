## AIC-654：笔试：手写可测试性评分器

**答**：实现 `scoreTestability(code)`。code: string（单函数源码字符串）。规则：用简单的静态特征打分（满分 100，起始 100 扣分）：1) 副作用关键词 `fetch/axios/Date.now/Math.random/localStorage` 每出现一处 −10（外部依赖难测）；2) 函数参数为空 → −15（无输入无法参数化）；3) `new Promise`/`async` 且无依赖注入（参数里无 fn 类型提示）→ −10；4) 嵌套 if/三元超过 3 层 → −15（分支复杂难覆盖）；5) 直接 `import` 后调用外部模块函数（简化：出现 `import` 且代码含 `(` 调用）→ −10；6) 有 `return` 且无副作用 → +5 奖励（纯函数倾向，但总分不超 100）。返回 `{ score:number (0-100), issues:string[], pure:boolean }`，pure = 无副作用关键词且无外部调用。边界：code 空返回 score=0；score clamp [0,100]。

```javascript
function scoreTestability(code = '') {
  if (!code.trim()) return { score: 0, issues: ['empty-code'], pure: false };
  let score = 100;
  const issues = [];
  const sideEffects = /fetch\(|axios|Date\.now\(|Math\.random\(|localStorage/g;
  const seMatches = code.match(sideEffects) || [];
  if (seMatches.length) { score -= seMatches.length * 10; issues.push(`side-effects:${seMatches.length}`); }
  // 参数为空：foo() 形式
  if (/\w+\s*\(\s*\)\s*\{/.test(code)) { score -= 15; issues.push('no-params'); }
  // async 但参数无函数型（简化：参数里没有 => 或 fn/callback 字样）
  if (/async/.test(code) && !/=>|fn|callback|deps/.test(code)) { score -= 10; issues.push('async-no-di'); }
  // 嵌套三元 / if 深度（简化：数 >>> 或连续 ? :）
  const ternaryDepth = (code.match(/\?/g) || []).length;
  if (ternaryDepth > 3) { score -= 15; issues.push('deep-branches'); }
  // import 后调用
  if (/import\s/.test(code) && /\w+\(/.test(code.replace(/import[^;]+;/g, ''))) {
    score -= 10; issues.push('external-call');
  }
  const pure = seMatches.length === 0 && !issues.includes('external-call');
  if (pure && /return/.test(code)) score += 5;
  score = Math.max(0, Math.min(100, score));
  return { score, issues, pure };
}

// 自测
const bad = `import { api } from './api';
function load() { const d = await api.get(); const t = Date.now(); return d + t; }`;
const good = `function calc(price, now) { return now > 100 ? price : price * 0.9; }`;
console.log(scoreTestability(bad).score < scoreTestability(good).score);
console.log(scoreTestability(good).pure === true);
console.log(scoreTestability(bad).issues.includes('side-effects:1'));
console.log(scoreTestability('').score === 0);
```

**评分点**：
- 副作用关键词扣分正确（每处 −10），并影响 pure 判定
- 参数为空 / async 无依赖注入 / 深分支 / 外部调用扣分
- 纯函数奖励 +5 且 clamp [0,100]
- 边界：空代码 score=0
- 能说清「可测试性评分的价值是给 AI 反馈——低分函数让 AI 重构成纯函数+依赖注入，而非补一堆 mock」属于加分
