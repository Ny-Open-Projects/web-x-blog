## AIC-571：笔试：手写审查流程状态机

**答**：实现 `createReviewStateMachine(pr, config)`。pr: `{ files, testsPass }`；config: `{ securityReviewer, techLead, autoMergeT3 }`. 状态：created → ci-running → gated（CI 通过）| blocked（CI 失败）→ routed → pending-review | auto-merged → approved → merged | rejected。方法：`transition(event)`。规则：1) created → ci-running（自动）；2) ci-running → gated/blocked（CI 结果）；3) gated → routed（信任路由 RBL-549）；4) routed → pending-review（T0/T1）或 auto-merged（T3）；5) pending-review → approved/rejected（人审结果）；6) approved → merged（自动合并）；7) **非法转换**：blocked → merged（CI 失败不能合并）；rejected → approved（拒绝后不能直接通过——需要新 PR）。返回 `{ state, transition(event), history: Array<{ from, event, to }> }`。

```javascript
const TRANSITIONS = {
  created: { 'start-ci': 'ci-running' },
  'ci-running': { 'ci-pass': 'gated', 'ci-fail': 'blocked' },
  gated: { 'route-t0': 'pending-review', 'route-t1': 'pending-review',
    'route-t3': 'auto-merged' },
  'pending-review': { approve: 'approved', reject: 'rejected' },
  approved: { merge: 'merged' },
  blocked: {},
  'auto-merged': {},
  merged: {}, rejected: {},
};
function createReviewStateMachine(config) {
  let state = 'created';
  const history = [];
  return {
    get state() { return state; },
    transition(event) {
      const allowed = TRANSITIONS[state];
      if (!allowed || !(event in allowed))
        throw new Error(`非法转换: ${state} --${event}--> ?`);
      const next = allowed[event];
      history.push({ from: state, event, to: next });
      state = next;
      return state;
    },
    history: () => [...history],
  };
}

// 自测
const sm = createReviewStateMachine({});
sm.transition('start-ci');
console.log(sm.state === 'ci-running');
sm.transition('ci-pass');
console.log(sm.state === 'gated');
sm.transition('route-t0');
console.log(sm.state === 'pending-review');
sm.transition('approve');
console.log(sm.state === 'approved');
sm.transition('merge');
console.log(sm.state === 'merged');
// 非法转换
e = null; try { sm.transition('merge'); } catch (x) { e = x; }
console.log(/非法转换/.test(e.message));                 // merged 终态
// blocked → merge 非法
const sm2 = createReviewStateMachine({});
sm2.transition('start-ci'); sm2.transition('ci-fail');
e = null; try { sm2.transition('merge'); } catch (x) { e = x; }
console.log(/非法转换/.test(e.message));                 // blocked 不能 merge
// 完整历史
console.log(sm.history().length === 5);
```

**评分点**：
- 状态机完整（created→ci-running→gated/blocked→routed→pending-review→approved→merged）；blocked 终态
- 非法转换抛错（blocked→merge / rejected→approved——状态机的安全约束）；history 可审计
- 边界（终态再转换/CI 失败路径/完整生命周期）；transition 表驱动（可扩展新状态）
- 能说清「AI 代码审查的状态机 = 流程的机械化：非法转换被阻止（CI 失败不能合并）——状态机防止流程绕过」属于加分
