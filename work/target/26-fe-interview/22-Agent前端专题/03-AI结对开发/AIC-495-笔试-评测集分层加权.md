## AIC-495：笔试：评测总分分层加权计算。
**答**：评测分层 `[{layer, weight, passed, total}]`。总分 = Σ(层通过率 × weight)/Σweight。输出总分与最弱层（通过率最低且 total ≥ 3）。

```javascript
function weightedScore(layers) {
  let num = 0, den = 0;
  for (const l of layers) {
    const w = l.weight ?? 1;
    num += (l.total ? l.passed / l.total : 0) * w;
    den += w;
  }
  const score = den ? +(num / den).toFixed(2) : 0;
  const weakest = layers.filter(l => l.total >= 3)
    .sort((a, b) => (a.passed / a.total) - (b.passed / b.total))[0];
  return { score, weakest: weakest?.layer ?? null };
}
console.log(weightedScore([
  { layer: 'core', weight: 3, passed: 18, total: 20 },
  { layer: 'edge', weight: 1, passed: 2, total: 10 },
])); // score 0.79；weakest edge

```

**评分点**：
- 加权平均公式正确（分母是权重和）。
- 最弱层有最小样本门槛（total ≥ 3）。
- weight 缺省按 1。
- 输出两位小数。
