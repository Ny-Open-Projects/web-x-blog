## AIC-744：笔试：实现 AI 代码质量基线的漂移检测器

**需求**：实现 `detectQualityDrift(baseline, samples, opts)`。`baseline`: `{ red, target }`；`samples`: `number[]`（近期质量分）；`opts.window`（默认 5）、`dropRatio`（默认 0.2）。规则：1) 取 samples 最近 window 个的均值 `recentAvg`；2) 若 `recentAvg < baseline.red * (1 - dropRatio)` 判 `redline-drift`；3) 若 `recentAvg` 比上一等长窗口均值下降超过 dropRatio 判 `sudden-drop`；4) 返回 `{ recentAvg, prevAvg, alerts: string[] }`。边界：samples 不足 window（用现有全部，prevAvg=null、不判 sudden-drop）；baseline.red<=0（不判 redline-drift）；samples 空（recentAvg=0、alerts 依规则）。

**答**：
- 结论先行：漂移检测要同时看「绝对水位」（是否跌破红线）和「相对变化」（是否突然下跌），前者抓长期退化，后者抓突发回归。
- 窗口均值能平滑单点噪声，但窗口不能太大，否则突发下跌会被稀释；默认 5 是折中。
- 追问钩子：为什么样本不足时不判 sudden-drop？——没有完整的前一窗口做对比，强行比较会误报。

```javascript
function detectQualityDrift(baseline = {}, samples = [], opts = {}) {
  const window = opts.window ?? 5;
  const dropRatio = opts.dropRatio ?? 0.2;
  const avg = a => a.length ? a.reduce((s, x) => s + x, 0) / a.length : 0;
  const recent = samples.slice(-window);
  const prev = samples.length > window ? samples.slice(-2 * window, -window) : [];
  const recentAvg = avg(recent), prevAvg = prev.length ? avg(prev) : null;
  const alerts = [];
  if (baseline.red > 0 && recentAvg < baseline.red * (1 - dropRatio)) alerts.push('redline-drift');
  if (prevAvg !== null && prevAvg > 0 && (prevAvg - recentAvg) / prevAvg > dropRatio)
    alerts.push('sudden-drop');
  return { recentAvg, prevAvg, alerts };
}
const r = detectQualityDrift({ red: 0.7 }, [0.9, 0.85, 0.8, 0.5, 0.45], { window: 3 });
console.log(r.recentAvg.toFixed(2)); // 0.58
console.log(r.alerts);               // ['sudden-drop'] —— 相对上一窗口突降 31%，超过 20% 阈值
console.log(detectQualityDrift({ red: 0.7 }, []).prevAvg === null); // 边界
```


**评分点**：
- 窗口均值与基线、上一窗口对比正确
- redline-drift 与 sudden-drop 双信号判定
- 样本不足时不判 sudden-drop
- 边界（空样本 / red<=0）处理
