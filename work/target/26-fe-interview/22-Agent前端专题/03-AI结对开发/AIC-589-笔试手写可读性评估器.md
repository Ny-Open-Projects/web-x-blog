## AIC-589：笔试：手写可读性评估

**答**：实现 `assessReadability(code)`。规则：1) 魔法值：`=== 3` / `if (x > 100)` 的硬编码数字（排除 0/1/常见阈值 200/500/1000）→ 'magic-numbers'；2) 抽象命名：`processData/handleThing/doStuff/manageItems` → 'abstract-naming'；3) 长链式：连续 ≥ 3 个 `.method()` → 'long-chain'；4) 嵌套深度：缩进 > 5 层 → 'deep-nesting'；5) 注释缺失：函数 > 3 个但注释 = 0 → 'no-comments'。返回 `{ issues: string[], readable: boolean }`（readable = issues ≤ 1）。边界：空 code（readable）；纯声明（无 issue）；全部问题（issues 5 个——不可读）。

```javascript
function assessReadability(code = '') {
  const issues: string[] = [];
  // 1) 魔法值
  const magicNums = [...code.matchAll(/[^\w-](\d{2,})[^\w]/g)]
    .filter(m => !['200', '500', '1000', '404'].includes(m[1]));
  if (magicNums.length > 2) issues.push('magic-numbers');
  // 2) 抽象命名
  const ABSTRACT = /(?:function|const)\s+(?:process|handle|manage|do|run)\w*/gi;
  if ((code.match(ABSTRACT) ?? []).length > 2) issues.push('abstract-naming');
  // 3) 长链式
  if (/\.\w+\([^)]*\)\.\w+\([^)]*\)\.\w+\(/.test(code)) issues.push('long-chain');
  // 4) 嵌套
  const maxIndent = Math.max(0, ...code.split('\n')
    .map(l => Math.floor((l.match(/^\s*/)?.[0].length ?? 0) / 2)));
  if (maxIndent > 5) issues.push('deep-nesting');
  // 5) 注释缺失
  const fns = (code.match(/function\s+\w+|=>\s*\{/g) ?? []).length;
  const comments = (code.match(/\/\/|\/\*/g) ?? []).length;
  if (fns > 3 && comments === 0) issues.push('no-comments');
  return { issues, readable: issues.length <= 1 };
}

// 自测
// 可读代码
const good = `
  // Fetch user orders with pagination
  function getUserOrders(userId: string, cursor?: string) {
    const orders = fetchOrders(userId, cursor);
    return orders.filter(o => o.status !== 'draft');
  }
`;
let r = assessReadability(good);
console.log(r.readable === true);

// 不可读代码
const bad = `
  function processData(data) {
    if (data.type === 3) {
      if (data.status === 100) {
        if (data.items) {
          return data.items.filter(x => x.v === 3).map(x => x.n).join(',').split(',').filter(x => x).map(x => x.trim()).filter(Boolean).map(x => x.toUpperCase()).filter(Boolean).join('|').substring(0, 100);
        }
      }
    }
  }
`;
r = assessReadability(bad);
console.log(r.issues.length >= 3);                       // magic + nesting + abstract naming + chain
console.log(r.readable === false);

// 空
console.log(assessReadability('').readable === true);
console.log(assessReadability('const x = 1;').readable === true);
```

**评分点**：
- 五维检测：魔法值/抽象命名/长链式/深嵌套/注释缺失——AI 可读性问题的全谱
- 魔法值的排除列表（200/500/1000 是常见合法阈值——不误报）；readable 阈值（≤ 1 issue）
- 边界（空 code/纯声明/全问题）；issues 清单可修复
- 能说清「AI 代码的可读性需要主动评估：AI 一次性生成不做可读性优化——人可能看不懂 AI 的"简洁"实现」属于加分
