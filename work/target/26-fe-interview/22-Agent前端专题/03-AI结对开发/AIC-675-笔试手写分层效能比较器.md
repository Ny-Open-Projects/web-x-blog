## AIC-675：笔试：手写分层效能比较器

**答**：实现 `compareStratified(before, after, opts)`。before/after: `{ group:string, value:number, weight:number }[]`（分组+指标值+该组权重/占比）；opts: `{ alertThreshold?:number, minGroupShare?:number }`（默认 alertThreshold=−0.05, minGroupShare=0.1）。规则：1) 按 group 配对，计算各组变化率 = (after−before)/before，before=0 用 (after>0?1:0)；2) 整体变化率 = Σ(after×weight)/Σ(before×weight) − 1；3) 辛普森悖论检测：整体变化率 > 0 但存在「权重 ≥ minGroupShare 的组」变化率 < alertThreshold → flag 'simpson-paradox'；4) 返回 `{ overall:number, groups:Array<{group,changeRate,weight,concern:boolean}>, flags:string[] }`。边界：before/after 空返回 overall=0；group 在 after 缺失按 0 计。

```javascript
function compareStratified(before = [], after = [], opts = {}) {
  const { alertThreshold = -0.05, minGroupShare = 0.1 } = opts;
  const afterMap = new Map(after.map(x => [x.group, x]));
  const beforeMap = new Map(before.map(x => [x.group, x]));
  const groups = new Set([...beforeMap.keys(), ...afterMap.keys()]);
  const rate = (b, a) => b === 0 ? (a > 0 ? 1 : 0) : (a - b) / b;
  const sumB = before.reduce((s, x) => s + x.value * x.weight, 0);
  const sumA = [...groups].reduce((s, g) => {
    const a = afterMap.get(g);
    const b = beforeMap.get(g);
    return s + (a ? a.value : 0) * (b ? b.weight : (a ? a.weight : 0));
  }, 0);
  const overall = sumB ? sumA / sumB - 1 : 0;
  const rows = [...groups].map(g => {
    const b = beforeMap.get(g)?.value ?? 0;
    const a = afterMap.get(g)?.value ?? 0;
    const weight = beforeMap.get(g)?.weight ?? afterMap.get(g)?.weight ?? 0;
    const changeRate = rate(b, a);
    return { group: g, changeRate, weight, concern: weight >= minGroupShare && changeRate < alertThreshold };
  });
  const flags = [];
  if (overall > 0 && rows.some(r => r.concern)) flags.push('simpson-paradox');
  return { overall, groups: rows, flags };
}

// 自测
const before = [
  { group: 'simple', value: 10, weight: 0.7 },
  { group: 'complex', value: 30, weight: 0.3 },
];
const after = [
  { group: 'simple', value: 5, weight: 0.7 },    // 快50%
  { group: 'complex', value: 36, weight: 0.3 }, // 慢20% → concern
];
const r = compareStratified(before, after);
console.log(r.overall > 0);                    // 整体提升
console.log(r.groups.find(g => g.group === 'complex').concern === true);
console.log(r.flags.includes('simpson-paradox'));
console.log(compareStratified([], []).overall === 0);
```

**评分点**：
- 分组配对变化率与 before=0 的特殊处理
- 整体变化率按权重加权（Σvalue×weight）
- 辛普森悖论检测：整体涨但高权重组退化
- concern 判定需满足权重阈值 + 变化率阈值双条件
- 能说清「分层比较的价值是发现被平均值掩盖的局部退化，尤其 Senior/复杂任务的负收益」属于加分
