## AIC-636：笔试：手写风格割裂检测器

**答**：实现 `detectStyleFragmentation(files, opts)`。files: `{path:string, features:{quotes:'single'|'double', semi:boolean, arrowFn:boolean, asyncAwait:boolean}}[]`；opts: `{ entropyThreshold?:number, scope?:'global'|'per-dir' }`（默认 entropyThreshold=0.6, scope='global'）。规则：1) 按 scope 分组（global 一组；per-dir 按 path 的目录分组）；2) 对每个特征计算香农熵 −Σp·log2(p)；3) 取组内所有特征的最大熵作为该组 fragmentationScore；4) score > entropyThreshold 的组标记为 'fragmented'；5) 返回 `{ groups:Array<{scope:string, score:number, status:string, topFeature:string}>, overallFragmented:boolean }`。边界：files 空返回空 groups；单文件熵为 0。

```javascript
function detectStyleFragmentation(files = [], opts = {}) {
  const { entropyThreshold = 0.6, scope = 'global' } = opts;
  const groupsMap = new Map();
  for (const f of files) {
    const key = scope === 'per-dir' ? f.path.replace(/\/[^/]+$/, '') || '/' : 'global';
    if (!groupsMap.has(key)) groupsMap.set(key, []);
    groupsMap.get(key).push(f.features);
  }
  const features = ['quotes', 'semi', 'arrowFn', 'asyncAwait'];
  const entropy = (vals) => {
    const m = new Map();
    for (const v of vals) { const k = String(v); m.set(k, (m.get(k) || 0) + 1); }
    const ps = [...m.values()].map(c => c / vals.length);
    return -ps.reduce((s, p) => s + p * Math.log2(p), 0);
  };
  const groups = [...groupsMap.entries()].map(([name, feats]) => {
    let best = { feature: '', score: 0 };
    for (const feat of features) {
      const e = entropy(feats.map(f => f[feat]));
      if (e > best.score) best = { feature: feat, score: e };
    }
    return {
      scope: name,
      score: best.score,
      topFeature: best.feature,
      status: best.score > entropyThreshold ? 'fragmented' : 'ok',
    };
  });
  return { groups, overallFragmented: groups.some(g => g.status === 'fragmented') };
}

// 自测
const files = [
  { path: 'src/a.ts', features: { quotes: 'single', semi: true, arrowFn: true, asyncAwait: true } },
  { path: 'src/b.ts', features: { quotes: 'double', semi: false, arrowFn: true, asyncAwait: true } },
  { path: 'src/c.ts', features: { quotes: 'single', semi: true, arrowFn: true, asyncAwait: true } },
];
console.log(detectStyleFragmentation(files).overallFragmented === true); // quotes/semi 有分歧
console.log(detectStyleFragmentation(files.slice(0, 1)).groups[0].score === 0); // 单文件无熵
console.log(detectStyleFragmentation([]).groups.length === 0);
```

**评分点**：
- 香农熵计算正确（−Σp·log2(p)）
- scope 分组：global vs per-dir 路径提取
- 取最大熵特征作为割裂分，status 按阈值判定
- 边界：空 files、单文件熵为 0
- 能说清「语法层割裂用 Formatter 兜底，模式层割裂（asyncAwait 等）要靠 rules + review，量化熵能定位问题模块」属于加分
