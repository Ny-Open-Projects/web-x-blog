## AIC-950：笔试：实现「上下文压缩器」（重要性打分 + 有损/无损分级压缩）
**答**：
- 核心需求：实现 `compressContext(segments, budget, opts)`。`segments: { id, text, kind, priority }[]`。返回 `{ kept, dropped, mode, ratio }`。
- 分级策略：① 无损层——对 `kind` 为 system/constraint 的段原样保留；② 有损层——对其他段按 priority 排序，预算内原样保留，超预算时对最低优先级段做「摘要」（取首句 + 关键行）而非直接丢弃；③ 仍超预算才丢弃。
- 摘要函数 `summarize(text)`：取首行 + 包含关键字（如 export/interface/const/return）的行，拼成精简版，长度不超过原长 30%。
- 边界：budget 是字符数；空 segments 返回空；budget=0 时仅保留无损层；ratio = 输出总长 / 输入总长。
- 语义：有损压缩要标注「已摘要」，让 AI/人知道内容不完整——结论：压缩的代价是信息损失，必须显式标记以便谨慎对待。
- 追问钩子：能指出「摘要是有损的，关键约束必须走无损层；压缩后应验证无损层完整保留」的候选人理解分级压缩的安全边界。

```typescript
function summarize(text) {
  const lines = String(text).split('\n');
  const key = lines.filter(l => /\b(export|interface|type|const|return|class)\b/.test(l));
  const out = [lines[0], ...key].filter(Boolean).join('\n');
  return out.slice(0, Math.max(20, Math.floor(text.length*0.3)));
}
function compressContext(segments=[], budget=0, opts={}) {
  const lossless = segments.filter(s=>['system','constraint'].includes(s.kind));
  const rest = segments.filter(s=>!['system','constraint'].includes(s.kind))
    .slice().sort((a,b)=>b.priority-a.priority);
  const kept=[], dropped=[];
  let used = lossless.reduce((s,x)=>s+x.text.length,0);
  kept.push(...lossless.map(s=>({...s, mode:'lossless'})));
  for (const s of rest) {
    if (used + s.text.length <= budget) { kept.push({...s,mode:'lossless'}); used+=s.text.length; }
    else {
      const sm = summarize(s.text);
      if (used + sm.length <= budget) { kept.push({...s,text:sm,mode:'lossy'}); used+=sm.length; }
      else dropped.push(s.id);
    }
  }
  const inLen=segments.reduce((s,x)=>s+x.text.length,0)||1;
  return { kept, dropped, ratio:+(used/inLen).toFixed(2) };
}
console.log(compressContext([{id:1,kind:'constraint',text:'never hardcode',priority:1},
  {id:2,kind:'code',text:'const a=1\nconst b=2',priority:2}], 10).kept.map(k=>k.mode));
```
**评分点**：
- 无损层（system/constraint）原样保留，不参与摘要。
- 有损层按 priority 排序，超预算时 summarize 摘要（首行+关键行，≤30%）。
- summarize 提取 export/interface/const/return 等关键行，实现合理。
- budget=0/空输入/ratio 计算等边界处理正确。
- 有损段标注 mode:lossy（显式标记信息损失），代码可运行。
