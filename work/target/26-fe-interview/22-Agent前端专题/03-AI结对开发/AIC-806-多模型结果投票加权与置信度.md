## AIC-806：多模型投票的结果，如何计算「置信度」而不是简单少数服从多数？
**答**：
- 简单多数忽略两个事实：不同模型**可靠性不同**（专业模型权重应更高），不同答案的**边际不同**（3:2 比 5:0 心虚得多）。所以置信度要综合「支持率 × 边际 × 模型可靠性」。
- 一种可用公式：`confidence = agreementRatio × margin × avgReliability`，其中 `agreementRatio = 最高票数/总票数`，`margin = (最高票-次高票)/总票数`，`avgReliability` 取投票模型的历史准确率加权平均。
- 模型可靠性要**动态更新**：用历史任务上「该模型答案与最终真相一致率」做 EWMA，避免一次评测定终身。
- 低置信度不是返回答案，而是**触发仲裁**：交给更强的裁判模型或人工，或返回多个候选让调用方决策；要设阈值分级处理。
- 追问钩子：追问「模型之间存在相关性怎么办」——能指出「同源模型（如同一厂商不同版本）票高度相关，等价于一票，要去相关或分组」的候选人非常有深度。

```typescript
type Vote = { modelId: string; answer: string; reliability: number };

function aggregate(votes: Vote[]) {
  if (!votes.length) return { answer: null, confidence: 0 };
  const tally = new Map<string, { count: number; relSum: number }>();
  for (const v of votes) {
    const t = tally.get(v.answer) ?? { count: 0, relSum: 0 };
    t.count += 1;
    t.relSum += v.reliability;
    tally.set(v.answer, t);
  }
  const ranked = [...tally.entries()]
    .map(([answer, t]) => ({ answer, ...t }))
    .sort((a, b) => b.count - a.count);
  const [top, second] = ranked;
  const total = votes.length;
  const agreementRatio = top.count / total;
  const margin = (top.count - (second?.count ?? 0)) / total;
  const avgReliability = top.relSum / top.count;
  const confidence = agreementRatio * (0.5 + 0.5 * margin) * avgReliability;
  return { answer: top.answer, confidence: +confidence.toFixed(3) };
}

const votes = [
  { modelId: 'm1', answer: 'A', reliability: 0.9 },
  { modelId: 'm2', answer: 'A', reliability: 0.8 },
  { modelId: 'm3', answer: 'B', reliability: 0.7 },
];
const res = aggregate(votes);        // A，高支持率但 2:1 边际，置信度适中
if (res.confidence < 0.6) console.log('触发仲裁 / 人工复核', res);
```
