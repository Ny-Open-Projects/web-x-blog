## AIC-561：笔试：手写人机分工路由器

**答**：实现 `routeReview(items)`。items: `{ type: 'mechanical'|'needs-human', description, autoFixable? }[]`. 规则：1) mechanical 且 autoFixable → 'auto-fixed'（自动修——零人工）；2) mechanical 且 !autoFixable → 'ai-flagged'（AI 标记但人需要知道）；3) needs-human → 'human-review'；4) 返回 `{ autoFixed: string[], aiFlagged: string[], humanReview: string[], summary: { autoFixed: n, aiFlagged: n, humanReview: n, humanTimeSaved: string } }`。边界：items 空（全 zero）；全 mechanical 且 autoFixable（全自动——humanReview 空）；全 needs-human（全自动零——全部人工）。

```javascript
function routeReview(items = []) {
  const autoFixed = [], aiFlagged = [], humanReview = [];
  for (const item of items) {
    if (item.type === 'mechanical' && item.autoFixable) {
      autoFixed.push(item.description);
    } else if (item.type === 'mechanical') {
      aiFlagged.push(item.description);
    } else if (item.type === 'needs-human') {
      humanReview.push(item.description);
    }
  }
  return {
    autoFixed, aiFlagged, humanReview,
    summary: {
      autoFixed: autoFixed.length, aiFlagged: aiFlagged.length,
      humanReview: humanReview.length,
      humanTimeSaved: `${autoFixed.length} 项自动修复，人审减少 ${autoFixed.length} 项`,
    },
  };
}

// 自测
const items = [
  { type: 'mechanical', description: 'import 排序', autoFixable: true },
  { type: 'mechanical', description: '引号统一', autoFixable: true },
  { type: 'mechanical', description: '未使用变量', autoFixable: false },
  { type: 'needs-human', description: '边界条件：user 可能为 null' },
  { type: 'needs-human', description: '架构决策：是否用 server component' },
];
let r = routeReview(items);
console.log(r.autoFixed.length === 2);                   // import + 引号
console.log(r.aiFlagged.length === 1);                   // 未使用变量
console.log(r.humanReview.length === 2);                 // 边界 + 架构
console.log(r.summary.humanTimeSaved.includes('2 项'));

// 全自动
r = routeReview(items.filter(i => i.autoFixable));
console.log(r.humanReview.length === 0);                 // 全自动——人审为零

// 全人工
r = routeReview(items.filter(i => i.type === 'needs-human'));
console.log(r.autoFixed.length === 0 && r.humanReview.length === 2);
// 空
console.log(routeReview([]).summary.autoFixed === 0);
```

**评分点**：
- 三类路由：auto-fixed（AI 自动修）/ ai-flagged（AI 标记人知道）/ human-review（人工审）
- humanTimeSaved 量化（AI 自动修节省的人审时间——RBL-944 效率叙事的数据锚点）；边界
- 分类的判断依据：mechanical = 规则可枚举（AI 擅长）；needs-human = 需要判断力（人擅长）
- 能说清「人机分工 = AI 筛机械问题（自动修 80%）→ 人只审 AI 不能判断的（意图/架构/安全直觉）」属于加分
