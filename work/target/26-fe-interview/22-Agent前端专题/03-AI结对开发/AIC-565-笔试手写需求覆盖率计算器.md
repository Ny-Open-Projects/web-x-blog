## AIC-565：笔试：手写需求覆盖率

**答**：实现 `requirementCoverage(requirements, code)`。requirements: `Requirement[]`（RBL-564 格式）；code: string。规则：1) 每条需求的关键词在 code 中的命中比例 ≥ 50% → covered；2) **覆盖率**：covered / total × 100；3) **未覆盖需求清单**：`Array<{ id, missingKeywords }>`——修复靶点 RBL-538；4) 返回 `{ coverage, covered: number, uncovered: Array<{ id, missing }>, details }`。边界：requirements 空（coverage 100）；code 空（coverage 0——全部 uncovered）；关键词全命中（covered）；关键词全未命中（uncovered）。

```javascript
function requirementCoverage(requirements = [], code = '') {
  if (!requirements.length)
    return { coverage: 100, covered: 0, uncovered: [], details: [] };
  const codeLower = code.toLowerCase();
  let covered = 0;
  const uncovered = [];
  const details = requirements.map(req => {
    const matched = req.keywords.filter(k => codeLower.includes(k.toLowerCase()));
    const isCovered = matched.length >= Math.ceil(req.keywords.length * 0.5);
    if (isCovered) covered++;
    else {
      const missing = req.keywords.filter(k => !codeLower.includes(k.toLowerCase()));
      uncovered.push({ id: req.id, missing });
    }
    return { id: req.id, matched, total: req.keywords.length, covered: isCovered };
  });
  return {
    coverage: +(covered / requirements.length * 100).toFixed(1),
    covered, uncovered, details,
  };
}

// 自测
const reqs = [
  { id: 'R1', keywords: ['login', 'password', 'session'] },
  { id: 'R2', keywords: ['search', 'filter', 'results'] },
  { id: 'R3', keywords: ['export', 'csv', 'download'] },
];
const code = `
  function handleLogin(password) { createSession(); }
  function searchWithFilter(query) { return filterResults(results); }
`;
let r = requirementCoverage(reqs, code);
console.log(r.coverage === 66.7);                       // R1/R2 covered, R3 not
console.log(r.covered === 2);
console.log(r.uncovered[0].id === 'R3');
console.log(r.uncovered[0].missing.includes('export'));
// details
console.log(r.details[0].covered === true);
console.log(r.details[2].covered === false);

// 空 code
r = requirementCoverage(reqs, '');
console.log(r.coverage === 0 && r.uncovered.length === 3);
// 空 reqs
console.log(requirementCoverage([], 'code').coverage === 100);
```

**评分点**：
- 关键词命中率 ≥ 50% 的覆盖判定（宽松匹配——60% 关键词也覆盖）；coverage 百分比
- uncovered 清单（修复靶点 RBL-538——缺哪些关键词）；details 的逐需求明细
- 边界（空 reqs 100%/空 code 0%/全命中/全未命中）；R1/R2/R3 的差异化结果
- 能说清「需求覆盖率的自动化 = AI 代码与原始需求的对账：覆盖率 < 100% = 有需求被遗漏（意图漂移 RBL-538）」属于加分
