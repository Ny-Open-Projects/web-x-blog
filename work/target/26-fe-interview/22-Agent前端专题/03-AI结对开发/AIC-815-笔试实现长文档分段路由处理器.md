## AIC-815：笔试：实现长文档分段路由器，按模型窗口切分并带重叠下发
**答**：
- 核心需求：实现 `routeChunks(text, { maxTokens, overlapRatio, estimate })`，按 token 上限切分，相邻片段保留 `overlapRatio` 比例的重叠，返回 `{ text, tokenCount, start, end, index }[]`。`estimate` 为外部传入的 token 估算函数。
- 切分优先在换行边界，找不到换行再退化为按字符切；必须保证单段 tokenCount ≤ maxTokens，否则整体拒绝（避免死循环）。
- 边界：空文本返回 `[]`；`maxTokens <= 0` 抛错；overlap 过大导致无法前进时强制至少前进一个 token；片段 index 连续。
- 追问钩子：追问「overlap 会不会导致同一内容被重复计费」——能答出「会，所以 overlap 比例要权衡召回与成本，通常 10%~15%」的候选人有成本意识。

```typescript
type Opts = { maxTokens: number; overlapRatio?: number; estimate: (s: string) => number };
type Chunk = { text: string; tokenCount: number; start: number; end: number; index: number };

function routeChunks(text: string, opts: Opts): Chunk[] {
  const { maxTokens, estimate } = opts;
  const ratio = opts.overlapRatio ?? 0.12;
  if (maxTokens <= 0 || typeof estimate !== 'function') throw new Error('bad opts');
  if (!text) return [];

  const chunks: Chunk[] = [];
  let cursor = 0;
  while (cursor < text.length) {
    let end = Math.min(text.length, cursor + maxTokens * 2); // 字符上界粗定位
    // 收缩直到 token 数在上限内
    while (end > cursor && estimate(text.slice(cursor, end)) > maxTokens) {
      const nl = text.lastIndexOf('\n', end - 1);          // 优先断在换行
      const next = nl > cursor ? nl : end - 1;
      if (next === end - 1 && estimate(text.slice(cursor, end - 1)) > maxTokens) end = end - 1;
      else end = next;
    }
    const piece = text.slice(cursor, end);
    if (!piece) throw new Error('cannot fit maxTokens'); // 单词超长，拒绝
    chunks.push({ text: piece, tokenCount: estimate(piece), start: cursor, end,
      index: chunks.length });
    const overlap = Math.floor(piece.length * ratio);
    const advance = Math.max(1, end - cursor - overlap);   // 至少前进 1 字符
    cursor += advance;
  }
  return chunks;
}

const est = (s: string) => Math.ceil(s.length / 2);
const chunks = routeChunks('第一段内容\n\n第二段内容\n\n第三段内容',
  { maxTokens: 4, estimate: est, overlapRatio: 0.2 });
console.log(chunks.map(c => c.index)); // [0,1,2...]
```
**评分点**：
- 单段 tokenCount 严格 ≤ maxTokens，靠循环收缩保证，不靠一次切片猜。
- 优先换行边界切分，退化路径正确处理，不死循环。
- overlap 计算用字符长度，`advance` 至少为 1，避免 ratio 过大导致原地打转。
- 空输入 / 非法 maxTokens 的边界处理到位。
- 返回 start/end/index 元信息便于溯源与计费，体现工程完整性。
