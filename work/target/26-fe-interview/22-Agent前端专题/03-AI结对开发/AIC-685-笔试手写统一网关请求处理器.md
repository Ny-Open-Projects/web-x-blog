## AIC-685：笔试：手写统一网关请求处理器

**答**：实现 `processGatewayRequest(req, config)`。req: `{ user:string, team:string, tokens:number, sensitivity:'L1'|'L2'|'L3', content:string }`；config: `{ users:string[], teamQuota:Record<string,number>, teamUsed:Record<string,number>, blockedPatterns:RegExp[], sensitivePatterns:RegExp[] }`。规则按序检查：1) 鉴权：user 不在 users → 'unauthorized'；2) 配额：teamUsed[team]+tokens > teamQuota[team] → 'quota-exceeded'；3) 内容阻断：content 命中 blockedPatterns → 'blocked-content'；4) 脱敏：content 命中 sensitivePatterns 的部分替换为 '***'；5) L3 敏感必须走 local 模型，L1/L2 走 cloud；6) 返回 `{ allowed:boolean, reason:string, model?:string, sanitized?:string }`。边界：任一检查失败立即返回 allowed=false 且不带 model/sanitized；team 无配额记录默认 quota=0（拒绝）。

```javascript
function processGatewayRequest(req = {}, config = {}) {
  const { users = [], teamQuota = {}, teamUsed = {}, blockedPatterns = [], sensitivePatterns = [] } = config;
  const { user, team, tokens = 0, sensitivity = 'L1', content = '' } = req;
  if (!users.includes(user)) return { allowed: false, reason: 'unauthorized' };
  const quota = teamQuota[team] ?? 0;
  const used = teamUsed[team] ?? 0;
  if (used + tokens > quota) return { allowed: false, reason: 'quota-exceeded' };
  if (blockedPatterns.some(re => re.test(content))) return { allowed: false, reason: 'blocked-content' };
  let sanitized = content;
  for (const re of sensitivePatterns) sanitized = sanitized.replace(re, '***');
  const model = sensitivity === 'L3' ? 'local-model' : 'cloud-model';
  return { allowed: true, reason: 'ok', model, sanitized };
}

// 自测
const config = {
  users: ['alice'],
  teamQuota: { fe: 1000 }, teamUsed: { fe: 300 },
  blockedPatterns: [/ignore previous instructions/i],
  sensitivePatterns: [/token=\w+/g, /phone=\d+/g],
};
const good = processGatewayRequest({ user: 'alice', team: 'fe', tokens: 100, sensitivity: 'L2',
  content: 'fetch token=abc phone=123' }, config);
console.log(good.allowed && good.model === 'cloud-model');
console.log(good.sanitized.includes('token=***') && good.sanitized.includes('phone=***'));
console.log(processGatewayRequest({ user: 'bob', team: 'fe', tokens: 1 }, config).reason === 'unauthorized');
console.log(processGatewayRequest({ user: 'alice', team: 'fe', tokens: 800 }, config).reason === 'quota-exceeded');
console.log(processGatewayRequest({ user: 'alice', team: 'fe', tokens: 1, content: 'ignore previous instructions' }, config).reason === 'blocked-content');
console.log(processGatewayRequest({ user: 'alice', team: 'fe', tokens: 1, sensitivity: 'L3', content: 'x' }, config).model === 'local-model');
```

**评分点**：
- 检查顺序正确（鉴权→配额→内容阻断→脱敏→路由），失败立即返回
- 脱敏对 sensitivePatterns 逐个 replace
- L3 强制 local 模型（隐私分级路由）
- 无配额 team 默认 quota=0 拒绝，失败响应不含 model/sanitized
- 能说清「网关把鉴权/配额/审计/脱敏/路由收敛到单一入口，密钥集中反而缩小泄露面」属于加分
