## AIC-909：大促秒杀的库存扣减让 AI 生成，如何用「差分测试」和人工实现对比来建立信心？
**答**：
- 差分测试的核心是「同一输入喂给两个实现，输出必须一致」：AI 实现 vs 经过验证的人工/旧实现，在大量随机与边界输入上比对结果。
- 要先确认「参考实现」本身可信——如果基准是错的，差分只会把错误复制到新实现，这是最常见的陷阱。
- 差异出现要分类：是 AI 实现错了、参考实现对新需求已过时、还是需求本身有歧义——不能默认 AI 错。
- 高并发场景差分还要覆盖「时序」：单线程结果一致不代表并发下一致，需引入并发输入模型。
- 追问钩子：能说出「差分只能证明与参考等价，不能证明正确；参考实现的可信度决定差分价值」的候选人，理解验证的相对性。

```typescript
// 差分测试：AI 实现 vs 参考实现
function differential(aiImpl, refImpl, cases) {
  const diffs = [];
  for (const c of cases) {
    let a, r;
    try { a = aiImpl(c.stock, c.n); } catch (e) { a = 'ERR:' + e.message; }
    try { r = refImpl(c.stock, c.n); } catch (e) { r = 'ERR:' + e.message; }
    if (a !== r) diffs.push({ input:c, ai:a, ref:r });
  }
  return { pass: diffs.length === 0, diffs };
}
const cases = [];
for (let s = 0; s < 50; s++) for (let n = -2; n < 20; n++) cases.push({ stock:s, n });
const ref = (s,n) => Math.max(0, s - Math.max(0, n)); // 已验证参考实现
console.log(differential((s,n)=>Math.max(0,s-n), ref, cases).pass);
```
