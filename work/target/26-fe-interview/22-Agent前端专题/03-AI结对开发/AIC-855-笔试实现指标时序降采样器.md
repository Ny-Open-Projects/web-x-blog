## AIC-855：笔试：实现指标时间序列降采样器（保留异常点）
**答**：
- 核心需求：实现 `downsample(points, bucketMs, keepAnomalies)`。将时序点按时间桶聚合（每桶取均值），但当 use keepAnomalies=true 时，桶内偏离桶均值超过 `2σ` 的点必须原样保留，不被均值抹平。
- 边界：空输入返回 `[]`；单点桶直接保留；`bucketMs <= 0` 抛错；保留异常点时同一桶输出「聚合点 + 异常点」多条记录，用 `isAnomaly` 标记；输出按时间排序。
- 语义：降采样用于长期存储与看板绘制，但**不能把异常抹掉**——这正是效能监控里最致命的问题（「平均值掩盖了那次事故」）。
- 追问钩子：追问「为什么不直接保留 max/min」——能答出「max/min 在正常波动时也会保留噪声，而 2σ 异常检测只保留统计显著的点」的候选人理解信噪取舍。

```typescript
type Point = { t: number; v: number };
type Out = { t: number; v: number; isAnomaly?: boolean; bucketStart?: number };

function downsample(points: Point[], bucketMs: number, keepAnomalies = true): Out[] {
  if (bucketMs <= 0) throw new Error('bucketMs must be positive');
  const buckets = new Map<number, Point[]>();
  for (const p of points ?? []) {
    const k = Math.floor(p.t / bucketMs) * bucketMs;
    buckets.set(k, [...(buckets.get(k) ?? []), p]);
  }
  const out: Out[] = [];
  for (const [start, ps] of buckets) {
    const mean = ps.reduce((s, p) => s + p.v, 0) / ps.length;
    const std = Math.sqrt(ps.reduce((s, p) => s + (p.v - mean) ** 2, 0) / ps.length) || 1e-9;
    out.push({ t: start, v: +mean.toFixed(2), bucketStart: start });
    if (keepAnomalies) {
      for (const p of ps) {
        if (Math.abs(p.v - mean) > 2 * std)
          out.push({ t: p.t, v: p.v, isAnomaly: true, bucketStart: start });
      }
    }
  }
  return out.sort((a, b) => a.t - b.t);
}
const series = Array.from({ length: 10 }, (_, i) => ({ t: i * 1000, v: 100 }));
series[5].v = 500; // 注入尖峰
console.log(downsample(series, 5000, true));
// 桶均值被拉高，但 500 这个异常点被原样保留，不会被抹平
```
**评分点**：
- 桶键用 `Math.floor(t/bucketMs)*bucketMs` 正确对齐时间窗口。
- 异常检测用 2σ，且 std 加 `|| 1e-9` 防常量序列除零。
- 异常点原样保留并带 isAnomaly 标记，不被均值覆盖。
- 输出按时间排序，单点桶/空输入/非法 bucketMs 边界处理完整。
- 能解释「为何不能只存 max/min」体现对监控语义的理解。
