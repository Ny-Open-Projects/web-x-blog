## AIC-457：笔试：按周聚合 AI 采纳率趋势并检测劣化。
**答**：记录 `[{week, adopted, total}]`，输出每周采纳率；若最近一周比前四周均值低 20%（相对）则 `degraded:true` 并给出降幅。

```javascript
function weeklyAdoption(records) {
  const byWeek = new Map();
  for (const r of records) {
    const w = byWeek.get(r.week) ?? { adopted: 0, total: 0 };
    w.adopted += r.adopted; w.total += r.total;
    byWeek.set(r.week, w);
  }
  const series = [...byWeek].sort((a, b) => a[0] - b[0])
    .map(([week, w]) => ({ week, rate: w.total ? w.adopted / w.total : 0, total: w.total }))
    .filter(s => s.total > 0);
  if (series.length < 2) return { series, degraded: false, insufficient: true };
  const last = series[series.length - 1];
  const base = series.slice(0, -1);
  const avg = base.reduce((s, x) => s + x.rate, 0) / base.length;
  const degraded = last.rate < avg * 0.8;
  return { series, degraded, baseline: +avg.toFixed(2), drop: degraded ? +((1 - last.rate / avg)).toFixed(2) : 0 };
}
console.log(weeklyAdoption([
  { week: 1, adopted: 8, total: 10 }, { week: 2, adopted: 8, total: 10 },
  { week: 3, adopted: 3, total: 10 },
])); // degraded: true（0.3 < 0.8×0.8）

```

**评分点**：
- 周率计算 + 除零保护（total=0 的周跳过均值）。
- 劣化判定用相对降幅（均值×0.8 阈值）。
- 数据不足 2 周不判定（返回 insufficient）。
- 输出含 baseline 便于汇报。
