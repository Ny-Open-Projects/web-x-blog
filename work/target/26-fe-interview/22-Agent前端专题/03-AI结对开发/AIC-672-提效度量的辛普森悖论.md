## AIC-672：整体提效但局部退化——辛普森悖论怎么破？

**答**：
- 结论先行：**整体平均值会掩盖分组真相——必须「分层看数据」**。AI 提效常见假象：整体交付变快，是因为「简单任务占比变多」，而核心复杂任务其实变慢了（AI 在复杂任务上反而添乱）。
- 辛普森悖论在 AI 度量的表现：1) 按「任务复杂度」分层——AI 让简单任务快 50%、复杂任务慢 20%，整体看是涨的（因为简单任务多），但复杂任务（真正值钱的）在退化；2) 按「人员经验」分层——新手涨、Senior 降（Senior 审 AI 代码的成本高于自己写），整体涨掩盖了高价值人才的负收益；3) 按「模块」分层——展示层涨、核心链路退化。
- 破解方法：1) **强制分层**：任何提效结论都要按复杂度/经验/模块至少一维拆开看；2) **看分布不看均值**：中位数、P90、分箱直方图——均值被极端值带偏；3) **看结构变化**：任务构成是否变了？简单任务占比上升会让平均值虚高。
- 追问钩子：为什么「Senior 变慢」特别值得警惕？——因为 Senior 承担的是高价值复杂任务；如果 AI 让 Senior 变慢（他们要花更多时间审查和纠正 AI 的低质量产出），整体数据的提升可能只是「低价值任务被 AI 加速」的假象，团队真正的核心能力在被侵蚀。

```typescript
type Task = { complexity: 'simple'|'complex'; withoutAI: number; withAI: number };

function stratifiedAnalysis(tasks: Task[]) {
  const byComplexity = {};
  for (const level of ['simple', 'complex'] as const) {
    const g = tasks.filter(t => t.complexity === level);
    if (!g.length) continue;
    byComplexity[level] = {
      improvement: (g.reduce((s, t) => s + t.withoutAI, 0) - g.reduce((s, t) => s + t.withAI, 0))
        / g.reduce((s, t) => s + t.withoutAI, 0),
    };
  }
  const totalBefore = tasks.reduce((s, t) => s + t.withoutAI, 0);
  const totalAfter = tasks.reduce((s, t) => s + t.withAI, 0);
  return {
    overallImprovement: (totalBefore - totalAfter) / totalBefore,
    byComplexity,
    // 整体涨但某层负增长 = 辛普森悖论
    simpsonParadox: Object.values(byComplexity).some((v: any) => v.improvement < 0)
      && totalAfter < totalBefore,
  };
}

const tasks: Task[] = [
  { complexity: 'simple', withoutAI: 10, withAI: 5 },    // 快50%
  { complexity: 'simple', withoutAI: 10, withAI: 5 },
  { complexity: 'complex', withoutAI: 30, withAI: 36 },  // 慢20%
];
const r = stratifiedAnalysis(tasks);
console.log(r.overallImprovement > 0);               // 整体涨 (50→46)
console.log((r.byComplexity as any).complex.improvement < 0); // 但复杂任务退化
console.log(r.simpsonParadox === true);
```
