## AIC-868：笔试：实现语义化版本兼容性检查器（SemVer 比较与 breaking 判定）
**答**：
- 核心需求：实现 `parseVersion(s)`（返回 `{ major, minor, patch }`，非法返回 null）与 `checkCompat(from, to, hasBreaking)`。`checkCompat` 返回 `{ level: 'major'|'minor'|'patch'|'invalid', compatible: boolean, reason }`。
- 规则：非法版本 → invalid/不兼容；`hasBreaking` 为 true 但 major 未变 → 不兼容（破坏性变更必须升 major）；major 变化 → 不兼容（无论是否声明 breaking）；minor/patch 变化且无 breaking → 兼容（允许新功能/修复）。
- 边界：版本号允许前导 `v`（如 `v1.2.3`）；比较大小按 major→minor→patch 字典序；缺失 minor/patch 视为 0（如 `1` = `1.0.0`）；负数/非数字视为非法。
- 追问钩子：追问「为什么破坏性变更必须升 major」——能答出「版本是给消费方的升级信号，major 变更让包管理器不会自动升级，避免半夜被 breaking change 打挂」的候选人理解 SemVer 的社会契约属性。

```typescript
function parseVersion(s: string) {
  if (typeof s !== 'string') return null;
  const m = s.trim().replace(/^v/, '').match(/^(\d+)(?:\.(\d+))?(?:\.(\d+))?$/);
  if (!m) return null;
  return { major: +m[1], minor: +(m[2] ?? 0), patch: +(m[3] ?? 0) };
}
function compare(a: any, b: any) {
  return a.major - b.major || a.minor - b.minor || a.patch - b.patch;
}
function checkCompat(from: string, to: string, hasBreaking = false) {
  const f = parseVersion(from), t = parseVersion(to);
  if (!f || !t) return { level:'invalid' as const, compatible:false, reason:'非法版本号' };
  if (hasBreaking && f.major === t.major)
    return { level:'major' as const, compatible:false, reason:'破坏性变更必须升 major' };
  const c = compare(t, f);
  if (t.major !== f.major) return { level:'major' as const, compatible:false, reason:'major 变化' };
  if (c < 0) return { level:'major' as const, compatible:false, reason:'版本回退' };
  return {
    level: t.minor !== f.minor ? 'minor' as const : 'patch' as const,
    compatible: true, reason: hasBreaking ? '不应发生' : '向后兼容',
  };
}
console.log(checkCompat('1.2.0', '1.3.0'));              // compatible:true, minor
console.log(checkCompat('v1.2.0', 'v2.0.0', true));      // major 变更，正常 breaking
console.log(checkCompat('1.2.0', '1.3.0', true));        // false：breaking 未升 major
console.log(checkCompat('1', '1.0.1'));                  // compatible:true, patch
```
**评分点**：
- parseVersion 支持前导 v 与缺省 minor/patch（补 0），非法输入返回 null。
- 破坏性变更未升 major 判为不兼容（核心得分点）。
- 版本回退判为不兼容，compare 按 major→minor→patch 字典序。
- 非法版本 → invalid 而非抛异常，返回结构完整。
- 能解释 SemVer 作为「升级信号」的社会契约是加分项。
