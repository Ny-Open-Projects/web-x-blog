## AIC-614：笔试：手写紧急度-验证强度自适应决策器

**答**：实现 `adaptVerification(signal, aiTrust)`。signal: `{ severity:'P0'|'P1'|'P2', timeToDeadlineMin:number, blastRadius:number }`（严重度/距截止分钟/影响面 0-100）；aiTrust: `{ reviewCoverage:number, historicalBugRate:number }`（AI 产出审查覆盖率 0-100/历史缺陷率 0-1）。规则：1) 基础强度：P0=3, P1=2, P2=1；2) 紧急加成：timeToDeadlineMin < 30 时 +1（越急越要加强验证，因为审查注意力低），但上限 4；3) AI 风险加成：historicalBugRate > 0.1 或 reviewCoverage < 50 时 +1；4) 影响面加成：blastRadius > 70 时 +1；5) 返回 `{ level:number (1-4), checks:string[], reason:string }`，checks 按 level 映射：1=['type','unit'], 2=[+regression], 3=[+e2e,security], 4=[+canary,manual-approval]。边界：输入字段缺失用默认值（severity=P2, 其余 0）。

```javascript
function adaptVerification(signal = {}, aiTrust = {}) {
  const { severity = 'P2', timeToDeadlineMin = 999, blastRadius = 0 } = signal;
  const { reviewCoverage = 100, historicalBugRate = 0 } = aiTrust;
  let level = severity === 'P0' ? 3 : severity === 'P1' ? 2 : 1;
  const reasons = [];
  if (timeToDeadlineMin < 30) { level++; reasons.push('deadline<30min'); }
  if (historicalBugRate > 0.1 || reviewCoverage < 50) { level++; reasons.push('low-ai-trust'); }
  if (blastRadius > 70) { level++; reasons.push('large-blast-radius'); }
  level = Math.min(4, Math.max(1, level));
  const layers = [['type', 'unit'], ['regression'], ['e2e', 'security'], ['canary', 'manual-approval']];
  const checks = layers.slice(0, level).flat();
  return { level, checks, reason: reasons.join('+') || 'baseline' };
}

// 自测
console.log(adaptVerification({ severity: 'P2', timeToDeadlineMin: 999, blastRadius: 10 }, {}).level); // 1
console.log(adaptVerification({ severity: 'P0', timeToDeadlineMin: 20, blastRadius: 90 },
  { reviewCoverage: 30, historicalBugRate: 0.2 }).level); // 4 (封顶)
console.log(adaptVerification({ severity: 'P0', timeToDeadlineMin: 20, blastRadius: 90 },
  { reviewCoverage: 30, historicalBugRate: 0.2 }).checks.includes('canary')); // true
console.log(adaptVerification({}, {}).level); // 1 (默认)
```

**评分点**：
- 基础强度按 severity 正确映射（P0=3/P1=2/P2=1）
- 紧急加成逻辑正确：越急 level 越高（反直觉但正确，因审查注意力低）
- AI 风险加成：缺陷率高或审查覆盖率低时加严
- level clamp 1-4 且 checks 分层映射完整
- 能说清「紧急场景不降低验证而是收窄验证范围，且因 AI 不可信要提高关键项强度」属于加分
