## AIC-624：团队 AI 协作从「单次生成」到「持续协同」的成熟度怎么分？

**答**：
- 结论先行：成熟度分四级——**L1 工具使用 → L2 流程嵌入 → L3 数据驱动 → L4 组织协同**。多数团队停在 L1，升级瓶颈不是工具而是流程与度量。
- L1 工具使用：个体用 AI 补全/生成代码，各自为战，无规范无度量；特征是「有人用得好，有人不用」，产出质量全看个人 prompt 水平。
- L2 流程嵌入：有团队 rules、规则文件、任务卡模板（AIC-510/102），AI 产出走统一 review 与门禁（AIC-537）；特征是「可复制」——新人按规范也能产出合格代码。
- L3 数据驱动：有结对日志、接受率/存活率/ROI 看板（AIC-623/142），用数据驱动 prompt 与规则优化；特征是「可改进」——知道哪里差、改了有没有效。
- L4 组织协同：AI 参与跨角色流程（产品→设计→代码→测试→运维），多 Agent 编排成常态，人聚焦架构与决策（AIC-390 跨职能 / AIC-084 多 Agent）；特征是「系统化」——AI 成为研发基础设施。
- 追问钩子：为什么「从 L1 到 L2」是最难的一级？——因为它要求个体改变工作习惯并接受流程约束，而 L1 的「自由随意」对个体短期最舒服；升级靠的不是买更好的工具，而是建立规范并让规范可见（规则进仓库、review 落地）。

```typescript
type Level = 1 | 2 | 3 | 4;
const MATURITY: Record<Level, { name: string; signals: string[]; bottleneck: string }> = {
  1: { name: '工具使用', signals: ['个体使用', '无规范'], bottleneck: '习惯改变' },
  2: { name: '流程嵌入', signals: ['rules', '门禁', '任务卡'], bottleneck: '规范落地' },
  3: { name: '数据驱动', signals: ['日志', '看板', 'ROI'], bottleneck: '度量可信度' },
  4: { name: '组织协同', signals: ['跨角色', '多Agent', '基础设施'], bottleneck: '组织变革' },
};

function assessMaturity(signals: string[]): Level {
  if (signals.includes('多Agent') && signals.includes('跨角色')) return 4;
  if (signals.includes('看板') && signals.includes('ROI')) return 3;
  if (signals.includes('rules') && signals.includes('门禁')) return 2;
  return 1;
}

console.log(assessMaturity(['个体使用']));                    // 1
console.log(assessMaturity(['rules', '门禁']));               // 2
console.log(assessMaturity(['rules', '看板', 'ROI']));        // 3
console.log(assessMaturity(['多Agent', '跨角色', 'ROI']));    // 4
```
