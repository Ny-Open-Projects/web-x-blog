## AIC-607：笔试：手写需求变更影响分析器

**答**：实现 `analyzeChangeImpact(assets, changedPaths, opts)`。assets: `{path:string, deps:string[], kind:'code'|'test'|'config'}[]`（依赖图）；changedPaths: `string[]`（需求变更直接涉及的文件）；opts: `{ includeTests?: boolean }`。规则：1) 直接影响：changedPaths 中的文件；2) 传递影响：依赖了直接受影响文件的其他文件（反向依赖，找「谁依赖了我」），递归直到不动点；3) 测试关联：若 includeTests（默认 true），与受影响源码同名的 `*.test.*` 文件也纳入；4) 返回 `{ direct:string[], transitive:string[], tests:string[], all:string[] }`，各数组去重且按路径排序。边界：changedPaths 为空返回全空；循环依赖需防死循环；文件不存在于 assets 时忽略。

```javascript
function analyzeChangeImpact(assets = [], changedPaths = [], opts = {}) {
  const { includeTests = true } = opts;
  const byPath = new Map(assets.map(a => [a.path, a]));
  // 反向依赖图：dep -> 依赖它的文件列表
  const reverse = new Map();
  for (const a of assets) {
    for (const dep of a.deps) {
      if (!reverse.has(dep)) reverse.set(dep, []);
      reverse.get(dep).push(a.path);
    }
  }
  const direct = [...new Set(changedPaths)].filter(p => byPath.has(p)).sort();
  // BFS 求传递影响
  const seen = new Set(direct);
  const queue = [...direct];
  while (queue.length) {
    const cur = queue.shift();
    for (const dependent of reverse.get(cur) || []) {
      if (!seen.has(dependent)) {
        seen.add(dependent);
        queue.push(dependent);
      }
    }
  }
  const transitive = [...seen].filter(p => !direct.includes(p)).sort();
  const tests = includeTests
    ? [...seen]
        .filter(p => byPath.get(p)?.kind === 'code')
        .map(p => p.replace(/(\.\w+)$/, '.test$1'))
        .filter(p => byPath.has(p))
        .sort()
    : [];
  return { direct, transitive, tests, all: [...direct, ...transitive, ...tests].sort() };
}

// 自测
const assets = [
  { path: 'a.ts', deps: [], kind: 'code' },
  { path: 'b.ts', deps: ['a.ts'], kind: 'code' },
  { path: 'c.ts', deps: ['b.ts'], kind: 'code' },
  { path: 'a.test.ts', deps: [], kind: 'test' },
];
const r = analyzeChangeImpact(assets, ['a.ts']);
console.log(r.direct.join(',') === 'a.ts');
console.log(r.transitive.join(',') === 'b.ts,c.ts'); // 反向依赖递归
console.log(r.tests.join(',') === 'a.test.ts');
console.log(analyzeChangeImpact(assets, []).all.length === 0);
```

**评分点**：
- 反向依赖图构建正确（找「谁依赖了我」而非正向依赖）
- BFS 递归到不动点 + seen 防循环依赖死循环
- 测试关联按同名 *.test.* 匹配且 includeTests 开关生效
- 边界处理：空变更/不存在文件/去重排序
- 能说清「变更影响分析的价值在于把 AI 的修改范围锁死在受影响文件内，避免全文重写」属于加分
