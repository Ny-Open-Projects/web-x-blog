## AIC-854：采集研发效能数据，隐私和合规的红线在哪里？
**答**：
- 红线一：**不采内容只采行为**——prompt 正文、代码片段、文件名可能含商业机密或个人隐私，默认不采；确需采样必须脱敏 + 明确授权 + 限定用途。
- 红线二：**不用于个人绩效考核**（除非有明确制度与法律程序）——监控开发者行为用于评价个人会引发抵触甚至违法风险（部分地区受劳动法/员工监测法规约束）。默认只做团队聚合。
- 红线三：**最小必要 + 限期留存**：只采回答业务问题所需的最少字段，设保留期（如 90 天），过期自动删除；原始明细与聚合数据分开存储，聚合数据无法反推个人。
- 合规流程：数据分类分级、访问审计（谁看了什么）、跨区域传输评估（数据出境）、向团队公开采集清单并允许申诉/退出。
- 追问钩子：能说出「默认只做团队聚合 + 个人数据不用于考核 + 保留期自动删除」三件套的候选人，理解数据体系的可持续前提是信任与合规。

```typescript
type Telemetry = { session: string; event: string; prompt?: string; code?: string; dev?: string };

function sanitize(t: Telemetry) {
  // 只保留行为元数据，剥离所有内容字段与直接身份标识
  const { session, event } = t;
  return { session: hash(session), event, ts: Date.now() };
}
function hash(s: string) { /* 不可逆哈希 + 盐 */ return 'h_' + s.length + '_' + s.charCodeAt(0); }

const policy = {
  collect: ['session', 'event', 'ts'],   // 白名单：只采这些
  forbid: ['prompt', 'code', 'dev'],     // 黑名单：明确禁止
  retentionDays: 90,
  personalUse: false,                    // 不用于个人考核
  aggregateOnly: true,                   // 默认团队聚合
};
function compliant(t: Telemetry) {
  const clean = sanitize(t);
  return { clean, policyCheck: policy.personalUse === false && policy.aggregateOnly };
}
console.log(compliant({ session:'s1', event:'accept', prompt:'机密 prompt', dev:'zhangsan' }).clean);
// { session:'h_2_115', event:'accept', ts:... } —— 内容已剥离
```
