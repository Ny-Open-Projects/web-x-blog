## AIC-423：笔试：实现评测题库季度轮换（替换 20%，旧题归档）。
**答**：`rotate(pool, ratio=0.2)`：按 lastUsed 最久优先替换出 ratio 数量，返回 `{active, archived}`；新题从 candidates 补足 active 数量；数量不足时保留旧题并输出 warning。

```javascript
function rotate(pool, candidates, ratio = 0.2) {
  const activeN = pool.filter(p => p.active).length;
  const outN = Math.floor(activeN * ratio);
  const active = pool.filter(p => p.active).sort((a, b) =>
    (a.lastUsed ?? 0) - (b.lastUsed ?? 0));        // 最久未用优先
  const out = active.slice(0, outN);
  const fill = candidates.slice(0, outN);
  const warnings = [];
  if (fill.length < outN) warnings.push(`candidates 不足：缺 ${outN - fill.length}，保留旧题`);
  const kept = out.slice(fill.length);             // 补不足的旧题继续在用
  return { active: [...active.slice(outN), ...kept, ...fill],
           archived: out.slice(0, fill.length).map(p => ({ ...p, active: false })),
           warnings };
}
console.log(rotate(
  [{ id: 1, active: true, lastUsed: 10 }, { id: 2, active: true, lastUsed: 20 }],
  [{ id: 9 }], 0.5)); // archived: [id1]，active 剩 id2 + id9

```

**评分点**：
- lastUsed 排序（null 视为最久）。
- 替换数量 = floor(active * ratio)，补足后 active 总数不变。
- candidates 不足时保留旧题 + warning——不静默缩减题库。
- 归档题目保留（可复用）而非删除。
