## AIC-667：笔试：手写有效采纳率计算器

**答**：实现 `computeEffectiveAdoption(events, opts)`。events: `{ userId:string, type:'install'|'request'|'accept'|'survive7d'|'rewrite', ts:number }[]`（按时间）；opts: `{ activeDaysMin?:number, surviveRatioMin?:number }`（默认 activeDaysMin=3, surviveRatioMin=0.5）。规则：1) 覆盖率 = 有 install 事件的用户数 / 总用户数（总用户数 = 所有出现过的 userId）；2) 活跃 = 有 request 事件的天数 ≥ activeDaysMin（按 ts 的日期去重）；3) 有效 = 有 accept 且 survive7d 数 / accept 数 ≥ surviveRatioMin，且活跃；4) 分层返回覆盖率、活跃率、有效率，各为 0-1；5) 接受率（全局）= accept 总数 / request 总数。边界：无用户全 0；某用户无 request 不算活跃也不算有效。

```javascript
function computeEffectiveAdoption(events = [], opts = {}) {
  const { activeDaysMin = 3, surviveRatioMin = 0.5 } = opts;
  const users = new Set(events.map(e => e.userId));
  if (users.size === 0) {
    return { coverage: 0, activeRate: 0, effectiveRate: 0, acceptRate: 0 };
  }
  const day = ts => new Date(ts).toDateString();
  const byUser = new Map();
  for (const u of users) byUser.set(u, { installed: false, days: new Set(), accept: 0, survive: 0 });
  let totalReq = 0, totalAccept = 0;
  for (const e of events) {
    const s = byUser.get(e.userId);
    if (e.type === 'install') s.installed = true;
    if (e.type === 'request') { s.days.add(day(e.ts)); totalReq++; }
    if (e.type === 'accept') { s.accept++; totalAccept++; }
    if (e.type === 'survive7d') s.survive++;
  }
  let installed = 0, active = 0, effective = 0;
  for (const s of byUser.values()) {
    if (s.installed) installed++;
    const isActive = s.days.size >= activeDaysMin;
    if (isActive) active++;
    const surviveRatio = s.accept ? s.survive / s.accept : 0;
    if (isActive && s.accept > 0 && surviveRatio >= surviveRatioMin) effective++;
  }
  return {
    coverage: installed / users.size,
    activeRate: active / users.size,
    effectiveRate: effective / users.size,
    acceptRate: totalReq ? totalAccept / totalReq : 0,
  };
}

// 自测（用不同日期毫秒）
const D = 86400000;
const events = [
  { userId: 'u1', type: 'install', ts: 0 },
  { userId: 'u1', type: 'request', ts: D }, { userId: 'u1', type: 'request', ts: 2*D },
  { userId: 'u1', type: 'request', ts: 3*D },
  { userId: 'u1', type: 'accept', ts: D }, { userId: 'u1', type: 'survive7d', ts: D },
  { userId: 'u2', type: 'install', ts: 0 }, // 装了不用
];
const r = computeEffectiveAdoption(events);
console.log(r.coverage === 1);          // 两人都 install
console.log(Math.abs(r.activeRate - 0.5) < 0.001);    // 只有 u1 活跃（3天）
console.log(Math.abs(r.effectiveRate - 0.5) < 0.001); // u1 存活率100%有效
console.log(computeEffectiveAdoption([]).coverage === 0);
```

**评分点**：
- 三层指标（覆盖/活跃/有效）计算逻辑正确
- 活跃按 request 事件的天数去重判定（≥activeDaysMin）
- 有效 = 活跃 且 存活率≥surviveRatioMin
- acceptRate = 全局 accept/request 总数
- 能说清「覆盖率/活跃率/有效率三层递进，只有有效率关联业务价值，接受率高但存活率低是假采纳」属于加分
