## AIC-875：老板问「建这个 AI 平台投了 10 个人月，值吗」，怎么评估收益？
**答**：
- 收益要分**硬收益**和**软收益**，别只讲「提升效率」这种空话。硬收益：接入团队数、能力复用次数（避免重复建设节省的人月）、模型成本下降（统一议价/缓存/路由）、发布周期缩短带来的业务价值。软收益：新人上手时间、满意度、事故恢复速度——要尽量找到代理指标量化。
- 关键算式：**节省 = 各团队若不自建所需投入之和 − 平台投入**。「5 个团队原本各自要接模型网关，每人 1 人月 = 5 人月；平台投入 3 人月 → 净赚 2 人月且长期复利」——这类对比最有说服力。
- 要用**反事实思维**：平台带来的提升有多少是平台功劳（AIC-847 归因）？用「接入前 vs 接入后」+ 「接入团队 vs 未接入团队」对照，诚实扣除大盘趋势。
- 设**止损点**：如果接入团队增长停滞、复用率低于阈值，说明平台没解决真痛点，要收缩或转向——平台也要有退出机制，不能因为已投入就硬撑（沉没成本谬误）。
- 追问钩子：能给出「复用节省 − 平台投入」的量化对比并用对照组归因的候选人，把技术平台讲成了商业case。

```typescript
type Team = { name: string; selfBuildMonths: number; adopted: boolean; beforeDays: number; afterDays: number };

function platformROI(teams: Team[], platformCostMonths: number) {
  const adopted = teams.filter(t => t.adopted);
  const avoided = adopted.reduce((s, t) => s + t.selfBuildMonths, 0); // 避免的重复建设
  const cycleGain = adopted.reduce((s, t) => s + (t.beforeDays - t.afterDays), 0) / (adopted.length || 1);
  const net = avoided - platformCostMonths;
  return {
    adoptedTeams: adopted.length,
    avoidedMonths: avoided,
    netMonths: net,                       // > 0 才说明划算
    avgCycleDaysSaved: +cycleGain.toFixed(1),
    verdict: net > 0 && adopted.length >= 2 ? 'positive' : 'reconsider',
    // 注意：cycleGain 未扣除大盘趋势，需对照未接入团队修正（AIC-847）
  };
}
console.log(platformROI([
  { name:'A', selfBuildMonths:2, adopted:true, beforeDays:10, afterDays:7 },
  { name:'B', selfBuildMonths:2, adopted:true, beforeDays:12, afterDays:8 },
  { name:'C', selfBuildMonths:1, adopted:false, beforeDays:9, afterDays:8 }, // 对照组
], 3)); // avoidedMonths 4, netMonths 1 → positive
```
