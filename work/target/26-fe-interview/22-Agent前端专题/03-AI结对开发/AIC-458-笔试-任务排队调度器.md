## AIC-458：笔试：实现 AI 任务冲突感知调度器。
**答**：任务 `[{id, files}]`。调度：同批任务文件无交集的并行（分桶），有交集的串行分批。输出批次 `[[id...], [id...]]`，最少批次数贪心即可，并输出冲突对清单。

```javascript
function schedule(tasks, maxConcurrent = Infinity) {
  const batches = [];
  const conflicts = [];
  for (let i = 0; i < tasks.length; i++) {
    const t = tasks[i];
    let placed = false;
    for (const b of batches) {
      const clash = b.some(id => {
        const o = tasks.find(x => x.id === id);
        return o.files.some(f => t.files.includes(f));
      });
      if (!clash && b.length < maxConcurrent) { b.push(t.id); placed = true; break; }
      if (clash) {
        b.forEach(id => {
          const key = [id, t.id].sort().join('|');
          if (!conflicts.includes(key)) conflicts.push(key);
        });
      }
    }
    if (!placed) batches.push([t.id]);
  }
  return { batches, conflicts };
}
console.log(schedule([
  { id: 'A', files: ['a.ts'] }, { id: 'B', files: ['b.ts'] }, { id: 'C', files: ['a.ts'] },
])); // batches [[A,B],[C]]，conflicts [A|C]

```

**评分点**：
- 贪心分桶：任务放进「与其无交集」的已有批次，否则新开批次。
- 冲突对：两任务文件交集非空即记录（去重）。
- 批次内任务数与并 发说明（受限于 agent 数量可选上限参数）。
- 空任务列表返回空批次。
