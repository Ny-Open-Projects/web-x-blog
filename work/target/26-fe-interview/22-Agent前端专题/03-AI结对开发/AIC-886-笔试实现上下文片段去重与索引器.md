## AIC-886：笔试：实现上下文片段去重与索引器（供 RAG 知识沉淀使用）
**答**：
- 核心需求：实现 `ContextIndex`。`add(fragment: { id, text, tags, ts })` 加入片段；加入时若与已有片段文本相似度（用词集合 Jaccard）> 0.85 则视为重复，归并（保留较新者，累加 reused 计数，记录 aliases）；`search(query, topK)` 按标签匹配 + 词重合度打分，返回 topK。
- 边界：空文本拒绝加入；标签大小写归一；相似度阈值可配；重复归并后 id 保留最新的但 aliases 含旧 id；搜索空结果返回 `[]`；ts 用于「新鲜度」加权（越新略优先）。
- 复杂度：朴素实现 O(n) 比较即可（片段量级有限）；能说出「海量时用向量索引（embedding + ANN）替代 Jaccard」是加分项。
- 追问钩子：追问「为什么不用精确去重」——能答出「AI 沉淀的表述常有细微差异（换个说法），精确去重会漏，模糊去重才能归并同义知识」的候选人理解知识治理的特点。

```typescript
type Fragment = { id: string; text: string; tags: string[]; ts: number; reused?: number; aliases?: string[] };

const words = (s: string) => new Set(s.toLowerCase().split(/\W+/).filter(Boolean));
const jaccard = (a: Set<string>, b: Set<string>) => {
  const inter = [...a].filter(x => b.has(x)).length;
  return inter / (a.size + b.size - inter || 1);
};

class ContextIndex {
  private items: Fragment[] = [];
  constructor(private threshold = 0.85) {}
  add(f: Fragment) {
    if (!f?.text?.trim()) return false;
    const normTags = f.tags.map(t => t.toLowerCase());
    const dup = this.items.find(x => jaccard(words(x.text), words(f.text)) > this.threshold);
    if (dup) {
      dup.aliases = [...(dup.aliases ?? []), dup.id, f.id]; // 归并旧 id
      dup.ts = Math.max(dup.ts, f.ts); dup.reused = (dup.reused ?? 0) + 1;
      dup.tags = [...new Set([...dup.tags, ...normTags])];
      return false;
    }
    this.items.push({ ...f, tags:normTags, reused:0 });
    return true;
  }
  search(query: string, topK = 3) {
    const q = words(query);
    return this.items.map(f => ({
      f,
      score: jaccard(q, words(f.text)) + 0.01 * (f.ts / Date.now()), // 相关度 + 新鲜度
    })).sort((a, b) => b.score - a.score).slice(0, topK).map(x => x.f);
  }
}
const idx = new ContextIndex();
idx.add({ id:'a', text:'长文档先分段再汇总', tags:['doc'], ts:1 });
idx.add({ id:'b', text:'长文档先分段再汇总！', tags:['DOC'], ts:2 }); // 归并
console.log(idx.search('长文档 分段', 1)[0].aliases); // ['a','b']
```
**评分点**：
- Jaccard 模糊去重，阈值可配，`|| 1` 防除零。
- 重复归并保留较新者、累加 reused、记录 aliases（可追溯）。
- 标签大小写归一，空文本拒绝，边界完整。
- 搜索综合相关度 + 新鲜度加权，topK 正确。
- 能提出海量场景用向量索引替代 Jaccard 是加分项。
