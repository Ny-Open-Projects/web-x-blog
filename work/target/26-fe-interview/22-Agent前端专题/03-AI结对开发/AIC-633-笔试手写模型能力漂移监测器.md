## AIC-633：笔试：手写模型能力漂移监测器

**答**：实现 `monitorDrift(records, opts)`。records: `{ model:string, taskId:string, ts:number, pass:boolean, latencyMs:number, cost:number }[]`（按时间排列的调用记录）；opts: `{ window:number (最近N条), minSamples:number, dropThreshold:number (0-1), latencySpike:number }`。规则：1) 按 model 分组，每组取最近 window 条；2) 样本数 < minSamples 标记 'insufficient'；3) 将最近 window 一分为二（前半/后半），若后半 passRate 比前半低 dropThreshold 以上 → 'quality-drop'；4) 后半平均 latency > 前半 × latencySpike → 'latency-spike'；5) 成本速率（cost/条）后半 > 前半 × 1.5 → 'cost-spike'；6) 返回 `Array<{model, status:'ok'|'insufficient'|'degraded', issues:string[], passRate:number}>`，status 有任一 issue 即 degraded。边界：records 空返回 []；样本刚好 minSamples 也参与检查。

```javascript
function monitorDrift(records = [], opts = {}) {
  const { window = 20, minSamples = 5, dropThreshold = 0.1, latencySpike = 1.5 } = opts;
  const byModel = new Map();
  for (const r of records) {
    if (!byModel.has(r.model)) byModel.set(r.model, []);
    byModel.get(r.model).push(r);
  }
  const out = [];
  for (const [model, arr] of byModel) {
    arr.sort((a, b) => a.ts - b.ts);
    const recent = arr.slice(-window);
    const issues = [];
    if (recent.length < minSamples) {
      out.push({ model, status: 'insufficient', issues: ['not-enough-samples'], passRate: 0 });
      continue;
    }
    const mid = Math.floor(recent.length / 2);
    const [first, second] = [recent.slice(0, mid), recent.slice(mid)];
    const rate = g => g.filter(r => r.pass).length / g.length;
    const avg = (g, k) => g.reduce((s, r) => s + r[k], 0) / g.length;
    const passRate = rate(second);
    if (rate(first) - passRate > dropThreshold) issues.push('quality-drop');
    if (avg(second, 'latencyMs') > avg(first, 'latencyMs') * latencySpike) issues.push('latency-spike');
    if (avg(second, 'cost') > avg(first, 'cost') * 1.5) issues.push('cost-spike');
    out.push({ model, status: issues.length ? 'degraded' : 'ok', issues, passRate });
  }
  return out;
}

// 自测
const base = 1000;
const recs = [];
for (let i = 0; i < 10; i++) {
  recs.push({ model: 'A', taskId: `t${i}`, ts: base + i, pass: i < 5, latencyMs: 100, cost: 1 });
  recs.push({ model: 'A', taskId: `u${i}`, ts: base + 10 + i, pass: false, latencyMs: 200, cost: 2 });
}
for (let i = 0; i < 10; i++) recs.push({ model: 'B', taskId: `b${i}`, ts: base + i, pass: true, latencyMs: 100, cost: 1 });
const r = monitorDrift(recs, { window: 20, minSamples: 5 });
console.log(r.find(x => x.model === 'A').issues.includes('quality-drop')); // true
console.log(r.find(x => x.model === 'A').status === 'degraded');
console.log(r.find(x => x.model === 'B').status === 'ok');
console.log(monitorDrift([]).length === 0);
```

**评分点**：
- 按 model 分组并按 ts 排序，取最近 window 条
- 前后半对比逻辑正确（passRate 下降 / latency 放大 / cost 放大）
- minSamples 不足标记 insufficient 且不与 degraded 混淆
- 三类 issue 独立判定，status 综合
- 能说清「漂移监测要用统计趋势（前后半对比）而非单点失败，且线上信号比定期跑分更早发现」属于加分
