## AIC-189：笔试：实现一个 Agent 权限分级器：三元组匹配、通配符资源、危险组合检测与最小权限建议？
**答**：实现 `checkPermission(perms, request)`：
- perms: `[{tool, resource(支持*通配), action}]`；request: `{tool, resource, action}`；
- 危险组合检测：terminal+exec 与 filesystem+write 同时存在时警告「可写文件系统+可执行=逃逸面」；
- 输出 `{allowed, matchedBy, warnings, advice}`；未匹配时给出「最接近的权限」建议（帮助配置者发现漏配）。

```javascript
function matchResource(pattern, resource) {
  const re = new RegExp('^' + pattern
    .replace(/[.+^${}()|[\]\\]/g, '\\$&')
    .replace(/\*\*/g, '.*').replace(/\*/g, '[^/]+') + '$');
  return re.test(resource);
}

function checkPermission(perms, request) {
  const hit = perms.find(p =>
    p.tool === request.tool && p.action === request.action &&
    matchResource(p.resource, request.resource));
  if (!hit) {
    const near = perms.filter(p => p.tool === request.tool)
      .map(p => `${p.tool}:${p.resource}:${p.action}`);
    return { allowed: false, matchedBy: null,
      advice: near.length ? `已有 ${near.join('; ')}，确认是否漏配 resource "${request.resource}"` : '该工具未授权' };
  }
  // 危险组合
  const hasExec = perms.some(p => p.tool === 'terminal' && p.action === 'exec');
  const hasWrite = perms.some(p => p.tool === 'filesystem' && p.action === 'write');
  const hasNet = perms.some(p => p.tool === 'network' && p.action === 'any');
  const warnings = [];
  if (hasExec && hasWrite) warnings.push('可执行+可写文件系统：存在自我修改/逃逸面，建议收紧 exec 到白名单命令');
  if (hasExec && hasNet) warnings.push('可执行+网络：存在外传风险，建议网络白名单');
  return { allowed: true, matchedBy: `${hit.tool}:${hit.resource}:${hit.action}`, warnings, advice: null };
}

// 测试
const perms = [
  { tool: 'filesystem', resource: 'src/**', action: 'write' },
  { tool: 'terminal', resource: 'npm test', action: 'exec' },
  { tool: 'network', resource: '*', action: 'any' },
];
console.log(checkPermission(perms, { tool: 'filesystem', resource: 'src/a.ts', action: 'write' }).allowed); // true
console.log(checkPermission(perms, { tool: 'filesystem', resource: 'package.json', action: 'write' }).advice);
console.log(checkPermission(perms, { tool: 'terminal', resource: 'npm test', action: 'exec' }).warnings.length > 0); // true 组合警告
```

**评分点**：
1. 通配符语义分层（`*` 单段、`**` 跨段）与正则转义完整性；
2. 危险组合检测（exec+write、exec+net）——权限审计看组合而非单条（AIC-086）；
3. 拒绝时给「最接近权限」建议，帮助区分漏配 vs 恶意请求；
4. 匹配返回 matchedBy 可追溯（审计日志需要）；
5. 追问：deny 规则优先于 allow（显式拒绝清单）是生产标配。
