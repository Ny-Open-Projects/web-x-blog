## AIC-405：笔试：合并多个评审器的意见，按位置去重并归一输出。
**答**：输入多来源意见 `[{source, file, line, message, severity}]`，合并规则：同 file+line（±2 行容差）视为同一问题合并输出（保留最高 severity、列出所有来源）；输出按 file/line 排序。

```javascript
function mergeFindings(all) {
  const sorted = [...all].sort((a, b) => a.file.localeCompare(b.file) || a.line - b.line);
  const sevRank = { high: 3, medium: 2, low: 1 };
  const out = [];
  for (const f of sorted) {
    const last = out[out.length - 1];
    if (last && last.file === f.file && Math.abs(last.line - f.line) <= 2) {
      last.sources.push(f.source);                      // 合并来源
      if (sevRank[f.severity] > sevRank[last.severity]) last.severity = f.severity;
    } else out.push({ file: f.file, line: f.line, severity: f.severity,
                      message: f.message, sources: [f.source] });
  }
  return out;
}
console.log(mergeFindings([
  { source: 'ai', file: 'a.ts', line: 10, message: 'NPE', severity: 'high' },
  { source: 'eslint', file: 'a.ts', line: 12, message: 'unsafe', severity: 'medium' },
  { source: 'ai', file: 'a.ts', line: 30, message: 'xss', severity: 'high' },
])); // 前两条合并：line 10, sources [ai, eslint], severity high

```

**评分点**：
- 行号容差合并（±2）是关键考点——不同工具行号基线不同。
- 合并保留最高 severity 与来源列表（可追溯）。
- 排序稳定：先 file 字典序再 line。
- 空输入返回空数组不抛错。
