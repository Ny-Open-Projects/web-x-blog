## AIC-411：笔试：检测规则库中「同主题矛盾指令」。
**答**：规则 `[{name, topic, directive, polarity}]`，polarity 为 must/ban。同 topic 下出现 must 与 ban 且关键词相同（directive 主词一致）即冲突，输出冲突对。directive 主词 = 第一个名词短语（简化：取首个中文动词后的宾语词）。

```javascript
function detectRuleConflict(rules) {
  const conflicts = [];
  const seen = new Set();
  const head = d => (d.match(/(?:必须|只能|禁止|不要)\s*([\u4e00-\u9fa5A-Za-z]+)/) || [])[1] || d;
  for (let i = 0; i < rules.length; i++) {
    for (let j = i + 1; j < rules.length; j++) {
      const a = rules[i], b = rules[j];
      if (a.topic !== b.topic) continue;
      const opposite = (a.polarity === 'must' && b.polarity === 'ban') ||
                       (a.polarity === 'ban' && b.polarity === 'must');
      if (opposite && head(a.directive) === head(b.directive)) {
        const key = [a.name, b.name].sort().join('|');
        if (!seen.has(key)) { seen.add(key); conflicts.push({ a: a.name, b: b.name, subject: head(a.directive) }); }
      }
    }
  }
  return conflicts;
}
console.log(detectRuleConflict([
  { name: 'r1', topic: 'style', polarity: 'must', directive: '必须使用 design token' },
  { name: 'r2', topic: 'style', polarity: 'ban', directive: '禁止使用 design token（legacy 区）' },
  { name: 'r3', topic: 'deps', polarity: 'must', directive: '必须使用 pnpm' },
])); // [r1|r2]

```

**评分点**：
- 同 topic 内 must/ban 配对检测是核心逻辑。
- 主词提取用正则近似即可，但要说明局限（面试可加分）。
- 多条同类规则要两两配对（笛卡尔积），注意去重（a,b 与 b,a）。
- 无冲突返回空数组。
