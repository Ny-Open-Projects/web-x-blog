## AIC-894：AI 工具试点效果很好，推广到全公司却推不动，怎么办？
**答**：
- 试点成功常是「选择性偏差」：试点团队自愿、有热情、场景适配；全公司有「不愿改变、场景不适配、被考核绑架」的人。推广不是复制工具，是**变革管理**。
- 分人群策略：创新者/早期采用者当**布道师**（让他们分享真实收益、提供内部模板）；对多数派要**降低门槛 + 展示同类案例**（「和你类似的团队用了效果如何」）；对抵触者先理解顾虑（怕被替代、怕学不会、怕数据被监控），用制度打消（不用于考核 AIC-854）而非强推。
- 推广要有**本地化适配**：不同场景的痛点不同，给「场景化入门包」（前端怎么用、测试怎么用、老人怎么迁移），而不是一套通用培训。
- 靠**机制而非运动**：把好实践固化进流程（新项目模板默认带规则文件、PR 模板含 AI 使用声明、onboarding 包含 AI 培训），让「不用 AI」反而变得麻烦；同时持续度量采纳与健康度，发现卡点就干预。
- 追问钩子：能说出「推广是变革管理，要分人群、降门槛、改机制，把好实践固化进流程而非靠运动式培训」的候选人，理解技术推广的组织本质。

```typescript
type Cohort = { name: string; size: number; adoption: number; barrier: string };

function rolloutPlan(cohorts: Cohort[]) {
  return cohorts.map(c => {
    const strategy = c.adoption > 0.6
      ? { action:'发展成布道师', detail:'分享案例、贡献模板' }
      : c.barrier === 'fear'
        ? { action:'制度打消顾虑', detail:'明确不用于考核 + 培训' }
        : { action:'降低门槛', detail:'场景化入门包 + 同伴结对' };
    return { cohort:c.name, size:c.size, ...strategy };
  });
}
console.log(rolloutPlan([
  { name:'早期采用者', size:20, adoption:0.9, barrier:'none' },
  { name:'多数派', size:200, adoption:0.3, barrier:'不会用' },
  { name:'抵触者', size:30, adoption:0.05, barrier:'fear' },
]));
// 分人群策略 + 机制固化（新项目模板/onboarding 默认带 AI 实践）
```
