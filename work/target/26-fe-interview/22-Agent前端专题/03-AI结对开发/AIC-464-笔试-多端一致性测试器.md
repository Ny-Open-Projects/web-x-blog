## AIC-464：笔试：实现「同一用例多端跑」的一致性校验。
**答**：用例结果 `[{caseId, platform, value}]`。校验：同 caseId 各端 value 一致（深比较用 JSON 序列化），输出一致集与分歧集（分歧集列出各端值）。

```javascript
function consistency(results) {
  const by = new Map();
  for (const r of results) {
    (by.get(r.caseId) ?? by.set(r.caseId, []).get(r.caseId)).push(r);
  }
  const consistent = [], diverged = [], uncovered = [];
  for (const [caseId, rs] of by) {
    if (rs.length === 1) { uncovered.push(caseId); continue; }
    const norm = rs.map(r => ({ p: r.platform, v: JSON.stringify(r.value) }));
    const first = norm[0].v;
    if (norm.every(n => n.v === first)) consistent.push(caseId);
    else diverged.push({ caseId, per: norm.map(n => ({ platform: n.p, value: JSON.parse(n.v) })) });
  }
  return { consistent, diverged, uncovered };
}
console.log(consistency([
  { caseId: 'c1', platform: 'h5', value: { a: 1 } },
  { caseId: 'c1', platform: 'mp', value: { a: 2 } },
  { caseId: 'c2', platform: 'h5', value: 1 },
])); // diverged: [c1]；uncovered: [c2]

```

**评分点**：
- 分组后组内比较，分歧组收集 {platform, value} 明细。
- 深比较用 JSON.stringify（并说明局限：键顺序敏感，可排序键改进）。
- 单端用例（只一端跑过）标记 uncovered。
- 一致与分歧互斥分组输出。
