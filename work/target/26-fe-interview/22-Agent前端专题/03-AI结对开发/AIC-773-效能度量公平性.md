## AIC-773：AI 效能度量中如何评估不同角色的收益公平性

**答**：
- 结论先行：AI 对不同角色（junior/senior、前端/后端）的收益不均是客观事实，度量要「看见差异」而非用整体均值掩盖；不公的收益分布会加剧能力鸿沟，是长期团队风险。
- 度量：按角色分层看提效幅度与质量变化；关注「junior 是否只被分配到低价值任务」「senior 是否因审查 AI 产出而负担加重」。
- 应对：为弱势角色提供针对性培训与更高价值任务的 AI 协作机会；把「审查负担」纳入 senior 的效能核算，避免隐形劳动被忽略。
- 追问钩子：为什么「senior 审查 AI 产出的时间」必须计入成本？——若不计入，senior 的效能会被低估，团队会误以为 AI 在 senior 群体收益低。

```javascript
// 分角色收益：计入审查负担
function roleBenefit(records) {
  const byRole = {};
  for (const r of records) {
    const o = (byRole[r.role] ??= { saved: 0, reviewCost: 0 });
    o.saved += r.hoursSaved ?? 0;
    o.reviewCost += r.reviewHours ?? 0;
  }
  return Object.entries(byRole).map(([role, o]) => ({
    role, net: +(o.saved - o.reviewCost).toFixed(1),
  }));
}
console.log(roleBenefit([
  { role: 'junior', hoursSaved: 10, reviewHours: 1 },
  { role: 'senior', hoursSaved: 4, reviewHours: 6 }, // 审查负担重，净收益可能为负
]));
// senior net = -2 → 提示 senior 被审查工作拖累
```
