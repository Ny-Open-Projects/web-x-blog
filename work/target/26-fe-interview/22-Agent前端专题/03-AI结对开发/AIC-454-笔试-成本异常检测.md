## AIC-454：笔试：实现成本速率异常检测（滑动窗口）。
**答**：事件流 `[{ts, usd}]`。实现 `detect(events, windowMs, threshold)`：任意窗口内累计成本超阈值即输出 `{alert: true, window: [start, end], sum}`（返回第一个命中窗口），否则 alert:false。

```javascript
function detect(events, windowMs, threshold) {
  let sum = 0, left = 0;
  for (let right = 0; right < events.length; right++) {
    sum += events[right].usd;
    while (events[right].ts - events[left].ts > windowMs) {
      sum -= events[left].usd; left++;
    }
    if (sum > threshold)
      return { alert: true, window: [events[left].ts, events[right].ts], sum: +sum.toFixed(2) };
  }
  return { alert: false };
}
console.log(detect([
  { ts: 0, usd: 40 }, { ts: 10_000, usd: 40 }, { ts: 20_000, usd: 40 },
], 15_000, 100)); // 窗口 [0,10000] 内 80 ≤ 100；[10000,20000] 内 80；无命中
console.log(detect([{ ts: 0, usd: 150 }], 1000, 100)); // 单条超限 → alert

```

**评分点**：
- 滑动窗口实现（双指针），避免 O(n²)。
- 命中即返回首个窗口并给出明细。
- 窗口边界：ts 含两端（闭区间）。
- 空流/窗口内单条超限都要正确。
