## AIC-811：笔试：实现请求血缘追踪器，跨模型调用透传 traceId 并构建调用树
**答**：
- 核心需求：实现 `Tracer`，提供 `startRoot(meta)`、`span(parent, name, meta)`、`finish(spanId)`、`getTree(traceId)`。每个 span 有唯一 `spanId`、`parentId`、`startAt/endAt`、`duration`；`getTree` 返回按父子关系嵌套的树。
- 边界：并发调用 spanId 不冲突（用计数器或 UUID）；父 span 未结束子 span 也能登记；未知 traceId 返回空数组；`finish` 幂等（重复调用不重复计时）。
- 关键：用 `Map<spanId, Span>` 存扁平结构，`getTree` 时按 `parentId` 分组再递归组装，避免每次插入都改树。
- 追问钩子：追问「如何支持跨进程透传」——能答出「用 W3C traceparent 头在 HTTP 边界传递 traceId + parentSpanId」的候选人具备分布式系统基础。

```typescript
type Span = {
  spanId: string; traceId: string; parentId?: string; name: string;
  meta: Record<string, any>; startAt: number; endAt?: number; children: Span[];
};

class Tracer {
  private flat = new Map<string, Span>();
  private seq = 0;
  private id() { return `s${++this.seq}`; }

  startRoot(meta: Record<string, any> = {}): Span {
    const s: Span = { spanId: this.id(), traceId: `t${++this.seq}`,
      name: 'root', meta, startAt: Date.now(), children: [] };
    this.flat.set(s.spanId, s);
    return s;
  }
  span(parent: Span, name: string, meta: Record<string, any> = {}): Span {
    const s: Span = { spanId: this.id(), traceId: parent.traceId, parentId: parent.spanId,
      name, meta, startAt: Date.now(), children: [] };
    this.flat.set(s.spanId, s);
    return s;
  }
  finish(s: Span) { if (s.endAt == null) s.endAt = Date.now(); } // 幂等

  getTree(traceId: string): Span[] {
    const nodes = [...this.flat.values()].filter(s => s.traceId === traceId);
    const roots: Span[] = [];
    for (const s of nodes) {
      const p = s.parentId ? this.flat.get(s.parentId) : null;
      if (p) p.children.push(s); else roots.push(s);
    }
    return roots;
  }
}

const t = new Tracer();
const root = t.startRoot({ user: 'u1' });
const main = t.span(root, 'model:main', { modelId: 'gpt-x' });
const judge = t.span(main, 'model:judge', { modelId: 'j1' });
t.finish(judge); t.finish(main); t.finish(root);
console.log(JSON.stringify(t.getTree(root.traceId), null, 2)); // 嵌套调用树
```
**评分点**：
- spanId 全局唯一（计数器/UUID），并发场景不冲突。
- `finish` 幂等，`endAt` 只在首次写入，避免重复计时。
- `getTree` 先扁平存储再按 `parentId` 组装，而非插入时维护树（O(n) 组装更清晰）。
- 正确处理「孤儿节点」（父不存在）作为 root 返回，不丢失数据。
- 能提到 `duration = endAt - startAt` 与跨进程 traceparent 透传是加分项。
