## AGT-588：手写 truncateForModel：日志头尾/表格前N行/代码骨架三类语义截断

**需求与边界**：
- 实现 truncate(result, budget)：按结果类型语义截断，输出 { text, truncated, note }。
- 边界要求：① 日志保留头 40% 尾 60%（错误常在尾部）且标记省略行数；② 表格保留前 N 行 + 总行数声明；③ 代码保留函数签名与闭合结构（括号配平），省略体用注释标记；④ budget 按"字符预算"统一计量。

**答**：
```javascript
function truncate(result, budget) {
  const t = typeof result === 'string' ? { type: 'log', text: result } : result;
  if (t.type === 'log') {
    const lines = t.text.split('\n');
    if (t.text.length <= budget) return { text: t.text, truncated: 0 };
    const head = Math.floor(budget * 0.4), tail = Math.floor(budget * 0.6);
    const skipped = lines.length - 2;
    return { text: lines.slice(0, 1).join('\n') + '\n…'
      + `（省略 ${skipped} 行）\n` + lines.slice(-1).join('\n'),
      truncated: skipped, note: '日志已按头尾截断' };
  }
  if (t.type === 'table') {
    const n = Math.max(1, Math.floor(budget / 80));   // 每行约80字符估算
    const rows = t.rows.slice(0, n);
    return { text: JSON.stringify(rows),
      truncated: t.rows.length - n,
      note: `共 ${t.rows.length} 行，已展示前 ${n} 行` };
  }
  if (t.type === 'code') {
    const lines = t.text.split('\n'); const out = []; let used = 0;
    for (const line of lines) {                      // 签名行优先保留
      const isSig = /^(function|class|const|async|def|export)\b/.test(line);
      if (isSig || used + line.length <= budget) {
        out.push(line); used += line.length + 1;
      } else { out.push('/* … 省略 … */'); break; }
    }
    return { text: out.join('\n'), truncated: lines.length - out.length,
      note: '代码已按结构截断' };
  }
  return { text: String(t).slice(0, budget), truncated: 0 };
}
```

**评分点**:
- 三类语义截断策略正确（日志头尾、表格行数声明、代码签名+闭合）。
- 省略量化（行数/字符）且带 note（UI 与模型都能感知截断）。
- budget 统一字符计量，类型未知回落纯 slice 兜底。
