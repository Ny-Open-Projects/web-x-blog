## AGT-589：手写 detectLoop + 干预条：相同调用连续3次检测、停止/提示/跳过三动作

**需求与边界**：
- 实现 LoopWatcher：订阅工具调用事件，检测"同工具+相似参数连续 ≥3 次"，触发干预。
- 边界要求：① 参数相似用稳定序列化（键排序）比较；② 中间穿插其他工具调用则重置计数；③ 干预动作 stop/hint/skip 各自正确落地（skip 要把该调用标记 skipped 通知运行时）；④ 只提示一次，用户忽略后不再重复弹（服务端硬上限兜底）。

**答**：
```javascript
class LoopWatcher {
  constructor({ threshold = 3, onDetect } = {}) {
    this.threshold = threshold; this.onDetect = onDetect;
    this.streakKey = null; this.count = 0; this.alerted = false;
  }
  onCall(tc) {
    const k = tc.tool + stableStringify(tc.args);  // 键排序稳定比较
    if (k === this.streakKey) {
      if (++this.count >= this.threshold && !this.alerted) {
        this.alerted = true;                       // 只提示一次
        this.onDetect({ tc, actions: this.actions(tc) });
      }
    } else { this.streakKey = k; this.count = 1; this.alerted = false; }
  }
  onOther() { this.streakKey = null; this.count = 0; this.alerted = false; } // 穿插重置
  actions(tc) {
    return {
      stop: () => runtime.cancel('loop_detected'),
      hint: () => ui.prompt('给 Agent 一句提示：').then(h =>
        h && runtime.injectHint(h)),              // 引导语注入下轮
      skip: () => runtime.skipToolCall(tc.id),    // 标记 skipped 换路
    };
  }
}
```

**评分点**:
- 稳定序列化比较参数（键序无关）；穿插其他调用重置计数。
- alerted 单次提示防打扰；三动作分别正确落地（skip 通知运行时）。
- 检测与干预解耦（onDetect 回调，UI 与运行时可替换）。
