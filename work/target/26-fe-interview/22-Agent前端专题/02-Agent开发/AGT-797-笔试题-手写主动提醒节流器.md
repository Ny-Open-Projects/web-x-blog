## AGT-797：手写 ProactiveThrottle：单卡上限、忽略降级、冷却期、置信门槛

**需求与边界**：
- 实现 ProactiveThrottle：consider(update, user)。
- 边界要求：① 同时最多 1 张卡（已有卡时排队不弹）；② 同话题被忽略 3 次降级 listOnly（不再弹卡）；③ 弹卡后同话题 7 天冷却；④ 置信 <0.7 不触发；⑤ 用户关闭通知后全部 listOnly（长期尊重）。

**答**：
```javascript
class ProactiveThrottle {
  constructor() { this.active = null; this.ignore = new Map();
    this.cool = new Map(); }
  consider(update, user) {
    if (user.notifications === false)               // 用户关闭：长期尊重
      return { mode: 'listOnly' };
    if (this.active) return { mode: 'queue' };      // 单卡上限
    if (update.confidence < 0.7) return null;
    const until = this.cool.get(update.topic);
    if (until && Date.now() < until) return { mode: 'listOnly' };
    if ((this.ignore.get(update.topic) ?? 0) >= 3)
      return { mode: 'listOnly',
        note: '多次忽略已降级为列表项' };
    this.active = update;
    this.cool.set(update.topic, Date.now() + 7 * 864e5);
    return { mode: 'card', update,
      onDismiss: () => { this.active = null;
        this.ignore.set(update.topic,
          (this.ignore.get(update.topic) ?? 0) + 1); },
      onOpen: () => { this.active = null; } };
  }
}
```

**评分点**:
- 五条节流规则齐全（单卡/队列/冷却/忽略降级/用户关闭）。
- onDismiss/onOpen 生命周期回调闭合 active 状态（防卡死）。
- 置信门槛前置。
