## 1206：笔试手写：实现多轮对话的槽位填充追踪

**答**：改为笔试题。**需求**：实现 trackDialog(turns)：turns 为 { role: 'user'|'bot', slots?: { [k]: v } }[]（bot 轮的 slots 表示确认的槽位）。维护槽位状态：user 提供的值记为 candidate，bot 确认后升级为 confirmed；用户改写已确认槽位则重置为 candidate。输出 final：{ [slot]: { value, status: 'confirmed'|'candidate' } }（仅保留有值的槽）。

```js
function trackDialog(turns) {
  const slots = {};   // name -> { value, status }
  for (const t of turns) {
    if (t.role === 'user') {
      for (const [k, v] of Object.entries(t.slots || {})) {
        const cur = slots[k];
        if (cur && cur.status === 'confirmed' && cur.value !== v) {
          slots[k] = { value: v, status: 'candidate' };   // 改写降级
        } else if (!cur || cur.status === 'candidate') {
          slots[k] = { value: v, status: 'candidate' };
        }
      }
    } else {
      for (const [k, v] of Object.entries(t.slots || {})) {
        const cur = slots[k];
        if (cur && cur.value === v) slots[k] = { value: v, status: 'confirmed' };
        else slots[k] = { value: v, status: 'confirmed' };   // bot 显式确认
      }
    }
  }
  return slots;
}
const turns = [
  { role: 'user', slots: { city: '北京', date: '周五' } },
  { role: 'bot', slots: { city: '北京' } },          // 确认 city
  { role: 'user', slots: { city: '上海' } },         // 改写已确认 city
];
console.log(trackDialog(turns));
// { city: { value: '上海', status: 'candidate' },
//   date: { value: '周五', status: 'candidate' } }
```

**评分点**：
- 状态机语义：candidate -> confirmed -> 改写降级 candidate（三态转换正确）
- bot 确认覆盖的语义（显式确认即 confirmed）
- 只输出有值槽位
- 能讨论：与对话式 RAG 的联动（确认槽位触发检索）、多值槽位（city 列表）的扩展
