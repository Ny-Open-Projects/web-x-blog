## 1110：笔试手写：实现批量同构请求的聚类检测

**答**：实现 detectAbuse(events)：events 为 { userId, target, tplId, ts }[]（tplId 为请求模板 id）。规则：同 (userId, tplId) 在 10 分钟窗口内触达 ≥5 个不同 target 且 targets 包含「非本人资产」≥80%，判 abuse；输出 { abusers: [{ userId, tplId, targets, foreignRate }] }。

```js
function detectAbuse(events, { windowMs = 600000, minTargets = 5, foreignCut = 0.8 } = {}) {
  const g = {};
  for (const e of events) {
    const k = e.userId + '|' + e.tplId;
    (g[k] ??= { userId: e.userId, tplId: e.tplId, targets: new Set(), foreign: 0, n: 0 });
    g[k].targets.add(e.target);
    g[k].n++;
    if (!isOwnAsset(e.userId, e.target)) g[k].foreign++;
  }
  const abusers = [];
  for (const k of Object.keys(g)) {
    const x = g[k];
    if (x.targets.size >= minTargets) {
      const foreignRate = x.foreign / x.targets.size;
      if (foreignRate >= foreignCut) {
        abusers.push({ userId: x.userId, tplId: x.tplId,
          targets: x.targets.size, foreignRate: +foreignRate.toFixed(3) });
      }
    }
  }
  return { abusers };
}
// 说明：生产实现需按 10 分钟滑动窗口切分，此处为全量简化版
```

**评分点**：
- 双条件判定：同模板批量（≥5 不同 target）+ 非本人资产占比（≥80%）
- 用 Set 去重 target，foreignRate 分母是去重后目标数
- 能讨论：滑动窗口切分的正确实现（固定窗口 vs 滑动窗口的边界效应）、与速率限制的互补关系
- 边界：单人单模板自己资产的批量操作不误报（foreignRate 低）
