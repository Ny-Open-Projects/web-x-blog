## AGT-850：手写 platformHealthCheck：六域检查（接入/运行时/模型/工具/数据/治理）、依赖拓扑、GoNoGo

**需求与边界**：
- 实现 platformHealthCheck(probes)。
- 边界要求：① 六域探针（sso/gateway/runtime/model/tools/memory）并行执行，单域超时 3s 记 timeout 不阻塞；② 依赖拓扑：model 依赖 vendor（vendor down → model degraded 而非 down）；③ 汇总 GoNoGo：核心域（gateway/runtime）down 即 NoGo；④ 输出含耗时与失败明细。

**答**：
```javascript
const DOMAINS = {
  sso: { core: false }, gateway: { core: true },
  runtime: { core: true }, model: { core: false, depends: 'vendor' },
  tools: { core: false }, memory: { core: false },
};
async function platformHealthCheck() {
  const results = await pMap(Object.entries(DOMAINS),
    async ([name, cfg]) => {
      const t0 = Date.now();
      try {
        const r = await withTimeout(probe(name), 3000);
        let status = r.status;
        if (cfg.depends && status === 'down'
          && probeCache(cfg.depends) === 'down')
          status = 'degraded';                     // 依赖降级传播
        return { name, status, ms: Date.now() - t0 };
      } catch {
        return { name, status: 'timeout', ms: Date.now() - t0 };
      }
    }, { concurrency: 6 });
  const coreDown = results.some(r =>
    DOMAINS[r.name].core && r.status === 'down');
  return { results,
    verdict: coreDown ? 'NoGo' : 'Go',             // 核心域判定
    failures: results.filter(r => r.status !== 'healthy') };
}
```

**评分点**:
- 六域并行探针+超时不阻塞；依赖降级传播（vendor down → model degraded）。
- GoNoGo 只看核心域；失败明细与耗时齐全（可定位）。
