## AGT-749：手写 SourcePreview：来源列表、排除/恢复、排除影响上下文重算、最少来源护栏

**需求与边界**：
- 实现 SourceController：toggle(id)/active()/guard()。
- 边界要求：① toggle 切换排除态；② active() 返回未排除来源（供重算上下文）；③ 全部被排除时 guard 阻止并提示（至少保留 1 个来源）；④ 排除触发上下文预算重算（排除大来源后可召回低分来源）；⑤ 操作带撤销栈（误排除可撤销）。

**答**：
```javascript
class SourceController {
  constructor(hits, budget) {
    this.hits = hits.map(h => ({ ...h, excluded: false }));
    this.budget = budget; this.undoStack = [];
  }
  toggle(id) {
    const h = this.hits.find(x => x.id === id);
    if (!h) throw new Error('NO_SOURCE');
    if (!h.excluded && this.active().length === 1)
      return { blocked: true, note: '至少保留一个来源' };  // 护栏
    this.undoStack.push(id);
    h.excluded = !h.excluded;
    return { refill: this.refill() };               // 排除后补位
  }
  active() { return this.hits.filter(h => !h.excluded); }
  refill() {                                        // 预算重算补位
    let used = this.active().reduce((a, h) => a + h.cost, 0);
    const pool = this.hits.filter(h => h.excluded
      && h.score >= 0.5).sort((a, b) => b.score - a.score);
    const recalled = [];
    for (const h of pool) {
      if (used + h.cost <= this.budget) {
        h.excluded = false; used += h.cost; recalled.push(h.id);
      }
    }
    return recalled;
  }
  undo() {
    const id = this.undoStack.pop();
    if (id) this.toggle(id);                        // 撤销栈
  }
}
```

**评分点**:
- 排除护栏（至少一个来源）+ 撤销栈（误操作可恢复）。
- 排除触发预算重算与低分来源补位（排除大源后信息不浪费）。
- toggle 幂等语义清晰且 blocked 有明确提示。
