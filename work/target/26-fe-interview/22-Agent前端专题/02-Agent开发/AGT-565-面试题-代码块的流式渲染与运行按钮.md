## AGT-565：流式输出的代码块，高亮/运行按钮/复制按钮何时出现

**答**：
- 流式中的代码块先展示纯文本（不做语法高亮，逐 token 高亮是性能黑洞），闭合 ``` 后再整体高亮；高亮失败降级纯文本。
- 操作按钮（复制/运行/折叠）在块闭合后挂载；"运行"按钮只对白名单语言+沙箱可用时出现（前端本地判定能力，不可运行的语言不出现假按钮）。
- 运行在沙箱（iframe/worker）执行并限资源，输出回填到块下方，超时终止。

```javascript
const RUNNABLE = new Set(['javascript', 'js', 'python']);
function CodeBlock({ lang, code, complete }) {
  if (!complete) return <pre className="raw">{code}</pre>;   // 流式中纯文本
  const canRun = RUNNABLE.has(lang) && sandboxAvailable();
  return <div className="code">
    <Toolbar actions={['copy', canRun && 'run']} />
    <Highlight code={code} lang={lang} fallback={<pre>{code}</pre>} />
    {canRun && <RunResult onRun={() => runInSandbox(code, { timeout: 3000 })} />}
  </div>;
}
```
