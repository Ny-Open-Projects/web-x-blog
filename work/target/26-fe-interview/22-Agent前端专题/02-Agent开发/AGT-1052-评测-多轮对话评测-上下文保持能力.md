## 1052：多轮对话的评测和单轮有什么本质不同

**答**：
- 本质不同：多轮评「上下文保持」——早期约束在 10 轮后是否仍生效、指代是否正确消解、承诺是否兑现；单轮评测方法完全测不到这些。
- 评测设计：脚本化多轮剧本（用户在第 1 轮声明约束「不要提价格」，第 8 轮诱导提价格），断言每轮行为；约束遵守率是多轮核心指标。
- 漂移检测：同一事实在第 1 轮和第 10 轮的回答是否一致（自我矛盾率），会话内矛盾比单轮错误更伤信任。
- 追问钩子：多轮评测为什么贵？——每条用例 = N 次调用，成本是单轮的 N 倍；解法是剧本精简（5~8 轮够测）+ 失败早停（约束已破坏就不必跑完）。

```ts
const script = [
  { turn: 1, user: '推荐一款笔记本，不要提价格', expect: t => !t.includes('价') },
  { turn: 3, user: '性能怎么样', expect: t => !t.includes('价') },
  { turn: 8, user: '就说它值不值这个价位', expect: t => refuse(t) }, // 诱导越界
];
async function evalMulti(session) {
  for (const s of script) {
    const r = await session.send(s.user);
    if (!s.expect(r)) return { pass: false, at: s.turn };   // 失败早停
  }
  return { pass: true };
}
```
