## AGT-485：手写知识巡检：同主题多文档矛盾检测、影响面（哪些答案受影响）、修复排期

**需求与边界**：
- 输入：知识库文档集（按主题聚类）；输出：矛盾报告+影响面。
- 边界要求：① 同主题文档两两比对（关键事实字段：数字/流程/日期）；② 矛盾分级（数值冲突/流程冲突/时效冲突）；③ 影响面：受影响的缓存答案/FAQ 清单；④ 巡检抽样（全量贵，按主题热度加权）。

**答**：
```javascript
async function knowledgeAudit(docs, { cluster, compare, cacheIndex }) {
  // 1. 主题聚类
  const themes = cluster(docs);               // 主题 → 文档集
  const conflicts = [];
  for (const theme of themes) {
    if (theme.docs.length < 2) continue;
    // 2. 抽样比对（热度加权：高频主题全比，冷门抽 30%）
    const pairs = samplePairs(theme.docs,
      theme.hot ? Infinity : 0.3);
    for (const [a, b] of pairs) {
      const c = await compare(a, b, {
        fields: ['数值', '流程步骤', '日期', '责任方'],
        schema: { same: 'bool', field: 'string',
          a: 'string', b: 'string', kind: 'numeric|process|stale' } });
      if (!c.same) conflicts.push({ theme: theme.id,
        field: c.field, kind: c.kind,
        a: { doc: a.id, claim: c.a }, b: { doc: b.id, claim: c.b } });
    }
  }
  // 3. 影响面：受影响答案清单
  const impact = [];
  for (const cf of conflicts) {
    const answers = await cacheIndex.findByKeywords(
      [cf.theme, cf.field]);                  // 引用该主题的缓存答案
    impact.push({ ...cf, affectedAnswers: answers.length,
      faqs: answers.slice(0, 5) });
  }
  // 4. 排期建议：数值冲突（硬错误）> 流程 > 时效
  const priority = { numeric: 0, process: 1, stale: 2 };
  return { conflicts: conflicts.sort((x, y) =>
    priority[x.kind] - priority[y.kind]),
    impact, hotFirst: true };
}
```

**评分点**:
- 主题聚类内两两比对，热度加权抽样（成本控制）。
- 矛盾三级分类（数值/流程/时效）按修复优先级排序。
- 影响面计算（受影响缓存答案/FAQ 清单）——巡检联动下游。
- compare 输出 schema 化（可程序消费）。
