## AGT-738：手写 preprocessScan：去斜、质量分级、数字合法性校验、拒收引导

**需求与边界**：
- 实现 qualityGate(scanResult)：输出 accept/reject/repair 决策。
- 边界要求：① 页均置信度 <0.7 拒收（给重拍引导）；② 0.7~0.85 标记 repair（降级入库+低置信标记）；③ 数字类内容（日期/金额）做合法性校验（非法即标疑）；④ 印章区域标记不删除；⑤ 决策带具体原因清单（哪几块低于阈值）。

**答**：
```javascript
function qualityGate(scan, { reject = 0.7, repair = 0.85 } = {}) {
  const low = scan.blocks.filter(b => b.conf < repair);
  const pageConf = avg(scan.blocks.map(b => b.conf));
  const illegalNums = scan.blocks.filter(b => b.type === 'number'
    && !plausible(b.text));                          // 非法数字
  const reasons = [];
  if (pageConf < reject)
    reasons.push(`整页置信度 ${pageConf.toFixed(2)} 低于阈值`);
  if (low.length > scan.blocks.length * 0.4)
    reasons.push(`${low.length} 个区块识别质量差`);
  if (illegalNums.length)
    reasons.push(`疑似非法数值：${illegalNums.slice(0, 3).map(b => b.text)}`);
  const decision = reasons.length && pageConf < reject ? 'reject'
    : reasons.length ? 'repair' : 'accept';
  return { decision, reasons,
    hint: decision === 'reject'
      ? '识别质量不足，建议提供电子版或重新拍摄' : null,
    flags: { repair: decision === 'repair',
      stamped: scan.stampedRegions, illegalNums } };
}
```

**评分点**:
- 三档决策（accept/repair/reject）阈值明确，reject 给自助修复引导。
- 数字合法性校验独立于置信度（置信高但内容非法照样抓）。
- 印章标记不删除（区域语义保留）；原因清单可定位到块。
