## AGT-796：手写 memCache：版本键、TTL、删除即失效、命中率统计、降采样联动

**需求与边界**：
- 实现 MemCache：get(userId, query, opts)/set/invalidateUser/bust(userId)。
- 边界要求：① 键含 profileVer + query hash + topK；② TTL 60s；③ invalidateUser 删除该用户全部缓存键（删除合规红线）；④ 命中率统计；⑤ 高峰期 topK 降采样自动（由 opts 传入 peak 标志）。

**答**：
```javascript
class MemCache {
  constructor(store) { this.store = store; this.stats = { hit: 0, miss: 0 }; }
  keyOf(userId, ver, query, opts) {
    return `mem:${userId}:${ver}:${hash(query)}:${opts.topK}`;
  }
  async get(userId, ver, query, opts) {
    const v = await this.store.get(this.keyOf(userId, ver, query, opts));
    v ? this.stats.hit++ : this.stats.miss++;
    return v ?? null;
  }
  async set(userId, ver, query, opts, result) {
    await this.store.set(this.keyOf(userId, ver, query, opts),
      result, { ttl: 60000 });
  }
  async bust(userId) {
    await this.store.deleteByPrefix(`mem:${userId}:`); // 删除即失效
    this.stats = { hit: 0, miss: 0 };
  }
  hitStats() {
    const { hit, miss } = this.stats;
    return { hitRate: hit / (hit + miss || 1) };
  }
}
async function retrieve(userId, query, { peak }) {
  const ver = await profile.version(userId);
  const opts = { topK: peak ? 5 : 10 };            // 降采样
  const hit = await memCache.get(userId, ver, query, opts);
  if (hit) return hit;
  const result = await vector.search(embed(query),
    { filter: { userId }, ...opts });
  await memCache.set(userId, ver, query, opts, result);
  return result;
}
```

**评分点**:
- 版本号进缓存键（画像更新自动失效）；删除走前缀清除（合规红线）。
- peak 降采样不拒服务；命中率统计。
