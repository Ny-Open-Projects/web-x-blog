## 968：笔试手写：实现评测门禁（多指标红线 + 综合分）

**答**：实现 gate(report, baseline)：report/baseline 均为 { acc, falseReject, p95, cost }。规则：acc 相对基线下降超过 0.02 → block；falseReject > 0.05 → block；p95 或 cost 相对基线上升超过 30% → block；其余 pass。输出 { verdict, reasons[] }，reasons 精确到指标与数值。

```js
function gate(report, baseline) {
  const reasons = [];
  const drop = baseline.acc - report.acc;
  if (drop > 0.02) reasons.push(`acc down ${(drop).toFixed(3)} > 0.02`);
  if (report.falseReject > 0.05) reasons.push(`falseReject ${report.falseReject} > 0.05`);
  for (const k of ['p95', 'cost']) {
    const up = (report[k] - baseline[k]) / baseline[k];
    if (up > 0.3) reasons.push(`${k} up ${(up * 100).toFixed(1)}% > 30%`);
  }
  return { verdict: reasons.length ? 'block' : 'pass', reasons };
}
console.log(gate({ acc: 0.83, falseReject: 0.06, p95: 1000, cost: 100 },
  { acc: 0.86, falseReject: 0.03, p95: 1000, cost: 100 }));
// { verdict: 'block', reasons: [ 'acc down 0.030 > 0.02', 'falseReject 0.06 > 0.05' ] }
```

**评分点**：
- 阈值比较方向正确（acc 是下降红线，p95/cost 是上升红线）
- reasons 带具体数值，可直接用于 CI 报告
- 基线为 0 的除零保护（可讨论：cost 基线 0 时按绝对值判断）
- 能讨论边界语义：0.02 是「恰好等于」不 block 还是 block（建议 > 严格大于并在注释声明）
