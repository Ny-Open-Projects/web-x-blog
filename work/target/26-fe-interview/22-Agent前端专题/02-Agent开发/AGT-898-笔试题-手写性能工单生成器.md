## AGT-898：手写 perfTickets：去噪、归因、收益排序、topN工单、验证方式

**需求与边界**：
- 实现 perfTickets(report, ctx, { topN = 5 } = {})。
- 边界要求：① 已知误报清单过滤；② 每条建议归因（结合 bundle 分析定位到模块/负责人）并估算收益（ms）；③ 按收益排序取 topN；④ 工单含验证方式（复测指标与环境）；⑤ 收益无法估算的进候选池不进工单。

**答**：
```javascript
function perfTickets(report, ctx, { topN = 5 } = {}) {
  const items = report.audits
    .filter(a => !KNOWN_FALSE_POSITIVE.has(a.id))  // 去噪
    .map(a => {
      const attr = attributeAudit(a, ctx.bundle);  // 归因到模块
      const gain = estimateGain(a, ctx.waterfall);
      return gain == null ? { pool: true, a, attr }
        : { gain, a, attr,
            verify: `复测 ${a.metric}（同环境）` };
    });
  const tickets = items.filter(i => !i.pool)
    .sort((a, b) => b.gain - a.gain)
    .slice(0, topN)
    .map(i => ({ owner: ownerOf(i.attr.module),
      gainMs: i.gain, action: i.a.suggestion,
      verify: i.verify }));
  return { tickets, pool: items.filter(i => i.pool) }; // 收益未明进池
}
```

**评分点**:
- 去噪+归因（定位到模块/负责人）；收益估算排序（性价比驱动）。
- 收益不可估的进候选池（不编数字进工单）。
- 每张工单带验证方式（优化必须可验证）。
