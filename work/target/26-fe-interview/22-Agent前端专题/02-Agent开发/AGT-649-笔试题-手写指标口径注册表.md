## AGT-649：手写 MetricRegistry：口径定义、采集位置、告警归属、缺失校验、口径版本

**需求与边界**：
- 实现 MetricRegistry：register/registerOrThrow/validateAll/bumpVersion。
- 边界要求：① 每指标必须含 { def, source, owner }，缺任一注册失败（不允许无主指标上大盘）；② 口径变更 bumpVersion 并记录 changelog（旧口径查询仍可用历史版本解释）；③ validateAll 输出缺失清单；④ 重名注册抛错（除非 force+changelog）。

**答**：
```javascript
class MetricRegistry {
  constructor() { this.map = new Map(); this.changelog = []; this.ver = 1; }
  register(name, { def, source, owner, force = false, note = '' }) {
    if (!def || !source || !owner)
      throw new Error(`METRIC_INCOMPLETE: ${name} 缺 def/source/owner`);
    if (this.map.has(name) && !force)
      throw new Error(`METRIC_DUP: ${name}`);
    if (force) {
      this.changelog.push({ ver: ++this.ver, name, from: this.map.get(name)?.def,
        to: def, note, at: Date.now() });       // 口径版本化
    }
    this.map.set(name, { def, source, owner, ver: this.ver });
  }
  get(name, { ver } = {}) {
    const cur = this.map.get(name);
    if (!cur) throw new Error('NO_METRIC: ' + name);
    if (ver && ver !== cur.ver) {               // 旧口径查询
      const old = this.changelog.filter(c => c.name === name
        && c.ver <= ver).at(-1);
      return { ...cur, def: old?.from ?? cur.def, historical: true };
    }
    return cur;
  }
  validateAll(expected) {
    return expected.filter(n => !this.map.has(n)); // 缺失清单
  }
}
```

**评分点**:
- 三要素强制（def/source/owner），无主指标注册即拒（防数字墙）。
- 口径变更带版本与 changelog，旧口径可历史解释（跨周对比不失真）。
- 重名保护（force 才覆盖且必须留痕）。
