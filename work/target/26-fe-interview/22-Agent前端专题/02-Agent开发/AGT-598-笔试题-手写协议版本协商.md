## AGT-598：手写 negotiate：客户端/服务端版本匹配、降级转换器、流量归零下线

**需求与边界**：
- 实现 negotiate(clientVer, serverVers) 与 degrade(ev, targetVer)。
- 边界要求：① 客户端版本服务端支持→直用；② 不支持→选服务端 ≤ 客户端的最高版（降级）；③ 客户端低于服务端全部版本→用服务端最低版+degrade 转换（v2 块流退化为 v1 文本流）；④ degrade 对未知 v2 事件返回 null（v1 管线丢弃）。

**答**：
```javascript
function negotiate(clientVer, serverVers) {
  if (serverVers.includes(clientVer)) return clientVer;
  const lower = serverVers.filter(v => v <= clientVer);
  if (lower.length) return Math.max(...lower);   // 服务端降级到 ≤客户端
  return Math.min(...serverVers);                // 客户端过旧：最低版+转换
}
function degrade(ev, targetVer) {
  if (targetVer >= 2) return ev;                 // 目标 v2 原样
  // v2 → v1：块流退化为文本流
  switch (ev.type) {
    case 'block.start': return null;
    case 'block.delta': return { type: 'text.delta', data: ev.data, seq: ev.seq };
    case 'block.end':   return null;
    default: return null;                        // 未知 v2 事件丢弃
  }
}
// 服务端下线判定：v1 流量占比 < 1% 持续 7 天才关
function canRetireOldVersion(traffic) {
  return traffic.v1Share < 0.01 && traffic.v1StreakDays >= 7;
}
```

**评分点**:
- 三分支协商正确（直用/服务端降级/客户端过旧+转换器）。
- degrade 保内容丢语义（块→文本），未知事件丢弃（前向兼容）。
- 下线门槛量化（份额+持续天数），不做激进关闭。
