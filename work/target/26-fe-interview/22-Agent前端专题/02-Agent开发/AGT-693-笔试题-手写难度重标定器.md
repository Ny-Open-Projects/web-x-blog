## AGT-693：手写 recalibrateDifficulty：通过率重标、难度迁移统计、过易退役建议

**需求与边界**：
- 实现 recalibrate(cases, run)。
- 边界要求：① 难度 = 1-通过率映射三档（<0.3 通过=hard，0.3~0.7=mid，>0.7=easy）；② 输出迁移矩阵（旧难度→新难度计数）；③ 连续两轮 easy 且通过率 >0.95 的用例给退役建议（保留少量锚定）；④ 锚定用例（anchor 标记）不退役。

**答**：
```javascript
function diffLabel(passRate) {
  return passRate < 0.3 ? 'hard'
    : passRate <= 0.7 ? 'mid' : 'easy';
}
function recalibrate(cases, run) {
  const migrate = {};
  const retire = [];
  const out = cases.map(c => {
    const pr = run.passRate(c.id);
    const nd = diffLabel(pr);
    const key = `${c.diff}->${nd}`;
    migrate[key] = (migrate[key] ?? 0) + 1;
    const rec = { ...c, diff: nd, lastPassRate: pr };
    if (c.diff !== 'easy' && nd === 'easy' && pr > 0.95
      && run.prevEasyStreak(c.id) >= 2
      && !c.anchor)                                // 锚定不退役
      retire.push(c.id);
    return rec;
  });
  return { cases: out, migrate,
    retire: retire.slice(0, Math.floor(retire.length * 0.8)),
    note: '保留20%过易用例作趋势监控锚' };
}
```

**评分点**:
- 通过率→难度映射正确；迁移矩阵量化漂移规模。
- 退役有护栏（锚定保留、保留 20% 作趋势监控、连续两轮才退役）。
- lastPassRate 落库（下次重标定有依据）。
