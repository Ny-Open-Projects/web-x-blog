## 1179：笔试手写：实现会话内检索复用（相似度阈值+强制刷新）

**答**：实现 reuseOrSearch(session, q, { threshold=0.92, force=false, search })：session 已有 { queries: string[], results: Map }。计算 q 与历史 queries 的最大相似度（用注入的 sim 函数）；超过阈值且非 force 返回 { reused: true, hits, matchedQuery }；否则执行 search(q)，写入 session 并返回 { reused: false, hits }。

```js
async function reuseOrSearch(session, q, { threshold = 0.92, force = false, search } = {}) {
  if (!force) {
    let best = null, bestSim = 0;
    for (const prev of session.queries) {
      const s = sim(prev, q);
      if (s > bestSim) { bestSim = s; best = prev; }
    }
    if (best && bestSim >= threshold) {
      return { reused: true, hits: session.results.get(best), matchedQuery: best, sim: +bestSim.toFixed(3) };
    }
  }
  const hits = await search(q);
  session.queries.push(q);
  session.results.set(q, hits);
  return { reused: false, hits };
}
const session = { queries: ['如何配置灰度'], results: new Map([['如何配置灰度', ['h1']]]) };
console.log(await reuseOrSearch(session, '灰度怎么配置',
  { sim: (a, b) => 0.95, search: async () => { throw new Error('不应调用'); } }));
// { reused: true, hits: ['h1'], matchedQuery: '如何配置灰度', sim: 0.95 }
```

**评分点**：
- 遍历取最大相似度，阈值判定含 force 跳过分支
- 写回 session 双结构一致（queries 数组 + results Map）
- 注入 sim/search 可测性好；验证「命中时不调 search」（测试用 throw 验证）
- 能讨论：阈值过高复用率低、过低答案陈旧——生产按意图分层阈值；force 场景（用户明确要求再搜）必须穿透
