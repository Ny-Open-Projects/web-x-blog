## AGT-639：手写 fingerprint：错误码+span位置+输入特征、规则合并、未知簇嵌入聚类

**需求与边界**：
- 实现 fingerprint(fail) 与 cluster(failures)。
- 边界要求：① 指纹 = 错误码 + 失败 span 名 + 输入特征桶（长度档/含特殊字符），稳定可复现；② 已知指纹（规则库）直接归因；③ 未知按错误消息嵌入相似度 >0.92 聚类，输出新簇；④ 每簇输出 { count, users, sample }。

**答**：
```javascript
function fingerprint(fail) {
  const lenBucket = fail.inputLen > 8000 ? 'long'
    : fail.inputLen > 1000 ? 'mid' : 'short';
  return [fail.code, fail.span, lenBucket,
    /[^\x00-\x7f]/.test(fail.input) ? 'non-ascii' : 'ascii'].join('|');
}
function cluster(failures, { sim = 0.92 } = {}) {
  const out = [];
  const byFp = groupBy(failures, fingerprint);
  for (const [fp, fs] of byFp) {
    if (RULES[fp]) {                             // 规则层：已知归因
      out.push({ fp, rule: RULES[fp], count: fs.length,
        users: new Set(fs.map(f => f.userId)).size, sample: fs[0] });
    }
  }
  const unknown = failures.filter(f => !RULES[fingerprint(f)]);
  const clusters = [];
  for (const f of unknown) {                     // 嵌入聚类发现新簇
    const emb = embed(f.msg);
    const c = clusters.find(c => cosine(c.emb, emb) > sim);
    if (c) { c.items.push(f); }
    else clusters.push({ emb, items: [f] });
  }
  return [...out, ...clusters.map(c => ({
    novel: true, count: c.items.length,
    users: new Set(c.items.map(f => f.userId)).size,
    sample: c.items[0],
  }))].sort((a, b) => b.count - a.count);
}
```

**评分点**:
- 指纹稳定（错误码+span+输入特征桶），规则层吃掉已知失败。
- 未知样本嵌入聚类发现新簇，簇带影响面（次数+独立用户数）与样本。
- 输出按影响面排序（可行动优先级）。
