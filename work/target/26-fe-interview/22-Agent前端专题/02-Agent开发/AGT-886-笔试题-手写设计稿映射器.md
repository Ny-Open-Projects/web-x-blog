## AGT-886：手写 mapDesign：图层树→组件映射表驱动、未映射AI兜底、token校验、布局保留

**需求与边界**：
- 实现 mapDesign(tree, mapper, components)。
- 边界要求：① mapper 按（图层特征：类型+命名约定）匹配组件库组件；② 未匹配节点走 aiCompose（标记 ai=true 待审）；③ 产出样式只允许 token 引用（裸色值/尺寸转 token，无对应 token 报 warning）；④ 文本节点直接映射 Text 组件；⑤ 树结构与嵌套层级保留。

**答**：
```javascript
function mapDesign(tree, mapper, components, { tokens }) {
  const walk = (node) => {
    if (node.type === 'text')
      return { comp: 'Text', props: { value: node.text },
        style: toTokens(node.style, tokens) };
    const hit = mapper.find(m => matchNode(m.match, node));
    if (hit)
      return { comp: hit.component,
        props: mapProps(hit, node), children: node.children.map(walk) };
    return { comp: 'AI_COMPOSE', ai: true,        // 未映射AI兜底
      spec: node, children: node.children.map(walk) };
  };
  const out = walk(tree);
  const warnings = collectBareStyles(out, tokens);  // 裸样式检查
  return { out, warnings };
}
function toTokens(style, tokens) {
  return Object.fromEntries(Object.entries(style)
    .map(([k, v]) => [k, tokens.find(v) ?? `${v}/*无token*/`]));
}
```

**评分点**:
- 映射表驱动优先，AI 只兜底未匹配节点且带 ai 标记（可审）。
- 裸样式转 token，无 token 显式 warning（设计系统一致性守卫）。
- 文本直映射；树结构层级保留（还原版式）。
