## 1277：笔试手写：实现 并行工具结果对齐合并器

**答**：模型并行发起 N 个 tool_call，结果乱序返回。实现 alignResults(calls, results)：calls 为 { id, name }[]，results 为 { callId, data }[]（可能重复/缺失/多出未知 callId）。输出按 calls 顺序对齐的数组；缺失 callId 的槽位填 { status: 'missing' }；多出的未知结果进 orphan；重复取第一条其余丢弃。返回 { aligned, orphan }。

```js
function alignResults(calls, results) {
  const byId = new Map();
  const orphan = [];
  for (const r of results) {
    if (!calls.some(c => c.id === r.callId)) { orphan.push(r); continue; }
    if (!byId.has(r.callId)) byId.set(r.callId, { status: 'ok', data: r.data }); // 重复取首条
  }
  const aligned = calls.map(c => byId.get(c.id) ?? { id: c.id, status: 'missing' });
  return { aligned, orphan };
}
```

**评分点**：
- callId 集合先判定（未知结果进 orphan 不混入）
- 重复结果首条胜出（幂等意识）
- missing 槽位显式标记（不发 null）
- 能讨论：missing 的处置——重试该工具还是告知模型失败
