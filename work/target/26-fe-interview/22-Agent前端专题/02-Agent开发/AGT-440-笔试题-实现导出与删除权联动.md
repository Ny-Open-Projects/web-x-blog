## AGT-440：手写数据权利实现：全数据域导出、删除贯穿（向量/缓存/日志）、审计

**需求与边界**：
- 输入：userId、数据域注册表（每个域的导出/删除实现）；输出：导出包或删除结果。
- 边界要求：① 域注册表驱动（新增数据域必须注册导出/删除，编译期防遗漏）；② 删除贯穿所有派生数据（向量块/缓存/日志中的引用）；③ 导出与删除同标准并列提供；④ 两个操作都审计留痕。

**答**：
```javascript
// 数据域注册：新增数据域必须实现两接口（防遗漏）
const DOMAINS = [
  { name: 'sessions',
    export: (uid) => sessions.all(uid),
    purge: (uid) => sessions.deleteAll(uid) },
  { name: 'memory',
    export: (uid) => memory.all(uid),
    purge: async (uid) => {
      const ids = await memory.idsOf(uid);
      await memory.deleteAll(uid);
      await Promise.all(ids.map(id => vectorStore.deleteByUser(id))); // 向量
      await cache.invalidateUser(uid);                                // 缓存
      await logs.scrubUser(uid);                                      // 日志引用
    } },
  { name: 'documents',
    export: (uid) => docs.originals(uid),
    purge: async (uid) => {
      const d = await docs.idsOf(uid);
      await docs.deleteAll(uid);
      await Promise.all(d.flatMap(id => [
        vectorStore.deleteByDoc(id), embedQueue.cancel(id)]));
    } },
];
async function exportAll(userId) {
  const parts = {};
  for (const d of DOMAINS) parts[d.name] = await d.export(userId);
  await audit.log({ userId, action: 'export' });
  return { format: 'json', schemaVersion: 1, generatedAt: now(), parts };
}
async function purgeAll(userId) {                 // 删除贯穿派生数据
  const results = [];
  for (const d of DOMAINS)
    results.push({ domain: d.name, ok: await d.purge(userId) });
  const failed = results.filter(r => !r.ok);
  if (failed.length) return { done: false, failed }; // 部分失败不静默
  await audit.log({ userId, action: 'purge' });
  return { done: true };
}
```

**评分点**:
- 域注册表模式：新增数据域强制实现 export/purge（编译期防漏）。
- 删除贯穿派生数据（向量/缓存/日志引用/队列任务）——不是只删主表。
- 导出与删除并列同标准，操作均审计。
- 部分失败不静默（failed 列表返回，可重试）。
