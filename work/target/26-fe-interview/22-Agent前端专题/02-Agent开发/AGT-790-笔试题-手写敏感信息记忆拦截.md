## AGT-790：手写 writeGuard：多类敏感正则+NER双通道、命中拒写、抽象化白名单通道

**需求与边界**：
- 实现 writeGuard(stmt)。
- 边界要求：① 硬拦截类：身份证/银行卡/密码口吻/手机号；② 抽象化类：人名/公司名/金额（替换为"客户A/公司B/X万"后可入档）；③ NER 通道兜底正则漏网（实体识别到 PERSON/ORG 走抽象化）；④ 返回 { allow, stmt, mask }；⑤ 全空/超长拒绝。

**答**：
```javascript
const HARD = [
  [/\d{17}[\dXx]/, 'id_card'], [/\d{16,19}/, 'bank_card'],
  [/1[3-9]\d{9}/, 'phone'], [/(密码|password)\s*[:：是]/i, 'password'],
];
function writeGuard(stmt, { ner = nerDetect } = {}) {
  if (!stmt?.trim() || stmt.length > 2000)
    return { allow: false, reason: 'invalid' };
  for (const [re, kind] of HARD)
    if (re.test(stmt))
      return { allow: false, reason: kind,
        note: '包含敏感信息，不会存入记忆' };      // 硬拦截
  const ents = ner(stmt);                          // NER兜底
  let masked = stmt;
  const maskMap = new Map();
  const nameOf = (t, i) => maskMap.get(t) ?? maskMap.set(t,
    `${t.slice(0, 1)}**#${i + 1}`).get(t);
  [...ents.PERSON, ...ents.ORG].forEach((t, i) =>
    masked = masked.replaceAll(t, nameOf(t, i)));
  masked = masked.replace(/([\d.]+)(万?元)/g, 'X$2'); // 金额抽象
  return { allow: true, stmt: masked,
    maskedKeys: [...maskMap.values()] };
}
```

**评分点**:
- 硬拦截四类齐全且语义明确（密码口吻也算）；抽象化通道保留语义可用。
- NER 兜底正则漏网；金额抽象化（数字→X 万）。
- 长度/空值校验前置。
