## AGT-792：手写 citeMemory：来源会话链接、引文校验、过期引用降级

**需求与边界**：
- 实现 citeMemory(mem, viewer)。
- 边界要求：① 引用含 originSessionId+quote（原文引用需与记忆存档一致，hash 校验）；② viewer 无权限访问来源会话时降级为不带链接的陈述；③ 来源会话已过保留期（>90 天全文已压）时引用摘要版本并标注；④ quote 防注入转义。

**答**：
```javascript
async function citeMemory(mem, viewer) {
  const ok = mem.quoteHash === hash(mem.quote);    // 引文完整性
  if (!ok) return { text: `[记忆] ${mem.statement}`,
    degraded: 'quote-mismatch' };
  const canOpen = await acl.can(viewer, 'read',
    { session: mem.originSessionId });
  const alive = await episodic.alive(mem.originSessionId); // 未压缩
  const esc = (s) => s.replace(/[<>&"]/g, c =>
    ({ '<': '&lt;', '>': '&gt;', '&': '&amp;', '"': '&quot;' }[c]));
  const text = `你此前提到：${esc(mem.quote)}`;
  if (!canOpen) return { text, degraded: 'no-permission' };
  if (!alive) return { text: text + '（原文已按策略压缩，此为摘要引用）',
    ref: { session: mem.originSessionId, summary: true } };
  return { text, ref: { session: mem.originSessionId,
    anchor: mem.originTurn } };
}
```

**评分点**:
- 引文哈希校验（防记忆被篡改后引用失真）。
- 三级降级（无权限/已压缩/正常）语义完整；quote 转义防注入。
- 引用带锚点可跳转（跨会话可核对）。
