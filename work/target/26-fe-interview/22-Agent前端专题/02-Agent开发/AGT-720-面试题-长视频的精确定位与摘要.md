## AGT-720：两小时视频问第三章讲了什么，长视频的层级索引与定位怎么做

**答**：
- 层级索引：全视频摘要 → 章节摘要（目录级）→ 段落级 → 句级；问"第三章"命中章节层，问具体问题命中句级——粗到细的层级让长视频检索不爆预算。
- 章节边界检测：字幕话题聚类 + 画面变化（PPT 翻页）双信号切分章节，人工校准一遍即可长期复用。
- 回答生成预算：先取相关章节摘要 + 命中段落全文，摘要层提供上下文压缩（不把两小时字幕塞给模型）。

```javascript
const videoIndex = {
  summary: fullSummary,                            // 全视频
  chapters: chapters.map(c => ({ ...c, summary: chapterSummary(c) })),
  segments: allSegments,                           // 句级
};
function retrieveFromVideo(q) {
  const ch = topChapter(q, videoIndex.chapters);   // 章节定位
  return {
    context: [ch.summary, ...topSegments(q, ch.segments)],
    cite: { videoId, t0: ch.t0 },                  // 章节跳转
  };
}
```
