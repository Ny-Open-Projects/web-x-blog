## AGT-469：手写版本变更检测：版本指纹、金标 Canary、静默变更报警与门禁

**需求与边界**：
- 输入：模型响应（含版本声明）、金标 Canary 集；输出：变更检测结果。
- 边界要求：① 版本指纹记录（API 声明的版本+响应行为指纹）；② Canary 集定时探测（行为漂移检测——响应分布变化）；③ 静默变更→报警并自动触发回归评测；④ 变更历史归档。

**答**：
```javascript
class VersionWatchdog {
  constructor({ canary, baseline, runner }) {
    this.canary = canary;            // 50 条金标 + 期望分布
    this.baseline = baseline;        // 首次基线快照
    this.runner = runner;
  }
  async probe(model) {
    const declared = await model.declaredVersion();
    // 1. Canary 行为指纹：金标题的回答分布
    const results = await Promise.all(this.canary.map(c =>
      this.runner(model, c.prompt)));
    const fp = fingerprint(results);   // {风格分布, 正确率, 长度均值}
    const drift = compareFp(fp, this.baseline.fp);
    // 2. 静默变更检测：版本号变 or 行为漂移超阈值
    const changed = declared !== this.baseline.declared ||
      drift.score > 0.15;
    if (changed) {
      await alert({ type: 'model_change',
        declared, drift: drift.score,
        dims: drift.changed });
      // 3. 自动触发全量回归评测（门禁）
      const gate = await regressionGate({ model });
      await archive({ ts: Date.now(), declared, fp, gate });
      return { changed, gate,
        action: gate.pass ? '接受新版本，更新基线'
          : '回退或调整 prompt 适配' };
    }
    return { changed: false, drift: drift.score };
  }
  schedule() { return setInterval(() => this.probe(this.model),
    6 * 3600e3); }                   // 每 6h 探测一次
}
// fingerprint：正确率 / 平均长度 / 风格标记分布 三维。
```

**评分点**:
- 双指纹：声明版本号 + 行为指纹（正确率/风格/长度分布）——静默变更两层检测。
- Canary 定时探测（6h 级）自动报警并联动回归门禁。
- 变更处置有据（gate.pass 决定接受/回退），基线随接受更新。
- 变更历史归档可审计。
