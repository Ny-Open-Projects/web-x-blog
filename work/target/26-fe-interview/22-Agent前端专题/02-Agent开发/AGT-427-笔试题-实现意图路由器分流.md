## AGT-427：手写意图路由：规则优先、分类器兜底、成本感知降级

**需求与边界**：
- 输入：query、意图配置（每意图的处理函数与成本档）；输出：路由决策 {intent, handler, reason}。
- 边界要求：① 高频简单意图规则先行（正则/关键词，零成本）；② 分类器兜底（小模型判意图+置信度）；③ 低置信不硬路由→澄清或默认管线；④ 全局降级开关（高负载时全走便宜管线）。

**答**：
```javascript
class IntentRouter {
  constructor({ rules, classifier, handlers, degradeMode = null }) {
    this.rules = rules;                 // [{match, intent}]
    this.classifier = classifier;
    this.handlers = handlers;           // intent -> fn
    this.degradeMode = degradeMode;     // 高负载降级
  }
  async route(query, ctx = {}) {
    // 0. 全局降级：负载高时全走便宜默认管线
    if (ctx.loadLevel === 'high' && this.degradeMode)
      return { intent: 'default', handler: this.handlers.default,
        reason: 'degraded' };
    // 1. 规则优先（零成本，按优先级序）
    for (const r of this.rules)
      if (r.match(query)) return { intent: r.intent,
        handler: this.handlers[r.intent], reason: 'rule' };
    // 2. 分类器兜底
    const c = await this.classifier(query);
    if (c.confidence >= 0.8 && this.handlers[c.intent])
      return { intent: c.intent, handler: this.handlers[c.intent],
        reason: 'classifier', confidence: c.confidence };
    // 3. 低置信：澄清或安全默认（不硬路由）
    if (c.clarify) return { intent: 'clarify',
      handler: this.handlers.clarify, options: c.options,
      reason: 'low_confidence' };
    return { intent: 'default', handler: this.handlers.default,
      reason: 'fallback', confidence: c.confidence };
  }
}
// rules 示例：[{match: /^\/report/, intent: 'report'},
//   {match: /(退款|退货)/, intent: 'refund'}]
// 每意图的 handler 内部再决定固定管线 or Agent（成本分档）。
```

**评分点**:
- 三级路由：规则（零成本）→分类器（小模型+置信门槛）→澄清/安全默认，低置信不硬路由。
- 全局降级开关（高负载切默认管线）的成本意识。
- reason/confidence 随决策返回（可观测可归因）。
- 能说明路由器与后端"固定管线 vs Agent"的成本分档配合。
