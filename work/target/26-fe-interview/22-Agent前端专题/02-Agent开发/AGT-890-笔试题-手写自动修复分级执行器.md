## AGT-890：手写 respond：三级分级（L1自动可逆/L2起草/L3人工）、频率上限、快照撤销

**需求与边界**：
- 实现 respond(attribution, policy)。
- 边界要求：① L1 仅限白名单动作（toggleFlag/cdnRollback）且 24h 内同动作 ≤2 次；② L1 执行前快照（配置态），带 undo 闭包；③ L2 产出草稿进评审队列；④ L3 升级值班；⑤ 每次决策记录级别与原因。

**答**：
```javascript
class Responder {
  constructor(policy) { this.policy = policy; this.today = new Map(); }
  async respond(attr) {
    const level = this.pickLevel(attr);
    if (level === 'L1') {
      const k = attr.action.name;
      if ((this.today.get(k) ?? 0) >= this.policy.maxPerDay)
        return this.toL2(attr, '频率上限');         // 超限降级L2
      const snapshot = await captureState(k);      // 快照
      await attr.action.execute();
      this.today.set(k, (this.today.get(k) ?? 0) + 1);
      return { level: 'L1',
        undo: () => restoreState(snapshot) };      // undo闭包
    }
    return this[level === 'L2' ? 'toL2' : 'toL3'](attr);
  }
  pickLevel(attr) {
    if (this.policy.l1.includes(attr.action?.name)
      && attr.confidence > 0.9) return 'L1';
    if (attr.confidence > 0.5) return 'L2';
    return 'L3';
  }
  toL2(attr, why) { return reviewQueue.add({ attr, why, level: 'L2' }); }
  toL3(attr) { return page({ attr }); }
}
```

**评分点**:
- 三级判定清晰（白名单+高置信才 L1）；频率上限超限自动降 L2。
- L1 快照+undo 闭包（可逆性落实）；决策留痕。
