## AGT-740：手写 allocateBudget：模态权重、图片降档、关键图保底、超预算裁剪

**需求与边界**：
- 实现 allocateBudget(candidates, budget, query)。
- 边界要求：① 模态预算按 query 意图权重分配（问图表则 image 权重高）；② 图片三级：full/thumb/ref 依次降档，每档成本 1800/200/10 tokens；③ 检索分最高的图片保底 full（即使超预算）；④ 文本块超预算时按相关度裁剪并标记 truncated。

**答**：
```javascript
function allocateBudget(candidates, budget, query) {
  const w = modalityWeights(query);                // { image, text, ... }
  const tiers = { full: 1800, thumb: 200, ref: 10 };
  const sorted = [...candidates].sort((a, b) => b.score - a.score);
  let imgUsed = 0, textUsed = 0;
  const kept = [];
  for (const c of sorted) {
    if (c.kind === 'image') {
      const tier = imgUsed + tiers.full <= budget * w.image || c === sorted[0]
        ? 'full'                                   // Top1 保底 full
        : imgUsed + tiers.thumb <= budget * w.image ? 'thumb' : 'ref';
      imgUsed += tiers[tier];
      kept.push({ ...c, tier });
    } else {
      const cost = tokenCount(c.text);
      if (textUsed + cost > budget * w.text) {
        kept.push({ ...c, truncated: true,
          text: c.text.slice(0, Math.max(0,
            budget * w.text - textUsed) * 2) });   // 字符≈2倍token
        continue;
      }
      textUsed += cost; kept.push(c);
    }
  }
  return { kept, usage: { image: imgUsed, text: textUsed, budget } };
}
```

**评分点**:
- 模态权重按 query 意图动态分配（问图保图）。
- 图片三级降档 + Top1 保底 full（关键图不可降）。
- 文本裁剪标记 truncated（下游与引用层感知）。
