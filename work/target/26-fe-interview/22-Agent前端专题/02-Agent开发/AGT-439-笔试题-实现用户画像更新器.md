## AGT-439：手写画像更新：交互提炼标签、置信度滚动、敏感维度拦截、用户可改

**需求与边界**：
- 输入：交互事件、现有画像；输出：更新后的画像。
- 边界要求：① 标签需证据积累（单次不立标签，≥3 次一致才立）；② 置信度随证据滚动更新（新旧证据加权）；③ 敏感维度（健康/财务/宗教）禁止自动推断；④ 用户显式修正覆盖自动推断（权威级）。

**答**：
```javascript
const SENSITIVE_DIMS = ['health', 'finance', 'religion',
  'political', 'sexual'];
function updateProfile(profile, events, { extractTags }) {
  const auto = events.map(e => extractTags(e))    // [{dim, value}]
    .flat().filter(t => !SENSITIVE_DIMS.includes(t.dim)); // 敏感拦截
  for (const t of auto) {
    const key = `${t.dim}:${t.value}`;
    const cur = profile.get(key) ??
      { dim: t.dim, value: t.value, evidence: 0, conf: 0, ts: [] };
    cur.evidence++;
    cur.ts.push(e.ts);
    // 置信度滚动：证据数对数饱和 + 近期权重
    cur.conf = Math.min(0.95,
      0.2 * Math.log2(cur.evidence + 1) +
      recencyWeight(cur.ts));                     // 老证据衰减
    profile.set(key, cur);
  }
  // 用户显式修正：覆盖自动推断
  for (const u of events.filter(e => e.type === 'user_set')) {
    profile.set(`${u.dim}:${u.value}`, { ...u,
      conf: 1, source: 'user', locked: true });   // 权威锁定
  }
  // 清理低置信旧标签
  for (const [k, v] of profile)
    if (v.conf < 0.15 && !v.locked) profile.delete(k);
  return profile;
}
const recencyWeight = (ts) => {
  const recent = ts.filter(t => Date.now() - t < 30 * 864e5).length;
  return recent / ts.length * 0.3;
};
// 呈现：画像透明页可查看/编辑/删除（AGT-329 个性化合规）。
```

**评分点**:
- 证据门槛（单次不立标签）+ 置信度饱和公式与近期加权（滚动更新）。
- 敏感维度硬拦截（白名单方式而非黑名单遗漏）。
- 用户显式修正权威覆盖（source:'user' + locked）。
- 低置信自动清理防画像膨胀；透明可编辑的合规意识。
