## 1098：安全防线怎么接进 CI 门禁

**答**：
- 安全回归集进门禁：每次防线/模型/工具变更，红队用例集自动跑，高危类「零通过」是硬门禁（一个绕过都不许合并）；低危类通过率不低于基线。
- 分层门禁速度：全量红队集慢（含 LLM 攻击模拟），CI 只跑「静态可判定」子集（规则可判的注入/泄露），LLM 攻击模拟放夜间。
- 防线配置也是变更面：权限白名单、消毒规则改动同样触发安全门禁——「改个白名单」是最高频的安全事故入口。
- 追问钩子：门禁误报太多团队就会开始绕过门禁——怎么防？——误报样本当日归因：是检测规则太糙就修规则，是真风险就保留；门禁的可信度靠「每个误报都有处理结论」维持。

```ts
const securityGate = {
  on: ['prompts/**', 'permissions.yml', 'sanitizer/**'],
  hard: { zeroBypass: ['exec', 'exfil', 'delete'] },   // 高危零通过
  soft: { minIntercept: baseline - 0.02 },
  ci: 'static-subset', nightly: 'llm-attack-sim',
};
function gate(results) {
  const hardFail = results.filter(r => HARD.includes(r.vector) && r.bypass);
  return hardFail.length ? block(hardFail) : pass();
}
```
