## AGT-435：手写多语言问答：语言检测、双路检索（原文+翻译）、专名保留、本地化输出

**需求与边界**：
- 输入：query、locale、翻译函数、术语表；输出：本地化答案。
- 边界要求：① query 语言≠文档语言时双路检索（原文+翻译后）；② 专有名词翻译时保留原文（品牌/代码标识）；③ 输出术语用官方译法（术语表优先）；④ 数字与日期格式按 locale。

**答**：
```javascript
async function crossLingualQA(query, locale, { detect, translate,
  search, llm, glossary }) {
  const lang = detect(query);                    // 'zh' / 'en' ...
  const docLang = 'en';
  let results;
  if (lang !== docLang) {
    // 双路：原文检索 + 翻译检索（专名保留）
    const translated = await translate(query, docLang, {
      protect: extractProperNouns(query) });     // 专名不翻译
    const [r1, r2] = await Promise.all([
      search(query, 30), search(translated, 30)]);
    results = rrf([r1, r2], 10);
  } else {
    results = await search(query, 10);
  }
  const answer = await llm({
    docs: results,
    rules: [
      `以 ${locale} 回答`,
      `术语使用官方译法：${JSON.stringify(glossary[locale] ?? {})}`,
      `专有名词保留原文（首次出现可附译名）`,
      `数字/日期格式按 locale=${locale}（例：zh→2026年1月1日）`],
  });
  return { answer, lang, sources: results.map(r => r.docId) };
}
const extractProperNouns = (q) =>
  (q.match(/[A-Z][\w-]+|[\u4e00-\u9fa5]{2,6}(系统|平台|组件)/g) ?? []);
// 低资源语言：按 langQuality 分桶评测，弱语言答案标注提醒。
```

**评分点**:
- 双路检索（原文+保护专名的翻译）+ RRF 融合，跨语言召回保障。
- 专名提取与保护翻译（品牌/组件名不翻）。
- 术语表优先 + 数字日期 locale 格式化——本地化不止语言。
- 低资源语言分桶评测意识（语言质量不均衡治理）。
