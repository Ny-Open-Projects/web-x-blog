## AGT-329：基于记忆系统的用户画像与个性化怎么设计？

**答**:
- 画像的两类来源：显式（用户设置/主页资料——权威但少）与隐式（交互历史提炼：偏好/习惯/专业水平——量大但噪）——隐式画像经记忆写入判据（AGT-223）提炼为结构化标签（技术背景/沟通风格/常用场景），带置信度与时间戳。
- 个性化注入：会话开始按画像注入（"该用户是资深前端，回答可直接深入"）——注入的是"处理方式"不是"结论预置"；画像错误会系统性带偏所有回答，注入前过相关性判断（本次任务是否与该画像维度相关）。
- 更新与遗忘：画像随交互滚动更新（新证据覆盖旧标签+置信度更新）；用户可见可编辑（画像透明页——个性化必须可解释可修正，否则"被算法定义"引发反感）。
- 边界：个性化不用于敏感维度（健康/财务状况推断标签敏感——合规红线），跨场景画像共享需用户授权。

```javascript
async function personalizedSession(user, task) {
  const profile = await memory.getProfile(user);  // 标签+置信度
  const relevant = profile.filter(p =>
    p.conf > 0.7 && relatedTo(task, p.dim));      // 相关性过滤
  return {
    system: SYSTEM + profileBlock(relevant),
    note: '画像可在设置页查看与编辑',             // 透明可修正
  };
}
// 敏感维度禁用；跨场景共享需授权。
```
