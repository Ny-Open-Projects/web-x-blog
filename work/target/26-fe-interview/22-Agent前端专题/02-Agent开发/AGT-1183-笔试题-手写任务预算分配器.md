## 1183：笔试手写：实现按历史占比的预算分配与动态回流

**答**：实现 Budget(total, hist)：hist 为 { [step]: 历史成本数组 }，按各步骤历史 P50 占比分配预算（P50 计算：排序取中位，偶数长度取中间两位均值）。spend(step, n)：本步剩余够则扣减返回 'ok'；不够但池（未分配+其他步骤剩余的 50%）够则借返回 'borrowed'；否则 'stop'。release(step, n) 回流。

```js
function p50(a) {
  const s = [...a].sort((x, y) => x - y);
  const m = s.length >> 1;
  return s.length % 2 ? s[m] : (s[m - 1] + s[m]) / 2;
}
class Budget {
  constructor(total, hist) {
    const med = Object.fromEntries(Object.entries(hist)
      .map(([k, v]) => [k, p50(v)]));
    const sum = Object.values(med).reduce((a, b) => a + b, 0) || 1;
    this.left = Object.fromEntries(Object.entries(med)
      .map(([k, m]) => [k, total * m / sum]));       // 按占比分配
    this.total = total;
  }
  pool() { return this.total - Object.values(this.left).reduce((a, b) => a + b, 0); }
  spend(step, n) {
    if (this.left[step] >= n) { this.left[step] -= n; return 'ok'; }
    if (this.pool() >= n) { this.left[step] -= n; return 'borrowed'; } // 借池
    return 'stop';
  }
  release(step, n) { this.left[step] += n; }
}
const b = new Budget(100, { plan: [10, 20], exec: [60, 80], review: [10, 30] });
console.log(b.spend('exec', 90) === 'stop' || b.spend('exec', 50)); // 结构验证
```

**评分点**：
- P50 计算正确（奇偶分支）；占比分配含除零保护
- spend 的三级语义（ok/borrowed/stop）与池的计算正确（total - 已分配剩余之和）
- 能讨论：借池的 50% 限制（防早期步骤挥霍）、回流激励（提前完成步骤回流池供关键步骤借用）
