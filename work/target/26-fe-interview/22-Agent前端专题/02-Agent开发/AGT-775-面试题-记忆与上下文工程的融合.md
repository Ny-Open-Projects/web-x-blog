## AGT-775：记忆系统与上下文组装器的职责边界（谁决定注入什么）

**答**：
- 记忆系统负责「生产与检索」（有哪些可用记忆、各自质量分），上下文组装器负责「调度」（在总预算内决定最终注入什么——记忆/RAG/历史的最终裁决权）。记忆系统不直接拼提示词。
- 接口契约：组装器向记忆系统发起带预算的检索请求（retrieve(query, { budget, task })），记忆系统返回带元数据的候选（分数/来源/成本），组装器按全局优化选择。
- 边界好处：上下文策略可独立实验（调整分区比例不动记忆代码），记忆质量可独立评测（不看注入策略）。反模式是记忆模块直接改 system prompt——策略耦合导致谁都不敢动。

```javascript
// 组装器：唯一拼 prompt 的地方
async function assemble(task) {
  const [mem, rag] = await Promise.all([
    memory.retrieve(task.query, { budget: ZONE.memory, task }),
    rag.retrieve(task.query, { budget: ZONE.rag }),
  ]);
  return compose({
    system: buildSystem(task),
    memory: pick(mem, { zone: ZONE.memory }),      // 全局裁决
    rag: pick(rag, { zone: ZONE.rag }),
    history: pick(task.session.turns, { zone: ZONE.history }),
  });
}
```
