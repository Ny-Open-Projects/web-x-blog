## AGT-795：手写 forgetScope：范围解析（单条/会话/全部）、层级联、缓存失效、审计

**需求与边界**：
- 实现 forgetScope(userId, scope)。
- 边界要求：① scope ∈ { item(id), session(id), all }；② 级联顺序：语义→情景→画像→向量→缓存→备份标记；③ all 模式必须二次确认标志 confirmed；④ 失败项收集不中断；⑤ 审计只记数量与 hashId（不记内容）。

**答**：
```javascript
async function forgetScope(userId, scope, { confirmed = false } = {}) {
  if (scope === 'all' && !confirmed)
    throw new Error('NEED_CONFIRM');               // 全删需确认
  const ids = scope === 'item' ? [scope.id]
    : scope === 'session' ? await semantic.bySession(scope.id)
    : await semantic.byUser(userId);
  const failed = [];
  for (const id of ids) {
    try {
      const m = await semantic.get(id);
      await semantic.delete(id);
      if (m.vecId) await vector.remove(m.vecId);   // 向量级联
      await episodic.purgeByOrigin(id);
      await cache.bust(`mem:${userId}`);
    } catch (e) { failed.push({ id, err: e.message }); }
  }
  if (scope === 'all') {
    await profile.clear(userId);
    await backup.markTombstone(userId);            // 备份打墓碑
  }
  audit.log({ action: 'memory.forget', userId: hashId(userId),
    scope, count: ids.length - failed.length, at: Date.now() });
  return { deleted: ids.length - failed.length, failed };
}
```

**评分点**:
- 三级范围 + all 强制确认；级联五层完整（含向量与备份墓碑）。
- 失败收集不中断（部分成功可见）；审计脱敏（hashId+数量）。
