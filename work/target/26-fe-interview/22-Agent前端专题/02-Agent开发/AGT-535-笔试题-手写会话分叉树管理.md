## AGT-535：手写消息树与激活路径：分叉、切换、渲染路径推导

**需求与边界**：
- 输入：消息数组（每条含 id/parentId/role/content），支持 fork（在任意消息后编辑重发）、switchBranch（切换兄弟分支）、activePath（推导当前展示路径）。
- 边界要求：① parentId 缺失视为根；② 环引用要检测并抛错；③ 切换分支后 leaf 引用正确维护；④ 空树返回空路径。

**答**：
```javascript
class MessageTree {
  constructor() { this.nodes = new Map(); this.leaf = null; }
  add(id, parentId, data) {
    if (parentId !== null && !this.nodes.has(parentId))
      throw new Error('parent not found');
    this.nodes.set(id, { id, parentId, ...data });
    this.leaf = id;
    return id;
  }
  fork(afterId, newId, data) {          // 编辑重发：以同 parent 挂新节点
    const n = this.nodes.get(afterId);
    if (!n) throw new Error('node not found');
    return this.add(newId, n.parentId, data);
  }
  activePath() {                        // 从 leaf 回溯到根
    const path = []; let cur = this.leaf;
    const seen = new Set();
    while (cur) {
      if (seen.has(cur)) throw new Error('cycle detected');  // 环检测
      seen.add(cur);
      const n = this.nodes.get(cur);
      if (!n) break;                    // 父缺失（被删）：到此为止
      path.unshift(n); cur = n.parentId;
    }
    return path;
  }
  switchBranch(nodeId) {                // 切到某分支：leaf 变为该分支最深叶
    this.leaf = this.deepestLeaf(nodeId);
  }
  deepestLeaf(id) {
    let cur = id;
    for (;;) {
      const kids = [...this.nodes.values()].filter(n => n.parentId === cur);
      if (!kids.length) return cur;
      cur = kids[kids.length - 1].id;   // 默认取最新分支
    }
  }
}
```

**评分点**:
- 用 parentId 单向引用建模消息树，编辑重发是 fork 到同父新分支而非原地改。
- activePath 从 leaf 回溯，含环检测与父缺失兜底（空树/断链不崩）。
- 切换分支维护 leaf 指针（deepestLeaf），兄弟分支计数支持 < 2/2 > UI。
