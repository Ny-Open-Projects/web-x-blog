## AGT-564：LaTeX 公式在流式输出中如何渲染（不完整公式/定界符跨chunk/性能）

**答**：
- 公式块（$$...$$ 或 \(...\)）在流式中先按"未闭合公式"处理：识别起始定界符后进入公式缓冲态，闭合前只显示原始文本（等宽+浅底色），闭合后再整体交给 KaTeX 渲染。
- 定界符可能被 chunk 切断（$$ 在两个 delta 里），识别要在「合并后的缓冲」上做而不是单 delta。
- 性能：KaTeX 渲染单个公式是毫秒级，但流式中每 delta 重渲染全文会爆；策略是"闭合才渲染 + 渲染结果缓存"，已完成公式不重复渲染。

```javascript
function FormulaAwareRenderer {
  buffer = ''; formulas = new Map();   // id → rendered html
  push(delta) {
    this.buffer += delta;
    // 在合并缓冲上找完整公式
    this.buffer = this.buffer.replace(
      /\$\$([\s\S]+?)\$\$/g, (_, tex) => this.render(tex));
    flushText(this.buffer.split(/\$\$[\s\S]*?/)[0] ?? this.buffer);
  }
  render(tex) {
    const id = hash(tex);
    if (!this.formulas.has(id))
      this.formulas.set(id, katex.renderToString(tex,
        { throwOnError: false }));    // 语法错误降级为原文
    return this.formulas.get(id);
  }
}
```
