## AGT-844：手写 promote：配置diff预览、评测门禁、数据源环境绑定校验、审计

**需求与边界**：
- 实现 promote(agentVer, from, to)。
- 边界要求：① 生成配置 diff（工具/提示词/参数/数据源）供确认；② 评测门禁：prod 评测集通过率 ≥ 基线-2pp 且安全用例全过；③ 数据源绑定校验（test 数据源不可晋升到 prod——脱敏数据源误上生产）；④ 晋升写审计（diff+决策人）；⑤ 同版本重复晋升幂等。

**答**：
```javascript
async function promote(agentVer, from = 'test', to = 'prod') {
  if (await deployedAt(agentVer, to))
    return { idempotent: true };                   // 重复晋升幂等
  const diff = configDiff(agentVer[from], agentVer[to]);
  const dsViolation = diff.dataSources.some(d =>
    d.testOnly || d.masked);                       // 数据源校验
  if (dsViolation)
    return { block: 'data-source',
      note: '测试/脱敏数据源不可晋升到生产' };
  const run = await runEval(agentVer, { set: 'prod-suite' });
  const gate = run.passRate >= baseline - 0.02
    && run.security.every(r => r.verdict === 'blocked');
  if (!gate) return { block: 'eval-gate',
    failures: run.failures.slice(0, 10) };
  await deploy(agentVer, to);
  audit.log({ type: 'agent.promote', ver: agentVer.id,
    from, to, diff, by: currentUser.id, at: Date.now() });
  return { ok: true, diff };
}
```

**评分点**:
- diff 预览先行（晋升前知情）；数据源环境绑定硬校验（脱敏源上生产是事故）。
- 双门禁（通过率+安全一票否决）；审计带 diff 与决策人。
- 幂等（重复晋升直接返回）。
