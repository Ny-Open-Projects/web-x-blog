## AGT-463：手写工具预算：工具级定价、任务内分配、昂贵工具审批降级

**需求与边界**：
- 输入：工具价目表、任务预算、调用请求；输出：允许/拒绝/降级。
- 边界要求：① 每工具预估成本（token+外部 API 费）；② 任务内按工具类别配额（昂贵工具单独上限）；③ 昂贵调用超限→降级为便宜替代或人审；④ 剩余预算随调用扣减可查。

**答**：
```javascript
class ToolBudget {
  constructor({ pricing, taskBudget, categoryCaps }) {
    // pricing: { web_search: 0.01, deep_research: 0.5, code_exec: 0.05 }
    this.pricing = pricing;
    this.remain = { total: taskBudget,
      ...Object.fromEntries(Object.entries(categoryCaps ?? {})
        .map(([k, v]) => [k, v])) };
  }
  request(tool, estCost) {
    const price = estCost ?? this.pricing[tool] ?? 0.01;
    // 1. 总预算检查
    if (price > this.remain.total)
      return { allow: false, reason: '总预算不足',
        remain: this.remain.total };
    // 2. 类别配额（昂贵工具单独上限）
    const cat = toolCategory(tool);             // cheap/expensive
    if (cat === 'expensive') {
      if (price > (this.remain[tool] ?? Infinity))
        return { allow: false, reason: '昂贵工具配额不足',
          alternatives: cheaperAlternatives(tool) };   // 降级建议
      this.remain[tool] -= price;
    }
    // 3. 扣减与返回
    this.remain.total -= price;
    return { allow: true, price,
      remainTotal: this.remain.total,
      note: price > 0.2 ? '昂贵调用：建议确认必要性' : null };
  }
  status() { return { ...this.remain,
    burnRate: this.burned / this.elapsedSteps }; }  // 燃烧率可监控
}
// cheaperAlternatives: deep_research → web_search×3
// 或转人审（用户确认后临时提额）。
```

**评分点**:
- 工具级定价+总预算双维度检查，类别配额隔离昂贵工具。
- 超限返回降级建议（便宜替代）而非裸拒绝。
- 昂贵调用提示确认（>0.2 阈值）与人审衔接。
- 剩余预算与燃烧率可监控（超速预警）。
