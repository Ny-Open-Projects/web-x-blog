## AGT-748：手写 ObjectRegistry：注册/指代解析辅助/会话缓存复用/容量淘汰

**需求与边界**：
- 实现 ObjectRegistry：register(asset, desc)/touch(id)/recent(n)/gc(max)。
- 边界要求：① 注册生成会话内短 id（obj-1 递增）供指代；② touch 更新 lastMentionAt；③ recent 返回最近提及排序；④ gc 超容量淘汰最久未提及（但被当前回答引用的不淘汰）；⑤ desc 存摘要（省内存）。

**答**：
```javascript
class ObjectRegistry {
  constructor() { this.map = new Map(); this.seq = 0; }
  register(asset, desc) {
    const id = `obj-${++this.seq}`;
    this.map.set(id, { id, kind: asset.kind, assetId: asset.id,
      desc: summarize(desc, 80), lastMentionAt: Date.now() });
    return id;
  }
  touch(id) {
    const o = this.map.get(id);
    if (!o) throw new Error('NO_OBJECT');
    o.lastMentionAt = Date.now();
  }
  recent(n = 5) {
    return [...this.map.values()]
      .sort((a, b) => b.lastMentionAt - a.lastMentionAt).slice(0, n);
  }
  gc(max, pinned = new Set()) {                     // pinned=被引用
    if (this.map.size <= max) return [];
    const sorted = [...this.map.values()]
      .sort((a, b) => a.lastMentionAt - b.lastMentionAt);
    const evict = [];
    for (const o of sorted) {
      if (this.map.size - evict.length <= max) break;
      if (pinned.has(o.id)) continue;               // 引用中不淘汰
      this.map.delete(o.id); evict.push(o.id);
    }
    return evict;
  }
}
```

**评分点**:
- 会话短 id（obj-N）支持序号指代；touch 维护时序。
- gc 的 pinned 保护（被当前回答引用的资产不淘汰）。
- desc 摘要存储（对象表不膨胀）。
