## AGT-645：手写 unbiasedPercentile：按采样率反加权、加权分位数、有效样本量

**需求与边界**：
- 实现 unbiasedPercentile(samples, field, p)。
- 边界要求：① 每样本带 sampleProb（采样概率），权重 = 1/prob；② 加权分位数：按权重累计排序取位；③ 有效样本量 = 权重和（反映真实总量）；④ prob 缺省 1（未加权样本兼容）；⑤ 空集返回 null。

**答**：
```javascript
function unbiasedPercentile(samples, field, p) {
  if (!samples.length) return null;
  const rows = samples.map(s => ({
    v: s[field],
    w: 1 / (s.sampleProb ?? 1),                 // 缺省全采
  })).filter(r => Number.isFinite(r.v)).sort((a, b) => a.v - b.v);
  const total = rows.reduce((a, r) => a + r.w, 0);  // 有效样本量
  let acc = 0;
  for (const r of rows) {
    acc += r.w;
    if (acc / total >= p) return r.v;           // 加权累计到位
  }
  return rows[rows.length - 1].v;
}
function effectiveN(samples) {
  return samples.reduce((a, s) => a + 1 / (s.sampleProb ?? 1), 0);
}
// 用法：高成本任务按 0.5 加采，直算 P95 会虚高
// unbiasedPercentile(traces, 'latency', 0.95)  // 反加权后可信
```

**评分点**:
- 权重 = 1/采样概率（反加权思想正确），prob 缺省兼容全采样本。
- 加权分位数按权重累计（非样本计数），有效样本量反映真实总量。
- 空集 null 兜底。
