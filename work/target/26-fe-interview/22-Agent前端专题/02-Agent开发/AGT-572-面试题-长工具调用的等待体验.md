## AGT-572：某工具要跑 30s~2min（深度检索/代码执行），等待体验怎么设计

**答**：
- 分层反馈：立即 ack（<100ms 显示"已发起 X"）、进度事件（服务端有就展示百分比/阶段文案）、无进度时给"预期时长"管理预期（"通常需要 1 分钟"）。
- 可离开：等待期间允许用户切走做别的（任务不依赖页面存活），完成时用通知/未读红点召回；这与"用户必须盯着"的短工具交互不同。
- 超过预期时长 2 倍时提供"取消并返回已有部分"（如果工具支持部分产出）。

```javascript
function LongToolWait({ tc }) {
  const [stage, setStage] = useState('started');
  useEffect(() => tc.on('progress', p => setStage(p.stage)), []);
  useEffect(() => {
    const t = setTimeout(() => ui.offer('耗时超过预期，取消并保留已有产出？',
      () => tc.cancel({ keepPartial: true })), tc.expectedMs * 2);
    return () => clearTimeout(t);
  }, [tc.id]);
  return <StageHint stage={stage} expected="通常需要 1 分钟"
    leaveSafe={true} />;   // 可离开，完成通知召回
}
```
