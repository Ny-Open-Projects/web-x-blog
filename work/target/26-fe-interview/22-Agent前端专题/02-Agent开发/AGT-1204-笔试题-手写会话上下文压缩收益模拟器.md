## 1204：笔试手写：对比三种压缩策略的会话成本与信息保留

**答**：实现 simulate(turns, strategy)：strategy = 'none' | 'rolling'（超 1500 保留近 4 条+摘要 30%）| 'entity'（保留含数字/ID 的轮次原文+其余摘要）。token = 字符/4。输出 { totalTokens, keptOriginal: 保留原文的轮次数 }（两策略对比信息保留量）。entity 策略判定含数字（\d）或大写连续 ID 的轮次为关键轮。

```js
function est(s) { return Math.ceil(s.length / 4); }
const hasKeyFact = t => /\d|[A-Z]{2,}/.test(t);
function simulate(turns, strategy, { compactAt = 1500, keep = 4, ratio = 0.3 } = {}) {
  let ctx = '', total = 0, keptOriginal = 0;
  for (const t of turns) {
    total += est(ctx) + est(t);
    if (strategy === 'none') { ctx += t + '\n'; continue; }
    ctx += t + '\n';
    if (est(ctx) > compactAt) {
      const lines = ctx.split('\n').filter(Boolean);
      let keepLines;
      if (strategy === 'rolling') {
        keepLines = lines.slice(-keep);
      } else {
        keepLines = lines.filter(hasKeyFact);
        if (!keepLines.length) keepLines = lines.slice(-keep); // 无关键轮兜底
      }
      keptOriginal += keepLines.length;
      const old = lines.filter(l => !keepLines.includes(l));
      ctx = '[摘要]' + old.join(' ').slice(0,
        Math.ceil(old.join(' ').length * ratio)) + '\n' + keepLines.join('\n') + '\n';
    }
  }
  return { totalTokens: total, keptOriginal };
}
const turns = Array.from({ length: 15 }, (_, i) =>
  i % 3 === 0 ? '订单 ORD-' + i + 金额 99 元 : '普通讨论轮次 ' + i);
console.log(simulate(turns, 'none'));
console.log(simulate(turns, 'entity'));
```

**评分点**：
- 三策略分支完整；entity 的关键轮判定（数字/ID 正则）与空兜底
- keptOriginal 作为「信息保留量」代理指标（成本-保留权衡可视化）
- 压缩触发时机的统一入口
- 能讨论：entity 策略对数字类问答的保留收益、模拟器驱动策略选型的实验设计
