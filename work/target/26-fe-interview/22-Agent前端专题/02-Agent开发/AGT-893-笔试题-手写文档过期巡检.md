## AGT-893：手写 docsPatrol：示例可运行巡检、链接巡检、AI修复草稿、人工区豁免

**需求与边界**：
- 实现 docsPatrol(docs)。
- 边界要求：① 代码示例逐个沙箱运行（超时 5s），失败标 stale；② 外链 HTTP 巡检（并发限 10，4xx/5xx 标断链）；③ AI 生成修复草稿（不直接改）；④ 人工区（decision/tradeoff 段）跳过不巡；⑤ 输出巡检报告+草稿清单。

**答**：
```javascript
async function docsPatrol(docs, { humanZone = ['决策', '取舍'] } = {}) {
  const report = [];
  for (const d of docs) {
    if (humanZone.some(z => d.path.includes(z))) continue; // 人工区豁免
    for (const ex of d.examples) {
      const r = await withTimeout(sandboxRun(ex), 5000);
      if (!r.ok) report.push({ path: d.path, kind: 'stale-example',
        line: ex.line, draft: await ai.fixExample(ex) });  // 修复草稿
    }
    const links = await pMap(d.links, checkLink, { concurrency: 10 });
    report.push(...links.filter(l => !l.ok)
      .map(l => ({ path: d.path, kind: 'broken-link', url: l.url })));
  }
  return { checked: docs.length, issues: report,
    drafts: report.filter(r => r.draft) };         // 草稿待确认
}
```

**评分点**:
- 示例沙箱运行+超时（过期判据客观）；人工区豁免（AI 不碰决策记录）。
- 修复只出草稿不直接改（文档变更可审）。
- 链接巡检并发限制。
