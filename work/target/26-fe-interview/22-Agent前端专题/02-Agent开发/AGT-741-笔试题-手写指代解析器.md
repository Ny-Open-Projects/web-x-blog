## AGT-741：手写 resolveReference：对象表注册、最近提及优先、多候选点选、操作映射

**需求与边界**：
- 实现 resolveReference(utterance, session)。
- 边界要求：① session.objects 每项 { id, desc, lastMentionAt, kind }；② 解析优先级：明确序号引用 > 描述匹配 > 最近提及 > 唯一对象推断；③ 多候选且无法唯一时返回 pick-needed；④ 序号引用越界抛错；⑤ 支持操作解析（zoom/column/segment）映射到结构化 op。

**答**：
```javascript
function resolveReference(utterance, session) {
  const objs = session.objects;
  const seq = utterance.match(/第(\d+)个|图(\d+)/);
  if (seq) {
    const idx = +(seq[1] ?? seq[2]) - 1;
    if (idx < 0 || idx >= objs.length)
      throw new Error('SEQ_OUT_OF_RANGE');         // 序号越界
    return { obj: objs[idx], confidence: 1 };
  }
  const matched = objs.filter(o => mentionMatch(utterance, o.desc));
  if (matched.length === 1)
    return { obj: matched[0], confidence: 0.8 };
  if (matched.length === 0 && objs.length === 1)
    return { obj: objs[0], confidence: 0.5 };      // 唯一推断
  if (matched.length > 1)
    matched.sort((a, b) => b.lastMentionAt - a.lastMentionAt);
  if (matched.length && matched[0].lastMentionAt
    > matched[1]?.lastMentionAt + 60000)
    return { obj: matched[0], confidence: 0.6 };   // 最近提及显著领先
  return { pickNeeded: matched.length ? matched : objs }; // 让用户点选
}
function toOp(utterance) {
  if (/放大|看不清/.test(utterance)) return { type: 'zoom' };
  if (/第(\S+)列/.test(utterance))
    return { type: 'column', col: RegExp.$1 };
  if (/那段视频|第(\d+)分钟/.test(utterance)) return { type: 'segment' };
  return null;
}
```

**评分点**:
- 四级解析优先级明确（序号>描述>最近>唯一），越界抛错不猜。
- 无法唯一时返回 pickNeeded（候选点选而非瞎选）。
- 指代操作映射为结构化 op（zoom/column/segment），由数据操作而非重新理解。
