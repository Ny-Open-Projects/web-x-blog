## 1072：评测基建怎么设计成可跨项目复用

**答**：
- 分层设计：内核（执行器、断言引擎、聚合、门禁）与项目层（评估集、判分器、rubric）分离；内核通用、项目层声明式配置。
- 接口契约：项目只需实现三个函数——loadCases()、runCase(case)、grade(output, case)；内核负责并发、重试、聚合、报告、门禁。
- 复用的边界：断言库（containsAll/toolSeq 等）沉淀为公共库；「意图分类」「聚类看板」等强业务组件做成可插拔扩展而非内置。
- 追问钩子：过度抽象的信号？——内核开始出现「为某个项目特判」的 if 分支；正确方向是把这些变成项目层的自定义断言/钩子。

```ts
// 内核：只依赖契约
async function runSuite(project, { concurrency = 16, gate = true }) {
  const cases = await project.loadCases();
  const rs = await pMap(cases, c => project.runCase(c).then(o =>
    ({ ...project.grade(o, c), case: c.id })), { concurrency });
  const report = aggregate(rs);
  return { ...report, gate: gate ? project.gatePolicy(report) : null };
}
// 项目层：三个函数 + 配置
const myProject = { loadCases, runCase, grade, gatePolicy };
```
