## AGT-468：手写评测统计报告：成功率置信区间、版本差异显著性、最小样本反推

**需求与边界**：
- 输入：新旧版本评测结果（成功次数/总数）；输出：区间+显著性+决策。
- 边界要求：① 成功率 Wilson 置信区间（小样本友好）；② 版本差异用比例检验近似（含显著性判断）；③ 样本量反推（给定 MDE 求最小样本）；④ 结论带"不显著≠无差异"提示。

**答**：
```javascript
function evalReport({ successes: s1, total: n1 },
                    { successes: s2, total: n2 },
                    { mde = 0.02, alpha = 0.05 } = {}) {
  const wilson = (s, n) => {
    const p = s / n, z = 1.96;
    const d = 1 + z * z / n;
    const center = (p + z * z / (2 * n)) / d;
    const half = z * Math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d;
    return { point: p, low: center - half, high: center + half };
  };
  const c1 = wilson(s1, n1), c2 = wilson(s2, n2);
  // 差异显著性（比例差的 z 检验近似）
  const p = (s1 + s2) / (n1 + n2);
  const se = Math.sqrt(p * (1 - p) * (1 / n1 + 1 / n2));
  const z = (s1 / n1 - s2 / n2) / (se || 1);
  const significant = Math.abs(z) > 1.96;
  // 最小样本反推：检测 MDE 需要
  const minSample = Math.ceil(16 * p * (1 - p) / (mde * mde));
  return {
    old: c1, new: c2,
    delta: c2.point - c1.point,
    significant, z,
    minSampleForMde: minSample,
    advice: n1 < minSample
      ? `样本不足（${n1}/${minSample}），结论不可靠`
      : significant
        ? `显著${c2.point > c1.point ? '提升' : '下降'}，可决策`
        : '不显著（不等于无差异），建议扩样本或延长观察',
  };
}
```

**评分点**:
- Wilson 区间正确实现（小样本友好，优于正态近似）。
- 差异显著性 z 检验近似与 1.96 阈值（alpha=0.05）。
- MDE 反推最小样本量，样本不足明确提示不可靠。
- "不显著≠无差异"的统计素养提示。
