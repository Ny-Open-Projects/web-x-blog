## AGT-773：个性化会不会造成不同用户服务质量差异（马太效应/新用户歧视）

**答**：
- 风险识别：重度用户画像丰富回答越来越好、新用户画像空回答平庸（马太效应）；画像错误的用户被持续错配（越错越偏）。对策：新用户保底质量线（前 N 轮用通用高质量模板）、画像置信度低时不做激进行为适配。
- 服务差异的可接受边界：表达风格可以个性化，事实质量/能力范围/响应优先级不得因画像差异（不能付费用户画像插队）。
- 审计机制：按画像分组的回答质量分布定期审计，组间差异超阈值（如某水平段负反馈率 2 倍）触发策略复盘。

```javascript
async function fairnessAudit() {
  const groups = groupUsersBy(profileConfidence);
  const quality = await Promise.all(groups.map(g =>
    ({ group: g.name, dislikeRate: dislikeRate(g),
      doneRate: doneRate(g) })));
  const spread = maxBy(quality, 'dislikeRate').dislikeRate
    / minBy(quality, 'dislikeRate').dislikeRate;
  return { quality, spread,
    action: spread > 2 ? 'review-policy' : null,   // 组间差异审计
  };
}
```
