## AGT-657：评测失败后，如何知道「这个失败」是已知失败模式的重复还是新空白

**答**：
- 给评测集画「覆盖地图」：用例按（能力维度 × 难度 × 场景）标注坐标，失败案例落在图上，一眼看出是已有格子里的重复失败（已知模式，走既有归因）还是空白格（新发现，需新建用例模式）。
- 失败去重：新失败先与失败模式库匹配（指纹/嵌入相似度），匹配上就归并计数，不重复建用例——否则评测集被同一类失败淹没。
- 空白格优先级：按线上出现频率加权，线上高频的空白格子优先补用例。

```javascript
const CAPS = ['retrieval', 'tool_use', 'reasoning', 'format', 'safety'];
const DIFFS = ['easy', 'mid', 'hard'];
function coverageMap(failures, cases) {
  const grid = new Map();                         // 能力×难度 格子
  for (const c of cases) grid.set(key(c.cap, c.diff), c);
  return failures.map(f => {
    const k = key(f.cap, f.diff);
    return { ...f, known: !!FAILURE_LIB.match(f),
      cell: k, blank: !grid.get(k) ? 'new-blank' : 'occupied' };
  });
}
function prioritizeBlanks(blanks, onlineFreq) {
  return blanks.sort((a, b) => onlineFreq[b.cell] - onlineFreq[a.cell]);
}
```
