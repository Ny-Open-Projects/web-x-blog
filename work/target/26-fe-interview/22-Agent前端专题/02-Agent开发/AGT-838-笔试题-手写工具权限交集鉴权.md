## AGT-838：手写 authorizeTool：RBAC∩Agent授权、ABAC数据过滤、destructive审批、审计

**需求与边界**：
- 实现 authorizeTool(tc, user, agent)。
- 边界要求：① 允许条件 = 用户角色允许 ∧ Agent 声明可用，交集；② ABAC 对参数做数据范围过滤（部门/区域字段），过滤后参数变化要记录；③ risk=destructive 返回 needApproval 带审批链；④ 每次决策写审计（allow/deny 都记）；⑤ 未知工具 deny-by-default。

**答**：
```javascript
async function authorizeTool(tc, user, agent) {
  const meta = TOOLS[tc.tool];
  if (!meta) return deny(tc, 'unknown-tool');      // 默认拒绝
  const rbacOk = (await userRoles(user)).includes(tc.tool)
    && agent.grants.includes(tc.tool);             // 交集
  if (!rbacOk) return deny(tc, 'rbac-or-agent-scope');
  let args = tc.args;
  const filtered = await abacFilter(args, user, meta.scopeFields);
  if (changed(filtered, args))
    audit.log({ type: 'tool.args.filtered', tool: tc.tool,
      user: user.id });                            // 过滤留痕
  if (meta.risk === 'destructive')
    return { ok: false, needApproval: true,
      chain: [user.id, user.manager ?? 'manager'],
      args: filtered };
  audit.log({ type: 'tool.authz', tool: tc.tool,
    user: user.id, allow: true });
  return { ok: true, args: filtered };
}
function deny(tc, reason) {
  audit.log({ type: 'tool.authz', tool: tc.tool, deny: reason });
  return { ok: false, reason };
}
```

**评分点**:
- RBAC∩Agent 授权交集 + deny-by-default（未知工具拒绝）。
- ABAC 过滤后参数变化留痕；destructive 走审批链不静默执行。
- allow/deny 双向审计。
