## AGT-899：手写 contractDrift：schema diff、类型再生成、编译报错定位、AI适配建议

**需求与边界**：
- 实现 contractDrift(oldSchema, newSchema)。
- 边界要求：① 三类变更：breaking（删字段/改类型/必填新增）、additive（新增可选）、cosmetic（描述变化）；② breaking 产出受影响调用点（编译前端类型报错定位）；③ AI 适配建议附每处影响点；④ additive 直接通过（自动再生成类型）；⑤ 输出 verdict（pass/break）。

**答**：
```javascript
function contractDrift(oldS, newS) {
  const diff = schemaDiff(oldS, newS);
  const breaking = diff.changes.filter(c =>
    c.kind === 'removed' || c.kind === 'type-changed'
    || (c.kind === 'required-added'));
  const additive = diff.changes.filter(c => c.kind === 'optional-added');
  if (!breaking.length) {
    regenTypes(newS);                              // additive自动通过
    return { verdict: 'pass', additive: additive.length };
  }
  regenTypes(newS);
  const impacted = compileErrors()                 // 报错即漂移点
    .map(e => ({ file: e.file, line: e.line, field: e.field }));
  return { verdict: 'break', breaking,
    impacted,
    suggestions: impacted.map(p =>
      ai.suggest(p, breaking.find(b => b.field === p.field))) };
}
```

**评分点**:
- 三类变更分级（additive 自动通过不阻塞日常迭代）；breaking 三判据正确。
- 编译报错定位受影响调用点（漂移可定位）。
- AI 适配建议逐点附加（可行动）。
