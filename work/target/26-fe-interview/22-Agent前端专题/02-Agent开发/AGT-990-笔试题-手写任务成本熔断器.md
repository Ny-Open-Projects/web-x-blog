## 990：笔试手写：实现单任务 token 成本熔断与恢复

**答**：实现 CostGuard(opts)：{ limit, windowMs, rate }。spend(n) 记录消耗，超 limit 抛 CostExceeded；每分钟消耗速率超过 rate 连续 2 个采样点抛 RunawayLoop（防失控循环）；reset() 清空。getReport() 返回 { total, rate }。用滑动窗口统计。

```js
class CostGuard {
  constructor({ limit, windowMs = 60000, rate }) {
    this.limit = limit; this.windowMs = windowMs; this.rate = rate;
    this.events = []; this.rateHits = 0; this.total = 0;
  }
  spend(n) {
    const now = Date.now();
    this.events.push({ t: now, n });
    this.total += n;
    // 滑动窗口速率检查
    const inWin = this.events.filter(e => now - e.t <= this.windowMs);
    const sum = inWin.reduce((s, e) => s + e.n, 0);
    const perMin = (sum / this.windowMs) * 60000;
    this.rateHits = perMin > this.rate ? this.rateHits + 1 : 0;
    if (this.rateHits >= 2) throw new RunawayLoop(perMin);  // 连续2采样超速
    if (this.total > this.limit) throw new CostExceeded(this.total, this.limit);
    return this.total;
  }
  reset() { this.events = []; this.total = 0; this.rateHits = 0; }
  getReport() { return { total: this.total,
    rate: (this.events.filter(e => Date.now() - e.t <= this.windowMs)
      .reduce((s, e) => s + e.n, 0) / this.windowMs) * 60000 }; }
}
```

**评分点**：
- 熔断两条件语义清晰：总量上限（硬熔断）+ 速率异常（失控循环检测）
- 速率用滑动窗口而不是固定分钟桶（边界突刺更平滑）
- rateHits 连续计数防偶发尖刺误杀
- 能讨论：熔断后应输出「已完成进展摘要」而非静默失败；reset 时机由编排器决定
