## 1190：笔试手写：检测编排拓扑中的孤立与环状节点

**答**：实现 health(edges)：edges 为 [from, to][]（Agent 调用关系）。检测：孤立节点（无入边也无出边，出现在 edges 里的节点才参与——从注册表传入 nodes）、环（调用环，给出环路径）。返回 { isolated: string[], cycle: string[] | null }（cycle 给出一条环路径）。

```js
function health(nodes, edges) {
  const inD = new Map(), outD = new Map();
  nodes.forEach(n => { inD.set(n, 0); outD.set(n, 0); });
  for (const [a, b] of edges) { outD.set(a, outD.get(a) + 1); inD.set(b, inD.get(b) + 1); }
  const isolated = nodes.filter(n => inD.get(n) === 0 && outD.get(n) === 0);
  // 环检测：DFS 三色
  const color = new Map(nodes.map(n => [n, 0]));
  let cycle = null;
  const path = [];
  function dfs(u) {
    if (cycle) return;
    color.set(u, 1); path.push(u);
    for (const [a, b] of edges) if (a === u) {
      if (color.get(b) === 1) { cycle = [...path.slice(path.indexOf(b)), b]; return; }
      if (color.get(b) === 0) dfs(b);
    }
    color.set(u, 2); path.pop();
  }
  nodes.forEach(n => { if (!color.get(n) && !cycle) dfs(n); });
  return { isolated, cycle };
}
console.log(health(['A','B','C','D'],
  [['A','B'],['B','C'],['C','A']]));
// { isolated: ['D'], cycle: ['A','B','C','A'] }
```

**评分点**：
- 孤立节点判定（入度出度全零）；环检测 DFS 三色正确并给出环路径
- 多环时返回第一条即可（报告指出即可再查）
- 能讨论：环在 Agent 拓扑的含义（互相调用易死循环，需显式预算熔断）、孤立节点的处置（下线或接线，零调用 Agent 是浪费）
