## 1266：笔试手写：实现 工具参数默认值填充校验器

**答**：实现 coerceArgs(args, schema)：args 为模型给出的参数对象，schema 为 { key: { type, default?, enum?, required? } }。处理：缺 required → 报错收集；缺可选字段填 default；类型不符做安全转换（'5'→5 的 number 化、'true'→true 的 boolean 化），转换失败进错误收集；enum 值不在集合 → 错误。返回 { args, errors }。

```js
function coerceArgs(args, schema) {
  const out = {}, errors = [];
  for (const [k, s] of Object.entries(schema)) {
    const v = args[k];
    if (v === undefined || v === null) {
      if (s.required) errors.push({ key: k, reason: 'required 缺失' });
      else if ('default' in s) out[k] = s.default;
      continue;
    }
    if (s.enum && !s.enum.includes(v)) { errors.push({ key: k, reason: `enum 外: ${v}` }); continue; }
    if (typeof v === s.type) { out[k] = v; continue; }
    const cast = s.type === 'number' ? Number(v)
      : s.type === 'boolean' ? (v === 'true' ? true : v === 'false' ? false : NaN)
      : String(v);
    if (typeof cast === s.type && cast === cast) out[k] = cast; // NaN 自不等
    else errors.push({ key: k, reason: `类型不可转换: 期望 ${s.type}` });
  }
  return { args: out, errors };
}
```

**评分点**：
- required 缺失报错、可选填默认（两分支不混）
- 类型安全转换白名单（number/boolean），失败不硬转
- NaN 判等用自不等技巧
- 能讨论：coerce 是容错层而非信任层——enum/类型仍应上报给重试
