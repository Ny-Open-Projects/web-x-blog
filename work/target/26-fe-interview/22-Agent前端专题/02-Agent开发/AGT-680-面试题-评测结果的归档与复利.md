## AGT-680：一年后团队最需要从评测体系里拿到什么（归档设计的复利价值）

**答**：
- 归档三件套：版本档案（每个提示词/模型版本：分数、失败样本、线上对照、决策人）、失败库（所有失败的最小复现+归因标签）、变更史（评测集/judge/判据的所有变更与原因）。
- 复利场景：新模型发布时，用历史失败库快速评估新模型是否解决旧痛点（旧失败用例全量重跑）；复盘时任何历史结论可追溯；新人训练用真实失败案例。
- 归档纪律：每季度从失败库出「失败模式演化报告」——哪些模式根治了、哪些在复发、新出现的模式，指导下一季度改进投入。

```javascript
const ARCHIVE = {
  versions: (v) => ({ scores, fails, online, decider }),   // 版本档案
  failLib: { by: '最小复现+归因标签', query: (mode) => all(mode) },
  changes: '评测集/judge/判据变更史',
};
async function newModelAssessment(newModel) {
  const oldFails = ARCHIVE.failLib.all();
  const rerun = await runEval(oldFails.cases, { model: newModel });
  return { solved: rerun.passRate,              // 旧痛点解决率
    regressions: rerun.newFails };              // 新引入问题
}
```
