## AGT-412：手写循环检测：同参重复、语义空转、进度停滞三类模式

**需求与边界**：
- 输入：调用历史 [{tool, args, summary}]；输出：{loop, type, evidence}。
- 边界要求：① 完全同参重复（连续 2 次即报）；② 近义参数轮换（归一化后重复）；③ 空转（结果摘要相似但无进展）；④ 步数间隔检测（窗口滑动防误报一次巧合）。

**答**：
```javascript
function detectLoop(history) {
  const norm = (a) => JSON.stringify(sortKeys(a ?? {}));
  const n = history.length;
  if (n < 3) return { loop: false };
  // 1. 完全同参连续重复
  const last = history[n - 1], prev = history[n - 2];
  if (last.tool === prev.tool && norm(last.args) === norm(prev.args))
    return { loop: true, type: 'exact_repeat', evidence: [prev, last] };
  // 2. 近义轮换：窗口内归一化重复 ≥2 次
  const window = history.slice(-6);
  const seen = new Map();
  for (const h of window) {
    const k = h.tool + norm(h.args);
    if (seen.has(k)) return { loop: true, type: 'rotate_repeat',
      evidence: [seen.get(k), h] };
    seen.set(k, h);
  }
  // 3. 语义空转：连续 3 次结果摘要相似（无新信息）且工具相同
  const last3 = history.slice(-3);
  if (last3.length === 3 &&
      last3.every(h => h.tool === last3[0].tool) &&
      pairwiseSim(last3.map(h => h.summary)) > 0.9)
    return { loop: true, type: 'semantic_idle',
      evidence: last3 };
  return { loop: false };
}
const sortKeys = (o) => Object.keys(o ?? {}).sort()
  .reduce((r, k) => (r[k] = o[k], r), {});
const pairwiseSim = (arr) => {
  let s = 0, c = 0;
  for (let i = 0; i < arr.length; i++)
    for (let j = i + 1; j < arr.length; j++) { s += sim(arr[i], arr[j]); c++; }
  return s / c;
};
// 响应策略：第一次 → 注入"停止重复，换思路"；
// 第二次 → 强制结束并给部分结果（AGT-277）。
```

**评分点**:
- 三类模式齐全：精确重复、参数归一化轮换、语义空转（摘要相似无进展）。
- 参数归一化（键排序）避免对象键序造成的漏检。
- 窗口滑动检测（防单次巧合误报）；分级响应（先提示后熔断）。
- evidence 带具体调用对，可审计可回放。
