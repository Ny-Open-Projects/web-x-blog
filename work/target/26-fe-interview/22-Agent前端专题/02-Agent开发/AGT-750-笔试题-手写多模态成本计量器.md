## AGT-750：手写 MMMeter：三阶段计费、按资产归因、浪费识别（贵而不被用）、月报

**需求与边界**：
- 实现 MMMeter：charge(phase, assetId, usd)/monthly(citations)。
- 边界要求：① phase ∈ parse/index/query，非法抛错；② 月报按阶段汇总+按资产归因；③ 浪费清单：资产成本 >P90 且引用次数为 0；④ 输出优化杠杆建议（查询期命中缓存率低时提示）；⑤ 幂等：同请求 id 重复计费忽略。

**答**：
```javascript
class MMMeter {
  constructor() { this.rows = []; this.seen = new Set(); }
  charge(phase, assetId, usd, reqId) {
    if (!['parse', 'index', 'query'].includes(phase))
      throw new Error('BAD_PHASE');
    if (reqId && this.seen.has(reqId)) return;      // 幂等防重复计费
    if (reqId) this.seen.add(reqId);
    this.rows.push({ phase, assetId, usd, at: Date.now() });
  }
  monthly(citations) {
    const byPhase = {};
    const byAsset = {};
    for (const r of this.rows) {
      byPhase[r.phase] = (byPhase[r.phase] ?? 0) + r.usd;
      byAsset[r.assetId] = (byAsset[r.assetId] ?? 0) + r.usd;
    }
    const costs = Object.values(byAsset);
    const p90 = percentile(costs, 0.9);
    const waste = Object.entries(byAsset)
      .filter(([id, usd]) => usd >= p90 && (citations[id] ?? 0) === 0)
      .map(([id]) => ({ id, usd: byAsset[id] }));
    return { byPhase, waste,
      lever: (byPhase.query / (byPhase.query + byPhase.parse || 1)) > 0.5
        ? '查询期占比过高：优先用预提取数据替代重读原图'
        : null };
  }
}
```

**评分点**:
- 三阶段校验 + 请求级幂等（重试不重复计费）。
- 浪费识别（成本 P90 ∧ 零引用）给出下线候选。
- 优化杠杆按阶段占比自动提示（成本看板可行动）。
