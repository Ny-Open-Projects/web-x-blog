## AGT-835：手写 tenantContext：标签注入、缺失拒绝、全程透传、跨租户访问校验

**需求与边界**：
- 实现 tenantMiddleware(req, res, next) 与 assertTenant(ctx, resource)。
- 边界要求：① 从网关头取 x-tenant-id 与用户 token，缺失直接 400（不默认租户）；② ctx 冻结（防运行时被改租户）；③ assertTenant 校验资源归属（资源 tenant ≠ ctx tenant 即 403）；④ 透传 traceId；⑤ 内部服务间调用带原 ctx（不重造）。

**答**：
```javascript
function tenantMiddleware(req, res, next) {
  const tenantId = req.headers['x-tenant-id'];
  const user = decodeJwt(req.headers.authorization);
  if (!tenantId || !user) return res.status(400).json({
    code: 'ctx.missing', message: '缺少租户或身份' });  // 缺失拒绝
  const ctx = Object.freeze({
    tenantId, userId: user.sub, role: user.role,
    traceId: req.headers['x-trace-id'] ?? genId(),
  });                                             // 冻结防篡改
  res.setHeader('x-trace-id', ctx.traceId);
  req.ctx = ctx;
  next();
}
function assertTenant(ctx, resource) {
  if (resource.tenantId !== ctx.tenantId)
    throw Object.assign(new Error('cross-tenant'), { status: 403,
      code: 'ctx.cross_tenant' });                // 横向越权拦截
  return resource;
}
function passthrough(ctx) {                       // 内部调用透传
  return { headers: { 'x-tenant-id': ctx.tenantId,
    'x-trace-id': ctx.traceId, 'x-user-id': ctx.userId } };
}
```

**评分点**:
- 缺失即 400（绝不默认租户——隔离第一原则）；ctx 冻结防运行时篡改。
- assertTenant 横向越权校验返回 403。
- traceId 生成与透传（响应头回带）；内部调用透传不重造。
