## AGT-406：手写答案引用校验：引用存在性、数字溯源、无引用事实句检测

**需求与边界**：
- 输入：模型输出（含 [n] 引用）、召回块数组；输出：校验结果 {pass, issues[]}。
- 边界要求：① 引用编号越界=失败；② 输出中的数字必须能在被引块或全文找到（数值幻觉检测，含单位）；③ 含【推断】标记的句子跳过数字校验；④ 数字匹配考虑千分位与单位差异。

**答**：
```javascript
function checkCitations(output, docs) {
  const issues = [];
  const cited = [...output.matchAll(/\[(\d+)\]/g)].map(m => +m[1]);
  // 1. 引用存在性
  for (const n of new Set(cited))
    if (n < 1 || n > docs.length) issues.push(`引用[${n}]越界`);
  // 2. 数字溯源（跳过推断句）
  const sentences = output.split(/(?<=[。！？])/);
  for (const s of sentences) {
    if (s.includes('【推断】')) continue;
    const refs = [...s.matchAll(/\[(\d+)\]/g)].map(m => docs[+m[1] - 1]);
    const nums = [...s.matchAll(/\d[\d,\.]*\s*(元|万|%|人|天)?/g)]
      .map(m => norm(m[0]));
    for (const n of nums) {
      const inRef = refs.some(d => d && normSearch(d.text, n));
      const inAny = docs.some(d => normSearch(d.text, n));
      if (!inAny) issues.push(`句子数字"${n}"无处溯源: ${s.slice(0, 30)}`);
      else if (!inRef && refs.length) issues.push(`数字"${n}"存在但引用不匹配`);
    }
  }
  // 3. 事实句无引用检测（排除开头礼貌句）
  const bare = sentences.filter(s => s.length > 15 &&
    !/\[\d+\]|【推断】/.test(s) && /\d|应该|必须|数据/.test(s));
  bare.forEach(s => issues.push(`事实句缺引用: ${s.slice(0, 30)}`));
  return { pass: issues.length === 0, issues };
}
const norm = (n) => n.replace(/,/g, '').replace(/\s+/g, '');
const normSearch = (text, n) => norm(text).includes(n);
```

**评分点**:
- 三层校验齐全：引用越界、数字溯源（区分"无处溯源"与"引用错位"两级）、事实句缺引用。
- 推断句豁免机制（【推断】跳过数字校验）体现引用体系完整性。
- 数字归一化处理（千分位/空格）减少误报。
- 句级切分与过滤规则合理（短句/非事实句不误报）。
