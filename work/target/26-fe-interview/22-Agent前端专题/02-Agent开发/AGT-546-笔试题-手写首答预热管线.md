## AGT-546：手写 prewarm：输入防抖预热、失败可降级、sendFirst 等待预热完成

**需求与边界**：
- 实现 prewarm() 与 sendFirst(msg)：输入开始 300ms 后预热（配额预检/连接预建/会话预建）。
- 边界要求：① 预热只触发一次，失败不阻塞发送（degrade 直接发送）；② 预建会话若未被使用要在 5 分钟后取消（防垃圾会话）；③ sendFirst 必须等预热完成再发（复用连接）；④ 预热耗时埋点。

**答**：
```javascript
let prewarmPromise = null, prewarmAt = 0, reservedSession = null;
function prewarm() {
  if (prewarmPromise) return prewarmPromise;
  const t0 = performance.now();
  prewarmPromise = Promise.allSettled([
    api.preflightQuota(),
    sse.connect(),
    api.precreateSession().then(s => { reservedSession = s; return s; }),
  ]).then(rs => {
    track('prewarm', { ms: Math.round(performance.now() - t0),
      ok: rs.filter(r => r.status === 'fulfilled').length });
  });
  setTimeout(() => {                          // 预建会话闲置回收
    if (reservedSession && !reservedSession.used)
      api.cancelSession(reservedSession.id);
  }, 5 * 60e3);
  return prewarmPromise;
}
input.addEventListener('input', debounce(() => prewarm(), 300));
async function sendFirst(msg) {
  await prewarmPromise?.catch(() => {});      // 预热失败不阻塞，降级直发
  return sse.send(msg, { sessionId: reservedSession?.id });
}
```

**评分点**:
- allSettled 聚合预热（单项失败不拖垮），sendFirst catch 后直发降级。
- 预建会话闲置回收（防垃圾会话膨胀）。
- 预热防抖 + 单次触发 + 耗时埋点。
