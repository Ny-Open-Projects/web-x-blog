## 999：多团队共享模型配额，预算体系怎么建

**答**：
- 配额三层：团队月度预算（硬上限，超了要走审批）、服务级预留（核心服务保底配额防被抢占）、弹性池（未用完的预算月末回流共享池）。
- 计量粒度到「服务 × 模型 × 任务类型」，否则预算超支无法归责；计费单价透明公示（含折扣），团队自己能算账。
- 超支流程自动化：80% 预警、95% 限流降档（自动切小模型）、100% 熔断待审批——降档比熔断体验好得多，是默认动作。
- 追问钩子：预算怎么定才不拍脑袋？——按「业务量 × 单位成本基线 × 增长系数」公式化核定，季度回顾校准，谁多花谁举证质量收益。

```ts
const quotas = {
  'team-search': { monthly: 2000, reserved: 200 },       // $，月度+保底
  'team-agent': { monthly: 5000, reserved: 500 },
};
async function spend(team, cost, meta) {
  const q = quotas[team], used = await meter.get(team, 'month');
  if (used / q.monthly > 0.95) return downgrade(meta);   // 自动降档
  if (used + cost > q.monthly) return approvalRequired(team, cost); // 熔断待审批
  return meter.add(team, cost, meta);
}
```
