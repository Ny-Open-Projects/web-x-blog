## 915：笔试手写：校验答案引用编号合法性并输出对齐报告

**答**：输入 answer（含 [n] 引用）、sources（来源数组，下标即编号-1）、阈值 simCut。返回 { ok, report, badCites }：ok 表示所有引用编号合法；report 列出每个引用的 { cite, valid, matchedSource }，编号越界或 sources 为空记 invalid。另实现 stripCitations(answer) 去引用后的纯文本，要求正确处理 [12] 多位数字。

```js
/**
 * @param {string} answer
 * @param {{title: string}[]} sources
 */
function checkCitations(answer, sources) {
  const report = [], bad = [];
  const re = /\[(\d+)\]/g; let m;
  while ((m = re.exec(answer)) !== null) {
    const n = Number(m[1]);
    const src = sources[n - 1] ?? null;          // 1-based -> 0-based，越界为 null
    if (!src) bad.push(n);
    report.push({ cite: n, valid: !!src, matchedSource: src ? src.title : null });
  }
  return { ok: bad.length === 0, report, badCites: [...new Set(bad)] };
}
function stripCitations(answer) {
  return answer.replace(/\[\d+\]/g, '').trim(); // 供下游相似度对齐
}
const r = checkCitations('支持灰度[1]，回滚要快[2][3]。', [{ title: '灰度指南' }, { title: '回滚手册' }]);
console.log(r.ok, r.badCites); // false [3]
```

**评分点**：
- 1-based 编号到 0-based 数组的映射与越界判断（常见 off-by-one）
- 正则覆盖多位数字；能说出模式不会误伤 [TS] 这类文本
- 报告结构完整可序列化，badCites 去重
- 边界：答案无引用（返回空 report + ok=true 并说明是否算合规）、sources 为空
