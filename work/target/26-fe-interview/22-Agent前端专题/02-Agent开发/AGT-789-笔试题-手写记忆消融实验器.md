## AGT-789：手写 ablation：逐字段关闭对比、净贡献计算、样本配对、置信判定

**需求与边界**：
- 实现 ablation(fields, evalSet, runFn)。
- 边界要求：① 基线（全开）+ 每字段关闭一轮；② 指标 oneShotRate（一次到位率），净贡献 = 基线 - 关闭后（正=该字段有用）；③ 配对跑（同用例同参数），差异显著性用配对二项检验；④ 输出按贡献排序，负贡献字段标记 remove 建议。

**答**：
```javascript
async function ablation(fields, evalSet, runFn) {
  const base = await runFn({ fields });            // 全开基线
  const rows = [];
  for (const f of fields) {
    const r = await runFn({ fields: fields.filter(x => x !== f) });
    const delta = base.ok - r.ok;                  // 净贡献
    const diff = evalSet.filter((c, i) =>
      base.perCase[i] !== r.perCase[i]);
    const wins = diff.filter((c, i) => r.perCase[i] === false).length;
    rows.push({ field: f, delta,
      p: binomTail(Math.min(wins, diff.length - wins), diff.length),
      significant: diff.length > 20
        && binomTail(Math.min(wins, diff.length - wins), diff.length) < 0.05 });
  }
  rows.sort((a, b) => b.delta - a.delta);
  return { baseline: base.ok,
    rows,
    actions: rows.filter(r => r.delta < 0).map(r =>
      ({ remove: r.field, note: '负贡献，建议移除注入' })) };
}
```

**评分点**:
- 消融逻辑正确（关一个比一次，正贡献=开着更好）。
- 配对 + 不一致子集二项检验（样本不足标不显著）。
- 负贡献字段给移除建议（实验可行动）。
