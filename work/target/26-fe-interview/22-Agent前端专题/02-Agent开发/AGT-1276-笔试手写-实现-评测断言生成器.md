## 1276：笔试手写：实现 评测断言生成器

**答**：实现 genAssertions(schema)：schema 为 { field, type, required, enum? }[]。为每字段生成断言函数列表：required → 存在且非空；type string → typeof 校验 + 非空串；number → 有限数；enum → 值在集合。返回 { case: (data) => ({ pass, failures }) }，一次调用跑全部断言并汇总失败字段。

```js
function genAssertions(schema) {
  const checks = [];
  for (const f of schema) {
    if (f.required) checks.push(d =>
      (d[f.field] === undefined || d[f.field] === null || d[f.field] === '')
        ? `${f.field}: required 缺失` : null);
    if (f.type === 'string') checks.push(d =>
      d[f.field] !== undefined && typeof d[f.field] !== 'string' ? `${f.field}: 需 string` : null);
    if (f.type === 'number') checks.push(d =>
      d[f.field] !== undefined && (typeof d[f.field] !== 'number' || !Number.isFinite(d[f.field]))
        ? `${f.field}: 需有限 number` : null);
    if (f.enum) checks.push(d =>
      d[f.field] !== undefined && !f.enum.includes(d[f.field]) ? `${f.field}: enum 外` : null);
  }
  return {
    run: data => {
      const failures = checks.map(c => c(data)).filter(Boolean);
      return { pass: failures.length === 0, failures };
    },
  };
}
```

**评分点**：
- 断言生成而非手写（schema → 断言的自动化）
- 每条断言返回 null 或失败信息（汇总风格）
- required/type/enum 三类独立判断
- 能讨论：生成断言可加入自定义谓词扩展点
