## 1070：笔试手写：计算评测分与线上指标的 Pearson 相关系数

**答**：实现 pearson(xs, ys)：等长数值数组，返回相关系数 r（-1~1），长度 < 3 返回 null；再实现 correlate(evalHist, onlineHist)：按日期对齐两组 { day, value }，缺失日期跳过（只保留双方都有的），不足 10 对返回 null。

```js
function pearson(xs, ys) {
  if (xs.length < 3 || xs.length !== ys.length) return null;
  const n = xs.length;
  const mx = xs.reduce((a, b) => a + b) / n, my = ys.reduce((a, b) => a + b) / n;
  let cov = 0, vx = 0, vy = 0;
  for (let i = 0; i < n; i++) {
    const dx = xs[i] - mx, dy = ys[i] - my;
    cov += dx * dy; vx += dx * dx; vy += dy * dy;
  }
  return vx && vy ? cov / Math.sqrt(vx * vy) : null;  // 零方差保护
}
function correlate(evalHist, onlineHist) {
  const e = new Map(evalHist.map(d => [d.day, d.value]));
  const pairs = onlineHist.filter(d => e.has(d.day)).map(d => [e.get(d.day), d.value]);
  if (pairs.length < 10) return null;                 // 样本不足不可信
  return pearson(pairs.map(p => p[0]), pairs.map(p => p[1]));
}
console.log(pearson([1,2,3,4,5],[2,4,6,8,10]).toFixed(2)); // '1.00'
```

**评分点**：
- Pearson 公式正确（协方差除以两方差积的平方根）
- 零方差返回 null（除零保护）、长度下限
- 按日期对齐 + 双侧缺失跳过（常见 bug 是直接按下标对齐）
- 能讨论：r 的解读边界（相关不等于因果、滞后相关：评测涨了线上周后才涨，可试 lag）
