## AGT-889：手写 autoAttribute：sourcemap还原、发布diff、置信分级（PR草稿/线索）、命中率统计

**需求与边界**：
- 实现 autoAttribute(issue, ctx)。
- 边界要求：① 输入上下文：还原堆栈+版本分布+最近发布diff；② 置信 ≥0.8 输出 fixDraft（PR 草稿结构），0.5~0.8 输出 clue（排查线索），<0.5 输出 need-human；③ 输出必须带 evidence 引用（堆栈行/diff hunk）；④ 归因结果入库供命中率统计；⑤ 复现信息缺失时降级（confidence 上限 0.5）。

**答**：
```javascript
async function autoAttribute(issue, ctx, { store = true } = {}) {
  let cap = 1;
  if (!issue.reproSteps) cap = 0.5;                // 无复现降级
  const attr = await llm.attribute({
    stack: await sourcemap.resolve(issue.stack),
    versions: issue.versions,
    release: ctx.diffSince(issue.firstSeen),
  }, { require: 'hypothesis+confidence+evidence' });
  attr.confidence = Math.min(attr.confidence, cap);
  const out = attr.confidence >= 0.8
    ? { level: 'fix-draft', pr: draftPR(attr), ...attr }
    : attr.confidence >= 0.5
      ? { level: 'clue', reasoning: attr.reasoning,
          suspects: attr.evidence.suspects, ...attr }
      : { level: 'need-human', ...attr };
  if (store) attributionDb.add({ issue: issue.id, out,
    at: Date.now() });                             // 命中率统计
  return out;
}
function hitRate(window) {
  const rows = attributionDb.in(window);
  return rows.filter(r => r.confirmed).length / rows.length;
}
```

**评分点**:
- 三级输出（PR 草稿/线索/人工）按置信分级；证据引用必带（可核对不瞎猜）。
- 复现缺失封顶置信（不装确定）。
- 归因入库 + 命中率统计（闭环数据）。
