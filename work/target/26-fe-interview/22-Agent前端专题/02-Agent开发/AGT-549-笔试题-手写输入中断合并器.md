## AGT-549：手写 steer 合并器：生成中纠错消息 200ms 合并、转向中断、半成品保留

**需求与边界**：
- 实现 SteerBuffer：生成中用户的多条纠正消息在 200ms 窗口合并，然后一次转向（中断当前流+带上下文重发）。
- 边界要求：① 生成空闲时消息直接发送不缓冲；② 合并后附带被中断回合引用；③ 中断后已生成内容保留可展开；④ 连续转向不叠加引用（引用最新被中断回合即可）。

**答**：
```javascript
class SteerBuffer {
  constructor(steerMs = 200) { this.buf = []; this.timer = null;
    this.lastInterrupted = null; }
  push(msg, state) {
    if (state === 'idle') return this.flushNow(msg);   // 空闲直发
    this.buf.push(msg);
    clearTimeout(this.timer);
    this.timer = setTimeout(() => this.flush(), this.steerMs);
  }
  async flush() {
    if (!this.buf.length) return;
    const msgs = this.buf.splice(0);
    const turn = currentTurn();
    if (turn && !turn.done) {
      await turn.cancel();
      turn.markInterrupted();                    // 半成品保留可展开
      this.lastInterrupted = turn.id;
    }
    await send({
      parts: msgs.map(m => m.parts).flat(),
      refs: this.lastInterrupted
        ? [{ turnId: this.lastInterrupted, note: '已被用户中断的上一轮' }]
        : [],                                    // 只引用最新中断回合
      instruction: '用户纠正了方向，结合上下文重新回答，避免重复已生成内容',
    });
  }
  flushNow(msg) { clearTimeout(this.timer);
    return send({ parts: msg.parts }); }
}
```

**评分点**:
- 空闲直发/生成中缓冲的分支正确；200ms 合并防"别别别"三连发。
- 中断保留半成品 + 只引用最新被中断回合（引用不叠加）。
- flush 后 buf 清空，二次 flush 无副作用。
