## 1075：笔试手写：实现意图分布偏离度检测（简版卡方）

**答**：实现 drift(expected, actual)：两组意图分布（Map intent->count）。将 actual 归一化到 expected 总量后计算卡方统计量 Σ(O-E)²/E（期望 E 为 expected 归一化后按 actual 总量缩放的值；actual 中新出现的意图按 E 取 5 计算）；自由度 = 意图种类数 - 1，对照 0.05 显著性阈值表返回 { chi2, drift }。

```js
function drift(expected, actual) {
  const totE = [...expected.values()].reduce((a, b) => a + b, 0);
  const totA = [...actual.values()].reduce((a, b) => a + b, 0) || 1;
  const keys = new Set([...expected.keys(), ...actual.keys()]);
  let chi2 = 0;
  for (const k of keys) {
    const E = (expected.get(k) ?? 5 / totE * totE) / totE * totA || 5; // 新意图 E=5
    const O = actual.get(k) ?? 0;
    chi2 += (O - E) ** 2 / E;
  }
  const df = Math.max(keys.size - 1, 1);
  // 0.05 显著性阈值表（df: chi2）
  const TABLE = { 1: 3.84, 2: 5.99, 3: 7.81, 4: 9.49, 5: 11.07, 6: 12.59, 7: 14.07, 8: 15.51 };
  const cut = TABLE[Math.min(df, 8)] ?? TABLE[8];
  return { chi2: +chi2.toFixed(3), drift: chi2 > cut, df };
}
console.log(drift(new Map([['qa', 60], ['code', 40]]),
                  new Map([['qa', 30], ['code', 70]])).drift); // true
```

**评分点**：
- 归一化方向正确：expected 缩放到 actual 总量（很多候选人方向反了）
- 新意图（expected 缺失）的处理：期望值取小常数 5
- df 计算与阈值表查询正确
- 能讨论：卡方要求期望频数 ≥5（小样本用 Fisher 精确检验）、这项检测的用途（评估集与线上分布偏离审计）
