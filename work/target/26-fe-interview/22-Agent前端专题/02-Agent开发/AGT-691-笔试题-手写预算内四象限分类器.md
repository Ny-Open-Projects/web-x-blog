## AGT-691：手写 quadrant：预算内/超预算 × 正确/错误四分类、曲线数据、浪费归因标签

**需求与边界**：
- 实现 quadrant(run, budget) 与 wasteReason(runs)。
- 边界要求：① 正确性以判据结果为准，预算含 tokens/轮次/时长，任一超限即超预算；② 四象限输出计数与占比；③ 预算-质量曲线按三档预算输出；④ 浪费归因：超预算正确案例标注原因（循环/过度检索/重试风暴，按轮次模式识别）。

**答**：
```javascript
function overBudget(run, budget) {
  return run.usage.total > budget
    || run.turns > budget.turns
    || run.elapsedMs > budget.ms;                  // 任一超限
}
function quadrant(run, budget) {
  const ob = overBudget(run, budget);
  const q = ob
    ? (run.correct ? 'over-ok' : 'over-bad')       // 超预算
    : (run.correct ? 'in-ok' : 'in-bad');          // 预算内
  return { case: run.caseId, q,
    waste: q === 'over-ok' ? wasteReason(run) : null };
}
function wasteReason(run) {
  const kinds = sameToolStreak(run.toolCalls);     // 循环识别
  if (kinds >= 3) return 'loop';
  if (run.retrievals > run.expectedRetrievals * 3) return 'over-retrieval';
  if (run.retries > 2) return 'retry-storm';
  return 'other';
}
function budgetCurve(allRuns, budgets) {
  return budgets.map(b => ({
    budget: b, okRate: allRuns.filter(r => quadrant(r, b).q === 'in-ok'
      || quadrant(r, b).q === 'over-ok').length / allRuns.length }));
}
```

**评分点**:
- 四象限判定完整（任一预算维度超限即超预算，正确性独立判定）。
- 浪费归因三模式识别（循环/过度检索/重试风暴）+ other 兜底。
- budgetCurve 输出预算-质量曲线（性价比视角）。
