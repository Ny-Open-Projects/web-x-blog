## 1225：笔试手写：实现降级链的灰度回升（恢复验证）

**答**：改为笔试题。**需求**：实现 RecoveryController(levels)：levels 为成本递减数组 [{ level, cost }]；demoteTo(idx) 降级；tryRecover()——恢复条件（注入的 probe() 返回 ok）满足时先回升一级并以 10% 流量试探（canaryMode），probe 连续 2 次 ok 才全量回升；probe 失败退回原级。返回当前 { level, canary }。

```js
class RecoveryController {
  constructor(levels, probe, { canaryRate = 0.1 } = {}) {
    this.levels = levels; this.probe = probe;
    this.idx = 0; this.canary = false; this.okStreak = 0;
  }
  demoteTo(idx) { this.idx = idx; this.canary = false; this.okStreak = 0; }
  current() { return { level: this.levels[this.idx].level, canary: this.canary }; }
  async tryRecover() {
    if (this.idx === 0) return this.current();          // 已在最高级
    const r = await this.probe();
    if (!r.ok) { this.okStreak = 0; this.canary = false; return this.current(); }
    if (!this.canary) { this.canary = true; return this.current(); }  // 10% 试探
    this.okStreak++;
    if (this.okStreak >= 2) {                            // 连续 2 次 ok 全量回升
      this.idx--; this.canary = false; this.okStreak = 0;
    }
    return this.current();
  }
}
```

**评分点**：
- 两段式回升（canary 10% 试探 -> 连续 2 次 ok 全量——防「降下去升不回来」与「回升即翻车」）
- probe 失败重置 okStreak 与 canary（退回原级语义）
- 已在最高级的短路
- 能讨论：canary 流量的指标观察（质量护栏）、probe 的设计（真实抽检而非健康检查 ping）
