## AGT-696：手写 renderScore：区间条、重叠判定、样本量提示、决策建议

**需求与边界**：
- 实现 renderScore(a, b)：输出结构化对比对象。
- 边界要求：① 两版本分数带 Wilson 区间；② 区间不重叠→显著结论，重叠→无法区分；③ 任一区间宽度 >0.08 给"样本不足"提示；④ 结论附样本量与建议动作（pass/fail/collect-more）。

**答**：
```javascript
function wilson(k, n, z = 1.96) {
  if (!n) return [0, 1];
  const p = k / n, d = 1 + z * z / n;
  const c = p + z * z / (2 * n);
  const r = z * Math.sqrt(p * (1 - p) / n + z * z / (4 * n * n));
  return [(c - r) / d, (c + r) / d];
}
function renderScore(a, b) {
  const ciA = wilson(a.pass, a.n), ciB = wilson(b.pass, b.n);
  const noOverlap = ciA[1] < ciB[0] || ciB[1] < ciA[0];
  const width = Math.max(ciA[1] - ciA[0], ciB[1] - ciB[0]);
  const verdict = !noOverlap ? 'uncertain'
    : (ciA[0] > ciB[1] ? 'a-wins' : 'b-wins');
  return {
    a: { rate: a.pass / a.n, ci: ciA },
    b: { rate: b.pass / b.n, ci: ciB },
    verdict, noOverlap,
    sampleHint: width > 0.08 ? '区间过宽，样本不足' : null,
    action: verdict === 'uncertain'
      ? `collect-more：建议各补 ${Math.ceil(400 / (1 - 0))} 用例`
      : verdict === 'a-wins' ? 'pass' : 'fail',
    n: { a: a.n, b: b.n },
  };
}
```

**评分点**:
- Wilson 区间与重叠判定正确（显著/不确定二分清晰）。
- 区间宽度触发样本量提示（不确定性可视化核心）。
- 结论直接映射动作（pass/fail/collect-more），决策规则前置。
