## AGT-623：Agent 系统的告警怎么分组路由（谁半夜被告警叫醒）

**答**：
- 按故障域分组：链路域（SSE/WS/网关）→平台组；模型域（供应商故障/成本暴涨）→AI 平台组；质量域（劣化/负反馈激增）→评测/产品组（工作时间告警，不半夜叫人）；工具依赖域→对应业务组。
- 告警分级：P0（服务不可用/成本爆跑）电话+IM；P1（质量劣化/依赖降级）IM 即时；P2（趋势异常）日报。每条告警带 runbook 链接与自动下钻数据，缩短 MTTR。
- 告警自愈优先：能自动处置的（切备用模型/清理缓存）先自愈，自愈失败才升级人工，告警里标注"已自动处置 X 次"。

```javascript
const ROUTES = [
  { domain: 'link',        team: 'platform',  level: { down: 'P0' } },
  { domain: 'model',       team: 'ai-platform', level: { costSpike: 'P0', degrade: 'P1' } },
  { domain: 'quality',     team: 'eval',      level: { any: 'P2', workhours: true } },
  { domain: 'tool:crm',    team: 'crm-oncall' },
];
function route(alert) {
  const r = ROUTES.find(r => alert.domain.startsWith(r.domain));
  if (r?.level?.workhours && !inWorkhours()) return dailyReport(alert);
  if (autoHeal(alert)) return notify({ ...alert, autohealed: true });
  return page(r.team, { ...alert, runbook: RUNBOOKS[alert.type] });
}
```
