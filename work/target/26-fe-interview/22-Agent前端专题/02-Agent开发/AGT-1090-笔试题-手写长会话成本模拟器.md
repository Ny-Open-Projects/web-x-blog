## 1090：笔试手写：模拟长会话成本（无压缩 vs 滚动压缩）

**答**：实现 sessionCost(turns, { compactAt=1500, keep=4, summaryRatio=0.3 })：每轮输入 = 当前上下文 + 新消息，token 按字符数/4 估算，单轮成本 = est(上下文+新消息)；上下文超过 compactAt 触发滚动压缩（保留最近 keep 条原文 + 其余部分截取 30% 作为摘要前缀）；返回 { totalTokens, compacts }。

```js
function est(s) { return Math.ceil(s.length / 4); }
function sessionCost(turns, { compactAt = 1500, keep = 4, summaryRatio = 0.3 } = {}) {
  let ctx = '', total = 0, compacts = 0;
  for (const t of turns) {
    total += est(ctx) + est(t);              // 每轮重发全历史
    ctx += t + '\n';
    if (est(ctx) > compactAt) {              // 触发滚动压缩
      const lines = ctx.split('\n').filter(Boolean);
      const old = lines.slice(0, -keep), recent = lines.slice(-keep);
      const sumLen = Math.ceil(old.join(' ').length * summaryRatio);
      ctx = '[摘要]' + old.join(' ').slice(0, sumLen) + '\n'
          + recent.join('\n') + '\n';
      compacts++;
    }
  }
  return { totalTokens: total, compacts };
}
const turns = Array.from({ length: 20 }, (_, i) => '第' + i + '轮的消息内容...');
console.log(sessionCost(turns, { compactAt: Infinity }));      // 无压缩基线
console.log(sessionCost(turns));                                // 压缩版对比
```

**评分点**：
- 成本模型正确：每轮成本 = 上下文 + 新消息（体现超线性增长的本质）
- 压缩策略实现完整：摘要占比 + 保留近 keep 条
- 返回 compacts 供两组对比
- 能讨论：模拟器的用途（压缩策略上线前的收益预估）、真实系统还应叠加前缀缓存与外部记忆优化
