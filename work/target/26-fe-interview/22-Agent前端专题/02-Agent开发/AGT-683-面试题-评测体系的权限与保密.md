## AGT-683：评测集是核心资产（含业务金标），权限与保密怎么做

**答**：
- 分级可见：用例输入全员可见（调试需要）、金标与判据限评测组、失败样本（含真实用户数据）脱敏后可见；对外合作只给「公开子集」。
- 防泄漏审计：评测集访问日志 + 异常访问告警（批量拉取金标）；提示词/工具引用评测内容时依赖图扫描（前面讲过）。
- 保密与效率平衡：金标加密静态存储，执行器运行时解密（评测服务持有密钥），终端开发看不到明文金标也能跑评测。

```javascript
function accessControl(actor, action, target) {
  const matrix = {
    dev:     { input: 'r', golden: 'none', fails: 'masked' },
    eval:    { input: 'r', golden: 'r', fails: 'r' },
    partner: { input: 'r(public)', golden: 'none', fails: 'none' },
  };
  const perm = matrix[actor.role]?.[target.kind];
  if (perm !== 'r') throw new Error('FORBIDDEN');
  audit.log({ actor: actor.id, action, target: target.id });
  return target.kind === 'golden'
    ? decrypt(target, EVAL_SERVICE_KEY)           // 运行时解密
    : target;
}
```
