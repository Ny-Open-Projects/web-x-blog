## AGT-737：手写 extractChart：数据序列提取、轴标签解析、数值容差校验、低置信标注

**需求与边界**：
- 实现 extractChart(img)：输出结构化数据序列。
- 边界要求：① 输出 { axis: {x[], y}, series: [{name, points}] }；② 数值点带置信度，均值 <0.8 整体标 low-confidence；③ 与 OCR 数字交叉校验（图内标注数字与提取值容差 5%）；④ 失败返回 null 而非猜测数据。

**答**：
```javascript
async function extractChart(img, { vision, ocr }) {
  const raw = await vision(img, EXTRACT_CHART_PROMPT); // 要求JSON输出
  const spec = safeJson(raw);
  if (!spec?.series?.length) return null;            // 失败不猜
  const annotations = await ocr(img);                // 图内标注数字
  const points = spec.series.flatMap(s => s.points);
  const conf = avg(points.map(p => p.conf ?? 1));
  const mismatch = points.filter(p => {
    const ann = annotations.numbers.find(a =>
      Math.abs(a.value - p.y) / Math.max(p.y, 1) <= 0.05);
    return p.labeled && !ann;                        // 有标注但OCR未见
  });
  return { ...spec,
    confidence: conf,
    lowConfidence: conf < 0.8 || mismatch.length > 0,
    note: conf < 0.8
      ? '图表数值为图像识别结果，可能存在误差' : null,
  };
}
```

**评分点**:
- 结构化输出固定 schema，解析失败返回 null（不猜数据）。
- 双校验：置信均值阈值 + OCR 标注交叉（5% 容差）。
- 低置信带用户可见 note（引用时提示误差）。
