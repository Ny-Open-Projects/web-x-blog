## AGT-735：手写 tableToChunks：小表整体/大表概览+行级展开、表头绑定、引用定位

**需求与边界**：
- 实现 tableToChunks(table, { smallRows = 10 })。
- 边界要求：① 行数 ≤ smallRows 时整表 Markdown 单块；② 大表输出概览块（表名/列含义/行数）+ 每行"列头：值"展开块；③ 行块文本必须包含表名与行号（检索命中可回定位）；④ 空表/无表头抛错；⑤ 单元格值含换行要压平。

**答**：
```javascript
function tableToChunks(table, { smallRows = 10 } = {}) {
  if (!table.rows?.length || !table.headers?.length)
    throw new Error('TABLE_INVALID');
  const flat = (v) => String(v ?? '').replace(/\s+/g, ' ').trim();
  if (table.rows.length <= smallRows) {
    return [{ kind: 'table-md', text: toMarkdown(table),
      ref: { tableId: table.id } }];
  }
  const summary = {
    kind: 'table-summary',
    text: `表【${table.title}】：${table.headers.join('、')}，`
      + `共 ${table.rows.length} 行。查询具体数值请结合行级内容。`,
    ref: { tableId: table.id },
  };
  const rows = table.rows.map((row, i) => ({
    kind: 'table-row',
    text: row.map((cell, j) =>
      `${flat(table.headers[j])}：${flat(cell)}`).join('；')
      + `（来源：${table.title} 第${i + 1}行）`,       // 可回定位
    ref: { tableId: table.id, row: i + 1 },
  }));
  return [summary, ...rows];
}
```

**评分点**:
- 分支正确（小表整体/大表概览+行级）；概览块有引导语（告诉检索器怎么用）。
- 行块绑定列头语义 + 表名行号（可回定位引用）。
- 空表/无表头显式抛错；换行压平防切块断裂。
