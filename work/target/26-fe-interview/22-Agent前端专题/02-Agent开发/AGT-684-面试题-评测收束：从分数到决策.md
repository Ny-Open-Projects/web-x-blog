## AGT-684：评测体系最终价值是支撑决策，如何设计「分数→决策」的映射规则

**答**：
- 决策矩阵前置：每个决策场景（发版/回滚/选型/续投）预先定义分数条件（主指标区间+安全一票否决+成本上限），工具自动给出建议决策+依据链，人只做最终确认。
- 决策可审计：每个「依据评测做成的决策」记录决策时的分数快照与规则版本——事后质疑（为什么当时上线了）可复现当时的判断依据。
- 规则演化：决策规则本身也要评审与版本化（谁有权限改门槛、改动需双人评审），防止"为通过而调规则"。

```javascript
const DECISION_RULES = {
  release: { main: '>= baseline-0.01', security: 'pass',
    cost: '<= baseline*1.05' },
  rollback: { main: '< baseline-0.03', or: ['security fail', 'dislike+50%'] },
};
function decide(run, rule) {
  const ok = evalExpr(rule.main, run) && run.security === 'pass'
    && evalExpr(rule.cost, run);
  const snap = { decision: ok ? 'release' : 'block',
    scores: run, ruleVer: RULE_VER };             // 快照存档可审计
  audit.decision(snap);
  return snap;
}
```
