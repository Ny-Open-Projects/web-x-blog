## AGT-443：手写防刷分机制：双集评测、背离报警、定期轮换、泛化理由归档

**需求与边界**：
- 输入：公开集与隐匿集、版本评测结果历史；输出：决策（可信/疑似刷分）。
- 边界要求：① 公开集分数上涨但隐匿集不涨→报警；② 隐匿集季度轮换 20%（替换进历史库）；③ 每次变更要求泛化理由归档（为什么不止解决这几个样本）；④ 分数历史可视化对比。

**答**：
```javascript
class AntiOverfit {
  constructor({ publicSet, holdout, rotation = 0.2 }) {
    this.publicSet = publicSet; this.holdout = holdout;
    this.rotation = rotation; this.history = [];
  }
  async evaluate(cfg, runner) {
    const pub = await runner(cfg, this.publicSet);
    const hid = await runner(cfg, this.holdout);   // 双集必跑
    const entry = { ts: Date.now(), cfg: cfg.id,
      public: pub.score, holdout: hid.score };
    this.history.push(entry);
    return { ...entry,
      verdict: this.verdict(entry, cfg) };
  }
  verdict(entry, cfg) {
    const prev = this.history.at(-2);
    const pubGain = entry.public - (prev?.public ?? 0);
    const hidGain = entry.holdout - (prev?.holdout ?? 0);
    // 背离检测：公开涨 ≥3% 但隐匿不涨或跌 → 疑似刷分
    if (pubGain >= 0.03 && hidGain <= 0)
      return { ok: false, reason: '背离：公开+隐匿不动',
        action: '要求泛化理由并人工复核', cfg: cfg.id };
    return { ok: true, pubGain, hidGain };
  }
  rotate() {                                       // 季度轮换 20%
    const n = Math.floor(this.holdout.length * this.rotation);
    const replaced = sample(this.holdout, n);
    this.holdout = this.holdout.filter(x => !replaced.includes(x))
      .concat(sampleFrom(REAL_BADCASE_POOL, n));   // 真实 badcase 补充
    archive(replaced);                             // 旧题进历史库
    return replaced.length;
  }
  requireRationale(cfg, change) {                  // 泛化理由归档
    return archive({ cfg: cfg.id, change,
      rationale: change.whyGeneralizes });         // 无理由不放行
  }
}
```

**评分点**:
- 双集必跑且背离检测逻辑正确（公开涨≥3% 隐匿不涨即报警）。
- 隐匿集定期轮换并从真实 badcase 补充（保持分布新鲜）。
- 泛化理由归档作为放行前置条件。
- 历史归档支持长期对比与审计。
