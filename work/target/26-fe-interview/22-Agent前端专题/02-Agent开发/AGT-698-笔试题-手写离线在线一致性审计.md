## AGT-698：手写 auditAlignment：高分负反馈配对归因、三类原因计数、修复动作路由

**需求与边界**：
- 实现 auditAlignment(records)：records 每条含 { offlineScore, onlineBad, features }。
- 边界要求：① 配对 = 离线高分(>0.9)且线上负反馈的样本；② 归因三类（coverage_gap 评测集缺分布/rubric_mismatch 判据错/context_shift 上下文漂移），自动初分+人工确认接口；③ 计数超阈值触发对应修复（补用例/修判据）；④ 一致性总分输出（1-脱节率）。

**答**：
```javascript
function classifyPair(r) {
  if (r.features.novelScenario) return 'coverage_gap';   // 评测集没这类
  if (r.judgeAgreement < 0.6) return 'rubric_mismatch';  // judge都不一致
  if (r.features.ctxDiffFromEval > 0.7) return 'context_shift';
  return 'unclassified';
}
function auditAlignment(records, { thresholds = { gap: 5, rubric: 5 } } = {}) {
  const pairs = records.filter(r => r.offlineScore > 0.9 && r.onlineBad);
  const causes = countBy(pairs.map(classifyPair));
  return {
    disconnectRate: records.length
      ? pairs.length / records.length : 0,
    causes,
    actions: [
      causes.coverage_gap > thresholds.gap
        && { act: 'add-cases', from: pairs.filter(p =>
          classifyPair(p) === 'coverage_gap').slice(0, 30) },
      causes.rubric_mismatch > thresholds.rubric
        && { act: 'revise-rubric' },
    ].filter(Boolean),
    humanReview: pairs.filter(p => classifyPair(p) === 'unclassified'),
  };
}
```

**评分点**:
- 配对定义明确（离线高分∧线上负反馈）；三类归因判据可计算。
- 阈值触发对应修复动作（补用例/修判据），审计有产出不空转。
- 未分类样本进入人工复核通道（自动归因不越界）。
