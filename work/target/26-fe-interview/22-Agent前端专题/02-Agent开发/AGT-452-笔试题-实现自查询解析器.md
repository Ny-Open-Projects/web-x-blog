## AGT-452：手写 self-query：自然语言拆解为语义 query+过滤条件，权限强制注入与放松重试

**需求与边界**：
- 输入：自然语言查询、用户 ACL、解析函数；输出：结构化检索请求。
- 边界要求：① 解析结果 schema 校验（非法字段丢弃）；② 权限字段系统覆盖（LLM 只能收窄不能扩权）；③ 相对时间解析（"最近三个月"→绝对区间）；④ 空结果按优先级放松条件重试（最多 2 次），最终不放松权限。

**答**：
```javascript
const FILTER_FIELDS = ['year', 'type', 'dept', 'project'];
async function selfQuery(nl, user, { parse, search, now }) {
  const raw = await parse(nl);              // {query, filter}
  const filter = {};
  for (const [k, v] of Object.entries(raw.filter ?? {})) {
    if (!FILTER_FIELDS.includes(k)) continue;           // 未知字段丢弃
    if (k === 'year' && /^最近/.test(String(v))) {
      const months = parseInt(v.match(/\d+/)?.[0] ?? 3);
      filter.yearGte = new Date(now() - months * 30 * 864e5)
        .getFullYear();                                 // 相对时间解析
    } else filter[k] = v;
  }
  // 权限覆盖：系统注入（覆盖 LLM 的 dept 声明）
  filter.acl = { $in: user.acl };
  let attempts = 0; const priority = ['project', 'type', 'yearGte'];
  while (attempts <= 2) {
    const docs = await search(raw.query, { filter, k: 20 });
    if (docs.length) return { docs, filter, attempts };
    // 放松：按优先级去掉低价值条件（权限永不放松）
    const drop = priority.find(p => p in filter);
    if (!drop) break;
    delete filter[drop]; attempts++;
  }
  return { docs: [], filter, attempts,
    note: '条件已放松至权限边界，仍无结果' };
}
```

**评分点**:
- 解析结果字段白名单校验（未知字段丢弃防注入）。
- 权限由系统覆盖注入（LLM 输出不可扩权），放松重试永不触碰权限。
- 相对时间→绝对区间解析。
- 放松按优先级递减且上限 2 次，空结果带解释返回。
