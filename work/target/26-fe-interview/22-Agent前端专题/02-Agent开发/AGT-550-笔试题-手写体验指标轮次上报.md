## AGT-550：手写 reportTurn：三层指标聚合、traceId 打通、失败轮次也上报、采样控制

**需求与边界**：
- 实现 TurnReporter：每轮结束后上报 tech/product/quality 三层指标。
- 边界要求：① 失败/中断轮次也要上报（errCode/aborted 字段）；② 负反馈轮次 100% 上报，正常轮次按 sampleRate 采样；③ 页面卸载前用 sendBeacon 兜底；④ 指标值做边界保护（ttft 上限 60s 封顶防脏数据）。

**答**：
```javascript
class TurnReporter {
  constructor({ sampleRate = 0.2 } = {}) { this.sampleRate = sampleRate; }
  finish(turn, signals = {}) {
    const isBad = turn.errCode || turn.aborted
      || (turn.feedbackTags?.length ?? 0) > 0;
    if (!isBad && Math.random() > this.sampleRate) return;  // 采样
    const rec = {
      traceId: turn.traceId,
      tech: {
        ttft: Math.min(turn.ttft ?? 0, 60000),          // 脏数据封顶
        tps: Math.min(turn.tokensPerSec ?? 0, 1000),
        aborted: !!turn.aborted, errCode: turn.errCode ?? null,
      },
      product: { copy: !!signals.copy, like: signals.like ?? 0,
        regen: signals.regen ?? 0, followUp: !!signals.followUp },
      quality: { cited: turn.sourcesCount ?? 0,
        feedbackTags: turn.feedbackTags ?? [] },
    };
    this.send(rec);
  }
  send(rec) {
    const body = JSON.stringify(rec);
    if (navigator.sendBeacon)                            // 卸载兜底
      navigator.sendBeacon('/api/metrics/turn', body);
    else fetch('/api/metrics/turn', { method: 'POST', body,
      keepalive: true });
  }
}
```

**评分点**:
- 失败/中断轮次必报（isBad 判定优先于采样），质量指标可归因。
- ttft/tps 封顶防脏数据污染分位数。
- sendBeacon + keepalive 双通道（页面卸载不丢最后一批）。
