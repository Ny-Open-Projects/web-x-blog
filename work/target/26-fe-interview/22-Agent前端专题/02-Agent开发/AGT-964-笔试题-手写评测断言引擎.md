## 964：笔试手写：实现可组合的评测断言引擎

**答**：实现 expect(output).toSatisfy(assertions)，断言包括：containsAll(list)、toolSeq(seq)（工具调用序列前缀匹配）、regex(re)、maxTokens(n)（用 est 函数估算输出 token）。所有断言 AND 组合，返回 { pass, failures: [...] }（失败断言带名字与实际值）；断言函数抛错视为该断言失败而非整体崩溃。

```js
function expect(output) {
  const failures = [];
  const run = (name, fn) => {
    try { const ok = fn(output); if (!ok) failures.push({ name, actual: safe(output) }); }
    catch (e) { failures.push({ name, error: String(e) }); }  // 抛错 = 断言失败
    return api;
  };
  const api = {
    containsAll: list => run('containsAll', o => list.every(s => String(o).includes(s))),
    toolSeq: seq => run('toolSeq', o => {
      const names = (o.toolCalls || []).map(t => t.name);
      return seq.every((s, i) => names[i] === s);        // 前缀匹配
    }),
    regex: re => run('regex', o => re.test(String(o))),
    maxTokens: (n, est) => run('maxTokens', o => est(o) <= n),
    toSatisfy: () => ({ pass: failures.length === 0, failures }),
  };
  return api;
}
const r = expect({ text: '支持灰度发布', toolCalls: [{ name: 'search' }, { name: 'read' }] })
  .containsAll(['灰度']).toolSeq(['search', 'read']).toSatisfy();
console.log(r.pass); // true
```

**评分点**：
- 断言隔离：单个断言抛错不影响其他断言执行（failures 收集完整）
- toolSeq 前缀匹配语义清晰，超长输出不误判
- est 作为注入参数（token 估算模型相关）
- 链式 API 实现正确，failures 结构可序列化
