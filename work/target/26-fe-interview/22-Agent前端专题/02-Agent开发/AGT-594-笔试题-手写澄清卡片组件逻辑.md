## AGT-594：手写 ClarifyCard 逻辑：单选/多选、校验、跳过默认值、文本兜底

**需求与边界**：
- 实现 clarifyState(schema) 返回 { sel, toggle, valid, answer, skip }。
- 边界要求：① multi 模式 toggle 正确增删，single 模式覆盖；② valid：single 需选且在 options 内，multi 需满足 schema.min（默认 1）；③ skip 仅 skippable 时可用且带 schema.default；④ answer 输出结构化 { type, value }，文本兜底 non-empty 校验。

**答**：
```javascript
function clarifyState(schema) {
  const vals = schema.options.map(o => o.value);
  let sel = schema.multi ? [] : null;
  const inOptions = (v) => vals.includes(v);
  return {
    toggle(v) {
      if (!inOptions(v)) return;                 // 非法选项忽略
      sel = schema.multi
        ? (sel.includes(v) ? sel.filter(x => x !== v) : [...sel, v])
        : v;                                     // 单选覆盖
    },
    get valid() {
      return schema.multi
        ? sel.length >= (schema.min ?? 1)
        : sel !== null;
    },
    answer() {
      if (!this.valid) throw new Error('CLARIFY_INVALID');
      return { type: 'choice', value: sel };
    },
    textAnswer(t) {
      const v = t.trim();
      if (!v) throw new Error('CLARIFY_EMPTY');
      return { type: 'text', value: v };         // 文本兜底
    },
    skip() {
      if (!schema.skippable) throw new Error('NOT_SKIPPABLE');
      return { type: 'skip', value: schema.default };
    },
  };
}
```

**评分点**:
- single 覆盖/multi 增删正确，非法值忽略（不在 options 内点不动）。
- valid 含 multi.min 校验；skip 带 default 且受 skippable 约束。
- 输出结构化 type+value（模型可解析），文本兜底非空校验。
