## AGT-848：手写 canaryGuard：指标监控、阈值判定（负反馈x2/完成率-5pp）、自动回滚、通知发布者

**需求与边界**：
- 实现 canaryGuard(exp)：周期检查灰度指标，超阈值自动回滚。
- 边界要求：① 判定：treat.dislikeRate ≥ ctrl×2 或 treat.doneRate ≤ ctrl-0.05 即回滚；② 样本不足（<100 会话）不判定；③ 回滚幂等（已回滚不再触发）；④ 回滚后通知发布者带证据（指标快照）；⑤ 恢复（指标回到安全区）不自动重新灰度（需人工）。

**答**：
```javascript
class CanaryGuard {
  constructor(exp) { this.exp = exp; this.rolledBack = false; }
  async check() {
    const { treat, ctrl } = await metrics.groups(this.exp.id);
    if (treat.sessions < 100) return { verdict: 'pending' }; // 样本不足
    if (this.rolledBack) return { verdict: 'already-rolled-back' };
    const bad = treat.dislikeRate >= ctrl.dislikeRate * 2
      || treat.doneRate <= ctrl.doneRate - 0.05;
    if (!bad) return { verdict: 'healthy' };
    this.rolledBack = true;                        // 幂等标志
    await runtime.rollout(this.exp.pkg, { ratio: 0, to: 'stable' });
    notify(this.exp.publisher, { type: 'canary-rollback',
      evidence: { treat, ctrl, at: Date.now() } });
    return { verdict: 'rolled-back', evidence: { treat, ctrl } };
  }
}
```

**评分点**:
- 双阈值判定（负反馈 2 倍 OR 完成率 -5pp）；样本门槛防误杀。
- 回滚幂等标志；通知带指标证据；恢复需人工（不自动反复横跳）。
