## 1195：笔试手写：找出某 Agent 的全部调用方（静态+动态）

**答**：实现 findCallers(agentId, { registry, code, logs })：registry 为 { [caller]: string[] }（每调用方依赖的 agent 列表）；code 为代码文本（含 agent.run("agentId") 形式引用即算，记为哨兵 'code-inline'）；logs 为 { caller, agent, ts }[]（近 30 天动态调用）。输出 { static, dynamic, all }（各自去重排序）。

```js
function findCallers(agentId, { registry, code, logs }) {
  const stat = new Set();
  for (const [caller, deps] of Object.entries(registry)) {
    if (deps.includes(agentId)) stat.add(caller);
  }
  const esc = agentId.replace(/[.*+?^\${}()|[\]\\]/g, '\\$&'); // 正则转义
  const re = new RegExp('agent\\.(?:run|invoke)\\(\s*["\'`]' + esc + '["\'`]');
  if (re.test(code)) stat.add('code-inline');        // 代码内联引用（需人工迁移）
  const dyn = new Set();
  for (const l of logs) if (l.agent === agentId) dyn.add(l.caller);
  const all = [...new Set([...stat, ...dyn])].sort();
  return { static: [...stat].sort(), dynamic: [...dyn].sort(), all };
}
const r = findCallers('coder-1', {
  registry: { pipelineA: ['coder-1'], pipelineB: ['searcher'] },
  code: "agent.run('coder-1')",
  logs: [{ caller: 'pipelineC', agent: 'coder-1', ts: 1 }],
});
console.log(r.all); // ['code-inline', 'pipelineA', 'pipelineC']
```

**评分点**：
- 三源合并去重：注册表、代码引用、动态日志
- agentId 的正则转义正确（特殊字符安全）
- 「code-inline」哨兵值标明内联引用需人工迁移
- 能讨论：退役清查必须双确认（静态+动态），只看注册表会漏内联调用、只看日志会漏低频调用
