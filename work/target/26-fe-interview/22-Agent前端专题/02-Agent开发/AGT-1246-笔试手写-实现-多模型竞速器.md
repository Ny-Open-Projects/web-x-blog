## 1246：笔试手写：实现 多模型竞速器

**答**：实现 raceModels(task)：task 为 { prompt, models: [{ name, call: () => Promise, p95 }] }。并行调用全部模型，取第一个成功者；若 800ms 内无人成功则放宽为「最先成功的任意结果」，若 3s 内仍无则抛错；失败/超时的其余调用必须被取消（计入 cancelled）。返回 { winner, cancelled, elapsed }。

```js
function raceModels(task, soft = 800, hard = 3000) {
  const cancelled = [];
  const t0 = Date.now();
  const wrapped = task.models.map(m =>
    m.call().then(
      r => ({ ok: true, name: m.name, r, ts: Date.now() - t0 }),
      e => ({ ok: false, name: m.name, e })
    )
  );
  return new Promise((resolve, reject) => {
    const timer = setTimeout(() => reject(new Error('hard timeout')), hard);
    Promise.allSettled(wrapped).then(rs => {
      const ok = rs.filter(r => r.status === 'fulfilled' && r.value.ok);
      if (!ok.length) { clearTimeout(timer); return reject(new Error('all failed')); }
      // 软时限内优先、否则取全局最先成功；未胜者全部记取消
      const pick = ok.find(v => v.value.ts <= soft) ?? ok.sort((a, b) => a.value.ts - b.value.ts)[0];
      ok.filter(v => v !== pick).forEach(v => cancelled.push(v.value.name));
      clearTimeout(timer);
      resolve({ winner: pick.value, cancelled, elapsed: Date.now() - t0 });
    });
  });
}
```

**评分点**：
- allSettled 而非 race（失败不抢占、可统计取消名单）
- 软/硬双时限语义区分
- 失败调用与被取消调用的区分
- 能讨论真实场景需 AbortController 真取消而非仅标记
