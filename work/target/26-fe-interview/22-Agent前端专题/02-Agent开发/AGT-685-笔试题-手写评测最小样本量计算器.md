## AGT-685：手写 minSample：比例检验样本量、配对设计、最小可检出差异

**需求与边界**：
- 实现 minSample(p1, delta, opts) 与 pairedMinSample(pDiscord, delta)。
- 边界要求：① 独立双组样本量公式（alpha=0.05, power=0.8 可配）；② 配对设计按不一致率折减（不一致率越低所需样本越少）；③ delta≤0 抛错；④ p1 边界（0 或 1）时用保守估计。

**答**：
```javascript
function minSample(p1, delta, { alpha = 0.05, power = 0.8 } = {}) {
  if (delta <= 0) throw new Error('DELTA_POSITIVE');
  const p2 = Math.min(p1 + delta, 0.999);
  const pBase = (p1 <= 0 || p1 >= 1) ? 0.5 : p1; // 边界保守估计
  const zA = qnorm(1 - alpha / 2), zB = qnorm(power);
  return Math.ceil(
    (zA * Math.sqrt(2 * pBase * (1 - pBase))
      + zB * Math.sqrt(p1 * (1 - p1) + p2 * (1 - p2))) ** 2
    / delta ** 2);                                // 双组总量
}
function pairedMinSample(pDiscord, delta) {
  if (delta <= 0 || pDiscord <= 0) throw new Error('BAD_INPUT');
  // 配对：只需在不一致子集上分辨方向
  return Math.ceil(1.96 ** 2 * 0.25              // 不一致子集中最保守
    / delta ** 2) / pDiscord;                    // 折算回总用例数
}
// 用法：92%→94% 需多少用例
// minSample(0.92, 0.02) ≈ 700+；若不一致率 0.1，配对只需 ~90
```

**评分点**:
- 公式正确（双组 z 检验样本量），delta≤0 显式抛错。
- p1 边界保守估计（0/1 时方差退化）。
- 配对设计按不一致率折减（核心省样本手段），并解释节省幅度。
