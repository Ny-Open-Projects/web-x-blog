## AGT-794：手写 distillQueue：事实抽取→证据计数→准入→分域写入、重复事实合并

**需求与边界**：
- 实现 DistillPipeline：ingest(session)/flush()。
- 边界要求：① 抽取事实带 { statement, domain, kind }；② 同语义事实合并（嵌入相似 >0.92 视为同一事实，evidence 累加）；③ evidence>=3 进语义库，否则留候选池；④ 候选池上限 500（LRU 淘汰最旧）；⑤ flush 幂等（重复跑不重复写）。

**答**：
```javascript
class DistillPipeline {
  constructor({ threshold = 3, cap = 500 } = {}) {
    this.threshold = threshold; this.cap = cap;
    this.pool = []; this.written = new Set();
  }
  async ingest(session) {
    const facts = await llm.extract(session.transcript, FACTS_PROMPT);
    for (const f of facts) {
      const dup = this.pool.find(p =>
        cosSim(embed(p.statement), embed(f.statement)) > 0.92);
      if (dup) dup.evidence++;                     // 同语义合并
      else this.pool.push({ ...f, evidence: 1 });
    }
    if (this.pool.length > this.cap)
      this.pool = this.pool.slice(-this.cap);      // LRU 淘汰
  }
  async flush() {
    const promoted = this.pool.filter(f => f.evidence >= this.threshold);
    const results = [];
    for (const f of promoted) {
      const key = hash(f.statement + f.domain);
      if (this.written.has(key)) continue;         // flush 幂等
      await semantic.write(f, { domain: f.domain });
      this.written.add(key);
      results.push(f);
    }
    this.pool = this.pool.filter(f => f.evidence < this.threshold);
    return { promoted: results.length,
      remaining: this.pool.length };
  }
}
```

**评分点**:
- 语义合并（0.92 相似阈值）防同一事实重复计数。
- 准入门槛 evidence>=3 + 候选池 LRU 上限（池不膨胀）。
- flush 幂等（written 集合判重）。
