## AGT-551：Agent 一次任务要跑 5~8 个工具，时间线组件怎么呈现（阶段/状态/耗时/可展开）

**答**：
- 时间线按「回合」组织：每回合 = 模型思考 + N 个工具调用 + 结果回填；节点状态机 queued→running→ok/error/skipped，运行中的节点显示已耗时（实时跳动）。
- 默认折叠为摘要行（"已查询 3 个数据源，耗时 4.2s"），点击展开看每个工具的入参摘要与结果预览——完整参数走调试面板，普通用户只看人话摘要。
- 失败节点红色可点击：展开显示失败原因与"重试此步"入口（服务端支持单步重试时）。

```jsx
function ToolTimeline({ turns }) {
  return turns.map(t => (
    <Turn key={t.id}>
      <TurnSummary turn={t} />          {/* 摘要：N个工具+耗时 */}
      <Expandable>
        {t.toolCalls.map(tc => (
          <ToolNode key={tc.id} tc={tc}  // 状态机驱动样式
            onRetry={tc.status === 'error' ? () => retryToolCall(tc.id) : null} />
        ))}
      </Expandable>
    </Turn>
  ));
}
function ToolNode({ tc, onRetry }) {
  const [elapsed, setElapsed] = useState(0);
  useEffect(() => {
    if (tc.status !== 'running') return;
    const t = setInterval(() => setElapsed(Date.now() - tc.startedAt), 500);
    return () => clearInterval(t);      // 只在运行中计时，避免无谓渲染
  }, [tc.status]);
  return <div className={`node ${tc.status}`}>
    <Icon name={tc.tool} /> {tc.summary}
    {tc.status === 'running' && <span>{(elapsed / 1000).toFixed(1)}s</span>}
    {onRetry && <button onClick={onRetry}>重试</button>}
  </div>;
}
```
