## AGT-664：静态评测集会被背题（针对用例优化），如何做对抗性增强

**答**：
- 三种增强：扰动（同模板换参数/换实体/换问法生成变体，语义不变答案可判）、对抗（LLM 生成"看起来类似但考不同点"的迷惑用例，人工抽检后入库）、隐藏集（held-out 不进日常回归，月度或发版跑，防刷分）。
- 变体生成的质量门槛：变体必须过「金标一致性校验」（对金标答案的期望不变），失败变体丢弃——自动生成的坏用例比没用例更糟。
- 轮换策略：用例池大于单次跑量，每次随机抽样跑（覆盖率统计保证周期内全覆盖），配合隐藏集构成双防线。

```javascript
async function augmentCases(seedCases, n) {
  const variants = await generateVariants(seedCases, n, {
    strategies: ['param_swap', 'paraphrase', 'entity_sub'],
  });
  const valid = [];
  for (const v of variants) {
    const ok = await goldenConsistency(v);        // 金标一致性校验
    if (ok) valid.push(v);
    else rejectLog.push({ v, reason: 'golden_drift' }); // 坏变体丢弃
  }
  return { pool: [...seedCases, ...valid],
    heldout: split(valid, { holdoutRatio: 0.2 }) };
}
```
