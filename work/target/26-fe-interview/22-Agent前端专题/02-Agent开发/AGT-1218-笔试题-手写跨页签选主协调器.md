## 1218：笔试手写：实现 BroadcastChannel 的页签选主（leader election）

**答**：实现 LeaderElection(tabId, channel)：claim() 广播竞选；收到他人 claim 时按 tabId 字典序（小者胜）——输者退位（isLeader=false）并监听 LeaderHeartbeat；胜者每 3s 发心跳，心跳超时（9s 无心跳）时重新 claim。isLeader() 返回当前状态。

```js
class LeaderElection {
  constructor(tabId, ch) {
    this.tabId = tabId; this.ch = ch; this.leader = null;
    ch.onmessage = e => this._on(e.data);
  }
  claim() { this.ch.postMessage({ type: 'claim', tabId: this.tabId }); }
  _on(m) {
    if (m.type === 'claim') {
      if (!this.leader || m.tabId < this.leader) {
        this.leader = m.tabId < (this.leader ?? m.tabId)
          ? m.tabId : (this.leader ?? m.tabId);
        if (this.leader !== this.tabId && this.isLeader()) {
          this.leader = m.tabId;                       // 字典序小者胜，自己退位
        }
      }
    }
    if (m.type === 'heartbeat') this.leader = m.tabId;
  }
  isLeader() { return this.leader === this.tabId; }
}
```

**评分点**：
- 确定性仲裁（tabId 字典序——双 claim 时唯一胜者，无协商震荡）
- 心跳超时重新竞选（领导者崩溃的恢复路径）
- 退位语义（输者停止领导行为——防双主）
- 能讨论：脑裂窗口（心跳间隔与超时的权衡）、跨页签锁（编辑锁与选主的组合）
