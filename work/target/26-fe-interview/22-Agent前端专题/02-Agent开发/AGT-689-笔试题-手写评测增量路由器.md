## AGT-689：手写 routeCases：diff影响面映射、受影响用例筛选、覆盖兜底、预算裁剪

**需求与边界**：
- 实现 routeCases(diff, mapping, { budget })。
- 边界要求：① diff 中每个变更项（prompt段落/工具/模板）映射到用例集；② 无映射关系的变更项按「能力域保守路由」（对应 cap 全量）；③ 预算超限时按难度加权抽样并标注 sampled；④ 空变更返回空计划。

**答**：
```javascript
function routeCases(diff, mapping, { budget = Infinity } = {}) {
  if (!diff.items.length) return { cases: [], sampled: false };
  const hit = new Set();
  for (const item of diff.items) {
    const direct = mapping[item.id] ?? [];
    direct.forEach(c => hit.add(c));
    if (!direct.length) {                          // 保守路由
      casesByCap(item.capHint).forEach(c => hit.add(c));
    }
  }
  let cases = [...hit];
  let sampled = false;
  if (cases.length > budget) {                     // 预算裁剪
    cases = weightedSample(cases,
      c => ({ easy: 1, mid: 2, hard: 4 }[c.diff]), budget);
    sampled = true;
  }
  return { cases, sampled, coverageNote: sampled
    ? '超预算抽样执行，结论标注为抽样结论' : '全量受影响用例' };
}
```

**评分点**:
- 影响面映射直连 + 无映射时保守路由（宁可多跑不漏跑）。
- 预算裁剪按难度加权（难题信息量优先），抽样结论显式标注。
- 空变更短路。
