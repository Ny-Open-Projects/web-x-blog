## AGT-544：手写视口驱动重组件加载：IntersectionObserver、预加载边距、失败重试、占位防CLS

**需求与边界**：
- 实现 LazyBlockManager：对每条消息的重组件（图表/高亮/公式）在进入视口 200px 前加载。
- 边界要求：① 加载失败降级为源码展示并支持手动重试（最多 2 次）；② 占位符高度 = 最终渲染高度估计值（防 CLS）；③ 流式中的消息不触发懒加载（等 complete）；④ 组件卸载时取消未完成的加载回调。

**答**：
```javascript
class LazyBlockManager {
  constructor(root) {
    this.io = new IntersectionObserver((es) => {
      for (const e of es) if (e.isIntersecting) this.load(e.target);
    }, { rootMargin: '200px', root });
    this.retries = new Map();
  }
  observe(el, { loadFn, complete }) {
    if (!complete) return;              // 流式未完成不懒加载
    el.__loadFn = loadFn;
    el.style.minHeight = estimateHeight(loadFn.type);  // 占位防 CLS
    this.io.observe(el);
  }
  async load(el) {
    this.io.unobserve(el);
    try { await el.__loadFn(); this.retries.set(el, 0); }
    catch (e) {
      const n = (this.retries.get(el) ?? 0) + 1;
      if (n <= 2) { this.retries.set(el, n); this.observe(el, el.__cfg); }
      else el.fallbackSource();         // 降级：源码展示 + 手动重试按钮
    }
  }
  unobserve(el) { this.io.unobserve(el); el.__loadFn = null; } // 卸载清理
}
```

**评分点**:
- rootMargin 预加载 + complete 才加载（流式中不浪费加载）。
- 失败重试上限与源码降级（重组件失败不白屏）。
- 占位 minHeight 防 CLS；卸载时清理 observer 引用。
