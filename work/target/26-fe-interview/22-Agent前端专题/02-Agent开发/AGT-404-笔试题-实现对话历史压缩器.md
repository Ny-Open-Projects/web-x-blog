## AGT-404：手写历史压缩器：数字/约束/决策原文保留，其余摘要

**需求与边界**：
- 输入：消息数组、token 预算、压缩函数（模拟 LLM 摘要）；输出：压缩后历史（≤预算、关键项原文、纪要标注 AI 生成）。
- 边界要求：① 数字与决策类内容正则提取永不摘要；② 摘要内容带"AI 纪要"标记与引用指针；③ 循环压缩直到达标（单次不够压两轮）；④ 空消息/超长单条消息的边界处理。

**答**：
```javascript
const NUM = /(\d+(\.\d+)?\s*(元|万|%|天|小时)|ORD\d+|金额|截止)/;
const DECISION = /(决定|确认|必须|约定|方案\s*[ABC])/;

async function compactHistory(history, budget, summarize) {
  const keep = [], compressible = [];
  for (const m of history) {
    if (m.role === 'system') { keep.push(m); continue; }     // 系统提示不动
    if (NUM.test(m.content) || DECISION.test(m.content))
      keep.push(m);                                          // 关键项原文保留
    else compressible.push(m);
  }
  let result = [...keep];
  if (tokens(result) <= budget) return { result, kept: keep.length };
  // 分批摘要压缩项（每批 8 条）
  for (let i = 0; i < compressible.length; i += 8) {
    const batch = compressible.slice(i, i + 8);
    const s = await summarize(batch.map(m => m.content).join('\n'));
    result.push({ role: 'system',
      content: `[AI纪要 第${i / 8 + 1}批] ${s}\n(原文见第 ${i + 1}~${i + 8} 轮)` });
    if (tokens(result) <= budget) { result.push(...compressible.slice(i + 8)); break; }
  }
  // 仍超预算：丢弃最老的纯闲聊纪要（降级）
  while (tokens(result) > budget && result.length > 2)
    result.splice(1, 1);
  return { result, kept: keep.length,
    warning: tokens(result) > budget ? '仍超预算' : null };
}
function tokens(msgs) { return msgs.reduce((s, m) => s + Math.ceil(m.content.length / 2), 0); }
```

**评分点**:
- 规则层（数字/决策/系统提示）与摘要层分离，关键内容永不改写。
- 摘要带"AI 纪要"标记与原文轮次指针（可回溯）。
- 分批摘要与超预算降级（丢最老闲聊）两级兜底，含 warning 输出。
- system 角色消息不参与摘要（安全锚不动）。
