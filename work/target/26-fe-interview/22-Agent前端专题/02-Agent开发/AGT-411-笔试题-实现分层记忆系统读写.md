## AGT-411：手写记忆系统：重复判重、时间衰减检索、冲突显式标记

**需求与边界**：
- 输入：写入事件 {text, type}、查询 {text, user}；输出：记忆存取。
- 边界要求：① 写入前与相关记忆判重（重复不入库）；② 检索按相关性×时间衰减排序；③ 新旧矛盾记忆都保留并标 conflict；④ 记录数上限 LRU 清理。

**答**：
```javascript
class Memory {
  constructor({ cap = 1000, decayDays = 90 }) {
    this.store = []; this.cap = cap; this.decay = decayDays * 864e5;
  }
  async write(ev) {
    const related = this.searchInternal(ev.text, 5);
    // 判重：与已有高相似记忆重复则不入库
    const dup = related.find(r => similarity(r.text, ev.text) > 0.92);
    if (dup) { dup.count++; dup.ts = Date.now(); return { dup: true }; }
    // 冲突检测：同主体矛盾 → 双保留标记
    const conflicts = related.filter(r => contradicts(r.text, ev.text));
    const rec = { id: uid(), ...ev, ts: Date.now(), count: 1,
      conflicts: conflicts.map(c => c.id) };
    conflicts.forEach(c => !c.conflicts.includes(rec.id) &&
      c.conflicts.push(rec.id));                    // 双向标记
    this.store.push(rec);
    if (this.store.length > this.cap) {             // LRU：最老低频清
      this.store.sort((a, b) => (a.ts + a.count * 864e5) - (b.ts + b.count * 864e5));
      this.store.shift();
    }
    return rec;
  }
  search(q, { topK = 5 } = {}) {
    return this.searchInternal(q, topK).map(r => ({
      ...r,
      score: similarity(r.text, q.text ?? q) *
        Math.exp(-(Date.now() - r.ts) / this.decay),  // 时间衰减
      conflictWarning: r.conflicts.length > 0,
    })).sort((a, b) => b.score - a.score);
  }
  searchInternal(q, k) {
    return this.store.map(r => ({ ...r, s: similarity(r.text, q) }))
      .filter(r => r.s > 0.3).sort((a, b) => b.s - a.s).slice(0, k);
  }
}
```

**评分点**:
- 写入判重（相似度阈值）+ 命中更新（count/ts 提升）而非重复入库。
- 冲突双向标记都保留（不静默覆盖，历史可回溯）。
- 检索分数 = 相关性 × 时间衰减指数，过期记忆自然降权。
- 容量上限 LRU 清理策略合理（低频+最老优先）。
