## AGT-442：手写影子模式：候选版本并行、影子结果只记录不返回、成本抽样

**需求与边界**：
- 输入：生产请求、prod/candidate 两个执行器、抽样率；输出：prod 结果（candidate 仅记录）。
- 边界要求：① 影子失败不影响生产（隔离异常）；② 影子抽样率可配（控成本）；③ 影子调用不占用生产配额/限流；④ 对比指标聚合（质量 judge+成本+延迟）。

**答**：
```javascript
class ShadowRunner {
  constructor({ prod, candidate, sampleRate = 0.1, judge }) {
    this.prod = prod; this.candidate = candidate;
    this.sampleRate = sampleRate; this.judge = judge;
  }
  async run(req) {
    const isShadow = Math.random() < this.sampleRate;
    // 影子异步并行，不阻塞主链路
    if (isShadow) {
      fireAndForget(async () => {
        try {
          const t0 = performance.now();
          const cand = await this.candidate(req,
            { quota: 'shadow',             // 独立配额池
              rateLimit: SHADOW_LIMIT });
          const dur = performance.now() - t0;
          const prod = await this.prod.peek(req);   // 复用生产结果对比
          const verdict = await this.judge(req,
            { a: prod.output, b: cand.output });
          await record({ ts: Date.now(), reqId: req.id,
            prodDur: prod.dur, candDur: dur,
            cost: { prod: prod.cost, cand: cand.cost },
            verdict, candError: null });          // 只记录
        } catch (e) {
          await record({ reqId: req.id,
            candError: e.message });              // 影子失败仅记录
        }
      });
    }
    return this.prod.run(req);                    // 主链路不受影响
  }
}
const fireAndForget = (p) => p.catch(() => {});   // 兜底吞异常
// 聚合分析：candError 率 / verdict 胜率 / 成本差 / P95 延迟差。
```

**评分点**:
- 零干扰：影子异步 fire-and-forget、独立配额池、异常隔离只记录。
- 抽样率控制影子成本。
- 对比三指标聚合（judge 质量/成本/延迟）且复用生产结果免重复调用。
- 候选失败率也是关键指标（candError 记录聚合）。
