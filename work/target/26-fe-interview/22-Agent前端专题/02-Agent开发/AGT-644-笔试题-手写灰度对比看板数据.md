## AGT-644：手写 canaryDashboard：四维对比、Wilson置信下界、verdict判定、版本指纹

**需求与边界**：
- 实现 canaryDashboard(treat, ctrl, metrics)。
- 边界要求：① 四维 doneRate/adoption/costPerTask/p95Latency 对比；② verdict：treat 置信下界 > ctrl→pass，置信上界 < ctrl→fail，否则 pending；③ 成本与延迟为逆向指标（低更好）需方向翻转；④ 版本指纹 = promptVer+modelVer+工具清单哈希。

**答**：
```javascript
function wilson(k, n, z = 1.96) {
  if (!n) return [0, 1];
  const p = k / n, d = 1 + z * z / n;
  const c = p + z * z / (2 * n);
  const r = z * Math.sqrt(p * (1 - p) / n + z * z / (4 * n * n));
  return [(c - r) / d, (c + r) / d];
}
const INVERSE = { costPerTask: true, p95Latency: true };  // 逆向指标
function verdict(m) {
  let [lo, hi] = wilson(m.treatGood, m.treatN);
  if (INVERSE[m.name]) [lo, hi] = [1 - hi, 1 - lo];      // 方向归一
  const ctrl = INVERSE[m.name] ? 1 - m.ctrl : m.ctrl;
  if (lo > ctrl) return 'pass';
  if (hi < ctrl) return 'fail';
  return 'pending';
}
function canaryDashboard(treat, ctrl, metrics) {
  const fp = hash([treat.promptVer, treat.modelVer,
    toolListHash(treat.tools)].join('|'));
  return { fingerprint: fp, rows: metrics.map(name => {
    const m = { name, treatGood: treat[name], treatN: treat.n,
      ctrl: ctrl[name] };
    return { ...m, verdict: verdict(m) };
  }) };
}
```

**评分点**:
- Wilson 置信区间处理小样本（不用裸均值决策）；逆向指标方向归一后统一判定。
- pass/fail/pending 三态明确，pending 才继续等样本。
- 版本指纹绑定灰度批次（回滚可精确定位）。
