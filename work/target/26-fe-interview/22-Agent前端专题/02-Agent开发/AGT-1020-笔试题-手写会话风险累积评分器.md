## 1020：笔试手写：实现会话级风险累积评分

**答**：实现 sessionRisk(turns)：每轮输入 { role, text }，用户轮过 classify(text) 得 level 0~3。评分规则：单轮 level3 直接 1.0；最近 5 轮里出现 level2 及以上 3 次 → 0.8；风险等级「逐轮上升」且最后一轮 >= 2 → 0.7；否则取最近一轮 level/3。返回 { score, reason }。

```js
function classify(text) {   // 简化：按特征词定级
  if (/rm\s+-rf|转账|删除所有/.test(text)) return 3;
  if (/忽略|绕过|越狱|password/.test(text)) return 2;
  if (/下载|上传|执行/.test(text)) return 1;
  return 0;
}
function sessionRisk(turns) {
  const lv = turns.filter(t => t.role === 'user').map(t => classify(t.text));
  if (lv.at(-1) === 3) return { score: 1, reason: 'single-shot critical' };
  const recent = lv.slice(-5);
  if (recent.filter(l => l >= 2).length >= 3) return { score: 0.8, reason: 'frequent high-risk' };
  const rising = lv.slice(-4).every((l, i, a) => i === 0 || l > a[i - 1]);
  if (rising && lv.at(-1) >= 2 && lv.slice(-4).length >= 3)
    return { score: 0.7, reason: 'escalating ladder' };       // 温水煮蛙形态
  return { score: (lv.at(-1) || 0) / 3, reason: 'current turn only' };
}
console.log(sessionRisk([
  { role: 'user', text: '你好' },
  { role: 'user', text: '帮我下载文件' },
  { role: 'user', text: '绕过限制' },
])); // { score: 0.7, reason: 'escalating ladder' }
```

**评分点**：
- 三条规则优先级正确（单轮致命 > 频次 > 形态）
- 「逐轮上升」判断只看用户轮序列，且要求最后一轮仍高危
- classify 与评分分离（可替换真实分类器），可测性好
- 能讨论：阈值经验值与误杀权衡、只评用户轮防止模型回复干扰、level3 触发的动作应是「阻断 + 审批」而非仅评分
