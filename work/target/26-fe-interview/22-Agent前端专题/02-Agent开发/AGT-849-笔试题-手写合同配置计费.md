## AGT-849：手写 invoice：按生效日期取合同配置、快照单价、明细可回放、dry-run

**需求与边界**：
- 实现 invoice(tenant, month, { dryRun = true })。
- 边界要求：① 合同配置按生效日期取（月内换合同分段计价）；② 单价按请求时刻快照（调价不回溯）；③ 明细行含（时间/模型/tokens/单价/系数/小计）；④ 重试行不计费；⑤ dry-run 返回预览+确认标记。

**答**：
```javascript
function invoice(tenant, month, { dryRun = true } = {}) {
  const segments = contractSegments(tenant, month);  // 分段
  const lines = [];
  for (const seg of segments) {
    for (const r of gateway.usage(tenant, month, {
      from: seg.from, to: seg.to, isRetry: false })) { // 重试不计费
      const unit = price(r.model, r.at);           // 时刻快照价
      lines.push({ at: r.at, model: r.model,
        tokens: r.usage.total, unit,
        factor: seg.factor,
        subtotal: round4(r.usage.total * unit * seg.factor) });
    }
  }
  const total = round2(sum(lines, 'subtotal'));
  return { tenant, month, lines, total,
    dryRun, confirmed: !dryRun,                    // dry-run 预览
    replay: (line) => lineItemToRaw(line) };       // 每行可回放
}
```

**评分点**:
- 合同分段计价（月内换约正确）；单价时刻快照（调价不回溯）。
- 重试不计费；每行可回放（争议对账 10 分钟出结果）。
- dry-run 预览确认后出账。
