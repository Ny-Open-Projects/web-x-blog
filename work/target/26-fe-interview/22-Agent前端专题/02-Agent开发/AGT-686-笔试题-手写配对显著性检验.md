## AGT-686：手写 pairedTest：不一致子集二项检验、p值、结论话术

**需求与边界**：
- 实现 pairedTest(cases)：cases 每条含 { oldPass, newPass }。
- 边界要求：① 只统计不一致子集（old≠new）；② 双侧二项检验 p 值（精确计算，n≤200 时枚举尾部）；③ 结论三态：new显著优/old显著优/无法区分；④ 全一致返回"无差异信息"。

**答**：
```javascript
function binomTail(k, n, p = 0.5) {
  const C = (n, r) => { let s = 1;
    for (let i = 0; i < r; i++) s = s * (n - i) / (i + 1);
    return s; };
  let tail = 0;
  for (let x = k; x <= n; x++) tail += C(n, x) * p ** x * (1 - p) ** (n - x);
  return Math.min(1, 2 * tail);                  // 双侧
}
function pairedTest(cases) {
  const diff = cases.filter(c => c.oldPass !== c.newPass);
  if (!diff.length)
    return { verdict: 'no-signal', note: '两版全一致，无差异信息' };
  const wins = diff.filter(c => c.newPass).length;
  const p = binomTail(Math.min(wins, diff.length - wins), diff.length);
  return { discordant: diff.length, wins, p,
    verdict: p < 0.05
      ? (wins > diff.length / 2 ? 'new 显著优' : 'old 显著优')
      : '无法区分（样本不足）' };
}
```

**评分点**:
- 不一致子集配对思想正确（功效远高于独立比较）。
- 精确二项 p 值（小样本枚举尾部而非正态近似）。
- 三态结论话术，"无法区分"不硬下结论。
