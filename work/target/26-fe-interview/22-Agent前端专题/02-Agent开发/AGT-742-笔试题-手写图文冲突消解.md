## AGT-742：手写 mergePaths：OCR 数值优先、冲突区域重看、融合输出标注来源

**需求与边界**：
- 实现 mergePaths(ocr, sem)：合并 OCR 与语义理解两路结果。
- 边界要求：① 数值类断言 OCR 优先（sem 与 ocr 数值不一致以 OCR 为准并标记 conflict）；② 冲突字段列出（字段/两路值/裁决依据）；③ sem 独有的语义信息保留但标注 unverified-numeric；④ 输出统一 { fields, conflicts } 结构。

**答**：
```javascript
function mergePaths(ocr, sem) {
  const fields = {}; const conflicts = [];
  const semFields = sem.fields ?? {};
  for (const [k, v] of Object.entries(semFields)) {
    if (isNumericField(k) && ocr.numbers?.[k] !== undefined) {
      if (String(ocr.numbers[k]) !== String(v)) {
        fields[k] = { value: ocr.numbers[k],
          source: 'ocr', note: '数值以OCR提取为准' };
        conflicts.push({ field: k, ocr: ocr.numbers[k],
          sem: v, rule: 'numeric-ocr-priority' });  // 裁决留痕
      } else fields[k] = { value: v, source: 'both' };
    } else {
      fields[k] = { value: v, source: 'sem',
        unverified: isNumericField(k) };            // sem数值无OCR佐证
    }
  }
  for (const [k, v] of Object.entries(ocr.numbers ?? {}))
    if (!(k in fields)) fields[k] = { value: v, source: 'ocr' };
  return { fields, conflicts,
    recheck: conflicts.length
      ? conflicts.map(c => c.region) : [] };        // 冲突区域建议重看
}
```

**评分点**:
- 数值 OCR 优先裁决明确且留痕（conflicts 列表可审计）。
- sem 独有数值标 unverified（下游回答时可加误差提示）。
- 冲突区域返回 recheck 建议（可触发定向重看）。
