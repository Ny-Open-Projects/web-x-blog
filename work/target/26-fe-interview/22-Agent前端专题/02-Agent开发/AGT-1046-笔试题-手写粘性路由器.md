## 1046：笔试手写：实现带粘性与权重调整的任务路由器

**答**：实现 Router：register(name, handler) 注册版本；setWeight(name, w) 设置新任务权重（总和可任意，按比例）；route(taskId) —— 已有粘性记录的任务路由到原版本，新任务按当前权重随机分配并记录。支持 drain(name) 返回该版本是否已无在途任务（用计数器模拟在途任务）。

```js
class Router {
  constructor() { this.h = new Map(); this.w = new Map();
    this.sticky = new Map(); this.inflight = new Map(); }
  register(name, handler) { this.h.set(name, handler); this.w.set(name, 0); this.inflight.set(name, 0); }
  setWeight(name, w) { if (!this.h.has(name)) throw new Error('unknown ' + name); this.w.set(name, w); }
  route(taskId) {
    if (!this.sticky.has(taskId)) {                 // 新任务按权重分配
      const total = [...this.w.values()].reduce((a, b) => a + b, 0);
      let r = Math.random() * total;
      for (const [name, w] of this.w) { r -= w; if (r <= 0) { this.sticky.set(taskId, name); break; } }
      this.sticky.set(taskId, this.sticky.get(taskId) || [...this.w.keys()][0]); // 全零兜底
    }
    const v = this.sticky.get(taskId);
    this.inflight.set(v, this.inflight.get(v) + 1);  // 在途计数
    return this.h.get(v)(taskId).finally(() =>
      this.inflight.set(v, this.inflight.get(v) - 1));
  }
  drained(name) { return this.inflight.get(name) === 0; }
}
```

**评分点**：
- 粘性语义正确：已分配任务不受 setWeight 影响，新任务才按新权重
- 权重按比例分配（总和不要求 100），全零权重的兜底分支
- 在途计数与 drained 判断支持安全下线
- 能讨论：粘性记录的清理时机（任务完成即删防内存泄漏）、权重变化导致用户「换版本」的体验问题（按用户而非任务粘）
