## 1275：笔试手写：实现 工具返回结构规整器

**答**：实现 normalizeToolResult(raw)：raw 为任意结构（对象/数组/字符串/数字）。目标 schema：{ ok, data, meta }。规则：字符串 → data: { text }；数组 → data: { items, count }；对象含 error 字段 → ok: false, data: { error }; 其余对象原样进 data；meta 记录 { kind, size }（size = JSON 序列化长度）。非法输入（undefined/函数）返回 ok: false。

```js
function normalizeToolResult(raw) {
  const kind = v => {
    if (v === undefined || typeof v === 'function') return 'invalid';
    if (v === null) return 'null';
    if (Array.isArray(v)) return 'array';
    return typeof v;
  };
  const k = kind(raw);
  if (k === 'invalid' || k === 'null') return { ok: false, data: { error: 'invalid result' }, meta: { kind: k, size: 0 } };
  const size = JSON.stringify(raw)?.length ?? 0;
  let data;
  if (typeof raw === 'string') data = { text: raw };
  else if (Array.isArray(raw)) data = { items: raw, count: raw.length };
  else if (typeof raw === 'object' && raw.error) return { ok: false, data: { error: raw.error }, meta: { kind: k, size } };
  else data = raw;
  return { ok: true, data, meta: { kind: k, size } };
}
```

**评分点**：
- kind 分派 + 各类型映射规则完整
- 对象带 error 字段的失败识别
- size 用序列化长度（体积意识，供裁剪参考）
- 能讨论：规整层让下游（模型/展示/缓存）拿到一致契约
