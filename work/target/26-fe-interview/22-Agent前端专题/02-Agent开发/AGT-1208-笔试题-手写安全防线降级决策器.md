## 1208：笔试手写：实现 fail-closed/fail-open 的分级降级决策

**答**：实现 guardDecide(action, guardState, riskCfg)：guardState = { main: 'ok'|'down', rule: 'ok'|'down' }；riskCfg = { [level]: { failMode: 'closed'|'open' } }。决策：main ok -> pass 主检结果；main down 时按 action.risk 的 failMode：closed -> reject（记 failClosed）+ fallback 到 rule 检测（rule ok 则 pass 时打标 degraded）；open -> rule 检测，rule 也 down -> passTagged。返回 { verdict: 'pass'|'passTagged'|'reject'|'block', tag? }。

```js
function guardDecide(action, guardState, riskCfg) {
  const fm = riskCfg[action.risk]?.failMode ?? 'closed';
  if (guardState.main === 'ok') return { verdict: 'pass' };
  if (fm === 'closed') return { verdict: 'reject', tag: 'failClosed' };
  if (guardState.rule === 'ok') {
    const risky = ruleDetect(action.content);
    return risky ? { verdict: 'block' }
      : { verdict: 'passTagged', tag: 'degraded' };   // 降级放行打标待回补
  }
  return { verdict: 'passTagged', tag: 'degraded' };
}
function ruleDetect(content) { return /忽略以上|发送到/.test(content); }
console.log(guardDecide({ risk: 'high', content: 'x' },
  { main: 'down', rule: 'ok' }, { high: { failMode: 'closed' } }));
// { verdict: 'reject', tag: 'failClosed' }
console.log(guardDecide({ risk: 'low', content: 'hello' },
  { main: 'down', rule: 'down' }, { low: { failMode: 'open' } }));
// { verdict: 'passTagged', tag: 'degraded' }
```

**评分点**：
- fail-closed/open 按 action 风险分级（决策矩阵完整）
- 降级放行必须打标（degraded 待回补——可观测语义）
- 双检测器降级链（main -> rule -> tagged pass）
- 能讨论：fail-closed 对可用性的冲击评估、打标内容的回补扫描流程
