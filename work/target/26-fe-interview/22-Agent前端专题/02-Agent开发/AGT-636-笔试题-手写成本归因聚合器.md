## AGT-636：手写 costReport：span 成本聚合、缓存节省、多维度 groupBy、快照单价

**需求与边界**：
- 实现 costReport(spans, dims)：输出按任意维度组合的成本报表。
- 边界要求：① 成本只在 llm/api 类 span 计量，其他 span 归零；② 缓存命中记 saved 不记 gross（净成本=毛-省）；③ 单价按调用时刻快照（span 带 priceSnapshot）；④ dims 无效键抛错，空集返回零报表。

**答**：
```javascript
function costReport(spans, dims) {
  for (const d of dims)
    if (!spans.every(s => d in s.tags) && !spans.every(s => d in s.attrs))
      throw new Error('BAD_DIM: ' + d);          // 维度校验
  const rows = new Map();
  for (const s of spans) {
    const kind = s.attrs.kind ?? 'tool';
    const gross = kind === 'llm' || kind === 'api' ? s.attrs['cost.usd'] ?? 0 : 0;
    const saved = s.attrs['cost.saved'] ?? 0;
    const key = dims.map(d => s.tags[d] ?? s.attrs[d]).join('|');
    const r = rows.get(key) ?? { gross: 0, saved: 0, n: 0 };
    r.gross += gross; r.saved += saved; r.n++;
    rows.set(key, r);
  }
  return [...rows.entries()].map(([k, r]) => {
    const [dVals, rest] = split(k, dims.length);
    return { ...Object.fromEntries(dims.map((d, i) => [d, dVals[i]])),
      ...r, net: r.gross - r.saved };            // 净成本
  });
}
function split(key, n) { const p = key.split('|');
  return [p.slice(0, n), p.slice(n)]; }
```

**评分点**:
- 计量边界正确（仅 llm/api 计成本，其他归零）；缓存 saved 独立统计并算净成本。
- 维度缺失显式抛错（防静默错报表）。
- 单价快照在 span attrs（历史账不随调价变化）。
