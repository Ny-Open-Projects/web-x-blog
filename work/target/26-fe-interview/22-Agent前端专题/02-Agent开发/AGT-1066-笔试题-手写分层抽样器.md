## 1066：笔试手写：实现分层抽样（配额保底）

**答**：实现 stratified(items, key, n)：按 key 分层抽 n 条；规则：每层至少 2 条（若层内 ≥2）；剩余名额按各层占比分配；层内随机抽（用传入的 rand 或 Math.random）；层数 ×2 > n 时每层抽 min(2, 层大小)。返回被抽中的样本。

```js
function shuffle(a, rand = Math.random) {
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rand() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}
function stratified(items, key, n, rand = Math.random) {
  const groups = {};
  for (const it of items) (groups[it[key]] ??= []).push(it);
  const keys = Object.keys(groups);
  const floor = keys.length * 2 > n ? 1 : 2;         // 保底数
  const picked = [];
  let used = 0;
  for (const k of keys) {
    const take = Math.min(floor, groups[k].length);
    picked.push(...shuffle([...groups[k]], rand).slice(0, take));
    used += take;
  }
  // 剩余名额按占比分配
  let rest = n - used;
  for (const k of shuffle(keys, rand)) {
    if (rest <= 0) break;
    const quota = Math.min(groups[k].length - floor, Math.ceil(rest * groups[k].length / items.length));
    const extra = shuffle([...groups[k]], rand).slice(floor, floor + Math.max(0, quota));
    picked.push(...extra); rest -= extra.length;
  }
  return picked;
}
```

**评分点**：
- 保底逻辑正确且处理「层数过多」退化（floor=1）
- 层内 shuffle 不修改原数组（拷贝）
- 剩余配额按占比、不超过层剩余量
- 能讨论：rand 注入使测试可复现、占比分配的舍入误差处理（最后一批兜底补齐）
