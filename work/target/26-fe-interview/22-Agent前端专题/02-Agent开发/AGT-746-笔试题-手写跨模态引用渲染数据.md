## AGT-746：手写 buildCite：图片bbox/视频时间戳/表行级三类引用的数据结构与跳转协议

**需求与边界**：
- 实现 buildCite(hit)：把检索命中转为标准引用对象。
- 边界要求：① 三类模态各自字段齐全（image: page+bbox+thumbUrl；video: t0/t1+keyFrame；table: row/col 范围）；② bbox 必须在页面范围内（越界 clamp）；③ 权限校验字段带（canView 由调用方传入校验函数）；④ 缺失必要字段抛错（不生成残缺引用）。

**答**：
```javascript
function buildCite(hit, { canView }) {
  const base = { id: hit.id, docId: hit.docId, kind: hit.kind };
  if (!canView(base)) return { ...base, denied: true };  // 无权限引用
  switch (hit.kind) {
    case 'image': {
      const bbox = clampBbox(hit.bbox, hit.pageSize);
      if (!hit.thumbUrl || !bbox) throw new Error('CITE_INCOMPLETE');
      return { ...base, page: hit.page, bbox,
        thumbUrl: hit.thumbUrl, hiUrl: hit.hiUrl };
    }
    case 'video': {
      if (hit.t0 == null || hit.t1 == null) throw new Error('CITE_INCOMPLETE');
      return { ...base, t0: hit.t0, t1: hit.t1,
        keyFrame: hit.keyFrameUrl };
    }
    case 'table': {
      if (!hit.ref?.tableId) throw new Error('CITE_INCOMPLETE');
      return { ...base, tableId: hit.ref.tableId,
        row: hit.ref.row, col: hit.ref.col };
    }
    default:
      return { ...base, text: hit.snippet, page: hit.page };
  }
}
function clampBbox(bbox, page) {
  return {
    x: Math.min(Math.max(bbox.x, 0), page.w),
    y: Math.min(Math.max(bbox.y, 0), page.h),
    w: Math.min(bbox.w, page.w - Math.max(bbox.x, 0)),
    h: Math.min(bbox.h, page.h - Math.max(bbox.y, 0)),
  };
}
```

**评分点**:
- 三类模态字段完整且缺字段抛错（不生成残缺引用）。
- bbox clamp 越界保护（渲染层安全）；无权限返回 denied 引用而非泄漏内容。
- 统一 base 结构（前端单组件可分发渲染）。
