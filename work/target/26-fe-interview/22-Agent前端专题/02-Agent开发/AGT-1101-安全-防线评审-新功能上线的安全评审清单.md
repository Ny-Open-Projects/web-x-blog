## 1101：Agent 新功能上线的安全评审清单该有哪些项

**答**：
- 清单八项：新增攻击面（新输入源？）、权限变化（新工具/白名单变更？）、数据流（新数据出界路径？）、注入暴露（新内容进上下文？）、输出风险（新输出渠道？）、第三方（新依赖/模型？）、降级安全（新防线的降级是 fail-closed 吗）、可观测（新风险有监控与审计吗）。
- 评审分级：低风险项自查打勾、中风险安全同事复核、高风险（权限/数据流变化）评审会过——清单的目的是「让讨论有起点」而不是形式。
- 评审产物：风险项转工单，未闭环不上线；清单版本化管理，随防线演进更新。
- 追问钩子：怎么避免评审流于打勾？——「反向提问」环节：评审人必须找出「这个功能的攻击者视角故事」（谁、通过什么、达到什么危害），讲不出故事说明没想透。

```ts
const checklist = [
  'new_input_source', 'permission_change', 'data_egress',
  'injection_surface', 'output_channel', 'third_party_dep',
  'fail_closed_on_degrade', 'audit_and_monitor',
];
function review(feature) {
  const risks = checklist.filter(item => feature.touches(item));
  const story = attackerStory(feature);          // 反向提问：攻击者视角
  return { level: risks.length > 2 ? 'high' : risks.length ? 'mid' : 'low',
    risks, story, blockers: risks.filter(r => !mitigated(r)) };
}
```
