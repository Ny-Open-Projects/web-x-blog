## 1170：笔试手写：实现答案过期预警（三信号聚合）

**答**：实现 staleCheck(ans, ctx)：ans = { cites: [{ docId, ver, reviewedAt }], negRate }；ctx = { superseded: Set, conflicts: number, negTrend: number（7 日负反馈率日环比均值） }。规则：引用文档在 superseded 集或 reviewedAt 超 180 天 → source 信号；conflicts > 0 → consistency 信号；negTrend > 0.02 → behavior 信号。输出 { signals: [...], action }（0 信号 'ok'；1 个 'ticket'；≥2 'auto_regen'）。

```js
const DAY = 86400000;
function staleCheck(ans, ctx) {
  const signals = [];
  const staleDoc = ans.cites.some(c =>
    ctx.superseded.has(c.docId) ||
    Date.now() - new Date(c.reviewedAt).getTime() > 180 * DAY);
  if (staleDoc) signals.push('source');
  if (ctx.conflicts > 0) signals.push('consistency');
  if (ctx.negTrend > 0.02) signals.push('behavior');
  return { signals,
    action: signals.length === 0 ? 'ok' : signals.length === 1 ? 'ticket' : 'auto_regen' };
}
const ctx = { superseded: new Set(['d2']), conflicts: 1, negTrend: 0.03 };
console.log(staleCheck({ cites: [{ docId: 'd2', ver: 1, reviewedAt: '2026-01-01' }],
  negRate: 0.1 }, ctx));
// { signals: ['source', 'consistency', 'behavior'], action: 'auto_regen' }
```

**评分点**：
- 三信号判定独立且规则清晰（source 含双条件：被替代或审校过期）
- 聚合动作分级正确（信号数决定处置强度）
- 日期解析与毫秒换算正确
- 能讨论：多信号触发的置信度更高所以允许自动重生成、单信号可能误报走人工、negTrend 阈值应随流量归一化
