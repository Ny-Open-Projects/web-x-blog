## AGT-897：手写 a11yRoute：机械可修清单、语义问题转人工、critical门禁、自动标注待确认

**需求与边界**：
- 实现 a11yRoute(issues, { fixable, needsHuman })。
- 边界要求：① issues 按 axe id 路由：fixable 清单内自动补丁（标注 auto-generated），needsHuman 转人工带原因；② critical 且不可自动修的进合并门禁（阻断）；③ 自动补丁不直接合（进待确认队列）；④ 同一 issue 重复出现合并计数；⑤ 输出三桶结构。

**答**：
```javascript
function a11yRoute(issues, { fixable, needsHuman }) {
  const buckets = { auto: [], human: [], gate: [] };
  const seen = new Map();
  for (const i of issues) {
    const k = i.id + i.node;
    if (seen.has(k)) { seen.get(k).count++; continue; }  // 合并计数
    const rec = { ...i, count: 1 }; seen.set(k, rec);
    if (fixable.has(i.id))
      buckets.auto.push({ ...rec, patch: aiPatch(i),
        mark: 'auto-generated-await-confirm' });   // 待确认队列
    else if (i.impact === 'critical')
      buckets.gate.push(rec);                      // critical阻断
    else
      buckets.human.push({ ...rec,
        why: needsHuman[i.id] ?? '语义判断需人工' });
  }
  return { ...buckets,
    gateBlocked: buckets.gate.length > 0 };        // 门禁判定
}
```

**评分点**:
- 三桶路由清晰（自动/人工/门禁）；critical 不可自动修才阻断（不滥阻断）。
- 自动补丁带待确认标注（不直接合）；重复 issue 合并计数。
- 人工项带原因（why 可解释）。
