## 906：笔试手写：实现按 Markdown 标题层级感知的分块器

**答**：输入 Markdown 字符串，按 `#`/`##`/`###` 标题切分为 chunk；每个 chunk 携带「标题路径」（如 `指南 > 安装 > 依赖`）；无标题的连续段落并入上一个 chunk；单 chunk 超过 maxLen（字符数）时在段落边界硬切。返回 chunk 数组。

```js
/**
 * @param {string} md
 * @param {number} maxLen
 * @returns {{path: string, text: string}[]}
 */
function chunkMarkdown(md, maxLen = 800) {
  const out = [];
  let path = [], buf = [], len = 0;
  const flush = () => {
    if (buf.length) { out.push({ path: path.join(' > ') || 'root', text: buf.join('\n') }); buf = []; len = 0; }
  };
  for (const line of md.split('\n')) {
    const m = line.match(/^(#{1,3})\s+(.+)/);
    if (m) {
      flush();                                    // 新标题 = 新 chunk 边界
      const level = m[1].length;
      path = path.slice(0, level - 1);            // 回退到父级
      path[level - 1] = m[2].trim();              // 覆盖/追加当前层级
      buf.push(line); len = line.length;          // 标题行保留在本 chunk
      continue;
    }
    if (len + line.length > maxLen && len > 0) flush(); // 超长在段落边界硬切
    buf.push(line); len += line.length + 1;
  }
  flush();
  return out;
}
console.log(chunkMarkdown('# A\n## B\ntext1\ntext2\n### C\ntext3').map(c => c.path));
// ['A > B', 'A > B > C']
```

**评分点**：
- 标题路径回退逻辑正确：`###` 出现时截断同级及以下，不能把上一个大章节的标题残留进路径
- flush 的调用时机：遇标题、超长、结尾三处，漏结尾会丢最后一个 chunk
- 超长硬切在段落边界而非字符中间
- 空输入 / 无标题输入返回 root 路径且不崩
