## AGT-643：手写 cacheHealth：命中率/收益/误命中、样本抓取、阈值建议、版本分段

**需求与边界**：
- 实现 cacheHealth(records)：records 每条含 { fromCache, savedUsd, regen, dislike, cacheVer }。
- 边界要求：① 命中率=命中/总数（除零保护）；② 误命中率=命中后 regen 或 dislike 占命中数，>5% 建议抬阈值；③ savedUsd 求和；④ 按 cacheVer 分段输出（embedding 升级后旧版本单独看）；⑤ 误命中样本列表（最多 10 条，供归因）。

**答**：
```javascript
function cacheHealth(records) {
  const total = records.length;
  const hit = records.filter(r => r.fromCache);
  const bad = hit.filter(r => r.regen || r.dislike);   // 误命中
  const base = {
    total,
    hitRate: total ? hit.length / total : 0,
    savedUsd: round2(hit.reduce((a, r) => a + (r.savedUsd ?? 0), 0)),
    falseHitRate: hit.length ? bad.length / hit.length : 0,
  };
  const action = base.falseHitRate > 0.05 ? 'raise_threshold'
    : base.hitRate < 0.1 ? 'lower_threshold' : null;
  const byVer = groupBy(records, 'cacheVer');
  return { ...base, action,
    byVer: Object.fromEntries(Object.entries(byVer)
      .map(([v, rs]) => [v, cacheHealth(rs)])),       // 版本分段
    badSamples: bad.slice(0, 10).map(r => ({
      q: r.query, sim: r.similarity, verdict: r.regen ? 'regen' : 'dislike' })),
  };
}
```

**评分点**:
- 三指标齐全（命中率/收益/误命中）且除零保护。
- 误命中 >5% 触发抬阈值建议（语义缓存健康红线），低命中率反向建议。
- 版本分段 + 误命中样本（含相似度，可归因阈值问题）。
