## AGT-650：手写 auditMaturity：三阶段清单、缺失项、优先级建议、阻塞关系

**需求与边界**：
- 实现 auditMaturity(capabilities)。
- 边界要求：① 三阶段清单（trace 基建/大盘决策/闭环迭代），逐项判定 done；② 阶段阻塞：P2 完成率依赖 P1（P1 未达 80% 时 P2 项标记 blocked）；③ 输出下一步建议（优先补低阶段缺失项）；④ 全部完成输出 next（进阶方向）。

**答**：
```javascript
const PHASES = {
  p1: { items: ['traceId贯穿', 'llmSpan', 'toolSpan', 'usage计量'],
        requires: null },
  p2: { items: ['大盘', '失败聚类', '负反馈回流'], requires: 'p1@0.8' },
  p3: { items: ['质量告警', '灰度看板', '回流评测集', '回放调试'],
        requires: 'p2@0.8' },
};
function auditMaturity(capabilities) {
  const report = {};
  for (const [p, cfg] of Object.entries(PHASES)) {
    const done = cfg.items.filter(i => capabilities.includes(i));
    const blocked = cfg.requires && !requireMet(cfg.requires, report);
    report[p] = { done: done.length, total: cfg.items.length,
      missing: cfg.items.filter(i => !done.includes(i)),
      blocked };                                 // 上游未达标则阻塞
  }
  const firstGap = ['p1', 'p2', 'p3'].find(p =>
    report[p].missing.length || report[p].blocked);
  return { ...report,
    next: firstGap
      ? `优先补齐 ${firstGap}: ${report[firstGap].missing.join('/')}`
      : '全链路就绪，可投入自动归因与成本寻优' };
}
function requireMet(req, report) {
  const [p, th] = req.split('@');
  return report[p] && report[p].done / report[p].total >= +th;
}
```

**评分点**:
- 三阶段清单与完成率统计；阶段阻塞依赖正确（P1 达 80% 才解锁 P2）。
- 下一步建议指向最低缺失阶段（建设顺序不倒置）。
- 全部就绪给出进阶方向（可行动收束）。
