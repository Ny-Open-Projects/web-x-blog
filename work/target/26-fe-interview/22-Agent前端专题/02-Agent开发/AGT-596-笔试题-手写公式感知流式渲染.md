## AGT-596：手写 FormulaStream：定界符跨chunk、闭合才渲染、缓存、失败降级

**需求与边界**：
- 实现 FormulaStream：push(delta) 输出 { safeText, pending }，完成时 flush 返回全文。
- 边界要求：① $$...$$ 闭合才渲染 KaTeX，未闭合进 pending（原样展示）；② 定界符跨 delta（$$ 分在两段）能正确识别（在合并缓冲上扫描）；③ 同一公式内容渲染缓存（hash 键）；④ KaTeX 抛错降级为原文等宽展示；⑤ flush 后无残留 pending。

**答**：
```javascript
class FormulaStream {
  constructor() { this.buf = ''; this.cache = new Map(); this.out = ''; }
  push(delta) {
    this.buf += delta;
    // 在合并缓冲上反复扫描闭合公式
    let m;
    while ((m = /\$\$([\s\S]+?)\$\$/.exec(this.buf))) {
      this.out += this.buf.slice(0, m.index);    // 公式前的安全文本
      this.out += this.renderTex(m[1]);
      this.buf = this.buf.slice(m.index + m[0].length);
    }
    // 无未闭合 $$ 残留时输出安全文本
    const lastDollar = this.buf.lastIndexOf('$$');
    if (lastDollar === -1) { this.out += this.buf; this.buf = ''; }
    return { safe: this.out, pending: this.buf };
  }
  renderTex(tex) {
    const key = hash(tex);
    if (!this.cache.has(key)) {
      try { this.cache.set(key, katex.renderToString(tex)); }
      catch { this.cache.set(key, `<code>${escapeHtml(tex)}</code>`); } // 降级
    }
    return this.cache.get(key);
  }
  flush() { this.out += this.buf; this.buf = ''; return this.out; }
}
```

**评分点**:
- 合并缓冲上扫描（跨 chunk 定界符正确）；while 循环处理一段内多个公式。
- 缓存按内容 hash；渲染失败降级为转义原文（不白屏不注入）。
- flush 吸收残留 pending（保证最终全文完整）。
