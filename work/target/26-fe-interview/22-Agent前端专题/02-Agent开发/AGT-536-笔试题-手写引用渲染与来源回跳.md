## AGT-536：手写引用解析器：角标替换、无来源丢弃、去重编号、HTML 转义

**需求与边界**：
- 输入：模型文本（含 [^n] 标记）+ sources 数组；输出：安全的 HTML 字符串。
- 边界要求：① 引用号超出 sources 范围直接丢弃（防幻觉引用）；② 同一来源多次引用合并编号；③ 来源 title 与片段需 HTML 转义防注入；④ 文本本身要先转义再插引用。

**答**：
```javascript
function esc(s) {
  return s.replace(/[&<>"']/g, c =>
    ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' }[c]));
}
function renderCitations(text, sources) {
  const map = new Map();               // sourceId → 编号（去重）
  sources.forEach((s, i) => map.set(s.id, i + 1));
  const body = esc(text).replace(/\[\^(\d+)\]/g, (_, n) => {
    const src = sources[+n - 1];
    return src ? `<sup class="cite" data-id="${esc(src.id)}" `
      + `title="${esc(src.docName)}">[${map.get(src.id)}]</sup>` : '';
  });
  const list = [...map.entries()].map(([id, num]) => {
    const s = sources.find(x => x.id === id);
    return `<li data-id="${esc(id)}"><b>[${num}]</b> `
      + `${esc(s.docName)}：${esc(s.snippet.slice(0, 120))}…</li>`;
  });
  return `<div class="answer">${body}</div><ol class="sources">${list.join('')}</ol>`;
}
```

**评分点**:
- 先转义文本再插引用（防 XSS），title/snippet 全部转义。
- 引用号越界丢弃防幻觉；同来源去重编号一致。
- 输出含来源列表且片段截断，防超长来源撑爆布局。
