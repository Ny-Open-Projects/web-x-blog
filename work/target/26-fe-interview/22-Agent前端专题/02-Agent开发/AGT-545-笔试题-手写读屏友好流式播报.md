## AGT-545：手写 A11yStreamer：流式静默、完成整段播报、reduced-motion、进度文本

**需求与边界**：
- 实现 A11yStreamer：包装流事件，驱动 aria-live 区域。
- 边界要求：① 流式期间 live 区域保持 busy 且不播报 delta；② 完成（done）一次性播报全文（超 1000 字播报摘要+提示）；③ 尊重 prefers-reduced-motion（不发打字机光标动画标志）；④ 中断（abort）播报"生成已停止，已保留前 N 字"。

**答**：
```javascript
class A11yStreamer {
  constructor() {
    this.mq = matchMedia('(prefers-reduced-motion: reduce)');
    this.chars = 0;
  }
  onDelta(delta) {
    this.chars += delta.length;
    live.set({ busy: true, text: '' });       // 流式静默，只标记忙
  }
  onDone(full) {
    const text = full.length > 1000
      ? summarize(full) + '（全文较长，可在正文中阅读）' : full;
    live.set({ busy: false, text });           // 完成后整段播报
  }
  onAbort() {
    live.set({ busy: false,
      text: `生成已停止，已保留前 ${this.chars} 字内容` });
  }
  cursorProps() {
    return { 'aria-hidden': true,               // 装饰性光标对读屏隐藏
      'data-reduced': this.mq.matches ? '1' : '0' };
  }
}
```

**评分点**:
- 流式静默/完成整段播报的核心策略正确（逐 token 播报是灾难）。
- 超长文本播摘要而非刷屏；abort 有内容保留的文本等价物。
- 光标 aria-hidden 且响应 reduced-motion。
