## AGT-786：手写 resolveConflict：显式覆盖/隐式观察/证据计数、存档不删除、时效衰减

**需求与边界**：
- 实现 MemoryStore：upsert(stmt, source)/resolveConflicts(stmt)/decay()。
- 边界要求：① source.type=explicit 时旧冲突记忆降级 archived（不删除，存档带原因）；② implicit 时写入候选池，evidence>=3 才提议覆盖；③ 记忆带 confirmedAt，超 180 天未确认自动降权（weight*0.5）；④ 无冲突直接写。

**答**：
```javascript
class MemoryStore {
  constructor() { this.facts = new Map(); this.candidates = new Map(); }
  async upsert(stmt, source) {
    const conflicts = [...this.facts.values()]
      .filter(f => contradicts(f.statement, stmt));
    if (source.type === 'explicit') {
      for (const c of conflicts) {
        c.status = 'archived';                      // 存档不删
        c.archivedBy = stmt; c.at = Date.now();
      }
      const f = { id: genId(), statement: stmt, confirmedAt: Date.now(),
        weight: 1, evidence: 1 };
      this.facts.set(f.id, f);
      return { action: 'overwrite', archived: conflicts.length };
    }
    const key = hash(stmt);
    const c = this.candidates.get(key)
      ?? { statement: stmt, evidence: 0, conflicts };
    c.evidence++;
    this.candidates.set(key, c);
    if (c.evidence >= 3)
      return { action: 'propose', conflicts };      // 攒证据才提议
    return { action: 'observed', evidence: c.evidence };
  }
  decay() {                                         // 时效衰减
    for (const f of this.facts.values())
      if (Date.now() - f.confirmedAt > 180 * 864e5 && !f.reconfirmed)
        f.weight *= 0.5;
  }
}
```

**评分点**:
- 显式立即覆盖且旧记忆存档（不删除，可回溯）；隐式走证据池（>=3 才提议）。
- 时效衰减针对未确认记忆（weight 减半而非删除）。
- 状态字段完整（status/archivedBy/confirmedAt）。
