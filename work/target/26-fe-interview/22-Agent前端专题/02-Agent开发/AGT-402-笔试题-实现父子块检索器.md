## AGT-402：手写父子块检索：子块召回、父块返回、去重与 ACL 过滤

**需求与边界**：
- 输入：query、索引（children 数组含 {id, parentId, text, acl}，parents Map）、用户 ACL、k；输出：父块数组（按最佳子块分数排序、去重、权限过滤）。
- 边界要求：① 召回后先 ACL 过滤再排序（防越权泄露）；② 同父多子只保留父块一次；③ 父块缺失降级返回子块；④ 过滤后不足 k 不放宽权限。

**答**：
```javascript
function retrieve({ queryEmbedding, children, parents, userAcl, k = 5 }) {
  // 1. 召回 top 3k 子块（余弦相似度）
  const scored = children
    .filter(c => c.acl.every(t => userAcl.includes(t)))  // 先过滤（硬权限）
    .map(c => ({ ...c, score: cosine(queryEmbedding, c.embedding) }))
    .sort((a, b) => b.score - a.score)
    .slice(0, k * 3);
  // 2. 子块 → 父块，同父取最高子分，去重
  const byParent = new Map();
  for (const c of scored) {
    const best = byParent.get(c.parentId);
    if (!best || c.score > best.score) byParent.set(c.parentId, c);
  }
  // 3. 父块组装，缺失降级用子块
  const results = [...byParent.values()]
    .sort((a, b) => b.score - a.score)
    .slice(0, k)
    .map(c => {
      const p = parents.get(c.parentId);
      return p
        ? { id: p.id, text: p.text, source: c.parentId,
            acl: p.acl ?? c.acl, score: c.score }
        : { id: c.id, text: c.text, source: c.parentId,
            acl: c.acl, score: c.score, degraded: true };  // 降级标注
    });
  // 4. 父块 ACL 终检（防父块 ACL 与子块不一致的索引错误）
  return results.filter(r => r.acl.every(t => userAcl.includes(t)));
}
function cosine(a, b) {
  let d = 0, na = 0, nb = 0;
  for (let i = 0; i < a.length; i++) { d += a[i]*b[i]; na += a[i]**2; nb += b[i]**2; }
  return d / (Math.sqrt(na) * Math.sqrt(nb) || 1);
}
```

**评分点**:
- 召回前先 ACL 硬过滤（权限前置），父块结果再做终检（防御索引 ACL 不一致的错配）。
- 同父去重取最高子分、排序正确；父块缺失有降级路径且带 degraded 标注。
- 权限不足时不放宽 ACL（返回少于 k 是正确行为）。
- 余弦实现含零向量除零保护。
