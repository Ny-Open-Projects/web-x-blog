## 979：多个 Agent 共享下游配额，限流怎么设计

**答**：
- 分层限流：全局层（供应商总 QPS/TPM 配额）+ 任务层（单任务并发上限）+ Agent 层（按重要级分配权重），防止一个失控循环吃光全局配额。
- 令牌桶 + 优先级抢占：用户交互请求优先级高于后台批处理，配额紧张时后台任务让路而不是用户请求排队。
- 配额耗尽的优雅降级：排队（可预期）> 降档模型（质量换速度）> 拒绝并明确告知（比超时强）。
- 追问钩子：怎么发现「失控循环」？——单任务 token 消耗速率监控，速率连续超阈值自动熔断该任务，这是最贵的故障模式。

```ts
class TokenBucket {
  constructor(cap, rate) { this.tok = cap; this.rate = rate; this.last = Date.now(); }
  take(n, priority) {
    this.refill();
    if (this.tok < n) {
      if (priority === 'batch') throw new Deferral();  // 后台任务让路
      return this.enqueue(n);                          // 交互请求排队
    }
    this.tok -= n; return true;
  }
}
// 单任务 token 速率熔断
```
