## AGT-652：评测结论新版好 2%，怎么判断这不是噪声（样本量/显著性/功效）

**答**：
- 先算最小样本量：检出 2% 的差异需要多少用例（效应量+显著性水平+功效三要素），样本不够的对比不要下结论，只说"方向性信号"。
- 二分类指标（通过/失败）用比例检验；连续指标（judge 分数）用 t 检验或 bootstrap 置信区间；配对设计（同一用例跑新旧两版）比独立样本功效高得多——优先配对。
- 多指标对比要防多重比较：跑 20 个指标总有几个"显著"，Bonferroni 或主指标预注册（只对主指标下结论）。

```javascript
function minSample(p1, delta, { alpha = 0.05, power = 0.8 } = {}) {
  const p2 = p1 + delta;
  const zA = 1.96, zB = 0.84;                   // alpha/power 对应 z 值
  return Math.ceil(
    (zA * Math.sqrt(p1 * (1 - p1)) + zB * Math.sqrt(p2 * (1 - p2))) ** 2
    / delta ** 2);
}
// 配对设计：同用例双跑，只统计不一致子集
function pairedTest(cases, oldV, newV) {
  const diff = cases.filter(c => c[oldV] !== c[newV]);
  const wins = diff.filter(c => c[newV]).length;
  return binomPValue(wins, diff.length);        // 二项检验
}
```
