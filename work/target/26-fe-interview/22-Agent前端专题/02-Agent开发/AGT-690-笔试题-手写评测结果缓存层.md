## AGT-690：手写 evalCache：三层键（用例+参数+模型版本）、版本失效、命中率统计

**需求与边界**：
- 实现 EvalCache：get/set/invalidations/hitStats。
- 边界要求：① 键 = hash(用例id + 输入内容 + 参数 + 模型版本 + judge版本)；② 任一版本变化自动失效（不命中旧键）；③ 命中结果带 cachedAt 与来源标记；④ 命中率按层统计（用例级/检索级）；⑤ 主动失效接口（知识库更新时）。

**答**：
```javascript
class EvalCache {
  constructor(store) { this.store = store; this.stats = { hit: 0, miss: 0 }; }
  key(c, ctx) {
    return hash([c.id, JSON.stringify(c.input), JSON.stringify(c.params),
      ctx.modelVer, ctx.judgeVer].join('|'));      // 全版本进键
  }
  async get(c, ctx) {
    const v = await this.store.get(this.key(c, ctx));
    if (v) this.stats.hit++; else this.stats.miss++;
    return v ? { ...v, cachedAt: v.at, fromCache: true } : null;
  }
  async set(c, ctx, result) {
    await this.store.set(this.key(c, ctx),
      { ...result, modelVer: ctx.modelVer, judgeVer: ctx.judgeVer,
        at: Date.now() });
  }
  invalidateBy(pred) {                             // 主动失效
    return this.store.deleteWhere(pred);           // 如 kbVer 变化
  }
  hitStats() {
    const { hit, miss } = this.stats;
    return { hitRate: hit / (hit + miss || 1),
      savedEstUsd: hit * COST_PER_EVAL };          // 缓存省钱量化
  }
}
```

**评分点**:
- 键含全版本三元组（模型/judge/参数），版本变化自然失效。
- 命中率统计与省钱量化（缓存收益可见）。
- 主动失效接口（知识库更新场景）。
