## AGT-587：手写 ParallelProgress：完成数聚合、部分失败状态、慢任务展开、快任务折叠

**需求与边界**：
- 实现 parallelProgress(calls, { slowMs = 1000 })：输出聚合视图数据。
- 边界要求：① 聚合文本区分全成/部分失败/全败；② 展开列表只含未完成或耗时 > slowMs 的项（快任务折叠进摘要）；③ 全部终态时触发 onComplete（含失败也触发）；④ 支持 cancelAll 级联取消。

**答**：
```javascript
class ParallelProgress {
  constructor(calls, { slowMs = 1000 } = {}) {
    this.calls = calls; this.slowMs = slowMs; this.done = new Set();
    calls.forEach(c => c.on('settle', (r) => this.onSettle(c, r)));
  }
  onSettle(c, r) {
    c.status = r.ok ? 'ok' : 'error';
    this.done.add(c.id);
    if (this.done.size === this.calls.length)
      this.onComplete?.(this.snapshot());       // 全终态（含失败）触发
  }
  snapshot() {
    const ok = this.calls.filter(c => c.status === 'ok').length;
    const err = this.calls.filter(c => c.status === 'error').length;
    const running = this.calls.filter(c => !c.status);
    const expanded = [...running,
      ...this.calls.filter(c => c.status === 'error'
        || (c.elapsed ?? 0) > this.slowMs)];    // 只展开慢与失败
    const text = err === 0 && running.length === 0
      ? `${ok}/${this.calls.length} 完成`
      : err > 0 ? `${ok}/${this.calls.length} 完成，${err} 失败`
      : `${ok}/${this.calls.length} 完成，进行中 ${running.length}`;
    return { ok, err, running: running.length, text, expanded };
  }
  async cancelAll(reason) {
    await Promise.allSettled(this.calls
      .filter(c => !c.status).map(c => c.cancel(reason)));  // 级联取消
  }
}
```

**评分点**:
- 全终态判定（含失败）才触发 onComplete，不漏报。
- 展开列表过滤规则明确（未完成 + 失败 + 慢任务），快任务折叠防闪跳。
- cancelAll 用 allSettled 级联（单个取消失败不影响其他）。
