## AGT-744：手写 visionFallback：熔断状态检查、缓存→OCR→拒答三级、降级标记与记账

**需求与边界**：
- 实现 visionFallback(img, task, deps)。
- 边界要求：① 熔断打开时按 缓存→OCR→拒答 三级降级；② 每级输出带 degraded 标记与级别（供 UI 提示）；③ 降级请求记账（级别计数，容量规划输入）；④ OCR 兜底仅当任务需要文字（task.needsText），否则直接拒答；⑤ 半开状态允许一次试探。

**答**：
```javascript
async function visionFallback(img, task, { circuit, cache, ocr, meter }) {
  if (circuit.state === 'open') {
    const cached = await cache.get(`desc:${await contentHash(img)}`);
    if (cached) return mark(cached, 'cache');       // 一级：缓存
    if (task.needsText) {                           // 二级：OCR
      const t = await ocr(img);
      meter.count('vision.fallback', { level: 'ocr' });
      return mark({ text: t.text }, 'ocr',
        { note: '图片理解降级，仅提取文字' });
    }
    meter.count('vision.fallback', { level: 'reject' });
    return mark(null, 'reject',
      { note: '图片理解暂不可用，文字问答不受影响' });  // 三级
  }
  if (circuit.state === 'half-open') circuit.probeLimit(1); // 限试探
  try {
    const out = await vision(img, task.prompt);
    circuit.success();
    return mark(out, 'primary');
  } catch (e) {
    circuit.failure();
    return visionFallback(img, task, { circuit, cache, ocr, meter });
  }
}
function mark(out, level, extra = {}) {
  return { ...out, degraded: level !== 'primary', level, ...extra };
}
```

**评分点**:
- 三级降级语义完整且每级带标记（UI 可提示）；needsText 门控 OCR 兜底。
- 半开限一次试探（防雪崩）；递归降级只在主链路失败时。
- 降级记账（容量规划输入）。
