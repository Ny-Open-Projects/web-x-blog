## AGT-622：会话回放/重跑功能涉及用户数据，合规上要过哪些关

**答**：
- 三道关：授权关（回放仅限用户自己或用户授权的客服/开发者，内部调试用脱敏副本）、用途关（重跑生成的内容不写回用户会话、不用于训练除非单独授权）、留存关（回放记录带 TTL 与访问审计）。
- 脱敏副本的保真权衡：脱敏后重跑结果会与原始不同（脱敏改变了输入），要明示"这是基于脱敏输入的近似重放"。
- 跨境与租户隔离：租户数据不出租户边界（回放服务按租户分域），跨境数据走合规通道。

```javascript
async function compliantReplay(turnId, actor) {
  const turn = await getTurn(turnId);
  assert(actor.canView(turn.owner));             // 授权关
  const masked = redact(turn, { preserve: 'semantics' });
  const out = await shadowLLM(masked.input);     // 用途关：影子环境
  audit.log({ actor: actor.id, turnId, action: 'replay',
    ttl: 7 * 864e5 });                           // 留存关
  return { approx: true, out,   // 明示近似重放
    note: '基于脱敏输入的近似重放，与原始输出可能存在差异' };
}
```
