## AGT-648：手写 dynamicSample：错误/高成本全采、灰度全采、常态动态调节、预算收紧

**需求与边界**：
- 实现 SamplingController：decide(turn) 返回采样率决策。
- 边界要求：① 错误/成本>P95/灰度实验 → 1.0；② 常态基础率 0.1，预算超 5% 自动降到 0.02；③ 高成本阈值随 P95 动态（滑动窗口）；④ 决策结果记录 reason（可审计为什么被采/被丢）。

**答**：
```javascript
class SamplingController {
  constructor({ base = 0.1, tightened = 0.02 } = {}) {
    this.base = base; this.tightened = tightened;
    this.costP95 = 0; this.tight = false;
  }
  updateCostP95(hist) { this.costP95 = percentile(hist, 0.95); }
  tighten(on) { this.tight = on; }                // 预算超限联动
  decide(turn) {
    let rate = this.tight ? this.tightened : this.base;
    let reason = this.tight ? 'budget_tightened' : 'base';
    if (turn.errCode) { rate = 1.0; reason = 'error'; }
    else if (this.costP95 && turn.cost > this.costP95) {
      rate = 1.0; reason = 'cost_outlier'; }
    else if (turn.expGroup) { rate = 1.0; reason = 'canary'; }
    return { rate, sample: Math.random() < rate, reason };
  }
}
// 观测成本联动
function obsCostGuard(month, ctrl) {
  if (month.obs / month.business > 0.05) ctrl.tighten(true);
  else ctrl.tighten(false);
}
```

**评分点**:
- 分级决策正确（错误/成本离群/灰度全采优先于预算收紧）。
- 成本阈值随 P95 滑动（自适应而非硬编码）；收紧仅影响常态采样（异常仍全采）。
- 每次决策带 reason 可审计。
