## AGT-788：手写 extractSlots：约束/决策/实体检测、回显确认、槽位覆盖与撤销

**需求与边界**：
- 实现 extractSlots(turn, session)。
- 边界要求：① 识别三类槽位：约束（预算/截止时间）、决策（选定方案）、实体（项目名/人名）；② 新值覆盖同 key 槽位时返回确认请求（不静默覆盖）；③ 支持 undo（撤销最近一次槽位写入）；④ 金额/日期规范化（"下周三"→具体日期）；⑤ 无槽位返回空。

**答**：
```javascript
const SLOT_PATTERNS = [
  { key: 'budget', re: /预算[:：]?\s*([\d.]+万?元?)/, norm: normMoney },
  { key: 'deadline', re: /(下周[一二三四五六日]|\d+月\d+日)/, norm: normDate },
  { key: 'decision', re: /就(用|定|选)了?([一-龥A-Za-z0-9]+)/ },
  { key: 'entity', re: /项目(?:名)?[:：]?\s*([一-龥A-Za-z0-9]+)/ },
];
function extractSlots(turn, session) {
  const out = [];
  for (const p of SLOT_PATTERNS) {
    const m = turn.text.match(p.re);
    if (!m) continue;
    const value = p.norm ? p.norm(m[1]) : m[1];
    const prev = session.slots[p.key];
    if (prev && prev.value !== value) {
      out.push({ key: p.key, value, prev,
        needConfirm: true });                      // 覆盖需确认
      continue;
    }
    session.undoStack.push({ key: p.key, prev });
    session.slots[p.key] = { value, at: Date.now(), turn: turn.id };
    out.push({ key: p.key, value, confirmed: true });
  }
  return out;
}
function undoSlot(session) {
  const last = session.undoStack.pop();
  if (!last) return null;
  if (last.prev) session.slots[last.key] = last.prev;
  else delete session.slots[last.key];             // 恢复或删除
  return last.key;
}
```

**评分点**:
- 四类槽位模式覆盖约束/决策/实体；金额日期规范化（"下周三"落具体值）。
- 覆盖需确认（needConfirm 不静默）；undo 栈恢复或删除语义正确。
- 槽位带来源轮次（可溯源）。
