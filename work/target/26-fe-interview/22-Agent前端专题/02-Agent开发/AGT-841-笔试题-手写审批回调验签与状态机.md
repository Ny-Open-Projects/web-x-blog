## AGT-841：手写 ApprovalCallback：验签、状态机同步（approved/rejected/cancelled）、重复回调幂等、超时升级

**需求与边界**：
- 实现 handleOaCallback(payload)。
- 边界要求：① 验签+时间戳窗口；② 状态机：pending→approved/rejected/cancelled，非法跃迁拒绝（如 cancelled 后又 approved）；③ 重复回调幂等（按审批单号+状态判重）；④ approved 恢复任务/rejected 终止带原因；⑤ OA 侧超时未回调触发平台侧升级（找上级）。

**答**：
```javascript
const TRANSITIONS = {
  pending: ['approved', 'rejected', 'cancelled'],
  approved: [], rejected: [], cancelled: [],
};
async function handleOaCallback(payload, sig) {
  if (!verifyWebhook(sig, JSON.stringify(payload), OA_SECRET))
    return { status: 401 };                        // 验签
  const approval = await store.get(payload.key);
  if (approval.status === payload.action)
    return { status: 200, idempotent: true };      // 幂等
  if (!TRANSITIONS[approval.status].includes(payload.action))
    return { status: 409, note: '非法状态跃迁' };   // 状态机
  await store.set(payload.key, { status: payload.action,
    by: payload.approver, at: Date.now(), memo: payload.memo });
  if (payload.action === 'approved') resumeTask(payload.key);
  else cancelTask(payload.key, `OA审批：${payload.action}`);
  return { status: 200 };
}
function onApprovalTimeout(key) {                   // 平台侧升级
  const t = task(key);
  return oaEscalate(t.approvalId, { to: t.manager,
    note: '审批超时，自动升级' });
}
```

**评分点**:
- 验签+重放窗口；状态机白名单跃迁（非法跃迁 409）。
- 幂等（同状态重复回调直接 200）；approved/rejected 分别恢复/终止任务。
- 超时升级到上级（审批链的兜底）。
