## AGT-699：手写 EvalBudget：单次预算、费用记账、超限降级、月度汇总与告警

**需求与边界**：
- 实现 EvalBudget：charge(run, owner)/check(plan)/monthly()。
- 边界要求：① 每次 CI 评测按 tokens+judge 调用计费到 owner（团队/PR）；② 单次超预算降级为抽样子集并标注 sampled；③ 月度按 owner 汇总与告警（超配额团队）；④ 预算配置可按层级（全局/团队/单次）覆盖。

**答**：
```javascript
class EvalBudget {
  constructor({ perRun = 5, teamMonthly = 200 } = {}) {
    this.perRun = perRun; this.teamMonthly = teamMonthly;
    this.ledger = [];                              // 费用台账
  }
  costOf(plan) {
    return plan.cases.reduce((a, c) =>
      a + (c.cost ?? EST_PER_CASE), 0);            // 预估费用
  }
  check(plan, owner) {
    const p = { ...plan, cost: this.costOf(plan) };
    if (p.cost > this.perRun) {                    // 单次超限降级
      p.cases = stratifiedSample(plan.cases,
        this.perRun / p.cost);
      p.sampled = true; p.cost = this.costOf(p);
    }
    return p;
  }
  charge(actual, owner, pr) {
    this.ledger.push({ owner, pr, usd: actual, at: Date.now() });
  }
  monthly() {
    const byOwner = groupBy(this.ledger, 'owner');
    const rows = Object.entries(byOwner).map(([o, ls]) =>
      ({ owner: o, usd: sum(ls, 'usd'),
        over: sum(ls, 'usd') > this.teamMonthly }));
    return { rows, alarm: rows.filter(r => r.over),
      top: maxBy(rows, 'usd') };                   // 谁在让CI变贵
  }
}
```

**评分点**:
- 计费到 owner/PR（费用归因），单次超限降级抽样并标注。
- 月度汇总含超配额告警与 top 消耗方（可行动治理）。
- 台账留痕（月度对账可复现）。
