## AGT-747：手写 judgeMultimodal：数值/引用/幻觉/语义四类判据路由、程序优先、judge兜底

**需求与边界**：
- 实现 judgeMultimodal(case, output)。
- 边界要求：① 判据路由：numeric（容差程序判）→ citation（存在性程序判+支撑性 judge）→ hallucination（陷阱用例：问图中没有的东西，检测编造）→ semantic（vision judge）；② numeric 无容差字段默认 5%；③ hallucination 命中即 0 分；④ 每条结果带 judgedBy（程序/人工/judge）与置信。

**答**：
```javascript
function judgeMultimodal(c, out) {
  switch (c.kind) {
    case 'numeric': {
      const tol = c.golden.tolerance ?? 0.05;
      const hit = Math.abs(out.value - c.golden.value)
        <= Math.abs(c.golden.value) * tol;
      return { score: hit ? 1 : 0, judgedBy: 'program' };
    }
    case 'citation': {
      const exists = out.citations.every(x => citeExists(x));
      return { score: exists && judgeSupport(out, out.citations) ? 1 : 0,
        judgedBy: exists ? 'mixed' : 'program' };
    }
    case 'hallucination':
      return { score: mentionsAny(out.answer, c.golden.absent) ? 0
        : 1, judgedBy: 'program',                 // 编造即0分
        note: mentionsAny(out.answer, c.golden.absent)
          ? '回答包含图中不存在的内容' : null };
    default:
      return { score: visionJudge(c, out), judgedBy: 'vision-judge',
        confidence: 0.7 };
  }
}
```

**评分点**:
- 四类判据路由完整且程序优先（成本可控）；numeric 默认 5% 容差。
- 幻觉陷阱用例命中即 0（一票否决式严厉）。
- judgedBy 标注（结果可信度分层，judge 结果抽样人工复核）。
