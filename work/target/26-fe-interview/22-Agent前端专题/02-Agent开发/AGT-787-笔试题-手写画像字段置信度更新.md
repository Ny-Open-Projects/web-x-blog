## AGT-787：手写 updateProfile：三来源优先级、置信度贝叶斯式更新、显式覆盖保护

**需求与边界**：
- 实现 updateProfile(profile, patch, source)。
- 边界要求：① 优先级 explicit > behavior > mined，低优先级不可覆盖高优先级字段值（只能补充 evidence）；② confidence 更新：explicit 设 1.0，behavior 每次证据 +0.15 封顶 0.9，mined +0.1 封顶 0.7；③ immutable 字段（constraints）只接受 explicit 且需二次确认标志；④ 返回变更清单。

**答**：
```javascript
const PRI = { explicit: 3, behavior: 2, mined: 1 };
const CAP = { explicit: 1, behavior: 0.9, mined: 0.7 };
function updateProfile(profile, patch, source) {
  const changes = [];
  for (const [k, v] of Object.entries(patch)) {
    const cur = profile[k] ?? { value: null, confidence: 0,
      source: null, evidence: 0 };
    const sameLevel = PRI[source.type] === PRI[cur.source];
    const higher = PRI[source.type] > (PRI[cur.source] ?? 0);
    if (cur.source === 'explicit' && source.type !== 'explicit')
      { cur.evidence++; continue; }                 // 不得覆盖显式
    if (k in CONSTRAINTS && !source.confirmed)
      throw new Error('CONSTRAINT_NEEDS_CONFIRM');
    if (higher || (sameLevel && cur.confidence < CAP[source.type])) {
      const conf = source.type === 'explicit' ? 1
        : Math.min(CAP[source.type], cur.confidence
          + (source.type === 'behavior' ? 0.15 : 0.1));
      if (cur.value !== v) changes.push({ k, from: cur.value, to: v });
      profile[k] = { value: v, confidence: conf,
        source: source.type, evidence: cur.evidence + 1 };
    }
  }
  return { profile, changes };
}
```

**评分点**:
- 优先级保护正确（显式字段低源只攒证据不覆盖）。
- 置信度分级封顶（behavior 0.9/mined 0.7，挖掘永不满信）。
- 约束类 immutable 需二次确认；变更清单返回（可审计可提示）。
