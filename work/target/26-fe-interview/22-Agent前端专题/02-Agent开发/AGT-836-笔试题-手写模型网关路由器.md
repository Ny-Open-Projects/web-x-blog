## AGT-836：手写 routeModel：能力匹配、租户合规过滤、成本优先、降级备选链

**需求与边界**：
- 实现 routeModel(req, tenant)。
- 边界要求：① 过滤条件：能力匹配（needs）∧ 租户允许清单 ∧ 健康状态；② 排序：成本优先但质量分低于阈值的剔除（成本不是唯一）；③ 返回 { model, fallbacks }（按同序的备选链）；④ 无可用模型抛 NO_ROUTE 带原因明细。

**答**：
```javascript
function routeModel(req, tenant, { minQuality = 0.7 } = {}) {
  const reasons = [];
  const pool = MODEL_CATALOG.filter(m => {
    if (!capsMatch(m, req.needs))
      { reasons.push(`${m.id}:caps`); return false; }
    if (!tenant.policy.allowedModels.includes(m.id))
      { reasons.push(`${m.id}:tenant-policy`); return false; }
    if (health(m.id) === 'down')
      { reasons.push(`${m.id}:down`); return false; }
    if (m.quality < minQuality && req.kind !== 'cheap-ok')
      { reasons.push(`${m.id}:quality`); return false; }
    return true;
  });
  if (!pool.length)
    throw Object.assign(new Error('NO_ROUTE'), { status: 503,
      detail: reasons });                          // 带原因明细
  const sorted = pool.sort((a, b) => cost(a, req) - cost(b, req));
  return { model: sorted[0].id,
    fallbacks: sorted.slice(1).map(m => m.id) };   // 备选链
}
async function sendWithFailover(req, route) {
  for (const m of [route.model, ...route.fallbacks]) {
    try { return await adapter(m).chat(req); }
    catch (e) { if (!e.retryable) throw e; }
  }
  throw new Error('ALL_ROUTES_FAILED');
}
```

**评分点**:
- 三重过滤（能力/租户/健康）+ 质量下限剔除；NO_ROUTE 带原因（可诊断）。
- 返回 fallbacks 备选链，failover 顺序与路由排序一致。
- 不可重试错误直接抛（不浪费备选）。
