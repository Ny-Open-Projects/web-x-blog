## AGT-743：手写 syncImages：内容哈希 diff、双删双索引、描述缓存失效、快照留存

**需求与边界**：
- 实现 imageDiff(oldDoc, newDoc) 与 syncImages(diff)。
- 边界要求：① 以 contentHash 为身份（URL 变化不算变更）；② 输出 added/removed/changed 三类；③ changed 执行双删（旧索引+缓存）双索引（新图）；④ removed 的图留存缩略快照供历史引用；⑤ 返回统计与失败清单。

**答**：
```javascript
function imageDiff(a, b) {
  const ha = new Map(a.images.map(x => [x.hash, x]));
  const hb = new Map(b.images.map(x => [x.hash, x]));
  const added = [], removed = [], changed = [];
  for (const [h, img] of hb)
    ha.has(h) ? null : added.push(img);
  for (const [h, img] of ha)
    hb.has(h) ? null : (hb.size && positionChanged(img, b)
      ? changed.push({ old: img, new: findByPosition(b, img.position) })
      : removed.push(img));
  return { added, removed, changed };
}
async function syncImages(diff) {
  const failed = [];
  const run = async (fn, item) => {
    try { await fn(item); } catch (e) { failed.push({ item, err: e.message }); }
  };
  await Promise.all([
    ...diff.added.map(x => run(indexImage, x)),
    ...diff.removed.map(x => run(async (img) => {
      await unindexImage(img);
      await snapshot(img);                          // 快照留存
    })),
    ...diff.changed.map(x => run(async ({ old, new: n }) => {
      await unindexImage(old);
      await descCache.invalidate(old.hash);         // 缓存双删
      await indexImage(n);
    })),
  ]);
  return { ...diff, failed, ok: !failed.length };
}
```

**评分点**:
- 哈希身份判定（URL 变更不触发重索引，省成本）。
- changed 三操作原子性尽力（双删+索引）且失败收集不中断。
- removed 快照留存（历史引用不 404）。
