## AGT-462：手写漂移检测：任务主线锚定、偏离度量、确认与回归策略

**需求与边界**：
- 输入：会话历史、初始任务声明；输出：漂移判定与建议动作。
- 边界要求：① 主线锚定（初始目标+关键约束常驻）；② 偏离度量（当前轮主题与主线的相关性，滑动窗口）；③ 漂移不强行拉回（用户主动换主题合法）→ 区分"用户主导"与"Agent 自漂"；④ 漂移确认话术自然（不生硬打断）。

**答**：
```javascript
class DriftDetector {
  constructor({ anchor, windowSize = 5, threshold = 0.3 }) {
    this.anchor = anchor;                    // {goal, constraints}
    this.windowSize = windowSize;
    this.threshold = threshold;
  }
  async check(turns, { relevance, userInitiated }) {
    const window = turns.slice(-this.windowSize);
    const scores = await Promise.all(window.map(t =>
      relevance(t, this.anchor.goal)));
    const avg = scores.reduce((a, b) => a + b) / scores.length;
    if (avg >= this.threshold) return { drift: false, avg };
    // 漂移了：区分来源
    if (userInitiated(window))                // 用户主动换题 → 合法
      return { drift: false, avg,
        note: '用户主导的话题切换，更新锚点建议',
        suggest: 'reanchor' };
    // Agent 自漂（多步执行中走偏）→ 拉回
    return { drift: true, avg,
      action: {
        mild: `提醒式回归："回到主线，我们正在完成：${this.anchor.goal}"`,
        severe: () => {                       // 偏离超 2 轮 → 确认
          return {
            question: `当前工作似乎偏离了原目标"${this.anchor.goal}"，是否继续当前方向？`,
            options: ['回归主线', '更新目标', '并行处理'],
          };
        } } };
  }
  reanchor(newGoal) {                         // 用户确认更新目标
    this.anchor = { goal: newGoal,
      constraints: this.anchor.constraints };
  }
}
```

**评分点**:
- 主线锚定+滑动窗口相关性度量，阈值判定。
- 区分用户主导切换（合法，建议 reanchor）与 Agent 自漂（拉回）——不误伤合法换题。
- 分级响应：轻漂提醒式回归、重漂交互确认（回归/更新/并行三选项）。
- reanchor 支持目标合法演进。
