## 972：模型供应商静默升级导致指标下滑，怎么发现和应对

**答**：
- 发现靠「金丝雀集」：每日用固定小集合（50~100 条带精确期望的题）探针跑生产模型，分数日环比下降超过阈值即告警——这是抓「供应商静默升级」的雷达。
- 应对三步：确认漂移范围（金丝雀集失败模式聚类：是格式漂移还是能力退化）→ 短期降级（切备用模型版本/调整 prompt 适配）→ 长期重新校准（全量评估重跑基线）。
- 合同与版本锁定：API 尽量锁版本号（如 model@2025-06），升级前要求供应商提前通知；锁不住就在合同里写 SLA 与变更通知义务。
- 追问钩子：为什么全量评测抓不到？——全量夜间跑延迟 24h 且噪声大，金丝雀集小而准、天天跑，才能把漂移发现时间从「天」压到「小时」。

```ts
async function canary() {
  const r = await runEval(canarySet, { model: 'prod-current' });
  const drift = (yesterday.acc - r.acc) / yesterday.acc;
  if (drift > 0.03) {                                  // 日环比下降 3%
    const clusters = clusterFailures(r.failures);      // 失败模式聚类
    alert('model drift', { drift, clusters });
    if (clusters.top === 'format') applyFormatPatch(); // 格式漂移可 prompt 热修
    else switchToFallbackModel();                      // 能力退化切备用
  }
}
```
