## AGT-846：手写 usageReport：多维度聚合（Agent/工具/模型）、预测余量、异常标注、导出

**需求与边界**：
- 实现 usageReport(tenant, month)。
- 边界要求：① 按 Agent/工具/模型三维聚合 tokens 与费用；② 余量预测：按近 7 天日均速率推算耗尽日期；③ 异常标注：任一维度环比涨 >100% 标 spike；④ 空月返回空报表不除零；⑤ 输出可导出 CSV 结构。

**答**：
```javascript
function usageReport(tenant, month, { quota } = {}) {
  const usage = gateway.usage(tenant, month);
  if (!usage.length)
    return { rows: [], empty: true };
  const agg = dim => groupBy(usage, dim);
  const rows = ['agent', 'tool', 'model'].map(dim => ({
    dim, rows: Object.entries(agg(dim)).map(([k, rs]) => ({
      key: k, tokens: sum(rs, 'tokens'),
      usd: round4(sum(rs, 'usd')) })),
  }));
  const last7 = dailyRate(tenant, { days: 7 });
  const remain = quota - sum(usage, 'tokens');
  const exhaustion = last7 > 0
    ? daysUntil(remain, last7) : null;             // 耗尽预测
  const spikes = rows.flatMap(r => r.rows)
    .filter(x => mom(x, month) > 2)
    .map(x => ({ key: x.key, mom: mom(x, month), flag: 'spike' }));
  return { rows, remain, exhaustion, spikes,
    csv: toCsv(rows) };                            // 可导出
}
```

**评分点**:
- 三维聚合齐全；余量预测按近 7 天速率（含耗尽日期，配额管理可行动）。
- 环比 spike 标注（异常自动浮出）；空月短路防除零；CSV 导出。
