## AGT-590：手写 StallWatchdog：8s 提示/15s 可恢复、心跳重置、重连补拉、UI 状态清理

**需求与边界**：
- 实现 StallWatchdog(stream)：轮询检测无事件时长，分级进入 hint/stall 状态。
- 边界要求：① heartbeat 与 data 都重置计时；② hint(8s) 与 stall(15s) 状态互斥且可恢复（收到事件立即清理 UI）；③ stall 提供 resume()：按 lastSeq 补拉缺失；④ stop() 后不再触发任何状态；⑤ 页面隐藏时暂停检测（后台无渲染，避免误报）。

**答**：
```javascript
class StallWatchdog {
  constructor(stream, { hintMs = 8000, stallMs = 15000 } = {}) {
    this.stream = stream; this.hintMs = hintMs; this.stallMs = stallMs;
    this.last = Date.now(); this.state = 'normal'; this.stopped = false;
    ['data', 'heartbeat'].forEach(ev =>
      stream.on(ev, () => this.touch()));
    this.timer = setInterval(() => this.check(), 1000);
    this.onHidden = () => { this.hidden = document.hidden; };
    document.addEventListener('visibilitychange', this.onHidden);
  }
  touch() { this.last = Date.now(); if (this.state !== 'normal') {
    this.state = 'normal'; ui.clearStall(); } }    // 恢复即清 UI
  check() {
    if (this.stopped || this.hidden) return;       // 隐藏时不误报
    const idle = Date.now() - this.last;
    if (idle >= this.stallMs && this.state !== 'stall') {
      this.state = 'stall';
      ui.showStall({ resume: () => this.resume() });
    } else if (idle >= this.hintMs && this.state === 'normal') {
      this.state = 'hint'; ui.showHint('响应变慢，正在等待…');
    }
  }
  async resume() {
    const missed = await api.fetchGap(this.stream.turnId, this.stream.lastSeq);
    missed.forEach(d => this.stream.emit('data', d));
  }
  stop() { this.stopped = true; clearInterval(this.timer);
    document.removeEventListener('visibilitychange', this.onHidden);
    ui.clearStall(); }
}
```

**评分点**:
- 分级状态互斥且可恢复（touch 统一重置 + 清 UI）。
- heartbeat 与 data 等价重置；页面隐藏暂停检测防误报。
- stop 清理定时器与监听器；resume 按 lastSeq 精确补拉。
