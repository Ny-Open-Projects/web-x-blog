## AGT-597：手写 dispatch：类型路由、seq 维护、未知事件忽略、重放测试支持

**需求与边界**：
- 实现 createDispatcher(handlers)：create(state, event) 纯函数式分发。
- 边界要求：① state.lastSeq 单调推进，乱序（seq 更小）事件丢弃；② 未知 type 静默忽略并计数（state.ignored）；③ handlers 抛错不让整个 dispatch 崩（错误进 state.errors）；④ 纯函数（不改动入参 state，返回新 state），可重放。

**答**：
```javascript
function createDispatcher(handlers, { onUnknown = () => {} } = {}) {
  return function dispatch(state, event) {
    if (event.seq <= (state.lastSeq ?? 0))
      return state;                              // 乱序/重复丢弃
    const next = { ...state, lastSeq: event.seq };
    const h = handlers[event.type];
    if (!h) {                                    // 未知事件：忽略+计数
      onUnknown(event.type);
      return { ...next, ignored: (next.ignored ?? 0) + 1 };
    }
    try { return h(next, event) ?? next; }       // handler 返回新 state
    catch (e) {
      return { ...next,
        errors: [...(next.errors ?? []),
          { type: event.type, msg: e.message }] }; // 单事件错误不崩
    }
  };
}
// 重放测试：同一事件流跑两遍结果一致
function replay(events, initialState, dispatch) {
  return events.reduce(dispatch, initialState);
}
```

**评分点**:
- 纯函数式分发（不改入参、返回新 state），天然可重放可测试。
- seq 单调判重；未知事件计数不崩（forward-compatible）。
- handler 异常被捕获进 errors 列表（单事件故障隔离）。
