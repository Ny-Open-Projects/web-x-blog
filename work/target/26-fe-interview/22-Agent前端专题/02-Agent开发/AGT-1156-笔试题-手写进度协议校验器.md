## 1156：笔试手写：实现任务进度事件的协议校验（配对与终局）

**答**：实现 validateStream(events)：events 为 { type, taskId, seq }[]。规则：类型必须合法；seq 严格递增；phase_start/phase_end 必须配对（无未闭合的 phase）；final/error 之后不得再有事件（终局性）；同一任务流校验。返回 { ok, errors: [{ i, reason }] }。

```js
const LEGAL = new Set(['phase_start','phase_end','step','artifact','degrade','final','error']);
function validateStream(events) {
  const errors = [];
  let open = 0, ended = false, lastSeq = -Infinity;
  events.forEach((e, i) => {
    if (!LEGAL.has(e.type)) errors.push({ i, reason: 'illegal type ' + e.type });
    if (e.seq <= lastSeq) errors.push({ i, reason: 'seq not increasing' });
    lastSeq = e.seq;
    if (ended) errors.push({ i, reason: 'event after final' });
    if (e.type === 'phase_start') open++;
    if (e.type === 'phase_end') { if (open === 0) errors.push({ i, reason: 'unmatched phase_end' }); else open--; }
    if (e.type === 'final' || e.type === 'error') ended = true;
  });
  if (open > 0) errors.push({ i: events.length, reason: 'unclosed phase' });
  return { ok: errors.length === 0, errors };
}
const s = [
  { type: 'phase_start', taskId: 't1', seq: 1 },
  { type: 'step', taskId: 't1', seq: 2 },
  { type: 'final', taskId: 't1', seq: 3 },
  { type: 'step', taskId: 't1', seq: 4 },
];
console.log(validateStream(s).errors.map(e => e.reason));
// ['event after final', 'unclosed phase']
```

**评分点**：
- 四条规则全部覆盖：类型合法性、seq 单调、phase 配对（含未闭合检查）、终局性
- 未闭合 phase 在流末尾统一检查（流中间无法判定）
- errors 带索引与原因（可定位）
- 能讨论：多 phase 嵌套是否允许（建议扁平化）、error 与 final 是否互斥（建议 error 也是终局）
