## AGT-802：企业接了 5 家模型供应商，模型网关要解决什么问题（协议统一/路由/降级/配额）

**答**：
- 协议统一：内部统一 API（消息/工具/流式事件格式），各供应商适配器转换；能力声明表（工具调用/上下文长度/多模态/价格）驱动路由。
- 路由策略：按任务类型（代码任务路由到强代码模型）、成本（便宜模型先试+质量门）、租户策略（某些租户指定境内模型合规）。
- 降级与熔断：供应商故障自动切备用（能力矩阵匹配的备选），熔断器按供应商维度；降级事件记审计（租户可查自己被降级的历史）。

```javascript
const GATEWAY = {
  models: MODEL_CATALOG,                          // 能力/价格声明表
  route(req, tenant) {
    const pool = tenant.policy.allowedModels      // 租户合规约束
      .filter(m => capsMatch(m, req.needs));
    return pool.sort(byCostThenQuality)[0] ?? failOver(req, pool);
  },
  async send(req, model) {
    try { return await adapter(model).chat(req); }
    catch (e) {
      if (e.retryable) return failOver(req, [model, ...alternates(model)]);
      throw e;
    }
  },
};
```
