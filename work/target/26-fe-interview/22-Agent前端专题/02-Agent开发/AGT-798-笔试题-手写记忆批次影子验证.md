## AGT-798：手写 shadowBatch：影子写、抽样质量检查、异常丢弃、达标晋升

**需求与边界**：
- 实现 shadowBatch(batch, checks)：蒸馏批次先写影子库。
- 边界要求：① 字段变更率 >30% 或抽样质量 <0.8 丢弃批次并告警；② 抽样 n=100 对照金标；③ 达标晋升（影子→正式，原子切换）；④ 全程幂等（同 batchId 重跑不重复写）；⑤ 晋升后记录批次快照（可回滚）。

**答**：
```javascript
async function shadowBatch(batch, { sampleN = 100 } = {}) {
  const dup = await shadow.exists(batch.id);
  if (dup) return { idempotent: true, verdict: dup.verdict }; // 幂等
  const changes = fieldChangeRate(batch.prev, batch.next);
  const sample = pick(batch.next, sampleN);
  const quality = await judgeAgainstGolden(sample, GOLDEN_FACTS);
  const verdict = changes > 0.3 || quality < 0.8 ? 'discard' : 'promote';
  if (verdict === 'discard') {
    await shadow.mark(batch.id, verdict);
    alert({ type: 'memory_batch_anomaly', batch: batch.id,
      changes, quality });
    return { verdict, changes, quality };
  }
  await shadow.promote(batch.id, {                 // 原子切换
    snapshot: snapshotOf(batch.prev),               // 快照可回滚
  });
  await shadow.mark(batch.id, 'promoted');
  return { verdict, changes, quality };
}
async function rollbackBatch(batchId) {
  const snap = await shadow.snapshot(batchId);
  await memory.restore(snap);                      // 按快照回滚
}
```

**评分点**:
- 双门禁（变更率 30% + 质量 0.8）任一超限即丢弃并告警。
- 幂等（batchId 判重）+ 晋升带前态快照（可回滚）。
- 抽样金标对照（批量变更当发布对待）。
