## AGT-641：手写 logSpan：三级分级、采集端正则+白名单脱敏、TTL、L3加密外置

**需求与边界**：
- 实现 logSpan(span, data, level)。
- 边界要求：① L1 仅白名单字段直接进 span；② L2 脱敏后存（手机/邮箱/身份证三类+兜底长数字串）；③ L3 加密外置对象存储（span 只留 blobRef），TTL 7 天；④ 脱敏不可逆且不破坏结构（JSON 结构保留）。

**答**：
```javascript
const PII = [
  [/1[3-9]\d{9}/g, (m) => m.slice(0, 3) + '****' + m.slice(-2)],   // 手机
  [/[\w.]+@[\w.]+/g, (m) => m.replace(/(.{2}).+(@.+)/, '$1***$2')], // 邮箱
  [/\d{17}[\dXx]/g, () => '***ID***'],                            // 身份证
  [/(?<!\d)\d{11,19}(?!\d)/g, (m) => m.slice(0, 4) + '****'],    // 兜底长数字
];
function redact(data) {
  if (typeof data === 'string')
    return PII.reduce((s, [re, fn]) => s.replace(re, fn), data);
  if (Array.isArray(data)) return data.map(redact);   // 结构保留
  if (data && typeof data === 'object')
    return Object.fromEntries(Object.entries(data)
      .map(([k, v]) => [k, redact(v)]));
  return data;
}
function logSpan(span, data, level = 2) {
  if (level === 1) {
    Object.assign(span.attrs, pick(data, WHITELIST)); // 白名单直存
  } else if (level === 2) {
    Object.assign(span.attrs, redact(data));
    span.ttl = 30 * 864e5;
  } else {
    span.blobRef = encryptStore(JSON.stringify(redact(data))); // L3加密外置
    span.ttl = 7 * 864e5;
  }
}
```

**评分点**:
- 三级分级行为正确（白名单直存/脱敏30天/加密外置7天）。
- 递归脱敏保留 JSON 结构；三类 PII + 兜底长数字（卡号）双保险。
- 脱敏在采集端（查询端拿到即已脱敏）。
