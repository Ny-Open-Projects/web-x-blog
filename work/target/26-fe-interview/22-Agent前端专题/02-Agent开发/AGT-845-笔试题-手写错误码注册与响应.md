## AGT-845：手写 ErrorRegistry：注册校验、一码多受众、只增不改语义、deprecated标记

**需求与边界**：
- 实现 ErrorRegistry：register/toResponse/deprecate。
- 边界要求：① 注册需 { user, dev, retryable, action } 四要素齐全；② 重复码抛错；③ 已注册码的语义字段（retryable/user）修改抛错（只增不改），仅允许加 detail；④ deprecate 标记不删除（旧客户端兼容）；⑤ toResponse 带.traceId 与 retryAfter 注入。

**答**：
```javascript
class ErrorRegistry {
  constructor() { this.map = new Map(); this.deprecated = new Set(); }
  register(code, { user, dev, retryable, action }) {
    if (this.map.has(code)) throw new Error('DUP_CODE');
    if ([user, dev, retryable, action].some(x => x === undefined))
      throw new Error('INCOMPLETE');               // 四要素
    this.map.set(code, Object.freeze({ user, dev, retryable, action }));
  }
  deprecate(code, since) {
    if (!this.map.has(code)) throw new Error('NO_CODE');
    this.deprecated.add(code);
    this.map.get(code).deprecatedSince = since;    // 只标记不删除
  }
  toResponse(code, ctx = {}) {
    const e = this.map.get(code)
      ?? { user: '服务异常', dev: 'unknown', retryable: true };
    return { code,
      message: e.user, detail: e.dev,
      retryable: e.retryable, action: e.action,
      retryAfter: ctx.retryAfter, traceId: ctx.traceId,
      deprecated: this.deprecated.has(code) || undefined };
  }
}
```

**评分点**:
- 四要素注册校验；语义字段冻结（只增不改，防下游判断漂移）。
- deprecate 只标记（旧客户端兼容期）；unknown 回落可重试默认。
