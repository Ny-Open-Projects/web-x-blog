## AGT-586：手写审批等待：风险分级超时动作、人工继续审批、审计留痕

**需求与边界**：
- 实现 ApprovalGate：等待用户审批，超时按风险分级执行默认动作（read 放行/write 挂起/destructive 拒绝）。
- 边界要求：① 超时阈值可配（默认 read 30s/write 300s/destructive 不超时一直等）；② 挂起后用户回来可"继续审批"，上下文保留；③ 每个自动决策写审计（工具/风险/动作/时间）；④ 取消任务时清理未决审批定时器。

**答**：
```javascript
class ApprovalGate {
  constructor({ timeouts = { read: 30000, write: 300000 }, audit }) {
    this.timeouts = timeouts; this.audit = audit; this.timers = new Map();
  }
  request(tc) {
    return new Promise((resolve) => {
      const t = this.timeouts[tc.risk];
      this.timers.set(tc.key, { resolve, tc });
      if (t) this.timers.get(tc.key).timer = setTimeout(
        () => this.timeout(tc.key), t);
      // destructive：不设定时器，一直等人工
    });
  }
  timeout(key) {
    const { tc, resolve } = this.timers.get(key);
    this.timers.delete(key);
    const action = { read: 'approve', write: 'pause' }[tc.risk] ?? 'wait';
    this.audit({ tool: tc.tool, risk: tc.risk, auto: action, at: Date.now() });
    if (action === 'approve') return resolve({ ok: true, auto: true });
    return resolve({ ok: false, state: 'paused',   // 挂起可继续
      resume: () => this.waitHuman(tc, resolve) });
  }
  waitHuman(tc, resolve) {                          // 回来后人工裁决
    return ui.confirmTool(tc).then(d => resolve(d));
  }
  approve(key, by)  { this.settle(key, { ok: true, by }); }
  reject(key, by)   { this.settle(key, { ok: false, by }); }
  settle(key, d) {                                  // 人工决策：清定时器
    const rec = this.timers.get(key);
    if (!rec) return;
    clearTimeout(rec.timer); this.timers.delete(key);
    this.audit({ tool: rec.tc.tool, by: d.by, ...d });
    rec.resolve(d);
  }
  dispose() {                                       // 任务取消：清所有定时器
    for (const { timer } of this.timers.values()) clearTimeout(timer);
    this.timers.clear();
  }
}
```

**评分点**:
- 风险分级超时动作正确（destructive 永不自动放行）。
- write 挂起后 resume 闭包保留人工裁决通道（任务上下文不丢）。
- 自动/人工决策都审计；dispose 清理定时器（防取消后仍触发）。
