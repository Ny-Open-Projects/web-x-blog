## 1115：笔试手写：生成攻击手法 × 防线的覆盖矩阵

**答**：实现 coverage(attacks, defenses)：attacks 为 { vector, defenses: string[] }[]（该手法依赖的防线），defenses 为 { name, healthy: bool }[]。输出每手法 { vector, covered: 必需防线全部健康, missing: 缺失防线名[] } 与总覆盖率（保留 3 位）。防线不健康视为缺失。

```js
function coverage(attacks, defenses) {
  const health = new Map(defenses.map(d => [d.name, d.healthy]));
  let ok = 0;
  const rows = attacks.map(a => {
    const missing = a.defenses.filter(d => health.get(d) !== true);
    if (!missing.length) ok++;
    return { vector: a.vector, covered: missing.length === 0, missing };
  });
  return { rows, rate: +(ok / (attacks.length || 1)).toFixed(3) };
}
const atks = [
  { vector: 'indirect_injection', defenses: ['sanitize', 'trust_tier'] },
  { vector: 'jailbreak', defenses: ['input_classifier'] },
];
const defs = [{ name: 'sanitize', healthy: false }, { name: 'trust_tier', healthy: true },
  { name: 'input_classifier', healthy: true }];
console.log(coverage(atks, defs));
// rows: [ { covered: false, missing: ['sanitize'] }, { covered: true, missing: [] } ], rate: 0.5
```

**评分点**：
- 「全部必需防线健康才算覆盖」的 AND 语义正确
- missing 列出具体缺口（可指导补防线顺序）
- 空数组除零保护
- 能讨论：矩阵的运营用途——防线下线/故障前的「影响面预评估」，防单点失效
