## AGT-585：手写 ToolTimeline 状态机：节点状态流转、部分失败、重试回退、折叠摘要

**需求与边界**：
- 实现 TimelineStore：addCall/fillResult/retry/markSkipped/summary。
- 边界要求：① 状态机 queued→running→ok/error/skipped，error 可重试回 running（记录 attempts），skipped 终态；② summary 输出"N 完成/M 失败/K 跳过"与总耗时（只计 running 与完成时长）；③ 重试超过 3 次锁定 failed；④ 事件乱序（result 先于 call）要容错。

**答**：
```javascript
class TimelineStore {
  constructor() { this.calls = new Map(); this.order = []; }
  addCall(tc) {
    const node = { ...tc, status: 'queued', attempts: 0,
      startedAt: null, results: [], key: tc.key ?? `${tc.turnId}:${tc.seq}` };
    if (this.calls.has(node.key)) return this.calls.get(node.key); // 乱序容错
    this.calls.set(node.key, node); this.order.push(node.key);
    return node;
  }
  fillResult(key, result) {
    const n = this.calls.get(key);
    if (!n) return this.addCall({ key, ...result });   // result 先到：建占位
    n.results.push(result);
    n.status = result.ok ? 'ok' : ++n.attempts >= 3 ? 'failed' : 'error';
    n.elapsed = result.elapsedMs;
  }
  retry(key) {
    const n = this.calls.get(key);
    if (n.status !== 'error') throw new Error('仅 error 可重试');
    n.status = 'running'; n.attempts++;
  }
  markSkipped(key, reason) {
    const n = this.calls.get(key); n.status = 'skipped'; n.reason = reason;
  }
  summary() {
    let ms = 0;
    const cnt = { ok: 0, error: 0, failed: 0, skipped: 0, running: 0 };
    for (const n of this.calls.values()) {
      cnt[n.status] = (cnt[n.status] ?? 0) + 1;
      ms += n.elapsed ?? 0;                      // 只计已完成的耗时
    }
    return { ...cnt, totalMs: ms,
      text: `${cnt.ok} 完成/${cnt.failed + cnt.error} 失败/${cnt.skipped} 跳过` };
  }
}
```

**评分点**:
- 状态机完整（error→重试回 running，3 次锁 failed，skipped 终态）。
- 乱序容错：result 先到建占位节点，call 重复到达幂等。
- summary 计数与耗时正确（只累计完成时长），文本摘要可直接渲染。
