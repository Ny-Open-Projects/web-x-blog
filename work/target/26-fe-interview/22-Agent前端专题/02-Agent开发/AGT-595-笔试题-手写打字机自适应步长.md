## AGT-595：手写 TypeWriter：缓冲自适应步长、flush 完整性、abort 冲刷、低性能直出

**需求与边界**：
- 实现 TypeWriter(el, { lowEnd })：push(delta)/flush/abort。
- 边界要求：① 每帧步长 = max(1, ceil(buf/30))（积压越大吐越快）；② flush 后 buf 为空且内容与累计 delta 完全一致（不丢字）；③ abort 保留已收内容并停帧；④ lowEnd 模式 push 即直出（无动画）；⑤ rAF 循环在无内容时空转不写 DOM。

**答**：
```javascript
class TypeWriter {
  constructor(el, { lowEnd = false } = {}) {
    this.el = el; this.buf = ''; this.total = '';
    this.stopped = false;
    if (!lowEnd) requestAnimationFrame(this.loop);
    this.lowEnd = lowEnd;
  }
  push(delta) {
    this.total += delta;                        // 全量对账基线
    if (this.lowEnd) { this.el.textContent = this.total; return; }
    this.buf += delta;
  }
  loop = () => {
    if (this.stopped) return;
    if (this.buf.length) {                      // 有内容才写 DOM
      const step = Math.max(1, Math.ceil(this.buf.length / 30));
      this.el.textContent += this.buf.slice(0, step);
      this.buf = this.buf.slice(step);
    }
    requestAnimationFrame(this.loop);
  };
  flush() {
    if (this.lowEnd) return this.total;
    this.el.textContent += this.buf; this.buf = '';
    // 完整性自检：渲染长度应等于累计 delta 长度
    console.assert(this.el.textContent.length === this.total.length,
      'typewriter lost chars');
    return this.total;
  }
  abort() { this.stopped = true; this.flush(); } // 保留已收内容并停帧
}
```

**评分点**:
- 步长公式自适应追赶积压；空转不写 DOM。
- flush 完整性断言（丢字可发现）；abort 停帧且保留内容。
- lowEnd 直出无动画（低端机兜底）。
