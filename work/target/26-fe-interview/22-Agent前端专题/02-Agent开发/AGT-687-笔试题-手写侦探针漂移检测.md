## AGT-687：手写 dailyProbe：金标canary跑分、漂移阈值、不可比窗口标记、judge重校准钩子

**需求与边界**：
- 实现 dailyProbe()：每天跑固定 canary 集，检测模型漂移。
- 边界要求：① 温度 0 固定用例，分数与基线偏差 >1.5 告警；② 告警时自动标记「不可比窗口」（start~recover，期间评测结论不可跨窗比较）；③ 连续 2 天漂移才告警（防单日抖动）；④ 恢复（连续 2 天回到基线）关闭窗口并触发 judge 校准钩子。

**答**：
```javascript
class DriftProbe {
  constructor({ thresh = 1.5, confirmDays = 2 } = {}) {
    this.thresh = thresh; this.confirmDays = confirmDays;
    this.devStreak = 0; this.okStreak = 0; this.window = null;
  }
  async probe() {
    const score = await runEval(CANARY, { temperature: 0 });
    const dev = Math.abs(score - CANARY.baseline);
    if (dev > this.thresh) {
      if (++this.devStreak >= this.confirmDays && !this.window) {
        this.window = { start: today() };        // 开不可比窗口
        alert({ type: 'model_drift', dev,
          actions: ['pin', 'incomparable', 'recalibrate'] });
      }
      this.okStreak = 0;
    } else {
      this.devStreak = 0;
      if (this.window && ++this.okStreak >= this.confirmDays) {
        markIncomparable({ ...this.window, end: today() });
        judgeRecalibrate(GOLDEN_SET);            // 恢复后重校准
        this.window = null; this.okStreak = 0;
      }
    }
    return { score, dev, window: this.window };
  }
}
```

**评分点**:
- 温度 0 固定集（侦探针语义），连续确认防单日抖动。
- 不可比窗口开启与恢复闭环（跨窗比较被禁止）。
- 恢复触发 judge 重校准（judge 也会漂移的意识）。
