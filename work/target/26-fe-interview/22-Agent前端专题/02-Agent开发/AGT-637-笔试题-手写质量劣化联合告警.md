## AGT-637：手写 checkDegradation：多指标burn rate、联合判定、基线快照、自动下钻样本

**需求与边界**：
- 实现 checkDegradation(window, baseline, opts)：输出告警或 null。
- 边界要求：① burn rate = 当前坏率/基线坏率（基线坏率为 0 时用绝对增量判定）；② 单指标不告警，≥2 个指标同向劣化才告警；③ 指标方向感知（dislikeRate 升=坏，citeHitRate 降=坏）；④ 样本窗 < 最小样本量不判定（防噪声）。

**答**：
```javascript
const DIR = { dislikeRate: 1, regenRate: 1, citeHitRate: -1, toolFailRate: 1 };
function burn(sig, cur, base) {
  const dir = DIR[sig];
  if (base <= 0) return dir * cur > dir * 0 ? (cur > 0 ? 2 : 0) : 0;
  const bad = dir === 1 ? cur / base : base / cur;   // 方向归一
  return isFinite(bad) ? bad : 2;
}
function checkDegradation(window, baseline,
  { minN = 200, thresh = 2, need = 2 } = {}) {
  if (window.n < minN) return null;               // 样本不足不判定
  const bad = Object.keys(DIR).filter(sig =>
    burn(sig, window[sig], baseline[sig]) >= thresh);
  if (bad.length < need) return null;             // 联合判定降噪
  return {
    type: 'quality_degrade', signals: bad,
    drilldown: window.samples
      .filter(s => bad.some(k => hitSignal(s, k))).slice(0, 20),
  };
}
```

**评分点**:
- 方向感知正确（升坏/降坏指标统一为 burn 语义）。
- 基线为 0 的边界用绝对增量而非除零；样本量下限防噪声。
- ≥2 指标联合判定 + 自动下钻样本（告警可行动）。
