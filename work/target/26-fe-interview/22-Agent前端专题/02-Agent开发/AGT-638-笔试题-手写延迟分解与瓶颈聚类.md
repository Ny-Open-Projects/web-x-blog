## AGT-638：手写 breakdown + bottleneckReport：五段分解、P95分位、瓶颈聚类占比

**需求与边界**：
- 实现 breakdown(turn) 与 bottleneckReport(turns)。
- 边界要求：① 五段 queue/preprocess/ttft/generate/postprocess，缺段记 0 不崩；② 总时长=分段和（允许与实测有 5% 误差，超差告警）；③ 瓶颈=最长段；④ 报告输出瓶颈分布占比与 P95 总时长。

**答**：
```javascript
const SEGS = ['queue', 'preprocess', 'ttft', 'generate', 'postprocess'];
function breakdown(turn) {
  const b = Object.fromEntries(SEGS.map(s =>
    [s, turn.spans.find(x => x.name === s)?.durMs ?? 0]));
  const sum = SEGS.reduce((a, s) => a + b[s], 0);
  b.check = Math.abs(sum - turn.totalMs) / turn.totalMs < 0.05; // 勾稽校验
  b.bottleneck = SEGS.reduce((m, s) => b[s] > b[m] ? s : m, SEGS[0]);
  return b;
}
function bottleneckReport(turns) {
  const bs = turns.map(breakdown);
  const dist = countBy(bs, 'bottleneck');
  return {
    dist: Object.fromEntries(Object.entries(dist)
      .map(([k, v]) => [k, v / bs.length])),      // 占比
    p95Total: percentile(bs.map(b => SEGS.reduce((a, s) => a + b[s], 0)), 0.95),
    badChecks: bs.filter(b => b.check === false).length, // 勾稽失败数
  };
}
```

**评分点**:
- 分段缺失兜底为 0；勾稽校验（分段和 vs 实测 5% 容差）体现数据可信意识。
- 瓶颈为最长段，报告输出占比 + P95 + 勾稽失败计数。
