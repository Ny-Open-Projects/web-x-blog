## 1239：笔试手写：实现模块联邦 shared 的版本协商降级链

**答**：实现 negotiate(host, sub, sharedSpec)：sharedSpec = { [pkg]: { singleton, requiredVersion } }。对每个 pkg：semver 满足 requiredVersion -> 用宿主版本（singleton）；不满足 -> 子应用自带（isFallback: true）并告警；子应用无该包 -> missing。semver 比较实现为简化函数 satisfies(version, range)（支持 ^x.y.z 与 >=x.y.z）。

```js
function semverNum(v) {
  const [a, b, c] = v.replace(/^v/, '').split('.').map(Number);
  return [a, b, c || 0];
}
function satisfies(version, range) {
  const [v, r] = [semverNum(version), semverNum(range.replace(/^[\^>=]+/, ''))];
  if (range.startsWith('^'))
    return v[0] === r[0] && (v[1] > r[1] || (v[1] === r[1] && v[2] >= r[2]));
  if (range.startsWith('>='))
    return v[0] > r[0] || (v[0] === r[0] && (v[1] > r[1] ||
      (v[1] === r[1] && v[2] >= r[2])));
  return false;
}
function negotiate(host, sub, sharedSpec) {
  const out = {};
  for (const [pkg, spec] of Object.entries(sharedSpec)) {
    if (!sub[pkg]) { out[pkg] = { mode: 'missing' }; continue; }
    if (spec.singleton && satisfies(host[pkg], spec.requiredVersion)) {
      out[pkg] = { mode: 'host', version: host[pkg] };
    } else {
      out[pkg] = { mode: 'fallback', version: sub[pkg],
        warn: spec.singleton ? 'singleton broken' : null };
    }
  }
  return out;
}
console.log(negotiate(
  { react: '18.2.0', zustand: '4.5.0' },
  { react: '18.1.0', zustand: '4.0.0' },
  { react: { singleton: true, requiredVersion: '^18.0.0' },
    zustand: { singleton: true, requiredVersion: '^4.5.0' } }));
// react host 18.2.0；zustand fallback（4.0.0 不满足 ^4.5.0）+ warn
```

**评分点**：
- satisfies 支持 ^ 与 >=（^ 的同主版本+次补丁下界语义）
- 协商降级链：host 单例 -> fallback 自带 + warn（singleton 破坏告警——双实例事故前兆）
- missing 分支
- 能讨论：fallback 的代价（双实例/context 断裂）、requiredVersion 的严格化策略
