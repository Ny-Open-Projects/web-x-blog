## AGT-745：手写 indexVideo：字幕话题分段、关键帧描述、时间戳引用、章节层级

**需求与边界**：
- 实现 indexVideo(video)：输出分段索引。
- 边界要求：① 段长 5~10 分钟（话题边界自适应，硬切上限 12 分钟）；② 每段 3~5 关键帧描述（均匀采样+画面变化点）；③ 每段输出 { text, frames, ref }，ref 含 t0/t1；④ 章节层：段聚类成章，章带摘要；⑤ 无字幕视频提示需先转写。

**答**：
```javascript
async function indexVideo(video, { asr, vision }) {
  if (!video.subtitleUrl && !await hasAudioTrack(video))
    throw new Error('NEED_TRANSCRIBE');
  const asrText = video.subtitleUrl
    ? await loadSubtitles(video.subtitleUrl)
    : (await transcribe(video)).text;
  const segs = topicSegment(asrText, { min: 5, max: 12 });  // 分钟
  const indexed = await pMap(segs, async (seg, i) => {
    const frames = await keyFrames(video, seg, 4);
    return { idx: i, text: seg.text,
      frames: await pMap(frames, f => vision(f, DESCRIBE_PROMPT)),
      ref: { videoId: video.id, t0: seg.t0, t1: seg.t1 } };
  }, { concurrency: 4 });
  const chapters = clusterChapters(indexed);       // 段聚类成章
  return { segments: indexed,
    chapters: chapters.map(c => ({ ...c, summary: summarize(c) })) };
}
```

**评分点**:
- 分段约束（5~12 分钟硬上限）+ 话题自适应；无字幕先转写（显式前置）。
- 关键帧描述与字幕共同索引（录屏核心信息在画面）。
- 章节层级 + 时间戳引用（粗到细定位）。
