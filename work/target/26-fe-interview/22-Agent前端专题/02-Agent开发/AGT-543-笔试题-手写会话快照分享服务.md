## AGT-543：手写分享快照：脱敏管线、签名、过期校验、strict 拦截模式

**需求与边界**：
- 实现 createShare(session, opts) 与 readShare(id, sig)。
- 边界要求：① 脱敏至少覆盖手机号/邮箱/内网域名三类，strict 模式命中即抛错；② 签名覆盖内容+过期时间，篡改内容或过期都拒绝；③ access 为 link 时任何人可读、login 时校验用户；④ 读取要有访问日志。

**答**：
```javascript
const RE = { phone: /1[3-9]\d{9}/g, email: /[\w.]+@[\w.]+/g,
             intranet: /(\.internal|\.corp|10\.\d+\.\d+\.\d+)/g };
function redact(text, strict) {
  let hits = 0;
  const out = text.replace(new RegExp(Object.values(RE).map(r => r.source).join('|'), 'g'),
    (m) => { hits++;
      if (strict) throw new Error('SENSITIVE: ' + m.slice(0, 4) + '***');
      return m.slice(0, 3) + '***'; });
  return { out, hits };
}
function createShare(session, { strict = false, expireDays = 7, access = 'link' } = {}) {
  const msgs = session.activePath().map(m => ({
    role: m.role, content: redact(m.content, strict).out }));
  const payload = JSON.stringify({ msgs,
    expireAt: Date.now() + expireDays * 864e5, access });
  const id = randomId();
  store.set(id, { payload, sig: hmac(id + payload) });
  return { url: `https://ai.example.com/s/${id}?sig=${store.get(id).sig}` };
}
function readShare(id, sig, user) {
  const rec = store.get(id);
  if (!rec || !timingSafeEq(rec.sig, sig)) throw new Error('BAD_SHARE');
  const data = JSON.parse(rec.payload);
  if (Date.now() > data.expireAt) throw new Error('EXPIRED');
  if (data.access === 'login' && !user) throw new Error('NEED_LOGIN');
  audit.log({ id, user: user?.id, at: Date.now() });   // 访问留痕
  return data.msgs;
}
```

**评分点**:
- strict 模式命中即拦截（先于打码），非 strict 打码保留前 3 位。
- 签名绑定 id+内容+过期时间，篡改/过期分别拒绝。
- access 分级鉴权 + 访问审计日志。
