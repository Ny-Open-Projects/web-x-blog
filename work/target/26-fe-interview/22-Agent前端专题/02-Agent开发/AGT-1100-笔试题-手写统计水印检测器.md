## 1100：笔试手写：实现简化版文本统计水印检测

**答**：实现 makeWatermark(key, vocabSize)：生成绿名单 Set（hash(token+key) % vocabSize < vocabSize/2 为绿）。encode(text)：对文本 token（简化：按空格分词）统计并返回 { text, greenRate }。detect(text, key, baseline=0.5, margin=0.15)：greenRate 超 baseline+margin 判定 { likely: true, rate }。相同 key 下检测结果可复现。

```js
function h(s) { let x = 2166136261; for (const c of s) { x ^= c.charCodeAt(0); x = Math.imul(x, 16777619); } return x >>> 0; }
function greenSet(key, vocabSize) {
  const g = new Set();
  for (let i = 0; i < vocabSize; i++) if (h(key + ':' + i) % 2 === 0) g.add(i);
  return g;
}
function encode(text, key, vocabSize = 1000) {
  const g = greenSet(key, vocabSize), toks = text.split(/\s+/).filter(Boolean);
  const green = toks.filter(t => g.has(h(t) % vocabSize)).length;
  return { text, greenRate: toks.length ? green / toks.length : 0, n: toks.length };
}
function detect(text, key, baseline = 0.5, margin = 0.15) {
  const { greenRate, n } = encode(text, key);
  if (n < 20) return { likely: false, rate: greenRate, note: '样本不足' }; // 短文本不可判
  return { likely: greenRate > baseline + margin, rate: +greenRate.toFixed(3) };
}
console.log(detect('the quick brown fox jumps over lazy dog again and again', 'k1').likely !== undefined); // true
```

**评分点**：
- 绿名单生成确定性（同 key 同结果），检测可复现
- 短文本样本不足的不可判定处理（统计水印的基本诚实）
- 阈值语义：baseline + margin，能讨论误报/漏报随 margin 的权衡
- 能讨论：真实水印作用在 token 采样而非事后检测、改写攻击的削弱效应、与显式元数据组合使用
