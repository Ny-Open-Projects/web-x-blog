## AGT-418：手写灰度控制器：用户稳定分桶、指标门升档、破线自动回退

**需求与边界**：
- 输入：用户 id、阶梯 [0,0.05,0.25,0.5,1]、指标快照（成功/成本/负反馈）；输出：该用户分到的版本。
- 边界要求：① 同用户稳定同桶（hash 分桶）；② 每档停留需指标连续稳定才升；③ 护栏破线自动缩一档并可一键回滚；④ 新增高危失败模式即冻结升档。

**答**：
```javascript
class RampController {
  constructor({ ladder = [0, 0.05, 0.25, 0.5, 1], stableDays = 3 }) {
    this.ladder = ladder; this.level = 1; this.stableDays = 0;
    this.stableDaysNeeded = stableDays; this.frozen = false;
  }
  assign(userId) {
    const bucket = hash(userId) % 100 / 100;      // 稳定分桶
    const ratio = this.ladder[this.level];
    return { version: bucket < ratio ? 'candidate' : 'stable',
      bucket, level: this.level };
  }
  onDailyMetrics({ successRate, costOver, negFeedbackRate,
                   newCriticalMode }) {
    // 护栏：成本破线 → 自动缩一档
    if (costOver) return this.down('cost_over');
    // 新增高危失败模式 → 冻结
    if (newCriticalMode) { this.frozen = true;
      return { action: 'freeze', reason: 'new_critical_mode' }; }
    // 指标稳定累计达标 → 升档
    if (successRate >= 0.9 && negFeedbackRate <= 0.02) {
      if (++this.stableDays >= this.stableDaysNeeded && !this.frozen &&
          this.level < this.ladder.length - 1) {
        this.level++; this.stableDays = 0;
        return { action: 'ramp_up', level: this.level };
      }
    } else this.stableDays = 0;                   // 波动重计
    return { action: 'hold', level: this.level };
  }
  rollback() { this.level = 0; return { action: 'rollback' }; }
  down(reason) { this.level = Math.max(0, this.level - 1);
    return { action: 'ramp_down', level: this.level, reason }; }
}
```

**评分点**:
- hash 稳定分桶保证同用户同版本（实验一致性）。
- 连续稳定天数门槛才升档，波动清零重计（防运气升档）。
- 护栏联动：成本破线自动缩档、新增高危模式冻结、可一键回滚。
- 阶梯与 hold/up/down/freeze 状态机完整可运行。
