## 1105：笔试手写：实现多 Agent 委托的权限收敛校验

**答**：实现 delegateCheck(parent, child)：parent/child 均为 { tools: Set, paths: string[]（前缀）, maxRisk: 0-3 }。校验：child.tools ⊆ parent.tools；child.paths 每个必须是 parent 某前缀的前缀；child.maxRisk ≤ parent.maxRisk；返回 { ok, violations }。violations 列出具体越界项。

```js
function isPrefix(pre, p) {
  return p === pre || p.startsWith(pre.endsWith('/') ? pre : pre + '/');
}
function delegateCheck(parent, child) {
  const v = [];
  for (const t of child.tools) if (!parent.tools.has(t)) v.push(`tool:${t}`);
  for (const p of child.paths) {
    const covered = parent.paths.some(pre => isPrefix(pre, p));
    if (!covered) v.push(`path:${p}`);              // 越界路径
  }
  if (child.maxRisk > parent.maxRisk) v.push(`risk:${child.maxRisk}>${parent.maxRisk}`);
  return { ok: v.length === 0, violations: v };
}
const parent = { tools: new Set(['fs.read', 'fs.write']), paths: ['/data'], maxRisk: 2 };
console.log(delegateCheck(parent, { tools: new Set(['fs.read']), paths: ['/data/sub'], maxRisk: 2 }));
// { ok: true, violations: [] }
console.log(delegateCheck(parent, { tools: new Set(['net.post']), paths: ['/etc'], maxRisk: 3 }).violations);
// ['tool:net.post', 'path:/etc', 'risk:3>2']
```

**评分点**：
- 三类越界（工具/路径/风险级）检查齐全
- 路径前缀匹配的边界（/data2 不被 /data 覆盖）
- violations 精确到具体项（可定位）
- 能讨论：只收窄不放大是单向阀设计、深层委托的风险递减（maxRisk 随 depth 递减可扩展）
