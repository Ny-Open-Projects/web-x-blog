## AGT-727：回答引用扫描文档时，如何按原文版式展示片段（而不是乱序文本）

**答**：
- 解析时保留「版面结构树」：块顺序（阅读顺序，双栏文档按栏序）、表格结构、图片位置；引用片段渲染时按结构树还原（表格渲染为表格、双栏按栏序），而不是把 OCR 文本按流式拼接。
- 阅读顺序检测是双栏 PDF 的头号坑：简单按 y 坐标排序会把两栏串行，需要栏检测（x 坐标聚类）后再排序。
- 引用渲染降级：结构信息缺失时退化为"原文截图+文本对照"双视图，用户自行对照。

```javascript
function readingOrder(layout) {
  const cols = clusterBy(layout.regions.map(r => r.x), { k: detectCols(layout) });
  return cols.flatMap(col =>
    col.sort((a, b) => a.y - b.y));                // 先分栏再栏内按y
}
function renderCite(cite) {
  if (cite.structure?.table) return <TablePreview {...cite.structure.table} />;
  if (cite.structure) return <StructuredText order={cite.structure.order} />;
  return <DualView img={cite.snapshot} text={cite.text} />;  // 降级双视图
}
```
