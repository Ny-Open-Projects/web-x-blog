## 1088：分钟级 Agent 任务断线后用户重连，怎么无缝恢复

**答**：
- 恢复三件套：任务状态持久化（每步落盘，断线不丢）、可重连的进度流（按 taskId 重连 SSE，从断点续推历史 + 实时）、幂等的续跑（已完成的步骤不重跑——重跑既慢又烧钱）。
- 协同点：重连时先推「已完成步骤的产物快照」（用户立即看到进度），再续实时流；前端渲染要能接受「补发的历史事件」。
- 用户中断与网络中断要区分：网络重连续跑；用户主动取消才终止任务（取消也要落账：已消耗成本计入）。
- 追问钩子：恢复后模型上下文怎么重建？——从持久化的「轮次记录」重放组装上下文，而不是让模型「重新想」——保证恢复后行为一致。

```ts
async function resume(taskId, sse) {
  const t = await store.load(taskId);
  for (const done of t.completedSteps) sse.send('history', done.snapshot); // 先补历史
  if (t.status === 'running') {
    await orchestrator.continue(t, sse);      // 从断点续跑（幂等）
  } else sse.send('done', t.final);
}
// 步骤幂等：完成即持久化，重入跳过
async function step(task, s) {
  if (task.done.has(s.id)) return task.done.get(s.id);
  const r = await s.run();
  task.done.set(s.id, r); await store.save(task);
  return r;
}
```
