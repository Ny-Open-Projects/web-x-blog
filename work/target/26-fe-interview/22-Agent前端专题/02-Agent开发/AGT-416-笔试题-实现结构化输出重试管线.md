## AGT-416：手写 JSON 输出管线：提取容错、校验失败带错误重试、最终降级

**需求与边界**：
- 输入：prompt、zod schema、maxRetry=2；输出：合法对象或降级结果。
- 边界要求：① 模型输出含 markdown 包裹/前后杂文时的 JSON 提取容错；② 重试时把校验错误具体信息回传模型；③ 枚举类字段校验失败后带候选清单重试；④ 两次失败降级返回 null+原始输出（供人工/调试）。

**答**：
```javascript
async function structuredOutput({ llm, prompt, schema, maxRetry = 2 }) {
  let lastRaw = '', lastErr = null;
  for (let i = 0; i <= maxRetry; i++) {
    const extra = lastErr
      ? `\n上次输出错误：${lastErr}\n请修正。` : '';
    const raw = await llm(`${prompt}${extra}
      只输出 JSON，不要其他文字。`);
    lastRaw = raw;
    const json = extractJson(raw);              // 容错提取
    if (!json) { lastErr = '无法解析出 JSON'; continue; }
    const parsed = schema.safeParse(json);
    if (parsed.success) return parsed.data;
    // 枚举错误补候选提示
    let msg = parsed.error.message;
    const enumIssue = parsed.error.issues.find(
      x => x.code === 'invalid_enum_value');
    if (enumIssue) msg += `，可选值：${enumIssue.options?.join('/')}`;
    lastErr = msg;
  }
  return { ok: false, raw: lastRaw, error: lastErr };   // 降级：原始输出保留
}
const FENCE = '\u0060'.repeat(3);           // 围栏用码点构造，避免源码内出现字面围栏
function extractJson(raw) {
  // 剥离 markdown 围栏（如 json 语言标签）包裹与前后杂文
  const m = raw.match(new RegExp(FENCE + '(?:json)?\\s*([\\s\\S]*?)' + FENCE)) ??
           raw.match(/(\{[\s\S]*\}|\[[\s\S]*\])/);
  if (!m) return null;
  try { return JSON.parse(m[1].trim()); } catch { return null; }
}
// zod schema：z.object({ category: z.enum(['a','b','c']), ... })
```

**评分点**:
- JSON 提取容错（markdown 包裹/杂文剥离）与解析失败、校验失败分型处理。
- 重试带回具体错误信息（含枚举候选清单）——给模型可执行的修正指令。
- 重试上限与降级路径（保留原始输出供调试/人工），不静默吞错。
- schema 用 zod 强校验，工程语义完整。
