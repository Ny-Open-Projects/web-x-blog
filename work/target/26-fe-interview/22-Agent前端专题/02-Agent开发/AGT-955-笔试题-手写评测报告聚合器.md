## 955：笔试手写：实现评测结果的分组聚合与对比报告

**答**：实现 summarize(runs, baseline)：runs 为 { version, intent, acc, tokens, p95 }[]。输出按 intent 分组的每组统计（acc 均值、tokens 均值、p95 取组内最大）+ 与 baseline 同版本对比的 delta（保留 3 位小数）；intent 在 baseline 缺失的组标 'new'。

```js
function groupBy(arr, key) {
  return arr.reduce((m, x) => ((m[x[key]] ??= []).push(x), m), {});
}
const mean = a => a.reduce((s, x) => s + x, 0) / (a.length || 1);
function summarize(runs, baselineVersion) {
  const out = {};
  for (const [intent, rs] of Object.entries(groupBy(runs, 'intent'))) {
    const acc = mean(rs.map(r => r.acc));
    const tokens = mean(rs.map(r => r.tokens));
    const p95 = Math.max(...rs.map(r => r.p95));
    const base = rs.find(r => r.version === baselineVersion);
    out[intent] = {
      n: rs.length, acc: +acc.toFixed(3), tokens: Math.round(tokens), p95,
      delta: base ? +(acc - base.acc).toFixed(3) : 'new',   // 对比基线
    };
  }
  return out;
}
const runs = [
  { version: 'v1', intent: 'qa', acc: 0.8, tokens: 900, p95: 1200 },
  { version: 'v2', intent: 'qa', acc: 0.86, tokens: 950, p95: 1500 },
  { version: 'v2', intent: 'coding', acc: 0.7, tokens: 3000, p95: 4000 },
];
console.log(summarize(runs, 'v1').qa); // { n:2, acc:0.83, tokens:925, p95:1500, delta:0.06 }
```

**评分点**：
- 分组聚合逻辑正确（均值/最大值语义不混用）
- delta 的基线匹配：同 intent 同 version 才比，缺失标 new
- 空组、除零保护（a.length || 1）
- 能讨论 p95 为什么取组内最大（组内已按意图聚合，取最差代表该意图的体验下限）
