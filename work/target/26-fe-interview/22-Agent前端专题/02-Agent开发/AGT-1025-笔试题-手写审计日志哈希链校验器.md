## 1025：笔试手写：实现审计日志哈希链与完整性校验

**答**：实现 AuditLog：append(ev) 生成 { seq, ts, ev, prev, hash }（hash = 简单哈希(JSON(ev)+prev)，seq 自增）；verify() 校验全链：seq 连续、prev 指向上条 hash、hash 重算一致；返回 { ok, brokenAt }（首个断点索引，全对返回 null）。篡改任意历史条目必须能被 verify 发现。

```js
function h(s) { let x = 5381; for (const c of s) x = ((x << 5) + x + c.charCodeAt(0)) >>> 0; return x.toString(16); }
class AuditLog {
  constructor() { this.items = []; }
  append(ev) {
    const prev = this.items.at(-1)?.hash ?? '0';
    const rec = { seq: this.items.length, ts: Date.now(), ev,
      prev, hash: h(JSON.stringify(ev) + prev) };
    this.items.push(rec);
    return rec;
  }
  verify() {
    for (let i = 0; i < this.items.length; i++) {
      const r = this.items[i];
      if (r.seq !== i) return { ok: false, brokenAt: i };
      const prev = i === 0 ? '0' : this.items[i - 1].hash;
      if (r.prev !== prev) return { ok: false, brokenAt: i };
      if (r.hash !== h(JSON.stringify(r.ev) + prev)) return { ok: false, brokenAt: i };
    }
    return { ok: true, brokenAt: null };
  }
}
const log = new AuditLog();
log.append({ act: 'fs.delete', path: '/tmp/a' });
log.append({ act: 'mail.send', to: 'a@b.c' });
console.log(log.verify().ok);   // true
log.items[0].ev.act = 'fs.read';  // 篡改
console.log(log.verify());        // { ok: false, brokenAt: 0 }
```

**评分点**：
- 哈希链结构正确：每条含前条 hash，篡改任一历史条目导致后续全部校验失败（brokenAt 定位首断点）
- seq 连续性校验（防删除中间条目）
- 首条 prev 的哨兵值 '0' 处理一致（append 与 verify 两处必须同源）
- 能讨论：真实系统用 HMAC+密钥（攻击者无法伪造整条链）、WORM 存储、哈希算法选型（生产用 SHA-256 不用自造）
