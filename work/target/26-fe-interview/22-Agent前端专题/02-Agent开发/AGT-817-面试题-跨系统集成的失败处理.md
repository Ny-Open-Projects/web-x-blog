## AGT-817：Agent 联动 5 个企业系统（CRM/OA/邮件），跨系统集成的失败处理与补偿怎么做

**答**：
- 集成纪律：每个系统适配器带「能力声明」（幂等性/事务性/可撤销），编排器据此选择失败策略——可撤销系统失败可自动补偿，不可撤销（已发邮件）失败必须人工介入。
- 部分成功的用户呈现：3/5 系统成功时明确列出哪些成功哪些失败+失败原因+重试按钮，绝不模糊"部分完成"。
- 幂等键贯穿：同一任务对同一系统的重试复用幂等键（防重复建单），跨系统的关联 ID（任务→各系统单号）持久化以便补偿。

```javascript
const ADAPTERS = {
  crm: { idempotent: true, reversible: true },
  mail: { idempotent: false, reversible: false },
};
async function fanOut(task, systems) {
  const results = [];
  for (const s of systems) {
    try {
      const r = await adapters[s].call(task, { idemKey: task.key + s });
      results.push({ system: s, ok: true, ref: r.id });
    } catch (e) {
      const a = ADAPTERS[s];
      if (a.reversible) await compensate(results, s);  // 可撤销自动补偿
      results.push({ system: s, ok: false,
        error: e.code, needsHuman: !a.reversible });
    }
  }
  return results;                                  // 明细呈现给用户
}
```
