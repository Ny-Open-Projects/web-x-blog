## AGT-736：手写 indexImage：结构化描述生成、OCR 交叉核对、一致性反验、人工队列

**需求与边界**：
- 实现 indexImage(img, ctx)。
- 边界要求：① 描述按四段模板（类型/实体/文字数值/作用）；② OCR 结果并入描述且数值与描述交叉核对（描述提到但 OCR 没有的数值标疑）；③ 反验（vision 判断描述是否符合图）不通过进人工队列；④ 产物带 contentHash 缓存键。

**答**：
```javascript
async function indexImage(img, ctx, { vision, ocr }) {
  const h = await contentHash(img);
  const cached = await cache.get(`desc:${h}:${VISION_VER}`);
  if (cached) return cached;
  const desc = await vision(img, DESC_PROMPT);       // 四段模板
  const ocrText = await ocr(img);
  const descNums = extractNumbers(desc);
  const ocrNums = new Set(extractNumbers(ocrText.text));
  const suspect = descNums.filter(n => !ocrNums.has(n)); // 交叉核对
  const check = await vision([img, desc], VERIFY_PROMPT);
  const out = { desc: desc + '\nOCR: ' + ocrText.text,
    ctx, imgRef: img.id, hash: h,
    suspectNums: suspect,
    status: check.verdict === 'consistent' && !suspect.length
      ? 'ok' : 'human-review',                       // 反验+疑值→人工
  };
  if (out.status === 'ok') await cache.set(`desc:${h}:${VISION_VER}`, out);
  return out;
}
```

**评分点**:
- 四段模板描述（防自由发挥漏数字）；OCR 交叉核对捕捉描述编数。
- 反验不通过或数值存疑都进人工队列（不静默入库）。
- contentHash+模型版本缓存键（重跑幂等省钱）。
