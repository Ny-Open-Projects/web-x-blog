## AGT-540：手写错误处理引擎：映射表、退避重试、半成品保留、埋点分类

**需求与边界**：
- 输入：ERROR_MAP（文案/可重试/动作）与请求函数；输出 withRetry(fn, code) 包装器。
- 边界要求：① 未知错误码归入 DEFAULT 分类（埋点不丢）；② 重试指数退避 1s/2s/4s 上限 3 次，仅对 retry:true 的码重试；③ 每次失败保留 partial（半成品）；④ 429 优先用服务端 retryAfter 而非本地退避。

**答**：
```javascript
const ERROR_MAP = {
  RATE_LIMITED: { retry: true, text: '请求太频繁，{s}秒后重试' },
  MODEL_TIMEOUT: { retry: true, text: '生成超时，可重试' },
  MODERATION: { retry: false, text: '内容未通过安全审核' },
  DEFAULT: { retry: false, text: '出错了，请稍后重试' },
};
async function withRetry(fn, opts = {}) {
  let attempt = 0, partial = null;
  for (;;) {
    try {
      const res = await fn({ partial, attempt });  // 传入半成品支持续写
      track('ai_err_recovered', { attempt });
      return res;
    } catch (e) {
      const cfg = ERROR_MAP[e.code] ?? ERROR_MAP.DEFAULT;  // 未知归类
      track('ai_err', { code: e.code, attempt, known: !!ERROR_MAP[e.code] });
      partial = e.partial ?? partial;              // 保留半成品
      if (!cfg.retry || attempt >= (opts.max ?? 3)) throw e;
      const delay = e.code === 'RATE_LIMITED' && e.retryAfter
        ? e.retryAfter * 1000                       // 服务端优先
        : Math.min(1000 * 2 ** attempt, 8000);      // 指数退避
      await new Promise(r => setTimeout(r, delay));
      attempt++;
    }
  }
}
```

**评分点**:
- 未知错误码回落 DEFAULT 且埋点标记 known（新增错误不丢分类）。
- 退避策略正确：429 用服务端 retryAfter，其余指数退避封顶；仅 retry:true 重试。
- partial 一路透传（重试可续写而非从零开始），最终失败也保留半成品。
