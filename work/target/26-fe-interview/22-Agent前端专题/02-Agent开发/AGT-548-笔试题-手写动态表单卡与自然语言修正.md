## AGT-548：手写 TaskFormCard 核心：schema 渲染、提交校验、修正补丁待确认态

**需求与边界**：
- 实现 applyCorrection(formState, text, schema)：从自然语言解析字段修正，返回待确认补丁。
- 边界要求：① 只修正 schema 中存在的字段（未知字段忽略并提示）；② 修正不直接生效，进 pendingPatch 由用户确认；③ 日期类解析支持相对表达（下周三）；④ 多字段同时修正合并为一个补丁。

**答**：
```javascript
function applyCorrection(formState, text, schema) {
  const patch = {};
  const hints = [];
  for (const f of schema.fields) {
    const val = extractFieldIntent(text, f);       // 按字段类型解析意图
    if (val !== undefined) {
      if (f.validate && !f.validate(val)) {        // 解析值过 schema 校验
        hints.push(`${f.label} 解析值不合法：${val}`); continue;
      }
      patch[f.name] = f.type === 'date'
        ? resolveRelativeDate(val) : val;          // 相对日期归一化
    }
  }
  const unknown = extractUnknownIntent(text, schema);
  if (unknown) hints.push(`未识别的字段：${unknown}（可补充说明）`);
  return { ...formState,
    pendingPatch: Object.keys(patch).length ? patch : null,
    highlight: Object.keys(patch),                 // 高亮待确认字段
    hints };
}
function confirmPatch(formState) {
  if (!formState.pendingPatch) return formState;
  return { ...formState, values:
    { ...formState.values, ...formState.pendingPatch },
    pendingPatch: null, highlight: [] };
}
```

**评分点**:
- 修正只进 pendingPatch + 高亮（不静默修改，用户可确认/拒绝）。
- schema 校验与未知字段提示（解析失败显式反馈）。
- 相对日期在确认时归一化（confirmPatch 才落值）。
