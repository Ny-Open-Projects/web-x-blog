## AGT-695：手写 leakScan：运行时资产与评测用例相似度扫描、疑泄漏替换、盲测探针

**需求与边界**：
- 实现 leakScan(assets, cases, { sim = 0.9 })。
- 边界要求：① 资产（提示词/工具描述/知识库）与用例输入做嵌入相似度；② 相似 >阈值标疑泄漏，输出（用例/资产/相似度）三元组；③ 疑泄漏用例生成替换候选（同能力域+同难度+不同表述）；④ 盲测探针：月度新流量样本盲测分与评测分偏差 >5 分触发深度审查。

**答**：
```javascript
async function leakScan(assets, cases, { sim = 0.9 } = {}) {
  const aEmbs = assets.map(a => ({ a, e: embed(a.text) }));
  const suspects = [];
  for (const c of cases) {
    const e = embed(c.input);
    let best = null;
    for (const { a, e: ae } of aEmbs) {
      const s = cosine(e, ae);
      if (s > sim && (!best || s > best.sim)) best = { asset: a.id, sim: s };
    }
    if (best) suspects.push({ case: c.id, ...best });
  }
  const replacements = await Promise.all(suspects.map(s =>
    pickReplacement(s.case, { sameCap: true, sameDiff: true })));
  const blind = await monthlyBlindProbe();
  return { suspects, replacements,
    blindDeviation: blind.evalScore - blind.blindScore,
    deepAudit: Math.abs(blind.evalScore - blind.blindScore) > 5
      && 'review_pipeline',                       // 深度审查触发
  };
}
```

**评分点**:
- 全量交叉扫描取最大相似资产（归因到具体资产而非只报用例）。
- 疑泄漏即替换（同能力同难度），不删除能力维度覆盖。
- 盲测探针偏差 >5 分触发深度审查（防泄漏的第二道防线）。
