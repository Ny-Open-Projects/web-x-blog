## 1262：笔试手写：实现 降级链健康探测器

**答**：实现 healthProbe(chain)：chain 为 { name, check: () => Promise<{ ok, latencyMs }> }[]（按优先级排列）。并发探测全部节点，输出 { available: [可达节点按链序], recommended: 最优先可用节点, allDown }。探测超时 500ms 视为不可达；节点连续 3 次（本轮仅单次，用参数 failStreak 模拟）不可达时跳过探测直接标死。

```js
function healthProbe(chain, failStreak = {}, timeout = 500) {
  const withTimeout = p => Promise.race([
    p, new Promise(res => setTimeout(() => res({ ok: false, latencyMs: timeout }), timeout))
  ]);
  return Promise.all(chain.map(async node => {
    if ((failStreak[node.name] || 0) >= 3) return { name: node.name, ok: false, dead: true };
    const r = await withTimeout(node.check().catch(() => ({ ok: false, latencyMs: timeout })));
    return { name: node.name, ok: !!r.ok, latencyMs: r.latencyMs, dead: false };
  })).then(rs => {
    const available = rs.filter(r => r.ok).map(r => r.name); // 保持链序
    return {
      available,
      recommended: available[0] ?? null,
      allDown: available.length === 0,
    };
  });
}
```

**评分点**：
- Promise.race 实现探测超时（check 抛错也要接住）
- dead 节点跳过探测（failStreak 由调用方累积）
- available 保持链优先级顺序
- 能讨论：探测结果与运行时降级表（AGT-1044）的联动
