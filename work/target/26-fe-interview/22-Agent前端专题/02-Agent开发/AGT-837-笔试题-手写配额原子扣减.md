## AGT-837：手写 checkAndDeduct：Redis 原子 Lua、月度/突发双限、超额策略、退还接口

**需求与边界**：
- 实现 checkAndDeduct(tenant, tokens) 与 refund(tenant, tokens)。
- 边界要求：① Lua 脚本原子执行（检查+扣减不可分割）；② 双限：月度超配走策略（hard-stop/overage），突发超限返回 throttle 带 retryAfter；③ 任务失败退还已扣（按实际 usage 差额）；④ 并发安全（多实例同时扣不减爆）。

**答**：
```javascript
const DEDUCT_LUA = `
local month = redis.call('hget', KEYS[1], 'month') or 0
local burst = redis.call('hget', KEYS[1], 'burst') or 0
local mLimit = tonumber(redis.call('hget', KEYS[1], 'mLimit'))
local bLimit = tonumber(redis.call('hget', KEYS[1], 'bLimit'))
local t = tonumber(ARGV[1])
if tonumber(month) + t > mLimit then return {0, 'month'} end
if tonumber(burst) + t > bLimit then
  local retryAfter = tonumber(redis.call('hget', KEYS[1], 'retryAfter')) or 30
  return {0, 'burst', retryAfter}
end
redis.call('hincrby', KEYS[1], 'month', t)
redis.call('hincrby', KEYS[1], 'burst', t)
return {1}
`;
async function checkAndDeduct(tenant, tokens, policy) {
  const r = await redis.eval(DEDUCT_LUA, 1, `quota:${tenant}`, tokens);
  if (r[0] === 0 && r[1] === 'month')
    return policy.onMonthExceed(tenant);           // hard-stop/overage
  if (r[0] === 0 && r[1] === 'burst')
    return { ok: false, throttle: true, retryAfter: r[2] };
  return { ok: true };
}
async function refund(tenant, actual, prepaid) {
  const diff = prepaid - actual;
  if (diff > 0) await redis.hincrby(`quota:${tenant}`, 'month', diff);
  return diff;                                     // 差额退还
}
```

**评分点**:
- Lua 原子性（检查+扣减一个脚本，防并发超扣）；双限语义分开（月度走策略/突发走限流）。
- retryAfter 由配置带出；refund 按差额退还。
