## AGT-647：手写 ProgressWatchdog：阶段事件/心跳分离、进度停滞告警、恢复清理

**需求与边界**：
- 实现 ProgressWatchdog(task)：区分心跳（链路活）与进度（任务推进），进度停滞 >60s 告警。
- 边界要求：① heartbeat 重置链路计时不影响进度计时；② progress 事件重置停滞计时并记录最后阶段；③ 停滞告警只发一次，恢复（新进度）后清理并可再次触发；④ stop 后全部清理。

**答**：
```javascript
class ProgressWatchdog {
  constructor(task, { stallMs = 60000 } = {}) {
    this.task = task; this.stallMs = stallMs;
    this.lastProgress = Date.now(); this.alerted = false;
    this.stopped = false;
    task.on('heartbeat', () => { /* 只证链路活，不重置进度计时 */ });
    task.on('progress', () => this.touch());
    this.timer = setInterval(() => this.check(), 5000);
  }
  touch() {
    this.lastProgress = Date.now();
    if (this.alerted) { this.alerted = false;    // 恢复：清告警
      clearAlert(this.task.id); }
  }
  check() {
    if (this.stopped) return;
    if (!this.alerted
      && Date.now() - this.lastProgress > this.stallMs) {
      this.alerted = true;
      alert({ type: 'progress_stalled', traceId: this.task.traceId,
        lastStage: this.task.stage, stalledMs: Date.now() - this.lastProgress });
    }
  }
  stop() { this.stopped = true; clearInterval(this.timer); }
}
```

**评分点**:
- 心跳与进度计时分离（心跳活但进度停=疑似循环的核心判据）。
- 告警单次触发、恢复后可再触发；stop 清理定时器。
- 告警携带最后阶段与停滞时长（可行动）。
