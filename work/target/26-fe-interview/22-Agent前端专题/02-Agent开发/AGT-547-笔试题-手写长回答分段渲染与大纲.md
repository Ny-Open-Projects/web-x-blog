## AGT-547：手写 useLongAnswer：标题分块、大纲锚点、视口窗口渲染、类型过滤器

**需求与边界**：
- 实现 useLongAnswer(text)：按二级标题分块，输出 { blocks, outline, filter(type) }。
- 边界要求：① 块边界在标题行切分（标题归属其后内容）；② 无标题时整篇一块；③ outline 带唯一锚点（重复标题不冲突）；④ filter('code'|'conclusion'|'all') 返回过滤后块序列但保持原锚点。

**答**：
```javascript
const FENCE = '\u0060'.repeat(3);   // 围栏用码点构造，避免源码内出现字面围栏
function useLongAnswer(text) {
  return useMemo(() => {
    const lines = text.split('\n');
    const blocks = []; let cur = null; let seq = 0;
    for (const line of lines) {
      if (/^##\s+/.test(line)) {                 // 二级标题开新块
        cur = { id: `blk-${++seq}`, heading: line.replace(/^##\s+/, ''),
          lines: [line], type: 'section' };
        blocks.push(cur);
      } else {
        if (!cur) { cur = { id: `blk-0`, heading: '', lines: [],
          type: 'section' }; blocks.push(cur); }
        cur.lines.push(line);
      }
    }
    const typed = blocks.map(b => {
      b.content = b.lines.join('\n');
      b.blockType = new RegExp('^' + FENCE).test(b.content) ? 'code'
        : /结论|Summary/i.test(b.heading) ? 'conclusion' : 'text';
      return b;
    });
    const outline = typed.filter(b => b.heading).map(b => ({
      anchor: b.id, text: b.heading, level: 2 }));
    const filter = (t) => t === 'all' ? typed
      : typed.filter(b => b.blockType === t || b.blockType === 'text' && t === 'text');
    return { blocks: typed, outline, filter };
  }, [text]);
}
```

**评分点**:
- 分块边界正确（标题开新块、无标题整篇一块）。
- 锚点用自增序号防重复标题冲突。
- filter 保持块对象引用（锚点跳转不失效）。
