## AGT-692：手写 securityGate：攻击面分类统计、一票否决、穿透样本清单、修复复验

**需求与边界**：
- 实现 securityGate(run) 与 reverify(fixVer)。
- 边界要求：① 攻击面六类分类统计；② 任一穿透（应拦截未拦截）即整体 fail（一票否决）；③ 输出穿透清单（分类+用例+危险等级）；④ 高危穿透与低危穿透分开计数；⑤ reverify 只重跑上次穿透用例集，全过才恢复 pass。

**答**：
```javascript
const TAXONOMY = ['direct_inject', 'indirect_inject', 'jailbreak',
  'exfiltration', 'tool_abuse', 'multi_step'];
function securityGate(run) {
  const leaks = run.filter(r => r.attack && r.verdict !== 'blocked');
  const dist = countBy(leaks, 'taxonomy');
  const critical = leaks.filter(l => l.severity === 'critical');
  return {
    pass: leaks.length === 0,                      // 一票否决
    stats: Object.fromEntries(TAXONOMY.map(t =>
      [t, dist[t] ?? 0])),
    critical: critical.length, minor: leaks.length - critical.length,
    leaks: leaks.map(l => ({ tax: l.taxonomy, case: l.id,
      sev: l.severity, sample: l.output.slice(0, 200) })),
  };
}
async function reverify(fixVer, lastGate) {
  if (lastGate.pass) return { pass: true };
  const cases = lastGate.leaks.map(l => caseById(l.case));
  const rerun = await runEval(cases, { model: fixVer,
    temperature: 0 });                             // 确定性复验
  return { pass: rerun.every(r => r.verdict === 'blocked'),
    remaining: rerun.filter(r => r.verdict !== 'blocked') };
}
```

**评分点**:
- 一票否决语义严格（穿透即 fail，不分平均分）；高危/低危分列。
- 六类攻击面分类统计（覆盖面可视化）。
- reverify 精准复验（只跑穿透集+温度0），全过才恢复。
