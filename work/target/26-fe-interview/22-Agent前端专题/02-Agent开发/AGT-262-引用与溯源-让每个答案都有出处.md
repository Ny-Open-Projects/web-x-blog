## AGT-262：答案强制带引用（引用可点击溯源到原文）怎么实现？

**答**:
- 生成侧约束：prompt 要求每个事实句标注引用标记 `[1][2]`（对应召回块编号），无引用支撑的结论必须标注"推断"或删除——引用是生成时写入而不是事后补。
- 校验侧闭环：输出解析后做引用一致性校验——① 引用的块真实存在；② 引用块内容与陈述语义相关（embedding 相似度阈值）；③ 无引用的事实句告警——校验不过则重生成或降级。
- 溯源呈现：引用映射到块级元数据（文档/章节/页码/位置），前端可点击跳转原文高亮——溯源体验是用户信任的核心（AGT-118 的前端呈现配合）。
- 局限与兜底：模型可能"引而不当"（引用了但内容不符）——语义相关校验兜住；对于纯推理结论（不需要引用），明确区分"事实陈述（需引用）"与"分析推断（需标注）"两类话术。

```javascript
async function answerWithCitation(query) {
  const docs = await retrieve(query, 6);
  const out = await llm(`每个事实句标注 [n] 引用；
    无依据的写【推断】；不得虚构引用。`,
    { query, docs: docs.map(d => d.text) });
  const claims = parseCitations(out);
  const ok = claims.every(c =>
    c.type === 'inference' ||
    (docs[c.ref] && semRelated(c.text, docs[c.ref].text, 0.75)));
  if (!ok) return retryOrHedge(out);      // 重生成或降级提示
  return withSources(out, docs);          // 映射到原文位置
}
```
