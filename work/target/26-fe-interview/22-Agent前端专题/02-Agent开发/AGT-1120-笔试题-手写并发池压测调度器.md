## 1120：笔试手写：实现阶梯并发压测调度（带熔断）

**答**：实现 loadTest(tasks, opts)：tasks 为 () => Promise 数组。按 levels 阶梯并发：每级并发数 = level，共跑 perLevel 个任务（复用 tasks 循环取用）；记录每级 { level, p95, fails }（p95 对本级单任务耗时排序取 95 分位）；某级失败率超 failCut 立即停止后续级别。返回结果数组。

```js
async function loadTest(tasks, { levels = [10, 20, 40], perLevel = 50, failCut = 0.01 } = {}) {
  const results = [];
  for (const level of levels) {
    const lat = [], fails = [];
    let next = 0;                                     // 任务分发游标
    const worker = async () => {
      while (next < perLevel) {
        const t = tasks[next++ % tasks.length];
        const t0 = performance.now();
        try { await t(); } catch { fails.push(1); }
        lat.push(performance.now() - t0);
      }
    };
    await Promise.all(Array.from({ length: level }, worker));  // level 个并发
    lat.sort((a, b) => a - b);
    const p95 = lat.length ? lat[Math.ceil(lat.length * 0.95) - 1] : 0;
    results.push({ level, p95: Math.round(p95), fails: fails.length });
    if (fails.length / perLevel > failCut) break;      // 熔断停止加压
  }
  return results;
}
```

**评分点**：
- 并发模型正确：level 个 worker 循环领取任务（不是一次 Promise.all 全并发）
- p95 计算含空数组保护；游标 next++ 的领取语义正确
- 熔断条件在每级结束时判定
- 能讨论：真实压测还需 ramp-up 速率控制与预热、perLevel 与 level 的关系（level > perLevel 时有效并发上限）
