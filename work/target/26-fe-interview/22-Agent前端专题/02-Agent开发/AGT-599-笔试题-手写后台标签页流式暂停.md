## AGT-599：手写 visibility 感知流缓冲：隐藏攒包、回前台冲刷对账、低带宽整段模式

**需求与边界**：
- 实现 BackgroundAwareStream(stream)：页面隐藏时暂停渲染只攒 buffer。
- 边界要求：① hidden 期间 delta 只进 buffer 不写 DOM；② 回前台 flush 后与服务端 reconcile（拉 done 状态对账）；③ saveData/慢网模式自动切 buffered（完成才推整段）；④ flush 幂等（重复 visibilitychange 不重复渲染）。

**答**：
```javascript
class BackgroundAwareStream {
  constructor(stream, net) {
    this.stream = stream; this.buf = '';
    this.mode = net.saveData || net.effectiveType === 'slow-2g'
      ? 'buffered' : 'live';                     // 低带宽整段模式
    this.onVis = () => {
      if (document.hidden) { this.paused = true; }
      else if (this.paused) { this.paused = false; this.flush(); }
    };
    document.addEventListener('visibilitychange', this.onVis);
    stream.on('delta', d => this.onDelta(d));
    stream.on('done', f => this.final = f);
  }
  onDelta(d) {
    if (this.mode === 'buffered') return;       // 整段模式：不渲染
    if (this.paused) { this.buf += d; return; } // 隐藏：只攒不渲染
    renderDelta(d);
  }
  flush() {
    if (this.buf) { renderDelta(this.buf); this.buf = ''; }  // 幂等：清空后不再渲染
    if (this.final) reconcile(this.stream.turnId, this.final.hash);
  }
  dispose() {
    document.removeEventListener('visibilitychange', this.onVis);
  }
}
```

**评分点**:
- 隐藏攒包/回前台冲刷，flush 幂等（buf 清空判据）。
- 低带宽自动整段模式（saveData 探测），节流省电。
- done 状态哈希对账（后台丢失的包由服务端权威补齐）。
