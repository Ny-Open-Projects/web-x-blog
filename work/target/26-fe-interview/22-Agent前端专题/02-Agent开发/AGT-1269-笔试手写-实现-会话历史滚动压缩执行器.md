## 1269：笔试手写：实现 会话历史滚动压缩执行器

**答**：实现 compactHistory(messages, budget)：messages 为 { role, content, tokens }[]。保留 system 全部、最近 keep=6 条、其余中段若 tokens 超额则合并为一条 summary 占位（content: '[摘要] ...'，tokens 记 200）；压缩后总 tokens 不超 budget 时返回 compacted: true，仍超则再砍最早的非 system 消息直到达标。返回 { messages, compacted, totalTokens }。

```js
function compactHistory(messages, budget, keep = 6) {
  const sys = messages.filter(m => m.role === 'system');
  const rest = messages.filter(m => m.role !== 'system');
  const tail = rest.slice(-keep), mid = rest.slice(0, -keep);
  let out = [...sys];
  if (mid.length) {
    const sumTokens = mid.reduce((s, m) => s + m.tokens, 0);
    out.push({ role: 'assistant', content: '[摘要] ' + mid.length + ' 轮已压缩', tokens: 200 });
    // 真实实现此处调用模型生成摘要；笔试以占位符表达结构
  }
  out.push(...tail);
  let total = () => out.reduce((s, m) => s + m.tokens, 0);
  const compacted = mid.length > 0;
  let i = 0;
  const trimmable = () => out.filter(m => m.role !== 'system');
  while (total() > budget && trimmable().length > 1) {
    const idx = out.findIndex(m => m.role !== 'system'); // 砍最早非 system
    out.splice(idx, 1);
  }
  return { messages: out, compacted, totalTokens: total() };
}
```

**评分点**：
- system 永不压缩、tail 保留（窗口语义）
- 中段合并为摘要占位（token 记账用常数近似）
- 仍超预算时从最早的继续砍（两级策略）
- 能讨论：压缩发生在写入时还是读取时（成本/延迟权衡）
