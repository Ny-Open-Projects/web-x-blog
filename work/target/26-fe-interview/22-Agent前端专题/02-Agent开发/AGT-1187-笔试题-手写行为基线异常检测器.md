## 1187：笔试手写：实现基于分位数基线的 Agent 行为异常检测

**答**：实现 zscore(x, q)：q 为 { p50, p90 }（分位数），z 近似 = (x - p50) / max(p90 - p50, 1e-9)。实现 detect(cur, baseline)：cur = { tool, paramsLen, tokensPerMin }；规则：工具在 FORBIDDEN 集 → { level: 'hard' }；paramsLen 或 tokensPerMin 的 z > 3 → { level: 'soft' }；否则 'ok'。quantile(arr, p) 线性插值实现。

```js
function quantile(arr, p) {
  if (!arr.length) return NaN;
  const s = [...arr].sort((a, b) => a - b);
  const idx = (s.length - 1) * p;
  const lo = Math.floor(idx), hi = Math.ceil(idx);
  return s[lo] + (s[hi] - s[lo]) * (idx - lo);     // 线性插值
}
function zscore(x, q) {
  return (x - q.p50) / Math.max(q.p90 - q.p50, 1e-9); // 防除零
}
function detect(cur, baseline, FORBIDDEN) {
  if (FORBIDDEN.has(cur.tool)) return { level: 'hard', reason: 'forbidden tool' };
  const zp = zscore(cur.paramsLen, baseline.params);
  const zc = zscore(cur.tokensPerMin, baseline.costRate);
  if (Math.abs(zp) > 3 || Math.abs(zc) > 3)
    return { level: 'soft', reason: `z=${zp.toFixed(1)}/${zc.toFixed(1)}` };
  return { level: 'ok' };
}
const b = { params: { p50: 10, p90: 15 }, costRate: { p50: 100, p90: 150 } };
console.log(detect({ tool: 'fs.read', paramsLen: 60, tokensPerMin: 110 }, b, new Set()));
// { level: 'soft', reason: 'z=10.0/0.2' }
```

**评分点**：
- 分位数线性插值实现正确（非简单取整）
- z 近似的分母保护与方向（偏离任一侧都算，用绝对值）
- hard 规则优先于统计规则（先硬后软）
- 能讨论：单侧偏离更合理（成本暴增危险、暴降也可能是故障）、基线随版本重建的必要性
