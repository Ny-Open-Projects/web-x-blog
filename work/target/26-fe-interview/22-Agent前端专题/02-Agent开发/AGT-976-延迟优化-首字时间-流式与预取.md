## 976：Agent 回答很慢，怎么压首字时间（TTFT）

**答**：
- 首字时间的构成：检索耗时 + prompt 组装 + 模型首 token；三段分别埋点，先找最大头再优化——多数系统检索占了 40% 以上。
- 检索段优化：embedding 结果缓存、索引预热、候选数收敛；生成段优化：流式输出（SSE）+ prompt 前缀缓存（system prompt 和工具定义放前面命中 KV cache）。
- 预取：用户开始输入时就推测性预检索（用输入前缀做 query），提交时命中预取结果直接生成，省掉整个检索 RTT。
- 追问钩子：流式输出的首字更快但总时长不变，值得吗？——值得，感知延迟由首字决定，TTFT 从 3s 到 800ms 用户满意度差异巨大。

```ts
async function chat(q, { prefetch }) {
  const t = mark();                       // 三段分别埋点
  const pre = prefetch?.hits ?? null;     // 输入期预取的检索结果
  const hits = pre || await retrieve(q);
  t('retrieve');
  const stream = await llm.stream(buildPrompt(hits, q), {
    promptCache: { system, tools },       // 前缀缓存命中 KV cache
  });
  t('ttfb');                              // 首 token 时间单独上报
  return stream;
}
```
