## AGT-839：手写 runLimited：多维限额、超限杀进程、部分输出保留、审计

**需求与边界**：
- 实现 runLimited(fn, limits)。
- 边界要求：① 限额四维：时长/CPU（近似用时长）/内存（监测不可行时用输出量代理）/输出大小；② 超时用 AbortController 级联取消；③ 超限返回部分输出（已产生的）+killed 原因；④ 输出超限截断标记；⑤ kill 写审计。

**答**：
```javascript
async function runLimited(fn, { timeoutMs = 5000, maxOut = 1e6 } = {}) {
  const ac = new AbortController();
  const chunks = []; let outBytes = 0; let killed = null;
  const timer = setTimeout(() => { killed = 'timeout';
    ac.abort(); }, timeoutMs);
  try {
    const result = await fn({
      signal: ac.signal,
      emit: (chunk) => {                           // 流式输出带限额
        outBytes += chunk.length;
        if (outBytes > maxOut) { killed = 'output-limit';
          ac.abort(); return; }
        chunks.push(chunk);
      },
    });
    return { ok: true, output: chunks.join(''), usage: { outBytes } };
  } catch (e) {
    if (aborted(e)) {
      audit.log({ type: 'sandbox.kill', reason: killed ?? 'error' });
      return { ok: false, killed: killed ?? 'error',
        partial: chunks.join(''),                  // 部分输出保留
        truncated: outBytes > maxOut };
    }
    throw e;
  } finally { clearTimeout(timer); }
}
```

**评分点**:
- 超时 AbortController 级联取消（不泄漏执行）；输出量代理内存限额。
- 超限返回部分输出+killed 原因+truncated 标记；kill 必审计。
- finally 清理定时器。
