## AGT-642：手写 depHealth + watch：三指标健康度、状态判定、联动降级、结构漂移告警

**需求与边界**：
- 实现 DepMonitor：record(dep, result)/health(dep)/watch(dep, cb)。
- 边界要求：① 三指标：成功率/P95延迟/参数错误率（区分依赖方故障与我方姿势问题）；② 状态 healthy/degraded/down 阈值 0.98/0.9；③ 状态跃迁触发 watch 回调（只在跃迁时触发一次）；④ 结果 schema 校验失败单独计 schemaDrift。

**答**：
```javascript
class DepMonitor {
  constructor() { this.win = new Map(); this.status = new Map(); }
  record(dep, r) {
    const w = this.win.get(dep) ?? { ok: 0, total: 0, argErr: 0,
      schemaDrift: 0, lats: [] };
    w.total++;
    if (r.ok) w.ok++;
    else if (r.errType === 'arg') w.argErr++;      // 我方参数错误
    else if (r.errType === 'schema') w.schemaDrift++; // 结构漂移
    if (r.latMs) w.lats.push(r.latMs);
    this.win.set(dep, w);
    const h = this.health(dep);
    const prev = this.status.get(dep);
    if (h.status !== prev) {                        // 跃迁才触发
      this.status.set(dep, h.status);
      this.watchers.get(dep)?.forEach(cb =>
        cb({ dep, from: prev, to: h.status, health: h }));
    }
  }
  health(dep) {
    const w = this.win.get(dep);
    const okRate = w.total ? w.ok / w.total : 1;
    const p95 = percentile(w.lats, 0.95);
    return { okRate, p95, argErrRate: w.argErr / (w.total || 1),
      schemaDrift: w.schemaDrift,
      status: okRate < 0.9 ? 'down' : okRate < 0.98 ? 'degraded' : 'healthy' };
  }
  watch(dep, cb) {
    (this.watchers.get(dep) ?? this.watchers.set(dep, []).get(dep)).push(cb);
  }
}
monitor.watch('tool.crm_query', ({ to, health }) => {
  if (to === 'down') runtime.degrade('crm_query', { to: 'cached' });
  if (health.schemaDrift > 0) alert({ type: 'schema_drift' }); // 漂移独立告警
});
```

**评分点**:
- argErr 与 schemaDrift 与依赖故障分开计数（归因不混）。
- 状态阈值分级且跃迁才触发回调（防风暴）。
- 结构漂移独立告警（先于硬故障发现问题）。
