## AGT-616：线上 trace 数据如何回流成为评测用例（形成质量闭环）

**答**：
- 三条回流通道：负反馈样本（点踩/重新生成）→ 直接进评测候选池；抽样回流（按难度/租户分层抽样）→ 保持评测集分布与线上一致；边界样本（长输入/多工具/失败重试成功）→ 定向采集避免评测集全是简单 case。
- 回流管线带清洗：脱敏、去重、标注期望答案（人工或强模型辅助 + 抽检），未经清洗不进评测集。
- 闭环度量：评测集覆盖率（线上 case 被评测集代表的程度）、用例激活率（回流的用例中真正进回归的比例）。

```javascript
function refluxTraces(traces) {
  const pool = [
    ...traces.filter(t => t.dislike || t.regen),        // 负反馈优先
    ...stratifiedSample(traces, { by: ['tenant', 'taskType'] }),
    ...traces.filter(t => t.edgeFlags?.length),         // 边界样本
  ];
  return pool.map(c => clean(c))                        // 脱敏去重
    .filter(c => c.annotated)                           // 未标注不进
    .map(addToEvalPool);
}
```
