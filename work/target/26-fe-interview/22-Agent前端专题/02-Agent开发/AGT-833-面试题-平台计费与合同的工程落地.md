## AGT-833：合同里超出配额按量计费这种条款，工程上怎么准确落地不出纠纷

**答**：
- 条款→配置：合同条款结构化（配额/单价/加价系数/超额策略/有效期）录入合同配置中心，计费引擎只读配置不硬编码——条款变更=配置变更+生效日期，不做代码发布。
- 计费可复现：每笔账单可回放到明细（哪些请求/单价快照/系数），争议时 10 分钟出对账单；出账前 dry-run 预览给租户确认。
- 边界场景预案：跨月任务、重试扣不扣费（平台承担）、缓存命中折扣、免费额度顺序——每条写进计费文档并在账单明细中体现。

```javascript
const contractConfig = {
  quota: 10_000_000, unitPrice: {...}, factor: 1.15,
  overage: 'billed', effectiveFrom: '2026-01-01',
};
function invoice(tenant, month) {
  const cfg = contracts.at(tenant, month);        // 按生效日期取配置
  const detail = gateway.usage(tenant, month)
    .map(r => lineItem(r, cfg));                  // 每笔可回放
  return { detail, dryRun: true };                // 出账前预览
}
```
