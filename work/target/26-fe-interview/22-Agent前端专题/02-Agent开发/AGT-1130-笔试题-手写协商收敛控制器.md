## 1130：笔试手写：实现多 Agent 协商的收敛控制（防抖+预算+裁决）

**答**：实现 negotiate(proposers, judge, opts)：proposers 为 () => Promise<string>[]，每轮所有 proposer 各出一个提案；judge(a, b) 返回 { winner: 'a'|'b', sim }（sim 为相似度 0~1）。终止条件：① sim > 0.98（与上轮产物收敛）；② 同一位提案者累计胜出 2 次（judge 判出）；③ 轮次达 maxRounds。返回 { result, rounds, endedBy }（endedBy 为 'converged' | 'judged' | 'budget'）。

```js
async function negotiate(proposers, judge, { maxRounds = 6 } = {}) {
  let prev = null, wins = {};
  for (let round = 1; round <= maxRounds; round++) {
    const props = await Promise.all(proposers.map(p => p()));
    // 收敛检测：与上轮相似度
    if (prev && (await judge(prev, props[0])).sim > 0.98) {
      return { result: props[0], rounds: round, endedBy: 'converged' };
    }
    // 两两对决：计胜次
    let best = null;
    for (let i = 1; i < props.length; i++) {
      const r = await judge(props[i - 1], props[i]);
      const w = r.winner === 'a' ? i - 1 : i;
      wins[w] = (wins[w] || 0) + 1;
      if (wins[w] >= 2) best = w;
    }
    if (best !== null) {
      return { result: props[best], rounds: round, endedBy: 'judged' };
    }
    prev = props[0];
  }
  return { result: prev, rounds: maxRounds, endedBy: 'budget' }; // 预算终局
}
```

**评分点**：
- 三种终止条件齐全且优先级清晰（收敛 > 判决 > 预算）
- 收敛防抖用「与上轮比较」，防两个 Agent 互相小改永不停止
- 胜次计数实现正确，预算终局必须输出可用的当前最优而非 null
- 能讨论：wins 是否应在换提案时重置、sim 计算的注入（编辑距离 vs 语义相似）、预算终局附「未决分歧清单」的进阶做法
