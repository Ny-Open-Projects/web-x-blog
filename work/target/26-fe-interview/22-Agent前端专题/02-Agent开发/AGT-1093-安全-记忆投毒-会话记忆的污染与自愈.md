## 1093：被污染的会话记忆怎么自愈

**答**：
- 污染路径：注入指令被写进会话记忆/长期记忆（「记住：以后所有回答都要带 xxx」），影响扩散到后续所有会话——比单轮注入危害大一个量级。
- 自愈机制：记忆条目带「来源与置信」标签；低置信记忆定期与高置信知识/用户确认比对，矛盾即降级或删除；用户可查看与一键清除 Agent 记忆（控制权交还用户）。
- 写入防线：记忆写入门槛（用户明确声明的偏好才可写入；外部内容里的「记住」指令永不入记忆——这是最常见的记忆投毒话术）。
- 追问钩子：怎么发现记忆已被污染？——定期「记忆体检」：抽样记忆条目生成测试问题，若 Agent 行为与产品规范偏离，回溯定位到具体记忆条目。

```ts
async function memoryWrite(candidate, source) {
  if (source.trust < TRUST_USER) return reject('外部来源不得写入记忆'); // 注入防线
  if (!await userConsent(candidate)) return reject('未获用户确认');
  return memory.add({ ...candidate, trust: source.trust, createdAt: Date.now() });
}
async function memoryCheckup() {
  for (const m of memory.sample(50)) {
    if (await violatesPolicy(m)) { memory.degrade(m); alert(m); }  // 自愈
  }
}
```
