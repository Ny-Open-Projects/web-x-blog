## AGT-694：手写 validateVariant：语义不变校验、金标一致性、坏变体丢弃记录

**需求与边界**：
- 实现 validateVariant(variant, seed)：判断扰动变体是否可用。
- 边界要求：① 语义相似度（原输入与变体嵌入）>0.85；② 金标一致性：变体跑 3 次温度0，与种子用例金标判定一致 ≥2/3；③ 实体扰动合法（换的地名/数量在金标期望的参数范围内仍成立）；④ 不合格变体丢弃并记录原因（sim_low/golden_drift/param_out）。

**答**：
```javascript
async function validateVariant(v, seed) {
  const sim = cosine(embed(v.input), embed(seed.input));
  if (sim <= 0.85)
    return { ok: false, reason: 'sim_low', sim };
  const paramOk = seed.golden.paramsAllow(v.entities);  // 实体扰动合法
  if (!paramOk) return { ok: false, reason: 'param_out' };
  const runs = await Promise.all([1, 2, 3].map(() =>
    runEval([{ ...v, temperature: 0 }], { quick: true })));
  const consistent = runs.filter(r =>
    verdictEqual(r.verdict, seed.golden.verdict)).length;
  if (consistent < 2)
    return { ok: false, reason: 'golden_drift', consistent };
  return { ok: true, sim, consistent };
}
// 批量：产出可用变体池并留存拒绝日志
async function augment(seedCases, n) {
  const accepted = [], rejected = [];
  for (const s of seedCases) {
    for (const v of await genVariants(s, n)) {
      const r = await validateVariant(v, s);
      (r.ok ? accepted : rejected).push(r.ok ? v : { v, ...r });
    }
  }
  return { accepted, rejected,            // 拒绝日志供人工复核
    note: '拒绝日志抽查可发现生成策略缺陷' };
}
```

**评分点**:
- 三重校验（语义相似/实体合法/金标一致）缺一不可，坏变体必拒。
- 金标一致性 2/3 温度0 复跑（容忍偶发）。
- 拒绝日志留档（可反查生成策略缺陷）。
