## AGT-726：白板照片/手写笔记这类非正式内容进库的质量门槛怎么定

**答**：
- 三道门槛：可读性（OCR/识别置信度）、可解释性（描述能否概括主要内容）、可检索性（入库试跑检索看能否被合理 query 命中）——手写潦草内容三关全挂就明确拒收并引导用户转文字。
- 白板/手写专项：手写识别单独模型与置信阈值，识别失败给"转写辅助"交互（模型给出猜测，用户确认修正后入库）——用户校对一遍的内容质量远高于硬塞。
- 拒收的体验设计：给出具体原因（"第 2 页模糊无法识别"）与自助修复路径（重拍/转文字），不静默丢弃。

```javascript
async function ingestInformal(img) {
  const ocr = await handwritingOCR(img);
  if (ocr.conf < 0.6) {
    const guess = await suggestTranscription(img);  // 转写辅助
    return ui.confirmTranscribe(guess);             // 用户校对后入库
  }
  const hit = await dryRunRetrieval(img, { probes: 5 }); // 可检索性试跑
  if (hit.none) return reject(img, { reason: 'unsearchable',
    hint: '内容与现有知识库主题无关或过潦草' });
  return index(img, ocr);
}
```
