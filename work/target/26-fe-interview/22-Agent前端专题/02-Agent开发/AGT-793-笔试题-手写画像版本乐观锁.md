## AGT-793：手写 patchProfile：版本号校验、409冲突重试、字段级LWW、审计

**需求与边界**：
- 实现 patchProfile(userId, patch, { since })。
- 边界要求：① 版本号不匹配返回 409 带当前版本；② 重试由调用方决定（服务端不自动合并）；③ 字段级冲突检测（patch 只含过期字段时可部分成功）；④ 每次成功写入版本+1 并写审计；⑤ 空 patch 拒绝。

**答**：
```javascript
async function patchProfile(userId, patch, { since } = {}) {
  if (!patch || !Object.keys(patch).length)
    throw new Error('EMPTY_PATCH');
  const cur = await store.getProfile(userId);      // { rev, fields }
  if (since !== undefined && since !== cur.rev)
    return { status: 409, currentRev: cur.rev };   // 版本冲突
  const conflicts = Object.keys(patch).filter(k =>
    cur.fieldRev?.[k] && since !== undefined
    && cur.fieldRev[k] > since);
  const applied = Object.fromEntries(
    Object.entries(patch).filter(([k]) => !conflicts.includes(k)));
  if (!Object.keys(applied).length)
    return { status: 409, conflicts, currentRev: cur.rev };
  const rev = cur.rev + 1;
  await store.putProfile(userId, {
    fields: { ...cur.fields, ...applied },
    fieldRev: { ...cur.fieldRev, ...Object.fromEntries(
      Object.keys(applied).map(k => [k, rev])) },
    rev,
  });
  audit.log({ userId: hashId(userId), rev, patch: applied,
    at: Date.now() });
  return { status: 200, rev, partial: conflicts.length > 0,
    conflicts };
}
```

**评分点**:
- 版本乐观锁 + 409 带当前版本（客户端可决定重试）。
- 字段级冲突检测支持部分成功（fieldRev 细粒度）。
- 空 patch 拒绝；审计不含明文敏感（hashId）。
