## 1240：笔试手写：实现评估样本入库前的脱敏与校验

**答**：实现 sanitizeCase(case, keep, masks)：masks 为正则数组（姓名/手机号），命中的片段替换为占位 [MASK-n]（同片段同占位——可逆映射）；keep 为不脱敏的术语。返回 { safe: { query, goldAnswer }, map }（占位->原文映射，加密语义由调用方处理）。保证 query 与 goldAnswer 中相同片段映射一致。

```js
function sanitizeCase(c, keep, masks) {
  const map = new Map(); let seq = 0;
  function mask(text) {
    let out = text;
    for (const re of masks) {
      out = out.replace(re, m => {
        if (keep.some(k => m.includes(k))) return m;     // 术语豁免
        if (!map.has(m)) map.set(m, `[MASK-${++seq}]`);
        return map.get(m);
      });
    }
    return out;
  }
  return {
    safe: { query: mask(c.query), goldAnswer: mask(c.goldAnswer) },
    map: Object.fromEntries(map),
  };
}
const c = { query: '张三的订单 13812345678 多少钱', goldAnswer: '张三的订单 13812345678 是 99 元' };
console.log(sanitizeCase(c, ['订单'], [/1\d{10}/g, /张三/g]));
// 同手机号同占位 [MASK-1]；张三 [MASK-2]；两字段映射一致
```

**评分点**：
- 同片段同占位（映射一致性——脱敏后仍可对齐）
- keep 术语豁免（脱敏不失真的平衡）
- 映射返回（可逆受控——加密语义交调用方）
- 能讨论：占位碰撞（不同原文映射同占位的边界）、评估意义保留与隐私的最小化权衡
