## AGT-763：基于记忆的主动推荐（例如你上次的问题有更新了）如何设计而不变成打扰

**答**：
- 主动服务三条件：相关性（新信息确实影响用户此前的关切）、时机（用户回来时呈现而非推送打扰）、可关闭（用户关掉后长期尊重，同类推荐冷却）。
- 触发机制：记忆订阅（用户关注的话题/文档有更新）→ 生成轻量提醒卡（一句话+跳转），不生成完整回答（点开才算数，成本可控）。
- 节流与优先级：同一时间最多 1 张提醒卡，低置信关联不触发；提醒被忽略 3 次自动降级为列表项（不再弹卡）。

```javascript
async function proactiveCheck(user) {
  const subs = await memory.subscriptions(user);
  const updates = await detectUpdates(subs, { since: user.lastVisit });
  const top = rankByRelevance(updates, user.profile)[0];
  if (!top || top.confidence < 0.7) return null;
  if (await ignored(user, top.topic) >= 3)
    return listOnly(top);                          // 忽略3次降级
  return reminderCard({ text: `你关注的「${top.topic}」有更新：${top.brief}`,
    cta: top.url });
}
```
