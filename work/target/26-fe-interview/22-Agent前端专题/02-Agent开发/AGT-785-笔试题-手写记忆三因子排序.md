## AGT-785：手写 rankMemories：相似/时近/重要性加权、指数衰减、预算截断、归因分数

**需求与边界**：
- 实现 rankMemories(query, memories, budget)。
- 边界要求：① score = 0.5*sim + 0.3*recency + 0.2*importance，recency = exp(-Δ天/14)；② importance ∈[0,1]，缺省 0.5；③ 按预算（token）贪心装入，单条超预算跳过（不截断半条）；④ 空输入返回空；⑤ 结果带 score 分解（可归因）。

**答**：
```javascript
const TOKENS = (s) => Math.ceil(s.length / 2);
function rankMemories(query, memories, budget) {
  const qEmb = embed(query);
  return memories.map(m => {
    const sim = cosSim(qEmb, m.emb ?? embed(m.statement));
    const days = (Date.now() - m.at) / 864e5;
    const recency = Math.exp(-days / 14);           // 半衰期14天
    const imp = m.importance ?? 0.5;
    const score = 0.5 * sim + 0.3 * recency + 0.2 * imp;
    return { ...m, score,
      parts: { sim, recency, imp } };               // 分数分解
  }).sort((a, b) => b.score - a.score)
    .reduce(({ picked, used }, m) => {
      const t = TOKENS(m.statement);
      if (used + t <= budget && t <= budget)        // 单条超预算跳过
        { picked.push(m); used += t; }
      return { picked, used };
    }, { picked: [], used: 0 }).picked;
}
```

**评分点**:
- 三因子公式正确，recency 指数衰减（半衰期语义）。
- 贪心装包按 token 预算，单条超预算跳过（不留半条垃圾）。
- score.parts 分解可归因（调权重时有依据）。
