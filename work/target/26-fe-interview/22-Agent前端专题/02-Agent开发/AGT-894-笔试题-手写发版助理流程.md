## AGT-894：手写 releaseAssistant：dry-run计划、人工确认、步进执行失败即停、回滚到步

**需求与边界**：
- 实现 releaseAssistant(branch, { confirm })。
- 边界要求：① 先出 dry-run 计划（版本号/变更清单/tag）；② 无 confirm 拒绝执行（生产发布人工确认）；③ 步进执行六步（ciGreen/changelog/bump/tag/notes/notify），任一步失败停止并回滚到已完成步骤的可回滚项（tag 可删）；④ 全程动作留痕。

**答**：
```javascript
const STEPS = [
  ['ciGreen', { undoable: false }],
  ['changelog', { undoable: true }],
  ['bumpVersion', { undoable: true }],
  ['tag', { undoable: true }],                     // tag可删
  ['notes', { undoable: true }],
  ['notify', { undoable: false }],
];
async function releaseAssistant(branch, { confirm = false, log } = {}) {
  const plan = await planRelease(branch);          // dry-run
  if (!confirm)
    return { plan, needConfirm: true };            // 无确认拒绝
  const done = [];
  for (const [name, meta] of STEPS) {
    const r = await runStep(name, plan);
    log?.({ step: name, ok: r.ok, at: Date.now() }); // 留痕
    if (!r.ok)
      return { aborted: name,
        rolledBack: await undoAll(done, meta) };   // 失败即停回滚
    done.push([name, meta]);
  }
  return { released: plan.version, steps: done.map(d => d[0]) };
}
async function undoAll(done) {
  for (const [name, meta] of done.reverse())
    if (meta.undoable) await undoStep(name);       // 只回滚可逆步骤
}
```

**评分点**:
- dry-run+强制人工确认（生产发布不自动化到底）。
- 步进失败即停；回滚只做可逆步骤（notify 等不可逆如实标注）。
- 全程留痕（步级日志）。
