## AGT-842：手写 DataFlowGuard：密级标记、工具白名单、组合工具链检查、拦截审计

**需求与边界**：
- 实现 DataFlowGuard：mark(data, level)/canFlow(data, tool)/audit。
- 边界要求：① 数据带密级（public/internal/restricted）；② 工具声明可接收密级上限；③ 工具链组合检查：读 restricted 的结果流向 mail（上限 internal）必须拦截；④ 派生数据继承最高密级（restricted 摘要仍 restricted）；⑤ 拦截写审计带原因。

**答**：
```javascript
const LEVELS = { public: 0, internal: 1, restricted: 2 };
class DataFlowGuard {
  constructor() { this.flows = new Map(); }
  mark(id, level, data) {
    this.flows.set(id, { level, data, derivedFrom: null });
    return id;
  }
  derive(newId, sourceIds, data) {
    const lv = Math.max(...sourceIds.map(id =>
      this.flows.get(id).level));                  // 派生继承最高密级
    this.flows.set(newId, { level: lv, data });
    return newId;
  }
  canFlow(dataId, tool) {
    const d = this.flows.get(dataId);
    const cap = LEVELS[tool.maxLevel ?? 'public'];
    const ok = d.level <= cap;
    if (!ok)
      audit.log({ type: 'dataflow.blocked', tool: tool.name,
        level: d.level, cap: tool.maxLevel });     // 拦截审计
    return ok;
  }
}
// 场景：读CRM(restricted) → 发邮件(internal) 必须拦截
guard.mark('crm-res', 'restricted', rows);
guard.canFlow('crm-res', { name: 'mail', maxLevel: 'internal' }); // false
```

**评分点**:
- 密级三档+工具上限声明；派生数据继承最高密级（摘要不降密——关键防绕过）。
- 拦截带审计（工具/密级/上限），流检查在调用前。
