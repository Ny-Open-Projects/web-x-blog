## AGT-700：手写 evalHealthCheck：四环元数据完整性、反模式检测、成熟度评分、改进清单

**需求与边界**：
- 实现 evalHealthCheck(state)：对评测体系做整体自检。
- 边界要求：① 四环检查（生产/执行/判定/消费）各自的元数据完整率；② 反模式检测（安慰剂集/judge未校准/只增不减/业务脱节）逐项布尔；③ 成熟度分 = 环完整率加权 - 反模式扣分，0~100；④ 输出按影响排序的改进清单（最多 5 条）。

**答**：
```javascript
function evalHealthCheck(state) {
  const rings = {
    produce: metaRate(state.cases, ['cap', 'diff', 'source', 'rubricVer']),
    execute: metaRate(state.runs, ['tier', 'cacheHit', 'cost']),
    judge: metaRate(state.judgements, ['judgeVer', 'calibrated']),
    consume: metaRate(state.decisions, ['ruleVer', 'snapshot']),
  };
  const anti = {
    placebo: state.cases.every(c => c.diff === 'easy'),      // 全简单=安慰剂
    judgeUncalibrated: !state.lastCalibration
      || daysSince(state.lastCalibration) > 30,
    onlyGrow: state.caseGrowth > 0.3 && state.passRateDelta > 0.15, // 只增不减
    disconnect: state.alignment.disconnectRate > 0.1,
  };
  const ringAvg = avg(Object.values(rings));
  const score = Math.round(ringAvg * 80
    - 5 * Object.values(anti).filter(Boolean).length);
  const fixes = [
    anti.judgeUncalibrated && '立即校准 judge（金标集）',
    anti.disconnect && '重修评测判据（对齐北极星）',
    anti.onlyGrow && '退役过易用例（难度重标定）',
    anti.placebo && '补充 mid/hard 用例',
    ...Object.entries(rings).filter(([, v]) => v < 0.9)
      .map(([k, v]) => `补齐 ${k} 环元数据（当前 ${Math.round(v * 100)}%）`),
  ].filter(Boolean).slice(0, 5);
  return { rings, anti, score: Math.max(0, Math.min(100, score)), fixes };
}
```

**评分点**:
- 四环元数据完整率量化（环咬合的落地检查）。
- 四反模式判据可计算（非主观打勾）。
- 成熟度分有加减逻辑且夹取 0~100；改进清单按影响排序且 ≤5 条（可执行）。
