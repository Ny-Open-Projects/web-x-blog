## AGT-800：手写 fairnessAudit：画像分组质量对比、差异比计算、阈值触发、保底策略建议

**需求与边界**：
- 实现 fairnessAudit(users, metrics)。
- 边界要求：① 按画像置信度三组（高/中/低）分组统计 dislikeRate/doneRate；② 差异比 = 最大组 dislikeRate / 最小组（除零保护），>2 触发 review；③ 低置信组给出保底建议（通用模板轮数）；④ 输出组样本量（小样本组标注不可比）；⑤ 结果可序列化存档（趋势对比）。

**答**：
```javascript
function fairnessAudit(users, metrics, { threshold = 2 } = {}) {
  const groups = groupBy(users, u =>
    u.profileConfidence > 0.7 ? 'high'
      : u.profileConfidence > 0.4 ? 'mid' : 'low');
  const rows = Object.entries(groups).map(([name, us]) => ({
    name, n: us.length,
    dislike: rate(metrics, us, 'dislike'),
    done: rate(metrics, us, 'done'),
    comparable: us.length >= 200,                  // 小样本标注
  }));
  const comparable = rows.filter(r => r.comparable);
  const rates = comparable.map(r => r.dislike);
  const spread = Math.max(...rates) / (Math.min(...rates) || 1e-9);
  return { rows, spread,
    alarm: spread > threshold && 'review-policy',
    advice: rows.find(r => r.name === 'low')
      ? { baseline: '低置信组前 10 轮使用通用高质量模板',
        onboarding: '引导完成画像三问' } : null,
    at: Date.now() };                              // 可存档对比
}
```

**评分点**:
- 三组分组 + 差异比计算含除零保护；小样本组标注不可比（不误报）。
- 阈值触发 review；低置信组给可执行保底建议。
- 时间戳留档支持趋势对比。
