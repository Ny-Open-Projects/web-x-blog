## 1284：笔试手写：实现 长任务里程碑校验器

**答**：实现 checkMilestones(plan, artifacts)：plan 为 { id, requires: string[] }[]（步骤依赖产物），artifacts 为已产出产物 id 集合。逐步骤判定：requires 全部在 artifacts 或可由已完成步骤产出 → 可执行；否则标记 blocked 并记录缺失产物。输出执行波次（每波可并行执行的步骤分组），无法推进时输出 stalled: true 与缺失清单。

```js
function checkMilestones(plan, artifacts) {
  const have = new Set(artifacts);
  const waves = [];
  const pending = [...plan];
  const missing = [];
  while (pending.length) {
    const ready = pending.filter(s => s.requires.every(r => have.has(r)));
    if (!ready.length) { // 无可推进 → 卡死
      for (const s of pending)
        missing.push({ id: s.id, missing: s.requires.filter(r => !have.has(r)) });
      return { waves, stalled: true, missing };
    }
    for (const s of ready) { s.requires.forEach(r => have.add(r)); have.add(s.id); }
    waves.push(ready.map(s => s.id));
    ready.forEach(s => pending.splice(pending.indexOf(s), 1));
  }
  return { waves, stalled: false, missing: [] };
}
```

**评分点**：
- 波次推进 = 拓扑分层的产物视角（依赖图执行的核心循环）
- 无可推进时给出缺失产物清单（诊断价值）
- 产物入集合后步骤自身 id 也算产物
- 能讨论：波次内并行执行与失败后的重排（部分完成回滚）
