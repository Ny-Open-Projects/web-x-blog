## 1150：笔试手写：从文档生成探针题并断言可达性

**答**：实现 probe(doc, retrieve, gen)：gen(text) 返回 { q, mustContain: string[] }[]（探针题与答案必须包含的关键词）；对每个探针调用 retrieve(q)，断言「返回结果包含 doc.id 且命中 mustContain 全部关键词（对命中 chunk 文本判断）」。输出 { docId, probes: [{ q, pass }], rate }。

```js
function probe(doc, retrieve, gen) {
  const ps = gen(doc.text);                       // 探针题生成（注入函数）
  const rs = ps.map(p => {
    const hits = retrieve(p.q);
    const hit = hits.find(h => h.docId === doc.id);
    const pass = !!hit && p.mustContain.every(k => hit.text.includes(k));
    return { q: p.q, pass };
  });
  return { docId: doc.id, probes: rs,
    rate: +(rs.filter(x => x.pass).length / (rs.length || 1)).toFixed(3) };
}
// gen 示例：从文档抽关键句生成问题与关键词
const doc = { id: 'd1', text: '灰度发布支持按 UID 尾号切流' };
const fakeGen = t => [{ q: '灰度怎么切流', mustContain: ['UID'] }];
const fakeRet = q => [{ docId: 'd1', text: '灰度发布支持按 UID 尾号切流' }];
console.log(probe(doc, fakeRet, fakeGen).rate);  // 1
```

**评分点**：
- 可达性双重断言：文档命中 + 关键词覆盖（只命中不算真可达）
- 除零保护与 rate 精度
- gen/retrieve 作为注入参数（可 mock 可接真实 LLM/引擎），可测性好
- 能讨论：探针的 false negative（生成的问题太偏导致漏检）——人工抽检探针质量、关键词选择策略（实体验证过的关键词而非任意词）
