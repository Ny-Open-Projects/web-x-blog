## AGT-467：手写交叉验证：异源模型并行作答、一致性度量、分歧裁决与降级

**需求与边界**：
- 输入：query、模型列表（≥2 异源）、一致性策略；输出：验证结果与最终答案。
- 边界要求：① 并行异源作答（防同源自我偏好）；② 一致性度量（数值精确比、语义相似比）；③ 全一致→直接出；多数一致→出多数并标注分歧；严重分歧→降级声明或转人；④ 成本分级（高价值问题才全量交叉，日常抽样）。

**答**：
```javascript
async function crossValidate(query, models, { similarity, isNumeric,
  onDisagreement }) {
  const answers = await Promise.all(models.map(m => m(query)));
  // 一致性度量：数值题精确比，语义题相似度
  const agree = (a, b) => isNumeric(query)
    ? normNum(a) === normNum(b)
    : similarity(a, b) > 0.85;
  const clusters = clusterAnswers(answers, agree);
  const sizes = clusters.map(c => c.length);
  const maxCluster = Math.max(...sizes);
  if (maxCluster === answers.length)
    return { answer: clusters[0][0], confidence: 'high',
      verified: true };                               // 全一致
  if (maxCluster > answers.length / 2)
    return { answer: majorityVote(clusters), confidence: 'medium',
      dissent: clusters.filter(c => c !== majorityCluster)
        .flat().slice(0, 1),
      note: '多数一致，少数分歧已保留' };
  // 严重分歧：按策略处置
  return onDisagreement({
    clusters, options: ['human_review', 'abstain', 'tie_break'] });
}
const normNum = (s) => (s.match(/[\d.,]+/) ?? [''])[0]
  .replace(/,/g, '');
// 成本分级：高价值（金融/医疗）全量交叉；
// 日常按 5% 抽样交叉（质量监控而非全量）。
```

**评分点**:
- 异源并行+按问题类型选度量（数值精确/语义相似）。
- 三档结果：全一致高置信/多数一致保留分歧/严重分歧走策略——不强行拍板。
- 成本分级意识（高价值全量、日常抽样）。
- normNum 归一化防格式误判。
