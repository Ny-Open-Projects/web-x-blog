## AGT-542：手写 useActivePath：消息树推导、分支计数、切换兄弟分支

**需求与边界**：
- 实现 useActivePath(messages, leafId)：输出当前路径与每个分叉点的 { index, count, onPrev, onNext }。
- 边界要求：① 路径从根到 leaf；② 分叉点 = 路径上某节点在树中有多个子分支，切换保持其余路径不变；③ leafId 为空时取默认最新叶；④ 消息中含孤儿节点（父已删）要剔除。

**答**：
```javascript
function useActivePath(messages, leafId) {
  return useMemo(() => {
    const byId = new Map(messages.map(m => [m.id, m]));
    const children = new Map();
    for (const m of messages) {
      if (m.parentId && !byId.has(m.parentId)) continue; // 孤儿剔除
      (children.get(m.parentId) ?? children.set(m.parentId, []).get(m.parentId))
        .push(m);
    }
    const leaf = leafId ?? [...messages]
      .filter(m => !messages.some(x => x.parentId === m.id))[0]?.id;
    // 回溯路径
    const path = []; let cur = leaf; const seen = new Set();
    while (cur && byId.has(cur) && !seen.has(cur)) {
      seen.add(cur); path.unshift(byId.get(cur)); cur = byId.get(cur).parentId;
    }
    // 分叉点：路径上父节点有多个孩子
    const branches = path.map((n, i) => {
      const sibs = children.get(n.parentId) ?? [];
      const idx = sibs.findIndex(s => s.id === n.id);
      return sibs.length > 1 ? {
        index: idx, count: sibs.length,
        onPrev: () => setLeaf(sibs[(idx - 1 + sibs.length) % sibs.length].id),
        onNext: () => setLeaf(sibs[(idx + 1) % sibs.length].id),
      } : null;
    });
    return { path, branches };
  }, [messages, leafId]);
}
```

**评分点**:
- 孤儿节点剔除 + 环检测（seen 集合），脏数据不崩。
- 默认 leaf 回退（无 leafId 取最新叶）。
- 分支切换是循环式（% 取模）且只影响本分叉点。
