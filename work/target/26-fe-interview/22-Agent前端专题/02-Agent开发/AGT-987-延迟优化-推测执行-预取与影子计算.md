## 987：推测执行（speculative execution）在 Agent 里怎么用

**答**：
- 推测执行三形态：输入期预取（用户打字时按前缀推测检索）、分支推测（意图分类未定时并行跑 top2 意图的检索）、结果推测（先渲染占位+骨架，结果到达替换）。
- 收益来源是「隐藏等待时间」：把检索 800ms 藏进用户输入的 2s 里，用户感知为零；代价是多花推测成本，命中率低于 50% 就不划算，所以推测范围只取 top 候选。
- 一致性处理：推测结果必须校验（提交的真实输入与推测输入一致性），不一致就丢弃重跑，绝不能直接用。
- 追问钩子：推测执行和缓存的区别？——缓存复用「过去」，推测准备「未来」；两者叠加（推测命中缓存）是极限优化。

```ts
input.on('change', debounce(async prefix => {
  if (prefix.length < 4) return;
  prefetch[prefix] = await retrieve(guessQuery(prefix));   // 输入期推测预取
}, 300));
submit.on('click', async () => {
  const key = guessQuery(input.value);
  const hits = prefetch[key] && matches(key, input.value)
    ? prefetch[key]            // 推测命中且校验一致
    : await retrieve(input.value);                          // 未命中重跑
  delete prefetch[key];
  return answer(input.value, hits);
});
```
