## AGT-662：每周评测跑完，如何自动生成人能看懂的报告（而不是裸数字表）

**答**：
- 报告骨架固定：本周分数与趋势（vs 上周/vs 基线）、按能力维度雷达图、新增失败 topN（带样本与初归因）、修复验证（上周失败项本周状态）、风险项（安全/成本）。
- 每个数字配「解释链接」：点失败数下钻到失败用例列表与回放，点趋势跳到对应变更记录——报告是导航页不是终点。
- 面向不同受众的版本：工程师版全量、管理层版一页三图（质量趋势/风险/投入产出），同一数据源不同渲染。

```javascript
async function weeklyReport(run, prev) {
  return {
    trend: diff(run, prev),                       // 分数趋势
    radar: byCapability(run),                     // 能力雷达
    newFails: topN(run.newFails, 10,
      { with: ['sample', 'attribution'] }),       // 带初归因
    fixed: verifyFixes(run, prev.fails),          // 修复验证
    risks: [run.security, run.costBudget],
    links: { fail: (id) => replayUrl(id), trend: changelogUrl() },
    forExec: summarizeOnePager(run),              // 管理层一页版
  };
}
```
