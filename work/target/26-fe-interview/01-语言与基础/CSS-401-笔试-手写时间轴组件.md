## CSS-401：笔试：手写时间轴组件

**答**：实现时间轴：① 垂直中轴线贯穿，节点圆点定位在线上；② 左右交替布局（奇偶条目分列中轴两侧，中屏以下全部靠左）；③ 节点内容卡片入场动画（滚动到视口触发，IntersectionObserver + class）；④ 中轴线随滚动进度填充（scroll-timeline 优先）；⑤ 事件点时间标签样式。写出核心实现。

```html
<ol class="timeline">
  <li><div class="card">立项</div></li>
  <li><div class="card">开发</div></li>
  <li><div class="card">上线</div></li>
</ol>
```

```css
.timeline { position: relative; }
.timeline::before {          /* 中轴 */
  content: ''; position: absolute;
  left: 50%; top: 0; bottom: 0; width: 2px;
  background: linear-gradient(var(--primary) var(--p, 0%), #eee 0);
  animation: fill linear both;
  animation-timeline: scroll(nearest);
}
@keyframes fill { to { --p: 100%; } }

.timeline li {
  position: relative;
  width: 50%;
  padding: 0 40px 32px 0;
}
.timeline li:nth-child(even) { margin-left: 50%; padding: 0 0 32px 40px; }
.timeline li::before {       /* 节点圆点 */
  content: ''; position: absolute;
  right: -7px; top: 8px; width: 14px; height: 14px;
  border-radius: 50%; background: var(--primary);
  box-shadow: 0 0 0 4px color-mix(in oklab, var(--primary) 15%, transparent);
}
.timeline li:nth-child(even)::before { right: auto; left: -7px; }

.timeline .card { opacity: 0; transform: translateY(16px); transition: all .4s; }
.timeline .card.in { opacity: 1; transform: none; }

@media (max-width: 640px) {  /* 单列 */
  .timeline::before { left: 8px; }
  .timeline li, .timeline li:nth-child(even) { width: 100%; margin-left: 0; padding: 0 0 24px 32px; }
  .timeline li::before, .timeline li:nth-child(even)::before { left: 1px; right: auto; }
}
```

```javascript
const io = new IntersectionObserver((es) =>
  es.forEach(e => e.isIntersecting && e.target.classList.add('in')), { threshold: 0.3 });
document.querySelectorAll('.timeline .card').forEach(c => io.observe(c));
```

**评分点**：
- 中轴绝对定位 + 节点圆点对齐（奇偶偏移镜像）
- 交替布局 nth-child(even) margin-left 50%
- 轴线填充 scroll-timeline（或渐变 stop 兜底）
- 入场动画 IO 触发 + 移动端单列降级
