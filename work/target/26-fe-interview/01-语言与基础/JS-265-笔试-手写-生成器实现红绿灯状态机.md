## JS-265：笔试：生成器实现红绿灯状态机

**题目**：用生成器实现红绿灯循环（绿→黄→红循环），每次 next 推进到下一状态；支持外部 next(true) 触发「紧急模式」跳到红灯；提供 tick(dt) 自动按时长推进。

**答**：
```javascript
function* traffic() {
  let emergency = false;
  const phases = [
    ['green', 30000], ['yellow', 3000], ['red', 25000],
  ];
  while (true) {
    for (const phase of phases) {
      emergency = yield phase;   // 产出 [state, dur]，接收外部标记
      if (emergency) {           // 紧急：强制红灯并跳过本轮剩余
        yield ['red', 0];
        emergency = false;
        break;
      }
    }
  }
}
// 驱动器：按 dur 自动推进
function drive(gen, onState) {
  let timer;
  const next = (flag = false) => {
    clearTimeout(timer);
    const [state, dur] = gen.next(flag).value;
    onState(state);
    timer = setTimeout(() => next(false), dur);
  };
  next();
  return { emergency: () => next(true), stop: () => clearTimeout(timer) };
}
const ctl = drive(traffic(), (s) => console.log('灯:', s));
ctl.emergency(); // 立刻切红灯
```

**评分点**：
- yield 双向通信接收外部事件（emergency）
- 状态与时长数据驱动（不是三段 if-else 硬编码）
- 驱动器负责定时推进，生成器只管状态转移——职责分离
- emergency 跳转逻辑与 timer 清理
