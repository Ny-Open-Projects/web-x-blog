## H5-419：笔试：手写离线操作队列重放器

**答**：实现 `OfflineQueue`：① `enqueue(op)`：网络失败的操作按序落 IndexedDB（带 opId 幂等键 + 实体依赖 key）；② `replay()`：按序重放，同实体操作保持顺序，不同实体可并行（按 dependencyKey 分组并发，组内串行）；③ 单个 op 失败策略：409 冲突标记待人工处理并跳过该组后续，网络错误暂停重放等下次触发；④ 重放完成回调带统计（成功/冲突/失败）；⑤ 重复重放幂等（服务端按 opId 去重）。写出核心实现。

```javascript
class OfflineQueue {
  constructor(store) { this.store = store; this.running = false; }
  async enqueue(op) { await this.store.append('oplog', { ...op, opId: op.opId || crypto.randomUUID() }); }
  async replay() {
    if (this.running) return;
    this.running = true;
    const ops = await this.store.all('oplog');
    const groups = new Map();
    for (const op of ops) {                               // 按实体分组
      const key = op.dependencyKey || op.opId;
      (groups.get(key) || groups.set(key, []).get(key)).push(op);
    }
    const stat = { ok: 0, conflict: [], fail: false };
    await Promise.all([...groups.values()].map(async (group) => {  // 组间并行
      for (const op of group) {                            // 组内串行
        try {
          const res = await api.post('/sync/op', op, { headers: { 'Idempotency-Key': op.opId } });
          if (res.status === 409) { stat.conflict.push(op.opId); return; } // 冲突: 该组后续跳过
          await this.store.del('oplog', op.opId);
          stat.ok++;
        } catch {
          stat.fail = true;                                // 网络错误: 暂停, 留待下次
          return;
        }
      }
    }));
    this.running = false;
    this.onDone?.(stat);
    if (!stat.fail && stat.conflict.length === 0) this.onClean?.();
  }
}
// 触发时机: online 事件 + SW sync + 下次启动
addEventListener('online', () => queue.replay());
```

**评分点**：
- dependencyKey 分组：组间并行/组内串行，正确保实体操作顺序
- 三类结果分明：成功/冲突跳过/网络失败暂停
- opId 幂等键 + Idempotency-Key 头，重复重放安全
- 触发时机多元（online/SW sync/启动）
