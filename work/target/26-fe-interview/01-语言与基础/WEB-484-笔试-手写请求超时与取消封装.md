## WEB-484：笔试：手写请求超时与取消封装

**题目**：实现 `request(url, opts)`：支持 `timeout`（默认 10s）、外部传入的取消信号；页面卸载时自动取消未完成请求；超时与手动取消抛出不同错误类型。

**答**：
```javascript
class TimeoutError extends Error { name = 'TimeoutError'; }
class CancelledError extends Error { name = 'CancelledError'; }

const pageUnload = new AbortController();
addEventListener('pagehide', () => pageUnload.abort());

function request(url, { timeout = 10000, signal, ...opt } = {}) {
  const ctl = new AbortController();
  const onAbort = () => ctl.abort();
  signal?.addEventListener('abort', onAbort);
  // 双信号联动：外部取消或页面卸载都会传导
  pageUnload.signal.addEventListener('abort', () => ctl.abort(), { once: true });
  const timer = setTimeout(() => ctl.abort(new TimeoutError('timeout')), timeout);
  return fetch(url, { ...opt, signal: ctl.signal })
    .catch(err => {
      if (signal?.aborted) throw new CancelledError('cancelled');
      if (err instanceof TimeoutError) throw err;
      throw new TimeoutError('timeout');
    })
    .finally(() => {
      clearTimeout(timer);
      signal?.removeEventListener('abort', onAbort);
    });
}
```

**评分点**：
- 用 AbortController 实现超时，不是 Promise.race（race 挡不住真实请求继续跑）
- 外部 signal 与内部 signal 的联动（级联取消）
- 错误分类：timeout 与 cancelled 可区分，调用方好处理
- pagehide/pageunload 兜底取消，防组件卸载后 setState 报警
