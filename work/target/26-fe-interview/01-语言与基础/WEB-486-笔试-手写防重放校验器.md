## WEB-486：笔试：手写防重放校验器

**题目**：实现服务端防重放校验器 `checkReplay(nonce, timestamp)`：timestamp 超过 ±5 分钟窗口拒绝；nonce 在窗口期内重复拒绝；内存有限，要自动清理过期记录。

**答**：
```javascript
const WINDOW = 5 * 60 * 1000;
const seen = new Map(); // nonce -> expireAt

function checkReplay(nonce, timestamp, now = Date.now()) {
  // 1. 时间窗校验
  if (Math.abs(now - timestamp) > WINDOW) return { ok: false, reason: 'expired' };
  // 2. nonce 记录存在且未过期 → 重放
  const hit = seen.get(nonce);
  if (hit && hit > now) return { ok: false, reason: 'replayed' };
  // 3. 记录并清理过期项（防 Map 无限膨胀）
  seen.set(nonce, now + WINDOW);
  if (seen.size > 100000) {
    for (const [k, exp] of seen) if (exp <= now) seen.delete(k);
  }
  return { ok: true };
}

// 测试
checkReplay('a', Date.now());        // ok
checkReplay('a', Date.now());        // replayed
checkReplay('b', Date.now() - 6e5);  // expired
```

**评分点**：
- 时间窗与 nonce 去重缺一不可，只查时间戳不是防重放
- Map 存过期时间并在超限时惰性清理，避免内存无限增长
- 时间比较用服务端时钟（now 参数可注入，方便测试）
- 能指出分布式部署下要用 Redis SETNX + TTL 替代内存 Map（加分）
