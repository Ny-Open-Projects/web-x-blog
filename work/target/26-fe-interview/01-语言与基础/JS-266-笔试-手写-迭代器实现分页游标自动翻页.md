## JS-266：笔试：迭代器分页游标自动翻页

**题目**：实现 `paginate(fetchPage)` 异步生成器：自动按游标翻页逐条产出；支持 `break` 提前终止（不再发后续请求）；首页游标为 null。

**答**：
```javascript
async function* paginate(fetchPage) {
  let cursor = null;
  while (true) {
    const page = await fetchPage(cursor); // { items, next }
    for (const item of page.items) yield item;
    if (!page.next) return;               // 无游标 = 到末尾
    cursor = page.next;
  }
}
// 消费：break 后生成器 return，不会继续拉页
for await (const item of paginate(c => fetch(`/api/list?cursor=${c ?? ''}`).then(r => r.json()))) {
  console.log(item.id);
  if (item.id > 50) break; // break 触发生成器提前结束——没有多余请求
}
```

**评分点**：
- async function* + for await-of 的完整闭环
- 游标 null 起点与终止条件（next 为空）
- break 提前终止语义（生成器 return、后续请求不发）——惰性核心考点
- 错误处理可加 try/catch 包装（加分）
