## H5-425：笔试：手写页面离开守卫与历史栈管理

**答**：实现 `LeaveGuard`（SPA 路由 + 浏览器双场景）：① 注册守卫：表单有未保存修改时拦截离开，弹确认对话框（继续离开/留下）；② 拦截两层：SPA 路由 beforeRouteLeave（history.pushState 场景）与浏览器 popstate/beforeunload；③ popstate 拦截：先 history.go(1) 恢复当前位置再弹确认（确认离开才真正后退）；④ beforeunload 兜底（刷新/关 tab，移动端不可靠但保留）；⑤ dirty 状态自动追踪（表单 input 变更置 dirty，保存后清除）。写出核心实现。

```javascript
class LeaveGuard {
  constructor(routerLeave) {
    this.dirty = false; this.routerLeave = routerLeave; this.pending = null;
    // 表单 dirty 自动追踪
    document.addEventListener('input', (e) => {
      if (e.target.closest('[data-guard-form]')) this.dirty = true;
    });
    // SPA 路由守卫
    window.addEventListener('popstate', () => {
      if (!this.dirty) return;
      history.go(1);                                          // 先恢复当前位置
      this._confirm().then(ok => { if (ok) { this.dirty = false; history.back(); } });
    });
    // 兜底: 刷新/关闭
    window.addEventListener('beforeunload', (e) => {
      if (!this.dirty) return;
      e.preventDefault(); e.returnValue = '';
    });
  }
  _confirm() {                                                // 确认对话框
    return new Promise((resolve) => {
      const overlay = buildConfirmDialog({
        text: '有未保存的修改，确定离开吗？',
        onLeave: () => resolve(true), onStay: () => resolve(false),
      });
      document.body.appendChild(overlay);
    });
  }
  // SPA 编程式导航守卫
  async navigate(url) {
    if (this.dirty && !(await this._confirm())) return false;
    this.dirty = false;
    this.routerLeave ? this.routerLeave(url) : (location.href = url);
    return true;
  }
  markSaved() { this.dirty = false; }
}
```

**评分点**：
- 双层拦截（popstate + beforeunload）且 popstate 先 go(1) 恢复再确认
- dirty 自动追踪（事件委托 data-guard-form）+ 保存清除
- 确认异步化（Promise resolve）不阻塞事件循环
- 移动端 beforeunload 不可靠的认知（popstate 是主防线）
