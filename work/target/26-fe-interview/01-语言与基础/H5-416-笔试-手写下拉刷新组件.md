## H5-416：笔试：手写下拉刷新组件

**答**：实现 `PullRefresh`：① 仅当 scrollTop === 0 且向下拖拽时激活（防与列表滚动冲突）；② 拖拽距离映射指示器位移，越界（>80px）阻尼递减；③ 松手时距离 ≥80px 触发 onRefresh（Promise），指示器进入 loading 态，完成后回弹收起；④ 未达阈值松手直接回弹；⑤ 刷新中禁止再次触发；iOS bounce 干扰下仍稳定。写出核心实现（rAF 节流）。

```javascript
class PullRefresh {
  constructor(el, { onRefresh, threshold = 80 } = {}) {
    this.el = el; this.onRefresh = onRefresh; this.t = threshold;
    this.indicator = el.querySelector('.pull-indicator');
    this.state = 'idle'; // idle | pulling | loading
    let sy = 0, pulling = false, dist = 0;
    el.addEventListener('touchstart', (e) => {
      if (this.state === 'loading') return;
      sy = e.touches[0].clientY;
      pulling = el.scrollTop <= 0;
    }, { passive: true });
    el.addEventListener('touchmove', (e) => {
      if (!pulling || this.state === 'loading') return;
      const dy = e.touches[0].clientY - sy;
      if (dy <= 0) return;
      dist = dy > this.t ? this.t + (dy - this.t) * 0.3 : dy;   // 越界阻尼
      this.state = 'pulling';
      this._render(dist);
      e.preventDefault();                                        // 阻止原生滚动
    }, { passive: false });
    el.addEventListener('touchend', async () => {
      if (this.state !== 'pulling') return;
      if (dist >= this.t) {
        this.state = 'loading';
        this._render(this.t, true);                              // loading 态
        try { await this.onRefresh?.(); } finally { this._done(); }
      } else this._done();
      dist = 0;
    });
  }
  _render(d, loading = false) {
    requestAnimationFrame(() => {
      this.indicator.style.transform = `translateY(${d}px)`;
      this.indicator.classList.toggle('loading', loading);
    });
  }
  _done() {
    this._render(0);
    this.state = 'idle';
  }
}
```

**评分点**：
- scrollTop===0 才激活的冲突防护
- 阻尼公式正确（超阈值部分 ×0.3）
- loading 态互斥（刷新中禁触发）+ finally 保证状态复位
- non-passive touchmove 仅在需要 preventDefault 时生效
