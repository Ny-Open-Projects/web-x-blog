## WEB-209：浏览器如何校验证书链？自签证书为什么会报错？

**答**：
- 校验链：从站点证书出发，逐级向上找到浏览器信任库里的根证书。每一级用上级公钥验证下级签名，同时检查 Basic Constraints（中间 CA 是否被允许再签发）。
- 除签名外还要校验：域名（SAN 是否包含访问域名）、有效期、Key Usage、吊销状态（CRL/OCSP）。
- 自签证书报错的原因：它不在信任链里，签名无法回溯到受信根——浏览器无法区分「自签」和「中间人伪造」，只能一视同仁报 `ERR_CERT_AUTHORITY_INVALID`。
- 工程实践：内网/本地开发用 mkcert 把本地根证书装入系统信任库；线上绝不能让用户「忽略警告」，忽略会训练用户点击危险告警。

```bash
# 查看站点证书链
openssl s_client -connect github.com:443 -showcerts </dev/null 2>/dev/null \
  | grep -E 's:|i:'   # s: subject, i: issuer

# 本地开发签发受信证书
mkcert -install
mkcert localhost 127.0.0.1 ::1   # 生成 localhost.pem + key，系统已信任
```
