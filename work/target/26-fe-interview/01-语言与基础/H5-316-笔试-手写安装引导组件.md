## H5-316：笔试：手写 PWA 安装引导组件

**题目**：实现安装引导逻辑：捕获 beforeinstallprompt 并存储；在合适时机（浏览商品超过 2 个页面且未安装）展示自定义安装条；iOS 走「分享→添加到主屏幕」的引导浮层；安装成功/拒绝都要上报并 7 天内不再提示。

**答**：
```javascript
function installGuide() {
  let deferred = null;
  const MUTE_KEY = 'install_muted_until';
  const muted = +localStorage.getItem(MUTE_KEY) > Date.now();

  addEventListener('beforeinstallprompt', (e) => {
    e.preventDefault();
    deferred = e;
    maybeShow();
  });
  addEventListener('appinstalled', () => {
    report({ install: 'ok' });
    muteForever();
  });

  function maybeShow() {
    if (muted || pagesViewed() < 2 || isStandalone()) return;
    if (isiOS()) showIosGuide();          // iOS 无原生提示
    else showChromeBanner();              // 有 deferred 才走这里
  }
  function showChromeBanner() {
    renderBanner(async () => {
      deferred.prompt();
      const { outcome } = await deferred.userChoice;
      report({ install: outcome });
      if (outcome === 'dismissed') localStorage.setItem(MUTE_KEY, String(Date.now() + 7 * 864e5));
      deferred = null;
    });
  }
  const isiOS = () => /iphone|ipad/i.test(navigator.userAgent);
  const isStandalone = () => matchMedia('(display-mode: standalone)').matches;
  const pagesViewed = () => +(sessionStorage.getItem('pv') || 0);
  addEventListener('popstate', () => sessionStorage.setItem('pv', pagesViewed() + 1));
}
```

**评分点**：
- beforeinstallprompt 的 preventDefault + 保存（时机自控）
- iOS 分支单独引导（平台差异处理）
- 拒绝后 7 天静默 + 已安装/已安装模式（standalone）不提示
- 转化数据上报（accepted/dismissed）
