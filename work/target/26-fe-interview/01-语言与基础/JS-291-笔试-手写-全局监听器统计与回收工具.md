## JS-291：笔试：全局监听器统计与回收

**题目**：实现 `listen(target, type, fn)` 包装：按 owner（组件名）分组统计当前监听数；`getStats()` 返回各 owner 计数；`releaseAll(owner)` 回收某组件的全部监听；超阈值（如同一 owner > 50）console.warn 疑似泄漏。

**答**：
```javascript
const registry = new Map(); // owner -> Set<{ target, type, fn }>
const THRESHOLD = 50;

function listen(owner, target, type, fn, opts) {
  if (!registry.has(owner)) registry.set(owner, new Set());
  const set = registry.get(owner);
  if (set.size >= THRESHOLD) console.warn(`[leak?] ${owner} 已挂 ${set.size} 个监听器`);
  target.addEventListener(type, fn, opts);
  const entry = { target, type, fn, opts };
  set.add(entry);
  return () => { target.removeEventListener(type, fn, opts); set.delete(entry); };
}

function getStats() {
  return Object.fromEntries([...registry].map(([o, s]) => [o, s.size]));
}
function releaseAll(owner) {
  const set = registry.get(owner);
  if (!set) return 0;
  set.forEach(({ target, type, fn, opts }) => target.removeEventListener(type, fn, opts));
  const n = set.size;
  registry.delete(owner);
  return n;
}

listen('chart', window, 'resize', onResize);
listen('chart', window, 'resize', onResize2);
console.log(getStats()); // { chart: 2 }
releaseAll('chart');     // 2 —— 组件卸载时一行回收
```

**评分点**：
- 注册表（Map + Set）记录「owner→监听明细」——回收依赖完整元信息
- removeEventListener 需要原 fn 引用（所以必须存 entry）
- 阈值告警（怀疑泄漏的主动性）
- 返回单个退订函数 + releaseAll 批量回收双层接口
