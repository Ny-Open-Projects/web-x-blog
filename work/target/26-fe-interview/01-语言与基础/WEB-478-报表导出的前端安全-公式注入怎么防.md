## WEB-478：报表导出的前端安全：公式注入怎么防

**答**：
- CSV/Excel 公式注入：用户昵称填 `=cmd|'/c calc'!A1`，运营用 Excel 打开导出文件时公式被执行
- 防御：导出时对以 `=`、`+`、`-`、`@`、Tab、回车开头的单元格内容做转义（前置 `'` 或空格）——这是行业标准做法（OWASP CSV Injection）
- 附带问题：CSV 打开中文乱码要加 BOM（`\uFEFF`）；大导出用流式写避免前端内存爆
- HTML 报表导出（打印/PDF）注意样式注入与外链泄漏
- 本质话术：导出内容含用户输入时，按「输出编码」对待，与 XSS 同一个安全模型

```javascript
function safeCell(v) {
  const s = String(v);
  return /^[=+\-@\t\r]/.test(s) ? `'${s}` : s; // 防公式注入
}
function exportCsv(rows) {
  const csv = '\uFEFF' + rows.map(r => r.map(safeCell).map(c => `"${c.replace(/"/g, '""')}"`).join(',')).join('\n');
  download(new Blob([csv], { type: 'text/csv;charset=utf-8' }), 'report.csv');
}
```
