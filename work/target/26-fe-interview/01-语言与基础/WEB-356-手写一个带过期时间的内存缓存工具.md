## WEB-356：手写一个带过期时间的内存缓存工具
**答**：
- 要点：Map 存储 + 时间戳过期判断；get 时惰性清理；set 支持单条 TTL；支持容量上限 LRU 淘汰加分。
- 边界：过期后返回 undefined；set 相同 key 刷新 TTL；并发场景单线程 JS 无锁，但要防 JSON 大对象引用共享（存副本或不可变约定）。

```javascript
class TTLCache {
  constructor(max = 100) { this.map = new Map(); this.max = max; }
  set(k, v, ttl = 60_000) {
    if (this.map.size >= this.max && !this.map.has(k)) {
      this.map.delete(this.map.keys().next().value); // 淘汰最旧
    }
    this.map.delete(k); // 保证 LRU 顺序
    this.map.set(k, { v, expire: Date.now() + ttl });
  }
  get(k) {
    const it = this.map.get(k);
    if (!it) return undefined;
    if (Date.now() > it.expire) { this.map.delete(k); return undefined; }
    this.map.delete(k); this.map.set(k, it);  // 命中置新
    return it.v;
  }
}
const c = new TTLCache(2);
c.set('a', 1, 50); console.log(c.get('a'));  // 1
setTimeout(() => console.log(c.get('a')), 60); // undefined
```
