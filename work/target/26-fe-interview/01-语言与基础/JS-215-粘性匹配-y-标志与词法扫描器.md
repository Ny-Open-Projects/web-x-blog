## JS-215：粘性匹配 y 标志与词法扫描器

**答**：
- y（sticky）：匹配必须从 lastIndex 处**开始**——不像 g 会向后搜索跳过
- 用途：手写 tokenizer（词法分析）——依次尝试 token 正则，不匹配即语法错误；g 的「跳过乱文本继续找」会让语法错误漏网
- y + g 共用 lastIndex 状态；与 replaceAll/matchAll 的组合注意粘性语义限制
- 性能优势：固定位置尝试失败立即返回，无扫描开销

```javascript
function tokenize(src) {
  const rules = [
    ['num', /\d+/y], ['op', /[+\-*/]/y], ['ws', /\s+/y],
  ];
  const tokens = [];
  let pos = 0;
  while (pos < src.length) {
    const found = rules.find(([, re]) => { re.lastIndex = pos; return re.test(src); });
    if (!found) throw new Error(`Unexpected token at ${pos}`); // 严格：非法字符报错
    const [type, re] = found; re.lastIndex = pos;
    const m = re.exec(src);
    if (type !== 'ws') tokens.push({ type, value: m[0] });
    pos = re.lastIndex;
  }
  return tokens;
}
console.log(tokenize('12 + 34 * 5'));
```
