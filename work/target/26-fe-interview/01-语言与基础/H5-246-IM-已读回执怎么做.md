## H5-246：IM 已读回执怎么做

**答**：
- 语义分级：送达（服务端收到并投递）→ 已收到（对方客户端拉到）→ 已读（对方滚动到消息并停留）——三级回执，别混用
- 上报策略：IntersectionObserver 检测消息进入视口 + 停留 500ms 以上才算已读，防止快速滑过误报
- 上报节流：批量上报「已读位置」（最大 seq）而非逐条上报——服务端把 ≤ 该 seq 的消息全标已读，消息量从 N 降到 1
- 防循环：A 标已读通知 B，B 界面更新不再触发新回执（本地状态位）；多端同步时用版本号防抖
- 隐私开关：微信式「关闭已读」意味着服务端仍记录但不回传，产品层面明确

```javascript
const io = new IntersectionObserver(entries => {
  entries.forEach(e => {
    if (e.isIntersecting) visibleIds.add(e.target.dataset.seq);
  });
}, { threshold: 0.5 });
// 滚动静止 500ms 后批量上报
let timer;
onScrollStop(() => {
  timer ??= setTimeout(() => {
    const maxSeq = Math.max(...visibleIds);
    if (maxSeq > reportedSeq) ws.send({ type: 'READ', seq: maxSeq });
    reportedSeq = maxSeq;
  }, 500);
});
```
