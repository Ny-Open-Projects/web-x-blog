## JS-389：笔试：手写任务执行器

**答**：实现 `runTasks(tasks, mode)`：① mode='serial'：顺序执行，前一个完成才下一个，任一失败中断并返回已完成结果；② mode='parallel'：Promise.all 语义；③ mode='continue'：串行但失败不中断（收集错误继续），返回 `{ results, errors }`；④ tasks 是返回 Promise 的函数数组（惰性调用）；⑤ 空 tasks 返回空结果。写出实现。

```javascript
async function runTasks(tasks, mode = 'serial') {
  if (!tasks.length) return mode === 'continue'
    ? { results: [], errors: [] } : [];

  if (mode === 'parallel') return Promise.all(tasks.map(t => t()));

  const results = [], errors = [];
  for (let i = 0; i < tasks.length; i++) {
    try {
      const v = await tasks[i]();
      results.push(v);
    } catch (e) {
      if (mode === 'serial') {                       // 中断: 返回已完成部分
        return { partial: results, error: e, failedAt: i };
      }
      errors.push({ index: i, error: e });           // continue: 记录后继续
      results.push(undefined);
    }
  }
  return mode === 'continue' ? { results, errors } : results;
}

// 用例
const tasks = [async () => 1, async () => { throw new Error('boom'); }, async () => 3];
await runTasks(tasks, 'serial');    // { partial: [1], error: boom, failedAt: 1 }
await runTasks(tasks, 'continue');  // { results: [1, undefined, 3], errors: [{index:1,...}] }
```

**评分点**：
- tasks 惰性调用（存函数不立即执行，串行模式前一个失败时后面的根本不调用）
- serial 中断返回已完成部分 + 失败位置
- continue 模式错误按索引收集、结果占位保持对齐
- parallel 直接委托 Promise.all
