## CSS-428：笔试：手写主题切换按钮

**答**：实现暗色模式切换：① 图标太阳/月亮随主题切换（旋转+透明度交叉过渡）；② 全站颜色过渡平滑（颜色 token transition，注意首帧不过渡）；③ View Transitions 圆形扩散切换（支持的浏览器从按钮位置扩散）；④ 用户偏好持久化（localStorage + 系统跟随 fallback）；⑤ reduced-motion 下瞬时切换。写出核心实现。

```html
<button class="theme-toggle" aria-label="切换主题">
  <svg class="sun">☀</svg><svg class="moon">🌙</svg>
</button>
```

```css
html { color-scheme: light dark; }
:root { --bg: #fff; --fg: #222; }
:root[data-theme='dark'] { --bg: #121212; --fg: #eee; }
body {
  background: var(--bg); color: var(--fg);
  transition: background .3s, color .3s;   /* 平滑, 首帧除外(见JS) */
}
@media (prefers-reduced-motion: reduce) {
  body { transition: none; }
}
.theme-toggle { position: relative; width: 44px; height: 44px; }
.theme-toggle svg {
  position: absolute; inset: 8px;
  transition: transform .4s var(--ease-out-quart), opacity .3s;
}
.theme-toggle .moon { transform: rotate(90deg) scale(.5); opacity: 0; }
[data-theme='dark'] .sun { transform: rotate(-90deg) scale(.5); opacity: 0; }
[data-theme='dark'] .moon { transform: none; opacity: 1; }
```

```javascript
// 首帧不过渡: 切换后下一帧才加过渡类
document.documentElement.classList.add('no-anim');
requestAnimationFrame(() => requestAnimationFrame(() =>
  document.documentElement.classList.remove('no-anim')));

async function toggleTheme(e) {
  const next = document.documentElement.dataset.theme === 'dark' ? 'light' : 'dark';
  // View Transitions: 从按钮位置圆形扩散(支持时)
  if (document.startViewTransition) {
    const t = document.startViewTransition(() =>
      document.documentElement.dataset.theme = next);
    await t.ready;
    const r = e.currentTarget.getBoundingClientRect();
    const x = r.left + r.width / 2, y = r.top + r.height / 2;
    const radius = Math.hypot(Math.max(x, innerWidth - x), Math.max(y, innerHeight - y));
    document.documentElement.animate(
      { clipPath: [`circle(0 at ${x}px ${y}px)`, `circle(${radius}px at ${x}px ${y}px)`] },
      { duration: 400, easing: 'ease-in', pseudoElement: '::view-transition-new(root)' });
  } else {
    document.documentElement.dataset.theme = next;
  }
  localStorage.setItem('theme', next);
}
// 初始化: 用户选择 > 系统偏好
document.documentElement.dataset.theme =
  localStorage.getItem('theme')
  ?? (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
```

**评分点**：
- 双图标交叉旋转过渡（transform+opacity）
- 首帧禁过渡（双 rAF 技巧）防止加载闪变
- View Transitions 圆形扩散从点击位置发起（clipPath + pseudoElement）
- 持久化优先级链（用户 > 系统）+ reduced-motion 降级
