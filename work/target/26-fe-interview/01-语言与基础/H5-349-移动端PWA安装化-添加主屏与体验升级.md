## H5-349：移动端 PWA 安装化：添加主屏与体验升级

**答**：
- 安装条件（Chrome）：manifest（name/icons/maskable/start_url/display: standalone）+ SW + HTTPS + 用户交互；iOS 走「添加到主屏幕」手动路径（16.4 起支持 Web App 安装提示 API 但依赖用户操作）
- 安装体验：beforeinstallprompt 捕获后存 deferredPrompt，在业务时机（用户完成关键任务后）触发 prompt——直接弹授权率极低
- standalone 模式适配：无浏览器 UI 后返回手势/状态栏区（safe-area）、内部导航要自建（standalone 下历史栈行为差异）、更新提示（SW 控制器更新后 reload 询问）
- 能力升级收益：安装后可解锁 Web Push（iOS）、独立窗口、图标入口——转化率比纯 H5 会话高
- 效果度量：安装事件（appinstalled）、安装后 DAU 占比、安装用户 vs 未安装用户的留存/转化对比

```javascript
let deferred;
addEventListener('beforeinstallprompt', (e) => { e.preventDefault(); deferred = e; });
// 在用户完成首单等价值时刻触发
function maybePromptInstall() {
  if (!deferred) return;
  deferred.prompt();
  deferred.userChoice.then(({ outcome }) => beacon({ install: outcome }));
  deferred = null;
}
addEventListener('appinstalled', () => beacon({ installed: true }));
// standalone 检测
const standalone = matchMedia('(display-mode: standalone)').matches;
```
