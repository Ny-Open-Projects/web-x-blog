## BAS-141：宏任务微任务基础输出题：这段代码输出什么？
**答**：
- 同步代码最先执行完：1、4。
- 整个同步栈清空后立即清空微任务队列：3；然后才取宏任务：2。
- 速记口诀：同步 → 微任务清空 → 一个宏任务 → 再清微任务，循环往复。

```javascript
console.log(1);                                // 同步
setTimeout(() => console.log(2), 0);           // 宏任务
Promise.resolve().then(() => console.log(3)); // 微任务
console.log(4);                                // 同步
// 输出 1 4 3 2：同步跑完 → 清微任务 → 取宏任务
```
