## JS-282：笔试：手机号脱敏与校验

**题目**：实现 `maskPhone(phone)`：中间 4 位脱敏（138****5678）；`isValidCNPhone(phone)`：宽松校验国内手机号；处理输入为 null/带空格的情况。

**答**：
```javascript
// 脱敏：捕获首 3 与尾 4
function maskPhone(phone) {
  const p = String(phone ?? '').replace(/\s/g, '');
  if (!/^1\d{10}$/.test(p)) return String(phone ?? ''); // 非手机号原样返回
  return p.replace(/^(1\d{2})\d{4}(\d{4})$/, '$1****$2');
}

// 校验：业务宽松（号段持续新增，精确白名单会漏）
function isValidCNPhone(phone) {
  return /^1[3-9]\d{9}$/.test(String(phone ?? '').replace(/\s/g, ''));
}

// 支持多格式输入
maskPhone('138 1234 5678');  // '138****5678'
maskPhone(null);              // ''
isValidCNPhone('13812345678'); // true
isValidCNPhone('12812345678'); // false（第二位不在 3-9）
```

**评分点**：
- 捕获组替换 `$1****$2` 的脱敏写法
- 输入清洗（去空格、null 兜底）——健壮性判分
- 宽松校验的理由（号段动态性）——工程判断加分
- 非手机号输入的降级返回
