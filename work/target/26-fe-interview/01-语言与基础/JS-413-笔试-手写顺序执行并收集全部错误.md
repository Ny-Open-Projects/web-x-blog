## JS-413：笔试：手写顺序执行并收集全部错误

**答**：实现 `sequenceAll(tasks)`：① 串行执行每个任务（前一个 settled 才开始下一个）；② 全部执行完毕（错误不中断）；③ 返回数组每项 `{ status, value|reason }`（allSettled 结构）且与输入对齐；④ 提供 `stopOnError` 选项（遇到第一个 rejected 停止，剩余标记 skipped）；⑤ 空 tasks 返回 []。写出实现。

```javascript
async function sequenceAll(tasks, { stopOnError = false } = {}) {
  const out = [];
  for (const t of tasks) {
    if (stopOnError && out.some(r => r.status === 'rejected')) {
      out.push({ status: 'skipped' });
      continue;
    }
    try {
      out.push({ status: 'fulfilled', value: await t() });
    } catch (e) {
      out.push({ status: 'rejected', reason: e });
    }
  }
  return out;
}
// 用法: 迁移脚本逐条执行, 全部记录哪条失败

```

**评分点**：
- 串行语义（for + await，非 Promise.all）
- 失败收集为 allSettled 结构且索引对齐
- stopOnError 的 skipped 标记（区分未执行与失败）
- 空 tasks 与全成功的边界
