## H5-324：笔试：手写左滑删除手势组件

**题目**：实现列表项左滑删除：水平滑动超过阈值露出删除按钮（宽 80px）；松手时按位移决定展开或收回（带 transition）；展开状态点击其他项或点删除后收回；与垂直滚动互不干扰（滑动方向判定）。

**答**：
```javascript
function swipeCell(item, { width = 80, threshold = 40 } = {}) {
  let startX = 0, startY = 0, deltaX = 0, locked = null, open = false;
  const inner = item.querySelector('.swipe-content');
  const transition = 'transform .25s ease';

  item.addEventListener('touchstart', (e) => {
    const t = e.touches[0];
    startX = t.clientX; startY = t.clientY;
    locked = null;
    inner.style.transition = ''; // 拖拽时无动画
  }, { passive: true });

  item.addEventListener('touchmove', (e) => {
    const t = e.touches[0];
    const dx = t.clientX - startX, dy = t.clientY - startY;
    if (locked === null) {
      if (Math.abs(dx) > 10 || Math.abs(dy) > 10)
        locked = Math.abs(dx) > Math.abs(dy) ? 'h' : 'v'; // 方向锁：先判主方向
    }
    if (locked !== 'h') return;
    deltaX = Math.max(-width, Math.min(0, (open ? -width : 0) + dx)); // 已展开继续拖
    inner.style.transform = `translateX(${deltaX}px)`;
  }, { passive: true });

  item.addEventListener('touchend', () => {
    if (locked !== 'h') return;
    open = deltaX < -threshold;
    inner.style.transition = transition;
    inner.style.transform = open ? `translateX(-${width}px)` : 'translateX(0)';
    if (open) closeOthers(item); // 展开时收回其他项
  });
  function closeOthers(self) {
    document.querySelectorAll('.swipe-content').forEach(el =>
      el !== self.querySelector('.swipe-content') && el.style.setProperty('transform', 'translateX(0)'));
  }
}
```

**评分点**：
- 方向锁（10px 内判定主方向），水平手势不干扰垂直滚动——核心判分点
- 位移钳制在 [-width, 0]；已展开状态从 -width 起拖
- 松手按 threshold 决定展开/收回 + transition 恢复
- 同时只允许一项展开（closeOthers）
