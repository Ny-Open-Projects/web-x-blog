## WEB-511：笔试：手写前端埋点事件录制器

**题目**：实现 `record()`：采集 click/change/scroll 等事件（滚动节流 200ms）与时间戳，形成事件流数组；提供 `replay(events, speed)` 按时间差回放到当前 DOM（触发 dispatchEvent）；支持停止。

**答**：
```javascript
function record() {
  const events = [];
  const t0 = Date.now();
  let lastScroll = 0;

  const onClick = e => events.push({ t: Date.now() - t0, type: 'click', sel: sel(e.target) });
  const onChange = e => events.push({ t: Date.now() - t0, type: 'change', sel: sel(e.target), v: e.target.value });
  const onScroll = () => {
    if (Date.now() - lastScroll < 200) return; // 节流
    lastScroll = Date.now();
    events.push({ t: Date.now() - t0, type: 'scroll', y: scrollY });
  };
  document.addEventListener('click', onClick, true);
  document.addEventListener('change', onChange, true);
  window.addEventListener('scroll', onScroll, { passive: true });

  return {
    events,
    stop() {
      document.removeEventListener('click', onClick, true);
      document.removeEventListener('change', onChange, true);
      window.removeEventListener('scroll', onScroll);
    },
  };
}
const sel = el => el.id ? `#${el.id}` : `${el.tagName.toLowerCase()}.${el.className}`;

function replay(events, { speed = 1, onEvent } = {}) {
  const timers = [];
  events.forEach(ev => {
    timers.push(setTimeout(() => onEvent?.(ev), ev.t / speed));
  });
  return { stop: () => timers.forEach(clearTimeout) };
}
```

**评分点**：
- 事件流记录相对时间戳（从录制起点），回放按差值调度
- scroll 节流避免事件流爆炸
- 录制必须可 stop 且移除监听；回放可取消（clearTimeout 数组）
- 选择器快照（sel）稳定表达目标元素，值采集注意脱敏（密码框不应录值）
