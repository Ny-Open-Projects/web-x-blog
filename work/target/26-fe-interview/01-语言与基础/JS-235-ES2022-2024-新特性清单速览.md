## JS-235：ES2022-2024 新特性清单速览

**答**：
- ES2022：顶层 await、类私有字段 #x、静态块、Object.hasOwn、at()、error.cause
- ES2023：findLast/findLastIndex、toSorted/toReversed/toSpliced/with（不可变数组方法）、Hashbang
- ES2024：Promise.withResolvers、Object.groupBy/Map.groupBy、正则 v 标志、Atomics.waitAsync、字符串 isWellFormed/toWellFormed
- ES2025 关键项：Iterator helpers（map/filter/toArray）、RegExp duplicate named groups、Set 方法
- 面试话术：不必背全，能按「可变性控制（toSorted 系列）/ 迭代增强 / Promise 便利」三类归纳并各举一例即达标

```javascript
// ES2023：不可变数组
const sorted = arr.toSorted((a, b) => a - b);   // 原数组不动
// ES2024：分组 + withResolvers
const g = Object.groupBy(users, u => u.dept);
const { promise, resolve } = Promise.withResolvers();
// ES2022：私有字段 + 顶层 await（模块内）
class Counter { #n = 0; inc() { return ++this.#n; } }
const cfg = await fetch('/config.json').then(r => r.json());
```
