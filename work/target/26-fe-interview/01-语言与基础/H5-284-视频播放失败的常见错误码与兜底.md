## H5-284：视频播放失败的常见错误码与兜底

**答**：
- 四类 MediaError：1 播放中止（正常）、2 网络错误（下载中断）、3 解码错误（格式/损坏）、4 不支持的源——监听 video 的 error 事件读 error.code
- 兜底链：网络类 → 自动重试换线路/CDN；解码类 → 切换备选格式（H.265 源切 H.264）；不支持类 → 提示下载 App 或换平台
- 排障辅助：上报 error.code + currentSrc + 网络类型 + 机型，按机型聚合找出解码兼容问题
- 隐性失败：error 不触发但卡住（stalled）——用 waiting/stalled 事件加超时判断主动 seek 重试
- MSE 场景：error 可能在 SourceBuffer 操作异常时触发，需配合 hls.js 的 error 事件分级处理（network/media fatal 分开恢复）

```javascript
video.addEventListener('error', () => {
  const codes = { 2: '网络错误', 3: '解码错误', 4: '格式不支持' };
  report({ code: video.error?.code, src: video.currentSrc });
  if (video.error?.code === 2) retryFromBackupCdn();
  else if (video.error?.code === 4) switchToH264Source();
  else showFallbackUI(codes[video.error?.code] || '播放失败');
});
```
