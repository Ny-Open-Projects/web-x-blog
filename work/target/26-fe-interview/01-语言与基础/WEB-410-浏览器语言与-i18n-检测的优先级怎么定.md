## WEB-410：浏览器语言与 i18n 检测的优先级怎么定？
**答**：
- 优先级：用户显式选择（存储）> 路由/域名（/en、jp.site.com）> navigator.languages > 服务端 Accept-Language > 默认。
- 细节：navigator.language 只有一个首选值，languages 是整个偏好列表（按权重）；bidi 语言（阿拉伯语）要同步 dir=rtl。
- 格式化：日期数字货币用 Intl.DateTimeFormat/NumberFormat，别手写规则；汇率金额注意 currency 显示与四舍五入规则。

```javascript
const locale = saved || routeLocale || (navigator.languages.find(l => SUPPORTED.has(l)) || 'en');
const nf = new Intl.NumberFormat(locale, { style: 'currency', currency: 'CNY' });
console.log(nf.format(12345.6)); // ¥12,345.60
document.documentElement.lang = locale;
console.log('Intl 全家桶替代手写格式化');
```
