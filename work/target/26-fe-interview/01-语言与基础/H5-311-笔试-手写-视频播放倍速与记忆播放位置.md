## H5-311：笔试：手写视频播放倍速与记忆播放位置

**题目**：实现播放器增强：倍速切换（0.5/1/1.25/1.5/2）、播放位置记忆（localStorage 按视频 ID 存，恢复时 seek，看完后清除）、节流保存进度（5s 一次）、beforeunload 时兜底保存。

**答**：
```javascript
function enhancedPlayer(video, videoId) {
  const KEY = `pos:${videoId}`;
  const speeds = [0.5, 1, 1.25, 1.5, 2];
  let speedIdx = 1;

  // 恢复进度（等元数据加载完成才能 seek）
  const saved = +localStorage.getItem(KEY) || 0;
  video.addEventListener('loadedmetadata', () => {
    if (saved > 5 && saved < video.duration - 10) video.currentTime = saved; // 看过的不恢复
  }, { once: true });

  // 节流保存
  let lastSave = 0;
  const save = () => {
    if (!video.currentTime) return;
    localStorage.setItem(KEY, String(video.currentTime));
  };
  video.addEventListener('timeupdate', () => {
    const now = Date.now();
    if (now - lastSave > 5000) { lastSave = now; save(); } // 节流 5s
  });
  addEventListener('pagehide', save); // 离开兜底
  video.addEventListener('ended', () => localStorage.removeItem(KEY)); // 看完清除

  return {
    nextSpeed() {
      speedIdx = (speedIdx + 1) % speeds.length;
      video.playbackRate = speeds[speedIdx];
      return speeds[speedIdx];
    },
    reset() { speedIdx = 1; video.playbackRate = 1; },
  };
}
```

**评分点**：
- seek 必须在 loadedmetadata 之后（currentTime 受 duration 限制）
- 节流保存 + pagehide 兜底，双保险
- 「看完清除」与「结尾 10s 不恢复」的边界处理
- 倍速 playbackRate 循环切换与 reset
