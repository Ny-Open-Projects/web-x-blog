## WEB-497：笔试：手写请求去重合并

**题目**：实现 `dedupeFetch(url, opts)`：同 key（method+url+body）的并发请求只发一次，共享同一结果；请求失败时不缓存，下一个调用者可重新发起；带 TTL 的成功缓存可选。

**答**：
```javascript
const inflight = new Map();

function dedupeFetch(url, opts = {}) {
  const key = `${opts.method || 'GET'}|${url}|${opts.body || ''}`;

  if (inflight.has(key)) return inflight.get(key); // 复用在飞请求

  const p = fetch(url, opts)
    .then(res => {
      if (!res.ok) throw res.status; // 失败不缓存，删除在飞记录
      return res.json();
    })
    .finally(() => inflight.delete(key)); // 无论成败都移除在飞标记

  inflight.set(key, p);
  return p;
}

// 并发三个相同请求只发一次
const [a, b, c] = await Promise.all([
  dedupeFetch('/api/user'), dedupeFetch('/api/user'), dedupeFetch('/api/user'),
]);
```

**评分点**：
- key 的构成要素：method+url+body，漏 body 会导致 POST 串数据
- 在飞 Map 的「finally 删除」时机——成功失败都要删，否则失败被永久缓存
- 返回同一个 Promise 实例（共享结果），而不是各自再发
- 失败不缓存语义：异常后下一个调用重新发起
