## CSS-427：笔试：手写新手引导蒙层

**答**：实现引导：① 全屏半透明蒙层，目标元素区域「挖孔」高亮（box-shadow 巨值方案或 SVG mask）；② 高亮框随步骤移动（getBoundingClientRect 定位 + 平滑过渡）；③ 提示卡片定位在挖孔附近（上下自动翻转）；④ 步骤指示与上一步/下一步/跳过；⑤ 窗口 resize 重定位。写出核心实现。

```html
<div class="guide" hidden>
  <div class="hole"></div>
  <div class="tip-card">
    <p>这里可以发起转账</p>
    <footer><button class="skip">跳过</button><span class="step-no">1/3</span><button class="next">下一步</button></footer>
  </div>
</div>
```

```css
.guide { position: fixed; inset: 0; z-index: var(--z-overlay, 300); }
.hole {
  position: absolute;
  border-radius: 8px;
  transition: all .3s var(--ease-out-quart);
  /* 挖孔方案: 巨大 box-shadow 盖住全屏, 挖孔区域透明 */
  box-shadow: 0 0 0 100000px rgb(0 0 0 / .6);
  pointer-events: none;
}
.tip-card {
  position: absolute;
  background: #fff; border-radius: 12px;
  padding: 16px; width: 260px;
  box-shadow: 0 4px 16px #0003;
  transition: all .3s var(--ease-out-quart);
}
.tip-card::before {                 /* 指向箭头: 方向由 class 控制 */
  content: ''; position: absolute;
  border: 8px solid transparent;
}
.tip-card.pos-bottom::before { top: -16px; border-bottom-color: #fff; left: var(--ax, 50%); }
.tip-card.pos-top::before { bottom: -16px; border-top-color: #fff; left: var(--ax, 50%); }
```

```javascript
const STEPS = [{ sel: '#transfer-btn', text: '这里可以发起转账' }, /* ... */];
let i = 0;
function show(i) {
  const el = document.querySelector(STEPS[i].sel);
  const r = el.getBoundingClientRect();
  Object.assign(hole.style, {
    left: r.left - 8 + 'px', top: r.top - 8 + 'px',
    width: r.width + 16 + 'px', height: r.height + 16 + 'px',
  });
  // 卡片定位: 下方空间够放下方, 否则上方
  const below = innerHeight - r.bottom > 160;
  tip.className = 'tip-card ' + (below ? 'pos-top' : 'pos-bottom');
  Object.assign(tip.style, below
    ? { top: r.bottom + 16 + 'px', left: Math.min(r.left, innerWidth - 280) + 'px' }
    : { bottom: innerHeight - r.top + 16 + 'px', left: Math.min(r.left, innerWidth - 280) + 'px' });
  stepNo.textContent = `${i + 1}/${STEPS.length}`;
}
addEventListener('resize', () => show(i));
el.scrollIntoView({ block: 'center' });  // 目标不在视口先滚过去再定位
```

**评分点**：
- 巨值 box-shadow 挖孔方案（简单高效）及替代（SVG mask）
- 挖孔与卡片 transition 平滑移动 + resize 重定位
- 卡片上下自动翻转的空间判定
- 目标不在视口时先 scrollIntoView 再测（时序）
