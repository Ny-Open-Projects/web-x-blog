## WEB-425：HTTP/3 真的彻底消灭队头阻塞了吗

**答**：
- 分层看：TCP 层队头阻塞（一个包丢、整条连接等）在 QUIC 下彻底解决——流之间独立重传
- HTTP/2 的传输层队头阻塞没有了；但**应用层**的队头阻塞仍可能存在：单条流的响应处理是顺序的
- 还剩的坑：QUIC 的 ACK/拥塞控制是连接级的，极端丢包下所有流的发送速率都会受影响（只是影响远小于 TCP）
- 另一个残留：客户端带宽竞争——多条流共用一条连接，带宽不足时资源之间还是会互相排队（优先级调度来解决）
- 结论话术：H3 消灭的是「传输层队头阻塞」，不要把话说满，面试官爱追问这一层

```javascript
// 用优先级配合：关键 CSS/首屏数据给高优先级（fetch priority）
fetch('/api/first-screen', { priority: 'high' });
fetch('/api/recommend', { priority: 'low' });
```
