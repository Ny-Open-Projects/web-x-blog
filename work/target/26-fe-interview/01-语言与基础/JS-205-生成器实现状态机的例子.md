## JS-205：生成器实现状态机：红绿灯例子

**答**：
- 状态机的核心是「状态转移规则」；生成器把「当前状态」存在执行位置里，yield 产出状态、next 推进转移
- 优点：转移逻辑线性可读（从上到下就是状态流转），不用 switch/map 管理转移表
- 扩展：next(value) 可注入外部事件（如「紧急模式」打断正常循环）
- 对比：复杂状态机（大量并行/嵌套）用 XState 更合适；简单线性状态流生成器更轻

```javascript
function* trafficLight() {
  while (true) {
    yield { state: 'green', dur: 30000 };
    yield { state: 'yellow', dur: 3000 };
    yield { state: 'red', dur: 25000 };
  }
}
const light = trafficLight();
setInterval(() => {
  const { value, done } = light.next();
  console.log('当前:', value.state, `持续 ${value.dur}ms`);
}, 1000); // 每 1s 推进演示；真实实现按 dur 定时推进
```
