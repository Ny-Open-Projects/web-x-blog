## WEB-509：笔试：手写请求熔断器

**题目**：实现熔断器 `breaker.wrap(fetchFn)`：连续 3 次失败进入 open（直接快速失败 10s）；半开状态放行 1 次探测请求，成功则关闭，失败重回 open。

**答**：
```javascript
function createBreaker({ threshold = 3, cooldown = 10_000 } = {}) {
  let fails = 0, state = 'closed', openedAt = 0;

  function probe() {
    if (state === 'open' && Date.now() - openedAt >= cooldown) state = 'half-open';
    return state;
  }

  return async function wrapped(...args) {
    const st = probe();
    if (st === 'open') throw new Error('breaker open'); // 快速失败
    try {
      const result = await fetchFn(...args);
      fails = 0; state = 'closed'; // 半开成功 → 关闭
      return result;
    } catch (e) {
      fails++;
      if (state === 'half-open' || fails >= threshold) {
        state = 'open';
        openedAt = Date.now();
        fails = 0;
      }
      throw e;
    }
  };
}

const safeCall = createBreaker().wrap((u) => fetch(u).then(r => {
  if (!r.ok) throw r.status; return r.json();
}));
```

**评分点**：
- 三态机 closed/open/half-open 完整，半开只放行探测请求（并发时可用单飞锁优化）
- 连续失败计数在成功时清零
- open 期间快速失败不真正发请求，保护下游
- 状态转换条件：half-open 失败必须重回 open
