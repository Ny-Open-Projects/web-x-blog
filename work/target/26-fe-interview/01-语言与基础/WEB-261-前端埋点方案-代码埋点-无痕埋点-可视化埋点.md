## WEB-261：前端埋点方案：代码埋点、无痕埋点、可视化埋点

**答**：
- 代码埋点：业务代码里手动 `track('buy_click', {...})`。精准带上下文，但侵入性强、漏埋多。
- 无痕（全量）埋点：SDK 自动劫持点击/路由/PV，按 DOM 路径上报。零侵入，但语义弱、数据量大、需要清洗。
- 可视化埋点：运营在页面截图上圈选元素生成配置，SDK 按配置匹配上报。折中，维护成本在平台侧。
- 工程实践：sendBeacon 上报（不阻塞页面卸载）、批量合并 + 空闲上报（requestIdleCallback）、本地队列 + 失败重试、采样率控制。
- SPA 坑：路由切换触发 PV（监听 history.pushState）；单页应用内 exit page 判定要用 beforeunload/visibilitychange 兜底。

```javascript
// 最小无痕埋点 SDK
document.addEventListener('click', (e) => {
  const el = e.target.closest('[data-track]');
  const path = el ? el.dataset.track : cssPath(e.target);
  queue.push({ type: 'click', path, ts: Date.now() });
}, true);
addEventListener('pagehide', flush); // 用 sendBeacon 兜底上报队列
```
