## JS-415：笔试：手写超时降级链

**答**：实现 `withFallback(fn, fallbacks, { timeout })`：① 主 fn 超时/失败后依次尝试 fallback 函数数组；② 每层共享总预算（总 timeout 减去已耗时，不是每层独立 timeout）；③ 全部失败抛 AggregateError（收集各层错误）；④ 某层成功立即返回（不浪费预算）；⑤ 每层尝试记日志（onAttempt 回调）。写出实现。

```javascript
async function withFallback(fn, fallbacks, { timeout = 3000, onAttempt } = {}) {
  const start = performance.now();
  const errors = [];
  const layers = [fn, ...fallbacks];
  for (let i = 0; i < layers.length; i++) {
    const remain = timeout - (performance.now() - start);
    if (remain <= 0) break;                              // 预算耗尽
    onAttempt?.(i, remain);
    try {
      return await Promise.race([
        layers[i](),
        new Promise((_, rej) => setTimeout(() => rej(new Error(`layer ${i} timeout`)), remain)),
      ]);
    } catch (e) {
      errors.push({ layer: i, error: e });
    }
  }
  const agg = new AggregateError(errors.map(x => x.error), 'all fallback layers failed');
  agg.attempts = errors;
  throw agg;
}
// 用法: 主源超时 → CDN 源 → 本地缓存
const data = await withFallback(
  () => api.main(), [() => api.cdn(), () => cache.get('key')],
  { timeout: 3000, onAttempt: (i) => log(`trying layer ${i}`) },
);
```

**评分点**：
- 共享总预算（每层超时 = 剩余预算）
- 成功即返回不再消耗预算
- AggregateError 聚合各层错误 + attempts 元数据
- 预算耗尽提前退出（不空转剩余层）
