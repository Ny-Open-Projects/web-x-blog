## JS-367：异步队列：优先级与并发上限的通用任务队列

**答**：
- 通用任务队列 = 优先级队列 + 并发槽 + 取消 + 观测——「图片预加载（low）、接口请求（high）、埋点（batch）」可共用一个队列基础设施
- 优先级实现：多级队列（critical/high/normal/low 数组）+ 高级优先出队——比堆实现简单且语义清晰（级别有限）；同级 FIFO
- 并发上限分维度：全局上限 + 按 host/类型上限（图片 CDN 4 个、API 6 个）——细分维度防一类任务饿死另一类
- 取消与去重：任务携带 key，同 key 在队则去重；取消 = 标记惰性跳过（出队时检查）
- 观测与治理：队列深度告警（积压说明产能不足）、按类统计耗时、慢任务采样——队列是基础设施，可观测性是长期维护前提

```javascript
class TaskQueue {
  #lanes = { high: [], normal: [], low: [] };
  #flying = 0;
  constructor(maxConcurrency) { this.max = maxConcurrency; }
  push(key, fn, lane = 'normal') {
    if (this.#find(key)) return this.#find(key).promise;      // 同 key 去重
    const task = { key, fn, lane, cancelled: false };
    const promise = new Promise((res, rej) => Object.assign(task, { res, rej }));
    this.#lanes[lane].push(task);
    this.#drain();
    return promise;
  }
  cancel(key) { for (const lane of Object.values(this.#lanes)) { const t = lane.find(t => t.key === key); if (t) t.cancelled = true; } }
  #find(key) { for (const lane of Object.values(this.#lanes)) { const t = lane.find(t => t.key === key); if (t) return t; } }
  #drain() {
    while (this.#flying < this.max) {
      const task = this.#lanes.high.shift() ?? this.#lanes.normal.shift() ?? this.#lanes.low.shift();
      if (!task || task.cancelled) { if (task?.cancelled) continue; break; }
      this.#flying++;
      task.fn().then(task.res, task.rej).finally(() => { this.#flying--; this.#drain(); });
    }
  }
}
```
