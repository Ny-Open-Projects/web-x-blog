## H5-394：剪贴板与触感反馈：细微交互能力清单

**答**：
- 剪贴板异步 API：navigator.clipboard.writeText/readText 需 HTTPS + 用户手势；读操作 iOS/部分浏览器弹权限，失败降级 execCommand('copy')（老 API 兜底）
- 复制富文本：ClipboardItem 写 text/html（支持度差异），优惠券码/分享文案场景验证双端
- 触感反馈：navigator.vibrate 仅 Android，iOS 无 Web API——App 内走桥（UIImpactFeedback），浏览器内 iOS 用 CSS 动画/声音反馈替代
- 输入触感：键盘触感是系统层，H5 只能通过 input 类型（type=number 触数字键盘）与 inputmode 控制键盘形态优化输入体验
- 微交互的降级哲学：能力不可用时必须有「无触感的等价反馈」（视觉高亮/音效），不能静默失效

```javascript
async function copyCode(code) {
  try { await navigator.clipboard.writeText(code); }
  catch {
    const ta = document.createElement('textarea');   // 降级: execCommand
    ta.value = code; document.body.appendChild(ta);
    ta.select(); document.execCommand('copy'); ta.remove();
  }
  toast('已复制');
  if (navigator.vibrate) navigator.vibrate(15);      // Android 轻触感
  else el.classList.add('flash');                    // iOS 视觉反馈替代
}
```
