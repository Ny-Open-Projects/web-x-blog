## JS-407：笔试：手写环形缓冲区

**答**：实现 `RingBuffer(capacity)`：① push 满员时覆盖最旧（记录 dropped 计数）；② 迭代顺序从最旧到最新；③ toSorted/last(n)/first(n) 快捷方法；④ drain()：取出全部并清空（消费语义）；⑤ O(1) push。写出实现。

```javascript
class RingBuffer {
  #buf; #head = 0; #size = 0; #dropped = 0;
  constructor(capacity) {
    this.capacity = capacity;
    this.#buf = new Array(capacity);
  }
  push(item) {
    if (this.#size === this.capacity) {                        // 满: 覆盖最旧
      this.#dropped++;
      this.#head = (this.#head + 1) % this.capacity;           // head 前移 = 丢最旧
      this.#size--;
    }
    this.#buf[(this.#head + this.#size) % this.capacity] = item;
    this.#size++;
    return this;
  }
  *[Symbol.iterator]() {
    for (let i = 0; i < this.#size; i++)
      yield this.#buf[(this.#head + i) % this.capacity];      // 最旧→最新
  }
  last(n = 1) { return [...this].slice(-n); }
  first(n = 1) { return [...this].slice(0, n); }
  drain() {
    const out = [...this];
    this.#head = 0; this.#size = 0;
    return out;
  }
  get dropped() { return this.#dropped; }
  get size() { return this.#size; }
}
// 场景: 最近 N 条日志/操作历史(内存恒定)
const log = new RingBuffer(100);
```

**评分点**：
- head/size 双指针环绕索引计算正确（push 覆盖时 head 前移）
- 迭代顺序最旧到最新（模运算遍历）
- dropped 计数可观测覆盖次数
- drain 消费语义（取出并重置指针）
