## WEB-281：前端监控的错误聚合与告警降噪怎么做？

**答**：
- 聚合指纹：用「错误类型 + message 正则归一化（去动态值）+ 堆栈首帧文件:行」生成 hash，同指纹合并成 issue，附出现次数/影响用户数/首次出现版本。
- 降噪手段：采样率（低危错误抽 10%）、同用户同错误去重（session 内只报一次）、忽略已知噪声（扩展程序注入、resize observer 循环）、依赖版本比对（新报错是否来自新发版）。
- 告警分级：P0（核心页面 JS 错误率突增/白屏率超阈值→电话）、P1（错误量级增长→IM 群）、P2（汇总日报）。基线用同比环比，绝对阈值随流量调整。
- 闭环：issue → 定位 release/commit → owner 认领 → 修复后验证趋势回落 → 关闭。

```javascript
function fingerprint(err) {
  const firstFrame = err.stack?.split('\n')[1] || '';
  return hash([err.name, normalize(err.message), firstFrame].join('|'));
  // normalize: 把数字/uuid/URL 替换成 <var>，让同模式错误聚合
}
```
