## JS-295：笔试：深拷贝的边界补充

**题目**：structuredClone 与常见手写版都不处理函数与「带行为的类实例」。实现增强：函数引用共享；类实例保留原型方法与私有状态（Object.create + 属性复制）；说明何时应放弃深拷贝改用序列化协议。

**答**：
```javascript
function cloneWithBehavior(obj, seen = new WeakMap()) {
  if (typeof obj === 'function') return obj;              // 函数共享引用（无法克隆闭包）
  if (obj === null || typeof obj !== 'object') return obj;
  if (seen.has(obj)) return seen.get(obj);
  if (obj instanceof Date || obj instanceof RegExp || obj instanceof Map || obj instanceof Set)
    return deepClone(obj, seen);                          // 内建类型走基础版

  // 类实例：新空对象 + 继承原型（方法自动可用）
  const out = Object.create(Object.getPrototypeOf(obj));
  seen.set(obj, out);
  for (const k of Reflect.ownKeys(obj)) {
    const d = Object.getOwnPropertyDescriptor(obj, k);
    Object.defineProperty(out, k, {
      ...d,
      value: typeof d.value === 'object' && d.value !== null
        ? cloneWithBehavior(d.value, seen) : d.value,
    });
  }
  return out;
}
class Cart { constructor(items) { this.items = items; } total() { return this.items.length; } }
const c2 = cloneWithBehavior(new Cart([1, 2]));
c2.total();      // 2 —— 方法可用（原型继承）
c2.items !== undefined && c2 instanceof Cart; // true
```

**评分点**：
- 函数无法克隆、引用共享的认知（闭包不可复制）
