## WEB-606：笔试：手写轮询调度器（前台密集 / 后台稀疏）

**答**：实现 `SmartPoller`：① 前台每 3s 轮询一次接口；② hidden 后降为每 60s 一次（绝对时间调度防定时器节流漂移）；③ 连续 3 次请求失败进入退避模式（间隔 ×2，上限 10 分钟），成功后恢复；④ 回前台时立即触发一次轮询并重置失败计数；⑤ stop() 清理一切。写出核心实现。

```javascript
class SmartPoller {
  constructor({ fgMs = 3000, bgMs = 60_000, maxMs = 600_000 } = {}) {
    this.fg = fgMs; this.bg = bgMs; this.max = maxMs;
    this.fails = 0; this.timer = null; this.stopped = false;
    document.addEventListener('visibilitychange', () => {
      if (document.visibilityState === 'visible') { this.fails = 0; this._tick(true); }
    });
    this._tick(true);
  }
  _interval() {
    const base = document.visibilityState === 'hidden' ? this.bg : this.fg;
    return Math.min(base * 2 ** this.fails, this.max);
  }
  async _tick(immediate = false) {
    clearTimeout(this.timer);
    if (this.stopped) return;
    const run = async () => {
      try { await this.fetcher(); this.fails = 0; }
      catch { this.fails++; }
      this._next();
    };
    if (immediate) run();
    else this._next();
  }
  _next() {
    const wait = Math.max(0, this.nextAt - Date.now());
    this.nextAt = Date.now() + this._interval();
    this.timer = setTimeout(() => this._tick(false), this._interval());
  }
  stop() { this.stopped = true; clearTimeout(this.timer); }
}
```

**评分点**：
- 前后台双间隔，后台用绝对时间考虑浏览器节流
- 失败指数退避 + 上限 + 成功恢复
- 回前台立即轮询并清零失败计数
- stop 清理无泄漏
