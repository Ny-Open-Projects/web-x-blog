## H5-312：笔试：手写音频解锁播放器

**题目**：实现移动端音频自动播放兜底：首次尝试直接播放；被拒后静音播放 + 任意首次交互解锁声音；提供 onUnlock 回调；解锁状态可查询。

**答**：
```javascript
function createAudioPlayer(src) {
  const audio = new Audio(src);
  audio.loop = true;
  let unlocked = false;

  const unlock = () => {
    unlocked = true;
    audio.muted = false;
    audio.volume = 1;
    // iOS 上 AudioContext 也需要 resume
    window.__audioCtx?.resume?.();
    document.removeEventListener('pointerdown', unlock);
    document.removeEventListener('touchend', unlock);
    handlers.onUnlock?.();
  };

  async function tryPlay() {
    try {
      await audio.play();
      if (!unlocked) {
        // 播放成功但可能是静音降级或浏览器允许
        audio.muted = true; // 先静音保证稳定
        document.addEventListener('pointerdown', unlock, { once: true });
        document.addEventListener('touchend', unlock, { once: true });
      }
    } catch {
      // 完全被拒：静音播 + 等解锁
      audio.muted = true;
      audio.play().catch(() => {});
      document.addEventListener('pointerdown', unlock, { once: true });
      document.addEventListener('touchend', unlock, { once: true });
    }
  }
  const handlers = { onUnlock: null };
  return {
    play: tryPlay,
    pause: () => audio.pause(),
    get unlocked() { return unlocked; },
    onUnlock(fn) { handlers.onUnlock = fn; },
  };
}
```

**评分点**：
- play() 返回 Promise 的 rejection 处理（未处理会 console 报错）
- 解锁监听用 { once: true } 防重复
- iOS AudioContext resume 联动（有 WebAudio 场景）
- unlocked 状态查询 + onUnlock 回调供 UI 更新
