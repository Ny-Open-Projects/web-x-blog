## JS-419：笔试：手写上下文传递的瀑布执行器

**答**：实现 `waterfall(steps)`：① steps 是 `[{ name, fn }]`，fn 接收 `(ctx, prev)`——ctx 贯穿全程（可被步骤修改），prev 是上一步返回值；② 返回 `{ ctx, results }`（results 按名索引）；③ 步骤可声明 `optional: true`，失败记 undefined 继续；④ 非可选失败中断并返回已完成部分 + 失败步骤名；⑤ 步骤耗时统计 per-step。写出实现。

```javascript
async function waterfall(steps) {
  const ctx = {};
  const results = {};
  const timings = {};
  for (const { name, fn, optional } of steps) {
    const t0 = performance.now();
    try {
      results[name] = await fn(ctx, results[steps[steps.indexOf({ name, fn, optional }) - 1]?.name]);
      // prev 更稳的实现: 记录 prevResult 变量
    } catch (e) {
      if (optional) { results[name] = undefined; }
      else return { ctx, results, timings, failedAt: name, error: e };
    }
    timings[name] = performance.now() - t0;
  }
  return { ctx, results, timings };
}
// 修正 prev 传递:
async function waterfall2(steps) {
  const ctx = {}, results = {}, timings = {};
  let prev;
  for (const { name, fn, optional } of steps) {
    const t0 = performance.now();
    try {
      prev = results[name] = await fn(ctx, prev);
    } catch (e) {
      if (optional) results[name] = undefined;
      else return { ctx, results, timings, failedAt: name, error: e };
    }
    timings[name] = +(performance.now() - t0).toFixed(1);
  }
  return { ctx, results, timings };
}
// 用法: 登录 → 拉权限 → 拉首屏(optional)
```

**评分点**：
- ctx 与 prev 双通道传递（贯穿 vs 相邻）
- optional 失败标记 undefined 继续 / 非可选中断返回失败步骤名
- per-step 耗时统计（可观测性）
- 中断返回已完成部分
