## CSS-415：笔试：手写圆形倒计时进度环

**答**：实现倒计时：① 圆环进度（conic-gradient）随剩余时间递减；② 中央数字倒计时（每秒跳动）；③ 最后 10s 变红 + 数字脉冲；④ 暂停/恢复；⑤ 时长参数化（任意秒数）。给出 @property 注册与 JS 计时实现。

```html
<div class="timer" style="--dur: 60">
  <div class="ring"><span class="num">60</span></div>
  <button class="toggle">暂停</button>
</div>
```

```css
@property --p { syntax: '<number>'; inherits: false; initial-value: 100; }
.timer .ring {
  --p: 100;
  width: 120px; height: 120px; border-radius: 50%;
  display: grid; place-items: center;
  background: conic-gradient(var(--ring-c, var(--primary)) calc(var(--p) * 1%), #eee 0);
  transition: --p 1s linear;             /* 每秒平滑走一格 */
}
.timer .num { font-size: 32px; font-variant-numeric: tabular-nums; }  /* 等宽数字防跳动 */
.timer.urgent { --ring-c: #f5222d; }
.timer.urgent .num { animation: beat 1s infinite; color: #f5222d; }
@keyframes beat { 50% { transform: scale(1.15); } }
.timer.paused .ring { transition-play-state: paused; } /* 需 JS 冻结 --p */
```

```javascript
class Countdown {
  constructor(el, totalSec) {
    this.el = el; this.total = totalSec; this.left = totalSec; this.timer = null;
    this.render();
  }
  render() {
    this.el.style.setProperty('--p', this.left / this.total * 100);
    this.el.querySelector('.num').textContent = this.left;
    this.el.classList.toggle('urgent', this.left <= 10);
  }
  start() {
    clearInterval(this.timer);
    this.timer = setInterval(() => {
      this.left--;
      this.render();
      if (this.left <= 0) { clearInterval(this.timer); this.onEnd?.(); }
    }, 1000);
  }
  pause() { clearInterval(this.timer); this.el.classList.add('paused'); }
  resume() { this.el.classList.remove('paused'); this.start(); }
}
```

**评分点**：
- @property 注册 --p 使 conic 进度可 transition（平滑递减）
- tabular-nums 等宽数字防止秒数跳动抖动
- urgent 变体（色环 + 脉冲）阈值切换
- 暂停/恢复实现与 setInterval 清理
