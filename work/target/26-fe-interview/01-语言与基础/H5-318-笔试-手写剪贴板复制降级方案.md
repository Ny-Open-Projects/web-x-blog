## H5-318：笔试：手写剪贴板复制降级方案

**题目**：实现 `copyText(text)` 三级降级：异步 clipboard API → execCommand 兜底（需临时选区）→ 提示用户手动复制。返回 { ok, method }。要求在非手势上下文也能工作（execCommand 路径）。

**答**：
```javascript
async function copyText(text) {
  // 一级：现代异步 API（需 https + 手势）
  if (navigator.clipboard?.writeText) {
    try {
      await navigator.clipboard.writeText(text);
      return { ok: true, method: 'async' };
    } catch { /* 继续降级 */ }
  }
  // 二级：execCommand（需真实选区，同步 API）
  try {
    const ta = document.createElement('textarea');
    ta.value = text;
    ta.style.cssText = 'position:fixed;opacity:0;'; // 不可见但可选中
    document.body.appendChild(ta);
    ta.focus(); ta.select();                        // iOS 需要 focus
    const ok = document.execCommand('copy');
    document.body.removeChild(ta);
    if (ok) return { ok: true, method: 'execCommand' };
  } catch { /* 继续降级 */ }
  // 三级：提示手动复制
  prompt('请手动复制：', text);
  return { ok: false, method: 'manual' };
}
```

**评分点**：
- 三级降级链完整，每级失败必须继续而不是抛出
- execCommand 需要「可见可选中的 textarea」+ focus + select——用 fixed+opacity 隐藏（display:none 选中无效）
- clipboard API 失败常见原因（非手势/非 https）能说出来
- 返回 method 让调用方区分提示文案
