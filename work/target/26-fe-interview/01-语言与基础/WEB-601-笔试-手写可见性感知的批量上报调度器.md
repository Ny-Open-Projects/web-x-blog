## WEB-601：笔试：手写可见性感知的批量上报调度器

**答**：实现 `VisReporter`：① 前台每 10s 或队列满 20 条批量上报；② 页面 hidden/pagehide 时立即 flush（用 sendBeacon，避免丢失）；③ 后台期间事件仍入队但暂停定时器（配合后台节流，不浪费唤醒）；④ flush 失败（fetch 降级路径）重试一次后丢弃；⑤ 队列上限 500 条防 OOM（满了丢最旧的并计数）。写出核心实现。

```javascript
class VisReporter {
  constructor(url) {
    this.url = url; this.queue = []; this.dropped = 0;
    this.timer = setInterval(() => this.flush(), 10_000);
    document.addEventListener('visibilitychange', () => {
      if (document.visibilityState === 'hidden') {
        clearInterval(this.timer); this.flush(true);
      } else this.timer = setInterval(() => this.flush(), 10_000);
    });
    addEventListener('pagehide', () => this.flush(true));
  }
  push(e) {
    if (this.queue.length >= 500) { this.queue.shift(); this.dropped++; }
    this.queue.push({ ...e, t: Date.now() });
    if (this.queue.length >= 20) this.flush();
  }
  flush(urgent = false) {
    if (!this.queue.length) return;
    const batch = { events: this.queue.splice(0), dropped: this.dropped };
    this.dropped = 0;
    if (urgent) { navigator.sendBeacon(this.url, JSON.stringify(batch)); return; }
    fetch(this.url, { method: 'POST', body: JSON.stringify(batch), keepalive: true })
      .catch(() => navigator.sendBeacon(this.url, JSON.stringify(batch))); // 重试一次
  }
}
```

**评分点**：
- 三种触发通道齐全（定时/批量/pagehide）且 pagehide 走 sendBeacon
- 后台暂停定时器配合浏览器节流，恢复时重建
- 队列上限 + 丢最旧 + 计数上报，防内存泄漏可观测
- keepalive/fetch 失败降级 sendBeacon 的兜底链
