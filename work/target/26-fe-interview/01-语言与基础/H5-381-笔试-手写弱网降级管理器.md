## H5-381：笔试：手写弱网降级管理器

**答**：实现 `DegradeManager`：① 按网络档位决定能力开关：effectiveType/rtt/saveData 三输入映射为档位（good/normal/poor/offline-ish）；② 各档位能力表：poor 关图片自动加载（低清图）、关视频预加载、埋点降频、关闭预取；③ 档位切换监听（connection change）实时生效并广播事件；④ 提供 isAllowed(cap) 查询接口；⑤ saveData 模式无论实际网速都按 poor 处理。写出核心实现与能力表结构。

```javascript
const CAP_TABLE = {
  good:   { img: 'high', video: 'auto', prefetch: true, trackRate: 1 },
  normal: { img: 'auto', video: 'metadata', prefetch: true, trackRate: 1 },
  poor:   { img: 'low', video: 'none', prefetch: false, trackRate: 0.3 },
};

class DegradeManager {
  constructor() {
    this.conn = navigator.connection || {};
    this.cap = this._evaluate();
    this.listeners = new Set();
    this.conn.addEventListener?.('change', () => {
      const next = this._evaluate();
      if (JSON.stringify(next) !== JSON.stringify(this.cap)) {
        this.cap = next;
        this.listeners.forEach(fn => fn(this.cap, this.level));
      }
    });
  }
  _evaluate() {
    const t = this.conn.effectiveType || '4g';
    this.level = this.conn.saveData || t === '2g' || (this.conn.rtt || 0) > 800 ? 'poor'
      : t === '3g' || (this.conn.rtt || 0) > 400 ? 'normal' : 'good';
    return CAP_TABLE[this.level];
  }
  isAllowed(cap) { return !!this.cap[cap]; }
  imgSrc(src) { // 按档位出图
    const q = this.cap.img;
    return q === 'low' ? src.replace(/(\.\w+)$/, '.low$1') : src;
  }
  onChange(fn) { this.listeners.add(fn); return () => this.listeners.delete(fn); }
}
```

**评分点**：
- 三输入（effectiveType/rtt/saveData）综合判档，saveData 强制 poor
- 能力表结构可扩展，档位映射清晰
- change 监听实时切换并广播（比较后才广播防重复）
- imgSrc 按档位出低清图的落地接口
