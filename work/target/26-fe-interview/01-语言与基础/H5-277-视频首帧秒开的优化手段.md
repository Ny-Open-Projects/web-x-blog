## H5-277：视频首帧秒开的优化手段

**答**：
- 编码侧：关键帧（GOP 首帧）提前——首帧间隔越短解码越快；编码为 fMP4 且 moov 前置（快速失败流），避免整个文件下载完才能播
- 传输侧：CDN 边缘预热、首片（1~2 秒的初始段）单独小文件、HTTP/3 或 QUIC 减握手
- 客户端侧：preload="auto" 抢加载、poster 图兜底感知、解码前隐藏 video 直到 loadeddata 事件（防黑屏闪烁）
- 播放器侧：首帧渲染超时降级（2s 没出画面切低码率）、预加载下一条（信息流场景）
- 指标定义：首帧时间 = 发起播放到第一帧上屏，分位数（P90）看而不是平均值

```javascript
video.addEventListener('loadeddata', () => video.classList.remove('hidden'), { once: true });
// 转码命令：moov 前置 + 短 GOP
// ffmpeg -i in.mp4 -movflags faststart -g 30 -c:v libx264 out.mp4
```
