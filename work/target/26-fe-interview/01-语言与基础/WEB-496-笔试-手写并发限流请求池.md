## WEB-496：笔试：手写并发限流请求池

**题目**：实现 `pLimit(n)`：返回包装函数，保证同一时刻最多 n 个请求在飞；支持 `pool.clear()` 清空排队任务与 `pool.activeCount`。

**答**：
```javascript
function pLimit(n) {
  const queue = [];
  let active = 0;

  const next = () => {
    if (active >= n || !queue.length) return;
    active++;
    const { fn, resolve, reject } = queue.shift();
    fn().then(resolve, reject).finally(() => {
      active--;
      next();
    });
  };

  const limit = (fn) => new Promise((resolve, reject) => {
    queue.push({ fn, resolve, reject });
    next();
  });

  limit.clear = () => { queue.forEach(({ reject }) => reject(new Error('cancelled'))); queue.length = 0; };
  Object.defineProperty(limit, 'activeCount', { get: () => active });
  return limit;
}

// 用法
const limit = pLimit(3);
urls.forEach(u => limit(() => fetch(u)).then(console.log));
limit.clear();
```

**评分点**：
- 队列 + active 计数的基本模型正确；任务完成必须触发 next()
- clear 要 reject 排队中的 Promise（不能只清数组，否则调用方永远 pending）
- activeCount 只读访问器的实现
- 能讲清楚为什么不是 setTimeout 轮询而是事件驱动调度（加分）
