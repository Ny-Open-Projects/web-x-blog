## CSS-404：笔试：手写文件拖拽上传区

**答**：实现上传区：① 虚线框占位，拖入时高亮（dragover 态）；② 拖入态要用 dragenter/leave 计数器解决「子元素触发 leave」的闪烁问题；③ 每文件一行：名称/大小/进度环（conic-gradient + @property）或进度条；④ 错误文件红色标记与原因；⑤ 粘贴（paste）上传图片支持。写出核心实现。

```html
<div class="drop" id="drop">
  <p>拖拽文件到此处，或</p><button>选择文件</button>
  <input type="file" multiple hidden>
  <ul class="files"></ul>
</div>
```

```css
.drop {
  border: 2px dashed #ccc; border-radius: 12px;
  padding: 32px; text-align: center;
  transition: all .2s;
}
.drop.over {
  border-color: var(--primary);
  background: color-mix(in oklab, var(--primary) 8%, white);
  transform: scale(1.01);
}
.row { display: flex; align-items: center; gap: 12px; margin-top: 12px; }
.row .ring {
  --p: 0;
  width: 28px; height: 28px; border-radius: 50%;
  background: conic-gradient(var(--primary) calc(var(--p) * 1%), #eee 0);
  transition: --p .2s;                    /* @property 注册后可过渡 */
}
.row.err { color: #f5222d; }
.row.err .ring { background: conic-gradient(#f5222d calc(var(--p) * 1%), #eee 0); }
```

```javascript
const drop = document.getElementById('drop');
let depth = 0;                                     // 计数器防子元素闪烁
['dragenter', 'dragleave', 'drop', 'dragover'].forEach(ev =>
  drop.addEventListener(ev, (e) => {
    e.preventDefault();
    if (ev === 'dragenter') { depth++; drop.classList.add('over'); }
    if (ev === 'dragleave' && --depth === 0) drop.classList.remove('over');
    if (ev === 'drop') { depth = 0; drop.classList.remove('over'); upload([...e.dataTransfer.files]); }
  }));
document.addEventListener('paste', (e) => {
  const imgs = [...e.clipboardData.files].filter(f => f.type.startsWith('image/'));
  if (imgs.length) upload(imgs);
});
async function upload(files) {
  for (const f of files) {
    const row = addRow(f);
    const fd = new FormData(); fd.append('file', f);
    const xhr = new XMLHttpRequest();
    xhr.upload.onprogress = (e) => row.ring.style.setProperty('--p', Math.round(e.loaded / e.total * 100));
    xhr.open('POST', '/api/upload'); xhr.send(fd);
    xhr.onload = () => xhr.status >= 400 && row.el.classList.add('err');
  }
}
```

**评分点**：
- dragenter/leave 深度计数器解决子元素闪烁（核心考点）
- conic-gradient 进度环 + @property 可过渡
- paste 事件剪贴板文件上传
- dragover preventDefault 才能触发 drop（行为链理解）
