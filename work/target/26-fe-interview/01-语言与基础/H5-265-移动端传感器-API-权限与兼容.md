## H5-265：振动/重力感应等移动端传感器 API 的权限与兼容

**答**：
- 振动：`navigator.vibrate([100, 50, 100])`（毫秒序列）；必须用户手势触发；iOS Safari 完全不支持——功能设计要有无声降级
- 加速度/陀螺仪：DeviceMotionEvent（晃动检测）与 DeviceOrientationEvent（方向）；iOS 13+ 需要 `DeviceOrientationEvent.requestPermission()` 显式授权（必须手势内调用）
- 通用限制：都需要 https；后台 tab 会被暂停；桌面浏览器无传感器直接不支持
- 隐私审查：传感器数据可用于指纹识别，所以浏览器加了权限与频率限制，设计上别依赖精确数值
- 交互场景：摇一摇、重力视差（卡片 3D 倾斜）、计步类小游戏——注意提供关闭入口（有晕眩用户）

```javascript
shakeBtn.onclick = async () => {
  if (typeof DeviceMotionEvent.requestPermission === 'function') {
    const state = await DeviceMotionEvent.requestPermission();
    if (state !== 'granted') return;
  }
  addEventListener('devicemotion', ({ acceleration }) => {
    const mag = Math.hypot(acceleration.x, acceleration.y, acceleration.z);
    if (mag > 25) triggerShake(); // iOS 降级：无振动，改用视觉反馈
  });
};
```
