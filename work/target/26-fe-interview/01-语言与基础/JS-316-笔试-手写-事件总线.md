## JS-316：笔试：手写事件总线

**题目**：实现 `EventBus`：on/off/once/emit；同名事件多监听；emit 传参与 this 可控；off 需匹配原引用（匿名函数无法解绑的说明）；通配符 `*` 监听所有事件（加分）。

**答**：
```javascript
class EventBus {
  #handlers = new Map(); // event -> Set<fn>

  on(event, fn) {
    if (!this.#handlers.has(event)) this.#handlers.set(event, new Set());
    this.#handlers.get(event).add(fn);
    return () => this.off(event, fn); // 返回退订
  }
  once(event, fn) {
    const wrap = (...args) => { this.off(event, wrap); fn(...args); };
    wrap._origin = fn;               // 保留原引用供 off 匹配
    return this.on(event, wrap);
  }
  off(event, fn) {
    const set = this.#handlers.get(event);
    if (!set) return;
    // 匹配包装器或原函数
    for (const h of set) {
      if (h === fn || h._origin === fn) set.delete(h);
    }
  }
  emit(event, ...args) {
    this.#handlers.get(event)?.forEach(fn => fn(...args));
    this.#handlers.get('*')?.forEach(fn => fn(event, ...args)); // 通配
  }
}

const bus = new EventBus();
const cb = (n) => console.log('got', n);
bus.on('msg', cb);
bus.once('msg', () => console.log('only once'));
bus.on('*', (ev, ...a) => console.log('[all]', ev, ...a));
bus.emit('msg', 42);  // got 42 / only once / [all] msg 42
bus.emit('msg', 7);   // got 7 / [all] msg 7 —— once 已自解绑
bus.off('msg', cb);
```

**评分点**：
- Set 存 handler（天然去重、O(1) 删除）
- once 用包装器 + _origin 保留原引用（off 兼容原函数）——细节判分
- off 必须引用匹配（匿名函数问题说明）
- 返回退订函数 + 通配符扩展（加分）
