## WEB-506：笔试：手写请求慢日志收集器

**题目**：实现 `slowLog()`：包装 fetch，超过阈值（默认 2s）的请求记录 `{url, dur, status}`；环形缓冲最多 50 条；提供 `getSlowLog()` 与自动周期上报。

**答**：
```javascript
function createSlowLog({ threshold = 2000, cap = 50, flushMs = 30000 } = {}) {
  const buf = [];

  const _fetch = window.fetch;
  window.fetch = async (...args) => {
    const t0 = performance.now();
    const url = typeof args[0] === 'string' ? args[0] : args[0].url;
    try {
      const res = await _fetch(...args);
      const dur = performance.now() - t0;
      if (dur > threshold) {
        buf.push({ url: url.split('?')[0], dur: Math.round(dur), status: res.status, at: Date.now() });
        if (buf.length > cap) buf.shift(); // 环形缓冲
      }
      return res;
    } catch (e) {
      const dur = performance.now() - t0;
      buf.push({ url: url.split('?')[0], dur: Math.round(dur), status: 'network', at: Date.now() });
      throw e;
    }
  };

  setInterval(() => {
    if (buf.length) navigator.sendBeacon('/api/slow-log', JSON.stringify(buf.splice(0)));
  }, flushMs);

  return { getSlowLog: () => [...buf] };
}
createSlowLog();
```

**评分点**：
- 包装 fetch 收集，而非侵入每个业务调用点
- 网络异常也要计入（catch 分支），不只看慢响应
- 环形缓冲（shift）控内存；去 query 再记 URL 防维度爆炸
- 周期性 flush 用 sendBeacon；getSlowLog 返回副本防止外部修改
