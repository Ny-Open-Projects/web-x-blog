## CSS-396：笔试：手写轮播图（scroll-snap 方案）

**答**：用 scroll-snap 实现：① 横向滚动吸附整屏、每屏一张图；② 指示点高亮当前屏；③ 圆点/箭头点击跳转（scrollTo）；④ 自动轮播（定时 scrollTo next，用户触摸后暂停）；⑤ 无 JS 也能翻（原生滚动惯性 + snap）。写出核心实现与自动轮播控制。

```html
<div class="carousel" id="car">
  <img src="1.jpg" alt="">
  <img src="2.jpg" alt="">
  <img src="3.jpg" alt="">
  <nav class="dots"></nav>
</div>
```

```css
.carousel {
  display: flex; overflow-x: auto;
  scroll-snap-type: x mandatory;
  scroll-behavior: smooth;
  scrollbar-width: none;
}
.carousel img {
  flex: 0 0 100%;
  scroll-snap-align: center;
  aspect-ratio: 16/9; object-fit: cover;
}
.dots { position: absolute; bottom: 12px; display: flex; gap: 8px; }
.dots i { width: 8px; height: 8px; border-radius: 50%; background: #0006; transition: background .2s; }
.dots i.on { background: #fff; }
```

```javascript
const car = document.getElementById('car');
const n = car.children.length;
let timer, userHold = false;

function go(i) {
  car.scrollTo({ left: i * car.clientWidth, behavior: 'smooth' });
}
function cur() { return Math.round(car.scrollLeft / car.clientWidth); }
function renderDots() {
  dots.querySelectorAll('i').forEach((d, i) => d.classList.toggle('on', i === cur()));
}
car.addEventListener('scroll', () => { renderDots(); }, { passive: true });
car.addEventListener('pointerdown', () => { userHold = true; clearInterval(timer); });
car.addEventListener('pointerup', () => { userHold = false; autoplay(); });
function autoplay() {
  clearInterval(timer);
  timer = setInterval(() => {
    if (!userHold) go((cur() + 1) % n);
  }, 3000);
}
autoplay();
```

**评分点**：
- scroll-snap-type mandatory + snap-align 实现吸附（原生滚动兼容）
- 当前屏索引 = round(scrollLeft / 宽度)
- 用户交互暂停自动轮播（pointerdown/up 状态）
- scrollTo 平滑翻页 + 取余循环
