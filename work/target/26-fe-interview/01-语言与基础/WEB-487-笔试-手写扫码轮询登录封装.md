## WEB-487：笔试：手写扫码轮询登录封装

**题目**：实现 `qrLogin()`：请求二维码 ID → 每 1.5s 轮询状态（waiting/scanned/confirmed/expired）→ expired 时静默刷新二维码重启轮询 → confirmed 返回 token。支持手动取消。

**答**：
```javascript
function qrLogin(onState) {
  let cancelled = false;
  let ctrl = new AbortController();

  async function run() {
    const { qrId } = await fetch('/api/qr/create', { signal: ctrl.signal }).then(r => r.json());
    onState({ status: 'waiting', qrId });

    while (!cancelled) {
      const { status, token } = await fetch(`/api/qr/${qrId}/status`, { signal: ctrl.signal })
        .then(r => r.json());
      onState({ status });
      if (status === 'confirmed') return token;
      if (status === 'expired') return run(); // 换码重来
      await new Promise(r => setTimeout(r, 1500));
    }
  }
  run();
  return {
    cancel() { cancelled = true; ctrl.abort(); },
  };
}

// 用法
const login = qrLogin(s => render(s.status));
login.cancel(); // 页面卸载时必须调用，否则轮询泄漏
```

**评分点**：
- 轮询必须带取消机制（AbortController + 标志位），否则组件卸载后持续请求
- expired 分支递归换码重启，而不是死等
- 状态回调 onState 抽象，让 UI 与逻辑解耦
- 能提长连接优化（SSE/WS）作为升级方向（加分）
