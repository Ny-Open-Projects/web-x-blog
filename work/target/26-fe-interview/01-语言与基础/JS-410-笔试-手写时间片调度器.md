## JS-410：笔试：手写时间片调度器

**答**：实现 `TimeSlicer`：① `run(genFn, { budget = 8 })`：驱动生成器，每片预算 budget ms，耗尽让出主线程（MessageChannel 立即让出，不用 setTimeout 4ms）；② 生成器 yield 即主动让出点；③ 支持外部取消（signal）；④ 返回 { result, slices, elapsed }（切片数统计）；⑤ 生成器抛错传播。写出实现。

```javascript
class TimeSlicer {
  #chan = new MessageChannel();
  constructor() {
    this.#p = new Promise(r => this.#chan.port1.onmessage = r);
  }
  #p;
  yieldNow() { return this.#p.then(() => this.#reset()); }
  #reset() { this.#p = new Promise(r => this.#chan.port1.onmessage = r); this.#chan.port2.postMessage(0); }

  async run(genFn, { budget = 8, signal } = {}) {
    const it = genFn();
    const start = performance.now();
    let slices = 0, lastYield = start, input;
    while (true) {
      signal?.throwIfAborted();
      const { value, done } = it.next(input);
      if (done) return { result: value, slices, elapsed: performance.now() - start };
      input = value?.yield ? await value.result : value;   // yield 可带异步结果
      if (performance.now() - lastYield >= budget) {       // 片耗尽
        slices++;
        await this.yieldNow();                              // MessageChannel: 微任务后立即宏任务
        lastYield = performance.now();
      }
    }
  }
}
// 用法: 大数组处理不阻塞交互
const slicer = new TimeSlicer();
const { result } = slicer.run(function* () {
  const out = [];
  for (let i = 0; i < 1e6; i++) {
    out.push(transform(data[i]));
    if (i % 1000 === 0) yield;        // 主动让出点
  }
  return out;
});
```

**评分点**：
- MessageChannel 让出（无 setTimeout 4ms 聚合损耗）
- budget 预算检查与切片计数
- signal.throwIfAborted 取消检查点
- 生成器 value 注入（异步结果回填 input）
