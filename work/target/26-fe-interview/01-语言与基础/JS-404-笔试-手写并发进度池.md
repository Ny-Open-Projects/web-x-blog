## JS-404：笔试：手写并发进度池

**答**：实现 `pool(items, worker, { concurrency, onProgress })`：① 按 concurrency 并发处理 items（每项调 worker(item)）；② 实时进度：onProgress({ done, total, failed, current }) 每项完成时触发；③ 单项失败收集但不中断（返回 { results, errors } 按序对齐）；④ 支持取消（AbortSignal，未开始的项跳过标记 cancelled）；⑤ 全部完成 resolve。写出实现。

```javascript
async function pool(items, worker, { concurrency = 4, onProgress, signal } = {}) {
  const results = new Array(items.length);
  const errors = new Array(items.length);
  let done = 0, failed = 0, next = 0;
  const total = items.length;

  const runner = async () => {
    while (next < total && !signal?.aborted) {
      const i = next++;
      try {
        results[i] = await worker(items[i], i);
      } catch (e) {
        errors[i] = e; failed++;
      }
      done++;
      onProgress?.({ done, total, failed, current: i, cancelled: !!errors[i]?.name?.startsWith?.('Cancelled') });
    }
  };
  await Promise.all(Array.from({ length: Math.min(concurrency, total) }, runner));
  return {
    results,
    errors: errors.map((e, i) => e && { index: i, error: e }).filter(Boolean),
    cancelled: signal?.aborted ? Array.from({ length: total }, (_, i) => i).filter(i => results[i] === undefined && !errors[i]) : [],
  };
}
// 用法: 1000 张图片上传, 并发 4, 实时进度条
const { results, errors } = await pool(files, uploadOne, {
  concurrency: 4,
  onProgress: ({ done, total }) => bar.style.width = `${done / total * 100}%`,
});
```

**评分点**：
- next 游标 + N 个 runner 的池模型（无队列锁开销）
- 结果按索引对齐、失败收集不中断
- 进度回调含 done/total/failed
- AbortSignal 取消语义（未开始项跳过）
