## WEB-502：笔试：手写验证码倒计时组件

**题目**：实现 `createCountdown(btn)`：点击后 60s 倒计时，期间禁用按钮；刷新页面倒计时不重置（localStorage 记结束时间）；用 rAF 或 interval 但离开页面要清理。

**答**：
```javascript
function createCountdown(btn, { duration = 60_000, key = 'sms_cd' } = {}) {
  let timer;

  function tick() {
    const end = +localStorage.getItem(key) || 0;
    const left = end - Date.now();
    if (left <= 0) {
      clearInterval(timer);
      btn.disabled = false;
      btn.textContent = '获取验证码';
      return;
    }
    btn.disabled = true;
    btn.textContent = `${Math.ceil(left / 1000)}s 后重试`;
  }

  function start() {
    localStorage.setItem(key, String(Date.now() + duration)); // 绝对时间，刷新不重置
    tick();
    timer = setInterval(tick, 500);
  }

  tick(); // 初始化时若仍在倒计时，恢复状态
  btn.addEventListener('click', start);
  return { destroy: () => clearInterval(timer) }; // 组件卸载必须清理
}
```

**评分点**：
- 记「结束时间戳」而非剩余秒数——刷新页面倒计时持续推进
- 初始化时先 tick 恢复进行中的倒计时
- interval 500ms 而非 1s（避免最后 1 秒显示不准），destroy 清理定时器
- 倒计时期间按钮 disabled 防重复发送
