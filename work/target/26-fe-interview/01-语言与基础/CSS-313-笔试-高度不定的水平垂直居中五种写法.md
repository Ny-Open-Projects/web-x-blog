## CSS-313：笔试：高度不定元素的水平垂直居中 5 种写法

**题目**：写出 5 种居中方案，要求元素高度不定（内容决定），并标注各自适用/局限。

**答**：
```css
/* 1. Flex（首选，语义清晰） */
.c1 { display: flex; align-items: center; justify-content: center; }

/* 2. Grid 一行 */
.c2 { display: grid; place-items: center; }

/* 3. 绝对定位 + transform（不需知道尺寸） */
.c3 { position: relative; }
.c3 > .box { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }

/* 4. 绝对定位 + inset auto 偏移（margin auto 拉伸法） */
.c4 > .box { position: absolute; inset: 0; margin: auto; width: fit-content; height: fit-content; }

/* 5. grid + 内容自身居中（元素即容器） */
.c5 { display: grid; place-content: center; }

/* 补充：fixed 全屏遮罩场景 */
.overlay { position: fixed; inset: 0; display: grid; place-items: center; }
```

**评分点**：
- 5 种齐全且每种「高度不定都成立」（translate 法与 flex 法天然支持）
- place-items 与 place-content 的区别能讲清（items 对齐子项，content 对齐轨道）
- margin: auto + inset 拉伸法需要 fit-content 尺寸的细节
- 各方案场景标注（遮罩/容器内/单元素）
