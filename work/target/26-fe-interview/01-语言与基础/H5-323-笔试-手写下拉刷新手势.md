## H5-323：笔试：手写下拉刷新手势

**题目**：实现下拉刷新：仅当页面滚动到顶部且手指下移时触发；拖拽距离有阻尼（越拉越难）；超过 80px 松手触发刷新（加载动画），不足则回弹；刷新期间禁止重复触发。

**答**：
```javascript
function pullToRefresh(content, onRefresh) {
  let startY = 0, pulling = false, distance = 0, refreshing = false;
  const THRESHOLD = 80;

  content.addEventListener('touchstart', (e) => {
    if (refreshing || window.scrollY > 0) return; // 顶部才允许
    startY = e.touches[0].clientY;
    pulling = true;
  }, { passive: true });

  content.addEventListener('touchmove', (e) => {
    if (!pulling) return;
    const dy = e.touches[0].clientY - startY;
    if (dy <= 0) { distance = 0; return; }
    distance = dy * (dy > 100 ? 100 / dy * 0.5 : 1); // 阻尼：超过 100 后增益骤减
    content.style.transform = `translateY(${Math.min(distance, 150)}px)`;
  }, { passive: true });

  content.addEventListener('touchend', async () => {
    if (!pulling) return;
    pulling = false;
    if (distance >= THRESHOLD && !refreshing) {
      refreshing = true;
      content.style.transform = 'translateY(60px)'; // 停在刷新位
      try { await onRefresh(); } finally {
        refreshing = false;
        content.style.transform = '';
      }
    } else {
      content.style.transform = ''; // 回弹
    }
    distance = 0;
  });
}
```

**评分点**：
- 触发条件：scrollY === 0 且向下拖——缺一个就误触发
- 阻尼函数（距离增益递减），手感的关键判分点
- 松手三态：达阈值进刷新态（停留+async 回调）、未达回弹
- refreshing 标志防重复；transform 回弹加 transition 更佳
