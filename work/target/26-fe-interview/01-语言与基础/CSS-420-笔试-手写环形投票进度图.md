## CSS-420：笔试：手写环形投票占比图

**答**：实现多选项占比环：① conic-gradient 按占比分段着色（JS 生成 stop 列表，累计边界）；② 动画从 0 展开到目标占比（@property --p 插值所有 stop 百分比）；③ 中心镂空（内圆遮罩或 radial 遮罩）；④ 图例与数值联动；⑤ 新数据到来平滑过渡（旧 stop → 新 stop 过渡）。写出核心实现。

```html
<div class="donut" id="donut"><span class="center">投票</span></div>
```

```css
@property --p { syntax: '<number>'; inherits: false; initial-value: 0; }
.donut {
  --p: 0;
  position: relative;
  width: 180px; height: 180px; border-radius: 50%;
  background: conic-gradient(var(--stops) calc(var(--p) * 1%), transparent 0);
  transition: --p .8s var(--ease-out-quart);
}
.donut::after {                 /* 中心镂空 */
  content: ''; position: absolute; inset: 28%;
  border-radius: 50%; background: #fff;
}
.donut .center {
  position: absolute; inset: 0;
  display: grid; place-items: center;
  z-index: 1;
}
```

```javascript
const COLORS = ['#1677ff', '#52c41a', '#fa8c16', '#999'];
function renderDonut(votes) {
  const total = votes.reduce((s, v) => s + v, 0);
  let acc = 0;
  const stops = votes.map((v, i) => {
    const from = acc / total * 100;
    acc += v;
    const to = acc / total * 100;
    return `${COLORS[i % COLORS.length]} ${from}% ${to}%`;
  }).join(', ');
  donut.style.setProperty('--stops', stops);
  requestAnimationFrame(() => donut.style.setProperty('--p', 100));  // 下一帧触发展开动画
}
// 数据更新: 直接换 --stops, transition --p 重新触发或使用 FLIP 类技巧;
// 更简单: 数值变化小场景直接切换(可接受), 大场景用双环交叉淡入
```

**评分点**：
- stop 列表按累计占比生成（边界不重叠不断档）
- @property --p + transition 实现「从 0 展开」动画
- 中心镂空用伪元素遮罩
- 动态数据更新策略（直接切换 vs 交叉过渡）能说清取舍
