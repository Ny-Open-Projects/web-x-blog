## JS-394：笔试：手写熔断器

**答**：实现 `CircuitBreaker(fn, { threshold, cooldown, halfOpenMax })`：① 三态：closed→连续失败≥threshold 转 open；open 期间直接抛 CircuitOpenError；冷却期过转 half-open；② half-open 放行探测请求（并发 ≤halfOpenMax），成功回 closed、失败回 open（重置冷却）；③ 成功（closed 态）重置计数；④ 事件回调 onStateChange；⑤ 失败分类：只统计可重试错误（传入判定函数）。写出实现。

```javascript
class CircuitOpenError extends Error { constructor() { super('circuit open'); this.name = 'CircuitOpenError'; } }

class CircuitBreaker {
  state = 'closed'; #fails = 0; #halfOpen = 0; #openedAt = 0;
  constructor(fn, { threshold = 5, cooldown = 30_000, halfOpenMax = 1, isRetryable = () => true, onStateChange } = {}) {
    Object.assign(this, { fn, threshold, cooldown, halfOpenMax, isRetryable, onStateChange });
  }
  async call(...args) {
    if (this.state === 'open') {
      if (Date.now() - this.#openedAt < this.cooldown) throw new CircuitOpenError();
      this.state = 'half-open';                          // 冷却结束进入探测
    }
    if (this.state === 'half-open') {
      if (this.#halfOpen >= this.halfOpenMax) throw new CircuitOpenError(); // 探测并发限制
      this.#halfOpen++;
      try {
        const r = await this.fn(...args);
        this.#close(); return r;
      } catch (e) {
        this.#open(); throw e;
      } finally { this.#halfOpen--; }
    }
    try {
      const r = await this.fn(...args);
      this.#fails = 0;                                   // 成功重置
      return r;
    } catch (e) {
      if (this.isRetryable(e) && ++this.#fails >= this.threshold) this.#open();
      throw e;
    }
  }
  #open() { this.state = 'open'; this.#openedAt = Date.now(); this.onStateChange?.('open'); }
  #close() { this.state = 'closed'; this.#fails = 0; this.onStateChange?.('closed'); }
}
```

**评分点**：
- 三态转换完整（open→half-open 靠冷却时间判定）
- half-open 探测并发限制（halfOpenMax）防探测风暴
- 成功重置失败计数、失败分类过滤（isRetryable）
- onStateChange 事件供监控告警
