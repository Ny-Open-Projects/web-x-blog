## JS-283：笔试：密码强度校验

**题目**：实现 `checkPwd(pwd)`：8-20 位；至少含大写、小写、数字中两类；特殊字符加分；不得含连续 3 位相同或正序/倒序连续字符（abc/321）；返回 { level: weak/mid/strong, reasons[] }。

**答**：
```javascript
function checkPwd(pwd) {
  const reasons = [];
  const p = String(pwd ?? '');
  if (p.length < 8 || p.length > 20) reasons.push('长度需 8-20 位');
  const kinds = [/[a-z]/, /[A-Z]/, /\d/].filter(r => r.test(p)).length;
  const special = /[^\w]/.test(p);
  if (kinds + (special ? 1 : 0) < 2) reasons.push('需至少两类字符');

  if (/(.)\1{2}/.test(p)) reasons.push('不能连续 3 位相同');
  if (/abc|bcd|cde|123|234|345|cba|321/i.test(p)) reasons.push('不能含连续序列');

  let level = 'weak';
  if (reasons.length === 0) {
    const score = kinds + (special ? 1 : 0) + (p.length >= 12 ? 1 : 0);
    level = score >= 4 ? 'strong' : 'mid';
  }
  return { level, reasons };
}
checkPwd('abcdefg1');  // weak: 需至少两类字符
checkPwd('Abc12345');  // mid: 不能含连续序列（Abc/123）
checkPwd('X7$kq9m2pZ'); // strong
```

**评分点**：
- 多个前瞻/字符类计数组合（可维护性优于巨型正则）
- 连续相同 `(.)\1{2}` 反向引用
- 连续序列检测（正/倒序）；length 边界
- 分级输出结构（level+reasons 支撑 UI 提示）
