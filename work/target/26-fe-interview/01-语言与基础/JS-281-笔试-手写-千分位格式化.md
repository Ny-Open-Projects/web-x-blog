## JS-281：笔试：手写千分位格式化

**题目**：实现 `thousands(n)`：支持整数与小数（小数部分不加逗号）、负数；给出正则与循环两种实现。

**答**：
```javascript
// 正则版：整数部分每隔 3 位插逗号
function thousands(n) {
  const [int, dec] = String(n).replace('-', '').split('.');
  const s = int.replace(/\B(?=(\d{3})+(?!\d))/g, ',');
  return (String(n).startsWith('-') ? '-' : '') + s + (dec ? '.' + dec : '');
}

// 循环版（面试防正则翻车的稳妥写法）
function thousandsLoop(n) {
  const neg = n < 0 ? '-' : '';
  const [int, dec] = Math.abs(n).toString().split('.');
  let out = '';
  for (let i = 0; i < int.length; i++) {
    const fromRight = int.length - i;
    out += int[i];
    if (fromRight > 1 && fromRight % 3 === 1) out += ','; // 从右数每 3 位后插
  }
  return neg + out + (dec ? '.' + dec : '');
}

thousands(1234567.89);   // '1,234,567.89'
thousands(-9876543);     // '-9,876,543'
```

**评分点**：
- 正则 `\B(?=(\d{3})+(?!\d))` 的三层拆解（非边界+前瞻分组+终结保护）
- 小数部分不处理、负号保留
- 循环版「从右数位置 %3」的判断逻辑
- 工程提示：实际项目用 Intl.NumberFormat（说明理由：本地化+四舍五入策略统一）
