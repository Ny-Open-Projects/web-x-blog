## JS-420：笔试：手写带进度的并行映射

**答**：实现 `asyncMap(items, mapper, { concurrency, onProgress })`：① 结果顺序与输入一致（无论完成先后）；② 并发上限控制（复用游标池模式）；③ onProgress 每完成一项触发 `{ done, total, percent }`，且提供「实时完成值流」onResult(index, value)（先到先得可用）；④ 全部完成后 resolve 结果数组；⑤ mapper 抛错则整体 reject（与池的收集模式区分）。写出实现。

```javascript
async function asyncMap(items, mapper, { concurrency = 4, onProgress, onResult } = {}) {
  const total = items.length;
  const results = new Array(total);
  let done = 0, next = 0;

  const runner = async () => {
    while (next < total) {
      const i = next++;
      const v = await mapper(items[i], i);     // 失败直接抛 → 整体 reject
      results[i] = v;
      onResult?.(i, v);                        // 实时流
      onProgress?.({ done: ++done, total, percent: done / total });
    }
  };
  await Promise.all(Array.from({ length: Math.min(concurrency, total) }, runner));
  return results;
}
// 用法
const urls = [...Array(100)].map((_, i) => `/img/${i}.jpg`);
const results = await asyncMap(urls, (u) => fetch(u).then(r => r.blob()), {
  concurrency: 4,
  onProgress: ({ percent }) => bar.style.width = `${percent * 100}%`,
  onResult: (i, blob) => renderImg(i, blob),   // 先完成先渲染
});
```

**评分点**：
- 游标并发池模式（next++ 分发，无队列开销）
- 结果按索引对齐（顺序一致性）
- onResult 实时流与 onProgress 进度双通道
- 与「失败收集」池的语义区分（这里整体 reject）
