## CSS-407：笔试：手写视差滚动

**答**：实现 hero 区视差：① 背景图慢速滚动（0.3x）、前景文字常速、装饰元素反向（-0.2x）；② 方案一：纯 CSS scroll-timeline（合成器驱动零 JS）；③ 方案二：rAF + 单次 getBoundingClientRect 批量读写；④ 用户滚动性能约束（两种方案都不触发逐帧 layout）；⑤ 不支持时的降级链。写出双方案实现。

```css
/* 方案一: 纯 CSS (优先) */
@supports (animation-timeline: scroll()) {
  .hero__bg {
    animation: bg-parallax linear both;
    animation-timeline: scroll(root);
  }
  @keyframes bg-parallax { to { transform: translateY(30vh); } }  /* 0.3x: 行程=滚动30% */
  .hero__deco {
    animation: deco-parallax linear both;
    animation-timeline: scroll(root);
  }
  @keyframes deco-parallax { to { transform: translateY(-20vh); } }
}
```

```javascript
// 方案二: rAF 批量读写 (通用降级)
const els = [{ el: bg, k: 0.3 }, { el: deco, k: -0.2 }];
let ticking = false;
addEventListener('scroll', () => {
  if (ticking) return;
  ticking = true;
  requestAnimationFrame(() => {
    const sy = scrollY;                        // 读: 一次
    for (const { el, k } of els)
      el.style.transform = `translate3d(0, ${sy * k}px, 0)`;  // 写
    ticking = false;
  });
}, { passive: true });
// 约束: 不用 getBoundingClientRect(避免强制布局), 用 scrollY 推导
```

**评分点**：
- 三层不同系数（0.3/1/-0.2）的视差速率设定
- scroll-timeline 方案零主线程、@supports 降级
- JS 方案 scrollY 推导 + rAF 合帧，明确避免逐帧 layout 读取
- translate3d 提层保证仅合成
