## JS-284：笔试：手写模板字符串解析器

**题目**：实现 `render(tpl, data)`：解析 `{{ name }}` 与 `{{ user.name }}`（点路径）；变量不存在输出空串（不报错）；转义 HTML 特殊字符（防 XSS）。

**答**：
```javascript
function getPath(obj, path) {
  return path.split('.').reduce((o, k) => (o == null ? undefined : o[k]), obj);
}
function escapeHtml(s) {
  return s.replace(/[&<>"']/g, c =>
    ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' }[c]));
}

function render(tpl, data) {
  return tpl.replace(/\{\{\s*([\w.]+)\s*\}\}/g, (_, key) => {
    const v = getPath(data, key);
    return v == null ? '' : escapeHtml(String(v));
  });
}

render('你好 {{ user.name }}，余额 {{ balance }} 元', {
  user: { name: '张三' }, balance: 99.5,
}); // '你好 张三，余额 99.5 元'

render('{{ miss }}!', {}); // '!'
render('{{ name }}', { name: '<b>x</b>' }); // '&lt;b&gt;x&lt;/b&gt;' —— 已转义
```

**评分点**：
- 正则支持点路径与两侧空白容错（\s*）
- getPath 的 reduce 逐级取值 + null 安全
- HTML 转义五字符（& 第一位替换）——安全判分点
- 缺失变量输出空串而非 undefined 字面量
