## CSS-413：笔试：手写面包屑与徽标

**答**：实现：① 面包屑层级长时中间项折叠为「…」（首尾保留，点击展开全部）；② 分隔符用伪元素（支持 RTL 逻辑属性）；③ 徽标（badge）挂在图标右上角，数字超 99 显示 99+；④ 徽标红点有脉冲动画；⑤ 徽标无障碍（aria-label 补充数值）。写出核心实现。

```html
<nav class="crumbs" aria-label="面包屑">
  <a href="/">首页</a><a href="/a">大类</a>
  <button class="more" hidden>…</button>
  <span class="hidden-items" hidden><a>层2</a><a>层3</a><a>层4</a></span>
  <a href="/a/b" aria-current="page">当前页</a>
</nav>

<span class="badge-wrap" aria-label="99+ 条未读">
  <svg><!-- bell --></svg><i class="badge" data-n="99+"></i>
</span>
```

```css
.crumbs { display: flex; align-items: center; gap: 8px; overflow: hidden; }
.crumbs a:not(:last-child)::after {           /* 分隔符伪元素 */
  content: '/';
  margin-inline-start: 8px; color: #bbb;
}
.crumbs [aria-current] { color: var(--fg); font-weight: 600; }
.crumbs .more { color: #999; background: none; border: none; }
/* 折叠逻辑: JS 检测溢出后显示 more, 隐藏中间项(结构约定) */

/* 徽标 */
.badge-wrap { position: relative; display: inline-flex; }
.badge {
  position: absolute; top: -4px; right: -8px;
  min-width: 16px; height: 16px; padding: 0 4px;
  border-radius: 8px;
  background: #f5222d; color: #fff;
  font-size: 10px; line-height: 16px; text-align: center;
  font-style: normal;
}
.badge::before { content: attr(data-n); }      /* 数值由 data 属性 */
.badge.pulse::after {                          /* 红点脉冲 */
  content: ''; position: absolute; inset: 0;
  border-radius: inherit; border: 1px solid #f5222d;
  animation: ping 1.5s infinite;
}
@keyframes ping { to { transform: scale(1.8); opacity: 0; } }
```

```javascript
// 溢出折叠: 检测 crumbs scrollWidth > clientWidth
const ro = new ResizeObserver(() => {
  const over = crumbs.scrollWidth > crumbs.clientWidth;
  more.hidden = !over;
  hiddenItems.hidden = !over;
});
ro.observe(crumbs);
more.addEventListener('click', () => { hiddenItems.hidden = false; more.hidden = true; });
```

**评分点**：
- 分隔符伪元素 + 逻辑属性（RTL 兼容）
- ResizeObserver 溢出检测折叠中间项
- 徽标 data 属性驱动数值 + aria-label 补充
- 脉冲用 ::after 缩放淡出（不重绘）
