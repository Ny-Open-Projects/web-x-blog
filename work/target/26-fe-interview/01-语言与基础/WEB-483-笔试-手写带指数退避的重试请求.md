## WEB-483：笔试：手写带指数退避的重试请求

**题目**：封装 `retryFetch(url, opts, { retries: 3, base: 500 })`：网络错误或 5xx 才重试，4xx 不重试；每次退避 `base * 2^n + 随机抖动`；支持超时。

**答**：
```javascript
function retryFetch(url, opt = {}, { retries = 3, base = 500, timeout = 10000 } = {}) {
  const attempt = async (n) => {
    const ctl = new AbortController();
    const timer = setTimeout(() => ctl.abort(), timeout);
    try {
      const res = await fetch(url, { ...opt, signal: ctl.signal });
      if (res.status >= 500 && n < retries) throw new Error('server'); // 5xx 可重试
      return res; // 4xx 直接返回，由业务层判断
    } catch (e) {
      if (n >= retries) throw e;
      const backoff = base * 2 ** n + Math.random() * base; // 指数退避 + 抖动
      await new Promise(r => setTimeout(r, backoff));
      return attempt(n + 1);
    } finally {
      clearTimeout(timer);
    }
  };
  return attempt(0);
}
```

**评分点**：
- 重试条件判断：5xx/网络错误重试，4xx（除 429）不重试——逻辑必须区分
- 指数退避必须带随机抖动，否则并发重试会同时打向服务端
- 每次尝试独立的超时控制（AbortController），不是整次共用
- 递归或循环实现均可，但要保证 finally 清理 timer
