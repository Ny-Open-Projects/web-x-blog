## JS-220：常见业务正则踩坑：千分位、手机号、密码

**答**：
- 千分位：`(?<=\d)(?=(\d{3})+$)` 插逗号——前瞻+后瞻组合的招牌用法；小数部分要排除
- 手机号：不要抄网上的全量段位表（新号段持续增加）；业务上宽松校验 `/^1\d{10}$/` + 服务端权威校验
- 密码：用「多个前瞻」比「字符类枚举组合」可维护；黑名单（qwerty）比正则更适合防弱密码
- 通用坑：g 标志复用 lastIndex、全局匹配循环漏零宽推进、正则对象跨请求复用

```javascript
// 千分位（整数部分）
function thousands(n) {
  return String(n).replace(/\B(?=(\d{3})+(?!\d))/g, ','); // \B 非词边界：开头不插
}
thousands(1234567); // "1,234,567"

// 手机号宽松校验
const phone = /^1[3-9]\d{9}$/;
// 金额分转元显示（前瞻插小数点）
'123456'.replace(/\B(?=(\d{2})$)/, '.'); // 不通用——金额格式化直接用 Intl.NumberFormat 更稳
```
