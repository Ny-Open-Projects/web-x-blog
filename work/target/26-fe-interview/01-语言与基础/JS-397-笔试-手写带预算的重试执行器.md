## JS-397：笔试：手写带总预算的重试执行器

**答**：实现 `retryWithBudget(fn, { budget, baseDelay, maxAttempts })`：① 总预算 budget（ms），每次重试的超时用「剩余预算」而不是固定值；② 退避 + 抖动，但延迟不超过剩余预算；③ 预算耗尽（含正在执行的任务）立即放弃——用 AbortSignal 让在途请求也中断；④ 返回 { value, attempts, elapsed } 或抛出最后一次错误；⑤ 不可重试错误立即放弃（不耗预算）。写出实现。

```javascript
async function retryWithBudget(fn, { budget = 3000, baseDelay = 100, maxAttempts = 10, isRetryable = (e) => !e.status || e.status >= 500 } = {}) {
  const start = performance.now();
  const ctrl = new AbortController();
  let lastErr;
  for (let i = 0; i < maxAttempts; i++) {
    const remain = budget - (performance.now() - start);
    if (remain <= 0) break;                                   // 预算耗尽
    try {
      const value = await Promise.race([
        fn(ctrl.signal),
        new Promise((_, rej) => setTimeout(() => { ctrl.abort(); rej(new Error('attempt timeout')); }, remain)),
      ]);
      return { value, attempts: i + 1, elapsed: performance.now() - start };
    } catch (e) {
      lastErr = e;
      if (!isRetryable(e)) throw e;
      const delay = Math.min(baseDelay * 2 ** i + Math.random() * baseDelay, remain);
      await new Promise(r => setTimeout(r, delay));
    }
  }
  const err = new Error(`budget exhausted after ${maxAttempts} attempts`, { cause: lastErr });
  err.lastError = lastErr;
  throw err;
}
// 特点: 每次尝试的超时 = 剩余预算, 且 abort 在途请求不悬挂
```

**评分点**：
- 剩余预算感知的单次超时（不是固定超时重试）
- AbortSignal 让在途任务随预算耗尽中断
- 退避延迟封顶为剩余预算
- 不可重试错误立即放弃；结果带 attempts/elapsed 元数据
