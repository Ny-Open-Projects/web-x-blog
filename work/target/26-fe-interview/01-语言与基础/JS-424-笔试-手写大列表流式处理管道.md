## JS-424：笔试：手写大数组流式处理管道

**答**：实现 `streamProcess(source, ...transforms, sink)`：① source 可为数组（模拟大数据）或 async iterable；② transforms 是逐项/逐块转换函数链（惰性：未消费不计算）；③ sink 聚合（如累计求和/写入），全程只驻留一个 chunk 的内存；④ 支持 signal 取消；⑤ 返回 sink 的聚合结果 + processed 计数。写出实现（生成器管道）。

```javascript
async function streamProcess(source, { chunkSize = 1000, transforms = [], sink, signal } = {}) {
  async function* gen(arr) {
    for (let i = 0; i < arr.length; i += chunkSize) {
      signal?.throwIfAborted();
      yield arr.slice(i, i + chunkSize);       // 惰性: 消费到才切下一块
    }
  }
  async function* apply(src) {
    for await (const chunk of src) {
      signal?.throwIfAborted();
      let c = chunk;
      for (const t of transforms) c = t(c);    // 逐块转换
      yield c;
    }
  }
  let processed = 0;
  for await (const chunk of apply(gen(source))) {
    sink(chunk);                                // 逐块进 sink, 不整驻内存
    processed += chunk.length ?? 1;
  }
  return { processed, result: sink.result };
}
```

**评分点**：
- async generator 惰性分块（未消费不计算）
- transforms 逐块链式（非逐项，减少调度开销）
- signal 检查点在块边界
- 全程只驻留一个 chunk（恒定内存语义）
