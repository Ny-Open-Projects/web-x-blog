## JS-232：内存泄漏的线上监控方案

**答**：
- 采样指标：performance.memory（Chromium：usedJSHeapSize/jsHeapSizeLimit）定时采样——注意 Safari/Firefox 无此 API
- 判定算法：同一会话内按时间窗回归斜率判断「持续增长」；结合页面驻留时长排除正常增长
- 辅助信号：Long Task 频率上升、GC 频率（可通过帧率间接感知）、崩溃率
- 归因增强：泄漏告警时附带路由轨迹与用户操作序列——复现路径比数值更值钱
- 兜底策略：heap 超阈值自动 reload（带提示），把「卡死」降级为「刷新」

```javascript
setInterval(() => {
  const m = performance.memory;
  if (!m) return;
  report({ used: m.usedJSHeapSize, limit: m.jsHeapSizeLimit, route: location.pathname, t: Date.now() });
}, 30000);
// 服务端按会话聚合画曲线，斜率异常 → 告警 + 附带操作轨迹
```
