## WEB-499：笔试：手写首屏接口竞态保护

**题目**：搜索页快速切换关键词时，慢请求的旧结果会覆盖新结果。实现 `raceGuard(fetcher)`：只接受最新一次调用的结果；旧请求完成后静默丢弃；支持取消底层请求（AbortController）。

**答**：
```javascript
function raceGuard(fetcher) {
  let seq = 0;

  return (...args) => {
    const my = ++seq;
    const ctl = new AbortController();
    return fetcher(...args, ctl.signal).then(result => {
      if (my !== seq) {
        ctl.abort(); // 已过期：取消底层请求，结果丢弃
        return null;
      }
      return result;
    });
  };
}

// 用法：搜索防竞态
const search = raceGuard(async (kw, signal) => {
  const res = await fetch(`/api/search?q=${kw}`, { signal });
  return res.json();
});
input.oninput = e => search(e.target.value).then(r => r && render(r));
```

**评分点**：
- 序号（seq）比较识别过期请求，核心判分点
- 过期请求要 abort 底层连接，不只是丢结果
- 返回 null 而不是抛错（静默丢弃），避免调用方误判为异常
- 能结合真实场景（搜索联想、tab 快速切换）说明触发条件
