## WEB-436：微前端下多个子应用的登录态怎么共享

**答**：
- 同域部署（最常见）：主/子应用共享 Cookie，登录态天然共享；差异只在各自的本地状态缓存
- 跨域子应用（iframe/独立域名）：走主应用统一鉴权，子应用通过 postMessage 或网关级 token 注入获得凭证
- token 管理归口：建议收敛到主应用（或共享 SDK），子应用只读不写，避免多个应用各自刷新 token 引发竞态
- 登出联动：主应用登出要通知全部子应用清缓存（CustomEvent / BroadcastChannel）
- 状态管理新解法：部分团队把登录态放进 shared store（如 qiankun 的 initGlobalState），但要保证刷新后仍能从接口恢复

```javascript
// 主应用广播登出
const bc = new BroadcastChannel('app-auth');
bc.postMessage({ type: 'LOGOUT' });
// 子应用监听
const bc2 = new BroadcastChannel('app-auth');
bc2.onmessage = (e) => { if (e.data.type === 'LOGOUT') resetLocalAuth(); };
```
