## CSS-411：笔试：手写空状态/错误页

**答**：实现空状态组件：① SVG 插画（几何图形组合）+ 呼吸浮动动画；② 主文案/副文案层级；③ 主行动按钮 + 次级链接；④ 网络错误变体（重试按钮 + 自动重试倒计时进度环）；⑤ 多场景复用（empty/error/403/404 按 type 变体）。写出核心实现。

```html
<div class="empty" data-type="error">
  <svg class="art" viewBox="0 0 120 120" aria-hidden="true">
    <circle cx="60" cy="60" r="40" class="c1"/>
    <path d="M45 65 l12 12 20-24" class="ok"/>
    <line x1="50" y1="55" x2="70" y2="55" class="eye"/>
    <line x1="70" y1="55" x2="50" y2="55" class="cross"/>
  </svg>
  <p class="t1">加载失败</p>
  <p class="t2">网络不稳定，请重试</p>
  <button class="retry">重试 <span class="cd">5</span>s</button>
</div>
```

```css
.empty { text-align: center; padding: 48px 0; }
.art { width: 120px; animation: float 3s ease-in-out infinite; }
@keyframes float { 50% { transform: translateY(-8px); } }

.art .c1 { fill: color-mix(in oklab, var(--primary) 10%, white); }
.empty .eye { display: block; stroke: #666; }
.empty[data-type='error'] .cross { stroke: #f5222d; display: block; }
.empty:not([data-type='error']) .cross { display: none; }

.t1 { font-size: 16px; font-weight: 600; margin: 16px 0 4px; }
.t2 { font-size: 13px; color: #999; }
.retry {
  margin-top: 16px; padding: 8px 24px;
  border-radius: 20px; background: var(--primary); color: #fff;
  position: relative; overflow: hidden;
}
/* 自动重试倒计时进度环: 底部进度条替代(简化) */
.retry::after {
  content: ''; position: absolute; left: 0; bottom: 0; height: 2px;
  width: calc(var(--cd-p, 100) * 1%);
  background: rgb(255 255 255 / .6);
  transition: width 1s linear;
}
```

```javascript
function autoRetry(sec = 5) {
  let s = sec;
  const t = setInterval(() => {
    s--;
    cdEl.textContent = s;
    retryBtn.style.setProperty('--cd-p', s / sec * 100);
    if (s <= 0) { clearInterval(t); reload(); }
  }, 1000);
}
```

**评分点**：
- data-type 驱动变体（eye/cross 显隐）
- 呼吸动画用 transform（合成器）
- 自动重试倒计时可视化（进度条 --cd-p）
- 插画用色走 token mix（主题兼容）
