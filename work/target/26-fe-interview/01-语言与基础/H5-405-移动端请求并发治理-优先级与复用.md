## H5-405：移动端请求并发治理：优先级、复用与失败隔离

**答**：
- 移动端并发窗口有限（弱网连接数少且慢），请求要分级：critical（首屏数据）/ high（用户操作响应）/ normal（详情预取）/ low（埋点/日志）——低级不得挤占高级
- 调度器实现：优先级队列 + 并发上限（弱网降到 3~4），同域请求复用连接（h2/h3 下天然复用）；关键请求用 fetchpriority/直接调用绕过队列
- 失败隔离：单个接口超时不阻塞页面——超时分级（critical 10s 重试、normal 5s 失败展示降级、low 静默丢弃）；重试带 jitter 防雪崩
- 去重与合并：同 URL 并发请求合并（in-flight 复用）；参数相同 payload 合批（feed 多个 item 详情）
- 监控：按优先级统计耗时分布与失败率，验证调度真的保护了关键链路

```javascript
class RequestScheduler {
  constructor({ max = 6, poorMax = 4, degrade } = {}) {
    this.queues = { critical: [], high: [], normal: [], low: [] };
    this.max = () => degrade?.level === 'poor' ? poorMax : max;
    this.flying = 0;
  }
  send(url, opts = {}, priority = 'normal') {
    return new Promise((resolve, reject) => {
      if (priority === 'critical' || this.flying < this.max()) return this._exec(url, opts, resolve, reject);
      this.queues[priority].push({ url, opts, resolve, reject });
    });
  }
  async _exec(url, opts, resolve, reject) {
    this.flying++;
    try {
      const ctrl = new AbortController();
      const t = setTimeout(() => ctrl.abort(), opts.timeout || 8000);
      resolve(await fetch(url, { ...opts, signal: ctrl.signal }));
      clearTimeout(t);
    } catch (e) { reject(e); }
    finally {
      this.flying--;
      for (const p of ['critical', 'high', 'normal', 'low']) {  // 高优先级先出队
        const next = this.queues[p].shift();
        if (next) return this._exec(next.url, next.opts, next.resolve, next.reject);
      }
    }
  }
}
```
