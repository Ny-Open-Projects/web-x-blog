## CSS-409：笔试：手写无限循环跑马灯

**答**：实现无缝跑马灯：① 内容复制一份首尾拼接，translateX 从 0 到 -50% 循环（无缝关键）；② 速度按内容宽度自适应（duration = 宽度/速度）；③ hover 暂停；④ 内容动态变更后重新计算时长；⑤ 两份内容宽度必须一致（flex 不换行固定宽）。写出核心实现。

```html
<div class="marquee">
  <div class="track">
    <ul class="set"><li>公告一</li><li>公告二</li><li>公告三</li></ul>
    <ul class="set" aria-hidden="true"><li>公告一</li><li>公告二</li><li>公告三</li></ul>
  </div>
</div>
```

```css
.marquee {
  overflow: hidden;
  white-space: nowrap;
}
.track {
  display: inline-flex;
  animation: marquee var(--dur, 20s) linear infinite;
}
.track:hover { animation-play-state: paused; }
.set {
  display: inline-flex;
  flex: 0 0 auto;              /* 不换行不收缩 */
  gap: 48px;
  padding-right: 48px;         /* 尾部间距保证无缝 */
}
@keyframes marquee { to { transform: translateX(-50%); } }  /* 50% = 一份内容宽 */
```

```javascript
function fitDuration(track, pxPerSec = 60) {
  const w = track.scrollWidth / 2;             // 一份内容宽度
  track.style.setProperty('--dur', `${w / pxPerSec}s`);
}
fitDuration(track);
new ResizeObserver(() => fitDuration(track)).observe(track.parentElement);
// 内容更新后: 重渲染 set → fitDuration 重算
```

**评分点**：
- 内容复制 + translateX(-50%) 的无缝原理（50% 恰好一份宽）
- linear 无停顿、flex 不换行保证两份等宽
- 时长 = 宽度/速度，ResizeObserver 动态适配
- hover 暂停 + aria-hidden 复制份无障碍处理
