## WEB-608：笔试：手写预渲染适配器

**答**：实现 `PrerenderAdapter`：① 提供 `defer(fn)`：预渲染期间注册的函数延迟到 prerenderingchange（激活）后执行，非预渲染环境立即执行；② `shouldReport()`：判断当前导航是否来自预渲染（`activationStart > 0`），用于区分统计；③ 动态注入 speculation rules：`injectRules(urls, eagerness)` 生成 `<script type="speculationrules">` 插入 head，重复注入替换旧的；④ 对不支持 Speculation Rules 的浏览器静默跳过。写出核心实现。

```javascript
class PrerenderAdapter {
  static deferred = [];
  static defer(fn) {
    if (document.prerendering) {
      document.addEventListener('prerenderingchange', () => fn(), { once: true });
      this.deferred.push(fn);
    } else fn();
  }
  static shouldReport(nav) {
    nav = nav || performance.getEntriesByType('navigation')[0];
    return nav?.activationStart > 0;
  }
  static injectRules(urls, eagerness = 'moderate') {
    if (!HTMLScriptElement.supports?.('speculationrules')) return false; // 不支持则跳过
    const old = document.querySelectorAll('script[data-speculation]');
    old.forEach(s => s.remove());
    const s = document.createElement('script');
    s.type = 'speculationrules';
    s.dataset.speculation = '1';
    s.textContent = JSON.stringify({
      prerender: [{ source: 'list', urls, eagerness }],
      prefetch: [{ source: 'list', urls, eagerness }],
    });
    document.head.appendChild(s);
    return true;
  }
}
// 用法: 打点/动画等副作用全部 defer, 预渲染期间零副作用
PrerenderAdapter.defer(() => beacon('page-active'));
```

**评分点**：
- prerendering/prerenderingchange 语义正确，副作用延迟到激活
- activationStart 判断预渲染来源，监控口径分离
- 动态注入用 `HTMLScriptElement.supports` 特性检测 + 旧规则替换
- 理解预渲染期间不能有不可逆副作用（打点/视频自动播放）
