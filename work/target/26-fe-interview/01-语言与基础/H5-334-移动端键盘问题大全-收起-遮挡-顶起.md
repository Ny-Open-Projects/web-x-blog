## H5-334：移动端软键盘问题大全：遮挡、顶起、收起监听

**答**：
- 键盘没有标准事件：iOS/Android 都要间接感知——focus/blur 事件 + window resize/visualViewport 变化组合判断，visualViewport API 是最可靠的新方案
- 遮挡问题：输入框被键盘盖住，用 visualViewport.height 计算 keyboard 高度并 scrollIntoView；iOS 上 focus 后延时 300ms 再滚才生效
- iOS 页面被顶起的残留滚动：键盘收起后 scrollTop 不回落，收起时手动 window.scrollTo 修正；fixed 定位元素在键盘期会漂移，改用 absolute/内容区 padding 方案
- Android 差异：resize 模式下视口变小（布局重排），调整模式 window 不变只整页上推——同一方案要双端行为分支
- 交互细节：收起键盘失焦时若表单未提交要保存草稿；聊天页面「键盘弹出后滚动到底部」要在 resize 后 rAF 里做

```javascript
const vv = window.visualViewport;
if (vv) {
  vv.addEventListener('resize', () => {
    const kb = window.innerHeight - vv.height;      // 估算键盘高度
    if (kb > 100) {                                  // 键盘弹出
      const el = document.activeElement;
      el?.scrollIntoView?.({ block: 'center' });
    } else { window.scrollTo(0, 0); }                // 收起修正
  });
}
// iOS 兜底: focus 后延时滚动
input.addEventListener('focus', () => setTimeout(() => input.scrollIntoView({ block: 'center' }), 300));
```
