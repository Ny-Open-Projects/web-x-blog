## H5-400：低端机降级体系：设备分档策略

**答**：
- 分档信号：JS 堆上限近似（performance.memory jsHeapSizeLimit）、hardwareConcurrency、deviceMemory、UA 机型库、首屏探针实测（加载耗时/INP 首测）——信号组合出 S/A/B 档
- 降级项分级：关闭视差/粒子动画、图片降分辨率、动画改 CSS 简化版、关闭 backdrop-filter/blur、轮播简化——按「视觉损失小 × 性能收益大」优先级排序
- 档位注入时机：首字节到执行前完成分档（内联脚本或 HTML 预注入 class），否则降级生效太晚
- 动态升降档：运行时帧率监控（连续低帧自动再降一档），会话内不回升（避免体验抖动）
- 效果度量：分档用户的核心指标（秒开/INP/崩溃率）对比，验证降级真的救了低端机而不是「全家一起降」

```javascript
// 分档探针
function tier() {
  const mem = navigator.deviceMemory || 0;
  const cores = navigator.hardwareConcurrency || 2;
  if (mem >= 6 && cores >= 8) return 'S';
  if (mem >= 4 && cores >= 4) return 'A';
  return 'B';
}
document.documentElement.dataset.tier = tier();
// CSS 按档降级
// [data-tier="B"] .parallax { display: none; }
// [data-tier="B"] img { filter: none; }
```
