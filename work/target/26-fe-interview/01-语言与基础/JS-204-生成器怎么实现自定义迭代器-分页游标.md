## JS-204：生成器实现自定义迭代器：分页游标

**答**：
- 把「翻页拉取」封装成生成器：for-of 直接消费，调用方无需关心分页逻辑
- 生成器返回对象时天然实现 [Symbol.iterator]——`for await` 或同步 for-of 皆可
- 边界处理：hasMore 判断、游标传递、终止条件
- 价值：把「过程式翻页循环」抽象成「惰性数据流」，代码量减半且支持解构/展开/管道复用

```javascript
async function* pageItems(fetchPage) {
  let cursor = null;
  do {
    const { items, next } = await fetchPage(cursor); // 拉一页
    for (const item of items) yield item;            // 逐条产出
    cursor = next;
  } while (cursor);
}
// 消费：像数组一样 for-of，翻页细节全隐藏
for await (const item of pageItems(c => fetch(`/api/list?cursor=${c ?? ''}`).then(r => r.json()))) {
  if (item.id > 100) break; // 惰性：够用即停，不拉完所有页
}
```
