## WEB-522：前端如何配合做设备指纹

**答**：
- 指纹信号源：UA/canvas 绘制差异/WebGL 渲染器字符串/屏幕与时区/字体列表/电池与传感器 API——多信号融合而非单点
- 前端职责：按风控 SDK 规范采集信号、加密上报；服务端聚合算出设备 ID 与置信度
- 合规边界：需要告知与用户授权（隐私政策），欧盟 GDPR 与国内个保法都管；无感指纹是灰色地带
- 稳定性难题：浏览器隐私保护（Canvas 噪声、UA 冻结、指纹混淆）让纯前端指纹漂移率高，需与服务端会话信号配合
- 面试话术：不要炫技列 API，讲「信号 → 融合 → 置信度 → 降级策略」的架构感更值钱

```javascript
async function collectSignals() {
  const gl = document.createElement('canvas').getContext('webgl');
  return {
    ua: navigator.userAgent,
    screen: `${screen.width}x${screen.height}@${devicePixelRatio}`,
    tz: Intl.DateTimeFormat().resolvedOptions().timeZone,
    gpu: gl?.getParameter(gl.getExtension('WEBGL_debug_renderer_info')?.UNMASKED_RENDERER_WEBGL),
  };
}
```
