## JS-380：预加载与预热调度：空闲期产能利用

**答**：
- 空闲产能的定义：主线程空闲（idle）、网络空闲（并发未满）、内存预算内——预加载调度器在三者同时空闲时干活，任一紧张立即让路
- 优先级清单：确定性预取（用户必然到的地方）> 概率预取 > 预热（Worker/wasm 实例化/连接预热）> 预渲染——按「命中率 × 收益」排序，预算逐项扣
- 调度实现：requestIdleCallback 分片执行预取任务清单（每 idle 片执行一个，不超预算）；网络维度接入请求调度器（低优先级队列，高优先级到来自动让路）
- 取消与失效：预取的数据带 TTL（过期丢弃）；用户实际导航路径偏离时取消未完成任务——预取管理器要有「任务生命周期」
- 效果度量：预取命中率（预取后实际访问比例）、预取后加载提速值——命中率 <30% 的预取是纯浪费，砍掉

```javascript
class PrefetchScheduler {
  #queue = []; #running = false;
  add(task, priority = 0) { this.#queue.push({ task, priority }); this.#queue.sort((a, b) => b.priority - a.priority); this.#pump(); }
  async #pump() {
    if (this.#running || !this.#queue.length) return;
    this.#running = true;
    while (this.#queue.length) {
      await new Promise(r => (requestIdleCallback || setTimeout)(r, { timeout: 2000 }));  // 等空闲
      const { task } = this.#queue.shift();
      if (task.expired()) continue;
      await task.run();                       // 一次 idle 只做一件事
    }
    this.#running = false;
  }
}
```
