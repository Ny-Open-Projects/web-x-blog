## WEB-615：笔试：手写协议占比与进程资源统计采样器

**答**：实现 `ProtoStats`：① 每 30s 采样一次 resource timing 中各协议（h2/h3/http/1.1）请求数与总传输字节，累计到窗口；② 输出当前窗口协议占比 `{ proto: { reqRatio, byteRatio } }`；③ 附带 JS 堆采样（performance.memory 存在时）一起上报，用于关联「协议性能与内存压力」；④ 窗口滚动：保留最近 5 个采样点做趋势；⑤ sendBeacon 失败静默。写出核心实现。

```javascript
class ProtoStats {
  constructor(intervalMs = 30_000) {
    this.win = []; // 最近5个采样点
    this.timer = setInterval(() => this._sample(), intervalMs);
    addEventListener('pagehide', () => this._report(true));
  }
  _sample() {
    const agg = {};
    for (const e of performance.getEntriesByType('resource')) {
      const p = e.nextHopProtocol || 'other';
      (agg[p] ||= { req: 0, bytes: 0 });
      agg[p].req++;
      agg[p].bytes += e.transferSize || 0;
    }
    const totalReq = Object.values(agg).reduce((s, x) => s + x.req, 0);
    const totalBytes = Object.values(agg).reduce((s, x) => s + x.bytes, 0);
    const ratios = Object.fromEntries(Object.entries(agg).map(([p, v]) => [p, {
      reqRatio: totalReq ? +(v.req / totalReq).toFixed(3) : 0,
      byteRatio: totalBytes ? +(v.bytes / totalBytes).toFixed(3) : 0,
    }]));
    const mem = performance.memory ? performance.memory.usedJSHeapSize : null;
    this.win.push({ ts: Date.now(), ratios, mem });
    if (this.win.length > 5) this.win.shift();
    return ratios;
  }
  _report(urgent) {
    const payload = { window: this.win };
    urgent ? navigator.sendBeacon('/api/mon/proto', JSON.stringify(payload))
           : fetch('/api/mon/proto', { method: 'POST', body: JSON.stringify(payload) }).catch(() => {});
  }
}
```

**评分点**：
- 请求占比与字节占比双口径（两者可能背离：h3 跑大文件时请求占比低字节占比高）
- 窗口滚动保留趋势（5 点），内存采样与协议关联
- pagehide 强制上报用 sendBeacon
- performance.memory 不存在的环境 mem=null 不中断
