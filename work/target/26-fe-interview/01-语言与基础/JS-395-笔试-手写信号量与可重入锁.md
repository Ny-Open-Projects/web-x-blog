## JS-395：笔试：手写信号量与可重入锁

**答**：实现：① `Semaphore(n)`：acquire（≤n 个并发持有，其余排队 FIFO）/release（唤醒队首）；② `withPermit(fn)` 包装；③ 可重入 Mutex：同 key 重复 acquire 计数 +1（嵌套调用不阻塞自己），release 计数归零才真正释放；④ 超时 acquire（等待超时 reject 并从队列移除）。写出实现。

```javascript
class Semaphore {
  #waiters = [];
  constructor(permits = 1) { this.permits = permits; this.available = permits; }
  acquire(timeout = Infinity) {
    if (this.available > 0) { this.available--; return Promise.resolve(); }
    return new Promise((resolve, reject) => {
      const w = { resolve, timer: null };
      if (timeout !== Infinity)
        w.timer = setTimeout(() => {                    // 超时: 出队
          this.#waiters = this.#waiters.filter(x => x !== w);
          reject(new Error('acquire timeout'));
        }, timeout);
      this.#waiters.push(w);
    });
  }
  release() {
    const w = this.#waiters.shift();
    if (w) { clearTimeout(w.timer); w.resolve(); }      // 直转下一个(不归还额度)
    else this.available = Math.min(this.permits, this.available + 1);
  }
  async withPermit(fn) { await this.acquire(); try { return await fn(); } finally { this.release(); } }
}

// 可重入 Mutex
class ReentrantMutex {
  #count = 0; #owner = null; #queue = [];
  async acquire(key) {
    if (this.#owner === key) { this.#count++; return; }  // 重入
    while (this.#owner) await new Promise(r => this.#queue.push(r));
    this.#owner = key; this.#count = 1;
  }
  release(key) {
    if (this.#owner !== key) throw new Error('not owner');
    if (--this.#count > 0) return;                       // 嵌套未退完
    this.#owner = null;
    const next = this.#queue.shift();
    if (next) next();                                    // 唤醒等待者(其内会竞争)
    else { /* 保持无主 */ }
    if (next) { /* 等待者拿到后自行设 owner */ }
  }
}
```

**评分点**：
- 信号量 release 直转等待者（额度不经过 available，防竞态）
- 超时 acquire 的出队清理
- 可重入计数语义（同 key 计数、归零才释放）
- withPermit 的 finally 保证释放
