## H5-254：PWA 离线页怎么做：兜底导航

**答**：
- 核心：install 时预缓存离线页 offline.html；fetch 拦截导航请求，网络失败时返回离线页
- 分策略处理：导航请求（document）失败→离线页；静态资源失败→缓存兜底；API 失败→本地暂存或错误提示
- 离线页内容：明确告知「您当前离线」+ 重试按钮 + 离线可用的功能入口（本地数据）
- 重试机制：监听 online 事件自动 reload 或提示刷新；离线期间队列化用户操作（Background Sync）
- 细节：离线页本身要在 install 阶段缓存成功，否则兜底失效；`cache.match` 匹配不到时必须手动 new Response

```javascript
self.addEventListener('fetch', (e) => {
  if (e.request.mode === 'navigate') {
    e.respondWith(
      fetch(e.request).catch(() => caches.match('/offline.html'))
    );
  } else {
    e.respondWith(caches.match(e.request).then(c => c || fetch(e.request)));
  }
});
```
