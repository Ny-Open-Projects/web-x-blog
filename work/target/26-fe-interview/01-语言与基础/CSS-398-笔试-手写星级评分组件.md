## CSS-398：笔试：手写星级评分组件

**答**：实现评分：① 5 星，支持半星（0.5 步进）；② 纯 CSS hover 预览 + 点击提交；③ 已选星保持（填充星 + 空星叠层技巧）；④ 键盘与读屏可用（radio 语义或 slider role）；⑤ 双层实现：底层灰星序列 + 上层裁剪的亮星（width 百分比裁剪）。写出核心实现。

```html
<div class="stars" role="radiogroup" aria-label="评分">
  <input type="radio" name="rate" id="s5" value="5"><label for="s5" style="--i:5"></label>
  <input type="radio" name="rate" id="s45" value="4.5"><label for="s45" style="--i:4.5"></label>
  <!-- ... s4 ... s0.5 -->
</div>
```

```css
.stars { position: relative; display: inline-flex; flex-direction: row-reverse; }
.stars input { position: absolute; opacity: 0; }   /* 视觉隐藏但可聚焦 */
.stars label {
  width: 28px; height: 28px; cursor: pointer;
  background: url(star.svg) center/contain no-repeat;
  filter: grayscale(1); opacity: .35;
  transition: transform .15s;
}
/* hover 预览: row-reverse 使选中项之后的兄弟(左侧)高亮 */
.stars label:hover,
.stars label:hover ~ label { filter: none; opacity: 1; }
/* 已选: radio:checked + 后续兄弟 */
.stars input:checked + label,
.stars input:checked + label ~ label { filter: none; opacity: 1; }
.stars label:hover { transform: scale(1.15); }
/* 半星: 奇数序号宽度裁剪(0.5步进标签宽一半) */
.stars label[value-half] { position: absolute; width: 14px; overflow: hidden; }
```

```javascript
// 读屏提示
stars.addEventListener('change', (e) => {
  stars.setAttribute('aria-valuenow', e.target.value);
  live.textContent = `已评分 ${e.target.value} 星`;
});
```

**评分点**：
- flex-direction: row-reverse 实现「选中+左侧高亮」纯 CSS 技巧
- radio 语义键盘可达（方向键在 radiogroup 内切换）
- hover 预览与 checked 持久的双通道选择器
- 半星裁剪方案（width 14px overflow hidden）
