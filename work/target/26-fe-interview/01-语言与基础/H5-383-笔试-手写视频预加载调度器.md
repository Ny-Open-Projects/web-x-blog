## H5-383：笔试：手写视频预加载调度器

**答**：实现 `VideoPreloader`（短视频 Feed）：① 维护当前播放索引 idx，只允许相邻视频预加载：当前 ±1 预加载（首帧/metadata），其余全部 idle；② 预加载档位可配：'none'（只加载当前）、'near'（±1）、'far'（±2）；③ 滑动切换（上报 newIndex）后立即调整预加载集合并释放非相邻资源（removeAttribute src + load() 释放解码器）；④ 弱网档（DegradeManager poor）强制 'none'；⑤ 资源释放计数防解码器泄漏。写出核心实现。

```javascript
class VideoPreloader {
  constructor({ level = 'near', degrade } = {}) {
    this.level = level; this.degrade = degrade;
    this.loaded = new Set();
    this.releaseCount = 0;
  }
  onSlide(newIdx, videos) {                          // videos: 有序 video 元素数组
    const level = this.degrade?.level === 'poor' ? 'none' : this.level;
    const want = new Set();
    if (level !== 'none') {
      want.add(newIdx);
      if (level !== 'none') want.add(newIdx - 1).add(newIdx + 1);
      if (level === 'far') want.add(newIdx - 2).add(newIdx + 2);
    } else want.add(newIdx);

    for (const [i, v] of videos.entries()) {
      if (want.has(i)) {
        if (!this.loaded.has(i)) {
          v.preload = 'metadata';
          v.src ||= v.dataset.src;
          this.loaded.add(i);
        }
      } else if (this.loaded.has(i)) {               // 释放非相邻
        v.removeAttribute('src'); v.load();
        this.loaded.delete(i);
        this.releaseCount++;
      }
    }
  }
  get stats() { return { loaded: [...this.loaded], released: this.releaseCount }; }
}
```

**评分点**：
- 相邻预加载集合计算正确（当前 ±1/±2 按档位）
- 非相邻视频释放（removeAttribute src + load()），防解码器与内存泄漏
- 弱网联动强制 none
- loaded 集合与释放计数支撑资源治理监控
