## JS-276：输出题：原型链修改后的查找结果

**题目**：动态修改原型/实例属性后的查找结果；说明 shadowing 与 Object.create 的行为。

**答**：
```javascript
function P() {}
P.prototype.say = () => 'proto';
const p1 = new P();
p1.say = () => 'own';        // 实例自身属性（shadowing）
p1.say();                    // 'own'——自身优先

const p2 = new P();
p2.say();                    // 'proto'

P.prototype.say = () => 'proto2';
p2.say();                    // 'proto2'——原型动态生效（实时查找）
delete p1.say;
p1.say();                    // 'proto2'——删自身后回退到原型

// Object.create：直接指定原型，无构造过程
const q = Object.create({ greet: () => 'hi' });
q.greet();                   // 'hi'
q.hasOwnProperty === undefined; // false —— q 沿链找到 Object.prototype 的方法
// Object.create(null) 则连 hasOwnProperty 都没有

// __proto__ 改链（不推荐，用 Object.setPrototypeOf）
const r = {};
Object.setPrototypeOf(r, { get() { return 'from-proto'; } });
r.get();                     // 'from-proto'
```

**评分点**：
- 查找顺序「自身 → 原型 → 更上层」，写操作 shadowing
- 原型修改的动态生效（p2.say 变 proto2）
- delete 自身属性后回退原型
- Object.create(null) 无原型方法的边界
