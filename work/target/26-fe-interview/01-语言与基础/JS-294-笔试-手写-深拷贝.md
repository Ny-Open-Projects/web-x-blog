## JS-294：笔试：手写深拷贝

**题目**：实现 `deepClone(obj)`：处理循环引用（WeakMap 记忆化）、Date/RegExp/Map/Set、数组与普通对象；保留原型（constructor 分支重建）；函数引用复制不递归。

**答**：
```javascript
function deepClone(obj, seen = new WeakMap()) {
  if (obj === null || typeof obj !== 'object') return obj; // 原始值/函数直返
  if (seen.has(obj)) return seen.get(obj);                  // 循环引用断链

  if (obj instanceof Date) return new Date(obj);
  if (obj instanceof RegExp) return new RegExp(obj.source, obj.flags);
  if (obj instanceof Map) {
    const m = new Map();
    seen.set(obj, m);
    obj.forEach((v, k) => m.set(deepClone(k, seen), deepClone(v, seen)));
    return m;
  }
  if (obj instanceof Set) {
    const s = new Set();
    seen.set(obj, s);
    obj.forEach(v => s.add(deepClone(v, seen)));
    return s;
  }

  const out = new obj.constructor(); // 保留原型（含子类实例）
  seen.set(obj, out);
  for (const key of Reflect.ownKeys(obj)) {          // 含 Symbol 键
    const desc = Object.getOwnPropertyDescriptor(obj, key);
    if (desc.get || desc.set) {
      Object.defineProperty(out, key, desc);          // getter/setter 直接复制描述符
    } else {
      out[key] = deepClone(desc.value, seen);
    }
  }
  return out;
}
// 验证
const a = { t: new Date(), list: [1, { x: 2 }] };
a.self = a;                       // 循环引用
const b = deepClone(a);
b.self === b;                     // true（链已重建）
b.list[1] !== a.list[1];          // true（深复制）
```

**评分点**：
- WeakMap 记忆化处理循环引用——核心判分点
- Date/RegExp/Map/Set 的特殊分支
- new obj.constructor 保留原型；Reflect.ownKeys 含 Symbol 键
- getter/setter 描述符处理（能写出即是超纲加分）
