## H5-372：移动端错误监控：JS 错误、白屏与资源失败

**答**：
- 错误三通道：window.onerror（JS 运行时）、unhandledrejection（Promise）、资源 onerror（img/script/css）+ 接口失败埋点——四类聚合才有完整错误面
- 白屏检测：关键容器节点渲染后采样（DOM 存在性 + canvas 采样像素法兜底），超时未渲染标记 white-screen 并抓取现场信息（资源加载列表、报错）
- 信息完备性：错误带 release 版本、sourcemap 解析（服务端按版本还原堆栈）、设备/网络/用户轨迹（最近 20 个事件）——只报 message 无法定位
- 移动端特有：WebView crash（进程级）无法 JS 上报，用「上次会话异常终止」推断（H5-596 方案）；桥调用失败单独通道
- 治理闭环：错误按 fingerprint 聚合（stack hash + 组件名），top 错误自动建单；报警带影响面（UV × 页面 PV）

```javascript
function captureErrors(send) {
  window.addEventListener('error', (e) => {
    e.target?.src ? send({ type: 'resource', src: e.target.src })
      : send({ type: 'js', msg: e.message, stack: e.error?.stack, file: e.filename, line: e.lineno });
  }, true);
  window.addEventListener('unhandledrejection', (e) =>
    send({ type: 'promise', reason: String(e.reason?.stack || e.reason) }));
  // 白屏检测: DOM ready 后 5s 关键节点仍空
  setTimeout(() => {
    if (!document.querySelector('#root [data-rendered]'))
      send({ type: 'white-screen', dom: document.body.innerHTML.slice(0, 500) });
  }, 5000);
}
```
