## JS-392：笔试：手写对象池

**答**：实现 `ObjectPool(factory, { max, reset })`：① acquire：空闲池有对象则复用（先 reset 清理状态），否则超 max 时排队等待归还；② release(obj)：归还并唤醒等待者；③ 上限控制：在借对象数 + 空闲数 ≤ max；④ destroy(obj)：归还时销毁（如 buffer 超龄）；⑤ 统计：inUse/idle/queued。写出实现。

```javascript
class ObjectPool {
  #idle = []; #waiters = []; #inUse = 0;
  constructor(factory, { max = 10, reset, maxAge = Infinity } = {}) {
    this.factory = factory; this.max = max; this.reset = reset;
    this.maxAge = maxAge;
    this.stats = { inUse: 0, idle: 0, queued: 0 };
  }
  async acquire() {
    if (this.#idle.length) {
      const obj = this.#idle.pop();
      this.reset?.(obj);                       // 复用前清理状态
      this.#inUse++;
      this.stats = { ...this.stats, inUse: this.#inUse, idle: this.#idle.length };
      return obj;
    }
    if (this.#inUse + this.#idle.length < this.max) {
      this.#inUse++;
      return this.factory();                   // 新建
    }
    this.stats.queued++;                       // 满了: 排队等归还
    return new Promise((resolve) => this.#waiters.push(resolve));
  }
  release(obj) {
    this.#inUse--;
    const w = this.#waiters.shift();
    if (w) { this.reset?.(obj); w(obj); this.#inUse++; }   // 直接转交等待者
    else this.#idle.push(obj);
    this.stats = { ...this.stats, inUse: this.#inUse, idle: this.#idle.length };
  }
  releaseAndMaybeDestroy(obj, age) {
    if (age > this.maxAge) { this.#inUse--; return; }       // 销毁不归还
    this.release(obj);
  }
}
// 用法: 大 ArrayBuffer 复用, 避免 GC 延迟释放
const pool = new ObjectPool(() => new ArrayBuffer(1024 * 1024), { max: 8 });
```

**评分点**：
- acquire 三分支：复用（reset 后）/新建（容量内）/排队（容量满）
- release 直转等待者（不经过 idle，减少竞争）
- reset 清理复用对象状态（防止脏数据）
- 统计信息暴露（inUse/idle/queued）
