## H5-220：视频自动播放策略全平台汇总与静音降级

**答**：
- 通用规则：静音视频基本全平台可自动播放；有声播放必须「用户手势解锁」或站内已有交互记录
- 平台差异：Chrome 有 MEI（媒体参与度）允许有声自动播放；iOS Safari 一律先静音；微信内置浏览器需 WeixinJSBridgeReady 事件
- 工程降级链：先尝试有声自动播放 → catch 后改 muted 播放 + 显示「点击开启声音」按钮 → 首次交互（click/touchend）后恢复声音
- 首帧优化：`preload="metadata"` + `poster` 占位，避免自动播放因加载慢而失败
- 坑：muted 属性必须写在 HTML 上（JS 后设置在 iOS 上偶发失效），播放失败要监听 promise rejection

```javascript
const v = document.querySelector('video');
v.play().catch(() => {
  v.muted = true;
  v.play().then(() => {
    const unlock = () => { v.muted = false; removeEventListener('click', unlock); };
    addEventListener('click', unlock, { once: true });
  });
});
```
