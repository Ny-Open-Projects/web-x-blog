## JS-406：笔试：手写滑动窗口限流器

**答**：实现 `SlidingWindow({ limit, windowMs })`：① windowMs 内最多 limit 次通过；② 精确滑动窗口（时间戳队列，不是固定窗口分桶）；③ `tryAcquire()`：立即判定（不排队）返回 true/false——用于「直接拒绝」场景；④ `acquire()`：等待最早请求滑出窗口（返回 Promise）；⑤ 多 key 独立限流（静态方法 `for(key)` 分域）。写出实现。

```javascript
class SlidingWindow {
  #hits = [];
  constructor({ limit, windowMs }) {
    this.limit = limit; this.windowMs = windowMs;
    this.#map = new Map();          // key -> hits[]
  }
  #map;
  #window(key = 'default') {
    const now = performance.now();
    const hits = this.#map.get(key) ?? this.#map.set(key, []).get(key);
    while (hits.length && now - hits[0] > this.windowMs) hits.shift();  // 滑出清理
    return hits;
  }
  tryAcquire(key = 'default') {
    const hits = this.#window(key);
    if (hits.length >= this.limit) return false;
    hits.push(performance.now());
    return true;
  }
  acquire(key = 'default') {
    const hits = this.#window(key);
    if (hits.length < this.limit) { hits.push(performance.now()); return Promise.resolve(); }
    const waitMs = this.windowMs - (performance.now() - hits[0]);  // 等最早一条滑出
    return new Promise(r => setTimeout(() => {
      this.#window(key);
      hits.push(performance.now());
      r();
    }, waitMs + 1));
  }
}
// tryAcquire: 秒杀类直接拒绝; acquire: 排队通过
```

**评分点**：
- 时间戳队列滑动窗口（无固定窗口边界突刺问题）
- tryAcquire 同步判定 vs acquire 排队两种语义
- 等待时长 = windowMs - 最早命中已存在时间
- 多 key 分域（Map per key）
