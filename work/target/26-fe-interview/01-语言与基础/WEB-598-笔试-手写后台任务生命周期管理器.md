## WEB-598：笔试：手写后台任务生命周期管理器

**答**：实现 `BgTaskRunner`：① 注册周期任务 `{ name, intervalMs, run, runInBg }`；② 前台按 intervalMs 执行；页面 hidden 时：runInBg=true 的任务降频执行（interval ×10，且对定时器漂移用绝对时间），否则暂停；③ 回前台立即补跑错过的任务一次（幂等由业务保证）；④ freeze 事件时停止一切并持久化任务状态到传入 store；⑤ resume 后恢复。写出核心实现。

```javascript
class BgTaskRunner {
  constructor(store) {
    this.tasks = new Map(); this.store = store;
    document.addEventListener('visibilitychange', () => this._sync());
    document.addEventListener('freeze', () => this._persist());
    document.addEventListener('resume', () => this._restore());
  }
  register(t) {
    this.tasks.set(t.name, { ...t, nextAt: 0, timer: null });
    this._sync();
  }
  _sync() {
    const bg = document.visibilityState === 'hidden';
    for (const t of this.tasks.values()) {
      clearTimeout(t.timer);
      if (bg && !t.runInBg) continue; // 后台暂停
      const iv = bg ? t.intervalMs * 10 : t.intervalMs;
      const schedule = () => {
        t.timer = setTimeout(async () => {
          const now = Date.now();
          if (now >= t.nextAt) { t.nextAt = now + iv; await t.run(); } // 绝对时间防漂移
          schedule();
        }, Math.max(0, (t.nextAt || Date.now()) - Date.now()));
      };
      schedule();
    }
    if (!bg) this._catchUp(); // 回前台补跑
  }
  _catchUp() { for (const t of this.tasks.values()) if (Date.now() >= (t.nextAt || 0) && t.nextAt) t.run(); }
  _persist() {
    const snap = [...this.tasks.values()].map(({ name, nextAt }) => ({ name, nextAt }));
    this.store.set('tasks', snap);
    for (const t of this.tasks.values()) clearTimeout(t.timer);
  }
  _restore() {
    for (const s of this.store.get('tasks') || []) {
      const t = this.tasks.get(s.name); if (t) t.nextAt = s.nextAt;
    }
    this._sync();
  }
}
```

**评分点**：
- 后台降频 ×10 且用绝对时间戳调度（后台定时器被节流的应对）
- runInBg=false 的任务后台暂停；回前台补跑一次
- freeze 持久化 + resume 恢复，理解进程冻结语义
- 定时器清理无泄漏（重调度前 clearTimeout）
