## H5-345：移动端支付与分享：桥能力设计与支付闭环

**答**：
- 支付闭环：H5 发起 → 桥调 Native 拉起收银台 → Native 完成支付 → 回调 H5（URL scheme 回跳或 bridge 回调）→ H5 轮询服务端订单状态确认（支付结果以服务端为准，不信回调参数）
- 三端差异：微信内只能走 JSAPI 支付（wx.chooseWXPay）、浏览器走 H5 支付（referer 校验坑）、App 内走桥；同一业务要按容器分发支付通道
- 分享能力：App 内走桥（share(text, imgs, channel)）；纯浏览器用 navigator.share（Web Share API，iOS/Android 支持已好）+ 系统分享面板
- 防重复支付：下单接口幂等（订单号防重）、支付按钮 loading 锁、桥超时后轮询订单而不是重新拉收银台
- 回调可靠性：Native 支付回调可能丢（App 被杀），落地页要「进入时先查订单状态」而不是等回调

```javascript
async function pay(orderId) {
  const channel = detectChannel(); // weixin | browser | app
  await api.post('/order/prepay', { orderId });   // 服务端生成支付参数
  if (channel === 'app') {
    await bridge.call('pay', { orderId });         // Native 收银台
  } else if (channel === 'weixin') {
    const p = await api.get(`/order/payparams?orderId=${orderId}`);
    await wx.chooseWXPay(p);                        // JSAPI 支付
  } else {
    location.href = `/api/pay/h5?orderId=${orderId}`; // H5 支付跳转
  }
  return pollOrderState(orderId);                  // 轮询确认, 服务端为准
}
async function pollOrderState(orderId, tries = 10) {
  for (let i = 0; i < tries; i++) {
    const s = await api.get(`/order/state?orderId=${orderId}`);
    if (s === 'PAID') return true;
    await new Promise(r => setTimeout(r, 1500));
  }
  return false;
}
```
