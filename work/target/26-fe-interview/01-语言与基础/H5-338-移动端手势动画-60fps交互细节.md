## H5-338：移动端手势驱动动画：从 touchmove 到 60fps

**答**：
- 手势动画链路：touchmove 里只记录数据（位移/速度），实际 DOM 更新放 rAF——把高频事件与渲染节拍解耦，避免一帧内多次写样式
- 只动合成属性：transform/opacity 才能走合成线程，手势拖拽用 `translate3d` 并加 will-change: transform 提升层；避免动 top/left/width（每次都 layout）
- 速度与惯性：跟手阶段位移直接映射；松手后用速度做惯性衰减（指数衰减或 spring 物理模型），rAF 循环驱动到收敛
- 越界阻尼：拖出边界时位移乘衰减系数（如 0.3），模拟原生 rubber-band 手感
- 中断处理：动画中途被新手势打断要「从当前值接续」——Web Animations API 或自己维护 current 值，避免闪跳回起点

```javascript
let x = 0, vx = 0, raf = 0, lastT = 0, lastX = 0;
el.addEventListener('touchmove', (e) => {
  const cx = e.touches[0].clientX;
  vx = cx - lastX; lastX = cx;
  requestAnimationFrame(() => {
    x += vx * (x < 0 || x > max ? 0.3 : 1);   // 越界阻尼
    el.style.transform = `translate3d(${x}px,0,0)`;
  });
}, { passive: true });

el.addEventListener('touchend', () => {       // 惯性衰减
  const decay = () => {
    vx *= 0.95; x += vx;
    el.style.transform = `translate3d(${x}px,0,0)`;
    if (Math.abs(vx) > 0.5) raf = requestAnimationFrame(decay);
  };
  decay();
});
```
