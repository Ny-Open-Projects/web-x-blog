## WEB-510：笔试：手写灰度分流函数

**题目**：实现 `grayBucket(uid)`：返回稳定可复现的桶号（0~99）；同一 uid 永远同桶；支持白名单强制进入实验桶；不同实验用不同 salt 互不干扰。

**答**：
```javascript
function hash32(str) {
  let h = 2166136261;
  for (let i = 0; i < str.length; i++) {
    h ^= str.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }
  return h >>> 0;
}

function grayBucket(uid, experiment, whitelist = []) {
  if (whitelist.includes(uid)) return 0; // 白名单强制实验桶
  return hash32(`${experiment}:${uid}`) % 100; // salt 保证各实验独立
}

grayBucket('u123', 'new-pay', ['vip1']); // 同一调用永远同结果
```

**评分点**：
- 哈希确定性：同一 uid+实验永远同桶（不能用 Math.random）
- salt（实验名）参与哈希，不同实验分流互不相关
- 白名单优先级最高
- 哈希分布均匀性（能提 FNV/Murmur 比取模 UID 数字更均匀加分）
