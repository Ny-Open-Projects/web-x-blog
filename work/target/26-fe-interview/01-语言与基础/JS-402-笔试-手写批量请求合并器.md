## JS-402：笔试：手写批量请求合并器

**答**：实现 `Batcher(batchFn, { maxWait, maxSize })`：① `load(id)` 返回 Promise 拿到该 id 的数据；② 窗口内（maxWait ms 或满 maxSize 个）的 id 合并为一次批量调用 `batchFn(ids)` 返回 Map；③ 每个调用方按 id 分发各自结果；④ batchFn 部分失败（某 id 缺失/报错）该 id 的调用方 reject，其他正常；⑤ 满窗立即发送不等 maxWait。写出实现。

```javascript
class Batcher {
  #queue = new Map();   // id -> Set<{resolve, reject}>
  #timer = null;
  constructor(batchFn, { maxWait = 20, maxSize = 50 } = {}) {
    this.batchFn = batchFn; this.maxWait = maxWait; this.maxSize = maxSize;
  }
  load(id) {
    return new Promise((resolve, reject) => {
      const set = this.#queue.get(id) || this.#queue.set(id, new Set()).get(id);
      set.add({ resolve, reject });
      if (this.#queue.size >= this.maxSize) this.#flush();          // 满窗立即
      else if (!this.#timer) this.#timer = setTimeout(() => this.#flush(), this.maxWait);
    });
  }
  async #flush() {
    clearTimeout(this.#timer); this.#timer = null;
    const q = this.#queue; this.#queue = new Map();
    const ids = [...q.keys()];
    let results;
    try { results = await this.batchFn(ids); }
    catch (e) { for (const waiters of q.values()) for (const w of waiters) w.reject(e); return; }
    for (const [id, waiters] of q) {
      const v = results?.get?.(id);
      if (v === undefined) for (const w of waiters) w.reject(new Error(`no result for ${id}`));
      else for (const w of waiters) w.resolve(v);
    }
  }
}
// 用法: 列表 30 张卡片并发 load(id) → 实际 1 次 batchFn([ids])
```

**评分点**：
- 双触发条件：maxWait 时间窗 / maxSize 满窗立即
- 一批内部分失败的按 id 隔离分发
- 调用方按 id 集合分发（同 id 多等待者共享结果）
- flush 时先清 queue 引用（防窗口内新请求混入本批）
