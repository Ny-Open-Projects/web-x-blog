## CSS-422：笔试：手写数字滚动动画

**答**：实现金额数字滚动：① 数值变化时每位数字向上滚动切换（0-9 数字列 translateY）；② 位数变化自适应（新增位淡入）；③ 千分位逗号分隔；④ 变速缓动（数字快速滚动后减速到位）；⑤ 无障碍：真实数值放 aria-label，滚动列 aria-hidden。写出核心实现。

```html
<span class="num-roll" aria-label="12850 元"><span class="cols" aria-hidden="true"></span></span>
```

```css
.num-roll { display: inline-flex; }
.col { display: inline-flex; height: 1em; overflow: hidden; }
.strip {
  display: flex; flex-direction: column;
  transition: transform .6s cubic-bezier(.2, .8, .2, 1);   /* 快起缓停 */
}
.strip span { height: 1em; line-height: 1em; }
.comma { transition: opacity .3s; }
```

```javascript
const DIGITS = [...'0123456789'];
function render(value) {
  const chars = value.toLocaleString();        // 千分位
  const cols = box.querySelectorAll('.col, .comma');
  // 位数对齐: 不足补空位(宽 0), 多余淡出移除
  while (cols.length < chars.length) {
    const col = document.createElement('span');
    col.className = 'col';
    col.innerHTML = `<i class="strip">${DIGITS.map(d => `<span>${d}</span>`).join('')}</i>`;
    box.append(col);
  }
  [...box.children].slice(chars.length).forEach(c => c.remove());
  [...chars].forEach((ch, i) => {
    const el = box.children[i];
    if (/\d/.test(ch)) {
      el.querySelector('.strip').style.transform = `translateY(-${+ch}em)`;
    } else {
      el.className = 'comma'; el.textContent = ch;
    }
  });
}
```

**评分点**：
- 数字条 strip translateY 按 em 对齐 line-height（等高列）
- 位数增减的 DOM 对齐策略
- toLocaleString 千分位处理
- aria-label 真值 + aria-hidden 滚动列（读屏友好）
