## H5-343：移动端传感器能力：陀螺仪、震动与地理定位

**答**：
- 陀螺仪 DeviceOrientationEvent 在 iOS 13+ 需要 requestPermission（且必须用户手势内调用）——摇一摇/全景类功能先过授权关
- 定位 geolocation：高精度（GPS）耗电耗时要按需开（enableHighAccuracy），超时设置必须配（timeout），弱网/室内 GPS 慢；App 内通常走桥调原生定位（更准更快）
- 震动 navigator.vibrate 只有 Android 支持，iOS 无 API——交互降级用 CSS 动画替代反馈
- 姿态数据融合：alpha/beta/gamma 角度值各厂商有偏差，精密场景（AR 指北针）要做滤波（低通/卡尔曼）与校准
- 传感器频率与功耗：高频监听（60Hz 陀螺仪）持续耗电，页面隐藏立即移除监听、用 throttle 控制回调频率

```javascript
async function enableShake() {
  if (typeof DeviceOrientationEvent.requestPermission === 'function') {
    const st = await DeviceOrientationEvent.requestPermission(); // iOS 必须手势内
    if (st !== 'granted') return false;
  }
  let last = 0;
  addEventListener('devicemotion', (e) => {
    const now = Date.now();
    if (now - last < 200) return;                // 节流省电
    last = now;
    const { x, y, z } = e.accelerationIncludingGravity;
    const g = Math.sqrt(x*x + y*y + z*z);
    if (g > 25) onShake();                       // 加速度阈值判定摇动
  });
  return true;
}
navigator.geolocation.getCurrentPosition(pos => {}, err => {
  if (err.code === err.PERMISSION_DENIED) guideToSettings();
}, { enableHighAccuracy: false, timeout: 8000, maximumAge: 60_000 });
```
