## H5-274：弱网 H5 体验优化清单：骨架屏-分页-降级

**答**：
- 感知层：骨架屏（布局占位防跳动）、进度反馈（上传/加载百分比）、错误可重试——弱网下「有反馈」比「快」更重要
- 传输层：接口合并（减少 RTT）、Gzip/Brotli、HTTP/3、关键接口预请求（DNS+TCP 预热）、图片按 effectiveType 降清晰度
- 数据层：分页 + 增量加载（杜绝一次拉全量）、本地缓存兜底（上次数据先渲染）、stale-while-revalidate
- 渲染层：首屏数据并行而非串行依赖、虚拟列表、非核心资源（推荐流/广告）延迟加载
- 度量闭环：按网络类型分桶看指标（2G/3G/4G/弱 WiFi），弱网专项的收益要用分桶数据证明

```javascript
const et = navigator.connection?.effectiveType || '4g';
const quality = { 'slow-2g': 0, '2g': 0, '3g': 1, '4g': 2 }[et] ?? 2;
document.documentElement.dataset.imgQuality = quality; // CSS/JS 据此选图清晰度
```
