## JS-338：任务调度器：优先级队列与过期时间设计

**答**：
- React 式调度模型：任务带 expiration（优先级越高越小）→ 小顶堆按 expiration 排序 → 每帧按剩余时间取任务执行；相同优先级按插入序（序列号 tie-break）
- 中断与恢复：任务切片化（generator/分批回调），调度器在预算耗尽时「保存游标」让出，下一帧从游标继续——高优先级任务可插队，低优先级任务被推迟甚至饿死（要防饥饿：低优先级任务等待超时后升级）
- 优先级提升场景：用户交互（点击的按钮渲染）抢占后台预计算——过期时间设计要反映「等多久不可忍」：Sync=立即、UserBlocking=250ms、Normal=5s、Idle=永不
- 取消语义：任务入队后取消（惰性删除：执行时检查 cancelled 标记，比堆删除简单）
- 手写考察点：小顶堆实现、时间片检查（shouldYield）、饿死防护、取消传播

```javascript
class Scheduler {
  constructor() { this.heap = []; this.seq = 0; }
  push(task, expiration) {
    this.heap.push({ task, expiration, seq: ++this.seq, cancelled: false });
    this._up(this.heap.length - 1);
  }
  cancel(task) { const it = this.heap.find(h => h.task === task); if (it) it.cancelled = true; }
  _less(a, b) { return a.expiration !== b.expiration ? a.expiration < b.expiration : a.seq < b.seq; }
  _up(i) { /* 上浮标准堆操作 */ }
  run(deadlineMs = 5) {
    const start = performance.now();
    while (this.heap.length && performance.now() - start < deadlineMs) {
      const top = this.heap[0];
      this._pop();
      if (top.cancelled) continue;
      top.task(() => performance.now() - start >= deadlineMs); // shouldYield 回调
    }
  }
}
```
