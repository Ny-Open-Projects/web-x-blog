## JS-416：笔试：手写按键消息合并器

**答**：实现 `Coalescer(handler, { windowMs })`：① `push(key, value)`：同 key 窗口内多次推送合并，窗口结束 handler 收到该 key 的值数组（或按 mergeFn 合并为单值）；② 不同 key 互不影响（各自窗口）；③ windowMs 结束触发（定时器按 key 管理）；④ mergeFn 自定义合并（默认数组）；⑤ flush(key) 立即触发。写出实现。

```javascript
class Coalescer {
  #buckets = new Map();   // key -> { values, timer }
  constructor(handler, { windowMs = 100, mergeFn } = {}) {
    this.handler = handler; this.windowMs = windowMs;
    this.mergeFn = mergeFn ?? ((_, values) => values);
  }
  push(key, value) {
    const b = this.#buckets.get(key) ?? this.#buckets.set(key, { values: [], timer: null }).get(key);
    b.values.push(value);
    if (!b.timer) b.timer = setTimeout(() => this.#flushKey(key), this.windowMs);
  }
  #flushKey(key) {
    const b = this.#buckets.get(key);
    if (!b) return;
    this.#buckets.delete(key);
    clearTimeout(b.timer);
    this.handler(key, this.mergeFn(key, b.values));
  }
  flush(key) { if (key) this.#flushKey(key); else for (const k of [...this.#buckets.keys()]) this.#flushKey(k); }
}
// 场景: 同一商品的库存变更消息窗口合并 → 一次刷新
const co = new Coalescer((key, values) => refreshCard(key, values.at(-1)), { windowMs: 200 });
co.push('sku-1', { price: 10 });
co.push('sku-1', { price: 12 });   // 合并 → 一次 refreshCard(sku-1, {price:12})
```

**评分点**：
- 按 key 独立桶与独立定时器（互不干扰）
- mergeFn 扩展点（默认数组/最后值/自定义聚合）
- flush 的批量与单 key 语义
- 定时器清理防泄漏（flushKey 清 timer）
