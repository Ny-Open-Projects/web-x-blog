## H5-376：笔试：手写优先级图片懒加载器

**答**：实现 `LazyImg`：① IntersectionObserver 触发加载，rootMargin 200px；② 并发上限 4（同屏多图避免网络竞争），按「距视口距离」优先加载近的；③ 加载失败重试 1 次（换备用 CDN 域名），再失败放占位图；④ 重复触发去重（同一元素只加载一次）；⑤ 提供 destroy() 清理观察器。写出核心实现。

```javascript
class LazyImg {
  constructor({ margin = '200px', concurrency = 4 } = {}) {
    this.loading = 0; this.queue = []; this.done = new WeakSet();
    this.io = new IntersectionObserver((ents) => {
      for (const e of ents) {
        if (!e.isIntersecting || this.done.has(e.target)) continue;
        this.done.add(e.target);
        this.io.unobserve(e.target);
        this.queue.push(e.target);
      }
      this.queue.sort((a, b) => a.getBoundingClientRect().top - b.getBoundingClientRect().top); // 近者优先
      this._drain();
    }, { rootMargin: margin });
  }
  observe(img) { this.io.observe(img); }
  _drain() {
    while (this.loading < 4 && this.queue.length) {
      const img = this.queue.shift();
      this.loading++;
      const load = (src) => new Promise((res, rej) => {
        const probe = new Image();
        probe.onload = res; probe.onerror = rej; probe.src = src;
      });
      const real = img.dataset.src;
      load(real).catch(() => load(real.replace('cdn1', 'cdn2')))  // 重试换域
        .catch(() => { img.src = img.dataset.placeholder || '/img/fallback.png'; })
        .finally(() => {
          if (img.src !== (img.dataset.placeholder || '/img/fallback.png') || true) img.src = img.src;
          this.loading--;
          this._drain();
        });
      img.src = real; // 实际元素也设 src(浏览器缓存命中探测结果)
    }
  }
  destroy() { this.io.disconnect(); this.queue = []; }
}
```

**评分点**：
- IO 触发 + 去重（WeakSet）+ unobserve，不重复加载
- 并发上限 + 按视口距离排序的优先级队列
- 失败两级兜底：换 CDN 重试一次 → 占位图
- destroy 清理观察器与队列无泄漏
