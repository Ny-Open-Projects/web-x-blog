## CSS-423：笔试：手写进度条

**答**：实现进度条：① 确定态：width 按 percent 过渡（0→100 平滑）；② 不确定态：滑块往返动画（无进度信息时）；③ 分段进度（多阶段任务，每段独立着色）；④ 条纹动效（斜纹滚动传达「进行中」，低端机/减动效关闭）；⑤ 无障碍（role=progressbar + aria-valuenow）。写出核心实现。

```html
<div class="bar" role="progressbar" aria-valuenow="60" aria-valuemin="0" aria-valuemax="100">
  <i class="fill" style="--p: 60"></i>
</div>
<div class="bar indet"><i></i></div>
```

```css
.bar {
  height: 8px; border-radius: 4px;
  background: #eee; overflow: hidden;
  position: relative;
}
.fill {
  position: absolute; inset-block: 0; left: 0;
  width: calc(var(--p) * 1%);
  background: var(--primary);
  transition: width .4s var(--ease-out-quart);
  border-radius: inherit;
}
/* 条纹: 渐变背景平移 */
.fill.striped {
  background: repeating-linear-gradient(45deg,
    var(--primary) 0 10px, color-mix(in oklab, var(--primary) 80%, white) 10px 20px);
  background-size: 28px 28px;
  animation: stripes .6s linear infinite;
}
@keyframes stripes { to { background-position: 28px 0; } }
/* 不确定态: 滑块往返 */
.indet i {
  position: absolute; inset-block: 0;
  width: 40%;
  background: var(--primary);
  animation: indet 1.2s var(--ease-out-quart) infinite;
}
@keyframes indet {
  from { left: -40%; }
  to { left: 100%; }
}
@media (prefers-reduced-motion: reduce) {
  .fill.striped, .indet i { animation: none; }
}
/* 分段: 多个 fill 并排, 各自 --p */
.segmented .fill { position: static; display: inline-block; }
```

**评分点**：
- width 过渡 + CSS 变量 --p 驱动（JS 只改变量）
- 条纹 repeating-linear-gradient 平移（进行中语义）
- 不确定态往返滑块动画
- reduced-motion 降级 + progressbar 语义
