## WEB-512：笔试：手写请求耗时瀑布图数据采集

**题目**：用 PerformanceObserver + Resource Timing 采集请求瀑布数据：每条请求提取 DNS/TCP/TLS/等待响应/内容下载各段耗时，按开始时间排序，输出 top 10 慢请求。注意 buffer 溢出问题。

**答**：
```javascript
function collectWaterfall({ top = 10 } = {}) {
  const rows = [];
  const po = new PerformanceObserver(list => {
    list.getEntries().forEach(e => {
      if (e.initiatorType === 'script') return; // 按需过滤
      rows.push({
        name: e.name.split('?')[0],
        start: Math.round(e.startTime),
        dns: Math.round(e.domainLookupEnd - e.domainLookupStart),
        tcp: Math.round(e.connectEnd - e.connectStart),
        tls: Math.round(e.secureConnectionStart ? e.connectEnd - e.secureConnectionStart : 0),
        wait: Math.round(e.responseStart - e.requestStart), // TTFB
        download: Math.round(e.responseEnd - e.responseStart),
        size: e.transferSize,
      });
    });
  });
  po.observe({ type: 'resource', buffered: true }); // buffered 拿到 observer 之前的历史
  return {
    topSlow() {
      return [...rows].sort((a, b) => (b.wait + b.download) - (a.wait + a.download)).slice(0, top);
    },
    disconnect: () => po.disconnect(),
  };
}
const wf = collectWaterfall();
setTimeout(() => console.table(wf.topSlow()), 5000);
```

**评分点**：
- Timing 各段语义正确：TTFB=responseStart-requestStart、TLS 用 secureConnectionStart 判空
- `buffered: true` 拿到注册前已发生的记录——高频遗漏点
- 排序按「等待+下载」总耗时取 top N
- URL 去 query 控制维度；disconnect 清理 observer
