## H5-377：笔试：手写不定高虚拟列表

**答**：实现不定高虚拟列表：① 每项有预估高度 estimateH，渲染后测量真实高度并更新 offset 累计数组；② scrollTop 二分查找定位起始项（offsets 有序数组）；③ 滚动中用「预估 offset」渲染，测量完成后校准（修正 transform 与 spacer 高度）；④ 向下滚动预估高度偏差的收敛策略（实际值逐步替换预估值）；⑤ 提供 scrollToIndex(index)。写出核心实现（60 行内）。

```javascript
class VList {
  constructor(container, { estimateH = 80, buffer = 5 } = {}) {
    this.c = container; this.eh = estimateH; this.buf = buffer;
    this.offsets = [0]; this.measured = new Map();
    this.wrap = document.createElement('div');          // 视口渲染层
    this.spacer = document.createElement('div');        // 撑高度
    this.c.append(this.spacer, this.wrap);
    this.wrap.style.position = 'absolute'; this.c.style.position = 'relative';
    this.c.addEventListener('scroll', () => requestAnimationFrame(() => this._render()), { passive: true });
  }
  setData(data) { this.data = data; this.offsets = [0]; this.measured.clear(); this._fill(); this._render(); }
  _fill() { // 用预估高度补齐 offsets
    while (this.offsets.length <= this.data.length)
      this.offsets.push(this.offsets[this.offsets.length - 1] + this.eh);
    this.spacer.style.height = this.offsets[this.data.length] + 'px';
  }
  _findIndex(top) { // 二分
    let lo = 0, hi = this.offsets.length - 1;
    while (lo < hi) { const mid = (lo + hi) >> 1; this.offsets[mid] < top ? lo = mid + 1 : hi = mid; }
    return lo;
  }
  _render() {
    const start = Math.max(0, this._findIndex(this.c.scrollTop) - this.buf);
    const end = Math.min(this.data.length, this._findIndex(this.c.scrollTop + this.c.clientHeight) + this.buf);
    this.wrap.innerHTML = '';
    this.wrap.style.transform = `translateY(${this.offsets[start]}px)`;
    for (let i = start; i < end; i++) {
      const el = this.render(this.data[i], i);
      this.wrap.appendChild(el);
      const real = el.getBoundingClientRect().height;
      if (this.measured.get(i) !== real) {           // 校准
        this.measured.set(i, real);
        const diff = real - (this.offsets[i + 1] - this.offsets[i]);
        for (let j = i + 1; j < this.offsets.length; j++) this.offsets[j] += diff;
        this.spacer.style.height = this.offsets[this.data.length] + 'px';
      }
    }
  }
  scrollToIndex(i) { this.c.scrollTop = this.offsets[i]; }
}
```

**评分点**：
- offsets 累计数组 + 二分定位，时间复杂度 O(log n)
- 预估 + 渲染后校准的收敛机制（diff 传播到后续所有项）
- 上下缓冲区渲染防快速滚动白屏
- scrollToIndex 精确到 offset（依赖已校准的 offsets）
