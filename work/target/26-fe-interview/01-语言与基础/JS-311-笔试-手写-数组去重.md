## JS-311：笔试：手写数组去重

**题目**：实现 `dedupe(arr)`：处理 NaN（Set/indexOf 视角不同）、对象引用去重（按 JSON 键或引用）、Symbol 键；O(n)。

**答**：
```javascript
// 基础：Set（NaN 会被 Set 正确去重——SameValueZero）
const dedupe = (arr) => [...new Set(arr)];
dedupe([1, 'a', 1, NaN, NaN]); // [1, 'a', NaN] ✅ NaN 正确去重
// 注意：new Set([NaN]).size === 1，而 arr.indexOf(NaN) 永远 -1

// 对象按内容去重：规范化键 + Map
function dedupeDeep(arr) {
  const seen = new Map();
  return arr.filter(item => {
    if (typeof item !== 'object' || item === null) return true;
    const key = JSON.stringify(sortKeys(item));
    if (seen.has(key)) return false;
    seen.set(key, true);
    return true;
  });
}
const sortKeys = (o) => Array.isArray(o)
  ? o.map(sortKeys)
  : o && typeof o === 'object'
    ? Object.keys(o).sort().reduce((r, k) => ((r[k] = sortKeys(o[k])), r), {})
    : o;

dedupeDeep([{ a: 1, b: 2 }, { b: 2, a: 1 }, { a: 1 }]);
// [{a:1,b:2},{a:1}] —— 键序无关

// 引用级去重（含 Symbol）
function dedupeRef(arr) {
  const seen = new Set();
  return arr.filter(x => !seen.has(x) && seen.add(x));
}
```

**评分点**：
- Set 的 SameValueZero 对 NaN 的正确处理（与 indexOf 的差异）
- 对象内容去重需「键序规范化」——本题核心
- filter + Set 的 O(n) 结构
- JSON.stringify 的局限（函数/循环引用）主动说明（加分）
