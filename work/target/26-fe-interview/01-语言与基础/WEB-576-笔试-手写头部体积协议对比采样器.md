## WEB-576：笔试：手写 QPACK 收益对比采样器

**答**：实现 `HeaderSampler`：① 采集页面全部 resource timing 中 h2 与 h3 资源的 `transferSize`/`encodedBodySize`，估算头部开销 = transferSize - encodedBodySize；② 按协议聚合：count、头部字节总和、单请求头部均值；③ 采样率 10%（hash 采样，同一 pv 稳定）；④ 输出对比对象并上报。写出实现，并说明为什么头部开销估算有误差。

```javascript
class HeaderSampler {
  constructor(rate = 0.1) {
    this.on = ((window.__PV_ID__ || '') .length * 2654435761 >>> 0) % 100 < rate * 100;
  }
  sample() {
    if (!this.on) return;
    const agg = { h2: { n: 0, hdr: 0 }, h3: { n: 0, hdr: 0 } };
    for (const e of performance.getEntriesByType('resource')) {
      const proto = e.nextHopProtocol;
      if (proto !== 'h2' && proto !== 'h3') continue;
      const hdr = Math.max(0, e.transferSize - e.encodedBodySize);
      agg[proto].n++;
      agg[proto].hdr += hdr;
    }
    const report = Object.fromEntries(Object.entries(agg).map(([k, v]) => [k, {
      count: v.n, headerBytes: v.hdr, avgHeader: v.n ? +(v.hdr / v.n).toFixed(1) : 0,
    }]));
    navigator.sendBeacon('/api/mon/qpack', JSON.stringify(report));
  }
}
```

**评分点**：
- 头部开销 = transferSize - encodedBodySize，方向正确并做负值防御
- h2/h3 同口径聚合且有均值，可对比 QPACK 效果
- 稳定 hash 采样（同 pv 结果一致），采样率可配置
- 能说出误差来源：cache 命中时 transferSize 为 0/压缩在 CDN 层差异/含 header 压缩前后不同（transferSize 是线上传输大小，QPACK 已压缩）
