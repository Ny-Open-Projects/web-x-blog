## H5-344：移动端文件上传：拍照、压缩与分片

**答**：
- 选文件入口：input accept="image/*" capture 调起相机；iOS 大图（HEIC 12MP）直接传原图是流量与内存灾难——必须前端压缩
- 压缩管线：createImageBitmap 解码（不占主线程解码）→ OffscreenCanvas 绘制缩放 → toBlob/canvas.convertToBlob 指定格式质量；HEIC 由浏览器自动解码（iOS 支持），不支持格式走服务端转码
- 分片上传：大文件 slice 分片（2~4MB）并发 2~3 片、断点续传（秒传/续传靠服务端返回已传分片列表）、最后 merge 接口
- 元数据校验：前端读文件头魔数校验真实类型（防改后缀）、图片方向 EXIF 修正（iOS 拍照 orientation 问题，现代浏览器 createImageBitmap imageOrientation 选项处理）
- 上传体验：进度用 XMLHttpRequest.upload.onprogress 或 fetch ReadableStream；页面切后台分片中断要可恢复

```javascript
async function compressImage(file, maxEdge = 1280, quality = 0.8) {
  const bmp = await createImageBitmap(file, { imageOrientation: 'from-image' }); // EXIF 修正
  const scale = Math.min(1, maxEdge / Math.max(bmp.width, bmp.height));
  const w = bmp.width * scale, h = bmp.height * scale;
  const off = new OffscreenCanvas(w, h);
  off.getContext('2d').drawImage(bmp, 0, 0, w, h);
  bmp.close();
  const blob = await off.convertToBlob({ type: 'image/jpeg', quality });
  return new File([blob], file.name.replace(/\.\w+$/, '.jpg'), { type: 'image/jpeg' });
}
```

```javascript
// 分片上传
async function uploadChunks(file, fileId, chunkSize = 4 * 1024 * 1024) {
  const done = new Set(await api.get(`/upload/done?fileId=${fileId}`));
  const total = Math.ceil(file.size / chunkSize);
  for (let i = 0; i < total; i++) {
    if (done.has(i)) continue;
    await api.post(`/upload/chunk?fileId=${fileId}&idx=${i}`,
      file.slice(i * chunkSize, (i + 1) * chunkSize));
  }
  return api.post(`/upload/merge?fileId=${fileId}&total=${total}`);
}
```
