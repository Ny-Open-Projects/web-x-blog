## WEB-280：弱网优化前端能做什么？离线包原理

**答**：
- 请求层：合并请求减少 RTT、接口数据压缩（br）、超时与重试策略（指数退避+抖动）、关键接口降级读缓存（stale 数据先渲染再刷新）。
- 资源层：图片按弱网降质（CDN 参数切小图）、预加载关键路径、骨架屏占位降低体感等待。
- 离线包：把 HTML/JS/CSS 打包成 zip 预先下发（App 内通过专用通道下载解压），WebView 请求命中本地文件直接返回，0 网络依赖；URL 映射用拦截器（App 层 shouldInterceptRequest）。
- Web 标准对应：Service Worker 缓存（Network First + 缓存兜底）实现近似离线包，PWA 的基础。
- 更新机制：版本号比对、差量包（bsdiff/zip diff）节省流量，后台静默更新下次启动生效。

```javascript
// SW 弱网兜底：先给缓存数据，同时请求新数据
self.addEventListener('fetch', (e) => {
  if (!e.request.url.includes('/api/')) return;
  e.respondWith(
    caches.match(e.request).then(hit => {
      const net = fetch(e.request).then(res => {
        caches.open('api-v1').then(c => c.put(e.request, res.clone()));
        return res.clone();
      }).catch(() => hit);
      return hit || net;   // 有缓存立即回，无缓存等网络
    })
  );
});
```
