## JS-425：笔试：手写轮询合并器

**答**：实现 `SyncHub`：① 多个消费者订阅同一数据源，单飞刷新（一次 fetch 服务所有等待者）；② 版本号仲裁：响应带 rev，旧 rev 丢弃不通知；③ 消费者各自记录 lastRev，通知时按消费者游标增量推送（rev > lastRev 的变更）；④ 刷新互斥（刷新中再次触发 refresh 复用在途 Promise）；⑤ 空转保护：连续 5 次无变更自动拉长轮询间隔 ×2。写出实现。

```javascript
class SyncHub {
  #subs = new Map();     // key -> { lastRev, cb }
  #rev = 0; #refreshing = null; #misses = 0; #interval = 5000;
  constructor(fetcher) { this.fetcher = fetcher; this.#schedule(); }
  subscribe(key, cb) {
    this.#subs.set(key, { lastRev: 0, cb });
    this.#refresh();                           // 新订阅触发一次
    return () => this.#subs.delete(key);
  }
  async #refresh() {
    if (this.#refreshing) return this.#refreshing;      // 单飞
    this.#refreshing = (async () => {
      try {
        const { rev, changes } = await this.fetcher(this.#rev);
        if (rev <= this.#rev) { this.#misses++; return; }  // 旧响应丢弃
        this.#misses = 0;
        this.#rev = rev;
        for (const [key, sub] of this.#subs) {
          const mine = changes.filter(c => c.rev > sub.lastRev);
          if (mine.length) { sub.lastRev = rev; sub.cb(mine); }
        }
      } finally {
        this.#refreshing = null;
        // 空转保护: 连续无变更拉长间隔
        this.#interval = this.#misses >= 5 ? Math.min(this.#interval * 2, 60_000) : 5000;
      }
    })();
    return this.#refreshing;
  }
  #schedule() { setTimeout(async () => { await this.#refresh().catch(() => {}); this.#schedule(); }, this.#interval); }
}
```

**评分点**：
- 单飞合并（refreshing Promise 复用）
- rev 单调仲裁（旧响应丢弃，防乱序）
- 按消费者游标增量分发（subs 各自 lastRev）
- 空转自适应间隔（misses 驱动退避）
