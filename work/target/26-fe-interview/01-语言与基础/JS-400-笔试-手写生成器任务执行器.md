## JS-400：笔试：手写生成器任务执行器

**答**：实现 `run(genFn)`：自动驱动 generator：① yield 一个值：是 Promise 则等结果后注入下一次 next()；② yield 函数则调用其结果继续；③ 支持返回值（genFn 的 return 是最终结果）；④ 生成器内抛错向上传播；⑤ 用它实现一个「带重试的流程」示例。写出实现。

```javascript
function run(genFn) {
  return new Promise((resolve, reject) => {
    const it = genFn();
    const step = (method, arg) => {
      let res;
      try { res = it[method](arg); }          // next 或 throw
      catch (e) { return reject(e); }
      if (res.done) return resolve(res.value);
      handle(res.value);
    };
    const handle = (v) => {
      // yield 函数: 先执行
      if (typeof v === 'function') v = v();
      // yield promise: 等结果注入
      if (v && typeof v.then === 'function')
        return v.then(r => step('next', r), e => step('throw', e));
      step('next', v);                        // 普通值直接注入
    };
    step('next');
  });
}

// 用法: 生成器流程(每步可重试)
function* flow() {
  const user = yield () => fetch('/api/user').then(r => r.json());
  const orders = yield () => fetch(`/api/orders?uid=${user.id}`).then(r => r.json());
  return { user, orders };
}
run(flow).then(console.log);
```

**评分点**：
- 递归驱动循环：next/throw 两路分发
- Promise 注入结果、函数先执行的语义分层
- done 判定取 return 值作为最终结果
- 生成器内同步异常捕获后 reject
