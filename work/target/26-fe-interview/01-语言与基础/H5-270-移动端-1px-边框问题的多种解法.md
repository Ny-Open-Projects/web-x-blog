## H5-270：移动端 1px 边框问题的多种解法

**答**：
- 问题本质：CSS 1px 是逻辑像素，DPR=2/3 的屏上实际渲染 2~3 物理像素，显得粗
- 解法一（伪类缩放）：::after 画 100% 尺寸边框再 `transform: scale(0.5)`，兼容最好，代码稍多
- 解法二（viewport 缩放）：整个页面按 1/DPR 缩放（rem 方案的副作用），全局统一但影响布局体系
- 解法三（渐变/阴影模拟）：`background-image: linear-gradient` 或极细 box-shadow，只适合单边
- 现代检查：`border: 0.5px` 在部分浏览器（Safari、Chrome 108+）已原生支持，可用 @supports 检测优先采用

```css
.border-1px { position: relative; }
.border-1px::after {
  content: ''; position: absolute; inset: 0;
  border: 1px solid #ddd;
  transform: scale(0.5); transform-origin: 0 0;
  width: 200%; height: 200%;
  pointer-events: none;
}
@supports (border: 0.5px solid #ddd) {
  .border-1px { border: 0.5px solid #ddd; }
  .border-1px::after { display: none; }
}
```
