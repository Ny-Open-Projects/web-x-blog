## WEB-489：笔试：手写分片上传器

**题目**：实现 `upload(file)`：5MB 分片、并发 3、失败重试 2 次、断点续传（localStorage 记已传分片）、全部完成后调 merge 接口校验。返回进度回调能力。

**答**：
```javascript
async function upload(file, { onProgress, chunkSize = 5 * 1024 * 1024, concurrency = 3 } = {}) {
  const key = `up:${file.name}:${file.size}`;
  const done = new Set(JSON.parse(localStorage.getItem(key) || '[]'));
  const total = Math.ceil(file.size / chunkSize);

  const pending = [...Array(total).keys()].filter(i => !done.has(i));
  let next = 0;
  async function worker() {
    while (true) {
      const i = next++;
      if (i >= pending.length) return;
      const idx = pending[i];
      const blob = file.slice(idx * chunkSize, (idx + 1) * chunkSize);
      let ok = false;
      for (let r = 0; r < 2 && !ok; r++) {
        try {
          await fetch(`/api/upload?i=${idx}&key=${key}`, {
            method: 'POST', body: blob,
          }).then(r => { if (!r.ok) throw r.status; });
          ok = true;
        } catch (e) { if (r === 1) throw e; }
      }
      done.add(idx);
      localStorage.setItem(key, JSON.stringify([...done])); // 断点续传
      onProgress?.(done.size / total);
    }
  }
  await Promise.all(Array(concurrency).fill(0).map(worker)); // 并发池
  await fetch('/api/merge', { method: 'POST', body: JSON.stringify({ key, total }) });
  localStorage.removeItem(key);
  return { total };
}
```

**评分点**：
- worker 池模式实现并发上限（不是 Promise.all 一把梭全部分片）
- 断点续传：本地记录已传分片，重传时跳过
- 单片失败重试有限次，重试耗尽要抛错而非静默丢片
- 最后 merge 校验、清理本地状态；进度回调按已传片数计算
