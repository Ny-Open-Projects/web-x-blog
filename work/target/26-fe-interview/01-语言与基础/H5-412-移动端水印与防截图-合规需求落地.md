## H5-412：移动端水印与防截图：合规需求的落地边界

**答**：
- 水印方案：CSS 叠加层（repeating 背景图/SVG pattern + pointer-events: none）覆盖内容；动态水印含用户 ID/时间戳，防「截图外传」的溯源需求
- 水印防篡改：MutationObserver 监听水印节点被删/改样式，被移除立即重建；层级用 z-index 上限 + 独立 stacking context；但 JS 水印可被 DevTools 移除——真防篡改要服务端渲染（图片打水印）或原生层
- 截图限制的真实边界：Web API 无法阻止系统截屏（iOS 无 API，Android FLAG_SECURE 是原生层能力）——需求对话要讲清「Web 只能做到水印溯源 + 敏感信息遮罩，无法真禁截屏」
- App 内加强：桥调原生开启 FLAG_SECURE（Android 防截屏/录屏）、iOS 只能靠水印；截屏事件监听（原生）回调 H5 打点
- 隐私合规：水印含设备/用户标识要注意个人信息展示范围（脱敏水印）

```javascript
function mountWatermark(text) {
  const svg = `<svg xmlns='http://www.w3.org/2000/svg' width='200' height='120'>
    <text x='10' y='60' fill='rgba(0,0,0,.08)' font-size='14'>${text}</text></svg>`;
  const el = document.createElement('div');
  el.id = '__wm__';
  el.style.cssText = `position:fixed;inset:0;pointer-events:none;z-index:2147483647;
    background:url("data:image/svg+xml,${encodeURIComponent(svg)}")`;
  document.body.appendChild(el);
  new MutationObserver(() => {                    // 防篡改
    if (!document.getElementById('__wm__')) mountWatermark(text);
  }).observe(document.body, { childList: true, subtree: false });
}
mountWatermark(`${user.id} ${Date.now()}`);
```
