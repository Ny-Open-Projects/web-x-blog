## JS-310：输出题：前瞻/后瞻断言匹配结果

**题目**：断言「零宽」的证明：匹配结果不包含断言内容；嵌套断言与捕获组的组合行为。

**答**：
```javascript
// 前瞻零宽：断言内容不出现在匹配结果
'abcd'.match(/abc(?=d)/);      // ['abc'] —— d 被检查但不消耗
'abcd'.match(/abc(d)/);        // ['abcd', 'd'] —— 捕获组才包含

// 千分位经典：位置断言
'1234567'.replace(/\B(?=(\d{3})+(?!\d))/g, ','); // '1,234,567'

// 后瞻（ES2018）
'¥100 $200'.match(/(?<=¥)\d+/g);   // ['100']（$ 前缀不命中）
'¥100 $200'.match(/(?<!¥)\d+/g);   // ['200']（不含 100 前面的… 注意 0 也命中：
                                    // 实际是 ['200']，因为 100 各位前面都是 ¥ 或数字）

// 负向断言组合：不含 bad 的单词
'good bad god'.match(/\b(?!bad)\w{3}\b/g); // ['good', 'god']

// 断言内捕获组仍然生效
'foo123'.match(/foo(?=(\d{3}))/); // ['foo', '123'] —— 断言内的组照样进 results
```

**评分点**：
- 断言零宽语义（检查位置不消耗字符）——核心
- 千分位断言的位置推导
- 负向断言 (?<!) 与 (?!) 的应用差异
- 断言内的捕获组仍进入结果数组（易漏细节）
