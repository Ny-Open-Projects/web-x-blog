## CSS-414：笔试：手写九宫格抽奖

**答**：实现九宫格抽奖：① 8 个奖品格 + 中心开始按钮（grid 布局，中间格留空）；② 点击后按顺时针路径轮转高亮：先加速、匀速多圈、最后减速停在目标（ease-out 分段变速）；③ 目标格由后端返回，前端按路径索引计算；④ 中奖格最终脉冲提示；⑤ 防重复点击（抽奖中禁用）。写出核心实现（JS 轮转 + CSS 高亮）。

```html
<div class="lottery">
  <div class="cell" data-i="0">奖1</div><div class="cell" data-i="1">奖2</div><div class="cell" data-i="2">奖3</div>
  <div class="cell" data-i="7">奖8</div><button class="go">开始</button><div class="cell" data-i="3">奖4</div>
  <div class="cell" data-i="6">奖7</div><div class="cell" data-i="5">奖6</div><div class="cell" data-i="4">奖5</div>
</div>
```

```css
.lottery { display: grid; grid-template-columns: repeat(3, 96px); gap: 8px; }
.cell { display: grid; place-items: center; height: 96px; border-radius: 8px; background: #f5f5f5; transition: all .1s; }
.cell.on {
  background: var(--primary); color: #fff;
  transform: scale(1.06);
}
.cell.win { animation: win-pulse .6s 2; }
@keyframes win-pulse { 50% { transform: scale(1.15); box-shadow: 0 0 0 8px #00000014; } }
.go { border-radius: 8px; background: #ff4d4f; color: #fff; border: none; }
.go:disabled { opacity: .6; }
```

```javascript
const PATH = [0, 1, 2, 3, 4, 5, 6, 7];   // 顺时针(data-i 序)
let running = false;
async function draw() {
  if (running) return; running = true; goBtn.disabled = true;
  const target = (await api.post('/lottery/draw')).index;   // 后端结果
  const laps = 3, steps = laps * 8 + ((target - 0 + 8) % 8);
  let cur = 0;
  for (let s = 0; s <= steps; s++) {
    const prev = cells[PATH[cur % 8]];
    prev.classList.remove('on');
    cur = (cur + 1) % 8;
    const cell = cells[PATH[cur]];
    cell.classList.add('on');
    // 变速: 前段加速 → 中段匀速 → 后段减速(按剩余步数插值)
    const remain = steps - s;
    const delay = s < 8 ? 160 - s * 12            // 加速
      : remain < 8 ? 80 + (8 - remain) * 40       // 减速
      : 80;                                        // 匀速
    await sleep(delay);
  }
  cells[PATH[cur]].classList.add('win');
  running = false; goBtn.disabled = false;
}
```

**评分点**：
- 顺时针路径数组（3x3 grid 的边缘索引顺序）
- 三段变速（加速/匀速/减速）的 delay 插值
- 目标索引与路径余数计算（跨圈定位）
- running 锁防重复抽奖
