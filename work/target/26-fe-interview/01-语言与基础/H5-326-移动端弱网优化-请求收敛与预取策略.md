## H5-326：移动端弱网优化：请求收敛与预取策略

**答**：
- 弱网第一原则是「少请求数」：合并接口（首屏聚合接口）、内联关键 CSS/JSON、图片懒加载与占位——弱网下 RTT 是主成本，每个请求都是一次往返
- 预取分级：确定性预取（用户必然到达的下一页首屏数据）、概率预取（列表第一项详情）、按需取消——配合 Network Information API 弱网时不预取（省流量优先）
- 弱网判定与分级：`navigator.connection.effectiveType`（2g/3g/4g）+ rtt/saveData，2g 关闭图片自动加载、禁用视频预加载、关闭非关键请求
- 请求优先级调度：核心请求（首屏数据）直发，次要请求（埋点/推荐）进队列延迟批量发，避免弱网下次要请求抢占并发窗口
- 失败体验兜底：弱网下超时阈值放宽 + 骨架屏，宁可慢不要白屏；失败重试带指数退避避免弱网雪崩

```javascript
const conn = navigator.connection || {};
const isPoorNet = conn.effectiveType === '2g' || conn.rtt > 800 || conn.saveData;

async function loadFirstScreen(ids) {
  // 收敛: 一个聚合接口替代 N 个详情接口
  const res = await fetch(`/api/aggregate?ids=${ids.join(',')}&lite=${isPoorNet ? 1 : 0}`);
  return res.json();
}
conn.addEventListener?.('change', () => {
  if ((navigator.connection.effectiveType === '2g')) {
    stopPrefetch(); document.querySelectorAll('img[data-src]').forEach(setLowQuality);
  }
});
```
