## CSS-408：笔试：手写全屏滚轮翻页

**答**：实现全屏翻页（PPT 式）：① 每屏 100dvh，wheel 触发上/下翻页（一屏一翻，连续滚动只算一次——冷却期 600ms）；② 触摸滑动翻页（速度阈值）；③ 键盘 PageUp/Down 与方向键；④ 当前页指示器；⑤ 翻页动画 transform 过渡。写出核心实现。

```html
<div class="deck" style="--cur: 0">
  <section>Page 1</section><section>Page 2</section><section>Page 3</section>
</div>
```

```css
.deck {
  height: 100dvh; overflow: hidden;
}
.deck section {
  height: 100%;
  transition: transform .5s var(--ease-out-quart);
}
/* 整体平移: 用容器 transform 或每页 translateY */
.deck { }
.deck section {
  position: absolute; inset: 0;
  transform: translateY(calc((var(--i) - var(--cur)) * 100%));
}
```

```javascript
const n = sections.length;
let cur = 0, lastFire = 0;
function go(d) {
  const next = Math.min(n - 1, Math.max(0, cur + d));
  if (next === cur) return;
  cur = next;
  deck.style.setProperty('--cur', cur);
  dots.forEach((dt, i) => dt.classList.toggle('on', i === cur));
}
addEventListener('wheel', (e) => {
  const now = Date.now();
  if (now - lastFire < 600) return;        // 冷却: 连续滚动一次翻页
  lastFire = now;
  go(e.deltaY > 0 ? 1 : -1);
}, { passive: true });
// 触摸: 速度阈值判定
let sy = 0, st = 0;
addEventListener('touchstart', (e) => { sy = e.touches[0].clientY; st = Date.now(); }, { passive: true });
addEventListener('touchend', (e) => {
  const dy = e.changedTouches[0].clientY - sy, dt = Date.now() - st;
  if (Math.abs(dy) > 50 && dt < 500) go(dy > 0 ? -1 : 1);
}, { passive: true });
// 键盘
addEventListener('keydown', (e) => {
  if (['ArrowDown', 'PageDown'].includes(e.key)) go(1);
  if (['ArrowUp', 'PageUp'].includes(e.key)) go(-1);
});
```

**评分点**：
- wheel 冷却期防止触控板惯性连翻（核心）
- CSS 变量驱动整组 translate 过渡
- 触摸速度阈值（50px/500ms）判定翻页
- 边界钳制（min/max）+ 三输入通道统一 go()
