## JS-342：重试与退避：幂等性约束下的安全重试

**答**：
- 重试前提是幂等：GET 天然可重试；POST 要服务端幂等键（Idempotency-Key）或业务幂等（唯一订单号）——「网络超时后原样重发 POST」可能造成重复下单
- 退避策略：指数退避 + 抖动（jitter）——base × 2^n + random(0, base)，防惊群；上限封顶（maxDelay）+ 总预算（maxAttempts 或总时长）
- 可重试错误分类：网络错误/5xx/429 可重试；4xx（参数错）不可重试；401 需要先刷新凭证再重试一次——错误分类决定重试矩阵
- 超时与重试的组合：单次超时短（快速失败）、总预算控制（整体 deadline）——避免「重试放大故障」（服务恢复瞬间的重试风暴）
- 与熔断的关系：连续失败达到阈值后熔断（直接快速失败一段时间），半开状态探测恢复——重试是单请求策略，熔断是服务级策略

```javascript
async function retry(fn, { attempts = 3, base = 200, maxDelay = 5000, onRetry } = {}) {
  for (let i = 0; i < attempts; i++) {
    try { return await fn(); }
    catch (e) {
      const retryable = !e.status || e.status >= 500 || e.status === 429;
      if (!retryable || i === attempts - 1) throw e;
      const delay = Math.min(base * 2 ** i + Math.random() * base, maxDelay);
      onRetry?.(i, delay, e);
      await new Promise(r => setTimeout(r, delay));
    }
  }
}
```
