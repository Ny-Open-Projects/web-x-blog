## JS-258：运算符优先级与隐式转换的坑

**答**：
- 转换规则：== 触发 ToPrimitive（对象先 valueOf 再 toString）；+ 遇对象先转原始值，遇字符串做拼接
- 经典组合：`[] + [] = ""`（两个都转 ""）、`[] + {} = "[object Object]"`、`{} + []` 在语句开头 = 0（{} 被当块）、`1 + '2' = '12'`
- 优先级高频点：`?.` 高于 `??`（?? 与 ||/&& 混用需括号）、new 的优先级高于方法调用、`a || (b && c)` 的结合
- 比较陷阱：NaN 与任何都不等（用 Object.is）；-0 === 0 但 Object.is 区分；null == undefined 为 true 但 === 为 false
- 解题守则：先把对象转原始值的结果标注出来，再套优先级，不凭感觉

```javascript
[] + [];        // ""
[] + {};        // "[object Object]"
1 + '2';        // '12'（拼接）
'5' - 2;        // 3（- 只有数值语义）
NaN === NaN;    // false
Object.is(NaN, NaN); // true
0.1 + 0.2 === 0.3;   // false（浮点）
0.1 + 0.2 < Number.EPSILON + 0.3; // 浮点比较要用误差容忍
```
