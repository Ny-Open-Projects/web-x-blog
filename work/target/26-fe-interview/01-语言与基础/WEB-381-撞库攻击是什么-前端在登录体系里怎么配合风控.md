## WEB-381：撞库攻击是什么？前端在登录体系里怎么配合风控？
**答**：
- 撞库：用其他网站泄露的账号密码批量试登录（用户复用密码）；表现为同 IP/同设备高频多账号尝试。
- 前端配合：上报设备指纹与行为数据（鼠标轨迹、输入节奏）、异常时弹验证码/二次验证、失败次数前端限流（防脚本绕过靠后端）。
- 产品侧：提示密码强度与泄露检测（HaveIBeenPwned 接口）、引导唯一密码+MFA。

```javascript
collectBehavior({ keystrokeInterval: 180, mousePath: 'human-like' });
if (failCount > 3) showCaptcha();
if (await pwnedCheck(sha1(password))) warn('该密码曾出现在泄露库，建议更换');
console.log('撞库防不住入口，防得住成本：指纹+行为+MFA');
```
