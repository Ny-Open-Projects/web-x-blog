## H5-382：笔试：手写列表滚动位置恢复器

**答**：实现 `ScrollKeeper`：① 离开列表页时保存 `{ scrollTop, listFirstId, ts }`（IndexedDB，key=路由+参数）；② 返回进入时：等数据渲染后恢复位置——恢复依据是 firstId 项滚到对应偏移 + delta（而不是直接 scrollTop，因为数据可能更新导致高度变化）；③ 数据项高度会变：恢复后 2 帧内二次校准（目标元素的 boundingRect 与预期差值补偿）；④ 超过 stalenessMs（30 分钟）不恢复从头开始；⑤ history back 与手动进入分支（popstate 或 entrance 标记）。写出核心实现。

```javascript
class ScrollKeeper {
  constructor(store, key, { staleMs = 30 * 60_000 } = {}) {
    this.store = store; this.key = key; this.stale = staleMs;
  }
  async save(container, firstId) {
    await this.store.set(this.key, {
      scrollTop: container.scrollTop, firstId, ts: Date.now(),
    });
  }
  async restore(container, findElById) {
    const s = await this.store.get(this.key);
    if (!s || Date.now() - s.ts > this.stale) return false;
    container.scrollTop = s.scrollTop;                 // 初步恢复
    return new Promise((resolve) => {
      requestAnimationFrame(() => requestAnimationFrame(() => {
        const el = findElById(s.firstId);              // 二次校准
        if (el) {
          const delta = el.offsetTop - s.scrollTop + (container.scrollTop - s.scrollTop);
          container.scrollTop = s.scrollTop + (el.offsetTop - s.scrollTop);
        }
        resolve(true);
      }));
    });
  }
}
// 使用: 列表页 pagehide 时 save(container, list[0].id);
// 返回时: await data ready → await keeper.restore(container, id => document.getElementById(`item-${id}`))
```

**评分点**：
- 保存三元组（scrollTop/firstId/ts）+ 过期判断
- 双 rAF 等渲染完成后再恢复，直接赋 scrollTop 的时序坑
- 基于锚点元素（firstId）的二次校准应对数据高度变化
- 存储走 IDB（跨会话）而非内存
