## H5-418：笔试：手写图片瀑布流布局器

**答**：实现 `Waterfall`：① 列数按容器宽度自适应（<480 两列，>=480 三列，>=768 四列）；② items 有 { id, w, h }（图片原始宽高），按「最短列优先」分配；③ 用绝对定位 + transform 布局（性能优先于 flex 方案），容器高度取最高列；④ 窗口 resize 重排（rAF 防抖）；⑤ 图片真实高度未知时用宽高比占位（aspect-ratio 防抖动），加载后可 update(id, h) 修正该列。写出核心实现。

```javascript
class Waterfall {
  constructor(container, gap = 12) {
    this.c = container; this.gap = gap; this.cols = []; this.items = new Map();
    this.ro = new ResizeObserver(() => requestAnimationFrame(() => this.layout()));
    this.ro.observe(container);
  }
  _colCount() {
    const w = this.c.clientWidth;
    return w >= 768 ? 4 : w >= 480 ? 3 : 2;
  }
  add(item) {
    this.items.set(item.id, item);
    this.layout();
  }
  layout() {
    const n = this._colCount();
    const cw = (this.c.clientWidth - this.gap * (n - 1)) / n;
    const heights = new Array(n).fill(0);
    for (const item of this.items.values()) {
      const col = heights.indexOf(Math.min(...heights));       // 最短列优先
      const h = cw * item.h / item.w;                          // 宽高比占位
      const x = col * (cw + this.gap), y = heights[col];
      const el = this.c.querySelector(`[data-id="${item.id}"]`) || this._make(item);
      el.style.cssText += `position:absolute;transform:translate(${x}px,${y}px);width:${cw}px;`;
      heights[col] += h + this.gap;
    }
    this.c.style.position = 'relative';
    this.c.style.height = Math.max(...heights) + 'px';
  }
  _make(item) {
    const el = document.createElement('div');
    el.dataset.id = item.id;
    el.innerHTML = `<img src="${item.src}" style="width:100%;aspect-ratio:${item.w}/${item.h};object-fit:cover" loading="lazy">`;
    this.c.appendChild(el);
    return el;
  }
}
```

**评分点**：
- 最短列分配算法正确（indexOf min）
- 宽高比占位防 CLS；绝对定位 + transform 布局性能优
- 列数断点自适应 + ResizeObserver/rAF 防抖重排
- 容器高度 = 最高列，避免内容截断

## 变体与延伸（补充）

**变体与延伸**：

1. 为什么布局用 transform 而不是直接改 top/left？ → transform 只触发合成与重绘，不进入重排；改 top/left 会引发 layout，滚动与 resize 时明显掉帧。
2. ResizeObserver 回调里为什么还要套一层 rAF？ → RO 在一帧内可能多次回调，rAF 把重排合并到下一帧只执行一次，避免连续 layout thrash。
3. 图片真实高度与 w/h 不符时怎么补救？ → 在 img 的 load 后按 naturalWidth/naturalHeight 调 update 修正该列高度，只重排该列后续元素而非整体重算。
