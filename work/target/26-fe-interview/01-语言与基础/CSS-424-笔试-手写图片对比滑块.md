## CSS-424：笔试：手写图片前后对比滑块

**答**：实现修图前后对比：① 两图叠放，上层用 clip-path: inset 按 --p 裁剪；② 分割线 + 拖拽手柄跟随；③ 拖拽（pointer 事件统一鼠标/触摸）更新 --p；④ 键盘可达（左右箭头步进 5%）；⑤ 双图尺寸严格一致（同一容器 + object-fit cover）。写出核心实现。

```html
<div class="compare" style="--p: 50" tabindex="0" role="slider"
     aria-label="对比滑块" aria-valuenow="50" aria-valuemin="0" aria-valuemax="100">
  <img class="after" src="after.jpg" alt="处理后">
  <img class="before" src="before.jpg" alt="处理前">
  <div class="divider"><i class="handle">⟷</i></div>
</div>
```

```css
.compare {
  position: relative; overflow: hidden;
  width: 100%; aspect-ratio: 4/3;
  touch-action: none;                 /* 阻止触摸滚动, 交给拖拽 */
}
.compare img {
  position: absolute; inset: 0;
  width: 100%; height: 100%; object-fit: cover;
}
.before {
  clip-path: inset(0 calc(100% - var(--p) * 1%) 0 0);  /* 只露左侧 --p% */
}
.divider {
  position: absolute; top: 0; bottom: 0;
  left: calc(var(--p) * 1%);
  width: 2px; background: #fff;
  transform: translateX(-1px);
}
.handle {
  position: absolute; top: 50%; left: 50%;
  transform: translate(-50%, -50%);
  width: 36px; height: 36px; border-radius: 50%;
  background: #fff; color: #333;
  display: grid; place-items: center;
  box-shadow: 0 2px 8px #0003;
  cursor: ew-resize;
}
.compare:focus-visible { outline: 2px solid var(--primary); }
```

```javascript
const comp = document.querySelector('.compare');
function setP(clientX) {
  const r = comp.getBoundingClientRect();
  const p = Math.min(100, Math.max(0, (clientX - r.left) / r.width * 100));
  comp.style.setProperty('--p', p);
  comp.setAttribute('aria-valuenow', Math.round(p));
}
comp.addEventListener('pointerdown', (e) => {
  comp.setPointerCapture(e.pointerId);
  setP(e.clientX);
});
comp.addEventListener('pointermove', (e) => {
  if (e.buttons || e.pointerType === 'touch') setP(e.clientX);
});
comp.addEventListener('keydown', (e) => {   // 键盘步进
  const cur = +getComputedStyle(comp).getPropertyValue('--p') || 50;
  if (e.key === 'ArrowLeft') { comp.style.setProperty('--p', Math.max(0, cur - 5)); }
  if (e.key === 'ArrowRight') { comp.style.setProperty('--p', Math.min(100, cur + 5)); }
});
```

**评分点**：
- clip-path inset 百分比裁剪驱动（单变量 --p 全联动）
- Pointer Events 统一鼠标/触摸 + setPointerCapture
- 键盘 slider 语义（role + aria-valuenow + 箭头步进）
- touch-action: none 阻止页面滚动抢手势
