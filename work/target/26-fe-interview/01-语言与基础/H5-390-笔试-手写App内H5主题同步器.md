## H5-390：笔试：手写 App 内 H5 主题同步器

**答**：实现 `ThemeSync`：① 主题优先级：App 下发（桥）> 用户本地选择（localStorage）> 系统偏好（prefers-color-scheme）；② App 内监听桥事件 theme.change 实时切换，浏览器内监听 media query 变化；③ 切换实现：html data-theme 属性 + CSS 变量，切换期间 body 加 class 禁用 transition 防闪变，下一帧移除；④ 首屏防闪：关键 CSS 内联当前主题（服务端按 cookie/userId 预判输出 data-theme）；⑤ 主题变化上报（用于统计用户主题分布）。写出核心实现。

```javascript
class ThemeSync {
  constructor(bridge) {
    this.bridge = bridge;
    this.current = this._resolve();
    this._apply(this.current);
    // 监听链
    bridge?.on('theme.change', (t) => this.set(t, 'app'));
    matchMedia('(prefers-color-scheme: dark)').addEventListener('change', () => {
      if (this.source === 'system') this.set(this._resolve(), 'system');
    });
  }
  _resolve() {
    return this.bridge?.theme          // 1. App 下发
      || localStorage.getItem('theme') // 2. 用户选择
      || (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light'); // 3. 系统
  }
  set(theme, source = 'user') {
    this.current = theme; this.source = source;
    document.body.classList.add('theme-switching');   // 禁 transition 防闪变
    this._apply(theme);
    requestAnimationFrame(() => requestAnimationFrame(() =>
      document.body.classList.remove('theme-switching')));
    if (source === 'user') localStorage.setItem('theme', theme);
    navigator.sendBeacon('/api/mon/theme', JSON.stringify({ theme }));
  }
  _apply(theme) { document.documentElement.dataset.theme = theme; }
}
```

```css
:root[data-theme='dark'] { --bg: #111; --fg: #eee; }
.theme-switching, .theme-switching * { transition: none !important; }
```

**评分点**：
- 三级优先级判定与来源追踪
- 切换期间禁 transition + 双 rAF 恢复，无闪变
- data-theme + CSS 变量主题方案
- 首屏服务端预判主题（SSR/内联）防白闪
