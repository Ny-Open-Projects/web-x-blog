## CSS-381：动画性能度量体系：帧率统计与掉帧归因

**答**：
- 线上度量：rAF 间隔采样（滑动窗口统计 P95 帧间隔与低帧占比）、长任务关联（掉帧时是否伴随 longtask）、动画 ID 标注（哪个动画劣化）——埋点聚合出「动画劣化 top 榜」
- 实验室度量：DevTools Performance 录制帧条、Rendering FPS meter；自动化 CI 用 Playwright 录制页面操作 + CDP 跟踪帧统计——回归门禁（P95 < 20ms）
- 归因决策树：掉帧时主线程忙 → JS/样式/布局长任务（找 Recalculate Style/Layout 事件）；主线程空闲仍掉帧 → 合成层问题（纹理过大/层爆炸/raster 排队）
- 指标口径：掉帧率（>33ms 帧占比）、卡顿用户占比（会话内 N 次连续掉帧）、动画流畅分（各动画 P95）——跟 INP 区分（INP 管交互响应，帧率管持续流畅）
- 报告闭环：动画性能纳入发布门禁与线上大盘，劣化 top 动画自动附 trace 附件

```javascript
class FpsProbe {
  constructor() { this.frames = []; this.start(); }
  start() {
    let last = performance.now();
    const tick = (t) => {
      this.frames.push(t - last); last = t;
      if (this.frames.length > 120) this.frames.shift(); // 2s 窗口
      requestAnimationFrame(tick);
    };
    requestAnimationFrame(tick);
    setInterval(() => this.report(), 10_000);
  }
  report() {
    const bad = this.frames.filter(d => d > 33).length;
    const sorted = [...this.frames].sort((a,b) => a-b);
    beacon({ p95: sorted[Math.floor(sorted.length*.95)], badRatio: bad / this.frames.length });
  }
}
```
