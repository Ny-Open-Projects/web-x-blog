## H5-222：MSE 是什么，流式播放为什么用它

**答**：
- MSE（Media Source Extensions）：让 JS 控制 `<video>` 的数据源——不再只喂一个 URL 文件，而是逐段喂编码后的媒体数据
- 解决的问题：自适应码率（边播边按网速换清晰度）、直播（实时追帧）、视频拼接（多文件无缝续播）
- 组成：MediaSource → SourceBuffer（每种编码一个）→ appendBuffer 喂 fMP4 片段；video.src 指向 MediaSource 的 objectURL
- 与协议的关系：HLS.js/DASH.js 都是「下载 m3u8/mpd → 下载 ts/m4s 分片 → 解封装 → MSE 喂给 video」
- 何时不用 MSE：普通点播小视频直接 URL 即可；iOS Safari 对 MSE 有限制（原生 HLS 支持）

```javascript
const ms = new MediaSource();
video.src = URL.createObjectURL(ms);
ms.addEventListener('sourceopen', () => {
  const sb = ms.addSourceBuffer('video/mp4; codecs="avc1.64001f"');
  fetch('/seg1.m4s').then(r => r.arrayBuffer()).then(buf => {
    sb.appendBuffer(buf);  // 喂一段，播一段
    sb.addEventListener('updateend', loadNextSegment);
  });
});
```
