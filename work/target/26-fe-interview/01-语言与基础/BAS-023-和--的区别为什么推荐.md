## BAS-023：== 和 === 的区别？为什么推荐 ===？
**答**：
- === 严格相等：类型不同直接 false，不做隐式转换。
- == 宽松相等：两边转成数字再比较，规则复杂，如 `0 == ''`、`'1' == true` 都是 true。
- 唯一推荐用 == 的场景：`x == null` 同时判 undefined 和 null，其余一律 ===。

```javascript
0 == '';        // true，'' 转成 0
'1' == true;    // true，两边都转成数字 1
null == 0;      // false，null 只与 undefined 宽松相等
0 === '';       // false，类型不同直接不等
if (x == null) {} // 等价于 x === undefined || x === null
```
