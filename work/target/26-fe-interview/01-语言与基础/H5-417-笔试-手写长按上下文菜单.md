## H5-417：笔试：手写长按上下文菜单

**答**：实现 `LongPressMenu`：① 长按 500ms 弹出菜单（回调带触发元素与坐标）；② 按住期间移动超过 10px 视为滚动意图，取消长按；③ 菜单打开后 touchmove/滚动/点击空白关闭；④ 阻止触发时的系统默认行为（iOS 长按选择文本/放大镜），但保持页面可滚动；⑤ 同一元素重复长按去抖（菜单开着不重复弹）。写出核心实现。

```javascript
class LongPressMenu {
  constructor(el, buildMenu, { duration = 500 } = {}) {
    let timer = null, sx = 0, sy = 0, opened = false;
    el.addEventListener('touchstart', (e) => {
      if (opened) return;                                  // 已打开去抖
      const t = e.touches[0];
      sx = t.clientX; sy = t.clientY;
      timer = setTimeout(() => {
        opened = true;
        e.preventDefault?.();                              // 阻止系统长按行为
        navigator.vibrate?.(10);
        buildMenu({ x: sx, y: sy, target: e.target });     // 渲染菜单
        const close = () => { opened = false; removeMenu(); };
        document.addEventListener('touchmove', close, { once: true, passive: true });
        document.addEventListener('touchend', close, { once: true });
        document.addEventListener('scroll', close, { once: true, capture: true });
      }, duration);
    }, { passive: true });
    el.addEventListener('touchmove', (e) => {              // 移动取消(滚动意图)
      const t = e.touches[0];
      if (Math.hypot(t.clientX - sx, t.clientY - sy) > 10) clearTimeout(timer);
    }, { passive: true });
    ['touchend', 'touchcancel'].forEach(ev =>
      el.addEventListener(ev, () => clearTimeout(timer), { passive: true }));
  }
}
// 用法:
// new LongPressMenu(listEl, ({x, y, target}) => showMenu(x, y, target.dataset.id));
```

**评分点**：
- 500ms 定时 + 移动 10px 取消（滚动意图判定）
- 菜单打开后 touchmove/scroll/抬起三类关闭信号
- 系统默认行为阻止的时机（打开时才阻止，不破坏滚动）
- 重复长按去抖与 cancel/touchend 清理
