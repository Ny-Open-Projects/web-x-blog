## H5-309：笔试：手写 IM 消息去重与排序器

**题目**：实现 `MessageStore`：按会话维护消息列表；`add(msg)` 按 seq 有序插入（乱序到达时插到正确位置）；按 msgId/localId 去重；`syncFrom(seq)` 返回大于该 seq 的消息用于断线续传；内存上限 500 条/会话（裁掉最旧）。

**答**：
```javascript
class MessageStore {
  #conv = new Map(); // convId -> { list: [], maxSeq, seen: Set }
  #convOf(id) {
    if (!this.#conv.has(id)) this.#conv.set(id, { list: [], maxSeq: 0, seen: new Set() });
    return this.#conv.get(id);
  }
  add({ convId, msgId, localId, seq, ...rest }) {
    const c = this.#convOf(convId);
    if (c.seen.has(msgId) || (localId && c.seen.has(localId))) return false; // 去重
    c.seen.add(msgId); localId && c.seen.add(localId);
    if (seq <= c.maxSeq - 500) return false; // 过旧丢弃

    // 有序插入（二分找位置）
    let lo = 0, hi = c.list.length;
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      c.list[mid].seq < seq ? lo = mid + 1 : hi = mid;
    }
    c.list.splice(lo, 0, { msgId, localId, seq, ...rest });
    c.maxSeq = Math.max(c.maxSeq, seq);
    if (c.list.length > 500) {
      const removed = c.list.splice(0, c.list.length - 500);
      removed.forEach(m => c.seen.delete(m.msgId));
    }
    return true;
  }
  syncFrom(convId, seq) { return this.#convOf(convId).list.filter(m => m.seq > seq); }
  latestSeq(convId) { return this.#convOf(convId).maxSeq; }
}
```

**评分点**：
- 二分插入保证有序（比 push+sort 高效）
- 双 ID 去重（服务端 msgId + 本地 localId，ack 前后各一）
- syncFrom 支持断线续传；maxSeq 是续传游标
- 容量裁剪时同步清 seen，防 Set 无限膨胀
