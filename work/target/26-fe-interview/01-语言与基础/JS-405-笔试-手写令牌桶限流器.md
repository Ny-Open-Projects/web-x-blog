## JS-405：笔试：手写令牌桶限流器

**答**：实现 `TokenBucket({ rate, capacity })`：① rate：每秒生成 rate 个令牌；capacity：桶容量（允许突发 ≤capacity）；② `take(n = 1)`：足够令牌立即通过，不足时等待到令牌够（返回 Promise）；③ 令牌按时间连续累积（不是定时器逐个加，用时间差计算）；④ 桶满不再累积；⑤ 取消等待（signal）。写出实现。

```javascript
class TokenBucket {
  #tokens; #last;
  constructor({ rate, capacity = rate }) {
    this.rate = rate; this.capacity = capacity;
    this.#tokens = capacity; this.#last = performance.now();
    this.#waiters = [];
  }
  #refill() {
    const now = performance.now();
    this.#tokens = Math.min(this.capacity, this.#tokens + (now - this.#last) / 1000 * this.rate);
    this.#last = now;
  }
  take(n = 1, signal) {
    this.#refill();
    if (this.#tokens >= n) { this.#tokens -= n; return Promise.resolve(); }
    const need = (n - this.#tokens) / this.rate * 1000;      // 攒够所需毫秒
    return new Promise((resolve, reject) => {
      const w = { n, resolve, timer: setTimeout(() => {
        this.#waiters = this.#waiters.filter(x => x !== w);
        this.#refill(); this.#tokens -= n; resolve();
      }, need) };
      signal?.addEventListener('abort', () => {
        clearTimeout(w.timer);
        this.#waiters = this.#waiters.filter(x => x !== w);
        reject(new DOMException('Aborted', 'AbortError'));
      }, { once: true });
      this.#waiters.push(w);
    });
  }
  async run(fn, { cost = 1, signal } = {}) { await this.take(cost, signal); return fn(); }
}
// 用法: 上报限流 20/s, 允许突发 50
const limiter = new TokenBucket({ rate: 20, capacity: 50 });
await limiter.run(() => api.report(event));
```

**评分点**：
- 时间差连续累积令牌（无定时器漂移），封顶 capacity
- 突发语义（capacity > rate 时首波可全过）
- 等待时间 = 缺口/rate 的精确计算
- signal 取消等待并清理
