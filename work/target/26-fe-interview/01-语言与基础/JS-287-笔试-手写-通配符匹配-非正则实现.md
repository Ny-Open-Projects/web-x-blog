## JS-287：笔试：通配符匹配

**题目**：实现 `wildcardMatch(pattern, str)`：`?` 匹配单字符、`*` 匹配任意长度（含 0）的字符串；不使用正则；时间复杂度 O(n*m) 以内；支持连续 `*`。

**答**：
```javascript
function wildcardMatch(pattern, str) {
  const n = pattern.length, m = str.length;
  // 动态规划：dp[i][j] = pattern 前 i 位是否匹配 str 前 j 位
  const dp = Array.from({ length: n + 1 }, () => new Array(m + 1).fill(false));
  dp[0][0] = true; // 空匹配空
  for (let j = 1; j <= m; j++) dp[0][j] = dp[0][j - 1] && pattern[0] === '*';
  for (let i = 1; i <= n; i++) {
    for (let j = 1; j <= m; j++) {
      const p = pattern[i - 1];
      if (p === '*') {
        dp[i][j] = dp[i - 1][j] /* * 吃 0 个 */ || dp[i][j - 1] /* 再吃 1 个 */;
      } else if (p === '?' || p === str[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1];
      }
    }
  }
  return dp[n][m];
}

wildcardMatch('a*c', 'abbbc');    // true
wildcardMatch('a?c', 'abc');      // true
wildcardMatch('a?c', 'ac');       // false
wildcardMatch('**a**', 'banana'); // true（连续 * 合并处理）
```

**评分点**：
- DP 状态定义与转移（* 的「吃 0 或吃 1」两条路径）——核心
- dp[0][j] 对前导 * 的初始化
- 连续 * 天然被 DP 覆盖（无需预处理）
- 能提双指针贪心 O(n·m)→近似线性 的进阶解法（加分）
