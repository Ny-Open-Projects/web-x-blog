## JS-212：命名捕获组与解构替换实战

**答**：
- 命名捕获：`(?<year>\d{4})` ——m.groups.year 替代脆弱的 m[1]
- matchAll 解构：`for (const { groups: { year, month } } of s.matchAll(re))` 一行拿字段
- replace 反向引用：`$<name>` 语法——`s.replace(re, '$<month>/$<day>/$<year>')`
- 工程价值：URL 路由解析、日志解析、表单拆分——语义化命名让正则可维护
- 细节：重复命名的组是语法错误；命名组未匹配到时 groups 中为 undefined

```javascript
const re = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/g;
const str = '发布于 2026-11-19，更新于 2026-10-01';
for (const { groups: { year, month, day } } of str.matchAll(re)) {
  console.log(year, month, day);
}
console.log('2026-11-19'.replace(re, '$<day>/$<month>/$<year>')); // 19/11/2026
```
