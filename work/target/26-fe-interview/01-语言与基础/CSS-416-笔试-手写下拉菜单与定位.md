## CSS-416：笔试：手写下拉菜单

**答**：实现下拉菜单：① 触发器点击/悬停展开，菜单绝对定位于触发器下方；② 边界翻转：靠近视口底部时向上展开、右侧溢出时右对齐（getBoundingClientRect 计算）；③ 键盘可达（Esc 关闭、方向键选择、focus trap）；④ 点击外部关闭；⑤ 入场动画（缩放原点随翻转方向变化）。写出核心实现。

```html
<div class="dd">
  <button class="trigger" aria-expanded="false">操作</button>
  <ul class="menu" role="menu" hidden>
    <li role="menuitem" tabindex="-1">编辑</li>
    <li role="menuitem" tabindex="-1">删除</li>
  </ul>
</div>
```

```css
.dd { position: relative; display: inline-block; }
.menu {
  position: absolute;
  top: calc(100% + 6px);
  inset-inline-start: 0;
  min-width: 140px;
  background: #fff; border-radius: 8px;
  box-shadow: 0 4px 16px #0002;
  padding: 4px;
  transform-origin: top left;
  animation: pop .15s var(--ease-out-quart);
}
.menu.flip-y { top: auto; bottom: calc(100% + 6px); transform-origin: bottom left; }
.menu.flip-x { inset-inline-start: auto; inset-inline-end: 0; transform-origin: top right; }
.menu [role='menuitem']:hover,
.menu [role='menuitem']:focus { background: #f5f5f5; }
@keyframes pop { from { transform: scale(.95); opacity: 0; } }
```

```javascript
function open() {
  menu.hidden = false;
  trigger.setAttribute('aria-expanded', 'true');
  const r = trigger.getBoundingClientRect();
  menu.classList.toggle('flip-y', r.bottom + menu.offsetHeight + 8 > innerHeight);
  menu.classList.toggle('flip-x', r.left + menu.offsetWidth > innerWidth);
  menu.querySelector('[role=menuitem]').focus();
}
document.addEventListener('click', (e) => {
  if (!dd.contains(e.target) && !menu.hidden) close();
});
addEventListener('keydown', (e) => {
  if (e.key === 'Escape') { close(); trigger.focus(); }
  if (e.key === 'ArrowDown' || e.key === 'ArrowUp') {
    e.preventDefault();
    const items = [...menu.querySelectorAll('[role=menuitem]')];
    const i = items.indexOf(document.activeElement);
    items[(i + (e.key === 'ArrowDown' ? 1 : items.length - 1)) % items.length].focus();
  }
});
```

**评分点**：
- 翻转判定用 getBoundingClientRect 对比视口剩余空间
- transform-origin 随翻转方向切换（动画自然）
- menuitem roving focus + 方向键循环 + Esc 归焦
- 点击外部关闭（contains 判定）
