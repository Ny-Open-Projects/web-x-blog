## H5-420：笔试：手写触摸速度追踪与惯性判定

**答**：实现 `TouchTracker`：① 记录最近 100ms 内的 touch 采样点（时间+坐标队列）；② 松手时计算瞬时速度（位移/时间，px/ms），用最近采样点而非全程平均（末端速度才真实）；③ 提供方向判定（水平/垂直/对角按角度阈值 30°）；④ 惯性判定：速度 > 0.5px/ms 且位移 > 20px 才认为 flick；⑤ 采样队列上限防内存增长。写出核心实现与 flick 回调。

```javascript
class TouchTracker {
  constructor({ flickMinV = 0.5, flickMinDist = 20, window = 100 } = {}) {
    this.samples = []; this.flickMinV = flickMinV; this.minDist = flickMinDist; this.win = window;
    el.addEventListener('touchstart', (e) => {
      this.samples = [];
      this._push(e.touches[0]);
    }, { passive: true });
    el.addEventListener('touchmove', (e) => this._push(e.touches[0]), { passive: true });
    el.addEventListener('touchend', (e) => this._flick(e.changedTouches[0]), { passive: true });
  }
  _push(t) {
    const now = performance.now();
    this.samples.push({ x: t.clientX, y: t.clientY, t: now });
    while (this.samples.length > 2 && now - this.samples[0].t > this.win) this.samples.shift();
  }
  _flick(t) {
    const now = performance.now();
    const old = this.samples[0];
    this.samples.push({ x: t.clientX, y: t.clientY, t: now });
    if (!old || now - old.t === 0) return null;
    const dx = t.clientX - old.x, dy = t.clientY - old.y, dt = now - old.t;
    const dist = Math.hypot(dx, dy);
    const v = dist / dt;                                    // px/ms
    const angle = Math.atan2(Math.abs(dy), Math.abs(dx)) * 180 / Math.PI;
    const dir = angle < 30 ? 'horizontal' : angle > 60 ? 'vertical' : 'diagonal';
    const result = { dx, dy, dt, v, dir, dist };
    if (v > this.flickMinV && dist > this.minDist)
      this.onFlick?.({ ...result, direction: dx > 0 ? 'right' : 'left', axis: dir });
    return result;
  }
}
// 用法: tracker.onFlick = ({ axis, dx }) => axis === 'horizontal' && slide(dx > 0 ? -1 : 1);
```

**评分点**：
- 滑动窗口采样（100ms）+ 队列清理，末端速度准确
- 速度 = 位移/时间（px/ms），方向角度阈值判定
- flick 双条件（速度 + 距离）防误触发
- touchend 用 changedTouches（move 后的终值）
