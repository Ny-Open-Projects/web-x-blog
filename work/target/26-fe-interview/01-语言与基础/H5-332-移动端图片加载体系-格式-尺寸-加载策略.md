## H5-332：移动端图片加载体系：格式、尺寸与加载策略

**答**：
- 格式选型链：AVIF > WebP > JPEG/PNG 兜底，用 picture/picture-source 按支持度自动降级；动图场景 AVIF/WebP 动图省一半以上体积
- 尺寸策略：按 DPR 与视口出多档尺寸（`srcset` + `sizes`），移动端避免把桌面大图直接下发；CDN 支持按参数实时缩放（?w=750&format=webp）
- 加载策略分层：首屏 eager + fetchpriority="high"；非首屏 lazy + 占位（低清 blurhash/主色背景）；轮播预加载相邻 1 张
- 体验细节：img 加 width/height 防布局抖动（CLS）、失败重试一次换 CDN 域名、大图渐进式 JPEG
- 流量敏感兜底：saveData 时下发低清档；WebP 支持探测用一次性特征图判断并缓存结果

```html
<picture>
  <source type="image/avif" srcset="hero.avif 1x, hero@2x.avif 2x">
  <source type="image/webp" srcset="hero.webp 1x, hero@2x.webp 2x">
  <img src="hero.jpg" srcset="hero@2x.jpg 2x" sizes="(max-width:750px) 100vw, 50vw"
       width="750" height="420" loading="lazy" decoding="async"
       fetchpriority="high" alt="商品图">
</picture>
```

```javascript
// 失败重试换 CDN
img.addEventListener('error', () => {
  if (!img.dataset.retried) {
    img.dataset.retried = '1';
    img.src = img.src.replace('cdn1', 'cdn2');
  }
}, { once: false });
```
