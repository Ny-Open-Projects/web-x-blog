## WEB-455：前端页面水印怎么做，怎么防删

**答**：
- 明水印：canvas/SVG 生成平铺背景（data URL 或 background-image），叠在页面最上层 `pointer-events: none`
- 暗水印（隐写）：把用户 ID 编进图片 LSB 像素或文本的零宽字符，泄漏后可溯源
- 防删手段：MutationObserver 监听水印节点被移除/样式被改，改了就重建；用 CSS 伪元素或 shadow DOM 提高门槛
- 认清边界：前端水印只能防「顺手截图保存」的普通用户，DevTools 面前一切前端水印都可破，核心数据要做服务端水印与权限控制
- 防截屏：浏览器网页无法真正防截屏，可尝试 Ctrl+P 时的打印样式加水印

```javascript
function watermark(text) {
  const c = document.createElement('canvas');
  c.width = 200; c.height = 120;
  const ctx = c.getContext('2d');
  ctx.rotate(-0.3); ctx.font = '14px sans-serif';
  ctx.fillStyle = 'rgba(0,0,0,0.08)';
  ctx.fillText(text, 20, 60);
  const div = document.createElement('div');
  div.style.cssText = `position:fixed;inset:0;pointer-events:none;z-index:99999;
    background:url(${c.toDataURL()}) repeat;`;
  document.body.appendChild(div);
  new MutationObserver(() => document.body.contains(div) || watermark(text)).observe(document.body, { childList: true });
}
```
