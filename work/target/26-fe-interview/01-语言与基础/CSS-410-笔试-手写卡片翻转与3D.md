## CSS-410：笔试：手写卡片翻转

**答**：实现 3D 翻转卡：① 正面/背面 backface-visibility 隐藏；② perspective 提供透视（父级）+ rotateY 翻转；③ 背面预旋转 180deg；④ hover（桌面）与 click（移动）双触发；⑤ 翻转高度以内容较高面为准（两面绝对定位撑高）。写出核心实现。

```html
<div class="flip">
  <div class="inner">
    <div class="face front">正面</div>
    <div class="face back">背面详情</div>
  </div>
</div>
```

```css
.flip {
  perspective: 1000px;              /* 透视必须在父级 */
  width: 260px;
}
.inner {
  position: relative;
  transform-style: preserve-3d;     /* 保留 3D 空间 */
  transition: transform .5s var(--ease-out-quart);
}
.face {
  backface-visibility: hidden;      /* 背面隐藏 */
  border-radius: 12px; padding: 24px;
}
.back {
  position: absolute; inset: 0;
  transform: rotateY(180deg);       /* 背面预旋转 */
}
/* 撑高: front 在流内定高, back 绝对定位 */
.flip:hover .inner,
.flip.flipped .inner { transform: rotateY(180deg); }
/* 内容差异高度: 用 grid 堆叠替代绝对定位(两面互相撑高) */
.inner { display: grid; }
.face { grid-area: 1/1; }
```

```javascript
// 移动端 click 触发
card.addEventListener('click', () => card.classList.toggle('flipped'));
```

**评分点**：
- perspective（父）+ preserve-3d（容器）+ backface-visibility 三件套
- 背面预旋转 180deg 的镜像原理
- grid-area 堆叠替代绝对定位解决两面高度差（高级点）
- hover 与 click 双通道 + 类切换翻转
