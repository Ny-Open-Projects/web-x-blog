## WEB-503：笔试：手写图片加载降级

**题目**：实现 `enhanceImg(img)`：加载失败时按链路降级——原域名 → 备用 CDN 域 → 静态占位图；防多次触发 onerror 死循环；上报失败明细（原始 URL 与当前步骤）。

**答**：
```javascript
const FALLBACKS = ['https://cdn-b.example.com', ''];
let reportQueued = [];

function enhanceImg(img) {
  const origin = img.dataset.origin || img.src;
  img.dataset.origin = origin; // 只记一次
  let step = 0;

  img.onerror = () => {
    step++;
    if (step === 1) {
      img.src = origin.replace(/https:\/\/cdn-[ab]\.example\.com/, FALLBACKS[0]);
      return;
    }
    if (step === 2) {
      reportQueued.push({ origin, page: location.pathname, t: Date.now() });
      img.src = 'data:image/svg+xml,' + encodeURIComponent(
        `<svg xmlns="http://www.w3.org/2000/svg" width="300" height="200"><rect width="100%" height="100%" fill="#eee"/><text x="50%" y="50%" text-anchor="middle" fill="#999">图片加载失败</text></svg>`);
      img.onerror = null; // 关键：占位图失败不再循环
    }
  };
}
// 批量上报
setInterval(() => {
  if (!reportQueued.length) return;
  navigator.sendBeacon('/api/img-fail', JSON.stringify(reportQueued.splice(0)));
}, 10000);
```

**评分点**：
- step 状态机防止 onerror 无限循环（占位图也失败时必须清掉 onerror）
- 备用域替换不能重复替换（data-origin 只记录一次）
- 失败上报批量聚合，sendBeacon 不阻塞
- 用 data URI 做占位图（不走网络，不会再触发 onerror）
