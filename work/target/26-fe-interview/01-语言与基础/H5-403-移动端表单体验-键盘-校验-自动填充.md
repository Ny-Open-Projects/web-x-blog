## H5-403：移动端表单体验：键盘、校验与自动填充

**答**：
- 键盘形态：inputmode（numeric/tel/email）+ type/autocomplete 语义正确——手机号 tel + autocomplete="tel" 触发系统自动填充与正确键盘，体验差距巨大
- 自动填充：autocomplete 属性集（name/email/address-line1/cc-number）+ 正确的 name/id 命名，密码/地址自动填充依赖这些语义标签
- 校验时机：input 事件轻校验（即时格式化如卡号空格分组）、blur 校验错误提示（不抢焦点）、提交时全量校验聚焦第一个错误项——避免「输入中报错」的烦躁
- 错误呈现：行内提示 + aria-invalid + 滚动到错误项；提交按钮防重复（loading 态锁定）
- 移动特有：数字键盘的小数点、iOS 密码自动填充（keychain）需要 autocomplete="current-password"、验证码自动填充（one-time-code）触发短信码一键输入

```html
<form>
  <input type="tel" inputmode="numeric" autocomplete="tel" name="phone"
         placeholder="手机号" required>
  <input type="text" inputmode="numeric" autocomplete="one-time-code"
         name="otp" maxlength="6" placeholder="验证码">
  <input type="email" inputmode="email" autocomplete="email" name="email">
  <button type="submit" aria-disabled="false">提交</button>
</form>
```

```javascript
// 卡号格式化 + 轻校验
cardInput.addEventListener('input', () => {
  const digits = cardInput.value.replace(/\D/g, '').slice(0, 16);
  cardInput.value = digits.replace(/(.{4})/g, '$1 ').trim();  // 分组
});
cardInput.addEventListener('blur', () => {
  const ok = cardInput.value.replace(/\s/g, '').length === 16;
  cardInput.setAttribute('aria-invalid', String(!ok));
  toggleError(cardInput, ok ? null : '请输入 16 位卡号');
});
```
