## WEB-485：笔试：手写弱网检测与降级开关

**题目**：实现 `netQuality()`：综合 Network Information API（effectiveType/rtt/downlink）与最近请求耗时，返回 'good' | 'mid' | 'bad'；连续 N 次请求超时则升级为 bad；提供 onChange 订阅。

**答**：
```javascript
function createNetQuality() {
  let level = 'good';
  let slowStreak = 0;
  const listeners = new Set();
  const c = navigator.connection;

  const evaluate = () => {
    if (slowStreak >= 3) level = 'bad';
    else if (c && (c.effectiveType === '2g' || (c.rtt && c.rtt > 800))) level = 'mid';
    else level = 'good';
    listeners.forEach(fn => fn(level));
  };

  c?.addEventListener('change', evaluate);
  window.addEventListener('online', evaluate);

  // 请求耗时观测：包装 fetch
  const _fetch = window.fetch;
  window.fetch = async (...args) => {
    const t0 = performance.now();
    try {
      const res = await _fetch(...args);
      if (performance.now() - t0 > 3000 || res.status >= 500) slowStreak++;
      else slowStreak = 0;
      return res;
    } catch (e) { slowStreak++; throw e; }
    finally { evaluate(); }
  };

  return {
    get level() { return level; },
    onChange(fn) { listeners.add(fn); return () => listeners.delete(fn); },
  };
}
const net = createNetQuality();
net.onChange(l => document.documentElement.dataset.net = l);
```

**评分点**：
- 信号融合：API 静态信息 + 实际请求耗时动态修正，只用单一信号不算满分
- 连续失败计数与恢复清零（slowStreak 逻辑）
- 包装 fetch 的做法及 finally 里 evaluate 的位置
- 订阅与退订返回清理函数
