## H5-422：笔试：手写视频播放状态机

**答**：实现 `VideoPlayer` 状态机：① 状态：idle → loading → playing ⇄ paused → ended；error 为全局可恢复分支；② 自动播放失败（NotAllowedError）等待用户手势后重试（一次性全局手势监听）；③ 播放中 error/stalled 处理：stalled >5s 尝试重载（currentTime 保留），error 计数 ≥3 次切换降级源（低码率 URL）或展示失败 UI；④ 弱网联动：DegradeManager poor 档直接加载低码率；⑤ 状态与耗时事件埋点（首次起播耗时 FPT）。写出核心实现。

```javascript
class VideoPlayer {
  constructor(video, { sources, degrade }) {
    this.v = video; this.sources = sources; this.degrade = degrade;
    this.errCount = 0; this.state = 'idle'; this.stallTimer = null;
    const poor = degrade?.level === 'poor';
    this.v.src = (poor ? sources.low : sources.main) || sources.main;

    this.v.addEventListener('loadedmetadata', () => this._setState('ready'));
    this.v.addEventListener('playing', () => {
      if (!this.t0) beacon({ fpt: performance.now() - (this.playRequestedAt || 0) }); // 首起播耗时
      this._setState('playing'); this.errCount = 0;
    });
    this.v.addEventListener('waiting', () => {
      this.stallTimer = setTimeout(() => this._reload(), 5000);   // 卡顿5s重载
    });
    ['playing', 'canplay'].forEach(ev => this.v.addEventListener(ev, () => clearTimeout(this.stallTimer)));
    this.v.addEventListener('error', () => this._onError());
    this.v.addEventListener('ended', () => this._setState('ended'));
  }
  async play() {
    this.playRequestedAt = performance.now();
    try { await this.v.play(); }
    catch (e) {
      if (e.name === 'NotAllowedError') {                     // 自动播放被拒
        const retry = () => { this.v.play().catch(() => {}); document.removeEventListener('touchend', retry); };
        document.addEventListener('touchend', retry, { once: true }); // 首次手势重试
      }
    }
  }
  _reload() {
    const t = this.v.currentTime;
    this.v.load();                                            // 重载保进度
    this.v.currentTime = t;
    this.v.play().catch(() => {});
  }
  _onError() {
    if (++this.errCount >= 3) {
      if (this.v.src !== this.sources.low) {                  // 降级低码率
        const t = this.v.currentTime;
        this.v.src = this.sources.low;
        this.v.currentTime = t; this.v.play().catch(() => {});
      } else { this._setState('error'); }                     // 最终失败 UI
    }
  }
  _setState(s) { this.state = s; this.onState?.(s); }
}
```

**评分点**：
- 状态机清晰，error 分支可恢复（重载保 currentTime）
- 自动播放拒绝 → 首次用户手势重试（once）
- stalled 5s 重载 + error 3 次降级源的阶梯策略
- 首起播耗时 FPT 埋点与弱网档联动
