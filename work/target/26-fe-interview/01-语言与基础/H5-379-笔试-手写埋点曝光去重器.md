## H5-379：笔试：手写曝光埋点去重器

**答**：实现 `ExposureTracker`：① IntersectionObserver 监听带 data-expose 元素，可见面积 ≥50% 且持续 ≥1s 才算有效曝光；② 同一会话同一 slotId 只计一次（sessionStorage 去重），支持重置（刷新内容场景 reset(ids)）；③ 有效曝光判定：进入视口启动计时，离开视口 <1s 则取消（用户快速划过不计）；④ 批量上报（满 10 条或 5s）；⑤ 列表复用场景元素被 v-if 重建后仍能正确去重（按 slotId 不按元素）。写出核心实现。

```javascript
class ExposureTracker {
  constructor({ url, threshold = 0.5, dwellMs = 1000 }) {
    this.timers = new Map(); this.pending = [];
    this.io = new IntersectionObserver((ents) => {
      for (const e of ents) {
        const slot = e.target.dataset.slotId;
        if (e.intersectionRatio >= threshold) {
          if (!this.timers.has(slot)) {
            this.timers.set(slot, setTimeout(() => {
              this.timers.delete(slot);
              this._report(slot, e.target.dataset);
            }, dwellMs));
          }
        } else {
          clearTimeout(this.timers.get(slot));    // 快速划过取消
          this.timers.delete(slot);
        }
      }
    }, { threshold: [threshold] });
  }
  observe(el) {
    if (sessionStorage.getItem(`exp:${el.dataset.slotId}`)) return; // 会话去重
    this.io.observe(el);
  }
  reset(ids) { ids.forEach(id => sessionStorage.removeItem(`exp:${id}`)); } // 内容刷新重置
  _report(slot, ds) {
    if (sessionStorage.getItem(`exp:${slot}`)) return;
    sessionStorage.setItem(`exp:${slot}`, '1');
    this.pending.push({ slot, scene: ds.scene, t: Date.now() });
    if (this.pending.length >= 10) this.flush();
  }
  flush() {
    if (!this.pending.length) return;
    navigator.sendBeacon('/api/track/expose', JSON.stringify(this.pending));
    this.pending = [];
  }
}
setInterval(() => {}, 5000); // 实际实现里 flush 也挂定时与 pagehide
```

**评分点**：
- 可见比例 + 停留时长双条件，离开即取消（防刷量）
- 会话去重按 slotId（元素重建不影响）+ reset 支持内容更新
- 批量上报与 pagehide 兜底
- IO 阈值配置合理（50% 面积）
