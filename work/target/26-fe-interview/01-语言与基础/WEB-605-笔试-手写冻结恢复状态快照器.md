## WEB-605：笔试：手写页面冻结/恢复状态快照器

**答**：实现 `FreezeSnapshot`：① 注册状态片段 `{ key, get, set }`；② freeze 事件时把所有片段快照序列化存入 IndexedDB（key + JSON）；③ resume 时比对冻结时间戳与当前时间差，超过 stalenessMs（默认 5 分钟）才恢复（数据可能过期）；④ 恢复完成后回调 onRestore；⑤ 序列化失败的片段跳过并记录。写出核心实现。

```javascript
class FreezeSnapshot {
  constructor(store, { stalenessMs = 5 * 60_000 } = {}) {
    this.store = store; this.fresh = stalenessMs; this.parts = [];
    document.addEventListener('freeze', () => this._save());
    document.addEventListener('resume', () => this._restore());
  }
  register(key, get, set) { this.parts.push({ key, get, set }); }
  async _save() {
    const snap = { frozenAt: Date.now(), data: {} };
    for (const p of this.parts) {
      try { snap.data[p.key] = JSON.parse(JSON.stringify(p.get())); }
      catch { snap.data[p.key] = undefined; (snap.skipped ||= []).push(p.key); }
    }
    await this.store.set('freeze-snap', snap);
  }
  async _restore() {
    const snap = await this.store.get('freeze-snap');
    if (!snap) return;
    if (Date.now() - snap.frozenAt > this.fresh) return; // 数据过期不恢复
    for (const p of this.parts) {
      if (snap.data[p.key] !== undefined) p.set(snap.data[p.key]);
    }
    this.onRestore?.(snap);
  }
}
```

**评分点**：
- freeze/resume 事件语义正确（进程冻结与解冻）
- 快照带 frozenAt + staleness 判断，理解冻结期间时间跳变
- JSON 化捕捉不可序列化片段，跳过且记录
- 只在过期阈值内恢复，避免陈旧状态覆盖新数据
