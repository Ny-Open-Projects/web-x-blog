## JS-286：笔试：手写关键词高亮

**题目**：实现 `highlight(text, keywords)`：多个关键词同时高亮（wrap 成 `<mark>`）；关键词含正则元字符时正确处理；避免嵌套标签破坏（转义文本 + 单次替换）；大小写不敏感可选。

**答**：
```javascript
const escapeRe = (s) => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');

function highlight(text, keywords, { caseInsensitive = false } = {}) {
  if (!keywords?.length) return text;
  // ① 先转义文本（防 XSS + 防 <mark> 被破坏）
  const safe = text.replace(/[&<>"']/g, c =>
    ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' }[c]));
  // ② 多关键词合并为一个交替正则（一次替换，避免嵌套高亮）
  const re = new RegExp(
    `(${keywords.map(k => escapeRe(k)).sort((a, b) => b.length - a.length).join('|')})`,
    caseInsensitive ? 'gi' : 'g'
  );
  return safe.replace(re, '<mark>$1</mark>');
}

highlight('React 与 Vue 都好', ['react', 'Vue'], { caseInsensitive: true });
// '<mark>React</mark> 与 <mark>Vue</mark> 都好'
highlight('价格 a.b 元', ['a.b']); // '<mark>a.b</mark>' —— 元字符被转义
```

**评分点**：
- 关键词正则元字符转义（escapeRe）——必踩坑
- 文本先 HTML 转义再高亮（顺序反了会注入）——安全核心
- 多关键词合并单正则 + 长词优先排序（防止短词截胡长词匹配）
- gi 标志的大小写选项
