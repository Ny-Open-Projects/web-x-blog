## H5-315：笔试：手写离线兜底 SW

**题目**：编写 sw.js：install 预缓存核心资源与离线页；fetch 拦截按请求类型分策略——导航请求 network-first（失败回离线页）、静态资源 cache-first、API network-only（失败返回 JSON 错误响应）；activate 清理旧版本缓存。

**答**：
```javascript
const V = 'v3';
const CORE = ['/', '/offline.html', '/app.css', '/app.js'];

self.addEventListener('install', (e) => {
  e.waitUntil(caches.open(V).then(c => c.addAll(CORE)).then(() => self.skipWaiting()));
});
self.addEventListener('activate', (e) => {
  e.waitUntil(
    caches.keys().then(keys => Promise.all(keys.filter(k => k !== V).map(k => caches.delete(k))))
      .then(() => self.clients.claim())
  );
});

self.addEventListener('fetch', (e) => {
  const { request } = e;
  if (request.method !== 'GET') return;

  if (request.mode === 'navigate') {
    // 导航：network-first，失败回离线页
    e.respondWith(fetch(request).catch(() => caches.match('/offline.html')));
  } else if (request.destination === 'style' || request.destination === 'script' || request.destination === 'image') {
    // 静态资源：cache-first + 后台更新
    e.respondWith(
      caches.match(request).then(hit =>
        hit ||
        fetch(request).then(res => {
          const clone = res.clone();
          caches.open(V).then(c => c.put(request, clone));
          return res;
        })
      )
    );
  } else if (request.url.includes('/api/')) {
    // API：network-only，失败返回结构化错误
    e.respondWith(fetch(request).catch(() =>
      new Response(JSON.stringify({ error: 'offline' }), { status: 503, headers: { 'Content-Type': 'application/json' } })
    ));
  }
});
```

**评分点**：
- 三类请求三策略，install/activate 生命周期完整
- 导航失败必须兜底离线页（这是「离线可用」的核心）
- cache-first 分支要 clone 响应再 put（body 只能读一次）
- API 失败返回合法 Response 而不是放空——respondWith 必须返回 Response
- 版本化缓存 + activate 清理
