## JS-253：事件循环综合输出题的解题框架

**答**：
- 四层优先级（每轮循环）：① 同步代码 ② 微任务（Promise.then/queueMicrotask/MutationObserver，全部清空）③ 渲染（rAF 回调）④ 宏任务（setTimeout）
- 解题五步：跑同步 → 清微任务（嵌套产生的微任务也清）→ 若有 rAF 走渲染 → 取一个宏任务 → 重复
- 易错点：await 后面的代码 = then 回调（微任务）；new Promise 执行器是同步的；setTimeout(0) 与 Promise.then 的相对顺序
- 每层内部保持 FIFO；同一层里嵌套产生的新任务排在当前层队列尾部（微任务在当前清空轮内继续处理）

```javascript
console.log('1');
setTimeout(() => console.log('2'), 0);
Promise.resolve().then(() => console.log('3'));
requestAnimationFrame(() => console.log('4')); // 渲染前
(async () => { await null; console.log('5'); })(); // await 后 = 微任务
console.log('6');
// 输出：1 6 3 5 (渲染) 4 2
// 同步 1,6 → 微任务 3,5 → rAF 4 → 宏任务 2
```
