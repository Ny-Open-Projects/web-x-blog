## H5-388：笔试：手写安全区与 vw 混合布局换算器

**答**：实现 `LayoutCalc`（构建期/运行时通用）：① `pxToVw(px, designWidth=750)`：设计稿像素转 vw 字符串（保留 2 位小数）；② `clampFontSize(minPx, maxPx, vwPx, designWidth)`：生成 clamp() 表达式；③ `safePadding(topPx, bottomPx)`：生成 max(env(safe-area-inset-*), px) 的 CSS 值（含 constant 兼容）；④ 小于 2px 的值不转 vw（保持 px，防 1px 边框问题）；⑤ 输出为可直接内联 style 的字符串。写出核心实现与示例输出。

```javascript
function pxToVw(px, designWidth = 750) {
  if (Math.abs(px) < 2) return `${px}px`;            // 小尺寸保 px(1px 边框)
  return `${+(px / designWidth * 100).toFixed(2)}vw`;
}

function clampFontSize(minPx, maxPx, vwPx, designWidth = 750) {
  const vw = +(vwPx / designWidth * 100).toFixed(2);
  return `clamp(${minPx}px, ${vw}vw, ${maxPx}px)`;
}

function safePadding(topPx = 44, bottomPx = 12) {
  return {
    paddingTop: `max(constant(safe-area-inset-top), ${topPx}px)`,
    paddingTopModern: `max(env(safe-area-inset-top), ${topPx}px)`,
    paddingBottom: `max(constant(safe-area-inset-bottom), ${bottomPx}px)`,
    paddingBottomModern: `max(env(safe-area-inset-bottom), ${bottomPx}px)`,
  };
}

// 示例输出
console.log(pxToVw(375));        // '50vw'
console.log(pxToVw(1));          // '1px'
console.log(clampFontSize(14, 20, 15, 750)); // 'clamp(14px, 2vw, 20px)'
console.log(safePadding().paddingBottomModern); // 'max(env(safe-area-inset-bottom), 12px)'
```

**评分点**：
- 设计稿宽度换算公式正确（px/750*100 vw），保留精度
- 小值保 px 的边界规则（1px 边框防模糊）
- clamp 限幅表达式生成正确
- env 与 constant 双写兼容老 iOS，max 防叠加
