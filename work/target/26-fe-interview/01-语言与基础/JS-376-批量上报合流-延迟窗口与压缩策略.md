## JS-376：批量上报合流：延迟窗口与压缩策略

**答**：
- 合流三策略：延迟窗口（攒 3~5s 或满 N 条发）、立即上浮（error 级别直接发不进队列）、pagehide 强制 flush——分级让关键数据不等窗口
- 压缩与裁剪：payload 精简（字段白名单）、采样（低价值事件按率采样）、gzip（fetch 自动）——上报体积分层管理，别把 100KB 埋点包发出去
- 失败重试与丢弃：重试 1 次后丢弃（别让上报风暴），丢弃计数入下一批（可观测丢失率）；IndexedDB 落盘只在「必须不丢」的 P0 事件启用
- 队列上限与背压：上限 500 条 + 丢最旧（保最新），丢弃计数上报——内存保护优先于数据完整（监控数据不能拖垮业务页面）
- 时序保持：事件带本地时间戳 + 单调序号；批量内按序排列——服务端按 seq 还原顺序，乱序防御

```javascript
class BatchReporter {
  #q = []; #dropped = 0;
  constructor({ max = 500, windowMs = 3000, flushSize = 20 } = {}) {
    Object.assign(this, { max, windowMs, flushSize });
    setInterval(() => this.flush(), this.windowMs);
    addEventListener('pagehide', () => this.flush(true));
  }
  report(level, event) {
    if (level === 'error') return this.#send([event]);        // error 立即上浮
    if (this.#q.length >= this.max) { this.#q.shift(); this.#dropped++; }
    this.#q.push({ ...event, seq: ++BatchReporter.seq, t: Date.now() });
    if (this.#q.length >= this.flushSize) this.flush();
  }
  flush(urgent = false) {
    if (!this.#q.length) return;
    const batch = { events: this.#q.splice(0), dropped: this.#dropped };
    this.#dropped = 0;
    urgent ? navigator.sendBeacon('/api/collect', JSON.stringify(batch))
           : fetch('/api/collect', { method: 'POST', body: JSON.stringify(batch), keepalive: true })
             .catch(() => {});                                // 失败丢弃, 计数下批
  }
}
```
