## WEB-524：灰度工具设计：按用户/百分比/白名单

**答**：
- 三种模式可组合：白名单（指定用户先试）→ 按用户哈希分桶（稳定可复现）→ 按流量百分比（新用户随机）
- 关键设计：分流因子与桶算法要稳定（同 uid 同实验永远同结果），否则用户「一会儿有一会儿没有」
- 前端实现：分流 SDK 启动时拉实验配置（实验名、占比、白名单、版本），按 uid 哈希决定桶，注入到全局变量供业务判断
- 观测配套：所有埋点必须带实验桶号，否则灰度数据无法归因
- 安全阀：一键全量回滚（配置中心改占比）优于重新发版；实验开关要有过期时间防遗忘

```javascript
function bucket(uid, exp) {
  const cfg = experiments[exp];
  if (cfg.whitelist?.includes(uid)) return 'treatment';
  const h = hash(`${exp}:${uid}`) % 100;
  return h < cfg.percent ? 'treatment' : 'control';
}
```
