## JS-302：笔试：大文件分块生成器

**题目**：实现 `chunks(blob, size)`：异步生成器逐块 yield Blob；块大小可配（默认 5MB）；支持进度回调（已产出字节/总量）；消费方 break 后不再切块（惰性）。

**答**：
```javascript
async function* chunks(blob, size = 5 * 1024 * 1024, onProgress) {
  const total = blob.size;
  let offset = 0;
  while (offset < total) {
    const end = Math.min(offset + size, total);
    yield blob.slice(offset, end);       // slice 是惰性引用，不复制数据
    offset = end;
    onProgress?.(offset, total);
  }
}
// 上传消费：break 即停止（后续块不会创建）
async function upload(file) {
  for await (const [i, chunk] of (async function* () {
    let i = 0; for await (const c of chunks(file, 4 * 1024 * 1024, (done, total) =>
      console.log(`${(done / total * 100).toFixed(0)}%`))) yield [i++, c];
  })()) {
    await fetch(`/upload?part=${i}`, { method: 'POST', body: chunk });
    if (i >= 2) break; // 演示提前终止
  }
}
```

**评分点**：
- Blob.slice 的惰性语义（引用范围，不立即复制）——核心认知
- async 生成器 + for-await 消费闭环
- 进度回调在产出后触发（offset 已推进）
- break 后不再 slice（生成器 return）
