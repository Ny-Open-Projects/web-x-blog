## CSS-298：文本溢出的自定义省略号方案

**题目**：实现多行截断且省略号可自定义（如「…展开全文」可点击、样式任意）：CSS line-clamp 只能给固定 …，要求右下角对齐且带交互。

**答**：
```css
/* 思路：line-clamp 截断 + 绝对定位的遮盖层放自定义按钮 */
.truncate {
  position: relative;
  max-height: 3em;                 /* 行高 1em × 3 行 */
  overflow: hidden;
  line-height: 1;
}
.truncate.expanded { max-height: none; }
.more {
  position: absolute;
  right: 0; bottom: 0;
  padding-left: 24px;              /* 遮住被截文字 */
  background: linear-gradient(to right, transparent, #fff 30%); /* 渐隐过渡 */
  color: #4285f4;
  cursor: pointer;
}
```
```html
<div class="truncate" id="t">
  很长的正文……
  <button class="more" onclick="t.classList.add('expanded'); this.remove()">…展开</button>
</div>
```
```javascript
// 检测是否真的溢出（短文不显示按钮）
const isOverflow = t.scrollHeight > t.clientHeight;
!isOverflow && t.querySelector('.more')?.remove();
```

**评分点**：
- 遮盖层方案：绝对定位 + 渐隐背景遮住截断处，实现任意样式省略号
- max-height = 行高×行数（不用 line-clamp 时也可行）
- 溢出检测（scrollHeight 比较）——短文不显示按钮的细节
- 展开态切换与按钮移除
