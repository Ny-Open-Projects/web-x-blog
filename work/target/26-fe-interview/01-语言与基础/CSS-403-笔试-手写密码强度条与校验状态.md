## CSS-403：笔试：手写密码强度条与校验状态

**答**：实现注册表单反馈：① 密码强度条 4 格，强度由 data-strength 驱动点亮格数与颜色（红/橙/黄/绿）；② 校验清单（长度/数字/大小写/符号）逐项打勾（用 :has/user-invalid 现代方案 + JS 兜底）；③ 输入时图标抖动提示错误（一次性动画，shake class 移除后重触发）；④ 提交按钮按表单有效性禁用（form:has(input:user-invalid)）。写出核心实现。

```html
<form>
  <input type="password" id="pwd" minlength="8" required pattern="(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{8,}">
  <div class="meter" data-strength="0"><i></i><i></i><i></i><i></i></div>
  <ul class="rules">
    <li data-rule="len">8位以上</li><li data-rule="num">含数字</li>
    <li data-rule="case">大小写</li><li data-rule="sym">特殊字符</li>
  </ul>
  <button class="submit">注册</button>
</form>
```

```css
.meter { display: flex; gap: 4px; margin-top: 8px; }
.meter i {
  flex: 1; height: 4px; border-radius: 2px;
  background: #eee; transition: background .2s;
}
/* 强度驱动点亮: data-strength 属性 */
.meter[data-strength='1'] i:nth-child(-n+1) { background: #f5222d; }
.meter[data-strength='2'] i:nth-child(-n+2) { background: #fa8c16; }
.meter[data-strength='3'] i:nth-child(-n+3) { background: #fadb14; }
.meter[data-strength='4'] i { background: #52c41a; }

/* 校验清单打勾: 现代 user-valid 方案 */
.rules li::before { content: '○ '; color: #999; }
.rules li:has(+ *),
.rules li.ok::before { content: '✓ '; color: #52c41a; }

/* 错误抖动: 一次性动画 */
@keyframes shake {
  25% { translate: -4px 0; } 50% { translate: 4px 0; }
  75% { translate: -2px 0; }
}
.pwd-wrap.shake { animation: shake .3s; }

/* 提交按钮: 表单含非法项时禁用(纯CSS) */
form:has(input:user-invalid) .submit { opacity: .5; pointer-events: none; }
```

```javascript
pwd.addEventListener('input', () => {
  const v = pwd.value;
  const score = [v.length >= 8, /\d/.test(v), /[a-z]/.test(v) && /[A-Z]/.test(v), /[^\w]/.test(v)]
    .filter(Boolean).length;
  meter.dataset.strength = score;
  rules.forEach((li) => { /* 按规则置 .ok */ });
});
// shake 重触发: 先移除再强制 reflow 再添加
wrap.classList.remove('shake'); void wrap.offsetWidth; wrap.classList.add('shake');
```

**评分点**：
- data-strength 驱动 nth-child 点亮与色阶
- :has(user-invalid) 纯 CSS 联动按钮禁用
- shake 重触发需要 reflow 技巧（void offsetWidth）
- 规则清单逐项状态与强度分层
