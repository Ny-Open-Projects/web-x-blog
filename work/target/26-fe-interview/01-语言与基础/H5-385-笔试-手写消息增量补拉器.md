## H5-385：笔试：手写消息增量补拉器

**答**：实现 `MsgSync`：① 本地维护游标 lastMsgId（IndexedDB），启动时按游标增量拉取 `/api/msg/missed?after=`；② 服务端返回按 id 升序，写入本地存储并更新游标（事务内原子）；③ 拉取上限分页（每页 100，循环拉到 done）；④ 重复消息防御：按 msgId 去重（本地已有跳过）；⑤ 并发保护：sync 进行中再次触发直接复用进行中的 promise。写出核心实现。

```javascript
class MsgSync {
  constructor(store, render) { this.store = store; this.render = render; this.syncing = null; }
  async sync() {
    if (this.syncing) return this.syncing;           // 并发复用
    this.syncing = (async () => {
      let cursor = await this.store.getMeta('lastMsgId') || 0;
      while (true) {
        const { msgs, done } = await api.get(`/api/msg/missed?after=${cursor}&limit=100`);
        const fresh = [];
        for (const m of msgs) {                       // 升序处理, 事务内原子
          if (await this.store.hasMsg(m.id)) continue; // 去重
          await this.store.putMsg(m);
          fresh.push(m);
        }
        if (fresh.length) {
          cursor = fresh[fresh.length - 1].id;
          await this.store.setMeta('lastMsgId', cursor); // 原子更新游标
          fresh.forEach(this.render);
        } else break;
        if (done) break;
      }
      this.syncing = null;
    })();
    return this.syncing;
  }
}
```

**评分点**：
- 游标增量 + 分页循环拉全（done 判定）
- 游标与消息写入同事务原子更新，防部分成功状态
- msgId 去重 + 升序处理保证顺序
- 并发触发复用同一 promise，防重复拉取
