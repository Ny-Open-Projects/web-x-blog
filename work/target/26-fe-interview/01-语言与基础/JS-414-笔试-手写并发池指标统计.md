## JS-414：笔试：手写并发池指标统计器

**答**：在并发池基础上实现指标统计：① `Pool`（并发上限）暴露实时 stats：active/pending/completed/failed；② 每任务记录耗时，暴露 `latencies()` 返回 P50/P95/max；③ 并发峰值记录（maxActive）；④ reset() 清统计不清任务；⑤ stats 对象是快照（冻结副本，外部修改不影响内部）。写出实现。

```javascript
class Pool {
  #active = 0; #pending = []; #lat = []; #maxActive = 0;
  #completed = 0; #failed = 0;
  constructor(limit) { this.limit = limit; }
  get stats() {                                              // 快照
    return Object.freeze({
      active: this.#active, pending: this.#pending.length,
      completed: this.#completed, failed: this.#failed,
      maxActive: this.#maxActive,
    });
  }
  latencies() {
    const s = [...this.#lat].sort((a, b) => a - b);
    const q = p => s[Math.min(s.length - 1, Math.floor(p * (s.length - 1)))];
    return { p50: q(.5), p95: q(.95), max: s[s.length - 1] ?? 0, n: s.length };
  }
  run(fn) {
    return new Promise((resolve, reject) => {
      this.#pending.push({ fn, resolve, reject });
      this.#drain();
    });
  }
  #drain() {
    while (this.#active < this.limit && this.#pending.length) {
      const { fn, resolve, reject } = this.#pending.shift();
      this.#active++;
      this.#maxActive = Math.max(this.#maxActive, this.#active);
      const t0 = performance.now();
      fn().then(v => { this.#completed++; resolve(v); }, e => { this.#failed++; reject(e); })
        .finally(() => {
          this.#lat.push(performance.now() - t0);
          this.#active--;
          this.#drain();
        });
    }
  }
  reset() { this.#lat = []; this.#maxActive = this.#active; this.#completed = this.#failed = 0; }
}
```

**评分点**：
- stats 返回冻结快照（防外部篡改内部计数）
- 延迟分位数（排序 + 索引）与 max
- maxActive 峰值记录（reset 时以当前 active 为基线）
- finally 中统一收尾（成功失败都计时）
