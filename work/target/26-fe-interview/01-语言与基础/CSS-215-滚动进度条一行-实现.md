## CSS-215：滚动进度条一行实现

**题目**：纯 CSS 实现顶部阅读进度条：宽度随整页滚动进度增长，不写 JS。

**答**：
```css
.progress {
  position: fixed;
  top: 0; left: 0;
  width: 100%;
  height: 3px;
  background: #4285f4;
  transform-origin: 0 50%;      /* 关键：从左端缩放 */
  transform: scaleX(0);
  animation: progress linear both;
  animation-timeline: scroll(root block); /* 整页滚动作为时间轴 */
  will-change: transform;
}
@keyframes progress { to { transform: scaleX(1); } }

/* 兼容降级：不支持时隐藏（避免常驻 0 宽条） */
@supports not (animation-timeline: scroll()) {
  .progress { display: none; }
}
```
```html
<div class="progress"></div>
```

**评分点**：
- transform-origin: 0 50% + scaleX 而非改 width（不触发布局，走合成）
- animation-timeline: scroll(root block) 的完整参数
- both 填充模式保证滚动前为 0、超后保持 1
- @supports 降级思路
