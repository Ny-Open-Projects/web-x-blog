## WEB-527：监控告警阈值怎么定，避免狼来了

**答**：
- 狼来了的本质：阈值拍脑袋定绝对值（如错误率>1%），各页面基线差异大，噪声常驻
- 基线对比法：按「同时段上周基线 + 同环比波动」做动态阈值，突增 X 倍或偏离置信区间才告警
- 分层告警：分位数（P95 TTFB）、绝对值（全站错误数为 0 基线下的任何突增）、可用性（拨测失败次数）各用各的策略
- 防疲劳机制：告警聚合（同因合并）、静默窗口（处理后 N 分钟不重复）、值班轮换与升级链（15 分钟未响应自动升级）
- 检验标准：好阈值系统的指标是「告警处置率 > 80%」，低于这个数说明该调阈值而不是加监控

```javascript
// 动态阈值示例：与上周同时段对比
const baseline = lastWeekSameHour.errorRate;
const now = currentErrorRate;
if (now > Math.max(baseline * 3, baseline + 0.5)) alert();
```
