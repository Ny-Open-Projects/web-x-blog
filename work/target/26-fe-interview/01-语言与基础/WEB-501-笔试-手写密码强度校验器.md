## WEB-501：笔试：手写密码强度校验器

**题目**：实现 `checkPassword(pwd)`：至少 8 位；必须含大小写字母、数字、特殊字符中至少三类；连续相同字符不超过 2 个；不得包含用户名子串；返回 `{ ok, reasons[] }`。

**答**：
```javascript
function checkPassword(pwd, username = '') {
  const reasons = [];
  if (pwd.length < 8) reasons.push('长度不足 8 位');
  if (pwd.length > 128) reasons.push('长度超限');

  const kinds = [/[a-z]/, /[A-Z]/, /\d/, /[^A-Za-z0-9]/].filter(r => r.test(pwd)).length;
  if (kinds < 3) reasons.push('需包含大小写字母/数字/特殊字符中的三类');

  if (/(.)\1{2,}/.test(pwd)) reasons.push('不能有连续 3 个相同字符');
  if (username && pwd.toLowerCase().includes(username.toLowerCase()))
    reasons.push('不能包含用户名');

  // 常见弱密码黑名单
  const WEAK = ['password', '12345678', 'qwertyui', '11111111'];
  if (WEAK.some(w => pwd.toLowerCase().includes(w))) reasons.push('过于常见');

  return { ok: reasons.length === 0, reasons };
}
checkPassword('Abc123!@#', 'tom'); // { ok: true, reasons: [] }
```

**评分点**：
- 字符类别用四个正则计数，不是长 if-else 罗列
- 连续相同字符 `(.)\1{2,}` 的反向引用用法
- 用户名子串比较要统一大小写
- 黑名单兜底 + reasons 数组让 UI 可逐条展示（产品思维）
