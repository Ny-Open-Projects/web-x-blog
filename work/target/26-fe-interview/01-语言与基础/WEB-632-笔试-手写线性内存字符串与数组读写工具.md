## WEB-632：笔试：手写线性内存字符串与数组读写工具

**答**：实现 `LinearMem` 工具类（包装 wasm exports）：① `writeStr(str)`：TextEncoder 编码写入线性内存，返回 `{ ptr, len }`，内存来自 wasm 导出的 alloc，不足时先调用 wasm 侧 grow（约定 `ensure(bytes)` 导出）并重建视图；② `readStr(ptr, len)`：从内存 UTF-8 解码；③ `writeBytes(u8)` / `readBytes(ptr, len)`；④ 视图失效防御：每次 grow 后重建缓存视图；⑤ free(ptr) 包装防重复释放（记 released 集合）。写出核心实现。

```javascript
class LinearMem {
  constructor(exports) {
    this.exports = exports;
    this.released = new Set();
    this._view = new Uint8Array(exports.memory.buffer);
  }
  _ensure(bytes) {
    if (this.exports.memory.buffer.byteLength < bytes) {
      this.exports.ensure(bytes);              // wasm 侧 grow
      this._view = new Uint8Array(this.exports.memory.buffer); // 重建视图
    }
  }
  writeStr(str) {
    const bytes = new TextEncoder().encode(str); // 字节长度而非字符数
    this._ensure(bytes.length);
    const ptr = this.exports.alloc(bytes.length);
    this._view.set(bytes, ptr);
    return { ptr, len: bytes.length };
  }
  readStr(ptr, len) { return new TextDecoder().decode(this._view.subarray(ptr, ptr + len)); }
  writeBytes(u8) {
    this._ensure(u8.length);
    const ptr = this.exports.alloc(u8.length);
    this._view.set(u8, ptr);
    return { ptr, len: u8.length };
  }
  readBytes(ptr, len) { return this._view.subarray(ptr, ptr + len); }
  free(ptr) {
    if (this.released.has(ptr)) return;        // 防重复 free
    this.released.add(ptr);
    this.exports.free(ptr);
  }
}
```

**评分点**：
- 字符串按字节长度处理（TextEncoder），不是 str.length
- grow 后重建 TypedArray 视图的核心坑点
- alloc/free 配对且防双重释放
- subarray 视图零拷贝读取的用法正确
