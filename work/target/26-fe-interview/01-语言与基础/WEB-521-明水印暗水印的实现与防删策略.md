## WEB-521：明水印/暗水印的实现与防删策略

**答**：
- 明水印：canvas 平铺背景（带员工工号/时间），防「顺手传播」；关键参数是密度、透明度、抗遮挡（多重交错布局）
- 暗水印：LSB 像素隐写（导出图片场景）或零宽字符（文本场景），肉眼不可见，泄漏后可溯源到人
- 防删三板斧：MutationObserver 监听移除并重建、多层 DOM 交错（删一层另一层还在）、shadow DOM 提高定位难度
- 边界认知：前端水印防君子不防小人，敏感文档要配合服务端渲染水印、下载走带水印的文件流
- 面试加分：能提「截图场景用 CSS 的 background-blend 或 canvas 导出水印，而非 DOM 叠层」

```javascript
function tiledWatermark(text) {
  const c = document.createElement('canvas');
  c.width = 240; c.height = 160;
  const ctx = c.getContext('2d');
  ctx.globalAlpha = 0.06;
  ctx.font = '16px sans-serif';
  ctx.fillText(text, 24, 80);
  const el = document.createElement('style');
  el.textContent = `.wm{position:fixed;inset:0;pointer-events:none;z-index:9999;
    background:url(${c.toDataURL()}) repeat;}`;
  document.head.appendChild(el);
  document.body.classList.add('wm');
  document.body.style.cssText = ''; // 触发挂载
}
```
