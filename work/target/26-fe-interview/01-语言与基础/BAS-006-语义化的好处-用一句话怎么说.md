## BAS-006：语义化的好处，用一句话怎么说？
**答**：
- 一句话版本：让"结构即含义"——对机器（搜索引擎、读屏器）可理解，对人（开发者）可维护。
- 展开点：SEO 权重更高、无障碍支持更好、去掉 CSS 后结构依然清晰、团队协作成本更低。
- 注意别只背"利于 SEO"，能说出可访问性与可维护性才是加分项。

```html
<header>站点标题</header>
<nav><a href="/">首页</a> <a href="/list">列表</a></nav>
<main>
  <article>
    <h1>文章标题</h1>
    <p>正文内容，读屏软件与爬虫都能理解主次关系</p>
  </article>
  <aside>相关推荐</aside>
</main>
<footer>版权信息</footer>
```
