## WEB-491：笔试：手写批量埋点上报器

**题目**：实现 `track(event)`：事件入队；队满 20 条或间隔 5s 批量上报；用 sendBeacon 优先、失败降级 fetch；页面关闭时 flush 剩余事件。

**答**：
```javascript
function createTracker() {
  const queue = [];
  const MAX = 20;
  let timer;

  function flush() {
    if (!queue.length) return;
    const batch = queue.splice(0);
    const payload = JSON.stringify(batch);
    if (!navigator.sendBeacon('/api/track', payload)) {
      fetch('/api/track', { method: 'POST', body: payload, keepalive: true });
    }
  }

  function track(event) {
    queue.push({ ...event, t: Date.now() });
    if (queue.length >= MAX) flush();
    else if (!timer) timer = setTimeout(flush, 5000);
  }

  addEventListener('pagehide', () => { clearTimeout(timer); flush(); });
  return { track, flush };
}
const tracker = createTracker();
tracker.track({ type: 'click', target: 'buy-btn' });
```

**评分点**：
- 双触发条件：数量阈值 + 时间阈值，只看一个不算完整
- sendBeacon 优先 + keepalive fetch 降级（sendBeacon 返回 false 表示队列满）
- pagehide（而非 unload）里 flush——unload 不可靠且影响 bfcache
- 批量结构带时间戳，服务端可还原时序
