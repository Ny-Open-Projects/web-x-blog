## WEB-307：本地开发自签名证书总报错，怎么优雅解决？
**答**：
- 根因：自签证书不在系统信任链里。手工 openssl 签发还要逐浏览器导入，维护成本高。
- 推荐 mkcert：一键生成本地 CA 并自动安装进系统/浏览器信任库，签出 localhost/*.dev.test 等域名证书，团队可信零配置。
- 容器/CI 场景：把 mkcert 生成的 rootCA 挂进镜像并更新 CA 信任目录；真机调试则要手动安装 CA 或用证书透明方案绕过。

```javascript
# mkcert 实操
# mkcert -install                        # 安装本地 CA
# mkcert localhost 127.0.0.1 myapp.test  # 签发证书
# 输出: localhost+2.pem / localhost+2-key.pem
const use = { cert: 'localhost+2.pem', key: 'localhost+2-key.pem', https: true };
console.log('npm i -D mkcert 或 brew install mkcert；vite: server.https 配置这对文件');
```
