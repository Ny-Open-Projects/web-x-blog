## JS-365：离线任务队列：持久化与重放

**答**：
- 队列生命周期：操作产生 → 入队（IndexedDB 持久化，带幂等键/依赖键）→ online/SW sync 触发重放 → 按依赖分组并行、组内串行
- 重放安全三件套：幂等键（防重复）、依赖键（保顺序）、冲突处理（409 时人工/自动合并）——离线队列的复杂性全在这三个约束
- 失败分级：网络错误暂停（下次再放）、业务冲突跳过组、数据过期（版本校验失败）提示用户重新操作——「不能重放的操作」（如一次性验证码）标记不可入队
- SW Background Sync：浏览器在恢复网络时自动唤醒 SW 执行重放——比 online 事件可靠（页面死了也能重放），Safari 支持差需降级
- 队列治理：上限（>500 条提示用户联网后手动同步）、过期（72h 前的失败操作丢弃）、统计上报（离线操作成功率）

```javascript
class OfflineQueue {
  constructor(store) { this.store = store; }
  async enqueue(op) {
    if (op.nonReplayable) throw new Error('不可离线的操作');
    await this.store.append('ops', { ...op, id: crypto.randomUUID(), ts: Date.now() });
    if ('serviceWorker' in navigator && 'sync' in registration)
      await registration.sync.register('replay-ops');       // 请求后台同步
    else this._tryReplay();
  }
  async replay() {
    const ops = await this.store.all('ops');
    const groups = new Map();
    for (const op of ops) {
      (groups.get(op.depKey ?? op.id) ?? groups.set(op.depKey ?? op.id, []).get(op.depKey ?? op.id)).push(op);
    }
    await Promise.all([...groups.values()].map(g => g.reduce(
      (chain, op) => chain.then(() => this._exec(op)), Promise.resolve())));
  }
  async _exec(op) {
    try {
      const res = await api.post('/sync', op, { headers: { 'Idempotency-Key': op.id } });
      if (res.status !== 409) await this.store.del('ops', op.id);
    } catch { /* 网络失败: 留在队列, 下次重放 */ }
  }
}
addEventListener('online', () => queue.replay());
```
