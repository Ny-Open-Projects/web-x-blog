## H5-380：笔试：手写移动端秒开指标采集器

**答**：实现 `PerfCollector`：① 采集 FCP/LCP/INP/CLS（web-vitals 语义自实现核心部分：LCP 用 PerformanceObserver largest-contentful-paint，INP 用 event timing 的最大交互延迟近似）；② 点击时间起点从 URL 参数 t0 对齐 App 侧打点，算 clickToFCP；③ 指标带上网络类型/机型/离线包命中标记，pagehide 时批量上报；④ 无相应 API 的浏览器逐项降级（无 LCP observer 用 FCP 代替并标记 degraded）；⑤ 采样率 20% 稳定采样。写出核心实现。

```javascript
class PerfCollector {
  constructor(rate = 0.2) {
    this.on = ((+sessionStorage.__pv || (sessionStorage.__pv = Math.random())), sessionStorage.__pv < rate);
    this.metrics = {};
    if (!this.on) return;
    try {
      new PerformanceObserver((l) => {
        const last = l.getEntries().pop();
        if (last) this.metrics.lcp = last.startTime;
      }).observe({ type: 'largest-contentful-paint', buffered: true });
    } catch { this.degraded = true; }
    try {
      new PerformanceObserver((l) => {
        for (const e of l.getEntries())
          if (e.interactionId) this.metrics.inp = Math.max(this.metrics.inp || 0, e.duration);
      }).observe({ type: 'event', buffered: true, durationThreshold: 16 });
    } catch {}
    const fcp = performance.getEntriesByName?.('first-contentful-paint');
    addEventListener('pagehide', () => this._report());
  }
  _report() {
    const nav = performance.getEntriesByType('navigation')[0];
    const t0 = Number(new URLSearchParams(location.search).get('t0') || 0);
    navigator.sendBeacon('/api/mon/second-open', JSON.stringify({
      ...this.metrics,
      degraded: !!this.degraded,
      fcp: nav?.domContentLoadedEventStart,
      clickToFCP: t0 ? nav?.responseStart + performance.now() - t0 : null,
      net: navigator.connection?.effectiveType,
      offline: window.__OFFLINE_HIT__,
    }));
  }
}
```

**评分点**：
- PerformanceObserver 各指标正确注册（buffered 取历史）
- API 缺失降级标记 degraded 而非静默缺数
- t0 对齐 App 侧点击起点，全链路口径
- 稳定采样与 pagehide 上报时机
