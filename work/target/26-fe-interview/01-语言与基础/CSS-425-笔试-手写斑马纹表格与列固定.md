## CSS-425：笔试：手写数据表格

**答**：实现数据表：① 斑马纹（偶数行浅色）+ 行 hover 高亮；② 表头吸顶 + 首列固定（sticky 双向，注意 z-index 层级）；③ 首列固定处的列阴影（区分滚动内容）；④ 单元格内容溢出省略 + title 提示；⑤ 空数据状态占位行。写出核心实现。

```html
<div class="tw">
  <table class="dt">
    <colgroup><col style="width:160px"><col><col><col></colgroup>
    <thead><tr><th>名称</th><th>状态</th><th>金额</th><th>时间</th></tr></thead>
    <tbody>
      <tr><td class="sticky-col">订单 A</td><td>已完成</td><td>¥128.00</td><td>2026-11-21</td></tr>
      <!-- 空态: <tr class="empty"><td colspan="4">暂无数据</td></tr> -->
    </tbody>
  </table>
</div>
```

```css
.tw {
  max-height: 60dvh; overflow: auto;
  border: 1px solid #eee; border-radius: 8px;
}
.dt { border-collapse: separate; border-spacing: 0; table-layout: fixed; width: 100%; }
.dt th, .dt td {
  padding: 10px 12px; text-align: left;
  white-space: nowrap; overflow: hidden; text-overflow: ellipsis;
}
/* 斑马纹 + hover */
.dt tbody tr:nth-child(even) { background: #fafafa; }
.dt tbody tr:hover { background: color-mix(in oklab, var(--primary) 6%, white); }
/* 表头吸顶 */
.dt th {
  position: sticky; top: 0;
  background: #f5f5f5; z-index: 2;
}
/* 首列固定: 左右双 sticky */
.dt th:first-child, .dt td:first-child {
  position: sticky; left: 0;
  background: inherit;             /* 继承行背景(斑马/hover 联动) */
}
.dt th:first-child { z-index: 3; }  /* 表头首列: 最高层级 */
.dt td:first-child { z-index: 1; }
/* 固定列右边界阴影(区分滚动区) */
.dt td:first-child::after {
  content: ''; position: absolute; top: 0; right: 0; bottom: 0; width: 8px;
  background: linear-gradient(to right, #0000000d, transparent);
  pointer-events: none;
}
.dt .empty td { text-align: center; color: #999; padding: 32px; }
```

**评分点**：
- 双向 sticky（th top + 首列 left）+ z-index 层级（3>2>1）
- 首列 background: inherit 让斑马/hover 穿透固定列（关键细节）
- border-collapse: separate 是 sticky td 生效前提
- 溢出省略 + 固定列边界阴影提示
