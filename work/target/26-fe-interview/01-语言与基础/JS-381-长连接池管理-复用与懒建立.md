## JS-381：长连接池管理：复用与懒建立

**答**：
- 连接分类与生命周期：HTTP（浏览器自动池化，前端只管合理并发）、WebSocket（业务级单例）、数据库/网关代理（服务端事）——前端「连接池」实际是 WS/SSE/WebTransport 单例管理
- 懒建立 vs 预建立：懒建立（首次用到才连，省资源）适合低频功能；预建立（页面加载即连）适合 IM 这类核心实时功能——按业务权重决策，配置可切
- 单例守护：全局唯一连接管理器（getInstance 语义）+ 引用计数（多个组件共用一条连接，计数归零才断）——防止组件各自建连
- 断线重连的状态机：connecting/online/reconnecting/offline 五态 + 指数退避 + 网络恢复触发（online 事件）——重连后要补拉增量（序号游标）
- 多连接场景：一个页面同时存在 IM 连接 + 通知连接时，统一「连接管理器」注册表（按 channel key），共享重连策略与网络状态

```javascript
class ConnManager {
  #conns = new Map();       // channel → { ws, refs, state }
  acquire(channel) {
    const c = this.#conns.get(channel) ?? this.#create(channel);
    c.refs++;
    return c;
  }
  release(channel) {
    const c = this.#conns.get(channel);
    if (c && --c.refs <= 0) { c.ws.close(); this.#conns.delete(channel); }  // 引用归零才断
  }
  #create(channel) {
    const ws = new WebSocket(`/ws/${channel}`);
    const c = { ws, refs: 0, state: 'connecting' };
    ws.onopen = () => c.state = 'online';
    ws.onclose = () => { c.state = 'offline'; if (c.refs > 0) this.#reconnect(channel); };
    this.#conns.set(channel, c);
    return c;
  }
  #reconnect(channel) { /* 指数退避重连 + 补拉增量 */ }
}
```
