## H5-319：笔试：手写图片懒加载

**题目**：实现 `lazyImages(root)`：对 `[data-src]` 图片用 IntersectionObserver 懒加载；进入视口前 200px 预加载；加载完成后停止观察并移除占位样式；加载失败显示占位图；不支持 IO 的环境降级滚动监听。

**答**：
```javascript
function lazyImages(root = document) {
  const imgs = [...root.querySelectorAll('img[data-src]')];

  const load = (img) => {
    img.src = img.dataset.src;
    img.removeAttribute('data-src');
    img.onerror = () => { img.src = '/static/placeholder.png'; img.onerror = null; };
    img.classList.remove('lazy-placeholder');
    io.unobserve(img);
  };

  const io = new IntersectionObserver((entries) => {
    entries.forEach(en => en.isIntersecting && load(en.target));
  }, { rootMargin: '200px 0px' }); // 提前 200px 预加载

  imgs.forEach(img => io.observe(img));

  // 降级：无 IO 的老环境用 scroll + getBoundingClientRect
  if (!('IntersectionObserver' in window)) {
    const check = () => imgs.filter(i => i.dataset.src).forEach(i => {
      const r = i.getBoundingClientRect();
      if (r.top < innerHeight + 200) load(i);
    });
    addEventListener('scroll', check, { passive: true });
    check();
  }
  return { disconnect: () => io.disconnect() };
}
```

**评分点**：
- rootMargin 预加载距离参数（用户感知不到加载）
- 加载后 unobserve（任务完成就移除，不浪费观察）
- data-src 在加载前不放 src（不浪费请求）
- 失败占位 + 降级路径（无 IO 环境）
