## CSS-421：笔试：手写商品图放大镜

**答**：实现电商放大镜：① hover 出现半透明遮罩块跟随鼠标；② 右侧大图容器显示对应区域（background-position 按 smallRatio 映射大图坐标）；③ 遮罩尺寸与放大倍率联动（zoom 倍率决定遮罩占原图比例）；④ 边界钳制（鼠标移出图区隐藏）；⑤ 大图预加载。写出核心实现。

```html
<div class="zoom">
  <div class="small"><img src="p.jpg"><i class="lens" hidden></i></div>
  <div class="big" hidden></div>
</div>
```

```css
.zoom { display: flex; gap: 16px; position: relative; }
.small { position: relative; width: 400px; cursor: crosshair; }
.small img { width: 100%; display: block; }
.lens {
  position: absolute; width: 200px; height: 200px;   /* zoom=2 → 遮罩=小图一半 */
  background: rgb(255 255 0 / .3);
  border: 1px solid var(--primary);
  pointer-events: none;
}
.big {
  width: 400px; height: 400px;
  background-image: url('p@2x.jpg');       /* 高清大图 */
  background-repeat: no-repeat;
  border: 1px solid #eee;
}
```

```javascript
const ZOOM = 2;
const smallEl = document.querySelector('.small');
const big = document.querySelector('.big');
function onMove(e) {
  const r = smallEl.getBoundingClientRect();
  const x = Math.min(Math.max(e.clientX - r.left, 0), r.width);   // 钳制
  const y = Math.min(Math.max(e.clientY - r.top, 0), r.height);
  lens.style.transform = `translate(${x - 100}px, ${y - 100}px)`;
  // 大图映射: 遮罩在小图的相对位置 × 大图尺寸 - 大图容器一半
  const bx = (x / r.width) * big.clientWidth * ZOOM - big.clientWidth / 2;
  const by = (y / r.height) * big.clientHeight * ZOOM - big.clientHeight / 2;
  big.style.backgroundSize = `${big.clientWidth * ZOOM}px ${big.clientHeight * ZOOM}px`;
  big.style.backgroundPosition = `${-bx}px ${-by}px`;
}
smallEl.addEventListener('mousemove', onMove);
smallEl.addEventListener('mouseenter', () => { lens.hidden = big.hidden = false; });
smallEl.addEventListener('mouseleave', () => { lens.hidden = big.hidden = true; });
// 预加载
const pre = new Image(); pre.src = 'p@2x.jpg';
```

**评分点**：
- 遮罩尺寸 = 小图/倍率 的联动关系（zoom 语义正确）
- background-position 映射公式（相对位置 × 大图 × 倍率 - 容器半宽）
- 边界钳制 + mouseleave 隐藏
- 大图预加载避免首次 hover 空白
