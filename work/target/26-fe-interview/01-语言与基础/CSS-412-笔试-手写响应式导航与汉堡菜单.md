## CSS-412：笔试：手写响应式导航

**答**：实现导航：① 桌面横向菜单，移动端汉堡按钮 + 侧滑抽屉；② 汉堡图标三条线动画变 X（纯 CSS 过渡）；③ 抽屉滑入 + 遮罩，打开时锁定滚动；④ 无 JS 方案（checkbox hack）与 JS 方案对比；⑤ 无障碍（aria-expanded + Esc 关闭）。写出核心实现。

```html
<header class="nav">
  <button class="burger" aria-expanded="false" aria-controls="drawer">
    <i></i><i></i><i></i>
  </button>
  <nav id="drawer" class="drawer">
    <a href="/">首页</a><a href="/about">关于</a>
  </nav>
  <div class="mask"></div>
</header>
```

```css
.burger { display: none; width: 44px; height: 44px; position: relative; }
.burger i {
  position: absolute; left: 10px; right: 10px; height: 2px;
  background: currentColor; transition: all .3s;
}
.burger i:nth-child(1) { top: 14px; }
.burger i:nth-child(2) { top: 21px; }
.burger i:nth-child(3) { top: 28px; }
.burger[aria-expanded='true'] i:nth-child(1) { top: 21px; transform: rotate(45deg); }
.burger[aria-expanded='true'] i:nth-child(2) { opacity: 0; }
.burger[aria-expanded='true'] i:nth-child(3) { top: 21px; transform: rotate(-45deg); }

.drawer {
  position: fixed; top: 0; bottom: 0; inset-inline-start: 0;
  width: min(280px, 80vw);
  transform: translateX(-100%);
  transition: transform .3s var(--ease-out-quart);
  background: #fff;
}
.nav.open .drawer { transform: none; }
.nav.open .mask {
  position: fixed; inset: 0; background: rgb(0 0 0 / .4);
  animation: fade .3s;
}

@media (min-width: 768px) {
  .burger, .mask { display: none; }
  .drawer { position: static; transform: none; display: flex; gap: 24px; }
}
@media (max-width: 767px) { .burger { display: block; } }
```

```javascript
burger.addEventListener('click', () => {
  const open = nav.classList.toggle('open');
  burger.setAttribute('aria-expanded', open);
  document.body.classList.toggle('modal-open', open);  // 滚动锁定
});
addEventListener('keydown', (e) => {
  if (e.key === 'Escape' && nav.classList.contains('open')) burger.click();
});
```

**评分点**：
- 汉堡→X 三线过渡（位移+旋转+透明度）
- 抽屉 translateX 滑入（transform 合成）
- aria-expanded 状态同步 + Esc 关闭
- 断点双形态（桌面静态/移动抽屉）响应式策略
