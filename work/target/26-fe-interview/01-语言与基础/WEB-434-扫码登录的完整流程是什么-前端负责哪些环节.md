## WEB-434：扫码登录的完整流程是什么，前端负责哪些环节

**答**：
- 流程：PC 前端拿二维码 ID（qrcode 场景ID）→ 轮询/长连接查状态 → 手机 App 扫码确认 → 状态变为已确认 → PC 换取登录态
- 状态机：待扫码 → 已扫码待确认 → 已确认 → 已过期；前端按状态渲染「扫码成功，请在手机确认」等提示
- 两种感知方式：短轮询（1~2s 一次，简单可靠）与 WebSocket/SSE（即时但要处理断线）；微信开放平台是长连接回调注入
- 二码一体的坑：二维码 ID 有时效（1~2 分钟），过期要静默刷新新码；刷新时要清掉旧轮询
- 安全点：二维码 ID 足够随机不可枚举；确认动作在手机侧完成二次认证，PC 端只是收结果

```javascript
async function pollQr(id, signal) {
  while (!signal.aborted) {
    const { status, token } = await fetch(`/api/qr/${id}/status`).then(r => r.json());
    if (status === 'confirmed') return loginWith(token);
    if (status === 'expired') return refreshQr(); // 静默换码重启轮询
    await new Promise(r => setTimeout(r, 1500));
  }
}
```
