## WEB-337：微信网页授权登录的流程是怎样的？
**答**：
- 跳转 open.weixin.qq.com/connect/oauth2/authorize（snsapi_base 静默 / snsapi_userinfo 需确认），回调带 code。
- 后端用 code + appsecret 调 /sns/oauth2/access_token 换 access_token 与 openid/unionid（此步必须服务端，secret 不能露）。
- 工程细节：code 一次一用 5 分钟有效；redirect_uri 域名要在公众号后台配置；同用户跨应用打通靠 unionid。

```javascript
// 前端只负责跳转与接 code，换 token 全在服务端
const authUrl = 'https://open.weixin.qq.com/connect/oauth2/authorize'
  + '?appid=APPID&redirect_uri=' + encodeURIComponent(cb)
  + '&response_type=code&scope=snsapi_userinfo#wechat_redirect';
// cb 页: location.search 里的 code POST 给自家后端 → 返回会话
console.log('code 一次性 5 分钟；scope 决定要不要用户点确认');
```
