## JS-292：笔试：定时器管理器

**题目**：实现 `TimerManager`：`setTimeout/setInterval` 语义的封装，返回 cancel 函数；`destroyAll()` 清空全部；同一回调的 interval 防重复注册；统计活跃数。

**答**：
```javascript
class TimerManager {
  #timers = new Set(); // id -> type
  #types = new Map();

  timeout(fn, ms, ...args) {
    const id = setTimeout(() => {
      this.#timers.delete(id);
      fn(...args); // 触发后自动出表（一次性）
    }, ms, ...args);
    this.#track(id, 'timeout');
    return () => this.cancel(id);
  }
  interval(fn, ms, key) {
    if (key && [...this.#types].some(([id, t]) => t.key === key)) return null; // 防重复
    const id = setInterval(fn, ms);
    this.#track(id, { type: 'interval', key });
    return () => this.cancel(id);
  }
  #track(id, meta) { this.#timers.add(id); this.#types.set(id, meta); }
  cancel(id) {
    (this.#types.get(id)?.type === 'interval' ? clearInterval : clearTimeout)(id);
    this.#timers.delete(id); this.#types.delete(id);
  }
  destroyAll() {
    [...this.#timers].forEach(id => this.cancel(id));
  }
  get active() { return this.#timers.size; }
}
// 组件卸载：tm.destroyAll()——定时器零泄漏
const tm = new TimerManager();
tm.interval(poll, 5000, 'poll-data'); // 二次同 key 注册返回 null
```

**评分点**：
- Set/Map 双结构管理 id 与元信息（类型+防重复 key）
- 一次性 timer 触发后自动移除（active 统计准确）
- interval 防重复注册的 key 机制
- 返回 cancel 闭包（调用方无需接触 id）
