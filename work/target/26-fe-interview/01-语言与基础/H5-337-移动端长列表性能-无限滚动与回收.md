## H5-337：移动端长列表性能：无限滚动、虚拟列表与 DOM 回收

**答**：
- 无限滚动天花板：DOM 累积导致内存与重排成本线性上涨，iOS 数千节点明显卡顿——超过一定量必须虚拟化
- 虚拟列表核心：只渲染可视区 ± 缓冲区，用 transform/绝对定位 + 总容器高度撑起滚动条；不定高场景用「预估高度 + 渲染后校准」二段式
- 移动端特有难题：惯性滚动速度快，IO/scroll 事件触发到渲染有延迟——加大缓冲区（上下各一屏）、滚动方向预判、快速滚动时显示占位骨架
- 图片高度未知问题：列表项图片先占位（宽高比容器）+ 异步加载后校准偏移，避免跳动；或图片定死尺寸（产品约束解决技术问题）
- 刷新保活：滚动位置恢复（详情页返回列表 scrollTo 缓存位置 + 数据不重拉，用内存缓存或 keep-alive）

```javascript
class VList {
  constructor(container, itemH, render) {
    this.c = container; this.h = itemH; this.render = render;
    this.data = [];
    this.spacer = document.createElement('div');
    this.viewport = document.createElement('div');
    this.viewport.style.position = 'relative';
    this.c.append(this.spacer, this.viewport);
    this.c.addEventListener('scroll', () => this._update(), { passive: true });
  }
  setData(d) { this.data = d; this.spacer.style.height = d.length * this.h + 'px'; this._update(); }
  _update() {
    const top = this.c.scrollTop;
    const vh = this.c.clientHeight;
    const buf = vh; // 一屏缓冲
    const start = Math.max(0, Math.floor((top - buf) / this.h));
    const end = Math.min(this.data.length, Math.ceil((top + vh + buf) / this.h));
    this.viewport.style.transform = `translateY(${start * this.h}px)`;
    this.viewport.innerHTML = '';
    for (let i = start; i < end; i++) this.render(this.data[i], i, this.viewport);
  }
}
```
