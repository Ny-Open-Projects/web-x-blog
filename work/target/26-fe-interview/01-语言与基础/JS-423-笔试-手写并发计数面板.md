## JS-423：笔试：手写并发计数面板

**答**：实现 `RequestTracker`：① 包装 fetch 记录生命周期：start/success/fail/cancel 四类事件计数；② 实时面板数据：activeCount（在飞请求）、最近 1s QPS（滑动窗口）、错误率（最近 100 次）；③ 按域名分组统计（同域名慢是常见归因）；④ 提供 snapshot() 冻结快照供上报；⑤ cancel 请求（AbortError）不计入错误率但单独计数。写出实现。

```javascript
class RequestTracker {
  #active = 0; #events = []; #recent = [];   #byHost = new Map();
  wrap(fetch) {
    return async (input, init = {}) => {
      const host = new URL(input, location.href).host;
      const t0 = performance.now();
      this.#active++;
      this.#events.push({ type: 'start', host, t: t0 });
      try {
        const res = await fetch(input, init);
        const dur = performance.now() - t0;
        const type = res.ok ? 'success' : 'fail';
        this.#record(type, host, dur);
        return res;
      } catch (e) {
        const type = e.name === 'AbortError' ? 'cancel' : 'fail';
        this.#record(type, host, performance.now() - t0, e);
        throw e;
      } finally { this.#active--; }
    };
  }
  #record(type, host, dur, error) {
    this.#events.push({ type, host, dur, t: performance.now() });
    this.#events = this.#events.filter(e => performance.now() - e.t < 1000); // 1s 窗口
    const h = this.#byHost.get(host) ?? this.#byHost.set(host, { n: 0, fail: 0, cancel: 0, totalDur: 0 }).get(host);
    h.n++; h[type === 'fail' ? 'fail' : type === 'cancel' ? 'cancel' : 'ok'] = (h[type] || 0);
    h.totalDur += dur;
    this.#recent.push({ type, dur });
    if (this.#recent.length > 100) this.#recent.shift();
  }
  snapshot() {
    const recent = this.#recent.filter(e => e.type !== 'cancel');
    const errRate = recent.length ? recent.filter(e => e.type === 'fail').length / recent.length : 0;
    return Object.freeze({
      activeCount: this.#active,
      qps: this.#events.filter(e => e.type === 'start').length,
      errorRate: +errRate.toFixed(3),
      cancelCount: this.#recent.filter(e => e.type === 'cancel').length,
      byHost: Object.freeze([...this.#byHost].map(([host, s]) => ({ host, ...s, avg: +(s.totalDur / s.n).toFixed(1) }))),
    });
  }
}
```

**评分点**：
- 四类事件区分（cancel 不入错误率但单独计数）
- 1s 滑动窗口 QPS 与最近 100 次错误率两种口径
- 按域名分组统计（归因维度）
- snapshot 冻结快照防上报后被修改
