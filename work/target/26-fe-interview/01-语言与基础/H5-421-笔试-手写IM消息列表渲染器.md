## H5-421：笔试：手写 IM 消息列表渲染器

**答**：实现 IM 消息列表渲染：① 消息条目不定高（文本/图片），用「测量缓存 + 预估」策略：渲染过的条目高度缓存，未渲染按类型预估（文本 60/图片 200/系统 32）；② 新消息到达自动滚到底（仅当用户已在底部附近 <100px，否则显示「新消息 N 条」浮标）；③ 时间分组头（间隔 >5min 插入时间条，计为一条虚拟项）；④ 倒序渲染（最新在底部）：虚拟列表从底部锚定，滚动向上加载历史；⑤ 提供 prependHistory(messages) 不打乱当前阅读位置。写出核心实现。

```javascript
class MsgList {
  constructor(container, estH = { text: 60, image: 200, system: 32 }) {
    this.c = container; this.est = estH;
    this.heights = new Map(); this.msgs = []; this.items = []; // items 含分组头
    this.c.addEventListener('scroll', () => this._onScroll(), { passive: true });
  }
  setMessages(msgs) {
    this.msgs = msgs;
    this.items = [];
    let lastT = 0;
    for (const m of msgs) {
      if (m.ts - lastT > 5 * 60_000) this.items.push({ type: 'time', m, h: this.est.system });
      this.items.push({ type: m.kind, m, h: this.est[m.kind] });
      lastT = m.ts;
    }
    this._render(true);
  }
  _h(i) { return this.heights.get(i) ?? this.items[i].h; }
  _total() { return this.items.reduce((s, _, i) => s + this._h(i), 0); }
  _render(keepBottom) {
    const nearBottom = this.c.scrollHeight - this.c.scrollTop - this.c.clientHeight < 100;
    this.c.style.height = this._total() + 'px';
    // 渲染可视区 ± 缓冲(实现同虚拟列表), 此处省略窗口计算
    this.viewport.innerHTML = itemsToHTML(this.items, this.heights, this.c);
    if (keepBottom && nearBottom) this.c.scrollTop = this.c.scrollHeight;
  }
  append(m) { this.setMessages([...this.msgs, m]); }
  prependHistory(msgs) {
    const before = this.c.scrollHeight - this.c.scrollTop;   // 保持阅读位置
    this.setMessages([...msgs, ...this.msgs]);
    requestAnimationFrame(() => {
      this.c.scrollTop = this.c.scrollHeight - before;
    });
  }
  _onScroll() {
    if (this.c.scrollTop < 50 && !this.loading) this.loadMore?.();  // 顶部加载历史
    const nearBottom = this.c.scrollHeight - this.c.scrollTop - this.c.clientHeight < 100;
    this.unreadBubble.style.display = nearBottom ? 'none' : 'block';
  }
}
```

**评分点**：
- 时间分组项与消息项统一进虚拟 items，高度缓存 + 预估
- 底部锚定策略：仅用户在底部时自动跟随，否则未读浮标
- prependHistory 的阅读位置保持（scrollHeight 差值补偿）
- 顶部触发历史加载防抖
