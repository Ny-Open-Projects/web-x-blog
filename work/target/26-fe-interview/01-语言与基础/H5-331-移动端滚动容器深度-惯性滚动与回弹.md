## H5-331：移动端滚动容器深度：惯性滚动、回弹与滚动性能

**答**：
- 原生惯性：body 滚动自带惯性；内层容器要 `-webkit-overflow-scrolling: touch`（iOS 惯性）或 overflow: auto + 现代 iOS 已默认；Android 各内核行为不一
- 回弹与边界：iOS 原生 bounce 可用 overscroll-behavior 控制（contain/none）；自定义下拉刷新在 iOS 上要处理 rubber-band 越界（scrollTop < 0 的判定）
- 滚动性能三原则：滚动容器内避免大 shadow/filter（重绘贵）、列表项避免动态改高度（layout 抖动）、滚动监听 passive: true 且用 rAF 合并处理
- 固定吸顶方案：position: sticky 优于 scroll 监听 + transform（不触发额外计算）；老内核 sticky 失效用 transform 方案兜底
- 软键盘顶起滚动：iOS 键盘弹起后 window 大小与滚动位置错乱，输入框 scrollIntoView + focus 延时处理是标准解法

```css
.scroller {
  overflow-y: auto;
  overscroll-behavior-y: contain;      /* 防滚动链到 body */
  -webkit-overflow-scrolling: touch;   /* 老 iOS 惯性 */
}
.header { position: sticky; top: 0; }  /* 吸顶首选 */
```

```javascript
// 下拉刷新: 越界判定 + passive 手势
scroller.addEventListener('touchmove', (e) => {
  if (scroller.scrollTop <= 0 && startY < currentY && pullDistance > 0) e.preventDefault();
}, { passive: false }); // 只在需要阻止默认时声明 non-passive
```
