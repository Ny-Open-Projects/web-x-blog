## JS-304：笔试：双向通信生成器（问答流程）

**题目**：实现问卷驱动器：生成器按序 yield 出问题；驱动器收集用户答案并 next(答案) 传回；支持 `next('SKIP')` 跳过当前题与 `done` 时返回汇总对象。

**答**：
```javascript
function* survey() {
  const name = yield { q: '姓名', key: 'name' };
  const age = yield { q: '年龄', key: 'age' };
  const city = yield { q: '城市（可跳过）', key: 'city', optional: true };
  return { name, age, city, completedAt: Date.now() };
}

function driveSurvey(gen, answers) {
  const result = {};
  let step = gen.next();          // 启动：拿到第一题
  while (!step.done) {
    const { key, optional, q } = step.value;
    const ans = answers[key] ?? (optional ? 'SKIP' : prompt(q));
    if (ans === 'SKIP' && !optional) throw new Error(`必填项缺失: ${key}`);
    result[key] = ans === 'SKIP' ? null : ans;
    step = gen.next(result[key]); // 答案传回 yield 表达式
  }
  return { answers: result, meta: step.value }; // done 的 value = 生成器 return 值
}

const s = driveSurvey(survey(), { name: '张三', age: 25 });
console.log(s.meta); // { name: '张三', age: 25, city: null, completedAt: ... }
```

**评分点**：
- next(答案) 的双向传值（yield 表达式接收）——核心
- while(!step.done) 的驱动循环与 return 值捕获（step.value）
- SKIP 跳过逻辑与必填校验
- 流程状态存于生成器执行位置（无需显式 index 游标）
