## JS-257：原型链与继承输出题的读法

**答**：
- 查找规则：属性沿 `obj.__proto__` 链向上找，命中即停；写操作永远写在对象自身（shadowing）
- 三个关键点位：constructor 在原型上、Object.prototype 的尽头是 null、函数的 Function.prototype（fn.__proto__ === Function.prototype）
- 读题套路：画链——「实例 → 构造函数.prototype → Object.prototype → null」，逐层标出哪些属性在哪层
- 易错点：修改 Array.prototype 影响所有数组；instanceof 沿链找 constructor.prototype；Object.create(null) 无链

```javascript
function A() {}
A.prototype.say = () => 'A';
const a = new A();
a.say();           // 'A'（原型上）
a.constructor === A; // true（constructor 在 A.prototype）
a.__proto__ === A.prototype;           // true
A.__proto__ === Function.prototype;    // true（函数的原型链）
a instanceof A;     // true：A.prototype 在 a 的链上
```
