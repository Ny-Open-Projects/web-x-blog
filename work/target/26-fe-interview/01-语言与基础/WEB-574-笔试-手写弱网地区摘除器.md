## WEB-574：笔试：手写弱网地区 Alt-Svc 自动摘除器

**答**：实现服务端 `RegionGuard`：① 输入滑动窗口内的失败事件流 `{ region, ok, ts }`；② 维护每地区最近 10 分钟的请求/失败计数（用环形桶实现，1 分钟 1 桶）；③ 失败率 >15% 且样本数 >50 时把地区加入摘除名单并回调 `onEvict`；④ 摘除后该地区事件不再参与统计；⑤ 支持手动恢复 `restore(region)`。写出核心实现。

```javascript
class RegionGuard {
  constructor({ onEvict, threshold = 0.15, minSamples = 50, onRestore }) {
    this.onEvict = onEvict; this.threshold = threshold; this.min = minSamples;
    this.evicted = new Set();
    this.win = new Map(); // region -> { buckets: Array(10)×{ok,fail}, cur }
    for (let i = 0; i < 10; i++) this.win._ = 0;
    this.win = new Map();
    setInterval(() => this._roll(), 60_000); // 每分钟滚动
  }
  _roll() {
    for (const st of this.win.values()) {
      st.buckets.unshift({ ok: 0, fail: 0 });
      st.buckets.pop();
    }
    this._evaluate();
  }
  record({ region, ok }) {
    if (this.evicted.has(region)) return; // 已摘除不参与统计
    const st = (this.win.get(region) ||= { buckets: Array.from({ length: 10 }, () => ({ ok: 0, fail: 0 })) });
    ok ? st.buckets[0].ok++ : st.buckets[0].fail++;
    this._evaluate();
  }
  _evaluate() {
    for (const [region, st] of this.win) {
      const ok = st.buckets.reduce((s, b) => s + b.ok, 0);
      const fail = st.buckets.reduce((s, b) => s + b.fail, 0);
      const total = ok + fail;
      if (total >= this.min && fail / total > this.threshold) {
        this.evicted.add(region);
        this.onEvict?.(region, { fail, total, ratio: fail / total });
      }
    }
  }
  restore(region) {
    this.evicted.delete(region);
    this.win.delete(region); // 清历史避免立刻再触发
    this.onRestore?.(region);
  }
}
```

**评分点**：
- 环形桶滑动窗口实现正确（unshift/pop 位移）
- 双阈值判定（样本量 + 失败率），避免小样本误杀
- 已摘除地区停止统计、恢复时清空历史窗口
- 时间滚动与事件记录分离，窗口语义清晰
