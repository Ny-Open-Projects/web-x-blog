# 05 链表（C-081 ~ C-100）

> 链表是笔试里最稳的一道"手写题"：不考算法思想，考指针是否干净、边界是否想全。**识别特征**：看到"倒数第 k""环""相交""翻转区间""重排"，就要想到哑结点 + 快慢指针 + 头插法三件套。

## 题型速查

| 子类型 | 核心手法 | 代表题 |
|---|---|---|
| 整体/区间反转 | 三指针迭代、哑结点 + 头插 | C-081 / C-082 |
| 快慢指针定位 | 一次遍历求中点、环入口、倒数第 k | C-085 / C-089 |
| 合并与排序 | 哑结点尾插、分治归并 | C-083 / C-093 |
| 复制与重排 | 哈希映射、找中点 + 反转 + 交替合并 | C-092 / C-094 |
| 数学与成环 | 进位模拟、先成环再断链 | C-098 / C-100 |

### C-081 反转链表 · 简单 · 字节/阿里/腾讯

**题干**：给定单链表的头节点 `head`，请反转整个链表，返回反转后的头节点。链表节点定义为 `function ListNode(val, next)`，空链表返回 `null`。要求原地修改指针，不新建节点。

**示例**：`输入: 1→2→3→4→5` → `输出: 5→4→3→2→1`

**思路**：
- 迭代：维护 `prev`、`cur` 两个指针，每步先用临时变量存下 `cur.next`，再把 `cur.next` 指向 `prev`，随后两指针前移。**必须先存后继**，否则改完指针就再也找不到原链表剩余部分。循环结束时 `cur` 一定是 `null`，新头是 `prev`。
- 递归：先反转 `head.next` 之后的整段并拿到新头，再让 `head.next.next = head`、`head.next = null`。关键洞察是递归函数返回的始终是原链表的尾节点，也就是反转后的新头，所以中途不需要传递新头。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

// 迭代：三指针就地反转，空间 O(1)
function reverseList(head) {
  let prev = null;
  let cur = head;
  while (cur) {
    const next = cur.next; // 先存后继，否则改指针后链路丢失
    cur.next = prev;       // 当前节点反向指
    prev = cur;            // prev 前移
    cur = next;            // cur 前移
  }
  return prev; // 循环结束时 cur 为 null，prev 才是新头
}

// 递归：返回值始终是反转后的新头
function reverseListRec(head) {
  if (!head || !head.next) return head;
  const newHead = reverseListRec(head.next);
  head.next.next = head; // 后继指回自己
  head.next = null;      // 断开旧方向，否则 1→2 之间成环
  return newHead;
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)（递归版栈空间 O(n)）

**易错点**：
- 没保存 `next` 就改 `cur.next`，后半条链直接丢失。
- 返回 `cur` 而不是 `prev`——循环终止时 `cur` 是 `null`。
- 递归版忘记 `head.next = null`，两个节点会互相指向形成环。
- 空链表、单节点必须能直接返回。

- 口述时按“存后继 → 改指向 → 双指针前移”三步讲，再补空链表与返回 `prev` 两个边界。

**变体与追问**：
- 只反转前 n 个节点（递归时用计数器，第 n 个之后不再递归）。
- 反转区间 `[m, n]`，即下一题。
- 追问"不用递归、不用额外空间"就是在考三指针迭代。

### C-082 反转链表 II · 中等 · 字节/腾讯

**题干**：给定单链表头节点 `head` 和两个整数 `left`、`right`（位置从 1 开始计数，且 `1 ≤ left ≤ right ≤ 长度`），请反转从 `left` 到 `right` 的这段子链表，返回反转后的链表头。

**示例**：`输入: 1→2→3→4→5, left = 2, right = 4` → `输出: 1→4→3→2→5`

**思路**：
- 先建哑结点 `dummy` 指向 `head`，从 `dummy` 走 `left - 1` 步到反转段的前驱 `pre`。步数按“前驱”算，不要按“第一个反转节点”算。
- 在 `[left, right]` 内做「头插」：`cur` 始终是反转段的第一个节点，每轮把 `cur.next` 摘下来插到 `pre` 后面。一共插 `right - left` 次，`pre` 和 `cur` 都不动，只有被搬的节点在变。
- 为什么用哑结点：当 `left = 1` 时前驱不存在，哑结点伪造了一个"永远存在的前驱"，把"改头"和"改中间"两种分支合并成一种。
- 头插法与"先整段反转再拼回"都能做，但后者要额外记录段尾并处理两处连接；头插只维护 `pre` 一个锚点，指针更少、更不容易错。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function reverseBetween(head, left, right) {
  const dummy = new ListNode(0, head);
  let pre = dummy;
  for (let i = 1; i < left; i++) pre = pre.next; // 停在 left 的前驱
  let cur = pre.next;                            // 反转段第一个节点
  for (let i = 0; i < right - left; i++) {
    const next = cur.next;  // 要搬到头部的节点
    cur.next = next.next;   // 从原位置摘除
    next.next = pre.next;   // 插到 pre 之后、原段头之前
    pre.next = next;
  }
  return dummy.next;
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)

**易错点**：
- 定位前驱走 `left` 步而不是 `left - 1` 步，导致从反转段内部开始。
- 头插次数写成 `right - left + 1`，多转一次会把段外节点卷进来。
- 忘记 `pre` 不动、误把 `pre` 跟着前移，反转段会错位。
- 返回 `head` 而不是 `dummy.next`，`left = 1` 时头已变。

**变体与追问**：
- 只反转奇数位/偶数位节点。
- 反转后再整体反转，考查对指针段的组合能力。
- 追问"能否一趟扫描完成"——本题已经是。

### C-083 合并两个有序链表 · 简单 · 字节/美团

**题干**：将两个升序链表 `list1`、`list2` 合并为一个新的升序链表并返回。新链表由拼接原有节点组成，不新建节点。任一链表为空时返回另一条。

**示例**：`输入: 1→2→4, 1→3→4` → `输出: 1→1→2→3→4→4`

**思路**：
- 哑结点 + 尾指针：比较两条链当前节点，把较小者接到 `tail.next`，尾指针前移。为什么用哑结点：结果链表的第一个节点要么来自 `list1` 要么来自 `list2`，用哑结点可以省掉"第一次接谁"的分支，最后返回 `dummy.next` 即可。
- 某条链走空后，剩下的一整段天然有序且都更大，直接整体挂到尾部，不需要再逐个比较——这是 O(m+n) 而不是 O((m+n)²) 的关键。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function mergeTwoLists(list1, list2) {
  const dummy = new ListNode(0);
  let tail = dummy;
  while (list1 && list2) {
    if (list1.val <= list2.val) { // 用 <= 保持稳定，相等时先取 list1
      tail.next = list1;
      list1 = list1.next;
    } else {
      tail.next = list2;
      list2 = list2.next;
    }
    tail = tail.next;
  }
  tail.next = list1 || list2; // 剩余整段直接接上
  return dummy.next;
}
```

**复杂度**：时间 O(m + n) ／ 空间 O(1)

**易错点**：
- 剩余段用 `while` 一个个接，虽正确但没必要。
- 返回 `dummy` 本身，结果多一个值为 0 的头。
- 比较写 `<` 而非 `<=`，相等元素顺序颠倒（本题不敏感，但归并排序里要求稳定）。
- 两条都为空时返回 `null`，`dummy.next` 恰好是 `null`，不要特判成 `undefined`。

- 合并复用了原节点；若题目要求保留入参，需先做深拷贝。

**变体与追问**：
- 合并 k 条（下一题），递推关系就是反复调用本题。
- 合并后去重、合并后取中位数（两个有序数组的升级版）。
- 递归写法只有四行，面试可主动提"递归更短但栈深 O(m+n)"。

### C-084 合并 K 个升序链表 · 困难 · 字节/快手

**题干**：给定一个链表数组 `lists`，每个链表都已按升序排列，请将所有链表合并为一个升序链表并返回。`lists` 可能为空数组，其中也可能包含空链表。

**示例**：`输入: [[1,4,5],[1,3,4],[2,6]]` → `输出: 1→1→2→3→4→4→5→6`

**思路**：
- 朴素做法是拿结果链表依次和第 2、3…k 条合并，第 i 次合并要扫过前 i 条链的全部节点，总代价 O(nk)，k 大时退化明显。
- 分治：把 k 条链两两配对合并，第一轮剩 k/2 条，第二轮 k/4 条……共 log k 轮，每轮所有节点被扫一次，总计 O(n log k)。这正是"归并排序的合并阶段"在链表上的形态。
- 小顶堆亦可：每次取 k 个头中最小者，取完把它的后继入堆，堆操作 O(log k)，共 n 次。JS 没有内置堆，笔试现场手写堆的出错率高于分治，优先分治。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function mergeTwo(a, b) {
  const dummy = new ListNode(0);
  let tail = dummy;
  while (a && b) {
    if (a.val <= b.val) { tail.next = a; a = a.next; }
    else { tail.next = b; b = b.next; }
    tail = tail.next;
  }
  tail.next = a || b;
  return dummy.next;
}

function mergeKLists(lists) {
  if (!lists || !lists.length) return null;
  // 分治：每轮把相邻两条合并，规模减半
  while (lists.length > 1) {
    const next = [];
    for (let i = 0; i < lists.length; i += 2) {
      next.push(mergeTwo(lists[i], lists[i + 1] || null));
    }
    lists = next;
  }
  return lists[0];
}
```

**复杂度**：时间 O(n log k)（n 为节点总数，k 为链表条数） ／ 空间 O(k)（每轮存下一层链表头）

**易错点**：
- `lists[i + 1]` 越界时为 `undefined`，要显式转成 `null`，否则 `mergeTwo` 里的 `b.val` 抛错。
- 空数组返回 `null` 而非 `[]`。
- 用 `splice` 边遍历边删会导致下标错乱，务必新建数组。
- 递归分治也可，但 k 很大时递归深度 O(log k) 尚可；逐个合并则是 O(k) 深度。

**变体与追问**：
- 改成"合并 k 个有序数组"，思路完全一致。
- 追问"如果有 10 万条链表" → 分治仍稳，堆的 O(n log k) 同阶但常数更大。
- 追问"内存受限" → 只能流式取头，堆更合适，分治需持有所有链头（O(k) 可接受）。

### C-085 删除链表的倒数第 N 个结点 · 中等 · 字节/阿里

**题干**：给定链表头节点 `head` 和整数 `n`，删除倒数第 `n` 个节点并返回头节点。保证 `n` 有效（`1 ≤ n ≤ 长度`）。要求只遍历一次。

**示例**：`输入: 1→2→3→4→5, n = 2` → `输出: 1→2→3→5`

**思路**：
- 要让 `slow` 停在待删节点的前驱，才能用 `slow.next = slow.next.next` 删除。为此让 `fast` 先从哑结点走 `n + 1` 步，制造 `n + 1` 的间距；随后 `fast`、`slow` 同步前进，`fast` 到 `null` 时 `slow` 恰好是前驱。
- 为什么用哑结点：若删的是头节点（`n` 等于链表长度），前驱本不存在；哑结点让"删除头"退化成"删除哑结点的后继"，不需要单独分支。
- 为什么是 `n + 1` 而不是 `n`：走 `n` 步只能让 `slow` 停在待删节点本身，拿不到前驱，这是本题最常见的 off-by-one。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function removeNthFromEnd(head, n) {
  const dummy = new ListNode(0, head); // 统一删除头/删除中间两种情况
  let fast = dummy, slow = dummy;
  // fast 先走 n+1 步，使 slow 最终停在待删节点的前驱
  for (let i = 0; i <= n; i++) fast = fast.next;
  while (fast) {
    fast = fast.next;
    slow = slow.next;
  }
  // slow 是前驱，跨过待删节点
  slow.next = slow.next.next;
  return dummy.next;
}
```

**复杂度**：时间 O(L)（L 为链表长度，只扫一遍） ／ 空间 O(1)

**易错点**：
- 走 `n` 步：`slow` 落在待删节点上，无法删除。
- `n` 等于长度时 `fast` 在预走阶段就变成 `null`，若循环写成 `while (fast.next)` 会抛错。
- 返回 `head`：删头时头已失效，必须返回 `dummy.next`。
- 删除后没有释放引用在 JS 里无所谓，但面试可提"其他语言要注意置空"。

- 工程代码仍应校验 `n >= 1` 且不超过链长，避免预走阶段空指针。

**变体与追问**：
- 删除倒数第 n 个并返回被删的值。
- 删除正数第 n 个（简单，但要处理 n = 1 的头删除）。
- 追问"能否不先求长度"——本题就是答案，快慢指针天然差 n。

### C-086 两两交换链表中的节点 · 中等 · 阿里/腾讯

**题干**：给定一个链表，请两两交换其中相邻的节点，并返回交换后链表的头节点。要求不修改节点的值，只能通过改指针完成；若节点总数为奇数，最后一个节点保持不动。

**示例**：`输入: 1→2→3→4` → `输出: 2→1→4→3`；`输入: 1→2→3` → `输出: 2→1→3`

**思路**：
- 迭代需要三个指针：`pre` 是当前这对节点的前驱，`a`、`b` 是这一对。交换顺序必须是：`a.next = b.next`、`b.next = a`、`pre.next = b`，三步缺一不可，先连后断才不会丢链。
- 交换完成后，这一对的尾节点是 `a`，所以 `pre = a`，下一轮从 `a.next` 开始。为什么用哑结点：`head` 会和第二个节点交换而不再是头，哑结点让第一对和其它对的写法统一。
- 循环条件是 `pre.next && pre.next.next`，只剩一个节点时自然停下，不需要判断奇偶。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function swapPairs(head) {
  const dummy = new ListNode(0, head);
  let pre = dummy;
  while (pre.next && pre.next.next) {
    const a = pre.next;
    const b = a.next;
    a.next = b.next; // 1. a 跨过 b 接上后一段
    b.next = a;      // 2. b 反指 a
    pre.next = b;    // 3. 前驱接上新的一对头
    pre = a;         // 本对尾部是 a，作为下一对的前驱
  }
  return dummy.next;
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)

**易错点**：
- 先写 `pre.next = b` 再取 `a`、`b`，节点已经丢了。
- 忘记 `a.next = b.next`，交换后这一对和后面整段断开。
- `pre = b`（本对头）而不是 `pre = a`（本对尾），下一轮会重复处理。
- 返回 `dummy.next`，不是原 `head`。

**变体与追问**：
- 递归版三行：交换前两个，再递归接上后面，返回 `b`。
- 每 k 个一组交换（下一题），本题是 k=2 的特例。
- 追问"不哑结点怎么写" → 必须先单独处理头两个节点，分支明显变多，这正是哑结点的价值。

### C-087 K 个一组翻转链表 · 困难 · 字节/腾讯

**题干**：给定链表头节点 `head` 和整数 `k`，请每 `k` 个节点一组进行翻转，返回翻转后的链表。若最后剩余节点不足 `k` 个，则保持原有顺序。不允许修改节点值。

**示例**：`输入: 1→2→3→4→5, k = 2` → `输出: 2→1→4→3→5`；`k = 3` → `输出: 3→2→1→4→5`

**思路**：
- 外层用一个 `pre` 指向"上一组的尾"，每轮先向后探 `k` 步：能走满说明这一组可以翻，走不满立刻返回，剩余部分原样保留——「先探测再翻转」是不足 k 个不动的关键。
- 翻转区间时记录 `next = tail.next`（下一组起点），以 `next` 为 `prev` 初值、`pre.next` 为 `cur` 初值反向指，走到 `cur === next` 结束。这样翻转后 `tail` 恰好成为新头、原组头成为新尾。
- 最后 `pre.next = tail` 接上新头，`pre = 原组头`（现为新尾）进入下一轮。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function reverseKGroup(head, k) {
  const dummy = new ListNode(0, head);
  let pre = dummy;
  while (true) {
    let tail = pre;
    for (let i = 0; i < k; i++) {
      tail = tail.next;
      if (!tail) return dummy.next; // 不足 k 个，保持原序
    }
    const next = tail.next; // 下一组的起点，也是翻转的终止边界
    let prev = next, cur = pre.next;
    while (cur !== next) {
      const nxt = cur.next;
      cur.next = prev;
      prev = cur;
      cur = nxt;
    }
    const newTail = pre.next; // 翻转前的组头，翻转后成组尾
    pre.next = tail;          // 接上新组头
    pre = newTail;            // 下一组的前驱
  }
}
```

**复杂度**：时间 O(n)（每个节点被访问两次：探测一次、翻转一次） ／ 空间 O(1)

**易错点**：
- 先翻转再判断够不够 k 个，不足时还得翻回去，容易把尾段弄乱。
- 翻转终止条件写成 `cur !== null`，会把后面的组一起翻掉。
- `pre = newTail` 写成 `pre = tail`，下一轮前驱错位。
- 忘记返回 `dummy.next`，k 大于长度时头未变但 k 合法时头已变。

- `k = 1` 或空链表时逻辑应自然成立，可作为提交前的边界自测。

**变体与追问**：
- 不足 k 个也翻转（去掉探测，直接翻到结尾）。
- 从尾部开始每 k 个翻转。
- 追问"能否只遍历一次" → 本题已是 O(n)，常数 2 可接受。

### C-088 环形链表 · 简单 · 字节/美团

**题干**：给定链表头节点 `head`，判断链表中是否有环。环的定义是某个节点的 `next` 指针指向链表中它之前的某个节点。要求空间 O(1)。

**示例**：`输入: 3→2→0→-4，且 -4 指回 2` → `输出: true`；`输入: 1→2` → `输出: false`

**思路**：
- 快慢指针：`slow` 每次走 1 步，`fast` 每次走 2 步。若无环，`fast` 一定先撞到 `null`；若有环，两者都进入环后，`fast` 每步相对 `slow` 追近 1 个节点，环长有限，最多一圈必追上。
- 为什么快指针走 2 而不是 3：走 2 时相对速度 1，不会"跳过"慢指针；走 3 在某些环长下会反复越过而不相遇，虽然最终也能相遇，但分析变复杂。
- 哈希表法（记录访问过的节点）时间同为 O(n)，但空间 O(n)，只适合作为对照答案，不能满足本题 O(1) 的要求。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function hasCycle(head) {
  let slow = head;
  let fast = head;
  // fast 走两步，必须同时判 fast 和 fast.next
  // 快指针每步比慢指针多走 1，有环时最多一圈必追上
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) return true;
  }
  // 无环时 fast 会先走到 null
  return false;
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)

**易错点**：
- 循环条件只写 `fast.next`，偶数长度无环时 `fast` 先变 `null` 抛错。
- 用 `slow.val === fast.val` 判断，值相等不代表同节点。
- 把相遇判断写在移动之前，初始 `slow === fast === head` 直接误判为有环。
- 单节点自环 `head.next === head`，循环条件成立，能正确返回 `true`。

- 相遇点不一定是入环点；求入口需要第二阶段（见下一题）。

**变体与追问**：
- 求环的长度：相遇后继续走，再次相遇的步数即环长。
- 求入环点（下一题）。
- 追问"为什么一定相遇" → 进入环后距离每步缩小 1，不可能跨过。

### C-089 环形链表 II · 中等 · 字节/腾讯

**题干**：给定链表头节点 `head`，返回链表开始入环的第一个节点；若链表无环，返回 `null`。要求空间 O(1)，且不允许修改链表。

**示例**：`输入: 3→2→0→-4，且 -4 指回 2` → `输出: 值为 2 的节点`

**思路**：
- 第一阶段与 C-088 相同：`slow`、`fast` 找相遇点。设头到入环点距离为 `a`，入环点到相遇点为 `b`，环长为 `L`。相遇时 `slow` 走了 `a + b`，`fast` 走了 `a + b + nL`，而 `fast` 路程是 `slow` 的两倍，化简得 `a = nL - b = (n-1)L + (L-b)`。
- 这个式子的含义：从**头节点**走 `a` 步，与从**相遇点**继续走 `L-b` 步，会同时到达入环点。所以第二阶段让一个指针回到 `head`，两者同速前进，相遇处就是入环点。
- 为什么不用哈希表：能过，但空间 O(n)；本题的考点就是这段数学推导。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function detectCycle(head) {
  let slow = head, fast = head;
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) {
      // 相遇后，一个从头出发，一个从相遇点出发，同速必在入环点相遇
      let p = head;
      while (p !== slow) {
        p = p.next;
        slow = slow.next;
      }
      return p;
    }
  }
  return null;
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)

**易错点**：
- 第二阶段让 `slow` 回到 `head`、`p` 留在相遇点也可以，但两个指针的起点写反后仍能相遇，容易讲不清逻辑。
- 无环时忘记返回 `null`，函数落到 `undefined`。
- 第二阶段写成 `p.next !== slow`，会停在入环点前一个节点。
- 相遇判断放在移动前，空链表会误判。

**变体与追问**：
- 求环长：相遇后固定一个指针，另一个绕一圈计数。
- 追问"n 一定是 1 吗" → 不一定，快指针可能多绕了几圈，但 `a ≡ L-b (mod L)` 的结论不变。
- 追问"能否用 Set" → 可以但 O(n) 空间，面试官通常要求优化到 O(1)。

### C-090 相交链表 · 简单 · 字节/阿里

**题干**：给定两个单链表的头节点 `headA`、`headB`，请找出并返回它们相交的起始节点；若不相交返回 `null`。题目保证链表中无环，且函数返回后原链表结构不变。

**示例**：`A: 4→1→8→4→5，B: 5→6→1→8→4→5`（8 为交点） → `输出: 值为 8 的节点`

**思路**：
- 设 A 独有段长 `a`、B 独有段长 `b`、公共段长 `c`。指针 `pa` 走完 A 后跳到 B 的头，指针 `pb` 走完 B 后跳到 A 的头，两者总路程都是 `a + c + b`，因此有交点时必然同时到达交点；无交点时同时变成 `null`，循环自然结束。
- 为什么能消除长度差：不是先求长度对齐，而是让两个指针"互换跑道"，把长度差补在对方的独有段上，等价于对齐后同速。
- 长度差法也可：先各求长度，长的先走差值步，再同步走。但代码多一段，且容易在差值方向写反。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

// 双指针“互换跑道”，不需要预先求长度
function getIntersectionNode(headA, headB) {
  let pa = headA, pb = headB;
  // 走完自己的链就换到对方链头，长度差被 a+c+b === b+c+a 抵消
  // 无交点时两指针会同时为 null，循环自然结束
  while (pa !== pb) {
    // 换链后继续同步前进，直到相遇或同时为 null
    pa = pa ? pa.next : headB;
    pb = pb ? pb.next : headA;
  }
  // 交点必须用节点引用判断，不能用 val
  return pa; // 相交则为交点，不相交则同时为 null
}
```

**复杂度**：时间 O(m + n) ／ 空间 O(1)

**易错点**：
- 用 `pa.val === pb.val` 判断相交，值相同不代表同一节点。
- 换链写成 `pa = headB` 时未判空，`pa` 走完不会停。
- 无交点时会各自换链走 `m+n` 步后同时为 `null`，循环能停，不要额外加计数。
- 题意要求不修改原链表，不要用"成环再判环"的取巧解法。

**变体与追问**：
- 若链表可能有环，需先判环再分类讨论，属于困难变体。
- 求两个链表的第一个公共节点（与本题同义）。
- 追问"如果要求 O(1) 且不换链" → 只能先求长度差，牺牲一次遍历。

### C-091 回文链表 · 简单 · 字节/美团

**题干**：给定单链表头节点 `head`，判断该链表是否为回文链表。要求时间 O(n)、空间 O(1)，且最好不破坏原链表结构。

**示例**：`输入: 1→2→2→1` → `输出: true`；`输入: 1→2→3` → `输出: false`

**思路**：
- 回文要求"首尾对称"，但链表只能单向走。把后半段反转后，前半段正序与后半段（原倒序）逐位比较即可，比较完再把后半段翻回去，保证函数无副作用。
- 找中点用快慢指针：`fast` 走两步、`slow` 走一步；当 `fast.next` 或 `fast.next.next` 为空时，`slow` 停在"前半段的最后一个节点"。这样奇数长度时中点本身不参与比较，偶数长度时正好对半分。
- 为什么不能整体反转再比较：整体反转后原链表已毁，且无法区分"前半"与"后半"，还会把中点算两次。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function isPalindrome(head) {
  if (!head || !head.next) return true;
  // 1. 快慢指针找前半段尾节点
  let slow = head, fast = head;
  while (fast.next && fast.next.next) {
    slow = slow.next;
    fast = fast.next.next;
  }
  // 2. 反转后半段
  let prev = null, cur = slow.next;
  while (cur) {
    const nxt = cur.next;
    cur.next = prev;
    prev = cur;
    cur = nxt;
  }
  // 3. 比较，后半段更短，以它为准
  let p1 = head, p2 = prev, ok = true;
  while (p2) {
    if (p1.val !== p2.val) { ok = false; break; }
    p1 = p1.next; p2 = p2.next;
  }
  // 4. 恢复后半段，避免修改入参
  let p = null, c = prev;
  while (c) { const n = c.next; c.next = p; p = c; c = n; }
  slow.next = p;
  return ok;
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)

**易错点**：
- 找中点条件写成 `while (fast && fast.next)`，`slow` 会落到右中点，奇数长度时比较范围错位。
- 比较循环用前半段长度，长链表奇数时 `p2` 先变 `null` 抛错。
- 只写 `return false` 提前退出，忘记恢复后半段（面试官会追问副作用）。
- 空链表、单节点直接返回 `true`。

**变体与追问**：
- 允许 O(n) 空间：把值压栈或转数组双指针，代码更短。
- 双向链表：直接从两端向中间夹。
- 追问"能否不回改" → 可以，但要么 O(n) 空间复制，要么接受修改入参，需与面试官确认。

### C-092 复制带随机指针的链表 · 中等 · 字节/快手

**题干**：给定一个链表，每个节点除 `next` 外还有一个 `random` 指针，可指向链表中任意节点或 `null`。请返回该链表的深拷贝：新链表的所有节点都是新建的，`next` 与 `random` 的指向关系与原链表完全一致。

**示例**：`输入: [[7,null],[13,0],[11,4],[10,2],[1,0]]` → `输出: 结构完全相同的新链表`

**思路**：
- 哈希法两遍：第一遍只按 `val` 建新节点，并用 `Map` 建立"原节点 → 新节点"的映射；第二遍再连 `next` 和 `random`。为什么必须先建完所有节点：`random` 可以指向后面的节点，甚至指向自己，边建边连会拿到尚未创建的对象。
- O(1) 空间法：把每个新节点插到原节点后面（`1→1'→2→2'`），此时 `cur.next` 就是副本，`random` 的副本就是 `cur.random.next`；最后把两条链拆开并恢复原链。笔试若无空间要求，哈希法更不容易写错，优先推荐。

**代码**：
```javascript
function Node(val, next = null, random = null) {
  this.val = val; this.next = next; this.random = random;
}

function copyRandomList(head) {
  if (!head) return null;
  const map = new Map();
  // 第一遍：只创建节点，建立映射
  for (let p = head; p; p = p.next) map.set(p, new Node(p.val));
  // 第二遍：连 next 与 random
  for (let p = head; p; p = p.next) {
    const copy = map.get(p);
    copy.next = p.next ? map.get(p.next) : null;
    copy.random = p.random ? map.get(p.random) : null;
  }
  return map.get(head);
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)（哈希表；O(1) 空间法见思路）

**易错点**：
- `p.random` 为 `null` 时直接 `map.get(null)` 得到 `undefined`，必须显式转 `null`。
- `next` 为 `null` 同理，否则新链表尾部指向 `undefined`。
- 边建边连 `random`，遇到指向后方节点时拿到的是 `undefined`。
- 返回 `head` 而不是 `map.get(head)`，返回了原链表。

**变体与追问**：
- 要求 O(1) 额外空间：写出"插入副本 → 连 random → 拆链"三步，注意拆链时恢复原链。
- 追问"random 指向自己" → 哈希法天然支持，因为映射已建好。
- 追问"链表有环" → 本题默认无环，有环需先判环或改用索引建图。

### C-093 排序链表 · 中等 · 字节/腾讯

**题干**：给定单链表头节点 `head`，请将其按升序排列并返回排序后的链表。要求时间 O(n log n)、空间 O(1)（递归栈不计入或要求自底向上）。

**示例**：`输入: 4→2→1→3` → `输出: 1→2→3→4`

**思路**：
- 链表不能随机访问，快排的分区需要反复扫描，代价高；归并只需改指针，是链表排序的天然选择。
- 自底向上归并：先求总长 `len`，令 `step = 1, 2, 4…`，每轮把链表按 `step` 切成若干段、相邻两段合并，`len` 轮后整体有序。因为没有递归，额外空间只有几个指针，满足 O(1)。
- 每轮用 `dummy` 重新串结果，`split` 负责"取前 n 个并断开"，`merge` 复用 C-083 的逻辑并把 `prev` 推进到合并段末尾。为什么断开很重要：不切断 `tail.next`，下一段会和当前段粘在一起，合并范围失控。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }
// 取前 n 个节点，断开并返回剩余部分的头
function split(node, n) {
  for (let i = 1; node && i < n; i++) node = node.next;
  if (!node) return null;
  const rest = node.next;
  node.next = null;
  return rest;
}

function merge(a, b, prev) {
  while (a && b) {
    if (a.val <= b.val) { prev.next = a; a = a.next; }
    else { prev.next = b; b = b.next; }
    prev = prev.next;
  }
  prev.next = a || b;
  while (prev.next) prev = prev.next; // 推进到合并段末尾
  return prev;
}
function sortList(head) {
  if (!head || !head.next) return head;
  let len = 0;
  for (let p = head; p; p = p.next) len++;
  const dummy = new ListNode(0, head);
  for (let step = 1; step < len; step *= 2) {
    let prev = dummy, cur = dummy.next;
    while (cur) {
      const left = cur, right = split(left, step);
      cur = split(right, step); // 下一轮的起点
      prev = merge(left, right, prev);
    }
  }
  return dummy.next;
}
```

**复杂度**：时间 O(n log n) ／ 空间 O(1)

**易错点**：
- `split` 忘记 `node.next = null`，两段仍然相连，`merge` 会走进已排好的部分。
- `step *= 2` 写成 `step++`，退化成 O(n²)。
- 每轮 `prev`、`cur` 没有重置到 `dummy`，第二轮从中间开始。
- 递归归并的栈空间是 O(log n)，若题目严格要求 O(1)，必须写自底向上。

**变体与追问**：
- 递归版：快慢找中点、断链、递归两半、合并，代码短但空间 O(log n)。
- 排序后去重、找中位数。
- 追问"为什么不用快排" → 链表分区需要额外遍历且难以原地，归并更契合指针结构。

### C-094 重排链表 · 中等 · 字节/阿里

**题干**：给定单链表 `L0→L1→…→Ln-1→Ln`，请将其重排为 `L0→Ln→L1→Ln-1→L2→Ln-2→…`。要求原地修改，不能只改变节点值。

**示例**：`输入: 1→2→3→4` → `输出: 1→4→2→3`；`输入: 1→2→3→4→5` → `输出: 1→5→2→4→3`

**思路**：
- 目标序列 = 前半段正序 + 后半段逆序交替。因此分三步：快慢指针找中点、反转后半段、两条链交替合并。
- 找中点后必须 `slow.next = null` 把两半彻底断开。这一步是防环的关键：后半段反转后原本的尾会指回前半段，不切断会在合并时形成环。
- 合并时用 `n1`、`n2` 暂存各自后继，再改指针；循环以 `p2` 为准，因为后半段长度不超过前半段，走完即结束。为什么不用计数器：链表长度奇偶不用特判，短的那条走完就是边界。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function reorderList(head) {
  if (!head || !head.next) return;
  // 1. 快慢指针找中点（前半段尾）
  let slow = head, fast = head;
  while (fast.next && fast.next.next) {
    slow = slow.next;
    fast = fast.next.next;
  }
  // 2. 断开并反转后半段
  let prev = null, cur = slow.next;
  slow.next = null;
  while (cur) {
    const nxt = cur.next;
    cur.next = prev;
    prev = cur;
    cur = nxt;
  }
  // 3. 交替合并两条链
  let p1 = head, p2 = prev;
  while (p2) {
    const n1 = p1.next, n2 = p2.next;
    p1.next = p2;
    p2.next = n1;
    p1 = n1;
    p2 = n2;
  }
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)

**易错点**：
- 不断开 `slow.next`，合并后链表成环，遍历死循环。
- 合并时先改 `p1.next` 再取 `p1.next` 的后继，后半段丢失。
- 中点条件写成 `fast && fast.next`，偶数长度时后半段比前半段长，合并边界错。
- 返回 `head`（原地修改无返回值），不要返回 `p1` 或 `prev`。

- 三步顺序不能颠倒，建议先在纸上画出偶数、奇数两种长度的指针变化。

**变体与追问**：
- 重排成"前半正序 + 后半正序"（等价于按位置洗牌）。
- 每 k 个一组重排。
- 追问"能否用数组存节点" → 可以 O(n) 空间，但本题明确要求原地，考的就是三步组合。

---

### C-095 删除排序链表中的重复元素 · 简单 · 美团/阿里

**题干**：给定一个已按升序排列的链表头节点 `head`，请删除所有重复的元素，使每个元素只出现一次，返回去重后的链表头。要求原地修改，不新建节点。

**示例**：`输入: 1→1→2` → `输出: 1→2`；`输入: 1→1→2→3→3` → `输出: 1→2→3`

**思路**：
- 因为链表有序，重复元素一定相邻，只需一个指针 `cur` 扫描：若 `cur.val === cur.next.val`，就让 `cur.next` 跨过下一个节点；否则 `cur` 前移。
- 为什么删除后 `cur` 不移动：可能连续三个甚至更多相同值（`1→1→1`），必须留在原地继续和新的 `cur.next` 比较，直到不同为止。
- 为什么不需要哑结点：头节点即使重复也一定保留第一个，`head` 本身永远有效，不存在"删头"的情况。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

// 单指针扫描，原地删除
function deleteDuplicates(head) {
  // 有序链表，重复元素必然相邻
  let cur = head;
  while (cur && cur.next) {
    if (cur.val === cur.next.val) {
      cur.next = cur.next.next; // 保留第一个，跳过后续相同值；cur 不动
    } else {
      cur = cur.next; // 只有确认不重复才前进
    }
  }
  return head;
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)

**易错点**：
- 删除后同时移动 `cur = cur.next`，连续重复会漏删。
- 循环条件只写 `cur`，`cur.next` 为 `null` 时访问 `.val` 抛错。
- 误加哑结点并返回 `dummy.next`，虽然结果对但多此一举。
- 空链表、单节点直接返回 `head`，循环自然不进入。

- 本题是下一题“重复的一个都不留”的对照组，先写熟它再处理哑结点。

**变体与追问**：
- 重复的一个都不留，即下一题（需要哑结点 + 整段跳过）。
- 无序链表去重：需要哈希表，且要保留首次出现顺序。
- 追问"能否递归" → 可以，`head.next = deleteDuplicates(head.next)` 再判断头与后继，但栈深 O(n)。

### C-096 删除排序链表中的重复元素 II · 中等 · 字节/美团

**题干**：给定一个已按升序排列的链表头节点 `head`，请删除所有含有重复数字的节点，只保留原链表中没有重复出现的数字，返回结果链表头。要求原地修改。

**示例**：`输入: 1→2→3→3→4→4→5` → `输出: 1→2→5`；`输入: 1→1→1→2→3` → `输出: 2→3`

**思路**：
- 与 C-095 的区别是"重复的一个都不留"，因此一旦发现重复，要跳过**整段**相同值，而不是只删多余的那些。
- 必须用哑结点：头节点本身可能重复而被删除（如 `1→1→2`），此时返回值不再是原 `head`。哑结点保证删除操作永远有一个合法的前驱 `pre`。
- 双指针：`cur` 扫描，`pre` 是最后一个"确定保留"的节点。若 `cur` 与 `cur.next` 同值，先记下该值，用内层 `while` 把 `cur` 推到第一个不同值，再令 `pre.next = cur`；否则 `pre = cur`、`cur` 前移。删除整段后 `pre` 不能动，因为它后面可能还是重复段。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function deleteDuplicates(head) {
  const dummy = new ListNode(0, head);
  let pre = dummy, cur = head;
  while (cur && cur.next) {
    if (cur.val === cur.next.val) {
      const v = cur.val;
      // 跳过整段等于 v 的节点
      while (cur && cur.val === v) cur = cur.next;
      pre.next = cur; // pre 不前进，后面可能还是重复段
    } else {
      pre = cur;
      cur = cur.next;
    }
  }
  return dummy.next;
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)

**易错点**：
- 只删 `cur.next` 而保留第一个重复值，结果变成 C-095。
- 内层跳过后 `pre = cur`，导致后续重复段无法删除。
- 忘记 `pre.next = cur`，被跳过的节点仍然挂在链上。
- 返回 `head`，`1→1→2` 时返回了已被删除的首个 1。

**变体与追问**：
- 保留一个重复（C-095），对比两题的哑结点使用差异。
- 无序链表删除所有重复值：需要先计数再重建。
- 追问"能否一趟扫描" → 本题内层虽然嵌套，但每个节点只被访问常数次，总体 O(n)。

### C-097 分隔链表 · 中等 · 腾讯/阿里

**题干**：给定链表头节点 `head` 和一个特定值 `x`，请对链表进行分隔，使得所有小于 `x` 的节点都出现在大于或等于 `x` 的节点之前。要求保留两个分区中每个节点的初始相对位置。

**示例**：`输入: 1→4→3→2→5→2, x = 3` → `输出: 1→2→2→4→3→5`

**思路**：
- 维护两条子链：`small` 串小于 `x` 的节点，`large` 串大于等于 `x` 的节点，均用尾插保证相对顺序不变。为什么不头插：头插会反转组内顺序，违反题意。
- 扫完后把 `small` 的尾接到 `large` 的头（跳过 `large` 的哑结点）。为什么最后必须 `l.next = null`：`large` 的尾节点在原链中可能正指向某个小于 `x` 的节点，不清空就会让新链表尾部指回 `small` 段，形成环。
- 哑结点在这里的作用仍是省掉"某条子链为空"的判断：无论哪边为空，拼接和返回都成立。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function partition(head, x) {
  const small = new ListNode(0);
  const large = new ListNode(0);
  let s = small, l = large, cur = head;
  while (cur) {
    if (cur.val < x) {
      s.next = cur;
      s = s.next;
    } else {
      l.next = cur;
      l = l.next;
    }
    cur = cur.next;
  }
  l.next = null;        // 关键：断开大链表尾部，防止成环
  s.next = large.next;  // 小链表尾接大链表头
  return small.next;
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)

**易错点**：
- 忘记 `l.next = null`，当最后一个节点小于 `x` 时 `large` 尾仍指向它，结果成环。
- 用头插法维护子链，相对顺序被反转。
- 返回 `small`（哑结点）而非 `small.next`。
- `x` 比所有值都小或都大时，另一条子链为空，拼接逻辑仍要正确。

**变体与追问**：
- 分三区（小于、等于、大于）的链表分区（颜色分类的链表版）。
- 分隔后要求两个分区内部也排序。
- 追问"为什么用两条哑结点而不是一条" → 两段独立成长，最后 O(1) 拼接，比反复找插入点简单。

### C-098 旋转链表 · 中等 · 字节/阿里

**题干**：给定链表头节点 `head` 和整数 `k`，请将链表每个节点向右移动 `k` 个位置，返回旋转后的链表头。`k` 为非负数。

**示例**：`输入: 1→2→3→4→5, k = 2` → `输出: 4→5→1→2→3`

**思路**：
- 右移 `k` 位等价于把"倒数第 `k` 个节点"变成新头。关键是 `k` 可能远大于链表长度，所以先求长度 `n`、令 `k %= n`；`k === 0` 时原样返回。
- 把尾节点指向头，先成环，再从环上找新的尾：新头是第 `n-k+1` 个节点（1 起），新尾是第 `n-k` 个节点，从 `head` 走 `n-k-1` 步即可。最后 `newTail.next = null` 断环。
- 为什么先成环：成环后不需要维护"尾连头"的特殊指针，只要在新位置剪一刀，逻辑最简洁；但剪完必须断，否则返回值虽然对，链表却是环形。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function rotateRight(head, k) {
  if (!head || !head.next) return head;
  let n = 1, tail = head;
  while (tail.next) { tail = tail.next; n++; }
  k %= n;
  if (k === 0) return head;
  tail.next = head; // 先成环
  let newTail = head;
  for (let i = 1; i < n - k; i++) newTail = newTail.next;
  const newHead = newTail.next;
  newTail.next = null; // 断环
  return newHead;
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)

**易错点**：
- 不取模，`k` 很大时循环次数爆炸或下标越界。
- 新尾走 `n-k` 步而不是 `n-k-1` 步，新头少移一位。
- 忘记 `newTail.next = null`，返回一条环链，后续遍历死循环。
- 空链表、单节点、`k % n === 0` 三种情况要提前返回。

- 旋转本质是定位“倒数第 k 个”节点，可与 C-085 的快慢指针法互相印证。

**变体与追问**：
- 左旋 `k` 位（等价于右旋 `n-k` 位）。
- 旋转后要求保持某个区间连续。
- 追问"能否不先求长度" → 可以用快慢指针让 `fast` 先走 `k` 步，但 `k` 大于长度时仍需取模，求长度更直观。

### C-099 奇偶链表 · 中等 · 字节/美团

**题干**：给定单链表头节点 `head`，请将所有索引为奇数的节点和索引为偶数的节点分别组合在一起，奇数节点在前、偶数节点在后，返回重新排序后的链表。索引从 1 开始，要求空间 O(1)，且保持两组内部的相对顺序。

**示例**：`输入: 1→2→3→4→5` → `输出: 1→3→5→2→4`

**思路**：
- 维护两条链：`odd` 串奇数位、`even` 串偶数位，`evenHead` 记住偶链头。每一轮把 `odd` 的下一个指向 `even` 的下一个（即下一个奇数位），再反过来让 `even` 指向新的 `odd.next`，两条链同步前移。
- 循环条件是 `even && even.next`：偶数位总是在奇数位后面，偶数位走完就说明没有新的奇数位了，用 `even` 作哨兵比用 `odd` 更安全。
- 最后 `odd.next = evenHead` 把偶链接到奇链尾部。为什么不需要再处理偶链尾：偶链尾的 `next` 在循环中始终被设为 `null` 或下一个偶节点，最后天然是 `null`。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function oddEvenList(head) {
  if (!head || !head.next) return head;
  let odd = head;
  let even = head.next;
  const evenHead = even;
  while (even && even.next) {
    odd.next = even.next; // 奇链接下一个奇数位
    odd = odd.next;
    even.next = odd.next; // 偶链接下一个偶数位
    even = even.next;
  }
  odd.next = evenHead; // 奇链尾接偶链头
  return head;
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)

**易错点**：
- 循环条件写成 `odd && odd.next`，会在奇链尾多接一个偶节点。
- 忘记保存 `evenHead`，最后找不到偶链头。
- 先移动 `odd` 再改 `even.next`，取到的 `odd.next` 已经是新值，偶链断掉。
- 空链表、单节点直接返回 `head`。

**变体与追问**：
- 按值奇偶分组（不是按位置），需要稳定分区。
- 奇偶分离后再合并成"奇偶交替"。
- 追问"能否递归" → 可以但栈深 O(n/2)，迭代更优。

### C-100 两数相加 · 中等 · 字节/腾讯

**题干**：给定两个非空链表，分别表示两个非负整数。数字按逆序存储，每个节点只存一位数字。请将两数相加，并以相同形式返回一个表示和的链表。除数字 0 本身外，两个数都不会以 0 开头。

**示例**：`输入: 2→4→3, 5→6→4`（表示 342 + 465） → `输出: 7→0→8`（表示 807）

**思路**：
- 逐位相加，`sum = x + y + carry`，当前位是 `sum % 10`，新进位是 `Math.floor(sum / 10)`。用哑结点 + 尾插构造结果，避免处理"结果第一位从哪来"。
- 循环条件必须包含 `carry`：两个链表都走完后，最高位的进位还要再补一个节点（如 `5 + 5 = 10`）。长度不等时缺失的一位按 0 处理。
- 为什么不能把链表转成数字再相加：链表可能有上百位，JS 的 Number 只有 53 位安全整数，`BigInt` 虽可但面试官要考的就是进位模拟。

**代码**：
```javascript
function ListNode(val, next = null) { this.val = val; this.next = next; }

function addTwoNumbers(l1, l2) {
  const dummy = new ListNode(0);
  let tail = dummy;
  let carry = 0;
  // carry 参与条件，处理最高位进位
  while (l1 || l2 || carry) {
    const x = l1 ? l1.val : 0;
    const y = l2 ? l2.val : 0;
    const sum = x + y + carry;
    carry = Math.floor(sum / 10);
    tail.next = new ListNode(sum % 10);
    tail = tail.next;
    if (l1) l1 = l1.next;
    if (l2) l2 = l2.next;
  }
  return dummy.next;
}
```

**复杂度**：时间 O(max(m, n)) ／ 空间 O(max(m, n))（结果链表本身）

**易错点**：
- 循环条件漏掉 `carry`，`5 + 5` 只得到 `0`，丢掉最高位 1。
- `carry = sum / 10` 没取整，小数进入下一轮。
- 长度不等时直接取 `l1.val`，短链走空后抛错。
- 用 `Number` 拼接整数，超过 `2^53` 精度丢失。

- 每位只存 0~9，不要假设链表表示的是 32 位整数。

**变体与追问**：
- 数字正序存储（LeetCode 445）：先反转两条链，或改用栈。
- 链表表示二进制求和。
- 追问"不允许修改入参" → 本题只读入参，天然满足；正序版若反转需先拷贝。
