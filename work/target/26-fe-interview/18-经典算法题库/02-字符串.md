# 02 字符串（C-021 ~ C-040）

> 字符串是笔试里「看着简单、写起来全是边界」的一类。前端岗位尤其爱考——因为 JS 的字符串不可变、`split/join` 随手可用，面试官想看的是你**在不能用内置方法时还能不能写出清晰逻辑**。**识别特征**：看到「括号 / 嵌套结构」就要想到栈；看到「回文」就要想到中心扩展或双指针；看到「大数运算」就要想到竖式模拟 + 进位；看到「按格式解析」就要想到一次扫描 + 状态机。

## 题型速查

| 子类型 | 核心手法 | 代表题 |
|---|---|---|
| 栈匹配 | 左括号入栈，右括号与栈顶比对 | C-021、C-031、C-036 |
| 双指针 / 中心扩展 | 以每个中心向两侧扩，或左右对撞 | C-023、C-039 |
| 竖式模拟 | 从低位往前逐位算，进位单独维护 | C-024、C-033、C-034 |
| 扫描式解析 | 一次遍历 + 状态标志 + 边界裁剪 | C-026、C-038 |
| 双向映射 | 两个 Map 互查，防止一对多 | C-029、C-035 |
| 动态规划 | 前 i 个字符能否由字典拼出 | C-030 |
| 规律构造 | 按定义生成下一项 / 按行重排 | C-027、C-028、C-040 |

| KMP | 前缀函数提前记录「失配后回哪」 | C-037 |
| 分段数值比较 | 按 `.` 切段，逐段比数值而非字典序 | C-032 |

### C-021 有效的括号 · 简单 · 字节/阿里/腾讯

**题干**：给定一个只包括 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 `s`，判断字符串是否有效。有效需同时满足：左括号必须用**相同类型**的右括号闭合；左括号必须以**正确的顺序**闭合；每个右括号都有一个对应的同类左括号。

**示例**：`输入: s = "()[]{}"` → `输出: true`；`输入: s = "(]"` → `输出: false`

**思路**：
- 为什么用栈：括号匹配是典型的「后进先出」结构——最近遇到的未闭合左括号，必须最先被闭合。用计数器不行，因为 `"(]"` 数量上平衡但类型不匹配。
- 最优：遇左括号压栈；遇右括号时，栈顶必须是对应的左括号，否则立即返回 `false`。遍历结束后栈必须为空，否则说明还有未闭合的左括号（如 `"(()"`）。
- 剪枝：长度是奇数必然无效，可提前返回，省掉整个遍历。

**代码**：
```javascript
function isValid(s) {
  if (s.length % 2 === 1) return false; // 奇数长度一定不配对

  const pairs = { ')': '(', ']': '[', '}': '{' };
  const stack = [];

  for (const ch of s) {
    if (ch === '(' || ch === '[' || ch === '{') {
      stack.push(ch);
    } else {
      // 栈空时 pop() 返回 undefined，与 pairs[ch] 不等，自然 return false
      if (stack.pop() !== pairs[ch]) return false;
    }
  }
  return stack.length === 0; // 必须全部闭合
}

// 变体：栈里直接存「期望遇到的右括号」，省掉反向查表
function isValidExpected(s) {
  const stack = [];
  const open = { '(': ')', '[': ']', '{': '}' };

  for (const ch of s) {
    if (open[ch]) stack.push(open[ch]);   // 左括号：压入期望的右括号
    else if (stack.pop() !== ch) return false;
  }
  return stack.length === 0;
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- 只判数量平衡（左右各一半）而不判类型与顺序，`"(]"` 会误判为 true。
- 遍历完忘了检查 `stack.length === 0`，`"(()"` 会返回 true。
- 栈空时直接 `stack[stack.length - 1]` 取到 `undefined` 后再比较，逻辑虽对但可读性差。
- 输入可能含其他字符，题目保证只有括号，但工程代码应加白名单校验。

**变体与追问**：
- 最长有效括号（LeetCode 32）：栈里存下标，或 DP / 双向计数。
- 括号生成（LeetCode 22）：回溯，左右括号剩余量约束。
- 若允许多种括号嵌套且有优先级：需扩展为语法分析器（递归下降）。

### C-022 最长公共前缀 · 简单 · 阿里/美团/快手

**题干**：编写一个函数来查找字符串数组中的**最长公共前缀**。如果不存在公共前缀，返回空字符串 `""`。

**示例**：`输入: strs = ["flower","flow","flight"]` → `输出: "fl"`

**思路**：
- 横向扫描：以第一个串为基准前缀，依次与后面的串比较，每次把前缀截断到匹配位置。最坏 O(S)（S 为所有字符总数），实现最直观。
- 纵向扫描：同时比较所有串的第 j 个字符，一旦出现不同或某个串已结束就停。两种复杂度同阶，但纵向扫描在「前缀很短」时更早退出。
- 分治 / 二分：适合海量字符串场景，二分前缀长度可以把比较次数降到 O(S log n)。
- 关键：一旦前缀变成空串就可以立即返回，后面不可能再变长。

**代码**：
```javascript
// 横向扫描：以第一个串为基准，逐步截断
function longestCommonPrefix(strs) {
  if (!strs.length) return '';
  let prefix = strs[0];

  for (let i = 1; i < strs.length; i++) {
    let j = 0;
    while (j < prefix.length && j < strs[i].length && prefix[j] === strs[i][j]) {
      j++;
    }
    prefix = prefix.slice(0, j);
    if (prefix === '') return ''; // 提前退出
  }
  return prefix;
}

// 纵向扫描：逐列比较所有串
function longestCommonPrefixVertical(strs) {
  if (!strs.length) return '';
  for (let j = 0; j < strs[0].length; j++) {
    const ch = strs[0][j];
    for (let i = 1; i < strs.length; i++) {
      if (j >= strs[i].length || strs[i][j] !== ch) {
        return strs[0].slice(0, j);
      }
    }
  }
  return strs[0];
}
```

**复杂度**：时间 O(S)（S 为所有字符串字符总数）／ 空间 O(1)

**易错点**：
- 空数组返回 `''`，不判空则 `strs[0]` 为 `undefined`。
- 数组只有一个元素时结果就是它本身，循环不执行要能自然返回。
- 纵向扫描里 `j >= strs[i].length` 必须放在前面，否则访问越界（JS 得 `undefined`，比较仍成立但语义不清）。
- 用 `strs[0].startsWith(prefix)` 反复判断虽然能过，但复杂度退化。

**变体与追问**：
- 求最长公共**后缀**：把字符串反转后套本题。
- 求最长公共**子串**（非前缀）：需 DP 或后缀数组。
- 海量字符串场景：分治两两求前缀，或二分长度 + 哈希。

### C-023 最长回文子串 · 中等 · 字节/腾讯/美团

**题干**：给定字符串 `s`，找到 `s` 中最长的回文子串。回文指正序与倒序相同的字符串。

**示例**：`输入: s = "babad"` → `输出: "bab"`（`"aba"` 同样是合法答案）

**思路**：
- 暴力：枚举所有子串再判断回文，O(n³)。
- DP：`dp[i][j]` 表示 `s[i..j]` 是否回文，转移 `dp[i][j] = (s[i] === s[j]) && dp[i+1][j-1]`，O(n²) 时间 O(n²) 空间。
- 最优（中心扩展）：回文的特点是「从中心向两侧对称」。回文中心有 `2n - 1` 个——n 个单字符中心（奇数长度）+ n-1 个字符间隙（偶数长度）。以每个中心向两侧扩展，直到字符不同为止，取最长。因为每个中心最多扩 n/2 次，总 O(n²)，但空间只要 O(1)，且常数远小于 DP。
- 关键：**必须同时处理奇偶两种中心**，只扩奇数是本题最常见的错误。

**代码**：
```javascript
function longestPalindrome(s) {
  if (s.length < 2) return s;

  let start = 0;
  let maxLen = 1;

  const expand = (l, r) => {
    while (l >= 0 && r < s.length && s[l] === s[r]) {
      l--;
      r++;
    }
    // 退出时 [l+1, r-1] 是当前中心能扩出的最长回文
    if (r - l - 1 > maxLen) {
      maxLen = r - l - 1;
      start = l + 1;
    }
  };

  for (let i = 0; i < s.length; i++) {
    expand(i, i);     // 奇数长度中心
    expand(i, i + 1); // 偶数长度中心
  }
  return s.slice(start, start + maxLen);
}
```

**复杂度**：时间 O(n²) ／ 空间 O(1)

**易错点**：
- 长度计算写成 `r - l`，多算了 2 个字符，结果截错。
- 只调 `expand(i, i)`，`"cbbd"` 会返回 `"bb"` 之外的错误结果（应为 `"bb"`，若不处理偶数中心会得到 `"b"`）。
- 更新 `maxLen` 只在更大时更新，若用 `>=` 在 `"aaaa"` 上会得到最后一个而不是第一个（一般无碍但要一致）。
- `s.slice` 的第二个参数是**结束下标（不含）**，写成 `start + maxLen - 1` 会少一个字符。

**变体与追问**：
- 回文子串的**个数**（LeetCode 647）：同样的中心扩展，改成累加。
- 最长回文**子序列**（LeetCode 516）：DP，允许不连续，O(n²) 空间。
- Manacher 算法：O(n)，用回文半径数组避免重复扩展，面试中能说清思路即可。

### C-024 字符串相乘 · 中等 · 字节/阿里/拼多多

**题干**：给定两个以字符串形式表示的**非负整数** `num1` 和 `num2`，返回它们的乘积，也用字符串表示。不能使用任何内置的大整数库，也不能直接将输入转为整数。

**示例**：`输入: num1 = "123", num2 = "456"` → `输出: "56088"`

**思路**：
- 为什么不能转数字：JS 的 `Number` 只有 53 位安全整数，两位 100 位的数相乘必然失真。
- 最优（竖式模拟）：结果最多 `m + n` 位。`num1[i]` 与 `num2[j]` 相乘的结果，一定会落在结果的第 `i + j` 和 `i + j + 1` 位上（低位对齐）。用数组 `res` 从低位往高位累加，每次先加上已有值再处理进位，天然避免「多次进位」的复杂逻辑。
- 最后从前往后跳过前导 0 拼成字符串；若全为 0（任一因数为 `"0"`）直接返回 `"0"`。

**代码**：
```javascript
function multiply(num1, num2) {
  if (num1 === '0' || num2 === '0') return '0';

  const m = num1.length, n = num2.length;
  const res = new Array(m + n).fill(0); // 结果最多 m+n 位

  for (let i = m - 1; i >= 0; i--) {
    for (let j = n - 1; j >= 0; j--) {
      const mul = (num1[i] - '0') * (num2[j] - '0');
      const p1 = i + j;      // 高位
      const p2 = i + j + 1;  // 低位
      const sum = mul + res[p2];
      res[p2] = sum % 10;
      res[p1] += Math.floor(sum / 10); // 累加到高位，不立即取模
    }
  }

  let k = 0;
  while (k < res.length - 1 && res[k] === 0) k++; // 跳过前导 0
  return res.slice(k).join('');
}
```

**复杂度**：时间 O(mn) ／ 空间 O(m + n)

**易错点**：
- 高位直接 `res[p1] = Math.floor(sum / 10)` 覆盖而非累加，会丢掉之前内层循环的进位。
- 下标公式写成 `i + j - 1 / i + j`，整体错一位。
- 忘记前导 0 跳过，`"9" × "9"` 会输出 `"081"`。注意 `k < res.length - 1` 保证至少留一位（结果本身是 0 的情况已被前置判断拦住）。
- 用 `parseInt` 或 `Number` 直接算，位数一多就静默失真。

**变体与追问**：
- 字符串相加（C-033）、二进制求和（C-034）：同为竖式，只是进位基数不同。
- 大数阶乘 / 大数幂：复用同一套「数组存每一位」的表示。
- 若允许 BigInt：`String(BigInt(a) * BigInt(b))` 一行，但面试要的是过程。

### C-025 反转字符串中的单词 · 中等 · 字节/美团/阿里

**题干**：给定字符串 `s`，请你反转字符串中**单词的顺序**。单词是由非空格字符组成的序列，`s` 中单词之间至少用一个空格分隔。返回结果中单词用**单个空格**连接，且**不含任何前导或尾随空格**。

**示例**：`输入: s = "  hello world  "` → `输出: "world hello"`

**思路**：
- 工程写法：`trim()` 去掉首尾空格 → `split(/\s+/)` 按任意长度空白切分 → `reverse()` → `join(' ')`。一行搞定，但面试官常追问「不用内置方法怎么写」。
- 手动写法：整体反转后，每个单词内部再反转一次。例如 `"ab cd"` 整体反转为 `"dc ba"`，再逐词反转得 `"cd ab"`。这是经典的双次反转技巧，与 C-005 轮转数组同源。
- 两种写法都要处理「多个连续空格」压缩成一个这一要求。

**代码**：
```javascript
// 写法一：内置方法，工程首选
function reverseWords(s) {
  return s.trim().split(/\s+/).reverse().join(' ');
}

// 写法二：两次反转，不依赖 split/reverse
function reverseWordsManual(s) {
  const chars = s.split(''); // 先转成可变数组
  const reverse = (i, j) => {
    while (i < j) {
      [chars[i], chars[j]] = [chars[j], chars[i]];
      i++;
      j--;
    }
  };

  reverse(0, chars.length - 1); // 1. 整体反转

  let i = 0;
  while (i < chars.length) {
    if (chars[i] === ' ') { i++; continue; }
    let j = i;
    while (j < chars.length && chars[j] !== ' ') j++;
    reverse(i, j - 1);          // 2. 单词内部反转回来
    i = j;
  }

  return chars.join('').trim().replace(/\s+/g, ' '); // 3. 压缩空格
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)（JS 字符串不可变，必然要开辟空间）

**易错点**：
- 用 `split(' ')` 而不是 `split(/\s+/)`，连续空格会产生空字符串元素，结果多出空格。
- 忘记 `trim()`，首尾残留空格。
- 手动版里 `reverse(i, j - 1)` 写成 `reverse(i, j)`，会把空格也反转进来。
- 认为「原地」可行：JS 字符串不可变，`s[0] = 'a'` 静默失败，必须转数组。

**变体与追问**：
- 反转字符串 II（LeetCode 541）：每 2k 个字符反转前 k 个。
- 反转**字符**顺序（LeetCode 344）：双指针对撞，真正的原地（传数组）。
- 追问「JS 里字符串为什么不能原地改」：原始值不可变 + 字符串驻留。

### C-026 字符串转整数 atoi · 中等 · 字节/阿里/美团

**题干**：请你实现 `myAtoi(s)`，将字符串转换为 32 位有符号整数。规则：(1) 忽略前导空格；(2) 读入可选的正负号；(3) 读取后续连续数字，遇到非数字即停止；(4) 若无有效数字转换则为 0；(5) 结果超出 `[-2^31, 2^31 - 1]` 时**饱和截断**到边界值。

**示例**：`输入: "   -42"` → `输出: -42`；`输入: "4193 with words"` → `输出: 4193`

**思路**：
- 典型的状态机式解析：空格 → 符号 → 数字 → 结束，四个阶段顺序固定，一次遍历即可。
- 真正的难点是**溢出判断**。不能先算出结果再和边界比——JS 里 `num * 10 + d` 超过 `2^53` 就已经失真了。必须在**累加之前**判断：若 `num > (INT_MAX - d) / 10`，则加上这一位必然溢出，直接返回边界值。
- 负数一侧的绝对值比正数大 1（`2147483648`），用「先算绝对值、最后乘符号」的写法可以统一处理，边界处返回 `INT_MIN` 即可。

**代码**：
```javascript
function myAtoi(s) {
  const INT_MAX = 2147483647;
  const INT_MIN = -2147483648;
  const n = s.length;
  let i = 0;

  while (i < n && s[i] === ' ') i++;              // 1. 跳过前导空格

  let sign = 1;
  if (i < n && (s[i] === '+' || s[i] === '-')) {  // 2. 读符号
    if (s[i] === '-') sign = -1;
    i++;
  }

  let num = 0;
  while (i < n && s[i] >= '0' && s[i] <= '9') {   // 3. 读数字
    const d = s.charCodeAt(i) - 48;
    // 4. 加这一位之前先判断是否溢出
    if (num > Math.floor((INT_MAX - d) / 10)) {
      return sign === 1 ? INT_MAX : INT_MIN;
    }
    num = num * 10 + d;
    i++;
  }

  return sign * num;                               // 5. 无数字时 num 为 0
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)

**易错点**：
- 用 `parseInt(s)` 一行通关，但 `"4193 with words"` 行为不符，且面试要过程。
- 溢出判断放在累加之后，`"2147483648"` 会被判为不溢出（因为在 JS 里它确实没溢出，但题目要求按 32 位判）。
- 符号后没有数字时（`"-"`、`"+abc"`）应返回 0，不能返回 `-0` 之外的怪值。
- 前导空格只跳 `' '`，`'\t'` 不算（题目只认空格）。
- 用 `s[i] - '0'` 依赖 JS 隐式转换，`'a' - '0'` 得 `NaN`，循环条件里必须先判字符范围。

**变体与追问**：
- 若允许十六进制 / 科学计数法：状态机扩展。
- 浮点版本：多一个「小数点后位数」的计数。
- 追问「JS 里 `Number('2147483648')` 为什么没问题」：`Number` 是 64 位浮点，本题限制的是 32 位语义。

### C-027 外观数列 · 中等 · 腾讯/美团/快手

**题干**：外观数列是一个递归定义的整数序列。从 `1` 开始，每一项都是对前一项的「读法」描述：统计前一项中连续相同数字的**个数**，写成「个数 + 数字」。给定正整数 `n`，返回外观数列的第 `n` 项。

**示例**：`输入: n = 4` → `输出: "1211"`（序列为 1 → 11 → 21 → 1211）

**思路**：
- 这是纯模拟题，没有巧妙算法，考点是**循环边界写得干不干净**。
- 核心是内层「数连续相同字符」的循环：固定起点 `i`，用 `j` 一路右移直到字符变化，则 `(j - i)` 是个数、`s[i]` 是数字，拼成 `count + digit` 后把 `i` 移到 `j`。
- 外层从第 2 项迭代到第 n 项，每轮用新串替换旧串。总复杂度取决于第 n 项的长度，约为 O(1.3^n)，在 `n ≤ 30` 的范围内完全够用。

**代码**：
```javascript
function countAndSay(n) {
  let s = '1';

  for (let k = 2; k <= n; k++) {
    let next = '';
    let i = 0;
    while (i < s.length) {
      let j = i;
      while (j < s.length && s[j] === s[i]) j++; // 找到连续段的右边界
      next += (j - i) + s[i];                    // 个数 + 数字
      i = j;
    }
    s = next;
  }

  return s;
}

// 对照：n = 5 时的中间过程
// 1 -> 11 -> 21 -> 1211 -> 111221
```

**复杂度**：时间 O(L)（L 为第 n 项长度，约 1.3^n）／ 空间 O(L)

**易错点**：
- 外层循环写成 `k = 1`，会多迭代一次，`n = 1` 时返回 `"11"`。
- 内层 `j` 忘记在每轮重置为 `i`，会导致跳字符。
- `next += (j - i) + s[i]` 中若 `j - i` 是数字、`s[i]` 是字符串，`+` 会先做数值加法——这里因为 `(j-i)` 是 number 而 `s[i]` 是 string，实际是 `1 + '1' = '11'`，恰好正确；但如果写成 `s[i] + (j - i)` 就会先拼字符串再算，务必注意运算顺序。
- `n = 1` 时直接返回 `'1'`，不能进循环。

**变体与追问**：
- 逆推：给定第 n 项，求可能的第 1 项（不唯一）。
- 统计「压缩字符串」（LeetCode 443）：原地压缩，双指针写回。
- 追问时间复杂度：第 n 项长度增长率为 Conway 常数 λ ≈ 1.3036。

### C-028 最长回文串（构造） · 简单 · 阿里/字节/美团

**题干**：给定一个包含大写字母和小写字母的字符串 `s`，返回由这些字母构成的最长回文串的**长度**。字母区分大小写。这是一道构造题，只需返回长度。

**示例**：`输入: s = "abccccdd"` → `输出: 7`（可构造 `"dccaccd"`）

**思路**：
- 回文串的结构是「左右对称」：除最中心的字符外，每个字符都必须成对出现。
- 于是统计每个字符的出现次数：偶数次可以全部用上；奇数次只能用 `count - 1` 个（留下一个不用）。
- 最后如果存在至少一个奇数次字符，可以从里面挑一个放在正中间，长度再 +1。注意**最多只能加 1**，不能把多个奇数都塞进去。
- 关键结论：答案 = 所有字符的「偶数部分之和」+（存在奇数 ? 1 : 0）。

**代码**：
```javascript
function longestPalindrome(s) {
  const cnt = new Map();
  for (const ch of s) {
    cnt.set(ch, (cnt.get(ch) || 0) + 1);
  }

  let len = 0;
  let hasOdd = false;

  for (const c of cnt.values()) {
    len += c - (c % 2);   // 偶数全留，奇数丢掉一个
    if (c % 2 === 1) hasOdd = true;
  }

  return hasOdd ? len + 1 : len; // 中心最多放一个
}

// 变体：真的把回文串构造出来（同长度下取一种字典序较小的）
function buildLongestPalindrome(s) {
  const cnt = new Map();
  for (const ch of s) cnt.set(ch, (cnt.get(ch) || 0) + 1);

  const keys = [...cnt.keys()].sort();
  let left = '';
  let mid = '';
  for (const ch of keys) {
    const c = cnt.get(ch);
    left += ch.repeat(Math.floor(c / 2));  // 成对的部分放两侧
    if (c % 2 === 1 && mid === '') mid = ch;
  }
  return left + mid + [...left].reverse().join('');
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)（字符集大小 ≤ 128）

**易错点**：
- 每个奇数字符都 +1，`"aaa"` 会得到 5（正确答案是 3）。
- 用 `len += c` 然后判断 `len % 2`，逻辑绕且易错。
- 大小写不合并，`'A'` 与 `'a'` 是不同字符，不能统一转小写。
- 空串返回 0，`hasOdd` 为 false 时直接返回 `len`，逻辑自然成立。

**变体与追问**：
- 用这些字符**构造出**具体的回文串：需要记录可用于中心的字符。
- 回文子串 vs 回文子序列：前者连续、后者可跳，是完全不同的题。
- 若要求最长回文串**字典序最小**：在长度固定后按字母序排半串。

### C-029 同构字符串 · 简单 · 字节/腾讯/快手

**题干**：给定两个字符串 `s` 和 `t`，判断它们是否是**同构**的。若 `s` 中的字符可以按某种映射关系替换得到 `t`，那么两个字符串同构。每个字符只能映射到另一个字符，不同字符不能映射到同一字符，字符可以映射到自己。

**示例**：`输入: s = "egg", t = "add"` → `输出: true`；`输入: s = "foo", t = "bar"` → `输出: false`

**思路**：
- 本题的核心约束是「**双向唯一**」：`s → t` 必须是一一映射，`t → s` 也必须是一一映射。
- 只维护一个方向的 Map 是不够的：`s = "ab", t = "cc"` 中 `a→c, b→c` 单向合法，但两个字符映射到同一个 `c`，违反「不同字符不能映射到同一字符」。
- 所以要建两张表互查，或者用「编码」技巧：把 s 和 t 各自转成「首次出现位置序列」，比较两个序列是否相同（如 `"egg"` → `[0,1,1]`，`"add"` → `[0,1,1]`）。
- 编码法的好处是把双向映射压缩成单次比较，逻辑更短。

**代码**：
```javascript
// 写法一：双向 Map 互查
function isIsomorphic(s, t) {
  if (s.length !== t.length) return false;
  const st = new Map(); // s 的字符 -> t 的字符
  const ts = new Map(); // t 的字符 -> s 的字符

  for (let i = 0; i < s.length; i++) {
    const a = s[i], b = t[i];
    if (st.has(a) && st.get(a) !== b) return false; // 一个 s 字符映射到两个 t 字符
    if (ts.has(b) && ts.get(b) !== a) return false; // 两个 s 字符映射到同一个 t 字符
    st.set(a, b);
    ts.set(b, a);
  }
  return true;
}

// 写法二：比较「首次出现位置」序列
function isIsomorphicByIndex(s, t) {
  const enc = (str) => {
    const first = new Map();
    return [...str].map((ch, i) => {
      if (!first.has(ch)) first.set(ch, i);
      return first.get(ch);
    }).join(',');
  };
  return enc(s) === enc(t);
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)（字符集有限）

**易错点**：
- 只用一张 Map，`"ab" / "cc"` 会被判为 true。
- 长度不同未提前返回，后面按下标取值会得到 `undefined`。
- 用 `Object` 当 Map 时 `'__proto__'` 之类键冲突（本题限字符，但工程代码要注意）。
- 编码法用 `charCodeAt` 拼接时没加分隔符，`[1,23]` 与 `[12,3]` 会撞。

**变体与追问**：
- 单词规律（LeetCode 290）：把字符换成单词，同样双向映射。
- 有效的字母异位词（C-035）：要求字符集合与频次完全相同，比同构更强。
- 追问「为什么单向不够」：举 `"ab" → "cc"` 反例。

### C-030 单词拆分 · 中等 · 字节/阿里/拼多多

**题干**：给定字符串 `s` 和一个字符串列表 `wordDict` 作为字典，判断 `s` 是否可以被空格拆分为一个或多个在字典中出现的单词。字典中的单词可以重复使用。

**示例**：`输入: s = "leetcode", wordDict = ["leet","code"]` → `输出: true`

**思路**：
- 朴素：回溯枚举所有切分点，指数级，遇到 `"aaaa...aab"` 这类用例直接超时。
- 最优（DP）：定义 `dp[i]` 表示「`s` 的前 i 个字符能否被拆完」。`dp[0] = true`（空前缀视为可拆）。转移：枚举最后一个单词的起点 j，若 `dp[j]` 为真且 `s[j..i)` 在字典中，则 `dp[i] = true`。
- 这个状态定义的关键是「以 i 结尾」——它把「一段区间是否合法」和「前缀是否可达」解耦，避免了记忆化搜索里对起点、终点的双重枚举。
- 优化：内层 j 只需从 `i - maxWordLen` 开始枚举，因为单词长度不会超过字典中最长的词。

**代码**：
```javascript
function wordBreak(s, wordDict) {
  const set = new Set(wordDict);
  const n = s.length;
  const dp = new Array(n + 1).fill(false);
  dp[0] = true; // 空串可拆

  let maxLen = 0;
  for (const w of wordDict) maxLen = Math.max(maxLen, w.length);
  if (maxLen === 0) return s.length === 0;

  for (let i = 1; i <= n; i++) {
    // j 只需回看 maxLen 个字符
    for (let j = Math.max(0, i - maxLen); j < i; j++) {
      if (dp[j] && set.has(s.slice(j, i))) {
        dp[i] = true;
        break; // 找到一个切分即可
      }
    }
  }
  return dp[n];
}
```

**复杂度**：时间 O(n² · L)（`slice` 与哈希各需 O(L)，加 maxLen 剪枝后为 O(n · maxLen · L)）／ 空间 O(n)

**易错点**：
- `dp[0] = false`，整个表永远为 false。
- 内层循环写成 `j <= i`，会产生长度为 0 的空单词。
- 不做 maxLen 剪枝，超长字符串用例会严重超时。
- `wordDict` 含重复单词时不先去重，Set 天然解决，但要记得转 Set 而不是用 `includes`（O(k) 查询）。
- 返回 `dp[n]` 而不是 `dp[n-1]`，`dp` 长度是 `n + 1`。

**变体与追问**：
- 单词拆分 II（LeetCode 140）：要求返回**所有**切分方案，需 DP + 回溯或记忆化。
- 若字典很小而 s 很长：用 Trie 替代 Set，可提前剪掉不可能的前缀。
- 追问「为什么不用贪心（每次取最长匹配）」：反例 `s = "catsandog"`，字典含 `"cats"` 与 `"cat"`。

### C-031 字符串解码 · 中等 · 字节/腾讯/美团

**题干**：给定一个经过编码的字符串，返回它解码后的字符串。编码规则为 `k[encoded_string]`，表示方括号内部的 `encoded_string` 重复 `k` 次。`k` 保证为正整数。输入保证是合法的，且不含多余空格。方括号可以嵌套。

**示例**：`输入: s = "3[a]2[bc]"` → `输出: "aaabcbc"`

**思路**：
- 嵌套结构 + 「遇到 `]` 要回到上一层」——天然的栈模型。
- 用两个栈分别存「重复次数」和「进入括号前的已有字符串」：遇 `[` 时把当前的 `num` 和 `cur` 压栈，然后清零重新开始收集；遇 `]` 时弹出 `k` 和 `prefix`，把 `cur` 重复 `k` 次后拼回 `prefix`。
- 关键细节：`k` 可能是**多位数**（如 `"10[a]"`），必须用 `num = num * 10 + digit` 累积，不能一位一位处理。
- 也可以只用一个栈存 `[次数, 前缀]` 的元组，本质相同。

**代码**：
```javascript
function decodeString(s) {
  const numStack = [];  // 待用的重复次数
  const strStack = [];  // 进入括号前已累积的字符串
  let cur = '';
  let num = 0;

  for (const ch of s) {
    if (ch >= '0' && ch <= '9') {
      num = num * 10 + (ch.charCodeAt(0) - 48); // 处理多位数
    } else if (ch === '[') {
      numStack.push(num);
      strStack.push(cur);
      num = 0;
      cur = '';
    } else if (ch === ']') {
      const k = numStack.pop();
      const prefix = strStack.pop();
      cur = prefix + cur.repeat(k); // 重复后接回外层前缀
    } else {
      cur += ch;                    // 普通字母
    }
  }

  return cur;
}
```

**复杂度**：时间 O(输出长度) ／ 空间 O(嵌套深度 + 输出长度)

**易错点**：
- `num` 只在遇 `[` 时清零；若在 `]` 处清零，`"3[a]2[bc]"` 的第二段会算错。
- 多位数字未累积，`"10[a]"` 会解成 `"aaaaaaaaaa"` 之外的错误结果（变成 `"a"` 重复 1 次再拼 0 次）。
- `]` 处忘记拼回 `prefix`，只做了 `cur.repeat(k)`，外层内容丢失。
- 用递归写法时忘记 `i` 的推进，导致死循环。

**变体与追问**：
- 编码（反向过程）：需要判断何时值得用 `k[...]`，属于压缩算法。
- 括号嵌套深度：只需计数，不需要栈。
- 若允许 `k` 为 0：`0[abc]` 应输出空串，`repeat(0)` 天然支持。

### C-032 比较版本号 · 中等 · 字节/阿里/快手

**题干**：给定两个版本号 `version1` 和 `version2`，比较它们。版本号由以 `.` 连接的若干修订号组成，每个修订号由数字组成，可能包含前导零。比较时按从左到右逐段比较**整数值**，忽略前导零；若某版本号段数较少，缺失的段视为 0。返回 `1`（v1 > v2）、`-1`（v1 < v2）或 `0`。

**示例**：`输入: version1 = "1.01", version2 = "1.001"` → `输出: 0`；`输入: "1.0", "1.0.0"` → `0`

**思路**：
- 最直接的坑：按字符串比较会得出 `"1.10" < "1.9"`（字典序），必须转成数值比较。
- 分段后逐段比数值，缺段补 0，一旦分出大小立即返回；全部相等返回 0。
- 更省空间的做法是双指针原地扫描：不 `split`，用两个指针各自跳过 `.` 并累加当前段的数值，扫完一段比一段。适合版本号极长时避免数组开销。

**代码**：
```javascript
// 写法一：分段 + 数值比较，最直观
function compareVersion(version1, version2) {
  const a = version1.split('.');
  const b = version2.split('.');
  const n = Math.max(a.length, b.length);

  for (let i = 0; i < n; i++) {
    // 缺失段补 0；parseInt 自动忽略前导零
    const x = parseInt(a[i] || '0', 10);
    const y = parseInt(b[i] || '0', 10);
    if (x > y) return 1;
    if (x < y) return -1;
  }
  return 0;
}

// 写法二：双指针原地扫描，O(1) 额外空间
function compareVersionTwoPointer(v1, v2) {
  let i = 0, j = 0;
  while (i < v1.length || j < v2.length) {
    let x = 0, y = 0;
    while (i < v1.length && v1[i] !== '.') x = x * 10 + (v1.charCodeAt(i++) - 48);
    while (j < v2.length && v2[j] !== '.') y = y * 10 + (v2.charCodeAt(j++) - 48);
    if (x !== y) return x > y ? 1 : -1;
    i++; // 跳过 '.'
    j++;
  }
  return 0;
}
```

**复杂度**：时间 O(max(m, n)) ／ 空间 O(m + n)（双指针版 O(1)）

**易错点**：
- 用字符串直接比：`"1.10"` vs `"1.9"` 会判错。
- 忘记缺失段补 0：`"1.0"` 与 `"1"` 比较时，短的一方循环提前结束，但长的一方剩余段全是 0，结果应是 0。
- `parseInt` 不传基数在某些引擎上有历史坑，统一传 `10`。
- 前导零导致长度不同（`"01"` vs `"1"`），必须转数值而不是比长度。

**变体与追问**：
- 版本号排序：把比较函数作为 `sort` 的 comparator。
- 若版本号超过 `2^53`：需逐位比较或 BigInt。
- 追问「语义化版本 `1.2.3-beta`」：需额外解析预发布标识，规则由 semver 规范定义。

### C-033 字符串相加 · 简单 · 阿里/字节/美团

**题干**：给定两个字符串形式的非负整数 `num1` 和 `num2`，计算它们的和并以字符串形式返回。不能使用任何内置的大整数库，也不能直接将输入转为整数。

**示例**：`输入: num1 = "11", num2 = "123"` → `输出: "134"`

**思路**：
- 小学数学竖式：从最低位开始逐位相加，`carry` 记录进位，每一位结果是 `(x + y + carry) % 10`，新进位是 `Math.floor(sum / 10)`。
- 循环条件要包含 `carry`——最高位相加可能产生新进位（`"9" + "1"` → `"10"`），若只按长度循环就会丢掉最高位的 1。
- 两个串长度不一定相同，取不到的那一位按 0 处理。
- 结果逆序收集后翻转，避免反复 `unshift` 造成 O(n²)。
- 另一个隐蔽的坑：JS 里 `'9' + 1` 是字符串拼接 `"91"`，所以取位时必须先转成数值再相加，否则 `sum` 直接变成一个字符串，后面 `% 10` 还可能因隐式转换而"看起来能跑"，酿成静默错误。

**代码**：
```javascript
function addStrings(num1, num2) {
  let i = num1.length - 1;
  let j = num2.length - 1;
  let carry = 0;
  const digits = [];

  while (i >= 0 || j >= 0 || carry > 0) {
    const x = i >= 0 ? num1.charCodeAt(i) - 48 : 0;
    const y = j >= 0 ? num2.charCodeAt(j) - 48 : 0;
    const sum = x + y + carry;

    digits.push(sum % 10);         // 本位
    carry = Math.floor(sum / 10);  // 进位

    i--;
    j--;
  }

  return digits.reverse().join('');
}
```

**复杂度**：时间 O(max(m, n)) ／ 空间 O(max(m, n))

**易错点**：
- 循环条件漏掉 `carry > 0`，`"9" + "1"` 返回 `"0"`。
- 用 `num1[i] - 0` 依赖隐式转换，`i < 0` 时是 `undefined - 0 = NaN`，必须先判边界。
- 用 `unshift` 头插，复杂度退化到 O(n²)。
- 输入可能有前导零（`"001"`），结果不应带前导零——本题两数都非负且常规输入，但工程上要 `replace(/^0+(?=\d)/, '')`。

**变体与追问**：
- 字符串相乘（C-024）：双重循环 + 位置映射，是本题的升级版。
- 二进制求和（C-034）：进位基数改为 2。
- 链表两数相加（LeetCode 2）：数据存在链表里，倒序存储更自然。

### C-034 二进制求和 · 简单 · 腾讯/美团/快手

**题干**：给定两个二进制字符串 `a` 和 `b`，以二进制字符串的形式返回它们的和。

**示例**：`输入: a = "11", b = "1"` → `输出: "100"`

**思路**：
- 与十进制相加（C-033）完全同构，只是进位基数从 10 变成 2。
- 本位结果 = `(x + y + carry) % 2`，可用位运算 `& 1` 代替取模；新进位 = `Math.floor(sum / 2)`，可用 `>> 1`。
- 同样要处理长度不等与最高位进位。
- 注意：JS 的位运算会先把操作数转成 **32 位有符号整数**，本题单次 `sum` 最大为 3，完全在安全范围内，可以放心用位运算；但如果是大整数场景就不能偷这个懒。
- 为什么不能 `parseInt(a, 2) + parseInt(b, 2)` 再 `toString(2)`：一旦位数超过 53 位，`parseInt` 返回的 number 就已经失真，结果会静默错误——这正是本题要求「按字符模拟」的原因。

**代码**：
```javascript
function addBinary(a, b) {
  let i = a.length - 1;
  let j = b.length - 1;
  let carry = 0;
  const bits = [];

  while (i >= 0 || j >= 0 || carry > 0) {
    const x = i >= 0 ? a.charCodeAt(i) - 48 : 0;
    const y = j >= 0 ? b.charCodeAt(j) - 48 : 0;
    const sum = x + y + carry;

    bits.push(sum & 1);           // 本位：等价于 sum % 2
    carry = sum >> 1;             // 进位：等价于 floor(sum / 2)

    i--;
    j--;
  }

  return bits.reverse().join('');
}
```

**复杂度**：时间 O(max(m, n)) ／ 空间 O(max(m, n))

**易错点**：
- 用 `parseInt(a, 2)` 直接转数字，长串会精度丢失（`parseInt` 返回 number）。
- 循环漏 `carry`，`"1" + "1"` 返回 `"0"`。
- `sum & 1` 写成 `sum & 2`，取到的是进位位。
- 结果数组忘 `reverse()`，输出是反的。
- 把 `carry` 初始化成 `''` 或 `undefined`，`sum` 会变成 `NaN`，整个结果变成 `"NaN"`。
- 输入可能有前导零（`"0011"`），按位模拟不会产生前导零，但若不从右往左对齐而是从左往右，会把最高位和最低位弄反。

**变体与追问**：
- 十进制版本（C-033）：只改基数。
- 二进制转十进制：`reduce((acc, c) => acc * 2 + (+c), 0)`，注意精度。
- 若要求不使用 `+` 运算符（LeetCode 371）：用位运算实现加法。

### C-035 有效的字母异位词 · 简单 · 字节/阿里/腾讯

**题干**：给定两个字符串 `s` 和 `t`，编写一个函数来判断 `t` 是否是 `s` 的字母异位词。字母异位词指两个字符串中**每个字符出现的次数都相同**（字符顺序可以不同）。

**示例**：`输入: s = "anagram", t = "nagaram"` → `输出: true`；`输入: "rat", "car"` → `false`

**思路**：
- 暴力：给两个串排序后比较，O(n log n)，代码最短但没利用「只关心频次」这一信息。
- 最优：用哈希表（或长度 26 的数组）统计 `s` 的字符频次，再遍历 `t` 逐个扣减；若某个字符不在表中或扣成负数，立即返回 false；最后表必须为空。
- 优化点：长度不同可直接返回 false，省掉全部统计。
- 若字符集限定小写字母，用长度 26 的 `Int32Array` 比 Map 更快，也避免哈希开销。

**代码**：
```javascript
// 写法一：哈希表，适配任意 Unicode 字符
function isAnagram(s, t) {
  if (s.length !== t.length) return false;

  const cnt = new Map();
  for (const ch of s) cnt.set(ch, (cnt.get(ch) || 0) + 1);

  for (const ch of t) {
    const v = cnt.get(ch);
    if (!v) return false;      // 不存在或已扣完
    if (v === 1) cnt.delete(ch);
    else cnt.set(ch, v - 1);
  }
  return cnt.size === 0;
}

// 写法二：限定小写字母，用定长数组，常数更小
function isAnagramLower(s, t) {
  if (s.length !== t.length) return false;
  const cnt = new Int32Array(26);
  for (let i = 0; i < s.length; i++) {
    cnt[s.charCodeAt(i) - 97]++;
    cnt[t.charCodeAt(i) - 97]--;
  }
  return cnt.every((v) => v === 0);
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)（字符集大小 26 或有限）

**易错点**：
- 只比较排序后的结果却忘记处理 Unicode：`[...s].sort()` 才行，`s.split('')` 会把代理对拆坏。
- 扣减时写成 `if (v <= 0) return false`，`v` 为 `undefined` 时比较结果为 false，漏判不存在的情况。
- 长度不同未提前返回，仍能得出正确结果但多做一倍工作。
- 数组版下标用 `charCodeAt(i) - 96`（差一），会整体错位。

**变体与追问**：
- 若字符含 Unicode：用 `[...s]` 按码点拆分，Map 统计。
- 字母异位词分组（LeetCode 49）：用排序后的串或频次数组作 key。
- 找到字符串中所有字母异位词（LeetCode 438）：定长滑动窗口 + 频次比较。

### C-036 简化路径 · 中等 · 字节/阿里/美团

**题干**：给定一个 Unix 风格的绝对路径 `path`，将其简化为**规范路径**。规则：多个连续斜杠视为单个；`.` 表示当前目录，可忽略；`..` 表示上级目录，需弹出上一级（若已在根目录则忽略）；结果必须以 `/` 开头，且不含结尾的 `/`，根目录为 `/`。

**示例**：`输入: path = "/a/./b/../../c/"` → `输出: "/c"`

**思路**：
- 分层处理：按 `/` 切分后，每一段只有三种语义——空串或 `.`（忽略）、`..`（弹栈）、普通目录名（压栈）。
- 用栈保存「当前路径的各级目录」，处理完后用 `/` 连接，前面补一个 `/`。
- 为什么栈合适：`..` 的语义是「回到**最近一层**」，正好对应栈的 LIFO。
- `".."` 在根目录时应该忽略而不是报错，`[].pop()` 返回 `undefined` 且不报错，天然安全——但工程代码里最好显式判空，意图更清晰。

**代码**：
```javascript
function simplifyPath(path) {
  const stack = []; // 当前路径的各级目录

  for (const seg of path.split('/')) {
    if (seg === '' || seg === '.') {
      continue;               // 连续斜杠、当前目录：直接跳过
    }
    if (seg === '..') {
      if (stack.length) stack.pop(); // 已在根目录则忽略
    } else {
      stack.push(seg);        // 普通目录名（含 "..." 这类合法名）
    }
  }

  return '/' + stack.join('/'); // 栈空时即 "/"
}

// 变体：只做解析、返回各级目录，拼装交给调用方（便于单元测试）
function simplifyPathSegments(path) {
  const stack = [];
  for (const seg of path.split('/')) {
    if (!seg || seg === '.') continue;
    if (seg === '..') {
      if (stack.length) stack.pop();
      continue;
    }
    stack.push(seg);
  }
  return stack;
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- 用 `path.split('/').filter(Boolean)` 后忘记 `..` 也要参与逻辑，先过滤再判断顺序错乱。
- 把 `"..."` 也当成 `..` 处理，实际它是合法目录名。
- 结果用 `'/' + stack.join('/')` 而不是 `stack.join('/') + '/'`，后者会多出尾部斜杠。
- `stack.pop()` 不判空，在空栈上虽不报错但语义不明；若改成 `stack.length--` 就会出负长度。

**变体与追问**：
- 相对路径解析：需结合当前工作目录先转绝对路径。
- 若要求支持通配符 `*`：需要 glob 匹配，本质是另一套逻辑。
- 追问「为什么不用字符串拼接 + 回溯」：`..` 需要删除「最后一整段」，字符串操作是 O(n)，栈是 O(1)。

### C-037 实现 strStr() · 中等 · 字节/腾讯/快手

**题干**：给定两个字符串 `haystack` 和 `needle`，在 `haystack` 中找出 `needle` 第一次出现的下标，不存在则返回 `-1`；若 `needle` 为空串则返回 `0`。

**示例**：`输入: haystack = "sadbutsad", needle = "sad"` → `输出: 0`

**思路**：
- 朴素（BF）：外层枚举起点，内层逐字符比较，最坏 O(mn)（如 `"aaaaab"` 找 `"aaab"`），每失配一次就把起点只后移一位，前面的比较信息全丢了。
- KMP 的核心：失配时不要回退主串指针，而是让模式串「跳到某个位置继续比」。跳到哪里由 `next` 数组决定——`next[i]` 表示 `needle[0..i]` 的**最长相等真前缀后缀**长度。因为这段前缀和后缀相同，把模式串右移到前缀对齐后缀的位置，前面这部分就一定已经匹配，无需重比。
- 构建 `next` 的过程本身就是「自己匹配自己」，用同一个失配回跳逻辑。

**代码**：
```javascript
function strStr(haystack, needle) {
  if (needle === '') return 0;
  const m = needle.length;

  // 1. 构建 next：next[i] = needle[0..i] 的最长相等前后缀长度
  const next = new Array(m).fill(0);
  for (let i = 1, k = 0; i < m; i++) {
    while (k > 0 && needle[i] !== needle[k]) k = next[k - 1]; // 失配回跳
    if (needle[i] === needle[k]) k++;
    next[i] = k;
  }

  // 2. 匹配：主串指针 i 永不回退
  for (let i = 0, k = 0; i < haystack.length; i++) {
    while (k > 0 && haystack[i] !== needle[k]) k = next[k - 1];
    if (haystack[i] === needle[k]) k++;
    if (k === m) return i - m + 1; // 完整匹配，返回起点
  }

  return -1;
}
```

**复杂度**：时间 O(n + m) ／ 空间 O(m)

**易错点**：
- 回跳写成 `k = next[k]`，会越界；必须是 `next[k - 1]`。
- `next` 定义成「含自身的 border」而不是「真前缀」，边界处理会整体偏移一位。
- 匹配成功后忘记返回，继续匹配会得到最后一次出现的位置。
- `needle` 为空串时返回 `-1`，而题目要求返回 `0`。
- `k === m` 判断放在 `if (haystack[i] === needle[k])` 之前，最后一次匹配会被漏掉。

**变体与追问**：
- 找**所有**出现位置：匹配成功后 `k = next[k - 1]` 继续。
- 最短循环节：`m - next[m-1]` 若不是 m 的因数则无循环节。
- 追问「什么时候用 KMP、什么时候用 Rabin-Karp」：单模式长文本用 KMP，多模式用 AC 自动机，允许哈希碰撞风险时 RK 更快。

### C-038 最后一个单词的长度 · 简单 · 阿里/美团/拼多多

**题干**：给定一个由单词和空格组成的字符串 `s`，返回字符串中**最后一个单词的长度**。单词指仅由字母组成、不包含任何空格字符的最大子字符串。

**示例**：`输入: s = "Hello World"` → `输出: 5`；`输入: "   fly me   to   the moon  "` → `输出: 4`

**思路**：
- 工程写法：`s.trim().split(/\s+/).pop().length`，一行完成。
- 面试写法：从尾部扫描。先跳过尾部空格，再往前数到下一个空格为止，两段循环都是 O(尾部长度)，不需要额外空间，也不用处理中间的多余空格——因为我们根本不看中间。
- 这是「从尾部反向扫描」的典型应用：题目问最后一个，从后往前找比从前往后找更自然。

**代码**：
```javascript
// 写法一：内置方法，可读性最好
function lengthOfLastWord(s) {
  return s.trim().split(/\s+/).pop().length;
}

// 写法二：从尾部扫描，O(1) 空间
function lengthOfLastWordScan(s) {
  let i = s.length - 1;

  while (i >= 0 && s[i] === ' ') i--;  // 1. 跳过尾部空格
  const end = i;                        // 最后一个单词的末字符下标

  while (i >= 0 && s[i] !== ' ') i--;  // 2. 往前找到单词前的空格
  return end - i;                       // 长度 = 末字符 - 起点前一位
}

// 变体：一次正向扫描，返回每个单词的长度
function wordLengths(s) {
  const res = [];
  let i = 0;
  while (i < s.length) {
    if (s[i] === ' ') {
      i++;
      continue;                          // 跳过连续空格
    }
    let j = i;
    while (j < s.length && s[j] !== ' ') j++;
    res.push(j - i);
    i = j;
  }
  return res;
}
```

**复杂度**：时间 O(n) ／ 空间 O(1)（写法二）

**易错点**：
- 用 `split(' ')` 不处理连续空格，`pop()` 可能取到空字符串，长度为 0。
- 忘记 `trim()`，`"a "` 会返回 0。
- 反向扫描时 `end - i` 的 `i` 是「单词前一个位置」，若单词在开头则 `i = -1`，`end - (-1)` 恰好是长度，逻辑自洽但要能说清。
- 字符串全为空格时 `end` 为 -1，结果 0，符合预期。

**变体与追问**：
- 求第一个单词的长度：正向扫描。
- 求每个单词的长度：一次遍历 + 状态标记。
- 追问「为什么不用正则 `/\w+$/`」：正则在超长串上有回溯风险，且本题两种写法都是线性。

### C-039 反转字符串中的元音字母 · 简单 · 腾讯/美团/字节

**题干**：给定字符串 `s`，仅反转字符串中的**所有元音字母**（`a`、`e`、`i`、`o`、`u`，含大小写），辅音字母和空格位置保持不变。

**示例**：`输入: s = "hello"` → `输出: "holle"`；`输入: "leetcode"` → `"leotcede"`

**思路**：
- 由于 JS 字符串不可变，先转成字符数组。
- 左右双指针向中间收：左指针跳过非元音，右指针跳过非元音，两者都停在元音上就交换；若 `l >= r` 说明已无更多可交换的元音，结束。
- 关键：内层跳过的 `while` 必须带 `l < r` 边界，否则像 `"bcdfg"` 这种全辅音的串会让指针一路跑出数组。
- 时间复杂度 O(n)、空间 O(n)（数组）。

**代码**：
```javascript
function reverseVowels(s) {
  const isVowel = (ch) => 'aeiouAEIOU'.includes(ch);
  const a = s.split('');
  let l = 0;
  let r = a.length - 1;

  while (l < r) {
    while (l < r && !isVowel(a[l])) l++;  // 左指针找元音
    while (l < r && !isVowel(a[r])) r--;  // 右指针找元音
    if (l < r) {
      [a[l], a[r]] = [a[r], a[l]];
      l++;
      r--;
    }
  }

  return a.join('');
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- 内层 `while` 不带 `l < r`，全辅音串会越界（JS 得 `undefined`，`includes` 返回 false，死循环）。
- 用 `switch` 或正则漏掉大写元音，`"A man"` 会算错。
- 交换后忘记 `l++ / r--`，两指针停在原地死循环。
- 直接把 `s` 当数组改（`s[l] = ...`），严格模式下抛错、非严格模式静默失败。
- 用 `Set` 存元音可以，但 `includes` 对 10 个字符的常量串来说更快，也避免每次新建集合。

**变体与追问**：
- 反转字符串（C-025 的姊妹题）：所有字符都交换。
- 只反转**数字**或只反转**字母**：换 `isVowel` 判定即可。
- 若要求保持元音大小写位置：题目默认「交换字符本身」，大小写随字符走，无需特殊处理。

### C-040 Z 字形变换 · 中等 · 字节/阿里/快手

**题干**：将一个给定字符串 `s` 根据给定的行数 `numRows`，以从上往下、从左到右进行 Z 字形排列（实际是「竖着走再斜着回」的 N 字形）。之后逐行读取，返回新的字符串。

**示例**：`输入: s = "PAYPALISHIRING", numRows = 3` → `输出: "PAHNAPLSIIGYIR"`

**思路**：
- 不要真的去构造二维矩阵——那要 O(n × numRows) 空间且下标换算极易错。
- 换个视角：给每个字符标上「它属于第几行」，然后按行收集。行走的轨迹是「向下 → 到底后向上 → 到顶后再向下」，等价于一个方向变量 `step` 在 `+1 / -1` 之间切换，碰到边界就反向。
- 用 `numRows` 个数组分别收集各行字符，最后顺序拼接。时间 O(n)、空间 O(n)，代码只有十几行且不会错下标。
- 两个边界：`numRows === 1` 时 `step` 永远为 +1 会越界，必须提前返回；`numRows >= n` 时每行只有一个字符，结果就是原串。

**代码**：
```javascript
function convert(s, numRows) {
  if (numRows === 1 || numRows >= s.length) return s;

  const rows = Array.from({ length: numRows }, () => []);
  let r = 0;      // 当前行
  let step = 1;   // 1 向下，-1 向上

  for (const ch of s) {
    rows[r].push(ch);
    if (r === 0) step = 1;                  // 撞顶，转向下
    else if (r === numRows - 1) step = -1;  // 撞底，转向上
    r += step;
  }

  return rows.map((row) => row.join('')).join('');
}

// 变体：按周期公式直接定位行号，不模拟方向
function convertByFormula(s, numRows) {
  if (numRows === 1 || numRows >= s.length) return s;
  const n = s.length;
  const cycle = 2 * numRows - 2;  // 一个完整「竖 + 斜」的周期
  let res = '';

  for (let r = 0; r < numRows; r++) {
    for (let i = r; i < n; i += cycle) {
      res += s[i];                          // 竖线上的字符
      const diag = i + cycle - 2 * r;       // 斜线上的字符
      if (r !== 0 && r !== numRows - 1 && diag < n) res += s[diag];
    }
  }
  return res;
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- `numRows === 1` 未提前返回，`r` 会一路加到 `numRows` 越界报错。
- 方向切换写在内层循环开头，第一个字符就被放错行。
- 用 `r === 0` 判断后立刻 `step = 1`，紧接着又执行 `r += step`，逻辑正确但若放在 `push` 之前就会错位。
- 返回时用 `rows.flat()` 再 `join('')` 也可以，但注意 `flat` 深度。
- 认为 Z 字形是「按列蛇形」，实际是「竖向 + 斜向」，画一遍 4 行的图就能确认。

**变体与追问**：
- 按 Z 字形**还原**原串：需要按行反推每行的字符数，再回填。
- 之字形层序遍历二叉树（LeetCode 103）：同样的 `step` 反向思想。
- 追问「能否 O(1) 空间直接算下标」：可以，第 `k` 个字符的行号是周期函数，但可读性差。
