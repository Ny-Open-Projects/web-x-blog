# 06 栈与单调栈（C-101 ~ C-120）

> 栈的题面通常只有一句话，考点全在"什么时候压、什么时候弹"。**识别特征**：看到"下一个更大/更小""左右第一个比它矮""去掉 k 位使字典序最小""括号匹配"，先想单调栈；看到"最近一次未匹配""表达式"，先想普通栈。

## 题型速查

| 子类型 | 核心手法 | 代表题 |
|---|---|---|
| 栈结构设计 | 辅助栈同步最值、双栈倒序 | C-101 / C-102 |
| 表达式求值 | 操作数栈、按优先级就地结算 | C-104 / C-106 |
| 单调栈求边界 | 维护递减/递增序列，弹出即结算 | C-107 / C-110 |
| 贪心 + 栈 | 弹栈前先看"后面还有没有" | C-111 / C-112 |
| 栈模拟 | 出栈序列验证、惰性展开、碰撞 | C-113 / C-116 |

### C-101 最小栈 · 简单 · 字节/阿里

**题干**：设计一个支持 `push`、`pop`、`top`、`getMin` 四种操作且所有操作均为 O(1) 的栈。`getMin` 返回当前栈中的最小元素。请在空栈上调用 `pop`、`top`、`getMin` 视为非法输入，不需要处理。

**示例**：`push(-2); push(0); push(-3); getMin() → -3; pop(); top() → 0; getMin() → -2`

**思路**：
- 只用一个变量记录最小值是不够的：当最小值被 `pop` 掉后，无法知道"上一个最小值"是谁，除非重新扫描，那就不是 O(1)。
- 辅助栈与主栈同步增长：`mins[i]` 存"主栈前 i+1 个元素中的最小值"。`push` 时新最小值 = `min(新值, 当前栈顶最小值)`；`pop` 时两栈一起弹，栈顶自然回到上一状态。
- 这就是"用空间换时间"的典型：每个元素多带一份历史最值，换来 O(1) 的回溯能力。也可以用「差值栈」省空间，但差值可能溢出且可读性差，面试优先写辅助栈。

**代码**：
```javascript
class MinStack {
  constructor() {
    this.stack = [];
    this.mins = []; // mins[i] 为 stack[0..i] 的最小值
  }
  push(val) {
    this.stack.push(val);
    const prevMin = this.mins.length ? this.mins[this.mins.length - 1] : Infinity;
    this.mins.push(Math.min(val, prevMin));
  }
  pop() {
    this.mins.pop();
    return this.stack.pop();
  }
  top() {
    return this.stack[this.stack.length - 1];
  }
  getMin() {
    return this.mins[this.mins.length - 1];
  }
}
```

**复杂度**：四种操作均为时间 O(1) ／ 空间 O(n)

**易错点**：
- `push` 时写成 `Math.min(val, this.mins[-1])`，空栈时得到 `NaN`，最小值全错。
- `pop` 只弹主栈不弹辅助栈，之后 `getMin` 返回已删除的最小值。
- 用单个 `min` 变量，弹掉最小值后无法恢复。
- 空栈调用 `getMin` 返回 `undefined`，题目虽说不处理，但接口最好保持一致。

**变体与追问**：
- 要求 O(1) 额外空间：栈里存 `val - min` 的差值，弹栈时用差值恢复上一个最小值。
- 求最大栈：把 `Math.min` 换成 `Math.max`。
- 追问"辅助栈能否只存更小值" → 可以，但 `pop` 时要判断弹出值是否等于辅助栈顶，写法更绕。

### C-102 用栈实现队列 · 简单 · 字节/美团

**题干**：请仅使用两个栈实现一个先入先出（FIFO）的队列，支持 `push`、`pop`、`peek`、`empty` 四种操作。`pop` 和 `peek` 调用时保证队列非空。

**示例**：`push(1); push(2); peek() → 1; pop() → 1; empty() → false`

**思路**：
- 栈是后进先出，倒一次就变先进先出。用 `in` 栈接收 `push`，用 `out` 栈负责 `pop`/`peek`。
- 只有当 `out` 为空时，才把 `in` 全部倒入 `out`。倒入后 `in` 的栈顶（最新元素）跑到 `out` 的栈底，最早进入的元素正好在 `out` 栈顶。
- 为什么"只在 out 空时倒"：如果每次 `pop` 都倒，会把 `out` 里已经排好序的元素又打乱，顺序直接错；而且频繁倒导致单次 O(n)。按需倒后，每个元素最多被搬一次，均摊 O(1)。

- 工程上 `empty` 要同时检查两个栈；`pop`/`peek` 的空栈行为由调用方保证，接口内部不必抛错，但可以加断言便于自测。

**代码**：
```javascript
class MyQueue {
  constructor() {
    this.inStack = [];
    this.outStack = [];
  }
  push(x) {
    this.inStack.push(x);
  }
  // 仅在 out 为空时，把 in 整体倒入 out
  _transfer() {
    if (this.outStack.length) return;
    while (this.inStack.length) {
      this.outStack.push(this.inStack.pop());
    }
  }
  pop() {
    this._transfer();
    return this.outStack.pop();
  }
  peek() {
    this._transfer();
    return this.outStack[this.outStack.length - 1];
  }
  empty() {
    return this.inStack.length === 0 && this.outStack.length === 0;
  }
}
```

**复杂度**：`push`、`empty` 时间 O(1)；`pop`、`peek` 均摊 O(1)，单次最坏 O(n) ／ 空间 O(n)

**易错点**：
- 每次 `pop` 都执行倒入，顺序错乱且复杂度退化。
- 倒入后忘记清空 `in`——`while (in.length) out.push(in.pop())` 本身会清空，但若用 `for` 遍历下标容易漏。
- `peek` 里调用 `this.pop()` 会把元素真的弹掉。
- `empty` 只看 `outStack`，漏掉还没倒过去的元素。

**变体与追问**：
- 用两个队列实现栈（下一题），思路相反。
- 追问"均摊 O(1) 怎么证明" → 每个元素一生只入 `in` 一次、搬到 `out` 一次、出 `out` 一次，总操作数 O(n)。
- 追问"如果要求严格 O(1) 单次" → 只能换数据结构，两个栈做不到。

### C-103 用队列实现栈 · 简单 · 阿里/快手

**题干**：请仅使用两个队列实现一个后入先出（LIFO）的栈，支持 `push`、`pop`、`top`、`empty`。`pop` 和 `top` 调用时保证栈非空。可以只用**一个**队列完成。

**示例**：`push(1); push(2); top() → 2; pop() → 2; empty() → false`

**思路**：
- 队列只能从队头出，而栈要弹出最新元素。技巧是：每 `push` 一个新元素后，把它前面的 `size - 1` 个元素依次从队头搬到队尾，这样队头永远是最后进来的元素。
- 例如队列 `[1,2]` 再 `push(3)` 得 `[1,2,3]`，把前两个搬到队尾 → `[3,1,2]`，队头 3 就是栈顶。
- 为什么用一个队列就够：搬运过程本身就是"用队列模拟栈"的核心，第二个队列只是搬运时的临时容器，而队列的 `shift` + `push` 可以在同一个队列里完成旋转，不需要额外容器。

**代码**：
```javascript
class MyStack {
  constructor() {
    this.q = [];
  }
  push(x) {
    this.q.push(x);
    // 把新元素之前的 size-1 个元素转到队尾，使队头成为栈顶
    const n = this.q.length;
    for (let i = 0; i < n - 1; i++) {
      this.q.push(this.q.shift());
    }
  }
  pop() {
    return this.q.shift();
  }
  top() {
    return this.q[0];
  }
  empty() {
    return this.q.length === 0;
  }
}
```

**复杂度**：`push` 时间 O(n)；`pop`、`top`、`empty` 时间 O(1) ／ 空间 O(n)

**易错点**：
- 循环次数写成 `q.length - 1` 且边循环边取长度，虽然长度不变但可读性差；应先存 `n`。
- 循环 `n` 次而不是 `n - 1` 次，队头又变回最旧元素。
- `pop` 用 `pop()`（数组尾部）而不是 `shift()`（队头），弹出了错误的元素。
- 把搬运放在 `pop` 里：也能实现，但 `top` 和 `pop` 都要处理，容易重复。

**变体与追问**：
- 两个队列版：`push` 进 q2，把 q1 全部搬到 q2，交换 q1/q2，使 q1 队头是栈顶。
- 追问"push O(n) 和 pop O(n) 哪个好" → 取决于读写比例，读多写少时把代价放在 `push` 更划算。
- 追问"队列底层是链表还是数组" → 数组 `shift` 是 O(n)，严格说 `pop` 不是 O(1)，工程上可用头指针模拟。

### C-104 逆波兰表达式求值 · 中等 · 字节/美团

**题干**：给定一个字符串数组 `tokens`，表示一个按逆波兰表示法（后缀表达式）书写的算术表达式，请计算其值。有效运算符为 `+ - * /`，除法向零截断，表达式一定合法，结果不会溢出。

**示例**：`输入: ["2","1","+","3","*"]` → `输出: 9`（(2+1)*3）；`["4","13","5","/","+"]` → `6`

**思路**：
- 后缀表达式的性质是"运算符出现时，它需要的两个操作数刚好已经算完并压在栈顶"。因此扫到数字就入栈，扫到运算符就弹两个数、算完再压回。
- 弹出顺序不能反：先弹出的是**右操作数**，后弹出的是**左操作数**。减法和除法不满足交换律，写反了 `4 13 5 / +` 会算成 `5/13` 而不是 `13/5`。
- 除法要用 `Math.trunc` 向零截断，而不是 `Math.floor`（后者对负数是向下取整，如 `-7/2` 得 `-4`，而题目要求 `-3`）。

**代码**：
```javascript
function evalRPN(tokens) {
  const st = [];
  for (const t of tokens) {
    if (t === '+' || t === '-' || t === '*' || t === '/') {
      const b = st.pop(); // 右操作数先出栈
      const a = st.pop(); // 左操作数后出栈
      if (t === '+') st.push(a + b);
      else if (t === '-') st.push(a - b);
      else if (t === '*') st.push(a * b);
      else st.push(Math.trunc(a / b)); // 向零截断，不能用 floor
    } else {
      st.push(Number(t)); // token 可能是多位数或负数
    }
  }
  return st.pop();
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- 写成 `const a = st.pop(); const b = st.pop();` 再算 `a - b`，减法和除法结果反了。
- 除法用 `Math.floor`，负结果错一位。
- 用 `parseInt` 也正确，但 `Number` 更直观；不要假设 token 是单字符。
- 表达式合法时最后栈里恰好一个值，不要返回整个栈。

**变体与追问**：
- 中缀转后缀（调度场算法），再求值。
- 支持括号与一元负号，即 C-105。
- 追问"为什么后缀表达式不需要考虑优先级" → 优先级在转后缀时已经编码进顺序，求值阶段只需顺序执行。

### C-105 基本计算器 · 困难 · 字节/腾讯

**题干**：给定一个字符串表达式 `s`，包含非负整数、`+`、`-`、`(`、`)` 和空格，请实现一个基本计算器求值。表达式保证合法，`+` 不能作为一元运算符出现在数字前，但 `-` 可以表示负号。

**示例**：`输入: "1 + (2 - (3 + 4))"` → `输出: -4`；`输入: "-(2+3)"` → `输出: -5`

**思路**：
- 用一个变量 `res` 累加"当前括号层内已完成的项"，`sign` 记录当前数字的符号，`num` 累积多位数。遇到 `+`/`-` 就把上一项结算进 `res` 并更新 `sign`。
- 遇 `(` 时，当前 `res` 和 `sign` 属于"括号外"，必须暂存；把 `res` 置 0、`sign` 置 1，开始独立计算括号内。遇 `)` 时先结算括号内最后一个数字，再弹出保存的 `sign` 和 `res`，把括号整体的值乘上外面的符号并加回外层。
- 为什么只用一个栈：数字与运算符是顺序消费的，真正需要"回到过去"的只有括号，压栈的只是 `(res, sign)` 这一对现场，不需要分别维护符号栈和数字栈。

**代码**：
```javascript
function calculate(s) {
  const st = [];
  let res = 0, sign = 1, num = 0;
  for (let i = 0; i < s.length; i++) {
    const c = s[i];
    if (c >= '0' && c <= '9') {
      num = num * 10 + (c.charCodeAt(0) - 48); // 累积多位数
    } else if (c === '+' || c === '-') {
      res += sign * num;
      num = 0;
      sign = c === '+' ? 1 : -1;
    } else if (c === '(') {
      st.push(res, sign); // 保存括号外的现场
      res = 0;
      sign = 1;
    } else if (c === ')') {
      res += sign * num;
      num = 0;
      res = res * st.pop() + st.pop(); // 先还原外层符号，再加外层结果
    }
  }
  return res + sign * num; // 收尾：最后一项没有运算符触发结算
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)（栈深等于括号嵌套层数）

**易错点**：
- 忘记收尾的 `res + sign * num`，最后一个数字丢失。
- `)` 处先弹 `res` 再弹 `sign`，顺序反了（压栈顺序是 `res`、`sign`）。
- 空格不跳过，走到 `else` 分支把状态清空。
- 一元负号 `-(2+3)`：`sign` 在 `(` 前被正确置 -1 并压栈，不要额外特判成 0。

**变体与追问**：
- 加入 `*`、`/`（下一题），需要先乘除后加减。
- 只有 `+`、`-`、无括号：可以不用栈，直接累加。
- 追问"如何支持幂运算" → 运算符优先级变多，改用调度场算法转后缀更清晰。

### C-106 基本计算器 II · 中等 · 字节/阿里

**题干**：给定一个字符串表达式 `s`，包含非负整数、`+`、`-`、`*`、`/` 和空格，请实现一个基本计算器求值。整数除法仅保留整数部分（向零截断），表达式保证合法。

**示例**：`输入: "3+2*2"` → `输出: 7`；`输入: " 3/2 "` → `输出: 1`；`输入: "3+5 / 2"` → `输出: 5`

**思路**：
- 乘除优先级高于加减，但表达式是从左到右扫的。做法是：栈里只存"待相加的项"，遇到 `+`/`-` 就把带符号的数字入栈；遇到 `*`/`/` 就立刻和栈顶结算（因为栈顶就是紧挨着的左操作数），把结果替换回栈顶。
- 这样一轮扫描后，栈里全是"已经处理完乘除、只剩加减"的项，求和即答案。为什么能这样做：乘除是左结合的，且只影响紧邻的左操作数，用栈顶就能拿到它，不需要优先级表。
- 多位数要累积，运算符或空格或字符串结束都可能触发结算，因此循环多走一位（`i <= s.length`），用一个哨兵位置收尾。

**代码**：
```javascript
function calculate(s) {
  const st = [];
  let num = 0;
  let op = '+'; // 上一个运算符，首个数字默认正号
  for (let i = 0; i <= s.length; i++) {
    const c = s[i];
    if (c >= '0' && c <= '9') {
      num = num * 10 + (c.charCodeAt(0) - 48);
      continue;
    }
    if (c === ' ') continue;
    // 遇到运算符或越界哨兵，结算上一个运算符
    if (op === '+') st.push(num);
    else if (op === '-') st.push(-num);
    else if (op === '*') st.push(st.pop() * num);
    else st.push(Math.trunc(st.pop() / num)); // 向零截断
    op = c;
    num = 0;
  }
  return st.reduce((a, b) => a + b, 0);
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- 忘记 `i <= s.length`，最后一个数字没被结算。
- 除法用 `Math.floor`，`-3/2` 会得到 `-2` 而非 `-1`。
- `op` 初始化为空，第一个数字入栈时判断不到符号。
- 空格直接 `continue` 前先把 `num` 清零，多位数被截断。

**变体与追问**：
- 加入括号（C-105），栈需要同时保存括号外现场。
- 加入幂运算，优先级三层，建议转后缀统一处理。
- 追问"能否不用栈" → 只有加减时可以；有乘除时必须暂存前面的加减项。

### C-107 每日温度 · 中等 · 字节/美团

**题干**：给定一个整数数组 `temperatures` 表示每天的温度，请返回一个数组 `answer`，其中 `answer[i]` 表示第 `i` 天之后第一个更高温度出现在几天后；若之后都不会升高，则 `answer[i] = 0`。

**示例**：`输入: [73,74,75,71,69,72,76,73]` → `输出: [1,1,4,2,1,1,0,0]`

**思路**：
- 暴力对每天向后找是 O(n²)。换个视角：不要"为每一天找答案"，而是"让后来的高温去回答之前等待中的天"。
- 维护一个**单调递减**栈，存的是"还没有找到更高温度"的下标。新的一天温度若高于栈顶那天的温度，说明栈顶那天的答案就是今天，弹出并写入天数差；可能连续弹多个，直到栈顶温度不低于今天。
- 为什么栈内一定递减：如果后入栈的温度更高，它早就把前面更低的弹掉了，剩下的一定是"从栈底到栈顶温度递减、下标递增"。每个下标最多入栈一次、出栈一次，所以是 O(n)。

**代码**：
```javascript
function dailyTemperatures(temperatures) {
  const n = temperatures.length;
  const answer = new Array(n).fill(0);
  const st = []; // 存下标，对应温度从栈底到栈顶递减
  // 让后来的高温去回答之前等待中的天
  for (let i = 0; i < n; i++) {
    while (st.length && temperatures[i] > temperatures[st[st.length - 1]]) {
      const prev = st.pop(); // prev 天找到了第一个更高温
      answer[prev] = i - prev;
    }
    st.push(i);
  }
  // 栈中剩余下标保持 0，表示之后再无更高温
  return answer;
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- 栈里存温度值而不是下标，算不出天数差。
- 判断用 `>=`，温度相等时提前弹出，答案偏小。
- 用 `if` 而不是 `while`，一天只能回答一个等待中的天，前面漏算。
- 剩余在栈里的下标保持初始值 0，正好符合题意。

**变体与追问**：
- 求之后第一个**更低**温度：把比较方向反过来，栈变递增。
- 求之前第一个更高温度：从右往左扫，或正向扫时在弹出时结算。
- 追问"为什么是 O(n) 而不是 O(n²)" → 内层 `while` 的总执行次数等于总入栈次数，均摊 O(1)。

### C-108 下一个更大元素 I · 简单 · 字节/阿里

**题干**：给定两个没有重复元素的数组 `nums1` 和 `nums2`，其中 `nums1` 是 `nums2` 的子集。请找出 `nums1` 中每个元素在 `nums2` 中对应位置的**右侧第一个更大元素**；若不存在，输出 `-1`。

**示例**：`输入: nums1 = [4,1,2], nums2 = [1,3,4,2]` → `输出: [-1,3,-1]`

**思路**：
- `nums2` 中每个元素的"下一个更大值"只依赖于它右侧的序列，与 `nums1` 无关。因此先对 `nums2` 跑一遍单调栈，把答案存进 `Map`，再拿 `nums1` 去查表。
- 从右往左扫 `nums2`：栈里保存"右侧可能的更大值"，且从栈顶到栈底递增（栈顶是最近的更大候选）。当前值入栈前，把栈顶所有 `<= 当前值` 的弹出——它们既比当前值小又更远，对更左边元素来说永远不如当前值有用。
- 弹完后栈顶就是当前值的下一个更大元素；栈空说明右侧没有更大的。为什么从右往左：处理到 `i` 时，右侧元素已经全部处理过，栈里就是"右侧的候选集合"。

**代码**：
```javascript
function nextGreaterElement(nums1, nums2) {
  const map = new Map();
  const st = [];
  // 从右往左，栈中保存右侧“可能更大”的候选
  for (let i = nums2.length - 1; i >= 0; i--) {
    const x = nums2[i];
    // 比 x 小的候选永远不可能成为更左边元素的答案
    while (st.length && st[st.length - 1] <= x) st.pop();
    // 弹完后栈顶就是右侧第一个更大值
    map.set(x, st.length ? st[st.length - 1] : -1);
    // 栈中元素从栈顶到栈底递增，栈顶最接近当前元素
    st.push(x);
  }
  return nums1.map((x) => map.get(x));
}
```

**复杂度**：时间 O(n + m) ／ 空间 O(n)（n、m 分别为 `nums2`、`nums1` 长度）

**易错点**：
- 弹出条件写成 `<` 而不是 `<=`，遇到相等元素时答案取到相等的值（本题元素不重复，但换成有重复就会错）。
- `Map` 未命中时返回 `undefined`，忘记转成 `-1`。
- 从左往右扫却仍用"栈顶即答案"的写法，方向反了。
- 直接双重循环 O(nm)，面试官会追问优化。

**变体与追问**：
- 下一个更大元素 II（循环数组，下一题）。
- 下一个更小元素：比较方向反过来。
- 追问"为什么用 Map 不用对象" → `Map` 的键可以是任意类型且无原型污染，性能也更稳定。

### C-109 下一个更大元素 II · 中等 · 字节/腾讯

**题干**：给定一个循环数组 `nums`（最后一个元素的下一个元素是数组的第一个元素），请返回每个元素的下一个更大元素；若不存在，返回 `-1`。

**示例**：`输入: [1,2,1]` → `输出: [2,-1,2]`；`输入: [1,2,3,4,3]` → `输出: [2,3,4,-1,4]`

**思路**：
- 循环数组的本质是"每个元素右侧最多再看一圈"，所以把数组逻辑上延长一倍，遍历 `2n - 1` 个位置（最后一位不需要再作为起点）。下标用 `i % n` 映射回原数组。
- 栈仍存下标，且只在前 `n` 个位置入栈：后 `n-1` 个位置只是"重复提供右侧元素"，如果把它们的下标也入栈，会重复计算甚至覆盖答案。
- 为什么是 `2n - 1` 而不是 `2n`：第 `2n` 个位置就是第 0 个元素本身，它不可能成为自己的"右侧更大元素"，多遍历一次没有意义。

**代码**：
```javascript
function nextGreaterElements(nums) {
  const n = nums.length;
  const res = new Array(n).fill(-1);
  const st = []; // 存下标，对应值递减
  // 逻辑上把数组延长一倍，每个元素最多向右看一圈
  for (let i = 0; i < 2 * n - 1; i++) {
    const idx = i % n;
    while (st.length && nums[st[st.length - 1]] < nums[idx]) {
      res[st.pop()] = nums[idx];
    }
    // 只有原数组下标入栈，避免重复处理
    if (i < n) st.push(idx);
  }
  return res;
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- 循环写 `i < 2 * n`，最后一个位置重复处理，虽不改变结果但多一次无意义操作；更重要的是如果入栈条件写成 `i < 2*n`，下标会重复入栈。
- `res` 初始化成 0 而不是 -1，未找到更大值的元素输出错误。
- 忘记取模，`nums[i]` 越界得到 `undefined`。
- 用双倍数组拼接 `[...nums, ...nums]` 也可，但空间多 O(n)。

**变体与追问**：
- 循环数组的下一个更小元素。
- 环形数组中每个元素到下一个更大值的距离。
- 追问"为什么只遍历 2n-1 次" → 环上任意元素向右看一圈必能覆盖所有候选，再走就重复了。

### C-110 柱状图中最大的矩形 · 困难 · 字节/腾讯

**题干**：给定 `n` 个非负整数，表示柱状图中每个柱子的高度，每个柱子宽度为 1 且紧挨排列。求该柱状图中能勾勒出的最大矩形面积。

**示例**：`输入: [2,1,5,6,2,3]` → `输出: 10`（由高度 5、6 两根柱子组成 5×2）

**思路**：
- 枚举"以某根柱子为最矮柱子"的矩形：向左找到第一个更矮的、向右找到第一个更矮的，中间整段都能用它的高度。答案就是 `height[i] × (right[i] - left[i] - 1)` 的最大值。
- 单调**递增**栈可以一次求出这两个边界：当遇到比栈顶矮的柱子 `i` 时，栈顶柱子的右边界就是 `i`；弹出它后，新的栈顶就是它左边第一个更矮的柱子。此时宽 = `i - 新栈顶 - 1`，面积可算。
- 首尾各加一个高度 0 的哨兵：首哨兵保证栈不会空（宽度公式始终有左边界），尾哨兵保证所有柱子最终都会被弹出结算。为什么栈内递增：一旦出现更矮的，比它高的柱子右边界就已确定，留着也没用。

**代码**：
```javascript
function largestRectangleArea(heights) {
  const h = [0, ...heights, 0]; // 首尾哨兵，省去边界特判
  const st = []; // 存下标，对应高度严格递增
  let best = 0;
  for (let i = 0; i < h.length; i++) {
    while (st.length && h[st[st.length - 1]] > h[i]) {
      const height = h[st.pop()];          // 以它为最矮柱子
      const width = i - st[st.length - 1] - 1; // 左右第一个更矮之间
      best = Math.max(best, height * width);
    }
    // 当前柱子入栈，维持高度递增
    st.push(i);
  }
  return best;
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- 宽度公式写成 `i - st[top]`，多算了一格，因为 `i` 和栈顶都是"更矮的柱子"，不能计入矩形。
- 不加尾哨兵，最后残留的递增柱子永远不会被结算。
- 不加首哨兵，弹出后栈空时 `st[st.length - 1]` 是 `undefined`，宽度变 `NaN`。
- 相等高度用 `>` 弹出即可；用 `>=` 也正确，只是结算归属不同，别混着讲。

**变体与追问**：
- 最大矩形（LeetCode 85，二维矩阵）：逐行累加高度，每行调用本题。
- 接雨水：同样用单调栈，但算的是"凹槽"面积，宽度与高度公式不同。
- 追问"为什么每个柱子只进出栈一次" → 内层 `while` 的总次数受入栈次数约束，均摊 O(1)。

### C-111 去除重复字母 · 中等 · 字节/快手

**题干**：给定一个字符串 `s`，请去除字符串中重复出现的字母，使得每个字母只出现一次，且返回结果的字典序最小。要求不能打乱其他字符的相对位置。

**示例**：`输入: "bcabc"` → `输出: "abc"`；`输入: "cbacdcbc"` → `输出: "acdb"`

**思路**：
- 要字典序最小，就要让靠前的字符尽量小，这正是单调递增栈的用武之地：新字符比栈顶小，就让更小的字符往前挪。
- 但不能随便弹：如果栈顶字符在当前位置之后不再出现，弹掉就永远丢失它，违反"每个字母出现一次"；只有 `last[栈顶] > i`（后面还有）时才能弹。
- 弹栈后要清掉 `used` 标记，因为该字符之后还会重新入栈；已经在栈里的字符直接跳过，避免重复。为什么 `last` 要在判断前先更新/使用：`last` 记录的是每个字符最后出现的下标，是"能否安全删除"的唯一依据。

**代码**：
```javascript
function removeDuplicateLetters(s) {
  const last = new Array(26).fill(-1);
  const used = new Array(26).fill(false);
  for (let i = 0; i < s.length; i++) last[s.charCodeAt(i) - 97] = i;

  const st = [];
  for (let i = 0; i < s.length; i++) {
    const c = s[i], k = c.charCodeAt(0) - 97;
    if (used[k]) continue; // 已在栈中，跳过
    while (st.length) {
      const top = st[st.length - 1];
      const tk = top.charCodeAt(0) - 97;
      if (top > c && last[tk] > i) { // 栈顶更大且后面还会出现，可安全弹出
        st.pop();
        used[tk] = false;
      } else break;
    }
    st.push(c);
    used[k] = true;
  }
  return st.join('');
}
```

**复杂度**：时间 O(n)（每个字符最多入栈、出栈一次） ／ 空间 O(1)（字母表大小 26）

**易错点**：
- 弹栈条件漏掉 `last[tk] > i`，把只出现一次的字符弹掉且再也补不回来。
- 忘记把 `used[tk]` 置回 `false`，该字符后续无法重新入栈。
- 相等时也弹（`top >= c`），虽不改变结果，但会多一次无意义操作；用 `>` 语义更清楚。
- 用 `s.indexOf` 动态判断"后面还有没有"，复杂度退化为 O(n²)。

**变体与追问**：
- 移掉 k 位数字（下一题），同为"贪心 + 单调栈"，但约束从"必须保留"变成"删固定个数"。
- 拼接两个字符串后去重求最小字典序。
- 追问"为什么不能直接排序" → 排序会打乱相对顺序，题目明确禁止。

### C-112 移掉 K 位数字 · 中等 · 字节/阿里

**题干**：给定一个以字符串表示的非负整数 `num` 和一个整数 `k`，请移除这个数中的 `k` 位数字，使剩下的数字最小。结果不能包含前导零；若结果为空，返回 `"0"`。

**示例**：`输入: num = "1432219", k = 3` → `输出: "1219"`；`输入: "10200", k = 1` → `"200"`

**思路**：
- 高位数字对数值影响最大，所以从左往右扫，一旦发现当前位比前一位小，就把前一位删掉——这等价于维护一个单调递增栈。
- 每弹一次 `k` 减一；扫描结束后如果 `k` 还有剩余，说明整个序列已经非递减，删末尾的 `k` 位即可（末尾对数值影响最小）。
- 最后处理前导零：跳过开头的 `'0'`，如果全被跳完则返回 `"0"`。为什么先弹再压：当前位可能就是后续位的"更优前驱"，它必须留在栈里继续参与比较。

**代码**：
```javascript
function removeKdigits(num, k) {
  const st = [];
  for (const c of num) {
    while (k > 0 && st.length && st[st.length - 1] > c) {
      st.pop(); // 前一位更大，删掉它能让高位更小
      k--;
    }
    st.push(c);
  }
  while (k-- > 0) st.pop(); // k 没用完，从末尾删
  let i = 0;
  while (i < st.length && st[i] === '0') i++; // 去前导零
  const res = st.slice(i).join('');
  return res === '' ? '0' : res;
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- `k` 用完后就不再压栈（把 `while` 写成 `if` 后漏了 `st.push`），结果丢位。
- 忘记处理剩余的 `k`，例如 `"1234", k = 2` 应得 `"12"`。
- 去前导零后返回空字符串而不是 `"0"`。
- `k` 大于等于长度时全部删完，仍要返回 `"0"`。

**变体与追问**：
- 移掉 k 位使结果最大：把比较符反过来。
- 去除重复字母（上一题）：保留规则不同，需额外记录"最后出现位置"。
- 追问"为什么删高位比删低位更划算" → 十进制下高位的权重是低位的 10 倍。

### C-113 验证栈序列 · 中等 · 字节/美团

**题干**：给定两个整数序列 `pushed` 和 `popped`，每个序列中的值都不重复。请判断 `popped` 是否可能是 `pushed` 经过若干次 `push` 和 `pop` 操作后得到的弹出序列。初始栈为空，每次只能压入 `pushed` 的下一个元素。

**示例**：`输入: pushed = [1,2,3,4,5], popped = [4,5,3,2,1]` → `输出: true`；`popped = [4,3,5,1,2]` → `false`

**思路**：
- 模拟：按 `pushed` 的顺序压栈，每压入一个就检查栈顶是否等于 `popped` 的当前待弹元素；等于就弹出，并让 `popped` 指针后移。**必须用 `while` 循环**，因为一次压入可能触发连续多次弹出（如压入 3 后可以立刻弹 3、2、1）。
- 全部压完后，如果 `popped` 指针走到末尾、栈为空，说明弹出序列合法；否则栈里还有无法按目标顺序弹出的元素。
- 为什么元素不重复很关键：若存在重复值，栈顶等于目标值时无法确定该弹哪一个，需要额外决策，问题会变成搜索。

**代码**：
```javascript
function validateStackSequences(pushed, popped) {
  const st = [];
  let j = 0; // popped 中下一个待匹配的下标
  for (const x of pushed) {
    // 按 pushed 顺序压栈，能弹就弹
    st.push(x);
    // 一次压入可能触发连续弹出
    while (st.length && st[st.length - 1] === popped[j]) {
      st.pop();
      j++;
    }
  }
  // 全部压完后栈空，说明 popped 是合法弹出序列
  return st.length === 0;
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- 用 `if` 代替 `while`，一次压入后只弹一个，后续序列全部错位。
- 忘记判断 `j` 越界：`popped[j]` 在全部匹配后是 `undefined`，比较结果为 `false`，恰好安全，但不要依赖这一点。
- 只判断 `j === popped.length` 而不判栈空（两者等价，但判栈空更直观）。
- 认为 `pushed` 和 `popped` 长度不同也能成立，应先判长度。

**变体与追问**：
- 元素可重复时的验证：需要回溯或计数约束，难度上升。
- 给定入栈序列，求所有可能的出栈序列（卡特兰数）。
- 追问"为什么时间复杂度是 O(n)" → 每个元素入栈一次、出栈至多一次。

### C-114 括号的分数 · 中等 · 字节/腾讯

**题干**：给定一个平衡括号字符串 `s`，请按以下规则计算并返回它的分数：`()` 得 1 分；`AB` 得 `A + B` 分（相邻拼接）；`(A)` 得 `2 × A` 分（嵌套）。

**示例**：`输入: "()"` → `1`；`"(())"` → `2`；`"()()"` → `2`；`"(()(()))"` → `6`

**思路**：
- 把"当前括号层已经累计的分数"放在栈里。遇 `(` 压入 0，表示进入新的一层；遇 `)` 弹出这一层的得分 `v`：如果 `v === 0`，说明是空括号 `()`，得分 1；否则是 `(A)`，得分 `2 * v`。然后把这个得分加到新的栈顶（外层）上。
- 为什么栈里只存分数就够：括号嵌套天然是栈结构，遇到 `)` 时"当前层"一定是栈顶，外层一定是新的栈顶，不需要额外记录层号。
- 初始栈放一个 0 作为最外层的累加器，这样 `()` 结束后也能直接加到 `st[0]`，省掉"栈空"的特判。

**代码**：
```javascript
function scoreOfParentheses(s) {
  // 用栈保存每一层已经累计的分数
  const st = [0]; // 栈底作为最外层累加器
  for (const c of s) {
    if (c === '(') {
      st.push(0); // 进入新的一层，该层初始分数为 0
    } else {
      // 弹出的是当前括号层的分数
      const v = st.pop();
      // 空括号得 1 分，嵌套得 2 倍，再累加给外层
      st[st.length - 1] += v === 0 ? 1 : 2 * v;
    }
  }
  return st[0];
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)（栈深为嵌套层数）

**易错点**：
- 把 `()` 和 `(A)` 都按 `2 * v` 处理，`v = 0` 时得分变成 0。
- `)` 结算后忘记加回外层，分数丢失。
- 初始栈为空，遇到第一个 `)` 时 `st[st.length - 1]` 越界。
- 把"拼接"误当成乘法：`()()` 是 1+1，不是 1×1。

**变体与追问**：
- 只有 `()` 和 `(A)`、没有并列时，答案就是 `2^深度`，可用深度计数 O(1) 空间。
- 求最长有效括号（下一题），同样利用括号的栈性质。
- 追问"能否 O(1) 空间" → 统计当前深度，遇到 `()` 时加 `1 << depth`，本质是把栈的累加换成幂次。

### C-115 最长有效括号 · 困难 · 字节/阿里

**题干**：给定一个只包含 `'('` 和 `')'` 的字符串 `s`，请找出其中最长有效（格式正确且连续）的括号子串的长度。

**示例**：`输入: "(()"` → `2`；`")()())"` → `4`；`""` → `0`

**思路**：
- 栈里存**下标**而不是字符，因为最终要算长度。栈底先放一个 `-1` 作为"上一个无法匹配的位置"的哨兵。
- 遇 `(` 压入下标；遇 `)` 先弹出一个 `(`（或哨兵）。弹完后如果栈空，说明当前 `)` 没有匹配，它成为新的分界，把它的下标压入；如果栈不空，则当前有效段的长度 = `i - 栈顶`。
- 为什么用下标：长度是"当前右端点减去最后一个未匹配位置"，字符本身提供不了这个信息；哨兵让第一段有效括号也能用同一公式。

**代码**：
```javascript
function longestValidParentheses(s) {
  const st = [-1]; // 栈底哨兵：最后一个未匹配位置
  let best = 0;
  for (let i = 0; i < s.length; i++) {
    if (s[i] === '(') {
      st.push(i);
    } else {
      st.pop(); // 尝试匹配一个 '('
      if (!st.length) {
        st.push(i); // 当前 ')' 无法匹配，成为新边界
      } else {
        best = Math.max(best, i - st[st.length - 1]);
      }
    }
  }
  return best;
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- 栈里存字符，弹出后无法计算下标差。
- 栈空时忘记压入当前下标，后续所有长度都从错误边界起算。
- 遇到 `)` 先判断栈空再弹，`-1` 哨兵的存在使"先弹再判"更简洁。
- 把 `best` 更新写在 `if` 外面，栈空时用 `st[-1]` 得到 `NaN`。

**变体与追问**：
- 动态规划：`dp[i]` 表示以 `i` 结尾的最长有效长度，分 `()` 和 `))` 两种转移，O(n) 空间。
- 双向计数：左右各扫一遍，空间 O(1)，但需要处理多余右括号。
- 追问"为什么这题不能用简单计数" → 单遍计数无法区分 `)(` 这种前缀非法的情况，需要栈或双向扫描提供边界。

### C-116 扁平化嵌套列表迭代器 · 中等 · 字节

**题干**：给定一个嵌套的整数列表 `nestedList`，其中每个元素要么是整数，要么是另一个嵌套列表。请实现迭代器 `NestedIterator`，提供 `next()` 返回下一个整数、`hasNext()` 判断是否还有整数。要求惰性求值，不要在构造时一次性展开全部元素。

**示例**：`输入: [[1,1],2,[1,1]]` → 依次输出 `1,1,2,1,1`；`输入: [1,[4,[6]]]` → `1,4,6`

**思路**：
- 用栈保存"当前还没消费完的列表 + 游标"，初始压入 `[nestedList, 0]`。栈顶永远是当前正在处理的那一层。
- `hasNext` 负责"把栈顶整理成整数"：若游标越界就弹层；若当前元素是列表，就把父层游标加一（表示这个子列表已经开始消费），再把子列表压栈；直到栈顶指向整数或栈空。
- `next` 只做取值和游标自增。为什么必须惰性：如果构造时递归展开，遇到极深的嵌套会爆栈，而且可能只需要前几个元素却展开了全部，浪费内存；惰性展开的复杂度只与实际访问深度相关。

**代码**：
```javascript
class NestedIterator {
  constructor(nestedList) {
    this.stack = [[nestedList, 0]]; // [列表, 当前下标]
  }
  hasNext() {
    while (this.stack.length) {
      const top = this.stack[this.stack.length - 1];
      const [list, i] = top;
      if (i >= list.length) {
        this.stack.pop(); // 这一层消费完
        continue;
      }
      if (typeof list[i] === 'number') return true;
      top[1]++;                      // 父层越过这个子列表
      this.stack.push([list[i], 0]); // 展开子列表
    }
    return false;
  }
  next() {
    if (!this.hasNext()) return null;
    const top = this.stack[this.stack.length - 1];
    return top[0][top[1]++];
  }
}
```

**复杂度**：`next`、`hasNext` 均摊 O(1)，单次最坏 O(深度)；空间 O(深度)

**易错点**：
- 展开子列表时忘记 `top[1]++`，父层会反复压入同一个子列表，死循环。
- `next` 里不调用 `hasNext`，栈顶还是列表时直接取值，返回数组。
- 构造时递归 `flat` 一次性展开，违背"惰性"要求（虽然结果对，但面试会扣分）。
- 空列表 `[]`：`hasNext` 应立即返回 `false`，不要压空层。

**变体与追问**：
- 实现 `NestedInteger` 的 `hasNext`/`next` 而不预展开，正是本题。
- 反向迭代（从尾到头）：把游标改为从 `length - 1` 递减。
- 追问"为什么均摊 O(1)" → 每个列表项最多被压栈、弹栈一次。

### C-117 行星碰撞 · 中等 · 腾讯/美团

**题干**：给定一个整数数组 `asteroids`，表示在同一行运动的小行星。绝对值表示大小，正负表示方向（正向右、负向左），速度相同。相撞规则：小的爆炸；大小相等则一起爆炸；同向不会相撞。求碰撞后剩下的行星。

**示例**：`输入: [5,10,-5]` → `输出: [5,10]`；`[8,-8]` → `[]`；`[10,2,-5]` → `[10]`

**思路**：
- 只有"栈顶向右（正）+ 当前向左（负）"才可能相撞。同向、或栈顶向左、或当前向右，都直接入栈。
- 用 `while` 处理连锁碰撞：当前行星可能连续撞毁多颗向右的行星，直到被更大的撞毁、同归于尽、或前方没有向右的行星。
- 用 `alive` 标记当前行星是否还在。比较绝对值：栈顶小则弹出继续；相等则弹出且当前也消失；栈顶大则当前消失。为什么用栈：碰撞只发生在"最近一颗还没被撞毁的向右行星"与当前之间，正是栈顶。

**代码**：
```javascript
function asteroidCollision(asteroids) {
  const st = [];
  for (const a of asteroids) {
    let alive = true;
    // 只有当前向左、栈顶向右才会撞
    while (alive && a < 0 && st.length && st[st.length - 1] > 0) {
      const top = st[st.length - 1];
      if (top < -a) {
        st.pop();               // 栈顶小，被撞毁，继续撞下一颗
      } else if (top === -a) {
        st.pop();               // 同归于尽
        alive = false;
      } else {
        alive = false;          // 当前小，直接消失
      }
    }
    if (alive) st.push(a);
  }
  return st;
}
```

**复杂度**：时间 O(n)（每颗行星最多入栈、出栈一次） ／ 空间 O(n)

**易错点**：
- 循环条件漏掉 `a < 0`，当前向右时也会去撞栈顶。
- 循环条件漏掉 `st[st.length - 1] > 0`，栈顶向左时两颗同向远离，不该撞。
- 相等时只弹栈顶、忘记 `alive = false`，当前行星会继续入栈。
- 用 `if` 替代 `while`，`[10,2,-5]` 这种需要连续撞的用例会算错。

**变体与追问**：
- 若速度不同，需要引入时间维度，不能简单用栈。
- 求碰撞次数或最终速度。
- 追问"为什么每颗行星只进出栈一次" → 撞毁即出栈，之后不再参与，总操作 O(n)。

### C-118 132 模式 · 中等 · 字节/阿里

**题干**：给定一个整数数组 `nums`，请判断其中是否存在下标 `i < j < k`，使得 `nums[i] < nums[k] < nums[j]`。存在返回 `true`，否则返回 `false`。

**示例**：`输入: [1,2,3,4]` → `false`；`[3,1,4,2]` → `true`（1 < 2 < 4）；`[-1,3,2,0]` → `true`

**思路**：
- 从右往左扫，把元素分成三个角色：`3` 是已经确定的较大值，`2` 是比 `3` 小、但在 `3` 左边的候选值，`1` 是当前扫描到的值。只要 `nums[i] < 3`，就找到了合法的 `1`。
- 用单调递减栈维护候选的 `2`：当前值比栈顶大时，栈顶就可以作为 `2`，而当前值作为它的 `3`，于是弹出栈顶并更新 `three = 栈顶`。为了让 `1` 更容易找到，`three` 要取所有可能中的**最大值**（`3` 越大，左侧越容易有更小的 `1`）。
- 为什么栈是递减的：如果新值更大，它会把更小的候选弹掉并"升级"为更靠左的 `3` 的候选；剩下的都是比它小的、位置更靠右的候选 `2`。

**代码**：
```javascript
function find132pattern(nums) {
  const st = [];          // 单调递减栈，存候选的 2
  let three = -Infinity;  // 已确定的最大的 3
  // 从右往左，先确定 j、k，再找左侧的 i
  for (let i = nums.length - 1; i >= 0; i--) {
    if (nums[i] < three) return true; // 找到 1
    while (st.length && st[st.length - 1] < nums[i]) {
      // 被弹出的值作 2、当前值作 3；保留最大的候选 2
      three = Math.max(three, st.pop());
    }
    // 当前值入栈，维持栈内递减
    st.push(nums[i]);
  }
  return false;
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- `three` 只在循环外赋值一次，或取"第一个弹出的值"：栈顶是最小的候选，越往下越大，必须用 `Math.max` 保留历史最大值，否则左侧更小的 `1` 会漏判。
- 判断写成 `nums[i] <= three`，题目要求严格小于。
- 从左往右扫却沿用"栈顶作 2"的逻辑，方向反了。
- 用三重循环 O(n³)，面试会要求优化。

**变体与追问**：
- 456 模式（`i<j<k` 且 `nums[i] < nums[j] < nums[k]`）更简单，只需维护前缀最小值。
- 132 模式的存在性改为计数，需要额外的数据结构。
- 追问"为什么从右往左" → `3` 和 `2` 都在 `1` 的右侧，从右扫才能先确定右侧两个角色。

### C-119 商品折扣后的最终价格 · 简单 · 美团/快手

**题干**：给定一个数组 `prices`，其中 `prices[i]` 是第 `i` 件商品的价格。对每件商品，如果它右侧存在价格小于或等于它的商品，则它的最终价格为 `prices[i] - prices[j]`，其中 `j` 是满足条件的最小下标；否则最终价格就是原价。请返回所有商品的最终价格数组。

**示例**：`输入: [8,4,6,2,3]` → `输出: [4,2,4,2,3]`

**思路**：
- 这是"下一个更小或相等元素"的模板题，用单调栈从左往右扫：栈里存还没找到折扣的商品下标，且价格从栈底到栈顶严格递增。
- 当前价格 `prices[i]` 若小于等于栈顶价格，说明栈顶商品找到了右侧第一个符合条件的折扣，弹出并写入 `prices[top] - prices[i]`。可能连续弹出多个，因为当前价格可能同时成为多件商品的折扣。
- 为什么用 `>=` 弹出：题目允许"小于或等于"，且当前下标 `i` 一定是栈顶商品右侧**最近**的合格折扣（更早的合格者早就把它弹掉了），相等时也应结算；弹出后栈内仍严格递增。

**代码**：
```javascript
function finalPrices(prices) {
  // 栈中保留还没找到折扣的商品下标
  const st = []; // 价格从栈底到栈顶递增
  const res = prices.slice(); // 默认无折扣，保留原价
  for (let i = 0; i < prices.length; i++) {
    // 相等也要结算，保证取到最近且合格的折扣
    while (st.length && prices[st[st.length - 1]] >= prices[i]) {
      const j = st.pop();
      // 当前价格是 j 右侧第一个合格（<=）的折扣
      res[j] = prices[j] - prices[i];
    }
    st.push(i);
  }
  return res;
}
```

**复杂度**：时间 O(n) ／ 空间 O(n)

**易错点**：
- 弹出条件写成 `>`，相等时不会打折，与题意不符。
- `res` 直接用 `prices` 原地改，会把"原价"改成"折后价"，后续比较用到错误价格。
- 栈里存价格而不是下标，无法回写结果。
- 忘记 `st.push(i)`，当前商品永远不会成为别人的折扣。

**变体与追问**：
- 下一个更大元素（C-107/C-108），比较方向相反。
- 折扣可以跨多个商品累加，需要改为前缀和/DP。
- 追问"为什么从左往右" → 当前元素是"右侧"的折扣来源，从左扫才能在遇到它时结算左侧等待中的商品。

### C-120 支持增量操作的栈 · 中等 · 字节

**题干**：请设计一个支持以下操作的栈 `CustomStack(maxSize)`：`push(x)` 若栈未满则压入；`pop()` 弹出栈顶并返回，空栈返回 `-1`；`increment(k, val)` 将栈底起的前 `k` 个元素都增加 `val`（若元素不足 `k` 个则全部增加）。要求 `increment` 的时间复杂度为 O(1)。

**示例**：`push(1); push(2); increment(2, 10); pop() → 12; pop() → 11`

**思路**：
- 朴素做法是 `increment` 遍历前 `k` 个元素逐个加，O(k)。要 O(1)，就不能真的去改每个元素，而是"记账"。
- 开一个与栈等长的 `add` 数组，`add[i]` 表示"从栈底到下标 `i` 的所有元素还欠着的增量"。`increment(k, val)` 只在 `min(k, size) - 1` 这个位置记一笔 `+val`，O(1) 完成。
- 弹出时把欠账下传：`add[i-1] += add[i]`，因为下标 `i` 的元素出栈后，这笔增量仍然应该作用于它下面的所有元素。当前弹出值 = `arr[i] + add[i]`。这就是"懒标记"思想：把 O(k) 的批量更新延迟到真正访问时，每次只付 O(1)。

**代码**：
```javascript
class CustomStack {
  constructor(maxSize) {
    this.max = maxSize;
    this.arr = [];
    this.add = []; // add[i]：栈底到 i 的公共增量（懒标记）
  }
  push(x) {
    if (this.arr.length === this.max) return;
    this.arr.push(x);
    this.add.push(0);
  }
  pop() {
    const i = this.arr.length - 1;
    if (i < 0) return -1;
    if (i > 0) this.add[i - 1] += this.add[i]; // 增量下传
    return this.arr.pop() + this.add.pop();
  }
  increment(k, val) {
    const i = Math.min(k, this.arr.length) - 1;
    if (i >= 0) this.add[i] += val; // 只记一笔，O(1)
  }
}
```

**复杂度**：`push`、`pop`、`increment` 均为时间 O(1) ／ 空间 O(maxSize)

**易错点**：
- `increment` 里真的循环加 `k` 个元素，虽然结果对但复杂度 O(k)，不满足要求。
- 忘记 `Math.min(k, size)`，`k` 大于栈大小时下标越界。
- 弹出的返回值写成 `arr[i]`，漏加懒标记 `add[i]`。
- 下传顺序写反：应先 `add[i-1] += add[i]`，再弹出 `add[i]`，否则这笔增量丢失。

**变体与追问**：
- 支持"栈顶 k 个元素加 val"：把懒标记方向反过来，从上往下传。
- 支持区间加、单点查的栈，本质是树状数组/差分的特例。
- 追问"懒标记会不会影响 push 的新元素" → 新元素 `add` 初始为 0，不会继承旧增量，正确。
