# 09 二叉树属性与路径（C-161 ~ C-180）

> 大厂笔试里二叉树从不为难你"会不会写递归"，而是考**递归该返回什么、该在哪里更新答案**。**识别特征**：看到"任意两节点间的最长/最大值"就要想到"枚举最高点 + 后序返回单边贡献"；看到"根到叶"就要想到"往下传剩余量，回溯时撤销选择"。

## 题型速查

| 子类型 | 核心手法 | 代表题 |
|---|---|---|
| 树形判定 | 后序返回哨兵值，一趟同时判性质与求高度 | C-161、C-162 |
| 路径最值 | 后序返回单边贡献，函数内用双侧更新全局答案 | C-163、C-164、C-172 |
| 根到叶路径 | 递归传剩余量/前缀字符串，回溯撤销选择 | C-165 ~ C-169 |
| 层序与子树统计 | BFS 取层首元素；子树返回聚合值 | C-171、C-173、C-176 |
| 树上 DP / 状态压缩 | 返回二元组（选/不选、和/个数）；位掩码记奇偶 | C-174、C-180 |
| 祖先与节点定位 | 递归返回命中节点，两侧都命中即为 LCA | C-177、C-178 |

### C-161 平衡二叉树 · 简单 · 字节/阿里

**题干**：给定一棵二叉树的根节点 `root`，判断它是否是高度平衡的二叉树。高度平衡的定义：每个节点的左右两个子树的高度差的绝对值不超过 1。空树视为平衡。树中节点数在 `[0, 5000]` 范围内。

**示例**：`输入: root = [3,9,20,null,null,15,7]` → `输出: true`；`输入: root = [1,2,2,3,3,null,null,4,4]` → `输出: false`

**思路**：
- 自顶向下：对每个节点都调用一次求高度的递归，判断左右高度差是否 ≤ 1，再递归判断左右子树。写法直白，但每个节点会被反复访问，链状树退化成 O(n²)。
- 自底向上：把"求高度"和"判平衡"合并成一趟。辅助函数返回子树高度，一旦发现不平衡就返回 -1 当哨兵，父节点看到 -1 立刻短路返回。
- 关键洞察：不平衡会向上传染——子树一旦不平衡，整棵树必然不平衡。所以 -1 可以直接一路上抛，完全不必再算高度，这正是能把 O(n²) 降到 O(n) 的原因。
- 面试表达：先说自顶向下的问题，再给自底向上并解释哨兵语义，比直接甩代码更能体现优化意识。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var isBalanced = function (root) {
  // 返回子树高度；返回 -1 表示该子树已不平衡
  const height = (node) => {
    if (!node) return 0;
    const l = height(node.left);
    if (l === -1) return -1;          // 左子树已坏，直接短路
    const r = height(node.right);
    if (r === -1) return -1;
    if (Math.abs(l - r) > 1) return -1;   // 本节点处高度差超标
    return Math.max(l, r) + 1;
  };
  return height(root) !== -1;
};
```

**复杂度**：时间 O(n)，每个节点只被访问一次 ／ 空间 O(h)，h 为树高，最坏（链状）O(n)

**易错点**：
- 只判断根节点左右高度差，忘了递归判断左右子树自身是否平衡——这是最经典的错解，`[1,2,2,3,3,null,null,4,4]` 能把它抓出来。
- 用了 -1 哨兵却没有"先检查子调用结果"，接着用 -1 参与 Math.max，导致高度算错、错误继续上传。
- `height(null)` 必须返回 0 而不是 -1，否则单节点树会被判成不平衡。

**变体与追问**：
- 若问"最少删几个节点能让树平衡"，升级为树形 DP，函数返回 (高度, 删除数) 二元组。
- 追问"求树高"与"判平衡"的差别：前者必须走完全部节点，后者可以提前退出，平均更快但最坏仍是 O(n)。

### C-162 完全二叉树的节点个数 · 中等 · 字节/美团

**题干**：给你一棵**完全二叉树**的根节点 `root`，求出该树的节点个数。要求时间复杂度小于 O(n)。完全二叉树：除最后一层外每层都满，且最后一层的节点都集中在最左边。节点数在 `[0, 5×10⁴]` 范围内。

**示例**：`输入: root = [1,2,3,4,5,6]` → `输出: 6`；`输入: root = []` → `输出: 0`

**思路**：
- 朴素遍历是 O(n)，不满足"小于 O(n)"的要求。真正的考点是吃透完全二叉树的结构：对任意子树，沿最左链走到底得到左深度，沿最右链走到底得到右深度。
- 若两个深度相等，这棵子树就是满二叉树，节点数可直接用 2^h − 1 算出，整棵子树被"跳过"，一次递归都不用。
- 若不等，说明只有最后一层不满，此时递归统计左右子树。关键结论：每次递归至少有一棵子树是满的，被跳过的部分不产生额外代价，总复杂度降到 O(log²n)。
- 关键洞察："最左深度 == 最右深度"在完全二叉树里与"满二叉树"等价，这是唯一可靠的跳过判据；换成"看节点数是否等于 2^h−1"就得先遍历，失去意义。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var countNodes = function (root) {
  if (!root) return 0;
  // 沿一侧走到空，返回节点层数
  const depth = (node, goLeft) => {
    let d = 0;
    while (node) {
      d++;
      node = goLeft ? node.left : node.right;
    }
    return d;
  };
  const l = depth(root, true);
  const r = depth(root, false);
  if (l === r) return 2 ** l - 1;                 // 满二叉树，直接算
  return 1 + countNodes(root.left) + countNodes(root.right);
};
```

**复杂度**：时间 O(log²n)，每次递归耗时 O(log n)，递归深度 O(log n) ／ 空间 O(log n)

**易错点**：
- 用 `1 << l` 求 2^l，层数一大就 32 位溢出（本题 5×10⁴ 尚安全，但通用写法应使用 `2 ** l`）。
- 深度口径不统一：这里 depth 统计的是"层数/节点数"，用 2^h − 1 时必须配套，写成边数会差一半。
- 空树返回 0、单节点返回 1，是边界用例；`l === r === 1` 时公式给出 1，刚好正确，不要额外特判。

**变体与追问**：
- 若只给"节点总个数 n"，求最后一层最右节点的位置，可用二分 + 编号判断，是本题的迭代版本。
- 追问：如何判断一棵树是否完全二叉树？→ BFS 层序，一旦遇到空孩子，之后不允许再出现非空节点。

### C-163 二叉树的直径 · 简单 · 字节/腾讯

**题干**：给你一棵二叉树的根节点 `root`，返回该树的**直径**。直径是树中任意两个节点之间最长路径的**边数**。这条路径可能经过根节点，也可能不经过。节点数在 `[1, 10⁴]` 范围内。

**示例**：`输入: root = [1,2,3,4,5]` → `输出: 3`（路径 4→2→1→3 或 5→2→1→3）

**思路**：
- 任意一条路径都有唯一的"最高点"——路径上离根最近的那个节点。枚举所有节点作为最高点，就能覆盖全部路径，不需要单独考虑"不经过根"的情况。
- 以某节点为最高点的最长路径 = 左子树深度 + 右子树深度（深度按边数计，叶子深度为 0），因为路径只能向下各走一条链。
- 后序遍历天然适配：先递归拿到左右深度，在函数内用二者之和更新全局最大值，再把 max(左, 右) + 1 返回给父节点。一趟 O(n)。
- 关键洞察：答案必须用全局变量在所有节点处取最大。只在根节点算一次 left + right 是本题最高频的错误，因为最长路径完全可能整条都在左子树里。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var diameterOfBinaryTree = function (root) {
  let ans = 0;
  // 返回以 node 为起点向下的最长边数
  const dfs = (node) => {
    if (!node) return 0;
    const l = dfs(node.left);
    const r = dfs(node.right);
    ans = Math.max(ans, l + r);   // 以 node 为最高点的路径
    return Math.max(l, r) + 1;    // 只能向一侧延伸给父节点
  };
  dfs(root);
  return ans;
};
```

**复杂度**：时间 O(n) ／ 空间 O(h)，递归栈深度等于树高，最坏 O(n)

**易错点**：
- 只在根节点计算 `dfs(left) + dfs(right)`，漏掉最高点位于子树中的更长路径。
- 深度口径混用：把叶子深度当成 1，最后答案会比标准答案多 2（每条链都多算 1）。
- 单节点返回 0、空树返回 0，都要能过；用 `ans = -1` 初始化会让单节点变成 -1。

**变体与追问**：
- 若把"节点数"当作路径长度，答案是 left + right + 1，返回值不变。
- 边带权重的版本：把 `+1` 换成 `+ w`，其余结构完全不变，是同一套模板。

### C-164 二叉树中的最大路径和 · 困难 · 字节/阿里

**题干**：路径被定义为一条节点序列，序列中相邻节点在树中相连，同一个节点在一条路径中最多出现一次。路径至少包含一个节点，且不一定经过根节点。给你二叉树的根节点 `root`，返回其最大路径和。节点值范围 `[-1000, 1000]`。

**示例**：`输入: root = [-10,9,20,null,null,15,7]` → `输出: 42`（路径 15→20→7）；`输入: root = [-3]` → `输出: -3`

**思路**：
- 一条路径的最高点唯一确定这条路径：它由"最高点 + 向左下的一条链 + 向右下的一条链"组成。所以枚举最高点即可覆盖所有路径。
- 定义 `gain(node)` 为"以 node 为起点向下的最大单边贡献"。它只能选一侧，因为父节点只能接一条链，故返回 `node.val + max(左, 右)`。
- 负贡献直接剪掉（与 0 取 max）：任何一条最优路径都不会主动包含收益为负的子树，这是贪心的正确性来源。
- 在函数内部用 `node.val + 左 + 右` 更新全局答案——这是"以当前节点为最高点"的路径，也是唯一允许同时用两侧的时刻。
- 关键洞察：返回值（给父节点，只能一边）与副作用（更新答案，可以两边）语义不同，必须分开写，这是本题唯一的难点。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var maxPathSum = function (root) {
  let best = -Infinity;              // 不能写 0，全负树会错
  // 返回以 node 为起点向下的最大单边贡献
  const gain = (node) => {
    if (!node) return 0;
    const l = Math.max(gain(node.left), 0);    // 负贡献剪掉
    const r = Math.max(gain(node.right), 0);
    best = Math.max(best, node.val + l + r);   // 以 node 为最高点
    return node.val + Math.max(l, r);          // 给父节点只能用一侧
  };
  gain(root);
  return best;
};
```

**复杂度**：时间 O(n) ／ 空间 O(h)，递归栈深度等于树高

**易错点**：
- 把归值写成 `node.val + l + r`，父节点会拿一条"拐两次弯"的链，答案虚高且逻辑错误。
- 全局最大值初始化为 0，遇到全负树（如 `[-3]`、`[-1,-2]`）会返回 0 这个不存在的路径和。
- 忘记 `Math.max(..., 0)` 剪负，负值子树被强行拼进路径。
- 把"路径和"和"节点个数"混淆，用节点计数方式写返回值。

**变体与追问**：
- 若要求输出最大路径本身：递归返回 (贡献, 路径节点数组)，合并取最大时拼接。
- 若限制"必须从根出发"，则退化为简单版，答案就是 max(gain(root), 0)，不需要全局变量。

### C-165 路径总和 · 简单 · 阿里/美团

**题干**：给你二叉树的根节点 `root` 和一个表示目标和的整数 `targetSum`，判断该树中是否存在**根节点到叶子节点**的路径，这条路径上所有节点值相加等于 `targetSum`。叶子节点指没有子节点的节点。

**示例**：`输入: root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22` → `输出: true`（5→4→11→2）；`输入: root = [1,2,3], targetSum = 5` → `输出: false`

**思路**：
- 把"目标和"改成"剩余要凑的数"往下传：每进入一个节点就减去它的值，到叶子时判断剩余是否恰好等于 0。这样不需要额外的累加变量，天然无回溯问题。
- 必须在叶子处判定：中途某个节点的值恰好等于剩余值但还有子节点，不算答案，因为路径必须终止于叶子。
- 空树直接返回 false；叶子判定要先于递归，否则单向孩子的节点会被漏判。
- 这是"带状态的递归"最基础的形态，下一题路径总和 II 只是把它改成"收集所有满足的路径"。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var hasPathSum = function (root, targetSum) {
  if (!root) return false;                    // 空树无路径
  // 叶子：剩余值必须正好等于当前节点值（传入时尚未扣除）
  if (!root.left && !root.right) return targetSum === root.val;
  return (
    hasPathSum(root.left, targetSum - root.val) ||
    hasPathSum(root.right, targetSum - root.val)
  );
};
```

**复杂度**：时间 O(n)，最坏访问全部节点 ／ 空间 O(h)，递归栈深度

**易错点**：
- 在非叶子节点就判断 `targetSum === node.val` 并返回 true，`[1,2] , 1` 这类用例会误判。
- 改用全局 sum 累加却忘记回溯（sum -= node.val），兄弟分支互相污染。
- 先递归再判叶子，导致进入 null 时访问 `root.val` 报错。
- 把"根到任意节点"当成"根到叶"，题意读错——本题要求叶子结束。

**变体与追问**：
- 若允许在任意节点结束（不要求叶子），把叶子判断改成"遇到剩余为 0 即 true"，但要注意节点值可为负，不能提前剪枝。
- 若要求路径不必须从根开始，就是 437 路径总和 III，需要前缀和 + 哈希表。

### C-166 路径总和 II · 中等 · 字节/快手

**题干**：给你二叉树的根节点 `root` 和一个整数目标和 `targetSum`，找出所有**从根节点到叶子节点**路径总和等于 `targetSum` 的路径，以二维数组返回（顺序不限）。节点值可为负数。

**示例**：`输入: root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22` → `输出: [[5,4,11,2],[5,8,4,5]]`

**思路**：
- 在 112 的基础上加"收集"：用 `path` 数组记录当前递归栈上的节点值，进入节点 push，离开节点 pop，这就是标准的回溯骨架。
- 因为节点值可能为负，不能靠"和已经超过目标"提前剪枝，必须一路走到叶子。
- 命中条件是"叶子 + 剩余值等于当前节点值"，此时要把 `path` **深拷贝**一份再放入结果，否则后续 pop 会把结果里的数组清空。
- 关键洞察：回溯（pop）必须放在两个递归**之后**，且不能放在 return 之前的分支里——否则提前返回的那条分支不会撤销选择，污染兄弟分支。用 `[...path]` 拷贝是唯一正确的收集方式。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var pathSum = function (root, targetSum) {
  const res = [];
  const path = [];
  const dfs = (node, rest) => {
    if (!node) return;
    path.push(node.val);                       // 做选择
    if (!node.left && !node.right && rest === node.val) {
      res.push([...path]);                     // 必须拷贝快照
    }
    dfs(node.left, rest - node.val);
    dfs(node.right, rest - node.val);
    path.pop();                                // 撤销选择
  };
  dfs(root, targetSum);
  return res;
};
```

**复杂度**：时间 O(n²) 最坏（链状树时每条路径拷贝 O(n)）／ 空间 O(h)，不计结果集

**易错点**：
- `res.push(path)` 没拷贝，最后结果全是空数组——这是本题第一杀手。
- 把 `path.pop()` 写在两个递归之间，导致右子树看到了左子树残留的节点。
- 在非叶子节点就收集，或漏判叶子，答案会多出前缀路径。
- 认为节点值为正可以剪枝——本题允许负值，剪枝会漏解。

**变体与追问**：
- 若路径允许从任意节点开始（不要求根），改为 437 的前缀和做法。
- 若只问"有几条"而不需要具体路径，省掉 path 数组，直接计数，空间降到 O(h)。

### C-167 路径总和 III · 中等 · 字节/腾讯

**题干**：给定一个二叉树的根节点 `root` 和一个整数 `targetSum`，求该二叉树里节点值之和等于 `targetSum` 的**路径数目**。路径不需要从根节点开始，也不需要在叶子节点结束，但方向必须向下（只能从父节点到子节点）。节点值可为负数，节点数 ≤ 1000。

**示例**：`输入: root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8` → `输出: 3`

**思路**：
- 暴力双重递归：以每个节点为起点向下累加求和，复杂度 O(n²)，n ≤ 1000 能过，但面试要的是 O(n)。
- 把数组上的"和为 K 的子数组"搬上树：任意一条向下的路径都可以写成"两个根前缀和之差"。遍历到节点时当前前缀和为 `cur`，只要历史路径上出现过 `cur - target`，就说明存在对应数量的路径以当前节点结尾。
- 用哈希表记录"从根到当前节点的这条链上，各前缀和出现了几次"，初始化为 `{0: 1}` 表示空前缀，用来覆盖"路径从根开始"的情况。
- 关键洞察：哈希表必须随递归**回溯**——进入节点加一，离开节点减一。否则左子树的前缀和会被右子树看到，统计出根本不存在的跨分支路径。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var pathSum = function (root, targetSum) {
  const prefix = new Map([[0, 1]]);        // 空前缀：覆盖"从根开始"
  let count = 0;
  const dfs = (node, cur) => {
    if (!node) return;
    cur += node.val;
    count += prefix.get(cur - targetSum) || 0;
    prefix.set(cur, (prefix.get(cur) || 0) + 1);
    dfs(node.left, cur);
    dfs(node.right, cur);
    prefix.set(cur, prefix.get(cur) - 1);  // 回溯，防止跨子树污染
  };
  dfs(root, 0);
  return count;
};
```

**复杂度**：时间 O(n)，每个节点进出各一次 ／ 空间 O(n)（哈希表最坏存 n 个不同前缀和）

**易错点**：
- 忘记初始化 `Map([[0, 1]])`，所有"从根出发"的路径都会漏算。
- 回溯时忘记把计数减一（直接 delete 也会错，因为前缀和可能重复出现）。
- 把 `cur` 当全局变量累加却不回退，或者把 `cur += node.val` 写在两次递归之间。
- 以为节点值为正可以剪枝——本题允许负数，剪枝必错。

**变体与追问**：
- 若改成"必须经过根节点"，直接用分治：统计跨根的路径数再递归左右。
- 若在数组上做同样的事，就是 560 和为 K 的子数组，模板完全一致。

### C-168 根到叶数字之和 · 中等 · 美团/拼多多

**题干**：给你一个二叉树的根节点 `root`，树中每个节点都存放一个 `0` 到 `9` 之间的数字。每条从根到叶的路径都代表一个从最高有效位开始的数字（例如路径 1→2→3 表示 123）。计算从根到叶生成的所有数字之和。叶子节点指没有子节点的节点。

**示例**：`输入: root = [1,2,3]` → `输出: 25`（12 + 13）；`输入: root = [4,9,0,5,1]` → `输出: 1026`（495 + 491 + 40）

**思路**：
- 数字是从高位往低位拼的，所以必须自顶向下维护 `cur = cur * 10 + node.val`，到叶子时把 cur 累加进总和。
- 不能自底向上拼：自底向上需要先知道子树深度才能确定当前数字的权重（10 的几次方），信息方向反了。
- 整棵树只有一趟遍历，每个节点贡献一次乘法，天然 O(n)。
- 关键洞察：`cur` 作为参数传递（而不是全局变量）就不需要手动回溯——这是把"状态"放在函数参数里的好处，也是回溯题降错误率的常用手法。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var sumNumbers = function (root) {
  let total = 0;
  const dfs = (node, cur) => {
    if (!node) return;
    cur = cur * 10 + node.val;                 // 高位在前的拼接
    if (!node.left && !node.right) {           // 到叶子才结算
      total += cur;
      return;
    }
    dfs(node.left, cur);
    dfs(node.right, cur);
  };
  dfs(root, 0);
  return total;
};
```

**复杂度**：时间 O(n) ／ 空间 O(h)，递归栈深度，最坏 O(n)

**易错点**：
- 用字符串 `cur + node.val` 再 `Number()` 转换，逻辑对但常数大，且超长路径会丢精度。
- 只在"有孩子"时递归、忘了处理叶子，导致叶子路径不结算。
- 把叶子判断写成 `if (!node)`，这样在 null 上就 return，但根的 val 已被漏加。
- 总和使用 32 位思维，深度大时会溢出（JavaScript 用 double，本题范围内安全）。

**变体与追问**：
- 若求所有数字的**乘积**，把累加改成累乘，注意初始值为 1。
- 若方向反过来（从叶到根拼字符串、求字典序最小），就是 988 从叶结点开始的最小字符串。

### C-169 二叉树的所有路径 · 简单 · 阿里/快手

**题干**：给你一个二叉树的根节点 `root`，按任意顺序返回所有**从根节点到叶子节点**的路径。每条路径以字符串形式表示，节点之间用 `"->"` 连接。叶子节点指没有子节点的节点。

**示例**：`输入: root = [1,2,3,null,5]` → `输出: ["1->2->5","1->3"]`；`输入: root = [1]` → `输出: ["1"]`

**思路**：
- 把"当前已走的路径"当作参数往下传：进入子节点时传 `path + node.val + "->"`，到叶子时把末尾的箭头裁掉即可。
- 因为字符串是不可变值，每条分支拿到的都是独立副本，天然不需要回溯——这是比"数组 + push/pop"更不容易写错的版本。
- 若坚持用数组：push 当前值、递归左右、再 pop，叶子处 `path.join("->")` 收集。两种写法等价，面试任选其一但要讲清取舍。
- 关键洞察：本题是"路径型回溯"的最小模板，所有根到叶的变体（求和、求数字、求最大字典序）都只是在叶子处换一个结算动作。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var binaryTreePaths = function (root) {
  const res = [];
  const dfs = (node, path) => {
    if (!node) return;
    path += node.val;                          // 字符串不可变，天然隔离分支
    if (!node.left && !node.right) {
      res.push(path);                          // 叶子即结算
      return;
    }
    dfs(node.left, path + '->');
    dfs(node.right, path + '->');
  };
  dfs(root, '');
  return res;
};
```

**复杂度**：时间 O(n·h)，每条路径长度 h，最坏 O(n²)（链状树）／ 空间 O(h)，不计结果集

**易错点**：
- 空树要返回 `[]`，而不是 `[""]`——只有真正到达叶子才 push。
- 在根节点就判断 `if (!node.left && !node.right)` 之前忘了先赋值 path，单节点树会输出空串。
- 用数组写时忘记 pop，兄弟分支路径串在一起。
- 箭头拼接位置写错（在 `path += node.val` 之前加），会出现 `"->1->2"` 这样的畸形串。

**变体与追问**：
- 若要求返回字典序最小的路径，把收集改成"比较并保留最小"（LC 988）。
- 若要求返回所有路径的节点数组而非字符串，push 时改用 `[...path]`，就是 113 的骨架。

### C-170 左叶子之和 · 简单 · 腾讯/美团

**题干**：给定二叉树的根节点 `root`，返回所有**左叶子**之和。左叶子定义为：它是某个节点的左孩子，且它本身没有子节点。节点值范围 `[-1000, 1000]`（可为负）。

**示例**：`输入: root = [3,9,20,null,null,15,7]` → `输出: 24`（左叶子只有 9 和 15）；`输入: root = [1]` → `输出: 0`

**思路**：
- 一个节点无法靠自己判断"我是左孩子还是右孩子"，这个身份只有父节点知道，所以必须由父节点把"是否左孩子"作为参数往下传。
- 递归条件是"是左孩子 **且** 是叶子"，两者缺一不可：只判叶子会把右叶子算进来，只判左孩子会把非叶子的左节点算进来。
- 另一种等价写法是在父节点处检查 `node.left` 是否为叶子，直接累加——把判定下沉一层，少传一个参数。
- 关键洞察：本题是"父节点视角 vs 子节点视角"的典型对照，面试里能把两种写法都讲出来并说明为什么要传标志，就是加分项。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var sumOfLeftLeaves = function (root) {
  // isLeft：当前节点是否为父节点的左孩子
  const dfs = (node, isLeft) => {
    if (!node) return 0;
    if (!node.left && !node.right) {
      return isLeft ? node.val : 0;            // 左叶子才计数
    }
    return dfs(node.left, true) + dfs(node.right, false);
  };
  return dfs(root, false);                     // 根节点不算左孩子
};
```

**复杂度**：时间 O(n) ／ 空间 O(h)，递归栈深度

**易错点**：
- 只判断"是叶子"就累加，右叶子（如示例中的 7）被错误计入。
- 递归时把左右标志写反，或者两处都传 true。
- 根节点误传 `true`，单节点树会返回根的值而不是 0。
- 节点值可为负，用 `ans = 0` 初始化没问题，但不要用 `-1` 之类的哨兵。

**变体与追问**：
- 求"右叶子之和"只需把标志取反；求"所有叶子之和"则完全不需要方向标志。
- 追问：求"最深的那一层的左叶子之和"——先求最大深度，再带深度参数二次遍历。

### C-171 找树左下角的值 · 中等 · 字节/美团

**题干**：给定一个二叉树的根节点 `root`，请找出该二叉树**最底层最左边**节点的值。假设二叉树中至少有一个节点。

**示例**：`输入: root = [2,1,3]` → `输出: 1`；`输入: root = [1,2,3,4,null,5,6,null,null,7]` → `输出: 7`

**思路**：
- 答案的定义是"最大深度那一层的最左节点"。层序遍历天然按层推进，每层的第一个元素就是该层最左节点，最后一层第一个即所求。
- 实现上每层开始前用 `queue[0].val` 覆盖一次答案，遍历完整棵树后留下的必然是最后一层的值——因为层序保证后处理的层一定更深。
- DFS 也能做：带深度参数，只有"深度严格大于当前记录"时才更新。同层不更新，先序遍历保证先遇到的是最左。
- 关键洞察：BFS 里"每次覆盖"不是 bug 而是设计——它用遍历顺序代替了比较深度，省掉一个状态变量。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var findBottomLeftValue = function (root) {
  let queue = [root];
  let ans = root.val;
  while (queue.length) {
    const next = [];
    ans = queue[0].val;                       // 每层第一个就是该层最左
    for (const node of queue) {
      if (node.left) next.push(node.left);
      if (node.right) next.push(node.right);
    }
    queue = next;                             // 推进到下一层
  }
  return ans;
};
```

**复杂度**：时间 O(n) ／ 空间 O(w)，w 为树的最大层宽（完全二叉树最坏 O(n)）

**易错点**：
- DFS 版本用 `>=` 更新深度，同层会不断被右侧节点覆盖，最后拿到最右。
- BFS 用 `queue.pop()` 或反向入队，结果变成最底层最右。
- 答案初值写成 0，若节点全为负又没有覆盖到位就会错——直接用 `root.val` 最稳。
- 把"最左"理解成"根一直往左走到底"，忽略了左子树可能很浅而右子树更深的情况。

**变体与追问**：
- 求"最底层最右"：BFS 每层取 `queue[queue.length - 1]`，或先入右孩子。
- 求"树的最大宽度"（LC 662）需要给节点编下标（左 2i、右 2i+1），再按层求下标差。

### C-172 最长同值路径 · 中等 · 字节/阿里

**题干**：给定一个二叉树的根节点 `root`，返回**最长的同值路径**的长度。这条路径中每个节点的值都相同，可以经过也可以不经过根节点。两个节点之间的路径长度用它们之间的**边数**表示。

**示例**：`输入: root = [5,4,5,1,1,null,5]` → `输出: 2`（路径 5→5→5 左侧两条边）；`输入: root = [1,4,5,4,4,null,5]` → `输出: 2`

**思路**：
- 与 543 二叉树的直径完全同构：同值路径也有唯一的最高点，以某节点为最高点的同值路径 = 左侧同值链长 + 右侧同值链长（按边数计）。
- 递归返回"以当前节点为起点、向下延伸的同值边数"：只有当子节点值与当前值相等时该侧才能 +1，否则该侧贡献为 0。
- 注意"该侧贡献为 0"不代表"该子树里没有更长的同值路径"——子树内部的答案由下层递归时已经更新过全局变量，所以本层只需老实取 0。
- 关键洞察：比较必须发生在"父与子"之间，所以判断是 `child.val === node.val`；而返回值单位是**边**，所以匹配时是 `+1` 而不是 `+1 个节点`。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var longestUnivaluePath = function (root) {
  let ans = 0;
  // 返回以 node 为起点向下的同值边数
  const dfs = (node) => {
    if (!node) return 0;
    const l = dfs(node.left);
    const r = dfs(node.right);
    // 只有值相同，这条边才能接上
    const left = node.left && node.left.val === node.val ? l + 1 : 0;
    const right = node.right && node.right.val === node.val ? r + 1 : 0;
    ans = Math.max(ans, left + right);   // 以 node 为最高点
    return Math.max(left, right);        // 只能单边延伸给父节点
  };
  dfs(root);
  return ans;
};
```

**复杂度**：时间 O(n) ／ 空间 O(h)，递归栈深度

**易错点**：
- 把 `ans` 更新写成 `Math.max(ans, Math.max(left, right))`，漏掉"左右两支同时出现"的情况（示例 1 的答案正是 1+1）。
- 返回值单位搞错：返回节点数而非边数，全同值链会多 1。
- 空树返回 0 没问题，但单节点树必须返回 0（无同值边），不要返回 1。
- 直接用 `node.left.val === node.val` 而不判 `node.left` 是否存在，空指针报错。

**变体与追问**：
- 若求"最长同值路径的节点数"，答案在最后 +1（路径为空时特判 0）。
- 若求"最长递增路径"（子节点值严格大于父节点），只需把 `===` 换成 `<`，模板不变。

### C-173 二叉树的坡度 · 简单 · 美团/字节

**题干**：一个树的**节点的坡度**定义为该节点左子树的节点之和与右子树节点之和的差的绝对值；没有左子树时左子树节点和为 0。**整个树的坡度**是所有节点坡度之和。给你二叉树的根节点 `root`，返回整个树的坡度。

**示例**：`输入: root = [1,2,3]` → `输出: 1`；`输入: root = [4,2,9,3,5,null,7]` → `输出: 15`

**思路**：
- 计算坡度需要"左子树所有节点之和"，而子树和只能自底向上聚合——后序遍历是把信息从叶子往上传的唯一顺序。
- 辅助函数返回以当前节点为根的子树和：`l + r + node.val`；在返回之前，用 `Math.abs(l - r)` 累加进全局坡度。
- 一趟遍历同时完成"求子树和"跳板和"累加所有坡度"两件事，O(n) 已是最优，因为每个节点至少要读一次。
- 关键洞察：这里的"返回值"和"副作用"再次分离——返回子树和（父节点需要），全局变量累加坡度（答案需要），和 124 的结构一模一样。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var findTilt = function (root) {
  let total = 0;
  // 返回以 node 为根的子树节点和
  const sum = (node) => {
    if (!node) return 0;
    const l = sum(node.left);
    const r = sum(node.right);
    total += Math.abs(l - r);      // 累加当前节点的坡度
    return l + r + node.val;       // 子树和上传
  };
  sum(root);
  return total;
};
```

**复杂度**：时间 O(n) ／ 空间 O(h)，递归栈深度

**易错点**：
- 只算根节点一个坡度就返回，忽略了"所有节点"这个限定。
- 返回 `l + r` 忘了加 `node.val`，父节点拿到的子树和偏小，连锁出错。
- 把坡度写成 `l - r` 不加绝对值，负坡度互相抵消。
- 空树返回 0；单节点坡度 0，也要能正确处理。

**变体与追问**：
- 若求"每个节点的坡度数组"，把累加改成 push 进数组即可。
- 若改成"统计值等于子树平均值的节点数"（LC 2265），返回值升级为 (和, 个数) 二元组。

### C-174 打家劫舍 III · 中等 · 字节/腾讯

**题干**：房屋排列成一棵二叉树，入口为 `root`。如果两个**直接相连**的房子在同一晚被打劫，房屋会自动报警。给定二叉树的根节点 `root`，返回在不触动警报的情况下能够盗取的最高金额。节点值非负。

**示例**：`输入: root = [3,2,3,null,3,null,1]` → `输出: 7`（偷 3 + 3 + 1）；`输入: root = [3,4,5,1,3,null,1]` → `输出: 9`（偷 4 + 5）

**思路**：
- 每个节点只有"偷 / 不偷"两个决策。偷了当前节点，两个子节点都必须不偷；不偷当前节点，子节点各自取最优即可。这是典型的树形 DP。
- 辅助函数返回二元组 `[不偷该节点的最优, 偷该节点的最优]`：`notRob = max(左[0], 左[1]) + max(右[0], 右[1])`，`doRob = val + 左[0] + 右[0]`。
- 为什么必须返回两个值？因为如果只返回"这棵子树的最大收益"，父节点无法知道子节点到底偷没偷，"偷了父节点就不能偷子节点"这个约束就无处表达——这就是后效性。
- 关键洞察：把状态显式暴露给调用方，是消解树上后效性的通用手段；它比记忆化搜索（Map 缓存）更省空间，因为一次后序遍历天然无重复子问题。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var rob = function (root) {
  // 返回 [不偷 node 的最大收益, 偷 node 的最大收益]
  const dfs = (node) => {
    if (!node) return [0, 0];
    const [nl, yl] = dfs(node.left);
    const [nr, yr] = dfs(node.right);
    const notRob = Math.max(nl, yl) + Math.max(nr, yr);  // 儿子随意
    const doRob = node.val + nl + nr;                    // 儿子必须不偷
    return [notRob, doRob];
  };
  const [a, b] = dfs(root);
  return Math.max(a, b);
};
```

**复杂度**：时间 O(n)，每个节点只访问一次 ／ 空间 O(h)，递归栈深度

**易错点**：
- 只返回一个最优值，父节点无法区分"子节点偷了没"，约束丢失。
- `doRob` 里误用 `Math.max(nl, yl)`，等于允许儿子被偷，答案虚高。
- 写记忆化搜索时用节点值当 key，节点值重复会串答案——必须用节点引用作 key。
- 空树返回 0（不是 `[0,0]`，注意在调用层取 max 时的位置）。

**变体与追问**：
- 若房子排成一条直线，退化为 LC 198；排成环则是 LC 213（拆成"抢首不抢尾"两种）。
- 若限制"最多只能偷 k 个房子"，二元组升级为三维 DP：`[偷/不偷][已偷个数]`。

### C-175 二叉树中第二小的节点 · 简单 · 阿里/美团

**题干**：给定一个特殊的二叉树：每个节点是正数，子节点数量只能是 2 或 0；且若某节点有两个子节点，则该节点的值等于两个子节点中**较小**的那个。求所有节点中**第二小**的值；若不存在则返回 `-1`。

**示例**：`输入: root = [2,2,5,null,null,5,7]` → `输出: 5`；`输入: root = [2,2,2]` → `输出: -1`

**思路**：
- 由性质可直接推出：**根节点一定是全局最小值**。因为每个父节点都等于子节点中的较小者，最小值只能一路上浮到根，所以 root.val 就是整个树的最小值。
- 于是"第二小"等价于"所有严格大于 root.val 的节点中的最小值"。递归时：若子节点值等于 root.val，说明它也是最小值，得继续往下找；否则它的值就是这一侧的候选。
- 两侧候选合并时，用 -1 表示"该侧没有候选"，取非 -1 的最小值。
- 关键洞察：利用结构可以做到剪枝——一旦某侧已经找到候选（值 > 根值），这条分支就不必再深入，因为下面的值只会更大。这是本题优于"收集全部值再排序"的原因。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var findSecondMinimumValue = function (root) {
  if (!root) return -1;
  // 只在"值大于全局最小值"的节点上取最小
  const dfs = (node) => {
    if (!node.left) return -1;                       // 叶子没有候选
    const l = node.left.val === root.val ? dfs(node.left) : node.left.val;
    const r = node.right.val === root.val ? dfs(node.right) : node.right.val;
    if (l === -1) return r;
    if (r === -1) return l;
    return Math.min(l, r);
  };
  return dfs(root);
};
```

**复杂度**：时间 O(n) 最坏（大量重复最小值时需一路下探）／ 空间 O(h)

**易错点**：
- 把"等于 root.val 的子节点"也当候选，答案退化成了最小值。
- 用 Set 收集后排序取 `[1]`，逻辑上能过但没利用结构；且 `[2,2,2]` 要特判长度为 1。
- 递归只走一侧就返回，漏掉另一侧可能更小的候选。
- 单节点树（无第二小）应返回 -1，不要返回节点值本身。

**变体与追问**：
- 若求"第 k 小"且树是 BST，直接中序遍历计数即可（LC 230）。
- 若树不满足本题的特殊性质，就退化为"遍历 + 维护最小与次小"的通用写法。

### C-176 统计值等于子树平均值的节点数 · 中等 · 美团/拼多多

**题干**：给你一棵二叉树的根节点 `root`，返回**值等于该节点子树平均值**的节点数量。子树平均值 = 子树中所有节点值的总和 ÷ 节点数量，结果**向下取整**。

**示例**：`输入: root = [4,8,5,0,1,null,6]` → `输出: 5`（5 个节点满足）

**思路**：
- 每个节点要判定平均值，就必须同时知道两件事：子树的**和**与子树的**节点个数**；只知道和是算不出平均值的。
- 后序返回二元组 `[sum, cnt]`：`sum = 左和 + 右和 + val`，`cnt = 左数 + 右数 + 1`。在本层先用 `Math.floor(sum / cnt)` 与 `val` 比较并累加计数，再返回二元组。
- 一行递归同时完成聚合与判定，正是后序遍历的强项：子树信息必须先于父节点可用。
- 关键洞察：树形 DP 常把"聚合值"打包成元组返回。坡度只要和（一维），本题要"和 + 个数"（二维），打家劫舍要"偷/不偷"（二维）——维度由问题需要的信息量决定。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var averageOfSubtree = function (root) {
  let count = 0;
  // 返回 [子树和, 子树节点数]
  const dfs = (node) => {
    if (!node) return [0, 0];
    const [ls, lc] = dfs(node.left);
    const [rs, rc] = dfs(node.right);
    const sum = ls + rs + node.val;
    const cnt = lc + rc + 1;
    if (Math.floor(sum / cnt) === node.val) count++;
    return [sum, cnt];
  };
  dfs(root);
  return count;
};
```

**复杂度**：时间 O(n) ／ 空间 O(h)，递归栈深度

**易错点**：
- 用 `Math.round` 或直接 `sum / cnt` 比较浮点，题目要求的是**向下取整**。
- 只返回子树和，导致父节点算不出平均值（信息不足）。
- 计数变量放在递归内部声明，每次调用都被重置，最后只剩 1 或 0。
- 空树返回 0；单节点树必然满足（val 等于自身平均），要能返回 1。

**变体与追问**：
- 若求"值**大于**子树平均值的节点数"，只改比较符，模板不变。
- 若要求返回所有满足条件的节点（而非计数），把 `count++` 换成收集节点引用。

### C-177 最深叶节点的最近公共祖先 · 中等 · 快手/字节

**题干**：给你一棵有根二叉树，返回它**最深叶节点的最近公共祖先**。最深叶节点是深度最大的叶子节点（根的深度为 0）。若最深叶节点只有一个，它自己就是答案。

**示例**：`输入: root = [3,5,1,6,2,0,8,null,null,7,4]` → `输出: 2`（最深叶子 7 和 4 的父节点）

**思路**：
- 对任意节点，只要比较"左子树里最深叶子的深度"与"右子树里最深叶子的深度"：相等则最深叶子分布在两侧，当前节点即为它们的 LCA；不等则 LCA 一定在更深的那一侧。
- 递归返回二元组 `(子树内最大深度, 该子树内最深叶子的 LCA)`。深度用**相对深度**（叶子返回 1 或 0 均可，只要一致），千万不能用全局最大深度去比。
- 左右相等时返回 `(深度 + 1, node)`；不等时把更深一侧的结果整体透传，深度 + 1。
- 关键洞察：这个"返回 (深度, 节点)"的形态和 1123 官方解法一致，本质是把"找最深处"和"找 LCA"合并成一趟后序，避免两趟遍历。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var lcaDeepestLeaves = function (root) {
  // 返回 [子树最大深度, 该子树内最深叶子的 LCA]
  const dfs = (node) => {
    if (!node) return [0, null];
    const [ld, ln] = dfs(node.left);
    const [rd, rn] = dfs(node.right);
    if (ld === rd) return [ld + 1, node];        // 两侧一样深 → 自己是 LCA
    return ld > rd ? [ld + 1, ln] : [rd + 1, rn]; // 更深的一侧透传
  };
  return dfs(root)[1];
};
```

**复杂度**：时间 O(n) ／ 空间 O(h)，递归栈深度

**易错点**：
- 先求全局最大深度再找 LCA，两趟遍历且容易在"该节点子树是否有最深叶子"上判错。
- 左右深度相等时返回 `null` 或某一侧的子结果，漏掉"当前节点才是分叉点"。
- 把深度 +1 加在错误的分支上，导致比较基准错位。
- 单节点树（root 自己是最深叶）应返回 root，验证 `ld === rd === 0` 的逻辑是否正确。

**变体与追问**：
- 若要求返回所有最深叶子节点本身（数组），需要带全局最大深度做二次遍历。
- 若求"最深叶子的个数"，在同样框架里把 LCA 换成计数即可。

### C-178 二叉树的最近公共祖先 · 中等 · 字节/阿里

**题干**：给定一个二叉树，找到该树中两个指定节点 `p`、`q` 的最近公共祖先。最近公共祖先：对节点 x，若 x 是 p、q 的祖先且 x 的深度尽可能大，则 x 为答案（一个节点也可以是它自己的祖先）。树中所有节点值唯一，p、q 均存在于树中。

**示例**：`输入: root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1` → `输出: 3`；`p = 5, q = 4` → `输出: 5`

**思路**：
- 递归语义定死："在以 root 为根的子树中找 p 或 q，找到哪个就返回哪个，都没找到返回 null"。这个朴素语义里已经蕴含了 LCA 的判定。
- 三种情况：左右返回值都非空 → p、q 分居两侧，root 就是 LCA；只有一侧非空 → 那侧返回的节点就是答案（它可能是 LCA 本身，也可能只是命中的 p/q）；两侧都空 → null。
- 基准情形：root 为空、root 就是 p、root 就是 q，三种都直接返回 root。此时返回的信息是"不完整"的（不知道另一侧有没有），但结合上层的双侧判定，恰好足够推出正确结果。
- 关键洞察：这是"返回值承载状态"的经典案例——不要试图在每一层判断"p 和 q 都在不在"，而是让返回值自己表达。比较时用节点**引用**而非 val，才是通用写法。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var lowestCommonAncestor = function (root, p, q) {
  // 基准情形返回"命中的那个节点"，它可能只是 p 或 q 本身
  if (!root || root === p || root === q) return root;
  const left = lowestCommonAncestor(root.left, p, q);
  const right = lowestCommonAncestor(root.right, p, q);
  if (left && right) return root;    // p、q 分居两侧，root 即 LCA
  // 只有一侧命中：p、q 都在那一侧，答案已由该侧带回
  return left || right;
};
```

**复杂度**：时间 O(n)，最坏遍历全部节点 ／ 空间 O(h)，递归栈深度

**易错点**：
- 用 `root.val === p.val` 比较，节点值重复（非本题约束）时会命中错误节点。
- 漏掉 `root === p || root === q` 的基准情形，导致祖先链断掉。
- 只处理"两侧都非空"，忘记 `return left || right` 导致同侧情形返回 null。
- 试图用一个全局变量记住答案，反而把简单问题写复杂——本题不需要全局变量。

**变体与追问**：
- 若树是 BST，利用值的大小关系可以迭代下降，O(h) 且不用递归（LC 235）。
- 若 p、q 可能不在树中，需要额外一遍校验；若求 k 个节点的 LCA，可返回命中计数。

### C-179 从叶结点开始的最小字符串 · 中等 · 腾讯/阿里

**题干**：给定一棵根为 `root` 的二叉树，每个节点的值都是 `0` 到 `25` 的整数，分别代表字母 `a` 到 `z`（`0` 代表 `a`，`1` 代表 `b`，依此类推）。返回从**叶节点开始、到根节点结束**的所有字符串中**字典序最小**的那个。

**示例**：`输入: root = [0,1,2,3,4,3,4]` → `输出: "dba"`（路径 3→1→0）；`输入: root = [25,1,3,1,3,0,2]` → `输出: "adz"`

**思路**：
- 方向是"叶 → 根"，也就是离根越近的字符越靠后。所以拼接新字符时必须放在**前面**：`cur = char + suffix`，才能保证根节点字母是最后一位。
- 自顶向下把"已拼好的后缀"往上传，到叶子时 `cur` 就是完整字符串，与当前最优做字典序比较并保留更小者。
- 也可以反向：回溯时把字符 push 进数组，到叶子时 reverse 再 join。两者等价，但字符串前缀拼接不需要撤销操作，更难写错。
- 关键洞察：字典序比较不能先比长度，直接用 JS 的 `<` 即可；而且必须在叶子处比较，非叶子节点的串是别条路径的前缀，没有意义。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var smallestFromLeaf = function (root) {
  let best = null;
  const dfs = (node, suffix) => {
    if (!node) return;
    // 叶在根之前，所以新字符拼在头部
    const cur = String.fromCharCode(97 + node.val) + suffix;
    if (!node.left && !node.right) {
      if (best === null || cur < best) best = cur;
      return;
    }
    dfs(node.left, cur);
    dfs(node.right, cur);
  };
  dfs(root, '');
  return best === null ? '' : best;
};
```

**复杂度**：时间 O(n·h)，每次拼接复制长度 h 的字符串，最坏 O(n²) ／ 空间 O(h)

**易错点**：
- 写成 `suffix + char`，得到的是根到叶的顺序，`"abd"` 与 `"dba"` 完全相反。
- 在非叶子节点就比较并更新 best，路径没有结束，结果错误。
- 用 `best = ""` 初始化后靠 `if (!best || ...)` 判断，虽然能跑但语义模糊，建议用 `null` 显式区分。
- 以为字典序 = 长度，先比长度再看字符，逻辑错误。

**变体与追问**：
- 若求字典序**最大**的字符串，把 `<` 改成 `>`，其余不动。
- 若求"根到叶字典序最小"，改用正序拼接（后缀追加），就是 257 的变体。

### C-180 二叉树中的伪回文路径 · 中等 · 阿里/美团

**题干**：给你一棵二叉树，每个节点的值为 `1` 到 `9`。称一条从根到叶的路径是**伪回文**的，当且仅当路径上所有节点值的某种排列可以构成回文序列。返回所有根到叶路径中伪回文路径的**数目**。

**示例**：`输入: root = [2,3,1,3,1,null,1]` → `输出: 2`；`输入: root = [2,1,1,1,3,null,null,null,null,null,1]` → `输出: 1`

**思路**：
- 一条序列能重排成回文 ⟺ 最多只有一个数字出现奇数次（偶数长度要求全偶，奇数长度允许恰好一个奇）。所以真正需要的信息不是每个数字出现几次，而是**次数的奇偶性**。
- 值域只有 1~9，用 9 位掩码表示奇偶：进入节点时 `mask ^= 1 << val`，该位的奇偶被翻转。异或天然满足"经过两次就抵消"，因此不需要显式回溯。
- 到叶子时判断 `mask` 中 1 的个数是否 ≤ 1：`mask & (mask - 1)` 会消掉最低位的 1，结果为 0 说明最多一个 1（0 个或 1 个都算）。
- 关键洞察：用位运算替代"计数数组 + 回溯"，既省掉撤销动作，又把"判断回文"压成一次位与，是状态压缩在树上的典型应用。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var pseudoPalindromicPaths = function (root) {
  let count = 0;
  const dfs = (node, mask) => {
    if (!node) return;
    mask ^= 1 << node.val;                       // 翻转该数字的奇偶位
    if (!node.left && !node.right) {
      // 最多一个 1 → 可重排成回文
      if ((mask & (mask - 1)) === 0) count++;
      return;
    }
    dfs(node.left, mask);
    dfs(node.right, mask);
  };
  dfs(root, 0);
  return count;
};
```

**复杂度**：时间 O(n) ／ 空间 O(h)，递归栈深度（掩码是数字，按值传递）

**易错点**：
- 把"最多一个 1"写成"恰好一个 1"，偶数长度的合法路径会被漏掉。
- 用计数数组却忘记在回溯时减一，兄弟分支互相污染。
- 在非叶节点计数，路径没有走完就判定。
- `1 << node.val` 时误以为要用 `val - 1`，其实只要全局一致即可（本题用 1~9 位没问题）。

**变体与追问**：
- 若要求路径上字符**顺序本身**是回文，就不能只用奇偶性，需要双端比较或哈希。
- 若求"最长伪回文路径"，升级为状态压缩 DP：记录每个掩码的最深深度。

---
