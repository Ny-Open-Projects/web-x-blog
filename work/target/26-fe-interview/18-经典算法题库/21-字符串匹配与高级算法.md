# 21 字符串匹配与高级算法（C-401 ~ C-415）

> 字符串高级算法是笔试的**分水岭**：字节、阿里、快手的「AK 场」（要求全对）会把 KMP / Manacher / 哈希 / AC 自动机放在最后 1~2 题，用来筛掉只会调 `indexOf` 的人。普通场次只考到 KMP 和哈希，但**问法很刁**——不会让你默写模板，而是问「为什么失配可以跳」「为什么 Manacher 是 O(n)」。**识别特征**：看到「子串出现位置、循环节、回文半径、多模式串」就要条件反射想到线性做法；看到 n 到 1e6 就绝不能写 O(n²)。

## 题型速查

| 算法 | 适用场景 | 复杂度 | 代表题 |
|---|---|---|---|
| KMP / next 数组 | 单模式匹配、循环节、最长回文前缀 | O(n+m) | C-401 C-402 C-403 |
| Manacher | 回文子串 / 最长回文 | O(n) | C-404 C-405 |
| Z 函数（扩展 KMP） | 串的 LCP、模式串所有出现位置 | O(n) | C-406 |
| 滚动哈希 | 子串判等、二分答案、多模式 | O(n) / O(n log n) | C-407 C-408 C-409 |
| AC 自动机 | 多模式串同时匹配 | O(总模式长 + 文本长) | C-410 |
| 后缀数组（倍增） | 后缀排序、最长重复子串 | O(n log²n) | C-411 |
| 最小表示法 | 循环同构串的最小字典序 | O(n) | C-412 |
| 字符串轮转 | 循环移位判定 | O(n) | C-413 C-414 |
| 区间 DP / 滚动数组 | 最长公共子串 | O(nm) / O(m) | C-415 |

### C-401 KMP 模板（实现 strStr） · 困难 · 字节/阿里

**题干**：给你两个字符串 `haystack` 和 `needle`，请你在 `haystack` 字符串中找出 `needle` 字符串的第一个匹配项的下标（下标从 0 开始）。如果 `needle` 不是 `haystack` 的一部分，则返回 `-1`。`needle` 为空串时返回 `0`。要求时间复杂度 **O(n + m)**，不得使用 `indexOf` 等内置查找。

**示例**：`输入: haystack = "sadbutsad", needle = "sad"` → `输出: 0`；`输入: haystack = "leetcode", needle = "leeto"` → `输出: -1`

**思路**：
- 暴力：枚举每个起点逐字符比对，最坏 O(nm)，例如 `haystack = "aaaaab"`、`needle = "aaab"` 时每次都要比到最后一个字符才失配。
- KMP 的核心是一张 `next` 数组：`next[i]` 表示**模式串前缀 `needle[0..i]` 的最长相等真前缀与真后缀的长度**。当 `haystack[i]` 与 `needle[j]` 失配时，我们已经知道 `needle[0..j-1]` 和文本末尾一段完全相同，于是可以把 `j` 直接跳到 `next[j-1]`，让「已经匹配上的那段」继续复用，而不是回退文本指针。
- **为什么不会漏解**：`next[j-1]` 是「当前已匹配后缀」的最长 border，任何比它短的候选都已被它覆盖；跳过去之后 `needle[0..next[j-1]-1]` 与文本对应段仍然相等，因此不会错过任何可能的起点。文本指针 `i` 只前进不后退，所以总时间是 O(n+m)。

**代码**：
```javascript
/**
 * KMP：返回 needle 在 haystack 中首次出现的下标，不存在返回 -1
 * next[i] = needle[0..i] 的最长相等前后缀长度（border）
 */
function strStr(haystack, needle) {
  const m = needle.length;
  if (m === 0) return 0;                    // 空模式串约定返回 0
  if (m > haystack.length) return -1;

  // 1) 自匹配构建 next 数组：i 是主指针，j 是当前 border 长度
  const next = new Array(m).fill(0);
  for (let i = 1, j = 0; i < m; i++) {
    while (j > 0 && needle[i] !== needle[j]) j = next[j - 1]; // 失配则沿 border 链回退
    if (needle[i] === needle[j]) j++;       // 能接上就延长 border
    next[i] = j;
  }

  // 2) 文本匹配：i 只增不减，j 失配时按 next 跳
  for (let i = 0, j = 0; i < haystack.length; i++) {
    while (j > 0 && haystack[i] !== needle[j]) j = next[j - 1];
    if (haystack[i] === needle[j]) j++;
    if (j === m) return i - m + 1;          // 完整匹配，起点是 i-m+1
  }
  return -1;
}

console.log(strStr('sadbutsad', 'sad')); // 0
console.log(strStr('leetcode', 'leeto')); // -1
console.log(strStr('a', ''));             // 0
```

**复杂度**：时间 O(n + m)，空间 O(m)（仅 next 数组）。

**易错点**：
- `next` 的第二层循环必须写 `while (j > 0 && ...)`，写成 `if` 会漏掉多次回退，导致错误匹配。
- 匹配成功后返回 `i - m + 1`，不是 `i`；若要求「所有出现位置」，命中后要写 `j = next[j - 1]` 继续找，不能直接 `return`。
- `needle` 为空要单独返回 0，否则 `needle[j]` 是 `undefined`，比较永远不相等。
- 用 `charCodeAt` 比较和用 `===` 比较字符串性能差别很大，1e6 级别建议转成 `Uint8Array` / `Int32Array` 再跑。

**变体与追问**：
- 求 `needle` 在 `haystack` 中所有出现位置：命中后记录 `i - m + 1`，再令 `j = next[j - 1]`。
- 求字符串的最小循环节：`n - next[n-1]`，若 `n % (n - next[n-1]) === 0` 则为循环节长度。
- 面试官常追问「next 和 nextval 的区别」：nextval 在 `needle[j] === needle[next[j]]` 时继续往前跳，减少无意义的比较。

### C-402 最短回文串 · 困难 · 字节/阿里

**题干**：给定一个字符串 `s`，你可以通过在字符串**前面**添加字符将其转换为回文串。请找到并返回用这种方式转换出的**最短**回文串。

**示例**：`输入: s = "aacecaaa"` → `输出: "aaacecaaa"`；`输入: s = "abcd"` → `输出: "dcbabcd"`

**思路**：
- 要在前面加最少字符，等价于**找出 `s` 的最长回文前缀**。设这段前缀长度为 `k`，则只需把 `s[k..n-1]` 反转后拼到 `s` 前面，长度增加 `n-k`，显然最小。
- 怎么快速求最长回文前缀？构造 `t = s + '#' + reverse(s)`，对 `t` 求 KMP 的 `next` 数组。`next` 最后一位就是 `t` 的最长相等前后缀长度，也就是「`s` 的前缀」与「`reverse(s)` 的后缀」的最长公共长度——而 `reverse(s)` 的后缀反过来正是 `s` 的前缀，所以它就是最长回文前缀长度。
- `#` 必须是不在 `s` 中出现的分隔符，否则匹配可能跨越拼接点，得到超过 `n` 的非法长度。

**代码**：
```javascript
/**
 * 最短回文串：KMP 求 s 的最长回文前缀，再把剩余后缀反转拼到前面
 */
function shortestPalindrome(s) {
  const n = s.length;
  if (n <= 1) return s;

  // 构造 s + '#' + reverse(s)，'#' 是不会出现在 s 中的哨兵
  const rev = s.split('').reverse().join('');
  const t = s + '#' + rev;

  // 对 t 求 next 数组（border 长度）
  const next = new Array(t.length).fill(0);
  for (let i = 1, j = 0; i < t.length; i++) {
    while (j > 0 && t[i] !== t[j]) j = next[j - 1];
    if (t[i] === t[j]) j++;
    next[i] = j;
  }

  // 最后一位 next 即 s 的最长回文前缀长度
  const k = next[t.length - 1];
  const suffix = s.slice(k);                 // 需要补的部分
  return suffix.split('').reverse().join('') + s;
}

console.log(shortestPalindrome('aacecaaa')); // "aaacecaaa"
console.log(shortestPalindrome('abcd'));      // "dcbabcd"
console.log(shortestPalindrome('a'));         // "a"
```

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：
- 拼接串必须用 `#` 隔开，且 `#` 不能出现在原串里；用 `$`、`|` 同理，但用普通字母会出错。
- 取的是 `next[t.length - 1]`，不是 `next[n-1]`；这是全题最容易写错的一行。
- 当 `s` 本身就是回文时 `k === n`，`suffix` 为空，返回原串，逻辑要能自然覆盖。
- 题目只允许在**前面**添加；若改成为「末尾添加」，应改为找最长回文**后缀**，构造 `reverse(s) + '#' + s`。

**变体与追问**：
- 在末尾添加最少字符（LC 214 变体）：把 `s` 和 `reverse(s)` 的位置对调即可。
- 允许在任意位置插入：转化为「最长回文子序列」，用区间 DP，O(n²)。
- 面试官会追问「为什么不用 Manacher」：Manacher 也能求最长回文前缀，但 KMP 写法更短、常数更小，笔试优先 KMP。

### C-403 重复的子字符串 · 简单 · 腾讯/美团

**题干**：给定一个非空的字符串 `s`，检查是否可以通过由它的一个子串重复多次构成。换句话说，`s` 是否能写成 `sub + sub + ... + sub`（至少两次）。

**示例**：`输入: s = "abab"` → `输出: true`（由 `"ab"` 重复两次）；`输入: s = "aba"` → `输出: false`；`输入: s = "abcabcabcabc"` → `输出: true`

**思路**：
- 暴力：枚举循环节长度 `len` 从 1 到 `n/2`，只检查能整除 `n` 的，再逐段比较，O(n²)。
- KMP 做法：求出 `next[n-1]`，记 `len = next[n-1]`，它是整串的**最长相等前后缀长度**。若 `len > 0` 且 `n % (n - len) === 0`，则 `s` 由长度为 `n - len` 的子串重复构成。
- 直觉：最长 border 意味着「去掉开头 `n-len` 个字符」和「去掉末尾 `n-len` 个字符」后剩下的部分相同，这恰好说明整串以 `n-len` 为周期在平移；再配合整除条件，就能保证它是完整的重复，而不是「错位重叠」。这个判定把「是否存在循环节」从 O(n²) 的逐长度枚举降到了 O(n)，也是 KMP 除了匹配之外最常被追问的用法，面试官经常要求现场证明 `n - next[n-1]` 就是最小循环节。

**代码**：
```javascript
/**
 * 重复的子字符串：next[n-1] 给出最长 border，
 * n - next[n-1] 就是候选最小循环节长度
 */
function repeatedSubstringPattern(s) {
  const n = s.length;
  if (n <= 1) return false;

  const next = new Array(n).fill(0);
  for (let i = 1, j = 0; i < n; i++) {
    while (j > 0 && s[i] !== s[j]) j = next[j - 1];
    if (s[i] === s[j]) j++;
    next[i] = j;
  }

  const border = next[n - 1];
  if (border === 0) return false;           // 没有任何相等前后缀
  const period = n - border;                // 候选循环节长度
  return n % period === 0;                  // 必须能整除才是完整重复
}

console.log(repeatedSubstringPattern('abab'));          // true
console.log(repeatedSubstringPattern('aba'));           // false
console.log(repeatedSubstringPattern('abcabcabcabc'));  // true
console.log(repeatedSubstringPattern('a'));             // false
```

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：
- 只判断 `border > 0` 不够，`"ababa"` 的 border 是 3，但 `n=5`、`period=2`，`5 % 2 !== 0`，不是重复串，必须加整除判断。
- `n <= 1` 要提前返回 false，单字符不视为「重复至少两次」。
- 另一种取巧写法 `(s + s).indexOf(s, 1) !== n` 依赖内置 `indexOf`，面试官可能要求手写，且复杂度不保证线性。
- 题目问的是「能否」，不是「最小循环节是多少」；若要求输出循环节，直接 `s.slice(0, period)`。

**变体与追问**：
- 求最小循环节：答案就是 `s.slice(0, n - next[n-1])`（需整除）。
- 求所有循环节长度：从最小循环节开始按倍数枚举。
- 判断两个串是否互为循环同构：`(a + a).includes(b)` 且长度相等。

### C-404 Manacher 求最长回文子串 · 中等 · 字节/阿里

**题干**：给你一个字符串 `s`，找到 `s` 中最长的回文子串。回文子串是指正着读和倒着读一样的连续子串。

**示例**：`输入: s = "babad"` → `输出: "bab"`（`"aba"` 也是合法答案）；`输入: s = "cbbd"` → `输出: "bb"`

**思路**：
- 暴力中心扩展：枚举每个中心向两边扩，O(n²)。问题在于奇偶长度要分两次处理，且大量重复计算。
- Manacher 先做**预处理**：在每个字符间插入 `#`，得到 `T`，长度变成 `2n+1`，这样奇回文和偶回文都统一成「以某个字符为中心」的奇回文。
- 维护当前回文右边界 `right` 和对应的中心 `center`。当 `i < right` 时，`i` 关于 `center` 的对称点是 `2*center - i`，它的臂长 `p[2*center-i]` 可以直接复用，但被右边界截断，所以取 `min(right - i, p[2*center-i])`。这就是**臂长复用**，它保证了每个位置最多被扩展常数次。
- **为什么总体 O(n)**：`right` 单调不减，`while` 每成功扩展一次 `right` 就右移一位，总扩展次数不超过 `n`，所以内层 `while` 的均摊代价是 O(1)。相比中心扩展的 O(n²)，Manacher 在 n=1e6 时仍能稳定通过，这是它值得背下来的唯一理由。

**代码**：
```javascript
/**
 * Manacher：插入 '#' 统一奇偶，p[i] 为以 T[i] 为中心的回文半径
 */
function longestPalindrome(s) {
  if (s.length < 2) return s;

  let T = '#';
  for (const ch of s) T += ch + '#';
  const n = T.length;
  const p = new Array(n).fill(0);
  let center = 0, right = 0, bestCenter = 0, bestLen = 0;

  for (let i = 0; i < n; i++) {
    // 臂长复用：对称点半径不能超过右边界
    if (i < right) p[i] = Math.min(right - i, p[2 * center - i]);
    while (i - p[i] - 1 >= 0 && i + p[i] + 1 < n &&
           T[i - p[i] - 1] === T[i + p[i] + 1]) p[i]++;
    if (i + p[i] > right) { center = i; right = i + p[i]; } // 更新最右边界
    if (p[i] > bestLen) { bestLen = p[i]; bestCenter = i; }
  }

  const start = (bestCenter - bestLen) / 2; // p[i] 即原串回文长度
  return s.slice(start, start + bestLen);
}

console.log(longestPalindrome('babad')); // "bab" 或 "aba"
console.log(longestPalindrome('cbbd'));  // "bb"
console.log(longestPalindrome('a'));     // "a"
```

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：
- 对称点下标是 `2 * center - i`，写成 `center - i` 是最常见错误。
- 预处理后 `p[i]` 恰好等于原串中的回文长度，不需要再除以 2；但**起点**要写 `(bestCenter - bestLen) / 2`。
- `while` 里的边界判断必须先查 `i - p[i] - 1 >= 0` 和 `i + p[i] + 1 < n`，顺序反了会越界读到 `undefined`。
- `bestLen` 初始为 0，单字符串不会进入循环，提前 `return s` 更稳。

**变体与追问**：
- 回文子串计数（C-405）：每个中心的贡献是 `floor((p[i] + 1) / 2)`，累加即可。
- 最短回文串：Manacher 求出以 0 为左端点的最长回文前缀。
- 分割回文串：先用 Manacher 预处理 `isPal[i][j]`，再做 DP。

### C-405 回文子串计数 · 中等 · 美团/快手

**题干**：给你一个字符串 `s`，请你统计并返回这个字符串中**回文子串**的数目。具有不同开始位置或结束位置的子串，即使是由相同的字符组成，也会被视作不同的子串。

**示例**：`输入: s = "abc"` → `输出: 3`（"a"、"b"、"c"）；`输入: s = "aaa"` → `输出: 6`（"a"×3、"aa"×2、"aaa"×1）

**思路**：
- 暴力中心扩展：枚举 `2n-1` 个中心，每个中心向两边扩，O(n²)。n 到 1e5 就会超时。
- Manacher 做法：预处理后，以 `T[i]` 为中心的回文半径是 `p[i]`。在原串中，这个中心贡献的回文子串个数是 `floor((p[i] + 1) / 2)`。
- 直觉：以 `#` 为中心对应偶回文，以字符为中心对应奇回文；半径每增加 1，对应原串回文长度增加 1，贡献一个子串。用 `"aaa"` 验证：`T = "#a#a#a#"`，`p = [0,1,2,3,2,1,0]`，贡献分别是 `0+1+1+2+1+1+0 = 6`，与答案一致。对偶回文来说，`#` 中心的 `p[i]` 一定是偶数，`(p[i]+1)/2` 向下取整恰好是「以该间隙为中心的回文对数」，不会多算也不会漏算。
- 相比中心扩展，Manacher 把每个中心的扩展复用起来，整体从 O(n²) 降到 O(n)。

**代码**：
```javascript
/**
 * 回文子串计数：Manacher 半径 -> 每个中心的贡献
 * 贡献公式：floor((p[i] + 1) / 2)
 */
function countSubstrings(s) {
  if (s.length === 0) return 0;

  // 预处理，统一奇偶回文
  let T = '#';
  for (const ch of s) T += ch + '#';
  const n = T.length;

  const p = new Array(n).fill(0);
  let center = 0, right = 0;
  let total = 0;

  for (let i = 0; i < n; i++) {
    if (i < right) p[i] = Math.min(right - i, p[2 * center - i]);
    while (
      i - p[i] - 1 >= 0 &&
      i + p[i] + 1 < n &&
      T[i - p[i] - 1] === T[i + p[i] + 1]
    ) {
      p[i]++;
    }
    if (i + p[i] > right) {
      center = i;
      right = i + p[i];
    }
    // 当前中心贡献的回文子串数
    total += Math.floor((p[i] + 1) / 2);
  }

  return total;
}

console.log(countSubstrings('abc')); // 3
console.log(countSubstrings('aaa')); // 6
console.log(countSubstrings('aba')); // 4
```

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：
- 贡献公式是 `floor((p[i] + 1) / 2)`，不是 `p[i]`，也不是 `(p[i] + 1) / 2` 直接取整前先乘。
- `total` 用普通 `Number` 即可，因为题目保证 `n <= 1000` 时答案不超过 5e5；若 n 到 1e5，答案可达 5e9，仍小于 `Number.MAX_SAFE_INTEGER`，不用 BigInt。
- 中心扩展写法更容易错在「奇偶两次扩展」的边界，Manacher 的 `#` 预处理能规避这个问题。
- 空串返回 0，不要返回 1。

**变体与追问**：
- 最长回文子串（C-404）：同一套 `p` 数组，取最大值并映射起点。
- 回文子序列计数（LC 730）：不是连续子串，必须用区间 DP，不能用 Manacher。
- 统计「长度大于 1」的回文子串：总数减去 `n`（每个单字符）。

### C-406 Z 函数模板（扩展 KMP） · 困难 · 快手/字节

**题干**：给定一个长度为 `n` 的字符串 `s`，定义 `z[i]` 为 `s` 与 `s[i..n-1]` 的**最长公共前缀（LCP）**长度，特别地 `z[0] = n`。请实现 `zFunction(s)` 返回整个 `z` 数组，要求时间复杂度 O(n)。并说明如何用它在线性时间内求出模式串 `pattern` 在文本 `text` 中的所有出现位置。

**示例**：`输入: s = "abacaba"` → `输出: [7,0,1,0,3,0,1]`

**思路**：
- 暴力：对每个 `i` 从 0 开始逐字符比对，最坏 O(n²)，例如全 `"aaaa..."` 每次都要比到末尾。
- Z 函数维护一个当前最靠右的匹配段 `[l, r)`（称为 Z-box），它满足 `s[l..r-1] === s[0..r-l-1]`。当 `i < r` 时，`i` 在 Z-box 内，利用「`s[i..]` 与 `s[i-l..]` 在 Z-box 范围内相同」这一性质，可以直接令 `z[i] = min(r - i, z[i - l])`，跳过已经确定相等的部分，再从该位置继续扩展。
- **为什么是 O(n)**：每次 `while` 成功匹配都会让 `r` 右移，而 `r` 单调不减、最多到 `n`，所以所有 `while` 的成功次数总和是 O(n)；失败比较每个 `i` 最多一次。
- 求多模式匹配：构造 `pattern + '#' + text`，若某个位置 `i` 落在 text 区且 `z[i] >= pattern.length`，就说明 `pattern` 在 `text` 的 `i - pattern.length - 1` 处出现。Z 函数和 KMP 本质同源，但 Z 函数更擅长回答「每个后缀与前缀的 LCP」，KMP 更擅长「模式串在文本中的匹配」，面试时能说清两者取舍是加分项。

**代码**：
```javascript
/**
 * Z 函数：z[i] = LCP(s, s[i..])，z[0] = n；[l, r) 为最右 Z-box
 */
function zFunction(s) {
  const n = s.length, z = new Array(n).fill(0);
  if (n === 0) return z;
  z[0] = n;
  let l = 0, r = 0;
  for (let i = 1; i < n; i++) {
    if (i < r) z[i] = Math.min(r - i, z[i - l]); // 盒内复用对称位置
    while (i + z[i] < n && s[z[i]] === s[i + z[i]]) z[i]++;
    if (i + z[i] > r) { l = i; r = i + z[i]; }   // 更新最右 Z-box
  }
  return z;
}

// 应用：pattern 在 text 中所有出现位置（O(n+m)）
function searchAll(text, pattern) {
  const s = pattern + '#' + text;
  const z = zFunction(s);
  const res = [];
  for (let i = pattern.length + 1; i < s.length; i++) {
    if (z[i] >= pattern.length) res.push(i - pattern.length - 1);
  }
  return res;
}

console.log(zFunction('abacaba'));      // [7,0,1,0,3,0,1]
console.log(searchAll('ababab', 'ab')); // [0,2,4]
```

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：
- `z[0]` 必须手动设为 `n`，循环从 `i = 1` 开始，否则会陷入自比较。
- 盒内取值是 `z[i - l]`，不是 `z[i - r]`；`l` 是盒的左端点。
- 扩展的边界条件要同时写 `i + z[i] < n` 和 `s[z[i]] === s[i + z[i]]`，顺序不能反。
- 拼接用的 `#` 不能出现在 `pattern` 或 `text` 里，否则会跨段匹配出错误结果。

**变体与追问**：
- Z 函数与 KMP 的 `next` 可以互相转化：`z[i]` 表示从 `i` 开始与前缀的 LCP，`next` 表示以 `i` 结尾的最长 border。
- 求字符串每个后缀与整串的 LCP：直接就是 Z 数组。
- 求本质不同子串数量：需要后缀数组 + LCP，Z 函数不够。

### C-407 字符串滚动哈希 · 中等 · 字节/腾讯

**题干**：实现一个字符串哈希结构：给定字符串 `s`，预处理后支持 **O(1)** 查询任意子串 `s[l..r)` 的哈希值，从而快速判断两个子串是否相等。要求使用「前缀哈希 + 幂次预处理」，并正确处理减法取模产生的负数。

**示例**：`s = "abcdef"`，`subHash(0,3)` 与 `subHash(3,6)` 应分别对应 `"abc"`、`"def"` 的哈希；对 `"abcabc"`，`subHash(0,3) === subHash(3,6)`。

**思路**：
- 把字符串看成 BASE 进制的大整数：`H(i) = (s[0]*BASE^(i-1) + ... + s[i-1]) mod MOD`。这样前缀哈希可以递推：`H(i+1) = H(i) * BASE + code(s[i])`。
- 子串 `[l, r)` 的哈希就是把前缀 `H(r)` 减去 `H(l)` 左移 `r-l` 位后的部分：`H(r) - H(l) * BASE^(r-l)`。预先算好 `pow[k] = BASE^k mod MOD`，查询就是 O(1)。
- **冲突风险**：单模哈希存在被构造碰撞的可能，笔试里通常够用；若题目数据恶意或要求严格，用双模（两个不同 MOD）或 `BigInt` 64 位哈希。JS 里 `1e9 * 1e9` 会超过 `Number.MAX_SAFE_INTEGER`，所有乘法必须用 `BigInt` 包一层，否则精度丢失会算错。工程上还可以预先算好每个字符的哈希贡献，避免每次重复调用 `charCodeAt`；对 1e6 级字符串，这点常数优化很关键。

**代码**：
```javascript
/**
 * 滚动哈希：O(n) 预处理，O(1) 查询任意子串哈希
 * 乘法用 BigInt 兜底，避免 1e18 超出 JS 安全整数
 */
const MOD = 1000000007;
const BASE = 131;
const mulmod = (a, b) => Number((BigInt(a) * BigInt(b)) % BigInt(MOD));

function buildHash(s) {
  const n = s.length;
  const h = new Array(n + 1).fill(0);  // 前缀哈希
  const p = new Array(n + 1).fill(1);  // BASE 的幂
  for (let i = 0; i < n; i++) {
    h[i + 1] = (mulmod(h[i], BASE) + s.charCodeAt(i)) % MOD;
    p[i + 1] = mulmod(p[i], BASE);
  }
  return { h, p };
}

// 查询 s[l..r) 的哈希，0 <= l < r <= n
function subHash({ h, p }, l, r) {
  let v = h[r] - mulmod(h[l], p[r - l]);
  v %= MOD;
  return v < 0 ? v + MOD : v;          // 处理负数取模
}

const H = buildHash('abcabc');
console.log(subHash(H, 0, 3) === subHash(H, 3, 6)); // true
console.log(subHash(H, 1, 4) === subHash(H, 4, 6)); // false
```

**复杂度**：预处理时间 O(n)，单次查询 O(1)，空间 O(n)。

**易错点**：
- JS 的 `Number` 只有 53 位精度，`h[l] * p[r-l]` 直接相乘会失真；要么用 `BigInt`，要么把 `MOD` 调到 `2^26` 级别并用 `Math.imul` 技巧。
- 减法后必须 `(v % MOD + MOD) % MOD`，只写 `v % MOD` 在 JS 里会得到负数。
- `BASE` 要大于字符集大小（通常 131 或 13331），且不能是 `MOD` 的倍数。
- 哈希只能判断「大概率相等」，最终答案若要求严格，冲突时要用 `slice` 双检。

**变体与追问**：
- 双模哈希：同时维护 `MOD1 = 1e9+7`、`MOD2 = 1e9+9`，两个都相等才认为相等。
- 最长重复子串（C-408）：二分长度 + 哈希集合。
- 回文判断：正串和反串各建一套哈希，比较对应区间。

### C-408 最长重复子串 · 困难 · 字节/阿里

**题干**：给你一个字符串 `s`，考虑其所有**重复子串**：即 `s` 的连续子串，在 `s` 中出现**至少两次**，且两次出现可以重叠。返回任意一个**最长重复子串**。如果 `s` 不含重复子串，返回 `""`。

**示例**：`输入: s = "banana"` → `输出: "ana"`；`输入: s = "abcd"` → `输出: ""`

**思路**：
- 暴力：枚举所有子串用哈希表计数，O(n³) 起步；即使只枚举长度也是 O(n²) 次哈希查询。
- 关键单调性：如果存在长度为 `L` 的重复子串，那么它长度为 `L-1` 的前缀也一定重复。因此「是否存在长度为 L 的重复子串」关于 L 单调，可以**二分答案**。
- 判定 `check(L)`：把所有长度为 `L` 的子串哈希值塞进 `Set`，一旦发现重复就返回起点。单次判定 O(n)，二分 O(log n)，总 O(n log n)。
- 冲突风险：哈希碰撞会把不相等当成相等，工程上可存 `(hash, 起点)` 并在命中时用 `slice` 双检，或直接上双模。

**代码**：
```javascript
/**
 * 最长重复子串：二分长度 + 滚动哈希判重
 */
function longestDupSubstring(s) {
  const n = s.length;
  if (n < 2) return '';
  const MOD = 1000000007, BASE = 131;
  const mulmod = (a, b) => Number((BigInt(a) * BigInt(b)) % BigInt(MOD));

  const h = new Array(n + 1).fill(0), p = new Array(n + 1).fill(1);
  for (let i = 0; i < n; i++) {
    h[i + 1] = (mulmod(h[i], BASE) + s.charCodeAt(i)) % MOD;
    p[i + 1] = mulmod(p[i], BASE);
  }
  const sub = (l, r) => {
    const v = h[r] - mulmod(h[l], p[r - l]);
    return ((v % MOD) + MOD) % MOD;
  };
  const check = (len) => {          // 存在长度 len 的重复子串则返回起点
    const seen = new Set();
    for (let i = 0; i + len <= n; i++) {
      const key = sub(i, i + len);
      if (seen.has(key)) return i;
      seen.add(key);
    }
    return -1;
  };

  let lo = 1, hi = n - 1, bestStart = -1, bestLen = 0;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    const idx = check(mid);
    if (idx !== -1) { bestLen = mid; bestStart = idx; lo = mid + 1; }
    else hi = mid - 1;
  }
  return bestLen === 0 ? '' : s.slice(bestStart, bestStart + bestLen);
}

console.log(longestDupSubstring('banana')); // "ana"
console.log(longestDupSubstring('abcd'));   // ""
console.log(longestDupSubstring('aaaa'));   // "aaa"
```

**复杂度**：时间 O(n log n)，空间 O(n)。

**易错点**：
- 二分下界从 1 开始，`len = 0` 没有意义；`n < 2` 直接返回空串。
- `check` 里发现重复要返回**当前**起点 `i`，不是第一次出现的起点；两者都合法，但返回 `i` 时 `slice` 一定在界内。
- 哈希值相同不代表字符串相同，严格题要加 `s.slice(i, i+len) === s.slice(prev, prev+len)` 双检。
- 答案要求「任意一个」，不要纠结字典序；若要求字典序最小，需要额外比较。

**变体与追问**：
- 可重叠 vs 不可重叠：本题允许重叠；若不允许，`check` 里要记录上次出现位置并判断 `i - prev >= len`。
- 最长重复子数组（两个数组）：用 DP `dp[i][j] = a[i]===b[j] ? dp[i-1][j-1]+1 : 0`。
- 本质不同子串数量：后缀数组 + LCP，`n(n+1)/2 - sum(LCP)`。

### C-409 Rabin-Karp 多模式匹配 · 中等 · 字节/腾讯

**题干**：给定一个文本串 `text` 和一个模式串数组 `patterns`，找出每个模式串在 `text` 中**所有出现位置**（允许重叠）。返回形如 `{ index, pattern }` 的结果数组。要求按模式串**长度分组**，每组只对文本做一次滑动窗口，而不是每个模式串都扫一遍文本。

**示例**：`输入: text = "ababcab", patterns = ["ab","abc","bc"]` → 输出包含 `ab@0`、`ab@2`、`ab@5`、`abc@2`、`bc@3`。

**思路**：
- 朴素多模式：每个模式串单独 KMP，总复杂度 O(k·n)，k 为模式数，模式多时不可接受。
- Rabin-Karp 的思路是「先比哈希、再比内容」：同一个长度的所有模式串哈希值放进哈希表，然后对文本做一次长度为 L 的滑动窗口，窗口哈希命中表就直接得到候选。
- 按长度分组后，若不同长度有 d 种，总复杂度 O(d·n + 总模式长度)。滑动窗口哈希可以 O(1) 从上一个窗口推出下一个：去掉高位、加上低位，但用前缀哈希实现更简单，笔试推荐前缀哈希版本。
- 命中哈希后必须用 `slice` 双检，否则碰撞会误报。

**代码**：
```javascript
/**
 * Rabin-Karp 多模式匹配：按长度分组 + 滚动哈希
 */
function multiPatternSearch(text, patterns) {
  const n = text.length, MOD = 1000000007, BASE = 131;
  const mulmod = (a, b) => Number((BigInt(a) * BigInt(b)) % BigInt(MOD));
  const h = new Array(n + 1).fill(0), p = new Array(n + 1).fill(1);
  for (let i = 0; i < n; i++) {
    h[i + 1] = (mulmod(h[i], BASE) + text.charCodeAt(i)) % MOD;
    p[i + 1] = mulmod(p[i], BASE);
  }
  const sub = (l, r) => ((h[r] - mulmod(h[l], p[r - l])) % MOD + MOD) % MOD;
  const hashStr = (str) => {
    let v = 0;
    for (const ch of str) v = (mulmod(v, BASE) + ch.charCodeAt(0)) % MOD;
    return v;
  };

  const byLen = new Map();          // len -> (hash -> pattern)
  for (const pat of patterns) {
    if (!byLen.has(pat.length)) byLen.set(pat.length, new Map());
    byLen.get(pat.length).set(hashStr(pat), pat);
  }
  const res = [];
  for (const [len, table] of byLen) {
    for (let i = 0; i + len <= n; i++) {
      const key = sub(i, i + len);
      if (!table.has(key)) continue;
      const pat = table.get(key);
      if (text.slice(i, i + len) === pat) res.push({ index: i, pattern: pat });
    }
  }
  return res;
}

const out = multiPatternSearch('ababcab', ['ab', 'abc', 'bc']);
console.log(out.map((x) => `${x.pattern}@${x.index}`).join(' '));
// ab@0 ab@2 bc@3 ab@5 abc@2（按长度分组，非文本顺序）
```

**复杂度**：设 d 为不同模式长度数，总模式长度为 P，则时间 O(d·n + P)，空间 O(n + P)。

**易错点**：
- 同一长度下两个不同模式串可能哈希相同，`Map` 的 key 会互相覆盖；严格场景要存 `hash -> pattern[]`。
- 空模式串要单独过滤，否则 `len = 0` 的窗口会死循环或产出 `n+1` 个结果。
- 滑动窗口右端是开区间 `i + len`，循环条件写 `i + len <= n`。
- 结果按长度分组输出，顺序不是文本顺序；若要求按出现位置排序，最后要 `sort((a,b) => a.index - b.index)`。

**变体与追问**：
- 单模式 Rabin-Karp：就是本题 d=1 的特例。
- 二维模式匹配：把每一行哈希成一个数，再对列做一次哈希。
- 敏感词过滤：多模式匹配 + AC 自动机（C-410）更合适，Rabin-Karp 需要按长度分组，模式长度差异大时退化。

### C-410 AC 自动机（多模式串） · 困难 · 字节/阿里

**题干**：给定一组模式串 `patterns` 和一个文本串 `text`，找出**所有**模式串在文本中出现的结束位置。要求一次扫描文本就匹配所有模式串，时间复杂度 O(总模式长度 + 文本长度 + 匹配结果数)。请实现 AC 自动机的建树、失配指针（fail）构建与扫描。

**示例**：`输入: patterns = ["he","she","his","hers"], text = "ushers"` → 匹配到 `she`（结束于 3）、`he`（结束于 3）、`hers`（结束于 5）。

**思路**：
- 多模式串如果每个都跑一遍 KMP，复杂度 O(k·n)。AC 自动机把「KMP 的 fail 指针」搬到 Trie 上：Trie 的每条边代表一个字符，`fail[u]` 指向「`u` 代表的串的最长真后缀，且该后缀是某个模式串的前缀」对应的节点。
- 构建 fail 用 BFS：根的子节点 fail 都是 0；对于节点 `u` 的字符 `ch` 子节点 `v`，从 `f = fail[u]` 出发，沿 fail 链找第一个有 `ch` 出边的节点，`fail[v]` 就是它的 `ch` 子节点；找不到则为根。
- 扫描文本时，当前节点沿 Trie 走，走不通就沿 fail 跳，和 KMP 的失配跳转完全同构。每个节点还要**继承 fail 节点的输出**，这样匹配到 `she` 时能同时报告后缀 `he`。
- **为什么是线性**：建 Trie O(总模式长)，BFS 每条 fail 边均摊 O(1)，扫描文本时当前深度只增不减（fail 只会让深度变小），总跳转次数 O(文本长)。

**代码**：
```javascript
/** AC 自动机：Trie + fail 指针 + 输出继承（数组实现） */
function buildAC(patterns) {
  const next = [new Map()], fail = [0], out = [[]];
  const newNode = () => { next.push(new Map()); fail.push(0); out.push([]); return next.length - 1; };

  for (const word of patterns) {
    let u = 0;
    for (const ch of word) {
      if (!next[u].has(ch)) next[u].set(ch, newNode());
      u = next[u].get(ch);
    }
    out[u].push(word);                 // 该节点结束一个模式串
  }
  const q = [...next[0].values()];     // 根的子节点 fail = 0
  for (let qi = 0; qi < q.length; qi++) {
    const u = q[qi];
    for (const [ch, v] of next[u]) {
      let f = fail[u];
      while (f > 0 && !next[f].has(ch)) f = fail[f];
      if (next[f].has(ch) && next[f].get(ch) !== v) fail[v] = next[f].get(ch);
      out[v].push(...out[fail[v]]);    // 继承后缀输出
      q.push(v);
    }
  }
  return { next, fail, out };
}

function searchAC(ac, text) {
  const { next, fail, out } = ac;
  const res = [];
  let u = 0;
  for (let i = 0; i < text.length; i++) {
    const ch = text[i];
    while (u > 0 && !next[u].has(ch)) u = fail[u];
    if (next[u].has(ch)) u = next[u].get(ch);
    for (const word of out[u]) res.push({ word, end: i });
  }
  return res;
}

const ac = buildAC(['he', 'she', 'his', 'hers']);
console.log(searchAC(ac, 'ushers')); // she@3, he@3, hers@5
```

**复杂度**：建树 O(P)，构建 fail O(P)，扫描 O(n + 匹配数)，空间 O(P)，其中 P 为所有模式串总长度。

**易错点**：
- 根节点（`u = 0`）失配时不能再跳，`while` 条件必须是 `u > 0`。
- 构建 fail 时 `next[f].get(ch) !== v` 的判断是为了防止 `f` 恰好等于 `u` 时自指，虽然正常 BFS 顺序下不会发生，但加上更安全。
- 输出继承 `out[v].push(...out[fail[v]])` 必须在入队前完成，否则 `she` 匹配不到 `he`。
- 节点数会随模式总长增长，用 `Map` 存子节点比二维数组省内存；若字符集固定小写字母，用 `Array(26)` 更快。

**变体与追问**：
- 统计每个模式串出现次数：在 `out` 里存模式编号，扫描时累加。若要统计 fail 链上所有祖先，需在 fail 树上做子树和（拓扑序累加）。
- 敏感词替换：扫描时记录命中区间，再按区间合并替换。
- 最大匹配 / 最短匹配：需要修改输出策略，AC 自动机本身只负责「找出所有」。

### C-411 后缀数组（倍增法） · 困难 · 字节/阿里

**题干**：给定一个字符串 `s`，返回它的**后缀数组** `sa`：`sa[i]` 表示 `s` 的所有后缀中字典序第 `i` 小的后缀的起始下标。要求使用**倍增法**实现，时间复杂度不高于 O(n log²n)。

**示例**：`输入: s = "banana"` → `输出: [5, 3, 1, 0, 4, 2]`（后缀依次为 `a`、`ana`、`anana`、`banana`、`na`、`nana`）

**思路**：
- 朴素做法：把所有后缀取出来排序，每次比较 O(n)，总 O(n² log n)，n 到 1e5 就爆。
- 倍增法把「比较后缀」拆成「比较两个长度为 `2^k` 的段」。先只按首字符排名（`k=0`），再按「前一半排名 + 后一半排名」这个二元组重新排名，`k` 每轮翻倍。当所有后缀排名互不相同时，排序就完成了。
- 每一轮用 `rank[i]` 表示「从 `i` 开始、长度为 `2^k` 的段的排名」。比较 `i` 和 `j` 时，先比 `rank[i]` 与 `rank[j]`，再比 `rank[i+k]` 与 `rank[j+k]`（越界视为 -1，因为短串字典序更小）。
- **为什么能降复杂度**：每个长度为 `2^k` 的段由两个 `2^(k-1)` 的段拼成，排名可以在 O(1) 内比较；每轮排序 O(n log n)，共 log n 轮，总 O(n log²n)。用基数排序可以进一步降到 O(n log n)。

**代码**：
```javascript
/**
 * 后缀数组：倍增 + 二元组排名
 * rank[i] 表示从 i 开始、长度 2^k 的段的排名
 */
function buildSuffixArray(s) {
  const n = s.length;
  if (n === 0) return [];
  const sa = Array.from({ length: n }, (_, i) => i);
  let rank = new Array(n);
  for (let i = 0; i < n; i++) rank[i] = s.charCodeAt(i);

  let k = 1;
  const cmp = (a, b) => {              // 先比首段，相等再比后一段
    if (rank[a] !== rank[b]) return rank[a] - rank[b];
    const ra = a + k < n ? rank[a + k] : -1;
    const rb = b + k < n ? rank[b + k] : -1;
    return ra - rb;
  };
  while (k < n) {
    sa.sort(cmp);
    const nextRank = new Array(n);
    nextRank[sa[0]] = 0;
    for (let i = 1; i < n; i++) {
      const same = cmp(sa[i - 1], sa[i]) === 0;
      nextRank[sa[i]] = nextRank[sa[i - 1]] + (same ? 0 : 1);
    }
    rank = nextRank;
    if (rank[sa[n - 1]] === n - 1) break; // 排名已两两不同
    k <<= 1;
  }
  return sa;
}

console.log(buildSuffixArray('banana')); // [5, 3, 1, 0, 4, 2]
console.log(buildSuffixArray('aaaa'));   // [3, 2, 1, 0]
```

**复杂度**：时间 O(n log²n)（比较排序），空间 O(n)。

**易错点**：
- 越界段的排名要视为 `-1`，不能视为 0，否则空前缀会和字符 `'\0'` 混淆，短后缀排序错误。
- 重新排名时必须用**旧的** `rank` 比较，所以要先算完 `nextRank` 再整体替换，不能边算边改。
- 终止条件是 `rank[sa[n-1]] === n-1`，表示排名从 0 到 n-1 全不同；写成 `k >= n` 也能结束，但多做一轮。
- `k <<= 1` 只在未终止时执行；若放在循环末尾无条件执行，最后一轮会不必要地翻倍。

**变体与追问**：
- 结合 `height` 数组（LCP）：`height[i] = LCP(sa[i-1], sa[i])`，可求本质不同子串数、最长重复子串。
- 基数排序优化：把 `sort` 换成两趟计数排序，复杂度 O(n log n)。
- 后缀自动机（SAM）：另一种 O(n) 解决子串问题的结构，笔试中出现频率低于后缀数组。

### C-412 最小表示法 · 中等 · 快手/字节

**题干**：给定一个长度为 `n` 的字符串 `s`，把它首尾相连看成循环串。请找出所有长度为 `n` 的循环同构串中**字典序最小**的那一个并返回。要求时间复杂度 O(n)。

**示例**：`输入: s = "baca"` → `输出: "abac"`（四个轮转为 `baca`、`acab`、`caba`、`abac`，最小是 `abac`）

**思路**：
- 暴力：枚举 `n` 个起点，每个取出长度 `n` 的串比较，O(n²)。
- 最小表示法用两个指针 `i`、`j` 分别代表两个候选起点，`k` 表示当前已经比较相等的长度。每次比较 `t[i+k]` 和 `t[j+k]`（`t = s + s`）：
  - 若相等，`k++` 继续；
  - 若 `t[i+k] > t[j+k]`，则以 `i..i+k` 中任意位置为起点的串都不可能最小（因为以 `j` 为起点、错位相同的串更小），可以直接令 `i = i + k + 1`；
  - 反之令 `j = j + k + 1`。
- **为什么是 O(n)**：每次比较失败都会让 `i` 或 `j` 至少前进 `k+1`，而 `i`、`j` 都小于 `n`，两者总前进量不超过 `2n`，所以总比较次数是线性的。
- 若更新后 `i === j`，要让其中一个再 `+1`，避免两个指针重合后死循环。

**代码**：
```javascript
/**
 * 最小表示法：双指针 + 跳过已证明不可能更优的区间
 */
function minRepresentation(s) {
  const n = s.length;
  if (n <= 1) return s;

  const t = s + s;          // 破环成链
  let i = 0;
  let j = 1;
  let k = 0;                // 当前已比较相等的长度

  while (i < n && j < n && k < n) {
    const a = t[i + k];
    const b = t[j + k];
    if (a === b) {
      k++;
      continue;
    }
    if (a > b) {
      i = i + k + 1;        // i 到 i+k 都不可能成为最小起点
      if (i === j) i++;
    } else {
      j = j + k + 1;
      if (i === j) j++;
    }
    k = 0;                  // 换了起点，重新比较
  }

  const start = Math.min(i, j);
  return t.slice(start, start + n);
}

console.log(minRepresentation('baca'));   // "abac"
console.log(minRepresentation('abab'));   // "abab"
console.log(minRepresentation('cba'));    // "acb"
```

**复杂度**：时间 O(n)，空间 O(n)（拼接串）。

**易错点**：
- 更新指针的公式是 `i = i + k + 1`，不是 `i = i + 1`；后者会退化成 O(n²)。
- 更新后要判断 `i === j`，重合时让后者 `+1`，否则 `k` 会一直增长或死循环。
- `k` 在每次指针移动后必须清零，因为旧起点的比较结果不能复用。
- 返回的是**最小循环同构串**，不是最小后缀；不要和 C-411 的后缀数组混淆。

**变体与追问**：
- 最大表示法：把 `a > b` 和 `a < b` 的分支对调即可。
- 判断两个串是否循环同构：分别求最小表示，比较是否相等，O(n)。
- 最小表示法的应用：循环同构计数、字符串去重、项链问题。

### C-413 旋转字符串 · 简单 · 腾讯/美团

**题干**：给定两个字符串 `s` 和 `goal`。如果 `s` 在若干次**循环移位**之后可以变成 `goal`，返回 `true`；否则返回 `false`。一次循环移位指把 `s` 最左边的字符移到最右边。

**示例**：`输入: s = "abcde", goal = "cdeab"` → `输出: true`；`输入: s = "abcde", goal = "abced"` → `输出: false`

**思路**：
- 朴素的判断是枚举每个移位次数，逐字符比较，O(n²)。
- 关键性质：`s` 的所有循环移位，都是 `s + s` 中长度为 `n` 的**连续子串**。例如 `s = "abcde"`，`s + s = "abcdeabcde"`，轮转结果 `"cdeab"` 正是从下标 2 开始、长度为 5 的子串。
- 因此只需判断 `goal` 是否是 `s + s` 的子串。长度不同直接返回 false；长度相同的前提下，`goal` 出现在 `s + s` 中当且仅当它是 `s` 的某个轮转。
- 复杂度取决于字符串查找实现：V8 的 `includes` 对普通文本接近 O(n)，理论最坏 O(n²)；若要求严格线性，用 C-414 的 KMP 版本。严格证明：若 goal 是 s 左移 k 位的结果，则 goal 等于 `(s+s).slice(k, k+n)`；反之 `(s+s)` 中任意长度 n 的子串，起点 k 都小于 n，对应左移 k 位。

**代码**：
```javascript
/**
 * 旋转字符串：goal 是否为 s 的循环移位
 * 核心性质：s 的所有轮转都是 (s + s) 的长度为 n 的子串
 */
function rotateString(s, goal) {
  // 1) 长度不同，不可能通过轮转得到
  if (s.length !== goal.length) return false;

  // 2) 空串旋转任意次仍然是空串
  if (s.length === 0) return true;

  // 3)  splic 成两倍长度，例如 "abcde" -> "abcdeabcde"
  const doubled = s + s;

  // 4) 在 doubled 中查找 goal；长度相等已保证不会误判
  //    V8 的字符串查找对常见输入接近线性
  return doubled.includes(goal);
}

console.log(rotateString('abcde', 'cdeab')); // true
console.log(rotateString('abcde', 'abced')); // false
console.log(rotateString('', ''));           // true
```

**复杂度**：时间 O(n)（期望，引擎优化）～ O(n²)（最坏），空间 O(n)。

**易错点**：
- 必须先判断长度相等，否则 `"abc"` 会被误判为 `"abcabc"` 的轮转。
- 空串要单独返回 true，`"".includes("")` 也是 true，但显式处理更清晰。
- 不要只检查 `goal` 是否是 `s` 的子串，必须是 `s + s` 的子串，否则会漏掉跨边界的情况。
- 面试官若要求「不允许用内置查找」，立刻切换到 KMP 版本（C-414），不要硬刚 `includes`。

**变体与追问**：
- 严格 O(n)：用 KMP 在 `s + s` 中匹配 `goal`（C-414）。
- 判断两个串是否互为旋转：`rotateString(a, b) && rotateString(b, a)`，长度相等时二者等价。
- 旋转数组找最小值（LC 153）：那是二分，不是字符串轮转，别混淆。

### C-414 字符串轮转（KMP 线性版） · 中等 · 字节/快手

**题干**：给定两个字符串 `s` 和 `goal`，判断 `goal` 是否为 `s` 的循环移位。要求**不使用** `includes` / `indexOf` 等内置子串查找，手写 KMP 在 **O(n)** 时间内完成。

**示例**：`输入: s = "abcde", goal = "cdeab"` → `输出: true`；`输入: s = "abcde", goal = "abced"` → `输出: false`

**思路**：
- 仍然利用「轮转串 = `(s + s)` 的长度为 n 的子串」这一性质，把问题转化为：在文本 `s + s` 中查找模式 `goal`。
- 用 KMP：先对 `goal` 求 `next` 数组，再在 `s + s` 上跑匹配。文本指针只前进不后退，总时间 O(n)。
- **为什么要限制起点**：`s + s` 的长度是 `2n`，若匹配起点 `>= n`，对应的其实是同一个轮转的重复，虽然结果不会错，但为了语义严谨，命中后检查 `i - n + 1 < n`。
- 相比 C-413 的 `includes`，KMP 版本的最坏复杂度有保证，面试官追问「如果输入是恶意构造的、`includes` 退化怎么办」时，这就是标准答案。另外，KMP 版本不需要额外创建 goal 的副本，空间也更可控；如果文本是流式到达的，KMP 还能边读边匹配，而 `includes` 必须等整个串到齐。

**代码**：
```javascript
/**
 * 字符串轮转：手写 KMP，在 s+s 中查找 goal
 */
function isRotation(s, goal) {
  const n = s.length;
  if (n !== goal.length) return false;
  if (n === 0) return true;

  // 1) 对模式串 goal 构建 next 数组
  const next = new Array(n).fill(0);
  for (let i = 1, j = 0; i < n; i++) {
    while (j > 0 && goal[i] !== goal[j]) j = next[j - 1];
    if (goal[i] === goal[j]) j++;
    next[i] = j;
  }

  // 2) 在 s+s 上匹配；最后一个字符不可能是新起点
  const text = s + s;
  for (let i = 0, j = 0; i < text.length - 1; i++) {
    while (j > 0 && text[i] !== goal[j]) j = next[j - 1];
    if (text[i] === goal[j]) j++;
    if (j === n) {
      const start = i - n + 1;
      return start < n;      // 起点落在 [0, n) 才是合法轮转
    }
  }
  return false;
}

console.log(isRotation('abcde', 'cdeab')); // true
console.log(isRotation('abcde', 'abced')); // false
console.log(isRotation('a', 'a'));         // true
```

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：
- 循环上界是 `text.length - 1`，因为起点最大为 `n-1`，对应匹配结束位置最大为 `2n-2`。
- 命中后 `start = i - n + 1`，判断 `start < n`；不判断虽然多数情况也对，但语义上不严谨。
- `goal` 为空串要提前返回 true，否则 `next` 为空、`goal[j]` 越界。
- 复用 C-401 的 KMP 时，注意这里的文本是 `s + s`，长度是 `2n`，不是 `n`。

**变体与追问**：
- 如果要求返回最小轮转次数：命中位置 `start` 就是次数（左移 start 位）。
- 多模式轮转匹配：对每个 goal 跑一次 KMP，或用 AC 自动机。
- 循环同构的字符串分组：对每个串求最小表示作为分组 key。

### C-415 最长公共子串（滚动数组优化） · 中等 · 美团/字节

**题干**：给定两个字符串 `a` 和 `b`，返回它们的**最长公共子串**（要求连续）。如果不存在公共子串，返回空串。要求空间复杂度优化到 O(min(|a|, |b|))。

**示例**：`输入: a = "ababc", b = "babca"` → `输出: "babc"`

**思路**：
- 定义 `dp[i][j]` 为「以 `a[i-1]` 和 `b[j-1]` **结尾**的最长公共子串长度」。转移：若 `a[i-1] === b[j-1]`，则 `dp[i][j] = dp[i-1][j-1] + 1`；否则为 0。答案是所有 `dp[i][j]` 的最大值。
- 为什么不能像最长公共子序列那样在不等时继承 `max(dp[i-1][j], dp[i][j-1])`？因为子串要求**连续**，一旦当前字符不等，以这两个位置结尾的公共子串就断了，必须归零。
- 滚动数组：`dp[i][j]` 只依赖左上方 `dp[i-1][j-1]`，可以只保留上一行。为了不覆盖还要用的值，内层循环从右往左更新（或者用两个一维数组 `prev`/`cur`）。用两个数组更直观，空间 O(m)。
- 记录答案时同时记下结束位置 `endPos`（在 `a` 中的下标），最后 `a.slice(endPos - maxLen, endPos)` 就是答案。

**代码**：
```javascript
/**
 * 最长公共子串：dp[i][j] 以 a[i-1]、b[j-1] 结尾的最长公共长度
 * 滚动数组只保留上一行，空间 O(m)
 */
function longestCommonSubstring(a, b) {
  const n = a.length;
  const m = b.length;
  if (n === 0 || m === 0) return '';

  let prev = new Array(m + 1).fill(0); // 上一行
  let maxLen = 0;
  let endPos = 0;                       // 答案在 a 中的结束下标

  for (let i = 1; i <= n; i++) {
    const cur = new Array(m + 1).fill(0);
    for (let j = 1; j <= m; j++) {
      if (a[i - 1] === b[j - 1]) {
        cur[j] = prev[j - 1] + 1;       // 只能从左上角转移
        if (cur[j] > maxLen) {
          maxLen = cur[j];
          endPos = i;                   // 注意：i 是 1-based
        }
      }
      // 不等时 cur[j] 保持 0，不能继承左/上
    }
    prev = cur;
  }

  return a.slice(endPos - maxLen, endPos);
}

console.log(longestCommonSubstring('ababc', 'babca')); // "babc"
console.log(longestCommonSubstring('abc', 'def'));     // ""
console.log(longestCommonSubstring('abc', 'abc'));     // "abc"
```

**复杂度**：时间 O(nm)，空间 O(m)（滚动数组）。

**易错点**：
- 状态定义必须是「以…结尾」，不等时归零；如果写成「前 i、前 j 个字符内的最优」，那就变成最长公共**子序列**了。
- `endPos` 存的是 1-based 的 `i`，最后 `slice(endPos - maxLen, endPos)` 恰好对应 `a` 的区间，不需要再 `-1`。
- 滚动数组用 `prev`/`cur` 两个数组最安全；若原地用一个数组并正序遍历，会读到已经被覆盖的 `dp[j-1]`。
- 空串要提前返回，否则 `new Array(m+1)` 虽然没问题，但 `slice` 结果可能不符合预期。

**变体与追问**：
- 最长公共子序列（LC 1143）：不等时 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`，空间同样可滚动。
- 多个字符串的最长公共子串：两两合并，或对第一个串二分长度 + 哈希。
- 要求输出所有最长公共子串：记录所有达到 `maxLen` 的结束位置，去重后输出。
