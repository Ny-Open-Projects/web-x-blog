# 08 二叉树遍历与构造（C-141 ~ C-160）

> 二叉树是大厂笔试的"基础设施题"：字节、美团、快手的每套笔试题里几乎必有一道树的遍历或构造，考察的是**递归直觉 + 边界处理**而不是技巧。**识别特征**：看到"树"先问三件事——① 能不能用"左右子树同构"的递归定义；② 需要哪种遍历序（前/中/后/层）；③ 遍历过程中是否需要额外状态（每层 size 快照、深度、父节点/next 指针、全局最优值）。看到"按层"就想队列，看到"第 k 层/右视图"就想 BFS 或带深度的 DFS，看到"由两种遍历构造"就想"谁定根、谁划分左右子树"。

## 题型速查

| 子类型 | 核心手法 | 代表题 |
|---|---|---|
| 深度优先遍历 | 递归 / 显式栈 / Morris | C-141、C-142、C-143 |
| 层序遍历 | BFS 队列 + 每层 size 快照 | C-144、C-145、C-154 |
| 基本性质 | 递归返回聚合值（高度/布尔） | C-146、C-147、C-148、C-149 |
| 由遍历序列构造 | 前序定根 + 中序定划分 + 哈希表定位 | C-150、C-151、C-152 |
| 按层/按列视图 | BFS 取边界元素 / DFS 带坐标 | C-153、C-157 |
| 层内指针 | 利用已建 next 做 O(1) 空间遍历 | C-156 |
| 边界与线索 | 分支特判 / 借用空指针 | C-158、C-159 |
| 迭代器 | 栈模拟中序、惰性求值 | C-160 |

> 所有代码块自带 `TreeNode` 定义（一行构造函数），可直接复制到控制台运行；节点结构统一为 `{ val, left, right }`。

### C-141 二叉树的前序遍历 · 简单 · 字节

**题干**：给你二叉树的根节点 `root`，返回它节点值的**前序遍历**结果（顺序为「根 → 左 → 右」）。约定节点数在 `[0, 100]` 内，节点值在 `[-100, 100]`。

**示例**：`输入: root = [1,null,2,3]` → `输出: [1,2,3]`；`root = []` → `[]`

**思路**：
- 递归最贴合定义：`visit(root); dfs(root.left); dfs(root.right)`。递归的价值在于"前序 = 根 + 左子树的前序 + 右子树的前序"本身就是一个自相似定义，写出来几乎就是题干翻译。
- 迭代用**显式栈**：弹出节点即访问，然后**先压右孩子、再压左孩子**。为什么顺序反着压——栈是后进先出，后压的左孩子会先弹出，从而保证"左子树先于右子树"被访问。这是所有"用栈模拟递归"题的通则。
- Morris 遍历可做到 O(1) 空间（见 C-159），但会临时修改树结构，前序版本在"建线索前访问"即可，面试作为加分项。
- 三种遍历的递归骨架完全一样，只差 `visit` 放在两次递归的哪个位置——这是本章必须建立的肌肉记忆。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function preorderTraversal(root) {
  const res = [], stack = [];
  if (root) stack.push(root);

  while (stack.length) {
    const node = stack.pop();
    res.push(node.val);                    // 根：弹出即访问
    if (node.right) stack.push(node.right); // 先压右
    if (node.left) stack.push(node.left);   // 后压左 => 左先出
  }
  return res;
}
```

**复杂度**：时间 O(n)／空间 O(h)（h 为树高，栈最深等于树高）

**易错点**：
- 压栈顺序写反（先左后右），输出会变成"根右左"。
- 空树直接返回 `[]`，不要 `return null`。
- 返回的是**值数组**而不是节点数组；面试官要求返回节点时要看清题意。
- 递归版本在链状树（n = 10⁴）上可能栈溢出，笔试题里要注意递归深度。

**变体与追问**：
- 中序/后序遍历（C-142、C-143）：只挪动 `visit` 的位置，但迭代版写法差异很大。
- N 叉树前序（LC 589）：把"左右孩子"换成 `children` 逆序压栈。
- 要求 O(1) 空间：Morris 前序——在"建线索"之前访问当前节点。

### C-142 二叉树的中序遍历 · 简单 · 腾讯

**题干**：给你二叉树的根节点 `root`，返回它节点值的**中序遍历**结果（顺序为「左 → 根 → 右」）。约定节点数在 `[0, 100]` 内。

**示例**：`输入: root = [1,null,2,3]` → `输出: [1,3,2]`；`root = []` → `[]`

**思路**：
- 递归：`dfs(left); visit; dfs(right)`，一行不改结构就能从 C-141 变过来。
- 迭代的关键是"先走到底"：用 `cur` 指针一路向左压栈直到 `null`，然后弹栈访问、再把 `cur` 指向该节点的右子树。**为什么必须这么绕**：中序的第一个元素是"最左"节点，而栈只能从顶端取，所以必须先把整条左链压进去；弹出后它的右子树同样要先处理其左链，于是循环复用同一逻辑。
- 循环条件是 `while (cur || stack.length)`：`cur` 非空表示"还有左链没压完"，栈非空表示"还有祖先没访问"，两者缺一都漏节点。
- **中序的特殊地位**：对二叉搜索树，中序遍历的结果严格升序。所以"验证 BST""BST 第 k 小""BST 转有序链表"全都建立在中序之上，这是本章最高频的联动考点。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function inorderTraversal(root) {
  const res = [], stack = [];
  let cur = root;

  while (cur || stack.length) {
    while (cur) {          // 一路向左，把左链全部压栈
      stack.push(cur);
      cur = cur.left;
    }
    cur = stack.pop();     // 最左的节点先出栈
    res.push(cur.val);     // 访问
    cur = cur.right;       // 转向右子树，重复上述过程
  }
  return res;
}
```

**复杂度**：时间 O(n)／空间 O(h)

**易错点**：
- 循环写成 `while (cur)`，栈里剩下的祖先节点全被丢掉，只能输出最左路径。
- 忘记 `cur = cur.right`，会死循环在同一个节点上。
- 空树时 `res` 应为 `[]`，`stack` 为空要能正常退出。
- 递归版在 BST 场景下不要加"提前返回"的剪枝，会让遍历不完整。

**变体与追问**：
- 验证二叉搜索树（LC 98）：中序结果必须严格递增，用 `prev` 记录前一个值。
- BST 中第 k 小的元素：中序计数到第 k 个即返回，可提前终止。
- 恢复二叉搜索树（LC 99）：中序里找到两处逆序对，交换节点值。

### C-143 二叉树的后序遍历 · 简单 · 阿里

**题干**：给你二叉树的根节点 `root`，返回它节点值的**后序遍历**结果（顺序为「左 → 右 → 根」）。约定节点数在 `[0, 100]` 内。

**示例**：`输入: root = [1,null,2,3]` → `输出: [3,2,1]`；`root = []` → `[]`

**思路**：
- 递归：`dfs(left); dfs(right); visit`。后序是树形 DP 的天然顺序——必须先拿到两个子问题的结果才能计算当前节点，这也是"打家劫舍 III""二叉树直径""判断平衡"都用后序的原因。
- 迭代有个巧妙做法：按「根 → 右 → 左」压栈遍历，最后把结果**整体反转**，就得到「左 → 右 → 根」。**为什么成立**：后序序列反转后恰好等于"根右左"，而"根右左"只用改一下 C-141 的压栈顺序就能得到，二者互为镜像。
- 另一种正统迭代用 `lastVisited` 指针记录上一次访问的节点，判断右子树是否已处理完；代码更长但不需要反转，且能在遍历过程中直接做事情（如释放节点）。
- 复杂度都一样：每个节点进出栈各一次，O(n)。选哪种取决于是否需要"流式"处理。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function postorderTraversal(root) {
  const res = [], stack = [];
  if (root) stack.push(root);

  while (stack.length) {
    const node = stack.pop();
    res.push(node.val);
    if (node.left) stack.push(node.left);   // 先压左
    if (node.right) stack.push(node.right); // 后压右 => 右先出
  }
  return res.reverse(); // 根右左 反转 => 左右根
}
```

**复杂度**：时间 O(n)／空间 O(h)

**易错点**：
- 忘记 `reverse()`，得到的是"根右左"而不是后序。
- 压栈顺序与 C-141 弄混：要得到"根右左"，必须先压左再压右（与前序正好相反）。
- 用 `reverse()` 会额外消耗 O(n) 时间（虽然仍是线性），要求"边遍历边处理"时要用 `lastVisited` 版本。
- 空树返回 `[]`，`stack` 初始为空时循环不执行，`reverse` 空数组安全。

**变体与追问**：
- 树形 DP 三件套：二叉树最大路径和（LC 124）、打家劫舍 III（LC 337）、二叉树直径（LC 543）都是后序 + 全局变量。
- 表达式树求值：后序即逆波兰表达式，直接栈求值。
- 释放整棵树（C 语言场景）：必须后序，先释放孩子再释放父节点，否则悬空指针。

### C-144 二叉树的层序遍历 · 中等 · 字节/美团

**题干**：给你二叉树的根节点 `root`，返回其节点值的**层序遍历**结果，即逐层地从左到右访问所有节点，结果按层分组为二维数组。约定节点数在 `[0, 2000]` 内。

**示例**：`输入: root = [3,9,20,null,null,15,7]` → `输出: [[3],[9,20],[15,7]]`；`root = []` → `[]`

**思路**：
- BFS 的物理模型就是队列：根入队，每次取出队首并把它非空的孩子入队，FIFO 保证"先入队的（浅层）先被访问"。
- **关键在于分层**：不能简单地"边出队边 push 结果"，必须在处理一层之前**快照当前队列长度 `size`**，只消费这 `size` 个节点，新入队的孩子留到下一轮。`size` 就是"本层节点数"，也是本题唯一的难点。
- 如果不用 `size` 快照，可以用"下一层数组 `next`"的写法（本实现采用），语义更直观，也避免了 `shift()` 的 O(n) 搬移开销——`shift` 在队列很长时会让整体退化为 O(n²)。
- 层序是所有"按层"问题的母题：锯齿、右视图、层平均值、每层最大值都是在 `for` 循环体内加一行逻辑。
- 复杂度：每个节点入队出队各一次，O(n) 时间；队列最宽处为 O(n/2)，空间 O(n)。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function levelOrder(root) {
  if (!root) return [];
  const res = [];
  let queue = [root];

  while (queue.length) {
    const level = [];   // 本层的值
    const next = [];    // 下一层的节点
    for (const node of queue) {
      level.push(node.val);
      if (node.left) next.push(node.left);
      if (node.right) next.push(node.right);
    }
    res.push(level);    // 一层处理完再入结果，天然分组
    queue = next;
  }
  return res;
}
```

**复杂度**：时间 O(n)／空间 O(n)

**易错点**：
- 用 `queue.shift()` 出队：单次 O(n)，整体 O(n²)，2000 个节点尚可，10⁵ 就超时。
- 没有分层，把整棵树拍平成一维数组，返回结构错。
- 空树必须返回 `[]`（而不是 `[[]]`），否则外层长度多 1。
- 孩子为 `null` 时不要入队，否则下一层长度被撑大，`level` 里出现空值。

**变体与追问**：
- 自底向上的层序（LC 107）：结果 `reverse()` 即可，不必改 BFS。
- 锯齿形层序（C-145）、右视图（C-153）、层平均值（C-154）：都是本题加一行。
- 要求返回"每层的最大宽度"（LC 662）：需要给节点编虚拟下标，属于层序的进阶变形。

### C-145 二叉树的锯齿形层序遍历 · 中等 · 快手

**题干**：给你二叉树的根节点 `root`，返回其节点值的**锯齿形层序遍历**：第一层（根）从左到右，第二层从右到左，第三层从左到右……依此类推，结果仍按层分组。

**示例**：`输入: root = [3,9,20,null,null,15,7]` → `输出: [[3],[20,9],[15,7]]`；`root = [1,2,3,4,null,null,5]` → `[[1],[3,2],[4,5]]`

**思路**：
- 骨架完全是 C-144 的层序：每层收集值、收集下一层节点。唯一的差别是"这一层要不要反着放"。
- 用一个布尔量 `leftToRight` 记录方向，每层结束后取反。偶数层（0 基）正序 `push`，奇数层 `reverse()`。
- **为什么"先收集再反转"而不是"按方向入队"**：入队顺序必须始终是"左孩子先、右孩子先"，否则下一层的父子关系会乱（下一层的左右顺序依赖本层的访问顺序）。所以方向只影响**输出**，不影响**遍历**，把两者解耦才不容易错。用 `unshift` 在前端插入同样可行，但它是 O(n)，不如 `reverse`。
- 复杂度与层序一致：O(n) 时间（`reverse` 的总代价不超过节点数），O(n) 空间。
- 追问常考"第几层从哪边开始"的边界：题目默认第 0 层从左到右，如果改成"从右到左"，只需把初始布尔值取反。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function zigzagLevelOrder(root) {
  if (!root) return [];
  const res = [];
  let queue = [root];
  let leftToRight = true;   // 第 0 层从左到右

  while (queue.length) {
    const level = [], next = [];
    for (const node of queue) {
      level.push(node.val);
      if (node.left) next.push(node.left);
      if (node.right) next.push(node.right);
    }
    res.push(leftToRight ? level : level.reverse());
    leftToRight = !leftToRight;  // 下一层换方向
    queue = next;
  }
  return res;
}
```

**复杂度**：时间 O(n)／空间 O(n)

**易错点**：
- 在 `for` 循环里根据方向决定 `unshift`/`push`，看似省一次反转，实际容易把子节点入队顺序也搞反。
- 方向变量放在循环内重置（每层都 `let leftToRight = true`），锯齿效果消失。
- 空树返回 `[]`；单节点返回 `[[val]]`。
- `reverse()` 是原地修改，如果 `level` 还要复用，记得先拷贝。

**变体与追问**：
- 自底向上 + 锯齿：两个变换叠加，注意顺序（外侧再 `reverse` 一次）。
- 按列之字形打印（Z 字形打印矩阵，LC 498）：同一思想的二维版本。
- 要求返回"每层最右节点"：锯齿方向与右视图无关，右视图始终取每层最右（C-153）。

### C-146 二叉树的最大深度 · 简单 · 美团

**题干**：给定二叉树的根节点 `root`，返回其**最大深度**。最大深度指从根节点到最远叶子节点的最长路径上的**节点数**。约定节点数在 `[0, 10^4]` 内。

**示例**：`输入: root = [3,9,20,null,null,15,7]` → `输出: 3`；`root = [1,null,2]` → `2`；`root = []` → `0`

**思路**：
- 递归定义极其干净：树的深度 = `1 + max(左子树深度, 右子树深度)`，空树深度为 0。这是"自相似结构 + 后序聚合"的教科书案例，写完递归都不需要额外变量。
- 迭代版用 DFS 栈存 `(节点, 当前深度)`，或 BFS 数层数。之所以值得写一个迭代版：链状树深 10⁴ 时递归会爆栈（Node 默认栈约 1 万层，恰好卡在边界）。
- **注意深度定义**：题目算"节点数"而不是"边数"，空树 0、单节点 1。如果按边数定义，空树是 -1、单节点 0，答案整体差 1，这是最常见的口径错误。
- 复杂度：每个节点访问一次，O(n) 时间；递归栈/显式栈深度等于树高，O(h) 空间（BFS 为 O(n)）。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function maxDepth(root) {
  if (!root) return 0;                       // 空树深度为 0
  return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}

// 迭代版：链状树递归会爆栈时使用，按层计数
function maxDepthIter(root) {
  let depth = 0, queue = root ? [root] : [];
  while (queue.length) {
    const next = [];
    for (const node of queue) {
      if (node.left) next.push(node.left);
      if (node.right) next.push(node.right);
    }
    depth++;
    queue = next;
  }
  return depth;
}
```

**复杂度**：时间 O(n)／空间 O(h)（BFS 版 O(n)）

**易错点**：
- 空树返回 0、单节点返回 1，别把"边数"口径混进来。
- 递归版没有尾调用优化，10⁴ 层链状树在部分环境会 `RangeError: Maximum call stack size exceeded`。
- 用 `Math.max` 时不要把 `+1` 写进参数里（`Math.max(depth(l)+1, depth(r)+1)` 也对，但容易和返回值混淆）。
- BFS 版 `depth++` 的位置在 for 之后，放错会多算一层。

**变体与追问**：
- 最小深度（C-147）：不能简单把 `max` 换成 `min`，单侧为空要特判。
- 二叉树直径（LC 543）：后序返回深度，同时用全局变量更新"左深 + 右深"。
- 判断平衡二叉树（LC 110）：后序返回 `-1` 表示不平衡，避免重复计算高度。

### C-147 二叉树的最小深度 · 简单 · 字节

**题干**：给定二叉树的根节点 `root`，返回其**最小深度**。最小深度指从根节点到**最近的叶子节点**的最短路径上的节点数。约定节点数在 `[0, 10^5]` 内。

**示例**：`输入: root = [3,9,20,null,null,15,7]` → `输出: 2`；`root = [1,null,2]` → `2`（不是 1，因为根不是叶子）

**思路**：
- 最自然的解法是 **BFS**：按层扩展，第一次遇到"左右孩子都为空"的节点时，当前层数就是最小深度。**为什么 BFS 天然最优**：BFS 按距离非降序访问，碰到叶子的那一刻不可能存在更浅的叶子，于是可以立即返回，平均能省掉大半节点。
- 递归写法有坑：不能写成 `1 + min(depth(left), depth(right))`。因为叶子必须"没有孩子"，若某个子树为空，`min(0, x)` 会得到 0，返回 1，把"根不是叶子"的情况算错。正确做法是：左空则返回 `1 + 右深度`，右空则返回 `1 + 左深度`，都非空才取 min。
- **为什么最小深度比最大深度难**：最大深度对"空子树贡献 0"是合理的，而最小深度要对空子树**忽略**而不是取 0，这是本题唯一的思维门槛。
- 复杂度：BFS 最坏 O(n) 时间、O(n) 空间；递归 O(n) 时间、O(h) 空间。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function minDepth(root) {
  if (!root) return 0;
  let queue = [root], depth = 0;

  while (queue.length) {
    const next = [];
    depth++;
    for (const node of queue) {
      if (!node.left && !node.right) return depth; // 第一个叶子即答案
      if (node.left) next.push(node.left);
      if (node.right) next.push(node.right);
    }
    queue = next;
  }
  return depth;
}

// 递归写法：单侧为空必须特判，不能直接取 min
function minDepthRec(root) {
  if (!root) return 0;
  if (!root.left) return 1 + minDepthRec(root.right);
  if (!root.right) return 1 + minDepthRec(root.left);
  return 1 + Math.min(minDepthRec(root.left), minDepthRec(root.right));
}
```

**复杂度**：时间 O(n)／空间 O(n)（BFS）或 O(h)（递归）

**易错点**：
- 直接套 `min`：`[1,2]` 会返回 1（错），正确是 2，因为节点 1 有左孩子，不是叶子。
- 忘记"叶子 = 左右都空"，把只有一个孩子的节点当叶子提前返回。
- 空树返回 0；只有根时返回 1。
- BFS 里 `return depth` 的位置必须在"判断是叶子"之后，否则根节点就被当成叶子。

**变体与追问**：
- 最大深度（C-146）：递归直接取 max，无此坑。
- 到最近叶子的距离（边数）：结果减 1。
- 每个节点的最近叶子距离（LC 742）：需要先建父指针图做多源 BFS，难度上一个大台阶。

### C-148 对称二叉树 · 简单 · 腾讯/美团

**题干**：给你一个二叉树的根节点 `root`，检查它是否**轴对称**（以根节点所在竖线为轴左右镜像）。约定节点数在 `[1, 1000]` 内。

**示例**：`输入: root = [1,2,2,3,4,4,3]` → `true`；`root = [1,2,2,null,3,null,3]` → `false`

**思路**：
- 对称不是"左子树等于右子树"，而是"左子树的**左**孩子 与 右子树的**右**孩子镜像相等，左子树的**右**孩子 与 右子树的**左**孩子镜像相等"。所以递归参数必须是**两个节点**，比较时交叉。
- 递归三要素：① 都为空 → 对称；② 只有一个为空 → 不对称；③ 值相等 **且** `mirror(a.left, b.right)` **且** `mirror(a.right, b.left)`。
- **为什么不能用"左右子树相同"来判断**：`[1,2,2,null,3,null,3]` 的左右子树本身不同（一个左倾一个右倾），但整体仍是对称的；反过来也有左右子树相同但整体不对称的例子。必须是镜像关系。
- 迭代做法：队列里**成对**入队 `(left, right)`、成对出队比较，本质是把递归的调用栈显式化。
- 复杂度：每个节点最多比较一次，O(n) 时间；递归深度为树高，O(h) 空间。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function isSymmetric(root) {
  // 判断 a、b 两棵子树是否互为镜像
  const mirror = (a, b) => {
    if (!a && !b) return true;              // 都空 => 对称
    if (!a || !b) return false;             // 一空一满 => 不对称
    return a.val === b.val
      && mirror(a.left, b.right)            // 交叉比较
      && mirror(a.right, b.left);
  };
  return !root || mirror(root.left, root.right);
}
```

**复杂度**：时间 O(n)／空间 O(h)

**易错点**：
- 写成 `isSame(root.left, root.right)`（比较两棵子树是否**相同**），`[1,2,2,null,3,null,3]` 会误判。
- 双空的判断必须放在单空之前，否则 `!a || !b` 会把"都空"判成 false。
- 用值比较 `===` 而不是 `==`；节点值可能为 0，`if (!a.val)` 之类的写法会误判。
- 空树按题意不存在，但 `!root` 返回 true 是安全兜底。

**变体与追问**：
- 相同的树（LC 100）：同位置比较，不交叉。
- 翻转等价二叉树（LC 951）：允许每个节点左右互换，递归时两种组合取或。
- 判断两棵树是否镜像（不要求同一棵树）：直接复用 `mirror(a, b)`，是本题的函数拆解版。

### C-149 翻转二叉树 · 简单 · 字节/阿里

**题干**：给你一棵二叉树的根节点 `root`，翻转这棵二叉树（每个节点的左右子树互换），并返回其根节点。约定节点数在 `[0, 100]` 内。

**示例**：`输入: root = [4,2,7,1,3,6,9]` → `输出: [4,7,2,9,6,3,1]`；`root = []` → `[]`

**思路**：
- 递归：对每个节点交换 `left` 与 `right`，再递归翻转两棵子树。因为每个节点都要做同一件事，且子问题结构相同，递归是最贴合定义的写法。
- 交换与递归的**先后顺序无关**（先交换再递归，或者先递归再交换结果一样），但必须两个都做，不能只交换根。
- 迭代两种：DFS 用栈把节点逐个弹出、交换孩子、把孩子压栈；BFS 用队列同理。**为什么迭代也成立**：每个节点只被访问一次，交换操作与访问顺序无关。
- 一个常被考的细节：交换用 `[a.left, a.right] = [a.right, a.left]` 解构，避免引入临时变量；`root` 本身不换位置，所以直接返回 `root`。
- 复杂度：每个节点访问一次，O(n) 时间；递归栈 O(h)，迭代队列/栈最坏 O(n)。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function invertTree(root) {
  if (!root) return null;
  // 1) 交换左右孩子
  [root.left, root.right] = [root.right, root.left];
  // 2) 递归翻转两棵子树
  invertTree(root.left);
  invertTree(root.right);
  return root;
}

// 迭代版（BFS）：避免深树递归爆栈
function invertTreeIter(root) {
  if (!root) return null;
  const queue = [root];
  for (let i = 0; i < queue.length; i++) {
    const node = queue[i];
    [node.left, node.right] = [node.right, node.left];
    if (node.left) queue.push(node.left);
    if (node.right) queue.push(node.right);
  }
  return root;
}
```

**复杂度**：时间 O(n)／空间 O(h)（迭代版 O(n)）

**易错点**：
- 只交换根节点的两个孩子，忘记递归到子树，只有第一层被翻转。
- 先递归后交换时，递归的是原来的孩子，交换后指针关系要理清（容易把同一棵子树翻两次）。
- 返回 `null` 还是 `root`：空树返回 `null`，非空必须返回根节点本身（不是新节点）。
- 原地修改会破坏原树，若题目要求"不修改原树"需要深拷贝。

**变体与追问**：
- 判断两棵树是否"翻转等价"（LC 951）：递归时比较 `(a.left,b.left)` 或 `(a.left,b.right)` 两种情况。
- 对称二叉树（C-148）：等价于"树与自身是否翻转等价"。
- 按层翻转（偶数层翻转）：层序 + 层索引控制。

### C-150 从前序与中序遍历序列构造二叉树 · 中等 · 字节/腾讯

**题干**：给定两个整数数组 `preorder` 和 `inorder`，其中 `preorder` 是二叉树的先序遍历，`inorder` 是同一棵树的中序遍历。请构造并返回这棵二叉树。约定树中**无重复元素**，节点数在 `[1, 3000]` 内。

**示例**：`输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]` → `输出: [3,9,20,null,null,15,7]`

**思路**：
- 前序的第一个元素一定是**根**。拿到根值后去中序里找它的位置 `mid`，`mid` 左边就是左子树的所有节点（共 `mid - left` 个），右边是右子树。有了"左子树节点个数"，就能同时切分前序数组。
- **为什么能唯一确定**：无重复元素时，根值在中序中位置唯一，于是左右子树的节点**集合**唯一；再对两半递归，结构完全确定。若允许重复元素，同一组遍历序列可能对应多棵树，问题就不成立——这是必答的一句。
- 递归函数的参数用**下标区间**而不是切片：`build(preL, preR, inL, inR)`，避免每层复制数组导致 O(n²) 时间和空间。用 `Map<值, 下标>` 把"中序定位"从 O(n) 降到 O(1)。
- 复杂度：每个节点建一次，O(n) 时间；哈希表 + 递归栈 O(n) 空间（栈深为树高）。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function buildTree(preorder, inorder) {
  const pos = new Map();
  inorder.forEach((v, i) => pos.set(v, i)); // 值 -> 中序下标
  let p = 0;                                 // 前序的全局游标

  const build = (inL, inR) => {
    if (inL > inR) return null;
    const root = new TreeNode(preorder[p++]); // 前序下一个即当前子树的根
    const mid = pos.get(root.val);
    root.left = build(inL, mid - 1);          // 左子树区间
    root.right = build(mid + 1, inR);         // 右子树区间
    return root;
  };

  return build(0, inorder.length - 1);
}
```

**复杂度**：时间 O(n)／空间 O(n)

**易错点**：
- 用 `inorder.indexOf(root.val)` 每个节点都扫一遍，复杂度退化为 O(n²)，3000 个节点就会明显变慢。
- 区间边界写成 `build(inL, mid)` 或 `build(mid, inR)`，会死递归或漏节点；空区间条件是 `inL > inR`。
- 前序游标 `p` 必须是**闭包外的可变变量**，放在递归函数内每次重置就全乱了。
- 空数组输入（题目保证 n ≥ 1，但接口要能处理）应返回 `null`。
- 递归深度：极端链状树 3000 层接近 Node 默认栈上限，必要时改迭代。

**变体与追问**：
- 中序 + 后序（C-151）：根在末尾，需要**先建右子树**。
- 前序 + 后序（C-152）：不唯一，因为单孩子无法区分左右。
- 前序构造 BST（LC 1008）：利用 BST 上下界，O(n) 且不需要中序。
- 中序 + 层序构造：层序首元素是根，按"是否在左区间"分组，O(n²) 但可优化到 O(n)。

### C-151 从中序与后序遍历序列构造二叉树 · 中等 · 阿里

**题干**：给定两个整数数组 `inorder` 和 `postorder`，其中 `inorder` 是二叉树的中序遍历，`postorder` 是同一棵树的后序遍历。请构造并返回这棵二叉树。约定树中**无重复元素**，节点数在 `[1, 3000]` 内。

**示例**：`输入: inorder = [9,3,15,20,7], postorder = [9,15,7,20,3]` → `输出: [3,9,20,null,null,15,7]`

**思路**：
- 后序的**最后一个**元素是根；中序里根的位置把左右子树分开。这一点与前+中构造完全对称，只是"取根"的方向反了。
- 关键差别：后序从右往左读，依次是"根 → 右子树根 → 右子树内部 …… → 左子树根"，所以递归时**必须先建右子树、再建左子树**，游标 `p` 从 `postorder.length - 1` 开始递减。若先建左子树，游标会指向错误的元素。
- **为什么必须"先右后左"**：后序的镜像（倒序）是"根右左"，即前序的镜像版本。前序配中序时我们按"根左右"消费前序，这里按"根右左"消费后序，顺序必须一致。
- 同样用 `Map` 存中序下标，区间用闭区间 `[inL, inR]`，避免数组切片。
- 复杂度：O(n) 时间、O(n) 空间。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function buildTree(inorder, postorder) {
  const pos = new Map();
  inorder.forEach((v, i) => pos.set(v, i));
  let p = postorder.length - 1;   // 后序从末尾往前消费

  const build = (inL, inR) => {
    if (inL > inR) return null;
    const root = new TreeNode(postorder[p--]); // 后序末尾是根
    const mid = pos.get(root.val);
    root.right = build(mid + 1, inR); // 先建右子树！
    root.left = build(inL, mid - 1);
    return root;
  };

  return build(0, inorder.length - 1);
}
```

**复杂度**：时间 O(n)／空间 O(n)

**易错点**：
- 先建左子树：后序游标会去取"右子树的根"，构造出的树结构完全错乱。
- 游标初值写成 `0` 或递增，必须从 `length - 1` 递减。
- 边界 `mid + 1` / `mid - 1` 写反，会漏掉或重复节点。
- 两个数组长度不一致时（非法输入）要能提前返回 `null`，否则越界取到 `undefined`。

**变体与追问**：
- 前序 + 中序（C-150）：方向相反，正好可以拿来对照记忆。
- 后序 + 中序构造 BST：利用 BST 性质可省掉 Map，直接按值域切分。
- 由中序 + 层序构造：层序首元素为根，其余按中序位置分组，递归下去。

### C-152 根据前序和后序遍历构造二叉树 · 中等 · 美团

**题干**：给定两个整数数组 `preorder` 和 `postorder`，其中 `preorder` 是二叉树的前序遍历，`postorder` 是同一棵树的后序遍历。请构造并返回这棵二叉树。如果存在多个答案，返回**任意一个**即可。约定节点数在 `[1, 30]` 内，值互不相同。

**示例**：`输入: preorder = [1,2,4,5,3,6,7], postorder = [4,5,2,6,7,3,1]` → `输出: [1,2,3,4,5,6,7]`

**思路**：
- 前序首元素 `pre[0]` 是根，后序末元素 `post[-1]` 也是根，两者一致，这是校验点。真正的信息在 `pre[1]`：它一定是**左子树的根**（只要左子树非空）。
- 在后序里找到 `pre[1]` 的位置 `idx`，则左子树包含 `post[0..idx]` 共 `idx + 1` 个节点，右子树包含 `post[idx+1 .. -2]`。据此同时切分两个数组，递归。
- **为什么答案不唯一**：若某个节点只有一个孩子，前序是"根 + 孩子"、后序是"孩子 + 根"，无论这个孩子是左还是右，两种遍历序列**完全相同**，无法区分。所以题目允许任意答案。实现上把这种情况统一当"左孩子"处理即可。
- **为什么仍能确定节点数**：`pre[1]` 在后序中的位置唯一确定左子树的规模，因此即使左右归属有歧义，每一层的划分是确定的，递归不会错乱。
- 复杂度：用 `Map` 存后序下标，每次 O(1) 定位，总 O(n) 时间、O(n) 空间；若用 `indexOf` 则 O(n²)。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function constructFromPrePost(preorder, postorder) {
  const postPos = new Map();
  postorder.forEach((v, i) => postPos.set(v, i));

  const build = (preL, preR, postL, postR) => {
    if (preL > preR) return null;
    const root = new TreeNode(preorder[preL]);
    if (preL === preR) return root;            // 只有一个节点

    // pre[preL + 1] 是左子树根，用它算出左子树节点数
    const leftSize = postPos.get(preorder[preL + 1]) - postL + 1;

    root.left = build(preL + 1, preL + leftSize, postL, postL + leftSize - 1);
    root.right = build(preL + leftSize + 1, preR, postL + leftSize, postR - 1);
    return root;
  };

  return build(0, preorder.length - 1, 0, postorder.length - 1);
}
```

**复杂度**：时间 O(n)／空间 O(n)

**易错点**：
- 忘记 `preL === preR` 的终止条件，单节点时会去取 `preorder[preL + 1]`（`undefined`），`postPos.get` 返回 `undefined`，`leftSize` 变 `NaN`。
- `leftSize` 算成 `idx - postL`（少 1），左子树会吞掉右子树的根。
- 右子树的后序区间是 `[postL + leftSize, postR - 1]`，末尾的 `-1` 是排除根，漏掉它会重复建节点。
- 误以为答案唯一，试图"判左右"——单孩子场景下根本无从判断，反而写死循环。

**变体与追问**：
- 前序 + 中序（C-150）唯一确定；中序 + 后序（C-151）唯一确定。只有"前 + 后"丢信息，这三者的对比是高频八股。
- 满二叉树的前序 + 后序：没有单孩子节点，因此**唯一**，可以按 `2^k - 1` 切分。
- 由前序 + 后序判断能否构成唯一树：统计"单孩子节点"的个数，为 0 才唯一。

### C-153 二叉树的右视图 · 中等 · 字节/快手

**题干**：给定一棵二叉树的根节点 `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值（即每一层最右边的节点）。约定节点数在 `[0, 100]` 内。

**示例**：`输入: root = [1,2,3,null,5,null,4]` → `输出: [1,3,4]`；`root = [1,null,3]` → `[1,3]`

**思路**：
- BFS 版最直观：层序遍历，每层取最后一个元素。C-144 的代码把 `res.push(level)` 换成 `res.push(level[level.length - 1])` 即可。
- DFS 版更省空间（不需要存整层）：**先访问右子树、再访问左子树**，并用 `depth` 记录当前深度。若 `depth === res.length`，说明这一层还是第一次被访问到，而第一次访问的必然是最右节点，直接记录。
- **为什么"先右后左"是关键**：换顺序后第一次到达某层的就是最左节点，结果变成左视图。深度 `depth` 从 0 开始，与 `res.length` 比较就是"这一层还没记录过"的判断。
- 两种解法的复杂度都是 O(n)；BFS 空间 O(n)（最宽一层），DFS 空间 O(h)（只存结果和递归栈）。
- 追问常考："如果从左侧看"——把左右递归顺序对调即可，其他不动。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function rightSideView(root) {
  const res = [];

  const dfs = (node, depth) => {
    if (!node) return;
    if (depth === res.length) res.push(node.val); // 该层第一次到访 => 最右
    dfs(node.right, depth + 1);                   // 先右
    dfs(node.left, depth + 1);                    // 后左
  };

  dfs(root, 0);
  return res;
}
```

**复杂度**：时间 O(n)／空间 O(h)

**易错点**：
- 先左后右，得到的是左视图。
- 用 `depth < res.length` 判断会漏掉新层；必须 `===`（深度不会跳跃）。
- `depth` 从 1 开始也能写，但比较条件要同步改成 `depth > res.length`，两处必须一致。
- 空树返回 `[]`；只有右链的树应逐层全部返回。

**变体与追问**：
- 左视图：递归顺序对调。
- 俯视图（LC 987 的简化版）：按列取最上层节点，需要坐标 + 排序。
- 二叉树的边界（C-158）：右视图 + 左视图 + 叶子的组合，但要求不同（不含某些节点）。

### C-154 二叉树的层平均值 · 简单 · 美团

**题干**：给定一个非空二叉树的根节点 `root`，以数组的形式返回每一层节点值的**平均值**。与实际问题答案误差在 `10^-5` 以内均视为正确。约定节点数在 `[1, 10^4]` 内，节点值在 `[0, 10^5]` 内。

**示例**：`输入: root = [3,9,20,null,null,15,7]` → `输出: [3.00000, 14.50000, 11.00000]`

**思路**：
- 层序遍历的"求和版"：每层遍历时累加 `sum`，同时本层节点数就是 `queue.length`，平均值 `sum / queue.length`。
- **为什么必须按层求平均**：平均值是"层内统计量"，如果只用一个全局 `sum`/`count`，得到的是整棵树的平均值，语义完全不同。这是本题与 C-146（数层数）的唯一区别——一个在层内累加，一个在层间计数。
- 也可以 DFS 实现：`sums[depth] += val`、`counts[depth]++`，最后逐层相除。DFS 的好处是不需要一次性存整层节点，但要额外两个数组。
- 复杂度：每个节点访问一次，O(n) 时间；队列最宽 O(n)，空间 O(n)（DFS 版为 O(h)）。
- 精度：JS 的 `number` 是双精度浮点，直接相除即可；C++/Java 要注意 `double` 而不是整除。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function averageOfLevels(root) {
  const res = [];
  let queue = root ? [root] : [];

  while (queue.length) {
    const next = [];
    let sum = 0;
    for (const node of queue) {
      sum += node.val;
      if (node.left) next.push(node.left);
      if (node.right) next.push(node.right);
    }
    res.push(sum / queue.length); // 本层平均值
    queue = next;
  }
  return res;
}
```

**复杂度**：时间 O(n)／空间 O(n)

**易错点**：
- 除数是 `queue.length`（本层节点数），不是 `res.length` 或全树节点数。
- `sum` 必须在每层开头重置为 0，写在循环外会累加所有层。
- 空树返回 `[]`；题目虽保证非空，接口仍要能处理。
- 节点值最大 10⁵、数量 10⁴，总和 10⁹，在安全整数内；若值域更大需注意精度。

**变体与追问**：
- 每层最大值/最小值（LC 515）：`sum` 换成 `max`，逻辑同构。
- 每层节点和：去掉除法。
- 求"每层方差"：需要 Σx 和 Σx² 两个累加器，是一次方差公式的应用。

### C-155 N 叉树的层序遍历 · 中等 · 腾讯

**题干**：给定一个 N 叉树的根节点 `root`，返回其节点值的层序遍历（即从左到右、逐层遍历）。结果按层分组为二维数组。节点定义：`Node { val, children: Node[] }`。约定节点数在 `[0, 10^4]` 内。

**示例**：`输入: root = [1,null,3,2,4,null,5,6]` → `输出: [[1],[3,2,4],[5,6]]`

**思路**：
- 与二叉树的层序**完全同构**：把"左孩子 / 右孩子"换成"遍历 `children` 全部入队"。N 叉树只是把"两个固定指针"变成了"一个数组"，BFS 的不变式（FIFO 保证按层）不依赖孩子的数量。
- 分层仍然靠"每轮换一个新数组 `next`"（或 `size` 快照）。`next` 里按 `children` 的顺序 push，天然保持从左到右。
- **为什么不能用"只用一个队列 + 记录层号"的写法**：也能做，但需要额外存 `(node, depth)`，空间常数更大；分层数组更直观。
- 复杂度：每个节点入队出队各一次，O(n) 时间；队列最宽一层，O(n) 空间（n 为节点数，最坏为星形树）。

**代码**：
```javascript
function Node(val = 0, children = []) {
  this.val = val; this.children = children;
}

function levelOrder(root) {
  if (!root) return [];
  const res = [];
  let queue = [root];

  while (queue.length) {
    const level = [], next = [];
    for (const node of queue) {
      level.push(node.val);
      for (const child of node.children) next.push(child); // 差异只在这一行
    }
    res.push(level);
    queue = next;
  }
  return res;
}
```

**复杂度**：时间 O(n)／空间 O(n)

**易错点**：
- `children` 可能是空数组而不是 `null`，`if (node.children)` 恒为真，必须直接遍历（空数组遍历零次，安全）。
- 节点字段名是 `children` 不是 `left/right`，从二叉树题照抄会立刻报错。
- 空树返回 `[]`；单节点返回 `[[val]]`。
- 用 DFS 实现层序时，要在 `depth` 超出当前结果长度时新建一层，否则同一层的数据会错位。

**变体与追问**：
- N 叉树的最大深度（LC 559）：`1 + max(children 的深度)`，空数组返回 1。
- N 叉树的前序/后序（LC 589/590）：把"左右"换成"children 顺序/逆序"。
- 序列化与反序列化 N 叉树（LC 428）：层序 + `null` 分隔符，是本题的工程化版本。

### C-156 填充每个节点的下一个右侧节点指针 · 中等 · 字节

**题干**：给定一棵**完美二叉树**（所有叶子在同一层，每个父节点都有两个子节点），其所有叶子节点都在同一层。每个节点除了 `val`、`left`、`right` 之外还有一个 `next` 指针，初始均为 `null`。请填充每个节点的 `next`，使其指向同层的下一个右侧节点；若右侧没有节点，则保持 `null`。要求使用**常量级额外空间**。

**示例**：`输入: root = [1,2,3,4,5,6,7]` → 输出层级序列 `[1,#,2,3,#,4,5,6,7,#]`（`#` 表示每层末尾的 `null`）

**思路**：
- 朴素做法是 BFS，用队列把每层节点串起来，空间 O(n)，不满足"常量空间"的要求。
- 关键观察：**上一层的 `next` 链已经建好**，可以把它当成一条链表来遍历。于是从最左节点开始逐层处理：对当前层的每个节点 `head`，做两次连接——① `head.left.next = head.right`（同一父节点的兄弟）；② 若 `head.next` 存在，`head.right.next = head.next.left`（跨父节点的表亲）。然后 `head = head.next` 沿链右移，本层走完后 `leftmost = leftmost.left` 进入下一层。
- **为什么只需 O(1) 空间**：不存任何节点集合，只用 `leftmost` 和 `head` 两个指针，靠树自身的 `next` 链导航。
- 终止条件用 `while (leftmost.left)`：完美二叉树的最后一层没有孩子，处理完倒数第二层就该停。
- 复杂度：每个节点被访问常数次，O(n) 时间；O(1) 额外空间（递归栈都不需要）。

**代码**：
```javascript
function Node(val = 0, left = null, right = null, next = null) {
  this.val = val; this.left = left; this.right = right; this.next = next;
}

function connect(root) {
  if (!root) return root;
  let leftmost = root;              // 当前层最左节点

  while (leftmost.left) {           // 最后一层没有孩子，提前退出
    let head = leftmost;
    while (head) {
      head.left.next = head.right;                       // 同一父节点的兄弟
      if (head.next) head.right.next = head.next.left;   // 跨父节点的表亲
      head = head.next;                                  // 沿 next 链右移
    }
    leftmost = leftmost.left;       // 下沉到下一层
  }
  return root;
}
```

**复杂度**：时间 O(n)／空间 O(1)

**易错点**：
- 忘记判断 `head.next`，最后一列的右孩子会指向 `undefined`（应为 `null`）。
- 写成 `while (leftmost)`，最后一层没有孩子时会取 `leftmost.left` 得到 `null` 后继续循环，逻辑错乱。
- 认为 `next` 需要手动置 `null`：题目初始即为 `null`，只要不误赋值即可。
- 把本题结论直接套到**非完美**二叉树上（LC 117）：会漏掉"跨父节点但中间隔着空孩子"的情况，需要沿 `next` 链找第一个有孩子的节点。

**变体与追问**：
- 填充每个节点的下一个右侧节点指针 II（LC 117）：普通二叉树，需要用 `next` 链做"找下一个有孩子的节点"的循环，或改用 BFS。
- 连接所有同层节点（不限于完美树）：同上。
- 用层序 + 双指针实现：`prev.next = cur`，空间 O(1) 但需要队列存层，除非用本题技巧。

### C-157 二叉树的垂序遍历 · 困难 · 字节/阿里

**题干**：给你二叉树的根节点 `root`，按**垂序**返回其节点值。对位于 `(row, col)` 的节点：左孩子为 `(row+1, col-1)`，右孩子为 `(row+1, col+1)`，根为 `(0, 0)`。垂序要求：按 `col` 从小到大；同一 `col` 内按 `row` 从小到大；若 `row`、`col` 都相同，则按**节点值**从小到大。约定节点数在 `[1, 1000]` 内。

**示例**：`输入: root = [3,9,20,null,null,15,7]` → `输出: [[9],[3,15],[20],[7]]`

**思路**：
- 题目给了三把排序键，最直接的解法就是**先把所有节点连同坐标收集起来，再三重排序，最后按 `col` 分组**。
- 坐标用 DFS 传播最简单：进入节点时带上 `(row, col)`，向左 `(row+1, col-1)`、向右 `(row+1, col+1)`。**为什么用 DFS 而不是 BFS**：坐标只依赖路径，与访问顺序无关，DFS 代码更短；BFS 也能做，但要额外维护队列中的坐标元组。
- **为什么必须按 `(col, row, val)` 三重排序**：`col` 决定分组，`row` 决定同列内的上下顺序，而同一 `(row, col)` 位置可能落多个节点（一个节点只有左孩子、另一个节点只有右孩子时可以在同一列同一行），此时题目要求按值升序。
- 分组时用"当前列号是否变化"来判断是否新建一组，注意 `col` 可能是负数，初值要用 `null`/`undefined` 而不是 `0`。
- 复杂度：收集 O(n)，排序 O(n log n)，分组 O(n)；空间 O(n)。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function verticalTraversal(root) {
  const nodes = [];
  const dfs = (node, row, col) => {
    if (!node) return;
    nodes.push([col, row, node.val]);
    dfs(node.left, row + 1, col - 1);
    dfs(node.right, row + 1, col + 1);
  };
  dfs(root, 0, 0);

  // 主键 col 升序，次键 row 升序，三键 val 升序
  nodes.sort((a, b) => a[0] - b[0] || a[1] - b[1] || a[2] - b[2]);

  const res = [];
  let lastCol = null;
  for (const [col, , val] of nodes) {
    if (col !== lastCol) {
      res.push([]);
      lastCol = col;
    }
    res[res.length - 1].push(val);
  }
  return res;
}
```

**复杂度**：时间 O(n log n)／空间 O(n)

**易错点**：
- `lastCol` 初始化为 `0`：若最小列恰好是 0，第一组会漏建（虽然之后会补上，但若整棵树只有一列就会出错）。用 `null` 最稳。
- 少写第三把键，同一 `(row, col)` 的多个值顺序不确定，判题失败。
- `col` 可以为负，不能假设非负后用数组下标存。
- 分组时把 `col` 和 `row` 搞反，输出的层次结构完全错。

**变体与追问**：
- 垂直遍历（按值排序的变体，LC 314）：只按 `col` 分组、组内按 `row`，是本题的简化版。
- 对角线遍历（LC 498）：`row - col` 相同的节点在一条对角线上。
- 俯视图：每列只取 `row` 最小的节点，可在本题基础上每组取首元素。

### C-158 二叉树的边界 · 中等 · 阿里

**题干**：给定一棵二叉树的根节点 `root`，按**逆时针**方向返回它的**边界**节点值。边界依次为：根节点 → 左边界（自上而下，**不含**叶子）→ 叶子节点（从左到右）→ 右边界（自下而上，**不含**叶子）。约定节点数在 `[0, 10^4]` 内。

**示例**：`输入: root = [1,null,2,3,4]` → `输出: [1,3,4,2]`；`root = [1]` → `[1]`

**思路**：
- 拆成四个子过程，顺序拼起来：① 根；② 左边界；③ 全部叶子；④ 右边界反转。
- 左边界：从 `root.left` 出发，只要不是叶子就记录，然后优先往左走、没有左孩子往右走（`cur.left || cur.right`）。**为什么不含叶子**：叶子归第 ③ 步统一收集，若这里也记录会重复。
- 右边界：从 `root.right` 出发同理，但顺序是自上而下，所以要**先存进临时数组再反转**，才能得到自下而上。
- 叶子：DFS 左右递归，遇到 `!left && !right` 就记录，天然是从左到右。
- **为什么单节点要特判**：单节点本身就是叶子，若继续走 ②③④，叶子收集会把根再加一次，得到 `[1,1]`。提前 `isLeaf(root)` 返回可一劳永逸。
- 复杂度：每个节点最多被访问常数次，O(n) 时间；递归栈 O(h)，结果数组 O(n)。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function boundaryOfBinaryTree(root) {
  if (!root) return [];
  const isLeaf = n => !n.left && !n.right;
  if (isLeaf(root)) return [root.val];   // 单节点，否则会重复

  const res = [root.val];

  let cur = root.left;                   // ② 左边界（不含叶子）
  while (cur) {
    if (!isLeaf(cur)) res.push(cur.val);
    cur = cur.left || cur.right;
  }

  const addLeaves = node => {            // ③ 叶子，从左到右
    if (!node) return;
    if (isLeaf(node)) { res.push(node.val); return; }
    addLeaves(node.left);
    addLeaves(node.right);
  };
  addLeaves(root);

  const right = [];                      // ④ 右边界（不含叶子），反向输出
  cur = root.right;
  while (cur) {
    if (!isLeaf(cur)) right.push(cur.val);
    cur = cur.right || cur.left;
  }
  res.push(...right.reverse());
  return res;
}
```

**复杂度**：时间 O(n)／空间 O(h)（结果数组 O(n)）

**易错点**：
- 左边界/右边界把叶子也算进去，节点在结果里出现两次。
- 单节点没特判，输出 `[1,1]`。
- 右边界忘记 `reverse()`，顺序变成自上而下。
- 左边界下降时只用 `cur.left`，遇到"只有右孩子"的节点会提前中断，必须 `cur.left || cur.right`。
- 根节点只加一次：不要在两个边界过程里都从 `root` 开始。

**变体与追问**：
- 顺时针边界：等价于"根 + 左边界反转 + 叶子 + 右边界"，方向整个翻过来。
- 只要左边界/右边界：直接取对应子过程。
- 二叉树的周长（LC 周赛题）：边界的"相邻节点距离"求和，需要额外记录路径长度。

### C-159 Morris 遍历 · 中等 · 腾讯

**题干**：实现二叉树的**中序遍历**，要求时间复杂度 O(n)、**额外空间 O(1)**（不允许递归、不允许显式栈，只允许常数个指针变量）。返回节点值数组。本题是 LC 94 的"进阶问法"，面试常以"能不能不用栈也不用递归"的形式出现。

**示例**：`输入: root = [1,null,2,3]` → `输出: [1,3,2]`

**思路**：
- 递归和栈都要 O(h) 空间，本质是用"外部容器"记住回家的路。Morris 的想法是：**把回家的路记在树上**——利用叶子节点空着的 `right` 指针，临时指向它的中序后继（即某个祖先）。
- 对当前节点 `cur`：
  - 若 `cur.left` 为空，直接访问 `cur`，然后 `cur = cur.right`（可能是指向祖先的线索，也可能是真实右孩子，处理方式恰好相同）。
  - 若 `cur.left` 不为空，找左子树中**最右**的节点 `pre`。若 `pre.right` 为空（第一次到达），把它指向 `cur`（建线索），然后 `cur = cur.left`；若 `pre.right === cur`（第二次到达，说明左子树已经遍历完），把线索**断开**（恢复原树），访问 `cur`，然后 `cur = cur.right`。
- **为什么额外空间是 O(1)**：只用了 `cur`、`pre` 两个指针，栈信息全部编码进了树结构。
- **为什么时间仍是 O(n)**：每条边最多被走两次（一次建线索、一次断线索），总步数与 n 成正比，常数约为 2。
- 关键纪律：遍历结束后必须把线索全部断开，否则树结构被永久破坏。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

function inorderTraversal(root) {
  const res = [];
  let cur = root;

  while (cur) {
    if (!cur.left) {                  // 没有左子树，直接访问
      res.push(cur.val);
      cur = cur.right;
    } else {
      let pre = cur.left;             // 找左子树最右节点（中序前驱）
      while (pre.right && pre.right !== cur) pre = pre.right;

      if (!pre.right) {               // 第一次到访：建线索
        pre.right = cur;
        cur = cur.left;
      } else {                        // 第二次到访：断线索 + 访问
        pre.right = null;
        res.push(cur.val);
        cur = cur.right;
      }
    }
  }
  return res;
}
```

**复杂度**：时间 O(n)／空间 O(1)

**易错点**：
- `while (pre.right && pre.right !== cur)` 少了 `pre.right !== cur`，在已建线索的树上会死循环。
- 第二次到访忘记 `pre.right = null`，树被永久改坏，后续任何操作都出错。
- 把"访问时机"写成前序（第一次到访就 `push`），得到的是前序而不是中序。
- 只在 `else` 分支里访问节点，`!cur.left` 分支忘了 `push`。

**变体与追问**：
- Morris 前序：在"建线索之前"访问 `cur`，其余不变。
- Morris 后序：需要额外反转右链，实现复杂，面试极少要求，但能说出来是加分项。
- O(1) 空间验证 BST（LC 98 进阶）：Morris 中序 + `prev` 指针比较相邻值。

### C-160 二叉搜索树迭代器 · 中等 · 美团

**题干**：实现一个 `BSTIterator` 类，表示按**中序遍历**迭代器遍历二叉搜索树（BST）：构造函数接收根节点 `root`；`next()` 返回 BST 中下一个最小的数；`hasNext()` 返回是否还有下一个数。要求 `next()` 和 `hasNext()` 的**均摊**时间复杂度为 O(1)，空间复杂度 O(h)。

**示例**：`root = [7,3,15,null,null,9,20]`，依次 `next()→3`、`next()→7`、`hasNext()→true`、`next()→9`、`next()→15`、`next()→20`、`hasNext()→false`

**思路**：
- 核心是**用栈模拟中序递归**：递归的"函数调用栈"里存的正是"还没访问的祖先"，我们手动维护这条左链。
- 构造函数：从根一路向左压栈，压到最左节点为止——栈顶就是最小值。
- `next()`：弹出栈顶（这就是下一个最小），然后对它的**右子树**重复"一路向左压栈"（右子树的最小值就是紧随其后的元素）。
- **为什么均摊 O(1)**：每个节点只会被压栈一次、出栈一次，n 次 `next()` 总共 O(n) 次操作，均摊到每次是 O(1)。单次最坏仍是 O(h)（右子树的左链很长），这是"均摊"二字的含义，必须说清楚。
- **为什么不用"一次性中序存数组"**：那样空间 O(n)，且失去惰性——对于超大或动态变化的 BST 不可接受；面试官追问"如果树很大、只取前 k 个"时，惰性求值才是正解。
- 复杂度：空间 O(h)（栈深为树高），`hasNext()` O(1)。

**代码**：
```javascript
function TreeNode(val = 0, left = null, right = null) {
  this.val = val; this.left = left; this.right = right;
}

class BSTIterator {
  constructor(root) {
    this.stack = [];
    this.pushLeft(root);          // 初始化：压入最左链
  }

  pushLeft(node) {
    while (node) {
      this.stack.push(node);
      node = node.left;
    }
  }

  next() {
    const node = this.stack.pop(); // 栈顶即当前最小
    this.pushLeft(node.right);     // 右子树的左链入栈
    return node.val;
  }

  hasNext() {
    return this.stack.length > 0;
  }
}
```

**复杂度**：`next()` 均摊 O(1)（最坏 O(h)），`hasNext()` O(1)；空间 O(h)

**易错点**：
- 构造函数忘记压左链，第一次 `next()` 就返回 `undefined`。
- `next()` 里只弹栈不处理右子树，遍历到某个节点后就"断流"。
- 用 `stack.shift()` 取最小值：栈的语义被破坏，且 O(n) 搬移。
- `hasNext()` 写成 `this.stack.length >= 0`（恒为 true），遍历结束后仍返回 true。
- 把"均摊 O(1)"说成"每次 O(1)"，被追问右链很长的情况时答不上来。

**变体与追问**：
- 倒序迭代器：把"一路向左"改成"一路向右"，用于求前驱。
- 带 `peek()` 的迭代器：只需返回 `stack[stack.length - 1].val` 而不弹出。
- BST 第 k 小（LC 230 进阶）：调 `next()` k 次，O(h + k)，比中序全量 O(n) 更优。
