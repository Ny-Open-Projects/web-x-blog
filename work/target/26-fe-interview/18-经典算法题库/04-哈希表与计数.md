# 04 哈希表与计数（C-061 ~ C-080）

> 哈希表是大厂笔试的"万能加速器"：凡是题干出现"是否出现过""出现多少次""配对""去重""下标差"，第一反应都该是哈希。它把"查找"从 O(n) 降到 O(1)，用空间换时间，是最典型的取舍题。**识别特征**：看到"两数/四数配对"想到用哈希存补数；看到"出现次数 Top K"想到计数 + 堆/桶；看到"原地找缺失/重复"想到把值当下标做原地哈希。

## 题型速查

| 子类型 | 核心手法 | 代表题 |
|---|---|---|
| 计数聚合 | Map 统计频率再按需筛选 | C-061 C-067 C-077 C-078 C-079 |
| 存在性/去重 | Set 或 Map 记录是否出现 | C-062 C-063 C-064 C-071 C-072 |
| 补数配对 | 哈希存 target - x，一次遍历配对 | C-066 |
| 原地哈希 | 把值当下标打标记，O(1) 空间 | C-069 C-070 |
| 设计类 | 数组 + 链地址法/桶 | C-075 C-076 |
| 映射/状态 | 双射（一一对应）校验 | C-065 C-073 C-074 |
| 前缀和 + 哈希 | 把"子数组和"转成"两前缀之差" | C-080 |

### C-061 字母异位词分组 · 中等 · 字节/阿里/腾讯

**题干**：给你一个字符串数组 `strs`，请你将**字母异位词**组合在一起。可以按任意顺序返回结果列表。字母异位词指由重新排列源单词的所有字母得到的新单词（字母种类与数量完全相同）。

**示例**：`输入: strs = ["eat","tea","tan","ate","nat","bat"]` → `输出: [["bat"],["nat","tan"],["ate","eat","tea"]]`

**思路**：
- 暴力：两两比较是否为异位词，O(n²·k)，且难以归组。
- 最优：核心是给每个单词算一个**与排列无关的指纹 key**，异位词的 key 必然相同。两种做法：① 把单词排序后的字符串当 key，O(k log k)；② 用长度 26 的计数数组编码成 `"1#0#2#..."` 当 key，O(k)。再用 `Map<key, string[]>` 聚合。总时间 O(n·k log k) 或 O(n·k)。

**代码**：
```javascript
function groupAnagrams(strs) {
  const map = new Map();
  for (const s of strs) {
    // 计数指纹：用 # 分隔避免 "1""11" 这类歧义
    const cnt = new Array(26).fill(0);
    for (const ch of s) cnt[ch.charCodeAt(0) - 97]++;
    const key = cnt.join('#');
    if (!map.has(key)) map.set(key, []);
    map.get(key).push(s);
  }
  return [...map.values()];
}

console.log(groupAnagrams(["eat", "tea", "tan", "ate", "nat", "bat"]));
// [["eat","tea","ate"],["tan","nat"],["bat"]]（顺序可能不同）
console.log(groupAnagrams([""]));   // [[""]]
console.log(groupAnagrams(["a"]));  // [["a"]]
```

**复杂度**：时间 O(n·k)（计数法，k 为单词最大长度），空间 O(n·k)。

**易错点**：
- 计数 key 必须用分隔符拼接，直接 `join('')` 会让 `[1,1,0]` 与 `[11,0,0]` 撞 key。
- 空字符串也要能成组，`""` 的计数 key 全 0，需正常处理。
- 排序法在 k 很大时较慢，但实现最短，面试可先讲排序法再优化。
- 返回的是二维数组，不是 Map。
- 排序法里字符串 sort 默认按字典序，无需传比较函数，这点与数字排序不同。

**变体与追问**：
- 找到所有字母异位词（LC 438）：定长滑窗 + 计数比较。
- 若字符集不止小写字母：改用 `Map<char,count>` 再把键排序后编码。
- 若要求组内也按字典序输出：聚合后对每组排序。

### C-062 存在重复元素 · 简单 · 字节

**题干**：给你一个整数数组 `nums`。如果任一值在数组中出现**至少两次**，返回 `true`；如果数组中每个元素互不相同，返回 `false`。

**示例**：`输入: nums = [1,2,3,1]` → `输出: true`

**思路**：
- 暴力：两两比较，O(n²)。
- 最优：**Set 去重**。遍历数组，若元素已在 Set 中说明重复，立即返回 true；否则加入。一次遍历即可，O(n) 时间、O(n) 空间。另一种思路是先排序再比较相邻元素，O(n log n) 时间、O(1) 额外空间——面试常被追问"如何省空间"时给出。两种是典型的"时间换空间 / 空间换时间"取舍。

**代码**：
```javascript
// 解法一：Set，O(n) 时间
function containsDuplicate(nums) {
  const seen = new Set();
  for (const x of nums) {
    if (seen.has(x)) return true; // 已出现
    seen.add(x);
  }
  return false;
}

// 解法二：排序后看相邻，O(n log n) 时间、O(1) 额外空间
function containsDuplicateSort(nums) {
  const a = nums.slice().sort((x, y) => x - y); // 不改原数组
  for (let i = 1; i < a.length; i++) {
    if (a[i] === a[i - 1]) return true;
  }
  return false;
}

console.log(containsDuplicate([1, 2, 3, 1]));      // true
console.log(containsDuplicate([1, 2, 3, 4]));      // false
console.log(containsDuplicateSort([1, 1, 1, 3, 3, 4, 3, 2, 4, 2])); // true
```

**复杂度**：解法一 O(n) / O(n)；解法二 O(n log n) / O(1)。

**易错点**：
- 空数组、单元素数组返回 false，循环自然覆盖。
- Set 用 SameValueZero 判等，`NaN` 能被正确判重（`NaN !== NaN` 但 Set 视为同一值）。
- 解法二用 `slice()` 避免修改入参；若不介意可原地排序。
- JS 默认 `sort()` 按字符串比较，必须传比较函数。
- 本题是哈希存在性判断的最小样板，后面的 219（限制下标差）和 220（限制值差）都是在它之上叠加约束，这两题值得一起记。

**变体与追问**：
- 存在重复元素 II（LC 219）：要求下标差 ≤ k，需记录最近下标。
- 存在重复元素 III（LC 220）：要求值差 ≤ t 且下标差 ≤ k，用有序集合/桶。
- 若数组值域很小且固定：可用位图或计数数组把空间降到 O(值域)。

### C-063 存在重复元素 II · 简单 · 字节/美团

**题干**：给你一个整数数组 `nums` 和一个整数 `k`，判断数组中是否存在**两个不同的下标** `i` 和 `j`，满足 `nums[i] === nums[j]` 且 `abs(i - j) <= k`。

**示例**：`输入: nums = [1,2,3,1], k = 3` → `输出: true`（下标 0 和 3，差 3）

**思路**：
- 暴力：对每个 i 向后检查 k 个元素，O(n·k)。
- 最优：**哈希存"最近一次出现的下标"**。遍历时若当前值已出现过，且 `i - lastIndex <= k` 即命中；否则把下标更新为当前 `i`。为什么更新而不是保留旧下标？因为下标越小、与未来元素的差值越大，越难满足 ≤ k，保留最新的下标对后续判定最有利。O(n) 时间、O(n) 空间。

**代码**：
```javascript
function containsNearbyDuplicate(nums, k) {
  const last = new Map(); // 值 -> 最近一次出现的下标
  for (let i = 0; i < nums.length; i++) {
    const x = nums[i];
    if (last.has(x) && i - last.get(x) <= k) {
      return true;          // 距离满足条件
    }
    last.set(x, i);         // 更新为最新下标（贪心）
  }
  return false;
}

console.log(containsNearbyDuplicate([1, 2, 3, 1], 3)); // true
console.log(containsNearbyDuplicate([1, 0, 1, 1], 1)); // true
console.log(containsNearbyDuplicate([1, 2, 3, 1, 2, 3], 2)); // false
```

**复杂度**：时间 O(n)，空间 O(min(n, 值域))。

**易错点**：
- 条件是 `<= k` 而不是 `< k`。
- 未命中时必须**更新**下标，否则后续更近的重复会漏判。
- `k = 0` 时任何两个不同下标差都 ≥ 1，恒为 false（逻辑自然成立）。
- 也可用大小为 k+1 的滑动窗口 Set，超窗口就删最旧元素。
- Map 里存的是下标而不是布尔值，这是与 217 最本质的区别；若 k 大于等于数组长度，本题直接退化为 217，此时用 Set 就够了，不必再记下标，这就是本题的简化思路。

**变体与追问**：
- 存在重复元素（LC 217）：k 视为无穷大，Set 即可。
- 存在重复元素 III（LC 220）：值差也要受限，需桶排序或有序结构。
- 若要求返回具体下标对：命中时返回 `[last.get(x), i]`。

### C-064 最长连续序列 · 中等 · 字节/腾讯

**题干**：给定一个**未排序**的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。请设计并实现时间复杂度为 **O(n)** 的算法。

**示例**：`输入: nums = [100,4,200,1,3,2]` → `输出: 4`（最长连续序列为 [1,2,3,4]）

**思路**：
- 暴力：对每个数都向后数 x+1、x+2……，最坏 O(n²)（如 1..n 的排列）。
- 最优：先把所有数放进 **Set**，然后只从**序列起点**开始数。判定起点的方法：若 `x-1` 不在 Set 中，则 x 一定是某段连续序列的开头；此时才循环检查 `x+1, x+2...` 是否存在并计数。这样每个数最多作为"起点"被数一次、作为"延伸"被访问一次，总 O(n) 时间、O(n) 空间。剪枝是达到 O(n) 的关键。

**代码**：
```javascript
function longestConsecutive(nums) {
  const set = new Set(nums);
  let best = 0;

  for (const x of set) {
    // 只有序列起点（x-1 不存在）才展开计数，避免重复扫描
    if (set.has(x - 1)) continue;
    let cur = x;
    let len = 1;
    while (set.has(cur + 1)) {
      cur++;
      len++;
    }
    best = Math.max(best, len);
  }
  return best;
}

console.log(longestConsecutive([100, 4, 200, 1, 3, 2])); // 4
console.log(longestConsecutive([0, 3, 7, 2, 5, 8, 4, 6, 0, 1])); // 9
console.log(longestConsecutive([])); // 0
```

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：
- 少了 `set.has(x-1)` 剪枝就退化为 O(n²)，这是本题的得分核心。
- 遍历 `set` 而非原数组，重复元素天然去重。
- 空数组返回 0。
- 计数初始为 1（x 自身），别从 0 开始。
- 返回值是长度而非序列本身；只有一个元素时应返回 1，空数组返回 0。

**变体与追问**：
- 最长递增子序列（LC 300）：子序列不要求连续，需 DP/贪心+二分，O(n log n)。
- 若要求返回具体序列而非长度：记录起点与长度，最后还原。
- 若数字范围很小：可用布尔数组标记后线性扫描，O(值域)。

### C-065 快乐数 · 简单 · 字节/阿里

**题干**：编写一个算法判断一个数 `n` 是否为**快乐数**。快乐数定义为：对一个正整数，每次将它替换为各位数字的**平方和**，重复这个过程直到变为 1（此时是快乐数），或陷入无限循环且始终变不到 1。

**示例**：`输入: n = 19` → `输出: true`（19→82→68→100→1）

**思路**：
- 暴力：不断算平方和，但不设终止条件会死循环。
- 最优：用 **Set 记录出现过的数**。每轮算平方和，若结果为 1 返回 true；若结果已在 Set 中，说明进入环、永远到不了 1，返回 false；否则加入集合并继续。因为平方和会快速收敛到小范围（三位数以上很快降到三位以内），循环次数是 O(log n) 级别。也可用**快慢指针**判环，把空间降到 O(1)。

**代码**：
```javascript
function isHappy(n) {
  const seen = new Set();
  while (n !== 1) {
    if (seen.has(n)) return false; // 进入循环
    seen.add(n);
    n = digitSquareSum(n);
  }
  return true;
}

function digitSquareSum(n) {
  let sum = 0;
  while (n > 0) {
    const d = n % 10;
    sum += d * d;
    n = Math.floor(n / 10);
  }
  return sum;
}

console.log(isHappy(19)); // true
console.log(isHappy(2));  // false
console.log(isHappy(1));  // true

// 快慢指针版（O(1) 空间）
function isHappyFast(n) {
  let slow = n;
  let fast = digitSquareSum(n);
  while (fast !== 1 && slow !== fast) {
    slow = digitSquareSum(slow);
    fast = digitSquareSum(digitSquareSum(fast));
  }
  return fast === 1;
}
console.log(isHappyFast(19)); // true
```

**复杂度**：时间 O(log n)，空间 O(log n)（Set）；快慢指针版空间 O(1)。

**易错点**：
- 没有环检测会死循环，这是本题唯一陷阱。
- `n % 10` 与 `Math.floor(n / 10)` 拆位，注意 n 可能为 0 的循环条件。
- 1 本身是快乐数，`while (n !== 1)` 直接跳过循环返回 true。
- 快慢指针版判断的是 `fast === 1`，不是 `slow === 1`。

**变体与追问**：
- 判断链表是否有环（LC 141/142）：同样的快慢指针思想。
- 若把"平方和"换成"立方和"：结论不同，但判环方法通用。
- 数学优化：所有不快乐数最终都会落入含 4 的环，可据此硬编码提前返回。

### C-066 四数相加 II · 中等 · 字节

**题干**：给你四个整数数组 `nums1`、`nums2`、`nums3`、`nums4`，长度都是 `n`。请你计算有多少个元组 `(i, j, k, l)` 能满足 `nums1[i] + nums2[j] + nums3[k] + nums4[l] === 0`。

**示例**：`输入: nums1=[1,2], nums2=[-2,-1], nums3=[-1,2], nums4=[0,2]` → `输出: 2`

**思路**：
- 暴力：四重循环枚举所有组合，O(n⁴)，n=200 时就 16 亿次，必超时。
- 最优：**分组 + 哈希**。把四个数组两两配对：先枚举 `nums1[i]+nums2[j]` 的所有和，用 Map 记录每个和出现的次数；再枚举 `nums3[k]+nums4[l]` 的和 `s`，在 Map 中查 `-s` 的次数并累加。这样把 O(n⁴) 降到 O(n²) 时间、O(n²) 空间。分成 2+2 而非 1+3 是为了让两半的规模对称、总枚举量最小。

**代码**：
```javascript
function fourSumCount(nums1, nums2, nums3, nums4) {
  const map = new Map(); // 前两数组所有两两之和 -> 出现次数
  for (const a of nums1) {
    for (const b of nums2) {
      const sum = a + b;
      map.set(sum, (map.get(sum) || 0) + 1);
    }
  }

  let count = 0;
  for (const c of nums3) {
    for (const d of nums4) {
      const need = -(c + d); // 后两数之和的相反数
      if (map.has(need)) count += map.get(need); // 累加组合次数
    }
  }
  return count;
}

console.log(fourSumCount([1, 2], [-2, -1], [-1, 2], [0, 2])); // 2
console.log(fourSumCount([0], [0], [0], [0]));               // 1
console.log(fourSumCount([1], [-1], [0], [0]));              // 1
```

**复杂度**：时间 O(n²)，空间 O(n²)。

**易错点**：
- 必须用 Map **计数**而非 Set，同一个和可能出现多次，每次都是不同元组。
- 累加的是 `map.get(need)` 而非 1。
- 结果可能超过 2³¹，JS Number 在 n ≤ 200 时安全（最大 1.6e9），但若 n 更大需注意精度。
- 不要试图排序后用双指针，四个数组相互独立，哈希分组才是正解。
- 统计的是元组个数而非不同的和，所以哈希表存的必须是出现次数而不是布尔标记；若四个数组长度不等，需按各自长度分别枚举，不能假设都为 n；另外结果可能超出 32 位整数范围。

**变体与追问**：
- 两数之和（LC 1）：哈希存补数，O(n)。
- 四数之和（LC 18）：同一数组内选四个数且去重，排序 + 双指针更合适。
- 若要求返回具体元组：Map 存"和 -> 下标对列表"，再拼接。

### C-067 前 K 个高频元素 · 中等 · 字节/腾讯

**题干**：给你一个整数数组 `nums` 和一个整数 `k`，请你返回其中出现频率**前 k 高**的元素。你可以按**任意顺序**返回答案。

**示例**：`输入: nums = [1,1,1,2,2,3], k = 2` → `输出: [1,2]`

**思路**：
- 暴力：统计频率后按频率全排序，O(n log n)。
- 次优：维护大小为 k 的**小顶堆**，O(n log k)，适合 n 极大、k 很小的流式场景。
- 最优（本题）：**桶排序**。频率最大不超过 n，建 n+1 个桶，`bucket[f]` 存所有频率为 f 的元素；再从高频桶往低频桶收集，凑满 k 个即止。统计 O(n)、装桶 O(n)、收集 O(n)，整体 O(n) 时间、O(n) 空间。

**代码**：
```javascript
function topKFrequent(nums, k) {
  const freq = new Map(); // 值 -> 频率
  for (const x of nums) freq.set(x, (freq.get(x) || 0) + 1);

  // 桶：下标为频率，最多 n 种频率
  const buckets = Array.from({ length: nums.length + 1 }, () => []);
  for (const [val, f] of freq) buckets[f].push(val);

  const res = [];
  for (let f = buckets.length - 1; f >= 1 && res.length < k; f--) {
    for (const val of buckets[f]) {
      res.push(val);
      if (res.length === k) break;
    }
  }
  return res;
}

console.log(topKFrequent([1, 1, 1, 2, 2, 3], 2)); // [1,2]
console.log(topKFrequent([1], 1));               // [1]
console.log(topKFrequent([4, 4, 4, 5, 5, 6], 2)); // [4,5]
```

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：
- 桶数组长度应为 `n + 1`（频率从 1 到 n），下标 0 空置。
- 收集时外层从高到低、内层逐个取，凑满 k 立即停。
- 不能用"值"做桶下标，要用"频率"。
- 返回顺序任意，无需再排序。
- 桶排序的隐含前提是频率为 1 到 n 的整数、正好可当下标，这也是它比比较排序更快的原因；若 k 大于不同元素个数，循环条件保证不会越界，返回全部即可，这也是面试常追问的取舍点。

**变体与追问**：
- 若数据是**流式**、内存受限：用小顶堆维护 k 个，O(n log k)、O(k) 空间。
- 按频率排序输出全部元素（LC 451）：桶排序后按频率降序拼接。
- 若 k 接近不同元素总数：直接全排序反而更简单。

### C-068 摩尔投票求众数 · 简单 · 字节/阿里

**题干**：给定一个大小为 `n` 的数组 `nums`，返回其中的**多数元素**。多数元素指在数组中出现的次数**大于 ⌊n/2⌋** 的元素。可以假设数组非空，且给定的数组总是存在多数元素。

**示例**：`输入: nums = [3,2,3]` → `输出: 3`

**思路**：
- 暴力：双重循环统计每个元素出现次数，O(n²)；或用哈希计数，O(n) 时间但 O(n) 空间。
- 最优：**摩尔投票（Boyer-Moore）**。维护候选人 `cand` 与票数 `count`：遍历时若 `count === 0` 就把当前元素设为候选人；若当前元素等于候选人则 `count++`，否则 `count--`。原理是"不同元素两两抵消"，由于多数元素出现次数过半，抵消到最后剩下的候选人必然是它。O(n) 时间、O(1) 空间，是该题的最优解。

**代码**：
```javascript
function majorityElement(nums) {
  let cand = null;
  let count = 0;
  for (const x of nums) {
    if (count === 0) {
      cand = x;      // 票数耗尽，换候选人
      count = 1;
    } else if (x === cand) {
      count++;       // 同阵营，票数 +1
    } else {
      count--;       // 不同阵营，抵消一票
    }
  }
  return cand;
}

console.log(majorityElement([3, 2, 3]));             // 3
console.log(majorityElement([2, 2, 1, 1, 1, 2, 2])); // 2
console.log(majorityElement([1]));                   // 1
```

**复杂度**：时间 O(n)，空间 O(1)。

**易错点**：
- 摩尔投票只在"多数元素保证存在"时才可直接返回候选人；否则需第二遍遍历验证其出现次数是否 > n/2。
- `count === 0` 时必须同时把 `count` 置 1，否则下一轮又会重置。
- 候选人初值无所谓，靠第一轮赋值。
- 返回的是元素值，不是下标或次数。

**变体与追问**：
- 求出现次数超过 n/3 的元素（LC 229）：最多两个候选人，用两组 cand/count 同时投票。
- 若要求返回出现次数：投票得到候选人后再遍历计数。
- 该思想也用于"找出数组中唯一出现奇数次的数"（配合异或）。

### C-069 找到所有数组中消失的数字 · 简单 · 字节/美团

**题干**：给你一个含 `n` 个整数的数组 `nums`，其中 `nums[i]` 在区间 `[1, n]` 内。请你找出所有在 `[1, n]` 范围内但**没有出现**在 `nums` 中的数字，以数组形式返回。要求时间 O(n)、额外空间 O(1)（不计返回数组）。

**示例**：`输入: nums = [4,3,2,7,8,2,3,1]` → `输出: [5,6]`

**思路**：
- 暴力：用 Set 记录出现过的数，再遍历 1..n 找缺失，O(n) 时间但 O(n) 空间。
- 最优：**原地哈希（值当下标）**。遍历数组，把值 `v` 对应的下标 `|v|-1` 处的元素**取负**作为"已出现"标记。第二轮遍历，若下标 `i` 处仍为正，说明数字 `i+1` 从未被标记，即缺失。标记时用 `Math.abs` 防止值已被翻负导致下标为负。O(n) 时间、O(1) 额外空间。

**代码**：
```javascript
function findDisappearedNumbers(nums) {
  const n = nums.length;
  // 第一轮：把出现过的值 v 对应的下标 v-1 标记为负
  for (let i = 0; i < n; i++) {
    const idx = Math.abs(nums[i]) - 1;
    if (nums[idx] > 0) nums[idx] = -nums[idx];
  }
  // 第二轮：仍为正的位置 i 说明数字 i+1 没出现过
  const res = [];
  for (let i = 0; i < n; i++) {
    if (nums[i] > 0) res.push(i + 1);
  }
  return res;
}

console.log(findDisappearedNumbers([4, 3, 2, 7, 8, 2, 3, 1])); // [5,6]
console.log(findDisappearedNumbers([1, 1]));                   // [2]
console.log(findDisappearedNumbers([2, 2]));                    // [1]
```

**复杂度**：时间 O(n)，空间 O(1)（不计返回数组）。

**易错点**：
- 取下标前务必 `Math.abs`，因为该位置可能已被前序元素标记为负。
- 重复出现的值（如 2 出现两次）第二次标记时 `nums[idx]` 已是负，需用 `if` 跳过，否则会翻回正数。
- 返回的是 `i + 1`，不是 `i`。
- 题目保证值域在 `[1, n]`，否则原地哈希不成立。

**变体与追问**：
- 数组中重复的数据（LC 442）：反过来，若目标位置已为负说明该值重复。
- 找到所有重复和缺失的数（LC 645）：一次遍历同时判断。
- 若不允许修改原数组：用 Set 或"求和/平方和"数学法，但后者可能溢出。

### C-070 数组中重复的数据 · 中等 · 字节

**题干**：给你一个长度为 `n` 的整数数组 `nums`，其中 `nums` 的所有整数都在范围 `[1, n]` 内，且每个整数**出现一次或两次**。请你找出所有出现**两次**的整数，以数组形式返回。要求时间 O(n)、额外空间 O(1)。

**示例**：`输入: nums = [4,3,2,7,8,2,3,1]` → `输出: [2,3]`

**思路**：
- 暴力：哈希计数，O(n) 时间但 O(n) 空间。
- 最优：**原地哈希取负标记**。遍历数组，把值 `v = |nums[i]|` 映射到下标 `idx = v - 1`：若 `nums[idx] > 0` 说明是第一次遇到 v，把该位置取负作为"已访问"标记；若 `nums[idx] < 0` 说明 v 之前已经出现过一次，这次是第二次，把 v 加入结果。整个过程只改符号、不破坏值域，O(n) 时间、O(1) 额外空间。

**代码**：
```javascript
function findDuplicates(nums) {
  const res = [];
  for (let i = 0; i < nums.length; i++) {
    const idx = Math.abs(nums[i]) - 1; // 值映射到下标
    if (nums[idx] > 0) {
      nums[idx] = -nums[idx];          // 第一次出现，打标记
    } else {
      res.push(idx + 1);               // 已标记过，说明重复
    }
  }
  return res;
}

console.log(findDuplicates([4, 3, 2, 7, 8, 2, 3, 1])); // [2,3]
console.log(findDuplicates([1, 1, 2]));                // [1]
console.log(findDuplicates([1, 2, 3]));                // []
```

**复杂度**：时间 O(n)，空间 O(1)（不计返回数组）。

**易错点**：
- 必须用 `Math.abs` 取原值，因为 `nums[i]` 可能已经被前面的元素改成负数。
- 判断用 `nums[idx] > 0`（未标记）还是 `< 0`（已标记），别写反。
- 每个数最多出现两次，所以不会出现"第三次"导致重复加入结果。
- 返回顺序任意，题目不要求有序。

**变体与追问**：
- 找到所有消失的数字（LC 448）：第二轮扫描仍为正的位置即为缺失。
- 只允许出现一次、找出唯一的重复数（LC 287）：可用快慢指针（值域当作链表）。
- 若值域不是 `[1, n]`：原地哈希失效，退回哈希表或排序。

### C-071 两个数组的交集 · 简单 · 字节

**题干**：给定两个数组 `nums1` 和 `nums2`，返回它们的**交集**。输出结果中的每个元素一定是**唯一**的，且可以按任意顺序返回。

**示例**：`输入: nums1 = [1,2,2,1], nums2 = [2,2]` → `输出: [2]`

**思路**：
- 暴力：双层循环判断 nums1 中每个元素是否出现在 nums2，O(n·m)，还要额外去重。
- 最优：**Set 去重 + 查找**。先把 `nums1` 所有元素放进 Set，再遍历 `nums2`，若元素在 Set 中则加入结果集。结果用 Set 保证唯一。每个元素被访问常数次，O(n + m) 时间、O(n + m) 空间。因为"唯一"是硬性要求，Set 天然满足。

**代码**：
```javascript
function intersection(nums1, nums2) {
  const set1 = new Set(nums1);   // 去重并支持 O(1) 查找
  const res = new Set();
  for (const x of nums2) {
    if (set1.has(x)) res.add(x); // 结果 Set 自动去重
  }
  return [...res];
}

console.log(intersection([1, 2, 2, 1], [2, 2]));       // [2]
console.log(intersection([4, 9, 5], [9, 4, 9, 8, 4])); // [9,4] 或 [4,9]
console.log(intersection([1, 2], [3, 4]));             // []
```

**复杂度**：时间 O(n + m)，空间 O(n + m)。

**易错点**：
- 结果必须**去重**，直接 push 会得到 `[2,2]`。
- 应该用较小的数组建 Set 以节省空间（可先比较两数组长度交换）。
- 返回类型是数组，需 `[...res]` 展开。
- 空数组交集为空，逻辑自然成立。
- Set 的 has 是平均 O(1)，所以整体线性；若改用数组的 includes，每次查找 O(m) 会让整体退化成 O(n·m)，这正是选对数据结构的关键；若某个数组为空，自然返回空结果，不会抛出异常。

**变体与追问**：
- 两个数组的交集 II（LC 350）：允许重复，次数取两数组中的较小值，需计数。
- 若数组已排序：可用双指针 O(1) 额外空间，且结果有序。
- 若要求"交集且保持 nums1 中的相对顺序"：遍历 nums1 判断是否在 nums2 的 Set 中。

### C-072 两个数组的交集 II · 简单 · 阿里/美团

**题干**：给你两个整数数组 `nums1` 和 `nums2`，请你以数组形式返回两数组的**交集**。返回结果中每个元素出现的次数，应与元素在**两个数组中都出现的次数一致**（即取两者出现次数的较小值）。可以按任意顺序返回。

**示例**：`输入: nums1 = [1,2,2,1], nums2 = [2,2]` → `输出: [2,2]`

**思路**：
- 暴力：对 nums1 每个元素在 nums2 中找并删除，O(n·m)。
- 最优：**计数哈希**。先统计较短数组的每个元素出现次数（Map），再遍历另一个数组，若当前元素计数 > 0 就收集一个并把计数减 1（减到 0 时删除，可选）。这样每个交集元素最多被收集"较小次数"次。O(n + m) 时间、O(min(n, m)) 空间。若数组已排序，也可用双指针，O(1) 额外空间但需先排序。

**代码**：
```javascript
function intersect(nums1, nums2) {
  // 用较短数组建计数表，节省空间
  if (nums1.length > nums2.length) [nums1, nums2] = [nums2, nums1];

  const cnt = new Map();
  for (const x of nums1) cnt.set(x, (cnt.get(x) || 0) + 1);

  const res = [];
  for (const x of nums2) {
    const c = cnt.get(x) || 0;
    if (c > 0) {
      res.push(x);          // 收集一次
      cnt.set(x, c - 1);    // 消耗一次计数
    }
  }
  return res;
}

console.log(intersect([1, 2, 2, 1], [2, 2]));       // [2,2]
console.log(intersect([4, 9, 5], [9, 4, 9, 8, 4])); // [4,9] 或 [9,4]
console.log(intersect([1, 2], [3, 4]));             // []
```

**复杂度**：时间 O(n + m)，空间 O(min(n, m))。

**易错点**：
- 是"取较小出现次数"，不能像 LC 349 那样去重。
- 每收集一次必须把计数减 1，否则会多收。
- 用较短数组建表可降低空间；交换时注意后续遍历对象也随之改变。
- 返回结果顺序任意，无需排序。

**变体与追问**：
- 两个数组的交集（LC 349）：元素唯一，用 Set。
- 若 nums2 极大、内存受限（nums2 在磁盘上）：用 nums1 的计数表流式扫描 nums2。
- 若要求结果有序：可用双指针法，先排序再同步推进。

### C-073 单词规律 · 简单 · 字节/快手

**题干**：给定一种规律 `pattern` 和一个字符串 `s`，判断 `s` 是否遵循相同的规律。这里的"遵循"指**完全匹配**：`pattern` 中的每个字母与 `s` 中的每个非空单词之间存在**双射**（一一对应）关系。

**示例**：`输入: pattern = "abba", s = "dog cat cat dog"` → `输出: true`

**思路**：
- 暴力：尝试建立映射再逐对校验，但只建单向映射会漏判。
- 最优：**双向映射（双射）校验**。用两个 Map：`p2w` 记录 pattern 字母 → 单词，`w2p` 记录单词 → pattern 字母。遍历时若任一方向出现不一致（同一字母对应不同单词，或同一单词对应不同字母）立即 false。另外单词数量必须等于 pattern 长度。O(n) 时间。只做单向映射会放过 "abba" 对 "dog dog dog dog" 这种反例。

**代码**：
```javascript
function wordPattern(pattern, s) {
  const words = s.split(' ');           // 按空格切分单词
  if (words.length !== pattern.length) return false;

  const p2w = new Map(); // 字母 -> 单词
  const w2p = new Map(); // 单词 -> 字母
  for (let i = 0; i < pattern.length; i++) {
    const p = pattern[i];
    const w = words[i];
    // 双向冲突检测
    if (p2w.has(p) && p2w.get(p) !== w) return false;
    if (w2p.has(w) && w2p.get(w) !== p) return false;
    p2w.set(p, w);
    w2p.set(w, p);
  }
  return true;
}

console.log(wordPattern("abba", "dog cat cat dog")); // true
console.log(wordPattern("abba", "dog cat cat fish")); // false
console.log(wordPattern("aaaa", "dog cat cat dog")); // false
console.log(wordPattern("abba", "dog dog dog dog")); // false
```

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：
- 必须**双向**映射，单向会漏掉"多对一"的非法情况。
- 单词数必须等于 pattern 长度，否则直接 false。
- `s.split(' ')` 对连续空格会产生空串，题目通常保证单空格分隔，面试可追问。
- 空格分隔的是"单词"，不是字符。
- pattern 与 s 的单词数不一致时应直接返回 false，这一步能省掉后面所有比较。

**变体与追问**：
- 同构字符串（LC 205）：字符对字符的双射，逻辑完全一致。
- 若 pattern 可能含多字符"符号"（如 "abc" vs "a,b,c"）：先拆分 pattern。
- 若要求忽略大小写：映射前统一 `toLowerCase`。

### C-074 有效的数独 · 中等 · 字节/腾讯

**题干**：请你判断一个 `9 x 9` 的数独是否有效。只需根据以下规则验证已经填入的数字是否有效即可：① 每一行包含数字 `1-9` 且不重复；② 每一列包含数字 `1-9` 且不重复；③ 每个粗实线分隔的 `3 x 3` 宫格内包含数字 `1-9` 且不重复。空白格用 `'.'` 表示。注意：有效数独不一定是可解的。

**示例**：`输入: board = [["5","3",".",...], ...]` → `输出: true`

**思路**：
- 暴力：分别检查每行、每列、每宫，逻辑重复且易错。
- 最优：**一次遍历 + 三组 Set**。为 9 行、9 列、9 个宫各维护一个 Set。遍历每个格子，若为 `'.'` 跳过，否则计算它所属的宫索引 `box = Math.floor(i/3)*3 + Math.floor(j/3)`，若数字已在对应行/列/宫的 Set 中出现则返回 false，否则加入。O(81) 时间、O(81) 空间。行索引 `i`、列索引 `j`、宫索引 `box` 三者一次性校验，简洁且不易漏。

**代码**：
```javascript
function isValidSudoku(board) {
  const rows = Array.from({ length: 9 }, () => new Set());
  const cols = Array.from({ length: 9 }, () => new Set());
  const boxes = Array.from({ length: 9 }, () => new Set());

  for (let i = 0; i < 9; i++) {
    for (let j = 0; j < 9; j++) {
      const v = board[i][j];
      if (v === '.') continue;
      const box = Math.floor(i / 3) * 3 + Math.floor(j / 3);
      if (rows[i].has(v) || cols[j].has(v) || boxes[box].has(v)) {
        return false; // 行/列/宫任一重复即无效
      }
      rows[i].add(v);
      cols[j].add(v);
      boxes[box].add(v);
    }
  }
  return true;
}

const board = [
  ["5","3",".",".","7",".",".",".","."],
  ["6",".",".","1","9","5",".",".","."],
  [".","9","8",".",".",".",".","6","."],
  ["8",".",".",".","6",".",".",".","3"],
  ["4",".",".","8",".","3",".",".","1"],
  ["7",".",".",".","2",".",".",".","6"],
  [".","6",".",".",".",".","2","8","."],
  [".",".",".","4","1","9",".",".","5"],
  [".",".",".",".","8",".",".","7","9"],
];
console.log(isValidSudoku(board)); // true
```

**复杂度**：时间 O(81) 即 O(1)，空间 O(81) 即 O(1)。

**易错点**：
- 宫索引公式 `Math.floor(i/3)*3 + Math.floor(j/3)` 要记牢，容易写成 `i*3+j` 等错误形式。
- `'.'` 必须跳过，不能当成数字。
- 只需验证"已填数字不冲突"，不必求解数独。
- 判断重复应在 `add` 之前，先查后加。
- 三组 Set 必须在同一次遍历中同步维护，分三次遍历虽然也对，但代码更长且更容易漏。

**变体与追问**：
- 解数独（LC 37）：回溯 + 三组 Set 剪枝，是本题的升级版。
- 若棋盘尺寸为 n×n、宫为 √n×√n：把 3 换成 `Math.sqrt(n)` 泛化。
- 用位运算（9 位掩码）替代 Set，可把空间进一步压缩到整数。

### C-075 设计哈希集合 · 简单 · 字节

**题干**：不使用任何内建的哈希表库，设计并实现一个 `MyHashSet` 类，支持：`add(key)` 向集合插入值；`remove(key)` 从集合移除值（若不存在则忽略）；`contains(key)` 返回集合中是否存在该值。`key` 范围是 `[0, 10^6]`。

**示例**：`add(1); add(2); contains(1)` → `true`；`contains(3)` → `false`

**思路**：
- 暴力：直接用一个长度 10⁶+1 的布尔数组，空间 1MB，简单可行但面试想考"哈希设计"。
- 最优：**数组 + 链地址法**。取一个质数作为桶数量（如 769 或 1009），`hash = key % BUCKETS`，每个桶是一个数组（链表）。`add` 时若桶内没有则 push；`remove` 时找到下标 `splice`；`contains` 用 `includes`。平均 O(1)，最坏 O(n/BUCKETS)。用质数做模数能让 key 分布更均匀，减少冲突。

**代码**：
```javascript
class MyHashSet {
  constructor() {
    this.BUCKETS = 769; // 质数，分布更均匀
    this.data = Array.from({ length: this.BUCKETS }, () => []);
  }

  _hash(key) {
    return key % this.BUCKETS;
  }

  add(key) {
    const bucket = this.data[this._hash(key)];
    if (!bucket.includes(key)) bucket.push(key);
  }

  remove(key) {
    const bucket = this.data[this._hash(key)];
    const idx = bucket.indexOf(key);
    if (idx !== -1) bucket.splice(idx, 1);
  }

  contains(key) {
    return this.data[this._hash(key)].includes(key);
  }
}

const set = new MyHashSet();
set.add(1);
set.add(2);
console.log(set.contains(1)); // true
console.log(set.contains(3)); // false
set.remove(1);
console.log(set.contains(1)); // false
```

**复杂度**：平均时间 O(1)，空间 O(n + BUCKETS)。

**易错点**：
- 必须处理**哈希冲突**，不能假设一个 key 独占一个桶。
- `remove` 前要先 `indexOf` 判断存在，`splice(-1,1)` 会误删末尾元素。
- 桶数选质数能改善分布；选得太小冲突多、太大浪费空间。
- JS 的 `key % BUCKETS` 对非负整数安全（题目 key ≥ 0）。
- 若 key 范围已知且不大，直接开布尔数组在工程上更快；这题考的是哈希设计思路而非必须最优。

**变体与追问**：
- 设计哈希映射（LC 706）：桶内存 `[key, value]` 键值对，需要额外实现 get/put。
- 若 key 范围很小：直接用布尔数组更快更省事，需说明取舍。
- 开放寻址法：冲突时线性探测下一个空位，缓存更友好但删除需要墓碑标记。

### C-076 设计哈希映射 · 简单 · 字节

**题干**：不使用任何内建的哈希表库，设计并实现一个 `MyHashMap` 类，支持：`put(key, value)` 向映射插入键值对，若 key 已存在则更新其值；`get(key)` 返回 key 对应的 value，不存在返回 `-1`；`remove(key)` 移除 key 及其对应值。`key` 与 `value` 范围均为 `[0, 10^6]`。

**示例**：`put(1,1); put(2,2); get(1)` → `1`；`get(3)` → `-1`；`remove(2); get(2)` → `-1`

**思路**：
- 暴力：用长度 10⁶+1 的数组直接寻址，简单但面试意在考"哈希设计"。
- 最优：**数组 + 链地址法**。选质数 769 作桶数，`hash = key % 769`，每个桶是**键值对数组** `[key, value]`。`put` 时先在桶内查找 key：找到就更新 value，否则 push 新对；`get` 找到返回 value，否则 -1；`remove` 找到则 `splice` 删除。平均 O(1)。与哈希集合的唯一区别是桶内存的是键值对而非单值，需要按 key 匹配。

**代码**：
```javascript
class MyHashMap {
  constructor() {
    this.BUCKETS = 769;
    this.data = Array.from({ length: this.BUCKETS }, () => []); // 每桶存 [key, value]
  }
  _hash(key) { return key % this.BUCKETS; }
  put(key, value) {
    const bucket = this.data[this._hash(key)];
    const pair = bucket.find((p) => p[0] === key);
    if (pair) pair[1] = value;        // 已存在则更新
    else bucket.push([key, value]);   // 不存在则插入
  }
  get(key) {
    const pair = this.data[this._hash(key)].find((p) => p[0] === key);
    return pair ? pair[1] : -1;       // 不存在返回 -1
  }
  remove(key) {
    const bucket = this.data[this._hash(key)];
    const idx = bucket.findIndex((p) => p[0] === key);
    if (idx !== -1) bucket.splice(idx, 1);
  }
}
// 测试
const m = new MyHashMap();
m.put(1, 1); m.put(2, 2);
console.log(m.get(1), m.get(3));   // 1 -1
m.put(2, 1);                       // 更新
console.log(m.get(2));             // 1
m.remove(2);
console.log(m.get(2));             // -1
```

**复杂度**：平均时间 O(1)，空间 O(n + BUCKETS)。

**易错点**：
- 不存在必须返回 `-1`，而不是 `undefined` 或 `null`。
- value 可能是 `0`，遍历时不能用 `if (pair[1])` 这种假值判断，要按键匹配。
- `put` 对已存在的 key 是**更新**而非重复插入，否则 get 可能取到旧值。
- `remove` 必须按键找下标再删，不能按值。
- put 的更新语义要基于引用修改或整体替换，绝不能对同一个 key 重复 push 出两份。

**变体与追问**：
- 设计哈希集合（LC 705）：桶内存单值，逻辑更简单。
- 若 key 范围极小：直接用数组，O(1) 且常数更小，但空间换时间。
- 若要求线程安全/并发：需加锁或分段锁，桶数即分段粒度。

### C-077 猜数字游戏 · 中等 · 字节/腾讯

**题干**：你在和朋友玩猜数字游戏（Bulls and Cows）。你写下一个秘密数字 `secret`，朋友猜了一个数字 `guess`。返回对朋友猜测的提示，格式为 `"xAyB"`：`A` 表示**数字和位置都猜对**的个数（bulls），`B` 表示**数字猜对但位置不对**的个数（cows）。

**示例**：`输入: secret = "1807", guess = "7810"` → `输出: "1A3B"`

**思路**：
- 暴力：对每个位置统计 bulls，再对每位在剩余位置里找 cows，需删除已配对，O(n²) 且易错。
- 最优：**一次遍历 + 计数数组**。第一遍：位置相同则 bulls++；否则分别把 secret 和 guess 该位数字计数到两个长度 10 的数组。统计完后，对每个数字 d，`cows += min(cntSecret[d], cntGuess[d])`——因为位置相同的已排除，剩下的只要两边都出现就能配对，取较小次数即可。O(n) 时间、O(1) 空间（10 个计数桶）。

**代码**：
```javascript
function getHint(secret, guess) {
  const cntS = new Array(10).fill(0);
  const cntG = new Array(10).fill(0);
  let bulls = 0;

  for (let i = 0; i < secret.length; i++) {
    const s = secret[i];
    const g = guess[i];
    if (s === g) {
      bulls++;                 // 位置 + 数字都对
    } else {
      cntS[+s]++;              // 只统计"位置不对"的数字
      cntG[+g]++;
    }
  }

  let cows = 0;
  for (let d = 0; d < 10; d++) {
    cows += Math.min(cntS[d], cntG[d]); // 两边都出现的数字配对
  }
  return `${bulls}A${cows}B`;
}

console.log(getHint("1807", "7810")); // "1A3B"
console.log(getHint("1123", "0111")); // "1A1B"
console.log(getHint("1", "0"));       // "0A0B"
console.log(getHint("11", "11"));     // "2A0B"
```

**复杂度**：时间 O(n)，空间 O(1)（固定 10 个桶）。

**易错点**：
- 位置相同的数字**不能**再计入 cows，所以要在 `else` 分支才计数。
- 返回格式是字符串 `"xAyB"`，不是数组或对象。
- `+s` 把字符转数字，注意别写成 `s - 0` 这种可读性差的写法（也行）。
- secret 与 guess 长度相同（题目保证），无需额外校验。

**变体与追问**：
- 若允许长度不同：先补齐或按较短截断，需明确规则。
- 若要求返回具体匹配位置：额外记录下标。
- 计数思想也可用于"找差异字符"（如 LC 389 找不同）。

### C-078 最常见的单词 · 简单 · 字节

**题干**：给定一个段落 `paragraph` 和一个禁用单词列表 `banned`，返回出现次数**最多**且**不在禁用列表**中的单词。题目保证至少有一个单词不在禁用列表中，且答案唯一。单词**不区分大小写**，答案返回**小写**形式，标点符号不计入单词。

**示例**：`输入: paragraph = "Bob hit a ball, the hit BALL flew far after it was hit.", banned = ["hit"]` → `输出: "ball"`

**思路**：
- 暴力：遍历每个单词，每次都在全文里数出现次数，O(n²)。
- 最优：**正则提取 + 计数**。先把段落转小写，用 `/[a-z]+/g` 提取所有单词（自动忽略标点和空格），`banned` 放进 Set 便于 O(1) 判断，再用 Map 统计非禁用词的出现次数，最后遍历取最大。O(n) 时间、O(单词种类数) 空间。用正则而非 `split(' ')` 是因为标点会粘在单词上（如 "ball,"）。

**代码**：
```javascript
function mostCommonWord(paragraph, banned) {
  const bannedSet = new Set(banned.map((w) => w.toLowerCase()));
  const words = paragraph.toLowerCase().match(/[a-z]+/g) || [];
  const cnt = new Map();

  let best = '';
  let bestCount = 0;
  for (const w of words) {
    if (bannedSet.has(w)) continue; // 跳过禁用词
    const c = (cnt.get(w) || 0) + 1;
    cnt.set(w, c);
    if (c > bestCount) {
      bestCount = c;
      best = w;
    }
  }
  return best;
}

console.log(
  mostCommonWord("Bob hit a ball, the hit BALL flew far after it was hit.", ["hit"])
); // "ball"
console.log(mostCommonWord("a, a, a, b, b, b, c", [])); // "a"（计数相同取先达到的）
```

**复杂度**：时间 O(n)，空间 O(k)（k 为不同单词数）。

**易错点**：
- 必须先用正则提取，`split(' ')` 会保留 "ball," 这种带标点的脏词。
- `paragraph.toLowerCase()` 后再匹配，否则大写字母会被 `[a-z]` 漏掉。
- `banned` 也要转小写再比较。
- 返回值是小写字符串，不是出现次数。
- `match` 可能返回 `null`（全无字母时），需兜底 `|| []`。

**变体与追问**：
- 若并列最多要求返回字典序最小：比较时加 `c === bestCount && w < best`。
- 若禁用列表很大：用 Set 是正确选择，避免线性扫描。
- 若段落是流式输入：维护计数与当前最优，O(1) 内存无法做到，仍需 Map。

### C-079 子域名访问计数 · 中等 · 字节/阿里

**题干**：网站域名 `domain` 由"子域名"和"父域名"组成，形如 `"discuss.leetcode.com"`。给你一个访问计数数组 `cpdomains`，其中每条格式为 `"count domain"`。请统计每个域名（**包括所有父域名**）的**总访问次数**，以 `"count domain"` 形式的数组返回。

**示例**：`输入: ["9001 discuss.leetcode.com"]` → `输出: ["9001 leetcode.com","9001 discuss.leetcode.com","9001 com"]`

**思路**：
- 暴力：对每条记录枚举所有子串组合再匹配，容易漏层级。
- 最优：**按点切分 + 逐级累加**。对每条记录，`split(' ')` 得到次数与完整域名；把域名按 `.` 切分成标签数组，从完整域名开始，每次**去掉最左边的标签**得到下一级父域名，一路累加到 Map。例如 `a.b.c` 依次处理 `a.b.c`、`b.c`、`c`。每条记录的处理代价与其域名长度成正比，总 O(总字符数)。

**代码**：
```javascript
function subdomainVisits(cpdomains) {
  const cnt = new Map(); // 域名 -> 总访问次数

  for (const item of cpdomains) {
    const [numStr, domain] = item.split(' ');
    const count = Number(numStr);
    const parts = domain.split('.'); // ["discuss","leetcode","com"]

    // 从完整域名开始，逐级去掉最左标签
    for (let i = 0; i < parts.length; i++) {
      const sub = parts.slice(i).join('.');
      cnt.set(sub, (cnt.get(sub) || 0) + count);
    }
  }

  const res = [];
  for (const [domain, c] of cnt) {
    res.push(`${c} ${domain}`);
  }
  return res;
}

console.log(subdomainVisits(["9001 discuss.leetcode.com"]));
// ["9001 discuss.leetcode.com","9001 leetcode.com","9001 com"]（顺序任意）

console.log(subdomainVisits([
  "900 google.mail.com",
  "50 yahoo.com",
  "1 intel.mail.com",
  "5 wiki.org",
])); // 含 "901 mail.com"、"951 com" 等
```

**复杂度**：时间 O(总字符数 × 域名层级)，空间 O(不同域名数)。

**易错点**：
- 每一条记录的**所有后缀**都要累加，不能只记完整域名。
- 输出格式是 `"count domain"`，中间一个空格，别写反。
- `parts.slice(i).join('.')` 生成的是从第 i 个标签到末尾的域名，i 从 0 开始遍历全部层级。
- 同一条记录里不同层级都要加同一个 count，不要累加错。

**变体与追问**：
- 若域名标签非常多：逐级拼接是 O(L²)，可改为从右往左增量构造字符串。
- 若要求结果按访问次数降序：收集后排序。
- 类似"统计文件路径各层级大小"，思路完全一致。

### C-080 连续数组 · 中等 · 字节/腾讯

**题干**：给定一个二进制数组 `nums`，找到含有**相同数量 0 和 1** 的最长连续子数组，并返回该子数组的长度。

**示例**：`输入: nums = [0,1]` → `输出: 2`；`输入: nums = [0,1,0]` → `输出: 2`

**思路**：
- 暴力：枚举所有子数组统计 0/1 个数，O(n²)。
- 最优：**把 0 视为 -1**，问题等价于"求和为 0 的最长连续子数组"。用**前缀和 + 哈希表存首次出现下标**：遍历时累加 `sum`（遇到 1 加 1，遇到 0 减 1），若 `sum` 之前出现过，说明两次出现之间的子数组和为 0，长度为 `i - first[sum]`；否则记录当前下标为首次出现。初始化 `map.set(0, -1)` 处理从下标 0 开始的子数组。O(n) 时间、O(n) 空间。

**代码**：
```javascript
function findMaxLength(nums) {
  const first = new Map(); // 前缀和 -> 首次出现的下标
  first.set(0, -1);        // 空前缀，处理从头开始的子数组
  let sum = 0;
  let best = 0;

  for (let i = 0; i < nums.length; i++) {
    sum += nums[i] === 1 ? 1 : -1; // 1 记 +1，0 记 -1
    if (first.has(sum)) {
      best = Math.max(best, i - first.get(sum)); // 同一前缀和之间差为 0
    } else {
      first.set(sum, i);      // 只记录首次出现，才能得到最长
    }
  }
  return best;
}

console.log(findMaxLength([0, 1]));       // 2
console.log(findMaxLength([0, 1, 0]));    // 2
console.log(findMaxLength([0, 1, 1, 0, 1, 1, 0, 0])); // 8
```

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：
- 必须预置 `first.set(0, -1)`，否则从头开始就平衡的子数组会被漏掉。
- 只记录**首次**出现：后面再遇到同一前缀和时**不能覆盖**，覆盖会缩短长度。
- 0 映射成 -1 是关键转化，直接数 0/1 个数会退化为 O(n²)。
- 返回长度，不是子数组本身或起止下标。
- 哈希表在这里的作用是 O(1) 查询某个前缀和上次出现在哪，从而把 O(n²) 的枚举降为一次扫描。

**变体与追问**：
- 和为目标值的最长子数组（含负数）：前缀和 + 哈希，逻辑完全一样。
- 元素 0/1 的最长连续 1（允许翻转 k 个 0）：滑动窗口更直接。
- 若数组元素是 1 和 2：映射成 +1/-1 同样可解。
