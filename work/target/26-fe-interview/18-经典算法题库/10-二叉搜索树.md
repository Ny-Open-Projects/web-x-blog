# 10 二叉搜索树（C-181 ~ C-200）

> BST 题在大厂笔试里几乎是"送分题中的陷阱题"：思路人人都会，栽在**边界与不变量**上。**识别特征**：看到"第 k 小 / 有序输出 / 前驱后继 / 两值比较"就想**中序遍历**；看到"验证、插入、删除、修剪"就想**上下界约束**；看到"计数种数"就想**卡特兰数**。

## 题型速查

| 子类型 | 核心手法 | 代表题 |
|---|---|---|
| 性质验证与维护 | 传上下界（而非只比父节点），递归重挂接 | C-181、C-183、C-184 |
| 有序性检索 | 按值大小单边下降，O(h) | C-182、C-191、C-192 |
| 中序即有序 | 中序序列相邻比较 / 反中序累加 / 计数众数 | C-185 ~ C-187、C-190、C-200 |
| 有序结构重建 | 中序序列 + 二分取中点保证平衡 | C-188、C-189、C-199 |
| 计数与构造 | 卡特兰数 DP、区间递归枚举 | C-193、C-194 |
| 子树裁剪与区间统计 | 越界则整体丢弃，界内累加 | C-195、C-196 |
| 由遍历序列构造 | 前序 + 上界递归切分；区间最大值作根 | C-197、C-198 |

### C-181 验证二叉搜索树 · 中等 · 字节/阿里

**题干**：给你一个二叉树的根节点 `root`，判断其是否是一个有效的二叉搜索树（BST）。定义：节点的左子树只包含**严格小于**当前节点的数；右子树只包含**严格大于**当前节点的数；左右子树自身也必须是 BST。

**示例**：`输入: root = [2,1,3]` → `输出: true`；`输入: root = [5,1,4,null,null,3,6]` → `输出: false`（4 在根的右侧却小于 5）

**思路**：
- 最常见的错解是"只比较节点与左右孩子"：它只能保证局部有序，管不了远层。隐蔽的反例是 `[5,4,6,null,null,3,7]`——3 是 6 的左孩子（3 < 6，局部合法），但它位于根 5 的右侧却比 5 小，全局非法。
- 正确做法是传**允许区间** `[low, high]`：进入左子树时把上界收紧为当前值，进入右子树时把下界收紧为当前值。约束沿祖先链继承，每个节点都同时受所有祖先的约束。
- 等价写法是"中序遍历必须严格递增"，记录前驱即可，代码更短；但面试先讲上下界，因为它直接回答了"为什么不能只比父亲"。
- 关键洞察：BST 的性质是**全局**的（所有左子树节点都小于根），而"父与子"只是它的必要条件。凡是"全局约束"，就必须用参数把约束往下传。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var isValidBST = function (root, low = -Infinity, high = Infinity) {
  if (!root) return true;
  // 必须严格落在开区间内
  if (root.val <= low || root.val >= high) return false;
  return (
    isValidBST(root.left, low, root.val) &&      // 左子树上界收紧
    isValidBST(root.right, root.val, high)       // 右子树下界收紧
  );
};
```

**复杂度**：时间 O(n)，每个节点访问一次 ／ 空间 O(h)，递归栈深度；中序写法可做到 O(1) 额外空间（Morris）

**易错点**：
- 只比较父子节点（`root.left.val < root.val`），远层祖先的约束丢失。
- 把边界初始化为 `-2**31` / `2**31-1`，节点值恰好等于边界时被误判为非法，应用 `±Infinity`。
- 用 `<` / `>` 还是 `<=` / `>=` 要看题意：本题要求严格不等，重复值即非法。
- 中序写法里 `prev` 初始化为 0 或 -1，节点全为负时首项比较出错。

**变体与追问**：
- 若允许重复值（左 ≤ 根 < 右），把左子树上界判断改成 `<=`。
- 若问"最多交换几次能修复"，先中序找出逆序对：一对相邻交换 or 两对（LC 99）。

### C-182 二叉搜索树中的搜索 · 简单 · 字节/腾讯

**题干**：给定二叉搜索树（BST）的根节点 `root` 和一个整数值 `val`，在 BST 中找到节点值等于 `val` 的节点，返回以该节点为根的**子树**；若不存在则返回 `null`。

**示例**：`输入: root = [4,2,7,1,3], val = 2` → `输出: [2,1,3]`；`val = 5` → `输出: null`

**思路**：
- BST 的有序性意味着"每一步都能排除一半的子树"：`val < root.val` 时右子树全体更大，不可能命中，只需往左；反之往右；相等即命中。
- 迭代写法的额外空间是 O(1)，不依赖递归栈，面试里更稳（不会因链状树爆栈）。递归写法则是 O(h)。
- 注意返回的是**节点**而不是节点值——题目要求返回整棵子树，所以 `return root`。
- 关键洞察：普通二叉树查找必须"两边都试"，BST 只需单边下降。这正是"有序性 = 剪枝"的最小例子，也是所有 BST 检索题（找前驱、找最近值、范围查询）的共同骨架。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var searchBST = function (root, val) {
  while (root) {
    if (root.val === val) return root;          // 命中，返回子树根
    root = val < root.val ? root.left : root.right;
  }
  return null;                                  // 走到空即不存在
};

// 递归写法：语义更贴近"在子树里找"，代价是 O(h) 的调用栈
var searchBSTRecursive = function (root, val) {
  if (!root || root.val === val) return root;
  return val < root.val
    ? searchBSTRecursive(root.left, val)
    : searchBSTRecursive(root.right, val);
};
```

**复杂度**：时间平均 O(log n)，最坏 O(n)（退化成链）／ 空间 O(1)

**易错点**：
- `return root.val` 而不是 `return root`，题目要的是子树。
- 循环里用 `if/else if` 却忘了更新 `root`，造成死循环。
- 递归版本里在 `root === null` 时访问 `root.val`，空指针报错。
- 默认认为复杂度是 O(log n)——链状 BST 会退化到 O(n)，面试被追问时要主动说明。

**变体与追问**：
- 找"最接近 val 的值"：沿路径记录候选，最后比较左右两侧（LC 270）。
- 找前驱/后继：一路记下"最后一个小于/大于 val 的祖先"。

### C-183 二叉搜索树中的插入操作 · 中等 · 美团/阿里

**题干**：给定二叉搜索树的根节点 `root` 和要插入树中的值 `val`，将值插入 BST 并返回插入后的根节点。输入数据保证新值与树中任意节点值都不同，答案可以返回任意合法的插入结果。

**示例**：`输入: root = [4,2,7,1,3], val = 5` → `输出: [4,2,7,1,3,5]`（5 挂在 7 的左孩子或 3 的右孩子都对）

**思路**：
- 插入位置是**唯一且必然存在**的：一路比较，遇到空位就挂上去。因为新值与已有值不同，最终一定落在某个空孩子上，不会卡在中间。
- 递归写法用返回值重新挂接：`root.left = insertIntoBST(root.left, val)`。这样"根为空就新建节点"这一句基准情形天然完成了挂接。
- 迭代写法需要额外保存 parent，再判断挂在左还是右，代码更长。面试首选递归，但要能口述迭代版。
- 关键洞察：新节点永远是叶子，所以插入不需要旋转就能保持 BST 性质——这也是"结构变化最小"的含义。追问平衡时就说：这正是 AVL / 红黑树要解决的问题。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var insertIntoBST = function (root, val) {
  if (!root) return new TreeNode(val);        // 找到空位，新建节点
  if (val < root.val) {
    root.left = insertIntoBST(root.left, val);   // 必须重新挂接
  } else {
    root.right = insertIntoBST(root.right, val);
  }
  return root;
};
```

**复杂度**：时间 O(h)，平均 O(log n)，最坏 O(n) ／ 空间 O(h)

**易错点**：
- 递归调用却忘了 `root.left = ...` 赋值，节点被创建但没有挂到树上。
- 空树时直接返回 `null`，忘记 `return new TreeNode(val)`。
- 以为插入会保持平衡——重复插入有序序列会退化成链表。
- 遇到相等值时随意覆盖，破坏"值唯一"的约定。

**变体与追问**：
- 迭代版：用 `parent` 一路下降，最后按大小挂在 `parent` 的左右。
- 若允许重复值，可加一个 `count` 字段；若要求插入后仍平衡，就是 AVL 的旋转插入。

### C-184 删除二叉搜索树中的节点 · 中等 · 字节/腾讯

**题干**：给定一个二叉搜索树的根节点 `root` 和一个值 `key`，删除 BST 中 `key` 对应的节点，并保证 BST 的性质不变，返回新的根节点。节点值唯一。

**示例**：`输入: root = [5,3,6,2,4,null,7], key = 3` → `输出: [5,4,6,2,null,null,7]`；`key = 0` → 原树不变

**思路**：
- 先按值定位，再分三种情况：**无左孩子** → 用右孩子顶替（叶子也走这条，右孩子为空即删除）；**无右孩子** → 用左孩子顶替；**两个孩子都有** → 找右子树中的最小节点（中序后继），把它的值复制过来，再去右子树里删掉那个后继。
- 为什么选右子树最小？它是"比当前节点大的所有值中最小的"，替换后左子树仍全小于它、右子树其余节点全大于它，BST 性质自动保持。用左子树最大值（前驱）同样成立。
- 判断顺序很重要：两个单孩子分支必须先写，最后才处理"双孩子"，否则叶子会被漏判。
- 关键洞察：删除的难点只在"双孩子"这一种情况，而它被转化成"删除一个最多只有一个孩子的节点"——递归保证问题规模下降，整体仍是 O(h)。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var deleteNode = function (root, key) {
  if (!root) return null;
  if (key < root.val) {
    root.left = deleteNode(root.left, key);
  } else if (key > root.val) {
    root.right = deleteNode(root.right, key);
  } else {
    if (!root.left) return root.right;      // 含叶子：右孩子即结果
    if (!root.right) return root.left;
    let succ = root.right;                  // 找中序后继
    while (succ.left) succ = succ.left;
    root.val = succ.val;                    // 值覆盖
    root.right = deleteNode(root.right, succ.val);  // 删掉后继
  }
  return root;
};
```

**复杂度**：时间 O(h)，平均 O(log n)，最坏 O(n) ／ 空间 O(h)

**易错点**：
- 双孩子时直接把 `root.right` 接上来，整棵左子树被丢弃。
- 替换值后忘记删除后继，树上出现两个相同值，破坏唯一性。
- 递归分支忘记重新挂接（`root.left = ...`），删除不生效。
- 删除根节点时返回了 `null` 或旧根，导致调用方拿到错误的树。

**变体与追问**：
- 改用左子树最大值（前驱）替代，代码对称。
- 若支持重复值，节点需带计数，删除时先减计数再决定是否真删。
- 追问"如何保证删除后仍平衡"→ AVL 删除需要沿路径回溯做旋转。

### C-185 二叉搜索树的最小绝对差 · 简单 · 快手/美团

**题干**：给你一棵二叉搜索树的根节点 `root`，返回树中**任意两不同节点值**之间的最小差值（绝对差）。节点数至少为 2。

**示例**：`输入: root = [4,2,6,1,3]` → `输出: 1`；`输入: root = [1,0,48,null,null,12,49]` → `输出: 1`

**思路**：
- BST 的中序遍历结果严格递增，因此"任意两节点的最小差"必然出现在**相邻两项**之间：跳过至少一个元素的差值，等于若干正差之和，一定不小于其中最小的那个。这个性质把 O(n²) 的暴力比较直接降到 O(n)。
- 实现只需一个变量记住"上一个访问的节点值"，中序访问到当前节点时用 `node.val - prev` 更新答案，然后更新 prev。
- prev 用 `null` 表示"还没有前驱"，不要用 0 或 -1——节点值可能为负，占位值会污染第一次比较。
- 关键洞察：**中序有序是 BST 题目的总开关**。凡是涉及"大小比较、找第 k、找众数、转累加树"，都先想"转成有序序列会怎样"。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var getMinimumDifference = function (root) {
  let prev = null;                 // 中序前驱，用 null 表示"还没有"
  let ans = Infinity;
  const inorder = (node) => {
    if (!node) return;
    inorder(node.left);
    if (prev !== null) ans = Math.min(ans, node.val - prev);
    prev = node.val;               // 处理完才更新前驱
    inorder(node.right);
  };
  inorder(root);
  return ans;
};
```

**复杂度**：时间 O(n) ／ 空间 O(h)，递归栈深度（可用 Morris 中序降到 O(1)）

**易错点**：
- 用两两比较的暴力 O(n²)，虽然能过，但面试会被追问"BST 有什么用"。
- `prev` 初始化为 0，若最小值节点为负数，第一次差值算错。
- 先更新 `prev` 再比较，差值恒为 0。
- 以为最小差一定在"父子之间"，反例是 `[1,null,2]` 的中序相邻项恰好是祖先关系——本质还是相邻项，但不要误以为是父子关系。

**变体与追问**：
- 求"任意两节点的最大差"：直接取中序首尾之差（最大值 - 最小值）。
- 若树不是 BST，就只能排序或 O(n²) 暴力，正说明有序性才是关键。

### C-186 二叉搜索树中第 K 小的元素 · 中等 · 字节/阿里

**题干**：给定一个二叉搜索树的根节点 `root` 和一个整数 `k`，请设计算法查找其中**第 k 个最小**的元素（从 1 开始计数）。树中节点数为 n，保证 `1 ≤ k ≤ n`。

**示例**：`输入: root = [3,1,4,null,2], k = 1` → `输出: 1`；`输入: root = [5,3,6,2,4,null,null,1], k = 3` → `输出: 3`

**思路**：
- BST 的中序遍历天然升序，所以"第 k 小"就是"中序访问到的第 k 个节点"。这个结论是本类题的地基。
- 递归中序无法真正提前退出（必须先走完左子树才能判断），而用**显式栈**模拟中序可以：一路向左压栈，弹出时计数，减到 0 立刻返回，右子树都不用进。
- 复杂度因此是 O(h + k) 而不是 O(n)：k 小时明显更快，这是面试官想听到的优化点。
- 关键洞察：BST 的"有序性"让你可以只在需要的那部分路径上花时间。凡是问"第 k 小 / 找前驱后继 / 范围查询"，都应该问自己"能不能不遍历全树"。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var kthSmallest = function (root, k) {
  const stack = [];
  let node = root;
  while (node || stack.length) {
    while (node) {                 // 一路向左，压入路径
      stack.push(node);
      node = node.left;
    }
    node = stack.pop();            // 当前最小
    if (--k === 0) return node.val;
    node = node.right;             // 转向右子树
  }
  return -1;
};
```

**复杂度**：时间 O(h + k)，h 为树高 ／ 空间 O(h)，栈的最大深度

**易错点**：
- 用 `if (k-- === 0)` 之类的写法，判断顺序错导致差一位。
- 一路向左时忘了 `node = node.left` 的更新。
- 先收集整个中序数组再取 `arr[k-1]`，复杂度 O(n)，被追问时答不上"怎么优化"。
- k 从 0 开始计数（题目明确从 1 开始）。

**变体与追问**：
- 求"第 k 大"：把中序换成反中序（右 → 根 → 左），一行改动。
- 若树会频繁插入删除并要求第 k 小，给每个节点维护"子树节点数"，每次 O(h) 定位（面试高频 follow-up）。

### C-187 把二叉搜索树转换为累加树 · 中等 · 腾讯/美团

**题干**：给出二叉搜索树的根节点 `root`（节点值互不相同），将其转换为**累加树**：每个节点的新值等于原树中**大于或等于**该节点值的所有值之和。返回转换后的根节点。

**示例**：`输入: root = [4,1,6,0,2,5,7,null,null,null,3,null,null,null,8]` → `输出: [30,36,21,36,35,26,15,null,null,null,33,null,null,null,8]`

**思路**：
- 要的是"所有大于等于当前值的和"，也就是从**大到小**依次累加。BST 的中序是升序，那么反中序（右 → 根 → 左）就是降序。
- 维护一个 running sum：访问到某节点时先累加再赋值（`sum += val; node.val = sum`），因为自己也算在"大于等于"里。
- 原地修改即可，题目要求不改变结构。改完后仍满足 BST 性质，因为映射 `f(x) = 后缀和` 是单调递增的。
- 关键洞察：**"把中序反过来用"**是 BST 题的高频技巧（第 k 大、累加树、求众数变体）。看到"从大到小"就该条件反射地想到"右-根-左"。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var convertBST = function (root) {
  let sum = 0;                     // 已访问过的更大值之和
  const reverseInorder = (node) => {
    if (!node) return;
    reverseInorder(node.right);    // 先走更大的
    sum += node.val;
    node.val = sum;                // 原地改写
    reverseInorder(node.left);
  };
  reverseInorder(root);
  return root;
};
```

**复杂度**：时间 O(n)，每个节点访问一次 ／ 空间 O(h)，递归栈深度

**易错点**：
- 用普通中序（升序）累加，得到的是"小于等于之和"，方向完全相反。
- 先 `node.val = sum` 再 `sum += node.val`，当前节点被漏加。
- 新建节点返回新树，题目要求原地修改，且调用方拿到的还是旧根。
- 担心修改后破坏 BST 性质——值和结构是两回事，这里结构未变。

**变体与追问**：
- 若求"每个节点小于等于所有值之和"，改用正序中序累加，代码对称。
- 若求"每个节点的排名（第几小）"，中序计数即可；若树非 BST，只能先排序。

### C-188 将有序数组转换为二叉搜索树 · 简单 · 字节/美团

**题干**：给你一个整数数组 `nums`，元素已按**升序**排列。请将其转换为一棵**高度平衡**的二叉搜索树。高度平衡指每个节点的左右两个子树高度差的绝对值不超过 1。

**示例**：`输入: nums = [-10,-3,0,5,9]` → `输出: [0,-3,9,-10,null,5]`（或 `[0,-10,5,null,-3,null,9]`，均合法）

**思路**：
- BST 的中序序列就是有序数组，所以"数组 → 树"是这个关系的逆操作：取中点当根，左半段递归建左子树，右半段递归建右子树。
- 取中点保证左右元素个数最多相差 1，子树高度差自然 ≤ 1，平衡是**构造方式带来的**，不需要额外调整。
- 实现要点：传下标区间 `[lo, hi]` 而不是 `slice`，避免每层 O(n) 的数组拷贝，把复杂度从 O(n log n) 压到 O(n)。
- 关键洞察：中点的取法（偏左 / 偏右）会产生不同的合法答案，题目不要求唯一。面试时说明这一点，能体现对"答案不唯一"的敏感。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var sortedArrayToBST = function (nums) {
  const build = (lo, hi) => {
    if (lo > hi) return null;              // 区间为空
    const mid = (lo + hi) >> 1;            // 偏左取中点
    const node = new TreeNode(nums[mid]);
    node.left = build(lo, mid - 1);
    node.right = build(mid + 1, hi);
    return node;
  };
  return build(0, nums.length - 1);
};
```

**复杂度**：时间 O(n)，每个元素建一个节点 ／ 空间 O(log n)，递归栈深度（树高）

**易错点**：
- 用 `nums.slice(0, mid)` 递归，虽然正确但每层拷贝数组，复杂度退化到 O(n log n)。
- 基准条件写成 `lo >= hi`，漏掉叶子节点。
- `mid` 计算用 `(lo + hi) / 2` 得到小数，访问 `nums[2.5]` 为 undefined。
- 空数组没有返回 null，而是进入递归导致越界。

**变体与追问**：
- 输入换成有序链表（LC 109）→ 用快慢指针找中点，复杂度变 O(n log n)。
- 若要求构造**完全二叉树**，需要按完全二叉树的层序形状填值，而不是简单二分。

### C-189 有序链表转换二叉搜索树 · 中等 · 阿里/字节

**题干**：给定一个单链表的头节点 `head`，其中的元素按**升序**排序，将其转换为**高度平衡**的二叉搜索树。链表节点定义：`function ListNode(val, next)`。

**示例**：`输入: head = [-10,-3,0,5,9]` → `输出: [0,-3,9,-10,null,5]`

**思路**：
- 与 108 完全同构，唯一区别是"取中点"：链表无法随机访问，要用**快慢指针**——slow 走一步、fast 走两步，fast 到头时 slow 正好在中点。
- 找到中点后必须**断开**左半段（`prev.next = null`），否则左半段递归时仍然连着右半段，会导致重复建树甚至无限递归。
- 基准情形要单独处理"只有一个节点"，否则快慢指针在 `head.next === null` 时无法前进。
- 关键洞察：链表的"取中点"是 O(n)，而二分递归共 log n 层，所以总复杂度 O(n log n)；若先转数组可以做到 O(n)，代价是 O(n) 额外空间——这是典型的时空权衡。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var sortedListToBST = function (head) {
  if (!head) return null;
  if (!head.next) return new TreeNode(head.val);   // 单节点
  let slow = head, fast = head, prev = null;
  while (fast && fast.next) {                     // 快慢指针找中点
    prev = slow;
    slow = slow.next;
    fast = fast.next.next;
  }
  prev.next = null;                               // 断开左半段，必须
  const root = new TreeNode(slow.val);
  root.left = sortedListToBST(head);
  root.right = sortedListToBST(slow.next);
  return root;
};
```

**复杂度**：时间 O(n log n)，每层取中点 O(n)、共 O(log n) 层 ／ 空间 O(log n)，递归栈

**易错点**：
- 忘记 `prev.next = null`，左半段递归时仍包含右半段，死循环或结果重复。
- 漏掉单节点基准情形，`fast.next` 为 null 时 `fast.next.next` 报错。
- 把链表节点直接当树节点返回（缺少 left/right 字段），后续判题失败。
- 认为复杂度是 O(n)——取中点本身是 O(n)，这是与 108 最大的差别。

**变体与追问**：
- 先转数组再二分：时间 O(n)、空间 O(n)，面试可主动提出这个权衡。
- 若要 O(n) 时间且 O(log n) 空间，用"中序模拟建树"：先算长度，再按中序顺序边遍历链表边填节点（高频 follow-up）。

### C-190 恢复二叉搜索树 · 中等 · 字节/腾讯

**题干**：给你二叉搜索树的根节点 `root`，该树中**恰好有两个节点的值**被错误地交换。请在不改变树结构的情况下恢复这棵树（返回根节点即可，判题会检查整棵树）。

**示例**：`输入: root = [1,3,null,null,2]` → `输出: [3,1,null,null,2]`；`输入: root = [3,1,4,null,null,2]` → `输出: [2,1,4,null,null,3]`

**思路**：
- 正确 BST 的中序序列严格递增。交换两个值之后，中序序列里会出现 **1 处或 2 处**逆序，恢复就是找出这两个被交换的节点。
- 若被交换的两节点在中序里**相邻**，只有 1 处逆序 `a[i] > a[i+1]`，这两个就是答案。
- 若**不相邻**，会出现 2 处逆序：第一处的"前一个"是大值节点，最后一处的"后一个"是小值节点。
- 实现技巧：`first` 只在第一次逆序时记录（`prev`），`second` 每次逆序都覆盖（当前节点）。这样两种情况被统一：相邻时 first/second 恰好是一对；不相邻时 second 最终停在最后一处的后一个。
- 关键洞察：交换**值**而不是交换节点，既满足"不改变结构"，又避免指针重连的高风险操作。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var recoverTree = function (root) {
  let first = null, second = null, prev = null;
  const inorder = (node) => {
    if (!node) return;
    inorder(node.left);
    if (prev && prev.val > node.val) {
      if (!first) first = prev;      // 第一次逆序：记住大值
      second = node;                 // 每次逆序都覆盖 → 落到小值
    }
    prev = node;
    inorder(node.right);
  };
  inorder(root);
  const tmp = first.val;             // 只交换值，不动结构
  first.val = second.val;
  second.val = tmp;
  return root;
};
```

**复杂度**：时间 O(n) ／ 空间 O(h)，递归栈深度；Morris 中序可做到 O(1)

**易错点**：
- 只处理"两处逆序"却漏了"相邻交换只有一处"的情况，`first` 或 `second` 为 null。
- `second` 也写成"只在第一次记录"，不相邻时只修好一半。
- 真去交换节点指针，结构被改坏且容易丢子树。
- 中序存数组后排序回填：正确但 O(n) 空间，且没有利用"恰好两个节点"这一信息。

**变体与追问**：
- Morris 中序遍历可以做到 O(1) 空间，是本题的空间最优解（面试加分项）。
- 若问"最多交换几次能修复"，答案就是逆序对的数量级：1 处 → 1 次，2 处 → 1 次。

### C-191 二叉搜索树的最近公共祖先 · 中等 · 字节/腾讯

**题干**：给定一个**二叉搜索树**，找到该树中两个指定节点 `p`、`q` 的最近公共祖先。所有节点值唯一，`p`、`q` 为不同节点且均存在于树中。

**示例**：`输入: root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8` → `输出: 6`；`p = 2, q = 4` → `输出: 2`

**思路**：
- BST 的有序性直接告诉你"两个节点在不在同一侧"：若 `p`、`q` 都小于当前节点，LCA 必在左子树；都大于则在右子树；一旦不再"同侧"（一个在左一个在右，或其中之一就是当前节点），当前节点就是分叉点，即 LCA。
- 所以根本不需要后序遍历，也不需要"左右返回值都非空"的判断——那套是普通二叉树（236）的解法，在 BST 上是杀鸡用牛刀。
- 迭代实现即可，空间 O(1)：一路按值下降，命中分叉就返回。
- 关键洞察：**普通树的 LCA 靠"结构"判定，BST 的 LCA 靠"值域"判定**。这条差异是面试官最想听到的对比，也是把 236 与 235 一起问的原因。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var lowestCommonAncestor = function (root, p, q) {
  while (root) {
    if (p.val < root.val && q.val < root.val) {
      root = root.left;            // 都在左侧
    } else if (p.val > root.val && q.val > root.val) {
      root = root.right;           // 都在右侧
    } else {
      return root;                 // 分叉点（含其中一个是根）
    }
  }
  return root;
};
```

**复杂度**：时间 O(h)，平均 O(log n)，最坏 O(n) ／ 空间 O(1)

**易错点**：
- 判断条件用 `<=` / `>=`，当其中一个节点恰好等于当前节点时会错误地继续下降。
- 假设 `p.val < q.val` 并只比较 `q`，`p`、`q` 顺序不定时会出错。
- 递归版本忘记 `return`，函数返回 undefined。
- 把"分叉点"误认为"值介于 p、q 之间的最深节点"，忽略了"其中之一就是祖先"的情形。

**变体与追问**：
- 普通二叉树的 LCA 只能用后序返回值判断（LC 236），复杂度 O(n)，值得对照记忆。
- 求 p、q 之间的距离：先找 LCA，再算两段深度之和（边数）。

### C-192 二叉搜索树迭代器 · 中等 · 阿里/美团

**题干**：实现 `BSTIterator` 类表示按**中序遍历** BST 的迭代器：`BSTIterator(root)` 初始化；`next()` 返回中序的下一个数字；`hasNext()` 判断是否还有下一个。假设 `next()` 调用总是有效的。要求 `next()` 和 `hasNext()` 均摊 O(1) 时间、O(h) 内存。

**示例**：`输入: ["BSTIterator","next","next","hasNext","next","hasNext","next","hasNext","next","hasNext"]` + `[[[7,3,15,null,null,9,20]],[],[],[],[],[],[],[],[],[]]` → `[null,3,7,true,9,true,15,true,20,false]`

**思路**：
- 栈里存的正是"中序遍历接下来要访问的路径"：初始化时把根的整条**左链**压栈，栈顶就是整棵树的最小值。
- `next()` 弹出栈顶作为当前最小值，然后把它**右子树的整条左链**压栈——右子树的最小值成为新的栈顶，这就是中序的下一步。
- 每一步只展开一条左链，每个节点进出栈各一次，所以 n 次 `next()` 的总代价是 O(n)，**均摊 O(1)**；单次最坏 O(h)。
- 关键洞察：这是"用显式栈把递归中序拆成可暂停的步骤"的标准做法。凡是"惰性遍历 + 可中断"的需求（分页、流式处理），都是这个骨架。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var BSTIterator = function (root) {
  this.stack = [];
  this.pushLeft(root);                 // 栈顶即最小值
};
BSTIterator.prototype.pushLeft = function (node) {
  while (node) {
    this.stack.push(node);
    node = node.left;
  }
};
BSTIterator.prototype.next = function () {
  const node = this.stack.pop();       // 当前最小
  this.pushLeft(node.right);           // 展开右子树的左链
  return node.val;
};
BSTIterator.prototype.hasNext = function () {
  return this.stack.length > 0;
};
```

**复杂度**：`next()` 均摊 O(1)、单次最坏 O(h)；`hasNext()` O(1) ／ 空间 O(h)

**易错点**：
- `next()` 只弹栈不压右子树的左链，遍历到第一个叶子就结束。
- 构造函数只压入 `root` 一个节点，后续顺序全错。
- 在构造函数里一次性把全部节点展开成数组：时间 O(n)、空间 O(n)，属于"假迭代器"，面试会被追问。
- 用箭头函数定义 prototype 方法，`this` 指向丢失。

**变体与追问**：
- 反序迭代器（右 → 根 → 左）只需把 `pushLeft` 改成 `pushRight`。
- 若要支持 `prev()` 双向移动，仅靠栈不够，需要额外保存遍历路径或改用 Morris。

### C-193 不同的二叉搜索树 · 中等 · 腾讯/字节

**题干**：给你一个整数 `n`，求恰由 `n` 个节点组成、且节点值从 `1` 到 `n` 互不相同的**二叉搜索树有多少种**。返回种数（`n ≤ 19`）。

**示例**：`输入: n = 3` → `输出: 5`；`输入: n = 1` → `输出: 1`

**思路**：
- 枚举根节点：若根为 `i`，则左子树由 `1..i-1` 构成（共 `i-1` 个节点），右子树由 `i+1..n` 构成（共 `n-i` 个）。左右子树独立，用乘法原理。
- 所以 `dp[n] = Σ dp[i-1] × dp[n-i]`（i 从 1 到 n），这就是卡特兰数。
- 为什么状态只需要"节点个数"、不需要具体值？因为 BST 的结构与"1..n 的填法"一一对应：形状定了，中序递增的填法唯一。
- 关键洞察：`dp[0] = 1` 是空树算一种，否则整个乘法链全为 0。这个"空结构算一种"的约定，是所有计数型 DP 的地基（也是卡特兰数的定义起点）。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

// dp[i]：i 个节点能构成的 BST 种数（卡特兰数）
var numTrees = function (n) {
  const dp = new Array(n + 1).fill(0);
  dp[0] = 1;                            // 空树算 1 种，否则乘法全为 0
  dp[1] = 1;
  for (let i = 2; i <= n; i++) {
    for (let root = 1; root <= i; root++) {
      const left = root - 1;            // 左子树节点数
      const right = i - root;           // 右子树节点数
      dp[i] += dp[left] * dp[right];    // 左右独立，乘法原理
    }
  }
  return dp[n];
};
```

**复杂度**：时间 O(n²) ／ 空间 O(n)（可用卡特兰通项 O(n) 时间，但阶乘易溢出）

**易错点**：
- `dp[0]` 初始化为 0，所有结果都变成 0。
- 循环里把 `dp[i]` 写成 `dp[root]`，或索引错位（`dp[i-root]` 写成 `dp[i-root-1]`）。
- 把"种数"和"列出所有树"混淆——本题只要数量，95 才要输出结构。
- n 较大时用通项公式 `C(2n,n)/(n+1)`，中间阶乘超出安全整数范围。

**变体与追问**：
- 要求输出所有树：LC 95，递归返回根节点列表，复杂度与卡特兰数同阶。
- 若问"n 个节点的二叉树有多少种形状"（不要求 BST），答案同样是卡特兰数——因为形状与 BST 一一对应。

### C-194 不同的二叉搜索树 II · 中等 · 字节/阿里

**题干**：给你一个整数 `n`，请生成并返回所有由 `n` 个节点组成、且节点值从 `1` 到 `n` 互不相同的**不同二叉搜索树**。可以按任意顺序返回答案。

**示例**：`输入: n = 3` → `输出: [[1,null,2,null,3],[1,null,3,2],[2,1,3],[3,1,null,null,2],[3,2,null,1]]`

**思路**：
- 与 96 同一个枚举思路，只是把"计数"换成"列出"：递归函数 `build(lo, hi)` 返回"用 `[lo, hi]` 能构成的所有 BST 的根节点列表"。
- 枚举根 `i`，拿到左列表和右列表，做**笛卡尔积**：每个左 × 每个右 组合成一个新根 `new TreeNode(i, l, r)`。
- 基准情形：`lo > hi` 必须返回 `[null]` 而不是 `[]`。返回 `[]` 会让笛卡尔积变成空集，整棵树都构造不出来——这是本题最容易写错的一行。
- 关键洞察：每个组合都必须 `new TreeNode`，绝不能复用左右子树的引用。否则不同树共享同一棵子树，修改一棵会污染另一棵（判题时表现为结构错乱）。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var generateTrees = function (n) {
  const build = (lo, hi) => {
    if (lo > hi) return [null];           // 空区间返回 [null]，不是 []
    const res = [];
    for (let i = lo; i <= hi; i++) {
      for (const l of build(lo, i - 1)) {
        for (const r of build(i + 1, hi)) {
          res.push(new TreeNode(i, l, r));  // 每个组合新建节点
        }
      }
    }
    return res;
  };
  return n === 0 ? [] : build(1, n);
};
```

**复杂度**：时间 O(卡特兰数 × n)，空间 O(卡特兰数 × n)；n = 8 时已有 1430 棵树

**易错点**：
- `lo > hi` 返回 `[]`，导致所有组合消失（最常见的 bug）。
- 复用 `l`、`r` 的引用而不新建节点，不同树之间共享子树。
- 在循环外 `new TreeNode`，只得到一棵树。
- `n = 0` 时按题意应返回空数组，但递归内部仍需 `[null]`，两个语义要区分。

**变体与追问**：
- 只要数量 → 96 的 O(n²) 卡特兰 DP，不要生成结构。
- 若要求"所有结构不同的二叉树"（不要求 BST），递归时忽略值、只枚举形状即可。

### C-195 修剪二叉搜索树 · 中等 · 快手/美团

**题干**：给你二叉搜索树的根节点 `root`，同时给定最小边界 `low` 和最大边界 `high`。通过修剪使所有节点的值落在 `[low, high]` 内，且**不改变**保留节点之间的相对结构。返回结果树的根节点。

**示例**：`输入: root = [1,0,2], low = 1, high = 2` → `输出: [1,null,2]`；`输入: root = [3,0,4,null,2,null,null,1], low = 1, high = 3` → `输出: [3,2,null,1]`

**思路**：
- 利用 BST 的有序性做**整棵子树丢弃**：若 `root.val < low`，则 root 及其整个左子树都小于 low，全部不合法，直接返回修剪后的右子树即可。
- 同理 `root.val > high` 时，root 和整个右子树一起丢弃，只处理左子树。
- 界内的节点：递归修剪左右子树并重新挂接，返回 root。
- 关键洞察：普通二叉树必须遍历每个节点才能知道谁越界，BST 只要看根就能判断"一整片"是否越界——这就是有序性带来的剪枝能力，也是本题从 O(n) 变成 O(合法节点数) 的原因。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var trimBST = function (root, low, high) {
  if (!root) return null;
  // 小于下界：自身与整个左子树都非法，只保留修剪后的右子树
  if (root.val < low) return trimBST(root.right, low, high);
  // 大于上界：自身与整个右子树都非法
  if (root.val > high) return trimBST(root.left, low, high);
  // 界内：结构不变，只把左右子树修剪后挂回去
  root.left = trimBST(root.left, low, high);
  root.right = trimBST(root.right, low, high);
  return root;
};
```

**复杂度**：时间 O(n)，最坏需访问所有界内节点 ／ 空间 O(h)，递归栈深度

**易错点**：
- 越界时仍然递归两侧，结果正确但没有利用 BST 性质（面试会被追问"为什么能剪"）。
- 越界时返回 `root` 本身而不是修剪后的子树，越界节点仍留在树里。
- 以为需要重建树——其实只是"摘掉"，剩下的结构天然保持。
- 边界写成开区间（`< low` 用 `<=` 判断），`low`、`high` 本身被误删。

**变体与追问**：
- 求"区间内所有节点值之和"（LC 938）：同样的剪枝骨架，界内节点累加即可。
- 若树不是 BST，就只能逐个判断并删除，无法整片剪枝。

### C-196 二叉搜索树的范围和 · 简单 · 美团/快手

**题干**：给定二叉搜索树的根节点 `root`，返回值位于范围 `[low, high]` 之间的所有节点值的**和**。

**示例**：`输入: root = [10,5,15,3,7,null,18], low = 7, high = 15` → `输出: 32`（7 + 10 + 15）

**思路**：
- 朴素做法是遍历全部节点、逐个判断是否在区间内，O(n)。但 BST 能告诉你更多信息。
- 若 `root.val < low`，则 root 与整个左子树都更小，全部跳过，只需递归右子树；若 `root.val > high`，只需递归左子树；界内则累加自身并递归两侧。
- 这样每个越界分支都在一层被截断，最坏仍是 O(n)（全部节点都在界内），但平均远快于全遍历。
- 关键洞察：与 195 修剪是**同一个骨架**——"越界就整片丢弃"。区别只是修剪要删除、本题要累加。把这两题放在一起记，能覆盖"利用 BST 性质做区间筛选"的所有变体。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var rangeSumBST = function (root, low, high) {
  if (!root) return 0;
  if (root.val < low) return rangeSumBST(root.right, low, high);   // 左侧全废
  if (root.val > high) return rangeSumBST(root.left, low, high);   // 右侧全废
  return (
    root.val +
    rangeSumBST(root.left, low, high) +
    rangeSumBST(root.right, low, high)
  );
};
```

**复杂度**：时间 O(n) 最坏，实际 O(界内节点数 + h) ／ 空间 O(h)

**易错点**：
- 越界时仍然递归两侧：结果正确但完全没用到 BST，面试追问时无法解释优势。
- 边界判断漏掉等号，`low` / `high` 本身被排除（本题是闭区间）。
- 把"跳过整棵子树"写成"跳过节点本身"，越界节点仍被累加。
- 空树没有返回 0。

**变体与追问**：
- 求区间内节点的个数：同样骨架，把累加换成计数。
- 求区间内的最小/最大值：用"找前驱/后继"的思路可以做到 O(h)，不必遍历。

### C-197 前序遍历构造二叉搜索树 · 中等 · 字节/阿里

**题干**：给定一个整数数组 `preorder`，它表示某棵**二叉搜索树**的前序遍历结果。请重建这棵树并返回根节点。保证 `preorder` 中每个值都是唯一的。

**示例**：`输入: preorder = [8,5,1,7,10,12]` → `输出: [8,5,10,1,7,null,12]`

**思路**：
- 前序的第一个元素必是根。BST 的性质决定：紧跟其后的元素若小于根就去左子树，大于根就去右子树。
- 递归时传"上界 `bound`"：只要当前元素 `< bound` 就仍属于这棵子树，否则它属于更上层的右子树，立即返回 null 交给上层处理。
- 左子树递归时 `bound = node.val`（左子树所有值都小于当前根）；右子树递归时**继承父上界**（右子树的值只需大于根、小于父上界）。
- 关键洞察：如果只按"大于根就切到右子树"而不传上界，右侧递归会把父节点之后更大的值错误吞进自己的左子树。上界就是"隐式的有序性"，它替代了普通重建题里必须的中序数组——这是 O(n) 而非 O(n log n) 的原因。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var bstFromPreorder = function (preorder) {
  let i = 0;                                    // 闭包共享下标
  const build = (bound) => {
    if (i === preorder.length || preorder[i] > bound) return null;
    const node = new TreeNode(preorder[i++]);   // 先消耗当前值
    node.left = build(node.val);                // 左子树上界收紧
    node.right = build(bound);                  // 右子树继承上界
    return node;
  };
  return build(Infinity);
};
```

**复杂度**：时间 O(n)，每个元素只被消费一次 ／ 空间 O(h)，递归栈深度；最坏 O(n)

**易错点**：
- 右子树递归时把 `bound` 写成 `Infinity` 或 `node.val`，导致父子边界混乱、结构错乱。
- 下标 `i` 用参数按值传递，各分支各持一份，元素被重复消费。
- 判断写成 `preorder[i] >= bound`，遇到重复值（虽本题唯一）会误判。
- 空数组没有返回 null（`build` 的首个判断已覆盖，但要知道原因）。

**变体与追问**：
- 后序遍历构造 BST：从数组末尾往前扫，把"上界"换成"下界"。
- 前序 + 中序重建**普通**二叉树（LC 105）：需要中序定位切分点，时间 O(n)。
- 只判断"某数组是否是某 BST 的合法前序"：用一个单调递减栈即可 O(n)。

### C-198 最大二叉树 · 中等 · 腾讯/拼多多

**题干**：给定一个不重复的整数数组 `nums`。按如下规则递归构建**最大二叉树**：创建根节点，值为 `nums` 中的最大值；递归地在最大值**左边**的子数组上构建左子树；递归地在最大值**右边**的子数组上构建右子树。返回构建出的根节点。

**示例**：`输入: nums = [3,2,1,6,0,5]` → `输出: [6,3,5,null,2,0,null,null,1]`

**思路**：
- 直接翻译定义：区间 `[lo, hi]` 内找最大值下标作为根，左右子区间递归。代码几乎和定义一一对应，难点在复杂度。
- 每次线性扫描找最大值，最坏 O(n²)（数组单调时每次只切掉一个元素）。面试标准解法可以到此为止，但要能主动说出"用单调栈可以做到 O(n)"。
- 单调栈做法：维护一个**递减**栈，扫描到新元素时不断弹出比它小的栈顶，被弹出的最后一个成为新元素的左孩子；新元素再挂到当前栈顶的右孩子上。
- 关键洞察：本题本质是"笛卡尔树"——区间最值作为根的结构。它与 197 前序构造 BST 形似而神不同：切分点由"最大值的位置"决定，而不是"第一个元素"。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var constructMaximumBinaryTree = function (nums) {
  const build = (lo, hi) => {
    if (lo > hi) return null;
    let maxIdx = lo;
    for (let i = lo + 1; i <= hi; i++) {
      if (nums[i] > nums[maxIdx]) maxIdx = i;   // 找区间最大值
    }
    const node = new TreeNode(nums[maxIdx]);
    node.left = build(lo, maxIdx - 1);
    node.right = build(maxIdx + 1, hi);
    return node;
  };
  return build(0, nums.length - 1);
};
```

**复杂度**：时间 O(n²) 最坏（单调数组），平均 O(n log n) ／ 空间 O(h)；单调栈可优化到 O(n)

**易错点**：
- 把最大值当索引下标使用（`nums[max]` 与 `maxIdx` 混用）。
- 左右区间写错，例如左区间写成 `[lo, maxIdx]`，最大值被重复使用导致死循环。
- 空数组没有返回 null。
- 单调数组（如 `[1,2,3,4,5]`）时递归深度 O(n)，节点多时会爆栈——这是 O(n²) 解法除时间外的隐患。

**变体与追问**：
- O(n) 单调栈解法（面试加分）：递减栈 + 左孩子/右孩子挂接。
- 最大二叉树的前序遍历恰好是原数组 `nums`，这是 654 与 197 互为逆运算的体现。

### C-199 将二叉搜索树变平衡 · 中等 · 阿里/字节

**题干**：给你一棵二叉搜索树，返回一棵**平衡后**的二叉搜索树，新树与原树有相同的节点值（结构可变）。只要每个节点左右子树高度差不超过 1 即视为平衡，返回任意一种合法答案。

**示例**：`输入: root = [1,null,2,null,3,null,4]` → `输出: [2,1,3,null,null,null,4]`

**思路**：
- 分两步走：① 中序遍历拿到**升序数组**（BST 的中序有序，这是唯一能保证"重建后仍是 BST"的顺序）；② 用 108 的"每次取中点"重建，平衡由构造方式自动保证。
- 为什么不直接在原树上做旋转？AVL 的旋转需要自底向上回溯判断四种失衡类型，代码量和出错率都远超"转数组重建成平衡树"。
- 两步都是 O(n)，总计 O(n)；空间上是 O(n) 数组 + O(log n) 递归栈。
- 关键洞察：这道题是 108 的"应用题"——把"结构平衡"问题转化成"有序数组 → 平衡 BST"的构造问题。识别出这个转化，代码不到 20 行。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var balanceBST = function (root) {
  const nums = [];
  const inorder = (node) => {
    if (!node) return;
    inorder(node.left);
    nums.push(node.val);           // 中序 → 升序
    inorder(node.right);
  };
  inorder(root);
  const build = (lo, hi) => {
    if (lo > hi) return null;
    const mid = (lo + hi) >> 1;    // 取中点保证平衡
    const node = new TreeNode(nums[mid]);
    node.left = build(lo, mid - 1);
    node.right = build(mid + 1, hi);
    return node;
  };
  return build(0, nums.length - 1);
};
```

**复杂度**：时间 O(n) ／ 空间 O(n)，中序数组 + O(log n) 递归栈

**易错点**：
- 想用旋转硬做：逻辑复杂且容易在"左右双旋"处出错，面试性价比极低。
- 中序收集时顺序写错（先右后左得到降序），重建出的树不是 BST。
- 重建时用 `slice` 切数组，复杂度退化到 O(n log n)。
- 认为答案唯一——取中点的偏左/偏右、以及不同合法形状都可以。

**变体与追问**：
- 若要求"旋转次数最少"，需要 DSW（Day-Stout-Warren）算法，先把树拉成链再重建。
- 若只需"树高不超过 h"而非严格平衡，可以按区间长度分配节点数（类似完全二叉树）。

### C-200 二叉搜索树中的众数 · 简单 · 美团/字节

**题干**：给你一个含重复值的二叉搜索树的根节点 `root`，找出并返回其中的**所有众数**（出现频率最高的元素）。若不止一个众数，按任意顺序返回。本题 BST 定义为：左子树节点值 `≤` 根值，右子树节点值 `≥` 根值（允许相等）。

**示例**：`输入: root = [1,null,2,2]` → `输出: [2]`；`输入: root = [0]` → `输出: [0]`

**思路**：
- 普通二叉树求众数要用哈希表统计频率（O(n) 空间）。但 BST 的中序遍历里**相同的值一定连续出现**，所以计数只需要一个变量：比较"当前值"与"上一个访问值"。
- 遍历中维护 `count`（当前值的出现次数）与 `maxCount`（历史最大）。若 `count > maxCount`：清空结果数组、放入当前值、更新 maxCount；若 `count === maxCount`：追加当前值。
- 这是**一次遍历、O(1) 额外空间**（除输出外）的解法，正是本题作为 BST 题的价值所在。
- 关键洞察：不能提前知道 maxCount，所以"发现更大的频率就清空重来"是唯一正确的在线策略。若想两趟遍历（先求最大频率再收集），要付出双倍时间。

**代码**：
```javascript
function TreeNode(val, left, right) {
  this.val = val === undefined ? 0 : val;
  this.left = left === undefined ? null : left;
  this.right = right === undefined ? null : right;
}

var findMode = function (root) {
  let prev = null, count = 0, maxCount = 0;
  let modes = [];
  const inorder = (node) => {
    if (!node) return;
    inorder(node.left);
    count = node.val === prev ? count + 1 : 1;    // 中序相同值相邻
    if (count > maxCount) {
      maxCount = count;
      modes = [node.val];                        // 刷新记录，清空重来
    } else if (count === maxCount) {
      modes.push(node.val);
    }
    prev = node.val;
    inorder(node.right);
  };
  inorder(root);
  return modes;
};
```

**复杂度**：时间 O(n) ／ 空间 O(h)，递归栈；除输出外额外空间 O(1)

**易错点**：
- 用 `Map` 统计全部频率再取最大：能过，但没利用 BST，被追问空间复杂度时很被动。
- `count > maxCount` 时只 push 不清空，旧众数残留（`[1,2]` 各出现一次会返回两个，恰好对；但 `[1,1,2]` 就错）。
- `prev` 初始化为 0，节点值可为负时首节点判断出错（用 `null`）。
- 漏掉 `count === maxCount` 的分支，多个众数只返回一个。

**变体与追问**：
- 普通二叉树求众数：只能 `Map` 计数，O(n) 空间。
- 求"出现次数超过一半"的元素：中序后可用摩尔投票，O(1) 空间。

---
