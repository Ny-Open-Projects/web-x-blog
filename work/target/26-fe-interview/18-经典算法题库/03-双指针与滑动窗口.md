# 03 双指针与滑动窗口（C-041 ~ C-060）

> 双指针与滑动窗口是大厂笔试里"性价比最高"的一类：题干一旦出现**有序数组**、**连续子数组/子串**、**原地修改**，八成就是它。它考的不是背模板，而是能否讲清"为什么这样移动指针不会漏解"。**识别特征**：看到"有序 + 找一对"想到对撞双指针；看到"最长/最短的连续区间"想到滑动窗口；看到"原地删除/去重"想到快慢指针。

## 题型速查

| 子类型 | 核心手法 | 代表题 |
|---|---|---|
| 对撞双指针 | 左右夹逼，按和/比较结果移动一侧 | C-041 C-042 C-055 C-060 |
| 快慢指针（原地） | 慢指针写、快指针读，覆盖即删除 | C-051 C-052 C-053 C-059 |
| 变长滑动窗口 | 右扩左缩，窗口内维护计数 | C-044 C-046 C-047 C-049 |
| 滑窗 + 哈希计数 | need/window 双表做覆盖判定 | C-045 C-050 |
| 单调队列 | 维护窗口内候选值的单调性 | C-048 |
| 双序列归并/匹配 | 双指针同步推进 | C-054 C-056 C-057 C-058 |

### C-041 两数之和 II（有序数组） · 中等 · 字节/腾讯

**题干**：给你一个下标从 **1** 开始的整数数组 `numbers`，它已按**非递减顺序**排列。请从数组中找出两个数，满足相加之和等于目标数 `target`。设这两个数分别是 `numbers[index1]` 和 `numbers[index2]`，要求 `1 <= index1 < index2 <= numbers.length`。以长度为 2 的数组 `[index1, index2]` 返回下标。测试用例保证存在**唯一**答案，且同一元素不能重复使用。要求额外空间为 O(1)。

**示例**：`输入: numbers = [2,7,11,15], target = 9` → `输出: [1,2]`

**思路**：
- 暴力：双重循环枚举所有下标对，找到和为 target 的一对，O(n²) 时间、O(1) 空间，n 到 3e4 时明显吃力。
- 最优：**有序**这个条件是钥匙。左右指针 `i` 指向最小、`j` 指向最大，求和后与 target 比较。若 `sum < target`，因为 `numbers[i]` 是当前最小值，它和任何 `numbers[k] (k <= j)` 相加都不会超过当前 sum，仍小于 target，所以 `numbers[i]` 可以**整体排除**，`i++` 安全；反之 `sum > target` 时 `numbers[j]` 也整体排除，`j--`。每次移动都严格排除一个元素且不会漏掉答案，故 O(n) 必然收敛到唯一解。

**代码**：
```javascript
/**
 * 有序数组两数之和：对撞双指针
 * @param {number[]} numbers 非递减数组，下标从 1 开始计
 * @param {number} target
 * @returns {number[]} 1-based 下标 [index1, index2]
 */
function twoSum(numbers, target) {
  let i = 0;
  let j = numbers.length - 1;
  while (i < j) {                     // 必须 i < j，等于会复用同一元素
    const sum = numbers[i] + numbers[j];
    if (sum === target) return [i + 1, j + 1]; // 题目要求 1-based
    if (sum < target) {
      i++;                            // 最小值配最大的都太小，排除 i
    } else {
      j--;                            // 最大值太大，排除 j
    }
  }
  return [-1, -1];                    // 题目保证有解，兜底
}

console.log(twoSum([2, 7, 11, 15], 9));   // [1, 2]
console.log(twoSum([2, 3, 4], 6));        // [1, 3]
console.log(twoSum([-1, 0], -1));         // [1, 2]
```

**复杂度**：时间 O(n)，空间 O(1)。

**易错点**：
- 返回值是 **1-based** 下标，忘记 `+1` 是最常见的丢分点。
- 循环条件写成 `i <= j` 会让同一元素被用两次，且可能死循环。
- 数组可能含负数，不能因为"和偏大"就提前 `break`，必须老老实实缩指针。
- 返回值是下标数组而非数值本身，读题要仔细。

**变体与追问**：
- 数组无序（LC 1）：用哈希表存 `target - num`，O(n) 时间、O(n) 空间。
- 要求返回所有不重复数对：命中后 `i++`、`j--`，并跳过相邻重复值，避免重复结果。
- 三数之和（LC 15）：排序后枚举第一个数，剩下两数用对撞双指针，整体 O(n²)，注意去重。

### C-042 验证回文串 · 简单 · 美团/快手

**题干**：给定一个字符串 `s`，验证它是否是回文串。只考虑**字母和数字**字符，忽略字母的大小写。空字符串视为有效回文串。

**示例**：`输入: s = "A man, a plan, a canal: Panama"` → `输出: true`（忽略标点后为 "amanaplanacanalpanama"）

**思路**：
- 暴力：先过滤出所有字母数字并转小写得到新串，再反转比较，O(n) 时间但 O(n) 额外空间。
- 最优：直接双指针在原串上走。`i` 从左、`j` 从右，遇到非字母数字就跳过，直到两侧都指向有效字符再比较（统一转小写）。一旦不等立即返回 false。这样原地判断，O(1) 额外空间。关键点是"跳过无效字符"的循环要写成 `while (i < j && !isValid(s[i])) i++`，否则 `i` 会越过 `j` 导致越界。

**代码**：
```javascript
function isPalindrome(s) {
  const isValid = (ch) => /[a-z0-9]/i.test(ch); // 字母或数字
  let i = 0;
  let j = s.length - 1;
  while (i < j) {
    // 跳过左侧非字母数字（注意 i < j 防止越界）
    while (i < j && !isValid(s[i])) i++;
    while (i < j && !isValid(s[j])) j--;
    if (s[i].toLowerCase() !== s[j].toLowerCase()) return false;
    i++;
    j--;
  }
  return true;
}

console.log(isPalindrome("A man, a plan, a canal: Panama")); // true
console.log(isPalindrome("race a car"));                     // false
console.log(isPalindrome(" "));                              // true
```

**复杂度**：时间 O(n)（每个字符最多被访问一次），空间 O(1)。

**易错点**：
- 内层跳过循环忘记加 `i < j`，全标点串会越界。
- 大小写：数字没有大小写，`toLowerCase` 对数字无副作用，可统一处理。
- 正则 `/[a-z0-9]/i` 里的 `i` 标志只对字母生效，别误以为能把中文也纳入"字母"。
- 题目说空串算回文，`" "` 过滤后为空也应返回 true。

**变体与追问**：
- 允许删除至多一个字符（LC 680）：遇到不等时，尝试跳过左或右一个字符后判断剩余是否回文。
- 只考虑 ASCII、要求 O(1) 空间：可手写 `charCodeAt` 区间判断代替正则，更快。
- 回文链表：先用快慢指针找中点，反转后半段再比较。

### C-043 反转字符串 · 简单 · 阿里/字节

**题干**：编写一个函数，将输入的字符数组 `s` 反转。必须**原地**修改输入数组、使用 O(1) 额外空间完成，不能分配新数组。

**示例**：`输入: s = ["h","e","l","l","o"]` → `输出: ["o","l","l","e","h"]`

**思路**：
- 暴力：`s.reverse()` 或新建数组倒序拷贝，O(n) 空间，违反"原地"约束。
- 最优：对撞双指针。`i` 从 0、`j` 从末尾，交换 `s[i]` 与 `s[j]` 后相向移动，直到 `i >= j` 停止。交换次数是 `floor(n/2)`，奇数长度时中间元素自然不动，无需特判。这是"原地反转"的母题，反转字符串中的单词、反转链表（迭代版）都从它演化而来。

**代码**：
```javascript
/**
 * 原地反转字符数组，O(1) 额外空间
 * @param {character[]} s
 * @returns {void} 直接修改 s
 */
function reverseString(s) {
  let i = 0;
  let j = s.length - 1;
  while (i < j) {
    // 解构交换，也可用临时变量
    [s[i], s[j]] = [s[j], s[i]];
    i++;
    j--;
  }
}

const arr = ["h", "e", "l", "l", "o"];
reverseString(arr);
console.log(arr); // ["o","l","l","e","h"]

const arr2 = ["H", "a", "n", "n", "a", "h"];
reverseString(arr2);
console.log(arr2); // ["h","a","n","n","a","H"]
```

**复杂度**：时间 O(n)，空间 O(1)。

**易错点**：
- 题目传入的是**字符数组**而非字符串；JS 字符串不可变，无法原地改。
- 空数组、长度 1 的数组循环不执行，天然正确，不需额外判断。
- 用 `[a,b]=[b,a]` 解构交换在数组中会创建临时数组，严格意义上不是 O(1) 空间；面试若强调极致可用临时变量。
- 不要返回新数组，函数应原地修改并返回 void（或返回 s 亦可）。
- 递归写法本质是分治，但会引入 O(n) 调用栈空间，工程上不如迭代稳妥。

**变体与追问**：
- 反转字符串 II（LC 541）：每 2k 个字符反转前 k 个，按块处理。
- 反转字符串中的单词 III（LC 557）：先按空格切分，每个单词内部反转。
- 反转链表：把"交换首尾"换成"改指针方向"，迭代版用三个指针 prev/cur/next。

### C-044 无重复字符的最长子串 · 中等 · 字节/阿里/腾讯

**题干**：给定一个字符串 `s`，请找出其中**不含重复字符**的**最长子串**的长度。子串必须连续。

**示例**：`输入: s = "abcabcbb"` → `输出: 3`（最长无重复子串为 "abc"）

**思路**：
- 暴力：枚举所有子串起点，用 Set 向后扩展直到重复，最坏 O(n²)。
- 最优：变长滑动窗口 + 哈希表记录"字符最近一次出现的下标"。右指针 `r` 每次纳入 `s[r]`；若该字符上次出现位置 `last >= l`，说明窗口内已重复，直接把 `l` **跳到** `last + 1`（而不是一格一格挪，这是 O(n) 的关键）。窗口 `[l, r]` 始终无重复，用 `r - l + 1` 更新答案。每个字符最多被右指针访问一次、左指针单调前进，总计 O(n)。

**代码**：
```javascript
function lengthOfLongestSubstring(s) {
  const last = new Map(); // 字符 -> 最近一次出现的下标
  let l = 0;              // 窗口左边界
  let ans = 0;
  for (let r = 0; r < s.length; r++) {
    const ch = s[r];
    // 只有上次出现位置落在当前窗口内，才需要收缩
    if (last.has(ch) && last.get(ch) >= l) {
      l = last.get(ch) + 1; // 直接跳到重复字符的下一位
    }
    last.set(ch, r);
    ans = Math.max(ans, r - l + 1); // 窗口 [l, r] 长度
  }
  return ans;
}

console.log(lengthOfLongestSubstring("abcabcbb")); // 3
console.log(lengthOfLongestSubstring("bbbbb"));    // 1
console.log(lengthOfLongestSubstring("pwwkew"));   // 3
console.log(lengthOfLongestSubstring(""));         // 0
```

**复杂度**：时间 O(n)，空间 O(字符集大小)（ASCII 可视作 O(1)）。

**易错点**：
- 忘记判断 `last.get(ch) >= l`：字符虽出现过但在窗口左侧之外，不应收缩。
- `l` 只能**单调右移**，不能用 `l = last+1` 无条件覆盖导致回退。
- 空串返回 0，循环不执行自然正确。
- 求的是"长度"不是"子串本身"，别多此一举拼字符串。

**变体与追问**：
- 至多包含 K 个不同字符的最长子串（LC 340）：改用"窗口内不同字符计数"作为收缩条件。
- 至少有 K 个重复字符的最长子串（LC 395）：分治或按"不足 K 的字符"切分。
- 若字符集只有小写字母，可用长度 128 的数组代替 Map，常数更小。

### C-045 最小覆盖子串 · 困难 · 字节/腾讯

**题干**：给你一个字符串 `s`、一个字符串 `t`。返回 `s` 中涵盖 `t` 所有字符的**最短子串**。如果 `s` 中不存在涵盖 `t` 所有字符的子串，返回空字符串 `""`。若存在多个最短，返回任意一个。注意 `t` 中重复字符需被覆盖相应次数。

**示例**：`输入: s = "ADOBECODEBANC", t = "ABC"` → `输出: "BANC"`

**思路**：
- 暴力：枚举所有子串并检查是否覆盖 t，检查本身 O(|t|)，总 O(n²·|t|)，必超时。
- 最优：滑动窗口 + 双哈希表。`need` 记录 t 中每个字符的需求数，`window` 记录当前窗口内的计数，用 `valid` 统计"已满足需求的字符种类数"。右指针扩张纳入字符，当 `valid === need.size` 时窗口已覆盖 t，此时尝试收缩左边界：每次移除 `s[l]` 前先用当前窗口长度更新最优答案，再左移。收缩到不再覆盖时停止扩张。关键在于 `valid` 只在某字符计数**恰好等于**需求时才 +1，超过需求不重复计。

**代码**：
```javascript
function minWindow(s, t) {
  const need = new Map();
  for (const ch of t) need.set(ch, (need.get(ch) || 0) + 1);
  const window = new Map();
  let valid = 0;                 // 已满足需求的字符种类数
  let l = 0, start = 0, minLen = Infinity;

  for (let r = 0; r < s.length; r++) {
    const ch = s[r];
    if (need.has(ch)) {
      window.set(ch, (window.get(ch) || 0) + 1);
      if (window.get(ch) === need.get(ch)) valid++; // 恰好满足才计一种
    }
    // 窗口已覆盖 t，尝试收缩左边界
    while (valid === need.size) {
      if (r - l + 1 < minLen) {   // 先更新答案再收缩
        minLen = r - l + 1;
        start = l;
      }
      const left = s[l];
      if (need.has(left)) {
        if (window.get(left) === need.get(left)) valid--; // 移除后不再满足
        window.set(left, window.get(left) - 1);
      }
      l++;
    }
  }
  return minLen === Infinity ? "" : s.slice(start, start + minLen);
}

console.log(minWindow("ADOBECODEBANC", "ABC")); // "BANC"
console.log(minWindow("a", "a"));               // "a"
console.log(minWindow("a", "aa"));              // ""
```

**复杂度**：时间 O(n + m)（n=|s|，m=|t|，每个字符最多进出窗口一次），空间 O(字符集)。

**易错点**：
- `valid` 用 `===` 而非 `>=`：计数超过需求时不能重复加，移除时同理要先判断是否"正好等于"需求再减。
- 更新答案必须在收缩**之前**，否则窗口已破坏。
- 返回空串的条件是 `minLen` 仍为 Infinity，而不是 `start === 0`。
- `t` 可能比 `s` 长，此时直接返回 `""`（代码逻辑也能自然覆盖）。

**变体与追问**：
- 找到字符串中所有字母异位词（LC 438）：固定窗口长度 = |t|，用同样的 `valid` 判定。
- 字符串的排列（LC 567）：同上，只需返回布尔。
- 若要求覆盖的是"字符集合"而非"多重集"（每种只需一次），可去掉计数、改用集合。

### C-046 找到字符串中所有字母异位词 · 中等 · 字节/美团

**题干**：给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的**字母异位词**的子串，返回这些子串的起始索引（顺序不限）。字母异位词指字母种类与数量完全相同、仅排列不同的字符串。

**示例**：`输入: s = "cbaebabacd", p = "abc"` → `输出: [0,6]`（"cba" 与 "bac"）

**思路**：
- 暴力：枚举每个起点，取长度 |p| 的子串排序后与排序后的 p 比较，O(n·m log m)。
- 最优：**定长滑动窗口**。窗口长度恒为 m=|p|，用 `need` 记录 p 的字符需求、`window` 记录窗口内计数、`valid` 记录已满足的种类数。右指针纳入 `s[r]`，当窗口长度超过 m 时移除最左字符 `s[r-m]`；长度恰好等于 m 时若 `valid === need.size` 即命中。窗口每次只进出各一个字符，O(1) 维护，总 O(n + m)。

**代码**：
```javascript
function findAnagrams(s, p) {
  const res = [];
  const m = p.length;
  if (s.length < m) return res;
  const need = new Map();
  for (const ch of p) need.set(ch, (need.get(ch) || 0) + 1);
  const window = new Map();
  let valid = 0; // 已满足需求的字符种类数

  for (let r = 0; r < s.length; r++) {
    const add = s[r];
    if (need.has(add)) {
      window.set(add, (window.get(add) || 0) + 1);
      if (window.get(add) === need.get(add)) valid++;
    }
    // 窗口超过 m，移除左边多出来的字符
    if (r >= m) {
      const del = s[r - m];
      if (need.has(del)) {
        if (window.get(del) === need.get(del)) valid--;
        window.set(del, window.get(del) - 1);
      }
    }
    if (valid === need.size) res.push(r - m + 1);
  }
  return res;
}

console.log(findAnagrams("cbaebabacd", "abc")); // [0, 6]
console.log(findAnagrams("abab", "ab"));        // [0, 1, 2]
console.log(findAnagrams("a", "ab"));           // []
```

**复杂度**：时间 O(n + m)，空间 O(字符集)。

**易错点**：
- 先移除后判断的顺序：必须先处理"超长移除"再判断命中，否则窗口长度不对。
- 起始索引是 `r - m + 1`，不是 `r - m`。
- `s` 比 `p` 短时应直接返回空数组，避免负索引。
- 移除字符时同样要"等于需求才 `valid--`"，超过需求的不计。

**变体与追问**：
- 字符串的排列（LC 567）：不收集索引，命中即返回 true。
- 最小覆盖子串（LC 76）：窗口变长，收缩条件换成"仍覆盖"。
- 若字符仅小写字母，用长度 26 的数组计数，比较两数组相等即可，常数更小但每次比较 O(26)。

### C-047 长度最小的子数组 · 中等 · 字节/阿里

**题干**：给定一个含有 `n` 个**正整数**的数组和一个正整数 `target`，找出该数组中满足其和 **≥ target** 的**长度最小**的连续子数组，返回其长度。如果不存在符合条件的子数组，返回 `0`。

**示例**：`输入: target = 7, nums = [2,3,1,2,4,3]` → `输出: 2`（子数组 [4,3] 和为 7）

**思路**：
- 暴力：枚举起点与终点累加求和，O(n²)。
- 最优：**正整数**保证前缀和单调递增，于是可以用滑窗。右指针不断累加 `sum`，当 `sum >= target` 时进入内层 `while`：先用当前窗口长度更新答案，再把左指针元素从 sum 中减去并右移，直到 sum 再次小于 target。每个元素最多被加入、移除各一次，总 O(n)。若元素含负数，前缀和不再单调，此滑窗失效，需用前缀和 + 二分或单调队列。

**代码**：
```javascript
function minSubArrayLen(target, nums) {
  let l = 0;
  let sum = 0;
  let ans = Infinity;

  for (let r = 0; r < nums.length; r++) {
    sum += nums[r];                 // 右边界扩张
    while (sum >= target) {         // 满足条件就尝试收缩
      ans = Math.min(ans, r - l + 1);
      sum -= nums[l];               // 移出左边
      l++;
    }
  }
  return ans === Infinity ? 0 : ans; // 找不到返回 0
}

console.log(minSubArrayLen(7, [2, 3, 1, 2, 4, 3])); // 2
console.log(minSubArrayLen(4, [1, 4, 4]));           // 1
console.log(minSubArrayLen(11, [1, 1, 1, 1]));       // 0
```

**复杂度**：时间 O(n)，空间 O(1)。

**易错点**：
- 只有元素全为正时该滑窗才成立；题目特意强调"正整数"就是在提示条件。
- 内层用 `while` 而非 `if`，一次扩张可能需要连续收缩多次。
- 返回的是长度而非子数组；无解返回 `0`，不是 `-1`。
- `ans` 初始为 Infinity，最后判断再转换，避免用 0 做初始值导致 Math.min 永远取 0。

**变体与追问**：
- 和 ≥ target 的最短子数组（含负数，LC 862 变体）：前缀和 + 单调双端队列，O(n)。
- 乘积小于 K 的子数组个数（LC 713）：窗口条件改为乘积 < k，需注意 k ≤ 1 的边界。
- 长度最小的子数组且要求恰好等于 target：前缀和 + 哈希表，类似两数之和。

### C-048 滑动窗口最大值 · 困难 · 字节/腾讯

**题干**：给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组最左侧移动到最右侧。窗口每次只向右移动一位，返回**每个窗口中的最大值**组成的数组。

**示例**：`输入: nums = [1,3,-1,-3,5,3,6,7], k = 3` → `输出: [3,3,5,5,6,7]`

**思路**：
- 暴力：每个窗口扫 k 个元素取最大，O(n·k)，k 接近 n 时退化为 O(n²)。
- 最优：**单调递减双端队列**存**下标**。新元素入队前，从队尾弹出所有值 ≤ 它的元素——这些元素比它小又比它早过期，永远不可能再成为任何窗口的最大值，可以安全丢弃。队首始终保持当前窗口最大值。每次右移时若队首下标 ≤ `r - k` 说明已滑出窗口，从队首移除。每个下标最多入队、出队各一次，总 O(n)。

**代码**：
```javascript
function maxSlidingWindow(nums, k) {
  const dq = [];   // 存下标，对应值单调递减
  const res = [];

  for (let r = 0; r < nums.length; r++) {
    // 队尾比当前值小的都弹出（它们不可能再是最大值）
    while (dq.length && nums[dq[dq.length - 1]] <= nums[r]) {
      dq.pop();
    }
    dq.push(r);
    // 队首下标滑出窗口则移除
    if (dq[0] <= r - k) dq.shift();
    // 窗口形成后才记录答案
    if (r >= k - 1) res.push(nums[dq[0]]);
  }
  return res;
}

console.log(maxSlidingWindow([1, 3, -1, -3, 5, 3, 6, 7], 3)); // [3,3,5,5,6,7]
console.log(maxSlidingWindow([1], 1));                        // [1]
console.log(maxSlidingWindow([9, 11], 2));                    // [11]
```

**复杂度**：时间 O(n)，空间 O(k)。

**易错点**：
- 队列必须存**下标**：只存值无法判断是否已滑出窗口。
- 弹出队尾用 `<=` 还是 `<` 会影响重复元素的处理，用 `<=` 可去掉冗余旧值，结果仍正确。
- `dq.shift()` 是 O(n) 操作，理论上可用数组 + 头指针模拟；本解法均摊仍是 O(n)，面试可说明。
- 记录答案的条件是 `r >= k - 1`，前 k-1 个位置窗口还没满。

**变体与追问**：
- 滑动窗口最小值：把比较方向反过来，改成单调递增队列。
- 队列的最大值（剑指 Offer 59-II）：设计一个支持 push/pop/max 的队列，用单调队列辅助。
- 若 k = 1，直接返回原数组；若 k ≥ n，返回全局最大值（单元素数组）。

### C-049 字符串的排列 · 中等 · 字节/快手

**题干**：给你两个字符串 `s1` 和 `s2`，写一个函数判断 `s2` 是否包含 `s1` 的某个**排列**。换句话说，`s1` 的某个排列是否是 `s2` 的一个子串。

**示例**：`输入: s1 = "ab", s2 = "eidbaooo"` → `输出: true`（"ba" 是 s1 的排列）

**思路**：
- 暴力：枚举 s1 所有排列（最多 m! 个）再在 s2 中查找，不可行。
- 最优：与"找所有字母异位词"同构，只是不收集索引、命中即返回。窗口长度固定为 |s1|，用 `need` / `window` 计数 + `valid` 判定覆盖。窗口右扩，超过长度就左缩，任一次 `valid === need.size` 即返回 true。复杂度 O(n + m)。因为字母异位词的本质就是"每种字符计数相同"，无需真的生成排列。

**代码**：
```javascript
function checkInclusion(s1, s2) {
  const m = s1.length;
  if (s2.length < m) return false;
  const need = new Map();
  for (const ch of s1) need.set(ch, (need.get(ch) || 0) + 1);
  const window = new Map();
  let valid = 0;

  for (let r = 0; r < s2.length; r++) {
    const add = s2[r];
    if (need.has(add)) {
      window.set(add, (window.get(add) || 0) + 1);
      if (window.get(add) === need.get(add)) valid++;
    }
    if (r >= m) {                       // 维持窗口长度恰为 m
      const del = s2[r - m];
      if (need.has(del)) {
        if (window.get(del) === need.get(del)) valid--;
        window.set(del, window.get(del) - 1);
      }
    }
    if (valid === need.size) return true;
  }
  return false;
}

console.log(checkInclusion("ab", "eidbaooo")); // true
console.log(checkInclusion("ab", "eidboaoo")); // false
console.log(checkInclusion("adc", "dcda"));    // true
```

**复杂度**：时间 O(n + m)，空间 O(字符集)。

**易错点**：
- 命中判断要放在"移除超长字符"**之后**，保证窗口长度正好为 m。
- `s2` 比 `s1` 短时直接 false，否则会误判。
- 这里返回布尔，不要照抄 438 收集索引的逻辑。
- 字符可能包含大写、数字等，用 Map 比固定 26 数组更稳。
- 窗口长度固定，无需像变长滑窗那样反复判断收缩条件，代码更直白。

**变体与追问**：
- 找到所有字母异位词（LC 438）：收集所有满足条件的起始索引。
- 最小覆盖子串（LC 76）：窗口变长，求最短覆盖。
- 若 s1 远小于 s2，可先算 s1 的计数指纹，再滚动更新 s2 窗口的指纹做比较。

### C-050 至多包含两个不同字符的最长子串 · 中等 · 字节

**题干**：给定一个字符串 `s`，找出**至多包含两个不同字符**的最长子串 `t`，返回该子串的长度。（子串必须连续；若不足两个字符则整个串即为答案。）

**示例**：`输入: s = "eceba"` → `输出: 3`（"ece"）

**思路**：
- 暴力：枚举所有子串、统计不同字符数，O(n²)。
- 最优：变长滑动窗口 + Map 计数。右指针不断纳入字符并累加计数；当 `map.size > 2`（窗口内不同字符数超过 2）时，循环左移 `l`、减少对应计数，计数归零就从 Map 删除，直到 `size` 回到 2。窗口始终满足"至多两种字符"，用 `r - l + 1` 更新答案。每个字符进出窗口各一次，O(n)。

**代码**：
```javascript
function lengthOfLongestSubstringTwoDistinct(s) {
  const cnt = new Map();   // 字符 -> 窗口内出现次数
  let l = 0;
  let ans = 0;

  for (let r = 0; r < s.length; r++) {
    const ch = s[r];
    cnt.set(ch, (cnt.get(ch) || 0) + 1);
    // 不同字符超过 2 个，收缩左边界
    while (cnt.size > 2) {
      const left = s[l];
      const c = cnt.get(left) - 1;
      if (c === 0) cnt.delete(left); // 计数归零必须删除，否则 size 不减
      else cnt.set(left, c);
      l++;
    }
    ans = Math.max(ans, r - l + 1);
  }
  return ans;
}

console.log(lengthOfLongestSubstringTwoDistinct("eceba")); // 3
console.log(lengthOfLongestSubstringTwoDistinct("ccaabbb")); // 5
console.log(lengthOfLongestSubstringTwoDistinct("a"));       // 1
```

**复杂度**：时间 O(n)，空间 O(1)（Map 最多存 3 个键）。

**易错点**：
- 计数减到 0 时必须 `delete`，否则 `Map.size` 不减，收缩永不停止。
- 空串返回 0，循环不执行自然正确。
- 题目是"至多两个"，只有一种字符的串也合法，不要误判。
- `ans` 更新在收缩**之后**，此时窗口才满足条件。

**变体与追问**：
- 至多 K 个不同字符的最长子串（LC 340）：把 2 换成参数 K，注意 K=0 的边界。
- 恰好 K 个不同字符的最长子串（LC 992）：转化为"至多 K"减"至多 K-1"，或用计数数组 + 分类。
- 替换后的最长重复字符（LC 424）：窗口条件改为"窗口长度 − 出现最多字符的次数 ≤ k"。

### C-051 删除有序数组中的重复项 · 简单 · 字节/阿里

**题干**：给你一个**非严格递增**排列的数组 `nums`，请你**原地**删除重复出现的元素，使每个元素**只出现一次**，返回删除后数组的新长度。必须原地修改输入数组并在 O(1) 额外空间下完成，元素的相对顺序应保持一致。

**示例**：`输入: nums = [1,1,2]` → `输出: 2, nums = [1,2,_]`（返回长度 2，前两位为去重结果）

**思路**：
- 暴力：用 `filter` 或 Set 生成新数组再拷回，O(n) 额外空间，违反原地约束。
- 最优：**快慢指针**。`slow` 指向已去重部分的末尾（也是下一个待写入位置），`fast` 负责遍历。因为数组有序，重复元素必然相邻，所以只需判断 `nums[fast]` 是否等于 `nums[slow]`：不等说明遇到新值，`slow++` 后写入；相等则跳过。每步 `fast` 前进一格，`slow` 最多前进 n 格，总 O(n)。

**代码**：
```javascript
function removeDuplicates(nums) {
  if (nums.length === 0) return 0;
  let slow = 0; // 已去重区间的最后一个下标
  for (let fast = 1; fast < nums.length; fast++) {
    // 与 slow 位置的元素比较：有序数组只有相邻才可能重复
    if (nums[fast] !== nums[slow]) {
      slow++;
      nums[slow] = nums[fast]; // 写入新值
    }
  }
  return slow + 1; // 长度 = 末位下标 + 1
}

console.log(removeDuplicates([1, 1, 2]));          // 2
console.log(removeDuplicates([0, 0, 1, 1, 1, 2, 2, 3, 3, 4])); // 5
console.log(removeDuplicates([]));                 // 0
```

**复杂度**：时间 O(n)，空间 O(1)。

**易错点**：
- 返回 `slow + 1` 而非 `slow`，`slow` 是下标。
- 与 `nums[slow]` 比较，不要错写成 `nums[slow - 1]`，否则边界和逻辑都会乱。
- 空数组要单独返回 0，否则 `nums[0]` 为 undefined。
- 题目不要求清理尾部多余元素，但若面试官要求，可在最后截断 `nums.length = slow + 1`。

**变体与追问**：
- 删除重复项 II（LC 80）：允许每个元素最多出现两次，比较对象改成 `nums[slow-2]`。
- 移除元素（LC 27）：删除指定值，条件改为 `!== val`。
- 若数组无序：先排序再原地去重，或直接用哈希表记录出现过的值（需额外空间）。

### C-052 删除有序数组中的重复项 II · 中等 · 字节

**题干**：给你一个有序数组 `nums`，请你**原地**删除重复出现的元素，使每个元素**最多出现两次**，返回删除后数组的新长度。必须原地修改并保持相对顺序，O(1) 额外空间。

**示例**：`输入: nums = [1,1,1,2,2,3]` → `输出: 5, nums = [1,1,2,2,3,_]`

**思路**：
- 暴力：统计每组重复个数再重建，逻辑繁琐且易越界。
- 最优：**快慢指针 + 保留位数判定**。`slow` 是下一个写入位置，`fast` 遍历。由于有序，判断"若把 `nums[fast]` 写到 `slow`，会不会让某个值超过 2 次"只需看 `nums[slow-2]`：若 `slow < 2` 说明不足两个，无条件保留；否则当 `nums[fast] !== nums[slow-2]` 时才写入。这是"保留 k 个"的通用模板，把 2 换成 k 即可推广。整体 O(n)。

**代码**：
```javascript
function removeDuplicates(nums) {
  const K = 2;            // 每个元素最多保留 K 个
  let slow = 0;           // 下一个写入位置
  for (let fast = 0; fast < nums.length; fast++) {
    // 前 K 个直接保留；否则与"倒数第 K 个已保留元素"比较
    if (slow < K || nums[fast] !== nums[slow - K]) {
      nums[slow] = nums[fast];
      slow++;
    }
  }
  return slow;
}

console.log(removeDuplicates([1, 1, 1, 2, 2, 3]));          // 5
console.log(removeDuplicates([0, 0, 1, 1, 1, 1, 2, 3, 3])); // 7
console.log(removeDuplicates([1, 1, 2]));                   // 3
```

**复杂度**：时间 O(n)，空间 O(1)。

**易错点**：
- `slow < K` 这个短路条件必须有，否则 `nums[slow-K]` 为负索引会取到 undefined/Python 式倒数。
- 比较对象是 `nums[slow-K]`，即已保留区间倒数第 K 个，而不是 `nums[fast-K]`。
- 返回 `slow`（已是长度），不是 `slow+1`，因为 slow 从 0 开始且已自增。
- 保留 1 个时该模板退化成 LC 26，可验证一致性。
- 模板的妙处在于无论 K 取多少都只需比较一个位置，不需要额外计数器。

**变体与追问**：
- 保留 1 个（LC 26）：K = 1。
- 保留任意 K 个：直接改常量，是最优雅的统一解法。
- 若要求不保序、只求长度：可用对撞双指针把超限元素换到后面，但需额外维护计数。

### C-053 移除元素 · 简单 · 阿里/美团

**题干**：给你一个数组 `nums` 和一个值 `val`，你需要**原地**移除所有数值等于 `val` 的元素，并返回移除后数组的新长度。元素的顺序可以改变，不需要考虑数组中超出新长度后面的元素。

**示例**：`输入: nums = [3,2,2,3], val = 3` → `输出: 2, nums = [2,2,_,_]`

**思路**：
- 暴力：新建结果数组收集非 val 元素再拷回，O(n) 额外空间。
- 最优：**快慢指针**。`fast` 遍历读，`slow` 指向下一个写入位置；只有 `nums[fast] !== val` 时才写入并 `slow++`。等于 val 的直接跳过，相当于被"覆盖删除"。O(n) 时间、O(1) 空间，且保持相对顺序。另一种对撞双指针适合 val 很少的场景：左指针找 val、右指针找非 val，交换后左移右指针。

**代码**：
```javascript
// 解法一：快慢指针（保序）
function removeElement(nums, val) {
  let slow = 0;
  for (let fast = 0; fast < nums.length; fast++) {
    if (nums[fast] !== val) {
      nums[slow] = nums[fast]; // 保留非 val 元素
      slow++;
    }
  }
  return slow;
}

// 解法二：对撞双指针（不保序，交换次数少）
function removeElementSwap(nums, val) {
  let i = 0;
  let n = nums.length;
  while (i < n) {
    if (nums[i] === val) {
      nums[i] = nums[n - 1]; // 用末尾元素覆盖
      n--;                   // 缩短有效长度，i 不前进
    } else {
      i++;
    }
  }
  return n;
}

console.log(removeElement([3, 2, 2, 3], 3));      // 2
console.log(removeElementSwap([0, 1, 2, 2, 3, 0, 4, 2], 2)); // 5
```

**复杂度**：时间 O(n)，空间 O(1)。

**易错点**：
- 返回的是**新长度**，不是数组；超出部分内容无所谓。
- 解法二里覆盖后 `i` **不能**自增，因为换过来的新元素还没检查。
- 空数组返回 0，循环不执行自然正确。
- `val` 不存在时返回原长度，逻辑应自然成立。

**变体与追问**：
- 删除有序数组中的重复项（LC 26/80）：条件换成与"已保留元素"比较。
- 移动零（LC 283）：把 0 移到末尾等价于"删除 0 后在尾部补 0"，快慢指针 + 补零。
- 若要求"删除后保持绝对顺序"且 val 很多：快慢指针更优；若 val 很少：对撞交换更少移动。

### C-054 按奇偶排序数组 · 简单 · 字节

**题干**：给定一个非负整数数组 `nums`，将数组中的所有**偶数**元素移到数组的**前面**，所有**奇数**元素移到数组的**后面**。返回满足此条件的**任意**数组。

**示例**：`输入: nums = [3,1,2,4]` → `输出: [2,4,3,1]`（[4,2,1,3]、[2,4,1,3] 等也正确）

**思路**：
- 暴力：新建两个数组分别收集偶数、奇数再拼接，O(n) 额外空间。
- 最优：**对撞双指针**。`i` 从前往后找第一个奇数，`j` 从后往前找第一个偶数，若 `i < j` 就交换二者，然后继续向中间推进。交换后左侧是偶数、右侧是奇数，天然满足"偶数在前"。每个元素最多被访问一次，O(n) 时间、O(1) 空间，且是原地操作。不要求稳定，所以交换即可，不必移动整段。

**代码**：
```javascript
function sortArrayByParity(nums) {
  let i = 0;
  let j = nums.length - 1;
  while (i < j) {
    // 左指针停在"该位置是奇数"的地方
    while (i < j && nums[i] % 2 === 0) i++;
    // 右指针停在"该位置是偶数"的地方
    while (i < j && nums[j] % 2 === 1) j--;
    if (i < j) {
      [nums[i], nums[j]] = [nums[j], nums[i]];
      i++;
      j--;
    }
  }
  return nums;
}

console.log(sortArrayByParity([3, 1, 2, 4])); // [4,2,1,3] 之类
console.log(sortArrayByParity([0]));         // [0]
console.log(sortArrayByParity([1, 2]));      // [2,1]
```

**复杂度**：时间 O(n)，空间 O(1)（不计返回数组）。

**易错点**：
- 内层两个 `while` 都必须带 `i < j`，否则可能越界。
- `% 2 === 1` 对负数不成立（-3 % 2 === -1），题目是非负整数才安全；通用写法用 `& 1`。
- 交换后 `i++`、`j--` 可推进，避免死循环。
- 题目允许任意顺序，不要画蛇添足去做稳定排序。

**变体与追问**：
- 按奇偶排序数组 II（LC 922）：要求奇数位放奇数、偶数位放偶数，且长度必为偶数，用两个指针分别走奇偶位。
- 移动零（LC 283）：类似分区，把 0 视作"偶数类"。
- 颜色分类（LC 75）：三路分区（荷兰国旗），可用三个指针一次遍历完成。

### C-055 有序数组的平方 · 简单 · 字节/腾讯

**题干**：给你一个按**非递减顺序**排序的整数数组 `nums`（可能含负数），返回每个数字的**平方**组成的新数组，要求新数组也按非递减顺序排序。

**示例**：`输入: nums = [-4,-1,0,3,10]` → `输出: [0,1,9,16,100]`

**思路**：
- 暴力：原地平方后排序，O(n log n)。
- 最优：观察平方后的最大值一定来自**两端**（最负或最正的数），且越往中间平方越小。于是用**对撞双指针**：`i` 指头、`j` 指尾，比较 `nums[i]²` 与 `nums[j]²`，较大者填入结果数组的**末尾**并移动对应指针。这样从大到小填、从后往前放，天然得到升序结果，O(n) 时间、O(n) 空间（结果数组必需）。

**代码**：
```javascript
function sortedSquares(nums) {
  const n = nums.length;
  const res = new Array(n);
  let i = 0;
  let j = n - 1;
  // 从结果数组末尾往前填，先放最大的
  for (let k = n - 1; k >= 0; k--) {
    const leftSq = nums[i] * nums[i];
    const rightSq = nums[j] * nums[j];
    if (leftSq > rightSq) {
      res[k] = leftSq;
      i++;
    } else {
      res[k] = rightSq;
      j--;
    }
  }
  return res;
}

console.log(sortedSquares([-4, -1, 0, 3, 10])); // [0,1,9,16,100]
console.log(sortedSquares([-7, -3, 2, 3, 11])); // [4,9,9,49,121]
console.log(sortedSquares([0]));                // [0]
```

**复杂度**：时间 O(n)，空间 O(n)（结果数组）。

**易错点**：
- 结果必须**从后往前**填，因为先确定的是最大值。
- 比较用平方值，不要比较原值（负数的平方可能更大）。
- `leftSq > rightSq` 用 `>` 还是 `>=` 都行，相等时任取一侧即可。
- 全部为负数或全部为正数时，双指针仍正确，无需特判。
- 不要尝试原地覆盖 nums，否则会破坏尚未读取的元素，必须另开结果数组。

**变体与追问**：
- 若要求原地修改：可先平方再用双指针"归并"式重排，但需临时变量，本质仍需 O(n) 辅助。
- 合并两个有序数组（LC 88）：同样"从后往前填"的技巧，避免覆盖。
- 若数组非有序：只能平方后排序，O(n log n) 是下界。

### C-056 合并两个有序数组 · 简单 · 字节/腾讯

**题干**：给你两个按**非递减顺序**排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n` 表示两数组中的元素数目。请你**原地**将 `nums2` 合并到 `nums1` 中，使合并后的数组仍按非递减顺序排列。`nums1` 初始长度为 `m + n`，其中后 `n` 个元素为 `0` 占位。函数不返回结果，结果直接存在 `nums1` 中。

**示例**：`输入: nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3` → `输出: [1,2,2,3,5,6]`

**思路**：
- 暴力：把 nums2 拷到 nums1 尾部再整体排序，O((m+n) log(m+n))，浪费了"两段已有序"的条件。
- 最优：**从后往前三指针**。`i = m-1`、`j = n-1`、`k = m+n-1`，每次比较 `nums1[i]` 与 `nums2[j]`，把较大者放到 `k` 再前移。从后往前的原因是 `nums1` 后半段是空闲占位，不会覆盖尚未处理的元素；若从前往后则必须额外搬移。O(m+n) 时间、O(1) 空间。

**代码**：
```javascript
function merge(nums1, m, nums2, n) {
  let i = m - 1;       // nums1 有效元素末尾
  let j = n - 1;       // nums2 末尾
  let k = m + n - 1;   // 写入位置（从后往前）

  while (i >= 0 && j >= 0) {
    if (nums1[i] > nums2[j]) {
      nums1[k--] = nums1[i--];
    } else {
      nums1[k--] = nums2[j--];
    }
  }
  // nums2 还有剩余则拷贝（nums1 剩余天然已在正确位置）
  while (j >= 0) {
    nums1[k--] = nums2[j--];
  }
}

const a = [1, 2, 3, 0, 0, 0];
merge(a, 3, [2, 5, 6], 3);
console.log(a); // [1,2,2,3,5,6]

const b = [1];
merge(b, 1, [], 0);
console.log(b); // [1]
```

**复杂度**：时间 O(m + n)，空间 O(1)。

**易错点**：
- 必须从后往前，从前往后会覆盖 `nums1` 尚未比较的元素。
- 循环结束后只需处理 `nums2` 的剩余；`nums1` 剩余本就已在前部有序。
- `m = 0` 时直接把 nums2 拷入；`n = 0` 时原样返回。
- 题目要求原地，别返回新数组。

**变体与追问**：
- 若不允许原地、要求返回新数组：标准归并，从前往后双指针。
- 合并两个有序链表（LC 21）：用哨兵节点 + 双指针，逻辑同构。
- 若两个数组长度相差悬殊且要求多次合并：可考虑二分插入减少移动。

### C-057 判断子序列 · 简单 · 字节/美团

**题干**：给定字符串 `s` 和 `t`，判断 `s` 是否为 `t` 的**子序列**。子序列指删除 `t` 中若干字符（也可不删）且不改变剩余字符相对位置后能得到 `s`。进阶：若有大量 `s` 需要匹配同一个 `t`（如 `s1, s2, ..., sk`），如何优化？

**示例**：`输入: s = "abc", t = "ahbgdc"` → `输出: true`

**思路**：
- 暴力：枚举 s 的每种删除组合去匹配，指数级。
- 最优：**双指针贪心**。`i` 走 `s`、`j` 走 `t`，当 `s[i] === t[j]` 时 `i` 前进；无论是否匹配 `j` 都要前进（t 的字符只能顺序用一次）。若 `i` 能走完 `s` 即为子序列，O(|t|) 时间。正确性来自贪心：匹配越早，给后续字符留的空间越大，不会更差。进阶场景用"下一个位置表 + 二分"，每个 s 查询 O(|s| log |t|)。

**代码**：
```javascript
function isSubsequence(s, t) {
  let i = 0;
  let j = 0;
  while (i < s.length && j < t.length) {
    if (s[i] === t[j]) i++; // 匹配上，s 前进
    j++;                    // t 总是前进
  }
  return i === s.length;    // s 全部匹配完
}

console.log(isSubsequence("abc", "ahbgdc")); // true
console.log(isSubsequence("axc", "ahbgdc")); // false
console.log(isSubsequence("", "abc"));       // true

// 进阶：预处理 t，构造每个位置之后各字符的首次出现下标
function buildNext(t) {
  const n = t.length;
  const next = Array.from({ length: n + 1 }, () => new Array(26).fill(-1));
  for (let i = n - 1; i >= 0; i--) {
    next[i] = next[i + 1].slice();        // 继承后一位的表
    next[i][t.charCodeAt(i) - 97] = i;    // 记录本字符位置
  }
  return next;
}
console.log(buildNext("abc").length); // 4，演示预处理结构
```

**复杂度**：基础双指针时间 O(|t|)，空间 O(1)；进阶预处理 O(26|t|)，单次查询 O(|s| log |t|)。

**易错点**：
- `j` 必须无条件前进，忘记会让循环卡死或误判。
- 空串 `s` 是任何串的子序列，应返回 true。
- 比较的是字符顺序，不是"字符是否都出现"。
- 进阶版中 `next` 表长度为 n+1，`next[n]` 全 -1 作为哨兵。
- 注意区分子序列与子串：子序列不要求连续，这正是双指针可以跳跃匹配的原因。

**变体与追问**：
- 不同的子序列（LC 115）：求 s 在 t 中作为子序列出现的个数，需 DP。
- 最短公共超序列（LC 1092）：LCS 的变形。
- 若 t 可修改、s 固定：可预处理 s 后对 t 做状态机匹配。

### C-058 长按键入 · 简单 · 字节

**题干**：你的朋友正在用键盘输入他的名字 `name`。偶尔会不小心**长按**某个键，导致该字符在 `typed` 中被输入一次或多次。给你两个字符串 `name` 和 `typed`，如果 `typed` 可能是 `name` 的输入结果（考虑长按），返回 `true`，否则返回 `false`。

**示例**：`输入: name = "alex", typed = "aaleex"` → `输出: true`（长按 a 和 e）

**思路**：
- 暴力：正则把 typed 中连续重复压成一个字符再与 name 比，但会丢失"name 自身也含连续重复"的信息，不可靠。
- 最优：**双指针**。`i` 走 name、`j` 走 typed。若 `name[i] === typed[j]` 则同时前进；否则若 `typed[j] === typed[j-1]`（说明这是长按产生的多余字符）则只让 `j` 前进；否则直接 false。循环结束后要求 `i === name.length`，且 `typed` 剩余字符必须全部等于 `typed[j-1]`（尾部多余的长按）。

**代码**：
```javascript
function isLongPressedName(name, typed) {
  let i = 0;
  let j = 0;
  while (j < typed.length) {
    if (i < name.length && name[i] === typed[j]) {
      i++;
      j++;
    } else if (j > 0 && typed[j] === typed[j - 1]) {
      j++;                 // 长按产生的重复字符，跳过
    } else {
      return false;        // 既不是当前待匹配字符，也不是长按
    }
  }
  return i === name.length; // name 必须全部匹配完
}

console.log(isLongPressedName("alex", "aaleex"));   // true
console.log(isLongPressedName("saeed", "ssaaedd")); // false（e 少了一个）
console.log(isLongPressedName("laiden", "laiden")); // true
console.log(isLongPressedName("pyplrz", "ppyypllr")); // false
```

**复杂度**：时间 O(|name| + |typed|)，空间 O(1)。

**易错点**：
- typed 尾部可能有额外长按字符，靠 `typed[j] === typed[j-1]` 分支自然消化，循环条件用 `j < typed.length`。
- `name` 未匹配完必须返回 false（如 name="abc"、typed="ab"）。
- `j > 0` 的判断防止首字符就越界比较。
- 不能用"压缩后相等"简单判断，因为 name 自身也可能有连续重复（如 "saeed"）。
- 若 typed 出现 name 中完全没有的新字符，会走 else 分支直接判 false。

**变体与追问**：
- 允许 typed 少字符（非长按场景）：就退化成判断子序列。
- 若要求 keypress 次数不超过某个上限：在双指针基础上额外计数。
- 相似题"验证回文串 II"：也是双指针 + 放宽一个条件。

### C-059 压缩字符串 · 中等 · 字节/阿里

**题干**：给你一个字符数组 `chars`，请使用**原地**算法将其压缩。压缩规则：连续重复字符若长度为 1 则保留该字符；若大于 1 则在字符后追加其长度（多位数字逐位写成字符）。压缩后的结果必须存回 `chars` 的前部分，返回压缩后的新长度。

**示例**：`输入: chars = ["a","a","b","b","c","c","c"]` → `输出: 6, chars 前 6 位为 ["a","2","b","2","c","3"]`

**思路**：
- 暴力：新建字符串拼接再拷回，O(n) 额外空间。
- 最优：**读写双指针**。`read` 遍历并统计当前字符连续出现次数 `count`；`write` 指向下一个写入位置。先写字符本身，若 `count > 1` 则把 `count` 的每一位数字转成字符依次写入（注意多位数字，如 12 要写 '1'、'2'）。由于 `write` 始终不超过 `read`，原地覆盖是安全的。O(n) 时间、O(1) 空间。

**代码**：
```javascript
function compress(chars) {
  let write = 0;   // 写入位置
  let read = 0;    // 读取位置
  const n = chars.length;

  while (read < n) {
    const ch = chars[read];
    let count = 0;
    // 统计当前字符连续出现次数
    while (read < n && chars[read] === ch) {
      read++;
      count++;
    }
    chars[write++] = ch;              // 先写字符
    if (count > 1) {
      // 多位数字逐位写入
      for (const d of String(count)) {
        chars[write++] = d;
      }
    }
  }
  return write;
}

const c1 = ["a","a","b","b","c","c","c"];
console.log(compress(c1), c1.slice(0, 6)); // 6 ["a","2","b","2","c","3"]

const c2 = ["a"];
console.log(compress(c2), c2);             // 1 ["a"]

const c3 = ["a","b","b","b","b","b","b","b","b","b","b","b","b"];
console.log(compress(c3), c3.slice(0, 4)); // 4 ["a","b","1","2"]
```

**复杂度**：时间 O(n)，空间 O(1)。

**易错点**：
- `count === 1` 时**不写**数字。
- 数字可能是多位，必须逐位写成字符（`String(count)` 展开），不能直接 `chars[write++] = count`。
- 写入的是**字符**而不是数字类型，`chars` 每个元素是单字符字符串。
- 原地覆盖时 `write <= read` 恒成立，但如果先把字符写出去再统计也未尝不可，注意别破坏待读数据。

**变体与追问**：
- 若允许额外空间：直接用正则 `replace(/(.)\1*/g, ...)` 更短，但失去 O(1) 空间。
- 字符串压缩（LC 443 的字符串版）：返回压缩后的字符串即可。
- 解码字符串（LC 394）：压缩的逆过程，需要栈处理嵌套。

### C-060 救生艇 · 中等 · 腾讯/美团

**题干**：给定数组 `people`，`people[i]` 表示第 `i` 个人的体重，船的数量不限，每艘船最多载**两人**，且载重总和不能超过 `limit`。每个人体重都不超过 `limit`。返回载到每个人所需的**最少**船数。

**示例**：`输入: people = [1,2], limit = 3` → `输出: 1`（两人同船，总重 3）

**思路**：
- 暴力：枚举所有人的分组方案，指数级。
- 最优：**排序 + 对撞双指针**。排序后让最重的人 `j` 与最轻的人 `i` 尝试同船：若 `people[i] + people[j] <= limit` 则两人一起走、`i++`、`j--`；否则最重的人无法与任何人同船（连最轻的都超重），只能独自一船、`j--`。每轮必消耗一艘船，贪心选择"能带就带最轻的"不会使解变差，因此得到最少船数。O(n log n) 排序 + O(n) 双指针。

**代码**：
```javascript
function numRescueBoats(people, limit) {
  people.sort((a, b) => a - b); // 升序，便于双指针
  let i = 0;
  let j = people.length - 1;
  let boats = 0;

  while (i <= j) {
    // 最轻 + 最重能同船就一起走，否则最重独自一船
    if (i < j && people[i] + people[j] <= limit) {
      i++;
    }
    j--;
    boats++; // 每轮至少送走最重的人
  }
  return boats;
}

console.log(numRescueBoats([1, 2], 3));           // 1
console.log(numRescueBoats([3, 2, 2, 1], 3));     // 3
console.log(numRescueBoats([3, 5, 3, 4], 5));     // 4
```

**复杂度**：时间 O(n log n)（排序主导），空间 O(1)/O(log n)（排序栈）。

**易错点**：
- 每艘船最多两人，不是"能装多少装多少"。
- 排序不能省：不排序无法保证"最重配最轻"的贪心正确。
- 循环条件 `i <= j`，当只剩一人时也要单独一船。
- JS 默认 `sort()` 按字符串比较，必须传 `(a,b)=>a-b`。

**变体与追问**：
- 若每艘船可载多人：变成装箱问题，贪心不再最优（NP-hard），需近似或 DP。
- 若船有不同的载重与成本：升级为区间贪心/DP。
- 证明要点：最重的人若能与最轻的同船，则一定存在最优解让他们同船（交换论证），因此贪心不失最优性。
