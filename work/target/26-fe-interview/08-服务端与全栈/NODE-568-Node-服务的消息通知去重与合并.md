## NODE-568：通知去重与合并
**答**:
- 去重层：事件级去重（同事件 ID 幂等——重复事件不发）、内容级去重（同用户同内容窗口内只发一次——去重键：uid+模板+关联对象+窗口）、已读联动（用户已看过（端上回执）→ 不再推送重复）。
- 合并层：同类型聚合（"3 人赞了你"——计数合并：聚合窗口内同类型事件计数合并为一条，ARC-394）、摘要合并（多渠道摘要——IM 一条 + 站内信一条 + push 一条（同消息多渠道不重复轰炸——渠道互斥策略））。
- 频控与勿扰：用户级频控（每天上限/每场景上限——NODE-453）、勿扰时段（夜间延迟到早间发送——延迟队列）、退订生效（偏好变更即时拦截 NODE-523）。
- 实现：通知管道（事件 → 去重检查 → 聚合缓冲 → 频控 → 渠道分发——管道各层可配置）、聚合缓冲（Redis 缓冲窗口 + 定时 flush 合并发送）。
- 观测：去重率/合并率/频控拦截率（通知健康指标——防轰炸有效性）。
```javascript
async function notify(msg) {
  if (await dedup.check(msg.key, { window: '10m' })) return;     // 内容级去重
  await aggBuffer.add(msg, { window: '5m' });                    // 聚合缓冲
}
// flush: 同类 N 条 → 合并为"N 人赞了你" → freq.allow(uid) → dispatch(channels)
```
