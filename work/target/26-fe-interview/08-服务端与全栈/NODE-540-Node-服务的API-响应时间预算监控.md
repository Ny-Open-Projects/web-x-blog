## NODE-540：响应时间预算监控
**答**:
- 预算体系落地（NODE-489 分层 → 监控闭环）：每接口声明预算（分层 tier + 具体值）→ 指标按预算归一化（预算达成率 = P95 / budget——跨接口可比）、预算违约看板（超预算接口清单——NODE-518 慢接口治理的数据源）。
- 监控维度：静态预算达标率（周报）、动态劣化检测（预算达成率周环比下降——新劣化预警 NODE-582 前端归因的服务端版）、预算与实际分布对比（P50/P95/P99 与预算的关系——P99 爆表 P95 达标 = 长尾问题单独处理）。
- 告警分级：单接口持续违约（治理工单）、核心接口违约（立即告警——SLA 关联 NODE-431）、预算变更审计（调预算要走评审——防"指标变慢就调预算"的阈值通胀 ARC-547）。
- 与前端联动：接口预算与前端等待体验对齐（前端页面预算分解到接口——ARC-546/583 映射）。
- 度量：全站预算达成率趋势（治理效果总指标）、预算覆盖度（多少接口有预算——覆盖率提升计划）。
```javascript
// 预算达成率
const budgets = { '/goods/detail': { tier: 'fast', p95: 200 }, '/report/gen': { tier: 'slow', p95: 2000 } };
metrics.gauge('budget.ratio', p95(route) / budgets[route].p95);   // <1 达标
// 周报：违约接口清单按 impact 排序 → 治理例会输入
```
