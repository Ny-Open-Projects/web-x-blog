## NODE-593：审核工作台协议
**答**:
- 队列协议：任务项（内容 + 上下文（用户/关联对象/机审置信度——辅助判断信息）+ 优先级 + 时效）、领取模型（抢单 vs 分配——负载与时效平衡）、处理协议（通过/拒绝（原因结构化——逐级原因树）/上报（疑难转资深））。
- 一致性体验：审核 SLA（队列时效——积压告警）、任务去重（同人同内容多渠道——合并处理）、双审（高风险内容双人审核——一致性要求）。
- 质量体系：抽检复核（按比例质检——审核员质量分）、标准沉淀（案例库：相似案例历史判定——一致性辅助）、误判反馈（申诉成立 → 反馈审核员/规则——质量闭环 ARC-547）。
- 审核记录：每次判定留痕（内容快照/判定人/理由——可追溯，NODE-442）、审核统计（效率/准确率——运营）。
- 协议扩展：多内容类型（文本/图片/视频片段——各类型 viewer 协议——前端渲染器注册）。
```javascript
// 队列任务协议
task = { id, content: { type: 'video', url, clip }, context: { user, history, machine: { verdict, score } },
  priority, sla }
// 动作：approve / reject({ reasonTree }) / escalate —— 判定留痕 audit.log
// 质检：sample(rate) → qcQueue —— 复核一致率
```
