## NODE-610：Node 版本升级演练
**答**:
- 升级灰度流程（NODE-420 的执行细化）：双镜像准备（新旧 Node 双版本镜像同代码——可并跑对比）、灰度指标对比（新旧版本实例 5% 对比 48h：错误率/P95/内存/GC——版本差异量化）、逐步放量（10%→50%→100%——每步观察窗口）、回滚演练（升级中途回滚——镜像回退验证 ARC-477）。
- 行为差异专项验证：事件循环时序敏感用例（微任务顺序依赖的测试）、加密/TLS 行为（OpenSSL 版本差异——握手/证书兼容）、原生模块（重编译后压测——ABI 兼容下性能与稳定性）、依赖矩阵（全部依赖在新 Node 下测试——CI 矩阵）。
- 性能对比方法：同机同流量 A/B（新旧版本实例并行接流量——同请求对比）、GC 特征对比（新 V8 的 GC 行为变化——停顿分布对比）、内存水位对比（RSS 趋势——内存行为差异）。
- 升级季协同（NODE-536）：多服务统一窗口——平台提供升级 PR 模板/检查清单/回归套件。
- 记录沉淀：升级报告（差异清单/性能数据/问题与解决——下个版本的升级手册）。
```yaml
# 升级灰度编排
node-upgrade:
  images: { old: node20, new: node22 }   # 同代码双镜像
  canary: { newShare: 5%, watch: 48h, metrics: [errRate, p95, rss, gcPause] }
  rollout: [10%, 50%, 100%]
  rollback-drill: true       # 升级中途演练回滚
```
