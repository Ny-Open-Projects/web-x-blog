## XP-367：跨端定位地图组件的性能（瓦片加载）

**答**：
- 瓦片：按视口+缩放级别请求，预加载移动方向 1 屏；瓦片缓存（LRU 200 块）。
- 性能：SVG 标记 > 1000 个转 Canvas 图层；聚类（zoom 小时聚合 POI）。
- 降级：地图 SDK 加载失败 -> 静态地图图 + 文字地址。

```javascript
// 瓦片管理
class TileManager {
  constructor(cacheSize = 200) { this.cache = new Map(); this.size = cacheSize; }
  get(z, x, y) {
    const key = `${z}/${x}/${y}`;
    if (this.cache.has(key)) {
      const v = this.cache.get(key);
      this.cache.delete(key); this.cache.set(key, v);  // LRU
      return v;
    }
    return null;
  }
  put(key, tile) {
    this.cache.set(key, tile);
    while (this.cache.size > this.size)
      this.cache.delete(this.cache.keys().next().value);
  }
}
```
