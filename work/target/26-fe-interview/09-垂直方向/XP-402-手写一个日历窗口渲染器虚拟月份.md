## XP-402：手写一个日历窗口渲染器（虚拟月份）

**答**：
- 需求：implement CalendarVirtual(monthsBack=6, monthsFwd=6)。window(centerMonth) 返回 ±offset 月数据（{ year, month, days, firstWeekday }）；shift(direction) 平移窗口并复用已有月数据（缓存 Map）；输出月数组。
- 边界：offset 缺省 6；月数据缓存上限 24 淘汰最远；days 用 Date 计算；闰年正确。
- 评分点：窗口平移；月缓存；闰年；LRU 淘汰

```javascript
class CalendarVirtual {
  constructor(offset = 6) {
    this.offset = offset; this.cache = new Map();
  }
  monthData(y, m) {                                  // m: 1-12
    const key = `${y}-${m}`;
    if (this.cache.has(key)) return this.cache.get(key);
    const first = new Date(y, m - 1, 1);
    const data = { year: y, month: m,
      days: new Date(y, m, 0).getDate(),
      firstWeekday: (first.getDay() + 6) % 7 };      // 周一为 0
    this.cache.set(key, data);
    while (this.cache.size > 24)
      this.cache.delete(this.cache.keys().next().value);
    return data;
  }
  window(center) {
    const out = [];
    for (let i = -this.offset; i <= this.offset; i++) {
      const d = new Date(center.year, center.month - 1 + i, 1);
      out.push(this.monthData(d.getFullYear(), d.getMonth() + 1));
    }
    return out;
  }
}
```
