## XP-231：小程序性能专项：setData 优化实践汇总（笔试）

**答**：
- 题目：小程序 setData 优化综合题——给定场景（长列表滚动+实时更新），写出优化方案（路径更新/合并/节流/骨架）。
- 思路：① 路径更新（只传变化字段，ALG-470）；② 同帧合并（HW-671）；③ 滚动节流（onPageScroll 节流 16ms）；④ 骨架屏（数据异步加载占位）。
- 评分点：四类手段齐全；路径写法正确；量化收益。

```javascript
// 场景：列表页滚动 + 实时价格更新
class OptimizedList {
  updatePrice(itemId, newPrice) {                                 // ① 路径更新（非全量）
    const index = this.data.list.findIndex(i => i.id === itemId);
    this.setData({ [`list[${index}].price`]: newPrice });           // 只传变化字段
  }
  batchUpdate(updates) {                                           // ② 同帧合并
    const patch = {};
    updates.forEach(({ index, field, value }) => {
      patch[`list[${index}].${field}`] = value;                     // 合并为一次 setData
    });
    this.setData(patch);                                             // 一次跨线程传输
  }
  onScroll() {                                                     // ③ 滚动节流
    if (this.scrollTimer) return;
    this.scrollTimer = setTimeout(() => {
      this.scrollTimer = null;
      this.setData({ scrollTop: this.lastScrollTop });
    }, 16);
  }
}
// 量化：全量 setData（5KB/次）→ 路径合并（200B/次）→ 传输量降 96%
```
