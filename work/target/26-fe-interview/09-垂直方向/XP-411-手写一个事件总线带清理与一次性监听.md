## XP-411：手写一个事件总线（带清理与一次性监听）

**答**：
- 需求：implement EventBus。on(event, fn) 返回取消函数；once(event, fn) 触发一次自动移除；emit(event, payload)；listenerCount(event)；off(event) 清空该事件。
- 边界：emit 无监听静默；once 在 emit 中移除自身不影响其他监听器；同一 fn 重复 on 去重。
- 评分点：取消函数；once 语义；去重；计数

```javascript
class EventBus {
  constructor() { this.map = new Map(); }
  on(event, fn) {
    const set = this.map.get(event) ?? new Set();
    set.add(fn); this.map.set(event, set);
    return () => set.delete(fn);                       // 取消函数
  }
  once(event, fn) {
    const off = this.on(event, payload => {
      off(); fn(payload);                              // 先移除再执行
    });
    return off;
  }
  emit(event, payload) {
    [...(this.map.get(event) ?? [])].forEach(fn => fn(payload));
  }
  off(event) { this.map.delete(event); }
  listenerCount(event) { return this.map.get(event)?.size ?? 0; }
}
```
