## XP-418：手写一个键盘高度适配器

**答**：
- 需求：implement KeyboardAdapt(visualViewport)。onResize(cb) 触发时机：键盘弹起（height 变小 > 100px）/收起；提供 keyboardHeight() 估算（原高度 - 当前）；返回清理函数；回调带 { keyboardHeight }。
- 边界：首次触发忽略（初始化）；旋转屏幕（宽变高）重置基准； vv 不可用降级 focus/blur 估算。
- 评分点：高度估算；旋转重置；阈值判定；降级

```javascript
function KeyboardAdapt(vv, cb) {
  if (!vv) return () => {};
  let baseH = vv.height, lastH = vv.height;
  const handler = () => {
    const h = vv.height;
    if (baseH === lastH && h < lastH - 100) {          // 键盘弹起
      cb({ keyboardHeight: lastH - h, state: 'shown' });
    } else if (h > lastH + 100) {
      cb({ keyboardHeight: 0, state: 'hidden' });
    }
    if (Math.abs(vv.width - window.innerWidth) > 50)
      baseH = h;                                       // 旋转重置
    lastH = h;
  };
  vv.addEventListener('resize', handler);
  return () => vv.removeEventListener('resize', handler);
}
// iOS 键盘不触发 window resize，必须用 visualViewport
```
