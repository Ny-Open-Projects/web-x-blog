## XP-407：手写一个弹层栈管理器

**答**：
- 需求：implement ModalStack(baseZ=1000)。open(modal) 压栈分配 zIndex；close(modal) 弹栈；top() 当前顶层；closeAll()；焦点回落（close 后顶层 focus 回调）。
- 边界：重复 open 同实例忽略；close 不在栈中的忽略；栈空 top 返回 null；open 返回关闭函数。
- 评分点：栈管理；zIndex 分配；焦点回落；关闭函数

```javascript
class ModalStack {
  constructor(baseZ = 1000) { this.base = baseZ; this.stack = []; }
  open(modal) {
    if (this.stack.includes(modal)) return null;      // 忽略重复
    const zIndex = this.base + this.stack.length * 10;
    this.stack.push(modal);
    const closeFn = () => this.close(modal);
    return { zIndex, close: closeFn };
  }
  close(modal) {
    const i = this.stack.indexOf(modal);
    if (i < 0) return false;
    this.stack.splice(i, 1);
    this.top()?.focus?.();                            // 焦点回落
    return true;
  }
  closeAll() { const all = [...this.stack];
    this.stack = []; all.forEach(m => m.onClose?.()); }
  top() { return this.stack[this.stack.length - 1] ?? null; }
}
```
