## XP-229：跨端容器包完整性：资源引用校验（笔试）

**答**：
- 题目：容器 bundle 资源完整性——图片/字体等资源引用校验（构建期检查引用的资源存在于包内）、缺失兜底（占位图）。
- 思路：构建期扫描代码中的资源引用 → 与 manifest 资源清单比对（缺失报错）；运行时：资源加载失败 → 占位兜底（不白屏）。
- 评分点：构建期校验；运行时兜底；资源清单。

```javascript
// 构建期：资源引用校验
function verifyAssets(bundle) {
  const referenced = new Set();
  bundle.modules.forEach(m => {                                   // 扫描代码引用
    const matches = m.code.matchAll(/assets\/([\w.-]+)/g);
    matches.forEach(([, name]) => referenced.add(name));
  });
  const available = new Set(bundle.assets.map(a => a.name));
  const missing = [...referenced].filter(r => !available.has(r));   // 缺失资源
  if (missing.length) throw new Error(`missing-assets: ${missing}`);   // 构建报错
}
// 运行时：资源加载失败兜底
class AssetLoader {
  async load(name) {
    try { return await this.loadFromBundle(name); }
    catch { report('asset-missing', { name }); return PLACEHOLDER_IMAGE; }   // 占位图
  }
}
```
