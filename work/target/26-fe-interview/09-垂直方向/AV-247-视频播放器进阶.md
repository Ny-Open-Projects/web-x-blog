## AV-247：视频播放器进阶：硬解失败与软解降级

**答**：
- 硬解失败场景：编码格式不支持（H265 in Safari 老版）、DRM 未授权、硬件解码器资源耗尽。
- 降级链：硬解 → 软解（WebCodecs 无硬件加速回退，CPU 占用高）→ 换编码（服务端转码 H264）→ 提示换设备。
- 探测：VideoDecoder.isConfigSupported 预检（HW-AV-740 关联）。

```javascript
async function pickDecoder(config) {                       // 解码能力探测
  const hard = await VideoDecoder.isConfigSupported({ ...config, hardwareAcceleration: 'prefer-hardware' });
  if (hard.supported) return { mode: 'hardware', config };
  const soft = await VideoDecoder.isConfigSupported(config);
  if (soft.supported) return { mode: 'software', config,
    warning: '软解：CPU 占用高，建议 720p 以下' };
  // H265 不支持：请求服务端转码 H264（转码任务队列）
  const transcoded = await requestTranscode(config.codec, 'avc1.640028');
  return { mode: 'transcoded', config: transcoded.config, taskId: transcoded.taskId };
}
```
