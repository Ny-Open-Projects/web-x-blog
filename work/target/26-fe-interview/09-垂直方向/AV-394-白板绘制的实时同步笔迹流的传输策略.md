## AV-394：白板绘制的实时同步：笔迹流的传输策略

**答**：
- 笔迹特性：高频点流（60Hz 采样）——逐点同步浪费；分片（每 100ms 打包一段）+ 完成时整体确认。
- 策略：绘制中走不可达通道（丢点画糊无妨），完成时可达通道确认最终笔迹。
- 性能：远端实时渲染用简化折线（抽稀），完成后渲染完整贝塞尔。

```javascript
// 笔迹同步
class StrokeSync {
  constructor(ws) { this.ws = ws; this.current = null; this.points = []; }
  start(id) { this.current = id; this.points = []; }
  addPoint(p) {
    this.points.push(p);
    if (this.points.length % 6 === 0)                 // 每 6 点/约100ms 打包
      this.ws.sendUnreliable({ type: 'stroke-partial',
        id: this.current, points: simplify(this.points) });
  }
  end() {
    this.ws.sendReliable({ type: 'stroke-done',
      id: this.current, points: this.points });       // 最终可达
    this.current = null;
  }
}
function simplify(pts, tol = 1) {                     // Douglas-Peucker 简化
  return pts.filter((_, i) => i % 2 === 0 || i === pts.length - 1);
}
```
