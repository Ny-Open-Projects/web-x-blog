## AV-352：浏览器自动播放策略与视频起播

**答**：
- 规则：有声自动播放被禁（需用户手势或 MEI 高）；muted 可自动播放。
- 方案：muted 起播 + 静音按钮提示、用户手势后 unmute（点击任意处）、尝试 play() 失败捕获降级。
- 广告/直播场景：首帧交互解锁声音是标准 UX。

```javascript
// 自动播放处理
async function autoplaySmart(video) {
  try { await video.play(); return { unmuted: !video.muted }; }
  catch (e) {
    video.muted = true;
    try { await video.play();                                        // 静音起播
      const unlock = () => { video.muted = false;
        document.removeEventListener('pointerdown', unlock); };
      document.addEventListener('pointerdown', unlock, { once: true });
      return { unmuted: false, note: '待手势解锁声音' };
    } catch { return { started: false, note: '完全阻止，需显式点击' }; }
  }
}
```
