## AV-248：视频播放器预加载策略：带宽感知的缓冲目标

**答**：
- 缓冲目标动态化：快网络缓冲 30s（抗抖动）、慢网络缓冲 10s（省内存起播快）——bufferTarget 按 bandwidth 调整。
- ABR 联动：缓冲水位 + 带宽估计共同决定清晰度切换（不只看带宽）。
- 预加载下一集：剧集场景当前集播到 80% → 预加载下一集首段。

```javascript
class AdaptiveBuffer {
  constructor(player, { fastTarget = 30, slowTarget = 10 } = {}) {
    this.player = player; this.targets = { fast: fastTarget, slow: slowTarget };
  }
  async adjust(bandwidthBps) {                              // 带宽感知
    const target = bandwidthBps > 5e6 ? this.targets.fast : this.targets.slow;
    this.player.hls.config.maxBufferLength = target;
    // 切清晰度还要看 buffer 水位（防 OOM/卡顿）：
    const buffered = player.bufferedEnd();
    if (buffered < 5 && bandwidthBps < 2e6) forceDowngrade();   // buffer 危险 + 带宽差：强制降档
  }
  preloadNext(nextUrl, atRatio = 0.8) {                      // 预加载下一集
    this.player.on('timeupdate', () => {
      if (this.player.currentTime / this.player.duration > atRatio && !this.preloaded) {
        fetch(nextUrl, { headers: { Range: 'bytes=0-500000' } });   // 首段预拉
        this.preloaded = true;
      }
    });
  }
}
```
