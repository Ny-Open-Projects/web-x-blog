## XP-233：小程序场景专项：直播小程序实现（笔试）

**答**：
- 题目：小程序直播——live-pusher（推流）/live-player（拉流）组件接入、观众端布局、弹幕（WX 环形缓冲，HW-767 思想）。
- 思路：推流端：live-pusher 组件（url=RTMP）；观众端：live-player（url=FLV）；弹幕：WebSocket + 环形缓冲渲染；性能：弹幕用 canvas（HW-769 复用）。
- 评分点：组件接入；弹幕渲染；性能控制。

```javascript
// 观众端直播页
const livePage = {
  data: { playUrl: '', danmaku: [] },
  onLoad(query) {                                                  // 进房
    const { playUrl, roomId } = this.parseDeepLink(query);          // 深链解析
    this.setData({ playUrl });
    this.connectDanmaku(roomId);                                     // WS 弹幕
  },
  connectDanmaku(roomId) {                                           // 弹幕（洪泛控制）
    this.ws = wx.connectSocket({ url: `wss://dm/${roomId}` });
    this.ws.onMessage(({ data }) => {
      const msg = JSON.parse(data);
      if (this.danmakuBuffer.length > 30) return;                     // 洪泛丢弃
      this.danmakuBuffer.push(msg);
      if (!this.pending) this.pending = setTimeout(() => this.flush(), 100);   // 合帧
    });
  },
  flush() {                                                          // 批量渲染
    this.pending = null;
    const batch = this.danmakuBuffer.splice(0, 5);
    this.setData({ danmaku: this.data.danmaku.concat(batch).slice(-30) });   // 只保留 30 条
  },
}
```
