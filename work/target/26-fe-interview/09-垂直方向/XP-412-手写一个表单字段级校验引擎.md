## XP-412：手写一个表单字段级校验引擎

**答**：
- 需求：implement FormValidator(schema)。validateField(field, value, all) 只跑该字段规则；validateAll() 全量；规则 { validate, message, deps? }；deps 声明依赖字段（依赖变化时联动重校验）；输出 { errors, touched }。
- 边界：规则抛错按校验失败处理；errors 只含当前失败字段；schema 空 return 空。
- 评分点：字段级校验；规则异常；依赖声明；全量兜底

```javascript
class FormValidator {
  constructor(schema) { this.schema = schema; }
  validateField(field, value, all = {}) {
    const errors = {};
    for (const rule of this.schema[field] ?? []) {
      let ok = false;
      try { ok = rule.validate(value, all); } catch { ok = false; }
      if (!ok) { errors[field] = rule.message; break; }
    }
    return errors;
  }
  validateAll(values) {
    let errors = {};
    for (const field of Object.keys(this.schema))
      errors = { ...errors, ...this.validateField(field, values[field], values) };
    return { errors, valid: !Object.keys(errors).length };
  }
  depsOf(field) {
    return (this.schema[field] ?? [])
      .flatMap(r => r.deps ?? []);
  }
}
```
