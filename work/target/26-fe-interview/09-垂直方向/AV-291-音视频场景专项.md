## AV-291：音视频场景专项：直播间红包雨交互

**答**：
- 题目：红包雨——服务端定时投放红包（坐标/批次），前端动画下落 + 点击抢红包（防重复/限流）+ 中奖结果展示。
- 思路：投放事件 → 红雨动画（DOM 池或 Canvas）；点击命中判定（碰撞区域）；抢红包请求（幂等 ID 防重复）+ 限流（客户端每秒最多 N 次）。
- 评分点：动画性能（DOM 池）；命中判定；幂等防重。

```javascript
class RedPacketRain {
  onBatch(packets) {                                          // 批次投放
    packets.forEach(p => this.spawn(p));                     // 生成红包实例（DOM 池复用）
  }
  spawn(packet) {
    const el = this.pool.acquire();                           // DOM 池
    el.style.left = packet.x + '%';
    el.style.animation = `fall ${packet.duration}ms linear`;
    el.dataset.id = packet.id;
    el.onclick = () => this.grab(packet.id);
  }
  async grab(packetId) {                                      // 抢红包
    if (this.grabbed.has(packetId)) return;                   // 防重复（客户端）
    const res = await api.grab({ packetId,
      idempotencyKey: crypto.randomUUID() });                 // 幂等键
    this.grabbed.add(packetId);
    if (res.amount) this.showReward(res.amount);              // 中奖动画
  }
}
```
