## AV-314：音视频平台专项：观看端异常退出与断点续看

**答**：
- 题目：用户中途退出直播/点播——断点续看（再次进入从上次位置继续）+ 观看历史保存（含有效时长）。
- 思路：定期保存断点（currentTime）→ beforeunload/pagehide 补报（sendBeacon）→ 再次进入查询断点 → 询问续播或重看。
- 评分点：断点保存频率；补报；续播询问。

```javascript
class ResumePlayback {
  constructor(video, contentId) {
    this.contentId = contentId;
    setInterval(() => this.save(), 10000);                    // 10s 保存断点
    addEventListener('pagehide', () => this.save(true));       // 退出补报
  }
  save(final = false) {
    const payload = { contentId: this.contentId, position: this.video.currentTime,
      effectiveSeconds: this.tracker.effectiveSeconds, final };
    final ? navigator.sendBeacon('/watch-progress', JSON.stringify(payload))
      : api.saveProgress(payload);
  }
  async checkResume() {                                        // 再次进入
    const { position } = await api.getProgress(this.contentId);
    if (position > 30) {                                       // > 30s 才提示续播
      return { resumeFrom: position,
        prompt: `上次看到 ${formatTs(position)}，继续播放？` };
    }
    return { resumeFrom: 0 };
  }
}
```
