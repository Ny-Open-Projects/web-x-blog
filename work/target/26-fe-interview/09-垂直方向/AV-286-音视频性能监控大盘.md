## AV-286：音视频性能监控大盘：全局质量视图

**答**：
- 题目：音视频平台质量大盘——按地域/运营商/设备档聚合首帧/卡顿/MOS，自动发现劣化维度。复用 VIZ 专题可视化能力。
- 思路：指标采集（AV-213）→ 聚合入库 → 大盘（热力图=地域×指标，趋势图=时序，下钻=维度切换）；告警（VIZ-294 思想）。
- 评分点：聚合维度；大盘图表选型；告警规则。

```javascript
class QualityDashboard {
  aggregate(samples) {                                       // samples: 全量通话指标
    return {
      byRegion: groupAggregate(samples, { by: 'region',
        metrics: { firstFrame: 'p75', stallRate: 'avg', mos: 'avg' } }),
      byCarrier: groupBy(samples, 'carrier'),                // 运营商维度
      byDeviceTier: groupBy(samples, 'deviceTier'),          // 设备档维度
    };
  }
  render(container) {                                        // 大盘渲染
    mount(container, [
      { type: 'heatmap', data: this.byRegion, metric: 'mos' },   // 地域热力
      { type: 'timeseries', data: this.trend, metrics: ['firstFrame', 'stallRate'] },
      { type: 'bar', data: this.byCarrier, metric: 'mos' },   // 运营商对比
    ]);
  }
}
```
