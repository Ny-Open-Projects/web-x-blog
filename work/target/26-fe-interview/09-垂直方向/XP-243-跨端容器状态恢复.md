## XP-243：跨端容器状态恢复：应用重建后的状态还原（笔试）

**答**：
- 题目：应用崩溃/重启后状态还原——持久化关键状态（路由栈/表单/滚动位置）→ 启动时还原 → 用户无感恢复。
- 思路：定期快照（10s/关键操作后）→ 持久化（AsyncStorage/SQLite）→ 启动检测快照 → 询问/自动恢复。
- 评分点：快照时机；还原策略；用户确认。

```javascript
class StateRestoration {
  constructor(store) { this.store = store; this.startSnapshot(); }
  startSnapshot() {                                            // 定期快照
    setInterval(() => this.snapshot(), 10000);
    addEventListener('beforeunload', () => this.snapshot());     // 退出快照
  }
  snapshot() {
    const state = { route: currentRoute, formData: getFormData(),
      scrollPositions: getScrollPositions(), ts: Date.now() };
    persist(state);                                              // 持久化（HW-391 复用）
  }
  async restore() {                                              // 启动还原
    const snapshot = await readSnapshot();
    if (!snapshot || Date.now() - snapshot.ts > 3600e3) return;   // 过期丢弃
    navigateTo(snapshot.route);                                    // 路由还原
    restoreFormData(snapshot.formData);                             // 表单还原
    restoreScroll(snapshot.scrollPositions);                        // 滚动还原
    showToast('已恢复上次浏览状态');
  }
}
```
