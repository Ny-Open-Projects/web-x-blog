## AV-429：手写一个断线操作队列（离线编辑队列）

**答**：
- 需求：implement OfflineQueue。enqueue(op) 离线时入队（持久化 IndexedDB）；flush(sender) 逐条发送（每条确认后下一条，失败重试 2 次后保留队列）；输出 { sent, remaining }。
- 边界：opId 去重；队列顺序保持（FIFO）；持久化恢复后继续 flush；上限 5000 溢出提示。
- 评分点：FIFO；重试保留；持久化恢复；溢出告警

```javascript
class OfflineQueue {
  constructor() { this.q = []; this.seen = new Set(); }
  async enqueue(op) {
    if (this.seen.has(op.opId)) return;
    this.seen.add(op.opId);
    this.q.push(op);
    await idbAppend('offline-q', op);
    if (this.q.length > 5000) report({ type: 'queue-overflow' });
  }
  async flush(send) {
    const sent = [];
    while (this.q.length) {
      const op = this.q[0];
      let ok = false;
      for (let i = 0; i < 3 && !ok; i++) {
        try { await send(op); ok = true; }
        catch { await sleep(500 * (i + 1)); }
      }
      if (!ok) break;                                  // 保留剩余
      this.q.shift(); sent.push(op.opId);
      await idbRemove('offline-q', op.opId);
    }
    return { sent, remaining: this.q.length };
  }
}
```
