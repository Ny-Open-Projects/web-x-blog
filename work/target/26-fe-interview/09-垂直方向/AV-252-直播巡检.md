## AV-252：直播巡检：自动化质量拨测

**答**：
- 题目：直播平台自动巡检——定时用无头浏览器进直播间采集质量指标（首帧/卡顿/音量），异常告警。复用 HW-897 云真机思想。
- 思路：巡检任务队列（每直播间 5 分钟一次）；headless 挂载播放器采 metrics；异常（首帧 > 3s/静音）告警+截图留证。
- 评分点：巡检任务编排；指标采集；异常判定与留证。

```javascript
class LivePatrol {
  constructor(pool) { this.pool = pool; }                    // headless 实例池
  async patrol(roomId) {
    const browser = await this.pool.acquire();
    const page = await browser.newPage();
    await page.goto(`/live/${roomId}`);
    const metrics = await page.evaluate(() => new Promise((res) => {
      const player = window.__player__;
      const t0 = performance.now();
      player.on('first-frame', () => res({
        firstFrameMs: performance.now() - t0,
        audioLevel: player.getAudioLevel(),
        buffered: player.bufferedEnd(),
      }));
      setTimeout(() => res({ timeout: true }), 10000);      // 超时兜底
    }));
    const bad = metrics.timeout || metrics.firstFrameMs > 3000
      || (metrics.audioLevel ?? 0) < 0.01;
    if (bad) {
      await page.screenshot({ path: `/patrol/${roomId}.png` });   // 留证
      fire('live-patrol-alert', { roomId, metrics });
    }
    browser.close();
  }
}
```
