## AV-266：音视频会议场景：实时字幕与翻译

**答**：
- 实时字幕：音频流 → ASR 服务（WebSpeech API 或云 ASR）→ 字幕渲染叠加；翻译走第二层（MT 服务）。
- WebSpeech API：SpeechRecognition（Chrome，免费但受限）vs 云 ASR（稳定/多语言/自定义词库）。
- 实现：音频 track → 采样上传 → 字幕片段（带时间戳）→ 渲染同步（与播放进度对齐）。

```javascript
class LiveCaptions {
  async start(audioTrack, { lang = 'zh', translateTo = null } = {}) {
    const recognition = new (window.SpeechRecognition || webkitSpeechRecognition)();
    recognition.lang = lang; recognition.continuous = true;
    recognition.interimResults = true;                       // 中间结果（低延迟）
    recognition.onresult = (e) => {
      const latest = e.results.at(-1);
      this.renderCaption({ text: latest[0].transcript, final: latest.isFinal });
      if (latest.isFinal && translateTo) this.translate(latest[0].transcript, translateTo);
    };
    // WebSpeech 不能直接吃 track——需云 ASR 时：track → AudioWorklet 采样 → WS 上传
  }
  async translate(text, to) {
    const { translation } = await mtService.translate(text, to);
    this.renderTranslation(translation);                     // 双行字幕（原文+译文）
  }
}
```
