## AV-437：手写一个视频转码任务进度聚合器

**答**：
- 需求：implement TranscodeAggregator(tasks)。tasks 为 [{ id, stages: [{ name, progress }], total } ]；overall(id) = 已完成阶段权重和 + 当前阶段进度×权重；权重均分；completed(id) 当 overall >= 100；批量 summary() 输出 { done, running, avg }。
- 边界：stages 顺序执行（后阶段进度 0）；progress clamp [0,100]；未知 id 返回 null。
- 评分点：阶段权重；顺序执行；clamp；批量汇总

```javascript
class TranscodeAggregator {
  constructor(tasks) { this.tasks = new Map(tasks.map(t => [t.id, t])); }
  overall(id) {
    const t = this.tasks.get(id);
    if (!t) return null;
    const per = 100 / t.stages.length;
    return +t.stages.reduce((s, st, i) => {
      const p = Math.min(100, Math.max(0, st.progress));
      return s + (st.done ? per : (i === t.stages.findIndex(x => !x.done) ? p / t.stages.length : 0));
    }, 0).toFixed(1);
  }
  summary() {
    const all = [...this.tasks.values()];
    const done = all.filter(t => this.overall(t.id) >= 100);
    const running = all.filter(t => this.overall(t.id) < 100);
    return { done: done.length, running: running.length,
      avg: +(all.reduce((s, t) => s + this.overall(t.id), 0) / (all.length || 1)).toFixed(1) };
  }
}
```
