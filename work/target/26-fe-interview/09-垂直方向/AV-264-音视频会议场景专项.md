## AV-264：音视频会议场景专项：入会门槛与设备预检

**答**：
- 题目：入会前设备预检页——权限检测/设备枚举/网络测速/扬声器回环测试，全过才入会（不过给降级建议）。
- 思路：① 权限探测（getUserMedia 抛错分类）；② 设备枚举（无摄像头提示纯音频）；③ 网络测速（fetch 大文件估算带宽/ICE 探测 RTT）；④ 回环测试（录 2s 播回验证麦克风）。
- 评分点：四步预检；降级建议；预检结果缓存。

```javascript
async function prejoinCheck() {
  const result = { mic: false, camera: false, network: false, speaker: false };
  try {                                                     // ① 权限+设备
    const stream = await navigator.mediaDevices.getUserMedia({ audio: true, video: true });
    result.mic = stream.getAudioTracks().length > 0;
    result.camera = stream.getVideoTracks().length > 0;
    const settings = stream.getAudioTracks()[0].getSettings();
    result.network = await measureBandwidth() > 1e6;        // ③ 带宽 > 1Mbps
    result.speaker = await loopbackTest(stream);            // ④ 回环：录 2s 播回测音量
  } catch (e) {
    result.permissionError = e.name;                        // NotAllowedError/NotFoundError
  }
  return { ...result,
    advice: !result.network ? '建议切换到 WiFi' : !result.camera ? '将以纯音频模式入会' : null };
}
```
