## XP-176：跨端容器推送通知：本地通知与远程推送

**答**：
- 题目：容器内业务触发本地通知（定时提醒）+ 远程推送（服务端触发）→ 点击通知路由到容器内页面（深链）。
- 思路：本地通知（Native API 定时触发）；远程推送（APNs/FCM）→ 点击 → 深链（scheme/route）→ 容器路由解析 → 页面跳转。
- 评分点：本地通知 API；深链路由解析；推送权限。

```javascript
class NotificationBridge {
  async scheduleLocal(notification) {                         // 本地定时通知
    return nativeNotify.schedule({
      id: notification.id, title: notification.title,
      body: notification.body,
      trigger: { type: 'time', at: notification.fireAt },      // 定时触发
      deepLink: notification.route,                             // 点击跳转
    });
  }
  onNotificationTap(deepLink) {                                // 点击 → 深链路由
    const url = new URL(deepLink, 'app://container');
    const route = url.pathname + url.search;                    // 解析路由
    this.navigator.push(route);                                 // 容器路由跳转
  }
  async requestPermission() {                                   // 推送权限
    const granted = await nativeNotify.requestPermission();
    if (!granted) showSettingsGuide();                            // 引导去设置
    return granted;
  }
```
