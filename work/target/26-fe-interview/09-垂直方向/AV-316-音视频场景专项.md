## AV-316：音视频场景专项：直播礼物连击与全屏特效触发

**答**：
- 题目：礼物连击（连续送礼累积）→ 达到阈值触发全屏特效——连击窗口（3s 内累积）、阈值判定、特效队列。
- 思路：连击计数（同用户同礼物 3s 窗口累积）；阈值表（10/50/100 触发不同特效）；特效队列（AV-257 复用）。
- 评分点：连击窗口逻辑；阈值判定；特效触发。

```javascript
class GiftComboTracker {
  constructor({ windowMs = 3000 } = {}) { this.combo = new Map(); }
  onGift({ userId, giftId, count }) {
    const key = `${userId}:${giftId}`;
    const cur = this.combo.get(key) ?? { count: 0, timer: null };
    clearTimeout(cur.timer);
    cur.count += count;
    cur.timer = setTimeout(() => this.combo.delete(key), this.windowMs);   // 窗口重置
    this.combo.set(key, cur);
    const tier = COMBO_THRESHOLDS.find(t => cur.count >= t.min && cur.count < t.max);
    if (tier && tier.effect !== this.lastEffect?.[key]) {       // 达到新阈值
      this.triggerEffect(tier.effect, { userId, giftId, total: cur.count });
    }
    return { comboCount: cur.count, tier };
  }
}
```
