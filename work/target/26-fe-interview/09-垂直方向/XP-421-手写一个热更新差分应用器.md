## XP-421：手写一个热更新差分应用器

**答**：
- 需求：implement DiffApplier(bsdpPatchFn)。apply(localBundle, patchUrl, sigVerify)：下载 patch -> 应用 -> 校验结果 hash -> 原子替换（失败回滚保留原版本）；输出 { ok, version }。
- 边界：patch 下载失败走整包兜底；校验失败回滚（不应用）；应用过程写入临时文件后 rename（原子）；回调上报每步。
- 评分点：差分优先；签名门控；原子写；整包兜底

```javascript
class DiffApplier {
  constructor(bsdpPatchFn) { this.patch = bsdpPatchFn; }
  async apply(localBundle, patchUrl, sigVerify, { fullUrl } = {}) {
    try {
      const patchData = await download(patchUrl);
      const next = await this.patch(localBundle, patchData);
      if (!(await sigVerify(next)))
        throw new Error('签名校验失败');
      await atomicWrite(next);
      return { ok: true, mode: 'diff' };
    } catch (e) {
      report({ type: 'diff-fail', msg: e.message });
      if (fullUrl) {
        const full = await download(fullUrl);          // 整包兜底
        if (await sigVerify(full)) {
          await atomicWrite(full);
          return { ok: true, mode: 'full' };
        }
      }
      return { ok: false, rollback: true };            // 保留原版本
    }
  }
}
```
