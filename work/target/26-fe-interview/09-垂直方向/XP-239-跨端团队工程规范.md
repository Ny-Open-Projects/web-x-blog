## XP-239：跨端团队工程规范：代码评审清单（笔试）

**答**：
- 题目：跨端容器代码评审清单——桥调用规范（批量/瘦身）、性能红线（ setData 量/列表窗口）、安全红线（非白名单 API）、内存红线（页面栈深度）。
- 思路：评审 checklist（PR 模板自动化检查部分 + 人工审查部分）；lint 自动化（ setData 量/非白名单 import）。
- 评分点：清单分类；自动化与人工分工；红线量化。

```javascript
const reviewChecklist = {
  automated: [
    '桥 payload < 256KB（lint：JSON.stringify 长度检查）',
    '非白名单 import 拒绝（eslint no-restricted-imports）',
    '硬编码颜色拒绝（必须走 token）',
    '页面栈深度 > 8 警告',
  ],
  manual: [
    'setData 是否路径更新/合并（而非全量）',
    '列表是否惰性 + 稳定 key',
    '新增 Native API 是否在白名单内（安全评审）',
    '内存：是否有定时器/监听器未清理',
    '降级：低端机是否测试过',
  ],
  pr: 'PR 模板内置 checklist——未勾选不允许合并',
};
```
