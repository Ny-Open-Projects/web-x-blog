## XP-248：跨端容器数据同步：本地与服务端双向同步（笔试）

**答**：
- 题目：容器离线数据双向同步——本地写队列 + 服务端拉增量 + 冲突解决（LWW/字段级合并）。复用 HW-336。
- 思路：本地变更日志（op/seq）→ 恢复网络推送；服务端增量拉取（lastSeq 游标）；冲突：LWW（时间戳）或字段级合并。
- 评分点：变更日志；游标拉取；冲突策略。

```javascript
class TwoWaySync {
  constructor(localDB) { this.db = localDB; this.lastServerSeq = 0; this.localOps = []; }
  localWrite(entity) {                                           // 本地写
    this.db.put(entity);
    this.localOps.push({ entity, ts: Date.now() });               // 变更日志
  }
  async sync() {                                                  // 双向同步
    await this.pushLocal();                                        // 推本地
    const { changes, lastSeq } = await api.pullChanges(this.lastServerSeq);   // 拉服务端
    changes.forEach(c => this.applyRemote(c));                     // 应用远端
    this.lastServerSeq = lastSeq;
  }
  applyRemote(remote) {                                            // 冲突处理
    const local = this.db.get(remote.id);
    if (!local || remote.ts > local.ts) this.db.put(remote);       // LWW
    else if (remote.ts === local.ts) this.fieldMerge(local, remote);   // 字段级合并
  }
}
```
