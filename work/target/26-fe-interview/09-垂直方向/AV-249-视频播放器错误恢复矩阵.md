## AV-249：视频播放器错误恢复矩阵：从解码错误到 CDN 切换

**答**：
- 题目：播放器错误恢复矩阵——错误类型（网络/解码/CDN/DRM）× 恢复动作（重试/切源/降级/提示）。完整实现调度器。
- 思路：错误分类 → 恢复动作映射表；重试带退避；CDN 切换（多 CDN 容灾，ALG-892 思想）；DRM 错误提示换授权。
- 评分点：错误分类完整；恢复动作矩阵；重试退避。

```javascript
class PlaybackErrorRecovery {
  constructor(player, cdnUrls) { this.player = player; this.cdns = cdnUrls; this.cdnIdx = 0; }
  async onError(error) {
    const kind = classify(error);                           // network/decode/cdn/drm
    const actions = {
      network: () => retryWithBackoff(() => this.player.reload(), 3),   // 网络重试
      decode: () => this.switchCodec(),                        // 解码：换编码/软解
      cdn: () => this.switchCDN(),                             // CDN：切源
      drm: () => this.promptLicense(),                         // DRM：提示授权
    };
    await actions[kind]?.();
  }
  async switchCDN() {                                        // CDN 切换
    this.cdnIdx = (this.cdnIdx + 1) % this.cdns.length;
    const ts = this.player.currentTime;                     // 保位置
    this.player.load(this.cdns[this.cdnIdx]);
    this.player.currentTime = ts;                            // 续播
    report('cdn-switch', { idx: this.cdnIdx });
  }
}
```
