## AV-313：音视频平台专项：直播封面与标题 A/B 测试

**答**：
- 题目：直播封面/标题 A/B——封面图两版分流（进入页随机），指标：点击进入率、观看时长。复用 HW-819 实验设计。
- 思路：封面 URL 带实验 bucket；指标采集（曝光→点击→观看时长）；显著性判定（HW-820 z 检验）。
- 评分点：分流实现；指标漏斗；显著性。

```javascript
class CoverExperiment {
  getCoverUrl(userId, covers) {                               // 封面分流
    const bucket = hashStr(userId) % 2;
    return { url: covers[bucket], variant: bucket === 0 ? 'A' : 'B' };
  }
  trackFunnel(userId, variant, event) {                       // 漏斗：曝光→点击→观看
    track('cover-funnel', { userId, variant, event });
  }
  async analyze() {
    const data = await queryFunnel(this.key);                  // 漏斗数据
    const ctrA = data.A.clicks / data.A.exposures;             // A 点击率
    const ctrB = data.B.clicks / data.B.exposures;
    const sig = significance(data.A.clicks, data.A.exposures,
      data.B.clicks, data.B.exposures);                        // z 检验（HW-820）
    return { ctrA: +ctrA.toFixed(3), ctrB: +ctrB.toFixed(3),
      significant: sig.significant, winner: sig.significant
        ? (ctrA > ctrB ? 'A' : 'B') : 'undetermined' };
  }
}
```
