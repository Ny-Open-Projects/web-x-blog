## AV-280：音视频播放器统计上报：观看时长与心跳

**答**：
- 题目：观看行为统计——有效观看时长（排除后台/暂停/静音）、心跳上报（30s 周期 + 关键事件即时）、退出补报。
- 思路：visibilitychange + playing 状态联合判定「有效观看」；心跳携带累计时长与断点；beforeunload/pagehide 补报（sendBeacon）。
- 评分点：有效观看判定；心跳协议；退出补报。

```javascript
class WatchTimeTracker {
  constructor(video, report) {
    this.effectiveSeconds = 0; this.lastTick = null;
    setInterval(() => this.tick(), 1000);                    // 每秒心跳
    document.addEventListener('visibilitychange', () => this.tick());   // 切后台结算
    addEventListener('pagehide', () => this.finalReport());   // 退出补报
  }
  tick() {
    const now = Date.now();
    const isValid = !document.hidden && !this.video.paused
      && !this.video.muted && this.video.readyState >= 3;
    if (isValid && this.lastTick) this.effectiveSeconds += (now - this.lastTick) / 1000;
    this.lastTick = now;
    if (now - this.lastReport > 30000) {                     // 30s 心跳
      report('watch-heartbeat', { effectiveSeconds: this.effectiveSeconds,
        position: this.video.currentTime });
    }
  }
  finalReport() { navigator.sendBeacon('/watch-final',       // 退出补报（不可取消）
    JSON.stringify({ effectiveSeconds: this.effectiveSeconds })); }
}
```
