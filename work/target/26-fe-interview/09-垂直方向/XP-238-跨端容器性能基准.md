## XP-238：跨端容器性能基准：低端机降级矩阵（笔试）

**答**：
- 题目：跨端容器低端机降级矩阵——动画/图片/列表/复杂效果按设备档位降级，降级开关服务端下发（HW-823 复用）。
- 思路：设备档（内存/CPU/历史帧率）→ 降级矩阵（低档：关动画/列表窗口减半/图片降档/关模糊）；服务端下发（不发版调整）。
- 评分点：降级矩阵；服务端下发；用户覆盖。

```javascript
const degradationMatrix = {
  low: { animation: false, listWindow: 5, imageQuality: 'low',
    blur: false, shadow: false, webgl: false },                    // 低档全关
  mid: { animation: 'reduced', listWindow: 10, imageQuality: 'mid',
    blur: true, shadow: true, webgl: true },
  high: {},                                                        // 高档全开
};
class DegradationManager {
  async apply(tier) {                                              // 分档应用
    const config = await fetchServerConfig(tier);                   // 服务端下发（可热调）
    const local = degradationMatrix[tier];
    const merged = { ...local, ...config };                          // 合并（服务端覆盖）
    bridge.commit([{ op: 'set-degrade-config', config: merged }]);
    this.userOverride?.(merged);                                     // 用户手动覆盖（设置页）
  }
}
```
