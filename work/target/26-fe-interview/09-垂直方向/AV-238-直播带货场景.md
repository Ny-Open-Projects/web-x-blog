## AV-238：直播带货场景：商品卡片与视频联动

**答**：
- 带货直播：讲解中商品卡片弹出（讲解中状态）、点击商品 → 不离开直播间的购买面板、库存实时刷新。
- 实现：讲解事件（信令/弹幕通道）→ 卡片入场动画；商品面板为独立层（视频层之上）；库存 WS 推送节流更新。
- 关键体验：点击不阻塞视频播放（面板侧滑而非全屏）。

```javascript
class LiveCommerce {
  onProductEvent({ type, product }) {                       // 讲解事件
    if (type === 'explaining') {
      this.card.show(product, { animation: 'slide-in', autoHideAfter: 300 });
      this.inventory.subscribe(product.id);                 // 订阅库存
    }
    if (type === 'finished') this.card.hide();
  }
  onInventory({ productId, stock }) {                       // 库存推送（节流）
    if (stock < 10) this.card.urgentStock(productId, stock);   // 库存紧张提示
  }
  openPanel(productId) {                                     // 点击商品：侧滑面板
    this.panel.show(productId);                              // 视频继续播放（不暂停）
    report('product-click', { productId, videoTimestamp: this.player.currentTime });
  }
}
```
