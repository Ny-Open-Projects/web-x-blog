## XP-203：小程序分包加载：主包/分包/独立分包

**答**：
- 题目：小程序分包——主包（启动必需 ≤2M）+ 分包（按需下载）+ 独立分包（不依赖主包可独立运行）。设计分包策略。
- 思路：主包只放启动页/公共组件/公共工具；业务分包按 tab/功能拆；独立分包（如活动页）不依赖主包——扫码直达不加载主包。
- 评分点：主包预算；分包边界；独立分包适用。

```javascript
// app.json 分包配置
const subpackages = [
  { root: 'pages/main', name: 'main', pages: ['index', 'detail'] },         // 主包外分包
  { root: 'pages/activity', name: 'activity', independent: true,            // 独立分包
    pages: ['promo'] },                                                      // 不依赖主包
  { preloadRule: { 'pages/main/index': { network: 'wifi', packages: ['activity'] } } },   // 预下载
};
// 分包边界：主包 ≤ 2M（启动必需）；单分包 ≤ 2M；总包 ≤ 20M
// 独立分包：扫码直达活动页（不加载主包）——启动最快但不能用主包组件/工具
// 预下载：进主包首页时 WiFi 预拉 activity 分包（点进去秒开）
```
