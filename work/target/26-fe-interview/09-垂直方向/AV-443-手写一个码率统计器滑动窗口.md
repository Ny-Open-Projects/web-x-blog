## AV-443：手写一个码率统计器（滑动窗口）

**答**：
- 需求：implement BitrateMeter(windowMs=5000)。push(bytes) 记录字节事件；rate() 返回窗口内 kbps；窗口滑出数据过期剔除；输出 { kbps, peak }。
- 边界：窗口无数据返回 0；bytes 累计（一次 push 可能很大）；peak 为历史窗口峰值；内存上限 1000 条。
- 评分点：滑动窗口；过期剔除；峰值记录；内存上限

```javascript
class BitrateMeter {
  constructor(windowMs = 5000) {
    this.win = windowMs; this.events = []; this.peak = 0;
  }
  push(bytes, now = Date.now()) {
    this.events.push({ bytes, at: now });
    if (this.events.length > 1000) this.events.shift();
  }
  rate(now = Date.now()) {
    this.events = this.events.filter(e => now - e.at <= this.win);
    const bytes = this.events.reduce((s, e) => s + e.bytes, 0);
    const kbps = Math.round(bytes * 8 / (this.win / 1000) / 1000);
    this.peak = Math.max(this.peak, kbps);
    return { kbps, peak: this.peak };
  }
}
// 用法：ws.onmessage = e => meter.push(e.data.byteLength);
```
