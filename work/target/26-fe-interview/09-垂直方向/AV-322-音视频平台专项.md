## AV-322：音视频平台专项：音视频资源预热与冷启动（笔试）

**答**：
- 题目：新直播间开播冷启动——SFU 资源预热（新房间预热 SFU worker）、CDN 预热（边缘缓存首帧）、推流端预连接。
- 思路：开播前（点击开播按钮）预热：SFU 分配 worker + CDN 预拉首帧 + RTMP 连接预建；开播时零冷启动。
- 评分点：预热时机；预热清单；冷启动耗时对比。

```javascript
class ColdStartPrewarm {
  async onStreamButtonPressed(roomId) {                       // 点击开播按钮（未推流）
    const tasks = await Promise.allSettled([
      sfuManager.prewarmWorker(roomId),                        // SFU worker 预热
      cdnManager.prewarmFirstFrame(roomId),                     // CDN 边缘预热
      rtmpClient.preconnect(roomId),                            // RTMP 连接预建
    ]);
    this.prewarmed = tasks.every(t => t.status === 'fulfilled');
    report('prewarm-done', { roomId, all: this.prewarmed,
      ms: Date.now() - start });                                // 预热耗时
  }
  async startPush(stream) {                                     // 真正推流
    if (this.prewarmed) {
      // 全部就绪：RTMP 直接复用预建连接 → 首帧到 CDN < 500ms
      await this.rtmpClient.push(stream);
    } else {
      // 预热失败：冷启动（首帧到 CDN 2~3s）——降级体验
      await this.coldStartPush(stream);
    }
  }
}
```
