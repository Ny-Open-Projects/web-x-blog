## AV-440：手写一个直播开播状态机

**答**：
- 需求：implement LiveStateMachine。状态：idle -> preparing(推流地址获取) -> live(首帧确认) -> paused -> ended；转换规则表校验（非法转换拒绝）；每转换发事件；输出 current 与 history。
- 边界：首帧确认由外部 fire first-frame；preparing 超时 10s 自动 ended(error)；重复 fire 同状态忽略。
- 评分点：状态机规则；非法拒绝；超时兜底；历史记录

```javascript
class LiveStateMachine {
  constructor({ prepareTimeout = 10_000 } = {}) {
    this.current = 'idle'; this.history = [];
    this.rules = {
      'idle->preparing': 1, 'preparing->live': 1, 'preparing->ended': 1,
      'live->paused': 1, 'paused->live': 1, 'live->ended': 1, 'paused->ended': 1,
    };
    this.prepareTimeout = prepareTimeout;
  }
  fire(event, payload) {
    const next = { 'start': 'preparing', 'first-frame': 'live',
      'pause': 'paused', 'resume': 'live', 'stop': 'ended', 'error': 'ended' }[event];
    if (!next) return { ok: false, reason: '未知事件' };
    const key = `${this.current}->${next}`;
    if (!this.rules[key]) return { ok: false, reason: `非法转换 ${key}` };
    this.history.push({ from: this.current, to: next, at: Date.now(), payload });
    this.current = next;
    if (next === 'preparing')
      this._timer = setTimeout(() => this.fire('error', 'preparing 超时'),
        this.prepareTimeout);
    if (next !== 'preparing') clearTimeout(this._timer);
    return { ok: true, state: next };
  }
}
```
