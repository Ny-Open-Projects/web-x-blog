## XP-391：手写一个预取命中率统计器

**答**：
- 需求：implement PrefetchStats。prefetch(key) 记录预取；consume(key) 标记消费；hitRate() = consumed/prefetched；未消费的预取（浪费）列 Top（按过期时间）；输出 { prefetched, consumed, hitRate, wasted }。
- 边界：重复 consume 只计一次；hitRate 保留 1 位；无预取返回 null；消费晚于 3s 记 slow。
- 评分点：命中统计；浪费列表；慢消费；空值

```javascript
class PrefetchStats {
  constructor() { this.map = new Map(); }
  prefetch(key, at = Date.now()) {
    this.map.set(key, { prefetchedAt: at, consumed: false, consumedAt: null });
  }
  consume(key, at = Date.now()) {
    const v = this.map.get(key);
    if (!v || v.consumed) return false;
    v.consumed = true; v.consumedAt = at;
    return true;
  }
  hitRate() {
    const all = [...this.map.values()];
    if (!all.length) return null;
    const consumed = all.filter(v => v.consumed);
    const wasted = all.filter(v => !v.consumed)
      .sort((a, b) => a.prefetchedAt - b.prefetchedAt).slice(0, 5);
    return { prefetched: all.length, consumed: consumed.length,
      hitRate: +(consumed.length / all.length * 100).toFixed(1) + '%',
      wasted: wasted.map(v => v.prefetchedAt),
      slow: consumed.filter(v => v.consumedAt - v.prefetchedAt > 3000).length };
  }
}
```
