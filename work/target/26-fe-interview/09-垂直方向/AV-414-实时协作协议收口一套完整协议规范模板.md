## AV-414：实时协作协议收口：一套完整协议规范模板

**答**：
- 规范包含：消息 schema（类型/字段/版本）、时序图（join/sync/cursor/stroke）、错误码、QoS 参数（心跳/超时/批量窗口）。
- 版本兼容：协议版本协商（hello 握手带 version），不兼容降级或拒绝。
- 验收：一致性测试（400）+ 压测（410）+ 演练（413）三关全过。

```javascript
// 协议规范对象
const PROTOCOL = {
  version: 3,
  messages: {
    hello: { fields: ['version', 'clientId', 'lastSeq'] },
    update: { fields: ['opId', 'update', 'lc'] },
    cursor: { fields: ['userId', 'anchor', 'head'] },
    stroke: { fields: ['id', 'points', 'final'] },
  },
  qos: { heartbeatMs: 5000, offlineAt: 30_000, batchWindowMs: 50 },
  errors: { 401: '未授权', 409: '版本冲突', 413: '消息超限' },
};
function negotiate(clientV, serverV) {
  return clientV === serverV ? 'ok' : clientV < serverV ? 'client-upgrade' : 'reject';
}
```
