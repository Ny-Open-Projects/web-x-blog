## AV-433：手写一个音视频指标采样聚合器

**答**：
- 需求：implement AVSampler(intervalMs=5000)。sample(fn) 定期拉取 getStats 结果聚合：rtt 均值/丢包率累计/码率均值；window(minutes) 输出 { rttP50, lossRate, bitrateAvg, samples }。
- 边界：samples < 5 输出 insufficient；丢包率 = 累计 lost / 累计 packets；分位用排序取值；stop 清定时器。
- 评分点：定时采样；窗口聚合；分位数；样本门槛

```javascript
class AVSampler {
  constructor(intervalMs = 5000) {
    this.rows = [];
    this.timer = setInterval(async () => {
      const s = await this.pull();
      if (s) this.rows.push(s);
    }, intervalMs);
  }
  async pull() { /* getStats 采集 rtt/lost/packets/bytes */ return null; }
  window(minutes = 5) {
    const cutoff = Date.now() - minutes * 60_000;
    const rows = this.rows.filter(r => r.at >= cutoff);
    if (rows.length < 5) return { state: 'insufficient', samples: rows.length };
    const rtts = rows.map(r => r.rtt).sort((a, b) => a - b);
    const lost = rows.reduce((s, r) => s + r.lost, 0);
    const packets = rows.reduce((s, r) => s + r.packets, 0);
    return { state: 'ok', samples: rows.length,
      rttP50: rtts[rtts.length >> 1],
      lossRate: packets ? +(lost / packets).toFixed(4) : 0,
      bitrateAvg: Math.round(rows.reduce((s, r) => s + r.kbps, 0) / rows.length) };
  }
  stop() { clearInterval(this.timer); }
}
```
