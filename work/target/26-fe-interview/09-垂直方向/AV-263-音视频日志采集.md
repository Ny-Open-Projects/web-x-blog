## AV-263：音视频日志采集：通话时间线与黑匣子

**答**：
- 题目：通话「黑匣子」——环形缓冲记录最近 30s 事件（stats 快照/信令/异常），异常时整体上报（HW-840 复用）。
- 思路：每秒采样 stats（RTT/丢包/帧率）入环形缓冲；错误/挂断时 dump 黑匣子上报；信令消息也入匣。
- 评分点：环形缓冲；异常触发 dump；时间线还原。

```javascript
class CallBlackBox {
  constructor({ windowMs = 30000 } = {}) { this.buf = []; this.windowMs = windowMs; }
  push(event) {                                             // 事件/stats 快照
    this.buf.push({ t: Date.now(), ...event });
    while (this.buf.length && Date.now() - this.buf[0].t > this.windowMs) this.buf.shift();
  }
  startSampling(pc) {                                       // 每秒采样
    setInterval(async () => {
      const stats = await pc.getStats();
      const v = [...stats.values()].find(r => r.type === 'inbound-rtp' && r.kind === 'video');
      this.push({ kind: 'stats', fps: v?.framesPerSecond, rtt: v?.roundTripTime,
        loss: v?.packetsLost });
    }, 1000);
  }
  dump(reason) {                                            // 异常/挂断时导出
    report('call-blackbox', { reason, timeline: [...this.buf] });
  }
}
```
