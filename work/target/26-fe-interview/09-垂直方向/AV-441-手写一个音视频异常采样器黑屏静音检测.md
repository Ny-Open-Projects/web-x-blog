## AV-441：手写一个音视频异常采样器（黑屏/静音检测）

**答**：
- 需求：implement AVAnomalySampler(video)。每 5s 检查：黑屏（drawImage 后像素全黑）、静音（analyser RMS < 0.001 持续 3 次）；输出异常事件 { type: black/silent, streak }。
- 边界：video paused/ended 不检测；黑屏判定阈值（亮度 < 10 占比 > 99%）；检测开销控制（抽样 1/16 像素）。
- 评分点：抽样检测；连续确认；状态排除；双通道

```javascript
class AVAnomalySampler {
  constructor(video) {
    this.video = video; this.streak = 0; this.timer = setInterval(() => this.check(), 5000);
    this.analyser = null;                             // 音轨接入后创建
  }
  check() {
    const v = this.video;
    if (v.paused || v.ended) return;
    const c = new OffscreenCanvas(160, 90);
    const ctx = c.getContext('2d', { willReadFrequently: true });
    ctx.drawImage(v, 0, 0, 160, 90);
    const px = ctx.getImageData(0, 0, 160, 90).data;
    let dark = 0, total = 0;
    for (let i = 0; i < px.length; i += 16) {         // 抽样 1/16
      const lum = 0.2126 * px[i] + 0.7152 * px[i+1] + 0.0722 * px[i+2];
      if (lum < 10) dark++;
      total++;
    }
    const black = dark / total > 0.99;
    const silent = this.analyser ? this.level() < 0.001 : false;
    this.streak = (black || silent) ? this.streak + 1 : 0;
    if (this.streak >= 2)                             // 连续 2 次确认
      report({ type: black ? 'black' : 'silent', streak: this.streak });
  }
  level() {
    const buf = new Float32Array(this.analyser.fftSize);
    this.analyser.getFloatTimeDomainData(buf);
    return Math.sqrt(buf.reduce((s, v) => s + v * v, 0) / buf.length);
  }
}
```
