## XP-170：跨端容器性能基准：建帧/首帧/内存基准测试

**答**：
- 题目：容器性能基准测试——首帧（冷启动→首帧渲染）、交互延迟（点击→响应）、内存（10 页面栈峰值）基准；CI 门禁（HW-398 复用）。
- 思路：固定测试场景（标准页面集）→ 真机批量跑分（HW-898 复用）→ 指标对比基线 → 劣化阻断。
- 评分点：基准场景设计；批量跑分；门禁集成。

```javascript
async function containerBenchmark(devicePool) {             // 真机批量
  const scenarios = [
    { name: 'cold-start', measure: () => coldStartToFirstFrame() },
    { name: 'tap-latency', measure: () => tapToResponseDelay() },
    { name: 'memory-10pages', measure: () => pushTenPagesPeakMem() },
  ];
  const results = [];
  for (const device of devicePool) {                          // 真机矩阵
    for (const sc of scenarios) {
      const runs = [];
      for (let i = 0; i < 5; i++) runs.push(await sc.measure(device));   // 5 轮取中位
      results.push({ device: device.model, scenario: sc.name,
        median: median(runs), baseline: BASELINES[sc.name] });
    }
  }
  const regressions = results.filter(r => r.median > r.baseline * 1.2);   // 劣化 20%
  if (regressions.length) { console.error(regressions); process.exit(1); }   // CI 门禁
}
```
