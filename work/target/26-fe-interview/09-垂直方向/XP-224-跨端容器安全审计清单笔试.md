## XP-224：跨端容器安全审计清单（笔试）

**答**：
- 题目：跨端容器安全审计——桥 API 白名单/热更新签名/插件沙箱/数据加密存储/深链校验，五项清单与渗透测试用例。
- 思路：① 桥 API 白名单（XP-152）——审计越权调用；② 热更新签名（XP-171）——篡改 bundle 测试；③ 插件沙箱（XP-162）——越权访问；④ 数据加密（HW-395 复用）；⑤ 深链校验（XP-195）——恶意深链参数。
- 评分点：五项清单完整；渗透用例；闭环修复。
