## XP-415：手写一个视觉基线管理器

**答**：
- 需求：implement VisualBaseline(storage)。save(key, img) 存基线；compare(key, img, tol=0.5) diff 百分比 < tol 通过；未存基线返回 needs-baseline（自动保存可选）；更新需 confirm 参数。
- 边界：尺寸不一致 fail；img 为 dataURL 字符串；storage 抽象 get/put；confirm=false 时只报告不覆盖。
- 评分点：基线存取；阈值判定；确认更新；首基线

```javascript
class VisualBaseline {
  constructor(storage) { this.store = storage; }
  async compare(key, img, { tol = 0.5, confirm = false } = {}) {
    const base = await this.store.get(key);
    if (!base) {
      if (confirm) await this.store.put(key, img);
      return { verdict: 'needs-baseline', saved: confirm };
    }
    const diff = pixelDiff(parseImg(base), parseImg(img), {});
    if (diff.pct <= tol) return { verdict: 'pass', pct: diff.pct };
    if (confirm) await this.store.put(key, img);       // 人工确认后更新
    return { verdict: 'fail', pct: diff.pct, bbox: diff.bbox,
      updated: confirm };
  }
}
function parseImg(dataURL) { /* 解码为 { w, h, data } */ return null; }
```
