## AV-393：协作大文档的性能：分页加载与局部订阅

**答**：
- 问题：万级对象全量同步 YDoc 初始化 > 2s、内存高。
- 手段：视口分页（只加载屏幕内对象）、局部订阅（Yjs subdoc 按页拆分）、增量渲染。
- 权衡：subdoc 拆分增加管理复杂度，> 5 万对象才值得。

```javascript
// 局部订阅
function viewportSync(doc, viewport, onAdd) {
  const shapes = doc.getMap('shapes');
  const loadVisible = () => {
    shapes.forEach((shape, id) => {
      if (inViewport(shape, viewport) && !loaded.has(id)) {
        loaded.add(id); onAdd(id, shape);
      }
    });
  };
  const loaded = new Set();
  shapes.observe(loadVisible);
  loadVisible();
  return { setViewport: v => (viewport = v, loadVisible()) };
}
function inViewport(shape, vp) {
  return shape.x + shape.w > vp.x && shape.x < vp.x + vp.w &&
         shape.y + shape.h > vp.y && shape.y < vp.y + vp.h;
}
```
