## AV-333：音视频平台专项：直播间搜索与推荐标签（笔试）

**答**：
- 题目：直播间发现——搜索（标题/标签模糊匹配，ALG-403 复用）与推荐标签（实时热门标签计算）。
- 思路：搜索索引（倒排，标题+标签+主播名）+ 推荐标签（滑动窗口热度计算，TopN 展示）；标签更新周期（5 分钟）。
- 评分点：搜索索引字段；热度计算；更新周期。

```javascript
class LiveDiscovery {
  buildIndex(rooms) {                                            // 倒排索引
    const index = new LocalSearch();
    rooms.forEach(r => index.addDoc(r.id,
      `${r.title} ${r.tags.join(' ')} ${r.streamerName}`));
    return index;
  }
  hotTags(liveRooms) {                                            // 热门标签
    const window = liveRooms.filter(r => Date.now() - r.startedAt < 3600e3);   // 最近 1h
    const tagCount = new Map();
    window.forEach(r => r.tags.forEach(t =>
      tagCount.set(t, (tagCount.get(t) ?? 0) + r.viewerCount)));   // 按观看量加权
    return [...tagCount].sort((a, b) => b[1] - a[1]).slice(0, 10)
      .map(([tag]) => tag);                                        // Top10
  }
}
```
