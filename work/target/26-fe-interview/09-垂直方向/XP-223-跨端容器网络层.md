## XP-223：跨端容器网络层：断线重连与请求队列（笔试）

**答**：
- 题目：跨端网络层断线重连——WS 心跳断线检测（HW-250 复用）+ 请求队列（离线积压重放）+ 退避重连。
- 思路：WS 心跳（10s ping，3 次超时判断线）→ 指数退避重连（1s/2s/4s...上限 30s）→ 重连成功重放队列。
- 评分点：心跳检测；退避重连；队列重放。

```javascript
class ResilientConnection {
  constructor(wsUrl) { this.url = wsUrl; this.queue = []; this.retries = 0; }
  connect() {
    this.ws = new WebSocket(this.url);
    this.heartbeat = setInterval(() => {                        // 心跳
      if (this.ws.readyState === WebSocket.OPEN) this.ws.send('ping');
    }, 10000);
    this.ws.onclose = () => this.reconnect();                    // 断线重连
  }
  reconnect() {                                                  // 指数退避
    clearInterval(this.heartbeat);
    const delay = Math.min(1000 * 2 ** this.retries++, 30000);
    setTimeout(() => this.connect(), delay);
    if (this.retries > 5) this.onGiveUp?.();                       // 放弃提示
  }
  send(data) {                                                   // 发送（断线入队）
    if (this.ws.readyState !== WebSocket.OPEN) { this.queue.push(data); return; }
    this.ws.send(JSON.stringify(data));
  }
  onReconnected() { this.queue.forEach(d => this.send(d)); this.queue = []; }   // 重放
}
```
