## AV-299：音视频平台灰度发布：客户端 SDK 灰度与回退

**答**：
- 题目：音视频 SDK 灰度——新版本 SDK 按流量灰度，指标哨兵（首帧/卡顿率）劣化自动回退。复用 HW-846 思想。
- 思路：SDK 版本 flag 下发 → 灰度组 vs 基线组指标对比 → 劣化自动暂停灰度；回退 = flag 关闭回旧版。
- 评分点：灰度策略；哨兵指标；回退机制。

```javascript
class SDKGrayscale {
  async getSDKVersion(userId) {                              // 版本分配
    const bucket = hashStr(userId) % 100;
    const grayPercent = await getFlag('av-sdk-gray', { default: 0 });
    return bucket < grayPercent ? 'v2' : 'v1';               // 灰度组/基线组
  }
  async sentinel(releaseId) {                                 // 灰度哨兵
    const { gray, base } = await metrics.compare(releaseId,
      { metrics: ['firstFrameP75', 'stallRate'], minSample: 500 });
    const degraded = gray.firstFrameP75 > base.firstFrameP75 * 1.2
      || gray.stallRate > base.stallRate * 1.5;
    if (degraded) {
      await pauseGray(releaseId);                              // 暂停灰度
      notifyOnCall(releaseId, 'SDK 劣化');
    }
  }
}
```
