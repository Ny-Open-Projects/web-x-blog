## AV-284：音视频弱网场景专项：弱网时的 UI 反馈设计

**答**：
- 弱网 UI 反馈：网络质量指示（信号图标）、卡顿提示（转圈+文案）、降级通知（已切换省流模式）、恢复通知。
- 实现：getStats 轮询 → 质量分 → UI 状态机（良好/一般/差/极差）——阈值与防抖（HW-822 滞回思想）。
- 设计原则：不频繁打扰（状态变化才提示）、可操作（建议动作）。

```javascript
class NetworkQualityUI {
  constructor() { this.state = 'good'; this.stableCount = 0; }
  update(stats) {
    const score = this.score(stats);                        // RTT/丢包/帧率综合
    const target = score > 0.8 ? 'good' : score > 0.5 ? 'fair'
      : score > 0.3 ? 'poor' : 'critical';
    if (target === this.state) return;
    this.stableCount++;                                      // 滞回：连续 3 次才切
    if (this.stableCount < 3) return;
    this.state = target; this.stableCount = 0;
    this.renderIndicator(target);                            // 信号图标
    if (target === 'critical')
      showToast('网络较差，已切换省流模式', { action: '关闭视频' });   // 可操作提示
  }
  score({ rtt, loss, fps }) {
    return 1 - Math.min(1, rtt / 0.5 * 0.4 + loss * 4 * 0.3 + (30 - fps) / 30 * 0.3);
  }
}
```

**追问**：

1. 质量分抖动会让图标反复切换，恶化与恢复要用同一套阈值吗？ → 不该，恶化要快（连续 2 次即降级），恢复要慢（连续 5 次才回升），避免一次短暂好转就把省流提示撤掉。
2. 弱网自动降画质后用户手动调回高清，又被自动降级，体验很差怎么办？ → 记住用户的手动选择，一段时间内不再自动降级，只提示当前网络状态，把决定权交回用户。
3. 弱网 UI 状态怎么在测试环境稳定复现？ → 用 DevTools 网络节流加 stats 注入开关，把状态机抽成纯函数，CI 里用可编排的网络脚本跑状态快照。
