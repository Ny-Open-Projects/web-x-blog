## XP-426：手写一个跨端性能指标采样调度器

**答**：
- 需求：implement PerfScheduler(probes, intervalMs=5000)。probes 为 [{ id, fn }]；轮询执行（错开起始时间防同时触发）；单次超时 3s 视为失败；连续 3 次失败暂停该探针 10 分钟；输出最近采样缓存 latest(id)。
- 边界：fn 抛错算失败；错开用 index*interval/len 偏移；stop 全停；latest 缺失 null。
- 评分点：错开调度；超时；连败暂停；latest 缓存

```javascript
class PerfScheduler {
  constructor(probes, intervalMs = 5000) {
    this.timers = []; this.latestMap = new Map();
    const fails = new Map();
    probes.forEach((p, i) => {
      const offset = i * intervalMs / probes.length;
      const t = setTimeout(() => {
        this.timers.push(setInterval(async () => {
          const f = fails.get(p.id) ?? 0;
          if (f >= 3) return;                          // 暂停
          try {
            const v = await Promise.race([
              p.fn(), sleep(3000).then(() => { throw new Error('timeout'); })]);
            fails.set(p.id, 0);
            this.latestMap.set(p.id, { v, at: Date.now() });
          } catch { fails.set(p.id, f + 1); }
        }, intervalMs));
      }, offset);
      this.timers.push(t);
    });
  }
  latest(id) { return this.latestMap.get(id) ?? null; }
  stop() { this.timers.forEach(clearTimeout, clearInterval);
    this.timers.forEach(t => { clearTimeout(t); clearInterval(t); }); }
}
```
