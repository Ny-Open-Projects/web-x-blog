## XP-244：跨端容器性能剖析实战：掉帧定位全流程（笔试）

**答**：
- 题目：容器页面掉帧定位——现象（滚动掉帧）→ 采集（帧率/主线程/桥调用）→ 归因（桥开销/重渲染/内存）→ 修复验证。
- 思路：① 采集：帧率采样 + 桥调用日志（XP-157）+ JS profile；② 归因：主线程长任务 → 桥/渲染；③ 修复：合帧/瘦身/虚拟化；④ 验证：修复后帧率对比。
- 评分点：采集手段；归因分类；修复验证闭环。

```javascript
function diagnoseFrameDrop(page) {                            // 掉帧定位
  const profiler = startProfile(page);                          // 采集
  simulateScroll(page);                                          // 复现滚动
  const profile = profiler.stop();
  // 归因分类
  const bridgeCalls = profile.bridge.calls.filter(c => c.event === 'scroll');
  const renderTime = profile.jsTasks.filter(t => t.name === 'render').reduce((s, t) => s + t.ms, 0);
  if (bridgeCalls.length > 60) {                                 // 桥调用 > 60/s
    return { cause: 'bridge-flood', fix: '合帧 16ms（XP-156）',
      before: profile.fps, estAfter: 55 };
  }
  if (renderTime > 10) {                                         // 渲染耗时高
    return { cause: 'over-render', fix: '虚拟列表/局部重建（XP-235）' };
  }
  return { cause: 'unknown', nextStep: 'heap snapshot 分析' };
}
```
