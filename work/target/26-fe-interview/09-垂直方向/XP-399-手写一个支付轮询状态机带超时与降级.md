## XP-399：手写一个支付轮询状态机（带超时与降级）

**答**：
- 需求：implement PayPoller(orderId, pollFn)。poll 每 2s 调 pollFn 直到状态 paid/failed 或超时 15s；超时降级为手动刷新提示（不自动终止订单）；轮询间隔递增（2s→3s→5s）。
- 边界：pollFn 抛错连续 3 次降级提示（网络差）；paid 立即停止并回调；stop() 清定时器。
- 评分点：递增轮询；超时降级；连错保护；paid 即停

```javascript
class PayPoller {
  constructor(orderId, pollFn, { timeoutMs = 15_000 } = {}) {
    this.orderId = orderId; this.pollFn = pollFn;
    this.timeoutMs = timeoutMs; this.errors = 0;
  }
  start(onResult) {
    this.t0 = Date.now();
    this._interval = 2000;
    const tick = async () => {
      if (Date.now() - this.t0 > this.timeoutMs)
        return onResult({ status: 'timeout',
          action: '手动刷新提示' });
      try {
        const r = await this.pollFn(this.orderId);
        this.errors = 0;
        if (r.status === 'paid' || r.status === 'failed')
          return onResult(r);
        this._interval = Math.min(5000, this._interval + 1000);
        this._timer = setTimeout(tick, this._interval);
      } catch {
        if (++this.errors >= 3)
          return onResult({ status: 'network',
            action: '降级手动刷新' });
        this._timer = setTimeout(tick, this._interval);
      }
    };
    tick();
  }
  stop() { clearTimeout(this._timer); }
}
```
