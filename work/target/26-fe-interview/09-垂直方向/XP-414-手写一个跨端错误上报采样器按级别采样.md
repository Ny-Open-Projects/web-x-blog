## XP-414：手写一个跨端错误上报采样器（按级别采样）

**答**：
- 需求：implement ErrorSampler(rates={ debug:0.1, info:0.5, warn:1, error:1 })。sample(level, err) 决定是否上报（error 全量、debug 10%）；alwaysIds 白名单错误码全量；输出 { sent, dropped } 统计。
- 边界：未知级别按 info；rates clamp [0,1]；同一错误指纹 1 分钟内只报一次（去重）。
- 评分点：分级采样；白名单；指纹去重；clamp

```javascript
class ErrorSampler {
  constructor(rates = {}) {
    this.rates = { debug: 0.1, info: 0.5, warn: 1, error: 1, ...rates };
    this.seen = new Map(); this.sent = 0; this.dropped = 0;
  }
  sample(level, err, alwaysIds = []) {
    const r = Math.min(1, Math.max(0, this.rates[level] ?? 0.5));
    const fp = fingerprint(err);
    const last = this.seen.get(fp);
    if (last && Date.now() - last < 60_000)
      { this.dropped++; return false; }                // 1 分钟去重
    const send = alwaysIds.includes(err.code) || Math.random() < r;
    if (send) { this.seen.set(fp, Date.now()); this.sent++; }
    else this.dropped++;
    return send;
  }
}
function fingerprint(err) {
  return String(err.code ?? err.message ?? '').slice(0, 60);
}
```
