## AV-436：手写一个推流质量自适应执行器

**答**：
- 需求：implement QualityExecutor(sender)。setPolicy({ maxBitrate, frameRate, scale }) 通过 sender.setParameters 应用（encodings[0]）；应用失败（参数不支持）逐字段回退尝试；输出 { applied, fallback }。
- 边界：getParameters 先读再改（保留其他字段）；scaleResolutionBy 需整数；每次应用后延迟 1s 验证生效（对比实际码率）。
- 评分点：参数回退；整数 scale；生效验证；getParameters

```javascript
class QualityExecutor {
  constructor(sender, getActualKbps) {
    this.sender = sender; this.actual = getActualKbps;
  }
  async setPolicy({ maxBitrate, frameRate, scale }) {
    const p = this.sender.getParameters();             // 先读
    const enc = p.encodings[0] ?? (p.encodings[0] = {});
    enc.maxBitrate = maxBitrate * 1000;
    enc.maxFramerate = frameRate;
    if (scale) enc.scaleResolutionDownBy = Math.max(1, Math.round(scale));
    try {
      await this.sender.setParameters(p);
      await sleep(1000);
      const kbps = await this.actual();
      return { applied: true, actualKbps: kbps,
        effective: kbps <= maxBitrate * 1.2 };
    } catch (e) {
      // 逐字段回退
      for (const field of ['scaleResolutionDownBy', 'maxFramerate', 'maxBitrate']) {
        try { delete enc[field]; await this.sender.setParameters(p);
          return { applied: false, fallback: field }; }
        catch {}
      }
      throw e;
    }
  }
}
```
