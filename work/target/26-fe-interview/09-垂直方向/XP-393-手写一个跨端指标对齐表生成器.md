## XP-393：手写一个跨端指标对齐表生成器

**答**：
- 需求：implement metricAlign(mapping)。mapping 为 { metric: { web: LCP, mini: firstRender, rn: contentAppear } }；输出对照表 [{ metric, web, mini, rn }]；缺失端标 N/A；反向查询 byEndTerm(term) 找端内指标名对应的统一指标。
- 边界：mapping 空返回空表；term 未命中返回 null；表按 metric 字母序。
- 评分点：对照表；N/A；反向索引；排序

```javascript
function metricAlign(mapping) {
  const rows = Object.entries(mapping).map(([metric, m]) => ({
    metric, web: m.web ?? 'N/A', mini: m.mini ?? 'N/A', rn: m.rn ?? 'N/A' }));
  rows.sort((a, b) => a.metric < b.metric ? -1 : 1);
  const index = new Map();
  for (const [metric, m] of Object.entries(mapping))
    for (const term of Object.values(m))
      if (term) index.set(term, metric);
  return { rows, byEndTerm: term => index.get(term) ?? null };
}
// metricAlign({ start: { web: 'LCP', mini: 'firstRender' } })
//   .byEndTerm('firstRender') -> 'start'
```
