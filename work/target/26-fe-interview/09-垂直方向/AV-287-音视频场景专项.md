## AV-287：音视频场景专项：跨浏览器兼容矩阵

**答**：
- 题目：WebRTC 兼容矩阵——Chrome/Firefox/Safari 差异（codec 支持/API 命名/行为差异）与适配层。
- 思路：codec 探测（H265/VP9/AV1 各浏览器差异）；Safari 差异（RTCRtpScriptTransform 命名、Simulcast 支持晚）；适配层统一封装。
- 评分点：兼容矩阵表；探测降级；适配层设计。

```javascript
const compatMatrix = {
  chrome: { codecs: ['h264', 'vp8', 'vp9', 'av1'], simulcast: 'full', e2ee: 'RTCRtpScriptTransform' },
  safari: { codecs: ['h264', 'vp8'], simulcast: 'partial(14.1+)',
    e2ee: 'insertableStreams(旧命名)', note: 'Safari 15+ 才有较完整支持' },
  firefox: { codecs: ['h264', 'vp8', 'vp9'], simulcast: 'full',
    e2ee: 'insertableStreams', note: 'AV1 支持较晚' },
};
class CompatAdapter {
  async detect() {                                           // 能力探测
    const support = { codecs: await probeCodecs(),
      e2ee: typeof RTCRtpScriptTransform !== 'undefined'
        ? 'new' : typeof RTCRtpSender.prototype.createEncodedStreams !== 'undefined' ? 'legacy' : 'none' };
    return support;
  }
  adapt(pc) {                                                 // 统一封装
    if (this.support.e2ee === 'legacy') {                     // Safari 旧 API 适配
      pc.addTransceiver = wrapWithLegacyTransform(pc.addTransceiver);
    }
  }
}
```
