## AV-259：视频清晰度切换：无缝切换与进度保持

**答**：
- 题目：清晰度切换（480p→1080p）不跳帧不丢进度——HLS ABR 自动切换（天然无缝）与手动切换（MSE 需 flush+续播）。
- 思路：HLS ABR：hls.js 自动按带宽切（GOP 对齐则无感）；手动切换：hls.currentLevel = n（同 MSE 缓冲保持）；MSE 裸实现：flush → 请求新质量 → seek 续播。
- 评分点：ABR 自动 vs 手动；进度保持；切换瞬间黑屏消除。

```javascript
class QualitySwitcher {
  async switchTo(level) {                                    // 手动切换
    if (this.hls) {                                          // hls.js：保持缓冲无缝
      this.hls.currentLevel = level;                         // 只切层不 flush
      // hls 内部：从新 level 对齐 GOP 边界续播——需转码 GOP 对齐（AV-253）
    } else {                                                  // MSE 裸实现
      const ts = this.video.currentTime;
      this.sourceBuffer.abort();
      this.sourceBuffer.remove(0, Infinity);                 // 清旧缓冲
      const newInit = await fetch(`/stream/${level}/init.mp4`);
      await appendInit(newInit);
      await appendFrom(ts);                                   // 从当前时间戳续拉
      this.video.currentTime = ts;
    }
    report('quality-switch', { level, seamless: this.hls ? 'yes' : 'manual' });
  }
}
```
