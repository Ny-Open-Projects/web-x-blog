## XP-242：跨端容器数据埋点：跨端埋点协议统一（笔试）

**答**：
- 题目：跨端埋点统一协议——事件 schema 统一（事件名/参数/平台字段）、各端采集适配（Web/RN/小程序/Flutter）、上报通道统一。
- 思路：事件 schema（JSON Schema 定义）→ 各端采集 SDK 适配（平台字段注入）→ 统一上报 endpoint；平台字段：platform/appVersion/deviceTier。
- 评分点：schema 统一；平台字段注入；通道统一。

```javascript
const trackingSchema = {                                     // 统一事件 schema
  required: ['event', 'ts', 'platform', 'appVersion'],
  properties: {
    event: { type: 'string', pattern: '^[a-z_]+$' },           // snake_case
    platform: { enum: ['web', 'rn', 'mp', 'flutter', 'electron'] },
    deviceTier: { enum: ['low', 'mid', 'high'] },
    params: { type: 'object' },
  },
};
class TrackingAdapter {
  constructor(platform, reporter) {
    this.platform = platform;                                  // 平台字段注入
    this.reporter = reporter;
  }
  track(event, params = {}) {
    const payload = { event, platform: this.platform,
      appVersion: getAppVersion(), deviceTier: getDeviceTier(),
      ts: Date.now(), params };
    const check = validateSchema(payload, trackingSchema);      // schema 校验
    if (!check.valid) { warn('tracking-schema-violation', payload); return; }
    this.reporter.send(payload);
  }
}
```
