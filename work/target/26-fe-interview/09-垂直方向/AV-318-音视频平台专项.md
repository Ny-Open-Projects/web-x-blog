## AV-318：音视频平台专项：直播间推广投放归因（笔试）

**答**：
- 题目：直播推广归因——投放渠道（信息流广告/搜索）带来的观众，追踪「点击→进房→观看时长→转化」归因链。
- 思路：渠道参数（UTM/点击 ID）透传进房；归因窗口（点击后 24h 内进房算）；转化事件（关注/打赏/购物）回传广告平台。
- 评分点：参数透传；归因窗口；转化回传。

```javascript
class AttributionTracker {
  captureEntry(entryParams) {                                  // 进房参数
    this.attribution = { channel: entryParams.utm_source,
      clickId: entryParams.click_id,                          // 广告平台点击 ID
      enterTs: Date.now() };
    // 归因窗口：点击后 24h 内进房算该渠道
  }
  onConvert(convertType) {                                     // 转化事件
    if (!this.attribution) return;
    if (Date.now() - this.attribution.enterTs > 86400e3) return;   // 窗口外
    api.attribution({                                          // 回传广告平台
      clickId: this.attribution.clickId, channel: this.attribution.channel,
      eventType: convertType,                                   // follow/gift/purchase
      value: convertType === 'gift' ? this.giftValue : null,
    });
  }
}
```
