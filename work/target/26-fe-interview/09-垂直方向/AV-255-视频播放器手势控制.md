## AV-255：视频播放器手势控制：快进音量亮度

**答**：
- 移动端播放器手势：左右滑快进/快退、左半屏上下滑亮度、右半屏上下滑音量——手势仲裁（HW-832 复用）。
- 实现：pan 手势 dx → seek（预览帧跟随）；dy 分区（左右）→ 亮度（CSS filter）/音量（volume）；松手提交。
- 亮度实现：video/filter 不渲染后台——用遮罩层 opacity 或 brightness filter。

```javascript
class PlayerGestures {
  constructor(player, el) {
    gestureRecognizer(el);                                  // HW-832 复用
    el.addEventListener('swipe', ({ detail }) => this.onSwipe(detail));
  }
  onSwipe({ dir, dx, dy }) {
    if (dir === 'left' || dir === 'right') {
      this.seekPreview = clamp(this.player.currentTime + dx / 5, 0, this.player.duration);   // dx→秒
      this.showSeekPreview(this.seekPreview);                // 预览帧跟随
    } else if (dir === 'up' || dir === 'down') {
      const left = this.startX < innerWidth / 2;
      if (left) this.brightness = clamp(this.brightness + dy / 200, 0.3, 1);   // 左半屏亮度
      else this.player.volume = clamp(this.player.volume + dy / 200, 0, 1);    // 右半屏音量
    }
  }
}
// 松手：seek 提交（player.currentTime = seekPreview）；亮度用 overlay 黑遮罩 opacity
```
