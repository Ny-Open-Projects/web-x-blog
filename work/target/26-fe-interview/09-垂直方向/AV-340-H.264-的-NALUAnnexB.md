## AV-340：H.264 的 NALU/AnnexB/AVCC 格式差异

**答**：
- NALU：编码数据基本单元（起始码 00 00 01 分隔）；SPS/PPS 元信息在流开头。
- AnnexB（TS/裸流）：起始码分隔，SPS/PPS 周期插入——直播切片友好。
- AVCC（MP4）：长度前缀 + extracrate 存 SPS/PPS——MSE 需要特定格式，转封装是常见坑。

```javascript
// NALU 解析与格式转换判断
function parseAnnexB(data) {
  const nalus = [];
  let i = 0;
  while (i < data.length - 3) {
    if (data[i] === 0 && data[i+1] === 0 && data[i+2] === 1) {
      const start = i + 3;
      let j = start;
      while (j < data.length - 2 &&
        !(data[j] === 0 && data[j+1] === 0 && data[j+2] === 1)) j++;
      nalus.push({ type: data[start] & 0x1f, data: data.subarray(start, j) });
      i = j;
    } else i++;
  }
  return nalus;   // type: 7=SPS 8=PPS 5=IDR 1=非IDR
}
// MSE 换装：AnnexB -> AVCC 需去起始码加长度前缀 + extracrate 合入 init segment
```
