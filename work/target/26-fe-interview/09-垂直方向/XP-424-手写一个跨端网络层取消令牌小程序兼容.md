## XP-424：手写一个跨端网络层取消令牌（小程序兼容）

**答**：
- 需求：implement CancelToken(adapter)。fetch(url, init) 返回 { promise, cancel }；cancel 调 adapter abort（小程序 task.abort/标准 AbortController）；cancel 后 promise reject CancelError；多请求各自独立。
- 边界：cancel 后再 cancel 幂等；已完成请求 cancel 无效；adapter 差异封装。
- 评分点：取消令牌；幂等；适配差异；错误类型

```javascript
function CancelToken(adapter) {
  return {
    fetch(url, init = {}) {
      const task = adapter.request(url, init);         // 返回可 abort 句柄
      let cancelled = false;
      const promise = new Promise((resolve, reject) => {
        task.then(resolve, e => reject(cancelled
          ? Object.assign(new Error('cancelled'), { name: 'CancelError' })
          : e));
      });
      return { promise,
        cancel() {
          if (cancelled) return;                       // 幂等
          cancelled = true;
          task.abort?.();
        } };
    },
  };
}
// 小程序 adapter.request 返回 RequestTask（有 abort），
// Web adapter 用 AbortController 包装成同接口
```
