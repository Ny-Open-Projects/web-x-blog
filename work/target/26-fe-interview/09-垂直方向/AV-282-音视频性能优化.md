## AV-282：音视频性能优化：解码器并行与多路视频内存

**答**：
- 题目：同页多路视频（4 路连麦）解码内存/CPU 优化——统一分辨率、按需解码（画中画小窗低帧率）、解码器复用。
- 思路：小窗视频降帧（requestVideoFrameCallback 丢弃帧或 track.contentHint）；4 路 720p 解码 CPU 占用 ~30%，降为 360p 小窗 → 8%。
- 评分点：按需解码策略；分辨率统一协商；内存监控。

```javascript
class MultiVideoOptimizer {
  optimize(videos) {                                         // 多路视频
    // 1. 小窗降帧：contentHint + frameRate 限制
    videos.filter(v => v.isPip).forEach(v => {
      v.track.contentHint = 'motion';
      v.applyFrameRate(15);                                   // 小窗 15fps 足够
    });
    // 2. 不可见视频暂停解码
    videos.filter(v => !v.visible).forEach(v => v.video.srcObject = null);   // 释放解码器
    // 3. 内存监控
    if (performance.memory.usedJSHeapSize > 500e6) {
      report('multi-video-mem-high');
      this.downgradePipResolution();                          // 小窗降分辨率
    }
  }
}
```
