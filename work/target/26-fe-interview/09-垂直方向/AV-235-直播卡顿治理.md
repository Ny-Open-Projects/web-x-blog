## AV-235：直播卡顿治理：卡顿率指标与归因

**答**：
- 卡顿定义：播放缓冲不足导致的画面冻结（buffer 空 → stall）；卡顿率 = 卡顿场次/总场次。
- 归因维度：观众网络（下行带宽）、CDN 节点（回源失败/命中率）、推流端（上行抖动传导）。
- 实现：播放器事件流（waiting/playing/stalled）+ buffer 状态采样 → 归因到 CDN 命中率。

```javascript
class StallMonitor {
  constructor(player) {
    this.stalls = [];
    player.addEventListener('waiting', () => this.stallStart = Date.now());
    player.addEventListener('playing', () => {
      if (this.stallStart) {
        this.stalls.push({ start: this.stallStart, ms: Date.now() - this.stallStart,
          bufferBefore: player.buffered.end(0) - player.currentTime });
        this.stallStart = null;
      }
    });
    setInterval(() => {                                     // buffer 水位采样
      const buffered = player.buffered.length
        ? player.buffered.end(0) - player.currentTime : 0;
      report('buffer-level', { buffered, playing: !player.paused });
    }, 1000);
  }
  report() { return { stallRate: this.stalls.length / this.sessionSeconds,
    avgStallMs: avg(this.stalls.map(s => s.ms)) }; }
}
```
