## AV-319：音视频平台专项：直播弹幕敏感场景风控（笔试）

**答**：
- 题目：直播弹幕风控——高频发送限流（每用户 N 条/分钟）、内容风控（AV-308 分层审核）、行为风控（刷屏/机器人模式识别）。
- 思路：令牌桶限流（每用户 10 条/分钟）；机器人识别（发送间隔方差过小/内容重复度高 → 验证码）；关联封禁（同设备多账号违规）。
- 评分点：限流参数；机器人识别特征；关联封禁。

```javascript
class DanmakuRiskControl {
  async check(userId, text, deviceFingerprint) {
    // 1. 限流：每用户 10 条/分钟（令牌桶）
    if (!await this.rateLimiter.acquire(`dm:${userId}`, 1)) {
      return { blocked: true, reason: 'rate-limit' };
    }
    // 2. 机器人识别：发送间隔方差过小（机器人定时发送）+ 重复度
    const intervals = this.sendIntervals(userId);
    const variance = varianceOf(intervals);
    if (variance < 100 && this.repetitionScore(text) > 0.8) {   // 定时+重复
      await this.requireCaptcha(userId);                       // 触发验证码
      return { blocked: true, reason: 'captcha-required' };
    }
    // 3. 关联封禁：同设备指纹已有违规账号
    if (await this.deviceBanned(deviceFingerprint)) {
      return { blocked: true, reason: 'device-banned' };
    }
    return { blocked: false };
  }
}
```
