## AV-373：活跃说话人检测与画面布局联动

**答**：
- 检测：audioLevel（getStats/getUserMedia 分析）超过阈值标记 speaking（防抖 300ms）。
- 布局：活跃者放大（主画面切换 hysteresis 防抖动：新说话人 1.5s 才切换主画面）。
- 性能：多路音频分析用 AudioWorklet 单实例集中处理。

```javascript
// 活跃说话人
class ActiveSpeaker {
  constructor(threshold = 0.03) {
    this.threshold = threshold; this.current = null; this.since = 0;
  }
  update(id, level, now) {
    if (level > this.threshold) {
      if (this.current === id) return this.current;
      if (!this.since) this.since = now;
      if (now - this.since > 1500) {                   // 1.5s 防抖
        this.current = id;
      }
    } else if (this.current === id && now - this.since > 3000) {
      this.current = null; this.since = 0;
    }
    return this.current;
  }
}
```
