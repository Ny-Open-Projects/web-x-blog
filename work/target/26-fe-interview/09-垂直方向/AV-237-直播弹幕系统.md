## AV-237：直播弹幕系统：海量弹幕渲染与洪泛控制

**答**：
- 弹幕洪泛：万条/分钟——三级缓冲：WS 合帧收包（HW-767 思想）→ 渲染队列（按轨道分配）→ 丢弃策略（过载丢低级弹幕）。
- 渲染：Canvas 轨道弹幕（HW-769 复用）或 DOM 池；高频插入用 DocumentFragment 批量。
- 优先级：礼物/高赞弹幕必显示，普通弹幕过载丢弃。

```javascript
class DanmakuFlood {
  constructor({ maxPerSecond = 60 } = {}) { this.queue = []; this.dropping = false; }
  onBatch(messages) {                                       // WS 批量到达
    for (const m of messages) {
      if (m.priority === 'high' || this.queue.length < this.maxPerSecond * 2)
        this.queue.push(m);                                // 高优必收；普通限量
    }
  }
  drain() {                                                  // rAF 消费
    const batch = this.queue.splice(0, 10);                  // 每帧最多 10 条
    batch.forEach(m => this.renderer.add(m));
    if (this.queue.length) requestAnimationFrame(() => this.drain());
  }
}
// 丢弃策略：queue 长度 > 阈值 → 丢弃普通弹幕（保留高优）→ 前端提示「弹幕速度过快已折叠」
```
