## AV-273：音视频测试数据合成：假音视频源生成

**答**：
- 题目：自动化测试需要可控音视频源——Canvas 合成动态画面 + WebAudio 合成音频 → 合成 MediaStream 供测试。
- 思路：Canvas（跳动时钟/色条+时间戳水印）→ captureStream(30)；WebAudio 振荡器 → MediaStreamDestination；合成双 track。
- 评分点：合成源构建；时间戳水印（帧级对齐验证）；音频测试信号（1kHz 正弦）。

```javascript
function createTestStream() {                              // 合成测试源
  const canvas = document.createElement('canvas');          // 视频：时钟+帧号
  canvas.width = 640; canvas.height = 360;
  const ctx = canvas.getContext('2d');
  let frameNo = 0;
  setInterval(() => {
    ctx.fillStyle = ['#f00', '#0f0', '#00f'][frameNo % 3];   // 色条轮转
    ctx.fillRect(0, 0, 640, 360);
    ctx.fillStyle = '#fff'; ctx.font = '48px monospace';
    ctx.fillText(`F${frameNo++} ${new Date().toISOString()}`, 20, 60);   // 帧号水印（延迟验证）
  }, 33);
  const videoStream = canvas.captureStream(30);
  const audioCtx = new AudioContext();
  const osc = audioCtx.createOscillator();                  // 1kHz 音频（连续性验证）
  const dest = audioCtx.createMediaStreamDestination();
  osc.connect(dest);
  osc.start();
  const stream = new MediaStream([...videoStream.getVideoTracks(), ...dest.stream.getAudioTracks()]);
  return stream;                                            // 端到端延迟可测（帧号差）
}
```
