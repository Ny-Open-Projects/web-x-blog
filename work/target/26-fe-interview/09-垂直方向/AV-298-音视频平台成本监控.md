## AV-298：音视频平台成本监控：带宽与转码成本（笔试）

**答**：
- 题目：音视频成本监控——TURN 带宽成本/转码成本/CDN 成本分维度统计与预算告警。复用 VIZ 大盘能力。
- 思路：成本数据源（TURN 流量日志/转码任务记录/CDN 账单）→ 归一化统计（元/分钟/千人）→ 大盘+预算告警（阈值 80%/100%）。
- 评分点：成本归集维度；单均成本；预算告警。

```javascript
class AVCostMonitor {
  aggregate(costs) {                                         // costs: [{type, bytes, region, ts}]
    const byType = groupBy(costs, 'type');                   // turn/transcode/cdn
    return Object.entries(byType).map(([type, items]) => ({
      type,
      totalMB: items.reduce((s, i) => s + i.bytes / 1e6, 0),
      cost: items.reduce((s, i) => s + i.cost, 0),
      perThousandUsers: items.reduce((s, i) => s + i.cost, 0) / (items[0].users / 1000),   // 千人成本
    }));
  }
  alert(costs, budget) {                                     // 预算告警
    const used = costs.reduce((s, c) => s + c.cost, 0);
    if (used > budget * 0.8) fire('av-cost-warning', { used, budget });   // 80% 预警
  }
}
```
