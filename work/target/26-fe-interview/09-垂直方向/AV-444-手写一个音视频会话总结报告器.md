## AV-444：手写一个音视频会话总结报告器

**答**：
- 需求：implement sessionReport(data)。data 为 { durationSec, firstFrameMs, stalls, avgKbps, resolution, disconnects, qualityChanges }；输出评分 0~100（起播 30 分：<1s 满分线性；流畅 30 分：无卡顿满分每卡 -5；画质 20 分：码率/分辨率达标；稳定 20 分：断连每次 -7）；输出 { score, breakdown, grade }。
- 边界：缺失维度按满分（数据不足不打负分）；grade >= 85 优 / 70 良 / 50 中 / 否则差；score clamp [0, 100]。
- 评分点：四维评分；缺失满分；分级；clamp

```javascript
function sessionReport(d) {
  const breakdown = {};
  breakdown.startup = d.firstFrameMs == null ? 30
    : Math.max(0, 30 - Math.max(0, d.firstFrameMs - 1000) / 100);
  breakdown.smooth = Math.max(0, 30 - (d.stalls ?? 0) * 5);
  breakdown.quality = (d.avgKbps >= 3000 && d.resolution >= 720) ? 20
    : d.avgKbps >= 1500 ? 12 : 6;
  breakdown.stability = Math.max(0, 20 - (d.disconnects ?? 0) * 7);
  const score = Math.min(100, Math.round(Object.values(breakdown)
    .reduce((s, v) => s + v, 0)));
  return { score, breakdown,
    grade: score >= 85 ? '优' : score >= 70 ? '良' : score >= 50 ? '中' : '差' };
}
// 输入来自 AVSampler/卡顿检测/首帧测量等采集器；
```
