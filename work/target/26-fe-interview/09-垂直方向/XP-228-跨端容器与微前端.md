## XP-228：跨端容器与微前端：容器内嵌 H5 微应用（笔试）

**答**：
- 题目：容器内嵌 H5 微应用——webview 加载 H5 子应用（微前端 qiankun 思想在容器场景），通信走 JSBridge；共享登录态。
- 思路：webview 加载微前端子应用（URL hash 路由）；通信：JSBridge（子应用 → 原生能力）+ URL 参数传递；登录态：Cookie/Token 注入。
- 评分点：webview 嵌入；通信桥；登录态共享。

```javascript
class H5MicroApp {
  async open(url) {                                              // 打开 H5 微应用
    const token = await this.getAuthToken();                      // 登录态
    const fullUrl = `${url}?token=${token}&theme=${this.currentTheme}`;   // 参数传递
    this.webview.load(fullUrl);                                    // WebView 加载
  }
  injectBridge() {                                                 // 注入 JSBridge
    this.webview.evaluateJS(`
      window.nativeAPI = {
        navigate: (route) => bridge.call('navigate', { route }),
        getUser: () => bridge.call('getUser'),
      };`);
  }
  onMessage(msg) {                                                 // H5 → 容器通信
    if (msg.type === 'close') this.webview.close();
    if (msg.type === 'navigate') this.navigator.push(msg.route);
  }
}
```
