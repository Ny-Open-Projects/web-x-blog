## XP-409：手写一个锚点定位重试器

**答**：
- 需求：implement anchorScroll(getEl, targetTop, retries=3)。每轮 scrollIntoView + 100ms 后校验 getBoundingClientRect().top 与 targetTop 差值 < 4px 成功；否则 scrollBy 修正再试；输出 { ok, attempts }。
- 边界：元素不存在返回 false；retries 上限 5；平滑滚动期间测量需等待（sleep 100ms）；全失败也返回最后位置。
- 评分点：重试校准；偏移修正；元素缺失；上限保护

```javascript
async function anchorScroll(getEl, targetTop = 60, retries = 3) {
  const sleep = ms => new Promise(r => setTimeout(r, ms));
  let attempts = 0;
  for (let i = 0; i < Math.min(retries, 5); i++) {
    const el = getEl();
    if (!el) return { ok: false, attempts };
    attempts++;
    el.scrollIntoView({ behavior: 'smooth' });
    await sleep(100);
    const top = el.getBoundingClientRect().top;
    if (Math.abs(top - targetTop) < 4)
      return { ok: true, attempts };
    window.scrollBy(0, top - targetTop);              // 修正吸顶偏移
    await sleep(50);
  }
  return { ok: false, attempts };
}
```
