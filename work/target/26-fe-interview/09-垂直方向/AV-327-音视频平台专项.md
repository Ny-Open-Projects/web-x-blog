## AV-327：音视频平台专项：直播间预约与开播提醒（笔试）

**答**：
- 题目：直播预约——用户预约未开播主播，开播时推送提醒（推送通道选择/勿扰时段/点击直达）。
- 思路：预约记录；开播事件 → 遍历预约用户 → 推送（App push/SMS 按用户偏好）；勿扰时段（22:00~8:00 延迟推送）；点击直达（深链进直播间）。
- 评分点：推送通道选择；勿扰处理；深链直达。

```javascript
class StreamReminder {
  async onStreamStart(roomId) {                                // 开播事件
    const subscribers = await this.getSubscribers(roomId);
    for (const user of subscribers) {
      const channel = await this.pickChannel(user);             // 用户推送偏好
      if (this.inDND(user)) {                                    // 勿扰时段
        await this.queueForLater(user, roomId);                  // 延迟到勿扰结束
        continue;
      }
      await pushService.send(user, channel, {
        title: '关注的主播开播了',
        deepLink: `app://live/${roomId}`,                         // 深链直达
        badge: 1,
      });
    }
  }
  async pickChannel(user) {                                     // 通道选择
    if (user.appOnline) return 'app-push';                       // App 在线：App push
    if (user.wechatBound) return 'wechat-template';              // 微信模板消息
    return user.phone ? 'sms' : null;
  }
}
```
