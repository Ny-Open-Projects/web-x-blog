## XP-388：手写一个跨端设备分档评分器

**答**：
- 需求：implement deviceTier(info, probes)。info: { memGB, cores, screenDpr }；probes: { fps, jsMs }；评分：内存 0~3/核数 0~3/fps 0~3/jsMs 0~3（越快越高）求和 0~12；映射 L0(<4)/L1(4-5)/L2(6-8)/L3(9+)；输出 { score, tier, config }（config 按档位给动画/图片/预取参数）。
- 边界：缺失项按中间值（2 分）；config 表内置；fps 0 视为未测按 2 分。
- 评分点：多维评分；缺失中间值；档位映射；配置表

```javascript
function deviceTier(info = {}, probes = {}) {
  const sc = (v, th) => v == null ? 2
    : v >= th[2] ? 3 : v >= th[1] ? 2 : v >= th[0] ? 1 : 0;
  const mem = sc(info.memGB, [2, 4, 6]);
  const cores = sc(info.cores, [4, 6, 8]);
  const fps = sc(probes.fps || 0, [30, 45, 55]) || 2;
  const js = probes.jsMs == null ? 2
    : probes.jsMs <= 20 ? 3 : probes.jsMs <= 50 ? 2 : 1;
  const score = mem + cores + fps + js;
  const tier = score >= 9 ? 'L3' : score >= 6 ? 'L2' : score >= 4 ? 'L1' : 'L0';
  const CONFIG = {
    L0: { anim: 'off', imgW: 360, prefetch: 0 },
    L1: { anim: 'basic', imgW: 720, prefetch: 1 },
    L2: { anim: 'full', imgW: 1080, prefetch: 2 },
    L3: { anim: 'full', imgW: 1080, prefetch: 4 },
  };
  return { score, tier, config: CONFIG[tier] };
}
```
