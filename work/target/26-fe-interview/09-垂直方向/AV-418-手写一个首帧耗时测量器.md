## AV-418：手写一个首帧耗时测量器

**答**：
- 需求：implement firstFrameMeter(video)。从 play() 调用起计时，到首次 timeupdate 或 loadeddata；输出 { ms, stages }：stages 记录 canplay/loadeddata 各时刻；abort/timeout（10s）计失败。
- 边界：重复 play 只测首次；video 已有 currentTime > 0 视为复用（重新加载才测）；输出含网络类型。
- 评分点：阶段打点；超时失败；事件清理；网络上下文

```javascript
class firstFrameMeter {
  constructor(video, { timeout = 10_000 } = {}) {
    this.video = video; this.timeout = timeout;
  }
  measure() {
    return new Promise(resolve => {
      const t0 = performance.now();
      const stages = {};
      const done = (ok) => {
        clearInterval(timer);
        video.removeEventListener('canplay', mark('canplay'));
        video.removeEventListener('loadeddata', mark('loadeddata'));
        video.removeEventListener('timeupdate', onTime);
        resolve({ ok, ms: Math.round(performance.now() - t0), stages,
          conn: navigator.connection?.effectiveType });
      };
      const mark = name => () => { stages[name] = Math.round(performance.now() - t0); };
      const onTime = () => done(true);
      video.addEventListener('canplay', mark('canplay'), { once: true });
      video.addEventListener('loadeddata', mark('loadeddata'), { once: true });
      video.addEventListener('timeupdate', onTime, { once: true });
      const timer = setTimeout(() => done(false), this.timeout);
      this.video.play().catch(() => done(false));
    });
  }
}
```
