## AV-317：音视频平台专项：直播间礼物打赏的幂等与对账

**答**：
- 题目：礼物打赏幂等——重复点击/网络重试不重复扣费（幂等键）；对账（送礼记录与支付流水核对）。
- 思路：幂等键 = userId + orderId（客户端生成 UUID）；服务端幂等表（键唯一约束，重复返回首次结果）；对账：T+1 定时核对。
- 评分点：幂等键设计；服务端幂等实现；对账流程。

```javascript
class GiftPayment {
  async send({ userId, giftId, count, idempotencyKey }) {
    // 幂等检查：同 key 返回首次结果
    const existing = await idempotentStore.get(idempotencyKey);
    if (existing) return existing.result;                     // 幂等返回
    const result = await db.transaction(async (tx) => {
      await tx.insert('gift_orders', { userId, giftId, count, idempotencyKey });   // 唯一约束
      await tx.update('balance', { userId, delta: -price });   // 扣费
      return { orderId: tx.lastId, success: true };
    }).catch(e => e.code === 'DUP' ? await idempotentStore.get(idempotencyKey)?.result : null);   // 并发重复
    await idempotentStore.put(idempotencyKey, { result });     // 幂等记录
    return result;
  }
  async reconcile(date) {                                      // T+1 对账
    const orders = await db.query('SELECT * FROM gift_orders WHERE date = ?', date);
    const payments = await payService.query(date);
    const mismatches = diff(orders, payments);                 // 差异
    if (mismatches.length) fire('reconcile-mismatch', mismatches);   // 告警
  }
}
```
