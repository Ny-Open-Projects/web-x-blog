## AV-294：音视频弱网场景：移动端后台推流保活

**答**：
- 题目：移动端直播切后台推流中断——保活策略：MediaSession 活跃、音频持续（视频可停）、画中画保活、原生桥兜底。
- 思路：视频切后台被系统暂停 → 音频保活（MediaSession 播放状态）；WebRTC 视频帧冻结但连接保活；原生 App 用后台任务 API。
- 评分点：保活手段分级；WebRTC 连接维持；恢复流程。

```javascript
class BackgroundKeepAlive {
  constructor() { this.setupMediaSession(); }
  setupMediaSession() {                                       // MediaSession 保活
    navigator.mediaSession.playbackState = 'playing';         // 标记播放中
    navigator.mediaSession.metadata = new MediaMetadata({ title: '直播中' });   // 锁屏显示
    // 静音音频源保活（不发声但保持音频会话）
    const ctx = new AudioContext();
    const osc = ctx.createOscillator(); osc.frequency.value = 0;   // 静音载波
    const gain = ctx.createGain(); gain.gain.value = 0;
    osc.connect(gain).connect(ctx.destination); osc.start();   // 保持音频活跃
  }
  onVisibilityChange() {
    if (document.hidden) {                                     // 切后台
      this.videoTrack.enabled = false;                         // 视频暂停（省电）
      report('background-push', { audioAlive: true });         // 音频继续
    } else {
      this.videoTrack.enabled = true;                          // 恢复视频
    }
  }
}
```
