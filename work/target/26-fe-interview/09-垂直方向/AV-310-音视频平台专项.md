## AV-310：音视频平台专项：直播复盘报告自动生成

**答**：
- 题目：直播结束后自动复盘——质量指标汇总（首帧/卡顿/MOS）+ 异常事件时间线 + 优化建议。复用 HW-889 复盘模板。
- 思路：指标聚合（本场 vs 历史均值对比）+ 异常时间线（黑匣子事件）+ 规则建议（卡顿高 → CDN 命中率检查）。
- 评分点：对比维度；异常时间线；建议可执行。

```javascript
async function generateLiveReview(liveId) {
  const metrics = await collectLiveMetrics(liveId);           // 本场指标
  const history = await getHistoricalAvg(metrics.roomId);      // 历史均值
  const anomalies = metrics.blackbox.filter(e => e.severity === 'error');   // 异常时间线
  return {
    summary: {
      firstFrameP75: { actual: metrics.firstFrameP75, baseline: history.firstFrameP75,
        delta: +(metrics.firstFrameP75 - history.firstFrameP75).toFixed(0) },
      stallRate: { actual: metrics.stallRate, baseline: history.stallRate },
      mos: { actual: metrics.mos, baseline: history.mos },
    },
    timeline: anomalies,                                       // 异常事件
    suggestions: [
      metrics.stallRate > 0.05 ? '卡顿率超标：检查 CDN 命中率与边缘节点分布' : null,
      metrics.firstFrameP75 > 2000 ? '首帧超 2s：确认 GOP 缓存已开启' : null,
    ].filter(Boolean),
  };
}
```
