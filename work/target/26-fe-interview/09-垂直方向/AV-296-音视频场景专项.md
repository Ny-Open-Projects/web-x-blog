## AV-296：音视频场景专项：直播画面布局引擎（多人合成）

**答**：
- 题目：多人直播布局引擎——N 路视频合成（宫格/主副/匀分），服务端混流布局指令生成；布局切换动画。
- 思路：布局模板（1/2/4/9 宫格）；按活跃度自动切换主画面；服务端 layout JSON（位置/尺寸/层级）下发 ffmpeg 合流。
- 评分点：布局模板；活跃切换；layout JSON schema。

```javascript
class LiveLayoutEngine {
  static templates = {
    solo: [{ x: 0, y: 0, w: 1, h: 1 }],
    pip: [{ x: 0, y: 0, w: 1, h: 1 }, { x: 0.7, y: 0.7, w: 0.28, h: 0.28 }],   // 画中画
    grid4: [{ x: 0, y: 0, w: 0.5, h: 0.5 }, { x: 0.5, y: 0, w: 0.5, h: 0.5 },
      { x: 0, y: 0.5, w: 0.5, h: 0.5 }, { x: 0.5, y: 0.5, w: 0.5, h: 0.5 }],
  };
  computeLayout(peers, activeSpeaker) {                       // 自动布局
    if (peers.length === 1) return { template: 'solo', slots: [peers[0]] };
    if (activeSpeaker)                                       // 演讲者模式
      return { template: 'pip',
        slots: [activeSpeaker, ...peers.filter(p => p !== activeSpeaker).slice(0, 1)] };
    return { template: 'grid4', slots: peers.slice(0, 4) };
  }
  toServerLayout(layout, resolution) {                        // 服务端混流指令
    return layout.slots.map((p, i) => ({
      peerId: p.peerId, x: layout.template.slots[i].x * resolution.w,
      y: layout.template.slots[i].y * resolution.h,
      w: layout.template.slots[i].w * resolution.w,
      h: layout.template.slots[i].h * resolution.h, zIndex: i }));
  }
}
```
