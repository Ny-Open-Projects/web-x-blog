## AV-324：音视频平台专项：音视频质量与业务指标关联分析（笔试）

**答**：
- 题目：质量与业务关联——首帧延迟/卡顿率与「观看时长/留存/打赏」的关联分析（分桶对比），量化质量对业务的影响。
- 思路：按质量分桶（首帧 < 1s / 1~3s / > 3s）→ 各桶业务指标（观看时长中位数/打赏率/次日留存）→ 关联结论（首帧每慢 1s 留存降 X%）。
- 评分点：分桶设计；业务指标选择；关联结论表述。

```javascript
async function qualityBusinessCorrelation(liveSamples) {
  const buckets = { fast: [], mid: [], slow: [] };            // 首帧分桶
  for (const s of liveSamples) {
    const bucket = s.firstFrameMs < 1000 ? 'fast'
      : s.firstFrameMs < 3000 ? 'mid' : 'slow';
    buckets[bucket].push(s);
  }
  return Object.entries(buckets).map(([name, samples]) => ({
    bucket: name, count: samples.length,
    avgWatchSeconds: avg(samples.map(s => s.watchSeconds)),    // 观看时长
    retentionD1: samples.filter(s => s.returnedNextDay).length / samples.length,   // 次日留存
    giftRate: samples.filter(s => s.gifted).length / samples.length,   // 打赏率
  }));
  // 结论示例：首帧 > 3s 的观众次留比 < 1s 的低 15%——量化质量价值
}
```
