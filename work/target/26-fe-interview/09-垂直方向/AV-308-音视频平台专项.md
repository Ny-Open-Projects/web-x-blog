## AV-308：音视频平台专项：弹幕敏感词与审核分层

**答**：
- 题目：弹幕审核分层——本地词库（Trie 即时拦截）→ 云端 AI 审核（异步，违规撤回）→ 人工复审（高敏感房间）。复用 HW-394。
- 思路：三层漏斗——L1 本地 Trie（毫秒级拦截已知词）→ L2 发送后异步 AI（违规撤回+用户警告）→ L3 高敏房间全人工。
- 评分点：三层漏斗；撤回机制；误杀申诉。

```javascript
class DanmakuModeration {
  async send(text) {
    // L1：本地 Trie 即时拦截
    const local = this.localFilter.filter(text);
    if (local.blocked) return { sent: false, reason: 'local-blocked' };
    const masked = local.text;
    await this.ws.send({ type: 'danmaku', text: masked });     // 发送（可能已被 L2 拦）
    // L2：异步 AI 审核（服务端）
    // 违规 → 服务端广播撤回该条 → 前端移除 + 用户警告
  }
  onRevoke({ msgId, reason }) {                                // 撤回处理
    this.removeDanmaku(msgId);
    showToast(`弹幕「${reason}」已被移除`);
    this.strikeCount++;                                        // 违规计数
    if (this.strikeCount >= 3) this.muteSelf(300);             // 3 次禁言 5 分钟
  }
}
```
