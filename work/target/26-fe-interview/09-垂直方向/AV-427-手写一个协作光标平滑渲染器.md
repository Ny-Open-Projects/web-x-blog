## AV-427：手写一个协作光标平滑渲染器

**答**：
- 需求：implement CursorAnimator(canvas)。onRemote(userId, x, y) 更新目标；rAF 循环对每光标 lerp（速度 0.3），到达阈值内贴齐；用户 3s 无更新淡出移除；输出绘制函数。
- 边界：首帧直接定位（不 lerp）；多光标颜色由 userId hash；canvas 尺寸变化重置。
- 评分点：lerp 平滑；首帧定位；超时移除；颜色 hash

```javascript
class CursorAnimator {
  constructor(ctx) {
    this.ctx = ctx; this.cursors = new Map();
    this.loop();
  }
  onRemote(userId, x, y) {
    const c = this.cursors.get(userId);
    this.cursors.set(userId, {
      x: c ? c.x : x, y: c ? c.y : y,          // 首帧直接定位
      tx: x, ty: y, color: hashColor(userId), lastAt: Date.now() });
  }
  loop = () => {
    const now = Date.now();
    for (const [id, c] of this.cursors) {
      if (now - c.lastAt > 3000) { this.cursors.delete(id); continue; }
      c.x += (c.tx - c.x) * 0.3;               // lerp 平滑
      c.y += (c.ty - c.y) * 0.3;
      this.ctx.fillStyle = c.color;
      this.ctx.beginPath();
      this.ctx.arc(c.x, c.y, 5, 0, Math.PI * 2);
      this.ctx.fill();
    }
    requestAnimationFrame(this.loop);
  }
}
function hashColor(id) {
  let h = 0; for (const ch of id) h = (h * 31 + ch.charCodeAt(0)) >>> 0;
  return `hsl(${h % 360}, 70%, 55%)`;
}
```
