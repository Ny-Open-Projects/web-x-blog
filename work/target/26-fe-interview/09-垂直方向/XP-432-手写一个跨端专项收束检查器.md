## XP-432：手写一个跨端专项收束检查器

**答**：
- 需求：implement FinalAudit(signals)。signals 为各专项检查结果 { launch, render, bridge, memory, network, stability }（各含 pass 与 failItems）；输出总分（pass 域占比）、红项列表、发布建议（全过可发布/有红项需修）。
- 边界：域缺失按未通过；failItems 为字符串数组；输出按严重排序（launch/stability 优先）；score 保留 1 位。
- 评分点：六域聚合；红项排序；发布建议；缺失按未过

```javascript
function FinalAudit(signals) {
  const DOMAINS = ['launch', 'stability', 'render', 'bridge', 'memory', 'network'];
  const rows = DOMAINS.map(d => ({
    domain: d,
    pass: signals[d]?.pass ?? false,
    failItems: signals[d]?.failItems ?? ['missing'],
  }));
  const passed = rows.filter(r => r.pass).length;
  const red = rows.filter(r => !r.pass)
    .sort((a, b) => DOMAINS.indexOf(a.domain) - DOMAINS.indexOf(b.domain));
  return {
    score: +(passed / DOMAINS.length * 100).toFixed(1),
    red: red.map(r => ({ domain: r.domain, items: r.failItems })),
    verdict: red.length === 0 ? '可发布'
      : red.some(r => ['launch', 'stability'].includes(r.domain))
        ? '阻塞发布（核心域未过）' : '有条件发布（限期修复）',
  };
}
```
