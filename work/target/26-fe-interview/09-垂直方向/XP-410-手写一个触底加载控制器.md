## XP-410：手写一个触底加载控制器

**答**：
- 需求：implement InfiniteLoader(el, loadFn, { threshold=200 })。scroll 监听（rAF 节流 + passive）近底触发 loadFn；并发锁（loading 期间不触发）；无更多（空结果）停止并回调；错误重试 1 次后停（手动重试按钮回调）。
- 边界：loadFn 返回空数组判 no-more；卸载时清理监听；首次自动加载一页。
- 评分点：rAF 节流；并发锁；重试降级；生命周期

```javascript
class InfiniteLoader {
  constructor(el, loadFn, { threshold = 200 } = {}) {
    this.el = el; this.loadFn = loadFn; this.th = threshold;
    this.loading = false; this.hasMore = true;
  }
  async maybeLoad() {
    if (this.loading || !this.hasMore) return;
    const near = this.el.scrollHeight - this.el.scrollTop
      - this.el.clientHeight < this.th;
    if (!near) return;
    this.loading = true;
    try {
      let items;
      try { items = await this.loadFn(); }
      catch { items = await this.loadFn(); }           // 重试 1 次
      if (!items.length) { this.hasMore = false;
        this.onNoMore?.(); }
    } catch (e) {
      this.hasMore = false;
      this.onError?.(e);                               // 手动重试按钮
    } finally { this.loading = false; }
  }
  bind() {
    let tick = false;
    this._handler = () => {
      if (tick) return; tick = true;
      requestAnimationFrame(() => { tick = false; this.maybeLoad(); });
    };
    this.el.addEventListener('scroll', this._handler, { passive: true });
    this.maybeLoad();                                  // 首页
  }
  destroy() { this.el.removeEventListener('scroll', this._handler); }
}
```
