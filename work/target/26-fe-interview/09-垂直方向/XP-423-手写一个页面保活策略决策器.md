## XP-423：手写一个页面保活策略决策器

**答**：
- 需求：implement KeepAliveDecision(tabs, memRatio, maxKeep=3)。决策：core tab 保活；memRatio > 0.8 时非核心全释放、core 减到 2；输出 { keep: [id], destroy: [id] }。
- 边界：tabs 为 [{ id, core, lastActive }]；保活按 lastActive 优先（最近活跃）；重复 id 去重；maxKeep 上限约束。
- 评分点：core 优先；水位联动；去重；上限

```javascript
function KeepAliveDecision(tabs, memRatio, maxKeep = 3) {
  const uniq = new Map(tabs.map(t => [t.id, t]));
  const core = [...uniq.values()].filter(t => t.core)
    .sort((a, b) => b.lastActive - a.lastActive);
  const others = [...uniq.values()].filter(t => !t.core);
  const keepLimit = memRatio > 0.8 ? 2 : maxKeep;
  return {
    keep: core.slice(0, keepLimit).map(t => t.id),
    destroy: [
      ...core.slice(keepLimit),
      ...(memRatio > 0.8 ? others : []),
    ].map(t => t.id),
  };
}
// destroy 页面状态序列化到 store，返回时恢复
```
