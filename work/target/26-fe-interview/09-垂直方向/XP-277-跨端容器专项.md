## XP-277：跨端容器专项：容器与 Native 双端日志关联排查（笔试）

**答**：
- 题目：容器问题排查——JS 日志与 Native 日志关联（同一 traceId 贯穿）→ 排查「JS 调 Native 失败」问题。
- 思路：请求入口生成 traceId → JS 日志/Native 日志/桥调用日志均带 traceId → 按 traceId 聚合还原全链路。
- 评分点：traceId 贯穿；日志聚合；归因分析。

```javascript
class TraceIdCorrelation {
  trace(method, args) {                                            // 桥调用日志
    const traceId = this.currentTraceId ??= genTraceId();           // traceId 贯穿
    containerLogger.info('bridge-call', { method, traceId, args: redact(args) });
    nativeLogger.info('bridge-receive', { method, traceId });       // Native 侧同 traceId
    return this.execute(method, args);
  }
  queryTrace(traceId) {                                             // 按 traceId 聚合
    const jsLogs = containerLogger.query({ traceId });              // JS 日志
    const nativeLogs = nativeLogger.query({ traceId });              // Native 日志
    return mergeTimeline([...jsLogs, ...nativeLogs]);                // 时间线合并（还原全链路）
  }
}
// 案例：JS 调 native.upload 失败 → traceId 聚合发现 Native 侧权限被拒 → 归因清晰
```
