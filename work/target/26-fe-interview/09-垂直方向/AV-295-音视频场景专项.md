## AV-295：音视频场景专项：直播间消息时序与优先级

**答**：
- 题目：直播间消息优先级体系——系统公告 > 礼物 > 弹幕，同优先级保序；阻塞弹幕（洪泛）不影响高优先级消息即时展示。
- 思路：双队列（高优即时、低优限速）；信令通道（可靠）与弹幕通道（可丢）分离；渲染层按优先级插队。
- 评分点：优先级队列；双通道分离；洪泛不影响公告。

```javascript
class MessagePriorityQueue {
  constructor() {
    this.high = [];                                          // 系统/礼物（可靠通道）
    this.normal = [];                                         // 弹幕（可丢通道）
  }
  onHighPriority(msg) { this.high.push(msg); this.render(msg); }   // 即时渲染
  onNormal(msg) {                                            // 弹幕限速
    if (this.normal.length < 50) this.normal.push(msg);
    else this.dropped++;                                     // 过载丢弃
  }
  drain() {                                                    // rAF 消费低优
    const batch = this.normal.splice(0, 8);                   // 每帧 8 条
    batch.forEach(m => this.render(m));
    if (this.normal.length) requestAnimationFrame(() => this.drain());
  }
}
// 双通道：WS 信令（系统/礼物，可靠有序）+ WS 弹幕（可丢，洪泛不影响信令）
```
