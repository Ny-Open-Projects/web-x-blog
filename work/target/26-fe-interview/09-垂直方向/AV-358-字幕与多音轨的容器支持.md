## AV-358：字幕与多音轨的容器支持

**答**：
- 容器：MP4 支持 WebVTT 字幕轨/多音轨；HLS 用 EXT-X-MEDIA 声明音轨/字幕轨。
- 前端：audioTracks/videoTracks API（浏览器支持参差）——Safari 好 Chrome 需 MSE 手动。
- 实践：多语言字幕用分离 VTT 文件 + track 元素（最兼容）。

```javascript
// 字幕 track 管理
function setupSubtitles(video, langs) {
  for (const [lang, url] of Object.entries(langs)) {
    const track = document.createElement('track');
    track.kind = 'subtitles'; track.label = lang;
    track.srclang = lang; track.src = url;
    video.appendChild(track);
  }
  return {
    enable(lang) {
      [...video.textTracks].forEach(t =>
        t.mode = t.language === lang ? 'showing' : 'disabled');
    },
    active: () => [...video.textTracks].find(t => t.mode === 'showing')?.language,
  };
}
```
