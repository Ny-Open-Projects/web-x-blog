## XP-251：跨端容器桥接进阶：批量指令合并与优先级

**答**：
- 题目：桥调用合并——同帧多次 commit 合并为一次桥调用（16ms 窗口），紧急操作（导航）插队直达。
- 思路：commit 收集到队列 → 16ms 定时器或达阈值（50 条）flush；导航等高优操作 flushNow（立即）。
- 评分点：合并窗口；阈值触发；紧急直达。

```javascript
class BatchingBridge {
  constructor(native, { windowMs = 16, threshold = 50 } = {}) {
    this.native = native; this.queue = []; this.timer = null;
    this.windowMs = windowMs; this.threshold = threshold;
  }
  commit(ops, { urgent = false } = {}) {                       // 提交（合并）
    if (urgent) return this.native.send(ops);                   // 紧急：直达
    this.queue.push(...ops);
    if (this.queue.length >= this.threshold) return this.flush();   // 阈值触发
    if (!this.timer) this.timer = setTimeout(() => this.flush(), this.windowMs);   // 窗口
  }
  flush() {
    clearTimeout(this.timer); this.timer = null;
    if (!this.queue.length) return;
    const ops = this.queue.splice(0);
    this.native.send(ops);                                       // 一次桥调用
  }
}
// 收益：滚动场景桥调用 60/s → 4/s（16ms 窗口合并）
```
