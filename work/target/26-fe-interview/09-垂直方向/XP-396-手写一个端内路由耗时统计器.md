## XP-396：手写一个端内路由耗时统计器

**答**：
- 需求：implement RouteTimer。start(route) 记录开始；ready(route) 记录就绪（渲染+数据）；report() 输出每路由 { count, p50, p75, slowest }（耗时 ms）；pending 统计未 ready 的（泄漏线索）。
- 边界：重复 ready 忽略；start 未 ready 超 5s 标记 stuck；路由排序按 p75 降序。
- 评分点：pending 管理；分位统计；stuck 检测；排序

```javascript
class RouteTimer {
  constructor() { this.pending = new Map(); this.done = []; }
  start(route, at = performance.now()) {
    this.pending.set(`${route}@${at}`, { route, at });
  }
  ready(route, at = performance.now()) {
    const key = [...this.pending.keys()].find(k => k.startsWith(route + '@'));
    if (!key) return false;                            // 重复/无 start
    const { at: t0 } = this.pending.get(key);
    this.pending.delete(key);
    this.done.push({ route, ms: Math.round(at - t0) });
    return true;
  }
  report(now = performance.now()) {
    const byRoute = {};
    for (const d of this.done)
      (byRoute[d.route] ??= []).push(d.ms);
    const stuck = [...this.pending.values()]
      .filter(p => now - p.at > 5000).map(p => p.route);
    const rows = Object.entries(byRoute).map(([route, arr]) => {
      const s = [...arr].sort((a, b) => a - b);
      return { route, count: s.length, p50: s[s.length >> 1],
        p75: s[Math.floor(s.length * 0.75)], slowest: s[s.length - 1] };
    }).sort((a, b) => b.p75 - a.p75);
    return { rows, stuck };
  }
}
```
