## AV-371：直播弹幕与视频流的渲染协同

**答**：
- 问题：弹幕高频 DOM 更新与视频渲染竞争主线程——卡顿时两者互相影响。
- 方案：弹幕 canvas 渲染（rAF 驱动，独立离屏）、批量更新（100ms 合帧）、限量（同屏 < 50 条）。
- 布局：滚动/顶部/底部三区模式，防遮挡（人脸检测可选）。

```javascript
// Canvas 弹幕
class DanmakuCanvas {
  constructor(canvas, { maxOnScreen = 50 } = {}) {
    this.ctx = canvas.getContext('2d');
    this.pool = []; this.lanes = Math.floor(canvas.height / 30);
    this.max = maxOnScreen;
  }
  push(text) {
    if (this.pool.length >= this.max) return;
    const lane = Math.floor(Math.random() * this.lanes);
    this.pool.push({ text, x: this.ctx.canvas.width,
      y: lane * 30 + 20, speed: 2 + Math.random() });
  }
  tick() {
    const { width } = this.ctx.canvas;
    this.ctx.clearRect(0, 0, width, this.ctx.canvas.height);
    this.ctx.font = '14px sans-serif';
    this.pool = this.pool.filter(d => {
      this.ctx.fillText(d.text, d.x, d.y);
      d.x -= d.speed;
      return d.x > -this.ctx.measureText(d.text).width;
    });
  }
}
```
