## AV-335：视频编码的本质：为什么压缩可行

**答**：
- 冗余三类：空间冗余（相邻像素相似）、时间冗余（相邻帧相似）、统计冗余（熵编码可压符号分布）。
- 编码器工作：预测（消除时空冗余）→ 变换（DCT 集中能量）→ 量化（有损丢弃）→ 熵编码（无损压缩）。
- 权衡：码率-质量-复杂度三角，任何编码器参数都在这三者间取舍。

```javascript
// 编码管线概念模型
function encodePipeline(frame, ref, { qp = 28 } = {}) {
  const predicted = interPredict(frame, ref);        // 时间冗余：运动补偿
  const residual = subtract(frame, predicted);       // 残差
  const transformed = dct2d(residual);               // 能量集中
  const quantized = quant(transformed, qp);          // 有损：QP 越大越糊
  const bits = entropyEncode(quantized);             // CAVLC/CABAC
  return { bits, reconstruct: add(predicted, dequant(quantized, qp)) };
}
// QP 28 vs 40：同帧体积差 3~5 倍，PSNR 差 3~6dB
```
