## XP-389：手写一个内存水位控制器

**答**：
- 需求：implement MemoryGovernor(limitMB)。update({ jsMB, nativeMB }) 记录水位；policy() 返回 normal/moderate/aggressive（>70%/85%）；aggressive 触发回调（清缓存/关动画）；恢复滞回（降到 65% 以下恢复 normal）。
- 边界：limit <= 0 抛错；回调只触发一次（状态变更时）；未知字段忽略。
- 评分点：水位计算；三档策略；滞回恢复；状态回调

```javascript
class MemoryGovernor {
  constructor(limitMB) {
    if (limitMB <= 0) throw new Error('limit > 0');
    this.limit = limitMB; this.ratio = 0; this.state = 'normal';
  }
  update({ jsMB = 0, nativeMB = 0 } = {}) {
    this.ratio = (jsMB + nativeMB) / this.limit;
    const next = this.ratio > 0.85 ? 'aggressive'
      : this.ratio > 0.7 ? 'moderate'
      : this.ratio < 0.65 ? 'normal' : this.state;
    if (next !== this.state) {
      const prev = this.state;
      this.state = next;
      this.onStateChange?.(prev, next);
    }
    return { ratio: +this.ratio.toFixed(2), state: this.state };
  }
}
```
