## AV-267：音视频弱网对抗：FEC+重传+编码自适应联合策略

**答**：
- 题目：设计联合弱网策略——丢包/RTT/带宽三信号 → 联合决策（FEC 开关/重传策略/编码参数）。
- 思路：丢包 < 5% → NACK 足够；5~15% → FEC + 降码率；> 15% → 强降级（帧率减半+分辨率减半+FEC 满配）。
- 评分点：三信号联合决策；策略表；平滑切换。

```javascript
function jointWeakNetworkStrategy({ loss, rtt, bandwidth }) {
  const decisions = [];
  if (loss < 0.05) {
    decisions.push({ action: 'nack-only' });                // NACK 足够
  } else if (loss < 0.15) {
    decisions.push({ action: 'fec-on', redundancy: 0.2 },
      { action: 'bitrate', value: bandwidth * 0.7 });       // 冗余+降码率
  } else {
    decisions.push({ action: 'fec-max', redundancy: 0.5 },
      { action: 'halve-fps' }, { action: 'halve-resolution' });
  }
  if (rtt > 0.3) decisions.push({ action: 'prefer-fec-over-nack' });   // 高 RTT 重传太慢
  return decisions;
}
// 平滑：决策变更需连续 3 次采样确认——防抖动频繁切参数
```
