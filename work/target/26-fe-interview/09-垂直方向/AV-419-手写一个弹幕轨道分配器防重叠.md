## AV-419：手写一个弹幕轨道分配器（防重叠）

**答**：
- 需求：implement DanmakuLanes(width, laneH)。push(text, duration) 分配轨道：选择预计到达时间不与现有弹幕重叠的轨道；估算宽度（text.length × fontSize）；无可用轨道丢弃并计数；输出 { lane, dropped: bool }。
- 边界：宽度超屏（> width）拆分或丢弃（返回 dropped）；轨道数由高度/ laneH 决定；duration 默认 8s。
- 评分点：宽度估算；冲突检测；定时回收；满载丢弃

```javascript
class DanmakuLanes {
  constructor(width, laneH = 30) {
    this.width = width; this.laneH = laneH;
    this.lanes = [];                                 // 每轨道: [ { exitAt, enterAt } ]
  }
  laneCount(height) { return Math.floor(height / this.laneH); }
  push(text, duration = 8, now = Date.now()) {
    const w = text.length * 14;                      // fontSize 14
    const speed = (this.width + w) / duration;       // px/ms
    const n = this.lanes.length || this.laneCount(200);
    for (let i = 0; i < n; i++) {
      const items = this.lanes[i] ??= [];
      const ok = items.every(it =>
        now >= it.exitAt || now + duration <= it.enterAt);
      if (ok) {
        items.push({ enterAt: now, exitAt: now + duration });
        setTimeout(() => {
          const arr = this.lanes[i];
          const j = arr.findIndex(x => x.enterAt === now);
          if (j >= 0) arr.splice(j, 1);
        }, duration * 1000);
        return { lane: i, dropped: false };
      }
    }
    return { lane: -1, dropped: true };              // 满载丢弃
  }
}
```
