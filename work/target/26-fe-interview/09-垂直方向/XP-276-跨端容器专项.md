## XP-276：跨端容器专项：容器内存水位监控与自动降级（笔试）

**答**：
- 题目：容器内存水位监控——JS heap 采样 → 水位分档（60%/75%/85%）→ 分级降级（关动画/释放页面/GC 提示）。
- 思路：内存采样（performance.memory / Native heap）→ 分档阈值 → 降级动作（HW-821/822 复用）→ 恢复滞回。
- 评分点：水位分档；降级动作；滞回恢复。

```javascript
class MemoryWatermark {
  constructor() { this.state = 0; this.lastChange = 0; }           // 0 正常 1~3 降级档
  tick(heapUsedMB, heapMaxMB) {                                     // 采样
    const ratio = heapUsedMB / heapMaxMB;
    const up = ratio > 0.85 ? 3 : ratio > 0.75 ? 2 : ratio > 0.6 ? 1 : 0;
    if (up > this.state) return this.escalate(up);                  // 升级立即
    if (up < this.state && Date.now() - this.lastChange > 30000)     // 滞回恢复
      return this.deescalate();
  }
  escalate(level) {                                                  // 分级降级
    this.state = level; this.lastChange = Date.now();
    const actions = { 1: 'disable-animations', 2: 'release-background-pages',
      3: 'release-all-caches' };
    bridge.commit([{ op: 'memory-degrade', level, action: actions[level] }]);
  }
}
```
