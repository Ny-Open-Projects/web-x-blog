## AV-326：音视频平台专项：直播间封禁与申诉流程（笔试）

**答**：
- 题目：直播间违规封禁——封禁分级（警告/限流/封禁）、申诉流程（提交→审核→结果通知）、解封条件。
- 思路：违规计分（不同违规不同分值，累积到阈值分级处罚）；申诉工单（证据提交→人工审核→结果推送）；解封自动评估。
- 评分点：违规计分；申诉流程；解封条件。

```javascript
class RoomPenaltySystem {
  async reportViolation(roomId, type, evidence) {              // 违规上报
    const score = VIOLATION_SCORES[type];                       // 违规分值
    const total = await this.addPenaltyScore(roomId, score);     // 累积
    const penalty = PENALTY_TIERS.find(t => total >= t.threshold);   // 分级处罚
    if (penalty) {
      await this.applyPenalty(roomId, penalty);                  // 警告/限流/封禁
      await notifyOwner(roomId, { penalty, appealUrl: `/appeal/${roomId}` });   // 通知+申诉入口
    }
  }
  async submitAppeal(roomId, evidence) {                       // 申诉
    const ticket = await auditStore.put({ type: 'appeal', roomId,
      evidence, status: 'pending', ts: Date.now() });
    notifyReviewers(ticket);                                     // 人工审核
    return { ticketId: ticket.id, eta: '48h' };
  }
}
```
