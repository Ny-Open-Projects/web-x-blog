## XP-322：跨端文件上传的统一（分片/并发/进度）

**答**：
- 统一 API：upload(file, { chunk, conc, onProgress })，各端 adapter（小程序 uploadFile/RN Blob/Flutter MultipartFile）。
- 优化：并发 3、失败分片重试、弱网降并发（301 联动）。
- 校验：分片 hash + 服务端合并校验。

```javascript
// 统一上传
async function uploadFile(file, adapter, { chunkMB = 4, conc = 3, onProgress } = {}) {
  const total = Math.ceil(file.size / (chunkMB * 1024 * 1024));
  let done = 0;
  for (let i = 0; i < total; i += conc) {
    const batch = Array.from({ length: conc }, (_, k) => i + k)
      .filter(k => k < total);
    await Promise.all(batch.map(async idx => {
      const slice = adapter.slice(file, idx * chunkMB * 1024 * 1024,
        (idx + 1) * chunkMB * 1024 * 1024);
      await adapter.uploadChunk(idx, slice);
      done++; onProgress?.(done / total);
    }));
  }
}
```
