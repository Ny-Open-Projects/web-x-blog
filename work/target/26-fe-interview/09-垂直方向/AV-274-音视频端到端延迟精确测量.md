## AV-274：音视频端到端延迟精确测量：帧号水印法

**答**：
- 题目：精确测量端到端延迟——发送端画面嵌入毫秒时间戳水印，接收端 OCR/解码水印差值 = 真实延迟（比 NTP 估算准）。
- 思路：发送端 canvas 画当前时间戳 → 推流；接收端截帧 → 识别时间戳 → 差值 = 延迟。自动化：模板匹配识别数字。
- 评分点：水印方案；识别方式（模板匹配/OCR）；与 getStats 估算的差异。

```javascript
async function measureE2ELatency(senderCanvas, receiverVideo) {
  // 发送端已嵌入时间戳（AV-273 帧号水印）
  return new Promise((res) => {
    receiverVideo.requestVideoFrameCallback(async () => {
      const canvas = document.createElement('canvas');
      canvas.width = receiverVideo.videoWidth;
      canvas.getContext('2d').drawImage(receiverVideo, 0, 0);
      const sentTs = await ocrTimestamp(canvas);             // OCR 识别发送端时间戳
      const latency = Date.now() - sentTs;                   // 真实端到端延迟
      res({ latencyMs: latency,
        breakdown: { network: latency - decodeRenderMs } });   // 减去本地解码渲染
    });
  });
}
// getStats 估算（RTT/2）不精确（不对称路由）——水印法是黄金标准
// 自动化：模板匹配数字识别（无需 OCR 库，9 个数字模板 + 位置固定）
```
