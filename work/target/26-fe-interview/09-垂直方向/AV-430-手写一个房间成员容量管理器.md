## AV-430：手写一个房间成员容量管理器

**答**：
- 需求：implement RoomCapacity(limit)。join(userId) 检查容量（满员按角色优先级踢出最久不活跃 viewer）；leave(userId)；active(now) 返回 10 分钟内活跃成员；输出 join 结果 { ok, kicked }。
- 边界：重复 join 视为刷新活跃时间；owner 不被踢；limit <= 0 抛错；kicked 成员收到通知事件。
- 评分点：容量检查；踢出策略；owner 保护；活跃过滤

```javascript
class RoomCapacity {
  constructor(limit) {
    if (limit <= 0) throw new Error('limit 必须 > 0');
    this.limit = limit; this.members = new Map();     // id -> { role, lastActive }
  }
  join(userId, role, now = Date.now()) {
    this.members.set(userId, { role, lastActive: now });
    let kicked = null;
    if (this.members.size > this.limit) {
      const victim = [...this.members.entries()]
        .filter(([id, m]) => m.role !== 'owner' && id !== userId)
        .sort((a, b) => a[1].lastActive - b[1].lastActive)[0];
      if (victim) {
        this.members.delete(victim[0]);
        kicked = { id: victim[0], reason: '容量满，最久不活跃' };
      }
    }
    return { ok: true, kicked };
  }
  leave(userId) { this.members.delete(userId); }
  active(now = Date.now()) {
    return [...this.members.entries()]
      .filter(([, m]) => now - m.lastActive < 600_000)
      .map(([id]) => id);
  }
}
```
