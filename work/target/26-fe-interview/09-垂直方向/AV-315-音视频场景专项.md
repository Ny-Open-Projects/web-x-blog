## AV-315：音视频场景专项：直播房间状态机与生命周期

**答**：
- 题目：直播房间状态机——idle→living→paused→ended，转换事件（开播/暂停/结束/异常断开）与前端 UI 联动。
- 思路：状态机驱动 UI（HW-309 复用）；异常断开（推流端断）→ paused → 自动结束（超时）或恢复；观众端状态同步（信令广播）。
- 评分点：状态定义与转换；异常处理；观众端同步。

```javascript
const roomStates = {
  idle: { next: ['living'], enter: '创建房间' },
  living: { next: ['paused', 'ended'], enter: '开播' },
  paused: { next: ['living', 'ended'], enter: '推流中断/手动暂停',
    timeout: { after: 300000, to: 'ended' } },               // 暂停超 5 分钟自动结束
  ended: { terminal: true, enter: '正常结束/异常超时' },
};
class RoomStateMachine extends StateMachine {
  constructor(roomId) { super({ initial: 'idle', transitions: [
    { from: 'idle', event: 'start', to: 'living' },
    { from: 'living', event: 'push-interrupt', to: 'paused' },   // 推流断开
    { from: 'paused', event: 'push-recover', to: 'living' },     // 恢复
    { from: 'paused', event: 'timeout', to: 'ended' },           // 超时结束
    { from: 'living', event: 'stop', to: 'ended' },
  ] }); }
}
// 观众端：信令广播状态变更 → UI 联动（暂停提示/回放引导）
```
