## AV-397：协作会话的掉线成员管理

**答**：
- 状态机：online（心跳正常）/ away（10s 无心跳）/ offline（30s）——UI 按状态显示。
- 掉线处理：其光标淡出、锁释放（超时自动解锁）、草稿保存提示。
- 回归：重新上线后走 391 同步流程，广播 presence 恢复。

```javascript
// 成员状态机
const MEMBER_STATES = { online: 0, away: 10_000, offline: 30_000 };
function memberState(lastHeartbeat, now = Date.now()) {
  const gap = now - lastHeartbeat;
  for (const [state, ms] of Object.entries(MEMBER_STATES))
    if (gap < ms) return state;
  return 'offline';
}
function releaseStaleLocks(doc, now = Date.now(), ttl = 60_000) {
  doc.shapes.forEach((shape, id) => {
    if (shape.lockedBy && now - shape.lockedAt > ttl) {
      doc.getMap('shapes').set(id, { ...shape, lockedBy: null });
      report({ type: 'lock-released', id, by: 'timeout' });
    }
  });
}
```
