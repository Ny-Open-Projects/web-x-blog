## AV-253：直播多码率转码规格：梯度和切片对齐

**答**：
- 转码规格梯度：1080p@4M / 720p@2M / 480p@1M / 360p@600k——ABR 切换需各档 GOP 对齐（同 I 帧位置），否则切换时跳帧。
- HLS 切片对齐：多码率切片边界必须一致（同起止时间戳）——转码器需统一切片配置。
- 前端感知：切档瞬间黑屏/跳帧 = GOP/切片未对齐。

```javascript
const transcodeLadder = {
  profiles: [
    { name: '1080p', bitrate: 4000000, fps: 30 },
    { name: '720p', bitrate: 2000000, fps: 30 },
    { name: '480p', bitrate: 1000000, fps: 30 },
  ],
  gopAligned: true,                                         // 各档 GOP 对齐（ABR 切换不跳帧）
  hlsSegmentAligned: true,                                  // 切片边界一致
  keyframeInterval: 2,                                      // 2s GOP（切片 2s 的倍数）
};
// 验证：各档切片首帧时间戳一致 → ABR 切换无跳帧
// 未对齐症状：切 720p→1080p 画面跳 2s 或黑屏 1 帧
```
