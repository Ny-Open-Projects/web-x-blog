## AV-423：手写一个视频抽帧器（指定时间点截帧）

**答**：
- 需求：implement grabFrames(videoUrl, timestamps)。按时间点 seek 并 drawImage 到 canvas，输出 { time, blob } 数组；seek 精度：targetTime 后等 seeked 事件；并发限制 1（video 单实例）。
- 边界：时间点超过时长 clamp 到 duration - 0.1；seek 精度问题（关键帧对齐）用 seekable 校验；失败时间点跳过并记录。
- 评分点：顺序 seek；超时保护；clamp；失败跳过

```javascript
async function grabFrames(videoUrl, timestamps, { w = 320 } = {}) {
  const video = document.createElement('video');
  video.src = videoUrl; video.muted = true; video.preload = 'auto';
  await new Promise(r => video.onloadedmetadata = r);
  const h = Math.round(w * video.videoHeight / video.videoWidth);
  const canvas = new OffscreenCanvas(w, h);
  const ctx = canvas.getContext('2d');
  const out = [], failed = [];
  for (const t0 of timestamps) {
    const t = Math.min(t0, video.duration - 0.1);
    try {
      await new Promise((resolve, reject) => {
        video.onseeked = resolve;
        video.onerror = reject;
        video.currentTime = Math.max(0, t);
        setTimeout(() => reject(new Error('seek timeout')), 3000);
      });
      ctx.drawImage(video, 0, 0, w, h);
      out.push({ time: t, blob: await canvas.convertToBlob({ type: 'image/jpeg', quality: 0.8 }) });
    } catch { failed.push(t0); }
  }
  return { frames: out, failed };
}
```
