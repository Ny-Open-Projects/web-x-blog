## AV-330：音视频平台专项：直播间弹幕消息持久化与回放（笔试）

**答**：
- 题目：弹幕持久化——实时弹幕写入队列 → 异步落库（批量）→ 回放时按时间轴重放（与视频进度对齐）。
- 思路：弹幕先入消息队列（Kafka）→ 消费者批量落库（100 条/批）；回放：按视频时间戳查询弹幕 → 与播放器进度同步渲染。
- 评分点：队列解耦；批量落库；回放同步。

```javascript
class DanmakuPersistence {
  async onDanmaku(msg) {                                        // 实时：入队列
    await kafka.produce('danmaku', { ...msg, liveId: this.liveId, ts: Date.now() });
  }
  async flushToDB() {                                            // 消费者批量落库
    const batch = await kafka.consume('danmaku', 100);           // 100 条/批
    await db.bulkInsert('danmaku', batch);                       // 批量插入
  }
  async replay(liveId, videoTs, windowSec = 5) {                 // 回放同步
    const danmaku = await db.query(
      'SELECT * FROM danmaku WHERE live_id = ? AND ts BETWEEN ? AND ?',
      [liveId, videoTs * 1000, (videoTs + windowSec) * 1000]);   // 时间窗口查询
    danmaku.forEach(d => this.render(d));                        // 与播放进度同步渲染
  }
}
```
