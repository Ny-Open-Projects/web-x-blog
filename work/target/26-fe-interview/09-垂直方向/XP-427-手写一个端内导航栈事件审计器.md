## XP-427：手写一个端内导航栈事件审计器

**答**：
- 需求：implement NavAudit()。记录 push/pop/replace 事件 [{ action, from, to, at }]；统计每页面进出次数与平均停留时长（pop 时结算）；report() 输出 { byPage: [{ page, visits, avgStayMs }], depth }（当前栈深）。
- 边界：replace 算一次进出；页面未 pop 不结算（当前在栈）；无事件空输出；depth = 当前未结算数。
- 评分点：栈事件；停留时长；深度；排序

```javascript
class NavAudit {
  constructor() { this.events = []; this.stack = []; }
  push(page, at = Date.now()) {
    this.stack.push({ page, at });
    this.events.push({ action: 'push', to: page, at });
  }
  pop(at = Date.now()) {
    const top = this.stack.pop();
    if (!top) return null;
    this.events.push({ action: 'pop', from: top.page, at });
    return { page: top.page, stayMs: at - top.at };
  }
  report(now = Date.now()) {
    const stays = new Map();
    for (const e of this.events)
      if (e.action === 'pop') {
        const v = stays.get(e.from) ?? { visits: 0, total: 0 };
        v.visits++; v.total += (e.stayMs ?? 0);
        stays.set(e.from, v);
      }
    return { depth: this.stack.length,
      byPage: [...stays.entries()].map(([page, v]) =>
        ({ page, visits: v.visits, avgStayMs: Math.round(v.total / v.visits) }))
        .sort((a, b) => b.avgStayMs - a.avgStayMs) };
  }
}
```
