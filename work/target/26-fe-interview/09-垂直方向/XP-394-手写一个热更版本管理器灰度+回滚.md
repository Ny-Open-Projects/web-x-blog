## XP-394：手写一个热更版本管理器（灰度+回滚）

**答**：
- 需求：implement HotfixManager。apply({ version, grayPct, sig })：灰度命中（uid hash < grayPct）且签名校验通过才应用；rollback(to) 切回历史版本（保留最近 2 版）；current() 返回当前版本。
- 边界：签名失败不应用并上报；rollback 到不存在版本报错；同版本重复 apply 幂等；历史版本上限 2 淘汰最旧。
- 评分点：灰度判定；签名门控；回滚上限；幂等

```javascript
class HotfixManager {
  constructor(uid, verifySig) {
    this.uid = uid; this.verify = verifySig;
    this.currentV = 'base'; this.history = [];       // [{ version, appliedAt }]
  }
  async apply({ version, grayPct, sig }) {
    if (version === this.currentV) return { applied: false, note: '已是该版本' };
    if (hash(this.uid) % 100 >= grayPct)
      return { applied: false, note: '不在灰度范围' };
    if (!(await this.verify(sig)))
      { report({ type: 'hotfix-sig-fail', version }); return { applied: false }; }
    this.history.push({ version: this.currentV, appliedAt: Date.now() });
    if (this.history.length > 2) this.history.shift();   // 保留 2 版
    this.currentV = version;
    return { applied: true, version };
  }
  rollback(to) {
    if (!this.history.some(h => h.version === to))
      throw new Error('版本不存在或已淘汰');
    this.currentV = to;
    return { rolledBack: to };
  }
  current() { return this.currentV; }
}
function hash(s) { let h = 0; for (const c of String(s)) h = (h * 31 + c.charCodeAt(0)) >>> 0; return h; }
```
