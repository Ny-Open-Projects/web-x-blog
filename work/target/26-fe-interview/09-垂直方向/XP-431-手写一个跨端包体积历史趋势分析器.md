## XP-431：手写一个跨端包体积历史趋势分析器

**答**：
- 需求：implement BundleTrend(history)。history 为 [{ date, end, jsKB }]；trend(end) 返回最近 30 天序列与斜率（线性回归）；预警：斜率 > 5KB/天 持续（预测 30 天后超预算）；输出 { slopeKBPerDay, forecast, alert }。
- 边界：样本 < 5 标 insufficient；斜率两位小数；forecast 按当前预算外推；同日多记录取均值。
- 评分点：线性回归；趋势预警；外推；样本门槛

```javascript
function BundleTrend(history, budgetKB = 3000) {
  return {
    trend(end, now = Date.now()) {
      const rows = history.filter(h => h.end === end && now - new Date(h.date) < 30 * 86400_000);
      if (rows.length < 5) return { state: 'insufficient' };
      const pts = rows.map(r => ({ x: new Date(r.date).getTime() / 86400_000, v: r.jsKB }));
      const n = pts.length;
      const sx = pts.reduce((s, p) => s + p.x, 0);
      const sy = pts.reduce((s, p) => s + p.v, 0);
      const sxy = pts.reduce((s, p) => s + p.x * p.v, 0);
      const sxx = pts.reduce((s, p) => s + p.x * p.x, 0);
      const slope = +((n * sxy - sx * sy) / (n * sxx - sx * sx)).toFixed(2);
      const last = pts[n - 1];
      const forecast = Math.round(last.v + slope * 30);
      return { slopeKBPerDay: slope, forecast,
        alert: slope > 5 && forecast > budgetKB
          ? `按当前增速 30 天后 ${forecast}KB 超预算` : null };
    },
  };
}
```
