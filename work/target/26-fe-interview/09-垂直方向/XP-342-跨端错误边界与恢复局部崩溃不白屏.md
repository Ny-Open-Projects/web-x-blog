## XP-342：跨端错误边界与恢复（局部崩溃不白屏）

**答**：
- 组件级：ErrorBoundary 捕获渲染错误 -> 降级 UI（重试按钮/骨架）。
- 页面级：崩溃上报 + 自动重启页面（计数防死循环，> 3 次停止）。
- 原生层：JS 崩溃不影响原生容器（隔离）。

```javascript
// 错误边界
class SafeBoundary extends React.Component {
  state = { failed: 0 };
  static getDerivedStateFromError() { return { hasError: true }; }
  componentDidCatch(e, info) {
    this.setState(s => ({ failed: s.failed + 1 }));
    report({ type: 'render-crash', msg: e.message, comp: info.componentStack });
  }
  render() {
    if (this.state.hasError)
      return this.state.failed < 3
        ? <RetryBoundary onRetry={() => this.setState({ hasError: false })} />
        : <StaticFallback />;                        // 防死循环兜底
    return this.props.children;
  }
}
```
