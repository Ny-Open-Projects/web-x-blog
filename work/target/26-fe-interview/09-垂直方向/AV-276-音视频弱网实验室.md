## AV-276：音视频弱网实验室：可控网络模拟测试

**答**：
- 题目：弱网测试环境——Chrome DevTools 网络节流 / Linux tc netem（延迟/丢包/抖动精确控制）/ 弱网档位矩阵跑测试用例。
- 思路：tc netem 精确控制（delay 200ms ± 50ms jitter, loss 2%）；档位矩阵（好/中/差/极差）跑完整通话 → 各档断言；输出弱网报告。
- 评分点：netem 命令；档位矩阵；报告输出。

```javascript
const weakNetProfiles = {
  good: { delay: '30ms', loss: '0%', jitter: '5ms' },
  fair: { delay: '150ms', loss: '2%', jitter: '30ms' },
  bad: { delay: '400ms', loss: '10%', jitter: '80ms' },
};
// tc qdisc add dev eth0 root netem delay 200ms 50ms loss 2%
async function runWeakNetSuite(callTest) {
  const report = {};
  for (const [name, profile] of Object.entries(weakNetProfiles)) {
    await applyNetem(profile);                              // tc 命令
    const result = await callTest();                        // 跑通话测试
    report[name] = { ...result,
      pass: result.video.fps > 15 && result.audio.delay < 0.2 };   // 各档断言
  }
  await clearNetem();
  return report;                                            // 弱网报告（档位 × 指标）
}
```
