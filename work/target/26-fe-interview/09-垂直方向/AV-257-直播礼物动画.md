## AV-257：直播礼物动画：全屏特效的渲染选型

**答**：
- 礼物特效：小礼物（Canvas emoji 飘过）vs 大礼物（全屏 MP4/Lottie/WebP 序列帧）——渲染选型按复杂度。
- 选型：Lottie（矢量动画、体积小、可交互）适合常规；WebP 序列帧（透明背景、简单解码）适合特效；MP4 alpha（HEVC alpha）最华丽但体积大。
- 性能：全屏特效同时最多 1 个（队列排队），避免 fillrate 爆炸。

```javascript
class GiftEffectManager {
  constructor() { this.queue = []; this.playing = false; }
  play(effect) {                                             // 效果排队（同时 1 个全屏）
    this.queue.push(effect);
    if (!this.playing) this.next();
  }
  async next() {
    const effect = this.queue.shift();
    if (!effect) { this.playing = false; return; }
    this.playing = true;
    const player = effect.type === 'lottie' ? lottiePlayer(effect.json)
      : effect.type === 'frames' ? webpSequencePlayer(effect.urls)   // WebP 序列帧
      : videoPlayer(effect.mp4);                           // MP4（alpha 通道）
    await player.finished;
    player.destroy();
    this.next();
  }
}
// 体积对比：Lottie 50KB / WebP 序列帧 2MB / MP4 5MB——按特效复杂度选
```
