## XP-404：手写一个手势仲裁状态机

**答**：
- 需求：implement GestureArbiter。feed(event) 接收 { type: down/move/up, dx, dy, pointers, durationMs }；按优先级判定：pinch(2指) > longpress(500ms 未动) > drag(位移>8) > tap(up 时位移<8)；锁定后直到 up 重置；输出当前手势或 null。
- 边界：move 累计位移；up 时未锁定且位移小判 tap；pointers 减少重置 pinch。
- 评分点：优先级判定；累计位移；锁定与重置；tap 兜底

```javascript
class GestureArbiter {
  constructor() { this.reset(); }
  reset() { this.locked = null; this.dx = 0; this.dy = 0;
    this.downAt = null; this.pointers = 0; }
  feed(e) {
    if (e.type === 'down') { this.pointers = e.pointers ?? 1;
      this.downAt ??= e.durationMs ?? 0; }
    if (e.type === 'move') {
      this.dx += e.dx ?? 0; this.dy += e.dy ?? 0;
      this.pointers = e.pointers ?? this.pointers;
    }
    if (this.locked) return e.type === 'up' ? this.reset() : this.locked;
    if (this.pointers >= 2) this.locked = 'pinch';
    else if (e.type === 'move' &&
      (e.durationMs ?? 0) - (this.downAt ?? 0) > 500 &&
      Math.hypot(this.dx, this.dy) < 5) this.locked = 'longpress';
    else if (Math.hypot(this.dx, this.dy) > 8) this.locked = 'drag';
    if (e.type === 'up') {
      const r = this.locked ?? (Math.hypot(this.dx, this.dy) < 8 ? 'tap' : null);
      this.reset(); return r;
    }
    return this.locked;
  }
}
```
