## XP-265：跨端容器专项：容器首屏数据预取协议设计（笔试）

**答**：
- 题目：容器首屏数据预取协议——Native 侧预取（点击前兆）→ 数据通过桥传给 JS → JS 直接渲染（免请求等待）。协议设计含失败兜底。
- 思路：协议：prefetch 请求（路由+参数）→ Native 侧发请求 → 缓存结果 → JS onLoad 时通过桥取缓存 → 命中直接渲染；失败兜底：JS 自己请求。
- 评分点：协议消息；缓存命中/失效；失败兜底。

```javascript
const prefetchProtocol = {
  // Native → JS：预取结果
  messages: [
    { type: 'prefetch-result', route: '/detail/1', data: {...}, fetchedAt: ts },
    { type: 'prefetch-failed', route: '/detail/1', error: 'timeout' },
  ],
};
class PrefetchProtocol {
  async onLoad(route, params) {                                   // 页面加载
    const cached = await bridge.call('getPrefetch', { route, params });   // 取 Native 缓存
    if (cached && Date.now() - cached.fetchedAt < 30000) {          // 30s 内有效
      this.render(cached.data);                                      // 命中：直接渲染
      return;
    }
    // 失效/未命中：JS 自己请求（兜底）
    const data = await this.fetchData(params);
    this.render(data);
  }
}
```
