## AV-424：手写一个直播延迟估算器（播放端）

**答**：
- 需求：implement latencyEstimator(video, hls)。利用 playlist 的 TARGETDURATION 与 buffered 末端 - currentTime 估 buffer 延迟；加上 segment 时长 × 2（服务端累积）近似 E2E；定期输出 { bufferMs, estE2EMs }。
- 边界：无缓冲数据返回 null；向前追帧（ currentTime 超前）记负值并 clamp 0；采样 5s 一次。
- 评分点：缓冲估算；服务端累积；追帧建议；负值 clamp

```javascript
class latencyEstimator {
  constructor(video, { segmentDur = 6, serverAccum = 2 } = {}) {
    this.video = video; this.segmentDur = segmentDur;
    this.serverAccum = serverAccum;
    this.timer = setInterval(() => this.sample(), 5000);
  }
  sample() {
    const sb = this.video.buffered;
    if (!sb.length) return report({ type: 'latency', value: null });
    const end = sb.end(sb.length - 1);
    const bufSec = Math.max(0, end - this.video.currentTime);
    const est = bufSec + this.serverAccum;
    report({ type: 'latency', bufferMs: Math.round(bufSec * 1000),
      estE2EMs: Math.round(est * 1000),
      advice: bufSec > this.segmentDur * 1.5
        ? '追帧：playbackRate=1.1 或 seek 到末尾' : 'ok' });
  }
  stop() { clearInterval(this.timer); }
}
```
