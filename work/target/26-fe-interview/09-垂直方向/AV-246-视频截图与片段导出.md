## AV-246：视频截图与片段导出：VideoFrame 精确截帧

**答**：
- 题目：视频播放页「截图」与「截取 10 秒片段」功能——精确到帧的截取（非 currentTime 近似）、片段重编码导出。
- 思路：截图 = seek 精确帧 → requestVideoFrameCallback 捕获帧 → canvas 导出；片段 = WebCodecs 按时间范围解码重编码。
- 评分点：requestVideoFrameCallback 精确帧；片段重编码管线；导出格式选择。

```javascript
async function captureExactFrame(video, ts) {              // 精确截帧
  return new Promise((res) => {
    video.currentTime = ts;
    video.requestVideoFrameCallback((now, metadata) => {    // 帧级回调（比 seek 事件准）
      const canvas = document.createElement('canvas');
      canvas.width = video.videoWidth; canvas.height = video.videoHeight;
      canvas.getContext('2d').drawImage(video, 0, 0);
      canvas.toBlob(res, 'image/jpeg', 0.92);
    });
  });
}
async function clipSegment(videoUrl, startSec, endSec) {    // 片段重编码
  const demuxer = await mp4boxDemux(videoUrl);               // 解封装
  const chunks = demuxer.samplesBetween(startSec, endSec);    // 时间范围内的 sample
  const encoder = new VideoEncoder({ output: c => muxer.add(c) });
  encoder.configure({ codec: 'avc1.640028', width: demuxer.width, height: demuxer.height });
  for (const sample of chunks) {
    const frame = await decodeSample(sample);                // 逐 sample 解码
    encoder.encode(frame, { keyFrame: sample.sync });       // 同步标记透传
    frame.close();
  }
  await encoder.flush();
  return muxer.finish();                                    // MP4 片段
}
```
