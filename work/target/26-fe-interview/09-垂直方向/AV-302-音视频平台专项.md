## AV-302：音视频平台专项：音视频 SDK API 设计原则

**答**：
- SDK API 设计：分层（核心层/组件层/UI 层）、事件驱动（onXxx 回调 + Promise 混合）、错误统一（错误码体系 AV-261）、可测试（依赖注入）。
- 核心层：PC 管理/订阅/发布——不依赖 UI；组件层：预建连/降级/录制——可组合；UI 层：视频容器/控制条——可选。
- 设计原则示例：所有异步操作返回 Promise + onXxx 事件并行（状态推送）。

```javascript
class AVSDK {
  // 分层 API 设计
  core = {                                                   // 核心层：无 UI 依赖
    join: (roomId) => Promise<Room>,                         // Promise 风格
    publish: (track) => Promise<PublishResult>,
    subscribe: (peerId, kind) => Promise<RemoteTrack>,
    on: (event: 'peer-join' | 'stream' | 'error', cb) => void,   // 事件并行
  };
  components = {                                             // 组件层：可组合
    autoDegrade: NetworkDegrader,                            // 弱网降级（AV-212）
    recorder: LocalRecorder,                                  // 录制（AV-216）
    prewarm: FastConnect,                                     // 预建连（AV-211）
  };
  ui = {                                                     // UI 层：可选
    VideoGrid: (props) => JSX,                               // 布局组件
    ControlBar: (props) => JSX,
  };
  errors = ERROR_MAP;                                        // 统一错误码（AV-261）
}
```
