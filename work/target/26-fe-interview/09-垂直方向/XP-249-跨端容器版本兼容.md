## XP-249：跨端容器版本兼容：老版本容器跑新业务代码（笔试）

**答**：
- 题目：容器版本碎片化——新业务代码用了新 API，老容器（用户未升级）跑不了——运行时能力探测 + 降级实现。
- 思路：启动探测容器 API 版本 → 业务代码按能力分支（新 API 有则用/无则降级实现）→ 降级实现兜底（功能等价但性能差）。
- 评分点：能力探测；分支降级；兜底完整性。

```javascript
class CapabilityDetection {
  detect() {                                                      // 容器能力探测
    return {
      jsi: typeof nativeCallSync === 'function',                  // JSI 支持
      sharedElement: typeof bridge.setTransition === 'function',   // 共享元素
      worklet: typeof bridge.setWorklet === 'function',            // worklet 动画
    };
  }
  getPageImplementation() {                                        // 按能力选实现
    const caps = this.detect();
    if (caps.worklet) return import('./page-worklet');             // 新实现（worklet 动画）
    return import('./page-fallback');                              // 降级实现（JS 动画）
  }
}
// 约定：新 API 上线必须带降级实现——lint 检查（新 API 调用必须有 fallback 分支）
```
