## XP-227：跨端容器版本升级：API 兼容层与渐进迁移

**答**：
- 题目：容器大版本升级（v1→v2 渲染引擎切换）——兼容层（旧 API shim 到新实现）、迁移工具（自动转换脚本）、渐进迁移（页面级灰度）。
- 思路：兼容层：v1 API → shim 包装调 v2 实现（业务无感）；迁移工具：codemod 自动改代码（80% 自动+20% 手工）；页面级灰度（路由白名单）。
- 评分点：兼容层 shim；codemod 迁移；页面灰度。

```javascript
class V2CompatLayer {                                          // v1 API shim
  // v1: page.setData({ key: value })
  // v2: page.update({ key: value })
  setData(data) {                                                // shim：v1 → v2
    warnDeprecated('setData → update (v2)');
    this.update(data);                                            // 调 v2 实现
  }
}
// codemod：jscodeshift 自动转换

//       j.identifier('update')), p.node.arguments));

// 页面灰度：路由白名单（新引擎只跑灰度页面）——异常回退单页
```
