## AV-309：音视频平台专项：弱网图片/视频降级策略（弹幕表情/封面）

**答**：
- 题目：弱网直播体验——弹幕表情降级（大图→文字）、封面降级（高清→模糊占位）、礼物动画降级（MP4→Lottie→文字）。
- 思路：网络档位驱动三级降级（HW-683 复用）；每类资源独立降级开关（flag）；恢复自动升级。
- 评分点：资源分级降级；恢复升级；用户可手动覆盖。

```javascript
class WeakNetAssetDegrader {
  constructor(netMonitor) { this.net = netMonitor; this.level = 'high'; }
  onNetworkChange(tier) {                                     // 网络档位变化
    const assetLevel = tier === 'good' ? 'high' : tier === 'fair' ? 'mid' : 'low';
    if (assetLevel !== this.level) {
      this.applyLevel(assetLevel);
      this.level = assetLevel;
    }
  }
  applyLevel(level) {                                         // 三级降级
    this.danmakuEmoji = level === 'low' ? 'text' : level;     // 表情：图片→文字
    this.cover = level === 'low' ? 'blur' : 'hd';             // 封面：模糊占位
    this.giftEffect = level === 'high' ? 'mp4' : level === 'mid' ? 'lottie' : 'none';   // 特效降级
    if (level === 'low') showToast('已切换省流模式');
  }
}
```
