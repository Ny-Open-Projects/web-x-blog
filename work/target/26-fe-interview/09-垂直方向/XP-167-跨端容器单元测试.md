## XP-167：跨端容器单元测试：指令集快照测试

**答**：
- 题目：渲染指令集回归测试——VDOM diff 生成的指令集与 golden 对比（JSON 快照），异常操作（删除不存在节点）单测覆盖。
- 思路：固定输入（初始树 + 操作序列）→ diff 输出指令集 → JSON.stringify 与 golden 比对；异常单测（错误处理路径）。
- 评分点：快照测试；异常路径覆盖；测试数据固定。

```javascript
describe('RenderBridge diff', () => {
  const fixtures = loadFixtures('render-diff');               // 固定测试数据
  fixtures.forEach(({ name, initialTree, operations, goldenOps }) => {
    it(name, () => {
      const bridge = new RenderBridge();
      bridge.mount(initialTree);
      operations.forEach(op => bridge.apply(op));              // 应用操作
      const ops = bridge.flush();
      expect(JSON.stringify(ops)).toBe(JSON.stringify(goldenOps));   // 快照对比
    });
  });
  it('remove non-existent node throws', () => {
    const bridge = new RenderBridge();
    expect(() => bridge.commit([{ op: 'remove', nodeId: 999 }]))
      .toThrow('node-not-found');                               // 异常路径
  });
});
```
