## AV-390：协作会话的版本快照与历史回放

**答**：
- 快照策略：每 N 条操作或每 T 秒全量快照（存 OSS），增量 update 存日志。
- 回放：快照 + 之后的 update 序列重放到任意时点——审计/还原需求。
- 恢复：协作者加入时拿最新快照 + 之后增量，避免全量重放。

```javascript
// 快照与增量
class HistoryStore {
  constructor({ every = 100 } = {}) { this.every = every; this.ops = []; this.snaps = []; }
  append(update) {
    this.ops.push({ update, at: Date.now() });
    if (this.ops.length % this.every === 0)
      this.snaps.push({ at: Date.now(), seq: this.ops.length,
        snapshot: Y.encodeStateAsUpdate(this.doc) });
  }
  async restoreAt(targetTs) {
    const snap = [...this.snaps].reverse().find(s => s.at <= targetTs);
    const doc = new Y.Doc();
    Y.applyUpdate(doc, snap.snapshot);
    for (const { update, at } of this.ops.slice(snap.seq))
      if (at <= targetTs) Y.applyUpdate(doc, update);
    return doc;
  }
}
```
