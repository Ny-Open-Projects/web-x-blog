## XP-422：手写一个跨端崩溃会话关联器

**答**：
- 需求：implement CrashLinker(crashes, perf)。crashes 为 [{ sessionId, type }]；perf 为 [{ sessionId, peakMemMB, longTaskRate }]；关联：OOM 崩溃会话的性能指标分布 vs 正常会话；输出 { oomSessions, memAvg, threshold }（若 OOM 会话内存显著偏高给出阈值建议）。
- 边界：无 perf 数据的会话跳过；threshold = 正常会话 P95 内存 ×1.1；样本 < 5 标 insufficient。
- 评分点：会话关联；P95 基线；阈值建议；样本门槛

```javascript
function CrashLinker(crashes, perf) {
  const perfMap = new Map(perf.map(p => [p.sessionId, p]));
  const oom = crashes.filter(c => c.type === 'oom')
    .map(c => perfMap.get(c.sessionId)).filter(Boolean);
  const normal = perf.filter(p => !oom.includes(p));
  if (normal.length < 5) return { state: 'insufficient' };
  const sorted = normal.map(p => p.peakMemMB).sort((a, b) => a - b);
  const p95 = sorted[Math.floor(sorted.length * 0.95)];
  return { oomSessions: oom.length,
    memAvg: Math.round(oom.reduce((s, p) => s + p.peakMemMB, 0) / (oom.length || 1)),
    normalP95: p95,
    threshold: Math.round(p95 * 1.1),
    verdict: oom.length && oom.every(p => p.peakMemMB > p95)
      ? 'OOM 会话内存均超正常 P95，设置内存告警阈值' : '关联不明确' };
}
```
