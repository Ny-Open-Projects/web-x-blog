## AV-251：视频播放器内存治理：长视频播放的内存回收

**答**：
- 长视频（2h 回放）内存增长：MSE SourceBuffer 累积、解码器缓冲、DOM 累积——治理：MSE 定期修剪（remove 已播段）。
- MSE 修剪：sourceBuffer.remove(start, end) 删除已播放数据（触发 updateend）；保留窗口 = currentTime ± 60s。
- 监控：performance.memory 采样 + video.webkitDecodedFrameCount 趋势。

```javascript
class MSEMemoryGovernor {
  constructor(sourceBuffer, { keepWindow = 60 } = {}) {
    this.sb = sourceBuffer; this.keep = keepWindow;
    setInterval(() => this.prune(), 30000);                 // 30s 修剪一次
  }
  async prune() {
    const current = video.currentTime;
    const removeEnd = current - this.keep;
    if (removeEnd > 0 && this.sb.buffered.length && this.sb.buffered.start(0) < removeEnd) {
      // 删除已播放超出保留窗口的部分
      const start = this.sb.buffered.start(0);
      this.sb.remove(start, removeEnd);                     // 异步：等 updateend
      await new Promise(r => this.sb.addEventListener('updateend', r, { once: true }));
      report('mse-pruned', { freed: removeEnd - start });
    }
  }
}
```
