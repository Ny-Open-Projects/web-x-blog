## AV-277：音视频场景专项：虚拟直播间（无人直播）

**答**：
- 无人直播：预录视频/虚拟形象（Live2D）+ TTS 弹幕回复 → 自动推流——前端：虚拟形象驱动（Live2D Web SDK）+ 弹幕触发动作。
- 实现：Live2D 模型渲染（口型同步 TTS 音频）+ 弹幕监听触发预设动作/语音回复 + 推流（canvas captureStream）。
- 合规提醒：平台对无人直播有限制——需标注 AI 生成。

```javascript
class VirtualStreamer {
  async init(modelUrl) { this.live2d = await loadLive2D(modelUrl); }
  onDanmaku(msg) {                                           // 弹幕触发回复
    const reply = this.replyRule.match(msg.text);            // 规则匹配
    if (reply) {
      const audio = await tts(reply.text);                   // TTS 合成
      this.live2d.lipSync(audio);                             // 口型同步
      this.live2d.motion(reply.motion);                       // 预设动作
      playAudio(audio);
    }
  }
  startPush() {                                               // 推流：canvas 合成
    const canvas = this.live2d.canvas;
    const stream = canvas.captureStream(30);                 // 形象画面
    const audioDest = audioCtx.createMediaStreamDestination();
    const mixed = new MediaStream([...stream.getVideoTracks(), ...audioDest.stream.getAudioTracks()]);
    rtmpPush(mixed, this.pushUrl);                            // 推流
  }
}
```
