## XP-429：手写一个跨端灰度分桶器（多实验正交）

**答**：
- 需求：implement ExperimentRouter(experiments)。assign(uid) 对每个实验独立分桶（hash(expId:uid)）；分桶配置 { expId, buckets, traffic }；流量百分比截断（< traffic 才参与）；输出 { expId: bucket }；实验间互不影响（正交）。
- 边界：traffic 缺省 1；buckets 缺省 2；未参与实验输出 null；hash 稳定性测试（同 uid 同结果）。
- 评分点：独立分桶；流量截断；正交性；缺省

```javascript
class ExperimentRouter {
  constructor(experiments) { this.exps = experiments; }
  assign(uid) {
    const out = {};
    for (const e of this.exps) {
      const traffic = e.traffic ?? 1;
      const h = hash(`${e.expId}:${uid}`) % 100;
      if (h >= traffic * 100) { out[e.expId] = null; continue; }
      out[e.expId] = h % (e.buckets ?? 2);
    }
    return out;
  }
}
function hash(s) { let h = 0; for (const c of String(s)) h = (h * 31 + c.charCodeAt(0)) >>> 0; return h; }
// 正交性：不同 expId 的 hash 域独立，分桶互不干扰
```
