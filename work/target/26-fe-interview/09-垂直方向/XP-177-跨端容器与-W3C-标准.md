## XP-177：跨端容器与 W3C 标准：Web API 兼容层

**答**：
- 容器兼容层：让 Web 业务代码（用 Web API）在容器中跑——兼容层实现 Web API 子集（localStorage/fetch/WebSocket/Canvas）映射到 Native。
- 适配原则：API 签名与 Web 一致（业务无感知）；不支持的 API 明确报错（而非静默失败）。
- 渐进增强：兼容层覆盖核心 API（95% 业务够用）→ 长尾 API 逐步补齐。

```javascript
class WebAPICompatLayer {
  localStorage = {                                            // localStorage 兼容
    getItem(k) { return NativeStorage.get(k); },
    setItem(k, v) { NativeStorage.set(k, String(v)); },
    removeItem(k) { NativeStorage.remove(k); },
  };
  fetch = async (url, options) => {                            // fetch 兼容
    const resp = await nativeFetch({ url, ...options });
    return { ok: resp.status < 400, status: resp.status,
      json: async () => resp.body, text: async () => JSON.stringify(resp.body) };
  };
  WebSocket = class {                                          // WebSocket 兼容
    constructor(url) { this._native = nativeWS.connect(url); }
    send(data) { this._native.send(data); }
    close() { this._native.close(); }
  };
}
// 原则：不支持 API（如 Service Worker）→ 抛明确错误 + 迁移指引
```
