## AV-328：音视频平台专项：直播间广告插入与体验平衡（笔试）

**答**：
- 题目：直播间广告插入——贴片广告（暂停时）/悬浮广告（角落）/信息流卡片（弹幕间隔），平衡体验与收益（频控/免广告权益）。
- 思路：广告位频控（每 N 分钟 1 次悬浮广告）；会员免广告跳过；点击率统计（广告收益归因）。
- 评分点：广告位类型；频控与豁免；收益归因。

```javascript
class LiveAd insertion {
  async shouldShow(userId, adSlot) {                            // 频控+豁免
    const isVIP = await userIsVIP(userId);                      // 会员免广告
    if (isVIP && adSlot.skippable) return false;
    const lastShown = await adFrequency.get(userId, adSlot.type);
    if (Date.now() - lastShown < adSlot.intervalMs) return false;   // 频控
    return true;
  }
  async show(userId, adSlot) {                                  // 展示
    await adFrequency.set(userId, adSlot.type, Date.now());
    this.renderAd(adSlot);
    track('ad-exposure', { userId, slot: adSlot.type, adId: adSlot.creativeId });
  }
  onClick(adId, userId) {                                       // 点击归因
    track('ad-click', { adId, userId });
    adPlatform.reportClick(adId, userId);                        // 广告平台回传
  }
}
```
