## XP-298：跨端网络层的统一封装（超时/重试/埋点）

**答**：
- 统一：各端 fetch/wx.request/uni.request 包装成一致 API，策略层（重试/缓存/埋点）复用。
- 差异处理：小程序无 AbortController——用 RequestTask.abort 封装 cancel。
- 度量：请求耗时分布/失败率分端对比（性能差异归因）。

```javascript
// 跨端网络层
function createTransport(adapter) {                  // adapter: 各端实现
  return async function request(url, init = {}) {
    const t0 = performance.now();
    try {
      const res = await adapter.request(url, init);
      report({ url, ms: performance.now() - t0, ok: true });
      return res;
    } catch (e) {
      report({ url, ms: performance.now() - t0, fail: e.message });
      throw e;
    }
  };
}
const wxAdapter = { request: (url, init) => new Promise((res, rej) => {
  const task = wx.request({ url, ...init, success: res, fail: rej });
  init.signal?.addEventListener('abort', () => task.abort());   // cancel 封装
}) };
```
