## AV-290：音视频信令安全：信令认证与防重放

**答**：
- 题目：信令通道安全——连接认证（JWT）、消息防重放（nonce+时间窗）、房间权限校验（join 前验证）。
- 思路：WS 连接时带 JWT（首条消息认证）；每消息带 nonce+ts（服务端窗口去重）；join 前校验房间权限（成员/黑名单）。
- 评分点：连接认证；防重放；权限校验。

```javascript
class SecureSignaling {
  constructor(ws, token) { this.token = token; this.sentNonces = new Set(); }
  authenticate() {                                            // 连接后首条消息
    this.ws.send(JSON.stringify({ type: 'auth', token: this.token }));
  }
  send(type, payload) {                                       // 防重放
    const nonce = crypto.randomUUID();
    const ts = Date.now();
    this.ws.send(JSON.stringify({ type, payload, nonce, ts }));
    this.sentNonces.add(nonce);
  }
  onMessage(msg) {                                            // 接收端校验
    if (Math.abs(Date.now() - msg.ts) > 30000) return;       // 时间窗 30s
    if (this.seenNonces.has(msg.nonce)) return;               // 重放丢弃
    this.seenNonces.add(msg.nonce);
    this.dispatch(msg);
  }
}
// 服务端：JWT 验签 → nonce 去重（LRU）→ ts 窗口校验 → join 权限（房间成员/黑名单）
```
