## AV-268：音视频会议场景专项：分组讨论室（Breakout Rooms）

**答**：
- 分组讨论室：主会场 → N 个分会场（各自 SFU 房间）→ 自动回收合并——前端：房间切换（ tear down + 建连）、成员广播。
- 信令流：主会场广播分组名单 → 各成员 join 对应子房间 → 讨论结束 → 全员回主房间。
- 实现细节：切换时旧连接清理（transport close）、子房间限流（每房 8 人）、主持巡视（join 任意子房间）。

```javascript
class BreakoutRooms {
  async moveToRoom(roomId) {                                // 切换讨论室
    await this.leaveCurrent();                              // 清理旧连接（transport close + consumer close）
    await this.signaling.join(roomId);                       // 加入子房间
    this.state = 'breakout';                                 // UI 切换
  }
  async returnToMain() {                                     // 回主会场
    await this.leaveCurrent();
    await this.signaling.join(this.mainRoomId);
    this.state = 'main';
  }
  onBroadcast(msg) {                                         // 广播（跨房间）
    if (msg.type === 'breakout-assign') this.moveToRoom(msg.roomId);   // 分组名单下发
    if (msg.type === 'breakout-end') this.returnToMain();    // 讨论结束回收
  }
}
```
