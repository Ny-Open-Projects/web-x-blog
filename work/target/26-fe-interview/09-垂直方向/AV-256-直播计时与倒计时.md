## AV-256：直播计时与倒计时：服务端时间对齐

**答**：
- 题目：秒杀/优惠倒计时——客户端倒计时与服务端活动结束时间对齐（客户端时钟不可信）。完整实现。
- 思路：进房时拉服务端时间（计算 offset = serverTs - clientTs）；倒计时 = 活动结束时间 - (clientNow + offset)；周期校准。
- 评分点：时钟偏移计算；对齐后倒计时；周期校准防漂。

```javascript
class ServerAlignedCountdown {
  async init(endTs) {
    const t0 = Date.now();
    const { serverTs } = await fetch('/time');               // 服务端时间
    const rtt = Date.now() - t0;
    this.offset = serverTs + rtt / 2 - t0;                   // 偏移（含 RTT/2 修正）
    this.endTs = endTs;
    this.tick();
  }
  now() { return Date.now() + this.offset; }                 // 对齐后的「服务端时间」
  tick() {
    const remain = Math.max(0, this.endTs - this.now());
    this.onTick?.(remain);
    if (remain > 0) setTimeout(() => this.tick(), 1000);
    else this.onEnd?.();
    if (remain > 60000 && remain % 60000 < 1000) this.resync();   // 每分钟校准防漂
  }
}
```
