## XP-220：跨端错误监控：多端错误采集与聚合

**答**：
- 题目：跨端错误监控——Web（window.onerror）/RN（ErrorUtils + Native crash）/小程序（App.onError）/Flutter（FlutterError.onError）统一采集。
- 思路：统一错误 schema（平台/错误类型/堆栈/设备）→ 聚合平台（按平台+版本分组）；符号化（RN 堆栈映射/HW-350 关联）。
- 评分点：各端采集点；统一 schema；符号化。

```javascript
// 统一错误采集
class UnifiedErrorReporter {
  init(platform) {                                              // 各端采集
    const collectors = {
      web: () => { addEventListener('error', e => this.report(e.error, 'js'));
        addEventListener('unhandledrejection', e => this.report(e.reason, 'promise')); },
      rn: () => { ErrorUtils.setGlobalHandler((error, isFatal) =>
        this.report(error, isFatal ? 'fatal' : 'js')); },
      mp: () => { App({ onError(err) { this.report(err, 'mp') } }); },
      flutter: () => { FlutterError.onError = (details) =>
        this.report(details.exception, 'flutter'); },
    };
    collectors[platform]?.();
  }
  report(error, kind) {                                          // 统一 schema
    send({ platform: this.platform, kind, message: error.message?.slice(0, 200),
      stack: error.stack?.slice(0, 2000), device: getDeviceInfo(),
      appVersion: getAppVersion() });
  }
}
```
