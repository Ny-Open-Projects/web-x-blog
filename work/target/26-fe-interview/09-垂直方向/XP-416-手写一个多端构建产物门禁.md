## XP-416：手写一个多端构建产物门禁

**答**：
- 需求：implement BundleGate(budgets)。check(artifacts) 校验各端产物体积（artifacts 为 { end: { jsKB, imgKB } }）；超预算项列出 { end, metric, over }；全超 30% 阻断（block）否则 warn；输出 { verdict, items }。
- 边界：未知端忽略；budget 缺项不计；artifacts 空返回 pass；over 百分比保留 1 位。
- 评分点：多端预算；超限比例；block/warn；未知忽略

```javascript
function BundleGate(budgets) {
  return {
    check(artifacts) {
      const items = [];
      for (const [end, m] of Object.entries(artifacts)) {
        const b = budgets[end];
        if (!b) continue;
        for (const [k, v] of Object.entries(m)) {
          const limit = b[k];
          if (limit == null) continue;
          if (v > limit)
            items.push({ end, metric: k, over: +((v / limit - 1) * 100).toFixed(1) + '%' });
        }
      }
      const worst = Math.max(0, ...items.map(i => parseFloat(i.over)));
      return { verdict: worst > 30 ? 'block' : items.length ? 'warn' : 'pass',
        items };
    },
  };
}
// budgets: { h5: { jsKB: 300 }, rn: { jsKB: 3000 } }
```
