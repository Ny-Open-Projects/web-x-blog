## AV-321：音视频平台专项：直播清晰度与流畅度用户感知调研（笔试）

**答**：
- 题目：主观质量调研——抽样用户观看后问卷（清晰度/流畅度/延迟打分），与客观指标（MOS 估算）对比校准。
- 思路：抽样问卷（1% 用户，播放后弹出轻量评分）；与客观 MOS 对比回归（校准公式）；样本偏差修正（HW-826 复用）。
- 评分点：抽样设计；回归校准；偏差修正。

```javascript
class SubjectiveQualityCalibration {
  async survey(userId) {                                       // 抽样问卷
    if (hashStr(userId) % 100 > 1) return;                     // 1% 抽样
    const scores = await promptSurvey([
      { q: '清晰度', scale: 5 }, { q: '流畅度', scale: 5 }, { q: '延迟', scale: 5 },
    ]);
    const objective = await getObjectiveMetrics(userId);        // 客观 MOS
    calibrationData.push({ subjective: avg(scores), objective: objective.mos,
      deviceTier: objective.tier });
  }
  calibrate() {                                                 // 回归校准
    // 校准公式：MOS_corrected = a × MOS_objective + b × deviceTier + c
    const { a, b, c } = linearRegression(calibrationData);      // 最小二乘
    return { formula: { a, b, c }, sampleSize: calibrationData.length,
      bias: avg(calibrationData.map(d => d.subjective - d.objective)) };   // 样本偏差
  }
}
```
