## AV-408：协作绘画的远程渲染性能（高频更新）

**答**：
- 远端笔迹：partial 高频到达——直接全量重绘卡；方案：partial 只画新增段（增量路径），done 后整体替换。
- 节流：渲染合并到 rAF（每帧最多一次全量重绘）。
- 简化：绘制中的 partial 用抽稀折线（性能优先），done 用完整曲线（质量优先）。

```javascript
// 增量笔迹渲染
class RemoteStrokeRenderer {
  constructor(ctx) { this.ctx = ctx; this.active = new Map(); }
  partial(id, points) {
    const prev = this.active.get(id) ?? [];
    const newPts = points.slice(prev.length);          // 只画新段
    this.ctx.beginPath();
    newPts.forEach((p, i) => {
      const from = i === 0 ? prev[prev.length - 1] : newPts[i - 1];
      this.ctx.moveTo(from.x, from.y); this.ctx.lineTo(p.x, p.y);
    });
    this.ctx.stroke();
    this.active.set(id, points);
  }
  done(id, points) {
    this.active.delete(id);
    drawSmoothCurve(this.ctx, points);                 // 完整贝塞尔替换
  }
}
```
