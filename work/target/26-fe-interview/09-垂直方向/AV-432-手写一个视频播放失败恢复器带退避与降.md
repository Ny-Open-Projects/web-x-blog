## AV-432：手写一个视频播放失败恢复器（带退避与降级）

**答**：
- 需求：implement RecoveryOrchestrator(player)。onError(e) 按错误类别执行恢复链：重试（退避 2^i 秒，最多 3 次）-> 切 codec -> 切 CDN -> 报错终止；每次尝试记录；输出 attempts 与最终状态。
- 边界：用户主动暂停不恢复；同类错误连续 5 次直接终止（防循环）；恢复成功重置计数。
- 评分点：恢复链；指数退避；连败熔断；用户暂停

```javascript
class RecoveryOrchestrator {
  constructor(player, { maxStreak = 5 } = {}) {
    this.player = player; this.streak = 0; this.log = [];
  }
  async onError(e) {
    if (this.player.userPaused) return { state: 'skipped', reason: '用户暂停' };
    if (++this.streak >= this.maxStreak)
      return { state: 'gave-up', reason: '连续失败' };
    const chain = [
      { kind: 'retry', delay: 2 ** this.streak },
      { kind: 'codec', to: 'h264' },
      { kind: 'cdn', to: 'backup' },
    ];
    for (const step of chain) {
      this.log.push({ kind: step.kind, at: Date.now() });
      try {
        await sleep((step.delay ?? 0) * 1000);
        await this.player.recover(step);               // 按步骤恢复
        this.streak = 0;
        return { state: 'recovered', via: step.kind, log: this.log };
      } catch (err) { this.log.push({ kind: step.kind, fail: err.message }); }
    }
    return { state: 'failed', log: this.log };
  }
}
```
