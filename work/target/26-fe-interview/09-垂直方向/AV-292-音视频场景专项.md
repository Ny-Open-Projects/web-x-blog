## AV-292：音视频场景专项：多人白板协作同步（HW-263 音视频版）

**答**：
- 直播课堂白板：老师画 → 学生实时看（SFU datachannel 广播）；学生画 → 老师审批后广播（或直接广播权限内）。
- 同步协议：笔画增量（点序列）广播 + 全量快照兜底（新加入者拿快照+增量）。
- 实现：DataChannel（低延迟，丢 1 笔可容忍——不可靠模式）或 WS（可靠）。

```javascript
class WhiteboardSync {
  constructor(dc) {
    this.dc = dc.createDataChannel('wb', { ordered: true, maxRetransmits: 3 });   // 半可靠
  }
  onLocalStroke(points) {                                     // 本地笔画
    this.dc.send(JSON.stringify({ type: 'stroke', points }));   // 增量广播
  }
  onRemoteStroke({ points, color }) {                          // 远端渲染
    this.canvas.drawStroke(points, color);
  }
  snapshotFor(newPeer) {                                       // 新成员：快照+增量
    const snap = this.canvas.serialize();
    this.dc.send(JSON.stringify({ type: 'snapshot', data: snap, to: newPeer }));
  }
}
```
