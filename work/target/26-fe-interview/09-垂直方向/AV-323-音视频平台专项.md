## AV-323：音视频平台专项：直播间异常流量防护（爬虫/攻击）（笔试）

**答**：
- 题目：直播间异常流量——爬虫批量进房（刷人气）、恶意刷礼物（盗刷）、CC 攻击（信令洪泛）。
- 思路：设备指纹 + 行为画像（进房节奏/弹幕模式）；爬虫特征（无弹幕只挂机/批量同 IP）；信令限流（每连接 N 消息/秒）。
- 评分点：爬虫特征；盗刷防护；信令限流。

```javascript
class AbnormalTrafficDefense {
  async onJoin(peer, fingerprint) {
    // 1. 设备指纹画像：同指纹历史行为
    const profile = await deviceProfile.get(fingerprint);
    if (profile.roomJoinRate > 50) {                           // 每分钟进 50 个房间
      fire('crawler-suspect', { fingerprint });                // 爬虫嫌疑
      return { joined: true, shadowBan: true };                 // 影子禁言（不告知）
    }
    // 2. 信令限流：每连接 30 消息/秒
    this.limiter.set(peer.id, new TokenBucket({ rate: 30, burst: 50 }));
    return { joined: true };
  }
  onSignal(peer) {                                             // 信令限流
    if (!this.limiter.get(peer.id)?.acquire()) {
      peer.close(1008, 'rate-limited');                        // 超限断连
      fire('signal-flood', { peerId: peer.id });
    }
  }
}
```
