## XP-153：跨端动态化：bundle 下发与版本管理

**答**：
- 动态化：bundle（JS 包）服务端下发，客户端按版本加载——热更新不发版；分包（核心/业务）控体积。
- 版本管理：manifest（版本号/文件 hash/依赖）→ 客户端拉取 → 校验 → 原子替换；失败回退上一版本（HW-841 复用）。
- 风控：签名校验（防篡改，AV/离线包同源思想）+ 灰度发布（HW-846 哨兵）。

```javascript
class BundleManager {
  async update() {
    const manifest = await fetchManifest();                 // 版本清单
    const cur = this.getCurrentVersion();
    if (manifest.version <= cur.version) return;             // 无更新
    const changed = diffModules(cur.modules, manifest.modules);   // 模块级 diff
    await this.download(changed, { verify: true });           // 下载+签名校验
    this.stage(manifest);                                     // 暂存（原子替换）
  }
  boot() {                                                    // 启动加载
    const staged = this.readStaged();
    if (staged) {
      try { return this.loadBundle(staged); }
      catch { this.rollback(); }                               // 崩溃回退（HW-841）
    }
    return this.loadBundle(this.getLastGood());
  }
}
```
