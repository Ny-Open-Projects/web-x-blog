## AV-407：协作对象引用与垃圾回收（删除的传播）

**答**：
- 问题：删除对象 A，另一端正在编辑 A（ unaware）——操作悬空。
- 方案：删除为墓碑（tombstone，CRDT 标记删除），引用检查 + 编辑端收到对象已删通知自动停笔。
- GC：墓碑保留到无活跃会话引用后清理（会话注册表跟踪）。

```javascript
// 删除传播
function deleteShape(doc, id, sessionRegistry) {
  const shape = doc.getMap('shapes').get(id);
  if (!shape) return;
  doc.getMap('shapes').set(id, { ...shape, deleted: true });   // 墓碑
  sessionRegistry.sessions.forEach(s =>
    s.notify({ type: 'shape-deleted', id }));
}
function gcTombstones(doc, sessions, now = Date.now()) {
  if (sessions.every(s => s.joinedAt > now - 300_000))  // 无长会话
    doc.getMap('shapes').forEach((shape, id) => {
      if (shape.deleted && now - shape.deletedAt > 600_000)
        doc.getMap('shapes').delete(id);               // 物理清理
    });
}
```
