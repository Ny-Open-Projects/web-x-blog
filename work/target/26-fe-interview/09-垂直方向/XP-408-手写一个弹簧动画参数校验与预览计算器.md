## XP-408：手写一个弹簧动画参数校验与预览计算器

**答**：
- 需求：implement springPreview({ stiffness, damping, mass=1 })。模拟 60fps 离散积分（10 帧窗口）输出每帧位移；settled() 判定收敛（振幅 < 0.001）及帧数；参数非法（stiffness <= 0）抛错。
- 边界：位移初值 1、速度 0；欧拉积分 step=1/60；输出含收敛帧数（超 120 帧标 never）。
- 评分点：欧拉积分；收敛判定；参数校验；帧窗口

```javascript
function springPreview({ stiffness, damping, mass = 1 } = {}) {
  if (stiffness <= 0) throw new Error('stiffness 必须 > 0');
  const dt = 1 / 60;
  let x = 1, v = 0;
  const frames = [];
  let settleAt = null;
  for (let i = 1; i <= 120; i++) {
    const a = -stiffness * x - damping * v;
    v += a * dt / mass;
    x += v * dt;
    frames.push(+x.toFixed(4));
    if (settleAt === null && Math.abs(x) < 0.001 && Math.abs(v) < 0.001)
      settleAt = i;
  }
  return { frames, settleFrames: settleAt ?? 'never',
    note: settleAt > 90 ? '阻尼过小收敛慢' : 'ok' };
}
```
