## AV-442：手写一个多视频同步播放控制器（教室场景）

**答**：
- 需求：implement SyncMaster(videos, tolerance=0.5)。play/pause/seek 广播到所有 video；定期校准：落后 > tolerance 的 video 追 currentTime（seek 或 playbackRate 1.05）。
- 边界：seek 后等全部 seeked 再 play；容忍带内不动（防抖）；video 数量 0 抛错。
- 评分点：集体 seek；容差带；追帧方向；空列表

```javascript
class SyncMaster {
  constructor(videos, tolerance = 0.5) {
    if (!videos.length) throw new Error('无视频');
    this.videos = videos; this.tol = tolerance;
  }
  async seekAll(t) {
    await Promise.all(this.videos.map(v =>
      new Promise(r => { v.onseeked = r; v.currentTime = t;
        setTimeout(r, 2000); })));
  }
  playAll() { this.videos.forEach(v => v.play()); }
  async calibrate(master) {
    const t = master.currentTime;
    for (const v of this.videos) {
      if (v === master) continue;
      const drift = v.currentTime - t;
      if (Math.abs(drift) <= this.tol) continue;
      if (drift > 0) v.currentTime = t;               // 超前跳回
      else v.playbackRate = 1.05;                     // 落后微加速
    }
  }
}
```
