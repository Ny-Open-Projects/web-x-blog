## AV-378：视频下载缓存与离线播放

**答**：
- 手段：Service Worker 缓存完整媒体（小文件）/ IndexedDB 分段缓存（大文件）+ 自定义 loader。
- DRM 限制：加密内容不可缓存明文——离线方案需 DRM 离线许可（Widevine offline）。
- 容量：IndexedDB 配额（Chrome ~60% 磁盘）与淘汰策略（LRU 按最后播放）。

```javascript
// 分段离线缓存
class OfflineStore {
  constructor(db = 'media-cache') { this.db = db; }
  async saveSegments(id, segs) {
    for (const [i, buf] of segs.entries())
      await idbPut(this.db, { id, idx: i, buf });
  }
  async load(id) {
    const segs = await idbQuery(this.db, id);
    return segs.sort((a, b) => a.idx - b.idx).map(s => s.buf);
  }
  async evict(maxMB = 500) {                          // LRU 淘汰
    const all = await idbAll(this.db);
    const sorted = all.sort((a, b) => a.lastPlayed - b.lastPlayed);
    let size = all.reduce((s, x) => s + x.bytes, 0);
    for (const item of sorted) {
      if (size <= maxMB * 1024 * 1024) break;
      await idbDelete(this.db, item.id);
      size -= item.bytes;
    }
  }
}
```
