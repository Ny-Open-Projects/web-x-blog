## XP-162：跨端容器安全：JS 沙箱与原生 API 白名单

**答**：
- 题目：容器内第三方 JS 插件安全——沙箱（无法访问非白名单 API）+ 权限声明（插件声明需要哪些 API，用户/运营审批）。
- 思路：JS 沙箱（Proxy 白名单，HW-385 复用）；权限声明 manifest.permissions → 安装时审批 → 运行时按授权放行。
- 评分点：Proxy 白名单；权限声明与审批；越权拦截。

```javascript
class PluginSandbox {
  constructor(grantedPermissions) { this.granted = new Set(grantedPermissions); }
  createAPI() {                                              // 白名单 API
    const FULL_API = { storage: StorageAPI, network: NetworkAPI, payment: PaymentAPI,
      camera: CameraAPI };
    return new Proxy({}, {
      get(target, module) {
        if (!this.granted.has(module))                        // 未授权模块：拦截
          throw new Error(`plugin-permission-denied: ${module}`);
        return FULL_API[module];
      },
    });
  }
}
// manifest.permissions: ['storage', 'network']——安装时运营审批
// 运行时：插件拿到的 api.payment 为 undefined 且访问报错——越权无法绕过（Proxy 拦截）
```
