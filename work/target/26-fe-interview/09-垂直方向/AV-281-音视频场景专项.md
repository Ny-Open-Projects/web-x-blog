## AV-281：音视频场景专项：语音房（语聊）听筒与混音

**答**：
- 语音房（多人语聊）：音频订阅策略（全员音频，视频可选）、Speaking 高亮（AV-214 复用）、礼物音效混音（AV-243）。
- 移动端适配：听筒/扬声器切换、后台播放（MediaSession API 锁屏控制）。
- 实现：MediaSession API 控制锁屏界面（播放/暂停显示）。

```javascript
class VoiceRoom {
  constructor() { this.setupMediaSession(); }
  setupMediaSession() {                                      // 锁屏控制（PWA/移动端）
    navigator.mediaSession.metadata = new MediaMetadata({
      title: '语音房', artist: roomName });
    navigator.mediaSession.setActionHandler('play', () => this.unmute());
    navigator.mediaSession.setActionHandler('pause', () => this.mute());
  }
  onSpeakingChange(peerId) {                                  // 说话高亮
    this.avatarHighlight(peerId);                             // 头像呼吸灯
  }
  switchAudioRoute(toSpeaker) {                               // 听筒/扬声器（原生桥）
    bridge.call('audioRoute', { to: toSpeaker ? 'speaker' : 'earpiece' });
  }
}
```
