## AV-245：视频处理管线：WebGL 滤镜与美颜

**答**：
- 滤镜管线：VideoFrame → WebGL 纹理 → 片元着色器（滤镜矩阵/LUT）→ 输出 → encode/推流。
- 美颜三步：磨皮（双边滤波）、美白（亮度曲线）、瘦脸（网格变形，原生 SDK 为主）——Web 端常做前两步。
- 性能：720p30 滤镜 GPU 占用 < 10%（shader 简单）；LUT 查表色最便宜。

```javascript
// WebGL 滤镜片元着色器（LUT 查表）
const filterFS = `
uniform sampler2D uVideo;    // 视频帧
uniform sampler2D uLUT;      // 滤镜 LUT（8x8x8 色立方）
varying vec2 vUv;
void main() {
  vec4 color = texture2D(uVideo, vUv);
  // LUT 查表：颜色 → 3D 查找坐标
  float cell = 1.0 / 8.0;
  float b = color.b * (8.0 - 1.0);
  vec2 lutUv = vec2(
    (floor(b) * 8.0 + color.r * 7.0) / 64.0,             // LUT atlas 布局
    color.g * (8.0 - 1.0) / 8.0 + floor(b) / 8.0);
  gl_FragColor = vec4(texture2D(uLUT, lutUv).rgb, color.a);
};`;
// 管线：video → texture → shader → canvas → captureStream() → encode
```
