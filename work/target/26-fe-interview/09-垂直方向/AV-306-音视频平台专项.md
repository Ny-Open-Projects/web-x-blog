## AV-306：音视频平台专项：多端消息漫游与已读同步

**答**：
- 多端漫游：手机/电脑/平板同账号——消息按 seq 漫游（各端拉增量）；已读状态按会话同步（读位置游标）。
- 实现：消息 seq 单调递增（全局）；各端记录 lastReadSeq；漫游 = 服务端按 seq 范围拉取；已读 = 上报游标 → 其他端拉取。
- 冲突：多端同时读 → 最大 seq 胜。

```javascript
class MessageRoaming {
  async pullMessages(since) {                                 // 拉增量
    const { messages } = await api.roam({ since, limit: 100 });
    messages.forEach(m => this.render(m));
    this.lastSeq = Math.max(this.lastSeq, ...messages.map(m => m.seq));
    return { hasMore: messages.length === 100 };
  }
  async markRead(seq) {                                       // 已读游标
    await api.readCursor({ seq });                             // 服务端记录
    this.lastReadSeq = seq;
  }
  async syncReadCursor() {                                     // 其他端同步
    const { readSeq } = await api.getReadCursor(this.sessionId);
    if (readSeq > this.lastReadSeq) {                          // 别端已读更多
      this.renderAsRead(this.lastReadSeq, readSeq);             // 渲染已读标记
      this.lastReadSeq = readSeq;
    }
  }
}
```
