## XP-392：手写一个秒开率聚合器

**答**：
- 需求：implement MiaopenAggregator(threshold=1000)。add({ end, durationMs }) 累计；rate(end) 返回该端秒开率；overall() 全端加权（按样本数）；输出 { byEnd, overall }，百分比 1 位。
- 边界：duration <= 0 忽略；未知端归 other；样本 < 30 的端标注 low-sample；threshold 可配。
- 评分点：分端聚合；低样本标注；非法忽略；加权总体

```javascript
class MiaopenAggregator {
  constructor(threshold = 1000) {
    this.th = threshold; this.rows = [];
  }
  add(row) {
    if (row.durationMs <= 0) return;
    this.rows.push({ ...row, end: row.end ?? 'other' });
  }
  rate(end) {
    const rows = this.rows.filter(r => r.end === end);
    if (!rows.length) return null;
    const fast = rows.filter(r => r.durationMs < this.th).length;
    return { rate: +(fast / rows.length * 100).toFixed(1) + '%',
      samples: rows.length,
      lowSample: rows.length < 30 };
  }
  overall() {
    const ends = [...new Set(this.rows.map(r => r.end))];
    return { byEnd: Object.fromEntries(ends.map(e => [e, this.rate(e)])),
      overall: +(this.rows.filter(r => r.durationMs < this.th).length
        / (this.rows.length || 1) * 100).toFixed(1) + '%' };
  }
}
```
