## XP-264：跨端容器专项：容器 WebView 与小程序/web 双通道降级（笔试）

**答**：
- 题目：业务双通道降级——容器不可用（版本过旧/崩溃）→ 自动降级到 H5/Web 版本（同一业务）；恢复后切回。
- 思路：能力探测（容器版本 >= 最低要求）→ 不满足降级到 H5（WebView 加载 Web 版）；恢复（升级完成）→ 切回容器。
- 评分点：探测条件；降级路径；恢复切换。

```javascript
class FallbackToWeb {
  async shouldUseContainer() {                                   // 能力探测
    const version = await getContainerVersion();
    const minVersion = await getMinRequiredVersion();             // 服务端下发最低版本
    return semverGte(version, minVersion);                         // 版本满足才用容器
  }
  async open(route) {                                             // 打开页面
    if (await this.shouldUseContainer()) {
      return this.containerNavigator.push(route);                   // 容器
    }
    return this.webviewNavigator.open(buildH5Fallback(route));     // 降级 H5
  }
  onContainerRecovered() {                                        // 容器恢复
    showToast('已升级完成，切换到新版本体验');
    this.reloadInContainer();                                       // 切回容器
  }
}
```
