## XP-401：手写一个通知权限转化漏斗统计器

**答**：
- 需求：implement PermFunnel。track(stage)：shown(弹窗展示)/granted/denied/guide(引导设置)；rate() 输出 { grantRate, denyRate, guideConvert }（guide 后 granted 比例）；分触发场景（trigger）统计。
- 边界：同会话重复 shown 去重；stage 未知忽略；无数据返回 null。
- 评分点：漏斗阶段；去重；引导转化；分场景

```javascript
class PermFunnel {
  constructor() { this.events = []; this.seen = new Set(); }
  track(stage, trigger = 'default') {
    const valid = ['shown', 'granted', 'denied', 'guide'];
    if (!valid.includes(stage)) return;
    if (stage === 'shown') {
      const key = trigger + Date.now().toString().slice(0, 10);
      if (this.seen.has(key)) return;
      this.seen.add(key);
    }
    this.events.push({ stage, trigger, at: Date.now() });
  }
  rate() {
    if (!this.events.length) return null;
    const shown = this.events.filter(e => e.stage === 'shown').length || 1;
    const granted = this.events.filter(e => e.stage === 'granted').length;
    const denied = this.events.filter(e => e.stage === 'denied').length;
    const guides = this.events.filter(e => e.stage === 'guide').length;
    const guideGranted = this.events.filter(e =>
      e.stage === 'granted' && this.events.some(g =>
        g.stage === 'guide' && g.trigger === e.trigger)).length;
    return { grantRate: +(granted / shown * 100).toFixed(1) + '%',
      denyRate: +(denied / shown * 100).toFixed(1) + '%',
      guideConvert: guides ? +(guideGranted / guides * 100).toFixed(1) + '%' : null };
  }
}
```
