## XP-245：跨端容器与微前端结合：容器内多业务隔离（笔试）

**答**：
- 题目：容器内多业务隔离——多业务团队页面在同一个容器（命名空间隔离/资源隔离/崩溃隔离）。复用 HW-169 思想。
- 思路：JS 上下文按业务域隔离（XP-169 复用）+ View 树按业务域分容器节点 + 崩溃隔离（XP-179）——单业务崩溃不影响其他。
- 评分点：三维隔离（JS/View/崩溃）；资源配额；域间通信。

```javascript
class BusinessIsolation {
  constructor() { this.domains = new Map(); }                   // 业务域 → 隔离实例
  registerDomain(domain, { maxMemory = 100e6 } = {}) {           // 注册业务域
    const ctx = contextPool.acquire(domain);                      // JS 隔离（XP-169）
    const viewRoot = createViewRoot(domain);                       // View 隔离
    this.domains.set(domain, { ctx, viewRoot, maxMemory });
  }
  onDomainCrash(domain, error) {                                 // 域崩溃隔离
    report('domain-crash', { domain, error: error.message });
    const d = this.domains.get(domain);
    d.ctx.destroy();                                              // 销毁该域上下文
    d.viewRoot.renderErrorCard();                                  // 该域占位
    // 其他域不受影响（独立上下文/View 树）
    this.domains.delete(domain);
  }
  interDomain(from, to, message) {                               // 域间通信（受控）
    const target = this.domains.get(to);
    target.ctx.postMessage({ from, ...message });                  // 消息传递（非直接调用）
  }
}
```
