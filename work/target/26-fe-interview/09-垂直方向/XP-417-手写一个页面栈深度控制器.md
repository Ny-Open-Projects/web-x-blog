## XP-417：手写一个页面栈深度控制器

**答**：
- 需求：implement StackGuard(maxDepth=10, memRatio)。canPush(depth, ratio) 判定：depth >= max 或 ratio > 0.85 时返回 replace-oldest（最老非核心页替换）；否则 push；输出 { action, victim }。
- 边界：victim 选择最老非核心页（core 属性保护）；无可替换时强制 push 并告警；depth/ratio 缺省安全值。
- 评分点：深度阈值；内存联动；core 保护；兜底

```javascript
class StackGuard {
  constructor(maxDepth = 10) { this.max = maxDepth; }
  canPush(depth, ratio = 0, stack = []) {
    if (depth < this.max && ratio <= 0.85) return { action: 'push' };
    const victim = [...stack].reverse()
      .find(p => !p.core && p !== stack[stack.length - 1]);
    if (victim) return { action: 'replace-oldest', victim };
    report({ type: 'stack-forced-push', depth });
    return { action: 'push', note: '无可替换，强制压栈' };
  }
}
// victim 从栈底向栈顶找最老的非 core 页面（reverse 后 find）
```
