## AV-400：协作系统的一致性测试：模型检查式验证

**答**：
- 方法：模拟多客户端随机操作（插入/删除/移动）+ 随机延迟乱序投递，最终状态必须一致。
- 断言：文档 hash 相同 + 语义约束（无悬空引用）+ 性能边界（收敛时间 < 1s）。
- 规模：2~5 客户端 × 数百操作即可覆盖主要并发路径。

```javascript
// 随机并发一致性测试
async function consistencyTest(clients = 3, rounds = 200) {
  const docs = Array.from({ length: clients }, () => new Y.Doc());
  const net = new RandomDelayNetwork(docs);
  for (let r = 0; r < rounds; r++) {
    const c = Math.floor(Math.random() * clients);
    randomOp(docs[c]);                                  // 随机插入/删除
    await net.flush(r);                                 // 随机延迟扩散
  }
  await net.settle();
  const hashes = docs.map(d => hashDoc(d));
  return { pass: new Set(hashes).size === 1,
    hashes, note: new Set(hashes).size > 1 ? '不一致！CRDT 实现有 bug' : '收敛' };
}
```
