## AV-382：视频上传的直传方案（分片 + 断点续传）

**答**：
- 直传：客户端 -> OSS/S3（签名直传，绕过应用服务器），分片并发上传。
- 断点：已传分片列表查询，秒传（文件 hash 命中）。
- 校验：分片 MD5 + 最终合并校验；弱网降并发。

```javascript
// 分片直传
async function uploadVideo(file, { chunkMB = 5, conc = 3 } = {}) {
  const hash = await fileHash(file);                  // 秒传
  const { uploadId, done: uploaded } = await api('/media/init', { hash, size: file.size });
  const total = Math.ceil(file.size / (chunkMB * 1024 * 1024));
  const pending = [...Array(total).keys()].filter(i => !uploaded.includes(i));
  for (let i = 0; i < pending.length; i += conc) {
    await Promise.all(pending.slice(i, i + conc).map(async idx => {
      const blob = file.slice(idx * chunkMB * 1024 * 1024,
        (idx + 1) * chunkMB * 1024 * 1024);
      const { url } = await api(`/media/${uploadId}/part-url`, { idx });
      const r = await fetch(url, { method: 'PUT', body: blob });
      if (!r.ok) throw new Error(`分片 ${idx} 失败`);
      return api(`/media/${uploadId}/part-done`, { idx });
    }));
  }
  return api(`/media/${uploadId}/complete`);
}
```
