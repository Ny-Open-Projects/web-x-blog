## AV-271：音视频回声问题排查：AEC 失效场景与自救

**答**：
- 题目：用户反馈「对方听到回声」——排查链路与前端自救措施（检测→提示→替代方案）。
- 思路：回声根因：AEC 未生效（蓝牙延迟漂移/系统混音器问题）、多设备外放互拾、浏览器 AEC 与系统 AEC 冲突。检测：播放测试音 → 采集端检测是否有回声能量。
- 评分点：根因分类；检测方案；自救提示（戴耳机/静音）。

```javascript
async function echoDiagnosis(stream) {                     // 回环检测
  const ctx = new AudioContext();
  const source = ctx.createMediaStreamSource(stream);
  const analyser = ctx.createAnalyser();
  source.connect(analyser);                                 // 不连 destination（不自loop）
  // 播放测试音（另一设备/通道）→ 检测采集端是否有对应能量
  const testTone = ctx.createOscillator(); testTone.frequency.value = 1000;
  const recorder = ctx.createScriptProcessor(2048);
  let echoDetected = false;
  testTone.connect(recorder);
  recorder.onaudioprocess = (e) => {
    const data = e.inputBuffer.getChannelData(0);
    const energy = data.reduce((s, x) => s + x * x, 0) / data.length;
    if (energy > 0.001) echoDetected = true;                // 采集到测试音 = 有回声
  };
  testTone.start(); testTone.stop(ctx.currentTime + 1);
  return { echoDetected,
    advice: echoDetected ? '检测到回声，请佩戴耳机或静音' : '回声正常' };
}
```
