## XP-171：跨端容器热更新安全：代码签名与完整性

**答**：
- 题目：热更新 bundle 安全——整包签名（ECDSA）+ 模块 hash 校验 + 运行时完整性（防内存篡改）。复用 HW-794 思想。
- 思路：构建时对 bundle 整体签名（私钥在 CI）→ 客户端验签（公钥内置）→ 加载时逐模块 hash 校验；运行时：关键函数 hash 抽查（防 hook 篡改）。
- 评分点：签名验签；逐模块校验；运行时抽查。

```javascript
class BundleSecurity {
  async verify(bundle) {                                     // 验签
    const signature = bundle.meta.signature;                   // ECDSA 签名
    const payload = bundle.modules.map(m => `${m.id}:${m.hash}`).sort().join('\n');
    const valid = await crypto.subtle.verify('ECDSA-P256-SHA256',
      PUBLIC_KEY, base64ToBuf(signature), new TextEncoder().encode(payload));
    if (!valid) throw new Error('bundle-signature-invalid');    // 弃包
    for (const module of bundle.modules) {                     // 逐模块校验
      const actual = await sha256(module.code);
      if (actual !== module.hash) throw new Error(`module-tampered: ${module.id}`);
    }
  }
  runtimeCheck(criticalFns) {                                  // 运行时抽查
    setInterval(() => {
      criticalFns.forEach(fn => {
        if (hashStr(fn.toString()) !== fn.__hash) fire('runtime-tamper', { fn: fn.name });
      });
    }, 30000);
  }
}
```
