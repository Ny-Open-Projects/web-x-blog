## XP-247：跨端容器网络层：请求优先级与并发控制（笔试）

**答**：
- 题目：容器网络层优先级——页面首屏请求（高优）> 预取（中优）> 埋点（低优），并发上限（高优抢占）。
- 思路：优先级队列（ALG-324 复用）；并发上限（同 host 6 个）；高优抢占（排队中低优让位）。
- 评分点：优先级队列；并发控制；抢占语义。

```javascript
class PriorityHttpQueue {
  constructor({ maxConcurrent = 6 } = {}) {
    this.max = maxConcurrent; this.q = []; this.active = 0; this.seq = 0;
  }
  request(options, { priority = 5 } = {}) {
    return new Promise((res, rej) => {
      this.q.push({ options, priority, seq: this.seq++, res, rej });
      this.pump();
    });
  }
  pump() {                                                        // 优先级调度
    while (this.active < this.max && this.q.length) {
      this.q.sort((a, b) => b.priority - a.priority || a.seq - b.seq);   // 高优先
      const job = this.q.shift();
      this.active++;
      this.adapter.request(job.options)
        .then(job.res, job.rej)
        .finally(() => { this.active--; this.pump(); });
    }
  }
}
// 首屏请求 priority 10 > 预取 5 > 埋点 1——首屏不被埋点阻塞
```
