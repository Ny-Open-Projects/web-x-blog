## XP-246：跨端容器与低代码平台：schema 驱动页面生成（笔试）

**答**：
- 题目：低代码平台生成容器页面——schema（组件树/绑定/事件）→ 渲染指令集（不经代码生成直接执行）或生成代码。
- 思路：schema（JSON 组件树 + 数据绑定 + 事件动作）→ 解释执行（直接映射指令集，灵活）或编译生成代码（性能好）；物料组件注册表。
- 评分点：schema 结构；解释 vs 编译；物料注册。

```javascript
const lowCodeSchema = {                                        // 页面 schema
  page: {
    components: [
      { type: 'NavBar', props: { title: '订单列表' } },
      { type: 'List', props: { dataSource: '{{orderList}}' },     // 数据绑定
        children: [{ type: 'Item', props: { template: '{{name}} / {{price}}' } }] },
      { type: 'Button', props: { text: '提交' },
        events: { onClick: { action: 'submitOrder' } } },          // 事件动作
    ],
  },
};
class SchemaExecutor {
  execute(schema) {                                              // 解释执行
    const ops = [];
    const walk = (node, parentId) => {
      const nodeId = genId();
      ops.push({ op: 'create', nodeId, type: node.type, props: resolveBindings(node.props, this.data) });
      ops.push({ op: 'insertChild', parentId, nodeId, index: this.childCount(parentId) });
      node.children?.forEach(c => walk(c, nodeId));
    };
    walk(schema.page, 0);
    bridge.commit(ops);                                            // 直接指令集（免生成代码）
  }
}
```
