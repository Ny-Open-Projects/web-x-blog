## AV-307：音视频场景专项：直播间进场动画与资源预加载

**答**：
- 题目：进直播间体验——进场动画（头像飞入/弹幕缓冲）与资源预加载（首屏弹幕/礼物面板图标）策略。
- 思路：进场即拉最近弹幕快照（服务端缓存最近 50 条）→ 秒出内容；礼物图标 iconfont/SVG sprite 预加载；主播头像 lazy + placeholder。
- 评分点：进场快照；资源预加载；动画性能。

```javascript
class RoomEntryExperience {
  async enter(roomId) {                                        // 进房流程
    const [snapshot, room] = await Promise.all([               // 并行：快照+房间信息
      api.getDanmakuSnapshot(roomId),                          // 最近 50 条弹幕缓存
      api.getRoomInfo(roomId),
    ]);
    renderRoom(room);
    renderDanmakuSnapshot(snapshot);                           // 秒出历史弹幕（无空白）
    preloadGiftIcons();                                        // 礼物面板图标预载
    this.connectWS(roomId);                                     // WS 后连（不阻塞首屏）
  }
  preloadGiftIcons() {
    const icons = GIFT_ICON_LIST;                              // iconfont 预加载
    const link = document.createElement('link');
    link.rel = 'preload'; link.as = 'font';
    link.href = icons.fontUrl;
    document.head.appendChild(link);
  }
}
```
