## AV-365：视频缩略图（雪碧图/预览条）生成

**答**：
- 进度条预览：定时间隔抽帧生成缩略图，拼接 sprite 图 + CSS background-position。
- 生成位置：服务端转码时生成（省客户端 CPU）；客户端即时（WebCodecs 抽帧）成本高。
- 加载策略：懒加载 sprite（hover 进度条才拉取），带宽敏感。

```javascript
// 客户端雪碧图生成
async function buildSprite(videoUrl, { every = 10, w = 160, h = 90 } = {}) {
  const video = document.createElement('video');
  video.src = videoUrl; video.muted = true;
  const meta = await new Promise(r => video.onloadedmetadata = r);
  const n = Math.ceil(meta.duration / every);
  const canvas = new OffscreenCanvas(w * Math.min(n, 10),
    h * Math.ceil(n / 10));
  const ctx = canvas.getContext('2d');
  for (let i = 0; i < n; i++) {
    video.currentTime = i * every + 0.1;
    await new Promise(r => video.onseeked = r);
    ctx.drawImage(video, (i % 10) * w, Math.floor(i / 10) * h, w, h);
  }
  return { blob: await canvas.convertToBlob({ type: 'image/jpeg' }),
    cols: Math.min(n, 10), rows: Math.ceil(n / 10), every };
}
```
