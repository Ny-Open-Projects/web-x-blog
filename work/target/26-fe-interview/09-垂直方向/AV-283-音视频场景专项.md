## AV-283：音视频场景专项：互动游戏直播（数据通道驱动的观众参与）

**答**：
- 互动直播：观众通过弹幕/按钮参与游戏（投票选剧情/控制游戏）——DataChannel/WebSocket 低延迟指令 + 服务端游戏引擎聚合。
- 实现：观众指令 → 聚合（多数决/权重）→ 游戏状态变更 → 直播画面实时反映（游戏 canvas 混入直播流）。
- 延迟要求：指令到画面 < 1s（否则体验差）——WebRTC datachannel 或专用 WS 通道。

```javascript
class InteractiveGame {
  onVote(optionId, userId) {                                  // 观众投票
    this.votes.set(optionId, (this.votes.get(optionId) ?? 0) + 1);
    if (this.votesTotal() % 100 === 0) this.broadcastProgress();   // 进度节流广播
  }
  async resolve() {                                            // 多数决
    const winner = [...this.votes.entries()].sort((a, b) => b[1] - a[1])[0];
    this.game.applyChoice(winner[0]);                          // 游戏状态变更
    broadcast('game-choice', { choice: winner[0] });            // 广播结果
    this.votes.clear();
  }
  composeStream() {                                            // 游戏画面混入直播
    const gameCanvas = this.game.canvas;
    const stream = gameCanvas.captureStream(30);
    // + 主播画面 pip 合成 → 推流
  }
}
```
