## XP-225：跨端容器性能基线：低端机体验保障（笔试）

**答**：
- 题目：低端机体验保障——设备分档（HW-689 复用）→ 分档降级（动画/列表/图片）→ 低端机基准验收。
- 思路：分档信号（内存/CPU/历史帧率）→ 降级清单（动画关闭/列表窗口减半/图片降档）→ 低端机验收标准（30fps 可用）。
- 评分点：分档信号；降级清单；验收标准。

```javascript
class DeviceTierDegradation {
  constructor(deviceTier) { this.tier = deviceTier; }            // low/mid/high（HW-689）
  apply() {                                                       // 分档降级
    const config = {
      low: { animation: false, listWindow: 5, imageQuality: 'low', blur: false },
      mid: { animation: 'reduced', listWindow: 10, imageQuality: 'mid' },
      high: {},
    }[this.tier];
    // 应用到容器：动画开关/列表窗口/图片档位
    bridge.commit([{ op: 'set-perf-config', config }]);
    return config;
  }
  acceptance(tier) {                                              // 分档验收
    return tier === 'low' ? { fps: '>= 30', coldStart: '< 3s', memory: '< 200MB' }
      : { fps: '>= 55', coldStart: '< 2s' };
  }
}
```
