## XP-155：跨端容器样式系统：CSS 子集与样式编译

**答**：
- 题目：自研容器不支持完整 CSS——设计「样式子集」+ 编译期校验（不支持的属性编译报错）+ 样式到 Native 属性的映射表。
- 思路：支持的 CSS 子集（flex 布局/常用属性）→ Yoga 布局引擎映射；编译期：lint 检查不支持的属性（如 position: fixed）→ 报错。
- 评分点：子集边界明确；Yoga 映射；编译期校验。

```javascript
const SUPPORTED_CSS = {
  layout: ['flexDirection', 'justifyContent', 'alignItems', 'flexWrap'],
  sizing: ['width', 'height', 'minWidth', 'maxWidth', 'flex', 'flexGrow'],
  spacing: ['margin', 'padding', 'gap'],
  visual: ['backgroundColor', 'borderRadius', 'borderWidth', 'opacity'],
  unsupported: ['position: fixed', 'float', 'grid', 'pseudo-classes', 'animation-name'],
};
function compileStyle(css) {                                // CSS → Yoga 属性
  const yoga = {};
  for (const [prop, value] of Object.entries(css)) {
    if (prop === 'display' && value === 'flex') { yoga.display = 'Flex'; continue; }
    if (prop === 'backgroundColor') { yoga.backgroundColor = parseColor(value); continue; }
    if (prop.startsWith('margin')) yoga[camelCase(prop)] = parseUnit(value);
    // 不支持：编译期报错
    if (UNSUPPORTED.has(prop)) throw new Error(`unsupported-css: ${prop}`);
  }
  return yoga;                                              // Yoga 布局引擎消费
}
```
