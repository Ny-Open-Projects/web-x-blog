## XP-428：手写一个跨端定位降级器

**答**：
- 需求：implement LocateFallback(adapter, { timeoutMs=3000, cacheTtl=120_000 })。locate() 先缓存（TTL 内直接回）-> adapter 定位 -> 超时/失败降级 DEFAULT_CITY 并上报；输出 { coords?, city, source: gps/cache/fallback }。
- 边界：缓存命中不计失败；连续失败 3 次延长降级时长（10 分钟内直接 fallback）；精度字段透传。
- 评分点：缓存优先；超时降级；连败延长；来源标注

```javascript
class LocateFallback {
  constructor(adapter, { timeoutMs = 3000, cacheTtl = 120_000 } = {}) {
    this.adapter = adapter; this.timeoutMs = timeoutMs;
    this.ttl = cacheTtl; this.fails = 0; this.fallbackUntil = 0;
  }
  async locate(now = Date.now()) {
    if (this.cache && now - this.cache.at < this.ttl)
      return { ...this.cache, source: 'cache' };
    if (now < this.fallbackUntil)
      return { city: DEFAULT_CITY, source: 'fallback' };
    try {
      const r = await Promise.race([
        this.adapter.locate(),
        sleep(this.timeoutMs).then(() => { throw new Error('timeout'); })]);
      this.fails = 0;
      this.cache = { ...r, at: now };
      return { ...r, source: 'gps' };
    } catch {
      if (++this.fails >= 3)
        this.fallbackUntil = now + 10 * 60_000;        // 延长降级
      return { city: DEFAULT_CITY, source: 'fallback' };
    }
  }
}
```
