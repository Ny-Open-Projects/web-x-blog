## AV-250：直播进度条预览：关键帧缩略图生成与懒加载

**答**：
- 题目：进度条悬停缩略图预览——关键帧缩略图（sprite 图：一图含 N 帧）+ 悬停定位帧 + 懒加载 sprite。
- 思路：服务端转码时抽帧生成 sprite（每 2s 一帧拼图）+ 时间索引；前端 hover → 查索引 → 显示对应 sprite 区域（background-position）。
- 评分点：sprite 索引结构；hover 定位计算；懒加载 sprite 文件。

```javascript
class ThumbnailPreview {
  constructor(spriteIndex) { this.index = spriteIndex; }    // [{ts, sprite: 0, x, y}]
  loaded = new Set();
  async hover(ts) {                                         // hover → 找帧
    const entry = this.index.find(e => e.ts <= ts).at(-1) ?? this.index[0];
    if (!this.loaded.has(entry.sprite)) {                    // sprite 懒加载
      await loadImage(`/sprites/${entry.sprite}.jpg`);
      this.loaded.add(entry.sprite);
    }
    return { sprite: entry.sprite,                            // CSS background-position 定位
      backgroundPosition: `-${entry.x}px -${entry.y}px`,
      time: formatTs(entry.ts) };
  }
}
// sprite 生成：ffmpeg -i live.mp4 -vf "fps=0.5,scale=160:90,tile=10x10" sprite_%d.jpg
// 每 2s 一帧，10×10 拼图——一场 2 小时直播 = 3600 帧 = 36 个 sprite
```
