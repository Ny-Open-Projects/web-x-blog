## AV-410：协作系统压测方案：模拟器设计

**答**：
- 模拟：N 虚拟客户端随机操作 + 真实延迟分布（正态 50±20ms + 抖动突发）。
- 指标：服务端 CPU/内存/广播延迟 P99、客户端同步延迟 P75、消息丢弃率。
- 爬坡：连接数阶梯增长找容量拐点（每 30s +100 客户端）。

```javascript
// 协作压测模拟器
class VirtualClient {
  constructor(roomId, profile) { this.roomId = roomId;
    this.lag = profile.lagMs; this.ops = 0; }
  async run(duration) {
    const end = Date.now() + duration;
    while (Date.now() < end) {
      this.ops++;
      await sendWithLag(randomOp(this.roomId), this.lag);
      await sleep(1000 / this.opsRate);
    }
  }
}
async function loadTest({ clients = 500, duration = 60_000 } = {}) {
  const cs = Array.from({ length: clients }, (_, i) =>
    new VirtualClient('room-' + (i % 20), { lagMs: 50 + Math.random() * 40 }));
  await Promise.all(cs.map(c => c.run(duration)));
  return collectServerMetrics();
}
```
