## XP-271：跨端容器专项：容器与原生混合——页面间共享元素动画失败兜底（笔试）

**答**：
- 题目：共享元素动画（XP-172）失败场景——目标页面未含共享元素/元素尺寸差异过大 → 动画失败 → 降级普通转场。
- 思路：Native 检测共享元素匹配（transitionId 找不到/尺寸差 > 2x）→ 降级为普通 push 动画；上报失败原因。
- 评分点：失败检测；降级转场；上报归因。

```javascript
class SharedElementFallback {
  onTransitionFail({ route, reason }) {                        // 动画失败回调
    if (reason === 'element-not-found') {                        // 目标页无匹配元素
      bridge.commit([{ op: 'retry-transition',
        transition: { type: 'slide', duration: 300 } }]);        // 降级普通转场
      report('shared-element-fail', { route, reason });           // 上报归因
    }
    if (reason === 'size-mismatch') {                             // 尺寸差过大
      // 降级 + 产品侧修复（检查 transitionId 声明）
      fire('shared-element-size-mismatch', { route });
    }
  }
}
```
