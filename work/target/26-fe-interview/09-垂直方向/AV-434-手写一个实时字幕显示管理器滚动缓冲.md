## AV-434：手写一个实时字幕显示管理器（滚动缓冲）

**答**：
- 需求：implement SubtitleRenderer(maxLines=3)。push(text, lang) 追加字幕；按时间自动过期（每条 4s）；渲染保留最近 maxLines；多语言并行时按 lang 分列。
- 边界：空文本忽略；同 lang 快速到达替换当前行（不堆积）；render 输出行数组（供 DOM/canvas 渲染）。
- 评分点：过期清理；替换策略；多语言分列；行数限制

```javascript
class SubtitleRenderer {
  constructor(maxLines = 3) {
    this.max = maxLines; this.items = [];             // { text, lang, at }
  }
  push(text, lang = 'zh') {
    if (!text) return;
    const now = Date.now();
    const last = [...this.items].reverse()
      .find(i => i.lang === lang);
    if (last && now - last.at < 1000)
      last.text = text, last.at = now;                // 快速到达替换
    else this.items.push({ text, lang, at: now });
    this.gc(now);
  }
  gc(now) {
    this.items = this.items.filter(i => now - i.at < 4000);
    const byLang = {};
    for (const i of this.items) {
      (byLang[i.lang] ??= []).push(i);
    }
    for (const [lang, list] of Object.entries(byLang))
      if (list.length > this.max)
        this.items = this.items.filter(i => i.lang !== lang ||
          list.slice(-this.max).includes(i));
  }
  render() {
    return this.items.map(i => ({ lang: i.lang, text: i.text }));
  }
}
```
