## XP-387：手写一个滚动掉帧统计器

**答**：
- 需求：implement ScrollFps(el)。监听滚动期间 rAF 帧间隔，> 32ms 记一次掉帧（>50ms 记严重）；输出 { dropRate, severe, avgFps }（滚动会话内）；start/stop 控制会话。
- 边界：未 start 的帧不计；连续掉帧合并统计（帧间隔持续大算一次长卡顿）；avgFps = 1000/avgInterval。
- 评分点：滚动窗口判定；掉帧分级；会话控制；均值

```javascript
class ScrollFps {
  constructor(el) {
    this.el = el; this.frames = []; this.running = false;
    this.longStalls = 0;
  }
  start() {
    this.running = true; this.frames = []; this.longStalls = 0;
    this._last = performance.now();
    this._onScroll = () => { this._scrolling = Date.now(); };
    this.el.addEventListener('scroll', this._onScroll, { passive: true });
    this._loop = t => {
      if (!this.running) return;
      const gap = t - this._last; this._last = t;
      if (this._scrolling && Date.now() - this._scrolling < 300)
        this.frames.push(gap);                        // 只统计滚动期间
      requestAnimationFrame(this._loop);
    };
    requestAnimationFrame(this._loop);
  }
  stop() {
    this.running = false;
    this.el.removeEventListener('scroll', this._onScroll);
    const drops = this.frames.filter(g => g > 32);
    const severe = drops.filter(g => g > 50).length;
    const avg = this.frames.reduce((s, v) => s + v, 0) / (this.frames.length || 1);
    return { dropRate: +(drops.length / (this.frames.length || 1)).toFixed(3),
      severe, avgFps: Math.round(1000 / (avg || 16.7)) };
  }
}
```
