## XP-159：跨端容器调试体系：元素审查与日志桥

**答**：
- 题目：自研容器调试工具——元素审查（JS 侧 VDOM 树 dump 到 Chrome DevTools）、日志桥（console 重定向）、网络面板代理。
- 思路：VDOM 树序列化为 Chrome 可识别格式（或自定义面板）；console.log 桥传到 DevTools；网络请求代理到主进程展示。
- 评分点：元素树 dump；console 重定向；网络面板。

```javascript
class DebugBridge {
  dumpTree(root) {                                           // 元素审查
    const walk = (node) => ({
      type: node.type, props: sanitize(node.props),
      children: node.children.map(walk),
    });
    devtools.send('elements', walk(root));                    // 自定义 DevTools 面板
  }
  hijackConsole() {                                          // console 重定向
    ['log', 'warn', 'error'].forEach(level => {
      const orig = console[level];
      console[level] = (...args) => {
        orig(...args);                                         // 本地保留
        bridge.send({ type: 'console', level, args: args.map(String).slice(0, 5) });
      };
    });
  }
  proxyNetwork(request) {                                     // 网络面板
    devtools.send('network', { url: request.url, method: request.method,
      status: request.status, ms: request.duration });
  }
}
```
