## AV-300：音视频场景专项：可访问性——听障用户的字幕与视觉提示

**答**：
- 题目：音视频可访问性——实时字幕（AV-266）+ 视觉化声音提示（音量波形指示谁在说）+ 键盘操作全支持。
- 思路：字幕常驻开关（用户偏好持久化）；说话人视觉指示（头像边框脉冲）；所有交互可键盘完成（Tab 遍历/Enter 确认）。
- 评分点：字幕优先级；视觉声音指示；键盘完整支持。

```javascript
class AccessibilityFeatures {
  async enableCaptions(userId) {                             // 字幕偏好
    const pref = await getUserPref(userId, 'captions');      // 持久化偏好
    if (pref.auto) await this.captions.start(this.audioTrack);   // 自动开启
  }
  visualSpeakingIndicator() {                                 // 视觉说话指示
    // 头像脉冲动画（代替「谁在说话」的音频线索）
    this.activeAvatar.classList.add('speaking-pulse');
    // 颜色不只靠色相——加形状差异（脉冲+边框粗细）
  }
  keyboardNavigation() {                                      // 全键盘操作
    this.el.addEventListener('keydown', (e) => {
      if (e.key === 'Enter') this.toggleMute();                // Enter 静音切换
      if (e.key === 'm') this.toggleMute();                     // M 快捷键
      if (e.key === 'v') this.toggleVideo();
    });
  }
}
```
