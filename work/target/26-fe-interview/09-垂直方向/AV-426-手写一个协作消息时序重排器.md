## AV-426：手写一个协作消息时序重排器

**答**：
- 需求：implement reorderMessages(buffer, windowMs=500)。乱序消息按 Lamport (c, n) 排序后输出；窗口内消息先缓冲，超窗或收到 flush 指令输出就绪序列；输出保持全序。
- 边界：同 counter 同 nodeId 视为重复丢弃；buffer 上限 1000 溢出强制 flush；空窗口 flush 返回空。
- 评分点：Lamport 排序；窗口缓冲；去重；溢出 flush

```javascript
class MessageReorderer {
  constructor(windowMs = 500) {
    this.windowMs = windowMs; this.buf = new Map(); this.timer = null;
    this.seen = new Set();
  }
  push(msg, emit) {
    const key = `${msg.lc.c}|${msg.lc.n}`;
    if (this.seen.has(key)) return;                   // 去重
    this.seen.add(key);
    this.buf.set(key, msg);
    if (this.buf.size > 1000) return this.flush(emit);
    if (!this.timer)
      this.timer = setTimeout(() => this.flush(emit), this.windowMs);
  }
  flush(emit) {
    clearTimeout(this.timer); this.timer = null;
    const sorted = [...this.buf.values()].sort((a, b) =>
      a.lc.c - b.lc.c || (a.lc.n < b.lc.n ? -1 : 1));
    this.buf.clear();
    sorted.forEach(emit);
    return sorted;
  }
}
```
