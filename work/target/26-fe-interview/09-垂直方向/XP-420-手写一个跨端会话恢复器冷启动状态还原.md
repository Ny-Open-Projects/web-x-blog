## XP-420：手写一个跨端会话恢复器（冷启动状态还原）

**答**：
- 需求：implement SessionRestore(storage)。save(state)（页面栈/表单草稿/滚动位置）序列化存储；restore() 启动时反序列化（超 24h 过期）；版本不匹配丢弃；输出恢复状态或 null。
- 边界：序列化失败（循环引用）静默返回 null；storage 抽象 get/set；version 参数校验；敏感字段（token）排除。
- 评分点：序列化保护；敏感排除；版本校验；TTL

```javascript
class SessionRestore {
  constructor(storage, version = 'v1') {
    this.store = storage; this.version = version;
  }
  async save(state, at = Date.now()) {
    try {
      const safe = JSON.parse(JSON.stringify(state, (k, v) =>
        /token|password/i.test(k) ? undefined : v));   // 排除敏感
      await this.store.set('session', { ...safe, v: this.version, at });
    } catch { report({ type: 'restore-save-fail' }); }
  }
  async restore(now = Date.now()) {
    const s = await this.store.get('session');
    if (!s) return null;
    if (s.v !== this.version) return null;
    if (now - s.at > 24 * 3600_000) return null;       // 过期
    return s;
  }
}
```
