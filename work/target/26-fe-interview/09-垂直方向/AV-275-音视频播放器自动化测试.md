## AV-275：音视频播放器自动化测试：断言矩阵（笔试）

**答**：
- 题目：播放器 E2E 断言矩阵——播放/暂停/seek/倍速/清晰度切换/全屏，每操作后的状态断言（playing 状态/buffered/currentTime/事件序列）。
- 思路：操作 → 等待事件 → 断言状态；事件序列校验（seek 后必有 seeking→seeked→timeupdate）；时序容忍（异步操作 settle）。
- 评分点：断言矩阵完整；事件序列校验；settle 等待。

```javascript
const playbackAssertions = {
  play: { action: p => p.play(), wait: 'playing', assert: p => !p.paused && p.readyState >= 3 },
  pause: { action: p => p.pause(), wait: 'pause', assert: p => p.paused },
  seek: { action: p => p.currentTime = 60, wait: 'seeked',
    assert: p => Math.abs(p.currentTime - 60) < 1 },
  speed: { action: p => p.playbackRate = 2, wait: null,
    assert: p => p.playbackRate === 2 },
  quality: { action: p => p.hls.currentLevel = 2, wait: 'levelSwitched',
    assert: p => p.videoHeight >= 720 },
};
async function runPlaybackSuite(player) {
  for (const [name, { action, wait, assert: check }] of Object.entries(playbackAssertions)) {
    action(player);
    if (wait) await waitForEvent(player, wait, 3000);       // 事件等待
    await settle(player, 100);                              // 状态稳定
    if (!check(player)) throw new Error(`${name} assertion failed`);
  }
}
```
