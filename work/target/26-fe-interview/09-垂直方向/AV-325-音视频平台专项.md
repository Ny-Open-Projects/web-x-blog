## AV-325：音视频平台专项：直播间多语言弹幕翻译展示（笔试）

**答**：
- 题目：国际化直播间——外语弹幕实时翻译（MT 服务异步），原译文双行展示；翻译延迟的 UI 处理（先原文后译文淡入）。
- 思路：检测语言（字符集+模型）→ 非目标语言弹幕异步翻译 → 渲染双行（原文+译文淡入）；翻译失败降级原文。
- 评分点：语言检测；异步翻译淡入；失败降级。

```javascript
class MultilingualDanmaku {
  async onDanmaku(msg) {                                        // 外语弹幕
    const lang = detectLanguage(msg.text);
    this.render(msg);                                            // 先渲染原文
    if (lang !== this.userLang && TRANSLATABLE.has(lang)) {
      try {
        const { translation } = await mtService.translate(msg.text, this.userLang);
        this.appendTranslation(msg.id, translation);             // 译文淡入追加
      } catch { /* 翻译失败：保留原文 */ }
    }
  }
  appendTranslation(msgId, text) {
    const el = this.msgElements.get(msgId);
    const sub = document.createElement('div');
    sub.className = 'translation';
    sub.textContent = text;
    sub.style.opacity = '0';                                    // 淡入
    el.appendChild(sub);
    requestAnimationFrame(() => sub.style.opacity = '1');
  }
}
```
