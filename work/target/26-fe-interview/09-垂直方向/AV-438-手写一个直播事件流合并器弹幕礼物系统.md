## AV-438：手写一个直播事件流合并器（弹幕/礼物/系统消息）

**答**：
- 需求：implement EventMerger(sources)。sources 为多个事件流 [{ type, events }]；按时间戳合并排序输出统一格式 { ts, type, payload }；相同 ts 按 source 优先级（gift > danmaku > system）稳定排序；窗口 200ms 批量输出。
- 边界：事件缺 ts 用到达时间；types 未知按 system；输出队列上限 1000 溢出丢弃最旧。
- 评分点：多源合并；稳定排序；窗口批量；队列上限

```javascript
class EventMerger {
  constructor({ windowMs = 200, maxQueue = 1000 } = {}) {
    this.windowMs = windowMs; this.max = maxQueue;
    this.queue = []; this.prio = { gift: 0, danmaku: 1, system: 2 };
  }
  push(type, payload, ts = Date.now()) {
    this.queue.push({ ts, type, payload,
      prio: this.prio[type] ?? 2 });
    if (this.queue.length > this.max) this.queue.shift();   // 丢最旧
    if (!this.timer)
      this.timer = setTimeout(() => this.flush(), this.windowMs);
  }
  flush() {
    clearTimeout(this.timer); this.timer = null;
    const out = this.queue.sort((a, b) =>
      a.ts - b.ts || a.prio - b.prio);
    this.queue = [];
    return out;
  }
}
```
