## AV-293：音视频场景专项：连麦互踢与冲突处理

**答**：
- 题目：同账号多端登录冲突——A 手机开播中，B 电脑登录同账号开播 → 冲突处理（踢前者/拒绝后者/共存策略）。
- 思路：服务端检测同账号双开播 → 策略仲裁（后登录踢前登录 + 通知）；前端处理被踢（保存状态+提示）。
- 评分点：冲突检测；仲裁策略；被踢方处理。

```javascript
class MultiDeviceConflict {
  async startPush(deviceId) {                                 // 开播请求
    const existing = await server.getActivePush(this.userId);
    if (existing && existing.deviceId !== deviceId) {
      const policy = await this.askUser(existing);             // 询问：挤掉对方/取消
      if (policy === 'takeover') {
        await server.kick(existing.deviceId, { reason: 'takeover' });   // 踢旧端
        report('device-takeover', { from: existing.deviceId, to: deviceId });
      } else return { started: false, reason: 'conflict' };
    }
    return this.doStart(deviceId);
  }
  onKicked({ reason }) {                                       // 被踢端处理
    this.stopPush({ saveState: true });                        // 保存录制状态
    showModal(`您的直播已在其他设备开启（${reason}）`);          // 提示
  }
}
```
