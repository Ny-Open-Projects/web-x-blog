## XP-430：手写一个跨端会话质量日报生成器

**答**：
- 需求：implement DailyDigest(samples)。samples 为 [{ end, miaopen, crashRate, stallRate }]；分端输出 { end: { miaopenRate, crashRate, stallRate, grade } }；grade：三项全达标优、一项超标良、两项以上差；阈值 miaopen>80%/crash<0.1%/stall<2%。
- 边界：端样本 < 30 标 low-sample；缺失指标按达标；输出按 grade 升序（差的在前）。
- 评分点：分端聚合；三指标；分级；低样本

```javascript
function DailyDigest(samples, th = { miaopen: 80, crash: 0.1, stall: 2 }) {
  const byEnd = {};
  for (const s of samples)
    (byEnd[s.end] ??= []).push(s);
  const rows = Object.entries(byEnd).map(([end, rows]) => {
    const rate = (sel) => rows.filter(sel).length / rows.length * 100;
    const miaopen = rate(r => r.miaopen);
    const crash = Math.max(...rows.map(r => r.crashRate));
    const stall = rate(r => r.stallRate);
    const bad = [miaopen < th.miaopen, crash >= th.crash, stall < 100 - th.stall]
      .filter(Boolean).length;
    return { end, miaopen: +miaopen.toFixed(1), crash,
      stall: +stall.toFixed(1),
      grade: bad === 0 ? '优' : bad === 1 ? '良' : '差',
      lowSample: rows.length < 30 };
  });
  return { byEnd: rows.sort((a, b) => (a.grade === '差' ? -1 : 1) - (b.grade === '差' ? -1 : 1)) };
}
```
