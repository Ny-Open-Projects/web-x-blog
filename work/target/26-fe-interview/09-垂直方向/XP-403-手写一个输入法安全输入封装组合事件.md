## XP-403：手写一个输入法安全输入封装（组合事件）

**答**：
- 需求：implement ImeGuard(inputEl, onChange)。compositionstart/end 跟踪组合态；组合中 onChange 抑制（只记录），end 时最终值回调；非组合输入直接回调；返回清理函数。
- 边界：未组合的 keydown Enter 不触发 onChange 两次；多输入框各自实例；removeEventListener 对称。
- 评分点：组合态跟踪；抑制回调；对称清理；最终值

```javascript
function ImeGuard(inputEl, onChange) {
  let composing = false;
  const start = () => { composing = true; };
  const end = e => { composing = false; onChange(e.target.value); };
  const input = e => { if (!composing) onChange(e.target.value); };
  inputEl.addEventListener('compositionstart', start);
  inputEl.addEventListener('compositionend', end);
  inputEl.addEventListener('input', input);
  return () => {
    inputEl.removeEventListener('compositionstart', start);
    inputEl.removeEventListener('compositionend', end);
    inputEl.removeEventListener('input', input);
  };
}
// 用法：const off = ImeGuard(el, v => save(v)); 组件卸载时 off();
```
