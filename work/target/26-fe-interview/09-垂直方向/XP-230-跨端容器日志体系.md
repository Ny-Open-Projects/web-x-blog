## XP-230：跨端容器日志体系：分级日志与远程收集

**答**：
- 题目：容器日志体系——分级（debug/info/warn/error）、环形缓冲（HW-331 复用）、远程收集（error 即时 + info 批量）。
- 思路：分级过滤（线上 info 以上）；环形缓冲（1000 条，error 常驻）；error 即时上报、info 定时批量；脱敏（HW-331 redact 复用）。
- 评分点：分级过滤；环形缓冲；脱敏收集。

```javascript
class ContainerLogger {
  constructor({ cap = 1000 } = {}) { this.ring = []; this.cap = cap; this.level = 'info'; }
  log(level, msg, data) {
    if (LEVELS[level] < LEVELS[this.level]) return;
    const entry = { t: Date.now(), level, msg, data: redact(data) };
    this.ring.push(entry);                                         // 环形
    if (this.ring.length > this.cap) this.ring.shift();
    if (level === 'error') this.report([entry]);                    // error 即时
  }
  flushBatch() {                                                    // info 批量
    if (this.ring.length < 50) return;
    this.report(this.ring.splice(0, 50));                           // 50 条批量
  }
  export() { return this.ring; }                                    // 黑匣子导出（HW-840）
}
```
