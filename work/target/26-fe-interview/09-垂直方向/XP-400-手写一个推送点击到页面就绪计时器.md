## XP-400：手写一个推送点击到页面就绪计时器

**答**：
- 需求：implement PushOpenMeter。start(payload) 记录点击时刻；ready() 记录页面就绪；report() 输出 { ms, route }；页面就绪定义由调用方传入（首帧/数据就绪）。
- 边界：未 start 的 ready 忽略；超 10s 未 ready 标记 timeout；payload.msgId 关联（去重统计）。
- 评分点：去重；超时标记；一次性上报；关联 msgId

```javascript
class PushOpenMeter {
  constructor(isReady) { this.isReady = isReady; }
  start(payload, at = Date.now()) {
    if (this._seen?.has(payload.msgId)) return;        // 去重
    this._seen ??= new Set(); this._seen.add(payload.msgId);
    this.t0 = at; this.payload = payload;
    this._timer = setTimeout(() => {
      if (!this.reported)
        report({ type: 'push-open-timeout', msgId: payload.msgId });
    }, 10_000);
  }
  ready(route) {
    if (!this.t0 || this.reported) return null;
    this.reported = true;
    clearTimeout(this._timer);
    const ms = Date.now() - this.t0;
    report({ type: 'push-open', ms, route, msgId: this.payload.msgId });
    return { ms, route };
  }
}
```
