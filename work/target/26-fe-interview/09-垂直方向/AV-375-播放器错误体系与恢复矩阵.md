## AV-375：播放器错误体系与恢复矩阵

**答**：
- 错误分类：网络（fetch/超时）、解码（codec 不支持）、媒体（缓冲枯竭/损坏）、DRM（license 失败）。
- 恢复矩阵：网络错 -> 重试+降档；解码错 -> 切 codec；buffer 枯竭 -> seek 重缓冲；DRM -> 重新授权。
- 上报：错误码统一枚举+上下文（网络/档位/时间点），支撑 Playability 大盘。

```javascript
// 恢复矩阵
function recover(error, player) {
  const matrix = {
    'network': () => player.retry({ downgrade: true }),
    'decode': () => player.switchCodec('h264'),
    'buffer-stalled': () => player.rebuffer(),
    'drm': () => player.reauth(),
  };
  const handler = matrix[error.category];
  if (!handler) { report({ type: 'unrecoverable', code: error.code }); return false; }
  handler();
  report({ type: 'recover-attempt', category: error.category });
  return true;
}
```
