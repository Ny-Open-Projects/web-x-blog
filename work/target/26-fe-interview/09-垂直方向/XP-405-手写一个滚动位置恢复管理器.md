## XP-405：手写一个滚动位置恢复管理器

**答**：
- 需求：implement ScrollMemory(ttlMs=5min)。save(key, { scrollTop, filters })；restore(key) 返回数据或 null（过期/不存在）；过期自动删除；列表数据版本不一致时（version 参数）不恢复。
- 边界：version 缺省匹配任意；save 覆盖旧值；store 上限 20 淘汰最旧；ttl 可配。
- 评分点：TTL 过期；版本校验；LRU 淘汰；恢复条件

```javascript
class ScrollMemory {
  constructor(ttlMs = 5 * 60_000) { this.ttl = ttlMs; this.store = new Map(); }
  save(key, data, version = null, at = Date.now()) {
    this.store.set(key, { ...data, version, at });
    if (this.store.size > 20)
      this.store.delete(this.store.keys().next().value);
  }
  restore(key, version = null, now = Date.now()) {
    const s = this.store.get(key);
    if (!s) return null;
    if (now - s.at > this.ttl) { this.store.delete(key); return null; }
    if (s.version !== null && version !== null && s.version !== version)
      return null;                                    // 数据版本变了不恢复
    return { scrollTop: s.scrollTop, filters: s.filters };
  }
}
```
