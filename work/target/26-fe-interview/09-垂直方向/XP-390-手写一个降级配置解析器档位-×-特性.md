## XP-390：手写一个降级配置解析器（档位 × 特性矩阵）

**答**：
- 需求：implement resolveFeatures(tier, matrix)。matrix 为 { feature: { L0: v0, L1: v1, ... } }；tier 缺失按 L1；某特性缺该档配置回退最近低档（L2 无则用 L1）；输出 { feature: value }；未知特性忽略。
- 边界：matrix 空返回空；tier 非法按 L1；值可为 false/数字/字符串。
- 评分点：档位回退；非法 tier；未知忽略；值类型

```javascript
function resolveFeatures(tier, matrix) {
  const ORDER = ['L0', 'L1', 'L2', 'L3'];
  const t = ORDER.includes(tier) ? tier : 'L1';
  const idx = ORDER.indexOf(t);
  const out = {};
  for (const [feat, levels] of Object.entries(matrix)) {
    for (let i = idx; i >= 0; i--) {                 // 向低档回退
      if (levels[ORDER[i]] !== undefined) {
        out[feat] = levels[ORDER[i]];
        break;
      }
    }
  }
  return out;
}
// resolveFeatures('L1', { particles: { L0: 0, L2: 5000 } }) -> { particles: 0 }
```
