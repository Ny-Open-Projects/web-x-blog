## AV-297：音视频场景专项：直播回放精彩片段自动剪辑

**答**：
- 题目：直播结束后自动剪辑精彩片段——信号源（弹幕密度/礼物峰值/音量突变）→ 候选片段 → 生成剪辑列表。
- 思路：信号聚合打分（滑动窗口密度）→ 峰值检测（局部极大）→ 片段切分（峰值前后扩 30s）→ 去重合并。
- 评分点：信号源设计；峰值检测；片段合并去重。

```javascript
function autoHighlights(signals, { minLen = 30, maxLen = 180 } = {}) {
  // signals: [{ts, danmakuCount, giftValue, audioLevel}]
  const scored = signals.map(s => ({
    ts: s.ts, score: s.danmakuCount * 0.4 + s.giftValue * 0.5 + s.audioLevel * 100 * 0.1,
  }));
  const peaks = [];
  for (let i = 1; i < scored.length - 1; i++)               // 局部极大（滑动窗口）
    if (scored[i].score > scored[i - 1].score && scored[i].score > scored[i + 1].score
      && scored[i].score > median(scored.map(x => x.score)) * 2)
      peaks.push(scored[i]);
  const clips = peaks.map(p => ({                            // 扩展片段
    start: Math.max(0, p.ts - 30), end: Math.min(p.ts + 60, maxLen + p.ts),
    score: p.score }));
  return mergeOverlapping(clips).filter(c => c.end - c.start >= minLen);   // 去重合并
}
```
