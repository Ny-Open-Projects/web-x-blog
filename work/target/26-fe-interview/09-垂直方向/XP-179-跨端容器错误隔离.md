## XP-179：跨端容器错误隔离：页面崩溃不影响其他页面

**答**：
- 题目：容器页 JS 崩溃隔离——异常捕获（try/catch + 全局兜底）→ 崩溃页面降级（错误占位）→ 其他页面不受影响（同上下文场景）。
- 思路：页面代码包 try/catch（每个生命周期）；全局 uncaught 兜底 → 标记崩溃页面 → 该页降级为错误占位，栈内其他页正常。
- 评分点：生命周期级捕获；全局兜底；降级占位。

```javascript
class CrashIsolation {
  wrapLifecycle(page) {                                        // 生命周期包裹
    ['onLoad', 'onShow', 'onReady'].forEach(lifecycle => {
      const orig = page[lifecycle];
      page[lifecycle] = (...args) => {
        try { return orig?.apply(page, args); }
        catch (e) { this.handleCrash(page, lifecycle, e); }     // 崩溃隔离
      };
    });
  }
  handleCrash(page, lifecycle, error) {                         // 崩溃处理
    report('page-crash', { pageId: page.id, lifecycle, error: error.message });
    page.renderErrorCard();                                     // 该页降级占位
    // 其他页面不受影响（栈内正常）——事件系统/路由不受污染
  }
}
// 全局兜底：uncaughtException → 同 handleCrash（标记崩溃页）→ 不杀引擎（其他页保活）
```
