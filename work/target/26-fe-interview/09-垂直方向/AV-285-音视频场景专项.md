## AV-285：音视频场景专项：会议录制合规与知情同意

**答**：
- 题目：会议录制合规——录制前全员知情同意（横幅提示+同意记录）、录制中指示（红点常驻）、退出后录制文件权限控制。
- 思路：录制开始信令广播 → 全员 UI 红点 + 入会提示「本会议将被录制」；同意记录（用户 ID+时间）留档；录制文件访问权限（参与者才可看）。
- 评分点：同意流程完整；录制中指示；文件权限。

```javascript
class RecordingCompliance {
  async startRecording(initiator) {
    await this.signaling.broadcast('recording-started', { by: initiator });   // 全员通知
    this.ui.showRecordingBadge();                             // 常驻红点
    await this.recordConsent();                               // 同意留档
  }
  async recordConsent() {
    for (const peer of this.room.peers.values()) {
      await auditStore.put({ type: 'recording-consent',
        userId: peer.userId, ts: Date.now(), method: 'banner-ack' });
    }
  }
  stopRecording() {
    return { file: this.recorder.stop(),
      accessPolicy: { participantsOnly: true, expires: '30d', auditTrail: true } };   // 文件权限
  }
}
```
