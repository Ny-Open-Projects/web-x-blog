## AV-360：视频指纹水印与防盗链前端配合

**答**：
- 水印：动态 HTML 覆盖层（防截图溯源）/烧录进视频帧（Canvas 合成）——前端无法绝对防，提高成本。
- 防盗链：签名 URL（时效+IP）+ Referer 校验 + 播放器行为指纹（异常并发上报）。
- 前端责任：水印防篡改（MutationObserver 监控移除）、异常播放模式上报。

```javascript
// 防移除水印
function tamperProofWatermark(container, text) {
  const wm = document.createElement('div');
  wm.textContent = text;
  wm.style.cssText = 'position:absolute;opacity:0.3;pointer-events:none;font-size:14px';
  container.appendChild(wm);
  const mo = new MutationObserver(muts => {
    for (const m of muts)
      if ([...m.removedNodes].includes(wm) ||
          wm.style.opacity !== '0.3') {
        report({ type: 'watermark-tampered' });
        wm.style.opacity = '0.3';
        if (!wm.isConnected) container.appendChild(wm);   // 重新挂载
      }
  });
  mo.observe(container, { childList: true, subtree: true, attributes: true });
  return () => mo.disconnect();
}
```
