## XP-406：手写一个图片策略决策器

**答**：
- 需求：implement imageDecision({ containerW, dpr, supports, tier })。输出 { width, format, lazy, placeholder }：width = containerW×dpr 取整；format 按支持（avif>webp>jpeg）且低档降 jpeg（解码快）；L0 关闭 blur 占位。
- 边界：containerW/dpr 缺省 375/2；supports 缺失全 false；width 上限 2160（防超大）；结果四舍五入到 10px（CDN 缓存友好）。
- 评分点：宽度计算；格式链；档位降级；10px 对齐

```javascript
function imageDecision({ containerW = 375, dpr = 2,
    supports = {}, tier = 'L1' } = {}) {
  let width = Math.round(containerW * dpr / 10) * 10;
  width = Math.min(2160, width);
  const format = tier === 'L0' ? 'jpeg'
    : supports.avif ? 'avif' : supports.webp ? 'webp' : 'jpeg';
  return { width, format,
    lazy: true, rootMargin: tier === 'L0' ? '100px' : '200px',
    placeholder: tier === 'L0' ? 'color' : 'blur' };
}
```
