## XP-383：手写一个跨端启动分段计时器

**答**：
- 需求：implement launchTrace(end)。提供 mark(stage) 与 finish() 输出各段耗时数组 [{ stage, ms }]；stage 顺序校验（乱序标记 anomaly）；total 为 sum；stages：proc/engine/framework/data/first-paint。
- 边界：重复 stage 覆盖前值；未 finish 时 total 为 null；stage 未知忽略并计数 unknown。
- 评分点：分段记录；乱序忽略；覆盖语义；total

```javascript
class launchTrace {
  constructor(end) {
    this.end = end; this.stages = []; this.lastTs = null; this.unknown = 0;
    this.finished = false;
  }
  mark(stage) {
    const known = ['proc', 'engine', 'framework', 'data', 'first-paint'];
    if (!known.includes(stage)) { this.unknown++; return; }
    const now = Date.now();
    const ms = this.lastTs == null ? 0 : now - this.lastTs;
    const prev = this.stages.find(s => s.stage === stage);
    if (prev) prev.ms = ms;
    else this.stages.push({ stage, ms });
    this.lastTs = now;
  }
  finish() {
    this.finished = true;
    return { end: this.end, stages: this.stages,
      total: this.stages.reduce((s, x) => s + x.ms, 0),
      unknown: this.unknown };
  }
}
```
