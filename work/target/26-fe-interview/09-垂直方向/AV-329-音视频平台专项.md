## AV-329：音视频平台专项：直播间评论回复与@功能（笔试）

**答**：
- 题目：弹幕回复与@——回复某条弹幕（引用展示）、@某用户（高亮提醒）、@全体（仅管理员）。
- 思路：回复 = 消息带 replyTo（渲染引用块）；@ = 文本中 @userId 解析 → 高亮 + 对方提醒（推送）；@全体权限校验。
- 评分点：引用渲染；@解析与提醒；权限校验。

```javascript
class DanmakuReply {
  async send({ text, replyTo, mentions }) {                     // 发送
    if (mentions?.includes('@all') && !this.isAdmin)            // @全体权限
      throw new Error('permission-denied');
    await this.ws.send({ type: 'danmaku', text,
      replyTo: replyTo?.msgId, mentions });
  }
  render(msg) {                                                 // 渲染
    if (msg.replyTo) {                                           // 引用块
      const quoted = this.msgElements.get(msg.replyTo);
      const quote = `<div class="quote">${quoted?.textContent ?? '原弹幕已删除'}</div>`;
      this.el.innerHTML = quote + msg.text;
    }
    if (msg.mentions?.includes(this.userId)) {                   // 被 @ 提醒
      this.el.classList.add('mentioned');                        // 高亮
      showToast(`${msg.user} 提到了你`);
    }
  }
}
```
