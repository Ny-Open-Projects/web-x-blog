## AV-338：H.264 与 H.265/VP9/AV1 的取舍

**答**：
- H.264：兼容性之王（所有设备硬解），压缩率基准。
- H.265：省 40% 码率但专利复杂、部分浏览器不支持；VP9：WebM 生态免费，YouTube 主力。
- AV1：再省 30%，解码复杂度高（软解吃 CPU），2024+ 新设备硬解逐步覆盖——浏览器能力探测决定分层策略。

```javascript
// 编解码能力探测与选型
async function pickCodec(media) {
  const candidates = [
    { c: 'av01.0.05M.08', rank: 1 },      // AV1 1080p
    { c: 'video/mp4; codecs="hvc1.1.6.L93.B0"', rank: 2 },  // H.265
    { c: 'video/webm; codecs="vp09.00.10.08"', rank: 3 },   // VP9
    { c: 'video/mp4; codecs="avc1.640028"', rank: 4 },      // H.264
  ];
  for (const { c, rank } of candidates) {
    const support = await MediaSource?.isTypeSupported(c) ??
      media.canPlayType(c);
    if (support) return { codec: c, rank };
  }
  return { codec: candidates[3].c, rank: 4 };   // 保底 H.264
}
```
