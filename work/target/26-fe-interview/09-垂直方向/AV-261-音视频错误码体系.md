## AV-261：音视频错误码体系：用户可理解的错误提示

**答**：
- 题目：音视频错误码统一体系——技术错误码 → 用户可理解文案 + 处理建议 + 上报归因。完整映射表实现。
- 思路：错误码分段（1xxx 权限 / 2xxx 网络 / 3xxx 设备 / 4xxx 解码）；映射文案（「摄像头被占用，请关闭其他应用」）。
- 评分点：分段体系；文案可操作性；上报归因字段。

```javascript
const ERROR_MAP = {
  1001: { msg: '摄像头权限被拒绝', action: '打开设置允许摄像头', retryable: false },
  1002: { msg: '摄像头被其他应用占用', action: '关闭视频会议等应用后重试', retryable: true },
  2001: { msg: '网络连接不稳定', action: '检查网络或切换 WiFi', retryable: true },
  3001: { msg: '麦克风未检测到', action: '请插入麦克风设备', retryable: true },
  4001: { msg: '视频格式不支持', action: '已为您切换兼容格式', retryable: true },
};
class AVError {
  constructor(code, detail) { this.code = code; this.detail = detail; }
  toUser() { const e = ERROR_MAP[this.code] ?? { msg: '未知错误', action: '请重试' };
    return { ...e, code: this.code }; }
  report() { report('av-error', { code: this.code, detail: this.detail,
    ua: navigator.userAgent }); }                           // 归因：UA/设备/网络
}
// 约定：错误码驱动 UI（toast 文案 + 是否可重试），技术细节只进日志
```
