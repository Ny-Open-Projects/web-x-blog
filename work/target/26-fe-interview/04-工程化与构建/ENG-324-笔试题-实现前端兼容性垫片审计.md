## ENG-324：手写 polyfill 审计

**需求与边界**：
- 需求：审计产物中的 polyfill——① 重复垫片（core-js 与手写 shim 双份实现同一特性）；② 未使用垫片（目标浏览器原生支持却被注入）；③ 按目标浏览器计算「可安全删除」清单与节省体积。
- 边界：① 特性映射表（polyfill 名 → ES 特性 → browserslist 最低版本）；② 原生支持判定用 caniuse 数据 + 声明目标交集；③ 手写 shim 检测（自实现 Array.prototype.xxx 且 core-js 也有 = 双份）。

**答**：
```javascript
const FEATURE_MAP = { 'es.array.flat': { feature: 'Array.prototype.flat', min: { chrome: 69, safari: 12 } } };
function polyfillAudit(bundle, targets, { corejsUsed = true } = {}) {
  const targetSet = parseTargets(targets);           // browserslist → 浏览器版本集
  const issues = [], savings = 0;
  for (const [name, chunk] of Object.entries(bundle.polyfills)) {
    const feat = FEATURE_MAP[name]?.feature;
    if (!feat) continue;
    const nativeEverywhere = targetSet.every(t =>
      nativeSupports(feat, t.browser, t.version));   // 全目标原生支持
    if (nativeEverywhere) {
      issues.push({ type: 'UNUSED', name, size: chunk.size,
        fix: '从 useBuiltIns 目标重算 / 显式排除' });
    }
    if (corejsUsed && hasManualShim(bundle, feat))    // core-js + 手写 shim 双份
      issues.push({ type: 'DUPLICATE', name, size: chunk.size,
        fix: '删除手写 shim，统一走 core-js 按需注入' });
  }
  return { issues, savingKB: issues.reduce((s, i) => s + i.size, 0) / 1024 };
}
```

**评分点**:
- 双检测（目标内未使用 + core-js 与手写 shim 重复）。
- 特性映射表驱动（polyfill 名 → ES 特性 → 最低版本）。
- 体积节省量化（审计有收益依据，ENG-243 联动）。
- 修复建议指向构建配置（useBuiltIns 重算）。
