## OPS-325：手写灰度日报

**需求与边界**：
- 需求：每日灰度摘要——① 当前档位与停留时长、② 指标对比快照（硬/软分区）、③ 当日决策记录（放量/熔断/降档）、④ 下一档门槛达成状态、⑤ 遗留问题与待办——交接班载体（SCN-OPS-210 checklist）。
- 边界：① 决策记录从灰度 FSM 日志取（SCN-OPS-292），不手工填；② 待办从「未通过的门禁项 + 未完成的验收项」自动汇总；③ 输出 IM 卡片格式（可点击跳详情）。

**答**：
```javascript
async function grayDailyReport(gray) {
  const fsmLog = gray.fsm.log;                         // 决策记录（SCN-OPS-292）
  const today = fsmLog.filter(e => withinDay(e.ts));
  const gates = gray.nextGateChecks();
  const todos = [
    ...gates.filter(g => !g.pass).map(g => `门禁未过: ${g.name}`),
    ...gray.acceptance.filter(a => !a.done).map(a => `验收未完: ${a.item}`),
  ];
  return {
    card: {
      stage: `${gray.stage}%（已停留 ${days(gray.stageEnteredAt)}d）`,
      hard: gray.metrics.hard.map(m => `${m.name}: ${m.value} vs ${m.baseline} ${m.ok ? '✅' : '🔴'}`),
      soft: gray.metrics.soft.map(m => `${m.name}: 趋势 ${m.trend}`),
      decisions: today.map(e => `${fmtTime(e.ts)} ${e.action} → ${e.to ?? ''} (by ${e.by})`),
      nextGate: gates.every(g => g.pass) ? '可放量' : `等待: ${gates.filter(g => !g.pass).map(g => g.name)}`,
      todos,
    },
    links: { detail: grayBoardUrl(gray.id), metrics: metricsUrl(gray.id) },   // IM 卡片可跳转
  };
}
```

**评分点**:
- 五要素齐（档位/指标/决策/门槛/待办——SCN-OPS-210 交接）。
- 决策从 FSM 日志取（不手工填——数据诚实）。
- 待办自动汇总（门禁+验收未过项）。
- IM 卡片带跳转链接（卡片是入口不是终点）。
