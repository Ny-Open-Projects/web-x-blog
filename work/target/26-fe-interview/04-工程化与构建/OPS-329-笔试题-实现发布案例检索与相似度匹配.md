## OPS-329：手写案例检索

**需求与边界**：
- 需求：发布案例库检索（SCN-OPS-248）——① 按失败模式标签 + 触及模块双重匹配打分；② 案例输出「症状/根因/预防」三段；③ 相似发布的成功率统计（SCN-OPS-283 历史画像）；④ 零命中时输出「新案例建议」。
- 边界：① 标签匹配权重 > 模块匹配（失败模式更决定性）；② 案例时间衰减（3 年前的案例降权——环境已变）；③ 成功率统计样本下限（<3 次不给出成功率）。

**答**：
```javascript
function searchCases(plan, caseBase, releases, { decayYears = 3 } = {}) {
  const scored = caseBase.map(c => {
    const tagOverlap = intersect(c.tags, plan.failureModeTags).length;
    const moduleOverlap = intersect(c.modules, plan.modules).length;
    const ageDecay = Math.max(0, 1 - yearsSince(c.ts) / decayYears);   // 时间衰减
    return { case: c, score: (tagOverlap * 3 + moduleOverlap) * ageDecay };
  }).filter(s => s.score > 0).sort((a, b) => b.score - a.score).slice(0, 5);
  const similar = releases.filter(r =>
    intersect(r.tags, plan.failureModeTags).length >= 2);
  return {
    cases: scored.map(s => ({
      id: s.case.id, symptom: s.case.symptom, rootCause: s.case.rootCause,
      prevention: s.case.prevention, score: s.score,
    })),
    successRate: similar.length >= 3
      ? similar.filter(r => r.outcome === 'success').length / similar.length
      : { insufficient: true, n: similar.length },     // 样本下限
    suggestNew: scored.length === 0 ? '无相似案例——本次发布后建议沉淀新案例' : null,
  };
}
```

**评分点**:
- 双重匹配打分（标签 ×3 权重 > 模块——SCN-OPS-261）。
- 时间衰减（3 年降权——环境变化防御）。
- 成功率样本下限（<3 次不出数——统计诚实）。
- 零命中引导沉淀新案例（案例库生长机制）。
