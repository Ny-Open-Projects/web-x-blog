## OPS-331：手写迁移编排

**需求与边界**：
- 需求：expand→migrate→contract 三阶段编排（SCN-OPS-265）——① 每阶段独立发布独立验证；② migrate 完成度对账（迁移条数 vs 总量）+ 抽样校验；③ contract 阶段门禁 = phase2 验证通过；④ 每阶段回滚 = 回退到上一步语义（数据向前兼容）。
- 边界：① 双写期的一致性校验（新旧字段值一致——写双读旧期的漂移检测）；② 对账不等时补迁移任务；③ contract 后旧字段保留一个观察期再物理删除。

**答**：
```javascript
async function migrationOrchestration(plan) {
  // Phase 1: expand（双写读旧）
  await release({ schema: plan.expand, front: 'readonly-new-fields' });
  const driftCheck = setInterval(() => {               // 双写一致性漂移检测
    const mismatches = compareFields(plan.expand.table);
    if (mismatches.rate > 0.001) alert({ type: 'DUAL_WRITE_DRIFT', rate: mismatches.rate });
  }, 5 * 60_000);
  // Phase 2: migrate（对账 + 抽样）
  const job = await startBackfill(plan.migrate);
  const reconciled = await waitFor(() => job.migratedCount === job.totalCount, { timeout: '24h' });
  if (!reconciled) { await enqueuePatchMigration(job.missing); }   // 补迁移
  const sampleOk = sampleVerify(job.migratedRange, { rate: 0.01 });   // 抽样校验
  clearInterval(driftCheck);
  // Phase 3: contract（门禁 = phase2 验证通过）
  if (!reconciled || !sampleOk) return { blocked: 'PHASE2_UNVERIFIED' };
  await release({ schema: plan.contract, gate: 'read-new' });
  scheduleDrop(plan.oldField, { after: '30d' });       // 观察期后物理删除
  return { done: true };
}
```

**评分点**:
- 三阶段独立发布验证（expand-contract——SCN-OPS-265）。
- 双写期漂移检测（新旧字段一致性）。
- 对账 + 抽样双重验证（contract 门禁）。
- 观察期后物理删除（contract 不急着删）。
