## BLD-298：手写双实例检测

**需求与边界**：
- 需求：从构建 stats/manifest 检测——① 同包多版本（lodash@4.17.15 与 4.17.21——SCN-ENG-293）；② 同版本多拷贝（同版本不同路径——pnpm symlink 归一化失败/monorepo 双构建）；③ 运行时单例风险标注（react/dgram 类——instanceof/hooks 风险包）。
- 边界：① 模块标识用「包名+版本+真实路径」三元组；② singleton 风险包清单（react/vue/styled-components——双实例会炸的）；③ 输出修复建议（alias/resolve 统一）。

**答**：
```javascript
const SINGLETON_RISK = ['react', 'react-dom', 'vue', 'styled-components', 'moment'];
function detectDuplicates(stats) {
  const modules = stats.modules.map(m => ({
    name: parsePkgName(m.resource),                    // 包名（node_modules 路径解析）
    version: parsePkgVersion(m.resource),
    path: normalizeRealPath(m.resource),               // pnpm symlink 归一化
  }));
  const grouped = groupBy(modules, m => `${m.name}@${m.version}`);
  const issues = [];
  // 多版本
  const byName = groupBy(modules, 'name');
  for (const [name, list] of Object.entries(byName)) {
    const versions = [...new Set(list.map(m => m.version))];
    if (versions.length > 1)
      issues.push({ type: 'MULTI_VERSION', name, versions,
        fix: `resolve.alias 统一到 ${versions.sort().at(-1)}` });
  }
  // 同版本多拷贝
  for (const [key, list] of Object.entries(grouped)) {
    const paths = [...new Set(list.map(m => m.path))];
    if (paths.length > 1)
      issues.push({ type: 'MULTI_COPY', name: key, paths,
        singletonRisk: SINGLETON_RISK.includes(key.split('@')[0].replace(/^@[^/]+\//, '')) 
          ? 'HIGH（instanceof/hooks 失效风险）' : 'LOW',
        fix: 'pnpm overrides / resolve.symlinks 检查' });
  }
  return issues.sort((a, b) => RISK[b.singletonRisk] - RISK[a.singletonRisk]);
}
```

**评分点**:
- 双检测（多版本 + 同版本多拷贝）与标识三元组。
- symlink 路径归一化（pnpm 下同版本多拷贝的常见误报/漏报）。
- singleton 风险分级（react 双实例 HIGH——SCN-BLD-216）。
- 修复建议映射（alias/overrides）。
