## ENG-316：手写工单聚类

**需求与边界**：
- 需求：工单文本聚类（关键词/标签）——① 相似工单聚合（同主题 ≥3 强制自助化，ENG-280 规则）；② 输出文档缺口清单（哪些主题缺 FAQ）与建议文档骨架；③ 已有文档却仍高工单的主题标记「文档质量差」。
- 边界：① 聚类用标签优先、文本相似度兜底（编辑距离/关键词重合）；② 时间窗（近 30 天）内统计；③ 输出按工单量降序。

**答**：
```javascript
function ticketCluster(tickets, docs, { window = 30, minRepeat = 3 } = {}) {
  const recent = tickets.filter(t => Date.now() - t.ts < window * 864e5);
  const clusters = [];
  for (const t of recent) {
    const c = clusters.find(c0 =>
      c0.tag === t.tag || similarity(c0.sampleText, t.text) > 0.6);   // 标签优先/相似兜底
    c ? c.items.push(t) : clusters.push({ tag: t.tag, sampleText: t.text, items: [t] });
  }
  return clusters.map(c => {
    const hasDoc = docs.some(d => d.topic === c.tag);
    return {
      topic: c.tag, count: c.items.length,
      action: c.items.length >= minRepeat
        ? (hasDoc ? 'DOC_QUALITY' : 'MISSING_FAQ')      // 有文档仍多工单 = 文档差
        : 'NORMAL',
      skeleton: c.items.length >= minRepeat && !hasDoc
        ? { title: `FAQ: ${c.tag}`, sections: c.items.slice(0, 5).map(t => t.question) } : null,
    };
  }).sort((a, b) => b.count - a.count);
}
```

**评分点**:
- 标签优先 + 相似度兜底的两级聚类。
- 四态动作（NORMAL/MISSING_FAQ/DOC_QUALITY）区分文档缺口与文档质量。
- ≥3 强制自助化（ENG-280 反客服化规则）。
- FAQ 骨架自动生成（从工单问题提取）。
