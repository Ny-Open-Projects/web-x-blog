## OPS-324：手写影子发布验证

**需求与边界**：
- 需求：影子发布期（0 流量）验证部署完整性——① 入口可达（新 HTML 200）；② chunk 清单完整（manifest 引用全存在）；③ buildinfo 正确（版本/commit 匹配）；④ 遥测上报链路通（哨兵能收到影子流量数据）；⑤ CDN 命中正常——全过才自动进 1% 灰度。
- 边界：① 检查项可配置（不同应用检查清单不同）；② 失败阻断 + 归因（哪项失败）；③ 影子期时长到但检查未跑完 = 阻断（不自动放行）。

**答**：
```javascript
async function shadowVerify(release, { checklist = DEFAULT_CHECKS, duration = 30 * 60_000 } = {}) {
  const results = {};
  for (const check of checklist) {
    results[check.name] = await check.run(release);    // { ok, detail }
    if (!results[check.name].ok)
      return { advance: false, failed: check.name, detail: results[check.name].detail,
        note: `影子验证失败：${check.name}——阻断灰度` };
  }
  const elapsed = Date.now() - release.shadowStart;
  if (elapsed < duration)
    return { advance: false, note: `影子期未满（${Math.round(elapsed / 60000)}/${duration / 60000}min），不自动放行` };
  audit({ release: release.id, verdict: 'SHADOW_PASS' });
  return { advance: true, next: 'gray-1%' };           // 全过自动进 1%（SCN-OPS-236）
}
const DEFAULT_CHECKS = [
  { name: 'entry-reachable', run: r => httpOk(r.entryUrl) },
  { name: 'manifest-complete', run: r => allChunksExist(r.manifest) },
  { name: 'buildinfo', run: r => r.buildinfo.commit === r.commit },
  { name: 'telemetry-flow', run: r => sentinelReceived(r.shadowTag) },
  { name: 'cdn-hit', run: r => cdnHitRate(r.entryUrl) > 0.95 },
];
```

**评分点**:
- 五项检查链（入口/清单/buildinfo/遥测/CDN——SCN-OPS-236）。
- 失败即阻断 + 归因（哪项失败）。
- 影子期未满不自动放行（时间完整性）。
- 全过自动进 1%（影子→灰度编排衔接）。
