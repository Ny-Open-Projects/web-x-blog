## BLD-331：手写插件治理

**需求与边界**：
- 需求：构建插件注册表（SCN-ENG-245）——① 注册声明（name/owner/stage/cost 预估/fixtures）；② 运行时度量（实际耗时 vs 声明——声明失真告警）；③ 移除审计（删除插件需 owner 确认——幽灵插件防御）；④ fixture 强制（注册时必须有 fixture 测试）。
- 边界：① 注册表进版本管理（变更可评审——SCN-ENG-219 配置单源）；② cost 预估单位（构建耗时的预估百分比）；③ 新插件门禁（fixture + 性能 diff——SCN-ENG-245 门槛）。

**答**：
```javascript
// plugins/registry.yaml（版本管理——变更可评审）
// - name: svg-sprite, owner: infra, stage: transform, costPct: 2, fixtures: test/fixture-svg
function pluginGovernance(registry, measured) {
  const issues = [];
  for (const p of registry) {
    const m = measured[p.name];
    if (!m) { issues.push({ plugin: p.name, type: 'NOT_INSTALLED' }); continue; }
    // 声明失真告警（预估 2% 实际 20%）
    if (m.costPct > p.costPct * 3)
      issues.push({ plugin: p.name, type: 'COST_UNDERESTIMATED',
        declared: p.costPct, actual: m.costPct,
        fix: '更新声明或优化插件（SCN-BLD-261 剖析）' });
    if (!p.fixtures)
      issues.push({ plugin: p.name, type: 'NO_FIXTURE', level: 'block',
        fix: '注册时必须提供 fixture（SCN-ENG-245 门槛）' });
  }
  // 幽灵插件（装了没注册）
  const ghost = Object.keys(measured).filter(name => !registry.find(p => p.name === name));
  ghost.forEach(g => issues.push({ plugin: g, type: 'GHOST_PLUGIN',
    fix: '注册或移除（幽灵插件是构建黑盒化主因）' }));
  return issues;
}
// 移除审计
removePlugin(name) { requireOwnerConfirm(name); audit({ action: 'plugin-remove', name }); }
```

**评分点**:
- 注册表四字段（name/owner/stage/cost/fixtures——SCN-ENG-245）。
- 声明失真检测（预估 vs 实际 3× 告警）。
- 幽灵插件检测（装了没注册——黑盒化防御）。
- 移除审计 + fixture 强制门槛。
