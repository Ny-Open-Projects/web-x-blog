## OPS-296：手写事件溯源编排

**需求与边界**：
- 需求：编排状态由事件流驱动（PlanCreated/StepStarted/StepSucceeded/StepFailed/RollbackTriggered）；状态 = 事件重放；支持时间旅行（任意事件数处状态）；定期快照加速；崩溃恢复 = 重放+对账（SCN-OPS-212）。
- 边界：① 事件只追加（不可改删）；② 快照与事件混合重放（快照后接增量事件）；③ 对账修正（台账 DONE 但实际未完成 → STALE）。

**答**：
```javascript
function createEventSourcedOrchestrator() {
  const events = [];
  const applyEvent = (state, e) => {
    switch (e.type) {
      case 'PlanCreated': return { ...state, plan: e.plan, steps: {} };
      case 'StepStarted': return { ...state, steps: { ...state.steps, [e.step]: 'RUNNING' } };
      case 'StepSucceeded': return { ...state, steps: { ...state.steps, [e.step]: 'DONE' } };
      case 'StepFailed': return { ...state, steps: { ...state.steps, [e.step]: 'FAILED' } };
      case 'RollbackTriggered': return { ...state, rolling: true };
      default: return state;
    }
  };
  return {
    append(e) { events.push({ ...e, seq: events.length, ts: Date.now() }); },   // 只追加
    stateAt(n) {                                       // 时间旅行
      const snapIdx = latestSnapshotBefore(n);
      let state = snapIdx >= 0 ? snapshots[snapIdx].state : {};
      for (const e of events.slice(snapIdx + 1, n)) state = applyEvent(state, e);
      return state;
    },
    current() { return this.stateAt(events.length); },
    snapshot() { snapshots.push({ at: events.length, state: this.current() }); },
    async resume(checkActual) {                        // 恢复：重放 + 对账
      const state = this.current();
      for (const [step, status] of Object.entries(state.steps)) {
        if (status === 'DONE' && !(await checkActual(step)))
          events.push({ type: 'StepInvalidated', step, reason: 'LEDGER_STALE', seq: events.length });   // 台账虚报
      }
      return this.current();
    },
  };
}
```

**评分点**:
- 事件只追加 + 状态纯函数重放（事件溯源核心）。
- 时间旅行 stateAt(n)（任意时点状态可回放）。
- 快照混合重放（性能优化）。
- 恢复对账（台账 DONE 但实际未完成 → StepInvalidated，SCN-OPS-212）。
