## OPS-284：结论可复核怎么做的？
**答**：
- 可复核要素：实验配置快照（分流规则/样本定义/指标口径/统计方法）+ 原始数据引用（可重算）+ 分析代码版本化——第三方能用这些材料重算出相同结论。
- 预注册：实验前声明「主要指标/样本量/判定标准」（防止事后挑指标 p-hacking）——预注册是实验科学的诚实底线。
- 显著性纪律：多重比较校正（同时看 N 个指标时假阳性膨胀）、最小样本量前置计算——统计卫生。
- 结论分级：达到预注册标准的结论 vs 探索性观察（未预注册的发现只作假设不作结论）——两种结论在报告中区分标注。
- 追问钩子：为什么「预注册」能防 p-hacking——事后看 20 个指标总能找到 1 个「显著」（多重比较的假阳性）；预注册把判定指标在看到数据前锁定，让「挑好看的指标」失去操作空间——这是灰度/实验结论可信度的制度保障。

```javascript
// 预注册：实验前锁定判定标准
preregister({
  primary: 'conversion',
  sampleSize: powerAnalysis({ effect: 0.02, power: 0.8, alpha: 0.05 }),
  guards: ['errorRate', 'complaintRate'],
});
// 分析时
const result = analyze(exp, { by: preregistered });    // 按预注册口径
result.exploratory = otherFindings;                    // 探索性发现单独标注
// 可复核包
exportReplicationPack({ configSnapshot, dataRef, analysisCode, prereg });
```
