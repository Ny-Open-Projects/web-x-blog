## OPS-307：手写实验预注册

**需求与边界**：
- 需求：实验开始前锁定判定口径（主指标/样本量/守护指标）→ 快照存证（hash）；分析时按预注册口径执行，探索性发现单独标注；输出可复核包（配置快照+数据引用+分析代码+预注册 hash）。
- 边界：① 样本量用功效分析前置计算（effect/power/alpha）；② 多重比较校正（探索指标 Bonferroni）；③ 预注册不可修改（修改 = 新实验）。

**答**：
```javascript
function preregister(exp) {
  const spec = {
    primary: exp.primaryMetric,
    guards: exp.guardMetrics,                          // 对冲指标（SCN-OPS-252）
    sampleSize: powerAnalysis({ effect: exp.expectedEffect, power: 0.8, alpha: 0.05 }),
    alpha: 0.05, createdAt: Date.now(),
  };
  const hash = sha256(JSON.stringify(spec));
  return { spec, hash };                               // 不可变存证
}
function analyze(exp, prereg, data) {
  const primary = testHypothesis(data, prereg.spec.primary, prereg.spec.alpha);
  const guards = prereg.spec.guards.map(g => testHypothesis(data, g, prereg.spec.alpha));
  // 探索性指标：Bonferroni 校正
  const exploratory = exp.otherMetrics.map(m =>
    testHypothesis(data, m, prereg.spec.alpha / exp.otherMetrics.length));
  return {
    verdict: primary.significant && guards.every(g => !g.harmful) ? 'ADOPT' : 'REJECT',
    exploratory: exploratory.filter(e => e.significant)
      .map(e => ({ ...e, note: '探索性发现，未预注册，仅作假设' })),   // 分级标注
    replication: { config: prereg.spec, hash: prereg.hash,
      dataRef: data.datasetId, code: analysisCodeVersion },   // 可复核包
  };
}
```

**评分点**:
- 预注册 hash 存证（判定口径锁定防 p-hacking——SCN-OPS-284）。
- 守护指标合取判定（主指标 + 对冲）。
- 探索性发现 Bonferroni 校正 + 分级标注（不冒充结论）。
- 可复核包四要素（配置/数据引用/代码/预注册）。
