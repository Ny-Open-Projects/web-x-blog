## ENG-313：手写依赖环检测

**需求与边界**：
- 需求：包依赖图 + 分层定义（core/ui/feature/app 单向）；检测——① 层间逆向依赖（feature→core 向上引用）；② 包内循环；③ 跨包循环输出环路径；④ 上收建议（共享逻辑下沉到共同下层）。
- 边界：① 循环输出完整路径（A→B→C→A）而非只报存在；② 类型循环豁免（import type 擦除，需标注 verbatimModuleSyntax 生效前提）；③ 上收建议基于「环内包的共同依赖集合」。

**答**：
```javascript
function layerAudit(graph, layers, { typeImportsExempt = true } = {}) {
  const layerOf = (pkg) => Object.entries(layers).find(([, pkgs]) => pkgs.includes(pkg))?.[0];
  const rank = { core: 0, ui: 1, feature: 2, app: 3 };
  const violations = [];
  // 层间逆向
  for (const [pkg, deps] of Object.entries(graph))
    for (const d of deps)
      if (rank[layerOf(d)] < rank[layerOf(pkg)])
        violations.push({ type: 'UPWARD', pkg, dep: d, from: layerOf(pkg), to: layerOf(d) });
  // 环检测（DFS 输出路径）
  const cycles = [];
  const color = {};
  const dfs = (p, path) => {
    if (color[p] === 1) { cycles.push([...path.slice(path.indexOf(p)), p]); return; }
    if (color[p] === 2) return;
    color[p] = 1; path.push(p);
    for (const d of graph[p] || []) dfs(d, path);
    color[p] = 2; path.pop();
  };
  for (const p of Object.keys(graph)) dfs(p, []);
  // 上收建议：环内包共同依赖的下层缺失
  const promote = cycles.map(c => {
    const shared = intersection(...c.map(p => graph[p]));
    return { cycle: c, suggest: shared.filter(x => rank[layerOf(x)] < rank[layerOf(c[0])])
      .length ? `将共享逻辑下沉: ${shared.join(',')}` : '新建 core 包承载共享逻辑' };
  });
  return { violations, cycles, promote };
}
```

**评分点**:
- 双检测（层间逆向 + 环）与完整环路径输出。
- 上收建议基于环内共享依赖（ENG-202 的治理落点）。
- 类型循环豁免及前提声明。
- 染色法环检测正确（三色标记）。
