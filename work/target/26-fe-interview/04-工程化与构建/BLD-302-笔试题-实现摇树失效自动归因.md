## BLD-302：手写摇树归因

**需求与边界**：
- 需求：对保留率高的包自动归因（SCN-BLD-276 延伸）——① 检查包格式（package.json 有无 module/exports import 条件——CJS-only 判定）；② 检查 sideEffects 声明（缺失/错误）；③ 检查消费方 import 方式（default 整包引入 vs named）；④ 输出归因 + 修复建议。
- 边界：① 归因优先级（格式 > sideEffects > 消费方式——格式是根因概率最高）；② 多因并存全部列出；③ 归因依据数据化（package.json 内容/消费方 import 语句）。

**答**：
```javascript
async function shakeAttribution(pkgName, stats, workspace) {
  const pkg = readPkg(pkgName);                        // 包的 package.json
  const consumers = findConsumers(pkgName, workspace); // 消费方 import 语句
  const causes = [];
  if (!pkg.module && !hasImportCondition(pkg))
    causes.push({ type: 'CJS_ONLY', fix: '联系上游提供 ESM 或换 ESM 替代包',
      evidence: 'package.json 无 module/exports.import' });
  if (pkg.sideEffects === undefined || pkg.sideEffects === true)
    causes.push({ type: 'SIDE_EFFECTS_UNDECLARED', fix: 'PR 上游声明 sideEffects 白名单',
      evidence: 'sideEffects 未声明——打包器保守全保留' });
  const badImports = consumers.filter(c => isDefaultFullImport(c));
  if (badImports.length)
    causes.push({ type: 'FULL_IMPORT', fix: '改为 named import（按需）',
      evidence: badImports.map(c => `${c.file}:${c.line}`).slice(0, 5) });
  return { pkgName, retainRate: computeRetainRate(pkgName, stats), causes,
    priority: causes.find(c => c.type === 'CJS_ONLY') ? 'P0' : 'P1' };   // 格式是根因概率最高
}
```

**评分点**:
- 三维归因（格式/sideEffects/消费方式）+ 优先级（格式根因概率最高）。
- 归因依据数据化（package.json/import 语句证据）。
- 多因并列（不只报第一个）。
- 修复建议可执行（PR 上游/改 import）。
