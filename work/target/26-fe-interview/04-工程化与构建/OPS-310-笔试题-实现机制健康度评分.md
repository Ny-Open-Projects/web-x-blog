## OPS-310：手写机制健康度

**需求与边界**：
- 需求：灰度机制自身健康分——分流（SRM 发生率）、哨兵（漏报率需事故回溯/误报率）、纪律（放量节奏遵守/绕过率）、回滚（SLO 达标率）；四维加权合成健康分；短板归因输出。
- 边界：① 漏报率的分母是「真实事故数」（哨兵有信号但没告警 / 总事故——SCN-OPS-282 回溯机制）；② 绕过带豁免不算违规；③ 短板归因给具体改进项。

**答**：
```javascript
function grayHealth(grays, incidents, sentinelStats, { weights = { split: .3, sentinel: .3, discipline: .2, rollback: .2 } } = {}) {
  const srmRate = grays.filter(g => g.srmDetected).length / grays.length;
  const splitScore = 1 - srmRate * 5;                  // SRM 率 20% → 0 分
  // 哨兵双率
  const fpRate = sentinelStats.falseAlarms / sentinelStats.alarms;
  const missRate = incidents.filter(i =>
    sentinelHadSignal(i) && !sentinelAlerted(i)).length / incidents.length;   // 漏报：事故回溯
  const sentinelScore = (1 - fpRate) * (1 - missRate);
  const discipline = grays.filter(g => g.rampSloOk && (!g.bypass || g.waiverValid)).length / grays.length;
  const rollback = grays.filter(g => g.rollbackSloMet).length / (grays.filter(g => g.rolledBack).length || 1);
  const dims = { split: splitScore, sentinel: sentinelScore, discipline, rollback };
  const total = Object.entries(dims).reduce((s, [k, v]) => s + v * weights[k], 0);
  const weakest = Object.entries(dims).sort((a, b) => a[1] - b[1])[0];
  return { dims, total,
    attribution: {
      split: srmRate > 0 ? '排查分流实现（缓存/重试/身份合并）' : null,
      sentinel: missRate > 0 ? '补观测盲区（用户先感知的错误类型）' : null,
      discipline: '放量节奏纪律培训或自动化拦截',
    }[weakest[0]],                                     // 短板归因
  };
}
```

**评分点**:
- 四维加权（split/sentinel/discipline/rollback）。
- 漏报率用事故回溯口径（哨兵有信号但未告警——SCN-OPS-282）。
- 绕过带豁免不扣分（合规绕过合法）。
- 短板归因到具体改进动作（评分 → 行动闭环）。
