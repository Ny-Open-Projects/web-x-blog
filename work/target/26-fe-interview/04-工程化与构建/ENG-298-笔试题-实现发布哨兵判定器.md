## ENG-298：手写发布哨兵

**需求与边界**：
- 需求：发布后窗口期（10 分钟）对比新旧版本指标（错误率/性能）；超阈值触发回滚建议（可配置自动执行）；窗口期指标噪声平滑（滑动 3 分钟窗）；恢复检测（指标回落自动解除告警）。
- 边界：① 基线取「发布前同窗口」数据（环境因素剥离）；② 错误率阈值 = 基线 × 倍数 + 绝对下限（低基线时不误报）；③ 每个指标独立判定，任一触发即整体告警。

**答**：
```javascript
function releaseSentinel({ window = 10 * 60_000, smooth = 3 } = {}) {
  const baseline = { errorRate: 0.005, ttiP75: 2200 };
  const history = [];
  function evaluate(sample, { autoRollback = false } = {}) {
    history.push(sample);
    const smoothWindow = history.slice(-smooth);       // 滑动平滑
    const cur = {
      errorRate: avg(smoothWindow.map(s => s.errorRate)),
      ttiP75: avg(smoothWindow.map(s => s.ttiP75)),
    };
    const verdicts = {};
    // 倍数 + 绝对下限双条件（低基线不误报）
    verdicts.errorRate = cur.errorRate > Math.max(baseline.errorRate * 1.5, 0.01) ? 'FAIL' : 'OK';
    verdicts.ttiP75 = cur.ttiP75 > baseline.ttiP75 * 1.3 ? 'FAIL' : 'OK';
    const failed = Object.entries(verdicts).filter(([, v]) => v === 'FAIL');
    if (failed.length) {
      const action = autoRollback ? 'ROLLBACK_EXECUTED' : 'ROLLBACK_SUGGESTED';
      report({ type: 'RELEASE_REGRESSION', failed: failed.map(([k]) => k), cur, baseline, action });
      if (autoRollback) rollbackEntry();
      return { verdicts, action };
    }
    if (wasFailing()) { clearAlert(); notify('指标恢复'); }   // 恢复检测
    return { verdicts, action: null };
  }
  return { evaluate };
}
```

**评分点**:
- 版本对比基线（发布前同窗口，环境剥离）。
- 倍数 + 绝对下限双条件（低基线误报防御）。
- 滑动窗口平滑（瞬时尖刺不触发）。
- 自动/建议两档回滚 + 恢复解除。
