## BLD-310：手写语法残留扫描

**需求与边界**：
- 需求：扫描产物中的现代语法残留（SCN-BLD-235）——① 解析产物 AST 检测目标浏览器不支持的特征（可选链/空值合并/static 块）；② 定位特征与最低版本要求；③ 输出修复指引（哪个 loader 漏配 targets——worker/loader 链独立配置的漏配是高发）。
- 边界：① 特征-版本映射表（ES 特性 → caniuse 最低版本）；② 按目标浏览器集合判定（browserslist 解析——全部目标都支持才放行）；③ 扫描性能（大产物——只扫 chunk 不扫 map）。

**答**：
```javascript
const FEATURES = { optionalChaining: { es: 'ES2020', min: { chrome: 80, safari: 13.1 } },
  nullishCoalescing: { es: 'ES2020', min: { chrome: 80, safari: 13.1 } },
  staticBlock: { es: 'ES2022', min: { chrome: 94, safari: 16.4 } } };
function scanSyntaxArtifacts(bundle, targets) {
  const targetSet = parseBrowserslist(targets);
  const issues = [];
  for (const chunk of bundle.chunks) {
    const ast = parseJs(chunk.code);                   // 产物 AST（排除 map）
    walk(ast, node => {
      const feature = detectFeature(node);             // 节点 → 特征名
      if (!feature) return;
      const f = FEATURES[feature];
      const supportedEverywhere = targetSet.every(t =>
        semver.gte(browserVersion(t, feature), f.min[t.family] ?? Infinity) || !f.min[t.family]);
      if (!supportedEverywhere)
        issues.push({ chunk: chunk.name, feature, es: f.es,
          unsupportedTargets: targetSet.filter(t => semver.lt(browserVersion(t), f.min[t.family] ?? Infinity)),
          fix: '检查该 chunk 的 loader 链 targets 配置（worker/loader 常漏配）' });
    });
  }
  return issues;   // 低版本浏览器白屏的产物级防线
}
```

**评分点**:
- 特征-版本映射表驱动（ES 特性 → caniuse 最低版本）。
- 全目标判定（任一目标不支持即报——SCN-ENG-243 数据驱动）。
- 修复指引指向 loader 链漏配（worker 高发——SCN-BLD-235）。
- 只扫 chunk 不扫 map（性能）。
