## OPS-252：对冲指标怎么设计？
**答**：
- 对冲原理：每个「要改善的指标」配一个「防恶化的守护指标」——提速发布配变更失败率、提高转化配客诉率、减少体积配功能完整度（SCN-ENG-284 反 Goodhart 的灰度版）。
- 对冲触发：守护指标劣化超阈值时，即使主指标亮眼也判定「不通过」——灰度判定是合取（主指标达标 AND 守护指标不劣化）。
- 对冲指标选择：与主指标有博弈关系的（优化 A 可能牺牲 B）——来自历史经验（哪些优化曾带来副作用）与业务常识。
- 展示同屏：主指标与守护指标在看板成对呈现——只看主指标的决策是盲决策。
- 追问钩子：为什么灰度判定必须是「主指标达标 AND 守护指标不劣化」的合取——单独看主指标时，「把客服入口藏起来」也能提升转化；对冲指标把「优化的隐藏代价」纳入判定，让灰度决策代表「净收益」而非「单点收益」——这是灰度从「指标游戏」到「价值判断」的关键。

```javascript
const HEDGE = { conversion: 'complaint_rate', deployFreq: 'changeFailRate',
                bundleSize: 'featureCompleteness' };
function grayVerdict(gray, stage) {
  const main = gray.metrics[stage.targetMetric];
  const guard = gray.metrics[HEDGE[stage.targetMetric]];
  const mainOk = main >= baseline * 1.02;
  const guardOk = guard <= baseline * 1.1;             // 守护劣化 < 10%
  return mainOk && guardOk ? 'PASS' : 'FAIL';
}
// 看板成对呈现
board.pair(stage.targetMetric, HEDGE[stage.targetMetric]);
```
