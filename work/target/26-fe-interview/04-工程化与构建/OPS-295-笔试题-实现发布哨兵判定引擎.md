## OPS-295：手写发布哨兵引擎

**需求与边界**：
- 需求：指标采样 → 滑动平滑 → 动态基线（同时段 4 周中位数，SCN-OPS-247）对比 → 判定；哨兵按信任分级（observe-only/alert-only/can-break，SCN-OPS-276）；每次判定记录（判定依据可审计）。
- 边界：① 基线样本不足降级绝对阈值并标注；② 平滑窗口内瞬时尖刺不触发；③ 判定记录带「当时基线值」供误报复盘。

**答**：
```javascript
class ReleaseSentinel {
  constructor(metric, { smooth = 3, history } = {}) {
    this.metric = metric; this.window = []; this.trust = trustLevel(metric);   // OPS-276 分级
    this.history = history;                            // 4 周历史（动态基线源）
  }
  feed(sample) {
    this.window.push(sample);
    if (this.window.length > this.smooth) this.window.shift();
    const cur = avg(this.window);                      // 平滑
    const base = dynamicBaseline(this.metric, sample.ts, this.history);
    const baseline = base.baseline ?? base.fallback;   // 样本不足降级
    const degraded = !base.baseline;
    const breached = cur > baseline * 1.3;
    const verdict = { cur, baseline, breached, degraded, ts: sample.ts,
                      trust: this.trust, at: Date.now() };
    auditLog.push(verdict);                            // 判定记录（含当时基线——误报复盘依据）
    if (breached && this.trust === 'can-break') return { action: 'BREAK', verdict };
    if (breached && this.trust !== 'observe-only') return { action: 'ALERT', verdict };
    return { action: breached ? 'OBSERVE' : 'OK', verdict };
  }
}
function dynamicBaseline(metric, ts, history) {
  const seasonal = history
    .filter(h => sameWeekdayHour(h.ts, ts) && !inEventWindow(h.ts))   // 同时段+排除事件
    .map(h => h[metric]);
  return seasonal.length >= 3
    ? { baseline: median(seasonal) }
    : { fallback: ABSOLUTE_THRESHOLDS[metric], note: '基线样本不足' };
}
```

**评分点**:
- 动态基线（同时段+排除事件+样本不足降级标注）。
- 滑动平滑（瞬时尖刺不触发）。
- 信任分级决定动作（observe/alert/break——SCN-OPS-276）。
- 判定记录带当时基线（误报复盘可回放）。
