## OPS-300：手写哨兵信任分级

**需求与边界**：
- 需求：哨兵生命周期 observe-only（冷启动）→ alert-only（误报率达标）→ can-break（可信）→ demoted（劣化降权）→ 恢复（修复后重新试用）；分级判定依据 30 天误报率与告警量。
- 边界：① 冷启动下限（<10 次告警不评级）；② 误报定义：告警后 15 分钟内指标自行恢复且无真实故障 = 误报；③ demoted 恢复需人工确认（不能自动恢复——防震荡）。

**答**：
```javascript
function sentinelTrust(sentinel, { minAlarms = 10, fpTarget = 0.05 } = {}) {
  const stats = sentinel.stats30d();
  if (stats.alarms < minAlarms) return { level: 'observe-only', note: '冷启动' };
  const fpRate = stats.falseAlarms / stats.alarms;     // 误报 = 15min 自恢复且无故障
  if (fpRate > 0.2) return { level: 'demoted', action: '降权为 observe-only' };
  if (fpRate > fpTarget) return { level: 'alert-only' };
  return { level: 'can-break' };                       // 误报率 < 5% 可接入熔断
}
function demoteRecovery(sentinel) {
  // demoted → alert-only 需人工确认（防震荡），不能自动恢复
  return requireManualConfirm(`哨兵 ${sentinel.id} 恢复 alert-only？`,
    { note: `当前误报率 ${sentinel.stats30d().falseAlarms / sentinel.stats30d().alarms}` });
}
// 分级变化事件
sentinel.onLevelChange((from, to) => audit({ from, to, ts: Date.now(), stats: sentinel.stats30d() }));
```

**评分点**:
- 五级生命周期（observe/alert/can-break/demoted/恢复）。
- 误报判定规则明确（15min 自恢复且无故障）。
- 误报率三档映射（<5% can-break / <20% alert / >20% demoted）。
- demoted 恢复需人工确认（防自动震荡——SCN-OPS-276）。
