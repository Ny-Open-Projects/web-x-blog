## OPS-302：手写审批流引擎

**需求与边界**：
- 需求：按风险级别装配审批节点（L0 空 / L2 [owner] / L3 [owner, platform, oncall-mgr]）；角色路由（角色 → 当前在职角色成员，代理规则）；节点超时升级；审批摘要自动生成（盲批防御，SCN-OPS-241）。
- 边界：① 顺序审批（前节点通过后激活下节点）；② 代理不产生「自己批自己」（申请人不能审批）；③ 摘要含 diff 摘要/影响面/回滚计划。

**答**：
```javascript
function assembleFlow(riskLevel, plan, applicant) {
  const templates = APPROVAL_TEMPLATES[riskLevel] ?? [];
  let prev = null;
  return templates.map(t => {
    const node = {
      role: t.role,
      approvers: activeMembersOf(t.role).filter(u => u !== applicant),   // 申请人不能自批
      timeout: t.timeout,
      escalateTo: t.escalateTo,
      brief: {
        diffSummary: summarizeDiff(plan.diff),         // 变更摘要
        impact: impactReport(plan),                    // 影响面
        rollback: plan.rollback,                       // 回滚计划
      },
      status: 'pending', prev,
    };
    prev = node;
    return node;
  });
}
function tickFlow(flow) {
  for (const node of flow) {
    if (node.status !== 'pending') continue;
    if (node.prev && node.prev.status !== 'approved') break;   // 顺序审批
    if (Date.now() - node.openedAt > node.timeout)
      escalate(node, node.escalateTo);                 // 超时升级
    return node;                                       // 当前活跃节点
  }
}
```

**评分点**:
- 角色路由 + 申请人自批防御（SoD）。
- 顺序审批链（前节点未通过后节点不激活）。
- 摘要三件套（diff/影响面/回滚——盲批防御）。
- 超时升级挂在节点级（每节点独立 SLA）。
