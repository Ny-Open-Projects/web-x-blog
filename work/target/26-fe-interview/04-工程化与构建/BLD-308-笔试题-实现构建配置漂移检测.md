## BLD-308：手写配置漂移检测

**需求与边界**：
- 需求：检测项目 config 与 preset 的漂移（SCN-ENG-267 温度计）——① 解析合并后配置（preset + override 求值）；② 与 preset 基线 diff（有效配置层面的差异——不是源码文本 diff）；③ 漂移模式聚类（≥3 项目相同 override → 上收 preset 建议）；④ 告警阈值（diffRatio > 30% = preset 失效预警）。
- 边界：① 语义键归一（嵌套展开/默认值剔除——只比「显式覆盖」）；② override 的意图分类（环境适配/错误修复/任意定制）；③ 输出上收建议带项目清单。

**答**：
```javascript
function configDrift(projects, preset, { driftThreshold = 0.3, promoteThreshold = 3 } = {}) {
  const report = projects.map(p => {
    const effective = resolveConfig([preset, p.config]);   // 合并求值（语义层）
    const overrides = explicitOverrides(effective, presetDefaults);   // 显式覆盖键
    return { name: p.name, keys: overrides,
      ratio: overrides.length / presetKeyCount };      // 漂移比例
  });
  // 模式聚类
  const keyCount = {};
  report.forEach(r => r.keys.forEach(k => (keyCount[k] ??= []).push(r.name)));
  const promote = Object.entries(keyCount)
    .filter(([k, names]) => names.length >= promoteThreshold)   // ≥3 项目相同 override
    .map(([k, names]) => ({ path: k, projects: names,
      suggest: '上收进 preset（SCN-ENG-267）' }));
  const drifting = report.filter(r => r.ratio > driftThreshold);
  return { report, promote,
    health: drifting.length ? 'PRESET_DRIFTING' : 'OK',
    fix: drifting.length ? `${drifting.map(d => d.name)} 漂移超 30%——共性上收或重新评估 preset 边界` : null };
}
```

**评分点**:
- 语义层 diff（合并求值后比，非源码文本）。
- 显式覆盖提取（默认值剔除——只算真 override）。
- 聚类上收建议（≥3 项目——SCN-ENG-304 同源）。
- preset 失效预警（漂移比例阈值）。
