## ENG-328：手写技术雷达校验

**需求与边界**：
- 需求：雷达数据（工具 × 环 × owner）校验——① 状态迁移必须带证据链接（试验报告/试点数据）；② 采纳环之外的技术出现在生产依赖 = 违规（需豁免记录）；③ 雷达容量上限（>40 告警）；④ hold 项必须有理由。
- 边界：① 生产依赖检测：雷达数据 × package.json 交叉；② 豁免带过期时间（ENG-281 同源）；③ hold 理由缺失 = 雷达最常见的形式主义。

**答**：
```javascript
function radarAudit(radar, prodDeps, waivers, { cap = 40 } = {}) {
  const issues = [];
  if (radar.length > cap) issues.push({ type: 'TOO_MANY', count: radar.length,
    note: '雷达是决策清单不是工具目录' });
  for (const item of radar) {
    if (item.ring === 'hold' && !item.reason)
      issues.push({ tool: item.name, type: 'HOLD_NO_REASON', fix: '补充暂缓理由（最值钱的部分）' });
    if (item.movedFrom && !item.evidence)
      issues.push({ tool: item.name, type: 'MOVE_NO_EVIDENCE', fix: '状态迁移附试验报告' });
  }
  // 生产依赖交叉检测
  for (const dep of prodDeps) {
    const item = radar.find(r => r.name === dep.name);
    if (item && item.ring !== 'adopt') {
      const waiver = waivers.find(w => w.tool === dep.name && new Date(w.expiresAt) > new Date());
      if (!waiver) issues.push({ tool: dep.name, type: 'NON_ADOPT_IN_PROD', ring: item.ring,
        fix: '走豁免评审或迁移到采纳环' });
    }
    if (item && item.ring === 'hold' && !waivers.find(w => w.tool === dep.name))
      issues.push({ tool: dep.name, type: 'HOLD_IN_PROD', severity: 'HIGH',
        fix: 'hold 且无豁免却在线上——雷达与实际脱节' });
  }
  return issues;
}
```

**评分点**:
- 双向交叉（雷达 × 生产依赖——脱节即违规）。
- hold 无理由 = 形式主义头号检测（ENG-274）。
- 迁移带证据（状态变化不免费）。
- 豁免过期联动（ENG-281 豁免治理复用）。
