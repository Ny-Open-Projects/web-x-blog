## BLD-329：手写火焰图数据

**需求与边界**：
- 需求：构建 hook 计时数据（SCN-BLD-300）转火焰图——① 树结构（hook 嵌套→父子层级）；② 自耗时计算（父时长 − 子时长合计——嵌套不失真）；③ 折叠格式（collapsed stack lines——speedscope/flamegraph 兼容）；④ TopN 自耗时（热点定位）。
- 边界：① 异步 hook 的时间重叠处理（并行 hook 不嵌套——按时间区间归属）；② 零时长节点过滤（噪声）；③ 跨构建对比（两次构建的火焰 diff——优化验证）。

**答**：
```javascript
function toFlameGraph(timings) {
  // 1. 构建树（parent 名字链接——异步按时间区间归属）
  const byName = new Map(timings.map(t => [t.name, t]));
  const root = { name: 'build', children: [] };
  for (const t of timings.sort((a, b) => a.start - b.start)) {
    const parent = t.parent ? byName.get(t.parent) : root;
    if (parent && !overlapsParallel(t, parent))        // 并行 hook 不嵌套
      (parent.children ??= []).push(t);
  }
  // 2. 自耗时
  const self = (t) => (t.end - t.start) - sum((t.children ?? []).map(c => c.end - c.start));
  // 3. collapsed 折叠格式（speedscope 兼容）
  const collapsed = [];
  const walk = (node, stack) => {
    const s = [...stack, node.name];
    collapsed.push(`${s.join(';')} ${Math.round(self(node))}`);
    (node.children ?? []).forEach(c => walk(c, s));
  };
  walk(root, []);
  // 4. TopN + 对比
  const top = timings.map(t => ({ name: t.name, self: self(t) }))
    .filter(t => t.self > 10).sort((a, b) => b.self - a.self).slice(0, 10);
  return { collapsed, top };
}
// 对比：diffFlames(before, after)——优化前后的自耗时变化
```

**评分点**:
- 树构建 + 异步重叠处理（并行 hook 不嵌套）。
- 自耗时 = 总 − 子合计（嵌套不失真——SCN-BLD-300）。
- collapsed 折叠格式（speedscope/flamegraph 兼容——工具生态）。
- TopN + 跨构建对比（优化验证）。

## 变体与延伸（补充）

**变体与延伸**：

1. 时间戳该用什么时钟？ → 单调时钟 process.hrtime 避免系统时间跳变，跨进程记录时再做一次偏移校正。
2. 多 worker 数据怎么合并？ → 按 worker 分组标注 lane，统一到同一时钟基准后按区间重叠拼装，避免时间轴错位。
3. 自耗时怎么算？ → 节点总时长减去所有直接子节点时长，begin/end 要成对匹配，缺失配对时按区间闭合处理，并标记为可疑节点，避免把异常区间画成正常耗时。
