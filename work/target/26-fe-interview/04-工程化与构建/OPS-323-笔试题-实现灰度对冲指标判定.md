## OPS-323：手写对冲判定

**需求与边界**：
- 需求：灰度放量判定 = 主指标达标 AND 守护指标不劣化（SCN-OPS-252）——① 主指标与守护指标映射表配置化；② 守护劣化容忍带（<10% 不触发）；③ 合取失败输出失败原因（哪个守护指标劣化了）；④ 看板成对呈现数据输出。
- 边界：① 主指标需统计显著（小样本不判定——SCN-OPS-203）；② 守护指标基线与主指标同时段（动态基线复用，SCN-OPS-304）；③ 映射缺失时该指标不参与判定（显式降级）。

**答**：
```javascript
function hedgeVerdict(gray, stage, { hedgeMap = HEDGE_DEFAULT, tolerance = 0.1 } = {}) {
  const target = stage.targetMetric;
  const guard = hedgeMap[target];
  if (!guard) return { verdict: 'PASS', note: `${target} 无对冲指标（显式降级）` };
  const main = gray.metrics[target];
  const mainSig = significance(main, gray.sampleSize);   // 统计显著性
  if (!mainSig.confident)
    return { verdict: 'INSUFFICIENT_SAMPLE', need: mainSig.required };
  const mainOk = main.value >= main.baseline * 1.02;
  const guardMetric = gray.metrics[guard];
  const guardOk = guardMetric.value <= guardMetric.baseline * (1 + tolerance);
  return {
    verdict: mainOk && guardOk ? 'PASS' : 'FAIL',
    failedOn: mainOk ? [guard] : [target, ...(guardOk ? [] : [guard])],
    pair: { [target]: main.value, [guard]: guardMetric.value },   // 看板成对
    reason: !mainOk ? `主指标未达标` : `守护指标 ${guard} 劣化 ${pct(guardMetric)}`,
  };
}
```

**评分点**:
- 合取判定（主达标 AND 守护不劣化——SCN-OPS-252）。
- 主指标统计显著前置（小样本不判定）。
- 守护劣化容忍带（10%）+ 映射缺失显式降级。
- 失败原因与成对数据输出（看板/决策双用）。
