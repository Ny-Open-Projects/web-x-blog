## BLD-326：手写多目标一致性

**需求与边界**：
- 需求：多目标产物（web/node/edge）的行为一致性测试（SCN-BLD-278）——① 统一 fixture 跨目标构建；② 行为断言（同输入同输出——纯函数行为/导出面）；③ 导出面 diff（跨目标导出差异——某目标漏导出）；④ 环境适配层的 mock（node 特有 API 的 web stub）。
- 边界：① 环境差异显式声明（哪些行为允许不同——平台差异 vs 缺陷区分）；② 断言集共享（一份断言跑三目标）；③ 失败归因（转换链差异 vs 平台语义差异）。

**答**：
```javascript
const TARGETS = ['web', 'node', 'edge'];
async function crossTargetConsistency(fixture, { allowedDiffs = {} } = {}) {
  const results = {};
  for (const t of TARGETS) {
    const built = await build(fixture, targetConfig(t));   // 各目标构建
    results[t] = await runBehavior(built, BEHAVIOR_SUITE, { env: t });   // 同断言集
  }
  const diffs = [];
  for (const behavior of BEHAVIOR_SUITE) {
    const outs = TARGETS.map(t => results[t][behavior.id]);
    if (!allEqual(outs)) {
      const isAllowed = allowedDiffs[behavior.id]?.includes('platform');
      diffs.push({ behavior: behavior.id, outs,
        verdict: isAllowed ? 'PLATFORM_DIFF' : 'INCONSISTENT',   // 平台差异 vs 缺陷
        cause: isAllowed ? allowedDiffs[behavior.id].note : guessCause(results) });
    }
  }
  // 导出面 diff
  const exportDiffs = TARGETS.map(t => exportsOf(results[t]))
    .reduce((a, b) => symmetricDiff(a, b));
  return { consistent: diffs.every(d => d.verdict === 'PLATFORM_DIFF') && !exportDiffs.length,
    diffs, exportDiffs };
}
```

**评分点**:
- 统一 fixture + 共享断言集（一断言跑三目标——SCN-BLD-278）。
- 平台差异 vs 缺陷区分（allowedDiffs 显式声明）。
- 导出面跨目标 diff（某目标漏导出）。
- 失败归因（转换链 vs 平台语义）。
