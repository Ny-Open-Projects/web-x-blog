## OPS-297：手写发布风险分级器

**需求与边界**：
- 需求：按显式因素分级（diff 大小/危险路径/灰度计划/窗口/历史相似成功率）→ L0~L3 → 审批强度映射；输出触发因素列表（分级可解释，SCN-OPS-202）；申诉改级记录。
- 边界：① 危险路径清单配置化；② 因素加权而非简单计数（危险路径权重 > 窗口）；③ 申诉改级必须留原级（审计）。

**答**：
```javascript
const DANGEROUS = loadConfig('dangerous-paths.yaml');
const WEIGHTS = { big: 2, dangerous: 3, noCanary: 2, badWindow: 1, lowHistory: 2 };
function riskLevel(pr, ctx) {
  const factors = [];
  let score = 0;
  if (pr.diffLines > 500) { factors.push('big'); score += WEIGHTS.big; }
  const hit = pr.paths.filter(p => DANGEROUS.some(d => p.startsWith(d)));
  if (hit.length) { factors.push({ dangerous: hit }); score += WEIGHTS.dangerous; }
  if (!pr.canaryPlan) { factors.push('noCanary'); score += WEIGHTS.noCanary; }
  if (isFridayAfternoon(ctx.ts)) { factors.push('badWindow'); score += WEIGHTS.badWindow; }
  if (similarSuccessRate(pr) < 0.8) { factors.push('lowHistory'); score += WEIGHTS.lowHistory; }
  const level = score >= 7 ? 'L3' : score >= 5 ? 'L2' : score >= 2 ? 'L1' : 'L0';
  return { level, factors, score, approval: APPROVAL_MAP[level] };   // 因素显式可解释
}
function appeal(level, newLevel, { reason, approver }) {
  return auditAppeal({ from: level, to: newLevel, reason, approver, original: level });   // 原级留痕
}
```

**评分点**:
- 因素加权（危险路径权重最高——影响面优先于时机）。
- 因素显式输出（分级可解释可申诉——SCN-OPS-202 反博弈）。
- 危险路径清单配置化（随治理演进）。
- 申诉留原级（审计完整）。
