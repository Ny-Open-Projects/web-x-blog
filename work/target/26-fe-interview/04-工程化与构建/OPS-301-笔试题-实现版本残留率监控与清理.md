## OPS-301：手写版本残留监控

**需求与边界**：
- 需求：从遥测统计在线版本分布 → 残留率（旧版本用户占比）→ 清理调度（N-2 资源在「残留率 < 1% 且超过保留窗口」后删除）→ 清理前二次验证（无流量探测）。
- 边界：① 残留率按 7 日活跃口径（7 日内有遥测的版本）；② 清理白名单（回滚目标版本永不清理，SCN-OPS-243）；③ 清理是可逆动作前的最后一道（清理失败不影响线上）。

**答**：
```javascript
function versionResidue(telemetry, releases, { threshold = 0.01, keepWindow = 7 } = {}) {
  const active = groupBy(telemetry.filter(t => withinDays(t.ts, 7)), 'version');
  const total = Object.values(active).reduce((s, a) => s + a.length, 0);
  const dist = Object.entries(active).map(([v, list]) =>
    ({ version: v, pct: list.length / total }));
  const current = releases.latest().version;
  const prev = releases.previous().version;
  return dist.filter(d => d.version !== current).map(d => ({
    ...d,
    residue: d.pct,
    canClean: d.pct < threshold && olderThan(d.version, keepWindow)
      && d.version !== prev,                           // 回滚目标版本永不清理
  }));
}
async function scheduleCleanup(candidates) {
  for (const c of candidates.filter(x => x.canClean)) {
    const probing = await probeTraffic(c.version, 24 * 3600_000);   // 清理前 24h 探测
    if (probing.zeroTraffic) await deleteAssets(c.version);         // 二次验证后清理
    else report({ type: 'CLEANUP_DEFERRED', version: c.version, traffic: probing.counts });
  }
}
```

**评分点**:
- 残留率 7 日活跃口径（长会话用户不误删——SCN-OPS-232）。
- 回滚目标版本白名单（安全网永不清理——SCN-OPS-243）。
- 清理前 24h 零流量探测（二次验证）。
- 清理推迟可观测（DEFERRED 事件）。
