## ENG-318：手写离线依赖包生成

**需求与边界**：
- 需求：私有源灾备——按 lockfile 生成离线依赖包（tarball 清单 + 校验），支持离线安装验证；增量更新（只打包新增/变化包）；离线包带完整性清单（安装时校验）。
- 边界：① 平台二进制依赖（esbuild/swc 多平台 tarball）全平台打包（缺失会让离线安装崩溃）；② tarball hash 校验（防离线介质损坏）；③ 离线安装演练（每周 CI 真实跑，ENG-279 纪律）。

**答**：
```javascript
async function offlinePack(lockfile, { prevManifest } = {}) {
  const packages = resolveLockfile(lockfile);          // 全量 tarball 引用
  const platformPkgs = packages.filter(p => isPlatformBinary(p));   // esbuild/swc 全平台
  const all = [...packages, ...platformPkgs.filter(p => !packages.includes(p))];
  const changed = prevManifest
    ? all.filter(p => !prevManifest[p.name] || prevManifest[p.name].hash !== p.hash)   // 增量
    : all;
  await downloadAll(changed);
  const manifest = Object.fromEntries(all.map(p => [p.name, { hash: p.hash, size: p.size }]));
  writeJson('offline/manifest.json', manifest);
  // 离线安装验证（每周 CI）
  await verifyOfflineInstall('offline/', { expectPackages: all.length });
  return { total: all.length, incremental: changed.length, manifest };
}
async function verifyOfflineInstall(dir, { expectPackages }) {
  const res = await pnpmInstallOffline(dir);
  if (res.installed !== expectPackages) fail(`离线包不完整: ${res.installed}/${expectPackages}`);
  for (const [name, meta] of Object.entries(readJson(dir + '/manifest.json')))
    if (sha256(res.tarball(name)) !== meta.hash) fail(`离线包损坏: ${name}`);   // 完整性校验
}
```

**评分点**:
- 平台二进制全平台打包（缺失是离线安装的头号崩溃原因）。
- 增量打包（prevManifest diff，介质与带宽友好）。
- 安装时逐包 hash 校验（介质损坏防护）。
- 每周 CI 演练（ENG-279 灾备防腐烂纪律）。
