## ENG-333：手写成熟度对标报告（ENG 收束）

**需求与边界**：
- 需求：整合 ENG 系列能力生成对标报告——① 输入各子域体检数据（monorepo 治理/CI/依赖/发布/DevEx/AI）；② 按四阶段模型（ENG-271）定位当前级别；③ 输出「下一步最值得投的三件事」（按 ROI 排序）+ 报告正文。
- 边界：① 各子域体检项带通过/部分/未通过三态（非二值）；② 阶段判定取「短板维度」（最低子域决定级别——木桶原则）；③ 三件事输出必须带预估 ROI 与 owner 建议。

**答**：
```javascript
function maturityReport(assessments) {                 // 各子域体检结果
  const domains = Object.entries(assessments).map(([name, a]) => ({
    name,
    score: a.items.reduce((s, i) => s + (i.pass ? 2 : i.partial ? 1 : 0), 0),
    max: a.items.length * 2,
  }));
  const weakest = domains.sort((a, b) => a.score / a.max - b.score / b.max)[0];   // 木桶短板
  const stage = weakest.score / weakest.max >= 0.7 ? 'L2' : weakest.score / weakest.max >= 0.4 ? 'L1' : 'L0';
  // 下一步三件事：各子域未通过项 × ROI（ENG-326 计算器复用）
  const candidates = Object.values(assessments)
    .flatMap(a => a.items.filter(i => !i.pass).map(i => ({ ...i, domain: a.name })));
  const top3 = candidates.map(c => ({ ...c, roi: estimateRoi(c) }))
    .sort((a, b) => b.roi - a.roi).slice(0, 3)
    .map(c => ({ item: c.item, roi: c.roi, owner: suggestOwner(c.domain) }));
  return {
    stage, weakest: weakest.name,
    top3,                                              // 带 ROI 与 owner
    summary: `当前 ${stage}（短板 ${weakest.name}），优先投入: ${top3.map(t => t.item).join(' / ')}`,
  };
}
```
