## OPS-330：手写灰度结束判定

**需求与边界**：
- 需求：灰度成功三条件合取（技术/业务/验收，SCN-OPS-268）——① 技术层含「周期覆盖」（工作日+周末各观察过）；② 业务层主指标 + 守护指标（SCN-OPS-323）；③ 验收清单全过；任一未过 → 决策树分支。
- 边界：① 周期覆盖按「各档位都覆盖」还是「整体覆盖」——取整体覆盖（任一大档位覆盖即算）；② 验收项分阻断/非阻断（非阻断缺失可带条件放全量）；③ 判定记录输出（哪些条件过了哪些没过）。

**答**：
```javascript
function grayCompletion(gray) {
  const tech = {
    hardOk: gray.hardMetrics.allPass(),
    cycleCovered: gray.observedWindows.has('weekday') && gray.observedWindows.has('weekend'),
  };
  const biz = {
    main: significance(gray.mainMetric).confident && gray.mainMetric.met,
    guards: gray.guardMetrics.every(g => !g.degraded),
  };
  const acceptance = {
    blocking: gray.acceptance.filter(a => a.blocking),
    nonBlocking: gray.acceptance.filter(a => !a.blocking && !a.done),
  };
  const pass = tech.hardOk && tech.cycleCovered && biz.main && biz.guards
    && acceptance.blocking.every(a => a.pass);
  return {
    verdict: pass ? 'ADVANCE_FULL' : 'DECISION_TREE',
    conditions: { tech, biz, acceptance: acceptance.blocking.every(a => a.pass) },
    conditional: !pass && acceptance.blocking.every(a => a.pass)
      ? { allow: 'CONDITIONAL_FULL', missing: acceptance.nonBlocking } : null,   // 非阻断缺失可带条件
    log: { tech, biz, acceptance: gray.acceptance },
  };
}
```

**评分点**:
- 三条件合取 + 周期覆盖检查（weekday+weekend——SCN-OPS-268）。
- 阻断/非阻断验收区分（非缺失可带条件放全量）。
- 判定详情输出（哪些过了哪些没过——决策可解释）。
- 未全过 → 决策树（SCN-OPS-299 衔接）。
