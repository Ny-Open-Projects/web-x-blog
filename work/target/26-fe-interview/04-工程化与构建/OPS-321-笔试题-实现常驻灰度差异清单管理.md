## OPS-321：手写常驻差异账本

**需求与边界**：
- 需求：企业客户常驻定制的差异账本——① 每个客户的差异 flag 清单（哪些功能/配置不同）+ 维护成本计量（flag 数 × 维护单价分账，SCN-OPS-262）；② 主版本升级时按客户生成回归范围（差异面 = 回归面）；③ 差异收敛建议（长期无人使用的定制 flag 提示移除）。
- 边界：① 差异 flag 与常规 flag 标记区分（standing vs regular）；② 成本按客户分账（有偿定制）；③ 回归范围按差异 flag 的消费模块推导。

**答**：
```javascript
function standingDiffLedger(customers, flags, { unitCost = 50 } = {}) {
  return customers.map(c => {
    const diffs = flags.filter(f => f.standing && f.customer === c.id);
    const monthlyCost = diffs.length * unitCost;       // 分账
    const upgradeRegression = diffs.flatMap(f => f.consumedByModules)   // 差异面 = 回归面
      .filter(unique);
    const stale = diffs.filter(f =>
      !f.usedRecently(90) && f.type !== 'compliance');  // 合规定制不移除
    return {
      customer: c.id, diffCount: diffs.length, monthlyCost,
      upgradeRegression,
      convergence: stale.length
        ? { flags: stale.map(f => f.key), suggest: '90 天未使用的定制 flag 建议移除（合规类除外）' }
        : null,
    };
  });
}
// 主版本升级时
upgradePlan({ perCustomer: customers.map(c => c.upgradeRegression) });
```

**评分点**:
- 差异账本三功能（分账/回归范围/收敛建议——SCN-OPS-262）。
- 差异面 = 回归面（升级回归范围由消费模块推导）。
- 合规类定制豁免收敛（不误删法规要求）。
- 90 天未使用阈值（定制的生命周期管理）。
