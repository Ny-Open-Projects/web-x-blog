## OPS-258：并行灰度怎么处理？
**答**：
- 流量池冲突：两个灰度同时 10% 流量，若无协调可能重叠 1%（叠加区）——叠加区用户受双重变更影响，指标无法归因。
- 分层正交：并行灰度按层分配（SCN-ENG-253 分层盐），层间独立不叠加；同层互斥（一个灰度占一个槽位）。
- 全局配额：同时进行的灰度数量上限（如 3 个）——过多并行灰度的组合空间爆炸（SCN-OPS-253 组合告警）。
- 重叠区处理：无法正交时的重叠区单独标记（双重变更用户），指标分析时排除或单列。
- 追问钩子：为什么并行灰度必须有「全局数量上限」——3 个灰度各有 2 组 = 8 种组合，4 个就有 16 种；组合数超分析能力后任何指标波动都无法归因（SCN-ENG-253 组合爆炸），上限是对「可归因性」的工程保护而非官僚限制。

```javascript
function graySlotManager(activeGrays, newGray) {
  const LAYER_CAP = 3;
  if (activeGrays.length >= LAYER_CAP)
    return reject(newGray, `并行灰度已达上限 ${LAYER_CAP}（组合爆炸防御）`);
  const layer = allocateOrthogonalLayer(newGray, activeGrays);   // 分层正交
  return assign(newGray, layer);
}
// 无法正交时的重叠区
const overlap = usersInBoth(grayA, grayB);
overlap.forEach(u => mark(u, 'DUAL_CHANGE'));            // 指标分析时单列
```
