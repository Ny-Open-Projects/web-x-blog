## OPS-326：手写自愈执行器

**需求与边界**：
- 需求：故障模式 → 自愈动作匹配执行（SCN-OPS-259）——① 规则表驱动（模式/动作/边界声明）；② 动作可逆性校验（不可逆动作拒绝自动执行）；③ 自愈频率熔断（同模式 1 小时内 >3 次自愈 = 系统性问题告警并停用该规则）；④ 全程审计。
- 边界：① 模式匹配防抖（同类故障 5 分钟内去重）；② 动作执行超时回滚（自愈动作本身失败要恢复现场）；③ 规则禁用需人工确认（防自愈规则被频繁误触发后静默失效）。

**答**：
```javascript
const SELF_HEAL_RULES = [
  { pattern: 'chunk-404', action: 'version-align-refresh', reversible: true },
  { pattern: 'srm-skew', action: 'pause-ramp', reversible: true },
  { pattern: 'rollback-entry', action: null, note: '回滚不可自动——走决策树' },   // 不可逆动作示例
];
async function selfHeal(incident, rules, { dedupe = 5 * 60_000, freqCap = 3 } = {}) {
  const rule = rules.find(r => r.pattern === incident.type);
  if (!rule?.action) return { healed: false, note: '无可自动动作（回滚走决策树 SCN-OPS-234）' };
  if (recentHeals(incident.type, dedupe).length) return { deduped: true };    // 防抖
  if (healCount(incident.type, 3600_000) >= freqCap) {
    disableRule(rule, { reason: '1h 内自愈超 3 次——系统性问题', requireManual: true });   // 频率熔断
    alert({ type: 'HEAL_FREQ_CAP', pattern: incident.type });
    return { capped: true };
  }
  const undo = await executeAction(rule.action, incident);   // 执行并保留 undo
  audit({ pattern: incident.type, action: rule.action, ts: Date.now() });
  return { healed: true, undo };                       // 自愈动作可逆（undo 通道）
}
```

**评分点**:
- 可逆性校验（不可逆动作显式拒绝——回滚走决策树）。
- 频率熔断（1h >3 次停用规则——系统性问题不硬扛）。
- 防抖去重（5 分钟同类不重复自愈）。
- undo 通道（自愈动作本身失败可恢复现场）。
