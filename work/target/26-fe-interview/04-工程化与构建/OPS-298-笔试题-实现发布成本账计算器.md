## OPS-298：手写发布成本账

**需求与边界**：
- 需求：按发布类型（normal/major/hotfix）计算全成本——机器（CI 分钟/双版本存储）、人力（审批/盯守/验收工时×时薪）、机会（值守占用）、摊销（演练与预案/发布次数）；输出单位成本对比与趋势。
- 边界：① 人力工时从审批/盯守/验收系统取（不是估算）；② hotfix 成本含「中断常规发布的连带成本」；③ 摊销按季度发布次数均摊。

**答**：
```javascript
function releaseCostLedger(releases, prices) {
  const byType = groupBy(releases, 'type');
  return Object.entries(byType).map(([type, list]) => {
    const per = list.map(r => {
      const machine = r.ciMinutes * prices.ci
        + (r.dualVersionDays ?? 0) * prices.storage;
      const labor = (r.approvalMin + r.watchMin + r.acceptanceMin) / 60 * prices.hourly;
      const opportunity = r.oncallOccupiedHours * prices.oncall;
      const hotfixExtra = type === 'hotfix'
        ? r.interruptedNormalReleases * avgCost(byType.normal) : 0;   // hotfix 连带成本
      return { id: r.id, machine, labor, opportunity, hotfixExtra,
        total: machine + labor + opportunity + hotfixExtra };
    });
    return {
      type, avgTotal: avg(per.map(p => p.total)),
      laborShare: avg(per.map(p => p.labor / p.total)),           // 人力占比（通常 > 机器）
      perRelease: per,
    };
  });
}
// 摊销
const drillAmortized = quarterlyDrillCost / releasesThisQuarter();
// 趋势：单位成本随自动化下降曲线
trend(byType.map(t => t.avgTotal));
```

**评分点**:
- 人力工时从系统取（非估算——SCN-OPS-267 诚实性）。
- hotfix 连带成本（中断常规发布的隐性代价）。
- 人力占比输出（证明人力是真实约束）。
- 摊销按季度发布次数均摊（成本归集完整）。
