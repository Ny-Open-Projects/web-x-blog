## ENG-292：手写幽灵依赖检测器

**需求与边界**：
- 需求：扫描源码 import，比对 package.json 声明；分类：未声明（phantom）/声明了但未使用（unused）/peer 误用（库包直接 import peer 而非引用注入）。
- 边界：① 解析子路径 import（lodash/fp 归属 lodash）；② 类型导入（import type）不豁免 phantom（运行时虽擦除但类型上同样应声明）；③ 内部包（@org/*）对照 workspace 清单；④ node 内建模块白名单。

**答**：
```javascript
const BUILTIN = new Set(require('module').builtinModules);
function phantomScan(file, src, pkgJson, workspacePkgs) {
  const imports = parseImports(src);                 // ast 解析 import/export from
  const declared = new Set([
    ...Object.keys(pkgJson.dependencies ?? {}),
    ...Object.keys(pkgJson.devDependencies ?? {}),
    ...Object.keys(pkgJson.peerDependencies ?? {}),
  ]);
  const used = new Set();
  const issues = [];
  for (const spec of imports) {
    if (spec.startsWith('.') || spec.startsWith('/')) continue;   // 相对路径
    const name = spec.startsWith('@')
      ? spec.split('/').slice(0, 2).join('/')        // @scope/pkg/sub -> @scope/pkg
      : spec.split('/')[0];                          // lodash/fp -> lodash
    if (BUILTIN.has(name)) continue;
    used.add(name);
    if (!declared.has(name))
      issues.push({ type: 'PHANTOM', name, file,
        internal: workspacePkgs.has(name) });        // 内部包提示走 workspace 引用
  }
  for (const name of declared)
    if (!used.has(name) && isDirectSourceUse(pkgJson.path, name))
      issues.push({ type: 'UNUSED', name, file });
  return issues;
}
```

**评分点**:
- 子路径 import 归一化（scope 包切两段）。
- 三分类（phantom/unused/peer 误用）完整。
- builtin 白名单与相对路径跳过。
- internal 标记（内部包应走 workspace 依赖）。
