## BLD-314：手写趋势检测

**需求与边界**：
- 需求：检测体积的缓慢劣化（SCN-BLD-283）——① 滚动斜率（近 30 次构建线性回归）；② 单 PR 跳变与缓变区分（单 PR > 5% 即跳变告警，缓变斜率阈值更低）；③ 分 chunk 维度（哪 chunk 在涨——业务 chunk 优先排查）；④ 与 Ratchet 联动（趋势检测预警在前，Ratchet 硬拦在后）。
- 边界：① 基线排除（大促/活动期的合理膨胀标记排除——SCN-SLA-742 事件排除）；② 斜率单位（KB/天——跨时间可比）；③ 检测粒度（入口级 + chunk 级双层）。

**答**：
```javascript
function sizeTrendDetection(builds, { creepKbPerDay = 5, jumpPct = 0.05 } = {}) {
  const issues = [];
  const analyze = (series, level, name) => {
    const sorted = series.sort((a, b) => a.ts - b.ts);
    const last = sorted.at(-1), prev = sorted.at(-2);
    // 1. 单 PR 跳变（硬）
    const jump = (last.gzip - prev.gzip) / prev.gzip;
    if (jump > jumpPct) issues.push({ level, name, type: 'JUMP',
      delta: last.gzip - prev.gzip, pr: last.pr });
    // 2. 缓变斜率（软）
    const slope = linearRegression(sorted.map(b =>
      ({ x: daysBetween(sorted[0].ts, b.ts), y: b.gzip }))).slope;   // KB/天
    if (slope > creepKbPerDay && !inEventWindow(last.ts))    // 事件排除（大促合理膨胀）
      issues.push({ level, name, type: 'CREEP', slope: +slope.toFixed(1),
        note: `按此趋势 30 天后 +${Math.round(slope * 30)}KB——Ratchet 将触发（SCN-ENG-291）` });
  };
  analyze(entrySeries(builds), 'entry', 'main');       // 入口级
  for (const [chunk, series] of chunkSeries(builds))   // chunk 级
    analyze(series, 'chunk', chunk);
  return issues.sort((a, b) => (b.type === 'JUMP') - (a.type === 'JUMP'));   // 跳变优先
}
```

**评分点**:
- 双检测（单 PR 跳变 + 缓变斜率）双层（入口+chunk）。
- 斜率单位 KB/天（跨时间可比）+ 未来推算（30 天后量化）。
- 事件排除（大促合理膨胀——SCN-SLA-742 同构）。
- 与 Ratchet 联动（软预警在前硬拦在后——SCN-BLD-283）。
