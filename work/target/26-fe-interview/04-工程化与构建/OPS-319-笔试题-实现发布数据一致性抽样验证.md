## OPS-319：手写数据一致性验证

**需求与边界**：
- 需求：回滚后对「新版本期间写入的真实数据」抽样——① 用旧版本读写路径实测（不只 schema 检查，SCN-OPS-277）；② 抽样策略（按数据类型分层：订单/配置/用户态，高风险类型 oversample）；③ 失败分类（读失败/展示异常/业务逻辑不兼容）与修复任务生成。
- 边界：① 抽样比例按数据量（大量数据抽 0.1%，小量全量）；② 读失败与逻辑不兼容区分（前者是 schema 问题，后者是业务逻辑问题）；③ 验证结果回填兼容性声明（修正「兼容」的错误声明）。

**答**：
```javascript
async function dataCompatVerify(writtenByNew, oldVersion, { sampleRate = 0.001 } = {}) {
  const byType = groupBy(writtenByNew, 'type');        // 订单/配置/用户态分层
  const results = [];
  for (const [type, list] of Object.entries(byType)) {
    const sample = list.length > 1000
      ? stratifiedSample(list, sampleRate, { oversample: HIGH_RISK_TYPES.includes(type) })
      : list;                                          // 小量全量
    for (const d of sample) {
      const r = await oldVersion.read(d);              // 旧版本真实读路径
      if (!r.ok) { results.push({ type, id: d.id, failure: 'READ_FAIL', err: r.err }); continue; }
      const rendered = oldVersion.render(r.data);      // 展示层
      if (!rendered.ok) { results.push({ type, id: d.id, failure: 'RENDER_FAIL' }); continue; }
      const biz = oldVersion.businessLogic(r.data);    // 业务逻辑（下单链路回放）
      if (!biz.ok) results.push({ type, id: d.id, failure: 'LOGIC_INCOMPAT', detail: biz.err });
    }
  }
  const failures = groupBy(results, 'failure');
  if (results.length)
    updateCompatDeclation({ corrected: failures.READ_FAIL ? 'schema 不兼容' : null,
      logic: failures.LOGIC_INCOMPAT ? '需业务逻辑兼容层' : null });   // 修正兼容声明
  return { sampled: results.length, failures: failures, repairTasks: genRepair(results) };
}
```

**评分点**:
- 三层失败分类（READ_FAIL/RENDER_FAIL/LOGIC_INCOMPAT——schema 检查抓不住逻辑级）。
- 分层抽样 + 高风险类型 oversample。
- 小数据量全量验证。
- 验证结果回填兼容性声明（修正错误声明——SCN-OPS-277 闭环）。
