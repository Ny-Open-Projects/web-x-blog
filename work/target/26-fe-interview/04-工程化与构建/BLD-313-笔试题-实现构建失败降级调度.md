## BLD-313：手写构建降级调度

**需求与边界**：
- 需求：构建失败的分级处置（SCN-BLD-264）——① 失败分类（源码/基础设施/配置）；② 重试策略（幂等基础设施失败指数退避，源码错误零重试）；③ 降级通道（本地构建 runbook——非标准发布带审计标记）；④ 降级频率监控（降级成为常态 = 基础设施故障）。
- 边界：① 幂等判定（依赖安装可重试/代码编译错误不可）；② 降级发布的补验义务（事后跑 CI 验证产物 hash 一致）；③ 重试上限与熔断（依赖源挂了不无限重试）。

**答**：
```javascript
async function buildFailureHandler(err, ctx, { maxRetry = 3 } = {}) {
  const kind = classify(err);                          // SOURCE / INFRA / CONFIG
  if (kind === 'SOURCE') return { action: 'BLOCK', note: '源码错误禁止降级放行' };
  if (kind === 'CONFIG') return { action: 'ROLLBACK_CONFIG', diff: err.configDiff };
  // INFRA：幂等重试
  const idempotent = ['dep-install', 'cache-read', 'cdn-upload'].includes(err.stage);
  if (idempotent) {
    for (let i = 0; i < maxRetry; i++) {
      await sleep(backoff(i));                         // 指数退避
      const r = await retryStage(err.stage).catch(e => e);
      if (!(r instanceof Error)) return { action: 'RETRIED_OK' };
      if (r.code === 'SERVICE_DOWN') break;            // 服务真挂：熔断重试
    }
  }
  // 降级：本地构建 runbook（SCN-ENG-279）
  const degraded = await localBuildRunbook(ctx);
  await postVerify(degraded.artifactHash);             // 补验义务：事后 CI hash 一致
  monitor.degradeRate();                               // 降级率监控（常态 = 基础设施故障）
  return { action: 'DEGRADED', audit: { reason: err.message, hash: degraded.artifactHash } };
}
```

**评分点**:
- 三分类处置（源码阻断/配置回滚/基础设施重试——SCN-BLD-264 分级）。
- 幂等判定驱动重试（指数退避 + 服务真挂熔断）。
- 降级补验义务（事后 CI hash 一致——非标准通道的验证闭环）。
- 降级率监控（常态化降级 = 基础设施问题）。
