## ENG-300：手写构建遥测聚合

**需求与边界**：
- 需求：遥测样本按维度聚合（scope: local/ci、task、project），输出各维 P50/P95、缓存命中率、本地 vs CI 差异倍数、劣化项目清单（P95 超 7 日基线 20%）。
- 边界：① 分位数用排序插值；② 本地/CI 差异倍数 = CI P95 / 本地 P95（>3 提示环境问题）；③ 劣化哨兵基线用 7 日滑动（排除单日异常）。

**答**：
```javascript
function telemetryAggregate(samples, { degradeThreshold = 1.2 } = {}) {
  const byDim = groupBy(samples, s => `${s.task}|${s.project}`);  // 分组键不含 scope，local/ci 才能落在同组内对比
  const results = [];
  for (const [dim, list] of byDim) {
    const durations = list.map(s => s.durationMs).sort((a, b) => a - b);
    const local = list.filter(s => s.scope === 'local'), ci = list.filter(s => s.scope === 'ci');
    results.push({
      dim,
      p50: quantile(durations, 0.5), p95: quantile(durations, 0.95),
      cacheHitRate: list.filter(s => s.cacheHit).length / list.length,
      ciLocalRatio: local.length && ci.length
        ? quantile(ci.map(s => s.durationMs), 0.95) / quantile(local.map(s => s.durationMs), 0.95) : null,
    });
  }
  // 劣化哨兵：7 日基线
  const degraded = results.filter(r => {
    const base = baseline7d(r.dim);                    // 7 日滑动基线
    return base && r.p95 > base * degradeThreshold;
  });
  return { results, degraded, hints: results
    .filter(r => r.ciLocalRatio > 3)
    .map(r => `${r.dim}: CI 比本地慢 ${r.ciLocalRatio.toFixed(1)}×，排查环境而非配置`) };
}
```

**评分点**:
- 三维聚合（scope/task/project）+ 分位插值。
- 本地 vs CI 比值诊断（>3 提示环境问题——ENG-269 洞察）。
- 7 日滑动基线劣化哨兵。
- 缓存命中率按维统计（治理目标定位）。

## 变体与延伸（补充）

**变体与延伸**：

1. P95 怎么算才准？ → 数据量小时保留原始样本直接排序取分位，量大时用 t-digest 近似并标注误差范围。
2. 劣化哨兵阈值怎么定？ → 基线分位变化率加绝对阈值双条件触发，只满足一个不报警，避免小样本噪声误报。
3. 分层维度选什么？ → 机器规格、项目、分支三条主轴，同层内比较才有解释力，跨层混合会掩盖真实劣化，也会放大抖动。
