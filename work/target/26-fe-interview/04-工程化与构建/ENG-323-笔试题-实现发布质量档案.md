## ENG-323：手写发布质量档案

**需求与边界**：
- 需求：聚合历史发布与哨兵结果——① 按维度分析异常率：星期几/时段/变更大小（diff 行数）/发布人经验；② 找出「高危发布模式」（如周五发布异常率 ×3）；③ 高危模式自动变成窗口规则建议（回灌 ENG-322）。
- 边界：① 样本量分组下限（<5 次发布的分桶不分析）；② 相关不等于因果（标注「模式相关性」）；③ diff 大小分桶（<100/100-500/>500 行）。

**答**：
```javascript
function releaseQualityArchive(releases, incidents) {
  const enriched = releases.map(r => ({
    ...r,
    failed: incidents.some(i => i.deployId === r.id),   // 部署归属（SCN-ENG-299 口径）
    sizeBucket: r.diffLines < 100 ? 'S' : r.diffLines < 500 ? 'M' : 'L',
  }));
  const dims = { weekday: r => new Date(r.ts).getDay(),
    size: r => r.sizeBucket, hour: r => new Date(r.ts).getHours() };
  const patterns = [];
  for (const [name, fn] of Object.entries(dims))
    for (const [bucket, list] of Object.entries(groupBy(enriched, fn))) {
      if (list.length < 5) continue;                    // 样本下限
      const rate = list.filter(r => r.failed).length / list.length;
      const base = enriched.filter(r => r.failed).length / enriched.length;
      if (rate > base * 2)                              // 2× 基线 = 高危模式
        patterns.push({ dim: name, bucket, rate, base,
          note: '模式相关性，非因果', suggest: ruleSuggestion(name, bucket) });
    }
  return { patterns, rules: patterns.map(p => p.suggest).filter(Boolean) };
}
function ruleSuggestion(dim, bucket) {                  // 回灌窗口规则
  return dim === 'weekday' && bucket === '5' ? '新增禁发规则: 周五全天'
    : dim === 'size' && bucket === 'L' ? 'L 级变更要求分批发布' : null;
}
```

**评分点**:
- 部署归属口径复用 DORA（SCN-ENG-299 一致性）。
- 样本下限 + 相关非因果标注（ENG-284 反 Goodhart）。
- 高危模式自动回灌窗口规则（数据 → 规则闭环）。
- 三维分析（星期/时段/变更大小）。
