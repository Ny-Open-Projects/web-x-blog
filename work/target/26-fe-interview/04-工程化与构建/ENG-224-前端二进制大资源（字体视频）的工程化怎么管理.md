## ENG-224：大资源工程化怎么管理？
**答**：
- 仓库策略：大文件不进 Git（LFS/独立 CDN 仓库 + manifest 引用）——git clone 时间与仓库膨胀是 monorepo 隐形杀手。
- 资源管线：字体子集化（按字符集 unicode-range 分片）、视频转码多清晰度（ABR）、3D 模型轻量化（SCN-661 同源）——处理管线自动化（CI 上传 CDN + 生成 manifest）。
- 版本化：资源 immutable hash 命名 + manifest 版本表，引用端按 manifest 解析 URL——资源更新不影响代码发布。
- 审计与清理：资源使用引用分析（哪些资源没被引用了），定期归档清理降存储成本。
- 追问钩子：为什么字体子集化要按 unicode-range 分片而不是整包子集——整包子集仍可能几 MB；按 range 切片后浏览器只下载实际用到的字符段（中文页面 vs 英文页面加载量差 10 倍）。

```javascript
// 资源 manifest（构建产出）
{ "fonts/noto-sans-sc": [
    { "range": "U+4E00-9FFF", "url": "cdn/.../noto-4e00.woff2", "hash": "a1b2" },
    { "range": "U+0000-00FF", "url": "cdn/.../noto-latin.woff2", "hash": "c3d4" } ] }
// CI 字体子集化
pyftsubset NotoSansSC.ttf --unicodes=U+4E00-9FFF --flavor=woff2
```
