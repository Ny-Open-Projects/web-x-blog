## ENG-330：手写成熟度评分

**需求与边界**：
- 需求：五维评分（交付/质量/治理/体验/智能，1~5 级）——① 每维由客观指标映射分数；② 抽样实做校验（随机抽 PR 检查评审质量）对客观分修正（±1 级）；③ 输出雷达 + 各维短板改进项。
- 边界：① 指标到分数的映射表显式（可评审）；② 抽样与指标分差 >2 级时标记「指标失真」；③ 评估面向改进不排名（ENG-285 纪律）。

**答**：
```javascript
function maturityScore(metrics, samples, { mapping } = {}) {
  const dims = {};
  for (const [dim, table] of Object.entries(mapping)) {
    const v = metrics[dim];
    dims[dim] = table.find(t => v >= t.min)?.level ?? 1;   // 显式映射表
  }
  // 抽样实做修正
  const sampleScore = avg(samples.map(s => s.processQuality));   // 1~5
  for (const dim of Object.keys(dims)) {
    const delta = sampleScore - metrics[`${dim}Proxy`];
    if (Math.abs(delta) > 2) report({ type: 'METRIC_DISTORTED', dim, delta,
      note: '指标与实做分差过大，指标可能被优化到失真' });   // ENG-284 反模式
    else dims[dim] = clamp(dims[dim] + Math.sign(delta) * (Math.abs(delta) > 1 ? 1 : 0), 1, 5);
  }
  const gaps = Object.entries(dims).filter(([, l]) => l <= 2)
    .map(([dim, l]) => ({ dim, level: l, plan: improvementPlan(dim) }));
  return { dims, gaps };   // 面向改进：gaps 进下年路线图（ENG-227）
}
```

**评分点**:
- 显式映射表（分数可评审非黑箱）。
- 抽样实做对客观分修正 + 分差 >2 失真告警（ENG-284/285 双保险）。
- clamp 修正幅度（±1 级，防抽样颠覆指标）。
- 短板 → 改进计划 → 路线图（评估闭环）。
