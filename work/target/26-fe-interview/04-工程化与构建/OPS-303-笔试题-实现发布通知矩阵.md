## OPS-303：手写发布通知矩阵

**需求与边界**：
- 需求：按事件类型路由通知——发布前预告（依赖方，API 变更需 ack）、发布中事件流（观察室）、发布后摘要（广播）、灰度放量降噪（日合并）、关键事件（回滚/熔断即时）；未 ack 阻塞发布。
- 边界：① ack 超时提醒（24h 未 ack 升级通知）；② 降噪窗口内关键事件穿透（合并但不吞关键）；③ 通知记录可审计（谁在什么时候被通知过）。

**答**：
```javascript
function notifyRouter(event, subscriptions) {
  const route = {
    preAnnounce: () => ({
      to: dependents(event.plan),
      needAck: hasApiChange(event.plan),               // API 变更必须确认
      escalateAfter: '24h',
    }),
    stepEvent: () => ({ to: 'watch-room', realtime: true }),
    grayAdvance: () => ({ to: subscribers, mergeWindow: '1d' }),   // 降噪合并
    rollbackOrBreak: () => ({ to: 'all-oncall', urgent: true, bypassMerge: true }),   // 关键穿透
  }[event.type]?.();
  if (!route) return;
  const audiences = resolveAudience(route.to, subscriptions);
  audiences.forEach(a => sendNotification(a, event, { ...route,
    record: auditLog.push({ event: event.type, to: a.id, ts: Date.now() }) }));   // 可审计
}
function gateCheck(plan) {
  const needAck = dependents(plan).filter(d => hasApiChange(plan) && !d.acked);
  if (needAck.length)
    return { blocked: true, pending: needAck, note: 'API 变更未获全部确认' };
  return { blocked: false };
}
```

**评分点**:
- ack 与发布门禁联动（未确认不发布——SCN-OPS-245）。
- 关键事件穿透降噪窗口（合并不吞关键）。
- ack 超时升级通知。
- 通知记录可审计（谁何时被告知过）。
