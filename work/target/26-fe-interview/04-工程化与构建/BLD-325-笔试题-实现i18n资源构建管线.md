## BLD-325：手写 i18n 管线

**需求与边界**：
- 需求：i18n 资源构建（SCN-BLD-273）——① 语言 chunk 拆分（每语言独立 chunk——按需加载）；② key 混淆（长 key → 短 id 映射——产物体积省 30%+）；③ 完整性校验（各语言 key 集合一致——漏译检测）；④ 使用分析（未使用的 key 剔除——摇树）。
- 边界：① 混淆映射文件独立产出（运行时解码——key 映射随 chunk）；② 漏译检测按 key 集合 diff（缺失 key fallback 到默认语言）；③ 未使用 key 的检测（源码扫描——SCN-BLD-273）。

**答**：
```javascript
function i18nBuild(locales, sourceFiles) {
  // 1. 使用分析
  const used = new Set();
  for (const f of sourceFiles)
    for (const m of fs.readFileSync(f, 'utf8').matchAll(/t\(['"]([\w.]+)['"]/g))
      used.add(m[1]);
  // 2. key 混淆（长 key → 短 id）
  const keyMap = {}; let i = 0;
  for (const k of used) keyMap[k] = i.toString(36);    // 基 36 短 id
  // 3. 语言 chunk + 完整性
  const chunks = {};
  for (const [lang, dict] of Object.entries(locales)) {
    const missing = [...used].filter(k => !(k in dict));
    if (missing.length) warn(`${lang} 漏译 ${missing.length} keys——fallback 到默认语言`);
    chunks[lang] = Object.fromEntries(
      [...used].filter(k => k in dict).map(k => [keyMap[k], dict[k]]));   // 混淆 + 未使用剔除
  }
  // 4. 产物（映射表随 chunk——运行时解码）
  return { keyMap, chunks: Object.fromEntries(Object.entries(chunks).map(([lang, data]) =>
    [lang, `export default ${JSON.stringify(data)}`])) };
}
```

**评分点**:
- 四段管线（使用分析/混淆/拆分/完整性）。
- 混淆映射随 chunk（运行时解码——key 重命名省体积）。
- 漏译检测（key 集合 diff + fallback 声明）。
- 未使用 key 剔除（摇树思想——SCN-BLD-273）。
