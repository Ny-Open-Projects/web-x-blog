## OPS-292：手写灰度放量状态机

**需求与边界**：
- 状态：NOT_STARTED → 1% → 5% → 25% → 50% → 100%，伴随 PAUSED（熔断）与 ROLLED_BACK。
- 边界：① 自动放量仅限 ≤25%（SCN-OPS-242 上限）；② 熔断冻结当前档位，恢复需显式解除（审计）；③ 每次档位变化记录（决策者/依据）；④ 降档允许（50→10 止血），升档需门槛达标。

**答**：
```javascript
function createGrayFSM({ stages = [1, 5, 25, 50, 100], autoCap = 25 } = {}) {
  let idx = -1, state = 'IDLE', log = [];
  const advance = (by, basis) => {
    if (idx + 1 >= stages.length) return { rejected: 'AT_FULL' };
    const next = stages[idx + 1];
    const auto = next <= autoCap && basis?.hardOk;     // 自动上限
    if (!auto && !by) return { rejected: 'NEED_HUMAN', next };
    idx++;
    log.push({ action: 'ADVANCE', to: next, by: by ?? 'auto', basis, ts: Date.now() });
    return { now: next };
  };
  const breakIt = (by) => {                            // 熔断：冻结当前档
    state = 'PAUSED';
    log.push({ action: 'BREAK', at: stages[idx], by, ts: Date.now() });
  };
  const resume = (by, condition) => {
    if (!conditionMet(condition)) return { rejected: 'RESUME_COND_UNMET' };
    state = 'RUNNING';
    log.push({ action: 'RESUME', by, condition, ts: Date.now() });
  };
  const downgrade = (to, by) => {                      // 降档止血（50→10）
    const i = stages.indexOf(to);
    if (i < 0 || i > idx) return { rejected: 'ONLY_DOWN' };
    idx = i;
    log.push({ action: 'DOWNGRADE', to, by, ts: Date.now() });
  };
  const rollback = (by) => { idx = -1; state = 'ROLLED_BACK'; log.push({ action: 'ROLLBACK', by, ts: Date.now() }); };
  return { advance, breakIt, resume, downgrade, rollback,
    get stage() { return idx >= 0 ? stages[idx] : 0; },
    get state() { return state; }, get log() { return log; } };
}
```

**评分点**:
- 自动放量 25% 上限（超限必须人工）。
- 熔断冻结/恢复带条件与审计（SCN-OPS-222 语义）。
- 降档止血与回滚区分（降档保留观察）。
- 全程决策日志（谁/依据/何时）。
