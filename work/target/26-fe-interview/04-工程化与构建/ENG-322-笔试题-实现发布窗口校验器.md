## ENG-322：手写发布窗口校验

**需求与边界**：
- 需求：发布申请校验——① 是否在允许窗口（Mon-Thu 14:00-17:00）；② 是否命中禁发（周五下午/节前 N 天/封网期）；③ 并发发布数（同时段 ≤2）；④ hotfix 豁免（带升级审批引用则放行并记录）。
- 边界：① 时区处理（窗口按发布地域时区）；② 节前判定用节假日日历服务；③ 并发检测含「已排期的待发布」（不只看运行中）。

**答**：
```javascript
function releaseWindowCheck({ ts, region, isHotfix, approvalRef }, calendar) {
  const local = toZoned(ts, TZ[region]);
  const day = local.getDay(), hour = local.getHours();
  if (isHotfix && approvalRef)                       // hotfix 豁免但记录
    return { allowed: true, bypass: 'HOTFIX', audit: { ts, approvalRef } };
  if (day === 5 && hour >= 12)                       // 周五下午禁发（ENG-258）
    return { allowed: false, reason: '周五下午（周末 MTTR 风险）' };
  if (calendar.isFreeze(ts)) return { allowed: false, reason: '封网期' };
  if (calendar.daysToHoliday(ts) <= 2)
    return { allowed: false, reason: '节前 2 天内' };
  if (day === 0 || day === 6 || hour < 14 || hour >= 17)
    return { allowed: false, reason: '非发布窗口（工作日 14:00-17:00）' };
  const concurrent = scheduledReleases(ts).length;   // 含已排期
  if (concurrent >= 2)
    return { allowed: false, reason: `同时段已有 ${concurrent} 个发布（归因上限）` };
  return { allowed: true };
}
```

**评分点**:
- 时区感知（多地域发布窗口本地化）。
- 禁发三层（周五下午/节前/封网）+ 原因可读。
- 并发检测含已排期（不只运行中）。
- hotfix 豁免带审批审计（不破坏治理）。
