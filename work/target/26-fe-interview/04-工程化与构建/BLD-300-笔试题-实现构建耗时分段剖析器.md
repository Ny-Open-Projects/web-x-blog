## BLD-300：手写分段剖析器

**需求与边界**：
- 需求：构建各阶段/插件 hook 的计时——① 阶段计时（resolve/transform/minify/emit）；② hook 级计时（每插件每个 hook 的耗时与调用次数）；③ 输出 TopN 报告（慢插件/慢 loader 定位——SCN-BLD-261）；④ 计时本身开销可忽略（采样或缓存时间戳）。
- 边界：① 异步 hook 的计时（await 前后时间戳——并发 hook 的时间归属）；② 嵌套 hook（hook 内再触发 hook）的树形归属；③ 输出火焰图数据格式（可导入分析工具）。

**答**：
```javascript
function instrumentHooks(compiler) {
  const timings = [];                                  // { name, start, end, parent }
  const stack = [];
  function wrap(hook, name) {
    const orig = hook.tap.bind(hook);
    hook.tap = (options, fn) => {
      return orig(options, (...args) => {
        const entry = { name: `${name}:${options.name ?? 'anon'}`,
          start: performance.now(), parent: stack.at(-1)?.name };
        stack.push(entry); timings.push(entry);
        try {
          const r = fn(...args);
          if (r?.then) return r.finally(() => { entry.end = performance.now(); stack.pop(); });   // 异步 hook
          entry.end = performance.now(); stack.pop();
          return r;
        } catch (e) { entry.end = performance.now(); stack.pop(); throw e; }
      });
    };
  }
  // 包装关键 hook
  ['resolve', 'transform', 'emit'].forEach(stage => wrap(compiler.hooks[stage], stage));
  return {
    report(topN = 10) {                                // 树形归属 + TopN
      const selfTime = computeSelfTime(timings);       // 总时长 − 子时长（自耗时）
      return { top: selfTime.sort((a, b) => b.ms - a.ms).slice(0, topN),
        flame: toFlameData(timings) };                 // 火焰图数据
    },
  };
}
```

**评分点**:
- hook 级插桩（含异步 hook 的 finally 计时）。
- 嵌套归属（栈结构——父子时间可分离）。
- 自耗时计算（总时长减子时长——嵌套不失真）。
- TopN + 火焰图数据双输出。
