## OPS-311：手写预案-脚本一致性校验

**需求与边界**：
- 需求：预案卡片（人读）与演练脚本（机跑）双向校验——① 每个预案有对应脚本（缺失 = 演练债务）；② 脚本步骤与预案步骤语义一致（步骤数/关键动作匹配）；③ 脚本断言与预案的「成功标准」一致（如 5 分钟内完成）；输出漂移清单与修复建议。
- 边界：① 步骤匹配用关键动作词表（模糊匹配，不是逐字）；② 断言阈值不一致按「更严格者生效」建议统一；③ 新预案宽限期（7 天内补脚本）。

**答**：
```javascript
function playbookScriptDrift(playbooks, scripts, { graceDays = 7 } = {}) {
  const issues = [];
  for (const pb of playbooks) {
    const sc = scripts.find(s => s.playbookId === pb.id);
    if (!sc) {
      const age = daysSince(pb.createdAt);
      if (age > graceDays)
        issues.push({ playbook: pb.id, type: 'NO_SCRIPT', fix: '生成演练脚本（演练债务）' });
      continue;                                        // 宽限期内不报
    }
    // 步骤语义匹配（关键动作词表）
    const pbActions = pb.steps.map(extractActionVerb);
    const scActions = sc.steps.map(extractActionVerb);
    const missing = pbActions.filter(a => !scActions.includes(a));
    if (missing.length)
      issues.push({ playbook: pb.id, type: 'STEP_DRIFT', missing,
        fix: `脚本缺少动作: ${missing.join(',')}` });
    // 断言阈值一致性
    for (const [key, pbVal] of Object.entries(pb.successCriteria)) {
      const scVal = sc.asserts?.[key];
      if (scVal && scVal !== pbVal)
        issues.push({ playbook: pb.id, type: 'ASSERT_MISMATCH', key,
          strict: Math.min(pbVal, scVal),              // 更严格者建议统一
          fix: `阈值不一致（预案 ${pbVal} vs 脚本 ${scVal}），建议统一为 ${Math.min(pbVal, scVal)}` });
    }
  }
  return issues;
}
```

**评分点**:
- 双向漂移检测（无脚本债务 + 步骤漂移 + 断言不一致——SCN-OPS-269）。
- 关键动作词表模糊匹配（不要求逐字一致）。
- 断言取更严格者统一（安全侧偏好）。
- 新预案宽限期（避免刚创建就报债务）。
