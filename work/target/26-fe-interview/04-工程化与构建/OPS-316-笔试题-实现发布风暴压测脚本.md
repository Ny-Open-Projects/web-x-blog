## OPS-316：手写发布风暴压测

**需求与边界**：
- 需求：模拟 50 并发发布 + 审批通知风暴 + flag 下发峰值——① 各组件吞吐断言（编排器/审批/flag 下发）；② 应急通道底线验证（满载下回滚 API P95 < 5s——永不排队）；③ 多租户隔离验证（A 团队风暴不影响 B 团队延迟）。
- 边界：① 压测在预发（生产影子）；② 应急通道压测独立于常规压测（资源优先级单独验证）；③ 断言失败输出瓶颈归因（哪个组件先饱和）。

**答**：
```javascript
async function stormTest({ concurrent = 50, teams = 5 } = {}) {
  const results = {};
  // 1. 并发发布吞吐
  results.orchestrator = await measure(() =>
    Promise.all(Array(concurrent).fill(0).map((_, i) =>
      createRelease({ planId: `storm-${i}`, team: `team-${i % teams}` }))),
    { assert: { p95: '< 30s', errorRate: '< 1%' } });
  // 2. 应急通道（独立验证：满载下回滚 P95）
  results.emergency = await measure(async () => {
    await saturate(results.orchestrator);              // 先打满
    return rollbackAPI({ planId: 'storm-0', latencyBudget: 5000 });
  }, { assert: { p95: '< 5s', note: '应急通道永不排队（SCN-OPS-288 底线）' } });
  // 3. 多租户隔离
  results.isolation = await measure(() => {
    stormTeam('team-0');
    return probeTeam('team-1');                        // B 团队延迟不受影响
  }, { assert: { bTeamP95Delta: '< 20%' } });
  // 瓶颈归因
  results.bottleneck = firstSaturated(results);
  return results;
}
```

**评分点**:
- 三段压测（吞吐/应急/隔离）断言齐全。
- 应急通道独立压测（满载下回滚 P95——SCN-OPS-288 底线）。
- 多租户隔离量化（B 团队延迟 delta）。
- 瓶颈归因输出（哪个组件先饱和）。
