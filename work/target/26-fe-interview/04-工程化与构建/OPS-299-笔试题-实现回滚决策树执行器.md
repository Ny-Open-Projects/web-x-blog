## OPS-299：手写回滚决策树

**需求与边界**：
- 需求：异常 → 判定是否发布引入 → 分支：入口/资源类秒级回滚；代码类评估修复 ETA vs 回滚代价（数据写入/灰度进度/用户感知）；代价不可接受 → 升级；每步决策记录。
- 边界：① 「是否发布引入」用版本归属（SCN-OPS-231 样本侧版本）判定；② 修复 ETA 估算输入（问题定位状态/修复复杂度）；③ 决策记录带决策依据（复盘依据）。

**答**：
```javascript
function rollbackDecisionTree(incident, release, { now = Date.now() } = {}) {
  const decisions = [];
  const isOurs = incident.samples.some(s => s.version === release.version);   // 样本侧版本归属
  decisions.push({ q: '发布引入?', a: isOurs, evidence: incident.samples.map(s => s.version) });
  if (!isOurs) return { action: 'NORMAL_INCIDENT_FLOW', decisions };
  if (incident.type === 'entry-or-resource') {
    decisions.push({ q: '类型', a: 'entry/resource → 秒级回滚' });
    return { action: 'ROLLBACK_ENTRY', decisions };
  }
  const fixEta = estimateFixEta(incident);             // { located, complexity } → 分钟
  const cost = assessRollbackCost({
    dataWrites: release.dataWriteVolume,               // 新版本数据写入量
    grayProgress: release.stage,                       // 灰度进度（50% 回滚要重爬）
    userAware: release.userFacingFeature,
  });
  const choice = fixEta < 15 && hasHotfixChannel() ? 'HOTFIX'
    : cost.acceptable ? 'ROLLBACK' : 'ESCALATE';
  decisions.push({ q: '修复 vs 回滚', a: choice,
    basis: { fixEta, cost } });                        // 决策依据
  audit(decisions);
  return { action: choice, decisions };
}
```

**评分点**:
- 版本归属判定（样本侧版本——不是时间窗）。
- 代价评估三因子（数据写入/灰度进度/用户感知——SCN-OPS-234）。
- 决策树每步留痕（evidence + basis）。
- 升级出口（代价不可接受不硬选）。
