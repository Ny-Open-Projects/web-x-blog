## ENG-295：手写发布编排器

**需求与边界**：
- 输入：发布计划（steps: {app, depends}）；按拓扑序执行（depends 满足后才执行下一步）；某步失败暂停后续并保留已完成步骤状态；支持整体回滚（逆序回滚已完成步骤）。
- 边界：① 环检测（循环依赖 fail-fast）；② 并行批次（无依赖关系的步骤同批并发）；③ 每步执行带重试（网络类错误重试 1 次）；④ 回滚逆序执行且失败记录不中断。

**答**：
```javascript
async function orchestrate(plan, { retryOnce = true } = {}) {
  detectCycle(plan.steps);                           // fail-fast
  const done = [], state = {};
  const batches = topologicalBatches(plan.steps);    // 并行批次
  for (const batch of batches) {
    const results = await Promise.allSettled(batch.map(step => runStep(step)));
    const failed = results.filter(r => r.status === 'rejected');
    if (failed.length) {
      // 回滚已完成步骤（逆序）
      for (const s of [...done].reverse()) {
        try { await rollback(s); } catch (e) { state[s.app] = 'ROLLBACK_FAILED'; }   // 记录不中断
      }
      return { status: 'ROLLED_BACK', failedAt: batch.map(s => s.app), state };
    }
    batch.forEach(s => { done.push(s); state[s.app] = 'DONE'; });
  }
  return { status: 'OK', state };
}
function topologicalBatches(steps) {                 // Kahn 分批
  const indeg = new Map(steps.map(s => [s.app, s.depends.length]));
  const out = [];
  let ready = steps.filter(s => indeg.get(s.app) === 0);
  while (ready.length) {
    out.push(ready);
    for (const s of ready)
      for (const t of steps)
        if (t.depends.includes(s.app) && indeg.get(t.app) > 0)
          if (--indeg.get(t.app) === 0) {} // in-place decrement
    ready = steps.filter(s => indeg.get(s.app) === 0 && !out.flat().includes(s));
  }
  return out;
}
```

**评分点**:
- Kahn 分批拓扑（无依赖步骤并行，CI 时间最优）。
- 环检测 fail-fast。
- 失败自动逆序回滚 + 回滚失败不中断（state 记录）。
- SDK 先行由 depends 表达（拓扑序天然保证）。
