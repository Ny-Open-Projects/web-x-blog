## BLD-332：手写增量一致性测试

**需求与边界**：
- 需求：增量构建正确性的随机测试（SCN-BLD-266）——① 随机变更序列生成（改文件/删文件/加文件/改配置）；② 增量构建 vs 全量构建产物 hash 比对（不变式）；③ 失败时输出「最小复现序列」（二分缩短变更序列）；④ 已知破坏点定向用例（动态依赖/插件产物）。
- 边界：① 随机种子固定（可复现的随机——SCN-BLD-254）；② 序列长度与迭代数平衡（20 序列 × 5 步）；③ 全量构建对照的成本（fixture 小项目——秒级）。

**答**：
```javascript
async function incrementalInvariant(bundler, project, { seed = 42, rounds = 20 } = {}) {
  const rnd = mulberry32(seed);                        // 固定种子（可复现）
  const KNOWN_TRAPS = ['dynamic-import-change', 'plugin-output-touch', 'symlink-add'];
  for (let round = 0; round < rounds; round++) {
    const seq = randomChangeSequence(rnd, project, { len: 5, includeTraps: round < 5 });   // 前 5 轮含已知陷阱
    const inc = await bundler.buildIncremental(seq);
    const full = await bundler.buildFull(projectState(project, seq));
    if (hash(inc.artifacts) !== hash(full.artifacts)) {
      // 最小复现：二分缩短变更序列
      const minimal = await minimizeSequence(bundler, project, seq);
      return { failed: true, seed, round, minimal,
        diff: artifactDiff(inc, full) };               // 差异定位（哪类产物不一致）
    }
  }
  return { failed: false, rounds, seed };
}
async function minimizeSequence(bundler, project, seq) {
  let lo = 1, hi = seq.length, minimal = seq;          // 二分最短失败前缀
  while (lo < hi) {
    const mid = (lo + hi) >> 1;
    const inc = await bundler.buildIncremental(seq.slice(0, mid));
    hash(inc.artifacts) !== hash(await bundler.buildFull(projectState(project, seq.slice(0, mid))))
      ? (hi = mid) : (lo = mid + 1);
  }
  return seq.slice(0, lo);
}
```

**评分点**:
- 不变式（增量 ≡ 全量——SCN-BLD-266 核心）。
- 随机序列含已知陷阱（前 5 轮定向——破坏点回归）。
- 固定种子（可复现随机——SCN-BLD-254）。
- 最小复现二分（失败序列缩短——调试可操作性）。
