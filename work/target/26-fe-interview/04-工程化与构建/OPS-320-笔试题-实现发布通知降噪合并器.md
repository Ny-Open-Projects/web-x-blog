## OPS-320：手写通知降噪

**需求与边界**：
- 需求：发布事件按优先级路由——低优先级（灰度放量步进）进合并窗口（日摘要）；中优先级（单步失败已自动恢复）合并窗口短；高优先级（回滚/熔断/审批超时）穿透立即发；合并摘要生成（窗口内事件聚合成一条）。
- 边界：① 穿透事件清空当前窗口（关键事件先发，避免摘要里混入已过时信息）；② 同类事件合并计数（「放量步进 ×5」）；③ 每类事件路由可配置。

**答**：
```javascript
function createNotifyDeduper({ windows = { low: 864e5, mid: 3600_000 } } = {}) {
  const buffer = new Map();                            // key -> { events, flushAt }
  function push(event, route) {
    if (route.priority === 'high') {                   // 高优先级穿透
      flushBuffer(route.channel);                      // 先清窗口（避免过时摘要）
      send(route.channel, event);
      return;
    }
    const key = `${route.channel}:${event.type}`;
    const b = buffer.get(key) ?? { events: [], flushAt: Date.now() + windows[route.priority] };
    b.events.push(event);
    buffer.set(key, b);
  }
  function flushBuffer(channel) {
    for (const [key, b] of buffer)
      if (key.startsWith(channel) && b.events.length) {
        const summary = summarize(b.events);           // 「放量步进 ×5」聚合计数
        send(channel, { type: 'DIGEST', summary, count: b.events.length });
        buffer.delete(key);
      }
  }
  setInterval(() => {
    for (const [key, b] of buffer)
      if (Date.now() >= b.flushAt) flushByKey(key);
  }, 60_000);
}
```

**评分点**:
- 三级优先级（high 穿透/mid 短窗/low 日合并）。
- 穿透前清空窗口（关键事件先行，摘要不混过时信息）。
- 同类聚合计数摘要（「×5」而非 5 条）。
- 窗口可配置 + 定时 flush。
