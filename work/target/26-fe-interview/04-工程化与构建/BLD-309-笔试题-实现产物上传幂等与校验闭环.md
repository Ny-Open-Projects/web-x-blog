## BLD-309：手写产物上传

**需求与边界**：
- 需求：产物上传 CDN 的完整闭环（SCN-BLD-247）——① 幂等上传（hash 命名重复无害）；② 并发限流（数千文件分片上传）；③ 抽验闭环（上传后拉回比对 hash）；④ 缺失清单重传（部分失败补偿）；⑤ HTML 最后切（原子性依赖顺序）。
- 边界：① 并发池（限流不冲垮 CDN——令牌桶）；② 校验失败的重试上限与最终报告；③ 顺序保证不可违反（资源→校验→HTML）。

**答**：
```javascript
async function publish(manifest, cdn, { concurrency = 20, retries = 3 } = {}) {
  const files = manifest.allFiles();                   // immutable 资源
  const pool = tokenBucket(concurrency);               // 令牌桶限流
  const failed = [];
  await Promise.all(files.map(async f => {
    const token = await pool.take();
    try {
      for (let i = 0; i <= retries; i++) {
        const ok = await cdn.put(f.path, f.content).catch(() => false);
        if (ok) break;
        if (i === retries) failed.push(f.path);
      }
    } finally { pool.release(token); }
  }));
  // 抽验闭环
  const roundtrip = await Promise.all(sample(files, 0.01).map(async f => {
    const back = await cdn.get(f.path);
    return sha256(back) === f.hash;                    // 拉回比对
  }));
  if (roundtrip.some(r => !r)) throw new Error('抽验失败——重传');
  if (failed.length) throw new Error(`上传不完整: ${failed.length} 个文件`);
  const missing = await diffManifestCdn(manifest, cdn);   // 全量清单 diff
  if (missing.length) throw new Error(`对象集缺失: ${missing}`);
  await cdn.switchHtml(manifest);                      // HTML 最后切（原子顺序）
  return { uploaded: files.length, verified: true };
}
```

**评分点**:
- 幂等 + 令牌桶限流（并发治理——SCN-BLD-247）。
- 双重校验（抽验 hash + 全量清单 diff）。
- 重试上限 + 最终失败报告。
- HTML 最后切（顺序原子性——发布流量治理）。
