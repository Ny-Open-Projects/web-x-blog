## BLD-330：手写产物安全扫描

**需求与边界**：
- 需求：产物级安全扫描（SCN-BLD-235 安全面）——① secret 扫描（高熵字符串/密钥模式——AKIA/aws secret/私钥头）；② eval/Function/new Function 检测（CSP 兼容 + 注入面）；③ 危险 API（document.write/innerHTML 大段注入）审计；④ 外部 URL 清单（外链审计——数据外发面）。
- 边界：① 高熵检测降噪（base64 图片/压缩数据误报——白名单 + 长度阈值）；② 定位回源（产物位置 → 源模块——SCN-BLD-277 归因）；③ 扫描进 CI（阻断级/警告级分级）。

**答**：
```javascript
const SECRET_PATTERNS = [
  { name: 'aws-key', re: /AKIA[0-9A-Z]{16}/ },
  { name: 'private-key', re: /-----BEGIN (RSA |EC )?PRIVATE KEY-----/ },
  { name: 'generic-high-entropy', re: /[A-Za-z0-9+/=]{40,}/, entropy: 4.5 },   // 熵阈值
];
function securityScan(bundle, { whitelist = [] } = {}) {
  const issues = [];
  for (const chunk of bundle.chunks) {
    // 1. secret
    for (const p of SECRET_PATTERNS) {
      for (const m of chunk.code.matchAll(p.re)) {
        if (p.entropy && entropy(m[0]) < p.entropy) continue;   // 低熵降噪（base64 图片）
        if (whitelist.some(w => chunk.code.includes(w))) continue;
        issues.push({ type: 'SECRET', name: p.name, chunk: chunk.name,
          level: 'block', source: attribution(chunk, m.index) });   // 回源归因
      }
    }
    // 2. eval 危险调用
    for (const call of extractCalls(chunk.code, ['eval', 'Function', 'document.write'])) {
      issues.push({ type: 'DANGEROUS_API', api: call.api, chunk: chunk.name,
        level: call.api === 'eval' ? 'block' : 'warn',   // eval 阻断（CSP 兼容）
        source: attribution(chunk, call.index) });
    }
    // 3. 外部 URL
    const urls = [...chunk.code.matchAll(/https?:\/\/(?!localhost)[\w.-]+/g)]
      .map(m => m[0]);
    issues.push({ type: 'EXTERNAL_URLS', chunk: chunk.name, urls: [...new Set(urls)],
      level: 'info' });                                // 外链审计（数据外发面）
  }
  return { blocked: issues.some(i => i.level === 'block'), issues };
}
```

**评分点**:
- 四类扫描（secret/eval/危险 API/外部 URL）分级（block/warn/info）。
- 熵阈值降噪（base64 图片误报防御）+ 白名单。
- 归因回源（产物位置 → 源模块——SCN-BLD-277）。
- CI 阻断语义（eval 阻断——CSP 兼容，SCN-BLD-246）。
