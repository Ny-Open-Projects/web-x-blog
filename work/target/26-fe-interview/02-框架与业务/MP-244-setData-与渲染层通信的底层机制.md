## MP-244：setData 底层通信机制？
**答**：
- 通信：逻辑层 setData(data) → 序列化（JSON 结构）→ Native 层跨线程传递 → 渲染层反序列化 → 与旧数据 diff → VDOM 更新渲染。
- 限制：单次 ≤ 1MB（超限丢数据）、必须可序列化（不能传函数/循环引用）、异步无渲染完成回调（近似用 wx.nextTick）。
- 性能本质：通信成本 = 数据体积 + 消息次数——两个维度都要优化。
- 渲染层 diff：WXML 数据绑定 diff 在渲染层内完成（无跨线程），所以「传全量对象」的真实代价在传输与序列化。
- 对比 Taro：Taro 在逻辑层先 diff，传增量路径——省传输，多一层 JS diff 成本。
