## MP-308：小程序页面栈管理：层级限制与导航策略

**答**：
- 页面栈限制：最多 10 层——超限 navigateTo 失败；深层流程（多步表单）要用 redirectTo（替换当前）或 wx.navigateBack 到指定 delta
- 导航 API 语义：navigateTo（压栈）/redirectTo（替换栈顶）/switchTab（清栈到 tab）/reLaunch（清全部）——「回退语义」决定选择；深链回跳用 navigateBack({ delta })
- 页面间通信：URL 参数（简单值）、事件通道（EventChannel——navigateTo 的 events 双向通信）、全局 store——「上一页返回刷新」用 eventChannel 或页面 onShow + 标记
- 栈溢出设计：向导类流程「一层完成 redirectTo 下一层」保持栈深恒定；列表→详情→详情的「无限层级」用 redirectTo 替换列表
- 深水点：getCurrentPages 的栈观测——运行时监控栈深度（接近 10 层告警 + 自动 redirectTo 策略）

```javascript
// 事件通道: 页面间双向通信
wx.navigateTo({
  url: '/pages/select/index',
  events: {                                        // 监听目标页事件
    selected: (data) => this.setData({ selected: data }),
  },
  success: (res) => {
    res.eventChannel.emit('init', { from: this.data.id });  // 传给目标页
  },
});
// 目标页: const ec = this.getOpenerEventChannel(); ec.emit('selected', item);
// 栈监控: if (getCurrentPages().length >= 9) wx.redirectTo(...) else wx.navigateTo(...)
```
