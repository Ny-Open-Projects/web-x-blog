## MP-285：笔试：手写图片预加载管理器
**题**：实现 ImgManager：preDownload(urls) 并发预下载到本地文件系统（wx.downloadFile + saveFile）；getLocal(url) 返回本地路径（命中缓存）或原 URL；LRU 上限 100 个文件自动清理；下载失败保留 URL 降级在线加载。

```javascript
class ImgManager {
  constructor(limit = 100) { this.limit = limit; this.map = new Map() } // url -> { local, t }
  async preDownload(urls, concurrency = 3) {
    const queue = urls.filter(u => !this.map.has(u))
    await Promise.all(Array.from({ length: concurrency }, async () => {
      while (queue.length) {
        const url = queue.shift()
        try {
          const { tempFilePath } = await wx.downloadFile({ url })
          const { savedFilePath } = await wx.saveFile({ tempFilePath })
          this.map.set(url, { local: savedFilePath, t: Date.now() })
          this._evict()
        } catch { /* 失败降级在线加载，不写缓存 */ }
      }
    }))
  }
  getLocal(url) { return this.map.get(url)?.local || url }
  async _evict() {
    while (this.map.size > this.limit) {
      const oldest = [...this.map.entries()].sort((a, b) => a[1].t - b[1].t)[0]
      wx.removeSavedFile({ filePath: oldest[1].local }) // 删本地文件
      this.map.delete(oldest[0])
    }
  }
}
```
**评分点**：
- downloadFile + saveFile 持久化（tempFilePath 重启失效，必须 saveFile）。
- LRU 清理含本地文件删除（不然文件系统泄漏）。
- 失败降级不写缓存。
