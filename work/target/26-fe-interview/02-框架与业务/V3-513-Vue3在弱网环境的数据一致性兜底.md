## V3-513：Vue3 在弱网环境的数据一致性兜底

**答**：
- 弱网下的状态机：每个数据域明确「fresh/stale/loading/error」四态——UI 按 stale-while-revalidate 展示（旧数据立即显示 + 静默刷新）
- 本地优先（local-first）读：IndexedDB 缓存上次成功数据 → 进入页面先渲染缓存 → 网络回来对比更新——弱网「秒开」的基础
- 写操作兜底：离线队列（H5-365）+ 乐观更新——弱网下提交「立即反馈 + 排队同步」
- 一致性校验：更新带版本号/更新时间戳，冲突时提示（不静默覆盖）——弱网重放的多写冲突兜底
- 降级 UI 约定：stale 数据带「最后更新时间」标记 + 手动刷新入口；offline 横幅全局——「数据可能旧」必须让用户知道

```javascript
const store = reactive({ data: null, staleAt: 0, state: 'idle' });
async function load() {
  const cached = await idb.get('list');       // 1. 本地优先
  if (cached) { store.data = cached; store.staleAt = cached.ts; store.state = 'stale'; }
  try {
    const fresh = await api.list();            // 2. 静默刷新
    store.data = fresh; store.staleAt = Date.now(); store.state = 'fresh';
    await idb.set('list', fresh);
  } catch { store.state = cached ? 'stale' : 'error'; }  // 3. 失败保持缓存态
}
```
