## V3-289：日期范围选择器的设计要点有哪些？
**答**：
- 状态机：idle → pickingStart → pickingEnd（hover 预览区间）；二次点击在已选区间内=缩区间，之外=重新开始；这是范围选择器的核心交互状态机。
- 双月历联动：左面板主导，右面板 = 左面板 + 1 个月；hover 时右端随指针预览，两端 min/max 约束用 Math.min/max。
- 禁用逻辑：minDate/maxDate/disabledDate 过滤生成矩阵时统一处理，边界（跨月首尾补位）也要禁用。
- 数据规范化：输出标准化 ISO 字符串或时区安全的 Date；注意用户本地时区与业务时区（酒店"入住日"按酒店时区）。
- 快捷项：近 7 天/本月/自定义由 preset 数组驱动；快捷项与手选互斥状态要同步高亮。

```typescript
const phase = ref('idle');
const [start, end] = [ref(null), ref(null)];
const hoverEnd = ref(null);
function onPick(date) {
  if (phase.value === 'idle' || (start.value && end.value && date < start.value) || date <= start.value) {
    start.value = date; end.value = null; phase.value = 'picking';      // 重新开始/选起点
  } else if (phase.value === 'picking') {
    end.value = date; phase.value = 'idle';
    emit('update:modelValue', [start.value, end.value]);
  }
}
const previewRange = computed(() => phase.value === 'picking' && hoverEnd.value
  ? [start.value, hoverEnd.value < start.value ? start.value : hoverEnd.value] : null);
// 预览用 previewRange 高亮，提交后用 [start,end]
```
