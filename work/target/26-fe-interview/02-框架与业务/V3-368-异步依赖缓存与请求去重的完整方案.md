## V3-368：Suspense 场景下异步依赖的缓存与请求去重怎么设计？
**答**：
- 问题：路由切换 A→B→A 会在 setup 再次 await，重复请求相同数据。
- 方案：数据层缓存 `Map<key, Promise|Data>`——promise 缓存保证并发去重，结果缓存保证回访命中；带 TTL 或版本 key 支持失效。
- Suspense 适配：setup 里 `await store.ensure(key, loader)`，命中缓存时 resolve 立即完成，Suspense 不再展示 fallback。
- 失效策略：列表页预取 + 详情页消费（同一 key）；编辑保存后 invalidate 对应 key；登出/切换账号清空。
- 与 Nuxt useAsyncData / VueUse useAsyncState 的关系：自研方案是它们的核心机制简化版，能讲清 key 设计与失效就够了。
```javascript
const cache = new Map()
function ensure(key, loader, ttl = 60_000) {
  const hit = cache.get(key)
  if (hit && Date.now() - hit.t < ttl) return hit.p
  const p = loader().finally(() => setTimeout(() => cache.delete(key), 0))
  cache.set(key, { p, t: Date.now() })
  return p
}
```
