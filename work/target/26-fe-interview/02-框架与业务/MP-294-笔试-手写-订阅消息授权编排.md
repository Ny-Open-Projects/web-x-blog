## MP-294：笔试：手写订阅消息授权编排
**题**：实现 askSubscribe(tmplIds)：先弹自定义说明弹窗（价值前置）用户同意后才调 wx.requestSubscribeMessage（真实授权弹窗）；返回 { granted, rejected }；拒绝后 7 天内不再打扰（storage 记录）；一次订阅 vs 长期订阅的语义说明。

```javascript
async function askSubscribe(tmplIds, { remindKey = 'subRemind' } = {}) {
  const lastReject = wx.getStorageSync(remindKey)
  if (lastReject && Date.now() - lastReject < 7 * 86400000) return { granted: false, rejected: true, silent: true }
  const { confirm } = await wx.showModal({
    title: '开启通知',
    content: '订阅后可在支付成功、发货时第一时间收到提醒'
  })
  if (!confirm) { wx.setStorageSync(remindKey, Date.now()); return { granted: false, rejected: true } }
  const res = await wx.requestSubscribeMessage({ tmplIds })
  const granted = tmplIds.filter(id => res[id] === 'accept')
  if (!granted.length) wx.setStorageSync(remindKey, Date.now())
  return { granted, rejected: granted.length === 0 }
}
```
**评分点**：
- 价值前置弹窗（转化率关键——直接弹原生框拒绝率高）。
- 拒绝冷却期（7 天）storage 记录。
- granted/rejected 结构化返回。
- 说明一次性订阅语义（每次触发需重新请求）与长期订阅的资质限制。
