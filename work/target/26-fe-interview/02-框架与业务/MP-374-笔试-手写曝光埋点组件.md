## MP-374：笔试：手写曝光埋点

**答**：实现曝光埋点组件：① IO observer 相对视口（intersectionRatio ≥0.5 触发）；② 停留 ≥800ms 才计有效曝光（快速划过取消——定时器 + 离开清除）；③ 会话内去重（同 slotId 只计一次——Set）；④ 页面卸载清理 observer；⑤ 批量上报（满 10 条或 onHide flush）。写出实现。

```javascript
Component({
  properties: { slotId: String, scene: String },
  lifetimes: {
    attached() { this._reported = new Set(); this._timers = new Map(); this._buf = []; },
    detached() { this._io?.disconnect(); this._timers.forEach(clearTimeout); flushTrack(); },
  },
  methods: {
    observe(el) {
      this._io = this.createIntersectionObserver({ observeAll: true })
        .relativeToViewport({ bottom: 0 });
      this._io.observe('.exp-slot', (res) => {
        const slot = res.dataset.slotId;
        if (res.intersectionRatio < 0.5) { clearTimeout(this._timers.get(slot)); this._timers.delete(slot); return; }  // 离开取消
        if (this._reported.has(slot)) return;          // 会话去重
        if (this._timers.has(slot)) return;
        this._timers.set(slot, setTimeout(() => {
          this._timers.delete(slot);
          this._reported.add(slot);
          this._buf.push({ slot, scene: this.data.scene, t: Date.now() });
          if (this._buf.length >= 10) flushTrack();
        }, 800));                                       // 停留 800ms 才有效
      });
    },
  },
});
// flushTrack: 队列满/onHide/pagehide 时 sendBeacon 等价(wx.request 批量)
// App onHide → flushTrack() 兜底
```

**评分点**：
- 可见比例 + 停留双条件（离开取消定时器）
- 会话去重（slotId Set）
- observeAll 批量观察与卸载清理
- 批量上报与 onHide flush 兜底
