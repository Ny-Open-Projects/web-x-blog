## MP-282：笔试：手写红包雨抽奖逻辑
**题**：红包雨 30s：服务端按时间片下发红包列表 [{id, x, delay, amount?}]；点击领取（幂等：本地已领 Set + 服务端 requestId）；活动结束汇总展示；防刷（点击间隔限速）。

```javascript
Page({
  data: { rain: [], ended: false, total: 0 },
  grabbed: new Set(), // 已领取红包 id（幂等）
  _lastClick: 0,
  onGrab(e) {
    const now = Date.now()
    if (now - this._lastClick < 200) return   // 防连点刷接口
    this._lastClick = now
    const { id } = e.currentTarget.dataset
    if (this.grabbed.has(id)) return           // 本地幂等
    this.grabbed.add(id)
    const requestId = `${this.activityId}:${id}`
    api.grab({ redPacketId: id, requestId })   // 服务端幂等去重
      .then(res => this.setData({ total: this.data.total + res.amount, [`rain[${e.currentTarget.dataset.index}].status`]: 'got' }))
      .catch(() => this.grabbed.delete(id))    // 失败允许重试
  },
  onEnd() {
    this.setData({ ended: true })
    api.grabSummary({ activityId: this.activityId }) // 服务端权威汇总
  }
})
```
**评分点**：
- 本地 Set 幂等 + 服务端 requestId 双层防重。
- 点击限速（200ms）。
- 汇总以服务端为准。
- 动画（红包下落）建议用 CSS 动画/Skyline worklet 而非 setData 驱动（说明即可加分）。
