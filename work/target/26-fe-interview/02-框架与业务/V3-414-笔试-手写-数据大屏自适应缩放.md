## V3-414：笔试：手写数据大屏的自适应缩放（1920×1080 基准）
**题**：设计画布 1920×1080，实现在任意分辨率下：等比缩放居中（transform: scale）；窗口比例不同时留白；提供 resetScale；监听 resize 用 rAF 节流；字号/图表容器均基于设计稿坐标无需改写。

```javascript
function useScreenScale(designW = 1920, designH = 1080) {
  const scale = ref(1)
  const el = ref(null)
  function resize() {
    const { innerWidth: w, innerHeight: h } = window
    scale.value = Math.min(w / designW, h / designH) // 等比，取小
    if (el.value) {
      el.value.style.transform = `scale(${scale.value})`
      el.value.style.transformOrigin = 'top left'
      el.value.style.left = `${(w - designW * scale.value) / 2}px` // 居中留白
      el.value.style.top = `${(h - designH * scale.value) / 2}px`
    }
  }
  let raf = 0
  const onResize = () => { cancelAnimationFrame(raf); raf = requestAnimationFrame(resize) }
  onMounted(() => { resize(); window.addEventListener('resize', onResize) })
  onBeforeUnmount(() => window.removeEventListener('resize', onResize))
  return { scale, el, onResize }
}
```
**评分点**：
- scale 取宽高比最小值（保证完整显示）+ 居中偏移计算。
- resize 用 rAF 节流 + 卸载移除监听。
- 说明缩放导致文字模糊时可改用 zoom 或按 dpr 优化（加分）。
- 图表库需要 resize 时调用 chart.resize()（配套说明）。
