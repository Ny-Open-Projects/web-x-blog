## MP-281：笔试：手写统一请求层
**答**：实现 request(options)：自动加 timestamp/nonce/sign（HMD5 排序参数签名）；GET 幂等失败重试 2 次（500ms/1s）；401 走 AuthManager 静默续期；业务错误（code≠0）统一 reject 带错误码；上报失败日志。

```javascript
function sign(params, secret) {
  const keys = Object.keys(params).sort()
  const str = keys.map(k => `${k}=${params[k]}`).join('&') + `&secret=${secret}`
  return md5(str)
}
function request(options, { retries = options.method === 'GET' ? 2 : 0 } = {}) {
  const ts = Date.now(), nonce = Math.random().toString(36).slice(2)
  const signParams = { ...options.data, timestamp: ts, nonce }
  const header = { ...options.header, 'X-Timestamp': ts, 'X-Nonce': nonce, 'X-Sign': sign(signParams, SECRET), token: wx.getStorageSync('token') }
  return new Promise((resolve, reject) => {
    const attempt = (left) => {
      wx.request({
        ...options, header,
        success(res) {
          if (res.statusCode === 401) return auth.relogin().then(() => attempt(0))
          if (res.data.code !== 0) return reject({ code: res.data.code, msg: res.data.msg })
          resolve(res.data.data)
        },
        fail() {
          if (left > 0) return setTimeout(() => attempt(left - 1), 500 * (retries - left + 1))
          report({ type: 'net_fail', url: options.url })
          reject({ code: 'NETWORK', msg: '网络异常' })
        }
      })
    }
    attempt(retries)
  })
}
```
**评分点**：
- 签名按 key 排序拼接（防篡改 + 防重放 nonce/timestamp）。
- 重试只对幂等 GET + 退避。
- 401 → 静默续期链路接入。
- 失败上报与统一错误码。
