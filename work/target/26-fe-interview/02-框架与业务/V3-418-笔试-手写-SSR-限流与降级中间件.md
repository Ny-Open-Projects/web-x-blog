## V3-418：笔试：手写 SSR 服务限流与降级中间件
**答**：实现 Nitro 中间件：令牌桶限流（rate/interval 按路由组）；超过阈值返回降级静态骨架（复用同一 URL 的静态版本）而不是 503；熔断：连续 N 次渲染超时则该路由 5 分钟内直接走降级；记录降级率。

```javascript
const buckets = new Map()
const breaker = new Map()
export default defineEventHandler(async (event) => {
  const path = event.path.split('?')[0]
  const now = Date.now()
  // 令牌桶
  const b = buckets.get(path) ||= { tokens: 100, last: now }
  b.tokens = Math.min(100, b.tokens + (now - b.last) / 100) // 每秒回 1
  b.last = now
  // 熔断窗口
  const br = breaker.get(path) || { fails: 0, until: 0 }
  breaker.set(path, br)
  if (now < br.until) return sendDegrade(event, path)
  if (b.tokens < 1) { br.fails++; if (br.fails >= 5) br.until = now + 5 * 60_000; metrics.degrade(path); return sendDegrade(event, path) }
  b.tokens--
  try {
    const start = Date.now()
    await next() // 正常 SSR
    if (Date.now() - start > 3000) { br.fails++; if (br.fails >= 5) br.until = now + 5 * 60_000 }
    else br.fails = 0
  } catch (e) {
    br.fails++; if (br.fails >= 5) br.until = now + 5 * 60_000
    metrics.degrade(path)
    return sendDegrade(event, path)
  }
})
function sendDegrade(event, path) {
  setHeader(event, 'Content-Type', 'text/html')
  setHeader(event, 'X-Degrade', '1')
  return renderStaticShell(path) // 预生成骨架
}
```
**评分点**：
- 令牌桶实现（按时间回填）。
- 降级返回静态骨架而非 503（体验优先）。
- 熔断计数 + 恢复窗口 + 成功重置。
- 降级标记 header 便于观测。
