## V3-425：笔试：手写「防抖搜索 + 请求竞态 + 缓存」组合搜索框
**题**：实现 `useSearch(fetcher)`：输入防抖 300ms；相同 keyword 命中本地缓存（Map，上限 50 LRU）；竞态防护（只保留最后一次响应）；空输入清空结果不请求；返回 { keyword, results, loading }。

```javascript
function useSearch(fetcher, { delay = 300 } = {}) {
  const keyword = ref('')
  const results = ref([])
  const loading = ref(false)
  const cache = new Map() // LRU：Map 有序，最新放最后
  let seq = 0
  watch(keyword, (kw) => {
    const id = ++seq
    kw = kw.trim()
    if (!kw) { results.value = []; loading.value = false; return }
    if (cache.has(kw)) {
      const hit = cache.get(kw)
      cache.delete(kw); cache.set(kw, hit) // 刷新 LRU
      if (id === seq) results.value = hit
      return
    }
    loading.value = true
    useDebounceFn(async () => {
      try {
        const res = await fetcher(kw)
        if (id !== seq) return // 过期响应
        results.value = res
        cache.set(kw, res)
        if (cache.size > 50) cache.delete(cache.keys().next().value)
      } finally { if (id === seq) loading.value = false }
    }, delay)()
  })
  return { keyword, results, loading }
}
```
**评分点**：
- 三层组合齐备：防抖、LRU 缓存、seq 竞态。
- LRU 刷新与容量淘汰正确。
- 空输入短路（不请求、清结果）。
- 防抖内仍校验 seq（防抖窗口内新输入覆盖）。
