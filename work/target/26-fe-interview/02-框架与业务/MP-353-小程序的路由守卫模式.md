## MP-353：小程序的路由守卫模式：登录态与权限拦截

**答**：
- 无守卫 API 的现实：小程序路由无 beforeEach——守卫靠「封装导航函数」（routeTo 替代 wx.navigateTo 统一拦截）+ 页面 Behavior 双层
- 导航封装守卫：routeTo(options) 先检查登录态 → 未登录重定向登录页 + 携带回跳参数 → 登录完成 navigateBack 回目标
- 页面级守卫：Behavior 的 onLoad 检查（页面已打开才发现未登录）——「直达链接」（扫码/分享）绕过导航封装 → Behavior 兜底必须存在
- 回跳设计：登录页接收 redirect 参数 → 登录成功 redirectTo 目标（栈语义：navigateTo 登录则 navigateBack + 通知刷新）
- 深水点：tab 页的守卫差异——switchTab 无法带参数——「登录后回 tab 页」要 reLaunch 或 store 中转

```javascript
// 导航封装守卫
export function routeTo(url, opts = {}) {
  const needAuth = routeMap[url]?.auth;
  if (needAuth && !getApp().store.token) {
    wx.navigateTo({ url: `/pages/login/index?redirect=${encodeURIComponent(url)}` });
    return;
  }
  wx.navigateTo({ url, ...opts });
}
// 登录页回跳
async onLogin() {
  const { redirect } = this.options;
  await doLogin();
  redirect ? wx.redirectTo({ url: decodeURIComponent(redirect) }) : wx.navigateBack();
}
// Behavior 兜底(直达链接): onLoad 检查 → redirect 登录页
```
