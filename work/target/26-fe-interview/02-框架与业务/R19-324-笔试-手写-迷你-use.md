## R19-324：笔试：手写迷你 use(Promise)
**答**：实现 `useMy(promise)`：promise pending 时 throw promise（Suspense 捕获）；resolved 返回值；rejected 抛出错误给 ErrorBoundary；同一 promise 二次调用直接命中缓存不 throw。

```javascript
function useMy(promise) {
  if (promise.__status === 'fulfilled') return promise.__value
  if (promise.__status === 'rejected') throw promise.__reason
  // pending：挂回调更新状态，然后 throw 让 Suspense 等待
  if (!promise.__wrapped) {
    promise.__wrapped = true
    promise.then(
      v => { promise.__status = 'fulfilled'; promise.__value = v },
      e => { promise.__status = 'rejected'; promise.__reason = e }
    )
  }
  throw promise // React/Suspense 捕获后，resolve 时重渲染本组件
}
```
**评分点**：
- 三态标记在 promise 对象上（缓存命中不重复 throw）。
- pending 时 throw promise 本身（Suspense 协议）。
- rejected 抛 reason（错误边界捕获）。
- 状态写入在 then 回调中完成，resolve 后触发重渲染由 React 负责。
