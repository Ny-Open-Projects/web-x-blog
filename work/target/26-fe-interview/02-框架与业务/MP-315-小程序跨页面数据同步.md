## MP-315：小程序跨页面数据同步：全局状态与事件通道

**答**：
- 跨页面同步三通道：全局 store（ getApp().globalData + 订阅封装）、事件总线（mitt 类）、页面栈直接操作（getCurrentPages 拿上一页实例 setData——耦合但直接）
- globalData 的响应式缺失：原生 globalData 是普通对象——改了别的页面不刷新；封装「getApp().store.subscribe」或在 onShow 里同步（页面显示时拉最新）
- 返回列表刷新的标准模式：详情页改数据 → 全局 store 更新 → 列表页 onShow 从 store 同步（或在 store 层 diff 提示）——「onShow 同步」简单可靠，是小程序的主流模式
- EventChannel 的页面级通信：navigateTo events——一次性流程（选择器）合适；常驻状态同步不适合
- 深水点：getCurrentPages 直接改上一页的边界——栈结构依赖（返回目标可能不是预期页面——redirectTo 后栈顶变了）；防御「按 route 匹配目标页」

```javascript
// store + onShow 同步模式
// store.js: globalData.cart = { items: [], sub(fn) {...} }
// 列表页
onShow() {
  const cart = getApp().store.cart;
  this.setData({ count: cart.items.length, list: cart.items });
}
// 详情页改数据
onBuy() {
  getApp().store.cart.items.push(item);   // 全局更新
  const list = getCurrentPages().find((p) => p.route === 'pages/cart/index');
  list?.setData({ list: getApp().store.cart.items });   // 防御: 按 route 找
}
```
