## MP-377：笔试：手写分包预下载策略器

**答**：实现动态分包预下载：① 用户路径模型：从埋点统计「页面 → 分包需求」转移表 { page: { pkg: probability } }；② 进入页面时：查转移表 → 概率 × 分包大小排序 → 预算内（总预下载 <2MB）选择 Top1 下载；③ 下载去重（已下载分包记录——wx.getAvailableSubpackages? 不存在则本地 Set）；④ 网络条件（wifi 全下、蜂窝只下高概率 ≥0.5）；⑤ 失效防护（下载失败不重试进入页——下次再说）。写出实现。

```javascript
const TRANSITION = {
  'pages/index': [{ pkg: 'order', p: 0.42, size: 500_000 }, { pkg: 'profile', p: 0.2, size: 300_000 }],
  'pages/order/list': [{ pkg: 'order-detail', p: 0.78, size: 400_000 }],
};
const downloaded = new Set();
const BUDGET = 2 * 1024 * 1024;
let usedBudget = 0;

export function preDownload(currentPage) {
  const candidates = (TRANSITION[currentPage] ?? [])
    .filter((c) => !downloaded.has(c.pkg))
    .filter((c) => isWifi() || c.p >= 0.5)             // 蜂窝只下高概率
    .sort((a, b) => b.p / b.size - a.p / a.size);       // 性价比: 概率/大小
  const picked = candidates.find((c) => usedBudget + c.size <= BUDGET);
  if (!picked) return;
  downloaded.add(picked);                               // 先标记防重复触发
  wx.preDownloadSubpackage
    ? wx.preDownloadSubpackage({ packageType: picked.pkg,
        success: () => { usedBudget += picked.size; },
        fail: () => { downloaded.delete(picked); } })   // 失败: 下次重试
    : fallbackStaticRule();                              // 低版本: preloadRule 静态配置兜底
}
function isWifi() { return wx.getNetworkType ? false : false; } // 实际: wx.getNetworkType 回调判断 wifi
// 埋点: 分包页 onLoad 上报「分包等待时间」→ 转移表按周更新
```

**评分点**：
- 数据驱动转移表（埋点统计）与性价比排序（概率/大小）
- 预算控制（2MB 上限）与已下载去重
- 网络分级（蜂窝只下高概率）
- 失败回退与低版本静态规则兜底
