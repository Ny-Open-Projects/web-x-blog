## R19-335：笔试：手写路由预取管理器
**答**：实现 PrefetchManager：hover 预取（幂等）；idle 批量预取（requestIdleCallback 分时）；预取带 TTL（5 分钟过期后可重取）；cancelAll 清理。

```javascript
class PrefetchManager {
  constructor(loaders, ttl = 5 * 60_000) {
    this.loaders = loaders
    this.ttl = ttl
    this.cache = new Map() // name -> { t, p }
    this.raf = null
  }
  prefetch(name) {
    const hit = this.cache.get(name)
    if (hit && Date.now() - hit.t < this.ttl) return hit.p
    const p = this.loaders[name]().catch(() => { this.cache.delete(name) })
    this.cache.set(name, { t: Date.now(), p })
    return p
  }
  idlePrefetch(names) {
    const run = (deadline) => {
      for (const name of names) {
        if (deadline.timeRemaining() <= 0) {
          this.raf = requestIdleCallback(run)
          return
        }
        this.prefetch(name)
      }
    }
    'requestIdleCallback' in window ? requestIdleCallback(run) : names.forEach(n => this.prefetch(n))
  }
  cancelAll() {
    cancelIdleCallback?.(this.raf)
    this.cache.clear()
  }
}
```
**评分点**：
- TTL 判断 + 失败清除可重取。
- idle 分时（timeRemaining 检查 + 续跑）。
- cancelAll 清理。
- 幂等（命中即返回）。
