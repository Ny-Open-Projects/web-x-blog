## R19-339：笔试：手写并发安全的搜索页
**答**：要求：输入框即时回显；列表按 deferred 值过滤；若列表来自服务端请求，加竞态防护与「计算中」提示；快速连续输入不卡顿。

```javascript
function SearchPage() {
  const [query, setQuery] = useState('')
  const [results, setResults] = useState([])
  const [deferred, isStale] = useMyDeferredValue(query)
  useEffect(() => {
    const ctrl = new AbortController()
    if (!deferred.trim()) { setResults([]); return }
    fetch(`/api/search?q=${encodeURIComponent(deferred)}`, { signal: ctrl.signal })
      .then(r => r.json())
      .then(d => { if (!ctrl.signal.aborted) setResults(d) })
      .catch(e => { if (e.name !== 'AbortError') setResults([]) })
    return () => ctrl.abort() // defer 值变化取消旧请求
  }, [deferred])
  return (
    <div>
      <input value={query} onChange={e => setQuery(e.target.value)} /> {/* Sync：打字流畅 */}
      <ul style={{ opacity: isStale ? 0.6 : 1 }}>
        {results.map(r => <li key={r.id}>{r.title}</li>)}
      </ul>
    </div>
  )
}
```
**评分点**：
- 输入与列表的优先级分离（query vs deferred）。
- deferred 变化时 abort 旧请求（竞态防护在 deferred 层做）。
- isStale 弱化样式提示。
- 能说明「为什么竞态防护绑在 deferred 而不是 query」（query 每键触发会取消过多）。
