## V3-283：树组件跨层级拖拽的实现细节是什么？
**答**：
- 拖入语义三态：根据指针相对目标节点的位置（上 1/4：前插入、中 1/2：成为子节点、下 1/4：后插入），pointermove 中按三区判定 drop type。
- 合法性校验：不能拖入**自己的子孙**（会造成环），拖动开始时收集子树 id 集合；不能拖到"折叠祖先的子孙"之外的不一致位置。
- 数据迁移：从原父 children splice 移除 + 目标位置插入（或 push 为子节点）；乐观更新 + 提交后端，失败回滚（保留操作前快照）。
- 视觉反馈：合法目标高亮边框（三态用不同线条：上线/环绕/下线），非法目标红框禁止；拖动时折叠被拖子树。
- 懒加载树注意：目标节点未加载子级时，"插入为子节点"需先请求子级再插入或延迟到展开时落位。

```typescript
function dropType(e, rect) {
  const y = (e.clientY - rect.top) / rect.height;
  return y < 0.25 ? 'before' : y > 0.75 ? 'after' : 'inside';
}
function isDescendant(nodeId, targetId, treeMap) {
  let cur = treeMap.get(targetId);
  while (cur) { if (cur.id === nodeId) return true; cur = treeMap.get(cur.parentId); }
  return false;
}
function moveNode(dragId, targetId, type) {
  if (isDescendant(dragId, targetId, treeMap)) return toast('不能移动到自己的子级');
  snapshot();                                            // 快照用于回滚
  removeFromParent(dragId);
  if (type === 'inside') treeMap.get(targetId).children.push(dragId);
  else insertSibling(dragId, targetId, type);
  api.moveNode({ id: dragId, parentId: type === 'inside' ? targetId : treeMap.get(targetId).parentId,
    index: indexOf(dragId) }).catch(rollback);
}
```
