## FRP-389：笔试：手写时间旅行

**答**：实现 store 的时间旅行：① 每次 set 自动快照（环形上限 50）；② jumpTo(n)：跳到第 n 个快照（未来快照保留——redo 栈语义）；③ diff(n, m)：两个快照的字段级差异（哪些字段变了）；④ 时间旅行期间的写：分叉（丢弃未来快照，从当前分叉）——git 语义；⑤ travel 模式通知（订阅者收到历史值——「视图回到过去」）。写出实现。

```javascript
export function withTimeTravel(store, { capacity = 50 } = {}) {
  const snapshots = [{ ...store.get(), __t: Date.now() }];
  let pointer = 0;
  let traveling = false;

  const origSet = store.set;
  store.set = (v, meta) => {
    if (traveling) {                                  // 分叉: 丢弃未来
      snapshots.length = pointer + 1;
      traveling = false;
    }
    origSet.call(store, v, meta);
    snapshots.push({ ...store.get(), __t: Date.now() });
    if (snapshots.length > capacity) snapshots.shift();
    pointer = snapshots.length - 1;
  };
  return {
    jumpTo(n) {
      const idx = Math.max(0, Math.min(snapshots.length - 1, n));
      traveling = idx < snapshots.length - 1;
      pointer = idx;
      origSet.call(store, { ...snapshots[idx] });     // 通知订阅者(视图回溯)
    },
    undo: () => store.jumpTo(pointer - 1),
    redo: () => store.jumpTo(pointer + 1),
    diff: (n, m) => {
      const a = snapshots[n], b = snapshots[m];
      const out = {};
      for (const k of new Set([...Object.keys(a), ...Object.keys(b)]))
        if (!Object.is(a[k], b[k])) out[k] = { from: a[k], to: b[k] };
      return out;
    },
    get position() { return pointer; }, get length() { return snapshots.length; },
  };
}
// 用法: undo/redo + 「两框架视图同步回溯」(订阅通知天然驱动)
```

**评分点**：
- 环形快照 + 指针模型（undo/redo）
- travel 中写入的分叉语义（丢弃未来）
- diff 的字段级输出（调试价值）
- 订阅通知驱动双框架视图同步回溯
