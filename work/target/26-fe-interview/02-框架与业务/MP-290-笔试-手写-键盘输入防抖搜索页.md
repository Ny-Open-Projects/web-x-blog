## MP-290：笔试：手写搜索页
**答**：input 实时搜索：300ms 防抖；seq 竞态防护（快速输入丢弃旧响应）；空值短路清结果；搜索历史（最近 10 条 storage）；iOS 键盘遮挡处理（adjust-position + 底部 padding）。

```javascript
Page({
  data: { keyword: '', results: [], history: wx.getStorageSync('searchHistory') || [] },
  _seq: 0, _timer: null,
  onInput(e) {
    const kw = e.detail.value
    this.setData({ keyword: kw })
    clearTimeout(this._timer)
    this._timer = setTimeout(() => this.search(kw), 300)
  },
  async search(kw) {
    kw = kw.trim()
    const seq = ++this._seq
    if (!kw) return this.setData({ results: [] }) // 空值短路
    try {
      const res = await api.search(kw)
      if (seq !== this._seq) return              // 竞态：旧响应丢弃
      this.setData({ results: res })
      this._saveHistory(kw)
    } catch (e) {
      if (seq === this._seq) wx.showToast({ title: '搜索失败', icon: 'none' })
    }
  },
  _saveHistory(kw) {
    const history = [kw, ...wx.getStorageSync('searchHistory').filter(h => h !== kw)].slice(0, 10)
    wx.setStorageSync('searchHistory', history)
    this.setData({ history })
  },
  onUnload() { clearTimeout(this._timer) }
})
```
**评分点**：
- 防抖 + seq 竞态双保护。
- 空值短路清结果不发请求。
- 历史去重 + 上限 + storage。
- 卸载清 timer；键盘遮挡说明（input adjust-position 或 scroll-view 内边距）。
