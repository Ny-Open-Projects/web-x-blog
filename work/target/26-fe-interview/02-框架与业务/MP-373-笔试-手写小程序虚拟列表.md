## MP-373：笔试：手写虚拟列表

**答**：实现小程序虚拟列表组件：① scroll-view + 数据切片（只渲染可见区 ±overscan）；② 高度缓存（初始预估 EST_H，SelectorQuery 异步批测回填）；③ offsetTop transform 定位（spacer 撑总高）；④ 测量批量化（一次 SelectorQuery 查可见区全部——不是逐项）；⑤ 测量修正后的位置重算（scrollTop 与实际偏移的校准）。写出实现。

```javascript
Component({
  data: { slice: [], spacerH: 0, offsetY: 0 },
  properties: { items: Array },
  lifetimes: {
    attached() { this._heights = new Map(); this._start = -1; this._EST = 120; this._VIEW = 800; this._OV = 5; },
  },
  methods: {
    async onScroll(e) {
      const { scrollTop } = e.detail;
      const start = Math.max(0, Math.floor(scrollTop / this._EST) - this._OV);
      const end = start + Math.ceil(this._VIEW / this._EST) + this._OV * 2;
      if (start === this._start) return;
      this._start = start;
      this.setData({
        slice: this.data.items.slice(start, end),
        offsetY: this._sumH(start),
        spacerH: this._sumH(this.data.items.length),
      });
      this._measure(start, end);                       // 异步批测修正
    },
    _measure(start, end) {
      this.createSelectorQuery().selectAll('.v-item').boundingClientRect((rects) => {
        rects?.forEach((r, i) => {
          const idx = start + i;
          if (this._heights.get(idx) !== r.height) {   // 实测回填
            this._heights.set(idx, r.height);
          }
        });
        this.setData({ offsetY: this._sumH(this._start), spacerH: this._sumH(this.data.items.length) });  // 修正重算
      }).exec();
    },
    _sumH(until) {
      let s = 0;
      for (let i = 0; i < until; i++) s += this._heights.get(i) ?? this._EST;
      return s;
    },
  },
});
// WXML: <scroll-view bindscroll="onScroll" enhanced>
//   <view style="height:{{spacerH}}px">
//     <view style="transform:translateY({{offsetY}}px)">
//       <view wx:for="{{slice}}" class="v-item" data-index="{{...}}">...</view>
```

**评分点**：
- 切片渲染 + spacer 撑高的虚拟化骨架
- 异步批测（一次 SelectorQuery 查全可见区——非逐项）
- 测量回填后 offset/spacer 重算（校准）
- overscan 缓冲与 start 变化短路（同区间不重算）
