## MP-289：笔试：手写分页加载封装
**题**：实现 ListPage 逻辑：enablePullDownRefresh 重置第一页；onReachBottom 加载下一页（防重复：loading 锁 + hasMore 判断）；加载失败允许重试；到底提示；页码/游标双模式。

```javascript
function createListPage({ fetchPage, pageSize = 20 }) {
  return {
    data: { list: [], page: 0, hasMore: true, loading: false, error: null },
    async _load(reset = false) {
      if (this.data.loading || (!reset && !this.data.hasMore)) return // 防重复
      this.setData({ loading: true, error: null })
      const page = reset ? 1 : this.data.page + 1
      try {
        const { items, hasMore } = await fetchPage({ page, cursor: reset ? null : this._cursor, pageSize })
        this._cursor = hasMore ? items.at(-1)?.id : null
        this.setData({ list: reset ? items : [...this.data.list, ...items], page, hasMore, loading: false })
      } catch (e) {
        this.setData({ loading: false, error: e.msg || '加载失败' })
      }
    },
    onPullDownRefresh() { this._load(true).finally(() => wx.stopPullDownRefresh()) },
    onReachBottom() { this._load(false) },
    retryLoad() { this._load(false) }
  }
}
// Page({ ...createListPage({ fetchPage: (p) => api.getList(p) }) })
```
**评分点**：
- loading 锁 + hasMore 双闸（防重复触发）。
- 页码与游标双模式（游标更稳——删除场景页码会漂移）。
- 失败重试不清列表。
- stopPullDownRefresh 必须调用。
