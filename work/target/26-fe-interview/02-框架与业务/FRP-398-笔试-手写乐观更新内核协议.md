## FRP-398：笔试：手写乐观更新内核

**答**：实现内核级乐观更新：① mutate(key, fn, { optimistic })：optimistic 值立即写 → 请求 → 成功写真实值 / 失败回滚；② 连续乐观操作的队列叠加（多条 pending 按序 reducer 应用——基于最新真实值）；③ 版本号仲裁（真实值带 rev——旧响应不覆盖新乐观值）；④ 回滚精度（只回滚失败的那条——其余 pending 保持）；⑤ 快照导出（乐观期间的 UI 状态与真实状态分列——调试用）。写出实现。

```javascript
export function createOptimisticStore() {
  let real = {}; let rev = 0;
  const pending = [];               // [{ id, reducer, key }]
  const subs = new Set();
  const view = () => pending.reduce((acc, p) => ({ ...acc, ...p.reducer(acc) }), real);
  const notify = () => subs.forEach((f) => f({ view: view(), real, rev, pendingCount: pending.length }));

  async function mutate(key, fn, { optimistic }) {
    const id = crypto.randomUUID();
    pending.push({ id, key, reducer: optimistic, ts: Date.now() });
    notify();                                        // 立即乐观视图
    try {
      const result = await fn();
      if (result.rev <= rev) throw new Error('stale response');   // 版本仲裁
      rev = result.rev;
      real = { ...real, ...result.data };
    } finally {
      // 只移除自己(失败时其余 pending 保持)
      const idx = pending.findIndex((p) => p.id === id);
      if (idx >= 0) pending.splice(idx, 1);
      notify();                                        // 真实值落地或回滚该条
    }
  }
  return { mutate, sub(fn) { subs.add(fn); return () => subs.delete(fn); },
    snapshot: () => ({ view: view(), real, rev, pending: pending.map((p) => p.key) }) };
}
// 双框架绑定: React useSyncExternalStore(view 订阅) / Vue customRef(view) — UI 只看 view
```

**评分点**：
- 乐观视图 = 真实值 + pending 队列按序 reduce（叠加语义）
- 只回滚失败条目（其余 pending 保持）
- rev 版本仲裁防旧响应覆盖
- snapshot 的双态导出（view vs real——调试乐观 UI 的关键）
