## V3-224：静态提升（hoistStatic）与 SSR 编译输出各做了什么优化？
**答**：
- 静态提升：纯静态 vnode 提到 render 函数外作为模块级常量，每次渲染直接引用，不重复创建；连续静态节点超过阈值（20）合并为单个 `createStaticVNode`（innerHTML 字符串）。
- 事件缓存：`@click="fn"` 内联函数经 cacheHandlers 编译为 `onCreate$1` 缓存引用，props 浅比较永远相等，子组件 memo 不被击穿。
- SSR 输出：SSR 编译生成 `ssrRender`/`ssrRenderList` 等函数，直接字符串拼接 HTML，无 vnode 创建，服务端吞吐更高。
- 双产物：同一模板同时生成 client（vnode/vapor）与 server（ssrRender）两份代码，由编译器按 target 分发。
- 追问钩子：静态提升的副作用？——被提升节点被共享引用，patch 时按 HOISTED 跳过，千万别在外部改动它。

```javascript
// client 产物
const _hoisted_1 = createElementVNode("span", null, "静态文案", -1 /* HOISTED */);
const _hoisted_2 = [_hoisted_1, _hoisted_1]; // 大段静态合并
function render() {
  return (openBlock(), createElementBlock("div", null, [..._hoisted_2]));
}
// server 产物（无 vnode）
import { ssrRenderAttrs } from 'vue/server-renderer';
function ssrRender(_ctx, _push, _parent) {
  _push(`<div><span>静态文案</span><p>${ssrInterpolate(_ctx.msg)}</p></div>`);
}
```
