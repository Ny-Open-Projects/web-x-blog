## V3-496：Vue3 错误边界体系：全局、组件级与异步错误

**答**：
- 三层捕获：app.config.errorHandler（全局兜底 + 上报）、onErrorCaptured（组件级边界，返回 false 阻止向上传播）、window 级（onerror/unhandledrejection 兜异步）——异步错误（Promise/watch 回调）会经过 errorHandler 但不触发组件级边界
- 组件级边界的 UI 恢复：onErrorCaptured 只能「捕获」不能「恢复渲染」——恢复要配合 key 重挂载（boundary 组件捕获后展示 fallback，重试时改 key 强制重建子树）
- 请求层错误与渲染错误分流：接口失败 → 请求层 toasty + 降级数据（不进 errorHandler 语义）；渲染崩溃 → 边界接管——两套策略别混
- 上报上下文：errorHandler 里带组件名（err 信息 + instance）、路由、用户操作轨迹——Vue 特有增益：instance 可拿到组件树路径
- Suspense 组合：async setup 的错误要用 onErrorCaptured 就近捕获（Suspense 不会自动转 fallback）——已知坑

```javascript
// 全局
app.config.errorHandler = (err, instance, info) => {
  report({ msg: err.message, stack: err.stack, info,
           comp: instance?.$options?.name, route: router.currentRoute.value.fullPath });
};
// 组件级边界 + 重试
onErrorCaptured((err) => { hasError.value = true; return false; });
// 重试: <Child v-if="!hasError" :key="retryKey" />
```
