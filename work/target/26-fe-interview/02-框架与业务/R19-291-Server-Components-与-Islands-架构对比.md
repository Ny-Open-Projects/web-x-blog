## R19-291：RSC 与 Islands 架构的本质差异？
**答**：
- Islands：整页静态 HTML + 交互组件作为独立岛各自水合（按需/可见时）；岛间通信靠 DOM/自定义事件。
- RSC：服务端渲染整棵树（含交互组件引用），客户端统一 React 运行时管理，树内状态通信自然。
- 数据流：Islands 每岛独立请求脚本/数据；RSC 由服务端统一编排数据。
- 心智：Islands = 「多框架多岛拼贴」，RSC = 「单一框架的服务端/客户端分层」。
- 选型：内容型站点（博客/文档）Islands 极致省 JS；应用型（重交互、状态复杂）RSC 更顺。
