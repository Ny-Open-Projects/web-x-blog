## FRP-350：框架无关键盘导航内核

**答**：
- 内核模式：roving tabindex（容器监听 + 焦点项切换）、焦点陷阱（Tab 循环）、快捷键注册表（组合键 → 动作）——纯 DOM/事件实现框架无关
- a11y 语义与实现分离：aria 属性由框架层绑定（响应式），键盘行为在内核——「语义在框架、行为在内核」的分工
- 快捷键注册表的冲突治理：作用域（全局/页面/组件）+ 优先级 + 冲突检测（注册时查重告警）——快捷键系统的工程化
- 焦点恢复协议：内核记录「触发者」→ 关闭浮层还原——跨框架浮层（React 弹层从 Vue 页面打开）焦点一致
- 测试：键盘行为用「真实 DOM 事件模拟」（jsdom/Playwright keyboard）——内核可无框架测试

```javascript
export function createRoving(container, { orientation = 'vertical' } = {}) {
  const move = (dir) => {
    const items = [...container.querySelectorAll(FOCUSABLE)];
    const i = items.indexOf(document.activeElement);
    items[(i + dir + items.length) % items.length]?.focus();
  };
  const onKey = (e) => {
    const map = orientation === 'vertical'
      ? { ArrowDown: 1, ArrowUp: -1 } : { ArrowRight: 1, ArrowLeft: -1 };
    if (e.key in map) { e.preventDefault(); move(map[e.key]); }
    if (e.key === 'Home') { e.preventDefault(); container.querySelector(FOCUSABLE).focus(); }
    if (e.key === 'End') { e.preventDefault(); [...container.querySelectorAll(FOCUSABLE)].at(-1).focus(); }
  };
  container.addEventListener('keydown', onKey);
  return () => container.removeEventListener('keydown', onKey);
}
```
