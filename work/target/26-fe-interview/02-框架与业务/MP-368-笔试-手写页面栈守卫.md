## MP-368：笔试：手写页面栈守卫

**答**：实现 `safeNav`：① navigateTo 前检查 getCurrentPages().length ≥10 → 自动改用 redirectTo（替换栈顶）；② 深层向导模式：向导流程内的跳转始终「替换」（栈深恒定）；③ 栈深监控埋点（接近上限告警）；④ navigateBack 的 delta 防护（delta 超栈深钳制）；⑤ 兼容 switchTab/reLaunch 直透。写出实现。

```javascript
const STACK_MAX = 10;
const wizardPages = new Set(['/pages/wizard/step1', '/pages/wizard/step2', '/pages/wizard/step3']);

export function safeNav(url, opts = {}) {
  const depth = getCurrentPages().length;
  const isWizard = wizardPages.has(currentRoute());
  // 埋点: 接近上限
  if (depth >= STACK_MAX - 1) beacon({ type: 'stack-warn', depth, to: url });
  if (depth >= STACK_MAX || isWizard || opts.replace) {
    return wx.redirectTo({ url });                   // 替换: 栈深恒定
  }
  return wx.navigateTo({ url });
}

export function safeBack(delta = 1) {
  const depth = getCurrentPages().length;
  const d = Math.min(delta, depth - 1);              // 钳制: 不越栈底
  if (d <= 0) return wx.reLaunch({ url: '/pages/index/index' });  // 栈底兜底回首页
  return wx.navigateBack({ delta: d });
}
function currentRoute() {
  return '/' + getCurrentPages().at(-1)?.route;
}
// 用法: 所有业务跳转统一走 safeNav — 栈溢出免疫
// 向导页: safeNav('/pages/wizard/step2') → redirectTo (完成一层替换一层)
```

**评分点**：
- 双触发条件（上限 + 向导模式）自动 redirectTo
- delta 钳制与栈底兜底（navigateBack 越界的失败处理）
- 栈深埋点（接近上限告警——观测先行）
- 向导模式集合的注册机制（可配置）
