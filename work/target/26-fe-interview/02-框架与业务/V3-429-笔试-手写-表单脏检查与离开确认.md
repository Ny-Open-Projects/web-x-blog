## V3-429：笔试：手写表单脏检查与离开确认（路由 + 刷新双拦截）
**答**：实现 `useFormGuard(formRef)`：dirty = 表单与初始快照不一致（深比较，忽略顺序）；dirty 时路由切换 beforeRouteLeave 弹确认；页面刷新/关闭触发 beforeunload；提交成功解除守卫。

```javascript
function useFormGuard(formRef, { onSubmit } = {}) {
  const initial = ref()
  let dirty = ref(false)
  onMounted(() => { initial.value = structuredClone(toRaw(formRef.value.model)) })
  watch(formRef.value.model, (v) => {
    dirty.value = !isEqual(structuredClone(toRaw(v)), initial.value)
  }, { deep: true })
  onBeforeRouteLeave(async (to, from) => {
    if (!dirty.value) return true
    return await confirm('表单未保存，确定离开？')
  })
  const onBeforeUnload = (e) => {
    if (dirty.value) { e.preventDefault(); e.returnValue = '' } // 刷新/关闭拦截
  }
  onMounted(() => window.addEventListener('beforeunload', onBeforeUnload))
  onBeforeUnmount(() => window.removeEventListener('beforeunload', onBeforeUnload))
  async function submit() {
    await onSubmit?.()
    dirty.value = false
    initial.value = structuredClone(toRaw(formRef.value.model)) // 新基线
  }
  return { dirty, submit }
}
```
**评分点**：
- 快照基线 + 深比较 dirty（提交后更新基线）。
- 路由守卫与 beforeunload 双拦截齐备。
- beforeunload 需 preventDefault + returnValue（兼容写法）。
- 卸载移除监听；structuredClone/toRaw 防引用比较失真。
