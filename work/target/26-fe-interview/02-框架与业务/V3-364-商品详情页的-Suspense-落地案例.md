## V3-364：商品详情页用 Suspense 编排的落地案例怎么设计？
**答**：
- 数据分三级：商品主信息（标题/价格/主图，必须先出）、SKU 与库存（次级）、评论与推荐（可延后）。
- 结构：外层 Suspense + 详情主组件（await 商品接口）；SKU 组件内层 Suspense；评论区再一层 + 独立错误边界（失败不阻塞主流程）。
- 细节：SKU 缺货不影响主图展示（独立失败域）；主数据失败时整页错误 UI + 重试；评论失败显示「加载失败，点击重试」局部提示。
- 数据层配套：请求去重（同 id 并发只发一次）、预加载（列表页 hover 预取商品 id 数据）、minDelay 掩盖闪烁。
- 收益量化：主接口 resolve 即可交互，TTI 提前约 300-500ms（视次接口耗时）。
