## V3-415：笔试：手写 IM 消息列表（时间分组 + 定位锚点 + 逆向加载）
**题**：实现消息列表核心：1) messages 按 5 分钟间隔分组展示时间条（computed 派生带 showTime 标记的行）；2) 新消息到达且用户在底部时自动滚动到底，用户上翻时不打断；3) 上滑加载历史（逆向）保持滚动位置（记录 scrollHeight diff）。

```javascript
const BOTTOM_EPS = 50
function useMessageList(messages) {
  const rows = computed(() => messages.value.map((m, i) => ({
    ...m,
    showTime: i === 0 || m.ts - messages.value[i - 1].ts > 5 * 60_000
  })))
  let stickBottom = true
  function onScroll(e) {
    const el = e.target
    stickBottom = el.scrollHeight - el.scrollTop - el.clientHeight < BOTTOM_EPS
  }
  function onNewMessage(el) {
    if (stickBottom) el.scrollTop = el.scrollHeight
    else showUnreadTip()
  }
  async function loadHistory(el) {
    const prevHeight = el.scrollHeight, prevTop = el.scrollTop
    await fetchOlder()
    await nextTick()
    el.scrollTop = el.scrollHeight - prevHeight + prevTop // 位置保持
  }
  return { rows, onScroll, onNewMessage, loadHistory }
}
```
**评分点**：
- 时间分组 computed 派生（不 mutate 原数据）。
- 底部吸附阈值判定 + 上翻不打断 + 未读提示。
- 逆向加载位置保持公式（scrollHeight diff）。
- EPS 容差（50px）而非严格等值。
