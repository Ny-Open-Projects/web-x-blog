## R19-343：笔试：手写并发安全的 IM 未读计数
**答**：消息高频到达更新未读数（低优 transition），当前正在输入的草稿（高优）不被阻塞；未读数显示旧值时角标加脉冲动画提示「有新消息」。

```javascript
function ChatHeader({ messages }) {
  const [unread, setUnread] = useState(0)
  const [displayed, setDisplayed] = useState(0)
  useEffect(() => {
    const count = messages.filter(m => !m.read).length
    startTransition(() => setUnread(count)) // 低优更新，不阻塞打字
  }, [messages])
  // displayed 用 deferred 或直接渲染 unread，isStale 时加脉冲
  const [deferredUnread, stale] = useMyDeferredValue(unread)
  return (
    <header>
      <span className={stale ? 'badge pulse' : 'badge'}>{deferredUnread}</span>
    </header>
  )
}
```
**评分点**：
- 高频计数更新包 transition（低优通道）。
- deferred + stale 脉冲提示（可感知的延迟）。
- 说明「旧值显示」是有意行为而非 bug。
- 消息 read 状态变更也走低优。
