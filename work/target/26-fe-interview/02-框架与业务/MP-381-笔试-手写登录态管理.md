## MP-381：笔试：手写登录态管理

**答**：实现 `ensureLogin`：① 三层判定：业务 token 有效（缓存+过期时间）→ checkSession（session_key 有效则 code2session 复用）→ 全量重登；② 静默原则：全程无授权弹窗（login 不需授权）；③ 并发调用单飞（多处同时 ensureLogin 共享一次）；④ 手机号授权的独立流程（open-type getPhoneNumber 的 code → 服务端换号——与登录态解耦）；⑤ 过期提前刷新（expiresIn - 300s 定时）。写出实现。

```javascript
let loginPromise = null;
let refreshTimer = null;

export async function ensureLogin() {
  const cached = wx.getStorageSync('token');
  if (cached && Date.now() < cached.expiresAt) return cached.token;   // L1: token 有效
  loginPromise ??= doLogin().finally(() => { loginPromise = null; }); // 单飞
  return loginPromise;
}
async function doLogin() {
  const sessionOk = await new Promise((r) => wx.checkSession({ success: () => r(true), fail: () => r(false) }));
  // L2: session_key 有效 → 服务端可用旧 code2session 上下文(简化: 仍换新 code 但静默)
  const { code } = await wx.login();
  const { token, expiresIn } = await api.code2session(code);
  const record = { token, expiresAt: Date.now() + expiresIn * 1000 };
  wx.setStorageSync('token', record);
  clearTimeout(refreshTimer);
  refreshTimer = setTimeout(ensureLogin, (expiresIn - 300) * 1000);   // 提前 5 分钟刷新
  return token;
}
// 手机号独立流程(与登录态解耦):
// <button open-type="getPhoneNumber" bindgetphonenumber="onPhone">
// onPhone(e) { api.bindPhone(e.detail.code); }  — code 服务端换手机号(新版, 无需 session_key 解密)
```

**评分点**：
- 三层判定顺序（token → checkSession → 全量重登）
- 全程静默（login 无授权弹窗的认知）
- 并发单飞 + 提前刷新定时
- 手机号 code 流程与登录态解耦（新版 encryptedData 弃用方向）
