## V3-273：树形表格的异步加载与展开状态管理怎么设计？
**答**：
- 数据结构：后端给**扁平带层级字段**（id/parentId/hasChildren）或懒加载接口（按 parentId 取子节点）；前端维护 `Map<id, {children, loaded}>`。
- 懒加载：展开时若未 loaded 则请求子节点，插入到父节点 children；`hasChildren: false` 显示叶子态，避免空 loading。
- 展开状态独立于数据：`expandedSet: Set<id>` 存展开的行 key，数据刷新后不丢失勾选/展开状态（key 稳定是前提）。
- 全选联动：树形勾选要向下级联 + 向上归并（父勾选状态 = 三态 indeterminate），递归计算在扁平化列表上做效率更高。
- 性能：树 + 虚拟滚动结合时把树**拍平为有序行数组**（含 depth 缩进字段），折叠用过滤而非重建树结构。

```typescript
interface Row { id: string; parentId: string | null; name: string; hasChildren: boolean; children?: Row[] }
const expanded = reactive(new Set<string>());
const childCache = reactive(new Map<string, Row[]>());
async function toggle(row: Row) {
  if (!expanded.value.has(row.id)) {
    if (row.hasChildren && !childCache.get(row.id)) {
      const children = await api.fetchChildren(row.id);   // 懒加载子级
      childCache.set(row.id, children);
    }
    expanded.value.add(row.id);
  } else expanded.value.delete(row.id);
}
// 拍平为虚拟列表行：depth 缩进 + 折叠过滤
function flatten(rows: Row[], depth = 0, out: { row: Row; depth: number }[] = []) {
  for (const r of rows) {
    out.push({ row: r, depth });
    if (expanded.value.has(r.id)) flatten(childCache.get(r.id) ?? r.children ?? [], depth + 1, out);
  }
  return out;
}
```
