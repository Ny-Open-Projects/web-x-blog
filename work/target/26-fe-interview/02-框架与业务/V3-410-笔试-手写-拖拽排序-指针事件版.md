## V3-410：笔试：手写拖拽排序（指针事件 + FLIP 动画核心）
**题**：实现列表拖拽排序核心 `useDragSort(list, elRefs)`：pointerdown 开始、移动时计算目标插入位（按元素中心 y 比较）、实时更新顺序数组、FLIP 动画（记录旧位置 → 重排 → transform 反向 → 过渡归零）。

```javascript
function useDragSort(list) {
  let dragging = null
  const onPointerDown = (index, e) => {
    dragging = { index, startY: e.clientY }
    e.target.setPointerCapture(e.pointerId)
    e.target.style.transform = `translateY(0)`
    e.target.style.zIndex = 10
  }
  const onPointerMove = (index, e) => {
    if (!dragging) return
    e.target.style.transform = `translateY(${e.clientY - dragging.startY}px)` // 跟随
    const els = [...e.target.parentElement.children]
    const target = els.findIndex(el => {
      const r = el.getBoundingClientRect()
      return el !== e.target && e.clientY > r.top + r.height / 2
    })
    if (target > -1) {
      const [moved] = list.value.splice(index, 1) // 实时重排
      list.value.splice(target, 0, moved)
      dragging.index = target
    }
  }
  const onPointerUp = (e) => {
    if (!dragging) return
    // FLIP：清 transform 前记录，重排后 diff 做过渡
    e.target.style.transition = 'transform .2s'
    e.target.style.transform = ''
    dragging = null
  }
  return { onPointerDown, onPointerMove, onPointerUp }
}
```
**评分点**：
- 指针事件替代 HTML5 DnD（移动端兼容 + 可控）。
- 以元素中心线判定插入位。
- 实时重排数据数组而非只挪 DOM。
- FLIP 思路（旧位置记录、反向 transform、过渡归零）至少能口述。
