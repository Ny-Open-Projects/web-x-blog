## R19-224：Action 返回的错误文案怎么做国际化？
**答**：
- 推荐返回「错误码」而非服务端渲染文案：action 返回 { code: 'STOCK_INSUFFICIENT' }，客户端按 locale 渲染对应文案——文案归前端，语义归服务端。
- 服务端文案方案（必须服务端出文案时，如邮件）：action 接受 locale 参数（从 cookie/用户设置取），用服务端 i18n 词典。
- 一致性：错误码枚举与前端词典 key 对齐，CI 校验词典完整性（新 code 必有翻译）。
- 字段级校验错误同样返回 code + 字段名，前端模板渲染 `${field} ${message}`。
- 面试亮点：说出「服务端只懂协议、客户端负责表达」的分层原则。
