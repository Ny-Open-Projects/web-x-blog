## R19-305：RSC 与微前端怎么共存？
**答**：
- RSC 的 Flight payload 依赖统一 React 运行时：子应用独立构建（不同 React 版本）时无法共享 RSC 树——子应用作为「客户端岛」集成。
- 模式一：iframe 隔离子应用（最稳），主应用 RSC 渲染外壳，postMessage 通信（鉴权 token 下发）。
- 模式二：Web Components 封装子应用入口，主应用 RSC 中像普通元素使用。
- 模式三：Module Federation 客户端合并（放弃子应用 RSC 化，统一 client 数据流）。
- 判据：子应用独立团队/独立部署 → iframe/WC 隔离；同团队强耦合 → MF 合并，逐步 RSC 化。
