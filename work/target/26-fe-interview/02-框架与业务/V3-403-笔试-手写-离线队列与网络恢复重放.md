## V3-403：笔试：手写离线队列（本地队列 + 网络恢复重放）
**答**：实现 `OfflineQueue`：push(op) 时网络不可用则入 localStorage 队列；恢复在线时按序重放；单条重放失败可跳过或重试（maxRetry）；幂等要求：op 带客户端生成的 requestId 防重复提交。

```javascript
class OfflineQueue {
  constructor(maxRetry = 3) {
    this.key = 'offline_ops'
    this.ops = JSON.parse(localStorage.getItem(this.key) || '[]')
    this.maxRetry = maxRetry
    window.addEventListener('online', () => this.flush())
    if (navigator.onLine) this.flush()
  }
  async push(op) {
    const item = { ...op, requestId: crypto.randomUUID(), retry: 0, ts: Date.now() }
    if (!navigator.onLine) { this.ops.push(item); this._save(); return { queued: true } }
    return this._exec(item)
  }
  async flush() {
    const remain = []
    for (const item of this.ops) {
      try { await this._exec(item) } catch {
        item.retry++
        if (item.retry < this.maxRetry) remain.push(item)
        else console.error('drop op', item.requestId)
      }
    }
    this.ops = remain; this._save()
  }
  async _exec(item) {
    const res = await fetch(item.url, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', 'X-Request-Id': item.requestId },
      body: JSON.stringify(item.body)
    })
    if (!res.ok) throw new Error('op failed')
  }
  _save() { localStorage.setItem(this.key, JSON.stringify(this.ops)) }
}
```
**评分点**：
- online 事件 + 启动时 flush 双触发。
- requestId 幂等头防重放重复（核心）。
- 重试上限与丢弃策略，避免死循环。
- 持久化在每次变更后同步写。
