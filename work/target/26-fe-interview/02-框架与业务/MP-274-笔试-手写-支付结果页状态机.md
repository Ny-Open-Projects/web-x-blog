## MP-274：笔试：手写支付结果页状态机
**答**：实现 reducer + 轮询编排：状态 QUERYING/PAID/FAILED/CANCELLED/PENDING_CONFIRM；轮询查单 5 次（2s 间隔）仍 PAYING → PENDING_CONFIRM；PAID 停轮询跳成功页；事件：PAY_CALL_SUCCESS/FAIL/QUERY_RESULT/TICK。

```javascript
function reducer(state, event) {
  switch (state.status) {
    case 'QUERYING':
      if (event.type === 'QUERY_RESULT') {
        if (event.orderStatus === 'PAID') return { status: 'PAID' }
        if (event.orderStatus === 'FAILED') return { status: 'FAILED' }
        if (event.times >= 5) return { status: 'PENDING_CONFIRM' } // 轮询超限
        return state
      }
      if (event.type === 'TICK') return { status: 'QUERYING', times: (state.times || 0) + 1 }
      return state
    case 'IDLE':
      if (event.type === 'PAY_CALL_SUCCESS') return { status: 'QUERYING', times: 0 }
      if (event.type === 'PAY_CALL_FAIL') return { status: event.cancel ? 'CANCELLED' : 'FAILED' }
      return state
    default: return state // PAID/FAILED/PENDING_CONFIRM 终态（可重试入口另议）
  }
}
// 编排：PAY_CALL_SUCCESS 后 setInterval 每 2s dispatch TICK + 发起查询；
// dispatch QUERY_RESULT 携带 orderStatus 与 times
```
**评分点**：
- 状态穷举（含 PENDING_CONFIRM——只认服务端）。
- 轮询超限转待确认（防死循环 + 防重复支付）。
- 取消与失败区分（文案与重试入口不同）。
- 终态停止轮询（clearInterval）说明。
