## FRP-331：跨框架部署与产物协议

**答**：
- 微前端产物协议：子应用导出 { mount(el, props), unmount() }——与框架无关的挂载契约（qiankun/wujie/原生 iframe 通用）
- 共享依赖协议：externals + 版本协商（主应用提供 React/Vue 单例，子应用声明 peer 范围）——版本冲突的灰度策略（不兼容版本子应用自带依赖）
- 资源隔离：子应用产物 hash + 独立 CDN 路径 + CSS 前缀——样式冲突的构建期约束（postcss-prefix 按包）
- 部署原子性：主应用与子应用独立发布——「子应用 API 依赖主应用能力」的向后兼容承诺（deprecated 周期）
- 深水点：公共 chunk 去重（module federation 的 shared 配置）——共享粒度与缓存命中的权衡（过度共享导致版本升级爆炸半径）

```javascript
// 子应用入口契约
export async function mount(el, props) {
  const app = createApp(Root, { ...props });
  app.use(router(props.base));
  app.mount(el);
  return () => app.unmount();          // 返回卸载函数(协议统一)
}
// 主应用消费:
const unmount = await import('@sub/order').then((m) => m.mount(el, { user }));
```
