## MP-394：笔试：手写路由封装

**答**：实现 `router`：① 路由表声明（路径 + 元信息：auth/tab/参数类型）——「魔法字符串」收敛为类型化路由；② navigate(to, params)：auth 元信息 → 未登录重定向登录页（回跳参数）；③ 参数序列化（对象 → query + 数组逗号 + 嵌套 JSON escape）与目标页反序列化（parseQuery）；④ tab 页跳转分派（switchTab 不带参——参数走 store 中转）；⑤ 守卫链（beforeEach 可拦截/重定向——埋点/AB 分流挂载点）。写出实现。

```javascript
export const ROUTES = {
  home: { path: '/pages/index/index', tab: true },
  detail: { path: '/pages/detail/index', auth: true, params: { id: Number } },
  login: { path: '/pages/login/index' },
};

const store = {};       // tab 参数中转
let beforeEach = null;

export function onBeforeEach(fn) { beforeEach = fn; }

export async function navigate(name, params = {}) {
  const route = ROUTES[name];
  if (!route) throw new Error(`unknown route: ${name}`);
  const next = { name, params, route };
  const guard = await beforeEach?.(next);            // 守卫链: 拦截/重定向
  if (guard === false) return;
  if (typeof guard === 'string') return navigate(guard);
  if (route.auth && !getApp().store.token) {
    return wx.navigateTo({ url: `${ROUTES.login.path}?redirect=${name}&p=${encodeURIComponent(JSON.stringify(params))}` });
  }
  if (route.tab) {
    if (Object.keys(params).length) store[`tab:${name}`] = params;   // switchTab 无参 → store 中转
    return wx.switchTab({ url: route.path });
  }
  const qs = Object.entries(params).map(([k, v]) =>
    `${k}=${encodeURIComponent(Array.isArray(v) ? v.join(',') : typeof v === 'object' ? JSON.stringify(v) : v)}`).join('&');
  wx.navigateTo({ url: `${route.path}${qs ? '?' + qs : ''}` });
}
export function parseRoute(name, options) {
  const def = ROUTES[name]?.params ?? {};
  return Object.fromEntries(Object.entries(def).map(([k, T]) => {
    const raw = options[k];
    return [k, T === Number ? +raw : T === Boolean ? raw === 'true' : raw ?? null];
  }));
}
// 守卫挂载: onBeforeEach(async (next) => { track('nav', next.name); if (ab(next.name) === 'B') return 'home'; });
```

**评分点**：
- 路由表元信息驱动（auth/tab/参数类型）
- 守卫链可拦截可重定向（埋点/AB 挂载点）
- switchTab 无参的 store 中转协议
- 序列化/反序列化对称（数组逗号/嵌套 JSON）与类型还原
