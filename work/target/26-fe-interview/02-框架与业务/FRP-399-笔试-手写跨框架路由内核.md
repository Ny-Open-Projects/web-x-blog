## FRP-399：笔试：手写跨框架路由内核

**答**：实现框架无关路由内核 `createRouter({ routes })`：① 路由匹配（路径模式 :param + 通配）→ 返回 { matched, params, query }；② navigate(to)：history.pushState + 内核状态更新 + 通知（各框架绑定各自渲染）；③ popstate 监听（浏览器前进后退）；④ 守卫链（beforeEach 可重定向/取消）；⑤ 钩子：路由切换的 scrollBehavior（内核层返回目标滚动位置）。写出实现与 React/Vue 绑定要点。

```javascript
export function createRouter({ routes, beforeEach } = {}) {
  let current = resolve(location.pathname + location.search);
  const subs = new Set();

  function resolve(url) {
    const [path, qs] = url.split('?');
    const query = Object.fromEntries(new URLSearchParams(qs));
    for (const r of routes) {
      const params = matchPath(r.path, path);        // :param 提取
      if (params) return { route: r, params, query, path };
    }
    return { route: routes.find((r) => r.path === '*') ?? null, params: {}, query, path };
  }
  function matchPath(pattern, path) {
    const pp = pattern.split('/'), np = path.split('/');
    if (pp.length !== np.length) return null;
    const params = {};
    for (let i = 0; i < pp.length; i++) {
      if (pp[i].startsWith(':')) params[pp[i].slice(1)] = decodeURIComponent(np[i]);
      else if (pp[i] !== np[i]) return null;
    }
    return params;
  }
  async function navigate(to, { replace = false } = {}) {
    const next = resolve(to);
    const redirect = await beforeEach?.(next, current);
    if (redirect) return navigate(redirect);          // 守卫重定向
    history[replace ? 'replaceState' : 'pushState']({}, '', to);
    current = next;
    subs.forEach((f) => f(current));
    next.route?.scrollBehavior?.({ to: next });       // 内核层滚动语义
  }
  addEventListener('popstate', () => {
    current = resolve(location.pathname + location.search);
    subs.forEach((f) => f(current));
  });
  return { navigate, get current() { return current; },
    sub(fn) { subs.add(fn); return () => subs.delete(fn); } };
}
// React 绑定: useSyncExternalStore(router.sub, () => router.current) → 渲染 matched 组件
// Vue 绑定:   customRef(router.sub) → computed 解析组件
```

**评分点**：
- 路径模式匹配（:param 提取 + 通配）
- 守卫链的重定向/取消语义
- pushState + popstate 双向同步
- 「内核匹配 + 各框架渲染」的分层（绑定层只消费 matched）
