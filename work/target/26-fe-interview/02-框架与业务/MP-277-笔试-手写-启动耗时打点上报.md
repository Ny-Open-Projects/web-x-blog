## MP-277：笔试：手写启动耗时打点上报
**答**：实现 Perf 类：mark(name) 打点；measure(startMark, endMark) 计时；启动链路自动串联（App onLaunch → 首页 onLoad → onReady）+ 分包下载耗时；批量上报（攒 20 条或 10s）；采样（成功 1% 失败 100%）；页面卸载 flush。

```javascript
class Perf {
  constructor({ sample = 0.01, flushSize = 20, flushMs = 10000 } = {}) {
    this.marks = {}; this.buffer = []; this.sample = sample
    this.timer = setInterval(() => this.flush(), flushMs)
  }
  mark(name) { this.marks[name] = Date.now() }
  measure(name, from, to) {
    const cost = this.marks[to] - this.marks[from]
    const isFail = cost > 3000 // 超阈值算异常
    if (isFail || Math.random() < this.sample) {
      this.buffer.push({ name, cost, fail: isFail, ts: Date.now(), route: getCurrentPages().at(-1)?.route })
    }
    if (this.buffer.length >= 20) this.flush()
    return cost
  }
  flush() {
    const list = this.buffer.splice(0)
    if (!list.length) return
    wx.request({ url: '/api/perf', method: 'POST', data: list, fail: () => { /* 失败重试队列 */ } })
  }
  dispose() { clearInterval(this.timer); this.flush() }
}
// App onLaunch: perf.mark('launch'); 首页 onReady: perf.measure('firstRender', 'launch', 'homeReady')
```
**评分点**：
- 打点-测量分离设计。
- 采样策略（失败全采成功采样）。
- 批量上报双阈值。
- 路由维度附带（按页面看启动）。
