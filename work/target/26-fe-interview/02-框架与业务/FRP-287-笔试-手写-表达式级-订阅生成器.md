## FRP-287：笔试：手写表达式级订阅生成器
**答**：给定模板 `<div><span>{{count}}</span><p class="{{cls}}">t</p></div>` 的 AST，实现 `codegenSubscribe(ast)`：输出订阅绑定数组——每个插值生成 `{ path: 'span/textContent', getter: '() => count' }`、class 绑定同理；静态内容零绑定。

```javascript
function codegenSubscribe(ast, path = '') {
  const bindings = []
  function walk(node, p) {
    if (node.type === 'expr') {
      bindings.push({ path: p, getter: `() => ${node.expr}` })
      return
    }
    if (node.type === 'element') {
      if (node.dynamicProps) {
        node.dynamicProps.forEach(prop =>
          bindings.push({ path: `${p}@${prop}`, getter: `() => ${node.props[prop].expr}` }))
      }
      (node.children || []).forEach((c, i) => walk(c, c.type === 'element' ? `${p}>${c.tag}[${i}]` : `${p}#text[${i}]`))
    }
  }
  walk(ast, 'root')
  return bindings
}
// 输出：
// [{ path: 'root>span[0]#text[0]', getter: '() => count' },
//  { path: 'root>p[1]@class', getter: '() => cls' }]
```
**评分点**：
- 每个动态点独立绑定（表达式级粒度）。
- 静态内容零绑定（跳过）。
- 路径唯一可定位（结构选择器）。
- 能说明运行时按 path 定位 DOM 节点 + effect 绑定 getter。
