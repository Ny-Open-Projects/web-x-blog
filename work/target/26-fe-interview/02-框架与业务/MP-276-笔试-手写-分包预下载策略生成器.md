## MP-276：笔试：手写分包预下载策略生成器
**答**：输入：页面跳转漏斗数据 [{ from, to, rate }]、分包大小与下载耗时 P50、单页面预下载总预算 2MB。实现 `genPreloadRule(data)`：贪心选择「跳转率 × 分包大小」性价比最高的组合，预算内按 rate 降序纳入；输出 preloadRule 配置（network 依据分包大小：>1M 仅 wifi）。

```javascript
function genPreloadRule(funnels, pkgSizes, budgetBytes = 2 * 1024 * 1024) {
  const candidates = funnels
    .filter(f => pkgSizes[f.to]) // to 是分包页面
    .map(f => ({ ...f, size: pkgSizes[f.to], value: f.rate * pkgSizes[f.to] }))
    .sort((a, b) => b.value - a.value)
  const rule = {}
  const used = new Map() // from -> bytes
  for (const c of candidates) {
    const cur = used.get(c.from) || 0
    if (cur + c.size > budgetBytes) continue // 预算约束
    used.set(c.from, cur + c.size)
    rule[c.from] ||= { network: 'all', packages: [] }
    if (c.size > 1024 * 1024) rule[c.from].network = 'wifi' // 大包仅 wifi
    if (!rule[c.from].packages.includes(c.to)) rule[c.from].packages.push(c.to)
  }
  return rule
}
// 输出形如 { 'pages/index/index': { network: 'wifi', packages: ['pkgGoods', 'pkgUser'] } }
```
**评分点**：
- 性价比排序（rate × size）贪心。
- 预算约束（2MB/页面）。
- 大包降级 wifi（网络条件感知）。
- 去重（同包多个入口）。
