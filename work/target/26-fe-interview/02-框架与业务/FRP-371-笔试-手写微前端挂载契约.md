## FRP-371：笔试：手写微前端挂载契约

**答**：实现微前端容器 `MicroContainer`：① `register(name, app)`：app 导出 { mount(el, props), unmount() }；② activate(name, props)：懒加载 chunk → mount（容器注入）→ 返回卸载句柄；③ 路由联动：activate 时传 base，子应用路由生效；④ 卸载链：deactivate 调 unmount → 清容器 → 订阅清理（bridge 按 source）；⑤ 重复 activate 防护（同 name 在跑则先 deactivate）；⑥ mount 失败重试一次 + 错误兜底 UI。写出实现。

```javascript
class MicroContainer {
  #apps = new Map();      // name -> { loader, instance? }
  #active = null;
  #bridge;
  constructor(bridge) { this.#bridge = bridge; }

  register(name, loader) { this.#apps.set(name, { loader }); }

  async activate(name, props = {}) {
    if (this.#active?.name === name) return;          // 已激活短路
    if (this.#active) await this.deactivate();
    const entry = this.#apps.get(name);
    let mod;
    try { mod = await entry.loader(); }               // 懒加载
    catch (e) { return this.#fallback(name, e); }
    for (let i = 0; i < 2; i++) {                     // mount 失败重试 1 次
      try {
        const el = this.#createEl(name);
        this.#active = {
          name,
          dispose: await mod.mount(el, { ...props, bridge: this.#bridge, base: `/${name}` }),
        };
        return;
      } catch (e) { if (i === 1) return this.#fallback(name, e); }
    }
  }
  async deactivate() {
    const a = this.#active;
    if (!a) return;
    await a.dispose?.();                              // 子应用卸载钩子
    this.#bridge.cleanup(a.name);                     // 桥按 source 清理订阅
    document.getElementById(`micro-${a.name}`)?.remove();
    this.#active = null;
  }
  #createEl(name) {
    const el = document.createElement('div');
    el.id = `micro-${name}`;
    document.querySelector('#micro-root').appendChild(el);
    return el;
  }
  #fallback(name, e) {
    document.querySelector('#micro-root').innerHTML = `<div class="micro-error">子应用 ${name} 加载失败 <button onclick="location.reload()">重试</button></div>`;
    report({ type: 'micro-mount-fail', name, error: String(e) });
  }
}
// 子应用侧契约: export async function mount(el, props) { ... return () => { /* 卸载清理 */ }; }
```

**评分点**：
- mount 返回 dispose 的契约设计（双向清理）
- 路由 base 注入与容器创建
- 卸载链完整（dispose → bridge.cleanup → DOM 移除）
- 重复激活防护 + mount 重试 + 兜底 UI
