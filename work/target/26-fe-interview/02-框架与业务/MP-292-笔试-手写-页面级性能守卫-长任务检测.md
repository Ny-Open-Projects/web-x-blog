## MP-292：笔试：手写长任务检测守卫
**答**：实现 guardLongTask(name, fn)：包装同步/异步函数，测量执行耗时；超 50ms 视为长任务——上报（函数名/耗时/页面路径）；同步大循环提供 chunkify 分片执行替代方案（Promise 分批让出逻辑层主线程）。

```javascript
async function chunkify(items, fn, chunkSize = 200) {
  for (let i = 0; i < items.length; i += chunkSize) {
    items.slice(i, i + chunkSize).forEach(fn)
    await new Promise(r => setTimeout(r, 0)) // 让出主线程（逻辑层单线程）
  }
}
function guardLongTask(name, fn) {
  return async (...args) => {
    const t0 = Date.now()
    try { return await fn(...args) }
    finally {
      const cost = Date.now() - t0
      if (cost > 50) {
        report({ type: 'long_task', name, cost, route: getCurrentPages().at(-1)?.route })
        console.warn(`[perf] ${name} took ${cost}ms`)
      }
    }
  }
}
// 用法：
// const safeRender = guardLongTask('renderList', async (rows) => chunkify(rows, r => cache.set(r.id, r)))
```
**评分点**：
- 耗时测量 + 阈值判定 + 上报带页面上下文。
- chunkify 分片让出（逻辑层无 rAF，用 setTimeout(0)）。
- finally 保证异常路径也测量。
- 50ms 阈值依据（交互流畅基线）。
