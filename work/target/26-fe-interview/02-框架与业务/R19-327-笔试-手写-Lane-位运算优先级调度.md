## R19-327：笔试：手写 Lane 位运算优先级调度器
**题**：实现简化 lane 调度：lanes 用 32 位整数（低位优先级高）；`scheduleUpdate(task, lane)` 入任务队列；`getNextLanes()` 返回当前最高优先级 lane；`processWork(deadlineMs)` 按优先级处理任务，超时让出，剩余任务下次继续；同 lane 任务合并为一次批量处理。

```javascript
const lanes = { SYNC: 0b0001, DEFAULT: 0b0010, TRANSITION: 0b0100, RETRY: 0b1000 }
const pendingByLane = new Map() // lane -> [tasks]
let pendingLanes = 0
function scheduleUpdate(task, lane) {
  pendingByLane.set(lane, [...(pendingByLane.get(lane) || []), task])
  pendingLanes |= lane
}
function getNextLanes() {
  for (let bit = 1; bit <= 0b1000; bit <<= 1) { // 低位优先
    if (pendingLanes & bit) return bit
  }
  return 0
}
function processWork(deadlineMs = 5) {
  const start = performance.now()
  let lane = getNextLanes()
  while (lane && performance.now() - start < deadlineMs) {
    const tasks = pendingByLane.get(lane)
    pendingByLane.delete(lane)
    pendingLanes &= ~lane           // 清除该 lane 位
    tasks.forEach(t => t())         // 同 lane 批量执行（一次渲染）
    lane = getNextLanes()
  }
  if (pendingLanes) scheduleNextTick(() => processWork(deadlineMs)) // 让出后继续
}
```
**评分点**：
- 位或叠加、位与取反清除（|、&、~）。
- 低位优先扫描；同 lane 批量（合并语义）。
- deadline 让出 + 剩余 lanes 续跑（中断恢复）。
- 能说明真实 React 还有「跨 lane 抢占、Suspense retry 通道」等细节。
