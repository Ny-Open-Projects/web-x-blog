## V3-430：笔试：手写抽屉多开与浏览器历史回退联动
**题**：实现侧边抽屉 `useDrawer()`：open(id) 时用 history.pushState 记录状态（抽屉 id 编码在 query）；浏览器返回键关闭抽屉（popstate 监听）；close() 用 history.back() 保持历史一致；多开嵌套（抽屉套抽屉）逐层入栈。

```javascript
function useDrawer() {
  const stack = reactive([])
  function open(id, props) {
    stack.push({ id, props })
    history.pushState({ drawerDepth: stack.length }, '', `?drawer=${id}`)
  }
  function close() {
    if (!stack.length) return
    if (history.state?.drawerDepth === stack.length) history.back() // 由 popstate 统一出栈
    else pop()
  }
  function pop() { stack.pop() }
  window.addEventListener('popstate', (e) => {
    const depth = e.state?.drawerDepth ?? 0
    while (stack.length > depth) pop() // 回退到对应深度
  })
  return { stack, open, close }
}
```
**评分点**：
- pushState/popstate 与栈深度对齐（depth 一致性是核心）。
- close 优先 history.back() 保持「返回键语义一致」。
- 多层抽屉逐层出栈（while）。
- 初始无抽屉时 depth=0 兜底。
