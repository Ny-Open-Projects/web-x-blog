## MP-279：笔试：手写分包体积审计脚本
**题**：实现 Node 脚本 auditDist(dir)：遍历构建产物（.js/.wxml/.wxss/.png…），按类型聚合体积，输出 TOP10 大文件、图片总量与占比、主包超 1.5M 告警、优化建议清单（图片 CDN 化/依赖去重提示基于文件名识别 lodash/moment）。

```javascript
const fs = require('fs')
const path = require('path')
function auditDist(dir) {
  const files = []
  ;(function walk(d) {
    fs.readdirSync(d).forEach(f => {
      const p = path.join(d, f)
      const stat = fs.statSync(p)
      stat.isDirectory() ? walk(p) : files.push({ file: path.relative(dir, p), size: stat.size, ext: path.extname(f) })
    })
  })(dir)
  const byExt = {}
  files.forEach(f => { byExt[f.ext] = (byExt[f.ext] || 0) + f.size })
  const total = files.reduce((s, f) => s + f.size, 0)
  const top10 = [...files].sort((a, b) => b.size - a.size).slice(0, 10)
  const imgTotal = byExt['.png'] + byExt['.jpg'] + byExt['.webp'] || 0
  const suggestions = []
  if (imgTotal / total > 0.3) suggestions.push('图片占比超 30%，建议 CDN 化本地图片')
  if (files.some(f => /moment\./.test(f.file))) suggestions.push('检测到 moment.js，建议换 dayjs')
  if (files.some(f => /lodash\./.test(f.file) && !/lodash-es/.test(f.file))) suggestions.push('全量 lodash，建议按需引入 lodash-es')
  console.table({ total, byExt, top10 })
  console.log(suggestions.join('\n'))
}
auditDist('./dist')
```
**评分点**：
- 递归遍历 + 按类型聚合。
- TOP 大文件定位。
- 基于规则的优化建议（图片/已知重依赖识别）。
- CI 集成思路（体积 diff 与阈值告警）。
