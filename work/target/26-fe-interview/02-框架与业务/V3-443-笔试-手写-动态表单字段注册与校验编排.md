## V3-443：笔试：手写动态表单的字段注册与校验编排（provide/inject 模式）
**题**：Form 组件 provide 上下文：field 组件 mounted 时注册自己的 name 与 validate；unmounted 注销；Form.validate() 按注册顺序逐个校验并聚合错误；字段变更时通知 Form 标脏。

```javascript
const FORM_KEY = Symbol('form')
export function useForm() {
  const fields = reactive(new Map())
  provide(FORM_KEY, {
    register(name, validate) { fields.set(name, validate) },
    unregister(name) { fields.delete(name) },
    setDirty() { dirty.value = true }
  })
  const dirty = ref(false)
  async function validate() {
    const errors = []
    for (const [name, validateField] of fields) { // 按注册顺序
      const err = await validateField()
      if (err) errors.push({ name, err })
    }
    return errors
  }
  return { fields, dirty, validate }
}
// FormField 内：
const form = inject(FORM_KEY)
onMounted(() => form.register(name, validate))
onBeforeUnmount(() => form.unregister(name)) // 动态字段销毁时注销
```
**评分点**：
- register/unregister 生命周期配对（动态字段删除后不再校验，核心）。
- validate 异步聚合（await 顺序执行，可并行优化说出即可）。
- inject key 用 Symbol 防冲突。
- dirty 状态由字段通知上抛。
