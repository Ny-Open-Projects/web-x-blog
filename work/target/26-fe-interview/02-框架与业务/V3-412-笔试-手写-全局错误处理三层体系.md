## V3-412：笔试：手写全局错误处理体系（全局/路由/组件三层）
**题**：实现 `setupErrorHandling(app, router)`：1) app.config.errorHandler 收集组件错误并上报（去重：同错误 60s 内只报一次）；2) router.onError 处理路由加载失败并重定向错误页；3) window.addEventListener('unhandledrejection') 兜底 Promise 异常；4) 错误信息截断防超大 payload。

```javascript
export function setupErrorHandling(app, router, report) {
  const seen = new Map()
  const reportOnce = (err, ctx) => {
    const key = String(err?.message || err).slice(0, 120)
    const now = Date.now()
    if (now - (seen.get(key) || 0) < 60_000) return
    seen.set(key, now)
    report({ message: String(err?.stack || err).slice(0, 2000), ctx }) // 截断
  }
  app.config.errorHandler = (err, inst, info) => {
    reportOnce(err, { info, component: inst?.type?.name })
    console.error(err)
  }
  router.onError(err => {
    reportOnce(err, { type: 'router' })
    if (/Failed to fetch dynamically imported/.test(err.message)) {
      window.location.reload() // chunk 失效（发版后旧入口）→ 整页刷新
    } else router.replace('/error')
  })
  window.addEventListener('unhandledrejection', e => reportOnce(e.reason, { type: 'promise' }))
}
```
**评分点**：
- 三层覆盖完整 + 上报去重（60s 窗口）。
- chunk 加载失败识别 → 整页刷新（发版场景，高频加分点）。
- 错误内容截断防上报体积失控。
- errorHandler 中仍 console.error 便于本地调试。
