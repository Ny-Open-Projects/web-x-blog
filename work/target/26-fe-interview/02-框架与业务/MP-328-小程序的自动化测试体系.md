## MP-328：小程序自动化测试体系：miniprogram-simulate 与 minitest

**答**：
- 测试分层：组件单元测试（miniprogram-simulate——渲染组件/触发事件/断言 DOM）、页面 E2E（miniprogram-automator——真机/模拟器驱动）、逻辑层纯函数（jest 直测）
- simulate 的能力与边界：可以 attach 渲染、触发 touch 事件、查询 selector——但「小程序特有 API」（wx.request 等）要 mock（wx 对象注入）
- automator 的流程测试：自动化 SDK（npm i miniprogram-automator）连开发工具——核心链路（登录/下单）真机回归
- CI 集成：miniprogram-ci（上传/预览/packNpm）+ automator（CLI 驱动开发工具自动化）——提审前的自动化门禁
- 深水点：mock 的分层——wx API mock（网络/存储）、时间 mock（setInterval 驱动的逻辑）、业务 SDK mock（支付/登录返回固定 code）——分层 mock 才能测「业务逻辑而非基础设施」

```javascript
// 组件测试 (miniprogram-simulate)
const id = simulate.load('/components/counter/index');
const comp = simulate.render(id, { value: 1 });
comp.attach(document.createElement('parent'));
comp.querySelector('.plus').dispatchEvent('tap');
await simulate.sleep(10);
expect(comp.instance.data.value).toBe(2);
// automator E2E:
const automator = require('miniprogram-automator');
const miniProgram = await automator.connect({ wsEndpoint: 'ws://localhost:9420' });
const page = await miniProgram.reLaunch('/pages/index/index');
await page.$('.buy-btn').tap();
```
