## V3-500：Vue3 测试金字塔：组件测试策略

**答**：
- 分层：纯函数/composable 单测（不挂载，直接调用——useXxx 用 effectScope 包裹测副作用清理）、组件行为测试（@vue/test-utils 挂载，断言 emit/props 渲染）、E2E 关键路径——Vue 特有优势：composable 是纯函数可直接单测
- composable 测试要点：ref/computed 的时序（await nextTick）、effectScope 清理断言（重复挂载不泄漏）——生命周期 hook 在测试环境的模拟
- 组件测试原则：测「行为契约」不测「实现细节」（断言 emit 与 DOM 结果，不断言内部 state 结构）——重构不破坏测试
- 异步组件测试：flushPromises + fake timers（debounce 场景）；Suspense/异步 setup 用 flushAll 序列
- 快照使用边界：小展示组件可用快照，业务组件禁用（快照让测试退化为「改了就更新」）——快照只防意外变更

```javascript
// composable 测试
it('useCounter cleanup', async () => {
  const scope = effectScope();
  const { count, inc } = scope.run(() => useCounter())!;
  inc(); expect(count.value).toBe(1);
  scope.stop();   // 副作用应随 scope 清理
});
// 组件测试
const wrapper = mount(Pager, { props: { total: 100, current: 1 } });
await wrapper.find('.next').trigger('click');
expect(wrapper.emitted('change')![0]).toEqual([2]);
```
