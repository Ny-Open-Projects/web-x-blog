## FRP-394：笔试：手写订阅审计层

**答**：给内核 store 加审计层：① wrapStore(store)：sub 返回「带身份的 dispose」——订阅登记 { source, stack, t }；② 审计：`audit()` 输出活跃订阅列表（按 source 聚合、存活时长）——「谁在订阅」可回答；③ 泄漏检测：定时对比 sub/unsub 计数，同 source 存活 >10min 且数量增长告警；④ set 频率打点（环形缓冲 + 每 key 通知次数统计——热点 key 归因）；⑤ 生产开销控制（审计层默认 off，URL/构建开关启用）。写出实现。

```javascript
export function wrapStore(store, { auditEnabled = false } = {}) {
  const active = new Map();     // dispose -> { source, stack, t }
  const keyHits = new Map();
  const origSub = store.sub, origSet = store.set;

  store.sub = (fn, source = 'anonymous') => {
    const dispose = origSub.call(store, fn);
    const record = { source, stack: auditEnabled ? new Error().stack?.split('\n')[2] : null, t: Date.now() };
    active.set(dispose, record);
    return () => { active.delete(dispose); dispose(); };
  };
  store.set = (v, meta) => {
    keyHits.set(meta?.key ?? '?', (keyHits.get(meta?.key ?? '?') ?? 0) + 1);
    return origSet.call(store, v, meta);
  };

  return {
    audit() {
      return {
        subscriptions: [...active.values()].map((r) => ({
          source: r.source, ageMs: Date.now() - r.t, stack: r.stack,
        })),
        hotKeys: [...keyHits.entries()].sort((a, b) => b[1] - a[1]).slice(0, 10),
        total: active.size,
      };
    },
    startLeakWatch({ everyMin = 10, threshold = 20 } = {}) {
      let last = 0;
      const timer = setInterval(() => {
        const n = active.size;
        if (n > last + threshold)
          console.warn('[audit] subscriptions growing fast', { from: last, to: n, by: audit().subscriptions.slice(0, 5) });
        last = n;
      }, everyMin * 60_000);
      return () => clearInterval(timer);
    },
  };
}
// 用法: React 壳 sub 时带 source='react:CartPage' — 泄漏可归因到组件
```

**评分点**：
- 带身份的订阅（source + stack 采集时机）
- audit 的归因输出（按 source 聚合 + 存活时长）
- 泄漏检测的增量告警（增长速率而非绝对值）
- 生产开销控制（默认 off + 开关）
