## FRP-298：笔试：手写框架升级兼容层
**题**：实现 `toOptionsAPI(setupFn)`：把 Composition 风格组件包装成 Options API 组件——setup 返回的 onMounted/onUnmounted 注册映射到 mounted/unmounted 钩子；data/ref 暴露到 this；保证卸载时清理。

```javascript
function toOptionsAPI(setupFn) {
  return {
    setup(_, { expose }) { /* Vue3 原生支持，此处演示手动桥接思路 */ },
    data() {
      const ctx = { mountedCbs: [], unmountedCbs: [], onMounted: f => this.mountedCbs.push(f), onUnmounted: f => this.unmountedCbs.push(f) }
      this.__ctx = ctx
      return { ...collectRefs(setupFn(ctx)) } // setup 结果展开为 data（ref 自动解包由框架处理）
    },
    mounted() { this.__ctx.mountedCbs.forEach(f => f()) },
    unmounted() { this.__ctx.unmountedCbs.forEach(f => f()) },
    beforeUnmount() { /* ref 清理由框架 */ }
  }
}
function collectRefs(result) {
  return Object.fromEntries(Object.entries(result).map(([k, v]) => [k, isRef(v) ? v : v]))
}
```
**评分点**：
- 生命周期映射正确（onMounted→mounted）。
- setup 结果注入（ref 解包语义说明）。
- 卸载清理路径完整。
- 能指出 Vue3 的 setup 内建兼容（此题为理解演示），或扩展到「第三方旧组件库桥接新框架」场景。
