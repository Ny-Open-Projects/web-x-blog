## V3-442：笔试：手写深链分享参数的编解码（防篡改 + 过期）
**答**：实现 `encodeShare(payload, secret)` / `decodeShare(token, secret)`：payload JSON → base64url；附 HMAC 签名防篡改；带过期时间（exp 字段）；解码时先验签再验过期，任一失败返回 null；长度压缩（去无意义字段）。

```javascript
const b64url = (s) => btoa(String.fromCharCode(...new TextEncoder().encode(s)))
  .replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '')
async function hmac(msg, secret) {
  const key = await crypto.subtle.importKey('raw', new TextEncoder().encode(secret),
    { name: 'HMAC', hash: 'SHA-256' }, false, ['sign'])
  const sig = await crypto.subtle.sign('HMAC', key, new TextEncoder().encode(msg))
  return b64url(String.fromCharCode(...new Uint8Array(sig)))
}
async function encodeShare(payload, secret) {
  const body = { ...payload, exp: Date.now() + 7 * 24 * 3600_000 }
  const data = b64url(JSON.stringify(body))
  const sig = await hmac(data, secret)
  return `${data}.${sig}`
}
async function decodeShare(token, secret) {
  const [data, sig] = token.split('.')
  if (!data || !sig) return null
  if (await hmac(data, secret) !== sig) return null // 篡改
  const body = JSON.parse(atob(data.replace(/-/g, '+').replace(/_/g, '/')))
  if (Date.now() > body.exp) return null // 过期
  const { exp, ...payload } = body
  return payload
}
```
**评分点**：
- 签名校验在解码前（先验签后验内容）。
- exp 过期校验。
- base64url 转换（URL 安全字符集）。
- 服务端 secret 才能防伪，前端实现需配合服务端签发（能说出这个局限加分）。
