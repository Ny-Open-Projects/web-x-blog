## V3-286：级联选择器的数据结构与性能设计怎么处理？
**答**：
- 数据模型：树形 options（value/label/children + isLeaf），懒加载模式 `loadData(node) => Promise<children>`，用 Map<value, node> 建立索引快速定位。
- 选中模型：存**路径数组**（['浙江', '杭州', '西湖']）而非叶子值——渲染回显、面包屑、清空、编辑态还原都直接用路径。
- 搜索：多级名称拼接的扁平索引（路径字符串 + 拼音首字母），search 时过滤叶子并**自动补全中间层路径**（叶子命中需展示完整链路）。
- 性能：面板渲染当前层级只渲染选中链路 + 当前层 options；千级节点用虚拟列表；勾选模式（multiple）选中集用 Set，路径合成延迟到提交。
- 懒加载坑：搜索命中未加载节点需先加载链路再展开；异步回填时避免整树重渲染（局部 children 替换）。

```typescript
const nodeIndex = new Map<string, OptionNode>();   // value -> node（含 parent 引用）
function buildIndex(nodes, parent = null) {
  for (const n of nodes) { n.parent = parent; nodeIndex.set(n.value, n); buildIndex(n.children ?? [], n); }
}
function getPath(node) {                            // O(深度) 取路径
  const path = [];
  for (let cur = node; cur; cur = cur.parent) path.unshift(cur.value);
  return path;
}
async function loadData(node) {
  if (node.loaded) return node.children;
  const children = await api.fetchOptions(node.value);
  node.children = children; node.loaded = true;     // 局部回填，不重建整树
  buildIndex(children, node);
  return children;
}
// 搜索：预构建 "浙江/杭州/西湖区" 路径字符串索引，命中叶子后 getPath 补全链路
```
