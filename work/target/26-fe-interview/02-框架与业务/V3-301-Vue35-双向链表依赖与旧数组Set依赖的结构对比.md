## V3-301：Vue 3.5 的双向链表依赖与旧版「数组+Set」依赖结构相比好在哪？
**答**：
- 旧结构：`dep = Set<ReactiveEffect>`，effect 侧还要用 `deps: Dep[]` 反向记录。触发更新时若开启 cleanup，要先 `dep.clear()` 把依赖全删光，再重新全量收集。
- 新结构：`dep` 本身是双向链表节点，effect 之间通过 `w/nextDep` 串成链表。清理时按 effect 自己的链表逐个摘除，**只摘本轮没再用到的**，无需清空全量重收。
- 收益：高频 trigger（如大数组每项变动）不再产生「清空 + 全量重收集」的 O(n) 抖动，追加式收集让重复触发近似 O(新增量)。
- 内存：每个依赖节点复用 `Link` 对象，effect 侧 `deps` 数组消失，双向引用变成统一链表，GC 友好。
- 追问钩子：链表节点里还带 `version` 字段，与版本计数配合判断脏状态——继续答 V3-303。
