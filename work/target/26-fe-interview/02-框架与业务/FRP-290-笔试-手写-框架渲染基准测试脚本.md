## FRP-290：笔试：手写渲染基准测试脚本
**题**：实现 `bench(name, runFn, { rounds = 10, warmup = 2 })`：预热轮次后计时取中位数与 P95；输出 ms 表格行；支持 async 任务；统计 GC 干扰（performance.memory 快照前后对比）。

```javascript
async function bench(name, runFn, { rounds = 10, warmup = 2 } = {}) {
  for (let i = 0; i < warmup; i++) await runFn() // 预热 JIT
  const times = []
  const memBefore = performance.memory?.usedJSHeapSize
  for (let i = 0; i < rounds; i++) {
    const t0 = performance.now()
    await runFn()
    times.push(performance.now() - t0)
  }
  const memAfter = performance.memory?.usedJSHeapSize
  times.sort((a, b) => a - b)
  const median = times[Math.floor(rounds / 2)]
  const p95 = times[Math.ceil(rounds * 0.95) - 1]
  return { name, median: +median.toFixed(2), p95: +p95.toFixed(2),
    memDelta: memAfter && memBefore ? +(memAfter - memBefore / 1024 / 1024).toFixed(1) : null }
}
// 用法：await bench('react-1000rows', () => rerender(1000))
```
**评分点**：
- 预热轮次（排除 JIT/懒加载干扰）。
- 中位数与 P95（不取平均——排除离群值）。
- 内存快照对比。
- async 支持与统计字段完整。
