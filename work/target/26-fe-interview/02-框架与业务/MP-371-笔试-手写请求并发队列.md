## MP-371：笔试：手写请求队列

**答**：实现小程序请求队列：① wx.request 并发上限 10——队列调度（高优先级插队：核心接口直发不排队）；② 按域名/类型分池（图片 downloadFile 与 API request 分池互不抢额度）；③ 队列超载保护（pending >50 丢最旧 low 任务并计数）；④ 每请求超时与重试（1 次退避）；⑤ 统计（flying/pending/dropped）。写出实现。

```javascript
class RequestPool {
  #lanes = { high: [], normal: [], low: [] };
  #flying = 0;
  constructor({ maxConcurrent = 10, timeout = 10000 } = {}) { Object.assign(this, { maxConcurrent, timeout }); }

  request(opts, lane = 'normal') {
    if (lane === 'high') return this.#exec(opts);     // 核心直发不排队
    if (this.#pendingCount() >= 50) {
      const oldest = this.#lanes.low.shift() ?? this.#lanes.normal.shift();
      oldest?.reject(new Error('pool overflow'));     // 丢最旧
      this.#dropped++;
    }
    return new Promise((resolve, reject) => {
      this.#lanes[lane].push({ opts, resolve, reject });
      this.#drain();
    });
  }
  async #exec(opts) {
    this.#flying++;
    try {
      return await new Promise((resolve, reject) => {
        wx.request({ ...opts, timeout: this.timeout, success: resolve, fail: reject });
      });
    } catch (e) {
      if (opts._retried) throw e;
      await new Promise((r) => setTimeout(r, 500));   // 退避 1 次
      return this.#exec({ ...opts, _retried: true });
    } finally { this.#flying--; this.#drain(); }
  }
  #drain() {
    while (this.#flying < this.maxConcurrent) {
      const task = this.#lanes.normal.shift() ?? this.#lanes.low.shift();
      if (!task) break;
      this.#exec(task.opts).then(task.resolve, task.reject);
    }
  }
  #pendingCount() { return this.#lanes.normal.length + this.#lanes.low.length; }
  get stats() { return { flying: this.#flying, pending: this.#pendingCount(), dropped: this.#dropped }; }
}
```

**评分点**：
- 三车道（high 直发/normal/low）与 10 并发对齐 wx.request 上限
- 超载丢最旧 + 计数（背压保护）
- 重试退避一次（防重试风暴）
- 分池互不抢额度（图片 vs API）的意识
