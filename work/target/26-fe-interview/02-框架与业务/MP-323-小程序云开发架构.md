## MP-323：小程序云开发架构：云函数与云数据库的接入层设计

**答**：
- 云开发三件套：云函数（node 运行时——免运维后端）、云数据库（文档型，前端直接 SDK 查询）、云存储（文件）——「前端直连数据库」的权限模型是设计核心
- 权限模型：基础库 SDK 直查数据库受「集合权限」控制（读/写分离）——敏感集合必须走云函数（服务端校验），只有「用户自有数据」（openid 隔离）可前端直查
- 云函数的冷启动：首次调用 1~3s——高频函数保活（定时触发器 ping）或「关键路径不用云函数」（网关 API）
- 数据设计：openid 自动注入（前端插入的数据带 openid 字段）——「只有创建者可读写」的权限规则（db.collection.where({ openid: '{openid}' })）
- 深水点：云函数与自建后端的取舍——快速验证/轻后端用云开发；复杂业务/多端复用（App/H5 同后端）用自建——边界是「多端」

```javascript
// 前端直查(用户自有数据): 云数据库权限 = 仅创建者可读写
const db = wx.cloud.database();
const notes = await db.collection('notes').where({ openid: '{openid}' }).orderBy('ts', 'desc').limit(20).get();
// 敏感操作走云函数(服务端校验):
const res = await wx.cloud.callFunction({ name: 'order', data: { action: 'create', sku } });
// 云函数内: openid = cloud.getWXContext().OPENID — 服务端可信来源
```
