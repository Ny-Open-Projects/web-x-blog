## FRP-286：笔试：手写静态节点提升标注器
**题**：给定模板 AST（`{ type: 'element'|'text'|'expr', tag?, content?, children? }`），实现 `hoistStatic(ast)`：返回 { hoisted: [...静态节点], root }——纯静态子树（无 expr 且子孙无 expr）从树上摘下放进 hoisted，树上留引用标记。

```javascript
function hoistStatic(ast) {
  const hoisted = []
  function isStatic(node) {
    if (node.type === 'expr') return false
    if (node.type === 'text') return true
    return (node.children || []).every(isStatic)
  }
  function walk(node) {
    if (node.children) {
      node.children = node.children.map(child => {
        if (isStatic(child)) {
          child.__hoisted = hoisted.length
          hoisted.push(child)          // 提升为常量
          return { type: 'ref', index: hoisted.length - 1 } // 树上留引用
        }
        walk(child)
        return child
      })
    }
  }
  walk(ast)
  return { hoisted, root: ast }
}
```
**评分点**：
- isStatic 递归判定（子树内不得含表达式）。
- 摘出 + 引用标记的双向结构。
- 遍历顺序（静态子树不再深入）。
- 说明运行时意义：重渲染时 hoisted vnode 直接复用，不重建不 diff。
