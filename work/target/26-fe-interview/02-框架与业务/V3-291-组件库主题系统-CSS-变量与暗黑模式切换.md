## V3-291：组件库主题系统：CSS 变量与暗黑模式切换怎么设计？
**答**：
- 变量分层：语义层（--color-primary/--color-bg-elevated）→ 映射层（按主题切换值）→ 组件层（组件只消费语义变量），换主题只换映射层。
- 暗黑实现：`<html data-theme="dark">` 属性选择器切换映射层变量值；少量强色（品牌色）用 color-mix/HSL 变换生成暗色版。
- 过渡：主题切换瞬间避免全页 transition 抖动（给 html 加 no-transition 类 100ms 再移除）。
- 动态主题：品牌定制色传入时 JS 计算 HSL 派生色（hover/active/disabled 梯度）写入 CSS 变量，运行时无编译。
- 兼容：不支持 CSS 变量的环境（老 WebView）降级方案：构建期注入主题包（按主题打包独立样式文件）。

```typescript
// 主题定义
const themes = {
  light: { '--color-primary': '#409eff', '--color-bg': '#fff', '--color-text': '#303133' },
  dark:  { '--color-primary': '#66b1ff', '--color-bg': '#141414', '--color-text': '#e5eaf3' },
};
function applyTheme(name: keyof typeof themes) {
  document.documentElement.dataset.theme = name;
  for (const [k, v] of Object.entries(themes[name])) document.documentElement.style.setProperty(k, v);
}
// 暗黑下品牌色派生（HSL 变换）
function derive(hex, lOffset) { const [h, s, l] = hexToHsl(hex); return hslToHex(h, s, l + lOffset); }
// 用法：primary=#409eff → hover=derive(primary, -8)、disabled=derive(primary, +25)
// 组件样式只写 var(--color-primary)，主题切换零 JS patch
```
