## V3-299：视频播放器封装的状态机设计是怎样的？
**答**：
- 状态模型：显式状态机（idle/loading/ready/playing/paused/buffering/error/ended），把 video 元素事件（canplay/playing/waiting/ended/error）映射为状态迁移，UI 只按状态渲染——避免"直接监听事件写散乱 if"。
- 自动播放策略：`autoplay + muted` 才有高成功率；被浏览器拒绝（NotAllowedError）后降级为"显示大播放按钮"。
- 缓冲与卡顿：waiting 事件进入 buffering，展示 spinner；上报卡顿率（waiting 次数/播放时长）； seek 后的等待与首播等待区分统计。
- 控制条：进度条拖动用 input range 或自绘（pointer 事件），dragging 期间暂停 currentTime 同步防抖动；音量/倍速持久化。
- 封装边界：Vue 层只做状态桥接与 UI，播放核心（hls.js/dash）通过适配器注入，方便换内核。

```typescript
function createPlayer(video) {
  const state = ref('idle');
  video.addEventListener('canplay', () => { if (state.value !== 'playing') state.value = 'ready'; });
  video.addEventListener('playing', () => (state.value = 'playing'));
  video.addEventListener('waiting', () => (state.value = 'buffering'));
  video.addEventListener('pause', () => { if (state.value === 'playing') state.value = 'paused'; });
  video.addEventListener('ended', () => (state.value = 'ended'));
  video.addEventListener('error', () => (state.value = 'error'));
  async function play() {
    try { await video.play(); }
    catch (e) { state.value = 'paused'; showBigPlayButton(); } // 自动播放被拒降级
  }
  return { state, play };
}
// UI：<VideoSpinner v-if="state === 'buffering'" /> <BigPlay v-if="state === 'paused' && !started" />
```
