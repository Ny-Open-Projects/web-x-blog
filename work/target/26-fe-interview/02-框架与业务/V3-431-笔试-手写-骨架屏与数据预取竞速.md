## V3-431：笔试：手写「预取 + 本地兜底」的商品列表加载策略
**题**：实现 `useGoodsList()`：进入页面立即用 sessionStorage 里的上次数据先渲染（兜底）；网络请求成功后更新；请求失败沿用旧数据并提示「数据可能过期」；数据写入带时间戳，超过 10 分钟不作为兜底。

```javascript
const KEY = 'goods:last'
function readCache() {
  try {
    const { ts, data } = JSON.parse(sessionStorage.getItem(KEY) || 'null') || {}
    if (data && Date.now() - ts < 10 * 60_000) return data
  } catch {}
  return null
}
function useGoodsList() {
  const list = ref(readCache() || [])
  const stale = ref(false)
  const loading = ref(false)
  async function load() {
    loading.value = true
    try {
      const res = await api.getGoodsList()
      list.value = res
      stale.value = false
      sessionStorage.setItem(KEY, JSON.stringify({ ts: Date.now(), data: res }))
    } catch {
      stale.value = list.value.length > 0 // 有旧数据展示旧数据
      if (!list.value.length) throw new Error('无数据且网络失败')
    } finally { loading.value = false }
  }
  onMounted(load)
  return { list, loading, stale, load }
}
```
**评分点**：
- 先渲染旧数据（感知速度）+ 成功后覆盖。
- 缓存带时间戳与新鲜度阈值。
- 失败分支区分「有旧数据 → stale 提示」与「无数据 → 抛错」。
- sessionStorage 读写 try/catch（隐私模式兼容）。
