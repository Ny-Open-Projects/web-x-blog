## MP-382：笔试：手写场景归因

**答**：实现 `parseEntry(options)`：① 合并冷启动（onLaunch options）与热启动（onShow options）——每次进入都解析（场景可能变化）；② scene 映射表（1047 扫码/1044 群分享/1089 搜索/…→ 渠道枚举）；③ 参数统一化：query 参数 + scene 码解码（二维码 scene 参数「a=1&b=2」的 32 字符压缩格式解析）；④ 归因上下文组装（inviter/act/sid 短码还原）；⑤ 产出埋点事件（entry 上报——首次归因 + 渠道分布）。写出实现。

```javascript
const SCENE_MAP = { 1047: 'qrcode', 1044: 'group-share', 1089: 'search', 1011: 'qrcode-scan', 1037: 'app-share' };

export function parseEntry(options = {}) {
  const scene = SCENE_MAP[options.scene] ?? `unknown-${options.scene}`;
  let query = { ...options.query };
  // 二维码 scene 字段: 32 字符压缩参数 "a=1&b=2" → 解析
  if (options.query?.scene) {
    Object.assign(query, Object.fromEntries(
      decodeURIComponent(options.query.scene).split('&').map((kv) => kv.split('='))));
  }
  const attribution = {};
  if (query.sid) attribution.shareId = query.sid;               // 短码 → 服务端还原
  if (query.inviter) attribution.inviter = query.inviter;
  if (query.act) attribution.activity = +query.act;
  const entry = { scene, query, attribution, ts: Date.now(), cold: !!options.entryType };
  track('entry', entry);                                         // 归因上报
  return entry;
}
// App 接入: onLaunch/onShow 都调 parseEntry(options) — 每次进入场景复核
// 短码还原: attribution.shareId → api.resolveShare(sid) → 完整上下文
```

**评分点**：
- 冷热启动双解析（onLaunch + onShow——场景可能变）
- scene 码 32 字符压缩参数解析（二维码特有）
- 归因上下文组装与短码还原分层
- entry 埋点与渠道分布闭环
