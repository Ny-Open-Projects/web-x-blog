## MP-295：笔试：手写动态分享配置
**答**：实现：Page.onShareAppMessage 动态标题（商品页带商品名/价格，落地面全局默认）；onShareTimeline 朋友圈分享（单页模式 query 精简）；分享参数带 userId 追踪归因；分享图规格（5:4）；分享路径白名单校验防篡改。

```javascript
Page({
  onShareAppMessage() {
    const goods = this.data.goods
    return {
      title: goods ? `${goods.title} 仅¥${goods.price}` : '精选好物，天天特卖',
      path: `/pages/goods/index?id=${this.goodsId}&inviterId=${this.userId}`,
      imageUrl: goods?.cover_500 || DEFAULT_SHARE_IMG // 5:4 规格 500x400
    }
  },
  onShareTimeline() {
    return {
      title: this.data.goods?.title || '特卖首页',
      query: `id=${this.goodsId}` // 朋友圈单页模式 query 有限，只带关键参数
    }
  }
})
// 落地校验：onLoad 中 inviterId 需在白名单/存在性校验，防伪造归因刷奖
```
**评分点**：
- 动态标题与兜底（商品页 vs 全局）。
- 朋友圈单页模式的 query 限制认知。
- 分享参数归因 + 防伪造校验（安全点）。
- 图片规格（5:4）细节。
