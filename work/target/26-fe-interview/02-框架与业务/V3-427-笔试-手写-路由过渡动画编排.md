## V3-427：笔试：手写路由过渡动画编排（mode=out-in + 数据未就绪兜底）
**答**：实现路由切换动画组件 RouterTransition：RouterView 包 Transition mode="out-in"（旧页先退场）；路由组件数据未就绪时显示骨架（配合 Suspense）；深链跳转（replace）不做动画（用 route.meta.noAnim 控制 transition name）。

```javascript
const RouterTransition = defineComponent({
  setup() {
    const route = useRoute()
    return () => h(Suspense, null, {
      default: () => h(Transition, { name: route.meta.noAnim ? 'none' : 'page', mode: 'out-in' }, {
        default: () => h((route.matched.at(-1)?.components?.default), { key: route.fullPath })
      }),
      fallback: () => h('div', { class: 'page-skeleton' })
    })
  }
})
// CSS:
// .page-enter-active { transition: opacity .2s, transform .2s }
// .page-enter-from { opacity: 0; transform: translateY(12px) }
// .page-leave-active { transition: opacity .15s }
// .page-leave-to { opacity: 0 }
```
**评分点**：
- Suspense 与 Transition 的正确嵌套顺序（Suspense 在外）。
- mode="out-in" 防新旧页重叠。
- key 用 fullPath 保证同名路由参数变化也触发动画。
- meta.noAnim 控制动画开关（替换型导航降级）。
