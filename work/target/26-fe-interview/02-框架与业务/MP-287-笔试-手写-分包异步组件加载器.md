## MP-287：笔试：手写分包异步加载器
**答**：实现 loadAsyncModule(pkgPath, { timeout, fallback })：包装 require.async（基础库支持）；加载超时或失败返回 fallback 模块并上报；加载成功缓存 promise（并发去重）；提供 preload 提前触发。

```javascript
const cache = new Map()
function loadAsyncModule(path, { timeout = 8000, fallback } = {}) {
  if (cache.has(path)) return cache.get(path)
  const p = Promise.race([
    require.async(`${path}.js`),
    new Promise((_, reject) => setTimeout(() => reject(new Error('load timeout')), timeout))
  ]).catch(e => {
    report({ type: 'async_module_fail', path, msg: e.message })
    return fallback // 降级模块（本地轻量实现或占位）
  })
  cache.set(path, p)
  return p
}
function preloadModule(path) { loadAsyncModule(path, { timeout: 15000, fallback: null }) }
// 使用（分包异步化页面内）：
// loadAsyncModule('../../pkgHeavy/lib/chart', { fallback: MiniChart }).then(renderChart)
```
**评分点**：
- require.async 包装 + 超时竞速。
- 失败降级模块（体验兜底）+ 上报。
- promise 缓存去重。
- preload 提前触发配合 preloadRule。
