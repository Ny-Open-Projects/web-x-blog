## MP-275：笔试：手写跨页面事件总线
**答**：实现 EventCenter：on/once/off/emit；TS 泛型约束事件名与 payload；页面卸载自动清理（提供 useAutoOff(page)——监听 page unload 事件统一 off）；emit 时异步调用防回调阻塞。

```javascript
class EventCenter {
  constructor() { this.map = new Map() } // event -> Set<fn>
  on(event, fn) {
    if (!this.map.has(event)) this.map.set(event, new Set())
    this.map.get(event).add(fn)
    return () => this.off(event, fn) // 返回取消函数
  }
  once(event, fn) {
    const wrap = (payload) => { this.off(event, wrap); fn(payload) }
    wrap.__orig = fn
    this.on(event, wrap)
  }
  off(event, fn) { this.map.get(event)?.delete(fn) }
  emit(event, payload) {
    Promise.resolve().then(() => [...(this.map.get(event) || [])].forEach(fn => fn(payload)))
  }
}
// 自动清理：页面注册时收集取消函数，onUnload 统一执行
function useAutoOff(page) {
  const disposers = []
  page.__autoOn = (ec, event, fn) => { disposers.push(ec.on(event, fn)) }
  page.__cleanEvents = () => disposers.forEach(d => d())
}
// Page({ onUnload() { this.__cleanEvents() } })
```
**评分点**：
- 泛型约束（事件名 → payload 类型映射）。
- once 的 wrap 包装与 off 一致性。
- emit 异步派发（防回调内同步异常影响 emit 方）。
- 自动清理机制（页面级防泄漏是小程序事件总线的头号坑）。
