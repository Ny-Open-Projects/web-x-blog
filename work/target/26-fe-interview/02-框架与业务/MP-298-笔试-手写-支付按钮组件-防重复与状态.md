## MP-298：笔试：手写支付按钮组件
**题**：实现 PayButton（Taro React）：idle → paying → done/error 四态；paying 期间点击无效（防重复拉起收银台）；error 显示原因并允许重试；支付结果回调与组件状态机联动（PENDING_CONFIRM 不允许重试支付）；卸载清理定时器。

```javascript
function PayButton({ orderId, amount }) {
  const [status, setStatus] = useState('idle') // idle/paying/done/error/pending
  const [msg, setMsg] = useState('')
  async function pay() {
    if (status !== 'idle' && status !== 'error') return // 防重复拉起
    setStatus('paying')
    try {
      const { paySign } = await api.prepay({ orderId })
      const res = await Taro.requestPayment({ ...paySign })
      if (res.errMsg.includes('ok')) {
        const order = await pollOrderStatus(orderId) // 查询确认
        setStatus(order.status === 'PAID' ? 'done' : 'pending')
        if (order.status !== 'PAID') setMsg('支付结果确认中，请勿重复支付')
      }
    } catch (e) {
      const cancel = e.errMsg?.includes('cancel')
      setStatus(cancel ? 'idle' : 'error') // 取消回 idle 可再点
      if (!cancel) setMsg('支付失败，请重试')
    }
  }
  return (
    <Button disabled={status === 'paying' || status === 'pending'} onClick={pay}>
      {status === 'paying' ? '支付中…' : status === 'done' ? '已支付' : status === 'pending' ? '确认中' : `支付 ¥${amount}`}
    </Button>
  )
}
```
**评分点**：
- 状态机禁非法转移（paying 期间无效点击）。
- 取消（cancel）与失败区分回退状态。
- pending 态禁止重试（防重复扣款——核心安全点）。
- 支付结果以查询订单确认而非 errMsg 推断。
