## V3-271：万行级虚拟滚动表格的设计方案是什么？
**答**：
- 核心结构：滚动容器（overflow auto）+ 上/下占位 div（撑起总高度）+ 可视窗口行；滚动时用 scrollTop 计算起始索引，`transform: translateY` 平移渲染切片。
- 定高 vs 动态高：定高用公式直取 `Math.floor(scrollTop / rowH)`；动态高用缓存数组（前缀和）+ 二分查找，测量后回填缓存。
- 表格特有：列布局用 colgroup + 固定列（sticky left/right）与主区域分离；行高一致才能与虚拟层对齐，动态行高要同步 sticky 列偏移。
- 数据层：10 万行以上必须服务端分页 + 本地窗口缓存（双向缓冲预取前后各一屏）；筛选/排序交给后端，前端只做视图切片。
- 细节：滚动节流用 rAF；保持滚动位置的数据刷新（scrollTop 修正）；`overscan` 防白屏。

```vue
<script setup>
import { ref, computed } from 'vue';
const ROW_H = 40, OVERSCAN = 6;
const container = ref(null);
const scrollTop = ref(0), viewH = ref(600);
const rows = ref(Array.from({ length: 100000 }, (_, i) => ({ id: i, name: `row-${i}` })));
const start = computed(() => Math.max(0, Math.floor(scrollTop.value / ROW_H) - OVERSCAN));
const end = computed(() => Math.min(rows.value.length, Math.ceil((scrollTop.value + viewH.value) / ROW_H) + OVERSCAN));
const slice = computed(() => rows.value.slice(start.value, end.value));
const onScroll = () => requestAnimationFrame(() => {
  const el = container.value;
  scrollTop.value = el.scrollTop; viewH.value = el.clientHeight;
});
</script>
<template>
  <div class="table-wrap" style="height:600px; overflow:auto" ref="container" @scroll="onScroll">
    <div :style="{ height: rows.length * ROW_H + 'px', position: 'relative' }">
      <div :style="{ transform: `translateY(${start * ROW_H}px)` }">
        <table style="table-layout:fixed">
          <colgroup><col style="width:80px"><col><col style="width:120px"></colgroup>
          <tr v-for="r in slice" :key="r.id" :style="{ height: ROW_H + 'px' }">
            <td>{{ r.id }}</td><td>{{ r.name }}</td><td><button>详情</button></td>
          </tr>
        </table>
      </div>
    </div>
  </div>
</template>
```
