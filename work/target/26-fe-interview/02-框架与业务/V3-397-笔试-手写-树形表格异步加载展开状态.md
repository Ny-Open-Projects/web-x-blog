## V3-397：笔试：手写树形表格的异步加载与展开状态管理
**答**：实现 `useTreeTable(fetchChildren)`：节点按需加载（懒加载 children）；维护 expanded Set（key 展开态）；刷新节点时保留展开态；提供 toggle(key) 与 loadedChildren 映射。

```javascript
function useTreeTable(fetchChildren) {
  const rows = ref([])                       // 扁平渲染行
  const expanded = reactive(new Set())       // 展开态
  const childrenMap = new Map()              // key -> child rows
  const loading = reactive(new Map())
  async function loadChildren(node) {
    if (childrenMap.has(node.key)) return childrenMap.get(node.key)
    loading.set(node.key, true)
    try {
      const kids = await fetchChildren(node)
      childrenMap.set(node.key, kids)
      return kids
    } finally { loading.set(node.key, false) }
  }
  async function toggle(key, node) {
    expanded.has(key) ? expanded.delete(key) : expanded.add(key)
    if (expanded.has(key)) await loadChildren(node)
    rebuild()
  }
  function rebuild() { // 从根展开态重建扁平行序
    const out = []
    const walk = (nodes, depth) => {
      for (const n of nodes) {
        out.push({ ...n, depth, hasChildren: n.hasChildren })
        if (expanded.has(n.key)) {
          const kids = childrenMap.get(n.key) || []
          walk(kids, depth + 1)
        }
      }
    }
    walk(rowsRoot.value, 0)
    rows.value = out
  }
  return { rows, expanded, toggle }
}
```
**评分点**：
- 展开态与数据分离（Set），刷新数据不丢展开态。
- 懒加载 + loading 态 + 缓存（childrenMap）。
- 扁平化 rebuild 带 depth 缩进信息。
- toggle 幂等（重复点击不重复请求，靠缓存短路）。
