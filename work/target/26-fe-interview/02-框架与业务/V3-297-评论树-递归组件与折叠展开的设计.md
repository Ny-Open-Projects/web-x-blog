## V3-297：评论树（递归组件）与折叠展开的设计怎么做？
**答**：
- 递归组件：`<CommentNode :node="node" />` 内部对 children 递归自身（name 递归或 import 自身），深度控制：超过 N 层折叠为"查看 x 条回复"跳转到平铺视图（避免 DOM 过深与样式混乱）。
- 折叠状态：Set<nodeId> 存折叠节点，折叠时渲染占位条（"已折叠 N 条回复，点击展开"）。
- 性能：千级评论树递归渲染会卡——渲染层只渲染当前展开的链路（扁平化数组 + depth 缩进，同树形表格方案），展开/折叠过滤数据而非卸载组件。
- 回复交互：回复框挂当前节点（就近渲染），提交后插入对应 children 并展开；被回复人 @ 引用。
- 排序与稳定：子节点按热度/时间排序可切换；排序变更不丢折叠状态（以 id 为 key）。

```typescript
// 深层树 → 扁平渲染列表（避免递归组件爆栈/DOM 深度）
const collapsed = reactive(new Set<string>());
function flattenComments(nodes, depth = 0, out = []) {
  for (const n of nodes) {
    out.push({ node: n, depth });
    if (collapsed.value.has(n.id)) {
      out.push({ type: 'fold', id: n.id, count: countDescendants(n) }); // 折叠占位
    } else {
      flattenComments(n.children ?? [], depth + 1, out);
    }
  }
  return out;
}
// 渲染：v-for="item in flattenComments" <Comment :style="{ marginLeft: item.depth * 24 + 'px' }" />
```
