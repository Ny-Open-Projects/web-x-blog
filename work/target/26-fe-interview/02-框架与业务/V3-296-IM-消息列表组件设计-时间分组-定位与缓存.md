## V3-296：IM 消息列表组件设计：时间分组、定位与缓存怎么做？
**答**：
- 结构：倒序渲染（新消息在底部）+ 虚拟滚动（历史消息可能上万条）；渲染模型用"有序消息数组 + 插入式时间分隔条"（相邻消息间隔 > 5 分钟插入）。
- 锚定策略：向上翻历史时新数据 **prepend 后保持滚动位置**（记录锚点消息 offset 修正 scrollTop）；新消息到达时，用户在底部才自动跟随，否则显示"N 条新消息"胶囊。
- 消息形态多态：文本/图片/撤回/系统消息按 type 渲染组件映射；长文本折叠（超过 500 字显示展开）。
- 状态同步：消息状态机（sending→sent→failed 可重发/已读回执）用 Map<localId, status> 管理乐观 ID。
- 缓存：会话消息本地缓存（IndexedDB 分页存储），断网时展示缓存并可离线查看。

```typescript
// 锚定：prepend 后保持视觉位置
function prependHistory(items) {
  const container = containerRef.value;
  const anchorMsg = list.value[0];
  const prevHeight = container.scrollHeight;
  const prevTop = container.scrollTop;
  list.value.unshift(...items);
  nextTick(() => {
    const delta = container.scrollHeight - prevHeight;
    container.scrollTop = prevTop + delta;               // 视觉无跳动
  });
}
// 时间分隔：渲染时插入，不污染数据
const renderList = computed(() => {
  const out = [];
  for (let i = 0; i < list.value.length; i++) {
    if (i === 0 || list.value[i].ts - list.value[i - 1].ts > 5 * 60_000)
      out.push({ type: 'time', ts: list.value[i].ts });
    out.push(list.value[i]);
  }
  return out;
});
```
