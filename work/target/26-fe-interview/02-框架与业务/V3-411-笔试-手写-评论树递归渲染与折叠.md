## V3-411：笔试：手写评论树（递归组件 + 折叠状态 + 扁平化）
**答**：给定评论树（children 数组），实现：1) `flattenTree(tree, collapsedSet)` 返回带 depth 的扁平渲染行（折叠的子树不展开）；2) toggle(id) 切换折叠；3) 回复时插入到目标节点 children 并刷新；防止数据环导致死递归（visited 检查）。

```javascript
function flattenTree(nodes, collapsedSet, depth = 0, out = []) {
  for (const n of nodes) {
    if (collapsedSet.has(n.id)) { out.push({ ...n, depth, hasChildren: n.children?.length > 0 }); continue }
    out.push({ ...n, depth, hasChildren: n.children?.length > 0 })
    if (n.children?.length) flattenTree(n.children, collapsedSet, depth + 1, out)
  }
  return out
}
function useComments(root) {
  const collapsed = reactive(new Set())
  const rows = computed(() => flattenTree(root.value, collapsed))
  const toggle = (id) => collapsed.has(id) ? collapsed.delete(id) : collapsed.add(id)
  function reply(targetId, comment) {
    const target = findNode(root.value, targetId)
    if (!target) throw new Error('target not found')
    ;(target.children ||= []).push({ ...comment, children: [] })
    collapsed.delete(targetId) // 回复后自动展开
  }
  return { rows, toggle, reply }
}
```
**评分点**：
- 折叠语义：折叠节点自身仍渲染，子树整体隐藏（不是删节点）。
- computed 派生行列表，折叠状态独立于数据。
- 回复插树 + 自动展开，边界（找不到 target）处理。
- 能指出后端数据成环时需 parentId 一致性校验。
