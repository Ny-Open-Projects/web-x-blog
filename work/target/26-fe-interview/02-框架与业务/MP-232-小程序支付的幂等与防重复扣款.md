## MP-232：支付防重复扣款？
**答**：
- 下单幂等：requestId 唯一键，服务端同 requestId 返回同一订单（不重复创建）。
- 支付中锁定：requestPayment 期间禁用按钮 + 订单状态「支付中」；服务端同订单的重复 prepay 调用返回原 prepay_id。
- 回调幂等：notify 按 transaction_id/订单号去重表（唯一索引 + 事务），重复通知返回成功但不重复入账。
- 对账兜底：定时任务比对「支付中超时未回调」订单，调查询订单 API 收敛状态；退款流程独立幂等。
- 前端兜底：支付结果页轮询状态而非本地推断——「成功」只认服务端。
