## V3-446：笔试：手写路由级代码分割与预加载策略（闲时 + hover 双通道）
**答**：实现预加载策略：1) 高频路由在 requestIdleCallback 时预取 chunk；2) 全部路由 hover 预取（幂等）；3) 用 link rel=modulepreload 标记已预取；4) 低优先级路由永不预取（配置 exclude）。

```javascript
const preloaded = new Set()
function prefetch(name) {
  const route = routeMap[name]
  if (!route || preloaded.has(name) || route.exclude) return
  preloaded.add(name)
  // import() 返回 module，触发 chunk 下载
  route.component().catch(() => preloaded.delete(name)) // 失败允许重试
}
function idlePrefetch(names) {
  const run = (deadline) => {
    for (const name of names) {
      if (deadline.timeRemaining() <= 0) { requestIdleCallback(run); return }
      prefetch(name)
    }
  }
  'requestIdleCallback' in window ? requestIdleCallback(run) : setTimeout(() => names.forEach(prefetch), 2000)
}
// 初始化：idlePrefetch(['home', 'detail'])
// hover：@mouseenter="prefetch('detail')"
```
**评分点**：
- 幂等集合 preloaded + 失败回滚。
- requestIdleCallback 分时消费（超时让位主线程）。
- exclude 低优先级配置。
- 失败重试能力（delete 后可再 prefetch）。
