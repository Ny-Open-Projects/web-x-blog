## V3-310：如何给响应式系统写性能回归测试？
**答**：
- 基准维度分三类：依赖收集开销（冷启动建链）、trigger 开销（热更新）、内存（heap 增长）。分别设计 micro benchmark。
- 典型用例：10 万项数组的索引遍历收集；高频 trigger（每帧改 1000 个 ref）下 effect 调度耗时；computed 链式依赖的重复触发次数断言。
- 用 `performance.now()` 统计多轮取中位数；逻辑正确性断言放在 vitest 单测里，基准测试只看趋势防回归。
- 对比基线：把结果落盘成 JSON，与上一版本对比，超过阈值（如 +15%）CI 报警。
- Vue 仓库自带的 `bench/` 目录思路可以借鉴：npm script 跑基准 + 输出表格。
```javascript
const arr = reactive(Array.from({ length: 100000 }, (_, i) => i))
let sum = 0
const t0 = performance.now()
effect(() => { sum = arr.reduce((a, b) => a + b, 0) })  // 收集
for (let i = 0; i < 100; i++) arr[i] = i * 2           // 触发
console.log('trigger cost:', performance.now() - t0)
```
