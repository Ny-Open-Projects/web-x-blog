## R19-288：RSC 的安全模型：为什么服务端代码不泄露？
**答**：
- 服务端组件代码不进客户端 bundle：DB SDK、密钥、内部 URL 只存在于服务端模块。
- 数据下发是「渲染结果」：只有显式放入 UI 的数据进 payload——忘记下发的敏感字段不会意外进 bundle（对比 CSR 把密钥误打包）。
- Server Action 的暴露面：仅 action 函数可被调用（带签名 id），服务端内部函数不可达；但仍要按公开端点做鉴权/限流。
- 反面教材：在客户端组件里 import 服务端工具（含密钥逻辑）会破坏边界——构建器会报错或意外打包。
- 面试表达：安全模型 = 「代码位置即信任边界」，加上「渲染产物即数据下发」。
