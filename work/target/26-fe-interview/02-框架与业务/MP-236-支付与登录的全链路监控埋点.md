## MP-236：支付与登录的监控埋点设计？
**答**：
- 支付漏斗：下单提交 → prepay 成功 → 收银台拉起 → 支付回调确认 → 结果页——每步埋 success/fail/cancel + 耗时，转化漏斗定位流失（拉起失败率/取消率）。
- 登录漏斗：wx.login → code2Session → token 签发 → 首个带凭证请求——失败码分布（code 过期/网络/风控）。
- 唯一链路 ID：traceId 贯穿前端埋点与服务端日志，跨端排查。
- 告警阈值：支付成功率 < 98%、code2Session 错误率突增——分级告警（企业微信/钉钉）。
- 采样策略：失败全采、成功 1% 采样控制上报量。
