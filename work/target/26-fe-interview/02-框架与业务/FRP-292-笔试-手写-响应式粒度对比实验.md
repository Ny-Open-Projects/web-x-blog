## FRP-292：笔试：手写响应式粒度对比实验
**题**：设计并实现一个可运行的对比实验：1000 个单元格，改 1 个值。方案 A（组件级）：整个网格重渲染（记 renderCount）；方案 B（表达式级）：只有目标单元格更新。断言 A.renderCount=1 且 B=0（不触发渲染）；输出两种方案耗时。

```javascript
// 方案 B：细粒度 signal + 单元格绑定
const cells = Array.from({ length: 1000 }, (_, i) => createSignal(i))
function bindCell(el, sig) {
  const update = () => { el.textContent = sig.get() }
  effect(update) // 只有该单元格订阅
  update()
}
function updateCell(i, v) { cells[i].set(v) } // 只通知一个订阅者

// 方案 A：组件级
let renderCount = 0
function ComponentLevelGrid() {
  renderCount++                       // 每次状态变化整网格重跑
  return `<div>${cells.map(c => `<span>${c.get()}</span>`).join('')}</div>`
}
// 实验：updateCell(500, 9999) → A: renderCount 0→1，重渲染 1000 个 span
//                      B: 1 个 span 更新，0 次网格渲染
console.time('A'); ComponentLevelGrid(); console.timeEnd('A')
console.time('B'); updateCell(500, 9999); console.timeEnd('B')
```
**评分点**：
- 实验设计能证明粒度差异（计数器/耗时双指标）。
- B 方案单点订阅正确（其余 999 个无感知）。
- 能解释为什么 B 的更新是 O(1) 而 A 是 O(n)。
- 结论迁移：React 重渲染模型 = A，Solid/Vapor = B。
