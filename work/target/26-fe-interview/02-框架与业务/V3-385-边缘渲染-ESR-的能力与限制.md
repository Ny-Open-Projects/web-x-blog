## V3-385：边缘渲染（ESR）的能力与限制是什么？
**答**：
- 形态：Nuxt 构建到边缘运行时（Cloudflare Workers/Vercel Edge），SSR 在离用户最近的节点执行，TTFB 显著下降。
- 能力：请求级缓存（KV）、A/B 分流、个性化边缘注入、地理路由。
- 限制：无长驻内存（无进程内缓存/连接池）、CPU 时间受限（重计算要挪到区域服务）、部分 Node API 不可用（fs、部分 crypto）。
- 适配要点：数据访问走 HTTP 化后端或边缘 KV；重渲染组件拆分减少边缘 CPU；session 用无状态 JWT。
- 决策：全球分布用户 + 动态内容 → ESR 收益大；单地区 + 重业务逻辑 → 区域容器更稳。
