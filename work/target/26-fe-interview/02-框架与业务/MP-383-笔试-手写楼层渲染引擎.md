## MP-383：笔试：手写楼层渲染

**答**：实现配置驱动首页：① 楼层注册表 `registerFloor(type, comp)` + 页面 WXML 动态渲染（component-placeholder 模式——小程序不支持动态 component is，用 block + wx:if 枚举或抽象节点 generictyping）；② 楼层数据隔离（每楼层独立 payload——一层数据异常不影响其他层渲染）；③ 楼层埋点统一（注册时自动注入曝光 Behavior）；④ 未知类型过滤 + 上报（配置错误监控）；⑤ 楼层顺序/样式参数由配置驱动。写出实现（抽象节点方案）。

```json
// floor.json (抽象节点)
{ "componentGenerics": { "floor": true } }
```

```xml
<!-- index.wxml 使用抽象节点 -->
<floor-floor wx:for="{{floors}}" wx:key="id" is="{{item.type}}" payload="{{item.payload}}" />
<!-- generictypes 映射: "floor-floor": "banner-floor" → app.json 或页面 json generictypes -->
```

```javascript
// 注册表 + 容错
const FLOORS = new Map();
export function registerFloor(type, comp) {
  comp.behaviors = [...(comp.behaviors ?? []), exposureBehavior];   // 自动注入曝光
  FLOORS.set(type, comp);
}
// 页面: 配置过滤 + 监控
async function loadFloors() {
  const fresh = await api.floors('home');
  const valid = [], unknown = [];
  for (const f of fresh) (FLOORS.has(f.type) ? valid : unknown).push(f);
  if (unknown.length) track('config-error', { unknown: unknown.map((f) => f.type) });
  this.setData({ floors: valid });
}
// 楼层组件内: payload 异常 → try/catch 降级占位(不白屏)
```

**评分点**：
- 抽象节点（componentGenerics）实现「动态组件」的小程序正解
- 曝光 Behavior 自动注入（注册时统一）
- 未知类型过滤 + 监控上报（配置错误可见）
- 楼层数据隔离与容错（单层异常不白屏）
