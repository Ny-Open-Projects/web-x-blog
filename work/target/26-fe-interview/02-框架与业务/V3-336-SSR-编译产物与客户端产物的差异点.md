## V3-336：SSR 编译产物与客户端 render 产物有什么差异？
**答**：
- SSR 版编译成 `ssrRender(ctx, push)`：不创建 vnode，直接往字符串缓冲 push HTML 片段，性能远高于「客户端 render + 序列化」。
- 动态文本用 `push(_toDisplayString(...))`，事件绑定、ref 等纯客户端信息在 SSR 产物中被剔除。
- 子组件调用变为 `ssrRenderComponent`，插槽是函数逐段渲染；Suspense/Teleport/Transition 有专门 ssr 分支处理。
- 指令与静态提升的产物形态不同：SSR 中静态内容直接拼字符串，无需 hoisted vnode。
- 客户端水合用普通 render 产物 + hydrate，两者共享同一模板源但编译目标不同，这就是同一 SFC 会产出两套代码的原因。
