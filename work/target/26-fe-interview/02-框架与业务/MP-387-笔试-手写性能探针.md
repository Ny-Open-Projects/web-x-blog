## MP-387：笔试：手写性能探针

**答**：实现页面性能探针 Behavior：① 页面启动：onLoad→onReady 耗时（首屏渲染）+ onLoad→首次 setData 回调（数据到达）；② setData 统计：次数/单次大小/累计大小/频率（包装页面 setData）；③ 分位数聚合（P50/P75/P95 按页面维度）；④ 上报策略：页面 onHide 时汇总上报 + 采样（10% 页面全量）；⑤ 与 wx.getPerformance 官方指标的合并口径。写出实现。

```javascript
export const perfBehavior = Behavior({
  lifetimes: {
    attached() {
      this._perf = { loadAt: 0, readyAt: 0, dataAt: 0, setData: { n: 0, bytes: 0, ms: [] } };
    },
  },
  pageLifetimes: {
    show() { this._perf.loadAt = Date.now(); },
  },
  methods: {
    markReady() {
      this._perf.readyAt = Date.now();
      beacon({ type: 'page-boot', route: this.route,
        onLoadToReady: this._perf.readyAt - this._perf.loadAt,
        onLoadToData: this._perf.dataAt - this._perf.loadAt });
    },
    wrapSetData(orig) {
      const self = this;
      return function (data, cb) {
        const size = JSON.stringify(data).length;
        const t0 = Date.now();
        orig.call(this, data, () => {
          const ms = Date.now() - t0;
          const p = self._perf.setData;
          p.n++; p.bytes += size; p.ms.push(ms);
          self._perf.dataAt ||= Date.now();          // 首次数据到达
          cb?.();
        });
      };
    },
    reportOnHide() {
      const { ms } = this._perf.setData;
      const sorted = [...ms].sort((a, b) => a - b);
      beacon({ type: 'page-perf', route: this.route, sample: Math.random() < 0.1,
        setDataN: ms.length, setDataBytes: this._perf.setData.bytes,
        p50: sorted[Math.floor(ms.length / 2)], p95: sorted[Math.floor(ms.length * 0.95)] });
    },
  },
});
// 官方指标合并: wx.getPerformance().createObserver → appLaunch/route/render 事件与自建指标同看板
```

**评分点**：
- 双锚点计时（onLoad→onReady 与 首次 setData 回调）
- setData 包装统计（次数/大小/耗时——通信成本可见）
- 分位数聚合 + onHide 汇总上报 + 采样
- 与官方 getPerformance 指标的合并口径
