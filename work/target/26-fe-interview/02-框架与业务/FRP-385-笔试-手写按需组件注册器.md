## FRP-385：笔试：手写按需组件注册器

**答**：实现跨框架组件按需注册：① `registry.define(name, { react: loader, vue: loader, styles: loader })`：双框架组件的懒加载描述；② `registry.load(name, framework)`：返回组件 promise（去重缓存——同 name+framework 单例）；③ 样式随组件注入（幂等——FRP-355 协议）；④ 预取接口（空闲期预载高频组件——按框架区分）；⑤ 注册表元信息导出（哪些组件/哪些框架已注册——文档生成）。写出实现。

```javascript
const registry = (() => {
  const defs = new Map();
  const cache = new Map();     // `${name}:${fw}` -> promise
  const injectedStyles = new Set();

  function define(name, def) { defs.set(name, def); }

  async function load(name, framework) {
    const def = defs.get(name);
    if (!def) throw new Error(`unknown component: ${name}`);
    const key = `${name}:${framework}`;
    if (!cache.has(key)) {
      cache.set(key, (async () => {
        const [comp, styleMod] = await Promise.all([
          def[framework](),
          def.styles?.() ?? Promise.resolve(null),
        ]);
        const css = styleMod?.default;
        if (css && !injectedStyles.has(name)) {      // 样式幂等注入(跨框架共享)
          const sheet = new CSSStyleSheet();
          sheet.replaceSync(css);
          document.adoptedStyleSheets = [...document.adoptedStyleSheets, sheet];
          injectedStyles.add(name);
        }
        return comp.default ?? comp;
      })());
      cache.get(key).catch(() => cache.delete(key)); // 失败可重试
    }
    return cache.get(key);
  }
  function prefetch(names, framework) {
    requestIdleCallback?.(() => names.forEach((n) => load(n, framework).catch(() => {})));
  }
  function meta() { return [...defs.entries()].map(([name, d]) => ({ name, frameworks: Object.keys(d).filter((k) => k !== 'styles') })); }
  return { define, load, prefetch, meta };
});
// 用法: registry.define('Table', { react: () => import('./table.react'), vue: () => import('./table.vue'), styles: () => import('./table.css') })
```

**评分点**：
- 双框架 loader 的懒加载单例缓存（key 含框架）
- 样式幂等注入且跨框架共享（不重复加载）
- 失败清缓存可重试 + idle 预取
- meta 导出（文档/监控消费）
