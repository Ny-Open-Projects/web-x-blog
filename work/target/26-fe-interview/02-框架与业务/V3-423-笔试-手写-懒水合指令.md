## V3-423：笔试：手写「懒水合」组件包装器（进入视口才激活交互）
**题**：实现 `LazyHydrate` 组件：包一层 IntersectionObserver，未进入视口时渲染静态占位（不挂载真实子组件），进入后挂载子组件并断开观察；提供 `whenIdle` 模式（空闲时也激活）；卸载清理 observer。

```javascript
const LazyHydrate = defineComponent({
  props: { whenIdle: Boolean },
  setup(props, { slots }) {
    const hydrated = ref(false)
    const el = ref(null)
    let ob = null
    function activate() { if (!hydrated.value) { hydrated.value = true; ob?.disconnect() } }
    onMounted(() => {
      if (props.whenIdle && 'requestIdleCallback' in window) {
        requestIdleCallback(activate)
        return
      }
      ob = new IntersectionObserver((entries) => {
        entries.forEach(en => en.isIntersecting && activate())
      }, { rootMargin: '200px' })
      ob.observe(el.value)
    })
    onBeforeUnmount(() => ob?.disconnect())
    return () => hydrated.value
      ? slots.default?.()
      : h('div', { ref: el, 'data-hydrate': 'pending' }, slots.placeholder?.())
  }
})
// 用法：<LazyHydrate><HeavyChart :data="data"/></LazyHydrate>
```
**评分点**：
- IntersectionObserver rootMargin 预加载缓冲。
- activate 幂等 + disconnect 清理。
- whenIdle 用 requestIdleCallback 兜底。
- 未水合阶段渲染 placeholder（区分 pending 状态标记）。
