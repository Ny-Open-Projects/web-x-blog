## FRP-370：笔试：手写跨框架事件桥

**答**：实现跨框架事件桥 `createBridge(namespace)`：① 基于 CustomEvent（bubbles + composed，跨 shadow/root 边界）；② emit(type, detail) / on(type, handler)（事件名自动加 namespace 前缀防冲突）；③ schema 校验（type → validator 注册，非法 detail 拒发并告警）；④ 节流选项（高频 type 合帧：windowMs 内合并保最后值）；⑤ 消息溯源（detail 带 __source 与 __ts）。写出实现。

```javascript
export function createBridge(namespace, schemas = {}) {
  const el = document.body;                          // 桥挂载点
  const pendingThrottle = new Map();

  function emit(type, detail, { throttleMs = 0 } = {}) {
    const full = `${namespace}:${type}`;
    const validator = schemas[type];
    if (validator && !validator(detail)) {            // schema 拒发
      console.warn(`[bridge] invalid payload for ${full}`, detail);
      return false;
    }
    const payload = { detail, __source: namespace, __ts: Date.now() };
    if (!throttleMs) return el.dispatchEvent(new CustomEvent(full, { detail: payload, bubbles: true, composed: true }));
    // 合帧: 窗口内保最后值
    const p = pendingThrottle.get(type) ?? pendingThrottle.set(type, { payload, timer: null }).get(type);
    p.payload = payload;
    if (!p.timer) p.timer = setTimeout(() => {
      pendingThrottle.delete(type);
      el.dispatchEvent(new CustomEvent(full, { detail: p.payload, bubbles: true, composed: true }));
    }, throttleMs);
    return true;
  }

  function on(type, handler) {
    const full = `${namespace}:${type}`;
    el.addEventListener(full, handler);
    return () => el.removeEventListener(full, handler);
  }
  return { emit, on, define: (type, validator) => { schemas[type] = validator; } };
}
// 协议约定: 事件名 ns:type / detail 带 __source 溯源 / schema 校验前置
```

**评分点**：
- composed + bubbles 跨边界（shadow/root 语义）
- namespace 前缀防冲突 + schema 校验前置（脏消息不进系统）
- 合帧选项与保最后值语义
- 溯源字段（source/ts）的调试价值
