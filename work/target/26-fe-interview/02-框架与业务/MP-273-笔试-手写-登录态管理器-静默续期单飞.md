## MP-273：笔试：手写登录管理器
**题**：实现 AuthManager：login() 拿 code → code2Session 换 token 存 storage；request() 包装 wx.request——401 时触发单飞重登（并发请求共享同一 promise），完成后重放原请求；重登上限 2 次跳登录页。

```javascript
class AuthManager {
  constructor() { this.reloginPromise = null; this.reloginCount = 0 }
  async login() {
    const { code } = await wx.login()
    const { token } = await wx.request({ url: '/api/login', data: { code }, method: 'POST' })
    wx.setStorageSync('token', token)
    this.reloginCount = 0
    return token
  }
  async request(options) {
    const res = await wx.request({ ...options, header: { ...options.header, token: wx.getStorageSync('token') } })
    if (res.statusCode === 401) {
      this.reloginPromise ||= this.login().finally(() => { this.reloginPromise = null })
      await this.reloginPromise
      if (++this.reloginCount > 2) { wx.navigateTo({ url: '/pages/login' }); throw new Error('登录失效') }
      return this.request(options) // 重放
    }
    if (res.statusCode >= 400) throw new Error(res.data?.msg || '请求失败')
    return res.data
  }
}
```
**评分点**：
- 单飞锁（reloginPromise 共享）是核心得分点。
- 重放原请求（新 token）。
- 上限保护 + 跳登录页。
- finally 清锁，防死锁。
