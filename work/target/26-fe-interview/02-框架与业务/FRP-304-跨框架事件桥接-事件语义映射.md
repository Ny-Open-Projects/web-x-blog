## FRP-304：跨框架事件桥接：事件语义映射与冒泡规则

**答**：
- 事件桥接的问题域：React 的合成事件 vs Vue 的原生绑定 vs 原生事件——跨边界的事件流（谁冒泡、preventDefault 谁处理）
- DOM 事件是通用语言：跨框架边界统一用「原生 DOM 事件 + CustomEvent detail」——合成事件不跨界（React 17+ 事件委托在 root 上，跨 root 不冒泡合成层）
- React → Vue 通信：React 组件在容器上 dispatchEvent(new CustomEvent('cart:add', { detail, bubbles: true }))——Vue 侧 addEventListener 消费；反之同理
- 冒泡与 composed：跨 shadow DOM 边界需要 composed: true——事件协议要写进桥接规范（事件名/detail 结构/是否冒泡）
- 性能与一致性：高频事件（scroll/mousemove）跨界节流——桥接层统一 rAF 合帧，避免两侧各处理一次

```javascript
// React 侧发事件(跨界桥)
function useBridgeEmit(type) {
  const ref = useRef(null);
  const emit = (detail) => ref.current?.dispatchEvent(
    new CustomEvent(type, { detail, bubbles: true, composed: true }));
  return [ref, emit];
}
// Vue 侧消费
onMounted((el) => {
  const handler = (e) => cart.add(e.detail);
  el.addEventListener('cart:add', handler);
  onUnmounted(() => el.removeEventListener('cart:add', handler));
});
```
