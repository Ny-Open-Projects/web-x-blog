## V3-277：表单字段联动出现循环依赖/抖动怎么治理？
**答**：
- 典型症状：A 变化触发 B 重算，B 又写回 A，形成振荡（值闪跳、校验无限触发）。
- 治理原则 1 单向数据流：联动只允许"源字段 → 目标字段"方向写，禁止目标回写源（双绑关系改成单一权威源 + 派生）。
- 治理原则 2 幂等写入：目标字段写入前比较新旧值，相等则跳过，天然截断循环。
- 治理原则 3 声明优先：visible/disabled/options 联动全部用声明式表达式由引擎统一计算（每轮只算一遍），替代链式 watch。
- 调试手段：给联动引擎加 trace 日志（谁触发谁、写入了什么值），循环一眼可见；必要时加最大跳数熔断并上报。

```typescript
// 引擎统一计算：每轮输入一次模型快照，产出所有派生状态，杜绝链式触发
function computeDerived(model) {
  const derived = {};
  for (const rule of linkageRules) {
    const next = rule.compute(model, derived);   // 只读 model，写 derived
    // 幂等写回：值没变不触发响应式更新，截断振荡
    if (!isSameValue(model[rule.field], next)) queuePatch(rule.field, next);
  }
  return derived;
}
// 反例：链式 watch 互相写
// watch(() => form.a, v => form.b = v * 2)
// watch(() => form.b, v => form.a = v / 2)  // ❌ 循环
// 正例：a 是权威源，b 是派生
// const b = computed(() => form.a * 2)      // 只读派生，不可写
```
