## FRP-281：笔试：手写最长递增子序列
**答**：实现 `lis(arr)`：返回最长严格递增子序列（值）与对应索引序列；O(n log n)；用于 diff 的最少移动判定场景验证。

```javascript
function lis(arr) {
  const n = arr.length
  if (!n) return { values: [], indices: [] }
  const tails = []      // tails[k] = 长度为 k+1 的子序列最小尾值
  const tailIdx = []    // 对应索引
  const prev = new Array(n).fill(-1)
  for (let i = 0; i < n; i++) {
    const x = arr[i]
    let lo = 0, hi = tails.length
    while (lo < hi) { const mid = (lo + hi) >> 1; tails[mid] < x ? lo = mid + 1 : hi = mid }
    if (lo === tails.length) { tails.push(x); tailIdx.push(i) } else { tails[lo] = x; tailIdx[lo] = i }
    prev[i] = lo > 0 ? tailIdx[lo - 1] : -1
  }
  const indices = []
  let cur = tailIdx[tailIdx.length - 1]
  while (cur > -1) { indices.unshift(cur); cur = prev[cur] }
  return { values: indices.map(i => arr[i]), indices }
}
// lis([2,0,3,1,6]) → { values:[0,1,6], indices:[1,3,4] }
```
**评分点**：
- tails 数组 + 二分替换（贪心正确性：同长度尾值越小越好）。
- prev 回溯还原完整序列（只回长度不行）。
- 复杂度 O(n log n)。
- 能说出 diff 场景输入是「新顺序中的旧索引」数组。
