## FRP-318：框架无关的表单内核

**答**：
- 表单内核的状态模型：values/errors/touched/status 三态——纯 JS 实现（值变更 → 触发校验 → 通知订阅），框架层只绑定
- 校验协议：字段级（async validator）+ 表单级（跨字段规则）+ 依赖校验（字段 A 校验依赖字段 B 值——值变更时重校验关联字段）
- 与各框架绑定的差异点：受控语义（React 的 controlled input / Vue 的 v-model）——内核只发「值变更事件」，绑定层转成各框架习惯
- 提交流程统一：validate all → focus first error → submit lock → optimistic/幂等提交——跨框架行为一致的关键（业务验收点）
- 成本评估：表单逻辑复杂（动态 schema/跨字段联动）才值得内核化；简单表单直接用各框架生态（React Hook Form/vee-validate）

```javascript
// 框架无关表单内核
export function createForm({ initial, validators }) {
  let values = { ...initial }, errors = {}, touched = {};
  const subs = new Set();
  const notify = () => subs.forEach((f) => f(snapshot()));
  async function setField(name, v) {
    values = { ...values, [name]: v };
    if (validators[name]) errors = { ...errors, [name]: await validators[name](v, values) };
    notify();
  }
  async function submit() {
    const all = await Promise.all(Object.entries(validators).map(([n, f]) => f(values[n], values)));
    const bad = Object.keys(validators).find((_, i) => all[i]);
    if (bad) return { ok: false, field: bad };
    return { ok: true, values };
  }
  function snapshot() { return { values, errors, touched }; }
  return { setField, submit, sub(fn) { subs.add(fn); return () => subs.delete(fn); }, snapshot };
}
```
