## V3-227：自定义指令的编译产物是什么？各生命周期钩子在什么时机触发？
**答**：
- 编译产物：模板上的 `v-focus` 编译为 vnode 的 `directives: [focusDirective]` 数组（Vapor 下编译为 `withDirectives` 调用），运行时在 patch 流程中统一挂载/调用钩子。
- 钩子映射：指令对象直接复用组件生命周期名——`created→beforeMount→mounted→beforeUpdate→updated→beforeUnmount→unmounted`。
- 触发时机：mounted 类钩子在**元素挂载到 DOM 后**（含子树 patch 完成）；updated 钩子在包含**子组件更新后**的时机触发。
- 参数：钩子入参 `(el, binding)`，binding 含 value/oldValue/arg/modifiers，`v-my="x"` 的 value 变化才触发 updated 钩子。
- 边界：指令操作 el 时注意 SSR 不执行 mounted 钩子（服务端无 DOM），需要 SSR 兼容的指令用 getSSRProps。

```javascript
// 指令 v-permission="'admin'" 编译产物（示意）
createVNode("button", { onClick: del }, "删除", 64, null, [
  [{ dir: Permission, arg: undefined, modifiers: {}, value: 'admin' }],
]);
const Permission = {
  mounted(el, { value }) { if (!hasRole(value)) el.parentNode?.removeChild(el); },
  updated(el, { value, oldValue }) { if (value !== oldValue) toggle(el, hasRole(value)); },
};
// withDirectives(vnode, directives) 运行时包装：
// mountElement 内：for (const [dir] of dirs) dir.mounted?.(el, binding)
```
