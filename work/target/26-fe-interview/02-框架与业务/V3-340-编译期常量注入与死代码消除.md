## V3-340：编译期常量注入（import.meta.env 等）与死代码消除怎么配合？
**答**：
- Vite 在构建期把 `import.meta.env.MODE/PROD/自定义 VITE_*` 替换为字面量，随后 esbuild/terser 对 `if (false)` 分支做 DCE。
- Vue 内部用 `__VUE_PROD_DEVTOOLS__`、`__VUE_OPTIONS_API__`、`__VUE_PROD_HYDRATION_MISMATCH_DETAILS__` 等全局常量做特性开关，打包时摇掉对应代码。
- 应用：业务里 `if (import.meta.env.DEV) reportDebug()` 生产产物自动剔除；功能灰度用「构建变量」而非运行时判断可省体积。
- 注意：动态访问（`import.meta.env[key]`）无法静态替换，必须写字面量 key。
- Vue 特性开关需要 define 配置补全，漏配会出现「生产包体积异常大」或 hydration 详情未关闭。
```javascript
// vite.config.ts
define: { __VUE_OPTIONS_API__: false, __VUE_PROD_DEVTOOLS__: false }
```
