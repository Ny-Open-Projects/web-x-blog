## R19-349：笔试：手写拖拽双通道更新
**题**：拖拽排序：被拖元素的视觉位置（transform 跟随鼠标）用同步 state（每帧更新必须流畅）；列表顺序变化（插入位判定）用低优 transition；松手后提交最终顺序（action）。

```javascript
function DragList({ list, reorderAction }) {
  const [dragPos, setDragPos] = useState(null)      // { x, y } 同步高频
  const [order, setOrder] = useState(list)
  function onPointerMove(e) {
    setDragPos({ x: e.clientX, y: e.clientY })      // Sync：视觉跟随
    const target = hitTest(e.clientX, e.clientY)
    if (target !== draggingIndex) {
      startTransition(() => {                       // 低优：顺序重排
        const [moved] = order.splice(draggingIndex, 1)
        order.splice(target, 0, moved)
        setOrder([...order])
        draggingIndex = target
      })
    }
  }
  function onPointerUp() {
    startTransition(async () => { await reorderAction(order.map(i => i.id)) })
    setDragPos(null)
  }
  return (
    <ul>
      {order.map((item, i) => (
        <li key={item.id}
          style={i === draggingIndex ? { transform: `translate(${dragPos?.x}px, ${dragPos?.y}px)` } : null}>
          {item.title}
        </li>
      ))}
    </ul>
  )
}
```
**评分点**：
- 双通道设计：视觉跟随 Sync、重排 transition（核心架构点）。
- hitTest 变化才触发低优重排（不是每帧）。
- 松手提交最终顺序（幂等全量顺序）。
- transition 内 splice + setOrder([...]) 的不可变说明。
