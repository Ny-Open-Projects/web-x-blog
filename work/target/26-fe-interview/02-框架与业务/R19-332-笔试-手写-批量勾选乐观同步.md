## R19-332：笔试：手写购物车批量勾选的乐观同步
**答**：实现 CartList：勾选 checkbox 立即更新 UI（乐观）；批量确认按钮把所有变更一次 action 提交；服务端返回逐项结果 { id, ok }，失败项回滚为 unchecked 并提示。

```javascript
function CartList({ items, syncAction }) {
  const [optimistic, addOptimistic, clear] = useOptimistic(
    items,
    (list, op) => list.map(it => it.id === op.id ? { ...it, checked: op.checked } : it)
  )
  const [failed, setFailed] = useState(new Set())
  function onToggle(id, checked) {
    addOptimistic({ id, checked })
    startTransition(async () => {
      const res = await syncAction([{ id, checked }]) // 单项即时同步
      if (!res.ok) setFailed(new Set([...failed, id]))
    })
  }
  const selected = optimistic.filter(i => i.checked)
  return (
    <div>
      <p>已选 {selected.length} 件，合计 ¥{selected.reduce((s, i) => s + i.price, 0)}</p>
      {optimistic.map(i => (
        <label key={i.id}>
          <input type="checkbox" checked={i.checked && !failed.has(i.id)}
            onChange={e => onToggle(i.id, e.target.checked)} />
          {i.title} {failed.has(i.id) && <span style={{color:'red'}}>同步失败</span>}
        </label>
      ))}
    </div>
  )
}
```
**评分点**：
- 乐观 toggle 单项 map 更新（不重建列表语义）。
- 派生值（数量/合计）由乐观列表计算（即时反馈）。
- 失败逐项修正（Set 记录 + UI 标记）。
- 单项即时提交 vs 批量提交的取舍能说清。
