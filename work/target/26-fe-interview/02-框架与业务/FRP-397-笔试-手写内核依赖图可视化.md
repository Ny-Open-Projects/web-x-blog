## FRP-397：笔试：手写依赖图可视化

**答**：实现响应式内核的依赖图工具：① 图构建：signal/computed/effect 节点 + 边（依赖方向）——从内核登记表导出；② 环检测：DFS 找 computed 循环依赖（a = computed(b), b = computed(a)）——报环路径；③ 可视化输出：DOT 语言（graphviz 可渲染）+ Mermaid 两种格式；④ 热点分析：入度最高的节点（被最多 effect 依赖的 signal——变更影响面）；⑤ 死节点：无出边无入边的 effect（可能泄漏）。写出实现。

```javascript
export function buildDepGraph(registry) {            // registry: 内核登记的节点
  const nodes = new Map();                           // id -> { type, label }
  const edges = [];                                  // [from, to] (依赖方向: from→to 被依赖)
  for (const [id, node] of registry) {
    nodes.set(id, { type: node.kind, label: node.name });
    for (const depId of node.deps) edges.push([depId, id]);   // dep → 依赖它的节点
  }
  return { nodes, edges };
}
export function detectCycle(graph) {
  const state = new Map();                           // 0 未访问 1 访问中 2 完成
  const stack = [];
  function dfs(id) {
    if (state.get(id) === 2) return null;
    if (state.get(id) === 1) {
      const start = stack.indexOf(id);
      return [...stack.slice(start), id];            // 环路径
    }
    state.set(id, 1); stack.push(id);
    for (const [from, to] of graph.edges) {
      if (from === id) { const c = dfs(to); if (c) return c; }
    }
    stack.pop(); state.set(id, 2);
    return null;
  }
  for (const id of graph.nodes.keys()) { const c = dfs(id); if (c) return c; }
  return null;
}
export function toDot(graph) {
  const lines = ['digraph deps {'];
  for (const [id, n] of graph.nodes) lines.push(`  "${id}" [label="${n.label}" shape=${n.type === 'effect' ? 'box' : 'ellipse'}]`);
  for (const [from, to] of graph.edges) lines.push(`  "${from}" -> "${to}"`);
  lines.push('}');
  return lines.join('\n');
}
export function hotspots(graph, top = 5) {           // 入度 = 影响面
  const inDeg = new Map();
  for (const [, to] of graph.edges) inDeg.set(to, (inDeg.get(to) ?? 0) + 1);
  return [...inDeg.entries()].sort((a, b) => b[1] - a[1]).slice(0, top);
}
```

**评分点**：
- 图构建的方向语义（依赖 vs 订阅者）
- DFS 三色环检测并输出路径
- DOT/Mermaid 双格式输出（工具生态）
- 热点（入度=影响面）与死节点分析
