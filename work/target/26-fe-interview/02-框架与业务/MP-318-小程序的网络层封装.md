## MP-318：小程序网络层封装：request 统一网关

**答**：
- 统一封装四件套：baseUrl 分环境（开发/体验/生产）、token 注入（Authorization + 401 重登重放）、错误归一（网络错误/HTTP 错/业务码三分类）、埋点（耗时/失败率）
- 小程序特有约束：并发上限（wx.request 最多 10 个并发——超限排队）、域名白名单（request 合法域名——开发工具勾选「不校验」仅限开发）
- 401 重登重放：token 失效 → ensureToken() 重新 login → 重放原请求（幂等方法才重放；写操作用幂等键）——登录与请求层的组合
- 超时与重试：wx.request timeout 默认 60s（太长）——按接口分级（列表 5s/支付查询 15s）；重试带退避
- 深水点：请求队列的并发治理——高峰页（瀑布流图片列表）与核心接口抢并发额度：核心接口直发，图片走 wx.downloadFile 排队

```javascript
const queue = []; let flying = 0; const MAX = 8;   // 留 2 个额度给核心
function enqueue(opts) {
  return new Promise((resolve, reject) => {
    queue.push({ opts, resolve, reject });
    drain();
  });
}
async function drain() {
  while (flying < MAX && queue.length) {
    const { opts, resolve, reject } = queue.shift();
    flying++;
    wx.request({ ...opts,
      complete: () => { flying--; drain(); } }).then?.(resolve, reject) ??
      wx.request({ ...opts, success: resolve, fail: reject, complete: () => { flying--; drain(); } });
  }
}
```
