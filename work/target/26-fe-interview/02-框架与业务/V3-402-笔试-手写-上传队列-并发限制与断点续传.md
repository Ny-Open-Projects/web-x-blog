## V3-402：笔试：手写文件上传队列（并发限制 + 断点续传）
**题**：实现 `UploadQueue`：add(file) 入队；全局并发限制 N；文件按 chunk 分片上传，记录已传分片（服务端返回 uploaded 数组）支持断点续传；单文件失败不影响队列，可重试；进度按字节聚合。

```javascript
class UploadQueue {
  constructor({ concurrency = 3, chunkSize = 4 * 1024 * 1024 }) {
    this.queue = []; this.active = 0; Object.assign(this, { concurrency, chunkSize })
  }
  add(file) {
    const task = { file, progress: 0, status: 'waiting', uploadedChunks: new Set() }
    this.queue.push(task); this._pump()
    return task
  }
  async _pump() {
    while (this.active < this.concurrency && this.queue.length) {
      const task = this.queue.shift()
      this.active++
      this._run(task).finally(() => { this.active--; this._pump() })
    }
  }
  async _run(task) {
    const { file } = task
    task.status = 'uploading'
    // 初始化：服务端返回已传分片索引（断点续传）
    const { uploadId, uploaded = [] } = await api.initUpload(file.name, file.size)
    uploaded.forEach(i => task.uploadedChunks.add(i))
    const chunks = Math.ceil(file.size / this.chunkSize)
    for (let i = 0; i < chunks; i++) {
      if (task.uploadedChunks.has(i)) continue
      const blob = file.slice(i * this.chunkSize, (i + 1) * this.chunkSize)
      try {
        await api.uploadChunk(uploadId, i, blob)
        task.uploadedChunks.add(i)
      } catch (e) { task.status = 'error'; return } // 失败保留进度，可重试
      task.progress = Math.round(task.uploadedChunks.size / chunks * 100)
    }
    await api.completeUpload(uploadId)
    task.status = 'done'
  }
  retry(task) { task.status = 'waiting'; this.queue.push(task); this._pump() }
}
```
**评分点**：
- 并发池（active 计数 + 完成后 pump 补位）。
- 断点续传：init 返回 uploaded 索引，跳过已传分片。
- chunk 上传失败保留进度、任务级重试。
- 全局并发与队列隔离，失败不阻塞后续任务。
