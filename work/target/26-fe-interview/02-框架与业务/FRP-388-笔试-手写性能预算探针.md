## FRP-388：笔试：手写性能预算探针

**答**：实现 `createBudgetProbe({ budgets })`：① wrapMount(framework, name, mountFn)：计时 mount，超预算告警 + 记录；② wrapUpdate：通过框架探针（React Profiler / Vue onRenderTriggered）接入 update 计时；③ 统计聚合：P50/P95/超预算次数，按组件×框架维度；④ CI 模式：返回退出码（超预算 → 非 0——Storybook CI 门禁）；⑤ 采样与上报（全量 dev / 10% prod）。写出实现。

```javascript
export function createBudgetProbe({ budgets, ci = false } = {}) {
  const records = new Map();     // `${name}:${framework}` -> [ms]

  function wrapMount(name, framework, mountFn) {
    return async (...args) => {
      const t0 = performance.now();
      const result = await mountFn(...args);
      const ms = performance.now() - t0;
      record(name, framework, ms);
      return result;
    };
  }
  function record(name, framework, ms) {
    const key = `${name}:${framework}`;
    (records.get(key) ?? records.set(key, []).get(key)).push(ms);
    const budget = budgets[name] ?? 5;
    if (ms > budget) {
      console.warn(`[budget] ${key} mount ${ms.toFixed(1)}ms > ${budget}ms`);
      if (ci) process.exitCode = 1;                   // CI 门禁
    }
  }
  function stats() {
    return [...records.entries()].map(([key, arr]) => {
      const s = [...arr].sort((a, b) => a - b);
      return { key, n: s.length, p50: s[Math.floor(s.length / 2)], p95: s[Math.floor(s.length * 0.95)] };
    });
  }
  function report() {
    const sample = ci || Math.random() < 0.1;         // prod 10% 采样
    if (sample) beacon({ type: 'budget', stats: stats() });
  }
  return { wrapMount, record, stats, report };
}
// React 集成: <Profiler id={name} onRender={(_, phase, dur) => probe.record(name, 'react', dur)}>
// Vue 集成: onRenderTriggered + performance.mark 差值
```

**评分点**：
- 双框架探针接入点差异（Profiler vs onRenderTriggered）
- P50/P95 聚合与超预算告警/CI 退出码
- 采样策略（dev 全量/prod 10%）
- 预算兜底默认值与维度 key 设计
