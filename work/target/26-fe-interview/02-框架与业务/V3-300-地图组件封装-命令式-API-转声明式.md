## V3-300：地图组件封装：命令式 API 如何转声明式？
**答**：
- 核心思路：地图 SDK（高德/百度/Leaflet）是命令式（setCenter/addMarker），声明式封装 = "props 变化 → 调用命令式 API"的**同步器层**；每个 prop 一个 watcher（或统一 diff）。
- 双向：地图内部交互（拖动改变 center）回写 props 要**避免回环**（isSyncing 标志或比较值相等短路）。
- 生命周期：SDK 异步加载（script 注入 + ready promise），组件卸载 destroy；实例通过 provide/inject 给 Marker 子组件（`<GMapMarker :position>` 内部拿 map 实例注册覆盖物）。
- 子组件即覆盖物：Marker/Polygon 组件在 mount 时 addOverlay、unmount 时 remove，props 变化只更新对应字段——与 Vue 组件树天然对齐。
- 事件统一：SDK 事件转 Vue emit，参数做解耦（防 SDK 对象直接进 Vue 数据流）。

```typescript
// MapContainer.vue：异步加载 + provide 实例
let map = null;
provide('map', computed(() => map));
onMounted(async () => {
  map = await loadAmap(key);
  map.on('moveend', () => emit('update:center', map.getCenter())); // 交互回写
  map.on('zoomend', () => emit('update:zoom', map.getZoom()));
});
// props → 命令式同步（防回环）
watch(() => props.center, (c) => {
  if (!map) return;
  const cur = map.getCenter();
  if (c.lng !== cur.lng || c.lat !== cur.lat) map.setCenter(c); // 相等短路
}, { deep: true });
// Marker.vue：mount 注册覆盖物
const mapRef = inject('map');
onMounted(() => { marker = new AMap.Marker({ position: props.position }); mapRef.value.add(marker); });
onBeforeUnmount(() => mapRef.value?.remove(marker));
watch(() => props.position, (p) => marker?.setPosition(p));
```
