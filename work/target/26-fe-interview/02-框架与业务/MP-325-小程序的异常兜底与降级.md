## MP-325：小程序的异常兜底与降级

**答**：
- 兜底层次：App.onError（全局 JS 错误上报 + toast）、页面级（onLoad try/catch + 错误态 UI）、组件级（关键组件的 error 插槽）——与 Web 错误边界同构
- onPageNotFound：路由不存在兜底（回首页 + 提示）——「外链失效页面」的体验兜底
- 数据降级：接口失败 → 缓存数据兜底（H5-363 同模式）→ 全失败错误态（重试按钮）——「三段兜底」标准链
- 热启动异常恢复：小程序切后台被杀（iOS 内存）——onLaunch 时的「状态恢复」（草稿/表单数据持久化）
- 深水点：App.onError 里的错误聚合（上报去重——同一错误高频刷爆限额）+ 「致命错误白名单」（支付/登录失败要强提示，其他静默）

```javascript
App({
  onError(msg) {
    const key = hash(msg);
    if (reported.has(key)) return;                   // 去重
    reported.add(key);
    beacon({ type: 'js-error', msg });
  },
  onPageNotFound(res) {
    wx.switchTab({ url: '/pages/index/index' });
    toast('页面不存在，已回到首页');
  },
});
// 页面级: onLoad 数据加载 try/catch → setData({ state: 'error' }) → WXML 错误态 + 重试
```
