## MP-391：笔试：手写返回刷新

**答**：实现详情页改数据 → 返回列表自动刷新：① 详情页提交后「定向通知上一页」（getCurrentPages 按 route 匹配目标页——不依赖栈位置）；② 三通道组合：直接 setData（同栈快路径）+ store 更新（其他页面/下次进入）+ EventChannel（若存在）；③ 列表页的接收协议（onDataChanged 回调约定——页面工厂统一注入）；④ 返回时机的时序（提交完成 → navigateBack 前 notify——back 后 onShow 的 store 兜底双保险）；⑤ 通知失败的降级（上一页已卸载 → 仅 store，返回时 onShow 拉取）。写出实现。

```javascript
// 详情页: 提交后定向通知
async function submitAndBack(page, newData) {
  await api.update(newData);
  store.set(`item:${newData.id}`, newData);          // L1: 全局 store(兜底)
  const target = getCurrentPages()
    .slice(0, -1).reverse()
    .find((p) => p.route === 'pages/list/index');    // 按 route 匹配(不依赖栈位)
  if (target?.onDataChanged) {
    target.onDataChanged(newData);                   // L2: 直接 setData(快路径)
  } else {
    store.markDirty('list');                         // L3: 标脏 → 返回后 onShow 拉取
  }
  wx.navigateBack();
}
// 列表页(页面工厂注入协议):
Page(createPage({
  onDataChanged(item) {                              // 定向更新(不整页重拉)
    const i = this.data.list.findIndex((x) => x.id === item.id);
    if (i >= 0) this.setData({ [`list[${i}]`]: item });
  },
  onShow() {
    if (store.isDirty('list')) { this.refresh(); store.clearDirty('list'); }   // 双保险
  },
}));
```

**评分点**：
- 按 route 匹配目标页（不依赖栈位置——redirectTo 后栈变化的防御）
- 三通道分层（store 兜底/直接 setData 快路径/标脏降级）
- 页面工厂注入 onDataChanged 协议（约定式）
- 提交完成 → notify → back 的时序 + onShow 双保险
