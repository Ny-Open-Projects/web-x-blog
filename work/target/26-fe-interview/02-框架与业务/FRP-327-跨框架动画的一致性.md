## FRP-327：跨框架动画的一致性

**答**：
- 动画分层：值动画（JS 驱动状态）、DOM 动画（CSS/WAAPI 直接操作）、框架过渡组件（Transition/framer-motion）——跨框架一致性靠「下沉到 DOM 层」
- WAAPI 作为通用层：element.animate 各框架都能调（返回 Animation 对象可 pause/reverse）——跨框架动画内核的最佳载体
- 入出场动画的框架语义：Vue Transition（类名约定）、React（CSS 类 + 状态）、Solid（Transition 组件）——统一方案「mount/unmount 时调 WAAPI」内核化
- FLIP 的内核化：位置快照 + transform 反向——纯 DOM 操作（读 getBoundingClientRect）框架无关；各框架只在「commit 后」调用内核
- 性能红线统一：只动 transform/opacity；框架过渡组件的 class 切换时机差异（commit 前后）是坑源——内核层统一时机

```javascript
// 跨框架动画内核 (WAAPI)
export function animatePresence(el, { enter, leave }) {
  return {
    enter: () => el.animate(enter.keyframes, { duration: enter.ms, easing: 'cubic-bezier(.2,.8,.2,1)', fill: 'forwards' }),
    leave: () => el.animate(leave.keyframes, { duration: leave.ms, fill: 'forwards' }).finished,
  };
}
// FLIP 内核
export function flip(el, mutate) {
  const first = el.getBoundingClientRect();
  mutate();                                        // 各框架的 commit 后调用
  const last = el.getBoundingClientRect();
  const dx = first.left - last.left, dy = first.top - last.top;
  el.animate([{ transform: `translate(${dx}px,${dy}px)` }, { transform: 'none' }], { duration: 250 });
}
```
