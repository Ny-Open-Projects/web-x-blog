## V3-449：笔试：手写请求并发限制池（限流 + 队列 + 优先级）
**答**：实现 `limitPool(n)` 返回 `run(fn, priority)`：最多 n 个并发；超出的按优先级（priority 大的先出队）排队；支持 clear() 清空队列；run 返回 Promise 透传结果/错误。

```javascript
function limitPool(n) {
  const queue = []   // { fn, priority, resolve, reject }
  let active = 0
  function next() {
    while (active < n && queue.length) {
      queue.sort((a, b) => b.priority - a.priority) // 优先级出队
      const { fn, resolve, reject } = queue.shift()
      active++
      fn().then(resolve, reject).finally(() => { active--; next() })
    }
  }
  return {
    run(fn, priority = 0) {
      return new Promise((resolve, reject) => { queue.push({ fn, priority, resolve, reject }); next() })
    },
    clear() { queue.length = 0 } // 排队中的被永久 pending？需 reject
  }
}
// clear 更严谨：
// clear() { queue.splice(0).forEach(q => q.reject(new Error('cancelled'))); }
// 用法：pool.run(() => api.getGoods(id), 5) // 高优先级插队
```
**评分点**：
- 并发计数 + 完成后 next 补位。
- 优先级排序出队（稳定的场景说明：页面切换后取消低优）。
- clear 必须 reject 排队任务（否则永久 pending，高频扣分点）。
- 错误透传不吞。
