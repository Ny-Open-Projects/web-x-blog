## MP-386：笔试：手写签名请求

**答**：实现 `signedRequest`：① 请求注入 ts（毫秒时间戳）+ nonce（uuid）+ sign（对「方法+路径+排序后参数+ts+nonce+token」做 HMAC-SHA256——用 token 派生而非硬编码 secret）；② 参数排序规范化（key 字典序 + 值序列化规则——数组/对象/空的序列化约定）；③ 客户端时间偏移校正（服务端返回 Date 头 → 校正偏移量缓存）；④ 防重放说明（服务端 nonce Redis SETNX + ts 窗口）。写出实现。

```javascript
let timeOffset = 0;

export function calibratedNow() { return Date.now() + timeOffset; }
export function calibrateFromResponse(headers) {
  const serverDate = headers?.Date ? new Date(headers.Date).getTime() : null;
  if (serverDate) timeOffset = serverDate - Date.now();   // 偏移校正缓存
}

function canonicalize(params) {
  return Object.keys(params).sort().map((k) => {
    const v = params[k];
    const s = Array.isArray(v) ? v.join(',') : (typeof v === 'object' ? JSON.stringify(v) : String(v ?? ''));
    return `${k}=${encodeURIComponent(s)}`;
  }).join('&');
}

async function signedRequest(opts) {
  const token = await ensureLogin();
  const ts = calibratedNow();
  const nonce = crypto.randomUUID?.() ?? `${ts}-${Math.random()}`;
  const signBody = [opts.method || 'GET', opts.url, canonicalize(opts.data ?? {}), ts, nonce, token].join('|');
  const sign = await hmacSHA256(signBody, token.slice(0, 16));  // token 派生密钥(会话级)
  const res = await wxRequest({ ...opts, header: { ...opts.header, 'x-ts': ts, 'x-nonce': nonce, 'x-sign': sign } });
  calibrateFromResponse(res.header);
  return res;
}
// 服务端校验链: |ts - now| < 60s → SETNX(nonce, 120s TTL) 防重放 → 同签名算法验签 → 业务
// 安全原则: 前端无绝对秘密(token 会话级派生), 真实边界在服务端校验
```

**评分点**：
- 签名内容规范（方法+路径+参数排序+ts+nonce——顺序约定一致性）
- token 派生密钥（无硬编码 secret 的安全认知）
- 时间偏移校正（客户端时钟漂移）
- 服务端防重放链（ts 窗口 + nonce SETNX）的完整描述
