## V3-413：笔试：手写组件库按需加载的 Vite 插件
**题**：实现一个 Vite 插件：把 `import { Button, Dialog } from 'my-ui'` 转换为各自入口的按需 import（ESM + 样式 `my-ui/es/button/style.css`），产物可 tree-shaking；仅处理来自指定库的导入；支持列表可配置。

```javascript
export function uiOnDemand(libName = 'my-ui') {
  return {
    name: 'vite-plugin-ui-on-demand',
    transform(code, id) {
      if (!/\.(vue|ts|js|tsx)$/.test(id)) return null
      const imports = []
      const comps = ['Button', 'Dialog']
      const re = new RegExp(`import\\s*\\{([^}]+)\\}\\s*from\\s*['"]${libName}['"]`)
      const m = code.match(re)
      if (!m) return null
      const names = m[1].split(',').map(s => s.trim().split(' as ')[0]).filter(n => comps.includes(n))
      if (!names.length) return null
      const replacement = names.map(n =>
        `import ${n} from '${libName}/es/${n.toLowerCase()}';\nimport '${libName}/es/${n.toLowerCase()}/style.css';`
      ).join('\n')
      return { code: code.replace(m[0], replacement), map: null }
    }
  }
}
```
**评分点**：
- 正则捕获导入列表并过滤已知组件（未知保持原 import）。
- 同步替换组件与样式两条 import。
- 用 transform 而非修改源文件（build 时自动失效于 ESM 树摇）。
- 能说明替代方案：ESM 包直接 tree-shaking + unplugin 自动导入。
