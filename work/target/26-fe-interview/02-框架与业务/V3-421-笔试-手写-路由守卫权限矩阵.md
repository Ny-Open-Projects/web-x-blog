## V3-421：笔试：手写路由守卫的权限矩阵（含异步权限与白名单）
**题**：实现 router.beforeEach 守卫：白名单路由（/login、/404）直接放行；需要登录的路由未登录跳登录页并带 redirect；需要权限的路由（meta.perm）检查用户权限（异步获取，缓存一次）；防循环跳转（redirect 参数校验）。

```javascript
router.beforeEach(async (to) => {
  const WHITE = ['/login', '/404']
  if (WHITE.includes(to.path)) return true
  const user = await getUserOnce() // 内部缓存，只请求一次
  if (!user) {
    if (to.path === '/login') return true
    return { path: '/login', query: { redirect: to.fullPath } }
  }
  const need = to.meta.perm
  if (need && !user.perms.includes(need)) {
    return { path: '/403' } // 无权限页，不再回跳
  }
  // 防循环：redirect 只允许站内路径
  if (to.path === '/login' && /^https?:/.test(to.query.redirect || '')) {
    return { path: '/login', query: { redirect: '/' } }
  }
  return true
})
// 登录成功后：router.push(route.query.redirect || '/')
```
**评分点**：
- 白名单与登录态判断顺序（先白名单短路）。
- 异步权限只取一次（缓存）。
- redirect 只允许站内路径，防开放跳转漏洞（安全点）。
- 无权限进 403 而不是回登录页（防死循环）。
