## FRP-382：笔试：手写状态机内核

**答**：实现 `createMachine`：① states 定义含 on 迁移表（target/guard/action）；② send(event)：guard 校验、action 执行、迁移、通知；③ history：迁移日志栈 + canBack/back()（回退到上一状态——action 不可逆的说明）；④ 进入/离开钩子（enter/exit 每状态）；⑤ 非法迁移计数（非法事件告警——业务 bug 信号）。写出实现。

```javascript
export function createMachine({ states, initial, context = {} }) {
  let current = initial;
  let ctx = { ...context };
  const history = [];
  const subs = new Set();
  let illegalCount = 0;

  function send(event, payload = {}) {
    const node = states[current];
    const t = node?.on?.[event];
    if (!t) {
      if (++illegalCount > 10) console.warn('[machine] too many illegal transitions', event);
      return false;                                  // 非法迁移
    }
    const target = typeof t.target === 'function' ? t.target(ctx, payload) : t.target;
    if (t.guard && !t.guard(ctx, payload)) return false;
    states[current]?.exit?.(ctx);
    history.push({ from: current, event, ctx: { ...ctx } });
    ctx = t.action?.({ ...ctx }, payload) ?? ctx;    // action 返回新 context
    current = target;
    states[current]?.enter?.(ctx, payload);
    subs.forEach((f) => f({ state: current, ctx, event, prev: history.at(-1)?.from }));
    return true;
  }
  function back() {
    const h = history.pop();
    if (!h) return false;
    states[current]?.exit?.(ctx);
    current = h.from;
    ctx = h.ctx;                                     // 恢复当时 context
    subs.forEach((f) => f({ state: current, ctx, event: '__back__' }));
    return true;
  }
  return { send, back, get state() { return current; }, get ctx() { return ctx; },
    get canBack() { return history.length > 0; },
    sub(fn) { subs.add(fn); return () => subs.delete(fn); } };
}
// 用法: 审批流
// states: { draft: { on: { submit: { target: 'review', guard: (c) => c.items.length > 0 } } },
//           review: { on: { approve: { target: 'done', action: (c) => ({ ...c, approvedAt: Date.now() }) } } } }
```

**评分点**：
- guard 拦截 + action 返回新 context（不可变更新）
- enter/exit 钩子时序（exit → 迁移 → enter）
- 历史回退恢复 context 快照 + action 不可逆的说明
- 非法迁移计数告警（业务 bug 信号）
