## MP-333：跨端项目的代码组织与平台差异层

**答**：
- 代码组织：业务逻辑层（框架无关——状态/校验/工具）、适配层（平台 API 封装——Taro API 二次包装，抹平端差异）、视图层（各端页面）——「逻辑跨端复用、视图各端定制」
- 平台差异治理：Taro.isTaro/process.env.TARO_ENV 条件编译（构建期剔除——体积干净）+ 运行时检测（Taro.getEnv）——构建期优先（死代码剔除）
- API 差异抹平：能力矩阵表（某端不支持的 API → 降级实现或隐藏功能）——「能力检测 + 功能开关」而不是 try/catch 兜底
- 样式差异：rpx 各端一致、安全区 API 差异（safe-area 封装）、字体加载差异——样式适配层的封装
- 深水点：「平台差异文档化」——差异登记表（能力/API/样式）进代码仓库，新端接入按表适配——经验资产化

```javascript
// 条件编译(构建期)
if (process.env.TARO_ENV === 'weapp') { wxPay(); }
else if (process.env.TARO_ENV === 'h5') { webPay(); }
// 适配层: 能力矩阵
export const CAPS = {
  pay: () => process.env.TARO_ENV !== 'alipay',
  subscribe: () => ['weapp', 'swan'].includes(process.env.TARO_ENV),
};
// 组件层: { CAPS.subscribe && <SubscribeBtn /> }  — 不支持端隐藏入口
```
