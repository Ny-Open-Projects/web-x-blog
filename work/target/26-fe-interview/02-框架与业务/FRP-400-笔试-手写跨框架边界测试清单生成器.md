## FRP-400：笔试：手写边界测试生成器

**答**：实现 `generateBoundaryTests(protocol)`：① 从桥接协议（事件 schema 清单）自动生成用例矩阵：每事件 × 正常 payload × 边界 payload（空/超长/类型错）× 双框架接收方；② schema 驱动的边界值生成（string→空/超长、number→0/负/NaN、object→缺字段）；③ 输出 vitest 用例代码（可执行）；④ 覆盖率报告（协议事件 × 用例类型的覆盖矩阵）；⑤ 高危事件标记（涉及状态写入的事件全组合必测）。写出实现。

```javascript
export function generateBoundaryTests(protocol, { framework = 'react' } = {}) {
  const cases = [];
  for (const [type, schema] of Object.entries(protocol.events)) {
    const payloads = genPayloads(schema);            // 正常 + 边界
    for (const [label, payload] of payloads) {
      cases.push({
        name: `${type} [${label}] → ${framework}`,
        run: async (ctx) => {
          if (label === 'valid') {
            await ctx.emit(type, payload);
            await expect(ctx.received()).toEqual(expect.objectContaining({ payload }));
          } else {
            await ctx.emit(type, payload);
            expect(ctx.received()).toBeNull();       // 非法 payload 被拒
            expect(ctx.warnings()).toContain(type);  // schema 告警
          }
        },
      });
    }
  }
  return {
    cases,
    vitestCode: cases.map((c) => `it('${c.name.replace(/'/g, "\\'")}', async () => { /* generated */ });`).join('\n'),
    coverage: coverageMatrix(protocol, cases),
  };
}
function genPayloads(schema) {
  const out = [['valid', genValid(schema)]];
  if (schema.type === 'string') out.push(['empty', ''], ['overlong', 'x'.repeat(10000)]);
  if (schema.type === 'number') out.push(['zero', 0], ['negative', -1], ['nan', NaN]);
  if (schema.type === 'object') out.push(['missing-fields', {}]);
  if (protocol.highRisk?.includes(schema.name)) /* 全组合 */ out.push(...genAllCombinations(schema));
  return out;
}
```

- schema 驱动的边界值生成（类型感知）

- 覆盖矩阵输出（测试债可视化）
