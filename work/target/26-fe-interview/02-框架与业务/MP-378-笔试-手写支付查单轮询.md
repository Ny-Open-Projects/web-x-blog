## MP-378：笔试：手写支付查单

**答**：实现支付结果确认 `confirmPayment(orderId)`：① 阶梯轮询：1.5s × 3 → 3s × 3 → 5s × 4（共 10 次 30s 内）——前密后疏；② 三出口：PAID → 成功页、CLOSED/REFUND → 失败处理、超时 → 「处理中」态（服务端异步回调兜底）；③ 用户取消支付的分支（requestPayment fail cancel → 直接查一次单——用户可能实际已支付）；④ 页面卸载取消轮询；⑤ 防重复进入（同订单已确认直接跳结果）。写出实现。

```javascript
const LADDER = [[1500, 3], [3000, 3], [5000, 4]];

function confirmPayment(page, orderId) {
  if (page._confirmed?.has(orderId)) return goResult(page, orderId);   // 防重复
  (page._confirmed ??= new Set()).add(orderId);
  let cancelled = false;
  page.onUnload(() => { cancelled = true; });
  const wait = (ms) => new Promise((r) => setTimeout(r, ms));

  return (async () => {
    for (const [ms, times] of LADDER) {
      for (let i = 0; i < times; i++) {
        if (cancelled) return;
        const s = await api.orderState(orderId).catch(() => null);
        if (s === 'PAID') return goResult(page, orderId);
        if (s === 'CLOSED' || s === 'REFUND') return goFail(page, orderId, s);
        await wait(ms);
      }
    }
    goPending(page, orderId);                          // 超时: 处理中态(服务端回调兜底)
  })();
}
// requestPayment fail 分支:
async function onPayFail(e, orderId) {
  if (e.errMsg?.includes('cancel')) {
    const s = await api.orderState(orderId).catch(() => null);  // 取消也可能已付(先拉起后杀进程)
    s === 'PAID' ? goResult(this, orderId) : toast('已取消支付');
  } else confirmPayment(this, orderId);                // 非 cancel: 走查单确认
}
```

**评分点**：
- 阶梯轮询节奏（前密后疏，30s 内覆盖微信回调延迟）
- 三出口清晰（成功/失败/处理中兜底）
- cancel 分支也查单（用户先支付后取消界面的真实场景）
- 页面卸载取消 + 防重复确认
