## MP-385：笔试：手写上传队列

**答**：实现 `UploadQueue`：① 并发 2~3 上传队列（优先级：用户手动选的先）；② 每任务：wx.uploadFile 的 uploadTask 引用（progress 回调驱动 UI/abort 取消）；③ 失败重试（网络错误 1 次 + 凭证过期重签再试）；④ 页面卸载全部 abort + pending 状态持久（未完成任务下次进入恢复提示）；⑤ 整体进度（已完成/总数）。写出实现。

```javascript
class UploadQueue {
  #tasks = []; #flying = 0; #MAX = 3;
  #done = 0; #onProgress;
  constructor({ onProgress } = {}) { this.#onProgress = onProgress; }

  add(file, { priority = false } = {}) {
    const task = { file, status: 'pending', progress: 0, taskId: crypto.randomUUID?.() ?? `${Date.now()}${Math.random()}` };
    priority ? this.#tasks.unshift(task) : this.#tasks.push(task);
    this.#drain();
    return task.taskId;
  }
  async #drain() {
    while (this.#flying < this.#MAX) {
      const t = this.#tasks.find((x) => x.status === 'pending');
      if (!t) break;
      t.status = 'uploading'; this.#flying++;
      this.#run(t);
    }
  }
  async #run(t) {
    try {
      let cred = await api.getUploadCredential();
      await new Promise((resolve, reject) => {
        const up = wx.uploadFile({
          url: cred.url, filePath: t.file.path, name: 'file', formData: cred.fields,
          success: (r) => resolve(r), fail: reject,
        });
        t.abort = () => up.abort();
        up.onProgressUpdate((p) => {
          t.progress = p.progress;
          this.#notify();
        });
      });
      t.status = 'done'; this.#done++;
    } catch (e) {
      if (!t._retried) {
        t._retried = true;
        const isAuthFail = e.errMsg?.includes('403');
        if (isAuthFail) cred = null;
        t.status = 'pending';                          // 重试一次
      } else t.status = 'failed';
    } finally {
      this.#flying--;
      this.#notify();
      this.#drain();
    }
  }
  cancel(taskId) { const t = this.#tasks.find((x) => x.taskId === taskId); t?.abort?.(); t.status = 'cancelled'; this.#drain(); }
  cancelAll() { this.#tasks.filter((t) => t.status === 'uploading').forEach((t) => { t.abort?.(); t.status = 'pending'; }); this.#flying = 0; }
  #notify() { this.#onProgress?.({ done: this.#done, total: this.#tasks.length, tasks: this.#tasks.map(({ taskId, status, progress }) => ({ taskId, status, progress })) }); }
}
// 页面卸载: queue.cancelAll() → 未完成持久到 storage → 下次进入提示恢复
```

**评分点**：
- 并发上限 + 优先级插入（unshift）
- uploadTask 引用（progress/abort）与取消语义
- 重试矩阵（网络错误 vs 凭证过期）
- 卸载全部取消 + 未完成持久恢复
