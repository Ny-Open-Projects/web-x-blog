## V3-330：Vapor 模式有哪些常见误区？
**答**：
- 误区一「Vapor 不用响应式」：错，响应式完整保留，只是订阅末端变细。
- 误区二「性能一定全面碾压」：首屏创建、静态内容两者接近；优势集中在高频小更新与运行时体积。
- 误区三「没有 diff 就不怕 key」：createFor 仍靠 key 复用，乱写 key（索引 key）同样引发状态错位。
- 误区四「可以直接替换 compiler」：需要配套 runtime helper 版本一致，混用不同 minor 版本会出现 helper 不兼容。
- 误区五「CSS/作用域、指令都变了」：模板语法层面几乎不变，心智成本低的是写法、高的是调试（没有 vnode 可看）。
