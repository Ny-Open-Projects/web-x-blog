## V3-248：异步组件与打包拆分的工程细节：chunk 策略、预加载与魔法注释？
**答**：
- chunk 归组：动态 import 相同模块天然合并；Vite 下用 `manualChunks`/`advancedChunks` 把低频组件归入公共 chunk，避免碎片请求。
- 预加载配合：路由跳转前 `import()` 预取（hover/触摸时），或 `<link rel="modulepreload">` 由构建器自动注入到首屏 HTML。
- 魔法注释：`/* @vite-ignore */`（阻止 Vite 分析动态变量）、`/* webpackPrefetch: true */`（低优先级预取，webpack 场景）、Vite 中用 `preloadRelated` 类插件实现同理。
- 注意：动态组件名映射（`components[name]`）必须静态穷举 import，否则打包器无法拆出 chunk 或运行时缺模块。
- 度量：用构建产物分析（rollup-plugin-visualizer）看 chunk 分布，保证"首屏 chunk 数量 ≤ 5、单 chunk < 200KB gzip"。

```javascript
// 动态组件映射：必须静态穷举
const maps = {
  Bar: () => import('./charts/Bar.vue'),       // 每个独立 chunk
  Line: () => import('./charts/Line.vue'),
  Pie: () => import('./charts/Pie.vue'),
};
// Vite 配置：低频图表归一组
export default defineConfig({
  build: {
    rollupOptions: { output: {
      advancedChunks: { groups: [{ name: 'charts', test: /src\/charts/ }] },
    } },
  },
});
// hover 预取路由组件
onMouseEnter = () => import('./views/Product.vue'); // 触发浏览器预下载 chunk
```
