## FRP-294：笔试：手写编译期条件死代码消除
**答**：给定编译配置 `flags = { PROD: true, DEVTOOL: false }`，实现 `deadCodeElim(code)`：把 `if (flags.X)` 中已知常量的分支消除（true 保留体、false 删除分支与 else）；处理嵌套 if；输出可验证的简化代码。只做简单模式（不要求完整 AST）。

```javascript
function deadCodeElim(code, flags) {
  let out = code
  for (const [k, v] of Object.entries(flags)) {
    const re = new RegExp(`if\\s*\\(${k}\\)\\s*\\{([\\s\\S]*?)\\}\\s*else\\s*\\{([\\s\\S]*?)\\}`, 'g')
    out = out.replace(re, (_, ifBody, elseBody) => v ? ifBody : elseBody)
    const re2 = new RegExp(`if\\s*\\(${k}\\)\\s*\\{([\\s\\S]*?)\\}`, 'g')
    out = out.replace(re2, (_, body) => v ? body : '') // 无 else：false 整体删除
  }
  return out
}
// 输入：if (PROD) { a() } else { b() }\nif (DEVTOOL) { c() }
// flags { PROD: true, DEVTOOL: false } → 'a()'
```
**评分点**：
- 常量分支替换（true 留体/false 删）。
- 有无 else 两种模式处理。
- 能说明真实实现基于 AST + esbuild/terser 的 DCE，以及嵌套 if 需多轮收敛。
- 应用：Vue 的 __VUE_OPTIONS_API__ 特性开关。
