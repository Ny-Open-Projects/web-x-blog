## V3-408：笔试：手写表单字段联动的循环依赖检测
**答**：字段联动规则 `links: { a: ['b'], b: ['c'], c: ['a'] }` 表示 a 变化触发 b 的重算……实现 `detectCycle(links)`：输出环路径（如 a->b->c->a）；提供 `applyChange(links, field, onChange)` 时检测到环则告警并只在环上执行一次（阻断无限重算）。

```javascript
function detectCycle(links) {
  const state = new Map() // 0 未访问 1 在栈中 2 完成
  let cyclePath = null
  function dfs(node, path) {
    if (cyclePath) return
    if (state.get(node) === 1) { // 回到栈中节点 → 有环
      const start = path.indexOf(node)
      cyclePath = [...path.slice(start), node].join('->')
      return
    }
    if (state.get(node) === 2) return
    state.set(node, 1)
    path.push(node)
    for (const next of links[node] || []) dfs(next, path)
    path.pop()
    state.set(node, 2)
  }
  Object.keys(links).forEach(n => dfs(n, []))
  return cyclePath // 无环返回 null
}
function applyChange(links, field, onChange, visiting = new Set()) {
  if (visiting.has(field)) return          // 运行时环阻断
  visiting.add(field)
  onChange(field)
  for (const next of links[field] || []) applyChange(links, next, onChange, visiting)
}
```
**评分点**：
- DFS 三色标记检测环并还原环路径。
- 运行时用 visiting Set 阻断重入（防无限循环）。
- 环检测在配置加载期做，运行时阻断做兜底——两层防线。
- 能说明环配置报错优于静默死循环。
