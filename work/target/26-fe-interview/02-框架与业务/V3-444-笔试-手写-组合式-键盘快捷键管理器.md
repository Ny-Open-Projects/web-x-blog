## V3-444：笔试：手写组合式键盘快捷键管理器（作用域 + 冲突处理）
**题**：实现 `useHotkeys(bindings)`：组合键解析（'ctrl+k'、'shift+?'）；组件卸载自动注销；输入框聚焦时不触发（可配置 allowInInput）；同一组合键后注册覆盖先注册（或按优先级）；返回 dispose。

```javascript
const handlers = new Map()
function parseCombo(combo) {
  return combo.toLowerCase().split('+').map(s => s.trim()).sort().join('+')
}
function isEditable(e) {
  const t = e.target
  return t.tagName === 'INPUT' || t.tagName === 'TEXTAREA' || t.isContentEditable
}
function useHotkeys(bindings, { allowInInput = false } = {}) {
  const onKeydown = (e) => {
    if (!allowInInput && isEditable(e)) return
    const parts = []
    if (e.ctrlKey || e.metaKey) parts.push('ctrl')
    if (e.shiftKey) parts.push('shift')
    parts.push(e.key.toLowerCase())
    const combo = parseCombo(parts.join('+'))
    const h = handlers.get(combo)
    if (h) { e.preventDefault(); h(e) }
  }
  onMounted(() => {
    Object.entries(bindings).forEach(([combo, fn]) => handlers.set(parseCombo(combo), fn))
    document.addEventListener('keydown', onKeydown)
  })
  const dispose = () => {
    Object.keys(bindings).forEach(combo => handlers.delete(parseCombo(combo)))
    document.removeEventListener('keydown', onKeydown)
  }
  onBeforeUnmount(dispose)
  return dispose
}
// useHotkeys({ 'ctrl+k': openSearch })
```
**评分点**：
- 组合键规范化解析（排序后比较，大小写/修饰键顺序无关）。
- 输入框屏蔽逻辑（可配置）。
- 卸载注销（dispose 同时清注册表与监听）。
- preventDefault 阻止浏览器默认（如 Ctrl+K 地址栏）。
