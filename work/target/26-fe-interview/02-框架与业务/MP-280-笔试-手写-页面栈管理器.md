## MP-280：笔试：手写页面栈管理器
**题**：实现 nav：navigateTo 超过 9 层时自动 redirectTo（替换当前页）防栈溢出；记录跳转轨迹（route 数组）供回溯；back(steps) 封装 navigateBack；带防抖（500ms 内重复跳转忽略）；登录拦截钩子（跳转前 check）。

```javascript
const routes = []
let lastNav = 0
function nav(to, options = {}) {
  const now = Date.now()
  if (now - lastNav < 500) return       // 防抖：快速双击
  lastNav = now
  if (options.beforeNav && !options.beforeNav(to)) return
  const depth = getCurrentPages().length
  routes.push(to)
  if (depth >= 10) {
    routes.splice(-2, 1) // redirectTo 替换当前页
    wx.redirectTo({ url: to })
  } else {
    wx.navigateTo({ url: to })
  }
}
function back(steps = 1) {
  routes.splice(-steps)
  wx.navigateBack({ delta: steps })
}
// 语义说明：栈满时 redirectTo 会破坏返回链——更优方案是弹层（组件级路由）或提示
```
**评分点**：
- 10 层限制的判定（getCurrentPages().length）。
- redirectTo 的返回链破坏风险要指出（加分项：弹层替代方案）。
- 防抖防双击。
