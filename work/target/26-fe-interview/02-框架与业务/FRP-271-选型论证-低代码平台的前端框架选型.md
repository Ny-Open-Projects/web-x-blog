## FRP-271：低代码平台的选型论证？
**答**：
- 渲染架构：schema 驱动 + 运行时渲染器（Vue render/React createElement 动态构建）——编译时框架不适合（模板在运行时才确定）。
- 框架选择：Vue（运行时模板兼容 + h 函数成熟）或 React（createElement + reconciler 定制）；Vue 生态有现成方案（lowcode 引擎）。
- 沙箱：组件白名单 + schema 校验（防注入）、属性表达式受控求值（new Function 替代方案）。
- 性能：schema 版本 diff 渲染、组件缓存池、大画布虚拟化。
- 面试表达：低代码的反编译时性是框架选型的决定性约束——先答这条再谈其他。
