## FRP-330：框架无关的国际化内核

**答**：
- 内核 API：t(key, params)（翻译+插值）、locale 状态（signal/ref）、格式化（date/number/plural 走 Intl API 原生）——框架层绑定 locale 的响应式
- Intl 原生能力优先：Intl.DateTimeFormat/NumberFormat/PluralRules——自研翻译内核只管「键 → 文案」，格式化全部交给 Intl（跨框架零差异）
- 懒加载与切换：语言包动态 import → 内核 setLocale → 通知订阅 → 框架层重渲染——切换 loading 态在各框架一致处理
- 复数与性别：ICU MessageFormat 的子集（复数必做）——内核解析器轻量实现或引入 @formatjs/icu-messageformat-parser
- 缺失键策略：回退链（zh-CN → zh → key 本身）+ dev 告警收集（缺失键上报 CI 补齐）

```javascript
export function createI18n({ fallback = 'en' } = {}) {
  let locale = 'en';
  let messages = {};
  const subs = new Set();
  const t = (key, params = {}, count) => {
    const tpl = messages[locale]?.[key] ?? messages[fallback]?.[key] ?? key;
    const plural = count != null ? new Intl.PluralRules(locale).select(count) : null;
    const final = plural ? (tpl[plural] ?? tpl.other) : tpl;
    return final.replace(/\{(\w+)\}/g, (_, k) => params[k] ?? '');
  };
  return {
    t, get locale() { return locale; },
    async setLocale(l) { messages[l] ??= (await import(`/locales/${l}.json`)).default; locale = l; subs.forEach((f) => f(l)); },
    sub(fn) { subs.add(fn); return () => subs.delete(fn); },
  };
}
```
