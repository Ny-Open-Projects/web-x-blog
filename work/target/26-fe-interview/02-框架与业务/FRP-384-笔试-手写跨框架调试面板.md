## FRP-384：笔试：手写跨框架调试面板

**答**：实现 `createDevPanel(kernel)`：① 状态 dump：所有内核 store 快照（按域分组）+ 时间戳——仲裁「React 与 Vue 看到的不一致」；② 时序记录：内核 set/get 的环形缓冲（最近 200 条，含 source/timeline）——时序问题的回放；③ 效果探针：effect 数量趋势（增长告警）；④ 面板 UI：注入固定层调试卡片（仅在 URL 带 __debug 时激活）；⑤ 快照对比：save/restore 状态（手动复现时序 bug）。写出实现。

```javascript
export function createDevPanel(kernel) {
  if (!location.search.includes('__debug')) return null;
  const timeline = new RingBuffer(200);
  kernel.onSet((info) => timeline.push({ ...info, t: performance.now() }));   // 内核打点

  const dump = () => ({
    stores: kernel.snapshotAll(),                    // 全域快照
    timeline: timeline.drain ? timeline.last(50) : [],
    effects: kernel.effectCount(),
    t: Date.now(),
  });
  window.__panel__ = { dump,
    save: () => sessionStorage.setItem('__snap__', JSON.stringify(dump())),
    restore: () => { kernel.restoreAll(JSON.parse(sessionStorage.getItem('__snap__')).stores); } };

  // UI 卡片
  const card = document.createElement('div');
  card.style.cssText = 'position:fixed;bottom:8px;right:8px;z-index:2147483647;background:#1e1e1e;color:#0f0;padding:8px;font:12px monospace;border-radius:8px';
  const render = () => { const d = dump(); card.textContent = `stores:${Object.keys(d.stores).length} effects:${d.effects} timeline:${d.timeline.length}`; };
  setInterval(render, 1000);
  card.ondblclick = () => { console.log('DUMP', dump()); };
  document.body.appendChild(card);
  return { dump };
}
// 用法: 复现「两框架不一致」→ dump 快照 → save → 操作 → restore 对比
```

**评分点**：
- dump 的仲裁设计（全域快照 + 时间戳）
- 时序环形缓冲（set/get + source）回放能力
- effect 计数泄漏探针
- URL 门控（仅调试环境激活）与快照 save/restore
