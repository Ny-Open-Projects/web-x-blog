## MP-388：笔试：手写两段式图片加载

**答**：实现 `TwoPhaseImage` 组件：① 先渲染缩略图（thumb URL——CDN 小尺寸）占位，高清图 bindload 后替换（淡入过渡）；② 失败处理：缩略图失败直接上高清；高清失败重试一次换 CDN 域名；③ lazy-load + 视口外释放（IO 离屏——内存治理：高清图列表场景释放非可视）；④ aspect 预占（width/height props 定住布局防跳动）；⑤ 加载态（骨架渐变背景）。写出实现。

```xml
<!-- two-phase-image.wxml -->
<view class="tpi {{loading ? 'loading' : ''}}" style="width:{{width}}rpx;height:{{height}}rpx">
  <image wx:if="{{!hdLoaded && thumb}}" src="{{thumb}}" mode="aspectFill" lazy-load class="img" />
  <image src="{{currentSrc}}" mode="aspectFill" lazy-load class="img {{hdLoaded ? 'fade-in' : ''}}"
    bindload="onHdLoad" binderror="onHdError" />
</view>
```

```javascript
Component({
  properties: { thumb: String, src: String, width: Number, height: Number },
  data: { hdLoaded: false, currentSrc: '' },
  lifetimes: {
    attached() { this._retried = false; this.setData({ currentSrc: this.data.thumb }); },
  },
  observers: {
    src(v) {
      if (!v) { this.setData({ currentSrc: this.data.thumb }); return; }
      this.setData({ currentSrc: v });                // 高清路径
    },
  },
  methods: {
    onHdLoad() { this.setData({ hdLoaded: true }); },  // 高清到达 → 淡入覆盖缩略图
    onHdError(e) {
      if (!this._retried) {                            // 换 CDN 域重试一次
        this._retried = true;
        this.setData({ currentSrc: this.data.src.replace('cdn1', 'cdn2') });
      } else if (this.data.thumb) {
        this.setData({ currentSrc: this.data.thumb }); // 高清彻底失败 → 保持缩略图
      }
    },
  },
});
/* wxss: .img { position:absolute; inset:0 } .fade-in { animation: fade .25s } .loading { background: #f0f0f0; animation: pulse 1s infinite } */
// 离屏释放: 列表父组件 IO observer → 离屏项 setData currentSrc='' (释放解码)
```

**评分点**：
- 缩略图占位 + 高清淡入覆盖（两段式语义）
- 失败矩阵（高清失败重试换域 → 回退缩略图）
- 宽高预占防布局跳动
- 离屏释放的内存治理意识
