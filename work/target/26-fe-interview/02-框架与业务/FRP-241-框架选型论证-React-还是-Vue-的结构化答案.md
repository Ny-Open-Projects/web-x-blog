## FRP-241：「React 还是 Vue？」的结构化论证答案？
**答**：
- 先反问上下文：新项目/存量？团队栈？业务形态？——直接给结论是减分项。
- React 端论证：生态最大（RSC/Next、RN、企业级组件库）、JSX 灵活、并发模型激进；代价：心智负担（hooks 纪律）、优化靠人工或 Compiler。
- Vue 端论证：模板编译优化（性能默认好）、渐进上手、官方全家桶一致性；代价：生态深度略小、大型工程 TS 体验历史上略弱（已大幅改善）。
- 结论模板：默认跟随团队与生态（多数场景两者都合适）；特定权重（重交互性能 / SEO 内容站 / 移动端）才倾斜。
- 亮点：说得出「两者的性能差异主要来自编译期信息与优化默认值，而不是运行时引擎」。
