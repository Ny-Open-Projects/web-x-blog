## V3-495：Vue3 权限控制体系：路由、组件、指令三层

**答**：
- 三层权限：路由级（beforeEach 校验 + 动态注册路由）、组件级（v-if 权限判断/包裹组件）、操作级（v-permission 指令控制按钮）——粒度递细，越细越易漏
- 路由层实现：登录后拉取权限点 → filter 静态路由表 → router.addRoute 动态挂载；刷新恢复（权限持久化到 store + 守卫等待权限就绪）——「守卫竞态」（权限未到先跳转）用 pending promise 闸门
- 指令实现：v-perm="'order:delete'" → mounted 时检查当前用户权限集合，无权限 removeElement——但 DOM 移除后响应式变化不会恢复（权限运行时变更少，可接受；要动态用 v-if 包装组件）
- 组件级逃生口：<Auth :perm="x"> 包裹 + 默认插槽降级内容（无权限提示）——比指令灵活（可留 UI 占位）
- 服务端兜底：前端权限只是体验优化，接口鉴权才是安全边界——前端权限模型与后端 ACL 同源（同一权限点表）

```javascript
// v-perm 指令
app.directive('perm', {
  mounted(el, binding) {
    if (!authStore.has(binding.value)) el.parentElement?.removeChild(el);
  },
});
// 路由守卫竞态闸门
let authReady = false, pending;
router.beforeEach(async (to) => {
  if (!authReady) await (pending ??= loadPermissions());
  if (to.meta.perm && !store.has(to.meta.perm)) return '/403';
});
```
