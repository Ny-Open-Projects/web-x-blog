## V3-432：笔试：手写组件级 SSR 缓存（key 设计 + 用户态隔离）
**题**：实现 `ssrCacheComponent(keyParts, ttl, render)`：key 由路由参数 + 环境维度组成（不含用户态字段）；用户态相关的渲染片段拆出去单独渲染（不可缓存）；缓存条目带生成时间，超 ttl 重渲染；命中时跳过 render。

```javascript
const cache = new Map()
function ssrCache(keyParts, ttl, render) {
  const key = keyParts.filter(Boolean).join('|') // 必须剔除用户态字段
  const now = Date.now()
  const hit = cache.get(key)
  if (hit && now - hit.t < ttl) return hit.html
  const html = render() // render 内只允许访问 keyParts 涵盖的上下文
  cache.set(key, { t: now, html })
  return html
}
// 正确示例：
// const html = ssrCache([route.params.id, locale], 60_000, () => renderGoodsBody(goods))
// const cart = renderUserCart(user)   // 用户态片段不进缓存
// return html + cart
```
**评分点**：
- key 设计原则：公共维度入 key，用户态绝不入（防串号——高频考点）。
- TTL 重渲染；keyParts filter(Boolean) 处理可选维度。
- 用户态片段拆分组合的「页面级 HTML 拼装」思路。
- 能提 LRU 上限或按路由分组清理防缓存膨胀。
