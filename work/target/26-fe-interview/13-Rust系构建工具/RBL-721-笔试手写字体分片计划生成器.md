## RBL-721：笔试：手写字体分片计划生成器（频率排序 + unicode-range）

**答**：实现 `planSlices(text, { sliceSize })`。1) 统计字符频率（去重）；2) 按频率降序排列字符；3) 按 sliceSize 分片（片间不重叠）；4) 生成每片的 unicode-range 字符串——连续码点合并为区间 `U+4E00-4E2A`，单个为 `U+4E00`，多段逗号分隔；5) 返回 `{ slices: Array<{ chars: string[], range: string }>, firstSliceChars: string[] }`。边界：空文本；sliceSize 大于字符数（单片）。

```javascript
function planSlices(text, { sliceSize = 500 } = {}) {
  const freq = new Map();
  for (const ch of text) freq.set(ch, (freq.get(ch) || 0) + 1);
  const sorted = [...freq.entries()].sort((a, b) => b[1] - a[1]).map(e => e[0]);
  const slices = [];
  for (let i = 0; i < sorted.length; i += sliceSize) {
    const chars = sorted.slice(i, i + sliceSize);
    slices.push({ chars, range: toUnicodeRange(chars) });
  }
  return { slices, firstSliceChars: slices[0]?.chars ?? [] };
}

function toUnicodeRange(chars) {
  const cps = [...chars].map(c => c.codePointAt(0)).sort((a, b) => a - b);
  const parts = [];
  let start = null, prev = null;
  const flush = () => {
    if (start === null) return;
    parts.push(start === prev ? `U+${start.toString(16).toUpperCase()}`
      : `U+${start.toString(16).toUpperCase()}-${prev.toString(16).toUpperCase()}`);
    start = null;
  };
  for (const cp of cps) {
    if (start === null) { start = cp; prev = cp; continue; }
    if (cp === prev + 1) prev = cp;
    else { flush(); start = cp; prev = cp; }
  }
  flush();
  return parts.join(', ');
}

// 自测
const text = '你好世界你好，前端构建！你好';
const { slices, firstSliceChars } = planSlices(text, { sliceSize: 4 });
console.log(firstSliceChars.slice(0, 3).join(''));       // 高频 '你','好','世' 前 3（频率降序）
console.log(slices.length === 2);                        // 7 个去重字符 / 4 = 2 片

// 连续码点合并
const ascii = planSlices('abcde', { sliceSize: 10 });
console.log(ascii.slices[0].range === 'U+61-65');
// 不连续
const mixed = planSlices('ac', { sliceSize: 10 });
console.log(mixed.slices[0].range === 'U+61, U+63');
// 单片边界
const one = planSlices('xyz', { sliceSize: 100 });
console.log(one.slices.length === 1);
console.log(planSlices('', { sliceSize: 10 }).slices.length === 0);
```

**评分点**：
- 频率降序与去重正确（首片是高频字符，preload 目标）
- unicode-range 生成正确：连续码点合并区间（U+61-65）、单个独立（U+63）、逗号分隔、大写 hex
- 分片不重叠；空文本返回空
- 能说清「首片高频 + preload 是 FOUT 治理的构建半边」属于加分
