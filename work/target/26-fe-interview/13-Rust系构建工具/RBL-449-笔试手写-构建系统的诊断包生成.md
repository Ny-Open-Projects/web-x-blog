## RBL-449：手写构建诊断包生成器
**需求**：实现 `createDiagnosticBundle()`：1) `collect()`：打包诊断要素——环境（OS/Node/工具版本/插件版本清单）、配置（脱敏后）、最近错误、最小复现（失败模块 + 依赖闭包的源码——可选脱敏）、日志尾部；2) 脱敏：secrets/env 值脱敏、路径归一（user 目录泛化）；3) 输出 zip/tar（单文件可粘贴给支持方）；4) 用户确认清单（展示将包含的内容——隐私透明）；5) 体积控制（源码闭包超过 1MB 截断为清单）。

```javascript
import os from 'node:os'

const SECRET_RE = /(token|secret|password|key)[=:]\s*\S+/gi

export async function createDiagnosticBundle({ root, error, config, plugins, logs }) {
  // 用户确认清单
  const manifest = [
    'environment.json (OS/Node/versions)',
    'config.json (sanitized)',
    'error.json (last error)',
    'minrepro/ (failed module + dep closure, sanitized)',
    'logs-tail.txt (last 200 lines)',
  ]
  const env = {
    os: `${os.type()} ${os.release()}`, arch: os.arch(),
    node: process.version, plugins: plugins.map((p) => `${p.name}@${p.version}`),
  }
  const configSanitized = JSON.parse(JSON.stringify(config).replace(SECRET_RE, '$1=[REDACTED]'))
  const pathNorm = (s) => s.replace(new RegExp(os.homedir(), 'g'), '~')

  const files = {
    'environment.json': JSON.stringify(env, null, 2),
    'config.json': JSON.stringify(configSanitized, null, 2),
    'error.json': JSON.stringify({ message: error?.message, stack: error?.stack?.split('\n').slice(0, 10) }, null, 2),
    'logs-tail.txt': logs.slice(-200).map(pathNorm).join('\n'),
  }
  // 最小复现：失败模块 + 依赖闭包
  const closure = error?.moduleDeps ?? []
  let total = 0
  for (const f of closure) {
    if (total > 1024 * 1024) { files['minrepro/TRUNCATED.txt'] = 'closed too large — file list only'; break }
    files[`minrepro/${f}`] = readSanitized(f)                  // 读源码 + 脱敏
    total += files[`minrepro/${f}`].length
  }
  return { manifest, files }                                   // 用户确认后再打包上传
}
const readSanitized = (f) => fs.readFileSync(f, 'utf8').replace(SECRET_RE, '$1=[REDACTED]')
```
**评分点**：
- 诊断五要素齐备（环境/配置/错误/最小复现/日志）
- 双层脱敏（secrets 正则 + 路径 home 泛化）
- 用户确认清单前置（隐私透明——诊断包不是偷偷上传）
- 体积控制（闭包超限截断为清单——诊断包不失控）
