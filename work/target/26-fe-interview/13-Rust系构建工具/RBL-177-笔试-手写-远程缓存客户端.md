## RBL-177：笔试：手写远程缓存客户端（HTTP 拉取 + 本地兜底 + 写入竞态处理）

**题目**：写 cache-client.mjs：实现 get(key) 与 put(key, payload)：1) get 先查本地 .cache/local/{key}，miss 时请求远程 GET /artifacts/{key}，命中则落本地并返回内容；2) 远程请求带 2s 超时与一次重试，超时/网络错降级为本地 miss 不抛错；3) put 并发 PUT 上传，与本地写入合并（写完本地即认为成功，上传失败仅告警）；4) payload 为 Buffer，key 为 hex hash；5) 统计 hit/localHit/miss 计数输出。

```javascript
// cache-client.mjs
import { existsSync, readFileSync, writeFileSync, mkdirSync } from 'node:fs';
import { join } from 'node:path';

const LOCAL = '.cache/local';
const stats = { hit: 0, localHit: 0, miss: 0 };

async function fetchWithTimeout(url, opts = {}, ms = 2000) {
  const ac = new AbortController();
  const t = setTimeout(() => ac.abort(), ms);
  try {
    const r = await fetch(url, { ...opts, signal: ac.signal,
      headers: { authorization: `Bearer ${process.env.CACHE_TOKEN}`, ...opts.headers } });
    return r;
  } finally { clearTimeout(t); }
}

export async function get(key) {
  const local = join(LOCAL, key);
  if (existsSync(local)) { stats.localHit++; return readFileSync(local); }
  for (let i = 0; i < 2; i++) {                 // 一次重试
    try {
      const r = await fetchWithTimeout(`${process.env.CACHE_API}/artifacts/${key}`);
      if (r.ok) {
        const buf = Buffer.from(await r.arrayBuffer());
        mkdirSync(LOCAL, { recursive: true });
        writeFileSync(local, buf);              // 回填本地
        stats.hit++; return buf;
      }
      if (r.status === 404) break;              // 不存在无需重试
    } catch (e) { /* 网络错/超时：降级 */ }
  }
  stats.miss++; return null;                    // 永不抛错，缓存只是加速层
}

export async function put(key, payload) {
  mkdirSync(LOCAL, { recursive: true });
  writeFileSync(join(LOCAL, key), payload);     // 本地先行
  try {
    const r = await fetchWithTimeout(`${process.env.CACHE_API}/artifacts/${key}`,
      { method: 'PUT', body: payload, headers: { 'content-type': 'application/octet-stream' } }, 10_000);
    if (!r.ok) console.warn(`[cache] remote put failed ${r.status}`);
  } catch { console.warn('[cache] remote put error (local ok)'); }
}
export const cacheStats = () => stats;
```
**评分点**：
- 本地优先 + 远程回填（两级语义清晰）。
- 超时 + 有限重试，404 不重试。
- 缓存失败降级不抛错（缓存是优化不是依赖）。
- put 本地先行、远程失败仅告警。
- 能提缓存投毒：put 必须带写鉴权 token。
