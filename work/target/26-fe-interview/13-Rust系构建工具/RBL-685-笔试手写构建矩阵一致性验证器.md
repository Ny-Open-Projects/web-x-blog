## RBL-685：笔试：手写多形态产物一致性验证器（行为对比 + 差异白名单）

**答**：实现 `verifyMatrix(outputs, testCases, { allowedDiffs })`。outputs: `{ variant, exports: Record<name, Function> }[]`；testCases: `{ name, args, expect, exportName }[]`——对每个变体的同一名导出执行同参数调用，断言结果一致。规则：1) 基准 = 第一个变体（esm-es2019）；2) 某变体结果与基准不同 → 记 diff `{ case, variant, base, actual }`；3) diff 命中 allowedDiffs（匹配 variant 名或 variant+'.'+case 名，支持通配 \*）→ 标记 allowed；4) 未允许的 diff 使验证失败，返回 `{ ok, diffs }`；5) 变体缺导出 → diff type 'missing-export'。边界：无 testCases 返回 ok；expect 与基准不等时整个验证 fail（基准自身错了）。

```javascript
function verifyMatrix(outputs, testCases, { allowedDiffs = [] } = {}) {
  if (testCases.length === 0) return { ok: true, diffs: [] };
  const base = outputs[0];
  const diffs = [];
  const allowed = (variant, name) => allowedDiffs.some(p =>
    p === variant || p === '*' || p === `${variant}.${name}`);

  for (const tc of testCases) {
    const baseFn = base.exports[tc.exportName];
    const baseRes = typeof baseFn === 'function' ? safeCall(baseFn, tc.args) : MISSING;
    if (tc.expect !== undefined && !deepEq(baseRes, tc.expect))
      return { ok: false, diffs: [{ case: tc.name, variant: base.variant, type: 'bad-base', base: baseRes }] };
    for (const out of outputs.slice(1)) {
      const fn = out.exports[tc.exportName];
      const res = typeof fn === 'function' ? safeCall(fn, tc.args) : MISSING;
      if (deepEq(res, baseRes)) continue;
      const d = { case: tc.name, variant: out.variant, type: res === MISSING ? 'missing-export' : 'value',
                  base: baseRes, actual: res === MISSING ? undefined : res,
                  allowed: allowed(out.variant, tc.name) };
      diffs.push(d);
    }
  }
  return { ok: diffs.every(d => d.allowed), diffs };
}
const MISSING = Symbol('missing');
const safeCall = (fn, args) => { try { return fn(...args); } catch (e) { return { __error: e.message }; } };
const deepEq = (a, b) => JSON.stringify(a) === JSON.stringify(b);

// 自测
const outputs = [
  { variant: 'esm-es2019', exports: { fmt: (n) => n.toFixed(2) } },
  { variant: 'iife', exports: { fmt: (n) => n.toFixed(2) } },
  { variant: 'es5', exports: { fmt: (n) => n.toFixed(2), legacyFmt: undefined } },
];
let r = verifyMatrix(outputs, [{ name: 'fmt', exportName: 'fmt', args: [3.141] }]);
console.log(r.ok === true);

// 降级包差异：允许
r = verifyMatrix(outputs,
  [{ name: 'legacyFmt', exportName: 'legacyFmt', args: [1] }],
  { allowedDiffs: ['es5.*'] });
console.log(r.ok === true && r.diffs[0].type === 'missing-export' && r.diffs[0].allowed === true);

// 未允许的差异
const broken = [{ variant: 'esm-es2019', exports: { fmt: (n) => n.toFixed(2) } },
                { variant: 'cjs', exports: { fmt: () => 'oops' } }];
r = verifyMatrix(broken, [{ name: 'fmt', exportName: 'fmt', args: [1.5] }]);
console.log(r.ok === false && r.diffs[0].variant === 'cjs');

// 基准错误
r = verifyMatrix(outputs, [{ name: 'fmt', exportName: 'fmt', args: [1.5], expect: 'wrong' }]);
console.log(r.ok === false && r.diffs[0].type === 'bad-base');
console.log(verifyMatrix(outputs, []).ok === true);
```

**评分点**：
- 基准先行：expect 校验基准自身（bad-base 短路），各变体对基准比较
- 差异白名单支持变体级/通配，missing-export 与 value 两类 diff 区分
- 安全调用（抛错变 __error 记录不中断）；无 testCases 直接 ok
- 能说清「多形态一致性是 SDK 质量底线，差异必须有白名单理由」属于加分
