## RBL-197：笔试：手写可恢复任务队列（CI 中断后从断点续跑）

**题目**：写 resumable-build.mjs：1) 场景：百包 monorepo 构建 40 分钟，CI 超时中断后重跑不应从头来；2) 任务状态持久化到 .build-state.json：{taskId: 'done'|'failed'|'pending'}；3) 启动时读状态文件，跳过 done 任务；4) 执行失败任务重试 1 次（可能是网络抖动），仍失败标记 failed 并继续其他任务（不 fail-fast，最大化利用本次运行）；5) 结束时输出：本次完成/跳过/仍失败清单；全部 done 则清空状态文件（下次全新开始）。

```javascript
// resumable-build.mjs
import { execSync } from 'node:child_process';
import { existsSync, readFileSync, writeFileSync, rmSync } from 'node:fs';

const STATE_FILE = '.build-state.json';
const loadState = () => existsSync(STATE_FILE)
  ? JSON.parse(readFileSync(STATE_FILE, 'utf8'))
  : Object.fromEntries(JSON.parse(readFileSync('tasks.json')).map(t => [t, 'pending']));

export async function runResumable(tasks, runOne, { retries = 1 } = {}) {
  const state = loadState();
  const pending = tasks.filter(t => state[t] !== 'done');
  console.log(`resume: ${tasks.length - pending.length} done, ${pending.length} pending`);

  const stillFailed = [];
  for (const task of pending) {           // 不 fail-fast：逐个处理把状态推到最远
    let ok = state[task] === 'done';
    for (let r = 0; r <= retries && !ok; r++) {
      try { await runOne(task); ok = true; }
      catch (e) { console.error(`FAIL ${task}${r < retries ? ' (retry)' : ''}: ${e.message}`); }
    }
    state[task] = ok ? 'done' : 'failed';
    if (!ok) stillFailed.push(task);
    writeFileSync(STATE_FILE, JSON.stringify(state, null, 2)); // 每个任务后落盘，中断可续
  }
  const done = tasks.filter(t => state[t] === 'done').length;
  const summary = { completed: pending.length - stillFailed.length,
    skipped: tasks.length - pending.length, stillFailed };
  if (tasks.every(t => state[t] === 'done')) {
    rmSync(STATE_FILE);                    // 全部完成清空，下次构建全新开始
    console.log('all done, state cleared');
  }
  return summary;
}
// runOne = (pkg) => execSync(`pnpm --filter ${pkg} build`, { stdio: 'inherit' })
// CI 超时中断 → 下次同 commit 重跑时 done 的包全部跳过，只补 failed/pending。
```
**评分点**：
- 每任务完成即落盘（中断粒度 = 单任务，不是整批）。
- 非严格 fail-fast（单任务失败仍推进其他，最大化本次运行价值）。
- 任务级重试 1 次（区分抖动与真失败）。
- 全部完成清状态文件（避免陈旧状态误跳过）。
- 能说出局限：依赖"输入没变"前提，commit 变了应重置状态（可结合指纹 hash 做校验）。
