## RBL-828：笔试：手写同意门控审计器（分级 + 门控检测）

**答**：实现 `auditConsent(files, { essential, knownTrackers })`。files: `{ name, code }[]`；essential: 文件名数组（豁免）；knownTrackers: 包标识字符串数组。规则：1) 非 essential 文件命中 knownTrackers 且代码不含 `consentGranted` 门控 → blocker 'ungated-tracker'；2) 非 essential 文件在「顶层执行路径」写 cookie（`document.cookie=` 且不在函数内/事件回调中——简化：行不含 function/=> 且不以 if 开头）→ blocker 'pre-consent-cookie'；3) essential 豁免一切；4) 返回 `{ blockers, ok }`（blockers 去重排序）。边界：空 essential；knownTrackers 空。

```javascript
function auditConsent(files, { essential = [], knownTrackers = [] } = {}) {
  const blockers = [];
  const seen = new Set();
  for (const f of files) {
    if (essential.includes(f.name)) continue;             // 豁免
    const lines = (f.code ?? '').split('\n');
    const gated = f.code.includes('consentGranted');
    for (const t of knownTrackers)
      if (f.code.includes(t) && !gated && !seen.has(`${f.name}:${t}`)) {
        seen.add(`${f.name}:${t}`);
        blockers.push(`ungated-tracker: ${f.name} 含 ${t} 但无同意门控`);
      }
    lines.forEach((line, i) => {
      const t = line.trim();
      if (t.includes('document.cookie=') &&
          !/function|=>|if/.test(t))                       // 顶层直写 cookie
        blockers.push(`pre-consent-cookie: ${f.name}:${i + 1}`);
    });
  }
  blockers.sort();
  return { blockers: [...new Set(blockers)], ok: blockers.length === 0 };
}

// 自测
const files = [
  { name: 'app.js', code: "document.cookie='theme=dark';\nimport './analytics';" },   // cookie 直写 + tracker 但 app 未门控
  { name: 'analytics.js', code: "consentGranted('analytics').then(() => init()); gtag();" },  // 门控 ok
  { name: 'ads.js', code: 'window.adsinit = 1; adsSdk();' },   // 未门控
  { name: 'consent-cmp.js', code: "document.cookie='consent=1';" },  // essential 豁免
];
let r = auditConsent(files, {
  essential: ['consent-cmp.js'],
  knownTrackers: ['gtag', 'adsSdk'],
});
console.log(r.ok === false);
console.log(r.blockers.some(b => b.startsWith('ungated-tracker: ads.js')));
console.log(r.blockers.some(b => b.startsWith('pre-consent-cookie: app.js:1')));
// app.js 含 tracker？不含（analytics import 不在 knownTrackers 匹配）——检查
console.log(!r.blockers.some(b => b.includes('app.js') && b.startsWith('ungated')));

console.log(auditConsent(files, { essential: ['app.js', 'consent-cmp.js', 'ads.js'], knownTrackers: ['adsSdk'] }).ok === true);
console.log(auditConsent([], { knownTrackers: ['x'] }).ok === true);
```

**评分点**：
- 分级豁免（essential 跳过一切）与未知脚本保守归 tracking 的判定正确
- 双向量检测：未门控追踪（knownTrackers + 无 consentGranted）与同意前 cookie 直写（顶层行判定）
- 去重排序输出；空输入安全
- 能说清「unknown 默认按 tracking 是把风险从不可逆的合规违规移到可观测的性能损耗」属于加分
