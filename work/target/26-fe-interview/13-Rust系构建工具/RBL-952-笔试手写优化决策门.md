## RBL-952：笔试：手写优化决策门（微基准 × 占比）

**答**：实现 `optimizationGate({ microDelta, fnShare, riskCost = 0.02, macroVerify })`。规则：1) expectedGain = microDelta × fnShare（microDelta 为相对提升 0~1）；2) expectedGain < riskCost（默认 2%）→ reject `{ reason }`（占比过低不值得冒险）；3) 达标且 macroVerify=true → 'merge'；macroVerify=false → 'macro-verify-required'（微基准只能定位，合并前必须宏复验）；4) fnShare > 0.5 且 microDelta > 0.5 → 加 note '高占比高收益——优先验证'。返回 `{ verdict, expectedGain }`。边界：fnShare 0；microDelta ≤ 0（负优化直接 reject）；参数越界。

```javascript
function optimizationGate({ microDelta, fnShare, riskCost = 0.02, macroVerify = false } = {}) {
  if (microDelta == null || fnShare == null || microDelta < 0 || fnShare < 0 || fnShare > 1)
    throw new Error('参数非法');
  if (microDelta === 0) return { verdict: 'reject', expectedGain: 0, reason: '无提升' };
  const expectedGain = +(microDelta * fnShare).toFixed(4);
  if (expectedGain < riskCost)
    return { verdict: 'reject', expectedGain,
      reason: `占比 ${(fnShare * 100).toFixed(1)}% × 提升 ${(microDelta * 100).toFixed(0)}% = 宏收益 ${(expectedGain * 100).toFixed(1)}% < 风险成本 ${(riskCost * 100).toFixed(0)}%` };
  const verdict = macroVerify ? 'merge' : 'macro-verify-required';
  const note = fnShare > 0.5 && microDelta > 0.5 ? '高占比高收益——优先验证' : undefined;
  return { verdict, expectedGain, ...(note && { note }) };
}

// 自测
// 高占比：微基准值得，但需宏复验
let r = optimizationGate({ microDelta: 0.3, fnShare: 0.4 });
console.log(r.expectedGain === 0.12 && r.verdict === 'macro-verify-required');

// 宏已复验 → merge
r = optimizationGate({ microDelta: 0.3, fnShare: 0.4, macroVerify: true });
console.log(r.verdict === 'merge');

// 低占比：拒绝
r = optimizationGate({ microDelta: 0.3, fnShare: 0.05 });
console.log(r.verdict === 'reject' && r.expectedGain === 0.015);
console.log(r.reason.includes('宏收益 1.5%'));

// 高占比高收益 note
r = optimizationGate({ microDelta: 0.6, fnShare: 0.8, macroVerify: true });
console.log(r.note === '高占比高收益——优先验证');

// 边界
r = optimizationGate({ microDelta: 0.2, fnShare: 0 });
console.log(r.verdict === 'reject' && r.expectedGain === 0);
r = optimizationGate({ microDelta: 0, fnShare: 0.9 });
console.log(r.verdict === 'reject');
let e; try { optimizationGate({ microDelta: 0.2, fnShare: 1.5 }); } catch (x) { e = x; }
console.log(/非法/.test(e.message));
```

**评分点**：
- 期望宏收益公式（微提升 × 占比）——「占比只能来自宏 profile」的决策模型
- macroVerify 闸门（微基准定位、宏基准决策的分工）；高占比高收益的优先级提示
- 边界：零提升/零占比/越界参数
- 能说清「微基准快 30% 但宏基准不变应回滚——决策依据是占比 × 收益而非局部速度」属于加分
