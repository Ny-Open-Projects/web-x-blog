## RBL-896：笔试：手写预取命中率分析器（命中率 + 浪费 + 调整）

**答**：实现 `prefetchAnalytics(events, { wasteThreshold })`。events: `{ url, type: 'prefetch'|'navigate', reused? }[]`。规则：1) hitRate = 命中的 prefetch / 全部 prefetch（命中 = reused=true 或 url 出现在后续 navigate）×100 保留 1 位；2) wasteByRoute：按路由（url 第一段路径）聚合的浪费率（未命中占比），保留 2 位小数；3) adjustments：浪费率 > wasteThreshold 的路由 → `{ route, action: 'remove-idle' }`；命中率高（>80%）的路由 → `{ route, action: 'promote-hover' }`；4) 返回 `{ hitRate, wasteByRoute, adjustments }`（无 prefetch 时 hitRate null）。边界：空 events；全命中（浪费率 0）。

```javascript
const routeOf = (url) => '/' + (url.split('/')[1] ?? '');

function prefetchAnalytics(events = [], { wasteThreshold = 0.5 } = {}) {
  const prefetches = events.filter(e => e.type === 'prefetch');
  if (!prefetches.length) return { hitRate: null, wasteByRoute: {}, adjustments: [] };
  const navigated = new Set(events.filter(e => e.type === 'navigate').map(e => e.url));
  const hits = prefetches.filter(e => e.reused || navigated.has(e.url));
  const hitRate = +(hits.length / prefetches.length * 100).toFixed(1);

  const byRoute = {};
  for (const e of prefetches) {
    const r = routeOf(e.url);
    (byRoute[r] = byRoute[r] || { total: 0, hit: 0 });
    byRoute[r].total++;
    if (e.reused || navigated.has(e.url)) byRoute[r].hit++;
  }
  const wasteByRoute = Object.fromEntries(Object.entries(byRoute)
    .map(([r, s]) => [r, +((s.total - s.hit) / s.total).toFixed(2)]));

  const adjustments = [];
  for (const [r, w] of Object.entries(wasteByRoute)) {
    if (w > wasteThreshold) adjustments.push({ route: r, action: 'remove-idle' });
    else if (w === 0 && byRoute[r].total >= 5)
      adjustments.push({ route: r, action: 'promote-hover' });
  }
  return { hitRate, wasteByRoute, adjustments };
}

// 自测
const events = [
  { url: '/shop/a.js', type: 'prefetch' }, { url: '/shop', type: 'navigate' },   // 命中
  { url: '/shop/b.js', type: 'prefetch' },                                        // 浪费
  { url: '/blog/x.js', type: 'prefetch', reused: true },                          // 命中
  { url: '/blog/y.js', type: 'prefetch' },
  { url: '/blog/z.js', type: 'prefetch' },
  { url: '/blog/w.js', type: 'prefetch' },
  { url: '/blog/v.js', type: 'prefetch' },                                        // blog 5/6 浪费
  { url: '/blog', type: 'navigate' },
];
let r = prefetchAnalytics(events, { wasteThreshold: 0.5 });
console.log(r.hitRate === 25.0);                         // 2/8
console.log(r.wasteByRoute['/shop'] === 0.5);
console.log(r.wasteByRoute['/blog'] === 0.83);
console.log(r.adjustments.some(a => a.route === '/blog' && a.action === 'remove-idle'));
console.log(!r.adjustments.some(a => a.route === '/shop'));   // 0.5 不超阈值

// 全命中 -> promote
r = prefetchAnalytics(Array.from({ length: 6 }, (_, i) =>
  ({ url: `/docs/d${i}.js`, type: 'prefetch', reused: true })));
console.log(r.hitRate === 100 && r.adjustments[0].action === 'promote-hover');

console.log(prefetchAnalytics([], {}).hitRate === null);
```

**评分点**：
- 命中双判据（reused 或后续 navigate）；hitRate 精度；无 prefetch 返回 null（不是 0）
- 分路由浪费率聚合正确；调整双动作（浪费 remove-idle、全命中 promote-hover 且带最小样本量防噪声）
- 边界：空 events、全命中
- 能说清「命中率优于覆盖率——指标定义的反身性决定优化方向」属于加分
