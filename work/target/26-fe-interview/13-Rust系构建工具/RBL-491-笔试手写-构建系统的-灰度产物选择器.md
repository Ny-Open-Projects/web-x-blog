## RBL-491：手写灰度产物选择器
**需求**：实现 `selectArtifact(request, releases)`：1) releases：[{ version, ratio, hash, status: active|paused }]；2) 灰度选择：按请求特征（uid hash 分桶——sticky；同一用户始终同版本）；3) 全量版本兜底（灰度版本全部 paused → 主版本）；4) 灰度比例调整（ratio 从 5%→100% 渐进，uid 取模保证扩大时老用户不跳变——sticky bucketing 的扩容一致性）；5) 返回 { version, hash, bucket }；6) 拨测支持：probe(uid) 模拟任意 uid 的分桶结果（灰度验证工具）。

```javascript
export function selectArtifact(request, releases, { stickySalt = 'v1' } = {}) {
  const active = releases.filter((r) => r.status === 'active')
  const main = releases.find((r) => r.status === 'active' && r.ratio >= 100) ?? releases[0]
  const grays = active.filter((r) => r.ratio < 100)

  function bucketOf(uid, version) {
    return parseInt(crypto.createHash('md5').update(`${stickySalt}:${version}:${uid}`).digest('hex').slice(0, 8), 16) % 10000 / 100
  }

  for (const gray of grays.sort((a, b) => a.ratio - b.ratio)) {
    if (bucketOf(request.uid, gray.version) < gray.ratio)
      return { version: gray.version, hash: gray.hash, bucket: 'gray' }
  }
  return { version: main.version, hash: main.hash, bucket: 'main' }
}
// 扩容一致性：bucketOf 按 version 锚定 → ratio 5→10 扩大时，原 5% 用户仍在（hash 不变）
// 验证工具：probe(uid) 遍历 releases 返回用户将拿到的版本
export const probe = (uid, releases) => selectArtifact({ uid }, releases)
```
**评分点**：
- sticky 分桶（uid+version 锚定 hash——同用户不跳变）
- 扩容一致性原理（ratio 扩大时旧桶用户不迁移——分桶盐值设计）
- 全量兜底（灰度全 paused → 主版本——可用性优先）
- probe 工具（灰度验证——分桶可测试）
