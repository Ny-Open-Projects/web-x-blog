## RBL-495：手写产物版权声明注入
**需求**：实现 `injectLicenseNotice(assets, deps)`：1) 收集依赖 license 信息（MIT/Apache/GPL——类型与版权人）；2) 策略分派：MIT/Apache → THIRD-PARTY-NOTICES 文件（文本保留）；GPL 类 → 构建阻断（公司策略）或显式豁免；3) 产物 banner：主 bundle 头部注入精简声明（版权行）；4) NOTICES 文件生成（按包排序 + license 全文引用）；5) 一致性校验：产物内实际打包的包 ↔ NOTICES 清单一致（多/少都告警——清单与事实同步）。

```javascript
export function injectLicenseNotice(assets, deps, { allowList = ['MIT', 'Apache-2.0', 'BSD-*', 'ISC'] } = {}) {
  const notices = []
  const blocked = []
  for (const dep of deps) {
    if (!dep.license) { blocked.push({ name: dep.name, reason: 'license unknown' }); continue }
    if (!allowList.some((a) => matchLicense(a, dep.license)))
      blocked.push({ name: dep.name, license: dep.license, reason: 'policy blocked' })
    else notices.push({ name: dep.name, version: dep.version, license: dep.license,
      copyright: dep.author ?? 'contributors' })
  }
  if (blocked.length)
    throw new Error(`license 策略阻断: ${blocked.map((b) => `${b.name}(${b.license})`).join(', ')}`)

  // THIRD-PARTY-NOTICES 生成
  const noticesMd = [
    '# Third Party Notices',
    ...notices.sort((a, b) => a.name.localeCompare(b.name))
      .map((n) => `- ${n.name}@${n.version} — ${n.license} © ${n.copyright}`),
  ].join('\n')

  // 主 bundle banner（精简）
  const banner = `/*! Contains third-party software. See THIRD-PARTY-NOTICES. (c) ${new Date().getFullYear()} */`
  for (const [name, source] of Object.entries(assets))
    if (name.endsWith('.js')) assets[name] = new RawSource(banner + '\n' + source.source())

  // 一致性：NOTICES ↔ 实际打包
  const bundled = new Set(deps.filter((d) => d.inBundle).map((d) => d.name))
  const listed = new Set(notices.map((n) => n.name))
  const mismatch = [...bundled].filter((p) => !listed.has(p))
  if (mismatch.length) console.warn(`打包但未列入 NOTICES: ${mismatch}`)   // 清单与事实同步告警

  assets['THIRD-PARTY-NOTICES.md'] = new RawSource(noticesMd)
  return { notices: notices.length, banner }
}
const matchLicense = (pattern, license) =>
  pattern.endsWith('*') ? license.startsWith(pattern.slice(0, -1)) : pattern === license
```
**评分点**：
- 策略分派（allowList 匹配 + GPL 阻断——合规策略可配置）
- NOTICES 文件 + banner 双载体（文件保留与产物标记）
- 一致性校验（打包事实 ↔ NOTICES 清单同步——多/少都告警）
- license unknown 也是阻断（未知的合规风险——不只是 GPL 才拦）
