## RBL-178：笔试：手写拓扑排序任务调度器（依赖图 → 并发执行波次）

**题目**：写 schedule.js：1) 输入任务表 {name, deps: [...]} 与并发度 N；2) 输出执行计划：把任务分波次，每波内任务无依赖关系可并行；3) 环检测：存在循环依赖时报错并列出环路径；4) 提供 execute(tasks, runner) 实际按波次并发执行（Promise.all 每波），某任务失败则后续波次取消；5) 波次内数量 ≤ N 的说明要等待槽位（用池实现而非整波等待，见代码）。

```javascript
// schedule.js
function topoWaves(tasks) {
  const indeg = new Map(), byName = new Map(tasks.map(t => [t.name, t]));
  for (const t of tasks) indeg.set(t.name, 0);
  for (const t of tasks) for (const d of t.deps) {
    if (!byName.has(d)) throw new Error(`未知依赖 ${d}`);
    indeg.set(t.name, indeg.get(t.name) + 1);
  }
  const waves = []; let wave = tasks.filter(t => indeg.get(t.name) === 0).map(t => t.name);
  const done = new Set();
  while (wave.length) {
    waves.push(wave);
    wave.forEach(n => done.add(n));
    const next = [];
    for (const t of tasks) {
      if (done.has(t.name)) continue;
      if (t.deps.every(d => done.has(d))) next.push(t.name);
    }
    wave = next;                                  // 不减 indeg 的写法用全量检查，简单正确
  }
  if (done.size !== tasks.length) {               // 环检测：找出剩余节点路径
    const cyc = tasks.filter(t => !done.has(t.name)).map(t => t.name);
    throw new Error(`循环依赖: ${cyc.join(' -> ')} -> ${cyc[0]}`);
  }
  return waves;
}

async function execute(tasks, runner, concurrency = 4) {
  const waves = topoWaves(tasks);
  const results = new Map();
  for (const wave of waves) {
    const pool = [...wave];
    const workers = Array.from({ length: Math.min(concurrency, pool.length) }, async () => {
      while (pool.length) {
        const name = pool.shift();
        results.set(name, await runner(byName(name)));
      }
    });
    await Promise.all(workers);                   // 波内并发，整波屏障保证依赖序
  }
  return results;
}
module.exports = { topoWaves, execute };
// wave1: [a,b,c]（无依赖）→ wave2: [d]（依赖 a,b）→ wave3: [e]
```
**评分点**：
- 波次划分正确：波内可并行、波间满足依赖。
- 环检测并输出环路径（不是只说"有环"）。
- 并发用 worker 池而非 wave-size 个并发（并发度可控）。
- 失败传播：runner 抛错终止后续波次。
- 能对比 turbo 的真实实现：动态调度（上游完成即调度下游，不必整波屏障）。
