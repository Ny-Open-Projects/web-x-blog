## RBL-716：笔试：手写导出面契约校验器（d.ts 声明 vs 运行时导出）

**答**：实现 `verifyExports(declared, runtime, { allowMissing })`。declared: d.ts 声明的导出名数组（含 'default'）；runtime: 实际运行时导出对象。规则：1) 声明但运行时缺失 → problem 'missing-runtime'（默认阻断）；2) 运行时存在但未声明 → problem 'undeclared'（警告级，可能是内部导出泄漏）；3) allowMissing: 白名单（声明了但确实可选缺失的导出名）豁免 missing；4) 返回 `{ problems: Array<{ name, type, level: 'error'|'warn' }>, ok }`。边界：两边全空 ok；declared 含重复名去重后校验。

```javascript
function verifyExports(declared = [], runtime = {}, { allowMissing = [] } = {}) {
  const rtSet = new Set(Object.keys(runtime));
  const seen = new Set();
  const problems = [];
  for (const name of declared) {
    if (seen.has(name)) continue;                        // 去重
    seen.add(name);
    if (!rtSet.has(name) && !allowMissing.includes(name))
      problems.push({ name, type: 'missing-runtime', level: 'error' });
  }
  for (const name of rtSet)
    if (!seen.has(name))
      problems.push({ name, type: 'undeclared', level: 'warn' });
  return { problems, ok: !problems.some(p => p.level === 'error') };
}

// 自测
const runtime = { default: 1, Button: 1, legacyUtil: 1 };   // legacyUtil 未声明
let r = verifyExports(['default', 'Button'], runtime);
console.log(r.ok === true && r.problems[0].type === 'undeclared');

r = verifyExports(['default', 'Button', 'Modal'], runtime);  // Modal 缺
console.log(r.ok === false && r.problems.some(p => p.type === 'missing-runtime' && p.name === 'Modal'));
console.log(r.problems.some(p => p.type === 'undeclared'));

// 白名单豁免
r = verifyExports(['default', 'Modal'], runtime, { allowMissing: ['Modal'] });
console.log(r.ok === true && r.problems[0].type === 'undeclared');

// 重复声明
r = verifyExports(['Button', 'Button'], runtime);
console.log(r.problems.length === 1);                    // 只报 undeclared（Button 无重复问题）

console.log(verifyExports([], {}).ok === true);
console.log(verifyExports([], runtime).problems.every(p => p.type === 'undeclared'));
```

**评分点**：
- 双向校验：声明缺失（error 级阻断）与未声明泄漏（warn 级）区分
- allowMissing 豁免正确（可选导出场景）；declared 去重
- ok 由 error 级决定；全空通过
- 能说清「类型说有、运行时没有是 TS 生态最阴险的静默错」属于加分
