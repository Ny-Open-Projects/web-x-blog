## RBL-945：笔试：手写一页纸叙事审计器（数字锚点 + 反模式）

**答**：实现 `auditNarrative(page)`。page: 五段 `{ 现状, 改善, 投资, 里程碑, 风险锚点 }`（字符串）。规则：1) 每段必须含数字（/\d/）——无数字 → finding 'no-anchor'；2) 反模式检测：改善段含「大幅提升」「显著优化」「非常好」等模糊词（无数字伴随）→ 'vague-claim'；3) 投资段必须含「回本」或「payback」→ 'no-roi'；4) 风险锚点段为空或纯技术词（全是 webpack/构建 等，无「事故/合规/风险」业务词）→ 'no-risk-anchor'；5) 返回 `{ findings: Array<{ section, type }>, ok }`。边界：段缺失（作为 finding 'missing-section'）；全数字段。

```javascript
const VAGUE = /大幅|显著|非常好|极大提升|明显优化/;
const RISK_WORDS = /事故|合规|风险|故障|泄漏|瓶颈/;

function auditNarrative(page = {}) {
  const findings = [];
  const sections = ['现状', '改善', '投资', '里程碑', '风险锚点'];
  for (const s of sections) {
    if (page[s] == null || page[s] === '') {
      findings.push({ section: s, type: 'missing-section' }); continue;
    }
    const text = String(page[s]);
    if (!/\d/.test(text)) findings.push({ section: s, type: 'no-anchor' });
    if (s === '改善' && VAGUE.test(text)) findings.push({ section: s, type: 'vague-claim' });
    if (s === '投资' && !/回本|payback/i.test(text)) findings.push({ section: s, type: 'no-roi' });
    if (s === '风险锚点' && !RISK_WORDS.test(text)) findings.push({ section: s, type: 'no-risk-anchor' });
  }
  return { findings, ok: findings.length === 0 };
}

// 自测
let good = {
  现状: '上线前置 48h | 故障 3 次/月 | 维护者 1 人',
  改善: '→ 前置 2h | 故障 0.2 次/月 | 自助率 85%',
  投资: '6 人月，回本 45 天',
  里程碑: '3 阶段完成率 66%',
  风险锚点: '不做 = 发布事故持续 + 合规缺口 + 单点风险',
};
console.log(auditNarrative(good).ok === true);

let bad = {
  现状: '构建很慢',                                   // 无数字
  改善: '将大幅提升构建体验',                          // 模糊 + 无数字
  投资: '需要 6 人月',                                 // 无回本
  里程碑: '分阶段推进',                                // 无数字
  风险锚点: '当前构建使用 webpack 4',                  // 无业务风险词
};
let r = auditNarrative(bad);
console.log(r.findings.map(f => f.type).sort().join(','));
// missing-section? 无。no-anchor, vague-claim, no-roi, no-anchor, no-risk-anchor
console.log(r.ok === false);

// 缺段
r = auditNarrative({ 现状: '3 小时' });
console.log(r.findings.filter(f => f.type === 'missing-section').length === 4);
console.log(auditNarrative({}).findings.length === 5);
```

**评分点**：
- 数字锚点检查全段覆盖；模糊词检测仅限改善段（精准定位反模式）
- 投资段 ROI 强制、风险段业务词强制（价值/风险/投资三类语言齐备才可决策）
- 缺段独立报告（missing-section 与内容问题区分）；边界
- 能说清「叙事与度量同源（每个论断带数字锚点）——技术完美但叙事失败拿不到资源」属于加分
