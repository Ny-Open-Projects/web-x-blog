## RBL-621：笔试：手写错误堆栈反解器（sourcemap 查询 + 版本绑定）

**答**：实现 `resolveStack(frames, mapStore)`。frames: `{ file, line, col, version }[]`（产物堆栈帧）；mapStore: `get(version, file) -> { rows: Array<Array<[genCol, srcIdx, srcLine, srcCol]>>, sources: string[] } | null`。返回新帧数组：能查到映射的帧附加 `{ srcFile, srcLine, srcCol, approximate }`——行内二分找 ≤col 的最后一个映射段；col 精确命中 approximate=false，否则 true（取最近左侧）。查不到 map 的帧保留原样并加 `unresolved: true`。边界：line 超界、rows 空、version 缺失。

```javascript
function resolveStack(frames, mapStore) {
  return frames.map(f => {
    const map = f.version ? mapStore.get(f.version, f.file) : null;
    if (!map || f.line < 1 || f.line > map.rows.length) return { ...f, unresolved: true };
    const row = map.rows[f.line - 1];                    // 行号 1-based
    if (!row || row.length === 0) return { ...f, unresolved: true };

    // 行内二分：找 <= col 的最后一个段（col 0-based）
    let lo = 0, hi = row.length - 1, best = null;
    while (lo <= hi) {
      const mid = (lo + hi) >> 1;
      if (row[mid][0] <= f.col) { best = row[mid]; lo = mid + 1; }
      else hi = mid - 1;
    }
    if (!best) return { ...f, unresolved: true };        // col 在首段之前
    const [gCol, srcIdx, srcLine, srcCol] = best;
    return { ...f, srcFile: map.sources[srcIdx], srcLine, srcCol,
             approximate: gCol !== f.col };              // 精确命中才 false
  });
}

// 自测
const mapStore = {
  get(version, file) {
    if (version !== 'v1' || file !== 'main.js') return null;
    return {
      sources: ['src/main.ts', 'src/util.ts'],
      rows: [
        [],                                              // 第 1 行无映射
        [[0, 0, 10, 2], [10, 0, 12, 4], [20, 1, 3, 0]],  // 第 2 行三段
      ],
    };
  },
};
const frames = [
  { file: 'main.js', line: 2, col: 0, version: 'v1' },   // 精确 -> src/main.ts:11:2（0-based line 10）
  { file: 'main.js', line: 2, col: 15, version: 'v1' },  // 近似 -> [10,0,12,4]
  { file: 'main.js', line: 2, col: 99, version: 'v1' },  // 近似 -> 最后段
  { file: 'main.js', line: 1, col: 0, version: 'v1' },   // 行无映射
  { file: 'main.js', line: 2, col: 5, version: 'v2' },   // 版本无 map
  { file: 'main.js', line: 9, col: 0, version: 'v1' },   // 行超界
];
const out = resolveStack(frames, mapStore);
console.log(out[0].srcFile === 'src/main.ts' && out[0].approximate === false);
console.log(out[1].srcLine === 12 && out[1].approximate === true);
console.log(out[2].srcFile === 'src/util.ts' && out[2].approximate === true);
console.log(out[3].unresolved === true);
console.log(out[4].unresolved === true);
console.log(out[5].unresolved === true);
```

**评分点**：
- 行内二分正确（≤col 最后段），best 为 null（col 早于首段）按 unresolved 处理
- approximate 判定准确（genCol 精确相等才 false）
- 边界五连：空行、首段之前、行超界、version 缺失、map 缺失全走 unresolved 不抛错
- 能说清「版本绑定防 map-JS 错配」与「未 resolve 帧保留原样供人工排查」属于加分
