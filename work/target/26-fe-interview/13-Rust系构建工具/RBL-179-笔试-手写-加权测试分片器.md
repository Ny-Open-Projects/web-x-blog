## RBL-179：笔试：手写时间加权测试分片器（LPT 贪心装箱）

**答**：写 shard-tests.mjs：1) 输入测试文件列表与历史耗时表（JSON：file→ms），无历史的按默认值 5000ms；2) 用 LPT（最长优先）贪心分到 N 片，目标最小化最慢片；3) 输出 shards.json（每片文件列表 + 预估总时长）与每片执行命令 `vitest run --shard`；4) 校验：所有文件恰分配一次；5) 支持排除 glob（e2e/** 不参与分片，单独跑）。

```javascript
// shard-tests.mjs
import { readFileSync, writeFileSync } from 'node:fs';

const DEFAULT_MS = 5000;
function shardWeighted(files, timings, n, exclude = [/^e2e\//]) {
  const list = files.filter(f => !exclude.some(g => g.test(f)));
  const excluded = files.filter(f => exclude.some(g => g.test(f)));
  const dur = f => timings[f] ?? DEFAULT_MS;
  const sorted = [...list].sort((a, b) => dur(b) - dur(a));   // 长任务优先（LPT）
  const shards = Array.from({ length: n }, () => ({ files: [], ms: 0 }));
  for (const f of sorted) {
    const s = shards.reduce((min, x) => (x.ms < min.ms ? x : min)); // 放最轻片
    s.files.push(f); s.ms += dur(f);
  }
  shards.forEach(s => s.files.sort());                        // 输出稳定
  const total = shards.reduce((a, s) => a + s.ms, 0);
  const maxMs = Math.max(...shards.map(s => s.ms), 1);
  return { shards, excluded, balance: (total / n / maxMs).toFixed(2) }; // 越接近 1 越均衡
}

const files = JSON.parse(readFileSync(process.argv[2] ?? 'test-files.json'));
const timings = existsTimings() ? JSON.parse(readFileSync('test-timings.json', 'utf8')) : {};
const N = Number(process.env.SHARDS ?? 4);
const { shards, excluded, balance } = shardWeighted(files, timings, N);

writeFileSync('shards.json', JSON.stringify(shards, null, 2));
shards.forEach((s, i) =>
  console.log(`shard ${i + 1}: est ${(s.ms / 1000).toFixed(1)}s, ${s.files.length} files`));
if (excluded.length) console.log(`excluded(单独跑): ${excluded.join(', ')}`);
console.log(`balance=${balance}`);

function existsTimings() { try { return !!readFileSync('test-timings.json'); } catch { return false; } }
// 校验：分片文件并集 === 原列表
const all = shards.flatMap(s => s.files).concat(excluded);
if (new Set(all).size !== files.length) throw new Error('分片丢失或重复！');
```
**评分点**：
- LPT 长任务优先（比轮转均衡性显著更好）。
- 无历史数据降级为默认值（冷启动可用）。
- 排除集单独处理不参与分片。
- 恰好覆盖校验（不丢不重）。
- balance 指标量化均衡度；能说出按上次实际耗时回写形成闭环。
