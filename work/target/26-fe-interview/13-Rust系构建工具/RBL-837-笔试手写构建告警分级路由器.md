## RBL-837：笔试：手写构建告警分级路由器（分级 + 合并 + 恢复）

**答**：实现 `class AlertRouter({ mergeWindowMs })`。规则：1) `route(event)`：分级——branch=main → P0；flaky → 'flaky'；scheduled → P1；其他 → P2（author-only）；2) 同因合并：同 level + 同 fingerprint 在 mergeWindow 内 → 抑制返回但计数累加（下一次同因触发时消息含 count）；3) `resolve(fingerprint)`：标记恢复——若该指纹有未恢复告警 → 生成恢复通知（返回 { type: 'resolved', durationMs }）；4) `stats()`：各 level 的通知数与合并抑制数。边界：fingerprint 缺失按事件对象 hash；resolve 未知的 fingerprint 无操作。

```javascript
class AlertRouter {
  constructor({ mergeWindowMs = 60000, now = Date.now } = {}) {
    this.window = mergeWindowMs; this.now = now;
    this.active = new Map();                             // fingerprint -> { level, count, lastAt, notified }
    this.stats = { P0: 0, P1: 0, P2: 0, flaky: 0, suppressed: 0 };
  }
  route(e) {
    const fp = e.fingerprint ?? JSON.stringify([e.branch, e.test ?? e.error]);
    const level = e.branch === 'main' ? 'P0'
      : e.flaky ? 'flaky' : e.scheduled ? 'P1' : 'P2';
    const prev = this.active.get(fp);
    const message = e.branch === 'main' ? `主干失败 ${fp} @${e.blame ?? 'unknown'}`
      : e.flaky ? `[flaky] ${e.test}`
      : e.scheduled ? `定时任务失败 ${fp}`
      : `@${e.author ?? 'unknown'} PR 构建失败`;
    if (prev && this.now() - prev.lastAt < this.window && prev.level === level) {
      prev.count++; prev.lastAt = this.now(); this.stats.suppressed++;
      return null;                                       // 窗口内抑制
    }
    const rec = { level, count: prev ? prev.count : 1, lastAt: this.now() };
    this.active.set(fp, rec);
    this.stats[level]++;
    return { level, fingerprint: fp, message: prev ? `${message}（已累计 ${rec.count} 次）` : message };
  }
  resolve(fp) {
    const rec = this.active.get(fp);
    if (!rec) return null;
    this.active.delete(fp);
    return { type: 'resolved', durationMs: this.now() - rec.lastAt };
  }
}

// 自测
let t = 0; const now = () => t;
const r = new AlertRouter({ mergeWindowMs: 60000, now });
r.route({ branch: 'main', fingerprint: 'F1', blame: 'alice' });
t = 1000;
console.log(r.route({ branch: 'main', fingerprint: 'F1' }) === null);   // 抑制
t = 61000;
let out = r.route({ branch: 'main', fingerprint: 'F1' });
console.log(out.message.includes('已累计 3 次'));         // 第 3 次恢复通知带计数
console.log(r.stats.P0 === 2 && r.stats.suppressed === 1);

// PR 分级
out = r.route({ branch: 'feat', author: 'bob', fingerprint: 'F2' });
console.log(out.level === 'P2' && out.message.includes('bob'));
out = r.route({ scheduled: true, fingerprint: 'F3' });
console.log(out.level === 'P1');

// 恢复
const res = r.resolve('F2');
console.log(res.type === 'resolved' && res.durationMs >= 0);
console.log(r.resolve('nope') === null);
```

**评分点**：
- 四级路由正确（main P0 / flaky 聚合 / scheduled P1 / PR P2）
- 同因合并：窗口内抑制返回 null 且计数累加，窗口过后恢复通知带累计数
- resolve 恢复通知带时长；stats 含抑制数（告警系统自身可观测）
- 能说清「flaky 不即时通知是保护 P0 信噪比，告警疲劳是分级体系的大敌」属于加分
