## RBL-804：笔试：手写预渲染权限泄漏检测器（数据标记 + 视角扫描）

**答**：实现 `auditPrerender(pages, { buildIdentity, sensitivePatterns })`。pages: `{ path, html, dataInjected: boolean }[]`（构建期预渲染的页面）；buildIdentity: 构建时使用的身份标记；sensitivePatterns: 正则数组（如用户名/邮箱/金额）。规则：1) dataInjected=true 的页面：html 中命中任一 sensitivePattern → finding `{ page, matched }`（数据内联 = 泄漏）；2) 无身份检查脚本的预渲染页（html 无 'forbidden' 分支/无权限标记）→ warning 'no-authz'; 3) 返回 `{ findings, ok }`（ok = 无 finding）。边界：空 pages；sensitivePatterns 空（用默认：邮箱/手机号）。

```javascript
const DEFAULT_PATTERNS = [/[\w.+-]+@[\w-]+\.\w+/g, /1[3-9]\d{9}/g];

function auditPrerender(pages, { buildIdentity, sensitivePatterns = DEFAULT_PATTERNS } = {}) {
  const findings = [];
  for (const p of pages) {
    if (!p.dataInjected) continue;
    const matched = [];
    for (const re of sensitivePatterns) {
      for (const m of p.html.matchAll(re)) matched.push(m[0].slice(0, 6) + '***');
    }
    if (matched.length)
      findings.push({ type: 'data-leak', page: p.path, matched: [...new Set(matched)].slice(0, 3),
        detail: `预渲染内联数据（构建身份 ${buildIdentity}）——未授权用户可见` });
    if (!/forbidden|authz|403/.test(p.html))
      findings.push({ type: 'no-authz', page: p.path,
        detail: '预渲染页无权限分支——确认该页是否公开数据' });
  }
  return { findings, ok: findings.length === 0 };
}

// 自测
const pages = [
  { path: '/public/about', html: '<p>公司简介</p>', dataInjected: false },       // ok
  { path: '/dashboard/li', html: '<td>张三</td><td>zhang@corp.com</td>', dataInjected: true },  // 泄漏
  { path: '/public/faq', html: '<p>FAQ forbidden 未涉及</p>', dataInjected: true },  // 无敏感数据但无权限分支
];
let r = auditPrerender(pages, { buildIdentity: 'ci-bot' });
console.log(r.ok === false);
console.log(r.findings.find(f => f.type === 'data-leak').matched.join(','));
console.log(r.findings.filter(f => f.type === 'no-authz').length === 2);   // 两个 dataInjected 页面都无 403 分支

// 公开数据注入页（无敏感数据 + 有权限标记文案）
r = auditPrerender([{ path: '/p', html: '<p>价格 forbidden</p>', dataInjected: true }], { buildIdentity: 'ci' });
console.log(r.ok === false && r.findings[0].type === 'no-authz');

console.log(auditPrerender([], { buildIdentity: 'x' }).ok === true);
```

**评分点**：
- dataInjected 门控（只审计真实内联数据的页面）；敏感模式匹配 + 脱敏输出（matched 截断加 ***）
- no-authz 次级检查（无权限分支的预渲染页提示确认公开性）
- 默认模式兜底（邮箱/手机）；空输入安全
- 能说清「SSG 的构建身份视角数据 = 全员可见，预渲染+权限是经典事故」属于加分
