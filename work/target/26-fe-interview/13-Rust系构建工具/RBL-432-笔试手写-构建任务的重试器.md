## RBL-432：手写构建任务重试器
**答**：实现 `retryTask(task, policy)`：1) 指数退避：delay = base * 2^attempt + jitter（±20% 抖动防同步重试风暴）；2) 时间预算上限：总重试时间不超过 maxTotalMs（超预算立即失败——CI 时间预算保护）；3) 错误分类：可重试（网络/超时）与不可重试（代码错误/配置错）——不可重试立即抛出；4) 重试事件上报（每次 attempt 记录，诊断 flaky）；5) 返回 { result, attempts, totalMs } 或 throw（带 attempts 元信息）。

```javascript
const RETRYABLE = ['NetworkError', 'TimeoutError', 'ECONNRESET', 'ETIMEDOUT']

function sleep(ms) { return new Promise((r) => setTimeout(r, ms)) }

export async function retryTask(task, { maxAttempts = 3, base = 500, maxTotalMs = 60_000, jitter = 0.2 } = {}) {
  const attempts = []
  const t0 = Date.now()
  for (let i = 0; i < maxAttempts; i++) {
    if (i > 0 && Date.now() - t0 > maxTotalMs)
      throw Object.assign(new Error(`retry budget exhausted after ${i} attempts`), { attempts })
    try {
      const result = await task.run()
      return { result, attempts: attempts.concat([{ ok: true, at: Date.now() }]), totalMs: Date.now() - t0 }
    } catch (e) {
      attempts.push({ ok: false, error: String(e.message), at: Date.now() })
      const retryable = RETRYABLE.some((t) => e.name === t || e.code === t || String(e.message).includes(t))
      if (!retryable || i === maxAttempts - 1) {
        e.attempts = attempts; e.totalMs = Date.now() - t0
        throw e                                                  // 不可重试或最后一次
      }
      const delay = Math.min(base * 2 ** i, 30_000)
      const jittered = delay * (1 + (Math.random() * 2 - 1) * jitter)
      await sleep(jittered)
    }
  }
}
```
**评分点**：
- 指数退避 + 抖动（±20%——防同步重试风暴的集群效应）
- 时间预算上限（CI 时间保护；预算检查在 sleep 前）
- 错误分类（不可重试立即抛——盲目重试掩盖代码 bug）
- attempts 元信息随错误传播（flaky 诊断数据源）
