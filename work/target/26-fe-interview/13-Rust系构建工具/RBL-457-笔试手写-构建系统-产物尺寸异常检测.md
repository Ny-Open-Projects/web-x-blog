## RBL-457：手写产物尺寸异常检测器
**答**：实现 `detectSizeAnomaly(history, current)`：1) history：某 chunk 近 30 次构建体积序列；2) MAD 离群检测：median ± 3×MAD 之外为异常（比标准差稳健——构建体积分布长尾）；3) 异常分级：轻度（3×MAD 外）/严重（5×MAD 外）——分级决定告警级别；4) 趋势检测：连续 10 次单调上涨（缓慢膨胀——单点检测漏掉的慢性病）；5) 输出 { anomalies, trend, advice }；6) 冷启动保护：历史 < 10 样本不判定（样本不足不可信）。

```javascript
function median(arr) {
  const s = [...arr].sort((a, b) => a - b)
  return s[Math.floor(s.length / 2)]
}

export function detectSizeAnomaly(history, current, { k1 = 3, k2 = 5 } = {}) {
  if (history.length < 10)
    return { anomalies: [], trend: 'insufficient-data', advice: '样本不足，不判定' }

  const sizes = history.map((h) => h.size)
  const med = median(sizes)
  const mad = median(sizes.map((s) => Math.abs(s - med))) || 1
  const anomalies = []
  if (Math.abs(current - med) > k2 * mad)
    anomalies.push({ level: 'critical', current, median: med, deviation: +((current - med) / mad).toFixed(1) })
  else if (Math.abs(current - med) > k1 * mad)
    anomalies.push({ level: 'warning', current, median: med, deviation: +((current - med) / mad).toFixed(1) })

  // 趋势：近 10 次单调上涨
  const recent = [...sizes.slice(-9), current]
  const monotonicUp = recent.every((v, i, a) => i === 0 || v >= a[i - 1])
  const growth = monotonicUp ? +(((recent[9] - recent[0]) / recent[0]) * 100).toFixed(1) : 0

  return {
    anomalies,
    trend: monotonicUp ? `slow-inflation +${growth}% (10 builds)` : 'stable',
    advice: anomalies.some((a) => a.level === 'critical')
      ? '严重离群：检查最近引入的大依赖'
      : monotonicUp && growth > 10 ? '缓慢膨胀：启动依赖体积审计' : '正常',
  }
}
```
**评分点**：
- MAD 而非标准差（构建体积长尾分布——MAD 稳健性认知）
- 分级告警（3×/5×MAD 两档——分级决定响应级别）
- 慢性趋势检测（连续单调上涨——单点异常检测的盲区）
- 冷启动保护（样本不足不判定——防止误报）
