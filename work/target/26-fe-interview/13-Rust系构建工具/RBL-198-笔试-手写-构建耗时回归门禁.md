## RBL-198：笔试：手写构建耗时回归门禁（PR 相对 main 基线超阈值即挡）

**题目**：写 perf-gate.mjs：1) 输入：本次 PR 各阶段耗时与 main 分支基线（最近 20 次成功构建的中位数）；2) 门禁规则：总耗时超基线 1.5x 且绝对值超 120s 才算回归（双条件防小数字抖动）；单阶段超 2x 标记警告；3) 首次构建无基线时放行并标记 baseline-missing；4) 输出判定 {verdict: 'pass'|'warn'|'block', report}，block 时附可疑阶段排序；5) 基线数据由 CI 每次成功构建上报累积（提供 record 函数）。

```javascript
// perf-gate.mjs
function median(arr) {
  const s = [...arr].sort((a, b) => a - b);
  const m = Math.floor(s.length / 2);
  return s.length % 2 ? s[m] : (s[m - 1] + s[m]) / 2;
}

export function perfGate(current, baseline, { ratio = 1.5, minDeltaSec = 120, stageRatio = 2 } = {}) {
  if (!baseline?.durations?.length) {
    return { verdict: 'pass', report: 'baseline-missing: 首次构建无基线，已放行' };
  }
  const base = baseline.durations.map(d => d.total);
  const baseMedian = median(base);
  const cur = current.total;
  const isRegression = cur > baseMedian * ratio && cur - baseMedian > minDeltaSec;

  // 可疑阶段：相对基线中位数放大最多者
  const suspects = Object.keys(current.stages)
    .map(s => ({ stage: s,
      cur: current.stages[s],
      base: median(baseline.durations.map(d => d.stages?.[s] ?? 0)),
      ratio: current.stages[s] / Math.max(1, median(baseline.durations.map(d => d.stages?.[s] ?? 0))) }))
    .filter(x => x.ratio >= stageRatio)
    .sort((a, b) => b.ratio - a.ratio);

  const report = [
    `总耗时 ${cur}s vs 基线中位数 ${baseMedian}s (${(cur / baseMedian).toFixed(2)}x)`,
    ...suspects.map(s => `⚠️ ${s.stage}: ${s.cur}s = ${s.ratio.toFixed(1)}x 基线`),
  ].join('\n');
  const verdict = isRegression ? 'block' : (suspects.length ? 'warn' : 'pass');
  return { verdict, report, baseMedian, suspects };
}

// record：CI 成功构建时上报，累积基线（保留最近 20 条）
export function record(baselineStore, job, total, stages) {
  baselineStore.durations ??= [];
  baselineStore.durations.push({ job, total, stages, ts: Date.now() });
  if (baselineStore.durations.length > 20) baselineStore.durations.shift();
  return baselineStore;
}
// CI 集成：PR job 末尾跑 perfGate；verdict=block 时 CI fail 并贴 report 到 PR 评论。
```
**评分点**：
- 双条件判定（比例 + 绝对差），防小耗时抖动误杀。
- 基线用中位数（抗离线值，不是平均）。
- 无基线放行并显式标记（不因缺数据误挡）。
- 可疑阶段排序定位（超阈值的阶段点名）。
- record 滚动窗口保留 20 条。
