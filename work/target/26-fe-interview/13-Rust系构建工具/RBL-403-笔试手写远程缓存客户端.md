## RBL-403：手写远程缓存客户端
**答**：实现 `createRemoteCache(endpoint)`：1) `fetch(key)`：GET 条目 → 校验内容 hash（记录的 outputHash vs 实际）→ 通过返回 outputs、不通过丢弃返回 null；2) `put(key, outputs)`：上传 `{ key, outputHashes, files }`（files 为 path→content 映射）；3) 网络失败静默降级（返回 null，不阻塞构建）；4) 超时（10s）处理；5) 上传去重（同 key 在途共享 Promise）；6) stats() 命中率。

```javascript
import crypto from 'node:crypto'
const sha = (s) => crypto.createHash('sha256').update(s).digest('hex')

export function createRemoteCache(endpoint, { timeoutMs = 10_000 } = {}) {
  const inflight = new Map()
  let hits = 0, misses = 0

  async function request(path, opt) {
    const ctrl = new AbortController()
    const timer = setTimeout(() => ctrl.abort(), timeoutMs)
    try {
      return await fetch(endpoint + path, { ...opt, signal: ctrl.signal })
    } catch { return null }                                 // 降级：网络失败静默
    finally { clearTimeout(timer) }
  }

  return {
    async fetch(key) {
      const res = await request(`/cache/${key}`)
      if (!res?.ok) { misses++; return null }
      const record = await res.json()
      const ok = Object.entries(record.files).every(([f, content]) => sha(content) === record.hashes[f])
      if (!ok) { misses++; return null }                    // hash 校验失败 = 拒用（防投毒/损坏）
      hits++
      return record.files
    },
    async put(key, files) {
      if (inflight.has(key)) return inflight.get(key)
      const hashes = Object.fromEntries(Object.entries(files).map(([f, c]) => [f, sha(c)]))
      const p = request(`/cache/${key}`, { method: 'PUT',
        body: JSON.stringify({ key, hashes, files }) }).finally(() => inflight.delete(key))
      inflight.set(key, p)
      return p
    },
    stats: () => ({ hits, misses, rate: hits + misses ? hits / (hits + misses) : 0 }),
  }
}
```
**评分点**：
- hash 校验必过才复用（远程缓存防投毒/损坏的唯一防线）
- 网络失败/超时静默降级（缓存是优化不是依赖）
- put 在途去重（并发上传共享 Promise）
- stats 命中率分母含校验失败（校验失败也算 miss——口径正确）
