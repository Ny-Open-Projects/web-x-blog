## RBL-806：笔试：手写性能基线重建器（冷却期 + 采样 + 漂移确认）

**答**：实现两部分。1) `rebaseline(history, { cooldown, sampleSize })`：history 为构建记录数组 `{ buildMs, cached }[]`（按时间序）。规则：跳过前 cooldown 条（冷却期）**且跳过 cached=true 的条**（缓存加速非稳态）；取剩余最近 sampleSize 条，不足返回 `{ ready: false, need }`；够则返回 `{ ready: true, p50, p95, n }`（p95 用最近排序插值）。2) `proposeUpdate(newP50, oldP50, { driftLimit })`：|漂移| < driftLimit → 'no-change-needed'；否则返回需要人工确认的字符串（含漂移百分比）。边界：history 全缓存；cooldown ≥ history 长度。

```javascript
function rebaseline(history, { cooldown = 3, sampleSize = 10 } = {}) {
  const usable = history.slice(cooldown).filter(h => !h.cached);
  if (usable.length < sampleSize)
    return { ready: false, need: sampleSize - usable.length };
  const sample = usable.slice(-sampleSize);
  const sorted = sample.map(h => h.buildMs).sort((a, b) => a - b);
  return {
    ready: true,
    p50: sorted[Math.floor(sorted.length / 2)],
    p95: sorted[Math.min(sorted.length - 1, Math.floor(sorted.length * 0.95))],
    n: sample.length,
  };
}
function proposeUpdate(newP50, oldP50, { driftLimit = 0.03 } = {}) {
  const drift = newP50 / oldP50 - 1;
  if (Math.abs(drift) < driftLimit) return 'no-change-needed';
  return `基线漂移 ${(drift * 100).toFixed(1)}% 需人工确认（业务扩容/工具变更/回归）`;
}

// 自测
const history = [
  { buildMs: 9000, cached: false },   // 冷却
  { buildMs: 8000, cached: false },   // 冷却
  { buildMs: 8500, cached: false },   // 冷却
  { buildMs: 3000, cached: true },    // 缓存跳过
  { buildMs: 5000, cached: false }, { buildMs: 5200, cached: false },
  { buildMs: 5100, cached: false }, { buildMs: 4900, cached: false },
  { buildMs: 5300, cached: false }, { buildMs: 5000, cached: false },
  { buildMs: 4800, cached: false }, { buildMs: 5100, cached: false },
  { buildMs: 5050, cached: false },
];
let r = rebaseline(history, { cooldown: 3, sampleSize: 8 });
console.log(r.ready === true && r.n === 8);
console.log(r.p50 === 5050);                             // 排序后中位
console.log(r.p95 === 5300);

r = rebaseline(history.slice(0, 10), { cooldown: 3, sampleSize: 10 });
console.log(r.ready === false && r.need === 3);          // 7 条可用缺 3

console.log(rebaseline(history, { cooldown: 20, sampleSize: 5 }).ready === false);
console.log(proposeUpdate(5100, 5000) === 'no-change-needed');    // 2% < 3%
console.log(proposeUpdate(5600, 5000).includes('12.0%'));
console.log(proposeUpdate(4000, 5000).includes('-20.0%'));
```

**评分点**：
- 冷却期与缓存条双重剔除（两类非稳态因素都处理）；采样不足返回缺口
- p50/p95 计算正确（排序索引）；漂移确认的双向（涨/跌都要确认）
- 边界：cooldown 超长、全缓存 history
- 能说清「非稳态数据建基线会让门禁失真，缓存条与冷启动都要剔除」属于加分
