## RBL-192：笔试：手写限流上传器（并发限流 + 重试 + 进度回调）

**答**：写 uploader.mjs：实现 uploadAll(files, uploadOne, opts)：1) 并发限流 N（默认 6）同时上传；2) 单文件失败指数退避重试（1s/2s/4s，共 3 次），最终失败收集进 errors 不中断整体；3) 进度回调 onProgress(done, total, file)；4) 限流实现不依赖第三方库（信号量/worker 池）；5) 全部结束后返回 {ok: [...], errors: [{file, err}]}。

```javascript
// uploader.mjs
const sleep = ms => new Promise(r => setTimeout(r, ms));

export async function uploadAll(files, uploadOne,
    { concurrency = 6, retries = 3, onProgress = () => {} } = {}) {
  const queue = [...files];
  const ok = [], errors = [];
  let done = 0;

  const worker = async () => {
    while (queue.length) {
      const file = queue.shift();
      let lastErr;
      for (let attempt = 0; attempt <= retries; attempt++) {
        try {
          await uploadOne(file);
          ok.push(file); lastErr = null;
          break;
        } catch (e) {
          lastErr = e;
          if (attempt < retries) await sleep(1000 * 2 ** attempt); // 1s/2s/4s 指数退避
        }
      }
      if (lastErr) errors.push({ file, err: lastErr.message });
      onProgress(++done, files.length, file);
    }
  };
  await Promise.all(Array.from({ length: Math.min(concurrency, files.length) }, worker));
  return { ok, errors };
}

// 用法（与 RBL-170 的产物上传对接）
import { readFileSync } from 'node:fs';
const distFiles = JSON.parse(readFileSync('manifest.json'));  // [{path, size}]
const r = await uploadAll(distFiles,
  async f => {
    const res = await fetch(`${process.env.CDN_URL}/${f.path}`, {
      method: 'PUT', body: readFileSync(`dist/${f.path}`),
    });
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
  },
  { concurrency: 6, onProgress: (d, t, f) => console.log(`[${d}/${t}] ${f.path}`) });
if (r.errors.length) { console.error('失败:', r.errors); process.exit(1); }
```
**评分点**：
- 固定 worker 池实现限流（不是 p-limit 依赖）。
- 指数退避序列正确（1/2/4s）且总尝试 = retries + 1。
- 单文件最终失败进 errors、不影响其余（与 fail-fast 场景区分）。
- 进度回调每次完成都触发（含失败）。
- 能说明上传场景为何用退避而非立即重试（CDN 限流/抖动）。
