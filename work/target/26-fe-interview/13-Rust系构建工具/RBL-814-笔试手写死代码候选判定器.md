## RBL-814：笔试：手写死代码候选判定器（执行面 + 白名单 + 置信）

**答**：实现 `deadCandidates(manifest, executed, { windowDays, minSizeKB })`。manifest: `Record<id, { sizeKB, isEntry: boolean, isErrorPath: boolean, inDynamicClosure: boolean, lastStaticSeen: number|null }>`；executed: `Set<id>`（RUM 执行面）。规则：1) 未在 executed 中且非 entry/非 isErrorPath/非动态闭包 → 候选；2) 置信分级：lastStaticSeen 为 null（源码早已删除该入口）→ 'high'；窗口内从未执行 → 'medium'；仅 sizeKB < minSizeKB 的降为 'low'（不值得动）；3) entry 强制豁免；4) 返回 `{ candidates: Array<{ id, sizeKB, confidence }>, totalKB }`（confidence 降序）。边界：executed 全命中（空候选）；manifest 空。

```javascript
function deadCandidates(manifest, executed, { windowDays = 90, minSizeKB = 2 } = {}) {
  const candidates = [];
  for (const [id, m] of Object.entries(manifest)) {
    if (executed.has(id)) continue;
    if (m.isEntry || m.isErrorPath || m.inDynamicClosure) continue;
    let confidence = m.lastStaticSeen == null ? 'high'
      : 'medium';
    if (m.sizeKB < minSizeKB) confidence = 'low';
    candidates.push({ id, sizeKB: m.sizeKB, confidence });
  }
  const rank = { high: 0, medium: 1, low: 2 };
  candidates.sort((a, b) => rank[a.confidence] - rank[b.confidence] || b.sizeKB - a.sizeKB);
  return {
    candidates,
    totalKB: +candidates.filter(c => c.confidence !== 'low')
      .reduce((s, c) => s + c.sizeKB, 0).toFixed(1),
  };
}

// 自测
const manifest = {
  'entry.js': { sizeKB: 100, isEntry: true, isErrorPath: false, inDynamicClosure: false, lastStaticSeen: 1 },
  'chart-lazy.js': { sizeKB: 200, isEntry: false, isErrorPath: false, inDynamicClosure: true, lastStaticSeen: 1 },   // 动态闭包豁免
  'old-page.js': { sizeKB: 80, isEntry: false, isErrorPath: false, inDynamicClosure: false, lastStaticSeen: null },  // 高置信
  'rare.js': { sizeKB: 50, isEntry: false, isErrorPath: false, inDynamicClosure: false, lastStaticSeen: 3 },         // 中置信
  'tiny.js': { sizeKB: 1, isEntry: false, isErrorPath: false, inDynamicClosure: false, lastStaticSeen: 3 },          // low
  'error-boundary.js': { sizeKB: 30, isEntry: false, isErrorPath: true, inDynamicClosure: false, lastStaticSeen: 3 },
};
const executed = new Set(['entry.js', 'rare.js']);
let r = deadCandidates(manifest, executed, { minSizeKB: 2 });
console.log(r.candidates[0].id === 'old-page.js' && r.candidates[0].confidence === 'high');
console.log(r.candidates.find(c => c.id === 'tiny.js').confidence === 'low');
console.log(r.candidates.find(c => c.id === 'rare.js') === undefined);   // executed 命中
console.log(r.candidates.find(c => c.id === 'chart-lazy.js') === undefined);  // 动态闭包豁免
console.log(r.totalKB === 80);

console.log(deadCandidates(manifest, new Set(Object.keys(manifest)), {}).candidates.length === 0);
console.log(deadCandidates({}, new Set(), {}).candidates.length === 0);
```

**评分点**：
- 四重豁免正确（entry/isErrorPath/动态闭包/executed 命中）；置信分级（lastStaticSeen null 为高置信）
- size 低于阈值降为 low 且不计入 totalKB（不值得动的分开）；排序正确（置信优先、同级 size 降序）
- 边界：全命中/空 manifest
- 能说清「『未执行』≠死代码，低频路径误判 = 线上功能缺失，需双模式验证」属于加分
