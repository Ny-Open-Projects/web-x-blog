## RBL-221：增量编译原理：依赖图与脏标记怎么传播

**答**:
- 核心：构建产物 = f(模块图)，增量编译只重算「受变更影响的子图」——正确性依赖依赖图的完整与准确
- 脏标记传播：变更文件 → 标脏自身 → 沿依赖边反向传播到「引用它的模块与依赖它的 chunk」；传播范围由图形态决定（公共模块变更影响面大）
- 两种增量粒度：模块级（重转换该模块）与 chunk 级（重渲染受影响 chunk）——产物 hash 未变的 chunk 可跳过 emit
- 关键难点：伪增量（变更导致全局重算）的检测——如 DefinePlugin 值变化影响全图，应提示用户而非静默全量

```text
变更 a.ts → mark a → parents(b.ts, c.ts) → chunks(chunk1, chunk2)
  → 重转换 a,b,c → 重渲染 chunk1/chunk2 → chunk3 hash 未变 → 跳过 emit
```
