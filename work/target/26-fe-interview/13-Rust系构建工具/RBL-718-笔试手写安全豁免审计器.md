## RBL-718：笔试：手写安全豁免审计器（漏洞分级 + 豁免过期 + 审计窗口）

**答**：实现 `securityAudit({ vulnerabilities, exemptions, auditAt, now, maxAuditAgeDays })`。vulnerabilities: `{ name, severity: 'critical'|'high'|'moderate'|'low' }[]`；exemptions: `{ pkg, reason, expires }[]`。规则：1) critical 且未被有效豁免 → blockers；2) high 未豁免 → warnings；3) 豁免过期（expires < now）→ 按未豁免处理 + notes 提示；4) auditAt 距 now 超 maxAuditAgeDays → blockers 追加 'audit-stale'（审计窗口过期产物拒绝发布）；5) 返回 `{ blockers, warnings, notes, ok }`（ok = blockers 为空）。边界：空漏洞；审计时间未来值（时钟漂移）按新鲜处理。

```javascript
const isExpired = (iso, now) => new Date(iso) < now;

function securityAudit({ vulnerabilities = [], exemptions = [], auditAt, now, maxAuditAgeDays = 7 }) {
  const blockers = [], warnings = [], notes = [];
  const exemptOf = (pkg) => exemptions.find(e => e.pkg === pkg && !isExpired(e.expires, now));

  for (const v of vulnerabilities) {
    const ex = exemptOf(v.name);
    if (ex && (v.severity === 'critical' || v.severity === 'high')) {
      notes.push(`豁免生效: ${v.name} (${ex.reason})`);
      continue;
    }
    if (ex && isExpired(ex.expires, now)) notes.push(`豁免已过期: ${v.name}`);
    if (v.severity === 'critical') blockers.push(`${v.name}（critical）`);
    else if (v.severity === 'high') warnings.push(`${v.name}（high）`);
  }
  const age = (now - new Date(auditAt)) / 86400000;
  if (age > maxAuditAgeDays) blockers.push(`audit-stale：审计已 ${Math.floor(age)} 天（限 ${maxAuditAgeDays}）`);
  return { blockers, warnings, notes, ok: blockers.length === 0 };
}

// 自测
const now = new Date('2026-11-22T10:00:00');
// 1) critical 未豁免阻断
let r = securityAudit({ vulnerabilities: [{ name: 'x', severity: 'critical' }, { name: 'y', severity: 'high' }],
  auditAt: '2026-11-21', now });
console.log(r.ok === false && r.blockers[0].includes('x') && r.warnings[0].includes('y'));

// 2) 有效豁免
r = securityAudit({ vulnerabilities: [{ name: 'x', severity: 'critical' }],
  exemptions: [{ pkg: 'x', reason: '无升级路径+无攻击面', expires: '2099-01-01' }],
  auditAt: '2026-11-21', now });
console.log(r.ok === true && r.notes[0].includes('豁免生效'));

// 3) 过期豁免
r = securityAudit({ vulnerabilities: [{ name: 'x', severity: 'critical' }],
  exemptions: [{ pkg: 'x', reason: '旧', expires: '2020-01-01' }], auditAt: '2026-11-21', now });
console.log(r.ok === false && r.notes.some(n => n.includes('过期')));

// 4) 审计窗口过期
r = securityAudit({ vulnerabilities: [], auditAt: '2026-11-01', now });
console.log(r.blockers[0] === 'audit-stale：审计已 21 天（限 7）');

// 5) 未来审计时间（时钟漂移）
r = securityAudit({ vulnerabilities: [], auditAt: '2026-11-25', now });
console.log(r.ok === true);

console.log(securityAudit({ vulnerabilities: [], auditAt: '2026-11-21', now }).ok === true);
```

**评分点**：
- 分级处置正确：critical 阻断、high 警告；豁免对 critical/high 生效且过期降级
- 审计窗口独立校验（超龄产物拒绝发布）；未来时间按新鲜处理（时钟漂移防御）
- notes 完整记录豁免生效/过期（审计可追溯）
- 能说清「安全检查前移到构建期让修复发生在 PR」属于加分
