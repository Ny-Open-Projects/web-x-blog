## RBL-574：笔试：手写构建进度估算器（加权工作量 + 渐进修正）

**答**：实现 `createProgress({ defaultWeight = 1 })`：`addModule(id, weight?)` 登记待处理模块；`addDiscovered(n)` 运行中发现新模块；`startModule(id)` / `finishModule(id, cost?)` 标记开始/完成。`progress()` 返回 0~1：分母 = 已登记模块总权重（发现新模块时分母变大、百分比回落），分子 = 已完成模块权重（完成时若给 cost，则把该模块的权重改为实际 cost 并同步修正分子分母）。边界：重复 addModule 忽略；finish 未 start 的模块忽略；全空时 progress 返回 0。

```javascript
function createProgress({ defaultWeight = 1 } = {}) {
  const modules = new Map();              // id -> { weight, started, done, cost }
  let discovered = 0;
  const weightOf = m => m.cost ?? m.weight;

  const total = () =>
    [...modules.values()].filter(m => m.started).reduce((s, m) => s + weightOf(m), 0);
  const done = () =>
    [...modules.values()].filter(m => m.done).reduce((s, m) => s + weightOf(m), 0);

  return {
    addModule(id, weight = defaultWeight) {
      if (modules.has(id)) return;                       // 重复登记忽略
      modules.set(id, { weight, started: false, done: false });
    },
    addDiscovered(n) { for (let i = 0; i < n; i++) modules.set(`dyn:${discovered++}`,
      { weight: defaultWeight, started: false, done: false }); },
    startModule(id) { const m = modules.get(id); if (m) m.started = true; },
    finishModule(id, cost) {
      const m = modules.get(id);
      if (!m || !m.started || m.done) return;            // 未 start / 重复 finish 忽略
      m.done = true; if (cost != null) m.cost = cost;    // 实际 cost 修正权重
    },
    progress() {
      const t = total(), d = done();
      return t === 0 ? 0 : Math.min(1, d / t);
    },
  };
}

// 自测
const p = createProgress();
p.addModule('a', 10); p.addModule('b', 5); p.addModule('a', 99);        // 重复忽略
p.startModule('a'); p.startModule('b');
p.finishModule('a', 20);                                                 // cost 修正
// 断言：p.progress() === 20/(20+5) === 0.8
p.addDiscovered(3);                                                      // 分母 +3
// 断言：Math.abs(p.progress() - 20/28) < 1e-9
p.finishModule('ghost');                                                 // 忽略
// 断言：p.progress() === 20/28；空实例 progress()===0
console.log(createProgress().progress() === 0);
```

**评分点**：
- 分母动态化正确（started 后才计入、新发现模块使百分比回落），体现「预估渐进修正」思想
- cost 修正逻辑正确：完成时同时修正分子分母（实际成本替换预估权重）
- 边界三连：重复 add/未 start finish/空集返回 0 全覆盖
- 能说清「加权 vs 计数」的取舍（大模块 1 个 ≠ 小模块 1 个）属于加分
