## RBL-617：笔试：手写依赖预构建失效判定器（四要素 hash + 并发锁）

**答**：实现 `class PrebuildManager`，注入 `fs`（内存实现）与 `hash(str)`。`shouldRebuild({ lockHash, configHash, toolVersion, force })`：读缓存目录 `_metadata.json`（含四要素 hash），任一不同或缺失或 force → true。`rebuild(deps)`：先抢锁（`_lock` 文件，写入时间戳；已存在且 <10s 视为他人持锁 → 抛 `LOCKED`），写产物文件列表 + 重新写 metadata，释放锁。`rebuild` 期间再次调用 shouldRebuild 必须返回 false（锁内 skip）。并发场景：持锁者失败要释放锁。

```javascript
class PrebuildManager {
  constructor(fs, hash, { now = Date.now } = {}) { this.fs = fs; this.hash = hash; this.now = now; }
  #key = (s) => this.hash(s);
  async shouldRebuild({ lockHash, configHash, toolVersion, force = false }) {
    if (force) return true;
    if (await this.fs.exists('_lock')) return false;                 // 他人持锁：skip
    if (!(await this.fs.exists('_metadata.json'))) return true;
    const meta = JSON.parse(await this.fs.read('_metadata.json'));
    const cur = this.#key(lockHash + configHash + toolVersion);
    return meta.hash !== cur;                                        // 任一要素变化 -> 重跑
  }
  async rebuild(deps, { lockHash, configHash, toolVersion }) {
    // 抢锁
    if (await this.fs.exists('_lock')) {
      const t = +await this.fs.read('_lock');
      if (this.now() - t < 10000) { const e = new Error('LOCKED'); e.code = 'LOCKED'; throw e; }
    }
    await this.fs.write('_lock', String(this.now()));
    try {
      for (const d of deps) await this.fs.write(`deps/${d}.js`, `// prebuilt ${d}`);
      await this.fs.write('_metadata.json', JSON.stringify({
        hash: this.#key(lockHash + configHash + toolVersion), deps,
        builtAt: this.now(),
      }));
    } finally {
      await this.fs.rm('_lock').catch(() => {});                     // 失败也释放锁
    }
  }
}

// 内存 fs
function memFs() {
  const m = new Map();
  return {
    m,
    write: async (n, c) => m.set(n, c),
    read: async (n) => { if (!m.has(n)) throw new Error('ENOENT'); return m.get(n); },
    exists: async (n) => m.has(n),
    rm: async (n) => m.delete(n),
  };
}
const hash = (s) => { let x = 0; for (const c of s) x = (x * 31 + c.charCodeAt(0)) | 0; return String(x); };

// 自测
const f = memFs();
const pm = new PrebuildManager(f, hash);
const ctx = { lockHash: 'L1', configHash: 'C1', toolVersion: 'v1' };
console.log(await pm.shouldRebuild(ctx) === true);                   // 无缓存
await pm.rebuild(['react', 'vue'], ctx);
console.log(await pm.shouldRebuild(ctx) === false);                  // 命中
console.log(await pm.shouldRebuild({ ...ctx, lockHash: 'L2' }) === true);  // lockfile 变
await pm.rebuild(['react'], { ...ctx, lockHash: 'L2' });

// 并发锁
const pm2 = new PrebuildManager(f, hash, { now: () => Date.now() });
let locked; try { await pm2.rebuild(['x'], ctx); } catch (e) { locked = e.code; }
console.log(locked === 'LOCKED');                                    // 锁内重入
// 过期锁（>10s）可抢
const pm3 = new PrebuildManager(f, hash, { now: () => Date.now() + 20000 });
await pm3.rebuild(['y'], ctx);
console.log(f.m.has('_lock') === false);                             // finally 释放
```

**评分点**：
- 四要素 hash 判定正确（任一变化即失效），force 直通；锁存在时 shouldRebuild 返回 false（skip 而非阻塞）
- 抢锁原子性与过期判定（<10s 视为他人持锁）；finally 释放锁（失败不悬挂）
- rebuild 先写产物后写 metadata（metadata 是完整性标志，最后写入）
- 能说清「两个终端同时 dev server 的写竞争」是该锁的真实动机属于加分
