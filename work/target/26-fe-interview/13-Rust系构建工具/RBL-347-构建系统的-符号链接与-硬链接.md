## RBL-347：构建系统的符号链接与硬链接（pnpm 语义）

**答**:
- pnpm 结构：全局 store（硬链接实体）+ node_modules 符号链接（.pnpm 目录真实路径，顶层 symlink）——省磁盘 + 严格依赖隔离
- 构建工具必须处理 symlink：resolve 要跟随 symlink 但保留真实路径（否则同一包出现两个身份 → 重复打包/循环依赖误判）、presymlinks 配置
- 坑清单：打包器解析出真实路径后 realpath 语义差异（bundle 内相对路径）、watch 不跟随 symlink（变更检测漏）、monorepo 内包 link（workspace link 与 npm link 混用混乱）
- 验证：产物内同包单实例断言（重复依赖检测联动 symlink 解析正确性）

```text
pnpm 链：node_modules/x → .pnpm/x@1/…（symlink） → store 硬链接
工具要点：resolve 跟随 + realpath 归一 + watch 覆盖 symlink
```
