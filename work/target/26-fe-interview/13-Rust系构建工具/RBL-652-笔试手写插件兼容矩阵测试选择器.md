## RBL-652：笔试：手写插件兼容矩阵测试选择器（peer 范围解析 + 矩阵裁剪）

**答**：实现 `selectMatrix(peerRange, available)`。peerRange: 简化 semver 区间字符串（如 `>=1.0.0 <2.0.0`、`^1.2.0`、`~1.1.0`）；available: 可用的核心版本数组。返回该插件应测试的版本列表：^ 视为 `>=x <(x+1).0.0`、~ 视为 `>=x.y <x.(y+1)`、>= 与 < 为显式边界。规则：1) 落在区间内的版本全选；2) 版本数 > maxN（可配，默认 5）时等间隔抽样但**必须包含区间内最新版**；3) 无可用版本返回空数组；4) 非法区间字符串抛错。compare 用语义化比较（实现 compareVersion）。

```javascript
function compareVersion(a, b) {
  const pa = a.split('.').map(Number), pb = b.split('.').map(Number);
  for (let i = 0; i < 3; i++) {
    const x = pa[i] || 0, y = pb[i] || 0;
    if (x !== y) return x - y;
  }
  return 0;
}

function parseRange(range) {
  const m = /^(\^|~)?(\d+)\.(\d+)\.(\d+)(\s+(>=|<)\s*(\d+)\.(\d+)\.(\d+))?$/.exec(range.trim());
  if (!m) throw new Error(`非法 peer 区间: ${range}`);
  const op = m[1] ?? '';
  const lo = `${m[2]}.${m[3]}.${m[4]}`;
  let hi = null;
  if (op === '^') hi = `${+m[2] + 1}.0.0`;
  else if (op === '~') hi = `${m[2]}.${+m[3] + 1}.0`;
  else if (m[5]) {
    if (m[5] === '>=') return { min: lo, max: null };
    return { min: null, max: m[6] + '.' + m[7] + '.' + m[8] };   // < 上界
  }
  return { min: op ? lo : null, max: hi };
}

function selectMatrix(peerRange, available, { maxN = 5 } = {}) {
  const { min, max } = parseRange(peerRange);
  const inRange = available.filter(v =>
    (min === null || compareVersion(v, min) >= 0) &&
    (max === null || compareVersion(v, max) < 0));
  if (inRange.length <= maxN) return inRange.sort(compareVersion);
  // 等间隔抽样 + 保最新
  const sorted = [...inRange].sort(compareVersion);
  const latest = sorted[sorted.length - 1];
  const step = (sorted.length - 1) / (maxN - 1);
  const picked = [];
  for (let i = 0; i < maxN - 1; i++) picked.push(sorted[Math.round(i * step)]);
  picked.push(latest);
  return [...new Set(picked)].sort(compareVersion);
}

// 自测
const avail = ['0.9.0', '1.0.0', '1.1.0', '1.2.0', '1.3.0', '1.9.0', '2.0.0', '2.1.0'];
console.log(selectMatrix('^1.0.0', avail).join(','));
// ['1.0.0','1.1.0','1.2.0','1.3.0','1.9.0']（2.x 排除，5 个内全选）
console.log(selectMatrix('~1.1.0', avail).join(','));    // 1.1.0,1.2.0（1.3 排除）
console.log(selectMatrix('>=1.2.0 <2.0.0', avail).join(','));
console.log(selectMatrix('^1.0.0', ['0.9.0', '2.0.0']).length === 0);
let e; try { selectMatrix('banana', avail); } catch (x) { e = x; }
console.log(/非法/.test(e.message));

// 抽样保最新：构造 8 个版本区间
const many = ['1.0.0','1.1.0','1.2.0','1.3.0','1.4.0','1.5.0','1.6.0','1.7.0'];
const m = selectMatrix('^1.0.0', many, { maxN: 4 });
console.log(m.length === 4 && m[m.length - 1] === '1.7.0' && m.includes('1.0.0'));
```

**评分点**：
- ^/~/>= 区间语义正确（^ 主版本、~ 次版本、显式边界组合）
- 抽样策略正确：等间隔 + 强制含最新版（兼容矩阵的最新版覆盖是回归底线）
- 区间外/空集返回空、非法区间抛错；compareVersion 三段数值比较（含缺省段）
- 能说清「矩阵测试把核心升级的兼容问题前置到插件侧」属于加分
