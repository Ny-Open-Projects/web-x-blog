## RBL-654：笔试：手写插件质量分计算器（加权评分 + 降级判定）

**答**：实现 `qualityScore(plugins, metrics, { threshold })`。metrics: `Map<name, { tests, matrix, docs, release, usage }>`（0~1），usage 按内部接入数分档（0-0.1/0.3/0.6/1.0 由 `usageTier(count)` 提供）。权重固定 `{ tests: .3, matrix: .25, docs: .15, release: .1, usage: .2 }`。返回 `Map<name, { score, status }>`：score 保留两位；status: 'active'（score ≥ threshold）、'review'（< threshold）、'missing'（无 metrics 数据）。缺单项维度的按剩余权重归一化（缺 usage 时其余权重和为 0.8，得分 = Σw×v / 0.8），全缺视为 missing。

```javascript
const WEIGHTS = { tests: 0.3, matrix: 0.25, docs: 0.15, release: 0.1, usage: 0.2 };
const usageTier = (count) =>
  count >= 100 ? 1.0 : count >= 30 ? 0.6 : count >= 5 ? 0.3 : 0.1;

function qualityScore(plugins, metrics, { threshold = 0.6 } = {}) {
  const out = new Map();
  for (const name of plugins) {
    const m = metrics.get(name);
    if (!m) { out.set(name, { score: 0, status: 'missing' }); continue; }
    const parts = {};
    for (const k of Object.keys(WEIGHTS)) {
      const v = k === 'usage' ? usageTier(m.usageCount ?? 0) : m[k];
      if (typeof v === 'number') parts[k] = v;
    }
    if (Object.keys(parts).length === 0) {
      out.set(name, { score: 0, status: 'missing' }); continue;
    }
    const wSum = Object.keys(parts).reduce((s, k) => s + WEIGHTS[k], 0);
    const raw = Object.keys(parts).reduce((s, k) => s + WEIGHTS[k] * parts[k], 0);
    const score = +(raw / wSum).toFixed(2);              // 缺项归一化
    out.set(name, { score, status: score >= threshold ? 'active' : 'review' });
  }
  return out;
}

// 自测
const metrics = new Map([
  ['good', { tests: 0.9, matrix: 1.0, docs: 0.8, release: 0.9, usageCount: 120 }],
  ['weak', { tests: 0.3, matrix: 0.4, docs: 0.2, release: 0.5, usageCount: 2 }],
  ['partial', { tests: 0.8, matrix: 0.9, docs: null, release: 0.7, usageCount: 50 }],  // 缺 docs
]);
const r = qualityScore(['good', 'weak', 'partial', 'ghost'], metrics);
console.log(r.get('good').status === 'active' && r.get('good').score >= 0.85);
console.log(r.get('weak').status === 'review' && r.get('weak').score < 0.6);
console.log(r.get('ghost').status === 'missing');

// partial 缺 docs：归一化后分母 0.85（.3+.25+.1+.2）
const p = r.get('partial');
const expected = ((0.3 * 0.8 + 0.25 * 0.9 + 0.1 * 0.7 + 0.2 * 0.6) / 0.85).toFixed(2);
console.log(p.score === +expected && p.status === 'active');

// 阈值调整
const strict = qualityScore(['good'], metrics, { threshold: 0.99 });
console.log(strict.get('good').status === 'review');
```

**评分点**：
- 加权计算正确；usage 按 tier 分档而非直接数值（使用面离散化）
- 缺项归一化实现正确（分母为实际可用权重和）；全缺 -> missing
- 阈值判定产生 active/review 两态；missing 独立（不是 0 分 review）
- 能说清「usage 高权重的原因：影响面大者维护优先」属于加分
