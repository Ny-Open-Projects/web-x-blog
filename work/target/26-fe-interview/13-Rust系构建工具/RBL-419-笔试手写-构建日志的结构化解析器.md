## RBL-419：手写构建日志结构化解析器
**需求**：实现 `parseBuildLog(logText)`：1) 提取错误：匹配多行错误块（`ERROR in file:line:col\nmessage\n  codeframe`）；2) 结构化：{ file, line, col, message, codeframe, rule? }；3) 聚类：同 file+message 前缀合并计数（同类错误折叠）；4) 提取警告（WARN 级）与任务耗时行（`✓ task 1.2s`）；5) 输出 { errors: [], grouped: [], warnings: [], tasks: [] }；6) 解析失败容错（未知行忽略不抛错）。

```javascript
const ERR_RE = /ERROR in (.+?):(\d+):(\d+)\n([\s\S]*?)(?=\n(?:ERROR|WARN|✓|✗)|$)/g
const WARN_RE = /WARN in (.+?):(\d+):(\d+)\n([\s\S]*?)(?=\n(?:ERROR|WARN|✓|✗)|$)/g
const TASK_RE = /([✓✗])\s+(\S+#[\w-]+)\s+([\d.]+)(ms|s)/

export function parseBuildLog(text) {
  const errors = [], warnings = [], tasks = []
  for (const m of text.matchAll(ERR_RE))
    errors.push({ file: m[1], line: +m[2], col: +m[3], message: m[4].trim().split('\n')[0],
      codeframe: m[4].trim() })
  for (const m of text.matchAll(WARN_RE))
    warnings.push({ file: m[1], line: +m[2], col: +m[3], message: m[4].trim().split('\n')[0] })
  for (const m of text.matchAll(TASK_RE))
    tasks.push({ status: m[1] === '✓' ? 'ok' : 'fail', task: m[2],
      ms: m[4] === 's' ? Math.round(parseFloat(m[3]) * 1000) : +m[3] })

  const grouped = new Map()                          // file+message 前缀聚类
  for (const e of errors) {
    const key = `${e.file}#${e.message.slice(0, 60)}`
    const g = grouped.get(key) ?? { ...e, count: 0 }
    g.count++
    grouped.set(key, g)
  }
  return { errors, grouped: [...grouped.values()], warnings, tasks }
}
```
**评分点**：
- 多行错误块正则边界（下个 ERROR/WARN/任务行截止——非贪婪+前瞻）
- 聚类键（file+message 前缀——同文件同类错误折叠计数）
- 任务行解析（单位换算 s→ms 统一口径）
- 容错（未知行忽略——日志解析永不抛错）
