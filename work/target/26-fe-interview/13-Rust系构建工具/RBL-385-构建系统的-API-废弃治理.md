## RBL-385：构建工具 API 废弃的治理实践

**答**:
- 废弃周期：警告期（deprecated 输出 + 替代方案文档，至少一个 minor）→ 静默期（仍可用但 CI 警告）→ 移除（major）——用户有迁移窗口
- 采集迁移进度：deprecation 警告的触发统计（多少用户还在用）——决定延期还是如期移除（数据驱动而非拍脑袋）
- 迁移支持：codemod 自动迁移（能自动绝不手迁）+ 迁移文档按场景组织——「废弃成本」越低用户越愿意配合升级
- 反模式：静默移除（用户升级即崩）、无限延期（API 永远删不掉）——数据驱动的中间态

```text
周期：警告期 → 静默期 → major 移除
数据：警告触发统计 → 延期/如期决策
支持：codemod + 场景化迁移文档
```
