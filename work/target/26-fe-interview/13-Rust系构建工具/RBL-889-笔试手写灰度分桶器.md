## RBL-889：笔试：手写灰度分桶器（hash + 锚定 + 审计）

**答**：实现两部分。1) `pickVersion(userId, { grayPercent, storage })`：storage 注入（getSession/setSession 模拟）。规则：锚定优先（storage 有 __build_ver 直接返回）；否则 bucket = djb2(userId) % 100，bucket < grayPercent → 'new' 否则 'old'，并写入 storage；2) `auditBalance(assignments, { tol })`：assignments: `{ userId, bucket }[]`——统计 100 桶分布，偏差 > expected×tol 的桶数 > 10 → 'skewed'（返回 { skewedBuckets, verdict }），否则 'balanced'。边界：grayPercent 0（全 old）/100（全 new）；storage 已有值直接用（不重算）；assignments 空。

```javascript
const djb2 = (s) => { let h = 5381; for (const c of s) h = ((h << 5) + h + c.charCodeAt(0)) >>> 0; return h; };

function pickVersion(userId, { grayPercent, storage }) {
  const anchored = storage.get('__build_ver');
  if (anchored) return anchored;
  const ver = djb2(userId) % 100 < grayPercent ? 'new' : 'old';
  storage.set('__build_ver', ver);
  return ver;
}

function auditBalance(assignments, { tol = 0.3 } = {}) {
  if (!assignments.length) return { verdict: 'balanced', skewedBuckets: [] };
  const counts = new Array(100).fill(0);
  assignments.forEach(a => counts[a.bucket]++);
  const expected = assignments.length / 100;
  const skewed = counts
    .map((c, i) => ({ i, dev: Math.abs(c - expected) }))
    .filter(x => x.dev > expected * tol)
    .map(x => x.i);
  return { verdict: skewed.length > 10 ? 'skewed' : 'balanced', skewedBuckets: skewed };
}

// 自测
const mem = new Map();
const storage = { get: (k) => mem.get(k) ?? null, set: (k, v) => mem.set(k, v) };
// 锚定优先
mem.set('__build_ver', 'new');
console.log(pickVersion('anyone', { grayPercent: 0, storage }) === 'new');   // 锚定覆盖
mem.clear();
// hash 稳定
const v1 = pickVersion('user-42', { grayPercent: 50, storage });
const v2 = pickVersion('user-42', { grayPercent: 50, storage });
console.log(v1 === v2);                                  // 会话内稳定
console.log(mem.get('__build_ver') === v1);

// 边界
console.log(pickVersion('x', { grayPercent: 0, storage: { get: () => null, set: () => {} } }) === 'old');
console.log(pickVersion('x', { grayPercent: 100, storage: { get: () => null, set: () => {} } }) === 'new');

// 均匀性
const uniform = Array.from({ length: 1000 }, (_, i) => ({ userId: `u${i}`, bucket: i % 100 }));
console.log(auditBalance(uniform).verdict === 'balanced');
const skewed = [...Array(50).fill({ bucket: 0 }), ...Array(500).fill({ bucket: 50 })];
console.log(auditBalance(skewed).verdict === 'skewed');
console.log(auditBalance([]).verdict === 'balanced');
```

**评分点**：
- 锚定优先于 hash 计算（会话内版本锁定）；hash 确定性（同用户同桶）
- 边界三态（grayPercent 0/100/锚定值）；存储注入（测试无 sessionStorage 依赖）
- 均匀性审计（tol 相对偏差、skewed 阈值 10 桶）；空 assignments
- 能说清「随机分流会造成 html 与 chunk 版本错配，稳定键 + 会话锚定是产物灰度的硬约束」属于加分
