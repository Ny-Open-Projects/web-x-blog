## RBL-588：笔试：手写基准报告聚合器（中位数/离群剔除/回归判定）

**答**：实现 `aggregate(samples)` 与 `judge(result, baseline, { threshold })`。`aggregate`：输入一组毫秒采样（可能含离群值），先剔除超过 3×MAD（中位绝对偏差）的离群点（不足 3 个样本不剔除），返回 `{ p50, p90, mean, n, outliers }`（outliers 为被剔除值数组，保留两位小数）。`judge`：对每个套件比较 result 与 baseline 的 p50，回归超 threshold（如 0.05 即 +5%）返回失败列表，并计算整体（各套件加权，权重 = baseline p50）的加权回归百分比。

```javascript
const median = (arr) => {
  const s = [...arr].sort((a, b) => a - b);
  const m = s.length >> 1;
  return s.length % 2 ? s[m] : (s[m - 1] + s[m]) / 2;
};

function aggregate(samples) {
  if (samples.length === 0) throw new Error('no samples');
  const med = median(samples);
  const mad = samples.length >= 3
    ? median(samples.map(v => Math.abs(v - med)))
    : Infinity;                                   // 不足 3 个不剔除
  const isOut = (v) => Math.abs(v - med) > 3 * mad;
  const outliers = samples.filter(isOut);
  const kept = samples.filter(v => !isOut(v));
  const data = kept.length ? kept : samples;      // 全被剔时兜底用原始
  const sorted = [...data].sort((a, b) => a - b);
  const p = (q) => sorted[Math.min(sorted.length - 1, Math.floor(q * sorted.length))];
  return {
    p50: +p(0.5).toFixed(2), p90: +p(0.9).toFixed(2),
    mean: +(data.reduce((a, b) => a + b, 0) / data.length).toFixed(2),
    n: data.length, outliers,
  };
}

function judge(result, baseline, { threshold = 0.05, weights } = {}) {
  const failures = [];
  let wSum = 0, rSum = 0;
  for (const name of Object.keys(baseline)) {
    const base = baseline[name].p50, cur = result[name].p50;
    const ratio = cur / base - 1;
    const w = weights?.[name] ?? base;             // 默认按 baseline 时间加权
    wSum += w; rSum += w * ratio;
    if (ratio > threshold) failures.push({ name, base, cur, delta: +ratio.toFixed(4) });
  }
  return { failures, overallDelta: +(rSum / wSum).toFixed(4), pass: failures.length === 0 };
}

// 自测
const agg = aggregate([100, 102, 98, 101, 300]);    // 300 是离群
// 断言：agg.outliers 含 300；agg.p50 === 101；agg.n === 4
const small = aggregate([50, 52]);
// 断言：small.outliers.length === 0（<3 样本不剔除）
const j = judge(
  { a: { p50: 105 }, b: { p50: 60 } },
  { a: { p50: 100 }, b: { p50: 100 } }, { threshold: 0.05 });
// 断言：j.failures = [{ name: 'a', ... delta: 0.05 }] 边界外才判（0.05 不超，需 >）
// b 回归 -40% 拉低 overallDelta
console.log(j.failures.every(f => f.delta > 0.05));
```

**评分点**：
- MAD 离群剔除实现正确且含「不足 3 个不剔除」「全剔除兜底」两个防御边界
- p50/p90 用排序索引取值，输出保留两位小数
- judge 的加权回归计算正确（默认权重 = baseline p50），失败判定用严格大于
- 能说清「离群剔除后仍报告 outliers 列表」的审计价值属于加分
