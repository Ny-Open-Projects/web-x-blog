## RBL-331：产物分析平台的自助化设计

**答**:
- 自助化目标：开发者不改构建配置就能看分析——分析报告自动生成（每次 CI 构建附带）+ 历史可查 + 对比可选（任意两个 commit diff）
- 报告内容分层：一屏总览（总体积趋势/异常标记）→ 可交互下钻（treemap 点击到模块）→ 可行动建议（重复依赖清单/替换建议带预期收益）
- 数据流水线：CI 构建产出 stats + sourcemap → 上传分析服务 → 解析入库（源码粒度体积归因）→ 报告 URL 回写 PR
- 规模化要点：分析解析有成本（map 大）——异步化 + 增量解析（只解析变更 chunk）+ 数据保留策略

```text
流水线：CI stats+map → 分析服务入库 → 报告 URL 回写 PR
报告：一屏总览 → 交互下钻 → 可行动建议（带收益预估）
```
