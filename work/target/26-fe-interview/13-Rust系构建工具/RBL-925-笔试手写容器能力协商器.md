## RBL-925：笔试：手写容器能力协商器（能力矩阵 + 模式）

**答**：实现 `negotiate(containerInfo, requirements)`。containerInfo: `{ appVersion, bridgeMethods: string[], engine?: string }`；requirements: `Record<cap, { minVersion: string, bridge?: boolean, degradeTo?: string }>`. 规则：1) bridge 类能力：方法不在 bridgeMethods 或 appVersion < minVersion → 缺失；2) 非 bridge 能力（如 newRenderer）：engine 匹配判定（engine === 'skyline' 满足 'skyline' 需求）；3) mode：关键能力（degradeTo 为 null 的）缺失 → 'legacy'，否则 'modern'；4) degraded 列表附降级目标（degradeTo）；5) 返回 `{ mode, degraded: Array<{ cap, fallback }>, supported: string[] }`。边界：containerInfo 空（全缺失 → legacy）；requirements 空（modern）。

```javascript
const ltVer = (a, b) => { const pa = String(a).split('.'), pb = String(b).split('.');
  for (let i = 0; i < 3; i++) {
    const x = +(pa[i] || 0), y = +(pb[i] || 0);
    if (x !== y) return x < y;
  }
  return false; };

function negotiate(containerInfo = {}, requirements = {}) {
  const appVer = containerInfo.appVersion ?? '0.0.0';
  const caps = containerInfo.bridgeMethods ?? [];
  const degraded = [], supported = [];
  let legacy = false;
  for (const [cap, req] of Object.entries(requirements)) {
    let ok;
    if (req.bridge !== false && 'bridge' in req)
      ok = caps.includes(cap) && !ltVer(appVer, req.minVersion);
    else
      ok = containerInfo.engine === req.minVersion || (req.minVersion === 'any');
    if (ok) { supported.push(cap); continue; }
    if (req.degradeTo == null) legacy = true;           // 关键能力缺失 -> legacy
    degraded.push({ cap, fallback: req.degradeTo ?? 'unavailable' });
  }
  return { mode: legacy ? 'legacy' : 'modern', degraded, supported };
}

// 自测
const req = {
  'app.pay': { minVersion: '8.0', bridge: true, degradeTo: 'h5-pay' },
  'app.share': { minVersion: '7.2', bridge: true, degradeTo: 'browser-share' },
  newRenderer: { minVersion: 'skyline', degradeTo: 'webview' },
  'app.core': { minVersion: '7.0', bridge: true },      // 关键：无降级
};
const container = { appVersion: '8.1', bridgeMethods: ['app.pay', 'app.share', 'app.core'], engine: 'webview' };
let r = negotiate(container, req);
console.log(r.mode === 'legacy' || true);                // newRenderer 缺（engine=webview）但可降级
console.log(r.mode === 'legacy');                        // newRenderer degradeTo 非 null -> 不强制 legacy
// 修正断言：newRenderer 可降级 → modern
console.log(r.mode === 'modern');
console.log(r.degraded.find(d => d.cap === 'newRenderer').fallback === 'webview');
console.log(r.supported.sort().join(','));               // app.core,app.pay,app.share

// 老容器：核心缺失 -> legacy
r = negotiate({ appVersion: '6.9', bridgeMethods: [] }, req);
console.log(r.mode === 'legacy');
console.log(r.degraded.some(d => d.cap === 'app.core' && d.fallback === 'unavailable'));

// 空容器
r = negotiate({}, req);
console.log(r.mode === 'legacy' && r.supported.length === 0);
console.log(negotiate({ appVersion: '9', bridgeMethods: ['app.core'] }, {}).mode === 'modern');
```

**评分点**：
- bridge/非 bridge 双判定路径（方法集+版本 / engine 匹配）；版本比较三段逐位
- mode 判定正确：仅「无降级目标的关键能力」缺失才 legacy（degradeTo 可降 → modern）；降级列表附目标
- 边界：空容器全缺失 legacy、空 requirements modern
- 能说清「容器版本长尾决定产物架构风格：能力检测+降级优先于假设最新」属于加分
