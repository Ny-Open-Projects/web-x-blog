## RBL-470：手写构建系统知识沉淀索引
**答**：实现 `createKnowledgeIndex()`：1) 条目：决策（ADR）/事故（复盘）/模式（最佳实践）三类，可互相链接（事故引用决策——「根因是决策 X 的后果」）；2) 检索：按标签 + 全文（简化：关键词倒排索引）；3) 时效：条目带 reviewDate（过期提醒——知识会腐化）；4) 关联推荐：读某条目时推荐「关联条目」（引用链）；5) 空白检测：高频错误签名（遥测）无对应知识条目 → 提示补文档（知识库与实际故障的对齐）。

```javascript
export function createKnowledgeIndex() {
  const entries = new Map()      // id → { kind, title, tags, body, links, reviewDate }
  const inverted = new Map()     // word → Set<id>

  function add(id, entry) {
    entries.set(id, { ...entry, links: entry.links ?? [] })
    for (const w of tokenize(entry.title + ' ' + entry.body)) {
      if (!inverted.has(w)) inverted.set(w, new Set())
      inverted.get(w).add(id)
    }
  }

  function tokenize(text) {
    return text.toLowerCase().split(/[^a-z0-9\u4e00-\u9fa5]+/).filter((w) => w.length > 1)
  }

  function search(query) {
    const words = tokenize(query)
    const scores = new Map()
    for (const w of words)
      for (const id of inverted.get(w) ?? [])
        scores.set(id, (scores.get(id) ?? 0) + 1)
    return [...scores.entries()].sort((a, b) => b[1] - a[1]).map(([id]) => entries.get(id))
  }

  function related(id) {                                          // 引用链推荐
    const e = entries.get(id)
    return e?.links.map((l) => entries.get(l)).filter(Boolean) ?? []
  }

  function audit(telemetryErrors) {
    const stale = [...entries.entries()].filter(([_, e]) => new Date(e.reviewDate) < Date.now())
    const covered = new Set([...entries.values()].flatMap((e) => e.tags))
    const gaps = telemetryErrors.filter((sig) => !covered.has(sig) && !search(sig).length)
    return { stale: stale.map(([id]) => id), gaps }               // 知识空白 = 补文档提示
  }

  return { add, search, related, audit }
}
```
**评分点**：
- 三类条目互链（事故引用决策——知识是图不是列表）
- 倒排索引检索（简化实现——关键词分词 + 计分）
- reviewDate 时效（知识腐化治理）
- 空白检测（遥测错误签名 vs 知识覆盖——知识库与现实的差距可见）
