## RBL-790：笔试：手写迁移看板汇总器（进度聚合 + 阻塞排序）

**答**：实现 `summarize(reports)`。report: `{ repo, stage: 0|1|2|3|4, blocked?: { step, reason, since }[] }[]`（stage：0 未开始 1 评估 2 翻译 3 验证 4 完成）。规则：1) 输出 `{ byStage: Record<stage, string[]>, blockers: Array<{ repo, step, reason, days }>, completion }`——completion = stage===4 占比（百分比 1 位小数）；2) blockers 按 days（since 距今天数）降序、取 top5；3) 「卡在 stage 2 超过 14 天」的仓库标记 stale（blockers 附 level: 'stale'）；4) 边界：无 report；blocked 缺 since（按 0 天）。

```javascript
function summarize(reports = []) {
  const byStage = {};
  for (let i = 0; i <= 4; i++) byStage[i] = [];
  const blockers = [];
  const now = Date.now();
  for (const r of reports) {
    byStage[r.stage]?.push(r.repo);
    for (const b of r.blocked ?? []) {
      const days = b.since ? Math.floor((now - new Date(b.since)) / 86400000) : 0;
      blockers.push({ repo: r.repo, step: b.step, reason: b.reason, days,
        level: r.stage === 2 && days > 14 ? 'stale' : 'normal' });
    }
  }
  blockers.sort((a, b) => b.days - a.days);
  const completion = reports.length
    ? +(reports.filter(r => r.stage === 4).length / reports.length * 100).toFixed(1)
    : 0;
  return { byStage, blockers: blockers.slice(0, 5), completion };
}

// 自测
const now = Date.now();
const day = (n) => new Date(now - n * 86400000).toISOString();
const reports = [
  { repo: 'a', stage: 4 },
  { repo: 'b', stage: 2, blocked: [{ step: 'css-plugin', reason: '等价物缺失', since: day(20) }] },
  { repo: 'c', stage: 2, blocked: [{ step: 'smoke', reason: 'CI 配额', since: day(3) }] },
  { repo: 'd', stage: 1 },
  { repo: 'e', stage: 0 },
];
let r = summarize(reports);
console.log(r.completion === 20);                        // 1/5
console.log(r.byStage[2].sort().join(','));              // b,c
console.log(r.blockers[0].repo === 'b' && r.blockers[0].level === 'stale');   // 20 天最久 + stale
console.log(r.blockers[1].repo === 'c' && r.blockers[1].level === 'normal');
console.log(r.blockers.length === 2);

r = summarize([]);
console.log(r.completion === 0 && r.blockers.length === 0);
r = summarize([{ repo: 'x', stage: 2, blocked: [{ step: 's', reason: 'r' }] }]);   // 无 since
console.log(r.blockers[0].days === 0);
```

**评分点**：
- 分阶段聚合正确；completion 百分比精度（1 位小数）
- blockers 按 days 降序取 top5；stale 判定条件精确（stage 2 且 >14 天）
- 无 since 按 0 天；空输入安全
- 能说清「stale 是迁移看板的核心价值：把『卡了很久没人管』显性化」属于加分
