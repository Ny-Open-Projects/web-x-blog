## RBL-776：笔试：手写区域合规特性审计器（存在性 + 矩阵）

**答**：实现 `auditRegions(builds, requirements)`。builds: `Record<region, { features: string[], entryKB }>`；requirements: `Record<region, string[]>`（必须存在的合规特性）。规则：1) 每区域检查全部 requirements：缺失 → problem `{ region, missing }`；2) 反向审计：产物包含「非本区域需求的合规特性」→ warning（region 泄漏：EU 产物带 CN 备案代码 = 冗余与法律风险）；3) 特性标记方式：产物内 `/* feature:cookie-consent */` 注释或清单（builds[].features 直接给定）；4) 返回 `{ problems, warnings, ok }`。边界：区域无需求；区域不在 builds。

```javascript
function auditRegions(builds, requirements = {}) {
  const problems = [], warnings = [];
  const allFeatures = [...new Set(Object.values(requirements).flat())];
  for (const [region, reqs] of Object.entries(requirements)) {
    const b = builds[region];
    if (!b) { problems.push({ region, missing: reqs, detail: '产物缺失' }); continue; }
    const missing = reqs.filter(f => !b.features.includes(f));
    if (missing.length) problems.push({ region, missing });
    // 反向：包含非本区域特性
    const others = allFeatures.filter(f => !reqs.includes(f) &&
      Object.entries(requirements).some(([r, fs]) => r !== region && fs.includes(f)));
    const leaked = b.features.filter(f => others.includes(f));
    if (leaked.length) warnings.push({ region, leaked });
  }
  return { problems, warnings, ok: problems.length === 0 };
}

// 自测
const requirements = { eu: ['cookie-consent', 'dsar-entry'], cn: ['beacon-备案'], us: [] };
const builds = {
  eu: { features: ['cookie-consent'], entryKB: 300 },              // 缺 dsar-entry
  cn: { features: ['beacon-备案', 'cookie-consent'], entryKB: 280 }, // 泄漏 eu 特性
  us: { features: [], entryKB: 250 },
};
let r = auditRegions(builds, requirements);
console.log(r.ok === false);
console.log(r.problems.find(p => p.region === 'eu').missing.join(',') === 'dsar-entry');
console.log(r.warnings.find(w => w.region === 'cn').leaked.join(',') === 'cookie-consent');

// 全合规
r = auditRegions({ eu: { features: ['cookie-consent', 'dsar-entry'], entryKB: 300 },
  cn: { features: ['beacon-备案'], entryKB: 280 },
  us: { features: [], entryKB: 250 } }, requirements);
console.log(r.ok === true && r.warnings.length === 0);

// 区域缺失
r = auditRegions({ eu: { features: ['cookie-consent', 'dsar-entry'], entryKB: 1 } }, requirements);
console.log(r.problems.find(p => p.region === 'cn').detail === '产物缺失');

console.log(auditRegions({}, {}).ok === true);
```

**评分点**：
- 正向存在性检查（缺失聚合为 missing 数组）；产物缺失独立处理（不误报为特性缺失）
- 反向泄漏检测（非本区域合规特性出现在产物——法律风险的隐性面）
- 空需求区域通过；全合规 ok
- 能说清「合规逻辑编译期保证存在性、区域泄漏是合规与体积双重问题」属于加分
