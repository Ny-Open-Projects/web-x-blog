## RBL-798：笔试：手写实验残留清偿检查器（状态机 + 分支检测）

**答**：实现 `auditExperiments(code, registry)`。registry: `Record<name, { status: 'running'|'concluded'|'cleaned', branches?: string[] }>`；branches 是实验的 flag 分支片段（如 ['if (__exp_x) {', '} else {']）。规则：1) status=running → 不审计；2) concluded：代码中仍出现 `__exp_{name}` flag 或 branches 片段 → finding 'debt'（列出残留类型：flag/branch）；3) cleaned：代码中**不应再有**任何该实验痕迹（连 flag 检查代码都应删）——残留 finding 'residue'；4) 返回 `{ findings: Array<{ name, type, line? }>, ok }`（ok = 无 finding）。边界：registry 空；branches 未提供时只查 flag。

```javascript
function auditExperiments(code, registry = {}) {
  const findings = [];
  const lines = code.split('\n');
  for (const [name, exp] of Object.entries(registry)) {
    if (exp.status === 'running') continue;
    const flag = `__exp_${name}`;
    const hitLines = [];
    lines.forEach((l, i) => {
      if (l.includes(flag)) hitLines.push({ line: i + 1, type: 'flag' });
      if (exp.branches?.some(b => l.includes(b)))
        hitLines.push({ line: i + 1, type: 'branch' });
    });
    for (const h of hitLines)
      findings.push({
        name,
        type: exp.status === 'concluded' ? 'debt' : 'residue',
        line: h.line, branchType: h.type,
      });
  }
  return { findings, ok: findings.length === 0 };
}

// 自测
const registry = {
  'exp-a': { status: 'running' },
  'exp-b': { status: 'concluded', branches: ['if (__exp_exp_b) {'] },
  'exp-c': { status: 'cleaned' },
};
const code = [
  'const x = __exp_exp_b ? V2 : V1;',
  'if (__exp_exp_b) { renderV2(); } else { renderV1(); }',
  'if (__exp_exp_c) { old(); }',                          // cleaned 却残留
  'normal();',
].join('\n');
let r = auditExperiments(code, registry);
console.log(r.ok === false);
console.log(r.findings.filter(f => f.name === 'exp-b').length >= 2);
console.log(r.findings.filter(f => f.name === 'exp-b').every(f => f.type === 'debt'));
console.log(r.findings.find(f => f.name === 'exp-c').type === 'residue');
console.log(r.findings.every(f => f.name !== 'exp-a'));  // running 不审计

// 清洁状态
r = auditExperiments('normal();', registry);
console.log(r.ok === true && r.findings.length === 0);

// 无 branches 只查 flag
r = auditExperiments('__exp_exp_b;', { 'exp-b': { status: 'concluded' } });
console.log(r.findings[0].branchType === 'flag');
console.log(auditExperiments('x', {}).ok === true);
```

**评分点**：
- 三态状态机语义正确：running 跳过、concluded 查 debt、cleaned 查 residue（更严）
- 残留类型区分（flag/branch）与行号定位；running 实验完全豁免
- 边界：无 branches 只查 flag、空 registry 通过
- 能说清「实验债的清偿需要机械检查——人不会记得删败者代码」属于加分
