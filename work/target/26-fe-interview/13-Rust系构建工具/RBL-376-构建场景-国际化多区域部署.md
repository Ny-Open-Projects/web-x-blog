## RBL-376：构建产物多区域部署的构建配合

**答**:
- region 差异面：语言（i18n 包）、合规（GDPR 产物的统计 SDK 差异——区域法律要求不同依赖）、时区/货币（配置注入）、CDN 域
- 构建策略：region 维度构建矩阵（区域差异走构建期条件+DefinePlugin）——或「一套产物 + 区域运行时配置」（灵活但合规差异大的场景不够）
- 合规驱动裁剪：GDPR region 剔除特定 SDK（构建期 flag）——合规要求是硬约束（构建矩阵验证每个 region 的依赖清单合规）
- 校验：region 产物 diff 审计（差异必须可归因到区域配置）——防「误把合规差异发错区域」的事故

```text
矩阵：region × 环境；差异 = 语言/合规 SDK/时区/CDN
合规：GDPR region 构建期裁剪（flag）+ 依赖清单审计
对账：region 产物 diff 归因到区域配置
```
