## RBL-913：笔试：手写存储迁移链执行器（迁移 + 回退）

**答**：实现 `migrateStorage(raw, migrations, { current, snapshotStore })`。migrations: `Record<fromVersion, (data) => data>`（from 版本 → 下一版本）。规则：1) 检测当前版本（raw.v 缺省 1），从 from 逐级迁移到 current；2) 迁移前快照（snapshotStore.save）——任一步失败：恢复快照，返回 `{ migrated: false, from, error }`；3) 无需迁移（raw.v === current）→ `{ migrated: false, from: current }`；4) raw 为 null（首次）→ 返回默认初始结构 `{ ...INITIAL, v: current, migrated: false }`；5) 版本跳跃缺失（无 from 版本的迁移函数）→ 失败处理。INITIAL 常量注入。

```javascript
function migrateStorage(raw, migrations = {}, { current, snapshotStore, INITIAL = {} } = {}) {
  if (raw == null) return { data: { ...INITIAL, v: current }, migrated: false, from: 'null' };
  const from = raw.v ?? 1;
  if (from === current) return { data: raw, migrated: false, from };

  snapshotStore.save(raw);                               // 迁移前快照
  let data = raw;
  for (let v = from; v < current; v++) {
    const fn = migrations[v];
    if (!fn) {
      snapshotStore.restore();
      return { migrated: false, from, error: `缺少 v${v}->${v + 1} 迁移函数` };
    }
    try { data = { ...fn(data), v: v + 1 }; }
    catch (e) {
      snapshotStore.restore();
      return { migrated: false, from, error: e.message };
    }
  }
  return { data, migrated: true, from };
}

// 自测
const snapshotStore = { saved: null,
  save: (d) => { snapshotStore.saved = JSON.parse(JSON.stringify(d)); },
  restore: () => JSON.parse(JSON.stringify(snapshotStore.saved)) };

const migrations = {
  1: (d) => ({ ...d, cartItems: d.cart ?? [] }),         // 1->2
  2: (d) => ({ ...d, currency: 'CNY' }),                 // 2->3
};
let r = migrateStorage({ v: 1, cart: ['a'] }, migrations, { current: 3, snapshotStore });
console.log(r.migrated === true && r.data.v === 3);
console.log(r.data.cartItems.join(',') === 'a' && r.data.currency === 'CNY');

// 首次
r = migrateStorage(null, migrations, { current: 3, snapshotStore, INITIAL: { theme: 'light' } });
console.log(r.data.theme === 'light' && r.data.v === 3);

// 无需迁移
r = migrateStorage({ v: 3, x: 1 }, migrations, { current: 3, snapshotStore });
console.log(r.migrated === false && r.data.x === 1);

// 中途失败回退
const badMigrations = { 1: () => { throw new Error('boom'); } };
r = migrateStorage({ v: 1, cart: ['x'] }, badMigrations, { current: 3, snapshotStore });
console.log(r.migrated === false && r.error === 'boom');
console.log(snapshotStore.restore().cart.join(',') === 'x');   // 快照保留旧数据

// 缺迁移函数
r = migrateStorage({ v: 2 }, migrations, { current: 4, snapshotStore });
console.log(r.error.includes('v3->4'));
```

**评分点**：
- 版本链逐级迁移（每步打 v 标记）；首次用户走 INITIAL；无需迁移短路
- 快照回退正确（任一步失败恢复旧数据——迁移失败不丢数据）；缺迁移函数显式报错
- 边界全覆盖（null/等版本/中途失败/缺函数）
- 能说清「灰度期新旧 schema 并存，迁移失败不丢数据是存储演化的底线」属于加分
