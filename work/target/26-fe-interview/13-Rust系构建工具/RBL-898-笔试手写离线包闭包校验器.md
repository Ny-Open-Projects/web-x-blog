## RBL-898：笔试：手写离线包闭包校验器（引用对账）

**答**：实现 `verifyOfflineClosure(manifest, htmlPages)`。manifest: `{ files: string[]（包内路径，无前导斜杠）, onlineFallbacks?: string[] }`；htmlPages: `Array<{ path, refs: string[] }>`（refs 为页面引用的 script/css/img URL）。规则：1) 引用归一：去掉协议/域名与前导斜杠 → 包内路径比对；2) 不在包内且不在 onlineFallbacks → problem `{ page, ref }`；3) 带 query/hash 的引用剥离后比对；4) 返回 `{ problems, ok }`。边界：无页面；refs 为空；onlineFallbacks 未提供视为空集。

```javascript
const normalize = (ref) => ref
  .replace(/^https?:\/\/[^/]+/, '')                      // 剥域名
  .split(/[?#]/)[0]                                      // 剥 query/hash
  .replace(/^\//, '');

function verifyOfflineClosure(manifest, htmlPages = []) {
  const inPkg = new Set(manifest.files ?? []);
  const fallbacks = new Set((manifest.onlineFallbacks ?? []).map(normalize));
  const problems = [];
  for (const page of htmlPages) {
    for (const ref of page.refs ?? []) {
      const local = normalize(ref);
      if (local === '') continue;                        // 空引用跳过
      if (!inPkg.has(local) && !fallbacks.has(local))
        problems.push({ page: page.path, ref, local,
          detail: '离线不可达且未声明 fallback——离线白屏风险' });
    }
  }
  return { problems, ok: problems.length === 0 };
}

// 自测
const manifest = {
  files: ['index.html', 'main.abc.js', 'style.css', 'logo.png'],
  onlineFallbacks: ['https://cdn.map.com/tiles/**'],
};
const pages = [
  { path: 'index.html', refs: ['main.abc.js', '/style.css', 'https://static.x.com/logo.png'] },   // 全在包内
  { path: 'list.html', refs: ['missing.js'] },           // 缺失
  { path: 'map.html', refs: ['https://cdn.map.com/tiles/3/1.png'] },  // fallback
];
let r = verifyOfflineClosure(manifest, pages);
console.log(r.ok === false);
console.log(r.problems.length === 1 && r.problems[0].page === 'list.html');
console.log(r.problems[0].local === 'missing.js');

// 域名归一命中包内
r = verifyOfflineClosure(manifest, [{ path: 'index.html', refs: ['https://h5.app.com/main.abc.js?v=1#top'] }]);
console.log(r.ok === true);

// fallback 未提供
r = verifyOfflineClosure(manifest, pages.slice(2), { });    // map 引用不在 fallback（manifest 有）
console.log(r.ok === true);
const noFallback = { ...manifest, onlineFallbacks: undefined };
r = verifyOfflineClosure(noFallback, pages.slice(2));
console.log(r.ok === false);

console.log(verifyOfflineClosure(manifest, []).ok === true);
```

**评分点**：
- 引用归一正确（剥域名/query/hash/前导斜杠）；query 版本参数不影响比对
- 双出口判定（包内或显式 fallback）；fallback 缺省为空集（保守——未声明的在线资源视为不可达）
- 空引用跳过；边界
- 能说清「页面级可用性是离线包的交付单位，文件完整性是必要不充分条件」属于加分
