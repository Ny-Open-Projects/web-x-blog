## RBL-674：笔试：手写诊断注册表与文档同步校验器

**答**：实现两部分。1) `createRegistry()`：`define(code, { message, hint, docs })` 注册诊断（code 格式 `RBL\d{4}` 且段位 1-5，重复定义抛错）；`diag(code, args)` 生成诊断对象 `{ code, message, hint, docs }`（未注册的 code 抛错——诊断也是治理资产）；2) `auditDocs(registry, docsPages)`：docsPages 为文档站已有 url 数组，校验每个已注册诊断都有文档页、每个文档页都对应已注册诊断（反向多余页告警），返回 `{ missing: string[], extra: string[] }`。边界：同 code 段位冲突（如 RBL1001 定义两次）抛错；diag 未注册 code 抛错。

```javascript
function createRegistry() {
  const map = new Map();
  const valid = (c) => /^RBL[1-5]\d{3}$/.test(c);
  return {
    define(code, def) {
      if (!valid(code)) throw new Error(`非法错误码: ${code}`);
      if (map.has(code)) throw new Error(`重复定义: ${code}`);
      if (typeof def.message !== 'function' || typeof def.hint !== 'function')
        throw new Error(`${code} 的 message/hint 必须是模板函数`);
      map.set(code, def);
    },
    diag(code, args) {
      const d = map.get(code);
      if (!d) throw new Error(`未注册错误码: ${code}`);
      return { code, message: d.message(args), hint: d.hint(args), docs: d.docs };
    },
    codes() { return [...map.keys()]; },
    _map: map,
  };
}

function auditDocs(registry, docsPages) {
  const pages = new Set(docsPages);
  const registered = [...registry._map.keys()].map(c => registry._map.get(c).docs);
  const missing = registered.filter(u => !pages.has(u));
  const regUrls = new Set(registered);
  const extra = docsPages.filter(u => !regUrls.has(u));
  return { missing, extra };
}

// 自测
const reg = createRegistry();
reg.define('RBL1001', {
  message: (id) => `Cannot resolve '${id}'`,
  hint: (id) => [`npm i ${id}`, '检查 alias'],
  docs: '/diagnostics/RBL1001',
});
reg.define('RBL2001', {
  message: (m) => `${m} 可能含副作用`,
  hint: () => ['声明 sideEffects'],
  docs: '/diagnostics/RBL2001',
});

const d = reg.diag('RBL1001', './x.js');
console.log(d.message === "Cannot resolve './x.js'");
console.log(d.hint[0] === 'npm i ./x.js');

let e1; try { reg.diag('RBL9999', {}); } catch (x) { e1 = x; }
console.log(/未注册/.test(e1.message));
let e2; try { reg.define('RBL1001', {}); } catch (x) { e2 = x; }
console.log(/重复定义/.test(e2.message));
let e3; try { reg.define('RBLX001', {}); } catch (x) { e3 = x; }
console.log(/非法/.test(e3.message));

const audit = auditDocs(reg, ['/diagnostics/RBL1001', '/diagnostics/RBL9999']);
console.log(audit.missing.length === 1 && audit.missing[0] === '/diagnostics/RBL2001');
console.log(audit.extra.length === 1 && audit.extra[0] === '/diagnostics/RBL9999');
console.log(auditDocs(reg, ['/diagnostics/RBL1001', '/diagnostics/RBL2001']).extra.length === 0);
```

**评分点**：
- 注册表治理：code 格式与段位校验、重复定义/未注册 diag 抛错、message/hint 必须是函数模板
- 双向文档同步：缺失页与多余页分别列出（文档腐化与孤儿页都暴露）
- diag 生成结构化诊断（code+message+hint+docs），与 RBL-568 诊断体系衔接
- 能说清「错误码是被治理的资产，注册表防未定义码散落」属于加分
