## RBL-570：笔试：手写构建内存峰值采样器与阶段归因

**答**：实现 `profileMemory(fn)`，包装一个异步构建函数：每 100ms 采样 `process.memoryUsage().heapUsed`（测试中用注入的 `getUsage` 替代），记录 `{ t, rss, phase }`（phase 由 fn 内调用 `mark(phase)` 切换）。完成后返回 `{ peak, peakPhase, curve }`：peak 是最大采样值，peakPhase 是峰值时刻所处阶段名。边界：fn 抛错仍返回已采集曲线（附 error）；采样不得阻塞主流程；fn 秒回（<100ms）时曲线至少 1 条。

```javascript
function profileMemory(fn, { interval = 100, getUsage = () => process.memoryUsage().heapUsed } = {}) {
  return async function (...args) {
    const curve = []; let phase = 'init'; let error = undefined;
    const timer = setInterval(() => {
      curve.push({ t: Date.now(), rss: getUsage(), phase });
    }, interval);
    const mark = (p) => { phase = p; };                       // 阶段切换即时生效
    curve.push({ t: Date.now(), rss: getUsage(), phase });    // 保底首条采样
    const started = curve[0].rss;
    try {
      const result = await fn({ mark }, ...args);
      return finalize(result);
    } catch (e) { error = e; return finalize(undefined); }
  };

  function finalize(result) {
    clearInterval(timer);
    curve.push({ t: Date.now(), rss: getUsage(), phase });    // 收尾采样
    const peakSample = curve.reduce((a, b) => (b.rss > a.rss ? b : a), curve[0]);
    return { peak: peakSample.rss, peakPhase: peakSample.phase, curve,
             delta: curve[curve.length - 1].rss - started,
             result, error };
  }
}

// 自测：模拟阶段化内存增长
const mem = { v: 0 };
const run = profileMemory(async ({ mark }) => {
  mark('graph');  mem.v = 300;
  await sleep(120);
  mark('transform'); mem.v = 800;                       // 峰值在 transform
  await sleep(120);
  mark('codegen'); mem.v = 200;
  await sleep(60);
  return 'ok';
}, { interval: 40, getUsage: () => mem.v });
const r = await run();
// 断言：r.result==='ok'，r.peak===800，r.peakPhase==='transform'，r.delta===200
```

**评分点**：
- 峰值归因正确：peak 取最大采样、peakPhase 取峰值时刻的 phase 而非最终 phase
- 保底采样保证秒级任务也有 ≥1 条曲线；收尾时 clearInterval 无泄漏
- fn 抛错不吞错（error 返回）且曲线完整返回；mark 的阶段切换在下个采样可见
- delta（净增长）与 peak 区分——长期驻存 vs 瞬时峰值是不同治理对象
