## RBL-778：笔试：手写主题变量完整性校验（覆盖 + 未适配 + 对比度）

**答**：实现 `validateThemes(themes)`。themes: `Record<name, Record<varName, string>>`（含 base 主题）。规则：1) 除 base 外每主题必须覆盖 base 的全部变量 → missing 数组（fatal）；2) 颜色类变量（名含 color/bg/border）与 base 值相同 → unchanged 告警（未真正适配）；3) 对比度抽查：`color` 与 `bg` 变量成对时（`color.text`/`bg.primary`）计算对比度 < 4.5 → 告警（简化对比度：亮度差百分比近似即可，提供 lum 函数注入）；4) 返回 `{ ok, missing: Record<theme, string[]>, unchanged: Record<theme, string[]>, contrastWarnings }`。边界：只有 base；非颜色变量值相同不算未适配。

```javascript
function validateThemes(themes, { lum = (c) => parseInt(c.slice(1), 16) / 0xffffff } = {}) {
  const base = themes.base ?? {};
  const missing = {}, unchanged = {}, contrastWarnings = [];
  for (const [name, vars] of Object.entries(themes)) {
    if (name === 'base') continue;
    const miss = Object.keys(base).filter(k => !(k in vars));
    if (miss.length) missing[name] = miss;
    const same = Object.keys(vars).filter(k =>
      /color|bg|border/i.test(k) && vars[k] === base[k]);
    if (same.length) unchanged[name] = same;
    // 对比度抽查（text vs bg 成对）
    for (const t of Object.keys(vars)) {
      if (!/^color\.text/.test(t)) continue;
      const bgK = t.replace('color.text', 'bg');
      if (bgK in vars) {
        const l1 = lum(vars[t]), l2 = lum(vars[bgK]);
        const ratio = (Math.max(l1, l2) + 0.05) / (Math.min(l1, l2) + 0.05);
        if (ratio < 4.5)
          contrastWarnings.push({ theme: name, pair: `${t}/${bgK}`, ratio: +ratio.toFixed(2) });
      }
    }
  }
  return { ok: Object.keys(missing).length === 0, missing, unchanged, contrastWarnings };
}

// 自测
const themes = {
  base: { 'color.text': '#111111', 'bg.primary': '#ffffff', 'color.accent': '#3b82f6', 'radius.md': '8px' },
  dark: { 'color.text': '#eeeeee', 'bg.primary': '#111111', 'color.accent': '#3b82f6', 'radius.md': '8px' },
  half: { 'color.text': '#eeeeee', 'bg.primary': '#111111' },       // 缺 accent/radius
  lazy: { 'color.text': '#111111', 'bg.primary': '#ffffff', 'color.accent': '#3b82f6' }, // 全同 base（未适配）
};
let r = validateThemes(themes);
console.log(r.ok === false);
console.log(r.missing.half.join(','));                   // color.accent,radius.md
console.log(r.unchanged.lazy.join(','));
console.log(r.unchanged.half.includes('radius.md') === false);  // 非颜色变量不算
console.log(r.contrastWarnings.length === 0);            // dark 对比度高

// 低对比度（注入 lum）
r = validateThemes({
  base: { 'color.text': '#888888', 'bg.primary': '#999999' },
  dark: { 'color.text': '#888888', 'bg.primary': '#999999' },
}, { lum: (c) => parseInt(c.slice(1), 16) / 0xffffff });
console.log(r.contrastWarnings.some(w => w.theme === 'dark'));
console.log(validateThemes({ base: { a: '1' } }).ok === true);
```

**评分点**：
- 覆盖完整性检查（缺项 fatal）与「未适配」（颜色值与 base 相同）区分；非颜色变量豁免
- 对比度成对抽查实现（text/bg 配对、ratio 近似可接受）；低对比度告警带主题名
- 边界：只有 base 通过、缺项聚合为 Record
- 能说清「暗色缺项的白闪根因是覆盖层完整性无机械保证，必须进构建门禁」属于加分
