## RBL-578：笔试：手写 monorepo 任务拓扑排序与有界并行执行

**答**：实现 `runTasks(tasks, { concurrency })`。tasks: `{ id, deps: string[], run: async () => void }`。要求：依赖先完成；无依赖任务并行执行但全局并发 ≤ concurrency；出现环时 reject（错误信息含环路径如 `a -> b -> a`）；未知依赖 id reject；任一任务失败时不再调度新任务，但等在途任务结束后整体 reject（附首个错误）。`runTasks` 返回 Promise<void>。

```javascript
function runTasks(tasks, { concurrency = 4 } = {}) {
  const byId = new Map(tasks.map(t => [t.id, t]));
  const state = new Map();                       // id -> pending|running|done
  let failed = false, firstErr = null, active = 0, scheduledDone = false;
  const queue = [];

  return new Promise((resolve, reject) => {
    for (const t of tasks)
      for (const d of t.deps)
        if (!byId.has(d)) return reject(new Error(`未知依赖: ${d}`));

    // 环检测（DFS）
    const visit = (id, stack) => {
      if (stack.includes(id)) throw new Error('依赖环: ' + [...stack.slice(stack.indexOf(id)), id].join(' -> '));
      for (const d of byId.get(id).deps) visit(d, [...stack, id]);
    };
    try { tasks.forEach(t => visit(t.id, [])); } catch (e) { return reject(e); }

    const ready = t => !failed && t.deps.every(d => state.get(d) === 'done');
    const pump = () => {
      if (failed) return;
      for (const t of tasks) {
        if (state.get(t.id) || !ready(t)) continue;
        state.set(t.id, 'running'); active++;
        t.run().then(() => {
          state.set(t.id, 'done'); active--; pump();
          check();
        }, e => { failed = true; firstErr = firstErr ?? e; active--; check(); });
      }
      check();
    };
    const check = () => {
      const allDone = tasks.every(t => state.get(t.id) === 'done');
      if (allDone) return resolve();
      if (failed && active === 0) return reject(firstErr);
      // 死锁保护：无任务可调度但也没在跑且没全完成（理论被环检测挡住，防御性）
    };
    pump();
  });
}

// 自测
const log = [];
const mk = (id, deps, ms) => ({ id, deps, run: () => sleep(ms).then(() => log.push(id)) });
await runTasks([mk('b', ['a'], 10), mk('a', [], 20), mk('c', ['a', 'b'], 5), mk('d', [], 5)], { concurrency: 2 });
// 断言：log 顺序 c 在 a、b 之后；全程并发不超 2

// 环检测
let err;
try { await runTasks([{ id: 'a', deps: ['b'], run: async () => {} }, { id: 'b', deps: ['a'], run: async () => {} }]); }
catch (e) { err = e; }
// 断言：err.message 含 '依赖环'
```

**评分点**：
- 依赖就绪判断与并发上限正确（无依赖任务并行、总数受 bound 约束）
- 环检测给出可读环路径；未知依赖显式 reject
- 失败语义正确：停止新调度、等待在途任务、整体 reject 且不吞首个错误
- 拓扑保证性说明：每次调度前检查全部依赖 done，天然容忍乱序完成
