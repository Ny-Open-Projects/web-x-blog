## RBL-479：手写 Node 产物冷启动预编译
**需求**：实现 `precompileServerBundle(entries)`：1) v8 compile cache（Node 22 内建 module.enableCompileCache）或手动 vm.Script cachedData——解析/编译成本前移到构建期；2) 字节码缓存文件生成 + 加载校验（Node 版本/产物 hash 匹配才复用）；3) cold start 度量：首请求耗时对比（无缓存 vs 编译缓存——收益量化）；4) 快照进阶：v8 startup snapshot（更激进——对象图预建，适用性受限说明）；5) 与 worker 重启联动：worker 冷启动也享受缓存。

```javascript
import vm from 'node:vm'
import fs from 'node:fs'
import crypto from 'node:crypto'

export function precompileServerBundle(entries, { cacheDir = '.cache/v8' } = {}) {
  const results = []
  for (const entry of entries) {
    const code = fs.readFileSync(entry, 'utf8')
    const key = crypto.createHash('sha256')
      .update(code + process.version).digest('hex')              // Node 版本参与 key（字节码格式绑定版本）
    const cachePath = `${cacheDir}/${key}.bin`

    let cachedData = null
    try { cachedData = fs.readFileSync(cachePath) } catch {}

    const script = new vm.Script(code, { filename: entry, cachedData, produceCachedData: !cachedData })
    const hit = script.cachedData && !script.cachedDataRejected   // 校验：rejected = 缓存不匹配
    if (!hit && script.cachedData) fs.writeFileSync(cachePath, script.cachedData)

    results.push({ entry, cacheHit: hit,
      savedParseMs: hit ? estimateParseSaving(code.length) : 0 })
  }
  return { results, totalSavedMs: results.reduce((s, r) => s + r.savedParseMs, 0) }
}

function estimateParseSaving(bytes) {
  return Math.min(bytes / 1024 / 50, 300)                        // 经验：~50KB/ms 解析，上限 300ms
}

// 用法：build 时 precompile；server 启动时用 cachedData 加载（或 Node22 enableCompileCache 自动）
```
**评分点**：
- 缓存 key 绑定 Node 版本（字节码格式随版本变——不校验就是崩溃源）
- cachedDataRejected 校验（V8 自报不匹配——正确性防线）
- 冷启动收益量化（首请求对比/解析耗时估算——优化要可度量）
- snapshot 适用边界说明（对象图预建限制多——不盲目推荐）
