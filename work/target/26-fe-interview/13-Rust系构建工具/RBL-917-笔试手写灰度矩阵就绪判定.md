## RBL-917：笔试：手写灰度矩阵就绪判定（三层 ready + 原子回滚）

**答**：实现两部分。1) `canProceed(matrix)`：matrix: `Record<layer, { ready: boolean, strategy }>`。规则：全 ready → true；否则 throw（列出未就绪层）；2) `rollbackAll(layers, { rollback })`：layers: `Record<name, rollbackFn>`。规则：**顺序执行但失败聚合**——所有层的回滚都尝试执行（即使前面失败），返回 `{ rolled: string[], failed: Array<{ layer, error }> }`；全部成功 → ok。3) `grayState(matrix, traffic)`：返回当前灰度状态摘要 `{ ready: boolean, blocked: string[], canaryPct: traffic }`。边界：layers 空（ok）；rollbackFn 同步/异步混合。

```javascript
function canProceed(matrix) {
  const notReady = Object.entries(matrix).filter(([, l]) => !l.ready).map(([k]) => k);
  if (notReady.length)
    throw new Error(`灰度撕裂风险: ${notReady.join(', ')} 未就绪——前端新版将调用旧后端`);
  return true;
}

async function rollbackAll(layers, {}) {
  const rolled = [], failed = [];
  for (const [name, fn] of Object.entries(layers)) {    // 全尝试：不短路
    try { await fn(); rolled.push(name); }
    catch (e) { failed.push({ layer: name, error: e.message }); }
  }
  return { rolled, failed, ok: failed.length === 0 };
}

function grayState(matrix, traffic) {
  const blocked = Object.entries(matrix).filter(([, l]) => !l.ready).map(([k]) => k);
  return { ready: blocked.length === 0, blocked, canaryPct: traffic };
}

// 自测
const matrix = {
  frontend: { ready: true, strategy: 'userId-hash' },
  gateway: { ready: true, strategy: 'header-tag' },
  backend: { ready: false, strategy: 'instance-dye' },
};
let e; try { canProceed(matrix); } catch (x) { e = x; }
console.log(/撕裂/.test(e.message) && e.message.includes('backend'));
console.log(canProceed({ a: { ready: true } }) === true);

// 回滚：失败聚合（全尝试）
const log = [];
const layers = {
  frontend: async () => { log.push('fe'); },
  gateway: async () => { log.push('gw'); throw new Error('gw down'); },
  backend: () => { log.push('be'); },                   // 同步混合异步
};
let r = await rollbackAll(layers);
console.log(r.rolled.join(',') === 'frontend,backend');  // gateway 失败但 backend 仍执行
console.log(r.failed[0].layer === 'gateway' && r.ok === false);
console.log(log.join(',') === 'fe,gw,be');               // 三层都被尝试

console.log((await rollbackAll({}, {})).ok === true);

const s = grayState(matrix, 10);
console.log(s.ready === false && s.blocked.join(',') === 'backend' && s.canaryPct === 10);
```

**评分点**：
- 就绪判定抛错列层（撕裂风险显性化——单键一致原则的前置）；空 matrix 通过
- 回滚「失败聚合不短路」（单层失败不阻止其他层回滚——回滚必须尽力而为）；同步异步混合处理
- grayState 摘要可观测；边界
- 能说清「三层回滚必须原子编排，单层回滚 = 撕裂——状态空间坍缩到用户维度」属于加分
