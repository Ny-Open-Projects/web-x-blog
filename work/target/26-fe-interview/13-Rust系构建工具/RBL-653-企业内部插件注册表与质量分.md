## RBL-653：企业内部插件注册表：准入审计、质量分与替代链

**答**:
- 企业场景的插件治理比公网 npm 强一个量级：准入审计（代码安全审查 + 许可证 + 维护者绑定）、质量分（下载量之外的工程指标）、替代链（A 废弃时明确 B 接替 + 迁移说明）——注册表是「插件生态的治理中枢」，没有它每个团队都在重复踩坑。
- 质量分维度（可自动化）：1) 测试覆盖与 CI 状态；2) 核心版本矩阵通过率（RBL-652）；3) 文档完备性（README/示例/变更日志机器检查）；4) 发布健康度（最近发布时间、semver 违规次数）；5) 使用面（内部仓库接入数——使用面大的插件维护优先级高）。分数定期重算公开，替代选型有据。
- 准入流程：提交申请 → 静态扫描（依赖审计/许可证/恶意模式）→ 双人代码评审 → 纳入矩阵测试 → 发布到内部 registry。关键设计：**准入不是终点**——持续审计（月度重扫）+ 降级机制（质量分跌破阈值 → 标记「需评审」→ 构建器诊断提示）。
- 替代链的数据结构：`{ name, status: active|deprecated, replacedBy, migration }`——废弃插件诊断引用此表（RBL-551/568 诊断体系）；迁移说明要给 codemod 或配置 diff，不能只给「用 B」。
- 追问钩子：为什么「使用面」是质量分里最重的权重？——使用面大的插件出问题影响面大，维护投入优先；同时使用面数据来自真实接入（注册表 API 统计），比「星标」这类社会信号更可靠。

```javascript
// 注册表数据模型与质量分
const registry = {
  plugins: {
    'rolldown-plugin-svg': {
      status: 'active', replacedBy: null, migration: null,
      scores: { tests: 0.9, matrix: 1.0, docs: 0.7, release: 0.8, usage: 0.95 },
      weights: { tests: 0.3, matrix: 0.25, docs: 0.15, release: 0.1, usage: 0.2 },
      auditedAt: '2026-11-01',
    },
    'old-css-plugin': {
      status: 'deprecated', replacedBy: 'rolldown-plugin-css-next',
      migration: '配置字段 map: { prefix } -> options: { prefix }，提供 codemod npx @internal/migrate-css',
    },
  },
  score(p) {
    const { scores, weights } = this.plugins[p];
    return Object.entries(weights).reduce((s, [k, w]) => s + w * scores[k], 0).toFixed(2);
  },
};
console.log(registry.score('rolldown-plugin-svg'));      // 0.89

// 构建时诊断
function auditPlugins(plugins) {
  return plugins.flatMap(p => {
    const meta = registry.plugins[p];
    if (!meta) return [{ level: 'warn', msg: `${p} 未注册（内部插件应走准入流程）` }];
    if (meta.status === 'deprecated')
      return [{ level: 'error', msg: `${p} 已废弃 -> ${meta.replacedBy}；迁移：${meta.migration}` }];
    if (+registry.score(p) < 0.6)
      return [{ level: 'warn', msg: `${p} 质量分过低，升级前需评审` }];
    return [];
  });
}
```
