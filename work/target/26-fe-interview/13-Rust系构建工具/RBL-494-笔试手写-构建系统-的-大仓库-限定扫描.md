## RBL-494：手写大仓库限定扫描
**需求**：实现 `scopedScan(root, { entries, maxDepth })`：1) 从入口出发的可达性扫描（不是全仓遍历——10 万文件全扫是分钟级）；2) 依赖驱动的范围：入口文件 → import 解析 → 递归（只触达真实依赖）；3) glob 声明扩展（**/*.stories.ts 这类约定文件——glob 展开后加入扫描集）；4) 边界收窄验证：可达集应 ⊆ 声明集（构建出的模块都在 tsconfig include 内——不一致告警）；5) 扫描统计（触达文件数/跳过文件数——扫描面可见）。

```javascript
export async function scopedScan(root, { entries, globs = [], resolve, readFile, tsInclude }) {
  const visited = new Set()
  const queue = []
  const stats = { touched: 0, skipped: 0 }

  function addGlobFiles() {
    // 约定文件：glob 展开后加入（如 stories/config）
    for (const pattern of globs) {
      for (const f of expandGlob(path.join(root, pattern))) queue.push(f)
    }
  }

  for (const e of entries) {
    const id = resolve(null, e)
    if (id) queue.push(id)
  }
  addGlobFiles()

  while (queue.length) {
    const id = queue.pop()
    if (visited.has(id)) continue
    visited.add(id); stats.touched++
    const content = readFile(id)
    for (const spec of extractImports(content)) {
      const dep = resolve(id, spec)
      if (dep) queue.push(dep); else stats.skipped++
    }
  }

  // 边界一致性：可达集 ⊆ tsconfig include
  const outside = [...visited].filter((f) => !tsInclude.some((p) => f.startsWith(p)))
  if (outside.length) console.warn(`扫描触达 include 外文件: ${outside.slice(0, 3)}（tsconfig include 与实际依赖不一致）`)

  return { modules: [...visited], stats, outside }
}
```
**评分点**：
- 依赖驱动扫描（从入口可达——不是全仓遍历，规模化的根本）
- glob 声明扩展（约定文件不靠 import 链——显式加入）
- 边界一致性校验（可达集 vs tsconfig include——两边不一致即配置漂移）
- 扫描统计（触达/跳过可见——扫描面可审计）
