## RBL-664：笔试：手写构建器迁移评估评分器（收益成本模型 + 优先级排序）

**答**：实现 `rankRepos(repos, { weights })`。repo: `{ name, buildSeconds, customPlugins, customLoaders, configHacks, ciRunsPerDay, devEditsPerDay }`。模型：1) benefit = 加权使用频率 × 构建时长收益：`(ciRunsPerDay × 1 + devEditsPerDay × 0.2) × buildSeconds / 60`；2) cost = `customPlugins × 3 + customLoaders × 2 + configHacks × 4`；3) net = benefit − cost；4) 返回按 net 降序数组 `{ name, benefit(1位小数), cost, net, verdict }`；verdict：net > 20 'migrate-first'、> 0 'migrate-later'、≤ 0 'stay'。5) 全部 stay 时给出 `totalNet` 与 `reason: 'no-economical-target'`。边界：空列表；负值入参按 0 处理。

```javascript
function rankRepos(repos, { weights } = {}) {
  const w = { ci: 1, dev: 0.2, ...(weights || {}) };
  const clamp0 = (n) => Math.max(0, n || 0);
  const scored = repos.map(r => {
    const buildMin = clamp0(r.buildSeconds) / 60;
    const freq = clamp0(r.ciRunsPerDay) * w.ci + clamp0(r.devEditsPerDay) * w.dev;
    const benefit = +(freq * buildMin).toFixed(1);
    const cost = clamp0(r.customPlugins) * 3 + clamp0(r.customLoaders) * 2 + clamp0(r.configHacks) * 4;
    const net = +(benefit - cost).toFixed(1);
    return { name: r.name, benefit, cost, net,
      verdict: net > 20 ? 'migrate-first' : net > 0 ? 'migrate-later' : 'stay' };
  });
  scored.sort((a, b) => b.net - a.net);
  if (repos.length === 0) return { list: [], totalNet: 0, reason: 'no-economical-target' };
  const totalNet = +scored.reduce((s, x) => s + x.net, 0).toFixed(1);
  return { list: scored, totalNet,
    reason: scored.every(x => x.verdict === 'stay') ? 'no-economical-target' : 'ok' };
}

// 自测
const repos = [
  { name: 'big-app', buildSeconds: 600, customPlugins: 1, customLoaders: 1, configHacks: 0,
    ciRunsPerDay: 50, devEditsPerDay: 200 },
  { name: 'hacked-legacy', buildSeconds: 900, customPlugins: 8, customLoaders: 4, configHacks: 6,
    ciRunsPerDay: 10, devEditsPerDay: 20 },
  { name: 'small-app', buildSeconds: 40, customPlugins: 0, customLoaders: 0, configHacks: 0,
    ciRunsPerDay: 20, devEditsPerDay: 100 },
];
const r = rankRepos(repos);
console.log(r.reason === 'ok');
console.log(r.list.map(x => x.name).join(','));          // big-app,small-app?,hacked-legacy（按 net 降序）
console.log(r.list[0].name === 'big-app' && r.list[0].verdict === 'migrate-first');
console.log(r.list.find(x => x.name === 'hacked-legacy').verdict === 'stay');
console.log(r.list.find(x => x.name === 'small-app').verdict !== 'migrate-first');

// 全 stay
const r2 = rankRepos([repos[1]]);
console.log(r2.reason === 'no-economical-target');

// 负值防御
const r3 = rankRepos([{ name: 'x', buildSeconds: -5, customPlugins: -1, ciRunsPerDay: -2, devEditsPerDay: -1 }]);
console.log(r3.list[0].net === 0 || r3.list[0].benefit === 0);
console.log(rankRepos([]).list.length === 0);
```

**评分点**：
- 频率加权模型正确（CI 权重高于 dev 编辑——CI 等待更贵）；负值防御（clamp 0）
- cost 公式覆盖三类成本且权重递增（configHack 最贵——最难迁移）
- 降序排序与三档 verdict 正确；全 stay 汇总 reason
- 能说清「迁移是投资决策，评分卡让排序可讨论可复审」属于加分
