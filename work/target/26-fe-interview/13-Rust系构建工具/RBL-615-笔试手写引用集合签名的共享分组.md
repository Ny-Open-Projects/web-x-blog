## RBL-615：笔试：手写引用集合签名的共享分组与收益过滤

**答**：实现 `groupShared(entries, modules, opts)`。entries: `{ id, closure: string[] }[]`；modules: `Map<id, { size }>`（KB）。opts: `{ minShared, minSize, overheadKB }`。返回 `{ shared: Array<{ sig, modules, savedKB }>, inlined: string[] }`：1) 计算每模块被哪些 entry 引用（closure 去重）；2) 引用数 ≥ minShared 且 size ≥ minSize 的模块按「引用集合签名」（entry id 排序后 join('+')）分组；3) 每组计算 savedKB = Σ size × (refs - 1)；savedKB > overheadKB 的组进 shared，否则组内模块全部进 inlined；4) 单 entry 引用的模块不参与（既不 shared 也不 inlined，留在 entry 自身）。边界：无共享模块；全部过小。

```javascript
function groupShared(entries, modules, opts) {
  const { minShared = 2, minSize = 0, overheadKB = 0 } = opts ?? {};
  const refs = new Map();                                // module -> Set(entryId)
  for (const e of entries) {
    const seen = new Set(e.closure);                     // 闭包去重
    for (const m of seen) {
      if (!refs.has(m)) refs.set(m, new Set());
      refs.get(m).add(e.id);
    }
  }
  const groups = new Map();                              // sig -> { modules, savedKB }
  const inlined = [];
  for (const [m, set] of refs) {
    if (set.size < minShared) continue;                  // 单引用：留 entry
    const size = modules.get(m)?.size ?? 0;
    if (size < minSize) { inlined.push(m); continue; }   // 过小：内联
    const sig = [...set].sort().join('+');
    if (!groups.has(sig)) groups.set(sig, { modules: [], savedKB: 0 });
    const g = groups.get(sig);
    g.modules.push(m);
    g.savedKB += size * (set.size - 1);                  // 每个额外引用省一份
  }
  const shared = [];
  for (const [sig, g] of groups) {
    if (g.savedKB > overheadKB) shared.push({ sig, ...g, savedKB: +g.savedKB.toFixed(2) });
    else inlined.push(...g.modules);                     // 收益不足：复制
  }
  return { shared, inlined: [...new Set(inlined)].sort() };
}

// 自测
const modules = new Map([
  ['lodash', { size: 70 }], ['react', { size: 130 }], ['ui-btn', { size: 8 }],
  ['utils', { size: 40 }], ['pageX', { size: 20 }], ['pageY', { size: 20 }],
]);
const entries = [
  { id: 'home', closure: ['lodash', 'react', 'ui-btn', 'pageX'] },
  { id: 'shop', closure: ['lodash', 'react', 'ui-btn', 'utils', 'pageY'] },
  { id: 'admin', closure: ['react', 'utils'] },
];
const r = groupShared(entries, modules, { minShared: 2, minSize: 10, overheadKB: 10 });
// 断言：
// shared 含 sig 'home+shop'（lodash 70+react 130+ui-btn 8——ui-btn size 8 < minSize 10 -> inlined）
// 实际：home+shop 组 = [lodash, react]，saved = 70*1 + 130*1 = 200 > 10 -> shared
// 'home+shop+admin' 组 = [react]？不对——react 被三个引用：sig 'admin+home+shop' 单独一组
// utils: sig 'admin+shop'，saved 40 > 10 -> shared
// ui-btn: size 8 < 10 -> inlined
console.log(r.shared.map(s => s.sig).sort());
// ['admin+home+shop', 'admin+shop', 'home+shop']
console.log(r.shared.find(s => s.sig === 'admin+home+shop').savedKB === 260);
console.log(r.inlined.includes('ui-btn') && !r.inlined.includes('lodash'));
```

**评分点**：
- 引用集合签名分组正确（entry 排序保证签名稳定；不同集合不同组，缓存友好）
- savedKB 公式正确：size × (refs - 1)，即每个额外入口省掉的重复字节
- 双重过滤链正确：size < minSize 直接内联（不进分组）；分组后 savedKB ≤ overhead 整组转内联
- 边界：单 entry 引用模块不进任何结果集；无共享返回空 shared
