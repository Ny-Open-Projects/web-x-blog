## RBL-843：笔试：手写迁移撤回条件检查器（kill criteria）

**答**：实现 `killCheck(m)`。m: `{ semanticFixedRate, blockingPlugins: Array<{ name, alternative?: boolean, customCost?: number }>, baseline: { speedup }, knowledgeDocumented, threshold?: { semantic?: number, speedup?: number, pluginCostCap?: number } }`。默认阈值：semantic ≥ 0.9、speedup ≥ 2、插件自定义成本 < 收益（以 speedup × 100 折算）。规则：1) 四项任一不过 → `{ action: 'freeze', reasons }`（reasons 用中文信号描述）；2) 全过 → `{ action: 'continue' }`；3) 撤回建议附 salvage 清单（可复用资产保留项）。边界：blockingPlugins 空（通过）；阈值覆盖生效。

```javascript
function killCheck(m) {
  const t = { semantic: 0.9, speedup: 2, ...(m.threshold ?? {}) };
  const reasons = [];
  if ((m.semanticFixedRate ?? 0) < t.semantic)
    reasons.push(`语义差异修复率 ${(m.semanticFixedRate ?? 0).toFixed(2)} < ${t.semantic}`);
  for (const p of m.blockingPlugins ?? [])
    if (!p.alternative && (p.customCost ?? Infinity) >= t.speedup * 100)
      reasons.push(`插件 ${p.name} 无替代且自研成本超收益`);
  if ((m.baseline?.speedup ?? 0) < t.speedup)
    reasons.push(`基准提速 ${m.baseline?.speedup ?? 0} 倍 < ${t.speedup} 倍——前提失效`);
  if (!m.knowledgeDocumented) reasons.push('关键知识未沉淀——人员风险');

  return reasons.length
    ? { action: 'freeze', reasons,
        salvage: ['检查器/测试基建保留', '复盘文档记录撤回原因'] }
    : { action: 'continue' };
}

// 自测
let r = killCheck({ semanticFixedRate: 0.95, blockingPlugins: [
  { name: 'css', alternative: true }], baseline: { speedup: 2.5 }, knowledgeDocumented: true });
console.log(r.action === 'continue');

r = killCheck({ semanticFixedRate: 0.7, blockingPlugins: [], baseline: { speedup: 3 }, knowledgeDocumented: true });
console.log(r.reasons[0].includes('0.70') && r.action === 'freeze');

r = killCheck({ semanticFixedRate: 0.95, blockingPlugins: [
  { name: 'heavy', customCost: 300 }], baseline: { speedup: 2 }, knowledgeDocumented: true });
console.log(r.reasons.some(x => x.includes('heavy')));   // 300 ≥ 200

r = killCheck({ semanticFixedRate: 0.95, blockingPlugins: [], baseline: { speedup: 1.5 }, knowledgeDocumented: true });
console.log(r.reasons[0].includes('1.5'));

r = killCheck({ semanticFixedRate: 1, blockingPlugins: [], baseline: { speedup: 3 }, knowledgeDocumented: false });
console.log(r.reasons[0].includes('知识'));

// 自定义阈值
r = killCheck({ semanticFixedRate: 0.8, blockingPlugins: [], baseline: { speedup: 3 }, knowledgeDocumented: true },
  { threshold: { semantic: 0.7 } });
console.log(r.action === 'continue');

r = killCheck({ semanticFixedRate: 1, blockingPlugins: [], baseline: { speedup: 4 }, knowledgeDocumented: true });
console.log(r.action === 'continue' && r.salvage === undefined);
```

**评分点**：
- 四项 kill criteria 全覆盖（语义可达/生态/收益证明/团队风险）；默认阈值与覆盖
- reasons 用业务语言（可给决策者看）；freeze 附 salvage 清单（撤回不清零）
- 边界：空插件列表通过、阈值覆盖生效
- 能说清「kill criteria 在评估期预设并签字，检查点越早证伪越便宜」属于加分
