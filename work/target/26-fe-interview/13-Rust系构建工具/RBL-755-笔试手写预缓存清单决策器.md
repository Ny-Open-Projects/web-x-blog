## RBL-755：笔试：手写 PWA 预缓存清单决策器（预算贪心 + RUM 提升）

**答**：实现 `precachePlan(resources, { budgetKB, rum })`。resources: `{ url, sizeKB, role: 'entry'|'chunk'|'asset', inEntryClosure: boolean }[]`；rum: `Record<url, usage>`（0~1 会话使用率）。规则：1) 首屏闭包资源按 size 升序贪心入清单（预算内）；2) 闭包外但 rum.usage ≥ 0.5 的资源作为提升候选——**提升优先于剩余闭包资源**（先处理提升项再回填闭包）；3) asset 角色默认不入（字体/图片走运行时缓存），除非在闭包内或被提升；4) 返回 `{ urls: string[], usedKB, skipped: string[] }`——skipped 是因预算落选的闭包资源。边界：空资源；budgetKB 0。

```javascript
function precachePlan(resources, { budgetKB = 500, rum = {} } = {}) {
  const isAsset = (r) => r.role === 'asset';
  const eligible = resources.filter(r => !isAsset(r) || r.inEntryClosure || (rum[r.url] ?? 0) >= 0.5);
  const promoted = eligible.filter(r => isAsset(r) || (!r.inEntryClosure && (rum[r.url] ?? 0) >= 0.5));
  const closure = eligible.filter(r => !promoted.includes(r) && r.inEntryClosure && !isAsset(r));

  const chosen = new Map();                              // url -> resource
  let used = 0;
  const tryAdd = (r) => {
    if (chosen.has(r.url) || used + r.sizeKB > budgetKB) return false;
    chosen.set(r.url, r); used += r.sizeKB;
    return true;
  };
  // 提升优先（按使用率降序）
  [...promoted].sort((a, b) => (rum[b.url] ?? 0) - (rum[a.url] ?? 0)).forEach(tryAdd);
  // 闭包按 size 升序回填
  const skipped = [];
  [...closure].sort((a, b) => a.sizeKB - b.sizeKB).forEach(r => {
    if (!tryAdd(r)) skipped.push(r.url);
  });
  return { urls: [...chosen.keys()].sort(), usedKB: used, skipped };
}

// 自测
const resources = [
  { url: '/entry.js', sizeKB: 100, role: 'entry', inEntryClosure: true },
  { url: '/vendor.js', sizeKB: 200, role: 'chunk', inEntryClosure: true },
  { url: '/hero.png', sizeKB: 80, role: 'asset', inEntryClosure: false, },        // 高频提升
  { url: '/ad.png', sizeKB: 50, role: 'asset', inEntryClosure: false },           // 低频不入
  { url: '/lazy.js', sizeKB: 300, role: 'chunk', inEntryClosure: true },
];
const rum = { '/hero.png': 0.8, '/ad.png': 0.1 };
let r = precachePlan(resources, { budgetKB: 500, rum });
console.log(r.urls.join(','));                          // entry,vendor,hero（lazy 300 超预算 skipped）
console.log(r.usedKB === 380);
console.log(r.skipped.join(',') === '/lazy.js');

r = precachePlan(resources, { budgetKB: 100, rum });
console.log(r.urls.join(',') === '/entry.js');          // 只有 entry 进

console.log(precachePlan([], { budgetKB: 100 }).urls.length === 0);
console.log(precachePlan(resources, { budgetKB: 0, rum }).urls.length === 0);
```

**评分点**：
- 提升优先于闭包回填的顺序正确（先高频 asset 后闭包贪心）；asset 仅在闭包内或被提升时入选
- 预算贪心语义正确（size 升序最大化资源数；超预算进 skipped 而非中断）
- rum 阈值 0.5 与低频 asset 排除；空预算/空资源安全
- 能说清「更新下载量是预缓存策略的优化目标，闭包预算控制 SW 安装时长」属于加分
