## RBL-542：手写产物体积分析器（重复检测 + 可达性 + 行动项）
**答**：541 落地——实现 `analyzeBundle(chunks, modules)`：1) 重复检测：同模块出现在多 chunk（非 shared 设计）或多版本同包；2) 可达性：入口不可达模块清单（为什么在产物里）；3) 行动项：按「节省 gzip KB / 难度」排序输出 Top3；4) 附用例：重复与不可达的检出。

```javascript
function analyzeBundle(chunks, modules, { entry } = {}) {
  // chunks: [{ id, modules: [moduleId], gzipBytes }]
  // modules: Map<moduleId, { pkg, gzipBytes, reachable? }>
  const actions = []

  // 1) 重复检测：模块多 chunk
  const moduleChunks = new Map()
  for (const c of chunks) for (const m of c.modules) {
    (moduleChunks.get(m) ?? moduleChunks.set(m, []).get(m)).push(c.id)
  }
  for (const [m, cs] of moduleChunks) {
    if (cs.length > 1) {
      const size = modules.get(m)?.gzipBytes ?? 0
      actions.push({ type: 'duplicate-module', module: m, chunks: cs, saveKB: +(size * (cs.length - 1) / 1024).toFixed(1), difficulty: '低（shared chunk 提取）' })
    }
  }
  // 多版本同包
  const pkgVersions = new Map()
  for (const [id, m] of modules) {
    (pkgVersions.get(m.pkg) ?? pkgVersions.set(m.pkg, new Set()).get(m.pkg)).add(id)
  }
  for (const [pkg, ids] of pkgVersions) {
    if (ids.size > 1) {
      actions.push({ type: 'duplicate-version', pkg, versions: [...ids], difficulty: '中（版本收敛）' })
    }
  }

  // 2) 可达性：入口闭包外的模块
  const closure = new Set()
  const stack = [entry]
  const depGraph = new Map([...modules].map(([id, m]) => [id, m.imports ?? []]))
  while (stack.length) {
    const m = stack.pop()
    if (closure.has(m)) continue
    closure.add(m)
    for (const d of depGraph.get(m) ?? []) stack.push(d)
  }
  for (const [id, m] of modules) {
    if (!closure.has(id) && (m.reachable === undefined)) {
      actions.push({ type: 'unreachable', module: id, saveKB: +(m.gzipBytes / 1024).toFixed(1), difficulty: '中（查引用来源）' })
    }
  }

  // 3) 行动项排序：节省 KB 降序
  actions.sort((a, b) => (b.saveKB ?? 0) - (a.saveKB ?? 0))
  return { actions, top3: actions.slice(0, 3) }
}

// 用例
const modules = new Map([
  ['lodash4', { pkg: 'lodash', gzipBytes: 24 * 1024, imports: [] }],
  ['lodash3', { pkg: 'lodash', gzipBytes: 24 * 1024, imports: [] }],
  ['heavy-widget', { pkg: 'widget', gzipBytes: 50 * 1024, imports: [] }],   // 入口不可达
  ['app-core', { pkg: 'app', gzipBytes: 2 * 1024, imports: ['lodash4'] }],
])
const chunks = [
  { id: 'home', modules: ['app-core', 'lodash4', 'heavy-widget'], gzipBytes: 76 * 1024 },
  { id: 'about', modules: ['lodash4', 'lodash3'], gzipBytes: 48 * 1024 },
]
const r = analyzeBundle(chunks, modules, { entry: 'app-core' })
console.log(r.top3.map((a) => `${a.type}:${a.saveKB ?? '-'}KB`))
// ['unreachable:50.0KB', 'duplicate-module:24.0KB', 'duplicate-version:-']
console.log(r.actions[0].type === 'unreachable')   // 最大节省优先
```
**评分点**：
- 模块多 chunk 重复检测（节省 = size×(n-1)）
- 多版本同包检测（版本收敛）
- 可达性分析（入口闭包外模块——「为什么在产物里」）
- 行动项按节省 KB 降序（可执行优先）
