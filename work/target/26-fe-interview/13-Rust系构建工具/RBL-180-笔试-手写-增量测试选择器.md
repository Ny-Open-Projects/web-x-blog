## RBL-180：笔试：手写增量测试选择器（git diff → 相关测试集）

**答**：写 pick-tests.mjs：1) 用 git diff --name-only HEAD~1 取变更文件（或传入 base）；2) 对每个变更的源文件 src/x/y.ts 找对应测试（规则：src 下同名 *.test.ts、同目录 __tests__/、或 e2e 前缀映射）；3) 无直接测试的变更文件输出到 `--untested` 清单（CI 可配置是否失败）；4) 合并所有测试路径 + 全局配置变更（jest.config/vitest.config、lockfile）触发全量；5) 输出"全量 or 增量"决策与测试文件列表。

```javascript
// pick-tests.mjs
import { execSync } from 'node:child_process';

const GLOBAL_PATTERNS = [/(jest|vitest)\.config\./, /package\.json$/, /pnpm-lock\.yaml$/];

function changedFiles(base = 'HEAD~1') {
  const out = execSync(`git diff --name-only ${base}...HEAD`, { encoding: 'utf8' });
  return out.split('\n').filter(Boolean);
}
function relatedTests(srcFile) {
  const cands = [];
  if (/\.(ts|tsx|js|jsx)$/.test(srcFile)) {
    const noExt = srcFile.replace(/\.(ts|tsx|js|jsx)$/, '');
    cands.push(`${noExt}.test.ts`, `${noExt}.test.tsx`, `${noExt}.spec.ts`);
    const parts = noExt.split('/');
    const dir = parts.slice(0, -1).join('/'), base = parts.at(-1);
    cands.push(`${dir}/__tests__/${base}.test.ts`, `${dir}/__tests__/${base}.tsx`);
  }
  try {
    return cands.filter(c => existsSync(c));
  } catch { return []; }
}
function existsSync(p) { try { require('node:fs').accessSync(p); return true; } catch { return false; } }

const base = process.argv[2] ?? 'HEAD~1';
const files = changedFiles(base);
if (files.some(f => GLOBAL_PATTERNS.some(g => g.test(f)))) {
  console.log('MODE=full'); process.exit(0);          // 全局输入变更 → 全量测试
}
const tests = new Set(), untested = [];
for (const f of files) {
  if (/\.test\.|\.spec\.|__tests__|\/e2e\//.test(f)) { tests.add(f); continue; }
  const rel = relatedTests(f);
  if (rel.length) rel.forEach(t => tests.add(t));
  else if (!f.startsWith('docs/')) untested.push(f);   // 文档变更不算缺口
}
console.log(`MODE=incremental\ntests=${[...tests].join(',')}\nuntested=${untested.join(',')}`);
// CI 门禁：STRICT=1 且 untested 非空时 fail，逼着补测试映射。
```
**评分点**：
- 全局配置/lockfile 变更升级为全量（不能只跑增量）。
- 测试映射规则多路匹配且容错（无测试文件不炸）。
- untested 缺口清单 + 可配置严格门禁。
- 自身变更的测试文件直接入选。
- docs 等非代码路径豁免。
