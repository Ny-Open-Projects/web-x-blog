## RBL-927：笔试：手写分层缓存键生成器（作用域 + 冲突）

**答**：实现两部分。1) `cacheKey(stage, ctx)`：ctx: `{ sourceHash, target, pkgResolveHash?, pkgSetHash? }`. 三级键：transform = hash(sourceHash|target)；resolve = transform + hash(pkgResolveHash)；chunk = resolve + hash(pkgSetHash)。缺失的上下文字段 → 抛错（键不完备防护）；未知 stage 抛错。2) `detectCollision(cache)`：cache 注入 `{ sample(n) -> Array<{ key, cached, recomputed }> }`——cached 与 recomputed 不等的条目 → collisions；有冲突 → 抛错。返回 `{ collisions }`。边界：ctx 缺 pkgResolveHash 但 stage=resolve 抛错；sample 空。

```javascript
const sha256 = (s) => { let h = 0; for (const c of s) h = (h * 31 + c.charCodeAt(0)) | 0;
  return Math.abs(h).toString(16).padStart(8, '0'); };

function cacheKey(stage, ctx = {}) {
  const need = { transform: [], resolve: ['pkgResolveHash'], chunk: ['pkgResolveHash', 'pkgSetHash'] };
  if (!(stage in need)) throw new Error(`未知阶段: ${stage}`);
  for (const f of need[stage])
    if (ctx[f] === undefined) throw new Error(`键不完备: stage=${stage} 缺 ${f}`);
  const t = sha256(`${ctx.sourceHash}|${ctx.target}`);
  if (stage === 'transform') return `transform:${t}`;
  const r = sha256(`${t}|${ctx.pkgResolveHash}`);
  if (stage === 'resolve') return `resolve:${r}`;
  return `chunk:${sha256(`${r}|${ctx.pkgSetHash}`)}`;
}

function detectCollision(cache) {
  const sampled = cache.sample?.() ?? [];
  const collisions = sampled.filter(s => s.cached !== s.recomputed);
  if (collisions.length)
    throw new Error(`缓存键冲突: ${collisions.length}/${sampled.length}——键不完备`);
  return { collisions: [] };
}

// 自测
const ctx = { sourceHash: 's1', target: 'es2019', pkgResolveHash: 'r1', pkgSetHash: 'p1' };
const k1 = cacheKey('transform', ctx);
const k2 = cacheKey('resolve', ctx);
const k3 = cacheKey('chunk', ctx);
console.log(k1.startsWith('transform:') && k2.startsWith('resolve:') && k3.startsWith('chunk:'));
console.log(k1 !== k2 && k2 !== k3);

// 上下文相同 → 键稳定
console.log(cacheKey('resolve', ctx) === cacheKey('resolve', { ...ctx }));

// 缺字段抛错
let e; try { cacheKey('chunk', { sourceHash: 's', target: 't' }); } catch (x) { e = x; }
console.log(/键不完备.*pkgResolveHash/.test(e.message));
e = null; try { cacheKey('unknown', ctx); } catch (x) { e = x; }
console.log(/未知阶段/.test(e.message));

// 冲突检测
let r = detectCollision({ sample: () => [
  { key: 'a', cached: 'x', recomputed: 'x' }, { key: 'b', cached: 'y', recomputed: 'z' }] });
console.log(r.collisions.length === 0);
e = null; try { detectCollision({ sample: () => [{ key: 'a', cached: 'x', recomputed: 'different' }] }); }
catch (x) { e = x; }
console.log(/键冲突/.test(e.message));
```

**评分点**：
- 三级键层级正确（逐级叠加上下文 hash）；缺字段防护（键不完备即抛错——防语义污染前置）
- 键稳定性（同 ctx 同键）；未知 stage 抛错
- 冲突检测语义（cached ≠ recomputed = 键不完备信号）；空 sample 安全
- 能说清「共享域由函数输入闭包决定：transform 纯函数全局共享、resolve 上下文敏感包内共享」属于加分
