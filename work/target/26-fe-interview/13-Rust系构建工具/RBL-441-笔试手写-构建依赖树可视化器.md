## RBL-441：手写依赖树可视化器
**答**：实现 `renderDepTree(root, graph)`：1) graph：Map<pkg, { deps: string[], version }>；2) 文本树输出（├─/└─ 缩进结构）；3) 循环引用标记 `(*)`（已渲染过的节点标星防无限递归）；4) 重复子树折叠：同节点第二次出现只显示引用不展开（npm ls 语义）；5) 版本冲突行高亮（同包不同版本在树中出现）；6) 输出 { text, cycles: [][] }。

```javascript
export function renderDepTree(root, graph) {
  const lines = []
  const cycles = []
  const rendered = new Set()                       // 全局已展开节点（折叠重复子树）

  function walk(pkg, prefix, isLast, path, version) {
    const meta = graph.get(pkg)
    const v = meta?.version ?? '?'
    const conflict = meta?.conflict ? ' ⚠️' : ''
    const connector = prefix ? (isLast ? '└─ ' : '├─ ') : ''
    if (path.includes(pkg)) {
      lines.push(`${prefix}${connector}${pkg}@${v} (*)`)       // 循环标记
      cycles.push([...path.slice(path.indexOf(pkg)), pkg])
      return
    }
    if (rendered.has(pkg) && path.length > 1) {
      lines.push(`${prefix}${connector}${pkg}@${v} (deduped)`) // 重复子树折叠
      return
    }
    lines.push(`${prefix}${connector}${pkg}@${v}${conflict}`)
    rendered.add(pkg)
    const deps = meta?.deps ?? []
    deps.forEach((d, i) => {
      walk(d, prefix ? `${prefix}${isLast ? '   ' : '│  '}` : '', i === deps.length - 1, [...path, pkg], v)
    })
  }

  walk(root, '', true, [], null)
  return { text: lines.join('\n'), cycles }
}

// 输出示例：
// app@1.0.0
// ├─ react@18.3.1
// │  └─ scheduler@0.23.0
// └─ lodash@4.17.21 (deduped)     ← 已在别处展开
```
**评分点**：
- 树形字符绘制正确（├─/└─/│ 前缀继承）
- 循环标记 (*)（访问路径检测——path.includes 而非全局 visited，全局 visited 会误标非循环重复）
- dedup 折叠语义（npm ls 行为——重复子树只引不展）
- 版本冲突行标记
