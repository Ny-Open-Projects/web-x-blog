## RBL-706：笔试：手写灰度放量门禁（多指标 guard + 持续天数确认）

**答**：实现 `shouldPromote(samples, baselines, rules)`。samples: 按天分组的指标 `Record<day, Record<metric, number>>`（至少需要连续 requiredDays 天数据）；baselines: `Record<metric, number>`；rules: `Record<metric, (cur, base) => boolean>`（true = 通过）。规则：1) 每个指标需**连续 requiredDays 天**都通过（中间一天失败即该指标 fail）；2) 日期序列按升序判断连续（无日期空洞——按排序后相邻差 1 天）；3) 任一指标 fail → 不放量，返回 broken 列表；4) 数据不足 requiredDays → fail 'insufficient-data'；5) 未知指标（rules 有但 samples 没有）→ fail 'missing-metric'。返回 `{ promote, broken: Array<{ metric, reason }> }`。

```javascript
const DAY = 86400000;

function shouldPromote(samples, baselines, rules, { requiredDays = 3 } = {}) {
  const days = Object.keys(samples).sort();
  if (days.length < requiredDays)
    return { promote: false, broken: [{ metric: '*', reason: 'insufficient-data' }] };

  // 连续性：相邻日期差 1 天（取最近 requiredDays 天）
  const streak = days.slice(-requiredDays);
  const isContiguous = streak.every((d, i) =>
    i === 0 || new Date(d) - new Date(streak[i - 1]) === DAY);
  if (!isContiguous)
    return { promote: false, broken: [{ metric: '*', reason: 'non-contiguous-days' }] };

  const broken = [];
  for (const metric of Object.keys(rules)) {
    let ok = true, reason = null;
    if (!(metric in samples[streak[0]])) { broken.push({ metric, reason: 'missing-metric' }); continue; }
    for (const d of streak) {
      const v = samples[d][metric];
      if (v === undefined) { ok = false; reason = 'missing-metric'; break; }
      if (!rules[metric](v, baselines[metric])) { ok = false; reason = `day ${d} 未达标`; break; }
    }
    if (!ok) broken.push({ metric, reason });
  }
  return { promote: broken.length === 0, broken };
}

// 自测
const rules = {
  successRate: (v, b) => v >= b - 0.003,
  buildP95: (v, b) => v <= b * 1.1,
};
const baselines = { successRate: 0.995, buildP95: 5000 };

// 1) 连续 3 天全过 -> promote
const ok3 = {
  '2026-11-19': { successRate: 0.996, buildP95: 5000 },
  '2026-11-20': { successRate: 0.994, buildP95: 5100 },
  '2026-11-21': { successRate: 0.997, buildP95: 4950 },
};
console.log(shouldPromote(ok3, baselines, rules).promote === true);

// 2) 中间一天失败
const bad = { ...ok3, '2026-11-20': { successRate: 0.98, buildP95: 5000 } };
let r = shouldPromote(bad, baselines, rules);
console.log(r.promote === false && r.broken[0].metric === 'successRate');

// 3) 日期不连续
const gap = { '2026-11-19': ok3['2026-11-19'], '2026-11-20': ok3['2026-11-20'],
              '2026-11-22': ok3['2026-11-21'] };
r = shouldPromote(gap, baselines, rules);
console.log(r.broken[0].reason === 'non-contiguous-days');

// 4) 数据不足
r = shouldPromote({ '2026-11-19': ok3['2026-11-19'] }, baselines, rules);
console.log(r.broken[0].reason === 'insufficient-data');

// 5) 未知指标
r = shouldPromote(ok3, baselines, { ...rules, peakMem: () => true });
console.log(r.broken[0].metric === 'peakMem' && r.broken[0].reason === 'missing-metric');
```

**评分点**：
- 连续天数语义正确（取最近 requiredDays 天且相邻差恰为 1 天，空洞即失败）
- 指标级短路（一天失败即记录），unknown metric 显式报告
- promote = broken 为空；不足数据独立报告
- 能说清「连续性是防『挑好日子放全量』的纪律」属于加分
