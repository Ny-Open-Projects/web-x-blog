## RBL-662：笔试：手写产物体积预算门禁（双轨阈值 + 豁免机制）

**答**：实现 `checkBudgets(output, budgets, baseline, exemptions)`。output: `Map<entry, sizeKB>`；budgets: `Map<entry, { absoluteKB, relativePct }>`（可缺项）；baseline: `Map<entry, sizeKB>` 或 null；exemptions: `Array<{ entry, reason, expires }>`（expires 是 ISO 日期）。规则：1) 超 absoluteKB → error；2) 有 baseline 且增长超 relativePct → error；3) entry 在 exemptions 中且未过期（比较 current date）→ 该 entry 的违规降级为 'exempt'（不阻塞但记录）；4) 过期豁免按违规处理并额外提示豁免过期；5) budgets 中存在但 output 缺 entry → error 'missing-entry'。返回 `{ blockers: string[], exempt: Array, notes: string[] }`。

```javascript
const isExpired = (iso, now = new Date()) => new Date(iso) < now;

function checkBudgets(output, budgets, baseline = null, exemptions = [], { now = new Date() } = {}) {
  const blockers = [], exempt = [], notes = [];
  const exemptOf = (entry) => exemptions.find(x => x.entry === entry && !isExpired(x.expires, now));

  for (const [entry, size] of output) {
    const b = budgets.get(entry);
    if (!b) continue;
    const exempt = exemptOf(entry);
    if (b.absoluteKB != null && size > b.absoluteKB) {
      const msg = `${entry} 超绝对预算 ${size}KB > ${b.absoluteKB}KB`;
      if (exempt) { exempt.push({ entry, msg, reason: exempt.reason }); notes.push(`豁免生效: ${entry} (${exempt.reason})`); }
      else blockers.push(msg);
    }
    const base = baseline?.get?.(entry);
    if (base && b.relativePct != null && size > base * (1 + b.relativePct / 100)) {
      const msg = `${entry} 相对基线增长 ${((size / base - 1) * 100).toFixed(1)}% 超限`;
      if (exempt) exempt.push({ entry, msg, reason: exempt.reason });
      else blockers.push(msg);
    }
  }
  for (const x of exemptions)
    if (isExpired(x.expires, now)) notes.push(`豁免已过期: ${x.entry}（${x.expires}）——请重新评估`);

  for (const entry of budgets.keys())
    if (!output.has(entry)) blockers.push(`${entry} 产物缺失`);

  return { blockers, exempt, notes };
}

// 自测
const output = new Map([['home', 260], ['admin', 150]]);
const budgets = new Map([
  ['home', { absoluteKB: 200, relativePct: 10 }],
  ['admin', { absoluteKB: 200, relativePct: 10 }],
  ['report', { absoluteKB: 100, relativePct: 10 }],
]);
const baseline = new Map([['home', 220], ['admin', 150]]);

// 1) home 双超 + report 缺失 + admin 正常
let r = checkBudgets(output, budgets, baseline);
console.log(r.blockers.length === 3);                    // home 绝对 + home 相对 + report missing

// 2) 豁免降级
r = checkBudgets(output, budgets, baseline,
  [{ entry: 'home', reason: '活动页大图预载', expires: '2099-01-01' }]);
console.log(r.blockers.length === 1 && r.exempt.length === 2 &&
            r.blockers[0].includes('report'));

// 3) 过期豁免
r = checkBudgets(output, budgets, baseline,
  [{ entry: 'home', reason: '旧豁免', expires: '2020-01-01' }]);
console.log(r.blockers.length === 3 && r.notes[0].includes('过期'));
```

**评分点**：
- 双轨阈值独立判定（绝对与相对都可能各自触发 blocker）
- 豁免语义正确：未过期降级为 exempt 并记 reason，过期按违规处理并提示重新评估
- missing-entry 检查（预算声明了但产物缺失）
- 能说清「豁免要记录在案防漂移」与「相对基线防阈值过时」的设计动机属于加分
