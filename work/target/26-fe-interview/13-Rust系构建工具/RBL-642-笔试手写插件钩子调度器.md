## RBL-642：笔试：手写插件钩子调度器（三钩子时序 + map 继承 + 缓存协议）

**答**：实现 `class PluginHost`：`add(plugin)` 注册插件（含可选 cacheable 标志）；`resolve(id, importer)`：按注册序跑 resolveId，null 放行，string 命中返回 `{ id }`，对象直接返回；全部放行返回 `{ id: builtin(id, importer) }`（内置函数注入）。`transform(mod)`：按序跑 transform（签名 (code, id)），null 放行，string 视为 { code }，对象取 code/map；**map 缺失继承前值**；收集 `usedPlugins`（实际执行了 transform 的插件名）。`cacheKey(mod)`：只有 mod 经过的 transform 插件全部 cacheable 时返回 `{ ok: true, key }`（key = 模块 id + code hash + 各 cacheable 插件版本拼接），否则 `{ ok: false, reason: 'non-cacheable-plugin' }`。边界：无插件注册的空 Host 正常工作；resolve 中插件抛错不中断后续（收集错误返回）。

```javascript
class PluginHost {
  constructor({ builtin } = {}) { this.plugins = []; this.builtin = builtin ?? ((id) => id); }
  add(p) { this.plugins.push(p); return this; }

  async resolve(id, importer) {
    const errors = [];
    for (const p of this.plugins) {
      if (!p.resolveId) continue;
      try {
        const r = await p.resolveId(id, importer);
        if (r == null) continue;
        return typeof r === 'string' ? { id: r } : r;
      } catch (e) { errors.push({ plugin: p.name, error: e }); }   // 抛错不中断
    }
    return { id: this.builtin(id, importer), errors };
  }

  async transform(mod) {
    let { code, map } = mod;
    const used = [];
    for (const p of this.plugins) {
      if (!p.transform) continue;
      const r = await p.transform(code, mod.id);
      if (r == null) continue;
      const t = typeof r === 'string' ? { code: r } : r;
      code = t.code; map = t.map ?? map;                 // 契约：缺 map 继承
      used.push(p.name);
    }
    return { code, map, usedPlugins: used };
  }

  cacheKey(mod, { hash = (s) => 'h' + s } = {}) {
    const used = this.plugins.filter(p => p.transform);
    if (used.some(p => p.cacheable === false))
      return { ok: false, reason: 'non-cacheable-plugin' };
    const key = [mod.id, hash(mod.code), ...used.map(p => `${p.name}@${p.version ?? 0}`)].join('|');
    return { ok: true, key };
  }
}

// 自测
const host = new PluginHost({ builtin: (id) => 'abs:' + id });
host.add({ name: 'alias', version: 1, resolveId: (id) => id === 'r' ? 'real' : null,
  transform: (c) => c.replace(/FOO/g, 'BAR') });
host.add({ name: 'mapper', version: 2, cacheable: true, transform: (c) => ({ code: c + ';MAPPED' }) });
host.add({ name: 'volatile', cacheable: false, transform: (c) => c });

const r1 = await host.resolve('r', '/a.js');
console.log(r1.id === 'real');
const r2 = await host.resolve('x', '/a.js');
console.log(r2.id === 'abs:x');

const mod = { id: '/m.js', code: 'FOO', map: 'm0' };
const t = await host.transform(mod);
console.log(t.code === 'BAR;MAPPED' && t.map === 'm0');    // map 继承
console.log(t.usedPlugins.join(','));

console.log(host.cacheKey(mod).ok === false);              // volatile 不可缓存
host.plugins.pop();                                        // 移除 volatile
console.log(host.cacheKey(mod).ok === true);
console.log(/alias@1/.test(host.cacheKey(mod).key));
```

**评分点**：
- 三钩子时序与返回值协议完整（null 放行/string 命中/对象结构化）
- map 继承契约实现（缺失时保留前值，sourcemap 链不断裂）
- resolve 插件抛错收集不中断（容错）；cacheKey 正确排除 non-cacheable 插件且含插件版本
- 能说清「transform 有状态导致缓存失效是增量编译正确性边界」属于加分
