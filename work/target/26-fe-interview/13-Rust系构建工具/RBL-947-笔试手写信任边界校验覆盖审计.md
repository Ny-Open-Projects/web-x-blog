## RBL-947：笔试：手写信任边界校验覆盖审计器（边界 parse 覆盖）

**答**：实现 `auditBoundaryChecks(code)`。规则：1) 识别「信任边界调用」：`fetch(` 返回值被直接解构/取属性而未过 zod parse → warn 'unvalidated-fetch'（fetch 后 3 行内无 `.parse(`/`.safeParse(`）；2) 识别已校验：`xxx.parse(` 或 `safeParse(` 在 fetch 结果赋值变量后的使用 → ok；3) `JSON.parse(res.data)` 无 schema → 同样 warn 'unvalidated-json'；4) 返回 `{ findings: Array<{ line, type, var? }>, ok }`。边界：无 fetch；parse 在其它行（距离 ≤3 行算覆盖）；async await 链简化按文本行。

```javascript
function auditBoundaryChecks(code = '') {
  const lines = (code ?? '').split('\n');
  const findings = [];
  lines.forEach((line, i) => {
    const m = /(?:const|let)\s+(\w+)\s*=\s*await\s+fetch\(|(\w+)\s*=\s*(?:await\s+)?res\.json\(\)/.exec(line);
    if (!m) return;
    const varName = m[1] ?? m[2];
    // 向后 3 行找 parse/safeParse
    const window = lines.slice(i, i + 4).join('\n');
    const validated = new RegExp(`${varName}[^;]*\\.(?:safeParse|parse)\\(`).test(window) ||
      /(?:schema|Schema)\w*\.(?:safeParse|parse)\(/.test(window);
    if (!validated)
      findings.push({ line: i + 1, type: /json\(\)/.test(line) ? 'unvalidated-json' : 'unvalidated-fetch',
        var: varName });
  });
  return { findings, ok: findings.length === 0 };
}

// 自测
const bad = [
  "const res = await fetch('/api/user');",
  "const data = await res.json();",
  "return data.name;",                                   // 未校验
].join('\n');
let r = auditBoundaryChecks(bad);
console.log(r.findings.length === 2);                    // fetch 与 json 两处
console.log(r.findings.every(f => f.type === 'unvalidated-fetch' || f.type === 'unvalidated-json'));
console.log(r.ok === false);

const good = [
  "const res = await fetch('/api/user');",
  "const data = UserSchema.safeParse(await res.json());",
  "if (!data.success) throw new Error('bad');",
  "return data.data.name;",
].join('\n');
r = auditBoundaryChecks(good);
console.log(r.ok === true && r.findings.length === 0);

// 距离 3 行内覆盖
const near = [
  "const res = await fetch('/api/x');",
  "const raw = await res.text();",
  "const data = JSON.parse(raw);",
  "const safe = Schema.parse(data);",
].join('\n');
r = auditBoundaryChecks(near);
// JSON.parse 无 schema 仍 warn；Schema.parse 在窗口内
console.log(r.findings.length === 1 && r.findings[0].type === 'unvalidated-json');

console.log(auditBoundaryChecks('const a = 1;').ok === true);
```

**评分点**：
- 信任边界识别（fetch/json 赋值变量）+ 3 行窗口的 parse 覆盖判定；两类 finding 区分
- safeParse 与 parse 等价认可；Schema.parse 模式识别
- 边界：无 fetch、覆盖命中
- 能说清「类型管编译期协作、运行时校验管信任边界——双层缺一不可」属于加分
