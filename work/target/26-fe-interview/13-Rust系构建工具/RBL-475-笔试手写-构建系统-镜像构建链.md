## RBL-475：手写容器镜像构建链
**需求**：实现 `createImagePipeline(docker)`：1) 多阶段构建管理：builder 层（全量依赖）→ runtime 层（仅产物）——镜像体积优化；2) 层缓存策略：COPY 顺序（package.json 先行——依赖层命中）、cache mount（pnpm store 跨构建复用）；3) 镜像标签策略：`{ app, sha, semver }` 三标签（可追溯 + 可回滚）；4) 镜像扫描门禁：trivy 扫描 CVE（critical 阻断）；5) distroless/scratch 精简与运行时依赖声明（alpine musl 兼容性提示）；6) 构建上下文优化：.dockerignore（上下文传输 + 防泄漏）。

```javascript
export function createImagePipeline(docker, { app }) {
  async function build({ sha, version }) {
    // Dockerfile 由模板生成（层顺序保证缓存命中）
    const dockerfile = `
FROM node:20-alpine AS build
WORKDIR /app
COPY package.json pnpm-lock.yaml ./
RUN --mount=type=cache,target=/root/.local/share/pnpm/store pnpm install --frozen-lockfile
COPY . .
RUN pnpm build

FROM node:20-alpine
WORKDIR /app
COPY --from=build /app/dist ./dist
COPY --from=build /app/node_modules ./node_modules
EXPOSE 3000
CMD ["node", "dist/server.js"]`
    const tags = [`${app}:${sha}`, `${app}:${version}`, `${app}:latest`]
    const image = await docker.build({ dockerfile, tags, context: '.dockerignore-guarded' })
    return { image, tags }
  }

  async function scan(image) {
    const findings = await docker.trivyScan(image)
    const critical = findings.filter((f) => f.severity === 'CRITICAL')
    if (critical.length) throw new Error(`镜像存在 ${critical.length} 个 CRITICAL CVE：${critical.map((c) => c.id).join(',')}`)
    return { findings, clean: critical.length === 0 }
  }

  async function push(image, registry) {
    for (const tag of image.tags) await docker.push(`${registry}/${tag}`)
  }

  return { build, scan, push,
    notes: { contextGuard: '.dockerignore 必须排除 node_modules/.git/.env',
      musl: 'alpine musl 与 glibc Native binding 不兼容需重编译' } }
}
```
**评分点**：
- 多阶段 + 层序缓存（package.json 先 COPY——层缓存命中的核心技巧）+ cache mount
- 三标签策略（sha/semver/latest——可追溯与可回滚）
- CVE 扫描门禁（critical 阻断——镜像安全左移）
- .dockerignore 双重价值（传输 + 泄漏防护）；musl 兼容陷阱提示
