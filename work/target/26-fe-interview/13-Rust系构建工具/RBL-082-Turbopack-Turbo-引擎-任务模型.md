## RBL-082：Turbopack 的 Turbo 引擎（任务模型）如何工作？
**答**：
- Turbo 引擎（turbo-tasks）是 Turbopack 的增量计算运行时：把每个计算单元建模为 Vc<T>（value cell）任务，任务执行时自动记录"读过哪些输入"形成细粒度依赖图。
- 关键机制：任务执行期间对其他任务/文件系统/环境变量的读取都被追踪（自依赖跟踪），变更发生时沿依赖图失效受影响任务，下次请求时惰性重算。
- 惰性求值：只有被消费的结果才会计算（类似按需拉取），冷启动时不需要全量构建模块图——初始只算请求入口。
- 并发模型：所有任务在 Rust 线程池执行，同一任务不会重复执行（去重），读-写通过任务缓存隔离，避免数据竞争。
- 持久化：任务结果 + 依赖边序列化写盘（turbo-tasks-fs），重启后复用。
- 追问钩子：这套模型类似自刷新电子表格（ spreadsheet model）——单元格依赖追踪+失效重算，面试时用这个类比讲清最快。

```text
Turbo 引擎（turbo-tasks）
┌────────────────────────────────────────────┐
│ taskA = read(file) → parse → transform     │
│   执行时自动记录：读了 file, parser 配置    │
│ file 变更 → 失效 taskA → 下次消费时惰性重算 │
│ 未被消费的任务不计算（懒）                  │
└────────────────────────────────────────────┘
类比：Excel 单元格 = 任务；公式依赖 = 自动追踪的输入；
     改一个单元格 → 只重算引用它的公式
```
