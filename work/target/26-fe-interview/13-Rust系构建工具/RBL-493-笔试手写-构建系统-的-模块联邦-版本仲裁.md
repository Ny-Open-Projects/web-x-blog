## RBL-493：手写 Module Federation 版本仲裁
**需求**：实现 `negotiateShared(declaredShared, loadedVersions)`：1) declaredShared：host/remote 各自声明（{ react: { singleton, requiredVersion } }）；2) 仲裁规则：singleton 包只加载一份——选满足所有 requiredVersion 的最高版本；无满足版本 → 拒绝加载（报兼容错误，不静默降级）；3) 非 singleton：多版本可共存（各自作用域加载）；4) 仲裁结果通知：{ name, resolvedVersion, provider, warnings }；5) 循环依赖安全（host 依赖 remote、remote 依赖 host 的 shared——快照协商防死锁）。

```javascript
import semver from 'semver'

export function negotiateShared(declaredShared, available) {
  const resolved = {}, warnings = []

  for (const [name, decl] of Object.entries(declaredShared)) {
    const candidates = available[name] ?? []                 // [{ version, provider }]
    if (decl.singleton) {
      // 满足全部 requiredVersion 的最高版本
      const required = decl.requiredVersions ?? []           // 多方 requiredVersion 汇总
      const ok = candidates.filter((c) => required.every((r) => semver.satisfies(c.version, r)))
      if (!ok.length) {
        throw new Error(`shared ${name} 无满足版本: required=${required} available=${candidates.map((c) => c.version)}`)
      }
      const best = ok.sort((a, b) => semver.rcompare(a.version, b.version))[0]
      resolved[name] = { version: best.version, provider: best.provider }
      // 版本偏离告警
      const wanted = [...new Set(required)]
      if (wanted.length > 1) warnings.push(`${name} 各方要求不一致 ${wanted} — 取最高兼容版`)
    } else {
      resolved[name] = candidates.map((c) => ({ version: c.version, provider: c.provider }))   // 多版本共存
    }
  }
  return { resolved, warnings }
}

// 语义示例：
// host: react singleton required ^18.2
// remote: react singleton required ^18.3
// → 选满足两者的最高 18.3.x；若 remote 要求 ^19 → 拒绝（不静默降级）
```
**评分点**：
- singleton 语义正确（单实例 + 全 requiredVersion 交集 + 最高版本）
- 无满足版本显式拒绝（不静默降级——运行时兼容错误的正确处理）
- 版本偏离告警（各方要求不一致——提前暴露协调问题）
- 非 singleton 多版本共存语义
