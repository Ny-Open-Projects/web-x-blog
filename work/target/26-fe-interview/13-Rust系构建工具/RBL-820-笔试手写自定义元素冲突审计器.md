## RBL-820：笔试：手写自定义元素冲突审计器（同名异类 + 幂等）

**答**：实现 `auditElements(bundles)`。bundles: `{ name, code }[]`。提取 `customElements.define('name', ClassName)` 与 `customElements.define('name', class extends ...)`（匿名类记录为 'anonymous'）。规则：1) 同一元素名在多 bundle 定义且类名不同（或一方匿名）→ conflict `{ name, definers }`；2) 同名同类（相同类名）→ 'idempotent'（info，安全但建议提升共享 chunk）；3) 同 bundle 内重复定义同元素 → conflict（自身冲突）；4) 返回 `{ conflicts, idempotents }`。边界：空 bundles；匿名类与具名类同名也判 conflict（无法证明同一）。

```javascript
function auditElements(bundles) {
  const defs = new Map();                                  // name -> [{ bundle, className }]
  for (const b of bundles) {
    const seenInBundle = new Set();
    for (const m of (b.code ?? '').matchAll(
      /customElements\.define\(\s*['"]([\w-]+)['"]\s*,\s*(?:class\s+(\w+)?|(\w+))/g)) {
      const name = m[1], cls = m[2] ?? m[3] ?? 'anonymous';
      (defs.get(name) || defs.set(name, []).get(name)).push({ bundle: b.name, className: cls });
      if (seenInBundle.has(name))
        defs.get(name).push({ bundle: b.name, className: cls + ':self-dup' });
      seenInBundle.add(name);
    }
  }
  const conflicts = [], idempotents = [];
  for (const [name, list] of defs) {
    const classes = new Set(list.map(l => l.className));
    if (classes.size > 1 || list.some(l => l.className === 'anonymous'))
      conflicts.push({ name, definers: list });
    else if (list.length > 1)
      idempotents.push({ name, bundles: [...new Set(list.map(l => l.bundle))] });
  }
  return { conflicts, idempotents };
}

// 自测
const bundles = [
  { name: 'main', code: "customElements.define('x-btn', XBtn);" },
  { name: 'widget-a', code: "customElements.define('x-btn', XBtn);" },      // 同类幂等
  { name: 'widget-b', code: "customElements.define('x-btn', OldXBtn);" },   // 异类冲突
  { name: 'widget-c', code: "customElements.define('x-icon', class extends HTMLElement {});" },   // 匿名
  { name: 'main2', code: "customElements.define('x-icon', XIcon);" },       // 匿名 vs 具名 -> conflict
  { name: 'dup', code: "customElements.define('x-tab', XTab);\ncustomElements.define('x-tab', XTab);" }, // 自重复
];
let r = auditElements(bundles);
console.log(r.conflicts.some(c => c.name === 'x-btn'));    // 异类
console.log(r.conflicts.some(c => c.name === 'x-icon'));   // 匿名 vs 具名
console.log(r.conflicts.some(c => c.name === 'x-tab'));    // 自重复
console.log(r.idempotents.some(i => i.name === 'x-btn' && i.bundles.includes('main')));
console.log(r.conflicts.length === 3 && r.idempotents.length === 1);

console.log(auditElements([]).conflicts.length === 0);
r = auditElements([{ name: 'solo', code: "customElements.define('x-a', A);" }]);
console.log(r.conflicts.length === 0 && r.idempotents.length === 0);
```

**评分点**：
- 三类冲突检出：同名异类/匿名类/自重复；匿名类保守判 conflict（无法证明同一）
- 同名同类幂等归 info 并列出 bundle 清单（共享提升的候选）
- define 提取兼容具名类/class 表达式/变量引用三种形态
- 能说清「幂等跳过安全、异类覆盖是加载顺序竞态必须显式暴露」属于加分
