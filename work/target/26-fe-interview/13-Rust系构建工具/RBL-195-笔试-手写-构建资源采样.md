## RBL-195：笔试：手写构建资源采样器（构建期间 CPU/内存峰值记录）

**题目**：写 resource-probe.mjs：1) 输入构建子进程（spawn 返回的 ChildProcess）；2) 每 500ms 采样一次其 CPU 时间与 RSS（Linux 下读 /proc/{pid}/stat 与 status，采样器自身开销可忽略）；3) 记录：峰值 RSS、平均 CPU%、采样点数；4) 进程退出后输出报告 JSON（对接 RBL-168 上报）；5) 停止条件：进程退出即停；若采样时进程已死要容错不崩。

```javascript
// resource-probe.mjs
import { readFileSync, existsSync, appendFileSync } from 'node:fs';
import { spawn } from 'node:child_process';

export function probe(child, { interval = 500, out = '.ci/resource.json' } = {}) {
  const samples = [];
  const clockTicks = 100; // Linux _SC_CLK_TCK

  const timer = setInterval(() => {
    try {
      if (child.pid == null || !existsSync(`/proc/${child.pid}`)) return; // 已死容错
      const stat = readFileSync(`/proc/${child.pid}/stat`, 'utf8');
      const status = readFileSync(`/proc/${child.pid}/status`, 'utf8');
      const utime = Number(stat.split(') ').pop().split(' ')[11]);
      const stime = Number(stat.split(') ').pop().split(' ')[12]);
      const rss = Number(status.match(/VmRSS:\s+(\d+)/)?.[1] ?? 0); // kB
      samples.push({ t: Date.now(),
        cpuSec: (utime + stime) / clockTicks,
        rssMB: +(rss / 1024).toFixed(1) });
    } catch { /* 进程刚好退出：忽略本拍 */ }
  }, interval);

  return new Promise(resolve => {
    child.on('exit', () => {
      clearInterval(timer);
      const peakRssMB = Math.max(0, ...samples.map(s => s.rssMB));
      const wallSec = samples.length * interval / 1000;
      const avgCpuPct = wallSec && samples.length > 1
        ? +((samples.at(-1).cpuSec - samples[0].cpuSec) / wallSec * 100).toFixed(1) : 0;
      const report = { peakRssMB, avgCpuPct, samples: samples.length };
      try { appendFileSync(out, JSON.stringify(report) + '\n'); } catch {}
      resolve(report);   // { peakRssMB: 2140.5, avgCpuPct: 380.2, samples: 240 }
    });
  });
}

// 用法：构建 + 采样一体
const build = spawn('rspack build', { shell: true, stdio: 'inherit' });
const r = await probe(build);
console.log(`peak RSS ${r.peakRssMB}MB, avg CPU ${r.avgCpuPct}%`);
```
**评分点**：
- 采样在 /proc 层面直读（比 exec ps 开销小两个量级）。
- 进程已退出的容错（竞态窗口必须处理）。
- 峰值与平均两个维度（内存看 peak，CPU 看均值）。
- cpu% 相对墙钟换算正确（多线程可 >100%，Rust 工具常 300%+）。
- 报告落盘可对接可观测（RBL-168）。
