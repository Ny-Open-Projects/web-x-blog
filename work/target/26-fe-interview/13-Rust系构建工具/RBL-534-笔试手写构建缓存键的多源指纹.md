## RBL-534：手写构建缓存键的多源指纹
**答**：实现 `cacheKey(inputs)`：构建缓存的键 = 多源指纹——1) 文件内容 hash（而非 mtime——mtime 不可靠：git checkout 回滚时间变化内容不变）；2) 配置指纹（影响产物的配置子集——排除无关配置）；3) 工具链指纹（打包器版本 + 插件版本 + loader 版本）；4) 依赖闭包 hash（import 的模块内容 hash 传播）；5) 附用例：配置无关项变化不失效、依赖传播失效。

```javascript
import { createHash } from 'crypto'

function h(s) { return createHash('sha256').update(s).digest('hex').slice(0, 16) }

function cacheKey({ fileContent, config, toolchain, depClosure }) {
  // 1) 内容 hash（不用 mtime：checkout 回滚时间变内容不变——mtime 不可靠）
  const contentH = h(fileContent)
  // 2) 配置指纹：只取影响产物的配置子集（白名单）
  const RELEVANT = ['mode', 'target', 'minify', 'define', 'loaderOptions']
  const configH = h(JSON.stringify(RELEVANT.map((k) => config?.[k] ?? null)))
  // 3) 工具链指纹
  const toolH = h(JSON.stringify(toolchain))
  // 4) 依赖闭包 hash（传播）
  const depH = h(JSON.stringify(depClosure ?? {}))
  return { key: `${contentH}.${configH}.${toolH}.${depH}`, parts: { contentH, configH, toolH, depH } }
}

// 用例
const base = { fileContent: 'code-v1', config: { mode: 'prod', debug: true }, toolchain: { bundler: 'rspack@1.0', swc: '1.7' }, depClosure: { 'a.js': 'h-a' } }
const k1 = cacheKey(base)

// 无关配置变化（debug 不在白名单）：键不变
const k2 = cacheKey({ ...base, config: { mode: 'prod', debug: false } })
console.log(k1.key === k2.key)                    // true：配置白名单生效

// 依赖变更 → depH 变 → 键变（级联失效）
const k3 = cacheKey({ ...base, depClosure: { 'a.js': 'h-a2' } })
console.log(k1.key !== k3.key)                    // true

// 工具链升级 → 键变
const k4 = cacheKey({ ...base, toolchain: { bundler: 'rspack@1.1', swc: '1.7' } })
console.log(k1.key !== k4.key)                    // true
console.log(k4.parts.toolH !== k1.parts.toolH)    // true
```
**评分点**：
- 内容 hash 优先于 mtime（checkout 回滚反例）
- 配置白名单（无关配置变化不失效——缓存误失效的治理）
- 工具链指纹（升级失效——脏缓存防线）
- 依赖闭包 hash 传播（级联失效）
