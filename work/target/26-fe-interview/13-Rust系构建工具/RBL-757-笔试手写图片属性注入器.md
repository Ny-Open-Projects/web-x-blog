## RBL-757：笔试：手写图片属性注入器（优先级 + srcset + preload 同源）

**答**：实现 `injectAttrs(imgs, { variants, breakpoints, defaultViewport })`。imgs: `{ src, priority?, aboveFold? }[]`（src 无扩展名，variants: `Record<src, Record<width, url>>`）。规则：1) priority=true → fetchpriority high、loading eager、进 preload 列表；2) aboveFold=false 且无 priority → loading lazy、decoding async；3) aboveFold true/undefined → 不注入 loading（保守）；4) 有变体（≥2 尺寸）→ 生成 srcset（`url w描述, ...`）与 sizes（`100vw` 简化）；5) preload 条目必须与该图 srcset 同源（imagesrcset + imagesizes 一起生成，无双下载风险）；6) 返回 `{ attrs: Array<{ src, attrs }>, preloads }`。边界：无变体不生成 srcset；priority 与 lazy 冲突时 priority 赢。

```javascript
function injectAttrs(imgs, { variants = {}, defaultViewport = 640 } = {}) {
  const attrs = [], preloads = [];
  for (const img of imgs) {
    const a = {};
    const vs = variants[img.src] || {};
    if (img.priority) {
      a.fetchpriority = 'high'; a.loading = 'eager';
      if (Object.keys(vs).length >= 2)
        preloads.push({ href: vs[defaultViewport] ?? Object.values(vs)[0],
          imagesrcset: srcsetOf(vs), imagesizes: '100vw', as: 'image' });
      else if (Object.keys(vs).length === 1)
        preloads.push({ href: Object.values(vs)[0], as: 'image' });
    } else if (img.aboveFold === false) {
      a.loading = 'lazy'; a.decoding = 'async';
    }
    if (Object.keys(vs).length >= 2) { a.srcset = srcsetOf(vs); a.sizes = '100vw'; }
    attrs.push({ src: img.src, attrs: a });
  }
  return { attrs, preloads };
}
const srcsetOf = (vs) => Object.entries(vs).map(([w, url]) => `${url} ${w}w`).join(', ');

// 自测
const variants = {
  hero: { 640: '/hero.640.webp', 1280: '/hero.1280.webp' },
  thumb: { 320: '/thumb.320.webp' },
};
let r = injectAttrs([
  { src: 'hero', priority: true },
  { src: 'item-3', aboveFold: false },
  { src: 'item-1' },
  { src: 'thumb' },
], { variants, defaultViewport: 640 });
console.log(r.attrs[0].attrs.fetchpriority === 'high' && r.attrs[0].attrs.loading === 'eager');
console.log(r.preloads[0].imagesrcset.includes('1280.webp'));   // preload 与 srcset 同源
console.log(r.preloads[0].href === '/hero.640.webp');

console.log(r.attrs[1].attrs.loading === 'lazy' && r.attrs[1].attrs.decoding === 'async');
console.log(r.attrs[2].attrs.loading === undefined);    // 保守：aboveFold 未声明不注入
console.log(r.attrs[3].attrs.srcset === undefined);     // 单变体不生成 srcset

// 无 priority 但多变体：仍有 srcset
console.log(r.attrs[2].attrs.srcset?.includes('1280.webp'));
console.log(injectAttrs([], {}).preloads.length === 0);
```

**评分点**：
- 优先级判定正确：priority 最高（覆盖一切）、非首屏默认 lazy、未声明保守不注入
- preload 与 srcset 同源生成（imagesrcset + imagesizes 成对，防双下载）；多变体才 srcset
- 单变体 preload 直接 href；空输入安全
- 能说清「误判 LCP 图是致命退化，所以默认规则保守、显式声明优先」属于加分
