## RBL-909：笔试：手写分包归属器（闭包 + 共享 + 超限）

**答**：实现 `assignSubpackages(graph, subpkgConfig, { mainMaxKB, copyThresholdKB })`。graph: `closureOf(route) -> string[]`（模块 id）；subpkgConfig: `Record<route, pkgName>`（'main' 或分包名）；模块尺寸注入 `sizeOf(id)->KB`。规则：1) 页面闭包按配置归属；2) 跨分包共享模块（被 ≥2 个不同分包引用）：size > copyThreshold → 归 'main'，否则 'copy'（各分包内联复制，owner 记 'copy' 但输出按分包重复）；3) 硬校验：main 总量 > mainMaxKB → 抛错列出超限量与「下沉建议」（最大模块列表）；4) 返回 `Map<module, owner>`。边界：无配置（全 main）；单分包。

```javascript
function assignSubpackages(graph, subpkgConfig, { mainMaxKB = 2048, copyThresholdKB = 30, sizeOf }) {
  const owner = new Map();
  for (const [route, pkg] of Object.entries(subpkgConfig))
    for (const m of graph.closureOf(route))
      if (!owner.has(m)) owner.set(m, pkg);              // 首次归属（已归属不覆盖——主包优先）

  // 跨分包共享统计
  const refPkgs = new Map();                             // mod -> Set<pkg>
  for (const [mod, pkg] of owner) {
    refPkgs.get(mod) || refPkgs.set(mod, new Set()).get(mod).add(pkg);
  }
  for (const [mod, pkgs] of refPkgs) {
    if (pkgs.size >= 2 && !pkgs.has('main')) {
      const target = sizeOf(mod) > copyThresholdKB ? 'main' : 'copy';
      owner.set(mod, target);
    }
  }
  const mainSize = [...owner].filter(([, p]) => p === 'main')
    .reduce((s, [m]) => s + sizeOf(m), 0);
  if (mainSize > mainMaxKB) {
    const top = [...owner].filter(([, p]) => p === 'main')
      .sort((a, b) => sizeOf(b[0]) - sizeOf(a[0])).slice(0, 3)
      .map(([m]) => `${m}(${sizeOf(m)}KB)`);
    throw new Error(`主包 ${mainSize}KB 超限 ${mainMaxKB}KB——下沉建议: ${top.join(', ')}`);
  }
  return owner;
}

// 自测
const closures = {
  '/pages/home': ['compA', 'shared-big', 'page-home'],
  '/pages/shop': ['compB', 'shared-big', 'page-shop'],
  '/pages/me': ['compC', 'shared-big'],
};
const graph = { closureOf: (r) => closures[r] ?? [] };
const size = { compA: 20, compB: 25, compC: 22, 'shared-big': 60, 'page-home': 15, 'page-shop': 18, 'page-me': 12 };
const cfg = { '/pages/home': 'main', '/pages/shop': 'sub-shop', '/pages/me': 'sub-me' };

let r = assignSubpackages(graph, cfg, { mainMaxKB: 200, copyThresholdKB: 30, sizeOf: (m) => size[m] });
console.log(r.get('shared-big') === 'main');             // 60 > 30 下沉主包
console.log(r.get('compA') === 'main' || r.get('compA') === 'main');
console.log(r.get('compB') === 'sub-shop');              // 单分包引用不迁移
console.log(r.get('page-home') === 'main');

// 主包超限
let e; try {
  assignSubpackages(graph, cfg, { mainMaxKB: 80, copyThresholdKB: 30, sizeOf: (m) => size[m] });
} catch (x) { e = x; }
console.log(/超限/.test(e.message) && e.message.includes('shared-big(60KB)'));

// 小模块 copy
r = assignSubpackages(graph, { '/pages/home': 'p1', '/pages/shop': 'p2' },
  { mainMaxKB: 200, copyThresholdKB: 60, sizeOf: (m) => size[m] });
console.log(r.get('shared-big') === 'copy');             // 60 ≤ 60 复制
```

**评分点**：
- 闭包归属正确（首次优先不覆盖）；共享判定（≥2 个不同分包且不含 main）
- 下沉/复制阈值决策（大模块进主包、小模块复制——RBL-596 内联取舍）；硬校验超限抛错带下沉建议
- 边界：单分包、无配置
- 能说清「平台结构约束让通用 chunk 算法失效——产物结构自由度决定算法选择」属于加分
