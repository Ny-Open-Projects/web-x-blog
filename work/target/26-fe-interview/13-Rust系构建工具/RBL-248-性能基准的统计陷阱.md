## RBL-248：性能基准的常见统计陷阱有哪些

**答**:
- 陷阱一：均值误导（长尾拖高）——构建耗时应报中位数 + P95；陷阱二：方差未报——单次测量毫无意义，IQR/标准差必报；陷阱三：顺序效应——先跑 A 后跑 B，OS 缓存偏向 B，应 ABBA 交叉或随机顺序
- 陷阱四：回归均值解读——两次采样差异在噪声区间内宣称改进，需要显著性检验（Mann-Whitney U 或 bootstrap CI）；陷阱五：环境漂移——跨天测量机器状态不同，同期 AB 对比才有效
- 预算噪声：CPU 频率漂移/后台任务，锁频或至少记录 CPU 型号与负载
- 结论表述规范：「在中机型 fixture 上，X 比 Y 快 1.8x（中位数，n=10，CI 区间）」——限定条件完整

```text
合格结论：Rolldown 冷构建 8.2s vs Rollup 21.4s，中位数，n=10，
CI95 [7.9, 8.5] vs [20.8, 22.0]，fixture mid-3k@v2，macbook m2pro 锁频
```
