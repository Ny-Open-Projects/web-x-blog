## RBL-498：手写构建器抽象层
**需求**：实现 `createBuilderAdapter(engine)`：1) 统一接口：`build/config/transform/stats` 四方法——上层业务只见抽象层；2) 引擎适配：rspack/rollup/esbuild 各自实现 adapter（差异 API 映射到统一面）；3) 能力探测：adapter 声明支持的能力集（如 lazyCompilation 只有 rspack 有）——上层按能力分支而非按引擎名分支（能力驱动而非身份驱动）；4) 降级：能力缺失时上层策略调整（懒编译不可用 → 预热全量）；5) 切换验证：同 fixture 双引擎产物 diff（切换的回归保障）。

```javascript
const ENGINES = {
  rspack: {
    build: (cfg) => import('@rspack/core').then((r) => rspackBuild(cfg)),
    capabilities: { lazyCompilation: true, moduleFederation: true, hmr: true },
    configTransform: (unified) => toRspackConfig(unified),       // 统一面 → 引擎配置
  },
  rollup: {
    build: (cfg) => import('rollup').then((r) => rollupBuild(cfg)),
    capabilities: { lazyCompilation: false, moduleFederation: false, hmr: false },
    configTransform: (unified) => toRollupConfig(unified),
  },
}

export function createBuilderAdapter(engineName) {
  const engine = ENGINES[engineName]
  if (!engine) throw new Error(`unknown engine ${engineName}`)

  return {
    capabilities: engine.capabilities,                           // 能力集声明
    async build(unifiedConfig) {
      const engineConfig = engine.configTransform(unifiedConfig)  // 统一面转换
      const result = await engine.build(engineConfig)
      return normalizeStats(result)                             // 引擎 stats → 统一 stats
    },
  }
}

// 上层按能力分支（不按引擎身份）
export async function devBuild(adapter, config) {
  if (adapter.capabilities.lazyCompilation)
    return adapter.build({ ...config, lazyCompilation: true })
  return adapter.build(config)                                  // 降级：全量编译
}
```
**评分点**：
- 统一面四方法 + configTransform（引擎差异收敛在 adapter 内）
- 能力驱动而非身份驱动（上层分支按 capabilities——换引擎不改业务代码）
- stats 归一（引擎 stats 差异在上层不可见）
- 切换验证（双引擎 fixture diff——抽象层的回归保障）
