## RBL-822：笔试：手写升级日就绪度评估器（规则 + 工时 + 看板）

**答**：实现两部分。1) `assess(repo, rules)`：rules: `Array<{ id, check(repo) -> { ok, detail? } }>`. 返回 `{ repo, ready, blockers: Array<{ id, detail }>, estimatedHours }`——工时 = blockers × 2 +（customPlugins > 3 追加 4 否则 1）。2) `board(repos, rules)`：聚合 ready 率 + 按 estimatedHours 降序的未就绪清单（人工优先处理最贵的）；输出 `{ readinessPct, backlog }`（backlog 含 repo/est/blockers，截 top5）。边界：rules 空（全部 ready）；repo 缺 customPlugins（按 0）。

```javascript
function assess(repo, rules = []) {
  const blockers = rules
    .map(r => ({ id: r.id, r: r.check(repo) }))
    .filter(x => !x.r.ok)
    .map(x => ({ id: x.id, detail: x.r.detail ?? '' }));
  const hours = blockers.length * 2 + ((repo.customPlugins ?? 0) > 3 ? 4 : 1);
  return { repo: repo.name, ready: blockers.length === 0, blockers, estimatedHours: hours };
}

function board(repos, rules) {
  const assessed = repos.map(r => assess(r, rules));
  const readyCount = assessed.filter(a => a.ready).length;
  const readinessPct = repos.length
    ? +(readyCount / repos.length * 100).toFixed(1) : 0;
  const backlog = assessed.filter(a => !a.ready)
    .sort((a, b) => b.estimatedHours - a.estimatedHours)
    .slice(0, 5);
  return { readinessPct, backlog };
}

// 自测
const rules = [
  { id: 'no-fork', check: (r) => ({ ok: !(r.fork ?? false), detail: '存在 fork 补丁' }) },
  { id: 'node-v', check: (r) => ({ ok: (r.nodeVersion ?? 20) >= 20, detail: 'Node < 20' }) },
  { id: 'deps', check: (r) => ({ ok: r.customPlugins <= 5, detail: '插件过多' }) },
];
const repos = [
  { name: 'clean', customPlugins: 2 },
  { name: 'forky', fork: true, customPlugins: 5, nodeVersion: 22 },
  { name: 'old-node', nodeVersion: 18 },
  { name: 'heavy', customPlugins: 8 },
];
let r = assess(repos[1], rules);
console.log(r.ready === false && r.blockers.length === 1 && r.estimatedHours === 6);   // 1 blocker*2 + 4

r = assess(repos[0], rules);
console.log(r.ready === true && r.estimatedHours === 1);

const b = board(repos, rules);
console.log(b.readinessPct === 25);                      // 1/4 ready
console.log(b.backlog[0].repo === 'forky' && b.backlog[0].estimatedHours === 6);
console.log(b.backlog.length === 3);                     // top5 内 3 个未就绪

console.log(board([], rules).readinessPct === 0);
console.log(board(repos, []).readinessPct === 100);      // 无规则全 ready
```

**评分点**：
- 规则检查聚合与工时公式正确（blocker 计价 + 插件复杂度加成）
- readiness 百分比精度；backlog 按 estimatedHours 降序 top5（先贵后便宜）
- 边界：空 rules 全 ready、缺 customPlugins 防御
- 能说清「升级日的价值在版本碎片收敛与问题归并，工时预估让排期可协商」属于加分
