## RBL-812：笔试：手写构建数据口径规范化报告器（协议 + 分层）

**答**：实现 `speedupReport(oldMs, newMs, protocol, { layers })`。protocol: `{ scope, cache, stat, warmup, runs, hardware }`（缺字段用默认表）。规则：1) 无口径字段（protocol 为 null/缺 scope）→ 抛错 'no-protocol'（禁止无口径数字）；2) speedup = old/new 保留 1 位；3) layers 提供时输出分层摘要（每层 `{ name, ratio, deterministic }`——deterministic 由层名判断：cold-build/CI 为 true，hmr/local 为 false），全部确定性层才返回 `headline`（可对外宣传的数字），否则 headline 为 null + note '含非确定性收益，请分层表述'；4) 返回 `{ speedup, protocolStr, headline, layers }`。边界：newMs 为 0 抛错；protocol 字段大小写规范化。

```javascript
const DEFAULTS = { scope: 'build only', cache: 'cold', stat: 'p50', warmup: 1, runs: 7, hardware: 'unspecified' };
const DET_LAYERS = ['cold-build', 'ci'];

function speedupReport(oldMs, newMs, protocol, { layers = [] } = {}) {
  if (!protocol || !protocol.scope) throw new Error('no-protocol：无口径的加速比是营销');
  if (!newMs || newMs <= 0) throw new Error('非法 newMs');
  const p = { ...DEFAULTS, ...protocol };
  const protocolStr = `${p.scope}/${p.cache}/${p.stat}/runs=${p.runs}/${p.hardware}`;
  const speedup = +(oldMs / newMs).toFixed(1);
  const normalizedLayers = layers.map(l => ({
    name: l.name.toLowerCase(), ratio: l.ratio,
    deterministic: DET_LAYERS.includes(l.name.toLowerCase()),
  }));
  const allDet = layers.length === 0 || normalizedLayers.every(l => l.deterministic);
  return {
    speedup, protocolStr,
    headline: allDet ? speedup : null,
    layers: normalizedLayers,
    note: allDet ? null : '含非确定性收益（hmr/local），请分层表述',
  };
}

// 自测
let r = speedupReport(80000, 10000,
  { scope: 'build only', cache: 'cold', stat: 'p50', runs: 7, hardware: 'm5.2xl' },
  { layers: [{ name: 'cold-build', ratio: 8 }] });
console.log(r.speedup === 8 && r.headline === 8);
console.log(r.protocolStr.includes('cold'));

r = speedupReport(80000, 10000,
  { scope: 'dev loop', cache: 'warm', hardware: 'macbook' },
  { layers: [{ name: 'cold-build', ratio: 8 }, { name: 'hmr', ratio: 2 }] });
console.log(r.headline === null && r.note.includes('分层表述'));   // hmr 非确定性
console.log(r.layers[1].deterministic === false);

let e; try { speedupReport(80000, 10000, null); } catch (x) { e = x; }
console.log(/no-protocol/.test(e.message));
e = null; try { speedupReport(80000, 0, { scope: 'x' }); } catch (x) { e = x; }
console.log(/非法/.test(e.message));
```

**评分点**：
- 口径强制（无 scope 抛错）与默认表合并；协议字符串随数字输出
- 分层确定性判定（hmr/local 不可宣传）；混合收益 headline 置 null
- 非法输入防御（newMs=0）；大小写规范化
- 能说清「口径必须随数字出现、混层加速比是营销不是工程」属于加分
