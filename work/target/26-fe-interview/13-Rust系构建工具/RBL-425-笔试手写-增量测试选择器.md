## RBL-425：手写增量测试选择器
**答**：实现 `selectTests(changedFiles, testIndex)`：1) testIndex：`{ testFile, imports: string[] }[]`（测试文件依赖索引）；2) 直接命中：变更文件被某测试 import → 该测试选中；3) 传递命中：变更的是「被测试依赖的模块」的依赖（源码模块图反向传播）；4) 特殊规则：配置文件变更（如 jest.config）→ 全量；快照测试涉及文件 → 对应快照测试；5) 返回 { selected, reason: Map<testFile, reason> }（每测试带选中原因——可解释性）；6) 未命中测试标注 skipped-not-affected（不是隐式跳过）。

```javascript
export function selectTests(changedFiles, testIndex, { configFiles = ['jest.config.*', 'vite.config.*'] } = {}) {
  if (changedFiles.some((f) => configFiles.some((c) => f.includes(c.replace('*',''))))) 
    return { selected: testIndex.map((t) => t.testFile),
      reason: new Map(testIndex.map((t) => [t.testFile, 'config changed'])),
      fullRun: true }

  // 源码模块反向依赖：testFile.imports 即其可达依赖集合（预计算含传递闭包更准）
  const selected = new Map()
  const changedSet = new Set(changedFiles)
  for (const t of testIndex) {
    const hit = t.imports.find((imp) => changedSet.has(imp))
    if (hit) selected.set(t.testFile, `imports ${hit}`)
  }
  // 快照规则
  for (const t of testIndex)
    if (t.snapshots?.some((s) => changedSet.has(s)) && !selected.has(t.testFile))
      selected.set(t.testFile, `snapshot ${t.snapshots.find((s) => changedSet.has(s))}`)

  return { selected: [...selected.keys()], reason: selected, fullRun: false,
    skippedNotAffected: testIndex.length - selected.size }
}
```
**评分点**：
- 直接/传递命中区分（imports 应含传递闭包——索引预计算是正确性前提）
- 配置文件 → 全量（保守正确的护栏）
- 可解释性（每个测试带 reason——incremental 不解释=不敢用）
- skipped 显式计数（不是隐式消失——可见性）
