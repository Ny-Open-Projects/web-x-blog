## RBL-189：笔试：手写构建守护进程（超时 kill + 通知回执 + 心跳日志）

**答**：写 build-guard.mjs：1) 执行传入的构建命令（spawn shell）；2) 硬超时（默认 20min）到点 SIGKILL 并标记 timeout；3) 心跳：每 60s 输出一条 `alive <elapsed>s`（CI 平台靠日志判断 job 存活，超长静默会被误判挂死）；4) 结束后发通知回执（HTTP POST：状态/耗时/退出码），通知失败不影响退出码；5) 通知发送本身带 5s 超时，整体进程退出码 = 构建结果。

```javascript
// build-guard.mjs
const build = spawn(process.argv[2], process.argv.slice(3), { shell: true,
  stdio: ['ignore', 'inherit', 'inherit'] }); // 构建日志直通，便于 CI 实时查看

const TIMEOUT = Number(process.env.BUILD_TIMEOUT_MS ?? 20 * 60_000);
const t0 = performance.now();

const heartbeat = setInterval(() =>
  console.log(`[guard] alive ${Math.round((performance.now() - t0) / 1000)}s`), 60_000);
const timer = setTimeout(() => {
  console.error(`[guard] timeout ${TIMEOUT / 1000}s, killing...`);
  build.kill('SIGKILL');
}, TIMEOUT);

const code = await new Promise(res => build.on('exit', res));
clearInterval(heartbeat); clearTimeout(timer);
const status = code === 0 ? 'success' : (code === null ? 'timeout' : 'failed');
const elapsed = Math.round((performance.now() - t0) / 1000);

// 通知回执：5s 超时，失败仅告警
try {
  await Promise.race([
    fetch(process.env.NOTIFY_WEBHOOK, {
      method: 'POST', headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ status, elapsed, exitCode: code, job: process.env.JOB_NAME }),
    }),
    new Promise((_, rej) => setTimeout(() => rej(new Error('notify timeout')), 5000)),
  ]);
} catch (e) { console.warn(`[guard] notify failed: ${e.message}`); }

console.log(`[guard] ${status} in ${elapsed}s`);
process.exit(status === 'success' ? 0 : 1);   // timeout 也要非零退出
```
**评分点**：
- 心跳日志防 CI 平台误判挂死（长构建必备）。
- 超时 SIGKILL 且 timeout 归入非零退出（不是"无结果"）。
- 通知与构建结果解耦：通知失败不改退出码。
- 通知自身有超时（不能让回执卡死主流程）。
- exit code 三态映射正确：success/failed/timeout。
