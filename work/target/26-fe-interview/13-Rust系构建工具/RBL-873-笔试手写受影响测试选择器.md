## RBL-873：笔试：手写受影响测试选择器（反向闭包 + 过滤）

**答**：实现 `selectTests(changed, graph, testFiles, { maxTests })`。graph: `Record<file, deps: string[]>`；testFiles: 测试文件数组。规则：1) 反向闭包：changed 文件的所有（传递）导入者；2) 选中 = 闭包 ∩ testFiles；3) 兜底：changed 本身是测试文件 → 直接选中；4) 闭包无测试命中时（如改了 README/配置）返回空（不跑全量——除非 opts.fallbackAll=true 则返回全部测试）；5) 选中超过 maxTests → 截断（CI 分片另处理）+ 标记 truncated。返回 `{ tests: string[], truncated: boolean }`。边界：graph 无该文件（只选中自身若是测试）；环安全。

```javascript
function selectTests(changed, graph, testFiles, { maxTests = 50, fallbackAll = false } = {}) {
  const testSet = new Set(testFiles);
  const affected = new Set();
  const visit = (f, stack = new Set()) => {
    if (affected.has(f) || stack.has(f)) return;        // 环/去重
    affected.add(f);
    for (const [file, deps] of Object.entries(graph))
      if (deps.includes(f)) visit(file, new Set([...stack, f]));
  };
  changed.forEach(f => visit(f));
  let tests = [...affected].filter(f => testSet.has(f));
  let truncated = false;
  if (!tests.length && fallbackAll) { tests = [...testSet]; truncated = tests.length > maxTests; }
  if (tests.length > maxTests) { tests = tests.slice(0, maxTests); truncated = true; }
  return { tests, truncated };
}

// 自测
const graph = {
  'src/util.ts': ['lodash'],                            // lodash 非内部
  'src/math.ts': ['src/util.ts'],
  'src/math.test.ts': ['src/math.ts'],
  'src/util.test.ts': ['src/util.ts'],
  'src/app.ts': ['src/math.ts', 'src/util.ts'],
  'src/app.test.ts': ['src/app.ts'],
};
const testFiles = ['src/math.test.ts', 'src/util.test.ts', 'src/app.test.ts'];

// 改 util.ts：三个测试都受影响
let r = selectTests(['src/util.ts'], graph, testFiles);
console.log(r.tests.sort().join(','));
// app.test.ts,math.test.ts,util.test.ts

// 改 math.test.ts 自身：只选自己
r = selectTests(['src/math.test.ts'], graph, testFiles);
console.log(r.tests.join(',') === 'src/math.test.ts');

// 改 README：无测试命中 -> 空
r = selectTests(['README.md'], graph, testFiles);
console.log(r.tests.length === 0);
r = selectTests(['README.md'], graph, testFiles, { fallbackAll: true });
console.log(r.tests.length === 3);

// 截断
r = selectTests(['src/util.ts'], graph, testFiles, { maxTests: 2 });
console.log(r.truncated === true && r.tests.length === 2);
```

**评分点**：
- 反向闭包正确（导入者递归 + 环保护 + 去重）；测试交集过滤
- 自身是测试文件直接命中；空命中兜底（fallbackAll 可选不默认——默认空是快检查的克制）
- 截断语义（truncated 标记供 CI 分片）；maxTests 边界
- 能说清「受影响选择是失效传播（RBL-635）的测试侧应用，位置在 pre-commit 的时延预算内」属于加分
