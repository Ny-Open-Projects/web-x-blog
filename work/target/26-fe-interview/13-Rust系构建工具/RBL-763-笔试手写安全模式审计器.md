## RBL-763：笔试：手写产物安全模式审计器（模式匹配 + 熵 + 来源）

**答**：实现 `auditSecurity(files)`。files: `{ name, code }[]`。内置模式：1) 'eval'：`eval(` 或 `new Function(` → warn；2) 'insecure-random'：`Math.random()` 出现在含 token/secret/otp/nonce/uuid 上下文的**同一语句/行**（同行 80 字符内）→ error；3) 'hardcoded-key'：`(api[_-]?key|secret)["']?\s*[:=]\s*["'][A-Za-z0-9]{16,}["']` → error；4) 'high-entropy'：32+ 长度 base64 样式串且前 80 字符上下文含 key/token → warn。返回 findings：`{ id, file, line, snippet }`（snippet 截 40 字符），按 file/line 排序去重。边界：空文件；同一行多命中都要报。

```javascript
const entropy = (s) => { const f = {}; for (const c of s) f[c] = (f[c] || 0) + 1;
  return -Object.values(f).reduce((a, n) => a + (n / s.length) * Math.log2(n / s.length), 0); };

function auditSecurity(files) {
  const findings = [];
  for (const f of files) {
    const lines = (f.code || '').split('\n');
    lines.forEach((line, i) => {
      const push = (id) => findings.push({ id, file: f.name, line: i + 1,
        snippet: line.trim().slice(0, 40) });
      if (/\beval\(|new Function\(/.test(line)) push('eval');
      if (/Math\.random\(\)/.test(line) &&
          /token|secret|otp|nonce|uuid/i.test(line.slice(Math.max(0, line.indexOf('Math.random') - 80),
            line.indexOf('Math.random') + 80)))
        push('insecure-random');
      const keyM = /(?:api[_-]?key|secret)["']?\s*[:=]\s*["']([A-Za-z0-9]{16,})["']/.exec(line);
      if (keyM) push('hardcoded-key');
      for (const m of line.matchAll(/(["'])([A-Za-z0-9+/=]{32,})\1/g)) {
        const ctx = line.slice(Math.max(0, m.index - 80), m.index);
        if (/key|token|secret/i.test(ctx) && entropy(m[2]) > 4.2) push('high-entropy');
      }
    });
  }
  // 排序去重（同 file+line+id 唯一）
  const seen = new Set();
  const out = findings.filter(x => {
    const k = `${x.file}:${x.line}:${x.id}`;
    if (seen.has(k)) return false;
    seen.add(k); return true;
  });
  out.sort((a, b) => a.file.localeCompare(b.file) || a.line - b.line);
  return out;
}

// 自测
const files = [
  { name: 'a.js', code: [
    'const t = "tok-" + Math.random().toString(36);',    // 同行上下文 -> error
    'render(Math.random());',                            // 无上下文 -> 不报
    'eval("1+1");',
    'const cfg = { apiKey: "AKIA1234567890abcdef12" };', // hardcoded
  ].join('\n') },
  { name: 'b.js', code: [
    'const secret = "Ab3xY9kL2mNpQrStUvWx8zK7jH5gF4dS";',  // 熵 + 上下文 -> high-entropy
    'const s = "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa";',   // 低熵不报
  ].join('\n') },
];
let r = auditSecurity(files);
console.log(r.map(x => x.id).join(','));
// insecure-random, eval, hardcoded-key, high-entropy（按 file/line 排序）
console.log(r.find(x => x.id === 'insecure-random').line === 1);
console.log(r.find(x => x.id === 'high-entropy').file === 'b.js');
console.log(r.find(x => x.id === 'eval').snippet.length <= 40);
console.log(auditSecurity([{ name: 'e.js', code: '' }]).length === 0);
```

**评分点**：
- 四模式实现正确：eval warn 级、random+上下文同语句判定、密钥正则、熵阈值 + 上下文过滤
- 低熵字符串不误报（熵计算 + 阈值）；snippet 截断
- 排序与去重（同 file/line/id）；空文件安全
- 能说清「产物审计对 define 注入与依赖引入问题的可见性优势」属于加分
