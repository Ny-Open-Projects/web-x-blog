## RBL-839：笔试：手写文档站死链检测器（站内链接 + 锚点）

**答**：实现 `auditLinks(pages, { redirects })`。pages: `Array<{ path, links: string[], anchors?: Set<string> }>`（anchors 为该页可用的锚点 id 集合）。规则：1) 站内链接（/ 开头）：页面部分（# 前split）不存在 → 'broken-page'；2) 含锚点：目标页 anchors 不含锚点 → 'broken-anchor'（页面存在但锚点错）；3) redirects: `Record<from, to>`——命中的链接按重定向后的目标判定；4) 外链（http）/mailto/纯锚点（#top）跳过；5) 返回 `{ broken: Array<{ from, to, type }>, ok }`。边界：无 links；目标页无 anchors 信息（无法校验锚点 → 只查页面）。

```javascript
function auditLinks(pages, { redirects = {} } = {}) {
  const known = new Map(pages.map(p => [p.path, p]));
  const broken = [];
  for (const p of pages) {
    for (const link of p.links ?? []) {
      if (!link.startsWith('/') || link === '/') continue;
      if (link.startsWith('/#')) continue;               // 纯锚点跳过
      const [raw, hash] = link.split('#');
      const target = redirects[raw] ?? raw;
      const page = known.get(target);
      if (!page) { broken.push({ from: p.path, to: link, type: 'broken-page' }); continue; }
      if (hash && page.anchors && !page.anchors.has(hash))
        broken.push({ from: p.path, to: link, type: 'broken-anchor' });
    }
  }
  return { broken, ok: broken.length === 0 };
}

// 自测
const pages = [
  { path: '/home', links: ['/guide/intro#setup', '/api', 'https://x.com', '#top', '/old-page'],
    anchors: new Set(['install']) },
  { path: '/guide/intro', links: ['/home#nonexistent'], anchors: new Set(['setup', 'usage']) },
  { path: '/api', links: [] },
];
let r = auditLinks(pages, { redirects: { '/old-page': '/home' } });
console.log(r.broken.some(b => b.type === 'broken-anchor' && b.to === '/home#nonexistent'));
console.log(r.broken.length === 1);                     // /old-page 重定向到 /home 有效；外链/纯锚点跳过
console.log(r.ok === false);

r = auditLinks(pages, {});                              // 无重定向：/old-page 死链
console.log(r.broken.some(b => b.type === 'broken-page' && b.to === '/old-page'));

// 锚点信息缺失只查页面
const p2 = [{ path: '/a', links: ['/api#foo'] }];
console.log(auditLinks(p2, {}).broken.length === 0);    // /api 存在但无 anchors 信息
console.log(auditLinks([], {}).ok === true);
```

**评分点**：
- 双级检测（页面级 broken-page 与锚点级 broken-anchor）；重定向映射后判定
- 外链/纯锚点/根路径跳过；锚点信息缺失时降级只查页面（不误报）
- 边界：无 links/空 pages
- 能说清「死链是文档质量门禁，锚点级检测需目标页 anchors 信息（构建期 slug 生成联动）」属于加分
