## RBL-702：笔试：手写包产物新鲜度校验与跨包失效传播

**答**：实现 `propagateFreshness(packages, changed, mode)`。packages: `Record<name, { sourceHash, distHash?, deps: string[], source: boolean }>`（distHash 为 null 表示未构建）；changed: 本次变更包名数组；mode: 'source' | 'dist'。规则：1) dist 模式：变更包标记「产物过期」（distHash 与 sourceHash 不符即过期）；2) 过期包的所有「dist 引用者」（依赖它的包且其 source=false 或 mode=dist）标记过期（递归）；3) source 模式：失效传播沿 source 引用（依赖链全部视为同一编译单元，返回合并失效集）；4) 返回 `{ stale: string[], rebuildOrder: string[] }`——rebuildOrder 是拓扑序（先建被依赖者）。边界：循环依赖抛错；changed 中不存在的包抛错。

```javascript
function propagateFreshness(packages, changed, mode) {
  for (const c of changed)
    if (!(c in packages)) throw new Error(`未知包: ${c}`);

  const stale = new Set();
  // 环检测（DFS on deps）
  const visit = (name, stack) => {
    if (stack.includes(name))
      throw new Error('依赖环: ' + [...stack.slice(stack.indexOf(name)), name].join(' -> '));
    for (const d of packages[name].deps) visit(d, [...stack, name]);
  };
  Object.keys(packages).forEach(n => visit(n, []));

  const isStale = (n) => {
    const p = packages[n];
    return p.distHash == null || p.distHash !== p.sourceHash;
  };
  // 传播：dist 引用（依赖过期包）
  const mark = (name) => {
    for (const [n, p] of Object.entries(packages)) {
      if (p.deps.includes(name) && (mode === 'dist' ? !p.source : true) && !stale.has(n)) {
        stale.add(n);
        mark(n);
      }
    }
  };
  for (const c of changed) {
    stale.add(c);
    mark(c);
  }
  // dist 模式下：dist 引用者的产物也过期（用过期产物构建的产物不可信）
  // 拓扑排序（stale 子集）
  const order = []; const done = new Set();
  const topo = (n, stack) => {
    if (done.has(n) || !stale.has(n)) return;
    if (stack.includes(n)) return;
    for (const d of packages[n].deps) topo(d, [...stack, n]);
    done.add(n); order.push(n);
  };
  [...stale].forEach(n => topo(n, []));
  return { stale: [...stale].sort(), rebuildOrder: order };
}

// 自测
const packages = {
  ui: { sourceHash: 's2', distHash: 's1', deps: [], source: false },   // ui 过期
  hooks: { sourceHash: 'h1', distHash: 'h1', deps: ['ui'], source: false },
  web: { sourceHash: 'w1', distHash: null, deps: ['ui', 'hooks'], source: true },
};
let r = propagateFreshness(packages, ['ui'], 'dist');
console.log(JSON.stringify(r.stale));                    // ["hooks","ui","web"]
console.log(r.rebuildOrder[0] === 'ui');                 // 先建被依赖者

r = propagateFreshness(packages, ['hooks'], 'dist');
console.log(r.stale.join(',') === 'hooks,web');          // ui 未受影响

let e; try {
  propagateFreshness({ a: { sourceHash: 'x', deps: ['b'], source: false },
                       b: { sourceHash: 'y', deps: ['a'], source: false } }, ['a'], 'dist');
} catch (x) { e = x; }
console.log(/依赖环/.test(e.message));

e = null; try { propagateFreshness(packages, ['ghost'], 'dist'); } catch (x) { e = x; }
console.log(/未知包/.test(e.message));
```

**评分点**：
- 新鲜度判定正确（distHash 缺失或不匹配都过期）；传播只沿 dist 引用（source 模式合并编译单元）
- 拓扑 rebuildOrder 保证被依赖者先建；环检测先于传播（提前暴露结构性问题）
- changed 校验；传播收敛（mark 递归去重）
- 能说清「stale 产物不报错所以必须构建期校验」属于加分
