## RBL-228：增量构建的观测：命中率与增量率怎么度量

**答**:
- 三个核心指标：缓存命中率（命中条目/应命中条目）、增量率（跳过模块数/总模块数）、端到端提速比（增量耗时/全量耗时）
- 采集点：构建工具的 stats（模块重转换计数）、缓存层日志（命中/miss 原因分类：指纹变/版本变/未见过）、watch 事件耗时
- miss 原因分类分析是最有价值的观测：指纹频繁变（配置抖动）vs 首次构建（正常）vs 版本升级（预期）——不同原因对策不同
- 看板化：CI 与本地分开统计（CI 冷环境命中率天然低），趋势监控防回归

```javascript
// miss 原因分类
const reasons = { fingerprint: 0, firstBuild: 0, toolVersion: 0 }
cache.on('miss', (reason) => reasons[reason]++)
// 看板：fingerprint 占比高 → 检查配置稳定性（如时间戳进配置）
```
