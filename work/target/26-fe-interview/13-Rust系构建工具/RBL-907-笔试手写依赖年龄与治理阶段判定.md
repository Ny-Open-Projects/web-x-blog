## RBL-907：笔试：手写依赖治理阶段判定器（Ratchet + 豁免）

**答**：实现 `gateDependencies(current, baseline, { stage })`。current: 本次 PR 引入的违规 `{ phantoms: Array<{ pkg, owner }>, multiVersions: Array<{ pkg, versions }> }`；baseline: 存量基线 `{ phantomCount, mvCount, exempt: Array<{ pkg, until }> }`. 规则：1) Ratchet：新增幽灵（不在基线也不在豁免期内）→ blocker；存量（在基线数内）→ 只在 stage='controlled' 时 blocker，'hemostasis'/'cleanup' 时 warn；2) 双版本：新增组合（pkg 不在基线 mv 列表）→ blocker（任何 stage——双版本直接恶化）；3) 豁免过期（until < now）→ 按新增处理；4) 返回 `{ blockers, warnings, ratchetOk }`（ratchetOk = 违规总数 ≤ 基线）。边界：baseline 缺失（全部按新增）；豁免列表空。

```javascript
function gateDependencies(current, baseline, { stage = 'hemostasis', now = new Date() } = {}) {
  const base = baseline ?? { phantomCount: 0, mvPkgs: [], exempt: [] };
  const exemptOf = (pkg) => base.exempt?.find(e => e.pkg === pkg && new Date(e.until) > now);
  const blockers = [], warnings = [];

  for (const p of current.phantoms ?? []) {
    if (exemptOf(p.pkg)) continue;                       // 豁免期内
    const isNew = !base.knownPhantoms?.some(k => k.pkg === p.pkg && k.owner === p.owner);
    if (isNew || stage === 'controlled') blockers.push({ type: 'phantom', ...p });
    else warnings.push({ type: 'phantom-legacy', ...p });
  }
  for (const mv of current.multiVersions ?? []) {
    if (exemptOf(mv.pkg)) continue;
    const known = base.mvPkgs?.includes(mv.pkg);
    if (!known || stage === 'controlled') blockers.push({ type: 'multi-version', ...mv });
    else warnings.push({ type: 'multi-version-legacy', ...mv });
  }
  const total = (current.phantoms?.length ?? 0) + (current.multiVersions?.length ?? 0);
  const baseTotal = (base.phantomCount ?? 0) + (base.mvPkgs?.length ?? 0);
  return { blockers, warnings, ratchetOk: total <= baseTotal || blockers.length === 0 };
}

// 自测
const baseline = { phantomCount: 3, mvPkgs: ['lodash'],
  knownPhantoms: [{ pkg: 'moment', owner: 'app' }, { pkg: 'old-ui', owner: 'app' }, { pkg: 'x', owner: 'b' }],
  exempt: [{ pkg: 'moment', until: '2099-01-01' }] };
let r = gateDependencies(
  { phantoms: [{ pkg: 'moment', owner: 'app' }, { pkg: 'new-lib', owner: 'app' }],
    multiVersions: [{ pkg: 'lodash', versions: ['3', '4'] }] },
  baseline, { stage: 'hemostasis' });
console.log(r.blockers.some(b => b.type === 'phantom' && b.pkg === 'new-lib'));   // 新增
console.log(!r.blockers.some(b => b.pkg === 'moment'));   // 豁免
console.log(r.blockers.some(b => b.type === 'multi-version'));    // 已知也 blocker? — 已知 + 非controlled → warn
console.log(r.warnings.some(w => w.type === 'multi-version-legacy'));
console.log(r.blockers.length === 1);

// controlled 硬门禁
r = gateDependencies(
  { phantoms: [{ pkg: 'moment', owner: 'app' }], multiVersions: [] }, baseline, { stage: 'controlled' });
console.log(r.blockers.some(b => b.type === 'phantom' && b.pkg === 'moment'));   // 存量也阻断

// 豁免过期
r = gateDependencies(
  { phantoms: [{ pkg: 'moment', owner: 'app' }], multiVersions: [] },
  { ...baseline, exempt: [{ pkg: 'moment', until: '2020-01-01' }] }, { stage: 'hemostasis' });
console.log(r.blockers.some(b => b.type === 'phantom'));

console.log(gateDependencies({ phantoms: [], multiVersions: [] }, baseline).ratchetOk === true);
```

**评分点**：
- Ratchet 语义正确：新增阻断、存量按阶段分级（止血 warn / controlled 阻断）、只紧不松
- 豁免三态（有效跳过/过期按新增）；双版本已知项在非 controlled 阶段降级 warn
- ratchetOk 判定（总数 ≤ 基线或无 blocker）；边界
- 能说清「门禁收紧节奏与存量消化同步，直接硬门禁会让团队对工具失去信任」属于加分
