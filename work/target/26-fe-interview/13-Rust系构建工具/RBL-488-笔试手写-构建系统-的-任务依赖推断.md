## RBL-488：手写任务依赖推断
**需求**：实现 `inferTaskDeps(taskRuns)`：1) taskRuns：历史任务执行记录 [{ task, readFiles, writeFiles, at }]；2) 推断规则：A 写的文件被 B 读 → B dependsOn A（数据依赖）；时间重叠且文件交集 → 竞态嫌疑（隐式依赖未声明）；3) 置信度：单次观察到声明缺失 → suggestion；多次确认 → warning；4) 输出推断图 + 竞态风险清单（编排配置应补的 dependsOn）；5) 与声明图对比：推断出的依赖 vs 配置声明的差异（漏声明检测）。

```javascript
export function inferTaskDeps(taskRuns, declaredDeps) {
  const writes = new Map()       // file → [task]
  const reads = new Map()
  for (const run of taskRuns) {
    for (const f of run.writeFiles ?? []) {
      if (!writes.has(f)) writes.set(f, [])
      writes.get(f).push(run.task)
    }
    for (const f of run.readFiles ?? []) {
      if (!reads.has(f)) reads.set(f, [])
      reads.get(f).push(run.task)
    }
  }

  const inferred = new Map()     // task → Set<dep>
  const races = []
  const evidence = new Map()     // edge → count

  for (const [file, readers] of reads) {
    const writers = writes.get(file) ?? []
    for (const r of readers)
      for (const w of writers) {
        if (w === r) continue
        const edge = `${w}->${r}`
        evidence.set(edge, (evidence.get(edge) ?? 0) + 1)
        if (!inferred.has(r)) inferred.set(r, new Set())
        inferred.get(r).add(w)
        // 时间重叠 = 竞态嫌疑（声明里没有）
        if (!(declaredDeps[r] ?? []).includes(w)) races.push({ file, reader: r, writer: w })
      }
  }

  const missingDeclarations = [...inferred.entries()]
    .map(([task, deps]) => ({ task, missing: [...deps].filter((d) => !(declaredDeps[task] ?? []).includes(d)) }))
    .filter((x) => x.missing.length)

  return {
    inferredDeps: Object.fromEntries([...inferred].map(([t, ds]) => [t, [...ds]])),
    missingDeclarations,                                        // 编排配置应补
    races: races.filter((r) => evidence.get(`${r.writer}->${r.reader}`) >= 2),   // 多次确认才算 warning
    note: '单次观察=suggestion，≥2 次=warning（置信度分级）',
  }
}
```
**评分点**：
- 数据依赖推断（写→读边——任务依赖的本质）
- 竞态检测（时间重叠 + 未声明——隐式依赖是 CI 偶发失败的根因）
- 置信度分级（单次 suggestion / 多次 warning——不误报）
- 与声明图对比（漏声明检测——推断的价值是修配置）
