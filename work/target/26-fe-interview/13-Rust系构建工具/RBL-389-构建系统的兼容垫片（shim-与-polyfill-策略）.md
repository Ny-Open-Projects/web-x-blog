## RBL-389：构建系统的兼容垫片策略

**答**:
- 垫片场景：新工具兼容旧配置语义（Rspack 兼容 webpack 特有行为）、新 preset 兼容旧业务配置（映射到新实现）——垫片让迁移平滑
- 垫片设计：语义对齐（旧行为精确模拟——垫片错了比不垫更糟）+ 使用计数（垫片被多少项目用着——决定保留时长）+ 标记与日志（垫片路径可观测）
- 退出策略：垫片不是永久债务——使用计数归零后按废弃周期移除；垫片文档注明「预期移除版本」
- 与 codemod 配合：垫片过渡 + codemod 引导迁移——垫片降低迁移门槛，codemod 完成真正迁移

```text
设计：语义精确对齐 + 使用计数 + 可观测标记
退出：计数归零 → 废弃周期 → 移除
配合：垫片过渡 + codemod 真迁移
```
