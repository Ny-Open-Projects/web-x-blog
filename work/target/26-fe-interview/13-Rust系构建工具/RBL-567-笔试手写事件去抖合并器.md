## RBL-567：笔试：手写文件事件去抖合并器（含窗口与风暴降级）

**答**：实现 `createMerger({ windowMs, stormThreshold, onFlush })`，`push(path, kind)` 接收文件事件（kind ∈ add/change/unlink）。同路径窗口内合并（优先级 change > add > unlink）；窗口静默 `windowMs` 后 flush，回调收到去重后的 `{ path, kind }[]`；若待 flush 集合超过 `stormThreshold`，改调 `onFlush(batch, { storm: true })` 供上层走全量重建。要求：连续 push 不重置已过半的窗口（可选进阶：滑动窗口），支持 `dispose()` 清理。

```javascript
function createMerger({ windowMs = 200, stormThreshold = 50, onFlush }) {
  const pending = new Map();       // path -> kind
  let timer = null;
  const rank = { unlink: 0, add: 1, change: 2 };       // change 优先保留

  function schedule() {
    if (timer) return;
    timer = setTimeout(flush, windowMs);
  }
  function flush() {
    timer = null;
    if (pending.size === 0) return;
    const batch = [...pending.entries()].map(([path, kind]) => ({ path, kind }));
    pending.clear();
    onFlush(batch, { storm: batch.length > stormThreshold });
  }
  return {
    push(path, kind) {
      const prev = pending.get(path);
      pending.set(path, prev && rank[prev] >= rank[kind] ? prev : kind);
      schedule();
    },
    dispose() { clearTimeout(timer); timer = null; pending.clear(); },
  };
}

// 自测
const events = [];
const m = createMerger({ windowMs: 50, stormThreshold: 3,
  onFlush: (b, meta) => events.push({ b: b.map(x => x.path + ':' + x.kind), storm: meta.storm }) });
m.push('/a.js', 'change'); m.push('/a.js', 'change');       // 去重
m.push('/b.js', 'unlink'); m.push('/b.js', 'change');       // 保留 change
await sleep(80);
m.push('/c.js', 'add'); m.push('/d.js', 'add'); m.push('/e.js', 'add'); m.push('/f.js', 'add');
await sleep(80); m.dispose();
// 断言：events[0].b = ['a.js:change','b.js:change']，events[1].storm === true
```

**评分点**：
- 同路径合并的 kind 优先级正确（change > add > unlink），防编辑器多事件误判为删除
- 窗口去抖正确（连续 push 不产生多次 flush），storm 标记按阈值触发供全量降级
- dispose 后无悬挂 timer、无后续 flush（资源清理边界）
- 大 O 意识：push O(1)（Map 操作），flush O(n)
