## RBL-696：笔试：手写 i18n 缺失与冗余审计器（跨语言一致性 + 分级阻断）

**答**：实现 `auditI18n({ used, translations, severities, reserve })`。used: 代码中使用的 key 集合（数组）；translations: `Record<lang, Record<key, string>>`；severities: `Record<lang, 'error'|'warn'>`；reserve: 保留 key（动态场景豁免冗余检测）。输出 `{ missing: Array<{ lang, key, level }>, unused: Array<{ lang, key }>, ok }`：1) missing：used 中某语言缺的 key，level 取 severities[lang]；2) unused：翻译存在但未使用且不在 reserve 的 key（冗余诊断）；3) ok = 所有 missing 无 level==='error'。边界：空 used（全部 unused 报冗余）；severities 缺语言按 'warn'。

```javascript
function auditI18n({ used = [], translations, severities = {}, reserve = [] }) {
  const usedSet = new Set(used);
  const missing = [], unused = [];
  for (const lang of Object.keys(translations)) {
    const dict = translations[lang];
    for (const key of usedSet)
      if (!(key in dict))
        missing.push({ lang, key, level: severities[lang] ?? 'warn' });
    for (const key of Object.keys(dict))
      if (!usedSet.has(key) && !reserve.includes(key))
        unused.push({ lang, key });
  }
  const ok = !missing.some(m => m.level === 'error');
  return { missing, unused, ok };
}

// 自测
const translations = {
  zh: { 'nav.home': '首页', 'nav.about': '关于', 'btn.buy': '购买', 'old.page': '旧页' },
  en: { 'nav.home': 'Home', 'btn.buy': 'Buy' },          // en 缺 nav.about
  xx: {},                                                // 全缺
};
const r = auditI18n({
  used: ['nav.home', 'nav.about', 'btn.buy'],
  translations,
  severities: { zh: 'error', en: 'error', xx: 'warn' },
});
console.log(r.ok === false);                             // en 缺 error 级
console.log(r.missing.filter(m => m.level === 'error').length === 2);  // en.about + (btn? zh 有)
console.log(r.missing.some(m => m.lang === 'xx' && m.level === 'warn'));

// 冗余
console.log(r.unused.some(u => u.lang === 'zh' && u.key === 'old.page'));

// reserve 豁免
const r2 = auditI18n({
  used: ['nav.home'],
  translations: { zh: { 'nav.home': '首页', 'status.a': 'A', 'status.b': 'B' } },
  reserve: ['status.a', 'status.b'],                     // 动态拼接保留
});
console.log(r2.unused.length === 0 && r2.ok === true);

// 空使用
const r3 = auditI18n({ used: [], translations: { zh: { a: '1' } } });
console.log(r3.unused.length === 1 && r3.ok === true);
```

**评分点**：
- missing 按语言分级（severity 缺省 warn），ok 由 error 级缺失决定
- unused 冗余检测跨语言对称；reserve 豁免动态拼接场景（防误删）
- 边界：空 used 报全量冗余、空语言字典全缺不崩
- 能说清「正式语言缺失阻断发布（error），低优先语言警告」的分级策略属于加分
