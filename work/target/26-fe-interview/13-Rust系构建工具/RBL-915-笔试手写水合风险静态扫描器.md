## RBL-915：笔试：手写水合风险静态扫描器（环境引用 + locale）

**答**：实现 `scanHydrationRisk(code, { inServerComponent })`。检测：1) 顶层/渲染路径直接引用 `window.`/`document.`/`localStorage.`（不在 useEffect/函数体/typeof 守卫内——简化：行内出现且行不以 if(typeof 开头且不在 function/=> 声明的行块内——用「行首缩进 = 0 且无 function/=>/useEffect」近似顶层）；2) `Date.now()`/`Math.random()` 直接出现在 JSX 返回的表达式中（行含 JSX 特征 `}` 前 `{` 或 return ( 之后到 ;)——简化：行含 Date.now/Math.random 且含 `{`）；3) `Intl`/`toLocaleString` 调用未传 locale 参数（Intl.xxxFormat( 后第一个参数不是引号字符串）→ warn；4) 返回 `{ risks: Array<{ type, line, severity }>, ok }`。边界：空代码；inServerComponent=true 时 window 引用升级 severity 'error'。

```javascript
function scanHydrationRisk(code = '', { inServerComponent = false } = {}) {
  const risks = [];
  const lines = code.split('\n');
  let inFunc = 0;
  lines.forEach((line, i) => {
    const t = line.trim();
    if (/function|=>|useEffect\(/.test(t)) inFunc++;     // 进入函数体（近似）
    if (/\}\)/.test(t) && inFunc > 0) inFunc--;          // 粗略出函数
    const topLevel = t.startsWith('') && inFunc === 0;   // 顶层近似
    if (/\b(window|document|localStorage)\./.test(t) && !/^if\s*\(\s*typeof/.test(t)) {
      risks.push({ type: 'env-ref', line: i + 1,
        severity: inServerComponent ? 'error' : topLevel ? 'warn' : 'info' });
    }
    if (/(Date\.now\(\)|Math\.random\(\))/.test(t) && /\{/.test(t))
      risks.push({ type: 'time-random', line: i + 1, severity: 'warn' });
    if (/Intl\.\w+Format\(\s*(?![`'"])/.test(t) && !/toLocaleString\(\s*[`'"]/.test(line))
      risks.push({ type: 'implicit-locale', line: i + 1, severity: 'warn' });
  });
  return { risks, ok: !risks.some(r => r.severity === 'error') };
}

// 自测
const code = [
  "const el = document.getElementById('x');",           // 顶层 env（warn / server error）
  "useEffect(() => { console.log(window.innerWidth); }, []);",   // 函数体 info
  "if (typeof window !== 'undefined') init();",         // 守卫跳过
  "return <span>{Date.now()}</span>;",                  // time-random
  "new Intl.DateTimeFormat().format(d);",               // 隐式 locale
  "new Intl.DateTimeFormat('zh-CN').format(d);",        // ok
].join('\n');
let r = scanHydrationRisk(code);
console.log(r.risks.filter(x => x.type === 'env-ref').length >= 1);
console.log(r.risks.some(x => x.type === 'time-random' && x.line === 4));
console.log(r.risks.some(x => x.type === 'implicit-locale' && x.line === 5));
console.log(!r.risks.some(x => x.line === 6));           // 显式 locale 不报
console.log(r.ok === true);                              // 非 server 无 error

r = scanHydrationRisk(code.split('\n')[0], { inServerComponent: true });
console.log(r.risks[0].severity === 'error' && r.ok === false);
console.log(scanHydrationRisk('', {}).risks.length === 0);
```

**评分点**：
- 三类检测实现（env 引用含 typeof 守卫豁免、JSX 内时间随机、隐式 locale）；顶层/函数体的 severity 分级近似
- inServerComponent 升级为 error（server bundle 扫描更严——RBL-779）；显式 locale 豁免
- 边界：空代码、守卫行跳过
- 能说清「静态扫描是水合防线的构建期半边，时间类必须数据单源修复」属于加分
