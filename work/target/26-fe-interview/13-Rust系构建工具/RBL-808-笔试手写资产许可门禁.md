## RBL-808：笔试：手写资产许可门禁（scope + notice + 注存活）

**答**：实现两部分。1) `auditLicenses(assets, registry, { distMode })`：assets: `{ id }[]`；registry: `Record<id, { license, scope: string[], notice?: string, required?: boolean }>`。规则：未注册 → problem；scope 不含 distMode → problem；required 且缺 notice → problem；返回 `{ problems, notices }`（有 notice 的资产聚合文本，排序）。2) `verifyLegalComments(source, minified)`：提取源码 `/*! 内容 */` 注释的前 40 字符，minified 缺失任一 → 抛错列出缺失。边界：registry 空（全部 problem）；source 无 legal 注释（通过）。

```javascript
function auditLicenses(assets, registry = {}, { distMode = 'self-host' } = {}) {
  const problems = [], notices = [];
  for (const a of assets) {
    const lic = registry[a.id];
    if (!lic) { problems.push(`${a.id}: 未注册许可信息`); continue; }
    if (!lic.scope?.includes(distMode))
      problems.push(`${a.id}: 许可 ${lic.license} 不允许 ${distMode} 分发`);
    if (lic.required && !lic.notice)
      problems.push(`${a.id}: 许可要求署名但缺 notice`);
    if (lic.notice) notices.push(`[${a.id}] ${lic.notice}`);
  }
  return { problems, notices: notices.sort() };
}

function verifyLegalComments(source, minified) {
  const legal = [...(source ?? '').matchAll(/\/\*!([\s\S]*?)\*\//g)]
    .map(m => m[1].trim().slice(0, 40));
  const missing = legal.filter(l => !minified.includes(l));
  if (missing.length)
    throw new Error(`许可注释被压缩剥除: ${missing.join(' | ')}——压缩器需保留 /*! */`);
  return { ok: true, checked: legal.length };
}

// 自测
const registry = {
  'font-brand': { license: 'Commercial', scope: ['self-host', 'cdn'], notice: 'BrandFont (c) X Co.', required: true },
  'hero.png': { license: 'CC-BY', scope: ['self-host'], notice: 'Photo by Y (CC-BY)' },
  'internal-logo': { license: 'Internal', scope: ['self-host', 'cdn'] },
};
let r = auditLicenses(['font-brand', 'hero.png', 'internal-logo'], registry, { distMode: 'self-host' });
console.log(r.problems.length === 0 && r.notices.length === 2);
console.log(r.notices[0].startsWith('[font-brand]'));    // 排序后 font-brand 在前

// cdn 分发：CC-BY 图片不允许
r = auditLicenses(['hero.png'], registry, { distMode: 'cdn' });
console.log(r.problems[0].includes('不允许 cdn'));

// 缺 notice
r = auditLicenses(['x'], { x: { license: 'MIT', scope: ['self-host'], required: true } });
console.log(r.problems[0].includes('缺 notice'));
console.log(auditLicenses(['z'], {}).problems[0].includes('未注册'));

// legal 注存活
const src = '/*! MIT (c) foo */ const a=1; /*! Custom (c) bar */ const b=2;';
console.log(verifyLegalComments(src, '/*! MIT (c) foo */const a=1;/*! Custom (c) bar */const b=2;').checked === 2);
let e; try { verifyLegalComments(src, 'const a=1;const b=2;'); } catch (x) { e = x; }
console.log(/剥除/.test(e.message) && e.message.includes('Custom'));
console.log(verifyLegalComments('const a=1;', 'const a=1;').checked === 0);
```

**评分点**：
- 三向门禁（未注册/scope 越界/缺 notice）；notices 聚合排序（THIRD-PARTY-NOTICES 的原料）
- legal 注提取（/*! 前缀）与存活性校验（40 字符前缀匹配容忍格式化）；缺失抛错含内容
- 边界：空 registry、无 legal 注通过
- 能说清「压缩器默认剥注释导致许可违规是静默的，门禁把法律要求机械化」属于加分
