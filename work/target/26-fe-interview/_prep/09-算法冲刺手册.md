## 1. 大厂笔试到底考什么

### 1.1 三种形态，准备方式完全不同

| 形态 | 典型公司 | 特征 | 你要练的 |
|---|---|---|---|
| **核心代码模式** | 字节、美团（部分）、快手 | LeetCode 原样式，只写函数体，输入输出由评测机处理 | 算法本身、复杂度 |
| **ACM 模式** | 阿里、腾讯（部分）、华为、银行系 | 自己读 stdin、自己拼输出、多组用例 | 输入解析 + 算法 + 输出格式，**三处都可能挂** |
| **在线 IDE 手写** | 面试中现场写 | 面试官看着你写，边写边讲 | 边写边解释、写错能自己发现 |

**关键差异**：ACM 模式里，算法对了但因输入解析错而 0 分的情况极常见。所以 `22-ACM模式与大厂笔试实操.md` 那 15 篇要单独练，尤其是 stdin 读取和多组输入循环。

### 1.2 时间与部分分

- 通常 **2~4 道题 / 90~120 分钟**，难度分布多为「1 简单 + 2 中等 + 1 困难」。
- **部分分是真实存在的**：暴力解过 30%~60% 用例也是分。**先交能跑的暴力，再优化**，这是最重要的考场策略。
- 超时（TLE）优先查：是否重复计算、是否用了 O(n²) 而 n=10⁵、是否有死循环。
- 超内存（MLE）优先查：是否开了 n×n 数组、是否递归太深、是否字符串反复拼接。

### 1.3 前端岗算法题的真实难度

不要被"前端不用刷算法"骗了。实际情况：

- **一面**：偶尔一道简单题（两数之和、有效括号、反转链表），主要看你写不写得出来。
- **二面/三面**：中等题为主（二叉树路径、滑动窗口、DP 入门），会追问复杂度和优化。
- **笔试环节**：中等偏难，DP、图、堆是分水岭。
- **手写题**（前端特有）：防抖节流、Promise、深拷贝、EventEmitter、虚拟 DOM diff——这部分在 `06-算法与手写/` 的 410 道 HW 里，**优先级高于 LeetCode**。

**结论**：算法要能过线（中等题 20 分钟内写对 + 讲清复杂度），手写题要能秒杀。不要为了刷 hard 题放弃手写。

## 2. 题型识别决策树

看到题目的第一分钟，先做这个判断，再动手。**90% 的题错在方向选错，不是代码写错。**

```
题目在问什么？
│
├─ 求「所有方案 / 所有组合 / 所有路径」
│   └─ 回溯（DFS + 撤销选择）           → 11-回溯与DFS
│
├─ 求「最少步数 / 最短距离 / 能否到达」
│   └─ BFS（层序扩展，第一次到达即最优） → 12-BFS与图
│
├─ 求「最优值」（最大/最小/最长/最少），且能拆成子问题
│   ├─ 有「选或不选」→ 背包 / 打家劫舍    → 16-背包与区间
│   ├─ 有「前 i 个元素」→ 线性 DP         → 15-线性与序列
│   ├─ 有「区间 [i,j]」→ 区间 DP          → 16-背包与区间
│   └─ 有「树结构」→ 树形 DP              → 09-树属性与路径
│
├─ 求「最优值」，且能证明局部最优=全局最优
│   └─ 贪心（排序后一次扫描）             → 17-贪心
│
├─ 数组有序 / 答案有单调性
│   └─ 二分（含「二分答案」）             → 13-二分查找
│
├─ 「连续子数组 / 连续子串」满足某条件
│   ├─ 条件随窗口扩大单调 → 滑动窗口      → 03-双指针与滑窗
│   └─ 求「和等于 K 的个数」→ 前缀和+哈希  → 01-数组与矩阵
│
├─ 「第 K 大 / 第 K 小 / 前 K 个」
│   └─ 堆（O(n log k)）或快速选择（O(n)） → 07-堆与TopK
│
├─ 「下一个更大/更小」「柱状图面积」
│   └─ 单调栈                             → 06-栈与单调栈
│
├─ 「括号匹配 / 嵌套结构 / 撤销」
│   └─ 栈                                 → 06-栈与单调栈
│
├─ 「连通性 / 合并集合 / 环检测（无向）」
│   └─ 并查集                             → 20-Trie并查集
│
├─ 「依赖顺序 / 有向无环」
│   └─ 拓扑排序（BFS 入度法）             → 12-BFS与图
│
├─ 「前缀匹配 / 单词查找」
│   └─ Trie                               → 20-Trie并查集
│
├─ 「边改边查区间」（动态区间查询）
│   └─ 线段树 / 树状数组                  → 20-Trie并查集
│
├─ 「链表」相关
│   └─ 哑结点 + 快慢指针 + 三指针反转      → 05-链表
│
└─ 「设计一个数据结构，要求 O(1)」
    └─ 哈希 + 双向链表 / 双栈 / 双堆       → 19-设计题
```

**三个高频陷阱**：

1. **「子数组」vs「子序列」**：子数组必须连续（滑窗/前缀和），子序列可不连续（DP/贪心）。看错这两个字，方法全错。
2. **「返回下标」vs「返回值」**：影响是否需要存 Map、是否要处理重复。
3. **「原地修改」**：一旦要求 O(1) 空间，哈希表方案直接作废，必须换双指针/原地交换。

## 3. 数据规模反推算法（最实用的考场技巧）

**看 n 的大小，直接排除掉不可能的算法。** 这一步能在 10 秒内锁定方向。

| n 的范围 | 可接受的复杂度 | 常见算法 |
|---|---|---|
| n ≤ 10 | O(n!)、O(nⁿ) | 全排列、暴力枚举、N 皇后 |
| n ≤ 20 | O(2ⁿ) | 状态压缩 DP、子集枚举、回溯 |
| n ≤ 100 | O(n³) | 区间 DP、Floyd、三重循环 |
| n ≤ 500 | O(n³) 勉强 / O(n²) 稳 | 二维 DP、矩阵运算 |
| n ≤ 5×10³ | O(n²) | 二维 DP、双重循环 |
| n ≤ 10⁵ | **O(n log n)** | 排序、二分、堆、线段树、归并 |
| n ≤ 10⁶ | **O(n)** | 双指针、哈希、单调栈、计数 |
| n ≤ 10⁹ | **O(log n)、O(√n)** | 二分答案、快速幂、数学公式 |

**示例**：题目说"数组长度 10⁵，求最长递增子序列"。
→ n=10⁵ 排除 O(n²) 的经典 DP（那是 n≤5000 的解法），必须用**贪心 + 二分**（O(n log n)），即 `patience sorting`。
→ 如果面试官只要求讲思路，也要主动说出"O(n²) 会超时，所以用贪心+二分"——这一句就是加分项。

## 5. 20 个核心模板（背下来，考场直接默写）

### 5.1 二分查找（双闭区间）

```javascript
function binarySearch(nums, target) {
  let left = 0, right = nums.length - 1;      // 双闭 [left, right]
  while (left <= right) {                      // 注意 <=
    const mid = left + ((right - left) >> 1);  // 防溢出
    if (nums[mid] === target) return mid;
    if (nums[mid] < target) left = mid + 1;    // 注意 +1
    else right = mid - 1;                      // 注意 -1
  }
  return -1;
}
```

**变体：找左边界**（第一个 ≥ target 的位置）

```javascript
function lowerBound(nums, target) {
  let left = 0, right = nums.length;           // 左闭右开 [left, right)
  while (left < right) {                       // 注意 <
    const mid = left + ((right - left) >> 1);
    if (nums[mid] < target) left = mid + 1;
    else right = mid;                          // 不收窄到 mid-1，保留候选
  }
  return left;                                 // 可能等于 nums.length
}
```

### 5.2 二分答案（"最小化最大值" / "最大化最小值"）

```javascript
function binaryAnswer(lo, hi, feasible) {
  while (lo < hi) {
    const mid = lo + ((hi - lo) >> 1);
    if (feasible(mid)) hi = mid;    // mid 可行 → 试着更小
    else lo = mid + 1;              // mid 不可行 → 必须更大
  }
  return lo;
}
// 用法：爱吃香蕉的珂珂 —— feasible(speed) = 以 speed 吃完是否 ≤ h 小时
```

### 5.3 滑动窗口（可变长）

```javascript
function slidingWindow(s) {
  const need = new Map(), window = new Map();
  let left = 0, valid = 0, ans = 0;
  for (let right = 0; right < s.length; right++) {
    // 1. 右扩：把 s[right] 纳入窗口
    const c = s[right];
    window.set(c, (window.get(c) || 0) + 1);
    if (window.get(c) === need.get(c)) valid++;

    // 2. 左缩：窗口不满足条件时收缩
    while (valid === need.size) {
      ans = Math.max(ans, right - left + 1);   // 3. 更新答案
      const d = s[left];
      if (window.get(d) === need.get(d)) valid--;
      window.set(d, window.get(d) - 1);
      left++;
    }
  }
  return ans;
}
```

### 5.4 前缀和 + 哈希（求和为 K 的子数组个数）

```javascript
function subarraySum(nums, k) {
  const map = new Map([[0, 1]]);   // 前缀和 0 出现 1 次（空数组）
  let sum = 0, count = 0;
  for (const x of nums) {
    sum += x;
    count += map.get(sum - k) || 0; // 之前的某个前缀和 = sum - k
    map.set(sum, (map.get(sum) || 0) + 1);
  }
  return count;
}
```

### 5.5 回溯（组合/排列通用骨架）

```javascript
function backtrack(nums) {
  const res = [], path = [], used = new Array(nums.length).fill(false);
  const dfs = () => {
    if (path.length === nums.length) { res.push([...path]); return; }  // 收集时深拷贝
    for (let i = 0; i < nums.length; i++) {
      if (used[i]) continue;                       // 排列：不能重复用
      // 组合去重：if (i > 0 && nums[i] === nums[i-1] && !used[i-1]) continue;
      used[i] = true;  path.push(nums[i]);         // 做选择
      dfs();                                        // 递归
      path.pop();      used[i] = false;            // 撤销选择
    }
  };
  dfs();
  return res;
}
```

### 5.6 BFS 最短步数

```javascript
function bfs(start, isGoal, getNeighbors) {
  const queue = [start];
  const visited = new Set([start]);   // 入队时标记，不是出队时！
  let step = 0;
  while (queue.length) {
    const size = queue.length;        // 关键：按层处理
    for (let i = 0; i < size; i++) {
      const cur = queue.shift();
      if (isGoal(cur)) return step;
      for (const nxt of getNeighbors(cur)) {
        if (visited.has(nxt)) continue;
        visited.add(nxt);
        queue.push(nxt);
      }
    }
    step++;
  }
  return -1;
}
```

### 5.7 DFS 岛屿（网格遍历）

```javascript
function numIslands(grid) {
  const m = grid.length, n = grid[0].length;
  let count = 0;
  const dfs = (i, j) => {
    if (i < 0 || i >= m || j < 0 || j >= n || grid[i][j] !== '1') return;
    grid[i][j] = '0';                          // 标记已访问（原地修改省空间）
    dfs(i + 1, j); dfs(i - 1, j); dfs(i, j + 1); dfs(i, j - 1);
  };
  for (let i = 0; i < m; i++)
    for (let j = 0; j < n; j++)
      if (grid[i][j] === '1') { count++; dfs(i, j); }
  return count;
}
```

### 5.8 拓扑排序（BFS 入度法）

```javascript
function topoSort(numCourses, prerequisites) {
  const graph = Array.from({ length: numCourses }, () => []);
  const indeg = new Array(numCourses).fill(0);
  for (const [a, b] of prerequisites) {        // b -> a
    graph[b].push(a); indeg[a]++;
  }
  const queue = [];
  for (let i = 0; i < numCourses; i++) if (indeg[i] === 0) queue.push(i);
  const order = [];
  while (queue.length) {
    const cur = queue.shift();
    order.push(cur);
    for (const nxt of graph[cur]) {
      if (--indeg[nxt] === 0) queue.push(nxt);
    }
  }
  return order.length === numCourses ? order : [];   // 长度不等 → 有环
}
```

### 5.9 并查集（路径压缩 + 按秩合并）

```javascript
class UnionFind {
  constructor(n) {
    this.parent = Array.from({ length: n }, (_, i) => i);
    this.rank = new Array(n).fill(0);
    this.count = n;                            // 连通分量数
  }
  find(x) {
    if (this.parent[x] !== x) this.parent[x] = this.find(this.parent[x]);  // 路径压缩
    return this.parent[x];
  }
  union(a, b) {
    const ra = this.find(a), rb = this.find(b);
    if (ra === rb) return false;
    if (this.rank[ra] < this.rank[rb]) this.parent[ra] = rb;
    else if (this.rank[ra] > this.rank[rb]) this.parent[rb] = ra;
    else { this.parent[rb] = ra; this.rank[ra]++; }
    this.count--;
    return true;
  }
}
```

### 5.10 Trie（前缀树）

```javascript
class TrieNode {
  constructor() { this.children = new Map(); this.isEnd = false; }
}
class Trie {
  constructor() { this.root = new TrieNode(); }
  insert(word) {
    let node = this.root;
    for (const ch of word) {
      if (!node.children.has(ch)) node.children.set(ch, new TrieNode());
      node = node.children.get(ch);
    }
    node.isEnd = true;
  }
  search(word) {
    const node = this.traverse(word);
    return !!node && node.isEnd;      // 注意：必须存在且是末尾
  }
  startsWith(prefix) { return !!this.traverse(prefix); }
  traverse(s) {
    let node = this.root;
    for (const ch of s) {
      if (!node.children.has(ch)) return null;
      node = node.children.get(ch);
    }
    return node;
  }
}
```

### 5.11 单调栈（下一个更大元素）

```javascript
function nextGreater(nums) {
  const n = nums.length, res = new Array(n).fill(-1);
  const stack = [];                     // 存下标，栈内对应值递减
  for (let i = 0; i < n; i++) {
    while (stack.length && nums[stack[stack.length - 1]] < nums[i]) {
      res[stack.pop()] = nums[i];       // 出栈即找到答案
    }
    stack.push(i);
  }
  return res;
}
```

### 5.12 小顶堆（手写，TopK 必备）

```javascript
class MinHeap {
  constructor() { this.h = []; }
  get size() { return this.h.length; }
  peek() { return this.h[0]; }
  push(v) {
    this.h.push(v);
    let i = this.h.length - 1;
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (this.h[p] <= this.h[i]) break;
      [this.h[p], this.h[i]] = [this.h[i], this.h[p]];
      i = p;
    }
  }
  pop() {
    const top = this.h[0], last = this.h.pop();
    if (this.h.length) {
      this.h[0] = last;
      let i = 0;
      for (;;) {
        const l = 2 * i + 1, r = l + 1;
        let m = i;
        if (l < this.h.length && this.h[l] < this.h[m]) m = l;
        if (r < this.h.length && this.h[r] < this.h[m]) m = r;
        if (m === i) break;
        [this.h[m], this.h[i]] = [this.h[i], this.h[m]];
        i = m;
      }
    }
    return top;
  }
}
// 求第 K 大：维护大小为 k 的小顶堆，堆顶就是答案
```

### 5.13 快排（含三路划分）

```javascript
function quickSort(nums, lo = 0, hi = nums.length - 1) {
  if (lo >= hi) return nums;
  const pivot = nums[lo + ((hi - lo) >> 1)];
  let i = lo, lt = lo, gt = hi;         // [lo,lt) < p, [lt,gt] == p, (gt,hi] > p
  while (i <= gt) {
    if (nums[i] < pivot) { [nums[i], nums[lt]] = [nums[lt], nums[i]]; i++; lt++; }
    else if (nums[i] > pivot) { [nums[i], nums[gt]] = [nums[gt], nums[i]]; gt--; }
    else i++;
  }
  quickSort(nums, lo, lt - 1);
  quickSort(nums, gt + 1, hi);
  return nums;
}
```

### 5.14 归并排序（求逆序对的载体）

```javascript
let count = 0;                                  // 逆序对计数
function mergeSort(nums, lo = 0, hi = nums.length - 1) {
  if (lo >= hi) return;
  const mid = lo + ((hi - lo) >> 1);
  mergeSort(nums, lo, mid);
  mergeSort(nums, mid + 1, hi);
  const tmp = [];
  let i = lo, j = mid + 1;
  while (i <= mid && j <= hi) {
    if (nums[i] <= nums[j]) tmp.push(nums[i++]);
    else { count += mid - i + 1; tmp.push(nums[j++]); }   // 左边剩余全是逆序
  }
  while (i <= mid) tmp.push(nums[i++]);
  while (j <= hi) tmp.push(nums[j++]);
  for (let k = 0; k < tmp.length; k++) nums[lo + k] = tmp[k];
}
```

### 5.15 01 背包（一维滚动）

```javascript
function knapsack(weights, values, capacity) {
  const dp = new Array(capacity + 1).fill(0);   // dp[j] = 容量 j 的最大价值
  for (let i = 0; i < weights.length; i++) {
    for (let j = capacity; j >= weights[i]; j--) {   // 必须逆序！
      dp[j] = Math.max(dp[j], dp[j - weights[i]] + values[i]);
    }
  }
  return dp[capacity];
}
// 完全背包：内层改成正序 for (j = w; j <= capacity; j++)
```

### 5.16 LIS（贪心 + 二分，O(n log n)）

```javascript
function lengthOfLIS(nums) {
  const tails = [];                    // tails[i] = 长度 i+1 的递增子序列的最小结尾
  for (const x of nums) {
    let lo = 0, hi = tails.length;     // 找第一个 >= x 的位置
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      if (tails[mid] < x) lo = mid + 1;
      else hi = mid;
    }
    tails[lo] = x;                     // 替换或追加
  }
  return tails.length;
}
```

### 5.17 LRU（Map 插入序版）

```javascript
class LRUCache {
  constructor(capacity) { this.cap = capacity; this.map = new Map(); }
  get(key) {
    if (!this.map.has(key)) return -1;
    const val = this.map.get(key);
    this.map.delete(key); this.map.set(key, val);   // 重新插入 = 移到最新
    return val;
  }
  put(key, value) {
    if (this.map.has(key)) this.map.delete(key);
    else if (this.map.size >= this.cap) {
      this.map.delete(this.map.keys().next().value); // 删最久未用（第一个）
    }
    this.map.set(key, value);
  }
}
```

### 5.18 KMP（next 数组）

```javascript
function buildNext(p) {
  const next = new Array(p.length).fill(0);
  let j = 0;
  for (let i = 1; i < p.length; i++) {
    while (j > 0 && p[i] !== p[j]) j = next[j - 1];  // 失配回退
    if (p[i] === p[j]) j++;
    next[i] = j;
  }
  return next;
}
function strStr(s, p) {
  if (!p) return 0;
  const next = buildNext(p);
  let j = 0;
  for (let i = 0; i < s.length; i++) {
    while (j > 0 && s[i] !== p[j]) j = next[j - 1];
    if (s[i] === p[j]) j++;
    if (j === p.length) return i - p.length + 1;
  }
  return -1;
}
```

### 5.20 链表三件套

```javascript
function ListNode(val, next) { this.val = val; this.next = next || null; }

// 1) 反转（三指针）
function reverse(head) {
  let prev = null, cur = head;
  while (cur) { const nxt = cur.next; cur.next = prev; prev = cur; cur = nxt; }
  return prev;
}

// 2) 找中点（快慢指针，偶数取前一个）
function middle(head) {
  let slow = head, fast = head;
  while (fast.next && fast.next.next) { slow = slow.next; fast = fast.next.next; }
  return slow;
}

// 3) 合并两个有序链表（哑结点）
function merge(a, b) {
  const dummy = new ListNode(0);
  let cur = dummy;
  while (a && b) {
    if (a.val <= b.val) { cur.next = a; a = a.next; }
    else { cur.next = b; b = b.next; }
    cur = cur.next;
  }
  cur.next = a || b;
  return dummy.next;
}
```

## 6. 考场策略

### 6.1 五步法（每题固定动作）

1. **复述题意**（30 秒）：把输入输出、边界条件用自己的话讲一遍。面试中这一步能救你——"你是说数组可能为空吗？"这句话本身就是加分。
2. **手算示例**（1 分钟）：用题目给的例子或自己造一个小例子，在纸上跑一遍。**不要跳过**，80% 的边界错误在这里暴露。
3. **说思路 + 复杂度**（1 分钟）：先说暴力，再说优化，明确复杂度。**面试时必须说，笔试时写注释里**。
4. **写代码**（10~15 分钟）：先写骨架（函数签名、边界返回），再填核心逻辑。
5. **自测**（3 分钟）：空输入、单元素、全相同、极值、负数、重复。

### 6.2 卡住了怎么办（按顺序试）

1. **降维**：二维想不通 → 先想一维；树想不通 → 先想链表。
2. **缩小 n**：n=3 时暴力枚举一遍，规律往往就出来了。
3. **换视角**：正向推不动 → 反向推（从结果倒推）；从前往后 → 从后往前。
4. **加辅助结构**：卡在查找 → 加哈希；卡在顺序 → 加栈/堆；卡在区间 → 加前缀和。
5. **实在不行写暴力**：明确说出暴力复杂度，然后说"这里可以优化到 XX，思路是用 YY"——**部分分 + 展示思路，比交白卷强十倍**。

### 6.3 复杂度口述模板

> "这个解法的时间复杂度是 O(n log n)，瓶颈在排序；空间是 O(n)，用来存哈希表。如果要求 O(1) 空间，可以改成先排序再双指针，代价是时间不变但不用额外空间。"

这句话包含四个采分点：**具体复杂度、瓶颈在哪、空间代价、替代方案**。背下来。

### 6.4 常见"送命"细节

| 陷阱 | 后果 | 规避 |
|---|---|---|
| `mid = (left + right) / 2` | 大数溢出（JS 里是精度丢失） | `left + ((right - left) >> 1)` |
| JS 位运算 32 位截断 | `1 << 31` 变负数；大数 `>>` 出错 | 超过 2³¹ 用 `Math.floor(x / 2)` |
| BFS 出队才标记 visited | 同一节点重复入队 → TLE | **入队时标记** |
| 回溯收集结果不深拷贝 | 所有结果都变成 `[]` | `res.push([...path])` |
| 0-1 背包一维正序 | 同一物品被用多次（变成完全背包） | 内层**逆序** |
| 滑动窗口左边收过头 | 漏解 | 先判断是否满足，再收缩 |
| 字符串比较用 `==` | 隐式转换 | 一律 `===` |
| 链表忘记处理头节点 | 头被删时崩溃 | **哑结点 dummy** |
| 递归没写终止条件/终止条件错 | 栈溢出 | 先写 base case 再写递归 |
| 结果没取模 | 大数题 WA | 按题意 `% 1000000007` |

## 7. 面试口述：把算法题讲成"工程判断"

面试官问算法，不只是看你写不写得出来，更看**你是否知道为什么这么写**。三段式回答：

**第一段 · 定性**
> "这是典型的滑动窗口题。特征是求'连续子数组'满足某条件，且窗口扩大时条件单调变化，所以可以用双指针维护一个窗口，右指针扩张、左指针收缩，整体 O(n)。"

**第二段 · 取舍**
> "也可以用前缀和 + 哈希做，同样是 O(n)，但空间多一个 O(n) 的表。滑动窗口的优势是空间 O(1)，代价是必须满足单调性——如果数组有负数，就不适用了。"

**第三段 · 落地**
> "实际业务里我用这个思路做过日志的异常区间检测，窗口是时间窗，条件是错误率阈值。当时遇到的问题是窗口内需要聚合统计，所以额外维护了一个计数 Map。"

**为什么这样讲能过**：定性证明你会识别题型，取舍证明你不是背模板，落地证明你有真实工程经验。三者缺一，都只是"会做题的人"，而不是"能用算法解决问题的人"。
