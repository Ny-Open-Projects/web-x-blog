## 三、典型错误案例（改前 → 改后）

1. **JS-345 Promise 手写**：`adopt` 定义了却从未调用 → `resolve(v)` 是空操作，promise 永不 fulfilled，整张卡的实现根本跑不通。改后补 `adopt(v);`。
2. **JS-384 熔断器**：`if (++fails === threshold)` → 冷却结束后 fails 已超过阈值，`===` 永不再成立，熔断器**永不重开**，持续故障期间一直放行请求。改为 `>=`。
3. **WEB-633 SIMD 探测**：探测字节里 `v128.const` 前缀写成 `0xFC`（misc 前缀）→ `WebAssembly.validate` 恒 false，SIMD 分支永不加载。实测改 `0xFD` 后 validate=true。
4. **BLD-082 esbuild**：「扩展必须写 Go」说反了——esbuild 插件 API 只在 JS 侧提供，Go 侧不开放插件钩子。
5. **BLD-082（精讲版）**：「降到 es5 以下它就不支持」方向反了——esbuild 最低只到 ES2015，连 `target: 'es5'` 都直接报错。
6. **HW-391 崩溃检测**：存活标记放 sessionStorage——它是标签页私有的，崩溃 tab 消失后标记随之销毁，崩溃恢复**从不触发**。改走 localStorage。
7. **HW-056 FlattenDeep**：`flat`/`map` 对稀疏空位的行为写反（`flat` 剔除空位、`map` 保留空位不调回调）；`[...arr]` 把空位变 undefined，与 flat 并不等价。
8. **ARC-075 监控 SDK**：`navigator.sendBeacon?.(...) ?? fetch(...)`——`??` 只对 null/undefined 回退，sendBeacon 失败返回 `false`，兜底永不执行，页面卸载批次被静默丢弃。改为 `if (!sendBeacon?.(...)) fetch(...)`。
9. **ARC-332 Form 校验引擎**：拼接路径恒以 `.` 开头，`filter(!startsWith('.'))` 把校验结果全部滤空——validate 从不校验任何字段，校验引擎形同虚设。
10. **NODE-132 限流**：毫秒时间戳直接乘「每秒」补币速率，放大 1000 倍——令牌桶瞬间满、漏桶瞬间空，限流彻底失效。补 `/1000`。
11. **ALG-221 布隆过滤器**：误判率 34% 实算应为 ≈93%（公式也错），照此选参数几乎不可用。
12. **ZSM-887/814 状态管理**：自称「50 问/六考点」实际只有 31 问/五组，「六个收官地图」列了 7 个 ID——已按实际卡数统一口径。
13. **JS 正则语法层（自动扫描）**：`(?>a+)` 原子组、`a*+` 占有量词是 PCRE/Java 语法，**JS 不存在**；`yield ...x`、可选链赋值目标（`bc?.onmessage = ...`）均为语法错误。
