## 三层漏斗

```
10,000 题（全库，字典）
   └─ 500 题（核心，课本）
        └─ 100 题（精讲，押题）

另有两条并列支线：
   430 题（经典算法，练手法）→ 960 张原卡（场景算法 + 手写，练选型与落地）
```

| 距面试 | 只看 |
|---|---|
| 1 周内 | `05-精讲100题.md` + 项目复盘 |
| 1 个月 | 核心 500 里的薄弱方向 + 8 周计划后 4 周 |
| 3 个月 | 完整 8 周路径 + 全库按方向扫一遍 |

## 一句话

题库只解决「素材供给」，真正决定结果的是：**一个能讲 20 分钟的项目 + 能扛三层追问的基础 + 15 分钟能跑通的手写**。
