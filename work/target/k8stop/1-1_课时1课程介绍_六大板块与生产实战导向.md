# Kubernetes 生产实战: 课程介绍 —— 六大板块、实战导向与版本说明

欢迎来到这门 K8s 实战课程。开篇先说清楚三件事：**这门课为什么以实战为主**、**总共讲哪六个板块**、**用到哪些版本**。看完这一节，你会知道后面每一章解决的是什么问题。

结论先摆：

1. **本课程的定位是"实战为主、理论为辅"**——基础理论市面上已经有很多书和视频，官方文档也非常详细；**真正缺的是一套系统、且贴合生产环境的教程**；
2. 课程大部分内容是**实战演练，可以直接搬到生产环境里用**；
3. 六个板块：**① 先入为主（安装）② 基础概念 ③ 进阶实战 ④ 日志监控 ⑤ Ingress ⑥ CI/CD**，外加**扩展篇（版本升级）**；
4. 安装部分同时讲 **kubeadm** 和**二进制**两种方式，并覆盖**不同版本的安装方法**，起到举一反三的作用；
5. 版本：K8s **1.17 / 1.19**（录制时最新是 1.19.6）、Docker **8.x**、CentOS **7.x / 8.x**、操作用 Xshell 6、虚拟化用 VMware。

## 纲要

- 为什么是实战为主：市场缺的不是理论，是"贴合生产"的系统教程
- 板块一：先入为主——生产级高可用集群搭建
- 板块二：基础概念——Docker 入门 + K8s 核心与进阶资源
- 板块三：进阶实战——准入控制、权限、持久化存储、中间件容器化、Operator/Helm
- 板块四：日志收集与监控——两类日志 + Prometheus 全家桶
- 板块五：Ingress——服务入口、灰度发布与自身监控
- 板块六：CI/CD——Jenkins 声明式流水线与镜像优化
- 扩展篇：K8s 与 etcd 的版本升级
- 版本与环境说明

## 一、为什么是"实战为主"

市面上讲 K8s 基础理论的书籍和视频已经很多，**官方文档对技术的讲解也非常详细**。但到今天为止，市面上很少——**几乎可以说没有**——一套**系统的、且贴合生产环境**的教程：

- 没有人从头教你**怎么快速在生产环境里把一套 K8s 系统建起来**；
- 也没有人教你**如何应对各类实际需求和场景**。

所以本课程的设计是：

```text
课程定位
├── 实战为主  →  大部分内容是实战演练，可直接用于生产
├── 理论为辅  →  理论只讲够用的部分，细节查官方文档
└── 场景驱动  →  按"实际工作中会遇到的问题和需求"来组织内容
```

## 二、六大板块总览

```text
① 先入为主   → 生产环境搭建高可用 K8s 集群 + 认知 K8s 组件
② 基础概念   → Docker 入门 + K8s 核心资源与进阶资源
③ 进阶实战   → 准入控制/权限/持久化存储/中间件容器化/Operator 与 Helm
④ 日志监控   → 两类日志收集 + Prometheus 监控告警
⑤ Ingress    → 服务入口、常用配置、灰度发布
⑥ CI/CD      → Jenkins 声明式流水线 + 镜像优化 + 账号权限
扩展篇       → K8s / etcd 版本升级
```

### ① 先入为主：先把生产级集群装起来

讲**如何在生产环境中搭建一套高可用的 K8s 集群**，同时对 K8s 本身和它的组件建立认知。

**先装集群再学概念的好处**：学习 K8s 基础概念时可以**边学边操作**，印象会深刻得多。

安装部分的关键安排：

| 内容 | 说明 |
| --- | --- |
| 两种安装方式 | **kubeadm** 与 **二进制** 都讲 |
| 多版本覆盖 | 讲如何应对不同版本的安装——学会后**其他版本甚至最新版都能举一反三** |
| 生产参数 | 会讲到生产环境中**比较重要的参数配置**，实际使用中非常关键 |

### ② 基础概念：Docker 与 K8s

分 Docker 和 K8s 两部分。

**Docker 只讲入门**——因为使用 K8s 时，它相当于**把 Docker 封装在自己的内部**并实现了容器编排，实际使用中对 Docker 的直接操作是很少的。但仍需了解 Docker，并且**要学会写 Dockerfile**——容器化业务应用时，大部分场景还是要自己动手写。另外会讲**如何制作体积较小的镜像**（后面 CI/CD 章节还会进一步讲如何缩小镜像体积）。

**K8s 概念分两块**：

```text
K8s 基础概念
├── 基础部分  → K8s 的核心资源、最常用的资源
└── 进阶部分  → 高级调度 + 权限管理
```

学完这两部分，就能回答"K8s 是个什么东西"，覆盖到 K8s 的全部知识，也把**生产环境中最常用的资源类型**系统学了一遍。

### ③ 进阶实战：准入控制、存储、中间件容器化

这一章分两块：

- **K8s 最常用的准入控制、权限管理、持久化存储**。持久化存储讲的是**云原生存储 Rook 的使用**，同时会涉及**基于 CSI 标准的 PVC 在线扩容、快照和回滚**；
- **生产环境常用中间件的容器化**：Redis、RabbitMQ、ZooKeeper、Kafka 等。同时会带大家了解 K8s 常用管理工具——**Operator 和 Helm**，用它们可以非常方便地部署比较复杂的应用（ZK、Redis、MySQL 等）。学完这一章，**就能在 K8s 上部署任意常用中间件**；
- 还会**带大家写一个自己的 Helm chart**（课程演示是部署 RabbitMQ 集群）。

### ④ 日志收集与监控

**日志收集分两类**：

```text
日志收集的两类
├── ① 输出到控制台的日志
└── ② 输出到容器本地文件的日志
```

为什么必须收集？因为**容器重启或者漂移，都会以最新、最干净的状态去运行**——日志不收集就会丢失，**出了问题可能无法排查**。

还会讲如何**通过不同的 namespace、不同的资源名称、不同的 Pod 名称去索引数据**。

**监控部分讲 Prometheus**：相比老牌监控系统，它**更适用、更适合监控容器、更灵活，而且查询速度非常快**。内容包括：

- 基本概念、数据类型和查询语法；
- 针对不同场景怎么监控——**云原生应用**（自带 metrics 接口，如 etcd 集群）直接抓取；**非原生应用**（不自带 metrics 接口）用 **exporter** 采集，再由 Prometheus 拉取；
- **黑盒监控**：监控 HTTP 状态、接口状态；
- **邮件告警、微信告警、自动发现配置**；
- 实战监控 **JVM**（JVM 参数、垃圾回收数据），并通过 **Eureka 自动发现**——Java 服务注册到 Eureka 之后，怎么实现自动发现并监控。

### ⑤ Ingress：K8s 的服务入口

Ingress 是 K8s 里**服务的入口**，也就是部署的业务应用的入口——**就像传统服务里的 Nginx**，起到**网关和路由**的作用。可以在 Ingress 里配置域名，通过域名就能访问到 K8s 里的服务。

本课程讲的是 **ingress-nginx**（K8s 官方基于 Nginx 开发的），以它为主。

常用配置包括：**域名重定向、前后端分离、黑白名单、访问速率限制**；还会用 Ingress **实现金丝雀发布（灰度发布）**。最后会用前面部署的 Prometheus **监控 Ingress**，根据 Ingress 的指标实现告警或预警。

### ⑥ CI/CD：Jenkins 自动发布到 K8s

这一章讲**如何通过 Jenkins 把应用自动发布、部署到 K8s 上**，是比较重要的一章。

```text
CI/CD 章节要点
├── 声明式流水线
│      比脚本式更灵活、更简单
│      配合 Blue Ocean 可以在线编辑和修改（图形化创建/修改流水线）
├── 用 Pod 做编译
│      在 K8s 集群中完成编译操作，而不是在固定的构建机上
├── 流水线设计
│      测试环境 / UAT 环境 / 生产环境 三种流水线怎么设计
│      两个例子演示整个发版流程 → 可推广到任意开发语言
│      （各语言的编译、发版步骤是类似的）
├── 镜像优化
│      如何优化镜像、做出体积更小的镜像
└── 账号管理
       基于 Jenkins 实现：不同人对不同项目有不同权限
       （公司人员多、项目多时的刚需）
```

### 扩展篇：版本升级

讲**如何把 K8s 升级到最新版**。课程开始录制时最新版是 1.17，录制过程中 K8s 发布了 1.18，而到你学的时候可能已经 1.19 甚至 1.20 了——所以本章会**升级到 beta 版的 1.19**（当时 1.19 尚未正式发布，先"一探究竟"，看看它改了哪些东西）。

升级涉及：**etcd 升级**、**master 节点与 node 节点升级**、**Calico 或 CoreDNS 升级**，以及**升级过程中可能遇到的问题**。

## 三、版本与环境说明

| 项 | 版本 / 工具 |
| --- | --- |
| **K8s** | 录制时最新 **1.19（1.19.6）**；课程涉及 **1.17** 与 **1.19** |
| **版本兼容性** | 1.17 / 1.18 / 1.19 **通用**；**核心资源在 1.17 以下版本也可用** |
| **Docker** | **8.x** |
| **CentOS** | **8.x** 与 **7.x**（两个版本差别不大，课程中会提到差异） |
| **操作集群** | **Xshell 6** |
| **虚拟化** | **VMware**（搭建 CentOS 与 K8s 服务器） |

> 关于"版本焦虑"：课程讲的新功能在 1.17 及以上版本都可用，而**核心资源在 1.17 以下也能用**——所以不必因为版本落后而担心学不了。

## 总结

- **定位：实战为主、理论为辅**。市面上不缺理论，缺的是一套**系统的、贴合生产环境的** K8s 教程——这门课补的就是这个；
- **六大板块**：安装（高可用生产集群，kubeadm + 二进制双路线）→ 基础概念（Docker 入门 + K8s 核心/进阶资源）→ 进阶实战（准入控制、权限、Rook 持久化存储与 CSI 扩容快照、中间件容器化、Operator/Helm）→ 日志监控（两类日志 + Prometheus 告警与 JVM 监控）→ Ingress（入口、灰度发布、自身监控）→ CI/CD（Jenkins 声明式流水线、Pod 编译、多环境流水线、镜像优化、账号权限）；
- **扩展篇**：K8s / etcd / Calico / CoreDNS 的版本升级与踩坑；
- **版本**：K8s 1.17 / 1.19（1.19.6 为当时最新），Docker 8.x，CentOS 7.x / 8.x，Xshell 6 + VMware；
- 课程发布后还会持续更新与答疑。
