# 16. RAG 评估标准、三大步骤与 Ragas 框架四大指标

## 纲要

- **评估的意义**：RAG 建立在 baseline 之后要靠评估驱动迭代；评估既判好坏，也指引优化方向。本质是度量「问题 / 上下文 / 答案」三者间的相关程度。
- **三大评估标准**：① **上下文相关性**（检索到的上下文是否紧扣问题、含解答关键信息，即检索可靠性）；② **忠实性**（答案与给定上下文的事实一致性，能否从上下文推断而非胡说）；③ **答案相关性**（答案是否直接回答问题、是否完整无遗漏、是否无冗余）。
- **评估三大步骤**：① 构建测试数据集（问题 + 标准答案 GT）；② 确定评估指标；③ 执行评估（把测试集送入 RAG 系统，收集上下文与生成答案，计算指标）。
- **Ragas 框架（2023）**：自动 RAG 评估框架；早期无参考（不需标注答案、省人工），新版部分指标需 GT（更准）；核心借 LLM 判断三者相关性，提示词设计是关键（明确指令 + 样例 + 要求给理由）。
- **Ragas 四大指标**：
 - **忠实性**：生成的答案拆细粒度陈述 → 每句验证能否从上下文推断 → 统计可推断占比（不需 GT）。
 - **答案相关性**（逆运算）：由生成答案逆向生成多个潜在问题 → 算这些潜在问题与原始问题的 embedding 余弦相似度均值（不需 GT）。
 - **上下文召回**（需 GT）：把 GT 拆陈述 → 验证能否从检索上下文推断（考验检索是否找得到）。
 - **上下文精度**（排序视角）：对 top-k 每个上下文判能否推出 GT（能=1）→ 按排序位算权重（越靠前权重越大）→ 以「推断成功数」为基数加权平均。

## 一、RAG 三大评估标准

- **上下文相关性**：检索到的上下文是否紧密围绕问题、是否含关键解答信息（检索可靠性）。
- **忠实性**：答案与上下文的事实一致性——答案能否被上下文支撑，不胡编。
- **答案相关性**：答案是否直接回答问题、是否完整（不漏答）、是否无冗余（不多答）。
- 三者度量都需语义理解；人工评估更准但贵，现多借 LLM 评估。

## 二、评估三大步骤

1. **构建数据集**：问题 + 标准答案（GT）。
2. **确定指标**：从标准衍生具体指标。
3. **执行评估**：测试集入 RAG 系统 → 收集上下文与生成答案 → 计算指标值（重点在指标怎么算）。

## 三、Ragas 框架与四大指标

- **框架特点**：2023 年开源，自动评估；借 LLM 能力判三者相关性；提示词写法是精髓（明确指令 + 样例 + 要求输出理由）。
- **数据集格式**：问题、生成答案、检索上下文（**列表，顺序即排序**，第一个最相关）、人工标准答案 GT（注意区分「生成答案」与「GT」）。

### 指标 1 · 忠实性（不需 GT）
答案拆细粒度陈述 → 逐句验证能否从上下文推断 → 可推断占比。例：答案含「出生地 / 出生日期」两句，均与上下文不符 → 0.5。

### 指标 2 · 答案相关性（不需 GT，逆运算）
由生成答案逆向生成多个潜在问题 → 算这些潜在问题与原始问题的 embedding 余弦相似度 → 取均值。需多角度生成以覆盖答案多个事实；生成问题的 prompt 含自我判断（含糊=1、明确=0，只取明确问题）。

### 指标 3 · 上下文召回（需 GT）
流程同忠实性，但拆分的是 GT：把 GT 拆陈述 → 验证能否从检索上下文推断。例：GT「法国在西欧 / 首都巴黎」，前者可找、后者不可找 → 0.5。

### 指标 4 · 上下文精度（排序视角，需 GT）
对 top-k 每个上下文判能否推出 GT（能=1）→ 按位置算权重（当前位置之前推断成功的比例，越靠前权重越大）→ 以推断成功数为基数加权平均。
例：3 个上下文，推断结果为 [失败,成功,成功] → 权重 [0,1/2,2/3] → 加权和 = 0+0.5+0.667 = 1.167，基数=2（成功数）→ 1.167/2 ≈ 0.58。

## 四、FAQ

**Q1：上下文精度与召回的区别？**
召回看「找没找到相关上下文」（不关心顺序）；精度看「相关的排没排最前」（顺序越靠前越好）。

**Q2：为什么忠实性 / 答案相关性不需标准答案？**
它们只评「答案↔上下文」「答案↔问题」关系，不涉及 GT；召回 / 精度要拿 GT 比对才知检索对不对。

**Q3：Ragas 为什么用 LLM 算指标？**
相关判断需语义理解，LLM 强于语义且可规模化，比纯人工省成本。

**Q4：上下文列表顺序在 Ragas 里有什么用？**
它代表检索排序，上下文精度指标用该顺序算权重。

## 五、面试高频问答

**1. RAG 三大评估标准？**
上下文相关性、忠实性、答案相关性。

**2. 评估 RAG 的三步？**
构建测试数据集（问题+GT）、确定指标、执行评估收集上下文与答案算分。

**3. Ragas 四个核心指标？**
忠实性、答案相关性、上下文召回、上下文精度。

**4. 上下文精度怎么算？**
对 top-k 判能否推出 GT，按排序位加权（越靠前权重越大），以推断成功数为基数加权平均。

## 六、ops 提示（增效）

> **评估先于优化**：没评估就调参是盲调；先建数据集 + 选指标。
>
> **四大指标对照看**：上下文召回 / 精度差 → 改检索或换 embedding；忠实 / 答案相关性差 → 改 prompt 或换 LLM。
>
> **GT 提升准度**：新版 Ragas 部分指标要 GT，标注少量标准答案能显著提评估可信度。
