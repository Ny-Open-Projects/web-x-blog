# 76. 上手 AgentGPT：网页配置、旅行规划与博客助手及定价

## 纲要

- **定位**：AgentGPT 是网页端 Agent，**无需编程基础**，比 AutoGPT 配置简单；settings 填 OpenAI API key（**测完务必删除防泄露**）。
- **内置 template**：研究 / 市场调研 / 旅行规划（类 GPS 但可循环执行任务）。
- **实战 1 旅行规划**：目标"武汉→云南七日游"（第 0 晚武汉出发、第 7 晚云南出发、第 8 早回武汉上班）；拆 4 步循环，第 5 步达最大循环终止；规划不合理（第 2 天昆明→丽江赶人）。
- **实战 2 博客助手**：目标"写博文介绍加州与阿拉斯加人口比"；拆 4 任务→写代码算比率→print 比率写入博文，结果 **1:54**（与前一致）；超最长循环限制。
- **商业化定价**：升级后每天 30 个 agent × 25 loop，增 GPT-4/无限 web 搜索/插件权限；价格贵；基础简单任务配合 ChatGPT 代码解释器即可。

> 本章按课程口径重构；产品名已规范化（AgentGPT/OpenAI/ChatGPT/GPS）；剥离营销与课程群引流。

## 一、网页配置

- 打开官网 → settings 填 OpenAI API key；测完删除防 key 泄露。
- 内置 template：研究/市场调研/旅行规划，可循环执行（区别于 GPS 单次）。

## 二、实战：旅行规划

- 武汉→云南七日游，约束第 0 晚出发、第 7 晚云南出发、第 8 早回武汉。
- 拆 4 步循环，第 5 步达最大循环终止；规划不合理（第 2 天昆明→丽江过赶）。

## 三、实战：博客助手

- 加州/阿拉斯加人口比，拆 4 任务 → 写代码算比率 → print 写入博文。
- 结果 1:54（同前）；超最长循环限制后停。

## 四、定价与替代

- 升级：每天 30 agent × 25 loop，含 GPT-4/无限搜索/插件；价贵。
- 基础简单任务：配 ChatGPT 代码解释器即可，不必上 AgentGPT。

不需要，网页端填 API key 即用。

测完删除，防泄露被盗刷。

**Q3：旅行规划实测如何？**
拆 4 步第 5 步达上限终止；规划不合理（次日赶场）。

**Q4：博客助手结果？**

## 六、面试高频问答

**1. AgentGPT 与 AutoGPT 上手差异？**
AgentGPT 网页零代码；AutoGPT 需本地环境。

**2. 循环上限是什么？**
达最大 loop 数自动终止（如旅行规划第 5 步、博客超最长限制）。

**3. 人口比两 agent 结果一致吗？**
一致，均≈1:54（加州:阿拉斯加）。

**4. 何时值得用 AgentGPT 付费？**
需高频多 agent 复杂任务；基础任务用代码解释器够。

## 七、ops 提示（增效）

> **key 用完即删**：网页端填 key 易泄露，测完删除。
>
> **循环上限设合理**：避免任务未达目标就停或无限烧钱。
>
> **基础任务别上付费**：代码解释器覆盖多数简单需求。
