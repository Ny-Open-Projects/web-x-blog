# 68. Midjourney V6 重大更新：提示词重写、六大要素与 style 参数

## 纲要

- **官方定调**：V6 对 prompt 重优化，文档直言"必须重新学写 prompt"；对无用词（award-winning/photorealistic/4k/8k）敏感且拖慢出图。
- **六大要素**（V6 强支持）：① 风格（style，明确美学/时代）② 主题（main focus + 外观/颜色/独特特征）③ 背景（setting：地点/室内外/时间/天气）④ 构图（composition：视角/角度/取景）⑤ 照明（lighting：明暗/情绪/氛围）⑥ 附加信息（复杂度/次要物体）。
- **关键参数**：`--style raw` 更直白中性现实（适文字/写实）；`--stylize 0–1000` 越高越天马行空（默认中等）。
- **算力消耗**：V6 消耗 fast 时长是 V5 的 1–2 倍（V6 ≈1.8 分钟/张，V5 ≈1 分钟/张；standard 15h 约 450–480 张）；手部细节仍差，用 remix 调优。
- **模式建议**：平时用 relax 模式（夜间响应快），省 fast 额度。
- **看新消息**：Discord 官方频道 announcements；read images 帮官方标注学优质 prompt。

> 本章按课程口径重构；产品名已规范化（Midjourney）；剥离营销与课程群引流。

## 一、V6 对提示词的敏感化

- V6 更精确理解 prompt，但**拒绝垃圾词**（4k/8k/photorealistic 等），加入反而拖慢、降质。
- 需清晰知道要画什么、让软件更懂你。

## 二、重写范式：六大要素

1. 风格 style：明确美学方向/时代。
2. 主题：重点 + 中心人物/物外观/颜色/独特特征。
3. 背景：地点、室内外、时间、天气。
4. 构图：视角、角度、取景偏好。
5. 照明：明暗、情绪（欢快/神秘）、氛围。
6. 附加：复杂度、深度、次要物体。

## 三、style 参数与算力

- `--style raw`：更直接中性现实，适合文字/写实场景。
- `--stylize 0–1000`：越大越富想象力（1000 天马行空，0 基本不扩展）。
- V6 比 V5 吃算力（fast 时长 1–2 倍）；relax 模式夜间快，建议默认 relax 玩 V6。

## 四、获取新信息与标注

- announcements 看版本发布；read images 用数字键选图帮官方标注，可学优质 prompt 复现。

## 五、FAQ

**Q1：V6 为什么不能写 4k/8k？**
V6 对无用词敏感，加入拖慢出图、降质，官方明确不再支持。

**Q2：--style raw 干什么？**
更直白中性现实输出，适合文字/写实类。

**Q3：V6 比 V5 慢多少？**
fast 时长约 1–2 倍；建议用 relax 省额度。

**Q4：手写 V6 prompt 的框架？**
按六大要素（风格/主题/背景/构图/照明/附加）结构化描述。

## 六、面试高频问答

**1. V6 相对 V5 最大变化？**
提示词重写必要、对无用词敏感、理解更精确、算力更吃。

**2. V6 六大要素是哪些？**
风格、主题、背景、构图、照明、附加信息。

**3. --stylize 与 --style raw 区别？**
stylize 控想象力强度（0–1000）；style raw 控现实直白度。

**4. 怎么低成本玩 V6？**
用 relax 模式（夜间快），避免 fast 额度快速消耗。

## 七、ops 提示（增效）

> **弃用 4k/8k 类词**：V6 视为垃圾词，拖慢降质。
>
> **六要素结构化**：风格/主题/背景/构图/照明/附加一次写全。
>
> **relax 省额度**：平时 relax 玩，fast 留关键图。
