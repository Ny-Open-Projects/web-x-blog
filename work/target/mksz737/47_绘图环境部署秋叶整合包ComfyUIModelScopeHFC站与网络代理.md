# 47. 绘图环境部署：秋叶整合包 / ComfyUI / ModelScope / HF / C 站与网络代理

## 纲要

- **上手方案**：在线平台（Stable Diffusion Online）即开即玩；本地部署需较大内存（仅推理 3060/3090/1080 可行，1080 需大内存）。
- **Windows 一键**：秋叶启动器（SD 整合包 v4.4，内置 Python/环境/模型，B 站搜「秋叶」拿百度云地址，认准原作者防木马）。
- **官方手动装坑**：Python 版本有要求（3.9~3.11，新版本不兼容 torch 核心组件），需加系统 PATH、装 git、拉仓库运行。
- **Linux / macOS**：Linux 一句命令；macOS（Apple 芯片）建议 M2+ 且内存 64GB+，显存:内存 ≈ 1:8，M 系推理效率偏低。
- **模型仓库**：C 站（Civitai，绘画专属）、HuggingFace（HF，models/datasets）、ModelScope（魔搭，国内访问方便）。
- **网络不通解法**：GitHub / HF 国内被墙，可用 Cloudflare Workers 边缘计算写一段 JS 反代，配独立域名在国内正常下载大模型。
- **专业工具**：Pinokio（一键配环境）、ComfyUI（流水线可视化，专业，SD Turbo 小狐狸即其流水线）。

> 本章按课程口径重构；模型名词已规范化；剥离营销与课程群引流（原「科学上网/购买账号」等表述仅保留网络代理技术实质）。

## 一、上手与硬件门槛

- **在线平台**：Stable Diffusion Online 等网页工具，设好参数即可玩，零部署。
- **本地推理硬件**：仅推理 3060/3090/1080 可跑；1080 内存太小（8GB）步数一多会卡顿。
- **显存:内存比**：N 卡 24GB 显存 ≈ 苹果 192GB 内存（约 1:8）；内存越大 WebUI 跑模型越顺、出图越快。
- **macOS 实测**：M1/M2 推理效率低（M1 iPad Pro 8GB 约 29s、M1 MacBook Pro 16GB 约 24s、M2 Air 8GB 约 18s 生成 512×512/50 步）；建议 M2+ 64GB+，不如直接上 4090 或双 3090。

## 二、Windows 一键部署

- **秋叶启动器（SD 整合包 v4.4）**：B 站搜「秋叶」拿百度云地址；内置 Python、环境、预制模型，安装即清爽界面、直接网页端打开。
- **防坑**：只信原作者发布的压缩包，网传压缩包可能夹带木马；装配置出问题查官方 issues。
- **官方手动装**：Python 须 3.9~3.11（新版本不兼容 torch），装 git、拉仓库、运行；秋叶本质是提前下好资源并逐个装环境。

## 三、Linux / macOS 部署

- **Linux**：已装 Python 后一句命令拉仓库+下模型即可。
- **macOS**：装基础环境 → 装 brew python → 下项目仓库 → 下 SD 模型（GitHub 单文件下，勿用 git clone 大文件，超大文件需用 Git LFS）→ 跑脚本出界面。讲师本机 M1 未实测，建议 M2+ 64GB+。

## 四、模型下载仓库

- **C 站（Civitai）**：绘画专属，models 按赞/下载量排序；分类含基础模型、姿态、风格、角色、漫画、背景、载具、动物等；post 可见别人用的模型与 prompt、采样器；国内需网络代理访问。
- **HuggingFace（HF）**：首页 models（搜 LCM 等看版本/下载量/命令行调用）、datasets（训练用数据集）、可下商业数据集或自爬。
- **ModelScope（魔搭）**：国内访问方便，模型库含文本生图、多模态图像描述、国画风/JK 风/洛丽塔等；模型数量少于 HF 与 C 站。
- **作者上传动机**：论证验证、扩大知名度、线上推广接商业合作、科研爱好。

## 五、网络不通的解法

- **问题**：国内直连 GitHub / HF 被墙，git clone 大文件拉不下来。
- **Cloudflare Workers 反代**：写一段 JS（边缘计算）配独立域名，国内即可正常下载 GitHub 仓库与 HF 模型（含十几个文件、单文件约 10GB、总约 100GB 的大模型）；可加 IP 限制只放行自己服务器。
- **注意**：代理方案为技术解法示意，实际部署与合规边界需自行评估。

## 六、专业工具

- **Pinokio**：一键下载模型/配置 WebUI 全套环境（文件系统/CPU/API/App），无需配 Python/git，类似秋叶但需网络连通 GitHub。
- **ComfyUI**：流水线可视化，用脚本或他人定制 json 流水线传参设模型；与 SD 最大区别是更专业。SDXL Turbo 小狐狸即用其配合的流水线（搜 how to run SD turbo on ComfyUI，下约 8.5KB 的 json 即配好）。
- **硬件忠告**：想认真做 AI 绘图，显卡照 4090 买；条件有限则双 3060 或单 3090；AMD 卡/Mac 常无法按官方步骤实操。

## 七、FAQ

**Q1：新手本地部署 SD 推荐什么？**
Windows 直接用秋叶整合包 v4.4 一键；macOS 建议 M2+ 64GB+，否则效率低。

**Q2：模型去哪下？**
绘画专属看 C 站；通用/数据集看 HF；国内方便看魔搭 ModelScope。

**Q3：GitHub/HF 拉不下来怎么办？**
大文件用 Git LFS；国内被墙可用 Cloudflare Workers 反代配独立域名下载。

**Q4：ComfyUI 和 WebUI 区别？**
ComfyUI 是流水线可视化、更专业，可用他人 json 流水线；WebUI 插件丰富、上手快。

## 八、面试高频问答

**1. 本地部署 SD 的主要硬件与系统坑有哪些？**
Python 版本须 3.9~3.11（新版本不兼容 torch）；macOS M 系效率低需 M2+ 64GB+；显存:内存约 1:8；AMD 卡/Mac 常无法按官方步骤跑。

**2. 主流模型仓库各适合什么？**
C 站绘画专属、HF 通用+数据集、魔搭国内方便；大文件用 Git LFS 下载。

**3. 国内访问 GitHub/HF 被墙怎么解？**
Git LFS 拉大文件；或用 Cloudflare Workers 反代配独立域名，可加 IP 白名单。

**4. ComfyUI 的价值？**
流水线可视化、可复用他人 json、专业可控，SD Turbo 等先进流水线多基于它。

## 九、ops 提示（部署）

> **认准官方源防木马**：秋叶等整合包只信原作者发布，网传压缩包有夹带风险。
>
> **大文件用 Git LFS**：GitHub/HF 超大模型别用 git clone，单文件下或 LFS。
>
> **硬件先到位**：认真做 AI 绘图先投显卡（4090/3090），环境配置问题迎刃而解。
