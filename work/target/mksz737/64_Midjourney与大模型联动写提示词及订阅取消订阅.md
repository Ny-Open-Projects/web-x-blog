# 64. Midjourney 与大模型联动写提示词及订阅取消订阅

## 纲要

- **LLM 当提示词生成器**：把 MJ 的 prompt 基础结构（主题/描述/风格/参数）作为上下文交给大模型，让它把中文描述或图片提炼成英文逗号分隔提示词。
- **固定指令**：追加"今后我只发图片描述或上传图，请按上述结构提炼提示词，不输出图，明白请回 OK"，锁定角色。
- **权重语法**：`词:1` 设置风格/元素权重；**参数必须放最后**（放中间会导致部分词不被支持）。
- **订阅**：standard plan 支持支付宝支付；免费试用超限会要求订阅。
- **取消订阅**：Discord 内 `/subscribe` → manage account → 两个按钮（周期结束不再续费 / 立即退款，按退款政策按比例扣，已消耗算力不退全款）。

> 本章按课程口径重构；产品名已规范化（Midjourney/Discord/支付宝）；剥离营销与课程群引流。

## 一、用 LLM 批量生成 MJ 提示词

- 把"主题+描述+风格+参数"四段结构交给大模型，作为提示词生成器上下文。
- 追加锁定指令："今后只发描述或图，按上述要求提炼提示词，不输出图"。
- LLM 输出逗号分隔英文 prompt，可直接贴到拼凑站选风格（如 NIJI）后复制。

## 二、权重语法与参数位置

- `关键词::权重`（如 `enjoy coffee::3`）调元素强度，权重 1–4。
- **参数放末尾**：`--ar`/`--v` 等若插在中间，MJ 会报"单词不支持"；挪到结尾重发即可。
- 拖图进 prompt（长 CDN 值 + 空格 + 指令）可让新图更贴合原图。

## 三、订阅与支付

- 免费试用超限后需订阅；standard plan 约 30 美元/月（≈200 元），慢速 GPU 不限、快速约 15 小时。
- 现已支持支付宝，支付后可浏览社区 gallery、复制他人 command/seed、点赞。

## 四、取消订阅与退款

- Discord 内 `/subscribe` → manage account 跳转页面。
- 两选项：① 当前周期结束不再扣费；② 立即退款（按政策按比例，已用算力会扣，非全额）。
- 切换计划也在同一页面。

## 五、FAQ

**Q1：为什么要让 LLM 代写 MJ 提示词？**
MJ 认英文，LLM 把中文描述/图片转成结构化英文 prompt，省去手动翻译拼接。

**Q2：权重符号放哪？**
`词::数值` 紧跟元素；整体参数（--ar 等）必须放 prompt 最后。

**Q3：取消订阅会全额退款吗？**
不会；立即退款按政策扣已消耗算力费用，仅未使用部分退。

**Q4：standard plan 快速 GPU 多久？**
约 15 小时/月，慢速不限；绘图量大时一周可能耗尽快速额度。

## 六、面试高频问答

**1. 如何让 LLM 稳定输出 MJ 提示词？**
把四段结构作上下文 + 追加"只提炼不绘图"锁定指令，输出英文逗号分隔 prompt。

**2. MJ 参数位置错误会怎样？**
插在中间会报词不支持；挪到末尾重发即可生效。

**3. 订阅与取消的关键路径？**
`/subscribe` → manage account；取消可选不续费或按比例立即退。

**4. 团队用 MJ 怎么划算？**
买几张高配显卡共享，比多人分摊同一账号更划算。

>
