# 14. 吴恩达 Prompt 工程课程指引（学习资料与思路）

## 纲要

- **官方课程**：deeplearning.ai 免费课《ChatGPT Prompt Engineering for Developers》；视频 + 笔记 + Python 沙箱（可运行命令看结果），左屏练右屏学。
- **别只看搬运**：B 站/YouTube 翻译版多为引流广告；建议看**英文原版**——前沿技术英文表述更准，且耳濡目染提升术语语感（像练 Prompt 一样练耳朵）。
- **中文笔记**：课程提供「1:1 复刻官方」的中文翻译笔记（含示例），在资料文件夹可取。
- **普适性**：虽以 ChatGPT 为例，但原则/笔记/视频**适用于所有 LLM**，非常值得学。
- **学法重心**：学「老师怎么想、思路是什么」比背 30/300 个现成 Prompt 重要——灵活用出来才是真掌握。

> 本章按课程口径重构；课程链接以官方当前为准；剥离营销与课程群引流。

## 一、官方课程入口

- 站点：deeplearning.ai → short courses → ChatGPT Prompt Engineering for Developers → enroll for free。
- 形态：视频 + 同步笔记 + 可运行 Python 命令的练习环境（左练右学）。

## 二、为什么学英文原版

- 英文单词/表述对前沿技术更准确；认识术语后看其他视频有「耳濡目染」效应。
- 无英文字幕时，可贴翻译字幕，但建议逐步过渡到英文。

## 三、中文笔记与普适性

- 中文笔记 1:1 复刻官方内容并加翻译示例，资料文件夹可取。
- 课程虽以 ChatGPT 示范，但**原则通用于所有大语言模型**。

## 四、学法：重思路而非死记

- 课程不堆「必学 N 个 Prompt」；核心是**学会怎么想**——把方法用活。
- 写 Prompt 同听英文：常写常练才清楚；常听常练才听懂。

## 五、FAQ

**Q1：官方课程免费吗？**
deeplearning.ai 的 short course 免费，含练习环境。

**Q2：看 B 站翻译版行吗？**
可入门，但多为引流；建议英文原版更准确。

**Q3：笔记和原则只适用于 ChatGPT？**
不，适用于所有 LLM。

**Q4：怎么学最有效？**
抓「思路/方法」，不背现成 Prompt；把原则灵活用出来。
