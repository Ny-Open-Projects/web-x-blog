# 79. [扩展] AppAgent：LLM 操作移动 App（ADB/计算机视觉/GPT-4V）

## 纲要

- **定位**：AppAgent 是 LLM 驱动的多模态代理，掌握并利用任何 App 执行复杂任务，**可跨 App**（如 Gmail 发邮件、X 平台发推），由大学团队（国人）发论文。
- **演示**：Gmail 中找联系人洋洋洒洒写邮件并发送，全程无需人类动手；类小爱/Siri 但更强（跨 App 复杂任务）。
- **技术关键**：
 - **计算机视觉能力**：GPT-4 有视觉，描述画面内容（文字性易识别，手写难）；非图片的 HTML 字符串直接解析告知 LLM 页面与待操作。
 - **CLI/ADB 连接**：手机数据线连电脑/服务器，通过 CLI 模拟点击/滑动；不停取帧消耗性能，手机侧小模型识别能力有限。
- **实验**：用 GPT-4V（$0.03/次，贵），需自有图像识别模型才宜批量；quickstart 需 ADB + Android Studio 配置 + OpenAI key。
- **现实意义**：把 LLM 触角伸到移动端；对比传统基于页面 API 调远程服务（订机票/酒店/食谱）。
- **看论文方法**：摘要（重点）→ 介绍（完成什么任务）→ 细节（怎么用，CLI）→ 实验数据（应用价值/缺点）；英文差用翻译对照。AMiner 查论文/代码。
