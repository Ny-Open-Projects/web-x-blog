# 74. AI Agent 两大方向：自主代理与生成式代理（AutoGPT/BabyAGI/AgentGPT/斯坦福虚拟小镇）

## 纲要

- **两大方向**：① 自主代理 autonomous agent（某专业方向，如景区问答、PDF 摘要；当前主应用=翻译整本书+提观点举例子等复杂任务）；② 生成式代理 generative agent（虚拟人/游戏角色，推动商业化落地）。
- **自主代理典型**：
 - **AutoGPT**：知名度最高开源，一句话需求自主自动化完成；GPT-4 贵（复杂任务约 5 刀且效果不稳），可用 GPT-3.5；token 消耗大、结果不稳，但作为 LM 自动化案例极大启发开发者。
 - **BabyAGI**：脚本跑无限循环拆复杂任务——拉取首任务→执行代理（LLM API 按上下文完成）→存结果→按目标与前结果创建新任务并重排优先级（防无限循环）。
 - **AgentGPT**：网页端。
- **生成式代理典型**：斯坦福+谷歌《Generative Agents》虚拟小镇——25 个虚拟人在游戏引擎中发生故事；架构含 perceive/plan/reflect/act + memory stream 记忆流（retrieve 检索记忆碎片→重 plan→respond）。

> 本章按课程口径重构；产品名已规范化（AutoGPT/BabyAGI/AgentGPT/Generative Agents）；剥离营销与课程群引流。

## 一、自主代理方向

- 某专业方向代理（景区问答、PDF 摘要）；复杂任务主应用：翻译整本书 + 提观点举例子。
- 当前落地以"小而专"为主，复杂任务才是感知未来方向。

## 二、AutoGPT 与 BabyAGI

- AutoGPT：一句话需求自主完成，GPT-4 贵且不稳，GPT-3.5 可；token 消耗大但开启新方向。
- BabyAGI：无限循环拆任务，执行→存结果→按目标重排优先级，避免陷入无限扩展。

## 三、生成式代理：斯坦福虚拟小镇

- 斯坦福+谷歌论文，25 虚拟人游戏引擎中生活；架构 perceive/plan/reflect/act + memory stream。
- 记忆流：retrieve 检索碎片→重 plan→respond，模拟人类处理事务思路。

## 四、方向对比与价值

- 自主代理解决"复杂任务自动化"；生成式代理缩小游戏开发时间、提升体验、助人类学研究。
- 生成式代理（虚拟人/游戏角色）是未来商业化重要部分。
