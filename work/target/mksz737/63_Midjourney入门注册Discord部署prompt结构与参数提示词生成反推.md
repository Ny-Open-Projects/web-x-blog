# 63. Midjourney 入门：注册、Discord 部署、prompt 结构与参数、提示词生成与反推

## 纲要

- **定位**：Midjourney（MJ）是商用文生图大模型，注册与交互依赖 Discord；相比本地 Stable Diffusion 是"黑盒"，无硬件成本（仅账号+魔法软件）。
- **注册与部署**：国内无法直接访问，需下载 Discord 桌面端并开网络代理；用国外邮箱（Outlook/Gmail）注册账号；自建 Discord 服务器后在成员列表找到 MJ 机器人 → 添加 App → 选自己服务器授权 → 聊天窗输入 `/` 调出 MJ 命令。
- **核心命令**：`/info` 看免费试用额度；`/settings` 选模型（默认最新 v5，NIJI 偏二次元）、风格/画质（低/中/高，默认中）、模式（public 发布社区、remix、turbo/fast/relax 速度档）。
- **绘图指令**：`/imagine prompt...` 生成图；输出 4 张供选。
- **关键参数**：`--ar` 比例（默认 1:1/16:9）、`--chaos` 混乱值（类温度，越高差异越大）、`--q` 质量、`--s` 尺寸、`--seed` 种子（固定人物/风格核心元素）、`--stop` 中途停止、`--stylize` 风格化。
- **prompt 三段式结构**：图像主体前缀 + 文本描述（场景/动作/表情） + 后置参数；MJ 与 SD 均**只认英文**（英文标注图数据源更多）。
- **提示词获取三法**：① 在线拼凑站（选风格/灯光/艺术风格/材质/尺寸，组合后复制）；② 上传图用 `/describe` 反推关键词；③ HuggingFace 的 clip-interrogator 等在线站反推；中文需 DeepL/谷歌/本地翻译转英文。

> 本章按课程口径重构；产品名已规范化（Midjourney/Discord/DeepL/HuggingFace）；剥离营销与课程群引流、微信/网盘水印。

## 一、注册与 Discord 部署

- 国内访问 Discord 需桌面端 + 网络代理；注册用 Outlook/Gmail 等国外邮箱更稳。
- 加入 MJ 官方讨论组，或在自建服务器添加 MJ 机器人（成员名单 → 机器人 → 添加 App → 授权）。
- 聊天窗输入 `/` 即出现 MJ 命令：`/info`（试用额度，约 25 分钟）、`/settings`（模型/风格/模式）。

## 二、模型、风格与模式配置

- 默认最新模型；NIJI 偏二次元画风，可在 settings 切换。
- 三行配置：风格（低/中/高画质，默认中）、public（输出发社区）、remix/variation（变化幅度）、turbo/fast/relax（速度档，消耗对应额度）。

## 三、prompt 结构与关键参数

- **三段式**：图像主体前缀 + 文本描述（场景/动作/面部表情） + 参数；中文不支持，需英译。
- **参数表**（重点）：
 - `--ar` 比例；`--chaos` 混乱值（类温度，0→100 差异渐大）；`--q` 质量/清晰度；`--s` 尺寸。
 - `--seed` 种子：固定核心元素，生成同风格/同表情系列图时必用。
 - `--stop` 中途停止；`--stylize` 风格化强度。

## 四、提示词生成与反向推导

- **拼凑站**：选风格/灯光/艺术风格/材质/尺寸组合，复制到剪贴板。
- **`/describe` 反推**：上传图 → MJ 解析出关键词，便于借鉴他人图。
- **clip-interrogator**：HuggingFace 在线传图 → 输出提示词。
- 中文描述需翻译（DeepL/谷歌/本地翻译软件）再拼接。

## 五、FAQ

**Q1：MJ 需要什么前置条件？**
Discord 桌面端 + 网络代理 + 国外邮箱注册的 Discord 账号；无本地显卡成本。

**Q2：为什么提示词必须用英文？**
英文标注图的数据源更多，MJ/SD 均优先英文；中文需自行翻译。

**Q3：--seed 有什么用？**
固定图片最核心元素，使前后生成的人物面相/整体风格变化不大，适合同系列图。

**Q4：没有灵感怎么写提示词？**
用在线拼凑站组合风格/材质，或传图用 `/describe`、clip-interrogator 反推。

## 六、面试高频问答

**1. MJ 的交互入口与核心命令是什么？**
Discord 机器人；`/imagine` 绘图、`/info` 看额度、`/settings` 配模型与模式。

**2. MJ prompt 的三段式与关键参数？**
主体前缀 + 文本描述 + 参数；重点 `--ar/--chaos/--seed/--stylize/--stop`。

**3. 如何反推一张图的提示词？**
`/describe` 上传图、或 HuggingFace clip-interrogator 在线反推。

**4. MJ 与 SD 在部署上的根本差异？**
MJ 黑盒商用（无硬件成本）；SD 本地控制台（需高配英伟达显卡自部署）。

## 七、ops 提示（增效）

> **参数后置**：`--ar`/`--seed` 等必须放 prompt 末尾，放中间会被忽略或报错。
>
> **seed 复用**：做同风格系列图先定 seed，再局部调权重。
>
> **反推提效**：看到好图先 `/describe` 存关键词，比从零写快得多。
