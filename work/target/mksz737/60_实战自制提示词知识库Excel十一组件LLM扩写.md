# 60. 实战：自制提示词知识库（Excel 十一组件 + LLM 扩写）

## 纲要

- **十一组件结构**：覆盖此前四大块（上下文/角色/格式/背景=主题或目标任务），扩展为约十一个部分——上下文、角色、格式、背景/主题、目标任务、步骤、行动指令、挑战、限制、示例、数据。
- **两步法**：① 定义基础数据（角色/限制/主题/格式/语气/数据等）；② 按用户选择拼接成新 prompt。
- **角色数据**：参考提示词网站（如 Awesome Prompts 中文站）摘抄，或让 LLM 以「提示词专家」身份扩写高频角色名称（纯文本输出便于粘贴）。
- **限制数据**：让 LLM 扩写常见限制（无专业术语/含≥3 参考链接/仅客观描述/第一人称/无个人意见/含历史背景/避免数字统计等）。
- **数据验证下拉**：Excel「数据验证→序列」选来源列，角色/限制/格式/主题均可下拉；末列用 `=B2&"、"&C2&...` 拼接，改选择即联动。
- **动态扩展**：新增 sheet 扩角色（如前端高级开发），下拉即出新结构；LLM 生成更专业拼接公式（加入「作为…的角色」「上下文：我的老师是科技工作者」等完整句式）。Notion 模板可设彩色标签更美观。

> 本章按课程口径重构；工具名已规范化（Excel/Notion/Awesome Prompts）；剥离营销与课程群引流。

## 一、十一组件框架

- 网络上有 Notion 写的「网络营销模型」知识库：左侧分类展开、右侧勾选（模型/语气/配色），底部「加工车间」合并成专属 prompt——本质是 Excel 多分类的呈现。
- 十一组件：上下文、角色、格式、背景/主题、目标任务、步骤、行动指令、挑战、限制、示例、数据。涵盖此前四大块并细化。

## 二、两步法落地

1. **定义基础数据**：用 Excel 建 sheet（如「角色」），从提示词网站摘抄或 LLM 扩写填入 A 列；调字体/颜色。
2. **拼接新 prompt**：末列公式把所选输入合并；下拉选择驱动动态输出。

## 三、用 LLM 扩写数据

- **角色**：定义「写提示词专家」，请其按示例扩写高频角色名称（纯文本输出便于复制）；如技术开发、前端高级专家等。
- **限制**：请其扩写常见限制——无专业术语、含≥3 参考链接、仅客观描述、仅第一人称、避免数字统计、含历史背景等（比原示例更严苛，实为输出格式要求）。
- **主题/格式/语气/数据**：同理准备；后续可跳过已准备部分。

## 四、数据验证与下拉

- 选「数据验证→序列」，来源选对应列（如主题列），回车确定即生成下拉。
- 角色/限制/格式/主题均可用序列下拉；选中后末列公式（如 `=B2&"、"&C2&...`）实时拼出 prompt。
- 例：角色=礼物挑选师、主题=支持客户挑礼物、任务=给老师挑礼物、限制=200 字内 → 拼接出完整 prompt。

## 五、动态扩展与美化

- 新增 sheet 扩角色（前端高级开发等），下拉即出新结构；选新角色后后续单元格自动跟随。
- 公式可让 LLM 生成更专业版（加「作为…的角色」「上下文：我的老师是科技工作者」等完整句式），自动换行放大更舒适。
- Notion 模板可设彩色标签（角色即标签）更美观；Excel 朴素但够用。

## 六、FAQ

**Q1：十一组件包含哪些？**
上下文、角色、格式、背景/主题、目标任务、步骤、行动指令、挑战、限制、示例、数据；涵盖并细化此前四大块。

**Q2：怎么快速填角色/限制数据？**
从 Awesome Prompts 等网站摘抄，或让 LLM 以「提示词专家」身份扩写高频名称（纯文本便于粘贴）。

**Q3：下拉怎么实现？**
Excel「数据验证→序列」选来源列即可；选不同值末列公式联动拼接。

**Q4：Notion 比 Excel 好在哪？**
可设彩色标签更美观，但 Excel/飞书足以沉淀；按需选择。

## 七、面试高频问答

**1. 自制 prompt 知识库的两步法？**
定义基础数据（角色/限制/主题等 sheet）+ 按选择拼接（末列公式合并）；下拉驱动动态生成。

**2. 如何用 LLM 加速搭库？**
以「提示词专家」身份扩写高频角色/限制名称，生成专业拼接公式，降低手工。

**3. 数据验证序列的作用？**
把来源列变下拉，选中即联动末列拼接，避免手敲、保证结构一致。

**4. 十一组件与四大块关系？**
四大块（上下文/角色/格式/背景）是基础，十一组件细化加入任务/步骤/指令/挑战/示例/数据。

## 八、ops 提示（实操）

> **先四大块后十一组件**：结构从简到繁，避免一开始过度设计。
>
> **LLM 扩写省手工**：角色/限制/公式都让模型生成，你只校验。
>
> **下拉保一致**：数据验证序列让全队用同一结构，减少偏差。
