# 21. 分阶段提问、明确目的与结构化思考（技巧五、六、七）

## 纲要

- **技巧五（分阶段提问）**：复杂问题一口吃不下，拆成多轮、每轮聚焦一个子目标，并反复强调最终目标防跑偏。
- **技巧六（明确要求和目的）**：重复/冲突指令会让模型失效；给「思维顺序」、或让模型**反过来问你背景**，把目的逼清楚。
- **技巧七（结构化思考）**：用「指令 + 输入 + 背景 + 输出要求」公式自检 Prompt，并让模型帮你评估/优化。
- **Agent 工具**：不会拆？可用 agentGPT（界面化、可本地部署、走 GPT-3.5 API）或 openintegration（本地命令行、结合主流模型操作电脑/编码）自动拆解复杂任务。

> 本章按课程口径重构；剥离营销与课程群引流，保留拆解范式、迭代反馈与 Agent 工具思路。

## 一、技巧五：分阶段提问，让模型一步步思考

- **为什么拆**：上下文长度受限，复杂任务一次性回答易丢焦点、易稀释。
- **怎么拆（食谱案例）**：
 1. 先问「常见巧克力蛋糕主料有哪些」。
 2. 再问「鸡蛋在蛋糕中的作用」→「什么能替代鸡蛋」。
 3. 收口：`作为资深糕点师，为小白出 3 份无蛋奶食谱，食材给具体克数`。
 4. 追评：`从营养/复杂度/口感/成本/保鲜打分，选最佳`。
- **注意点**：
 - 始终强调最终目标，防止模型前后文失联跑偏。
 - 真实性/专业度要靠你补背景，别指望设了专家就全自动。
 - 分块后模型会重复前文，别顺着它的重复再引导，越带越远。

```mermaid
flowchart LR
    A[子问题1:主料] --> B[子问题2:鸡蛋作用]
    B --> C[子问题3:替代物]
    C --> D[收口:3份无蛋奶食谱+克数]
    D --> E[打分选最佳]
```

## 二、技巧六：明确你的要求和目的

- **冲突指令会失效**：同一轮既「做 1 份」又「做 3 份」→ 模型以先收到的为准或直接混乱。靠**迭代**改 Prompt 重发解决。
- **给思维顺序**：`从互联网起源描述，重点详述移动互联网，并对新媒体未来做预估` —— 比裸问「发展史」更贴你的思路。
- **让模型反问背景**（最稳的目的澄清法）：
 - 句式：`假设你是<专家>，我是<小白客户>；我不太会提问，请逐步引导我让需求更具体，完成后回复"完成背景收集，开始回复"。`
 - 模型逐个提问，你逐条答（答「不知道」就跳下一题），收集完再出答案。

## 三、技巧七：结构化思考你的 Prompt

- **公式自检**：写完后对照 `指令 + 输入 + 背景 + 输出要求` 看缺哪项。
- **让模型当评委**：`作为机器学习专家，评估以下 Prompt 是否含明确指令/背景/输入/输出要求并给建议，用举例说明` —— 把弱 Prompt 优化成强 Prompt。
- **心法**：常写常练、把公式「疯狂套用」，量变引起质变。

## 四、Agent 拆解工具

- **agentGPT**：图形界面，填 GPT API Key 后输入复杂目标，自动拆解逐步执行；**可本地部署**，数据留本地。普通用户多用 GPT-3.5，省钱够用。
- **openintegration**：本地命令行工具，结合主流大模型，在本地实现「操作电脑 / 编码 / 复杂功能」。
- **chatGPT plus 用户**：可用类 agent 的助手自动拆复杂问题并汇总。
- **定位**：当你「不会拆、懒得拆」时的杠杆，但理解拆解逻辑本身仍是核心能力。

## 五、FAQ

**Q1：分阶段时模型忘了前面内容怎么办？**
每轮重述/强调最终目标，把关键结论再贴回上下文，防止失联。

**Q2：重复指令冲突怎么救？**
删掉冲突项、保留目标，编辑后重发；模型会重新响应。

**Q3：让模型反问背景会不会很啰嗦？**
会多几轮，但能逼清真实目的，比拿到跑偏答案再返工省事。

**Q4：Agent 工具要付费吗？**
agentGPT 可本地部署用自有 API；openintegration 本地免费；plus 用户的 agent 类功能随订阅。

## 六、面试高频问答

**1. 复杂任务大模型答不好，怎么拆？**
分阶段多轮，每轮一个子目标，并始终强调最终目标防跑偏（技巧⑤）。

**2. 重复/冲突指令有什么后果？**
模型以先收到为准或混乱；用迭代改 Prompt 重发（技巧⑥）。

**3. 怎么快速判断一个 Prompt 写得好不好？**
套「指令+输入+背景+输出要求」四项自检，缺哪项补哪项（技巧⑦）。

**4. 不会拆复杂问题能用什么工具？**
agentGPT（界面/本地部署）、openintegration（命令行本地）等自动拆解助手。

## 七、ops 提示（实践）

> **拆完再问**：复杂任务先列子问题树，再逐轮发，别一口闷。
>
> **目的澄清用反问**：自己说不清需求时，让模型当 interviewer 逐步收集背景。
>
> **工具是杠杆不是依赖**：会用 Agent 拆，但拆解逻辑要自己懂，方能校验结果。
