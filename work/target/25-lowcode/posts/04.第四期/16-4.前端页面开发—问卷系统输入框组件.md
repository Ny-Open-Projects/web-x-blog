# 前端页面开发—问卷系统输入框组件

> **导语**：前面做的视频、图片、列表都是"展示型"组件，而问卷系统的输入框是第一个"采集型"组件——它不仅要在编辑器里配置，还要在发布后的页面上接收用户输入并把数据交回项目。本文讲清这条链路：视图组件里预留的 `onUpdate` / `onChange` 回调如何把值传出去，以及右侧配置面板的默认值与显隐处理。读完后你会明白为什么采集型组件必须放在 `share` 包里并预留回调。

## 前置知识

- 已完成警告视图等展示类组件，建议先阅读《前端页面开发—警告视图组件+属性配置组件》。
- 理解视图组件放在 `share` 公共包、编辑器与发布页共用的工程结构。
- 了解 `pnpm build:share` 的作用与 `isHidden` 表单显隐约定。

## 正文

### 采集型组件与展示型组件的区别

点击输入框组件，中间画布会出现一个带标题的输入框。标题初始是"请输入标题"，可自定义成"姓名""年龄"之类；占位符是"请输入内容"；还能给一个默认值，比如把"性别"默认设为"男"，这样多数用户不必重复填写，少数用户改一下即可。

但真正不同的是：发布之后的页面是给**终端用户**填写的。用户点进输入框打字，这个内容必须双向同步回项目，才能在提交问卷时被收集。因此输入框组件除了展示，还要预留一个数据出口——这正是它比展示型组件复杂的地方。

### 视图组件与类型定义

视图组件定义在 `share` 的 `LowCodeInput` 下，结构很简单：一个 `div` + 一个 `span` 放标题 + 一个 `input`。它接收父组件传来的 config——来自 `src/pages/Editor/EditorCanvas.tsx` 里 `generateComponent` 生成的组件配置，源头是 store 里当前选中组件的 props。

类型定义在 `share` 里，包含：

- `title`：标题，默认"请输入标题"；
- `text`：输入框里的内容值（store 中存储）；
- `placeholder`：占位符，默认"请输入内容"；
- `onUpdate`：预留方法，默认 `undefined`。

注意别把 `title` 和 `text` 搞混：**前面是标题，后面才是用户填写的内容**。改动 `share` 里的类型后，同样要重新打包，client 才能引用到新字段。

### 预留 onChange / onUpdate 数据出口

核心思路是：视图组件不自己保存用户输入，而是把值"抛出去"。

在 `input` 上绑定 `onChange`，用户编辑时通过事件对象的 `event.target.value` 拿到输入内容，再调用 props 里预留的 `onUpdate` 把值传出去。编辑器里这个回调可以什么都不做，但**发布页面**会实现它，从而同步拿到用户输入，完成"视图 → 项目数据"的回显。

也就是说：同一个 `LowCodeInput` 组件，在编辑器里只负责展示配置效果，在发布页里则通过 `onUpdate` 把填写内容交回问卷提交逻辑。这个预留回调是采集型组件能被两端复用的关键。store 里的数据变化时，组件照例会重新渲染，保证配置改动即时可见。

### 右侧配置面板

配置属性组件放在 `client` 侧，沿用二次封装的表单外层与子项：

- **标题项**：默认 `title` 已改成"请输入标题"；
- **占位符项**：没输入内容时显示"请输入内容"；
- 每个子项都经过统一方法处理成表单需要的数据格式，并依据 `isHidden` 判断是否展示。

`share` 的类型里，把不需要在面板出现的某些项（例如回调相关的 `onUpdate`）`isHidden` 设为 `true`，配置面板就不会渲染它们。想看未打包前的原始定义，可以查 `import default config` 对应的默认配置文件。

改完记得把组件与类型都从 `share`、`client` 各自的主入口抛出——这一步反复强调，是因为漏了导出就会在别处报"找不到"。

### 顺手修掉一个类型导出错误

上一节在 `pages/edit/editCanvas` 出现过一个警告：提示某个 ID 找不到。根因是之前定义 alert 组件时，导出类型写错了名字——本该导出 `AlertComponentConfig`，却误写成了带 `Result` 后缀的另一个类型，导致那个类型不带 `id` 字段。前端循环遍历组件清单时找不到 alert，TypeScript 就提前报错。把导出改回正确的类型名即可消除警告。

这类问题很典型：低代码编辑器靠"组件类型清单"驱动渲染，任何一个类型导出名写错，都会让遍历映射断链。

## 小结

- 输入框是采集型组件，既要编辑器配置，也要在发布页接收用户输入。
- 视图组件 `LowCodeInput` 放在 `share`，类型含 `title / text / placeholder / onUpdate`。
- `onChange` 通过 `event.target.value` 取值并调用预留的 `onUpdate`，由发布页面实现数据回显。
- `title` 是标题、`text` 是内容，两者不要混淆；store 变化会触发重新渲染。
- 配置面板用 `isHidden` 隐藏不该出现的项；组件与类型都要在主入口导出。
- 组件清单靠类型名映射，导出名写错会导致遍历断链并触发 TS 警告。
