# 前端页面开发—文本视图组件+属性配置组件

> **导语**：走到这里，编辑模块的组件开发已经形成固定套路了。本文用文本组件把这套套路再走一遍：share 里一个 `<span>` 加动态字号、类型文件里定义默认值与通用组件类型、client 里用 `FormContainer` 和 Ant Design 的 `Segmented` 做右侧配置面板。更重要的是理解「一次定义、多端复用」——这些组件后续会被发布页面（release 项目）直接引入渲染。

## 前置知识

- 建议先了解《前端页面开发—视频组件展示视图》与《前端页面开发—视频组件配置属性》，本文沿用其中的「视图组件 + 属性配置组件」流程。
- 建议先了解《公共组件+类型子项目 share 创建和项目配置》，理解公共组件为什么要放在 share 里。

## 正文

### 文本组件要做什么

点击左侧文本组件，中间视图展示的是一个空白占位元素（提示「这里修改为你要的文字」）；右侧属性面板可以改两样东西：**展示的文本**与**字体大小**。相比前面带图片地址、跳转链接的组件，文本组件只有 `title` 和 `size` 两个属性，是最适合拿来巩固流程的一个。

组件都定义在 share 公共项目里，不是只给编辑器用：后面开发发布页面时，会新建 `release` 项目，直接引入这些组件就能把页面渲染出来。所以「定义 → 导出 → 打包」这一步不能省。

### 视图组件：一个 span 加动态字号

新建 `LowCodeText` 目录，视图组件本体非常简单——一个 `<span>` 元素，加上根据配置算出来的 `className`。

字号要跟着 store 里维护的数据同步变化：用 `useState` 保存 `size`，store 改变时重新渲染；组件内部用 `switch` 把 `size` 映射成 Tailwind CSS 的字号类：

| size | 含义 | Tailwind 类 |
| --- | --- | --- |
| `xs` | 超小 | `text-xs` |
| `sm` | 小 | `text-sm` |
| `base` | 基础（默认） | `text-base` |
| `lg` | 大 | `text-lg` |
| `xl` | 超大 | `text-xl` |

装了 Tailwind CSS 插件后，鼠标移到类名上就能看到具体数值：`text-base` 是 16px、行高 24px；`text-lg` 是 18px、行高 28px。 props 里的 `title` 取默认值作为展示文字，两处数据最终都从 store 流向视图。

### 类型与默认值

类型文件里做三件事：

- 定义文本组件的属性接口：`title`（文字）与 `size`（五档字号枚举）。
- 设置默认值：`title` 给一段占位文字，`size` 默认 `base`（标准大小）。
- 转成**通用组件类型**：请求后端接口需要统一的数据格式——每个组件都有 `id`、`type` 和 `props`（配置属性），文本组件也按这个结构转换，并剔除可选属性。

把类型和组件都导出、重新打包 share 之后，client 与 release 都能引用。

### 右侧属性组件：FormContainer + Segmented

client 侧新建 `LowCodeComponents/LowCodeText` 属性组件，沿用之前二次封装的 `FormContainer`：

- 如果组件是**列表形式**、能新增条目（比如列表、轮播），用 `FormContainerWithList`；
- 文本组件不是列表，用普通的 `FormContainer` 即可。

里面放两个 `FormPropLabel`：一个填 `title` 文本，一个设 `size` 大小。字号选择用 Ant Design 的 `Segmented` 分段控制器，传入 `options` 数组，每项是一个 `{ value, label }` 对象：

```json
[
  { "value": "xs", "label": "超小" },
  { "value": "sm", "label": "小" },
  { "value": "base", "label": "基础" },
  { "value": "lg", "label": "大" },
  { "value": "xl", "label": "超大" }
]
```

`value` 与视图层 `switch` 里的档位一一对应，选中的值回写 store，视图随即重渲染。最后把新组件导出，并在右侧「按当前选中组件类型展示对应配置面板」的映射里注册进去。

### 打包与验证

改完 share 要在根目录执行 `pnpm build:share` 重新打包，配套代码 `代码（已8期）/代码（已8期）/15-7/lowcode/package.json` 里的脚本正是：

```json
{
  "scripts": {
    "run:client": "pnpm --filter client run dev",
    "run:server": "pnpm --filter server run start:dev",
    "build:share": "pnpm --filter share run build",
    "build:client": "pnpm --filter client run build"
  }
}
```

client 侧依赖（见 `代码（已8期）/代码（已8期）/15-7/lowcode/packages/client/package.json`）也正好覆盖了本节用到的能力：

```json
{
  "dependencies": {
    "@lowcode/share": "workspace:^",
    "ahooks": "^3.7.8",
    "antd": "^5.11.2",
    "classnames": "^2.3.2",
    "mobx": "^6.12.0",
    "mobx-react-lite": "^4.0.5",
    "react-router-dom": "^6.20.1",
    "tailwindcss": "^3.3.5",
    "ulid": "^2.3.0"
  }
}
```

`antd` 提供 `Segmented`，`mobx` 维护配置状态，`tailwindcss` 提供字号类，`ulid` 生成组件唯一 ID。调试时输入「我是小滴课堂老王」，再依次切换超小 / 小 / 基础 / 大 / 超大，文字实时变化即说明链路打通。

## 小结

- 文本组件只有 `title`、`size` 两个属性，是巩固「视图组件 + 属性配置组件」流程的好例子。
- 视图层用一个 `<span>` 加 `switch` 映射五档 Tailwind 字号类，`size` 由 store 驱动重渲染。
- 类型层定义属性接口、默认值，并转成含 `id / type / props` 的通用组件类型。
- 右侧用 `FormContainer` 包裹 `FormPropLabel`，字号选项交给 Ant Design 的 `Segmented`。
- share 里的组件会被发布页面复用，改完记得 `pnpm build:share`。
