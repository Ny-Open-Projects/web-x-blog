# 课程章集目录速览：从 NestJS 基础到全栈项目实战的学习地图

> **导语**：这一集不写具体代码，而是带大家把预先课的大纲完整过一遍，弄清楚每一章要解决什么问题、章与章之间怎么衔接。预先课的核心目标是把 NestJS 从"认识框架"推进到"能独立开发后端接口"，为后面正式进入低代码平台项目打底。读完你会对整条学习路径心里有数，知道每一阶段该重点抓什么。

## 前置知识

本文是课程导学的目录速览，**无需前置基础即可阅读**。如果你想先了解整个大课最终要做出什么，可以顺手翻一翻《低代码平台项目大课介绍+适合人员+学后水平》，但那不是阅读本文的前提。

## 正文

### 第 1 章：认识 NestJS 与初始化项目

第一章先对 NestJS 建立一个基础认识，然后用框架脚手架创建初始项目，并逐项介绍初始化目录结构：哪些文件代表什么含义、启动入口在哪里、基础的运行逻辑是怎样的。这一步的重点不是背目录，而是理解一个 NestJS 应用从 `main.ts` 到模块、控制器是怎么串起来的。

### 第 3 章：装饰器、控制器与 NestCLI

有了项目骨架，接着通过一个基础示例理解什么是装饰器，以及装饰器在 NestJS 中的应用。随后详细讲解控制器（Controller）——它负责接收请求、返回响应，是接口开发的主战场。脚手架提供的 NestCLI 也值得专门花时间掌握：用几条快捷命令就能生成模块、控制器、服务等模板代码，NestJS 里的 RESTful 风格 API 同样可以快速生成，能省下大量重复的手写工作。

### 第 4 章：Providers、Module、中间件与文件上传

第四章进入框架进阶用法。提供者（Providers）是 NestJS 依赖注入的核心，要理解它的逻辑、如何自定义 Provider，以及全局工厂模式等用法；模块（Module）负责组织与封装这些提供者。在此基础上讲中间件，以及 NestJS 框架里如何处理文件上传。这几块共同决定了后端代码能不能写得可复用、可维护。

### 第 5 章：异步处理与拦截器

第五章专攻"横切逻辑"：处理异步和拦截器。这里会依次讲到响应拦截器、异常拦截器（异常过滤器）、管道 Pipe 转换，以及用管道验证 DTO。配合 RxJS 处理异步数据流，就能把统一响应格式、统一错误格式、参数校验这些每个接口都要做、却不该混进业务代码的事情，全部收敛到框架层。低代码平台后续大量接口都会复用这一套约定。

### 第 6 章：用 TypeORM 连接数据库

第六章通过 TypeORM 连接数据库，快捷地操作增删改查，并学习配置实体——也就是在代码里定义一张表及其字段，让表结构与 TypeScript 类一一对应。这是把"接口能返回数据"升级成"数据能持久化"的关键一步。

### 第 7 章：正式进入项目实战

第七章开始不再练单个知识点，而是完整走一遍项目开发：先开发后端接口，再开发前端模块，前端调取之前写好的后端接口，把整条链路调通，完成一次全栈闭环。实战会覆盖课程管理的增删改查，以及用户的注册、登录接口。走完这一章，预先课的知识点就全部落到了一个能跑的项目里。

### 配套工程形态

预先课阶段用的是单一 NestJS 项目，而正式的《全栈多端低代码平台项目大课》工程是 pnpm workspace 多包仓库，根目录下的 `代码（已8期）/代码（已8期）/8-2/lowcode/pnpm-workspace.yaml` 只声明了一行规则：

```yaml
packages:
  - "packages/*"
```

即所有子项目都放在 `packages/` 下（client、server、share 等），由根工程统一管理依赖与脚本。预先课打下的 NestJS 基础，最终都会落到 `packages/server` 这个后端子项目里。配套资料：《全栈多端低代码平台项目大课》HTML 与 PDF 版本，可作为整门课的索引随时查阅。

## 小结

- 预先课的主线是 NestJS：认识框架 → 初始化项目 → 装饰器与控制器 → Providers/Module/中间件 → 拦截器与管道 → TypeORM → 全栈实战。
- NestCLI 的模板生成能力与 RESTful API 快速生成，是提升后端开发效率的关键工具。
- 第 5 章的响应拦截器、异常过滤器与管道验证，是后面统一接口格式的基础设施。
- 第 6 章的 TypeORM 实体负责把代码里的数据结构同步成数据库表。
- 第 7 章通过"后端接口 + 前端联调"完成全栈闭环，是从知识点走向项目实战的分水岭。
