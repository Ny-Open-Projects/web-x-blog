# 择其善者而从之—前端页面开发提效之 UI 组件库

> **导语**：开发前端页面时，UI 组件库能大幅提效。本文梳理主流组件库——Ant Design（React/Vue/Mobile）、Element Plus、Vant 的来路与适用场景，并给出按框架、按端选型的建议。

## 前置知识

建议先看《逐鹿中原—服务端渲染框架之 Nextjs + Nuxtjs》，了解前端框架选型背景。

## 正文

### 为什么用组件库

很多公司有自研 UI 或不依赖第三方，但多数业务项目会引入成熟组件库来复用按钮、表单、表格等，避免重复造轮子。下面按 GitHub 热度与团队背景逐一介绍。

### Ant Design 家族

**Ant Design React**

- GitHub Star 约 **88.2k**，是所有组件库中最高的，主要得益于 React 的流行；
- 由阿里巴巴蚂蚁金服团队于 **2015 年**开源；
- 是基于 **React** 的企业级 UI 组件库，主要用于中后台产品，也可用于官网等前端站点。

**Ant Design Mobile**

- 移动端版本，Star 约 **11.2k**；
- 同样由蚂蚁金服团队，2016 年开源；
- 主打移动端 Web 的极致体验，官网提供现成移动组件直接引入。

**Ant Design Vue**

- 用于 Vue 框架的 Ant Design 版本；
- 由社区网友维护（非大厂团队），Star 少于 Element Plus。

### Element 家族（Vue）

**Element Plus**

- 由阿里巴巴**饿了么**团队开发；
- **Element UI**（Vue 2）于 2016 年开源，**Element Plus**（Vue 3）于 2021 年开源；
- 面向设计师与开发者，适用于 **PC 端**。

**Vant**

- 由**有赞**团队开源，2017 年发布，现版本 **4**，Star 约 **22k**；
- 轻量、可定制的移动端 Vue 组件库，适用于移动端。

### 按框架与端选型建议

- **PC 端 + React** → Ant Design React（最受欢迎、稳定持续维护）；
- **移动端 + React** → Ant Design Mobile；
- **PC 端 + Vue** → Element Plus（大厂维护，优先）或 Ant Design Vue；
- **移动端 + Vue** → Vant。

> 注：Ant Design Vue 由社区网友维护，相比大厂直接维护的 Element Plus，长期维护风险略高，因此 Vue PC 端更推荐 Element Plus。

## 小结

1. Ant Design React（88.2k）最受欢迎，蚂蚁金服 2015 开源，企业级 React 中后台首选。
2. Ant Design Mobile（11.2k）是移动端 React 方案。
3. Ant Design Vue 由社区维护，热度低于 Element Plus。
4. Element Plus（Vue 3，饿了么 2021）与 Element UI（Vue 2，2016）是 Vue PC 主力。
5. Vant（有赞，v4，22k）是轻量移动端 Vue 组件库。
6. 选型口诀：React 用 AntD，Vue PC 用 Element Plus，Vue 移动用 Vant。
