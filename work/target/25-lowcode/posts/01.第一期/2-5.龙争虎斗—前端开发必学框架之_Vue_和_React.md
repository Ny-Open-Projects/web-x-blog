# 龙争虎斗—前端开发必学框架之 Vue 和 React

> **导语**：Vue 和 React 是国内最主流的两个前端框架，也是面试与选型绕不开的话题。本文从 GitHub 热度、设计理念、编程风格、组件范式到两者的 Diff 算法，做一次系统对比，帮你根据项目与团队技术栈做取舍。

## 前置知识

建议先看《互联网大厂技术 Leader+高级前端技术组长之技术选型》，理解「框架要匹配项目与团队」的原则。

## 正文

### 热度与生态

国内中小型公司多用 Vue，但互联网大厂两者都要掌握——两个框架的项目都极多。经过多年迭代，它们在模板语法、生态、状态管理、性能上各有优点，选哪个取决于项目需求与团队技术栈。

从 GitHub Star 看受欢迎程度：

- **Vue**：约 206k（由国人**尤雨溪**于 2014 年创建，2020 年推出 Vue 3，现官网默认即 Vue 3）。
- **React**：约 215k（由 Facebook 于 2013 年开源，严格说是 **JavaScript 库**而非完整框架，专注构建 UI）。

Vue 发布较晚，Star 略少属正常。

### Vue 3 的特点

- 引入更灵活、可复用的**组合式 API（Composition API）**，基于函数式开发，更易测试与理解；
- 通过**虚拟 DOM** 与静态提升（static hoist）优化渲染，减少编译/运行时开销；
- 建议从 **Vue 2** 学起再过渡到 Vue 3，概念更易消化。

### React 的特点

- React 官网主推用 **Next.js** 开发全栈/服务端渲染应用，纯前端则推荐 **Vite** 更轻快；
- Hooks（16.8）成熟后，18 时代函数组件已是绝对主流（class 组件仍可用，官方只是不再主推），降低学习曲线；
- 采用**单向数据流 + 虚拟 DOM**，新旧虚拟 DOM 对比、不直接操作真实 DOM，渲染效率更高。

> 注意区分：Next.js 是 React 的服务端渲染框架；NestJS 是基于 Node 的后端框架，两者不要混淆。

### 编程风格对比

**React 计数器（JSX + hooks）**：

```tsx
function App() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}
```

**Vue 计数器（template + script + style）**：

```vue
<template>
  <button @click="count++">{{ count }}</button>
</template>
<script setup>
import { ref } from 'vue';
const count = ref(0);
</script>
```

React 用 JSX，标签可动态定义（如 `tag = 'h1'` 再渲染 `<tag>`）；Vue 用固定模板语法 `<template>`，按框架封装逻辑走，相对「约定多于灵活」。

### 组件与状态管理

- React 18 全面函数组件；Vue 3 向组合式 API 靠拢。
- 状态管理：Vue 建议 **Pinia**（与组合式开发统一）；React 建议 **Redux Toolkit** 或 **MobX**。

### Diff 算法对比

两者都通过虚拟 DOM 提升性能，都采用**同级对比**策略：生成 old vnode / new vnode，逐层比较，找出差异后替换、增删，避免直接操作真实 DOM。

**Vue 3 策略：首尾对比 + 最长递增子序列**

示例：旧序列 `A B C D E F`，新序列 `A D B C E F`。Vue 3 先去掉首尾相同的 `A` 和 `F`，聚焦中间 `B C D` → `D B C`。找出保持不动的节点（`B`、`C`，下标 1、2）即「最长递增子序列」，只需把 `D` 前移一次即可，移动次数最少。

**React 策略：基于索引的挂载位置判断**

React 遍历新列表，用每个节点在旧列表中的下标（`oldIndex`）与已处理节点的最大下标（`lastPlacedIndex`）比较：`oldIndex >= lastPlacedIndex` 不移动，否则标记移动。一次遍历完成排序——但注意它**不保证**最小移动次数（极端乱序时可能多移），这也是 Vue 3 引入最长递增子序列的原因。

更深入的原理建议直接阅读两者源码中 Diff 相关函数实现。

## 小结

1. 国内中小公司多 Vue，大厂 Vue / React 都要会；React（215k）与 Vue（206k）热度相当。
2. Vue 由尤雨溪 2014 年创建，Vue 3 主打组合式 API 与静态提升。
3. React 是 JS 库，18 版本默认函数组件，单向数据流 + 虚拟 DOM。
4. React 用 JSX（更灵活），Vue 用 template（约定更多）。
5. 状态管理：Vue 选 Pinia，React 选 Redux Toolkit / MobX。
6. Diff 都做同级对比；Vue 3 用首尾对比 + 最长递增子序列，React 用索引位置判断，目标都是最小化 DOM 移动。
