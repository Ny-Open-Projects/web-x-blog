# 群雄纷争—高级+全栈前端工程师必学之 Express+Koa+Nestjs

> **导语**：高级 / 全栈工程师绕不开 Node 后端框架。本文对比 Express、Koa、NestJS 三者的 GitHub 热度、定位与设计理念，并解释本大课最终选择 NestJS 的原因。注意区分：NestJS 是 Node 后端框架，Next.js 是 React 的服务端渲染框架。

## 前置知识

建议先看《龙争虎斗—前端开发必学框架之 Vue 和 React》，建立框架对比的视角。本文聚焦 Node 服务端框架。

## 正文

### 三个框架的热度（GitHub Star）

- **Express**：约 62.2k
- **NestJS**：约 60.8k（比 Express 少一点，但晚发布好几年，说明近年最火的 Node 后端框架非它莫属）
- **Koa**：约 34.4k

Express 与 Koa 都由 TJ Holowaychuk 主导创建，Koa 是他吸收 Express 经验后与团队重新设计的现代化版本（独立实现，不是 Express 的分支）。

### Express：轻量简洁的元老

- 2010 年创立，定位**轻量级框架**，专注 Web 服务器与路由；
- 与 Koa 相比，Express 更简洁（Next.js 是 React 全栈方案，不在同一维度比较）；
- 路由功能强大灵活，可轻松管理复杂路由；
- 因轻量，性能与效率较高，有丰富中间件生态便于扩展；
- 但提供的功能更基础，若需要复杂逻辑，要靠第三方插件、中间件或自行封装。

小滴课堂官网有 Vue 3 + Express 的全栈课程，上一个前端大课的后端接口也是用 Express 开发的。

### NestJS：全功能的企业级框架

- 2017 年由波兰开发者（Kamil Mysliwiec）创立，比 Express 晚 7 年，但 GitHub 受欢迎度已逼近；
- **全功能框架**，内置依赖注入、管道（Pipe）、守卫（Guard）等；
- 架构清晰、易于维护大型项目，特别适合中大型后端；
- 用 **TypeScript** 开发，完美结合 TS，提供更好的类型安全与开发工具支持；
- 集成大量现代化开发思想与最佳实践，提升开发效率与代码质量；
- 小滴课堂官网有专门的 NestJS 专题课（大课之前刚录制）。

相比 Express / Koa，NestJS 更「重型」——功能与工具模块已内置，直接引用即可，无需自己引第三方中间件或自行拓展。

### Koa：精炼现代的极简派

- 基于 Express 经验重构，更现代化；
- 使用 ES6+ 语法，强调**中间件**概念（方法中大量 `async/await` 异步调用）；
- 本身不含很多功能，需开发者自行组合中间件；
- 没有 NestJS 那么重型、全面；
- 中间件机制强大，可实现细粒度控制，设计优雅、易学易定制拓展。

### 三者对比小结与选型

- **Express / Koa**：都轻量、简洁优雅、性能高（因为小）；
- **NestJS**：重型很多，功能与工具模块内置，直接引用。

本大课选择 **NestJS** 的主要原因：项目规模大、后续迭代频繁，全功能框架能让架构更清晰、维护更省力。

## 小结

1. 热度：Express(62.2k) ≈ NestJS(60.8k) > Koa(34.4k)。
2. Express 2010 年轻量框架，路由强、中间件生态丰富，但功能基础。
3. NestJS 2017 全功能框架，内置依赖注入/管道/守卫，TypeScript 原生，适合大型项目。
4. Koa 与 Express 同作者，更现代、中间件机制强、需自组中间件。
5. Express/Koa 轻量高性能，NestJS 重型内置全。
6. 大课选 NestJS：架构清晰、易维护、契合大型低代码后端。
