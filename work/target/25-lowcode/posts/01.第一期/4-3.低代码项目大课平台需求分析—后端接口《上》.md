# 低代码项目大课平台需求分析—后端接口《上》

> **导语**：本文按「用户相关」与「低代码编辑相关」两个分类，拆解低代码平台需要开发的后端接口。通过已上线的项目演示，逐个数清楚注册登录、验证码、微信扫码登录，以及编辑端发布、组件获取、OSS 资源上传/查询/删除等接口的职责与差异。

## 正文

### 用户相关接口
正常工作流中，产品经理会根据原型图列出后端需要开发的接口。本节课先讲用户相关与低代码编辑相关两类。

**1. 图形验证码获取接口**
由后端通过图形验证码插件生成 SVG 格式数据，也可由前端拿到 SVG 后转成图片展示。

**2. 获取手机验证码接口**
点击获取时请求后端，后端生成四位随机验证码并调用运营商接口发送到用户手机号。

**3. 注册接口**
填写密码、图形验证码、手机验证码、手机号并校验通过后，提交注册。

**4. 账号密码登录接口**
登录页填写手机号、密码后提交。

**5. 手机验证码登录接口**
图形验证码与手机验证码逻辑与前文一致，通过传入不同字段（`register` / `login`）区分用途，后端在 Redis 中分类存储，避免冲突。

**6. 微信扫码登录相关接口**
流程较复杂，包含：请求微信服务端校验权限、获取 `ticket` / `token` 并展示二维码、微信回调通知、前端轮询接口查询扫码状态（轮询查看 release 状态）。

**7. 获取用户信息接口**
进入低代码编辑页时请求一次。后端返回用户 ID 后，判断该用户此前是否存过草稿或发布过组件，若有则从数据库读取并渲染，使一进页面就能看到上次的组件。

### 低代码编辑相关接口
**1. 低代码页面发布接口**
在编辑端点击发布时提交一次。

**2. 低代码组件获取接口**
进入页面初始化时请求数据库中的组件；前端会对比 `localStorage` 中的草稿时间戳与接口数据时间戳，读取最新的一份（优先用更晚的 `localStorage` 草稿）。

**3. 视频/图片上传接口**
上传时提交 `upload` 接口，资源存入阿里云 OSS。

**4. 从 OSS 查询所有资源接口**
上传完成或打开页面时自动请求，展示该用户已上传的视频/图片。

**5. 删除资源接口**
点击删除按钮时调用，复用同一路径，采用 RESTful 风格 DELETE，随后重新请求资源列表获取最新数据。

### 接口分类小结
| 分类 | 接口 |
| --- | --- |
| 用户相关 | 图形验证码、手机验证码、注册、账号密码登录、手机验证码登录、微信扫码（校验/二维码/回调/轮询）、获取用户信息 |
| 低代码编辑 | 发布、组件获取、上传（OSS）、查询资源、删除资源 |

## 小结
- 用户相关接口涵盖验证码、注册、登录（密码/手机/微信）与用户信息获取；
- 图形/手机验证码通过 `register` / `login` 字段在 Redis 中分类，避免相互冲突；
- 微信扫码登录由「服务端校验 + 二维码 + 回调 + 前端轮询」组成；
- 编辑端核心接口是发布、组件获取、OSS 上传/查询/删除，删除采用 RESTful DELETE；
- 组件获取时前端以 `localStorage` 草稿时间戳与接口数据比对，取最新渲染。
