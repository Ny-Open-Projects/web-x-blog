# React项目部署配置—线上代码上传OSS配置

> **导语**：上一节已经在云效流水线里把 React 项目打包构建完成，产物是 `dist` 目录，线上代码都在里面。本文讲最后一步——把 `dist` 上传到阿里云 OSS 的 Bucket，并完成 Bucket 侧与流水线侧的配置。读完后你能独立新建一个静态资源 Bucket、设好静态页面与公共读权限，并在流水线里加对 OSS 上传步骤的源文件目录。

## 前置知识

- 已完成 React 项目的打包构建并了解 `dist` 产物，建议先阅读《React项目部署配置—打包构建》。
- 了解云效 DevOps 流水线的基本操作，建议先阅读《项目部署上线—云效DevOps开通使用介绍》。
- 有一个可用的阿里云账号，能进入「对象存储 OSS」控制台。

## 正文

### 先建一个 Bucket

打包构建完成后会生成 `dist` 目录，所有线上代码都存放在其中。接下来要把这份代码上传到阿里云 OSS 的某一个 Bucket 里，因此先在 OSS 控制台新建一个 Bucket。演示中创建的 Bucket 名为 `lowcode-client`（按自己的命名习惯来即可）；执行过自动部署后，流水线会把代码上传到这个 Bucket 里。

### Bucket 侧的三项必备配置

新建 Bucket 之后，还有几处不配就访问不了的设置：

- **域名管理**：绑定自己的域名。演示时先留空，等部署上线、需要正式访问时再回来绑定。
- **静态页面**：在数据管理里把静态页面的首页设为 `index.html`，否则访问时无法正确展示页面。
- **读写权限**：把权限设为**公共读**。若保持私有，外部用户是访问不到的。

这三项属于"建完 Bucket 必须检查"的清单，尤其公共读权限最容易被漏掉。

### 流水线里新增 OSS 上传步骤

回到云效流水线，在上一节"打包构建"步骤之后**再添加一个步骤**，选择「OSS 上传」。选中后，平台会自动带上「对象存储 OSS 服务连接」。随后逐项填写：

- **Bucket 地域**：按自己账号所在地域选择，例如广州、北京、深圳；
- **Bucket 名称**：从下拉列表里选中刚新建的那个 Bucket；
- **Bucket 目录**：上面的这个目录可以**不填**；
- **源文件目录**：**必填**，用来确定把哪些文件上传到 Bucket。

### 源文件目录到底填什么

这是本节最容易填错的一项。看代码里的路径结构：打包后生成的 `dist` 位于 `packages/client` 之下，与 `public`、`src` 同级。目录关系示意：

```text
packages/
└── client/
    ├── public/
    ├── src/
    └── dist/        ← 打包产物，待上传的线上代码
```

因此源文件目录应指向：

```text
packages/client/dist
```

有一个细节要留意：本地限制了 Git 上传，`dist` 并没有提交到云效代码库里，它是流水线执行打包构建之后**才生成**的。所以配置这一步时必须和前一步的打包构建串起来——先构建产出 `dist`，OSS 上传步骤才能找到并上传它。

### 串起整条链路

配置完成后，流水线的执行顺序是：

1. 运行打包构建，生成 `packages/client/dist`；
2. 进入 OSS 上传步骤，自动关联到选定的 Bucket；
3. 把 `dist` 下的静态代码上传到 Bucket，供线上访问。

本节最后点击「仅保存」，**先不要运行**——等后续几个部署配置都补齐后再统一执行，避免中间态上线。本文没有关联具体项目源码文件，以上路径与配置项均按本节讲解的流水线配置整理。

## 小结

- 打包构建产出 `dist`，线上代码都在其中，需上传到 OSS 的 Bucket。
- 新建 Bucket 后要配置域名绑定、静态页面首页 `index.html`、读写权限设为公共读。
- 流水线新增「OSS 上传」步骤，选 Bucket 地域与 Bucket 名称。
- Bucket 目录可不填，源文件目录必填，指向 `packages/client/dist`。
- `dist` 未提交到代码库，由流水线打包后才生成，所以上传步骤必须接在构建步骤之后。
- 配置完先「仅保存」，暂不运行。

## 下一步

前端静态代码上传配置好后，建议接着看《React项目部署配置—Docker-compose文件上传至公共存储空间》，把 `docker-compose.yaml` 也纳入部署链路；随后后端 Nginx 镜像、服务端渲染镜像的构建上传会依次展开，最终串成完整的自动化部署流水线。
