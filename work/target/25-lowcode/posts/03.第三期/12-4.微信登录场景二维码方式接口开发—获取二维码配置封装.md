# 微信登录场景二维码方式接口开发—获取二维码配置封装

> **导语**：本文实现时序图中的「生成二维码与 ticket」环节。我们封装三个方法：`getAccessToken`、`getTicket`、`getQrCode`，在控制器暴露 GET 接口，返回二维码 URL 与 ticket，并把 ticket 以 `{ isScan: false }` 存入 Redis，等待用户扫码。

## 前置知识

- 已完成《微信登录场景二维码方式接口开发—微信服务器接入验证》的接入配置。
- 微信所有能力都需先获取 `access_token`，它是调用后续接口的「钥匙」。
- 了解 Redis 的 `set` 与过期时间（单位：秒）。

## 正文

### 新增获取二维码的控制器

在 `wechat-login.controller.ts` 中加一个 GET 接口 `login`：

```ts
@Get('login')
async wechatLogin() {
  return this.wechatLoginService.login();
}
```

### 封装获取 access_token

在 `wechat-login-two.module.ts` 中新增私有方法 `getAccessToken`，通过 fetch 请求课程提供（或官方）的地址，拼接 `appId`、`appSecret`：

```ts
private accessTokenUrl = 'https://api-v2.chatclass.net/...?appid=xxx&secret=xxx';

async getAccessToken() {
  const response = await fetch(this.accessTokenUrl);
  return await response.json();（返回整个 json，取 access_token 在调用方）
}
```

正式开发时把域名替换为微信官方 `https://api.weixin.qq.com/...` 即可。

### 封装获取 ticket

微信官方文档「账号管理 → 生成带参数二维码」中，**临时二维码**通过 POST 请求创建，body 为 JSON，包含 `expire_seconds`（本例 120 秒）、`action_name: 'QR_SCENE'`、`action_info`：

```ts
async getTicket(token: string) {
  const response = await fetch(
    `https://api-v2.chatclass.net/...?access_token=${token}`,
    {
      method: 'POST',
      body: JSON.stringify({
        expire_seconds: 120,
        action_name: 'QR_SCENE',
        action_info: { scene: { scene_id: 123 } }（源码示例值）
      })
    }
  );
  return (await response.json()).ticket;
}
```

正确返回中 `ticket` 就是一段字符串，凭它在有效期内换取二维码。

### 封装获取二维码 URL

把 `config.ts` 中的 `qrUrl` 前缀与 `ticket` 拼接即可：

```ts
async getQrCode() {
  const token = (await this.getAccessToken()).access_token;（与上式一致：getAccessToken 返回 json 对象）
  const ticket = (await this.getTicket(token)).ticket;
  const qrCodeUrl = `${this.config.qrUrl}?ticket=${ticket}`;
  return { qrCodeUrl, ticket };
}
```

### 服务层：存 ticket 到 Redis

在 `wechat-login.service.ts` 中调用上面方法，并把 ticket 作为 key 存入 Redis，value 为对象（含 `isScan`）：

```ts
const { qrCodeUrl, ticket } = await this.wechatLoginTwoModule.getQrCode();
const redisKey = `wechat:ticket:${ticket}`;
await this.redis.set(
  redisKey,
  JSON.stringify({ isScan: false }),
  'EX',
  120
);
return { data: { qrCodeUrl, ticket } };
```

存入时 `isScan: false`，供后续用户扫码后改为 `true`。

### 接口联调

启动服务后，浏览器访问 `/api/wechat_login/login`，返回 `data.qrCodeUrl` 与 `data.ticket`，打开 `qrCodeUrl` 即可看到二维码。此时 Redis 中 `wechat:ticket:xxx` 的 `isScan` 为 `false`。

## 小结

- 获取二维码需三步：access_token → ticket → 拼接 `qrUrl?ticket=xxx`。
- 临时二维码建议设置 `expire_seconds: 120`（2 分钟）。
- ticket 以 `wechat:ticket:${ticket}` 为 key 存入 Redis，value 为 `{ isScan: false }`，过期 120 秒。
- 课程环境与正式环境仅域名不同，替换为官方 `api.weixin.qq.com` 即可上线。
