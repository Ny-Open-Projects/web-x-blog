# 低代码项目前端项目开发—微信登录接口联调

> **导语**：本文完成微信扫码登录的前端闭环：定义「获取二维码」与「轮询」两个接口，在 `WeChatLogin` 组件中接入 `useRequest`，实现点击按钮拿 ticket/二维码、定时轮询判断扫码状态、扫码成功后自动登录跳转。

## 前置知识

- 已完成《低代码项目前端项目开发—微信登录前端页面开发》的静态结构。
- 后端已有 GET `/wechat_login/login`（获取二维码）与 GET `/wechat_login/check_scan?ticket=xxx`（轮询）。
- 已安装 `ahooks`（含 `useRequest` 的 `debounceWait` 防抖/轮询配置）。

## 正文

### 定义微信登录接口

在 `src/api/wechat-login.ts` 中：

```ts
export async function getWechatLogin() {
  return makeRequest('/wechat_login/login');
}
export async function checkScan(ticket: string) {
  return makeRequest(`/wechat_login/check_scan?ticket=${ticket}`);
}
```

获取二维码无参数（GET），轮询需传 `ticket`。

### 获取二维码并展示

```tsx
const { run: getQr, loading } = useRequest(() => getWechatLogin(), {
  manual: true,
  onSuccess: (res) => {
    setTicket(res.data.ticket);
    setQrCodeUrl(res.data.qrCodeUrl);
    setWechatLogin(true); // 打开弹窗
    // 启动 120 秒倒计时，过期把 activeQrCode 置 false
  }
});
```

点击「微信账号登录」或「重新刷新」时调用 `getQr`。`loading` 期间展示旋转兜底，成功后展示二维码图片。

### 轮询判断扫码状态

轮询接口用 `useRequest` 并设置 `manual: true`（手动触发）与 `debounceWait`：

```tsx
const { run: poll } = useRequest((ticket) => checkScan(ticket), {
  manual: true,
  debounceWait: 2000, // 防抖 2 秒：轮询靠 onSuccess 里无 data 时递归 run，防抖把节奏压到约 2 秒一次
});
```

轮询逻辑：

1. 若 `wechatLogin` 为 `false`（弹窗未开）直接 return。
2. 无 `data` → 继续轮询（用户尚未扫码）。
3. 有 `data`（token）→ 关闭弹窗，调用 `login(token)` 完成登录。

```tsx
onSuccess: (res) => {
  if (!wechatLogin) return;
  if (!res.data) { poll(ticket); return; }
  setWechatLogin(false);
  login(res.data);
}
```

打开弹窗后立即启动轮询；后端在用户未扫码时返回空 `data`（仅 `code:0`），有扫码时返回 `data` 为 token。

### 联调注意点

- 轮询节奏：`debounceWait` 设为 2000 毫秒（2 秒一次）更合理，避免 500 毫秒过快。
- 二维码过期时间应为 `120 * 1000`（2 分钟），而非 120 毫秒。
- 关闭按钮需放在 Modal 外层控制标签，避免点击关闭误触发按钮再次打开。
- 后端 `appId`/`appSecret` 会定时更新，练习间隔较久需回小滴课堂官网重新复制 `appSecret`；本地需用花生壳内网穿透让微信回调可达。

### 联调验证

启动前后端，刷新页面点「微信账号登录」：按钮置灰、展示二维码、每 2 秒轮询一次；手机微信扫码后，最后一次轮询返回 `data`（token）并登录成功，跳转低代码编辑页。

## 小结

- 微信登录前端两接口：获取二维码（GET）、轮询（GET + ticket）。
- 获取二维码成功后写入 `ticket`/`qrCodeUrl`、打开弹窗、启动 120 秒倒计时。
- 轮询用 `debounceWait: 2000`，无 data 继续轮询，有 data 即登录。
- 注意轮询节奏、二维码过期时间（2 分钟）、关闭按钮位置与后端密钥刷新。
