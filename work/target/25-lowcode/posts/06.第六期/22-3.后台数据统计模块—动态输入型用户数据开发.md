# 后台数据统计模块—动态输入型用户数据开发

> **导语**：上节渲染出可点击切换的问卷组件表格。本节实现「点击查看数据后，下方动态展示用户填写内容」——对 input / textArea 这类输入型组件，按组件 ID 请求提交数据并渲染；对 radio / checkbox 则留坑给下一节的 ECharts 图表。重点讲清输入型与图表型的判断逻辑。

## 前置知识

- 需先读《后台数据统计模块—动态输入型问卷组件开发》，本节的 `currentSelect` 由它传入。
- 数据请求使用 `ahooks` 的 `useRequest`（前端 `package.json` 含 `"ahooks": "^3.7.8"`）。
- 后端有「根据组件 ID 获取问卷填写数据」的接口，对应路径类似 `/api/low_code/get_question_data_by_id`，POST 请求。

## 正文

### 用 isMore 区分两类组件（源码变量名 isMore，语义：radio/checkbox 图表型为 true）

父组件把 `currentSelect`（当前选中组件）传给 `DataSource` 子组件。子组件先用 `useMemo` 判断它是否是「输入型」：

```ts
const isMore = useMemo(() => {
  const array = ['radio', 'checkbox'];
  return !array.includes(currentSelect?.type);
}, [currentSelect]);
```

逻辑很直白：radio / checkbox 属于固定选项、能聚合，归为图表型；其余（input、textArea）是用户自由输入，归为输入型。后续用 `isMore`（语义相反：radio/checkbox 图表型为 true） 决定下方渲染「文本列表」还是「图表占位」。

```tsx
{isMore ? <图表占位 /> : <生成用户输入内容 />}
```

### 生成用户输入内容

`generatorTexts` 负责把用户提交的问卷数据渲染出来：

```tsx
function generatorTexts() {
  const pageTitle = store.title; // 低代码编辑平台配置的页面标题
  const flat = currentData.flat();   // 服务端返回的是二维数组，先拍平成一维
  return (
    <div>
      <span>{pageTitle} 的问卷填写信息</span>
      {flat.map((text, index) => (
        <p key={index}>{text}</p>
      ))}
    </div>
  );
}
```

要点：

- 页面标题从全局 store 取（编辑平台配的标题）；
- `currentData` 是「数组包数组」的二维结构，用 `flat()` 拍平成单层再遍历；
- 用 `index` 当 `key` 渲染每条填写内容，切换不同组件即展示不同用户的数据。

### 按 ID 重新请求接口

点击不同组件的「查看数据」时，需要重新拉一次数据。用 `useRequest` 封装接口：

```ts
const { run } = useRequest(
  (id: number) => getQuestionDataByTypeRequest({ id }),
  {
    manual: true, // 手动触发
    onSuccess: (res) => {
      const data = res.map((item) => item.value);
      setCurrentData(data);
    },
  }
);
```

- 因为父组件已传了默认选中项，manual: true 禁用自动执行，另用 `useEffect` 监听 `currentSelected`（含首屏）触发 `execGetQuestionData()`——这正是首屏默认展示第一个组件数据的落点；
- 点「查看数据」时调用 `run(id)` 才真正发请求；
- `onSuccess` 里只抽取每条记录的 `value`，组成新数组塞进 `currentData`。

接口定义上，简单类型直接 `{ id: number }` 即可，不必非得在 `share` 里声明复杂 DTO。

### 输入型 vs 图表型的分流

整套数据流是：

1. 父组件 `currentSelect` 变化 →
2. 重新 `run(id)` 请求该组件填写数据 →
3. `isMore`（语义相反：radio/checkbox 图表型为 true） 判定类型：
   - 输入型（input / textArea）：渲染 `generatorTexts` 文本列表；
   - 图表型（radio / checkbox）：渲染图表占位，下一节接 ECharts。

## 小结

- `useMemo` 用 `['radio','checkbox']` 判断 `isMore`（语义相反：radio/checkbox 图表型为 true），区分输入型与图表型。
- 服务端返回二维数组，前端用 `flat()` 拍平后遍历渲染。
- `useRequest` 设 `manual: true`，点击「查看数据」时 `run(id)` 按组件 ID 重新请求。
- `onSuccess` 抽取每条 `value` 存入 `currentData`，驱动下方展示。
