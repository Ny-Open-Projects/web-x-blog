# 后台数据统计模块—用户表格数据导出Excel压缩包

> **导语**：上节我们实现了 Excel 文件的浏览器下载。本节更进一步——用 JSZip 把导出的 Excel 再打包成 ZIP 压缩包，让下载体积更小、更便于批量分发。核心思路是复用上节的「生成 Buffer」逻辑，但跳过「写文件」分支，改用 JSZip 生成 Blob 后同样走浏览器下载。

## 前置知识

- 先读完《后台数据统计模块—用户表格数据导出Excel《下》》，本节的 `saveFile` / `saveFileWithBlob` / `isWriteFile` 都建立在其之上。
- JSZip 是成熟的压缩库，项目前端依赖见 `课程配套代码/22-1/lowcode/packages/client/package.json` 中的 `"jszip": "^3.10.1"`。
- 了解 `Blob` 与 `URL.createObjectURL` 的基本用法（见上节）。

## 正文

### 整体思路：复用生成，跳过写文件

导出压缩包和导出Excel 的前半段完全一样：请求数据 → 组装工作簿 → `writeBuffer()` 得到二进制 Buffer。区别只在最后一步——

- 导出Excel：走 `isWriteFile = true` 分支，手动 `new Blob(...)` 再下载；
- 导出压缩包：把 `isWriteFile` 设为 `false`，拿到 Buffer 和 title 后交给 `excelToZip`，由 JSZip 来生成 Blob。

也就是说，我们**不再自己原生构造 Blob**，而是让 JSZip 在 `generateAsync` 时直接产出 `type: 'blob'` 的对象，更省事。

### 在页面上绑定导出压缩包按钮

给统计页再加一个按钮，绑定 `handleExportZip`：

```ts
const buffer = await jsonToExcel(data, { isWriteFile: false });
// buffer、title 都在返回对象里
excelToZip(buffer, title);
```

注意 `jsonToExcel` 这里传入 `isWriteFile: false`，表示「只生成 Buffer，不写文件」，这样就不会触发上节的下载逻辑，而是把结果交给我们自己处理。

### excelToZip：用 JSZip 打包

`excelToZip` 同样放在 `utils/excel` 工具里：

```ts
import JSZip from 'jszip';

async function excelToZip(buffer: ArrayBuffer, title: string) {
  const zip = new JSZip();
  // 第一个参数是压缩包内文件名，第二个参数是内容（二进制形式传入）
  zip.file(`${title}数据统计.xlsx`, buffer);
  // 生成 Blob 类型的压缩包
  const blob = await zip.generateAsync({ type: 'blob' });
  saveFileWithBlob(blob, `${title}.zip`);
}
```

关键点：

- `zip.file(name, content)`：第一个参数是「压缩包里面的文件名」，第二个参数是二进制 Excel 内容；
- `zip.generateAsync({ type: 'blob' })`：异步生成 Blob，JSZip 内部已经帮我们处理好 Blob 转换，不用再手动 `new Blob`；
- 最后依旧调用上节的 `saveFileWithBlob`，复用「创建 `<a>` + `download` + `click()` + `revokeObjectURL`」整条下载链路。

### 关于后缀名的小提示

课程演示用的是 macOS，压缩包后缀自然是 `.zip`，下载解压后得到和上一节一模一样的 Excel 内容。如果你在 Windows 上，Windows 10/11 自带 ZIP 解压（双击即可打开 JSZip 生成的 `.zip`）；想产出 RAR 才需要装第三方工具；若你不想产出 ZIP 类型，可另行寻找能生成 RAR 的插件。

## 小结

- 导出压缩包复用「生成 Buffer」逻辑，仅关闭 `isWriteFile` 开关。
- JSZip 用 `file()` 放入 Excel，用 `generateAsync({ type: 'blob' })` 产出 Blob。
- 下载动作仍复用 `saveFileWithBlob`，无需重复造轮子。
- 压缩后体积更小，适合批量分发；后缀按平台习惯处理即可。
