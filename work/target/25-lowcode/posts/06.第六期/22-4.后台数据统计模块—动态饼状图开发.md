# 后台数据统计模块—动态饼状图开发

> **导语**：上节对 radio / checkbox 留了图表占位。本节用 ECharts for React 把占位补成真正的动态饼状图——以「性别」组件为例，左侧图例、标题、鼠标悬浮放大与计数提示一应俱全。核心是把后端返回的数据处理成 ECharts 需要的 `{ name, value }` 格式。

## 前置知识

- 先读《后台数据统计模块—动态输入型用户数据开发》，本节的 `currentSelect`、`currentData` 来自它。
- 图表库见前端 `package.json`：`"echarts": "^5.4.3"` 与 `"echarts-for-react": "^3.0.2"`。
- ECharts 配置项繁杂，按官方文档（title / tooltip / legend / series）查用即可，不必死记。

## 正文

### 用 ReactECharts 替换占位

把上节的图表占位抽成 `ReactECharts` 组件：

```tsx
import ReactECharts from 'echarts-for-react';

<ReactECharts option={getPieOptions()} />
```

`echarts-for-react` 只需传 `option` 配置对象，其余内部帮你渲染。配置由 `getPieOptions()` 生成。

### 饼状图配置 getPieOptions

```ts
function getPieOptions() {
  return {
    title: { text: itemTitle }, // 标题，如「性别」
    tooltip: {},                // 悬浮提示框
    legend: { orient: 'vertical', left: '20%' }, // 图例左上角垂直排列
    series: [
      {
        name: '分类个数',
        type: 'pie',
        radius: '50%',
        data, // [{ name: '男', value: 1 }, ...]
      },
    ],
  };
}
```

- `title.text` 用 `useMemo` 从 `currentSelect.options.title` 取（缺省有兜底标题），这样切换到 checkbox 时标题会自动变「爱好」；
- `legend` 设左上角、垂直排列；
- `series[0].type = 'pie'`，`radius: '50%'` 控制圆大小；
- 真正的数据放在 `data` 里。

### 把数据整理成 { name, value }

`data` 同样用 `useMemo` 计算，处理的就是「每个选项被选了几次」：

```ts
const data = useMemo(() => {
  // columnOptions: 组件选项 [{ id, value }]
  return columnOptions.map((item) => ({
    name: item.value,
    value: result[item.id] ?? 0,
  }));
}, [columnOptions]);
```

`result` 是个「以选项 ID 为键、出现次数为值」的对象，用 `reduce` 统计：

```ts
const result = currentData.reduce((acc, arr) => {
  arr.forEach((val) => {
    acc[val] = (acc[val] ?? 0) + 1;
  });
  return acc;
}, {});
```

`currentData` 是 `currentData` 的副本。逻辑是：遍历每个选项 ID，在结果对象里累加计数。控制台打印可验证 `result` 形如 `{ '': 1, '女性选项ID': 1 }`（第一个选项无 ID 时 key 为空）。

### 数据随选中项动态更新

`currentSelected` 和 `isMore` 变化时，会重新跑上面的 `useMemo`，更新 `data` 与 `itemTitle`。例如：

- 选中「性别」组件 → 标题「性别」，饼图显示男 / 女各 1；
- 切到「爱好」组件 → 标题自动变「爱好」，饼图数据随之刷新。

悬浮到扇形上会显示对应分类的个数（由 `tooltip` 提供），整体交互完成。

## 小结

- `echarts-for-react` 只吃 `option`，配置按官方文档拼。
- 标题、数据都用 `useMemo` 跟随 `currentSelect` 动态计算。
- 数据格式必须为 `{ name, value }`，用 `reduce` 统计各选项出现次数。
- series 中 `type: 'pie'` + `radius` 控制圆形；`legend` 控制图例位置。
