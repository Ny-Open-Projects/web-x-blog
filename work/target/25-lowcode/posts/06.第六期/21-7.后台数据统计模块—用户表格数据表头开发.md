# 后台数据统计模块—用户表格数据表头开发

> **导语**：左侧用户统计表格的表头来自问卷组件的 `title`。本文讲解在 `dataCount` 父组件用 `useRequest` 请求「获取问卷组件」接口、把返回数据重组成 Ant Design Table 要求的 `{ title, dataIndex, key }` 格式，并在无问卷组件时置灰页面。

## 前置知识

- 已搭建统计页布局，见《后台数据统计模块—前端页面布局开发》。
- 已开发获取问卷组件接口，见《后台数据统计模块—后端接口获取问卷组件开发》。
- 已了解 Ant Design Table 列定义，见《低代码平台项目前端 React 项目配置—Ant-design+TailwindCSS》。

## 正文

### 父组件请求问卷组件接口

在 `dataCount` 中定义 `components` 状态（`useState`），通过 `useRequest` 请求 `getQuestionComponents`（封装于 `api/low-code`，底层 `axios` 请求 `/api/low_code/question_components`）：

- `useRequest` 未设 `manual`，进入页面即自动请求一次；
- `onSuccess` 里解构出 `data`，判断 `data.length === 0` 时说明该发布页没有问卷类型组件，调用 `handleDisable`（即 `setDisable(true)`）置灰，并提示「请先创建至少一个表单组件」；
- 有数据则把 `data` 存入 `components`，并传给子组件 `ComponentDatas`，同时传入 `handleDisable`。

### 子组件重组表头格式

抽离子组件 `ComponentDatas`（子组件在 `pages/DataCount/`（大写 D），父组件是 `pages/dataCount.tsx`），接收 `components` 与 `handleDisable`。表格用 Ant Design 的 `Table`，其列数据（`columns`）需满足格式：`{ title, dataIndex, key }`（三者要一致，便于后续按 `dataIndex`/`key` 定位内容）。

父组件传来的原始数据是 `{ id, type, options, page_id, ... }`，需要在子组件用 `useMemo`（依赖父组件 `components` 变化）遍历重组：

```ts
const cols = components.map((item) => ({
  title: item.options?.title ?? '默认标题',
  dataIndex: item.id,   // 如 337 / 338 / 339 / 340
  key: item.id,
}));
```

- `key` 与 `dataIndex` 都设为组件 `id`（如 337 姓名、338 描述、339 性别、340 爱好）；
- `title` 取 `options.title`，缺失则兜底默认标题。

重组后的数组（含 `dataIndex`/`key`/`title`）直接传给 `Table` 的 `columns`，即可渲染出「姓名/描述/性别/爱好」表头。

### 调试要点

可临时 `console.log` 父组件原始数据确认结构，再打印重组后的 `cols` 验证格式符合 antd 要求。注意原始数据属性多，若不重组直接喂给 Table 会因缺 `dataIndex`/`key` 而报错。

## 小结

1. 父组件 `useRequest` 自动请求 `getQuestionComponents`，无数据则置灰并提示。
2. 子组件 `ComponentDatas` 用 `useMemo` 把 `{id,type,options}` 重组成 `{title,dataIndex,key}`。
3. `dataIndex`/`key` 取组件 `id`，`title` 取 `options.title`（兜底默认）。
4. 重组后的列数组直接传给 antd `Table` 的 `columns` 渲染表头。
