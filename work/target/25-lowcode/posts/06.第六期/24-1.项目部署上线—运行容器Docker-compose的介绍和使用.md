# 项目部署上线—运行容器Docker-compose的介绍和使用

> **导语**：前面已经分别构建出了发布项目、后端服务，以及两者对应 Nginx 的镜像，镜像一多，逐个敲 `docker run` 启动就成了一件又长又易错的事。本文讲 Docker Compose：用一份 YAML 配置文件提前编排好多个容器的创建与启动参数，再用一条命令同时启动或关闭它们。读完后你能看懂 `docker-compose.yml` 的结构，也能把它和手写 `docker run` 对应起来。

- 会在 Linux 服务器上执行基本的 Docker 命令。

## 正文

### 为什么需要 Docker Compose

到这一步，我们手上有多个镜像要构建并运行：发布项目镜像、后端服务镜像，以及前后两个 nginx 镜像。如果直接在服务器上为每个容器配置启动命令，命令又多又杂，还容易漏掉端口映射、环境变量这类参数。

Docker Compose 是 Docker 官方推出的工具，用来**管理多个容器、把它们组织成一个应用服务**。它把多个容器之间的创建与启动命令提前编排进一份配置文件，最后只用一个命令就能同时启动或关闭这些容器，多容器场景的管理成本一下子降下来。后面要讲的阿里云云效 DevOps 一键部署，也是建立在这套编排能力之上。

### 配置文件：docker-compose.yml

与 Dockerfile 类似，Docker Compose 也靠配置文件工作，但格式是 **YAML**，文件名通常是 `docker-compose.yml`（后缀是 `yaml` / `yml`，不是 Dockerfile 那一套）。文件放在代码工作区根目录。需要区分不同环境时，也可以在文件名上做备注，比如针对 MySQL、Redis 各准备一份。

### 先看手写 docker run 长什么样

以启动一个 MySQL 容器为例，平时在 Linux 服务器里会写成多行命令（行尾用 `\` 换行）：

```bash
docker run \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=<你的密码> \
  --name class_mysql \
  --restart always \
  -d mysql:8.0
```

各参数含义：`-p` 端口映射、`-e` 设置 MySQL 密码、`--name` 容器名、`--restart` 让 Docker 重启后容器也自动重启、`-d` 后台运行，最后是镜像及版本 `mysql:8.0`。

### 用 YAML 替代这一长串命令

同样的配置放进 `docker-compose.yml`，结构如下（示意，字段与取值按本节讲解整理）：

```yaml
version: '3.0'

services:
  mysql-db:
    image: mysql:8.0
    restart: always
    container_name: class_mysql
    environment:
      MYSQL_ROOT_PASSWORD: <你的密码>
    ports:
      - "3306:3306"

  redis:
    image: redis:4.0
```

几处对照关系：

- `version` 指定 Docker Compose 版本，这里用 `3.0`（旧版本会被弃用，选 3 系）；
- `services` 下配置要启动的多个容器，每缩进一层就是一个新服务；
- `mysql-db` 服务里，`image`、`restart`、`container_name`、`environment`（密码）、`ports`（端口映射）逐一对应手写命令里的参数；
- 再加一个容器只需在 `services` 下继续缩进写一个服务，例如 `redis` 配 `image: redis:4.0`，即可同时启动多个容器。

也就是说，手写命令里的每个开关，在 YAML 里都有对应的键；把分散的命令收拢成声明式配置，就是 Docker Compose 的核心价值。

### 一条命令启动与关闭

配置文件准备好后，用下面的命令启动：

```bash
docker compose -f docker-compose.yml up -d
```

- `-f`：指定依赖哪个配置文件去执行；
- `up`：启动运行；
- `-d`：后台运行。

同理，关闭这些容器也只需对应的 `down` 命令，不必逐个容器处理。下一节会实际启动低代码平台的四个容器，把 `image`（tag 变量）、`restart`（总是重启）、`ports`、`extra_hosts` 逐项配齐（最终仓库 compose 无容器名/环境变量，MySQL/Redis 宿主机自装）。

## 小结

- Docker Compose 用于管理多个容器组成的应用服务，一条命令即可同时启动或关闭。
- 配置文件是 YAML 格式的 `docker-compose.yml`，放在代码工作区根目录，不是 Dockerfile。
- `version`、`services`、`image`、`restart`、`container_name`、`environment`、`ports` 分别对应手写 `docker run` 的各项参数。
- 在 `services` 下继续缩进添加服务，就能编排 Redis 等多个容器。
- 启动命令为 `docker compose -f docker-compose.yml up -d`，`-f` 指定文件、`up` 启动、`-d` 后台运行。
