# Jmeter5.X基础功能组件+线程组和取样器

> **导语**：环境装好之后，真正上手 JMeter 要先搞懂两个核心概念——线程组（模拟并发用户）和取样器（具体要压哪个接口）。本文用课程低代码平台的"发布页面获取组件"接口做例子，带你完成第一个压测脚本的搭建。

## 前置知识

本文依赖《多环境快速安装Jmeter5》中完成的 JMeter 5.x 安装与汉化。压测目标接口来自课程后端（NestJS）与发布页面（Next.js），建议对 HTTP 请求有基本认知即可。

## 正文

### 什么是线程组（Thread Group）

JMeter 里，**线程组**就是"一组并发执行的线程"，用来模拟多个用户同时请求服务。

可以把它想象成这样：一个网页打开后，前端会并发请求很多后端接口；每个用户的每一次请求，都可以看作一个线程；一组用户一起请求，就组成了线程组。

右键 **测试计划 → 添加 → 线程 → 线程组**，即可创建。除了普通的"线程组"，菜单里还有 **setUp 线程组**、**tearDown 线程组** 以及 **开放模型线程组（Open Model Thread Group）** 等类型，日常最常用的就是普通"线程组"，其余类型我们后续单独讲。

### 线程组的三个关键参数

创建线程组后，重点理解下面三个变量：

| 参数 | 含义 | 例子 |
| --- | --- | --- |
| 线程数 | 模拟的虚拟用户数，一个用户≈一个线程 | 设为 50，即 50 个并发用户 |
| Ramp-Up 时间（秒） | 在多少秒内把所有线程启动完毕 | 设为 10，即 10 秒内启动 50 个线程，约每秒 5 个 |
| 循环次数 | 每个线程重复发送请求的次数 | 设为 2，则总请求 = 50 × 2 = 100 |

组合理解：

- 线程数 50 + Ramp-Up 10 秒 + 循环 1 次 → 10 秒内完成 50 个请求，约每秒 5 个。
- 线程数 50 + Ramp-Up 10 秒 + 循环 2 次 → 总请求 100 个，约每秒 10 个。
- 勾选"永远"循环，则会持续不断地请求，常用于稳定性/耐久性压测，调试阶段记得关掉。

此外，"取样器错误后要执行的动作"保持默认"继续"即可，单个请求失败不影响整体。

### 什么是取样器（Sampler）

线程组只决定了"多少人、多快、循环几次"，但具体**压哪个接口**由取样器决定。JMeter 支持 HTTP、FTP、JDBC 等多种协议的取样器，我们的接口都是 HTTP 请求，所以用 **HTTP 请求** 取样器。

右键 **线程组 → 添加 → 取样器 → HTTP 请求** 即可。一个线程组下可以添加多个取样器（比如把用户注册、登录接口都放进来）。

### 实战：压测"发布页面获取低代码组件"接口

以课程低代码平台为例，发布出去的页面访问时会请求一个**免登录、GET 方式、仅需 `?id=` 页面参数**的接口，非常适合作为第一个演示接口（对应代码 `packages/server/src` 中端口 3000 的 release 模块）。

在 HTTP 请求取样器中按如下填写：

- **名称**：发布页面获取低代码组件接口（可自定义，便于区分）
- **协议**：`http`（本地服务，不是 https）
- **服务器名称或 IP**：`127.0.0.1`
- **端口号**：`3000`（来源于 `src/main.ts` 的 `app.listen(3000)`）
- **方法**：`GET`
- **路径**：`/api/low_code/release?id=3`

> 说明：不同电脑压测同一本地接口，结果会因机器性能、网络环境而异。若想更接近真实，可将服务部署到云服务器（Linux）后在局域网/服务器内压测。本文聚焦本地演示。

如果是 POST 请求，需要在"消息体数据"里填请求体，文件上传（图片、视频等）相关配置也在对应选项卡中设置。

填完后点击 **保存**，建议把 `.jmx` 脚本存到本集对应目录（如 `28-5`），方便后续复现。配套资料里已提供 `线程组-000001.jmx`、`线程组-000002.jmx` 等示例脚本可供对照。

### 运行脚本

选中线程组，点击工具栏的 **启动** 按钮即可运行。若勾选了"永远"，运行会一直持续，可随时点 **停止**；调试时建议设循环次数为 1，10 秒 Ramp-Up 跑完即自动结束。

不过，运行完之后请求到底成功没成功、响应时间多少、吞吐量（TPS）如何——这些我们还看不到。下一节课就来解决这个问题。

## 小结

- 线程组模拟并发用户，核心是**线程数 / Ramp-Up 时间 / 循环次数**三个参数。
- 取样器决定压测的具体接口，HTTP 接口用 **HTTP 请求** 取样器。
- 一个线程组可挂多个取样器，也可创建多个线程组分别管理不同模块（用户模块、低代码接口模块等）。
- 本地调试用 `127.0.0.1:3000`，GET 接口填协议/IP/端口/路径即可，POST 需在消息体数据填参。
- 运行结果需在"查看结果树/聚合报告"中观察，下集讲解。
