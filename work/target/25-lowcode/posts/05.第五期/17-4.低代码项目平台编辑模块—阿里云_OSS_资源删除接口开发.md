# 低代码项目平台编辑模块—阿里云_OSS_资源删除接口开发

> **导语**：删除配置就绪后，本节把它封装成真正的 `DELETE` 接口。接口先校验登录与资源存在性，再串联（教学注：源码把归属校验放在删库一步、晚于删 OSS，严格说存在越权删文件隐患，先验归属再删 OSS 才是安全顺序）“删 OSS 对象 + 删数据库记录”两步，确保存储与元数据一致；最后用 Apifox 实测，验证 OSS 文件与数据库行同步消失。

## 前置知识

阅读本文前，建议先掌握《低代码项目平台编辑模块—阿里云 OSS 资源删除配置》。本文使用上一节写好的 `deleteFromAliOss(url)` 方法，并在 `resource` 模块里补齐控制层与服务层。

## 正文

### 控制层：DELETE 删除接口

在 `resource.controller.ts` 中新增一个 RESTful 风格的 `DELETE` 接口（路由用单数 `resource`，不加 s）。两点约束：

- 必须登录：复用之前的登录鉴权，解密 token 拿到当前用户 `id`；
- 删除目标是**数据库里的资源记录 id**，通过 `@Query()` 装饰器接收。

```ts
@Delete()   // 或 /resource?id=xxx，按课程实现为准
@UseGuards(AuthGuard)（最终仓库为 APP_GUARD 全局守卫 + @Public() 白名单）
async delete(
  @Query() query: DeleteResourcesRequest, // 仅含 id
  @getUserMess() user: { id: number },
) {
  return this.resourceService.delete(Number(query.id), user.id);
}
```

`DeleteResourcesRequest` 类型定义在 `share` 项目里，这里只需要 `id` 字段——对应 Navicat 里 `resources` 表中每条记录的主键。

### 服务层：先查、再删 OSS、最后删库

`ResourcesService.deleteResource(id, account_id)` 接收两个 number 类型参数：资源记录 `id` 与用户 `userId`。逻辑分四步：

**1. 查询资源是否存在**

```ts
const resource = await this.resourceRepo.findOneBy({ id });
if (!resource) {
  throw new BadRequestException('资源不存在');
}
```

查不到直接抛“资源不存在”。

**2. 删除 OSS 上的对象**

依赖已声明好，调用上一节的删除方法，传入的是**数据库里该资源的 URL**（不是前端接口传过来的 id）：

```ts
await this.aliOss.deleteFromAliOss(resource.url);
```

> 注意：传给阿里云删除 API 的是资源 URL，前端接口只负责传记录 id；二者不要混淆。

**3. 删除数据库记录**

OSS 删掉后，数据库记录也要同步删除，并且用 `id` + `userId` 两个条件一起约束，双重保险更稳妥：

```ts
await this.resourcesRepository.delete({ id, account_id });
```

**4. 返回结果**

两步都成功即返回“删除成功”。

### Apifox 联调实测

打开 Apifox 新建一条测试用例：

- 请求：`DELETE /api/resources?id=xxx`（Query 传 id），不是 `upload`；
- 参数：不再用 body，而是在 **Query** 里传 `id`（即你想删的那条 URL 对应的记录 id）；
- Headers：带上 `Authorization: Bearer <token>`（token 有效期 7 天，可从上传接口的用例直接复制过来）。

测试结果：

- 传 `id=12`：返回删除成功。去阿里云 Bucket 刷新，原本的 `三个一-<时间戳>.jpg` 已经不在；再刷新数据库，`resource` 表里第 12 条记录也消失了——OSS 与数据库同步清理。
- 传 `id=10`（不存在）：接口返回“资源不存在”。

## 小结

- 删除接口为 RESTful `DELETE`，需登录鉴权，目标用 Query 传记录 `id`；
- service 四步：查存在 → 调 `deleteFromAliOss(resource.url)` 删 OSS → 用 `id+userId` 双条件删库 → 返回成功；
- 传给阿里云的是资源 URL，前端只传记录 id，二者区分清楚；
- 不存在的资源统一抛 `BadRequestException('资源不存在')`；
- Apifox 实测验证 OSS 文件与数据库行同步删除。
