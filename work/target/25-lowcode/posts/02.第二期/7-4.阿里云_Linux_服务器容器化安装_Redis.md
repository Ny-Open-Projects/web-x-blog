# 阿里云 Linux 服务器容器化安装 Redis

> **导语**：本文演示如何用一行 `docker run` 在阿里云 Linux 服务器上容器化安装 Redis，并讲解密码鉴权、端口放行，以及用 QuickRedis 可视化工具连接与基本操作。

## 前置知识
阅读本文建议先看完《阿里云 Linux 服务器容器化安装 Mysql》，已掌握 Docker 安装与容器端口映射、安全组放行的基本套路。

## 正文

### 一行命令安装 Redis
```bash
docker run --name xdclass-redis \
  -p 6379:6379 \
  -d redis \
  redis-server --requirepass xdclass.net168
```

参数说明：

- `--name xdclass-redis`：容器名称；
- `-p 6379:6379`：映射 Redis 默认端口；
- `-d redis`：后台运行 Redis 镜像；
- `redis-server --requirepass xdclass.net168`：设置访问密码。

执行时本地无镜像会自动拉取并运行，`docker ps` 可见名为 `xdclass-redis` 的容器。

### 放行安全组端口
同 MySQL 一样，需在阿里云安全组新增规则，把 3306 改为 **6379** 并保存，外部才能连接。

### 命令行操作 Redis
进入容器并用密码鉴权：

```bash
docker exec -it <容器ID> redis-cli
auth xdclass.net168
set name xdclass
get name
```

若未 `auth` 直接操作会提示无权限，需先鉴权再 `set`/`get`。

### 用 QuickRedis 可视化连接
资料提供的可视化工具为 **QuickRedis**。新建连接：

- 名称：`xdclass-local`；
- IP：服务器公网 IP；
- 端口：6379（默认）；
- 密码：`xdclass.net168`；
- 直连模式，测试连接成功后保存。

界面中可新建 key（如 `age`，值 `20`），刷新即显示；key 的过期时间 `-1` 表示永久有效，设置如 `10` 即 10 秒后过期（过期后状态变为 `-2`，key 消失）。

> 提示：Mac 安装 QuickRedis 若报错，可先在终端执行官方给出的修复命令再重装。

### 配套资料
QuickRedis 安装说明见课程资料包。

## 小结
- `docker run` 一行装 Redis：命名、映射 6379、后台运行、用 `--requirepass` 设密码；
- 安全组需开放 6379；
- 命令行进入容器后须先 `auth` 再操作；
- QuickRedis 用 IP + 6379 + 密码直连，可直观管理 key 与过期时间。
