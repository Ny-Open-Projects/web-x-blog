# 云服务器搭建 Docker 环境和使用讲解

> **导语**：本文在已购并连接云服务器的基础上，讲解 Docker 环境的搭建与基础命令。我们将演示更新 yum 源、安装 Docker CE、查看版本，以及容器与镜像的常用操作，为后续容器化安装 MySQL/Redis 打基础。

## 前置知识
阅读本文建议先看完《低代码平台云服务器选配》，确保已购服务器、重置密码并能 SSH 登录。

## 正文

### 为什么先装 Docker
本项目安装第三方应用、部署自有服务，都通过 Docker 完成，因此它是必备环境。

### 安装步骤
1. **更新 yum 源**（新购服务器务必执行）：

```bash
yum update
```

2. **安装依赖工具包**（来自阿里云官方步骤，直接复制执行）；
3. **添加阿里云 Docker CE 仓库**到服务器仓库列表，便于用 yum 源安装/更新 Docker CE；
4. **安装最新版 Docker**，完成后用 `docker -v` 查看版本（示例为 24.0.7）。

### 容器基础命令
```bash
systemctl start docker     # 启动
systemctl status docker    # 查看状态
systemctl stop docker      # 停止
systemctl restart docker   # 重启
docker ps                  # 查看运行中的容器
docker ps -a               # 查看所有容器（含已停止）
docker stop <容器ID>       # 停止指定容器
docker rm <容器ID>         # 删除已停止容器
docker images              # 查看本地镜像
docker rmi <镜像ID>        # 删除镜像（需指定镜像 ID）
```

> 注意：`docker rm` 删容器、`docker rmi` 删镜像，删除镜像可用镜像 ID 或名称（同标签多版本时用 ID 更精确）。

### 镜像仓库
所有可拉取的镜像都存放在 **Docker Hub** 镜像仓库。搜索镜像（如 MySQL、Redis）后，在 Tags 页可查看版本；不加版本默认拉取 `latest`。镜像体积可在 Tags 页查看，后续拉取 MySQL 一般选 8.0。

## 小结
- 安装顺序：更新 yum 源 → 装依赖 → 加阿里云 Docker CE 仓库 → 装 Docker → `docker -v` 验证；
- 容器命令：`start/status/stop/restart`、`ps`、`ps -a`、`stop`、`rm`；
- 镜像命令：`images`、`rmi`（按 image ID）；
- 镜像统一来自 Docker Hub，注意选择版本标签；
- 后续将用 `docker run` 容器化安装 MySQL 与 Redis。
