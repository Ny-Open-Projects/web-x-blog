# TypeORM 框架-轻松掌握链接 Mysql 数据库配置

> **导语**：本节从零演示在 Nest 项目中接入 TypeORM 并连接远端的 MySQL：安装三个依赖、编写 config.ts、在主模块注册，最后用 hello 接口验证连接是否成功。

## 前置知识
- 已理解 ORM 概念：建议先看《探索 Node 世界中的数据建模—ORM 框架》。
- 已在服务器容器化安装 MySQL：建议看《阿里云 Linux 服务器容器化安装 Mysql》。
- 本项目代码为独立练习工程，非低代码正式工程。

## 正文
### 安装三个依赖
在 Nest 项目中使用 TypeORM 操作 MySQL，需要核心包、Nest 适配层与数据库驱动：

```bash
pnpm add typeorm @nestjs/typeorm mysql2
```

- `typeorm`：ORM 核心
- `@nestjs/typeorm`：Nest 与 TypeORM 的桥接模块
- `mysql2`：MySQL 驱动程序

### 编写 config.ts
在项目根目录新建 `config.ts`，导出连接选项：

```ts
import { TypeOrmModuleOptions } from '@nestjs/typeorm';

export const typeOrmConfig: TypeOrmModuleOptions = {
  type: 'mysql',
  host: '远程服务器公网IP',
  port: 3306,
  username: 'root',
  password: '你的密码',
  database: 'study_class_local',
  entities: ['dist/**/*.entity{.ts,.js}'],
  synchronize: true,
};
```

关键属性说明：
- `entities`：扫描所有以 `.entity` 结尾的文件作为数据表定义。
- `synchronize: true`：项目启动时自动按实体同步数据库表与字段，开发期极方便；线上应注释掉改用手动迁移。
- `database` 填的是**数据库名** `study_class_local`，而不是容器名 `study_class_mysql`，两者混淆会导致连接失败。

### 在主模块注册
`src/app.module.ts` 引入并 `forRoot` 注入配置：

```ts
import { TypeOrmModule } from '@nestjs/typeorm';
import { typeOrmConfig } from './config';

@Module({
  imports: [TypeOrmModule.forRoot(typeOrmConfig)],
})
export class AppModule {}
```

放在主模块是因为所有涉及数据库操作的子模块都要共享这份连接配置。

### 验证连接
启动后请求 `GET /` 返回 `Hello World` 即说明主模块加载正常、配置无误。后续章节再用它做真正的增删改查。

## 小结
- 连接 MySQL 需 `typeorm` + `@nestjs/typeorm` + `mysql2` 三件套。
- `config.ts` 用 `TypeOrmModuleOptions` 描述连接信息，`synchronize` 实现表自动同步。
- 主模块 `forRoot(typeOrmConfig)` 完成全局注册。
- `database` 务必填数据库名，别与容器名混淆。
