# 低代码平台项目代码管理—云效 Codeup

> **导语**：多人协作与自动化部署的前提是代码集中托管。本节以阿里云云效 Codeup 为例，演示生成 SSH 公钥、关联远程仓库、提交并推送低代码平台 monorepo 的全过程。

## 前置知识
- 已初始化 pnpm workspace 工程，包含 client、server、share、release 子包：建议先看《项目管理 pnpm-workspace 初始化项目》。
- 掌握基本的 Git 提交、推送命令。

## 正文
### 为什么选云效 Codeup
后续课程会用到云效的 DevOps 自动化部署，因此代码需托管到云效仓库。相比其它平台，云效与阿里云服务器、流水线打通更顺畅，界面操作也更友好。

### 新建空仓库
登录云效后新建一个空白代码仓库，名称取为 `lowcode`，描述填写「低代码平台项目」，其余选项保持默认，确认后创建一个空的 Git 仓库。

### 配置 SSH 公钥
推荐使用 SSH 方式连接。本地生成密钥对：

```bash
ssh-keygen -t rsa -C "your_comment"
```

过程中提示是否覆盖已有密钥时，可直接重写；提示输入口令（passphrase）时留空回车即可，否则每次推送都要输入密码。注意：若把旧公钥提交到别的仓库，会提示被占用，此时重写一份即可。

生成后复制公钥内容。macOS 可用：

```bash
pbcopy < ~/.ssh/id_rsa.pub
```

Windows 使用对应命令复制。回到云效「个人设置 → SSH 公钥」粘贴并添加，有效期设为永久。

### 关联远程并推送
在本地项目根目录操作。注意根目录此前未初始化 Git，且各子目录遗留的 `.git` 需先清理，改为在根目录统一托管：

```bash
rm -rf .git
git init
```

添加 `.gitignore`，忽略 `node_modules`：

```bash
echo "node_modules" > .gitignore
```

关联远程地址并推送：

```bash
git remote add origin git@codeup.aliyun.com:xxx/lowcode.git
git add .
git commit -m "init"
git push -u origin master
```

刷新云效仓库页面，即可看到 client、server、share 等子项目全部出现在远端，代码托管完成。

## 小结
- 使用 SSH 连接需先生成并添加公钥，口令留空更省心。
- monorepo 应在根目录统一 `git init`，删除子目录冗余的 `.git`。
- 用 `.gitignore` 忽略 `node_modules`，避免提交体积膨胀。
- 代码上云后，本地误删或误改都能从远端恢复。
