## 面试卡：安全类问题应答

**密码存储**：MD5 加密入库不明文（更优答法：实际生产应加盐/bcrypt，课程用 MD5 是教学简化——主动升级答案加分）。注册成功直接签发 JWT 免二次登录。

**防账号枚举**：预先课教学版做了统一提示"账号或密码错误"，课程主工程此处未统一（分开提示）——面试可作为「我后来补的改进」来讲。

**JWT 安全**：payload 只放 id 不放密码；verify 需 try/catch 兜非法 token；iat/exp 判过期；返回脱敏绝不带密码；accountId 一律从 token 解出而非前端传参（Omit 在编译期排除）。

**防刷体系**（成本动机先行）：短信按条收费，盗刷烧钱。防线 = 60 秒限流 + 图形验证码前置 + Redis 原子性防重提交（保证 Redis 与 MySQL 一致性）；验证码 key 用 MD5(IP+设备指纹) 绑定设备。

**接口级**：JWT 全局 Guard 默认拦截一切 + @Public 显式豁免，杜绝忘加守卫；CORS 全开（`app.enableCors()` 无白名单）是待补项，生产应配白名单；发布页免登录接口不含敏感数据；问卷防重复提交靠 MD5(ip+ua) 匿名标识（单机直连有效，反代需 trust proxy + XFF）而非登录态。

**密钥红线**：AccessKey/JWT 私钥只走环境变量不入镜像不进前端；OSS AccessKeySecret 必须真实否则资源传到他人账户。
