# 42. 向量搜索原理：从向量到语义相似度

## 纲要

- **向量是什么**：空间中有位置有方向的量；二维向量即 (x,y)，多维即更多轴的数组
- **维度**：描述事物的特征轴（如鸟的眼睛/嘴/翅/羽）；维度越多，事物描述越精准
- **文本向量化**：计算机不懂语言，只能算数；用机器学习把文本转多维向量，靠向量距离算语义相似
- **相似度算法**：余弦相似度、点积、欧氏距离等；值越接近 1 表示语义越相近
- **语义搜索**：向量搜索别名，能捕捉「鸟」与「啄木鸟/老鹰」的语义关联，而非字面匹配

## 一、向量与维度

```mermaid
flowchart LR
    A[非数值实体: 鸟] --> B[定义维度: 眼/嘴/翅/羽]
    B --> C[每维度赋值]
    C --> D[多维向量]
    D --> E[向量间计算相似度]
```

向量 = 在维度基础上赋予的值。描述事物特征的维度越多，刻画越丰富越精准。

## 二、文本如何变成向量

计算机只能计算，**语言必须数据化**。主流做法是：对文本做语法/词法分析 → 转成多维向量 → 用向量计算文本间相似度。

```
用户问: "公园里有什么"
   ↓ Embedding 模型
向量 A = [0.12, -0.03, ..., 0.88]   (多维数组)
   ↓ 与知识库各片段向量算余弦相似度
筛选 score > 0.5 的片段
```

## 三、相似度与 score

| 算法 | 说明 |
|---|---|
| 余弦相似度 | 夹角越小越相似，最常用 |
| 点积 | 向量内积，兼顾长度与方向 |
| 欧氏距离 | 空间直线距离 |

Pinecone 控制台里 `score` 即相似度得分：**越高越相似**（如完全匹配 0.9998，无关内容得分骤降）。

## 四、为什么向量搜索强于关键词

全文搜索靠关键词频率，无法理解语义；向量搜索把「鸟」与「啄木鸟/老鹰」映射为相近向量，能返回语义相关结果，而非字面命中。

## 五、FAQ

**Q1：维度是不是越多越好？**
一般越多越精准，但成本与噪声也上升；Embedding 模型维度（如 1024）由模型决定。

**Q2：score 阈值怎么定？**
课程用 0.8；实际按数据调，太低召回噪声，太高漏召回。

**Q3：向量搜索和语义搜索关系？**
同一回事；向量搜索是技术实现，语义搜索是能力描述。

## 六、面试高频问答

**1. 文本相似度为什么用向量？**
语言需数据化才能计算；向量把语义编码进数字，距离即相似度。

**2. 常见相似度算法？**
余弦相似度（最常用）、点积、欧氏距离；底层由模型/库实现，应用层无需深究。

**3. 向量维度意义？**
每个维度是一个语义特征轴，维度越高描述越细。

## 七、ops 提示（检索基线）

> **score 阈值要调**：默认 0.8 不一定适合你的语料，用真实问句回归确定。
>
> **语义+关键词混合**：纯向量在专有名词（订单号/产品名）上可能弱，生产建议混合检索。
>
> **维度需对齐**：向量库索引维度必须与 Embedding 模型输出维度一致，否则写入失败。
