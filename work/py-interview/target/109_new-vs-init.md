# 109. __new__ vs __init__：谁造对象，谁填属性

> 分类：编程范式/Python 类 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**__new__** / **__init__** / **构造** / **单例**
> 原文锚点：第 105 段「经常可能会问的 __init__ 与 __new__ 这两个方法的区别」

## 一句话总述
**`__new__` 负责创建实例**（静态方法，首参是 `cls`，**必须返回实例**），`__init__` 负责**初始化**已创建的实例（首参 `self`，**不能返回非 None**）；调用顺序是先 `__new__` 后 `__init__`。

## 面试官视角
- **考察意图**：从"会写类"到"理解实例化全过程"，单例是必追问的落点。
- **P5** 能说出"一个造一个初始化" / **P6** 能写出 `__new__` 的签名与 `super().__new__(cls)` / **P7** 能指出**返回非本类实例时 `__init__` 不会被调用**，并据此实现单例与不可变子类 `[源码]`。
- **红旗**：① 把 `__init__` 叫构造函数；② `__new__` 里忘记 `return`（实例变 `None`）；③ 不知道 `__new__` 是隐式静态方法、首参是 `cls`。
- **惊艳点**：`__new__` 返回的若是**别的类型**，`__init__` 直接被跳过——这是实现"返回缓存实例"（单例）的关键。验证：单例类第二次构造不再打印 init `[实测]`。

## 主问答
**Q：__new__ 和 __init__ 有什么区别？**
**A：**
1. **职责**：`__new__(cls, *args)` **创建并返回实例**（真正意义的构造）；`__init__(self, *args)` 在实例已存在后**绑定属性**。
2. **参数与返回**：`__new__` 首参是**类 `cls`**、必须 `return` 一个实例（通常 `super().__new__(cls)`）；`__init__` 首参是**实例 `self`**、返回值必须是 `None`，否则 `TypeError`。
3. **顺序与跳过**：`Obj()` 先调 `__new__` 再调 `__init__`；若 `__new__` 返回的**不是本类实例**，Python **不会**调用 `__init__`。
**加分层**：典型用途——**单例**（`__new__` 里缓存实例）、**继承不可变类型**（`str`/`tuple`，需在 `__new__` 里改值，因为 `__init__` 时对象已不可变）、**对象池**。

## 关键代码
```python
class Singleton:
    _inst = None
    def __new__(cls, *a, **k):
        if cls._inst is None:
            cls._inst = super().__new__(cls)   # 只创建一次
        return cls._inst
    def __init__(self, x):
        self.x = x                             # 每次仍会执行

print(Singleton(1) is Singleton(2))   # True —— 同一实例

class Upper(str):                     # 不可变类型需在 __new__ 改值
    def __new__(cls, s): return super().__new__(cls, s.upper())

print(Upper("abc"))                   # ABC
```

## 总结与追问预判
