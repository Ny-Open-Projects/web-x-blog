# 49. 初始化二维数组的坑：别用 [[0]*n]*m

> 分类：语言基础/数据模型 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**列表乘法** / **共享引用** / **列表推导式**
> 原文锚点：第 13 段「如何在 Python 里正确初始化一个二维数组…其实它里面有个坑」

## 一句话总述
`[[0] * n] * m` 的外层 `*` 只是**重复同一个引用**，m 行共享**同一个 list**，改一行会改全部行；正解是**列表推导式** `[[0] * n for _ in range(m)]`。

## 面试官视角
- **考察意图**：这是"可变对象 + 引用语义"最经典的落地题，几乎必考。
- **P5** 知道用推导式 / **P6** 能解释乘法为何共享引用 / **P7** 能推广成"任何可变对象都别用 `*` 复制"。
- **红旗**：① 写 `[[0]*3]*3` 还觉得没问题；② 说"加个 deepcopy 就行"（不治根因还更慢）；③ 以为 `[0]*n` 也不安全。
- **惊艳点**：`[0] * n` **安全**，`[[0]] * m` **危险**——差别只在元素可不可变。验证：改一个元素看整行是否跟着变 `[实测]`

## 主问答
**Q：怎么初始化一个 3×3 的二维数组？下面这样写有什么问题？**
**A：**
1. **先给结论**：用 `[[0] * n for _ in range(m)]`，**不要**用 `[[0] * n] * m`。
2. **再给机制**：列表乘法是**重复同一个对象的引用**，不是调用构造函数；外层乘 m 次，得到的是 m 个指向**同一行**的引用，所以改 `a[0][0]` 会同时改掉所有行。
3. **最后给边界**：`[0] * n` 这种**元素不可变**的乘法是安全的——改元素会新建对象，不会互相影响；但只要元素可变，`*` 就一定会踩坑。
**加分层**：同一条规则适用于 dict、set 和自定义对象：**复制可变对象一律别用 `*`**，用推导式或工厂函数逐层新建。

## 关键代码
```python
bad = [[0] * 3] * 3
bad[0][0] = 1
print(bad)                     # [[1,0,0],[1,0,0],[1,0,0]] ← 三行全变
print(bad[0] is bad[1])        # True ← 同一行对象

good = [[0] * 3 for _ in range(3)]
good[0][0] = 1
print(good)                    # [[1,0,0],[0,0,0],[0,0,0]]
print(good[0] is good[1])      # False
```
