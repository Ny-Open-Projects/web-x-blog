# 66. 链表有哪几种，用 Python 怎么表示

> 分类：算法与数据结构/链表 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**单链表** / **双链表** / **循环双向链表**
> 原文锚点：第 14~30 段「简单的话就是单链表…双链表…把首尾也相连起来，就形成这个循环双向链表」

## 一句话总述
链表按指针数分三种：**单链表**（value + next）、**双链表**（prev + value + next）、**循环双向链表**（首尾相连）；Python **没有内置链表**，用**类持有引用**即可表示。

## 面试官视角
- **考察意图**：能否把"图"翻译成代码结构，这是做链表题的前提。
- **P5** 能画出结构 / **P6** 能写出节点类并说清各指针含义 / **P7** 能指出 Python 里 `next` 只是**对象引用**，以及双向链表的空间代价。
- **红旗**：① 把节点和链表混为一谈（不写容器类）；② 尾节点 `next` 不置 None；③ 说不清双链表多一份 prev 换来什么。
- **惊艳点**：**循环**双向链表正是 `OrderedDict` 的底层结构（见 56），把"刷题结构"和"标准库实现"打通是加分项。验证：读 `Modules/_collectionsmodule.c` `[源码]`。

## 主问答
**Q：Python 没有内置链表，怎么表示链表这种结构？**
**A：**
1. **先给结论**：用**类**表示节点——单链表两个属性 `value` 与 `next`；双链表加一个 `prev`；循环双向链表再把**头节点的 prev 指向尾、尾节点的 next 指向头**。
2. **再给机制**：Python 里 `next` 只是**指向另一个对象的引用**，链就是靠引用串起来的；尾节点 `next` 置 `None` 表示结束。
3. **最后给重点**：需掌握三类操作——**插入节点、反转链表、合并多个链表**；双链表牺牲一个指针换来**双向遍历与 O(1) 删除已知节点**。
**加分层**：实际工程里很少手写链表（内置 list 更快且更省事），它主要是**面试考察**结构；要队列/栈直接用 `collections.deque`。

## 关键代码
```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class Node:
    value: int
    next: Optional["Node"] = None          # 单链表节点

@dataclass
class DNode:
    value: int
    prev: Optional["DNode"] = None
    next: Optional["DNode"] = None         # 双链表节点

head = Node(1, Node(2, Node(3)))
print(head.value, head.next.next.value)    # 1 3
```
