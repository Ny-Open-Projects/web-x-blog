# 96. 判断回文数：字符串双指针与两条边界

> 分类：算法与数据结构/字符串 | 难度：L1 | 题型：工程题 | 频率：高 | 关键词：**回文** / **负数** / **首尾指针** / **个位数**
> 原文锚点：第 71~91 段「如果 x 小于零我们直接返回 False……首尾指针往中间收拢」

## 一句话总述
回文数 = 正着读反着读一样；用**字符串 + 首尾双指针**向中间比对，遇到不等即 False，指针相遇仍未不等则 True；两条必答边界是**负数一律 False**、**个位数一律 True**。

## 面试官视角
- **考察意图**：看你能不能**先把边界说清楚**再写代码，以及是否知道还有**不用转字符串**的数学解。
- **P5** 只会 `str(x) == str(x)[::-1]` / **P6** 手写双指针并答出两条边界 / **P7** 主动给出**反转后一半数字的 O(1) 空间解**（见 97）`[实测]`。
- **红旗**：① 忘了负数（`-121` 因负号必然不是回文）；② 认为 `10` 是回文（末尾为 0 的非零数都不是）；③ 把个位数漏掉（循环不执行，应返回 True）。
- **惊艳点**：一句归纳边界——**负数 False；末尾为 0 且 x≠0 时 False；0 与个位数 True**。验证：`10`、`1001`、`0`、`7` 四个用例即可覆盖全部分支 `[实测]`。

## 主问答
**Q：怎么判断一个整数是不是回文数？**
**A：**
1. **边界先行**：`x < 0` 直接返回 `False`（带负号不可能对称）；`0` 和**个位数**返回 `True`（首尾指针初始就相遇，循环不执行）。
2. **字符串解法**：`s = str(x)`，设 `begin=0`、`end=len(s)-1`，`while begin < end`：若 `s[begin] != s[end]` 返回 False，否则两指针向中间收拢；循环结束返回 True。
3. **复杂度**：时间 `O(n)`（n 为位数），转字符串需 `O(n)` 额外空间；若题目要求"**不转字符串**"，改用数值解法（见 97）。
**加分层**：末尾是 `0` 的非零数（如 `10`、`100`）一定不是回文——首位不可能是 0，这是数值解法里常用的**快速剪枝**。

## 关键代码
```python
def is_palindrome_str(x):        # 字符串 + 双指针
    if x < 0:                    # 边界一：负数必 False
        return False
    s = str(x)
    begin, end = 0, len(s) - 1
    while begin < end:           # 个位数时循环不执行 → True
        if s[begin] != s[end]:
            return False
        begin += 1; end -= 1
    return True

def is_palindrome_short(x):      # 切片一行版
    s = str(x)
    return s == s[::-1]

for v in (121, -121, 10, 0, 7, 1221, 12321):
    print(v, is_palindrome_str(v))
# 121 True / -121 False / 10 False / 0 True / 7 True / 1221 True / 12321 True
```
