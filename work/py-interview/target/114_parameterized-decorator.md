# 114. 给装饰器本身加参数：三层闭包或类构造参数

> 分类：编程范式/装饰器 | 难度：L3 | 题型：工程题 | 频率：中 | 关键词：**带参装饰器** / **三层闭包** / **use_int** / **行为开关**
> 原文锚点：第 44~56 段「如何给装饰器本身增加参数，用它控制装饰器自己的行为」

## 一句话总述
想让装饰器**自己带参数**，就要多包一层：函数版是**三层闭包**（`参数 → 装饰器 → wrapper`），类版是**`__init__` 收参数、`__call__` 收函数**；用途是**控制装饰器自身的行为**（如耗时打印成 int 还是 float）。

## 面试官视角
- **考察意图**：考闭包层数与"谁在哪一层被执行"，这是最容易写错的装饰器变体。
- **P5** 只写过不带参的 / **P6** 能写出三层闭包并说清每层收到什么 / **P7** 能指出类版更清晰（参数进 `__init__`、函数进 `__call__`），并判断何时该改用 `functools.partial` 或配置对象 `[经验]`。
- **红旗**：① 层数写错（想带参却只写两层，把函数当成"参数"收到）；② 类版把 `func` 收进 `__init__` 导致参数无处安放；③ 忘记最内层仍要 `return` 原函数结果。
- **惊艳点**：记忆口诀——**`@D(x)` 时，`D(x)` 先执行，它的返回值才是真正的装饰器**；所以带参版调用链是"先配置、后包装"。验证：类版 `@LogTime(use_int=True)` 打印整型 `[实测]`。

## 主问答
**Q：如何给装饰器传参数？两种写法分别怎么写？**
**A：**
1. **函数版（三层）**：最外层 `def log_time(use_int=False)` 收**装饰器参数**，返回真正的装饰器 `deco`；`deco(func)` 收**函数**，返回 `wrapper`；`wrapper(*args, **kwargs)` 收**被调函数的实参**。
2. **类版**：`__init__(self, use_int=False)` 收**装饰器参数**存为 `self.use_int`；`__call__(self, func)` 收**函数**并返回内层包装函数；使用时 `@LogTime(use_int=True)`（**括号必须有**）。
3. **用途**：参数化的是**装饰器行为**，如格式化方式、是否启用、阈值大小；不影响被装饰函数的签名。
**加分层**：参数多于 2~3 个时，闭包会很难读，此时类版或"配置对象 + 函数版"更易维护；别忘了最内层仍要 `functools.wraps(func)`。

## 关键代码
```python
import time

class LogTime:                          # 类版：参数进 __init__
    def __init__(self, use_int=False):
        self.use_int = use_int

    def __call__(self, func):           # 函数进 __call__
        def _log(*args, **kwargs):
            begin = time.perf_counter()
            try:
                return func(*args, **kwargs)
            finally:
                cost = time.perf_counter() - begin
                print(f'cost {int(cost) if self.use_int else cost}')
        return _log

@LogTime(use_int=True)                  # 括号必须先造实例
def my_sleep():
    time.sleep(0.1)

my_sleep()                              # cost 0
```

## ⚠️ 原文纠错
原文用类实现带参装饰器：`__init__` 接收 `use_int` 布尔值、`__call__` 接收函数、按 `use_int` 决定打印 int 还是 float，实现正确，予以保留。原文默认 `use_int=False` 打印浮点、传 True 打印整型，与描述一致。卡面补充的函数版三层闭包与"参数多用配置对象"属扩展，已用 `[经验]` 标注。转写中的音译词已还原为标准术语。

## 总结与追问预判
- 带参 = **多一层**；类版参数进 `__init__`、函数进 `__call__`；`@D(x)` 先求值 `D(x)`。
