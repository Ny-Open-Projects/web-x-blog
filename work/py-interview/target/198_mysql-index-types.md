# 198. MySQL 索引类型

> 分类：数据库 | 难度：L2 | 题型：概念题 | 频率：高 | 关键词：**普通索引** / **唯一索引** / **联合索引** / **主键索引** / **全文索引** / **B+树**
> 原文锚点：第 109~117 段「索引类型：普通索引(create index)、唯一索引(值必须唯一, create unique index)、多列/联合索引(B+树 key 由多列值组成)、主键索引(一表一个)、全文索引(倒排索引, InnoDB 旧版不支持)」

## 一句话总述
MySQL 常见索引类型：**普通索引**（纯加速）、**唯一索引**（值必须唯一，可判重）、**联合索引**（多列组合，B+ 树 key 由多列值拼成，引出最左前缀）、**主键索引**（一表一个，InnoDB 即聚集索引）、**全文索引**（倒排索引，适合搜索）。除全文索引外，其余底层都是 **B+ 树**。

## 面试官视角
- **考察意图**：是否分得清各类索引的语义与适用场景，尤其联合索引与主键索引的特殊性。
- **P5** 能说出五种类型名字 / **P6** 能讲清唯一索引用于约束唯一、联合索引引出最左前缀、主键索引一表一个 / **P7** 能指出全文索引 InnoDB 5.6+ 已支持（旧版 only MyISAM）、以及生产全文检索多走专用引擎（ES 等）。
- **红旗**：认为"全文索引 InnoDB 永远不支持"（5.6+ 已支持，源表述偏旧）；或说"可以建多个主键索引"（主键只能一个）。
- **惊艳点**：联合索引的本质是 B+ 树 key 按**多列拼接排序**，所以才有最左前缀；单列索引则是单 key——理解这点就不会死记"最左原则" `[经验]`。

## 主问答
**Q（面试官原话）：** MySQL 有哪些索引类型？唯一索引和主键索引有什么区别？

**A · 标准答案骨架：**
1. **先给结论**：五类——**普通、唯一、联合、主键、全文**；除全文外底层都是 B+ 树。
2. **再给机制**：**普通索引**只加速；**唯一索引**额外约束列值唯一（可 NULL，除非显式 NOT NULL）；**联合索引**把多列拼成 B+ 树 key，须满足**最左前缀**才命中；**主键索引**一表仅一个且非空唯一，InnoDB 下即**聚集索引**（叶存整行）；**全文索引**用倒排，适合长文本检索。
3. **最后给边界**：唯一索引允许**多个 NULL**（NULL 不等同于值），而主键索引**不允许 NULL**；全文索引 InnoDB **5.6 起已支持**，但大规模全文检索仍建议专用搜索引擎（Elasticsearch 等）。

**加分层**：主键索引与唯一索引都有"唯一"约束，但主键还隐含 **NOT NULL + 一表一个 + 聚集（InnoDB）** 三重身份 `[经验]`。

## 版本与兼容性

|---|---|---|
| MySQL 5.6（2013）起 InnoDB 支持 FULLTEXT | 此前仅 MyISAM 支持全文索引 | 现在两者都支持全文索引；大规模全文检索建议 ES，不全靠 DB |

## 关键代码
```sql
-- 各类索引创建语法 [实测, MySQL 8]
CREATE INDEX idx_name ON t(col);                 -- 普通索引
CREATE UNIQUE INDEX uk_email ON t(email);        -- 唯一索引
CREATE INDEX idx_a_b ON t(a, b, c);              -- 联合索引（引出最左前缀）
ALTER TABLE t ADD PRIMARY KEY (id);              -- 主键索引（一表一个）
```

## ⚠️ 原文纠错
原文音译需还原：「**mycircle / myyircl**」→ **MySQL**；「**interDB**」→ **InnoDB**；「**蚂蚁SM**」→ **MyISAM**；「**createindex / createuniqueindex**」→ **CREATE INDEX / CREATE UNIQUE INDEX**。事实翻转：原文称"InnoDB 不支持全文索引"——**MySQL 5.6 起 InnoDB 已支持 FULLTEXT**，与 495 卡（InnoDB vs MyISAM）所记翻转一致；生产全文检索仍多走 ES。概念正确：五类索引定义、联合索引 B+ 树 key 多列拼接、主键一表一个。核对范围：第 109~117 段 索引类型。

## 总结与追问预判
- 五类索引；除全文外皆 B+ 树；联合索引多列拼 key→最左前缀；主键 InnoDB 即聚集。
