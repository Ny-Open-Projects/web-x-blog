# 172. TCP 与 UDP 的区别

> 分类：网络 | 难度：L2 | 题型：对比题 | 频率：高 | 关键词：**TCP** / **UDP** / **面向连接** / **可靠** / **字节流**
> 原文锚点：第 88~93 段「TCP 面向连接、可靠、基于字节流；UDP 无连接、不可靠、面向报文；TCP 有缓冲区分段，UDP 无缓冲直接发」

## 一句话总述
**TCP** 是**面向连接、可靠、基于字节流**的传输协议（三次握手、确认重传、有发送缓冲区可分段）；**UDP** 是**无连接、不可靠、面向报文**的协议（发完不管、无缓冲区、应用层给多少发多少）。

## 面试官视角
- **考察意图**：是否分得清两者语义差异并能给出选型场景。
- **P5** 能说出 TCP 可靠/UDP 不可靠 / **P6** 能讲清"面向字节流 vs 面向报文"及缓冲区差异 / **P7** 能给出选型（需要可靠/有序用 TCP；实时/低延迟/广播用 UDP，如 DNS、音视频、QUIC）。
- **红旗**：把"可靠"简单说成"不会丢包"（实为"丢了对端能发现并重传"）；或认为 UDP 永远比 TCP 快。
- **惊艳点**：HTTP/3 直接基于 **QUIC（跑在 UDP 上）** 来规避 TCP 队头阻塞——UDP 不意味着"低级"，而是"把可靠性交给应用层控制" —— 验证：Chrome 对支持的站点走 `h3` 可查 `[经验]`。

## 主问答
**Q（面试官原话）：** TCP 和 UDP 有什么区别？分别在什么场景用？

**A · 标准答案骨架：**
1. **先给结论**：TCP **面向连接、可靠、字节流**；UDP **无连接、不可靠、面向报文**。
2. **再给机制**：TCP 有**三次握手**建连、每包**确认重传**保可靠，且带**发送缓冲区**可对应用数据**分段**发送；UDP 发完即弃、无确认，应用层给多少**直接当报文**发出、无缓冲。
3. **最后给边界**：TCP 适**可靠性优先**场景（Web/DB/文件）；UDP 适**实时/低延迟/广播**场景（DNS 查询、音视频通话、游戏），或应用层自己实现可靠（QUIC）。

**加分层**："可靠"是"对端确认+重传"而非"物理不丢"；UDP 的代价是应用要自己处理丢包乱序——别把负担想轻了 `[经验]`。

## 关键代码
```python
import socket
# TCP：SOCK_STREAM，面向字节流，带缓冲区 [实测]
tcp = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
# UDP：SOCK_DGRAM，面向报文，无连接 [实测]
udp = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
udp.sendto(b"hi", ("1.1.1.1", 53))   # 发完即弃，无确认
```
