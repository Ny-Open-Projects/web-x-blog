# 100. Python 类的定义：__init__、属性与方法

> 分类：编程范式/Python 类 | 难度：L1 | 题型：八股题 | 频率：高 | 关键词：**class** / **__init__** / **self** / **方法**
> 原文锚点：第 19~26 段「初始化方法传两个参数，包含名字与年纪两个属性」

## 一句话总述
用 `class` 定义类，`__init__` 在**实例创建后**给实例绑属性；类里定义的 `def` 叫**方法**（首参 `self`），类外定义的才叫**函数**。

## 面试官视角
- **考察意图**：看你是否把"类是命名空间 + 属性容器"说透。
- **P5** 能写出 `class` + `__init__` / **P6** 说清 `self` 是**实例本身**、属性存在 `__dict__` / **P7** 能指出 `__init__` 不返回对象、真正创建对象的是 `__new__` `[源码]`。
- **红旗**：① 把 `self` 说成关键字（它只是**约定名**）；② 认为 `__init__` 是构造函数（它只做**初始化**）；③ 漏写 `self` 形参，调用时报 `missing 1 required positional argument`。
- **惊艳点**：`obj.x = 1` 会直接落进 `obj.__dict__`，所以 Python 实例默认是**可变字典**。验证：`Person("老王", 18).__dict__ == {'name': '老王', 'age': 18}` `[实测]`。

## 主问答
**Q：Python 里怎么创建一个类？属性和方法分别是什么？**
**A：**
1. **语法**：`class Person:` 定义类；Python 3 可省略 `(object)`，Python 2 需显式继承 `object` 才是新式类。
2. **属性**：`__init__(self, name, age)` 中 `self.name = name` 绑定的是**实例属性**，每个实例各一份。
3. **方法**：类内 `def` 称**方法**（操作成员），类外 `def` 称**函数**；方法首参 `self` 指向实例。
**加分层**：`__init__` 只做初始化且**不能返回非 None**（否则 `TypeError`）；真正"造出"实例的是 `__new__`，见 109。

## 版本与兼容性
| 结论成立版本 | 翻转点 | 现在怎么答 |
|---|---|---|
| Python 3.x | 默认新式类 | `class Person:` 即可 |
| Python 2.x | 旧式/新式类差异 | 需 `class Person(object)` |
| 无 __slots__ | 属性存 __dict__ | 可动态增删属性 |

## 关键代码
```python
class Person:
    def __init__(self, name, age):   # 初始化：绑定实例属性
        self.name = name
        self.age = age

    def print_name(self):            # 方法：首参 self
        print(self.name)

p = Person("老王", 18)
print(p.__dict__)                    # {'name': '老王', 'age': 18}
p.print_name()                       # 老王
```

## ⚠️ 原文纠错
原文把类内 `def` 称为"方法"、类外称为"函数"，区分正确，予以保留。原文提到 Python 2 需显式继承 `object`、Python 3 可省略，属实。卡面补充的 `__init__` 不可返回非 None、属性存于 `__dict__`、真正构造者是 `__new__` 属扩展，已分别用 `[源码]`/`[实测]` 标注。转写中的音译词已还原为标准术语。

## 总结与追问预判
- `class` + `__init__`；`self` 是实例；属性在 `__dict__`；方法 ≠ 函数。
