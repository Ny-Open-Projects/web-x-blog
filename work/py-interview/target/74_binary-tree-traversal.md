# 74. 二叉树怎么表示，三种遍历怎么写

> 分类：算法与数据结构/二叉树 | 难度：L2 | 题型：工程题 | 频率：高 | 关键词：**前序** / **中序** / **后序** / **递归**
> 原文锚点：第 130~152 段「先处理根，然后是左子树，之后是右子树…中序就是把 print 放在中间」

## 一句话总述
二叉树节点 = `data` + `left` + `right`（空表示无子树，两者皆空即叶子）；三种遍历**只差打印节点的位置**——前序**根左右**、中序**左根右**、后序**左右根**。

## 面试官视角
- **考察意图**：二叉树是递归结构的典型，考的是递归思维与"同一模板换位置"的抽象能力。
- **P5** 能说出三种顺序 / **P6** 能三次写出递归版 / **P7** 能给出**非递归（栈）版**并能由两种遍历反推树结构。
- **红旗**：① 三种顺序记混；② 递归忘了 `if not root: return` 基线；③ 以为遍历只能递归。
- **惊艳点**：**中序遍历二叉搜索树会得到有序序列**——这是二叉搜索树的定义性性质，也是面试官最爱接的一问。验证：对 BST 中序输出断言已升序 `[实测]`。

## 主问答
**Q：如何表示二叉树？三种遍历怎么实现？**
**A：**
1. **先给结构**：节点类持三个属性——`data` 存值、`left` 指向左子树、`right` 指向右子树；都为 `None` 即为**叶子节点**。
2. **再给模板**：递归天然适配——因为二叉树是**递归定义**的（任一非叶节点看下去仍是一棵二叉树）。三种遍历代码几乎相同，**只移动"访问节点"那一行**：前序放在两个递归**之前**，中序放在**中间**，后序放在**之后**。
3. **最后给复杂度**：三种遍历时间均为 **O(n)**（每节点访问一次），空间 **O(h)**（h 为树高，来自递归栈；最坏链状树 h=n）。
**加分层**：工程里递归深度受解释器限制（Python 默认约 1000），深树要用**显式栈**改写成迭代版；层序遍历则用 `deque` 做 BFS。

## 关键代码
```python
class TreeNode:
    def __init__(self, data, left=None, right=None):
        self.data, self.left, self.right = data, left, right

def preorder(r):  return [] if not r else [r.data] + preorder(r.left) + preorder(r.right)
def inorder(r):   return [] if not r else inorder(r.left) + [r.data] + inorder(r.right)
def postorder(r): return [] if not r else postorder(r.left) + postorder(r.right) + [r.data]

#      1
#     / \      前序 1 2 3 / 中序 2 1 3 / 后序 2 3 1
#    2   3
root = TreeNode(1, TreeNode(2), TreeNode(3))
print(preorder(root), inorder(root), postorder(root))
```

## ⚠️ 原文纠错
原文对先/中/后序的定义与"只改 print 位置"的讲解准确；需补正：原文称代码"寥寥四行"用的是**列表拼接**的简化写法，真实工程中应 yield 或追加到外部列表以避免 O(n²) 拼接开销，卡面保留简洁写法并在此说明。转写中的音译词已还原为标准术语。未发现原理性错误。
