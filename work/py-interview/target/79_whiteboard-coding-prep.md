# 79. 白板编程怎么准备才有效

> 分类：算法与数据结构/面试方法 | 难度：L1 | 题型：八股题 | 频率：中 | 关键词：**白板编程** / **按类型刷** / **剑指 Offer** / **面经**
> 原文锚点：第 8~49 段「白板编程…我们需要多刷题…按照数据结构来归一个类，不是靠记忆，而是真正掌握」

## 一句话总述
白板编程 = **脱离 IDE 手写/口述代码**；有效准备方式是**按数据结构分类刷**（链表/栈/二叉树/排序各刷一类）+ **剑指 Offer 类高频题亲手实现** + **面试前按公司面经定向补**。

## 面试官视角
- **考察意图**：这类题不是考技术，是看**你的准备是否成体系**。
- **P5** 说"我在刷题" / **P6** 能给出分类、资源与节奏 / **P7** 能说清"理解 vs 背题"的区别并给出自检方法。
- **红旗**：① 说"刷了很多"却说不出分类；② 承认靠背模板；③ 没做过脱离补全的手写训练。
- **惊艳点**：判断标准不是"刷了几百题"，而是**能否不看资料手写快排/归并**——写不出来就说明是在背题。验证：给自己计时 15 分钟白纸手写 `[经验]`。

## 主问答
**Q：算法面试/白板编程你是怎么准备的？**
**A：**
1. **先给方法**：**按类型刷**优先于按难度刷——把链表、栈、二叉树、排序、堆各自刷一类，同类题套路高度重合，性价比最高。
2. **再给资源**：在线题库（LeetCode 等）提供**大量测试用例**，能暴露边界处理不足；经典面试书（如剑指 Offer）覆盖高频题型，建议**大部分亲手用 Python 实现一遍**。
3. **最后给关键**：**先独立思考再去看题解**；看完题解要复盘"为什么别人想到而我没想到"，**总结成模板**；面试前按数据结构归类复盘，**靠理解而不是靠记忆**。
**加分层**：面试前搜目标公司的**面经**，看它偏好考哪一类，针对性补；同时保持日常低频练习，避免长期写业务代码导致"手生"。

## 关键代码
```python
# 自检工具：随机抽题计时，强制脱离补全手写
import random, time
TOPICS = ["反转链表", "合并两个有序链表", "最小栈", "两个栈实现队列",
          "TopK 最小堆", "快排", "归并排序", "二叉树中序遍历"]
def drill():
    topic = random.choice(TOPICS)
    input(f"题目【{topic}】按回车开始手写，写完再回车：")
    t = time.time()
    input("完成？回车结束计时：")
    print(f"{topic} 用时 {time.time()-t:.0f}s（目标 < 15 分钟）")
drill()
```
