# 75. 堆为什么是完全二叉树，大顶堆与小顶堆怎么分

> 分类：算法与数据结构/堆 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**完全二叉树** / **大顶堆** / **小顶堆** / **堆顶**
> 原文锚点：第 153~158 段「堆其实就是一棵完全二叉树，它有最大堆跟最小堆之分」

## 一句话总述
堆是**完全二叉树**（因此可以用**数组**紧凑存储、无需指针）；**大顶堆**要求每个非叶节点 ≥ 其孩子（堆顶最大），**小顶堆**反之（堆顶最小）。

## 面试官视角
- **考察意图**：堆是 TopK、优先队列、堆排序的共同基础，必须讲清"结构性 + 堆序性"两条性质。
- **P5** 知道堆顶是最值 / **P6** 能说清完全二叉树 + 堆序两点 / **P7** 能给出数组下标关系与上浮下沉的复杂度。
- **红旗**：① 以为堆是"排好序的数组"；② 说不清完全二叉树为何能用数组存；③ 混淆大顶堆与小顶堆在 TopK 中的用法。
- **惊艳点**：数组下标关系——`i` 的左孩子 `2i+1`、右孩子 `2i+2`、父节点 `(i-1)//2`，**没有指针**正是堆省内存的原因。验证：对任意随机数组 `heapq.heapify` 后逐点校验 `[实测]`。

## 主问答
**Q：什么是堆？它和普通二叉树有什么不同？**
**A：**
1. **先给两条性质**：**结构性**——必须是**完全二叉树**（除最后一层外全满，最后一层靠左对齐）；**堆序性**——每个非叶节点的值都**不小于**（大顶堆）或**不大于**（小顶堆）其孩子。
2. **再给存储**：正因为是完全二叉树，堆可以**用数组表示**，下标 `i` 的孩子在 `2i+1` / `2i+2`，父在 `(i-1)//2`，**不需要左右指针**，非常省内存。
3. **最后给操作**：取最值 O(1)（看堆顶）；插入与删除堆顶都是 **O(log n)**（上浮/下沉）；建堆 `heapify` 是 **O(n)** 而非 O(n log n)。
**加分层**：Python 的 `heapq` 实现的是**小顶堆**，且它是**函数集合操作普通 list**，不是独立的堆类——这一点常考（见 65）。

## 关键代码
```python
import heapq, random
a = [5, 3, 8, 1]
heapq.heapify(a)                       # 原地 O(n) 建小顶堆
print(a, a[0])                         # [1, 3, 8, 5] 1 —— 堆顶最小
# 校验下标关系：i 的孩子 2i+1 / 2i+2
ok = all(a[i] <= a[2*i+1] for i in range(len(a)//2) if 2*i+1 < len(a))
print("满足小顶堆性质:", ok)
# 大顶堆的常用做法：存负值
maxh = [-x for x in a]; heapq.heapify(maxh)
print(-maxh[0])                        # 最大值 [实测]
```
