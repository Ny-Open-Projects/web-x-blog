# 162. 分段机制（Segmentation）

> 分类：操作系统/内存 | 难度：L2 | 题型：概念主问 | 频率：中 | 关键词：**分段** / **段表** / **段内连续** / **栈与堆**
> 原文锚点：第 18~34 段「分段为满足代码逻辑需求（数据保护/隔离）；段表含段号段长起始地址；段内连续段间离散；代码/数据/栈/堆段」

## 一句话总述
**分段**按**逻辑意义**把内存分成段（代码段/数据段/栈段/堆段），用**段表（segment table：段号+段长+起始地址）**映射；**段内连续、段间离散**，目的是**数据保护与隔离**，段大小由用户程序决定。

## 面试官视角
- **考察意图**：是否分得清分页（为利用率）与分段（为逻辑/保护）的根本出发点。
- **P5** 能说出段表三要素、段内连续 / **P6** 能讲清为什么分段便于保护与隔离（不同段权限不同） / **P7** 能对比分页：分页大小固定 OS 定、分段大小用户定。
- **红旗**：把分段说成"为了减少碎片"（那是分页的出发点）；或认为段间也连续。
- **惊艳点**：段的概念直接对应程序的**代码段/数据段/栈/堆**——栈区容量有限（常几 MB），无递归出口会**栈溢出**；堆区（malloc/new）可开大数组 —— 验证：递归无 base case 触发 `RecursionError`/`stack overflow` `[经验]`。

## 主问答
**Q（面试官原话）：** 分段是什么？和分页有什么区别？

**A · 标准答案骨架：**
1. **先给结论**：分段按**逻辑模块**划分内存（代码/数据/栈/堆），用**段表**记录段号、段长、起始地址；**段内连续、段间离散**。
2. **再给机制**：每段可设不同访问权限（如代码段只读），实现**保护与隔离**；段大小由程序语义决定，不像页那样固定。
3. **最后给边界**：分页是**物理层**为利用率而生、大小固定；分段是**逻辑层**为保护/隔离而生、大小可变——二者出发点相反。

**加分层**：现代系统常把分段与分页结合（如 x86 先分段再分页），但面试答清二者区别即可 `[经验]`。

## 关键代码
```python
# 概念示意：段表 = 段号 → (基址, 段长) [经验]
seg_table = {0: (0x1000, 4096), 1: (0x2000, 8192)}  # 代码段/数据段
def seg_translate(seg, offset):
    base, limit = seg_table[seg]
    assert 0 <= offset < limit, "段内越界"
    return base + offset
```
