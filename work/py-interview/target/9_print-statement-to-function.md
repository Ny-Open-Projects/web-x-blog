# 9. print 从语句变成函数

> 分类：版本差异 | 难度：L1 | 题型：八股题 | 频率：中 | 关键词：**print 函数** / **sep** / **end** / **__future__**
> 原文锚点：第 14~29 段「在 Python 3 里面 print 成为了函数，在 Python 2 里面它是一个关键字」

## 一句话总述
Python 3 把 `print` 从**语句**升级为**函数**，换来 `sep`/`end`/`file`/`flush` 四个可控参数；Python 2 可用 `__future__` 提前拿到该行为。

## 面试官视角
- **考察意图**：这道小题的真实考点是"你有没有真的做过 2→3 迁移"。
- **P5** 知道 3 里要加括号 / **P6** 知道 `sep`/`end` 两个参数 / **P7** 能说出 2 里加括号的陷阱与 `__future__` 的迁移手法。
- **红旗**：① 以为 2 里加括号就是函数调用；② 不知道 `flush`；③ 不知道 `print` 可以重定向到文件。
- **惊艳点**：Python 2 里写 `print("a", "b")` 打印的是**一个二元组**（含括号），不是两个字符串 `[经验]`。

## 主问答
**Q：Python 2 和 3 的 print 有什么不一样？**
**A：**
1. **先给结论**：3 里 `print` 是**内置函数**，可传 `sep`（分隔符）、`end`（行尾）、`file`（输出目标）、`flush`（是否立即刷缓冲）。
2. **再给机制**：2 里它是语句，加括号只是把内容包成 tuple；想提前用函数语义，要在文件头写 `from __future__ import print_function`。
3. **最后给边界**：迁移时最容易漏的是**输出格式**——`print(a, b)` 在两边输出不同（2 打 tuple、3 打空格分隔），日志对比类测试容易因此失败。
**加分层**：`print(..., flush=True)` 常用于容器里看实时日志，否则 stdout 重定向到文件时是块缓冲，看不到即时输出。

| 结论成立版本 | 翻转点 | 现在怎么答 |
|---|---|---|

## 关键代码
```python
print("a", "b", sep="|", end="!\n")   # a|b!
print("progress", flush=True)         # 容器里实时刷出
```

## ⚠️ 原文纠错
未发现技术错误。原文「Python 2 中加括号是合并成 tuple 对象」的说法准确；机翻中的模块名与参数名音译已还原为 `__future__` / `print_function`。
