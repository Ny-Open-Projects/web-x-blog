# 94. 原地反转字符串：双指针一次搞定

> 分类：算法与数据结构/字符串 | 难度：L1 | 题型：工程题 | 频率：高 | 关键词：**原地** / **首尾指针** / **O(1) 空间** / **交换**
> 原文锚点：第 34~42 段「一个从头开始，一个从尾部开始，把首尾交换，然后两个指针一个前移一个后移」

## 一句话总述
原地反转字符数组用**首尾双指针**：`begin` 从头、`end` 从尾，**交换两端**后各自向中间移动，直到**两指针相遇**即停；时间 `O(n)`、额外空间 `O(1)`。

## 面试官视角
- **考察意图**：最基础的对撞指针题，看你能不能**不使用额外空间**、并说清循环终止条件。
- **P5** 用新列表倒着装（O(n) 空间） / **P6** 写出双指针原地版 / **P7** 顺带指出 Python 里 `list.reverse()` 就是这件事，但面试要求**手写则不能用** `[实测]`。
- **红旗**：① 新开一个列表存放结果（违反"不允许额外空间"）；② 循环条件写成 `<=` 导致中间元素自交换（不出错但多余）；③ 忘了 `end = len(s) - 1` 的边界起点。
- **惊艳点**：`while begin < end` 这一条同时覆盖了**奇数长度**（中间元素无需动）和**偶数长度**（刚好交换完）两种情况。验证：分别跑长度为 4 与 5 的数组对照 `[实测]`。

## 主问答
**Q：原地反转一个字符数组，不能用额外空间，怎么写？**
**A：**
1. **思路**：设 `begin = 0`、`end = len(s) - 1`，循环条件是 `begin < end`；循环体内**交换 `s[begin]` 与 `s[end]`**，然后 `begin += 1`、`end -= 1`。
2. **为什么对**：每轮把一对对称位置的元素放到正确位置，共需 `n // 2` 轮；**指向同一元素（奇数长度中间位）时无需交换**，所以条件是 `<` 而非 `<=`。
3. **复杂度**：时间 `O(n)`，只用了两个整型变量，**额外空间 `O(1)`**，满足"原地修改、不返回"的要求。
**加分层**：Python 的元组解包 `s[begin], s[end] = s[end], s[begin]` 一行完成交换；若允许用内置方法，`list.reverse()` 本身**原地、无返回值**（与 `reversed()` 完全不同，见 95）。

## 关键代码
```python
def reverse_string(s):                 # 原地修改，无返回值
    begin, end = 0, len(s) - 1
    while begin < end:                 # 相遇即停，奇数长度中间位不动
        s[begin], s[end] = s[end], s[begin]   # 元组解包交换
        begin += 1
        end -= 1

a = list("hello"); reverse_string(a); print("".join(a))   # olleh
b = list("abcd");  reverse_string(b); print("".join(b))   # dcba

# 库函数版本（面试若允许）
c = list("hello"); c.reverse()         # 原地，返回 None
print("".join(c))                      # olleh
```

## ⚠️ 原文纠错
原文"首尾双指针 + 交换 + 向中间收拢 + 相遇停止"的解法正确，予以保留；"单个指针无法解决、需要两个指针"的判断也正确。原文提到 `reversed(s)` 返回新序列、原 `s` 不变，与 `list.reverse()` 原地修改的差异，卡面已在 95 单列。转写中的音译词已还原为标准术语。
