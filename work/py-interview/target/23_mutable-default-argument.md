# 23. 为什么不能用可变对象做默认参数

> 分类：语言基础/函数 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**默认参数只计算一次** / **__defaults__** / **None 哨兵**
> 原文锚点：第 75~79 段「默认参数只计算一次…每次调这个函数的时候，实际上引用的都是原来那个列表」

## 一句话总述
默认参数在 **def 执行（函数定义）时**求值一次并塞进 `func.__defaults__`，所有调用**共享同一个对象**——所以可变默认值会**跨调用累积**。

## 面试官视角
- **考察意图**：是真踩过这个坑，还是只背了"用 None 代替"。
- **P5** 知道写 `None` / **P6** 能说出"定义时求值 + `__defaults__` 存放" / **P7** 能讲清它对缓存的反向利用与代价。
- **红旗**：① 说"每次调用都会新建一个 []"；② 用 `if not x` 代替 `if x is None`（把 0 和 "" 也吞掉）；③ 不知道怎么查看默认值对象。
- **惊艳点**：`bad.__defaults__` 里能直接看到那个被反复 append 的 list。验证：`bad(); bad(); print(bad.__defaults__)` → `([0, 0],)` `[实测]`

## 主问答
**Q：下面这个函数调两次为什么第二次返回了两个元素？**
**A：**
1. **先给结论**：因为**默认参数只在函数定义时求值一次**，之后每次调用复用同一个 list 对象。
2. **再给机制**：`def` 语句执行时创建函数对象，把默认值存进 `__defaults__`（仅限关键字默认值存 `__kwdefaults__`）；函数体每次调用都跑，但默认值**不再重新求值**。
3. **最后给边界**：不可变默认值（None/int/str/tuple）看不出问题，只有**可变**默认值才会累积。正确写法是 `def f(x=None): x = [] if x is None else x`，**用 `is None` 而不是 falsy 判断**。
**加分层**：这特性可反向用来做函数内缓存（`def f(x, _c={})`），但可读性差，生产上更该用 `functools.lru_cache`。

## 关键代码
```python
def bad(x, acc=[]):
    acc.append(x); return acc
print(bad(1), bad(2))        # [1] [1, 2]  ← 被上一次调用污染
print(bad.__defaults__)      # ([1, 2],)  共享的那个 list

def good(x, acc=None):
    acc = [] if acc is None else acc
    acc.append(x); return acc
print(good(1), good(2))      # [1] [2]
```

## ⚠️ 原文纠错
原文「默认参数只计算一次」结论正确。补充一处原文未提及的事实：仅限关键字参数的默认值存放在 `__kwdefaults__` 而非 `__defaults__` `[经验]`。

## 总结与追问预判
- 默认值是**定义期**产物，不是调用期产物；可变默认值必然跨调用累积。
