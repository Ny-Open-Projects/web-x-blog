# 27. 函数形参的固定顺序：位置 → 默认 → *args → 仅限关键字 → **kwargs

> 分类：语言基础/函数 | 难度：L2 | 题型：八股题 | 频率：中 | 关键词：**形参顺序** / **仅限关键字** / **SyntaxError**
> 原文锚点：第 101~104 段「我们还可以去混用它们…既有 args 又用 kwargs」

## 一句话总述
形参声明顺序是**语法硬规则**：**普通位置参数 → 默认参数 → `*args` → 仅限关键字参数 → `**kwargs`**，写反要么 SyntaxError，要么语义悄悄变掉。

## 面试官视角
- **考察意图**：函数签名到底写过多少、是否理解"星号是分界线"。
- **P5** 能说个大概 / **P6** 能背全五段并说出 `*args` 之后的普通参数会变成仅限关键字 / **P7** 能讲清"为什么要有仅限关键字"这一设计动机。
- **红旗**：① 说"顺序随便，能跑就行"；② 不知道 `def f(a=1, b)` 是语法错误；③ 把 keyword-only 说成"只能按名字传的默认参数"。
- **惊艳点**：`*args` 后面的**裸参数**自动变成仅限关键字，`f(1,2,3,4,5)` 会因为缺 `c=` 而报 TypeError——这个报错信息很多人没见过。验证：CPython 直接运行 `[实测]`

## 主问答
**Q：`def f(a, b=2, *args, c, d=4, **kw)` 这样写合法吗？调用时要注意什么？**
**A：**
1. **先给结论**：合法，且这正是**完整的五段顺序**：位置参数 `a` → 默认参数 `b` → `*args` → 仅限关键字 `c`（无默认，必传）与 `d`（有默认）→ `**kw`。
2. **再给机制**：`*args` 是分界线，**它之后出现的普通参数一律只能按关键字传**（PEP 3102）；`**kwargs` 必须垫底。
3. **最后给边界**：默认参数**不能**排在非默认参数前面（`def f(a=1, b)` 直接 SyntaxError）；仅限关键字参数**没有默认值就必须显式用 `c=...` 传**，否则 TypeError。
**加分层**：仅限关键字参数的设计动机是**防止位置传参把布尔开关传错**（如 `sort(key=..., reverse=True)`），可读性优先于简短。

## 追问链
| 层 | 追问 | 在测什么 | 怎么接 | 答不出停在哪档 |
|---|---|---|---|---|
| L1 | 形参分几段 | 术语 | 五段 | 换题 → 不及格 |
| L2 | `*args` 后的参数怎么传 | 机制 | 仅限关键字，必须 k=v | 判 P5 |
| L3 | `def f(a=1, b)` 合法吗 | 边界 | 不合法，SyntaxError | 判 P6 |
| L4 | 为什么需要仅限关键字 | 设计动机 | 防布尔开关传错位 | 判 P6+ |
| L5 | 你会在公共 API 上怎么设计签名 | 架构判断 | 必填前置、开关用 keyword-only | 答上判 P7 |

## 版本与兼容性
| 结论成立版本 | 翻转点 | 现在怎么答 |
|---|---|---|
| CPython 3.0+ | 仅限关键字参数由 PEP 3102 引入，Python 2 无此语法 | 一律按 Python 3 五段顺序答 |

## 关键代码
```python
def f(a, b=2, *args, c, d=4, **kw):
    return a, b, args, c, d, kw
print(f(1, 2, 3, 4, c=5, e=6))   # (1, 2, (3, 4), 5, 4, {'e': 6})
# f(1, 2, 3, 4, 5)               # TypeError: f() missing 1 required keyword-only argument: 'c'
# def g(a=1, b): pass            # SyntaxError: non-default argument follows default argument
```
