# 118. 工厂方法：把"创建"从"使用"里剥出去

> 分类：编程范式/设计模式 | 难度：L2 | 题型：工程题 | 频率：高 | 关键词：**工厂方法** / **解耦** / **if-else 分派** / **开闭**
> 原文锚点：第 17~26 段「工厂模式解决对象创建问题，把对象的创建跟使用解耦」

## 一句话总述
**工厂方法**用一个函数（或类方法）**封装对象创建**：调用方只传**类型标识**，工厂返回对应实例，从而把"**创建**"与"**使用**"解耦；新增产品时只改工厂一处。

## 面试官视角
- **考察意图**：考你是否理解解耦点在哪，以及**开闭原则**在 Python 里怎么落地。
- **P5** 能写出 `if type == 'dog': return DogToy()` / **P6** 能用**字典注册表**替代 if-else，新增类型只加一行 / **P7** 能指出"注册式工厂 + 装饰器注册"才是可插拔方案，并说明鸭子类型下工厂的价值边界 `[经验]`。
- **红旗**：① 写了工厂但调用方仍在 `isinstance` 判断类型；② `if-else` 链越来越长却不知道换字典；③ 认为工厂必须写成类（Python 里**函数/类方法**就够）。
- **惊艳点**：用 `dict` 做**类型→构造器**映射，甚至用装饰器自动注册，新增产品**零改动工厂**。验证：`TOYS['bird'] = BirdToy` 后工厂无需改一行 `[实测]`。

## 主问答
**Q：什么是工厂模式？写个例子。**
**A：**
1. **定义**：工厂（factory）是**专门负责创建对象**的对象/函数；把**对象的创建与使用解耦**，调用方只声明要什么，不关心怎么 new。
2. **示例**：`DogToy.speak()` 打印"汪汪"、`CatToy.speak()` 打印"喵喵"；`toy_factory(kind)` 传入 `'dog'` 返回 `DogToy()`，传入 `'cat'` 返回 `CatToy()`。
3. **分类**：通常分为**工厂方法**（单一产品、子类决定）与**抽象工厂**（一族相关产品，见 119）。
**加分层**：Python 里最简单的工厂是 `dict` 映射或 `getattr(模块, 类名)`；配合 `@classmethod` 还能让子类继承工厂逻辑（`cls` 是子类）。

## 关键代码
```python
class DogToy:
    def speak(self): return '汪汪'

class CatToy:
    def speak(self): return '喵喵'

TOYS = {'dog': DogToy, 'cat': CatToy}      # 注册表替代 if-else

def toy_factory(kind):                      # 工厂方法
    try:
        return TOYS[kind]()
    except KeyError:
        raise ValueError(f'unknown toy: {kind}')

print(toy_factory('dog').speak())           # 汪汪
```
