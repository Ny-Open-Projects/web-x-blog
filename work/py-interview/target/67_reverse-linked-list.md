# 67. 迭代法反转单链表怎么写才不出错

> 分类：算法与数据结构/链表 | 难度：L3 | 题型：工程题 | 频率：高 | 关键词：**三指针** / **prev/cur** / **就地反转**
> 原文锚点：第 39~56 段「首先我们是两个指针，一个是 prev，一个是 cur…最后我们把 prev 返回」

## 一句话总述
反转单链表用**迭代三指针**：维护 `prev` 与 `cur`，每轮先**存下 next**、再把 `cur.next` **反向指向 prev**、然后两个指针**同时前移**；循环结束返回 `prev`。

## 面试官视角
- **考察意图**：链表题的入门门槛，看指针操作是否干净、有没有断链。
- **P5** 能讲思路 / **P6** 一次写对并说清 O(n)/O(1) / **P7** 能顺带给出**递归版**与"反转前 N 个"的变体。
- **红旗**：① 先改 `cur.next` 再取 next，导致**断链**；② 返回 `cur`（此时已为 None）；③ 循环条件写成 `cur.next`。
- **惊艳点**：迭代版是**原地 O(1) 空间**，递归版是 O(n) 栈空间——面试官常在此追问。验证：百万节点下递归版直接爆栈 `[实测]`。

## 主问答
**Q：手写一个反转单链表的函数。**
**A：**
1. **先给思路**：`prev = None`，`cur = head`；当 `cur` 非空时循环，每轮把 `cur.next` 改指 `prev`，再整体前移。
2. **再给顺序**（关键）：必须**先暂存 `next_node = cur.next`**，再反转 `cur.next = prev`，最后 `prev = cur; cur = next_node`。顺序错了就断链。
3. **最后给复杂度**：时间 **O(n)**（每个节点访问一次），空间 **O(1)**（只用了常数个指针）；循环结束时 `cur` 为 None，**新头是 `prev`**。
**加分层**：递归版思路是"反转 head 之后的部分，再把 head 接到尾部"，代码更短但有 O(n) 递归栈，长链表会 `RecursionError`，生产环境一律用迭代版。

## 关键代码
```python
class Node:
    def __init__(self, v, nxt=None): self.value, self.next = v, nxt

def reverse(head):
    prev, cur = None, head
    while cur:
        next_node = cur.next     # 1) 先存后继，防止断链
        cur.next = prev          # 2) 反向指
        prev, cur = cur, next_node  # 3) 双指针前移
    return prev                  # 新头

def to_list(h): return [] if not h else [h.value] + to_list(h.next)
head = Node(1, Node(2, Node(3, Node(4, Node(5)))))
print(to_list(reverse(head)))    # [5, 4, 3, 2, 1]
```

## ⚠️ 原文纠错
原文逐步讲解的"prev/cur 双指针 + 前移"思路与最终"返回 prev"均正确；但口语描述中提到"两个指针"实际实现需要**三个**（含暂存的 next 节点），卡面已补正为三指针写法，避免按两指针实现时断链。转写中的音译变量名已还原为 prev / cur / next。未发现原理性错误。

## 总结与追问预判
- 存后继 → 反向指 → 双前移；返回 prev；O(n)/O(1)。
