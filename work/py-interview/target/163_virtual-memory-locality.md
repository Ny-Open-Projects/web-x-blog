# 163. 虚拟内存与局部性原理

> 分类：操作系统/内存 | 难度：L2 | 题型：概念主问 | 频率：高 | 关键词：**虚拟内存** / **局部性原理** / **swap** / **空间/时间局部性**
> 原文锚点：第 35~50 段「物理内存不足时把暂不用的内存放硬盘；根据局部性原理只需装必要信息，看起来比实际内存大」

## 一句话总述
**虚拟内存**让程序以为自己有比物理内存大得多的地址空间：暂不用的内存页换出到**硬盘（swap）**，需要时再换入。其理论基石是**局部性原理**（时间局部性 + 空间局部性）。

## 面试官视角
- **考察意图**：是否理解虚拟内存"为什么能超出物理内存"以及局部性为何成立。
- **P5** 能说出 swap 换入换出、虚拟内存扩容 / **P6** 能解释时间/空间局部性并说明为何只需装部分页 / **P7** 能指出 swap 不是无限扩容（换入换出有 IO 代价，过度即抖动，见 164 卡）。
- **红旗**：认为虚拟内存可以"无限扩充"；或说不清局部性两分支。
- **惊艳点**：局部性让**预取（prefetch）**和**缓存**有效——CPU 缓存、页缓存都建立在它之上 —— 验证：顺序遍历数组比随机访问快数倍，正是空间局部性在起作用 `[实测]`。

## 主问答
**Q（面试官原话）：** 什么是虚拟内存？局部性原理又是什么？

**A · 标准答案骨架：**
1. **先给结论**：虚拟内存把**暂时不用**的内存页换到硬盘、需要时换回，从而呈现比物理内存更大的地址空间；其依据是**局部性原理**。
2. **再给机制**：**时间局部性**（刚访问的内存很可能不久再访问）、**空间局部性**（被访问内存附近也很可能被访问）——故程序运行时只需把"必要页"装入内存。
3. **最后给边界**：虚拟内存**不是无限扩容**：换入换出是磁盘 IO，过度使用会演变为**内存抖动**（见 164 卡），性能反而暴跌。

**加分层**：虚拟内存同时提供**进程隔离**（各自独立地址空间），不止是扩容——这是常被忽略的收益 `[经验]`。

## ⚠️ 原文纠错
原文第 43~46 段将「局部性原理」音译为「**球形原理**」，正确术语为 **局部性原理（principle of locality）**，含时间局部性与空间局部性两分支。虚拟内存"换出硬盘/换回"论述正确。核对范围：第 35~50 段虚拟内存与局部性原理。

## 总结与追问预判
- 虚拟内存=换入换出扩容+隔离；局部性=时间+空间，支撑只需装部分页。
- 顺势会问：**内存抖动与置换策略（见 164 卡）**、**分页机制（见 161 卡）**。
