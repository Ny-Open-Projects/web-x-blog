# 156. 线程同步之信号量（Semaphore）

> 分类：并发 | 难度：L2 | 题型：原理题 | 频率：中 | 关键词：**信号量** / **计数** / **限流**
> 原文锚点：第 41~44 段「信号量可以控制同时访问同一资源的线程数，传一个值控制最多几个线程」

## 一句话总述
**信号量（Semaphore）**用**计数器**控制同时进入临界区的线程数量（N 个）；与锁的区别是：锁只允许 **1** 个，信号量允许 **N** 个——常用于连接池、限流。

## 面试官视角
- **考察意图**：是否分得清锁与信号量，以及能否举出信号量的真实用场（限流/池化）。
- **P5** 会用 `threading.Semaphore(n)` 限制并发数 / **P6** 能说清内部计数器 `acquire` 减、`release` 加、归零则阻塞 / **P7** 能指出信号量滥用会变"慢锁"，以及 `BoundedSemaphore` 防多 release。
- **红旗**：把信号量当锁用（设成 1）还说不清区别。
- **惊艳点**：`BoundedSemaphore` 在 `release` 超过初始值时报 `ValueError`，能抓出"多释放"bug —— 验证：初始 2、release 第 3 次抛异常 `[实测]`。

## 主问答
**Q（面试官原话）：** 锁和信号量有什么不一样？信号量一般用在哪？

**A · 标准答案骨架：**
1. **先给结论**：**锁**只允许 **1** 个线程进临界区；**信号量**允许 **N** 个，本质是带计数的许可。
2. **再给机制**：`Semaphore(n)` 内部计数，`acquire` 成功则减 1、为 0 时阻塞；`release` 加 1。
3. **最后给边界**：当 N=1 时退化为锁；但语义上信号量表达"**最多 N 个并发**"，典型用于**连接池/限流**，而非保护单一变量。

**加分层**：信号量与锁是不同抽象：锁保护互斥资源，信号量限制并发度——别混用 `[经验]`。

## 关键代码
```python
import threading
sem = threading.Semaphore(3)   # 最多 3 个线程同时进入

def work():
    with sem:                  # acquire 成功才进，满 3 个则阻塞 [实测]
        print("holding a slot")
```
