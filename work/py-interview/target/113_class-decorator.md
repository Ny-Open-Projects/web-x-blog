# 113. 用类实现装饰器：__call__ 让实例可调用

> 分类：编程范式/装饰器 | 难度：L2 | 题型：八股题 | 频率：中 | 关键词：**类装饰器** / **__call__** / **可调用对象** / **状态**
> 原文锚点：第 32~43 段「使用类来编写装饰器，实现 __call__ 方法」

## 一句话总述
类也能当装饰器：**`__init__` 接收被装饰函数**并保存在实例上，**`__call__` 里写包装逻辑**，因为带 `__call__` 的实例是**可调用对象**，能顶替原函数的位置。

## 面试官视角
- **考察意图**：看你是否把"装饰器 = 可调用对象替换"这件事真正抽象出来。
- **P5** 知道要实现 `__call__` / **P6** 能写出 `__init__` 存 func、`__call__` 透传参数的完整写法 / **P7** 能指出类装饰器的**独特优势：天然可持有状态**（实例属性），以及它和函数闭包的选型差异 `[经验]`。
- **红旗**：① 只在 `__init__` 里写逻辑、忘了 `__call__`；② `__call__` 里漏掉 `return`；③ 认为类装饰器必须要加括号（**不带参时 `@LogTime` 不加括号**）。
- **惊艳点**：类装饰器把"闭包变量"升级成"实例属性"，**状态可读可改**（如计数、限流阈值）。验证：`my_sleep.calls` 能直接读出累计调用次数 `[实测]`。

## 主问答
**Q：怎么用类实现一个装饰器？和函数版有什么区别？**
**A：**
1. **写法**：`class LogTime:` 的 `__init__(self, func)` 把原函数存为 `self.func`；`__call__(self, *args, **kwargs)` 里记时、调原函数、打印、返回结果。
2. **原理**：`@LogTime` 会执行 `my_sleep = LogTime(my_sleep)`，`my_sleep` 从此是**实例**；调用 `my_sleep()` 触发的是 `__call__`。
3. **优势**：状态可挂在实例属性上（计数、阈值、缓存），比闭包更直观；**带参时写成 `@LogTime(use_int=True)`**（先实例化，再调用实例去包装）。
**加分层**：带参数时**必须加括号**，因为要先 `__init__` 造一个装饰器实例；不带参时不能加括号，否则会把函数当成构造参数传错位置。

## 关键代码
```python
import time

class LogTime:
    def __init__(self, func):        # 接收被装饰函数
        self.func = func
        self.calls = 0               # 用实例属性存状态

    def __call__(self, *args, **kwargs):
        begin = time.perf_counter()
        self.calls += 1
        try:
            return self.func(*args, **kwargs)
        finally:
            print(f'cost {time.perf_counter() - begin:.4f}s')

@LogTime
def my_sleep():
    time.sleep(0.1)

my_sleep()
print(my_sleep.calls)                # 1 —— 状态可读
```
