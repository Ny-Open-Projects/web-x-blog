# 147. 文件与权限命令：chmod / chown / chgrp / ls / cp / rm

> 分类：操作系统/Linux | 难度：L2 | 题型：工程题 | 频率：中 | 关键词：**chmod** / **chown** / **chgrp** / **rwx** / **文件权限**
> 原文锚点：第 30~33 段「chown 改所有者、chmod 改模式、chgrp 改组；ls 列举、rm 删除、cd 切换、cp 拷贝」

## 一句话总述
Linux 下管控文件靠三类命令：**`chown`** 改属主、**`chgrp`** 改属组、**`chmod`** 改权限位（rwx）；配合 `ls -l` 查看、`cp` 拷贝、`rm` 删除、`cd` 切换目录，是日常排障与部署的基础。

## 面试官视角
- **考察意图**：考你能否把权限位（rwx 与数字 755/644）讲清，并安全使用这些命令。
- **P5** 能说出 chmod/chown/chgrp 的用途 / **P6** 能解释 **rwx 数字表示**（r=4/w=2/x=1，755 = 属主rwx、组与其他 rx）并举例 / **P7** 能指出 `chmod -R`、`rm -rf` 的**危险性**与误操作防护，以及 `chown` 递归改属主对服务的影响 `[经验]`。
- **红旗**：① 说不清 755/644 每一位含义；② 以为 `rm` 有回收站（Linux 默认直接删）；③ `chmod 777` 当通用解法（安全隐患）。
- **惊艳点**：`chmod 755 file` = `rwxr-xr-x`；`chmod u+x` 只给属主加执行位。验证：`stat -c %a file` 直接看数字权限 `[实测]`。

## 主问答
**Q：chmod / chown / chgrp 分别干嘛？755 是什么意思？**
**A：**
1. **结论**：`chown` 改**属主**、`chgrp` 改**属组**、`chmod` 改**权限位**；三者分别管"谁拥有 / 哪个组 / 能干什么"。
2. **机制**：`chmod` 用 rwx 对应 4/2/1；`755` = 属主 rwx(7)、组 rx(5)、其他 rx(5)；`644` = 属主 rw、组与其他 r。
3. **边界**：`rm -rf`、递归 `chmod -R` / `chown -R` **不可逆且危险**，生产前务必确认路径，避免误删或改崩服务权限。
**加分层**：`chmod +x` 给执行位、`chown -R user:group dir` 递归改属主属组是部署常见操作。

## 关键代码
```bash
chown user:group app.py      # 改属主与属组
chmod 755 deploy.sh          # rwxr-xr-x
chmod 644 config.ini         # rw-r--r--
ls -l                        # 查看权限与属主
stat -c %a deploy.sh         # 直接看数字权限
```

```python
import os
os.chmod("deploy.sh", 0o755)     # rwxr-xr-x（八进制前缀 0o）
```
