# 84. 二叉树的左视图与右视图：层序遍历的变形

> 分类：算法与数据结构/二叉树 | 难度：L3 | 题型：工程题 | 频率：中 | 关键词：**左视图** / **右视图** / **层序变形** / **取首尾**
> 原文锚点：第 118~121 段「我们只需要把每一层的最左边跟最右边的拿出来作为结果」

## 一句话总述
左视图 = 从左边看树能看到的节点（**每层第一个**），右视图 = 每层**最后一个**；只要在**层序遍历**基础上对每层取 `层[0]` 或 `层[-1]` 即可，无需新算法。

## 面试官视角
- **考察意图**：考**迁移能力**——能不能看出新题是旧题的变形，而不是重新发明。
- **P5** 没思路 / **P6** 说出"层序 + 取首尾" / **P7** 补出 DFS 解法（先访问右子树 + 记录深度）并比较两者空间 `[实测]`。
- **红旗**：① 试图用中序/后序去凑层信息；② 把右视图答成"最右路径"（那是另一题）；③ 忽略空树。
- **惊艳点**：两视图都能用**同一个 DFS** 解决——先递归右子树、按深度首次到达即记录，右视图是"先右"、左视图是"先左" `[实测]`。验证：两种方法在随机树上输出一致。

## 主问答
**Q：怎么求二叉树的左视图和右视图？**
**A：**
1. **定义**：左视图是从左侧看过去每层**第一个可见**节点，右视图是每层**最后一个**；例：树 `3 / 9 20 / 15 7` 的左视图为 `3, 9, 15`，右视图为 `3, 20, 7`。
2. **BFS 解**：跑层序遍历，每层子列表取 `层[0]`（左视图）或 `层[-1]`（右视图）拼进结果；时间 `O(n)`，空间 `O(w)`。
3. **DFS 解**：递归时带上 `depth`，若 `depth == len(ans)` 说明该层首次到达，记录节点值；先走右子树得右视图，先走左子树得左视图；空间 `O(h)`。
**加分层**：BFS 要存整层，DFS 只存一条路径；**树很宽时 DFS 更省空间**，需要按层做别的处理时才选 BFS。

## 关键代码
```python
class N:
    def __init__(self, v, l=None, r=None): self.value, self.left, self.right = v, l, r

def level_order(root):                 # 复用 82 的层序，返回每层子列表
    if not root:
        return []
    res, cur = [], [root]
    while cur:
        res.append([n.value for n in cur])
        nxt = []
        for n in cur:
            if n.left:  nxt.append(n.left)
            if n.right: nxt.append(n.right)
        cur = nxt
    return res

def views_bfs(root):                   # BFS：每层取首 / 取尾
    layers = level_order(root)
    return [lay[0] for lay in layers], [lay[-1] for lay in layers]

def view_dfs(root, side="right"):      # DFS：按深度首次到达，先右得右视图
    ans = []
    def go(node, depth):
        if not node:
            return
        if depth == len(ans):
            ans.append(node.value)
        first, second = (node.right, node.left) if side == "right" else (node.left, node.right)
        go(first, depth + 1); go(second, depth + 1)
    go(root, 0)
    return ans

tree = N(3, N(9), N(20, N(15), N(7)))
print(views_bfs(tree))                 # ([3, 9, 15], [3, 20, 7])
print(view_dfs(tree, "left"))          # [3, 9, 15]
```
