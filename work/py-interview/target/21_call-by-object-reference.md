# 21. Python 传参到底是传值还是传引用

> 分类：语言基础/函数 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**共享传参** / **引用副本** / **重绑定**
> 原文锚点：第 14~20 段「Python 唯一支持的，我们称作叫共享传参…传递的是实参中这个引用它的一个拷贝值」

## 一句话总述
Python 只有一种参数传递方式——**共享传参（call by object reference）**：形参拿到的是实参引用的**副本**，两者指向同一对象，改不改得动只取决于**对象可变与否**。

## 面试官视角
- **考察意图**：是真懂"变量是标签"，还是背了"可变传引用、不可变传值"这句错话。
- **P5** 说得出共享传参 / **P6** 能画出两段代码的内存指向图 / **P7** 能点出"形参重绑定对外永远不可见"这条边界。
- **红旗**：①"可变传引用、不可变传值"——传递方式只有一种；②说"Python 拷贝了整个对象"；③ 答不出用 `id()` 验证。
- **惊艳点**：传参前后 `id()` **相同**证明是同一对象；`s += "a"` 后函数内 id 变、外部 id 不变，证明只是**重绑定**。验证：`python3` 直接跑下面代码 `[实测]`

## 主问答
**Q：Python 里面传参是传值还是传引用？为什么 list 会被函数改掉、str 不会？**
**A：**
1. **先给结论**：都不是。Python 唯一支持**共享传参**，传的是**对象引用的副本**。
2. **再给机制**：调用 `f_list(ll)` 时形参 `l` 绑定到 `ll` 指向的**同一个 list 对象**，`l.append(0)` 是**原地修改**，所以外部可见；而 `s += "a"` 对不可变对象无法原地改，只能**新建对象并让形参指向它**，外部实参毫发无损。
3. **最后给边界**：**任何**对形参的重新赋值 `x = ...` 都只是**重绑定形参这个名字**，永远不影响外部实参——这条与对象可变不可变**无关**。
**加分层**：对 C/Java 背景的人一句话讲透：它就是"值传递，但传的那个值是地址"。

## 关键代码
```python
def f_list(l):
    print("in ", id(l)); l.append(0)     # 原地修改 → 外部可见
def f_str(s):
    print("in ", id(s)); s += "a"        # 新建对象并重绑定 → 外部不可见
ll, ss = [], "he"
print("out", id(ll)); f_list(ll); print(ll)   # [0]
print("out", id(ss)); f_str(ss);  print(ss)   # he
```

## ⚠️ 原文纠错
原文「既有时候表现的像传引用，有时候又表现的像传值」方向正确，但需补正：**可变/不可变改变的是"能否原地修改"，不是"传递方式"**，传递方式自始至终只有一种。原文中的音译术语已统一还原为标准写法（call by object reference）。
