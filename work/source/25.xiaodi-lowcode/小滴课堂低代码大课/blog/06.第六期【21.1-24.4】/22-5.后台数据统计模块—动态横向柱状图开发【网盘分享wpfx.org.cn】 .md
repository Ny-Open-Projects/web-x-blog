# 后台数据统计模块—动态横向柱状图开发

> **导语**：动态图表最后一种——横向柱状图。它和饼状图共用同一套数据流，区别只在 ECharts 配置：Y 轴放分类名（游泳 / 篮球 / 按摩），X 轴放数值，背景条铺满 100% 做对比。本节讲清横向柱状图的配置要点，整个数据统计模块图表部分就此收尾。

## 前置知识

- 先读《后台数据统计模块—动态饼状图开发》，本节的 `getPieOptions` 与 `pieData` 思路可直接复用。
- 仍基于 `echarts` + `echarts-for-react`（前端 `package.json` 已含）。
- 数据格式依旧是 `{ name, value }`，由 `reduce` 统计选项次数得到。

## 正文

### 复用组件，只换配置方法

横向柱状图同样用 `ReactECharts`，只是 `option` 来自 `getBarOptions()`：

```tsx
<ReactECharts option={getBarOptions()} />
```

与上节饼状图相比，组件、数据流、`useMemo` 统计逻辑完全一致，唯一变化是配置项。ECharts 配置项极多，按官方文档查用即可，无需背诵。

### 横向柱状图的关键配置

```ts
function getBarOptions() {
  return {
    grid: { left: '20%', containLabel: true }, // 网格左移更居中，标签不被裁剪
    legend: { data: [] },                       // 此处无图例需求，置空
    xAxis: { max: 100 },                        // X 轴 0~100，表示百分比
    yAxis: {
      type: 'category',
      data: barNames, // ['游泳','篮球','按摩']
    },
    series: [
      {
        type: 'bar',
        data: barValues, // 每项实际人数
        // 背景条：统一铺满 100
        showBackground: true,
        backgroundStyle: { color: '#eee' },
      },
    ],
  };
}
```

要点拆解：

- **横向的关键在 Y 轴**：`yAxis.type = 'category'`，`data` 放分类名（游泳、篮球、按摩），柱子自然横向生长；
- **X 轴表示数值**：`xAxis.max = 100` 表示按百分比，悬浮时显示「游泳 1」「篮球 1」等；
- **背景条**：`showBackground: true` + `backgroundStyle` 把每条槽位铺成灰色 100%，前景色（蓝）按真实人数填充，视觉对比强烈；
- `grid.containLabel: true` 保证 Y 轴长名称不被裁掉。

### 数据动态化

`barNames` 与 `barValues` 同样用 `useMemo` 跟随 `currentSelect` 变化：

```ts
const barNames = columnOptions.map((i) => i.value);   // 选项文本
const barValues = columnOptions.map((i) => result[i.id] ?? 0); // 出现次数
```

点击 radio / checkbox（如「爱好」），`currentSelect` 改变 → 图例、分类名、数值全部刷新，柱子实时重绘。整个动态图表体系（饼图 + 横向柱状图）就此闭环。

## 小结

- 横向柱状图与饼状图共用数据流，仅 `option` 不同。
- 横向靠 `yAxis.type='category'` 放分类名，`xAxis` 放数值。
- `showBackground` 铺满灰色 100% 做底，前景按真实计数填充。
- 数据仍用 `useMemo` + `reduce` 处理成 `{ name, value }` 风格，随选中项刷新。
