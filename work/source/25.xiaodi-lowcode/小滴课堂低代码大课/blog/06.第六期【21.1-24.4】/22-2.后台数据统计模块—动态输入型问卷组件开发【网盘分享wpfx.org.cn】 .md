# 后台数据统计模块—动态输入型问卷组件开发

> **导语**：数据统计页右侧要展示「动态图表」。本节先把支撑图表的表格渲染出来——请求所有问卷组件接口，用 Ant Design 的 Table 列出「标题 / 类型 / 操作」，并通过「查看数据」按钮切换当前选中的组件，为下一节展示用户填写内容或图表做准备。

## 前置知识

- 建立在《后台数据统计模块—用户表格数据导出Excel《下》》之后，同属后台数据统计模块。
- 前端使用 React + Ant Design（`antd` 见前端 `package.json` 依赖 `"antd": "^5.11.2"`），表格组件为 `Table`。
- 了解 `useState` 状态管理与受控组件的基本用法。

## 正文

### 右侧表格要展示什么

统计页右侧的效果是：

- 「标题、类型、操作」三列表头是**写死**的固定列；
- 表格内容来自上一节请求回来的问卷组件数据——也就是 `input`、`textarea`、`radio`、`checkbox` 等组件类型，以及它们各自的 `title`；
- 点击某一行的「查看数据」，下方就动态渲染该组件的用户数据或图表。

注意：输入框（input）、文本域（textarea）是用户自定义输入的内容，不支持聚合图表；而 radio、checkbox 是固定选项，才适合用 ECharts 展示。

### 抽出 ComponentSelect 子组件

父组件 `DataCount` 原本用一段占位文本，现在抽出一个 `ComponentSelect` 子组件：

```tsx
<ComponentSelect
  components={components}
  setCurrentSelect={setCurrentSelect}
  defaultId={defaultId}
/>
```

三个入参含义：

- `components`：请求「获取所有问卷组件」接口拿到的数据；
- `setCurrentSelect`：切换当前选中项的回调；
- `defaultId`：默认选中的组件 ID，保证首屏刷新就有内容展示。

父组件请求到组件列表后，直接把第一项交给 `setCurrentSelect` 作为默认值，这样第一次进入页面右侧就有数据。

### Table 的列定义与 render

在子组件里，表头（columns）前两项固定，第三项「操作」多一个 `render` 函数：

```ts
const columns = [
  { title: '标题', dataIndex: 'title', key: 'title' },
  { title: '类型', dataIndex: 'type', key: 'type' },
  {
    title: '操作',
    key: 'action',
    render: (_, record) => (
      <Button
        disabled={record.key === currentSelect?.id}
        onClick={() => setCurrentSelect(record)}
      >
        查看数据
      </Button>
    ),
  },
];
```

`render` 的第二个参数是当前行数据 `record`，据此判断「当前行是不是已选中的那一项」——若是则 `disabled`，避免重复点击。点击时把整行数据回传给父组件的 `setCurrentSelect`，实现切换。

### dataSource 的数据格式转换

Table 需要的 `dataSource` 结构是 `{ key, title, type, component }`：

```ts
const dataSource = components.map((item) => ({
  key: item.id,
  title: item.title || '未命名组件', // 兜底数据
  type: item.type,
  component: item, // 整项透传，供后续使用
}));
```

`key` 用组件 `id`；`title` 缺失时给兜底文案；`component` 把原对象整项保留，方便点击时拿到完整信息。

## 小结

- 右侧表格三列：标题、类型、操作，其中「操作」用 `render` 渲染「查看数据」按钮。
- 通过 `useState` 维护 `currentSelect`，默认选中第一项保证首屏有内容。
- 已选中的行按钮 `disabled`，点击切换 `currentSelect`。
- `dataSource` 需转换成 `{ key, title, type, component }` 格式，title 缺省有兜底。
