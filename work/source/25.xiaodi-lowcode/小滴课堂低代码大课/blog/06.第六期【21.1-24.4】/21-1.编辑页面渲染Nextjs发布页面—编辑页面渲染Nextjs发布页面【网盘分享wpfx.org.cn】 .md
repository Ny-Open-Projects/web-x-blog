# 编辑页面渲染Nextjs发布页面—编辑页面渲染Nextjs发布页面

> **导语**：用户在编辑平台点击「发布」后，需要原地看到发布后的页面。本文讲解在 React 编辑项目中新增 `release` 路由，用 HTML 的 `<embed>` 标签内嵌 Next.js 发布页 URL，并通过路由参数把页面 ID 透传进去。

## 前置知识

- 已掌握发布页面本身的开发，见《低代码项目发布页面—获取页面渲染》《低代码项目发布页面—发布页面提交问卷》。
- 已了解 React 路由配置，见《低代码项目前端项目开发—路由配置》。
- 已了解 `useNavigate` / `useLocation`，见《低代码项目前端项目开发—公共状态管理+自定义 hooks》。

## 正文

### 新增 release 路由页面

在 React 编辑项目的 `router/index.tsx` 中新增路径 `release`，`element` 指向 `Release` 组件（与 `preview`、`index`、`edit`、`login`、`register` 同级，维护在 `pages` 目录下）。

### 用 embed 内嵌 Next.js 发布页

`Release` 组件的核心是用 HTML 自带的 `<embed>` 标签把 Next.js 发布页的 URL 嵌进来。`<embed>` 不仅能嵌图片，也能嵌 HTML 页面/视频，无需额外引入：

```tsx
<embed type="text/html" src={url} width="100%" height="100%" />
```

其中 `url` 拼接为：`http://localhost:3001/` + 页面 ID（如 `3`）。这里的 3001 是 Next.js 发布项目的端口，与编辑平台 5173 是不同工程。

### 透传页面 ID

点击编辑平台的「发布」按钮（`run` 成功回调里）跳转时，路由为 `release?id=3`（当前页面 ID）。在 `Release` 组件中通过 `useLocation()` 拿到 `location.search`，再用 `replace` 把 `?id=` 这一段删掉，只保留纯数字 `3`，拼进 `embed` 的 `src`，否则 Next.js 路由 `/release/3` 收不到正确参数。

### 二维码与返回按钮

- 二维码：用 Ant Design 的 `QRCode` 组件，把发布页 URL 传入即可生成可扫码访问的二维码；
- 返回按钮：用 antd 图标，点击时调用 `useNavigate()` 得到的 `nav(-1)` 实现「返回上一页」，回到编辑平台重新配置。

### 上线提示

当前 `url` 写死 `localhost`，后续项目上线时只需把 IP/域名替换即可。至此，无代码能力的用户也能在平台拖拽配置页面、一键发布，获得属于自己的线上官网或问卷系统。

## 小结

1. 编辑平台新增 `release` 路由，组件与 `preview` 等并列。
2. 用原生 `<embed type="text/html" src=url>` 内嵌 Next.js 发布页，无需引依赖。
3. 通过 `useLocation` 取 `?id=` 并 `replace` 为纯 ID，拼进 `embed` 的 `src`。
4. antd `QRCode` 生成访问二维码；`nav(-1)` 实现返回编辑页。
