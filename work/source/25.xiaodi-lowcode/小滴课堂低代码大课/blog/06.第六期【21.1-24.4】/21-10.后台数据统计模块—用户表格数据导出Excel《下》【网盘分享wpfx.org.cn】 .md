# 后台数据统计模块—用户表格数据导出Excel《下》

> **导语**：上一节我们用 ExcelJS 在内存中拼好了工作簿（表头 + 内容），但浏览器还看不到、也不能下载。本节完成「临门一脚」——把工作簿转成二进制 Buffer，借助浏览器原生的 Blob 与 `URL.createObjectURL` 触发下载，让导出的 Excel 真正落到本地，双击即可打开。

- 了解浏览器端文件下载机制：Blob、`<a>` 标签的 `download` 属性、`window.URL.createObjectURL` / `revokeObjectURL`。

## 正文

### 为什么还需要 Blob 和下载逻辑

上一节我们通过 `Workbook` 添加了表头和内容，也成功 `console.log` 打印出来了，但那只是存在于内存中的对象。要让用户在 Chrome 里「点到就能下载、下载后能用 Excel 打开」，需要两步：

1. 把工作簿转成**二进制 Buffer**；
2. 把 Buffer 包成浏览器可识别的 **Blob 大对象**，再借助 `<a>` 标签触发下载。

### 第一步：工作簿转 Buffer

ExcelJS 提供了 `Workbook.XLSX.writeBuffer()`，它把整张表序列化成二进制的 `ArrayBuffer`（本质是一串字节）。拿到 Buffer 后，我们把它和页面的 `title` 一起传给 `saveFile`：

```ts
const buffer = await workbook.xlsx.writeBuffer();
saveFile(buffer, `${title}数据统计.xlsx`);
```

注意文件后缀要带 `.xlsx`，这样本地才会按 Excel 文件识别。这里的写入逻辑受一个 `isWriteFile` 变量控制——父组件调用导出方法时传入 `true`，才会真正执行写文件 + 下载；后续「导出压缩包」那篇会把它设成 `false`，走另一条路。

### 第二步：Buffer 包成 Blob

`saveFile` 内部真正做的是把二进制包成 Blob：

```ts
function saveFile(buffer: ArrayBuffer, fileName: string) {
  // 第一个参数必须是数组形式，第二个参数声明类型
  const blob = new Blob([buffer], {
    type: 'application/octet-stream',
  });
  saveFileWithBlob(blob, fileName);
}
```

要点：

- Blob 第一个参数要用**数组**包裹二进制数据；
- `type: 'application/octet-stream'` 表示「未知二进制流」，是我们这种二进制导出场景的固定写法。

Blob 本身在控制台打印只能看到大小和类型，看不到内容，这是正常的。

### 第三步：触发浏览器下载

`saveFileWithBlob` 负责把 Blob 变成一次真实下载：

```ts
function saveFileWithBlob(blob: Blob, fileName: string) {
  // 1. 把 Blob 转成一个临时 URL
  const url = window.URL.createObjectURL(blob);
  // 2. 创建一个 <a> 标签
  const a = document.createElement('a');
  a.href = url;
  a.download = fileName; // 下载时的文件名
  // 3. 自动触发点击
  a.click();
  // 4. 释放 URL，避免内存泄漏
  window.URL.revokeObjectURL(url);
}
```

这里有两个浏览器原生 API 要记住：

- `window.URL.createObjectURL(blob)`：静态方法，为 Blob 生成一个临时的 `blob:` 开头的 URL，生命周期绑定在当前 document 上。
- `window.URL.revokeObjectURL(url)`：用完即释放，否则会一直占用内存。

`<a>` 标签的 `download` 属性决定「下载后保存的文件名」，配合 `a.click()` 即可静默触发下载，无需用户真的去点。

### 实际效果

回到页面点「导出Excel」，Chrome 会直接弹出下载提示，文件名类似「小滴课堂低代码开发页面数据统计.xlsx」。下载后双击打开，里面的行、列、内容跟页面渲染的一模一样，导出链路就此闭环。

## 小结

- `workbook.xlsx.writeBuffer()` 把工作簿序列化成二进制 Buffer。
- Blob 用数组包裹 Buffer，并声明 `application/octet-stream` 类型。
- `URL.createObjectURL` 生成临时地址，`<a download>` + `click()` 触发下载。
- 下载完成后务必 `revokeObjectURL` 释放内存。
- `isWriteFile` 开关区分「导出Excel」与后续「导出压缩包」两条分支。
