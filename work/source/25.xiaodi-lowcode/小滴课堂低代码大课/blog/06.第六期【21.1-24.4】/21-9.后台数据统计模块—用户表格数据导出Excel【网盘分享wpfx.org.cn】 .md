# 后台数据统计模块—用户表格数据导出Excel

> **导语**：表格统计好的问卷数据，需要能导出成 Excel 离线分析。本文讲解用 `ExcelJS` 生成工作簿、把 antd 表头格式改造成 Excel 列头、填入行数据，并预告浏览器下载所需的后续处理。

## 前置知识

- 已开发表格内容与表头，见《后台数据统计模块—用户表格数据内容开发》《后台数据统计模块—用户表格数据表头开发》。
- 已了解 antd Table 的 `columns`/`dataSource`，见上两节。
- 依赖 `exceljs`（见 `代码（已8期）/21-9/lowcode/packages/client/package.json` 已加入 `"exceljs": "^4.4.0"`）。

## 正文

### 引出 ExcelJS

要把页面表格导出为 `.xlsx`，引入第三方库 `ExcelJS`（GitHub 上的开源电子表格生成库，可写数据与样式到 xlsx/json）。通过 `pnpm install exceljs` 安装。它能在浏览器中生成 Excel 对象，再配合下载方式落地为文件。

### 导出按钮与共用方法

页面预留的「导出 Excel」按钮绑定 `handleExportExcel`，点击时调用共用方法 `jsonToExcel`，并传入参数：

- `isWriteFile`：是否直接写文件下载。导出 Excel 传 `true`，导出压缩包（下节课）传 `false`；缺省默认 `true`；
- `columns`：当前表格表头数组（上节生成的 `{ title, dataIndex, key }`）；
- `dataSource`：表格内容数组；
- `title`：来自 store 的页面标题（如「小滴课堂低代码平台」），作为工作表抬头。

### jsonToExcel 的实现（utils/excel）

`jsonToExcel` 接收上述四个参数并解构，主要步骤：

1. **创建工作簿**：`new ExcelJS.Workbook()` 实例化；
2. **添加工作表**：`workbook.addWorksheet(title)`，用页面标题作为工作表名；
3. **设置行高**：`workbook.properties` 相关的 `defaultRowHeight = 20`；
4. **生成表头**：`generateHeader(columns)` 把 antd 格式改造成 Excel 需要的 `{ header, key, width }`——`header` 为列头显示文字（取 `title`），`key` 为数据匹配键（取 `dataIndex`），`width` 为列宽；
5. **添加行数据**：直接 `addRows(dataSource)`，内容保持原格式一五一十写入，无需改造。

### 浏览器中预览生成结果

调用后可在浏览器 `console.log` 打印生成的对象（`workbook`）确认：表头 `headers` 是含四个元素的数组（姓名/描述/性别/爱好，各带 style、width、key），行数据对应每列。此时数据已正确生成，但还只是内存对象，并未下载到本地——浏览器无法直接预览 Excel，需要再加工成可下载的文件。

## 小结

1. 用 `ExcelJS` 生成 xlsx，`pnpm install exceljs` 安装（已在 client 依赖中）。
2. `handleExportExcel` 调共用 `jsonToExcel`，传 `isWriteFile=true`、表头、内容、页面标题。
3. `jsonToExcel`：建工作簿 → 加工作表（抬头）→ 设行高 → `generateHeader` 把 antd 列改造成 `{header,key,width}` → `addRows` 写入内容。
4. 当前仅生成内存对象，浏览器下载落地留待下节课。
