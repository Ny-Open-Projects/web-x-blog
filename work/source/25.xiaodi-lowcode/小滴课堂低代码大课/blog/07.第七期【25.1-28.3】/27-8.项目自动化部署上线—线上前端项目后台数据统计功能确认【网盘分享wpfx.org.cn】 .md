# 项目自动化部署上线—线上前端项目后台数据统计功能确认

> **导语**：编辑平台功能确认后，本集验证最后一个线上模块——后台数据统计。实测用户问卷数据的展示、Excel 导出、压缩包导出，以及基于问卷组件的动态表格、饼状图与柱状图，确认整套低代码平台全部上线成功。

- 已完成《项目自动化部署上线—线上前端项目编辑平台功能确认》，编辑平台核心功能已验证。
- 后台数据统计模块的开发参见《后台数据统计模块—用户表格数据内容开发》《后台数据统计模块—动态饼状图开发》等。

## 正文

### 数据看板与用户列表

进入**后台数据统计**页面，左侧展示所有填写过问卷组件的用户提交记录。先在发布页提交一条新记录（如"小弟 / 客服 / 冰冰"），回到统计页即可看到新增数据，说明前后端数据同步正常。

### 导出 Excel 与压缩包

- 点击**导出 Excel**：表格成功导出，可在本地打开核对；
- 点击**导出压缩包**：压缩包同样成功导出，便于批量分发。

### 动态表格与图表

右侧是动态表格，可按问卷组件类型查看填写内容：

- **textarea**：如"小滴课堂讲师""小滴客服"的填写内容；
- **input**：如姓名"大招""彬彬"；
- **radio（性别）**：点击查看数据，饼状图与柱状图随之渲染。

例如性别选"男 / 女"、爱好选"游泳"后，饼状图与柱状图能正确反映分布；取消某一项的勾选即可从图表中隐藏该维度。动态图表渲染正常。

### 全套上线收尾

至此，后端（NestJS）、前端发布（Next.js）、前端编辑平台（React）三个项目全部上线成功，且功能验证均无问题。实际实操时请按你自己的服务器 IP、端口、Bucket 地址与已备案域名来配置。

## 小结

1. 后台数据统计左侧展示所有问卷提交用户记录，数据实时同步。
2. Excel 导出、压缩包导出均成功。
3. 动态表格可按 textarea / input / radio 等组件类型查看填写内容。
4. 饼状图、柱状图能正确反映问卷分布，维度可交互显隐。
5. 三个项目全部上线成功，低代码平台整套链路验证完毕。
