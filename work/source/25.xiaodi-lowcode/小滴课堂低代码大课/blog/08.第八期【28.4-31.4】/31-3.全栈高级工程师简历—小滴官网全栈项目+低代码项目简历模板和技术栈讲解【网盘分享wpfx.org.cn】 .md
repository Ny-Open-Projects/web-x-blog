# 全栈高级工程师简历—小滴官网全栈项目 + 低代码项目模板与技术栈讲解

> **导语**：课程走到简历环节，目标是把「前端大课」和「低代码大课」两门课学到的技术栈与项目，整理成一份全栈高级工程师简历。本文先讲第一个模块——技术栈：为什么要分类写、每一类该放哪些技术、以及没学过第一门大课的同学该怎样如实删减。配套资料：高级前端开发工程师简历【前端大课+低代码】.docx / .pdf。

## 前置知识

建议先读《大厂面试官角度告诉你-项目经验需要注意的事情》，先搞清楚简历里项目经验该怎么写、面试官会盯哪些点。本文只覆盖「技术栈」这一栏，不涉及项目描述与自我评价。

## 正文

### 先分类，再列举

技术栈最好按类别分组写，比一口气列二十个名词规整得多；当然也可以不加序号、按由易到难分点列举，看个人习惯。分类的价值在于让面试官几秒内看清你的能力面，而不是在一长串缩写里找关键词。

如果没学过第一个前端大课，不必硬凑：把自己确实没接触过的技术栈或项目适当删减即可，写上去经不起追问反而扣分。

### 编程语言与样式

- HTML、CSS、JavaScript，以及 ES6 进阶语法；
- TypeScript 静态类型校验；
- CSS 预处理器（Less / Sass）、Tailwind CSS。

其中 CSS 预处理器在前端大课里有详细讲解，Tailwind CSS 则是本低代码大课前端配置里实际使用的方案，两者都属于「用过就能写」的部分。

### 框架与多端

- Vue 3 与全家桶；
- Nuxt：Vue 生态的服务端渲染框架；
- Next.js：React 生态的服务端渲染框架，用来优化页面 SEO——本大课的发布页正是用它；
- Vue 多端开发：微信小程序、Android / iOS APP，前端大课里从需求分析一直讲到上架应用市场；
- React 开发复杂项目：本低代码编辑端、自定义 Hooks、第三方 ahooks、immer，以及 MobX 公共状态管理。

### 开发工具

- Webpack 构建与包体积优化（很重要）、Vite、Babel；
- Git / GitHub、第三方组件库的使用。

### 服务端技术

- 常用 Linux 命令，能操作文件与容器；
- Docker 容器部署：用 Dockerfile 生成镜像、Docker Compose 一份文件起多个镜像与容器，以及容器的启动、停止、重启、删除；
- Nginx 反向代理服务器，连接不同服务器实现负载均衡；
- MySQL 数据库，ORM 框架提升开发效率——前端大课用 SQLAlchemy，本低代码大课用 TypeORM；
- Express / NestJS 开发后端接口，具备用 Node.js 技术栈写服务端的经验；
- Redis 缓存：自定义 key、发布订阅；
- RabbitMQ 死信队列实现订单延时关单（属前端大课内容，没学过可删减）。

### 运维、云服务与其他

- 结合 Docker 与 CI/CD 实现 DevOps：前端大课走 GitGo 类工具，本大课改用阿里云云效流水线；
- 阿里云服务器、域名、HTTP / HTTPS 配置，OSS 加速图片资源；
- 视频点播能力（华为云视频）、微信支付、OAuth 2.0 登录。

### 按自己的情况做删减

看完这份清单，逐项对照掌握程度做取舍：没学过 RabbitMQ、没接触过华为云视频点播，就大胆删掉；Redis 缓存学完本低代码大课已经足够写进简历；Tailwind CSS、TypeORM、云效 DevOps、Docker 部署这些是本课实打实做过的，可以放心保留。

简历不是越长越好，能被追问到底的条目才是有效条目。

## 小结

- 技术栈按类别分组写，比无序长列表更规整、更利于面试官快速定位。
- 编程语言 / 样式、框架与多端、开发工具、服务端、运维云服务是五个主要分类。
- 两门大课的技术要区分：前端大课偏 Vue / Nuxt / SQLAlchemy / GitGo，本大课偏 React / Next.js / TypeORM / 云效。
- 没学过第一门大课就如实删减 RabbitMQ、视频点播等条目，避免被追问露怯。
- 保留「真正动手做过」的技术，比堆砌名词更有说服力。
