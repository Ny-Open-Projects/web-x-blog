# 多环境快速安装 JMeter 5.x

> **导语**：性能压测的第一步是把工具跑起来。本文手把手演示在 Windows、macOS、Linux 三种系统下安装 JMeter 5.x 与 JDK 8 环境，并讲解目录结构与永久汉化的方法，让你在任何电脑上都能几分钟内启动 JMeter。

## 前置知识

阅读本文前，建议先了解压测的动机与 JMeter 的基本定位，可先看《Jmeter性能压测—基本介绍和使场景》。本文不依赖低代码项目代码，属于独立的环境准备篇。

## 正文

### 为什么必须用 JDK 8

JMeter 是纯 Java 编写的性能压测工具，运行前必须安装 JDK。课程统一要求 **JDK 8**（即 Java 1.8）。

这里有几个容易踩的坑：

- 不要安装最新的 JDK 11、JDK 21 等版本。尽管 JDK 11 在企业里也越来越常见，但 JMeter 在部分高版本 JDK 下可能出现兼容问题、无法启动。
- 绝大多数公司生产/测试环境仍以 JDK 8 为主，保持环境一致能避免"本地能跑、服务器跑不了"的尴尬。

安装完成后，打开终端输入：

```bash
java -version
```

若看到 `java version "1.8.0_xxx"` 类似输出，说明 JDK 8 已就绪。Windows 10、Windows 11、macOS、Linux（阿里云/腾讯云等服务器）各自的安装指引文档已在课程资料中给出，按系统对号入座即可。

### 下载并解压 JMeter 5.x

打开 JMeter 官网，点击 **Download Releases**，在 Binary（二进制）发行包中选择 **Apache JMeter 5.6.3**（zip 压缩包）。下载后解压即可使用，无需额外安装步骤。

如果你访问官网下载速度慢，课程资料里已上传打包好的安装包，包含：

- `apache-jmeter-5.6.3.zip`（Windows / macOS / Linux 通用，解压即用）
- JDK 8 安装包（分 macOS 版、Windows 版、Linux 版）

> 提示：JMeter 本身是跨平台的，同一个压缩包在三种系统下解压后都能运行，区别仅在启动文件不同。

### 解压后的核心目录

解压后会得到如下关键目录，其中我们日常打交道最多的是 `bin`：

- **bin/**：核心可执行目录，包含启动脚本与配置文件。
  - macOS / Linux 启动：双击执行 `jmeter`（无扩展名的可执行脚本）。
  - Windows 启动：双击 `jmeter.bat`。
  - 分布式压测主节点：启动 `jmeter-server`（Windows 下为 `jmeter-server.bat`）。这是后续做分布式压测时才用到的，本地单机压测暂时用不到。
  - `jmeter.properties`：系统级配置文件，语言、编码、各种默认行为都在这里改。
- **extras/**：插件与扩展包目录。
- **lib/**：核心依赖包目录，JMeter 运行所需的所有 jar 都在这里维护。

> Windows 用户注意：务必在资源管理器中开启"显示文件扩展名"。否则 `jmeter.bat` 和 `jmeter`（无扩展名）、`.conf`、`.sh` 等文件容易混淆，导致双击错文件。

### 启动 JMeter

- macOS：双击 `bin/jmeter` 脚本，系统会自动拉起一个终端窗口执行启动逻辑，随后 JMeter 主界面弹出。
- Windows：双击 `bin/jmeter.bat`。
- Linux（含云服务器）：执行 `bin/jmeter` 脚本（通常配合 `nohup` 或 X11 转发使用图形界面，服务器环境一般只用命令行模式 `jmeter -n`）。

### 永久汉化：改 jmeter.properties

首次启动默认是英文界面。临时切换语言的方式是：菜单栏 **Options → Choose Language → Chinese (Simplified)**。但这种方式**只生效一次**，关闭再启动又变回英文。

要永久汉化，需修改配置文件：

1. 打开 `bin/jmeter.properties`（用任意编辑器如 Sublime / VS Code 打开即可）。
2. 搜索 `language`，默认是：

```properties
language=en
```

3. 在其下方新增一行，指定简体中文：

```properties
language=zh_CN
```

4. 保存文件，彻底关闭 JMeter（连同它拉起的终端一起关掉），重新启动，`jmeter.bat` / `jmeter` 后界面即永久显示中文。

## 小结

- JMeter 依赖 JDK，课程统一使用 **JDK 8**，不要用过高的 JDK 版本以免兼容问题。
- 下载 `Apache JMeter 5.6.3` 的 zip 包，解压即用，跨平台通用。
- 启动入口：`jmeter`（macOS/Linux）、`jmeter.bat`（Windows）、`jmeter-server`（分布式）。
- 核心目录 `bin` 放脚本与配置，`lib` 放依赖，`extras` 放插件。
- 临时切语言在 Options 菜单，永久汉化改 `jmeter.properties` 里的 `language=zh_CN`。
