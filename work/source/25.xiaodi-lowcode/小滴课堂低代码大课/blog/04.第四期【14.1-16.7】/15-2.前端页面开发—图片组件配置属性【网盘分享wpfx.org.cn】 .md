# 前端页面开发—图片组件配置属性

> **导语**：低代码编辑器的每个组件都有「中间视图 + 右侧属性面板」两面。这一集补齐图片组件的右侧属性：名称、大小、填充方式、点击跳转方式、跳转地址与图片 URL。重点不在堆表单，而在复用二次封装的 Form 与 Form.Item、用 MobX store 驱动响应式更新，以及一个容易写错的导入 bug——函数被当成类型引入。

## 前置知识

- 已看完图片组件的展示视图，知道它渲染时读哪些 props，可回顾《前端页面开发—图片组件展示视图》。
- 做过视频组件的属性面板，熟悉「Form 二次封装 + Form.Item 二次封装」的套路，可参考《前端页面开发—视频组件配置属性》。
- 了解 React 的 useMemo、受控组件与 MobX store 的基本用法。

## 正文

### 图片组件要配哪些属性

选中画布里的图片，右侧面板大致有这些项：

- 图片名称、默认值（图片名称）、图片大小（默认 200）；
- 填充方式（覆盖等）；
- 图片点击后的跳转方式：有跳转链接 / 无；选中前者后，发布出去的页面里点图片就能跳转，地址在「跳转地址」里设置；
- 图片地址（URL）：决定图片显示成什么样。

一句话概括属性面板的职责：**把用户的配置写进组件的 props，中间视图读同一份 props 实时渲染**。

### 属性组件放在哪、怎么搭

注意一个目录约定：右侧的**属性组件放在前端 `client` 的 `components` 里**，不在 `share` 公共包。本集新建 `local-image` 文件夹。结构和视频组件那套完全一致：

- 最外层用 Form 的二次封装；
- 每个子项用 Form.Item 的二次封装 `formPropLabel`，传 `label` 和具体控件（输入框 / Select / 二选一），并传 `propName` 指定要改哪个属性。

```tsx
<FormPropLabel label="图片名称" propName="name">
  <Input />
</FormPropLabel>
```

父组件传进来的属性，会先用 `useMemo` 配合 `fillComponentPropsByConfig` 转换成 `{ defaultValue, value, isHidden }` 形式，再交给封装表单消费——这样每新增一个组件，属性面板几乎不用重写骨架。

跳转方式用 Ant Design 的 `Segmented`，`options` 是「跳转链接 / 无跳转链接」两个配置对象，对应 `propHandleClick`（图片是否可点击）。

### 填充方式：Select + object-fit

`fitOptions` 是一个 `{ value, label }` 数组，喂给 Ant Design 的 `Select`：

```ts
const fitOptions = [
  { value: 'contain', label: '包含' },
  { value: 'cover', label: '覆盖' },
  { value: 'fill', label: '填充' },
  { value: 'none', label: '无' },
  { value: 'scale-down', label: '缩小' },
];
```

选中不同值（比如从 `scale-down` 改成 `cover`），组件监听到变化 → `useMemo` 重新计算默认值 → 修改 store 里维护的 `options` → 重新渲染，图片的 `object-fit` 样式**同步更新**。图片大小改小，元素高度也跟着变小；名称随手改也即时生效。这就是「中间视图 + 右侧属性 + store」三者联动的响应式闭环。

### 两个容易踩的坑

**导入 bug：函数别当类型引**。`image hooks` 里之前有一条警告：`fillComponentPropsByConfig` 被当成类型用 `type` 引入，但它其实是要**执行的函数**，只有做类型校验时才用 `type`。改成普通导入后告警消失。这类问题在 TS 严格模式下很常见。

**写死的字符串要换掉**。`edit` 组件里，图片属性面板还没开发时，右侧被临时写死成 `'video'`；现在面板做好了，改用 `getComponentConfig.get(type)` 按组件类型取对应配置，点击图片时右侧才会展示真正的图片属性组件。

另外，图片地址与跳转地址支持自定义上传，但**资源上传接口还没开发**，本集先跳过这一块；等全部组件做完、图片/视频上传接口补齐，再回来联调（连同页面发布、页面组件获取两个接口一起）。最后别忘了在 `index.ts` 引入 `local-image`，并在属性组件的导出文件里多抛出一个出口。

### 工程依赖对照

前端工程用 `~/*` 指向 `src/*` 的路径别名，`tsconfig.json` 里开着 `strict`：

```json
{
  "compilerOptions": {
    "strict": true,
    "jsx": "react-jsx",
    "baseUrl": ".",
    "paths": { "~/*": ["src/*"] }
  }
}
```

依赖上可对照 `代码（已8期）/15-2/lowcode/packages/client/package.json`：`antd`、`ahooks`、`mobx` / `mobx-react-lite`、`axios`、`classnames`、`tailwindcss` 等，正是「Ant Design 表单 + MobX 状态 + 样式工具」这套组合。

## 小结

- 图片属性面板配置项：名称、大小、填充方式、跳转方式、跳转地址、图片 URL。
- 属性组件放 `client/components` 而非 `share`，复用 Form 与 `formPropLabel` 两层二次封装。
- `fitOptions` 经 `Select` 选择后写入 store，`useMemo` 重算并驱动 `object-fit` 响应式更新。
- `fillComponentPropsByConfig` 是函数不是类型，别用 `type` 导入；写死的 `'video'` 要换成按类型取配置。
- 上传相关功能留到资源上传接口完成后再联调；记得补 `index.ts` 引入与导出。
