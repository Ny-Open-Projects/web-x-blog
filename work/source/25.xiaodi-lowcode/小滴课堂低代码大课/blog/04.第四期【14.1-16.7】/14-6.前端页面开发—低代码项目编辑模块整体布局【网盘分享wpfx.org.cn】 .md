# 前端页面开发—低代码项目编辑模块整体布局

> **导语**：低代码编辑页的发布接口、页面组件获取接口都已就绪，本节开始把编辑器的前端骨架搭起来。核心是「上下 + 左中右」的整体布局：头部放标题、预览/草稿/发布与数据统计入口，下半部分左侧组件列表、中间画布、右侧属性面板。本文还会讲清页面专属组件该放哪个目录、Ant Design `Tabs` 怎么组织左右面板，以及 Flex/Tailwind CSS 在其中的作用。

## 前置知识

需要先有编辑页的路由与登录判断，建议看过《低代码项目前端项目开发—路由配置》；左右面板联动会用到公共状态，见《低代码项目前端项目开发—公共状态管理+自定义 hooks》。数据从哪来回哪去，可对照《后端接口开发—低代码项目编辑模块页面组件获取接口》与《低代码项目平台编辑模块后端接口梳理》。

## 正文

### 先把数据链路想清楚

编辑页背后有两个已完成的接口：发布接口把组件的配置、属性、样式写进数据库；页面组件获取接口则在用户再次进入时把这些组件拉回来渲染。所以「用户发布过页面」是有数据的前提，没发布过就是初始为空的白板。

此外还有三个资源类接口——图片/视频上传到阿里云 OSS、资源删除、资源获取——前面已整理好，等布局与主体逻辑完成后再接。先把页面骨架立起来，再往里填接口，顺序才不会乱。

### 整体布局：上下 + 左中右

页面是上下结构，下半部分再分左、中、右三栏：

- **头部（Header）**：左侧是可修改的页面标题；中间是预览、存草稿、发布三个操作；右侧是后台数据统计的跳转入口和用户头像。
- **左侧**：组件列表，点击某个组件就在中间画布里渲染出来。
- **中间**：画布/编辑区，展示组件、支持排序；选中某个组件时，右侧同步显示它可配置的属性。
- **右侧**：属性配置区，分「组件属性」和「全局属性」两个 Tab。

这个分区就是低代码编辑器的标准骨架，后续所有组件展示、拖拽、工具栏、键盘操作都是在这个框架里长出来的。

### 目录组织：页面专属组件放 `pages/editor`

入口是已经创建好的 `Editor` 路由页面，`Index` 负责判断登录状态，未登录跳转到 login / register。布局相关组件抽离成 `EditHeader`、`EditLeftPanel`、`EditRightPanel`，统一放在 `pages/editor/` 目录下，而不是 `components/`。

判断标准很简单：**只在这个页面用、不复用，就放在页面目录下；需要跨页面公共复用，才放到 `components/`**。一开始就按这个原则分目录，后面组件越加越多也不会到处乱放。

### 用 Flex 与 Tailwind CSS 写布局

样式以 Flex 为主，这也是前端多元素上下/左右排版最核心的手段：

- 最外层用 `flex flex-col`（Tailwind CSS 里 `flex-col` 表示纵向排列）做上下结构，高度占满 100%；
- 下半部分主体用一个 `flex` 默认横向排列，自然形成左中右三栏；
- 头部只设阴影、内边距与白色背景；
- 中间画布设 `overflow-y: auto`（Y 轴可上下滚动）、横向隐藏，保证组件多时能滚、但不能左右拖动。

这一节的样式代码较多，课程里提前写好、只讲结构；逻辑复杂的地方再逐行讲解。这种「样式先行、逻辑重点讲」的节奏，能避免每个视频都耗在重复的 CSS 上。

### 左右面板用 Ant Design `Tabs`

左侧 `EditLeftPanel` 返回 Ant Design 的 `Tabs` 组件，用 `items` 数组决定有几个页签，数组里每个对象含 `key`、`label`、`icon`（图标从 `@ant-design/icons` 引入）。当前只有一个页签，比如 `key: 'component-list'`，`defaultActiveKey` 设置默认选中项；后面组件分类多了，往 `items` 里加对象即可，内部组件列表先用一个占位符顶着，后续换成公共维护的子组件。

右侧 `EditRightPanel` 结构类似，也是 `Tabs`，但有两个页签：一个放组件属性配置，一个放全局属性（`key` 如 `page-fields`），各自配 `label` 和图标。`items` 用对象数组定义，并补上 Ant Design 提供的 TS 类型声明做类型校验；不加也能跑，但加上后字段写错会更早暴露。两个页签的内容同样先占位，等属性配置组件开发完再替换。

顺带一个细节：浏览器标签页图标可以在 `index.html` 里改 `<link>` 的 `href`，把自定义 svg 放进 `assets` 目录替换掉默认的 `public/vite.svg`；缓存没刷新时看到的可能还是旧图标，清一下缓存即可。

## 小结

- 编辑页依赖发布接口与页面组件获取接口；发布过才有数据渲染，否则是白板。
- 布局为「头部 + 左中右」：头部含标题、预览/草稿/发布、统计入口、头像；左侧组件列表、中间画布、右侧属性面板。
- 页面专属组件放 `pages/editor/`，公共复用组件才放 `components/`。
- 布局靠 Flex：`flex flex-col` 做上下，`flex` 做左右；画布 `overflow-y: auto` 且横向隐藏。
- 左右面板用 Ant Design `Tabs` + `items` 数组组织，图标取自 `@ant-design/icons`。
