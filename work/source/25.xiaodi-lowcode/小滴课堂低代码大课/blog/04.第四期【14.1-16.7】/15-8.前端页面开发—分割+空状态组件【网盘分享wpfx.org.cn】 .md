# 前端页面开发—分割+空状态组件

> **导语**：这一集是两个「小而典型」的组件：分割线 Divider 和空状态 Empty。它们体量不大，却把低代码组件的开发范式演示得很完整——share 里放展示视图、client 里放属性面板、Ant Design 组件二次封装、属性变化经 store 同步回视图。文中还会顺带交代后面一长串组件与联调的推进顺序。

## 正文

### 分割组件：一条线，三个属性

分割组件放在 share 包的 `src/components/local-sprite`。它本质上是一条横线加一点上下间距，对外暴露三个自定义属性：

- `text`：分割线上的文本，为空就只显示一条线；
- `dash`：是否虚线；
- `orientation`：文本位置，左 / 中 / 右。

底层用 Ant Design 的 `Divider`。渲染逻辑有个关键点：**传给 Divider 的 props 必须剔除 `text`**，因为 Divider 本身不接收这个属性，硬传会报错。项目里用自定义的 `objectOmit` 从对象里删掉某个属性来解决：

```tsx
const dividerProps = objectOmit(props, ['text']);

return props.text ? (
  <Divider {...dividerProps} orientation={props.orientation}>
    <span>{props.text}</span>
  </Divider>
) : (
  <Divider {...dividerProps} />
);
```

文本用自定义的 `<span>` 承载，`orientation` 决定它靠左、居中还是靠右。这也是二次封装第三方组件的常见套路：**自定义属性自己消化，不属于原组件的属性先剔除再透传**。

### 分割的属性面板

属性面板在 client 的 `components/local-components` 里（`LocalSpriteComponent`），依旧是「Form 二次封装 + Form.Item 二次封装」：

- 输入文字 → 改 `text`；
- 是否虚线 → 改 `dash`，同步更新 store，视图立刻变成虚线；
- 文字位置 → 用 Ant Design 的 `Segmented`，`options` 为 `left` / `center` / `right`（label 向左 / 居中 / 向右）。

选中「居中」后 value 变为 `center`，store 里的 `orientation` 更新，组件监听到变化重新渲染，Divider 的 `orientation` 随之改变，文本就挪到中间。整条链路和前面几个组件完全一致，**属性改 store、store 驱动重渲染**。

### 空状态组件：Empty 加一层可配置

空状态组件在 share 包的 `local-empty`，用 Ant Design 的 `Empty`：

- `description` 设置描述文本；
- 可指定图片，没给就用 `Empty` 自带的默认空状态图；
- 图片样式可配：宽、高、填充方式（`object-fit`）。

```tsx
<Empty
  description={props.description}
  image={props.image || undefined}   // 不传时用 Empty 自带默认空状态图
  imageStyle={{ width: props.width, height: props.height, objectFit: props.objectFit }}
/>
```

写完记得**导出组件并重新打包 share**，否则 client 里引不到新组件。

client 侧的属性面板同样用两层表单封装：图片先用普通 `Input` 占位（资源上传接口还没做），描述项传 `name="description"`、`label`、`propName`，宽高用 `type="number"` 的 Input——改宽度图片同步变大、改高度同步升高，完全响应式。填充方式用 `Select` 配好选项即可。后续资源上传接口完成后，图片就可以换成本地上传或在线图片。

### 这一阶段的整体路线图

讲师在结尾把后续顺序交代得很清楚，值得记一下，避免「只见树木」：

1. 先补齐富文本、二维码、警告信息三类组件——加上已完成的这些，用户就能用平台发布一个官网式页面；
2. 再做问卷系统的四个输入类组件，支撑问卷类页面；
3. 之后开发图片/视频资源的上传、删除接口并联调，打通页面发布、缓存回显、组件拖拽排序、上下键排序、删除/撤销/前进、预览、草稿；
4. 最后才轮到发布后的页面与后台数据统计。

所以这几集的共同主题其实只有一个：**让「点击左侧组件列表 → 中间视图 → 右侧属性面板」三者选中态与数据同步、并做到响应式**。工程依赖可对照 `代码（已8期）/15-8/lowcode/packages/client/package.json`（`antd`、`ahooks`、`mobx`、`mobx-react-lite`、`tailwindcss` 等）与 `tsconfig.json` 的 `~/*` 路径别名。

## 小结

- 分割组件用 Ant Design `Divider`，自定义 `text` / `dash` / `orientation` 三个属性。
- 透传前要用 `objectOmit` 剔除 Divider 不接收的 `text`，文本用自定义 `span` 承载。
- 属性面板用 `Segmented` 配 left/center/right，改动经 store 同步回视图。
- 空状态用 `Empty`，可配 description、图片与宽高/填充；写完要导出并重新打包 share。
- 后续按「剩余组件 → 资源上传删除接口 → 联调 → 排序/预览/草稿 → 发布页与数据统计」推进。
