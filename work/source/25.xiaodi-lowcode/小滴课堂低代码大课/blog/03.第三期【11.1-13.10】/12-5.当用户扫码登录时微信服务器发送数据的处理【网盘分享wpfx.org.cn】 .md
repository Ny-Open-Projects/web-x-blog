# 当用户扫码登录时微信服务器发送数据的处理

> **导语**：本文实现时序图的「用户扫码 → 微信回调 → 查/建用户 → 签发 token → 更新 Redis」环节。重点讲解如何把微信回调的 XML 数据解析为普通对象、按 `openId` 判断注册、生成 token，并把 Redis 中 ticket 的 `isScan` 置为 true，同时给微信服务器返回对话回复。

## 前置知识

- 已完成《微信登录场景二维码方式接口开发—获取二维码配置封装》，Redis 中已有 `wechat:ticket:xxx => { isScan: false }`。
- 了解 `user` 表含 `openId` 字段（微信唯一标识）。
- 已配置 JWT 签发（`jwtService.sign`）。

## 正文

### 新增微信回调接口（POST）

在 `wechat-login.controller.ts` 中新增 POST 接口接收微信推送：

```ts
@Post('message')
async wechatMessage(@Body() body) {
  return this.wechatLoginService.wechatMessage(body);
}
```

注意：接入验证是 GET，回调推送是 POST，路径不同。

### 解析微信 XML 数据为对象

微信推送的是 XML，需借助 `xml2js` 插件转成对象。封装 `WechatDataTo` 工具类，提供：

- `getObject(data)`：课程中转版本，直接把已处理的数据转对象（返回 Promise）。
- 正式环境用 `getChannelStr(data)`：通过流 `data`/`end` 事件接收原始 XML 再转换。
- `getLastData(obj)`：把多层数组/对象拍平为一维普通对象，方便取值。

转换后形如：

```ts
{
  xml: { ticket, CreateTime, EventKey, Event, ToUserName, FromUserName, MsgType }
}
```

其中 **`FromUserName` 即 openId**，`ticket` 是本次扫码会话的标识。

### 按 openId 查/建用户并生成 token

从 `lastData.FromUserName` 取出 `openId`，用全局 `UserModule`（在 `app.module.ts` 以 `global: true` 注册）查用户：

```ts
const openId = lastData.FromUserName;
const exist = await this.userRepository.findOne({ where: { openId } });
let userId: number;
if (exist) {
  userId = exist.id;
} else {
  const data = await this.userRepository.save({
    headImage: randomAvatar,
    name: randomName,
    openId,
    phone: '',
    password: ''
  });
  userId = data.id;
}
const token = this.jwtService.sign(String(userId));
```

首次扫码用户没有手机号与密码，这两个字段留空，仅以微信身份登录。

### 更新 Redis 的 isScan 状态

把该 ticket 对应的 `isScan` 改为 `true`，并把 token 一并存入：

```ts
const redisKey = `wechat:ticket:${lastData.Ticket}`;
const existKey = await this.redis.exists(redisKey);
if (existKey) {
  await this.redis.set(
    redisKey,
    JSON.stringify({ isScan: true, token }),
    'EX',
    120
  );
}
```

> Redis 存对象必须 `JSON.stringify`，否则会报错。

### 回复微信服务器

根据 `Event` 判断是首次关注（`subscribe`）还是再次扫码（`SCAN`），返回对应的 XML/文本回复（如「感谢关注，讲师微信是 xxx」或「欢迎回来，讲师微信是 xxx」），微信会在公众号对话框中展示。

## 小结

- 回调接口为 POST，微信推送数据为 XML，用 `xml2js` 解析后拍平为普通对象。
- `FromUserName` 就是 openId；按它查用户，没有则插入一条（phone/password 为空）。
- 无论新老用户都签发 JWT；随后把 Redis 中 `wechat:ticket:xxx` 的 `isScan` 改为 `true` 并写入 token。
- 需按 `Event` 给微信服务器返回不同的关注/欢迎回复。
