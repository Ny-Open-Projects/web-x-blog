# 低代码项目前端项目开发—登录模块接口联调

> **导语**：本文为登录模块补齐后端接口定义并接入前端：新增「账号密码登录」与「手机验证码登录」两个接口，用 `useRequest` 在登录子组件中发起请求，成功后写入登录态并跳转。

## 正文

### 定义登录接口与参数类型

在 `src/api/user.ts` 中新增：

```ts
export async function getLoginWithPassword(data: ILoginWithPasswordRequest) {
  return makeRequest('/user/password', { method: 'POST', data });
}
export async function getLoginWithForm(data: ILoginWithFormRequest) {
  return makeRequest('/user/form', { method: 'POST', data });
}
```

在 `share` 的类型文件中用 `Pick<IUser, ...>` 派生：

```ts
export type ILoginWithPasswordRequest = Pick<IUser, 'phone' | 'password'>;
export type ILoginWithFormRequest = Pick<IUser, 'phone'> & {
  sendCode: string;
};
```

`password` 登录需要 `phone`+`password`；`form` 登录需要 `phone`+`sendCode`，无需密码。定义完成后 `pnpm build share` 重新打包。

### 账号密码登录联调

在 `Account.tsx` 中用 `useRequest`：

```tsx
const { run: execLogin, loading } = useRequest(
  (values) => getLoginWithPassword(values),
  {
    ready: true,
    onSuccess: (res) => login(res.data.token),
  }
);
```

- `ready: true`：默认不执行，点击「登录」才触发。
- 成功后调用 `useStoreAuthor` 的 `login(token)` 写入状态与 localStorage。
- 按钮用 `loading` 属性显示加载态。

### 手机验证码登录联调

在 `Captcha.tsx` 中同理调用 `getLoginWithForm`：

```tsx
const { run: execLogin, loading } = useRequest(
  (values) => getLoginWithForm(values),
  {
    ready: true,
    onSuccess: (res) => login(res.data.token),
  }
);
```

注意获取短信验证码时 `type` 必须为 `login`，否则 Redis key 不匹配。

### 接口联调验证

启动服务后：

1. 账号密码登录：用注册过的账号（如密码 `321`）登录，成功拿到 token。
2. 手机验证码登录：图形验证码填如 `UXAD`，点获取验证码（Redis 中查到如 `1086`），填入后登录，同样成功。

两种方式的 token 都会写入 localStorage 并完成前端登录态切换。

## 小结

- 新增 `/user/password`（phone+password）与 `/user/form`（phone+sendCode）两接口。
- 参数类型用 `Pick<IUser,...>` 派生，账号密码登录无 sendCode，验证码登录无 password。
- 两个子组件均用 `useRequest` + `ready: true` 手动触发，成功后调用 `login(token)`。
- 联调前确保后端已启动、短信验证码 type 为 `login`。
