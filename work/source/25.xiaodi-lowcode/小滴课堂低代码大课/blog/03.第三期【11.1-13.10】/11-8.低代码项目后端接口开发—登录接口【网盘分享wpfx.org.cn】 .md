# 低代码项目后端接口开发—登录接口

> **导语**：本文在注册接口的基础上，为低代码平台实现**账号密码登录**与**手机验证码登录**两种方式。重点讲解如何复用手机号查重、密码加密比对、Redis 验证码校验与 JWT 签发，以及两种登录方式的差异处理。

## 前置知识

- 已完成《低代码项目后端接口开发—注册接口》，理解 JWT 的 `secret` 与 7 天过期配置。
- 掌握 Redis 中验证码的三层 key：`request:code:phone`（注册）与 `login:code:phone`（登录）。
- 熟悉 NestJS 服务层 `Repository.findOne` 查询与 `BadRequestException` 异常抛出。

## 正文

### 两种登录方式的控制器

在 `user.controller.ts` 中新增两个 POST 接口：账号密码登录路径 `password`，手机验证码登录路径 `form`：

```ts
@Post('password')
async passwordLogin(@Body() body: PasswordLoginDto) {
  return this.userService.passwordLogin(body);
}

@Post('form')
async formLogin(@Body() body: FormLoginDto) {
  return this.userService.formLogin(body);
}
```

对应的 DTO：`PasswordLoginDto` 含 `phone`、`password`；`FormLoginDto` 含 `phone`、`sendCode`。

### 账号密码登录服务

`passwordLogin` 逻辑：

1. **查用户是否注册**：`findOne({ where: { phone } })`，查不到则抛「登录的账号不存在」。
2. **校验密码**：数据库密码是加密后的，需把前端传入的密码同样加密后比对：

```ts
const isPassword = SecretUtil.getSecret(password) === user.password;
if (!isPassword) {
  throw new BadRequestException('密码不正确');
}
```

3. **签发 token**：复用 `jwtService.sign(String(user.id), { expiresIn: '7d' })`，返回 `data` 为 token，提示「登录成功」。

### 手机验证码登录服务

`formLogin` 与账号密码登录**共用「查用户是否注册」这一段**，区别在于第二步不再是校验密码，而是校验 Redis 中的短信验证码：

```ts
const codeExist = await this.redis.exists(`login:code:${phone}`);
if (!codeExist) {
  throw new BadRequestException('请先获取手机验证码');
}
const codeStr = await this.redis.get(`login:code:${phone}`);
const code = codeStr.split('_')[1];
if (code !== sendCode) {
  throw new BadRequestException('验证码不正确');
}
```

> 注意：获取短信验证码时，类型参数必须传 `login`（而不是 `request`），否则 Redis key 不匹配，永远取不到验证码。

校验通过后同样签发 7 天 JWT 返回。

### 接口联调

- 账号密码登录：POST `/user/password`，传 `phone` + `password`（如注册时的 `321`），成功返回 token。
- 手机验证码登录：先请求 `login` 类型的图形验证码与短信验证码，手机收到如 `7918`，再 POST `/user/form` 传 `phone` + `sendCode`，返回 token。

## 小结

- 登录提供两种方式：账号密码（`/user/password`）与手机验证码（`/user/form`）。
- 两种方式的「查用户是否注册」逻辑完全一致，可复用。
- 密码登录比对的是「加密后」的密码；验证码登录比对的是 Redis 中 `login:code:phone` 存储的验证码。
- 都通过 `jwtService.sign` 签发 7 天 token，与注册接口共用 JWT 配置。
