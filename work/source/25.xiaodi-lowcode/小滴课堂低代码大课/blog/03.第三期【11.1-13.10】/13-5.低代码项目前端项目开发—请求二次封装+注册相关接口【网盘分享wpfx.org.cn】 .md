# 低代码项目前端项目开发—请求二次封装+注册相关接口

> **导语**：本文做两件事：用 axios **二次封装**请求（统一 baseURL、请求/响应拦截器），并定义注册相关的三个接口（图形验证码、短信验证码、注册），同时把接口参数类型收敛到公共 `share` 项目，便于前后端复用。

## 前置知识

- 已阅读《低代码项目前端项目开发—注册组件开发《上》》，注册表单已就绪。
- 已安装 `axios`，并了解请求拦截器/响应拦截器概念。
- 了解 TypeScript 的 `Pick`、`interface` 与 `type` 的区别。

## 正文

### axios 二次封装

在 `src/utils/request.ts` 中：

```ts
import axios, { AxiosRequestConfig } from 'axios';

export const baseURL = 'http://127.0.0.1:3000';
export const api = '/api';

const request = axios.create({ baseURL: baseURL + api });
```

**请求拦截器**：自动给 headers 注入 token（从公共状态 `useStoreAuthor` 读取）：

```ts
request.interceptors.request.use(config => {
  const { token } = useStoreAuthor();
  if (token) {
    config.headers.authorization = token;
  }
  return config;
});
```

**响应拦截器**：取出 `response.data`，当 `code === 0 && msg !== undefined` 时做统一提示处理。

最后导出异步方法 `makeRequest`：

```ts
export async function makeRequest(url: string, options?: AxiosRequestConfig) {
  const res = await request({ url, ...options });
  return res.data;
}
```

### 定义注册相关接口

在 `src/api/user.ts` 中定义三个接口：

```ts
export async function getCaptcha(data: IGetCaptchaRequest) {
  return makeRequest('/user/captcha', { method: 'POST', data });
}
export async function sendCode(data: ISendCodeRequest) {
  return makeRequest('/user/sendCode', { method: 'POST', data });
}
export async function getRegister(data: IRegisterRequest) {
  return makeRequest('/user/register', { method: 'POST', data });
}
```

### 收敛接口参数类型到 share 项目

在公共 `share` 项目的 `src/types/request/user.ts` 中定义类型，复用数据库实体 `IUser`：

```ts
import { PickType } from '@nestjs/mapped-types';
// 或前端用 TS 内置 Pick
export type IRegisterRequest = Pick<IUser, 'phone' | 'password'> & {
  sendCode: string;
  confirm: string;
};
export type ISendCodeRequest = Pick<IUser, 'phone'> & {
  captcha: string;
  type: 'register' | 'login';
};
export interface ICaptcha {
  type: 'register' | 'login';
}
```

`IUser` 字段含 `id`、`phone`、`openId`、`headImage`、`name`、`password`。用 `Pick` 从实体派生参数类型，避免重复声明。

> 约定：用 `interface` 定义可扩展的实体（如 `IUser`），用 `type` 定义固定派生类型（如参数类型）。

定义完成后在根目录 `pnpm build share` 重新打包，前端即可从 `@lowcode/share` 引入。

### 后端开启 CORS

联调前需在 NestJS 入口开启跨域：

```ts
app.enableCors();
```

## 小结

- axios 二次封装：统一 `baseURL`（含 `/api`）、请求拦截器注入 token、响应拦截器统一处理。
- 注册相关三接口：图形验证码 `/user/captcha`、短信验证码 `/user/sendCode`、注册 `/user/register`，均为 POST。
- 接口参数类型收敛到 `share`，用 `Pick<IUser, ...>` 复用数据库实体字段，减少重复。
- 前端联调前后端需 `app.enableCors()` 开启跨域。
