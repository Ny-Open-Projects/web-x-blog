# 低代码项目前端项目开发—注册组件开发《上》

> **导语**：本文开始开发登录注册页与**注册组件**的静态结构。我们把页面拆分为父组件（控制登录/注册切换）与子组件（注册表单、图形/短信验证码等），并用 Ant Design 的 Form 完成手机号、密码、确认密码与协议勾选的校验。

## 前置知识

- 已阅读《低代码项目前端项目开发—公共状态管理+自定义 hooks》，了解 `useStoreAuthor` 与登录态。
- 已安装 `antd`（Ant Design）、`ahooks`（含 `useTitle`）。
- 了解 Ant Design Form 的基本用法（`Form`、`Form.Item`、`useForm`）。

## 正文

### 父组件：登录/注册切换

`pages/LoginOrRegister.tsx` 用 `useState` 维护 `loginOrRegister`（初始 `true` 显示注册）。点击「去登录」按钮触发方法将其取反：

```tsx
const [loginOrRegister, setLoginOrRegister] = useState(true);

// 切换方法
const changeState = () => setLoginOrRegister(v => !v);
```

根据 `loginOrRegister` 决定渲染 `<Register />` 还是 `<Login />` 子组件，并把 `changeState` 传给它们用于切换。

### 页面背景与标题

外层 div 用 TailwindCSS 设置 `h-full` 与背景图（取自 `public/bg.jpg`）：

```tsx
<div className="h-full bg-[url('/bg.jpg')] ...">
  {loginOrRegister ? <Register onChange={changeState} /> : <Login onChange={changeState} />}
</div>
```

### 注册子组件结构

`components/register/Register.tsx` 中用 `useTitle` 设置页签标题为「小滴课堂低代码平台-注册」：

```tsx
useTitle('小滴课堂低代码平台-注册');
```

内部把输入框抽离为 `<RegisterOption />` 子组件，避免父组件臃肿；图形验证码、短信验证码也单独抽成组件。

### 用 Ant Design Form 做校验

`components/register/RegisterOption.tsx` 以 `Form` 包裹，使用 `Form.useForm()` 操作表单数据域。包含 5 项：

1. 手机号：`name="phone"`，`rules` 必填，提示「请输入手机号码」。
2. 密码：`name="password"`，必填，提示「请输入密码」。
3. 确认密码：`name="confirm"`，必填，提示「请确认密码」。
4. 协议勾选：`Checkbox` 配合 `Form.Item` 的 `valuePropName="checked"`、`name="remember"`，rules 校验是否勾选，提示「请先同意协议」。
5. 注册按钮：`htmlType="submit"`，触发 Form 的 `onFinish`。

```tsx
<Form onFinish={onFinish} initialValues={{ remember: true }}>
  <Form.Item name="phone" rules={[{ required: true, message: '请输入手机号码' }]}>
    <Input />
  </Form.Item>
  <Form.Item name="remember" valuePropName="checked" rules={[{ validator: (_, v) => v ? Promise.resolve() : Promise.reject('请先同意协议') }]}>
    <Checkbox>同意小滴课堂隐私策略</Checkbox>
  </Form.Item>
  <Button htmlType="submit">注册</Button>
</Form>
```

`remember: true` 表示复选框默认选中。点击注册未填内容时，会自动提示各项错误信息。

## 小结

- 登录注册页拆分为父组件（控制 `loginOrRegister` 切换）与注册/登录子组件。
- 注册表单用 Ant Design `Form` + `Form.Item` + `useForm` 实现校验。
- 共 5 项：手机号、密码、确认密码、协议勾选、注册按钮；协议项用 `valuePropName="checked"`。
- 标题用 `ahooks` 的 `useTitle` 设置；背景图用 TailwindCSS 的 `bg-[url(...)]`。
