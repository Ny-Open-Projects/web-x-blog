# 第三方短信验证码平台接入申请操作指引

> **导语**：短信验证码接口开发之前，得先把第三方短信服务选好、开通好。这一集不写代码，而是把完整业务链路画清楚——后端生成随机验证码、调服务商 API 发到用户手机、把同一份验证码存进 Redis、前端回传后比对；再给出平台选型的几个维度、官方与第三方厂商的区别，以及课程提供的免费测试套餐怎么开通。

## 正文

### 先理清整条业务链路

讲师用一张图把短信验证码从生成到校验走了一遍，拆成五步：

1. **后端生成验证码**：用户点「获取验证码」，Node 后端随机生成一个 4 位数字（例如 `1234`）；
2. **调用第三方 API**：把验证码和手机号一起传给短信服务商的接口；
3. **服务商投递**：服务商与运营商（中国移动 / 中国联通 / 中国电信）对接，把短信发到用户手机，用户收到 `1234`；
4. **前端回传**：用户在页面输入 `1234`，前端调后端接口把这个值传回来；
5. **比对通过**：后端把回传值与**先前存在 Redis 里的那份**比对，一致即验证通过，可继续注册或登录（本项目支持手机验证码登录）。

最关键的设计是第 2 步的「一分为二」：同一份随机验证码，一方面发给服务商，另一方面写进 Redis。没有 Redis 这份副本，后端就无从判断用户填的对不对。理解了这个闭环，后面写装饰器封装时就不会漏掉缓存那一步。

### 选型要看哪几个维度

买服务前别只看价格，讲师列了五个考量点：

- **价格 / 套餐**：不同短信类型、不同服务商的套餐单价差异不小；
- **到达率与到达时间**：从「后端生成 → 调 API → 用户收到」这条链路耗时是否合理，直接影响体验；
- **短信内容是否灵活可配**：能否自定义编辑文案、插入变量，以支撑登录、注册等多场景（例如「XX 科技有限公司的登录/注册验证码」）；
- **是否支持多种推广内容**：业务推广、新品宣讲、会员关怀等，比如店铺给老用户发生日/节日礼品通知；
- **多维度数据统计**：后台能看发送量、成功与失败、发送记录、日志分析与费用统计，便于排查和控成本。

### 官方服务与第三方厂商怎么选

平台上大致有两条路：

| 路线 | 特点 | 适合谁 |
| --- | --- | --- |
| 云厂商官方短信服务（阿里云、腾讯云） | 需自己按「申请签名 → 申请模板 → 系统设置 → 发送短信」四步走完，还要提交营业执照等资料 | 有企业资质、要长期正式上线 |
| 云市场里的第三方厂商 | 像在平台开店，签名/模板由厂商代申请并处理好；购买后按客服要求提交资料即可用；常有免费试用次数和按次套餐 | 学习、练习、快速接入 |

课程里推荐的是第二种：省去自己申请签名和模板的门槛，套餐也很便宜（例如几十元上千次，足够课程里反复测试，远不止免费试用的几次）。官方服务则更适合正式生产环境，腾讯云本集不展开。

正式对接第三方时，接口侧要关心的参数一般是：目标手机号（`mobile`）、模板 id（`templateId`，固定值）、以及随机验证码变量（`value`）；服务商还会提供发送状态查询和请求示例，用来确认短信是否真的送达。

### 课程提供的免费套餐与开发者配置

如果不想自己申请资质购买，课程准备了一套可直接练习的免费短信套餐：

- 在官网「个人中心 → 开发设置 → 基本配置」里查看开发者配置，拿到 `APP ID` 与 `APP Secret`（开发者密钥）；
- 若「发送短信权限」显示未启用，联系客服/讲师开通即可免费使用；
- `APP Secret` 会定时更新，隔一段时间再调验证码服务时，要重新重置并复制进代码，否则会鉴权失败；
- 调用课程封装后的接口，需要传的参数是：`APP ID`、`APP Secret`、`code`（随机验证码）、接收手机号，以及固定值 `templateCode`。

学过大课一、已经开通过这套服务的同学，这一块可以快速跳过，直接进入代码开发部分。

### 和后续开发的关系

本集把「服务从哪来、参数有哪些、验证码怎么闭环」讲清楚，下一集才动手写封装——把发短信这件事做成可复用的装饰器，让业务接口里只关心「给哪个手机号发」。所以这里记住三件事就够：**随机码要生成一份、发一份、存 Redis 一份；比对以 Redis 为准；密钥会过期要重置**。

## 小结

- 完整链路：生成随机码 → 调服务商 API → 用户收到 → 前端回传 → 与 Redis 副本比对。
- 验证码必须「一分为二」：既发给服务商，也存 Redis，否则无法校验。
- 选型看价格、到达率/到达时间、内容可配性、推广场景支持、数据统计五个维度。
- 官方服务要自申请签名/模板/资质；第三方厂商代处理好，更适合学习与快速接入。
- 课程免费套餐在个人中心的开发者配置里，`APP Secret` 会定时更新，需重置后重新复制。
