# 微信登录场景二维码方式接口开发—微信服务器接入验证

> **导语**：本文实现时序图的第二步「接入验证」。我们将新建 `wechat-login` 模块，开发微信服务器回调的 GET 接口，通过内网穿透（花生壳）让外网可访问本地服务，并按微信官方规则用 SHA1 校验签名，完成接入。

## 前置知识

- 已阅读《宏观梳理微信登录场景二维码业务逻辑-系统时序图》，明确「接入验证」在整体流程中的位置。
- 已在微信公众平台/课程官网拿到回调配置所需的 `token`（自定义密文）、`appId`、`appSecret`。
- 了解 NestJS 模块的创建（`nest g resource`）与 GET 请求处理。

## 正文

### 新建 wechat-login 模块

使用命令创建 RESTful 模块并清理多余的测试文件、entity、detail：

```bash
nest g resource wechat-login
```

在 `wechat-login.controller.ts` 中把接入验证接口定义为 GET，路径统一为 `/wechat_login/callback`：

```ts
@Get('callback')
async insert(@Query() query: CallbackInsertRequest) {
  return this.wechatLoginService.insert(query);
}
```

### 内网穿透让微信能访问本地

微信服务器需要能回调到我们的本地接口。用「花生壳」做内网穿透：

1. 下载花生壳客户端，扫码/注册登录。
2. 新增映射：外网类型选 HTTPS，内网主机 `127.0.0.1`，内网端口 `3000`（本地 NestJS 端口）。
3. 保存后获得一个外网域名，拼接 `/api/wechat_login/callback` 即可被外网访问。

课程实操时，可在小滴课堂官网「个人中心 → 开发者配置」中填写回调地址与自定义 `token` 完成接入。

### 微信回调参数的类型校验

微信接入验证会发送 4 个字符串参数（`signature`、`timestamp`、`nonce`、`echostr`）。在公共 `share` 项目的 `types/request/wechat-login.ts` 中定义接口：

```ts
export interface CallbackInsertRequest {
  signature: string;
  timestamp: string;
  nonce: string;
  echostr: string;
}
```

并在 `share/src/types/index.ts` 中统一 `export *` 导出，再通过 `pnpm build share` 重新打包，前端/后端即可引入使用。控制器用 `@Query()` 配合该类型做校验。

### 签名校验逻辑

微信官方要求：把 `token`、`timestamp`、`nonce` 三个参数**字典序排序**后拼接成字符串，再做 **SHA1** 加密，结果与传入的 `signature` 比对；一致则说明请求来自微信，最后把 `echostr` 原样返回即可完成接入。

```ts
import * as crypto from 'crypto';

const arr = [token, timestamp, nonce].sort();
const str = arr.join('');
const sha = crypto.createHash('sha1').update(str).digest('hex');
if (sha === signature) {
  return echostr; // 返回随机字符串即接入成功
}
```

### 微信登录配置与工具模块

在 `config.ts` 中新增 `wechatLoginConfig`：

```ts
export const wechatLoginConfig = {
  appId: '...',
  appSecret: '...',
  qrUrl: 'https://...', // 官方生成二维码前缀地址
  token: 'test_xdclass'
};
```

并新建 `wechat-login-two.module.ts` 动态模块（`forRoot(config)`），把配置注入为可全局访问的 `token` 等属性，供后续获取 access_token、ticket 复用。

### 处理统一返回格式的兼容

本项目的响应拦截器会在数据外层包一层 `data`。微信要求接入验证直接返回 `echostr` 字符串，因此拦截器中需加判断：当 `msg === '微信验证回调'` 时直接 `return data.data`，避免多层包裹导致微信校验失败。

## 小结

- 接入验证是微信扫码登录的第一步，接口为 GET `/wechat_login/callback`。
- 用花生壳内网穿透把本地 3000 端口暴露到外网，供微信服务器回调。
- 微信回调 4 个参数：`signature`、`timestamp`、`nonce`、`echostr`，校验规则是「三参数字典序排序 + SHA1」比对 `signature`。
- 校验通过需原样返回 `echostr`；注意响应拦截器要兼容直接返回字符串。
- `appId`/`appSecret`/`token` 等配置放入 `config.ts`，通过动态模块全局可用。
