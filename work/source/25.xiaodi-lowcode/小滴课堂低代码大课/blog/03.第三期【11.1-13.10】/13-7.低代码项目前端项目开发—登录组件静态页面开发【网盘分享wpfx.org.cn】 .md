# 低代码项目前端项目开发—登录组件静态页面开发

> **导语**：本文开发登录组件的静态结构：在登录父组件中通过 `activeKey` 切换「账号密码登录」与「手机验证码登录」两种子组件，并预留微信登录占位，同时复用上一节的验证码 hooks。

## 前置知识

- 已完成《低代码项目前端项目开发—注册组件开发《上》》与《低代码项目前端项目开发—注册模块联调》中的 `useSendCode` hooks。
- 了解 Ant Design Form 与 `useState` 控制 Tab 切换。

## 正文

### 登录父组件与 Tab 切换

`components/login/Login.tsx` 用 `useTitle` 设置页签为「登录」，并用 `activeKey` 状态控制两种登录方式：

```tsx
const [activeKey, setActiveKey] = useState(1);

// 账号密码登录组件接收 setActiveKey 用于互相切换
<Account onChange={setActiveKey} />
<Captcha onChange={setActiveKey} />
```

把 `activeKey` 强转为布尔：`activeKey === 1` 显示账号密码登录，否则显示手机验证码登录。

### 复用验证码 hooks

手机验证码登录子组件 `Captcha.tsx` 中引入上一节封装的 `useSendCode`，并传入 `type="login"`：

```tsx
const { /* 图形/短信验证码组件 */ } = useSendCode('login');
```

这样获取到的图形验证码与短信验证码都是 `login` 类型，对应后端 `login:code:phone` 的 Redis key。

### 账号密码登录子组件 Account

`components/login/Account.tsx` 用 Form 包裹：

- 手机号输入框：`name="phone"`，rules 必填且校验手机号正则。
- 密码输入框：`name="password"`，必填，placeholder「请输入密码」。
- 登录按钮：`htmlType="submit"`，触发 `onFinish` 中预留的登录方法（接口下一节联调）。

### 手机验证码登录子组件 Captcha

`components/login/Captcha.tsx`：

- 手机号输入框（同上校验）。
- 中间抽出独立的验证码 `Form.Item`（即 `useSendCode` 返回的图形 + 短信验证码标签）渲染。
- 登录按钮同样调用预留方法。
- 传入的 `type` 为 `login`，保证图形/短信验证码与登录接口一致。

### 「去注册」跳转

登录组件提供「还没有账号？去注册」入口，点击调用父组件传入的 `changeState` 切回注册组件（注意需把该方法正确传递到子组件）。

## 小结

- 登录父组件用 `activeKey`（1/0）切换账号密码登录与手机验证码登录。
- 两种子组件均基于 Ant Design Form，手机号做必填 + 正则校验，密码必填。
- 手机验证码子组件复用 `useSendCode('login')`，保证验证码类型为登录。
- 微信登录暂留占位，下一节再开发；「去注册」通过 `changeState` 切回注册页。
