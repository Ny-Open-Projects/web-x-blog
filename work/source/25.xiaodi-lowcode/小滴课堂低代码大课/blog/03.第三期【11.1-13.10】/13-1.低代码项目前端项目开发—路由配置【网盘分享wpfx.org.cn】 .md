# 低代码项目前端项目开发—路由配置

> **导语**：本文开始低代码平台前端开发，第一步是把**路由与路由守卫**搭好。我们将用 React Router DOM 的哈希路由组织页面，并在根路由中根据登录态决定跳转到「登录注册页」还是「低代码编辑页」。

## 前置知识

- 已阅读《低代码项目前端项目开发—公共状态管理+自定义 hooks》（下一节）以理解登录态来源，但本文先用临时变量演示。
- 了解 React 基础与 `react-router-dom` 的 `createHashRouter`、`RouterProvider`。
- 项目已初始化（Vite + React + TypeScript + Ant Design + TailwindCSS）。

## 正文

### 创建页面组件

在 `src/pages` 下创建三个页面：

- `index.tsx`：根路由的路由守卫（后续在此判断登录态）。
- `LoginOrRegister.tsx`：登录/注册页（首字母大写）。
- `Edit.tsx`：低代码编辑页（首字母大写）。

### 配置路由表

在 `src/router/index.ts` 中引入 `createHashRouter`：

```ts
import { createHashRouter } from 'react-router-dom';

export const router = createHashRouter([
  {
    path: '/',
    element: <Home />,
    children: [
      { path: 'loginOrRegister', element: <LoginOrRegister /> },
      { path: 'edit', element: <Edit /> }
    ]
  }
]);
```

根路径渲染 `Home`，子路由包含登录注册页与编辑页。

### 在入口挂载路由

`main.tsx` 中引入 `router` 与 `RouterProvider`：

```ts
import { RouterProvider } from 'react-router-dom';
import { router } from './router';

createRoot(...).render(<RouterProvider router={router} />);
```

### 自定义路由守卫

在 `pages/index.tsx` 中用 `useLocation` 拿到当前路径，用 `useNavigate` 做跳转：

```ts
const location = useLocation();
const nav = useNavigate();

function beforePathChange(pathname: string) {
  const isLogin = true; // 临时写死，后续由公共状态替换
  if (isLogin) {
    if (['/loginOrRegister'].includes(pathname)) {
      nav('/edit'); // 已登录还访问登录页 → 跳编辑页
    }
  } else {
    if (pathname !== '/loginOrRegister') {
      nav('/loginOrRegister'); // 未登录访问权限页 → 跳登录页
    }
  }
}
```

子路由通过 `<Outlet />` 渲染（类似 Vue 的 `<router-view />`）。本项目配置的是**哈希路由**，地址栏会带 `#`。

## 小结

- 用 `createHashRouter` 组织根路由 `/` 与子路由 `loginOrRegister`、`edit`。
- 入口用 `RouterProvider` 挂载路由，子页面用 `<Outlet />` 展示。
- 路由守卫通过 `useLocation` + `useNavigate` 实现：已登录访问登录页跳编辑页，未登录访问权限页跳登录页。
- 当前 `isLogin` 为临时写死，下一篇将接入真实的 MobX 状态。
