# 低代码项目前端项目开发—注册模块联调

> **导语**：本文把上一节封装好的图形验证码、短信验证码、注册接口真正接入注册表单，用 `ahooks` 的 `useRequest` 串联「获取验证码 → 倒计时 → 提交注册 → 自动登录跳转」的完整交互。

## 前置知识

- 已安装 `ahooks`，了解 `useRequest` 的 `run`、`loading`、`ready`（手动触发）与 `onSuccess`。

## 正文

### 图形验证码请求

在自定义 hooks `useSendCode` 中用 `useRequest` 调用 `getCaptcha`：

```ts
const { run: refreshCaptcha, loading: loadingGetCaptcha } = useRequest(
  () => getCaptcha({ type }),
  {
    onSuccess: (res) => setCaptchaSrc(res.data),
    // 默认会执行一次，拿到验证码图片源
  }
);
```

- `run` 重命名为 `refreshCaptcha`，用于点击图片时刷新验证码。
- `loading` 用于请求期间禁用输入框。
- 成功后把图片源写入 `captchaSrc` 触发重渲染。
- 注册失败时也要调用它重置验证码。

### 短信验证码请求与倒计时

复制 `useRequest` 调用 `sendCode`，成功后开启倒计时：

```ts
const { run: execSendCode, loading: loadingSendCode } = useRequest(
  (params) => sendCode(params),
  {
    onSuccess: () => setStartCountdown(true),
    ready: true, // 手动触发
  }
);
```

`startCountdown` 置为 `true` 后，`useEffect` 检测到变化即启动每秒递减的定时器：60 秒后清除定时器、恢复按钮可点、重置倒计时。按钮文本在 `loading` 时显示「加载中」。

### 注册接口请求

在 `RegisterOption` 中用 `useRequest` 调用 `getRegister`，并设置 `ready: true`（默认不执行，点击注册才触发）：

```ts
const { run: execRegister, loading: loadingRegister } = useRequest(
  (values) => getRegister(values),
  {
    ready: true,
    onSuccess: (res) => {
      login(res.data.token); // 注册成功直接登录
      nav('/edit');
    },
    onError: (err) => {
      refreshCaptcha(); // 失败重置验证码
      message.warning(err?.response?.data?.msg ?? '出现未知错误');
    }
  }
);
```

`onFinish` 拿到表单 `values` 后调用 `execRegister(values)`；`loadingRegister` 用于注册期间禁用按钮。

### 登录态写入

在 `useStoreAuthor` 中新增 `login` 方法（`action` 来自 MobX）：

```ts
login: action(async (token: string) => {
  store.token = token;
  localStorage.setItem('token', token);
})
```

注册成功后调用 `login(token)` 并 `nav('/edit')` 跳转编辑页。

### 联调验证

启动前后端，刷新页面：图形验证码自动展示；填手机号 + 图形验证码 + 获取短信验证码（手机收到如 6025）→ 填密码/确认密码/协议 → 点注册。网络调慢可见注册按钮禁用，成功后自动跳转编辑页，`localStorage` 中存有 token。

## 小结

- 用 `ahooks` 的 `useRequest` 串联图形验证码、短信验证码、注册三接口。
- 图形验证码默认执行一次；短信/注册接口设 `ready: true` 手动触发。
- 短信验证码成功后启动 60 秒倒计时并禁用按钮；注册期间禁用按钮防重复提交。
- 注册成功通过 MobX `action` 写入 token 到状态与 `localStorage`，并跳转编辑页。
