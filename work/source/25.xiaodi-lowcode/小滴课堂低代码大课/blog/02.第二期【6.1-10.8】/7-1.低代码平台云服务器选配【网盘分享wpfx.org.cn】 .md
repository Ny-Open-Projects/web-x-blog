# 低代码平台云服务器选配

> **导语**：本文讲解低代码平台运行环境的起点——云服务器选配。我们将说明为什么推荐大厂云服务器而非本地部署，给出推荐的配置与操作系统版本，并演示通过 SSH 连接、重置实例密码与持久连接。

## 前置知识
阅读本文建议先看完《实战演练—低代码平台项目数据库设计》，数据库设计完成后需要服务器来运行 MySQL、Redis 与项目本身。

## 正文

### 为什么推荐云服务器
可选厂商：阿里云、腾讯云、华为云（国内），以及亚马逊云（偏海外）。推荐大厂，稳定不易「跑路」，可长期使用。

不建议在本地 Windows 上直接装第三方应用：源码安装麻烦、路径与兼容性坑多，还没学项目就先被环境劝退。即使是 Mac 本地方便一些，仍推荐统一在云服务器操作。

### 推荐配置
- **规格**：建议 2 核 8G（非硬性，满足课程要求即可；双十一等活动 2 核 2G 3M 带宽也够用，约一年 99 元）；
- **购买数量**：1–2 台；
- **付费方式**：包年/包月或按量付费均可；
- **新用户优惠**：仅新注册有活动价，可用家人身份注册后换绑手机号。

### 环境说明
- **操作系统**：务必使用 **CentOS 7.8 及以上 64 位**，不要用 Windows；
- **带宽**：1–5M，或按量付费；
- **避免踩坑**：不要用本地虚拟机，部署卡顿且安装问题多。

### 连接服务器
购买后第一件事是**重置实例密码**，否则无法远程连接。随后用 SSH 连接：

```bash
ssh root@你的服务器IP
```

输入密码回车即可登录。登录后可 `ping www.baidu.com` 验证网络是否通畅。

### 持久连接
默认连接一段时间会自动过期，导致操作中终端卡死。使用以下方式保持连接（终端不关闭即一直在线）：

```bash
ssh -o ServerAliveInterval=60 root@你的服务器IP
```

## 小结
- 选大厂云（阿里/腾讯/华为），稳定可长期使用；
- 推荐 2 核 8G（或 2 核 2G 够用），CentOS 7.8+ 64 位；
- 购后先重置实例密码，再用 `ssh root@IP` 连接；
- 用 `ServerAliveInterval` 保持持久连接，避免自动过期卡死；
- 切勿用本地虚拟机或 Windows 直接部署。
