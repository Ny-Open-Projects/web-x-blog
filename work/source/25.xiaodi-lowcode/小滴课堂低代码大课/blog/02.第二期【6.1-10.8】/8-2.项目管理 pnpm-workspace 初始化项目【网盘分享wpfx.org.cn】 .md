# 项目管理 pnpm-workspace 初始化项目

> **导语**：本文动手初始化本项目的 pnpm-workspace。我们将创建根目录、用 `pnpm init` 生成 `package.json`、编写 `pnpm-workspace.yaml` 声明子项目目录，并一次性安装公共开发依赖，为后续创建 client / server / share 子项目做准备。

## 前置知识
阅读本文建议先看完《深度解析 pnpm-workspace 的灵动工作空间管理》，理解 workspace 的优势与结构。

## 正文

### 创建根目录并初始化
新建空文件夹 `lowcode`，用 VS Code 打开，在终端执行：

```bash
pnpm init
```

生成根目录 `package.json`，记录项目依赖与 `scripts` 启动脚本。

### 声明工作区
创建 `pnpm-workspace.yaml`，声明子项目统一放在 `packages/` 下：

```yaml
packages:
  - "packages/*"
```

保存后，后续所有子项目都在 `packages/` 中创建。

### 安装公共开发依赖
将 Node.js、React、React DOM、TypeScript 等公共依赖一次性装到根目录（开发环境），子项目即可复用、无需重复下载。注意 `@types/node` 的版本要与本机 Node 大版本一致（示例 Node 18，则写 `18`）：

```bash
pnpm add -D -w typescript@^5.2.2 @types/node@18 @types/react@^18.2.37 @types/react-dom@^18.2.15 @types/lodash@^4.14.201
```

其中 `-D` 表示开发依赖，`-w` 表示安装到 workspace 根目录。安装完成后生成根 `node_modules` 与 `package.json` 中的依赖声明。

根 `package.json` 中预置了用于统一调度各子项目的脚本（后续逐节补充）：

```json
{
  "name": "lowcode",
  "version": "1.0.0",
  "scripts": {
    "run:client": "pnpm --filter client run dev",
    "run:server": "pnpm --filter server run start:dev",
    "run:share": "pnpm --filter share run dev",
    "run:release": "pnpm --filter release run dev",
    "build:client": "pnpm --filter client run build",
    "build:server": "pnpm --filter server run build",
    "build:release": "pnpm --filter release run build",
    "build:share": "pnpm --filter share run build",
    "start:server": "pnpm --filter server run start:prod",
    "start:release": "pnpm --filter release run start"
  },
  "devDependencies": {
    "@types/lodash": "^4.14.201",
    "@types/node": "18",
    "@types/react": "^18.2.37",
    "@types/react-dom": "^18.2.15",
    "typescript": "^5.2.2"
  },
  "dependencies": {
    "@ant-design/icons": "^5.2.6",
    "antd": "^5.11.2",
    "react": "^18.2.0",
    "react-dom": "^18.2.0"
  }
}
```

### 安装公共生产依赖
前端运行还需 `antd`、`@ant-design/icons`、React 等生产依赖，同样装到 workspace 根目录：

```bash
pnpm add -w antd@^5.11.2 @ant-design/icons@^5.2.6 react@^18.2.0 react-dom@^18.2.0
```

> 不加 `-D` 默认进入生产依赖。

## 小结
- 根目录 `lowcode` 用 `pnpm init` 初始化；
- `pnpm-workspace.yaml` 用 `packages: ["packages/*"]` 声明子项目目录；
- `-w` 把公共依赖装到 workspace 根目录，子项目复用、版本统一；
- `@types/node` 版本需与本机 Node 大版本一致；
- 根 `package.json` 预置 `run:*` / `build:*` 脚本，用 `--filter` 调度各子项目。
