# TypeORM 框架—实现数据库增+查操作

> **导语**：本节对比原生 SQL 与 TypeORM API，演示如何向数据表新增一条记录，以及如何按单条件、多条件（AND / OR）进行查询，体会 ORM 的简洁。

## 前置知识
- 已定义 User 实体并自动同步表结构：建议先看《TypeORM 框架—配置实体和自动同步数据库》。

## 正文
### 原生 SQL 的插入
先用原生 SQL 回顾插入语法，便于对照：

```sql
INSERT INTO user (name, phone, password)
VALUES ('老王', '311', '311');
```

执行后刷新表即可看到新增的一行。

### TypeORM 的插入
在控制器或 Service 中调用 Repository 的 `save` 方法，把对象作为参数传入即可：

```ts
@Get('test')
create() {
  return this.userRepository.save({
    name: '老王',
    phone: '311',
    password: '311',
  });
}
```

请求该接口后，数据库 `user` 表多出一条数据——无需写任何 SQL。

### 查询的三种场景
#### 1. 单字段条件查询
```ts
this.userRepository.find({ where: { name: '老王' } });
```
返回所有 `name` 为「老王」的记录（数组形式）。

#### 2. 多条件 AND 精确查询
在 `where` 对象里追加属性，条件之间是 AND 关系：

```ts
this.userRepository.find({ where: { name: '老王', phone: '311' } });
```
只有 `name` 且 `phone` 同时匹配才会返回。

#### 3. 多条件 OR 查询
OR 需要把 `where` 写成数组，每个对象是一组条件：

```ts
this.userRepository.find({
  where: [
    { name: '老王' },
    { phone: '311' },
  ],
});
```
满足任意一组条件即被查出。

### 原生对照
对应的原生查询如：

```sql
SELECT * FROM user WHERE name = '老王';
```

TypeORM 的 `find` 让查询以对象描述，避免了字符串拼接，可读性更好。

## 小结
- 新增用 `repository.save(对象)`，对象键值即字段值。
- `find({ where })` 单对象为 AND 多条件，数组则为 OR 关系。
- 条件属性名须与实体字段一致，否则查不到。
- ORM 把 SQL 收敛为对象操作，更安全也更易维护。
