# 前端子项目 React 创建和项目配置

> **导语**：本文在 workspace 根目录基础上，用 Vite 创建前端子项目 client（React），并演示如何删除重复的公共依赖、重命名为 `@lowcode/client`、配置根目录调度脚本，最后启动验证。

## 前置知识
阅读本文建议先看完《项目管理 pnpm-workspace 初始化项目》，根目录与 `pnpm-workspace.yaml` 已就绪。

## 正文

### 用 Vite 创建 client
进入 `packages` 目录，用 Vite 初始化 React 子项目，命名为 `client`：

```bash
pnpm create vite
# 项目名称：client
# 框架：React
# 模板：React（第一项）
```

完成后 `packages/client` 即一个标准的 Vite + React 初始化工程。

### 删除重复公共依赖
根 `package.json` 已维护 React、React DOM、TypeScript 等公共依赖（React 18、TypeScript 5），因此把子项目 `client/package.json` 中这些重复声明删除，统一使用根目录版本，避免不一致。

子项目 `client/package.json` 仅保留自身所需：

```json
{
  "name": "@lowcode/client",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "tsc && vite build",
    "lint": "eslint . --ext ts,tsx --report-unused-disable-directives --max-warnings 0",
    "preview": "vite preview"
  },
  "dependencies": {},
  "devDependencies": {
    "@types/react": "^18.2.37",
    "@types/react-dom": "^18.2.15",
    "@typescript-eslint/eslint-plugin": "^6.10.0",
    "@typescript-eslint/parser": "^6.10.0",
    "@vitejs/plugin-react": "^4.2.0",
    "eslint": "^8.53.0",
    "eslint-plugin-react-hooks": "^4.6.0",
    "eslint-plugin-react-refresh": "^0.4.4",
    "vite": "^5.0.0"
  }
}
```

### 重命名为 @lowcode/client
把子项目名称改为从属于 workspace 的 `@lowcode/client`，保持命名统一。

### 配置根目录调度脚本
在根 `package.json` 的 `scripts` 中已配置（见上篇），用 `--filter` 定位子项目后执行其脚本：

```json
"run:client": "pnpm --filter client run dev"
```

同理 `server` / `share` / `release` 的启动、打包、线上运行脚本也一一对应。

### 安装依赖并启动
回到根目录执行安装，pnpm 会自动为 client 下载所需依赖：

```bash
pnpm install
pnpm run:client
```

浏览器打开 Vite 提供的地址，即可看到 React 初始化页面，说明 client 子项目已成功接入 workspace。

`client/tsconfig.json` 关键配置（目标 ES2020、jsx 用 react-jsx、严格模式）：

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "useDefineForClassFields": true,
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "skipLibCheck": true,
    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "resolveJsonModule": true,
    "isolatedModules": true,
    "noEmit": true,
    "jsx": "react-jsx",
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noFallthroughCasesInSwitch": true
  },
  "include": ["src"],
  "references": [{ "path": "./tsconfig.node.json" }]
}
```

## 小结
- 用 `pnpm create vite` 创建 client，选 React 模板；
- 删除子项目中与根目录重复的公共依赖，版本统一；
- 重命名为 `@lowcode/client`，保持 workspace 命名规范；
- 根 `scripts` 用 `--filter client run dev` 调度；
- `pnpm install` 后 `pnpm run:client` 即可启动。
