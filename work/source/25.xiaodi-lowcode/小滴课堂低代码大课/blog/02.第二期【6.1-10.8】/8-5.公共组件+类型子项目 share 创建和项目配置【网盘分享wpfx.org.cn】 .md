# 公共组件+类型子项目 share 创建和项目配置

> **导语**：本文创建第三个子项目 share，用于沉淀 client / server / release 共用的公共组件与 TypeScript 类型。我们将用 `unbuild` 做打包，配置 `build.config.ts`、`package.json` 与 `tsconfig.json`，并演示打包产物（ESM / CJS / 类型声明）。

## 前置知识
阅读本文建议先看完《后端子项目 Nest 创建和项目配置》，client 与 server 已接入同一 workspace。

## 正文

### 创建 share 子项目
在 `packages` 下新建 `share` 文件夹并初始化：

```bash
cd packages && mkdir share && cd share
pnpm init
```

初始化生成 `package.json`。创建 `src` 目录与入口 `src/index.ts`，写入一个测试变量用于验证：

```ts
// src/index.ts
export const xd = '小滴课堂';
```

### 安装打包工具 unbuild
share 需打包生成 `dist` 后，才供 client / 后端引用。打包工具选用 **unbuild**（内部集成 Rollup，配置简洁，优于 webpack / Rollup 手动配置）：

```bash
pnpm add -D unbuild
```

### 配置 build.config.ts
在 share 根目录创建 `build.config.ts`：

```ts
import { defineBuildConfig } from 'unbuild';

export default defineBuildConfig({
  entries: ['src/index'],
  outDir: 'dist',
  declaration: true,
  emitCJS: true,
  external: ['react', 'react-dom', 'antd', '@ant-design/icons'],
});
```

要点：

- `entries`：打包入口，从 `src/index` 开始；
- `outDir`：产物输出到 `dist`；
- `declaration: true`：额外输出 TypeScript 类型声明（`.d.ts`），方便其他子项目获得类型提示；
- `emitCJS: true`：借助 Rollup 同时输出 CommonJS 格式（Node 模块）；
- `external`：排除 react / react-dom / antd 等已在根目录安装的公共依赖，避免重复打包。

### 配置 package.json
将 share 的 `package.json` 配置为统一命名与多格式导出：

```json
{
  "name": "@lowcode/share",
  "type": "module",
  "author": "xdclass",
  "exports": {
    ".": {
      "import": "./dist/index.mjs",
      "require": "./dist/index.cjs"
    }
  },
  "main": "./dist/index.cjs",
  "module": "./dist/index.mjs",
  "types": "./dist/index.d.ts",
  "files": ["dist"],
  "scripts": {
    "build": "unbuild"
  },
  "devDependencies": {
    "unbuild": "^2.0.0"
  }
}
```

- `name`：`@lowcode/share`；
- `type: module`：采用 ES Module 格式；
- `exports` / `main` / `module` / `types`：分别指向 ESM（`.mjs`）、CommonJS（`.cjs`）与类型声明（`.d.ts`）；
- `files`：发布包仅包含 `dist`；

### 配置 tsconfig.json
```json
{
  "compilerOptions": {
    "moduleResolution": "bundler",
    "jsx": "react-jsx",
    "strict": true,
    "target": "ES2021",
    "module": "ESNext",
    "skipLibCheck": true
  },
  "include": ["src"]
}
```

关键项：用 bundler 解析策略、`jsx: react-jsx` 支持组件语法、开启 `strict`、编译目标 `ES2021`、`module: ESNext`，并对 `src` 做编译。

### 执行打包
根 `package.json` 已配置 `build:share`（`pnpm --filter share run build`）。在根目录执行：

```bash
pnpm build:share
```

打包成功后 `share/dist` 下生成多个文件：

- `index.cjs`：CommonJS 格式（含 `require` 用法、严格模式）；
- `index.mjs`：ES Module 格式（用 `export` 导出）；
- `index.d.ts`：TypeScript 类型声明。

若把 `build.config.ts` 中的 `declaration` 与 `emitCJS` 关掉（默认 false），重新打包则仅生成 ESM 的 `.mjs`，缺少类型与 CJS 产物。

## 小结
- share 用 `pnpm init` 创建，入口 `src/index.ts` 导出公共变量/组件/类型；
- 打包工具选 `unbuild`（内部集成 Rollup），配置 `build.config.ts`；
- `declaration` 输出 `.d.ts` 类型、`emitCJS` 输出 CommonJS、`external` 排除公共依赖；
- `package.json` 以 `@lowcode/share` 命名，导出 ESM/CJS/类型三套产物；
- `pnpm build:share` 生成 `dist`，供其他子项目引用。
