# 低代码项目平台编辑模块—前端资源删除逻辑开发

> **导语**：资源管理这一节的收尾工作：把删除逻辑接进公共组件，再把公共资源管理组件铺到卡片、轮播图、视频等属性面板里。过程中会暴露一个列表型组件的典型 bug——轮播图加了两张图，改第二张却总改到第一张，根因是没维护「当前展开的是第几项」。本文讲清删除接口怎么调、成功后如何刷新列表，以及怎么靠 store 里的 `itemExpandIndex` + `useEffect` 修掉索引错位。

## 前置知识

删除能力依赖后端的资源删除接口，建议先看过《低代码项目平台编辑模块—阿里云 OSS 资源删除配置》与《低代码项目平台编辑模块—阿里云 OSS 资源删除接口开发》；前端列表如何拉数据见《低代码项目平台编辑模块—前端资源获取逻辑开发》，上传流程见《低代码项目平台编辑模块—前端资源上传逻辑开发》。

## 正文

### 删除逻辑：调接口 → 提示 → 刷新列表

公共组件 `LowResource` 是资源管理的底座：每个资源用 Ant Design 的 `Image` 展示，上方显示「选择此图片」，下面展示资源名称，每张图底下配一个「删除此资源」按钮，图标从图标库引入。外层 `div` 绑定点击方法，动态带出当前资源名称与 ID。

删除方法用 `ahooks` 的 `useRequest` 调接口：接口定义在 `api/resource` 里的 `deleteResource(id)`，底层走 `resourceApi.delete`。成功后做两件事——提示「删除成功」，并调用 `onDelete`。

这里有个值得点名的命名问题：`onDelete` 实际执行的是「重新获取资源列表」，因为删除后列表变了，要再拉一次最新数据渲染。严格说它应该叫 `getResource` 之类，命名成 `onDelete` 容易让人误解，读代码时要看清它真正的职责。本地开发环境下「删除成功」可能提示两次，是开发模式的重复执行提示，不影响结果。

### 把公共组件铺到各组件属性面板

之前只有图片列表和图片组件接入了公共资源管理组件，这一节把其余需要的都补上：

- **卡片**：把原来的占位 `input` 删掉，引入 `utils/components` 里定义的公共组件，传入 `coverImage` / `image` 等参数；
- **轮播图 Swiper**：它本身是列表型，支持「添加新项」，用 `listOption` 之类的配置接入；
- **视频 Video**：同样换成公共组件。

验证视频上传：选中一个视频后，上传期间一直显示 loading；请求成功后资源出现在列表里，并取视频第一帧作为封面展示。点击视频会把播放地址写进 store 的 state，编辑态下不可播放，要等预览功能开放后才能播放（预览、草稿、发布留到后续开发）。

### 轮播图索引错位的 bug

轮播图默认一张图，点「添加新项」变成两张。给第一项设置图片地址正常，但展开第二项再设置时，界面没更新，反而又把第一项改了。

原因很直接：列表型组件没有维护「当前展开/选中的是哪一项」。属性配置和资源上传都默认落在第 0 项，用户改第二项时，代码仍按第 0 项去写，自然串位。

### 用 `itemExpandIndex` 记录当前项

修复思路是在 store 里补回当前展开项的索引：

- 在 `store component` 里保留 `itemExpandIndex`（之前被删掉了，其实不该删——没有它就不知道用户改的是哪一项）；
- 提供一个 action，如 `setItemExpandIndex(index: number)`，接收当前展开项的索引；
- 通过 `useStoreComponent` 这个自定义 hook 把方法抛给组件使用；
- 在列表型表单容器 `FormContainerWithList` 里用 `useEffect` 监听展开项变化，一旦变化就同步更新 store 里的 `itemExpandIndex`。

这样后续「设置属性 / 上传资源」都能拿到正确的项，不再覆盖第一项。注意 store 里对应的字段名别写漏（少一个 `s` 之类会导致取不到值），这类小拼写错在响应式链路里很难查。

修复后再验证：展开第二项设置图片，改的是第二个；回头改第一项，第一项变、第二项保持不变，两项互不干扰。列表型组件的资源上传管理到此才算完整。

### 阶段收尾与后续

到这一节为止，编辑模块里三块能力都跑通了：组件在画布展示、右侧属性联动修改、资源的上传/获取/删除。接下来要做的是交互增强：拖拽排序、每个组件选中时出现的工具栏（上移/下移/删除）、键盘操作（删除、排序、撤销/前进），以及页面头部的各项功能。

## 小结

- `LowResource` 用 Ant Design `Image` 展示资源，每项带「删除此资源」按钮，动态显示名称与 ID。
- 删除走 `useRequest` → `deleteResource(id)` → `resourceApi.delete`；成功后提示并调用 `onDelete` 重新拉取资源列表，该命名实际语义是 `getResource`。
- 公共资源管理组件要铺到卡片、轮播图（`listOption`）、视频等属性面板；视频上传取第一帧做封面。
- 轮播图多图改错项的根因是没维护当前展开项索引；补 `itemExpandIndex` + action + `useEffect` 同步即可修复。
- 至此组件展示、属性联动、资源上传/获取/删除全部跑通，后续转入排序、工具栏与键盘操作。
