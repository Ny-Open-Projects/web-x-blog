# 低代码项目大课平台需求分析—后端接口《下》

> **导语**：本文承接后端接口《上》，继续拆解低代码平台剩余的后端接口：H5 发布页相关接口，以及后台数据统计相关接口。通过已上线项目演示，讲清组件获取、问卷检测、问卷提交，以及统计数据表头/数据/动态图表所需的三类接口。

## 前置知识
阅读本文建议先看完《低代码项目大课平台需求分析—后端接口《上》》，了解用户相关与低代码编辑相关接口。

## 正文

### H5 发布页相关接口
发布页基于 Next.js 服务端渲染（SSR），页面渲染由服务端完成，因此浏览器侧看不到常规接口请求，但后端仍需提供以下接口：

**1. 低代码组件获取接口**
H5 渲染哪些内容（轮播图、视频、各组件及其数据）依赖后端返回的组件与数据，接口一次性拉取并渲染。

**2. 检测是否有问卷组件接口**
用于决定是否显示「提交问卷」按钮。后端检测当前页面是否包含输入框、单选框、多选框等问卷类型组件；若无问卷类型，则不展示提交入口。

**3. 提交问卷接口**
用户填写并点击提交时请求，将问卷数据写入数据库。

### 后台数据统计相关接口
进入后台数据统计后，针对已提交的问卷数据，需要以下接口：

**1. 获取所有问卷组件接口（表头）**
返回当前低代码页面包含哪些组件，用于在表格左侧展示表头。

**2. 获取所有问卷数据接口（表格数据）**
返回每份问卷的详细提交内容，以表格形式呈现。

**3. 根据 ID 查询某个问卷组件数据接口（动态图表）**
点击某个组件「查看数据」时，把该组件 ID 传给后端，后端查出所有用户在该组件上的提交结果并返回，用于右侧动态图表（饼状图、横向柱状图）展示。

### 一个重要的业务规则
同一用户重新发布低代码页面时，**之前收集到的问卷数据会被全部重置**。因此重新发布后，后台统计仅反映最新一次发布后产生的数据。

### 接口汇总
| 分类 | 接口 |
| --- | --- |
| H5 发布页 | 低代码组件获取、检测是否有问卷组件、提交问卷 |
| 后台数据统计 | 获取所有问卷组件（表头）、获取所有问卷数据、根据 ID 查询某组件数据 |

## 小结
- H5 发布页依赖「组件获取 + 问卷检测 + 问卷提交」三类接口；
- 问卷检测接口决定是否展示提交按钮，避免无问卷时也出现入口；
- 后台数据统计需要「表头接口 + 数据接口 + 按 ID 查组件数据接口」；
- 按组件 ID 查询是右侧动态图表的数据来源；
- 同一用户重新发布会重置历史问卷数据。
