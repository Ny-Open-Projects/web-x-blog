# 低代码平台项目大课介绍+适合人员+学后水平

## 前置知识

无需前置基础即可阅读，这是课程的第一集。后续技术选型与环境搭建会从零展开。

## 正文

### 我们要做出一个什么样的平台

本大课讲解的是一个**大型复杂的 React 项目**，不仅有前端，还有后端。学完并亲手把低代码平台开发出来后，用户（运营、产品经理等不具备编码能力的人）可以直接用平台**零代码发布自己的网站或问卷系统**：

- 发布网站：别人可以通过链接访问；
- 问卷系统：收集用户信息，把数据整理成可视化图表，并支持在线 Excel 下载。

也就是说，平台本身是一个「让非技术人员也能搭建页面」的低代码（low-code）产品。

### 多端架构：三个子项目

课程按照「先需求文档、再技术选型、后编码落地」的互联网大厂流程推进。项目是多端的，涉及三个子项目，每个子项目开工前都会从产品需求文档出发。

**1. B 端——低代码编辑端（React）**

使用 React 最新稳定版（18），配合：

- **TypeScript**：静态类型校验；
- **ahooks**：第三方 Hooks 库（以及自定义的 Hooks）；
- **MobX**：状态管理；
- **Ant Design**：组件库；
- **ECharts**：图表可视化；
- **Tailwind CSS**：样式框架。

**2. 后端（Nest）**

- **Nest**：基于 Node 的后端框架，提供接口；
- **TypeORM** + **MySQL**：持久化；
- **Redis**：缓存，提升接口性能；
- **Docker**：生成镜像、运行容器，支撑项目上线；
- **Nginx**：反向代理转发请求；
- **阿里云 OSS**：静态资源存储；
- **JMeter**：后端接口性能压测与优化。

**3. C 端——H5 发布页（Next.js）**

用户最终访问的页面，使用：

- **Next.js**（SSR 服务端渲染）；
- **TypeScript**；
- **Ant Design**；
- **Tailwind CSS**（与编辑端一致，提升样式开发效率）。

### 适合人群（八类）

1. 学过 React 想进阶，但缺少大型 React 项目经验；
2. 只会阅读框架、对 React 不熟；
3. 想转行进入互联网大厂；
4. 回到三四线城市做前端（薪资偏低，掌握全栈+自动化部署更能带项目、接外包增收）；
5. 在职大厂前端想提升能力；
6. 准备跳槽、简历缺少亮点项目，可把本项目写进简历；
7. 需要带团队的技术骨干；
8. 在校大学生，毕业前补齐项目经验。

### 学后水平

- 加强 Vue 框架使用能力（大厂必备开发框架之一）；
- 提升工作与面试的竞争力；
- 从 B 端到 C 端、从零开发到部署上线的全栈闭环；
- 对标**高级前端工程师 / 技术组长**的项目难度；
- 掌握产品分析设计、解决方案选择、功能需求落地上线的完整能力。

除宏观技术栈外，课程还会细讲多端项目环境、拖拽排序、React Hooks 基础、性能优化、接口数据调试、数据库、第三方组件、后端部署上线等分类专题。

## 小结

1. 课程交付物是一个低代码平台，让用户零代码发布网站与问卷系统。
2. 项目分三端：B 端编辑端（React）、后端（Nest + TypeORM + MySQL + Redis + Docker）、C 端 H5（Next.js SSR）。
3. 编辑端用 MobX 做状态管理、Ant Design + ECharts + Tailwind CSS 做 UI 与可视化。
4. 后端用 Redis 做缓存、Docker 做容器化、Nginx 做代理、阿里云 OSS 存资源、JMeter 做压测。
5. 适合从零基础到在职大厂前端、跳槽者、在校生等八类人群。
6. 学完对标高级前端 / 技术组长，具备全栈与自动化部署能力。
