# Nextjs 应用路由器和导航跳转

> **导语**：本节深入 Next.js 的 App Router，讲解如何新建路由页、嵌套路由、用 `layout.tsx` 共享组件，以及 Link 标签跳转与 `useRouter` 编程式导航两种跳转方式，并演示如何获取当前路径。

## 前置知识

建议先看《Nextjs 项目文件介绍和页面布局》，理解 `src/app` 文件路由与 `layout.tsx`。本文工程依赖见 `代码（已8期）/代码（已8期）/3-3/package.json`。

## 正文

### App Router 与 Pages Router

Next.js 有两种路由方式：

- **App Router**：Next.js 13 引入的新范式，基于 React 最新特性；官方推荐新项目使用。
- **Pages Router**：13 之前创建路由的主要方式，新版本仍兼容，但官方建议用新的 App Router。

本大课全部使用 **App Router**。

### 创建新路由页面

在 `src/app` 下新建文件夹（如 `about`），里面放 `page.tsx` 即可。可用 VS Code 的「用户代码片段」配置 `rcc` 快捷键快速生成组件骨架，文件名即路由路径：文件夹叫 `about`，访问地址就是 `/about`。

加上 Tailwind 样式 `min-h-screen`（即 `min-height: 100vh`，占满视口高度）让页面铺满。同理可再建 `personal` 文件夹 + `page.tsx`，访问 `/personal`。

### 嵌套路由

在 `about` 下再建 `other` 文件夹 + `page.tsx`，访问路径即 `/about/other`——这就是嵌套路由，规则简单：目录层级即 URL 层级。

### 用 layout.tsx 共享组件

若希望 `about` 及其子路由共享某个组件（如头部 `Header`），可在 `about` 下新建 `layout.tsx`：

- 导出函数命名为 `AboutLayout`（不再是 `RootLayout`）；
- **不要**写 `<html>` / `<body>`（根布局已有），直接用一个 `<div>` 包裹；
- 把共享组件（如 `<header>头部共享的组件</header>`）放在 `children` 之前。

这样访问 `/about` 与 `/about/other` 都会渲染这个共享头部。在 `personal` 下用同样方式也能建立 `PersonalLayout`。

### 跳转方式一：Link 组件

使用 `next/link` 的 `<Link>` 标签，`href` 指定目标：

```tsx
import Link from 'next/link';

<Link href="/about">去关于的页面</Link>
```

点击即跳转到 `/about`；`href="/about/other"` 则跳到嵌套路由。

### 跳转方式二：编程式导航 useRouter

更复杂的场景用 `useRouter` 钩子（需 `use client` 标记为客户端组件）：

```tsx
'use client';
import { useRouter } from 'next/navigation';

const router = useRouter();
<button onClick={() => router.push('/about')}>去关于的页面</button>
```

日常开发中编程式导航更灵活，不用手写标签。

### 获取当前路径 usePathname

需要判断「当前是否处于某路径」来高亮导航时，用 `usePathname`（同样需 `use client`）：

```tsx
'use client';
import { usePathname } from 'next/navigation';

const pathname = usePathname();
// pathname === '/personal' 时为红色，否则其他颜色
```

### 加载兜底与错误

官网还提供 `loading.tsx` / `error.tsx` 与 `Suspense` 的 `fallback` 配置，用于接口未返回时的旋转加载（loading UI）与路由错误处理——按官网示例配置即可。

## 小结

1. 新项目用 App Router；Pages Router 为旧方案、仍兼容。
2. 新建「文件夹 + page.tsx」即新路由，文件夹名即路径。
3. 嵌套路由 = 目录层级；`/about/other` 对应 `about/other/page.tsx`。
4. 子路由共享组件用同级 `layout.tsx`（不含 html/body）。
5. 跳转：`<Link href>` 标签式 与 `useRouter().push()` 编程式（需 `use client`）。
6. `usePathname()` 获取当前路径做导航高亮；官网提供 loading/error UI。
