# Nextjs 项目文件介绍和页面布局

> **导语**：上一节创建了初始化工程，本节逐文件拆解 Next.js 项目的目录结构，重点讲清 `.next`、`src/app`、`layout.tsx`、`page.tsx` 的作用，以及根布局如何通过 `metadata` 与字体做 SEO 与全局样式。

## 前置知识

## 正文

### 构建产物与生产运行

`.next` 文件夹相当于 Vite 项目 `build` 后生成的 `dist`——是**生产环境代码**。重新构建：

```bash
pnpm build
```

运行生产代码：

```bash
pnpm start
```

框架底层已封装好逻辑，直接命令即可在 3000 端口跑起生产环境。平时开发用 `pnpm dev` 即可。

### 核心目录与文件

- **node_modules**：项目全部依赖。
- **public**：存放图片、SVG 等静态资源。
- **src**：业务代码根目录。
  - **src/app**：Next.js 的**文件路由**目录，路由页都放在这里。
  - 页面图标、全局样式（因初始化选了 Tailwind CSS，会有对应配置）。
- **.gitignore**：Git 忽略清单。
- **next-env.d.ts**：Next.js 的 TypeScript 类型定义。
- **next.config.js**：框架配置文件。
- **postcss.config.js**：Tailwind CSS 的 PostCSS 配置。
- **tailwind.config.ts**：Tailwind 的 theme / 插件规则配置。
- **tsconfig.json**：全局 TypeScript 编译配置。
- **README.md**：项目说明。
- **package-lock.json / pnpm-lock.yaml**：依赖版本锁定文件。多人协作时锁定每个插件版本（如固定 18 版），保证他人拉取代码后下载的依赖与你本地一致，避免新版不兼容。

工程 `package.json` 关键字段如下（见 `代码（已8期）/代码（已8期）/3-2/package.json`）：

```json
{
  "name": "next-test",
  "version": "0.1.0",
  "private": true,
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start",
    "lint": "next lint"
  },
  "dependencies": {
    "react": "^18",
    "react-dom": "^18",
    "next": "14.0.1"
  },
  "devDependencies": {
    "typescript": "^5",
    "tailwindcss": "^3.3.0"
  }
}
```

### 根布局 layout.tsx

`src/app/layout.tsx` 是应用的**根布局组件（root layout）**，导出的是一个 React 函数。它做了几件事：

1. 从 Next.js 引入 `metadata` 类型，设置页面 `title` 与 `description`——这就是 SEO 所需的 `<meta>` 标签；
2. 用 `next/font` 加载谷歌字体 **Inter**；
3. 引入全局 CSS；
4. 接收 `children`（任意 React 子节点），在 `<body>` 中渲染，并用 `inter.className` 设置全局字体。

```tsx
export const metadata = { title: 'Create Next App', description: 'Generated by Create Next App' };

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="zh-CN">
      <body className={inter.className}>{children}</body>
    </html>
  );
}
```

打开浏览器控制台查看 `<head>`，能看到 `title` 与 `name="description"` 的 meta 标签——注释掉 `metadata` 再刷新，这两个标签就会消失，证明它用于 SEO。

### 首页 page.tsx

`src/app/page.tsx` 导出的是**首页内容**，会作为 `layout` 的 `children` 被渲染。可把内容改成简单结构（如一个 `<div>首页</div>`），并加上 Tailwind 样式 `min-h-screen`（即 `min-height: 100vh`，占满视口高度），避免页面样式错乱。

`tsconfig.json` 中已配置路径别名（见 `代码（已8期）/代码（已8期）/3-2/tsconfig.json`）：

```json
{
  "compilerOptions": {
    "paths": { "@/*": ["./src/*"] }
  }
}
```

这样可用 `@/` 直接引用 `src` 下模块。

## 小结

1. `.next` 是生产构建产物，对应 Vite 的 `dist`；`pnpm build` 生成、`pnpm start` 运行。
2. 业务代码在 `src`，路由在 `src/app`，新建「文件夹 + page.tsx」即新页面。
3. 锁文件保证多人协作依赖版本一致。
4. `layout.tsx` 是根布局，通过 `metadata` 设置 SEO 的 title/description，用 `next/font` 加载 Inter 字体。
5. `page.tsx` 是首页，作为 `children` 被根布局渲染；`min-h-screen` 占满视口。
6. `tsconfig.json` 用 `@/*` 别名指向 `src`。
