# 第 15 册 快问快答冲刺卡 —— 60 道高频题闪卡（考前最后 3 天）

> 用法：遮住答案自测，答不出的回炉对应章节。每题答案压缩到 3 句以内——
> 这不是完整答案，是"神经通路"，面试时以它为骨架展开。
> 按章节分组，每 10 题一组，配合各章"一页速记卡"滚动复习。

## A 组：Java 基础与集合（对应第 1 章）

1. **String 不可变的四条理由？** 池化复用、hashCode 可缓存、线程安全、防篡改安全。
2. **重写 equals 为什么必须重写 hashCode？** HashMap 先 hash 定桶再 equals 精确匹配；只重写 equals 会 get 不到、去重失效。
3. **Integer == 的坑？** 缓存 -128~127，128 起是新对象；包装类一律 equals。
4. **ArrayList 扩容？** 懒初始化 10，扩 1.5 倍（old >> 1），Arrays.copyOf 复制。
5. **为什么工程上不用 LinkedList？** 随机访问 O(n)、每节点两指针内存放大、缓存不友好；数组局部性原理碾压。
6. **HashMap put 流程四步？** 扰动 hash → 初始化 → (n-1)&hash 定桶 → 覆盖/尾插/树化 → 超阈值扩容。
7. **树化阈值 8 与退化 6 的由来？** 阈 8 = bin 已有 8 个节点时下一次插入触发（实测 8 键仍链表）；泊松分布下 bin 长 8 概率千万分之一；退化 6 留缓冲防抖动。
8. **CHM 的 size 怎么统计？** baseCount + CounterCell[] 分段（LongAdder 思想），返回近似值。
9. **CHM 为什么 key/value 不许 null？** get 返回 null 有二义性，并发容器必须一次确定。
10. **泛型擦除的四个限制？** 不能 new T()/T[]/instanceof T、不支持基本类型、静态成员不能用类泛型、重载签名冲突。

## B 组：并发与 JUC（对应第 2 章）

11. **volatile 三句话？** 可见性（MESI 刷主存）、有序性（内存屏障）、不保证原子性。
12. **DCL 为什么加 volatile？** new 三步可能重排（赋引用先于初始化），其他线程拿到半初始化对象。
13. **锁升级四态？** 无锁→偏向→轻量→重量；JDK15 禁用偏向锁，JDK21 已彻底移除（实测 -XX:+UseBiasedLocking 报 Unrecognized）。
14. **线程池执行流程口诀？** 先核心、再队列、后非核心、最后拒绝。
15. **Executors 两大罪？** Fixed 无界队列 OOM；Cached 线程数无上限爆炸。
16. **线程数怎么定？** N≈C×U×(1+W/C) 起步，压测定案，动态线程池运行时调。
17. **submit 的异常去哪了？** 被 FutureTask 存进 Future，不打印——静默丢失的经典 bug。
18. **AQS 的核心结构？** volatile state + CLH 变体双向队列 + park/unpark + 模板方法（tryAcquire 留给子类）。
19. **CAS 三坑？** ABA（版本号）、自旋烧 CPU（LongAdder 分段）、只能一变量（封装对象）。
20. **LongAdder 为什么快？** 热点分散到 Cell[]，读弱写强，sum() 是近似快照。

## C 组：JVM（对应第 3 章）

21. **对象分配路径？** TLAB → Eden CAS → Survivor 复制 → 年龄 15/动态年龄 → 老年代。
22. **Full GC 触发五条？** 老年代满、元空间满、System.gc、CMS 失败、G1 to-space exhausted。
23. **双亲委派三目的？** 安全（核心类不可替换）、唯一（同类一个加载器）、复用（父加载不重复）。
24. **三色标记漏标两条件？** 黑引用了白 + 灰到白的引用被断；CMS 增量更新，G1 SATB，ZGC 读屏障自愈。
25. **G1 什么时候反而不如 CMS？** 小堆（<6G）：RSet 维护成本占堆 10%+，CMS 卡表更便宜。
26. **ZGC 亚毫秒的秘密？** 着色指针 + 读屏障自愈，让对象复制也并发；JDK21 分代 ZGC 是生产推荐。
27. **OOM 排查三板斧？** jstat 看趋势 → jmap -dump:live → MAT 支配树找 GC Roots 引用链。
28. **JVM 必开三件套？** HeapDumpOnOutOfMemoryError、统一 GC 日志、ExitOnOutOfMemoryError（OOM 快速失败）。
29. **JIT 三板斧？** 分层编译（C1+C2）、方法内联（<35 字节）、逃逸分析（标量替换/锁消除）。
30. **无栈异常怎么排查？** HotSpot 高频异常省略栈帧，加 -XX:-OmitStackTraceInFastThrow。

## D 组：Spring 与框架（对应第 4 章）

31. **Bean 生命周期一句话？** 实例化→注入→Aware→前置→初始化→后置→使用→销毁；AOP 代理在后置处理生成。
32. **三级缓存第三级为什么必须有？** ObjectFactory 延迟决定"返回原对象还是提前代理"，保证 AOP 语义正确。
33. **AOP 失效根因一句话？** 绕过代理对象直接调用（同类 this 调用、final/private 方法、new 出来的对象）。
34. **事务失效清单？** 非 public、自调用、catch 吞异常、默认只回滚 RuntimeException、传播错配。
35. **REQUIRES_NEW 与 NESTED？** 前者挂起旧事务新建独立事务（双连接），后者保存点同事务、外层回滚内层必回滚。
36. **自动装配机制？** imports 注册文件 + 条件注解（OnClass/OnMissingBean/OnProperty），用户 Bean 优先。
37. **Mapper 接口为什么能注入？** JDK 动态代理 + MapperFactoryBean + ImportBeanDefinitionRegistrar 扫描。
38. **先提交后通知怎么写？** TransactionSynchronization#afterCommit 里发 MQ，保证消费方能读到数据。
39. **构造器注入的好处？** 天然暴露循环依赖（启动即失败）+ 不可变 + 显式依赖，团队规范应强制。
40. **Boot3 关键变化？** JDK17 基线、javax→jakarta、AOT/Native、Micrometer Tracing。

## E 组：MySQL 与 Redis（对应第 5、6 章）

41. **B+ 树为什么矮胖？** 非叶节点只存键扇出极大，3~4 层覆盖千万行；叶子链表支持范围扫。
42. **二级索引为什么回表？** 叶子只存索引列+主键，其他列要回聚簇索引取；覆盖索引免回表。
43. **MVCC 可见性判断？** 版本链 + ReadView（m_ids/min/max/creator），RC 每语句、RR 每事务一次视图。
44. **两阶段提交顺序？** redo prepare → 写 binlog → redo commit；崩溃恢复看 binlog 完整性定夺。
45. **分片键四原则？** 高频查询带分片键、分布均匀、业务身份相关（user_id）、避免跨片事务。
46. **缓存三大问题口诀？** 穿透挡（布隆/空值）、击穿合（单飞/逻辑过期）、雪崩抖（TTL 随机+多级）。
47. **缓存一致性标准方案？** 先更新 DB 再删缓存 + binlog 异步删 + TTL 兜底最终一致。
48. **分布式锁四要素？** SET NX PX、唯一 value、Lua 原子释放、看门狗续期；正确性靠 DB 兜底。
49. **哨兵选主四步？** replica-priority → offset 最大 → runid 最小；主观下线→客观下线→Raft 选 leader→执行转移。
50. **热 key 治理？** 本地缓存兜底 + key 打散分片 + 大促预热；热 key 是预测出来的不是故障时发现的。

## F 组：MQ 与分布式（对应第 7、8 章）

51. **MQ 三作用三代价？** 异步/解耦/削峰；一致性变弱、链路变长、多一个运维件。
52. **不丢消息三端？** 发送 ack=all+幂等 producer；broker 3 副本+minISR=2；消费先处理后手动提交。
53. **消费幂等四法？** 唯一键约束、状态机、乐观锁版本号、去重表。
54. **rebalance 头号诱因？** 处理耗时超 max.poll.interval.ms；对策：调小单批 + CooperativeSticky。
55. **事务消息原理？** 半消息 → 本地事务 → 提交/回滚 → 未确认则回查生产者；只保证发送侧原子。
56. **TCC 三坑？** 空回滚、悬挂、幂等——都以"事务记录表"解决；资金链路选 TCC，一般业务选 SAGA/消息表。
57. **CAP 选型口诀？** 注册中心选 AP（Nacos AP/Eureka），协调与锁选 CP（ZK/etcd）；无分区时 CA 可兼得。
58. **Raft 三子问题？** 选主（term+多数派）、日志复制（多数派提交）、安全（选举限制保证新 Leader 有全部已提交日志）。
59. **限流四算法一句区别？** 固定窗口有突刺；滑动窗口消突刺；漏桶恒速；令牌桶允许突发。
60. **稳定性四段论？** 预防（冗余/隔离/预案）→ 感知（SLO 错误预算）→ 止血（回滚优先）→ 复盘（无责文化）。

## G 组：架构与 AI（对应第 9、10 章）

61. **场景题五步法？** 澄清→估算→主干→难点→演进；先问规模再画图。
62. **秒杀防超卖三道锁？** Redis Lua 原子预扣 → MQ 排队 → DB 条件更新（n>0）+ 幂等回补。
63. **Feed 流混合推拉？** 小 V 写扩散（推）、大 V 读聚合（拉）、收件箱 ZSet 截 3000 条。
64. **QPS 与 RT 关系？** QPS=线程数/RT；RT 涨→线程需求涨→切换开销涨→死亡螺旋；先看下游与 GC 别急着扩容。
65. **大对象三宗罪？** 大 key（慢查询阻塞单线程）、大事务（连接与锁）、大查询（OOM）。
66. **RAG 链路？** 切分→Embedding→向量库→混合检索→重排→带引用生成；调优先做"检索归因 vs 生成归因"分离。
67. **企业 RAG 三命门？** 权限过滤（ACL 必须带）、知识时效（增量管道）、评测集质量。
68. **Agent 六模块？** 规划、记忆（短期上下文/长期向量）、工具（MCP）、编排（图状态机）、护栏、可观测。
69. **LLM 成本四刀？** 降单价（路由/私有化）、降 token（裁剪/摘要）、降次数（语义缓存）、预算熔断。
70. **AI 输出三出口？** 可用、人审（human-in-the-loop）、拒绝；高风险操作永远有人审出口。
