> 来源：agent-dev 域矩阵 AD 系列同源（AD-050/186~210/241~250/261~310 手写预备事实），准确性同源。
> 使用：面试自测（计时→答题→对照→复盘）/ 团队招聘（评分细则直接用）/ 练习（AD-649 时间盒）。

## 评分标准（四维加权，AD-402）

| 维度 | 权重 | 说明 |
|------|------|------|
| 功能正确 | 40% | 核心逻辑正确（循环/终止/回填），AD-401 题单功能点 |
| 边界处理 | 20% | 错误反馈/幻觉工具/超窗/取消（AD-200 五 bug 对应） |
| 工程质量 | 20% | 类结构（AD-186 五类）/命名/脱敏（AD-054）/轨迹（AD-040） |
| 并发与安全 | 20% | 线程安全（AD-058）/幂等（AD-038）/权限校验（AD-235）/预算（AD-193） |

**扣分点权重**（AD-512）：工具结果未回填 -10｜无终止条件 -15｜中断未恢复 -5｜预算未实现 -10｜上下文未裁剪 -5。
**加分点**（AD-513）：主动放弃能力 +5／错误反馈自修复 +5／轨迹埋点 +5／并发安全 +5／幂等处理 +5。

## 时间管理（AD-405）

设计类图 5 min → 核心逻辑 60% 时间 → 边界处理 20% → 测试断言 10% → 自查 10%。时间盒内宁可边界简述，不写一半核心。

## 使用指南（AD-714）

1. **自测**：计时答题（纸上或 IDE 关闭补全）→ 对照参考实现 → 按细则自评 → 错题回矩阵行复盘（AD-xxx）。
2. **招聘**：按 JD 选题（IO 密集选流式变体 AD-403），细则直接评分，红旗清单（AD-635）辅助判断。
3. **练习**：每题完成后对照追问清单自答（AD-406），追问答不上回矩阵行学习。

## 红旗清单（AD-635 面试反模式）

说 Agent 万能无边界｜无安全意识（工具裸奔）｜无成本概念（无预算）｜无评测体系｜无版本概念——任一红旗 = 基础分封顶。
