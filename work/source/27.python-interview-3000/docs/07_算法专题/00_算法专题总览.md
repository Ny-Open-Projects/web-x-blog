## 备考策略(面试官视角)

1. **先讲思路再写码**:A006 三数之和这类题,先说「排序+固定一个+双指针」与去重要点,再落笔;闷头写码是高频减分项。
2. **复杂度必须带空间复杂度**:说 O(n) 时主动说清「哈希表 O(n) 空间」;追问链里几乎每题都埋了空间优化的追问。
3. **边界主动覆盖**:空输入、单元素、全相同、溢出(int 在 Python 不溢出,但要说明这与 Java 的差异,是 Python 岗加分点)。
4. **用 Pythonic 写法但不说框架黑话**:`collections.Counter`、`defaultdict`、`heapq.nlargest` 用得对是加分,但手撕题考的是原语级实现,该手写双向链表就手写(见 A011)。
5. **每题先跑一遍**:`code/07_算法专题/` 下代码全部标准库可运行,跑通并记住断言输出是「验证过」的证据。
