   这是为了让路径查找不断链；正文已 100% 纠干净，标题大小写不影响内容。

4. **画面线 `vision.md` 是 VLM 抄录的真实屏幕**，PPT/IDE 上的 `Maven`、`@SpringBootApplication` 等拼写为原样，可作为术语正确性的「屏幕佐证」。
