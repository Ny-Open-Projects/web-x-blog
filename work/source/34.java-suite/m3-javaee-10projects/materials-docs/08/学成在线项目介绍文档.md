学成在线项⽬介绍⽂档  
1 ⾸⻚  
进⼊⾸⻚，点击左侧课程分类菜单或 “ 课程 ” ，进⼊课程搜索⻚⾯。
 
2 课程搜索  
进⼊课程搜索⻚⾯，输⼊关键字进⾏搜索，也可以通过⼀级课程分类、⼆级课程分类、课程难度等级进
⾏搜索。
 
 
3 课程详情

<!-- page 2 -->
课程详情⻚⾯展⽰了课程的详情信息，包括：课程名称、课程介绍、课程章节、教育机构信息等。
 
在课程详情⻚⾯点击⻢上学习进⼊课程学习⻚⾯，如果该课程为收费课程则需要购买课程。
 
4 在线视频  
通过右侧课程章节切换课程视频在线学习。

5 课程管理  
教学管理⼈员进⼊教学管理平台课程管理功能界⾯，进⾏编辑课程信息、上传课程视频等操作。
