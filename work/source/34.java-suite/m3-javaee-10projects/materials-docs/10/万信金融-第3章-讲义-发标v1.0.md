什么是发标
 
P2P
行业习惯把平台里某个投资项目称为
“
标的
”
，简称
“
标
”
。一个标的一般至少包含：描述、借款用途、
借款总额、还款方式、借款利率、借款期限等基本信息。通俗来讲：
“
标的
”
就是：借款人在
P2P
平台发起的借款项目。
“
发标
”
就是：借款人在
P2P
平台申请借款。
