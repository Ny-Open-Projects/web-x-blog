1 
业务概述
 
前面在实现开户业务时，系统只是要求用户填写了个人姓名和身份证信息，并没有进行身份认证和校
验。这里面就存在着各种风险，例如：假名，盗用他人身份证等等。
特别是对于借款人来说，系统必须对其身份进行认证和校验，否则会对后续交易产生较大风险。系统要
么在开户时进行身份认证和校验，要么在发标
(
交易的第
1
步
)
时进行身份认证和校验，考虑到有些用户即
使开户也不一定会进行交易
(
例如：发标
)
，所以把身份认证和校验放在发标时实现。更新后的发标流程
如下：
