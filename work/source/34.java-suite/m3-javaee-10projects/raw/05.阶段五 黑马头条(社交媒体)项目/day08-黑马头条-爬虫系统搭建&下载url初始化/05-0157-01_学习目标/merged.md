PPT章节标题：1爬虫是什么
PPT正文内容：
网络爬虫 (Web crawler) 是一种按照一定的规则，自动地抓取万维网链接的程序或脚本，它们被广泛用于互联网数据挖掘或其他相关网站，可以自动采集其所能够访问到的网页内容，以获取或提取这些网页的内容和检索方式。从功能上讲，爬虫一般分为数据采集、处理、存储等几个部分。
传统爬虫从一个或若干初始网页的URL开始，获得初始网页上的URL，在抓取网页的过程中，不断从当前页面抽取新的URL放入队列，然后从队列中取出URL，然后，它将根据一定的搜索策略从队列中选择下一步要抓取的URL，对页面进行分析，提取出新的URL，然后将这些新的URL放入队列，如此循环，直到满足停止条件。对于爬虫系统，这一过程所得到的分析结果还能对以后的抓取过程给出反馈和指导。
