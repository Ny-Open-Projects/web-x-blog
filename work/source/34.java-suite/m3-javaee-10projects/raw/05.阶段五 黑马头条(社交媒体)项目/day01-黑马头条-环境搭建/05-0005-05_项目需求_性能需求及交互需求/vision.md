- 内容：列出“频道栏”、“文章列表”、“搜索功能”、“友吧”、“我的”、“行万”等模块，每个模块下有具体功能点。
- 列点：
  - 频道栏：用户可以通过此功能添加自己感兴趣频道，在添加频道时，系统可依据用户喜好进行推荐。
  - 文章列表：需要显示文章标题、文章图片、评论信息等，且需监控文章是否在APP做预期的行为。
  - 搜索功能：获取用户搜索的内容，并记录用户的历史搜索信息。
  - 用户中心：用户可以在其中心查看文章、评论、点赞、收藏、分享等操作；除此之外还要收集用户文章的浏览时间，是否喜欢等行为信息。
  - 实名认证：用户可以进行身份证或手机号认证，实名认证之后即可成为自媒体人，在平台上发布文章。
  - 注册登录：登录时，盐值内容为手机号或邮箱注册，通过手机或邮箱进行登录，首次发布文章。

  - 内容管理：管理员审核自媒体人发布的文章，并对文章进行新增、修改、删除等操作。
