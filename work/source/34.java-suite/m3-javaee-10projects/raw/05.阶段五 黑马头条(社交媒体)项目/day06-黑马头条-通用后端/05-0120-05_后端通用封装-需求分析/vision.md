画面5、画面6、画面11、画面12、画面13：
- 后台管理系统大部分功能都是对数据进行增删改查，少部分功能还有增加功能。在企业开发过程中，常需封装通用的接口来处理此类功能，以提高开发效率，但其封装过程会涉及以下几个关键点需要注意处理：
  - 权限的控制（访问、数据、操作）
  - 信息安全控制（SQL注入的问题）
- 对于部分功能需求归纳总结为以下功能点：
  - 新增：能够通过插入授权的数据表数据
  - 修改：能够通过修改指定的字段数据
  - 删除：能够通过删除指定条件的数据
  - 列表：能够通过加载不同数据表的数据，并支持条件查询、分页等
  - 在通用功能中，对于以上功能可做前后端业务处理
  - 在通用功能中，可控制不同数据表的操作权限

- 2.2 实现思路
  - 【持久层】
    - 通过动态SQL或者SQL拼接方式，实现通用的持久层
  - 【业务层】
    - 定义操作权限，控制框架的不操作权限（增删改查CRUD），每次操作之前需要检查此权限
