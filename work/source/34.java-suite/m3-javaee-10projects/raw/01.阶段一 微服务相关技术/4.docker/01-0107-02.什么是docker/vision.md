- 标题：1 Docker简介
- 子标题：1.2 什么是Docker
- 内容：为什么选择 Docker？
  (1) 上手快
  用户只需要几分钟，就可以把自己的程序“Docker化”，Docker 依赖于“写时复制”（copy-on-write）模型，使修改应用程序也非常迅速，可以说达到“随心所欲，代码即成”的境界。
  随后，就可以创建容器来运行应用程序了。大多数 Docker 容器只要不到 1 秒中即可启动。由于去除了管理程序的开销，Docker 容器拥有很高的性能，同时一台主机中也可以运行更多的容器，使用户尽可能的充分利用系统资源。
