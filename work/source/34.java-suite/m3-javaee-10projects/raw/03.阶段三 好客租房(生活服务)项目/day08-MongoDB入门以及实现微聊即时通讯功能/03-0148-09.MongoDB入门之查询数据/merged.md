1.3.6、查询数据
MongoDB 查询数据的语法格式如下：
db.user.find([query], [fields])
• query：可选，使用查询操作符指定查询条件。
• fields：可选，使用投影操作符指定返回的键。查询时返回文档中所有键值，只需省略该参数即可（默认省略）。
如果你需要以易读的方式求取数据，可以使用 pretty() 方法。语法格式如下：
db.col.find().pretty()
```
