内容：
在ES6中，对函数的参数做了优化，使得我们在操作函数时更加的便捷。
在ES6以前，我们无法给一个函数参数设置默认值，只能采用类似写法：
```javascript
function add(a, b) {
b = b || 1;
return a + b;
}
```
现在可以这么写：
```javascript
function add(a, b = 1) {
return a + b;
}
```
