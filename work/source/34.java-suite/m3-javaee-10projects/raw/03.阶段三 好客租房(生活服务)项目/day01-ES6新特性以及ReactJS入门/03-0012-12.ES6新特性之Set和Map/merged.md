标题：1.8. set和map
内容：
- Set 本质与数组类似，不同在于 Set 中只存储不同元素，如果元素相同会被忽略，和 java 中的 Set 非常相似。
- 构造函数：
  ```javascript
  // Set构造函数可以接收一个数组或迭代器
  let set = new Set();
  set.add(1); // 添加元素
  // 改变数据
  let set2 = new Set([2,3,4,5,5]); // 得到[2,3,4,5]
  ```
- 方法：
  ```javascript
  set.add(1); // 添加元素
  set.clear(); // 清除
  set.delete(2); // 删除指定元素
  set.has(2); // 判断是否存在
  set.forEach(function() {}); // 遍历元素
  set.size; // 元素个数，属性，不是方法。
  ```
