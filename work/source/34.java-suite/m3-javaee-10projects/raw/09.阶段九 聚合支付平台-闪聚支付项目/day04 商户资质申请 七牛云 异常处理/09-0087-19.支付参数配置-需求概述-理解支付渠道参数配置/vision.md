1) 这一组画面整体在讲什么（一句话）：
讲解闪聚支付平台如何为商户聚合第三方支付渠道（如支付宝、微信支付、百度钱包等），并配置相应的支付参数和服务类型。

2) 按时间顺序列出每张画面的要点，标注它对应的画面序号：
画面1：
- 标题：“1.1.2 理解支付渠道参数配置”
- 内容：解释闪聚支付平台作为中介，聚合微信、支付宝等第三方支付渠道，商户需在闪聚平台配置支付渠道参数。
- 图表：用户 → 聚合支付通道 → 闪聚支付平台 → 支付宝、微信支付、百度钱包等第三方支付渠道。

画面2：
- 标题：“一、整体流程如下：”
- 内容：1. 商户在支付宝、微信开通支付后，配置参数（包括AppID、密钥等）。
- 图表：展示AppID、支付宝网关、RSA2(SHA256)密钥、RSA(SHA1)密钥等参数。

画面3：
- 标题：“二、商户应该配置哪些第三方渠道的参数呢？”
- 内容：1. 首先理解服务类型，服务类型分为线上和线下两大类。
- 线上支付服务通道：手机APP支付、PC网页支付、手机网页支付、小程序支付。
- 线下支付服务通道：收款码支付(C扫B)、B扫C。

画面4：
- 标题：“三、总结”
- 内容：1. 应用创建成功后，自动跳转到绑定服务类型页面。
- 图表：展示“闪聚支付”后台界面，包括“应用管理”、“支付渠道管理”、“结算管理”等模块，以及“服务类型”、“支付渠道”、“支付参数”等配置项。

画面5：
- 标题：“三、总结”
- 内容：2. 点击开启服务为应用绑定服务类型。
- 图表：展示“闪聚支付”后台界面，包括“应用设置”、“服务类型”、“支付渠道”、“支付参数”等配置项。

画面6：
- 标题：“三、总结”
- 内容：3. 根据所绑定的服务类型，需要为应用配置支付渠道参数。
- 图表：展示“闪聚支付”后台界面，包括“应用”、“支付渠道参数”、“微信”、“支付宝”等模块，以及“手机网页支付”、“扫码支付”、“APP支付”、“H5支付”等支付方式。
