4) PPT 标题、架构图/流程图的结构（谁指向谁）、表格数据：
画面1、5、9、11、14：架构图/流程图结构：
- “浏览器/App” → “商户平台应用”（步骤1：输入手机号请求注册）
- “商户平台应用” → “商户服务”（步骤2：新增商户）
- “商户服务” → “SaaS平台”（步骤3：获取手机验证码）
- “SaaS平台” → “验证码服务”（步骤4：发送手机验证码）
- “验证码服务” → “商户服务”（步骤5：校验成功）
- “商户服务” → “浏览器/App”（步骤6：注册成功）
- “商户服务” → “SaaS平台”（步骤7：新增用户并初始化管理员）
- “SaaS平台” → “商户服务”（步骤8：更新商户下门店信息）
- “商户服务” → “SaaS平台”（步骤9：更新用户管理权限）

画面2、7、8：PPT文字内容：
- “商户平台应用”：提供商户信息管理、员工管理、门店管理等功能。
- “商户服务”：提供商户管理的相关服务接口，包括商户基本信息管理、资质申请、商户应用管理、渠道参数配置、商户员工信息管理、商户门店管理等。
- “SaaS平台”：闪聚支付项目是一个SaaS平台，所谓SaaS平台即多个用户用平台的业务功能，这样用户即可省去软件系统开发的成本，每个商户就是一个租户，所以又称为多租户系统。SaaS平台提供租户管理、账号管理、权限管理、资源管理、套餐管理、系统认证授权等功能。在上图商户注册的流程中，商户注册的账号等信息需要写入SaaS平台，由SaaS平台统一管理账号，分配权限，商户统一通过SaaS平台登录闪聚支付。
- “验证码服务”：提供获取短信验证码、校验验证码的接口。

画面12、13：PPT文字内容：
- “2.1.2 开发步骤”：
  1. 首先实现商户信息在商户服务注册成功（暂时不与SaaS平台交互）。
  2. 待商户信息注册成功，资质申请通过、支付参数配置完成再与SaaS平台进行对接。
  3. 与SaaS平台交互前需要部署SaaS平台，学习SaaS暴露的接口及认证接口，接通SaaS方可实现用户登录，这部分放在本书章节最后实现。
