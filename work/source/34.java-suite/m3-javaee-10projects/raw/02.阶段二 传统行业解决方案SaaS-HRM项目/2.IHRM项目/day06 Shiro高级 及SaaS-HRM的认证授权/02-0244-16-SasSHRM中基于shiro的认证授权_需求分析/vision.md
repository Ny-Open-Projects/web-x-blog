4) 出现的 PPT 标题、架构图/流程图的结构（谁指向谁）、表格数据也要写清楚：
PPT 标题：JWT 与 Shiro 认证授权方式对比。
左侧流程图（JWT 认证授权方式）：
- 前端浏览器 → 用户登录 → 系统微服务 → 认证通过 → 生成 token → 返回 token 信息。
- 前端浏览器 → 获取企业信息 → 请求头 + 白色 token → 企业微服务 → 解析 token → 校验操作权限。
右侧流程图（Shiro 认证授权方式）：
- 前端浏览器 → 用户登录 → 系统微服务 → 增加安全数据 → SHIRO 会话管理 → Redis 服务。
- 前端浏览器 → 获取企业信息 → 请求头包含 sessionid → 企业微服务 → 获取安全数据。
- SHIRO 会话管理 → 指向两个 Realm 域。
- 两个 Realm 域 → 指向 SHIRO 会话管理。
下方列表：
1. 搭建环境
2. 登录改造
3. 自定义 realm
4. 自定义会话管理器
