- 画面7、8、9、13、14：展示数据库表结构图。
  - 表结构：
    - 用户表：
      - 用户ID varchar(64) pk
      - 用户名 varchar(40)
    - 角色表：
      - 角色ID varchar(64) pk
      - 角色名 varchar(40)
    - 权限表：
      - 权限标识 varchar(64) pk
      - 权限名称 varchar(40)
    - 用户关联角色表：
      - 用户ID varchar(64) <1>+
      - 角色ID varchar(64) <1>+
    - 角色权限关联表：
      - 角色ID varchar(64) <1>+
      - 权限ID varchar(64) <1>+
  - 外键关系：
    - 用户表 → 用户关联角色表：FK_USER_ROLE
    - 角色表 → 用户关联角色表：FK_ROLE_USER
    - 角色表 → 角色权限关联表：FK_ROLE_PERMISSION
    - 权限表 → 角色权限关联表：FK_PERMISSION_ROLE
  - 底部文字：一个用户拥有若干角色，每一个角色拥有若干权限。这样，就构成“用户-角色-权限”的授权模型。在这种模型中，用户与角色之间，角色与权限之间，一般者是多对多的关系。
