1) 这一组画面整体在讲什么（一句话）：
讲解数据可视化的步骤，包括定义问题、确定数据、确定维度、确定图表类型等核心环节。

2) 按时间顺序列出每张画面的要点，标注它对应的画面序号：
画面1：
- 标题：4 怎样进行数据可视化
- 内容：展示数据可视化的流程图，包含 Data → filtering → Visual Form → rendering → View → User 等环节。
- 文字说明：数据可视化过程可以分为下面几个步骤：
  1. 定义要解决问题
  2. 确定要展示的数据和数据结构
  3. 确定要展示的数据的维度（字段）
  4. 确定使用的图表类型
  5. 确定图表的交互

画面2：
- 标题：4.1 定义问题
- 内容：解释数据可视化的首要目的是让用户看懂数据、理解数据，因此需要先定义要解决的问题。
- 示例：我想看过去两月销售额的变化，是增长了还是下跌了，什么原因导致的？
- 提示：可以从趋势、对比、分布、流程、时序、空间、关联性等角度来定义自己要解决的问题。

画面3：
- 标题：4.2 确定要展示的数据
- 内容：进行数据可视化首先要有效数据，由于画布大小的限制，过量的数据不能够在直接显示出来，所以要确定展示的数据。
- 问题列表：
  1. 我要展示的数据是否已经加工？是否存在空值？
  2. 是列表数据还是图形数据？
  3. 数据的规模有多大？
  4. 是否要对数据进行聚合？是否要分层展示数据？
  5. 如何加载到页面？是否需要在前端对数据处理？

画面4：
- 标题：4.3 确定要显示的数据维度
- 内容：进行可视化时要对字段进行选择，选择不同的字段在后面环节中选择适合的图表类型也不同。
- 图表：展示“数据分类”的思维导图，包含“自然的分类方式”（名词、有序、间隔、比例）和“是否连续”（分类、有序、无序、数字、时间、对数）。

画面5：
- 标题：4.4 确定使用的图表类型
- 内容：有非常多的图表类型可以使用，但需要根据要解决的问题、数据的结构、选择的数据维度来确定要显示的图表类型。
- 图表：展示多种图表类型，包括柱状图、折线图、饼图、热力图、地图、散点图等。
