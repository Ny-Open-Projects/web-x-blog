画面10：
- 标题：4.4、获取管理员权限
- 内容：环信提供的 REST API 需要权限才能访问，权限通过发送 HTTP 请求来获取 token 来体现。说明：API 描述的时候使用到的 (APP 的 client_id) 之类的这些参数需要管理员权限。
- 重要提示：获取 token 的时候服务端会返回 token 有效期，具体参看返回的 expires_in 字段值。由于网络延迟原因，系统对 token 在此表示的有效期稍微有点误差，如果发现 token 使用异常请重新获取新的 token，比如 http response code 返回 401。另外，请不要频繁向服务端发送获取 token 的请求，同一账号发送此请求超过一定频率会导致服务端拒绝，切记，切记！！
- 说明：client_id 和 client_secret 可以在环信管理后台的 APP 详情页面看到。
