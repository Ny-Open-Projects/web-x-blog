画面 3: 在模拟器中点击屏幕底部的“电话”图标，弹出一个圆形拨号界面。

画面 8: 在桌面点击“Oracle VM VirtualBox”图标，打开虚拟机管理器，显示“CentOS 7.0 - 64位”虚拟机的配置信息。
