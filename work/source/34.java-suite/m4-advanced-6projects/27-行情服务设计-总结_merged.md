### 1) 视频摘要

本视频课程为技术实战教学，主要围绕“行情服务”的设计与实现展开。内容分为两大核心部分：

*   **第一部分：行情服务功能与数据库设计 (第3章)**。讲师首先介绍了行情服务的整体功能流程，强调其作为交易平台的核心角色，即对行情数据进行加工与代理转发。随后，重点讲解了数据库结构设计，针对海量行情数据（如K线、分时、报价）提出了分库分表的解决方案，并详细演示了在 PostgreSQL 中创建相关表结构的 SQL 语句。
*   **第二部分：PostgreSQL 服务端配置与安装 (第3章)**。讲师演示了如何在 CentOS 系统上安装 PostgreSQL 11.2，并进行服务端配置，包括修改监听地址、配置远程访问权限（`pg_hba.conf`），以及创建数据库用户和表结构。
*   **第三部分：课程总结与预告 (第4章)**。讲师对本章内容进行了总结，强调了理解逻辑流程和数据库结构的重要性，并预告了下一章将讲解 RocketMQ 的安装。

整个课程以实战为导向，通过 PPT 讲解、代码演示和数据库操作，系统地传授了构建高可用行情服务所需的技术栈。
