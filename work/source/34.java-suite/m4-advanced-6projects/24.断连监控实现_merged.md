    ```java
    @GetMapping("/findPage")
    public Pager<DeviceDTO> findPage(
        @RequestParam(value = "page", required = false, defaultValue = "1") Long page,
        @RequestParam(value = "pageSize", required = false, defaultValue = "10") Long pageSize,
        @RequestParam(value = "sn", required = false) String sn,
        @RequestParam(value = "tag", required = false) String tag
    ) {
        return deviceService.queryPage(page, pageSize, sn, tag, null);
    }
    ```
    *   **说明**：这是一个分页查询接口，接收 `page`、`pageSize`、`sn` 和 `tag` 四个参数，用于查询设备列表。

*   **代码片段 2 (DeviceController.java - PostMapping)**：
    ```java
    @PostMapping("/clientAction")
    ```
