### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **API文档 (YAPI)**：
    *   **接口路径**: `GET /task-service/task/userWorkTop10/start/end/isRepair/regionId`
    *   **请求参数**:
        *   `start`: 开始日期，示例 `2020-11-01`
        *   `end`: 结束日期，示例 `2020-11-31`
        *   `isRepair`: 是否为运维单，布尔值
        *   `regionId`: 区域ID
    *   **请求体 (Body)**: 无
    *   **响应数据**: 返回一个 `List<UserWork>` 对象列表。

*   **Java 代码**:
    *   **Service层 (`TaskService.java`)**:
        ```java
        List<UserWork> getUserWorkTop10(LocalDateTime start, LocalDateTime end, Boolean isRepair, Long regionId);
        ```
    *   **Service实现层 (`TaskServiceImpl.java`)**:
        ```java
        // 使用 QueryWrapper 构建查询条件
        QueryWrapper<TaskEntity> qw = new QueryWrapper<>();
        qw.select("count(user_id) as user_id", "user_name")
          .lambda()
          .between(TaskEntity::getUpdateTime, start, end)
          .eq(TaskEntity::getTaskStatus, VMSYSTEM_TASK_STATUS_FINISH)
          .groupBy(TaskEntity::getUserName)
          .orderByDesc(TaskEntity::getUserId)
          .last("limit 10");

        // 动态添加区域和运维单条件
        if (regionId != null && regionId > 0) {
            qw.lambda().eq(TaskEntity::getRegionId, regionId);
        }
        if (isRepair) {
            qw.lambda().eq(TaskEntity::getProductTypeId, VMSYSTEM_TASK_TYPE_SUPPLY);
        } else {
            qw.lambda().eq(TaskEntity::getProductTypeId, VMSYSTEM_TASK_TYPE_SUPPLY);
        }

        // 使用 Stream API 转换结果
        this.list(qw).stream().map(t -> {
            var userWork = new UserWork();
            userWork.setUserName(t.get("user_name"));
            userWork.setWorkCount(t.get("user_id"));
            return userWork;
        }).collect(Collectors.toList());
        ```
    *   **Controller层 (`TaskController.java`)**:
        ```java
        @GetMapping("/userWorkTop10")
        public List<UserWork> getUserWorkTop10(
            @RequestParam LocalDateTime start,
            @RequestParam LocalDateTime end,
            @RequestParam Boolean isRepair,
            @RequestParam Long regionId
        ) {
            return taskService.getUserWorkTop10(start, end, isRepair, regionId);
        }
        ```

*   **数据库查询语句 (最终生成)**:
    ```sql
    SELECT count(user_id) as user_id, user_name
    FROM task_entity
    WHERE update_time BETWEEN '2021-01-01 00:00:00' AND '2021-11-31 00:00:00'
      AND task_status = 'TASK_STATUS_FINISH'
      AND region_id = 1
      AND product_type_id = 'TASK_TYPE_SUPPLY'
    GROUP BY user_name
    ORDER BY user_id DESC
    LIMIT 10;
    ```
