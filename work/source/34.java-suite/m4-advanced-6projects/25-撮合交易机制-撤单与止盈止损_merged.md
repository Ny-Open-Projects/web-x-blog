        *   **止盈 (Stop-Profit/Stop Profit)**: 当股票到达某一价格且出现利润时，打算离场平仓，在目标价位挂单卖出就是止盈。

        *   **止损 (“割肉”)**: 当某一投资出现的亏损达到预定数额时，及时斩仓出局，以避免形成更大的亏损。
