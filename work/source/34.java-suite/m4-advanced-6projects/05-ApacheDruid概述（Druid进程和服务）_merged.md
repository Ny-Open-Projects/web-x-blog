    *   **部署架构说明**:
        *   `Master`: 运行 Coordinator 和 Overlord 进程，管理数据可用性和摄取。
        *   `Query`: 运行 Broker 和可选的 Router 进程，处理来自外部客户端的查询。
        *   `Data`: 运行 Historical 和 MiddleManager 进程，运行数据的采集以及存储所有历史查询数据负载。
