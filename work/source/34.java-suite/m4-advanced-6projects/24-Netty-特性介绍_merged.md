    *   **Netty 三大优势**: 1. 高并发；2. 高性能；3. 易封装。
    *   **BIO 与 NIO 的区别**: BIO 是阻塞 I/O，每个连接对应一个线程；NIO 是非阻塞 I/O，通过 Selector 实现单线程处理多连接。

        3.  **ChannelHandlerContext**: 用于传输业务数据。
        4.  **ChannelPipeline**: 用于保存处理过程需要用到的 ChannelHandler 和 ChannelHandlerContext。
