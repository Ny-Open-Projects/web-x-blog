### 1) 视频摘要

本视频课程主要讲解了如何在 Spring Cloud 微服务架构中，通过 **Spring Cloud Gateway** 作为统一的网关服务，实现对下游服务（如用户服务和认证服务）的访问控制与认证授权。课程重点演示了如何配置 Gateway 以代理 OAuth2 认证服务，并通过 Postman 工具模拟客户端获取访问令牌（Token）的过程。此外，课程还介绍了如何集成 **Druid** 数据库连接池监控，以便实时监控数据库的运行状态，从而在生产环境中快速定位和排查性能瓶颈。

### 4) 关键场景与演示描述

*   **场景一：Gateway 服务启动与路由配置**
    *   **演示**: 讲师在 IDE 中展示 `StockGatewayApplication.java` 的启动类代码，确认其为 Spring Boot 应用。随后，通过 `application.yml` 文件展示 Gateway 的路由配置，明确将 `/user` 路径转发至用户服务，将 `/oauth` 路径转发至认证服务。
    *   **目的**: 验证 Gateway 服务已成功启动，并理解其路由转发机制。

*   **场景二：通过 Postman 获取 OAuth2 Token**
    *   **演示**: 讲师在 Postman 中创建一个 POST 请求，目标地址为 `http://127.0.0.1:10680/oauth/token`。设置请求类型为 `Basic Auth`，并输入用户名和密码。发送请求后，成功获取到包含 `access_token`、`refresh_token` 和 `user_name` 等字段的 JSON 响应。
    *   **目的**: 演示如何通过网关代理，成功获取到认证服务颁发的访问令牌，这是后续访问受保护资源的前提。

*   **场景三：使用 Token 访问用户服务**
    *   **演示**: 讲师在 Postman 中创建一个新的请求，目标地址为 `http://127.0.0.1:10680/user/userLogin`。在请求头中设置 `Authorization` 为 `Bearer Token`，并粘贴上一步获取的 `access_token`。发送请求后，成功返回用户登录信息的 JSON 数据。
    *   **目的**: 验证网关能够成功将带有 Token 的请求转发至用户服务，并成功返回数据，证明整个认证和访问流程是完整的。

*   **场景四：Druid 数据库监控**
    *   **演示**: 讲师在浏览器中访问 `http://127.0.0.1:10681/druid/index.html`，进入 Druid 的监控页面。在“WebApp Stat”页面中，展示了当前 Web 应用的请求次数、Session 数、SQL 执行次数等关键性能指标。
    *   **目的**: 展示如何通过 Druid 监控工具实时查看数据库连接池和 Web 应用的运行状态，为生产环境的性能优化和故障排查提供数据支持。
