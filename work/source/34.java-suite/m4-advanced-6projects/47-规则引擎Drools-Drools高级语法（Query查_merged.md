### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT / 文档内容**:
    *   **Drools 高级查询语法**：在 PPT 中明确指出，`query` 查询仅包含规则文件中的 LHS（左操作数）部分，不需要指定 `when` 和 `then` 部分，并以 `end` 结束。
    *   **具体语法结构**：
        ```drl
        query 查询的名称(可选参数)
        LHS
        end
        ```
    *   **示例代码**：
        ```drl
        // 不带参数的查询
        query "query_1"
        $s:Student(age == 50)
        end

        // 带参数的查询
        query "query_2"(String sname)
        $s:Student(age > 5 && name == sname)
        end
        ```

*   **代码关键内容**:
    *   **规则文件 `query.drl`**:
        ```drl
        package testquery
        import com.ithema.drools.entity.Student

        // 定义一个Query查询，可以到工作内存中查询符合条件的Fact对象
        query "query_1"
        $s:Student(age == 50)
        end

        // 定义一个Query查询，可以到工作内存中查询符合条件的Fact对象，带有查询参数
        query "query_2"(String sname)
        $s:Student(age > 5 && name == sname)
        end
        ```
    *   **Java 测试类 `DroolsTest.java`**:
        ```java
        // 根据名称调用规则文件中定义的查询
        QueryResults results = session.getQueryResults(query: "query_1");
        int size = results.size();
        System.out.println("符合条件的Fact对象个数：" + size);
        for (QueryResultsRow row : results) {
            Student s = (Student) row.get("$s");
            System.out.println(s);
        }

        // 激活规则，由Drools框架自动进行规则匹配，如果规则匹配成功，则执行当前规则
        session.fireAllRules();

        // 关闭会话
        session.dispose();
        ```
