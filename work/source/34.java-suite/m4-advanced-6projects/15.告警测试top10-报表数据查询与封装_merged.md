#### PPT / 文档内容

*   **API设计文档**：
    *   **路径 (Path)**: `/report/top10Alarm?startTime&endTime`
    *   **方法 (Method)**: `GET`

    *   **返回数据**: 一个 `object` 类型，包含 `deviceid`, `quotaId`, `quotaName`, `heapValue` 四个字段。

    *   展示设备指标名称（纵轴）和告警次数（横轴）的柱状图。
    *   按照告警次数从多到少排序。
*   **实现思路**：
    *   (1) 编写查询语句，实现异常次数Top10统计。
    *   (2) 定义InfluxDB中检索出的具体POJO类。
    *   (3) 在 `AlarmService` 接口定义获取Top10设备指标。
    *   (4) 在控制器中调用服务层方法。

#### 代码关键内容

*   **POJO 类 `HeapPoint`**：
    ```java
    @Data
    @Measurement(name = "quotas")
    public class HeapPoint {
        @Column(name = "deviceid")
        private String deviceId;
        @Column(name = "quotaId")
        private String quotaId;
        @Column(name = "quotaName")
        private String quotaName;
        @Column(name = "heapValue")
        private Long heapValue;
    }
    ```

*   **InfluxDB 查询语句**：
    ```sql
    select top(heapValue,deviceid,quotaId,quotaName,10) as heapValue
    from (
        select count(value) as heapValue from quota where alarm='1'
        and time>='2020-09-01' and time<='2020-09-30'
        group by deviceid,quotaId,quotaName
    ) order by desc
    ```
    *   **注释**：讲师特别指出，InfluxQL 中分组条件不需要像传统 SQL 那样写在 `select` 后面。

*   **服务层 `ReportServiceImpl.java`**：
    ```java
    @Override
    public List<HeapPoint> getTop10Alarm(String startTime, String endTime) {
        StringBuilder ql = new StringBuilder("select top(heapValue,deviceid,quotaId,quotaName,18) as heapValue ");
        ql.append("from (select count(value) as heapValue from quota where alarm='1' ");
        ql.append("and time>='"+startTime+"' and time<='"+endTime+"'");
        ql.append("group by deviceid,quotaId,quotaName ) order by desc");
        List<HeapPoint> heapPointList = influxRepository.query(ql.toString(), HeapPoint.class);
        return heapPointList;
    }
    ```

*   **控制器层 `ReportController.java`**：
    ```java
    @GetMapping("/report/top10Alarm")
    public List<HeapPoint> getTop10Alarm(@RequestParam String startTime, @RequestParam String endTime) {
        return reportService.getTop10Alarm(startTime, endTime);
    }
    ```
