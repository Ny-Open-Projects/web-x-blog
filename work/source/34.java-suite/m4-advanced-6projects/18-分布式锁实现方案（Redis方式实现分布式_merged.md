### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT / 文档内容**:
    *   **章节标题**: `2.3 Redis实现分布式锁` 和 `2.3.1 版本一`。
    *   **核心概念**: Redis 实现分布式锁比较简单，就是调用 redis 的 `set` 命令设置值，能够设置成功则表示加锁成功，即获得锁，通过调用 `del` 命令来删除设置的键值，即释放锁。
    *   **加锁命令**: `set lock_key lock_value NX`
    *   **解锁命令**: `del lock_key`

*   **代码关键内容**:
    *   **Java 代码 (StockController.java)**:
        ```java
        @GetMapping("/stock")
        public String stock() {
            try {
                // 尝试获取锁
                boolean locked = redisTemplate.opsForValue().setIfAbsent("mylock", "mylock");
                if (locked) { // 获取到了分布式锁
                    int stock = Integer.parseInt(redisTemplate.opsForValue().get("stock"));
                    if (stock > 0) {
                        stock--;
                        redisTemplate.opsForValue().set("stock", stock + "");
                        System.out.println("库存扣减成功，剩余库存：" + stock);
                    } else {
                        System.out.println("库存不足！！！");
                    }
                    // 释放锁
                    redisTemplate.delete("mylock");
                } else {
                    System.out.println("没有获得锁，不能执行减库存操作...");
                }
            } catch (Exception ex) {
                System.out.println("争抢异常。");
            }
        }
        ```
