### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT / 文本内容**：
    *   **章节标题**：`4.4 Pattern模式匹配`。
    *   **核心概念**：`pattern` 的语法结构为 `绑定变量名:Object(字段约束)`。
    *   **绑定变量命名规范**：建议以 `$` 开头。
    *   **LHS 部分**：由一个或多个条件组成，条件称为 `pattern`。
    *   **Field约束部分**：需要返回 `true` 或 `false` 的 0 个或多个表达式。
    *   **匹配条件总结**：
        1.  工作内存中必须存在 `Order` 类型的 `Fact` 对象。
        2.  `Fact` 对象的 `originalPrice` 属性值必须小于 200。
        3.  `Fact` 对象的 `originalPrice` 属性值必须大于等于 100。
    *   **LHS 多模式连接**：多个 `pattern` 之间可以使用 `and` 或 `or` 进行连接，默认连接为 `and`。

*   **代码示例**：
    *   **规则二（初始版本）**：
        ```java
        rule "book_discount_2"
        when
            $order:Order(originalPrice < 200 && originalPrice >= 100)
        then
            $order.setRealPrice($order.getOriginalPrice() - 20);
            System.out.println("成功匹配到规则二，所购图书总价在100到200元的优惠20元");
        end
        ```
    *   **规则二（绑定变量作用于属性版本）**：
        ```java
        rule "book_discount_2"
        when
            $order:Order($op:originalPrice < 200 && originalPrice >= 100)
        then
            System.out.println("$op + $op");
            $order.setRealPrice($order.getOriginalPrice() - 20);
            System.out.println("成功匹配到规则二，所购图书总价在100到200元的优惠20元");
        end
        ```
    *   **规则二（多模式连接版本）**：
        ```java
        rule "book_discount_2"
        when
            $order:Order($op:originalPrice < 200 && originalPrice >= 100) and
            $customer:Customer(age > 20 && gender == 'male')
        then
            System.out.println("$op + $op");
            $order.setRealPrice($order.getOriginalPrice() - 20);
            System.out.println("成功匹配到规则二，所购图书总价在100到200元的优惠20元");
        ```
