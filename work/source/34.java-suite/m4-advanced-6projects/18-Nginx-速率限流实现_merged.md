### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT内容**:
    *   **漏桶算法示意图**: 图(a)展示了水从龙头匀速流入漏桶，再匀速流出；图(b)展示了主机如何通过漏桶控制网络流量。
    *   **Nginx限流配置说明**: 详细解释了 `limit_req_zone` 和 `limit_req` 指令的参数含义。
    *   **配置示例**: 展示了完整的Nginx限流配置代码。

*   **关键代码**:
    *   **`limit_req_zone` 配置**:
        ```nginx
        limit_req_zone $binary_remote_addr zone=contentRateLimit:10m rate=2r/s;
        ```
        *   `$binary_remote_addr`: 基于客户端IP进行限流。
        *   `zone=contentRateLimit:10m`: 定义一个名为 `contentRateLimit` 的内存共享区域，大小为10MB。
        *   `rate=2r/s`: 表示每秒最多允许2个请求。

    *   **`limit_req` 配置**:
        ```nginx
        limit_req zone=contentRateLimit burst=4 nodelay;
        ```
        *   `zone=contentRateLimit`: 指定使用上面定义的共享内存区域。
        *   `burst=4`: 允许在超过速率限制的情况下，额外处理4个请求。
        *   `nodelay`: 表示在处理突发请求时，不延迟，立即处理。

    *   **完整配置示例**:
        ```nginx
        # 配置共享内存区
        limit_req_zone $binary_remote_addr zone=contentRateLimit:10m rate=2r/s;

        # 在server块中应用限流
        server {
            listen 80;
            server_name localhost;

            # 对 /web/items/ 路径应用限流
            location /web/items/ {
                limit_req zone=contentRateLimit burst=4 nodelay;
                content_by_lua_file /usr/local/openresty/nginx/lua/items-access.lua;
            }
        }
        ```
