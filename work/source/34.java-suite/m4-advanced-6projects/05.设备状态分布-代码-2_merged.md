### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT / 文档内容**:
    *   **API 定义**: 路径 `/report/statusCollect`，方法 `GET`。
    *   **返回数据格式**: 一个包含 `name` (string, 必填) 和 `value` (number, 必填) 字段的 `object` 数组。
    *   **代码结构**: 展示了 Controller、Service、Repository 三层的代码组织结构。

*   **代码关键内容**:

    *   **`ReportController.java`**:
        ```java
        @RestController
        @RequestMapping("/report")
        public class ReportController {
            @Autowired
            private ReportService reportService;

            @GetMapping("/statusCollect")
            public List<PleVO> getStatusCollect() {
                return reportService.getStatusCollect();
            }
        }
        ```

    *   **`ReportService.java`**:
        ```java
        @Service
        public class ReportService {
            @Autowired
            private ESRepository esRepository;

            public List<PleVO> getStatusCollect() {
                Long allDeviceCount = esRepository.getAllDeviceCount();
                Long offlineCount = esRepository.getOfflineCount();
                Long alarmCount = esRepository.getAlarmCount();

                PleVO devicePie = new PleVO();
                devicePie.setName("正常设备");
                devicePie.setValue(allDeviceCount);

                PleVO offlinePie = new PleVO();
                offlinePie.setName("离线设备");
                offlinePie.setValue(offlineCount);

                PleVO alarmPie = new PleVO();
                alarmPie.setName("告警设备");
                alarmPie.setValue(alarmCount);

                List<PleVO> pieList = new ArrayList<>();
                pieList.add(devicePie);
                pieList.add(offlinePie);
                pieList.add(alarmPie);

                return pieList;
            }
        }
        ```

    *   **`ESRepository.java`**:
        ```java
        @Repository
        public interface ESRepository {
            Long getAllDeviceCount();
            Long getOfflineCount();
            Long getAlarmCount();
        }
        ```

            private String name;
            private Long value;

            // Getters and Setters
        }
