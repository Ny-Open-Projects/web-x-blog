    *   **方法描述**:
        *   `update` 方法：更新工作内存中的数据，并让相关的规则重新匹配。
        *   `insert` 方法：向工作内存中插入数据，并让相关的规则重新匹配。
    *   **代码示例**:
        *   `update` 方法示例：
            ```drl
            rule "要求Student的age小于10岁"
            when
                $s:Student(age < 10)
            then
                $s.setAge(15);
                update($s); // 更新数据，导致相关的规则会重新匹配
                System.out.println("规则: 要求Student的age小于10岁触发了...");
            end
            ```
        *   `insert` 方法示例：
            ```java
            Student student = new Student();
            student.setAge(5);
            kieSession.insert(student);
            kieSession.fireAllRules();
            ```

    *   **规则文件 (`student.drl`)**:
