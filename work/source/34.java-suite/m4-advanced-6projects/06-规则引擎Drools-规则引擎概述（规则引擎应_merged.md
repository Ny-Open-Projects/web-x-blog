- **2.4 Drools介绍**：
  - Drools 是由 **Boss** 组织提供的基于 **Java 语言** 开发的开源规则引擎。
  - 它可以将复杂的业务规则从硬编码中解放出来，以规则脚本的形式存储在文件或特定的存储介质中（如数据库）。
  - 业务规则的变更不需要修改项目代码，重启服务器即可在线上环境立即生效。
  - **Drools 源码下载地址**：`https://github.com/kiegroup/drools`
