    *   配置步骤：第一步导入依赖，第二步配置 `application.yml`，第三步重启 Zipkin。

*   **代码关键内容**:

    *   **`ZipkinSenderProperties.java` 中的 `SenderType` 枚举**：
        ```java
        public enum SenderType {
            // RabbitMQ sender.
            RABBIT,

            // Kafka sender.
            KAFKA,

            // HTTP based sender.
            WEB
        }
        ```
        *   该枚举定义了 Sleuth 支持的三种数据发送方式：`RABBIT`、`KAFKA`、`WEB`。

    *   **`application.yml` 配置文件**：
        ```yaml
        server:
          port: 9101
        spring:
          application:
            name: trace-1
        sleuth:
          sampler:
            probability: 1 # 这个是收集比例，1表示100%，全部收集
        zipkin:
          base-url: http://localhost:9411
          sender: rabbit
          type: rabbit
          rabbitmq:
            host: 68.79.7.219
            port: 5672
            username: admin
            password: admin@2020
            virtual-host: /
        ```
        *   `sleuth.zipkin.sender.type=rabbit`：指定使用 RabbitMQ 作为发送器。
        *   `sleuth.zipkin.base-url`：指定 Zipkin 服务的地址。
        *   `rabbitmq`：配置 RabbitMQ 的连接信息。

    *   **Maven 依赖**：
        ```xml
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-amqp</artifactId>
        </dependency>
        ```

    *   **启动 Zipkin 服务的命令**：
        ```bash
        java -jar zipkin-server-2.12.2-exec.jar --STORAGE_TYPE=mysql --MYSQL_HOST=127.0.0.1 --MYSQL_TCP_PORT=3306 --MYSQL_DB=zipkin --MYSQL_USER=root --MYSQL_PASS=root --RABBITMQ_ADDRESSES=68.79.7.219:5672 --RABBITMQ_USER=admin --RABBITMQ_PASSWORD=admin@2020 --RABBITMQ_VIRTUAL_HOST=/
        ```
        *   该命令用于启动 Zipkin 服务，并配置其使用 MySQL 作为存储，同时连接到指定的 RabbitMQ 服务器。
