*   **PPT 内容**:
    *   **章节标题**: “3.4 使用MySQL存储追踪信息”。
    *   **概念说明**:
        *   **Span**: 基本工作单元，发送一个远程调用会产生一个 Span，Span 是一个 64 位 ID 唯一标识的。
        *   **Trace**: 一系列 Span 组成的一个树状结构，一个 API 接口调用可能需要调用多个微服务。
        *   **Annotation**: 用来定义一个请求的开始和结束。
    *   **数据库表结构图**:
        *   `zipkin_annotations`: 包含 `trace_id_high`, `trace_id`, `span_id`, `a_key`, `a_value`, `a_type`, `a_timestamp` 等字段。
