### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT / 文档内容**:
    *   **章节标题**: `5.1.3 Nginx环境搭建`
    *   **核心说明**: “当文件存储策略为本地存储或者FastDFS存储时，需要使用Nginx服务来对外提供文件的下载和查看等功能。”
    *   **配置步骤**: “第一步：安装Nginx(略)”，“第二步：配置 Nginx_HOME/conf/nginx.conf 进行配置”。
    *   **关键配置块**: `#下面是server虚拟主机的配置 server #server标志定义虚拟主机开始`
    *   **关键指令与注释**:
        *   `listen 10000;`：用于指定虚拟主机的服务端口。
        *   `server_name localhost;`：用于指定虚拟主机的IP地址或者域名。
        *   `root D:\UploadFiles;`：用于指定虚拟主机的网页根目录。
        *   `location ~*.\.(gif|jpg|jpeg|png|bmp|swf|ico)$`：通过location指令来对网页URL进行分析处理，所有扩展名为.gif、.jpg、.jpeg、.png、.bmp、.swf、.ico的静态文件都会被处理。
        *   `expires 30d;`：用于指定静态文件的过期时间，这里是30天。
        *   `access_log logs/access.log main;`：用于指定此虚拟主机的访问日志存放路径。

*   **代码 (Nginx 配置文件)**:
    ```nginx
    #下面是server虚拟主机的配置
    server {
        listen 10000; #listen用于指定虚拟主机的服务端口
        server_name localhost; #server_name用来指定IP地址或者域名，多个域名之间用空格分开
        index index.html index.htm index.php; #index用于设定访问的默认首页地址
        root D:\UploadFiles; #root指令用于指定虚拟主机的网页根目录，这个目录可以是相对路径名，也可以是绝对路径名
        location ~*.\.(gif|jpg|jpeg|png|bmp|swf|ico)$ { #通过location指令来对网页URL进行分析处理，所有扩展名为.gif、.jpg、.jpeg、.png、.bmp、.swf、.ico的静态文件都会被处理
            expires 30d; #expires用来指定静态文件的过期时间，这里是30天
            access_log off; #access_log用来指定此虚拟主机的访问日志存放路径
        }
    }
    ```
