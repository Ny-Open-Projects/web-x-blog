### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

#### PPT / 文本内容

*   **章节标题**：`4.8 Drools内置方法`。
*   **核心概念**：
    *   规则文件的 `RHS` 部分的主要作用是通过插入、删除或修改工作内存中的 `Fact` 数据，来达到控制规则引擎执行的目的。
    *   `update` 方法：更新工作内存中的数据，并让相关的规则重新匹配。
    *   `retract` 方法：删除工作内存中的数据，并让相关的规则重新匹配。
    *   `insert` 方法：插入新的 `Fact` 到工作内存中。
*   **`salience` 属性说明**：用于设置当前规则的执行优先级，数值越大越优先执行，默认值为 0。

#### 代码内容

*   **`Student` 实体类 (Java)**：
    ```java
    package com.itheima.drools.entity;

    /**
     * 学生
     */
    public class Student {
        private int id;
        private String name;
        private int age;

        public int getId() {
            return id;
        }

        public void setId(int id) {
            this.id = id;
        }

        public String getName() {
            return name;
        }

        public void setName(String name) {
            this.name = name;
        }

        public int getAge() {
            return age;
        }

        public void setAge(int age) {
            this.age = age;
        }
    }
    ```

*   **`student.drl` 规则文件**：

    **规则 1: `update` 方法示例**
    ```drl
    rule "rule_student_age小于10岁"
    when
        $s : Student(age < 10)
    then
        $s.setAge(15); // 更新数据，导致相关的规则会重新匹配
        System.out.println("规则rule_student_age小于10岁触发");
    end
    ```

    **规则 2: `retract` 方法示例**
    ```drl
    rule "rule_student_age等于10岁时删除数据"
    /*
     * salience: 设置当前规则的执行优先级，数值越大越优先执行，默认值为0。
     * 因为当前规则的匹配条件和下面规则的匹配条件相同，为了保证先执行当前规则，需要设置优先级
     */
    salience 100
    when
        $s : Student(age == 10)
    then
        retract($s); // retract方法的作用是删除工作内存中的数据，并让相关的规则重新匹配。
    end
    ```
