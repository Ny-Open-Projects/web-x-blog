### 1) 视频摘要

本视频课程为“Drools 决策表实战”教学，主要演示如何在 Java 项目中使用 Drools 的决策表（Decision Table）功能。课程通过一个“个人所得税计算器”的示例，详细讲解了从创建 Maven 项目、引入依赖、编写 Excel 格式的决策表、编译决策表为 DRL 代码、到在 Java 中加载并执行规则的完整流程。视频重点在于展示如何将业务规则从业务人员熟悉的 Excel 表格形式，转换为可执行的程序代码，并通过单元测试验证其功能。
