### 1) 视频摘要

本视频是关于 **Drools 规则引擎** 的高级语法教学。讲师通过 IntelliJ IDEA 开发环境，结合 PPT 讲解和代码演示，系统地介绍了 Drools 中的关键概念和用法。主要内容包括：

*   **`date-effective` 属性**：用于指定规则的生效时间，确保规则在特定时间点后才被激活。
*   **`global` 全局变量**：用于在规则文件中定义可被 Java 代码访问的变量，实现规则与业务逻辑的交互。
*   **`query` 查询**：用于在规则文件中定义查询，以便在 Java 代码中调用。
*   **`function` 自定义函数**：用于在规则文件中调用 Java 方法。
*   **`LHS` 和 `RHS` 加强**：用于增强规则的匹配和执行能力。
*   **`halt`、`getWorkingMemory`、`getRule` 等**：用于控制规则的执行流程和获取规则信息。

讲师通过编写和调试规则文件（`.drl`）以及对应的 Java 测试类（`DroolsTest.java`），演示了如何在实际项目中应用这些高级语法。

### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

#### PPT 关键内容

*   **章节标题**：`6. Drools高级语法`，下设子章节 `6.1 global全局变量`、`6.2 query查询`、`6.3 function函数`、`6.4 LHS加强`、`6.5 RHS加强`、`6.6 halt`、`6.7 getWorkingMemory`、`6.8 getRule`。
*   **`global` 关键字说明**：
    *   用于在规则文件中定义全局变量。
    *   语法结构：`global 对象类型 对象名称`。
    *   使用注意事项：
        1.  如果对象类型为包装类型（如 `Integer`），在一个规则中改变其值，只对当前规则有效，对其他规则中的全局变量无影响。
        2.  如果对象类型为集合类型或 JavaBean，在一个规则中改变了全局变量的值，对 Java 代码和所有规则都有效。
*   **`date-effective` 属性说明**：
    *   用于指定当前规则的生效时间。
    *   语法结构：`date-effective "YYYY-MM-DD HH:mm:ss"`。
*   **`query` 查询说明**：
    *   用于在规则文件中定义查询。
    *   语法结构：`query 查询名`。
*   **`function` 函数说明**：
    *   用于在规则文件中定义函数。
    *   语法结构：`function 返回类型 函数名(参数列表)`。
*   **`LHS` 和 `RHS` 加强说明**：
    *   `LHS` 加强：用于增强规则的匹配能力。
    *   `RHS` 加强：用于增强规则的执行能力。
*   **`halt` 关键字说明**：
    *   用于在规则匹配成功后，立即停止规则的执行。
*   **`getWorkingMemory` 方法说明**：
    *   用于获取当前规则引擎的工作内存。
*   **`getRule` 方法说明**：
    *   用于获取当前规则引擎中的规则。
