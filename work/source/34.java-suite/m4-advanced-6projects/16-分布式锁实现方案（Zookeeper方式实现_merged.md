### 1) 视频摘要

本视频演示了一个基于 Spring Boot 的分布式库存扣减系统，核心目的是展示如何使用 `InterProcessMutex`（一个基于 Curator 的分布式锁）来解决高并发场景下的“超卖”问题。视频通过修改锁的等待超时时间（`acquire(time: 2, TimeUnit.SECONDS)`）来对比不同情况下的系统表现：当库存充足时，系统能成功扣减并正确递减库存；当库存不足时，系统会拒绝操作并打印错误信息。演示中还展示了在没有获取到锁的情况下，系统如何优雅地处理并发冲突，避免了数据不一致。
