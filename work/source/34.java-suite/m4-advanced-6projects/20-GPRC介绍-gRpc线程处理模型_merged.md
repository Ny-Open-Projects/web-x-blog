### 1) 视频摘要

本视频片段来自一个关于 gRPC 技术的教程，主要讲解 gRPC 的线程模型。讲师通过对比 BIO（阻塞 I/O）和 NIO（非阻塞 I/O，Reactor 模式）两种模型，详细阐述了 gRPC 如何借鉴 Netty 的线程分工作原理来优化性能。核心内容包括：
- **gRPC 线程模型**：遵循 Netty 的线程分工原则，将协议层（I/O）和应用层（业务逻辑）处理分离。
- **BIO 模型**：使用线程池，但应用层处理是同步阻塞的，容易因业务处理耗时而阻塞 I/O 线程。
- **NIO (Reactor) 模型**：使用单线程或线程池的 Reactor 线程处理所有 I/O 事件，通过分发器（Dispatcher）将读写事件分发给不同的 Handler 处理，避免了阻塞。
- **讲师演示**：通过在 PPT 上拖动和修改图表，动态地展示了两种模型的结构和流程，重点强调了 Reactor 模式如何通过事件驱动避免阻塞。
