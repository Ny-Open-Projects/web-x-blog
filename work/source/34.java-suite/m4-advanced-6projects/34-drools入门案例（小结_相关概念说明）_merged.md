### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT / 图表**:
    *   **核心架构图**: 展示了 Drools 引擎的五个核心组件及其交互关系：
        *   `Rule Base` (规则库)
        *   `Working Memory` (工作内存)
        *   `Pattern Matcher` (匹配器)
        *   `Agenda` (议程)
        *   `Execution Engine` (执行引擎)
    *   **概念说明**:
        *   **Working Memory**: 规则引擎从这里获取数据并进行模式匹配。
        *   **Fact**: 插入到工作内存中的对象，是应用与引擎交互的桥梁。
        *   **Rule Base**: 存储规则文件定义的规则。
        *   **Pattern Matcher**: 将规则库中的规则与工作内存中的事实对象进行匹配。
        *   **Agenda**: 存储被匹配后激活的规则。
        *   **Execution Engine**: 执行议程中被激活的规则。

*   **代码**:
    *   **规则文件 (`Order.java`)**:
        ```java
        rule "book_discount_3"
        when
            $order:Order(originalPrice >= 200 && originalPrice < 300)
        then
            $order.setRealPrice($order.getOriginalPrice() - 50);
            System.out.println("成功匹配到规则三");
        end

        rule "book_discount_4"
        when
            $order:Order(originalPrice >= 300)
        then
            $order.setRealPrice($order.getOriginalPrice() - 100);
            System.out.println("成功匹配到规则四");
        end
        ```
    *   **主程序文件 (`DroolsTest.java`)**:
        ```java
        KieSession session = kieContainer.newKieSession();
        // Fact对象，事实对象
        Order order = new Order();
        order.setOriginalPrice(500);
        // 将Order对象插入到工作内存中
        session.insert(order);
        System.out.println("----优惠后价格：" + order.getRealPrice());
        // 激活规则，由Drools框架自动进行规则匹配，如果规则匹配成功，则执行当前规则
        session.fireAllRules();
        // 关闭会话
        session.dispose();
        System.out.println("优惠后价格：" + order.getRealPrice());
        ```
