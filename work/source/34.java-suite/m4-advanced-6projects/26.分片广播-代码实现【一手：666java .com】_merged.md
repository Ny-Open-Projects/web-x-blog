### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **关键代码片段**：
    ```java
    @XxlJob("supplyJobHandler")
    public Return<String> supplyJobHandler(String param) throws Exception {
        // 获取分片参数
        ShardingUtil.ShardingVo shardingVo = ShardingUtil.getShardingVo();
        int numbers = shardingVo.getTotal(); // 分片总数
        int index = shardingVo.getIndex();   // 当前分片索引

        // 获取告警阈值
        Integer percent = taskService.getSupplyAlertValue();

        // 构建查询条件
        QueryWrapper<VendingMachineEntity> qw = new QueryWrapper<>();
        qw.eq(VendingMachineEntity::getVStatus, VMSYSTEM_VM_STATUS_RUNNING);

        // 使用 Lambda 表达式对分片进行分组
        List<VendingMachineEntity> vmList = vmService.list(qw)
            .stream()
            .collect(Collectors.groupingBy(VendingMachineEntity::getInnerCode))
            .values()
            .stream()
            .flatMap(List::stream)
            .collect(Collectors.toList());

        // 遍历售货机列表
        vmList.forEach(vm -> {
            int count = vmService.inventory(percent, vm); // 检查库存
            if (count == 0) {
                XxlJobLogger.log("售货机" + vm.getInnerCode() + "缺货");
                vmService.sendSupplyTask(vm); // 发送补货任务
            }
        });

        return Return.SUCCESS;
    }
    ```

    *   **任务分发**：`vmService.sendSupplyTask(vm)` 用于向售货机 `vm` 发送补货任务。
