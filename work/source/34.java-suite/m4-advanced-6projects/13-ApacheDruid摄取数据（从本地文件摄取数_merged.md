### 4) 关键场景与演示描述

*   **场景一：访问 Druid 控制台并加载数据**
    *   **描述**: 讲师首先在浏览器中访问 Druid 控制台 (`http://druid服务ip:8888`)，并点击“Load data”进入数据加载页面。他展示了控制台的主界面，包括“Status”、“Data sources”、“Segments”、“Tasks”、“Data servers”等主要功能模块。
    *   **技术点**: 该场景演示了 Druid 控制台的用户界面和基本导航。

*   **场景二：配置数据源和预览数据**
    *   **描述**: 讲师在“Connect and parse raw data”页面，将文件路径设置为 `/tutorial/wikipedia-2015-09-12-sampled.json`，并点击“Preview”按钮。页面显示了数据的预览，包括时间戳、频道、城市、评论等字段。
    *   **技术点**: 该场景演示了如何指定数据源文件路径，并通过预览功能验证数据内容。

*   **场景三：配置数据模式**
    *   **描述**: 讲师切换到“Transform and configure schema”页面。他将“Query granularity”设置为 `HOUR`，并配置了维度和度量。页面提示“Each column in Druid must have an assigned type”，并提供了“Add dimension”和“Add metric”按钮。
    *   **技术点**: 该场景演示了如何定义数据的粒度和数据类型，这是 Druid 数据摄取的核心配置。

*   **场景四：提交任务并查询数据**
    *   **描述**: 讲师点击“Submit”按钮，任务被提交。随后，他切换到“Query”页面，执行 SQL 查询 `SELECT * FROM itcast`。查询结果以表格形式展示，包含时间、频道、城市、评论等字段。
    *   **技术点**: 该场景演示了如何提交数据摄取任务，并通过 SQL 查询验证数据是否成功加载。

*   **场景五：任务管理界面**
    *   **描述**: 讲师切换到“Tasks”页面，展示了任务管理界面。该界面列出了当前系统中的所有任务，包括任务名称、状态和操作按钮。
    *   **技术点**: 该场景演示了 Druid 的任务管理功能，用于监控和管理数据摄取任务。

*   **场景六：从 Kafka 摄取数据的介绍**
    *   **描述**: 讲师在 PPT 页面上介绍了从 Kafka 摄取数据的场景。他提到，数据加载器当前仅支持本地文件，但未来版本将支持 Kafka 和 AWS Kinesis。
    *   **技术点**: 该场景介绍了 Druid 支持的其他数据源类型，并指出了当前版本的限制。
