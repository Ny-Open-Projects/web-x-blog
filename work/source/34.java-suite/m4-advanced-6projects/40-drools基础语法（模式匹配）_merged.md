### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

#### **PPT / 文本内容**

*   **核心概念**：
    *   `pattern` 的语法结构：`绑定变量名:Object(字段约束)`。
    *   绑定变量名可以省略，建议以 `$` 开头。
    *   `Field约束部分` 需要返回 `true` 或 `false`。
    *   LHS 部分可以定义多个 `pattern`，默认用 `and` 连接。
*   **匹配条件总结**：
    1.  工作内存中必须存在 `Order` 类型的 `Fact` 对象（类型约束）。
    2.  `Fact` 对象的 `originalPrice` 属性值必须小于 200（属性约束）。
    3.  `Fact` 对象的 `originalPrice` 属性值必须大于等于 100（属性约束）。
    *   以上条件必须同时满足，规则才可能被激活。

#### **代码示例**

*   **规则二（初始版本）**：
    ```java
    //规则二，所购图书总价在100到200元的优惠20元
    rule "book_discount_2"
    when
        Sorder:Order(originalPrice < 200 && originalPrice >= 100)
    then
        Sorder.setRealPrice(Sorder.getOriginalPrice() - 20);
        System.out.println("成功匹配到规则二，所购图书总价在100到200元的优惠20元");
    end
    ```

*   **规则二（绑定变量在属性上）**：
    ```java
    //规则二，所购图书总价在100到200元的优惠20元
    rule "book_discount_2"
    when
        Sorder:Order($op:originalPrice < 200 && originalPrice >= 100)
    then
        System.out.println("$op=" + $op);
        Sorder.setRealPrice(Sorder.getOriginalPrice() - 20);
        System.out.println("成功匹配到规则二，所购图书总价在100到200元的优惠20元");
    end
    ```

*   **规则二（多模式示例）**：
    ```java
    //规则二，所购图书总价在100到200元的优惠20元
    rule "book_discount_2"
    when
        Sorder:Order($op:originalPrice < 200 && originalPrice >= 100) and
        $customer:Customer(age > 20 && gender=='male')
    then
        System.out.println("$op=" + $op);
        Sorder.setRealPrice(Sorder.getOriginalPrice() - 20);
        System.out.println("成功匹配到规则二，所购图书总价在100到200元的优惠20元");
    ```
