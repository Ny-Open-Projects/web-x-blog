### 1) 视频摘要

本视频是一个关于 **Drools 规则引擎** 的入门教程，通过一个“图书折扣”案例来演示如何在 Java 项目中使用 Drools。视频主要展示了如何创建一个简单的订单实体类 `Order`，以及如何在 `bookDiscount.drl` 规则文件中定义三条不同的折扣规则。规则根据订单的原始价格（`originalPrice`）分段应用优惠：低于 100 元无优惠，100-200 元优惠 20 元，200-300 元优惠 50 元。视频通过 IntelliJ IDEA 开发环境进行演示，同时辅以 PPT 讲义，内容涵盖了规则引擎的概念、应用场景以及 Drools 的基本语法。

        ```java
        public class Order {
            private Double originalPrice; // 订单原始价格
            private Double realPrice;     // 订单真实价格，即优惠后价格

            public String toString() {
                return "Order{" +
                        "originalPrice=" + originalPrice +
                        ", realPrice=" + realPrice +
                        '}';
            }

            public Double getOriginalPrice() {
                return originalPrice;
            }
        }
        ```
    *   **`bookDiscount.drl` 规则文件**:
        *   **规则一**:
            ```drl
            rule "book_discount_1"
            when
                $order: Order(originalPrice < 100)
            then
                $order.setRealPrice($order.getOriginalPrice());
                System.out.println("成功匹配到规则一");
            end
            ```
        *   **规则二**:
            ```drl
            rule "book_discount_2"
            when
                $order: Order(originalPrice >= 100 && originalPrice < 200)
            then
                $order.setRealPrice($order.getOriginalPrice() - 20);
                System.out.println("成功匹配到规则二");
            end
            ```
        *   **规则三**:
            ```drl
            rule "book_discount_3"

                $order: Order(originalPrice >= 200 && originalPrice < 300)
            ```
