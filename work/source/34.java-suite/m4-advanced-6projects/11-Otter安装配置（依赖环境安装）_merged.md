        *   **架构图**: 描述了 Otter 系统的典型架构，包含 `manager`（web管理）、`node`（工作节点）、`zookeeper`（协调）和 `db`（数据源）。
        *   **说明**:
            *   `db`: 数据源以及需要同步到的库。
            *   `Canal`: 获取数据库增量日志，支持独立部署和内嵌模式。
            *   `manager`: 配置同步规则，设置数据源同步等。
            *   `zookeeper`: 协调 `node` 进行协调工作。
            *   `node`: 负责任务处理，根据任务配置对数据源进行解析并同步到目标数据库。
        *   **原理描述**: 基于 Canal 的开源产品，获取数据库增量日志数据。典型管理系统架构：`manager (web管理) + node (工作节点)`。
