    *   **生成任务编号**:
        ```java
        private String generateTaskCode() {
            String date = LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyyMMdd")); // 日期部分
            String key = "task.task.code"; // Redis key
            Object obj = redisTemplate.opsForValue().get(key);
            if (obj != null) {
                redisTemplate.opsForValue().set(key, value, 1L, Duration.ofDays(1)); // 设置过期时间
                return date + redisTemplate.opsForValue().increment(key, 1L).toString(); // 拼接并返回
            }
            return date + "0001"; // 初始值
        }
        ```
    *   **创建任务**:
        ```java
        @Transactional(rollbackFor = {Exception.class}, noRollbackFor = {LogicException.class})
        public boolean createTask(TaskViewModel taskViewModel) throws LogicException {
            TaskEntity taskEntity = new TaskEntity();
            taskEntity.setTaskCode(generateTaskCode()); // 设置任务编号
            taskEntity.setTaskStatus(VMSystem.TASK_STATUS_CREATING);
            taskEntity.setProductType(taskViewModel.getProductType());
            taskEntity.setUserName(userService.getUserById(taskViewModel.getInnerCode()).getUserName());
            taskEntity.setAddr(vInfo.getAddr());
            this.save(taskEntity); // 保存任务
            // 为每个任务详情创建记录
            taskDetailsService.saveDetails(taskEntity.getId(), taskViewModel.getDetails());
            return true;
        }
        ```
