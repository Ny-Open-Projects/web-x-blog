### 1) 视频摘要

本视频片段是关于“数据聚合服务开发”课程中“Canal安装与配置”部分的教学内容。讲师通过在终端（Terminal）中操作 Docker 容器，演示了如何安装并配置 Canal 服务以作为 MySQL 的从库（slave），从而实现数据同步。核心步骤包括：启动 MySQL 容器、在容器内安装 vim 工具、修改 MySQL 配置文件以启用二进制日志（binlog）并设置为 ROW 模式、重启 MySQL 服务、创建 Canal 专用的数据库用户，并最终启动 Canal 服务端容器。整个过程旨在为后续的数据同步任务（如使用 Otter）做准备。

### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT / 文档内容**:
    *   **章节标题**: “1.5 canal安装”。
    *   **关键步骤**:
        *   创建 MySQL 容器：`docker run -d --name canal_mysql -v /mnt/canal_mysql:/var/lib/mysql -p 3306:3306 -e MYSQL_ROOT_PASSWORD=123456 mysql:5.7`
        *   安装 vim：在容器内执行 `apt-get update && apt-get install vim -y`。
        *   修改 MySQL 配置：在 `/etc/mysql/mysql.conf.d/mysqld.cnf` 中添加：
            ```latex
            log-bin=mysql-bin
            binlog-format=ROW
            server_id=1
            ```
        *   重启 MySQL：`docker restart canal_mysql`
        *   创建 Canal 用户：`CREATE USER canal IDENTIFIED BY 'canal';`
        *   授予权限：`GRANT SELECT, REPLICATION SLAVE, REPLICATION CLIENT ON *.* TO 'canal'@'%';`
        *   刷新权限：`FLUSH PRIVILEGES;`
