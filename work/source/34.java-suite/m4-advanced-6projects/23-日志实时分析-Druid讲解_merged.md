### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT 标题**: `4.2 Apache Druid` -> `4.2.1 Apache Druid介绍`
*   **关键概念**:
    *   **OLTP (Online Transaction Processing)**: 传统的数据库应用，面向操作人员，支持日常事务处理。
    *   **OLAP (Online Analytical Processing)**: 数据仓库的主要应用，面向决策人员，支持复杂的分析和决策。
*   **关键对比表格：OLTP 与 OLAP 区别**

    | 维度 | OLTP | OLAP |
    | :--- | :--- | :--- |
    | **用户** | 面向操作人员，支持日常操作 | 面向决策人员，支持管理需要 |
    | **功能** | 日常操作处理 | 分析决策 |
    | **DB 设计** | 面向应用，事务驱动 | 面向主题，分析驱动 |
    | **数据** | 当前的，最新的细节的 | 历史的，聚集的，多维的，集成的，统一的 |
    | **存取** | 可更新，读/写数十条记录 | 不可更新，但周期性刷新，读上百万条记录 |
    | **工作单位** | 简单的事务 | 复杂的查询 |
    | **DB 大小** | 100MB-GB | 100GB-TB |

*   **关键特性列表**:
    *   支持高吞吐实时数据摄入。
    *   支持复杂聚合函数（如 `count`, `sum`）及自定义 UDF。
    *   支持 `GroupBy`, `Select`, `Search` 查询。
    *   支持从 Kafka、HDFS、对象存储等数据源加载数据。
*   **性能对比表格：开源 OLAP 数据处理系统**

    | 系统 | 数据规模 | 查询效率 | 并发度 | SQL 支持 | 灵活性 |
    | :--- | :--- | :--- | :--- | :--- | :--- |
    | **Druid** | 超大 | 高 | 高 | 中 | 中 |
    | **Kylin** | 超大 | 高 | 高 | 低 | 高 |
    | **Elasticsearch** | 中等 | 中等 | 高 | 中 | 高 |
    | **Spark SQL** | 超大 | 低 | 低 | 高 | 高 |

*   **架构设计要点**:
    *   **Realtime Node**: 实时摄入数据，生成 Segment（LSM-Tree 实现）。
    *   **Historical Node**: 加载已生成的数据文件，提供查询服务。
    *   **Broker Node**: 对外提供查询服务，合并返回结果。
    *   **Coordinator Node**: 负责数据均衡和管理生命周期。
