### 1) 视频摘要

本视频演示了一个基于 Spring Boot 的 Java 后端项目如何与 EMQX MQTT 消息中间件进行集成，实现设备数据的订阅与处理。核心内容包括：
- **环境搭建**：在 IntelliJ IDEA 中配置并运行一个名为 `ykk-backend` 的 Spring Boot 项目。
- **MQTT 客户端配置**：在 `EmqClient.java` 中初始化 MQTT 客户端，连接到 EMQX 服务器，并订阅特定主题。
- **消息处理**：在 `EmqMsgProcess.java` 中定义 `messageArrived` 方法，用于接收并解析 MQTT 消息。
- **服务调用**：解析后的设备数据会通过 `quotaService` 和 `deviceService` 等服务进行业务处理。
- **前端测试**：使用 EMQX Dashboard 的 Websocket 功能模拟发送 MQTT 消息，验证后端接收和处理能力。
- **调试与验证**：通过控制台日志和 EMQX Dashboard 的消息列表，确认整个消息流转链路成功。

整个过程展示了从后端代码开发、服务部署到前端消息测试的完整闭环，是典型的物联网（IoT）后端开发演示。

### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

#### 代码关键内容：

*   **`EmqClient.java`**：
    ```java
    @PostConstruct
    public void init() {
        System.out.println("初始化方法，订阅主题");
        emqClient.connect();
        // 订阅所有主题
        quotaService.getAllSubject().forEach(s -> {
            try {
                emqClient.subscribe(topicName: "queue" + s);
            } catch (MqttException e) {
                e.printStackTrace();
            }
        });
    }
    ```

*   **`EmqMsgProcess.java`**：
    ```java
    @Override
    public void messageArrived(String topic, MqttMessage mqttMessage) throws Exception {
        String payloadName = mqttMessage.getPayload();
        System.out.println("接收到消息：" + payloadName);
        ObjectMapper mapper = new ObjectMapper();
        Map payloadMap = mapper.readValue(payload, Map.class);
        // 解析设备信息
        DeviceInfoDTO deviceInfoDTO = quotaService.analysis(topic, payloadMap);
        if (deviceInfoDTO != null) {
            // 调用设备服务保存设备信息
            deviceService.saveDeviceInfo(deviceInfoDTO.getDevice());
            // 调用配额服务保存配额列表
            quotaService.saveQuotaToInflux(deviceInfoDTO.getQuotaList());
        }
    }
    ```

    *   **技术点**：展示了 Spring Boot 的自动装配机制、MQTT 客户端的初始化和主题订阅模式。

    *   **描述**：讲师切换到 `EmqMsgProcess.java` 文件，展示 `messageArrived` 方法。该方法是 MQTT 客户端回调函数，当接收到消息时会被触发。方法内首先打印消息内容，然后使用 `ObjectMapper` 将 JSON 字符串反序列化为 `Map`，再调用 `quotaService.analysis()` 方法解析出 `DeviceInfoDTO` 对象。如果解析成功，会调用 `deviceService.saveDeviceInfo()` 和 `quotaService.saveQuotaToInflux()` 两个服务方法，分别保存设备信息和配额数据。
