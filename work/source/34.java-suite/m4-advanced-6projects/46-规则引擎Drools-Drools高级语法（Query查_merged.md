    **Java 代码 (DroolsTest.java):**

    ```java
    // 设置全局变量
    session.setGlobal(identifier: "count", value: 5);
    List<String> list = new ArrayList<String>();
    list.add("itheima");
    session.setGlobal(identifier: "gList", list);

    // 插入 Fact 对象
    Student s1 = new Student();
    s1.setAge(50);
    session.insert(s1);

    // 根据名称调用规则文件中定义的查询
    QueryResults results = session.getQueryResults(query: "query_1");
    int size = results.size();
    System.out.println("符合条件的Fact对象个数：" + size);

    // 遍历查询结果
    for (QueryResultsRow row : results) {
        Student s = (Student) row.get("$s");
        System.out.println(s);
    }

    // 激活规则
    session.fireAllRules();
    ```

    ```drl
    // 定义一个Query查询，可以得到工作内存中符合查询条件的Fact对象
    query query_1
        $s: Student(age = 50)
    end
    ```
