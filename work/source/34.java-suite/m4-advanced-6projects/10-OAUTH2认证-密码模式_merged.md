### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT 图表：密码模式 (3.9节)**
    *   **参与者**: Resource Owner (资源所有者), Client (客户端), Authorization Server (授权服务器)。
    *   **流程**:
        1.  Resource Owner 向 Client 提供 Password Credentials。
        2.  Client 将 Password Credentials 发送给 Authorization Server。
        3.  Authorization Server 验证凭据后，返回 Access Token (可选：Refresh Token) 给 Client。

*   **PPT 图表：简化模式 (3.8节)**
    *   **参与者**: Resource Owner, User-Agent, Authorization Server。
    *   **流程**:
        1.  User-Agent 向 Authorization Server 发起请求，包含 Client Identifier 和 Redirection URI。
        2.  Authorization Server 重定向 User-Agent 到授权页面。
        3.  User-Agent 在授权页面上认证。
        4.  User-Agent 被重定向回 Redirection URI，并附带 Access Token。

*   **代码示例：密码模式的令牌请求**
    ```http
    POST /token HTTP/1.1
    Host: server.example.com
    Content-Type: application/x-www-form-urlencoded

    grant_type=password
    &username={用户ID}
    &password={密码}
    &scope={授权范围}
    ```

*   **代码示例：密码模式的令牌响应**
    ```json
    {
      "access_token": "{访问令牌}",
      "token_type": "{令牌类型}",
      "expires_in": "{过期时间}",
      "refresh_token": "{刷新令牌}",
      "scope": "{授权范围}"
    }
    ```

*   **代码示例：简化模式的令牌请求**
    ```http
    POST /token HTTP/1.1
    Host: server.example.com
    Content-Type: application/x-www-form-urlencoded

    grant_type=implicit
    &response_type=token
    &client_id={客户端ID}
    &redirect_uri={重定向URI}
    &scope={授权范围}
    ```

*   **代码示例：简化模式的令牌响应**
    ```http
    HTTP/1.1 302 Found
    Location: https://example.com/callback#access_token={访问令牌}&token_type=Bearer&expires_in={过期时间}&scope={授权范围}
    ```

*   **场景一：密码模式流程演示**
    *   **描述**: 讲师在屏幕上展示“密码模式”的流程图。图中，资源所有者（Resource Owner）直接向客户端（Client）提供用户名和密码。客户端随后将这些凭据发送给授权服务器（Authorization Server）。授权服务器验证凭据后，返回访问令牌（Access Token）和可选的刷新令牌（Refresh Token）给客户端。
    *   **技术要点**: 该模式省略了“code”验证环节，直接返回令牌，简化了流程，但安全性较低。

    *   **技术要点**: 该模式通过重定向URI在浏览器中传递令牌，适用于前端应用，但令牌以明文形式存在于URL中，安全性较低。

    *   **技术要点**: 密码模式适用于高度信任的环境，如内部系统或客户端与服务器之间的直接通信。简化模式适用于前端应用，但令牌安全性较低。

    *   **技术要点**: 请求中必须包含 `grant_type=password`、`username` 和 `password` 参数。响应中包含 `access_token`、`token_type`、`expires_in`、`refresh_token` 和 `scope` 等字段。
