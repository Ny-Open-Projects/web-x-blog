### 1) 视频摘要

本视频片段展示了一个 Java 项目中，如何使用 Elasticsearch 的 `SearchRequest` 和 `QueryBuilder` API 来实现一个基于地理位置的自动售货机（Vending Machine）搜索功能。核心内容包括：

*   **构建复杂查询**：通过 `GeoDistanceQueryBuilder` 设置搜索范围和排序，通过 `BoolQueryBuilder` 添加必须满足的条件。
*   **执行搜索并处理结果**：调用 `esClient.search` 方法执行查询，并处理返回的 `SearchResponse`。
*   **结果转换与异常处理**：将搜索结果 `SearchHits` 转换为自定义的 `VmInfoDTO` 对象列表，并处理可能发生的 `IOException`。
*   **数据转换**：使用 `JsonUtil` 将搜索结果的 `_source` 字段反序列化为对象，并设置其属性（如距离、经纬度）。
*   **辅助方法**：演示了如何根据节点信息生成唯一的内部编码（InnerCode）。

整个过程体现了在 Spring Boot 项目中，如何集成 Elasticsearch 进行数据检索和业务逻辑处理。

### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **关键代码片段**：

    ```java
    // 构建搜索请求
    SearchRequest searchRequest = new SearchRequest("_index: "vm");
    SearchSourceBuilder sourceBuilder = new SearchSourceBuilder();

    // 构建地理距离查询
    GeoDistanceQueryBuilder geoDistanceQueryBuilder = new GeoDistanceQueryBuilder("location");
    geoDistanceQueryBuilder.distance(mSearch.getDistance(), DistanceUnit.DEFAULT);
    geoDistanceQueryBuilder.point(mSearch.getLat(), mSearch.getLon());
    geoDistanceQueryBuilder.order(SortOrder.ASC); // 按距离升序排序

    // 构建布尔查询
    BoolQueryBuilder boolQueryBuilder = new BoolQueryBuilder();
    boolQueryBuilder.must(geoDistanceQueryBuilder); // 必须满足地理距离条件

    // 应用查询和排序
    sourceBuilder.query(boolQueryBuilder);
    sourceBuilder.sort(geoDistanceSortBuilder);

    // 执行搜索
    SearchResponse searchResponse = esClient.search(searchRequest, RequestOptions.DEFAULT);

    // 处理结果
    SearchHits hits = searchResponse.getHits();
    if (hits.getTotalHits().value == 0) {
        return Lists.newArrayList();
    }

    List<VmInfoDTO> vmInfoList = Lists.newArrayList();
    Arrays.stream(hits.getHits()).forEach(h -> {
        try {
            VmInfoDTO vmInfo = JsonUtil.getJson(h.getSourceAsString(), VmInfoDTO.class);
            vmInfo.setDistance((int)h.getSortValues()[0]); // 设置距离
            vmInfo.setLongitude(h.getSortValues()[1]); // 设置经度
            vmInfo.setLatitude(h.getSortValues()[2]); // 设置纬度
            vmInfoList.add(vmInfo);
        } catch (IOException e) {
            e.printStackTrace();
        }
    });

    return vmInfoList;
    ```

*   **关键公式/概念**：

    *   **地理距离排序**：`GeoDistanceQueryBuilder.order(SortOrder.ASC)`，用于按距离升序排列结果。
    *   **布尔查询**：`BoolQueryBuilder.must(...)`，用于指定查询必须满足的条件。
    *   **搜索结果处理**：`SearchHits.getTotalHits().value` 获取总命中数，`hits.getHits()` 获取具体结果。
