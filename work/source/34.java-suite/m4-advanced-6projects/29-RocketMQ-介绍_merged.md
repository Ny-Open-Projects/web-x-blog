    *   **3.1.2 RabbitMQ物理架构**: 集群包含4个模块：NameSrv, Broker, Producer, Consumer。
    *   **3.1.3 RocketMQ术语解析**:
        *   **Producer**: 消息生产者，负责发送消息。
        *   **Consumer**: 消息消费者，负责消费消息。
        *   **Producer Group**: 发送同一类消息的多个生产者实例组成的组。
        *   **Consumer Group**: 消费同一类消息的多个消费者实例组成的组。
        *   **Topic**: 消息的逻辑分类，如订单Topic、库存Topic。
        *   **Message**: 消息的载体，必须指定topic。
        *   **Tag**: 对Topic的进一步细化，用于消息过滤。
        *   **Broker**: 消息中转角色，负责存储、转发消息，也称为Server。
    *   **3.2 下载**: RocketMQ 4.4.4安装包和RocketMQ Console控制台的下载链接。
