    ```java
    boolQuery.filter(QueryBuilders.rangeQuery("create_time").gte(start).lte(end));
    boolQuery.filter(QueryBuilders.termQuery("pay_status", VHSysten.PAY_STATUS_PAID));
    sourceBuilder.query(boolQuery);
    ```

*   **代码片段 2 (聚合配置)**：
    ```java
    AggregationBuilder regionAgg = AggregationBuilders.terms("region")
        .field("region_name")
        .subAggregation(AggregationBuilders.sum("amount_sum").field("amount"))
        .order(BucketOrder.aggregation(path: "amount_sum", asc: false))
        .size(30);
    sourceBuilder.aggregation(regionAgg);
    ```

*   **代码片段 3 (执行查询与结果处理)**：
    ```java
    SearchResponse searchResponse = esClient.search(searchRequest, RequestOptions.DEFAULT);
    Aggregations aggregations = searchResponse.getAggregations();
    if (aggregations == null) return result;
    var term = aggregations.get("region");
    var buckets = term.getBuckets();
    if (buckets.size() == 0) return result;
    buckets.stream().forEach(bucket -> {
        result.getAxis().add(bucket.getKeyAsString());
        Double value = bucket.getAggregations().get("amount_sum").getValue();
        result.getSeries().add(value);
    });
    ```

*   **代码片段 4 (控制器接口)**：
