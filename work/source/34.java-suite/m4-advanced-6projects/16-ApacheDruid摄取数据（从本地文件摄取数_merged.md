        ```json
        {
          "type": "index",
          "datasource": "mydatasource",
          "granularity": "all",
          "queryGranularity": "all",
          "dimensions": ["animal", "location", "triple-number"],
          "metrics": [
            {
              "type": "count",
              "name": "count"
            }
          ],
          "filter": {
            "type": "or",
            "fields": [
              {
                "type": "Selector",
                "dimension": "animal",
                "value": "super-mongoose"
              },
              {
                "type": "Selector",
                "dimension": "triple-number",
                "value": "300"
              },
              {
                "type": "Selector",
                "dimension": "location",
                "value": "3"
              }
            ]
          },
          "ioConfig": {
            "type": "index",
            "firehose": {
              "type": "local",
              "baseDir": "quickstart/tutorial",
              "filter": "transform-data.json"
            },
            "appendToExisting": false
          },
          "tuningConfig": {
            "type": "index",
            "maxRowsPerSegment": 5000000,
            "maxRowsInMemory": 25000
          }
        }
        ```
    *   **查询语句 (部分)**:
        ```sql
        SELECT * FROM (
          SELECT
            MILLIS_TO_TIMESTAMP(timestamp) AS ts,
            animal,
            location,
            triple-number,
            count
          FROM mydatasource
          WHERE ts > 1599999999999
        ) WHERE ts > 1599999999999
        ```

*   **公式 / 函数**:

    *   `Selector`: 用于在数据中选择特定维度值的过滤器。
    *   `or`: 逻辑“或”操作符，用于组合多个过滤条件。
