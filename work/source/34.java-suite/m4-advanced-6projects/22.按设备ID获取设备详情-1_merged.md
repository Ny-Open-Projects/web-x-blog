### 1) 视频摘要

本视频为一个技术教程，主要讲解如何在物联网（IoT）监控系统中，结合 **ElasticSearch** 和 **InfluxDB** 两个数据库，实现设备指标的持久化存储与查询。核心内容是通过 **ElasticSearch** 存储设备的最新状态（如“正常”或“温度过高”），并通过 **InfluxDB** 存储设备的详细指标数据（如温度、湿度的具体数值）。视频通过代码演示和命令行操作，展示了如何根据设备ID、标签和状态条件，从两个数据库中查询并返回设备的最新指标数据。整个系统旨在为前端页面提供实时、精准的设备状态和指标展示。

        ```java
        public Pager<DeviceDTO> searchDevice(Long page, Long pageSize, String deviceid, String tags, Integer state) {
            SearchRequest searchRequest = new SearchRequest("_index", "devices");
            SearchSourceBuilder sourceBuilder = new SearchSourceBuilder();
            BoolQueryBuilder boolQueryBuilder = QueryBuilders.boolQuery();
            if (!Strings.isNullOrEmpty(deviceid)) {
                boolQueryBuilder.must(QueryBuilders.wildcardQuery("name", "deviceid=" + deviceid));
            }
            if (!Strings.isNullOrEmpty(tags)) {
                boolQueryBuilder.must(QueryBuilders.wildcardQuery("tag", "tag=" + tags + "*"));
            }
            if (state != null) {
                if (state.intValue() == 1) {
                    boolQueryBuilder.must(QueryBuilders.termQuery("name", "status", true));
                } else if (state.intValue() == 0) {
                    boolQueryBuilder.must(QueryBuilders.termQuery("name", "online", false));
                }
            }
            sourceBuilder.query(boolQueryBuilder);
            searchRequest.source(sourceBuilder);
            return esClient.search(searchRequest, Pager.class);
        }
        ```
