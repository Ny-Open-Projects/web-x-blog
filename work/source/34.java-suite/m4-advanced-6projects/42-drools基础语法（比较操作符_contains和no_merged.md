*   **测试类 `DroolsTest.java`**：
    ```java
    import org.kie.api.runtime.KieSession;
    public class DroolsTest {
        @Test
        public void test20() {
            KieServices kieServices = KieServices.Factory.get();
            KieContainer kieContainer = kieServices.newKieClasspathContainer();
            KieSession session = kieContainer.newKieSession();
            // Fact对象，事实对象
            ComparisonOperatorEntity fact = new ComparisonOperatorEntity();
            fact.setNames("张三");
            List<String> list = new ArrayList<String>();
            list.add("张三");
            fact.setList(list);
            session.insert(fact);
            // 激活规则，由Drools框架自动进行规则匹配，如果规则匹配成功，则执行当前规则
            session.fireAllRules();
            // 关闭会话
            session.dispose();
        }
    }
    ```

### 4) 关键场景与演示描述

*   **场景 1: 创建实体类**
    *   讲师在 IntelliJ IDEA 中创建了一个名为 `ComparisonOperatorEntity` 的 Java 类。
    *   该类包含两个私有属性：`names` (String 类型) 和 `list` (List<String> 类型)，以及对应的 getter 和 setter 方法。
    *   该类用于存储测试规则所需的数据。

*   **场景 2: 编写规则文件**
    *   讲师在项目目录 `resources/rules/` 下创建了一个名为 `comparisonOperator.drl` 的文件。
    *   在该文件中，编写了两个规则：
        1.  **`rule_comparison_contains`**：当实体的 `names` 字段包含 `"张三"`，并且 `list` 字段也包含 `names` 的值时，触发规则并打印日志。
        2.  **`rule_comparison_notcontains`**：当实体的 `names` 字段不包含 `"张三"`，并且 `list` 字段也不包含 `names` 的值时，触发规则并打印日志。
    *   这两个规则用于演示 `contains` 和 `not contains` 操作符的用法。

*   **场景 3: 编写并运行测试用例**
    *   讲师在 `DroolsTest.java` 文件中编写了一个测试方法 `test20`。
    *   在方法中，首先获取了 `KieServices` 和 `KieContainer`，然后创建了一个 `KieSession`。
    *   创建了一个 `ComparisonOperatorEntity` 实例，并设置其 `names` 为 `"张三"`，`list` 为包含 `"张三"` 的列表。
    *   调用 `session.insert(fact)` 将事实对象插入会话。
    *   调用 `session.fireAllRules()` 激活并执行规则。
    *   最后调用 `session.dispose()` 关闭会话。
    *   视频画面显示了控制台输出，表明 `rule_comparison_contains` 规则成功触发。

*   **场景 4: 展示规则语法**
    *   在 PPT 中，讲师展示了 Drools 的规则语法，包括 `matches` 和 `not matches` 用于正则表达式匹配，以及 `Object(field matches "正则表达式")` 和 `Object(field not matches "正则表达式")` 的结构。
    *   这部分内容为后续学习更复杂的规则匹配提供了基础。
