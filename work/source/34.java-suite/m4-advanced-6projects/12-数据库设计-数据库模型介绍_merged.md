### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **核心概念与流程**：
    *   **数据库模型**：是数据库的基础，是对客观事物的符号表示，是现实世界的抽象。
    *   **数据模型类型**：主要包含概念数据模型、逻辑数据模型与物理数据模型。
    *   **数据库建模三步骤**：**概念模型 -> 逻辑模型 -> 物理模型**。
*   **概念模型**：
    *   定义：面向用户、面向现实世界，与DBMS无关，与业务相关，按用户观点建模。
    *   举例：金融交易中的概念包括“客户”、“股票”、“订单”、“持仓”等。
*   **逻辑模型**：
    *   定义：将概念模型具体化，是对概念模型的进一步细化。
    *   举例：客户信息包含“客户名称、客户账号、客户电话、客户地址”等属性；股票包含“股票代码、股票名称、股票市场、股票单位”等。
*   **物理模型**：
    *   定义：对真实数据库的描述，对数据做最低层的抽象，面向计算机系统。
    *   内容：涉及“表、视图、字段、数据类型、长度、主键、外键、索引、约束、是否可为空、默认值”等。
*   **总结**：
    *   概念模型：**是什么**（描述业务概念）。
    *   逻辑模型：**做什么**（定义数据结构和关系）。
    *   物理模型：**怎么做**（用SQL实现）。
