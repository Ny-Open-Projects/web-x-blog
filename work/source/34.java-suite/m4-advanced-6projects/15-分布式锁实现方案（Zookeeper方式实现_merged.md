### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **代码片段 (StockController.java)**:
    ```java
    @GetMapping("/stock")
    public String stock() {
        InterProcessMutex mutex = new InterProcessMutex(curatorFramework, path: "/mylock");
        try {
            boolean locked = mutex.acquire(0, TimeUnit.SECONDS);
            if (locked) {
                int stock = Integer.parseInt(redisTemplate.opsForValue().get("stock"));
                if (stock > 0) {
                    stock--;
                    redisTemplate.opsForValue().set("stock", stock + "");
                    System.out.println("库存扣减成功，剩余库存：" + stock);
                } else {
                    System.out.println("库存不足！！！");
                }
                // 释放锁
                mutex.release();
            } else {
                System.out.println("没有获得锁，不能执行减库存操作...");
            }
        } catch (Exception ex) {
            System.out.println("争抢锁异常...");
        }
        return "OK";
    }
    ```
