*   **流程图**:

        *   **K线数据**: 按产品 ID 分表，粒度精确到分钟。
        *   **分时数据**: 采用 HASH 分布，保留一天数据。
        *   **产品ID联表分表**: 用于关联查询。
        *   **摘要数据**: 存储开盘价和收盘价，便于结算。

*   **文字说明**:
    *   **核心设计思想**: 为应对海量数据和高并发，采用“缓存 + 数据分表”策略。
    *   **分表策略**: K线数据按产品ID分表，分时数据采用HASH分布。
    *   **核心数据处理**: 每天行情的开盘价和收盘价独立存储。
