*   **代码/命令**：
    *   **创建用户**：
        ```bash
        useradd -d /home/ceph_user -m ceph_user
        passwd ceph_user
        ```
    *   **设置 sudo 权限**：
        ```bash
        echo "ceph_user ALL = (root) NOPASSWD:ALL" | sudo tee /etc/sudoers.d/ceph_user
        sudo chmod 0440 /etc/sudoers.d/ceph_user
        ```
    *   **配置 SSH**：
        ```bash
        # ~/.ssh/config
        Host CENTOS7-1
        Hostname CENTOS7-1
        User ceph_user
        Host CENTOS7-2
        Hostname CENTOS7-2
        User ceph_user
        Host CENTOS7-3
        Hostname CENTOS7-3
        User ceph_user
        ```
    *   **关闭防火墙**：
        ```bash
        systemctl stop firewalld.service
        systemctl disable firewalld.service
        ```
    *   **禁用 SELinux**：
        ```bash
        setenforce 0
        # 永久生效
        vi /etc/selinux/config
        SELINUX=disabled
        ```
