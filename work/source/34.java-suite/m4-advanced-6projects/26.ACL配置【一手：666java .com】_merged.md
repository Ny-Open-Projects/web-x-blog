*   **PPT 文档内容**:

    *   **核心概念**: `HTTP 认证使用外部自建 HTTP 应用认证授权数据源，根据 HTTP API 返回的数据判定授权结果，能够实现复杂的 ACL 权限逻辑。`
    *   **插件说明**: `emqx_auth_http` 插件同时包含认证功能，可通过注释禁用。
    *   **状态码映射**:
        *   无权限: API 返回 4xx 状态码 (HTTP status code)
        *   授权成功: API 返回 200 状态码
        *   忽略授权: API 返回 200 状态码且消息体为 `ignore`

*   **代码配置文件 (`emqx_auth_http.conf`)**:
    *   **普通用户认证请求**:
        ```ini
        # Value: URL
        auth.http.req = http://192.168.200.1:8991/mqtt/auth
        # Value: post | get | put
        auth.http.req.method = post
        # Value: json | x-www-form-urlencoded
        auth.http.req.content_type = x-www-form-urlencoded
        # Value: Params
        auth.http.req.params = clientid=%c,username=%u,password=%P
        ```
    *   **超级用户认证请求**:
        ```ini
        # Value: URL
        auth.http.super_req = http://127.0.0.1:8991/mqtt/superuser
        # Value: post | get | put
        auth.http.super_req.method = post
        # Value: json | x-www-form-urlencoded
        auth.http.super_req.content_type = x-www-form-urlencoded
        # Value: Params
        auth.http.super_req.params = clientid=%c,username=%u
        ```
    *   **ACL 请求配置**:
        ```ini
        # Value: URL
        auth.http.acl_req = http://127.0.0.1:8991/mqtt/acl
        # Value: post | get | put
        auth.http.acl_req.method = get
        # Value: json | x-www-form-urlencoded
        auth.http.acl_req.content_type = x-www-form-urlencoded
        # Value: Params
        auth.http.acl_req.params = access=%A,username=%u,clientid=%c,ipaddress=%i,protocol=%P,topic=%t,mountpoint=%m
        ```
