### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

#### 代码关键内容

- **`DeviceController.java` 中的 `@PostMapping` 方法**：
  ```java
  @PostMapping("/clientAction")
  public void clientAction(@RequestBody Map<String, String> param) {
      System.out.println(param); // 打印接收到的参数
      String deviceId = param.get("clientId"); // 获取设备ID
      if (param.get("action").equals("client_connected")) { // 如果是连接事件
          deviceService.updateOnlineDeviceId(deviceId, online: true); // 更新设备为在线
      }
      if (param.get("action").equals("client_disconnected")) { // 如果是断开事件
          deviceService.updateOnlineDeviceId(deviceId, online: false); // 更新设备为离线
      }
  }
  ```
