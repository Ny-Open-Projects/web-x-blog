*   **技术要点**：讲师强调了漏桶算法的核心思想是“**匀速出水**”，即服务器的处理能力是恒定的，而不是根据请求量动态调整。这与令牌桶算法不同，令牌桶是“先发令牌，后处理”，而漏桶是“先接收请求，再处理”。
