### 1) 视频摘要

本视频为一个关于 **Apache Druid** 数据分析引擎的安装与配置实战教程。讲师通过在 Linux 服务器（终端）上进行一系列操作，演示了如何从零开始部署 Druid 的单节点（single-server）环境。整个过程涵盖了依赖服务（如 Kafka 和 ZooKeeper）的验证、Druid 软件包的下载与解压、核心配置文件的修改（包括主机名、ZooKeeper 地址、时区设置等），以及最终的启动脚本执行。视频内容以实操为主，旨在为学习者提供一个清晰、可复现的 Druid 环境搭建流程。

*   **章节 3: 配置文件修改 (1:30 - 3:00)**
    *   **内容**: 讲师通过 `vi` 编辑器修改了 Druid 的多个配置文件：

        *   **`/root/druid/conf/druid/single-server/small/coordinator-overlord/jvm.config`**: 同样设置了时区。

*   **章节 4: 启动 Druid 服务 (3:00 - 3:45)**
    *   **内容**: 讲师执行了启动脚本 `/root/druid/bin/start-single-server-small`，启动了 Druid 的所有组件（broker, coordinator, historical, router 等）。终端输出显示服务已成功启动。

*   **章节 5: 访问 Druid 服务 (3:45 - 结束)**
