### 1) 视频摘要

本视频课程主要讲解如何在 Nginx 服务器中，利用 Lua 语言（通过 OpenResty 框架）实现用户访问商品详情页的日志收集，并将这些日志数据实时发送到 Apache Kafka 队列中。课程内容围绕一个名为 `item-access.lua` 的 Lua 脚本展开，该脚本负责：
- 引入必要的 Lua 库（`cjson` 用于 JSON 处理，`resty.kafka.client` 和 `resty.kafka.producer` 用于 Kafka 操作）。
- 配置 Kafka 服务的地址和端口。
- 创建一个 Kafka 生产者。
- 从 HTTP 请求中提取关键信息（如用户 IP、请求时间、访问路径、认证 Token）。
- 将这些信息格式化为 JSON 消息。
- 使用 Kafka 生产者将消息发送到指定的 Kafka Topic。
- 最后，对原始请求进行重定向，将用户跳转到商品详情页。

整个过程展示了如何在 Web 服务器层实现日志的实时采集和传输，是典型的“日志收集”和“实时数据接入”场景。

*   **Lua 库文档**：展示了 `resty.kafka` 库的官方文档，说明了其功能和使用方法。

#### 代码关键内容

*   **Lua 脚本 `item-access.lua`**：
    ```lua
    local cjson = require "cjson"
    local client = require "resty.kafka.client"
    local producer = require "resty.kafka.producer"

    -- 配置 Kafka 服务地址
    local broker_list = {
        { host = "192.168.211.137", port = 9092 }
    }

    -- 创建 Kafka 生产者
    local bp = producer:new(broker_list, { producer_type = "async" })

    -- 获取请求信息
    local headers = ngx.req.get_headers()
    local ip = headers["X_FORWARDED_FOR"] or ngx.var.remote_addr or "0.0.0.0"

    -- 创建消息体
    local message = {
        actime = ngx.time(),
        uri = ngx.var.uri,
        ip = ip,
        token = "Bearer ITHEMAOPJAVAITCAST"
    }

    -- 发送消息
    local ok, err = bp:send("logitems", nil, cjson.encode(message))
    if not ok then
        ngx.say("Send error: ", err)
        return
    end

    -- 重定向到商品详情页
    ngx.redirect("/web/items/" .. ngx.var.uri)
    ```
