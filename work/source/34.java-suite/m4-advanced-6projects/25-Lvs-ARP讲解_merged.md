### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT 内容**:
    *   **章节标题**: “5.3.3 ARP配置（地址解析协议）”
    *   **关键概念**:
        *   `arp_ignore`: 控制系统在收到外部的 ARP 请求时，是否要返回 ARP 响应。取值 0 表示“只要本机配置了 IP，就能响应请求”。
        *   `arp_announce`: 控制系统在发送 ARP 请求时的行为。取值 2 表示“只在本网卡进行通告（推荐）”。
    *   **配置文件**: `/etc/sysctl.conf`
    *   **配置命令**: `sysctl -p`
    *   **路由命令**: `route add host 192.168.211.130 dev lo:1`

*   **代码/命令**:
    *   **安装软件**: `yum install ipvsadm`
    *   **查看 LVS 状态**: `ipvsadm -Ln`
    *   **配置文件内容**:
        ```
        net.ipv4.conf.all.arp_ignore = 1
        net.ipv4.conf.default.arp_ignore = 1
        net.ipv4.conf.lo.arp_ignore = 1
        net.ipv4.conf.all.arp_announce = 2
        net.ipv4.conf.default.arp_announce = 2
        net.ipv4.conf.lo.arp_announce = 2
        ```
    *   **应用配置**: `sysctl -p`
