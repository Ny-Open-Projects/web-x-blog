### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **代码关键内容**：
    *   **Java 类定义**：
        ```java
        package Monitor;

        import org.springframework.beans.factory.annotation.Autowired;
        import org.springframework.stereotype.Component;

        @Component
        public class Monitor {
            @Autowired
            private EmqClient emqClient;

            @PostConstruct
            public void init() {
                System.out.println("初始化方法，订阅主题");
                emqClient.connect();
                try {
                    emqClient.subscribe(topicName: "mytopic");
                } catch (MqttException e) {
                    e.printStackTrace();
                }
            }
        }
        ```
    *   **关键注解**：
        *   `@Component`：将 `Monitor` 类标记为 Spring 组件，使其能够被 Spring 容器管理。
        *   `@Autowired`：自动装配 `EmqClient` 类型的 Bean。
        *   `@PostConstruct`：在 Spring 容器完成 Bean 的初始化后，自动调用 `init()` 方法。
    *   **关键方法**：
        *   `emqClient.connect()`：连接到 MQTT 服务器。
        *   `emqClient.subscribe(topicName: "mytopic")`：订阅名为 `mytopic` 的 MQTT 主题。
        *   `e.printStackTrace()`：打印异常堆栈信息，用于调试。

*   **图表/界面关键内容**：
    *   **IntelliJ IDEA 控制台**：显示了 Spring Boot 应用的启动日志，包括服务注册、端口启动、数据库连接等信息。
    *   **EMQ X Web 管理界面**：
        *   **Overview 页面**：显示了 EMQ X 服务器的基本信息，如版本号、运行时长、节点状态等。
        *   **Websocket 页面**：用于配置和测试 MQTT 客户端连接，包含 Host、Port、Client ID、Topic 等字段。
