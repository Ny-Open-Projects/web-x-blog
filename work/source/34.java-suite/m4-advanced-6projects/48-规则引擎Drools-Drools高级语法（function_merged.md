### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT 内容**:
    *   **标题**: "6.3 function函数"
    *   **核心定义**: `function` 关键字用于在规则文件中定义函数，其作用类似于 Java 中的方法，可以将业务逻辑集中放置在一个地方，便于修改和复用。
    *   **语法结构**: `function 返回值类型 函数名(可选参数) { //逻辑代码 }`
    *   **操作步骤**:
        1.  编写规则文件 `/resources/rules/function.drl`。
        2.  在文件中定义函数。
        3.  在规则中调用函数。

*   **关键代码**:

    **在 `function.drl` 中定义函数**:
    ```drl
    package testfunction
    import com.ithema.drools.entity.Student

    // 定义一个函数
    function String sayHello(String name) {
        return "hello " + name;
    }
    ```

    **在 `function.drl` 中定义规则并调用函数**:
    ```drl
    // 定义一个规则，在规则中调用上面的函数
    rule "rule_function_1"
    when
        $s:Student(age > 60)
    then
        // 调用定义的函数
        String ret = sayHello($s.getName());
        System.out.println("调用sayHello函数，获得返回结果：" + ret);
    end
    ```

    **在 `DroolsTest.java` 中的测试代码**:
    ```java
    // 设置日期格式
    System.setProperty("drools.dateformat", "yyyy-MM-dd HH:mm");

    // 获取Kie容器对象
    KieServices kieServices = KieServices.Factory.get();
    KieContainer kieContainer = kieServices.newKieClasspathContainer();

    // 获取会话对象
    KieSession session = kieContainer.newKieSession();

    // 设置全局变量
    session.setGlobal("count", 5);
    List<String> list = new ArrayList<String>();
    list.add("itheima");
    session.setGlobal("gList", list);
    session.setGlobal("userService", new UserService());

    // 创建并插入Fact对象
    Student s1 = new Student();
    s1.setAge(60);
    s1.setName("张三");
    session.insert(s1);

    // 激活规则
    session.fireAllRules();

    // 关闭会话
    session.dispose();
    ```
