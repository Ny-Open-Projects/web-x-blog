### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **关键代码片段**：
    ```java
    private Result caculate(List<AgencyScopeDto> agencyList, String location) {
        Map<String, Double> agencyMap = Maps.newHashMap();
        for (AgencyScopeDto agencyScopeDto : agencyList) {
            for (List<Map> maps : agencyScopeDto.getMultiPoints()) {
                for (Map map : maps) {
                    String point = getPoint(map); // 获得坐标值
                    Double distance = EntCoordSyncJob.getDistance(point, location); // 调用百度地图工具类，计算两点之间的距离
                    Double preDistance = (Double) agencyMap.get(agencyScopeDto.getAgencyId());
                    if (preDistance == null || distance < preDistance) {
                        agencyMap.put(agencyScopeDto.getAgencyId(), distance);
                    }
                }
            }
        }
        return null;
    }
    ```

*   **关键方法和类**：
    *   `EntCoordSyncJob.getDistance(String point, String location)`: 用于计算两点间距离的工具类方法。
    *   `Maps.newHashMap()`: 用于创建一个 `Map<String, Double>` 来存储机构 ID 和其最近距离。
    *   `getPoint(Map map)`: 一个辅助方法，用于从 `Map` 中提取坐标值（如 `lng` 和 `lat`）。
    *   `AgencyScopeDto.getMultiPoints()`: 一个方法，返回一个 `List<List<Map>>`，其中每个 `Map` 包含一个坐标点的经纬度信息。

### 4) 关键场景与演示描述

*   **场景一：方法结构与循环嵌套**

    *   在内层循环中，开发者调用 `getPoint(map)` 方法从 `Map` 中提取坐标值。

*   **场景三：距离比较与更新**

*   **场景四：工具类调用与数据结构使用**
    *   视频中展示了如何使用 `EntCoordSyncJob` 这样的外部工具类来完成核心的地理计算。
