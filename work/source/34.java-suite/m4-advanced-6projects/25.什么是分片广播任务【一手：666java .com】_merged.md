### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **核心概念与图表**：
    *   **分片广播任务**：将一个任务拆分到多个执行器并行处理，以提高效率。
    *   **核心架构图**：
        *   **调度中心 (Scheduler Center)**：负责任务的分发和管理。
        *   **执行器 (Executor)**：实际执行任务的服务器节点。
        *   **注册中心 (Registry Center)**：用于执行器向调度中心注册。
        *   **业务数据 (Business Data)**：总数据量为 30000 条。
        *   **分片参数**：图中展示了三个执行器，分别处理不同的数据分片：
            *   执行器1：处理 1-10000 条数据，分片参数为 0.3。
            *   执行器2：处理 10001-20000 条数据，分片参数为 1.3。
            *   执行器3：处理 20001-30000 条数据，分片参数为 2.3。
        *   **分片广播流程**：调度中心根据分片参数，将任务分发给不同的执行器，每个执行器处理自己负责的数据范围。

*   **关键公式与算法**：
    *   **分页查询算法**：
        *   总页数 = 总记录数 / 分片数量
        *   每页大小 = 总记录数 / 总页数
        *   查询条件：`分页索引 = 当前分片索引`，`每页大小 = 当前分片大小`
    *   **取模运算算法**：
        *   查询条件：`mod(id, 总分片数) = 当前分片索引`
        *   例如，如果总分片数为3，当前分片索引为1，则查询条件为 `mod(id, 3) = 1`。

*   **代码与配置**：
    *   **任务配置**：
        *   `任务描述`：扫描售货机
        *   `运行模式`：Cron
        *   `JobHandler`：`supplyJobHandler`
        *   `路由策略`：`分片广播`
    *   **分片参数**：在任务配置中，需要设置分片总数和分片参数。
