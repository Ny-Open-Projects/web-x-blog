    ```java
    public Map calculateAmount(OrderDTO orderDTO) {
        // 计算订单距离
        orderDTO = this.getDistance(orderDTO);
        // 地址解析失败，直接返回
        if("sender_error_msg".equals(orderDTO.getSenderAddress()) || "receiver_error_msg".equals(orderDTO.getReceiverAddress())) {
            Map map = new HashMap();
            map.put("amount", "0");
            map.put("errorMsg", "无法计算订单距离和订单价格，请输入真实地址");
            map.put("orderDto", orderDTO);
            return map;
        }
        // 创建规则引擎会话
        KieSession session = kieContainer.newKieSession();
        // 设置Fact对象
        AddressRule addressRule = new AddressRule();
        addressRule.setTotalWeight(orderDTO.getOrderCargoDto().getTotalWeight().doubleValue());
        addressRule.setDistance(orderDTO.getDistance().doubleValue());
        // 将对象加入到工作内存
        session.insert(addressRule);
        // 触发所有规则
        int i = session.fireAllRules();
        System.out.println("触发了" + i + "条规则");
        // 判断规则匹配结果
        if(addressCheckResult.isPostCodeRule()) {
            System.out.println("规则匹配成功, 订单价格为：" + addressCheckResult.getResult());
            orderDTO.setAmount(new BigDecimal(addressCheckResult.getResult()));
        }
        session.destroy();
        return null;
    }
    ```

    该类用于封装规则匹配所需的数据，包含 `totalWeight` 和 `distance` 两个属性。

    该类用于存储规则匹配的结果，包含 `isPostCodeRule()` 方法和 `getResult()` 方法。

### 4) 关键场景与演示描述

*   **场景一：地址解析失败处理**
    *   **描述**：在 `calculateAmount` 方法中，首先调用 `getDistance` 方法获取订单距离。如果 `getSenderAddress()` 或 `getReceiverAddress()` 返回的值等于错误提示字符串（如 `"sender_error_msg"`），则创建一个 `Map` 对象，将订单金额设置为 `"0"`，并设置错误信息，最后返回该 `Map`。这体现了对异常情况的优雅处理。

*   **场景二：规则引擎初始化与Fact设置**
    *   **描述**：代码中通过 `kieContainer.newKieSession()` 创建了一个规则引擎会话。然后，创建了一个 `AddressRule` 对象，并通过 `setTotalWeight` 和 `setDistance` 方法设置其属性值。接着，调用 `session.insert(addressRule)` 将该对象插入到工作内存中，为规则匹配做准备。

*   **场景三：规则触发与结果处理**
    *   **描述**：调用 `session.fireAllRules()` 触发所有规则，并打印触发的规则数量。然后，通过 `addressCheckResult.isPostCodeRule()` 判断规则是否匹配成功。如果匹配成功，则调用 `addressCheckResult.getResult()` 获取计算出的价格，并通过 `orderDTO.setAmount(...)` 将价格更新到 `OrderDTO` 对象中。这展示了规则引擎如何根据业务规则动态计算结果。

    *   **描述**：在编写代码时，IDE 提供了智能提示，例如在 `equals` 方法后提示 `contains`、`startsWith` 等方法，以及在 `new AddressRule()` 后提示 `setTotalWeight` 和 `setDistance` 方法。这有助于开发者快速编写正确的代码。
