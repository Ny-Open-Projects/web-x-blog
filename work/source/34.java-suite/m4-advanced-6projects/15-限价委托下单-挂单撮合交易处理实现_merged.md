*   **`generateTradeDeal` 方法**:
    ```java
    private TradeDeal generateTradeDeal(TradeStockQuoteLast quoteLast, LimitPlaceOrderRequestVo request) {
        // 转换为报价深度
        Map<Long, Long> deepOffers = cvtDeepOffer(quoteLast, request.getDirection());
        // 计算公式：均价 = (档位1价格 * 档位1数量 + 档位n价格 * 档位n数量) / (档位1数量 + 档位n数量)
        long amount = 0;
        long volume = 0;
        long needVolume = request.getExecVolume();
        for (Map.Entry<Long, Long> deepOffer : deepOffers.entrySet()) {
            if (!checkMatchDeepPrice(request, deepOffer.getKey())) {
                continue;
            }
            if (needVolume <= deepOffer.getValue()) {
                amount += needVolume * deepOffer.getKey();
                volume += needVolume;
                needVolume = 0;
                break;
            } else {
                needVolume = needVolume - deepOffer.getValue();
                amount += deepOffer.getKey() * deepOffer.getValue();
                volume += deepOffer.getValue();
            }
        }
        // 返回生成的成交记录
        return new TradeDeal(amount, volume, ...);
    }
    ```

#### **公式**

*   **均价计算公式**:
    $$ \text{均价} = \frac{\sum_{i=1}^{n} (\text{档位}i\text{价格} \times \text{档位}i\text{数量})}{\sum_{i=1}^{n} \text{档位}i\text{数量}} $$

*   **买方向的更新成本价公式**:
    $$ \text{更新成本价} = \frac{(\text{持仓成本价} \times \text{持仓数量} + \text{本次成交均价} \times \text{本次成交数量})}{(\text{持仓数量} + \text{本次成交数量})} $$

*   **卖方向的更新成本价公式**:
    $$ \text{更新成本价} = \frac{(\text{持仓成本价} \times \text{持仓数量} - \text{本次成交均价} \times \text{本次成交数量})}{(\text{持仓数量} - \text{本次成交数量})} $$
