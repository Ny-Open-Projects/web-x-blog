*   **代码片段 1 (TaskCompletedMsgHandler.java)**:
    ```java
    @Override
    public void process(String jsonMsg) throws IOException {
        TaskCompleteContract taskCompleteContract = JsonUtil.getObj(jsonMsg, TaskCompleteContract.class);
        if (taskCompleteContract == null || Strings.isNullOrEmpty(taskCompleteContract.getInnerCode())) return;

        // 如果是投放工单，将售货机状态改为运行状态
        if (taskCompleteContract.getTaskType() == VMSYSTEM_TASK_TYPE_DEPLOY()) {
            vmService.updateStatus(taskCompleteContract.getInnerCode(), VMSYSTEM_VM_STATUS_RUNNING);
        }

        // 如果是撤销工单，将售货机状态改为撤销状态
        if (taskCompleteContract.getTaskType() == VMSYSTEM_TASK_TYPE_REVOKE()) {
            vmService.updateStatus(taskCompleteContract.getInnerCode(), VMSYSTEM_VM_STATUS_REVOKE);
        }
    }
    ```
