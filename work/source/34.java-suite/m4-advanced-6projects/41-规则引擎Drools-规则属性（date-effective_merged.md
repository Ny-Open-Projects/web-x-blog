### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

#### PPT 内容

*   **章节标题**: “5.10 date-expires属性”
*   **属性定义**: `date-expires` 属性用于指定规则的失效时间，即只有当前系统时间小于或等于设置的时间，规则才有可能触发。
*   **默认格式**: 默认日期格式为 `dd-MMM-yyyy`。
*   **注意事项**: 规则文件中的日期格式必须与程序中设置的格式一致，否则会导致规则不匹配。

#### 代码关键内容

*   **规则文件 `dateeffective.drl`**:
    ```drl
    package testdateeffective
    import java.text.SimpleDateFormat
    import java.util.Date

    rule "rule_dateeffective_1"
        date-effective "2020-10-10 10:00:00"  // 指定规则生效时间
        when
        then
            System.out.println("规则: rule_dateeffective_1触发了，触发的时间为：" + new SimpleDateFormat("yyyy-MM-dd HH:mm:ss").format(new Date()));
    end
    ```

*   **测试类 `DroolsTest.java`**:
