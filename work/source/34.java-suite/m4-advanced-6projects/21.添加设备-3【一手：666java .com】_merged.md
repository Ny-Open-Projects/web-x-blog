    ```java
    @Autowired
    private RestHighLevelClient restHighLevelClient;

    public void addDevices(DeviceDTO deviceDTO) {
        if (deviceDTO == null) return;
        IndexRequest request = new IndexRequest("devices");
        String json = JsonUtil.serialize(deviceDTO);
        Map<String, Object> map = JsonUtil.getJson(json, Map.class);
        request.source(map);
        request.id(deviceDTO.getDeviceId());
        restHighLevelClient.index(request, RequestOptions.DEFAULT);
    }
    ```
    *   **说明**：这是一个将 `DeviceDTO` 对象添加到名为 `devices` 的索引中的方法。它使用 `RestHighLevelClient` 发送一个 `IndexRequest`。
