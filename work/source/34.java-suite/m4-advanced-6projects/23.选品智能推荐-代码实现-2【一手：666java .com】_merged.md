### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **关键代码片段 (Elasticsearch 查询构建)**：
    ```java
    // 构建范围查询
    RangeQueryBuilder rangeQueryBuilder = QueryBuilders.rangeQuery(name: "update_time")
        .gte(LocalDateTime.now().plusMonths(-3).format(DateTimeFormatter.ISO_DATE_TIME))
        .lte(LocalDateTime.now().format(DateTimeFormatter.ISO_DATE_TIME));

    // 构建布尔查询
    BoolQueryBuilder boolQueryBuilder = QueryBuilders.boolQuery();
    boolQueryBuilder.must(rangeQueryBuilder);
    boolQueryBuilder.must(QueryBuilders.termQuery(name: "business_id", businessId));

    // 构建聚合
    AggregationBuilder orderAgg = AggregationBuilders.terms(name: "sku").field("sku_id")
        .subAggregation(AggregationBuilders.count(name: "count").field("sku_id"))
        .order(BucketOrder.aggregation(path: "count", asc: false))
        .size(10);

    // 构建搜索请求
    SearchRequest searchRequest = new SearchRequest();
    searchRequest.source().query(boolQueryBuilder);
    searchRequest.source().aggregation(orderAgg);
    ```

*   **关键代码片段 (处理聚合结果)**：
    ```java
    try {
        SearchResponse searchResponse = esClient.search(searchRequest, RequestOptions.DEFAULT);
        Aggregations aggregations = searchResponse.getAggregations();
        if (aggregations == null) return Lists.newArrayList();
        Terms terms = (Terms) aggregations.get("sku");
        List<Bucket> buckets = terms.getBuckets();
        return buckets.stream()
            .map(b -> b.getKeyAsString())
            .collect(Collectors.toList());
    } catch (IOException e) {
        e.printStackTrace();
    }
    return null;
    ```
