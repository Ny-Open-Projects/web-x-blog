        ```java
        public void addDevices(DeviceDTO deviceDTO) {
            if (deviceDTO == null) return;
            if (deviceDTO.getDeviceId() == null) return;
            IndexRequest request = new IndexRequest("devices");
            String json = JsonUtil.serialize(deviceDTO);
            Map map = JsonUtil.getObjByJson(json, Map.class);
            request.source(map);
            request.id(deviceDTO.getDeviceId());
            try {
                restHighLevelClient.index(request, RequestOptions.DEFAULT);
            } catch (JsonProcessingException e) {
                e.printStackTrace();
            } catch (IOException e) {
                e.printStackTrace();
                log.error("设备添加发生异常");
            }
        }
        ```
    *   **设备查询方法 (`searchDeviceById`)**:
        ```java
        public DeviceDTO searchDeviceById(String deviceId) {
            SearchRequest searchRequest = new SearchRequest("_index: devices");
            SearchSourceBuilder searchSourceBuilder = new SearchSourceBuilder();
            searchSourceBuilder.query(QueryBuilders.termQuery("_id", deviceId));
            searchRequest.source(searchSourceBuilder);
            try {
                SearchResponse searchResponse = restHighLevelClient.search(searchRequest, RequestOptions.DEFAULT);
                SearchHits hits = searchResponse.getHits();
                long hitCount = hits.getTotalHits().value;
                if (hitCount == 0) return null;
                DeviceDTO deviceDTO = null;
                for (SearchHit hit : hits) {
                    String hitResult = hit.getSourceAsString();
                    deviceDTO = JsonUtil.getObjByJson(hitResult, DeviceDTO.class);
                    deviceDTO.setDeviceId(deviceId);
                    break;
                }
                return deviceDTO;
            } catch (IOException e) {
                e.printStackTrace();
                log.error("设备查询发生异常");
                return null;
            }
        }
        ```
