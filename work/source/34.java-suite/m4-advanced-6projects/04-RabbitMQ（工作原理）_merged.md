该图是本视频的核心视觉元素，展示了消息从生产者到消费者的完整路径：

    *   每个生产者通过一个 `connection` 连接到 Broker。
    *   `connection` 下方是多个 `Channel`，用于实际的消息发送。

*   **中间：Broker (RabbitMQ)**
    *   一个紫色的矩形框，代表消息队列服务进程。
    *   内部包含两个核心组件：
        *   **Exchange (交换机)**：图中显示了两个 Exchange，它们是消息路由的决策点。
        *   **Queue (队列)**：图中显示了多个 Queue，用于存储消息。
    *   **数据流向**：
        1.  生产者通过 Channel 将消息发送到 Broker。
        2.  消息首先到达 Exchange。
        3.  Exchange 根据预设的路由规则，将消息转发到一个或多个 Queue。
        4.  消费者通过 Channel 从 Queue 中获取消息。

*   **右侧：消费者 (Consumer)**
    *   两个蓝色方块代表消息消费者。
    *   每个消费者通过一个 `connection` 连接到 Broker。

#### 文本：组成部分说明

画面下方的列表详细解释了架构图中的各个组件：

*   **Broker**: 消息队列服务进程，此进程包括两个部分：Exchange 和 Queue。
*   **Exchange**: 消息队列交换机，按一定的规则将消息路由转发到某个队列，对消息进行过滤。
*   **Queue**: 消息队列，存储消息的队列，消息到达队列并转发给指定的消费者。
*   **Producer**: 消息生产者，即生产方客户端，生产方客户端将消息发送到MQ。
*   **Consumer**: 消息消费者，即消费方客户端，接收MQ转发的消息。
