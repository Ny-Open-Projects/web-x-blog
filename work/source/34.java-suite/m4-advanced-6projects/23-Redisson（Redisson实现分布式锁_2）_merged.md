### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **代码片段 1 (StockController.java)**:
    ```java
    @GetMapping("/stock")
    public String stock() {
        RLock lock = redissonClient.getLock(name: "mylock"); // 获取锁对象
        try {
            lock.lock(leaseTime: 5000, TimeUnit.MILLISCONDS); // 尝试获取锁，租约5秒
            int stock = Integer.parseInt(redisTemplate.opsForValue().get("stock")); // 读取库存
            if(stock > 0) {
                stock--; // 库存减一
                redisTemplate.opsForValue().set("stock", stock+""); // 写回库存
                System.out.println("库存扣减成功，剩余库存：" + stock); // 输出成功信息
            } else {
                System.out.println("库存不足！！！"); // 输出不足信息
            }
        } catch (Exception ex) {
            System.out.println("争抢异常..."); // 捕获异常
        } finally {
            System.out.println("程序结束..."); // 最终输出
        }
    }
    ```

*   **关键概念**:
    *   **分布式锁**: 用于在分布式系统中保证对共享资源的互斥访问。
    *   **Redisson**: 一个用于在 Redis 上实现分布式锁的 Java 客户端库。
    *   **租约时间 (leaseTime)**: 锁的持有时间，防止死锁。
    *   **原子性**: 保证一系列操作要么全部成功，要么全部失败。
