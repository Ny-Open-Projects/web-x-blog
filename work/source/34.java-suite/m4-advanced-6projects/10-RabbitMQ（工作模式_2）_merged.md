### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

#### PPT 内容

*   **章节标题**: “2.5 RabbitMQ工作模式”
*   **子章节标题**: “2.5.4 路由模式” 和 “2.5.5 通配符模式”
*   **路由模式特点**:
    1.  每个消费者监听自己的队列。
    2.  生产者将消息发送给交换机，由交换机根据 `routingKey` 来转发消息到指定的队列。
*   **路由模式图解**: 生产者 -> (Type: direct) 交换机 -> (routingKey=error) 消费者队列 -> 消费者；以及 (routingKey=info) 消费者队列 -> 消费者。
*   **通配符模式特点**:
    1.  每个消费者监听自己的队列。
    2.  生产者声明队列和交换机，并且绑定交换机和队列时设置通配符模式的 `routingKey`。
    3.  生产者将消息发送给交换机，由交换机根据 `routingKey` 来转发消息到指定的队列。
*   **通配符模式图解**: 生产者 -> (Type: topic) 交换机 -> (routingKey=#.email.#) 消费者队列 -> 消费者；以及 (routingKey=#.sms.#) 消费者队列 -> 消费者。

#### 代码内容

*   **配置类**: `RabbitmqConfig`
*   **常量定义**:
    ```java
    public static final String EXCHANGE = "myexchange2";
    public static final String QUEUE = "myqueue2";
    public static final String ROUTING_KEY = "fire2";
    ```
*   **交换机配置**:
    ```java
    @Bean(EXCHANGE)
    public DirectExchange exchange() {
        return ExchangeBuilder.directExchange(EXCHANGE).durable(true).build();
    }
    ```
*   **队列配置**:
    ```java
    @Bean(QUEUE)
    public Queue queue() {
        return new Queue(QUEUE);
    }
    ```
*   **绑定配置**:
    ```java
    @Bean
    public Binding binding(@Qualifier(QUEUE) Queue queue, @Qualifier(EXCHANGE) DirectExchange exchange) {
        return BindingBuilder.bind(queue).to(exchange).with(ROUTING_KEY);
    }
    ```
*   **`DirectExchange` 源码**:
    ```java

        ...
        public final String getType() {
            return "direct";
        }
    }
    ```
