### 1) 视频摘要

本视频课程讲解了如何在 Spring Boot 项目中，通过 Swagger2 实现对受保护 API 的鉴权访问。讲师首先介绍了在 Swagger UI 中直接调用受保护接口时会遇到的 401 错误问题，并提出了三种解决方案：集成 OAuth2、自定义全局参数、以及全局预置参数。课程重点演示了第三种方法——“全局预置参数”，即在 Swagger 配置中设置一个全局的 `Authorization` 头，使得所有接口无需手动添加 token 即可调用。讲师通过修改 `AutoSwaggerConfiguration` 自动化配置类，添加 `securitySchemes` 方法来实现此功能，并最终在 Swagger UI 中成功调用了受保护的接口，验证了配置的有效性。
