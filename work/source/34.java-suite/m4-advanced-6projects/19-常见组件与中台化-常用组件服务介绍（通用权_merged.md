### 1) 视频摘要

本视频课程讲解了如何将一个已有的 TMS（运输管理系统）项目集成到一个通用的权限系统中。核心内容包括：
*   **前端页面集成**：将 TMS 的前端页面通过 `<iframe>` 嵌入到权限系统的前端页面中，实现统一的 UI 展示。
*   **网关路由配置**：使用 Zuul 网关将对 TMS 的请求转发到其后端服务，确保请求能正确路由。
*   **菜单配置**：在权限系统的后台管理界面中，为 TMS 项目配置相应的菜单项，使其在权限系统中可见。
*   **资源权限配置**：为 TMS 的各个功能点（如 `viewtree`、`addtag`）配置访问权限，定义哪些用户或角色可以访问。
*   **角色与用户管理**：创建角色，将菜单和资源权限分配给角色，然后将角色授权给具体用户，完成权限的最终分配。

整个过程旨在实现一个已有的业务系统（TMS）与一个统一的权限管理平台的无缝集成，从而实现统一的用户认证、权限控制和界面展示。
