    *   **配置语法**: `Syntax: limit_conn zone number;`，其中 `zone` 是共享内存区域名，`number` 是允许的最大连接数。

*   **代码关键内容**:

        ```nginx
        # 限制每个客户端IP与服务器的连接数，同时限制虚拟服务器的连接总数
        limit_conn_zone binary_remote_addr zone=perip:10m;
        limit_conn_zone binary_remote_addr zone=perserver:10m;

        # 示例
        server {
            listen 80;
            server_name localhost;

            location / {
                # content_by_lua_file ...;
            }

            location /user/ {
                # 限制每个客户端IP的连接数
                limit_conn perip 2;
                # 限制每个虚拟服务器的连接数
                limit_conn perserver 10;
            }
        }
        ```
