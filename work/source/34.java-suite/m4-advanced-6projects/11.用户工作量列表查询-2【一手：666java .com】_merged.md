                LocalDateTime start = LocalDateTime.of(now.getYear(), now.getMonth(), dayOfMonth, hour, minute, second, 0);
                UserWork userWork = taskService.getUserWork(u.getId());

                userWork.setUserName(u.getUserName());

### 4) 关键场景与演示描述

*   **场景一：动态查询条件构建 (01:00 - 01:30)**
    讲师在 `UserServiceImpl` 中，通过 `LambdaQueryWrapper` 对象动态地为 `UserEntity` 添加查询条件。他首先检查 `regionId` 是否为 `null`，如果非空，则使用 `eq` 方法将其与 `UserEntity` 的 `regionId` 字段进行等值匹配；否则，使用 `roleId` 字段进行匹配。这展示了如何在服务层实现灵活的查询条件。
