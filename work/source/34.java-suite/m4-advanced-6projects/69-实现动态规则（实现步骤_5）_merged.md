### 1) 视频摘要

本视频课程演示了一个基于 Spring Boot 和 Drools 规则引擎的订单服务系统如何实现动态价格计算。核心内容包括：
*   **数据模型**：通过 Navicat Premium 管理数据库表 `pd_oms.rule`，该表用于存储规则的 ID、内容、版本等元数据。
*   **规则引擎集成**：在 IntelliJ IDEA 中，通过 `CommandLineRunner` 在应用启动时加载数据库中的规则，并通过 `RulesReloadController` 提供 HTTP 接口进行规则的热加载。
*   **规则定义**：在 Notepad++ 中编写 Drools 规则文件（`.drl`），根据订单的重量和距离，动态计算运费。
*   **API 接口**：使用 Swagger UI 提供的 RESTful API，前端可以发送订单数据，后端根据规则引擎计算并返回运费。
*   **技术栈**：Spring Boot, Drools, MySQL, Swagger UI, IntelliJ IDEA, Navicat Premium。

整个过程展示了如何将业务规则从数据库中动态加载并应用到系统中，实现了规则与代码的分离，便于业务人员维护和调整。
