### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT / 图表 1: CephFS 逻辑架构图**
    *   **组件**:
        *   **Ceph Client**: 位于用户空间，通过 VFS 和 Ceph 库与下层通信。
        *   **Ceph Metadata Daemon (mds)**: 提供元数据服务，包含 DRAM cache。
        *   **Ceph Object Storage Daemon (osd)**: 提供实际存储，支持 BTRFS / EBOFS 等文件系统。
        *   **Ceph Monitor (mon)**: 提供集群管理。
    *   **关系**: Client 通过 MDS 获取元数据，通过 OSD 获取实际数据，Monitor 管理整个集群状态。

*   **PPT / 图表 2: CephFS IO 流程图**
    *   **流程步骤**:
        1.  **Client 连接 Monitor**：获取集群 map 信息。
        2.  **新 OSD 主动上报**：新主 OSD (如 OSD1) 由于没有 PG 数据，会主动上报 Monitor，告知 OSD2 临时接管。
        3.  **数据同步**：临时主 OSD2 会将数据全部同步给新主 OSD1。
        4.  **Client 直接读写**：Client 读写直接连接临时主 OSD2。
        5.  **数据写入**：OSD2 收到写入后，会将数据写入另外两个副本节点。
        6.  **等待写入成功**：等待 OSD2 以及另外两个副本节点写入成功。
        7.  **返回结果**：三个 OSD 份数据都写入成功后，返回给 Client，读写操作完成。
    *   **关键状态**:
        *   `PG Temp [2,3,1]`: 临时 PG 状态，表示数据分布在 2、3、1 号 OSD 上。
        *   `backfill`: 数据同步过程。
        *   `新的临时主`: 临时主 OSD。
