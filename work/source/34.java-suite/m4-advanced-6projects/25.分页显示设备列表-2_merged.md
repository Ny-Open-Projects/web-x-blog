### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **关键代码片段**：

    ```java
    @Override
    public Page<DeviceQuotaVO> queryDeviceQuota(Long page, Long pageSize, String deviceid, String tag, Integer state) {
        // 1. 查询设备列表
        Page<DeviceQuotaVO> pager = esRepository.searchDevice(page, pageSize, deviceid, tag, state);
        
        // 2. 遍历设备列表，转换为配额VO
        pager.getItems().forEach(deviceDTO -> {
            DeviceQuotaVO deviceQuotaVO = new DeviceQuotaVO();
            BeanUtils.copyProperties(deviceDTO, deviceQuotaVO);
            
            // 3. 获取该设备的配额列表
            List<QuotaInfo> quotaList = quotaService.getLastList(deviceDTO.getDeviceId());
            deviceQuotaVO.setQuotaList(quotaList);
            
            // 4. 将转换后的VO添加到结果列表
            pager.getItems().add(deviceQuotaVO);
        });
        
        // 5. 封装分页结果
        PageResult<DeviceQuotaVO> pageResult = new PageResult<>();
        pageResult.setItems(pager.getItems());
        pageResult.setPage(pager.getPage());
        pageResult.setPageSize(pager.getPageSize());
        pageResult.setCounts(pager.getCounts());
        
        return pageResult;
    }
    ```
