*   **关键文字内容**：
    *   **背景**：微服务架构下，服务间依赖性导致雪崩效应，因此需要熔断器。
    *   **历史**：2012年推出，2018年开源。
    *   **工作原理**：
        *   **Slot 机制**：每个 Entry 创建一个 Slot Chain，Slot 负责不同职责。
        *   **Slot 职责**：
            *   `NodeSelectorSlot`：收集资源路径，用于限流降级。
            *   `ClusterBuilderSlot`：存储资源统计信息，用于多维度流控和降级。
            *   `StatisticSlot`：记录、统计 runtime 指标监控信息。
            *   `FlowSlot`：进行流量控制。
            *   `AuthoritySlot`：做黑白名单控制。
            *   `DegradSlot`：做熔断降级。
            *   `SystemSlot`：控制总入口流量。
    *   **扩展机制**：通过 SPI 接口扩展 SlotChain，可自行添加自定义 Slot。
