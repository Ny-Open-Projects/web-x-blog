### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **代码片段 1 (QuotaController.java - create 方法)**:
    ```java
    @PostMapping
    public boolean create(@RequestBody QuotaVO vo) {
        QuotaEntity quotaEntity = new QuotaEntity();
        BeanUtils.copyProperties(vo, quotaEntity);
        try {
            emqClient.subscribe(topicName: "Queue/" + vo.getSubject());
        } catch (MqttException e) {
            e.printStackTrace();
        }
        return quotaService.save(quotaEntity);
    }
    ```

*   **代码片段 2 (QuotaController.java - queryPage 方法)**:
    ```java
    @GetMapping
    public Pager<QuotaEntity> queryPage(@RequestParam(value = "page", required = false, defaultValue = "1") Long page,
                                        @RequestParam(value = "pageSize", required = false, defaultValue = "10") Long pageSize,
                                        @RequestParam(value = "quotaName", required = false) String quotaName) {
        return quotaService.queryPage(page, pageSize, quotaName);
    }
    ```

*   **代码片段 3 (Monitor.java - init 方法)**:
    ```java
    @PostConstruct
    public void init() {
        System.out.println("初始化方法，订阅主题");
        emqClient.connect();
        quotaService.getAllSubject().forEach(s -> {
            try {
                emqClient.subscribe(topicName: "Queue/" + s);
            } catch (MqttException e) {
                e.printStackTrace();
            }
        });
    }
    ```

    CREATE TABLE IF NOT EXISTS tb_quots (

        CONSTRAINT tb_quots_name_index UNIQUE (name)
