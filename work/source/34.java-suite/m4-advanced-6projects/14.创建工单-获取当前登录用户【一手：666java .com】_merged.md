### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **关键代码片段**：

    *   **`TaskService` 服务层 (`TaskServiceImpl.java`) - `createTask` 方法**：
        ```java
        @Transactional(rollbackFor = {Exception.class}, noRollbackFor = {LogicException.class})
        public boolean createTask(TaskViewModel taskViewModel) throws LogicException {
            if (hasNewLogic(taskViewModel.getTaskType(), taskViewModel.getProductType())) {
                throw new LogicException("该机器有未完成的同类工单");
            }
            // 创建主任务实体
            TaskEntity taskEntity = new TaskEntity();
            BeanUtils.copyProperties(taskViewModel, taskEntity);
            taskEntity.setTaskStatus(VMSysEnum.TASK_STATUS_CREATE);
            taskEntity.setProductType(taskViewModel.getProductType());
            String userName = userService.getUserInfo(taskViewModel.getUserId()).getUserName();
            taskEntity.setUserName(userName);
            taskEntity.setAddr(taskViewModel.getAddr());
            this.save(taskEntity);
            
            // 如果是生产工单，向 VMService 添加子任务
            if (taskViewModel.getProductType() != VMType.TASK_TYPE_SUPPLY) {
                taskViewModel.getDetails().forEach(d -> {
                    TaskDetailsEntity detailsEntity = new TaskDetailsEntity();
                    BeanUtils.copyProperties(detailsEntity, d);
                    detailsService.save(detailsEntity);
                });
            }
            return true;
        }
        ```

    *   **`TaskController` 控制器层 (`TaskController.java`) - `create` 方法**：
        ```java
        @PostMapping("/create")
        public boolean create(@RequestBody TaskViewModel task) throws LogicException {
            return taskService.createTask(task);
        }
        ```

        ```java
        @Autowired
        private HttpServletRequest request; // 自动注入请求对象

        public Integer getUserId() {
            String userId = request.getHeader("userId");
            if (Strings.isNullOrEmpty(userId)) {
                return null;
            } else {
                return Integer.parseInt(userId);
            }
        }

        public String getUserName() {
            return request.getHeader("userName");
        }
        ```

*   **关键概念**：
    *   **分层架构**：Controller -> Service -> DAO。
