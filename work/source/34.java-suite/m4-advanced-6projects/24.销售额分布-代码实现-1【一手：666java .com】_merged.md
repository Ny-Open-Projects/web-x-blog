    ```java
    @Override
    public BarChartCollect getCollectByRegion(LocalDate start, LocalDate end) {
        SearchRequest searchRequest = new SearchRequest("_index: "order");
        SearchSourceBuilder sourceBuilder = new SearchSourceBuilder();
        BoolQueryBuilder boolQueryBuilder = QueryBuilders.boolQuery();

        // 设置查询条件
        boolQueryBuilder.filter(QueryBuilders.rangeQuery("create_time").gte(start).lte(end));
        boolQueryBuilder.filter(QueryBuilders.termQuery("pay_status", "VMSYSTEM_PAY_STATUS_PAID"));

        sourceBuilder.query(boolQueryBuilder);
        sourceBuilder.size(0); // 不返回文档，只返回聚合结果

        // 设置聚合
        AggregationBuilder regionAgg = AggregationBuilders.terms("region")
            .field("region_name")
            .subAggregation(AggregationBuilders.sum("amount_sum").field("amount"))
            .order(BucketOrder.aggregation("amount_sum", false))
            .size(30);

        sourceBuilder.aggregation(regionAgg);
        searchRequest.source(sourceBuilder);

        return null;
    }
    ```

    *   **Elasticsearch 查询构建**：使用 `SearchRequest`、`SearchSourceBuilder`、`BoolQueryBuilder`、`RangeQuery`、`TermQuery`。

    *   **分页与排序**：`sourceBuilder.size(0)` 用于只获取聚合结果，`BucketOrder.aggregation` 用于对聚合桶进行排序。
