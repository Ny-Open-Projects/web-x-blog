### 1) 视频摘要

本视频课程旨在介绍一个名为“品达通用权限系统”的开源项目。该系统是一个基于 Spring Cloud 和 Spring Boot 的微服务架构，旨在解决企业中普遍存在的用户权限管理、认证、鉴权、加密、解密和 XSS 防护等重复开发问题。课程首先概述了系统的功能特性，然后通过架构图详细展示了其分层结构，包括前端、网关、应用层、服务层和支撑层。最后，课程介绍了项目的工程结构、核心服务（网关服务和权限服务）及其启动命令，并列出了开发所需的环境依赖。

    *   项目根目录包含 `pd-auth` (权限工程)、`pd-gateway` (网关服务) 和 `pd-tools` (公共组件)。
