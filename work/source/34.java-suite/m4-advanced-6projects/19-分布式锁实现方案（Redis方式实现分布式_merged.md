    *   解决方案：`为了解决这个问题可以在加锁时设置一个过期时间防止死锁。`

        *   加锁命令：`set lock_key lock_value NX PX 5000`

*   **Java 代码**:
    ```java
    @GetMapping("/stock")
    public String stock() {
        try {
            // 尝试加锁
            Boolean locked = redisTemplate.opsForValue().setIfAbsent("mylock",
                    "myLock", 5000, TimeUnit.MILLISECONDS);
            if (locked) { // 加锁成功
                int stock = Integer.parseInt(redisTemplate.opsForValue().get("stock"));
                if (stock > 0) {
                    stock--;
                    redisTemplate.opsForValue().set("stock", stock + "");
                    System.out.println("库存扣减成功，剩余库存：" + stock);
                } else {
                    System.out.println("库存不足！！！");
                }
                // 释放锁
                redisTemplate.delete("mylock");
            } else {
                System.out.println("没有获得锁，不能执行减库存操作...");
            }
        } catch (Exception ex) {
            System.out.println("争抢锁异常...");
        }
        return "OK";
    }
    ```

*   **Redis 命令行操作**:
    *   **加锁**: `SET lock_key lock_value NX PX 5000`
    *   **解锁**: `DEL lock_key`
    *   **查看键值**: `GET stock`

*   **Redis API 源码片段**:
    ```java
    @Nullable
    Boolean setIfAbsent(K key, V value, long timeout, TimeUnit unit);
    ```
    *   **注释**: `Set <code>key</code> to hold the string <code>value</code> and expiration <code>timeout</code> if <code>key</code> does not exist.`
    *   **参数说明**: `key`、`value`、`timeout`、`unit`。
