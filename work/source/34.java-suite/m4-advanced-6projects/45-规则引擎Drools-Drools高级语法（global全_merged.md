### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT 内容**：
    *   **标题**：`6.1 global全局变量`
    *   **核心定义**：`global` 关键字用于在规则文件中定义全局变量，允许应用程序的对象在规则文件中被访问，为规则文件提供数据或服务。
    *   **语法结构**：`global 对象类型 对象名称`
    *   **关键注意事项**：
        1.  如果对象类型为包装类型（如 `Integer`），在一个规则中修改其值，只对当前规则有效，对其他规则中的 `global` 不会有影响。
        2.  如果对象类型为集合类型（如 `List`）或 JavaBean 类型，修改其值后，对 Java 代码和所有规则都有效。

*   **代码关键内容**：

    **Java 代码 (`UserService.java`)**:
    ```java
    package com.ithema.drools.service;
    public class UserService {
        public void save() {
            System.out.println("UserService.save()...");
        }
    }
    ```

    **Drools 规则文件 (`global.drl`)**:
    ```drl
    // 当前规则文件用于测试global全局变量
    package testglobal
    import com.ithema.drools.service.UserService

    global java.lang.Integer count; // 定义一个包装类型的全局变量
    global java.util.List gList; // 定义一个集合类型的全局变量
    global UserService userService; // 定义一个JavaBean类型的全局变量

    rule "rule_global_1"
    when
    then
        count += 10; // 对于包装类型的全局变量的修改只对当前规则生效
        System.out.println("规则: rule_global_1触发了...");
        System.out.println("全局变量count计算之后的值为: " + count);
        gList.add("fitcast"); // 修改集合类型的全局变量
        System.out.println("全局变量gList的size: " + gList.size());
        userService.save();
    end

    rule "rule_global_2"
    when
    then
        System.out.println("规则: rule_global_2触发了...");
        System.out.println("全局变量的值为: " + count);
        System.out.println("全局变量gList的size: " + gList.size());
    end
    ```

    **Java 测试代码 (`DroolsTest.java`)**:
    ```java
    // ... 其他代码 ...
    session.setGlobal("count", 0); // 设置包装类型全局变量
    session.setGlobal("gList", new ArrayList<>()); // 设置集合类型全局变量
    session.setGlobal("userService", new UserService()); // 设置 JavaBean 类型全局变量

    // 激活规则，Drools框架自动进行规则匹配，如果规则匹配成功，则执行当前规则
    session.fireAllRules();

    // 关闭会话
    session.dispose();
    ```
