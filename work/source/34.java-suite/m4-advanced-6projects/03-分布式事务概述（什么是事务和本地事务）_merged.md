### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **PPT 文本内容**：
    *   **2.1 什么是事务**：
        *   事务是由一组操作组成的一个工作单元。
        *   **ACID特性**：
            *   **原子性 (atomicity)**：执行单元中的操作要么全部执行成功，要么全部失败。
            *   **一致性 (consistency)**：执行前后数据都是完整的。
            *   **隔离性 (isolation)**：事务与事务之间是完全隔离的。
            *   **持久性 (durability)**：事务完成后对数据的改变会永久性地存储起来。
    *   **2.2 什么是本地事务**：
        *   本地事务就是用关系型数据库来控制事务。
        *   关系型数据库通常都有ACID特性。
        *   传统的单体应用会将数据全部存储在一个数据库中，会借助关系型数据库来完成事务控制。
    *   **2.3 什么是分布式事务**：
        *   在分布式系统中，一次操作由多个系统协同完成。
        *   举例：电商项目中用户下单，需要订单系统和库存系统协同完成。
        *   强调：**通过网络协同完成**是分布式事务的核心，即使访问的是同一个数据库，只要涉及多个系统，也属于分布式事务。
