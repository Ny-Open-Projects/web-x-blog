### 1) 视频摘要

本视频是一个关于 **Apache Druid** 的快速入门教程，主要演示了如何在单机环境下安装和启动 Druid 服务。课程内容基于官方文档，首先介绍了安装前的系统要求（特别是对 Java 8 的依赖），然后指导用户下载并解压 Druid 的二进制包，最后演示了如何通过执行脚本启动 Druid 服务，并访问其 Web 管理界面。整个过程旨在帮助初学者快速搭建一个可运行的 Druid 环境，为后续的数据摄取和查询操作做准备。
