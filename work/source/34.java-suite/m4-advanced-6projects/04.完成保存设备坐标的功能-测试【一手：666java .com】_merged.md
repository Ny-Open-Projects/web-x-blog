    ```java
    @Override
    public void process(String jsonMsg) throws IOException {
        TaskCompleteContract taskCompleteContract = JsonUtil.getbyJson(jsonMsg, TaskCompleteContract.class);
        if (taskCompleteContract == null || Strings.isNullOrEmptys(taskCompleteContract.getInnerCode())) return;
        // 如果是投放工单，修改设备状态为运行中
        if (taskCompleteContract.getTaskType() == VMSys.TASK_TYPE_DEPLOY) {
            vmservice.updateStatus(taskCompleteContract.getInnerCode(), VMSys.VM_STATUS_RUNNING);
            // todo: 保存设备的坐标（数据4-es）
            var vmDistance = new VMDistance();
            BeanUtils.copyProperties(taskCompleteContract, vmDistance);
            vmservice.setVMDistance(vmDistance);
        }
        // 如果是撤机工单，修改设备状态为撤机中
        if (taskCompleteContract.getTaskType() == VMSys.TASK_TYPE_REVOKE) {
            vmservice.updateStatus(taskCompleteContract.getInnerCode(), VMSys.VM_STATUS_REVOKE);
        }
    }
    ```
    *   **关键点**: 该方法处理来自前端的工单完成消息，根据工单类型（投放或撤机）更新设备状态，并将设备坐标信息保存到 `VMDistance` 对象中，为后续的 Elasticsearch 操作做准备。
