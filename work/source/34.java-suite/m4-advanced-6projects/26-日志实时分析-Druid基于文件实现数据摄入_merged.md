### 1) 视频摘要

本视频教程旨在指导用户如何使用 Apache Druid 的 **数据加载器 (Data Loader)** 图形化界面，将一批静态数据（JSON 格式）导入 Druid 集群。教程从官方文档的“Loading data with the data loader”部分开始，逐步演示了从选择数据源、配置数据格式、定义时间戳列、设置维度和度量，到最终提交数据加载任务的完整流程。整个过程强调了 Druid 的核心概念，如时间戳列、维度和度量，并展示了如何通过 Web 界面进行数据摄取。

### 4) 关键场景与演示描述

*   **场景一：数据源选择与配置** (00:05 - 00:10)
    *   **描述**：用户在 Druid Web 界面中，点击“Load data”后，选择“Local disk”作为数据源。在右侧的配置面板中，用户将数据文件路径设置为 `quickstart/tutorial/wikipedia.json`，并点击“Apply”按钮。系统提示“Please fill out the fields on the right sidebar to get started”。

*   **场景二：时间戳列配置** (00:10 - 00:16)
    *   **描述**：用户点击“Next: Parse time”进入时间戳配置步骤。在右侧面板中，用户选择 `time` 列作为时间戳列，并将其格式设置为 `ISO8601`。系统提示“Druid requires a primary timestamp column (internally stored in a column called `time`). If you do not have a timestamp in your data, select `Constant` value. In our example, the `time` column in our raw data is the only candidate that can be used as the primary time column.”

*   **场景三：数据转换与维度/度量配置** (00:16 - 00:34)
    *   **描述**：用户依次点击“Next: Transform”和“Next: Configure time”。在“Transform”步骤中，用户为 `channel`、`cityName`、`countryCode` 等列添加维度。在“Configure time”步骤中，用户将时间粒度设置为 `HOUR`。

*   **场景四：数据发布与查询** (00:34 - 00:43)
    *   **描述**：用户点击“Next: Publish”，在右侧面板中为数据源命名 `wikipedia`，然后点击“Submit”按钮提交任务。任务提交成功后，视频切换到 Druid 的查询界面，用户可以执行 SQL 查询来验证数据是否已成功加载。在查询界面中，用户执行了 `SELECT * FROM wikipedia` 查询，并成功返回了数据。
