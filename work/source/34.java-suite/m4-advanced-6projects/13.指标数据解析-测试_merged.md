### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **关键代码片段 1 (分析方法)**:
    ```java
    @Override
    public DeviceInfoDTO analysis(String topic, Map<String, Object> payloadMap) {
        // 1. 根据主题查询配额列表
        List<QuotaEntity> quotaList = baseMapper.selectBySubject(topic);
        if (quotaList.size() == 0) return null;

        // 2. 从 payloadMap 中提取设备ID
        String deviceId = (String) payloadMap.get("deviceId");
        if (StringUtils.isEmpty(deviceId)) return null;

        // 3. 创建 DeviceInfoDTO 对象
        DeviceInfoDTO deviceInfoDTO = new DeviceInfoDTO();
        deviceInfoDTO.setDeviceId(deviceId);

        // 4. 遍历 quotaList，将 payloadMap 中的参数填充到 quotaList 中
        for (QuotaEntity quota : quotaList) {
            if (payloadMap.containsKey(quota.getKey())) {
                QuotaDTO quotaDTO = new QuotaDTO();
                BeanUtils.copyProperties(quota, quotaDTO);
                quotaDTO.setValue(payloadMap.get(quota.getKey()).toString());
                quotaDTO.setValueType(quota.getValueType());
                quotaDTO.setKey(quota.getKey());
                quotaDTO.setWebhook(quota.getWebhook());
                quotaDTO.setReferenceValue(quota.getReferenceValue());
                quotaDTO.setUnit(quota.getUnit());
                quotaList.add(quotaDTO);
            }
        }

        // 5. 将 quotaList 设置到 deviceInfoDTO 中
        deviceInfoDTO.setQuotaList(quotaList);
        return deviceInfoDTO;
    }
    ```
