### 1) 视频摘要

本视频演示了一个基于 Spring Boot 的分布式系统中，客户端如何通过 MQTT 消息总线与服务端进行通信，并最终将数据持久化到 H2 数据库的过程。核心内容包括：

*   **系统架构**：客户端（`LkdClientApplication`）订阅服务端（`VmsServiceApplication`）发布的 MQTT 消息。
*   **消息处理**：服务端的 `VersionCfgMsgHandler` 类负责解析接收到的 JSON 消息，提取 SKU 价格、SKU 版本和渠道容量等配置信息。
*   **数据持久化**：客户端接收到消息后，通过 MyBatis 框架执行 SQL 语句，将 SKU 和渠道的配置信息批量插入到 H2 数据库的 `tb_sku` 和 `tb_channel` 表中。
*   **技术栈**：主要使用了 Spring Boot、MyBatis、MQTT 协议和 H2 数据库。演示了如何在 `application.yml` 中配置数据库连接和 MQTT 服务。

### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **代码片段 1**：`VersionCfgMsgHandler.java` 中的 `process` 方法，用于处理 MQTT 消息。
    ```java
    @Override
    public void process(String jsonStr) throws IOException {
        try {
            VersionCfg versionCfg = JSONUtil.toBean(jsonStr, VersionCfg.class);
            if(versionCfg.getData() == null) return;
            VncCfgVersionEntity versionInfo = versionService.getVersionInfo(versionCfg.getInnerCode());
            if(versionInfo == null) return;
            if(versionCfg.getData().getSkucfgVersion() < versionInfo.getSkucfgVersion()){
                SkuCfg skuCfg = vncCfgService.getSkucfg(versionCfg.getInnerCode(), 2, skuCfg);
                mqttProducer.send(topic: TopicConfig.TQ_VM_TOPIC_version, 2, skuCfg);
            }
            if(versionCfg.getData().getSkupriceCfg() < versionInfo.getSkupriceCfg()){
                SkuPriceCfg skuPriceCfg = vncCfgService.getSkupriceCfg(versionCfg.getInnerCode(), 2, skuPriceCfg);
                mqttProducer.send(topic: TopicConfig.TQ_VM_TOPIC_version, 2, skuPriceCfg);
            }
            if(versionCfg.getData().getChannelCfg() < versionInfo.getChannelCfg()){
                ChannelCfg channelCfg = vncCfgService.getChannelCfg(versionCfg.getInnerCode(), 2, channelCfg);
                mqttProducer.send(topic: TopicConfig.TQ_VM_TOPIC_version, 2, channelCfg);
            }
        } catch (Exception e) {
            log.error("process versionCfg error. vm request msg is: " + jsonStr, e);
        }
    }
    ```
