private LoginResp empLogin(LoginReq req) throws IOException {
    LoginResp resp = new LoginResp();

    String code = redisTemplate.boundValueOps(req.getMobile()).get();

**2. 合作商登录 (`login`)**
```java
@Override
public LoginResp login(LoginReq req) throws IOException {
    LoginResp resp = new LoginResp();
    resp.setSuccess(false);
    String code = redisTemplate.opsForValue().get(req.getClientToken());
    if (Strings.isNullOrEmpty(code)) {
        resp.setMsg("验证码错误");
        return resp;
    }
    if (!req.getCode().equals(code)) {
        resp.setMsg("验证码错误");
        return resp;
    }

    QueryWrapper<PartnerEntity> qw = new QueryWrapper<>();
    qw.lambda().eq(PartnerEntity::getAccount, req.getAccount());
    PartnerEntity partnerEntity = this.getOne(qw);
    if (partnerEntity == null) {
        resp.setMsg("不存在该账户");
        return resp;
    }

    if (!BCrypt.checkpw(req.getPassword(), partnerEntity.getPassword())) {
        resp.setMsg("账号或密码错误");
        return resp;
    }

    resp.setSuccess(true);
    resp.setUserName(partnerEntity.getName());
    resp.setUserId(partnerEntity.getId());
    resp.setMsg("登录成功");

    TokenObject tokenObject = new TokenObject();
    tokenObject.setUserId(partnerEntity.getId());
    tokenObject.setLoginType(VMSYSTEM.LOGIN_EMP);
    tokenObject.setMobile(partnerEntity.getMobile());
    String token = JWTUtil.createJWTByObj(tokenObject, partnerEntity.getMobile() + VMSYSTEM.JWT_SECRET);
    resp.setToken(token);

    return resp;
}
```

#### **关键公式 / 逻辑**

*   **验证码校验逻辑**：`req.getCode().equals(code)`，用于比对用户输入的验证码与 Redis 中存储的验证码是否一致。
*   **用户存在性校验**：`userEntity == null` 或 `partnerEntity == null`，用于判断数据库中是否存在对应的用户或合作商账户。
*   **密码校验逻辑**：`BCrypt.checkpw(req.getPassword(), partnerEntity.getPassword())`，使用 BCrypt 算法对用户输入的密码和数据库中存储的哈希密码进行比对。
*   **JWT 令牌生成**：
    ```latex
    \text{token} = \text{JWTUtil.createJWTByObj}(\text{tokenObject}, \text{mobile} + \text{JWT\_SECRET})
    ```
    其中 `tokenObject` 包含用户ID、登录类型和手机号，`JWT_SECRET` 是用于签名的密钥。
