*   **PPT 文本内容**:
    *   **2.3.1. 功能概述**:
        *   ID 全称 Identifier，中文翻译为标识符，是用于唯一标识对象或记录的符号。

        *   随着社会发展，对数据库分库分表的需求增加，单个数据库的自增ID无法满足需求，需要一个能够生成全局唯一ID的系统。
    *   **2.3.2. 应用场景**:
        *   **1. 全局唯一**: 这是最简单的要求，即不能出现重复的ID。
