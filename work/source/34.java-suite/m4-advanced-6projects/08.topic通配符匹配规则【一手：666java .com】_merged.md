        *   **多层通配符 `#`**：
            *   用于匹配主题树中任意层级。
            *   `love/#` 可匹配 `love/you`、`love/you/with`、`love/you/with/all`、`love/you/with/all/my/heart` 等。
            *   **重要规则**：`#` 必须是主题树的最后一个字符，例如 `love/#` 是有效的，但 `love/#/with` 是无效的。
        *   **单层通配符 `+`**：
            *   只匹配主题树中的一层。
            *   `love/you/+` 可匹配 `love/you/with` 和 `love/you/and`，但不匹配 `love/you/with/all/my/heart`。
            *   **重要规则**：`+` 必须位于主题层级分隔符 `/` 的右边，除非它是指定自己（如 `love/+`）。`+` 不能用于 `love/+` 这样的形式。
        *   **注意事项**：
            1.  层次主题分隔符用于主题中引入层次，多层通配符和单层通配符可以被使用，但它们不能被用来做发布者的消息。
            2.  Topic 命名尽量见名知意，符合规范，主题名字是大小写敏感的。例如，`love` 和 `LOVE` 是两个不同的主题。
            3.  以 `/` 开头会产生一个不同的主题。例如，`/love` 与 `love` 不同，`/love/#` 与 `love/#` 不同，但不匹配 `love/+`。
            4.  不要在任何主题中包含 `null` (Unicode `\x0000`) 字符。
            5.  在主题树中，长度被限制于 64k 内，但并非在没有限制层级数目的情况下。
            6.  可以有任意数量的根节点；也就是说，可以有任意数量的主题树。
