### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

#### PPT / 文本内容

*   **核心概念**：声明式缓存是通过在方法上添加注解来自动执行缓存操作，类似于声明式事务。
*   **兼容性**：JCache 原生 API 与自定义的声明式缓存可以共存，互为补充。
*   **实现原理**：基于 AOP，通过 Spring 的拦截器机制拦截 Controller 方法。
*   **核心类/注解**：
    *   `@Cache`：用于缓存方法的返回值。
    *   `@CacheEvict`：用于清理指定缓存数据。
    *   `@CacheMethodInterceptor`：缓存拦截器，用于拦截加载缓存相关注解的方法。
    *   `AbstractCacheAnnotationProcessor`：抽象缓存注解处理器，为缓存操作提供公共方法。
    *   `CachesAnnotationProcessor`：缓存注解处理器，处理 `@Cache` 注解。
    *   `CacheEvictorAnnotationProcessor`：失效缓存注解处理器，处理 `@CacheEvict` 注解。
    *   `EnableCache`：开启缓存功能注解，通常用于项目的启动类。

#### 代码示例

*   **JCache 原生 API 代码片段**：
    ```java
    @GetMapping("/check")
    public String check() {
        int check = cacheChannel.check(region, key);
    ```
