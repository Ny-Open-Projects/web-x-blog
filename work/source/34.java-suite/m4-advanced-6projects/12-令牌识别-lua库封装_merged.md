            local response = {}
            if auth_header == nil then

                return response
            end

    *   **JWT 签名与验证函数**:
        *   **签名**: `local jwt_token = jwt:sign({ header, payload })`

*   **关键公式 / 概念**:
    *   **JWT 结构**: JWT 由三部分组成：Header（头部）、Payload（载荷）、Signature（签名）。
    *   **签名算法**: `alg` 参数指定签名算法，如 `HS256`。
    *   **验证选项**: `validators` 模块用于校验 JWT 中的声明，如 `exp`（过期时间）、`nbf`（不早于）、`iat`（签发时间）等。
    *   **过期时间**: `exp` 声明用于指定 JWT 的过期时间，验证时会与当前时间进行比较。
