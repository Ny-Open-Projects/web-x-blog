### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

*   **图表：WebSocket 与 AJAX 轮询对比图**
    *   **左侧（AJAX 轮询）**：
        *   **通信方式**：基于 HTTP 协议。
        *   **交互模式**：客户端（Client）周期性地向服务器（Server）发送 `GET /poll` 请求。
        *   **数据传输**：服务器在收到请求后，返回数据。这种模式是“请求-响应”式的，不是真正的实时推送。
        *   **缺点**：频繁的 HTTP 请求会浪费带宽和服务器资源。
    *   **右侧（WebSockets）**：
        *   **通信方式**：基于 TCP 协议。
        *   **交互模式**：客户端与服务器建立一个持久的 `WebSocket` 连接。
        *   **数据传输**：连接建立后，客户端和服务器可以双向、实时地发送和接收数据，无需频繁的 HTTP 请求。
        *   **优点**：节省服务器资源和带宽，实现真正的实时通信。
