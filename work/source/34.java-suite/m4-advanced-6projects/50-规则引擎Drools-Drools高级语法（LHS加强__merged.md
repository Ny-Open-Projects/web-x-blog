### 3) 出现的 PPT / 公式 / 图表 / 代码的关键内容

#### PPT 文档内容

*   **章节标题**: `6.4.2 条件元素 eval`
    *   **描述**: `eval` 用于规则体的 LHS 部分，并返回一个 Boolean 类型的值。
    *   **语法结构**: `eval(表达式)`
    *   **示例**: `eval(true)`, `eval(false)`, `eval(1 == 1)`

*   **章节标题**: `6.4.3 条件元素 not`
    *   **描述**: `not` 用于判断 Working Memory 中是否存在某个 Fact 对象，如果不存在则返回 true，如果存在则返回 false。
    *   **语法结构**: `not Object` (可选属性约束)
    *   **示例**: `not Student()`

#### 代码内容

*   **规则文件 `lhs.drl`**:
    ```drl
    rule "rule_lhs_1"
    when
        $s:Student(name in ("张三","李四","王五"))
    then
        System.out.println("规则: rule_lhs_1触发了...");
    end

    rule "rule_lhs_2"
    when
        $s:Student(name not in ("张三","李四","王五"))
    then
        System.out.println("规则: rule_lhs_2触发了...");
    end

    rule "rule_lhs_3"
    when
        eval(true)
    then
        System.out.println("规则: rule_lhs_3触发了...");
    end
    ```
