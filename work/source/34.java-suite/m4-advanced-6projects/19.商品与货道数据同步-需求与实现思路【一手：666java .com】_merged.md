#### 文本内容

*   **需求分析：** 售货机启动时，根据本地记录的版本信息，向服务器请求最新数据。
*   **实现思路：**
    1.  售货机启动后连接 EMQ 服务器，读取本地 `tb_version` 表并发送给服务器。
    2.  在 `EmqMsgCallback` 的 `messageArrived` 方法中监听服务器返回信息。
    3.  同步货道信息时，先删除 `tb_channel` 表中旧数据，再插入新数据，并修改 `tb_version` 表中的货道版本。
    4.  同步商品信息时，直接删除 `tb_sku` 表中旧数据，插入新数据，并修改 `tb_version` 表中的商品版本。
