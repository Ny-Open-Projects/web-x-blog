数字货币 Python 量化投资实战

从量化概念、Python/Pandas 基础，到交易所接口、择时 / 选币 / 套利策略与自动交易 —— 一门可跑通闭环的量化实战课。

📚 课程内容由转写稿经「源稿 → 图文卡片」管线制作中，章节课时结构如下；每课时将配图文讲解 + 可运行代码 + 知识图谱。
课程大纲11 章 · 58 课时
学习路径建议
① 入门：第1章 量化投资介绍 + 第2章 比特币介绍，建立概念与标的认识；
② 打基础：第3章 Python 基础 + 第4/5章 Pandas，掌握数据处理；
③ 连真实：第6章 交易所接口，把数据跑通；
④ 上策略：第7章 择时 / 第9章 选币 / 第10章 套利，配合看板实操；
⑤ 成闭环：第8章 自动交易，接入模拟盘验证（不接真实资金）。
说明：本课程为量化方法教学内容，配套看板为模拟数据演示；不构成投资建议，数字货币与量化交易风险极高，历史/模拟业绩不代表未来收益。
