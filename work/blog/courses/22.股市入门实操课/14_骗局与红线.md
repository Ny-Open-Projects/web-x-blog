# 第 14 章 骗局与红线

> 本章目标：让你在遇到这些话术的 10 秒内识别出危险。
> 这一章读完不需要记住理论，只需要记住一个反应：**跑。**

---

## 14.1 一个残酷的匹配关系

先看一组对应关系：

| 骗局类型 | 目标客单价 | 你的资金 |
|---|---|---|
| 荐股群会员费 | 3000–30000 元/年 | 1000 元 |
| 量化软件 | 5000–50000 元 | 1000 元 |
| 带单分成 | 盈利的 30%–50% | 1000 元 |
| 场外配资 | 保证金 1 万起 | 1000 元 |
| 杀猪盘 | 5 万–50 万 | 1000 元 |

**注意第一行的数字。** 一个收 3000 元会员费的荐股群，需要骗 3 个你这样的人才能覆盖成本。

你手里这 1000 元，在骗子眼里是**获客成本**，不是目标。他们真正想要的是：让你相信，然后加钱。

> **所有针对新手的骗局，第一阶段都不指望赚你的本金，他们要的是你的信任。**

理解这一点，你就能看懂接下来的所有套路。

---

## 14.2 六种专坑新手的套路

### 套路一：免费荐股群

**流程**：

```
第 1 步：短视频/公众号/知乎，"免费分享，扫码进群"
第 2 步：进群后，每天有"老师"发早盘分析，看起来很专业
第 3 步：偶尔推一只票，第二天真的涨了（小盘股，群里几百人一起买，能拉起来）
第 4 步：你信了。老师说"想继续跟，加入 VIP 群，年费 6800"
第 5 步：交钱后，推的票开始亏。老师说"市场不好，再等等"，或者"你做T+0降低成本"
第 6 步：群解散，换一个名字重新开始
```

**第 3 步是关键设计**：几百人同时买入一只小盘股，确实能拉一个涨停。但**你买不进去**（涨停了），或者买进去后他们出货给你。

**识别方法**：

| 信号 | 说明 |
|---|---|
| "免费" | 免费是为了收后面的钱 |
| 群里有"托" | 你会发现总有几个账号特别热情、总在感谢老师 |
| 只推小盘股 | 大盘股拉不动 |
| 不让问具体逻辑 | "跟着做就行，别问那么多" |
| 开始卖会员/课程 | 图穷匕见 |

**正确反应**：**不进群，不扫码。**

### 套路二：带单老师 / 喊单

**流程**：

```
"老师"给你实时喊单：现在买入 XX，目标价 XX，止损 XX
你跟着做，赚了分成，亏了算你的
```

**真相**：

- 他们同时向几百人喊单，方向随机。总有一半人赚
- 赚的那一半会被要求分成，亏的那一半自己承担
- 喊单的平台往往是**他们自己的虚假平台**，你的钱根本没进市场

**识别方法**：**任何人让你在"指定平台"开户，都是骗局。** 合法的证券账户只能通过持牌券商开。

### 套路三：量化软件 / "稳赚系统"

**话术**：

> "我们的 AI 量化系统，回测年化 300%，胜率 92%，一台电脑挂机就能赚钱。"

**为什么这是假话**：

1. **回测可以随便做。** 第 12 章讲过，过拟合能做出任何你想要的曲线。一个"胜率 92%"的回测，通常意味着它用了未来数据。
2. **真能年化 300% 的人，不会卖软件。** 他会去借钱自己跑。卖软件的收入上限是几百万，自己跑的上限是无限。
3. **"挂机赚钱"违反基本常识。** 如果存在这种东西，它会被套利到消失。

**识别方法**：

| 信号 | 说明 |
|---|---|
| 展示"实盘截图" | 截图可以 P，也可以是模拟盘 |
| 强调"胜率"不强调"回撤" | 骗子只讲收益 |
| 要求你先买软件 | 他自己都不用自己的系统 |
| 提供"试用" | 让你先尝到甜头（模拟盈利），再买 |

**检查方法**：问他一句——**"这个策略的最大回撤是多少？"**

骗子通常答不上来，或者答"没有回撤"（这是不可能的）。

### 套路四：场外配资（违法）

**话术**：

> "10 倍杠杆，1000 元变 1 万，涨 10% 你就翻倍。"

**真相**：

```
10 倍杠杆，标的跌 10% → 你的本金归零
10 倍杠杆，标的跌 5% → 你亏掉 50%
```

**而且这是违法的。** 场外配资属于非法经营证券业务，不受任何法律保护。平台跑路、强制平仓、资金挪用，你无处申诉。

**识别方法**：任何提供"杠杆"、"配资"、"放大资金"的非券商渠道，一律是违法的。

**唯一的合法杠杆是融资融券**，门槛 50 万资产 + 半年经验，而且杠杆通常只有 1 倍左右。

### 套路五：虚假交易平台（黑平台）

**流程**：

```
第 1 步：给你一个"交易软件"下载链接（不是应用商店的）
第 2 步：软件界面和正规软件一模一样，行情也对得上
第 3 步：你入金，能正常买卖，还能小赚
第 4 步：想出金 → "系统维护" → "需要交保证金" → "需要交税" → 无限循环
第 5 步：平台关闭，换域名重开
```

**关键识别点**：

| 信号 | 说明 |
|---|---|
| 软件来源不明 | 只能从链接下载，应用商店搜不到 |
| 入金方式奇怪 | 让你转到**个人账户**或"客服提供的账户" |
| 出金有阻碍 | 任何"出金需要先交钱"都是骗局 |
| 承诺高收益 | 正规券商从不承诺收益 |

**正确做法**：**只在持牌券商的官方 App 交易。** 应用商店搜索，或者券商官网下载。

### 套路六：杀猪盘（最危险）

**流程**：

```
第 1 步：社交平台认识（婚恋、兴趣群、游戏），建立感情或信任
第 2 步：无意中透露"我在做投资，收益不错"
第 3 步：带你小赚几次（钱是他打给你的，让你相信平台真实）
第 4 步：鼓励你加大投入，"我们一起攒钱买房"
第 5 步：你投入全部积蓄 → 平台无法提现 → 人消失
```

**这个套路最可怕的地方**：它先建立情感连接，再动你的钱。理性判断在情感面前会失效。

**识别方法**：

**任何在网上认识的人，主动跟你聊投资、带你赚钱，100% 是杀猪盘。** 没有例外。

## 14.3 遇到这些话术，立刻离开

把这几句记下来。听到任意一句，不需要思考，直接退出：

```
□ "稳赚不赔" / "保本保收益"
□ "内部消息" / "主力要拉这只票"
□ "AI 量化，年化 300%"
□ "跟着老师做，不用自己判断"
□ "先交会员费 / 软件费 / 保证金"
□ "在我们平台开户，手续费更低"
□ "出金需要先交税 / 交保证金"
□ "这个链接下载，应用商店没有"
□ "加我微信，拉你进群"
□ "我舅舅在证监会 / 我认识庄家"
```

**"保本保收益"这五个字本身就是违法的。** 任何金融产品都不能承诺保本保收益（资管新规后，银行理财都不能承诺了）。

## 14.4 三条红线

### 红线一：不加杠杆

| 形式 | 是否合法 |
|---|---|
| 融资融券（券商） | 合法，门槛 50 万 |
| 场外配资 | **违法** |
| 借钱炒股 | 合法但**极其危险** |
| 信用卡套现炒股 | 违规，且危险 |

**为什么这是红线**：杠杆会放大亏损，且触发强制平仓。**用杠杆的人不是在投资，是在赌自己不会被强平。**

1000 元本金，你没有资格加杠杆，也不需要。你的目标是学会，不是暴富。

### 红线二：只在持牌机构交易

**如何验证**：

| 要查什么 | 去哪查 |
|---|---|
| 券商是否合法 | 中国证监会官网 → 合法机构名录 |
| 从业人员是否合法 | 中国证券业协会 → 从业人员信息公示 |
| 基金是否合法 | 中国证券投资基金业协会 → 信息公示 |
| 公司是否真实存在 | 国家企业信用信息公示系统 |

**证监会官网**：`www.csrc.gov.cn`
**中国证券业协会**：`www.sac.net.cn`

**查询是免费的，30 秒能查完。** 任何让你犹豫的平台，先查再说。

### 红线三：账户不交给任何人

| 行为 | 风险 |
|---|---|
| 把账号密码给"老师"代操作 | 资金可能被转走，且**你可能要承担全部亏损** |
| 签"代客理财"协议 | 多数无效，且可能涉及非法经营 |
| 用别人的账户交易 | 违规，且资金安全无保障 |

**法律事实**：证券账户实名制。**账户里的钱是你的，但账户被用来做什么，你要负责。**

如果别人用你的账户做违规交易（如操纵市场），你要承担后果。

## 14.5 一个真实的比例

说一个不好听但必要的事实。

**A 股个人投资者中，长期（5 年以上）能稳定盈利的比例，各种研究给出的数字通常在 10%–20% 之间。**

这意味着：**你身边 10 个股民里，大概 8 个是亏的。**

这不是劝你别玩，是让你调整预期：

```
你的目标不该是"成为那 10%"
而该是"不要成为那 80%"
```

**这两个目标的实现路径完全不同：**

| 目标 | 需要什么 | 成功率 |
|---|---|---|
| 成为前 10% | 极强判断力 + 大量时间 + 运气 | 很低 |
| 不成为后 80% | **不做蠢事**（高杠杆、频繁交易、听消息、追涨） | 很高 |

**"不亏"比"赚"容易得多，而且它本身就让你进入了前 20%。**

## 14.6 如果已经被骗了

不要羞愧，先做四件事：

```
1. 立刻停止转账，不要再"交保证金解冻"
2. 保存所有证据：聊天记录、转账凭证、平台截图、对方账号
3. 报警（110 或到派出所），说明是电信网络诈骗
4. 拨打 12386（证监会服务热线）举报非法证券活动
```

**关于第 1 条**：骗子最常用的二次收割话术是"你的账户被冻结了，交 20% 保证金就能解冻"。**这是假的。** 交了就再也没了。

**关于报警**：越早越好。资金一旦被多层转移，追回难度急剧上升。

---

## 本章要记住的 3 件事

1. **所有骗局的第一阶段都不图你的本金，图你的信任。** "免费"是最贵的东西。
2. **"保本保收益"本身就是违法的。** 任何说这五个字的人或平台，直接判定为骗局。
3. **你的目标不是成为前 10%，是不成为后 80%。** "不亏"比"赚"容易，而且效果一样。

## 动手做

### 练习 14-1：查一次合法机构（10 分钟）

1. 打开证监会官网（csrc.gov.cn）
2. 找到"合法机构名录"
3. 查一下你开户的券商在不在这份名单里
4. 顺便看一下名单里的机构总数

**目的**：让你知道"查询"这个动作只要 30 秒，从而在犹豫时愿意去查。

### 练习 14-2：做一次"骗局识别"练习（30 分钟）

在短视频平台刷 30 分钟"理财/炒股"内容，把上面 14.3 的话术清单打印出来，一条条对照。

**记录你遇到了几条。** 大多数人会在 30 分钟内遇到 5 条以上。

### 练习 14-3：给你的家人写一段话（10 分钟）

写一段 100 字左右的话，告诉家里长辈：

```
什么样的"投资"一定是骗局
（重点：保本高收益、让你转账到个人账户、让你下载陌生 App）
```

**为什么做这个练习**：你学会了防范，但你的父母可能正在被"养老理财"套路。**这个练习可能比这本书其他任何一章都更值钱。**
