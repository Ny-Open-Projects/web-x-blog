# 附录 D 从入门到精通路线图

> 这一页是全书的总纲：回答"我现在在哪、下一步学什么、大概要多久"。
> 配合 20.7 的四级标准使用。

---

## D.1 四个阶段

```
入门（3–6 个月）→ 上手（1 年）→ 进阶（2–3 年）→ 系统化（3–5 年）
```

**注意：时间是陪伴实操的，不是纯读书的。** 每个阶段的核心都是"边做边学"，读书只占 20%。

---

## D.2 自评表：你现在在哪一级

逐项打勾（20 项，每级 5 项）：

### 入门级（第 1–14 章）

```
□ 1. 能口算一笔交易的全部费用（含最低 5 元佣金）
□ 2. 能解释 T+1、涨跌停、集合竞价、除权除息
□ 3. 完成过开户，并核对过交割单
□ 4. 完成过 20 笔模拟交易且有记录
□ 5. 知道止损执行率，并且 ≥ 80%
```

### 上手级（第 15、19 章）

```
□ 6. 有书面的目标配置（股/债/金/现金比例）
□ 7. 知道自己的组合再平衡规则（定期 + 阈值）
□ 8. 持有过债券类或黄金类资产，知道它们的功能定位
□ 9. 会按"五查 + 编制方案"挑选 ETF
□ 10. 用"买偏离"或低频再平衡管理过至少一次比例偏离
```

### 进阶级（第 16–18 章）

```
□ 11. 能说清一个因子的收益来源（风险补偿/行为偏差/制度套利）
□ 12. 做过至少一次样本外检验，知道自己的策略有没有过拟合
□ 13. 维护着假设登记表（H-001 起编号）
□ 14. 算过组合内资产的相关性
□ 15. 有书面的暴跌预案和风险预算表
```

### 系统级（第 17、20 章）

```
□ 16. 交易系统的四模块全部书面化（信号/仓位/执行/复盘）
□ 17. 每周流程 < 3 小时，不看每日盘面
□ 18. 连续 12 个月产出月报
□ 19. 系统有过正式的版本迭代（v1.x 变更记录）
□ 20. 经历过一轮 20%+ 的回撤并按预案执行了
```

### 评级

| 达成 | 你在这里 |
|---|---|
| ≤ 5 项 | **入门中**——按第 13 章的 90 天计划走 |
| 6–10 | **上手中**——重点补第 15、19 章，开始配置 |
| 11–15 | **进阶中**——重点补第 16–18 章，开始研究 |
| 16–20 | **系统化中**——重点是让系统跑过一轮完整牛熊 |

## D.3 每个阶段的学什么、读什么

### 阶段一：入门（本书第 1–14 章 + 90 天计划）

| 内容 | 资源 |
|---|---|
| 规则与费用 | 本书 1–3 章 + 交易所投教网站 |
| 操作 | 本书 4–5 章 + 模拟盘 |
| 方法 | 本书 6–7 章 |
| 风控与心理 | 本书 8–9 章（**最重要的两章**） |
| 防骗 | 本书 14 章 |
| 书 | 《漫步华尔街》《共同基金常识》（附录 C） |

**毕业标准**：90 天计划完成，评估表 9–10 分（第 13.2 节）。

### 阶段二：上手（开始真实配置）

| 内容 | 资源 |
|---|---|
| 资产配置 | 本书 15 章 |
| 资产扩展 | 本书 19 章 |
| 资金要求 | 建议 ≥ 1 万（配置才可操作） |
| 书 | 《投资者的未来》（西格尔） |

**毕业标准**：组合里至少有两类低相关资产，经历过一次再平衡。

### 阶段三：进阶（开始研究）

| 内容 | 资源 |
|---|---|
| 因子 | 本书 16 章 + 中证指数官网的 Smart Beta 指数方案 |
| 研究流程 | 本书 17 章 + 自己的假设登记表 |
| 风险管理 | 本书 18 章 |
| 回测深化 | 本书 12 章 + rqalpha/backtrader 文档 |
| 书 | 《主动投资组合管理》（Grinold & Kahn，**难，选读**）；《投资者的心灵修炼》 |

**毕业标准**：至少 3 个假设走完"登记→验证→结论"全程，其中至少 1 个被放弃。

### 阶段四：系统化（第 17、20 章 + 时间）

| 内容 | 资源 |
|---|---|
| 系统四模块 | 本书 20 章 |
| 工具链 | akshare/tushare 文档、rqalpha 源码 |
| 纪律 | 自己的月报（连续 12 期） |
| 书 | 《海龟交易法则》（看规则化思想，不必照抄）；行为金融学教材 |

**毕业标准**：系统跑过一轮 20%+ 回撤并按预案执行；系统有过基于实验的版本迭代。

## D.4 每阶段的时间与资金参考

| 阶段 | 时长 | 建议资金 | 该做的事 |
|---|---|---|---|
| 入门 | 3–6 月 | 1000–5000 元 | 模拟盘 + 小额实盘走流程 |
| 上手 | 1 年 | 1–10 万 | 建配置、定投、第一次再平衡 |
| 进阶 | 2–3 年 | 10 万+ | 研究假设、因子实践、风险管理落地 |
| 系统化 | 3–5 年 | 视个人 | 系统运转、经历完整牛熊 |

**资金的顺序不能颠倒**：先有小资金走完流程，再放大资金。**跳级 = 用大钱买你还没学会的教训。**

## D.5 贯穿全程的四条不变量

无论走到哪个阶段，这四条永远成立（它们是全书的骨架）：

```
① 费用是唯一确定的敌人（第 3 章）
   → 任何阶段，降低交易频率永远优先于任何优化

② 回撤的不对称性决定防守优先（第 8 章）
   → 亏 50% 要涨 100%，任何阶段都一样

③ 可证伪性是判断任何"方法"的第一标准（第 11、17 章）
   → 解释一切的理论，指导不了任何一次下单

④ 情绪无法靠意志力解决，只能靠预案（第 9、18 章）
   → 所有关键决策，必须在平静时预先写好
```

## D.6 最后一页

这本书的开始是一个问题："我投 200–1000 元，能挣钱吗？"

全书的答案是：**不能，而且这个答案越早接受越好。**

但这 1000 元买到的东西是真实的：

```
一套不会让你亏光 100 万的规则
一个能识别 90% 骗局的免疫体系
一份关于你自己的行为数据
一条从"凭感觉"到"讲证据"的路径
```

**剩下的路，是你的 90 天计划、你的一年配置、你的三年系统，一步一步走出来的。**

市场永远在，规则不会失效。慢，就是快。
