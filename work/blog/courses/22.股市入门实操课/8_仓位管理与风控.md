# 第 8 章 仓位管理与风控

> 本章目标：这一章是全书最重要的一章。
> 前七章教你怎么看，这一章教你怎么"活下来"。
> 如果只能读一章，读这一章。

---

## 8.1 一个必须先接受的事实

**你一定会看错。**

不是"可能会"，是"一定会"。而且会经常看错。

任何声称高胜率的策略，在真实市场里胜率通常在 45%–55% 之间。这意味着**你有一半的时间是错的**。

那么问题就变成：

> 既然一半会错，我怎么能不死？

答案只有一个：**让每次错的时候，亏得少。**

这就是仓位管理和风险控制要解决的全部问题。它不提高你的胜率，它只保证你错的时候能继续玩下去。

### 一个思想实验

两个人，各 1000 元，各做 10 笔交易，都是 5 胜 5 负。

| | 甲 | 乙 |
|---|---|---|
| 赢的时候 | +50% | +10% |
| 输的时候 | −50% | −10% |
| 结果 | 越赚越少，越亏越多 | 复利增长 |

甲的算账：

```
1000 → 赢 → 1500 → 输 → 750 → 赢 → 1125 → 输 → 562 → ...
10 笔后约 610 元
```

乙的算账：

```
1000 → 赢 → 1100 → 输 → 990 → 赢 → 1089 → 输 → 980 → ...
10 笔后约 1050 元
```

**同样的胜率，结果差了 72%。**

原因：亏损和盈利的复利不对称。亏 50% 需要涨 100% 才能回本。这个数学事实叫"**回撤的不对称性**"：

| 亏了多少 | 需要涨多少才回本 |
|---|---|
| 10% | 11.1% |
| 20% | 25% |
| 30% | 42.9% |
| **50%** | **100%** |
| 70% | 233% |
| 90% | 900% |

**这张表是全书最重要的表。** 它说明：**防守的价值远高于进攻。**

## 8.2 先决定最多亏多少，再决定买多少

这是仓位管理的核心公式，顺序绝对不能反。

```
第一步：确定单笔最大可承受亏损（占总资金比例）
第二步：确定止损幅度
第三步：反推仓位
```

```
仓位金额 = 单笔最大亏损额 ÷ 止损幅度
```

### 标准版本：2% 法则

| 项目 | 数值 |
|---|---|
| 本金 | 1000 元 |
| 单笔最大亏损 | 2% = **20 元** |
| 止损幅度 | 10% |
| **可买金额** | 20 ÷ 10% = **200 元** |

**200 元买不了任何东西。** 1 手 510300 就要 413 元。

这就是小资金面临的第一个数学困境。

---

## 8.3 小资金的真实困境（必须讲清楚）

2% 法则是机构和小资金通用的标准，但它在 1000 元本金上**无法执行**。原因：

```
最小交易单位 = 1 手 = 413 元（510300）
若止损 10% → 单笔亏损 = 41.3 元 = 本金的 4.1%
→ 已经是 2% 法则的两倍
```

**买 2 手更糟**：

```
2 手 = 826 元
止损 10% → 亏损 82.6 元 = 本金的 8.3%
```

连续错三次：1000 → 917 → 841 → 771，**三次错误就亏掉 23%**。

### 所以你有三个选择

| 方案 | 做法 | 单笔风险 | 代价 |
|---|---|---|---|
| **A. 只买 1 手 + 留大量现金** | 413 元仓位，587 元现金 | **4.1%** | 资金利用率低（但对你反而是好事） |
| **B. 买 2 手 + 收紧止损** | 826 元仓位，止损 5% | 4.1% | 止损太窄，ETF 正常波动就被打掉 |
| **C. 接受更高风险** | 826 元仓位，止损 10% | 8.3% | **不建议**，三次错就伤筋动骨 |

### 我的建议：方案 A

```
1000 元本金
持仓：1 手 510300 = 413 元（仓位 41%）
现金：587 元
止损：-10%（亏 41 元 = 本金 4.1%）
```

**方案 A 有一个必须说清的代价：单位成本翻倍。**

```
2 手 826 元：往返佣金 10 元 → 占 1.21%
1 手 413 元：往返佣金 10 元 → 占 2.42%   ← 翻倍
```

因为佣金最低 5 元是**固定成本**，仓位越小，它占的比例越高（第 3 章"成本临界点"）。

**但这不构成反对理由**，前提是你同时接受另一条约束：

```
1 手 + 一年 2–3 次   → 年成本 7.3% 以下，可接受 ✅
1 手 + 每月 2 次     → 年成本 58%，灾难 ❌
```

**换句话说："小仓位"必须和"低频率"配套。** 第 8 章和第 3 章在这里交汇：仓位决定风险暴露，频率决定成本拖累，**两者一起才决定你能不能活下来**。

**为什么接受"资金利用率低"**：

1. 你现在是学习阶段，**仓位低意味着犯错成本低**。这 587 元现金不是浪费，是保险。
2. 满仓的唯一好处是"涨的时候赚得多"，但你现在的目标不是赚得多。
3. **保留现金 = 保留选择权**。当市场大跌、估值分位从 55% 掉到 20% 时，你有钱加仓。满仓的人只能看着。

> **这不是"保守"，这是"给自己留后手"。**

### 修正第 4 章的建议

第 4 章的练习是"买 2 手走流程"——那是**为了体验完整流程**（含卖出、交割单核对），可以做。

但**长期持仓应该是 1 手 + 现金**。这两件事不矛盾：练习时买 2 手然后卖掉，之后正式开始只买 1 手。

## 8.4 止损：为什么它反人性但必须做

### 止损的本质

止损不是"承认自己错了"，是**在下单前就把最大损失锁死**。

```
没有止损：亏损无上限（理论上股票可以跌 90% 以上）
有止损：亏损 = 预设幅度
```

### 三种止损方式

| 类型 | 触发条件 | 优点 | 缺点 |
|---|---|---|---|
| **价格止损** | 跌到某个价位（如 -10%） | 客观、可执行 | 可能被正常波动打掉 |
| **时间止损** | 持有 N 天仍未达预期 | 释放被占用的资金 | 判断标准主观 |
| **逻辑止损** | 买入的理由消失了（如指数成分变化、基本面恶化） | 最符合本质 | 需要判断力 |

**对 1000 元本金的你**：

- 主用**价格止损**（简单、客观）
- 宽基 ETF 用 **-15%**（因为 ETF 波动小，10% 容易被噪音触发）
- 个股用 **-10%**（个股风险更大）

### 止损的执行难点

必须提前知道这三件事，否则你会当场犹豫：

**① 跌停卖不掉。**

如果标的跌停（-10%），你的止损单挂在跌停价上，但前面排着几十万手卖单，你成交不了。第二天可能继续跌停。

**应对**：**止损位不要设在整数关口和跌停价附近**，设在它们上方一点。

**② 跳空缺口。**

今天收盘 4.13，明天因为利空消息直接开盘 3.90，跌幅 5.6%。你的 -15% 止损单在 3.90 直接就触发了，但成交价是 3.90 不是 3.51。

**应对**：止损是"触发即卖"，不是"保证以这个价格卖"。接受这个现实。

**③ 心理上的"再等等"。**

这是最常见的失败。价格跌到你的止损位，你会想"再等等，说不定明天就反弹了"。

**应对**：**下单时直接挂条件单**。很多券商支持"止损委托"（价格跌到 X 自动卖出）。用工具代替意志力。

### 一个反直觉的事实

**止损会让你错过很多反弹。** 这是真的。

你止损之后，股票第二天涨回来，你会非常难受。这种情况会发生很多次。

**但你无法预先知道哪次会反弹、哪次会继续跌。** 止损的作用不是"每次都正确"，是"保证单次错误不致命"。

## 8.5 最大回撤：你真正该关心的指标

收益率是别人评价你的标准，**最大回撤是你自己该关心的标准**。

### 定义

```
最大回撤 = 从历史最高点到之后最低点的最大跌幅
```

举例：

```
账户从 1000 涨到 1200（高点）
然后跌到 900（低点）
最大回撤 = (900 - 1200) ÷ 1200 = -25%
```

### 为什么它比收益率重要

因为它决定你**能不能拿得住**。

| 最大回撤 | 需要多久回本（假设年化 8%） | 你的心理状态 |
|---|---|---|
| -10% | 约 1.3 年 | 还好 |
| -20% | 约 2.8 年 | 焦虑 |
| -30% | 约 4.5 年 | 想清仓 |
| **-50%** | **约 8.6 年** | **大概率割在底部** |

**关键洞察**：回撤超过你的心理承受能力时，你会在最低点卖出。**这时候的"回撤"就变成了"永久损失"。**

### A 股宽基的历史回撤（作为心理准备）

| 时期 | 沪深300 最大回撤 |
|---|---|
| 2007–2008 | 约 **-72%** |
| 2015–2016 | 约 **-47%** |
| 2018 | 约 **-32%** |
| 2021–2024 | 约 **-45%** |

**这不是恐吓，这是让你提前知道"会发生什么"。**

你买入宽基 ETF 的时候，必须在心里接受：**未来某一天，我的账户会从最高点跌掉 40% 以上，并且持续两三年。**

如果你接受不了，说明你的仓位太重了——减到你能接受为止。

### 一个实用的心理测试

```
假设明天你的账户从 1000 元变成 600 元（-40%），
你会：
A. 立刻卖出，再也不碰
B. 焦虑但不动，每天看盘
C. 加仓
```

- 选 A → **仓位太重，减到 400 元以内**
- 选 B → 仓位合适，但需要第 9 章的心理训练
- 选 C → 你可能高估了自己的承受力，等真的跌 40% 再说

## 8.6 三种仓位模型

### 模型一：固定比例（最适合新手）

```
每次买入，仓位不超过总资金的 X%
```

| 阶段 | 单次仓位 | 说明 |
|---|---|---|
| 学习期（前 3 个月） | **40%** | 1000 元 → 400 元（1 手 ETF） |
| 熟练后 | 60% | |
| 有 3 年以上经验 | 80% | |

**永远不满仓。** 至少留 20% 现金。

### 模型二：估值联动（进阶，推荐学会）

把第 7 章的估值分位和仓位绑定：

| PE 历史分位 | 目标仓位 |
|---|---|
| 0% – 20% | **80% – 100%** |
| 20% – 40% | 60% – 80% |
| 40% – 60% | **40% – 60%** |
| 60% – 80% | 20% – 40% |
| 80% – 100% | **0% – 20%** |

**用法**：每月查一次分位，把仓位调整到对应区间。

这个模型的好处：**它强制你"便宜时多买、贵时少买"**，而这正是普通人最难做到的（人性让你反过来）。

**1000 元本金怎么用**：因为最小单位是 413 元，你只能在 0%、41%、82% 三档之间跳。所以：

- 分位 < 40% → 1 手（41%）
- 分位 40%–70% → 1 手（维持）
- 分位 > 70% → 0 手（清仓或空仓等）

**小资金的仓位精度很低，这是数学限制，接受它。**

### 模型三：核心-卫星（资金大了再用）

```
核心（80%）：宽基 ETF，长期持有，不动
卫星（20%）：个股或行业 ETF，主动操作
```

**这个模型的意义**：把"投资"和"娱乐"分开。80% 的钱按纪律走，20% 的钱让你满足"我想试试"的冲动。

**1000 元本金不建议用**——200 元的卫星仓买不了任何东西。等资金到 5 万以上再说。

## 8.7 分散的真相

"不要把鸡蛋放在一个篮子里"这句话被说烂了，但多数人理解错了。

### 假分散

```
买 3 只银行股 → 相关性 0.9 以上，等于买 1 只
买沪深300ETF + 中证500ETF → 相关性 0.8 以上，分散效果有限
买 5 只新能源行业的股票 → 同涨同跌，完全没分散
```

**分散的关键不是"数量"，是"相关性"。** 两个高度相关的资产放在一起，不叫分散。

### 真分散

| 组合 | 相关性 | 效果 |
|---|---|---|
| 沪深300 + 中证500 | 0.8 | 弱 |
| 沪深300 + 黄金 ETF | 约 0.1 | **强** |
| A 股 + 美股 | 约 0.3 | 中 |
| 股票 + 债券 | 负相关或接近 0 | **强** |

### 对 1000 元本金的现实

**你做不到真分散。**

- 1 手 510300 = 413 元，买 2 只不同资产要 826 元，剩 174 元
- 而"股票 + 债券"的组合，债券 ETF 一手通常也要 100 元左右，可以买

但这意义不大。**1000 元的正确策略不是"分散"，是"少亏"。**

**结论**：1000 元只买 1 个宽基 ETF，不要试图分散。分散是资金到 10 万以上才需要考虑的问题。

## 8.8 把这一章变成一张检查表

每次下单前，逐条打勾：

```
□ 1. 我这笔最多能亏多少钱？（写下来，精确到元）
□ 2. 这笔亏损占总资金的百分比是多少？（超过 5% 就减仓）
□ 3. 我的止损位在哪里？（具体价格）
□ 4. 止损位距离现价多少？（决定仓位大小）
□ 5. 我有没有挂条件单/止损单？（没有就现在挂）
□ 6. 买入理由是什么？（一句话写下来）
□ 7. 如果判断错了，什么信号会告诉我？（逻辑止损条件）
□ 8. 这笔钱未来 6 个月会不会用到？（会 → 不买）
□ 9. 现在估值分位是多少？（决定该不该买）
□ 10. 我是不是因为"怕错过"才想买？（是 → 不买）
```

**第 10 条最难，也最重要。** FOMO（错失恐惧）是所有亏损的起点。

## 本章要记住的 3 件事

1. **亏 50% 需要涨 100% 才回本。** 防守的价值永远高于进攻，这张回撤表要背下来。
2. **小资金无法执行 2% 法则，这是数学限制。** 1000 元的正确做法是"1 手 + 大量现金"，接受 4% 的单笔风险，而不是硬凑 2%。
3. **分散看相关性，不看数量。** 1000 元不需要分散，只需要少亏。
