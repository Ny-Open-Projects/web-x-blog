# LeetCode 556. 下一个更大元素 III (go)

> 来源：[Wang's Blog](https://blog.csdn.net/tyro_java/article/details/145397820)
> 语言：**go**（由 TypeScript 等价转写）

## 题目描述

- - 
- 给你一个正整数 n ，请你找出符合条件的最小整数，其由重新排列 n 中存在的每位数字组成，并且其值大于 n 。如果不存在这样的正整数，则返回 -1
- - 
- 注意 ，返回的整数应当是一个 32 位整数 ，如果存在满足题意的答案，但不是 32 位整数 ，同样返回 -1

## 示例

```
输入：n = 12
输出：21

输入：n = 12
输出：21

输入：n = 21
输出：-1

输入：n = 21
输出：-1
```

## 提示

- 1 <= n <= 
 2
 31
 2^{31}
 231 - 1
