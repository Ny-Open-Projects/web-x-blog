# 第 18 章 风险管理进阶

> 本章目标：从"单笔止损"（第 8 章）升级到"组合层面的风险管理"。
> 核心内容：波动率的可预测性、相关性怎么用、凯利公式为什么危险、尾部风险的现实。
> 这一章假设你已理解第 8 章的回撤不对称性。

## 18.1 一个重要且令人安心的区分

> **收益几乎不可预测，但风险（波动率）是可预测的。**

这是风险管理能成立的基础。

| 变量 | 可预测性 | 证据 |
|---|---|---|
| 明天涨还是跌 | 几乎为零 | 第 11 章：短期接近随机 |
| 明天波动多大 | **相当可预测** | 波动率有"聚集性"：今天波动大，明天大概率也大 |
| 下月收益分布的大致范围 | 部分 | 估值分位 + 当前波动率能给出大致区间 |

**波动率聚集性**是金融数据的经典特征：平静的市场倾向于继续平静，恐慌的市场倾向于继续恐慌。

**实战含义**：你无法预测明天涨跌，但你**可以**在市场波动率升高时降低仓位、在波动率极低时保持警惕。**这是有数据支持的仓位调节依据**，比任何"感觉要跌"都可靠。

## 18.2 相关性：组合风险的乘法器

### 定义与直觉

```
相关性 ρ ∈ [-1, +1]
ρ = +1   两个资产完全同涨同跌（等于同一个资产）
ρ = 0    涨跌无关
ρ = -1   完全反向（完美对冲）
```

### 组合波动率的公式（两个资产）

```
σ²组合 = w1²σ1² + w2²σ2² + 2·w1·w2·ρ·σ1·σ2
                                ↑
                    这一项由相关性决定，ρ 越小组合越稳
```

### A 股常见资产对的经验相关性（大致量级）

| 资产对 | 相关性 | 配置价值 |
|---|---|---|
| 沪深300 ↔ 中证500 | 0.8+ | **弱**，分散效果有限 |
| 沪深300 ↔ 债券 | 约 0 至略负 | **强**，经典组合 |
| A 股 ↔ 黄金 | 接近 0 | **强** |
| A 股 ↔ 美股 | 约 0.3–0.5（危机时上升） | 中 |
| 同行业两只股票 | 0.85+ | **假分散** |

### 危机时刻的警告：相关性会上升

**平时相关性低的资产，在暴跌时可能一起跌**（"所有风险资产的相关性在危机中趋近于 1"）。

所以"分散"的真实效果是：**平时让你更平稳，但不保证在最大危机中保护你。** 真正的危机保护来自两样东西：**现金仓位和债券**。

这就是第 15 章股债配置的价值——它不是收益最高的方案，是**危机中唯一大概率有效的方案**。

## 18.3 凯利公式：为什么你应该只用半凯利，甚至不用

### 公式

离散版的凯利公式给出"最优下注比例"：

```
f* = p − q/b
其中：
  p = 胜率
  q = 1 − p（败率）
  b = 盈亏比（赢时赚 p/b 元的期望…简化：赢多少 / 输多少）
```

**算例**：胜率 55%，赢时赚 10%，输时亏 10%（b=1）：

```
f* = 0.55 − 0.45/1 = 0.10 → 每次应押 10%
```

### 凯利公式的三个致命问题

**① 你的 p 和 b 是估的，不是真的。**

凯利对参数误差极其敏感。你以为胜率 55%（实际 48%），凯利会告诉你押 10%，而真实最优是 0——**参数稍微高估，凯利就从"最优"变成"自杀公式"**。实证上，胜率高估 5 个百分点，长期破产概率会大幅上升。

**② 满凯利的波动让人无法执行。**

满凯利策略的回撤极深（理论上最大回撤超过 50% 是常态）。**你几乎一定会在回撤中放弃执行**——然后凯利的数学保证就失效了。

**③ A 股的约束让它更不可行。**

T+1、涨跌停、最小 1 手（第 2 章），让"精确按 f* 比例下注"物理上做不到。

### 实用建议

```
机构常用：半凯利（f*/2）——波动减半，长期收益只损失约 25%
你的情况：第 8 章的"单笔风险 ≤ 2%–4%" 已经 implicitly 比满凯利保守得多，
          继续用它。凯利公式作为"上限检查"工具：
          如果你的仓位算出来超过半凯利，说明你押太重了
```

**把凯利用作"不许超过的天花板"，而不是"应该达到的目标"。**

## 18.4 尾部风险：你的止损单救不了你

第 8 章讲过止损的三个执行难点（跌停、跳空、心理）。这一章把它升级为"尾部风险"的完整图景。

### 金融市场是肥尾的

正态分布假设下，沪深300 单日跌 8% 的概率小到几乎不会发生。**现实中它发生过多次。**

| 现象 | 正态分布预期 | 现实 |
|---|---|---|
| 单日 ±5% 以上的极端日 | 极罕见 | A 股历史上出现上百次 |
| 连续跌停 | 几乎不可能 | ST 股常见，2015 年千股跌停 |

**肥尾的含义**：极端事件的概率远比你想象的大，而**你的止损在极端事件中会失效**（跳空穿越止损价、跌停卖不出）。

### 对策：不是更好的止损，而是更低的仓位

尾部风险面前，止损是"事后补救"，仓位是"事前防御"：

```
应对尾部风险的检查单：
□ 单一标的 ≤ 总资金 40%（第 8 章）
□ 单一行业 ≤ 总资金 30%（即使买行业 ETF）
□ 永远保留 ≥ 20% 现金（危机时它既是缓冲又是弹药）
□ 不使用任何杠杆（第 14 章红线）
□ 接受"极端日一定会发生"这件事，提前写好当天的动作预案
```

**最后一条最实用**：暴跌那天你会肾上腺素飙升、无法思考。**预案必须是平静时写好的**：

```
我的暴跌预案：
- 指数单日跌 > 5%：我不做任何操作，收盘后检查估值分位
- 我的持仓跌 > 15%：检查是否触发止损条件，触发则次日执行
- 出现千股跌停类极端：不抄底、不割肉，等三天再决策
```

## 18.5 波动率目标：一个简单可用的仓位调节器

这是本章最实用的工具。原理：**波动大就少拿仓位，波动小就多拿**，让组合的实际波动稳定在目标附近。

### 简化版操作

```
1. 计算过去 20 日沪深300 的日波动率 σ（日线标准差）
2. 年化：σ_年 = σ × √252
3. 目标波动率：设为 15%（一个温和值）
4. 目标仓位 = 目标波动率 ÷ σ_年，上限 100%

例：
  当前 σ_年 = 12% → 仓位 = 15/12 = 125% → 封顶 100%
  当前 σ_年 = 30% → 仓位 = 15/30 = 50%
  当前 σ_年 = 45%（恐慌期）→ 仓位 = 33%
```

**为什么它有效**：它自动实现"恐慌期减仓、平静期持仓"，而这两件事恰好是散户最难做到的（恐慌时想割、平静时想梭哈）。

**在哪查**：很多行情软件有"历史波动率"指标（HV20 = 20 日历史波动率），可以直接读数。

**限制**：它不能让你逃过第一天下跌（波动率上升是滞后的），它只是**长期把你的风险暴露维持在可承受范围**。

## 18.6 风险预算：一张表管住整个组合

把前面所有内容收口成一张风险预算表（资金到 1 万以上就该用）：

| 预算项 | 上限 | 为什么 |
|---|---|---|
| 单一标的 | 40% | 个股黑天鹅（财报暴雷、退市） |
| 单一行业 | 30% | 行业政策风险 |
| 单一策略 | 50% | 策略失效（第 17 章） |
| 单日最大亏损 | 总资金 2%–4% | 第 8 章 |
| 杠杆 | **0** | 第 14 章红线 |
| 现金下限 | 20% | 尾部缓冲 |

**用法**：每次想加仓时，先检查加完后是否突破任何一项上限。**突破任何一条 → 不加。**

这张表的价值和第 8 章的下单十条检查一样：**它让你在情绪上头时，有一个冷静的自己写好的答案。**

---

## 本章要记住的 3 件事

1. **收益不可预测，但波动率可预测。** 波动率聚集是真实规律，用它调节仓位比"感觉要跌"可靠。
2. **凯利公式只能当天花板，不能当目标。** 你的参数是估的，参数误差会把"最优"变成"自杀"。坚持第 8 章的 2%–4% 单笔风险。
3. **尾部风险面前，止损会失效，仓位才是防御。** 肥尾是常态：提前写好暴跌预案，比暴跌当天想破头有用一万倍。
