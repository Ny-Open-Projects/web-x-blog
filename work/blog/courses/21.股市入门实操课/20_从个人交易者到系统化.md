# 第 20 章 从个人交易者到系统化

> 本章是全书的收口：把前面 19 章的东西，装进一个可持续运转的**系统**。
> 精通的定义不是会多少技巧，而是拥有一套**可复现、经过验证、纪律化**的流程，并且知道它什么时候该被推翻。

---

## 20.1 先定义"系统化"

个人交易者和系统化交易者的区别，不在资金量，在结构：

| | 个人交易者 | 系统化交易者 |
|---|---|---|
| 决策来源 | 当时的感觉、消息、心情 | 预先写好的规则 + 预先登记的假设 |
| 买入依据 | "我觉得它要涨" | "条件 X 满足，规则 Y 触发" |
| 仓位依据 | 心情好坏、胆子大小 | 风险预算表（第 18 章） |
| 复盘 | 靠记忆 | 月度报告 + 实验记录 |
| 失败后 | 换一个方法重头再来 | 定位到流程哪一步出错 |
| 时间投入 | 看盘 3 小时/天 | 流程运转 3 小时/周 |

**注意最后一行。** 系统化的直接收益是**把时间从每天变成每周**——这才是它能长期持续的原因。

---

## 20.2 系统的四个模块

```
┌────────────────────────────────────────────┐
│              你的交易系统                    │
├────────────┬────────────┬─────────────────┤
│ ① 信号模块  │ ② 仓位模块  │ ③ 执行模块       │
│ 什么时候买   │ 买多少      │ 怎么买          │
│ (第7/16章)  │ (第8/18章)  │ (第2/3章)       │
├────────────┴────────────┴─────────────────┤
│ ④ 复盘模块：记录 → 归因 → 修正 (第9/17章)     │
└────────────────────────────────────────────┘
```

四个模块全部写成**书面规则**，缺一个都不算系统。

### 模块一：信号（什么时候买/卖）

来自第 7 章和第 16 章，最小可用版本：

```
买入信号（同时满足）：
- 目标资产估值分位 < 40%（或月度定投日到达）
- 波动率目标仓位 > 当前实际仓位（第 18 章）
- 未触发任何风险预算上限

卖出信号（满足其一）：
- 估值分位 > 70% 且持有收益 > 20%
- 止损条件触发（第 8 章 ATR 法）
- 持有逻辑消失（第 8 章逻辑止损）
```

### 模块二：仓位（买多少）

直接用第 8 章 + 第 18 章的公式和预算表，不新增内容。

### 模块三：执行（怎么买）

来自第 2、3 章：限价单、9:25 后挂单、ETF 五查、条件单。**执行规则要细化到"几点、挂什么价、单笔多少"**，不留当天发挥空间。

### 模块四：复盘（怎么改进）

见 20.4。这是多数系统缺的部分——**没有复盘的系统只会重复错误。**

## 20.3 工具链：程序员的最小系统

A 股散户没有程序化下单通道（第 13 章讲过：券商 API 门槛 50 万 + 报备），所以你的系统注定是**半自动**：

```
自动化：数据获取 + 信号计算 + 提醒
人工：  下单执行 + 复盘判断
```

### 最小工具链

| 层 | 工具 | 说明 |
|---|---|---|
| **数据** | akshare / baostock（免费）；tushare（部分免费） | 日线够用，注意 point-in-time 问题 |
| **计算** | Python + pandas / polars | 指标、估值分位、波动率 |
| **回测** | rqalpha / backtrader / vectorbt | 第 12 章已入门 rqalpha |
| **提醒** | 定时任务 + 推送（邮件/企业微信/Telegram） | 信号触发时通知你，而不是你盯盘 |
| **记录** | git 仓库 + 实验记录（第 17 章） | 假设登记表、月报 |

### 一个真实的周流程（每周 2–3 小时）

```
周日（1 小时）：
  □ 跑数据脚本，更新估值分位、波动率
  □ 检查是否有信号触发（买入/卖出/再平衡）
  □ 有信号 → 按规则生成 Monday 的委托清单

周一开盘后（10 分钟）：
  □ 按清单下单（限价单，9:25 后）
  □ 记录成交情况 vs 清单的偏差

月末（1 小时）：
  □ 更新持仓表、交易日志
  □ 写月度复盘（模板见 20.4）

季度（2 小时）：
  □ 回顾假设登记表：有没有该放弃的？有没有新假设？
  □ 检查风险预算是否被突破
```

**注意：没有"每天看盘"。** 系统化的直接标志就是**你不再需要每天看盘**——因为信号会来找你。

## 20.4 复盘系统：月度报告模板

每个月固定一天（如第一个周日），写一页：

```
## 组合月报 · 2026-11

### 一、结果
总资产：______ 元（月初 ______，变动 ______%）
对比基准（沪深300）：本月 ______% vs ______%，超额 ______%
年内最大回撤：______%

### 二、交易
本月交易：____ 笔
每笔是否符合规则？（逐笔 是/否）
违规交易：____ 笔，原因：______

### 三、纪律检查
□ 风险预算表有没有被突破？
□ 止损执行率：______%
□ 我有没有做过"计划外"的操作？

### 四、市场与假设
估值分位：______%（月初 ______）
波动率（HV20 年化）：______%
假设登记表更新：______

### 五、下月计划（最多 3 条）
1. ____________
2. ____________
3. ____________
```

**第五部分最多 3 条**——超过 3 条说明你在空想，不是在执行。

### 归因的纪律

复盘的核心是回答一个问题：**这个月的结果，是能力还是运气？**

| 情况 | 归因方法 |
|---|---|
| 跑赢基准 | 是因为持有的资产好，还是因为仓位时机对？（拆开看） |
| 跑输基准 | 是策略问题、执行问题，还是资产本身的问题？ |
| 违规交易 | **无论盈亏都要记录**——赚钱的违规比亏钱的违规更危险 |

第 9 章说过：**赚钱的违规交易会固化坏习惯。** 月报必须把它们抓出来。

## 20.5 系统的版本迭代

你的系统应该像软件一样有版本号和变更记录：

```
v1.0（2026-12）：
  - 信号：估值分位 + 月定投
  - 仓位：单笔 ≤ 4%，单标的 ≤ 40%
  - 执行：周一部分限价单
  - 复盘：月报模板 v1

v1.1（2027-03）变更记录：
  + 新增波动率仓位调节（第 18 章）
  + 修复：止损单忘记挂 → 加"周日检查条件单"步骤
  - 移除：行业 ETF 轮动（3 个月验证无效，见 E-003）
```

**规则：每季度至少一次正式迭代；每次变更必须写"为什么改"和"依据哪个实验"。**

没有依据的变更 = 情绪驱动 = 回到个人交易者。

## 20.6 什么时候应该彻底停下来

系统化不等于永远交易。**预先写好"退出条件"**，和写止损一样重要：

```
停下来检查的触发条件（满足任一）：
□ 连续 2 年跑输沪深300，且归因显示是策略问题而非执行问题
□ 我发现自己开始违反风险预算表且屡教不改
□ 生活发生重大变化（收入、健康、家庭），这笔钱的角色变了
□ 我发现自己不再享受这个过程，只是机械地坚持
```

**第三个触发条件最重要，也最容易被忽略。** 你的钱的角色变了（比如要买房、要养娃），配置就必须变——**这不是投资失败，是生命周期管理**（第 15 章）。

**停止交易后的钱去哪**：全部转入宽基 ETF 定投或债基组合，用最省心的方式持有。**你已经完成了一个完整的学习闭环，剩下的交给时间和复利。**

## 20.7 精通的定义

回到本章开头的问题。到这一章，你可以用这个标准自查：

| 等级 | 标志 |
|---|---|
| **入门** | 懂规则、算得清费用、会开户下单（本书第 1–14 章） |
| **上手** | 有配置、会再平衡、能独立操作 ETF 组合（第 15、19 章） |
| **进阶** | 理解因子、做过完整研究流程、有风险管理框架（第 16–18 章） |
| **系统化** | 四模块书面化、周流程运转、月报持续产出、版本迭代有据（第 20 章） |

**系统化不是终点。** 系统运转 3 年、经历过一轮牛熊的检验，你才有资格说"精通"。**在此之前，"谦逊地执行自己的规则"就是最高水平的表现。**

---

## 本章要记住的 3 件事

1. **系统 = 信号 + 仓位 + 执行 + 复盘，四个模块全部书面化。** 缺复盘模块的系统只会重复错误。
2. **系统化的直接收益是"每天看盘"变成"每周 2–3 小时"。** 信号来找你，而不是你找信号。
3. **预先写好"彻底停下来"的条件。** 生活变化、连续跑输、不再享受——都是合法的退出理由，退出不是失败。

## 动手做

### 练习 20-1：给你的系统写 v1.0（1 小时）

新建一个文档 `我的交易系统 v1.0.md`，按 20.2 的四模块写：

```
① 信号模块：买入条件 ___ 条，卖出条件 ___ 条（全部可验证，无模糊词）
② 仓位模块：单笔上限 ___%，单标的 ___%，现金下限 ___%
③ 执行模块：什么时间、什么单型、什么标的池
④ 复盘模块：月报模板（抄 20.4），复盘日定在每月 ___ 号
```

**检验**：找一个不懂股票的朋友读它。**他能复述你的规则吗？** 能，才算书面化成功。

### 练习 20-2：搭数据提醒（1 小时，程序员）

写一个脚本：每周日晚跑一次，计算沪深300 估值分位 + HV20，与你设定的阈值比较，结果发到你自己的邮箱或微信提醒。

**这一步完成后，你就正式实现了"信号找我"。**

### 练习 20-3：写你的退出条件（10 分钟）

按 20.6 的四个触发条件，结合自己的实际情况改写，存到你交易系统的文档里，和家人说一声。

**为什么要告诉家人**：真正触发那天，你需要有人提醒你"你自己写过的规则"。
