# 第 9 章 交易心理与认知偏差

> 本章目标：让你认识八个会稳定让你亏钱的心理机制，并且知道唯一有效的解药。
> 这一章没有公式，但它的杀伤力不亚于第 8 章。

---

## 9.1 一个前提：你不是理性的

经济学有一门分支叫行为金融学，它的起点是一个**实验事实**：

> 人在面对金钱风险时的决策，系统性地偏离"理性人"模型，且偏离方式是**可预测的**。

不是"有时候不理智"，是**总是朝同一个方向犯错**。这就是为什么它能被做成"清单"。

丹尼尔·卡尼曼（2002 年诺贝尔经济学奖得主）和 Amos Tversky 在 1979 年提出的**前景理论**给出了核心结论：

```
同样金额的损失带来的痛苦 ≈ 同样金额的收益带来的快乐的 2 – 2.5 倍
```

这个"2 倍"不是比喻，是实验测量出来的系数。

### 它意味着什么

```
你今天赚 100 元 → 快乐值 +1
你今天亏 100 元 → 快乐值 −2.2
```

所以一个"50% 概率赚 100，50% 概率亏 100"的公平赌局，**理性上应该接受，心理上你会拒绝**。

在股市里，这个偏差造成了第 8 章讲的"亏 50% 需要涨 100% 才回本"的加倍痛苦——不只是钱的问题，是心理上更难承受。

## 9.2 处置效应：赚了就跑，亏了死扛

**这是散户亏钱的第一大原因，没有第二。**

### 定义

```
处置效应 = 倾向于卖出盈利的资产，持有亏损的资产
```

### 典型场景

你买了 2 只 ETF：

- A 赚了 8%
- B 亏了 8%

你会怎么做？**大多数人会卖掉 A，留着 B。**

理由听起来很合理：
- "A 已经赚了，先落袋为安"
- "B 只是暂时跌，等回本我就卖"

### 为什么这是错的

```
卖出 A → 你的账户里留下的是亏损资产
留着 B → 你继续承担 B 继续下跌的风险
```

**结果是：你的组合里全是亏损的，赚钱的都被你卖了。**

长期下来，你的账户结构变成"一堆等着回本的亏损单"。

### 更深的机制

"等回本我就卖"这句话里藏着一个东西：**你把买入价当成了决策基准。**

但买入价是历史，市场不知道你的成本。**市场不会因为你亏了 8% 就对你仁慈。**

正确的判断标准只有一个：**如果我现在是空仓，我还会买它吗？**

- 会 → 继续持有
- 不会 → 卖掉，不管盈亏

### 解药

```
每次想卖的时候问自己：
"我是因为看好它卖，还是因为它赚钱了卖？"
```

如果是后者，你在执行处置效应。

## 9.3 锚定效应：你的成本价是个假锚

### 定义

```
锚定效应 = 过度依赖第一个接触到的数字做判断
```

在股市里，最常见的锚是**你的买入价**。

### 典型场景

你 4.13 元买入，现在 3.80 元。

**你的大脑会想**："跌了 8%，等回到 4.13 我就卖。"

**但市场在想什么？** 市场不知道你 4.13 买的。市场在根据公司的盈利、行业的景气度、资金的流向定价。

**"等回本"这个念头，纯粹是你和自己的一场对话，与市场无关。**

### 另一个锚：整数关口

```
"跌到 4.00 我就买"  →  结果跌到 4.01 就反弹
"涨到 5.00 我就卖"  →  结果涨到 4.98 就回落
```

整数关口没有经济学意义，但**大量的人在里面下单**，所以它变成了自我实现的支撑/阻力。这不是玄学，这是订单簿的事实。

### 解药

**把成本价从你的决策界面里去掉。**

很多交易软件可以隐藏持仓成本。**打开这个功能。** 你看不到成本，就不会被它锚定。

如果做不到，至少遵守一条：**决策时只看"现在的价格相对于价值贵不贵"，不看"我赚了还是亏了"。**

## 9.4 确认偏误：你只看得见支持自己的信息

### 定义

```
确认偏误 = 主动寻找、注意、记住支持自己观点的信息，
          忽略、贬低、遗忘反对自己的信息
```

### 典型场景

你买入了某只 ETF 后：

- 看到利好的新闻 → "我就说吧，我判断对了"
- 看到利空的新闻 → "这是短期扰动，不影响长期逻辑"
- 看到有人唱空 → "这人是韭菜/庄托"

**注意最后一条**：你会给反对意见贴标签，而不是评估它的论据。

### 为什么这很危险

因为它让你**在错误的方向上越走越深**，而且你感觉不到。

你买入的理由可能是错的，但因为所有反对信息都被过滤了，你会一直觉得自己"逻辑很完备"。

### 解药

**买入前写下"反方论点"。**

在下单之前，用三分钟写下：

```
我做多这个标的的三个理由：
1. ___________
2. ___________
3. ___________

如果有人要反驳我，他最可能说什么：
1. ___________
2. ___________

如果第 2 条成立，我该怎么调整？
___________
```

**这个动作的价值在于：它强迫你预先承认自己可能错。** 等你真的错了，你至少有一个"我自己写过"的提醒。

## 9.5 后见之明偏差：我早就知道

### 定义

```
后见之明偏差 = 事情发生后，认为自己"早就预测到了"
```

### 典型场景

市场大跌之后，你会想："我早就感觉要跌了，当时那个信号很明显。"

**但你没有卖。** 因为当时你并不确定。

### 为什么它有害

因为它让你**高估自己的判断力**，从而在下次下更大的注。

"我上次看对了" → "这次我也一定对" → 加仓 → 亏得更多。

### 解药

**唯一有效的办法：写交易日志，并在事前写。**

事后写的记录会被记忆污染。**只有事前写下的、带时间戳的判断，才是真实的判断。**

## 9.6 过度自信：90% 的司机认为自己高于平均水平

### 数据

心理学有个经典统计：**约 90% 的司机认为自己的驾驶水平高于平均。**

股市里同样：**绝大多数新手在开户时认为自己能赚钱。**

### 在股市里的表现

| 表现 | 后果 |
|---|---|
| 交易过于频繁 | 手续费吃掉收益（第 3 章） |
| 集中持仓 | 一次判断错误就重伤 |
| 不加止损 | "我看得准，不需要止损" |
| 加杠杆 | "这次很确定" |

### 一个校准方法

**记录你每一笔交易，三个月后统计胜率。**

如果你以为自己胜率 70%，实际统计是 47%，这个数字比任何说教都有用。

## 9.7 赌徒谬误：跌了这么久该涨了

### 定义

```
赌徒谬误 = 认为独立事件的概率会"自我平衡"
```

轮盘赌连开 10 次红，赌徒认为"下次该黑了"。**但轮盘没有记忆**，下一次仍然是 50%。

### 在股市里

```
"已经跌了 5 天了，明天该涨了"
"连续三个跌停，肯定要反弹"
```

**价格不会因为你亏了钱就对你补偿。** 短期的涨跌接近随机，没有"该涨了"这回事。

### 注意区分

这里要说清楚一件重要的事：**估值分位有均值回归的逻辑，但短期涨跌没有。**

- 长期（3–5 年）：估值低 → 未来收益大概率更高（有统计支持）
- 短期（1–5 天）：涨跌接近随机（无统计支持）

**"跌久了会涨"在长期有一定依据，在短期是纯粹的赌徒谬误。** 分清这两者，是成熟与否的分界线。

## 9.8 羊群效应与近因效应

### 羊群效应

```
看到别人买 → 我也想买
看到群里都在说某只票 → 感觉它是机会
```

**为什么危险**：你看到的信息，是别人**想让你看到**的。真正的机会不会在群里被大声宣布。

### 近因效应

```
最近的经历，会不成比例地影响你的判断
```

- 刚经历一轮牛市 → 认为"股市就是会涨"
- 刚经历一轮熊市 → 认为"股市就是骗局"

**A 股的周期通常是 3–7 年。** 你入市时看到的市场状态，只是周期的一个切片，不代表全部。

**这解释了一个现象**：2021 年入场的人觉得"股市一直在跌"，2019 年入场的人觉得"股市能赚钱"。**同样的市场，不同的切片。**

## 9.9 唯一有效的解药：交易日志

上面八个偏差，光靠"知道"是治不了的。知道处置效应的人，照样会卖盈持亏。

**唯一被验证有效的方法是：把决策过程外化、记录下来、事后复盘。**

### 为什么有效

因为它把"我感觉"变成了"我记录"。记忆会美化自己，文字不会。

### 日志模板（照着抄）

```markdown
## 交易 #001

### 事前（下单前必须填完）
- 日期时间：2026-11-10 09:42
- 标的：510300 沪深300ETF
- 方向：买入
- 价格：4.131
- 数量：100 份（1 手）
- 金额：413.10 元
- 占总资金比例：41%
- 止损价：3.51（-15%）
- 最大亏损：62.0 元（占本金 6.2%）

### 买入理由（三条，必须写完）
1. 估值分位 55%，中性区间，先建立仓位熟悉流程
2. 沪深300 覆盖 A 股核心资产，流动性最好（日成交额 44 亿）
3. 这是我第一次真实持仓，目的是学习而非盈利

### 反方论点（我可能错在哪）
1. 估值中性偏上，不是好买点
2. 如果经济数据继续走弱，指数可能还有 20% 下跌空间

### 卖出条件（提前定好）
- 价格跌到 3.51 → 无条件止损
- 持有满 6 个月且估值分位上到 80% → 考虑卖出
- 需要这笔钱 → 卖出

### 事后（卖出后填）
- 卖出日期：____
- 卖出价格：____
- 盈亏：____ 元（____%）
- 持股天数：____
- **我当时判断对了吗？** 对 / 错 / 部分对
- **如果重来一次，我会怎么做？** ____________
- **这笔交易暴露了我什么毛病？** ____________
```

### 用三个月，你会得到什么

**一份诚实的自我画像：**

```
我的真实胜率：___%（你以为是多少？）
我平均持有天数：___ 天
我因为"怕错过"买入的比例：___%
我止损执行率：___%（计划止损但没执行的有几次？）
我最大的单笔亏损：___ 元
```

**这张表比任何课程都有价值。** 因为它是关于你自己的数据。

## 9.10 一个思维工具：把决策和结果分开

这是本章最后一个、也是最重要的观念。

```
好的决策 ≠ 好的结果
坏的决策 ≠ 坏的结果
```

举例：

| 决策 | 结果 | 评价 |
|---|---|---|
| 满仓买入一只听说的股票，赚了 30% | 好结果 | **坏决策**（冒了不该冒的险） |
| 按纪律买入宽基，止损出场，亏 8% | 坏结果 | **好决策**（风险可控，纪律执行） |

**为什么这个区分重要**：如果你用结果评价决策，你会强化坏习惯。

赚了钱 → "我的方法有效" → 下次下更大注 → 迟早一次归零。

**这是散户最常见的死法：用一次幸运的结果，固化了一个必死的习惯。**

### 正确的自我评价标准

```
每次交易后不问"我赚了吗"，
而问"我按计划执行了吗"。
```

- 按计划执行，亏了 → **这是成功的交易**
- 没按计划执行，赚了 → **这是失败的交易**（你在训练自己破坏纪律）

---

## 本章要记住的 3 件事

1. **损失的痛苦是同等收益快乐的 2–2.5 倍。** 这是生理层面的，不是意志力问题，所以要靠规则而不是靠决心。
2. **处置效应是散户亏钱的头号原因。** "等回本我就卖"这句话里，藏着把成本价当决策基准的错误。
3. **好的决策和好的结果不是一回事。** 用结果评价决策，会让你把运气当成能力。

## 动手做

### 练习 9-1：建立你的交易日志（30 分钟，现在就做）

按 9.9 的模板，在你常用的笔记软件里建一个文件。

**不要等有交易了再建。** 现在就建好，把模板填进去，空着部分留白。等真下单时，你只需要填空。

### 练习 9-2：记录一次"未执行的判断"（一周）

这一周里，如果你产生过"我觉得某只票要涨"的念头，**写下来，但不要买**。

一周后回头看：它涨了还是跌了？

**重复四周。** 你会得到一个非常宝贵的数据：**你的直觉到底有多准。**

多数人的结果是——接近 50%。这个发现会省下你很多学费。

### 练习 9-3：做一次归因分析（30 分钟）

回忆你过去任何一次"觉得亏了/赚了但说不清为什么"的经历（买东西、工作决策都行），按这个格式写：

```
事情：___________
我当时认为的原因：___________
实际可能的原因：___________
我有没有只找支持自己的信息？___________
```

**目的**：在没花钱的情况下，先看见自己的偏差模式。
