# 对账数据导出：需求思路、不分页分账列表查询与 EasyExcel 导出实现及测试

合作商后台的点位分账查询是分页展示的，页面上看看没问题，但月底真要对账，合作商更希望拿到一个 Excel 文件。这一节就在分账查询的基础上补上数据导出：把符合条件的分账记录以 Excel 格式下载下来。功能做完，「合作商分账结算」这一章也就收尾了。

## 先给结论

- 需求：合作商按条件搜出分账列表后，可一键导出 Excel，表格就四列——分账日期、分账点位、订单数、分账金额。
- 实现三步走：查数据（不分页、查全部）→ EasyExcel 转成 Excel 文件流 → 通过 HTTP 把文件流响应给前端。
- 不用 POI 而用 EasyExcel：POI 内存消耗严重，EasyExcel 是阿里对 POI 重写后的产物，解决了内存问题，用起来也确实 easy。
- 查询侧新增 `ReportService.getList`，复用分页查询的 Wrapper 构建逻辑，去掉分页、返回 `List`。
- 导出侧新建 `BillExportDataVO`，用 `@ExcelProperty` 定义列名与列序号，`@DateTimeFormat` 格式化日期。
- Controller 里 `EasyExcel.write(response.getOutputStream(), ...).sheet("分账数据").doWrite(data)` 一条链完成写出，方法上抛 `IOException`。

## 需求与实现思路：三步走，为什么不用 POI

在合作商后台，当合作商根据点位搜索出分账列表之后，还可以把数据以 Excel 格式导出。导出后的表格包含四列：分账日期、分账点位、订单数、分账金额，对应一段时间段内每个点位的分账情况。

实现思路三步：

1. 根据合作商输入的条件从数据库中查询结果，注意是不分页的全部数据——导出场景下没有人只想要一页。
2. 运用 EasyExcel 把查询结果转换成可识别的结构化对象，调用它内部封装好的方法生成 Excel 文件流。
3. 通过 HTTP 的方式把文件流响应到前端，浏览器自动下载。

不少人第一时间会想到 POI——它确实也能操作 Excel，但内存消耗是个老大难问题，数据量一大很容易出问题。EasyExcel 正是阿里技术人员对 POI 重写之后的产物，核心目标就是解决内存消耗问题，同时 API 设计得很轻。立可得项目选它，就是这个原因。

## 第一步：不分页的合作商分账列表查询

导出的数据源来自一个新的 Service 方法。在 `ReportService` 中定义 `getList`：它不分页，返回值直接是 `List`，泛型还是 `OrderCollectEntity`。参数参照上面的分页查询，去掉页码和页大小，把剩下四个拿过来——合作商 ID、点位名称、起止日期。

```java
@Override
public List<OrderCollectEntity> getList(Integer partnerId, String nodeName, LocalDate start, LocalDate end) {
    var query = new LambdaQueryWrapper<OrderCollectEntity>();
    query.select(OrderCollectEntity::getDate, OrderCollectEntity::getNodeName,
                 OrderCollectEntity::getOrderCount, OrderCollectEntity::getTotalBill,
                 OrderCollectEntity::getOrdererId);
    if (Strings.isNotBlank(nodeName)) {
        query.like(OrderCollectEntity::getNodeName, nodeName);
    }
    if (start != null && end != null) {
        query.le(OrderCollectEntity::getDate, end);
        query.ge(OrderCollectEntity::getDate, start);
    }
    query.orderByDesc(OrderCollectEntity::getDate);
    return orderCollectService.list(query);
}
```

实现逻辑完全可以参照之前分页查询的写法：构建 Wrapper 的部分原样搬过来，点位名称模糊匹配、日期范围过滤、按日期降序都保持一致。唯一的区别在最后一行——不再走 `page`，而是调用 `orderCollectService` 的 `list` 方法，把 Wrapper 直接传给它，符合条件的记录一次性全部返回。

## 第二步：导出数据模型 BillExportDataVO

先加依赖。EasyExcel 的依赖加到 service-common 工程里，项目当前用的版本是 2.2.6，加完刷新一下 Maven。

然后在订单微服务里建数据对象：打开 http 包下的 viewModel 目录，新建 `BillExportDataVO`。这个类上的注解就是用来定义「怎么输出到 Excel」的：

- `@Data`：Lombok 的注解，生成 getter/setter，不用多说。
- `@ContentRowHeight(15)`：内容行高，从字面意思就能猜到作用。
- `@HeadRowHeight(20)`：表头行高，一般比内容行高一点更好看。
- `@ColumnWidth(25)`：列宽。这几个值可以先临时写上，导出后看格式不满意再调。

```java
@Data
@ContentRowHeight(15)
@HeadRowHeight(20)
@ColumnWidth(25)
public class BillExportDataVO {

    @ExcelProperty(value = "分账日期", index = 0)
    @DateTimeFormat("yyyy年MM月dd日")
    private Date date;

    @ExcelProperty(value = "分账点位", index = 1)
    private String nodeName;

    @ExcelProperty(value = "订单数", index = 2)
    private Integer orderCount;

    @ExcelProperty(value = "分账金额", index = 3)
    private Integer amount;
}
```

`@ExcelProperty` 是关键注解，用来标识属性和导出 Excel 列之间的对应关系：`value` 是列名，也就是表头第一行显示的内容；`index` 是列下标，0 就是第一列。四个字段依次对应分账日期、分账点位、订单数、分账金额。

日期字段还有个格式化问题：加 `@DateTimeFormat` 时注意选 `com.alibaba.excel` 包下 EasyExcel 自带的那个，格式指定为 `yyyy年MM月dd日`，导出时就按这个格式输出。写到这一步应该会有点眼熟——EasyExcel 的玩法和很多框架相似，注解标注映射关系，框架负责读写。

## 第三步：export 接口与文件流输出

参照合作商后台 API 文档里的「合作商分账信息导出」接口：地址是 report 下的 export，路径上有 `partnerId`（合作商 ID）、`start`/`end`（开始与截止日期）。所以导出方法写在 `ReportController` 下，方法名就叫 export：

```java
@GetMapping("/export/{partnerId}/{start}/{end}")
public void export(HttpServletResponse response,
                   @PathVariable Integer partnerId,
                   @PathVariable @DateTimeFormat(pattern = "yyyy-MM-dd") LocalDate start,
                   @PathVariable @DateTimeFormat(pattern = "yyyy-MM-dd") LocalDate end,
                   @RequestParam(value = "nodeName", required = false, defaultValue = "") String nodeName) throws IOException {

    var exportData = reportService.getList(partnerId, nodeName, start, end)
            .stream().map(item -> {
                var vo = new BillExportDataVO();
                vo.setAmount(item.getTotalBill());
                vo.setDate(Date.from(item.getDate().atTime(0, 0)
                        .atZone(ZoneId.systemDefault()).toInstant()));
                vo.setOrderCount(item.getOrderCount());
                vo.setNodeName(item.getNodeName());
                return vo;
            }).collect(Collectors.toList());

    response.setContentType("application/vnd.ms-excel");
    response.setCharacterEncoding("utf-8");
    response.setHeader("Content-disposition", "attachment;filename=bill.xlsx");
    EasyExcel.write(response.getOutputStream(), BillExportDataVO.class)
            .sheet("分账数据")
            .doWrite(exportData);
}
```

几个值得展开的细节：

- 三个路径参数都用 `@PathVariable` 接，两个日期还要加 `@DateTimeFormat(pattern = "yyyy-MM-dd")` 做格式化。点位名称可能有也可能没有，所以不从路径传，改用 `@RequestParam` 从问号后面传，`required = false`，默认空字符串。
- 因为要向浏览器输出文件，方法还得加一个 `HttpServletResponse` 参数。
- `getList` 返回的是 `OrderCollectEntity` 集合，而导出需要的是 VO 集合，中间用 stream 流转换：`map` 里 new 出 `BillExportDataVO`，逐字段赋值，最后 `collect(Collectors.toList())`。
- 类型转换是唯一的小坎：实体里的日期是 `LocalDate`，而 VO 里定义的是 `java.util.Date`，两者不是一个类型。转换链是 `atTime(0, 0)` 定位到当天零点 → `atZone(ZoneId.systemDefault())` 挂上系统默认时区 → `toInstant()` 拿到 Instant → `Date.from(instant)` 收工，转成 util 包下的 Date。
- 响应头三连：`Content-Type` 设为 `application/vnd.ms-excel`（xlsx 文件的类型），字符集 utf-8，`Content-disposition` 设为 `attachment;filename=bill.xlsx`——指定是附件下载，下载后的默认文件名就是 bill.xlsx。
- 最后 `EasyExcel.write`：传入 `response.getOutputStream()` 输出流和 VO 的 class 类型，`.sheet("分账数据")` 指定 sheet 名称，`.doWrite(exportData)` 把数据写出去。方法上抛一个 `IOException`，导出代码就完成了。

测试很简单：启动订单微服务，在浏览器里直接输入测试地址，带上合作商 ID 和时间段，回车。浏览器会多出一个下载的 Excel，点开就能看到导出的数据——目前库里只有一条测试数据，所以也只导出一条：北京西单广场，5 单，分账金额 167，日期按注解里定义的 `yyyy年MM月dd日` 格式输出。控制台里能看到实际执行的 SQL，条件是 owner_id 加日期范围，结果按 date 降序。

到这里，对账数据导出功能就完成了，「合作商分账结算」一章到此收束：分页查询、不分页列表、Excel 导出，一条完整的对账链路都齐了。

## 小结

- 对账导出 = 不分页查询 + EasyExcel 转换 + HTTP 文件流响应，三步走。
- POI 能干但吃内存，EasyExcel 是阿里重写 POI 的产物，大数据量导出更稳。
- `@ExcelProperty` 的 value 定列名、index 定列序；日期格式交给 `com.alibaba.excel` 包下的 `@DateTimeFormat`。
- `LocalDate` 转 `java.util.Date`：`atTime(0,0).atZone(ZoneId.systemDefault()).toInstant()`，再 `Date.from`。
- 响应头别忘了 `Content-disposition: attachment;filename=xxx.xlsx`，否则浏览器不会触发下载。
- `EasyExcel.write(out, VO.class).sheet("分账数据").doWrite(list)` 一条链写完收工。
