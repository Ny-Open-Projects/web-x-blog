这节课继续讲 Vue 3 的响应式 API，了解一下计算属性。计算属性是什么呢？在日常工作中，一种最常见的情况就是根据一些响应式对象的值来进行计算，并且显示其他的值。

## 从模板逻辑说起

举一个例子：页面中要显示一个 button，这个 button 会根据当前的年龄大小，决定是否可以点击以及显示什么文本。假如年龄大于等于十岁，可以点击，显示"可以参加"；小于十岁则不可点击，显示"未满十岁不可以参加"。

怎样完成这个任务？第一步当然想到直接在模板上做文章。加一个 button，type 等于 button。首先添加文本：user.age 大于等于十的时候显示"可以参加"，否则显示"未满十岁不可以参加"，用一个三元表达式。然后再添加 disabled 属性：user.age 小于十岁的时候 disabled 为 true，也就是不能点击。

把年龄改成八岁验证一下：八岁时按钮是灰色的，不能点击；点击 increase 到九再到十的时候，按钮不再是 disabled，文本也显示正确了。

这样做当然可以，但我们发现：如果在模板中写了太多这样的逻辑，比如很多其他地方也要写这些三元表达式和不同的逻辑，模板就会变得很臃肿、难以维护。同时可复用性也很差：假如年龄的显示要在不同地方使用相同的逻辑，就得拷贝粘贴再写一遍。

## 使用 computed

为了解决这个问题，可以使用计算属性。首先引入新的 API computed，创建一个变量叫 buttonStatus。computed 接受一个 function，function 的返回就是你想要的值。我们期望返回一个 object，里面有两个值：text（显示怎样的文本）和 disabled（button 是否被禁用）。里面的逻辑和三元表达式写的一样，直接复制过来：

```ts
import { computed } from 'vue'

const buttonStatus = computed(() => {
  return {
    text: user.age >= 10 ? '可以参加' : '未满十岁不可以参加',
    disabled: user.age < 10
  }
})
```

看一下它是什么类型：叫 ComputedRef，一个非常类似 ref 的类型。假如要访问其中的值，也需要使用 value 属性来访问，比如 buttonStatus.value.text 可以访问成功。假如是在模板中使用的话，它也会自动解包，因此在模板表达式中不需要使用 value。

给模板返回 buttonStatus，模板里显示文本就是 buttonStatus.text，disabled 就是 buttonStatus.disabled，这样就完成了任务。最终结果：一开始显示是正确的，年龄增加到十的时候这里发生了变化，说明我们使用 computed 完成了同样的任务。

## 为 computed 标注类型

把它和 TS 结合一下。和之前的 reactive、ref 一样，它也存在自动类型推论：这里 return 了 text 和 disabled，一个是 string 类型、一个是布尔类型，可以看到它推断成了正确的类型。

假如想一开始就特殊设定一个类型，和 ref 一样，可以设定一个泛型：比如想让它返回布尔，就在里面传入布尔。但我们这里明显是错误的，会报错；假如改成 return 布尔值，对应的错误就消失了。所以可以使用这种方式为 computed 标注类型，让你的返回和这个类型相同。

## computed 的两个特点

**第一，计算属性值会基于它的响应式依赖被缓存。** 也就是说，计算属性 buttonStatus 仅仅在它的响应式依赖更新时才会重新计算。在表达式中使用的 user，会被自动收集为依赖：它会分析里面所有使用的变量，发现有哪些响应式对象，把这些作为依赖分析并保存下来。当依赖发生变化时，buttonStatus 才会被重新计算。这就是说，假如 user.age 不改变，无论多少次访问 buttonStatus，都会立即返回先前已经计算过的结果，速度更快。

**第二，计算属性默认是只读的。** 因为计算属性返回的值我们称之为派生状态：它是根据一些响应式对象返回的一个和它共存的值，所以会被视为只读的，而且永远不应该被改变。假如你想改变它，就应该改变它所依赖的原始状态，触发新的计算，这时它就会被更新了。

## 小结

这节课讲了 computed 的三个内容：它怎样使用；怎样为它标注类型；它的两个特点（基于响应式依赖缓存、默认只读），这两个特点要记住。
