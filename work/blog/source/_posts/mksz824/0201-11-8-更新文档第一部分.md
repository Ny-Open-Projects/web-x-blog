上节课学了查找，这节课进入增删改查里的"改"。更新文档总体有两种形式：第一种叫 replace，完全替换，把整个文档都替换掉，有点像 HTTP method 里的 PUT；第二种叫 update，只更新某几个特定字段，对应 HTTP method 里的 PATCH。第二种显然更常见，因为我们很少会把整个文档全部更新掉。

先看 replace 完全替换，方法比较简单：await userCollection.replaceOne()，两个参数，第一个是查询条件（filter），第二个是替换成的新文档，写任何 object 都可以。我们想把 James 这条数据修改掉，filter 写 name 等于 James，替换值写 name 为 LBG、age 为 40。把返回值 replaceDocument 打印出来，输出 acknowledged: true 说明成功，modifiedCount: 1 说明修改了一条，matchedCount 也是一条。直接用数据库界面看，name 改成了 LBG、年龄改成了 40，符合预期。replace 就这么简单。

再来说 update，它针对某几个值修改，可以对每一项做更精细化的操作，这里又要用到操作符（operator），和上节课接触的非常类似。更新操作有一系列常用操作符：$set 是最基本的，更新某个 key 对应的值；$inc 是 increment/decrement，把数字类型自增或自减；$rename 重命名一个 key；$unset 直接移除这个 key；$mul 是 multiply，对 number 做乘法。还有更多，先介绍这几个。格式和查找操作符非常类似，也用对象表示，区别是前面写 update operator，后面是你想更新的值，同样放在一个 object 里以 key-value 形式写：前面是 field（想更新的 key），后面是要更新的数据。

正好用两个操作做实验：用 $set 修改球员名称，用 $inc 修改球员年龄。方法也和 replaceOne 相似，用 await userCollection.updateOne()。它的第一个参数同样是 filter，但我们不想再用 name 做查询条件了，因为它会经常变，希望用唯一的 ID 查询。注意这里不能直接用字符串构建查询条件，还记得吗，ID 是固定的类型 ObjectID，一个特殊对象，所以要从 mongodb 库里引入 ObjectId，用 new ObjectId() 构造函数把 ID 传进去（从数据库界面 View Document 里拷贝）。

第二个参数是更新条件，文档里它的类型叫 UpdateFilter。点进去看，能看到一系列操作符，我们说的 $set、$inc 都在其中。用 UpdateFilter 类型来构建条件可以获得自动补全。它需要一个泛型 TSchema，就是你要更新的文档的类型，简单写上 name 为 String、age 为 Number 即可。写 $set 时可以看到自动补全出现了，传入泛型后 name 和 age 都有了对应类型。$set 里写 name 更新为 LeBron，把 updateFilter 传给第二个参数，打印最终结果。输出同样有 modifiedCount、matchedCount 等，修改成功。刷新数据库看，LeBron 出现了，age 是 40，name 更新成功。

接下来测 $inc。把 $inc 放进去，修改 age，写对应的数字：想让它增加 1 就写 1，增加 2 写 2，也可以用 -1、-2 来减。我们增加 1，运行后查看数据，age 变成了 41，没问题。

这节课简单学了更新的两种方式：replace 完全更新，以及带一系列操作符的 update，用"操作符加对应值"构建 update filter 进行更新。
