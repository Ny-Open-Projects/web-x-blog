经过一周的学习，我们完成了两个任务：一是通过对前端工具链一系列工具的了解和使用，制定了我们的几大标准；二是完成了 B 端项目最初期框架的搭建。现在开始本周的总结。

先看学到了什么知识点。首先是脚手架：我们使用 OpsFlow CLI 创建了项目的基础结构，并且比较了 Vue CLI 和 Vite 之间的区别，了解了它们各自的优势和特点。

接下来是代码规范阶段。我们主要使用 ESLint 来规范代码，学习了它的基本使用和配置文件的配置方法。还有一个和 ESLint 走另一个风格的是 Prettier，我们学习了它和 ESLint 的区别、定位、作用以及使用。

最后要明确我们的产出，就是代码规范文档，地址我已经贴在这里了，大家可以看一下：B 端项目编码规范。点进去，里面有我们采用的 ESLint 规范合集、规则的详情，链接都贴在这里；还有开发时推荐的插件；其他规则虽然我没有采用，但可以按照个人或团队的意愿添加一些补充的 ESLint 规范。关于 Prettier 的使用，我还给大家创建了一个分支，想使用 Prettier 的话可以查看这个分支，它可以和 ESLint 良好地一起运作。

说完代码规范，是项目文件结构和命名规范，我们同时产出了另一个文档：项目文件结构规范。里面有参考链接、最后生成的文件规范和命名规范，还有得出的注意事项。

接下来是 Git Flow。我们讲了两种 Git Flow：一个是标准的、比较复杂的 Git Flow，另一个是我们采用的 GitHub Flow，并根据 GitHub Flow 得出了怎样使用 Git 进行开发的过程。同样有一个 Git Flow 的文档，里面有图片描述和文字描述。最后是两个规范：一是分支命名，feature 开头表示功能开发，hotfix 开头代表 bug 修复；二是 commit 信息，我觉得挺重要：必须杜绝 update、fix bug 这类废话，每次提交必须言之有物，言简意赅地把一次 commit 完成的任务说清楚。

接下来进入项目开发阶段。规则制定好以后就可以开发了。首先完成了 Ant Design Vue 的安装、全局导入和使用。要特别注意：这里组件很多，我不可能一个一个给大家讲，所以大家必须多看文档，尝试多用不同的组件进行开发。

然后是两大全家桶。一个是 Vue Router：从 SPA Router 的简单原理开始入门，完成了安装、全局引用、添加路由，可以使用内置的 RouterView 和 RouterLink 做跳转和容器相关的操作；还有在 Setup 中使用钩子函数，配合 Composition API 操作，useRoute 和 useRouter 分别用来获取路由信息和完成导航行为。

另一个是状态管理 Vuex。首先讲了为什么要使用全局状态工具，然后是安装和一些概念，比如 store、state、mutations，还可以使用 commit 方法提交 mutations；之后同样是配合组合式 API 的钩子函数 useStore，用它拿到全局的状态。最后因为项目比较庞大，需要把不同的状态分成好几块，所以使用了 module，把 store 拆分成多块。

知识点讲完了，我要提两个要点，这两个要点也是课中多次提过的，一定要强化这样的意识。一是将标准文档化，让标准有据可依，让团队中的成员有参考。二是 TypeScript：既然使用了 TypeScript，就必须以静态语言的特性进行思考，更深入地进入编码理念，这个理念很重要。

最后是本周作业。我觉得最重要的作业是写自己的技术标准文档，因为规范文档没有确定答案，我的文档里也写了很多备选项。大家可以根据我的简介和自己的偏好，或者自己去研究不同标准之间的区别，写出适合自己团队和项目的文档。还有一个隐形作业，就是多练：把框架搭建的代码最好都手写一遍，熟悉一遍 Vue、Vuex 和 Vue Router 的基本用法。

这周就学习到这里，下一周我们进入更深入的编码阶段。谢谢大家。
