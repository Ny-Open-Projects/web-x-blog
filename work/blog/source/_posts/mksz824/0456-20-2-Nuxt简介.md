上节课介绍了本次更新的课程提纲，整个项目主要使用 Nuxt 完成，所以这节课先对它做一个简介。Nuxt 是我最近非常喜欢的一个框架，做项目特别方便、速度很快，也希望借这个机会安利一下：未来如果你要做一个比较复杂的项目，可以考虑它。

先看什么是 Nuxt.js。官网地址是 nuxt.com，另外还有中文网站。我推荐大家使用英文官网：中文站是旧的文档，没有更新到最新版本。它目前最新的大版本是 3，后面我们学的都是 Nuxt 3 的知识，不会使用 Nuxt 2。如果你之前的项目用的是 Nuxt 2，这套内容不适用，最好学习最新版。

Nuxt 和 Vue.js 有千丝万缕的联系：它是基于 Vue.js 的应用框架，可以帮助我们快速构建强大、高度可维护的应用程序。它采用了一种非常特殊的形式：在服务器端和客户端渲染都能运行，这一点很重要，可以提供更好的性能和用户体验。React 生态里对应的大名鼎鼎的产品就是 Next.js，两者内在的思想完全一致。

Nuxt 有几个特点。第一是它提供了一种简单的工作流程，让我们更快地开发：它预设好了一系列规则和目录结构，帮助我们组织和管理代码，还内置了很多常用功能和插件。和用 Vite 或 Vue CLI 开发的应用不同，它不是从头开始，我们不需要自己选择工具和代码结构，也不用一个个安装：路由不需要手动装 Vue Router，状态管理不需要装 Vuex，代码分割等也都内置了。官网那句 "Compose with everything you need" 就说明了这一点：routing（路由）、data fetching（数据获取）、assets（静态资源）、SEO、error handling、state management（状态管理）、middleware 等等都已集成，甚至还有 server routes，也就是说它是前后端完全一体的，在同一个项目里就能写后端代码，不用分成两个项目。

第二是良好的可扩展性。它支持用模块的方式扩展功能，可以轻松引入和配置需要的模块。官网的 modules 页面里有非常多的现成模块，市面上流行的工具基本都能找到，快速安装即可使用。

第三是性能优化。两点：一是利用 Vue.js 异步组件的特性实现代码分割和按需加载，提高页面加载速度；二是支持服务端渲染，可以在服务端生成静态的 HTML 文件，加快页面首次渲染速度（这一点后面会重点介绍）。这种方式还能提高 SEO，让网站在搜索引擎中更容易被发现。

最后，Nuxt 提供了一些开发工具，帮助我们更方便地开发和调试。比如 Nuxt CLI 命令行工具，可以快速启动开发服务器、观察代码变化并自动刷新页面。还有集成的 DevTools，特别要说一下：它非常强大且不用另外安装，成功启动项目后它就嵌在页面中，帮助我们理解和调试代码，后面会演示，非常好用。

总的来说，Nuxt 是一个强大且灵活的应用框架：能快速构建优秀的 Vue.js 应用，提供简洁的工作流程，有良好的可扩展性、出色的性能和丰富的开发工具。学习和使用它可以在未来省下大量时间，是一个很好的可以快速上手的框架。
