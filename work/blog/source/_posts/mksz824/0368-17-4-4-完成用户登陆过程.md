上节完成了发送验证码，这节打通整个登录流程。登录一共分三步：

1. 调用登录接口 `loginByPhoneNumber`（参数为 phoneNumber 和 verifyCode），获取 token；
2. 设置 header，后续请求要带上特殊的 Authorization header，格式是 Bearer 加上 token；
3. 调用获取用户信息的接口，最终更新 store。

## 第一步：登录拿 token

token 之后可能还要用，所以希望存在 state 里，这就得和 store 打交道。打开 `user.ts`，所有与用户相关的 mutation 和 action 都集中在这里，创建一个新的 action，命名为 login，两个参数：从 context 中解构出 commit，以及 payload。

```ts
async login({ commit }, payload) {
  return axios.post('user/loginByPhoneNumber', payload).then((rawData) => {
    commit('login', rawData.data)
  })
}
```

接着修改 mutation。先给 state 补上默认值：新增 token 字段，`isLogin` 默认为 false。然后重写 login mutation：rawData 的类型直接复用 ResponseData，data 里就是 token 字段。把 token 从 rawData 中取出，赋给 `state.token`，原来遗留的旧逻辑删掉。

先感受一下第一步能否跑通。回到 `LoginView`，删掉之前的假数据，验证通过后构造 payload（phoneNumber 和 verifyCode），从 `useStore` 拿到 store，调用 `store.dispatch('login', payload)`。

测试：填入手机号，点击获取验证码，从响应里拿到验证码填入后点击登录。可以看到 loginByPhoneNumber 发送成功，data 里返回了一长串 token，第一步完成。

## 第二步：设置通用 header

token 拿到后要设置 header。axios 有没有一劳永逸设置（或删除）某个 header 的方法？有，静态属性。在 mutation 成功之后设置：

```ts
axios.defaults.headers.common.authorization = `Bearer ${token}`
```

这样就是一次通用的添加，之后每个请求都会带上这个 header。

## 第三步：获取用户信息

有了 header 就能发第二个请求。参考已有写法，再添加一个 action，叫 `fetchCurrentUser`，调用 `user/getUserInfo` 获取用户信息，成功后 commit `fetchCurrentUser`。

对应的 mutation 里，第二个参数同样是 rawData，但现有的类型不够用了，只有一个 userName 属性，而服务器实际返回一大堆 user 属性。于是新建一个 `UserDataProps` 接口描述真正返回的数据，把 ResponseData 里的 userName 去掉，换成 `data: UserDataProps`。

在 mutation 里，先把 `isLogin` 置为 true，登录到这一步才算真正完成；然后把 rawData 里的 data 展开赋给 state 的 data。

## 组合两个 action

最终需要一个操作触发两个 action：先 dispatch login，再 dispatch fetchCurrentUser。可以在组件里 dispatch 完一个后在 then 里触发第二个，但 Vuex 的 action 提供了更优雅的方式，新建一个 action 组合多个 action，让异步逻辑都留在 store 里，组件代码更清爽。

新建 action `loginAndFetch`，第一个参数是 context，里面可以拿到 dispatch。注意一定要 return，这样组件侧拿到的才是 Promise：

```ts
async loginAndFetch({ dispatch }, loginData) {
  return dispatch('login', loginData).then(() => {
    return dispatch('fetchCurrentUser')
  })
}
```

组件里把 dispatch 换成 loginAndFetch，then 里先 `message.success` 提示登录成功，两秒后通过 `router.push` 跳转到首页（router 从 useRouter 引入）。

## 修正 UserProfile

还有个小瑕疵：最早创建的 UserProfile 组件显示登录状态时会报错，因为 username 现在不在 user 的第一级，而在 data 里。修改为先判断 data 存在，再取 `user.data` 下的字段；顺便把展示改成 nickname。

完整跑一遍：获取验证码、填入、点击登录。请求依次发出，loginByPhoneNumber 返回 token；getUserInfo 的请求头里 Authorization 已经是 Bearer 加 token，成功返回用户信息；页面跳转后，UserProfile 显示出用户 nickname（Viking3），因为 store 更新后组件拿到的信息也更新了。

这节完成了登录和获取用户数据两个异步操作，同时学会了设置 axios 的常用 header 使其在每次请求中生效，以及用 Vuex action 做组合调用。
