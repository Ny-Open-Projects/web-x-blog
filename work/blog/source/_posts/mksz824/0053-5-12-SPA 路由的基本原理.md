上节课使用 Ant Design Vue 创建了页面的基本框架，发现应用有好几个页面，现在需要给整个项目添加基本路由，把这几个页面整合在一起。添加之前，先说说 SPA 项目和普通网站在路由跳转方面的区别。

## 传统网站 vs SPA

传统网站的基本工作方式是：针对不同的 URL 渲染不同的 HTML 静态页面。以豆瓣电影为例，点击《疯狂原始人》的链接，会跳转到一个新的 URL；页面跳转时，会重新加载所有静态资源，比如 js 和 css，所以能观察到从空白到展示的过程。查看它的源代码，HTML 内容都是后端直接渲染生成的。

SPA 中文是单页面应用（Single Page Application），它没什么神奇的，也是一个 Web 应用。以掘金为例：点击某个链接，它没有跳转到其他页面，而是出现 loading 效果，然后把内容渲染进来。这是由 JS 实现的动态渲染 DOM 内容，并且 JS 可以更改链接的默认行为，点击每个链接时地址栏同样会发生变化。

对比两者，SPA 的优点很明显：第一，速度快，第一次下载完所有静态文件，跳转时不需要再次下载；第二，交互趋于无缝，更接近原生应用的体验；第三，为前后端分离提供了实践场所，前端负责所有逻辑，后端只要提供接口就可以。

## 工作原理

工作原理其实就是研究它怎样实现路由转换。详细的原理可以了解 HTML5 提出的 History API，这里举一个浅显易懂的例子。

首先要获得不刷新页面的前提下，动态改变浏览器地址栏 URL 的能力。这个 API 来自 HTML5 的 History 对象，叫 pushState。它有三个参数：state 是与网址相关的状态对象；title 是新页面的标题，但现在所有浏览器都会忽略这个值；url 是新的网址，必须与当前页面处于同一个域，浏览器的地址栏将显示这个网址。最后一个参数最重要，就是我们要修改的 URL。

## 手写一个简陋的 router

我实现了一个简陋版：页面有三个链接 home、resume、contact，点击任意一项要完成两件事：修改地址栏的 URL，并且更新页面内容。

思路用图描述：页面里创建一个空的 div，上面有三个链接。点击每个链接时，第一步跳转到对应的 URL，想到可以用 pushState；第二步获取链接上的属性，根据属性获取对应的模板。给链接添加不同的自定义属性，把模板以 key-value 的 object 存在本地，根据 key 拿到 value 就能获得不同的模板，再用 DOM 方法替换内容，比如 getElementById 拿到 app 后修改 innerHTML。

看代码。一开始存了一个 key-value 的 object，key 对应跳转的 URL，value 是要显示的 HTML。给 document 绑定 click 事件，三个 a 链接上有一个 data-route 的自定义数据，存的就是这三个 key。点击时判断目标元素的 class 是否包含 nav，包含就触发 handleChange：

```javascript
const handleChange = (key) => {
  history.pushState(null, '', key);
  document.getElementById('app').innerHTML = data[key];
};

document.addEventListener('click', (e) => {
  if (e.target.classList.contains('nav')) {
    handleChange(e.target.dataset.route);
  }
});
```

handleChange 里先 pushState，三个参数：第一个传 null，第二个是 title，第三个是真正要跳转的 URL；跳转完毕后用 innerHTML 替换内容。点击 resume、contact、home 都会正常切换。

## 后退与前进

还要注意后退和前进的行为。每次 pushState 都会往 window.history 对象中添加一个值，可以把它想象成类似数组的结构，alert(window.history.length) 后每次点击都能看到 length 在增加。后退等于在这个数据结构中往前挪一步，前进是往后挪一步。可以用 onpopstate 监控这个状态，用 window.location.pathname 拿到当前跳转的值（是跳转以后的值），再调用 handleChange 重新渲染即可。演示：跳转几个页面后点击后退，都能成功回到对应地址。

这就是路由系统实现的最简原理。真实的路由实现比这个例子复杂得多，这套 SPA 的路由系统一般被称为 Router。Vue 是渐进式框架，本身没有路由系统，要实现 SPA 功能需要另外的方案，就是 Vue Router：Vue.js 的官方路由管理器，可以和 Vue 深度衔接，并且为 Vue3 推出了全新的 Vue Router 4 版本。
