上节课完成了右键菜单的基本雏形，但遗留了一个问题：我们希望右键菜单像之前的快捷键（hotkeys）一样支持程序化调用，而不是引入一个组件放到 editor 界面中。那么怎样用函数调用的方式创建一个组件，并添加到特定节点中？

我们很熟悉 Ant Design Vue 的 `message` 方法，它就是用函数调用方式完成组件展示的。为了完成这个任务，先到入口文件 main.ts 里考察。第一种方式大家都知道：`createApp` 创建一个应用实例，再 mount 到特定节点。但我认为应用实例太重了，这里只是一个简单的组件，有没有简单一点的方法？

通过看 Element Plus 的源代码，我找到了方法。官方文档没有介绍它，这里演示一下。

## createContextMenu

新建文件 `createContextMenu.ts`，从文件名可以看出要用函数方式创建菜单。需要先有一个 VNode 实例，可以用之前学过的 `createVNode`（即 h 函数）：

```ts
import { createVNode, render } from 'vue'
import ContextMenu from './ContextMenu.vue'

export function createContextMenu(options: { actions: ActionItem[] }) {
  const vnode = createVNode(ContextMenu, options)
  const container = document.createElement('div')
  render(vnode, container)
  document.body.appendChild(container)
}
```

`createVNode` 的第一个参数是组件本身，第二个参数是它的 props，这里就是 actions。

## 一个类型报错及其解决

把 `ContextMenu.vue` 里定义的 `ActionItem` 类型拿过来时会出现错误：`Vue has no exported member 'ActionItem'`。原因是 .vue 文件要被 TS 认识，需要添加特殊的类型声明，它只是一个 `DefineComponent` 的实例。当 TS 要从这个声明里拿一个特定的导出时，自然就找不到。

解决方案是把 interface 放到单独的 ts 文件中，供 TS 或 vue 共同导入。我把 `ActionItem` 挪到了 `createContextMenu.ts` 里，ContextMenu.vue 中删掉定义改为导入，问题就解决了。

## render 函数

重点来了：一个官方文档都没有披露的神秘函数 `render`，它可以把一个 VNode 渲染到特定节点上。它需要两个参数：VNode 和对应的 DOM 节点。所以先创建一个容器节点，`document.createElement('div')`，然后：

```ts
render(vnode, container)
document.body.appendChild(container)
```

把渲染好的 container 直接添加到 body 上，函数就完成了。默认导出 `createContextMenu`。

## 在 editor 中调用

回到 editor.vue，原来的 `<ContextMenu>` 组件和它的引入都删掉，改用函数调用：

```ts
import createContextMenu from '@/components/createContextMenu'

onMounted(() => {
  createContextMenu({ actions: testActions })
})
```

保存后在页面上验证：右键点击，菜单正常出现。打开 Elements 面板可以看到 body 下面多了一个 div，就是我们添加的 ContextMenu，因为用的是 `document.body.appendChild`，所以它被挂到了这里。

这节课完成了用函数调用方式渲染组件。特别注意 `render` 这个函数，它是从 Vue 的 global API 里引过来的，是一个隐藏的大宝藏。下节课做收尾工作：把这个方法插件化（放到 plugins 文件中）、在特定时机删除实例（现在只 render 了没有删除），以及传递参数正确地调用 mutation。
