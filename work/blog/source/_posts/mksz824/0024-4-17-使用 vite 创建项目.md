这节课使用 Vue 3 官方的脚手架工具来创建项目。2021 年之前我们经常使用的脚手架叫 Vue CLI。进入 2021 年以后，随着新的脚手架工具 Vite 的出现，前端脚手架的世界发生了翻天覆地的变化。随着流行度越来越高，它现在已经是 Vue 3 默认的脚手架工具了。Vite 也是 Vue 的作者尤雨溪推出的。

## Vite 的特点

参考最好都找官网地址，不要找第三方地址。文档地址是 cn.vitejs.dev，也就是中文文档。

官网首页写的最大特点是"下一代前端工具链，为开发提供极速响应"。所以它最大的特点就是快，其他特点都围绕这个字展开：

- **极速的服务启动**：本地服务器可以非常快地启动，使用原生 ESM 文件，无需打包。用过 Vue CLI 的同学知道，它的底层使用 Webpack 构建，每次都要进行打包，所以 Vite 比 Webpack 快很多。
- **轻量快速的热重载**。
- **丰富的功能**：对 TS、JSX 和 CSS 等支持开箱即用。
- **优化的构建**：预配置 Rollup 进行构建，还有通用的插件。
- **完全类型化的 API**：灵活的 API 和完整的 TypeScript 类型。如果去开发它的插件等，会方便很多。

另外一条特点：它是一个通用的脚手架工具，不仅仅限于 Vue 3。假如是 React 或其他框架，都可以使用 Vite 创建项目。

想了解更多的话，可以看"为什么选 Vite"章节，那里讲了前因后果，文章比较长，感兴趣的可以课下参考。

## 为什么选 Vite 而不是 Vue CLI

工具链章节已经说得很清楚了。项目脚手架第一个推荐的就是 Vite：轻量级、快速、速度极快的构建工具，是 Vue 3 官方推荐的脚手架。Vue CLI 是官方提供的基于 Webpack 的 Vue 工具链，但它现在处于维护模式。文档写得很清楚：建议使用 Vite 开始新的项目，除非你依赖特定的 Webpack 特性。最后还是那个字，快，Vite 比 Vue CLI 快很多。基于这三点，我们最终选择 Vite。

## 创建项目

了解完特点，正式使用它。进入"开始"章节。首先有个总览，讲了一个读音趣闻：它的发音是 /vit/（类似"维特"），不是 white，这是个法语词，意思是"快速的"。

来到"搭建第一个 Vite 项目"章节。第一点要注意兼容性：Node.js 版本要达到 14.18 以上或 16 以上。我推荐直接把版本升到 16 以上。检查本地 node 版本，我们是 16.13.0，满足条件。

满足后用一行命令创建：

```bash
npm create vite@latest
```

稍等片刻会弹出一系列输入框：第一个是项目名称，我们取 vue3-basic；然后选择 framework，有很多选项，这里选 Vue；接着问使用 JavaScript 还是 TypeScript，我们选 TypeScript。通过这三个问题就创建好了项目文件夹，进入后 npm install，然后 npm run dev，整个项目就可以运行了。

如果想更简便，用一行命令直接搞定，不输入这些内容。文档里写了"附加的命令行选项直接指定项目名称和你想要的模板"。特别注意，根据 npm 版本有两种写法：

npm 6 的写法：

```bash
npm create vite@latest vue3-basic --template vue-ts
```

后面加上文件夹名称（任意项目名称都可以）和想要的模板，传参用 --template 加模板名称。模板名称可以查阅文档：一种 framework 对应两种模板，比如 vue 就有 vue 和 vue-ts，react 就有 react 和 react-ts。

npm 7 及以上的写法不同：传参不一样，需要在 --template 之前多加两个横杠：

```bash
npm create vite@latest vue3-basic -- --template vue-ts
```

这里要特别注意。查看我们的 npm 版本：npm -v 是 8.1.0，在 7 之上，所以要使用后一种命令。复制过来回车，一次性就把项目创建完毕了，不会再有那些交互问题。
