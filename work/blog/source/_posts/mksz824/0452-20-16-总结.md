这节课总结本章学到的知识。

一开始介绍了 Nuxt 的特点和优势，然后讲了一个重要概念：Nuxt 的渲染模式。这是 Nuxt 这类框架和 SPA 最重要的区别，值得了解并记忆。

第一种是传统的 render 模式，即客户端渲染：浏览器端完成页面渲染。官网的图写得很清楚，首先下载一个空的 HTML 文档，再下载对应的 JS 文件，运行 JS，最后由 JS 生成整个站点的结构并支持交互。

第二种是同构渲染，也就是 Nuxt 3 使用的渲染模式，同时在服务器端和客户端进行。第一步是 SSR（Server Side Rendering），Full HTML 直接渲染回来，浏览器直接生成了页面结构，但还不能交互；接着下载并运行 JS，这一步完成后注水（hydration）过程结束，整个应用就可以交互了。要特别注意两种模式的区别和同构渲染的优势：首屏渲染速度快、SEO 非常友好（一开始就返回完整页面）、可以减轻客户端压力，同时要理解 hydration 这个注水过程。

接下来是 Nuxt 3 的特性。第一个是 auto-imports（自动导入），一开始可能有些生涩，用久了会越来越体会到便利性。它可以自动导入特殊文件夹中的内容，比如 components、composables 和 utils 这几个文件夹的内容不需要手动导入；Vue 的 API 也可以自动导入；Nuxt 3 内置的全局函数（比如 useFetch）同样可以自动导入。

然后介绍了 Pages 和 Routing。这部分很简单，是直观的文件系统路由，页面放在 Pages 文件夹中，用中括号加参数名创建动态路由；NuxtPage 是提供的全局组件，用于占位；NuxtLink 完成不同页面间的导航。

之后是 Middleware，一个全新的概念。可以在 middleware 文件夹中创建单独的文件，然后在页面中用 definePageMeta 定义，注意要和文件名保持一致，这是第一种方式；第二种是直接使用 inline function 定义；第三种是全局中间件，文件带 `.global` 后缀，在每个路由上都会运行。

再是状态管理，我们也挺熟悉了。Nuxt 3 提供了现成的全局组合式函数 useState 来完成状态管理，我们还用 useCurrentUser 对它做了一个小优化来完成类型推论，大家可以回顾一下源码的写法。

接下来是很重要的 data fetching，有三种方式。第一是 useFetch，组合式函数，在组件 setup 中获取数据最直接的方式。第二个是稍底层的 `$fetch`，发送网络请求的通用函数，基于 ofetch 库，可以把它想象成类似 axios 的库。第三种是 useAsyncData，和 useFetch 相似的另一种在组件中发异步请求的组合式函数，通常和 `$fetch` 一起使用，更精确地控制请求发送；它比 useFetch 用途更广泛，第二个参数的回调只要返回标准 Promise 就可以胜任。useFetch 其实就是 `$fetch` 和 useAsyncData 一起使用的语法糖。最后还讲了用 useNuxtData 获取缓存的数据：useFetch 和 useAsyncData 的结果都会缓存进来，可以从中取值。

简单回顾三种方式的用法。useFetch 返回一系列响应式对象，可以传第二个参数，比如用 pick 筛选返回的字段（比如只要 name 和 username），还能拿到 data、pending、status、refresh 等响应式变量。`$fetch` 非常直观，返回的不是响应式对象，直接返回数据，是更底层的通用函数。useAsyncData 第一个参数是 key，即这次请求独一无二的标识符，第二个参数是返回数据的回调，返回的响应式对象和 useFetch 完全一致，它是比 useFetch 更通用的概念。

之后讲了发送请求的时机。默认是页面等到数据获取完毕后再渲染，用的是 Vue Suspense 特性；可以改为路由跳转结束后再发请求，加参数 `lazy: true` 即可；还可以做 client-only fetching，和普通 SPA 一样在页面渲染完毕、hydration 结束后再发请求，需要加参数 `server: false`。但我不推荐后者，同构是很好的特性，这样做会破坏它。

然后是静态文件，这部分很简单。Nuxt 3 用两个文件夹存放静态文件，有区别：assets 用于组织未编译的静态资源，一般会被编译处理，比如 CSS、LESS 文件；public 可以看作静态服务器的根路径，里面的文件都可以直接通过 URL 访问。

最后是 SEO and meta，这是 Nuxt 3 的重要特性之一，也是同构框架比 SPA 强的关键点。实现方式有三种：useHead、useSeoMeta，以及全局组件（Title、Meta、Style 等）。

以上就是本章的全部知识，大家可以通过这节小结唤醒记忆、做一次回顾。
