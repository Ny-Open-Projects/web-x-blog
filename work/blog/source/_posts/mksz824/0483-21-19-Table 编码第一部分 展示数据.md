上两节课完成了 default 布局，现在进入 users 用户管理表格的一系列开发。一个典型的表格我认为应该有这些功能，它们是循序渐进的：

1. **展示数据**：把所有数据展示到表格中，还可能转换某些特定字段成我们想要的格式，等会儿就会遇到这样的例子。
2. **分页**：数据获取后的典型场景。要知道总共有多少条，计算出多少页，点击对应页时数据刷新。
3. **排序**：通过自定义手段完成数据排序。我想到的是用创建时间或更新时间排序，显示最新或最老的数据。学完后同学们可以自行发挥用更多字段排序，这里只是抛砖引玉。
4. **搜索**：通过特殊字段完成搜索，比如按 username 键入名称，点击查询后数据刷新，非常经典的功能。
5. **自定义操作**：表格中除了数据展示，还有一些额外操作。比如一键封禁用户（点击后把用户 disable，无法登录），或一键删除用户等等。

这节课完成最简单的：数据获取并展示到表格上。第一步先把数据格式修改一下，现在拿到的字段太少，只有 username 和 nickname，我们希望拿到大多数字段并返回。把查询语句分行写会更清楚，因为后面还要添加各种条件。更新字段为：username、nickname、type、role、createdAt、updatedAt，都是之前确定好的。如果数据库里没有这么多数据，可以用之前的后端系统创建更多数据。

另外没必要返回 object，直接返回 users 数组即可。

## 获取数据与 Table 组件

来到 `users/index.vue`，添加 script 标签写逻辑。数据获取大家已经非常熟悉，用 Nuxt 3 提供的 `useFetch`，API 传 `/api/users`，返回 data，再拿一个 pending 状态：

```ts
const { data, pending } = await useFetch('/api/users')
```

数据有了，看表格怎样展示。使用 Nuxt UI 的 Table 组件，它其实能胜任上面提出的大多数任务。第一步是展示，看它的例子：有一系列 people 的数组，通过 `rows` 属性传进去即可展示；此外还有 `columns`，用来确定每一列对应的属性。

columns 上有一系列属性，我们暂时需要 key 和 label：key 指从数据里选哪个值（比如 key 是 id，数据里的字段也是 id）；label 是列头展示的字符，比如 id 显示为大写的 ID。我们的 data 已经有了，来创建 columns，就是一堆 `{ key, label }` 的 object，和返回数据一一对应，大家可以自行写一下。

保存后把 UTable 拿过去，去掉原来的 h1，传递关键信息：

```vue
<UTable :rows="data" :columns="columns" :loading="pending" />
```

rows 传 data，columns 传写好的 columns，最后是读取状态：发送新异步请求时有个 loading 状态，把 pending 传进去即可。

看最终结果：数据展示到表格里了，data 来自后端返回，columns 是我们自定义的，把汉字和属性一一对应起来。

## 用 Day.js 格式化时间

还有个问题：时间格式看起来不友好，现在是 ISO 8601 标准格式，也就是 MongoDB 存的格式，并不好读，希望转换成更好读的方式。这里需要一个新工具：Day.js，现在时间处理最火的轻量级库，只有 2KB，可以非常方便地完成时间解析。

安装很简单：`npm install dayjs`，不需要额外的类型文件，一次性装完（我已装好，大家自行安装）。

它的使用直接在代码里解释。import 进来后创建一个 computed value，在 data 上做变换：返回 `data.value.map()`，把每个 user 的 createdAt 覆盖掉。Day.js 的用法很简单：把标准 ISO 时间格式传进去，再调用 `format` 方法格式化。它有一系列格式化占位符：yyyy 代表年，MM 代表月，dd 是日，然后是小时和分钟。我们选年月日加时分的格式，搞不清楚可以看文档。updatedAt 做相同操作，最后别忘了返回 user。最终用 `userData` 替换 data 传给表格：

```ts
const userData = computed(() =>
  data.value?.map((user) => {
    user.createdAt = dayjs(user.createdAt).format('YYYY-MM-DD HH:mm')
    user.updatedAt = dayjs(user.updatedAt).format('YYYY-MM-DD HH:mm')
    return user
  })
)
```

刷新后时间格式完成了修改，最基础的功能实现，这节课任务完成。除了 Table 的基本使用，还希望大家学会 Day.js：它有四万多 star，非常火的时间解决方案。以后遇到任何和时间相关的问题，第一个就想到 Day.js。
