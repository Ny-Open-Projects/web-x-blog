上节课完成了下载文件的第一部分，但它有一个重要局限：只能下载同源文件。遇到跨域文件时下载就会失效，a 链接退回默认行为，直接在浏览器里打开对应 URL。想下载跨域文件，自然的思路是借助异步请求。

先把上节课的逻辑抽成 `downloadFile` 方法，移到这个方法里，并在 TemplateDetail 中使用。接下来解决跨域问题。判断跨域很简单：a 链接有一个特殊属性 origin，只要它不等于本地 `location.origin`，就说明是跨域。所以加一个 if else，跨域逻辑写在 if 里，同源的直接走原来的逻辑。

跨域场景用 axios 发请求，因为是文件，用 get 请求即可。关键是设置一个特殊的 responseType：我们要拿的是二进制文件而不是普通文本。XHR 的 responseType 是一个枚举属性，返回响应数据的类型，默认是 text，可选值里有 arraybuffer，也有我们想要的 blob，即包含二进制数据的 Blob 对象。文档我贴在注释里，大家可自行查阅。设置方式是在 axios 的配置参数里加 `responseType: 'blob'`。

拿到 data 之后，data 里的 `data.data` 就是最终的二进制数据，可以创建下载链接了。还记得预览时学过两种图片地址方案：第一种是静态方法 `URL.createObjectURL`，创建一个 DOMString，返回一个与 document 绑定的 URL，表示指定的 File 对象；这里传 Blob 是同样的效果。第二种是 FileReader 的 `readAsDataURL`，返回 base64 格式的字符串。相比之下第一种更简单，我们采用它：把 `link.href` 设为 `URL.createObjectURL(data.data)`，然后照旧触发 click 事件触发下载。

这里要加一个小的 setTimeout，因为文件比较大时，创建过程是一个简单的异步过程。做完之后还有一件重要的事：清理。我们创建的 URL 对象存在于内存中，文件比较大时会持续占用内存、得不到回收，所以必须释放。对应的静态方法是 `URL.revokeObjectURL`，用来释放之前通过 `createObjectURL` 创建的 URL 对象。释放同样采取异步方式，重新写一个与下载并列的 setTimeout，把 `link.href` 传进去。时间上我设的是十秒，这不是特定值，参考的一段下载代码里设的是四十秒，大家按自己的需求确定即可。

整个过程完成后，在 TemplateDetail 里直接下载封面图 coverImage，它是跨域文件，验证一下。清空控制台，点击下载图片海报，可以看到请求成功返回，test.png 也完成了下载。

最后还有一种情况要处理：并非所有跨域文件都支持跨域访问，对这种文件我们无能为力，但程序至少不能没反应，应该提供一个兜底方式，把图片在新窗口打开显示。我在项目里放了一张不支持跨域访问的图片，点击下载图片海报，可以看到浏览器报出跨域禁止的错误。处理方式是在 axios 的 Promise 里加 catch：拿到错误 e 后，把 `link.target` 设为 `_blank`，在新窗口打开，`href` 设为图片地址，最后照常 dispatch。

异常处理完成后再次点击，图片会在新窗口弹出，至少不会像之前那样毫无反应，用户可以在新窗口里自行下载。至此整个流程完成：从最简单的本地文件，到跨域文件的两种处理方式，前端下载文件的方法就介绍完了。
