上节课讲解了组件的属性，它是从上至下、从父组件传到子组件的过程。但某些情况下，子组件要反向和父组件交互，在操作发生时通知父组件。这和 DOM 原生事件很类似：绑定了 click 事件后，按钮被点击时我们能捕获整个过程并做处理。

## 需求

在 MyProfile 组件中添加一个按钮，点击后隐藏年龄信息，毕竟年龄是敏感信息；同时通知父组件 App.vue 当前年龄是否被隐藏，父组件据此更新 document.title。

## 定义和发射事件

既然是 MyProfile 发射出去的事件，就必须先定义。在 defineComponent 的 object 上添加一个和 props 平级的属性 emits，它接受一个数组，因为组件可以发送多个事件。事件名叫 change，表示隐藏状态发生了变化：

```typescript
import { defineComponent, ref } from 'vue';

export default defineComponent({
  name: 'MyProfile',
  props: { /* ... */ },
  emits: ['change'],
  setup(props, ctx) {
    const isHidden = ref(false);
    const toggleHide = () => {
      isHidden.value = !isHidden.value;
      ctx.emit('change', isHidden.value);
    };
    return { isHidden, toggleHide };
  },
});
```

实现思路是：用一个 ref（isHidden）表达年龄是否隐藏；点击按钮时取反它的值。特别注意，除了修改值还有第二个重要任务：发射事件。发射需要用到 setup 的第二个参数 ctx（context），它上面有一系列属性：attrs、slots、emit、expose，这里先用 emit，其余以后再讲。`ctx.emit('change', isHidden.value)` 的第一个参数是事件名，第二个是要发射出去的值。

TypeScript 在这里能帮上忙：因为 emits 里定义过 change，调用 emit 时会自动联想出这个事件名。

模板里按钮的文本用三元表达式切换，年龄信息用 v-if 在 isHidden 为 false 时显示。点击按钮验证：内容可以正常切换，按钮文本也随之变化。

## 父组件监听

接下来在父组件上监听这个自定义事件，写法和原生事件一样，使用 @ 符号，而且会自动提示已定义的事件名 change：

```html
<MyProfile :user="user" @change="onChange" />
```

回调的参数就是子组件发射出来的那个布尔值，据此更新标题：

```typescript
const onChange = (isHidden: boolean) => {
  document.title = isHidden ? '年龄被隐藏' : '年龄显示出来了';
};
```

特别注意：要在 setup 中返回 onChange，用到什么就返回什么。点击隐藏时标题变成"年龄被隐藏"，点击显示时变成"年龄显示出来了"，App.vue 成功获取到了子组件的状态。

## 遗留问题

我们一直在追求类型的完美，但事件这里只能描述名称，没办法详细描述事件参数和返回的类型。之后会另辟蹊径解决这个问题，请持续关注。

## 小结

现在我们掌握了组件最重要的两块内容：属性和事件。它们看起来不难，但构成了组件的核心。请重点理解 setup 的两个参数：props 用来获取属性，context 上面能拿到一系列工具，其中一个就是发射事件的 emit。
