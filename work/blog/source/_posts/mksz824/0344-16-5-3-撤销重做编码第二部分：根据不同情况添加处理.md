上节课完成了第一步：建好数据结构，并在各操作时刻把历史记录写进数组。这节课完成第二步，创建 `undo` 和 `redo` 两个 mutation，并根据不同类型的历史记录做对应处理。

先解释两个词：undo 就是常见的 Ctrl+Z，向前回退；redo 是重做，向后推进。这节课逻辑稍复杂，我会写更多注释，帮助未来我们自己或其他工程师理解这段代码。

来到 editor.ts 新建 `undo` mutation，第一个参数是 state。

## 先拿到正确的 index

第一步拿到当前要操作的历史条目。这里有两种情况：

- 从来没有 undo 过（`historyIndex === -1`，初始值）：取数组最后一项，`state.historyIndex = state.histories.length - 1`；
- 已经 undo 过：继续往前走一格，`state.historyIndex--`，回退到上一步。

index 处理完之后，取出对应的记录：

```ts
const history = state.histories[state.historyIndex]
```

## 按 type 分三种情况处理

三种类型的情况又可以用 `switch` 了。我的建议是：遇到三种以上的分支情形就用 switch。switch 的对象是 `history.type`。

**case 'add'**：undo 是取反操作，当初是添加元素，现在就要删掉它。用之前删除时同样的 `filter`：

```ts
state.components = state.components.filter(
  component => component.id !== history.componentId
)
break
```

**case 'delete'**：当初删除了组件，undo 就要把它放回原始位置。这里有个特殊需求：把一项插入到数组的指定位置。lodash 没有现成方法，自己写。

数组的插入有两种方式：`splice` 和 `slice`。区别是面试常问的点，`splice` 会 mutate 原数据，调用后 `state.components` 直接变化；`slice` 是 immutable 的，调用后原数组不变。两种都能完成任务，这里抱着学习态度选稍微复杂点的 immutable 方式，顺便多了解一下数组操作。

在 helper 里创建 `insertAt` 函数，插入到某一项：

```ts
function insertAt(array: any[], index: number, newItem: any) {
  return [
    ...array.slice(0, index),
    newItem,
    ...array.slice(index),
  ]
}
```

用 slice 把数组在 index 处分成前后两段并展开，中间放入新元素，返回一个新数组。`slice(index)` 只传第一个参数时会自动截到最后。

调用时注意它是 immutable 操作，要接收返回值：

```ts
state.components = insertAt(
  state.components,
  history.index as number,
  history.data,
)
```

第二个参数传入历史记录里保存的 `index`；第三个是要恢复的数据 `history.data`。由于 `index` 是可选字段，这里可能是 undefined，但我们知道这种情况下它一定存在，直接类型断言 `as number`。最后别忘 `break`。

**case 'modify'**：按图上的分析，找到被修改的元素，把它恢复到旧值。注释写出来就是：先按 id 拿到被 modify 的 component，再 restore to the old value。先从 `history` 里解构出 `componentId` 和 `data`，再从 data 里取 `key` 和 `oldValue`。然后用写过多遍的 `find` 找到要更新的组件：

```ts
const updatedComponent = state.components.find(
  component => component.id === componentId
)
if (updatedComponent) {
  updatedComponent.props[key as keyof AllComponentProps] = oldValue
}
```

找到了就恢复旧值：`props[key] = oldValue`。这里会报一个和之前一样的类型错误，做一次类型断言 `as keyof AllComponentProps` 即可。最后 `break`，再补一个 `default: break`。
