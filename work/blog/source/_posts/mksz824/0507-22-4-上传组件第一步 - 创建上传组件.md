上节课完成了表单的联动和验证，表单看起来已经比较完美，但有一个属性没添加：picture，也就是用户头像。说到头像就是图片地址，有图片自然涉及文件上传和处理。

Nuxt 3 的内容里我们还没涉猎文件上传，正好借这个时机完成这个功能，看看在 Nuxt 3 中文件上传和处理是怎样完成的。首先想到需要一个组件来完成上传，就像 UInput、USelect 一样，那么有没有 UUpload 呢？Nuxt UI 目前还没有上传组件，需要自己完成。相信这难不倒大家：之前前端内容里有一章正好讲通用上传组件的开发和使用，原理和实现讲得非常透彻，这里温故而知新，做一个简化版的实践。

同时会发现一个适应复杂表单组件的标准做法：自定义组件只要支持 v-model 就可以了。在想要的时间节点更新 v-model，值就可以更新到 userData 上，进而完成一系列功能和验证，很容易和整个表单系统联动。

## 组件骨架

来看 `FileUploader` 组件的开发，我把它放到了 components 文件夹。要实现的就是在特定时间点完成上传以及 v-model 的更新。这节课先不完成上传，先实现和整个表单系统的接入。

创建组件：外层一个 div，应该是左右结构，左侧显示头像，右侧一个 button 点击选择文件。头像用之前用过的 UAvatar，button 用 UButton。

添加代码：外层 div 用 flex 并排显示，加 items-center 和一个左右的间距。左侧放 UAvatar，它默认是灰色的，希望变成白色，用 Nuxt UI 组件通用的 `ui` 属性添加 Tailwind 类名，把 background 改成白色。右侧加 UButton，文案写 Upload。

## 接入表单系统

把组件展示到界面：userData 里先添加一个 picture 属性置为空；从 `#components` 拿到自动导入的组件，这里能拿到 FileUploader；在 fields 里 nickname 下面添加一个字段，label 写 User Avatar，name 是 picture（和属性名称对应），as 是 FileUploader（自定义组件）。保存后界面上就出现了这个组件。

给组件添加 v-model 实现。先声明 props：第一部分希望把 username 也传过来，可以加在头像上作为 fallback，没有图片时显示对应字母；第二个就是很重要的 modelValue，设为可选的 string，不传时置为空字符串。把 defineProps 的泛型传进去。然后定义事件，先暂定为最简单的：只支持 v-model，即 `update:modelValue`。

实现功能：拿一个内部变量 `innerValue`，从 modelValue 衍生，默认值是不存在时为空字符串。把值传上去：src 用 innerValue，alt 用 username。

## 选择文件

实现选择图片的功能，和之前一样：添加一个隐藏的 input，点击 UButton 时其实触发这个 input 完成文件选择。给 input 加 `style="display: none"` 让它显示不出来；在 Upload 上添加一个 `triggerUpload` 函数，功能就是点击一下这个控件。

需要拿到 DOM 节点，创建一个变量 `fileInput`：初始 null，有值后是 HTMLInputElement。添加同名 ref 产生联系。triggerUpload 里先判断 fileInput.value 存在（先清空旧值），然后调用它的 click()。把 triggerUpload 加到 UButton 的 click 事件上。

测试：刷新后点击 Upload，文件选择框弹出来了，第一步功能实现。

## 模拟更新 v-model

接下来在 input change 的时候拿到文件并更新 v-model。先给 input 加 `accept`，只接收图片类型的文件；再添加处理函数 `handleFileChange`，接收事件对象。

拿文件大家已经非常熟悉：先拿 `event.target`，做 HTMLInputElement 类型断言，然后拿到上面的 files。files 的类型是 FileList 或 null，所以用 if 把 null 过滤掉。这里只支持单个文件，拿 files 的第一项即可。

console 一下确认能拿到文件。开头说了这节课不需要完成上传过程，所以只模拟：找了一个静态图片地址叫 `updateUrl`（大家也可以自己找一个图片 URL），然后：

```ts
innerValue.value = updateUrl
emit('update:modelValue', updateUrl)
```

除了更新 innerValue，还要支持 v-model，即 emit update:modelValue，把 updateUrl 传进去。最后把 handleFileChange 加到 input 的 change 事件上。

最后做一个小改动：username 是必传项，组件调用时它的值自然对应表单里的值，传 `userData.value.username`。

## 测试

测试整个功能：点击 Upload 选择一张图片，图更新了，说明第一步实现；再看 pre 里的数据，支持 v-model 后 picture 对应的值也更新了。自定义的 uploader 成功接入整个表单系统。
