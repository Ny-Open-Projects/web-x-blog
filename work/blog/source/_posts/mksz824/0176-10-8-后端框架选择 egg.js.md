前面几节我们调研了 TypeScript 和 Koa 2。它们的共同特点是简单、扩展性强，很适合个人开发者的小项目。但如果换成企业级大型项目，很多程序员一起维护，过于灵活反而可能带来负面影响：每个人都可能写出自己风格、千奇百怪的代码，对统一维护和开发非常不利。

所以站在架构师的角度，模拟一个真实复杂全流程项目的后端开发框架选型时，我有三个诉求。

第一，需要一套优秀的统一约定或架构来开发，抹平团队之间的差异，减少多个开发人员的学习成本，大家学会之后就能并行开发。第二，要有丰富的扩展机制和可定制性。我们不需要大集市模式的框架。所谓大集市模式，就是框架里包罗万象，数据库、模板引擎、验证库等等全部内置，哪怕你根本不用，也会让框架非常臃肿。理想状态是想用哪个功能时，自行安装并配置。第三，对 TypeScript 的支持，这是我很看重的一点。在前端感受过 TS 的魔力之后，我在复杂项目中对 TS 的依赖程度上了一个新台阶。后端项目层级可能比前端更多、更复杂，还有上下文对象贯穿整个程序，有了 TS 类型支持，可以自动联想类型、方法和属性，对开发效率和规避错误都非常完美。

按照这三个需求调研和使用了一段时间后，我发现阿里出品的 egg.js 是非常好的选择，完美契合三个要求，还有几个得天独厚的点。首先它的 Star 数有一万七千多，说明使用的人多、足够流行，我看一个开源库会把 Star 数作为很重要的衡量标准。其次它是大厂出品，维护有保障。再次它是国内团队开发，中文文档质量很高。不少国内程序员英文不算好，读国外框架的英文文档有障碍，中文文档有保证对我们是实打实的利好。

再回到三个主要需求逐一验证。打开 eggjs.org 的指南，设计原则里明确写了具备很高的可扩展性，一个插件只做一件事：比如要用 MySQL 数据库，就封装成 egg-mysql 这样的插件引入使用；用模板引擎，也有对应的插件完成工作，符合丰富扩展机制和可定制性的要求。同时还有一条约定优于配置，按统一约定开发就有统一的架构和文件格式，团队内部采用这种方式能减少学习成本。最后是 TS 支持，教程最下面有专门的 TypeScript 章节，配有一系列独特文档，说明支持得很良好。特别要注意的是这里有一篇 egg.js 和 Koa 的文章：egg.js 是在 Koa 2 基础上开发的，对熟悉 Koa 2 的朋友来说是个很好的福利。

调研下来 egg.js 应该是很好的选择。这里再顺带介绍一个 egg.js 之后的后起之秀 Nest.js，值得大家注意，它是现在 Node.js 界非常火的框架，有四万个 star。它的一大特点是源代码完全用 TypeScript 编写，对 TS 的支持非常纯粹；而 egg.js 本身源码是 JS 写的，靠提供一系列定义文件来支持 TypeScript，从语言统计里也能看到它 TypeScript 占比达百分之九十九。其他鲜明特性和 egg.js 类似，同样满足前面两个机制。它本身还有一个非常独特的亮点：在类上大量使用装饰器，和 Angular 有点像，用过 Angular 的话会觉得非常亲切。从文档看，@Controller 装饰器就定义了一个基本控制器；要用 response，就用 @Res 注入响应对象；要用 request，就用 @Req 注入请求对象。感兴趣的话可以尝试，它也是非常出色的后端框架。对我们项目来说，Nest.js 和 egg.js 都符合要求。

概念讲到这里，大家更关心的还是编码，接下来就创建项目，从项目出发阐述 egg.js 的基础知识和核心思想。注意我们要创建的是 TS 项目，和官方直接开始部分有区别，要按 TypeScript 章节里的快速入门来做。先创建一个文件夹，我称之为 OpsFlow 后端，进入后在里面运行 npm init egg --type=ts，其中 --type=ts 告诉它用 TypeScript 语言初始化。前提提醒一下，Node.js 版本最好在 10 以上再创建，万无一失。等待一段时间后会弹出交互，依次填写 project name（直接用默认）、description（随便写）、author（写你的名字），还有一个 cookie security keys 安全码，会自动生成一个，用默认的即可，init 就完成了。

接着运行 npm install 安装依赖，依赖比较多，稍微等一会儿。装完就可以用内置的 npm run dev 启动开发环境。启动时 egg-ts-helper 会创建一系列声明文件，然后看到 started 在 7001 端口，说明启动成功。访问 localhost:7001，看到 hi, egg 的信息，整个过程就成功了，同时也能看到项目的基本结构。

这节课我们完成了后端框架选型，用 egg.js 创建了项目并成功运行起来。下节课继续介绍 egg.js 的基础知识。
