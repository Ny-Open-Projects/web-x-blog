这节课开始功能编码，首先解决布局问题。现在整个界面可以说是丑出天际，需要用 Nuxt UI 简单装修一下。一般的管理系统都有这么一个界面，我画了一个 mockup，先过一遍：

整体布局分几部分。第一部分是 header 头部：左侧是一个 link，很好实现；右侧是一个 dropdown，即一个类似头像的图标，点击后弹出下拉菜单，里面有几项：第一项显示 username，第二项是编辑个人资料（点击后跳转到对应链接），第三项是退出登录。现在不需要实现任何功能，只需要把界面渲染出来。

header 之后是左右两栏结构：左边是一系列导航，比如用户管理、海报管理、其他管理等；右边是管理系统常见的界面，映入眼帘的第一步是一个表格（都要展示数据），表格下面左侧显示共有多少条记录，右侧一般是分页；上面还有一些额外的功能，比如按某个属性查询（用户管理自然按用户名查），输入后点击查询刷新出新值；还有创建新用户的按钮。

这就是整个 default layout 的框架，点击导航时只有中间内容区在变，其他地方都不变。这节课的任务是装修 header。

## 修缮 header 结构

header 相对简单，左侧是直接的链接，不在话下；右侧是 dropdown，适合练手看看 Nuxt UI 的下拉菜单由哪些组件完成。

先把代码挪到前面做简单修缮：那些多余的导航项都不需要了，只保留 home，其他删掉。一些判断也不需要了：能出现这个界面说明已登录，user 自然存在；user 不存在会自动跳到 login 页面。所以删掉这些判断，留一个 li，先放一个 username。再把 flex 简单装修一下，加一些 Tailwind 类，其实和之前类似，只是加了居中、border 等。

保存后界面变成了和 mockup 非常类似的布局：链接在左侧，username 在右侧。接下来替换右侧，渲染一个下拉菜单。

## Dropdown 与 Avatar

下拉菜单在 Nuxt UI 中叫 Dropdown。它有一系列属性，不一一看，直接看例子。Dropdown 最重要的是 `items` 属性，用来渲染下拉菜单的内容；还有 popover 相关的 `placement`，指定下拉菜单出现的位置，bottom start 就是在下方靠开始的位置。它里面有个 slot，决定哪个元素触发下拉菜单。

这里和示例有点区别：示例用的是 button，而我们希望用一个头像。所以还需要 Nuxt UI 的另一个组件 Avatar。把 Dropdown 的示例代码复制过来放在 li 里，items 暂时不添加，先把 slot 里的触发元素换成 Avatar。

Avatar 很简单，我们需要 src、alt 和 size 这几个属性。尺寸有大小多种选择，sm 代表小，我们希望这里是 lg 大尺寸，先改一下。然后传入动态值：src 用 data 里的 picture 属性（user 的图片）；alt 用于 picture 为 undefined 时用一个字母代替图片，取 userData.username。

看界面效果，Avatar 已经出现了。下一步添加下拉菜单的 items。

## items 数组结构

items 是一个数组，数组里放多项。特别注意看文档：Dropdown 可以做成带多个分割线的形式，每个分割线之间是一个数组，比如第一组是一个数组，示例里创建了四个数组。我们希望有一条分割线，所以要创建两个数组。

第一个数组里，第一行希望显示头像加 username，和文档示例非常类似，直接照猫画虎拿过来，调整缩进。label 从 userData 取 username；src 和 alt 跟 Avatar 的属性完全一样，直接复制过来。

别忘了把 items 传给 Dropdown 组件（`v-bind="{ items }"`）。保存后下拉菜单出现了，第一项成功添加。

接下来添加第二组，里面有两项，属性直接复制，解释一下含义：label 是里面的内容；icon 是图标的名称（图标的规则等会儿说）；shortcut 是快捷键操作，可以写任何字母的快捷键；click 是点击后调用的回调函数。保存后点击就能弹出对应的选项了。再把退出登录加上，和编辑资料非常类似。

## Iconify 图标方案

最后解释一下 icons 的解决方案，非常强大。这么长一串图标名可能有些费解，解释完就清楚了。

Nuxt UI 使用的是 Iconify，一个图标解决方案合集，几乎囊括市面上所有的图标，选择范围非常广，有十万加的图标。可以通过 icones 网站搜索：跳转过去能看到各种图标集合，你知道的图标集合基本都能找到。

命名规则是：`i` 加 `-`，然后是 collection name，再加 `-` 加 icon name。比如 `i-hero-xxx`，集合名是 hero icons，后面是具体的图标名称。

搜索一下：搜 hero 出现 hero icons 系列，选第一个；再搜 pencil（编辑模式），出现各种铅笔图标，点击后命名是 `pencil-square-20-solid`，和我们代码里的一致。这个 20 其实是图标大小，往前还有 16 的，还有不带尺寸的。

这就是图标相关的解决方案。解释完以后，大家去找对应图标就很容易了。保存后看 header 的最终成果：点击弹出一个完美的下拉菜单，三个选项，中间有分割线，第一项显示名称，后两项是带图标的文字。

这节课完成了 header 的编码工作，熟悉了 Nuxt UI 的两个组件以及图标解决方案的使用方式。
