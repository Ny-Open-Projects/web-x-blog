上节课我们介绍了对 MongoDB 数组的处理，现在能插入、删除以及按数字下标更新了。这节课学怎样按数组中的元素来更新，比如只想把数组里那个 golf 改成另一个值。解决这个问题前，先学怎样查找具体的数组元素。查找的道理和之前完全一样：基本的查找、带特定操作符的查找，针对数组都是一个道理，只是多了一些新操作符，一起看看。

第一种是完全匹配查找，老内容。我这里稍微改了下代码：给 db.collection 传入了泛型，规定 model 的类型长什么样子，之后 document 就会在特定场景提供到自动补全当中去，现在 hobbies 可以自动补全出来了。当前数组里有 golf、music、reading 三项，把整个数组原样复制过去作为条件，调用 findOne 查找，console.log 把 result 打印出来，运行 ts-node 后查到了 brown 这条记录。但这种查找方式非常笨，必须数组完全匹配才能查到。

我们希望数组中部分元素匹配也能查到，这时用新操作符 $all：只要包含你给的项就能查到对应的结果。假如我们只知道两项 golf 和 music，没有其他的，条件写成 hobbies 的 $all，把你想要查找的项放进去即可，现在只要求包含 golf 和 music。运行后同样查到这条记录，因为它的 hobbies 包含这两项。$all 就是"包含"的意思。

第三种情况是匹配其中某个元素：条件不用写 array 或 object 类型，直接以字符串的形式提供就好，比如直接查 golf。运行后也能查到对应的记录，它会自动帮你在 hobbies 中进行遍历，查找是否有你需要的元素，非常方便。它还提供各种字符串相关的操作符，比如查找字符串时可以用正则 $regex，写 golf 的部分匹配，运行后同样查到这条记录。

现在了解了怎么搜索数组元素，该说说搜到的数组元素怎样更新了。MongoDB 提供了一个对应的占位符 $。等会儿写的时候大家会发现它的写法比较奇怪，一开始可能比较难理解，多用几次就学会了。

把之前的 update 代码拿出来，把注释去掉。updateOne 的第一个参数是要找的记录，这次多一个条件：查找 hobbies 当中的特定项，比如还是高尔夫 golf。找到以后，更新部分有个特殊写法：之前我们用 'hobbies.0' 这种数组下标，现在用占位符 $ 代替数组下标，它代表你查找到这一项的下标。比如 golf 在 hobbies 中是第 0 项，这个 $ 在这里就等于 0。更新成 golfNew，看看能否更新具体元素成功。运行后输出更新成功，用 query 查一下，golf 已经被更新成 golfNew，说明成功了。

特别注意：你提供的查询条件必须能够查找到记录才行。假如条件没有查到任何元素，更新就不会有任何效果，这一点大家肯定也知道。

通过这节课学习了查找数组，以及根据查找到的数组结果更新的方式。到这里增删改查的基本知识已经差不多都掌握了，操作符非常多，是比较庞杂的一系列内容。下节课做一个小小的汇总，把这部分内容整理一下，温故而知新。
