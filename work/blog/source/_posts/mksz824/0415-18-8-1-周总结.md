到这一讲，本周的学习就完成了。这周表面上是在完成剩余页面的开发，实际主题是一些有特点的第三方工具的使用和对应的原理分析，还有一个钩子函数的进化过程。希望通过这一周的学习扩展大家知识的广度：对客户端浏览器操作文件的方法更加了解，以后遇到类似需求时，既能轻松选用合适的第三方工具完成任务，也了解它们内在的简单原理。下面回顾本周要点。

第一个是使用最多的 html2canvas，一个 DOM 节点截图工具。基本用法就是直接调用这个方法，把节点转化成 Canvas。有了 Canvas 之后就可以做后续处理，上传图片也好，转成字符串也好，都没问题。同时我们踩了一些坑：它不支持 box-shadow，需要把 box-shadow 去掉；它内部的图片必须支持跨域访问，不支持的话对应图片就不会显示。最后还学了 html2canvas 的基本原理，用一段简单代码模拟了整个过程：先使用 SVG 的 foreignObject 标签插入需要的 DOM 元素，创建一个新的 SVG 文件；然后创建 image 标签，用生成的 SVG 文件作为它的 href；再用 `canvas.getContext('2d')` 拿到上下文，调用 drawImage 把这个 image 绘制到 canvas 画布上，之后就可以用 canvas 做下一步操作了。

第二个工具是 qrcode，用来生成二维码。我们学了生成二维码的基本操作，还特别提到了 Vue 上一个容易踩的坑：watch 监听响应式数组时的问题，怎样才能正确拿到新值和旧值。

第三个是 clipboard.js，实现内容拷贝到剪贴板。基本使用很简单，同时我们解释了它的原理。完成拷贝有两种方式：第一种用现代的 Clipboard API，也就是 `navigator.clipboard.writeText` 方法。理想美好，现实骨感，这个 API 并不是所有浏览器都支持。所以学习了 clipboard.js 的一种实现：它使用兼容性更好的 execCommand 命令，但这个命令不支持指定要拷贝的文本，所以要另辟蹊径获取对应文本。具体做法是创建一个 textarea 节点，把位置设置成不可见，把它的 value 设成想要拷贝的内容，调用 select 选中这些值，最后调用 `document.execCommand('copy')` 完成拷贝。

之后是本周比较复杂的钩子函数改造：useLoadMore。它的基本功能同时满足加载更多和无限滚动两种需求，我们先在首页完成了任务；到了我的作品页，因为那里有上页下页的翻页，我们给它添加了翻页功能；最后继续进化，实现了分页选取。从这个钩子函数的改造可以看出，完成一个 UI 任务时，首先要想到把 UI 和逻辑解耦。useLoadMore 就做到了界面和逻辑的解耦，一套逻辑可以适配多个界面表现形式。

最后是浏览器端下载文件的原理。它的原理挺简单：同源的情况下，使用 a 链接的 download 属性，把 download 属性设置为想保存的文件名，直接触发 a 链接的 click，就可以完成默认下载。跨域的情况稍微复杂一点，需要发送异步请求，特别注意要把返回的数据设置成 Blob 类型，然后用 `URL.createObjectURL` 把 Blob 存成内存 URL，再点击 a 链接下载。之后还学了服务器端下载文件的原理：如果不想让浏览器端用 JavaScript 处理下载，而是直接用 HTTP 请求完成，最好的方式是使用 Content-Disposition 响应头。把它设置为 attachment 加上 filename，发起请求时浏览器就会自动下载文件。这种方式兼容性非常好，也不需要任何 JavaScript 操作，是非常好的实现方式。

最后我们对 FileSaver.js 做了源码解析，发现它的实现和我们的方法几乎一致，只是添加了更多兼容性代码，也就是 polyfill。比如它使用了 msSaveOrOpenBlob 这个微软 IE 浏览器专属的方法；最终兜底方案是创建一个新窗口，用 FileReader 读取文件拿到 base64 数据，设置到新窗口的 href 上完成下载。

本周工具用得多，知识点也稍微密集一些，请大家课后回顾，好好消化。本周学习就到这里，谢谢大家。
