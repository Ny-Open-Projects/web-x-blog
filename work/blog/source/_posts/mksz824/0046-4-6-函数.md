上节课讲了 interface，它像一种规范和契约，规定一个对象应该长成什么样子，稍有不同就会发出警告。这节课来接触老朋友函数。函数是构成程序的重要组成部分，在 Haskell 里函数被称为"一等公民"，意思是函数和其他对象地位相同：可以作为参数传入，可以存入数组，可以被另一个函数返回，也可以赋值给变量。

## 约定输入和输出

函数由输入和输出两部分构成：输入通过传参实现，输出就是返回值。用 TypeScript 分别约定它们：

```typescript
function add(x: number, y: number): number {
  return x + y;
}
```

参数名后加冒号声明参数类型，返回值类型写在括号后面。调用 `add(1, 2)` 没问题；把参数改成 string 会报错；多传一个参数同样报错。返回值也有约束：`const result = add(1, 2)` 的 result 自动获得了 number 类型。

## 可选参数

参数变多时如何实现可选参数？和 interface 一样加问号：

```typescript
function add(x: number, y: number, z?: number): number {
  if (typeof z === 'number') {
    return x + y + z;
  }
  return x + y;
}
```

注意可选参数后面不能再接必选参数，比如再加一个 t 会报错：`a required parameter cannot follow an optional parameter`。

## 函数类型

除了声明写法，JavaScript 里还有函数表达式。写成 const 加箭头函数的形式后，把鼠标移到 add 上会发现一个神奇的现象：add 自动获得了一个类型。也就是说函数不仅有输入输出的类型，它本身也有类型。因此不能把它赋给一个声明为 string 类型的变量。

如果要显式声明函数类型，在冒号后写出完整的签名，箭头连接返回值。注意这里的箭头不是 ES6 的箭头函数，而是 TS 中声明函数类型返回值的写法：

```typescript
const add2: (x: number, y: number, z?: number) => number = add;
```

牢记一点：在 TypeScript 中，冒号后面写的都是类型声明，和实际的代码逻辑没有关系。

## 用 interface 描述函数

上节课说 interface 有 duck typing 的概念，可以描述各种类型，那么它能描述函数吗？看它的第二个法宝。新建一个接口，把函数签名放进去，返回值改用冒号而不是箭头：

```typescript
interface ISum {
  (x: number, y: number, z?: number): number;
}
```

注意两种写法的区别：直接声明类型时用箭头连接返回值，interface 里则用冒号。把 add 赋值为 ISum 类型的变量，完全可以匹配。

最后留一个小悬念：`const add = ...` 这种函数表达式写法，我们并没有声明类型，add 却自动获得了函数的类型，这是为什么？下节课揭晓。
