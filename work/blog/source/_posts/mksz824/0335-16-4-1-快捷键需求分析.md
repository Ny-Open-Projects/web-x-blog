拖动改变位置和大小这两个重要交互已经完成，现在来做另一个对用户很重要的交互：快捷键。在常见的交互需求中，用户会不自觉地使用快捷键完成画布上元素的常用操作，尤其是画布这种场景，提供快捷键非常有必要，它会让整个应用的易用性上升一个层次。

举个例子：选中一个图层，点击 Command 加 C 或 Control C，会显示已拷贝；点击 Control V 显示已粘贴，就能拿到粘贴的图层；点击 Delete 会删除当前图层；按上下左右键进行对应移动。这些操作在键盘上微调位置，比使用鼠标方便很多。

## 需求分类

线上应用里已经有一系列提示，它们对应的就是这些快捷键操作。分类以后有两类需求。

第一类是**元素选择**，这些操作大部分前提是元素被选中。

- **拷贝图层**：Command C 或 Control 加 C，是组合键。实现原理是对 store 进行操作：保存一份（或创建一份）当前被选中元素的数据结构。
- **粘贴图层**：Command 加 V 或 Control 加 V，把刚才新建的元素添加到 components 数组中。
- **删除图层**：Backspace 或者 Delete，在 components 数组中删除选中的元素。可以用 filter 直接把对应 id 过滤出去，当时还留了一个作业让大家自己完成，相信很简单。
- **取消选择**：点击 ESC，把 store 中指示的 currentElement 置成空即可，表示当前没有任何选择。

第二类是**元素移动**：

- 上下左右移动一像素，使用上下左右键触发；
- 上下左右移动十像素，使用 shift 加上下左右触发。

它们本质上都是更新选中元素，也就是更新 props 中的 top、left 值，给它加减对应的数值，就能实现元素移动。

最后还有一个需求：**撤销重做**，也就是代码编辑器里非常常见、大家每天用得最多的功能。撤销是 command 加 z，重做是 command shift 加 z。这是本周难度最大的需求，所以这里暂时不做，下一章具体讲怎样完成。

## 选择 hotkeys.js

了解需求后，需要一个好用的库来帮助完成快捷键的绑定。之前创建过一个很简单的 useKeyPress 函数，在 InlineEdit 组件中完成了 esc 和 enter 的绑定。但现在需求复杂了很多，有很多组合键，需要一个更完善的第三方库。这也是一贯的思路：了解了原理以后，对于比较复杂的需求，自己研究的解决方案有可能没法胜任，就可以用更完善的第三方库作为替代方案。

推荐使用 hotkeys.js，它是 GitHub 上比较火的解决方案，star 有 4.7k。它是一个独立的第三方库，不和 Vue 或 React 这类 UI 层面的库做强绑定，大小只有 3k 左右，功能很强大，而且是国人开发者的作品。

看它的几个特性。首先是 supported keys：支持非常多的 modifiers（功能键），比如 Mac 上的系列键，Shift、Option、Control、Command 等等。还支持一系列 special keys，比如 Backspace、Tab、Clear、Enter、Return、ESC 等等，想要的 key 基本都支持。

用法上它是一个函数，有两个参数：第一个是需要监听的键的名称，组合键直接用加号连接；第二个是回调函数，在里面触发对应的行为。

它还有一个更高级的特性：scope 的概念。可以把快捷键设置多个 scope，在不同的 scope 中启用不同的快捷键处理方式。比如在 editor 下 Control C 是复制，在另外页面 Control C 是另外一个作用，这时就可以设置多个 scope 来完成任务。还有更多特性，有兴趣可以自己研究。

## 小结
