上节课成功新建了项目。在正式学习 Vue 3 知识之前，先看一下初始创建的文件结构，并安装几个好用的 VS Code 插件。工欲善其事，必先利其器。

## 初始文件结构

进入项目文件夹（如果还没 npm install，先安装依赖），用 VS Code 打开，可以看到由几个文件夹和一系列文件组成。

来到一个项目，我习惯第一个看 package.json，了解有哪些命令和依赖。命令有三条：npm run dev，启动本地开发服务器；build，给生产环境打包；preview 和 dev 不同，用来预览打包生成以后的代码。这里只需要使用 npm run dev，回车后可以看到速度非常快，约 400 毫秒就编译完毕。用过 Vue CLI 的同学知道它需要很长时间，Vite 确实快。打开对应路径，端口号是 5173，就能看到项目创建成功。

再看依赖，非常精简：dependencies 里只安装了 Vue；devDependencies 有 vite 及其一个插件、typescript 和 vue-tsx。

看完 package.json 来到 tsconfig.json。上一章介绍 TypeScript 时提到过，这是配置文件，这里简单浏览就好。有一点奇怪的是，这里还含有另一个配置文件 tsconfig.node.json，打开后和它非常相似。区别在于 Vite 有两个运行环境：第一是浏览器运行环境，就是刚才打开的页面；第二是 Vite 本身运行在 node.js 下。这两个配置文件分别对应两种不同的环境，了解即可。

接下来是 vite.config.ts，顾名思义，它是整个脚手架工具的配置文件，默认很简单，里面就安装了一个插件 plugin-vue，用来处理各种不同的 Vue 文件。之后我们会在这个配置文件上扩展、安装新插件，到时候再讲玄机。

配置文件说完，进入项目本身。index.html 是根文件、最基本的入口文件，很简单，里面有一个 id 为 app 的入口节点，对应的处理在 src/main.ts。得益于 Vite 的强大，可以直接把 .ts 文件放在这里。main.ts 里的代码也很简单：把 createApp 引进来，调用 createApp 对应的入口组件，mount 到 app 节点上，最终出现对应的结果。这些 API 后面都会讲解，大家了解意思就好。

这里还留了一个伏笔：现在在 TS 中引用 .vue 后缀名的文件会报错，怎样解决马上会说。

说完入口文件再说根组件 App.vue。它也很简单，引用了一个子组件并添加两个 a 链接（都是两张图），最终形成页面结果。对应的子组件是 HelloWorld，里面就是一段文字和一个 button 的效果，功能之后再讲，现在分清楚文件结构即可。

最后要特殊强调一个文件：vite-env.d.ts。点开可以看到它添加了一个 reference，指向 vite/client，安装在 node_modules 当中。探索一下这个文件：滑到最下面找到 vite/client.d.ts，发现它定义的是一系列第三方文件的类型，比如 CSS 文件、图片等一系列文件。有了这些定义，我们才能在 main.ts 中加载对应的文件，比如 .css 文件可以成功加载并获得类型。

## 两个必装 VS Code 插件

为了让开发过程更友好，推荐两个 VS Code 插件。

**第一个是 Volar（Vue 官方推荐，必装）。** 官方文档的 IDE 支持部分写明：推荐使用 VS Code 配合 Volar 插件，它提供语法高亮、TS 支持，以及模板内表达式和组件 props 的智能提示等。

在扩展商店搜索 Volar。大家以前开发 Vue 文件一般用 Vetur 插件，特别注意不要两个都装：如果要用 Volar，第一步就是把 Vetur 禁用掉，两者会互相冲突。

Volar 有什么功能？.vue 文件是一种不规则的文件类型，称为 SFC，它把 script、template、style 三块不同的内容放到一个文件中，VS Code 默认没法识别。禁用 Volar 后 reload，可以看到所有内容都变成了灰色；启用后三块都被高亮了。

简介它的两个功能。第一是属性提示：在 HTML 节点上自动提示对应属性，比如 a 链接键入 href 会提示，还可以快速输入；默认的 Vue 指令也会提示，比如 v-if、v-bind 等一系列提示。不仅有原生 HTML tag 的提示，组件也有：HelloWorld 组件中有一个 message 属性，把它删掉输入 msg，message 属性就会出现，很方便输入。第二是和 TS 相关的功能，非常强大：在 script 中定义变量 a = 1，在 template 中输入时它会根据变量名称提示，比如输入 a 就出现 about，并提示对应类型。about = 1 经过类型推论自动是 number 类型。

**第二个是 TypeScript Vue Plugin。** 它和刚才的报错相关：main.ts 中引入 .vue 文件报错，是因为 .vue 不是合法的文件类型，TS 没法看懂和解析。搜索第二个结果 TypeScript Vue Plugin，启用它，一瞬间错误就消失了。它还能正确识别 .vue 后缀的文件并支持跳转，点击引用可以成功跳到对应文件。

## 浏览器插件

除了这两个 VS Code 插件，还要安装一个官方推荐的浏览器插件（Vue Devtools），地址在文档里，大家自己安装。安装后打开开发者工具，选择 Vue，稍等片刻它会把组件生成一棵树，看得非常清楚：可以选择组件，里面的值都有。比如 HelloWorld 组件中 props 的 message 传的是什么、setup 中有一个 ref 值，都可以直接修改，点击后页面上的值也会更新。ref 是什么后面课程会讲。这个浏览器插件非常方便，请安装一下。

Vue 默认创建的文件结构，两个必装的 VS Code 插件，一个浏览器插件，今天的任务就完成了。下节课继续规范开发环境，看看还要安装什么工具把它做到完美。
