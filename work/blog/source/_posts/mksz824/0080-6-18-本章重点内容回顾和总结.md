经过一周的学习，我们完成了两个大任务：一个是根据业务组件 LText 的编码过程；另一个是业务组件的属性和对应表单展示的显示和更新。最后还修复了一个小问题：VNode 在 template 中无法展示的问题。来看看通过这个过程我们学习到了什么知识点，做一次整个过程回顾。

回顾的时候，我建议大家打开自己在 Git 上面的提交记录。良好的 commit message 可以很好地帮我们回顾这一周的知识，请大家别忘了我们的 Git 标准。我这里已经创建了 pull request，上面的 message 也很清晰，知道每一小节做了什么样的事情。

回到文档当中。首先完成的是业务组件的过程。第一步，我们创建了编辑器 Vuex store 的结构；然后在画布中使用一个组件循环展示了画布中的一系列组件。接下来是组件的初步实现。特别注意这里我们引入了 lodash，用它的这一系列 utility function 来完成功能，比如完成了分离样式属性的功能。第三点，我们添加了通用和特殊的属性，并将这些属性转换成了 props 验证的类型，放在了 LText 组件上面。之后完成了抽取重用逻辑的过程，包括 style 的抽取和点击跳转这两个公共逻辑的抽取。最后添加了一些 action：在左侧组件库点击的时候添加到画布的一个整体的逻辑，这其实是对 Vuex 的一系列操作。

完成 LText 这个简单的组件以后，我们来到组件属性对应表单的展示和更新过程。首先要获得正在被编辑的元素，这里我们使用了 Vuex getters 来完成。接下来创建了属性和表单组件的对应关系，使用一个 object 来完成。然后使用 PropsTable 这么一个组件，将传入的属性渲染成对应的表单组件。接下来丰富对应关系字段，添加了一系列字段用来支持更多自定义配置，比如添加了 subComponent 和 options 来添加一系列子组件。最后我们使用一个标准流程更新表单并完成实时同步，这个标准很关键。在这里我们用图的方式给大家解释了单向数据流在这里是怎样运作的。

这样就完成了两大块内容。当然接下来还提了一个小需求，用这个需求学习一系列知识点，就是 Vue 组件渲染的真谛和不同的书写方法。首先弄清楚了 Virtual DOM 是什么、组件返回的是什么内容；接下来学习了 createVNode 和 h 函数，它们用来创建虚拟 DOM 的 VNode 节点；然后了解了 template 写法和 JSX 写法各有什么优劣；最后说了写 Vue 组件的几种格式：最常见的 SFC 单文件格式、function 函数式组件、用 render function 书写的 object 等等。

这就是整个内容。再提几个要点，也是课中多次提到的。第一个当然是 TypeScript 在实际项目中的实践。一定要强化 TS 的意识，必须以静态语言的特性进行思考，让它帮助我们完成一系列的工作，深入到编码理念中去。

第二个要点，我们得出了一个真谛：开发展示和编辑属性表单组件的真谛。以后我们会二次开发或者自研一系列属性对应的表单组件，这个可以作为这类组件的指导思想：一是必须提供一个属性传入需要编辑的值，这个属性默认称之为 value，可以使用任何字段，但要有这样的值；二是必须提供一个事件，发射出编辑后更新的值，这个事件默认为 change。这就是这个过程的一个真谛。

第三个要点，通过这个过程，我们了解了 Vue 组件的返回是什么，以及 template 和 JSX 的异同：什么情况下选择 template 写法，什么情况下选择 JSX 写法。

最后是作业，分为三个部分，分别锻炼大家三方面的能力。第一个很简单，之前也说过：完成删除画布组件的逻辑，主要练习 Vuex 的操作。现在有添加可以新增，这里希望大家在画布中每个组件上加一个按钮（因为还没有快捷键），点击这个按钮就可以删除画布中的组件。第二个作业是添加更多的属性和组件的对应关系。我们现在添加了一部分作为举例，其实还有更多，每个类型上我都添加了一个。希望大家把其他的一部分都添加上去。特别注意有一些特殊的属性，比如 opacity（透明度）：它是滑动选择，使用 slider 组件，但它是 100 到 0 倒排的，并且要注意值的转换，因为它上面显示的是 100，最终应该转换成 1，因为 opacity 最大是 1，是从 0 到 1 的对应关系。这个作业还能了解到 Ant Design Vue 组件的一些使用，比如 slider 上面的一系列属性和特殊的 initalTransform、afterTransform 处理。最后一个作业是修复在画布中点击组件跳转的问题。hello3 有 url 并且 actionType 等于 url，点击编辑它的时候会自动跳转。所以我们要修复这个问题：当它在画布中的时候，希望点击这个行为不会被触发。

讲到这里，这一周就告一段落了。不知道大家学习得怎么样？谢谢大家。
