现在我们想在项目中添加测试，需要一款通用的测试框架：支持特定的语法来写测试用例，并且可以运行这些测试。如果对测试框架有些了解，你可能会想到 Mocha 或 Jasmine，这两个是我之前写测试用得最多的框架。但现在我要介绍一个后起之秀：Jest，它是 Facebook 出品的一款通用测试框架，吸收了几位老前辈的特点，还内置了许多新特性。

一个测试框架一般有这么几大功能，一个好的框架必须在这些特性上做到完美，之后我也会分门别类地讲解。第一类是断言：提供一系列 API，让你判断一个值是否对应相应的结果。这个功能 Jest 是内置的，而 Mocha 需要另外安装断言库，比如 chai。第二是异步支持：代码异步运行时，测试框架必须有能力知道异步测试是否结束，Mocha 和 Jest 对这个特性都有良好支持。第三是 Mock：让测试有能力模拟那些和本次测试无关的内容和返回，对测试进行简化和隔离，这无疑非常重要。Jest 内置了 Mock 功能，而 Mocha 需要安装第三方插件，比如 Sinon。最后是代码覆盖率（test coverage），可以看到你的测试覆盖了代码的多少部分。Jest 也是内置的，Mocha 需要安装第三方工具，比如 Istanbul。

从这里可以看出 Jest 的特点：开箱即用，什么功能都给你配齐，而且零配置，用起来非常方便。Mocha 的特点则是灵活、可扩展，把一些功能的实现交给第三方插件，用啥自己看着办。

再看看官网的其他特点。它的口号是 "Delightful JavaScript Testing Framework"，意思是令人愉悦的、用它写测试很开心的框架。很多知名项目都在使用它，比如 Babel、TypeScript、Node、React、Angular、Vue 等等。其他特性包括 fast and safe（运行速度非常快）、内置的 code coverage、easy mocking（非常容易实现 mock）。同时它还是 create-react-app 和 Vue CLI 这两个脚手架工具内置的默认测试框架，说明它已经得到了非常高的肯定。

下面简单介绍它的使用。它是一个命令行工具，自然用 `npm install jest --save-dev` 安装。我新建了一个项目来讲解 Jest 的基本用法，装完后用 `npx jest --version` 查看版本，可以看到我安装的是 26.6.3。

接下来介绍第一个核心概念：断言。打开它的文档，点击 Using Matchers 章节。断言的意思就是判断一个值是否对应相同的结果，这是测试的精髓所在：判断计算出来的值是否是预期的结果。通用框架提供一系列语法帮助我们完成这项工作。在 Jest 中，这些 API 称为 Matchers，分为几类：Common Matchers，代表方法是 toBe，判断一个值完全等于另一个值；布尔判断，有 toBeNull、toBeUndefined、toBeDefined、toBeTruthy、toBeFalsy 等，看名字就知道用途；数字类，有 toBeGreaterThan、toBeGreaterThanOrEqual 等一系列判断数字的 API；还有字符串类的 toMatch，以及对象、数组等类型。这里就不一一展开了，有兴趣可以自己看文档。

现在用 Jest 完成几个通用的测试，我这里已经写好了，关键是熟悉不同 API 的使用。测试文件以 test.js 结尾，所有内容都包裹在 test 当中，每一个 test 包裹的内容称为一个 case，每个 case 一般测一个独立的功能点。比如 `expect(2 + 2).toBe(4)` 和 `expect(2 + 2).not.toBe(5)`，意思是等于四、不等于五。这就是 expect 语法的思想：非常接近英语的语法，写测试就像写英文作文一样简单，测试的内容也更加明晰。哪怕你没用过这个库，看到这两句话也知道它在判断什么。

下面把这些常见 Matchers 系列拿出来练练手：test not equal 已经写好；test to be true or false，对应 toBeTruthy 和 toBeFalsy；test number，4 大于 3 应该通过，2 小于等于 3；test object，希望对象的 name 等于 Viking，用 toEqual 和另一个对象比较。写完这几个简单的测试，直接在界面里运行一遍 test，它会自动运行以 .test.js 结尾的一系列测试用例。可以看到所有 case 全部通过，每个 case 标注得很清楚，画着勾，最后显示 pass。

这节课带大家了解了 Jest 这个通用测试工具和它的特点，以及最核心的断言库，并用断言完成了一系列最简单的测试。下节课深入 Jest 的高级内容。这节课到这里，谢谢大家，再见。
