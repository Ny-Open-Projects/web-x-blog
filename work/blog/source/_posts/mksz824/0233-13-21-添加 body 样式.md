## props 转 CSS：propsToStyle

背景的属性来自 content 当中的 props，它是一个 key-value 结构，比如 background-repeat 等于 no-repeat。想让它生成对应的 CSS 属性，可以把它们加到 body 的内联样式上：在 body 上添加一个 style 属性，把里面的 CSS 转换后添加进去。

转换规则其实很微妙。首先需要从 object 转换成字符串；其次属性名需要转换格式：把大写字母转换成"杠 + 小写字母"的连字符形式，比如 fontSize 变成 font-size。

来到 service，创建一个新方法 propsToStyle，参数叫 props，默认值是一个空对象。逻辑：

- 用 `Object.keys(props)` 拿到所有的 key，生成 styleArray（`keys.map(key => ...)`）；
- 每个 key 需要转换：value 不用动，key 要找到大写字母并转换。用一个 replace 配合正则 `/[A-Z]/g` 匹配所有大写字母（全局匹配），匹配到的字符串处理为模板字符串：一个 `-` 加上 `toLowerCase()` 转成小写。这样 fontSize 就转换成了 font-size 这样的字符串；
- 转换完成后把 value 放回去：value 取 `props[key]`；
- 最后 return 一个模板字符串：前面是 format 之后的 key，后面是 value，中间加个冒号和空格。

这样 styleArray 就完成了。return 时把 styleArray 用 join 连接成字符串，不同属性之间用分号连接，这样我们就生成了一个可以在 body 上使用的内联样式字符串。

## 挂到 body 上

在 service 里调用：`const bodyStyle = this.propsToStyle(content && content.props)`，content 存在的情况下再去取对应的值，拿到 bodyStyle 后随返回值一起返回。

有了数据，在模板的 body 上添加 `style="{{ bodyStyle }}"`，保存后刷新，背景添加上去了。

## CSS Reset

但背景和编辑器里的 work 还有一点出入：页面有一些空白和偏移。这些偏移来自浏览器对某些元素属性的默认值，比如 p 标签有 user agent stylesheet 提供的默认 margin。处理默认样式大家都很清楚：需要一个 CSS reset。这里直接使用一个 CDN 地址（mini reset，来自 Bootstrap CDN）添加到模板里，把浏览器的默认样式去掉。保存后看效果：默认的空白消失了，DevTools 里可以看到 mini reset 生效了，默认的 CSS 样式被删掉，现在看起来舒服一点了。

## 剩下的两个样式问题

还有两个问题需要解决，就是上节课说的剩下两个。第一个是不同手机浏览器不适配的问题。现在我们是 iPhone 6/7/8（375px），看起来最舒服，和编辑器完全一样，完美模拟了输出，因为编辑器中画布的宽度跟它一模一样，也是 375px。但如果切换手机型号（改变宽度，比如 425px），就会出现轻微的错位；宽度越大，错位的感觉越明显。

第二个问题：组件库中有一些通用样式没有起到作用。比如 p 标签的换行都没有了。在 l-text（也就是 OpsFlow 组件库的组件）中，它有一个单独的样式文件，对 p 标签（l-text 这个 class 下）添加了 `white-space: pre-wrap`，可以让换行符自动运作、正常换行。但没有添加这个样式的话，文本就会连在一起，换行符不起作用。

下节课会致力于解决这两个样式问题。
