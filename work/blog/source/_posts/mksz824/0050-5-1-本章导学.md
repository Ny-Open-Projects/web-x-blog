欢迎来到新一周的学习。上一周完成了基础知识的深入，认真学习的话，TypeScript 和 Vue3 的掌握程度应该上了新台阶。有了这些基础，我们就可以开始正式的项目研发了。这一周是项目的最初阶段，包括项目规范的介绍和制定，以及项目初期框架的整体搭建。

和之前的内容相比，这一周不算很难。有 Vue3 全家桶开发基础的同学，也许会觉得有些知识点已经掌握了，但我还是会尽量从不同的角度讲述，尤其想把 TypeScript 的类型思想继续深入到大家的编程习惯里。内容不困难，但一定要动手实践，不要光看。

## 本周收获

**第一部分是项目准备工作。** 首先是前端工具链相关工具的介绍和总结；接着是脚手架的使用，除了我们主打的 vue-cli，还对比了 Vite 之间内在的思想和优劣。对比学习已经成为整个课程的重要脉络。然后是编码规范，会详细讲解 ESLint，作为加餐还会讲讲很多人都好奇的 Prettier 是怎样工作的。特别注意，我们要产出编码规范文档；除了编码规范还有项目结构规范，同样要有文档支持。第一部分的最后会讲两种标准的 Git Flow，以对比的形式得出我们项目的 Git 操作标准，同样落到文档上。

**第二部分是项目框架搭建。** 这是实实在在写代码的内容，因为是项目前期所以不会很难，主要使用 Ant Design Vue、Vue Router 以及 Vuex，把整个项目的架子搭起来，同时教给大家框架的基础知识。有的知识点会写代码，有的直接写好讲解，以我认为的难易度为标准。

## 关键词

- **技术文档**：技术文档是项目前期重要的参考标准，技术规范必须落实到文档中，让所有团队成员参与并执行，这对项目发展和团队合作大有裨益。文档化是我一直给大家灌输的思想之一。
- **TypeScript**：开始在项目里使用 TS 以后，必须以 TypeScript 的思考方式去思考和解决问题，抛弃一部分 JS 无类型的思想。看到任何变量都想让它获得特定的类型，享受类型带来的便利。

## 学习方法

1. **对比学习**：上周对比框架，这次对比工具。对比不同工具的功能和实现，收获更多，选择工具时也更游刃有余。
2. **亲自实践**：古话说"无他，唯手熟耳"。即使代码简单，也建议快速写一遍，全当复习巩固。而且我保证会给你这些简单知识的一些新认识。
3. **不要教条主义**：很多解决方案没有唯一的标准答案，做项目不能照本宣科，没有金科玉律，适合自己项目的方案才是最优解。
4. **多看文档**：这周会接触一些第三方库，很多知识点需要自己翻阅文档，考验看文档的能力。

本周的开端就讲这么多，让我们正式开始项目，一起 happy hacking。
