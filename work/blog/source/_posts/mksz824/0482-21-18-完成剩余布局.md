这节课继续完成布局编码。上节课完成了 header，这节课完成下面这一块，同时学习几个 Tailwind CSS 的新功能。

## 修正 container

先修正之前的一个小问题：外层套了一个 container，导致整个宽度不是完全占满，而是生成了一个宽度为 1280 的容器。管理系统的布局一般要占据整个浏览器宽度，所以做个小修改：把这些都删掉，class 全去掉，只留一个 div。现在宽度占满了。

然后在 header 上加一点修饰：现在它完全顶齐，上面没有任何 padding。把 `pb` 改成 `py-2`，再加一点 x 轴的 `px-2`，最后加一个 `shadow`，创建一个浅浅的阴影，看起来更有层次感。

## Flex 左右布局

接下来生成下面的侧边栏和右侧的主要容器。点击导航时，内容最终就存放在右侧。这是经典的左右两栏布局，使用 flex 再合适不过。创建一个 flex 容器，并给它最小高度让它占满整个视窗：`min-h-screen`，也就是 min-height 100vh。

左边希望是定长的，右侧占据剩余空间。怎样创建一个定长容器？这里可以引出 Tailwind 的另一个强大功能：我们希望左侧是一个定死的 300px，但在文档里找不到直接定死多少 px 的数值，而是用 `w-3.5` 这样的比例（width 等于多少 rem）。最接近的精确值是 `w-72`，对应 288px，但我们希望是 300。

这种完全确定的值用 arbitrary values 完成：`w-[300px]`，方括号里填具体的像素值或比例值，就可以实现完全自定义的宽度。文档里 using custom values 一节有更多 arbitrary values 的详情，各种属性都能这样设定，非常强大。

给左侧添加 `w-[250px]`（或 300px，大家可以自行设置），再加背景色 `bg-gray-300`。右侧要占据剩余空间，相信大家都了解，直接加 `flex-1` 即可，再加背景色 `bg-gray-100`。

保存后左右两侧布局成功生成：左边定宽 250px，右侧占据剩余空间，整体用的 flex，顺带学了 arbitrary values 的用法。

## 修饰与 Sidebar

接着加一些 padding，别让内容直接顶到边上。左侧加一个 border 简单美化：`border-r` 只在右侧加，`border-gray-300` 显示右侧边框；把 gray 背景删掉；再加 padding-bottom 和 x 轴的 `px-2`。右侧同样加一些 padding：`pt-3` 和 `px-3`。

现在左右布局完成。接下来把 slot 放到右侧，因为这里是主要配置所在。然后在左侧添加一个 sidebar：我已创建了全局组件 `sidebar.vue`，把它放在这里，里面渲染导航。

竖向导航在 Nuxt UI 中有现成组件，叫 VerticalNavigation。很简单，和之前的 Menu 类似，通过一个 links 数组传进去，就会展示出一系列内容。我直接复制了 links，先创建三个：用户管理、海报管理、模版管理，接下来主要针对用户管理的表格做一系列功能。

把 links 传给 VerticalNavigation 组件，看一下最终结果：界面出现了，左侧导航和右侧内容都有了。点击用户管理，会跳转到对应路由，显示 users index page，这是之前创建过的路由，所以能成功显示。
