上节课完成了 controller 的初步学习。controller 主要涉及 HTTP request 和 HTTP response 两部分内容：请求部分能获取多种用户输入的参数，响应部分能返回对应的内容以及设置一些 response 的信息。

在进行下一步之前，我们面临一个问题：HTTP 请求中有多种 method，对一些特定的 method，我们要模拟用户发送复杂的数据，比如 body 当中的 JSON 数据，所以需要一款趁手的工具来进行模拟。而且后面我们的应用作为一个 RESTful API 的后端应用，也需要一款好用的工具做测试和 API 的分类管理。

之前使用的是 curl 这款工具，虽然简单，但参数实在太多，看起来眼花缭乱。图形化界面无疑更方便好用。所以隆重推出一款家喻户晓的工具：Postman。在这里可以进行下载，最好任何软件都在官方网站下载，网址是 postman.com/downloads。特别注意，新版 Postman 已经不仅仅是一个基于 Chrome 的插件，而是一个独立的应用，强烈建议大家下载新版。我两个都安装了，可以看一下异同：旧版是圆形图标，是浏览器插件；新版是方形图标，flat design，看到图标你就知道下载了新版。

下载完毕后点击打开。第一次打开有注册和登录的功能，可以直接点 Skip and go to the app 跳过使用。我建议大家注册一个免费的账户，Create Free Account 完全免费，而且可以自动云同步你的所有请求和分类的记录，非常方便。顺便提一句，Postman 已经完全不是当年那个简单的 Chrome 插件了，它现在是一个估值五十六亿美元的大的 API 云服务公司。一个小工具做到极致，说明它也能有巨大的潜力。

用之前的账号登录后，会来到这样的界面。我这里已经创建了两个 collection，里面有一系列已经创建好的请求，都云同步到这里。这时新建一个 collection 作为测试：在 collection 处点击加号，称之为 test。collection 其实就是分组功能。然后点 add request，第一个 request 先测试一个 get 请求。特别注意：method 选择 GET，URL 是 test，id 可以设置成 2。点击 send，就能返回对应的数据了。query 也可以很方便地添加：在 Params 里添加 name 等于 Viking，它最终会按格式添加到 URL 上面，发送后 query 也能拿到。get 还是很简单的。

现在添加第二个请求，也就是 POST。add request，称为 test post，method 设置成 POST，URL 复制过来，test 后面带 id 2。要输入数据：第一种方法使用 JSON 格式的 body，需要添加一个 header。它有一些默认 header，none hidden 可以不用管，我们添加之前说的 content-type，有自动联想，选择 application/json。添加完 header，在 body 中添加数据：切到 body 标签，有不同的格式，这里选择 raw 原始格式，右边可以切换成 JSON 的高亮显示方式。添加 name 等于 Viking、color 等于 blue，body 就有了。点击 send 看结果：它能把 body 解析出来，name 和 color 都出现了。

POST 发送的数据可以是 JSON 格式，当 content-type 设置成 application/json 等一系列格式时按 JSON 解析；还可以使用 form 格式，这是传统的表单提交形式。我们测试一下表单：先把 header 改变一下，改成 `application/x-www-form-urlencoded`，这是 form 的一种编码格式；body 中也要改变，不能使用 raw 了，要使用对应的 form 表单形式，同样填 name 等于 viking、color 等于 red。修改完毕后点击 send，它同样能发送并解析成功：name viking、color red。这两种格式的 POST 数据都测试了，Egg.js 会对它们做特殊处理，把数据转换成我们看到的 object 形式。

还有一个很好用的功能：在侧边栏点击第三个图标，叫 Code。点开后它可以自动创建代码片段，比如之前说的很长的 curl 命令，它可以根据当前请求自动生成。比如 Form 格式的请求，可以看到 Content-Type 设置成了对应的格式，`--data-urlencode` 按 form 表单的形式添加数据，和发送 JSON 是不一样的。这里还可以切换成各种不同的工具，非常多，比如你想用 Axios，切换过去直接把这段代码拷进去就能使用，非常方便。

这节课我们简单学习了 Postman 的下载、注册以及使用，之后会将它作为 HTTP 请求的主要调试和存档工具。
