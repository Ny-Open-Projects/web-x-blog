## 第一步：样式系统改为绝对定位

第一步是改变现有的样式系统，让元素按照 `position: absolute` 的形式展示到界面上。我已将其他元素删除，只留一个测试元素，并添加了一系列定位相关的属性，都是已有的属性：width、height、left、top，还有 position absolute。现在画布上已经能渲染出成功定位的元素，就是那个灰色的框。

但有个问题：外层的 EditWrapper 是处理事件的主力，元素被它包裹着。现在鼠标悬浮上去时，EditWrapper 完全错位，坍缩到了上面（上面那条灰色线就是它）。

元素是在 slot 里面渲染的，而事件要添加到 EditWrapper 这个 tag 上。怎样解决？

想法很简单：把传入内部的 style 拿出一部分渲染到 EditWrapper 上，把定位、高度、宽度这些相同的属性放到外层，问题就迎刃而解了。

## 把定位样式提升到 EditWrapper

首先把组件属性传进来：添加一个参数 `props`，传递的是 ComponentProps，type 是 object。添加完毕后，只需要将定位以及宽度、高度、left、top 的信息拿出来附上去。使用 lodash 的 `pick`（之前用过，选取一系列的值），创建一个 computed：

```ts
const styles = computed(() =>
  pick(props.props, ['position', 'top', 'left', 'width', 'height'])
)
```

拿这五个关于定位的值就够了。然后把 styles 返回出去，放到 EditWrapper 上：`:style="styles"`。

看效果：EditWrapper 已经渲染到正确的位置了，但组件本身上面还有 top 和 left 值，出现了二次偏离。既然组件的定位交给外侧的 EditWrapper 处理，内部就暂时禁止定位：编辑器画布区域内部的组件不使用 position absolute，直接使用 static，这样就不会二次偏离。加一个样式：写一个针对内部组件的选择器（建议给内部组件加一个特殊的 class，这里直接写 `*` 简化演示），设置 `position: static !important`。

现在看结果：行为完成了，样式没问题，Wrapper 和里面的元素完美重合。

## 计算偏移量

开始计算的第一步：偏移量。回顾图示：偏移量就是紫色的那部分，鼠标位置减去元素位置。鼠标的 x、y 通过 `e.clientX`、`e.clientY` 拿到；元素的值需要拿到外侧的 wrapper，也就是 EditWrapper。

因为要和 DOM 打交道，创建一个 ref：`editWrapper: Ref<HTMLElement | null>`，初始为 null，把 editWrapper 返回出去，在模板上给它赋 ref。这样就能拿到对应的 DOM 节点了。

第一个要监控的事件是 mousedown（鼠标按下去的时候）。创建对应的回调，叫 `startMove`，参数是 MouseEvent。内部首先拿到 `currentElement`，也就是 `editWrapper.value`。

然后创建一个对象保存偏移量，称为 `gap`，有两个值：x 轴偏移量和 y 轴偏移量。计算方式是减法：

```ts
const gap = { x: 0, y: 0 }
if (currentElement) {
  gap.x = e.clientX - currentElement.getBoundingClientRect().left
  gap.y = e.clientY - currentElement.getBoundingClientRect().top
}
```

获取元素偏移量用的是 DOM 节点上的 `getBoundingClientRect` 方法。这个方法返回的值非常丰富：拿到一个 DOM 节点调用它，就能得到一系列关于尺寸和定位的值，这里需要 left 和 top。

可以写得更简单一些：只调用一次，把 left、top 解构出来：

```ts
const { left, top } = currentElement.getBoundingClientRect()
gap.x = e.clientX - left
gap.y = e.clientY - top
```

## 验证

console 一下看看能否成功拿到值：把 startMove 返回出去，添加到模板上，在 mousedown 的时候调用 `startMove`。切换到 console，随便点击一下，可以看到 x 和 y 轴的偏移量都算出来了。试几次：y 是 7、x 是 74.5，数值应该正确。

这样就完成了移动时最重要的数值，偏移量的计算。有了这个值，就可以在移动的时候算出新的坐标值了。下节课搞定移动。
