欢迎来到新一周的学习。上一周完成了前后端结合的一系列知识，这一周来完成应用剩余的工作。

整个应用的大体结构都已经搭好，剩下的页面里有大量重复工作：创建不同的 action、发送请求、处理各自的 mutation、处理数据，再把数据以各种样式展示到界面上。这种高度重复的需求我不会带着大家一一编码，而是从中间挑一些比较独特、工作中少见的需求来完成，扩展知识面的广度，顺便学习几个工具的原理。本周难度中等，以实用性为主。尤其是几个工具在使用过程中有不少奇特的坑，我会带着大家一起走一遍，前端这个舞台上，面对不同兼容性的浏览器和系统，踩坑之旅非常常见，也必不可少。

## 本周要完成的功能

**发布作品。** 上周完成了编辑器的保存，还剩一个重要功能：发布。对作品点击发布，它会发一系列请求：第一步对编辑区域截图，生成封面图并重新上传文件；接着保存作品、创建渠道。渠道是一系列 URL，同一作品生成多个 URL 可适用于不同场景。渠道在发布成功页管理，可以创建和删除渠道。发布流程会用一个钩子函数整合，上周有 useSaveWork，这次是 usePublishWork，步骤更多也更复杂；有了它，在任何想发布作品的地方都能直接重用这段逻辑。

**二维码与复制。** 把渠道链接生成二维码，也就是将 URL 转成二维码图。另一个功能是拷贝文本到剪贴板：点击复制按钮就能把字符串复制成功。

**钩子函数的进化。** 我们会完成几个相似的功能，体现一个钩子函数的进化过程：首页的加载更多用它，作品页的翻页也可以用它，从点击加载更多，到支持无限滚动，再到支持分页。通过这个过程继续体会 Composition API 的妙用，做到数据和界面分离：有了数据，就能演化出多种界面实现。

**下载文件。** 学习前端下载文件的原理并有具体的编码过程：先做最简单的同域文件下载，再学跨域文件下载，最后用 FileSaver.js 分析它的源码和实现原理，会发现和前两种方法异曲同工。

## 功能点与工具

功能点与工具一一对应：截图需要大名鼎鼎的 html2canvas，学习基本用法，同时看看它的踩坑之旅，这个工具 issue 很多，那些坑是我长期使用后总结出来的；生成二维码用使用人数非常多的 QRCode；复制文本到剪贴板先用第三方库 clipboard.js，分析它的原理，然后自己写一个能完成类似功能的实现。

希望这周的内容能让大家掌握几个特殊第三方工具的使用和原理，以后遇到类似需求能立刻想到它们；更重要的是深入理解钩子函数的意义。功能点就是这么多，闲话不多说，正式进入本周的学习。
