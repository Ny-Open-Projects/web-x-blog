上节课我们熟悉了使用 axios 完成异步上传的过程，这节课就依葫芦画瓢，在 Upload 组件中把最基本的流程添加进去。打开开发进度表，第一步是基本上传流程：点击按钮选择文件就可以完成上传。设计图描述的是同样的过程，点击上传后出现文件选择框，选择文件后显示"正在上传"，成功则显示"上传成功"，失败则显示"上传失败"。

这里有两种开发模式可选：TDD，或者先开发再写测试。我选择先开发再写测试，因为这节课的测试有一些难度，先写测试可能出现一系列问题。

## 用 button 触发隐藏的 input

第一个小问题：设计稿上的入口是一个 button，但我们使用的是 `input type="file"`，怎么把 input 换成 button 呢？不必把 input 做得和 button 一模一样，可以拐个弯想：把 file input 隐藏掉，在点击想处理上传的元素（比如 button）时，用 JS 给 file input 的 DOM 触发一次点击，就可以实现相同的效果。

我已创建了 Uploader.vue 的基础文件。首先添加一个 button，文案"点击上传"；下面是一个 `input type="file"`，由于属性比较多单独换行；再给它加 `style="display: none"` 让它不可见。

接下来要在点击 button 时触发 input 的 click。要拿到 input 的 DOM 节点，自然要创建一个 ref。在 setup 中创建 fileInput，它的类型是联合类型：一开始是 null，之后是 HTMLInputElement，初始值为 null。再写一个 triggerUpload 函数：判断 fileInput 存在，就调用它的 click 方法。把 fileInput 和 triggerUpload 都 return 出去，模板上给 input 加 `ref="fileInput"`，给 button 绑定 click 事件到 triggerUpload。

把组件添加到首页试一下：页面上看不到 input（已被隐藏），点击上传后触发了隐藏 input 的 click 事件，打开了文件选择框。第一个小问题完成。

## 上传状态

接下来添加 props：目前只有一个 action，即发送 post 请求的地址，type 是 string，required 为 true。

然后是经典的上传过程，有一点小区别：因为要显示不同状态（点击上传、正在上传、上传成功、上传失败），需要一个响应式对象在不同阶段修改值。这里有四个特殊的值，很自然想到用字符串字面量。定义 `type UploadStatus`，包含四个状态：ready（准备好上传）、loading（正在上传）、success（上传成功）、error（上传失败），正好对应四个文本。

创建响应式对象 fileStatus，类型是 Ref<UploadStatus>，初始值 ready，同样 return 出去。接着把上节课的逻辑复制过来：handleFileChange 中把 post 的地址替换成 props.action，并在各阶段修改状态，发送请求前把 fileStatus.value 改成 loading；成功回调里改成 success；catch 出错时改成 error。

响应式对象的值变化后，界面上就可以按状态显示不同内容了：用 v-if 和 v-else 分别判断 loading、success、error 等状态，展示对应的文本。最后在 input 的 change 事件上绑定 handleFileChange（记得把它 return 出去）。

## 验证

整个逻辑写通后在实际页面验证：点击上传，选择 component-props 图片，界面先显示"正在上传"，随后变成"上传成功"。流程成功。

上传组件的第一步完成了。虽然还没有好看的界面，但文件已经可以成功上传，最基本的流程跑通了。下节课我们先给这个简单流程编写测试，这样在添加更多功能时，测试可以保证新功能不会影响之前的功能。
