上节课成功生成了 Nuxt 的基础模板，了解了文件结构，选好了编辑器和插件。从这节课正式进入编码过程，先讲 Nuxt 基础知识，过程中会配合最终的管理系统项目进行：通过基础知识的学习慢慢构建最终成品。

开始前要认识 Nuxt 3 的一个重要特性 Auto Imports（自动导入）。只要在特定文件夹中放了对应的文件，Nuxt 会自动把它们导入到项目中，省去手动导入的麻烦，也不用再担心代码冗长繁琐的导入问题。

自动导入包括三部分。第一是 Vue.js 的 API：比如使用 ref 不需要导入就可以直接使用，也不会报错。第二是三个文件夹中的所有内容：components（组件）、composables（就是之前说的 hooks 函数，使用了 Vue 3 响应式特性的一系列函数，换了个名称叫 composables）、utils（utilities，项目中杂七杂八的功能函数）。之后会重点演示前两个文件夹。第三是 Nuxt 内置的全局函数，比如 useFetch，不需要导入就可以直接使用，这些全局函数会随着课程深入一点点讲解。

先介绍 components 文件夹，组件都放在这里，使用时直接调用即可。我们创建一个组件并使用，展示自动导入功能。注意文件夹拼写一定是 components，Nuxt 是规则非常明晰的框架，不要写错。创建一个 HelloWorld 组件：

```vue
<template>
  <h1>{{ message }} {{ counter }}</h1>
  <button @click="counter++">increase</button>
</template>

<script setup lang="ts">
const counter = ref(0)
defineProps<{ message: string }>()
</script>
```

定义 counter 时直接使用 ref，不会报错，稍后验证它能正确工作。再 define 一个 props，只有一个 message 属性，string 类型。两者都输出到 h1 上，再加一个 button，点击时 counter 自增。

在 app.vue 入口文件中，去掉内置的 NuxtWelcome，直接改成 HelloWorld（有自动提示），并传入 message 属性值 Yuki。可以看到信息显示出来了，两个自动导入的特性都成功了，点击按钮交互也完全可以运作。

另一个自动导入的特性是 composables。演示一下：创建之前写过的 useKeyPress，在点击特定按键时触发事件：

```ts
export default (key: string, cb: () => void) => {
  const trigger = (event: KeyboardEvent) => {
    if (event.key === key) cb()
  }
  onMounted(() => document.addEventListener('keydown', trigger))
  onUnmounted(() => document.removeEventListener('keydown', trigger))
}
```

key 是 string，还有一个 callback 表示点击这个 key 时要做什么处理。用 onMounted 和 onUnmounted 添加和卸载事件（它们是 Vue 的 API，自动导入）。trigger 是一个 handler，event 是 KeyboardEvent：如果触发的 key 等于传入的 key，就执行 cb。注意要导出，export default 之后才能使用。

现在在 HelloWorld 中直接使用 useKeyPress。按说 composables 里的内容在任何地方都可以直接使用，但如果是第一次新建这个文件夹，会发现它不能直接使用，也没有自动补全，直接用会报错。原因在于：Nuxt 会监控文件系统并自动生成全局类型，位置在项目下的 .nuxt 文件夹，其中有一个 imports.d.ts，这就是魔法发生的地方，它把这些对应的定义都做了处理。但全新新建的文件夹还没进入监控范围，所以需要重启开发服务器。重启后就纳入监控系统了，之后一劳永逸，文件夹中添加多少文件都会自动生成定义，其他特殊文件夹同理。

重启后再打开 imports.d.ts，可以看到 useKeyPress 已经纳入其中。此时再使用就不会报错了。我们希望按下键盘 J 时自动增加 counter：`useKeyPress('j', () => counter.value++)`，保存后点击键盘上的 J，数值就会加一，功能实现。

这节课介绍了 Nuxt 中很重要的自动导入功能，以及两个重要文件夹：components 放置各种组件，composables 放置通用的 hooks 函数，它们都可以享受自动导入；此外 Vue.js 的 API 同样可以自动导入。
