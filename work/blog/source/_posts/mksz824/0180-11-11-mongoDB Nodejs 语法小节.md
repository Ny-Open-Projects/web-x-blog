前面的内容学了 MongoDB Node.js Driver 增删改查的一系列操作。这部分不算难，但细碎知识点非常多，非常容易遗忘，可能学到现在之前的知识点就忘得差不多了。针对这类内容，需要每到一个特定的小节或知识点节点，就用自己的手段做知识总结，对抗天生的遗忘曲线。我推荐用思维导图来记录，能很好地分类和汇总知识。我花了半个小时画好这张图，也是为了自己以后复习方便。一个好的技术思维导图，能帮你随时随地拿起来就快速复习或定位知识。

对技术思维导图，我建议大家必须包含两点，能明显提高效率。一是文档地址：在部分条目右边加上文档链接，点击就能快速跳转过去。文字写法再简洁也可能没涵盖所有知识点，有链接就能迅速到文档里查。二是简单的代码示例：代码比文字更有说服力，能让你更快理解知识。比如我查询那里加了一个简单的代码示例，一看就知道条件怎么写、是什么规范，比文字强得多。学完知识后，不妨用思维导图归类总结，这是个通用的建议。

回到知识本身，按增删改查的顺序过一遍。

先说插入，最简单，两个方法：insertOne 接受一个参数，就是你想插入的 document，填进去即可；insertMany 接受数组，可以放多个文档。

然后是查询，比较复杂，因为有各种条件，还要对结果做过滤、返回特定数据或格式。方法上，find 返回多条结果，findOne 是它的简化版本。主要用 find 讲解。特别注意 find 返回的不是直接的数组，而是 cursor 指针对象，需要用它的方法，比如 forEach 或 toArray，转换成可操作、可展示的对象。find 有两个参数：一个叫 query，查询条件；一个叫 FindOptions，用 options 做结果过滤。

查询条件的基本格式：可以直接查属性对应的值，比如 name 等于什么；也可以用 MongoDB 内置的 operator 过滤。学过的几类：比较操作符比大小，greater than、less than；逻辑操作符用 $or、$and 把几个条件结合；元素操作符 $exists 看属性是否存在，$type 看它是什么类型。把这几类操作符组合起来，就能构造出复杂的数据结构作为条件。

有了结果还需要对结果操作，有这些结果选项：limit 规定返回多少条；skip 跳过前面多少条，limit 加 skip 可以很好完成分页；sort 排序，正序或倒序；projection 投影，决定保留哪些字段，保留写 1，不保留写 0。查询条件加结果过滤，正好组合成 find 的两个参数。

还有查询数组的特别方式，因为数组是比较特殊的数据格式。介绍两个：一是部分匹配，想查数组中是否有哪几项，用 $all 操作符，比如查 hobbies 中是否包含 a 和 b 两项；二是查询单个元素，看数组中是否有这么一个元素，直接写成字符串即可，不需要数组类型。查询数组查到后还有一个占位符的操作，下面说更新时讲。

查询说完说更新。更新是查询的变种：先查到特定记录，再对其中的部分进行替换，比查询多一个操作，自然也多一个参数。第一个参数是 filter（有的地方叫 query，一个意思），第二个参数是要替换的部分文档。更新介绍了两个方法：replaceOne 全部替换，一般不是我们想要的；updateOne 是重点的部分替换。部分替换就有更新操作符。格式和查询那边差不多：update operator 写在最前面，后面是操作的 key 和值，比如把 name 设置成 new name。介绍过几个：$set 最基本，设置为新值；$inc 自增或自减，数字类型；$rename 重命名；$unset 删除这个键等等。

和查询数组相对，数组更新也有一系列操作，因为数组是比较复杂的数据结构。内置操作符：$push 添加特定项，格式同样先写 $push 再写键 hobbies 和要加的项；$pop 删除第一项或最后一项。修改数组特定一项有两种方式：一是用下标，比如第一项就是 0；二是用占位符 $，代表查询到的结果的下标，可以把它理解成 $ 就是一个查询到的下标（0、1、2 这样），然后进行修改，和按下标更新本质一样。

最后说更新操作符更上面一层的 update operator modifiers：$each 可以一次插入多项，因为 $push 只能插单独一项，用 $each 后配合数组格式一次插多项；$position 可以在特定位置插入。还有更多 modifier，这里只介绍这两项。

最后是删除，非常简单：deleteOne 和 deleteMany。deleteOne 也接受一个 filter 参数，就是查询条件，已经说过多次了。这里不给代码示例了，大家自己去文档中学习，很快就能掌握。
