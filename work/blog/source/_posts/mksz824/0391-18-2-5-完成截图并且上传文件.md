上节完成了截图过程，这节完成截取图片并上传。目前拿到的是一个 HTML canvas 元素，可以用在 Cropper.js 那里学到的知识：用 toBlob 把 canvas 转换成 Blob 类型的文件再上传。整体流程三步：截图 → 转换成 Blob → 用 Blob 完成上传，是三个异步操作，所以在 helper.ts 中创建一个 async 函数来统一完成，命名为 takeScreenshotAndUpload，名字长一点没关系，一眼就知道它干什么。它接受一个参数：要截取哪一部分的内容（HTMLElement）。

## 第一步：获取 canvas

函数内第一步是获取 canvas 元素：`return await html2canvas(ele, { width: 375, useCORS: true, scale: 1 })`，width 375 是中间区域的宽度，useCORS true 处理跨域图片，scale 调成 1，参数都是之前调试好的。

## 第二步：canvas 转 Blob

toBlob 是回调式的 API，希望统一用 Promise 风格，所以再写一个辅助函数 getCanvasBlob：接受 HTMLCanvasElement，返回一个 Promise，构造时用 `canvas.toBlob((blob) => resolve(blob))`，把回调转成 Promise。

有个类型问题：由于 blob 在回调里，无法类型推论，返回的是 Promise\<unknown\>。所以显式给 Promise 加泛型，类型和 toBlob 的数据类型保持一致，`Blob | null`：

```ts
function getCanvasBlob(canvas: HTMLCanvasElement): Promise<Blob | null> {
  return new Promise((resolve) => {
    canvas.toBlob((blob) => resolve(blob))
  })
}
```

第二步就是 `const canvasBlob = await getCanvasBlob(canvas)`，类型是 Blob 或 null，所以先判断存在再做下一步。

## 第三步：提取公共上传方法

上传文件这个逻辑在多处都出现过，上传组件、image-processor 里都有，每次都写一遍太繁琐，应该提取成公共方法。添加一个 async 函数 uploadFile，两个参数：

- 第一个是要上传的文件。注意这里要定义成 **Blob 类型而不是 File**，因为 Blob 是 File 的父类，上传的可能是 File 也可能是 Blob；
- 第二个是上传到哪，即 URL，加一个默认值，采用现有后端接口 `utilities/upload-image`。

函数第一步先创建 File：如果 `file instanceof File` 直接返回；否则用 File 构造函数把 Blob 包进去，`new File([blob], fileName)`。因为 Blob 没有 name，所以要加一个 fileName 参数，默认值 `screenshot.png`。看一下类型定义就能理解它们的关系：`interface File extends Blob`，File 只比 Blob 多 lastModified 和 name 两个属性。

接着是大家都很熟的上传流程：新建 FormData，`formData.append('file', newFile)`（file 有 name 属性可作第一个参数），然后 `await axios.post(url, formData, { headers: { 'Content-Type': 'multipart/form-data' } })`。

这里还有个类型细节：返回的 data 是 any，希望有确定的类型。axios 的 post 接受两个泛型，第二个泛型就是 AxiosResponse 包裹的 T，把外部传入的泛型 R 传给它，data 就是 R 类型了。

上传后的数据结构是 errno 加 data，data 里是 urls，一个数组，一般只有一项，就是上传成功的图片地址。在 responseTypes 里定义 `interface UploadData { urls: string[] }` 和 `export type ResponseUploadData = ResponseData<UploadData>`，从 `../store/responseType` 导入。第三步就是 `const data = (await uploadFile<Blob, ResponseUploadData>(canvasBlob)).data`，类型完美匹配，返回 data 即可。

## 验证

在 editorView 中导入 takeScreenshotAndUpload 并调用，传入 el。response 的类型是 undefined 或 ResponseUploadData，先 type guard 判断存在再打印 `response.data.urls`。点击发布，Network 里 upload-image 请求返回了一个 URL，复制打开，图片已经完美上传到 OSS，显示也没问题。

截图成功上传并返回可访问的 OSS 地址，下一步就可以完成发布大计了。这节把多个异步操作抽象进一个函数，还多次用到了泛型。
