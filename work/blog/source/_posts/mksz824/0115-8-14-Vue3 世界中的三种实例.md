上节课我们遇到了 vm 这个实例，现在有了比较多的 Vue3 基础知识，可以把 Vue3 中的实例种类做一个归纳总结了。先从文档看起，Vue2 的部分非常简单：每个 Vue 应用都是通过 Vue 函数创建一个新的实例，也就是 new Vue。创建时它会将 data 作为 property 添加到响应式系统中，在 vm 中获得实例上的 property，设置它也会影响到原始数据，就是这么简单。

到了 Vue3 就不一样了，一共有三种实例。

## Application Instance 应用实例

第一种是 application instance，应用实例，使用 createApp 创建。在我们的代码应用中，整个 app 就是 createApp 创建出来的应用实例。把它 console.log 出来，可以看到它上面混合了非常多的属性和方法，具体每个的用途不细说，我们用到过 mount 和 use，大家可以自己研究。它的大多数方法都支持链式调用，返回应用实例本身。比如 use 方法用来注册全局插件，返回的就是实例本身。

大家可以想想从 Vue2 到 Vue3 为什么要有这样的修改，migration guide 里讲了原因，可以到文档中寻找答案。

## Component Instance 组件实例

第二种是 component instance，组件实例。刚才说 use 这类方法返回的都是应用实例本身，但有例外：mount 方法把应用实例挂载到 DOM 节点中，参数是 DOM 节点的 selector，它返回的不是应用实例，而是组件实例，可以从这里拿到组件实例中的一系列内容。

除了这些，还有一些内置或全局属性，比如 attrs 和 refs（用过 Vue2 的应该很熟悉），以及全局注册的属性，比如 Ant Design Vue 注册到全局的 confirm、message 等方法。所以组件实例由三方面组成：组件返回的属性、内置属性、全局属性。

除了这两种，还有一种特殊的实例，称为 internal component instance，内部组件实例。它是组件自身的代码中获取自身实例的一种方法。它和刚才说的组件实例是一种吗？通过代码来看。

另一个有意思的部分是最上面的 appContext，点开也有一堆属性，和最早的应用实例（appInstance）上面的下划线 context 属性点开后完全一致、一一对应。appContext 一看就是一个可以在全局共享的状态，组件内拿到它，就可以使用全局注册的内容做一些操作和处理。

## 小结

现在搞清楚了 Vue3 中的三种实例：最大的 application instance 应用实例，其下是 component instance 组件实例，最后是 internal component instance 组件内部实例。还有一个问题是它们之间怎样传递数据，下节课我们来做这方面的总结。这节课到这里，谢谢大家。
