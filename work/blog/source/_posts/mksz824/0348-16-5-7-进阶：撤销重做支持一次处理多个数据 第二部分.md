上节课改了 `updateComponent` 的形式，让它一次保存多个键值的数据。接下来要在 undo 和 redo 的 modify 分支里完成对应的批量回滚。这里要加上判断 key 是否为数组的逻辑，比原来稍复杂。

而且我们发现这段逻辑在 undo 和 redo 两处高度相似，自然要抽成一个公共函数。

## 设计 modifyHistory 函数

这个函数需要三个参数：

1. `state`（EditorProps），拿到要更新的元素；
2. `history`（HistoryProps），拿 componentId 和 data，知道改哪个值；
3. `type`，是 undo 还是 redo，字符串字面量类型两种取值。

在 editor.ts 里添加：

```ts
function modifyHistory(
  state: EditorProps,
  history: HistoryProps,
  type: 'undo' | 'redo',
) {
  const { componentId, data } = history
  const { key, oldValue, newValue } = data
  ...
}
```

先从 history 中取 `componentId` 和 `data`，再从 data 里取 `key`、`oldValue`、`newValue` 三组值。data 是 any 类型（有多种数据形态）没有自动补全，所以手动写出来。key 是 any，暂时断言成联合类型，命名为 `newKey`：

```ts
const newKey = key as keyof AllComponentProps | (keyof AllComponentProps)[]
```

既可能是单个 string 类型的 key，也可能是这种类型的数组。

## 函数主体

第一步找到要更新的组件，`find` 已经写过很多遍，拿到后判断存在再继续。然后判断 newKey 是否为数组（check if key is array）：

**数组分支**：用 `forEach` 循环赋值，第一参数叫 `keyName`，第二个是 `index`，两者都能获得正确的类型。赋值时按 type 区分：

```ts
newKey.forEach((keyName, index) => {
  updatedComponent.props[keyName] =
    type === 'undo' ? oldValue[index] : newValue[index]
})
```

undo 恢复旧值，redo 推进到新值，都用对应的 index。

**单值分支**：逻辑更简单，不用循环，直接把上面的赋值复制过来，去掉 index：

```ts
updatedComponent.props[newKey] =
  type === 'undo' ? oldValue : newValue
```

## 替换两处 mutation

有了这个函数，undo 和 redo 里原来那一长串 modify 处理就可以删掉了，各替换成一行：

```ts
modifyHistory(state, history, 'undo')
```

redo 处同样调用，type 传 `'redo'`。

## 验证与收尾

到界面上验证：把元素放大到出现两条记录（位置一条、大小一条），点击撤销，先回到原始大小，再点击回到原始位置；再点重做，第一步回到新位置，第二步恢复新大小。两种情况都正确，第一个优化点就实现了。

课下可以把测试用例丰富一下，覆盖两个新情况：一是 `updateComponent` 传入多个 key-value 的场景，二是 undo 和 redo 各自的批量形式。至于实现过程，看代码其实没什么难度，我们主要做的就是数据结构的改变，原来只能存普通 string，现在可以存数组保存多个值，并一次恢复多个值。
