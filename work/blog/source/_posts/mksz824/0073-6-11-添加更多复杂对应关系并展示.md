上节课介绍了几个简单的对应关系，这节课接触几个更复杂的组件。图上面是上节课完成的，下面有两个新属性。第一个比如 fontFamily，需要一个 a-select，也就是一个下拉菜单；另一个比如 text-align，需要一个 a-radio-group，渲染出几个不同的选项。它们的目的都是从限定的几个值中选出其中一个。这个需求不困难，要点在于渲染这些属性不仅需要一个组件，而是需要几个组件的组合。

看文档：比如刚才说的 a-radio-group，除了组件本身，我们还需要渲染一系列子组件，并使用它们的特性。自然而然想到要扩充现在的 PropToForm 属性，让它可以容纳更多内容。来添加：除了现有的 component，还需要包裹它的另外一个组件，称之为 subComponent，可选，也是 string 类型。除了 subComponent，一般还要循环渲染它包裹的选项，可以称之为 options，因为要渲染一系列选项。自然想到一个类似数组的结构。一般这种选项都有显示的文字和选中后真正的值：value 是选择以后的值，text 是它展示出来的文字。所以需要两个属性：一个叫 text，是 string；另一个也称之为 value，是 any。options 本身是可选的。这样 PropToForm 上的属性就定义完了。

接着多添加几个选项。第一个是 text-align，直接复制过来，给它添加一系列属性：主 component 是 a-radio-group，subComponent 是 a-radio-button，text、options 等都跟上面一样。

有了这个，需要对 PropsTable 做修改，让它多渲染一些内容。把原来的展示删掉，加在它的 slot 当中。先判断 value.options 是否存在，存在再渲染。这里可以使用 Vue3 新推出的 fragment，也就是空节点：template 标签。在上面添加 v-if 判断 options 是否存在，即 value.options。假如存在，跟上面的逻辑一样，循环渲染它的 subComponent：is 是 value.subComponent，当然要加 v-for 循环 option，加一个索引 k 作为 key，value 自然不可少，是 option.value，最后在里面放文本 option.text。这样就增加完了。注意它对应的就是数据结构，最后渲染出来的就是这样的结构。

看一下现在的选项。特别注意，我在 editor.ts 的测试数据里添加了一系列数据，包括 text-align 和之后要测试的 fontFamily。点击第一个，对齐的选项完全出现了，很方便。

再添加另一个：fontFamily 跟 text-align 已经非常相似了，只需要把它添加到 propsMap 中。直接复制，不同的是它的主 component 是 a-select，subComponent 是 a-select-option。它的 options 有这些，注意 text 和 value 不一样：value 是真正要作用到后面 CSS 上的值。保存后看页面，它已经出现了，字体在这里，可以点击选择。另一个维度的组件对应关系就实现了。

现在修正一个 bug。虽然组件的渲染和显示都正常，但打开控制台可以看到一个错误。这个错误说的是 a-slider 传入的 value 和它需要的值有差距：它希望是 number，但我们传入的是字符串。所以有时在传入属性之前要做一定的转换，才能适配对应组件需要的 value 值。这是非常常见的需求，因为很多组件需要的 value 和我们提供的值有差距，要做到统一化，就要提供一个方法进行转换。

还是可以在 PropToForm 上添加。添加一个叫 initalTransform 的函数，代表初始时的转换。特别注意它是函数，也是可选的。传入的值是 any 类型（可能有很多种），返回自然也是 any，这两处确实都是不确定的。刚才问题出现在 lineHeight，给它添加对应的 initalTransform：传入的值肯定是 string，用 parseFloat 转换一下就完成了。

除了定义转换，还要在 PropsTable 里调用它。来到 PropsTable，现在要判断 item.initalTransform 假如存在，就转换一下：`item.initalTransform(value)` 把 value 包裹；假如不存在，就用原始的值。看一下错误是否还在：清空控制台，点击第一个，错误已经不存在了，转换成功。

还有一个问题：字号虽然没有报错，但注意我们传入的是 "12px" 这样的字符串，而 a-input-number 需要的 value 其实是 number 类型。有可能组件内部做了转换，但我们最好还是将字符串转换成数字。来到 propsMap 的字号这里，一样添加 initalTransform，传入 string，用 parseInt 转换一下 v。这样就完成了转换，整个实现比较完美了。
