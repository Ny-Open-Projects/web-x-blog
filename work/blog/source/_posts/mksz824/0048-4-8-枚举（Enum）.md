枚举（Enum）对前端工程师来说是个全新概念，但很好理解。任何项目里都会遇到常量，也就是程序运行中不会被改变的值，JS 里通常用 const 声明。但有些取值是一定范围内的一系列常量，比如一周的七天、三原色、上下左右四个方位，这些就适合用枚举表示。

## 数字枚举

用 enum 关键字定义一个方向枚举：

```typescript
enum Direction {
  Up,
  Down,
  Left,
  Right,
}
```

枚举成员会被赋值从 0 开始自动递增的数字：Up 是 0，Down 是 1。取值用 `console.log(Direction.Up)`，用 ts-node 运行后输出 0。

枚举还有一个神奇之处：反向映射。可以把枚举看成数组，`Direction[0]` 会返回 'Up' 这个字符串，就像一个双向映射。

枚举成员也可以手动赋值，未手动赋值的枚举项会接着上一个值递增：

```typescript
enum Direction {
  Up = 10,
  Down, // 11
  Left, // 12
  Right, // 13
}
```

看看编译后的代码，就能明白反向映射是怎么实现的。`tsc enums.ts` 之后可以看到一个自执行函数，里面封装了独立的作用域。关键的一行是 `Direction["Up"] = 0`，由于 JavaScript 的赋值运算符返回被赋予的值，所以接下来会执行 `Direction[0] = "Up"`，这样双向赋值就完成了。

## 字符串枚举

字符串枚举就是给每一项都指定字符串值，这样更容易处理和调试，因为它们提供的是有意义、可调试的字符串：

```typescript
enum Direction {
  Up = 'up',
  Down = 'down',
  Left = 'left',
  Right = 'right',
}
```

注意一旦某项加了字符串值，后面的项都必须是字符串。它的典型用途是简单的字符串比较：服务器返回一个值，取值可能是 up、down、left、right，我们就可以拿它和枚举比较，执行不同逻辑：

```typescript
const value = 'up';
if (value === Direction.Up) {
  console.log('go up');
}
```

编译运行后输出 go up。

## 常量枚举

最后讲一个提升性能的技巧：常量枚举。在 enum 前面加一个 const 关键字，编译后再打开产物文件会发现逻辑少了许多：调用 `Direction.Up` 的地方被直接内联成了字符串 'up'，不会生成任何对应的 JavaScript 对象代码。

但不是所有枚举都能用常量枚举。枚举成员的值分两种：常量值（constant number）和计算值（computed number），只有常量值可以用于常量枚举。本节课的例子都是常量值，计算值以后遇到再慢慢分析。

## 小结

这节课介绍了枚举的概念和基本用法：数字枚举、字符串枚举和常量枚举。
