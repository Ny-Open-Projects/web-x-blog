欢迎来到新一周的学习。上一周我们完成了编辑器的一系列交互，交互功能已经大大提升。这一周要正式和后端打交道：把应用的数据持久化地保存在数据库中，并针对 SPA 项目前后端分离开发的一些通用难点和痛点进行攻坚。

上一阶段大家跟随后端老师开发出了一系列可用的后端接口，现在把它们接进来。

## 本周功能一览

一开始会讲前后端分离的概念，并分析接口的功能和需求，请求和返回，用 Postman 进行分析。虽然我们已经有写好的后端接口，但这里还要插一句：前端 mock server 是怎样实现的。真实项目中前端和后端分离开发一般是平行进行的，所以前端需要用一个假的 server（mock server）自行实现接口。

mock server 要做得和真的 server 非常相似，会分三点讲：快速搭建；自定义接口和返回数据；使用 JWT 完成路由保护。

有了 mock server 之后，接下来完成登录。登录会使用 Ant Design Vue 提供的 a-form 组件完成表单验证，还要讲一下源代码解析，a-form 实现 validate 的过程比较复杂，这里给大家加餐讲解。之后是应用通用状态的添加：对 SPA 来说，我们会有整个应用的一系列通用状态，比如全局 loading 状态（是否现在有数据正在 loading）、细粒度的 loading 状态（同时发好几个请求时，现在 loading 的是哪个）、以及全局错误状态（network 错误或数据错误时显示）。这几个状态还是很有意思的。

之后实现登录过程以及登录状态的持久化，登录完成以后，下次进入或刷新还能保持登录状态。再往后是路由权限的验证：有一些路由（比如编辑器）必须登录后才能访问，要添加这部分权限验证。最后来到编辑器的作品操作：本周有获取作品和保存作品两个功能。保存作品还能玩出一些花样，最简单的是点击保存；因为编辑器里经常有交互，还要添加自动保存（过一段时间保存一次）；以及未保存就跳转前的提示，比如编辑了作品后直接点返回首页或关闭窗口，会弹出提示让你先保存再跳转。

## 涉及的知识点

- **vuex action**：用来发送异步请求；
- **JSON server**：实现 mock server 的工具，非常简便但强大；
- **Ant Design Vue**：使用 a-form 完成表单验证，它还提供了 useForm hooks 函数，我们会对比两者实现的异同；
- **axios 拦截器（interceptor）**：更高级一点的用法，实现全局通用状态的添加；
- **JSON Web Token（JWT）**：完成登录状态的持久化，保存在哪里、怎样在重新进入时取出来，都是有学问的东西；
- **Vue Router 钩子函数**：路由权限验证要添加 router 的钩子，比如 `beforeEach` 可以直接加在 router 实例上，`beforeRouteLeave` 可以用 Composition API 的形式添加到 setup 中；
- **高阶函数**（重点）：我们会多次用到它。遇到重复的逻辑时，就想到用高阶函数帮我们完成重复的工作。
