这节课简单安装、实验一下 mongoose 的用法，和原生 Node.js 实现做个比较，看看异同。有了前面的内容，理解起来会简单很多。再强调一遍：mongoose 不是一个独立的 MongoDB 实现，它是 ODM，基于之前学的 Node.js MongoDB Driver 建立。

演示连接、查询和创建。先安装 npm install mongoose，这个包自带 types，不用另外安装。创建一个单独的脚本 mongoose.ts，入口函数叫 main，因为内部要用 await，所以是 async function。整体结构还是 try catch 加 finally。

第一步创建连接。从 mongoose 导入 connect，顾名思义就是连接。它是异步的，所以要 await connect()，传入 URL，和之前一样，用 hello 这个数据库。连接成功后 console 一句说明。

mongoose 的数据结构都从一个特殊的 schema 开始：每个 schema 映射 MongoDB 中的一个 collection，并定义这个集合的数据长什么样子。创建第一个 schema 叫 productSchema（我们要创建一系列产品）：new Schema()，在 object 中定义字段和字段类型，比如 name 是 String，price 是 Number。和 Vue 很像，用构造函数进行定义。

有了 schema 就可以创建 model。model 是从 schema 衍生而来的构造函数，用于实例化最终的数据。创建 productModel：使用 mongoose 内置的 model 函数，两个参数，第一个是 model 的名称，叫 product；第二个传入 schema。model 创建完毕，就可以创建数据了。每个实例化的 model 称为一个 document（文档），对应数据库中的一条数据。

第一种创建方式用 model 上的静态方法。特别注意也是异步的。productModel 上有个静态方法 create，就是添加一条数据，和原生 Node.js MongoDB Driver 有区别：那边叫 insertOne，这里是 create；不过 insertMany 对应的 createMany 也是有的，和之前一样。这里调用 create，传入数据：name 是 cell phone，price 是 1300，再 console 一下最终 result 的样子。finally 里加关闭连接的代码，从 mongoose 导入 disconnect 调用即可，然后执行入口函数。

运行 ts-node mongoose.ts，数据创建成功。到数据库里 refresh 一下 collection，发现创建了一个叫 products 的集合，打开后记录插入成功。注意集合名称是 model 名称的变种：model 叫 product，mongoose 会把它变成小写并转换成复数，得到 products。

第二种方式用构造函数实例化创建，非常相似：创建一个 iPad，new ProductModel()，传入对应数据，改一下名称和价格。实例化完毕后调用实例上的 save 方法，完成数据保存。把之前两个都注释掉再运行，iPad 也创建成功了。

之前说过 schema 可以更好地约束集合数据的类型，有助于数据统一性。验证一下：把 price 改成 string 类型再操作，会弹出一串错误，告诉我们 Cast to Number failed for value "hello"，定义的是 number 类型却传入了字符串，无法转换，这就完成了数据验证。再试多余字段：加一个 age，成功后看数据（直接转成 JSON 格式），iPad 4000 是最新添加的数据，但 age 并没有加上去。说明通过 model 的形式完全约束了数据结构的样子和类型，多余的参数不会添加上去，就是通过这种方式约束类型。

最后看怎样把现有的集合映射到 model 上。要借助一个特殊参数。比如我们想查询之前创建的 user 数据，先把上面的都注释掉，新建一个 userSchema：name、age、hobbies，还有 team，它是 ObjectID 类型，从 Schema.Types.ObjectId 提取即可；ref 指另外一个 model 的名称，我们还没有，暂时写在那里，两个表联合查询的功能后面再演示。特别注意要多加一个特殊参数：记得命名规则是 model 名称转小写加复数，已有的 user 集合不符合这个规则，所以创建 model 时要加 {collection: 'user'} 指定集合名称，把两者对应起来。然后新建 userModel：model('User', userSchema, {collection: 'user'})。

接着查询：await userModel.find({age: {$gt: 30}})。查询方式和 MongoDB Node.js driver 完全一样，有 find、findOne，参数也非常类似。写完 query 后要调用 exec 方法返回对应的数据，最后打印。再次强调：想把现有 collection 和 schema 对应，要加 collection 参数指定集合名称。运行后大于 30 的数据都返回了，查询成功。

这就是 mongoose 的基本操作。它和 MongoDB Node.js SDK 非常类似，只不过多了 schema 和 model 的概念，用于约束集合数据结构。更多内容会结合 egg.js 应用之后再讲。下节课的任务是在 egg.js 应用中添加 MongoDB 的实现。
