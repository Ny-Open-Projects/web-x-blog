> 分类：备份恢复 | 难度：L1 | 题型：八股题 | 频率：高 | 关键词：**全量备份** / **增量备份** / **差异备份** / **恢复链**
> 原文锚点：第 34~45 段「增量备份则拷贝上一次备份之后所变化的数据，差异备份拷贝第一次全备之后变化的数据」

## 一句话总述
**全量**=全部数据；**差异**=相对**上一次全量**以来的变化；**增量**=相对**上一次任意备份**以来的变化。越省空间，恢复链越长。

## 面试官视角
- **考察意图**：这是送分题，答错直接暴露没做过备份策略；顺带看有没有想过恢复链风险。
- **P5** 能说清三者定义 / **P6** 能指出各自缺点 / **P7** 会补「增量恢复**必须按顺序逐个应用**，中间断一个就全废」。
- **红旗**：「差异和增量一样」；「增量恢复只要最后一个就行」；「备份越小越好」。
- **惊艳点**：差异备份的**体积随天数递增**（第 N 天 ≈ N 天变化量），增量每天体积相近——这是两者最直观的分水岭（`[经验]`）。

## 主问答
**Q：全量、增量、差异备份有什么区别？你们怎么排备份周期？**
**A：**
1. **先给结论**：全量=整个库；差异=自**上次全量**以来所有变化；增量=自**上次任意备份**以来的变化。
2. **再给机制**：第一天全备，第二天差异=第1天后变化，第三天差异=**第1天后**的全部变化（越往后越大）；第二天增量=第1天后变化，第三天增量=**第2天后**变化（每天只含当天量）。
3. **最后给边界**：增量**恢复链最长**——全量 + 每个增量**依次**应用，缺一个即失败；差异只需全量 + 最新差异，恢复链最短。
**加分层**：常见排期是「每周一次全量 + 每天增量」，并保留 binlog 覆盖最后一次备份到故障点之间的窗口。

## 关键代码
```bash
# XtraBackup：差异与增量的唯一区别是 --incremental-basedir 指向谁
# 增量：basedir 指向上一次（全量或增量）备份目录
xtrabackup --backup --incremental-basedir=/bk/inc1 --target-dir=/bk/inc2
# 差异：basedir 始终指向最近一次全量目录
xtrabackup --backup --incremental-basedir=/bk/full --target-dir=/bk/diff2
```

```sql
-- 增量恢复的起点锚点：备份时刻的 binlog 文件与位点

```
