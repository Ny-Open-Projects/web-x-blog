## 一句话总述
Percona Server 是 Percona 公司在 MySQL 官方版上**完全兼容**的二次开发版，**性能优于社区版**并自带线程池、审计、热备份等工具，但**新版本滞后官方 2~3 个月**。

## 面试官视角
- **考察意图**：是否知道主流第三方发行版及其卖点。
- **P5** 知道 Percona 兼容官方版、性能更好。
- **P6** 能说清滞后期与 XtraDB/线程池等特性。
- **P7** 能权衡「追新特性」与「稳定性」的取舍。
- **红旗**：说 Percona 是 fork 不兼容官方版。
- **惊艳点**：点出 Percona 同时支持 MGR 且审计/线程池是其差异化卖点 `[经验]`。

## 主问答
**Q：Percona Server 是什么，和官方版比如何？**
**A：**
1. **结论**：Percona Server 对官方版**完全兼容**并二次优化，性能更优，自带审计日志、线程池、热备份等工具。
2. **机制**：用 XtraDB（InnoDB 分支）、提供企业版才有的线程池与审计能力；官方版有的功能它基本都有。
3. **边界**：因基于旧版二次开发，Percona 最新版通常滞后官方 2~3 个月，想要最新特性还得等。
**加分层**：若环境已用 ProxySQL/PMM，Percona 生态联动最顺。
