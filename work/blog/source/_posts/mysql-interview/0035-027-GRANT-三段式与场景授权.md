> 分类：用户管理 | 难度：L2 | 题型：场景题 | 频率：高 | 关键词：**GRANT 三段式** / **ON 作用对象** / **TO 账号**
> 原文锚点：第 87~94 段「用户 A 通过服务器 B 对位于 C 服务器上的 db1 数据库中的表 tb1 进行读写操作，如何授权」

## 一句话总述
`GRANT` 语法固定三段：**授予什么权限（GRANT 后）→ 作用在哪个对象（ON 后）→ 给哪个账号（TO 后）**；场景题的关键是把"应用所在机器"翻译成 host。

## 面试官视角
- **考察意图**：给你一个"人—机器—库—表"的四元组，看你能不能翻译成一条正确的 GRANT，这是对"账号 = user@host"理解的直接检验。
- **P5** 能写出 `GRANT ... ON ... TO ...` 的基本句式。
- **P6** 能正确识别 host 应填**应用服务器 B 的地址**（不是 C，也不是 A 的客户端），并按读写需求挑出权限集合。
- **P7** 会反问"读写"的边界：是否需要 DELETE、是否需要建临时表，并坚持**最小权限 + 限网段 + SSL**。
- **红旗**：① 把 host 写成数据库服务器 C 的地址；② 直接 `GRANT ALL ON *.*`；③ 忘记 host 导致默认 `%`。
- **惊艳点**：这类题的陷阱在 host——**授权对象是"发起连接的机器"即 B**，写成 C 或 `%` 都会错 `[经验]` —— 验证：`SELECT USER(), CURRENT_USER();` 看客户端实际来源。

## 主问答
**Q（面试官原话）：** 用户 A 要部署在服务器 B 上，去读写服务器 C 上 MySQL 的 db1 库 tb1 表，你怎么授权？

**A：**
1. **结论**：`GRANT SELECT, INSERT, UPDATE, DELETE ON db1.tb1 TO 'A'@'B的IP或网段';` —— host 填 **B 的地址**，不是 C。
2. **机制**：三段式分别是**权限列表**（GRANT 后）、**作用对象**（ON 后，可到 `*.*` / `db.*` / `db.tbl`）、**目标账号**（TO 后，必须是已用 `CREATE USER` 建好的账号）。
3. **边界**：按**最小权限原则**只给必要的权限——只读就只给 `SELECT`；`ON *.*` 会扩散到所有库，**绝不能图省事**。

**加分层**：生产上 host 应限制到内网网段而非 `%`，并配合 SSL 加密链路；授权后必须 `SHOW GRANTS FOR` 复核。

## 追问链
| 层 | 追问 | 在测什么 | 怎么接 | 答不出停在哪档 |
|---|---|---|---|---|
| L1 | GRANT 语法几段 | 概念 | 权限 / ON 对象 / TO 账号 | 换题 → 不及格 |
| L2 | host 填哪台机器 | 核心陷阱 | 填应用服务器 B | 判 P5 |
| L3 | 只读给什么权限 | 最小权限 | 只给 SELECT | 判 P6 |
| L4 | ON 后面能写多细 | 粒度控制 | `*.*` / `db.*` / `db.tbl` | 判 P6+ |
| L5 | 远程链路怎么加固 | 安全判断 | 限网段 + SSL + 定期审计 | 答上判 P7 |

## 版本与兼容性
| 结论成立版本 | 翻转点 | 现在怎么答 |
|---|---|---|
| 5.7 / 8.0 | 三段式语法一致；区别是 **8.0 必须先 CREATE USER** | 统一按"先建账号再授权 + 三段式"答 |

## 关键代码
```sql
-- 场景：应用部署在 192.168.1.10，访问 db1.tb1，只需读写
CREATE USER 'app_a'@'192.168.1.10' IDENTIFIED BY 'Pwd#2026a' REQUIRE SSL;
GRANT SELECT, INSERT, UPDATE ON db1.tb1 TO 'app_a'@'192.168.1.10';
-- 复核：确认权限与 host 都正确
SHOW GRANTS FOR 'app_a'@'192.168.1.10';
```

## ⚠️ 原文纠错
原文示例写的是"给用户 user@IP 授予对 DB.TB 表的 select、insert、update 和 delete 权限"，与场景描述（读写）一致，未发现技术错误。补充一点原文未强调的：授权前应用服务器 B 的地址应精确到主机或最小网段，避免用 `%`。机翻音译（grent、crerent）已还原为 GRANT。

## 总结与追问预判
- GRANT 三段式：**权限 → ON 对象 → TO 账号**。
- 场景题陷阱：**host 是发起方 B**，权限按最小集给，复核用 `SHOW GRANTS`。
