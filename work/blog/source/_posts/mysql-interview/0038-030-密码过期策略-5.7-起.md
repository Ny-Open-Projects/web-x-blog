> 分类：用户管理 | 难度：L2 | 题型：工程题 | 频率：中 | 关键词：**PASSWORD EXPIRE** / **default_password_lifetime** / **沙箱模式**
> 原文锚点：第 134~157 段「在 5.7 中引入了密码过期时间的设置…如果设置了密码过期，那么用户在下次登录的时候必须要设置一个新的密码」

## 一句话总述
**5.7 起支持密码过期**：全局用 `default_password_lifetime`，单账号用 `ALTER USER ... PASSWORD EXPIRE`；**过期账号的新连接必须先改密码**。

## 面试官视角
- **考察意图**：看你是否知道数据库本身就有密码生命周期管理。
- **P5** 知道有"密码过期"这个能力。
- **P6** 能说出全局参数与三种取值 `DEFAULT / NEVER / INTERVAL n DAY`。
- **P7** 能区分**已建连接不受影响、新连接被拦截**，并知道过期后进**沙箱模式**。
- **红旗**：① 说"一过期所有连接立刻断开"；② 以为过期账号登录后仍可正常查询。
- **惊艳点**：**过期只影响新建连接**，旧会话照常执行；过期会话进入沙箱，除改密码外几乎什么都做不了 `[经验]` —— 验证：置过期后旧会话仍能 `SHOW DATABASES`，重连即报 1820。

## 主问答
**Q（面试官原话）：** 怎么让账号定期改密码？过期之后正在跑的业务会立刻断吗？

**A：**
1. **结论**：用 **5.7 起的 `default_password_lifetime`**（全局）或 `ALTER USER ... PASSWORD EXPIRE INTERVAL n DAY`（单账号）；**正在跑的连接不会立刻断**。
2. **机制**：三种取值——`DEFAULT`（跟随全局）、`NEVER`（永不过期）、`INTERVAL n DAY`；过期账号登录后进入**沙箱模式**，必须先重设密码。
3. **边界**：过期判断发生在**建立连接时**，旧连接不受影响；开启前必须确认应用能自动获取新密码。

**加分层**：`SET PERSIST` 让全局策略**重启后仍生效**，避免配置重启丢失（详见 016 卡）。

## 版本与兼容性
| 结论成立版本 | 翻转点 | 现在怎么答 |
|---|---|---|
| ≤ 5.6 | **无**密码过期能力 | 只能靠外部流程 |
| 5.7 起 | 引入 `default_password_lifetime` 与 PASSWORD EXPIRE | 按"5.7 起支持，8.0 沿用"答 |

## 关键代码
```sql
SET PERSIST default_password_lifetime = 90;
ALTER USER 'test'@'localhost' PASSWORD EXPIRE;
SELECT user, host, password_last_changed, password_lifetime FROM mysql.user WHERE user='test';
```

## ⚠️ 原文纠错
原文演示版本为"MySQL 8.0.11"，并称密码过期"5.7 引入"——与官方一致，未发现技术错误。原文"前期配置的过滤策略"应为"**全局配置**的默认过期策略"口误，已按正确语义重写。机翻音译（noover、loser）已还原为 NEVER、ALTER USER。

## 总结与追问预判
- 密码过期 = **5.7 起**，全局 `default_password_lifetime` / 单账号 `PASSWORD EXPIRE`。
- **只影响新连接**，旧会话照常；过期后进入沙箱模式。
