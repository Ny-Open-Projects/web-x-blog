> 分类：服务器配置 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**动态参数** / **只读参数** / **重启生效**
> 原文锚点：第 191~195 段「配置文件中的配置分为两类，一种可以通过 SET 命令动态修改，另一种则只能通过配置文件修改后重启服务器使其生效」

## 一句话总述
MySQL 参数分两类：**动态参数**可用 `SET` 运行时改，**只读参数**只能改配置文件后**重启生效**（如启用二进制日志）——后者天然不会出现"运行时与配置不一致"。

## 面试官视角
- **考察意图**：看你是否知道"不是所有参数都能在线改"，避免说出"改 log_bin 用 SET"这种外行话。
- **P5** 知道有些参数要重启才生效。
- **P6** 能举出只读参数的例子（`log_bin`），并说明动态参数才需要担心一致性。
- **P7** 能给出判断方法（`SHOW VARIABLES` 之外看官方文档 Dynamic 属性），并落到变更流程：只读参数走重启窗口、动态参数走双写（SET + 配置文件）。
- **红旗**：① 以为所有参数都能 `SET GLOBAL`；② 动态参数只改配置文件不改运行时，或反之。
- **惊艳点**：**只有动态参数才会出现"运行时 ≠ 配置文件"的漂移**——只读参数改完必然重启 `[经验]` —— 验证：对比 `SHOW VARIABLES` 与配置文件取值。

## 主问答
**Q（面试官原话）：** MySQL 的参数都是改完就生效吗？哪些必须重启？

**A：**
1. **结论**：分两类——**动态参数**可 `SET` 在线生效；**只读参数**只能改配置文件后**重启**才生效。
2. **机制**：典型只读参数是**启用二进制日志**（`log_bin`），实例启动时即确定，无法在线开关。
3. **边界**：只读参数必须重启，**不会出现运行时与配置不一致**；漂移只在动态参数上。

**加分层**：动态参数变更要**两边都改**——`SET GLOBAL` + 同步改配置文件（8.0 用 `SET PERSIST`）。

## 版本与兼容性
| 结论成立版本 | 翻转点 | 现在怎么答 |
|---|---|---|
| 5.7 及之前 | 动态参数需手工双写配置文件 | 按"SET GLOBAL + 改配置"答 |
| 8.0 | 新增 `SET PERSIST`，自动写 `mysqld-auto.cnf` | 现在补一句"8.0 优先用 SET PERSIST"（详见 016 卡） |

## 关键代码
```sql
SHOW VARIABLES LIKE 'log_bin';        -- 只读参数，需改配置后重启
SHOW VARIABLES LIKE 'max_connections';-- 动态参数，可在线改
SET GLOBAL max_connections = 1000;    -- 立即生效，但重启会丢
```

未发现技术错误。核对范围：第 191~195 段关于配置分两类、启用二进制日志属只读配置、只读参数运行时与文件必然一致的描述，与官方行为一致。机翻音译（sate 格外、macCNF）已还原为 SET GLOBAL、my.cnf。

## 总结与追问预判
- **只读参数**必须重启，**动态参数**才可能漂移。
- 动态参数变更要**两边都改**；8.0 用 `SET PERSIST`。
