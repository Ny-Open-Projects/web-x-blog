## 纲要

- **日期占位**：`{{current_date}}` 让模型感知「今天几号」（预约 / 跨天场景必备）
- **文件加载**：`@SystemMessage(fromResource="模板.txt")` 把长提示词抽到资源文件
- **业务参数混合**：系统模板（文件）+ `@V` 业务参数（name/age）一并交给模型
- **适用场景**：从 DB / 接口取业务参数，与系统提示词组合成完整指令
- **验证**：改模板内容为韩语 / 东北话，控制台返回对应语言即生效

> 本章把系统提示词玩出进阶组合，按课程口径重构；代码为课程示意，去品牌与脱敏处理。

## 一、日期占位

模型本身不知道「今天几号」，用占位符注入当前日期：

```java
@SystemMessage("今天是 {{current_date}}，请据此回答日期相关问题")
String chat(@UserMessage String q);
```

`{{current_date}}` 由框架在运行时替换为真实日期，模型即可正确回答「今天几号」。

## 二、文件加载长提示词

提示词较长时，抽到 `resources` 下的模板文件，避免代码臃肿：

```java
@SystemMessage(fromResource = "my-system-message.txt")
String chat(@UserMessage String q);
```

`my-system-message.txt` 内容示例：
```
你是中国专业法律顾问，只回答与中国法律相关的问题。
```

## 三、系统模板 + 业务参数混合

系统提示词模板（文件）含业务占位符，方法用 `@V` 传入真实参数：

```java
@SystemMessage(fromResource = "sys-role.txt")   // 模板含 {{name}} {{age}}
String chat(@MemoryId String id,
            @V("name") String name,
            @V("age") int age,
            @UserMessage String message);
```

`sys-role.txt`：
```
你是我的好朋友，我叫 {{name}}，今年 {{age}} 岁，请用东北话回答我的问题。
```

调用时模型同时收到系统角色模板与业务参数，回答更「智能化」。

```mermaid

```

## 四、FAQ

**Q1：current_date 格式可控吗？**
框架按约定格式注入；具体格式以版本文档为准。

**Q2：模板文件放哪？**
放 `resources` 目录，`fromResource` 写相对路径。

**Q3：业务参数能进系统提示词吗？**
能；系统模板中用 `{{name}}` 占位，方法 `@V` 传值即可。

## 五、面试高频问答

1. **如何让模型知道日期？** 用 `{{current_date}}` 占位符由框架注入。
2. **长提示词怎么管理？** `fromResource` 抽到资源文件，代码更干净。
3. **系统模板 + 业务参数如何组合？** 模板写 `{{name}}` 占位，`@V` 绑定业务参数传入。

## 六、ops 提示

> **模板版本化**：提示词模板纳入版本管理，变更可回溯。
>
> **日期时区**：`current_date` 注意时区，跨时区业务显式指定。
>
> **参数脱敏**：业务参数（姓名/年龄）入提示词前评估隐私，必要时脱敏。
