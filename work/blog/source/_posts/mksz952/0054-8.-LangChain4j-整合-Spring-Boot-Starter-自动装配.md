## 纲要

- **依赖替换**：把普通 `langchain4j-openai` 换成 `langchain4j-openai-spring-boot-starter`
- **配置驱动**：`application.properties` 配 `api-key` / `base-url` / `model-name` 三项
- **自动装配**：`@Autowired OpenAIChatModel` 即可注入，无需手动 `builder`
- **测试验证**：`@SpringBootTest` 中调用 `model.chat()` 跑通

> 本章把前面的原生调用搬进 SpringBoot，实现配置化接入，按课程口径重构；代码为课程示意，去品牌与脱敏处理。

## 一、从原生到 Starter

前面用 `OpenAIChatModel.builder()` 手动构造。工程化后更优雅的做法是用 **Spring Boot Starter 自动装配**：依赖换成 starter，参数写进配置文件，框架启动时自动把 `OpenAIChatModel` 注入容器。

## 二、依赖切换

```xml
<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-openai-spring-boot-starter</artifactId>
</dependency>
```

## 三、配置文件

课程 demo 用测试 key 与测试地址；注意若严格按文档的模型名而不配 `base-url`，可能触发限流（`m2` 错误），因此课程演示额外指定了 `base-url` 与模型名。

```properties
langchain4j.openai.api-key=demo
langchain4j.openai.base-url=https://api.openai.com/v1
langchain4j.openai.model-name=gpt-4o-mini
```

## 四、自动装配注入

```java
import dev.langchain4j.model.openai.OpenAIChatModel;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;

@SpringBootTest
class OpenAiTest {

    @Autowired
    OpenAIChatModel model;

    @Test
    void hello() {
        String answer = model.chat("你是谁？");
        System.out.println(answer);
    }
}
```

测试跑通即说明 `OpenAIChatModel` 已通过自动装配注入，业务代码可直接 `@Autowired` 使用。

## 五、FAQ

**Q1：starter 和普通依赖区别？**
starter 多了 `spring.factories` / 自动配置类，按配置自动创建 `OpenAIChatModel` Bean 并注入容器。

**Q2：为什么课程要手动加 base-url？**
避免默认地址 + 文档模型名组合触发限流，演示环境显式指定更稳。

**Q3：多个模型怎么注入？**
不同模型用不同 starter / 不同前缀配置，各自注入对应类型的 Model Bean。

## 六、面试高频问答

1. **SpringBoot Starter 自动装配原理？** 依赖 `META-INF/spring.factories` 或 `AutoConfiguration`，按条件创建 Bean。
2. **LangChain4j 的 starter 配置前缀？** `langchain4j.openai.*`。
3. **为什么工程化推荐 starter 而非 builder？** 配置与代码分离，便于多环境切换与密钥托管。

## 七、ops 提示

> **配置与代码分离**：模型参数走配置文件 / 配置中心，密钥走环境变量，禁止明文入库。
>
> **版本一致性**：starter 版本受 `langchain4j-bom` 约束，与手动引入保持一致。
>
> **多环境**：`application-dev.properties` / `application-prod.properties` 抽离 key 与 base-url，避免生产误用 demo。
