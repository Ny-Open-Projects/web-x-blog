# 低代码项目平台编辑模块—页面组件滚动时工具栏的显隐开发

> **导语**：上一集留了个体验问题：画布一滚动，选中组件右下角的工具栏会跟着位置乱跳。这一集用「滚动即隐藏、停止 300ms 再显示」把它解决掉，并叠加 `IntersectionObserver` 的可见度判断。实现上涉及 `useRef` 监听父容器滚动、`useImperativeHandle` 把子组件方法交给父组件调用，以及拖拽结束后强制重算工具栏坐标——都是 React 编辑器里很值得记的手法。

## 正文

### 要解决的体验问题

选中轮播图时，工具栏固定在它右下角。但画布一滚动，这个位置就会发生偏移，看起来像「飘」了。本集的策略很直接：

- **滚动时隐藏工具栏**；
- **停止滚动再显示**；
- 若选中的组件已被滚出可视区域**超过 10%（0.1）**，即使停止滚动也不显示——这一条是此前用 `IntersectionObserver` 实现的能力，本集与滚动逻辑叠加生效。

### 监听谁：画布父容器

工具栏的位置是相对画布算的，所以要监听的是**画布的父容器**，而不是 window。用 `useRef` 建一个 `canvasContainerRef` 绑定到 canvas 的父级 div，在 `useEffect` 里挂滚动监听：

```ts
useEffect(() => {
  const el = canvasContainerRef.current;
  el?.addEventListener('scroll', handleScroll);
  return () => el?.removeEventListener('scroll', handleScroll);
}, [scrolling]);
```

拿到 DOM 元素后再监听 `scroll`，事件回调是 `handleScroll`。注意 `useEffect` 的清理函数里必须 `removeEventListener`，否则监听会越挂越多。

### 滚动隐藏 + 停止 300ms 显示

`handleScroll` 的核心是「防抖」：只要还在滚，就不断清掉上一个定时器，并把 `scrolling` 置为 `true`、隐藏工具栏；一旦停下来，定时器才真正跑完，把状态与显示一起恢复：

```ts
const handleScroll = () => {
  clearTimeout(timerRef.current);
  setScrolling(true);
  canvasRef.current?.setShowToolbar(false);   // 隐藏工具栏

  timerRef.current = setTimeout(() => {
    setScrolling(false);
    canvasRef.current?.setShowToolbar(true);  // 停止 300ms 后显示
  }, 200);
};
```

滚动过程中定时器被反复清除，所以「显示」永远不会在滚动中途触发；**停止滚动满 300ms** 才恢复。定时器同样要在 `useEffect` 清理里 `clearTimeout`。`scrolling` 变量变化时 `useEffect` 重新执行，监听与定时器都得到正确重置。

### 父组件怎么调子组件的方法：useImperativeHandle

`setShowToolbar` 是子组件 `EditorCanvas` 里的方法，父组件要调它，用的是 React 的 `useImperativeHandle` + 一个 ref 容器：

```ts
// 父组件：createRef 建一个「容器」，传给子组件时改名 onRef
const canvasRef = createRef<CanvasHandle>();

// 子组件：把方法装进容器
useImperativeHandle(onRef, () => ({
  setShowToolbar,
}));
```

讲师用了个很形象的比喻：父组件递给子组件一个「木桶」（ref），子组件把自己的方法（水）装进去再还回来，父组件就能引用调用了。这和 Vue 里子组件用 `defineEmits` 把方法抛给父组件是同一类需求，只是 React 走 `useImperativeHandle`。

隐藏本身落在工具栏组件里：`showToolbar` 取反后作为 `hidden` 传给 `EditorChooiseToolbar`，JSX 里用 `classnames` 动态拼类名，`hidden` 为 true 时工具栏隐藏。

### 拖拽结束：强制重算工具栏坐标

还有一处联动：把选中的视频组件拖到第二、第三个位置后，工具栏也得跟着挪。做法是在工具栏（孙子组件）里再用一次 `useImperativeHandle`，暴露 `setRefrash`（源码拼写）；父组件在拖拽结束时调用：

```ts
toolbarRef.current?.setRefrash(true);
```

这个标志会触发对应的 `useEffect` 重新执行 `resizeComponent`——重新读取当前选中组件在浏览器中的坐标与宽高，从而把工具栏摆到新位置。（演示里第一次拖动没变化，是因为组件当时已被滚动逻辑隐藏了。）

最后还补了一个小细节：用 `useTitle` 把编辑页标题设成「小滴低代码平台 - 页面编辑」。

工程依赖可对照 `代码（已8期）/18-8/lowcode/packages/client/package.json`：拖拽用 `@dnd-kit/core` / `@dnd-kit/sortable` / `@dnd-kit/utilities`，动态类名用 `classnames`，状态用 `mobx` / `mobx-react-lite`，撤销能力用 `mobx-shallow-undo`。

## 小结

- 策略：滚动即隐藏工具栏，停止滚动满 300ms 再显示；组件被滚出超过 10% 时保持隐藏。
- 用 `useRef` 绑定画布父容器，在 `useEffect` 里 `addEventListener('scroll')`，并在清理函数里移除监听与定时器。
- `handleScroll` 靠反复 `clearTimeout` 实现防抖，避免滚动中途误显示。
- 父调子方法用 `useImperativeHandle` + ref 容器；隐藏由 `classnames` 拼 `hidden` 类实现。
- 拖拽结束调 `setRefrash(true)` 触发 `resizeComponent` 重算工具栏坐标。
