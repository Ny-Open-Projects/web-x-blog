# 低代码项目平台编辑模块—阿里云_OSS_资源删除配置

> **导语**：上传接口完成后，资源还需要能被删除——用户在编辑器里换掉图片、视频时，旧文件应该从 OSS 上清理掉。本节课我们在 `ali-oss.module.ts` 里补一个 `deleteFromAliOss` 方法：从前端传来的 URL 中剥离自定义域名、保留“文件名+后缀”、解码后再调用阿里云 `delete` API，并以 204 状态码判定删除成功。

## 前置知识

阅读本文前，建议先掌握《低代码项目平台编辑模块—阿里云 OSS 资源上传接口开发》。删除方法是上传方法（`uploadToAliOss`）的姊妹方法，同样写在 `AliOssModule` 里，且依赖上一节已经约定好的自定义短域名。

## 正文

### 删除方法的设计

在 `ali-oss.module.ts` 中，除了已有的 `uploadToAliOss`，我们新增一个 `deleteFromAliOss(url)`。它接收**要删除资源的 URL**，核心任务是：从这个完整 URL 里提取出“文件名 + 后缀”，再交给阿里云的 `delete` API 去删对象。

为什么只传 URL 就够了？因为上传时我们已经把默认域名替换成了自有短域名（`local.16web.net` 之类），URL 里天然包含了对象在 Bucket 中的路径，解析出来即可定位文件。

### 三步处理 URL

`deleteFromAliOss` 内部对该 URL 做如下处理：

**1. 剔除自定义域名**

前端传来的 URL 形如 `http://local.16web.net/upload_files/三个一-1700000000000.jpg`。用 `replace` 把前面那段自定义域名整体替换成空字符串，只剩下 `/upload_files/三个一-1700000000000.jpg`（即对象的 key，含路径、文件名与后缀）。

```ts
const objectKey = url.replace(aliOssDomain, '');
```

**2. 解码字符串**

处理完的字符串还要做一次 `decodeURI`（即 decode URL），把可能经过编码的中文字符还原，否则直接传给阿里云 API 会找不到对象。

```ts
const decodedKey = decodeURI(objectKey);
```

**3. 调用阿里云 delete**

把解析好的 key 传给 `this.aliOss.delete(decodedKey)`：

```ts
async deleteFromAliOss(url: string) {
  const objectKey = decodeURI(url.replace(aliOssDomain, ''));
  const res = await this.aliOss.delete(objectKey);
  if (res.status === 204) {
    // 204 代表删除成功，无需额外返回信息
    return;
  }
  throw new BadRequestException('删除失败，请重试');
}
```

### 状态码判定与异常处理

阿里云 OSS 删除成功后返回的状态码是 **204**（No Content），所以只要 `res.status === 204` 就认为删除成功，方法直接结束、不返回额外内容。如果状态不是 204，说明删除失败，主动抛出 `BadRequestException('删除失败，请重试')`，让上层接口统一返回错误。

## 小结

- 删除方法 `deleteFromAliOss(url)` 与上传方法同处 `AliOssModule`；
- 处理 URL 三步：剔除自定义域名 → 保留文件名+后缀（对象 key）→ `decodeURI` 解码；
- 调用 `this.aliOss.delete(key)`，按 `res.status === 204` 判定成功；
- 删除失败时抛出 `BadRequestException`，交由全局异常拦截器统一处理。
