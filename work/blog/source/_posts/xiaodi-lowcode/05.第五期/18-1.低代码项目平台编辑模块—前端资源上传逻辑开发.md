# 低代码项目平台编辑模块—前端资源上传逻辑开发

> **导语**：上一章把阿里云 OSS 的资源上传、获取、删除接口都做完了，这一章开始接前端。本文聚焦「上传」这一条链路：右侧图片地址旁的上传按钮、点击后弹出历史资源弹窗、`FormData` 调上传接口、成功后重新拉取列表刷新，以及用 `useRequest`、`Modal`、`useRef`、`IntersectionObserver` 级别的前端手法把 loading、视频封面等细节兜住。

## 前置知识

- 建议先了解《低代码项目平台编辑模块—阿里云 OSS 资源上传接口开发》与《低代码项目平台编辑模块—阿里云 OSS 资源获取接口开发》，本文直接调用这两个后端接口。
- 建议先了解《前端页面开发—图片组件配置属性》，上传按钮就挂在图片组件的属性面板里。

## 正文

### 先看效果

登录平台（前端端口注意不是默认的 3000，演示里是 4001），选中图片组件，右侧「图片地址」旁边多了一个上传按钮。点击后弹出资源弹窗，里面列出之前已上传的三张图片；点选其中一张，画布上的图片立刻被替换。若获取资源的接口还没返回，弹窗会显示 loading 状态——把浏览器网络调成慢速 3G 就能稳定复现。

弹窗左侧另有上传按钮：点击触发隐藏的 `<input type="file">`，打开系统文件选择框，选中一张 PNG 后调用后端上传接口把文件传到 OSS；上传成功后**重新请求资源获取接口**，列表里就多出这一项。

### 用 UploadEditOrChooiseInput 替换占位 input

图片属性组件最下方原本是一个普通 `input` 占位，现在换成公共组件 `UploadEditOrChooiseInput`，定义在 `utils components` 里，传入两个参数：

- `type`：资源类型，图片组件传图片类型，视频组件传 `video`。
- `propName`：要回写的字段名，这里是 `url`。

它的接口还预留了 `listOptions`（仅 `keyName?` 与 `defaultValues` 两键）与其它 props：当列表、轮播这类可新增多项的组件引入它时，才需要传这些参数来区分「单个资源」还是「一组资源」。

组件 JSX 分左右两块：左边是 input 框，默认值取父组件 `FormPropLabel` 传来的 `props.url`；右边是上传按钮，用 Ant Design 的图标组件加 hover 手型/置灰样式。点击按钮打开弹窗，由 `visible` 控制显隐，同时把 `type`、`visible`、`onChoice`（选中已有资源时更新 store 里的值、同步刷新 URL）、关闭回调都传下去。

### 上传弹窗：Modal + loading + 资源列表

`UploadComponent` 接收 `visible`、`type`、关闭回调与 `onChoice`。内部用 Ant Design 的 `Modal`：

- `title` 是动态值，如「选择上传的图片」；
- `open` 由 `visible` 控制，取消 / 确定都可关闭，演示里把取消按钮隐藏了；
- 内容区用三元表达式在「加载中」与「资源列表」之间切换：loading 时显示从 Ant Design 引入的旋转图标，数据到位后 `map` 循环渲染各个资源子项。

获取资源用 ahooks 的 `useRequest` 请求 `getResources` 接口，成功后通过 `setResource`（`useState`）写入响应数据，再交给列表循环渲染。

### 触发文件选择与 FormData 上传

上传逻辑挂在一个 `<input type="file">` 上，用 `useRef` 拿到 `uploadRef`，点击按钮时执行 `uploadRef.current.click()` 打开系统选择框。选中文件触发 `handleUploadChange`：

1. 先判断是否真的选中了资源，没有就终止。
2. 构造 `FormData`，`append` 一个 `type`（图片 / 视频），再 `append` 选中的文件（文件数组取第一项）。
3. 调用上传接口（同样用 `useRequest` 定义）。
4. 上传成功后**重新请求资源获取接口**，拿到包含新资源的最新列表。
5. 清空 input 里已打开的文件，避免下次选同一文件不触发 change。

上传过程中用 `loadingWithUpload` 把按钮切换成加载态；`accept` 按 `type` 决定可选文件类型——视频就限视频，否则限图片。

### 视频封面：取第一帧

列表里每一项要展示缩略图。图片资源直接取地址展示；视频资源则用阿里云 OSS 的「截取视频第一帧」参数生成封面，这段方法可以在阿里云 OSS 文档里查到，由 `getVideoFirstFrameOrImage` 统一处理。

### api/resource 里的三个接口

新建 `api/resource` 文件，集中定义三个方法：

| 方法 | 请求 | 说明 |
| --- | --- | --- |
| `uploadFile` | POST + `FormData` | headers 设 `multipart/form-data` |
| 资源获取 | GET | RESTful 风格，路径带类型 |
| 资源删除 | DELETE | 路径带类型与资源 ID |

上传与删除的路径参数一致，都是「类型 + 资源标识」，只是方法不同。

## 小结

- 图片属性面板里的 `UploadEditOrChooiseInput` 传 `type` 与 `propName`，列表类组件才需要额外的 `listOptions`。
- 弹窗用 Ant Design `Modal`，`visible` 控制显隐，`useRequest` 拉资源列表，`useState` 存数据后 `map` 渲染。
- 上传靠 `useRef` 触发隐藏的 `input[type=file]`，选中后用 `FormData` 传 `type` 与文件。
- 上传成功必须**重新请求资源获取接口**才能刷新列表，并清空 input 里的文件。
- 视频缩略图用阿里云 OSS 的截取第一帧参数生成；`api/resource` 统一放上传 / 获取 / 删除三个方法。
