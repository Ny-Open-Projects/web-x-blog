# 低代码平台项目前端 React 项目配置—Ant-design+TailwindCSS

> **导语**：低代码编辑平台需要大量表单、弹窗与布局组件，手写样式成本高。本节在前端 client 子项目引入 Ant Design 组件库与 Tailwind CSS 原子化样式框架，让页面既好看又好改。

## 前置知识
- 已创建 React 前端子项目：建议先看《前端子项目 React 创建和项目配置》。
- 项目已能通过 `@lowcode/share` 复用公共变量：见《前端 client 项目使用公共项目 share 变量》。

## 正文
### 安装 Ant Design
通过 filter 只给 client 安装：

```bash
pnpm --filter client add antd
```

安装完成后，`packages/client/package.json` 的依赖里会出现 `antd`（关联代码节选）：

```json
{
  "name": "@lowcode/client",
  "dependencies": {
    "@lowcode/share": "workspace:^",
    "antd": "^5.11.2",
    "autoprefixer": "^10.4.16",
    "postcss": "^8.4.31",
    "tailwindcss": "^3.3.5"
  }
}
```

在 `src/App.tsx` 中直接引入并使用按钮组件：

```tsx
import { Button } from 'antd';

function App() {
  return <Button type="primary">小滴课堂</Button>;
}
```

`type="primary"` 才会呈现主题色，否则按钮背景是空白的。启动后访问 `http://localhost:5173`，即可看到 Ant Design 样式的按钮。

### 安装 Tailwind CSS
依次安装 Tailwind 及其构建依赖：

```bash
pnpm --filter client add -D tailwindcss postcss autoprefixer
```

生成两份配置文件：

```js
// tailwind.config.js
export default {
  content: ['./index.html', './src/**/*.{ts,tsx}'],
  theme: { extend: {} },
  plugins: [],
};
```

```js
// postcss.config.js
export default {
  plugins: {
    tailwindcss: {},
    autoprefixer: {},
  },
};
```

在样式入口（如 `src/assets/base.css`）写入 Tailwind 三段指令：

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

并在 `App.tsx` 中引用该样式文件：

```tsx
import './assets/base.css';
```

### 验证原子化样式
删除脚手架默认样式后，用类名给共享文本上色并放大字号：

```tsx
import { sharedText } from '@lowcode/share';

function App() {
  return <div className="text-red-500 text-8xl">{sharedText}</div>;
}
```

由于新增了配置文件，需要重启 `pnpm run:client` 才能生效。刷新页面，文本变为红色，把 `text-red-500` 改为 `text-red-800` 即变为更深的红。

## 小结
- Ant Design 提供开箱即用的组件，`type="primary"` 控制主按钮样式。
- Tailwind CSS 通过 `content` 扫描文件生成原子类，配合 `postcss` 与 `autoprefixer` 构建。
- 样式入口文件需引入 base/components/utilities 三段指令。
- 新增配置后必须重启前端服务。
