# 低代码平台项目后端 Nest 项目配置—TypeORM

> **导语**：Nest 后端操作 MySQL 依赖 TypeORM。本节在已初始化的 server 子项目中安装依赖、编写数据库连接配置、创建 User 模块与实体，并验证接口能正常返回数据。

## 前置知识
- 已创建 Nest 后端子项目：建议先看《后端子项目 Nest 创建和项目配置》。
- 已在云服务器用容器化方式安装好 MySQL：建议看《阿里云 Linux 服务器容器化安装 Mysql》。
- 想系统了解 ORM 概念，可参考《探索 Node 世界中的数据建模—ORM 框架》。

## 正文
### 安装 TypeORM 相关依赖
在 Nest 项目中使用 TypeORM，需要三个包：核心 `typeorm`、Nest 适配层 `@nestjs/typeorm`，以及 MySQL 驱动 `mysql2`。通过 filter 只给 server 安装：

```bash
pnpm --filter server add typeorm @nestjs/typeorm mysql2
```

### 编写数据库配置 config.ts
在项目根目录新建 `config.ts`，导出 TypeORM 连接选项：

```ts
import { TypeOrmModuleOptions } from '@nestjs/typeorm';

export const typeOrmConfig: TypeOrmModuleOptions = {
  type: 'mysql',
  host: '你的云服务器公网IP',
  port: 3306,
  username: 'root',
  password: '你的数据库密码',
  database: 'study_class_local',
  entities: ['dist/**/*.entity{.ts,.js}'],
  synchronize: true,
};
```

注意几点：
- `host` 填的是阿里云服务器的公网地址，而非本地。
- `database` 填数据库名 按课程脚本为 `xdclass-lowcode`（低代码项目库），别和容器名混淆，否则连接会出问题。
- `synchronize: true` 会在项目启动时，按代码里的实体自动同步数据表与字段；开发环境方便，线上建议关闭。
- `entities` 指向所有以 `.entity` 结尾的文件，框架据此加载表结构。

### 在主模块注册 TypeORM
打开 `src/app.module.ts`，引入并注册：

```ts
import { TypeOrmModule } from '@nestjs/typeorm';
import { typeOrmConfig } from './config';

@Module({
  imports: [TypeOrmModule.forRoot(typeOrmConfig)],
})
export class AppModule {}
```

### 创建 User 模块与实体
用 Nest CLI 生成 RESTful 风格的 User 模块：

```bash
cd packages/server
nest g resource user
```

脚手架会生成 controller、service、module 以及 DTO。实体文件 `user.entity.ts` 暂定义 `id`、`name`、`phone`、`password` 几个字段，并在 `user.module.ts` 中通过 `TypeOrmModule.forFeature([User])` 注册该实体，这样 `UserService` 才能注入 `UserRepository` 操作数据库。

控制器里保留一个查询方法即可：

```ts
@Get()
findAll() {
  return this.userRepository.find();
}
```

### 验证联通
启动服务 `pnpm --filter server start:dev`，用 API 工具请求 `GET /user`，即可从 MySQL 返回用户数据，说明 TypeORM 配置成功。完成后把改动提交到云效仓库。

## 小结
- Nest 使用 TypeORM 需安装 `typeorm`、`@nestjs/typeorm`、`mysql2` 三个包。
- 连接配置集中在 `config.ts`，`synchronize` 实现代码驱动表结构同步。
- 实体通过 `TypeOrmModule.forFeature` 注册后才能注入 Repository。
- 配置细节在后续《TypeORM 框架-轻松掌握链接 Mysql 数据库配置》会再深入。
