# 阿里云 Linux 服务器容器化安装 Mysql

> **导语**：本文在 Docker 环境就绪后，演示如何用一行 `docker run` 命令在阿里云 Linux 服务器上容器化安装 MySQL 8.0，并讲解端口映射、安全组放行，以及用 Navicat 连接、建库、导入 SQL。

## 前置知识
阅读本文建议先看完《云服务器搭建 Docker 环境和使用讲解》，确保 Docker 已安装并可执行命令。

## 正文

### 一行命令安装 MySQL
```bash
docker run --name xdclass-mysql \
  -e MYSQL_ROOT_PASSWORD=xdclass.net168 \
  -p 3306:3306 \
  -d mysql:8.0
```

参数说明：

- `--name xdclass-mysql`：容器名称；
- `-e MYSQL_ROOT_PASSWORD=xdclass.net168`：设置 root 密码的环境变量；
- `-p 3306:3306`：把容器 3306 映射到服务器 3306；
- `-d`：后台运行；
- `mysql:8.0`：从 Docker Hub 拉取 8.0 镜像。

执行时若本地无该镜像，Docker 会自动到远端拉取、生成容器并运行。用 `docker ps` 可看到名为 `xdclass-mysql`、端口 `3306->3306` 的容器。

### 放行安全组端口
外部（如 Navicat）要连接容器内 MySQL，必须**在阿里云安全组开放 3306**。进入云服务器控制台 → 安全组 → 管理规则 → 新增/复制一条规则把端口改为 3306 并保存。

原理：服务器内 Docker 运行的 MySQL 容器通过 3306 与服务器映射，外部连接需服务器先开放该端口。

### 用 Navicat 连接并建库
资料中提供 Navicat 的 Windows / Mac 安装包。新建 MySQL 连接：

- 连接名：`xdclass-local-lowcode`；
- 主机：服务器公网 IP；
- 端口：3306（已开放）；
- 用户名：root；
- 密码：`xdclass.net168`（即容器启动时设置的密码）。

连接后新建数据库 `xdclass_local`，字符集与排序规则取默认第一项，确定即可创建。

### 导入 SQL 建表
导入课程提供的 `xdclass-lowcode.sql` 文件：运行 SQL 文件 → 选择 `.sql` 路径 → 开始。完成后打开表刷新，即可看到五张核心表（user / page / component / component_data / resourcess）及预置数据。

### 配套资料
安装包与 SQL 脚本见：`笔记+资料-已8期/xdclass-lowcode.sql`、资料内 Navicat 安装包。

## 小结
- `docker run` 一行装 MySQL：命名、设密码、映射 3306、后台运行、指定 8.0；
- 必须在阿里云安全组开放 3306 外部才能连接；
- Navicat 用公网 IP + 3306 + 容器密码连接；
- 建库 `xdclass_local` 后导入 `.sql` 得到五张表与数据。
