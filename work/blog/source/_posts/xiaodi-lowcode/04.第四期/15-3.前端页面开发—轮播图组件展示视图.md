# 前端页面开发—轮播图组件展示视图

> **导语**：本节给低代码编辑器加第三个具体组件——轮播图。它的展示视图和图片组件几乎一样（只有一张图时完全一致），差别主要在右侧属性配置。本文讲清 `share` 子包里组件与类型怎么新增、如何用 Ant Design `Carousel` 遍历渲染 `images`、轮播图属性类型包含哪些字段，以及一个务必记住的动作：改完 `share` 一定要重新打包，否则前端找不到新组件。

## 前置知识

建议先看过《前端页面开发—图片组件展示视图》与《前端页面开发—图片组件配置属性》，因为轮播图视图直接复用了图片组件；组件列表点击后如何渲染，见《前端页面开发—低代码项目编辑模块左侧组件列表样式》。整体编辑器骨架参考《前端页面开发—低代码项目编辑模块整体布局》。

## 正文

### 展示效果：与图片组件同源

点击左侧组件列表里的轮播图，希望它能在中间画布的视图组件里展示出来。它跟图片组件的显示逻辑是一样的：默认只有一张图片时，效果与图片组件一模一样；只有右侧属性组件开发完、支持「添加多一个项」，才会出现多张图和底部的指示点（指示点数量对应图片数量）。所以这一节只做展示视图，属性配置沿用上一节图片组件的配置组件占位。

### 组件放在 `share` 公共子项目

低代码平台的组件视图统一放在 `share` 子项目的 `components/` 目录下，本节新建一个目录（如 `LowCodeSwiper`），`index.ts` 里同时导出类型与组件。这样 `client`（编辑态）和 `release`（发布态）都能引用同一份渲染实现，避免两套代码不一致。

### 用 `Carousel` 渲染 `images`

视图实现很轻：用 Ant Design 的 `Carousel`（走马灯）作为容器，从父组件传进来的 props 里取 `images` 数组，遍历每一项，复用之前写好的 `ImageComponent`，把图片和 `key` 传进去即可。属性配置发生变化时，重置属性并重新渲染，保证画布与配置同步。

复用的价值在这里体现得很明显：轮播图不需要再写一遍图片加载、占位、样式，只是把多个图片组件塞进一个可切换的容器里。

### 类型定义与默认值

`SwiperComponentProps` 大致包含这些属性：

- `id`：组件 ID；
- `interval`：轮播切换间隔，单位毫秒；
- `autoPlay`：是否自动播放；
- `images`：图片数组；
- `showIndicators`：是否显示指示点；
- 指示器方位：`bottom` / `top` / `left` / `right`，控制指示点放在图片上、下、左、右。

还要把它转成**通用组件类型**：通过泛型接口传入，剔除可选属性与图片配置属性；`id` 不需要在属性面板里展示，设 `isHidden: true`。取值上同时准备 `defaultValue` 与 `value`——初始用默认值，用户改过之后以 `value` 为准，取不到 `value` 时回退到 `defaultValue`。默认配置是：播放时长 `3000` 毫秒（约 3 秒一张）、`autoPlay` 为 `true`（源码默认自动播放）、`showIndicators` 为 `true`、方位 `bottom`。

在 `share` 的 `index.ts` 里补两处导出：一是通用的 `Swiper` 组件类型（含 `id`、`type`、`props` 等通用字段），二是 `Swiper` 组件本身，这样其它子包才能按统一方式引入。

### 别忘重新打包 `share`

这是最容易漏的一步：改完 `share` 里的组件与导出后，必须执行一次 `share` 子包的打包（如 `pnpm build:share`）。`client` 通过 workspace 依赖引用的是 `share` 构建产物，不重新打包，前端就找不到新增的 `Swiper` 组件，直接报错。养成「改 share → 打包 → 刷新页面」的习惯，能少踩很多莫名其妙的模块找不到。

### 把属性面板暂时指向 `images`

本节还没做轮播图专属的属性配置，所以先把 `getComponentPropsByType` 映射（ComponentFields），沿用图片组件的配置组件占位。等下一节课把轮播图属性组件做出来，再切换到对应面板，届时就能设置指示点、播放速度、图片数量等。

从第三个组件开始，重复逻辑（定义类型、导出、视图渲染、打包）已经很清楚，后面每新增一个组件都会按「左侧点击展示视图 + 右侧属性配置」成对推进，节奏会明显加快。

`client` 子包通过路径别名引用源码，见 `代码（已8期）/代码（已8期）/15-3/lowcode/packages/client/tsconfig.json`：

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "useDefineForClassFields": true,
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "skipLibCheck": true,

    /* Bundler mode */
    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "resolveJsonModule": true,
    "isolatedModules": true,
    "noEmit": true,
    "jsx": "react-jsx",

    /* Linting */
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noFallthroughCasesInSwitch": true,
    "baseUrl": ".",
    "paths": {
      "~/*": ["src/*"]
    }
  },
  "include": ["src"],
  "references": [{ "path": "./tsconfig.node.json" }]
}
```

`baseUrl` 与 `paths` 里的 `~/*` 别名让组件引用不必写一长串相对路径；`client` 的 `package.json` 里以 `@lowcode/share: workspace:^` 依赖共享子包，`mobx-react-lite`、`ulid` 等也在此阶段引入，为后续组件状态与唯一 ID 做准备。

## 小结

- 轮播图展示视图与图片组件同源，单图时效果一致，差异在右侧属性配置。
- 组件放在 `share` 子项目 `components/` 下，`index.ts` 同时导出类型与组件，供 client 与 release 复用。
- 用 Ant Design `Carousel` 遍历 `images` 数组，每项复用 `ImageComponent`，属性变化时重渲染。
- `SwiperComponentProps` 含 `id`、`interval`、`autoPlay`、`images`、`showIndicators` 与方位；默认 3000ms、默认自动播放（`autoPlay=true`）、显示指示点、方位 `bottom`。
- 改完 `share` 必须重新打包，否则前端找不到新组件；属性面板暂时指向 `images` 占位。
