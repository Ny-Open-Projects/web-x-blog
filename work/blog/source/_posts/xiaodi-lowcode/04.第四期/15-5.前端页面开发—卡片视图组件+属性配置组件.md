# 前端页面开发—卡片视图组件+属性配置组件

> **导语**：卡片是低代码平台里最典型的一类组件：一张封面图，加标题和描述，右侧恰好三个可配属性。本文用卡片把「视图组件 + 属性配置组件」这对组合一次做完，并借此讲透一个反复出现的规律——右侧改了数据，中间视图为什么能同步刷新，也就是 React 里需要自己实现的双向数据流。

## 前置知识

建议先读《前端页面开发—轮播图组件配置属性》，此时组件抽离、`componentExport` 出口与 store 结构都已熟悉。另需了解 Ant Design 的 `Card` 与 `Card.Meta`、`Form.Item` 二次封装，以及 `useMemo` 监听 props 变化的写法。配套工程见 `代码（已8期）/代码（已8期）/15-5/lowcode/`。

## 正文

### 卡片视图长什么样

点击左侧的卡片组件，中间画布展示的样式分两部分：上方是一张 600×200 的兜底封面图，下方是标题与描述。右侧属性面板有三项：封面图片、标题、描述。

封面图片这项比较特殊：等图片资源上传逻辑开发完，点击会打开弹窗，从本地选图上传后替换显示。当前阶段先用默认值占位，把上传逻辑注释留好。

### 视图组件：Ant Design Card + Meta

在 `share` 的 `components` 下新建 `LowCodeCard` 目录（share 侧）与 `LowCodeComponents/LowCodeCard`（client 侧），`index.ts` 统一抛出类型与组件。视图组件本身很薄：

```tsx
export const CardComponent = (props: ICardComponentProps) => (
  <Card cover={<img src={props.coverImg} alt="" />}>
    <Card.Meta title={props.title} description={props.description} />
  </Card>
);
```

`Card.Meta` 直接承接 `title` 与 `description`，封面用 `<img>` 读 `coverImg`。组件值不能写死，而是通过 `useMemo` 监听 store 里的 props 变化重新获取：数据变了，组件重新渲染。

默认值定义在 `cardComponentDefaultConfig`：600×200 的 `coverImg`、`title`、`description`。每项配置都是含 `value`、`defaultValue`、`isHidden` 的对象——这是全平台通用的配置形态，属性面板靠 `isHidden` 决定显不显示某项。

### 新增组件要改三处

按前面的架构，每加一个组件都要同步三个地方，漏一个就拿不到组件：

1. `localCard/index.ts` 抛出组件与类型；
2. `types.ts` 里新增 `TCardComponentConfig`，以及卡片属性类型（`coverImg`、`title`、`description`），并联合进通用组件类型；
3. `componentExport` 的 `componentList` 里注册这一项。

本阶段 `tsconfig.json` 里的路径别名让这些引用更简洁：

```json
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "strict": true,
    "baseUrl": ".",
    "paths": { "~/*": ["src/*"] }
  }
}
```

右侧属性配置组件放在前端 `src/components` 下新建的 `localCard` 里，同样由二次封装的外层 `Form` 加里层 `Form.Item` 组成，把三个属性作为参数传进去。属性面板里用 `useMemo` 依据 store 数据重置表单值；`isHidden` 控制是否隐藏某项。封面图片那项先注释占位，等资源上传接口完成再补。

最后别忘了把右侧大组件里原先用于占位的写法，替换成这套「按代码取默认配置」的正常实现。

### 双向数据流：改数据，视图跟着变

实际操作一下：手动把封面图改成一个不存在的地址，右侧数据一变，中间那张图立刻加载失败；改标题、改描述，画布也是实时更新。这背后的链路值得画清楚：

```
右侧属性面板（改 title）
        ↓ 触发 updateCurrentComponent
store.componentConfigs[id].props.title  ← MobX 响应式更新
        ↓
中间视图通过 useMemo 从 store 取 props → 重新渲染
```

也就是说：**视图改变要写回 store，store 改变要响应式同步回视图**。在 Vue 里框架替你做了这层双向绑定，React 是单向数据流，得自己按这个规律把两头皮筋接起来。前面讲过的每一个组件都遵循同一条道理，理解之后，自己新增任意组件都不难。

## 小结

- 卡片视图用 Ant Design `Card` + `Card.Meta`，属性只有封面图、标题、描述三项。
- 封面图依赖后续 OSS 上传弹窗，当前阶段先注释占位、用默认值。
- 新增组件必须同步改三处：组件 `index.ts` 抛出、`types.ts` 加类型、`componentExport` 注册。
- 通用配置形态是 `value` / `defaultValue` / `isHidden` 三件套，`isHidden` 控制属性显隐。
- React 下双向数据流要自己实现：右侧改值写回 store，视图再从 store 响应式取数。
