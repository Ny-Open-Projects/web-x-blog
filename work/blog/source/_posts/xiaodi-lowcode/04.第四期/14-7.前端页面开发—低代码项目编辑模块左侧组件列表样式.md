# 前端页面开发—低代码项目编辑模块左侧组件列表样式

> **导语**：编辑器左侧那排可点击添加的组件入口（拖拽排序发生在画布内），本质是"配置数组 + 公共样式子组件"。本文讲清如何用两份配置数组分别管理展示型组件与问卷输入型组件，抽出一个带 icon / name / type 的公共子组件循环渲染，并用 interface 消除 any 警告。读完你会掌握用数据驱动列表、避免重复 JSX 的组件化思路。

## 前置知识

建议先读《前端页面开发—低代码项目编辑模块整体布局》，了解编辑器左 / 中 / 右三栏的职责划分；再熟悉 React 的 map 渲染与 key、TypeScript 的 interface，以及 Ant Design 中 Tabs、Divider 等基础组件——不熟悉的话按组件名去 Ant Design 官网搜索即可。

## 正文

### 左侧列表要渲染什么

这一集把提前开发好的组件引入进来（export default 抛出），就能看到左侧的组件列表。它分成两组：

第一组是**展示型组件**：轮播图、视频、卡片、列表、二维码、图片等，用于搭建官网/落地页内容。第二组是**输入型组件**：输入框、文本域、单选框、多选框，属于问卷系统——用户访问发布后的页面时，通过这些组件填写内容，平台借此收集信息。两组之间用 Ant Design 的 Divider 分割线隔开。

一旦想清楚"两组的每一项长得都一样，只是图标和文字不同"，实现方案就很自然了：把差异抽成数据，把共性抽成组件。

### 两份配置数组 + 一个公共样式组件

代码里定义了两个配置数组：components 存展示型组件，componentByUserInput 存输入型组件。数组里每个元素是一个对象，含三个属性：type（组件类型）、name（显示名称）、icon（图标）。

公共样式组件 EditorComponent 负责渲染每一项，它用 React 的 FC 函数式组件配合泛型，把入参通过 interface 明确定义下来——否则传入对象的属性会被推断为 any，TypeScript 会给出警告：

```tsx
interface EditorComponentProps {
  icon: React.ReactNode;
  name: string;
  type: string;
}

const EditorComponent: FC<EditorComponentProps> = ({ icon, name, type }) => {
  return (
    <div className="edit-component-item">
      {icon}
      <span>{name}</span>
    </div>
  );
};
```

（结构对应视频演示；配套前端工程见 `代码（已8期）/代码（已8期）/14-7/lowcode/packages/client/`。）

渲染时循环 map 配置数组，用展开运算符把每个对象的 type / name / icon 插进 EditorComponent，并记得补上唯一 key——和 Vue 里 v-for 必须有 key 是同一个道理：

```tsx
{components.map((item) => (
  <EditorComponent key={index}（源码按 index；按 type 亦可，教学演示如此） {...item} />
))}
```

### icon 从哪来

icon 直接从 @ant-design/icons 里按需引入，引入进来的就是一个 React 组件，放进配置数组即可。个别组件比较特殊：二维码这一项的 icon 暂时用了一张本地图片（xdclass.net.svg），通过 `<img src>` 渲染，而不是图标组件。想找某个图标叫什么名字，去图标库按名称搜索就能定位。

### type 为什么现在就要带上

type 在当前这一集还用不上，但提前存进配置里是有意设计：后续点击组件时，需要区分它是"配置展示型组件"还是"问卷输入型组件"，走不同的逻辑分支。把这类判别信息随配置一起维护，等逻辑变复杂时就不必回头大改数据结构。

### 抽离带来的收益

对比"一个一个手写列表项"的做法：不抽离子组件时，几十个组件的 JSX 会堆成一长段，样式重复、逻辑臃肿、改一处要动一片。现在用数组管配置、用公共子组件管样式，新增一个组件只需往数组里加一个对象，列表和渲染逻辑都不用动——这正是低代码编辑器本身也在贯彻的"配置化"思想。

## 小结

- 左侧列表分两组：展示型组件与问卷输入型组件，用 Ant Design 的 Divider 分隔。
- 差异抽成两份配置数组（每项含 type / name / icon），共性抽成公共样式组件 EditorComponent。
- 用 FC + 泛型 + interface 定义入参类型，避免属性被推断为 any 产生警告。
- map 渲染时用展开运算符传参并补唯一 key；icon 来自 @ant-design/icons，二维码项暂用本地图片。
- type 提前写入配置，为后续区分组件类型、走不同逻辑留出扩展点。
