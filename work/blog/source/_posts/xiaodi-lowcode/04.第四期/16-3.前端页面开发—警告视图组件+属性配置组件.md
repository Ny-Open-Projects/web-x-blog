# 前端页面开发—警告视图组件+属性配置组件

> **导语**：警告组件是发布官网类页面组件的最后一个。它把前面反复练过的模式又走了一遍——Ant Design `Alert` 接四个参数，右侧用 `Select` 与两个 `Switch` 做配置，改动写回 store 再同步到视图。本文顺带把这一阶段的收尾工作与后续排期理清楚：资源上传接口、预览、草稿、排序、键盘操作，哪些先做、哪些后补。

## 正文

### 警告组件暴露哪些属性

`Alert` 在中间画布里可以展示成功提醒、提示信息、警告、错误等样式。配置属性面板提供四项：

- `type`：四种取值——`success`、`info`、`warning`、`error`；
- `title`：提示文本内容（渲染时才映射为 antd Alert 的 message）；
- `showIcon`：是否显示辅助图标；
- `showClose`：是否显示关闭按钮（渲染时映射为 antd 的 closable）。

视图侧就是按 `store` 里维护的这四个值渲染 `Alert`；类型定义上，`type` 是四种字面量联合，其余为 `boolean` 或 `string`，并统一转成含 `defaultValue`、`value`、`isHidden` 的表单配置形态。默认给 `warning`，需要时改成 `success`、`info` 或 `error`。

### 属性面板：Select 加两个 Switch

前端 `src/components` 下的 `LowCodeComponents/LowCodeAlert/AlertComponentProps`，二次封装的外层组件传入竖向 `layout`，再逐项接：

```tsx
<FormContainer layout="vertical" onValuesChange={updateCurrentComponent}>
  <Form.Item name="title" label="请输入文本">
    <Input />
  </Form.Item>
  <Form.Item name="type" label="类型">
    <Select options={alertTypeOptions} />
  </Form.Item>
  <Form.Item name="showIcon" label="是否显示图标">
    <Switch />
  </Form.Item>
  <Form.Item name="showClose" label="是否显示关闭按钮">
    <Switch />
  </Form.Item>
</WrapperForm>
```

- 文本用 `Input`，类型用 `Select` 从配置实体里取选项；
- 两个布尔值各用一个 `Switch`；
- 表单变化触发 `updateCurrentComponent`，把改动写回 store；
- store 变化后通过 `useMemo` 重置表单与视图，完成同步。

这里再次印证那条规律：视图改变要影响 store，store 改变也要**响应式**同步回视图。前面讲过的每个页面组件都是这个道理，区别只在属性个数。

### 为什么值得反复练这套模式

经过这么多组件示例，重点其实不在某个组件本身，而在「复杂 React 项目里如何规整逻辑」。把类型、默认值、视图、属性面板按固定目录拆开，别人接手时能一眼看清链路；否则过几天自己回头看都会懵。面对公司里五花八门的需求，有稳定的开发思路、代码便于维护，比多写几个组件重要得多。

### 收尾排期：还差哪些逻辑

发布官网类页面组件到这一节就全部完成了，接下来进入问卷系统类的四个组件。但在此之前还有一批「欠账」要补：

1. **先补三个资源接口**：OSS 上传、获取、删除。视频组件要传本地视频、图片组件要传本地图片，替换后才能真正发布出可访问的页面。弹窗里还要读取历史上传记录回显。
2. **再补交互逻辑**：预览、草稿、拖拽排序、键盘排序与删除。
3. **最后补齐主链路**：发布接口还差两条，页面组件获取也差两条。

顺序上坚持「一个脚印一个脚印来」：多个逻辑一起讲容易懵，一步步拆开才都能理解清楚。

## 小结

- 警告组件基于 Ant Design `Alert`，暴露 `type`、`message`、`showIcon`、`closable` 四项。
- `type` 四种取值（`success` / `info` / `warning` / `error`），布尔项用 `Switch`，类型项用 `Select`。
- 表单 `onValuesChange` → `updateCurrentComponent` → store → `useMemo` 同步视图，规律与前面组件一致。
- 组件按类型 / 默认值 / 视图 / 属性面板固定拆分，便于维护与协作。
- 后续先补 OSS 上传 / 获取 / 删除三接口，再补预览、草稿、排序、键盘操作与发布链路。
