# 第1集_项目自动化部署上线—更改线上_ip+端口

> **导语**：自动化部署配置全部就绪，正式上线前必须先把代码里写死的"本地 IP + 端口"改成线上服务器的值。本文按模块梳理需要修改的所有位置：Nginx 配置、docker-compose 端口、React 编辑平台请求地址、Nest 服务端渲染请求后端的地址，并提醒开放阿里云安全组。

## 前置知识

- 已完成《DevOps自动化部署实现—多个镜像运行在服务器配置《下》》，理解了四个镜像变量与一键启动。
- 清楚本平台的服务端口规划，参见《项目部署上线—Docker-compose运行多容器的配置》。

## 正文

### 先看懂端口规划

`docker-compose.yml` 里四个服务对外暴露的端口是固定约定，上线前心里要有数：

```yaml
services:
  backend:         ports: - "5001:3000"   # 后端 NestJS 直连
  backend_nginx:   ports: - "5000:80"     # 后端 Nginx 代理（前端统一访问 5000）
  frontend:        ports: - "4001:3000"   # 前端发布直连
  frontend_nginx:  ports: - "4000:80"     # 前端发布 Nginx 代理（访问发布页用 4000）
```

约定：外部访问后端统一走 Nginx 代理端口 **5000**；访问前端发布页统一走 Nginx 代理端口 **4000**。

### 修改两处 Nginx 配置里的后端地址

Nginx 需要反向代理到后端服务，所以最终仓库的两份 conf 已用 `host.docker.internal`（配合 compose `extra_hosts: host.docker.internal:host-gateway`），无需写死公网 IP；「改 IP」适用于课程阶段写死地址的做法：

- `nginx/server.nginx.conf`：代理后端服务，端口填 **5001**（Nginx → 后端 5001）；
- `nginx/release.nginx.conf`：前端发布 Nginx 代理，端口填 **4001**（Nginx → 前端发布 4001）。

### 开放阿里云安全组

登录阿里云，进入实例 → **安全组** → 管理规则，把 `4001`、`5001`、`4000`、`5000` 四个端口都放行，否则外部访问会直接失败。

### 修改 React 编辑平台（client）的请求地址

编辑平台有两处地址要改：

1. **发布页请求前端发布项目**：在 `client` 项目的发布路由页面（如 `release.tsx`）里，最终仓库这些地址走环境变量：client 为 `VITE_API_BASE_URL` / `VITE_RELEASE_BASE_URL`，release 为 `NEXT_PUBLIC_API_BASE_URL`（构建期注入），改 `.env` 不必改源码；课程阶段做法是直接改源码里的 IP服务器 IP，端口用 **4000**（走 Nginx 代理）；
2. **请求后端接口**：在 `client/utils/request.ts` 二次封装的 axios 基址里，把 IP + 端口改成线上后端 Nginx 代理地址，端口用 **5000**。

### 修改 Nest 服务端渲染项目请求后端的地址

前端发布（Next.js）项目调用后端接口的文件也要统一改：

- `src/components/ComponentRender.tsx`：检查是否已提交问卷等接口；
- `page.tsx`（发布页组件获取接口）：请求获取发布页组件的接口；
- 这些文件里的后端 IP + 端口同样改为线上后端 Nginx 代理地址（端口 **5000**）。

### 提交代码

所有涉及上线的 IP 与端口改完后，统一提交到远程仓库（注意改成你自己的服务器 IP 和对应端口），流水线才能拉到正确配置。

## 小结

1. 端口约定：后端代理 5000、后端直连 5001、发布页代理 4000、发布页直连 4001。
2. 两处 Nginx 配置（`nginx/server.nginx.conf`、`nginx/release.nginx.conf`）的后端地址要改成线上值。
3. 阿里云安全组必须开放 4000 / 4001 / 5000 / 5001 四个端口。
4. React 编辑平台改 `release.tsx`（发布页，端口 4000）与 `request.ts`（后端，端口 5000）。
5. Nest 服务端渲染项目改 `componentRender.tsx`、`page.tsx` 里的后端地址（端口 5000），改完提交代码。
