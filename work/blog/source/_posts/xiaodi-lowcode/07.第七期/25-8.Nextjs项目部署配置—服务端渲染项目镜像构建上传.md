# Nextjs项目部署配置—服务端渲染项目镜像构建上传

> **导语**：本集补齐前端发布（Next.js）项目本身的镜像，至此四个镜像全部构建完成。同时我们整体回顾一下整个构建阶段：React 打包上传 OSS、compose 文件暂存、四个镜像推送 ACR，为下一步部署到自有服务器做好准备。

## 前置知识

- 已完成《Nextjs项目部署配置—服务端渲染Nginx镜像构建上传》，已构建前端发布 Nginx 镜像。
- 前端发布项目镜像的 Dockerfile 建议结合《项目部署上线—构建前端发布Nextjs镜像的Dockerfile配置》理解。

## 正文

### 构建前端发布项目镜像

在前端发布的并行任务里再**添加一个步骤**，选择**阿里云镜像构建个人版**（个人仓库版本）：

- 步骤名称：`部署前端release项目镜像`；
- 地域：广州；
- 仓库 / 命名空间：`local-images`；
- **标签（Tag）**：自定义为 `frontend-<环境变量>`，对应 `docker-compose.yml` 里的 `frontend_tag`；
- **Dockerfile 路径**：填 `release.Dockerfile`。

```yaml
# docker-compose.yml 中前端发布服务的镜像引用
frontend:
  image: ${frontend_tag}
  restart: always
  ports:
    - "4001:3000"
```

执行后任务输出会给出 `frontend-<环境变量>` 这个标签，以及前端项目镜像本身。

### 构建阶段全景回顾

到目前为止，构建阶段（第一阶段）完成了三件事：

1. **React 编辑平台**：打包构建出 `dist` → 上传阿里云 OSS Bucket（即 25-3 的 `lowcode-client`）；
2. **docker-compose.yml**：归档到云效公共存储空间，供后续部署阶段拉取；
3. **四个镜像**：后端项目、后端 Nginx、前端发布项目、前端发布 Nginx，全部推送到 ACR 的 `local-images` 命名空间。

```yaml
# 四个服务与端口映射一览（docker-compose.yml）
services:
  backend:         # 后端 NestJS  -> 5001:3000
  backend_nginx:   # 后端 Nginx   -> 5000:80
  frontend:        # 前端发布     -> 4001:3000
  frontend_nginx:  # 前端发布Nginx-> 4000:80
```

### 下一步要做什么

构建阶段完成后，需要新建一个**部署阶段**：先把 `docker-compose.yml` 上传到自己的服务器，再从 ACR 拉取四个镜像，最后 `docker compose up -d` 一键启动。

## 小结

1. 前端发布项目镜像标签为 `frontend-<环境变量>`，对应 `frontend_tag`。
2. 对应的 Dockerfile 是 `release.Dockerfile`。
3. 四个镜像（后端项目 / 后端 Nginx / 前端发布项目 / 前端发布 Nginx）已全部推送到 ACR。
4. 构建阶段三件事：React 打包上传 OSS、compose 文件暂存、四个镜像推送。
5. 后续部署阶段只需把文件拉到自有服务器并 `docker compose up`。
