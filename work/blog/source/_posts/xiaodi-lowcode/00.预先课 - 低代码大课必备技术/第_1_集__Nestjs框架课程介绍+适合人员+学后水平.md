# Nestjs框架课程介绍+适合人员+学后水平

> **导语**：本文是《全栈多端低代码平台项目大课》预先课的第一集，带大家认识本课要学的核心后端框架 NestJS，搞清楚它适合哪些人、学完能达到什么水平，并预览最终要落地的低代码平台项目。

## 前置知识

无需前置基础即可阅读。本文是预先课的开篇，后面会逐步展开 NestJS 的环境搭建、装饰器、Providers、控制器、拦截器、DTO、TypeORM、JWT 等知识点，建议接着看《Nestjs环境搭建和项目创建》。

## 正文

### 为什么要学 Node 后端框架

作为前端开发工程师，想要进阶为全栈，Node 后端几乎是必学的一环。日常开发 Node 后端接口，我们通常不会裸写，而是通过框架来提效，常见的选择有 Express、Koa，以及近期最热门、速度和便利性都很突出的 **NestJS**。

- 如果你是**前端工程师**，想往全栈或高级前端走，NestJS 是很好的切入点。
- 如果你是**后端工程师**，也可以学习 NestJS；尤其是 Java 工程师，上手会非常快，因为 NestJS 的设计思想（控制反转、依赖注入）跟 Spring 等 Java 体系高度相似。多掌握一门 Node 后端能力，就多一个就业方向。
- 如果你是**全栈工程师**，想进一步补齐后端工程化能力，同样适合学习本课。

### 从招聘市场看 NestJS 的需求

打开 Boss 直聘直接搜索 Node 相关岗位，可以看到大量「Node 后端开发工程师」「Node 开发工程师」的招聘。其中和 TypeScript 契合度最高的，就是 NestJS。不少岗位描述写明：使用 NestJS 进行后台开发，为前端提供接口。

- 初级到中级 Node.js 岗位薪资集中在 8K~13K。
- 例如广州番禺 12K~20K 的 Node.js 岗位，要求 Express 或 NestJS 均可。
- 深圳 20K~30K 的中高级前端开发工程师岗位，也会要求能用 Node.js 完成后端基础的 CRUD，并掌握 NestJS。

前端求职竞争激烈时，多学一个 Node 后端框架，求职面会更广，对工程化思路和理解深度也有帮助。

### 学完课程你能达到什么水平

通过本课，你将全方位了解 NestJS 的「全家桶」：

- 使用 **Nest CLI** 脚手架创建项目；
- 理解**装饰器（Decorator）**、**Providers（提供者）**、**控制器（Controller）**；
- 掌握各类**拦截器（Interceptor）**与**管道（Pipe）**；
- 使用 **DTO（Data Transfer Object）** 约束接口入参；
- 基于 **TypeORM** 这一 ORM 框架操作 **MySQL** 数据库，并实现实体与数据库的同步；
- 在 NestJS 中实现 **JWT** 权限校验；
- 理解并自定义**依赖注入（DI）**，包括全局依赖注入；
- 理解 NestJS 的核心设计思想——**控制反转（IoC）** 与**依赖注入（DI）**。

前端部分，课程会结合 **React** + **Ant Design** + **Tailwind CSS** 开发页面，并调用上面这些后端接口，完成用户注册、登录以及课程的增删改查。

### 项目实战效果预览

课程最终会交付一个完整的课程管理项目，大致包含：

1. 登录 / 注册页面（样式从简，重点演示后端接口能力）；
2. 登录后进入课程管理页，展示课程列表；
3. 支持课程的**创建、编辑、删除、分页**；
4. 所有数据均来自后端接口，由前端请求后渲染。

代码层面分为前端与后端两份工程。后端使用 NestJS，开发接口时按业务**分模块（Module）**。例如用户相关逻辑放在 `user` 模块，课程相关放在 `course` 模块。每个模块都有自己的 `module`、`controller`（控制层）与 `service`（数据层 / 服务层）。

以用户模块为例，它的 `module` 里需要提前声明要注入哪些依赖，在使用的地方直接声明即可。依赖通常是一个类，而类的实例化等工作全部交给 NestJS 框架完成。在控制器里通过 `this.userService.xxx()` 就能直接调用服务层封装的业务逻辑。

后端工程整体结构还包括：公共配置、公共拦截器、主模块 `app.module.ts`，以及自定义的工具类与依赖。

### 课程的学习形式

课程以「视频讲解 + 文字笔记 + 代码分析 + 交互流程图 + 配套源码」的形式呈现，并提供技术交流群免费答疑。配套工程采用 pnpm 管理的 monorepo 结构，根目录的 `pnpm-workspace.yaml` 通过 `packages: - "packages/*"` 把多个子包纳入同一工作空间，便于前端、后端、公共包统一协作。

## 小结

- NestJS 是当前最热门的 Node 后端框架，设计思想借鉴 Java 体系，适合前端、后端、全栈工程师进阶学习。
- 招聘市场上 Node 后端（含 NestJS / Express / Koa）岗位需求较大，掌握它能拓宽求职面。
- 本课带你掌握 NestJS 全家桶：装饰器、Providers、控制器、拦截器、DTO、TypeORM、JWT、依赖注入。
- 前端采用 React + Ant Design + Tailwind CSS，对接后端接口完成注册、登录与课程 CRUD。
- 工程以 pnpm-workspace 多包形式组织，便于多端协同开发。
