# 初出茅庐—使用 Nextjs 创建初始化项目

> **导语**：技术栈定下 Next.js，本章是它的快速入门。本文带你从安装 Node、用 `create-next-app` 脚手架初始化工程，到切换 pnpm 依赖、理解 `package.json` 脚本、启动开发服务器并认识 `src/app` 路由目录。

## 前置知识

建议先看《大展经纶—低代码项目大课的技术栈选择》，确认发布端选用 Next.js。需要一台已联网的电脑。

## 正文

### 第一步：确认 Node 环境

Next.js 运行在 Node 之上。先看本机是否安装 Node：

```bash
node -v
```

课程演示环境是 **18.18**。若未安装，到 Node 官网下载：左侧是稳定版（演示时约 20.9），右侧 21.1 为尝鲜版（新特性但不稳定），学习用建议选稳定版，按系统（Windows / macOS 64 位）下载安装即可。

### 第二步：理清包执行器与包管理工具

- **包管理工具**：`npm`、`pnpm`、`yarn`——负责安装与管理依赖；
- **包执行器**：`npx`——负责执行 npm 包提供的命令行工具，本身不是包管理器。

Node 18 自带 `npx`（约 9.8.1），无需单独安装。

### 第三步：用脚手架创建项目

官方推荐用 `create-next-app` 创建第一个 Next.js 项目：

```bash
npx create-next-app next-test
```

执行后会进入交互式选项（底色深时部分提示看不清，按需选择即可）：

- 项目名：`next-test`
- 是否使用 **TypeScript**：Yes
- 是否使用 **ESLint**：No（课程选择）
- 是否使用 **Tailwind CSS**：Yes
- 是否使用 `src/` 目录存放业务代码：Yes
- 是否使用 **App Router**（官方推荐路由方式）：Yes
- 另一个额外选项：No

创建完成后，桌面会出现 `next-test` 工程。

### 第四步：改用 pnpm 并启动

默认用 npm 下载依赖（生成 `package-lock.json`）。课程改用 **pnpm** 以获得更快安装速度——删除 npm 产物后，用 pnpm 重新安装。

打开 `package.json`，`scripts` 里就是运行命令：

```json
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start",
    "lint": "next lint"
  }
}
```

启动开发服务器：

```bash
pnpm dev
```

终端会输出本地地址（默认 `http://localhost:3000`），浏览器打开即可看到初始页面。

> 若 IDE 报「找不到模块」之类的引入警告，可执行 VS Code 的 `Reload Window`（macOS 用 `Cmd+Shift+P` 调出命令面板选第一个）重新加载，让配置生效。

### 第五步：认识目录与新建路由

业务代码统一放在 `src/` 下；Next.js 的**文件路由**由 `src/app` 目录承载。新建一个路由页面很简单：在 `app` 下建一个文件夹，里面放 `page.tsx` 即可。

最后把本次初始化提交到本地仓库，方便后续演进。

## 小结

1. 先确认 Node（建议稳定版，课程用 18.18）。
2. `npx` 是包执行器，`npm/pnpm/yarn` 是包管理工具。
3. `npx create-next-app` 交互选项：TS=Yes、ESLint=No、Tailwind=Yes、src=Yes、App Router=Yes。
4. 改用 pnpm 安装更快，依赖锁文件为 pnpm 风格。
5. `package.json` 的 `dev/build/start/lint` 对应启动、构建、运行生产、检查。
6. 路由基于 `src/app` 目录，新建文件夹 + `page.tsx` 即新页面。
