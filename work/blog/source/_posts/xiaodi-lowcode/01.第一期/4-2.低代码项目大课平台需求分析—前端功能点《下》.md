# 低代码项目大课平台需求分析—前端功能点《下》

> **导语**：本文承接前端功能点《上》，聚焦低代码平台「后台数据统计」模块的功能需求。我们将通过已开发完成的项目，讲解问卷数据收集、Excel/压缩包导出、动态图表统计等能力，并顺势引出三端工程结构与公共复用（share）的雏形。

## 前置知识
阅读本文建议先看完《低代码项目大课平台需求分析—前端功能点《上》》，了解注册登录与低代码编辑页面的功能点。

## 正文

### 后台数据统计要解决什么问题
低代码平台的编辑端用于「搭建页面并发布」，而发布页（H5）往往包含问卷组件（输入框、文本域、单选框、多选框等）。当用户访问发布页并填写提交后，这些数据需要被集中收集、查看与统计——这就是后台数据统计模块的职责。

需要注意一个前提：**如果发布的页面中没有包含任何问卷组件，后台就不会有可统计的数据**；只有用户真实提交后，表格与图表才有内容。

### 表格收集与导出
后台数据统计左侧是一张表格，逐行展示每一位填写者的提交数据。结合项目中问卷组件的配置（如单选框标题「爱好」，选项可自定义为洗脚、按摩、看美女），表格会呈现对应用户填写的结果。

当数据量变大时，支持两种导出方式：

- **导出 Excel**：通过 Office / WPS 打开处理；
- **导出压缩包**：数据量大时体积更小，便于传输。

### 动态图表统计
右侧区域用于可视化展示统计数据：

- 顶部列出所有问卷组件的标题（如姓名、爱好、默认展示标题）及其类型（文本域、单选框、多选框）；
- 点击「查看数据」时，以图表形式呈现对比，例如饼状图、横向柱状图，以及多选框各选项的勾选分布。

需要特别注意的业务规则：**同一用户针对一个低代码页面只收集一次问卷信息**。后端会依据设备/用户维度做去重，重复提交会被拦截并提示「已提交过问卷」。

### 三端工程结构与公共复用
在演示部署后的代码时，可以看到所有业务代码都维护在 `packages` 目录下，分为三端：

- `client`：基于 React 的低代码编辑端与后台数据统计前端；
- `release`：基于 Next.js 的 H5 发布页（服务端渲染）；
- `server`：基于 Nest 的后端接口服务。

三者公共的组件与类型统一抽到 `share`子项目中，以最大化复用。多个子项目通过 pnpm-workspace 管理，具体实现留到后续章节讲解。

## 小结
- 后台数据统计依赖发布页中的问卷组件，无问卷则无数据；
- 表格支持分页、导出 Excel 与导出压缩包；
- 动态图表（饼状图、横向柱状图）用于对比问卷选项分布；
- 同一用户同一页面仅收集一次问卷，后端做去重；
- 工程上 client / release / server 三端共用 `share` 中的公共组件与类型。
