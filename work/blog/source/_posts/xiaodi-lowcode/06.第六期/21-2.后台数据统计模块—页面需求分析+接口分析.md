# 后台数据统计模块—页面需求分析+接口分析

> **导语**：问卷页面上线后，运营者需要在后台统计「哪些用户填了什么」。本文做需求分析：拆解左侧用户数据表格、右侧组件列表与动态图表的页面结构，并明确需要开发的三个后端接口。

## 前置知识

- 已了解发布页与问卷数据落库，见《低代码项目发布页面—需求分析》《低代码项目发布页面—后端接口提交问卷信息》。
- 已了解 `component` 表与 `component_data` 表，见《实战演练—低代码平台项目数据库设计》。

## 正文

### 页面结构总览

后台数据统计页面分左右两栏：

**左侧——用户提交信息统计表**
- 表头来自问卷组件的 `title`：如「姓名」（输入框）、「描述」（文本域）、「性别」（单选）、「爱好」（多选）；
- 表格内容来自 `component_data` 表中各用户填写/选择的值；
- 支持分页、换行，底部有「导出 Excel」「导出压缩包」入口。

**右侧——组件列表与动态图表**
- 顶部组件列表横向排列（姓名、描述、性别、爱好等）；
- 点击某组件「查看数据」展示图表：输入型（如姓名）只列出填写了哪些人；单选/多选这类固定选项才能生成图表；
- 默认展示第一个组件（姓名）的列表，点击性别/爱好则展示饼状图 + 横向柱状图，并标注各选项个数。

动态图表只对固定选项（radio、checkbox）生效，因为选项枚举已知；自由输入项无法聚合，只能罗列。

### 需要的三个后端接口

1. **获取问卷组件接口**：请求当前页面所有问卷类型组件，用于渲染左侧表头（及右侧组件列表），需登录鉴权。
2. **获取问卷组件内容接口**：请求 `component_data` 中各用户提交的内容，用于渲染左侧表格内容，需登录鉴权。
3. **通过组件 ID 获取某问卷组件内容接口**：点击右侧某组件时，按组件 ID 查 `component_data` 返回该组件所有用户的选择/输入，用于绘制动态图表，需登录鉴权。

### 数据来源澄清

- `component` 表：存组件自身配置（类型、`title`、`options` 选项列表），如单选「男/女」、多选「游泳/篮球/按摩」；
- `component_data` 表：存用户填写结果（组件 ID + `value`，如老王、女、游泳），第一个选项默认 ID 为空。

> 配套资料：需求文档见 `课程配套资料（笔记+资料）/全栈低代码平台需求文档.pdf`，流程图见 `图.drawio`。

## 小结

1. 页面左栏统计用户问卷提交（表头来自组件 `title`，内容来自 `component_data`）。
2. 右栏展示组件列表与动态图表，仅 radio/checkbox 类固定选项能出饼图+柱状图。
3. 需三个接口：获取问卷组件、获取问卷组件内容、按组件 ID 获取内容，均需登录。
4. 组件配置在 `component` 表，用户填写在 `component_data` 表。
