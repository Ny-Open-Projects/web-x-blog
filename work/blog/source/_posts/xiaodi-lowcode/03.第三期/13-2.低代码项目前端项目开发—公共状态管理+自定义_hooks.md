# 低代码项目前端项目开发—公共状态管理+自定义 hooks

> **导语**：本文用 MobX 搭建前端的**公共状态管理**，并封装自定义 hooks `useStoreAuth`，把「是否登录」从 localStorage 中的 token 推导为响应式计算属性，从而替换上一节路由守卫里写死的 `isLogin`。

## 前置知识

- 已阅读《低代码项目前端项目开发—路由配置》，了解路由守卫中临时写死的 `isLogin`。
- 项目已安装 `mobx`、`mobx-react-lite`（或直接在 store 中使用 MobX API）。
- 了解 `localStorage` 存储 token 的基本用法。

## 正文

### 用 MobX 创建权限 store

在 `src/store/index.ts` 中，用 `makeAutoObservable` 把对象变为可观察：

```ts
import { makeAutoObservable, observable } from 'mobx';

export function createStoreAuth() {
  return makeAutoObservable({
    token: localStorage.getItem('token') ?? '',
    details: null
  });
}
```

`token` 初始化时从 `localStorage` 读取（空则用 `?? ''`），`details` 为用户信息，初始为 `null`。两者均为响应式。

### 分类维护 store 与 hooks

权限相关单独放一个文件，并在 `store/index.ts` 统一 `export *`：

```ts
export * from './author';
```

hooks 也分模块放 `src/hooks`，统一从 `hooks/index.ts` 导出。

### 封装 useStoreAuth

在 `src/hooks/auth.ts` 中：

```ts
import { computed } from 'mobx';
import { createStoreAuth } from '../store';

const store = createStoreAuth();

export function useStoreAuth() {
  const isLogin = computed(() => !!storeAuth.token);（直接引用 store 属性，computed 才能持续追踪）
  return { isLogin };
}
```

`computed` 把 token 强转为布尔值：有 token 为 `true`，无则为 `false`，且是响应式的。

### 在路由守卫中接入真实登录态

回到 `pages/index.tsx`，引入 `useStoreAuth` 替换写死的变量：

```ts
import { useStoreAuth } from '../hooks';

const { isLogin } = useStoreAuth();
```

`computed` 的值需通过 `.get()` 取出。启动项目后：

- `localStorage` 无 token → 默认显示登录注册页。
- 手动添加 `token=1` 并刷新 → 跳转到有权限的编辑页；删除 token 又回到登录页。

## 小结

- MobX 的 `makeAutoObservable` 接收对象参数，返回可观察（响应式）对象。
- 权限状态 `token`、`details` 从 `localStorage` 初始化，`details` 初始为 `null`。
- `useStoreAuth` 用 `computed(() => !!token).get()` 推导响应式 `isLogin`。
- store 与 hooks 都分模块维护，并在各自 `index.ts` 统一导出，方便复用。
