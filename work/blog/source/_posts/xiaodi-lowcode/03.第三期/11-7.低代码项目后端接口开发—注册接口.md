# 低代码项目后端接口开发—注册接口

> **导语**：本文在前几篇「图形验证码接口」「手机短信验证码接口」的基础上，继续开发低代码平台的**注册接口**。我们将从控制器、DTO 校验、服务层业务逻辑到自动登录的 JWT 签发一步步实现，并打通 Redis 验证码比对、密码加密、手机号查重等完整链路。

## 前置知识

- 已掌握《低代码项目后端接口开发—图形验证码接口》与《低代码项目后端接口开发—手机验证码接口》中 Redis 存储结构（`register:code:phone` 三层 key）。
- 了解 NestJS 的控制器（`@Controller`）、DTO 校验（`ValidationPipe` + class-validator）与 TypeORM 的 `Repository` 操作。
- 已配置 JWT 模块（`@nestjs/jwt`），知道 token 的 `secret` 与过期时间配置方式。

## 正文

### 控制器新增注册方法

在 `user.controller.ts` 中新增一个 POST 接口，路径为 `register`：

```ts
@Post('register')
async register(@Body() body: RegisterDto) {
  return this.userService.register(body);
}
```

这里通过 `@Body()` 拿到前端传来的参数，并交给 `userService.register` 处理。

### 注册 DTO 的参数校验

注册接口需要前端传递 **4 个字段**：

| 字段 | 含义 |
| --- | --- |
| `phone` | 手机号（账号） |
| `sendCode` | 用户填入的短信验证码 |
| `password` | 密码 |
| `confirm` | 确认密码 |

使用 `RegisterDto` 做类型与必填校验，任意一个为空或类型不正确，`ValidationPipe` 都会拦截并返回错误。

### 服务层：手机号查重

进入 `user.service.ts`，定义 `register` 方法，第一步是根据手机号查重，避免重复注册：

```ts
const existUser = await this.userRepository.findOne({
  where: { phone }
});
if (existUser) {
  throw new BadRequestException('该手机号已被注册');
}
```

### 校验短信验证码与 Redis 比对

注册时要把用户传入的 `sendCode` 与 Redis 中存储的验证码比对。验证码存储的 key 同样采用三层结构：

```
register:code:${phone}
```

取值后按 `_` 拆分为「时间戳 + 验证码」，取第二段与用户传入的验证码对比；若 Redis 中不存在，则提示「请先获取短信验证码」：

```ts
const redisKey = `register:code:${phone}`;
const exist = await this.redis.exists(redisKey);
if (!exist) {
  throw new BadRequestException('请先获取短信验证码');
}
const codeStr = await this.redis.get(redisKey);
const code = codeStr.split('_')[1];
if (code !== sendCode) {
  throw new BadRequestException('短信验证码不正确');
}
```

### 二次密码一致性校验

密码与确认密码必须一致，否则抛出「两次输入的不一致」。

### 随机头像、昵称与密码加密

用户数据入库前，利用封装好的 `RandomUtil` 随机生成昵称与头像：

```ts
const name = this.randomUtil.randomName();
const avatar = this.randomUtil.randomAvatar();
```

密码不可明文入库，需通过 `SecretUtil.getSecret(password)` 加密。

### 插入用户并自动登录签发 JWT

组装实体后调用 `userRepository.save` 入库，拿到自增 `id`：

```ts
const user = await this.userRepository.save({
  username: name, head_img: avatar, phone, password: pwd, open_id: ''
});
```

为了让用户体验更好，**注册成功后直接自动登录**，签发 7 天过期的 token（过期时间在 config.ts `signOptions.expiresIn` 全局配置，注册/登录共用）：

```ts
const token = this.jwtService.sign({ id: user.id });
return { data: token, msg: '注册成功' };
```

JWT 配置在 `config.ts` 中通过 `JwtModuleOptions` 提供 `secret` 与 `signOptions.expiresIn`，并在 `app.module.ts` 里通过 `JwtModule.register(config)` 全局注册，注册、登录接口均可复用。

### 接口联调验证

启动项目后，先在 Apipost 中依次请求「图形验证码 → 短信验证码（手机收到如 5837）→ 注册接口」，传入 `phone`、`password`、`confirm`、`sendCode`。接口返回 `data` 为 token，即表示注册 + 自动登录成功。

## 小结

- 注册接口是 POST `/user/register`，依赖 `RegisterDto` 做 4 个字段校验。
- 完整链路：手机号查重 → Redis 短信验证码比对 → 两次密码一致 → 随机昵称/头像 → 密码加密 → 入库 → 签发 7 天 JWT。
- Redis 验证码采用 `register:code:phone` 三层 key，按 `_` 拆分出真实验证码。
- 注册成功后直接签发 token 实现自动登录，提升用户体验。
