## 一句话总述
`mergo.Merge` 默认把 src 同名字段写进 dst **零值**字段；未导出不动，建议合并同类型实例。

## 面试官视角
- 意图：理解默认不覆盖语义与反射边界。
- P5 调用 / P6 三规则 / P7 WithOverride 代价。
- 红旗：以为 Merge 总覆盖；以为能合并不同类型。
- 惊艳点：dst 非零点默认不动，是"合并"非"赋值" —— 验证 `mergo.Merge` 默认 `Overwrite=false`。

## 主问答
**Q（面试官原话）：** 用 mergo 合并两个结构体，结果符合预期吗？
**A：**
1. **结论**：默认 `Merge(&dst, src)` 只覆盖 dst 的**零值**同名字段，非零点保留。
2. **机制**：反射按名匹配；dst 须同类型实例指针，未导出字段 `CanSet=false` 不参与。
3. **边界**：不同类型官方不建议合并，按名匹配默认不覆盖，结果难预期。
**加分层：** 强制覆盖用 `WithOverride`，会抹掉 dst 非零值。

## 关键代码
```go
// 示意，未验证：默认合并只覆盖零值字段
package main

import (
	"fmt"
	"log"

	"dario.cat/mergo"
)

type User struct {
	Name  string
	Hobby string
}

func main() {
	u1 := User{Name: "t3", Hobby: "swim"} // 非零点
	u2 := User{Name: "t4", Hobby: "ping"}
	if err := mergo.Merge(&u1, u2); err != nil {
		log.Fatal(err)
	}
	fmt.Printf("%+v\n", u1) // {t3 swim}，u2 未覆盖
}
```
