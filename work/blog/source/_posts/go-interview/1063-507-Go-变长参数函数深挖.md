> 原文锚点：第 1~46 段「变长参数规则/切片展开/可选参数/编译期求值(make/len/cap)/nil函数panic/函数选项模式」

## 思路与架构
变长参数是"切片语法糖 + 展开操作符"的组合：声明端 `...T` 退化为 `[]T`，调用端 `s...` 把切片展开。由此带出三个延伸——① 展开的正确姿态（打平 vs 整体）② 求值时机（数组 len/cap 编译期、普通函数运行期）③ 配置 API 设计（变长按序的局限 → Functional Options）。回答时以"语法糖本质"为主线串起。

## 方案取舍
```text
变长参数相关矩阵：
──────────────────────────────────────────────────────────────
点               结论                     易错/边界
声明             ...T 且最后、仅1个        多个变长参数非法
体内类型         []T 切片                 形参实参类型一致(含interface)
调用              s... 打平               直接传 s 整体→类型错
可选参数         必传+变长                按长度分支
求值时机         数组 len/cap 编译期      普通函数返回值运行期
函数边界         nil 函数调用 panic       死循环函数可无 return
配置设计         变长按序→Functional Options  异构可选配置用选项模式

设计法则：
- 变长参数=同类型同角色多值（append/日志字段）
- 异构可选配置→ Functional Options（Option=func(*T)）
- 数组 len/cap 可作 const 初值，切片不行
```

## 答题技巧
```text
面试话术（先语法后展开，再延伸）：
1. 语法：...T 仅1个且最后，体内为 []T，类型一致含 interface
2. 展开：s... 打平多参；直接传 s 整体→编译错
3. 求值：数组 len/cap 编译期常量；普通函数返回值运行期
4. 边界：nil 函数调用 panic；死循环函数无 return 合法
5. 设计：同构多值用变长；异构可选配置用 Functional Options
```

## 细节与核心 API

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums { total += n }
    return total
}
sum(1, 2, 3)            // 直接传散列参数
s := []int{1, 2, 3}
sum(s...)              // 切片展开传参（必须显式 ...）
// 变长参数本质是切片，但函数内不可 append 后影响调用方（底层数组共享仍可能）
func logf(prefix string, args ...interface{}) { fmt.Println(append([]interface{}{prefix}, args...)...) }
// 仅在最后参数可用 ...T；接口变长参数常配合 reflect 做泛型前替代
```
