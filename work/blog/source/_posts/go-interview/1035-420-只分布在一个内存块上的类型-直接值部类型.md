> 分类：Go 语言基础 · 内存布局 | 难度：L2 | 题型：分类题 | 频率：中 | 关键词：**直接值部**/**单内存块**/**bool/数值/指针/结构体/数组**/**无间接引用**
> 原文锚点：第 7~9 段「内存块=承载若干值部的连续内存片段；直接值部只分布在一个内存块；单块类型含布尔/数值/指针/结构体/数组」

## 一句话总述
Go 里"每个值只分布在一个内存块上"的类型，就是**直接值部类型**：**布尔、数值、指针（含 unsafe.Pointer）、结构体、数组**。判定法则一句话——**该类型的值不含任何指向其他内存块的指针/间接引用**，整块连续存储，复制时整体搬走。

## 面试官视角
- 考察意图：是否真正理解"哪些 Go 类型在内存里是连续的、哪些是分散的"，这是理解切片/map/逃逸的地基。
- 分档：P5 能说出 bool/int/struct/array 是连续；P6 能补上"指针类型本身也是单块"（指针值只是一个机器字）；P7 能给出判定法则"是否含间接引用"。
- 红旗：把 slice/string/map 也算进"单内存块"；或漏掉"指针类型本身单块"。
- 惊艳点：点出"指针类型的值（一个地址）只占一个机器字、是单块；但它**指向**的那块是间接值部"——区分"指针本身"与"指针所指"。

## 主问答
**Q（面试官原话）：** Go 里哪些类型的值只占用一个内存块？
**A：**
1. **标准答案（5 类）**：布尔、数值（int/float/complex/rune/byte）、指针（含 `unsafe.Pointer` 这种非类型安全指针）、结构体、数组——它们的值**整体落在一个连续内存块**里 `[经验]`。
2. **判定法则**：看值里**有没有指向别处内存的指针**。这 5 类类型自身不含间接引用，所以直接值部 = 全部值部，占单块；一旦类型里嵌了指针（如切片头、map 的 hmap 指针），值就被拆到多个块。
3. **易错点——指针本身是单块**：`*T` 的值只是一个机器字（地址），它自己只占一个内存块；它**指向**的 `T` 才是另一块（间接值部）。所以"指针类型"归单块，"被指的类型"另算。

## 关键代码
```go
// 单内存块类型：值整体连续，复制即整体搬走
type Point struct{ X, Y int64 } // 结构体：16B 同块
var a Point = Point{1, 2}
var b = a // 复制整个结构体（单块），b 与 a 互不影响

var p *int = new(int) // p 本身(指针)占 1 机器字=单块；*p 指向的 int 是另一块
```

## 总结与追问预判
"单内存块类型"= 不含间接引用的类型，判定法则是"看值里有没有指针"。含间接引用的类型（slice/map/chan/func/interface/string）会占多个块——见 420。本卡与 923-direct-indirect-part（传参拷贝直接部分）互补：923 讲"传值模型"，本卡讲"单内存块类型分类"这一面试题本身。
