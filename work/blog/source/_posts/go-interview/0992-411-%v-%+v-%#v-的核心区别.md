> 分类：Go 标准库 | 难度：中 | 题型：高频考点 | 频率：高 | 关键词：**%v、%+v、%#v、结构体、字段名、类型名**

> 原文锚点：第 105~108 段「%v / %+v / %#v 的区别」

## 一句话总述
三者都用于「默认格式」输出，区别在信息量：`%v` 只输出结构体各字段的**值**（不含字段名）；`%+v` 同时输出**值 + 字段名**；`%#v` 输出最完整——值 + 字段名 + **结构体类型名 + 字段类型**，可直接当 Go 字面量复现。

## 面试官视角
这是 fmt 动词里最高频的考点题（题面就是「%v %+v %#v 区别」）。考官就等一句话分清三者信息量递进。能用「值 → 值+字段名 → 值+字段名+类型名」三层递进作答即满分。

## 主问答
**Q（面试官原话）：** Go 里 %v、%+v、%#v 有什么区别？

1. **%v（最小信息）**：按默认格式输出值，对结构体**只输出各字段的值**，不显示字段名。调试时信息最少。
2. **%+v（带字段名）**：输出值与**字段名**，便于看出哪个值对应哪个字段；仍不含类型定义。
3. **%#v（最完整）**：输出值 + 字段名 + **结构体类型名 + 各字段的类型**，输出等价于 Go 源码里的复合字面量，可直接拷贝复现。

## 版本与兼容性
| 动词 | 输出内容 |
|------|----------|
| %v | 值 |
| %+v | 值 + 字段名 |
| %#v | 值 + 字段名 + 类型名 |

## 关键代码
```go
type User struct{ Name string; Age int }
u := User{"Tom", 18}
fmt.Printf("%v\n", u)   // {Tom 18}
fmt.Printf("%+v\n", u)  // {Name:Tom Age:18}
fmt.Printf("%#v\n", u)  // main.User{Name:"Tom", Age:18}
```

## 总结与追问预判
核心：**递进关系——%v 值 / %+v 值+字段名 / %#v 值+字段名+类型名**。追问可延伸到其他动词（见 411 / 411-string-float-verbs）或 FMT 三函数（见 411）。
