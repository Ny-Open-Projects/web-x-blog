> 分类：排序算法 | 难度：中 | 题型：代码实现 | 频率：高 | 关键词：**partition、双指针、交换、基准归位、返回值**

> 原文锚点：第 18~79 段「分区函数双指针走查与基准归位」

## 一句话总述
partition 是快排的核心：选基准后用双指针从两端向中间扫描，把「左大右小」的错序对交换，直到两指针交汇，再把基准换到交汇处，返回基准最终下标。返回值是后续递归的区间切分点。

## 面试官视角
手写 partition 是最能区分水平的环节。错误集中在：指针移动条件写反、循环退出后基准归位写错、返回值导致区间重叠。能写出「循环不变量清晰 + 返回正确下标」的人直接过。

## 主问答
**Q（面试官原话）：** 手写一个 partition，说明指针怎么动、返回什么？

1. **双指针扫描**：以首元素为基准，左指针 i 从 low+1 向右找「>基准」，右指针 j 从 high 向左找「<基准」；`i<j` 时交换这对错序元素，直到 i、j 交汇。
2. **基准归位**：交汇后把基准（a[low]）与交汇点前的元素交换，使基准落入最终有序位置；源码走查中该下标为 j-1。
3. **返回值语义**：返回基准最终下标 p，调用方据此递归 `[low,p-1]` 与 `[p+1,high]`；p 必须落在正确分区边界上，否则递归区间会漏元素或死循环。

## 版本与兼容性
| 实现 | 基准取法 | 特点 |
|------|----------|------|
| 双指针(Hoare 变体) | 首元素 | 交换少、快；区间边界需小心 |
| Lomuto | 末元素 | 易写易讲；略多交换 |
| 三向切分 | 任意 | 重复多时退化为 O(n) |

## 关键代码
```go
// Lomuto 分区（pivot 取末元素，最易讲解）
func partition(a []int, low, high int) int {
    pivot := a[high]
    i := low
    for j := low; j < high; j++ {
        if a[j] < pivot {
            a[i], a[j] = a[j], a[i]
            i++
        }
    }
    a[i], a[high] = a[high], a[i]
    return i
}
```

## 总结与追问预判
核心：**partition 让基准归位并返回其下标，递归区间必须排除它**。被追问实现差异时，指出双指针与 Lomuto 只是指针运动方式不同、分区不变量一致；重复元素多是三向切分（见 1717）。
