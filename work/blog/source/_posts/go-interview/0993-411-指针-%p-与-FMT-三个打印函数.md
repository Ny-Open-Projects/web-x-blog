> 原文锚点：第 92~104 段「指针输出与 FMT 三函数区别」

## 一句话总述
指针用 `%p` 打印地址（十六进制）。`fmt` 三函数区别在三处：是否支持格式化（`Printf` 支持、`Print`/`Println` 不支持）、结尾是否加换行（`Println` 加、`Print`/`Printf` 不加）、多值之间是否插空格（`Println` 总是插、`Print` 仅相邻都非字符串时插）。

## 面试官视角
FMT 三函数区别是经典送分+送命题。考官常追问「Print 和 Println 空格规则有何不同」——答出「Println 总是插空格、Print 仅相邻非字符串才插」即过关。

## 主问答
**Q（面试官原话）：** Print、Printf、Println 有什么区别？

1. **格式化支持**：`Printf` 支持 `%v` 等格式动词；`Print` 与 `Println` 直接按默认格式输出，不解析动词。
2. **换行**：`Println` 在结尾自动追加换行符；`Print` 与 `Printf` 不追加，需手动 `\n`。
3. **多值空格**：`Println` 在相邻参数间总是插入空格；`Print` 仅当相邻的两个参数都**不是**字符串类型时才插空格，否则原样拼接。
4. **指针**：`%p` 输出变量的内存地址（如 `0xc000...`）。

## 版本与兼容性
| 函数 | 格式化 | 换行 | 多值空格 |
|------|--------|------|----------|
| Print | 否 | 否 | 仅相邻非串才插 |
| Printf | 是 | 否 | 同 Print |
| Println | 否 | 是 | 总是插 |

## 关键代码
```go
fmt.Print("a", "b")     // ab（字符串相邻不插空格）
fmt.Println("a", "b")   // a b\n（总是插空格+换行）
fmt.Printf("%p\n", &x)  // 0xc0000b2000
```

## 总结与追问预判
核心：**Printf 管格式化、Println 管换行+始终空格、Print 最朴素**。追问常拐向 `%v` 三兄弟（见 411）。
