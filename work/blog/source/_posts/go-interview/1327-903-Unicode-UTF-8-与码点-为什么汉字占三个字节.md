> 原文锚点：第 16~36 段「Go 语言里面的字符串是以 UTF-8 格式保存的，UTF-8 编码是 Unicode 编码的一种实现方式…Unicode 是由非盈利组织统一码联盟负责的…Unicode 本身只定义了字符与码点的映射关系…常见的有三种编码格式，分别是 UTF-8、UTF-16 和 UTF-32…UTF 是 Unicode Transformation Format 的缩写…在 UTF-8 编码当中，一个码点值可能由一到四个字节组成」

## 一句话总述
**Unicode** 是字符到码点的映射标准（由统一码联盟维护），**UTF-8 是它的一种变长实现**：按码点大小用 **1~4 个字节**存储，ASCII 占 1 字节、汉字占 3 字节，从而兼顾兼容性与空间效率。

## 面试官视角
P6 知道「UTF-8 中文 3 字节」；P7 要讲清**字符集与编码格式的区别**（Unicode 是标准/码点映射，UTF-8 是存储实现）、**变长规则的分档**，以及「码点是 Unicode 的基本单位而非字符」这一精确表述。

## 主问答
**Q（面试官原话）：** Unicode 和 UTF-8 是什么关系？为什么汉字占 3 个字节？

1. **Go 的存储格式**：Go 字符串**以 UTF-8 格式保存**，UTF-8 是 **Unicode 编码的一种实现方式** `[源码]`。
2. **Unicode 的由来**：为解决字符集互不兼容的问题，包罗万象的 **Unicode 字符集**出现，由非盈利组织**统一码联盟**负责维护 `[源码]`。
3. **它只是标准**：Unicode **本身只定义字符与码点的映射关系**，相当于一套标准 `[源码]`。
4. **落地有多种编码**：真正落地时有多种编码格式，常见的有 **UTF-8、UTF-16、UTF-32** 三种 `[源码]`。
5. **UTF 的含义**：UTF 是 **Unicode Transformation Format** 的缩写，意为 **Unicode 字符转换格式** `[源码]`。
6. **码点是基本单位**：Unicode 标准的基本单位**不是字符而是码点**；在 UTF-8 中**一个码点值可能由 1~4 个字节组成** `[源码]`。
7. **变长规则（按码点大小）**：
   - **0~127（U+0000~U+007F）**：**1 字节**，且与 ASCII 重合 `[源码]`
   - **带变音符号的拉丁文、希腊文、西里尔字母、阿拉伯文**：**2 字节** `[源码]`
   - **东亚文字（含汉字）**：**3 字节** `[源码]`
   - **极少使用的语言字符**：**4 字节** `[源码]`
8. **码点的本质**：把 Unicode 字符集按一定顺序排列后，给每个字符一个**固定的序列号**，该序列号的值就是码点 `[源码]`。

## 关键代码
```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	for _, s := range []string{"A", "é", "中", "𝄞"} {
		// RuneCountInString 返回码点数，len 返回字节数
		fmt.Printf("%s runes=%d bytes=%d\n", s, utf8.RuneCountInString(s), len(s))
	}
	// 输出：
	//   A   runes=1 bytes=1  (ASCII，1 字节)
	//   é   runes=1 bytes=2  (拉丁文，2 字节)
	//   中   runes=1 bytes=3  (汉字，3 字节)
	//   𝄞   runes=1 bytes=4  (音乐符号，4 字节)

	// 遍历码点：range 会自动解码 UTF-8，i 是字节下标
	for i, r := range "中文" {
		fmt.Printf("byteIdx=%d rune=%c codePoint=%d\n", i, r, r)
	}
}
```

## 总结与追问预判
**「Unicode 定标准，UTF-8 定存储」**是本卡题眼。追问常是「为什么 UTF-8 要变长」——答案是**节省空间**：小码点用少字节，同时前 128 个与 ASCII 完全兼容，这是它能成为互联网主流编码的关键。字符数获取见同批 903-rune-iteration。

## ⚠️ 原文纠错
1. 事实核校：Go 用 UTF-8、Unicode 由统一码联盟维护、Unicode 定义字符与码点映射、UTF-8/16/32 三种常见实现、UTF 全称、码点 1~4 字节、四档变长规则及汉字 3 字节——均准确 `[经验]`。
2. 补充：原文说「每个中文的码点值都由三个字节组成」应更精确表述为**汉字在 UTF-8 下通常占 3 字节**（对应 U+4E00~U+9FFF 等常用区），并非所有汉字都固定 3 字节；扩展区汉字可能占 4 字节 `[经验]`。
3. 崩坏词归一：源码将 Unicode、UTF-8、码点、字符集等术语音译为多组崩坏词，本卡统一为规范术语 `[经验]`。
