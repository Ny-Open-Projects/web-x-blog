## 一句话总述
Go 字符串有两种字面量写法：**双引号** `"..."` 是**解释型字符串字面量（interpreted string literal）**，会**解析转义字符**（如 `\n` `\t` `\"`）；**反引号** `` `...` `` 是**原生字符串字面量（raw string literal）**，内容**原样输出、不解析任何转义**。两者类型都是 `string`，区别只在"是否解析转义"。

## 面试官视角
- 意图：考察对 Go 字符串字面量两种写法的**精确区分**——这是极高频的基础题。
- P5 能说出"双引号解析转义、反引号原样"；P6 能点出"两者都是 string 类型、反引号可跨行"；P7 能补充"反引号内不能包含反引号本身"这一边界。
- 红旗：以为反引号里的 `\n` 会换行（实际原样输出 `\n` 两个字符）；以为两者类型不同。
- 惊艳点：点出"反引号常用于写正则、SQL、多行模板——因为不用层层转义"，显出实战经验。

## 主问答
**Q（面试官原话）：** Go 里双引号和反引号定义的字符串有什么区别？
**A：**
1. **结论**：双引号 = 解释型字符串字面量，解析转义；反引号 = 原生字符串字面量，原样输出不转义。两者类型都是 `string`。
2. **机制**：双引号内 `\t` `\n` `\"` 等会被解释成对应控制字符；反引号内**所有字符原样保留**（含反斜杠、换行），适合写正则/SQL/多行文本，省去转义地狱。
3. **边界**：反引号内**不能出现反引号本身**（Go 语法限制）；双引号内不能直接写未转义的双引号（需 `\"`），但可直接写单引号 `[经验]`。

## 关键代码
```go
package main

import "fmt"

func main() {
    s1 := "a\tb" // 解释型：\t 被解析成制表符
    s2 := `a\tb` // 原生型：原样输出 a\tb 四个字符
    fmt.Printf("%q\n", s1) // "a\tb"（含真实制表符）
    fmt.Printf("%q\n", s2) // "a\\tb"（反斜杠+ t，未转义）

    // 反引号可跨行、原样保留换行
    s3 := `line1
line2`
    fmt.Println(s3) // 输出两行，含真实换行
}
```

## 总结与追问预判
- 双引号解释转义、反引号原生原样；类型都 string；反引号适合正则/SQL/多行。
- 预判：转义表示细节 → 见 416；单引号 byte/rune → 见 416；间接值部 → 见 420（本卡讲字面量语法）。
