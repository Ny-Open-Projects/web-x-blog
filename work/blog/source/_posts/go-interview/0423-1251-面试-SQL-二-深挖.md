## 方案取舍
- **CTE vs 嵌套子查询**：CTE 可读、可复用；复杂集合运算改写为多 CTE（a/b/c）优于深嵌套。
- **HAVING vs WHERE**：WHERE 过滤行（GROUP BY 前）、HAVING 过滤组（GROUP BY 后）+ 聚合函数，时机不可混。
- **排名取法**：嵌套 MAX 排除法对并列稳健；现代优先窗口函数明确 ROW_NUMBER/RANK/DENSE_RANK 语义。

## 答题技巧

## 细节与核心 API

**多步聚合 CTE + JOIN（优于深嵌套子查询）：**

```sql
WITH agg AS (
  SELECT user_id, COUNT(*) AS cnt FROM orders GROUP BY user_id
)
SELECT u.name, a.cnt
FROM agg a JOIN user u ON u.id = a.user_id;
```

**集合运算 IN / NOT IN（差集，注意 NOT IN 含 NULL 的语义陷阱）：**

```sql
SELECT id FROM a WHERE id IN  (SELECT id FROM b); -- 交集
SELECT id FROM a WHERE id NOT IN (SELECT id FROM b);
-- 危险：b 含任意 NULL 时，NOT IN 整集结果为 NULL（不返回任何行）！
-- 安全写法用 NOT EXISTS 或确保子查询列 NOT NULL
SELECT id FROM a WHERE NOT EXISTS (SELECT 1 FROM b WHERE b.id = a.id);
```

**行转列 GROUP_CONCAT（拼接）：**

```sql
SELECT dept, GROUP_CONCAT(name ORDER BY name SEPARATOR ',') AS members
FROM emp GROUP BY dept;
```

**分组后过滤 HAVING（WHERE 先过滤行、HAVING 后过滤组）：**

```sql
SELECT dept, AVG(salary) AS avg_sal
FROM emp GROUP BY dept HAVING AVG(salary) > 10000;
```

**排名第二：排除极值再取极值（对并列稳健）：**

```sql
SELECT MAX(salary) FROM emp
WHERE salary < (SELECT MAX(salary) FROM emp); -- 次高薪；并列最高时仍正确
```
