> 分类：Go 语言 | 难度：L3 | 题型：陷阱题 | 频率：高 | 关键词：**参数重新赋值、解除引用、快捷方式、不影响外层**

> 原文锚点：第 69~75 段「对参数重新赋值并没有影响到外面的切片…解除了引用关系」

## 一句话总述
在函数里**给切片参数整体重新赋值**，只是让这个局部描述符改指向另一块底层数组，调用方的切片少了一个引用，其自身内容与长度都不受影响。

## 面试官视角
P6 会说"函数里改切片会影响外面"；P7 要区分两种动作：**改元素**走的是共享内存，会互相看见；**给参数重新赋值**改的是局部描述符里的指针，与原切片解除引用关系 `[经验]`。原文那个类比很贴切：快捷方式原本指向文件 A，重新赋值后指向文件 B，文件 A 只是少了一个引用 `[源码]`。

## 主问答
**Q（面试官原话）：** 函数里给切片参数重新赋值，外面的切片会变吗？

1. **不会变**：重新赋值改变的是局部描述符的指针，与外层切片解除引用关系 `[实测]`。
2. **改元素才会互相看见**：写元素作用于共享的底层数组，改指向则不会 `[经验]`。
3. **快捷方式类比**：参数原本指向文件 A，重新赋值后指向文件 B，文件 A 只是少了一个引用 `[源码]`。
4. **原文实测**：函数内把新切片赋给参数后，外层切片打印仍是原来的值 `[实测]`。

## 关键代码
```go
func f3(s []int) {
	s = []int{4, 5, 6} // 只改局部描述符的指向
}
func main() {
	s := []int{1, 2, 3}
	f3(s)
	fmt.Println(s) // 仍是 [1 2 3]
}
```
> 验证：调用后外层切片内容与长度均未改变 `[实测]`。

## 总结与追问预判
**改元素影响外层，改指向不影响**。想要外层也变，就传指针或把结果返回去，别指望"引用传递"。
