> 覆盖源 17-13 的边界延伸：rune 与 byte 两级反转的语义差异、异或交换的同址自清零雷、Go 原生多赋值的实现机制、反转族题目的变形谱系。主卡已给两法主线，本附录做坑与变形深挖。

## 思路与架构

```text
字符串反转的坑位图
├─ 层级坑: []byte vs []rune
│   ├─ "你好" UTF-8 = 6 字节, 2 个 rune
│   ├─ byte 级反转: 多字节序列被撕碎 -> 乱码
│   │   [实测] "\xbd\xa5堽\xe4"
│   └─ rune 级反转: 按字符整体交换 -> "好你" 正确
├─ 异或交换的暗雷
│   ├─ 三步: a^=b; b^=a; a^=b  (两变量, 正确)
│   ├─ 同址自交换: b[i]^=b[i] -> 0 (数据销毁!)
│   │   <- 双指针 i<j 已保证不同址, 改写成 for i<=j 就爆
│   └─ 可读性: 三行魔法 vs 一行多赋值
└─ 变形谱系
    ├─ 栈法/递归法 (175 系列)
    ├─ 部分反转 (k 个一组)
    └─ 只反转字母保持非字母位置 (双指针跳过)
```

## 方案取舍
- **byte/rune 两级反转的本质**：`[]byte` 反转的是**存储序列**，`[]rune` 反转的是**字符序列**——"你好" 的 UTF-8 是 6 字节（你=3B、好=3B），字节级反转把两个多字节编码的内部字节也颠倒，产出非法 UTF-8（[实测] `"\xbd\xa5堽\xe4"`）。**「字符串反转」必须先问自己：反转的对象是字节还是字符**——Go 里默认答案应是 rune，除非明确处理纯 ASCII/二进制 [实测]。
- **异或交换的同址雷**：三步异或依赖「a、b 是两个不同存储位」——若 i==j（或同一指针），第一步 `a^=a` 直接清零，数据永久丢失。双指针循环条件 `i<j` 天然保证异址，但**把循环条件改写成 `i<=j`（或中点判断失误）就踩雷**。临时变量法无此雷——这是「工程不用异或法」的第二个理由（第一是可读性）[经验]。
- **Go 的多赋值不是「语法糖那么简单」**：`r[i], r[j] = r[j], r[i]` 由编译器保证**先求值右侧再赋值**，等价临时变量且无自交换雷——它就是「异或法想省的那个临时变量」的安全版本。答异或法时主动收尾一句「Go 里多赋值已解决临时变量问题，异或只剩教学价值」，体现语言理解深度 [经验]。
- **反转族变形的应答框架**：所有变形题都复用「双指针+条件跳过/分段」骨架——部分反转（k 个一组，组内反转组间衔接）、保持非字母位置（i/j 遇非字母跳过）、单词反转（先按空格切分再各自反转或整体反转再归位单词）。**变形 = 骨架不变 + 交换条件变化**，答题先点破这一点再动手 [经验]。

## 答题技巧
- 两法写完主动做中文反例：「[]byte 异或法对『你好』会输出乱码，工程必须 []rune」——一个反例直接拉开档次 [实测]。
- 异或推导用「c=a^b 中间量」讲，三性质（自反/零元/交换结合）一次列全，别背三行 [经验]。
- 被问「同值变量能异或交换吗」→ 能（两个不同存储位）；同**址**才致命——`i<=j` 改写即触雷 [经验]。
- 被问「还有别的反转方式」→ 报栈法/递归法（175 系列）并点评各自空间代价，展示反转谱系视野 [边界]。
- 主动边界到 `1713-string-reverse-two-ways`（两法主线）、`175-reverse-stack-queue`/`175-reverse-stack-recursive`/`175-reverse-stack.deep`（栈与递归法族）、`903-rune-iteration`/`903-len-is-bytes`（rune/byte 语义底座），构成「字符串处理」专题 [边界]。

## 细节与核心 API

```go
// 反转字符串（按 rune，正确处理中文/emoji）
func reverse(s string) string {
    r := []rune(s)
    for i, j := 0, len(r)-1; i < j; i, j = i+1, j-1 { r[i], r[j] = r[j], r[i] }
    return string(r) // 不要用 []byte 反转，会切断多字节 UTF-8 字符
}
// 异或交换陷阱：当 a、b 指向同一变量时会清零
func xorSwap(a, b *int) { *a ^= *b; *b ^= *a; *a ^= *b }
x, y := 1, 2
xorSwap(&x, &y)          // OK: x=2 y=1
// p := &x; xorSwap(p, p) // 灾难：*p 变 0（a^a=0 且就地修改）
// 结论：异或交换无性能收益（现代 CPU 三临时数更快且安全），且同址会出错，面试可点出此坑
```
