> 分类：并发模型 | 难度：L2 | 题型：事故题 | 频率：高 | 关键词：**循环变量复用** / **取址** / **同一地址**

> 原文锚点：第 11~34 段「for-range 元素进行取址，循环里元素始终指向同一个地址」

## 一句话总述
旧版 Go 的 for-range 循环变量在每次迭代**复用同一变量（同一地址）**；对其取址并把指针追加进切片，遍历结束后所有指针都指向最后一个元素。一句话背法：**「for-range 旧版循环变量单实例，取址 &u 三次同地址→全指向最后元素；取址即拷贝值修复，Go 1.22 起翻转」**。

## 面试官视角
这是"取址 + 循环变量"的经典坑，常紧接循环变量捕获题出现。考官看你是否分得清"加不加地址"的差异。
- **P5**：知道取址会出问题。
- **P6**：说清复用同一地址 + 给出正确写法（拷贝值）。
- **P7**：知道 Go 1.22 已翻转该语义。
- **红旗**：以为"每次迭代 u 是新变量"；以为打印出来的地址各不相同。
- **惊艳点**：复现只需打印 `&u` 三次，地址完全相同 `[经验]` go1.21。

## 主问答
**Q（面试官原话）：** 下面这段 for-range 取地址存进切片，为什么打印出来全是最后一个元素？

**先铺垫（由浅入深第 1 层）**：`for _, u := range users` 里的 `u` 是用来"承载当轮元素"的临时变量。关键问题是——它在整个循环里是"一个"还是"每轮一个"？旧版答案是"一个"。

1. **结论（第 2 层·机制）**：旧版 for-range 的循环变量 `u` 在循环外只创建一次，每次迭代覆盖它 `[源码]`。
2. **机制（第 3 层）**：`&u` 取的是同一个地址，三次追加的都是这一地址；遍历完该地址里是最后元素的值 `[源码]`。
3. **边界（第 4 层）**：若切片元素是引用类型（如 `[]*User`）且**不取址**直接 append，则各元素各自独立，结果正常 `[经验]`。
4. **修复（第 5 层·实战）**："取址即拷贝值"——`u := users[i]` 先拷出独立副本再取址，跨版本正确 `[经验]`。
5. **版本（第 6 层）**：该坑本质是"循环变量单实例"，与闭包无关；Go 1.22 起每次迭代独立变量，顺带修复 `[源码]` release notes。

## 版本与兼容性
| 维度 | 说明 |
|------|------|
| Go ≤1.21 | for-range 每次迭代复用同一循环变量（单实例），`&u` 同地址 `[源码]` |
| Go 1.22 起 | 每次迭代有独立变量（per-iteration scope），该写法自愈 `[源码]` release notes |
| 引用类型 | `[]*User` 不取址直接 append 则各元素独立，结果正常 |
| 推荐写法 | 取址前先 `u := users[i]` 拷贝副本，兼容老代码 |

## 关键代码
```go
package main

import "fmt"

type User struct {
	ID   int
	Name string
}

func main() {
	users := []User{{1, "a"}, {2, "b"}, {3, "c"}}
	var ps []*User

	// 反例（旧版≤1.21）：三次 &u 是同一地址，ps 全指向最后元素
	for _, u := range users {
		ps = append(ps, &u)
	}
	for _, p := range ps {
		fmt.Printf("id=%d name=%s\n", p.ID, p.Name) // 全打印 3 c
	}

	// 正解：取址即拷贝值
	var qs []*User
	for i := range users {
		u := users[i] // 拷贝出独立副本
		qs = append(qs, &u)
	}
	for _, q := range qs {
		fmt.Printf("id=%d name=%s\n", q.ID, q.Name) // 1 a / 2 b / 3 c
	}
}
```

## 总结与追问预判
**背这三句就够**：① **旧版 for-range 循环变量单实例，取址 &u 同地址**；② **遍历完所有指针指向最后元素**；③ **修复=拷贝值，Go 1.22 起翻转**。
**预判追问**：
- 「和 goroutine 循环变量是同一回事吗？」→ 同根"循环变量单实例"，一个取址一个闭包读（见 1017 goroutine 循环变量）。
- 「引用类型切片会中招吗？」→ 不取址直接 append 则各元素独立，正常。
- 「1.22 改了啥？」→ 每轮独立变量，该坑自愈（见 1017 同号卡）。
