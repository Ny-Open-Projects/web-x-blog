> 原文锚点：第 12~21 段「嵌入结构体同名方法…必须外层重写…内嵌指针vs值(值复制副本开销大)」

## 一句话总述
当嵌入的多个结构体存在同名方法时，外层必须显式重写该方法（否则调用存在歧义无法编译使用）；嵌入用指针还是值决定共享同一实例还是复制副本——值嵌入会复制一份，内存开销更大。

## 面试官视角
- 意图：是否懂方法提升的冲突消解规则，以及指针/值嵌入的内存与语义差异。
- P5 知同名要重写；P6 说清重写原因与提升优先级；P7 知指针嵌入共享、值嵌入复制副本的开销。
- 红旗：以为同名方法会自动"随机选一个"；忽略值嵌入的复制成本。
- 惊艳点：提升优先级是"外层 > 内层"；一旦外层声明该方法，调用即走外层——这正是覆盖语义 `[经验]`。

## 主问答
**Q（面试官原话）：** 嵌入的结构体有同名方法怎么办？嵌入用指针还是值？
**A：**
1. **同名方法冲突**：嵌入的多个结构体若有同名方法，外层结构体必须显式重写该方法，否则调用存在歧义、无法使用 `[源码]`。
2. **重写即覆盖**：外层声明同名方法后，调用走外层（提升优先级：外层 > 内层），等价于"覆盖"。
3. **指针嵌入共享**：嵌入指针（*T）多个外层共享同一底层实例，修改互相可见。
4. **值嵌入复制**：嵌入值（T）会把副本拷进外层，内存占用更大，且各自独立——大结构体宜用指针嵌入。

## 关键代码
```go
// 示意，未验证：同名方法冲突——外层必须重写；指针vs值嵌入的内存差异
package main
import "fmt"
type A struct{}
func (A) Hello() { fmt.Println("A.Hello") }
type B struct{}
func (B) Hello() { fmt.Println("B.Hello") }
type C struct {
    A
    B
}
func (C) Hello() { fmt.Println("C.Hello(重写覆盖 A/B)") } // 必须重写，否则 c.Hello() 歧义
func main() {
    var c C
    c.Hello() // 走 C 自身：C.Hello(重写覆盖 A/B)
}
```
