## 一句话总述
Go 变长参数用 `...T` 表示：① **只能有 1 个且必须是参数列表最后一个**；② 函数体内该形参就是 `[]T` 切片类型；③ 形参类型与实参必须一致（含 interface{}）。调用时用 `s...` 把切片**打平**成多个实参；若直接传切片则被当成**一个整体参数**，类型不匹配会报错。可借此实现"必传 + 可选"参数。

## 主问答
**Q（面试官原话）：** Go 的变长参数函数怎么用？有什么注意点？
**A：**
1. **语法约束**：变长参数只能是**最后一个形参**且**最多一个**；函数体内它就是 `[]T` 切片（如 `...int` 即 `[]int`）。
2. **类型一致**：实参类型必须与 `T` 一致，传入 `[]interface{}` 时也要逐元素是 interface。
3. **切片展开**：调用时用 `s...` 把切片元素逐个展开成多实参；若**直接传切片**则它被当成一个 `[]T` 参数，与 `...T` 期望的"多个 T"类型不符，编译报错。
4. **可选参数**：把必传参数放前、变长参数放后即可实现"可选参数"——调用时按需传，函数内判断长度走不同逻辑。

## 关键代码
```go
package main

import "fmt"

// 变长参数：只能是最后一个形参，函数体内是切片类型
func sum(prefix string, nums ...int) {
	fmt.Println(prefix, nums) // nums 类型为 []int
}

func main() {
	sum("直接传:", 1, 2, 3) // 直接传多个实参

	s := []int{1, 2, 3}
	sum("展开传:", s...) // 三个点打平：逐元素作为多参数
	// sum("整体传:", s)  // 错误：把切片当 1 个参数，类型不匹配([]int vs int)
}
```

## 总结与追问预判
- 变长参数 = `...T` 切片语法糖，1 个且最后；`s...` 展开、直接传切片报错；可拼可选参数。
