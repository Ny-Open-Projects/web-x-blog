> 原文锚点：第 1~9 段「Unix 起源 / GNU 项目 / Linux 内核发布」

## 一句话总述
1969 年贝尔实验室做出 Unix；1983 年 Stallman 发起 GNU 项目补齐了一整套自由软件，却始终缺内核；1991 年 Linus 发布 Linux 内核并开源——**GNU 用户态 + Linux 内核**才构成今天的 Linux 操作系统，GPL 是把两者粘合起来的许可证。

## 面试官视角
这题表面考历史，实际考「你说的 Linux 到底指什么」。答出「Linux 严格讲只是内核，发行版 = 内核 + 用户态 + 包管理」，说明你分得清层次；再补一句 GPL 的传染性，这题就过了。

## 主问答
**Q（面试官原话）：** Linux 和 GNU 是什么关系？为什么说 Linux 严格来说只是个内核？

1. **Unix 是源头**：1969 年贝尔实验室做出首个 Unix，迅速成为学界主流，但作为商业闭源系统，传播与修改受授权限制。
2. **GNU 补用户态、缺内核**：1983 年发起的 GNU 项目做出编译器、编辑器、Shell 等自由软件，唯独内核长期空缺。
3. **Linux 补上内核**：1991 年 Linus 发布内核 0.01 并以自由软件形式公开，全球开发者涌入贡献，内核逐步稳定高效。
4. **两者融合**：GNU 组件 + Linux 内核 = 现代操作系统，发行版再叠加包管理与配置，形成多样化选择。
5. **GPL 是粘合剂**：1992 年内核改用 GPL 授权，与 GNU 项目打通，保障了自由使用、修改与分发的权利。

## 关键代码
```go
// Go 侧视角：内核名来自 uname，发行版身份来自 /etc/os-release
package main

import (
	"fmt"
	"os"
	"os/exec"
)

func main() {
	out, _ := exec.Command("uname", "-r").Output()
	fmt.Printf("内核版本: %s", out)        // 只反映内核，如 6.1.0-13-amd64
	b, _ := os.ReadFile("/etc/os-release")
	fmt.Println("发行版信息:\n" + string(b)) // 用户态与包管理由发行版决定
}
```

## 总结与追问预判
核心：**Linux 是内核，GNU 提供用户态，GPL 保证自由**。追问常拐向「GPL 传染性」「CentOS 与 RHEL 的关系」「Android 算不算 Linux」，备好一句「用户态可替换，内核才是 Linux」。

## ⚠️ 原文纠错
1. 事实核校： [经验] 原文称 Unix 是「商业地缘的操作系统」——应为**商业闭源、受授权限制**的操作系统，并非地域概念。
2. 事实核校： [经验] 原文在里程碑段落中把 0.01 与 1.0 混述，实际 0.01 发布于 1991 年 9 月、1.0 发布于 1994 年 3 月，两者相隔两年多。
3. 崩坏词归一：源码将 GNU / GPL / Shell / TCP/IP / X Window 等音译为多组崩坏词，本卡统一为规范术语。
