## 一句话总述
`GOPRIVATE` 自 Go 1.13 起支持，作用是让**匹配到的模块既不走代理、也不做校验和数据库校验**；它按模块路径前缀匹配，使用 Go 的 `path.Match` 通配语法而非正则，可用 `go env -w` 持久化。

## 面试官视角
这题考的是精确性。很多人只会背「配 GOPRIVATE」，却说不清它**同时**关掉了代理和校验两件事，也不知道通配符不是正则。答出「它是 GONOPROXY 与 GONOSUMDB 的默认值」就是分水岭。

## 主问答
**Q（面试官原话）：** 私有仓库的包拉不下来，你怎么处理？

1. **版本要求**：该变量从 Go 1.13 版本开始支持，1.13 之前没有这个配置项。
2. **核心作用**：让指定域名的模块**不走代理**，直接通过域名对应的源码仓库拉取；同时**不做校验和数据库校验**。
3. **配置语法**：与代理变量类似，可用完整域名，也可用通配符；匹配的是**模块路径前缀**，用的是 `path.Match` 语法而非正则表达式。
4. **写法示例**：`*.corp.example.com` 覆盖该域名下的模块；若无二级域，直接写完整域名做完全匹配也可以，多个模式用逗号分隔。
5. **持久化**：既可用环境变量临时设置，也可用 `go env -w` 写入配置，后者对同一台机器上的所有工程生效。

## 关键代码
```go
// Go 侧视角：用 path.Match 验证通配模式是否真的覆盖了目标模块
package main

import (
	"fmt"
	"path"
)

func main() {
	mod := "git.corp.example.com/team/pkg"
	ok, _ := path.Match("*.corp.example.com/*", mod)
	fmt.Println("是否被 GOPRIVATE 覆盖:", ok) // 注意 * 不匹配 "/"
}
```

## 总结与追问预判
核心：**一条配置同时关代理与校验，按前缀匹配**。追问常拐向「配了还拉不下来怎么办」，备好三类原因：Git 鉴权未配、自签证书需额外设置、模块路径与仓库地址不一致。
