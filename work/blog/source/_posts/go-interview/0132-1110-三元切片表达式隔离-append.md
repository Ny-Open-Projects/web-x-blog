> 分类：Go 语言基础 | 难度：L3 | 题型：技巧题 | 频率：中 | 关键词：**三元切片表达式**/**限制容量**/**隔离串扰**
> 原文锚点：第 23~31 段「用三元索引限制 cap…append 扩容不影响原切片」

## 一句话总述
用**三元切片表达式** `s[low:high:cap]` 可**限制新切片的容量上限**，使后续 `append` 必定**触发扩容、换底层地址**，从而与原切片彻底脱钩、互不干扰——它是隔离 append 串扰的通用技巧。

## 面试官视角
- 考察意图：是否掌握三元表达式这一"高级切片操作"，以及它如何精确控制 cap。
- 分档：P5 知普通截取；P6 知三元表达式能限 cap；P7 能讲清 cap 相对原切片起点的语义与脱钩原理。
- 红旗答案：把 `s[a:b:c]` 的第三个参数当成"新切片长度"或"绝对容量"。
- 惊艳点：点出 **第三个 cap 是相对原切片起点的绝对上限（非相对 high 的增量）**，且必须 `cap >= high` `[经验]`。

## 主问答
**Q（面试官原话）：** 怎么让截取后的切片 append 不影响原切片？
**A：**
1. **结论**：三元表达式锁定 cap，强制 append 扩容换地址。
2. **机制**：`s5 := s4[0:2:2]` 表示 len=2、cap=2（cap 是相对 s4 起点的绝对上限）。`append(s5, x)` 时 cap 已满 → 扩容 → 分配新数组，s5 指向新地址，原 s4 完全不受影响。
3. **边界**：`s[low:high:cap]` 中 cap 是**相对原切片起点**的索引上限（即新切片最多到原数组的第 cap 个元素），须满足 `cap >= high`；它是安全截断、隔离串扰的关键。

**加分层：** 不写第三参数时 cap = 原切片尾，append 极易原地覆盖——三元表达式是"防御性切片"的标准写法。

## 关键代码
```go
s4 := []int{0, 1, 2, 3}
s5 := s4[0:2:2]     // len=2, cap=2
s5 = append(s5, 9)  // cap 满 → 扩容换地址
fmt.Println(s4)     // [0 1 2 3] 原切片不受影响
```

## 总结与追问预判
三元表达式 `s[low:high:cap]` 用 cap 上限强制 append 扩容换地址，是隔离串扰的标准手段。追问接"copy 克隆"与"append 克隆保 nil"。
