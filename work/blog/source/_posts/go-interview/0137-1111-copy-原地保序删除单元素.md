## 一句话总述
保序删除单元素用 `copy(a[i:], a[i+1:])` 把后段前移一位，再 `a = a[:len(a)-1]`；原地、零新分配（复用底层数组），O(n) 但常数小 `[源码]`。

## 面试官视角
- 意图：是否掌握 `copy` 重叠切片的正确用法与保序删除。
- P5 会写 copy 删除 / P6 说清原地前移与零分配 / P7 知与 append 法的取舍。
- 红旗：`copy(a[i+1:], a[i:])` 方向写反；忘了最后截断。
- 惊艳点：源与目的重叠时 `copy` 仍正确（Go 的 copy 处理重叠） —— 验证 `builtin.copy` `[源码]`。

## 主问答
**Q（面试官原话）：** 要保留顺序地删掉切片里第 i 个元素，怎么写？
**A：**
1. **结论**：`copy(a[i:], a[i+1:]); a = a[:len(a)-1]` 把 `[i+1:]` 整体前移覆盖 `a[i]`，再缩 len。
2. **机制**：`copy` 处理源目的重叠是定义行为，原地前移不新分配；只搬 `len-i-1` 个元素 `[源码]`。
3. **边界**：仍共享原底层数组，若切片来自大数组截取，缩 len 不会释放前面内存（见内存泄漏卡）。
**加分层：** 比 append 法少一次可能的扩容判断，常更省；可读性稍弱。

## 关键代码
```go
// 示意，未验证：保序删除 a[i]（原地前移）
a := []int{1, 2, 3, 4, 5}
i := 1
copy(a[i:], a[i+1:]) // a = [1 3 4 5 5]
a = a[:len(a)-1]     // a = [1 3 4 5]
```
