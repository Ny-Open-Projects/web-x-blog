## 一句话总述
TCP 的七大特点：**可靠性**（确认应答、超时重传、校验）、**面向连接**（三次握手 / 四次挥手）、**流量控制**（滑动窗口）、**拥塞控制**（降速重传）、**有序传输**、**全双工**、**易于实现**。

## 面试官视角
P6 能说出可靠与面向连接；P7 要能**逐条给出实现机制**——可靠性靠哪四种手段、连接建立与终止各几次握手、流控与拥塞控制的手段差异，并能区分「流控（对端收不下）」与「拥塞控制（网络扛不住）」。

## 主问答
**Q（面试官原话）：** TCP 为什么是可靠的？它有哪些核心特性？

1. **可靠性**：通过**确认应答、超时重传、错误检测、校验**等机制确保传输可靠，解决网络中**丢失、重复、延迟**等问题 `[源码]`。
2. **面向连接**：通信开始前必须先建立连接，建立过程即**三次握手**；连接终止通过**四次挥手** `[源码]`。
3. **流量控制**：通过**滑动窗口机制**实现，使收发双方能**根据当前网络状况动态调整传输速率**，避免拥堵、提高效率 `[源码]`。
4. **拥塞控制**：网络拥塞时通过**减小发送速率、重传丢失的数据包**等方式，避免拥塞持续发生，维护网络稳定性 `[源码]`。
5. **有序传输**：数据**按发送顺序传输**，对文件传输、网页浏览、邮件发送等需要有序处理的程序非常重要 `[源码]`。
6. **全双工通信**：发送方与接收方**可以同时发送和接收数据**，提高通信效率 `[源码]`。
7. **易于实现**：实现相对简单，**许多操作系统和网络设备内置支持**，便于开发和部署 `[源码]`。
8. **关键区分**：流量控制解决**接收方处理不过来**，拥塞控制解决**网络链路扛不住**，二者目标不同 `[经验]`。

## 关键代码
```go
package main

import (
	"fmt"
	"net"
	"time"
)

func main() {
	conn, err := net.Dial("tcp", "127.0.0.1:8080")
	if err != nil {
		fmt.Println("跳过演示：需要本机 8080 端口的演示服务：", err)
		return
	}
	defer conn.Close()

	// 超时重传在内核完成，应用层通过超时设置避免无限等待
	_ = conn.SetDeadline(time.Now().Add(5 * time.Second))

	// 全双工：读写可在两个 goroutine 中同时进行，互不阻塞
	go func() {
		buf := make([]byte, 4096)
		for {
			n, err := conn.Read(buf)
			if err != nil {
				return
			}
			_ = buf[:n]
		}
	}()

	_, _ = conn.Write([]byte("ping"))
	time.Sleep(time.Second)
}
```

## 总结与追问预判
**可靠性四手段 + 连接三次/四次 + 流控与拥塞的区分**是核心得分点。面试官常追问「流控和拥塞控制有什么不同」——答案是**流控看接收方窗口，拥塞控制看网络状况**，两者共同决定实际发送速率。
