> 分类：Go 语言基础 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**copy**/**覆盖式复制**/**目标长度陷阱**
> 原文锚点：第 33~69 段「copy 方法…覆盖式、返回个数、长度必须预设」

## 一句话总述
`copy(dst, src)` 是**覆盖式**复制（用 src 元素覆盖 dst 对应位置），返回实际复制个数；**目标切片必须先 `make` 出长度**，否则（长度为 0）复制无效——这是 copy 最常见的坑。

## 面试官视角
- 考察意图：是否理解 copy 的"覆盖"语义与"dst 长度决定一切"的约束。
- 分档：P5 知 copy 复制切片；P6 知覆盖式、返回个数；P7 能讲清 len=0 / 只设 cap 不设 len 都无效。
- 红旗答案：以为 `copy` 会"追加"、或 dst 只给 cap 就能复制。
- 惊艳点：点出 **copy 是覆盖不是追加，dst 多余元素保留原值（不会清零）** `[经验]`。

## 主问答
**Q（面试官原话）：** 怎么用 copy 克隆切片？要注意什么？
**A：**
1. **结论**：`copy(dst, src)` 覆盖式复制，dst 须先 `make` 出长度 n。
2. **机制**：`dst := make([]T, n); copy(dst, src)` 把 src 前 n 个元素**覆盖**进 dst；返回 `min(len(dst), len(src))`。`src[0]=1` 覆盖 `dst[0]`、`src[1]=2` 覆盖 `dst[1]`，其余 dst 元素不动。
3. **边界**：dst 长度为 0 → 什么也不复制；dst 比 src 长 → **超出部分保留原值**（copy 不负责清零）；只设 cap 不设 len → 同样无效（因为 len 仍为 0）。

**加分层：** 与 append 不同，copy 永远"覆盖"而非"追加"——要的是独立副本就先 `make` 出正确长度。

## 关键代码
```go
src := []int{1, 2, 3}
dst := make([]int, len(src)) // 必须预设长度
n := copy(dst, src)          // n = 3，dst 与 src 地址不同
fmt.Println(dst, n)          // [1 2 3] 3
```

## 总结与追问预判
copy 是覆盖式复制，dst 必须先 `make` 出长度，返回复制个数。追问接"append 克隆"与"三元表达式保 nil 特性"。

## ⚠️ 原文纠错
1. 机翻崩坏词归一：`copcopen`/`扩币`→**copy**（或 copy+append 组合）；`构版本`→**Go 版本**；`耳pad`→**append**；`六`→**nil**。事实推理正确，仅术语崩坏，本卡已归一 `[经验]`。
2. 原文用多个 f 函数演示 copy 的覆盖规则（src 为空→覆盖 0 个、src 默认值→覆盖 0 值）—结论准确，本卡归纳为"覆盖式 + dst 长度决定"并补出"只设 cap 不设 len 同样无效"的边界。
