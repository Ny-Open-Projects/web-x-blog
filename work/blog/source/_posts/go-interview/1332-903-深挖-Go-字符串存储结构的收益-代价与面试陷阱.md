> 分类：Go 基础 / string | 难度：L4 | 题型：综合题 | 频率：高 | 关键词：**只读字节切片、不可变性、并发安全、O(1) 长度、拷贝代价、UTF-8**

> 原文锚点：第 50~87 段「字符串整个结构的大小就是十六字节…字符串的底层存储结构其实是一个只读的字节切片…Go 的字符串类型，它的设计是一个不可变类型，也就是一旦创建就不能修改它的内容…这种不可变性确保了字符串在并发环境下的安全性…字符串本身还包含了字节序列的长度，使得获取字符串长度操作的时间复杂度就是 O(1)…不可变性也是有代价的，就是对字符串修改的时候会产生副本，而占用额外的存储空间」

## 思路与架构

把 Go 字符串讲透，按「**结构 → 语义 → 编码 → 收益与代价**」四层展开：

1. **结构层**：`string` 是**结构体描述符**，只有两个字段——`data uintptr`（指向底层只读字节数组）+ `len int`（字节数）。64 位下各 8 字节，故 `unsafe.Sizeof` 恒为 **16**，与内容长度无关。
2. **语义层**：底层是**只读的字节切片**，用 **UTF-8** 保存。因此 `len` 返回的是**字节数不是字符数**（"中文" 为 6）；下标取到的是**字节**；不能直接通过下标修改字符（**编译期报错**），只能整体重新赋值（**产生一次拷贝**）。
3. **编码层**：Unicode 是**字符到码点的映射标准**（统一码联盟维护），UTF-8 是其**变长实现**，一个码点占 **1~4 字节**：ASCII 1 字节、拉丁/希腊/西里尔 2 字节、汉字 3 字节、生僻字符 4 字节。`rune` 即一个 Unicode 码点。
4. **收益与代价层**：不可变性带来**并发安全**（可被多个 goroutine 共享）与**O(1) 获取长度**；代价是**修改必然产生副本**，占用额外存储。

## 方案取舍

| 需求 | 做法 | 代价 | 说明 |
|---|---|---|---|
| 取字节数 | `len(s)` | 无 | O(1)，描述符已存长度 |
| 取字符数 | `utf8.RuneCountInString(s)` | O(n) 扫描 | 优于 `len([]rune(s))`，不分配 |
| 随机访问第 N 个字符 | `[]rune(s)[n]` | 分配切片 | 无法真正 O(1) |
| 只遍历字符 | `for range s` | 无 | 自动解码，i 为字节下标 |
| 修改（ASCII） | `[]byte(s)` 后改 | 一次拷贝 | 按字节，安全 |
| 修改（含中文） | `[]rune(s)` 后改 | 一次拷贝 | 按字符，避免截断 |
| 高频拼接 | `strings.Builder` | 预分配 | 避免反复拷贝 |

取舍要点：**不可变换来了安全与 O(1) 长度，代价是写操作必然拷贝**。因此高频拼接必须用 `strings.Builder` 而非 `+=`，这是把底层结构知识转化为工程实践的关键一步。

## 答题技巧

1. **从一道题切入**：面试官常以 `unsafe.Sizeof("hello")` 发问——先答 **16**，再拆出「描述符 = 指针 + 长度」，立刻能引出底层结构。
2. **三个易错点主动说**：`len` 是字节数、`range` 的 i 是字节下标、下标不可赋值。这三点答出即超越多数候选人。
3. **区分字符集与编码**：Unicode 定标准（码点映射），UTF-8 定存储（变长字节），说清这层关系体现基础扎实。
4. **给出工程结论**：不可变 → 高频拼接用 `strings.Builder`；这是把八股落到代码上的加分句。
5. **止步档位**：能讲清结构与 len 语义即达 L4；能完整讲出编码分档、rune 遍历差异、不可变收益代价并给出 Builder 优化，即达 L5。

## 细节与核心 API

```go
type stringHeader struct { Data uintptr; Len int } // 1.20 前；1.20+ 用 unsafe.StringData
s := "hello"
b := []byte(s)                 // 发生拷贝：string 只读，转 []byte 必须新建底层数组
s2 := string(b)               // 也发生拷贝
// 代价：大字符串频繁 string<->[]byte 拷贝有性能与 GC 压力
// 收益：string 不可变，可安全共享、可作 map key、可并发读
// 零拷贝（unsafe，仅当确定不写）：unsafe.String/unsafe.Slice（1.20+），要自担生命周期风险
// 陷阱：字符串拼接大量小串用 + 会多次分配，改用 strings.Builder
```
