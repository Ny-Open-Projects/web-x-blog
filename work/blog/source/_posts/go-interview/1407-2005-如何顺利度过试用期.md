> 分类：求职与录用 / 职场起步 | 难度：L1 | 题型：方法论 | 频率：低 | 关键词：**试用期法定上限**/**法定 vs 公司惯例**/**试用期≠实习期**/**转正时间线**/**提前 3 日通知**
> 原文锚点：第 1~36 段「试用期是公司与员工相互了解的阶段……工作态度/学习能力/团队合作/问题解决/结果导向……复杂任务先整理文档再讨论……靠谱的人事事有回应件件有着落」
> 版本口径：**[2026 年·中国大陆]**。法条为现行《劳动合同法》《社会保险法》《劳动法》，校验与排程脚本按条号实现、本机真跑 [实测]。本卡只讲「入职后这段试用期该怎么过，以及它有哪些法定边界」；录用条件的定义见 2001，岗位内容见 2002，谈薪见 2003，公司选择见 2004。

## 一句话总述
试用期不是「单位说了算」的考察期，而是**有法定上限、有工资下限、必须缴社保、不能随意解除的劳动合同期——先守红线，再谈表现**。五条法定红线：①期限有上限（合同 <3 个月不得约定；3 个月~1 年 ≤1 个月；1~3 年 ≤2 个月；3 年以上或无固定 ≤6 个月；**同一单位同一劳动者只能约定一次**，仅约定试用期的试用期不成立、该期限即合同期限，[法条：劳动合同法第 19 条]）；②工资有下限（不低于同岗最低档**或**约定工资 80% 两者取高，且不低于当地最低工资，[第 20 条]）；③社保必缴（用工之日起 30 日内登记，「试用期不缴社保」是违法不是惯例，[社会保险法第 58 条]）；④解除受限（除第 39 条、第 40 条第 1/2 项情形外不得解除且应说明理由，[第 21 条]）；⑤劳动者侧相反——**试用期内提前 3 日通知即可解除**，转正后提前 30 日书面通知（[第 37 条]）。表现层保留源文软技能框架：**结果导向 + 及时汇报（复杂任务先出文档再讨论）+ 及时求助**，判据一句话——「靠谱的人不是事事都完美搞定的人，而是事事有回应、件件有着落、凡事有交代」。

## 面试官视角
- 考察意图：入职沟通中「你对试用期怎么看 / 30-60-90 天计划」是常见问题——测你能否区分「红线」（法定）与「表现」（加分），以及有没有可交付的里程碑意识。
- 分档：P5 能说出试用期要好好表现；P6 能说出期限上限与「只能约定一次」；P7 能报出「工资下限取高规则」「社保 30 日强制」「提前 3 日 vs 30 日」三组法定细节，并把「公司惯例 ≠ 法律规定」讲清楚。
- 红旗答案：把「转正考核不合格就不给转正」「试用期不缴社保」「试用期可以随时辞退」当公司合法惯例；把「早到晚走」当转正标准。
- 惊艳点：报得出可计算的数字——合同 6 个月却约定试用期 3 个月 → **违法**（上限 1 个月）；合同 36 个月约定 7 个月 → **违法**（上限 6 个月）；入职 2026-01-15、试用期 3 个月 → 截止 2026-04-15、试用期内离职最晚 2026-04-12 通知 [实测]。

## 主问答
**Q（面试官原话）：** 你入职后的 30 / 60 / 90 天计划是什么？
**A：**
1. **每个阶段给「产出物」而不是「我会努力」**：「第 30 天：完成环境搭建、摸清主干业务与协作流程，交付一个边界清楚的小任务；第 60 天：独立负责一个模块，跑通需求到上线的完整闭环并输出文档；第 90 天：对齐转正目标，把负责的模块做到能独立维护，同时把试用期暴露的问题和补法整理清楚。」[经验]
2. **表现层做三件事**（源文框架，方向正确）：结果导向（对齐团队目标，重质量效率）；及时汇报（任务有回应、件件有着落；复杂任务**先整理文档再讨论**——文档既是深度思考、又是可举证的产出）；及时求助（卡住或发现方向问题立即沟通，新人求助是理所当然）[源码]。
3. **红线层先自查**（与态度无关，单位不做就是违法）：期限是否超第 19 条上限、是否被约定过两次试用期、是否只签了「试用期合同」（仅约定试用期的试用期不成立）；工资是否低于第 20 条下限；是否 30 日内办社保登记（[社会保险法第 58 条]——「自愿签字放弃」依[劳动合同法第 26 条]无效）[实测]。
4. **被辞退时问三件事**：公司以「试用期不符合录用条件」解除，必须**事先有明确、可量化、已告知并签字确认的录用条件，且能举证**（[法条：劳动合同法第 21 条、第 39 条第 1 项]）——「我入职时从没见过这样的标准」本身就是抗辩，这正是 2001 讲「招聘要求 ≠ 法律录用条件」的现实意义 [源码]。
5. **兜底话术**（被追问「你是不是很难搞」）：「不是难搞，是我希望规则清楚。规则清楚对双方都好——我知道怎么被评估、公司也知道怎么合规用人，这样我才能把精力放在产出上。」把「守红线」翻译成「我想安心做事」[经验]。

## 关键代码
```go
// probation.go —— 试用期合法长度校验器 + 时间线排程（按法条算，不凭感觉）
// ① 校验器：按《劳动合同法》第 19 条算法定上限并判违法；按第 20 条校验工资下限
// ② 排程器：给定入职日与试用期长度，排截止日、评估节点、离职通知节点
package main

import (
	"fmt"
	"time"
)

const (
	noticeInProbation = 3  // 第 37 条：试用期内提前 3 日通知即可解除
	noticeAfterProb   = 30 // 第 37 条：转正后提前 30 日书面通知
	evalLeadDays      = 15 // 转正评估节点：截止日前 15 日（公司惯例，非法定，可改）
)

// maxProbationMonths 按《劳动合同法》第 19 条返回法定试用期上限（月）；0 = 不得约定
func maxProbationMonths(contractMonths int) (int, string) {
	switch {
	case contractMonths < 3:
		return 0, "不满 3 个月：不得约定试用期 [第 19 条]"
	case contractMonths < 12:
		return 1, "3 个月以上不满 1 年：不超过 1 个月 [第 19 条]"
	case contractMonths < 36:
		return 2, "1 年以上不满 3 年：不超过 2 个月 [第 19 条]"
	default:
		return 6, "3 年以上或无固定期限：不超过 6 个月 [第 19 条]"
	}
}

// wageFloor 按《劳动合同法》第 20 条返回试用期工资下限 = max(同岗最低档, 约定工资 80%, 当地最低工资)
func wageFloor(agreedSalary, peerFloor, localMinWage float64) (floor float64, basis string) {
	ref := agreedSalary * 0.8
	if peerFloor > ref {
		ref = peerFloor
	}
	floor, basis = ref, fmt.Sprintf("max(约定工资80%%=%.0f, 同岗最低档=%.0f) = %.0f", agreedSalary*0.8, peerFloor, ref)
	if localMinWage > floor {
		floor, basis = localMinWage, fmt.Sprintf("低于当地最低工资 %.0f，取下限 = %.0f", localMinWage, localMinWage)
	}
	return floor, basis
}

func main() {
	fmt.Println("=== 试用期合法长度校验 · [2026 年·中国大陆] ===")

	// 一、期限校验（第 19 条）
	cases := []struct{ contract, agreed int }{
		{2, 1}, {6, 1}, {6, 3}, {12, 2}, {12, 3}, {24, 2}, {36, 6}, {36, 7}, {60, 6},
	}
	for _, c := range cases {
		limit, _ := maxProbationMonths(c.contract)
		verdict := "合法"
		if c.agreed > limit {
			verdict = "违法：超出部分无效，已履行可主张赔偿金 [第 83 条]"
		}
		fmt.Printf("合同 %2d 个月 / 约定试用期 %d → 上限 %d → %s\n", c.contract, c.agreed, limit, verdict)
	}

	// 二、工资校验（第 20 条）
	for _, x := range []struct {
		agreed, peer, minWage, paid float64
	}{
		{10000, 0, 2690, 8000},
		{10000, 9000, 2690, 8000}, // 同岗最低档 9000 > 80%=8000，下限取 9000
		{10000, 0, 2690, 7000},
	} {
		floor, _ := wageFloor(x.agreed, x.peer, x.minWage)
		verdict := "合法"
		if x.paid < floor {
			verdict = fmt.Sprintf("违法：低于下限 %.0f，差额可主张补足 [第 20 条]", floor)
		}
		fmt.Printf("约定 %.0f / 同岗 %.0f / 实发 %.0f → 下限 %.0f → %s\n", x.agreed, x.peer, x.paid, floor, verdict)
	}

	// 三、时间线排程：入职 2026-01-15、试用期 3 个月（试用期自用工之日起算）
	onboard := time.Date(2026, 1, 15, 0, 0, 0, 0, time.Local)
	end := onboard.AddDate(0, 3, 0)
	fmt.Printf("\n入职 %s、试用期 3 个月 → 截止 %s\n", onboard.Format("2006-01-02"), end.Format("2006-01-02"))
	fmt.Printf("  试用期内离职最晚通知 = %s（提前 %d 日 [第 37 条]）\n", end.AddDate(0, 0, -noticeInProbation).Format("2006-01-02"), noticeInProbation)
	fmt.Printf("  转正评估节点(建议)   = %s（截止日前 %d 日，公司惯例非法定）\n", end.AddDate(0, 0, -evalLeadDays).Format("2006-01-02"), evalLeadDays)
	fmt.Printf("  转正后离职最晚通知   = %s（提前 %d 日书面 [第 37 条]）\n", end.AddDate(0, 0, -noticeAfterProb).Format("2006-01-02"), noticeAfterProb)
}
```

实测输出（go1.26.5 darwin/amd64）[实测]：合同 6 个月约 3 个月 → 违法（上限 1 个月）；合同 12 个月约 3 个月 → 违法（上限 2 个月）；合同 36 个月约 7 个月 → 违法（上限 6 个月）。工资校验第二条：约定 10000、同岗最低档 9000 时**下限是 9000 不是 8000**（取高规则）。时间线：截止 2026-04-15，试用期内离职最晚 2026-04-12 通知（提前 3 日），转正评估节点建议 2026-03-31。

## 总结与追问预判
一句话记忆：**「红线 → 时间线 → 表现」**——表现不好最多是丢工作，红线被踩是权利被侵。追问预判：「公司说不缴社保转正再补行吗」——不行，30 日内强制、放弃约定无效，可先沟通再投诉/仲裁。「早到晚走怎么看」——加班不是法定义务（[法条：劳动法第 41 条] 限制加班时长），出勤可当观察项，**转正评估最该看产出不是工时**；试用期届满单位未依第 39 条解除，劳动关系即继续为正式员工，不存在「不给转正又不解除」的悬置状态。录用条件三件事（明确/告知/签字）见 2001 [边界]。

## ⚠️ 原文纠错
1. 通篇把试用期定义为「公司的考察期 / 个人的适应期」，**从头到尾没有法律边界**——最大概念缺口。期限上限、工资下限、社保必缴、解除受限全是法定硬边界，恰恰是新人最该先知道的部分。
2. 「尽量要做到早到晚走」「早到比晚走更重要」——把公司惯例当通用标准。加班不是法定义务；转正评估该看产出；源文自己也说「晚走看团队风格」，前后自相矛盾。
3. 「积极争取转正机会」——方向对但易被误读成「转正是争取来的、单位可单方不给」：试用期届满未依第 39 条解除即转正；单位想解除必须有明确、告知、签字的录用条件且能举证。
4. 「第一个…第三个…第三个…」——编号错乱，应为态度/学习/合作/问题解决四要素顺序。
5. 「注力」→注意、「活作」→合作、「焦急摸鱼」→消极摸鱼、「二是事事有回应」→「**而是**事事有回应」、「才能负责人出面」→「让负责人出面」、「重源」→资源，转写崩坏统一规范。
