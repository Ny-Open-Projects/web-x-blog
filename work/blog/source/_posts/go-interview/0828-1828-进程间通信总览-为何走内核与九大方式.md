## 一句话总述
进程间通信（IPC）的前提是：各进程用户地址空间相互独立、通常不能互访，但内核空间被所有进程共享——所以进程间数据交换必须经内核中转。常见方式含管道、消息队列、共享内存、信号、信号量、套接字、内存映射文件、RPC 等，按速度与场景各异。

## 面试官视角
- 意图：是否先讲清"为何必须 IPC"与"为何走内核"，再列举方式。
- P5 知用户空间独立、需内核；P6 能列举主要 IPC 方式；P7 知速度排序（共享内存最快、套接字跨网但延迟高）。
- 红旗：以为进程能直接读写彼此内存；混淆"共享内存快"与"它要自管同步"。
- 惊艳点：共享内存最快（零拷贝、免内核态往返），但需配信号量/锁自管同步；套接字可跨主机但有网络延迟 `[经验]`。

## 主问答
**Q（面试官原话）：** 什么是 IPC？为什么进程间通信必须经由内核？
**A：**
1. **隔离前提**：每个进程用户地址空间独立、互不可见，内核空间却由所有进程共享 `[源码]`。
2. **内核中转**：进程无法直接互访对方内存，数据交换必须经内核缓冲/中转完成。
3. **方式多样**：管道、消息队列、共享内存、信号、信号量、套接字、内存映射文件、RPC 等。
4. **速度梯度**：共享内存最快（免拷贝），套接字可跨网络但延迟高，按性能与场景选型。

## 关键代码
```go
// 示意，未验证：Go 用 os.Pipe 创建匿名管道，演示"经内核 fd 中转"的进程内 IPC
package main
import ("fmt"; "os"; "io")
func main() {
    r, w, _ := os.Pipe() // 匿名管道：返回读/写两个 fd
    go func() { w.Write([]byte("hello via pipe")) }()
    buf := make([]byte, 64)
    n, _ := r.Read(buf)
    fmt.Println("读到:", string(buf[:n])) // 经内核管道中转
    _ = io.Discard
}
```
