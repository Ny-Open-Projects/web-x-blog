> 分类：并发模型 | 难度：L2 | 题型：工程题 | 频率：高 | 关键词：**变量复制、参数传递、per-iteration、defer**

> 原文锚点：第 39~41 段「将变量 i 复制给 x，再打印 x…输出零到九」

## 一句话总述
在循环体里把迭代变量**复制一份**给局部副本，闭包捕获的就成了每轮独立的副本，这是 Go 1.22 之前最通用的修法。

## 面试官视角
P6 只会 `i := i`；P7 要给出**三条等价解法**并说清各自适用场景：循环内复制、作为函数参数传入、升级到 Go 1.22 语义 `[经验]`。加分点：判断依据是"闭包会不会在当前轮之后才执行"，同步执行的闭包根本不需要修，别无脑复制 `[源码]`。

## 主问答
**Q（面试官原话）：** 循环里起 goroutine，怎么保证每轮拿到自己的值？

1. **循环内复制**：`x := i` 后闭包引用 x，每轮一次新变量，输出恢复 0~9 `[实测]`。
2. **作为参数传入**：把值作为匿名函数参数 `go func(v int){...}(i)`，调用时即完成估值 `[源码]`。
3. **升级语言版本**：Go 1.22 起循环变量改为每轮独立，前提是 go.mod 声明对应版本；老模块不生效 `[经验]`。
4. **不必过度防御**：若闭包在当前轮内同步执行完，共享变量不会出问题，无脑复制只是噪音 `[经验]`。

## 关键代码
```go
for i := 0; i < 10; i++ {
	i := i          // 复制一份，闭包捕获副本
	go func() { fmt.Println(i) }()
}
// 等价写法：参数传入
for i := 0; i < 10; i++ {
	go func(v int) { fmt.Println(v) }(i)
}
```
> 验证：两种写法均输出 0~9 且无重复值 `[实测]`。
