## 一句话总述
Go 实现二叉树用**链式存储**：`TreeNode` 结构体含 `Val` 与左右指针 `Left/Right`。插入（二叉搜索树语义）递归进行——值小于当前节点插左子树、大于插右子树，找到 `nil` 位置即挂入。结构类似链表，只是节点多了一个指针。

## 面试官视角
- 考察意图：能否徒手写 `TreeNode` 定义与递归 insert，理解 BST 插入的比较逻辑。
- 分档：P5 知节点含左右指针；P6 能写递归 insert；P7 知 BST 性质、插入不自动平衡（退化为链表）。
- 红旗答案：insert 不递归到 nil 直接覆盖；混淆「值相等」插入方向。
- 惊艳点：点出「二叉树节点=链表节点多一指针」，以及「简单 insert 不保证平衡、退化时退化为链表需 AVL/红黑树」 [经验]。

## 主问答
**Q（面试官原话）：** 用 Go 怎么定义二叉树并插入节点？
**A：**
1. **结构定义**：`TreeNode` 含 `Val` + `Left/Right *TreeNode`，链式存储，相当于链表多一个指针 [经验]。
2. **递归插入**：值小于当前节点往左子树递归、大于往右子树递归，遇到 `nil` 子树即挂入新节点 [经验]。
3. **性质与边界**：此为 BST 语义；简单插入不自动平衡，极端有序插入会退化为链表——平衡需 AVL/红黑树 [经验]。

## 关键代码

```go
// Go 链式二叉树 + 递归插入（BST 语义）
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}
// 插入：值小插左、值大插右，遇 nil 挂入
func Insert(root *TreeNode, v int) *TreeNode {
    if root == nil {
        return &TreeNode{Val: v} // 找到 nil 位置挂新节点
    }
    if v < root.Val {
        root.Left = Insert(root.Left, v)
    } else if v > root.Val {
        root.Right = Insert(root.Right, v)
    }
    // 相等：本实现忽略（可按需挂左/右或计数）
    return root
}
// 注：简单插入不保证平衡，有序插入会退化为链表；平衡需 AVL/红黑树
```
