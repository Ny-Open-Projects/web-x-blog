## 一句话总述
Go 里"字面量（literal）"是值在代码中的文字写法；其中**组合字面量（composite literal）**专用于表示**结构体、数组、切片、映射**这四类聚合类型的值，而指针、通道、接口类型的值**没有字面量形式**，需用 `new`/`make`/构造等方式得到。

## 面试官视角
这是偏基础的题，但能区分"只会写 `struct{}`"和"真正理解类型系统与字面量体系"的候选人；常延伸到零值、nil 与组合字面量的关系。

## 主问答
**Q（面试官原话）：** Go 里哪些类型的值可以用组合字面量表示？

**A：**

1. **组合字面量的适用类型**：只有**结构体（struct）、数组（array）、切片（slice）、映射（map）**这四类聚合类型能用组合字面量 `Type{...}` 表示值；其余基础类型用各自基础字面量（如整数 `1`、浮点 `1.1`、虚数 `1.2i`、rune `'a'`、字符串 `"foo"`/`\`bar\``、函数 `func(...)`）。
2. **字面量 ≠ 组合字面量**：字面量是广义"值的文字写法"，组合字面量是特指聚合类型的值构造形式；数值、字符、字符串、函数各有自己的字面量，但只有四类聚合类型用"组合"形式。
3. **没有字面量形式的类型**：**指针（pointer）、通道（channel）、接口（interface）** 的值无法用字面量直接写出，必须通过 `new(T)`、`make(chan T)`、`var i I = impl{}` 等方式获得。
4. **零值特例**：切片和映射的**零值是 `nil`**，而组合字面量（如 `[]int{}`、`map[K]V{}`）得到的是**非 nil 的空容器**，二者不同（见边界卡）。

## 版本与兼容性
- 组合字面量语法自 Go 1.0 稳定；数组字面量省略长度（`[...]T{...}`）自 Go 1.0 支持。
- Go 1.13 起整数字面量作虚数虚部可非十进制（如 `0o10i`），此前虚部前的整数字面量必须为十进制。

## 关键代码
```go
// 基础字面量
n := 1          // 整数字面量（含 0b/0o/0x 形式）
f := 1.1e2     // 浮点字面量（十进制整数+小数点+小数+以10为底指数）
c := 1.2i      // 虚数字面量
r := 'a'       // rune 字面量（单引号）
s := "foo"     // 字符串字面量（双引号，UTF-8）
fn := func(x int) int { return x } // 函数字面量

// 组合字面量：仅结构体/数组/切片/映射
type Person struct{ Name string; Age int }
p := Person{Name: "a", Age: 1} // 结构体组合字面量
arr := [3]int{1, 2, 3}         // 数组组合字面量
sl := []int{1, 2}              // 切片组合字面量
m := map[string]int{"k": 1}    // 映射组合字面量
```

## 总结与追问预判
- 记忆口诀：**"结、数、切、映"四兄弟能用组合字面量；指、通、接三兄弟不能**。
- 预判追问：组合字面量和"零值"什么关系？答：四类聚合类型中，切片/映射的零值是 nil，组合字面量给的是非空容器，结构体/数组的零值（`Person{}` 之类）其实也可用组合字面量（空字段）表达——结构体/数组的零值**能**用组合字面量表，切片/映射的零值(nil)**不能**。
