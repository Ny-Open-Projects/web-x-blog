> 分类：算法 / 排序 | 难度：L1~L2 | 题型：实现题 | 频率：中 | 关键词：**插入排序**/**有序区扩张**/**移位插入**/**稳定排序**/**近有序 O(n)**

> 原文锚点：第 1~16 段「取未排序首个元素插入已排序部分…5 3 8 2 1 过程演示…n-1 次迭代…j=i-1 左移比较」

## 一句话总述
插入排序 = **打扑克理牌**：维护左侧有序区，每轮取未排序区第一个元素 `key`，从右往左把有序区中比它大的元素依次右移一位，最后把 `key` 插入空出的位置。n-1 轮后全有序。核心三行：`key=a[i]; while j>=0 && a[j]>key { a[j+1]=a[j]; j-- }; a[j+1]=key`。

## 面试官视角
- 意图：O(n²) 排序三件套（冒泡/选择/插入）的第三件，看能否不背模板、讲清「为什么移位比交换省」与「近有序数组近 O(n)」。
- 分档：P5 写对实现；P6 讲清与冒泡/选择的差异（移位 vs 交换、稳定性）；P7 能接希尔排序（分组插入）与近有序实战场景。
- 红旗答案：把移位写成两两 swap（对但白做功）；说不出插入排序是稳定的。
- 惊艳点：一句话定位三兄弟——**冒泡是相邻交换、选择是全局选最、插入是有序区移位**；数据近乎有序时插入排序反而最快 [经验]。

## 主问答
**Q（面试官原话）：** Golang 中如何实现插入排序？

**A：** 以源文例子 `[5,3,8,2,1]` 升序为例 [实测]：

1. **过程**：首元素 5 自成有序区 → 取 3 插到 5 前 → 取 8 插到 5 后 → 取 2 移到 3 前（依次和 8/5/3 比较、右移）→ 取 1 插到最前 → `[1,2,3,5,8]`。
2. **实现**：外层 `i` 从 1 到 n-1（n-1 轮），`key=a[i]` 暂存待插元素；内层 `j=i-1` 起左扫，`a[j]>key` 就 `a[j+1]=a[j]` 右移，停住后 `a[j+1]=key` 归位。
3. **复杂度**：最坏/平均 O(n²)（逆序时比较+移位全满）、最好 O(n)（已序，每轮只比较一次不移位）；空间 O(1)；**稳定**（大于才移，等于不动，相对序不乱）。
4. **对比定位**（详见各卡）：冒泡相邻两两交换见 1714，选择每轮全局选最见 1715，插入每轮只做一次「移位+落位」——同样的 O(n²)，常量更小、且近有序时近似 O(n)。

## 关键代码
```go
package main

import "fmt"

func insertionSort(a []int) {
	for i := 1; i < len(a); i++ { // n-1 轮，a[0] 自成有序区
		key := a[i]               // 待插元素
		j := i - 1
		for j >= 0 && a[j] > key { // 有序区比 key 大的右移
			a[j+1] = a[j]
			j--
		}
		a[j+1] = key // 归位
	}
}

func main() {
	for _, s := range [][]int{{5}, {5, 3}, {5, 3, 8, 2, 1}} {
		insertionSort(s)
		fmt.Println(s)
	}
}
```

[实测] 输出：`[5]` / `[3 5]` / `[1 2 3 5 8]`，与源文演示逐例一致。

## 总结与追问预判
核心：**三行内层循环是肌肉记忆；答题必带「稳定 + 近有序 O(n)」两个卖点**。追问往对比与工程走：冒泡对比见 1714 与 `1714-bubble-vs-selection.deep`、选择排序见 1715 与 `1715-selection-two-way.deep`、快排见 1717、复杂度分析方法见 1711；标准库收尾用插入类排序的工程事实可引 `1250-custom-sort-null-last` 的 sort 实践。
