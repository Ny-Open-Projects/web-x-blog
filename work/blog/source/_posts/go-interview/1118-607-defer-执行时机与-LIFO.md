> 分类：错误处理 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**defer 时机** / **return 求值** / **LIFO**
> 原文锚点：第 1~13 段「return 表达式先计算存入返回值寄存器再执行 defer」

## 一句话总述
defer 在函数 return 之前、return 表达式求值之后执行；多个 defer 按声明逆序（LIFO）出栈。

## 面试官视角
- 意图：是否真懂 return 与 defer 的先后，而非只背"延迟执行"。
- 分档：P5 知延迟 / P6 说清 return 先求值再 defer / P7 知命名返回值被 defer 改。
- 红旗：以为 defer 在 return 之后；以为按顺序执行。
- 惊艳点：return s+s 等价于 r=s+s;return，defer 在此间改写 r `[源码]` 语言规范。

## 主问答
**Q（面试官原话）：** defer 到底在什么时候执行？多个 defer 什么顺序？
**A：**
1. **结论**：defer 在 return 语句的"表达式求值"之后、函数真正返回之前执行。
2. **机制**：return 先把结果写入返回值寄存器，再依次弹出 defer 栈执行；栈是 LIFO，后声明先跑。
3. **边界**：defer 执行晚于 return 表达式，但早于控制权交还调用方，故可改命名返回值。
**加分层：** LIFO 顺序常被用来做"后注册先释放"的资源清理，顺序写错会泄漏。

## 总结与追问预判
- return 先求值入寄存器，再 LIFO 执行 defer，最后返回。
