## 一句话总述
算法面试备考本质是**刷题**，但决定效果的不是刷了多少，而是六条纪律：先独立思考再查答案、必须动手写、不熟的题重复刷到脱稿、笔试遗留题回头补熟、重点刷高频题型、基础题（快排/二分/树遍历）练到闭眼能写。

## 面试官视角
- 考察意图：不只看你会多少算法，更看**自驱准备方法**与**动手熟练度**——很多候选人「一学就会一写就废」。
- 分档：P5 知刷题重要；P6 能说出系统方法（六法）并动手实现；P7 能按目标公司归类高频题、制定重复刷计划。
- 红旗答案：只说「多刷 LeetCode」无方法；认为看视频/文档=掌握（从不独立写）。
- 惊艳点：点出「独立思考发生碰撞才记得牢」「不熟重复刷到不看答案也能写」「按公司历年题归类高频三类(查找/动态规划/分治)」 [经验]。

## 主问答
**Q（面试官原话）：** 怎么准备数据结构和算法的面试？
**A：**
1. **先独立思考再查答案**：看完题先自己求解，只有「思考发生碰撞」理解才深、才不易忘；直接看答案省时但损效果 [经验]。
2. **必须动手写一遍**：「自己动手写一遍胜过看别人写十遍」，很多「一学就会一写就废」就是没独立实现过 [经验]。
3. **不熟的题重复刷**：参考完答案才能写出的题，要重复刷到**不看答案也能很快写出来**为止 [经验]。
4. **笔试遗留题回头补熟**：笔试没写出的题，后续面试大概率再被问「现在有没有思路」；能答出甚至多法实现印象极好 [经验]。
5. **重点刷高频题型**：大厂高频三类是**查找、动态规划、分治**；按目标公司(如字节)历年题归类，出现频率最高的几类重点准备 [经验]。
6. **基础题闭眼能写**：快排、二分查找、二叉树前/中/后序遍历要达到闭眼能写；连基础题都答不出基本被判死刑 [经验]。

## 关键代码

```go
// 二分查找：有序切片中定位 target，未找到返回 -1
// 面试「基础题闭眼能写」代表：边界(空/单元素)、循环不变量 lo<=hi、mid 防溢出
func binarySearch(a []int, target int) int {
    lo, hi := 0, len(a)-1
    for lo <= hi {
        mid := lo + (hi-lo)/2 // 防 (lo+hi) 溢出
        if a[mid] == target {
            return mid
        } else if a[mid] < target {
            lo = mid + 1
        } else {
            hi = mid - 1
        }
    }
    return -1
}
```

## 总结与追问预判
算法面试 = 「程序 = 算法 + 数据结构」，数据结构是算法落地的存储基础。面试常追问「你刷了多少、怎么刷」→ 用六法回答显得有方法而非盲目刷题；再被追问具体算法时，用「快排/二分/遍历闭眼能写」证明基础扎实。
