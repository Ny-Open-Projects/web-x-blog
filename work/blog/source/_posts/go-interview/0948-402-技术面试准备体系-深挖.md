> 覆盖源 4-2 全文：五大范围 + 针对性准备 + 信息vs知识 + 漏题扩展复盘 + 80/20。主卡已给总纲，本附录做「五大范围自查清单」与「检索式学习执行节奏」。

## 思路与架构

```text
技术面试准备执行体系
├─ 五大范围自查: DB·缓存 / 算法 / OS·网络 / 语言特性 / 项目经历
├─ 检索式学习: 导图(知识点→问题→答案) → 折叠自述 → 讲不清即回头补
└─ 复盘扩展: 一道漏题 → 扩散到相关知识域(如 redo log → 全日志家族 + 事务)
```

## 方案取舍
- **广度 vs 重点**：先铺齐五大范围（避免致命盲区），再按 80/20 把多数时间压到高频重点；顺序不可颠倒，否则容易在基础面上翻车 [经验]。
- **被动阅读 vs 主动检索**：精读资料拿到的只是「信息」，信息必须经自己编码才算「知识」；用「折叠答案自述」强制检索，比重复阅读高效得多 [经验]。
- **单题补救 vs 知识域扩展**：只补那一道题见效快但脆弱，面试官换个问法就露怯；扩展到知识域（如 MySQL 日志全家族）才能覆盖追问 [经验]。

## 答题技巧
- 被问「怎么准备」按「范围 → 方法 → 主次 → 复盘」四段答，显章法 [经验]。
- 重点考点来源按优先级排：JD 明确要求 > 简历技能点 > 通用高频（前两者直接决定通过率）[经验]。
- 主动边界到 `171`(算法备考)、`802`(runtime 备考)、`1003`(并发答题)、`112`(STAR 案例)，构成准备全栈 [边界]。
