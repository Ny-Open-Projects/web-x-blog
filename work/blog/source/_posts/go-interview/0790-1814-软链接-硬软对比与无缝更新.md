## 一句话总述
软链接（符号链接）是一个独立的特殊文件，内容存放「指向目标的文件路径」，类似 Windows 快捷方式——删原文件即成死链。它新建独立 inode、可跨文件系统、可链目录。硬软链接的本质区别就在「是否共享 inode」。

## 面试官视角
硬软对比是文件系统面试的高频收尾题。考官期待一张清晰的对比表，并能用「inode 是否共享」一句话点透。能举「软件无缝更新靠 inode 分离」的应用案例是 P7 加分项。

## 主问答
**Q（面试官原话）：** 软链接和硬链接有什么区别？各有什么用？

1. **软链接指向路径而非 inode**：`ln -s 原 目标` 生成新 inode，文件内容是目标路径；删原文件后软链变死链（访问报 No such file or directory），删软链不影响目标。
2. **硬软核心区别**：硬链接共享原 inode（同文件多名字）；软链接有独立 inode，只是存了路径。故硬链不能跨 FS、不能链目录；软链两者皆可。
3. **删除表现**：删软链不影响目标；删硬链只减链接数，0 才删原文件。
4. **inode 分离的应用**：因文件名与 inode 解耦，运行中程序靠 inode 号识别文件——更新时新文件用同名生成新 inode，不影响运行中的旧版，下次启动才指向新版，实现无缝更新。

## 关键代码
```bash
ln -s /real/file.txt link.txt   # 软链接
readlink link.txt               # 看指向路径
```

## 总结与追问预判
核心：**软链=路径指针(独立inode)、可跨FS可链目录、删原成死链；硬链=同inode、受限制**。追问可延伸到「为什么软件热更新靠 inode」——文件名换、inode 不换，运行中进程无感知。
