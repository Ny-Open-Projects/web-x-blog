## 纲要

- **大模型本质**：生成式自回归模型，工作是「文字接龙」——逐 token 串行生成；采用流式输出（先生成先展示）降低延迟。
- **下一个 token 如何定**：模型先输出所有候选 token 的概率，按概率高低采样；并非永远选最高概率，因此同问题答案有随机性。
- **token 与分词**：token 是介于字母与单词之间的「子词」，是几乎所有大模型的计费单位（GPT-4o 输入 $5 / 百万、输出 $15 / 百万；DeepSeek 输入 ¥1 / 百万、输出 ¥2 / 百万）；词表规模 GPT-3=5 万、Qwen2=15 万、Llama3.1=12 万；BPE 分词通过「最小粒度 → 两两合并词频最高」循环生成词表。
- **Transformer 架构**：2017 Google《Attention Is All You Need》，encoder-decoder；主流 LLM 采用 decoder（逐 token 生成），核心是 multi-head self-attention，捕捉每个 token 与全局 token 的语义关联（弥补 RNN/LSTM 不足）。
- **训练三阶段**：预训练（海量数据打基础）→ 指令微调（人工标注指令数据做特定任务）→ 基于人类反馈的强化学习 RLHF（奖励模型作「导师」，相对排序标注，对齐安全与可用）。
- **能力分类**：基础能力（世界知识 / 理解 / 阅读总结 / 代码 / 多语）、涌现能力（推理 / 指令跟随）、增强能力（自我批判 / 工具使用）。
- 本章按课程口径重构；产品名 / 框架名已规范化（GPT-4o / DeepSeek / Qwen / Llama / BERT / BPE / RLHF）；剥离营销与课程群引流。

## 一、大模型是如何「接龙」的

- **自回归生成**：输入问题后，模型先生成一个字，再把「输入 + 已生成字」送回模型生成下一个字，直到结束符。例如回答「什么是大模型」可能 13 字 + 1 结束符 = 14 次推理，且串行耗时。
- **流式输出的原因**：内容多时逐字生成相当耗时，先生成先展示能显著降低体感延迟。
- **下一个 token 的确定**：模型对全部候选 token 输出概率，按概率采样；概率越高越可能被选中，但也会给次高概率一定机会——这正是「同一问题答案不一定相同」的根源（随机性）。

## 二、token 与 BPE 分词

- **token 是子词**：介于字母与单词之间。用单词作 token 会导致词表爆炸与 OOV（未登录词 unk）；用字母则丧失语义。子词兼顾语义与词表规模。
- **计费单位**：token 是计费粒度，国内外价格差异大（如 DeepSeek 远低于 GPT-4o）。
- **BPE 算法**：给定语料 → 拆成最小粒度（字母 / 汉字）作初始词表 → 两两合并、统计词频最高组合 → 循环并入新 token，直到达到词表阈值。例：`e,s`→`es`→`est`。
- **逆分词**：模型输出也是 token，需经逆分词转回可读文本。

## 三、Transformer 与 self-attention

- **架构来源**：2017 Google 论文提出 encoder-decoder；encoder 产出全局语义特征（BERT 类），decoder 负责逐 token 生成（当前主流 LLM 采用），末端分类层预测下一 token 概率。
- **核心机制**：multi-head self-attention 让每个 token 与上下文所有 token 建立关联（可视化中颜色越深关联越强）。例：句中 `it` 通过自注意力判定指代 `animal` 而非 `stick`——弥补了 RNN / LSTM 在长程依赖上的不足。
- **发展史（以 OpenAI 为例）**：GPT-1（2018，1.2 亿）→ GPT-2（2019，15 亿）→ GPT-3（1750 亿），均为 decoder-only；规模定律带来性能跃升，GPT-4 / 4o 进一步拓展多模态。

## 四、训练三阶段：预训练 → 指令微调 → RLHF

- **预训练**：在海量无标注语料上学通用基础技能（阅读 / 写作等），相当于「从小学到大学」。
- **指令微调**：用人工标注的指令数据（任务描述 + 答案）增强特定任务能力，相当于「岗位培训」。
- **RLHF**：训练一个奖励模型充当「导师」，用相对好坏（而非绝对分数）标注人类偏好，据此更新权重，使模型对齐安全与可用——相当于「导师指导，做好奖励、做差惩罚」。
- 三者构成当今几乎所有大模型训练的标准框架。

## 五、大模型的能力分类

- **基础能力**：世界知识、理解、阅读理解与总结、代码、多语言等。
- **涌现能力（emergent）**：规模突破临界点后突然出现的推理、指令跟随等能力（小模型无）。
- **增强能力**：自我批判、使用外部工具等（模型自我提升）。

## 六、FAQ

**Q1：为什么大模型回答会「逐字蹦」？**
因自回归逐 token 生成，且串行推理耗时；流式输出是为降低延迟的产品取舍。

**Q2：token 为什么不用整词？**
整词词表过大（时态 / 变形），且新词会 OOV；子词用组合覆盖新词，兼顾语义与词表规模。

**Q3：self-attention 解决了什么？**
捕捉 token 间全局依赖，正确消解指代等语义关系，克服 RNN/LSTM 长程遗忘。

**Q4：RLHF 中的「导师」是什么？**
一个由人类偏好数据训练出的奖励模型，判定生成结果好坏，用以强化学习对齐人类价值观。

## 七、面试高频问答

**1. 简述大模型自回归生成过程。**
输入文本 → 分词为 token → 模型预测下一 token 概率并采样 → 拼接回输入循环 → 直到结束符；输出 token 经逆分词还原文本。

**2. 什么是 token？为什么用子词而非单词？**
token 是模型处理与计费的基本单位，是介于字母与单词的子词；子词避免词表爆炸与 OOV，且保留语义组合能力。

**3. Transformer 的核心是什么？**
multi-head self-attention，用于建模每个 token 与全局 token 的语义关联。

**4. 预训练、指令微调、RLHF 各自作用？**
预训练打通用基础；指令微调增强特定任务；RLHF 以奖励模型对齐人类安全与可用性偏好。

## 八、ops 提示（增效）

> **理解随机性**：同 prompt 不同输出是概率采样所致，评测时需多次取稳定结论。
>
> **训练三段论**：判断一个模型「能不能训」，先看它处在预训练 / SFT / RLHF 哪一段。
>
> **能力分层**：基础 / 涌现 / 增强三类能力决定「该用多大模型、花多少算力」。
