## 纲要

- **知识图谱定义**：表示「实体及其关系」的结构化图形。节点=实体（人/地点/事物/概念）及其属性（名称/类型/描述），边=实体间关系。目的：把现实世界信息以结构化方式组织，让机器高效理解处理。
- **核心表示：三元组（主体 - 谓语 - 客体）**：主体（实体/节点）、谓语（主体与客体间的关系或属性，常为动词短语）、客体（另一实体或属性值）。例：`詹姆斯 - like - 蒙娜丽莎画像`。
- **关系有方向性**：「认识」相互无向；「住在北京」有向（只能张三住北京，不能倒过来）。
- **知识图谱三大特点**：① 图形结构化（节点+边天然带语义关联）；② 强语义性（明确关系类型/属性，利于深层理解）；③ 支持推理推断（由已知关系链传递/对称性推出新事实）。
- **典型应用**：医疗诊断（病症→疾病推断）、推荐系统（用户-商品关联推断）、问答系统（查节点属性/关联节点综合推理）。
- **本章金融智库数据（两类）**：① **风险事件数据**（来自 OpenKG IREE 数据集，15 行业 / 4000+ A股公司 / 59 类风险事件，覆盖财报/运营/声誉危机如裁员）；② **企业投资数据**（投资机构→企业的投资关系、轮次、时间，及企业信息/专利）。
- 本章按课程口径重构；产品/数据集名已规范化（OpenKG / IREE）；剥离营销与课程群引流。

## 一、什么是知识图谱

知识图谱是用图形结构表示实体及关系的数据库。它不只存实体，还建立实体间的语义关系——这种图结构本身**天生带语义关联**，不需额外操作即可从节点关系中读出的信息。

**三元组**是知识图谱最典型的表示方式：
- **主体（Subject）**：要描述的实体/对象，通常是图中某个具体节点（人/地点/事物）。
- **谓语（Predicate）**：主体与客体之间的关系或属性，常为动词/动词短语，负责把不同实体连接成图。
- **客体（Object）**：与主体相关联的另一实体，或某个属性值（字符串/数值）。

> 例：`詹姆斯 - like(喜欢) - 蒙娜丽莎画像`；`蒙娜丽莎 - 被画于 - 卢浮宫`；`卢浮宫 - 位于 - 巴黎`。

**关系方向性**：「张三-认识-李四」相互无向；「张三-住在-北京」有向，不能反说「北京住在张三」。

## 二、知识图谱三大特点

1. **图形结构化**：节点表实体、边表关系，信息在语义层面天生关联，从图结构即可读出节点间关系。
2. **强语义性**：明确的关系类型与属性描述实体连接，利于更深层次理解。
3. **支持推理推断**：可从已知信息推出新事实（通过关系链传递、对称性等）。例：已知 A 是 B 的朋友、B 是 C 的朋友，可推断 A 与 C 的间接关联。

## 三、典型应用场景

| 场景 | 做法 | 价值 |
| --- | --- | --- |
| 医疗诊断 | 整合病症/体征/病史+医学知识库，由症状关联推断疾病 | 推断最可能的疾病（流感 or 肺炎） |
| 推荐系统 | 构建商品关系 + 用户兴趣图谱，结合历史行为推断 | 推「常一起购买」的关联商品 |
| 问答系统 | 查实体节点属性 / 关联节点综合推理 | 如「爱因斯坦出生年份」直接取节点属性值 |

三类场景的共性：**找到与问题相关的节点 → 取其属性或关联节点 → 综合推理出有价值信息**，这是知识图谱最大价值。

## 四、本章金融智库数据

为辅助金融决策/投研（快速归集企业投资关系与风险事件），使用两类知识图谱数据：

- **风险事件数据（IREE，来自 OpenKG）**：投资领域细粒度风险事件抽取数据集。描述企业市场行为/财报/运营/信誉/声誉问题（如裁员、股权质押、业绩承诺未达标）。覆盖 **15 个行业、4000+ 家 A 股上市公司、59 类风险事件**。原始为 JSON 行格式，事件信息存于 `label` 字段（事件类型 + 主体 + 时间/数值等属性）。
- **企业投资数据**：描述投资机构对企业的投资关系。含三类对象：投资者（id/名称/投资轮次/时间）、公司（id/名称/别名/经营时间/地址/专利）、专利（名称/类型/id）。关系如「投资者-投资-公司」「公司-拥有-专利」。

> 这两份数据后续将被解析、预处理、转成三元组，存入图数据库，再用于构建 Graph RAG 金融智库应用。

## 五、FAQ

**Q1：三元组和传统表结构有何不同？**
表结构扁平、关系靠外键隐式表达；三元组用「主体-谓语-客体」显式表达关系，天然适合多跳推理与语义关联查询。

**Q2：为什么知识图谱能支持推理？**
因为关系以图结构显式存储，可沿边做多跳遍历与传递推理，而不仅是关键词匹配。

**Q3：IREE 数据集是什么？**
OpenKG 下的投资领域细粒度风险事件抽取数据集，含 59 类企业风险事件，是本章金融智库风险图谱的数据源。

**Q4：金融数据里为什么有 id 而不是直接写公司名？**
投资关系数据用 id 关联（省存储、防重），构建图谱时需把 id 映射回公司全称等属性，并做公司名一致性处理。

## 六、面试高频问答

**1. 知识图谱的核心表示？**
三元组：主体 - 谓语 - 客体（实体-关系-实体/属性值）。

**2. 知识图谱三大特点？**
图形结构化、强语义性、支持推理推断。

**3. 知识图谱典型应用？**
医疗诊断、推荐系统、问答系统（共性：找相关节点→取属性/关联→推理）。

**4. 本章金融智库用哪两类数据？**
风险事件数据（IREE/OpenKG，59 类风险事件）与企业投资数据（投资关系+公司+专利）。

## 七、ops 提示（增效）

> **图谱 vs 向量库选型**：需多跳关系/语义关联/聚合统计 → 上图谱；纯语义相似匹配 → 向量库足够。两者常互补（见后续混合）。
>
> **数据预处理是图谱质量命门**：id 映射、公司名别名一致性（如「格力电器」↔「珠海格力电器股份有限公司」）做不好，关系就断链。
>
> **关系方向性别搞反**：建模时明确谓语方向，否则图遍历会漏掉或错误关联。
