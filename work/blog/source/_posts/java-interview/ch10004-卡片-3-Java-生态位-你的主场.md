### 卡片 3：Java 生态位（你的主场）
- **Spring AI**：统一模型抽象（Chat/Embedding/VectorStore）、RAG/Function Calling 支持，Java 工程师首选入口；
- **LangChain4j**：轻量级 LLM 应用框架；
- **LangGraph / Dify / n8n**：可视化编排（Python 系为主，但平台层 Java 可对接）；
- **MCP（Model Context Protocol）**：Anthropic 发起的工具/数据接入标准协议——Agent 接入外部世界的 USB 接口，Java SDK 已可用。
