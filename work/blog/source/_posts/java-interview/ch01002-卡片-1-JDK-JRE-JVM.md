### 卡片 1：JDK / JRE / JVM
- **JVM**：虚拟机，负责把字节码（.class）翻译成机器码执行。一次编译，到处运行。
- **JRE** = JVM + 核心类库（java.lang、java.util 等），只能运行程序。
- **JDK** = JRE + 开发工具（javac 编译器、jdb 调试器、jstack/jmap 排查工具），能开发程序。
- 记忆口诀：**JDK 开发用，JRE 运行用，JVM 是心脏**。
