### 题 10.3.2：LLM 应用的成本怎么控制？模型网关怎么设计？

**【参考回答（可背）】**
成本结构：成本 = token 单价 × token 量 × 调用次数。四刀砍下去：
1. **降单价**：模型分级路由（简单任务小模型/规则引擎，复杂任务大模型；分类器先分流）、私有化小模型承接高频固定任务（微调/Distill）、供应商比价与缓存供应商；
2. **降 token 量**：Prompt 精简与模板复用、上下文裁剪（只给相关块）、历史摘要压缩、输出长度约束（max_tokens + 结构化少废话）；
3. **降次数**：**语义缓存**（相同/相似问题直接返回缓存， embedding 相似度判定 + TTL + 知识更新失效）、批处理接口（离线任务 batch API 半价）、合并调用；
4. **架构手段**：流式输出（降低首字延迟不省钱但提升体验）、预算熔断（用户/租户级限额）、请求排队削峰。
**模型网关设计（背架构）**：统一 API（屏蔽供应商差异）→ 路由（模型分级/AB）→ 限流与配额 → 缓存层 → 重试与降级（主模型挂切备模型）→ 计量计费（token 记账到租户）→ 全链路日志（Prompt/响应留存审计）。等价于"AI 时代的 API 网关 + 成本中心"。

**【追问链】**
1. Prompt 管理怎么做？→ 版本化（Git 管理模板）、变量注入与转义、灰度发布 Prompt、评测集回归后再全量——Prompt 是代码，要有 CI。
2. 降级链路？→ 大模型 → 小模型 → 规则兜底 → 友好失败文案。AI 功能也要有熔断。

**【P10 加分项】**
给 ROI 叙事："客服 Agent 上线后，人工会话占比从 100% 降到 40%，单会话成本从 3 元降到 0.4 元（含模型与基础设施），满意度持平——AI 项目的验收语言是业务指标（解决率/人力释放/转化率），不是 token 数。"
