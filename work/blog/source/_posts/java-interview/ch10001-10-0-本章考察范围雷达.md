# 第 10 章 AI 时代：LLM、Agent 与 AI 应用架构 —— Java 工程师的 AI 考察新地图

> 2025~2026 年的 P10 面试新增了一整块内容：**AI 应用架构能力**。
> P10 不要求你会训练模型，但必须能回答：
> "怎么把 LLM 落进一个亿级用户的现有系统？怎么治理幻觉与成本？Agent 平台怎么架构？"
> 本章是全卷面向未来的一章，也是当前面试差异化最大的地方。

---


## 10.0 本章考察范围雷达

| 维度 | P5-P6 | P7-P8 | P9-P10 |
|------|-------|-------|--------|
| LLM 基础 | 会调 API、懂 Token | 推理成本结构、上下文工程 | 模型选型与私有化决策 |
| RAG | 概念清楚 | Embedding/检索/重排全链路 | 评估体系与效果治理 |
| Agent | 会用 Function Calling | ReAct/规划/记忆架构 | 多 Agent 平台、MCP 生态 |
| 工程化 | Prompt 会写 | 成本控制、网关、灰度 | AI 中台、ROI 与组织落地 |
