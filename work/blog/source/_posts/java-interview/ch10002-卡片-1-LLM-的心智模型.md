### 卡片 1：LLM 的心智模型
LLM 是一个**基于上下文的文本续写概率机器**：输入 token 序列，输出下一个 token 的概率分布。
推论（工程必懂）：
1. 它**没有数据库**，知识停在训练截止日 → 需要外部知识（RAG）；
2. 它会**一本正经编造**（幻觉），因为目标是最像而不是最对 → 需要引用与校验；
3. 输出质量强依赖输入（上下文）→ **Prompt 工程本质是上下文工程**；
4. Token 计费：1 个汉字约 1~2 token，上下文窗口 = 输入+输出共享（如 128K/1M）。
