【标准回答话术】HikariCP 是 Spring Boot 2.0+ 默认连接池（字节码优化+FastList+无锁设计最快）。背后的原理是：关键参数：maximumPoolSize（经验公式 core×2+磁盘数，连接不是越大越好）、connectionTimeout、maxLifetime（小于 MySQL wait_timeout）。
