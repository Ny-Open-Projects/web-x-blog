### 卡片 4：Spring Boot 解决了什么？
不是新框架，是 Spring 的**约定优于配置层**：自动装配（按 classpath 条件装配 Bean）+ Starter 依赖聚合 + Actuator 生产特性。"Spring Boot 的本质是：**把'如何配置'的决策权收编到框架，团队配置漂移归零**。"
