> 分类：算法与数据结构/栈与队列 | 难度：L2 | 题型：八股题 | 频率：中 | 关键词：**DFS 用栈** / **BFS 用队列** / **底层结构** / **回溯**
> 原文锚点：第 5~6 段「在深度优先遍历的时候我们使用栈，在广度优先遍历的时候我们使用队列来作为辅助」

## 一句话总述
栈和队列本身简单，却是**图遍历与众多高级结构的底层**：DFS 靠栈（一路走到底再回溯），BFS 靠队列（一层一层扩散）；Python 没有内置栈类型，用 `list`/`deque` 替代，二者常因 **LIFO/FIFO 易混**而放在一起考。

## 面试官视角
- **考察意图**：看你能否把"小结构"和"大算法"连起来，形成知识网而非孤立记忆。
- **P5** 只会说栈是后进先出 / **P6** 能举出 DFS/BFS 两个消费者 / **P7** 还能说出回溯、单调栈、表达式求值、消息队列等延伸 `[经验]`。
- **红旗**：① 说"Python 有 Stack 类"；② 认为递归 DFS 不用栈（递归调用栈就是栈）；③ 把 BFS 的队列换成栈后仍称"层序"。
- **惊艳点**：一句话串起来——**DFS 的递归实现等价于显式栈，BFS 必须用队列**；把 DFS 的栈换成队列就变成 BFS，反之亦然。验证：同一张图，两种容器跑出不同访问顺序 `[实测]`。

## 主问答
**Q：栈和队列除了本身，还在哪些地方充当底层结构？**
**A：**
1. **图/树的遍历**：**DFS 用栈**（深度优先，走到底再回溯；递归写法本质就是调用栈），**BFS 用队列**（广度优先，按层扩散，见 85）。
2. **算法工具**：栈支撑**回溯**（撤销上一步）、**单调栈**（下一个更大元素）、**表达式求值与括号匹配**；队列支撑**消息队列、任务调度、滑动窗口**。
3. **Python 落地**：标准库**没有 Stack 类型**，用 `list`（尾部 append/pop，O(1)）或 `collections.deque`（两端都 O(1)）实现；**别用 `list.pop(0)` 当队列**（O(n)，见 69）。
**加分层**：因为一个 LIFO 一个 FIFO 容易记混，面试常**两个一起问**，甚至直接要求"用栈实现队列"（71）。

## 关键代码
```python
from collections import deque

graph = {"A": ["B", "C"], "B": ["D"], "C": ["D"], "D": []}

def dfs(start):                       # 显式栈：走到底再回溯
    seen, out, stack = set(), [], [start]
    while stack:
        n = stack.pop()
        if n in seen: continue
        seen.add(n); out.append(n)
        stack.extend(reversed(graph[n]))
    return out

def bfs(start):                       # 队列：按层扩散
    seen, out, q = {start}, [], deque([start])
    while q:
        n = q.popleft(); out.append(n)
        for nxt in graph[n]:
            if nxt not in seen:
                seen.add(nxt); q.append(nxt)
    return out

print(dfs("A"))   # ['A', 'B', 'D', 'C'] —— 深度优先
print(bfs("A"))   # ['A', 'B', 'C', 'D'] —— 广度优先
```
