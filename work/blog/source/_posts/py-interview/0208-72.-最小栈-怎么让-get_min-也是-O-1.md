> 分类：算法与数据结构/栈 | 难度：L3 | 题型：工程题 | 频率：高 | 关键词：**辅助栈** / **MinStack** / **同步压弹**
> 原文锚点：第 105~109 段「如何去使用栈来去实现一个最小值栈…每一次我们需要获取它的最小值」

## 一句话总述
最小栈 = **主栈 + 辅助最小栈**：辅助栈**同步**压入"当前最小值"（重复值也要压），弹出时同步弹；这样 `min()` 直接取辅助栈栈顶，**全程 O(1)**。

## 面试官视角
- **考察意图**：考察"用空间换时间"和**不变量**的维护。
- **P5** 想到再开一个栈 / **P6** 能写对同步压弹与重复值处理 / **P7** 能给出更省空间的"差值编码"变体并说明适用场景。
- **红旗**：① 辅助栈只在新值更小时才压，但弹出时无条件弹（会错位）；② `min` 时 `min(...)` 全栈扫描（O(n)）；③ 忽略重复最小值的处理。
- **惊艳点**：**只在 ≤ 当前最小值时压**配合"弹出时仅当等于栈顶才弹"可省空间，但**重复值必须都压**，否则连续相同最小值会被提前弹空。验证：`push(2),push(2),pop(),min()` 用例 `[实测]`。

## 主问答
**Q：设计一个栈，能在 O(1) 时间内返回最小值。**
**A：**
1. **先给结论**：用**两个栈**——`data` 存数据，`mins` 存"压入该元素时的当前最小值"，两者**严格同步**压弹。
2. **再给规则**：`push(x)` 时把 `min(x, mins[-1])`（栈空则为 x）压入 `mins`；`pop()` 时两个栈**同时弹**；`min()` 返回 `mins[-1]`。
3. **最后给边界**：`min()` 在空栈时要明确约定（抛异常）；重复最小值**必须重复压入**，否则弹出次数不匹配。
**加分层**：更省空间的做法是 `mins` 只在**出现新的更小值**时压 (value, count)，或存**差值编码**（需支持减法与溢出处理）；但同步压弹版最直白、最不容易写错，面试首选。

## 关键代码
```python
class MinStack:
    def __init__(self): self.data, self.mins = [], []
    def push(self, x):
        self.data.append(x)
        self.mins.append(x if not self.mins else min(x, self.mins[-1]))
    def pop(self):
        if not self.data: raise IndexError("pop from empty stack")
        self.mins.pop(); return self.data.pop()     # 同步弹
    def min(self):
        if not self.mins: raise IndexError("min from empty stack")
        return self.mins[-1]
    def __len__(self): return len(self.data)

s = MinStack()
for x in (3, 1, 2, 1): s.push(x)
print(s.min(), s.pop(), s.min())   # 1 1 1 —— 重复最小值仍正确
```
