> 分类：编程范式/面向对象设计 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**组合** / **继承** / **has-a** / **is-a**
> 原文锚点：第 30~41 段「有组合并且继承都能完成这个功能的时候，优先使用组合」

## 一句话总述
**组合**是"类里持有其他类的实例"= **has-a**（有一个），**继承**是"子类扩展父类" = **is-a**（是一个）；两者都能完成时**优先用组合**，因为继承会带来**类膨胀与强耦合**。

## 面试官视角
- **考察意图**：考设计取向而非语法——能不能忍住不写继承。
- **P5** 背出 has-a/is-a / **P6** 举出标准库例子（Stack 持有 deque、Counter 继承 dict）/ **P7** 能说出**脆弱基类**问题并给出"优先组合 + 薄继承"的判断 `[经验]`。
- **红旗**：① 把"代码复用"当成用继承的理由（组合同样能复用）；② 举不出任何组合实例；③ 认为继承层次深一点无所谓。
- **惊艳点**：标准库就是答案——**`Stack` 用组合包 `deque`（has-a），`Counter`/`defaultdict` 用继承扩展 `dict`（is-a）**；判断标准：想复用**行为**用组合，想复用**接口契约**才用继承。验证：`collections.Counter.__mro__` 可见 `dict` 在其后 `[实测]`。

## 主问答
**Q：组合和继承有什么区别？什么时候用哪个？**
**A：**
1. **组合**：把**其他类的实例作为自己的属性**，方法**委托**给它，是 has-a；如 `Stack` 内部持 `deque`，`push/pop` 转调 `append/pop`。
2. **继承**：子类继承父类，是 is-a；如"狗是一种动物"→ `Dog(Animal)`；`Counter`/`defaultdict` 是 `dict` 的子类。
3. **取向**：两者都能完成时**优先组合**，让代码保持简单；继承容易造成**代码膨胀**，父类一改子类全受影响。
**加分层**：继承会**暴露父类全部接口**（`Counter` 因此拥有 dict 所有方法），不想暴露就只能用组合；这是"组合优于继承"的工程根因。

## 关键代码
```python
from collections import deque, Counter

class Stack:                          # 组合：has-a deque
    def __init__(self):
        self._d = deque()

    def push(self, x): self._d.append(x)   # 委托
    def pop(self):      return self._d.pop()

print(Counter.__mro__)                # (Counter, dict, object) —— is-a dict
```

## ⚠️ 原文纠错
原文"有组合并且继承都能完成这个功能的时候，优先使用组合，让代码保持尽量简单"以及"继承可能会有代码膨胀的问题"，判断均正确，予以保留。原文以 `Counter`/`defaultdict` 作为继承 `dict` 的例子，属实。卡面补充的"组合持有引用需注意共享"属扩展，已注明。转写中的音译词已还原为标准术语。

## 总结与追问预判
- 组合 = **has-a + 委托**；继承 = **is-a + 接口继承**；默认选组合。
