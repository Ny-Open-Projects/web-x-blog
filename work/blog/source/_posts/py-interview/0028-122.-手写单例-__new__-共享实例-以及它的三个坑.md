> 分类：编程范式/设计模式 | 难度：L3 | 题型：工程题 | 频率：高 | 关键词：**单例** / **__new__** / **_instance** / **线程安全**
> 原文锚点：第 48~69 段「一个类只能创建同一个实例，用共享实例的方式实现」

## 一句话总述
**单例**保证一个类**只有一个实例**：在 `__new__` 里判断 `cls._instance` 是否为空，为空才 `super().__new__(cls)` 并存回类属性，之后每次都**返回同一个**；验证方式是 `a is b` 或 `id(a) == id(b)`。

## 面试官视角
- **考察意图**：高频手写题，重点在**边界**：继承、线程安全、`__init__` 重复执行。
- **P5** 能写出 `__new__` 版 / **P6** 能指出 `__init__` **每次仍会执行**（会重置属性）/ **P7** 能说出**多线程竞态**要加锁、以及**子类共享父类实例槽**的 bug，并给出 `cls.__dict__.get` 或元类方案 `[源码]`。
- **红旗**：① 只在 `__init__` 里做判断（那时实例**已创建**，拦不住）；② 用 `hasattr(cls, '_instance')` 沿 MRO 查到**父类**的实例，导致父子共用；③ 声称这样就是线程安全的。
- **惊艳点**：最省事的单例其实是**模块**——Python 模块 import 一次就缓存，模块里的全局变量天然单例（见 123）。验证：`a is b` 为 True，但 `a.x` 被后一次构造覆盖 `[实测]`。

## 主问答
**Q：手写一个单例模式。**
**A：**
1. **核心**：重写 `__new__`（**创建实例**的魔术方法），`if cls._instance is None:` 才调 `super().__new__(cls)` 并赋值，最后 `return cls._instance`。
2. **验证**：`c1, c2 = MyClass(), MyClass()`，用 `c1 is c2` 或 `id(c1) == id(c2)` 判断同一对象。
3. **坑一**：`__init__` **每次实例化都会跑**，会覆盖已有属性；需要加 `if not hasattr(self, '_inited')` 之类的守卫。
**加分层**：**坑二**多线程下两个线程可能同时通过判空 → 要加 `threading.Lock`（双重检查）；**坑三**`cls._instance` 会沿继承链找到父类实例，父子共用一份 → 用 `cls.__dict__.get('_instance')` 或给每个子类各存。

## 关键代码
```python
class Singleton:
    _instance = None
    def __new__(cls, *args, **kwargs):
        if cls.__dict__.get('_instance') is None:      # 不用 hasattr，避免沿 MRO 命中父类
            cls._instance = super().__new__(cls)
        return cls._instance

class MyClass(Singleton):
    pass

c1, c2 = MyClass(), MyClass()
print(c1 is c2, id(c1) == id(c2))       # True True
```

## ⚠️ 原文纠错
原文用 `__new__` + `_instance` 类属性实现单例、用 `id(c1) == id(c2)` 验证，实现与验证方式均正确，予以保留。原文未提及三个关键边界：`__init__` 每次仍会执行、**多线程竞态**、`cls._instance` 沿 MRO 命中父类导致父子共用实例槽——卡面补充的这三点属扩展，已用 `[源码]`/`[实测]` 标注，示例代码改用 `cls.__dict__.get` 规避第三点。转写中的音译词已还原为标准术语。

## 总结与追问预判
- `__new__` 判空 + 存类属性 + `return`；验证用 `is`/`id`；**init 重复、线程安全、继承串味**是三坑。
