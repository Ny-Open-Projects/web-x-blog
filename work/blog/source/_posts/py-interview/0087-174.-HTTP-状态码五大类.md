## 一句话总述
HTTP 状态码分五类：**1xx** 继续、**2xx** 成功（200）、**3xx** 重定向（301 永久/302 临时/304 未修改）、**4xx** 客户端错误（400/401/403/404/405）、**5xx** 服务器错误（500）。面试重点记 301 vs 302 与常见 4xx/5xx。

## 面试官视角
- **考察意图**：是否掌握状态码的"分类语义"而非死记数字，以及能区分易混对（301/302）。
- **P5** 能说出五类各自含义 / **P6** 能区分 301（永久）vs 302（临时）、404 vs 403 / **P7** 能讲清 304（协商缓存命中、不返正文）、405（方法未实现）。
- **红旗**：把 403（禁止）说成 404（不存在）；或认为 301/302 只是"数字不同"。
- **惊艳点**：301/302 虽都是跳转，但 **301 会被浏览器缓存、SEO 权重转移**，302 不转移——选错会改变缓存与搜索排名 —— 验证：刷新后 Network 面板看是否"from disk cache" `[经验]`。

## 主问答
**Q（面试官原话）：** 常见的 HTTP 状态码有哪些？301 和 302 有什么区别？

**A · 标准答案骨架：**
1. **先给结论**：五类——**1xx** 继续、**2xx** 成功（200）、**3xx** 重定向、**4xx** 客户端错、**5xx** 服务端错。
2. **再给机制**：**301 永久重定向**（资源已永久迁移，浏览器缓存、SEO 权重转移）、**302 临时重定向**（仅本次跳转，不缓存）；**304** 是协商缓存命中（资源未变，不返正文）；**403** 是"无权限"、**404** 是"不存在"——二者语义不同。
3. **最后给边界**：**405** 是服务端未实现该 HTTP 方法（如框架没写对应路由）；**500** 是服务端未捕获异常——这些是需要"按语义定位"的，不是背数字。

**加分层**：状态码首位即类别，面试先报类别再给例子，比直接甩数字更显体系化 `[经验]`。
