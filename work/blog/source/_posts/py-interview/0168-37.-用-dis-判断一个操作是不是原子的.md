> 分类：并发/线程安全 | 难度：L3 | 题型：八股题 | 频率：中 | 关键词：**dis 模块** / **字节码** / **单指令原子**
> 原文锚点：第 47~58 段「我们可以使用 dis 模块来分析字节码…一个字节码就能完成的就是原子操作」

## 一句话总述
`dis.dis()` 把函数反编译成字节码，**能一条条数出来你写的语句用了几条指令**——只有**单条指令**完成的才是原子的，多指令的都可能被切走。

## 面试官视角
- **考察意图**：是否掌握"用工具证明"而不是靠背结论。
- **P5** 知道有 `dis` 模块 / **P6** 能读出 `LOAD → BINARY_OP → STORE` 三步 / **P7** 知道 3.11 起指令会被**特化**、判断要看步骤数而非记指令名。
- **红旗**：① 说"Python 直接解释源码、没有字节码"（实际先编译为字节码再执行）；② 死记 3.8 的指令名来答 3.12 的题；③ 以为特化后 `+=` 变原子了。
- **惊艳点**：3.11+ 同一函数被反复调用后字节码会**自适应特化**（如出现 `BINARY_OP_ADD_INT`），**指令名会变，但多步本质不变**。验证：连续 `dis.dis` 两次对比 `[实测]`

## 主问答
**Q：怎么判断一个 Python 操作是不是线程安全的？**
**A：**
1. **先给结论**：用 `dis.dis(func)` 看它编译成几条字节码，**单条指令**完成的才是原子操作。
2. **再给机制**：`x = 1` 只编译成一次存值指令（如 `STORE_SUBSCR`）；`x += 1` 则是**取值 → 运算 → 存回**三步，任意一步之间都可能发生线程切换。
3. **最后给边界**：指令名与条数**随版本变化**（3.11 引入自适应特化解释器），判断原子性要看**是否存在读-改-写序列**，而不是背指令名。
**加分层**：`sys.setswitchinterval` 与原子性判断无关——它只改变切换频率，多步操作在任何频率下都不安全。

## 关键代码
```python
import dis
def assign(x): x[0] = 1      # 单步存值 → 原子
def incr(x):   x[0] += 1     # 读-改-写 → 非原子
dis.dis(assign)
dis.dis(incr)                # 观察取值 / 运算 / 存回三步
```
