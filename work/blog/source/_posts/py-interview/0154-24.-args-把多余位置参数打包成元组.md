> 分类：语言基础/函数 | 难度：L1 | 题型：八股题 | 频率：高 | 关键词：**可变位置参数** / **tuple** / **透传**
> 原文锚点：第 80~92 段「*args 会被打包成一个 tuple，也就是把所有可变参数打包成一个 tuple 对象」

## 一句话总述
`*args` 用来接收**数量不确定的位置参数**，函数体内 `args` 是一个 **tuple**；名字可以随便起，起作用的是前面那颗星。

## 面试官视角
- **考察意图**：是"会用"还是"知道它是什么类型、放在哪一位"。
- **P5** 会用 `*args` 定义函数 / **P6** 知道它是 tuple、不传时是空元组 / **P7** 知道它在形参表中的**合法位置**与只读语义。
- **红旗**：① 以为 `args` 是 list；② 以为名字必须叫 args；③ 说能在函数里给它 append。
- **惊艳点**：`*args` 只能出现在**普通位置参数之后、仅限关键字参数与 `**kwargs` 之前**，写反直接 SyntaxError。验证：CPython 直接解析 `[实测]`

## 主问答
**Q：`def f(*args)` 里的 args 是什么类型？不传参数时它是什么？**
**A：**
1. **先给结论**：是 **tuple**；不传多余位置参数时是**空元组 `()`，不是 None**。
2. **再给机制**：调用时解释器把落位之后剩余的位置实参收集成一个元组绑定到 `args`，可以迭代、索引、再解包，但**长度不可变**。
3. **最后给边界**：它**只收位置参数**——`f(a=1)` 里的 `a=1` 会进 `**kwargs` 而不是 args；没有 `**kwargs` 兜底时多余的**关键字**参数直接 TypeError。
**加分层**：最高频的实战场景是**装饰器与包装函数里的原样透传**（`def wrapper(*args, **kwargs)`）。

## 关键代码
```python
def f(*args):
    print(type(args), args)
    for i, v in enumerate(args):
        print(i, v)
f(1)            # <class 'tuple'> (1,)
f(1, 2, 3)      # <class 'tuple'> (1, 2, 3)

def g(a, *args, k=0):      # k 是仅限关键字参数
    return a, args, k
print(g(1, 2, 3, k=9))     # (1, (2, 3), 9)
```
