> 分类：版本差异 | 难度：L1 | 题型：八股题 | 频率：高 | 关键词：**/** / **//** / **真除法** / **向下取整**
> 原文锚点：第 43~46 段「Python 3 的除法会返回浮点数，而不是像 Python 2 里面直接截断并返回整数」

## 一句话总述
Python 3 的 `/` 是**真除法**（恒返回 float），`//` 是**向下取整**的整除；负数上两者与 Python 2 的截断行为会分叉。

## 面试官视角
- **考察意图**：考的是 2→3 迁移时最容易静默出错的那一行代码。
- **P5** 知道 3 里 `/` 得 float / **P6** 知道用 `//` 还原整除 / **P7** 能指出负数上的取整方向差异。
- **红旗**：① 说"// 就是去掉小数"；② 以为 `//` 结果一定是 int；③ 忘了 `//` 对浮点也生效。
- **惊艳点**：**`-7 // 2 == -4` 而 `int(-7 / 2) == -3`**——`//` 向下取整、截断是向零，负数上必分叉 `[经验]`。

## 主问答
**Q：Python 2 迁到 3 时，除法要注意什么？**
**A：**
1. **先给结论**：`/` 从"整数截断"变成**真除法**，所有整数相除都会得到 float；要旧行为必须显式写 `//`。
2. **再给机制**：`//` 是 floor division，结果**向下取整**；当操作数含 float 时结果也是 float（`7.0 // 2 == 3.0`）。
3. **最后给边界**：迁移期最危险的是**负数整除**——旧代码的截断语义与新代码的向下取整语义结果不同，且不会报错，属于静默错误。
**加分层**：Python 2 也可通过 `from __future__ import division` 提前启用真除法，便于同一份代码在两边行为一致。

| 结论成立版本 | 翻转点 | 现在怎么答 |
|---|---|---|
| Python 3.x 全系 | Python 2 的 `/` 对整数截断；3 起为真除法 | 一律按真除法答，并主动补充负数取整方向的坑 |

## 关键代码
```python
print(7 / 2, 7 // 2)      # 3.5  3
print(-7 // 2, int(-7/2)) # -4  -3 —— 向下取整 vs 向零截断
print(7.0 // 2)           # 3.0 —— 操作数含浮点则结果为浮点
```

## ⚠️ 原文纠错
原文只说「3 里返回 float、要旧行为用 `//`」，未提示**负数取整方向不同**这一静默差异（表述不完整，非错误）；机翻中的运算符音译已还原。

- `/` 真除法、`//` 向下取整；迁移重点在负数。
