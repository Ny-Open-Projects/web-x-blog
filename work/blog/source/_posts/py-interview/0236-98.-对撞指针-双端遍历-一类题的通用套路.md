> 分类：算法与数据结构/双指针 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**双端遍历** / **原地** / **O(1) 空间** / **相遇即停**
> 原文锚点：第 103~104 段「从首尾分别往中间移动来做一个操作，这个就是我们所说的双端遍历」

## 一句话总述
**对撞指针**（双端遍历）是固定套路：两个指针一头一尾，**在相遇前**每轮做一次对称操作（交换/比较/累加），然后同时向中间收拢；适用于**有序数组两数之和、反转、回文判定**等"对称"问题。

## 面试官视角
- **考察意图**：考**模式识别**——看到"对称/有序/原地"就该想到它，而不是每题从头推。
- **P5** 只会暴力双重循环 / **P6** 认出这是双指针并写对终止条件 / **P7** 能对比**快慢指针**与**滑动窗口**说明何时用哪个 `[经验]`。
- **红旗**：① 循环条件写成 `<=`（多一次无效操作）；② 指针只移动一个导致死循环；③ 在**无序**数组上用对撞指针解两数之和（必须先排序）。
- **惊艳点**：一句选型口诀——**有序 + 求和 → 对撞；原地 + 对称 → 对撞；子串/区间 → 滑动窗口；链表环/中点 → 快慢指针**。验证：把两数之和在排序后用对撞从 O(n²) 降到 O(n) `[实测]`。

## 主问答
**Q：什么是对撞指针？哪些题可以用？**
**A：**
1. **定义**：`left = 0`、`right = n - 1`，循环条件 `left < right`，每轮处理一对对称位置后 `left += 1`、`right -= 1`，**相遇即结束**。
2. **适用**：① **原地反转**（94）；② **回文判定**（96）；③ **有序数组两数之和**（和大了右移、和小了左移）；④ 盛水容器类"两端取较矮者"问题。
3. **复杂度**：每个位置最多访问一次，时间 `O(n)`，额外空间 `O(1)`。
**加分层**：与同类套路区分——**快慢指针**解决链表环与中点，**滑动窗口**解决连续子串/区间；三者都是"双指针"，但**移动方向不同**（对撞是相向、滑动是同向）。

## 关键代码
```python
def is_palindrome(s):                  # 回文判定：对称比较
    left, right = 0, len(s) - 1
    while left < right:
        if s[left] != s[right]:
            return False
        left += 1; right -= 1
    return True

def two_sum_sorted(nums, target):      # 有序两数之和：按和的大小移动一端
    left, right = 0, len(nums) - 1
    while left < right:
        s = nums[left] + nums[right]
        if s == target: return [left, right]
        if s < target: left += 1
        else:          right -= 1
    return None

print(is_palindrome("abba"), is_palindrome("abca"))          # True False
print(two_sum_sorted([1, 2, 4, 7, 11], 9))                   # [1, 3]
```
