> 分类：语言特性 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**is** / **==** / **id** / **None 单例**
> 原文锚点：第 74~82 段「使用 is 实际上就判断这两个地址是不是一样…我们经常用 is None 而不是 ==」

## 一句话总述
`==` 比**值是否相等**（走 `__eq__`），`is` 比**是否为同一个对象**（等价于比较 `id`）；判 `None` 必须用 `is`。

## 面试官视角
- **考察意图**：这道八股的真考点是"能不能说清为什么判空要用 is"，而不是背结论。
- **P5** 知道 `is` 比地址 / **P6** 能解释 `None` 是单例 / **P7** 能补上小整数缓存与 `==` 可被重载的坑。
- **红旗**：① "is 比 == 快所以用 is"；② 用 `is` 比较整数或字符串；③ 用 `== None`。
- **惊艳点**：`a is b` 语义等价于 `id(a) == id(b)`；而**字面量写 `x is 257` 在 CPython 里结果不可依赖** `[经验]`。

## 主问答
**Q：is 和 == 有什么区别？为什么判断 None 要用 is？**
**A：**
1. **先给结论**：`==` 比较**值**，可被 `__eq__` 重载；`is` 比较**身份**，不可重载，等价于比较 `id`。
2. **再给机制**：`None` 是**单例**，全进程只有一个对象，所以用 `is` 判断既准确又不受 `__eq__` 重载干扰 `[经验]`。
3. **最后给边界**：`is` 只能用于**单例对象**（`None` / `True` / `False`）或明确要做身份比较的场景；拿它比数值、字符串会踩到 CPython 的缓存实现，结论不可移植。
**加分层**：自定义类如果重载了 `__eq__` 却没重载 `__hash__`，对象会变成不可哈希——这是改 `==` 语义时最常见的连带伤害。

## 关键代码
```python
a = [1, 2, 3]; b = [1, 2, 3]
print(a == b)   # True  —— 值相等
print(a is b)   # False —— 两个不同的对象
print(id(a) == id(b))   # 与上一行结论一致
```
