> 分类：算法与数据结构/集合结构 | 难度：L1 | 题型：八股题 | 频率：中 | 关键词：**set** / **frozenset** / **去重** / **集合运算**
> 原文锚点：第 20~21 段「在 python 里面有常用两种，一种是 set 可变集合，还有一种是 frozenset 是一种不可变集合」

## 一句话总述
`set` 是**可变**集合（可 add/discard），`frozenset` 是**不可变**集合（创建后不能改）；后者因此**可哈希**，能作为 dict 的键或放进另一个集合。

## 面试官视角
- **考察意图**：把"不可变 ⇒ 可哈希"这条主线（见 52）迁移到集合类型上验证。
- **P5** 知道两种集合 / **P6** 说清 frozenset 可哈希、能做 key / **P7** 能讲集合运算、去重场景与 `discard`/`remove` 差异。
- **红旗**：① 不知道 frozenset；② 以为 set 也能当字典键；③ 混淆 `remove`（缺失抛错）与 `discard`（静默）。
- **惊艳点**：存在性判断用 set 是 **O(1)**，list 是 O(n)——去重 + 查重的经典优化就是换容器。验证：大列表下两次 `in` 耗时对比 `[实测]`。

## 主问答
**Q：Python 有哪几种集合类型？区别是什么？**
**A：**
1. **先给结论**：`set` 可变、`frozenset` 不可变；两者都**无序、元素唯一**，底层同样基于哈希表。
2. **再给差别**：不可变使 `frozenset` **可哈希**，因此能作为 dict 的 key 或 set 的成员；`set` 不可哈希，做不了。
3. **最后给操作**：增删 `add` / `remove`（缺则 KeyError）/ `discard`（缺则静默）；运算用 `|` `&` `-` `^` 及 `<` 子集判断。
**加分层**：元素必须**可哈希**（list/dict 进不去，tuple/frozenset 可以）；业务上"把一组标签当复合键"正是 frozenset 的典型用途。

## 关键代码
```python
s = {1, 2, 3}
s.add(4); s.discard(99)          # discard 缺失不报错
try: s.remove(99)
except KeyError: print("remove 会抛错")
fs = frozenset([1, 2])
print(hash(fs) is not None)      # True —— 可哈希
d = {fs: "复合键可用"}            # frozenset 能当 key
try: d[{1, 2}] = "x"
except TypeError: print("set 不可哈希，不能当 key")
print({1,2,3} - {2}, {1,2} | {5})  # {1, 3} {1, 2, 5}
```
