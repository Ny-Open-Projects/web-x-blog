## 一句话总述
被问"你用过哪些内置算法和数据结构"时，**不要零散枚举**，按**线性 / 链式 / 字典 / 集合**四类结构 + **排序 / 二分 / 堆 / 缓存**四类算法**成体系地答**。

## 面试官视角
- **考察意图**：看你是"想到哪儿说哪儿"还是**脑子里有知识图谱**。
- **P5** 能报出 list/tuple/dict/set / **P6** 能补上 collections 的 namedtuple/deque/Counter/OrderedDict/defaultdict / **P7** 能顺带说 bisect、heapq、functools.lru_cache 并说明场景。
- **红旗**：① 只答 list 和 dict；② 不知道 collections 模块（原文明确说"这就很不应该了"）；③ 把库名念错或张冠李戴。
- **惊艳点**：能把**结构类型 × 算法分类 × 内置还是标准库**三个维度同时列出来。验证：让对方随便点一类，你能 30 秒内展开。

## 主问答
**Q：Python 常用的内置算法和数据结构有哪些？**
**A：**
1. **先给分类框架**：按**线性结构**（list 可变、tuple 不可变）、**链式结构**（标准库 collections.deque 双端队列）、**字典结构**（dict 及其衍生 Counter / OrderedDict / defaultdict）、**集合结构**（set 可变、frozenset 不可变）四类展开。
2. **再补算法侧**：排序用内置 `sorted`；查找用 `bisect` 模块做二分；堆用 `heapq`；缓存用 `functools.lru_cache`（Python 3 新增）。
3. **最后点场景**：deque 用来实现栈与队列；Counter 计数；OrderedDict 保序；defaultdict 给缺失键兜默认值。
**加分层**：主动说"collections 是除内置类型之外我最常用的标准库"，并补一句 OrderedDict 底层是**循环双向链表**保序 `[源码]`，直接拉开差距。

## 版本与兼容性
| 结论成立版本 | 翻转点 | 现在怎么答 |
|---|---|---|
| Python 3.7+ | dict 自身已保证**插入顺序** | 普通保序直接用 dict，OrderedDict 只在需要 move_to_end 时用 |
| Python 3.2+ | `functools.lru_cache` 加入 | 缓存优先用装饰器，不必手写 |

## 关键代码
```python
import collections, bisect, heapq
from functools import lru_cache

names = collections.namedtuple("Point", "x y")   # 具名元组
dq = collections.deque([1, 2, 3]); dq.appendleft(0)  # 双端队列
cnt = collections.Counter("abcab")               # 计数 -> a:2 b:2 c:1
dd = collections.defaultdict(int); dd["k"] += 1  # 缺失键默认 0
print(bisect.bisect_left([1, 3, 5], 3))          # 二分位置 -> 1
print(heapq.nsmallest(2, [5, 1, 3]))             # 堆取最小 -> [1, 3]
```

## ⚠️ 原文纠错
原文把 `lru_cache` 描述为"Python 3 新增的一个缓存算法"需补正：`functools.lru_cache` 是 **3.2** 加入的装饰器；另外原文提到的排序/二分/堆模块名在转写中有音译失真，**已统一还原为 sorted / bisect / heapq**。其余未发现技术错误。
