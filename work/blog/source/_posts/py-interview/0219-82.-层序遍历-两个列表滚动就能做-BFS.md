> 分类：算法与数据结构/二叉树 | 难度：L2 | 题型：工程题 | 频率：高 | 关键词：**BFS** / **层序** / **current-next** / **列表的列表**
> 原文锚点：第 64~99 段「访问这一层的时候，我们把它的所有孩子这一层全都加进来」

## 一句话总述
层序遍历 = **广度优先**，用 `current` / `next` **两个列表滚动**：遍历当前层时把下一层的非空孩子收进 `next`，本层走完就**整体切换到下一层**，每层的值成一个子列表。

## 面试官视角
- **考察意图**：能不能把"一层一层"这个直觉落成**可维护的双缓冲**，而不是用单个队列却分不清层边界。
- **P5** 只说出 BFS / **P6** 写出双列表并给出 O(n) / **P7** 指出 `pop(0)` 是 O(n) 的坑、改用 `deque` 或双列表 `[实测]`。
- **红旗**：① 用单队列但分不清层，返回一整条扁平列表；② 把空孩子也塞进 `next` 导致死循环；③ 忘记每层结束清空 `next`。
- **惊艳点**：双列表法**天然带层边界**，返回"列表的列表"无需记录层号；若用 `deque`，则靠**每层开始时取 `len(queue)`** 划界。验证：两种写法跑同一棵树输出一致 `[实测]`。

## 主问答
**Q：给定根节点，返回二叉树层序遍历（每层一个子列表），怎么写？**
**A：**
1. **思路**：维护 `current`（本层节点）与 `next`（下层节点）；遍历 `current` 时把每个节点的非空 `left`/`right` `append` 进 `next`。
2. **收尾**：本层值 `[n.value for n in current]` 进结果；若 `next` 非空则把它的值也进结果，然后 `current, next = next, []`。
3. **终止**：当 `next` 为空（没有下一层）时结束，返回结果；时间复杂度 `O(n)`，空间 `O(w)`（w 为最大层宽）。
**加分层**：这题**必须先判空根**，否则 `[n.value for n in current]` 会对 `None` 取属性直接报错（见 83）。

## 关键代码
```python
from collections import deque

def level_order(root):                 # 双列表滚动：天然带层边界
    if not root:
        return []
    res, current = [], [root]
    while current:
        res.append([n.value for n in current])
        nxt = []
        for node in current:
            if node.left:  nxt.append(node.left)
            if node.right: nxt.append(node.right)
        current = nxt
    return res

def level_order_deque(root):           # 单队列：每层开始取 len 划界
    if not root:
        return []
    res, q = [], deque([root])
    while q:
        size = len(q)
        res.append([q[i].value for i in range(size)])
        for _ in range(size):
            node = q.popleft()
            if node.left:  q.append(node.left)
            if node.right: q.append(node.right)
    return res
```

## ⚠️ 原文纠错
原文双列表思路与"只收集非空孩子"的做法正确，予以保留。原文口述的「程序遍历」标准术语为**层序遍历（level order / BFS）**，「广度优先」表述正确，卡面统一还原为标准术语。原文一次提交失败的根因是**未处理空树**，该点已单独成卡（见 83）。
