> 分类：操作系统 | 难度：L2 | 题型：概念主问 | 频率：高 | 关键词：**进程** / **线程** / **资源隔离**
> 原文锚点：第 6~14 段「进程是对运行时程序的封装，是系统分配资源与调度的基本单位」

## 一句话总述
进程是**资源分配与调度的基本单位**（拥有独立地址空间），线程是**进程内的子任务、CPU 调度的基本单位**（共享进程内存）；一个进程可含多个线程。

## 面试官视角
- **考察意图**：是否分得清"谁拥有资源、谁被调度、谁共享内存"，这是后续线程安全与 IPC 所有问题的地基。
- **P5** 能说出进程独立、线程共享内存 / **P6** 能讲清进程是资源单位、线程是调度单位，并举一反例 / **P7** 能说出何时用多进程（隔离/CPU 密集）何时用多线程（IO 密集/共享状态）。
- **红旗**：把线程说成"轻量进程"就结束；或认为线程也有独立地址空间。
- **惊艳点**：Linux 下线程即"共享地址空间的轻量级进程（LWP）"，`getpid` 相同、`gettid` 不同 —— 验证：`ps -eLf` 看 LWP 列，内核视角二者同源。

## 主问答
**Q（面试官原话）：** 进程和线程到底有什么区别？你平时怎么理解？

**A · 标准答案骨架：**
1. **先给结论**：进程是**资源分配与调度的基本单位**，线程是**CPU 调度的基本单位**、寄生于进程。
2. **再给机制**：进程拥有**独立的虚拟地址空间**与文件句柄等资源；同一进程的线程**共享堆与全局变量**，只独享栈与寄存器。
3. **最后给边界**：切换成本上，**线程切换**只换上下文、**进程切换**要换地址空间（TLB 失效）；但进程间天然隔离，线程间要自己处理数据竞争。

**加分层**：多进程隔离性强但通信贵（需 IPC）；多线程共享内存通信快但引出线程安全问题——这是后面所有题的伏笔 `[经验]`。

## 关键代码
```python
import os, threading

def whoami():
    # getpid 相同证明同一进程；线程是进程内子任务 [经验]
    print("pid", os.getpid(), "tid", threading.get_ident())

t = threading.Thread(target=whoami)
t.start(); t.join()
```

## 总结与追问预判
- 进程=资源单位+独立地址空间；线程=调度单位+共享内存；切换成本线程更低。
- 顺势会问：**线程安全（见 154 卡）** 与 **进程间通信（见 158 卡）**。
