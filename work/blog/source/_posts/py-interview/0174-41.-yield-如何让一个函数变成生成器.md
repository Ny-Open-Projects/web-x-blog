> 分类：语言基础/生成器 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**yield** / **挂起** / **generator 对象**
> 原文锚点：第 3~10 段「当一个函数里面有 yield 关键字的时候，它就变成了一个生成器函数…可以挂起执行并保持当前状态」

## 一句话总述
函数体里出现 `yield` 就是**生成器函数**——**调用它并不执行函数体**，而是返回一个 generator 对象；每次 `next()` 推进到下一个 yield 处**产出值并原地挂起**。

## 面试官视角
- **考察意图**：是否理解"惰性 + 状态保留"，而不是只会背 yield 两个字。
- **P5** 知道 yield 产出值 / **P6** 知道调用不执行、状态保留 / **P7** 能说出惰性求值的内存优势与"一次性耗尽"的边界。
- **红旗**：① 说"调用生成器函数会执行函数体"；② 以为生成器能重复遍历；③ 把 yield 和 return 当成一回事。
- **惊艳点**：生成器是**一次性**的，耗尽后再 `next()` 抛 `StopIteration`，再遍历一次必须**重新调用**。验证：连续两次 for 循环对比 `[实测]`

## 主问答
**Q：什么是生成器？yield 起了什么作用？**
**A：**
1. **先给结论**：含 `yield` 的函数是生成器函数；调用它返回 **generator 对象**，函数体**一行都不执行**。
2. **再给机制**：`next()` 驱动它执行到**下一个 yield**，把值交给调用方后**原地挂起**（局部变量、指令指针全部保留），下次再从断点继续。
3. **最后给边界**：生成器**只能消费一次**；函数里的 `return value` 不会出现在迭代结果中，而是被塞进 `StopIteration.value`（3.3+）。
**加分层**：真正的价值是**惰性求值**——不必一次性把整个序列装进内存，处理大文件或无限序列时差距是数量级的（见 8 卡生成器推导式）。

## 关键代码
```python
def simple_gen():
    yield "hello"
    yield "world"
g = simple_gen()
print(type(g))                 # <class 'generator'>
print(next(g), next(g))        # hello world
try:
    next(g)
except StopIteration:
    print("已耗尽")             # 一次性，重试需重新调用
print(list(simple_gen()))      # ['hello', 'world']
```

## ⚠️ 原文纠错
原文称"生成器就是可以生成值的函数"，需补正：**调用生成器函数返回的是生成器对象，函数体在 `next()` 时才真正执行**。原文中的音译术语已统一还原为 yield / generator。
