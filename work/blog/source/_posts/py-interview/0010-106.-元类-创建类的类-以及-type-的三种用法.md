> 分类：编程范式/元类 | 难度：L3 | 题型：八股题 | 频率：中 | 关键词：**元类** / **type** / **类的创建** / **bases**
> 原文锚点：第 61~83 段「元类创建类，类再创建实例」

## 一句话总述
**元类（metaclass）是创建类的类**：实例由类创建，类由元类创建；内置元类是 `type`，`class X: a = 1` 等价于 `type('X', (), {'a': 1})`——**类名、基类元组、属性字典**三参数。

## 面试官视角
- **考察意图**：不指望你写框架，但要看你能否把"类也是对象"这条链路说完整。
- **P5** 知道有元类这个概念 / **P6** 能写出 `type(name, bases, dict)` 的等价定义 / **P7** 能说出 `type(obj)` 与 `obj.__class__` 的等价关系，以及 `type(type) is type` 的自举闭环 `[源码]`。
- **红旗**：① 说"元类是类的父类"（元类是**类的类型**，不是父类）；② 把 `type(x)` 只当成"看类型"的工具，不知道它还能**造类**；③ 声称业务代码里也该大量用元类。
- **惊艳点**：一条链——`type(1) is int`、`type(int) is type`、`type(type) is type`；`type` 是自己的实例，形成**自举**。验证：三条 `is` 表达式全部为 `True` `[实测]`。

## 主问答
**Q：什么是元类？type 除了查类型还能干什么？**
**A：**
1. **定义**：元类是**创建类的类**；普通对象由类创建，类由元类创建（`type`），构成"元类 → 类 → 实例"三层。
2. **type 造类**：`type(name, bases, dict)` 三参数分别是**类名、基类元组、属性字典**；`class X: a = 1` 与 `X = type('X', (), {'a': 1})` 完全等价。
3. **带方法/继承**：`class Child(Base): bar = True` 等价为 `type('Child', (Base,), {'bar': True, 'hello': hello}`，其中 `hello` 是外部定义的普通函数。
**加分层**：类体执行后属性就存放在一个 dict 里（可通过 `__dict__` 查看），这正是 `type` 第三参数能直接接管类定义的原因。

## 版本与兼容性
| 结论成立版本 | 翻转点 | 现在怎么答 |
|---|---|---|
| Python 3.x | 默认元类是 type | `class A:` 即由 type 创建 |
| Python 2.x | 需显式继承 object | 否则是旧式类 |
| 指定元类 | py3 用 metaclass= | py2 用 __metaclass__ 属性 |

## 关键代码
```python
class X:
    a = 1
X2 = type('X', (), {'a': 1})      # 与上完全等价
print(X.a, X2.a, type(X2))        # 1 1 <class 'type'>

print(type(1) is int)             # True
print(type(int) is type)          # True
print(type(type) is type)         # True —— 自举
```
