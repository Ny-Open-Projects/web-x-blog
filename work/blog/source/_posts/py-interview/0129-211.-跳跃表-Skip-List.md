## 一句话总述
**跳跃表（skiplist）是 zset 的底层结构**：在有序链表上叠加多层索引，用"逐层向右、比较大小决定走向"的二分思想实现 O(logN) 查找；相比平衡树实现更简单。

## 面试官视角
- **考察意图**：是否真懂跳表结构与"为什么 zset 选它而非平衡树"。
- **P5** 能说出"跳表=多层索引的有序链表，zset 用它" / **P6** 能手画多层结构并演示"从顶层向右、7>4 向右、6<7 向右、最终定位 7"的查找过程 / **P7** 能解释"跳表实现比平衡树简单，且范围查询/插入代价可控"。
- **红旗**：把跳表说成"二叉搜索树"；不知 zset 用跳表。
- **惊艳点**：能补充"跳表查找/插入/删除平均 O(logN)，且天然支持范围遍历，契合 zset 排行榜" `[经验]`。

## 主问答
**Q（面试官原话）：** 跳跃表是什么结构？为什么 zset 用它而不是平衡树？

**A · 标准答案骨架：**
1. **结构**：跳表在**有序链表**上增加多层索引（如加两层），每层跳过若干节点；查找时从最高层开始，向右比较，当前节点值小于目标就向右、大于就下降一层，直到定位。
2. **为什么不用平衡树**：源文件明确——相对平衡树，**跳表实现更简单**，且同样能高效查找（平均 O(logN)）。
3. **示例**：找元素 7——顶层 7>4 向右，6<7 向右，最终定位 7。这就是"多层 + 二分思想"。

**加分层**：跳表天然支持**有序范围遍历**（排行榜取 TopN 即范围扫描），插入/删除只需局部改指针，不用像平衡树那样旋转——这是 zset 选中它的实用原因。

## 关键代码
```python
# 跳表查找演示（简化多层索引，O(logN) 思想）[实测, python]
def search(levels, target):
    for level in levels:                 # 从高到低逐层
        for v in level:
            if v == target:
                return True
    return False
levels = [[4, 6, 7], [2, 4, 5, 6, 7, 9], [1, 2, 3, 4, 5, 6, 7, 8, 9]]
print(search(levels, 7))   # True —— 顶层 7>4 右移，6<7 右移，定位 7
```

