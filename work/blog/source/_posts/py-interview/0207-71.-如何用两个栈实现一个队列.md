> 分类：算法与数据结构/栈与队列 | 难度：L3 | 题型：工程题 | 频率：高 | 关键词：**输入栈** / **输出栈** / **摊销 O(1)**
> 原文锚点：第 101~104 段「如何去使用两个栈来去实现一个队列…这也是经常被问到的问题」

## 一句话总述
两个栈分别扮演**输入栈**与**输出栈**：入队只压输入栈，出队只从输出栈弹；**输出栈空时才把输入栈整体倒入**，因此每个元素最多被倒一次，**摊销 O(1)**。

## 面试官视角
- **考察意图**：经典变形题，考察"用受限结构组合出新语义"与**摊销**意识。
- **P5** 能讲出"倒栈"思路 / **P6** 能写对并说明为什么不能每次都倒 / **P7** 能给出摊销证明与边界（两个栈都空时返回什么）。
- **红旗**：① 每次出队都把输入栈倒来倒去（退化成 O(n)）；② 输出栈非空时还去倒栈（会打乱顺序）；③ 忘了两个栈都空时判空。
- **惊艳点**：关键不变量是"**输出栈栈顶永远是最早入队的元素**"，只要不破坏它就能保证 FIFO。验证：随机操作序列与 deque 对拍 `[实测]`。

## 主问答
**Q：两个栈怎么实现队列？复杂度是多少？**
**A：**
1. **先给结构**：`in_stack` 收所有入队元素，`out_stack` 供出队；出队时若 `out_stack` 为空，就把 `in_stack` **全部弹出并依次压入** out_stack。
2. **再给为什么对**：倒栈把"后进先出"翻转一次变成"先进先出"；且**必须在 out_stack 为空时才倒**，否则会把新元素插到老元素前面，破坏顺序。
3. **最后给复杂度**：单次出队最坏 O(n)（刚好要倒一整栈），但**每个元素一生只被倒一次**，n 次操作总代价 O(n)，**摊销 O(1)**。
**加分层**：状态判断要严谨——只有 `in_stack` 和 `out_stack` **同时为空**才代表队列为空，只看一个会误判。

## 关键代码
```python
class QueueByTwoStacks:
    def __init__(self): self.in_s, self.out_s = [], []
    def push(self, v): self.in_s.append(v)
    def _pour(self):
        if not self.out_s:                 # 仅当输出栈空才倒
            while self.in_s:
                self.out_s.append(self.in_s.pop())
    def pop(self):
        if not self.in_s and not self.out_s: raise IndexError("empty")
        self._pour()
        return self.out_s.pop()
    def empty(self): return not self.in_s and not self.out_s

q = QueueByTwoStacks()
for i in (1, 2, 3): q.push(i)
q.push(4)
print(q.pop(), q.pop(), q.empty())   # 1 2 False
```
