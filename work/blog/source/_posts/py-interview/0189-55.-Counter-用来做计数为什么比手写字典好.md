> 分类：算法与数据结构/collections | 难度：L1 | 题型：八股题 | 频率：中 | 关键词：**Counter** / **most_common** / **dict 子类**
> 原文锚点：第 51~58 段「counter 实际上就是 dict，我们看到它是字典的一个子结构，是字典的一个子类」

## 一句话总述
`collections.Counter` 是 **dict 的子类**，值固定为计数（int），`Counter("abcab")` 一行完成词频统计，`most_common(n)` 直接取 TopN。

## 面试官视角
- **考察意图**：看你是手写 `if k in d` 还是知道标准库已经封装好了。
- **P5** 会用 `Counter(...)` / **P6** 知道它是 dict 子类、`most_common` 用法 / **P7** 能说清 `elements()`、加减集合运算与"负数计数"细节。
- **红旗**：① 说它是独立的新类型；② 以为 `Counter["不存在"]` 会抛 KeyError；③ 不知道 `most_common` 的排序成本。
- **惊艳点**：缺失键返回 **0** 而不是抛异常（重写了 `__missing__`）；两个 Counter 可直接 `+` / `-` 做并集与差集。验证：`c["zzz"]` 得 0 `[实测]`。

## 主问答
**Q：怎么统计一个字符串里各字符出现的次数？**
**A：**
1. **先给结论**：`collections.Counter("abcab")` 一行得到 `{'a':2, 'b':2, 'c':1}`，它是 **dict 的子类**，可当普通字典用。
2. **再给机制**：构造时接收任意可迭代对象并逐个累加；内部重写 `__missing__`，所以**访问不存在的键返回 0** 而非 KeyError。
3. **最后给边界**：`most_common(n)` 走排序，**取 TopN 时 n 小才划算**（全量排序是 O(m log m)，可用 `heapq.nlargest` 替代）；`elements()` 只在计数为正时产出。
**加分层**：`Counter` 支持 `+`（相加）、`-`（相减，只保留正结果）、`&`（取小）、`|`（取大），做多组统计合并非常省事。

## 关键代码
```python
from collections import Counter
c = Counter("abcab")
print(c)                       # Counter({'a': 2, 'b': 2, 'c': 1})
print(c["zzz"])                # 0 —— 缺失键返回 0，不报错
print(c.most_common(2))        # [('a', 2), ('b', 2)]
print(sorted(c.elements()))    # ['a', 'a', 'b', 'b', 'c']
print((c - Counter("ab")))     # Counter({'a': 1, 'b': 1, 'c': 1})
print(c.total())               # 5（3.10+）
```

## ⚠️ 原文纠错
原文说 Counter 的"value 值是 int 值"，需补正：计数可为任意可作加法的数值，且**允许为 0 或负数**（减法产生），此时 `elements()` 会跳过。其余未发现技术错误；转写中的音译词已统一还原为 Counter / dict。

- Counter = 计数专用 dict 子类；缺键返 0、可 TopN、可集合运算。
