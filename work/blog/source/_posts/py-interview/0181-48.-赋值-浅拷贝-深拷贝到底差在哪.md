> 分类：语言基础/数据模型 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**共享引用** / **copy.copy** / **deepcopy**
> 原文锚点：第 7~13 段「直接把一个可变对象赋值给另一个变量…两个变量指向同一个对象」

## 一句话总述
三个层次——**赋值**只是给同一对象多贴一个标签（**不产生拷贝**）；**浅拷贝**新建容器但**子对象仍共享**；**深拷贝**递归复制、完全独立。

## 面试官视角
- **考察意图**：能否一句话讲清三者，并知道什么时候不需要深拷贝。
- **P5** 知道 `copy.deepcopy` / **P6** 能说清浅拷贝挡不住嵌套 / **P7** 能说出"元素不可变时深浅拷贝表现一致"与深拷贝的代价。
- **红旗**：① 把 `b = a` 说成"浅拷贝"；② 以为 `dict(x)` 能隔离嵌套；③ 无脑 `deepcopy`（慢，且拷不动句柄/锁）。
- **惊艳点**：对**只含不可变元素**的容器，浅拷贝与深拷贝**表现完全一致**（子对象根本改不动）；差别只在嵌套了可变对象时才暴露。验证：对比两种结构 `[实测]`

## 主问答
**Q：Python 里浅拷贝和深拷贝有什么区别？分别怎么实现？**
**A：**
1. **先给结论**：`b = a` 是**共享引用**（零拷贝）；`copy.copy(x)` 是**一层新容器**；`copy.deepcopy(x)` 是**完全独立**的递归副本。
2. **再给机制**：浅拷贝只复制容器本身，元素仍是原对象的引用；深拷贝递归复制所有层级，并用 memo 字典处理**循环引用**。
3. **最后给边界**：深拷贝**慢得多**，遇到文件句柄、锁、数据库连接会失败或产生错误语义；能用浅拷贝 + 不可变数据就别上深拷贝。
**加分层**：`a[:]`、`list(a)`、`dict(a)`、`a.copy()` 统统是**浅**拷贝——写法不同，语义完全一样。

## 关键代码
```python
import copy
a = [[1], [2]]
b = a                  # 赋值：同一对象，零拷贝
c = copy.copy(a)       # 浅拷贝：新容器，子 list 仍共享
d = copy.deepcopy(a)   # 深拷贝：完全独立
c[0].append(9); print(a)    # [[1, 9], [2]] ← 浅拷贝挡不住嵌套
d[1].append(9); print(a)    # [[1, 9], [2]] 原对象不受深拷贝影响
print(a[:] is a, [x is y for x, y in zip(a, a[:])])   # False [True, True]
```

## ⚠️ 原文纠错
原文把"直接赋值"称为**浅拷贝**，术语不严谨：`b = a` **不产生任何拷贝**，只是给同一对象再贴一个标签；真正的浅拷贝是 `copy.copy()` / `list(a)` / `a[:]`。此处按公认定义更正。

## 总结与追问预判
- 零拷贝 / 一层 / 递归三层；只有嵌套可变对象才需要深拷贝。
