> 分类：算法与数据结构/collections | 难度：L1 | 题型：八股题 | 频率：中 | 关键词：**defaultdict** / **__missing__** / **default_factory**
> 原文锚点：第 69~74 段「defaultdict 也是 dict 一个子类，对于缺失值来说，我们可以给它一个默认值」

## 一句话总述
`defaultdict(default_factory)` 是 dict 子类，访问**不存在的键**时自动调用工厂函数生成默认值并**写回字典**，从而免去 `setdefault` 判空。

## 面试官视角
- **考察意图**：看你是否还在写 `if k not in d: d[k] = []` 这种样板代码。
- **P5** 会用 `defaultdict(int)` / **P6** 说清是 `__missing__` 钩子且会写回 / **P7** 能指出它与 `dict.setdefault` 的差别和陷阱。
- **红旗**：① 以为默认值是"共享的同一个对象"；② 传 `defaultdict(0)`（要传**可调用对象**）；③ 用 `d[k]` 做只读查询，无意中污染了字典。
- **惊艳点**：工厂函数是**每次调用生成新对象**，所以 `defaultdict(list)` 下每个键得到独立列表。验证：两键 id 不同 `[实测]`。

## 主问答
**Q：defaultdict 有什么用？和普通 dict 比差别在哪？**
**A：**
1. **先给结论**：构造时传一个**可调用对象**（如 `int` / `list` / `set`），访问缺失键时它被调用生成默认值，**并写入字典**。
2. **再给机制**：靠 dict 子类的 `__missing__` 钩子实现——`__getitem__` 找不到键时触发，而非 `get()` 路径（**`get()` 不触发**）。
3. **最后给坑**：工厂必须可调用（`defaultdict(0)` 会 TypeError）；用 `d[k]` 做**只读**查询会凭空插入键，判断存在请用 `in` 或 `get`。
**加分层**：分组场景（一对多）用 `defaultdict(list)` 一行搞定；计数可用 `defaultdict(int)`，但多数情况下 `Counter` 更贴切。

## 关键代码
```python
from collections import defaultdict
dd = defaultdict(int)
print(dd["missing"])        # 0 —— 不抛 KeyError
dd["a"] += 1                # 直接累加，无需判空
print(dd, "a" in dd)        # defaultdict(<class 'int'>, {'a': 1}) True

g = defaultdict(list)
g["x"].append(1); g["y"].append(2)
print(g["x"] is g["y"])     # False —— 每个键独立新列表
print(g.get("nope"))        # None —— get 不触发工厂
print("nope" in g)          # False —— 未被写入
```

## ⚠️ 原文纠错
原文演示"访问不存在的 key 依然返回 0 而不是抛出 KeyError"正确，但**未说明该默认值会被写入字典**这一副作用，卡面已补正。转写中的音译词已统一还原为 defaultdict / dict / KeyError。未发现其他技术错误。

## 总结与追问预判
- 缺失键走工厂生成 + 写回；`get()` 不触发；别用 `d[k]` 做纯查询。
