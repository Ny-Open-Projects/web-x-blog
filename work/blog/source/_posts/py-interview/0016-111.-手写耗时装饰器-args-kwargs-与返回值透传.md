> 分类：编程范式/装饰器 | 难度：L2 | 题型：工程题 | 频率：高 | 关键词：**耗时统计** / ***args** / **返回值透传** / **内层函数**
> 原文锚点：第 9~31 段「编写一个记录函数耗时的装饰器」

## 一句话总述
耗时装饰器模板：外层 `def log_time(func)` 收函数，内层 `def _log(*args, **kwargs)` **收任意参数**，先记 `begin`、调原函数、**保存结果**、打印耗时，**最后把结果 return 出去**。

## 面试官视角
- **考察意图**：这是最经典的手写题，考细节——**参数透传**与**返回值**最容易漏。
- **P5** 能写出两层嵌套 / **P6** 用 `*args, **kwargs` 兼容任意签名且**不吞掉返回值** / **P7** 会补 `try/finally` 保证异常时也打印，并指出计时该用 `time.perf_counter()` 而非 `time.time()` `[经验]`。
- **红旗**：① 内层没写参数（`def _log():`）导致被装饰函数收不到实参；② **忘记 `return`** 原函数结果，调用方拿到 `None`；③ 用 `print` 打日志而不走 `logging`。
- **惊艳点**：两个地道改进——`time.time()` 受系统时钟调整影响，测耗时应用**单调时钟 `perf_counter()`**；用 `try/finally` 保证**抛异常时也记录**。验证：被装饰函数抛错时仍打印耗时 `[实测]`。

## 主问答
**Q：手写一个统计函数执行时间的装饰器。**
**A：**
1. **结构**：外层接收 `func`，内层用 `*args, **kwargs` 接收**任意位置参数与关键字参数**，再原样传给 `func`。
2. **计时**：调用前 `begin = time.time()`，调用后 `print(time.time() - begin)`；原函数**结果先存变量再返回**，避免吞掉返回值。
3. **返回**：外层 `return _log`（返回内层函数对象，**不要加括号**），内层 `return res`。
**加分层**：生产写法用 `functools.wraps` 保留元信息（见 112）、用 `logging` 而非 `print`、用 `perf_counter` 计时、用 `try/finally` 保证异常路径也记日志。

## 关键代码
```python
import time, logging

def log_time(func):
    def _log(*args, **kwargs):
        begin = time.perf_counter()          # 单调时钟，更可靠
        try:
            res = func(*args, **kwargs)      # 原样透传参数
            return res                       # 关键：别吞掉返回值
        finally:
            cost = time.perf_counter() - begin
            logging.warning('%s cost %.4fs', func.__name__, cost)
    return _log                              # 返回函数对象，不加括号

@log_time
def my_sleep():
    time.sleep(1)

my_sleep()                                   # my_sleep cost 1.00...s
```

## ⚠️ 原文纠错
原文实现使用 `time.time()` 记录起止时间并打印耗时、`print` 输出、原函数结果先保存后返回，结构正确，予以保留。原文未处理异常路径（函数抛错则耗时日志丢失），也未使用 `functools.wraps`，卡面补充的 `try/finally`、`perf_counter`、`logging` 属工程改进，已用 `[经验]`/`[实测]` 标注。转写中的音译词已还原为标准术语。
