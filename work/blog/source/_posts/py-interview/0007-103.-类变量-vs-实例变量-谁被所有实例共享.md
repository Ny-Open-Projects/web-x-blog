> 分类：编程范式/Python 类 | 难度：L2 | 题型：八股题 | 频率：高 | 关键词：**类变量** / **实例变量** / **共享** / **属性查找**
> 原文锚点：第 42~53 段「类变量由所有实例共享，实例变量由实例单独享有」

## 一句话总述
**类变量**定义在类体里、**由该类所有实例共享**（如 `country = 'China'`）；**实例变量**在 `__init__` 里用 `self.x` 绑定、**每个实例各一份**、互不影响。

## 面试官视角
- **考察意图**：考**属性查找顺序**与"共享"的真实含义，顺带引出可变类变量陷阱。
- **P5** 能区分两种变量 / **P6** 说清"读时先实例后类，写 `self.x` 只建实例属性" / **P7** 能推演**可变类变量被所有实例共享修改**的后果 `[实测]`。
- **红旗**：① 说"实例改类变量会改掉类变量"（实际是**给自己新建了同名实例属性**）；② 用 `list`/`dict` 当类变量做"默认容器"；③ 不知道要用 `类名.x` 才能真正改类变量。
- **惊艳点**：`self.x = v` 永远只写实例；要改类变量必须 `Person.country = v`。验证：某实例 `self.country='US'` 后，`Person.country` 仍是 `'China'` `[实测]`。

## 主问答
**Q：类变量和实例变量有什么区别？**
**A：**
1. **类变量**：类体中定义，由**该类所有实例共享**；需要在不同实例间共享数据时用它（如所有人的 `country` 都是 `China`）。
2. **实例变量**：`__init__` 中 `self.name = name` 绑定，**各实例独立**，一个实例改了不影响另一个。
3. **查找顺序**：读属性**先查实例 `__dict__`，没有再查类**（进而按 MRO 查父类）；`self.x = v` 只创建/覆盖**实例**属性，不动类变量。
**加分层**：常见陷阱——类变量若是 `list`/`dict` 这类**可变对象**，任一实例 `self.items.append(x)` 都会**改到共享的那一个**，应在 `__init__` 里初始化（见 104）。

## 关键代码
```python
class Person:
    country = "China"             # 类变量：所有实例共享
    def __init__(self, name):
        self.name = name          # 实例变量：各实例独立

a, b = Person("老王"), Person("老李")
print(a.country, b.country)       # China China
a.country = "US"                  # 只给 a 建了同名实例属性
print(a.country, b.country, Person.country)   # US China China
```

## ⚠️ 原文纠错
原文"类变量由所有实例共享、实例变量由实例单独享有、不同实例之间不会互相影响"，表述准确，予以保留。原文 `Person` 示例未涉及可变类变量的共享陷阱，卡面补充的该陷阱属扩展（详见 104），已注明。转写中的音译词已还原为标准术语。

## 总结与追问预判
- 类变量**共享**、实例变量**独立**；`self.x` 只动实例；改类变量用 `类名.x`。
