> 分类：编程范式/装饰器 | 难度：L1 | 题型：八股题 | 频率：高 | 关键词：**一等公民** / **语法糖** / **高阶函数** / **@**
> 原文锚点：第 5~31 段「装饰器就是接收一个函数作为参数，添加功能后返回一个新函数的函数」

## 一句话总述
Python 中**函数是一等公民**（可当参数传递），装饰器就是**接收一个函数、加功能后返回一个新函数**的高阶函数；`@deco` 只是 `f = deco(f)` 的**语法糖**，两种写法完全等价。

## 面试官视角
- **考察意图**：确认你理解的是"函数调用链"而不是魔法语法。
- **P5** 能说出装饰器是"函数套函数" / **P6** 能写出 `@` 的等价展开式 / **P7** 能说明装饰发生在**定义时（import 时）**而非调用时，并由此解释"装饰器副作用何时生效" `[源码]`。
- **红旗**：① 认为 `@` 是特殊语法、无法手写等价形式；② 说不清"一等公民"意味着什么；③ 以为每次调用函数时才执行装饰逻辑（外层只跑一次）。
- **惊艳点**：装饰器既可用**函数**实现也可用**类**实现（实现 `__call__` 即可），判断标准是"可调用"。验证：`LogTime(func)` 与 `log_time(func)` 装饰效果一致 `[实测]`。

## 主问答
**Q：什么是装饰器？@ 到底做了什么？**
**A：**
1. **本质**：装饰器是**高阶函数**——**接收函数作参数 → 包装新功能 → 返回新函数**；也可由**类**实现，只要实例可调用。
2. **一等公民**：Python 里函数也是对象，**可以当参数传递、可以作返回值**，这是装饰器成立的前提。
3. **语法糖**：`@log_time` 写在 `def` 上方，等价于在定义后执行 `my_sleep = log_time(my_sleep)`；之后调用的是**返回的新函数**。
**加分层**：装饰在**模块导入/函数定义时**执行一次，外层包装逻辑只跑一次，被包函数每次调用都跑；这决定了装饰器适合做"只做一次"的事（注册、绑定）。

## 关键代码
```python
def log_time(func):
    def _log(*args, **kwargs):      # 内層接收任意参数
        return func(*args, **kwargs)
    return _log                      # 返回新函数

@log_time
def my_sleep():
    pass

# 等价的手写形式：
def my_sleep2():
    pass
new_sleep = log_time(my_sleep2)      # 与 @ 完全等价
```

原文"装饰器是接收一个函数作为参数，添加功能后返回一个新函数的函数"、"既可以通过函数实现也可以通过类实现"，以及"`@` 只是语法糖、与 `new_sleep = log_time(my_sleep)` 等价"，表述均正确，予以保留。原文提到装饰器对应设计模式中的**装饰器模式**、属于**面向切面编程（AOP）**思路，判断成立。卡面补充的"装饰在定义时执行一次"属扩展，已用 `[源码]` 标注。转写中的音译词已还原为标准术语。
