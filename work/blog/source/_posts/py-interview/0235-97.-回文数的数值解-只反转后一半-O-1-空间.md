> 分类：算法与数据结构/数学 | 难度：L3 | 题型：工程题 | 频率：中 | 关键词：**反转一半** / **O(1) 空间** / **整数溢出** / **剪枝**
> 原文锚点：第 65~68 段「你能不能不用把整数转化成 string 来判断」

## 一句话总述
不转字符串的回文数解法：**只反转数字的后一半**，与前一半比较；用"**反转值 ≥ 剩余值**"作为到达中点的判据，时间 `O(log₁₀ n)`、**额外空间 `O(1)`**。

## 面试官视角
- **考察意图**：考**数值建模**与边界剪枝——这是"字符串解法"之后的进阶追问。
- **P5** 只会转字符串 / **P6** 能说出"反转后一半"的思路 / **P7** 写对中点判据并解释**为什么不用考虑溢出**（反转值最多比原数多一位，Python 整型任意精度）`[实测]`。
- **红旗**：① 完整反转整个数字（可能溢出，且逻辑冗余）；② 中点判据写错（奇数长度要 `rev // 10`）；③ 漏掉"末位为 0 的非零数"剪枝。
- **惊艳点**：先剪枝——**负数 False；`x % 10 == 0 and x != 0` 也 False**（首位不可能为 0）。这两条能把一半用例挡在函数入口。验证：`10`、`100` 直接返回 False `[实测]`。

## 主问答
**Q：不把整数转成字符串，怎么判断回文数？**
**A：**
1. **剪枝**：`x < 0` 返回 False；`x % 10 == 0 and x != 0` 也返回 False（末位为 0 的数首位必不为 0，无法对称；`0` 本身是回文）。
2. **反转后一半**：循环 `rev = rev * 10 + x % 10; x //= 10`，直到 **`rev >= x`** 说明已处理到中点。
3. **比较**：偶数位时判 `x == rev`；奇数位时 `rev` 多一位（中间那位），判 `x == rev // 10`。
**加分层**：复杂度是 `O(log₁₀ n)`（按位数算，而非按数值大小），额外空间 `O(1)`；Python 整型**不会溢出**，但用 C/Java 实现时完整反转需考虑溢出，这也是只反转一半的另一个理由。

## 关键代码
```python
def is_palindrome_num(x):
    if x < 0 or (x % 10 == 0 and x != 0):   # 剪枝：负数 / 末位为 0 的非零数
        return False
    rev = 0
    while rev < x:                          # 反转到一半即停
        rev = rev * 10 + x % 10
        x //= 10
    return x == rev or x == rev // 10       # 偶数位 / 奇数位

for v in (121, -121, 10, 0, 7, 1221, 12321, 1001):
    print(v, is_palindrome_num(v))
# 121 True / -121 False / 10 False / 0 True / 7 True / 1221 True / 12321 True / 1001 True
```
