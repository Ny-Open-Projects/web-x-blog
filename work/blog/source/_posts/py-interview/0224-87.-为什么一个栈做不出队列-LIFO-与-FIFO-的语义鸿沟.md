> 分类：算法与数据结构/栈与队列 | 难度：L2 | 题型：八股题 | 频率：中 | 关键词：**LIFO** / **FIFO** / **可见性** / **反证**
> 原文锚点：第 25~29 段「如果我们只使用一个栈的话，我们发现这题根本就是无解的」

## 一句话总述
栈只能看到**栈顶**一个元素，而队列要求**先取最早进入的元素（在栈底）**；单个 LIFO 结构**无法在不违反规则的前提下触达栈底**，所以"单栈实现队列"无解，必须引入第二个栈做**一次顺序翻转**。

## 面试官视角
- **考察意图**：考你对**结构语义**的理解深度，而不是背题；也考"卡住时会不会画图模拟"。
- **P5** 只会说"做不到" / **P6** 能从可见性角度说明为什么 / **P7** 会给出**画图模拟法**并推广到"受限结构组合"的一般思路 `[经验]`。
- **红旗**：① 说"一个栈也能，只要倒来倒去"（倒的过程需要额外空间，本质就是第二个栈）；② 混淆栈顶栈底；③ 说不清"翻转"发生在哪一步。
- **惊艳点**：把这类题归纳成通用套路——**先确认单结构是否无解 → 无解就增加到两个 → 画图模拟操作序列 → 归纳不变量**。验证：拿"用队列实现栈"（225）反向套用，同样成立 `[实测]`。

## 主问答
**Q：能不能只用一个栈实现队列？为什么？**
**A：**
1. **结论**：不能。栈只暴露**栈顶**，而队列的 `pop` 要返回**最早入队**的元素，它此刻位于**栈底**；在不违反"只能操作栈顶"的前提下无法取出。
2. **反证**：若强行把上面的元素弹出来找栈底元素，弹出的元素必须暂存——这个**暂存区本身就是第二个栈**，已经不是"单栈"。
3. **出路**：用**两个栈**，一个收、一个出，出栈空时把收栈整体倒入；倒入这个动作正是**把 LIFO 翻转一次成 FIFO**（实现见 71）。
**加分层**：这题的解法套路可复用——**遇受限结构题先判断单结构可行性与不变量，再考虑加一个辅助结构**，并用画图模拟验证。

## 关键代码
```python
# 反证演示：想取栈底元素，必须把上面的元素"暂存"，而暂存区就是第二个栈
class OneStackQueueAttempt:
    def __init__(self): self.s = []
    def push(self, v): self.s.append(v)
    def pop_illegal(self):
        buf = []                      # ← 这就是第二个栈，题目不允许
        while len(self.s) > 1:
            buf.append(self.s.pop())
        bottom = self.s.pop()
        while buf:
            self.s.append(buf.pop())
        return bottom

# 合法解：两个栈，输出栈空时才倒（见 71）
class TwoStackQueue:
    def __init__(self): self.in_s, self.out_s = [], []
    def push(self, v): self.in_s.append(v)
    def pop(self):
        if not self.out_s:
            while self.in_s: self.out_s.append(self.in_s.pop())
        return self.out_s.pop()

q = TwoStackQueue()
for v in (1, 2, 3): q.push(v)
print(q.pop(), q.pop(), q.pop())      # 1 2 3 —— FIFO 成立
```
