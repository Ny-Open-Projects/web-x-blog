> 分类：语言基础/函数 | 难度：L1 | 题型：八股题 | 频率：高 | 关键词：**可变关键字参数** / **dict** / **配置透传**
> 原文锚点：第 93~98 段「对于关键字参数，会把它打包成一个字典对象…kwargs 是一个字典类型」

## 一句话总述
`**kwargs` 接收**数量不确定的关键字参数**，函数体内是一个 **dict**（CPython 3.7+ 保证保持调用时的插入顺序），不传时是**空 dict**。

## 面试官视角
- **考察意图**：会不会用、知不知道它带来的**静态检查代价**。
- **P5** 会用 `**kwargs` / **P6** 知道是 dict 且键必须是字符串 / **P7** 能说出"公共 API 上滥用会丢掉签名与 IDE 补全"这一判断。
- **红旗**：① 以为键可以是任意对象；② 以为改它会影响调用方传入的字典；③ 说它能放在形参表中间。
- **惊艳点**：解包进来的键若与已声明形参**重名**，直接 `TypeError: got multiple values for argument`。验证：CPython 直接运行 `[实测]`

## 主问答
**Q：`**kwargs` 在函数里是什么？它和 `*args` 怎么配合？**
**A：**
1. **先给结论**：是 **dict**，键为参数名字符串、值为实参；不传时是空 dict。
2. **再给机制**：调用处 `f(a=1, b=2)` 中无法匹配到具名形参的关键字实参，被收集成 dict 传入；函数内拿到的 dict 是**新建的**，改它不影响调用方的原字典。
3. **最后给边界**：`**kwargs` 必须放在形参表**最后**；键必须能对应上形参标识符，与已有形参重名会报重复赋值错误。
**加分层**：配置透传（如 `requests.get(url, **opts)`）是它的主场，代价是**丢掉签名、IDE 补全与静态检查**——对外暴露的 API 别滥用。

## 关键代码
```python
def f(**kwargs):
    print(type(kwargs), kwargs)
f(a=1, b=2)                 # <class 'dict'> {'a': 1, 'b': 2}

def g(a, **kw):
    return a, kw
print(g(1, x=2))            # (1, {'x': 2})
# g(1, a=2)                 # TypeError: got multiple values for argument 'a'
opts = {"timeout": 3}
def h(**kw): kw["x"] = 1; return kw
print(h(**opts), opts)      # {'timeout': 3, 'x': 1} {'timeout': 3} 原 dict 不受影响
```

## 总结与追问预判
- `**kwargs` = 多余关键字实参的 dict 收集器，必须放最后，代价是签名弱化。
