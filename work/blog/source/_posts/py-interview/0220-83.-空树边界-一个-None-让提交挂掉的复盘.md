> 原文锚点：第 103~115 段「报错的原因是 NoneType object has no attribute value」

## 一句话总述
层序遍历漏判**空树**时，`[n.value for n in current]` 会对 `None` 取属性，抛 `AttributeError: 'NoneType' object has no attribute 'value'`；**先判空根返回 `[]`** 即可，代价一行。

- **惊艳点**：写完代码**先口头过四类输入**——正常、空、单节点、极端（退化成链/全相同值）——再动手提交 `[实测]`，一次通过率明显更高。验证：把四类用例写成断言本地跑一遍即可。

## 主问答
**Q：你提交层序遍历时报错 NoneType 没有 value，问题出在哪、怎么避免？**
**A：**
1. **定位**：`root` 为 `None` 时循环仍会执行，`current` 里是 `[None]`，取 `.value` 即触发 `AttributeError`。
2. **修法**：函数入口加 `if not root: return []`；同理递归题入口写 `if root is None: return`。
3. **预防**：编码前先把**空输入 / 单元素 / 重复值 / 极端规模**四类列出来，写完逐个自测，再提交。
**加分层**：把这类边界沉淀成**自己的用例模板**——下次遇到树/链表的题直接套；踩过的坑要"长记性"并写成清单，否则会反复犯。

## 关键代码
```python
def level_order(root):
    if not root:                       # ★ 边界一：空树
        return []
    res, current = [], [root]
    while current:
        res.append([n.value for n in current])
        nxt = []
        for node in current:
            if node.left:  nxt.append(node.left)
            if node.right: nxt.append(node.right)
        current = nxt
    return res

# 自测四类输入：正常 / 空 / 单节点 / 退化成链
class N:
    def __init__(self, v, l=None, r=None): self.value, self.left, self.right = v, l, r

assert level_order(None) == []                                   # 空
assert level_order(N(1)) == [[1]]                                # 单节点
assert level_order(N(3, N(9), N(20, N(15), N(7)))) == [[3], [9, 20], [15, 7]]
assert level_order(N(1, N(2, N(3)))) == [[1], [2], [3]]          # 斜树
```
