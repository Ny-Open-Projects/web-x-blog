> 分类：操作系统/内存 | 难度：L2 | 题型：概念主问 | 频率：中 | 关键词：**分页** / **页表** / **逻辑地址** / **物理地址**
> 原文锚点：第 4~17 段「分页为高效管理内存、减少碎片；逻辑地址分固定大小页，物理地址分帧，页表映射，逻辑物理可不连续」

## 一句话总述
**分页**把程序的**逻辑地址**按固定大小（通常 4KB，由 OS 定）切成**页（page）**，物理内存切成同样大小的**帧（frame）**，用**页表（page table）**做逻辑→物理映射；页可离散分配，从而减少外部碎片。

## 面试官视角
- **考察意图**：是否理解"逻辑地址与物理地址分离"这一现代内存管理的基石。
- **P5** 能说出页/帧/页表、逻辑物理映射 / **P6** 能讲清为什么离散分配能减碎片、页表的作用 / **P7** 能延伸到 TLB、多级页表（大地址空间下页表本身也占内存）。
- **红旗**：认为逻辑地址和物理地址是一一连续对应的；或把分页说成"为了数据保护"。
- **惊艳点**：分页解决的是**外部碎片**与地址空间隔离，效率代价是每次访存多一次页表查询——靠 **TLB（快表）** 缓存命中来摊薄 —— 验证：`getconf PAGESIZE` 看本机页大小，通常 4096 `[经验]`。

## 主问答
**Q（面试官原话）：** 什么是分页？页表是干嘛用的？

**A · 标准答案骨架：**
1. **先给结论**：分页将逻辑地址切成等大的**页**，物理内存切成等大的**帧**，由**页表**记录"页→帧"的映射，实现逻辑地址到物理地址的转换。
2. **再给机制**：程序只看到连续的逻辑地址；页表把每页映射到任意物理帧，**页之间可以离散存放**，从而避免外部碎片、提高内存利用率。
3. **最后给边界**：页大小固定（OS 定，常见 4KB）；页表本身是数据结构，大地址空间下需**多级页表**避免页表自身过大。

**加分层**：分页的出发点是**内存利用率**，与"段"的出发点（逻辑保护）不同——见 162 卡对比 `[经验]`。

## 关键代码
```python
# 概念示意：用 dict 模拟页表，逻辑页号 → 物理帧号（离散映射）[经验]
page_table = {0: 3, 1: 7, 2: 1}
def translate(page, offset, page_size=4096):
    frame = page_table[page]
    return frame * page_size + offset
print(translate(1, 100))   # 逻辑地址(页1, 偏移100) → 物理地址 7*4096+100
```
