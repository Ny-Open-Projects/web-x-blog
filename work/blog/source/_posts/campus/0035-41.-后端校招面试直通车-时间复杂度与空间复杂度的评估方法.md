## 纲要

- 时间复杂度与空间复杂度的定义：都是描述算法资源消耗的函数，统一用大 O 符号表示
- 时间复杂度的推导规则：统计算法的所有基本操作次数，只保留多项式的最高阶并去掉系数
- 从 O(1) 到 O(n) 再到 O(n²)：三个典型例子完整推导
- 常见复杂度量级对照表，以及常见排序算法的复杂度
- 空间复杂度的评估：只看算法运行过程中额外分配的内存
- 时间与空间的置换关系：同一个问题，优化时间往往要牺牲空间，反之亦然

## 复杂度的定义

在计算机科学中，时间复杂度本质上是一个函数，用来描述算法的运行时间随输入规模增长的趋势；空间复杂度同样是一个函数，描述算法运行过程中占用的内存空间。两者都用大 O（Big O）符号表示。

评估复杂度时有两条关键规则，贯穿后面所有的推导：

- **取最高阶**：一个算法的全部基本操作次数可以写成一个多项式，只保留幂次最高的那一项
- **去系数**：最高阶前面的常数系数一律舍去，因为大 O 关注的是增长趋势而不是精确值

这两条规则的依据是：当输入规模 n 足够大时，低阶项和系数对增长趋势的影响可以忽略。

## 时间复杂度的推导

### 常数阶 O(1)

第一个例子是取列表的第一个值。无论列表的长度是一百还是一百万，都只需要取第一个下标的元素即可，操作次数与列表长度完全无关：

```go
func First(list []int) int {
	return list[0]
}
```

这是典型的 **O(1)**，也称常数阶。

### 线性阶 O(n)

第二个例子是求无序列表的最大值。因为列表无序，无法确定最大值的位置，只能逐个比较：

```go
func Max(list []int) int {
	max := list[0]              // 1 次：初始化
	for _, n := range list[1:] { // n-1 次：遍历
		if n > max {            // n-1 次：判断
			max = n             // 平均 (n-1)/2 次：命中时赋值
		}
	}
	return max
}
```

把每一步都数出来：

| 操作 | 次数 |
| --- | --- |
| `max := list[0]` | 1 |
| `for` 遍历 | n - 1 |
| `if` 判断 | n - 1 |
| `max = n` 赋值 | 平均 (n - 1) / 2 |

总操作次数约为 `1 + (n-1) + (n-1) + (n-1)/2`，整理后是 n 的一次多项式。按"取最高阶、去系数"的规则，结果是 **O(n)**，线性阶。

### 平方阶 O(n²)

第三个例子是双层循环，外层遍历每个元素，内层再遍历一轮，在内层里比较并在条件成立时累加：

```go
func CountPairs(list []int) int {
	result := 0
	for _, a := range list {      // n 次：外层遍历
		for _, b := range list {  // n 次：内层遍历
			if b < a {            // 平均 n/2 次成立
				result += a + b
			}
		}
	}
	return result
}
```

设列表长度为 n：

- 外层循环执行 n 次
- 每次外层循环中，内层循环体包含：n 次遍历 + n 次判断 + 平均 n/2 次累加，合计 `n + n + n/2 = 5n/2`

总操作次数为 `n × 5n/2 = 5n²/2`。取最高阶得到 n²，去掉系数 5/2，结果就是 **O(n²)**，平方阶。

### 常见复杂度量级

| 复杂度 | 非正式术语 | 典型操作次数表达式 |
| --- | --- | --- |
| O(1) | 常数阶 | 1 或任意常数次操作 |
| O(log n) | 对数阶 | 5·log n + 20 |
| O(n) | 线性阶 | 2n + 3 |
| O(n log n) | 线性对数阶 | n·log n + 5n + 2 |
| O(n²) | 平方阶 | 3n² + 2n + 1 |
| O(2ⁿ) | 指数阶 | 2ⁿ |

有了量级表，就可以横向比較常见排序算法：

| 排序算法 | 时间复杂度 |
| --- | --- |
| 冒泡排序 | O(n²) |
| 选择排序 | O(n²) |
| 插入排序 | O(n²) |
| 快速排序 | O(n log n) |

## 空间复杂度的推导

空间复杂度评估的是算法**运行过程中额外分配**的内存。输入本身占用的空间通常不计入。

### O(1) 的例子

对列表求和，整个过程只分配了累加变量 `sum` 一个变量，无论输入多长，额外空间都恒定：

```go
func Sum(list []int) int {
	sum := 0 // 唯一的一次内存分配
	for _, n := range list {
		sum += n
	}
	return sum
}
```

### O(n) 的例子

生成平方列表时，初始化了一个空的结果切片，随后循环中每个输入元素都会追加一个值进去，结果切片的长度最终等于输入长度：

```go
func Squares(list []int) []int {
	result := make([]int, 0, len(list)) // 分配次数随输入线性增长
	for _, n := range list {
		result = append(result, n*n)
	}
	return result
}
```

结果切片最终占用 n 个单位的空间，因此空间复杂度是 **O(n)**。

相比时间复杂度，空间复杂度的评估要直观得多：只需要看算法执行过程中有没有随输入规模增长的数据结构即可。

## 时间与空间的置换关系

在同一个算法里，时间复杂度与空间复杂度是相互制衡的：想压低时间复杂度，往往要付出空间的代价；反过来，想节省内存，通常就要接受更长的时间。两者很难同时优化。

以"判断某个数字是否存在于列表"为例。

第一种做法是一次遍历：

```go
func ContainsByScan(list []int, target int) bool {
	for _, n := range list {
		if n == target {
			return true
		}
	}
	return false
}
```

最坏情况下要扫完整个列表，**时间复杂度 O(n)，空间复杂度 O(1)**。

第二种做法是预先把列表装进哈希表：

```go
func ContainsByMap(list []int, target int) bool {
	index := make(map[int]struct{}, len(list))
	for _, n := range list {
		index[n] = struct{}{}
	}
	_, ok := index[target]
	return ok
}
```

预处理付出了 O(n) 的空间，换来之后每次查询 **O(1)** 的时间复杂度（均摊），**空间复杂度 O(n)**。

两种情况对比如下：

| 方案 | 时间复杂度 | 空间复杂度 | 适用场景 |
| --- | --- | --- | --- |
| 一次遍历 | O(n) | O(1) | 只查询一次，或内存受限 |
| 哈希表预处理 | 预处理 O(n)，查询 O(1) | O(n) | 同一份数据被反复查询 |

这也解释了工程上为什么会出现各种"空间换时间"的设计：缓存、倒排索引、布隆过滤器，本质都是在用额外的存储把一个 O(n) 甚至更高的查询压到 O(1)。

```go
	list := []int{3, 1, 7, 5, 2}

	fmt.Println("First        O(1) 时间 / O(1) 空间:", First(list))
	fmt.Println("Max          O(n) 时间 / O(1) 空间:", Max(list))
	fmt.Println("CountPairs   O(n^2) 时间 / O(1) 空间:", CountPairs(list))

}
```

### 技术点总结

- 时间复杂度与空间复杂度都是描述资源消耗随规模变化的函数，统一用大 O 表示
- 推导时间复杂度时，先数出全部基本操作的次数组合成多项式，再取最高阶并去掉系数
- 遍历一次、最坏情况下扫完全量数据，通常是 O(n)；嵌套两层遍历通常是 O(n²)
- 空间复杂度只看运行期额外分配的内存，是否出现随输入线性增长的数据结构是关键判据
- 时间与空间存在置换关系，空间换时间需要通过查询频次来判断是否划算

## API 速览

| API | 签名 | 作用 | 复杂度 |
| --- | --- | --- | --- |
| 下标访问 | `list[i]` | 按下标随机访问切片元素 | 时间 O(1) |
| `len` | `len(list) int` | 返回切片长度 | 时间 O(1) |
| `append` | `append(s []T, v ...T) []T` | 向切片尾部追加元素，容量不足时扩容 | 均摊时间 O(1) |
| `make` | `make([]T, len, cap)` / `make(map[K]V, n)` | 预分配切片或 map，减少扩容次数 | 空间 O(n) |
| map 读写 | `m[k] = v` / `v, ok := m[k]` | 哈希表写入与查找 | 均摊时间 O(1) |
| `sort.Ints` | `sort.Ints(x []int)` | 就地升序排序（标准库快排变体） | 时间 O(n log n)，空间 O(log n) |
