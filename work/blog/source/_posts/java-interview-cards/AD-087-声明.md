## MCP · 声明（权限）

- **事实**：MCP server 的权限声明：server 声明所需权限（文件/网络/交易），客户端按声明授权（JA-145 roots 的权限面）
- **原理**：声明式权限让接入审批有据（JA-082 评估的输入），声明与实际行为一致性要审计（超声明=风险），与最小权限联动
- **常见误区**：
  1. 权限自动协商无需声明（错）
  2. 声明只是文档（实际约束要客户端执行）（错）
  3. 声明与行为天然一致（错）
- **工程用法**：权限声明治理
- **版本锚点**：实战共识
