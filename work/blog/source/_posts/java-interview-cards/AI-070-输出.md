## 应用 · 输出（结构化）

- **事实**：结构化输出：JSON schema 约束（response_format/grammar 约束解码），下游解析稳定
- **原理**：自然语言输出解析脆弱（格式漂移），schema 约束（供应商支持）+解析容错（重试/修复）双保险，与 function calling 的参数 schema 同机制
- **常见误区**：
  1. 结构化输出限制智能（错）
  2. 解析失败就报错（错）
  3. schema 可省略（错）
- **工程用法**：工程可靠性
- **版本锚点**：实战共识
