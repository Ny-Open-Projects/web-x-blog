## 理论 · BASE（BASE）

- **事实**：BASE 理论：基本可用（Basically）、软状态（Soft）、最终一致（Eventually）
- **原理**：AP 路线的工程化表述：接受中间状态最终收敛，互联网大规模系统的主流选择（与 ACID 对比）
- **常见误区**：
  1. BASE 与 CAP 无关（错）
  2. 最终一致=永远不一致（错）
  3. 软状态是故障状态（错）
- **工程用法**：最终一致性方案的理论基础
- **版本锚点**：理论共识
