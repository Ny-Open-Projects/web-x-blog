## 协议 · Agent 互操作（A2A）

- **事实**：A2A 协议（Agent-to-Agent，2025 业界提出）：跨厂商 Agent 互操作（Agent 卡片声明能力/任务协商）
- **原理**：MCP 管"Agent↔工具"，A2A 管"Agent↔Agent"（互补不竞争），Java 生态跟进观察，与 MCP 知识（JA-024）对照
- **常见误区**：
  1. A2A 与 MCP 是竞争关系（错）
  2. Agent 互操作已解决（错）
  3. A2A 不存在（错）
- **工程用法**：协议全景
- **版本锚点**：2025
