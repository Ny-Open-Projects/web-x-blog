## 中间件 · 职责（网关）

- **事实**：LLM 网关六大职责：协议转换、鉴权、限流配额、路由降级、计费归集、缓存（AI-028 的展开）
- **原理**：每职责有实现件（JA-277 标签/JA-096 base-url），网关是 AI 中间件的核心节点，与 DF-037 API 网关职责对照
- **常见误区**：
  1. 网关只做转发（错）
  2. 职责可以随意裁剪（错）
  3. 网关是必需品（小团队可直连）（错）
- **工程用法**：网关架构全景
- **版本锚点**：实战共识
