## 编排 · 意图（路由）

- **事实**：路由 Agent：意图识别（分类）分发到对应专家 Agent/工作流，路由是"多 Agent 的入口调度员"
- **原理**：多 Agent 系统的入口模式（JA-027 主从的变体），路由可用小模型（成本 JA-414），误路由的代价与路由准确率权衡
- **常见误区**：
  1. 路由用旗舰模型（错）
  2. 路由不存在（错）
  3. 误路由无代价（错）
- **工程用法**：路由 Agent 设计
- **版本锚点**：实战共识
