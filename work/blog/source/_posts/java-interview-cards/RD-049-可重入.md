## 分布式锁 · 可重入（Redisson）

- **事实**：Redisson 可重入锁用 hash 结构（field=线程标识 value=重入次数）
- **原理**：加锁 hash increment、解锁 decrement 到 0 删除，Lua 保证判断与操作原子，比 SETNX 版本功能完整（可重入/公平/读写锁）
- **常见误区**：
  1. Redisson 锁不可重入（错）
  2. 可重入计数存在 string 里（错）
  3. Redisson 锁是纯 Java 内存锁（错）
- **工程用法**：生产分布式锁首选 Redisson
- **版本锚点**：Redisson 文档
