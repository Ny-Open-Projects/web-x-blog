## 手写 · 百行（骨架）

- **事实**：简单 Agent 手写可在百行内完成：循环+模型调用+工具分发+终止判断四块，理解原理后手写是 P9-P10 面试题
- **原理**：手写证明理解本质（框架只是封装），面试考察"不用框架能否写 Agent"，与手写笔试（本域压轴交付）联动
- **常见误区**：
  1. Agent 必须框架才能写（错）
  2. 手写不现实（错）
  3. 手写与面试无关（错）
- **工程用法**：手写认知
- **版本锚点**：实战共识
