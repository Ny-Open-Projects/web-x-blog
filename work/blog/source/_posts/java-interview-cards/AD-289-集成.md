## 手写 · 集成（RAG）

- **事实**：Agent 与 RAG 的手写集成：检索实现为工具（retriever 工具注册）或上下文注入（前置检索），两模式的手写要点
- **原理**：JA-051 RAG 与 Agent 的组合手写面：工具模式（Agent 决定何时检索）与注入模式（每问必检索）取舍，与 RAG 组件知识联动
- **常见误区**：
  1. RAG 与 Agent 无法手写组合（错）
  2. 两模式无差异（错）
  3. 注入模式总是更优（错）
- **工程用法**：RAG 集成手写
- **版本锚点**：实战共识
