## Spring AI · 客户端属性（MCP）

- **事实**：MCP 客户端经 spring.ai.mcp.client 属性配置（enabled/连接清单等）
- **原理**：多 MCP server 连接声明式管理，enabled 开关控制整组连接，配置中心可管理
- **常见误区**：
  1. MCP 客户端只能代码配置（错）
  2. enabled 是可选装饰（错）
  3. 多 server 不能并存（错）
- **工程用法**：MCP 客户端装配
- **版本锚点**：Spring AI 1.0 GA
