## 泛型 · 类型擦除（语法语义）

- **事实**：Java 泛型是编译期检查、运行时擦除：List<String> 与 List<Integer> 运行时是同一个类。
- **原理**：向后兼容 JDK5 之前的字节码；泛型信息仅保留在 Signature 属性供反射读取。
- **常见误区**：
  1. List<String> 运行时携带 String 类型信息。（错）
  2. 擦除意味着泛型完全没有任何运行时痕迹。（错）
  3. 泛型检查发生在运行期。（错）
- **工程用法**：反射 getGenericType() 可读取声明处的泛型参数。
- **版本锚点**：JLS 4.6（擦除）
