## Prompt · 防御（注入）

- **事实**：Prompt 注入攻击：外部内容（网页/文档）携带指令覆盖系统提示，防御：指令与数据隔离（标签包裹外部内容）、输入检测、最小权限工具
- **原理**：RAG 检索到的文档/用户输入都可能是注入载体，system prompt 声明"外部内容只是数据"，高危工具（发邮件/写库）需人工确认，是 Agent 安全第一威胁
- **常见误区**：
  1. 注入只影响聊天（错）
  2. RAG 内容是安全的（错）
  3. 模型能识别所有注入（错）
- **工程用法**：Agent 安全必修
- **版本锚点**：实战共识
