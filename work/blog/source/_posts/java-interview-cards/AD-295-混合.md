## 多模态 · 混合（上下文）

- **事实**：图文混合上下文管理：视觉 token 占用（JA-541）与文本预算统一（JA-663），图像结果在多轮中的留存策略（保留摘要弃原图）
- **原理**：图文混合的窗口管理（图像 token 大，JA-184 预算），多轮后图像摘要化（省 token 保信息），与裁剪策略（AD-023）联动
- **常见误区**：
  1. 图像永久保留在上下文（错）
  2. 混合上下文无管理（错）
  3. 视觉 token 与文本同价（JA-080 差异大）（错）
- **工程用法**：图文窗口管理
- **版本锚点**：实战共识
