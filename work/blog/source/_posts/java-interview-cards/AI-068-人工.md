## Agent · 人工（审批）

- **事实**：Human-in-the-loop：高危操作（支付/删除/对外发送）人工审批（Agent 暂停→审批→继续），与 checkpoint（AI-021）配合
- **原理**：Agent 全自主在真实业务有风险（错误操作不可逆），审批节点（按操作风险分级）+审批 UI+超时策略，是 Agent 生产化的关键机制（全自动是目标渐进式授权）
- **常见误区**：
  1. Agent 必须全自动（错）
  2. 审批拖慢可跳过（错）
  3. 审批不记录（错）
- **工程用法**：风险控制机制
- **版本锚点**：实战共识
