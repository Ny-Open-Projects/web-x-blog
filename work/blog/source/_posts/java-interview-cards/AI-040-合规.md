## 数据 · 合规（隐私）

- **事实**：LLM 数据合规：训练数据版权、用户数据脱敏（PII 不入 prompt）、输出合规审查
- **原理**：调用外部 API 时用户数据出域（隐私风险，脱敏/本地模型），生成内容合规（金融建议/医疗建议免责声明），企业落地的法务前置
- **常见误区**：
  1. 合规是算法团队的事（错）
  2. 脱敏影响效果可以不做（错）
  3. 本地部署就没有合规问题（错）
- **工程用法**：合规工程
- **版本锚点**：实战共识
