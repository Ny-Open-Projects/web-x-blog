## 客户端 · 线程安全（Lettuce）

- **事实**：Java 客户端选型：Lettuce（Netty 线程安全单连接多路复用）vs Jedis（每连接不线程安全需池）
- **原理**：Boot 2.0 起默认 Lettuce，连接复用省资源，Jedis 简单直观高并发下连接池压力大，两者都支持 Cluster/Sentinel
- **常见误区**：
  1. Lettuce 需要连接池否则不安全（单连接多路复用是线程安全的）（错）
  2. Jedis 线程安全（错）
  3. 两者 API 完全相同（错）
- **工程用法**：客户端选型题
- **版本锚点**：实战共识
