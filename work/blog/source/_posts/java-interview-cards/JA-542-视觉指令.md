## 多模态 · 视觉指令（prompt）

- **事实**：视觉 prompt 结构：图像+文本指令的组合设计（"先描述图表类型再提取数据"分步指令）
- **原理**：视觉任务与文本任务一样需要 prompt 工程（JA-109 只解决了输入通道），分步指令提升图表/文档理解精度
- **常见误区**：
  1. 图像不需要 prompt 工程（错）
  2. 一步到位指令最优（错）
  3. 视觉 prompt 无版本管理（错）
- **工程用法**：视觉提示工程
- **版本锚点**：实战共识
