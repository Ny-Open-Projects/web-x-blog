## 运维 · 数据倾斜（倾斜）

- **事实**：Cluster 数据/流量倾斜：bigkey 落单节点、hash tag 聚集、热点 key
- **原理**：排查 cluster node 各节点内存与 QPS 对比，治理：拆 key、打散 hash tag、本地缓存
- **常见误区**：
  1. 倾斜自动均衡（Cluster 不自动迁移流量）（错）
  2. 倾斜只影响内存（错）
  3. 从库可分摊写流量（错）
- **工程用法**：Cluster 运维知识
- **版本锚点**：实战共识
