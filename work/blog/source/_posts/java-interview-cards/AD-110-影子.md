## 评测 · 影子（在线）

- **事实**：Agent 影子运行：新版本 Agent 对真实任务并行跑（影子，不执行副作用），对比轨迹与结果后放量
- **原理**：JA-234 影子双发在 Agent 的落地：副作用让影子必须有"只规划不执行"模式（AD-104 dry-run 结合），与灰度（JA-205）联动
- **常见误区**：
  1. Agent 影子会执行副作用（错）
  2. 影子运行无价值（错）
  3. 直接全量切新版本（错）
- **工程用法**：影子运行设计
- **版本锚点**：实战共识
