## 工具 · 出口（网络）

- **事实**：网络类工具的出口管控：白名单域名+出口 IP 隔离（JA-394），Agent 网络访问与企业出网策略统一
- **原理**：网络工具（HTTP 请求）可外泄数据或访问内网（SSRF 风险），白名单+出口隔离双防，与网络安全知识联动
- **常见误区**：
  1. 网络工具无风险（错）
  2. 域名白名单影响功能（安全优先）（错）
  3. SSRF 与 Agent 无关（错）
- **工程用法**：网络工具管控
- **版本锚点**：实战共识
