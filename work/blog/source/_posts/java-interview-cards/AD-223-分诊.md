## 案例 · 分诊（安全）

- **事实**：安全运营 Agent：告警分诊（SIEM 告警归类）+IOC 检索（威胁情报工具）+处置建议（人确认），安全场景的误报率高是 Agent 价值点
- **原理**：安全告警量大误报多（人力瓶颈），Agent 分诊提效（JA-441 内部场景），误杀风险→建议制（不自动处置）
- **常见误区**：
  1. 安全 Agent 自动封 IP（错）
  2. 告警分诊无价值（错）
  3. 误报不影响价值（错）
- **工程用法**：安全运营案例
- **版本锚点**：实战共识
