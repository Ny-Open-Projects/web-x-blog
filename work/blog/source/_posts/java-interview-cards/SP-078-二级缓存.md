## MyBatis · 二级缓存（缓存）

- **事实**：MyBatis 二级缓存 namespace 级多 SqlSession 共享但生产慎用
- **原理**：跨 namespace 不可见（关联查询更新不失效）、序列化开销、集群下各节点独立（除非第三方实现），生产多用 Redis 缓存替代
- **常见误区**：
  1. 二级缓存集群自动同步（错）
  2. 二级缓存默认开启（错）
  3. 二级缓存比 Redis 缓存更可靠（错）
- **工程用法**：缓存注解失效排查时知道二级缓存边界
- **版本锚点**：MyBatis 文档
