## 场景 · 对比（延迟队列）

- **事实**：延迟队列方案对比：RocketMQ 延迟消息、Redis ZSet 轮询、时间轮、DB 扫描
- **原理**：精度/规模/可靠性排序：RocketMQ（可靠大规模）>时间轮（内存高精度）>Redis ZSet（轻量）>DB 扫描（简单低效），本项目 Redis ZSet 实测过（轮询语义）
- **常见误区**：
  1. DB 扫描是最佳方案（错）
  2. Redis ZSet 实时触发（是轮询）（错）
  3. 延迟队列必须用 MQ（错）
- **工程用法**：延迟场景方案选型
- **版本锚点**：实战方法论
