## MCP · 本地直连（调试）

- **事实**：stdio MCP server 的本地调试：本地客户端直连子进程（echo 调试工具），免宿主环境干扰
- **原理**：MCP 开发的调试友好设计（本地可全链路调），调试客户端脚本化（协议级测试 AD-120 前置），stdio 天然本地可调
- **常见误区**：
  1. stdio 无法本地调试（错）
  2. 调试必须宿主环境（错）
  3. 本地直连是调试标准姿势（错）
- **工程用法**：MCP 调试方法
- **版本锚点**：实战共识
