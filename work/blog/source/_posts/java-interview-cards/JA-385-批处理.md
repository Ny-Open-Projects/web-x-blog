## Spring AI · 批处理（场景）

- **事实**：Spring AI 在非 Web 场景同样可用：CLI 批处理/定时任务直接用 ChatClient（无 Web 依赖）
- **原理**：框架不绑定 Web（核心是模型调用库），批量知识入库/离线评估（JA-058）都是非 Web 用例
- **常见误区**：
  1. Spring AI 必须在 Web 项目（错）
  2. 批处理要走 HTTP 自建（错）
  3. 非 Web 场景需特殊配置（错）
- **工程用法**：非 Web 用例
- **版本锚点**：Spring AI 1.0 GA
