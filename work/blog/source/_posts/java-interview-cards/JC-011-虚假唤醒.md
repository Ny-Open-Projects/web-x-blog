## wait/notify · 虚假唤醒（误用）

- **事实**：等待条件必须用 while 循环判断而不能用 if 以防虚假唤醒
- **原理**：OS 或 notifyAll 唤醒后条件可能已被其他线程消费，while 在唤醒后重新检查条件，JLS 明确允许虚假唤醒存在
- **常见误区**：
  1. 虚假唤醒是 Myth 实际不存在（错）
  2. if 与 while 在等待条件时等价（错）
  3. 虚假唤醒只发生在 Linux 平台（错）
- **工程用法**：所有条件等待统一写 while(条件不满足) wait
- **版本锚点**：JLS 17.2.3
