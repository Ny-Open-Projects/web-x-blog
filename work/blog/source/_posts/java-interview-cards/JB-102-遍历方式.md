## HashMap · 遍历方式（误用）

- **事实**：entrySet 遍历（含 key/value）性能优于先 keySet 再 get（后者每 key 额外一次 hash 定位）。
- **原理**：keySet().get(k) 重复走一遍 hash 定位。
- **常见误区**：
  1. keySet 再 get 与 entrySet 遍历性能完全相同。（错）
  2. entrySet 遍历在 JDK8 后被废弃。（错）
  3. 只取 key 时也应使用 entrySet。（错）
- **工程用法**：JDK8 的 forEach 与 Stream 同样基于 entrySet 视图。
- **版本锚点**：JDK 8+（entrySet 推荐）
