## Agent · 提权（人审）

- **事实**：Agent 权限提升请求流程：任务需要超出当前授权的工具时，Agent 发起提权请求（人工批准后临时授权）
- **原理**：JA-679/259 人审的权限面：不是预先给全权限而是按需申请（最小权限动态版 JA-500），请求留痕审计
- **常见误区**：
  1. Agent 预配全权限（错）
  2. 提权流程不存在（错）
  3. 临时授权无风险（错）
- **工程用法**：按需授权
- **版本锚点**：实战共识
