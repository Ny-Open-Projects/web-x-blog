## 案例 · 监控（舆情）

- **事实**：舆情监控 Agent：多源监控（新闻/社交 API 工具）+情感与主题分析+预警（负面扩散），预警分级（JA-382 舆情等级），响应建议（人决策）
- **原理**：舆情场景的实时性（流式监控 AD-108）与分级预警，响应人决策（公关敏感），与监控案例（AD-223）联动
- **常见误区**：
  1. 舆情监控纯人工（错）
  2. 情感分析不需要（错）
  3. 预警自动响应（错）
- **工程用法**：舆情案例
- **版本锚点**：实战共识
