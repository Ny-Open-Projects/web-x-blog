## 堆 · 堆（结构）

- **事实**：堆：完全二叉树数组存储（i 子节点 2i+1/2i+2），插入/删除 O(logN) 查顶 O(1)
- **原理**：Java PriorityQueue 默认小顶堆，大顶堆用 Collections.reverseOrder()，建堆 O(N)（自底向上下沉）比逐个插入 O(NlogN) 优
- **常见误区**：
  1. 堆是完全有序的（错）
  2. Java PriorityQueue 是大顶堆（错）
  3. 建堆 O(NlogN)（错）
- **工程用法**：TopK/优先级调度基础
- **版本锚点**：理论共识
