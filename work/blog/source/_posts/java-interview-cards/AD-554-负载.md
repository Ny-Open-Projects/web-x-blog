## 协作 · 负载（均衡）

- **事实**：Agent 群体负载均衡：任务分发的负载均衡（按 Agent 当前负载/能力匹配），负载不均导致热点 Agent 延迟高
- **原理**：负载均衡是多 Agent 的容量治理（JA-131 水位的多 Agent 版），均衡策略（最少任务/能力匹配），与负载知识联动
- **常见误区**：
  1. 任务随机分发（错）
  2. 负载均衡不必要（错）
  3. 热点无影响（错）
- **工程用法**：负载均衡设计
- **版本锚点**：实战共识
