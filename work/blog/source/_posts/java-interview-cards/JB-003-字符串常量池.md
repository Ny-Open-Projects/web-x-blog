## String · 字符串常量池（内存）

- **事实**：字符串常量池从 JDK7 起位于堆中，JDK6 及之前位于永久代。
- **原理**：常量池入堆后可被 GC 回收，缓解永久代 OOM 问题。
- **常见误区**：
  1. 字符串常量池在 JDK8 之后位于元空间。（错）
  2. 字符串常量池位于栈内存。（错）
  3. 字符串常量池在 JDK7 后被彻底移除。（错）
- **工程用法**：new String("x") 时字面量 x 入池、堆上另有副本对象。
- **版本锚点**：JDK 7（常量池移入堆）
