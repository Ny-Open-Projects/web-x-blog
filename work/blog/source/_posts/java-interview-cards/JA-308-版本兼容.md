## MCP · 版本兼容（生产）

- **事实**：MCP server 升级的兼容性管理：inputSchema 变更=破坏性变更（客户端填参逻辑失效），schema 只增不改
- **原理**：工具契约演进纪律（与 API 版本管理同构），schema 变更走新版本工具而非原地改
- **常见误区**：
  1. schema 可随意修改（错）
  2. 兼容性由客户端保证（错）
  3. 版本管理不适用于 MCP 工具（错）
- **工程用法**：工具契约演进
- **版本锚点**：MCP 生产化
