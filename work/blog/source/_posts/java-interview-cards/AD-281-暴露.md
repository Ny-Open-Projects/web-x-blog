## 手写 · 暴露（API）

- **事实**：Agent 的 REST API 暴露：POST /agents/{id}/tasks 提交（幂等键 AD-057）→GET 任务状态（AD-273）→SSE 轨迹流（AD-283），API 即产品（JA-641）
- **原理**：REST 暴露让 Agent 服务化（AD-102 平台的接口面），三接口是任务 API 最小集，与 API 设计（JA-641）联动
- **常见误区**：
  1. Agent 无对外 API（错）
  2. 接口设计随意（错）
  3. SSE 不是任务接口（错）
- **工程用法**：REST 暴露
- **版本锚点**：实战共识
