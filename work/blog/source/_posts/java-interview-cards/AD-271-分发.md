## 手写 · 分发（并发）

- **事实**：并发 Agent 的任务分发器实现：任务入队列→工作线程取任务→创建 Agent 实例执行→结果回调，分发器是“Agent 的线程池”
- **原理**：分发器模式（生产者消费者 AL-035 联动），并发度=工作线程数（配额 JA-100 联动），队列满的拒绝策略（AD-017 类比）
- **常见误区**：
  1. 并发 Agent 直接开线程跑（错）
  2. 分发器是过度设计（错）
  3. 并发度无限（错）
- **工程用法**：分发器实现
- **版本锚点**：实战共识
