## 手写 · 问题（评审）

- **事实**：手写 Agent code review 常见问题：终止条件漏预算/工具结果未回填（消息序列断）/脱敏遗漏/并发上下文污染/错误吞掉，五问题高频
- **原理**：review 高频问题的沉淀（AD-200 bug 清单的评审面），review 时按清单速查，与 review 纪律（AD-209）联动
- **常见误区**：
  1. review 无 Agent 特有问题（错）
  2. 五问题是小概率（错）
  3. 清单重复（清单是速查价值）（错）
- **工程用法**：review 问题沉淀
- **版本锚点**：实战共识
