## Agent · 模式选型（编排）

- **事实**：Agent 编排模式选型：固定工作流（确定性高）vs 单 Agent+工具（灵活）vs 多 Agent（复杂任务），按任务确定性需求排序
- **原理**：AI-049 的决策细化：能工作流不 Agent（可控可测），Agent 是灵活性代价换来的，与 MY-105 变更纪律呼应
- **常见误区**：
  1. 多 Agent 一定优于工作流（错）
  2. 工作流过时了（错）
  3. 三者随意选（错）
- **工程用法**：编排选型框架
- **版本锚点**：实战共识
