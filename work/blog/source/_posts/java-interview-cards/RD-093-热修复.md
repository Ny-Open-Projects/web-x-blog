## 运维 · 热修复（故障）

- **事实**：线上热修复手段：CONFIG SET 动态调参、CLIENT KILL 踢连接、DEBUG SLEEP 禁用
- **原理**：CONFIG SET 改淘汰策略/超时不用重启，变更后 CONFIG REWRITE 落盘，危险命令 ACL 治理
- **常见误区**：
  1. CONFIG SET 需重启生效（错）
  2. 热修不需要记录（错）
  3. 所有命令都可热改（错）
- **工程用法**：应急工具箱
- **版本锚点**：实战共识
