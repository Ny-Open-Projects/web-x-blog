## 工程 · 容量（压测）

- **事实**：Agent 容量压测：mock 模型压测编排层（并发任务数/队列深度/资源占用），真实模型抽样压测（成本），两层压测（JA-400 的 Agent 版）
- **原理**：压测定位 Agent 系统瓶颈（编排层 vs 模型层），mock 压并发容量、真实压端到端，与压测方法论联动
- **常见误区**：
  1. 压测只打真实模型（错）
  2. Agent 无容量问题（错）
  3. 两层压测是过度设计（错）
- **工程用法**：Agent 压测
- **版本锚点**：实战共识
