## 提示 · 宪法（system）

- **事实**：Agent 的 system prompt 是"宪法"：角色/目标/工具使用规则/边界/输出规范全在此定义
- **原理**：system 优先级最高（AI-449），宪法质量决定 Agent 行为上限，宪法版本化管理（AI-064），宪法是 Agent 工程的第一资产
- **常见误区**：
  1. system 可有可无（错）
  2. 规则写在用户消息里（错）
  3. 宪法不需要版本化（错）
- **工程用法**：宪法设计纪律
- **版本锚点**：实战共识
