## 协作 · 汇总（安全）

- **事实**：多 Agent 安全汇总：信任边界（JA-175）+身份（AD-098）+通信加密+审计（AD-097）的汇总检查单，系统级安全评审
- **原理**：多 Agent 安全的汇总评审（单 Agent 安全的组合面 JA-081），检查单进架构评审（JA-524），与安全治理联动
- **常见误区**：
  1. 多 Agent 安全=单 Agent 安全（错）
  2. 汇总评审不必要（错）
  3. 信任边界只在单 Agent（错）
- **工程用法**：多 Agent 安全汇总
- **版本锚点**：实战共识
