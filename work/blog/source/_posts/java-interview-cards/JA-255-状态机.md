## Agent · 状态机（状态）

- **事实**：Agent 任务显式状态机：PLANNING→EXECUTING→VERIFYING→DONE/FAILED，状态落库支撑恢复与审计
- **原理**：隐式状态（只存在循环变量）无法 checkpoint（AI-021 落地），状态机是长任务 Agent 的骨架
- **常见误区**：
  1. Agent 不需要状态机（错）
  2. 状态只在内存（错）
  3. 状态机与恢复无关（错）
- **工程用法**：长任务骨架
- **版本锚点**：实战共识
