## SQL · 流程（优化）

- **事实**：SQL 优化流程：慢日志定位→explain（analyze）分析→索引优化或 SQL 改写→回归验证
- **原理**：先看 type/rows/Extra 三要素，改索引最常见，改写（join 顺序、子查询转 join）其次，最后才是参数与架构
- **常见误区**：
  1. 优化先从改参数开始（错）
  2. explain 结果一定准确（错）
  3. 优化不需要验证（错）
- **工程用法**：方法论回答框架
- **版本锚点**：实战方法论
