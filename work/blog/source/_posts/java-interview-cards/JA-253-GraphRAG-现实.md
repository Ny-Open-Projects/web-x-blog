## RAG · GraphRAG 现实（图谱）

- **事实**：GraphRAG（AI-044）的 Java 现实：无开箱框架组件，需图库（Neo4j）+实体抽取管道自建，按 ROI 决策
- **原理**：多跳关系问题少的企业场景不值得建图（成本高），诚实评估而非追新，与选型 ROI 思维（AI-027）联动
- **常见误区**：
  1. GraphRAG 有 Java 开箱组件（错）
  2. 所有场景都该上图（错）
  3. 建图成本为零（错）
- **工程用法**：进阶 RAG 决策
- **版本锚点**：实战共识
