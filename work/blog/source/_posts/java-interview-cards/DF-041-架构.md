## RPC · 架构（Dubbo）

- **事实**：Dubbo 架构：注册中心+Provider/Consumer+Monitor，动态代理+SPI 扩展
- **原理**：分层设计（协议层/交换层/传输层），SPI 微内核插件化（扩展点全开放），3.x 转向应用级服务发现（兼容云原生）
- **常见误区**：
  1. Dubbo 只能用 Dubbo 协议（错）
  2. SPI 是 Java 原生（Dubbo 增强）（错）
  3. 3.x 仍是接口级发现（错）
- **工程用法**：Dubbo 架构演进
- **版本锚点**：Dubbo 3.x
