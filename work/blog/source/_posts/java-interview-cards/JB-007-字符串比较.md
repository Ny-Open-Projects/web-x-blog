## String · 字符串比较（误用）

- **事实**：比较 String 内容必须用 equals，== 只比较引用地址。
- **原理**：== 在两个相同字面量（同入常量池）时碰巧为 true，造成"有时对有时错"的隐蔽 bug。
- **常见误区**：
  1. == 对 String 内容相同就一定返回 true。（错）
  2. equals 比较 String 会抛空指针且无法避免。（错）
  3. 字符串比较用 == 是官方推荐写法。（错）
- **工程用法**：方法入参接收外部字符串时一律 equals 且常量在前。
- **版本锚点**：阿里手册强制条款
