## 工程 · 伸缩（弹性）

- **事实**：Agent 弹性伸缩实现：按队列深度/任务延迟伸缩执行器（JA-478 HPA 的 Agent 面），缩容保护（进行中任务完成再缩）
- **原理**：弹性伸缩的 Agent 面（JA-478 HPA 联动），伸缩指标（队列深度 JA-397），缩容保护（AD-307 停机），与弹性知识联动
- **常见误区**：
  1. Agent 实例固定不伸缩（错）
  2. 伸缩无保护（错）
  3. 指标只有 CPU（错）
- **工程用法**：弹性伸缩实现
- **版本锚点**：实战共识
