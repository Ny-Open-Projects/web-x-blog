## MCP · 工具级（限流）

- **事实**：MCP 工具级限流：server 对每工具限流（重工具独立阈值），限流响应为结构化错误（模型可理解等待）
- **原理**：工具资源消耗差异大（JA-018），工具级限流防单工具打垮 server，限流错误回喂模型重试（JA-016），与限流知识联动
- **常见误区**：
  1. MCP server 不限流（错）
  2. 限流是进程级（工具级更细）（错）
  3. 限流错误不用管（错）
- **工程用法**：工具限流
- **版本锚点**：实战共识
