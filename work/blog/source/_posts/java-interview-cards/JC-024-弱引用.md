## ThreadLocal · 弱引用（内存语义）

- **事实**：ThreadLocalMap 的 key 是弱引用 value 是强引用
- **原理**：ThreadLocal 外部引用消失后 key 会被 GC 回裂为 null，但 value 仍被线程强引用无法回收，线程池场景线程长存导致泄漏，必须 finally remove
- **常见误区**：
  1. key 与 value 都是弱引用（错）
  2. 有 cleanUp 机制所以绝不泄漏（错）
  3. 内存泄漏只发生在 ThreadLocal 是局部变量时（错）
- **工程用法**：线程池中用完必须 remove() 写进代码规范
- **版本锚点**：JDK 源码
