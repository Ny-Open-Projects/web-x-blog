## 语言杂项 · 自动模块化（版本）

- **事实**：JDK9 引入模块系统（JPMS）：module-info.java 声明依赖与导出，JDK 内部 API（如 sun.misc.Unsafe 部分）被强封装。
- **原理**：强封装破坏了直接依赖 JDK 内部 API 的老代码——升级 JDK 的最大阻力源。
- **常见误区**：
  1. JDK9 对内部 API 没有任何封装变化。（错）
  2. JPMS 强制所有类库都必须模块化。（错）
  3. module-info.java 是可选的注解文件。（错）
- **工程用法**：升级 JDK 的两大障碍：内部 API 封装与废弃 API 清理。
- **版本锚点**：JDK9+
