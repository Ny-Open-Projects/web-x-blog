## 运维 · 隔离（多实例）

- **事实**：多业务共享 Redis 集群的隔离：按业务分实例/分 slot 段+配额限制
- **原理**：共享实例互相影响（某业务 bigkey/热 key 拖垮全实例），大业务独立实例，中小业务共享但监控分业务 QPS（ACL+监控打标）
- **常见误区**：
  1. 共享集群自动隔离（错）
  2. 隔离只靠 key 前缀（不足以限资源）（错）
  3. 多实例成本高必须共享（错）
- **工程用法**：平台化治理
- **版本锚点**：实战方法论
