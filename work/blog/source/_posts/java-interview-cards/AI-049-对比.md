## Agent · 对比（框架）

- **事实**：Agent 框架对比：LangGraph（图编排/状态机）、Spring AI（Java 生态）、Dify/LangFlow（低代码可视化）、自研（可控性最高）
- **原理**：编排复杂度决定选择：简单工具调用用 SDK 直接写，状态机式多步用 LangGraph，业务人员参与用 Dify，核心生产系统自研+SDK 组合，P10 观点：框架是脚手架不是壁垒
- **常见误区**：
  1. 框架越新越好（错）
  2. 低代码适合所有生产场景（错）
  3. 必须用框架（错）
- **工程用法**：框架选型论证
- **版本锚点**：实战共识
