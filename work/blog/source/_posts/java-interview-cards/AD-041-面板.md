## 观测 · 面板（三件）

- **事实**：Agent 可观测三件：轨迹浏览器（步级回放）、token 成本面板（步均/任务均）、工具健康面板（JA-468）
- **原理**：三件构成 Agent 运维最小集（缺一排障盲区），与中台观测（JA-376）集成，观测成本与价值评估
- **常见误区**：
  1. Agent 可观测只有日志（错）
  2. 三件是过度设计（错）
  3. 面板与运维无关（错）
- **工程用法**：观测三件套
- **版本锚点**：实战共识
