## 工程 · i18n（模板）

- **事实**：多语言 prompt 模板管理：按语言域维护模板文件，渲染时按用户语言选择
- **原理**：面向多区域用户的产品（模板资产化 JA-078 扩展），语言维度与版本维度正交
- **常见误区**：
  1. prompt 只需中文版（错）
  2. 多语言靠模型自己翻译（错）
  3. i18n 是可选装饰（错）
- **工程用法**：国际化工程
- **版本锚点**：实战共识
