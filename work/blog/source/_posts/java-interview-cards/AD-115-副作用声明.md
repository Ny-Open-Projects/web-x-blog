## MCP · 副作用声明（工具）

- **事实**：MCP 工具的副作用声明：工具描述中声明只读/可写/幂等性，客户端据此决定确认策略（JA-259 联动）
- **原理**：副作用声明让客户端"知情调用"（写工具需确认），声明进 description 或元数据，与工具安全分级（AD-076）联动
- **常见误区**：
  1. 副作用无需声明（错）
  2. 客户端不关心副作用（错）
  3. 声明与确认无关（错）
- **工程用法**：副作用声明
- **版本锚点**：实战共识
