## 上下文 · 消息序列（管理）

- **事实**：Agent 的消息序列管理：system+任务+历史轮次（含工具调用与结果）持续增长，窗口管理是 Agent 工程核心
- **原理**：消息序列是 Agent 的工作记忆（JA-014 观念延伸），窗口溢出=Agent 失忆，裁剪策略（摘要/裁旧）决定长任务能力
- **常见误区**：
  1. 消息序列自动无限扩展（错）
  2. 窗口管理是可选项（错）
  3. 溢出由框架自动完美处理（错）
- **工程用法**：上下文管理核心
- **版本锚点**：实战共识
