## MCP · 签名（handler）

- **事实**：MCP 工具 handler 签名：入参为反序列化后的请求对象（按 inputSchema），出参为 CallToolResult（content 列表）
- **原理**：handler 是"普通 Java 方法"（框架处理协议），出参 content 类型决定客户端消费方式（JA-093），签名清晰是可测试前提
- **常见误区**：
  1. handler 直接处理 JSON 字符串（错）
  2. 出参就是字符串（错）
  3. 签名与 schema 无关（错）
- **工程用法**：handler 设计
- **版本锚点**：实战共识
