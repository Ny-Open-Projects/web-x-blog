## GC · 构成（停顿）

- **事实**：GC 停顿=STW 阶段总和（初始标记、复制/清理等），并发阶段不贡献停顿
- **原理**：G1 的 Initial Mark 随 Minor GC 发生、Remark 与 Cleanup 是主要 STW，ZGC 仅极短 STW，分析停顿构成才能对症
- **常见误区**：
  1. GC 停顿=标记+清除全程（错）
  2. 并发阶段也算停顿（错）
  3. ZGC 完全无停顿（错）
- **工程用法**：延迟优化先拆停顿构成
- **版本锚点**：实战方法论
