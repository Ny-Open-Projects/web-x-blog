## 上下文 · 记忆系统（集成）

- **事实**：Agent 与外部记忆系统集成（Mem0 类记忆服务）：记忆读写 API 化（AD-290 接口的外部实现），记忆服务独立部署多 Agent 共享
- **原理**：外部记忆服务的集成模式（AD-090 接口的 SaaS 实现），共享记忆的隐私边界（JA-072），与记忆服务生态联动
- **常见误区**：
  1. 记忆只能内置（错）
  2. 外部记忆无必要（错）
  3. 集成成本高（API 简单）（错）
- **工程用法**：外部记忆集成
- **版本锚点**：实战共识
