## 安全 · MCP（供应链）

- **事实**：恶意 MCP server 供应链攻击：第三方 server 携带恶意工具（数据外泄/后门），防线=来源审计（AD-082）+行为监控（JA-312）+权限最小化
- **原理**：供应链攻击在 MCP 生态的形态（与依赖投毒同构），第三方 server 视为不可信组件（信任边界 JA-175），与供应链安全联动
- **常见误区**：
  1. 市场 server 都安全（错）
  2. 供应链攻击不存在（错）
  3. 行为监控不需要（错）
- **工程用法**：供应链防线
- **版本锚点**：实战共识
