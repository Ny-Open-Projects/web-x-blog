## RAG 评测 · 标注一致性（噪声）

- **事实**：golden set 标注一致性问题：多人标注同一查询期望片段不一致（Kappa 系数度量），需仲裁机制
- **原理**：评估标尺本身有噪声（JA-245 的质量面），一致性差的条目仲裁或剔除，标尺可信度先于指标
- **常见误区**：
  1. 标注天然完全一致（错）
  2. 不一致的条目保留无影响（错）
  3. 单人标注没有噪声（错）
- **工程用法**：评估数据质量
- **版本锚点**：实战共识
