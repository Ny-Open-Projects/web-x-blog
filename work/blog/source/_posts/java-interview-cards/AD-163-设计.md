## 评测 · 设计（判分）

- **事实**：Agent 评测判分 prompt 设计：judge 按 rubric 评分（任务完成/效率/安全三维度），judge 输入含任务+轨迹+产出
- **原理**：JA-651 判分在 Agent 的特化：轨迹是判分输入（不同于单轮答案），三维度加权，judge 版本管理（AI-064）
- **常见误区**：
  1. judge 只看最终结果（错）
  2. 三维度不必分开（错）
  3. 判分 prompt 无需版本化（错）
- **工程用法**：判分设计
- **版本锚点**：实战共识
