## 治理 · 矩阵（合规）

- **事实**：Agent 合规矩阵：数据密级（JA-380）×部署形态（云/私有）×功能（可用场景）三维矩阵，合规矩阵是 Agent 准入的判定表
- **原理**：合规矩阵的 Agent 面（JA-380 矩阵的 Agent 维），准入判定表化（JA-525 自动化），与合规知识联动
- **常见误区**：
  1. 合规无矩阵（错）
  2. 三维不必要（错）
  3. 矩阵手工判断（判定表自动化）（错）
- **工程用法**：合规矩阵
- **版本锚点**：实战共识
