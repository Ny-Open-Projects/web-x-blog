## 场景 · 预扣（秒杀）

- **事实**：秒杀库存方案：Redis 预扣（Lua 原子判断+扣减）+MQ 异步下单+DB 最终扣减兜底
- **原理**：Redis 单线程扛住瞬时扣减流量，MQ 削峰进入下单流程，DB 用乐观锁兜底防超卖，本项目总结的三段式
- **常见误区**：
  1. 秒杀直接打 DB 加锁即可（错）
  2. Redis 预扣后一定成单（MQ 失败需回补）（错）
  3. 预扣与 DB 无一致性要求（错）
- **工程用法**：大促库存架构
- **版本锚点**：实战方法论
