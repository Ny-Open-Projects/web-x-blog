## 运维 · 故障（演练）

- **事实**：Agent 故障演练矩阵：模型不可用（降级）/工具故障（摘除）/配额耗尽（收尾）/记忆污染（回滚）四场景，演练验证 runbook（AD-416）
- **原理**：演练矩阵的 Agent 特化（JA-286 的 Agent 面）：每场景验证对应防线，演练产出 runbook 更新，与混沌工程联动
- **常见误区**：
  1. Agent 不需要演练（错）
  2. 四场景覆盖不全没关系（错）
  3. runbook 静态（错）
- **工程用法**：演练矩阵
- **版本锚点**：实战共识
