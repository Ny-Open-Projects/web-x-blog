## Agent · 结构化（输出）

- **事实**：Agent 输出结构化：最终产出按 schema（结论/证据/步骤/置信度），程序可消费（JA-374 细化），输出质量纳入评测
- **原理**：结构化输出让 Agent 从"演示"变"生产组件"（下游可集成），schema 是 Agent 的输出契约，与评测（JA-375）联动
- **常见误区**：
  1. Agent 输出给人看即可（错）
  2. 结构化限制能力（错）
  3. schema 无关评测（错）
- **工程用法**：输出契约设计
- **版本锚点**：实战共识
