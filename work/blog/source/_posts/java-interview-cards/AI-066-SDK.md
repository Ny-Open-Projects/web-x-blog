## Java · SDK（集成）

- **事实**：Java SDK 层细节：超时（连接/读分开）、重试（429 退避）、流式（SSE 客户端）、连接池、代理配置
- **原理**：LLM SDK 是特殊"HTTP 客户端"（长响应/流式/限流语义），超时长于生成时间、429 与 5xx 区别重试、SSE 断线处理，与 HTTP 客户端工程知识联动
- **常见误区**：
  1. SDK 开箱即用无需配置（错）
  2. 超时用默认 30 秒（错）
  3. 流式处理与普通 HTTP 相同（错）
- **工程用法**：客户端工程细节
- **版本锚点**：实战共识
