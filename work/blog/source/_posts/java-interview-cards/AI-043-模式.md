## Agent · 模式（失败）

- **事实**：Agent 失败模式：工具错误（参数错/权限无）、死循环（反复重试同工具）、上下文溢出（历史过长）、幻觉结论（工具没返回却编造）
- **原理**：按模式设防：参数校验+错误反馈给模型、循环上限+重复检测、历史压缩、结论必须引用工具结果（faithfulness 校验），与护栏（AI-019）配套
- **常见误区**：
  1. Agent 失败靠重试（错）
  2. 死循环不存在（错）
  3. 幻觉只在无工具时（错）
- **工程用法**：失败模式工程
- **版本锚点**：实战共识
