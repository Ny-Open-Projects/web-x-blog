## 工程 · 清单（评审）

- **事实**：AI 功能 code review 清单：密钥不入库（JA-043）/防串号（JA-097）/工具幂等（JA-218）/注入边界（JA-225）/输出扫描（JA-262）五项必查
- **原理**：把前面红线收敛成 review checklist，人工 review 前先跑静态检查，与 MY-104 SQL 审核思想同构
- **常见误区**：
  1. review 与普通代码一样（错）
  2. 清单是形式主义（错）
  3. 红线靠自觉（错）
- **工程用法**：质量门
