## 工程 · 模型（影响）

- **事实**：模型升级对 Agent 行为影响：新模型工具调用风格变化（参数格式/多工具倾向）改变 Agent 轨迹，模型升级必须过 Agent 回归套件（JA-680）
- **原理**：模型是 Agent 的"大脑"（AD-059 三元组），换脑=行为全变，回归是唯一保障（JA-094 基线），与模型升级纪律（JA-391）联动
- **常见误区**：
  1. 模型升级对 Agent 无影响（错）
  2. 行为不可比较（错）
  3. 回归套件可选（错）
- **工程用法**：模型升级纪律
- **版本锚点**：实战共识
