## Java · LangChain4j（集成）

- **事实**：LangChain4j：Java 版 LangChain（AiServices 声明式、RAG 组件、多模型支持）
- **原理**：声明式接口（注解定义 AI 服务）降低样板代码，RAG 管道组件齐全，与 Spring AI 并存按团队偏好选，都支持 function calling
- **常见误区**：
  1. LangChain4j 是 Python 库（错）
  2. 两者 API 完全相同（错）
  3. 只能用其中之一（错）
- **工程用法**：框架选型
- **版本锚点**：实战共识
