## 应用 · LLM 网关（网关）

- **事实**：LLM 网关：统一多模型接入（切换/降级）、限流计费、缓存、审计日志，类似 API 网关的 LLM 版
- **原理**：模型可替换性（供应商切换/新模型灰度）与应用解耦，计费归集到业务方，敏感内容审计在网关层，开源实现（LiteLLM/Higress AI）
- **常见误区**：
  1. 直连模型厂商即可（错）
  2. 网关影响生成质量（错）
  3. 切换模型无成本（错）
- **工程用法**：LLM 应用基础设施
- **版本锚点**：实战共识
