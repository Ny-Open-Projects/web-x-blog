## 工程 · API（架构）

- **事实**：对外 AI API 设计要点：流式开关/幂等键（JA-467）/超时声明/配额头（剩余量）/错误码规范，API 即产品
- **原理**：对外 AI API 与内部调用差异（契约/配额/SLA 显式化），与 REST 设计规范联动，网关强制（JA-317）
- **常见误区**：
  1. AI API 随便设计（错）
  2. 对外与内部一样（错）
  3. 契约不需要声明（错）
- **工程用法**：API 产品化
- **版本锚点**：实战共识
