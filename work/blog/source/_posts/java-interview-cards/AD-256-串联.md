## 工程 · 串联（观测）

- **事实**：Agent 日志与 trace 串联：轨迹条目带 traceId（JA-096 全链路），轨迹与日志/指标三方可关联（观测三支柱在 Agent 的统一）
- **原理**：观测统一是排障效率（JA-596 trace 树的 Agent 面），三支柱割裂=排障三头跑，与可观测三支柱（DF-053/091）联动
- **常见误区**：
  1. 轨迹与 trace 无关（错）
  2. 三支柱在 Agent 无法统一（错）
  3. 串联成本高（错）
- **工程用法**：观测统一
- **版本锚点**：实战共识
