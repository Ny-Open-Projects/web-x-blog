## 治理 · 治理（供应商）

- **事实**：Agent 供应商治理：多供应商接入清单（JA-721）/健康监控（JA-381）/合同（JA-515）/退出预案（JA-391）四件，供应商是 Agent 的关键依赖
- **原理**：供应商治理四件在 Agent 域的落地（Agent 依赖供应商 JA-056），供应商事故=Agent 故障，与供应商知识联动
- **常见误区**：
  1. 供应商治理与 Agent 无关（错）
  2. 四件冗余（错）
  3. 退出预案可选（错）
- **工程用法**：供应商治理
- **版本锚点**：实战共识
