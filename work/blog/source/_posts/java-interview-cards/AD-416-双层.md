## 协作 · 双层（监控）

- **事实**：多 Agent 双层监控：每 Agent 独立大盘（AD-207）+系统级大盘（端到端成功率/协作效率 AD-203），双层定位问题层级
- **原理**：双层监控定位"哪个 Agent 的问题还是协作的问题"（JA-203 端到端的监控面），与大盘知识联动
- **常见误区**：
  1. 监控只有全局一层（错）
  2. 双层是过度设计（错）
  3. 单层足够定位（错）
- **工程用法**：双层监控
- **版本锚点**：实战共识
