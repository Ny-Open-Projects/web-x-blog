## 编排 · 策略（聚合）

- **事实**：多 Agent 结果聚合策略：投票（多数一致）/加权（按 Agent 专长）/裁决者（独立裁判 Agent）/融合（合并要点），按任务选
- **原理**：JA-244 聚合的多 Agent 版：聚合策略决定"群体智慧"质量，辩论（AD-029）是聚合的对抗变体，策略与任务类型匹配
- **常见误区**：
  1. 聚合就是简单拼接（错）
  2. 策略无关紧要（错）
  3. 拼接总是可行（错）
- **工程用法**：聚合策略
- **版本锚点**：实战共识
