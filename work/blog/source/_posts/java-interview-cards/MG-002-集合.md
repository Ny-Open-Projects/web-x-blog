## 文档模型 · 集合（概念）

- **事实**：集合（collection）对应关系模型的表但无固定 schema
- **原理**：同一集合文档结构可以不同，schema 由应用层保证（或 JSON Schema 校验），灵活但也要求自律
- **常见误区**：
  1. 集合强制 schema（错）
  2. 集合必须先建才能插数据（错）
  3. 无 schema 意味着不需要设计（错）
- **工程用法**：建模评审仍必须做
- **版本锚点**：官方文档
