## DP · DP（入门）

- **事实**：动态规划：状态定义+转移方程+初始化+遍历顺序四要素，重叠子问题+最优子结构两前提
- **原理**：自顶向下（记忆化递归）与自底向上（填表）等价，空间优化（滚动数组）常见，背包/LCS/编辑距离三经典，与回溯对比（DP 记子问题）
- **常见误区**：
  1. DP 就是递归（错）
  2. 状态定义随意（错）
  3. DP 一定优于贪心（错）
- **工程用法**：DP 方法论
- **版本锚点**：理论共识
