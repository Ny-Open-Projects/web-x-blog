## 学习 · few-shot（跨任务）

- **事实**：跨任务学习：历史成功任务的轨迹摘要作为 few-shot 示例（相似任务检索注入），Agent 越用越熟练
- **原理**：数据飞轮（JA-452）的 Agent 版：成功轨迹是最好的示例，检索注入（JA-013），失败轨迹不注入（JA-531 分类）
- **常见误区**：
  1. Agent 无法从历史学习（错）
  2. 历史轨迹全部注入（错）
  3. 学习不需要成功判定（错）
- **工程用法**：跨任务学习
- **版本锚点**：实战共识
