## 数据结构 · 为什么不用 B+树（选型）

- **事实**：Redis 不用 B+ 树：内存场景 hash/skiplist/listpack 更快且快照友好
- **原理**：B+ 树为磁盘优化（减少 IO 深页缓存），内存访问 hash O(1) 已够，持久化用整体快照而非 B+ 树原地更新
- **常见误区**：
  1. 内存里 B+ 树最快（错）
  2. Redis 用了 B+ 树做索引（错）
  3. 不用 B+ 树是因为实现复杂（错）
- **工程用法**：存储引擎选型思维题
- **版本锚点**：架构思维
