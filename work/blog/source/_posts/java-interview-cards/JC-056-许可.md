## 协作工具 · 许可（Semaphore）

- **事实**：Semaphore 维护许可数用于限流与资源池
- **原理**：acquire 获取 release 归还，公平模式可选，典型场景：数据库连接池上限、接口并发限流
- **常见误区**：
  1. Semaphore 的许可是资源本身（错）
  2. release 可以使许可超过初始值（默认不允许）（错）
  3. Semaphore 默认公平（错）
- **工程用法**：接口并发数控制首选
- **版本锚点**：JDK 文档
