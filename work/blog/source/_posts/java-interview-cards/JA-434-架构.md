## 场景 · 架构（客服）

- **事实**：智能客服 Java 架构深化：意图路由→RAG 答复→情绪识别升级人工→会话摘要转接，四级漏斗
- **原理**：AI-037 的架构细化：情绪/升级漏斗控制转人工率（北极星），会话摘要让人工接手有上下文，与 JA-289 指标联动
- **常见误区**：
  1. 客服直接 LLM 回复（错）
  2. 情绪识别可选（错）
  3. 转接无需上下文（错）
- **工程用法**：客服漏斗设计
- **版本锚点**：实战共识
