## 案例 · 运维（SRE）

- **事实**：SRE Agent 深化：告警分诊（读监控/查日志/关联变更）→预案建议（runbook 检索 JA-416）→执行确认（AD-080），SRE 知识库是弹药
- **原理**：SRE Agent 的价值在"告警风暴降噪"（分诊减少人处理量），知识库与工具双轮，与运维案例（AD-124）互补细化
- **常见误区**：
  1. SRE Agent 自动重启生产（错）
  2. 分诊无价值（错）
  3. 知识库不需要（错）
- **工程用法**：SRE Agent 案例
- **版本锚点**：实战共识
