## Agent · 资源池（预算）

- **事实**：Agent token 预算池按任务隔离：每任务独立预算池（超限熔断），任务间互不挤占
- **原理**：JA-276 步数上限的资源版：步数防循环、预算池防成本，双重防线，预算池与租户预算（JA-461）联动
- **常见误区**：
  1. 任务共享全局预算（错）
  2. 预算池无必要（错）
  3. 池隔离影响效率（错）
- **工程用法**：任务级预算
- **版本锚点**：实战共识
