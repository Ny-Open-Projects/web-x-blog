## 流式 · 首字（延迟）

- **事实**：首字延迟（TTFT）优化组合：流式+精简 system（缓存前缀稳定）+供应商 prompt cache 命中+就近区域
- **原理**：TTFT 是流式体验核心指标（AI-052），四招叠加把秒级压到数百毫秒，与 JA-297 并发模型联动
- **常见误区**：
  1. TTFT 无法优化（错）
  2. 首字延迟与 prompt 无关（错）
  3. 优化只靠换模型（错）
- **工程用法**：流式延迟工程
- **版本锚点**：实战共识
