## 工程 · 描述质量（工具）

- **事实**：工具 description 写清何时用/何时不用/参数含义，描述质量直接决定模型调用准确率
- **原理**：模型靠描述选工具填参数（AI-058 联动），描述含糊导致误调用或不调用，上线前自查描述可读性
- **常见误区**：
  1. 描述随便写不影响调用（错）
  2. 模型会读代码推断（错）
  3. 描述越长越好（错）
- **工程用法**：工具工程规范
- **版本锚点**：实战共识
