## 工程 · 生成器（校验）

- **事实**：从 schema 生成 JSR-303 校验器：结构化输出的 schema 与 Java 校验注解同步生成（schema 变更→校验同步）
- **原理**：JA-226 二次校验的自动化：手工维护校验与 schema 脱节，代码生成保证一致，与代码生成工程联动
- **常见误区**：
  1. 校验手动维护即可（错）
  2. 生成器不必要（错）
  3. schema 与校验天然一致（错）
- **工程用法**：校验同步自动化
- **版本锚点**：实战共识
