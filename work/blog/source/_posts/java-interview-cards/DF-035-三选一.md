## 锁 · 三选一（对比）

- **事实**：分布式锁对比：Redis（AP 高性能可能丢锁）、ZK/etcd（CP 可靠但慢）、DB（唯一行锁简单）
- **原理**：按业务分级：防重执行用 Redis（效率锁），强互斥（资金）用 ZK/etcd 或 DB 乐观锁（正确性锁），P10 观点：Redis 锁的正确性争议决定了它只适合效率场景
- **常见误区**：
  1. Redis 锁适合一切场景（错）
  2. ZK 锁性能最高（错）
  3. DB 锁不可用（错）
- **工程用法**：锁选型论证框架
- **版本锚点**：实战方法论
