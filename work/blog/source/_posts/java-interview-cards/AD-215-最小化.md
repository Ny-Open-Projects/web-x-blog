## 协作 · 最小化（上下文）

- **事实**：跨 Agent 上下文传递最小化：父传子只传任务必需信息（不传全量历史），最小化防泄露（JA-018 数据最小化的 Agent 面）
- **原理**：全量传递=泄露面扩大+token 浪费（JA-025），最小化传递是安全与成本双优，与数据最小化（JA-418）联动
- **常见误区**：
  1. 传递全量上下文更稳（错）
  2. 最小化影响子任务（按任务设计传递面）（错）
  3. 与安全无关（错）
- **工程用法**：传递最小化
- **版本锚点**：实战共识
