## 数据 · 库 A/B（评估）

- **事实**：知识库 A/B：新旧库（不同切分/模型/清洗策略）并行建索引，同 query 集对比检索质量后再切流
- **原理**：知识库变更的验证手段（MY-105 变更规范的 AI 版），影子索引（JA-501 相关）+golden set 判定
- **常见误区**：
  1. 知识库直接替换（错）
  2. A/B 无法实现（错）
  3. 对比不需要 query 集（错）
- **工程用法**：知识库变更验证
- **版本锚点**：实战共识
