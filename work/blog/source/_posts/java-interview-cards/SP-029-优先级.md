## Boot · 优先级（配置）

- **事实**：配置优先级：命令行参数 > 环境变量 > application-{profile} > application
- **原理**：SpringApplication.setAddCommandLineProperties 默认开，K8s 部署靠环境变量覆盖文件配置
- **常见误区**：
  1. application 文件优先级高于环境变量（错）
  2. profile 文件优先级低于主文件（错）
  3. 命令行参数默认被忽略（错）
- **工程用法**：容器化配置注入的依据
- **版本锚点**：Boot 文档
