## 案例 · 效能（研发）

- **事实**：研发效能 Agent：需求→技术方案草稿→任务拆解（JA-010）→代码骨架生成（AD-156 防线）→测试生成（AD-122），研发全链辅助
- **原理**：研发效能 Agent 的全链设计（各环节 Agent 化的集成案例），每环节人审（代码入库规范 AD-459），与研发案例（AD-122）联动
- **常见误区**：
  1. 研发 Agent 全自动写代码入库（错）
  2. 需求理解不需要（错）
  3. 测试生成可选（错）
