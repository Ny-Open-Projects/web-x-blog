## 场景 · 幂等（幂等）

- **事实**：接口幂等辅助：Redis SET NX 请求 ID（token 机制）前置防重
- **原理**：防重提交：提交前领 token（SET NX），提交时校验删除（Lua 原子），与 DB 唯一键双层兜底，TTL 控制防重窗口
- **常见误区**：
  1. Redis 幂等是唯一防线（错）
  2. token 机制不需要原子校验（错）
  3. 幂等窗口越长越好（按业务定）（错）
- **工程用法**：防重提交方案
- **版本锚点**：实战共识
