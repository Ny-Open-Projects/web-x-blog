## Agent · 卡死（监控）

- **事实**：长任务 Agent 心跳监控：步间超时检测（相邻步骤间隔超阈=卡死），告警+自动终止+checkpoint 续跑
- **原理**：Agent 卡死的检测面（JA-276 步数上限的补充：上限是次数、心跳是时间），与调度器健康检查联动
- **常见误区**：
  1. Agent 不会卡死（错）
  2. 卡死靠人工发现（错）
  3. 检测成本高（心跳轻量）（错）
- **工程用法**：Agent 健康监控
- **版本锚点**：实战共识
