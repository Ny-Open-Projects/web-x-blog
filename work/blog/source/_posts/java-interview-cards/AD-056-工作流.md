## 架构 · 工作流（集成）

- **事实**：Agent 与工作流引擎集成：工作流管确定性步骤、Agent 节点处理智能步骤（混合编排），各取所长
- **原理**：JA-368 三模式的最优组合：引擎提供持久化/重试/可视化的成熟件，Agent 提供智能，与 LangGraph4j（JA-369）对照
- **常见误区**：
  1. Agent 取代工作流（错）
  2. 集成是过度设计（错）
  3. 引擎与 Agent 互斥（错）
- **工程用法**：混合编排
- **版本锚点**：实战共识
