## 手写 · 实现（执行）

- **事实**：工具执行器实现：查注册表→参数反序列化→执行（带超时 JA-053）→结果包装为 tool 消息→异常包装为错误消息（JA-016 反馈）
- **原理**：执行器是"防御式调用"（每步防错），实现细节决定 Agent 健壮性（JA-448 失败清单的代码面），与执行隔离（AD-053）联动
- **常见误区**：
  1. 执行器直接反射调用（错）
  2. 异常直接上抛（错）
  3. 超时不需要（错）
