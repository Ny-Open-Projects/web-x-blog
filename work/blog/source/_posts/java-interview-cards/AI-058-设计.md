## Agent · 设计（工具）

- **事实**：工具设计原则：原子性（一个工具一件事）、描述完备（用途/参数/边界/错误码）、幂等（重试安全）、错误信息可读（模型能自我修复）
- **原理**：工具是 Agent 的"手"，工具质量决定 Agent 上限，错误信息返回给模型（可读）让它修正参数重试，与 RPC 接口设计原则同构
- **常见误区**：
  1. 工具越多越好（错）
  2. 工具描述随意（错）
  3. 工具错误对用户可见（错）
- **工程用法**：工具工程化
- **版本锚点**：实战共识
