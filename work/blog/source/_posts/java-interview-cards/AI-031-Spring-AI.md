## Java · Spring AI（集成）

- **事实**：Spring AI：统一 LLM/向量库/工具调用抽象（ChatClient/EmbeddingModel），Java 生态的 AI 应用框架
- **原理**：屏蔽厂商差异（OpenAI/Ollama/通义），RAG 抽象（DocumentLoader/Splitter/VectorStore），与 LangChain4j 对比：Spring 集成更深，1.0 已 GA
- **常见误区**：
  1. Spring AI 只支持 OpenAI（错）
  2. Java 无法做 AI 应用（错）
  3. Spring AI 就是 LangChain（错）
- **工程用法**：Java 开发者主框架
- **版本锚点**：Spring AI 1.0
