## 语言杂项 · 整数溢出（语法语义）

- **事实**：int 溢出不抛异常而是静默回绕（wrap around），必须用 Math.addExact 或 Math.multiplyExact 显式检测。
- **原理**：二进制补码运算天然回绕，硬件层面不报错。
- **常见误区**：
  1. int 溢出会抛 ArithmeticException。（错）
  2. int 溢出会自动提升为 long。（错）
  3. 溢出后的结果仍然符合数学直觉。（错）
- **工程用法**：Math.addExact 溢出抛 ArithmeticException——金融计算必用。
- **版本锚点**：JLS 4.2.2
