## RAG · 实现（混合检索）

- **事实**：混合检索的 Java 落地形态：向量库语义召回 + ES 关键词召回双路，应用层 RRF（倒数排名融合）合并排序
- **原理**：向量召回弱在专有名词（AI-008），关键词路补齐，RRF 免调融合权重，是生产 RAG 标配（AI-032/062 之上）
- **常见误区**：
  1. 混合检索必须同一库实现（错）
  2. RRF 需要训练权重（错）
  3. 双路检索是过度设计（错）
- **工程用法**：混合检索架构
- **版本锚点**：实战共识
