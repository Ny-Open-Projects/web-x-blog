## 工程 · 集成（网格）

- **事实**：Agent 与 Service Mesh：Agent 服务间调用经 mesh（mTLS/观测/流量治理 JA-097），mesh 让 Agent 微服务化治理统一
- **原理**：mesh 集成（DF-098 的 Agent 面），mTLS 与观测的统一收益，与 mesh 权衡（JA-098 复杂度）联动
- **常见误区**：
  1. Agent 服务不需要 mesh（错）
  2. mesh 无收益（错）
  3. 集成复杂度可忽略（错）
- **工程用法**：mesh 集成
- **版本锚点**：实战共识
