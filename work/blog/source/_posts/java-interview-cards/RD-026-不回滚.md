## 事务 · 不回滚（MULTI）

- **事实**：Redis 事务 MULTI/EXEC 队列化执行不支持回滚
- **原理**：命令入队时语法错误整个事务不执行，运行时错误（如对 string 执行 LPUSH）不回滚继续执行后续命令，官方认为回滚无必要（编程错误场景）
- **常见误区**：
  1. Redis 事务支持回滚（错）
  2. 运行时错误会中止事务（错）
  3. 事务有隔离无原子（有原子：命令串行执行不穿插）（错）
- **工程用法**：与 Lua 对比题
- **版本锚点**：官方文档
