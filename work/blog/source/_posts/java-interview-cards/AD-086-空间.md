## MCP · 空间（命名）

- **事实**：MCP 工具命名空间规范：server 名做前缀（github_create_issue），模型看到唯一名，消歧与溯源（哪个 server 的工具）双收益
- **原理**：命名空间让工具可溯源（JA-312 审计按 server），规范命名是接入层标准动作，与 AD-085 联动
- **常见误区**：
  1. 命名空间影响模型理解（错）
  2. 无规范必要（错）
  3. 前缀可选装饰（错）
- **工程用法**：命名空间规范
- **版本锚点**：实战共识
