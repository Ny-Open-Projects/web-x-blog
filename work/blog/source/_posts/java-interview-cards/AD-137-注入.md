## 安全 · 注入（回喂）

- **事实**：工具结果的注入检测：外部内容（网页/API 返回）回喂模型前过注入检测（JA-394），工具是注入进入的通道
- **原理**：工具结果是不可信输入（网页/第三方 API 可能被投毒），回喂前检测是 Agent 特有防线，与 JA-225 边界标签联动
- **常见误区**：
  1. 工具结果可信无需检测（错）
  2. 检测影响性能（轻量扫描）（错）
  3. 注入只在用户输入（错）
- **工程用法**：工具注入防线
- **版本锚点**：实战共识
