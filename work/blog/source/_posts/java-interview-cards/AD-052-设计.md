## 手写 · 设计（schema）

- **事实**：工具 schema 设计：参数名语义化/类型明确/必填标注/描述清晰（JA-015），schema 是模型填参的"表单"
- **原理**："表单"类比帮助 schema 设计（模型按表单填参），schema 差=填参错（JA-015），与 JSON Schema 知识联动
- **常见误区**：
  1. schema 无关紧要（错）
  2. 参数名随意（错）
  3. 模型能猜参数（错）
- **工程用法**：schema 设计纪律
- **版本锚点**：实战共识
