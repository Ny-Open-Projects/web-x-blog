## 记忆 · MaaS（服务）

- **事实**：记忆即服务（Memory as a Service）：记忆能力服务化（统一 API 多 Agent 共享），服务化让记忆能力复用（AD-101 平台的记忆面）
- **原理**：记忆服务化（AD-353 外部记忆的平台化），统一 API 让 Agent 免各自实现，与平台化（AD-102）联动
- **常见误区**：
  1. 记忆各自实现即可（错）
  2. 服务化是过度设计（错）
  3. 复用无价值（错）
- **工程用法**：记忆服务化
- **版本锚点**：实战共识
