## 多Agent · 协议（通信）

- **事实**：Agent 间通信协议：消息结构（任务/结果/状态）标准化，跨 Agent 通信可追溯（JA-674 观测前提）
- **原理**：协议化让多 Agent 系统可维护（消息即契约），自然语言通信不可靠（结构化优先），与 MCP/A2A 协议（JA-567）趋势联动
- **常见误区**：
  1. Agent 间自然语言随意聊（错）
  2. 协议化是过度设计（错）
  3. 通信与观测无关（错）
- **工程用法**：通信协议设计
- **版本锚点**：实战共识
