## 工具 · 设计（SDK）

- **事实**：工具 SDK 设计：工具开发 SDK（基类+注解+测试工具 AD-237），SDK 让工具开发标准化（三件套开箱），与开发者体验联动
- **原理**：工具 SDK 的设计（JA-684 的开发体验面），SDK 降低工具开发门槛（JA-654 自助化），与开发者体验知识联动
- **常见误区**：
  1. 工具开发无 SDK（错）
  2. SDK 是过度设计（错）
  3. 开发体验不重要（错）
- **工程用法**：工具 SDK
- **版本锚点**：实战共识
