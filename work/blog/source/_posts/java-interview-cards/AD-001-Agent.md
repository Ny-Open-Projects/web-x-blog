## 架构 · Agent（定义）

- **事实**：Agent 的定义：能感知任务、自主决策（规划/反思）、调用工具行动、迭代直到完成目标的系统，与单轮问答的本质区别是"循环与自主决策"
- **原理**：单轮问答一问一答结束，Agent 在循环中自主决定下一步（调工具/继续推理/结束），自主性是定义核心
- **常见误区**：
  1. Agent 就是聊天机器人加皮肤（错）
  2. Agent 必须多 Agent 才算（错）
  3. 自主决策与循环是 Agent 定义核心，缺一不是（错）
- **工程用法**：Agent 定义的答题起点
- **版本锚点**：2025 共识
