## 工程 · 沉淀（知识）

- **事实**：企业 prompt 资产库：领域 prompt 模板库（分类管理/版本/评估数据/负责人），跨业务复用
- **原理**：prompt 从"散落代码"到"资产库"（AI-064 企业版），复用降低重复建设（JA-384 中台价值），与知识管理联动
- **常见误区**：
  1. prompt 资产库无必要（错）
  2. 复用场景不存在（错）
  3. 管理成本大于收益（错）
- **工程用法**：prompt 资产化
- **版本锚点**：实战共识
