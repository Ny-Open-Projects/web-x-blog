## 工程 · 工具面板（观测）

- **事实**：工具调用面板：每工具的调用率/成功率/参数错误率/平均耗时，工具健康度画像（JA-314 的 Agent 侧）
- **原理**：工具是 Agent 的"依赖服务"（JA-014 监控对等），面板定位坏工具（JA-365 badcase 思想），与 JA-357 循环观测联动
- **常见误区**：
  1. 工具不需要独立面板（错）
  2. 调用率是唯一指标（错）
  3. 画像与工具无关（错）
- **工程用法**：工具可观测
- **版本锚点**：实战共识
