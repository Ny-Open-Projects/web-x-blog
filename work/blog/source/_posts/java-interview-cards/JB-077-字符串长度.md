## 语言杂项 · 字符串长度（性能）

- **事实**：String.length() 返回的是 UTF-16 代码单元数而非字符数：增补字符（如 emoji）占 2 个代码单元。
- **原理**：JDK9 前 String 底层是 char[]（UTF-16），JDK9+ byte[]+coder 逻辑上仍是 UTF-16 语义。
- **常见误区**：
  1. String.length() 返回的是"字符个数"对任何字符都成立。（错）
  2. 一个 emoji 的 length() 是 1。（错）
  3. codePointCount 与 length 结果总是相同。（错）
- **工程用法**：涉及 emoji/生僻字的文本处理必须用码点 API（codePointAt 等）。
- **版本锚点**：JDK 9+（Compact Strings JEP 254）
