## 多模态 · 预算（成本）

- **事实**：多模态 Agent 的视觉 token 预算：图像 token 远高于文本（JA-541），预算管理与图像数量/分辨率联动（JA-430）
- **原理**：多模态 Agent 的成本结构（视觉是成本大头），预算联动策略（减图/降分辨率/降采样），与统一预算（JA-663）联动
- **常见误区**：
  1. 视觉成本忽略不计（错）
  2. 预算只管文本（错）
  3. 图像越多越好（错）
- **工程用法**：视觉预算管理
- **版本锚点**：实战共识
