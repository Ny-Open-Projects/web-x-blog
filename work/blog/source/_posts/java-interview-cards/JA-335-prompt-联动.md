## 工程 · prompt 联动（灰度）

- **事实**：prompt 版本与灰度联动：灰度桶绑定 prompt 版本（桶内稳定），版本切换按桶推进
- **原理**：prompt 灰度不是简单百分比（同桶内版本漂移会污染实验数据），与实验单元隔离（JA-271）联动
- **常见误区**：
  1. prompt 版本全量同步切换（错）
  2. 桶与版本无关（错）
  3. 漂移不影响数据（错）
- **工程用法**：灰度-版本矩阵
- **版本锚点**：实战共识
