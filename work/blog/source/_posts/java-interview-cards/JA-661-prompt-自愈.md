## 质量 · prompt 自愈（自愈）

- **事实**：prompt 自愈机制：评估发现的失败样本自动归因（缺失约束/格式漂移），生成候选改写重测，改优后人工确认上线
- **原理**：prompt 迭代的手动瓶颈（JA-442 自动搜索的进阶），自愈是"评估驱动改进"的自动化，人工确认保留兜底
- **常见误区**：
  1. prompt 自愈全自动上线（错）
  2. 自愈不可能实现（错）
  3. 自愈与评估无关（错）
- **工程用法**：prompt 自愈设计
- **版本锚点**：实战共识
