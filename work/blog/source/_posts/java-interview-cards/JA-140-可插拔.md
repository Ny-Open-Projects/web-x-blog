## LangChain4j · 可插拔（HTTP）

- **事实**：LC4j 的 HTTP 客户端层可插拔（JDK HttpClient/OkHttp 等实现模块）
- **原理**：企业网络环境（代理/证书/连接池）按需选 HTTP 层，与网关 base-url（JA-096）配套
- **常见误区**：
  1. HTTP 客户端固定不可换（错）
  2. 必须用 OkHttp（错）
  3. 网络层不可配置（错）
- **工程用法**：企业网络适配
- **版本锚点**：LangChain4j 1.0
