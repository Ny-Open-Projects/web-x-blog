## 工程 · 预算（记忆）

- **事实**：会话记忆的 token 预算：窗口按条数截断是粗粒度，长消息场景需按 token 估算动态裁剪
- **原理**：MessageWindowChatMemory 只看条数不看长度，单条超长消息仍可挤爆窗口预算，精细预算需自定义裁剪
- **常见误区**：
  1. 窗口按条数即按 token（错）
  2. 长消息不影响窗口（错）
  3. 记忆预算无需管理（错）
- **工程用法**：记忆成本治理
- **版本锚点**：实战共识
