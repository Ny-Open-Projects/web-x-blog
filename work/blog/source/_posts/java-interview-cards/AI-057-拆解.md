## Agent · 拆解（规划）

- **事实**：任务规划：复杂任务拆解（计划-执行-验证），计划先行（先产出步骤再逐步执行）降低跑偏
- **原理**：直接执行长任务容易目标漂移（逐步偏移原始目标），plan-and-execute 模式先定计划（可人工审核）再执行，每步对照计划校验，与 ReAct 循环（AI-016）互补
- **常见误区**：
  1. 规划浪费 token（错）
  2. 拆解由用户完成（错）
  3. 计划不需要审核（错）
- **工程用法**：复杂任务可靠性
- **版本锚点**：实战共识
