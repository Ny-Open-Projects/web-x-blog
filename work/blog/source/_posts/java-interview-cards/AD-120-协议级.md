## MCP · 协议级（测试）

- **事实**：MCP server 的协议级 CI 测试：测试客户端走完整协议（握手/发现/调用），断言 schema 与 handler 一致（JA-315 落地）
- **原理**：协议级测试防"注册成功但协议错"（握手失败/发现为空类问题），CI 中协议测试与单元测试并存，与契约测试（JA-282）联动
- **常见误区**：
  1. MCP server 单测足够（错）
  2. 协议测试不必要（错）
  3. schema 漂移自动发现（要主动测）（错）
- **工程用法**：协议级测试
- **版本锚点**：实战共识
