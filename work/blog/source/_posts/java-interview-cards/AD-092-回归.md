## 评测 · 回归（门禁）

- **事实**：Agent 回归门禁：评测套件（JA-680）分数低于基线阻断发布，与 prompt/工具变更触发（JA-415 矩阵）联动
- **原理**：Agent 变更（宪法/工具/模型）的回归保护（JA-525 准入延伸），门禁让 Agent 迭代可控，与评估即代码（JA-665）联动
- **常见误区**：
  1. Agent 变更直接发布（错）
  2. 门禁可选（错）
  3. 基线固定不变（错）
- **工程用法**：Agent 门禁
- **版本锚点**：实战共识
