## 案例 · 辅导（教育）

- **事实**：教育辅导 Agent：苏格拉底式（JA-554）+学生画像（薄弱点记忆 AD-071）+进度追踪，画像用于个性化难度
- **原理**：教育场景的画像价值（因材施教），画像合规（未成年人数据 JA-198 加权），与教育 prompt 约束联动
- **常见误区**：
  1. 教育 Agent 直接给答案（错）
  2. 学生画像无用（错）
  3. 未成年人合规无关（错）
- **工程用法**：教育 Agent 案例
- **版本锚点**：实战共识
