## GC · 虚引用（引用处理）

- **事实**：虚引用对象的回收靠 Reference Handler 线程处理队列
- **原理**：DirectByteBuffer 依赖虚引用触发 Cleaner 释放堆外内存，Reference 处理慢或 System.gc 被禁会堆积引用拖垮性能
- **常见误区**：
  1. 虚引用 get() 能拿到对象（错）
  2. 虚引用不影响对象回收流程（错）
  3. Reference Queue 由应用线程处理（错）
- **工程用法**：堆外内存释放链路知识
- **版本锚点**：HotSpot
