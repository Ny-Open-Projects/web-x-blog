## 多模态 · 视觉（prompt）

- **事实**：视觉工具的 prompt 设计：图像+明确任务指令（"提取表格数据/描述异常"），视觉任务的输出格式约束（JSON 结构）与文本任务同工程化
- **原理**：JA-542 视觉 prompt 的 Agent 工具化面：视觉工具与文本工具同工程标准（描述/schema/校验），混用导致视觉工具质量低
- **常见误区**：
  1. 视觉工具不需要 prompt 工程（错）
  2. 输出无法结构化（错）
  3. 视觉工具免测试（错）
- **工程用法**：视觉工具工程
- **版本锚点**：实战共识
