## MCP · 与网关关系（定位）

- **事实**：MCP 与 API 网关的关系：MCP 是工具协议不是流量网关，企业内两者共存（网管南北向流量、MCP 管 Agent 工具接入）
- **原理**：定位混淆会导致重复建设，MCP 解决"AI 工具生态接入"，网关解决"HTTP 流量治理"
- **常见误区**：
  1. MCP 替代 API 网关（错）
  2. 两者是竞争关系（错）
  3. 工具接入走普通网关即可（错）
- **工程用法**：架构定位澄清
- **版本锚点**：实战共识
