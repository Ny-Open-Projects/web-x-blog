## 工程 · 版本对齐（运维）

- **事实**：框架版本与模型能力对齐：新模型新参数（如 reasoning/结构化模式）需要框架版本支持
- **原理**：供应商新能力滞后于 API 发布（框架适配周期），升级框架才能用新参数，与 JA-175 锁版纪律平衡
- **常见误区**：
  1. 框架与模型能力无关（错）
  2. 新参数随时可用（错）
  3. 锁版与新能力无冲突（错）
- **工程用法**：版本-能力矩阵
- **版本锚点**：实战共识
