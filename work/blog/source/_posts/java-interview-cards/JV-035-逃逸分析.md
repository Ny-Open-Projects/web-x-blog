## JIT · 逃逸分析（逃逸分析）

- **事实**：JIT 逃逸分析可做标量替换让对象分配彻底消失
- **原理**：对象不逃逸出方法/线程时拆成标量放在栈上或寄存器，本项目实测：仅局部引用的对象循环分配 GC 次数为零，逃逸写 static 字段后立即触发 GC
- **常见误区**：
  1. Java 对象总在堆上分配（错）
  2. 逃逸分析把对象放到堆的更快区域（错）
  3. 标量替换就是把对象搬到栈上字面复制（错）
- **工程用法**：验证方法：分配循环+static 逃逸字段对比 GC 次数
- **版本锚点**：HotSpot 实测
