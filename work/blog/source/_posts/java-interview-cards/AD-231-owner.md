## 治理 · owner（清单）

- **事实**：Agent 清单与 Owner 制：每个生产 Agent 登记（用途/权限/Owner/评测基线），无 Owner 的 Agent 下线
- **原理**：JA-596 Owner 思想的 Agent 版：Agent 数量增长后治理需要清单（盲区即风险），清单与依赖管理（JA-721）联动
- **常见误区**：
  1. Agent 清单无必要（错）
  2. Owner 是形式主义（错）
  3. 清单不影响治理（错）
- **工程用法**：Agent 清单制
- **版本锚点**：实战共识
