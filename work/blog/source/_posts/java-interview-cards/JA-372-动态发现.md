## Agent · 动态发现（工具）

- **事实**：动态工具发现：Agent 启动/任务开始时经 MCP listTools 发现可用工具集（工具清单随生态变化）
- **原理**：JA-094 通知与 Agent 的结合：工具集不是编译期固定，运行期注入扩展能力，安全边界靠白名单（JA-152）
- **常见误区**：
  1. Agent 工具编译期固定（错）
  2. 动态发现天然安全（错）
  3. 发现不需要校验（错）
- **工程用法**：动态 Agent 能力
- **版本锚点**：实战共识
