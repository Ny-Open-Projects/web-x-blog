## 索引 · 通配符（失效）

- **事实**：前导通配符 like '%xx' 无法走 B+ 树（后缀 like 'xx%' 可以）
- **原理**：B+ 树按前缀有序，% 开头破坏前缀定位，全文搜索需求交给 ES
- **常见误区**：
  1. like '%x%' 能走索引（错）
  2. 通配符在尾部也失效（错）
  3. like 失效是语法错误（错）
- **工程用法**：搜索类需求选型 ES 而非 like
- **版本锚点**：实战共识
