## 场景 · 消息灰度（灰度）

- **事实**：消息灰度：按灰度标记路由到灰度 topic/消费组（染色），新消费逻辑灰度验证
- **原理**：全链路灰度在 MQ 层的落地：生产染色（header 标记）→路由隔离→消费隔离，与 HTTP 灰度同构，是 P10 全链路压测知识的一部分
- **常见误区**：
  1. 灰度只影响 HTTP 不影响 MQ（错）
  2. 灰度消息混跑无风险（错）
  3. 灰度路由是客户端配置（错）
- **工程用法**：全链路灰度方案
- **版本锚点**：实战方法论
