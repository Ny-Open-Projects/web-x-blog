## 缓存 · 雪崩（雪崩）

- **事实**：缓存雪崩：大量 key 同时过期或 Redis 宕机，流量全打到库
- **原理**：方案：TTL 加随机抖动、多级缓存（本地+Redis）、集群高可用、限流降级兜底
- **常见误区**：
  1. 雪崩只发生在 Redis 宕机时（错）
  2. TTL 一致便于管理（错）
  3. 雪崩无解只能听天由命（错）
- **工程用法**：缓存三大问题之三
- **版本锚点**：实战共识
