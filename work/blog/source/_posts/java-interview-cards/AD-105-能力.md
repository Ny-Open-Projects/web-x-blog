## 工程 · 能力（开关）

- **事实**：Agent 能力运行时开关：单个工具/能力运行时禁用（故障隔离），开关粒度到工具级
- **原理**：工具级开关是降级的细粒度（JA-053 降级链的工具面），坏工具摘除不影响 Agent 整体，与特性开关（JA-205）联动
- **常见误区**：
  1. 工具开关是启动期配置（错）
  2. 运行时禁用不存在（错）
  3. 开关粒度到 Agent 级（太粗）（错）
- **工程用法**：工具级开关
- **版本锚点**：实战共识
