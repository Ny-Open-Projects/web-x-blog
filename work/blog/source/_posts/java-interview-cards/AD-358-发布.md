## 工具 · 发布（灰度）

- **事实**：工具灰度发布：新版本工具先灰度（部分 Agent 实例），评测回归通过再全量（与 Agent 灰度 AD-206 同机制）
- **原理**：工具发布的灰度面（工具是 Agent 依赖 JA-083），灰度发现工具问题不扩散，与发布纪律联动
- **常见误区**：
  1. 工具发布直接全量（错）
  2. 灰度不必要（错）
  3. 发布无回归（错）
- **工程用法**：工具灰度
- **版本锚点**：实战共识
