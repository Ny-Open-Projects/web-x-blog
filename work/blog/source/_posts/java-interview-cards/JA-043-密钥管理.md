## 工程 · 密钥管理（安全）

- **事实**：API key 管理：环境变量或配置中心注入，严禁提交仓库与打进镜像
- **原理**：key 泄漏即计费风险与数据风险，Spring 的属性覆盖机制天然支持环境变量注入，与配置外部化知识（SP-087）联动
- **常见误区**：
  1. key 放代码注释里最方便（错）
  2. 镜像里内置 key 无风险（错）
  3. key 可以明文进日志（错）
- **工程用法**：安全基线
- **版本锚点**：实战共识
