## 协作 · 分工（组织）

- **事实**：多 Agent 的组织分工：每个 Agent 有 Owner 团队（JA-596），跨团队 Agent 协作的接口协议（AD-032）与治理（AD-159）
- **原理**：组织分工与 Agent 拆分对应（康威定律 JA-084），跨团队协作的界面清晰（协议+治理），与组织协作（JA-408）联动
- **常见误区**：
  1. Agent 由一个团队全管（错）
  2. 组织分工不需要（错）
  3. 跨团队协作罕见（多团队是常态）（错）
- **工程用法**：组织分工
- **版本锚点**：实战共识
