## 索引 · 覆盖索引（覆盖）

- **事实**：查询所需列全部在索引中则免回表称为覆盖索引
- **原理**：explain Extra 出现 Using index 即覆盖，count 查询、联合索引带排序列是经典覆盖场景
- **常见误区**：
  1. 覆盖索引是一种索引类型（错）
  2. 覆盖索引免回表是错误的说法（错）
  3. Using index 表示用了主键（错）
- **工程用法**：高频查询设计成覆盖索引
- **版本锚点**：explain 解读
