## 运维 · 调优（GC）

- **事实**：Kafka broker JVM 调优：堆 6GB 内（靠页缓存不靠堆）、G1/ZGC、避免大对象
- **原理**：Kafka 内存策略：页缓存为主 JVM 堆小（6G），频繁 Full GC 触发 ISR 抖动（心跳超时），版本升级（4.0 起官方推荐 ZGC）
- **常见误区**：
  1. 堆越大越好（错）
  2. Kafka 无 GC 压力（错）
  3. Full GC 与 ISR 无关（错）
- **工程用法**：JVM 与 MQ 联动知识
- **版本锚点**：实战共识
