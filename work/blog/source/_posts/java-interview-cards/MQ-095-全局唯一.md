## 设计 · 全局唯一（消息 ID）

- **事实**：消息 ID 全局唯一且进日志（消息体+业务键），生产端记录"发送 ID 清单"支撑对账
- **原理**：ID 用于幂等去重、轨迹串联与对账比对（生产条数 vs 消费条数），ID 生成用雪花或 MQ 自带 messageId（RocketMQ 自带唯一），不生成则丢失排查无从下手
- **常见误区**：
  1. messageId 由消费方生成（错）
  2. ID 不需要进业务日志（错）
  3. 对账不需要消息 ID（错）
- **工程用法**：可观测性设计规范
- **版本锚点**：实战共识
