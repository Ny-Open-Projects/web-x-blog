## Agent · 评审清单（工具）

- **事实**：Agent 工具评审四查：描述质量（JA-108）/幂等性（JA-218）/超时设置（JA-275）/权限边界（JA-235），新工具上线四项全过
- **原理**：工具上线的质量门（工具是 Agent 的"API"），四查清单化（与 MY-110 检查单同构），清单进 review 模板
- **常见误区**：
  1. 工具上线即用不评审（错）
  2. 四查是形式主义（错）
  3. 清单与工具无关（错）
- **工程用法**：工具质量门
- **版本锚点**：实战共识
