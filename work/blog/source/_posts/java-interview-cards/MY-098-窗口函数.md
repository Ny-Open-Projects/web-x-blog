## SQL · 窗口函数（窗口）

- **事实**：窗口函数 over(partition by ... order by ...) 做分组内排名/累计/同比不减少行数
- **原理**：与 group by 的区别（不聚合行数），row_number/rank/dense_rank 排名差异（并列处理），lag/lead 取前后行
- **常见误区**：
  1. 窗口函数会合并行（错）
  2. rank 与 row_number 完全相同（错）
  3. 窗口函数不能用于 where（窗口在 where 之后执行，需要套子查询）（错）
- **工程用法**：复杂报表 SQL 标配
- **版本锚点**：MySQL 8.0
