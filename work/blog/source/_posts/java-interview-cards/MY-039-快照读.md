## 事务 · 快照读（读）

- **事实**：普通 select 是快照读（MVCC 无锁），select ... for update/lock in share mode 与 update/delete 是当前读
- **原理**：当前读必须读最新已提交版本并加锁，快照读读 ReadView 视图版本，两者并存是幻读讨论的基础
- **常见误区**：
  1. select 默认是当前读（错）
  2. 当前读不加锁（错）
  3. for update 是快照读（错）
- **工程用法**：区分两类读是理解幻读的前提
- **版本锚点**：InnoDB 文档
