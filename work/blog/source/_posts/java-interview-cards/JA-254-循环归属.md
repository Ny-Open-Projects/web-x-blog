## Agent · 循环归属（边界）

- **事实**：Java 框架的 Agent 边界：框架管"模型↔工具"执行循环（JA-053），任务规划/多 Agent 编排/长状态需自建
- **原理**：判断标准：单工具循环内框架够用，跨任务状态与多 Agent 协作进入自建区（LangGraph 类编排），诚实划界
- **常见误区**：
  1. 框架能做全部 Agent（错）
  2. 循环都要手写（错）
  3. 框架循环与自建无区别（错）
- **工程用法**：Agent 架构划界
- **版本锚点**：实战共识
