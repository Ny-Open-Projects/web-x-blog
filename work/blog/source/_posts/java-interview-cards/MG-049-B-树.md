## 索引 · B 树（底层）

- **事实**：MongoDB 索引底层 B 树（与 MySQL B+ 树不同：非叶节点也存数据指针）
- **原理**：WiredTiger B 树叶子与非叶都含键，范围扫描仍高效，与 MySQL B+ 树差异是常见考点
- **常见误区**：
  1. MongoDB 用 B+ 树（错）
  2. 索引结构与 MySQL 完全相同（错）
  3. B 树不支持范围查询（错）
- **工程用法**：存储结构对比题
- **版本锚点**：官方文档
