## 安全 · 管理（密钥）

- **事实**：Agent 密钥管理：模型 key/工具 API key 的集中管理（密钥服务/配置中心加密），轮换机制（定期+泄漏应急），密钥不入代码与日志（JA-043）
- **原理**：密钥管理的集中化（分散配置密钥是泄漏面），轮换演练（泄漏应急 JA-590），与密钥管理知识联动
- **常见误区**：
  1. 密钥放配置文件即可（错）
  2. 轮换不必要（错）
  3. 泄漏应急流程多余（错）
- **工程用法**：密钥管理
- **版本锚点**：实战共识
