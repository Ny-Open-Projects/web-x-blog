## 工程 · README（文档）

- **事实**：AI 功能交付文档：架构图（JA-238 分层）、评估集入口、降级链、成本口径、runbook（故障预案）五件套
- **原理**：AI 功能的交付完整性（不止代码），运维可接手（预案可执行），与交付文档纪律联动
- **常见误区**：
  1. AI 功能不需要专项文档（错）
  2. 文档与代码同步可选（错）
  3. 五件套是形式主义（错）
- **工程用法**：交付完整性
- **版本锚点**：实战方法论
