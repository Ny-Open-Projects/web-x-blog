## 工程 · 幂等（接口）

- **事实**：AI 接口幂等键设计：客户端传 Idempotency-Key（DF-104），服务端缓存响应供重放（计费不重复）
- **原理**：生成类接口幂等（JA-056 延伸到对外 API），重放返回同答案（成本保护），与 REST 设计规范联动
- **常见误区**：
  1. AI 接口天然幂等（错）
  2. 幂等键是可选装饰（错）
  3. 重放要重新计费（错）
- **工程用法**：对外 API 设计
- **版本锚点**：实战共识
