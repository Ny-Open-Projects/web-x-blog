## Agent · 套件（评测）

- **事实**：Agent 评测回归套件组织：按任务类型分套件（工单套件/报告套件），工具 mock 剧本随套件，回归按变更影响跑对应套件
- **原理**：Agent 评测的组织（JA-212/680 深化）：套件化让回归可选择性执行（CI 成本控制），与回归包（JA-407）联动
- **常见误区**：
  1. Agent 评测一个套件全跑（错）
  2. 套件划分无意义（错）
  3. mock 剧本无价值（错）
- **工程用法**：评测套件化
- **版本锚点**：实战共识
