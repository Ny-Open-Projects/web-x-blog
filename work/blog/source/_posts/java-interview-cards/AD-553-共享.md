## 协作 · 共享（预算）

- **事实**：多 Agent 共享预算管理：系统总预算池按 Agent 分配子池（AD-500 池的多 Agent 版），子池超限不影响他人（隔离），总池告警
- **原理**：共享预算的隔离与总控（隔离防挤占、总控防超支），预算分配按任务价值（JA-417），与预算知识联动
- **常见误区**：
  1. 所有 Agent 共享一个池（错）
  2. 子池隔离不必要（错）
  3. 总池告警可选（错）
- **工程用法**：共享预算管理
- **版本锚点**：实战共识
