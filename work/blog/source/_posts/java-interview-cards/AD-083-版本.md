## Agent · 版本（工具）

- **事实**：工具版本升级对 Agent 行为影响：工具语义变化（参数/返回结构）改变 Agent 行为，工具版本纳入 Agent 版本三元组（AD-059）
- **原理**：工具是 Agent 行为的组成部分（JA-059 三元组），升级工具=潜在行为变更，工具升级走评估回归（JA-680 套件）
- **常见误区**：
  1. 工具升级无行为影响（错）
  2. 版本管理只管 prompt（错）
  3. 工具与 Agent 版本无关（错）
- **工程用法**：工具版本治理
- **版本锚点**：实战共识
