## 工程 · 膨胀（观测）

- **事实**：prompt 长度膨胀监控：prompt 平均长度趋势（需求堆积让 prompt 越来越长），长度警戒线与瘦身触发
- **原理**：JA-062 瘦身的触发机制：长度趋势是"prompt 腐化"信号（每加一条规则），定期瘦身（JA-163 度量闭环），与腐化治理联动
- **常见误区**：
  1. prompt 只加不减是常态（错）
  2. 长度无需监控（错）
  3. 膨胀无风险（错）
- **工程用法**：prompt 腐化治理
- **版本锚点**：实战共识
