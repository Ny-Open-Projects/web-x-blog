## 工程 · 续跑（体验）

- **事实**：断点续跑的产品面：任务中断后用户可见"已完成的步骤/未完成的步骤"，一键续跑（AD-037 checkpoint 的 UX）
- **原理**：checkpoint 的用户价值（JA-037 技术面）：中断不再=重来（体验大升级），续跑 UI 与轨迹展示（JA-219）联动
- **常见误区**：
  1. 中断只能重来（错）
  2. 续跑 UI 无价值（错）
  3. checkpoint 无用户面（错）
- **工程用法**：续跑体验设计
- **版本锚点**：实战共识
