## Agent · 介质（协作）

- **事实**：多 Agent 通信介质选型：进程内队列（同应用）→MQ（跨服务/解耦）→共享状态库（长任务），按耦合度选
- **原理**：AI-049 多 Agent 架构的落地介质，MQ 介质天然获得重试与轨迹（MQ-001 联动），进程内最简
- **常见误区**：
  1. 多 Agent 只能内存通信（错）
  2. 通信介质随意选（错）
  3. MQ 不适合 Agent（错）
- **工程用法**：多 Agent 落地
- **版本锚点**：实战共识
