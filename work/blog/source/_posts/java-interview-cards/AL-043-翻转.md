## 技巧 · 翻转（字符串）

- **事实**：字符串技巧：整体翻转+局部翻转（旋转单词）、双指针原地（Java String 不可变用 char[]）、KMP/暴力匹配
- **原理**：Java String 不可变性（JB-001 联动）必须转 char[] 操作，旋转问题（三次翻转）套路，字符串题注意 Unicode（Java char 是 UTF-16 码元）
- **常见误区**：
  1. Java String 可原地修改（错）
  2. 翻转问题必须用栈（错）
  3. 匹配只有暴力法（错）
- **工程用法**：字符串手写基础
- **版本锚点**：理论共识
