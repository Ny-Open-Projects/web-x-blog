## 评测 · 多Agent（端到端）

- **事实**：多 Agent 系统端到端评测：整链（路由→子 Agent→聚合）的任务成功率与协作效率，端到端与单 Agent 评测互补
- **原理**：多 Agent 的评测单位是"系统"而非单 Agent（JA-258/274 组合行为），端到端评测抓协作问题（单 Agent 评测盲区），与系统测试思想联动
- **常见误区**：
  1. 单 Agent 评测代表系统（错）
  2. 端到端评测不必要（错）
  3. 协作效率无法评测（错）
- **工程用法**：端到端评测
- **版本锚点**：实战共识
