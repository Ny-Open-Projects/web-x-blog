## 多模态 · 截图（工具）

- **事实**：截图理解工具：网页/应用截图→结构化理解（UI 状态/错误信息提取），GUI Agent（JA-433）与运维诊断的基础工具
- **原理**：截图理解是 GUI Agent 的"眼睛"（JA-433 依赖件），截图质量与分辨率影响理解（JA-430 预处理），产出结构化供 Agent 决策
- **常见误区**：
  1. 截图理解不可实现（错）
  2. 截图无需预处理（错）
  3. 产出为自然语言（结构化才可决策）（错）
- **工程用法**：截图工具设计
- **版本锚点**：实战共识
