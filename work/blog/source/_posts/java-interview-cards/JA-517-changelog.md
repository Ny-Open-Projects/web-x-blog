## 工程 · changelog（监控）

- **事实**：供应商 API changelog 订阅与巡检：文档变更/deprecation 公告纳入信息流（JA-391 下线预案的输入）
- **原理**：供应商接口演进监控（AI-066 SDK 联动），静默变更（JA-392）的文档面补充，与变更情报机制联动
- **常见误区**：
  1. 供应商变更会通知到位（错）
  2. changelog 不重要（错）
  3. 巡检文档是浪费（错）
- **工程用法**：变更情报
- **版本锚点**：实战共识
