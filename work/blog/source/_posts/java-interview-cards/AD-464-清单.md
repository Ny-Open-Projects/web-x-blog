## 协作 · 清单（交接）

- **事实**：Agent 任务交接清单：交接时传递（已完成步骤/中间产物/未完成事项/注意点），交接完整性决定接手 Agent 的成败
- **原理**：交接不完整=接手者"失忆重启"（JA-434 会话摘要的 Agent 间版），交接清单模板化，与 checkpoint（AD-037）联动
- **常见误区**：
  1. 交接自动完整（错）
  2. 清单不需要（错）
  3. 中间产物不用传（错）
- **工程用法**：交接清单设计
- **版本锚点**：实战共识
