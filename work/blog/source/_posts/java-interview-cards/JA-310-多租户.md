## MCP · 多租户（生产）

- **事实**：MCP server 多租户隔离：工具执行按调用方身份过滤（鉴权上下文进 server）
- **原理**：共享 server 多业务接入时防越权（JA-235 同思想），身份经传输层传递（HTTP header/stdio 环境变量）
- **常见误区**：
  1. MCP server 天然多租户（错）
  2. 身份识别可选（错）
  3. 隔离靠客户端自觉（错）
- **工程用法**：MCP 租户隔离
- **版本锚点**：MCP 生产化
