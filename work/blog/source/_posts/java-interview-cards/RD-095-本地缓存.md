## 架构 · 本地缓存（多级）

- **事实**：多级缓存架构：Caffeine（本地，微秒）+Redis（集中，毫秒）+DB
- **原理**：本地缓存扛热 key 与 Redis 故障（降级层），一致性问题靠短 TTL（秒级）+变更广播（Pub/Sub 失效本地），读路径优先本地
- **常见误区**：
  1. 本地缓存与 Redis 一致性必须强一致（错）
  2. 本地缓存越大越好（堆内内存与 GC 压力）（错）
  3. 多级缓存是过度设计（错）
- **工程用法**：高性能读架构
- **版本锚点**：实战方法论
