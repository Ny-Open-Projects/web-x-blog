## 工程 · 成本归集（观测）

- **事实**：成本归集实现：观测数据带业务标签（tenant/user），按标签聚合 token 与费用出账单
- **原理**：多业务共享 LLM 网关时按标签分摊成本（AI-051），Micrometer tag 是 Spring AI 观测的落点，财务口径与监控口径一致
- **常见误区**：
  1. 成本无法按业务拆分（错）
  2. 归集靠事后日志手工统计（错）
  3. 标签只有模型名（错）
- **工程用法**：平台化成本治理
- **版本锚点**：实战共识
