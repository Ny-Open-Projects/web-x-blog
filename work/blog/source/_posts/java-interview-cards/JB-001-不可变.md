## String · 不可变（语法语义）

- **事实**：String 是不可变类：内部 value 数组为 final 且不提供修改方法。
- **原理**：不可变保证常量池安全共享、hashCode 可缓存、天然线程安全。
- **常见误区**：
  1. String 提供 setCharAt 方法可以原地修改字符。（错）
  2. String 因为不可变所以性能一定比 StringBuilder 差。（错）
  3. String 的 + 拼接在任何场景都等价于 StringBuilder。（错）
- **工程用法**：防御式编程：对外暴露的字段如果是 String 可免防御性拷贝。
- **版本锚点**：JDK9+ 底层从 char[] 改为 byte[]+coder（Compact Strings）。
