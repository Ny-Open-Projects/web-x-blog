## MCP · 开发流程（server）

- **事实**：MCP server 开发流程（Java）：定义工具 handler（请求→结果）→注册到 McpServer →选择 transport（stdio/SSE）→打包供宿主拉起
- **原理**：流程四步与 JA-023 SDK 对应，每步有独立测试点（handler 单测/注册验证/transport 联调），是 MCP 工具开发的标准路径
- **常见误区**：
  1. MCP server 开发无固定流程（错）
  2. 四步可以乱序（错）
  3. handler 与 transport 耦合（错）
- **工程用法**：开发流程标准
- **版本锚点**：实战共识
