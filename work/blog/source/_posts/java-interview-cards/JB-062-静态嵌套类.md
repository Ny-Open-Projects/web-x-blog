## 内部类 · 静态嵌套类（语法语义）

- **事实**：static 嵌套类不持有外部实例引用，可独立实例化；语义上更接近"把类组织进外部类的命名空间"。
- **原理**：不需要访问外部实例就应声明为 static——Effective Java 相关条目。
- **常见误区**：
  1. 所有嵌套类都持有外部类引用。（错）
  2. static 嵌套类必须依附外部实例才能创建。（错）
  3. static 嵌套类不能访问外部类的 static 字段。（错）
- **工程用法**：集合内的 Builder/Node 类几乎都是 static 嵌套类（如 HashMap.Node）。
- **版本锚点**：JLS 8.1
