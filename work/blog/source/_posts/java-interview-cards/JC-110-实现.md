## 并发容器 · 实现（CopyOnWriteArraySet）

- **事实**：CopyOnWriteArraySet 内部是 CopyOnWriteArrayList 加 contains 去重
- **原理**：contains 是 O(n) 线性扫描，元素多时写与查询都慢，只适合极小且读极多的监听器集合
- **常见误区**：
  1. 它底层是 HashMap（错）
  2. contains 是 O(1)（错）
  3. 适合大集合高频写（错）
- **工程用法**：监听器、观察者集合
- **版本锚点**：JDK 源码
