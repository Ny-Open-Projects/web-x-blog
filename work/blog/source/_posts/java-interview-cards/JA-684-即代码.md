## 网关 · 即代码（配置）

- **事实**：网关配置即代码：路由/配额/降级规则进 Git 版本管理，变更走 PR 评审+自动生效
- **原理**：网关配置治理（JA-652 配置漂移的根治）：配置与代码同纪律，回滚=回 PR，与 IaC 思想联动
- **常见误区**：
  1. 网关配置后台手改（错）
  2. 即代码是过度设计（错）
  3. 配置不需要评审（错）
- **工程用法**：网关配置工程
- **版本锚点**：实战共识
