## 手写 · 资源（清理）

- **事实**：循环外资源清理：HTTP 客户端/线程池/沙箱容器在 Agent 生命周期结束时关闭（finally 或 AutoCloseable），泄漏在长运行服务累积
- **原理**：清理是手写易遗漏点（AD-200 清单），AutoCloseable+try-with-resources 是 Java 惯用法（MY-053 联动），泄漏在 soak（JA-642）暴露
- **常见误区**：
  1. 资源由 GC 处理（错）
  2. 清理可选（错）
  3. finally 与清理无关（错）
- **工程用法**：资源清理
- **版本锚点**：实战共识
