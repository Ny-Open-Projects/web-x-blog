## 手写 · 骨架（代码）

- **事实**：手写 Agent 循环代码骨架：初始化消息→循环{调模型拿响应→解析工具调用→执行→结果作 tool 消息回填→判断终止}→返回
- **原理**：骨架对应生产实现（AD-004），手写版用简化模型调用（接口注入便于测试），与 ExamSolutions 风格一致
- **常见误区**：
  1. 骨架与生产实现无关（错）
  2. 手写版不需要终止判断（错）
  3. 工具分发是伪代码级（真实实现要 schema 解析）（错）
- **工程用法**：手写骨架要点
- **版本锚点**：实战共识
