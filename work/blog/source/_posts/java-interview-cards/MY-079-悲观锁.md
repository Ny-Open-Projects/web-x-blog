## SQL · 悲观锁（锁）

- **事实**：悲观锁 select ... for update 在事务内锁住选中行直到提交
- **原理**：热点行强一致更新（账户余额）、与乐观锁按冲突率选择，for update 必须走索引否则锁范围放大
- **常见误区**：
  1. for update 不需要事务（错）
  2. 它锁到语句执行结束（错）
  3. for update 是表锁（错）
- **工程用法**：支付类场景锁选型
- **版本锚点**：实战共识
