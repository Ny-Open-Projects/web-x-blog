## ID · 对比（选型）

- **事实**：ID 选型：雪花（无依赖高性能，时钟依赖）、号段（DB 依赖，连续可读）、UUID（无序索引差）、业务语义 ID（订单号可读）
- **原理**：按需求：纯性能雪花、可读性业务 ID（日期+机器+序列）、DB 唯一约束场景自增，分库分表场景禁自增（冲突），与分片键设计联动
- **常见误区**：
  1. UUID 适合主键（索引性能差）（错）
  2. 自增 ID 分库没问题（错）
  3. 雪花是唯一方案（错）
- **工程用法**：ID 方案对比题
- **版本锚点**：实战共识
