## 内存 · 总体（结构）

- **事实**：JVM 进程内存 = 堆 + 元空间 + 线程栈合计 + Code Cache + GC 开销 + Direct Memory
- **原理**：容器里按此总账设 limit（如堆 70% 留 30% 给其余），只算堆会撞 cgroup OOMKill，这是容器 OOMKill 的第一根因
- **常见误区**：
  1. 容器 OOMKill 时堆一定也满了（错）
  2. JVM 进程内存约等于堆大小（错）
  3. 元空间占堆内存（错）
- **工程用法**：容器内存规划公式
- **版本锚点**：实战共识
