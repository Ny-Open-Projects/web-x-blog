## 场景 · 工单 Agent（内部）

- **事实**：内部工具 Agent 案例：工单自动分类/转派/回复草稿（工具=工单系统 API），ROI 清晰易落地
- **原理**：Agent 落地从"内部高 ROI 场景"起步（AI-037/027），外部用户场景风险高后上，与 AI-073 落地路径联动
- **常见误区**：
  1. Agent 先上外部场景（错）
  2. 内部场景 ROI 低（错）
  3. 工单场景太简单（错）
- **工程用法**：Agent 落地路径
- **版本锚点**：实战共识
