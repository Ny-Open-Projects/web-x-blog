## 协作 · 总结（权衡）

- **事实**：协作确定性/灵活性权衡总结：结构越强（工作流/主从）确定性越高灵活性越低，开放协作反之，按任务错误代价定（AD-018 的多 Agent 版）
- **原理**：权衡总结是多 Agent 设计的总纲（JA-368 选型的系统面），错误代价高的环节结构化，与权衡知识联动
- **常见误区**：
  1. 结构化与灵活性兼得（错）
  2. 权衡不存在（错）
  3. 按模型能力定（错）
- **工程用法**：权衡总结
- **版本锚点**：实战共识
