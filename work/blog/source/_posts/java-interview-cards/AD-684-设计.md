## 工具 · 设计（API）

- **事实**：工具 API 设计原则：语义清晰（动词+名词）/参数最小化（AD-442）/错误标准化（AD-116）/幂等声明（AD-115），API 设计让工具好用
- **原理**：工具 API 的设计原则（工具=微服务 API 的设计标准），原则让模型与人都好用，与 API 设计联动
- **常见误区**：
  1. 工具 API 随意设计（错）
  2. 原则不必要（错）
  3. 只给模型用不用设计（人也要维护）（错）
- **工程用法**：工具 API 设计
- **版本锚点**：实战共识
