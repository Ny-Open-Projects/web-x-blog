## 工程 · 清单（评审）

- **事实**：Agent 代码 review 清单：宪法含边界与放弃条件/工具幂等与超时/终止三条件/轨迹埋点/脱敏/并发安全六查
- **原理**：AD-200 bug 清单的 review 化（防御式 review），六查对应五 bug+安全，与 review 纪律（JA-285）联动
- **常见误区**：
  1. Agent 代码普通 review（错）
  2. 清单是形式主义（错）
  3. 六查有重叠（互补设计）（错）
- **工程用法**：Agent review 清单
- **版本锚点**：实战共识
