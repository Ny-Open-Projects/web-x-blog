## 手写 · 查询（API）

- **事实**：任务查询接口实现：按 taskId 查状态与轨迹（GET /tasks/{id}），查询是无副作用读（幂等天然），轨迹从存储读取
- **原理**：查询 API 让异步任务（AD-108）可跟踪（用户轮询/推送），接口幂等（JA-467 延伸），与 REST 设计联动
- **常见误区**：
  1. 任务提交后无法查询（错）
  2. 查询接口不需要（错）
  3. 轨迹不对外（错）
- **工程用法**：任务查询 API
- **版本锚点**：实战共识
