## Cluster · 16384（槽位）

- **事实**：Cluster 按 16384 个 slot 分片 key（CRC16(key) mod 16384）
- **原理**：槽位是路由与迁移单位，节点负责槽区间，客户端重定向 MOVED/ASK，16384 是权衡（gossip 心跳包大小）
- **常见误区**：
  1. slot 数量可配置（写死 16384）（错）
  2. CRC16 是为了负载均衡唯一目的（主要是一致性与分布）（错）
  3. slot 与 key 一对一（一个 key 一个 slot 但 key 可 hash tag 多 key）（错）
- **工程用法**：Cluster 基础八股
- **版本锚点**：官方文档
