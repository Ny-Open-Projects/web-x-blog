## 组织 · 团队（角色）

- **事实**：Agent 开发团队角色：Agent 工程师（循环/工具/编排）+评测工程师（任务集/判分）+安全（红线/红队）+领域专家（宪法与验收），四角色协作
- **原理**：JA-408 协作界面在 Agent 域的细化：领域专家写宪法（业务知识），评测保质量，与团队矩阵（JA-342）联动
- **常见误区**：
  1. Agent 开发一个人搞定（错）
  2. 角色是形式主义（错）
  3. 领域专家不参与开发（错）
- **工程用法**：团队角色设计
- **版本锚点**：实战共识
