## 多Agent · 黑板（模式）

- **事实**：黑板模式：多 Agent 读写共享问题空间（黑板），任意 Agent 贡献部分解，适合开放问题
- **原理**：黑板是共享工作区（AD-030）的开放式变体（无预设流程），自由度高但收敛难（需要裁决机制），与主从对比选型
- **常见误区**：
  1. 黑板模式不存在（错）
  2. 黑板适合确定性流程（错）
  3. 收敛不需要机制（错）
- **工程用法**：黑板模式认知
- **版本锚点**：实战共识
