## 演进 · 动态（边界）

- **事实**：Agent 与工作流的边界动态化：流程成熟后 Agent 步骤固化为工作流节点（Agent 探索→固化），反向（新需求 Agent 探索）
- **原理**：JA-479 演进的动态版：成熟路径沉淀为工作流（成本降），边界随成熟度移动，与流程治理联动
- **常见误区**：
  1. 边界静态固定（错）
  2. 固化是倒退（是成熟化）（错）
  3. 动态边界无管理（错）
- **工程用法**：边界动态管理
- **版本锚点**：实战共识
