## 编排 · 水位（资源）

- **事实**：并发 Agent 水位控制：同时运行的 Agent 数上限（模型配额与资源约束），排队调度（JA-109 队列），水位监控
- **原理**：并发 Agent 放大 token 消耗（JA-025），水位超限排队（削峰），与容量规划（JA-535）联动
- **常见误区**：
  1. 并发 Agent 无上限（错）
  2. 水位监控可选（错）
  3. 排队影响体验（比失控好）（错）
- **工程用法**：并发水位
- **版本锚点**：实战共识
