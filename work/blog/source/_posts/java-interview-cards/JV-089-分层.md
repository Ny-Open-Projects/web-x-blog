## 启动 · 分层（优化）

- **事实**：启动速度优化组合：分层编译、AppCDS、减小堆、延迟初始化
- **原理**：C1 快速编译减少解释执行，Spring 的 lazy-init 减少启动期 Bean 创建，GraalVM native image 是极致方案（启动毫秒级但有兼容限制）
- **常见误区**：
  1. 启动速度只能靠加大内存优化（错）
  2. 分层编译会拖慢启动（错）
  3. GraalVM native image 与 Java 完全兼容（错）
- **工程用法**：微服务与 FaaS 启动优化清单
- **版本锚点**：实战方法论
