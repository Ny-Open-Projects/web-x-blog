## 案例 · Agent（研发）

- **事实**：研发 Agent：代码评审（diff→评审意见）/测试生成（代码→测试用例）/文档生成，工具=代码库与 CI，产物是"建议"（人合并）
- **原理**：研发场景天然安全（产物是建议非直接修改 JA-478），评审 Agent 提效显著（低风险高频），与 AI-036 代码生成联动
- **常见误区**：
  1. 研发 Agent 直接改主干（错）
  2. 产物无需人审（错）
  3. 研发场景不适合 Agent（错）
