## 工程 · 部署（多区域）

- **事实**：Agent 多区域部署：无状态编排层多区域+数据层（记忆/向量）区域化（JA-596 数据驻留），跨区域调用延迟权衡（JA-096）
- **原理**：多区域部署的 Agent 面（JA-598 的 Agent 层），编排无状态易多活（JA-649），数据驻留约束区域，与多活知识联动
- **常见误区**：
  1. Agent 单区域部署（错）
  2. 多区域无必要（错）
  3. 数据层全球共享（错）
- **工程用法**：多区域部署
- **版本锚点**：实战共识
