## 规划 · 两种模式（对比）

- **事实**：plan-and-execute 与 ReAct 对比：前者先全量规划后执行（确定性强），后者边想边做（灵活），按任务可预测性选
- **原理**：可预测任务（步骤固定）用 plan-and-execute（可审计），探索性任务用 ReAct，与工作流（JA-368）三分
- **常见误区**：
  1. 两种模式无区别（错）
  2. ReAct 永远更优（错）
  3. 可预测任务也用 ReAct（错）
- **工程用法**：规划模式选型
- **版本锚点**：实战共识
