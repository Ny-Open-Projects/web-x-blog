## String · 安全共享（线程）

- **事实**：String 作为字段在多线程间共享无需同步：不可变对象天然线程安全且可安全发布。
- **原理**：final 字段 + 不可变语义获得 JMM 安全发布保证。
- **常见误区**：
  1. String 共享需要 volatile 修饰才可见。（错）
  2. String 赋值存在竞态条件。（错）
  3. String 拼接在多线程下会损坏数据。（错）
- **工程用法**：不可变对象是并发设计的默认选择（JCiP 原则）。
- **版本锚点**：JLS 17.5（不可变）
