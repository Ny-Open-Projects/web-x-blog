## MCP · 子进程（生命周期）

- **事实**：stdio 型 MCP server 由宿主客户端以子进程拉起（stdin/stdout 通信，生命周期随客户端）
- **原理**：本地工具 server 随客户端启停（IDE/桌面端管理），server 崩溃即工具不可用，重连策略归客户端
- **常见误区**：
  1. stdio server 独立常驻（错）
  2. 生命周期由 server 自己管理（错）
  3. 崩溃自动重拉无需处理（错）
- **工程用法**：本地 server 运维
- **版本锚点**：MCP 规范
