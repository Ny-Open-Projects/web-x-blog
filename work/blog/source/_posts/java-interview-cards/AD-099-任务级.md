## 工程 · 任务级（配额）

- **事实**：Agent 任务级配额：单任务 token 预算（AD-500 池）+用户日预算+全局预算三级，超限优雅终止（汇报进度）
- **原理**：三级配额防失控（JA-461 三维的 Agent 面），超限终止要设计（JA-005 收尾），与成本熔断（JA-279）联动
- **常见误区**：
  1. Agent 无配额概念（错）
  2. 超限直接报错（优雅收尾才是设计）（错）
  3. 三级是过度设计（错）
- **工程用法**：任务配额体系
- **版本锚点**：实战共识
