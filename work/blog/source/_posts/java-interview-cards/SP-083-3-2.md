## Boot · 3.2（虚拟线程）

- **事实**：Spring Boot 3.2 开 spring.threads.virtual.enabled=true 让 Tomcat/@Async 走虚拟线程
- **原理**：IO 密集服务吞吐显著提升（阻塞时让出载体线程），synchronized pin 载体的问题在 JDK24 修复，代码零改动升级
- **常见误区**：
  1. 虚拟线程改变编程模型需要重写（错）
  2. 开启后 CPU 密集也加速（错）
  3. 虚拟线程与 @Async 不兼容（错）
- **工程用法**：IO 密集服务低成本扩容
- **版本锚点**：Boot 3.2
