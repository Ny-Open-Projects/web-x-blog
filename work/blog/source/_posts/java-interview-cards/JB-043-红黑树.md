## TreeMap · 红黑树（语法语义）

- **事实**：TreeMap 底层是红黑树，按 key 排序（自然序或 Comparator），基本操作 O(log n)。
- **原理**：红黑树通过旋转与染色维持近似平衡。
- **常见误区**：
  1. TreeMap 底层是哈希表。（错）
  2. TreeMap 的基本操作是 O(1)。（错）
  3. TreeMap 不支持排序遍历。（错）
- **工程用法**：需要按 key 范围查询/有序遍历时选 TreeMap。
- **版本锚点**：TreeMap 源码
