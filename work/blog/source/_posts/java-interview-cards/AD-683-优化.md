## 工具 · 优化（成本）

- **事实**：工具成本优化：下游 API 成本（外部 API 计费）的优化（缓存/批处理/降级），工具成本的观测（AD-478）驱动优化

- **常见误区**：
  1. 工具成本不可优化（错）
  2. 优化无数据支撑（错）
  3. 只有模型成本（错）
