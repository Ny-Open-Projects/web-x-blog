## LLM · 幻觉（现象）

- **事实**：幻觉：模型编造不存在的事实（引用/数据/API），源于概率生成而非知识库检索
- **原理**：缓解：RAG（给真实资料）、引用溯源（要求标注来源）、低温、评估集回归，幻觉无法根除只能工程约束，Java 开发者最相关的场景是"AI 生成的 API 不存在"
- **常见误区**：
  1. 幻觉可以完全消除（错）
  2. RAG 后无幻觉（错）
  3. 低温下无幻觉（错）
- **工程用法**：可靠生成的工程约束
- **版本锚点**：实战共识
