## String · UTF16与码点（语法语义）

- **事实**：Java 用 UTF-16 编码字符串：BMP 内字符 1 个 char，增补字符（如 emoji）占 2 个 char（代理对）。
- **原理**：length()/charAt 以代码单元为单位；码点操作用 codePointAt/codePointCount。
- **常见误区**：
  1. length() 对任何字符串都等于"可见字符数"。（错）
  2. emoji 的 length() 是 1。（错）
  3. Java 用 UTF-8 编码字符串内部存储。（错）
- **工程用法**：涉及 emoji 的截断必须按码点边界，否则产生非法字符。
- **版本锚点**：JDK 9+（Compact Strings）
