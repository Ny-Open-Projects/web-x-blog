## 案例 · 导诊（医疗）

- **事实**：医疗导诊 Agent 案例：症状收集（多轮问诊）→科室推荐（知识库）→预约工具（挂号系统），定位“导诊”不“诊断”（边界清晰 JA-045），全程留痕
- **原理**：导诊案例的边界设计（导诊≠诊断的责任链），多轮问诊的上下文管理（AD-014），预约工具强确认（AD-080）
- **常见误区**：
  1. 导诊 Agent 直接诊断（错）
  2. 边界无需声明（错）
  3. 预约自动执行（错）
- **工程用法**：导诊案例
- **版本锚点**：实战共识
