## 工程 · 瘦身度量（提示词）

- **事实**：提示词瘦身的度量闭环：离线评估对比瘦身前后质量（不降质才上线），再观测 token 节省
- **原理**：先度量后上线（AI-077 门禁纪律），瘦身收益（AI-062）必须有对比数据支撑
- **常见误区**：
  1. 瘦身只看 token 省（错）
  2. 质量影响可以忽略（错）
  3. 瘦身后不需要验证（错）
- **工程用法**：优化闭环
- **版本锚点**：实战共识
