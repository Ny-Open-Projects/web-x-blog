## 可靠性 · jitter（退避）—— 7 类问法与标准话术

**Qdistributed-141（概念考察·P1-P3）**
【面试官】请谈谈你对「可靠性」中「jitter」的理解。
【标准回答话术】指数退避+jitter：delay=base×2^n 加随机抖动，避免重试同步扎堆。背后的原理是：无抖动的退避让所有客户端同一时刻重试（thundering herd），AWS SDK 默认 full jitter，jitter 是退避算法的标配。
【评分点】① 准确说出核心机制（jitter）；② 能带出原理层而非背结论。 ③ 版本锚点：AWS 架构博客
