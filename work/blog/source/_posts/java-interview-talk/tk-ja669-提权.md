## Agent · 提权（人审）—— 7 类问法与标准话术

【标准回答话术】Agent 权限提升请求流程：任务需要超出当前授权的工具时，Agent 发起提权请求（人工批准后临时授权）。背后的原理是：JA-679/259 人审的权限面：不是预先给全权限而是按需申请（最小权限动态版 JA-500），请求留痕审计。
