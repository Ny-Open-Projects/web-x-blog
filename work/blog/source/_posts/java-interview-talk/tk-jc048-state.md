## AQS · state（实现）—— 7 类问法与标准话术

**Qconcurrency-330（概念考察·P4-P6）**
【面试官】请谈谈你对「AQS」中「state」的理解。
【标准回答话术】AQS 核心是一个 volatile int state 加 CLH 变体等待队列。背后的原理是：获取失败的线程封装成 Node 入队 park，释放时唤醒队首后继；state 语义由子类定义（重入次数、许可数、闩计数）。
【评分点】① 准确说出核心机制（state）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK 源码
