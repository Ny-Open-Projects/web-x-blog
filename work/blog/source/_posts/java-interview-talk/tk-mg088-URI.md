## Java · URI（连接）—— 7 类问法与标准话术

**Qmongodb-610（概念考察·P1-P3）**
【面试官】请谈谈你对「Java」中「URI」的理解。
【标准回答话术】连接 URI 携带 replicaSet 参数（副本集自动发现与故障切换的前提）。背后的原理是：指定 replicaSet 后驱动自动发现全部成员并在主挂时切换，不指定则只连单个节点（主挂不切换），高可用配置第一参数。
【评分点】① 准确说出核心机制（URI）；② 能带出原理层而非背结论。 ③ 版本锚点：官方文档
