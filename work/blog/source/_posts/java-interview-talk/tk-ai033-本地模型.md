## Java · 本地模型（集成）—— 7 类问法与标准话术

**Qai-225（概念考察·P1-P3）**
【面试官】请谈谈你对「Java」中「本地模型」的理解。
【标准回答话术】本地部署模型：Ollama（易用）/vLLM（高吞吐生产），Java 通过 OpenAI 兼容接口接入。背后的原理是：数据不出域（隐私/合规）场景本地部署，Ollama 开发体验好（一行拉模型），vLLM 生产吞吐高（PagedAttention），硬件要求（显存）是门槛。
【评分点】① 准确说出核心机制（本地模型）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
