## 并发容器 · 读无锁（CHM）—— 7 类问法与标准话术

**Qconcurrency-421（概念考察·P1-P3）**
【面试官】请谈谈你对「并发容器」中「读无锁」的理解。
【标准回答话术】CHM 的 get 完全不加锁。背后的原理是：Node 的 val 与 next 用 volatile 保证可见，读路径无锁无 CAS 是 CHM 读性能高的根源。
【评分点】① 准确说出核心机制（读无锁）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK8 源码

**Qconcurrency-424（工程落地·P7-P9）**
