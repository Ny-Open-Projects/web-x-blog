## 手写 · 校验（格式）—— 7 类问法与标准话术

**Qagent-dev-2556（概念考察·P1-P3）**
【面试官】请谈谈你对「协作」中「分工」的理解。
【标准回答话术】多 Agent 的组织分工：每个 Agent 有 Owner 团队（JA-596），跨团队 Agent 协作的接口协议（AD-032）与治理（AD-159）。背后的原理是：组织分工与 Agent 拆分对应（康威定律 JA-084），跨团队协作的界面清晰（协议+治理），与组织协作（JA-408）联动。
【评分点】① 准确说出核心机制（分工）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
