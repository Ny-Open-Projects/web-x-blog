## GC · 引用处理（清理）—— 7 类问法与标准话术

**Qjvm-666（概念考察·P1-P3）**
【面试官】请谈谈你对「GC」中「引用处理」的理解。
【标准回答话术】处理 Reference（软/弱/虚）本身在 GC 的 STW 或并发阶段执行。背后的原理是：大量 Reference 对象（如海量 WeakReference 缓存）会拉长引用处理阶段，软引用缓存泛滥是老年代暴涨经典案例。
【评分点】① 准确说出核心机制（引用处理）；② 能带出原理层而非背结论。 ③ 版本锚点：HotSpot
