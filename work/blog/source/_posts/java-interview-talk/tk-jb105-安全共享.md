## String · 安全共享（线程）—— 7 类问法与标准话术

**Qjava-basics-729（概念考察·P1-P3）**
【面试官】请谈谈你对「String」中「安全共享」的理解。
【标准回答话术】String 作为字段在多线程间共享无需同步：不可变对象天然线程安全且可安全发布。背后的原理是：final 字段 + 不可变语义获得 JMM 安全发布保证。
【评分点】① 准确说出核心机制（安全共享）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 17.5（不可变）
