## 聚合 · $lookup（性能）—— 7 类问法与标准话术

**Qmongodb-253（概念考察·P6-P8）**
【面试官】请谈谈你对「聚合」中「$lookup」的理解。
【标准回答话术】$lookup（关联查询）是性能黑洞能冗余就冗余。背后的原理是：跨集合关联相当于 SQL JOIN 但无索引优化时全扫，建模时冗余热点字段（如类目名进商品文档）避免 lookup。
