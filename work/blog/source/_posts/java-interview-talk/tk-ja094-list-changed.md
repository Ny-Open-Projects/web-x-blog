## MCP · list_changed（通知）—— 7 类问法与标准话术

**Qjava-ai-652（概念考察·P1-P3）**
【面试官】请谈谈你对「MCP」中「list_changed」的理解。
【标准回答话术】MCP 服务端工具清单变更时发送通知（tools/list_changed），客户端重新 listTools。背后的原理是：工具热更新协议化（新增工具无需重启客户端），客户端要处理通知刷新缓存，动态工具生态基础。
【评分点】① 准确说出核心机制（list_changed）；② 能带出原理层而非背结论。 ③ 版本锚点：MCP 规范
