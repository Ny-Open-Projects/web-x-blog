## 压测 · 影子库（全链路）—— 7 类问法与标准话术

**Qdistributed-358（概念考察·P1-P3）**
【面试官】请谈谈你对「压测」中「影子库」的理解。
【标准回答话术】全链路压测：流量染色+影子库/影子表（压测数据隔离）+旁路验证（DB 写隔离）。背后的原理是：压测数据写真实库会污染生产，影子表（同库不同表）或影子库（独立实例）承接压测写，读流量正常回源，大促前容量验证必备。
【评分点】① 准确说出核心机制（影子库）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
