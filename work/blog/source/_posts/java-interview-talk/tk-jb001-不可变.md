## String · 不可变（语法语义）—— 7 类问法与标准话术

**Qjava-basics-1（概念考察·P4-P6）**
【面试官】请谈谈你对「String」中「不可变」的理解。
【标准回答话术】String 是不可变类：内部 value 数组为 final 且不提供修改方法。背后的原理是：不可变保证常量池安全共享、hashCode 可缓存、天然线程安全。
【评分点】① 准确说出核心机制（不可变）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK9+ 底层从 char[] 改为 byte[]+coder（Compact Strings）。
