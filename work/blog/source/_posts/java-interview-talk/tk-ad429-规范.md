## 治理 · 规范（协作）—— 7 类问法与标准话术

**Qagent-dev-2997（概念考察·P1-P3）**
【面试官】请谈谈你对「工具」中「协议」的理解。
【标准回答话术】工具发现协议标准化：发现接口统一（list/describe），客户端与实现解耦（MCP 生态的标准化思想）。背后的原理是：发现协议统一让工具生态互通（JA-024 协议思想），自定义发现=生态孤岛，与 MCP 发现（AD-088）联动。
【评分点】① 准确说出核心机制（协议）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
