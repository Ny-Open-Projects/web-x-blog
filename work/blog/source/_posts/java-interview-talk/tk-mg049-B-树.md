## 索引 · B 树（底层）—— 7 类问法与标准话术

**Qmongodb-337（概念考察·P1-P3）**
【面试官】请谈谈你对「索引」中「B 树」的理解。
【标准回答话术】MongoDB 索引底层 B 树（与 MySQL B+ 树不同：非叶节点也存数据指针）。背后的原理是：WiredTiger B 树叶子与非叶都含键，范围扫描仍高效，与 MySQL B+ 树差异是常见考点。
【评分点】① 准确说出核心机制（B 树）；② 能带出原理层而非背结论。 ③ 版本锚点：官方文档
