## 参数 · buffer pool（buffer pool）—— 7 类问法与标准话术

**Qmysql-470（概念考察·P1-P3）**
【面试官】请谈谈你对「参数」中「buffer pool」的理解。
【标准回答话术】innodb_buffer_pool_size 是最关键参数：专用数据库服务器设物理内存 50%-75%。背后的原理是：缓存数据页与索引页，命中率（InnoDB buffer pool hit rate）99%+ 为健康，改大小需重启（8.0 支持在线动态调整）。
【评分点】① 准确说出核心机制（buffer pool）；② 能带出原理层而非背结论。 ③ 版本锚点：InnoDB 文档
