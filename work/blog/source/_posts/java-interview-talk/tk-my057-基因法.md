## 分库分表 · 基因法（分片键）—— 7 类问法与标准话术

**Qmysql-393（概念考察·P1-P3）**
【面试官】请谈谈你对「分库分表」中「基因法」的理解。
【标准回答话术】分片键选择与基因法：订单号嵌入用户 ID 基因，使订单表与用户表同路由。背后的原理是：同一用户数据落同一分片免跨片 join，订单查询按订单号（带基因）与按用户（同基因）都单分片命中，是电商通用手法。
【评分点】① 准确说出核心机制（基因法）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
