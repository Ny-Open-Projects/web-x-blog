## LangChain4j · 可插拔（HTTP）—— 7 类问法与标准话术

**Qjava-ai-904（概念考察·P1-P3）**
【面试官】请谈谈你对「LangChain4j」中「可插拔」的理解。
【标准回答话术】LC4j 的 HTTP 客户端层可插拔（JDK HttpClient/OkHttp 等实现模块）。背后的原理是：企业网络环境（代理/证书/连接池）按需选 HTTP 层，与网关 base-url（JA-096）配套。
【评分点】① 准确说出核心机制（可插拔）；② 能带出原理层而非背结论。 ③ 版本锚点：LangChain4j 1.0
