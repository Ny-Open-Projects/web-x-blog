## 可靠性 · Idempotency-Key（接口）—— 7 类问法与标准话术

**Qdistributed-722（概念考察·P1-P3）**
【面试官】请谈谈你对「可靠性」中「Idempotency-Key」的理解。
【标准回答话术】HTTP 幂等标准实践：客户端生成 Idempotency-Key 头，服务端存储首响应供重放返回。背后的原理是：Stripe 式设计：首次处理并缓存响应，同 key 重放返回缓存结果（不重复执行），key 过期回收，支付/订单类 API 的行业标准。
【评分点】① 准确说出核心机制（Idempotency-Key）；② 能带出原理层而非背结论。 ③ 版本锚点：Stripe API 设计
