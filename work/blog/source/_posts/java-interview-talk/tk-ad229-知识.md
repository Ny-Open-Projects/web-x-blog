## 案例 · 知识（企业）—— 7 类问法与标准话术

**Qagent-dev-1597（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「提取」的理解。
【标准回答话术】最终答案提取：终止后从最后 assistant 消息提取文本（或结构化 entity），提取时剥离工具调用残留。背后的原理是：最终提取是 Agent 的“出口”（输出的契约 AD-047），残留工具调用标记会污染输出，与输出结构化联动。
【评分点】① 准确说出核心机制（提取）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
