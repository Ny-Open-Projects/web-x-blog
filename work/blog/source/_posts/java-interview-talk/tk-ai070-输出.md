## 应用 · 输出（结构化）—— 7 类问法与标准话术

**Qai-484（概念考察·P4-P6）**
【面试官】请谈谈你对「应用」中「输出」的理解。
【标准回答话术】结构化输出：JSON schema 约束（response_format/grammar 约束解码），下游解析稳定。背后的原理是：自然语言输出解析脆弱（格式漂移），schema 约束（供应商支持）+解析容错（重试/修复）双保险，与 function calling 的参数 schema 同机制。
【评分点】① 准确说出核心机制（输出）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
