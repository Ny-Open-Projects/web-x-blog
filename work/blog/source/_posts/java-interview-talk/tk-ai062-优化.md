## 成本 · 优化（token）—— 7 类问法与标准话术

**Qai-428（概念考察·P1-P3）**
【面试官】请谈谈你对「成本」中「优化」的理解。
【标准回答话术】token 成本优化细节：system prompt 精简（长指令压缩为要点）、历史摘要（滚动压缩）、few-shot 精选（2-3 个高质量）、结构化输出（JSON 短于自然语言）。背后的原理是：每 token 都是钱（输入输出同价），prompt 瘦身是零风险优化（先离线评估不降质），缓存 system prompt（供应商 prompt caching 折扣），与 AI-026 四招配合。
【评分点】① 准确说出核心机制（优化）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
