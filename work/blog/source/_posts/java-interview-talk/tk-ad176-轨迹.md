## 安全 · 轨迹（隐私）—— 7 类问法与标准话术

**Qagent-dev-1226（概念考察·P1-P3）**
【面试官】请谈谈你对「协作」中「最小化」的理解。
【标准回答话术】跨 Agent 上下文传递最小化：父传子只传任务必需信息（不传全量历史），最小化防泄露（JA-018 数据最小化的 Agent 面）。背后的原理是：全量传递=泄露面扩大+token 浪费（JA-025），最小化传递是安全与成本双优，与数据最小化（JA-418）联动。
【评分点】① 准确说出核心机制（最小化）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
