## Spring AI · id 来源（会话）—— 7 类问法与标准话术

【面试官】请谈谈你对「Spring AI」中「id 来源」的理解。
【标准回答话术】conversationId 来源三选：前端显式传（会话模型）→后端解析（用户+会话）→默认值（无状态单轮）。背后的原理是：会话标识决定记忆隔离粒度（JA-064），来源不清是串号（JA-097）的根源，接口设计先定 id 语义。
【评分点】① 准确说出核心机制（id 来源）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
