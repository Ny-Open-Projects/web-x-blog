## String · 常量折叠（误用）—— 7 类问法与标准话术

**Qjava-basics-722（概念考察·P6-P8）**
【面试官】请谈谈你对「String」中「常量折叠」的理解。
【标准回答话术】两个编译期常量拼接（final String a="x"; String s=a+"y";）在编译期直接折叠为常量；含变量的拼接只能运行期计算。背后的原理是：常量折叠是编译器优化，变量拼接无法折叠。
【评分点】① 准确说出核心机制（常量折叠）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 15.28

**Qjava-basics-725（工程落地·P7-P9）**
【面试官】在你带过的项目里，「常量折叠」你是怎么用的？踩过什么坑？
【标准回答话术】使用要点：可验证：折叠后的 s == "xy" 为 true（同池引用）。事实依据：两个编译期常量拼接（final String a="x"; String s=a+"y";）在编译期直接折叠为常量；含变量的拼接只能运行期计算。常见误区要规避：任何字符串拼接都会在编译期折叠。
【评分点】① 给出可落地的要点而非概念；② 主动暴露一个真实踩坑并给出规避方案。
