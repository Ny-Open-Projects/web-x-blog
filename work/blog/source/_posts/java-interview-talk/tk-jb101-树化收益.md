## HashMap · 树化收益（性能）—— 7 类问法与标准话术

**Qjava-basics-701（概念考察·P6-P8）**
【面试官】请谈谈你对「HashMap」中「树化收益」的理解。
【标准回答话术】树化把最坏查询从 O(n) 降到 O(log n)，防御 hash 碰撞攻击（恶意构造同 hash key）。背后的原理是：Tomcat 曾因 hash 碰撞 DoS 加固——树化是安全加固不只是性能优化。
【评分点】① 准确说出核心机制（树化收益）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK 8+ 源码
