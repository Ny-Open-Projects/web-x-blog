## 架构 · 本地缓存（多级）—— 7 类问法与标准话术

**Qredis-659（概念考察·P1-P3）**
【面试官】请谈谈你对「架构」中「本地缓存」的理解。
【标准回答话术】多级缓存架构：Caffeine（本地，微秒）+Redis（集中，毫秒）+DB。背后的原理是：本地缓存扛热 key 与 Redis 故障（降级层），一致性问题靠短 TTL（秒级）+变更广播（Pub/Sub 失效本地），读路径优先本地。
【评分点】① 准确说出核心机制（本地缓存）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
