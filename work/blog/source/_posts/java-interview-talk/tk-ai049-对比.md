## Agent · 对比（框架）—— 7 类问法与标准话术

**Qai-337（概念考察·P1-P3）**
【面试官】请谈谈你对「Agent」中「对比」的理解。
【标准回答话术】Agent 框架对比：LangGraph（图编排/状态机）、Spring AI（Java 生态）、Dify/LangFlow（低代码可视化）、自研（可控性最高）。背后的原理是：编排复杂度决定选择：简单工具调用用 SDK 直接写，状态机式多步用 LangGraph，业务人员参与用 Dify，核心生产系统自研+SDK 组合，P10 观点：框架是脚手架不是壁垒。
【评分点】① 准确说出核心机制（对比）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
