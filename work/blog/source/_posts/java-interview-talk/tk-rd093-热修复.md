## 运维 · 热修复（故障）—— 7 类问法与标准话术

**Qredis-645（概念考察·P1-P3）**
【面试官】请谈谈你对「运维」中「热修复」的理解。
【标准回答话术】线上热修复手段：CONFIG SET 动态调参、CLIENT KILL 踢连接、DEBUG SLEEP 禁用。背后的原理是：CONFIG SET 改淘汰策略/超时不用重启，变更后 CONFIG REWRITE 落盘，危险命令 ACL 治理。
【评分点】① 准确说出核心机制（热修复）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
