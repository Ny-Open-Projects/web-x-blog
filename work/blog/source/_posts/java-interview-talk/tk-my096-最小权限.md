## SQL · 最小权限（权限）—— 7 类问法与标准话术

**Qmysql-666（概念考察·P1-P3）**
【面试官】请谈谈你对「SQL」中「最小权限」的理解。
【标准回答话术】账号权限最小化：业务账号只授 DML（无 DDL/无 drop），只读账号专供报表，root 隔离运维。背后的原理是：权限泄漏与误操作是数据事故主源，grant 按 IP 限定来源，审计日志（audit plugin）记录敏感操作。
【评分点】① 准确说出核心机制（最小权限）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
