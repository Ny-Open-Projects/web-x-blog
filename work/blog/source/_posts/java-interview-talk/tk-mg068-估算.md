## 运维 · 估算（容量）—— 7 类问法与标准话术

**Qmongodb-470（概念考察·P1-P3）**
【面试官】请谈谈你对「运维」中「估算」的理解。
【标准回答话术】容量估算：文档数×平均大小×（1+索引开销）×副本数，压缩后（WT）×0.3-0.5。背后的原理是：索引开销 20-50%（按索引数），WiredTiger 压缩 2-5 倍，预估分片时间点（单副本集容量上限），与 Redis 容量估算同方法论。
【评分点】① 准确说出核心机制（估算）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
