## String · intern（内存）—— 7 类问法与标准话术

**Qjava-basics-22（概念考察·P4-P6）**
【面试官】请谈谈你对「String」中「intern」的理解。
【标准回答话术】JDK7+ 的 intern() 对堆中已存在的等值字符串返回其自身引用（不再拷贝到池）。背后的原理是：JDK6 intern 是拷贝进永久代所以返回值不同，JDK7 改为池中保存堆引用。
【评分点】① 准确说出核心机制（intern）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK7+

【评分点】① 快速识别误区不顺着说；② 给出正确的版本锚定表述（JDK7+）。

**Qjava-basics-25（工程落地·P7-P9）**

【标准回答话术】使用要点：海量重复字符串场景 intern 可显著省内存（需评估 GC 压力）。事实依据：JDK7+ 的 intern() 对堆中已存在的等值字符串返回其自身引用（不再拷贝到池）。常见误区要规避：JDK7+ 的 intern() 一定会返回常量池中的新拷贝对象。
【评分点】① 给出可落地的要点而非概念；② 主动暴露一个真实踩坑并给出规避方案。
