## 工程 · 分层（配置）—— 7 类问法与标准话术

**Qagent-dev-1422（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「响应」的理解。
【标准回答话术】模型响应解析实现：响应拆解为"文本部分+工具调用列表"（模型可同时输出），文本与工具调用的分离逻辑。背后的原理是：响应双内容（文本+工具调用）的解析是手写易错点（AD-200 bug 清单），分离正确才能正确回填，与消息模型（AD-188）联动。
【评分点】① 准确说出核心机制（响应）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
