## Spring AI · 客户端属性（MCP）—— 7 类问法与标准话术

**Qjava-ai-1219（概念考察·P1-P3）**
【面试官】请谈谈你对「Spring AI」中「客户端属性」的理解。
【标准回答话术】MCP 客户端经 spring.ai.mcp.client 属性配置（enabled/连接清单等）。背后的原理是：多 MCP server 连接声明式管理，enabled 开关控制整组连接，配置中心可管理。
【评分点】① 准确说出核心机制（客户端属性）；② 能带出原理层而非背结论。 ③ 版本锚点：Spring AI 1.0 GA
