## 架构 · query cache（缓存）—— 7 类问法与标准话术

**Qmysql-582（概念考察·P1-P3）**
【面试官】请谈谈你对「架构」中「query cache」的理解。
【标准回答话术】query cache 在 MySQL 8.0 被移除（命中失效代价大于收益）。背后的原理是：任何表更新使相关缓存全部失效，高更新场景得不偿失，8.0 删除该功能改由应用层 Redis 承担缓存职责。
【评分点】① 准确说出核心机制（query cache）；② 能带出原理层而非背结论。 ③ 版本锚点：MySQL 8.0
