## 语言杂项 · 浮点比较（语法语义）—— 7 类问法与标准话术

**Qjava-basics-435（概念考察·P4-P6）**
【面试官】请谈谈你对「语言杂项」中「浮点比较」的理解。
【标准回答话术】浮点数（float/double）不能直接用 == 比较相等，应使用误差范围或 BigDecimal。背后的原理是：IEEE754 二进制无法精确表示 0.1 等十进制小数。
【评分点】① 准确说出核心机制（浮点比较）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 4.2.3

**Qjava-basics-438（工程落地·P7-P9）**
【面试官】在你带过的项目里，「浮点比较」你是怎么用的？踩过什么坑？
【标准回答话术】使用要点：资金计算用 BigDecimal 或长整型分单位；String 构造 BigDecimal 必用（double 构造有精度坑）。事实依据：浮点数（float/double）不能直接用 == 比较相等，应使用误差范围或 BigDecimal。常见误区要规避：0.1 + 0.2 在 Java 中精确等于 0.3。
【评分点】① 给出可落地的要点而非概念；② 主动暴露一个真实踩坑并给出规避方案。
