## 文档模型 · 集合（概念）—— 7 类问法与标准话术

**Qmongodb-8（概念考察·P1-P3）**
【面试官】请谈谈你对「文档模型」中「集合」的理解。
【标准回答话术】集合（collection）对应关系模型的表但无固定 schema。背后的原理是：同一集合文档结构可以不同，schema 由应用层保证（或 JSON Schema 校验），灵活但也要求自律。
【评分点】① 准确说出核心机制（集合）；② 能带出原理层而非背结论。 ③ 版本锚点：官方文档
