## 线程 · 线程栈（栈内存）—— 7 类问法与标准话术

**Qjvm-491（概念考察·P4-P6）**
【面试官】请谈谈你对「线程」中「线程栈」的理解。
【标准回答话术】每个线程栈预留约 1MB（-Xss），万级线程仅栈就预留 GB 级。背后的原理是：unable to create native thread OOM 常见根因：线程数超系统限制（ulimit）或内存不足，虚拟线程（JDK21）把栈移到堆上解决该问题。
【评分点】① 准确说出核心机制（线程栈）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
