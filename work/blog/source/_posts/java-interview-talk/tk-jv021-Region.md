## 收集器 · Region（G1）—— 7 类问法与标准话术

**Qjvm-141（概念考察·P1-P3）**
【面试官】请谈谈你对「收集器」中「Region」的理解。
【标准回答话术】G1 把堆划分为多个等大 Region 逻辑分代停顿可预测。背后的原理是：Region 大小 1-32MB（2 的幂自动选），Eden/Survivor/Old 是 Region 的角色标记而非物理连续区域，按停顿目标优先回收价值高的 Region（垃圾优先）。
【评分点】① 准确说出核心机制（Region）；② 能带出原理层而非背结论。 ③ 版本锚点：G1 论文
