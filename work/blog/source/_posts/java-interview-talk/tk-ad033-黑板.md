## 多Agent · 黑板（模式）—— 7 类问法与标准话术

**Qagent-dev-225（概念考察·P1-P3）**
【面试官】请谈谈你对「多Agent」中「黑板」的理解。
【标准回答话术】黑板模式：多 Agent 读写共享问题空间（黑板），任意 Agent 贡献部分解，适合开放问题。背后的原理是：黑板是共享工作区（AD-030）的开放式变体（无预设流程），自由度高但收敛难（需要裁决机制），与主从对比选型。
【评分点】① 准确说出核心机制（黑板）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
