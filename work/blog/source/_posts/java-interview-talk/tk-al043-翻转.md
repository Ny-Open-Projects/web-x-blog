## 技巧 · 翻转（字符串）—— 7 类问法与标准话术

**Qalgorithm-295（概念考察·P1-P3）**
【面试官】请谈谈你对「技巧」中「翻转」的理解。
【标准回答话术】字符串技巧：整体翻转+局部翻转（旋转单词）、双指针原地（Java String 不可变用 char[]）、KMP/暴力匹配。背后的原理是：Java String 不可变性（JB-001 联动）必须转 char[] 操作，旋转问题（三次翻转）套路，字符串题注意 Unicode（Java char 是 UTF-16 码元）。
【评分点】① 准确说出核心机制（翻转）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识
