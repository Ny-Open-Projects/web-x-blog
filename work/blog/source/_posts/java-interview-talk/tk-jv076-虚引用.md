## GC · 虚引用（引用处理）—— 7 类问法与标准话术

**Qjvm-526（概念考察·P1-P3）**
【面试官】请谈谈你对「GC」中「虚引用」的理解。
【标准回答话术】虚引用对象的回收靠 Reference Handler 线程处理队列。背后的原理是：DirectByteBuffer 依赖虚引用触发 Cleaner 释放堆外内存，Reference 处理慢或 System.gc 被禁会堆积引用拖垮性能。
【评分点】① 准确说出核心机制（虚引用）；② 能带出原理层而非背结论。 ③ 版本锚点：HotSpot
