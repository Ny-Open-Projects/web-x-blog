## 接口 · default方法（语法语义）—— 7 类问法与标准话术

**Qjava-basics-407（概念考察·P4-P6）**
【面试官】请谈谈你对「接口」中「default方法」的理解。
【标准回答话术】JDK8 起接口可以有 default 方法（有实现体）；实现类初始化时会连带初始化"含 default 方法的"接口。背后的原理是：JLS 12.4.1 规定：类初始化时，声明了 default 方法的父接口会被初始化。
【评分点】① 准确说出核心机制（default方法）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK8+

**Qjava-basics-410（工程落地·P7-P9）**
【面试官】在你带过的项目里，「default方法」你是怎么用的？踩过什么坑？
【标准回答话术】使用要点：本机实测：new Impl() 打印了含 default 的接口 I 的初始化，不含 default 的 I2 未初始化。事实依据：JDK8 起接口可以有 default 方法（有实现体）；实现类初始化时会连带初始化"含 default 方法的"接口。常见误区要规避：接口实现类初始化永远不会触发任何接口的初始化。
【评分点】① 给出可落地的要点而非概念；② 主动暴露一个真实踩坑并给出规避方案。
