## 安全发布 · this 逸出（误用）—— 7 类问法与标准话术

**Qconcurrency-484（概念考察·P6-P8）**
【面试官】请谈谈你对「安全发布」中「this 逸出」的理解。
【标准回答话术】构造器中把 this 交给外部（注册监听器、启动线程）导致未构造完成的对象被并发访问。背后的原理是：发布时 final 字段尚未赋值，其他线程可能读到默认值，修复：构造完成后统一发布或用静态工厂。
【评分点】① 准确说出核心机制（this 逸出）；② 能带出原理层而非背结论。 ③ 版本锚点：JCiP 4.3
