## Java · 会话隔离（并发）—— 7 类问法与标准话术

**Qai-589（概念考察·P1-P3）**
【面试官】请谈谈你对「Java」中「会话隔离」的理解。
【标准回答话术】多用户并发会话隔离：上下文（历史/记忆）按 session key 隔离，禁止共享可变状态。背后的原理是：串用他人上下文是严重事故（隐私+错误回答），实现：会话存储按 sessionId 分区+并发集合，Java 侧用 ThreadLocal 传 session 上下文（与线程池场景 TTL 知识联动）。
【评分点】① 准确说出核心机制（会话隔离）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
