## 安全 · 执行器（注入）—— 7 类问法与标准话术

**Qagent-dev-659（概念考察·P6-P8）**
【面试官】请谈谈你对「案例」中「Agent」的理解。
【标准回答话术】运维 Agent：告警读取→根因初判（查日志/指标工具）→预案执行（重启/扩容需确认）→复盘记录，高危操作强确认。背后的原理是：运维 Agent 是"人审+自动化"典型（AD-080 交易级确认），预案知识库（JA-416 runbook）是 Agent 的大脑辅料，错误操作代价极高。
【评分点】① 准确说出核心机制（Agent）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
