## 运维 · 数据倾斜（倾斜）—— 7 类问法与标准话术

**Qredis-470（概念考察·P1-P3）**
【面试官】请谈谈你对「运维」中「数据倾斜」的理解。
【标准回答话术】Cluster 数据/流量倾斜：bigkey 落单节点、hash tag 聚集、热点 key。背后的原理是：排查 cluster node 各节点内存与 QPS 对比，治理：拆 key、打散 hash tag、本地缓存。
【评分点】① 准确说出核心机制（数据倾斜）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
