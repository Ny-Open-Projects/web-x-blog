## 运维 · 隔离（多实例）—— 7 类问法与标准话术

**Qredis-617（概念考察·P1-P3）**
【面试官】请谈谈你对「运维」中「隔离」的理解。
【标准回答话术】多业务共享 Redis 集群的隔离：按业务分实例/分 slot 段+配额限制。背后的原理是：共享实例互相影响（某业务 bigkey/热 key 拖垮全实例），大业务独立实例，中小业务共享但监控分业务 QPS（ACL+监控打标）。
【评分点】① 准确说出核心机制（隔离）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
