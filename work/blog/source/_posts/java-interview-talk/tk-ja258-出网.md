## 工程 · 出网（网络）—— 7 类问法与标准话术

**Qjava-ai-1800（概念考察·P1-P3）**
【面试官】请谈谈你对「工程」中「出网」的理解。
【标准回答话术】企业出网适配：代理/证书/内网网关三层（HTTP client 层配置），框架可插拔 HTTP 层（JA-140）承接。背后的原理是：企业内网环境是现实约束，网络层问题伪装成"模型不可用"，排障分层（网络→网关→供应商）。
【评分点】① 准确说出核心机制（出网）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
