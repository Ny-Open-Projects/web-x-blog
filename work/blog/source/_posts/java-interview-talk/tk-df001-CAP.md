## 理论 · CAP（CAP）—— 7 类问法与标准话术

**Qdistributed-1（概念考察·P1-P3）**
【面试官】请谈谈你对「理论」中「CAP」的理解。
【标准回答话术】CAP 三选二是分区发生时的选择：CP 保一致牺牲可用、AP 保可用容忍暂时不一致。背后的原理是：网络分区（P）在分布式系统必然发生无法取舍，实际是在 C 与 A 之间权衡（如注册中心选型）。
【评分点】① 准确说出核心机制（CAP）；② 能带出原理层而非背结论。 ③ 版本锚点：理论共识
