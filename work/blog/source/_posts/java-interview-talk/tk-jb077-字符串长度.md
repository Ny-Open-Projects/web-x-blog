## 语言杂项 · 字符串长度（性能）—— 7 类问法与标准话术

**Qjava-basics-533（概念考察·P6-P8）**
【面试官】请谈谈你对「语言杂项」中「字符串长度」的理解。
【标准回答话术】String.length() 返回的是 UTF-16 代码单元数而非字符数：增补字符（如 emoji）占 2 个代码单元。背后的原理是：JDK9 前 String 底层是 char[]（UTF-16），JDK9+ byte[]+coder 逻辑上仍是 UTF-16 语义。
【评分点】① 准确说出核心机制（字符串长度）；② 能带出原理层而非背结论。 ③ 版本锚点：JDK 9+（Compact Strings JEP 254）
