## 多模态 · 统一（预算）—— 7 类问法与标准话术

**Qjava-ai-4565（概念考察·P1-P3）**
【面试官】请谈谈你对「多模态」中「统一」的理解。
【标准回答话术】多模态与文本 token 预算统一管理：图像 token 折算后与文本同池预算（一个请求的总预算视图）。背后的原理是：JA-223 预算分配的多模态版：图像占预算大（JA-541 分块），统一视图才能做取舍（减图 or 减文本）。
【评分点】① 准确说出核心机制（统一）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
