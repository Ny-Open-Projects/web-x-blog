## 消费 · rebalance（再平衡）—— 7 类问法与标准话术

**Qmq-29（概念考察·P1-P3）**
【面试官】请谈谈你对「语义」中「乱序」的理解。
【标准回答话术】乱序处理：按 key 分区路由保序+消费端单线程/串行队列。背后的原理是：跨分区无法保序，消费端并发处理同 key 需按 key 分发到串行队列（内存排队），P10 级别能说出"保序的完整链路"（生产路由+分区+消费串行）。
【评分点】① 准确说出核心机制（乱序）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
