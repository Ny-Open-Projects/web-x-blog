## 事务 · pipeline（对比）—— 7 类问法与标准话术

**Qredis-190（概念考察·P1-P3）**
【面试官】请谈谈你对「事务」中「pipeline」的理解。
【标准回答话术】pipeline 是批量发送减 RTT 不保证原子，事务/Lua 保证原子。背后的原理是：pipeline 一次发 N 条命令收 N 个结果省网络往返，大量写入场景吞吐倍增，事务额外保证串行。
【评分点】① 准确说出核心机制（pipeline）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
