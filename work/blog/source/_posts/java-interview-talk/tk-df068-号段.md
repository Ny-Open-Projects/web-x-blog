## ID · 号段（号段）—— 7 类问法与标准话术

**Qdistributed-470（概念考察·P1-P3）**
【面试官】请谈谈你对「ID」中「号段」的理解。
【标准回答话术】号段模式：DB 批量取号段（如 1-1000）内存分发，双 buffer 预取消抖动。背后的原理是：号段表（biz_tag+max_id+step）乐观锁更新，取号高峰 DB 压力被号段长度摊薄，双 buffer 在用到 10% 时预取下段，美团 Leaf 实现。
【评分点】① 准确说出核心机制（号段）；② 能带出原理层而非背结论。 ③ 版本锚点：美团 Leaf
