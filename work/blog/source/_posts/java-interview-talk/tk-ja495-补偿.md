## Agent · 补偿（失败）—— 7 类问法与标准话术

**Qjava-ai-3459（概念考察·P1-P3）**
【面试官】请谈谈你对「Agent」中「补偿」的理解。
【标准回答话术】Agent 失败补偿：已执行不可逆工具的逆操作补偿（撤销通知/回滚库存预留），补偿链与 SAGA（DF-063）同构。背后的原理是：Agent 是分布式执行的特例（每工具是一笔"事务"），补偿设计让失败可恢复，幂等优先补偿兜底（JA-257）。
【评分点】① 准确说出核心机制（补偿）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
