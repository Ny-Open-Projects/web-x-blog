## Agent · 人工（审批）—— 7 类问法与标准话术

**Qai-470（概念考察·P1-P3）**
【面试官】请谈谈你对「Agent」中「人工」的理解。
【标准回答话术】Human-in-the-loop：高危操作（支付/删除/对外发送）人工审批（Agent 暂停→审批→继续），与 checkpoint（AI-021）配合。背后的原理是：Agent 全自主在真实业务有风险（错误操作不可逆），审批节点（按操作风险分级）+审批 UI+超时策略，是 Agent 生产化的关键机制（全自动是目标渐进式授权）。
【评分点】① 准确说出核心机制（人工）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
