## 顺序 · 锁队列（顺序消费）—— 7 类问法与标准话术

**Qmq-232（概念考察·P1-P3）**
【面试官】请谈谈你对「场景」中「消息灰度」的理解。
【标准回答话术】消息灰度：按灰度标记路由到灰度 topic/消费组（染色），新消费逻辑灰度验证。背后的原理是：全链路灰度在 MQ 层的落地：生产染色（header 标记）→路由隔离→消费隔离，与 HTTP 灰度同构，是 P10 全链路压测知识的一部分。
【评分点】① 准确说出核心机制（消息灰度）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
