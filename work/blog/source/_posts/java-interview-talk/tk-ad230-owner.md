## 治理 · owner（清单）—— 7 类问法与标准话术

**Qagent-dev-1604（概念考察·P1-P3）**
【面试官】请谈谈你对「手写」中「资源」的理解。
【标准回答话术】循环外资源清理：HTTP 客户端/线程池/沙箱容器在 Agent 生命周期结束时关闭（finally 或 AutoCloseable），泄漏在长运行服务累积。背后的原理是：清理是手写易遗漏点（AD-200 清单），AutoCloseable+try-with-resources 是 Java 惯用法（MY-053 联动），泄漏在 soak（JA-642）暴露。
【评分点】① 准确说出核心机制（资源）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
