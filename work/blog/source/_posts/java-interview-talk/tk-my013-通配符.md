## 索引 · 通配符（失效）—— 7 类问法与标准话术

**Qmysql-85（概念考察·P1-P3）**
【面试官】请谈谈你对「索引」中「通配符」的理解。
【标准回答话术】前导通配符 like '%xx' 无法走 B+ 树（后缀 like 'xx%' 可以）。背后的原理是：B+ 树按前缀有序，% 开头破坏前缀定位，全文搜索需求交给 ES。
【评分点】① 准确说出核心机制（通配符）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
