## Spring AI · @Tool（工具）—— 7 类问法与标准话术

**Qjava-ai-57（概念考察·P1-P3）**
【面试官】请谈谈你对「Spring AI」中「@Tool」的理解。
【标准回答话术】Spring AI 用 @Tool 注解声明工具方法，框架自动包装为 ToolCallback。背后的原理是：模型通过 function calling 输出工具调用，框架执行方法并回填结果，业务只写普通 Java 方法。
【评分点】① 准确说出核心机制（@Tool）；② 能带出原理层而非背结论。 ③ 版本锚点：Spring AI 1.0 GA
