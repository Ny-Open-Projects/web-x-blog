## 数据 · 合规（隐私）—— 7 类问法与标准话术

**Qai-274（概念考察·P1-P3）**
【面试官】请谈谈你对「数据」中「合规」的理解。
【标准回答话术】LLM 数据合规：训练数据版权、用户数据脱敏（PII 不入 prompt）、输出合规审查。背后的原理是：调用外部 API 时用户数据出域（隐私风险，脱敏/本地模型），生成内容合规（金融建议/医疗建议免责声明），企业落地的法务前置。
【评分点】① 准确说出核心机制（合规）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
