【标准回答话术】Agent 自我改进循环：失败任务分析→改进宪法/工具描述→评估验证→上线（提示词自愈 JA-661 的 Agent 版），改进有评估兜底。背后的原理是：自改进是 Agent 演进的高级形态（人工改进的自动化），自动化改进有风险（评估兜底是底线），与 DSPy 思想（JA-442）联动。
