## 模型 · prompt（多语言）—— 7 类问法与标准话术

【标准回答话术】prompt 语言与性能：英文 prompt 在多数模型更稳（训练分布），中文 prompt 经测试决定（模型中文能力演进快）。背后的原理是："英文 prompt 更稳"是经验规律而非铁律（JA-216 token 联动），用评估集 A/B 实测决定，与 AI-217 i18n 联动。
【评分点】① 准确说出核心机制（prompt）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
