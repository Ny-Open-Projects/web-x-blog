## 实践 · 治理（慢 SQL）—— 7 类问法与标准话术

**Qmysql-722（概念考察·P1-P3）**
【面试官】请谈谈你对「实践」中「治理」的理解。
【标准回答话术】慢 SQL 治理体系：上线前 SQL 审核（RDM/Inception 类工具）+线上慢日志监控+TopSQL 优化闭环。背后的原理是：事前拦截（索引缺失/全表扫描 SQL 拒绝发布）优于事后救火，DBA 平台自动化审核+治理看板。
【评分点】① 准确说出核心机制（治理）；② 能带出原理层而非背结论。 ③ 版本锚点：实战方法论
