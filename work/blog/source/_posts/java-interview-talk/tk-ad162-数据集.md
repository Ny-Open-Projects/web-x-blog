## 评测 · 数据集（轨迹）—— 7 类问法与标准话术

**Qagent-dev-1128（概念考察·P1-P3）**
【面试官】请谈谈你对「评测」中「与单测」的理解。
【标准回答话术】Agent 评测与单元测试的分层：单测测工具逻辑（mock 模型）/评测测 Agent 行为（真实或 mock 剧本）/线上影子测真实分布，三层不互相替代。背后的原理是：JA-481 金字塔的 Agent 版：三层各回答不同问题（逻辑对/行为对/真实好），混淆层级让测试低效，与测试策略联动。
【评分点】① 准确说出核心机制（与单测）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
