## Object · 虚假唤醒（误用）—— 7 类问法与标准话术

**Qjava-basics-505（概念考察·P6-P8）**
【面试官】请谈谈你对「Object」中「虚假唤醒」的理解。
【标准回答话术】等待条件必须用 while 循环判断而非 if：被唤醒后条件可能已被其他线程改变。背后的原理是：notifyAll 会唤醒所有等待线程，先到者可能改变条件。
【评分点】① 准确说出核心机制（虚假唤醒）；② 能带出原理层而非背结论。 ③ 版本锚点：JLS 17.2.3
