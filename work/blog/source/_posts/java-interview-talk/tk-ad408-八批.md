## 工程 · 八批（收束）—— 7 类问法与标准话术

**Qagent-dev-2850（概念考察·P1-P3）**
【面试官】请谈谈你对「协作」中「结论」的理解。
【标准回答话术】多 Agent 结论冲突解决：两 Agent 结论矛盾时裁决机制（裁判 Agent/多数投票/规则优先级），冲突是常态要设计。背后的原理是：结论冲突是多 Agent 常态（独立视角必然分歧，AD-029 辩论动机），无裁决机制则输出随机，与聚合策略（AD-132）联动。
【评分点】① 准确说出核心机制（结论）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
