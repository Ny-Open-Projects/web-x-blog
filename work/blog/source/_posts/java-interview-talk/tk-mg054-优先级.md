## 副本集 · 优先级（配置）—— 7 类问法与标准话术

**Qmongodb-372（概念考察·P1-P3）**
【面试官】请谈谈你对「副本集」中「优先级」的理解。
【标准回答话术】副本集成员配置：priority（选举权重）、hidden（不可读）、delayed（延迟从库）。背后的原理是：priority 0 节点不主动竞选，hidden 从库专供备份/分析，delayed 从库（延迟 N 秒）防误操作恢复，官方文档核对。
【评分点】① 准确说出核心机制（优先级）；② 能带出原理层而非背结论。 ③ 版本锚点：官方文档核对
