## String · SDS（编码）—— 7 类问法与标准话术

**Qredis-8（概念考察·P1-P3）**
【面试官】请谈谈你对「String」中「SDS」的理解。
【标准回答话术】String 底层是 SDS（简单动态字符串）支持二进制安全与 O(1) 长度。背后的原理是：SDS 记录长度字段与预分配空间，免 strlen 与缓冲区溢出，可存图片等二进制数据。
【评分点】① 准确说出核心机制（SDS）；② 能带出原理层而非背结论。 ③ 版本锚点：SDS 实现
