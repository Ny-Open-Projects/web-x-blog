## Java · 能力（定位）—— 7 类问法与标准话术

**Qai-540（概念考察·P1-P3）**
【面试官】请谈谈你对「Java」中「能力」的理解。
【标准回答话术】Java 工程师 AI 能力定位：应用层（RAG/Agent 工程）、治理层（成本/评估/安全）、平台层（网关/观测），不必深入模型层（训练/算法）。背后的原理是：工程能力迁移是路径（分布式系统的超时/降级/幂等/对账/灰度全部适用于 AI 依赖），与算法岗差异化协作（算法提供模型，工程提供落地），P10 面试的价值主张。
【评分点】① 准确说出核心机制（能力）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
