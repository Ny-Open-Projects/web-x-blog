## 手写 · 执行器（并行）—— 7 类问法与标准话术

**Qagent-dev-2514（概念考察·P8-P10）**
【面试官】请谈谈你对「协作」中「独立」的理解。
【标准回答话术】多 Agent 独立版本管理：每个 Agent 独立版本三元组（AD-059），组合版本（发布快照）记录整体状态。背后的原理是：独立版本+组合快照（发布时全组合可追溯），组合版本让"整体行为"可复现（JA-402 延伸），与版本治理联动。
【评分点】① 准确说出核心机制（独立）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
