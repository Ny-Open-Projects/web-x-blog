## 运维 · 角色（controller）—— 7 类问法与标准话术

**Qmq-372（概念考察·P1-P3）**
【面试官】请谈谈你对「设计」中「全局唯一」的理解。
【标准回答话术】消息 ID 全局唯一且进日志（消息体+业务键），生产端记录"发送 ID 清单"支撑对账。背后的原理是：ID 用于幂等去重、轨迹串联与对账比对（生产条数 vs 消费条数），ID 生成用雪花或 MQ 自带 messageId（RocketMQ 自带唯一），不生成则丢失排查无从下手。
【评分点】① 准确说出核心机制（全局唯一）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
