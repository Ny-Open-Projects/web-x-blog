## Agent · 冲突（并发）—— 7 类问法与标准话术

**Qjava-ai-3445（概念考察·P1-P3）**
【面试官】请谈谈你对「Agent」中「冲突」的理解。
【标准回答话术】多 Agent 并发写冲突：两个 Agent 修改同一资源（库存/工单），锁或幂等或资源级串行化。背后的原理是：多 Agent 并发的正确性（JA-258 并行工具的资源面），与 DB 并发控制思想同构（乐观锁 JA-078 联动）。
【评分点】① 准确说出核心机制（冲突）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
