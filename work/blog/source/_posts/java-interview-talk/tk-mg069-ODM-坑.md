## Java · ODM 坑（ODM）—— 7 类问法与标准话术

**Qmongodb-477（概念考察·P1-P3）**
【面试官】请谈谈你对「Java」中「ODM 坑」的理解。
【标准回答话术】ODM（Spring Data/Mongoose）掩盖文档模型本质，P10 应能脱离 ODM 直谈文档设计。背后的原理是：ODM 的 @Document/@Field 映射隐藏 BSON 结构，复杂聚合仍要原生管道，建模评审用原生文档视角。
【评分点】① 准确说出核心机制（ODM 坑）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
