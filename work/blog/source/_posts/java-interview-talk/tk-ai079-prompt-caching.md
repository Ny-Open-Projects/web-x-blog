## 成本 · prompt caching（缓存）—— 7 类问法与标准话术

**Qai-547（概念考察·P1-P3）**
【面试官】请谈谈你对「成本」中「prompt caching」的理解。
【标准回答话术】供应商 prompt caching：相同前缀（system prompt/few-shot）命中缓存按折扣计费。背后的原理是：system prompt 与 few-shot 每次请求重复且最长，前缀缓存命中可省 50-90% 输入费用，要求前缀稳定（动态内容放后缀）。
【评分点】① 准确说出核心机制（prompt caching）；② 能带出原理层而非背结论。 ③ 版本锚点：2024-2025
