## RPC · 选型（序列化）—— 7 类问法与标准话术

**Qdistributed-302（概念考察·P1-P3）**
【面试官】请谈谈你对「RPC」中「选型」的理解。
【标准回答话术】序列化选型：JSON（可读通用慢）、Protobuf（紧凑跨语言）、Hessian（Java 生态）、Kryo（快但不跨语言）。背后的原理是：考量维度：体积/速度/兼容性（字段增删）/跨语言/安全性（反序列化漏洞），Java 内部 Hessian/Kryo，对外 API JSON，跨服务 Protobuf。
【评分点】① 准确说出核心机制（选型）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
