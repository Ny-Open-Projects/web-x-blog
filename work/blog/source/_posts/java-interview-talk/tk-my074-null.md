## 类型 · null（null）—— 7 类问法与标准话术

**Qmysql-512（概念考察·P1-P3）**
【面试官】请谈谈你对「类型」中「null」的理解。
【标准回答话术】列默认尽量 NOT NULL：null 影响索引统计、count(col) 忽略 null、is null 判断易错。背后的原理是：null 参与比较结果为 unknown、聚合跳过 null、可空列索引需要额外标记，默认 NOT NULL+默认值是规范，但 is null 查询可以走索引。
【评分点】① 准确说出核心机制（null）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
