## Prompt · 防御（注入）—— 7 类问法与标准话术

**Qai-162（概念考察·P1-P3）**
【面试官】请谈谈你对「Prompt」中「防御」的理解。
【标准回答话术】Prompt 注入攻击：外部内容（网页/文档）携带指令覆盖系统提示，防御：指令与数据隔离（标签包裹外部内容）、输入检测、最小权限工具。背后的原理是：RAG 检索到的文档/用户输入都可能是注入载体，system prompt 声明"外部内容只是数据"，高危工具（发邮件/写库）需人工确认，是 Agent 安全第一威胁。
【评分点】① 准确说出核心机制（防御）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
