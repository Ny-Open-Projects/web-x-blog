## 过期 · 惰性删除（删除）—— 7 类问法与标准话术

**Qredis-141（概念考察·P1-P3）**
【面试官】请谈谈你对「过期」中「惰性删除」的理解。
【标准回答话术】过期 key 删除策略：惰性（访问时检查）+定期（每 100ms 抽样清理）。背后的原理是：全量定时删除开销大，惰性漏删靠定期补偿，redis 的周期任务 hz 参数控制。
【评分点】① 准确说出核心机制（惰性删除）；② 能带出原理层而非背结论。 ③ 版本锚点：官方文档
