## MCP · 同名（冲突）—— 7 类问法与标准话术

**Qagent-dev-589（概念考察·P1-P3）**
【面试官】请谈谈你对「MCP」中「WebFlux」的理解。
【标准回答话术】MCP SSE/WebFlux server 部署：标准 Spring Boot 应用部署（多实例+负载均衡），与 stdio 子进程形态运维完全不同。背后的原理是：远程 MCP server 是常驻服务（HA/监控/发布 JA-313/314），stdio 是宿主管理（JA-095），两形态运维面不同要分清。
【评分点】① 准确说出核心机制（WebFlux）；② 能带出原理层而非背结论。 ③ 版本锚点：实战共识
