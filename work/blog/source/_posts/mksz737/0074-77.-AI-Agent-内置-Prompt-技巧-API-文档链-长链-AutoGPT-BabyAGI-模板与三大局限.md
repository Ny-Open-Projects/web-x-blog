## 纲要

- **API 文档链 prompt**：给 LLM 工具使用手册文档 + 用户问题 → 组装 API 请求（URL/方式/参数）→ summary；本质是封装 prompt 提供足够上下文（类 GPTS 接口请求）。
- **长链 prompt**：更多上下文，让 LLM 先拆任务 → 按步找合适工具 → 按格式思考；感知/计划/实施/observe 循环，自动发消息=死循环直到达标（目标是否达成交 LLM 自判）。
- **AutoGPT prompt**：针对 GPT-4 上下文限制改 template；含目标 + `task_complete` 命令 + 约束（短期记忆 4000 词限制、重要信息存文件、回忆过去事件）+ 资源（联网/长期记忆/GPT-3.5 驱动简单任务/文件输出）+ 评估（自我批评/反思/最小步骤/成本）；输出 `thoughts/command/args` 由 JSON 解析。
- **BabyAGI prompt**：三 agent——创建任务（按前结果创新任务）、优先级排序（挑 Top5）、执行并标记完成；阻无限扩展。
- **斯坦福小镇**：定时随机触发任务/行动，模拟生活社交（未展开 prompt）。
- **三大局限**：① 短期记忆上下文限制（工具选择/上下文有限，厂商攻更长上下文）；② 交互延迟（逐步执行显笨，导游类比）；③ 幻觉（transformer 不确定性，输错只能续执行，多任务重复才发现错）。

> 本章按课程口径重构；产品名已规范化（AutoGPT/BabyAGI/GPTS/JSON）；剥离营销与课程群引流。

## 一、API 文档链与长链

- API 文档链：文档 + 问题 → 组装请求 → summary，封装上下文让 LLM 编码调接口。
- 长链：更多上下文，先拆任务再按步找工具；自动发消息构成循环直到达标。

## 二、AutoGPT 与 BabyAGI 模板

- AutoGPT：针对上下文限制，约束短期记忆 4000 词、重要信息存文件、输出 thoughts/command/args（JSON 解析）。
- BabyAGI：创建/优先级/执行三 agent，按前结果创新任务并排 Top5，阻无限扩展。

## 三、局限一：上下文与延迟

- 短期记忆上下文限制：工具选择与对话上下文有限，倒逼厂商做更长上下文/更快输出。
- 交互延迟：逐步执行显笨（对比经验导游即时给方案），但未来算力提升会飞跃。

## 四、局限二/三：幻觉

- 幻觉=transformer 不确定性，输错只能续执行，多任务重复才发现错。
- 三大局限共同指向：更长上下文、更快输出、多任务校验是攻防重点。

## 五、FAQ

**Q1：API 文档链 prompt 做什么？**
给文档+问题，让 LLM 组装 API 请求并 summary，封装上下文。

**Q2：AutoGPT 模板为什么限 4000 词？**
针对 GPT-4 上下文限制，重要信息存文件、回忆过去事件。

**Q3：BabyAGI 怎么防失控？**
创建/优先级/执行三 agent，按前结果创新任务并排 Top5。

**Q4：Agent 三大局限？**
上下文限制、交互延迟、幻觉（输错不可回溯）。

## 六、面试高频问答

**1. 长链 prompt 的核心？**
先拆任务再按步找工具，自动循环发消息直到达标。

**2. AutoGPT 输出格式？**
thoughts/command/args，JSON 解析供接口调用。

**3. Agent 为什么显笨？**
逐步执行+等待，交互延迟，对比人类即时方案显笨。

**4. 幻觉在 Agent 中如何暴露？**
输错只能续执行，多任务重复运行才发现错误。

## 七、ops 提示（增效）

> **模板学 AutoGPT**：约束记忆+存文件+JSON 输出，是工具连接关键。
>
> **BabyAGI 优先级必设**：防任务无限扩展烧 token。
>
> **幻觉靠多任务校验**：单轮不可信，重复执行暴露错误。
