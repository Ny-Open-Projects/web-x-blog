## 纲要

- **手动装 SD WebUI**：终端建非 root 用户（`adduser user`，SD 不允许 root 跑）→ `apt update` + 装 `python3-pip` + `libTCMALLOC`（权限坑多）→ `su user` → `git clone` → `python3.10 -m venv` 建虚拟环境（隔离依赖避版本冲突）→ `./webui.sh` 自动装 torch/torchvision。
- **模型传入**：百度网盘下好模型 → 传到 `root/autoDL-temp` → `move` 到 `models/stable-diffusion` → `chown user:user`；缺 `openai/clip` 从 HF 下丢目录。
- **端口与访问**：改 `webui-user.sh` 的 `COMMANDLINE_ARGS` 加 `--port 6006`，用实例"自定义服务"分配域名访问。
- **保存镜像**：更多 → 保存镜像（免费额度 30G，超量约 0.18 元/天/GB），释放 GPU 省钱、新实例直接加载复用。
- **社区镜像**：算法社区搜 SD WebUI，选下载量高/日期近/框架版本明（如 v1.8，含 xformers 加速、预装 anything/麦娜写实），开箱即用。
- **模型市场 codewithGPU**：`pip install codewithGPU requests` 后用命令快速下模型（比网盘快）；可发布私有/团队模型。
- **克隆实例**：按量关机后空闲 GPU 不足 → 克隆实例带数据盘（每天次数限）；或"无卡模式"开机看配置。
- **Conda 环境管理**：`conda create -n 名 python=3.11`、`activate`、`list`、`install`；`conda init` + bashrc 加 `conda activate` 自动激活；coffeeUI/SD 要求 3.10.6+ 别太新。

## 一、手动安装 SD WebUI

- 建非 root 用户 `adduser user`（SD 脚本禁 root 运行）；`apt update` 装 python3-pip + libTCMALLOC。
- `su user` → `git clone` → `python3.10 -m venv` 建虚拟环境 → `./webui.sh` 自动装 torch/torchvision。
- 虚拟环境隔离依赖，避 AI 库对 python 版本的硬性要求冲突。

## 二、模型传入与端口

- 百度网盘下模型 → `root/autoDL-temp` → `move` 到 `models/stable-diffusion` → `chown user:user`。
- 缺 `openai/clip` 从 HuggingFace 下丢目录；改 `webui-user.sh` 加 `--port 6006` 以便"自定义服务"访问。

## 三、保存镜像与社区镜像

- 保存镜像：更多 → 保存镜像（免费 30G，超量约 0.18 元/天/GB），释放 GPU 后新实例加载复用。
- 社区镜像：算法社区搜 SD WebUI，选下载量高/近日期/框架明（v1.8 等），含 xformers 加速、预装 anything/麦娜写实，开箱即用（注意单批数量别太高防爆显存）。

## 四、模型市场与克隆/Conda

- codewithGPU：`pip install codewithGPU requests`，命令快速下模型（比网盘快）；可发布私有/团队模型。
- 克隆实例：按量关机后空闲 GPU 不足 → 克隆带数据盘（每日次数限）；或"无卡模式"开机看配置。
- Conda：`conda create -n 名 python=3.11`/`activate`/`list`/`install`；bashrc 加 `conda activate` 自动激活；SD/coffeeUI 要求 3.10.6+ 别太新。

## 五、FAQ

**Q1：SD 为什么不能用 root 装？**
脚本禁止 root 运行，需 `adduser` 建普通用户再 `su`。

**Q2：模型怎么传进实例？**
百度网盘 → `autoDL-temp` → move 到 `models` → chown 改属主。

**Q3：社区镜像和手动装怎么选？**
求快用社区镜像（开箱即用）；要调文件/学流程用手动。

**Q4：克隆实例解决什么？**
按量关机后空闲 GPU 不足时，克隆带数据盘换新机继续。

**2. 保存镜像的价值？**

**3. codewithGPU 模型市场？**
命令快速下模型（比网盘快），可发私有/团队模型。
