## 纲要

- **来源**：论文《Principles for Prompt Engineering》（面向 Llama/GPT），中英对照版给出 26 条原则，适合 Llama 与 GPT 系。
- **精选原则（课程标注重点）**：
 1. 无需礼貌用语（请/谢谢），直接描述任务。
 2. 指明受众（专家/小白）。
 3. 复杂任务拆成系列简单提示做交互。
 4. 用肯定指令（执行），避免否定（不要）。
 5. 要清晰理解用「像对 11 岁孩子解释/用通俗语言」。
 6. 「我愿付 $X 小费以获得更好方案」——实测比不加更细致（光合作用例：加后多含重要性/探讨/参考）。
 7. 示例驱动（少样本）。
 8. 格式化提示：`### 指令` / `### 示例` 用符号+空行分隔各部分（指令/示例/问题/背景/输入），勿全连写。
 9. 用「你的任务是…」「必须完成…」短语（与 CoT 互补提准）。
 10. 「将受处罚」短语（同小费，更慎重）。
 11. 自然人类口吻回答。
 12. 逐步思考（step by step）。
 13. 确保回答无偏见、不依赖刻板印象（如女性职位推荐偏见）。
 14. 让模型反问澄清细节直到够信息（适合新领域/不会提问时）。
 15. 「教我某主题，结尾含测验但不直接给答案，答后判对错」——似面试。
 16. 设定角色（重要技巧）。
 17. 明确分隔符。
 18. 重复关键词/短语多次（防长文跑题，强化核心）。
 19. 思维链 COT（LangChain/LlamaIndex 提炼关键信息关联长文）。
 20. 输出引导符（末尾加期望开头引导方向，适短文）。
 21. 「请详细写关于 X 并加所有必要信息」。
 22. 改文本不改风格：「只修语法词汇使其自然，不改原写作风格」。
 23. 多文件编程：「每生成多文件代码就建脚本自动创建/修改文件」。
 24. 续写：「我为你准备了…」引导续写。
 25. 明确模型须遵循的要求（设规则）。
 26. 保样本风格相似：「据提供段落风格撰写」。
- **前沿工具推荐**：沉浸式翻译（Chrome 插件，配 OpenAI/DeepL API 或默认微软翻译，可译 PDF/网页）、OpenAI Translator（页面翻译）、AMiner（热点文献+微信阅读+与论文对话）、Monica（每日 100 次免费搜索/问答/总结/图片解释，付费 unlimited）、Glarity（网页总结+绘画+翻译，可总结 YouTube 视频、Ask YouTube Video，比 Monica 免额外付费）。

## 一、26 条原则来源与精选

- 论文《Principles for Prompt Engineering》中英对照，26 条适合 Llama/GPT；课程逐条核对价值并标注重点。
- **无需礼貌用语**：直接描述任务即可。
- **指受众/肯否指令/拆解/简单解释/小费/示例/格式化分隔/角色/COT** 等前面技巧的体系化汇总。

## 二、重点原则详解

- **小费效应实测**：光合作用例，加「我愿付 $X 以获得更好方案」后输出更细（含重要性/深入探讨/参考），但不加的直给版也较完整；差异在「获得更好方案」措辞。
- **分隔符关键**：用 `###`、空行、反引号区分指令/示例/问题/背景/输入，勿连写——连写模型难区分。
- **角色+肯定指令+COT 互补**：「你的任务是…必须…」+「逐步思考」+「确保正确」共同提准。
- **反问澄清（第14条）**：让模型先问 10 个问题你答，再输出——适合新领域/不会提问时。
- **教+测验（第15条）**：似面试，学完含测验不直接给答案、答后判对错。

## 三、其余原则速览

- 自然口吻、重复关键词防跑题、输出引导符、详写加必要信息、改文不改风、多文件自动建脚本、续写引导、明确规则、保风格相似等。
- 不必全用同一条；纯知识检索可脱离背景介绍使指令更具体。

## 四、前沿工具推荐

- **沉浸式翻译**：Chrome 插件，配 OpenAI/DeepL API 或默认微软翻译；可译 PDF 与网页中英对照（OpenAI 翻译比 DeepL 准，官方推 DeepL）。
- **OpenAI Translator**：页面翻译（见前面）。
- **AMiner（AMiner.cn）**：热点文献/文章，含微信阅读、引用、与论文对话（问 prompt 技巧等）。
- **Monica**：每日 100 次免费搜索/问答/总结/图片解释；右侧阅读/搜索/写作/翻译/绘画工具箱；付费 unlimited（如 $8.3/月含 GPT-4/Claude 查询）。
- **Glarity**：网页总结+绘画+翻译，可总结/对话 YouTube 视频（Ask YouTube Video）；免 Monica 额外付费，但 ChatGPT 模式约 4k token 限制（用 LangChain/LlamaIndex 提炼前面）。

## 五、FAQ

**Q1：26 条原则适合哪些模型？**
论文面向 Llama/GPT 系；多数通用，建议结合模型实测。

**Q2：「小费」措辞真有用吗？**
实测加「获得更好方案」后输出更细，但差异有限；可作提准小技巧。

**Q3：为什么要格式化分隔提示？**
用 `###`/空行区分各部分，连写模型难提取信息；分隔后按部分精准输出。

**Q4：推荐哪些翻译/文献工具？**
沉浸式翻译（PDF/网页）、AMiner（文献对话）、Monica/Glarity（网页总结+YouTube 摘要）。

## 六、面试高频问答

**1. 列举 5 条高价值 prompt 原则。**
无需礼貌用语、指受众、肯定指令、示例驱动、格式化分隔（或加 COT/角色/反问澄清）。

**2. 「小费」与「受处罚」短语作用？**
促使模型更慎重细致输出，属心理式提示干预，实测略提准。

**3. 第14/15条适合什么场景？**
新领域学习或不会提问时，让模型反问澄清（14）；教学自测用教+测验（15）。

**4. Glarity 与 Monica 区别？**
Glarity 免额外付费做网页/YouTube 总结翻译；Monica 有每日免费额度与工具箱，深入用需订阅。

## 七、ops 提示（增效）

> **原则挑用不堆砌**：纯检索可省背景，指令更具体。
>
> **分隔符必用**：`###`+空行区分指令/示例/输入，提准提解析。
>
> **工具按需装**：翻译用沉浸式翻译，文献用 AMiner，网页/视频总结用 Glarity。
