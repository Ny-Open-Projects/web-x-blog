## 纲要

- **平台定位**：AutoDL 云 GPU 租赁，初学按量计费；4090/24G 约 2.68 元/h，RTX3090 夜间更便宜（1.3–1.6 元/h），包月约 600+。
- **租用实例**：控制台 → 容器实例 → 租用；计费方式按量/包日/包周/包月（初学按量）；筛选 4090、选可扩容硬盘。
- **CUDA 版本**：选 11.8 或 12.2（向下兼容，高版并行能力更强）。
- **数据盘**：免费 50G，跑完删大模型基本够用。
- **基础镜像**：Miniconda（自带 python 环境）或 PyTorch 3.8 预装（CUDA 11.8）。
- **实例配置**：GPU 24G/CPU 12 核/内存 90G/系统盘 30G/数据盘 50G；余额不足 24h 关机、15 天释放。
- **快捷工具**：Jupyter/终端/文件上传；AutoPanel 公网网盘（百度网盘授权，apps/autoDL 目录传大文件最方便）。
- **百度网盘配置**：设独立访问密码 → 百度网盘创建应用（软件 autoDL）→ 获取 access token → AutoPanel 添加授权 → 上传/下载（仅能到"我的应用数据/apps/autoDL"）。

## 一、租用与计费

- 注册认证后低价用 4090/24G（初学按量，约 2.68 元/h）。
- 控制台租用实例：按量/包日/包周/包月；初学选按量，筛选 4090 + 可扩容硬盘。

## 二、CUDA 与镜像

- CUDA 选 11.8/12.2（向下兼容）；基础镜像 Miniconda 或 PyTorch 3.8 预装（CUDA 11.8）。
- 实例：GPU 24G/CPU 12 核/内存 90G/系统盘 30G/数据盘 50G。

## 三、文件传输：AutoPanel 公网网盘

- AutoPanel 提供公网网盘（百度网盘授权），传大文件最方便。
- 配置：设独立访问密码 → 百度网盘创建应用（软件选 autoDL）→ 获取 access token → 添加授权。
- 上传/下载仅到"我的应用数据/apps/autoDL"，可回实例面板查看。

## 四、计费与释放

- 余额不足 24h 关机、15 天释放；按量关机即停计费，包月/包天关机仍计费。
- 大数据上传下载优先用公网网盘，非小文件不用终端 scp。
