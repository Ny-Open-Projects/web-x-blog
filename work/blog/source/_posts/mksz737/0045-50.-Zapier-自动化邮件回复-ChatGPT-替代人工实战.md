## 纲要

- **目标**：用 Zapier（自动化流程工具）接 ChatGPT，收到新邮件→LLM 分析→模拟发件人语气自动回信→发回，跑通「AI 代回邮件」流水线。
- **gmail 折中**：gmail 更新政策后不允许第三方直接发信（仅部分如 Facebook 可），改用 **Outlook** 作邮件触发器与发送器。
- **核心配置链路**：New Email 触发 → ChatGPT（API Key + 模型 + 内置 instruction + 邮件内容拼装 prompt）→ Send Email 回复。
- **Prompt 模板**：从邮件提取学员名与问题 → 套用回复模板 → 把 Markdown 转 HTML 更美观；可加 filter 过滤（body 含「老师/问题」才处理）。
- **关键参数**：模型选 GPT-3.5 Turbo（便宜快，上下文 16k、回复 4k token）；temperature/top_p 设一致（建议 1 或 0.8，给一定随机性更易理解用户）；max token 写小些防流水线跑不通。

> 本章按课程口径重构；产品名已规范化（Zapier）；剥离营销与课程群引流。

## 一、整体效果与前置

- 模拟学生发邮件问课程问题 → 账号收到后交 LLM 分析 → 按预设 prompt 模拟讲师语气回信 → 自动发出。
- 前置：注册 Zapier 账号；准备 ChatGPT API Key（platform.openai.com → API keys → Create secret key）；准备 Outlook 邮箱（gmail 因政策限制改 Outlook）。

## 二、构建流水线

1. **触发器**：选 Outlook 的 New Email 事件（企业共享邮箱可指定 inbox，个人留空）。
2. **ChatGPT 步骤**：登录 ChatGPT 账号填 API Key；选模型（3.5 Turbo 最划算）；在 Action 用 Insert Data 把 new email 的发件人/正文（body content）拼进 prompt。
3. **Prompt 设计**：「帮写回复邮件——收到付费学员关于课程问题的邮件，从内容提取学员名与不明确的问题，套用下列模板描述问题并尝试解答；若响应是 Markdown 源码转成 HTML」。
4. **发送步骤**：选 Outlook 的 Send Email；To = from email，Subject 用「RE:」+ 原主题，Body Format 选 HTML，Body 取 ChatGPT 回复；点对点回复个人，营销场景才需邮件服务商群发。

## 三、参数与调试

- **模型与 token**：3.5 Turbo 上下文约 16k token、回复上限 4k；API 接口对 3.5 头部数量最大 4096（官方限制）。
- **temperature / top_p**：二者类似，控制随机性（0=完全聚焦、2=高创意）。建议设一致（如都 1 或 0.8）；只设其一即可，不要同时设两个不同值。
- **instruction（内置上下文）**：「你是专业邮件回复专家，考虑用户情绪与交际，针对问题回复；用户用什么语言你用什么语言，以中文为主」。
- **常见坑**：usermessage 漏填会报 `user_message is missing`；max token 写 4096 可能 conversation 流程跑不通，调小即可；发布前关掉旧测试流程避免干扰。

## 四、过滤与判断

- 加 Filter 步骤：body content contains「老师/问题」才进流程，过滤无需处理的邮件。多条件用 AND（都满足）或 OR（任一满足）。

## 五、FAQ

**Q1：为什么不用 gmail 直发？**
gmail 更新邮件政策，仅允许部分应用直发，第三方回复邮件受限；改用 Outlook 折中。

**Q2：自动回信用什么模型划算？**
GPT-3.5 Turbo 最便宜最快，流程化场景足够；有 GPT-4 权限再升级。

**Q3：temperature 设多少好？**
建议 1 或 0.8，给一定随机性更易理解用户；纯摘要场景调低（如 0）减少发挥。

**Q4：怎么避免误回无关邮件？**
加 Filter：正文含「老师/问题」等关键词才触发，用 AND/OR 组合条件。

## 六、面试高频问答

**1. 简述 Zapier+ChatGPT 自动回信的链路。**
Outlook New Email 触发 → 拼装发件人/正文进 prompt → ChatGPT（API Key+模型+instruction）生成 HTML 回复 → Outlook Send Email 点对点回信。

**2. 自动化邮件为什么要 Markdown 转 HTML？**
纯 Markdown 长段无分行显乱；转 HTML 嵌入邮件模板后排版更舒适、专业。

**3. temperature 与 top_p 的关系？**
都控制生成随机性；建议设为同一值（如 1），只设其一，避免冲突。

**4. 生产环境自动回信注意什么？**
gmail 政策限制改 Outlook；加 filter 防误回；max token 不宜过大防流程失败；发布前关旧测试流。

## 七、ops 提示（自动化）

> **先跑通再精修**：课程先打通流水线，prompt 后续可订制更精准/具体。
>
> **点对点 vs 群发**：个人回复用 Outlook 点对点；营销群发需用邮件服务商。
>
> **参数留余地**：max token 调小防 Zap 流程中断；temperature 给随机性提升理解。
