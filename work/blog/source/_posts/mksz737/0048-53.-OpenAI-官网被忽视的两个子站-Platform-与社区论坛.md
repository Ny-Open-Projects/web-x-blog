## 纲要

- **子站一：Platform（platform.openai.com）**
 - **Examples**：官方示例分类——extract（解析/摘要拆分）、generate（生成）、transform（转换）、code（代码）、natural language、structure data（结构化数据）；可搜「summarize/explaine code」看 prompt 与 sample response、接口形态。
 - **Playground**：创建 Assistant / 微调后的 chat 可在此访问；调 temperature（越高随机性越强，摘要类调低）、max tokens（控制响应长度）；hover 看参数说明；Learn 学接口开发；切换 Node.js / Python 示例代码（View Code）。
- **子站二：官方社区论坛（forum）**
 - 按 tag 筛选（plugin / plugin-development / API / usage / announcements 等）；announcements 为一手官方公告（锁回复）。
 - 如「自定义 GPT 文件未持久化（knowledge files don't get persisted）」有官方开发者回复，像追剧看需求排期。
- **延伸**：官方 Blog（Company→Blog，含 Overview/Security/Research）、Twitter/X、Careers；Blog 与 Research 发布内部最新动态（如 GPTs 发布、Altman 回归）。

> 本章按课程口径重构；界面名词已规范化；剥离营销与课程群引流。

## 一、Platform 子站

- **Examples 区**：覆盖 extract/generate/transform/code/natural language/structure data 六类官方示例；点 generate 看方案、搜「summarize 给二年级生总结」「explain code」看 prompt 与 sample response、接口样式。示例浅显但可据此了解功能边界与调用方式。
- **Playground 区**：左侧可创建 Assistant 或访问微调后的 chat，发消息得响应；调 temperature（摘要类调低少发挥）、max tokens（控长度）；hover 弹参数说明；点 Learn 学接口开发；View Code 切 Node.js/Python 示例（二者皆解释型语言）。

## 二、官方社区论坛

- 按标签筛感兴趣方向（文件上传/plugin/API/账号等），看哪些 tag 量大即关注度高（如 chatgpt-plugin、plugin-development、API、usage）。
- **announcements**：官方一手公告，锁回复只能浏览，信息极有用。
- **开发者互动**：如用户反馈「自定义 GPT 上传文件未被理解/丢失」，官方开发者回帖；像追剧看功能排期与进度，很多讨论有趣。

## 三、延伸信息源

- **Blog**：官网 Company→Blog，重点看 Overview/Security/Research；发布内部动态（GPTs 发布、Altman 回归等）。
- **Research**：AI 研究与贡献动态。
- **社交媒体**：Twitter/X、Careers 招聘。

## 四、FAQ

**Q1：Platform 的 Examples 有什么用？**
按六类（解析/生成/转换/代码/自然语言/结构化）给官方 prompt 与接口示例，快速了解能力边界。

**Q2：Playground 调 temperature 注意什么？**
越高随机性越强；摘要/精确类任务调低，减少不必要发挥。

**Q3：论坛 announcements 为什么值得看？**
是一手官方公告（锁回复），含 GPTs 发布、政策变更等关键信息。

**Q4：自定义 GPT 文件丢失怎么办？**
论坛有官方回复案例：文件可能未持久化（knowledge files don't get persisted），需确认上传与存储链路。

## 五、面试高频问答

**1. OpenAI 哪两个子站常被忽视？**
Platform（Examples+Playground）与官方社区论坛；前者看示例/调参/示例码，后者看公告与开发者互动。

**2. Playground 的核心参数？**
temperature（随机性，摘要调低）、max tokens（响应长度）；hover 看说明，支持 Node.js/Python 示例。

**3. 怎么获取 OpenAI 一手信息？**
论坛 announcements + 官方 Blog（Overview/Security/Research）+ Research 页，而非二手搬运。

**4. Examples 六大分类是什么？**
extract、generate、transform、code、natural language、structure data。

## 六、ops 提示（情报）

> **先翻 Examples 再写代码**：官方示例直接给 prompt 与接口形态，省试错。
>
> **论坛看公告与排期**：announcements + 开发者回帖，掌握功能上线与坑。
>
> **Blog/Research 跟前沿**：内部动态与论文级研究，比社媒八卦准。
