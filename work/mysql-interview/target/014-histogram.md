# 014 直方图

> 分类：MySQL 8.0 新特性/优化 | 难度：L2 | 题型：概念主问 | 频率：中 | 关键词：**直方图** / **ANALYZE TABLE** / **列统计** / **执行计划**
> 原文锚点：第 272~275 段「8.0 支持数据直方图，优化器用列分布判断执行计划」

## 一句话总述
MySQL 8.0 引入**直方图（Histogram）**：对列统计值分布，优化器据此生成更准确的执行计划；用 `ANALYZE TABLE ... UPDATE HISTOGRAM` 创建，弥补索引在非均匀分布列上的统计短板。

## 面试官视角
- **考察意图**：是否知道 8.0 除索引外的统计手段。
- **P5** 知道 8.0 有直方图。
- **P6** 能说清直方图补充列分布统计、改善执行计划。
- **P7** 能讲何时用直方图而非索引（大基数列、非等值查询）。
- **红旗**：说「直方图就是另一种索引」。
- **惊艳点**：点出直方图存在 `mysql.column_statistics` 字典表，不占存储引擎索引 `[源码]`。

## 主问答
**Q：MySQL 的直方图有什么用，怎么建？**
**A：**
1. **结论**：直方图让优化器掌握**列值分布**，对无索引或索引选择性差的非等值/`IN` 查询给出更优计划。
2. **机制**：`ANALYZE TABLE t UPDATE HISTOGRAM ON col WITH N BUCKETS` 采样建桶；优化器读分布决定行数估算，减少误走全表/错选 JOIN 顺序。
3. **边界**：直方图不替代索引（索引用于定位/排序），适合**大基数、非均匀、少更新**的列；列更新频繁需重建。
**加分层**：与不可见索引配合，可先验证统计再决定是否建索引。
