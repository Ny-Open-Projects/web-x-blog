# 037 ANSI_QUOTES：禁止双引号当字符串

> 分类：服务器配置 | 难度：L2 | 题型：八股题 | 频率：中 | 关键词：**ANSI_QUOTES** / **双引号** / **可移植性**
> 原文锚点：第 81~92 段「ANSI_QUOTES 的作用是禁止使用双引号来引用一个字符串，使 MySQL 的工作方式更接近于标准 SQL」

## 一句话总述
默认 MySQL 允许用**双引号表示字符串**；加上 `ANSI_QUOTES` 后**双引号只能作标识符引号**，字符串必须用单引号——提前堵住将来迁移/升级的坑。

## 面试官视角
- **考察意图**：看你是否关注 SQL 的**可移植性**，而不只是"能跑就行"。
- **P5** 知道字符串标准写法是单引号。
- **P6** 能说出 `ANSI_QUOTES` 的作用：双引号被解释为标识符，用它括字符串会报错。
- **P7** 能讲清为什么要开：提前暴露不标准写法，避免数据库迁移或版本升级时批量改程序。
- **红旗**：① 以为双引号在任何数据库都能当字符串；② 开启后不知如何改（应改单引号而非去掉限制）。
- **惊艳点**：开启后 `"abc"` 被当成**列名**（标识符），报的是"Unknown column"而不是语法错误 `[经验]` —— 验证：`SELECT "abc";` 在开启前后对比报错信息。

## 主问答
**Q（面试官原话）：** 你们项目里双引号能当字符串用吗？要不要限制？

**A：**
1. **结论**：默认可以，但**建议用 `ANSI_QUOTES` 禁掉**——标准 SQL 规定字符串用单引号。
2. **机制**：开启后双引号只作**标识符引号**，`WHERE name = "abc"` 会被解析成列名 `abc`，直接报错。
3. **边界**：代价是存量代码里所有双引号字符串都要改成单引号，所以**新项目建议开、老项目要评估改造量**。

**加分层**：真正的价值是**提前暴露不标准写法**——否则等迁移到其他数据库或升级后不再兼容时，要改的是成千上万处。

## 关键代码
```sql
SET SESSION sql_mode = CONCAT(@@sql_mode, ',ANSI_QUOTES');
SELECT 'abc';    -- OK：单引号字符串
SELECT "abc";    -- 报错：被当成列名（Unknown column 'abc'）
```

- `ANSI_QUOTES`：双引号**只能作标识符**，字符串一律单引号。
- 价值在**提前暴露不标准写法**，降低迁移成本。
